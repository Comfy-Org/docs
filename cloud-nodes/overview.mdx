A Comfy Cloud node is a regular ComfyUI node that sends its job to run on Comfy's own GPUs instead of the local machine. Drop it into a graph like any other node. No subscription is required: an account and credits are enough, the same as any other partner node.

<Note>
**Not the same as Comfy Cloud, and not the same as Partner Nodes.** Comfy Cloud nodes are a distinct feature from two things with similar names:

- **Comfy Cloud** is the hosted, subscription-based version of ComfyUI at cloud.comfy.org. Its Creator and Pro plans support bringing your own LoRA from CivitAI or Hugging Face. Comfy Cloud nodes do not support that yet, see Limitations below.
- **Partner Nodes** usually refers to the separate, larger catalog of third-party API model integrations (Kling, MiniMax, Gemini, and others). Comfy Cloud nodes are built on the same node plumbing but call Comfy's own infrastructure specifically, not a third-party API.
</Note>

## What it is

Each Comfy Cloud node runs one fixed workflow on a pinned model version, so a saved graph keeps producing the same result over time. Your graph, prompts, and inputs stay on your machine apart from what the node sends to run the job.

## Available nodes

Nine nodes at launch, across image, video, and audio:

| Node | Modality |
| --- | --- |
| Comfy Cloud Flux 2 Text to Image | Image |
| Comfy Cloud Mage Flow Text to Image | Image |
| Comfy Cloud Mage Flow Turbo Text to Image | Image |
| Comfy Cloud Z-Image Turbo Text to Image | Image |
| Comfy Cloud MiniMax H3 Text to Video | Video |
| Comfy Cloud MiniMax H3 Image to Video | Video |
| Comfy Cloud MiniMax H3 First-Last Frame to Video | Video |
| Comfy Cloud MiniMax H3 Reference to Video | Video |
| Comfy Cloud MiniMax Music 3 Text to Audio | Audio |

This list is sourced from `comfy_api_nodes/nodes_comfy_cloud.py` in the ComfyUI repository. Keep it in sync with that file rather than with any planning document, since planning documents for this feature have drifted from what actually shipped at least once.

## Billing

Comfy Cloud nodes are billed per GPU-second in credits, shown on the node before you run it. There is no subscription and no monthly floor.

## Limitations

- No bring-your-own LoRA or checkpoint yet. Each node exposes a fixed set of hosted weights. Direct upload is a planned next step, not available in this release.
- On the classic canvas (the default view for a plain local install, as opposed to the newer Vue-based canvas), a Comfy Cloud node does not yet carry a distinct Comfy badge. It looks like any other partner node until that lands.
