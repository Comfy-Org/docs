## Comfy Cloud サブスクリプション管理へのアクセス

1. [cloud.comfy.org](https://cloud.comfy.org/?utm_source=docs) にアクセスしてログインします。
2. プロフィールメニューを開き、**プランを管理** をクリックします。
3. **プランとクレジット** で、**請求と請求書** をクリックします。

これにより Stripe の請求ポータルが開き、支払い方法と請求書を管理できます。プランを変更するには、Comfy Cloud 内の **プランを変更** を使います。[Comfy Cloud プランの変更](/ja/support/subscription/changing-plan) を参照してください。
