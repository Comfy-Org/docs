Comfy Cloud の請求書は **プランとクレジット** から確認できます。**請求と請求書** は Stripe の請求ポータルを開き、請求書一覧と PDF ダウンロードはそこにあります。

## Comfy Cloud の支払い履歴へのアクセス

1. [cloud.comfy.org](https://cloud.comfy.org/?utm_source=docs) にアクセスしてログインします。
2. プロフィールメニューを開き、**プランを管理**をクリックします。
3. **プランとクレジット**で、**請求と請求書**をクリックします。Stripe の請求ポータルが開きます。
4. Stripe で請求書を開いて詳細を表示するか、PDF をダウンロードします。

新しい請求書が生成される前に、請求先情報が正しいことを確認してください。これらは [Comfy Cloud の支払い情報の編集](/ja/support/payment/editing-payment-information) から更新できます。

## 請求書が発行されるタイミング

Comfy Cloud は、サブスクリプションの更新やクレジット購入など、決済が成功するたびに請求書を発行します。請求書は Stripe の請求ポータルで他の請求とともに表示されます。
