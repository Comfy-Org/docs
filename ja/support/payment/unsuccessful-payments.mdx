Comfy Cloud の支払いが失敗すると、未払いの請求書が決済されるまでワークスペースのサブスクリプションが一時停止することがあります。購入済みのクレジットはワークスペースに残ります。復元は **プランとクレジット** から始まります。ComfyUI は支払い失敗専用のバナーを表示しません。

## Comfy Cloud の支払いが失敗するとどうなりますか

1. 購入済みのクレジットはワークスペースに残ります。残高が尽きたとき、またはワークスペースが支払いの復旧状態にあるときは実行が拒否されます。
2. 支払いが滞っているワークスペースでは、**プランとクレジット** のクレジット不足バナーに **お支払い方法を更新** が表示され、未払いの請求書が決済されるまでサーバーは新しいチャージを拒否します。この状態で **クレジットを追加** をクリックすると、チャージ画面ではなく **お支払いが完了しませんでした** というタイトルの支払い復旧ダイアログが開きます。
3. 請求管理ができないワークスペースメンバーには、ワークスペースオーナーへの連絡が案内されます。

## 支払い失敗後のお支払い方法の更新

1. [cloud.comfy.org](https://cloud.comfy.org/?utm_source=docs) にアクセスしてログインします。
2. プロフィールメニューの **プランを管理**、または **設定 → ワークスペース → プランとクレジット** から **プランとクレジット** を開きます。
3. クレジット不足バナーの **お支払い方法を更新** をクリックするか、**請求と請求書** をクリックして Stripe 請求ポータルを開きます。
4. Stripe で未払いの請求書を支払い、お支払い方法を更新して保存します。

[Comfy Cloud の支払い情報の編集](/ja/support/payment/editing-payment-information) を参照してください。

## 支払いが失敗する一般的な理由

### 資金不足

- カードの利用可能残高または信用限度額が不足しています
- **解決策**: 資金を追加するか、別の支払い方法を使用してください

### カードの有効期限切れ

- クレジットカードまたはデビットカードの有効期限が切れています
- **解決策**: 有効なカードで支払い情報を更新してください

### 情報の誤り

- カード番号、CVV、または請求先住所が正しく入力されていません
- **解決策**: 支払い詳細を確認して修正してください

### 発行元によるカードの拒否

- 銀行またはカード発行元が取引を拒否しました
- **解決策**: 銀行に連絡して支払いを承認してください

### 国際的な制限

- カードが国際取引をサポートしていません
- **解決策**: 国際支払いを有効にするか、別のカードを使用してください

### セキュリティによる保留

- 銀行が取引を不審なものとしてフラグ付けしました
- **解決策**: 銀行に連絡して、請求の確認と承認を得てください

## 将来の支払い失敗を防ぐには

- 支払い情報を最新の状態に保ってください
- 請求日の前にカードに十分な資金があることを確認してください
- 有効期限が切れる前にカードの詳細を更新してください
- 銀行に Comfy Organization Inc からの請求を許可するよう依頼してください

## サポートが必要ですか？

これらの解決策を試しても支払い問題が続く場合は、以下の情報を添えて [サポートチーム](https://support.comfy.org/) にお問い合わせください：

- アカウントのメールアドレス
- 受信したエラーメッセージ
- 使用しようとしている支払い方法
- 関連する取引 ID
