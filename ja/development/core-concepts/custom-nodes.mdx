## カスタムノードについて

ComfyUI をインストールした後、ComfyUI には多くの組み込みノードが含まれていることに気づくでしょう。これらのネイティブノードは **Comfy Core** ノードと呼ばれ、ComfyUI 公式によってメンテナンスされています。

さらに、ComfyUI コミュニティのさまざまな作者によって作成された数多くの [**カスタムノード**](https://registry.comfy.org) があります。これらのカスタムノードは ComfyUI に広範な機能をもたらし、その能力と機能の範囲を大幅に拡張します。

このガイドでは、カスタムノードに関連するさまざまな操作について説明します。インストール、更新、無効化、アンインストール、依存関係のインストールなどを含みます。

誰でも ComfyUI 用の独自のカスタム拡張機能を開発し、他の人と共有することができます。多くのコミュニティカスタムノードを [こちら](https://registry.comfy.org) で見つけることができます。独自のカスタムノードを開発したい場合は、以下のセクションを訪れて開始してください：

### 1. カスタムノードのインストール

現在、ComfyUIは複数の方法でカスタムノードのインストールをサポートしています。以下の方法があります：

- [ComfyUIマネージャーを使用したインストール（推奨）](#install-via-comfyui-manager)
- Gitを使用したインストール
- 手動インストール

カスタムノードは**ComfyUIマネージャー**を使用してインストールすることを推奨します。これはComfyUIのカスタムノードエコシステムにおいて非常に重要なツールです。これにより、カスタムノードの管理（検索、インストール、更新、無効化、アンインストールなど）が簡単になります。ComfyUIマネージャーでインストールしたいノードを検索し、クリックしてインストールするだけです。

ただし、現在すべてのカスタムノードはGitHubに保存されているため、GitHubに正常にアクセスできない地域向けに、このガイドではさまざまなカスタムノードのインストール方法について詳しく説明します。

また、プラグイン管理には**ComfyUIマネージャー**の使用を推奨しているため、このツールを使用したプラグイン管理をお勧めします。ソースコードは[こちら](https://github.com/Comfy-Org/ComfyUI-Manager)で確認できます。

そのため、このドキュメントでは、ComfyUIマネージャーをカスタムノードインストールの例として使用し、関連する紹介セクションでノード管理の使用方法について補足します。

<Tip>GitHubにスムーズにアクセスできない地域の場合は、他のコードホスティングサービスサイト（giteeなど）で対応するリポジトリをフォークし、そのリポジトリアドレスを使用してノードインストールを完了することもできます。</Tip>

```bash
cd D:\ComfyUI_windows_portable\ComfyUI\custom_nodes
```

次に、`git clone`コマンドを使用してノードインストールを完了します。

```bash
git clone https://github.com/Comfy-Org/ComfyUI-Manager
```

![Gitでカスタムノードをインストール](/images/concepts/custom_nodes/install_custom_nodes_by_git.jpg)

これはカスタムノードコードのクローンが成功したことを意味します。次に、対応する依存関係をインストールする必要があります。
</Step>

</Step>
</Steps>

### 2. ノード依存関係のインストール

カスタムノードはすべて、関連する依存関係のインストールが必要です。例えば、ComfyUI-Managerの場合、[requirements.txt](https://github.com/Comfy-Org/ComfyUI-Manager/blob/main/requirements.txt)ファイルにアクセスして依存パッケージの要件を確認できます。

前の手順では、カスタムノードコードをローカルにクローンしただけで、対応する依存関係はインストールしていません。そのため、次に対応する依存関係をインストールする必要があります。

<Note>
実際には、ComfyUI-Managerを使用してプラグインをインストールすると、ComfyUI Managerが自動的に依存関係のインストールを完了します。プラグインのインストール後、ComfyUIを再起動するだけで済みます。これが、ComfyUI Managerを使用してカスタムノードをインストールすることを強く推奨する理由です。

ただし、状況によってはComfyUI Managerを使用してカスタムノードをスムーズにインストールできない可能性があるため、より詳細な依存関係インストールガイドを提供しています。
</Note>

[依存関係](/ja/development/core-concepts/dependencies)の章では、ComfyUIにおける依存関係に関する関連コンテンツを紹介しました。ComfyUIは**Python**ベースのプロジェクトであり、ComfyUIを実行するために独立した**Python**ランタイム環境を構築しています。すべての関連依存関係は、この独立した**Python**ランタイム環境にインストールする必要があります。

システムレベルのターミナルで直接`pip install -r requirements.txt`を実行すると、対応する依存関係がシステムレベルの**Python**環境にインストールされる可能性があり、ComfyUIの環境では依存関係が不足し、対応するカスタムノードが正常に動作しなくなります。

そのため、次にComfyUIの独立したPythonランタイム環境を使用して依存関係のインストールを完了する必要があります。

ComfyUIのバージョンによって、対応する依存関係のインストール方法が異なります：

<Tabs>
<Tab title="ComfyUIポータブル版">
ComfyUIポータブル版では、`\ComfyUI_windows_portable\python_embeded`ディレクトリにある組み込みPythonを使用します。このPythonを使用して依存関係のインストールを完了する必要があります。

まず、ポータブル版ディレクトリでターミナルを起動するか、ターミナルを起動してから`cd`コマンドで`\ComfyUI_windows_portable\`ディレクトリに移動します。

![ターミナルの起動](/images/concepts/custom_nodes/open_terminal.jpg)

ターミナルのディレクトリが`\ComfyUI_windows_portable\`であることを確認します。下の例では`D:\ComfyUI_windows_portable\`です。

![ターミナル](/images/concepts/custom_nodes/terminal.jpg)

次に、`python_embeded\python.exe`を使用して依存関係のインストールを完了します：

```bash
python_embeded\python.exe -m pip install -r ComfyUI\custom_nodes\ComfyUI-Manager\requirements.txt
```
もちろん、ComfyUI-Managerを実際にインストールしたカスタムノードの名前に置き換えることもできますが、対応するノードディレクトリに`requirements.txt`ファイルが存在することを確認してください。
</Tab>

<Tab title="Comfyデスクトップ">

<Tip>
Comfyデスクトップでは、インストールプロセス中にすでにComfyUI-Managerとその依存関係がインストールされているため、デスクトップ版でComfyUI Managerの依存関係を手動でインストールする必要はありません。
問題がなければ、ComfyUI Managerを使用してカスタムノードをインストールすることをお勧めします。これにより、手動で依存関係をインストールする必要がありません。
</Tip>

![Comfyデスクトップターミナル](/images/concepts/custom_nodes/desktop_terminal.png)
 
次に、以下のコマンドを使用して対応するプラグインの依存関係をインストールします：

```bash
pip install -r .\custom_nodes\<対応するカスタムノード名>\requirements.txt
```
下図は、ComfyUI-Hunyuan3Dwrapperの依存関係インストールの例です：

![Comfyデスクトップ依存関係のインストール](/images/concepts/custom_nodes/install_dependencies.png)

</Tab>

<Tab title="カスタムPython環境ユーザー">
カスタムPython環境を使用しているユーザーは、`pip install -r requirements.txt`を使用して依存関係のインストールを完了することをお勧めします。
</Tab>

</Tabs>

### カスタムノードのバージョン管理

カスタムノードのバージョン管理は、実際にはGitのバージョン管理に基づいています。Gitを使用してノードのバージョンを管理できますが、ComfyUI Managerはこのバージョン管理機能を非常にうまく統合しています。[@Dr.Lt.Data](https://github.com/ltdrdata) 氏に感謝します。このような便利なツールを提供してくれてありがとうございます。

このセクションでは、これら2つの異なるプラグインバージョン管理方法について説明します。ただし、ZIPパッケージを使用して手動インストールを行うと、対応するGitバージョン履歴情報が失われ、バージョン管理ができなくなります。

<Tabs>

<Tab title="ComfyUI Managerを使用したバージョン管理">

<Tip>ComfyUI Managerは現在も反復開発中であるため、実際の最新のインターフェースや手順は大幅に変更される可能性があります。</Tip>

<Steps>
<Step title="ノード管理インターフェースに入る">
図のように該当の操作を行い、ComfyUI Managerのインターフェースに入ります。
</Step>
<Step title="該当のカスタムノードパッケージを見つける">
対応するフィルターを使用してインストール済みのノードパッケージを絞り込み、該当のノード管理を行います。
</Step>
<Step title="バージョンの切り替えを実行する">
該当のバージョンに切り替えます。Managerが対応する依存関係の更新とインストールを完了します。通常、バージョン切り替え後はComfyUIを再起動して変更を有効にする必要があります。
</Step>
</Steps>

</Tab>

<Tab title="Gitを使用したバージョン管理">

<Steps>
<Step title="コマンドラインでディレクトリに移動する">

該当のノードが格納されているディレクトリフォルダーを見つけます（例：`ComfyUI/custom_nodes/ComfyUI-Manager`）。
`cd` コマンドを使用して該当のフォルダーに入ります：
```bash
cd <インストール先ディレクトリ>/ComfyUI/custom_nodes/ComfyUI-Manager
```

</Step>
<Step title="Gitコマンドでバージョンを確認する">

次のコマンドを使用して、利用可能なすべてのタグとリリースを表示できます：
```bash
git tag
```
これにより、すべてのバージョンタグが一覧表示され、切り替えたいバージョンを選択できます。

</Step>
<Step title="指定バージョンに切り替える">

次のコマンドを使用して、指定したタグまたはリリースに切り替えます：
```bash
git checkout <タグ名>
```
`<タグ名>` を切り替えたい特定のバージョンタグに置き換えてください。

</Step>
<Step title="特定のコミットバージョンに切り替える">

特定のコミットバージョンに切り替えたい場合は、次のコマンドを使用できます：
```bash
git checkout <コミットハッシュ>
```
`<コミットハッシュ>` を切り替えたい特定のコミットハッシュに置き換えてください。

</Step>
<Step title="依存関係をインストールする">

バージョン切り替え後、対応するカスタムノードパッケージの依存関係が変更される可能性があるため、該当のノードの依存関係を再インストールする必要があります。「[ノード依存関係のインストール](#2-ノード依存関係のインストール)」セクションの手順を参照して、該当の環境に入りインストールを行ってください。
</Step>
</Steps>

### マネージャーのインストール

ComfyUI サーバーアプリケーションを実行している場合、マネージャーをインストールする必要があります。ComfyUI が実行されている場合は、続行する前に閉じてください。

最初のステップは Git のインストールです。これはソフトウェアバージョン管理のためのコマンドラインアプリケーションです。Git は [github.com](https://github.com) から ComfyUI マネージャーをダウンロードします。[git-scm.com](https://git-scm.com/) から Git をダウンロードしてインストールします。

Git をインストールした後、ComfyUI サーバープログラムディレクトリに移動し、**custom_nodes** とラベル付けされたフォルダーに入ります。コマンドウィンドウまたはターミナルを開きます。コマンドラインが現在のディレクトリパスを **custom_nodes** として表示していることを確認します。以下のコマンドを実行して ComfyUI-Manager リポジトリをクローンします：

```bash
git clone https://github.com/Comfy-Org/ComfyUI-Manager.git
```

これによりマネージャーがダウンロードされます。技術的には、これは _Git リポジトリのクローン_ と呼ばれます。
