Comfy Router を使うと、1つの Comfy APIキーで `https://api.comfy.org` を通じてパートナーモデルを呼び出せます。モデルの入力を `POST /v2/models/{provider}/{model}` に送信し、完了した結果を待ちます。この例では `bfl/flux-2-pro` で画像を生成します。

<Steps>
  <Step title="APIキーを作成する">
    [Comfy ワークスペース](https://platform.comfy.org/profile/api-keys)でキーを作成します。Bash 互換のターミナルで、次を設定します：

    ```bash
    export COMFY_API_KEY="comfyui-..."
    ```

    APIキーはサーバー上またはローカル環境に保管してください。これらの例はターミナルまたはサーバー向けであり、ブラウザの JavaScript 向けではありません。
  </Step>

  <Step title="このリクエスト用のキーを保存する">
    この画像に対して、この値を一度だけ生成します。同じリクエストを再試行する場合は、それを再利用してください。

    ```bash
    export COMFY_REQUEST_KEY="$(uuidgen)"
    ```

    `uuidgen` が利用できない場合は、別の UUID ジェネレーターを使用してください。新しい画像を開始するときは、新しいキーを使用します。
  </Step>

  <Step title="画像を生成する">
    言語を選択して例を実行します。画像生成には数分かかることがあります。

    <CodeGroup>

    ```bash cURL
    curl --max-time 660 \
      https://api.comfy.org/v2/models/bfl/flux-2-pro \
      -H "X-API-Key: $COMFY_API_KEY" \
      -H "Idempotency-Key: $COMFY_REQUEST_KEY" \
      -H "Content-Type: application/json" \
      -d '{"prompt": "a red teapot on a windowsill, morning light"}'
    ```

    ```python Python
    # Python 3.10+
    # Install: python -m pip install "comfy-sdk>=0.1.9"
    # Save as quickstart.py, then run: python quickstart.py

    import os

    from comfy_sdk import Comfy

    # Comfy reads COMFY_API_KEY from the environment.
    with Comfy() as client:
        result = client.models.run(
            "bfl/flux-2-pro",
            {"prompt": "a red teapot on a windowsill, morning light"},
            idempotency_key=os.environ["COMFY_REQUEST_KEY"],
            timeout=660.0,
        )

    print("image:", result["result"]["sample"])
    ```

    ```typescript TypeScript
    // Node.js 22+
    // Install: npm install @comfyorg/sdk@^0.1.9 --save-dev tsx
    // Save as quickstart.mts, then run: npx tsx quickstart.mts

    import { comfy } from "@comfyorg/sdk";

    // Comfy reads COMFY_API_KEY from the environment.
    type FluxResult = { result: { sample: string } };
    const idempotencyKey = process.env.COMFY_REQUEST_KEY;
    if (!idempotencyKey) throw new Error("Set COMFY_REQUEST_KEY first.");

    const { data } = await comfy.models.run<FluxResult>(
      "bfl/flux-2-pro",
      { prompt: "a red teapot on a windowsill, morning light" },
      { idempotencyKey, timeoutMs: 660_000 },
    );

    console.log("image:", data.result.sample);
    ```

    </CodeGroup>

    どちらの SDK も環境から `COMFY_API_KEY` を読み取ります。
  </Step>

  <Step title="結果を読み取って保存する">
    このモデルでは、画像URL はレスポンスボディの `result.sample` にあります。省略したレスポンスは次のようになります。以下の URL は例示用です：

    ```json
    {
      "status": "Ready",
      "result": { "sample": "https://example.com/generated-image.jpeg" }
    }
    ```

    返された URL を開くか、ダウンロードします：

    ```bash
    curl --fail --location "PASTE_IMAGE_URL_HERE" --output teapot.jpg
    ```

    速やかにダウンロードしてください。Router は BFL のアセットを Comfy のストレージに再ホストできますが、URL は期限切れになり、リプレイしても更新されません。再ホストが失敗すると、より短命なプロバイダー URL が残ることがあります。詳しくは[結果アセット](/ja/development/comfy-router/reference#結果アセット)を参照してください。
  </Step>
</Steps>
