<div className="router-quickstart-marker" />

Comfy Router を使うと、1つの Comfy APIキーで `https://api.comfy.org` を通じてパートナーモデルを呼び出せます。モデルの入力を `POST /v2/models/{provider}/{model}` に送信し、完了した結果を待ちます。この例では、ビデオモデルの `byteplus/dreamina-seedance-2-5-260628` を実行します。

これらの例では Comfy をデフォルトのプロバイダーとして使用します。別のプロバイダーを使用するには、SDK 呼び出しに `model_provider` を追加するか、URL に `?model_provider=<provider>` を追加します。[プロバイダー対応マトリクス](/ja/development/comfy-router/providers)に、利用可能なモデルとプロバイダーの組み合わせが一覧表示されています。

まずは以下の `byteplus/dreamina-seedance-2-5-260628` から始めるか、先に[別のモデルを選択](/ja/development/comfy-router/models)してください。

<Steps>
  <Step title="APIキーを作成する">
    [あなたの Comfy ワークスペース](https://platform.comfy.org/profile/api-keys?onboarding=router)でキーを作成します。Bash 互換のターミナルで、次を設定します：

    ```bash
    export COMFY_API_KEY="comfyui-..."
    ```

    APIキーはサーバー上またはローカル環境に保管してください。これらの例はターミナルまたはサーバー向けであり、ブラウザの JavaScript 向けではありません。

    Router はリクエストごとにクレジットを消費します。ワークスペースにクレジット残高がない場合、最初の実呼び出しは `error_type: insufficient_credits` とともに `402` を返します。このチェックはボディの検証が行われる前に実行されるため、クレジットのないワークスペースでは、不正なリクエストであっても `402` が返ることがあります。リクエストボディをデバッグする前に、[ワークスペースの請求](https://platform.comfy.org)でクレジットを追加してください。
  </Step>

  <Step title="このリクエスト用のキーを保存する">
    このリクエストのために、この値を一度だけ生成します。同じリクエストを再試行する場合は、それを再利用してください。

    ```bash
    export COMFY_REQUEST_KEY="$(uuidgen)"
    ```

    `uuidgen` が利用できない場合は、別の UUID ジェネレーターを使用してください。新しい生成を開始するときは、新しいキーを使用します。
  </Step>

  <Step title="モデルを実行する">
    言語を選択して例を実行します。生成には数分かかることがあります。

    <CodeGroup>

    ```bash cURL
    curl --max-time 660 \
      https://api.comfy.org/v2/models/byteplus/dreamina-seedance-2-5-260628 \
      -H "X-API-Key: $COMFY_API_KEY" \
      -H "Idempotency-Key: $COMFY_REQUEST_KEY" \
      -H "Content-Type: application/json" \
      -d '{"content": [{"text": "A red fox trotting through a snowy pine forest", "type": "text"}], "duration": 5, "ratio": "16:9", "resolution": "720p"}'
    ```

    ```python Python
    # Python 3.10+
    # インストール: python -m pip install "comfy-sdk>=0.3.0"
    # quickstart.py として保存し、次を実行: python quickstart.py

    import os

    from comfy_sdk import Comfy

    # Comfy は環境から COMFY_API_KEY を読み取ります。
    with Comfy() as client:
        result = client.models.run(
            "byteplus/dreamina-seedance-2-5-260628",
            {
                "content": [
                    {
                        "text": "A red fox trotting through a snowy pine forest",
                        "type": "text",
                    },
                ],
                "duration": 5,
                "ratio": "16:9",
                "resolution": "720p",
            },
            idempotency_key=os.environ["COMFY_REQUEST_KEY"],
            timeout=660.0,
        )

    print("result:", result)
    ```

    ```typescript TypeScript
    // Node.js 22+
    // インストール: npm install "@comfyorg/sdk@>=0.4.0" --save-dev tsx
    // quickstart.mts として保存し、次を実行: npx tsx quickstart.mts

    import { comfy } from "@comfyorg/sdk";

    // Comfy は環境から COMFY_API_KEY を読み取ります。
    const idempotencyKey = process.env.COMFY_REQUEST_KEY;
    if (!idempotencyKey) throw new Error("Set COMFY_REQUEST_KEY first.");

    const result = await comfy.models.run(
      "byteplus/dreamina-seedance-2-5-260628",
      {
        content: [
          {
            text: "A red fox trotting through a snowy pine forest",
            type: "text",
          },
        ],
        duration: 5,
        ratio: "16:9",
        resolution: "720p",
      },
      { idempotencyKey, timeoutMs: 660_000 },
    );

    console.log("result:", result.data);
    ```

    ```swift Swift
    // Swift 5.9+（macOS 14+、iOS 17+）。このスニペットはコマンドラインプログラムです。
    // iOS アプリ内にキーを同梱しないでください。バイナリから抽出可能です。
    // アプリでは、独自のバックエンドを呼び出し、キーはそこに保管してください。
    // インストール: .package(url: "https://github.com/Comfy-Org/comfy-swift-sdk.git", from: "0.5.0") を追加
    // ターゲットに ComfySwiftSDK を追加し、これを Sources/.../main.swift に置いて、次を実行: swift run

    import ComfySwiftSDK
    import Foundation

    let env = ProcessInfo.processInfo.environment

    guard let apiKey = env["COMFY_API_KEY"], !apiKey.isEmpty else {
        fatalError("Set COMFY_API_KEY first.")
    }
    guard let requestKey = env["COMFY_REQUEST_KEY"], !requestKey.isEmpty else {
        fatalError("Set COMFY_REQUEST_KEY first.")
    }

    let client = ComfyCloudClient(apiKey: apiKey)

    let result = try await client.models.run(
        "byteplus/dreamina-seedance-2-5-260628",
        input: [
            "content": [
                [
                    "text": "A red fox trotting through a snowy pine forest",
                    "type": "text",
                ],
            ],
            "duration": 5,
            "ratio": "16:9",
            "resolution": "720p",
        ],
        idempotencyKey: requestKey,
        timeout: 660  // 秒
    )

    print(result.output)
    ```

    </CodeGroup>

    4つの例はすべて `COMFY_API_KEY` からキーを取得します。Python と TypeScript の
    クライアントは環境から自動的に読み取り、Swift の例は読み取って
    `ComfyCloudClient(apiKey:)` に渡します。
  </Step>

  <Step title="結果を読み取る">
    Router はモデル固有のネイティブな結果を返します。レスポンスボディを確認し、アプリケーションに必要なフィールドを読み取ってください。
  </Step>
</Steps>

## 待機の代わりにキューを使用する

`run` は画像の準備ができるまで接続を保持します。`request_id` をすぐに受け取り、このプロセスまたは別のプロセスから後で結果を収集するには、代わりに `submit` を呼び出してください（ステップ 3 でインストールする SDK のバージョンには含まれています）。または、同じボディを HTTP で `POST /v2/models/{provider}/{model}/requests` に送信します。ステップ 2 と同様に `Idempotency-Key` を一緒に送信してください。接続が切断された後に再試行された送信は、再びキューに入れて二重に課金される代わりに、元のリクエストを返します。SDK は `submit` 呼び出しごとに1つを生成します。すべてのモデルページには、同期スニペットの横に **Queue and collect later** タブがあり、[キュー配信](/ja/development/comfy-router/queue)でステータス、キャンセル、収集について説明しています。

キュー配信は、キーの背後にあるワークスペースにスコープされます。これは [あなたの Comfy ワークスペース](https://platform.comfy.org/profile/api-keys?onboarding=router)で作成されたキーが持つスコープです。
