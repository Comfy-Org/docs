モデルを選択し、そのスキーマを確認して、`POST /v2/models/{provider}/{model}` を呼び出します。ルートと認証はモデル間で変わりません。各モデルは独自のネイティブなリクエストボディを受け取り、独自のネイティブな結果を返します。
