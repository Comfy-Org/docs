## リクエストのセットアップ

**モデル ID:** `wavespeed/wavespeed-nano-banana-pro`

**エンドポイント:** `POST https://api.comfy.org/v2/models/wavespeed/wavespeed-nano-banana-pro`

<Note>
Router はこのモデルについて作成済みの入力スキーマを公開していないため、スニペットの生成元となるリクエスト例がありません。Router はリクエストボディをそのまま WaveSpeed に転送します。WaveSpeed 自身の API ドキュメントを参照してボディを構築し、[Router クイックスタート](/ja/development/comfy-router/quickstart)を使って送信してください。
</Note>
