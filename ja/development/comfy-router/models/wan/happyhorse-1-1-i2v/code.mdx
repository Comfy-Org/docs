HappyHorse 1.1 I2V の API リファレンスです。HappyHorse 1.1 の画像から動画への変換は、静止した最初のフレームをアニメーション化し、同期したセリフ、エフェクト、音楽を同じパスでレンダリングします。

## クイックスタート

[Comfy ワークスペース](https://platform.comfy.org/profile/api-keys)でキーを作成し、`COMFY_API_KEY` としてエクスポートします。Python と TypeScript のスニペットは Comfy SDK（`pip install comfy-sdk`、`npm install @comfyorg/sdk`）を使用します。cURL のスニペットは、生の HTTP で同じ呼び出しを行います。

**モデル ID:** `wan/happyhorse-1.1-i2v`

**エンドポイント:** `POST https://api.comfy.org/v2/models/wan/happyhorse-1.1-i2v`

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment.
# The SDK automatically creates an idempotency key and reuses it for automatic retries.
with Comfy() as client:
    result = client.models.run(
        "wan/happyhorse-1.1-i2v",
        {
            "input": {

            },

print("video:", result["output"]["video_url"])
```
