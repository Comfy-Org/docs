<ParamField body="input.img_url" type="string">
  先頭フレーム画像のURL、またはBase64エンコードされたデータ。wan2.5-i2v-preview および

<ParamField body="input.media" type="object[]">
  メディアアセットのリスト。ビデオ生成用の参照素材（画像、オーディオ、ビデオ）を
指定します。各要素には type フィールドと url フィールドが含まれます。このフィールドは、この
コンポーネントから提供されるすべてのモデルで共有されますが、あるモデルが受け付ける
type 値、およびそのモデルが画像やビデオの入力を img_url や
reference_video_urls ではなくここで受け取るかどうかは、モデルによって異なります。モデルごとの
サポートされる type 値:
- wan2.7-i2v: first_frame、last_frame、driving_audio、first_clip。first_frame および
  last_frame: JPEG/JPG/PNG/BMP/WEBP、各辺 240-8000 ピクセル、アスペクト比 1:8
  から 8:1、最大 20MB、パブリック URL または data:\{MIME_type};base64,... URL。
  driving_audio（WAV/MP3、2-30 秒、最大 15MB）および first_clip（MP4/MOV、2-10
  秒、各辺 240-4096 ピクセル、最大 100MB）: パブリック HTTP/HTTPS URL; インラインの
  data: URL は受け付けられません。
- wan2.7-r2v: first_frame（オプション、最大 1）、reference_image、reference_video。少なくとも
  reference_image または reference_video を 1 つ指定する必要があり、reference_image と
  reference_video の合計は最大 5 です。first_frame および reference_image: JPEG/JPG/PNG/BMP/WEBP
  （アルファチャンネルなし）、各辺 240-8000 ピクセル、アスペクト比 1:8 から 8:1、最大
  20MB、パブリック URL または data:\{MIME_type};base64,... URL。reference_video: パブリック
  HTTP/HTTPS URL; インラインの data: URL は受け付けられません。
- wan2.7-videoedit: video（正確に 1 つ、編集対象のクリップ: MP4/MOV、2-10 秒、
  各辺 240-4096 ピクセル、最大 100MB、パブリック HTTP/HTTPS URL; インラインの data: URL
  は受け付けられません）に加えて、オプションで 0 から 4 の reference_image（JPEG/JPG/PNG/BMP/WEBP、
  各辺 240-8000 ピクセル、アスペクト比 1:8 から 8:1、最大 20MB、パブリック URL
  または data:\{MIME_type};base64,... URL）。
- wan3.0-video、wan3.0-video-prime: first_frame（最大 1）、last_frame（最大 1）、
  reference_image（最大 10）、reference_video（最大 5 クリップ、合計再生時間 \<= 15 秒）、
  reference_audio（最大 5 クリップ、合計再生時間 \<= 15 秒）、file（最大 1、link とは
  併用不可）、link（最大 1、file とは併用不可）。reference_*/file/link タイプ
  と first_frame/last_frame タイプは、同じリクエスト内では同時に使用できません。
  配列の順序が、プロンプト内のアセットの参照順序を定義します（Image 1、Video 1、
  Audio 1、...）。first_frame、last_frame および reference_image: JPEG/JPG/PNG/BMP/WEBP、
  各辺 240-8000 ピクセル、アスペクト比最大 8:1、最大 20MB、パブリック URL または
  data:\{MIME_type};base64,... URL。reference_video、reference_audio、file および link: パブリック
  HTTP/HTTPS URL; インラインの data: URL は受け付けられません。
- happyhorse-1.0-i2v、happyhorse-1.1-i2v: first_frame のみ、正確に 1 つ。これらの表記は
  先頭フレームをここで受け取り、img_url では受け取りません。少なくとも 300x300 ピクセル、アスペクト比
  1:2.5 から 2.5:1、JPEG/JPG/PNG/WEBP、最大 20MB、パブリック URL または
  data:\{MIME_type};base64,... URL。
- happyhorse-1.0-r2v、happyhorse-1.1-r2v: reference_image のみ、1 から 9 つ。これは
  モデル唯一の参照入力です。最短辺が少なくとも 400 ピクセル、JPEG/JPG/PNG/WEBP、
  最大 20MB、パブリック URL または data:\{MIME_type};base64,... URL。reference_video は
  この操作の入力タイプではありません。
- happyhorse-1.0-video-edit: video（正確に 1 つ、編集対象のクリップ: MP4/MOV、3-60
  秒、長辺が最大 4096 ピクセル、短辺が少なくとも 360 ピクセル、アスペクト
  比 1:2.5 から 2.5:1、最大 100MB、パブリック HTTP/HTTPS URL; インラインの data:
  URL は受け付けられません）に加えて、オプションで 0 から 5 の reference_image（JPEG/JPG/PNG/BMP/WEBP、
  少なくとも 300x300 ピクセル、アスペクト比 1:2.5 から 2.5:1、最大 20MB、パブリック URL
  または data:\{MIME_type};base64,... URL）。
- happyhorse-1.0-t2v、happyhorse-1.1-t2v、wan2.7-t2v、wan2.6-t2v、wan2.5-t2v-preview:
  テキストから動画への操作。これらのパートナーリファレンスにはメディア入力の記載がないため、
  このフィールドは未設定のままにしてください。
- wan2.5-i2v-preview、wan2.6-i2v、wan2.6-r2v: このコンポーネントはこれらの表記に対して
  メディアの語彙を列挙していません。wan2.5-i2v-preview および wan2.6-i2v は先頭
  フレームを img_url で受け取り、wan2.6-r2v は参照クリップを reference_video_urls で受け取ります。
上記のモデルごとの数はパートナーの制約であり、このスキーマの制約ではありません。media には
minItems/maxItems が宣言されていません。これは、許容されるタイプとその上限がモデルごとに
異なるためです。スキーマ上の受け入れは、プロバイダーによる受け入れを意味しません。また、
その逆に、上記のアセットごとの「最大 20MB」という数値（画像入力の上限であり、インラインで
送信できる唯一の入力）は、パートナーが最終的に受け取るアセットに対する上限であり、アセットが
パブリック URL の場合は記載どおりに適用されます。そのバイト列は Comfy を経由しないためです。
インラインの data:\{MIME_type};base64,... URL は Comfy を経由し、転送上限にも直面します。
Comfy Router の POST ボディは合計 100 MiB に制限され、それを超えると 413 が返され、
base64 はペイロードを約 4/3 に膨らませます。したがって、およそ 75 MB を超える単一のインライン
アセットは、ここに示すパートナーのルールに到達する前に拒否されます。そのサイズでは、パートナー自身の20MB の上限であればインラインで問題なく収まるため、アセット 1 つ分についてはパートナーのルールが制約となります。複数のアセットにまたがる場合はトランスポートの上限が制約となります。100 MiB という Router の上限は、各要素ではなくリクエスト全体を制限するためです。これらの上限に近いものは、パブリック URL として送信してください。

wan2.7 モデルでは、指定しない場合、解像度ティアに基づいてデフォルトが決まります。
wan3.0-video では、adaptive（デフォルト）が入力メディアの比率と意図に基づいて適切な
アスペクト比を自動的に推奨します。

  指定可能な値: `adaptive`, `16:9`, `9:16`, `1:1`, `4:3`, `3:4`
</ParamField>

<ParamField body="parameters.resolution" type="string">
  解像度レベル。サポートされる値はモデルによって異なります:
- wan2.5-i2v-preview: 480P、720P、1080P
- wan2.6 モデル（t2v、i2v、r2v）: 720P、1080P のみ（480P は非サポート）
- wan2.7 モデル（i2v、t2v、r2v、videoedit）: 720P、1080P（デフォルト 1080P）
- wan3.0-video, wan3.0-video-prime: 480P, 720P, 1080P（上流のデフォルトは 1080P）
- happyhorse-1.0-* (t2v, i2v, r2v, video-edit): 720P, 1080P
- happyhorse-1.1-* (t2v, i2v, r2v): 480P, 720P, 1080P
このプロキシは、resolution も size も指定していないビデオ生成リクエストを拒否します。
これは、解像度ティアが課金レートを選択するためです。チェックの前に resolution を大文字に変換し、
大文字に変換した値を転送します。この enum に含まれない値には 400 を返し、
480P については（resolution として送信された場合も、480P の size として送信された場合も）
上記で 480P がないと記載されている wan2.6、wan2.7、happyhorse-1.0 モデルに対して 400 を返します。

  Possible values: `480P`, `720P`, `1080P`
</ParamField>

<ParamField body="parameters.seed" type="integer">
  乱数シード。モデルが生成するコンテンツのランダム性を制御するために使用します。

  Range: `0` から `2147483647`
</ParamField>

<ParamField body="parameters.shot_type" type="string" default="&quot;single&quot;">
  インテリジェントなマルチレンズ制御。prompt_extend が有効な場合にのみ機能します。
wan2.6 および wan2.7-r2v モデル用です。
- single: シングルショットビデオ（デフォルト）
- multi: マルチショットビデオ

  Possible values: `multi`, `single`
</ParamField>

<ParamField body="parameters.size" type="string">
  幅*高さ 形式のビデオ解像度。対応する解像度はモデルによって異なります。
wan2.5 T2V の場合: 480P（480*832、832*480、624*624）、720P、1080P の各サイズ
wan2.6 T2V/R2V の場合（480P なし）:
  720P: 1280*720、720*1280、960*960、1088*832、832*1088
  1080P: 1920*1080、1080*1920、1440*1440、1632*1248、1248*1632
size と resolution の両方を送信した場合、課金ティアを選択するのは size であり、
resolution は引き続き、そのモデルに対してこのプロキシが受け付ける値である必要があります。
480P の size は、resolution の説明で 480P がないと記載されているすべてのモデルで 400 を返します。
</ParamField>

<ParamField body="parameters.watermark" type="boolean" default="false">
  透かしロゴを追加するかどうか。透かしは右下隅に配置されます。
</ParamField>
