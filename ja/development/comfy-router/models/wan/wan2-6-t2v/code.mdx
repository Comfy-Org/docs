Wan 2.6 T2V の API リファレンス。Wan 2.6 のテキストから動画への変換は、プロンプトのみから短いビデオを生成します。解像度は 720P または 1080P、長さは最大 15 秒です。

**入力：** オーディオ, テキスト · **出力：** ビデオ + オーディオ

**モデル ID:** `wan/wan2.6-t2v`

**エンドポイント:** `POST https://api.comfy.org/v2/models/wan/wan2.6-t2v`

async def main():

                },

                    "resolution": "720P",
                    "duration": 5,
                },
            },
        )

        # リクエストが完了するまでポーリングし、サーバーが指定する Retry-After の秒数だけ待機します。

        # プロバイダー自身のペイロード。models.run() が返すのと同じ値です。
        # 失敗またはキャンセルされたリクエストは、ここで型付きの Router エラーを発生させます。

<ParamField body="input.audio_url" type="string">
  オーディオファイルのダウンロードURL。対応フォーマット: mp3 と wav。reference_video_urls とは併用できません。
</ParamField>

<ParamField body="input.img_url" type="string">
  最初のフレームの画像URL、または Base64 エンコードされたデータ。wan2.5-i2v-preview と
wan2.6-i2v モデルでは必須です。happyhorse-1.x の i2v 表記は最初のフレームをここでは
受け取りません。type が first_frame のメディア要素として受け取ります（下記の media を
参照してください）。また、wan2.6-i2v で成功する img_url ボディは、
happyhorse-1.0-i2v と happyhorse-1.1-i2v ではプロバイダーに拒否されます。
wan2.7/wan3.0 の表記も同様に参照アセットを media で受け取ります。
画像フォーマット: JPEG、JPG、PNG、BMP、WEBP。
解像度: 360～2000ピクセル。ファイルサイズ: 最大10MB。
</ParamField>

<ParamField body="input.media" type="object[]">
  メディアアセットのリスト。動画生成の参照素材（画像、オーディオ、ビデオ）を指定します。
各要素は type フィールドと url フィールドを持ちます。このフィールドはこのコンポーネントから
提供されるすべてのモデルで共有されており、どのモデルがどの type 値を受け入れるか、
また画像やビデオの入力を img_url や reference_video_urls ではなくここで受け取るかどうかは、
モデルごとに異なります。モデルごとの対応 type 値:
- wan2.7-i2v: first_frame、last_frame、driving_audio、first_clip。first_frame と
  last_frame: JPEG/JPG/PNG/BMP/WEBP、1辺 240～8000ピクセル、アスペクト比 1:8
  ～8:1、最大 20MB、公開 URL または data:\{MIME_type};base64,... URL。
  driving_audio（WAV/MP3、2～30秒、最大 15MB）と first_clip（MP4/MOV、2～10
  秒、1辺 240～4096ピクセル、最大 100MB）: 公開 HTTP/HTTPS URL。インラインの
  data: URL は受け付けられません。
- wan2.7-r2v: first_frame（任意、最大1）、reference_image、reference_video。少なくとも
  1つの reference_image または reference_video が必要で、reference_image と
  reference_video を合計して最大5つです。first_frame と reference_image: JPEG/JPG/PNG/BMP/WEBP
  （アルファチャンネルなし）、1辺 240～8000ピクセル、アスペクト比 1:8～8:1、最大
  20MB、公開 URL または data:\{MIME_type};base64,... URL。reference_video: 公開
  HTTP/HTTPS URL。インラインの data: URL は受け付けられません。
- wan2.7-videoedit: video（ちょうど1つ、編集対象のクリップ: MP4/MOV、2～10秒、
  1辺 240～4096ピクセル、最大 100MB、公開 HTTP/HTTPS URL。インラインの data: URL
  は受け付けられません）と、任意で0～4つの reference_image（JPEG/JPG/PNG/BMP/WEBP、
  1辺 240～8000ピクセル、アスペクト比 1:8～8:1、最大 20MB、公開 URL
  または data:\{MIME_type};base64,... URL）。
- wan3.0-video、wan3.0-video-prime: first_frame（最大1）、last_frame（最大1）、
  reference_image（最大10）、reference_video（最大5クリップ、合計再生時間 \<= 15秒）、
  reference_audio（最大5クリップ、合計再生時間 \<= 15秒）、file（最大1、link
  と併用不可）、link（最大1、file と併用不可）。reference_*/file/link タイプ
  と first_frame/last_frame タイプは、同じリクエスト内で同時に使用できません。
  配列の順序が、プロンプト内のアセットの参照順序（Image 1、Video 1、
  Audio 1、...）を定義します。first_frame、last_frame、reference_image: JPEG/JPG/PNG/BMP/WEBP、
  1辺 240～8000ピクセル、アスペクト比 最大 8:1、最大 20MB、公開 URL または
  data:\{MIME_type};base64,... URL。reference_video、reference_audio、file、link:
  公開 HTTP/HTTPS URL。インラインの data: URL は受け付けられません。
- happyhorse-1.0-i2v、happyhorse-1.1-i2v: first_frame のみ、ちょうど1つ。これらの表記
  は最初のフレームを img_url ではなくここで受け取ります。少なくとも 300x300 ピクセル、
  アスペクト比 1:2.5～2.5:1、JPEG/JPG/PNG/WEBP、最大 20MB、公開 URL または
  data:\{MIME_type};base64,... URL。
- happyhorse-1.0-r2v、happyhorse-1.1-r2v: reference_image のみ、1～9つ。これが
  このモデル唯一の参照入力です。最短辺が少なくとも 400 ピクセル、JPEG/JPG/PNG/WEBP、
  最大 20MB、公開 URL または data:\{MIME_type};base64,... URL。reference_video は
  この操作の入力タイプではありません。
- happyhorse-1.0-video-edit: video（ちょうど1つ、編集対象のクリップ: MP4/MOV、3～60
  秒、長辺が最大 4096 ピクセル、短辺が少なくとも 360 ピクセル、アスペクト
  比 1:2.5～2.5:1、最大 100MB、公開 HTTP/HTTPS URL。インラインの data:
  URL は受け付けられません）と、任意で0～5つの reference_image（JPEG/JPG/PNG/WEBP、
  少なくとも 300x300 ピクセル、アスペクト比 1:2.5～2.5:1、最大 20MB、公開 URL
  または data:\{MIME_type};base64,... URL）。
- happyhorse-1.0-t2v、happyhorse-1.1-t2v、wan2.7-t2v、wan2.6-t2v、wan2.5-t2v-preview:
  テキストから動画への操作。これらのパートナー向けリファレンスにはメディア入力の記載がないため、
  このフィールドは未設定のままにしてください。
- wan2.5-i2v-preview、wan2.6-i2v、wan2.6-r2v: このコンポーネントはこれらの表記向けの
  メディア語彙を列挙していません。wan2.5-i2v-preview と wan2.6-i2v は最初の
  フレームを img_url で受け取り、wan2.6-r2v は参照クリップを reference_video_urls で受け取ります。
上記のモデルごとの個数はパートナーの制約であり、このスキーマの制約ではありません。media には
minItems/maxItems が宣言されていません。許容される type とその上限はモデルごとに
異なるためです。スキーマが受け入れることは、プロバイダーが受け入れることを意味しません。
逆に、上記のアセットごとの「最大 20MB」という数値（画像入力の上限であり、インラインで
送信できる唯一の入力です）は、パートナーが最終的に受け取るアセットに対する上限であり、
アセットが公開 URL の場合はそのまま適用されます。そのバイト列は Comfy を
経由しないためです。インラインの data:\{MIME_type};base64,...
URL は Comfy を経由するため、転送時の上限にも直面します。Comfy Router の
POST ボディは合計 100 MiB に制限され、それを超えると 413 が返されます。また base64 は
ペイロードを約 4/3 に膨らませるため、約 75 MB を超える単一のインラインアセットは、
ここに示したパートナーのルールに到達する前に拒否されます。そのサイズでは、単一のアセットがパートナー自身の
20MB の上限にはインラインで余裕をもって収まるため、1 つのアセットではパートナーのルールが制約となります。トランスポートの上限は複数のアセットにまたがる場合に制約となります。100 MiB の Router 上限は各要素ではなくリクエスト全体を制限するためです。これらの上限に近いものはパブリック URL として送信してください。

<ParamField body="input.media[].url" type="string" required>
  メディアファイルの URL: パブリックな HTTP/HTTPS URL、または、上記の `media` の説明で各モデルごとに列挙されているまさに IMAGE 入力（wan2.7-i2v の first_frame と last_frame、wan2.7-r2v の first_frame と reference_image、wan2.7-videoedit の reference_image、wan3.0-video と wan3.0-video-prime の first_frame、last_frame、reference_image、happyhorse-1.0-i2v と happyhorse-1.1-i2v の first_frame、happyhorse-1.0-r2v と happyhorse-1.1-r2v の reference_image、happyhorse-1.0-video-edit の reference_image）に限り、インラインの `data:{MIME_type};base64,...` URL を指定できます。これらのモデルのビデオ、オーディオ、ファイル、リンク入力はいずれもインラインの data: URL を受け付けません。パートナー自身のアップロードサービスによる oss://dashscope-instant の一時 URL、または (wan2.7-videoedit では) Asset Center の asset_id は、それをアップロードした Alibaba Cloud アカウントに対してのみ解決されます。Comfy は自身のキーでモデル呼び出しを行い、アップロード経路を公開していないため、呼び出し元自身の oss:// URL や asset_id はサポートされない入力です。このフィールドは URL スキームを検証しないため、そのような値はここで拒否されることなくパートナーへそのまま転送されます。モデルごとのサイズとピクセルの制限、およびインラインペイロード全体を制限する 100 MiB の Router リクエストボディ上限については、`media` の説明を参照してください。

<ParamField body="input.prompt" type="string">
  テキストプロンプト。中国語と英語をサポートし、長さは 800 文字を超えません

複数の参照ビデオを使う wan2.6-r2v では、'character1'、'character2' などを使用して、
参照ビデオの順序に従って被写体を参照します。例: "Character1 sings on the roadside, Character2 dances beside it"
wan3.0-video の参照モードでは、'Image 1'、'Video 1'、'Audio 1' などを使用して、
media 配列内の対応する順序でメディアアセットを参照します。
</ParamField>

<ParamField body="input.reference_video_urls" type="string[]">
  wan2.6-r2v モデル専用の参照ビデオ URL。1 ～ 3 本のビデオ URL の配列です。
入力の制限:
- フォーマット: mp4、mov
- 本数: 1 ～ 3 本のビデオ
- 1 本のビデオの長さ: 2 ～ 30 秒
- 1 ファイルのサイズ: 最大 30MB

参照の再生時間: ビデオ 1 本の場合は最大 5 秒、2 本の場合はそれぞれ最大 2.5 秒、3 本の場合はそれに比例して短くなります。

  生成されるビデオの再生時間（秒）:
- wan2.5 モデル: 5 秒または 10 秒
- wan2.6-t2v、wan2.6-i2v: 5、10、または 15 秒
- wan2.6-r2v: 5 秒または 10 秒のみ（15 秒は非サポート）
- wan2.7-i2v、wan2.7-t2v: [2, 15] の範囲の整数
- wan2.7-r2v、wan2.7-videoedit: [2, 10] の範囲の整数

  モデルが適切な再生時間を選ぶスマート再生時間モードを有効にします
このプロキシは [-1, 30] の範囲外の再生時間に対して 400 を返します。

  範囲: `-1` から `30`

<ParamField body="parameters.ratio" type="string">
  生成されるビデオのアスペクト比。wan2.7 および wan3.0 モデル専用です。
wan2.7 モデルでは、指定しない場合は解像度ティアに基づいてデフォルトが決まります。
wan3.0-video では、adaptive（デフォルト）が入力メディアの比率と意図に基づいて
適切なアスペクト比を自動的に推奨します。

  指定可能な値: `adaptive`, `16:9`, `9:16`, `1:1`, `4:3`, `3:4`
</ParamField>

<ParamField body="parameters.resolution" type="string">
  解像度レベル。サポートされる値はモデルによって異なります:
- wan2.5-i2v-preview: 480P、720P、1080P
- wan2.6 モデル（t2v、i2v、r2v）: 720P、1080P のみ（480P は非サポート）
- wan2.7 モデル（i2v、t2v、r2v、videoedit）: 720P、1080P（デフォルト 1080P）- wan3.0-video、wan3.0-video-prime: 480P、720P、1080P（アップストリームのデフォルトは 1080P）
- happyhorse-1.0-*（t2v、i2v、r2v、video-edit）: 720P、1080P
- happyhorse-1.1-*（t2v、i2v、r2v）: 480P、720P、1080P
このプロキシは、解像度もサイズも指定していないビデオ生成リクエストを拒否します。解像度のティアが課金レートを決定するためです。チェックの前に解像度を大文字に変換し、その大文字化した値を転送します。この enum に含まれない値には 400 を返し、上記で 480P を持たないと記載されている wan2.6、wan2.7、および happyhorse-1.0 モデルでは、480P（解像度として送信された場合も、480P のサイズとして送信された場合も）に対して 400 を返します。

  指定可能な値: `480P`, `720P`, `1080P`
</ParamField>

<ParamField body="parameters.seed" type="integer">
  乱数シード。モデルが生成するコンテンツのランダム性を制御するために使用します

  範囲: `0` から `2147483647`
</ParamField>

<ParamField body="parameters.shot_type" type="string" default="&quot;single&quot;">
  インテリジェントなマルチレンズ制御。prompt_extend が有効な場合にのみ動作します。
wan2.6 および wan2.7-r2v モデル向け。
- single: シングルショットビデオ（デフォルト）
- multi: マルチショットビデオ

  指定可能な値: `multi`, `single`
</ParamField>

<ParamField body="parameters.size" type="string">
  width*height 形式のビデオ解像度。サポートされる解像度はモデルによって異なります:
wan2.5 T2V の場合: 480P（480*832、832*480、624*624）、720P、1080P のサイズ
wan2.6 T2V/R2V の場合（480P なし）:
  720P: 1280*720, 720*1280, 960*960, 1088*832, 832*1088
  1080P: 1920*1080, 1080*1920, 1440*1440, 1632*1248, 1248*1632
サイズと解像度の両方を送信した場合、課金ティアを選択するのはサイズであり、
解像度はそのモデルに対してこのプロキシが受け付ける値である必要があります。480P のサイズは、
解像度の説明で 480P を持たないと記載されているすべてのモデルで 400 を返します。
</ParamField>

<ParamField body="parameters.watermark" type="boolean" default="false">
  ウォーターマークロゴを追加するかどうか。ウォーターマークは右下隅に配置されます
</ParamField>
