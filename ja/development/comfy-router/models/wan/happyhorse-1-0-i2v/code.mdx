# 環境変数から COMFY_API_KEY を読み取ります。
# 各 submit() 呼び出しは独自の Idempotency-Key を発行し、自動リトライで再利用します。
async def main():

        handle = await client.models.submit(

                        },

                    "resolution": "720P",
                    "duration": 5,
                },
            },
        )

        # リクエストが完了するまでポーリングし、サーバーが指定する Retry-After だけ待機します。
        async for update in handle.iter_events():

        # プロバイダー自身のペイロードで、models.run() が返す値と同じです。

<ParamField body="input.audio_url" type="string">

</ParamField>

<ParamField body="input.img_url" type="string">
  先頭フレーム画像のURLまたはBase64エンコードされたデータ。wan2.5-i2v-preview および wan2.6-i2v モデルでは必須です。happyhorse-1.x の i2v 表記は、先頭フレームをここでは受け取りません。first_frame タイプの media 要素として受け取ります（後述の media を参照）。また、wan2.6-i2v では成功する img_url ボディも、happyhorse-1.0-i2v および happyhorse-1.1-i2v ではプロバイダーに拒否されます。さらに wan2.7/wan3.0 の表記も、参照アセットを media で受け取ります。画像フォーマット: JPEG、JPG、PNG、BMP、WEBP。解像度: 360-2000 ピクセル。ファイルサイズ: 最大 10MB。
</ParamField>

<ParamField body="input.media" type="object[]">
  メディアアセットのリスト。ビデオ生成のための参照素材（画像、オーディオ、ビデオ）を指定します。各要素には type と url フィールドが含まれます。このフィールドはこのコンポーネントから提供されるすべてのモデルで共有されており、どのモデルがどの type 値を受け入れるか（また、画像やビデオの入力を img_url や reference_video_urls ではなくここで受け取るかどうか）はモデルごとに異なります。モデルごとの対応する type 値:
- wan2.7-i2v: first_frame、last_frame、driving_audio、first_clip。first_frame と
  last_frame: JPEG/JPG/PNG/BMP/WEBP、1辺あたり 240-8000 ピクセル、アスペクト比 1:8
  から 8:1 の間、最大 20MB、公開URLまたは data:\{MIME_type};base64,... URL。
  driving_audio（WAV/MP3、2-30 秒、最大 15MB）および first_clip（MP4/MOV、2-10
  秒、1辺あたり 240-4096 ピクセル、最大 100MB）: 公開 HTTP/HTTPS URL。インラインの
  data: URL は受け付けられません。
- wan2.7-r2v: first_frame（任意、最大 1）、reference_image、reference_video。
  reference_image または reference_video のうち少なくとも 1 つが必要で、
  reference_image と reference_video の合計は最大 5 です。first_frame と
  reference_image: JPEG/JPG/PNG/BMP/WEBP（アルファチャンネルなし）、1辺あたり
  240-8000 ピクセル、アスペクト比 1:8 から 8:1 の間、最大 20MB、公開URLまたは
  data:\{MIME_type};base64,... URL。reference_video: 公開 HTTP/HTTPS URL。インラインの
  data: URL は受け付けられません。
- wan2.7-videoedit: video（厳密に 1 つ。編集対象のクリップ: MP4/MOV、2-10 秒、
  1辺あたり 240-4096 ピクセル、最大 100MB、公開 HTTP/HTTPS URL。インラインの
  data: URL は受け付けられません）と、任意で 0 から 4 つの reference_image
  （JPEG/JPG/PNG/BMP/WEBP、1辺あたり 240-8000 ピクセル、アスペクト比 1:8 から 8:1
  の間、最大 20MB、公開URLまたは data:\{MIME_type};base64,... URL）。
- wan3.0-video、wan3.0-video-prime: first_frame（最大 1）、last_frame（最大 1）、
  reference_image（最大 10）、reference_video（最大 5 クリップ、合計再生時間 \<= 15s）、
  reference_audio（最大 5 クリップ、合計再生時間 \<= 15s）、file（最大 1、link とは
  併用不可）、link（最大 1、file とは併用不可）。reference_*/file/link タイプと
  first_frame/last_frame タイプは、同じリクエスト内では相互に排他的です。配列の順序が
  プロンプト内のアセットの参照順序を定義します（Image 1、Video 1、Audio 1、...）。
  first_frame、last_frame、reference_image: JPEG/JPG/PNG/BMP/WEBP、1辺あたり
  240-8000 ピクセル、アスペクト比最大 8:1、最大 20MB、公開URLまたは
  data:\{MIME_type};base64,... URL。reference_video、reference_audio、file、link:
  公開 HTTP/HTTPS URL。インラインの data: URL は受け付けられません。
- happyhorse-1.0-i2v、happyhorse-1.1-i2v: first_frame のみ、厳密に 1 つ。これらの
  表記は先頭フレームを img_url ではなくここで受け取ります。少なくとも 300x300
  ピクセル、アスペクト比 1:2.5 から 2.5:1 の間、JPEG/JPG/PNG/WEBP、最大 20MB、
  公開URLまたは data:\{MIME_type};base64,... URL。
- happyhorse-1.0-r2v、happyhorse-1.1-r2v: reference_image のみ、1 から 9 つ。これが
  このモデルの唯一の参照入力です。最短辺が少なくとも 400 ピクセル、
  JPEG/JPG/PNG/WEBP、最大 20MB、公開URLまたは data:\{MIME_type};base64,... URL。
  reference_video はこの操作の入力タイプではありません。
- happyhorse-1.0-video-edit: video（厳密に 1 つ。編集対象のクリップ: MP4/MOV、3-60
  秒、長辺が最大 4096 ピクセル、短辺が少なくとも 360 ピクセル、アスペクト比 1:2.5
  から 2.5:1 の間、最大 100MB、公開 HTTP/HTTPS URL。インラインの data: URL は
  受け付けられません）と、任意で 0 から 5 つの reference_image（JPEG/JPG/PNG/WEBP、
  少なくとも 300x300 ピクセル、アスペクト比 1:2.5 から 2.5:1 の間、最大 20MB、
  公開URLまたは data:\{MIME_type};base64,... URL）。
- happyhorse-1.0-t2v、happyhorse-1.1-t2v、wan2.7-t2v、wan2.6-t2v、wan2.5-t2v-preview:
  テキストから動画への操作。これらのパートナーのリファレンスには media 入力の記載が
  ないため、このフィールドは未設定のままにしてください。
- wan2.5-i2v-preview、wan2.6-i2v、wan2.6-r2v: このコンポーネントはこれらの表記に
  対して media の語彙を列挙していません。wan2.5-i2v-preview と wan2.6-i2v は先頭
  フレームを img_url で受け取り、wan2.6-r2v は参照クリップを reference_video_urls で
  受け取ります。
上記のモデルごとの数は、このスキーマの制約ではなくパートナーの制約です。media には minItems/maxItems が宣言されていません。これは、許容されるタイプとその上限がモデルごとに異なるためです。スキーマが受け入れることはプロバイダーが受け入れることを意味しません。逆に、上記のアセットごとの「最大 20MB」という数値（画像入力の上限であり、唯一インラインで送信できる入力です）は、最終的に受け取るアセットに対するパートナーの上限であり、アセットが公開URLの場合は記載どおりに適用されます。そのバイト列は Comfy を経由しないためです。インラインの data:\{MIME_type};base64,... URL は Comfy を経由するため、転送の上限にも直面します。Comfy Router の POST ボディは合計 100 MiB に制限され、それを超えると 413 が返されます。また base64 はペイロードを約 4/3 に膨らませるため、およそ 75 MB を超える単一のインラインアセットは、ここに記載されたパートナーのルールに到達する前に拒否されます。そのサイズでは、パートナー自身の20MB の上限ならインラインに余裕で収まります。そのため、単一アセットの場合に効いてくるのはパートナー側のルールです。複数のアセットにまたがる場合は転送上限のほうが効きます。100 MiB の Router 上限は各要素ではなくリクエスト全体を制限するためです。これらの上限に近づくものは、公開 URL として送信してください。

<ParamField body="input.prompt" type="string">
  テキストプロンプトの語句。中国語と英語に対応し、長さは 800 文字以内です

複数の参照ビデオを使う wan2.6-r2v では、参照ビデオの順序に合わせて被写体を 'character1'、'character2' などで参照します。

- wan2.7-r2v、wan2.7-videoedit: [2, 10] の整数
- wan3.0-video: ビデオ入力なしの場合は [2, 30] の整数。ビデオ入力ありの場合は、
  入力ビデオの再生時間 + 出力ビデオの再生時間の合計が 30 秒を超えてはなりません。-1 は
  スマート再生時間モードを有効にし、モデルが適切な再生時間を選択します

  範囲: `-1` から `30`
</ParamField>

<ParamField body="parameters.prompt_extend" type="boolean" default="true">
  プロンプトのインテリジェントな書き換えを有効にするかどうか。デフォルトは true です
</ParamField>

<ParamField body="parameters.ratio" type="string">
  生成されるビデオのアスペクト比。wan2.7 および wan3.0 モデル専用です。
wan2.7 モデルでは、指定しない場合、解像度のティアに基づいてデフォルトが決まります。
wan3.0-video では、adaptive（デフォルト）が入力メディアの比率と意図に基づいて適切な
アスペクト比を自動的に推奨します。

  指定可能な値: `adaptive`、`16:9`、`9:16`、`1:1`、`4:3`、`3:4`
</ParamField>

<ParamField body="parameters.resolution" type="string">
  解像度レベル。サポートされる値はモデルによって異なります:
- wan2.5-i2v-preview: 480P、720P、1080P
- wan2.6-i2v: 720P、1080P のみ（480P は非サポート）
- wan2.7 モデル（i2v、t2v、r2v、videoedit）: 720P、1080P（デフォルト 1080P）
- wan3.0-video、wan3.0-video-prime: 480P、720P、1080P（上流のデフォルト 1080P）このプロキシは、解像度もサイズも指定されていないビデオ生成リクエストを拒否します。解像度の階層によって課金レートが決まるためです。

  指定可能な値: `480P`, `720P`, `1080P`
</ParamField>

<ParamField body="parameters.seed" type="integer">
  乱数シード。モデルが生成するコンテンツのランダム性を制御するために使用します

  範囲: `0` から `2147483647`
</ParamField>

<ParamField body="parameters.shot_type" type="string" default="&quot;single&quot;">
  インテリジェントなマルチレンズ制御。prompt_extend が有効な場合にのみ機能します。wan2.6 および wan2.7-r2v モデル用。
- single: シングルショットビデオ（デフォルト）
- multi: マルチショットビデオ

  指定可能な値: `multi`, `single`
</ParamField>

<ParamField body="parameters.size" type="string">
  幅*高さ 形式のビデオ解像度。対応する解像度はモデルによって異なります:
wan2.5 T2V の場合: 480P (480*832, 832*480, 624*624)、720P、1080P の各サイズ
wan2.6 T2V/R2V の場合（480P なし）:
  720P: 1280*720, 720*1280, 960*960, 1088*832, 832*1088
  1080P: 1920*1080, 1080*1920, 1440*1440, 1632*1248, 1248*1632
</ParamField>

<ParamField body="parameters.watermark" type="boolean" default="false">
  ウォーターマークロゴを追加するかどうか。ウォーターマークは右下隅に配置されます
</ParamField>
