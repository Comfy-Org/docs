<ParamField body="input.audio_url" type="string">
  オーディオファイルのダウンロードURL。対応形式: mp3、wav。reference_video_urls とは併用できません。
</ParamField>

<ParamField body="input.img_url" type="string">
  先頭フレームの画像URL、または Base64 エンコードされたデータ。wan2.5-i2v-preview および wan2.6-i2v モデルでのみ必須です。happyhorse-1.x の i2v 表記は、ここでは先頭フレームを受け取りません。先頭フレームは type が `first_frame` の `media` 要素として渡します (下記 `media` を参照)。wan2.6-i2v で成功する `img_url` のボディは、happyhorse-1.0-i2v および happyhorse-1.1-i2v ではプロバイダーに拒否されます。画像形式: JPEG、JPG、PNG、BMP、WEBP。解像度: 360～2000ピクセル。ファイルサイズ: 最大10MB。
</ParamField>

<ParamField body="input.media" type="object[]">
  wan2.7、wan3.0、happyhorse-1.x モデル用のメディアアセットリスト。ビデオ生成に使用する参照素材（画像、オーディオ、ビデオ）を指定します。各要素は type フィールドと url フィールドを持ちます。
対応する type の値はモデルによって異なります:
- wan2.7-i2v: first_frame、last_frame、driving_audio、first_clip
- wan2.7-r2v: reference_image、reference_video
- wan2.7-videoedit: video、reference_image
- wan3.0-video: first_frame（最大1）、last_frame（最大1）、reference_image（最大10）、
  reference_video（最大5クリップ、合計再生時間 \<= 15秒）、reference_audio（最大5クリップ、
  合計再生時間 \<= 15秒）、file（最大1、link とは併用不可）、link（最大1、file とは
  併用不可）。reference_*/file/link タイプと first_frame/last_frame タイプは、同じリクエスト内で
  同時に使用できません。配列の順序が、プロンプト内でのアセットの参照順序（Image 1、Video 1、Audio 1、…）を
  定義します。
- happyhorse-1.x-i2v: first_frame のみで、ちょうど 1 つ。少なくとも 300x300 ピクセル、
  JPEG/JPG/PNG/WEBP、最大 20MB、公開 URL または data:\{MIME_type};base64,... URL。
  この表記は img_url を一切受け付けません。先頭フレームはここに渡します。
- happyhorse-1.x-r2v: reference_image のみで、1〜9 枚。最短辺が少なくとも
  400 ピクセル、最大 20MB、公開 URL または data: URL。reference_video はこの
  オペレーションの入力タイプではありません。
- happyhorse-1.x-video-edit: video
上記のアセットごとの「最大 20MB」は、最終的に受け取る画像に対するパートナー側の
上限であり、アセットが公開 URL の場合はそのまま適用されます。そのバイト列が
Comfy を経由しないためです。インラインの data: URL は Comfy を経由するため、
転送の上限にも直面します。Comfy Router の POST body は合計 100 MiB が上限で、
超えると 413 が返ります。base64 はペイロードを約 4/3 に膨らませるため、およそ
75 MB を超える単一のインラインアセットは、ここに示すパートナーのルールに到達する
前に拒否されます。そのサイズでも、パートナー自身の 20MB 上限にある単一のアセットは
インラインで余裕をもって収まります。つまり、1 つのアセットではパートナーのルールが
効き、転送の上限は複数のアセットにまたがって効きます。100 MiB の Router の上限は
各要素ではなくリクエスト全体を制限するためです。これらの上限に近いものは公開 URL
として送信してください。
