```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 環境変数から COMFY_API_KEY を読み取ります。
# 各 submit() 呼び出しは独自の Idempotency-Key を生成し、自動リトライ時に再利用します。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "kling/kling-4.0",
            {
                "contents": [
                    {
                        "text": "The fox turns toward the camera.",
                        "type": "prompt",
                    },
                    {
                        "type": "first_frame",
                        "url": "https://example.com/fox.png",
                    },
                ],
                "settings": {
                    "duration": 3,
                    "resolution": "720p",
                },
            },
        )
        print("request_id:", handle.request_id)  # モデル ID と合わせて、別のプロセスに必要な情報はこれだけです

        # リクエストが完了するまでポーリングし、サーバーが指定する Retry-After の時間だけ待機します。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # プロバイダー自身のペイロードで、models.run() が返す値と同じものです。
        # 失敗またはキャンセル済みのリクエストは、ここで型付きの Router エラーを発生させます。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

import { comfy } from "@comfyorg/sdk";

// 環境変数から COMFY_API_KEY を読み取ります。
// 各 submit() 呼び出しは独自の Idempotency-Key を生成し、自動リトライ時に再利用します。
const handle = await comfy.models.submit("kling/kling-4.0", {
  contents: [
    {
      text: "The fox turns toward the camera.",
      type: "prompt",
    },
    {
      type: "first_frame",
      url: "https://example.com/fox.png",
    },
  ],
  settings: {
    duration: 3,
    resolution: "720p",
  },
});
console.log("requestId:", handle.requestId); // モデル ID と合わせて、別のプロセスに必要な情報はこれだけです

// リクエストが完了するまでポーリングし、サーバーが指定する Retry-After の時間だけ待機します。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run() が返すのと同じ結果です。失敗またはキャンセル済みのリクエストは、ここで reject されます。
const result = await handle.get();

console.log(result.data);

## スキーマ

### 入力

<ParamField body="contents" type="object[]">
  プロンプトと入力メディア。"prompt"、"first_frame"、"middle_frame"、"last_frame" の項目のみを含む場合は画像から動画へを選択し（プロンプトと最大 10 フレーム）、"refer_image"、"feature_video"、"base_video"、"element"、"voice" のいずれかを含む場合は omni ビデオを選択します（最大 15 入力、うち画像は最大 10、ビデオは最大 5、element は最大 7、voice は最大 3）。"feature_video"、"base_video"、またはビデオキャラクターの element を含むリクエストは、ビデオ入力の料金で課金されます。
</ParamField>

<ParamField body="contents[].element_id" type="string">
  type が "element" の場合の element ID。
</ParamField>

<ParamField body="contents[].id" type="string">
  この入力の参照 ID。プロンプト内で @id として使用します。タスク内で一意である必要があります。"element" と "voice" では必須です。
</ParamField>

<ParamField body="contents[].text" type="string">
  type が "prompt" の場合のテキストプロンプト。英語は最大 26,000 文字、英語以外は最大 11,000 文字です。comfy-api は 1～26,000 文字を強制し、Kling 自体はそれより長い英語以外のテキストを拒否します。他の入力は @id として参照します。
</ParamField>

<ParamField body="contents[].type" type="string" required>
  入力タイプ。画像から動画へは "prompt"、"first_frame"、"middle_frame"、"last_frame" のみを受け付け、それ以外のタイプは拒否します。omni ビデオはさらに "refer_image"、"feature_video"（参照ビデオ）、"base_video"（編集対象のビデオ、最大 1 つ）、"element"、"voice" も受け付けます。

  指定可能な値: `prompt`、`first_frame`、`middle_frame`、`last_frame`、`refer_image`、`feature_video`、`base_video`、`element`、`voice`
</ParamField>

<ParamField body="contents[].url" type="string">
  画像またはビデオの URL。type がフレーム、"refer_image"、"feature_video"、"base_video" の場合に使用します。画像は Base64 でもかまいません。画像は .jpg、.jpeg、.png で最大 30MB、各辺が少なくとも 300px、アスペクト比が 2:5 から 5:2 の範囲です。ビデオは .mp4 または .mov で最大 300MB、長さは 3～30 秒です。
</ParamField>

<ParamField body="contents[].voice_id" type="string">
  type が "voice" の場合の voice ID。Kling のプリセット voice またはカスタム voice です。
</ParamField>

<ParamField body="options" type="object">
  ウォーターマークのオプションなどの一般設定。`options.callback_url` と `options.external_task_id` は Kling 4.0 ではサポートされず、Comfy Router は `options` 内でいずれかを設定したリクエストを拒否します。トップレベルの `callback_url` または `external_task_id` はこのスキーマの一部ではなく、リクエストが Kling に到達する前に削除されます。
</ParamField>

<ParamField body="options.watermark_info" type="object">
  ウォーターマーク付きの結果を同時に生成するかどうか。カスタムウォーターマークはサポートされていません。明示的な null は、/proxy の Kling 4.0 チェックおよび Kling と同様に、未指定として扱われます。
</ParamField>

<ParamField body="options.watermark_info.enabled" type="boolean">
  true はウォーターマーク付きの結果を生成する、false は生成しないことを意味します。デフォルトは false です。
</ParamField>

<ParamField body="prompt" type="string">
  テキストから動画へのプロンプト。`contents` が存在しないか空の場合に必須で、空でない `contents` と併用すると拒否されます。英語は最大 26,000 文字、英語以外は最大 11,000 文字です。comfy-api は 1～26,000 文字を強制し、Kling 自体はそれより長い英語以外のテキストを拒否します。
</ParamField>

<ParamField body="settings" type="object" required>
  解像度、アスペクト比、再生時間などの出力設定。
</ParamField>

<ParamField body="settings.aspect_ratio" type="string">
  生成されるフレームのアスペクト比（幅:高さ）。テキストから動画への場合は "21:9"、"16:9"、"9:16"、"1:1" のいずれか（デフォルトは "16:9"）、omni ビデオの場合はこれらに加えて "adaptive"（デフォルトは "adaptive"）です。画像から動画への場合は画像に従います。明示的な null は、/proxy の Kling 4.0 チェックおよび Kling と同様に、未指定として扱われます。

  指定可能な値: `21:9`、`16:9`、`9:16`、`1:1`、`adaptive`
</ParamField>

<ParamField body="settings.duration" type="integer">
  ビデオの長さ（秒）、3～30。`contents` に "base_video" が含まれる場合を除き必須です。その場合、編集では省略してベースビデオの長さを維持できます。そのような呼び出しは保留され、要求された解像度での 30 秒の最大値で見積もられます。これは価格ではなく上限であり、完了したタスクについて Kling が報告する価格から課金されます。

  範囲: `3` ～ `30`
</ParamField>

<ParamField body="settings.resolution" type="string" required>
  生成されるビデオの解像度。"720p" または "1080p" のいずれか。必須です。

  指定可能な値: `720p`、`1080p`
</ParamField>

`GET /v2/models/kling/kling-4.0/openapi.json` で Router が提供するスキーマから生成されています。これはリクエストがプロバイダーに到達する前に呼び出しを検証するのと同じドキュメントです。
