## スキーマ

### 入力

<ParamField body="contents" type="object[]">
  プロンプトと入力メディア。項目の種類によって Kling の操作が決まります。"prompt"、"first_frame"、"middle_frame"、"last_frame" の項目のみを持つ場合は画像から動画へ（プロンプトと最大 10 フレーム）が選択され、"refer_image"、"feature_video"、"base_video"、"element"、"voice" のいずれかの項目を持つ場合はオムニビデオが選択されます。`contents` がない場合または空の場合はテキストから動画へのままです。オムニビデオはプロンプト項目に加えて最大 15 個の入力（合計 16 項目）を受け付け、画像（フレームと "refer_image"）は最大 10 個、ビデオ（"feature_video" と "base_video"、うち "base_video" は最大 1 個）は最大 5 個、要素は最大 7 個、ボイスは最大 3 個です。これらの上限のいずれかを超えたリクエストは、`contents` を名指しする 422 で拒否されます。サブジェクトを使うには項目 `{"type": "element", "element_id": "<Kling element ID>", "id": "hero"}` を追加し、ボイスを使うには項目 `{"type": "voice", "voice_id": "<Kling voice ID>", "id": "narrator"}` を追加します。どちらも `id` が必要で、プロンプト項目からは @hero や @narrator として参照します。要素 ID とカスタムボイス ID は、それを作成した Kling アカウントに属します。"feature_video"、"base_video"、またはビデオキャラクター要素を含むリクエストは、ビデオ入力の料金で課金されます。
</ParamField>

<ParamField body="contents[].element_id" type="string">
  Kling の要素 ID（type が "element" の場合）。要素とは Kling 上にすでに存在するサブジェクト（キャラクターまたはオブジェクト）であり、この項目はそれを指定するだけで、アップロードは行いません。Kling は要素 ID をそれを作成した Kling アカウントに限定するため、別の Kling アカウントで作成された ID は解決されません。オムニビデオのリクエストごとに最大 7 個の要素。ビデオキャラクター要素はビデオ入力の料金で課金されますが、comfy-api は `element_id` からそれを判別できないため、見積もりでは低いレートで計上される可能性があります。
</ParamField>

<ParamField body="contents[].id" type="string">
  この入力の参照 ID で、呼び出し側が選択し、プロンプト内で @id として使用します。タスク内で一意である必要があります。"element" と "voice" では必須です。
</ParamField>

<ParamField body="contents[].text" type="string">
  テキストプロンプト（type が "prompt" の場合）。英語で最大 26,000 文字、英語以外で最大 11,000 文字。comfy-api は 1 ～ 26,000 文字を強制し、Kling 自体はそれより長い英語以外のテキストを拒否します。別の項目を参照するには、@ に続けてその項目の `id` を書きます。たとえば `id` が "hero" の要素項目と `id` が "narrator" のボイス項目がある場合、"@hero walks into the room and @narrator says hello" のように書きます。
</ParamField>

<ParamField body="contents[].type" type="string" required>
  入力の種類。画像から動画へは "prompt"、"first_frame"、"middle_frame"、"last_frame" のみを受け付け、それ以外の種類は拒否します。オムニビデオはさらに "refer_image"、"feature_video"（参照ビデオ）、"base_video"（編集対象のビデオ、最大 1 個）、"element"（`element_id` で指定するサブジェクト）、"voice"（`voice_id` で指定するボイス）も受け付けます。Comfy Router の id kling/kling-4.0-flash は `contents` をまったく受け付けません。/proxy の Kling 4.0 Flash の画像から動画へおよびオムニビデオのルートは、Kling 4.0 より狭いセットを受け付けます。画像から動画へは "prompt" と "first_frame"、オムニビデオは "prompt"、"first_frame"、"refer_image"、"feature_video"、"base_video"、"element" で、"voice" はありません。

  指定可能な値: `prompt`、`first_frame`、`middle_frame`、`last_frame`、`refer_image`、`feature_video`、`base_video`、`element`、`voice`
</ParamField>

<ParamField body="contents[].url" type="string">
  画像またはビデオの URL（type がフレーム、"refer_image"、"feature_video"、"base_video" の場合）。画像は Base64 でもかまいません。画像は .jpg、.jpeg、.png で最大 30MB、各辺 300px 以上、アスペクト比は 2:5 ～ 5:2 です。ビデオは .mp4 または .mov で最大 300MB、長さは 3 ～ 30 秒です。
</ParamField>

<ParamField body="contents[].voice_id" type="string">
  Kling のボイス ID（type が "voice" の場合）。Kling のプリセットボイスまたはカスタムボイスです。Kling はカスタムボイス ID をそれを作成した Kling アカウントに限定します。オムニビデオのリクエストごとに最大 3 個のボイス。/proxy の Kling 4.0 Flash ルートはボイス項目を受け付けず、Router の id kling/kling-4.0-flash は `contents` を受け付けません。
</ParamField>

<ParamField body="options" type="object">
  ウォーターマークのオプションなどの一般設定。`options.callback_url` と `options.external_task_id` は Kling 4.0 ではサポートされていません。Comfy Router は `options` 内でいずれかを設定したリクエストを拒否します。トップレベルの `callback_url` や `external_task_id` はこのスキーマの一部ではなく、リクエストが Kling に到達する前に削除されます。
</ParamField>

<ParamField body="options.watermark_info" type="object">
  ウォーターマーク付きの結果を同時に生成するかどうか。カスタムウォーターマークはサポートされていません。明示的な null は、/proxy Kling 4.0 のチェックおよび Kling と同様に、指定なしとして扱われます。
</ParamField>

<ParamField body="options.watermark_info.enabled" type="boolean">
  true はウォーターマーク付きの結果を生成することを意味し、false は生成しないことを意味します。デフォルトは false。
</ParamField>

<ParamField body="prompt" type="string">
  テキストから動画へのプロンプト。`contents` がない場合または空の場合は必須で、空でない `contents` と同時に指定すると拒否されます。英語で最大 26,000 文字、英語以外で最大 11,000 文字。comfy-api は 1 ～ 26,000 文字を強制し、Kling 自体はそれより長い英語以外のテキストを拒否します。
</ParamField>

<ParamField body="settings" type="object" required>
  解像度、アスペクト比、再生時間などの出力設定。
</ParamField>

<ParamField body="settings.aspect_ratio" type="string">
  生成されるフレームのアスペクト比（幅:高さ）。テキストから動画への場合は "21:9"、"16:9"、"9:16"、"1:1"、"4:3"、"3:4" のいずれか（デフォルト "16:9"）、オムニビデオの場合はこれらまたは "adaptive"（デフォルト "adaptive"）。画像から動画へは画像に従います。明示的な null は、/proxy Kling 4.0 のチェックおよび Kling と同様に、指定なしとして扱われます。

  指定可能な値: `21:9`、`16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`adaptive`
</ParamField>

<ParamField body="settings.duration" type="integer">動画の長さ（秒単位）で、3 から 30 までです。`contents` に "base_video" が含まれる場合を除き必須です。その場合、編集ではこれを省略してベースビデオの長さを維持できます。そのような呼び出しは保留され、要求された解像度で最大 30 秒として見積もられます。これは価格ではなく上限であり、完了したタスクについて Kling が報告する価格から請求されます。

  範囲: `3` から `30`
</ParamField>

<ParamField body="settings.dynamic_range" type="string">
  生成されるビデオのダイナミックレンジです。"sdr" または "hdr" のいずれかです。デフォルトは "sdr" です。"hdr" には "1080p" または "4k" の解像度が必要で、"720p" では拒否されます。HDR ビデオは出力 1 秒あたりのコストが高くなります。明示的な null は、/proxy の Kling 4.0 チェックおよび Kling と同様に、未指定として扱われます。

  指定可能な値: `sdr`, `hdr`
</ParamField>

<ParamField body="settings.resolution" type="string" required>
  生成されるビデオの解像度です。"720p"、"1080p"、"4k" のいずれかです。必須です。

  指定可能な値: `720p`, `1080p`, `4k`
</ParamField>

これは、Router が `GET /v2/models/kling/kling-4.0/openapi.json` で提供するスキーマから生成されており、リクエストがプロバイダーに到達する前に呼び出しを検証する際に使用するのと同じドキュメントです。
