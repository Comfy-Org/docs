同じボディを `POST https://api.comfy.org/v2/models/kling/kling-4.0-flash/requests` に送信します。Router は実行が受け付けられるとすぐに `201` と `request_id` を返し、結果は準備ができた時点で、このプロセスからでも別のプロセスからでも取得できます。[キューによる配信](/ja/development/comfy-router/queue)では、ステータス、キャンセル、取得の流れを説明します。

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 環境変数から COMFY_API_KEY を読み取ります。
# 各 submit() 呼び出しは独自の Idempotency-Key を発行し、自動リトライ時に再利用します。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "kling/kling-4.0-flash",
            {
                "prompt": "A neon-lit alley in the rain, slow dolly forward.",
                "settings": {
                    "aspect_ratio": "16:9",
                    "duration": 5,
                    "resolution": "720p",
                },
            },
        )
        print("request_id:", handle.request_id)  # モデル ID と合わせれば、別のプロセスに必要な情報はこれだけです

        # リクエストが完了するまでポーリングし、サーバーが指定する Retry-After だけ待機します。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # プロバイダー自身のペイロードで、models.run() が返す値と同じです。
        # 失敗またはキャンセルされたリクエストは、ここで型付きの Router エラーを発生させます。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 環境変数から COMFY_API_KEY を読み取ります。
// 各 submit() 呼び出しは独自の Idempotency-Key を発行し、自動リトライ時に再利用します。
const handle = await comfy.models.submit("kling/kling-4.0-flash", {
  prompt: "A neon-lit alley in the rain, slow dolly forward.",
  settings: {
    aspect_ratio: "16:9",
    duration: 5,
    resolution: "720p",
  },
});
console.log("requestId:", handle.requestId); // モデル ID と合わせれば、別のプロセスに必要な情報はこれだけです

// リクエストが完了するまでポーリングし、サーバーが指定する Retry-After だけ待機します。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run() が返すのと同じ結果です。失敗またはキャンセルされたリクエストはここで reject されます。
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 送信。Router は request_id、status_url、response_url、cancel_url とともに 201 を返します。
curl https://api.comfy.org/v2/models/kling/kling-4.0-flash/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"prompt\": \"A neon-lit alley in the rain, slow dolly forward.\", \"settings\": {\"aspect_ratio\":\"16:9\",\"duration\":5,\"resolution\":\"720p\"}}"

# 2. ステータスが COMPLETED になるまでポーリングし、各レスポンスが指定する Retry-After 秒だけ待機します。
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/kling/kling-4.0-flash/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 取得。モデルのネイティブ出力とともに 200、まだ実行中ならステータスボディとともに 202 を返します。
curl https://api.comfy.org/v2/models/kling/kling-4.0-flash/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## スキーマ

### 入力

<ParamField body="options" type="object">
  透かしオプションなどの一般設定。`options.callback_url` と `options.external_task_id` は Kling 4.0 ではサポートされていません。Comfy Router は、`options` 内でいずれかを設定したリクエストを拒否します。トップレベルの `callback_url` や `external_task_id` はこのスキーマには含まれず、リクエストが Kling に到達する前に削除されます。
</ParamField>

<ParamField body="options.watermark_info" type="object">
  透かし入りの結果を同時に生成するかどうか。カスタム透かしはサポートされていません。明示的な null は、/proxy の Kling 4.0 チェックと Kling 本体がそうするのと同様に、未指定として扱われます。
</ParamField>

<ParamField body="options.watermark_info.enabled" type="boolean">
  true は透かし入りの結果を生成することを意味し、false は生成しないことを意味します。デフォルトは false です。
</ParamField>

<ParamField body="prompt" type="string" required>
  ポジティブおよびネガティブの記述を含めることができるプロンプト。英語で最大 26,000 文字、非英語で最大 11,000 文字です。comfy-api は 1〜26,000 文字を強制し、Kling 自体はそれを超える非英語テキストを拒否します。
</ParamField>

<ParamField body="settings" type="object" required>
  解像度、アスペクト比、再生時間などの出力設定。
</ParamField>

<ParamField body="settings.aspect_ratio" type="string">
  生成されるフレームのアスペクト比（幅:高さ）。"21:9"、"16:9"、"9:16"、"1:1"、"4:3"、"3:4" のいずれか。デフォルトは "16:9" です。

  指定可能な値: `21:9`, `16:9`, `9:16`, `1:1`, `4:3`, `3:4`
</ParamField>

<ParamField body="settings.duration" type="integer" required>
  ビデオの再生時間（秒）で、3〜20 です。必須。

  範囲: `3` から `20`
</ParamField>

<ParamField body="settings.resolution" type="string" required>
  生成されるビデオの解像度。Kling 4.0 Flash は "720p" のみをレンダリングします。必須。

  指定可能な値: `720p`
</ParamField>

このページは、Router が `GET /v2/models/kling/kling-4.0-flash/openapi.json` で提供するスキーマから生成されています。これは、リクエストがプロバイダーに到達する前に Router が呼び出しを検証する対象となるのと同じドキュメントです。
