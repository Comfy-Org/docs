同じボディを `POST https://api.comfy.org/v2/models/kling/kling-long-image-4.0/requests` に送信します。Router は実行が受け付けられるとすぐに `request_id` を含む `201` を返し、結果は準備ができ次第、このプロセスまたは別のプロセスから収集できます。[キューの配信](/ja/development/comfy-router/queue)では、ステータス、キャンセル、収集について説明します。

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 環境変数から COMFY_API_KEY を読み取ります。
# 各 submit() 呼び出しは独自の Idempotency-Key を発行し、自動リトライのために再利用します。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "kling/kling-long-image-4.0",
            {
                "contents": [
                    {
                        "text": "A landing page for a specialty coffee roaster: hero, product showcase, roasting story and footer.",
                        "type": "prompt",
                    },
                ],
                "settings": {
                    "resolution": "1k",
                    "skill": "webpage",
                },
            },
        )
        print("request_id:", handle.request_id)  # モデル ID と合わせて、別のプロセスに必要なものはこれだけです

        # リクエストが完了するまでポーリングし、サーバーが指定した Retry-After の時間だけ待機します。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # プロバイダー自身のペイロードで、models.run() が返すのと同じ値です。
        # 失敗またはキャンセルされたリクエストは、ここで型付きの Router エラーを発生させます。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 環境変数から COMFY_API_KEY を読み取ります。
// 各 submit() 呼び出しは独自の Idempotency-Key を発行し、自動リトライのために再利用します。
const handle = await comfy.models.submit("kling/kling-long-image-4.0", {
  contents: [
    {
      text: "A landing page for a specialty coffee roaster: hero, product showcase, roasting story and footer.",
      type: "prompt",
    },
  ],
  settings: {
    resolution: "1k",
    skill: "webpage",
  },
});
console.log("requestId:", handle.requestId); // モデル ID と合わせて、別のプロセスに必要なものはこれだけです

// リクエストが完了するまでポーリングし、サーバーが指定した Retry-After の時間だけ待機します。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run() が返すのと同じ結果です。失敗またはキャンセルされたリクエストはここで reject されます。
const result = await handle.get();

console.log(result.data);
```

## スキーマ

### 入力

<ParamField body="contents" type="object[]" required>
  プロンプトと最大3枚の参照画像。
</ParamField>

<ParamField body="contents[].id" type="string">
  この入力の参照ID。プロンプト内で @id として使用します。タスク内で一意である必要があります。
</ParamField>

<ParamField body="contents[].text" type="string">
  type が "prompt" の場合のテキストプロンプト。最大166,000英文字または71,000非英文字。参照画像は @id で指定します。
</ParamField>

<ParamField body="contents[].type" type="string" required>
  入力タイプ。"prompt" 項目がちょうど1つ必須です。"webpage" スキルは最大1つの "style_refer_image" と最大1つの "subject_refer_image" を受け取ります。"ecommerce" スキルは1〜3個の "refer_image" 項目（商品写真）を受け取ります。Elements はサポートされていません。

  可能な値: `prompt`, `refer_image`, `style_refer_image`, `subject_refer_image`
</ParamField>

<ParamField body="contents[].url" type="string">
  type が参照画像の場合の画像URLまたはBase64データ。画像は .jpg、.jpeg、.png 形式で、最大30MB、各辺300px以上、アスペクト比率は2:5から5:2の間です。
</ParamField>

<ParamField body="options" type="object">
  ウォーターマークオプションなどの一般設定。`options.callback_url` と `options.external_task_id` は Kling 4.0 ではサポートされていません。Comfy Router は `options` 内でいずれかを設定したリクエストを拒否します。トップレベルの `callback_url` または `external_task_id` はこのスキーマの一部ではなく、リクエストが Kling に到達する前に削除されます。
</ParamField>

<ParamField body="options.watermark_info" type="object">
  ウォーターマーク付きの結果を同時に生成するかどうか。カスタムウォーターマークはサポートされていません。明示的な null は、/proxy の Kling 4.0 チェックと Kling と同様に、未指定として扱われます。
</ParamField>

<ParamField body="options.watermark_info.enabled" type="boolean">
  true はウォーターマーク付きの結果を生成することを意味し、false は生成しないことを意味します。デフォルトは false です。
</ParamField>

<ParamField body="settings" type="object" required>
  スキル、解像度、ページ長などの出力設定。
</ParamField>

<ParamField body="settings.length" type="string">
  "ecommerce" スキルでのページ長。"short"、"medium"、"long" のいずれかです。デフォルトは "medium" です。"webpage" では無視されます。

  可能な値: `short`, `medium`, `long`
</ParamField>

<ParamField body="settings.resolution" type="string">
  出力解像度。"1k" または "2k" のいずれかです。デフォルトは "1k" です。

  可能な値: `1k`, `2k`
</ParamField>

<ParamField body="settings.skill" type="string" required>
  "webpage"（Webページデザイン）または "ecommerce"（EC商品詳細ページ）のいずれかです。必須です。

  可能な値: `webpage`, `ecommerce`
</ParamField>
