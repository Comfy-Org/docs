`bria/image` の API リファレンスです。Comfy Router が Bria から提供しています。

**入力:** テキスト、画像 · **出力:** 画像

## クイックスタート

[ご利用の Comfy ワークスペース](https://platform.comfy.org/profile/api-keys?onboarding=router)でキーを作成し、`COMFY_API_KEY` としてエクスポートします。Python と TypeScript のスニペットは Comfy SDK（`pip install comfy-sdk` と `npm install @comfyorg/sdk`）を使用します。cURL のスニペットは、同じ呼び出しを生の HTTP で実行するものです。

**モデル ID:** `bria/image`

**エンドポイント:** `POST https://api.comfy.org/v2/models/bria/image`

同じボディを `POST https://api.comfy.org/v2/models/bria/image/requests` に送信します。Router は実行が受け付けられるとすぐに `201` と `request_id` を返し、結果は準備ができ次第、このプロセスまたは別のプロセスから収集されます。[キュー配信](/ja/development/comfy-router/queue)では、ステータス、キャンセル、収集について順を追って説明します。

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 環境から COMFY_API_KEY を読み取ります。
# 各 submit() 呼び出しは独自の Idempotency-Key を生成し、自動再試行のために再利用します。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bria/image",
            {
                "prompt": "A red vintage bicycle leaning against a brick wall in soft morning light",
            },
        )
        print("request_id:", handle.request_id)  # モデル ID と合わせれば、別のプロセスに必要なのはこれだけです

        # リクエストが完了するまでポーリングし、サーバーが指定する Retry-After の時間だけ待機します。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # プロバイダー自身のペイロードで、models.run() が返す値と同じものです。
        # 失敗したリクエストまたはキャンセル済みのリクエストは、ここで型付きの Router エラーを発生させます。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 環境から COMFY_API_KEY を読み取ります。
// 各 submit() 呼び出しは独自の Idempotency-Key を生成し、自動再試行のために再利用します。
const handle = await comfy.models.submit("bria/image", {
  prompt: "A red vintage bicycle leaning against a brick wall in soft morning light",
});
console.log("requestId:", handle.requestId); // モデル ID と合わせれば、別のプロセスに必要なのはこれだけです

// リクエストが完了するまでポーリングし、サーバーが指定する Retry-After の時間だけ待機します。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run() が返す結果と同じです。失敗したリクエストまたはキャンセル済みのリクエストは、ここで reject されます。
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 送信。Router は request_id、status_url、response_url、cancel_url を伴う 201 を返します。
curl https://api.comfy.org/v2/models/bria/image/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"prompt\": \"A red vintage bicycle leaning against a brick wall in soft morning light\"}"

# 2. ステータスが COMPLETED になるまでポーリングし、各レスポンスが示す Retry-After 秒だけ待機します。
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/bria/image/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 収集。モデル本来の出力を伴う 200、まだ実行中の場合はステータスボディを伴う 202。
curl https://api.comfy.org/v2/models/bria/image/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## スキーマ

### 入力

<ParamField body="aspect_ratio" type="string" default="&quot;1:1&quot;">
  出力画像のアスペクト比。"1:1"、"2:3"、"3:2"、"3:4"、"4:3"、"4:5"、"5:4"、"9:16"、"16:9"、"16:10"、"10:16"、"2:1"、"1:2"、"21:9"、"9:21"、"3:1"、"1:3"、"4:1"、"1:4"、"5:1"、"1:5" のいずれか。Bria は "16:10" 以降の比率を、"4MP" の場合、prompt と structured_prompt の両方を送るリファインメントの場合、および prompt を持たない画像の場合に拒否します。
</ParamField>

<ParamField body="images" type="string[]">
  新しい画像のヒントとなる参照画像。公開 URL または Base64 エンコード。対応フォーマットは JPEG、JPG、PNG、WEBP。要素は正確に 1 つだけ含める必要があります。
</ParamField>

<ParamField body="ip_signal" type="boolean" default="false">
  true の場合、プロンプトに含まれる知的財産権コンテンツの可能性について警告を返します。
</ParamField>

<ParamField body="model_version" type="string">
  使用するモデルのバージョン。"FIBO" のみ指定できます。省略すると同じモデルが実行されます。
</ParamField>

<ParamField body="output_type" type="string" default="&quot;png&quot;">
  出力画像のフォーマット。"png" または "jpeg"。
</ParamField>

<ParamField body="prompt" type="string">
  テキストによる指示。これ単体で新しい画像を生成するほか、images や structured_prompt と組み合わせて結果を誘導したりリファインしたりできます。
</ParamField>

<ParamField body="prompt_content_moderation" type="boolean" default="true">
  true の場合、プロンプトのモデレーションに失敗すると 422 を返します。
</ParamField>

<ParamField body="resolution" type="string" default="&quot;1MP&quot;">
  出力画像の解像度。"1MP" または "4MP"。"4MP" は画像のディテールを改善しますが、レイテンシが約 30 秒増加します。
</ParamField>

<ParamField body="seed" type="integer">
  決定論的な生成のためのシード。省略した場合はランダムなシードが使用されます。
</ParamField>

<ParamField body="structured_prompt" type="string">
  以前の生成結果から得られた、JSON 形式の構造化プロンプトを含む文字列。同じシードとともに使用するとその画像を再現でき、一部を変更すると画像をリファインできます。
</ParamField>

<ParamField body="visual_input_content_moderation" type="boolean" default="true">
  true の場合、入力画像のモデレーションに失敗すると 422 を返します。
</ParamField>

<ParamField body="visual_output_content_moderation" type="boolean" default="true">
  true の場合、出力画像のモデレーションに失敗すると 422 を返します。
</ParamField>

Router が `GET /v2/models/bria/image/openapi.json` で提供するスキーマから生成されたもので、リクエストがプロバイダーに届く前に Router が呼び出しを検証する際に使うドキュメントと同じです。

</ResponseField>

<ResponseField name="status" type="string">

  取りうる値: `IN_PROGRESS`、`COMPLETED`、`ERROR`、`UNKNOWN`
</ResponseField>
