同じボディを `POST https://api.comfy.org/v2/models/bria/video-edit-erase/requests` に送信します。Router は実行が受け付けられるとすぐに `201` と `request_id` を返し、結果は準備ができ次第、このプロセスからでも別のプロセスからでも収集できます。[キュー配信](/ja/development/comfy-router/queue)では、ステータス、キャンセル、収集について説明しています。

```python Python
from comfy_sdk import Comfy

# 環境変数から COMFY_API_KEY を読み取ります。
# 各 submit() 呼び出しは独自の Idempotency-Key を発行し、自動リトライのために再利用します。
with Comfy() as client:
    handle = client.models.submit(
        "bria/video-edit-erase",
        {
            "auto_trim": True,
            "mask": "https://bria-test-images.s3.us-east-1.amazonaws.com/videos/eraser/video1_mask.mp4",
            "video": "https://bria-test-images.s3.us-east-1.amazonaws.com/videos/eraser/video1_video.mp4",
        },
    )
    print("request_id:", handle.request_id)  # モデル ID と合わせれば、別のプロセスに必要な情報はこれだけです

    # リクエストが完了するまでポーリングし、サーバーが指定する Retry-After だけ待機します。
    for update in handle.iter_events():
        print(update.status, update.queue_position)

    # プロバイダー自身のペイロードで、models.run() が返すのと同じ値です。
    # 失敗またはキャンセル済みのリクエストは、ここで型付きの Router エラーを発生させます。
    result = handle.get()

print(result)
```

import { comfy } from "@comfyorg/sdk";

// 環境変数から COMFY_API_KEY を読み取ります。
// 各 submit() 呼び出しは独自の Idempotency-Key を発行し、自動リトライのために再利用します。
const handle = await comfy.models.submit("bria/video-edit-erase", {
  auto_trim: true,
  mask: "https://bria-test-images.s3.us-east-1.amazonaws.com/videos/eraser/video1_mask.mp4",
  video: "https://bria-test-images.s3.us-east-1.amazonaws.com/videos/eraser/video1_video.mp4",
});
console.log("requestId:", handle.requestId); // モデル ID と合わせれば、別のプロセスに必要な情報はこれだけです

// リクエストが完了するまでポーリングし、サーバーが指定する Retry-After だけ待機します。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run() が返すのと同じ結果です。失敗またはキャンセル済みのリクエストは、ここで reject されます。
const result = await handle.get();

console.log(result.data);

## Schema

### Input

<ParamField body="auto_trim" type="boolean">
  true の場合、5 秒を超えるビデオは最初の 5 秒にトリミングされます。false（デフォルト）の場合、それより長いビデオは拒否されます。
</ParamField>

<ParamField body="mask" type="string" required>
  削除する領域を定義するマスクビデオの公開 URL。白いピクセルは削除する領域を示し、黒いピクセルは保持されます。
</ParamField>

<ParamField body="output_container_and_codec" type="string">
  出力コンテナとコーデックのプリセット。

  指定可能な値: `mp4_h264`, `mp4_h265`, `webm_vp9`, `mov_h265`, `mov_proresks`, `mkv_h264`, `mkv_h265`, `mkv_vp9`, `gif`
</ParamField>

<ParamField body="preserve_audio" type="boolean">
  入力ビデオのオーディオを保持するかどうか。
</ParamField>

<ParamField body="video" type="string" required>
  入力ビデオの公開 URL。auto_trim が true でない限り最大再生時間は 5 秒です。入力解像度は最大 750p まで対応しており、それより大きい入力はダウンスケールされます。
</ParamField>
