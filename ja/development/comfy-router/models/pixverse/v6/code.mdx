同じボディを `POST https://api.comfy.org/v2/models/pixverse/v6/requests` に送信します。Router は実行が受け付けられるとすぐに `request_id` とともに `201` を返し、結果は準備ができ次第、このプロセスまたは別のプロセスから収集されます。[キューの配信](/ja/development/comfy-router/queue)では、ステータス、キャンセル、収集について説明しています。

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 環境変数から COMFY_API_KEY を読み取ります。
# 各 submit() 呼び出しは独自の Idempotency-Key を発行し、自動リトライで再利用します。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "pixverse/v6",
            {
                "aspect_ratio": "16:9",
                "duration": 5,
                "prompt": "a single red maple leaf falling onto still water",
                "quality": "360p",
            },
        )
        print("request_id:", handle.request_id)  # モデル ID とあわせて、別プロセスが必要とするすべての情報

        # リクエストが完了するまでポーリングし、サーバーが示す Retry-After だけ待機します。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # プロバイダー自身のペイロードで、models.run() が返すのと同じ値です。
        # 失敗またはキャンセル済みのリクエストは、ここで型付きの Router エラーを発生させます。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 環境変数から COMFY_API_KEY を読み取ります。
// 各 submit() 呼び出しは独自の Idempotency-Key を発行し、自動リトライで再利用します。
const handle = await comfy.models.submit("pixverse/v6", {
  aspect_ratio: "16:9",
  duration: 5,
  prompt: "a single red maple leaf falling onto still water",
  quality: "360p",
});
console.log("requestId:", handle.requestId); // モデル ID とあわせて、別プロセスが必要とするすべての情報

// リクエストが完了するまでポーリングし、サーバーが示す Retry-After だけ待機します。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run() が返すのと同じ結果です。失敗またはキャンセル済みのリクエストは、ここで reject されます。
const result = await handle.get();

console.log(result.data);
```

  -H "X-API-Key: $COMFY_API_KEY"
