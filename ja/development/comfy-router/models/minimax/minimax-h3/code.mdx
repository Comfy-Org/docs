`minimax/minimax-h3` の API リファレンスです。MiniMax H3（Hailuo 03）はオムニモーダルな動画モデルで、1 回の生成で映像と音声トラックを同時に出力するため、完成したクリップにはセリフ、効果音、音楽がそのまま含まれます。
