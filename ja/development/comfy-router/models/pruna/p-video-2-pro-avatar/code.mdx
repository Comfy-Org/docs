同じボディを `POST https://api.comfy.org/v2/models/pruna/p-video-2-pro-avatar/requests` に送信します。Router は実行が受け付けられるとすぐに `201` と `request_id` を返し、結果は準備でき次第、このプロセスからでも別のプロセスからでも収集できます。[キューの配信](/ja/development/comfy-router/queue)では、ステータス、キャンセル、収集の流れを説明します。

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 環境変数から COMFY_API_KEY を読み取ります。
# submit() の各呼び出しは独自の Idempotency-Key を発行し、自動リトライ時に再利用します。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "pruna/p-video-2-pro-avatar",
            {
                "input": {
                    "audio": "https://example.com/speech.mp3",
                    "image": "https://example.com/portrait.png",
                    "resolution": "768p",
                },
            },
        )
        print("request_id:", handle.request_id)  # モデル ID と合わせて、別のプロセスが必要とするものすべて

        # リクエストが完了するまでポーリングし、サーバーが指定する Retry-After だけ待機します。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # プロバイダー自身のペイロードで、models.run() が返す値と同じものです。
        # 失敗またはキャンセル済みのリクエストは、ここで型付きの Router エラーを発生させます。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 環境変数から COMFY_API_KEY を読み取ります。
// submit() の各呼び出しは独自の Idempotency-Key を発行し、自動リトライ時に再利用します。
const handle = await comfy.models.submit("pruna/p-video-2-pro-avatar", {
  input: {
    audio: "https://example.com/speech.mp3",
    image: "https://example.com/portrait.png",
    resolution: "768p",
  },
});
console.log("requestId:", handle.requestId); // モデル ID と合わせて、別のプロセスが必要とするものすべて

// リクエストが完了するまでポーリングし、サーバーが指定する Retry-After だけ待機します。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run() が返すのと同じ結果です。失敗またはキャンセル済みのリクエストは、ここで reject されます。
const result = await handle.get();

console.log(result.data);
```

```bash cURL

  -H "X-API-Key: $COMFY_API_KEY" \

  -H "X-API-Key: $COMFY_API_KEY"

# 3. 収集します。200 はモデルのネイティブ出力、実行中は 202 とステータスボディを返します。
curl https://api.comfy.org/v2/models/pruna/p-video-2-pro-avatar/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## スキーマ

### 入力

<ParamField body="input" type="object" required>
  P-Video-2-Pro Avatar のパラメータ。ジョブは返されたビデオの秒数単位で課金され、返されたファイルから計測して秒未満を切り捨て、`resolution` の料率で計算されます。セーフティフィルタは常に有効です。リクエスト内の `enable_safety_filter` の値は無視されます。
</ParamField>

<ParamField body="input.audio" type="string">
  音声の発話 URI。1 秒から 3 分まで、最大 64 MiB。出力の長さを決定します。設定した場合、`voice_script` は無視されます。
</ParamField>

<ParamField body="input.image" type="string" required>
  ポートレート URI。最初のフレームとして使用されます。jpg、png または webp、最大 20 MiB。アスペクト比を決定します。
</ParamField>

<ParamField body="input.prompt" type="string" default="&quot;The person is talking.&quot;">
  ビデオに表示される内容。
</ParamField>

<ParamField body="input.prompt_upsampling" type="boolean" default="true">
  ポートレートからシーンの動きを `prompt` に追加します。
</ParamField>

<ParamField body="input.resolution" type="string" default="&quot;768p&quot;">
  出力解像度: 480p、768p、1080p、2k または 4k。1080p、2k、4k は 768p のビデオをアップスケールします。
</ParamField>

<ParamField body="input.seed" type="integer">
  再現可能な生成のためのシード。
</ParamField>

<ParamField body="input.voice" type="string">
  `voice_script` 用のテキスト読み上げ音声。例: `Zephyr (Female)`。
</ParamField>

<ParamField body="input.voice_language" type="string">
  `voice_script` 用のテキスト読み上げ言語。例: `English (US)`。
</ParamField>

<ParamField body="input.voice_prompt" type="string">
  `voice_script` の話し方の指示（トーン、ペース、アクセント）。読み上げはされません。
</ParamField>

<ParamField body="input.voice_script" type="string">
  `audio` が設定されていない場合にテキスト読み上げで話す言葉。
</ParamField>
