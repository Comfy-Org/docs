## クイックスタート

**モデル ID:** `viggle/video-remix`

**エンドポイント:** `POST https://api.comfy.org/v2/models/viggle/video-remix`

同じボディを `POST https://api.comfy.org/v2/models/viggle/video-remix/requests` に送信します。Router は実行が受け付けられるとすぐに `request_id` を含む `201` を返し、結果は準備ができ次第、このプロセスまたは別のプロセスから収集されます。[キューの配信](/ja/development/comfy-router/queue)では、ステータス、キャンセル、収集の流れを順に説明します。

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 環境変数から COMFY_API_KEY を読み取ります。
# 各 submit() 呼び出しは独自の Idempotency-Key を生成し、自動リトライで再利用します。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "viggle/video-remix",
            {
                "background_mode": "original",
                "image_url": "https://example.invalid/viggle/character.png",
                "motion_video_url": "https://example.invalid/viggle/dance.mp4",
            },
        )
        print("request_id:", handle.request_id)  # モデル ID と合わせて、別プロセスに必要なのはこれだけです

        # リクエストが完了するまでポーリングし、サーバーが指定する Retry-After の間待機します。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # プロバイダー自身のペイロードで、models.run() が返すのと同じ値です。
        # 失敗またはキャンセルされたリクエストは、ここで型付きの Router エラーを発生させます。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 環境変数から COMFY_API_KEY を読み取ります。
// 各 submit() 呼び出しは独自の Idempotency-Key を生成し、自動リトライで再利用します。
const handle = await comfy.models.submit("viggle/video-remix", {
  background_mode: "original",
  image_url: "https://example.invalid/viggle/character.png",
  motion_video_url: "https://example.invalid/viggle/dance.mp4",
});
console.log("requestId:", handle.requestId); // モデル ID と合わせて、別プロセスに必要なのはこれだけです

// リクエストが完了するまでポーリングし、サーバーが指定する Retry-After の間待機します。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run() が返すのと同じ結果です。失敗またはキャンセルされたリクエストはここで reject されます。
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 送信します。Router は request_id、status_url、response_url、cancel_url を含む 201 を返します。
curl https://api.comfy.org/v2/models/viggle/video-remix/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"background_mode\": \"original\", \"image_url\": \"https://example.invalid/viggle/character.png\", \"motion_video_url\": \"https://example.invalid/viggle/dance.mp4\"}"

# 2. status が COMPLETED になるまでポーリングし、各レスポンスが指定する Retry-After 秒だけ待機します。
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/viggle/video-remix/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 収集します。完了時はモデルのネイティブ出力を含む 200、実行中はステータスボディを含む 202 を返します。
curl https://api.comfy.org/v2/models/viggle/video-remix/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

  キャラクター画像の公開 http(s) URL です。
</ParamField>

<ParamField body="model" type="string">

</ParamField>

<ParamField body="motion_video_url" type="string" required>
  駆動ビデオの公開 http(s) URL です。最大 100 MiB まで。
</ParamField>
