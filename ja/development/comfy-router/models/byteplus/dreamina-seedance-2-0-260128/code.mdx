### 出力

<ResponseField name="content" type="object">
  動画生成タスクの完了後の出力です。出力動画のダウンロードURLと、BytePlusが返す場合はその最終フレームのダウンロードURLを含みます。`video_url` と `last_frame_url` はどちらもComfyのストレージに再ホストされ、ここにあるその他のフィールドはすべてBytePlus独自のものです。Nullable: BytePlusはタスクの24時間後にURLをクリアするため、その後にポーリングした成功済みドキュメントでは `content` が存在しないかnullであることがあります。
</ResponseField>

<ResponseField name="content.last_frame_url" type="string">
  生成された動画の最終フレームのダウンロードURLで、リクエストで `return_last_frame` を設定した場合に返されます。このURLから画像形式を推測しないでください: BytePlusはリクエスト側で最終フレームをPNGとして文書化していますが、Routerは供されたバイト列をそのまま再ホストし、上流のContent-Typeまたはコンテンツスニッフィングから型を判定します。`image/jpeg` は両方が失敗した場合の最後のフォールバックにすぎません。Routerは最終フレームをComfyのストレージに再ホストしてこのフィールドを書き換えるため、通常は最大24時間有効なComfy署名付きURLになります。発行時に24時間で署名され、23時間のメモから再適用されるため、後でのポーリングでは残り1時間しかないURLが返ることがあります。再ホストを実行できなかった場合、このフィールドは代わりにBytePlus自身のURLを保持し、BytePlusはタスクの24時間後にそれをクリアします。いずれの場合もリンクは期限切れになるため、URLを保存するのではなくフレームをダウンロードしてください。
</ResponseField>

<ResponseField name="content.output_format" type="string">
  BytePlusが `content` の内部にネストした場合の、生成された動画のコンテナ形式（mp4またはmov）です。Seedanceモデルはこれを `content` のトップレベルの兄弟として返すことの方が多く、トップレベルの `output_format` フィールドを参照してください。Routerは存在する方の値を読み取ります。
</ResponseField>

<ResponseField name="content.upstream_expires_at" type="string (date-time)">
  上流URLが機能しなくなるRFC 3339時刻です。URL自体が持つ最も早い署名時刻と有効期間の和で、`updated_at` が存在する場合はタスクの `updated_at` に24時間（BytePlusが文書化したURLの寿命）を加えた時刻より後になることはなく、存在しない場合はタスクの `updated_at` に24時間を加えた時刻です。`upstream_video_url` または `upstream_last_frame_url` が存在する場合にのみ存在し、どちらのソースも時刻を提供しない場合は省略されます。再ホストされた `video_url` / `last_frame_url` の寿命とは無関係です。

  Format: `date-time`
</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  BytePlus自身の最終フレームのダウンロードURLで、再ホストされた `last_frame_url` の隣にバイト単位でそのまま返され、`upstream_video_url` と同じ条件が適用されます: オプトインしたワークスペースのみ、Seedance 2.xのみ、BytePlusがクリアすると存在しなくなり、`upstream_expires_at` まではベアラ資格情報です。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  BytePlus自身の出力動画のダウンロードURLで、再ホストされた `video_url` の隣にバイト単位でそのまま返されます。Comfyがサーバー側でオプトインしたワークスペースがポーリングしたSeedance 2.xのタスクにのみ存在し（リクエストパラメータはありません）、それ以外のすべての場合、たとえばワークスペースに解決されない資格情報（特定のワークスペースにスコープされていないレガシーなAPIキーなど）では存在しません。また、生成から24時間後にBytePlusがURLをクリアすると存在しなくなります。これは署名済みのオブジェクトストレージURL、つまりベアラ資格情報であるため、それを保持する誰もが有効期限まで動画をダウンロードできます。シークレットと同様に扱ってください。有効期限は `upstream_expires_at` で、Seedance 2.5ではBytePlusがダウンロード回数を100回に制限しており、そのうち1回はRouter自身の再ホストが消費します。
