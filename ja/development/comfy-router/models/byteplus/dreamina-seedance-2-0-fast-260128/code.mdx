</ResponseField>

<ResponseField name="content.upstream_expires_at" type="string (date-time)">
  上流 URL が機能しなくなる RFC 3339 時刻。最も早い署名時刻に URL 自体が持つ有効期間を加えたもので、`updated_at` が存在する場合はタスクの `updated_at` に 24 時間を加えたもの（BytePlus がドキュメント化している URL の寿命）より後になることはなく、存在しない場合はタスクの `updated_at` に 24 時間を加えたものです。`upstream_video_url` または `upstream_last_frame_url` が存在する場合にのみ存在し、どちらのソースも時刻を提供しない場合は省略されます。再ホストされた `video_url` / `last_frame_url` の寿命とは無関係です。

  形式: `date-time`
</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  最終フレームについての BytePlus 自身のダウンロード URL。再ホストされた `last_frame_url` の隣に、`upstream_video_url` と同じ条件でそのままのバイト列として返されます。オプトインしたワークスペースのみ、Seedance 2.x のみが対象で、BytePlus がクリアすると存在しなくなり、`upstream_expires_at` まではベアラー資格情報として扱われます。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  出力ビデオについての BytePlus 自身のダウンロード URL。再ホストされた `video_url` の隣に、そのままのバイト列として返されます。Comfy がサーバー側でオプトインしたワークスペースがポーリングする Seedance 2.x のタスクにのみ存在し（リクエストパラメータはありません）、それ以外のすべての場合には存在しません。たとえばワークスペースに解決されない資格情報（特定のワークスペースにスコープされていないレガシー APIキーなど）の場合も含みます。また、生成から 24 時間後に BytePlus が URL をクリアすると存在しなくなります。これは署名付きオブジェクトストレージの URL であり、したがってベアラー資格情報です。所持している人は誰でも有効期限までビデオをダウンロードできるため、シークレットと同様に扱ってください。有効期限は `upstream_expires_at` で、Seedance 2.5 では BytePlus がダウンロード回数を 100 回に制限しており、そのうち 1 回は Router 自身の再ホストで消費されます。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  出力ビデオのダウンロード URL。Router はビデオを Comfy のストレージに再ホストしてこのフィールドを書き換えるため、通常は最大 24 時間有効な Comfy 署名付き URL になります。発行時に 24 時間で署名され、23 時間のメモから再送されるため、後でポーリングすると残り 1 時間しかない URL が返ることがあります。再ホストを実行できなかった場合、このフィールドは BytePlus 自身の URL を保持し、BytePlus はタスクの 24 時間後にそれをクリアし、一部のモデルではダウンロード回数を 100 回に制限しています。いずれの場合もリンクは期限切れになるため、URL を保存するのではなくビデオをダウンロードしてください。
</ResponseField>

<ResponseField name="created_at" type="integer">
  タスクが作成された時刻。値は秒単位の UNIX タイムスタンプです。
</ResponseField>

<ResponseField name="duration" type="number">
  生成されたビデオの再生時間（秒）。BytePlus がこの点で一貫していないため、整数ではなく数値として宣言されています。ビデオタスクが整数秒を返すこともあれば、同じ BytePlus の別のサーフェスが小数の再生時間を報告することも確認されているため、クライアントは整数値であると仮定してはなりません。BytePlus 自身のフィールドで、成功したビデオタスクで返され、そのまま転送されます。
</ResponseField>

<ResponseField name="error" type="object">
  エラー情報。タスクが成功した場合は null が返されます。タスクが失敗した場合はエラー情報が返されます。
</ResponseField>

<ResponseField name="error.code" type="string">
  上流の ModelArk エラーコード。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected、OutputAudioSensitiveContentDetected はコンテンツポリシーによる拒否を識別します。ファミリーにはドット区切りの理由が付くことがあり、たとえば InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation、OutputImageSensitiveContentDetected.DeepFake などがあります。これは列挙型ではなくオープンな文字列であり、他のコードは検証やプロバイダーの失敗を表します。Router はポリシーファミリーを HTTP 400 のエラーエンベロープと HTTP 200 の失敗タスク応答で認識し、トランスポートの失敗を上書きすることはありません。
</ResponseField>

<ResponseField name="error.message" type="string">
  エラーメッセージ
</ResponseField>

<ResponseField name="id" type="string">
  動画生成タスクの ID
</ResponseField>

<ResponseField name="model" type="string">
  タスクで使用されたモデルの名前とバージョン
</ResponseField>

<ResponseField name="output_format" type="string">
  生成されたビデオのコンテナ形式（mp4 または mov）。`content` の兄弟としてトップレベルで返されます。Seedance のビデオタスククエリはここでこの値を返します。BytePlus 独自のフィールドで、変更されずにそのまま転送されます。
</ResponseField>

<ResponseField name="resolution" type="string">
  生成されたビデオの解像度（例: `1080p`）。BytePlus 独自のフィールドで、成功したビデオタスクで返され、変更されずにそのまま転送されます。
</ResponseField>

<ResponseField name="seed" type="integer">
  タスクで実際に使用された生成シード。BytePlus 独自のフィールドで、成功したビデオタスクで返され、変更されずにそのまま転送されます。

  形式: `int64`
</ResponseField>

<ResponseField name="status" type="string">
  タスクの状態

  取りうる値: `queued`, `running`, `cancelled`, `succeeded`, `failed`, `expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  タスクが最後に更新された時間。この値は秒単位の UNIX タイムスタンプです。
</ResponseField>

<ResponseField name="usage" type="object">
  リクエストのトークン使用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  モデルによって生成されたトークン数
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  ビデオ生成モデルでは入力トークン数は計算されず、0 が既定値です。そのため、total_tokens = completion_tokens となります。
</ResponseField>
