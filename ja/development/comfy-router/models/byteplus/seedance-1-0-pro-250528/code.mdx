</ResponseField>

<ResponseField name="content.upstream_expires_at" type="string (date-time)">
  上流のURLが機能しなくなるRFC 3339時刻です。URL自体が持つ最も早い署名時刻に有効期間を加えたものであり、`updated_at` が存在する場合はタスクの `updated_at` に24時間（BytePlusがドキュメント化しているURLの寿命）を加えた時刻を超えることはなく、存在しない場合はタスクの `updated_at` に24時間を加えた時刻になります。`upstream_video_url` または `upstream_last_frame_url` が存在する場合にのみ存在し、どちらのソースも時刻を提供しない場合は省略されます。再ホストされた `video_url` / `last_frame_url` の寿命とは無関係です。

  形式: `date-time`
</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  最終フレームに対するBytePlus自身のダウンロードURLで、再ホストされた `last_frame_url` の隣に、`upstream_video_url` と同じ条件でそのままのバイト列として返されます。オプトインしたワークスペースのみ、Seedance 2.xのみが対象で、BytePlusが消去すると存在しなくなり、`upstream_expires_at` まではベアラ認証情報として扱われます。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  出力ビデオに対するBytePlus自身のダウンロードURLで、再ホストされた `video_url` の隣にそのままのバイト列として返されます。Comfyがサーバー側でオプトインしたワークスペースがポーリングするSeedance 2.xのタスクに限り存在します（リクエストパラメータはありません）。それ以外のすべての場合、たとえばワークスペースに紐づかないレガシーAPIキーのように、ワークスペースを解決できない認証情報の場合には存在せず、またBytePlusが生成の24時間後にURLを消去すると存在しなくなります。これは署名付きオブジェクトストレージのURLであるためベアラ認証情報であり、これを保持する誰もが有効期限までビデオをダウンロードできます。シークレットと同様に扱ってください。有効期限は `upstream_expires_at` で、Seedance 2.5ではBytePlusがダウンロード回数を100回に制限しており、そのうち1回はRouter自身の再ホストが消費します。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  出力ビデオのダウンロードURLです。RouterはビデオをComfyのストレージへ再ホストしてこのフィールドを書き換えるため、通常は最大24時間有効なComfy署名付きURLになります。発行時に24時間で署名され、23時間のメモから再送されるため、後のポーリングでは残り1時間しかないURLが返ることがあります。再ホストを実行できなかった場合、このフィールドはBytePlus自身のURLのままとなり、BytePlusはタスクの24時間後にそれを消去し、一部のモデルではダウンロード回数を100回に制限します。いずれの場合もリンクは失効するため、URLを保存するのではなくビデオをダウンロードしてください。
</ResponseField>

<ResponseField name="created_at" type="integer">
  タスクが作成された時刻。値は秒単位のUNIXタイムスタンプです。
</ResponseField>

<ResponseField name="duration" type="number">
  生成されたビデオの再生時間（秒）。BytePlusの扱いが一貫していないため、整数ではなく数値として宣言されています。ビデオタスクでは整数秒が返されることが観測されており、同じBytePlusの別の画面では小数の再生時間が報告されるため、クライアントは整数値だと想定してはいけません。BytePlus独自のフィールドで、成功したビデオタスクで返され、そのまま転送されます。
</ResponseField>

<ResponseField name="error" type="object">
  エラー情報。タスクが成功した場合はnullが返されます。タスクが失敗した場合はエラー情報が返されます。
</ResponseField>

<ResponseField name="error.code" type="string">
  上流のModelArkエラーコード。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected、OutputAudioSensitiveContentDetected はコンテンツポリシーによる拒否を示します。ファミリーにはドット区切りの理由が付くことがあり、たとえば InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation、OutputImageSensitiveContentDetected.DeepFake などがあります。これは列挙型ではなくオープンな文字列です。その他のコードは検証やプロバイダーの障害を表します。RouterはHTTP 400のエラーエンベロープとHTTP 200の失敗タスク応答の両方でポリシーファミリーを認識しますが、トランスポート層の失敗を上書きすることはありません。
</ResponseField>

<ResponseField name="error.message" type="string">
  エラーメッセージ
</ResponseField>

<ResponseField name="id" type="string">
  動画生成タスクの ID
</ResponseField>

<ResponseField name="model" type="string">
  タスクで使用されたモデルの名前とバージョン
</ResponseField>

<ResponseField name="output_format" type="string">
  生成された動画のコンテナ形式（mp4 または mov）。`content` の兄弟としてトップレベルで返されます。Seedance の動画タスク照会が返す位置です。BytePlus 自身のフィールドで、変更されずに転送されます。
</ResponseField>

<ResponseField name="resolution" type="string">
  生成された動画の解像度（例: `1080p`）。BytePlus 自身のフィールドで、成功した動画タスクで返され、変更されずに転送されます。
</ResponseField>

<ResponseField name="seed" type="integer">
  タスクで実際に使用された生成シード。BytePlus 自身のフィールドで、成功した動画タスクで返され、変更されずに転送されます。

  形式: `int64`
</ResponseField>

<ResponseField name="status" type="string">
  タスクの状態

  指定可能な値: `queued`, `running`, `cancelled`, `succeeded`, `failed`, `expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  タスクが最後に更新された時刻。値は UNIX タイムスタンプ（秒）です。
</ResponseField>

<ResponseField name="usage" type="object">
  リクエストのトークン使用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  モデルが生成したトークン数
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  動画生成モデルでは入力トークン数は計算されず 0 とみなされます。そのため total_tokens = completion_tokens です。
</ResponseField>
