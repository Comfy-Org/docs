</ResponseField>

<ResponseField name="content.last_frame_url" type="string">
  生成されたビデオの最終フレームのダウンロードURLで、リクエストで `return_last_frame` を設定した場合に返されます。このURLから画像形式を推測しないでください。BytePlusはリクエスト側で最終フレームをPNGと記述していますが、Routerは提供されたバイト列をそのまま再ホストし、上流のContent-Typeまたはコンテンツスニッフィングから形式を判定します。`image/jpeg` は両方が失敗した場合の最後のフォールバックにすぎません。Routerは最終フレームをComfyのストレージに再ホストしてこのフィールドを書き換えるため、通常は最大24時間有効なComfy署名付きURLになります。生成時に24時間で署名され、23時間のメモから再送されるため、後でのポーリングでは残り1時間しかないURLが返ることがあります。再ホストを実行できなかった場合、このフィールドにはBytePlus自身のURLが残りますが、BytePlusはタスクの24時間後にそれを消去します。いずれの場合もリンクは期限切れになるため、URLを保存するのではなくフレームをダウンロードしてください。
</ResponseField>

<ResponseField name="content.output_format" type="string">
  BytePlusが `content` の中にネストして返す場合の、生成されたビデオのコンテナ形式（mp4またはmov）です。Seedanceモデルでは `content` のトップレベルの兄弟として返すことが多く、トップレベルの `output_format` フィールドを参照してください。Routerはどちらか存在する方を読み取ります。
</ResponseField>

<ResponseField name="content.upstream_expires_at" type="string (date-time)">
  上流のURLが機能しなくなるRFC 3339の時刻です。URL自体が持つ最も早い署名時刻と有効期間、または `updated_at` が存在する場合はタスクの `updated_at` に24時間（BytePlusが文書化しているURLの寿命）を加えた時刻のいずれか早い方です。`upstream_video_url` または `upstream_last_frame_url` が存在する場合にのみ存在し、どちらのソースも時刻を提供しない場合は省略されます。再ホストされた `video_url` / `last_frame_url` の寿命とは無関係です。

  形式: `date-time`
</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  BytePlus自身の最終フレームのダウンロードURLで、再ホストされた `last_frame_url` の隣に、`upstream_video_url` と同じ条件でそのまま返されます。オプトインしたワークスペースのみ、Seedance 2.xのみで、BytePlusが消去すると存在しなくなり、`upstream_expires_at` までベアラ認証情報として扱われます。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  BytePlus自身の出力ビデオのダウンロードURLで、再ホストされた `video_url` の隣にそのまま返されます。Comfyがサーバー側でオプトインしたワークスペースがポーリングするSeedance 2.xタスクでのみ存在します（リクエストパラメーターはありません）。それ以外のすべての場合、たとえばワークスペースに解決されない認証情報（特定のワークスペースにスコープされていないレガシーAPIキーなど）では存在せず、生成から24時間後にBytePlusがURLを消去すると存在しなくなります。これは署名付きオブジェクトストレージのURLであるためベアラ認証情報であり、それを保持する誰もが有効期限までビデオをダウンロードできます。シークレットと同様に扱ってください。`upstream_expires_at` に期限切れとなり、Seedance 2.5ではBytePlusがダウンロード回数を100回に制限しており、そのうち1回はRouter自身の再ホストで消費されます。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  出力ビデオのダウンロードURLです。RouterはビデオをComfyのストレージに再ホストしてこのフィールドを書き換えるため、通常は最大24時間有効なComfy署名付きURLになります。生成時に24時間で署名され、23時間のメモから再送されるため、後でのポーリングでは残り1時間しかないURLが返ることがあります。再ホストを実行できなかった場合、このフィールドにはBytePlus自身のURLが残りますが、BytePlusはタスクの24時間後にそれを消去し、一部のモデルではダウンロード回数を100回に制限しています。いずれの場合もリンクは期限切れになるため、URLを保存するのではなくビデオをダウンロードしてください。
</ResponseField>

<ResponseField name="created_at" type="integer">
  タスクが作成された時刻です。値はUNIXタイムスタンプ（秒）です。
</ResponseField>

<ResponseField name="duration" type="number">
  生成されたビデオの再生時間（秒）です。整数ではなく数値として宣言されているのは、BytePlusがこれについて一貫していないためです。ビデオタスクでは整数秒を返すことが観測されており、同じBytePlusの他の画面では小数の再生時間が報告されるため、クライアントは整数値を前提にしてはいけません。BytePlus自身のフィールドで、succeededのビデオタスクで返され、そのまま転送されます。
</ResponseField>

<ResponseField name="error" type="object">
  エラー情報です。タスクが成功した場合はnullが返されます。タスクが失敗した場合はエラー情報が返されます。
</ResponseField>

<ResponseField name="error.code" type="string">
  上流のModelArkエラーコードです。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected、OutputAudioSensitiveContentDetectedはコンテンツポリシーによる拒否を示します。ファミリーにはドット区切りの理由が付くことがあり、たとえばInputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation、OutputImageSensitiveContentDetected.DeepFakeなどがあります。これは列挙型ではなくオープンな文字列です。その他のコードは検証やプロバイダーの失敗を表します。RouterはHTTP 400のエラーエンベロープとHTTP 200の失敗タスク応答でポリシーファミリーを認識し、トランスポートの失敗を上書きしません。
</ResponseField>

<ResponseField name="error.message" type="string">
  エラーメッセージ
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the video generation task
</ResponseField>

<ResponseField name="model" type="string">
  タスクで使用されたモデルの名前とバージョン
</ResponseField>

<ResponseField name="output_format" type="string">
  生成済みビデオのコンテナ形式（mp4 または mov）。`content` の兄弟としてトップレベルで返されます。Seedance のビデオタスククエリはここで返します。BytePlus 独自のフィールドで、そのまま転送されます。
</ResponseField>

<ResponseField name="resolution" type="string">
  生成済みビデオの解像度（例: `1080p`）。BytePlus 独自のフィールドで、成功したビデオタスクで返され、そのまま転送されます。
</ResponseField>

<ResponseField name="seed" type="integer">
  タスクで実際に使用された生成シード。BytePlus 独自のフィールドで、成功したビデオタスクで返され、そのまま転送されます。

  形式: `int64`
</ResponseField>

<ResponseField name="status" type="string">
  タスクの状態

  指定可能な値: `queued`、`running`、`cancelled`、`succeeded`、`failed`、`expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  タスクが最後に更新された時間。値は秒単位の UNIX タイムスタンプです。
</ResponseField>

<ResponseField name="usage" type="object">
  リクエストのトークン使用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  モデルによって生成されたトークン数
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  ビデオ生成モデルでは、入力トークン数は計算されず、デフォルトで 0 になります。そのため、total_tokens = completion_tokens です。
</ResponseField>
