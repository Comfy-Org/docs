<ResponseField name="content" type="object">
  ビデオ生成タスク完了後の出力です。出力ビデオのダウンロード URL を含み、BytePlus が返す場合はその最終フレームのダウンロード URL も含みます。`video_url` と `last_frame_url` はどちらも Comfy のストレージへ再ホストされており、ここにある他のすべてのフィールドは BytePlus 自身のものです。null 許容: BytePlus はタスクの 24 時間後に URL をクリアするため、その後にポーリングした成功済みドキュメントでは `content` が存在しないか null になることがあります。
</ResponseField>

<ResponseField name="content.last_frame_url" type="string">
  生成されたビデオの最終フレームのダウンロード URL で、リクエストで `return_last_frame` を設定した場合に返されます。この URL から画像形式を推測しないでください。BytePlus はリクエスト側で最終フレームを PNG としてドキュメント化しており、Router は配信されたバイト列をそのまま再ホストし、上流の Content-Type またはコンテンツスニッフィングから型を判定します。`image/jpeg` はその両方が失敗したときの最後のフォールバックにすぎません。Router は最終フレームを Comfy のストレージへ再ホストしてこのフィールドを書き換えるため、通常は最大 24 時間有効な Comfy 署名付き URL になります。発行時に 24 時間で署名され、23 時間のメモから再生されるため、後でポーリングすると残り 1 時間しかない URL が返ることがあります。再ホストを実行できなかった場合は、代わりに BytePlus 自身の URL がこのフィールドに残りますが、BytePlus はタスクの 24 時間後にそれをクリアします。いずれの場合もリンクは失効するため、URL を保存するのではなくフレームをダウンロードしてください。

</ResponseField>

<ResponseField name="content.upstream_expires_at" type="string (date-time)">
  上流の URL が機能しなくなる RFC 3339 の時刻です。URL 自体が持つ最も早い署名時刻に有効期間を加えたもので、`updated_at` が存在する場合はタスクの `updated_at` に 24 時間（BytePlus がドキュメント化している URL の寿命）を加えた時刻を超えることはなく、存在しない場合はタスクの `updated_at` に 24 時間を加えた時刻になります。`upstream_video_url` または `upstream_last_frame_url` が存在する場合にのみ存在し、どちらのソースも時刻を返さない場合は省略されます。再ホストされた `video_url` / `last_frame_url` の寿命とは無関係です。

  形式: `date-time`
</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  最終フレームの BytePlus 自身のダウンロード URL で、再ホストされた `last_frame_url` の隣にそのままのバイト列で返されます。条件は `upstream_video_url` と同じです。オプトインしたワークスペースのみ、Seedance 2.x のみで、BytePlus がクリアすると存在しなくなり、`upstream_expires_at` まではベアラー資格情報として扱われます。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  出力ビデオの BytePlus 自身のダウンロード URL で、再ホストされた `video_url` の隣にそのままのバイト列で返されます。Comfy がサーバー側でオプトインしたワークスペースによってポーリングされた Seedance 2.x のタスクでのみ存在し（リクエストパラメーターはありません）、それ以外のすべてのケースでは存在しません。ワークスペースに解決されない資格情報（ワークスペースにスコープされていないレガシー APIキーなど）も含みます。また、生成から 24 時間後に BytePlus が URL をクリアすると存在しなくなります。これは署名付きオブジェクトストレージの URL であり、したがってベアラー資格情報です。これを保持する誰もが失効までビデオをダウンロードできるため、シークレットと同様に扱ってください。`upstream_expires_at` に失効し、Seedance 2.5 では BytePlus がダウンロード回数を 100 回に制限しており、そのうち 1 回は Router 自身の再ホストで消費されます。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  出力ビデオのダウンロード URL です。Router はビデオを Comfy のストレージへ再ホストしてこのフィールドを書き換えるため、通常は最大 24 時間有効な Comfy 署名付き URL になります。発行時に 24 時間で署名され、23 時間のメモから再生されるため、後でポーリングすると残り 1 時間しかない URL が返ることがあります。再ホストを実行できなかった場合は、代わりに BytePlus 自身の URL がこのフィールドに残りますが、BytePlus はタスクの 24 時間後にそれをクリアし、一部のモデルではダウンロード回数が 100 回に制限されます。いずれの場合もリンクは失効するため、URL を保存するのではなくビデオをダウンロードしてください。
</ResponseField>

<ResponseField name="created_at" type="integer">
  タスクが作成された時刻です。値は秒単位の UNIX タイムスタンプです。
</ResponseField>

<ResponseField name="duration" type="number">
  生成されたビデオの再生時間（秒）です。BytePlus がこの点で一貫していないため、整数ではなく数値として宣言されています。ビデオタスクが整数秒を返すこともあれば、同じ BytePlus の別のサーフェスが小数の再生時間を報告することも観測されているため、クライアントは整数値だと仮定してはいけません。BytePlus 自身のフィールドで、成功したビデオタスクで返され、変更されずに転送されます。
</ResponseField>

<ResponseField name="error" type="object">
  エラー情報です。タスクが成功した場合は null が返されます。タスクが失敗した場合はエラー情報が返されます。
</ResponseField>

<ResponseField name="error.code" type="string">
  上流の ModelArk エラーコードです。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected、OutputAudioSensitiveContentDetected はコンテンツポリシーによる拒否を識別します。ファミリーにはドット区切りの理由が付くことがあり、たとえば InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation、OutputImageSensitiveContentDetected.DeepFake などがあります。これは列挙型ではなくオープンな文字列で、他のコードは検証やプロバイダーの障害を表します。Router は HTTP 400 のエラーエンベロープと HTTP 200 の失敗タスク応答でポリシーファミリーを認識しますが、トランスポート層の障害を上書きすることはありません。
</ResponseField>

<ResponseField name="error.message" type="string">
  エラーメッセージ
</ResponseField>

<ResponseField name="id" type="string">
  ビデオ生成タスクの ID

</ResponseField>

  <ResponseField name="model" type="string">
  タスクで使用されたモデルの名前とバージョン
</ResponseField>

<ResponseField name="output_format" type="string">
  生成済みビデオのコンテナ形式（`mp4` または `mov`）。`content` の兄弟としてトップレベルで返されます。ここが Seedance ビデオタスククエリで返される位置です。BytePlus 独自のフィールドで、変更されずにそのまま転送されます。
</ResponseField>

<ResponseField name="resolution" type="string">
  生成済みビデオの解像度（例: `1080p`）。BytePlus 独自のフィールドで、成功したビデオタスクで返され、変更されずにそのまま転送されます。
</ResponseField>

<ResponseField name="seed" type="integer">
  タスクで実際に使用された生成シード。BytePlus 独自のフィールドで、成功したビデオタスクで返され、変更されずにそのまま転送されます。

  形式: `int64`
</ResponseField>

<ResponseField name="status" type="string">
  タスクの状態

  取り得る値: `queued`, `running`, `cancelled`, `succeeded`, `failed`, `expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  タスクが最後に更新された時刻。値は UNIX タイムスタンプ（秒単位）です。
</ResponseField>

<ResponseField name="usage" type="object">
  リクエストのトークン使用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  モデルによって生成されたトークン数
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  ビデオ生成モデルでは、入力トークン数は計算されず、デフォルトで 0 になります。そのため、total_tokens = completion_tokens となります。
</ResponseField>
