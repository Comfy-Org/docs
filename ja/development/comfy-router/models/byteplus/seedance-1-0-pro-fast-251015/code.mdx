<ResponseField name="content.upstream_last_frame_url" type="string">
  BytePlus自身の最終フレームのダウンロードURL。再ホストされた `last_frame_url` の隣に、`upstream_video_url` と同じ条件でバイト単位でそのまま返される。オプトインしたワークスペースのみ、Seedance 2.x のみが対象で、BytePlusがクリアした後は存在せず、`upstream_expires_at` まではベアラー資格情報として扱われる。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  BytePlus自身の出力ビデオのダウンロードURL。再ホストされた `video_url` の隣にバイト単位でそのまま返される。Comfyがサーバー側でオプトインしたワークスペースがポーリングするSeedance 2.xのタスクに対してのみ存在する（リクエストパラメータはない）。それ以外のすべての場合には存在せず、ワークスペースに解決されない資格情報（ワークスペースにスコープされていないレガシーAPIキーなど）でも存在せず、またBytePlusが生成から24時間後にURLをクリアした後も存在しない。これは署名付きオブジェクトストレージのURLであるためベアラー資格情報であり、それを保持する誰もが有効期限までビデオをダウンロードできるので、シークレットと同様に扱うこと。有効期限は `upstream_expires_at` であり、Seedance 2.5 ではBytePlusがダウンロード回数を100回に制限しており、そのうち1回はルーター自身の再ホストで消費される。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  出力ビデオのダウンロードURL。ルーターはビデオをComfyのストレージに再ホストしてこのフィールドを書き換えるため、通常は最大24時間有効なComfy署名付きURLになる。発行時に24時間で署名され、23時間のメモから再送されるため、後でのポーリングでは残り1時間しかないURLが返ることがある。再ホストを実行できなかった場合、このフィールドは代わりにBytePlus自身のURLを保持し、BytePlusはタスクの24時間後にそれをクリアし、一部のモデルではダウンロード回数を100回に制限する。いずれにせよリンクは失効するので、URLを保存するのではなくビデオをダウンロードすること。
</ResponseField>

<ResponseField name="created_at" type="integer">
  タスクが作成された時刻。値は秒単位のUNIXタイムスタンプである。
</ResponseField>

<ResponseField name="duration" type="number">
  生成されたビデオの再生時間（秒）。BytePlusがこの点で一貫していないため、整数ではなく数値として宣言されている。ビデオタスクが整数の秒を返すことも観測されており、同系列のBytePlusの他のサーフェスは小数の再生時間を報告するため、クライアントは整数値であると仮定してはならない。BytePlus自身のフィールドであり、成功したビデオタスクで返され、そのまま転送される。
</ResponseField>

<ResponseField name="error" type="object">
  エラー情報。タスクが成功した場合はnullが返される。タスクが失敗した場合はエラー情報が返される。
</ResponseField>

<ResponseField name="error.code" type="string">
  上流のModelArkエラーコード。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected、OutputAudioSensitiveContentDetected はコンテンツポリシーによる拒否を示す。ファミリーには、InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation、OutputImageSensitiveContentDetected.DeepFake のように、ドット区切りの理由が付くことがある。これは列挙型ではなくオープンな文字列であり、他のコードは検証およびプロバイダーの失敗を表す。ルーターはHTTP 400のエラーエンベロープとHTTP 200の失敗タスク応答でポリシーファミリーを認識するが、トランスポートの失敗を上書きすることはない。
</ResponseField>

<ResponseField name="error.message" type="string">
  エラーメッセージ
</ResponseField>

<ResponseField name="id" type="string">ビデオ生成タスクのID
</ResponseField>

<ResponseField name="model" type="string">
  タスクで使用されたモデルの名前とバージョン
</ResponseField>

<ResponseField name="output_format" type="string">
  生成済みビデオのコンテナ形式（mp4 または mov）。`content` の兄弟として最上位レベルで返されます。Seedance のビデオタスククエリはここで返します。BytePlus 独自のフィールドで、変更されずに転送されます。
</ResponseField>

<ResponseField name="resolution" type="string">
  生成済みビデオの解像度（例: `1080p`）。BytePlus 独自のフィールドで、成功したビデオタスクで返され、変更されずに転送されます。
</ResponseField>

<ResponseField name="seed" type="integer">
  タスクで実際に使用された生成シード。BytePlus 独自のフィールドで、成功したビデオタスクで返され、変更されずに転送されます。

  形式: `int64`
</ResponseField>

<ResponseField name="status" type="string">
  タスクの状態

  可能な値: `queued`、`running`、`cancelled`、`succeeded`、`failed`、`expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  タスクが最後に更新された時間。値は UNIX タイムスタンプ（秒単位）です。
</ResponseField>

<ResponseField name="usage" type="object">
  リクエストのトークン使用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  モデルによって生成されたトークン数
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  ビデオ生成モデルの場合、入力トークン数は計算されず、デフォルトで 0 になります。したがって、total_tokens = completion_tokens です。
</ResponseField>
