</ResponseField>

<ResponseField name="content.upstream_expires_at" type="string (date-time)">
  上流のURLが機能しなくなる RFC 3339 時刻です。URL自体が持つ最も早い署名時刻と有効期間、ただし `updated_at` が存在する場合はタスクの `updated_at` と24時間（BytePlus の文書化されたURLの寿命）のうち遅くない方、存在しない場合はタスクの `updated_at` と24時間です。`upstream_video_url` または `upstream_last_frame_url` が存在する場合にのみ存在し、どちらのソースも時刻を提供しない場合は省略されます。再ホストされた `video_url` / `last_frame_url` の寿命とは無関係です。

  形式: `date-time`
</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  BytePlus 自身の最終フレームのダウンロードURLで、再ホストされた `last_frame_url` の隣にそのままのバイト列で返されます。条件は `upstream_video_url` と同じです。オプトインしたワークスペースのみ、Seedance 2.x のみ、BytePlus が消去すると欠落し、`upstream_expires_at` まではベアラ資格情報です。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  BytePlus 自身の出力ビデオのダウンロードURLで、再ホストされた `video_url` の隣にそのままのバイト列で返されます。Comfy がサーバー側でオプトインしたワークスペースがポーリングする Seedance 2.x タスクでのみ存在します（リクエストパラメータはありません）。それ以外のすべての場合、たとえばワークスペースに解決されない資格情報（ワークスペースにスコープされていないレガシー APIキーなど）では存在せず、また生成から24時間後に BytePlus がURLを消去すると存在しなくなります。これは署名付きオブジェクトストレージのURLであり、したがってベアラ資格情報です。保持している人は誰でも有効期限までビデオをダウンロードできるため、秘密情報として扱ってください。`upstream_expires_at` に失効し、Seedance 2.5 では BytePlus が100回のダウンロードに制限しており、そのうち1回は Router 自身の再ホストが消費します。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  出力ビデオのダウンロードURLです。Router はビデオを Comfy のストレージに再ホストしてこのフィールドを書き換えるため、通常は最大24時間有効な Comfy 署名付きURLになります。発行時に24時間で署名され、23時間のメモから再生されるため、後でポーリングすると残り1時間程度のものが返ることがあります。再ホストを実行できなかった場合、このフィールドは BytePlus 自身のURLを保持し、BytePlus はタスクの24時間後にそれを消去し、一部のモデルでは100回のダウンロードに制限します。いずれの場合もリンクは失効するため、URLを保存するのではなくビデオをダウンロードしてください。
</ResponseField>

<ResponseField name="created_at" type="integer">
  タスクが作成された時刻。値は秒単位の UNIX タイムスタンプです。
</ResponseField>

<ResponseField name="duration" type="number">
  生成されたビデオの再生時間（秒）。BytePlus がこの点で一貫していないため、整数ではなく数値として宣言されています。ビデオタスクが整数秒を返す例や、姉妹の BytePlus サーフェスが小数の再生時間を報告する例が観測されているため、クライアントは整数値を前提にしてはいけません。BytePlus 自身のフィールドで、成功したビデオタスクで返され、そのまま転送されます。
</ResponseField>

<ResponseField name="error" type="object">
  エラー情報。タスクが成功した場合は null が返されます。タスクが失敗した場合はエラー情報が返されます。
</ResponseField>

<ResponseField name="error.code" type="string">
  上流の ModelArk エラーコード。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected、OutputAudioSensitiveContentDetected はコンテンツポリシーによる拒否を識別します。ファミリーにはドット区切りの理由が付くことがあり、たとえば InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation、OutputImageSensitiveContentDetected.DeepFake などです。これは列挙型ではなくオープンな文字列です。他のコードは検証やプロバイダーの障害を表します。Router は HTTP 400 のエラーエンベロープと HTTP 200 の失敗タスク応答でポリシーファミリーを認識しますが、トランスポートの障害を上書きすることはありません。
</ResponseField>

<ResponseField name="error.message" type="string">
  エラーメッセージ
</ResponseField>

<ResponseField name="id" type="string">
  ビデオ生成タスクの ID
</ResponseField>

<ResponseField name="model" type="string">
  タスクで使用されたモデルの名前とバージョン
</ResponseField>

<ResponseField name="output_format" type="string">
  生成済みビデオのコンテナ形式（mp4 または mov）。`content` の兄弟としてトップレベルで返されます。Seedance のビデオタスククエリはここでこれを返します。BytePlus 独自のフィールドであり、変更されずにそのまま転送されます。
</ResponseField>

<ResponseField name="resolution" type="string">
  生成済みビデオの解像度。例: `1080p`。BytePlus 独自のフィールドであり、成功したビデオタスクで返され、変更されずにそのまま転送されます。
</ResponseField>

<ResponseField name="seed" type="integer">
  タスクで実際に使用された生成シード。BytePlus 独自のフィールドであり、成功したビデオタスクで返され、変更されずにそのまま転送されます。

  形式: `int64`
</ResponseField>

<ResponseField name="status" type="string">
  タスクの状態

  取り得る値: `queued`、`running`、`cancelled`、`succeeded`、`failed`、`expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  タスクが最後に更新された時間。値は秒単位の UNIX タイムスタンプです。
</ResponseField>

<ResponseField name="usage" type="object">
  リクエストのトークン使用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  モデルによって生成されたトークン数
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  ビデオ生成モデルでは、入力トークン数は計算されず、0 がデフォルトです。そのため、total_tokens = completion_tokens となります。
</ResponseField>
