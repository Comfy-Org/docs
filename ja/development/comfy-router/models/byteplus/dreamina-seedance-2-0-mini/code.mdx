</ResponseField>

<ResponseField name="content.last_frame_url" type="string">
  生成された動画の最終フレームのダウンロードURLで、リクエストが `return_last_frame` を設定した場合に返されます。このURLから画像形式を推測しないでください。BytePlusはリクエスト側では最終フレームをPNGとして文書化していますが、Routerは提供されたバイト列をそのまま再ホストし、上流のContent-Typeまたはコンテンツスニッフィングから型を判定します。`image/jpeg` はその両方が失敗した場合の最後のフォールバックにすぎません。Routerは最終フレームをComfyのストレージに再ホストしてこのフィールドを書き換えるため、通常は最大24時間有効なComfy署名付きURLになります。発行時に24時間で署名され、23時間のメモから再利用されるため、後でポーリングすると残り1時間しかないURLが返ることがあります。再ホストを実行できなかった場合、このフィールドはBytePlus自身のURLのままとなり、BytePlusはタスクの24時間後にそれを消去します。いずれの場合もリンクは期限切れになるため、URLを保存するのではなくフレームをダウンロードしてください。
</ResponseField>

<ResponseField name="content.output_format" type="string">
  生成された動画のコンテナ形式（mp4またはmov）で、BytePlusが `content` の中にネストして返す場合に含まれます。Seedanceモデルはこれを `content` のトップレベルの兄弟として返すことの方が多く、その場合はトップレベルの `output_format` フィールドを参照してください。Routerはどちらか存在する方を読み取ります。
</ResponseField>

<ResponseField name="content.upstream_expires_at" type="string (date-time)">
  上流のURLが機能しなくなるRFC 3339時刻。URL自体が持つ最も早い署名時刻に有効期間を加えたもので、`updated_at` が存在する場合はタスクの `updated_at` に24時間を加えた時刻（BytePlusが文書化しているURLの寿命）より遅くなることはなく、存在しない場合はタスクの `updated_at` に24時間を加えた時刻です。`upstream_video_url` または `upstream_last_frame_url` が存在する場合にのみ存在し、どちらのソースも時刻を提供しない場合は省略されます。再ホストされた `video_url` / `last_frame_url` の有効期間とは無関係です。

  形式: `date-time`
</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  BytePlus自身の最終フレームのダウンロードURLで、再ホストされた `last_frame_url` の隣に、`upstream_video_url` と同じ条件でバイト単位でそのまま返されます。オプトインしたワークスペースのみ、Seedance 2.xのみ、BytePlusが消去した後は存在せず、`upstream_expires_at` まではベアラ認証情報です。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  BytePlus自身の出力動画のダウンロードURLで、再ホストされた `video_url` の隣にバイト単位でそのまま返されます。Comfyがサーバー側でオプトインしたワークスペースによってポーリングされたSeedance 2.xのタスクにのみ存在します（リクエストパラメータはありません）。それ以外のすべての場合には存在せず、ワークスペースに解決されない認証情報（特定のワークスペースにスコープされていないレガシーAPIキーなど）も含まれます。また、BytePlusが生成の24時間後にURLを消去すると存在しなくなります。これは署名済みオブジェクトストレージのURLであるため、ベアラ認証情報です。保持している人は誰でも有効期限まで動画をダウンロードできるので、秘密情報として扱ってください。`upstream_expires_at` に期限切れとなり、Seedance 2.5ではBytePlusが100回のダウンロードに制限しており、そのうち1回はRouter自身の再ホストで消費されます。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  出力動画のダウンロードURL。Routerは動画をComfyのストレージに再ホストしてこのフィールドを書き換えるため、通常は最大24時間有効なComfy署名付きURLになります。発行時に24時間で署名され、23時間のメモから再利用されるため、後でポーリングすると残り1時間しかないURLが返ることがあります。再ホストを実行できなかった場合、このフィールドはBytePlus自身のURLのままとなり、BytePlusはタスクの24時間後にそれを消去し、一部のモデルでは100回のダウンロードに制限します。いずれの場合もリンクは期限切れになるため、URLを保存するのではなく動画をダウンロードしてください。
</ResponseField>

<ResponseField name="created_at" type="integer">
  タスクが作成された時刻。値は秒単位のUNIXタイムスタンプです。
</ResponseField>

<ResponseField name="duration" type="number">
  生成された動画の再生時間（秒）。BytePlusがこれについて一貫していないため、整数ではなく数値として宣言されています。動画タスクが整数秒を返す例や、同系列のBytePlusのサーフェスが小数の再生時間を報告する例が観察されているため、クライアントは整数値と仮定してはいけません。BytePlus自身のフィールドで、成功した動画タスクで返され、変更されずに転送されます。
</ResponseField>

<ResponseField name="error" type="object">
  エラー情報。タスクが成功するとnullが返されます。タスクが失敗すると、エラー情報が返されます。
</ResponseField>

<ResponseField name="error.code" type="string">
  上流のModelArkエラーコード。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected、OutputAudioSensitiveContentDetected はコンテンツポリシーによる拒否を識別します。ファミリーにはドット区切りの理由が付くことがあり、例えば InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation、OutputImageSensitiveContentDetected.DeepFake などです。これは列挙型ではなくオープンな文字列です。他のコードは検証やプロバイダーの失敗を表します。RouterはHTTP 400のエラーエンベロープとHTTP 200の失敗タスク応答でポリシーファミリーを認識しますが、トランスポートの失敗を上書きすることはありません。
</ResponseField>

<ResponseField name="error.message" type="string">
  エラーメッセージ
</ResponseField>

<ResponseField name="id" type="string">
  ビデオ生成タスクのID
</ResponseField>

<ResponseField name="model" type="string">
  タスクで使用されるモデルの名前とバージョン
</ResponseField>

<ResponseField name="output_format" type="string">
  生成済みビデオのコンテナ形式（mp4 または mov）。`content` の兄弟としてトップレベルで返されます。これは Seedance のビデオタスククエリが返す場所です。BytePlus 独自のフィールドで、変更されずに転送されます。
</ResponseField>

<ResponseField name="resolution" type="string">
  生成済みビデオの解像度（例: `1080p`）。BytePlus 独自のフィールドで、成功したビデオタスクで返され、変更されずに転送されます。
</ResponseField>

<ResponseField name="seed" type="integer">
  タスクで実際に使用された生成シード。BytePlus 独自のフィールドで、成功したビデオタスクで返され、変更されずに転送されます。

  形式: `int64`
</ResponseField>

<ResponseField name="status" type="string">
  タスクの状態

  取り得る値: `queued`, `running`, `cancelled`, `succeeded`, `failed`, `expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  タスクが最後に更新された時間。値は秒単位の UNIX タイムスタンプです。
</ResponseField>

<ResponseField name="usage" type="object">
  リクエストのトークン使用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  モデルによって生成されたトークン数
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  ビデオ生成モデルでは、入力トークン数は計算されず、デフォルトは 0 です。したがって、total_tokens = completion_tokens です。
</ResponseField>
