</ResponseField>

<ResponseField name="content.upstream_expires_at" type="string (date-time)">
  アップストリームのURLが機能しなくなるRFC 3339時刻です。URL自体が持つ最も早い署名時刻に有効期間を加えたもので、`updated_at` が存在する場合はタスクの `updated_at` に24時間（BytePlusがドキュメント化しているURLの寿命）を加えた時刻より後になることはなく、存在しない場合はタスクの `updated_at` に24時間を加えた時刻になります。`upstream_video_url` または `upstream_last_frame_url` が存在する場合にのみ存在し、どちらのソースも時刻を提供しない場合は省略されます。再ホストされた `video_url` / `last_frame_url` の寿命とは無関係です。

  形式: `date-time`
</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  再ホストされた `last_frame_url` の隣にバイト単位でそのまま返される、BytePlus独自の最終フレームのダウンロードURLです。条件は `upstream_video_url` と同じで、オプトインしたワークスペースのみ、Seedance 2.xのみ、BytePlusがクリアした後は存在せず、`upstream_expires_at` まではベアラ資格情報です。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  再ホストされた `video_url` の隣にバイト単位でそのまま返される、BytePlus独自の出力ビデオのダウンロードURLです。Comfyがサーバー側でオプトインしたワークスペースによってポーリングされたSeedance 2.xタスクにのみ存在し（リクエストパラメータはありません）、それ以外のすべての場合には存在しません。ワークスペースに解決されない資格情報（特定のワークスペースにスコープされていないレガシーAPIキーなど）も含まれ、BytePlusが生成の24時間後にURLをクリアすると存在しなくなります。これは署名付きオブジェクトストレージのURL、つまりベアラ資格情報であるため、それを保持する誰もが有効期限までビデオをダウンロードできます。秘密情報と同様に扱ってください。`upstream_expires_at` で期限切れになり、Seedance 2.5ではBytePlusが100ダウンロードに制限しており、そのうち1回はRouter自身の再ホストで消費されます。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  出力ビデオのダウンロードURLです。RouterはビデオをComfyのストレージに再ホストしてこのフィールドを書き換えるため、通常は最大24時間有効なComfy署名付きURLになります。発行時に24時間で署名され、23時間のメモから再生されるため、後でのポーリングでは残り1時間しかないURLが返ることがあります。再ホストを実行できなかった場合、このフィールドはBytePlus独自のURLを保持し、BytePlusはタスクの24時間後にそれをクリアし、一部のモデルでは100ダウンロードに制限します。いずれの場合もリンクは期限切れになるため、URLを保存するのではなくビデオをダウンロードしてください。
</ResponseField>

<ResponseField name="created_at" type="integer">
  タスクが作成された時刻です。値は秒単位のUNIXタイムスタンプです。
</ResponseField>

<ResponseField name="duration" type="number">
  生成されたビデオの再生時間（秒）です。整数ではなく数値として宣言されているのは、BytePlusの扱いが一貫していないためです。ビデオタスクでは整数秒が返されることが観測されており、同じBytePlusの他のサーフェスでは小数の再生時間が報告されるため、クライアントは整数値を前提にしてはいけません。BytePlus独自のフィールドで、成功したビデオタスクで返され、変更されずに転送されます。
</ResponseField>

<ResponseField name="error" type="object">
  エラー情報です。タスクが成功した場合はnullが返されます。タスクが失敗した場合は、エラー情報が返されます。
</ResponseField>

<ResponseField name="error.code" type="string">
  アップストリームのModelArkエラーコードです。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected、OutputAudioSensitiveContentDetected はコンテンツポリシーによる拒否を識別します。ファミリーにはドット区切りの理由が付くことがあり、例えば InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation、OutputImageSensitiveContentDetected.DeepFake などがあります。これは列挙型ではなくオープンな文字列です。他のコードは検証やプロバイダーの障害を表します。RouterはHTTP 400のエラーエンベロープおよびHTTP 200の失敗タスク応答でポリシーファミリーを認識しますが、トランスポートの障害を上書きすることはありません。
</ResponseField>

<ResponseField name="error.message" type="string">
  エラーメッセージ
</ResponseField>

<ResponseField name="id" type="string">
  動画生成タスクの ID
</ResponseField>

<ResponseField name="model" type="string">
  タスクで使用されたモデルの名前とバージョン
</ResponseField>

<ResponseField name="output_format" type="string">
  生成済みビデオのコンテナ形式（mp4 または mov）。`content` の兄弟要素として TOP LEVEL で返されます。Seedance のビデオタスククエリはここでこの値を返します。BytePlus 独自のフィールドであり、変更されずにそのまま転送されます。
</ResponseField>

<ResponseField name="resolution" type="string">
  生成済みビデオの解像度（例: `1080p`）。BytePlus 独自のフィールドであり、成功したビデオタスクで返され、変更されずにそのまま転送されます。
</ResponseField>

<ResponseField name="seed" type="integer">
  タスクで実際に使用された生成シード。BytePlus 独自のフィールドであり、成功したビデオタスクで返され、変更されずにそのまま転送されます。

  形式: `int64`
</ResponseField>

<ResponseField name="status" type="string">
  タスクの状態

  指定可能な値: `queued`, `running`, `cancelled`, `succeeded`, `failed`, `expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  タスクが最後に更新された時間。値は秒単位の UNIX タイムスタンプです。
</ResponseField>

<ResponseField name="usage" type="object">
  リクエストのトークン使用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  モデルによって生成されたトークン数
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  ビデオ生成モデルでは入力トークン数は計算されず、0 がデフォルトとなります。したがって、total_tokens = completion_tokens となります。
</ResponseField>
