同じボディを `POST https://api.comfy.org/v2/models/stability/control-style/requests` に送信します。Router は実行が受け付けられるとすぐに `request_id` とともに `201` を返し、結果は準備ができ次第、このプロセスまたは別のプロセスから収集できます。[キュー配信](/ja/development/comfy-router/queue)では、ステータス、キャンセル、収集の流れを説明します。

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 環境変数から COMFY_API_KEY を読み取ります。
# submit() の各呼び出しは独自の Idempotency-Key を発行し、自動リトライ時に再利用します。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/control-style",
            {
                "aspect_ratio": "16:9",
                "fidelity": 0.5,
                "image": "https://storage.googleapis.com/example-bucket/style.png",
                "prompt": "a castle on a cliff",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # モデル ID と合わせて、別プロセスに必要な情報はこれだけです

        # リクエストが完了するまでポーリングし、サーバーが指定する Retry-After の秒数だけ待機します。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # プロバイダー自身のペイロードで、models.run() が返すのと同じ値です。
        # 失敗またはキャンセル済みのリクエストは、ここで型付きの Router エラーを発生させます。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 環境変数から COMFY_API_KEY を読み取ります。
// submit() の各呼び出しは独自の Idempotency-Key を発行し、自動リトライ時に再利用します。
const handle = await comfy.models.submit("stability/control-style", {
  aspect_ratio: "16:9",
  fidelity: 0.5,
  image: "https://storage.googleapis.com/example-bucket/style.png",
  prompt: "a castle on a cliff",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // モデル ID と合わせて、別プロセスに必要な情報はこれだけです

// リクエストが完了するまでポーリングし、サーバーが指定する Retry-After の秒数だけ待機します。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run() が返すのと同じ結果です。失敗またはキャンセル済みのリクエストは、ここで reject されます。
const result = await handle.get();

console.log(result.data);
```

## スキーマ

### 入力

<ParamField body="aspect_ratio" type="string">
  約1メガピクセルでの出力アスペクト比。デフォルトは 1:1。

  指定可能な値: `1:1`、`16:9`、`9:16`、`21:9`、`9:21`、`3:2`、`2:3`、`5:4`、`4:5`
</ParamField>

<ParamField body="fidelity" type="number">
  結果がソースのスタイルにどの程度従うか。デフォルトは 0.5。

  範囲: `0` から `1`
</ParamField>

<ParamField body="image" type="string (uri)" required>
  スタイルソースの Comfy 署名付きアセットURL。

  形式: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  画像に含めない内容。
</ParamField>

<ParamField body="output_format" type="string">
  `png` のみ返されます。

  指定可能な値: `png`
</ParamField>

<ParamField body="prompt" type="string" required>
  ソース画像のスタイルで生成する内容。
</ParamField>

<ParamField body="seed" type="integer">
  0 または省略時はランダムなシードが選択されます。

  範囲: `0` から `4294967294`
</ParamField>

<ParamField body="style_preset" type="string">
  受け付けられますが適用されません。
</ParamField>

Router が `GET /v2/models/stability/control-style/openapi.json` で提供するスキーマから生成されており、リクエストがプロバイダーに到達する前に呼び出しを検証する際と同じドキュメントです。

### 出力

<ResponseField name="finish_reason" type="string" required>
  200 の場合は常に SUCCESS。
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  （最初の）PNG 画像の Comfy 署名付きURL。最大24時間有効。

  形式: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  SDXL のみ、複数の画像が返された場合。出力順に並んだすべての Comfy 署名付き画像URLで、それぞれ最大24時間有効。
</ResponseField>

<ResponseField name="seed" type="integer" required>
  画像の生成に使用されたシード。
</ResponseField>
