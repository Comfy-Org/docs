同じボディを `POST https://api.comfy.org/v2/models/stability/sd3.5-medium/requests` に送信します。Router は実行が受け付けられるとすぐに `201` と `request_id` を返し、結果は準備ができ次第、このプロセスまたは別のプロセスから収集します。[キューの配信](/ja/development/comfy-router/queue)では、ステータス、キャンセル、収集の流れを順に説明します。

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 環境から COMFY_API_KEY を読み取ります。
# submit() の呼び出しごとに独自の Idempotency-Key を発行し、自動リトライで再利用します。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/sd3.5-medium",
            {
                "aspect_ratio": "16:9",
                "prompt": "a lighthouse on a cliff at sunset, oil painting",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # モデル ID と合わせて、別のプロセスに必要なのはこれだけです

        # リクエストが完了するまでポーリングし、サーバーが指定する Retry-After の間待機します。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # プロバイダー自身のペイロードで、models.run() が返す値と同じものです。
        # 失敗またはキャンセル済みのリクエストは、ここで型付きの Router エラーを発生させます。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 環境から COMFY_API_KEY を読み取ります。
// submit() の呼び出しごとに独自の Idempotency-Key を発行し、自動リトライで再利用します。
const handle = await comfy.models.submit("stability/sd3.5-medium", {
  aspect_ratio: "16:9",
  prompt: "a lighthouse on a cliff at sunset, oil painting",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // モデル ID と合わせて、別のプロセスに必要なのはこれだけです

// リクエストが完了するまでポーリングし、サーバーが指定する Retry-After の間待機します。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run() が返すのと同じ結果です。失敗またはキャンセル済みのリクエストは、ここで reject されます。
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 送信します。Router は request_id、status_url、response_url、cancel_url とともに 201 を返します。
curl https://api.comfy.org/v2/models/stability/sd3.5-medium/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"aspect_ratio\": \"16:9\", \"prompt\": \"a lighthouse on a cliff at sunset, oil painting\", \"seed\": 12345}"

# 2. ステータスが COMPLETED になるまでポーリングし、各レスポンスが指定する Retry-After 秒だけ待機します。
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/stability/sd3.5-medium/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 収集します。モデル固有の出力とともに 200、まだ実行中ならステータスボディとともに 202 を返します。
curl https://api.comfy.org/v2/models/stability/sd3.5-medium/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## スキーマ

### 入力

<ParamField body="aspect_ratio" type="string">
  テキストから画像へのみ。出力のアスペクト比は約100万画素になります。デフォルトは 1:1 です。

  指定可能な値: `1:1`、`16:9`、`9:16`、`21:9`、`9:21`、`3:2`、`2:3`、`5:4`、`4:5`
</ParamField>

<ParamField body="cfg_scale" type="number">
  画像がプロンプトにどの程度厳密に従うか。

  範囲: `1` から `10`
</ParamField>

<ParamField body="image" type="string (uri)">
  画像から画像へのみ。ソース画像の Comfy 署名付きアセットURL。

  形式: `uri`
</ParamField>

<ParamField body="mode" type="string">
  デフォルトはテキストから画像へです。画像から画像へでは `image` と `strength` が必要です。

  指定可能な値: `text-to-image`、`image-to-image`
</ParamField>

<ParamField body="negative_prompt" type="string">
  画像に含めたくない内容。
</ParamField>

<ParamField body="output_format" type="string">
  返されるのは `png` のみです。

  指定可能な値: `png`
</ParamField>

<ParamField body="prompt" type="string" required>
  生成する内容。
</ParamField>

<ParamField body="seed" type="integer">
  0 または省略した場合はランダムなシードが選ばれます。

  範囲: `0` から `4294967294`
</ParamField>

<ParamField body="strength" type="number">
  画像から画像へのみ。ソース画像からどの程度変化させるか。1 ではソース画像を無視します。

  範囲: `0` から `1`
</ParamField>

<ParamField body="style_preset" type="string">
  Stability のスタイルプリセット。例えば `photographic` です。
</ParamField>

Router が `GET /v2/models/stability/sd3.5-medium/openapi.json` で提供するスキーマから生成されています。これは、リクエストがプロバイダーに到達する前に Router が呼び出しを検証する際に使用するものと同じドキュメントです。

### 出力

<ResponseField name="finish_reason" type="string" required>
  200 の場合は常に SUCCESS です。
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  （最初の）PNG 画像の Comfy 署名付きURL。最大24時間有効です。

  形式: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  SDXL のみ。複数の画像が返された場合に使用します。すべての Comfy 署名付き画像URLを出力順に並べたもので、それぞれ最大24時間有効です。
</ResponseField>

<ResponseField name="seed" type="integer" required>
  画像の生成に使用されたシード。
</ResponseField>
