<ParamField body="cfg_scale" type="number">

<ParamField body="clip_guidance_preset" type="string">

<ParamField body="extras" type="object">
  互換性のために受け付けられますが、無視されます。
</ParamField>

<ParamField body="init_image" type="string (uri)" required>
  ソース画像の Comfy 署名付きアセット URL。

  形式: `uri`
</ParamField>

<ParamField body="mask_image" type="string (uri)">
  マスクの Comfy 署名付きアセット URL。MASK_IMAGE_WHITE と MASK_IMAGE_BLACK では必須で、INIT_IMAGE_ALPHA では拒否されます。

  形式: `uri`
</ParamField>

<ParamField body="mask_source" type="string" required>
  マスクの取得元。MASK_IMAGE_WHITE と MASK_IMAGE_BLACK は `mask_image` を読み取り、その白または黒のピクセルを再描画します。INIT_IMAGE_ALPHA は `init_image` のアルファチャンネルを読み取ります。

  指定可能な値: `MASK_IMAGE_WHITE`、`MASK_IMAGE_BLACK`、`INIT_IMAGE_ALPHA`
</ParamField>

<ParamField body="sampler" type="string">
  Stability のサンプラー名。例: `K_DPMPP_2M`。
</ParamField>

<ParamField body="samples" type="integer">
  生成する画像の枚数。デフォルトは 1。返される画像ごとに課金されます。

  範囲: `1` から `10`
</ParamField>

<ParamField body="seed" type="integer">
  バッチ全体のシード。0 または省略時はランダムなシードが選ばれます。

  範囲: `0` から `…`
</ParamField>

<ParamField body="steps" type="integer">
  拡散ステップ数。デフォルトは 30。

  範囲: `10` から `30`
</ParamField>

<ParamField body="style_preset" type="string">
  Stability のスタイルプリセット。例: `photographic`。
</ParamField>

<ParamField body="text_prompts" type="object[]" required>
  プロンプト。それぞれに任意の重みを指定できます。負の重みを指定するとネガティブプロンプトになります。
