同じボディを `POST https://api.comfy.org/v2/models/stability/generate-ultra/requests` に送信します。Router は実行が受け付けられるとすぐに `request_id` とともに `201` を返し、結果は準備が整い次第、このプロセスからでも別のプロセスからでも回収できます。[キュー配信](/ja/development/comfy-router/queue)では、ステータス、キャンセル、回収の流れを説明しています。

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 環境変数から COMFY_API_KEY を読み取ります。
# 各 submit() 呼び出しは独自の Idempotency-Key を生成し、自動リトライで再利用します。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/generate-ultra",
            {
                "aspect_ratio": "16:9",
                "prompt": "a lighthouse on a cliff at sunset, oil painting",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # モデル ID と合わせれば、別のプロセスに必要な情報はこれだけです

        # リクエストが完了するまでポーリングし、サーバーが指定した Retry-After だけ待機します。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # プロバイダー自身のペイロードで、models.run() が返すのと同じ値です。
        # 失敗した、またはキャンセル済みのリクエストは、ここで型付きの Router エラーを発生させます。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 環境変数から COMFY_API_KEY を読み取ります。
// 各 submit() 呼び出しは独自の Idempotency-Key を生成し、自動リトライで再利用します。
const handle = await comfy.models.submit("stability/generate-ultra", {
  aspect_ratio: "16:9",
  prompt: "a lighthouse on a cliff at sunset, oil painting",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // モデル ID と合わせれば、別のプロセスに必要な情報はこれだけです

// リクエストが完了するまでポーリングし、サーバーが指定した Retry-After だけ待機します。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run() が返すのと同じ結果です。失敗した、またはキャンセル済みのリクエストはここで拒否されます。
const result = await handle.get();

console.log(result.data);
```

## スキーマ

### 入力

<ParamField body="aspect_ratio" type="string">
  テキストから画像へのみ。出力のアスペクト比。デフォルトは 1:1。

  指定可能な値: `1:1`, `16:9`, `9:16`, `21:9`, `9:21`, `3:2`, `2:3`, `5:4`, `4:5`
</ParamField>

<ParamField body="image" type="string (uri)">
  `stability/generate-ultra` のみ。ソース画像の Comfy が署名したアセット URL。これを送信すると画像から画像へ切り替わり、`strength` が必須になります。

  形式: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  画像に含めたくない要素。
</ParamField>

<ParamField body="output_format" type="string">
  `png` のみが返されます。

  指定可能な値: `png`
</ParamField>

<ParamField body="prompt" type="string" required>
  生成する内容。
</ParamField>

<ParamField body="seed" type="integer">
  0 または省略した場合はランダムなシードが選択されます。

  範囲: `0` から `4294967294`
</ParamField>

<ParamField body="strength" type="number">
  `stability/generate-ultra` の画像から画像へのみ。ソース画像からどれだけ変化させるか。1 を指定するとソース画像は無視されます。

  範囲: `0` から `1`
</ParamField>

<ParamField body="style_preset" type="string">
  Stability のスタイルプリセット。例: `photographic`。
</ParamField>

Router が `GET /v2/models/stability/generate-ultra/openapi.json` で提供するスキーマから生成されています。これは、リクエストがプロバイダーに到達する前に呼び出しを検証する際に使用するドキュメントと同じです。

### 出力

<ResponseField name="finish_reason" type="string" required>
  200 の場合は常に SUCCESS です。
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  （最初の）PNG 画像の Comfy が署名した URL。最大 24 時間有効です。

  形式: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  SDXL のみ。複数の画像が返された場合。出力順に並んだ、Comfy が署名したすべての画像URL。それぞれ最大 24 時間有効です。
</ResponseField>

<ResponseField name="seed" type="integer" required>
  画像の生成に使用されたシード。
</ResponseField>
