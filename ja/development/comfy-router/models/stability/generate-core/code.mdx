## スキーマ

### 入力

<ParamField body="aspect_ratio" type="string">
  テキストから画像へのみ。出力のアスペクト比率。デフォルトは 1:1。

  指定可能な値: `1:1`、`16:9`、`9:16`、`21:9`、`9:21`、`3:2`、`2:3`、`5:4`、`4:5`
</ParamField>

<ParamField body="image" type="string (uri)">
  `stability/generate-ultra` のみ。ソース画像の Comfy 署名付きアセットURL。これを送信すると画像から画像へ切り替わり、`strength` が必須になります。

  形式: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  画像に含めたくない要素。
</ParamField>

<ParamField body="output_format" type="string">
  返されるのは `png` のみです。

  指定可能な値: `png`
</ParamField>

<ParamField body="prompt" type="string" required>
  生成する内容。
</ParamField>

<ParamField body="seed" type="integer">
  0 または省略時はランダムなシードが選ばれます。

  範囲: `0` から `4294967294`
</ParamField>

<ParamField body="strength" type="number">
  `stability/generate-ultra` の画像から画像へのみ。ソース画像からどれだけ変化させるか。1 を指定するとソース画像は無視されます。

  範囲: `0` から `1`
</ParamField>

<ParamField body="style_preset" type="string">
  Stability のスタイルプリセット。例: `photographic`。
</ParamField>
