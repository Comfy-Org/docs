同じボディを `POST https://api.comfy.org/v2/models/meshy/meshy-7.1/requests` に送信します。Router は実行が受け付けられるとすぐに `201` と `request_id` を返し、結果は準備でき次第、このプロセスまたは別のプロセスから収集されます。[キュー配信](/ja/development/comfy-router/queue)では、ステータス、キャンセル、収集について説明します。

```python Python
from comfy_sdk import Comfy

# 環境変数から COMFY_API_KEY を読み取ります。
# 各 submit() 呼び出しは独自の Idempotency-Key を生成し、自動リトライのために再利用します。
with Comfy() as client:
    handle = client.models.submit(
        "meshy/meshy-7.1",
        {
            "art_style": "realistic",
            "mode": "preview",
            "prompt": "a red cube",
        },
    )
    print("request_id:", handle.request_id)  # モデル ID と合わせて、別のプロセスに必要な情報はこれだけです

    # リクエストが完了するまでポーリングし、サーバーが指定する Retry-After の時間待機します。
    for update in handle.iter_events():
        print(update.status, update.queue_position)

    # プロバイダー自身のペイロードであり、models.run() が返すのと同じ値です。
    # 失敗したリクエストまたはキャンセル済みのリクエストは、ここで型付きの Router エラーを発生させます。
    result = handle.get()

print(result)
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 環境変数から COMFY_API_KEY を読み取ります。
// 各 submit() 呼び出しは独自の Idempotency-Key を生成し、自動リトライのために再利用します。
const handle = await comfy.models.submit("meshy/meshy-7.1", {
  art_style: "realistic",
  mode: "preview",
  prompt: "a red cube",
});
console.log("requestId:", handle.requestId); // モデル ID と合わせて、別のプロセスに必要な情報はこれだけです

// リクエストが完了するまでポーリングし、サーバーが指定する Retry-After の時間待機します。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run() が返すのと同じ結果です。失敗したリクエストまたはキャンセル済みのリクエストは、ここで reject されます。
const result = await handle.get();

console.log(result.data);
```

import Foundation
import ComfySwiftSDK

// 環境変数から COMFY_API_KEY を読み取ります。
// 各 submit() 呼び出しは独自の Idempotency-Key を生成し、自動リトライのために再利用します。

for try await update in handle.events() {
    print(update.state.rawValue, update.queuePosition.map(String.init) ?? "unknown")

let result = try await handle.result()

## スキーマ

### 入力

#### `preview` バリアント

<ParamField body="ai_model" type="string">
  実行するMeshyモデル。Comfy Routerルートではこれはパス（`/v2/models/meshy/{model}`）から提供され、省略するか null として送信できます。Routerは検証後にパスのモデルをここに書き込みます。v1 /proxyルートではMeshyTextTo3DPreviewRequestを参照してください。これはこれをMeshyAiModelに制約します。
</ParamField>

<ParamField body="art_style" type="string" default="&quot;realistic&quot;">
  オブジェクトの希望するアートスタイルを記述します。

  指定可能な値: `realistic`、`sculpture`
</ParamField>

<ParamField body="geometry_resolution" type="string" default="&quot;standard&quot;">
  生成されるメッシュのジオメトリ解像度。2kと4kは、より細かい表面ディテールのためにUltraパスを実行します。2kには ai_model meshy-7、meshy-7.1 または latest が必要です。4kには meshy-7.1 または latest が必要です。

  指定可能な値: `standard`、`2k`、`4k`
</ParamField>

<ParamField body="is_a_t_pose" type="boolean" default="false">
  非推奨。代わりに pose_mode を使用してください。モデルをA/Tポーズで生成するかどうか。
</ParamField>

<ParamField body="mode" type="string" required>
  プレビュータスクを作成する場合、このフィールドは "preview" に設定する必要があります。

  指定可能な値: `preview`
</ParamField>

<ParamField body="moderation" type="boolean" default="false">
  true の場合、入力コンテンツは有害な可能性のあるコンテンツがないかスクリーニングされます。
</ParamField>

<ParamField body="pose_mode" type="string">
  生成されるモデルのポーズモードを指定します。

  指定可能な値: `a-pose`、`t-pose`、``
</ParamField>

<ParamField body="prompt" type="string" required>
  3Dモデルがどのようなオブジェクトであるかを記述します。最大600文字。
</ParamField>

<ParamField body="should_remesh" type="boolean" default="true">
  リメッシュフェーズを有効にするかどうかを制御します。false の場合、最も高精度な三角形メッシュを返します。
</ParamField>

<ParamField body="symmetry_mode" type="string" default="&quot;auto&quot;">
  モデル生成中の対称性の動作を制御します。

  指定可能な値: `off`、`auto`、`on`
</ParamField>

<ParamField body="target_polycount" type="integer" default="30000">
  生成されるモデルのポリゴンの目標数を指定します。有効範囲は100～300,000です。

  範囲: `100` ～ `300000`
</ParamField>

<ParamField body="topology" type="string" default="&quot;triangle&quot;">
  生成されるモデルのトポロジーを指定します。

  指定可能な値: `quad`、`triangle`
</ParamField>

<ParamField body="ultra_mode" type="boolean" default="false">
  非推奨。代わりに geometry_resolution を使用してください。true は geometry_resolution 2k と同等です。ai_model が meshy-7、meshy-7.1 または latest の場合にのみサポートされます。
</ParamField>

#### `refine` バリアント

<ParamField body="ai_model" type="string">
  実行するMeshyモデル。Comfy Routerルートではこれはパス（`/v2/models/meshy/{model}`）から提供され、省略するか null として送信できます。Routerは検証後にパスのモデルをここに書き込みます。v1 /proxyルートではMeshyTextTo3DRefineRequestを参照してください。これはこれをMeshyAiModelに制約します。
</ParamField>

<ParamField body="enable_pbr" type="boolean" default="false">
  ベースカラーに加えてPBRマップ（metallic、roughness、normal）を生成します。Sculptureスタイルを使用する場合は enable_pbr を false に設定する必要があることに注意してください。
</ParamField>

<ParamField body="mode" type="string" required>
  リファインタスクを作成する場合、このフィールドは "refine" に設定する必要があります。

  指定可能な値: `refine`
</ParamField>

<ParamField body="moderation" type="boolean" default="false">
  true の場合、入力コンテンツは有害な可能性のあるコンテンツがないかスクリーニングされます。
</ParamField>

<ParamField body="preview_task_id" type="string" required>
  対応するプレビュータスクID。指定したプレビュータスクのステータスは SUCCEEDED である必要があります。
</ParamField>

<ParamField body="texture_image_url" type="string">
  テクスチャリング処理をガイドする2D画像を提供します。.jpg、.jpeg、.png 形式、または base64 エンコードされたデータURIをサポートします。
</ParamField>

<ParamField body="texture_prompt" type="string">
  テクスチャリング処理をガイドする追加のテキストプロンプトを提供します。最大600文字。
</ParamField>

<ParamField body="texture_resolution" type="string" default="&quot;2k&quot;">
  生成されるテクスチャのテクスチャ解像度。2k、4k、8k のいずれかです。4k と 8k には ai_model meshy-6、meshy-7、meshy-7.1 または latest が必要です。

  指定可能な値: `2k`、`4k`、`8k`
</ParamField>

`GET /v2/models/meshy/meshy-7.1/openapi.json` で Router が提供するスキーマから生成されています。これは、リクエストがプロバイダーに到達する前に Router が呼び出しを検証する対象となる、同じドキュメントです。
