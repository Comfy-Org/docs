同じ本文を `POST https://api.comfy.org/v2/models/pika/pika-h3-flex-image-to-video/requests` に送信します。Router は実行が受け付けられるとすぐに `request_id` とともに `201` を返し、結果は準備ができ次第、このプロセスまたは別のプロセスから収集します。[キューの配信](/ja/development/comfy-router/queue)では、ステータス、キャンセル、収集の流れを説明します。

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 環境変数から COMFY_API_KEY を読み取ります。
# 各 submit() 呼び出しは独自の Idempotency-Key を発行し、自動リトライで再利用します。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "pika/pika-h3-flex-image-to-video",
            {
                "duration": 5,
                "image": "https://example.invalid/pika/first-frame.png",
                "prompt": "The camera slowly pushes in as the leaves begin to sway in the wind",
                "resolution": "480p",
            },
        )
        print("request_id:", handle.request_id)  # モデル ID と合わせて、別のプロセスが必要とするすべての情報

        # リクエストが完了するまでポーリングし、サーバーが指定する Retry-After だけ待機します。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # プロバイダー自身のペイロードで、models.run() が返すのと同じ値です。
        # 失敗またはキャンセル済みのリクエストは、ここで型付きの Router エラーを発生させます。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 環境変数から COMFY_API_KEY を読み取ります。
// 各 submit() 呼び出しは独自の Idempotency-Key を発行し、自動リトライで再利用します。
const handle = await comfy.models.submit("pika/pika-h3-flex-image-to-video", {
  duration: 5,
  image: "https://example.invalid/pika/first-frame.png",
  prompt: "The camera slowly pushes in as the leaves begin to sway in the wind",
  resolution: "480p",
});
console.log("requestId:", handle.requestId); // モデル ID と合わせて、別のプロセスが必要とするすべての情報

// リクエストが完了するまでポーリングし、サーバーが指定する Retry-After だけ待機します。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run() が返すのと同じ結果です。失敗またはキャンセル済みのリクエストは、ここで拒否されます。
const result = await handle.get();

console.log(result.data);
```

## スキーマ

### 入力

<ParamField body="aspect_ratio" type="string">
  出力のアスペクト比。`auto` はプロンプトとメディア入力から1つを選びます。省略すると Pika が選択します。`rewrite` がオンの場合は `auto`、そうでなければ最初のメディア入力の比率、それもなければ 16:9 になります。

  可能な値: `auto`、`21:9`、`16:9`、`3:2`、`4:3`、`5:4`、`1:1`、`4:5`、`3:4`、`2:3`、`9:16`、`9:21`
</ParamField>

<ParamField body="channel_mode" type="string" default="&quot;mono&quot;">
  オーディオステム専用。`mono` は分離前にダウンミックスします。`stereo` は両方のチャンネルを保持します。ビデオのオーディオは変わりません。

  可能な値: `stereo`、`mono`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  ビデオの長さ（整数秒）、5〜15。

  範囲: `5` 〜 `15`
</ParamField>

<ParamField body="image" type="string">
  先頭フレーム画像の URL。静的な JPEG、PNG、WebP で、最大 24 MiB、4000万ピクセルまでです。
</ParamField>

<ParamField body="last_frame_image" type="string">
  最終フレーム画像の URL。フォーマットとサイズ制限は `image` と同じです。
</ParamField>

<ParamField body="output_mode" type="string" default="&quot;video&quot;">
  `video` はビデオのみを返します。`audio-stems` はさらに Dialogue、Music、Effect の WAV ステムを `output.stems` に返し、Pika の秒単位のステム分離料金が加算されます。

  可能な値: `video`、`audio-stems`
</ParamField>

<ParamField body="prompt" type="string" required>
  ビデオとそのオーディオを説明するテキストプロンプト。
</ParamField>

<ParamField body="resolution" type="string" default="&quot;768p&quot;">
  出力解像度。480p と 768p はネイティブです。1080p、2k、4k は 768p で生成してからアップスケールし、オーディオとフレームレートは維持します。

  可能な値: `480p`、`768p`、`1080p`、`2k`、`4k`
</ParamField>

<ParamField body="rewrite" type="boolean" default="true">
  生成前にプロンプトを改善します。false にすると、書かれたままのプロンプトを使用します。
</ParamField>

<ParamField body="seed" type="integer" default="0">
  ビデオのシード。0 以上。

  範囲: `0` 〜 `…`

  フォーマット: `int64`
</ParamField>
