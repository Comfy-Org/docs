### 入力

<ParamField body="aspect_ratio" type="string">
  出力のアスペクト比。`auto` はプロンプトとメディア入力から1つを選びます。省略するとPikaが選択します。`rewrite` がオンの場合は `auto`、そうでなければ最初のメディア入力の比率、それもなければ 16:9 になります。

  指定可能な値: `auto`, `21:9`, `16:9`, `3:2`, `4:3`, `5:4`, `1:1`, `4:5`, `3:4`, `2:3`, `9:16`, `9:21`
</ParamField>

<ParamField body="channel_mode" type="string" default="&quot;mono&quot;">
  オーディオステム専用。`mono` は分離前にダウンミックスします。`stereo` は両方のチャンネルを保持します。ビデオのオーディオは変化しません。

  指定可能な値: `stereo`, `mono`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  ビデオの長さ（整数秒）。5〜15。

  範囲: `5` 〜 `15`
</ParamField>

<ParamField body="output_mode" type="string" default="&quot;video&quot;">
  `video` はビデオのみを返します。`audio-stems` は Dialogue、Music、Effect のWAVステムを `output.stems` に追加で返し、Pikaの秒単位のステム分離料金が加算されます。

  指定可能な値: `video`, `audio-stems`
</ParamField>

<ParamField body="prompt" type="string" required>
  ビデオとそのオーディオを説明するテキストプロンプト。
</ParamField>

<ParamField body="references" type="object[]" required>
  順序付きの参照メディア。画像は最大9件、ビデオは最大3件、オーディオファイルは最大3件、合計12件までです。少なくとも1つの画像またはビデオが必須です。各ファイルは最大24 MiBです。ビデオとオーディオのクリップは2〜15秒で、種類ごとに合計15秒までです。Pikaは出力秒数に加えて参照ビデオの秒数も課金します。
</ParamField>

<ParamField body="references[].type" type="string" required>
  ファイルのメディア種別。

  指定可能な値: `image`, `video`, `audio`
</ParamField>

<ParamField body="references[].url" type="string" required>
  参照ファイルのURL。画像はPNG、JPEG、WebPです。
</ParamField>

<ParamField body="resolution" type="string" default="&quot;768p&quot;">
  出力解像度。480pと768pはネイティブです。1080p、2k、4kは768pで生成してからアップスケールし、オーディオとフレームレートを維持します。

  指定可能な値: `480p`, `768p`, `1080p`, `2k`, `4k`
</ParamField>

<ParamField body="rewrite" type="boolean" default="true">
  生成前にプロンプトを改善します。false に設定すると、記述どおりのプロンプトが使用されます。
</ParamField>

<ParamField body="seed" type="integer" default="0">
  ビデオのシード。0以上。

  範囲: `0` 〜 `…`

  形式: `int64`
</ParamField>
