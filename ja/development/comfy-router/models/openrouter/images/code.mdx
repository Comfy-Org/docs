`openrouter/images` の API リファレンスです。Comfy Router が Openrouter から提供します。

**入力:** テキスト、画像 · **出力:** 画像

## リクエストの設定

[Comfy ワークスペース](https://platform.comfy.org/profile/api-keys?onboarding=router)でキーを作成し、`COMFY_API_KEY` としてエクスポートします。Python の場合は `pip install comfy-sdk` を実行します。TypeScript の場合は `npm install @comfyorg/sdk` を実行します。cURL は生の HTTP を使用します。

**モデル ID:** `openrouter/images`

**エンドポイント:** `POST https://api.comfy.org/v2/models/openrouter/images`

<Note>
このモデルには実行可能なリクエスト例がありません。以下の入力ドキュメントに従ってリクエストボディを構築し、[Router クイックスタート](/ja/development/comfy-router/quickstart)で使用してください。
</Note>
