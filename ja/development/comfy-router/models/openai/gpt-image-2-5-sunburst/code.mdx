モデルが公開している例はこのフィールドを省略した生成呼び出しです。`image` を追加することが 2 つのモードの違いのすべてです。同じエンドポイント、同じモデル id ですが、編集プロンプトはシーンではなく望む変更を記述するため、構造的に新しいのはこのフィールドだけであるにもかかわらず、以下の編集ボディは生成例とは異なる読み方になります。
これは印刷されているとおりにそのままコピーできます: `{"prompt": "give the rocketship rainbow coloring", "image": ["data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg=="], "size": "1024x1024"}`。ペイロードは省略形ではなく完全な 1x1 PNG であり、このボディは Router 自身のリクエスト検証テストで受け入れられるケースとしてピン留めされています。ご自身の画像のバイト列に置き換えてください。
1 つの画像またはその配列を受け付けます。gpt-image-1 以降は最大 16 枚を受け取り、Router はディスパッチ前にこのスキーマからそれを強制します。
</ParamField>

<ParamField body="mask" type="string">
  1 つの画像を、Router が呼び出し元に代わって取得する https URL、またはバイト列をインラインで含む `data:image/<format>;base64,<payload>` URI のいずれかで指定します。受け付ける画像タイプは png、webp、jpeg で、そのセットはプロバイダーに任されるのではなく解決時に強制されます。svg、gif、avif、tiff はここで拒否され、送信した画像を名指しします。原因から 2 ホップ離れたパートナーエラーになることはありません。
URL 形式を優先してください。base64 ペイロードはおよそ 4/3 に膨らみ、リクエストボディ全体は 100 MiB に制限されるため、インライン形式では約 75 MB のソース画像が上限になります。URL はそれを完全に回避します。この説明の最後に示す画像ごとおよびリクエストごとのメディア上限はボディ上限よりも厳しいため、実際のサイズの画像では先にそれに達します。
URL は認証情報なしで解決できる必要があります。Router はサーバー側で取得し、呼び出し元の認証情報をリクエストに付けません。そのため、署名がクエリ文字列にある presigned URL がサポートされる形式です。`/api/assets/{id}/content` のような認証済みエンドポイントは、画像ではなく Router に 401 を返します。その URL をご自身でリクエストし、リダイレクト先の署名済み URL を渡してください。
取得はオープンなインターネットではなく、名前付きのホストセットに限定され、同じリストが送信した URL だけでなくすべてのリダイレクトホップにも再適用されます。そのため、他のホストの URL、またはリスト外へリダイレクトする URL は、プロバイダーに接触する前に拒否されます。現在、そのリストは Comfy 自身のアセット配信のみです。Comfy のアセットバケット配下の署名済み `storage.googleapis.com` URL で、これは `/api/assets/{id}/content` がリダイレクトする形式です。パートナー CDN や通常の https ホストはリストにありません。
2 つの拡張が展開中で、現在はどちらもデフォルトで無効です。それらは 1 つの切り替えの背後で提供され、一緒に有効になります。そのため、以下はまだ構築対象とするものではなく今後のものとして扱ってください。どちらかに依存する前に確認してください。
1 つ目は `POST /customers/storage` がアップロード先として署名するバケットです。展開がお使いの環境に届くまで、そのエンドポイントからのアップロード URL はここで拒否されます。バケットは Comfy 自身のものでホストも同じであってもです。したがって「Comfy にアップロードしてから URL を渡す」はまだ機能せず、機能する形式は `/api/assets/{id}/content` がリダイレクトする署名済み URL です。
2 つ目は全員に一度にではなくアカウントごとに有効になります。これらのホストの背後にあるバケットは当社のものではなくお客様のものであるためです。上記の切り替えがオンになっても、サードパーティの受信メディアが有効化されていないアカウントは拒否され、ホストがサポートされていないというのではなくその旨を伝えられます。Comfy の担当者にアカウントで有効化するよう依頼してください。さらに次のサードパーティのオブジェクトストレージホストを許可します。バケットはお客様のものであり、Router は所有権を主張しません: Cloudflare R2 (`<account>.r2.cloudflarestorage.com`、`<id>.r2.dev`)、Amazon S3 (`s3.amazonaws.com` および `s3.<region>.amazonaws.com`、path-style または `<bucket>.` 接頭辞形式のいずれか)、Azure Blob Storage (`<account>.blob.core.windows.net`)、Alibaba Cloud OSS (`<bucket>.oss-<region>.aliyuncs.com`、`oss-accelerate` エンドポイントを含む)。これらは特にオブジェクトストレージのエンドポイントです。同じプロバイダードメイン上の汎用エンドポイント、たとえば Alibaba Function Compute トリガーはリストに含まれず、拒否されます。
以下の例は形状のみを示しています。実際の値には署名クエリパラメータも含まれますが、公開された例は仕様に永久に残り、実際の署名は漏えいした認証情報であると同時に、機能しなくなるリンクでもあるため、ここでは意図的に省略しています。
各画像は 25 MiB に制限され、1 リクエストの画像は合計 64 MiB に制限されます。
