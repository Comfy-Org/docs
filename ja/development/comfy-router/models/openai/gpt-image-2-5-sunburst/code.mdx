<ParamField body="image" type="string | string[]">
  編集対象のソース画像。このフィールドの有無が編集操作を選択します。テキストから画像への生成では完全に省略してください。
モデルの公開されている例は、このフィールドを省略する生成呼び出しです。`image` を追加することが2つのモードの違いのすべてです（同じエンドポイント、同じモデル id）。ただし編集プロンプトはシーンではなく、望む変更を記述するため、構造的に新しいのはこのフィールドだけであるにもかかわらず、以下の編集ボディは生成の例とは異なって読めます。
記載どおりにそのままコピーできます: `{"prompt": "give the rocketship rainbow coloring", "image": ["data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg=="], "size": "1024x1024"}`。ペイロードは省略形ではなく完全な 1x1 PNG であり、このボディは Router 自身のリクエスト検証テストで受理されるケースとしてピン留めされています。ご自身の画像のバイト列に差し替えてください。
1枚の画像、またはその配列を受け付けます。gpt-image-1 以降は最大16枚で、Router はディスパッチ前にこのスキーマからそれを強制します。
</ParamField>

<ParamField body="mask" type="string">
  1枚の画像で、呼び出し元に代わって Router が取得する https URL、またはバイト列をインラインで運ぶ `data:image/<format>;base64,<payload>` URI のいずれかです。受け入れられる画像タイプは png、webp、jpeg で、このセットはプロバイダーに委ねるのではなく解決時に強制されます。svg、gif、avif、tiff は、原因から2ホップ離れたパートナーエラーになる代わりに、ここで拒否され、送信した画像を名指しします。
URL 形式を推奨します。base64 ペイロードはおよそ 4/3 に膨張し、リクエストボディ全体は 20 MiB に制限されるため、インライン形式の上限はソース画像約 15 MB になります。URL はこれを完全に回避します。
URL はお客様の認証情報なしで解決できなければなりません。Router はサーバー側で取得し、リクエストに呼び出し元の認証情報を一切付けません。そのため、署名がクエリ文字列に含まれる presigned URL がサポートされる形式です。`/api/assets/{id}/content` のような認証付きエンドポイントは、画像ではなく 401 を Router に返します。その URL をご自身でリクエストし、リダイレクト先の署名付き URL を渡してください。
取得はオープンなインターネットではなく、名前を挙げたホストの集合に限定され、同じリストが、送信する URL だけでなくすべてのリダイレクトホップにも再適用されます。そのため、それ以外のホストの URL、またはリスト外へリダイレクトする URL は、プロバイダーに接触する前に拒否されます。現在このリストは Comfy 自身のアセット配信のみです。Comfy のアセットバケット配下の署名付き `storage.googleapis.com` URL で、これが `/api/assets/{id}/content` のリダイレクト先の形式です。パートナー CDN や通常の https ホストはリストに含まれません。
2つの拡張がロールアウト中で、どちらも本日時点ではデフォルトで無効です。1つの切り替えの背後で提供され、同時に有効化されます。そのため以下はすべて、まだ依存して構築するものではなく、今後の提供予定として扱ってください。どちらかに依存する前に確認してください。
1つ目は、`POST /customers/storage` がアップロード先として署名するバケットです。ロールアウトがお使いの環境に届くまで、そのエンドポイントからのアップロード URL はここで拒否されます。バケットは Comfy 自身のものでホストも同じであってもです。つまり「Comfy にアップロードしてから URL を渡す」はまだ機能せず、機能するのは `/api/assets/{id}/content` がリダイレクトする署名付き URL の形式です。
2つ目は、さらに以下のサードパーティのオブジェクトストレージホストを許可します。そこではバケットはお客様のものであり、Router はその所有権を主張しません。Cloudflare R2（`<account>.r2.cloudflarestorage.com`、`<id>.r2.dev`）、Amazon S3（`s3.amazonaws.com` および `s3.<region>.amazonaws.com`、path-style 形式または `<bucket>.` プレフィックス形式のいずれか）、Azure Blob Storage（`<account>.blob.core.windows.net`）、Alibaba Cloud OSS（`<bucket>.oss-<region>.aliyuncs.com`、`oss-accelerate` エンドポイントを含む）。これらは特にオブジェクトストレージのエンドポイントです。同じプロバイダードメイン上の汎用エンドポイント、たとえば Alibaba Function Compute のトリガーは、リストに含まれず拒否されます。
以下の例は形状のみを示しています。実際の値は署名クエリパラメータも伴いますが、公開された例は仕様に永遠に残り、実際の署名は漏洩した認証情報であると同時に機能しなくなるリンクでもあるため、ここでは意図的に省略しています。
各画像は 25 MiB、1リクエストの画像は合計 64 MiB が上限です。
