<ParamField body="mask" type="string">
  1枚の画像。呼び出し元の代わりに Router が取得する https URL、またはバイトをインラインで含む `data:image/<format>;base64,<payload>` URI のいずれかの形式です。受け入れられる画像タイプは png、webp、jpeg で、このセットはプロバイダーに任されるのではなく解決時に強制されます。svg、gif、avif、tiff はここで拒否され、送信した画像を名指しするため、原因から2ホップ離れたパートナーエラーにはなりません。
URL 形式を推奨します。base64 ペイロードは約 4/3 に膨張し、リクエストボディ全体は 10 MiB に制限されるため、インライン形式ではソース画像が約 7.5 MB で上限に達します。URL ならこれを完全に回避できます。
URL はあなたの資格情報なしで解決できなければなりません。Router はサーバーサイドでこれを取得し、リクエストに呼び出し元の資格情報を一切送信しません。そのため、署名がクエリ文字列に含まれる Comfy 署名済みアセット URL がサポートされる形式です。`/api/assets/{id}/content` のような認証済みエンドポイントは、画像ではなく 401 を Router に返します。その URL はご自身でリクエストし、リダイレクト先の署名済み URL を渡してください。取得はオープンインターネットではなく Comfy 自身のアセットバケットに限定され、送信した URL だけでなくすべてのリダイレクトホップにも適用されるため、サードパーティの URL やリダイレクトする URL は拒否されます。
以下の例は形状のみを示しています。実際の値には署名用のクエリパラメータも含まれますが、公開された例は仕様に永久に残るため、また実際の署名は漏洩した資格情報であると同時に機能しなくなるリンクでもあるため、ここでは意図的に省略しています。
各画像は 25 MiB、1リクエストの画像は合計 64 MiB に制限されています。
