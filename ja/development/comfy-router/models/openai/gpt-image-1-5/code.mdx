モデルが公開している例はこのフィールドを省略した生成呼び出しです。`image` を追加することが 2 つのモードの違いのすべてです（同じエンドポイント、同じモデル ID）。ただし編集用のプロンプトはシーンではなく、望む「変更」を記述するため、以下の編集ボディは、構造的に新しいのがこのフィールドだけであるにもかかわらず、生成の例とは異なって読めます。
これは記載どおりにそのままコピーできます: `{"prompt": "give the rocketship rainbow coloring", "image": ["data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg=="], "size": "1024x1024"}` ペイロードは省略形ではなく完全な 1x1 PNG で、このボディは Router 自身のリクエスト検証テストで受け入れられるケースとしてピン留めされています。ご自身の画像のバイト列に差し替えてください。
1 枚の画像またはその配列を受け付けます。gpt-image-1 以降は最大 16 枚で、Router はディスパッチ前にこのスキーマに基づいてそれを強制します。
</ParamField>

<ParamField body="mask" type="string">
  1 枚の画像を、Router が呼び出し元に代わって取得する https URL、またはバイト列をインラインで含む `data:image/<format>;base64,<payload>` URI のいずれかの形式で指定します。受け入れられる画像形式は png、webp、jpeg で、このセットはプロバイダーに任されるのではなく解決時に強制されます。svg、gif、avif、tiff はここで拒否され、送信した画像を名指しするため、原因から 2 ホップ離れたパートナーエラーにはなりません。
URL 形式を推奨します。base64 ペイロードはおよそ 4/3 に膨らみ、リクエストボディ全体は 20 MiB に制限されるため、インライン形式では約 15 MB のソース画像が上限になります。URL ならこれを完全に回避できます。
URL は認証情報なしで解決できる必要があります。Router はサーバー側でそれを取得し、リクエストに呼び出し元の認証情報を付けません。そのため、クエリ文字列に署名が含まれる形式の署名付き URL がサポートされる形式です。`/api/assets/{id}/content` のような認証が必要なエンドポイントは、画像ではなく 401 を Router に返します。その URL はご自身でリクエストし、リダイレクト先の署名付き URL を渡してください。
取得は開かれたインターネットではなく、名前を指定されたホストの集合に限定されます。同じリストは、送信した URL だけでなくすべてのリダイレクトホップにも再適用されます。そのため、他のホスト上の URL や、リスト外へリダイレクトする URL は、プロバイダーに接続される前に拒否されます。現在このリストは Comfy 自身のアセット配信のみです。Comfy のアセットバケット配下の署名付き `storage.googleapis.com` URL で、これが `/api/assets/{id}/content` がリダイレクトする形式です。パートナーの CDN や通常の https ホストはリストに含まれません。
2 つの拡張が展開中で、どちらも現在はデフォルトで無効です。これらは 1 つの切り替えの背後で提供され、同時に有効化されます。そのため、以下はすべて今後登場するものとして扱い、まだ依存して構築する対象とは考えないでください。どちらかに依存する前に確認してください。
1 つ目は、`POST /customers/storage` がアップロード先として署名するバケットです。展開がお使いの環境に到達するまで、そのエンドポイントからのアップロード URL はここで拒否されます。バケットは Comfy 自身のものでホストも同じであるにもかかわらずです。したがって「Comfy にアップロードしてから URL を渡す」方法はまだ機能せず、機能する形式は `/api/assets/{id}/content` がリダイレクトする署名付き URL です。
2 つ目は、さらに以下のサードパーティのオブジェクトストレージホストを許可します。ここではバケットはお客様のものであり、Router はその所有権を主張しません: Cloudflare R2（`<account>.r2.cloudflarestorage.com`、`<id>.r2.dev`）、Amazon S3（`s3.amazonaws.com` および `s3.<region>.amazonaws.com`、パス形式または `<bucket>.` 接頭辞形式のいずれか）、Azure Blob Storage（`<account>.blob.core.windows.net`）、Alibaba Cloud OSS（`<bucket>.oss-<region>.aliyuncs.com`、`oss-accelerate` エンドポイントを含む）。これらは特にオブジェクトストレージのエンドポイントです。同じプロバイダードメイン上の汎用エンドポイント、例えば Alibaba Function Compute のトリガーは、リストに含まれず拒否されます。
以下の例は形状のみを示しています。実際の値には署名のクエリパラメータも含まれますが、公開された例は仕様の中に永遠に残り、実際の署名は漏洩した認証情報であると同時に機能しなくなるリンクでもあるため、ここでは意図的に省略しています。
各画像は 25 MiB、1 つのリクエストの画像は合計 64 MiB が上限です。
