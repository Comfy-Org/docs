<ParamField body="mask" type="string">
  1 つの画像で、呼び出し元に代わって Router が取得する https URL、またはバイト列をインラインで含む `data:image/<format>;base64,<payload>` URI のいずれかです。受け入れられる画像タイプは png、webp、jpeg で、このセットはプロバイダーに任されるのではなく解決時に強制されます。svg、gif、avif、tiff はここで拒否され、送信した画像が名指しされます。原因から 2 ホップ離れたパートナーエラーになることはありません。
URL 形式を推奨します。base64 ペイロードはおよそ 4/3 に膨張し、リクエストボディ全体は 100 MiB に制限されるため、インライン形式は約 75 MB のソース画像で上限に達します。URL ならこれを完全に回避できます。この説明の最後に記載されている画像ごとおよびリクエストごとのメディア上限はボディ上限より厳しいため、実際のサイズの画像ではまずそちらに達します。
URL は認証情報なしで解決できる必要があります。Router はサーバー側で取得し、リクエストに呼び出し元の認証情報を付けません。そのため、署名がクエリ文字列に含まれる署名付き URL がサポートされる形式です。`/api/assets/{id}/content` のような認証が必要なエンドポイントは、画像ではなく Router に 401 を返します。その URL をご自身でリクエストし、リダイレクト先の署名付き URL を渡してください。
取得はオープンなインターネットではなく、名前を挙げたホストの集合に限定されます。同じリストは、送信した URL だけでなくすべてのリダイレクトホップにも再適用されます。そのため、他のホスト上の URL、またはリスト外へリダイレクトする URL は、プロバイダーに接続する前に拒否されます。現在このリストは Comfy 自身のアセット配信のみです。Comfy のアセットバケット配下の署名付き `storage.googleapis.com` URL で、これは `/api/assets/{id}/content` がリダイレクトする形式です。パートナー CDN や通常の https ホストはリストに含まれません。
2 つの拡張が展開中で、どちらも現在デフォルトでは無効です。それらは 1 つの切り替えの背後で提供され、一緒に有効になります。そのため、以下はすべてまだこれから提供されるものとして扱い、まだ依存して構築する対象とはしないでください。どちらかに依存する前に確認してください。
1 つ目は、`POST /customers/storage` がアップロード先として署名するバケットです。展開がお使いの環境に到達するまで、そのエンドポイントからのアップロード URL はここで拒否されます。バケットは Comfy 自身のものでホストも同じであるにもかかわらずです。そのため「Comfy にアップロードしてから URL を渡す」はまだ機能せず、機能するのは `/api/assets/{id}/content` がリダイレクトする署名付き URL の形式です。
2 つ目は、全員に対して一度にではなくアカウントごとに有効化されます。これらのホストの背後にあるバケットが当社ではなくお客様のものであるためです。上記の切り替えがオンになっても、サードパーティの受信メディアが有効化されていないアカウントは拒否され、ホストがサポートされていないと告げられるのではなく、その旨の文言で通知されます。お使いのアカウントで有効化するよう Comfy の担当者に依頼してください。これにより、さらに以下のサードパーティのオブジェクトストレージホストが許可されます。バケットはお客様のものであり、Router はそれに対する所有権を主張しません: Cloudflare R2 (`<account>.r2.cloudflarestorage.com`、`<id>.r2.dev`)、Amazon S3 (パス形式または `<bucket>.` プレフィックス形式のいずれかで、`s3.amazonaws.com` および `s3.<region>.amazonaws.com`)、Azure Blob Storage (`<account>.blob.core.windows.net`)、Alibaba Cloud OSS (`oss-accelerate` エンドポイントを含む `<bucket>.oss-<region>.aliyuncs.com`)。これらは特にオブジェクトストレージのエンドポイントです。同じプロバイダードメイン上の汎用エンドポイント、たとえば Alibaba Function Compute のトリガーはリストに含まれず、拒否されます。
