## スキーマ

### 入力

<ParamField body="background" type="string">
  背景の透明度

  取り得る値: `transparent`、`opaque`

<ParamField body="image" type="string | string[]">
  編集するソース画像。このフィールドが存在すること自体が編集操作を選択します。テキストから画像を生成する場合は、このフィールドを完全に省略してください。
モデルの公開例はこのフィールドを省略した生成呼び出しです。`image` を追加することが2つのモードの違いのすべてであり、エンドポイントもモデル id も同じです。ただし編集プロンプトはシーンではなく、加えたい変更を記述するため、構造的に新しいのはこのフィールドだけであるにもかかわらず、下記の編集ボディは生成の例とは違った読み方になります。
これは記載どおりにそのままコピーできます: `{"prompt": "give the rocketship rainbow coloring", "image": ["data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg=="], "size": "1024x1024"}`。ペイロードは省略形ではなく完全な 1x1 PNG であり、このボディは Router 自身のリクエスト検証テストで受理されるケースとしてピン留めされています。ご自身の画像のバイト列に差し替えてください。
1枚の画像、またはその配列を受け付けます。gpt-image-1 以降は最大 16 枚で、Router はディスパッチ前にこのスキーマに基づいてそれを強制します。
</ParamField>

<ParamField body="mask" type="string">
  1枚の画像。Router が呼び出し元に代わって取得する https URL、またはバイト列をインラインで含む `data:image/<format>;base64,<payload>` URI のいずれかです。受け付ける画像タイプは png、webp、jpeg で、このセットはプロバイダーに任されるのではなく解決時に強制されます。svg、gif、avif、tiff はここで拒否され、送信した画像を名指しするため、原因から2ホップ離れたパートナーエラーにはなりません。
URL 形式を推奨します。base64 ペイロードは約 4/3 に膨張し、リクエストボディ全体は 20 MiB に制限されるため、インライン形式ではソース画像が約 15 MB で上限に達します。URL ならこれを完全に回避できます。
URL は認証情報なしで解決できる必要があります。Router はそれをサーバー側で取得し、リクエストに呼び出し元の認証情報を付けません。そのため、クエリ文字列に署名が含まれる presigned URL がサポートされる形式です。`/api/assets/{id}/content` のような認証が必要なエンドポイントは、画像ではなく 401 を Router に返します。その URL を自分でリクエストし、リダイレクト先の署名付き URL を渡してください。
取得は開かれたインターネットではなく、名前を挙げたホストの集合に限定され、同じリストが送信した URL だけでなくすべてのリダイレクトホップにも再適用されます。したがって、それ以外のホストの URL、またはリスト外へリダイレクトする URL は、どのプロバイダーにも接触する前に拒否されます。現在このリストは Comfy 自身のアセット配信のみです。Comfy のアセットバケット配下の署名付き `storage.googleapis.com` URL で、これが `/api/assets/{id}/content` のリダイレクト先となる形式です。パートナー CDN や通常の https ホストはリストにありません。
2つの拡張がロールアウト中で、いずれも本日時点ではデフォルトで無効です。これらは1つの切り替えの背後で提供され、まとめて有効化されます。したがって、以下はすべてまだ依存対象として構築するものではなく、今後のものとして扱ってください。どちらかに依存する前に確認してください。
1つ目は `POST /customers/storage` がアップロード先として署名するバケットです。ロールアウトがお使いの環境に到達するまで、そのエンドポイントからのアップロード URL はここで拒否されます。たとえバケットが Comfy 自身のものでホストも同じであってもです。つまり「Comfy にアップロードしてから URL を渡す」はまだ動作せず、動作する形式は署名付き URL、すなわち `/api/assets/{id}/content` がリダイレクトする先です。
2つ目は、さらに以下のサードパーティのオブジェクトストレージホストを許可します。そこではバケットはあなたのもので、Router はその所有権を主張しません: Cloudflare R2 (`<account>.r2.cloudflarestorage.com`、`<id>.r2.dev`)、Amazon S3 (`s3.amazonaws.com` および `s3.<region>.amazonaws.com`、path-style または `<bucket>.` を前置する形式のいずれか)、Azure Blob Storage (`<account>.blob.core.windows.net`)、Alibaba Cloud OSS (`<bucket>.oss-<region>.aliyuncs.com`、`oss-accelerate` エンドポイントを含む)。これらは特にオブジェクトストレージのエンドポイントです。同じプロバイダードメイン上の汎用エンドポイント、たとえば Alibaba Function Compute のトリガーはリストになく、拒否されます。
以下の例は形状のみを示しています。実際の値には署名のクエリパラメータも含まれますが、ここでは意図的に省略しています。公開された例はスペックに永遠に残り、実際の署名は漏洩した認証情報であると同時に機能しなくなるリンクでもあるためです。
各画像は 25 MiB、1リクエストの画像は合計 64 MiB が上限です。
