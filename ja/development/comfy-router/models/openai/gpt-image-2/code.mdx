URL は認証情報なしで解決できなければなりません。Router はサーバー側でこれを取得し、リクエストに呼び出し元の認証情報を付けません。そのため、署名がクエリ文字列に含まれる presigned URL がサポートされる形式です。`/api/assets/{id}/content` のような認証が必要なエンドポイントは、画像ではなく Router に 401 を返します。その URL をご自身でリクエストし、リダイレクト先の署名付き URL を渡してください。
フェッチはオープンなインターネットではなく、名前を挙げたホストの集合に限定され、同じリストは、送信する URL だけでなくすべてのリダイレクトホップにも再適用されます。したがって、それ以外のホストの URL、あるいはリスト外へリダイレクトする URL は、プロバイダーに接続する前に拒否されます。現在、このリストは Comfy 自身のアセット配信のみです。Comfy のアセットバケット配下の署名付き `storage.googleapis.com` URL で、これは `/api/assets/{id}/content` がリダイレクトする形式です。パートナー CDN や通常の https ホストはリストにありません。
