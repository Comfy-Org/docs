Comfy Router はすべてのモデルを単一のルート `POST /v2/models/{provider}/{model}` で配信します。そのうち一部のモデルは複数のプロバイダーから配信でき、`model_provider` クエリパラメーターでどちらが呼び出しを実行するかを選択します。モデル ID、リクエストボディ、レスポンスの形状は変わりません。詳細は API リファレンスの [`model_provider`、`strict_mode`、`fallback_provider`](/ja/development/comfy-router/reference#post-v2modelsprovidermodel) を参照してください。

## Comfy（直接）

[モデルカタログ](/ja/development/comfy-router/models) のすべてのモデルは Comfy Router によって直接配信されます。これは `model_provider` を指定しない呼び出しで使われるものであり、以下に記載のないすべてのモデルにとって唯一のルートです。

## fal

- [Dreamina Seedance 2.0 260128](/ja/development/comfy-router/models/byteplus/dreamina-seedance-2-0-260128/code): `byteplus/dreamina-seedance-2-0-260128`、`?model_provider=fal` を指定すると `fal/fal-seedance-2.0` として配信されます
- [Dreamina Seedance 2.5 260628](/ja/development/comfy-router/models/byteplus/dreamina-seedance-2-5-260628/code): `byteplus/dreamina-seedance-2-5-260628`、`?model_provider=fal` を指定すると `fal/fal-seedance-2.5` として配信されます
- [Nano Banana 2](/ja/development/comfy-router/models/google/nano-banana-2/code): `vertexai/gemini-3.1-flash-image`、`?model_provider=fal` を指定すると `fal/fal-nano-banana-2` として配信されます
- [Nano Banana Pro](/ja/development/comfy-router/models/google/nano-banana-pro/code): `vertexai/gemini-3-pro-image`、`?model_provider=fal` を指定すると `fal/fal-nano-banana-pro` として配信されます
- [GPT Image 2](/ja/development/comfy-router/models/openai/gpt-image-2/code): `openai/gpt-image-2`、`?model_provider=fal` を指定すると `fal/fal-gpt-image-2` として配信されます

## WaveSpeed

- [Nano Banana Pro](/ja/development/comfy-router/models/google/nano-banana-pro/code): `vertexai/gemini-3-pro-image`、`?model_provider=wavespeed` を指定すると `wavespeed/wavespeed-nano-banana-pro` として配信されます

`strict_mode` のデフォルトは false のため、ネイティブモデルのスキーマに沿って書かれたリクエストは代替プロバイダー独自のスキーマに変換され、レスポンスは元のスキーマに変換し直されます。そのプロバイダーで表現できないネイティブのフィールドは破棄され、`X-Comfy-Router-Dropped-Params` レスポンスヘッダーにその名前が示されます。
