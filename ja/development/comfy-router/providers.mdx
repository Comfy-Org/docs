すべてのモデルで `POST /v2/models/{provider}/{model}` を使用します。デフォルトのプロバイダーは Comfy です。代替の配信先があるモデルでは、`model_provider` を指定すると、モデル ID やリクエストボディを変更せずに別のプロバイダーを選択できます。詳細は API リファレンスの [`model_provider`、`strict_mode`、`fallback_provider`](/ja/development/comfy-router/reference#post-v2modelsprovidermodel) を参照してください。
