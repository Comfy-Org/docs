すべてのモデルは `POST /v2/models/{provider}/{model}` を使用します。デフォルトのプロバイダーは Comfy です。代替の配信先があるモデルでは、`model_provider` を指定すると、モデル ID やリクエストボディを変更せずに別のプロバイダーを選択できます。詳細は API リファレンスの [`model_provider`、`strict_mode`、`fallback_provider`](/ja/development/comfy-router/reference#post-v2modelsprovidermodel) を参照してください。

## プロバイダー別の対応状況

`strict_mode=false`（デフォルト）では、選択したプロバイダー向けにネイティブのリクエストとレスポンスが変換されます。変換できないフィールドは `X-Comfy-Router-Dropped-Params` レスポンスヘッダーに一覧表示されます。
