Comfy Cloud API を通じて送信されたワークフローは、他の Cloud ワークフローと同じクレジットおよび同時実行の制限を受けます。

## クレジットと使用量

API リクエストは、Comfy Cloud の Web UI と同じ月額クレジットの割り当てから消費されます。API 専用のクレジットプールはありません。各プランに含まれるクレジット、トップアップのオプション、ワークフローごとの実行時間の上限は、UI のジョブと同様に API のジョブにも適用されます。

月額クレジットの量とトップアップのオプションについては、[料金ページ](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)を参照してください。トップアップはアカウントのダッシュボードから購入できます。

## 同時実行の制限

前のジョブの完了を待たずに複数のワークフローを送信できます。ジョブはサブスクリプションのプランの上限まで並列で実行されます：

| プラン   | 同時実行ワークフロー数 |
| :------- | :--------------------- |
| Standard | 1                      |
| Creator  | 3                      |
| Pro      | 5                      |

Team プランでは、メンバーごとの同時実行ワークフロー数が Pro より多くなります。現在の同時実行数の上限は [platform.comfy.org](https://platform.comfy.org) で確認してください。それを超えたジョブはキューに入り、スロットが空きしだい実行されます。

キューが満杯の場合、SDK は限られた回数の範囲で再試行した後、`QueueFull` を発生させます。

Team プランと Enterprise プランでは、同時実行はメンバーごとに適用されます。ワークスペースの各メンバーに独自の同時実行上限が割り当てられるため、あるメンバーの実行中ジョブが他のメンバーのジョブをブロックすることはありません。

<Info>
  複数のジョブを同時に実行できるのは API 経由のみです。Comfy Cloud UI では 1 人につき同時に実行できるワークフローは 1 つで、エディタでキューに入ったワークフローは順番に実行されます。サブスクリプションの詳細については、[料金プラン](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)を参照してください。
</Info>

## 実行時間とキューの上限

各 Cloud ワークフローには最大実行時間があり、上限を超えたジョブは自動的にキャンセルされます：

| プラン   | 最大実行時間 |
| :------- | :----------- |
| Standard | 30 分        |
| Creator  | 30 分        |
| Pro      | 1 時間       |

キューには最大 150 件のワークフローを同時に保持できます。Team プランと Enterprise プランでは、キューの上限はメンバーごと、かつワークスペースごとに適用されます。各メンバーがそれぞれ 150 件を持ち、チーム全体で共有する 1 つのキューではありません。あるメンバーが上限に達しても、この上限のもとで他のメンバーの送信がブロックされることはありません。Team の同時実行数の上限を引き上げるには、[サポート](https://support.comfy.org/)にお問い合わせください。

## 既存の v1 連携

非推奨の [v1 Cloud API](/ja/development/cloud/overview) も Comfy Cloud 上で動作します。既存の連携や、[Comfy API v2](/ja/api-reference/v2/overview) ではまだ利用できない Cloud の機能にはこちらを使用してください。実行可能なサンプルは非推奨の [Cloud API Reference](/ja/development/cloud/api-reference) にあります。
