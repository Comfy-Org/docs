Comfy Cloud エディターで作成したワークフローは、バックエンドサービスやバッチスクリプトなど、独自のアプリケーションから [Comfy SDKs](/ja/development/api-development/sdks) を使って実行できます。Comfy Cloud は、デフォルトのカスタムノードセットを備えたスタンダードビルドでワークフローを実行します。ワークフローがスタンダードビルドに含まれないカスタムノードやモデルを必要とする場合は、カスタムビルドを作成します。これは、Comfy Cloud がユーザーに代わって実行する、独自のカスタムノードとモデルをまとめたパッケージです。このページでは、API を通じてスタンダードビルドでワークフローを実行する方法と、その後、同じコードをカスタムビルドに向ける方法を説明します。

## 開始する前に

コードから Comfy Cloud を呼び出すには、次のものを用意してください:

- **有料の Comfy Cloud サブスクリプション**
- **Comfy Cloud エディタで動作するワークフロー**: コードから実行する前に、エディタでテストしてください。標準ビルドに含まれないカスタムノードやモデルが必要な場合は、先に[カスタムビルドを作成](/ja/development/deploy/cloud-custom-builds)してください。
- **Python 3.10 以降、または Node 22 以降**: インストールする SDK には、いずれかが必要です。

Comfy Cloud をまだ使ったことがない場合は、[Comfy Cloud](/ja/get_started/cloud) から始めてください。

## スタンダードビルドでワークフローを実行する

スタンダードビルドでは、Comfy Cloud がサポートするカスタムノードのみを使用するワークフローであれば実行できます。コードから実行するには、APIキーを作成し、SDKをインストールし、ワークフローをAPI形式でエクスポートします。

<Steps>
  <Step title="APIキーを作成する">
    アプリケーションは各リクエストとともにキーを送信するため、Developer Platform でアプリケーション用のキーを作成します。

    1. [platform.comfy.org](https://platform.comfy.org) にログインし、**API Keys** をクリックします。
    2. **New API key** をクリックし、名前を入力してから **Generate key** をクリックします。
    3. キーをコピーして安全な場所に保管します。Developer Platform に表示されるのは一度だけです。

    キーは `comfyui-` で始まります。キーの管理方法については [APIキーの取得](/ja/development/api-development/getting-an-api-key) を参照してください。
  </Step>
  <Step title="SDKをインストールする">
    <CodeGroup>
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    </CodeGroup>
  </Step>
  <Step title="ワークフローをAPI形式でエクスポートする">
    SDKが送信するのはワークフローのAPI形式であり、エディタが保存するファイルではありません。

    - Comfy Cloud のエディタでワークフローを開き、**File** > **Export (API)** を選択して、ファイルを `workflow_api.json` として保存します。

    ファイルの内容については [ワークフローAPI形式](/ja/development/api-development/workflow-api-format) を参照してください。
  </Step>
  <Step title="ワークフローを実行する">
    SDKは別のベースURLを設定しない限り Comfy Cloud にリクエストを送信するため、APIキーのみを渡します。

    <CodeGroup>
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." });

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    </CodeGroup>

    - `"9"` は、`workflow_api.json` 内の出力ノードのIDに置き換えてください。
    - `run()` はジョブが完了するまで待機し、その後コードが出力をディスクに書き込みます。

    入力の設定、進捗の追跡、エラーの処理については、[Comfy SDK](/ja/development/api-development/sdks) を参照してください。
  </Step>
</Steps>

## カスタムBuildでワークフローを実行する

カスタムBuildをデプロイすると、独自のURLを持つデプロイメントが作成されます。ベースURLを変更すれば、前のセクションのコードがそのデプロイメント上で実行されます。

<Warning>
  デプロイメントは、ワーカーが稼働している間はGPU時間を、削除するまではストレージを消費します。テストが終わったら、停止または削除してください。詳しくは[クリーンアップ](/ja/development/serverless/overview#クリーンアップ)を参照してください。
</Warning>

<Steps>
  <Step title="Buildを作成してデプロイする">
    [Custom Builds](/ja/development/deploy/cloud-custom-builds)に従って、ワークフローからBuildを作成し、デプロイします。
  </Step>
  <Step title="デプロイメントURLをコピーする">
    1. Developer Platformで、デプロイメントのページを開きます。
    2. デプロイメントのステータスが**Ready**になるまで待ちます。
    3. **Run via API**で、**Deployment URL**をコピーします。

    デプロイメントURLは`https://dep-<id>.run.comfy.app`の形式です。
  </Step>
  <Step title="ベースURLを設定する">
    `COMFY_BASE_URL`にデプロイメントURLを設定します:

    ```bash
    export COMFY_BASE_URL="https://dep-<id>.run.comfy.app"
    ```
  </Step>
  <Step title="ワークフローを実行する">
    [スタンダードビルドでワークフローを実行する](#スタンダードビルドでワークフローを実行する)のコードを、APIキーを指定して実行します。これでSDKはジョブをデプロイメントに送信します。
  </Step>
</Steps>

<Tip>
  まずターミナルからデプロイメントをテストするには、次を実行します:

  ```bash
  comfy deploy run --deployment <deployment-id> --workflow workflow_api.json
  ```
</Tip>
