[Comfy SDK](/ja/development/api-development/sdks) は [Comfy API v2](/ja/api-reference/v2/overview) を使用して通信します。ベータ期間中、セルフホストの ComfyUI は v2 自体を提供しません。[comfy-api-proxy](https://github.com/Comfy-Org/comfy-api-proxy) は、インスタンスと並行して動作し、その前段で v2 のコントラクトを提供する小規模なオープンソースサービスです。

<Note>
  このプロキシは暫定的なものです。v2 API が安定したら ComfyUI 本体に取り込まれ、プロキシは不要になります。
</Note>

## インストールと実行

```bash
pip install comfy-api-proxy
comfy-api-proxy
```

デフォルトでは `127.0.0.1:8188` の ComfyUI をプロキシし、`127.0.0.1:8189` で v2 API を提供します。どちらも変更するには `--comfyui` と `--port` を使用します。

インストール先にモデルファイルをアップロードしたい場合は、`--comfyui-base-dir /path/to/ComfyUI` を付けて実行します。

## SDK の接続先を設定する

ベース URL を設定し、通常どおりクライアントを構築します:

```bash
export COMFY_BASE_URL="http://127.0.0.1:8189"
```

<CodeGroup>
```python Python
from comfy_sdk import Comfy

client = Comfy()
```

```typescript TypeScript
import { Comfy } from "@comfyorg/sdk";

const client = new Comfy();
```
</CodeGroup>

[SDK ガイド](/ja/development/api-development/sdks) の内容はすべて、Comfy Cloud に対する場合と同じように、プロキシに対しても動作します。

## 認証

認証はデフォルトでは必須ではありません。プロキシに静的なベアラートークンが設定されている場合は、そのトークンを SDK の APIキーとして渡します: `Comfy(api_key="...")`。

<Warning>
  プロキシはデフォルトではループバックにのみバインドします。ループバックを超えて公開する場合、たとえばレンタル GPU 上の ComfyUI の前段に置く場合は、ベアラートークンを設定するか、認証を行うリバースプロキシを前段に配置してください。
</Warning>
