ComfyUI をヘッドレスで実行するための公開 API は、時間とともに進化してきました。新しい統合には、[Comfy API v2](/ja/api-reference/v2/overview) を使用してください。この API は、オープンソースの ComfyUI（ベータ期間中は [API Proxy](/ja/development/comfyui-server/api-proxy) 経由）、Comfy Cloud、および新しい [Serverless API](/ja/development/serverless/overview) でサポートされています。古いバージョンには、非推奨の [v1 Cloud API](/ja/development/cloud/overview) が含まれています。
