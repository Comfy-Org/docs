ComfyUI フロントエンドは現在、内部境界においてローカルノード ID をブランド化された文字列型 `NodeId` に正規化します。シリアライズされたワークフローや API ペイロードには依然として数値 ID が含まれる場合がありますが、litegraph (レガシー) 内のノード ID（`node.id`、`LLink.origin_id`、`LLink.target_id` など）は、フロントエンドに入力された後は文字列として扱う必要があります。リンク ID（`LLink.id`）とリルート ID は数値のままです。

拡張機能の作者は、ノード ID に対する数値比較を避けるべきです。特に、サブグラフ境界センチネルはブランド化された文字列 ID として公開されています:

- `SUBGRAPH_INPUT_ID` は `-10` からシリアライズされます
- `SUBGRAPH_OUTPUT_ID` は `-20` からシリアライズされます

文字列 `'-10'` および `'-20'` と比較するか、レガシー値を比較する前に両辺を文字列に正規化してください。
