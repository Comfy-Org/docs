## どれを使うべき？

| | Comfy MCP<br />クラウド接続 | Comfy MCP<br />ローカル接続 | Comfy Agent |
|---|---|---|---|
| **説明** | 自分のエージェントで Comfy Cloud のワークフローを実行します。 | 自分のエージェントでローカルの ComfyUI を操作します。 | ComfyUI 内でエージェントとチャットし、選択済みのワークフローを理解、構築、編集、実行します。 |

| **GPU** | クラウド GPU（ハードウェア要件なし） | ローカル GPU | 現時点ではクラウド GPU。Comfy Desktop 対応の提供開始後はローカルハードウェア。 |

## MCP とは？

**Model Context Protocol (MCP)** は、AI アシスタントが標準化されたインターフェースを通じて外部ツールやサービスと連携できるようにするオープンスタンダードです。AI エージェントがサービスごとに独自の API 形式を把握する必要はなく、MCP はツールを統一された方法で公開します。

MCP サーバーを Claude Desktop、Claude Code、Cursor、Amp に接続すると、AI アシスタントは次のことができるようになります。

- テキストの説明から**画像を生成**
- テキストや画像から**動画を作成**
- テキストや画像から**3D モデルを生成**
- AI モデルを使って**オーディオや音楽を生成**
- タスクに適したツールを見つけるために**モデルやテンプレートを検索**

……これらすべてを自然言語の対話を通じて行え、API 呼び出しを手動で書く必要はありません。
