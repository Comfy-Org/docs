## どれを使うべき？

| | Comfy MCP<br />クラウド接続 | Comfy MCP<br />ローカル接続 | Comfy In-App Agent |
|---|---|---|---|
| **説明** | 自分のエージェントで Comfy Cloud ワークフローを実行します。 | 自分のエージェントでローカルの ComfyUI を操作します。 | アプリ内で AI とチャットし、AI がワークフローを構築・実行してくれる様子を確認できます。 |
| **最適な用途** | ローカルに ComfyUI をセットアップしたくない初心者。<br />ワークフローを共有したい人。 | ローカルに ComfyUI を導入している人。<br />プライベートなカスタムノードを持っている人。<br />ローカルファイルシステムを操作する必要がある人。 | 初心者から上級のワークフロー作成者まで、すべての人。<br />キャンバスを見てワークフローを視覚的に確認したい人。 |
| **必要条件** | 自分専用のエージェント。<br />有料実行には Comfy Cloud サブスクリプション。 | 自分専用のエージェント。<br />ローカルの ComfyUI セットアップ。 | セットアップ不要。<br />有料実行には Comfy Cloud サブスクリプション。 |
| **GPU** | クラウド GPU（ハードウェア要件なし） | ローカル GPU | クラウド GPU（ハードウェア要件なし） |
| **モデル** | Comfy Cloud モデル。<br />独自モデルのインポートが可能です。 | 自分のマシンにダウンロードしたローカルモデル。 | Comfy Cloud モデル。<br />独自モデルのインポートが可能です。 |
| **カスタムノード** | Comfy Cloud でサポートされているカスタムノード。 | 任意のカスタムノードをインストールできます。 | Comfy Cloud でサポートされているカスタムノード。 |

MCP の 2 つの列は**同じ製品であり、同じページ**です。[Comfy MCP](/ja/agent-tools/mcp) を参照して選択してください。両方を同時に接続することもできます。

## MCP とは？

**Model Context Protocol (MCP)** は、AI アシスタントが標準化されたインターフェースを通じて外部ツールやサービスと連携するためのオープンスタンダードです。各サービスのカスタム API 形式を AI エージェントが学習する必要はなく、MCP はツールを統一された方法で公開します。

MCP サーバーを Claude Desktop、Claude Code、Cursor、Amp に接続すると、AI アシスタントは以下のことが可能になります：

- **画像生成**: テキスト説明から
- **動画作成**: テキストや画像から
- **3D モデル生成**: テキストや画像から
- **オーディオ・音楽生成**: AI モデルを使用
- **モデル・テンプレート検索**: タスクに適したツールを見つける

……すべて自然言語の対話を通じて、API 呼び出しを手動で書く必要はありません。
