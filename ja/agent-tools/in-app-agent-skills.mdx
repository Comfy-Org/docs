## 個人スキルとは？

個人スキルとは、Comfy Agent 向けの再利用可能な指示のまとまりです。名前、いつ使うかを示す 1 行の説明、そして指示そのものが含まれます。

個人スキルは、「正方形の画像を作成する」「白い背景を使う」「実行前にノードの接続を確認する」といった指示を繰り返すために使用します。

個人スキルはアカウントに保存されます。Agent は、スキルの説明がリクエストと一致したとき、または名前で指定したときにそのスキルを読み込みます。

## チャットでスキルを作成する

保存する内容、名前、使用するタイミングを Agent に伝えます:

> これを product-shot というスキルとして保存して: 製品画像を依頼したときは、正方形の 1024 × 1024 キャンバス、ニュートラルグレーの背景、Save Image ノードを使用すること。実行前にワークフローを検証すること。

Agent は今後のメッセージのためにスキルを保存します。新規または更新されたスキルは、次のメッセージから有効になります。

## Agent パネルでスキルを管理する

メッセージ欄の **+** メニューに**スキル**サブメニューがあり、スキルの一覧が表示されます。選ぶとそのスキルがメッセージに添付され、**スキルを管理**を選ぶとスキル画面が開き、追加・編集・削除ができます。

![Agent パネルのスキル画面](/images/agent_tools/agent_skills_panel.png)

保存したスキルの名前は変更できません。名前を変えるには、削除してから新しい名前で追加し直します。フォームを保存せずに閉じた場合、入力内容はこのデバイスに下書きとして残り、保存または破棄するまで保持されます。

## スキルの項目

| 項目 | 役割 | ルール |
| --- | --- | --- |
| **名前** | Agent がスキルを読み込むときの識別子。 | 64 文字まで。使用できるのは ASCII の英字、数字、`.`、`_`、`-` です。名前は一意である必要があり、常に読み込まれる組み込みスキルの名前は使用できません。 |
| **使用するタイミング** | いつ読み込むかを示す 1 行。スキルを使用するかどうかにかかわらず、すべてのメッセージと一緒に送信されます。 | 1 行で 1,024 文字まで。短く保ってください。 |
| **指示** | スキルが読み込まれた後に Agent が従う内容。 | 必須。 |

## サイズ上限

一覧には各スキルのサイズがバイト単位で表示されます。スキルはアカウントのサイズ上限を共有し、上限を超える保存はフォームが拒否して、先にスキルを削除するよう求めます。

## スキルを使用する

名前でスキルを依頼します:

> 私の product-shot スキルを使って、赤いスニーカーのスタジオ写真ワークフローを作成して。

Agent は、リクエストが説明と一致した場合にスキルを自動的に選択することもできます。一覧から選ぶには、メッセージ入力欄で `/` を入力し、メニューの**スキル**セクションから選びます。

## スキルを更新または削除する

同じスキル名で指示を置き換えます:

> 私の product-shot スキルを更新して、白い背景と 1536 × 1536 のキャンバスを使用するようにして。

名前でスキルを削除します:

> 私の product-shot スキルを削除して。

## 既存のスキルファイルを保存する

`SKILL.md` ファイルの内容をチャットに貼り付け、個人スキルとして保存するよう Agent に依頼します。Agent はファイルの先頭にあるヘッダーから名前と説明を読み取ります。保存されたスキルは次のメッセージから利用できます。

## 公開スキルを使用する

公開スキルは、あなたが作成したものに限らず誰でも使用できる共有スキルです。名前で公開スキルを依頼するか、やりたいことを説明すると、Agent はあなたの個人スキルと同じようにそれを使用します:

> ニュートラルグレーの背景に赤いスニーカー用の product-shot 公開スキルを使用して。

## 組み込みガイダンスとコーディングエージェントスキル

Comfy Agent には、ワークフローを構築しモデルを選択するためのガイダンスが含まれています。個人スキルと公開スキルは、そのガイダンスに加えて、繰り返し行うタスク向けの指示を追加します。

[コーディングエージェント向けスキル](/ja/agent-tools/skills)は、Claude Code などのツールに別途インストールします。そこでインストールしても、Comfy Agent には追加されません。

API キー、パスワード、アクセストークンはスキルの指示に含めないでください。データの取り扱いについては、[データとプライバシー](/ja/agent-tools/in-app-agent-data-privacy#スキルとガイダンス)を参照してください。
