## スキルパックとは？

スキルパックは、Comfy Agent 向けの再利用可能な指示のまとまりです。各パックには名前、いつ読み込むかを示す 1 行のトリガー行、そして指示そのものが含まれます。

スキルパックは、「正方形の画像を作成する」「白い背景を使う」「実行前にノードの接続を確認する」といった繰り返しの指示に使用します。

自分で作成したパックは自分のアカウントだけのものです。Agent は、トリガー行がリクエストと一致したとき、または名前で指定したときにパックを読み込みます。

## チャットでスキルを作成する

保存する内容、名前、使用するタイミングを Agent に伝えます:

> これを product-shot というスキルとして保存して: 製品画像を依頼したときは、正方形の 1024 × 1024 キャンバス、ニュートラルグレーの背景、Save Image ノードを使用すること。実行前にワークフローを検証すること。

Agent は今後のメッセージのためにスキルを保存します。新規または更新されたスキルは、次のメッセージから有効になります。

## スキルを使用する

名前でスキルを依頼します:

> 私の product-shot スキルを使って、赤いスニーカーのスタジオ写真ワークフローを作成して。

トリガー行がリクエストと一致した場合、Agent はスキルを自動的に選択することもできます。一覧から選ぶには、メッセージ入力欄で `/` を入力し、メニューの **Skills**（スキル）セクションから選びます。

## 設定でスキルパックを管理する

**設定** → **スキルパック** を開くと、アカウント内のすべてのパックが表示されます。各パックには名前とサイズが表示されます。

- **スキルパックを追加** で新規作成用のフォームが開きます。
- **編集** で既存パックのトリガー行と指示を変更できます。作成したパックの名前は変更できません。
- **削除** でパックを削除します。削除は元に戻せません。

## スキルパックの項目

| 項目 | 役割 | ルール |
| --- | --- | --- |
| **名前** | Agent がパックを読み込むときの識別子。 | 64 文字まで。使用できるのは英数字、`.`、`_`、`-` です。名前は一意である必要があり、常時有効な組み込みパックの名前は使用できません。 |
| **トリガー行** | いつ読み込むかを示す 1 行。パックを使用するかどうかにかかわらず、すべてのメッセージと一緒に送信されます。 | 1 行で 1,024 文字まで。短く保ってください。 |
| **指示** | パックが読み込まれた後に Agent が従う内容。 | 必須。 |

## サイズ上限

パック一覧には各パックの合計サイズがバイト単位で表示されます。パックの作成・編集中は、入力に応じて指示のサイズがフォームに表示されます。パックはアカウントのサイズ上限を共有します。新しいパックが上限を超える場合、フォームは保存せず、先にパックを削除するよう求めます。

## スキルを更新または削除する

同じスキル名で指示を置き換えます:

> 私の product-shot スキルを更新して、白い背景と 1536 × 1536 のキャンバスを使用するようにして。

名前でスキルを削除します:

> 私の product-shot スキルを削除して。

## 既存のスキルファイルを保存する

`SKILL.md` ファイルの内容をチャットに貼り付け、スキルパックとして保存するよう Agent に依頼します。Agent はファイルの先頭にあるヘッダーから名前と説明を読み取ります。保存されたスキルは次のメッセージから利用できます。

## 公開スキルを使用する

公開スキルは、あなたが作成したものに限らず誰でも使用できる共有スキルです。名前で公開スキルを依頼するか、やりたいことを説明すると、Agent はあなたのスキルパックと同じようにそれを使用します:

> ニュートラルグレーの背景に赤いスニーカー用の product-shot 公開スキルを使用して。

## 組み込みガイダンスとコーディングエージェントスキル

Comfy Agent には、ワークフローを構築しモデルを選択するためのガイダンスが含まれています。スキルパックと公開スキルは、そのガイダンスに加えて、繰り返し行うタスク向けの指示を追加します。

[コーディングエージェント向けスキル](/ja/agent-tools/skills)は、Claude Code などのツールに別途インストールします。そこでインストールしても、Comfy Agent には追加されません。

API キー、パスワード、アクセストークンはスキルの指示に含めないでください。データの取り扱いについては、[データとプライバシー](/ja/agent-tools/in-app-agent-data-privacy#スキルとガイダンス)を参照してください。
