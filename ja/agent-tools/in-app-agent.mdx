<Note>
  **Comfy Agent は Comfy Cloud で一般提供されています**。ウェイトリストは不要です。Comfy Desktop のローカルサポートは近日公開予定です。通知を受け取るには[ウェイトリストに参加してください](https://links.comfy.org/agentalpha)。
</Note>

ComfyUI の中でそのまま、やりたいことを記述するだけです。ワークフローの計画、構築、実行を行います。あなたが作業している間もキャンバスを編集し、あなたと並んで一緒に作り上げます。

## できること

- ComfyUI 環境で利用可能なテンプレート、モデル、ノードを検索します。
- テンプレートからワークフローを構築し、プロンプトや設定をカスタマイズします。
- 残りの部分を再構築せずに、現在のワークフローの一部を変更します。
- ノードの追加、接続、設定、削除を行います。
- 実行前にワークフローを検証します。
- 画像を検査し、ビデオやオーディオのプロパティを読み取ります。
- ワークフローを実行し、その出力を返します。
- Agent が応答している間もキャンバスで作業を続けられます。完了を待つ必要はなく、現在開いている内容を基に動作します。
- 平易な言葉でスキルを作成したり、自分自身のスキルだけでなく Comfy の公開スキルの使用を Agent に依頼したりできます。詳しくは [Agent スキル](/ja/agent-tools/in-app-agent-skills) を参照してください。
- 複数のチャットを同時に開けます。各チャットは独自の履歴とコンテキストを持つ独立したセッションです。

## どこで使用できるか

| Comfy Agent を使用する場所 | 期待されること |
| --- | --- |
| **Comfy Cloud** | 一般提供されています。Agent、ワークフロー、アセットは Comfy Cloud アカウントを使用します。インストールが必要なローカルパッケージはありません。 |
| **Comfy Desktop** | **近日公開。** ローカルの ComfyUI（独自のモデルやカスタムノードを含む）で Comfy Agent が利用可能になったときに通知を受け取るには、[ウェイトリストに参加してください](https://links.comfy.org/agentalpha)。 |

いずれの場合も、Agent のリクエストはネットワーク経由で Comfy サービスを使用します。[データとプライバシー](/ja/agent-tools/in-app-agent-data-privacy)を参照してください。

Comfy Agent は [Comfy MCP](/ja/agent-tools/mcp) および [Comfy CLI](/ja/agent-tools/cli) とは別のものです。MCP は外部の AI クライアントを Comfy に接続します。CLI はターミナルおよびスクリプトのワークフロー向けです。Comfy Agent は ComfyUI インターフェース内で動作します。

最初の画像を作成するには、[Comfy Agent をはじめる](/ja/agent-tools/in-app-agent-installation#最初の画像を作成する)に従ってください。

## 編集するワークフローを選択

Agentパネルのワークフローセレクターを使って編集するワークフローを選択し、メッセージを送信します。Agentが応答している間に別のタブへ切り替えても、その編集内容がそちらにリダイレクトされることはありません。

Agentは自身でタブを作成したり切り替えたりすることはできません。別の場所で作業するには、他のワークフローを開き、Agentパネルでそれを選択して、新しいメッセージを送信します。

Agentは、別の開いているワークフローや保存済みのワークフローを、現在のタブに読み込むことなく比較のために読み取ることができます。例えば:

> このワークフローを私のポートレートワークフローと比較して、ここで同じサンプラー設定を使用してください。

## ワークフローの構築と編集

新しいワークフローの場合は、空白のワークフロータブを開き、Agent パネルでそれを選択します。Agent は、個々のノードから構築する前に、一致するテンプレートを検索します。テンプレートには、接続されたグラフと出力ノードが含まれます。

既存のワークフローを変更する場合は、変更したい部分と、そのまま維持する部分を指定します。

- 「プロンプトを水彩画の風景に変更して。モデルとサンプラーの設定はそのままにして。」
- 「画像生成の後にアップスケーリングのステージを追加して。」
- 「ここにインストール済みのモデルを使って、このワークフローを Flux に切り替えて。」

Agent はキャンバス上でリアルタイムに構築し、その間もあなたはキャンバスの編集を続けられます。

## 実行前の検証

Agent は実行前に、ノードの接続、モデル名、必須の値、出力ノードを確認します。ワークフローのエラーと、あなたにしか指定できない入力を切り分けます。

ワークフローが有効でも、画像、ビデオ、その他の入力がまだ必要な場合は、ファイルを添付して Agent に続けるよう依頼します。

## メディアを扱う

エージェントは、静止画像の表示内容と寸法を検査できます。ビデオについては、再生時間、寸法、フレームレート、形式を読み取ることができます。オーディオについては、再生時間、形式、オーディオトラックを読み取ることができます。

メッセージボックスの **Attach a file** を使用して、画像やファイルを追加します。メディアを会話にドラッグすることもできます。

| 会話に追加 | 質問 | 結果 |
| --- | --- | --- |
| 画像 | 「この画像のライティングについて説明してください。」 | プロンプトを改善するために使える説明。 |
| ビデオ | 「これを最初の5秒にトリムしてください。」 | 短くしたビデオファイル。 |
| 2つのビデオクリップ | 「クリップAの後にクリップBを連結してください。」 | その順序で両方のクリップを含む1つのビデオ。 |
| ビデオとオーディオファイル | 「このオーディオをビデオに追加してください。」 | 指定したオーディオ付きのビデオ。 |

メディアの編集には、お使いのインストール環境でメディアツールが利用可能である必要があります。クラウドでは、編集したファイルはアセットライブラリに保存されます。エージェントは会話内でプレビューまたはファイルリンクを返します。

## 実行権限

メッセージボックスの横で実行権限を選択します。

- **Ask** は各ワークフローの実行前に承認を求めます。
- **Auto** は毎回確認せずにワークフローを実行します。

**Save changes** を選択すると設定が適用されます。Ask モードでは、承認メッセージ内の **Run** を選択するとワークフローが開始され、**Cancel** を選択するとその実行を拒否できます。

Ask と Auto はワークフローの実行を制御します。どちらのモードでも、Agent は選択済みのワークフローを編集できます。

## エージェントが利用できるもの

エージェントは、あなたのメッセージ、選択済みのワークフロー、選択済みのノード、添付ファイル、ワークフローのエラーを使用します。設定を比較または再利用するよう依頼すると、別のワークフローを読み取ることもできます。

クラウドとローカルのデータフロー、チャット履歴、プライバシー管理については、[Comfy Agent のデータとプライバシー](/ja/agent-tools/in-app-agent-data-privacy)を参照してください。

## 停止またはキャンセル

メッセージボックスで **停止** を選択すると、Agent の現在の応答を停止できます。ワークフローの実行には、[実行とキューのエリア](/ja/interface/overview)に別のコントロールがあります。すでに送信されたワークフローを管理するには、そちらを使用してください。

## チャット履歴

会話は保存されるため、以前の会話にいつでも戻れます。

- パネルヘッダーの **New chat** で新しい会話を開始します。
- **Show chat history** で保存済みの会話一覧を開きます。Current、Today、Yesterday、Earlier にグループ分けされています。会話を選ぶと再度開くことができ、会話のオプションから名前の変更、コピー、削除ができます。

会話の保存場所は環境によって異なります。[チャット履歴と同期](/ja/agent-tools/in-app-agent-data-privacy#チャット履歴と同期)を参照してください。
