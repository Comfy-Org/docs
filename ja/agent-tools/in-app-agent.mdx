<Note>
  **プライベートアルファ。** Comfy In-App Agent は、限られたユーザーを対象に順次展開されています。公開ドキュメントと Web サイトのページはまだ利用できません。アクセスをリクエストするには、ウェイトリストに参加してください。
</Note>

**Comfy In-App Agent** は、Comfy Cloud 内のエージェント体験です。チャットで希望を説明すると、エージェントがグラフ上でワークフローを構築または編集できます。

## エージェントを使用する

1. Comfy Cloudでワークフローを開きます。
2. ワークフローバーで **Ask Comfy Agent** を選択します。
3. チャットを使用するワークフローを選択します。グラフアクセスが不要なご質問の場合は、**Don't work in a workflow** を選択することもできます。
4. プロンプトを入力します。`@` と入力してノードを参照するか、**Add nodes from graph** を選択するか、またはエージェントにより多くのコンテキストを与えるために画像、ビデオ、オーディオファイル、3Dモデル、テキストファイルを添付します。
5. 提案されたグラフの変更と出力を確認します。エージェントが間違える可能性があるため、実行する前にワークフローをチェックしてください。

エージェントは、ワークフロータブごとに個別のチャットを保持します。**Chat history** を使用すると、以前の会話に戻ったり、名前を変更したり、マークダウンとしてコピーしたりできます。

## 実行権限

送信ボタンの横にあるコントロールは、エージェントがワークフローを実行できるタイミングを決定します：

- **ワークフロー実行前に確認**：実行のたびに承認が必要です。
- **承認なしで自動実行**：エージェントは確認なしでワークフローを実行できます。
- **制限付き自動実行**：実行が設定したクレジット上限を超える場合にのみ確認します。

実行権限は実行にのみ影響し、編集には影響しません。エージェントは選択済みワークフローを引き続き変更できます。プロンプトを送信する前にこの設定を確認してください。

## レスポンスをレビューする

ターン中、パネルにはエージェントの進捗状況と、使用しているツールが表示されます。レスポンスには、書式付きテキスト、コード、生成済みメディア、ダウンロード可能なアセット、ワークフロータブを開くリンクを含めることができます。

レスポンスを評価するには、レスポンスのサムズアップまたはサムズダウンのコントロールを使用します。バグを報告する場合や、詳細を共有する場合は、以下のフィードバックリンクを使用してください。

## 現在のアルファ版の制限事項

- アクセスは機能フラグ付きで、選択済みの Comfy Cloud アカウントに限定されています。
- 作業はチャットで選択済みのワークフローに限定されます。編集をリクエストする前に、ワークフローセレクターを確認してください。
- エージェントと人間の編集は同じクラウドワークフローを更新できますが、広範なオフライン編集とクリエイター向けの競合解決インターフェースは、このアルファ版の対象外です。
- 接続が中断された場合は、追加の編集を行う前に、パネルが再接続されるまでお待ちください。ワークフローを実行する前に、グラフの状態を確認してください。
- 停止または中断されたエージェントのターンは、自動的には再開されません。必要に応じて、新しいターンを開始してください。
