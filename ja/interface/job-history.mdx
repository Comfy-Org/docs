**Job History** は設定 `Comfy.Queue.QPOV2` が有効なときだけ左サイドバーに出るタブです。先頭に登録（`prepend`）され、別キュー UI を開かずに進行中ジョブと履歴を確認できます。

オフにするとタブは消えます。ヘッダーの Run / キューは引き続きジョブを開始します。本ページはサイドバーの履歴面向けです。

## 今後の追記候補

- 進行中 / 完了 / 失敗行
- アイコン上のバッジ
- キャンセル、クリア、再キュー
- Assets（実行出力）との関係
- 旧キュー UI との違い
