**Job History** は、設定 **Docked job history/queue panel**（`Comfy.Queue.QPOV2`）が有効なときに現れる左サイドバータブです。フロントエンドはサイドバーの**先頭**（`prepend`）に登録し、フローティングのキューオーバーレイを使わずにアクティブジョブと過去の実行を確認できます。

設定がオフのときはタブが削除され、代わりにフローティングのジョブ履歴オーバーレイ（`Comfy.Queue.ToggleOverlay`）が使えます。どちらの場合もトップの Run / キュー操作でジョブは開始できます。このページは**サイドバー**の Job History について説明します。

## Job History を有効にする

1. **Settings** を開く。
2. `Comfy` → `Queue` → `Layout` で **Docked job history/queue panel**（`Comfy.Queue.QPOV2`）を有効にする。
3. 左サイドバー先頭に **Job History** アイコンが現れる。

実験的な設定です。nightly では既定でオン。他のビルドでタブが見えない場合は設定を確認してください。

## パネルを開く

**Job History** アイコンをクリックします。実行中またはキュー中のジョブがあり、このタブが**非アクティブ**のとき、アイコンにアクティブジョブ数の数値バッジが付きます。タブを開くとその表示は消えます。

## タブ: All、Completed、Failed

ヘッダーのステータスタブ:

- **All**: 現在のフィルタでの全ジョブ。
- **Completed**: 完了した実行。
- **Failed**: リストに失敗ジョブが 1 件以上あるときだけ表示。

タブ下の要約行は実行中・キュー中の数（またはアクティブジョブなし）を示します。**Clear queue** は保留中（キュー済みで未実行）のジョブをすべてキャンセルします。

## 検索・フィルタ・ソート

ヘッダーツールで絞り込みます。

- **検索**: テキストでジョブをフィルタ。
- **フィルタ**: **All workflows** または **Current workflow**。
- **ソート**: **Most recent** または **Total generation time**。

## ジョブ一覧と操作

ステータス、実行中の進捗、出力がある場合のプレビューサムネイルが一覧されます。行またはコンテキストメニューから:

**実行中またはキュー中**

- 新しいタブでワークフローとして開く
- ジョブ ID をコピー
- ジョブをキャンセル

**完了**

- アセットを検査（プレビューがある場合）
- 出力を現在のワークフローにローダーノードとして追加
- プレビューアセットをダウンロード
- 新しいタブでワークフローとして開く
- ワークフローをエクスポート
- ジョブ ID をコピー

**失敗**

- 新しいタブでワークフローを開く
- ジョブ ID をコピー
- エラーメッセージをコピー
- エラーを報告
- 履歴リストからジョブを削除

ヘッダーのアクションメニューには **Clear history** があり、確認ダイアログが開きます。履歴クリアはキュー履歴エントリを削除します。保存済みアセットとの関係はダイアログの注記を読んでください。

## アセットとエラーとの関係

完了した実行の出力は、アセットシステムが有効なとき [アセット](/ja/interface/assets) にも出ます。ワークフローの失敗や不足リソースは、グラフ修正時に [右サイドパネル](/ja/interface/right-side-panel) の **Errors** タブに出ます。
