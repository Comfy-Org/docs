左サイドバーの **Nodes** エントリからノードライブラリを開きます。Comfy Core、Partner Nodes、インストール済みカスタムノードなど、このインスタンスで使えるすべてのノードを検索できます。

![ノードライブラリの All nodes タブ。上部に BOOKMARKED セクションが表示される](/images/interface/overview/node_library_bookmarked.png)

![ComfyUI ノードライブラリパネル。Essentials タブで入力と出力のタイルを表示](/images/interface/overview/node_library_essentials.png)

**Essentials** タブが利用できる場合、パネルには 2 つのタブがあります:

- **Essentials（エッセンシャル）**: 多くのワークフローで必要になるノードを用途別にまとめたグリッドです。セクションは、入力と出力、生成（画像、動画、テキスト、音声、3D）、制御とガイダンス（画像）、編集とユーティリティ（画像変換、画像ユーティリティ、画像フィルターとエフェクト、画像の色、画像の選択とマスク、動画変換、動画合成、動画の選択とマスク、3D 変換）です。タイルにマウスを合わせるとノードをプレビューでき、タイルをキャンバスにドラッグするとワークフローに追加できます。フィルターボタンで扱うメディアタイプだけを表示し、リストボタンで任意のセクションにジャンプできます。
- **All nodes（すべてのノード）**: すべてのノードの一覧です。Comfy Nodes、パートナーノード、拡張機能、ブループリントで絞り込み、並び順を既定のカテゴリ順と A-Z で切り替えられます。

**All nodes** でノードのブックマークアイコンをクリックすると、リスト上部の **Bookmarked（ブックマーク済み）** セクションに追加されます。

![ComfyUI ノードライブラリパネルの All nodes タブ。ブックマーク済み、Comfy ノード、パートナーノード、拡張機能の各グループを表示](/images/interface/overview/node_library_all_nodes.png)

**Essentials** タブは ComfyUI バックエンドで有効になっている場合に表示され、Comfy Cloud と nightly ビルドでは有効です。セルフホストの安定版では **All nodes** のみが表示されます。以前のパネルに戻すには、`設定(Settings)` --> `Comfy` --> `Node Library` で `New Node Library Design` を無効にします。
