ComfyUI には**自動拡張入力**（autogrow inputs、動的入力とも呼ばれます）を持つノードがあります。こうしたノードは入力スロットを固定で表示しません。最後の空き入力を接続すると、次の入力が自動的に追加されます。そのため 1 つのノードで、2 枚でも 20 枚でも画像をまとめて扱えます。

## 自動拡張入力の仕組み

1. **最後の空き入力を接続する。** このページの例では、**Batch Images** ノードの `image0` に画像を接続し、`image1` は空きのままです。
2. **ノードが自動で伸びる。** 最後の空き入力を埋めると、その下に新しい空の入力が追加されます。下の図では `image1` を接続したあとに `image2` が現れています。
3. **必要なだけ繰り返す。** 最後の入力を埋めるたびにノードは再び伸び、そのノードが許可する最大入力数まで増えていきます。

![2 つの入力を接続し、新しく追加された空き入力がハイライトされた Batch Images ノード](/images/interface/features/autogrow/autogrow-2.png)

知っておくと役立つ点が 2 つあります。

- **順序に意味があります。** 入力は表示されている順にノードへ渡されるため、`image0` が `image1` より先になります。順番が結果に影響する場合（例: 動画モデルにまとめて渡す画像）は注意してください。
- **空き入力はプレースホルダーです。** 何か接続して初めてノードのデータの一部になります。0 個の入力も許可するノードは、すべてのスロットが空でも実行できます。

## 自動拡張入力を使うノード

| ノード | 伸びる入力 | 最大入力数 |
|---|---|---|
| **Batch Images** | `image` | 50 |
| **Batch Masks** | `mask` | 50 |
| **Batch Latents** | `latent` | 50 |
| **And** / **Or** | `value` | 10 |
| **Nano Banana 2** など参照画像を取るパートナーノード | `image_1`、`image_2` など | 最大 14 枚 |

上限はノードごとに決まっています。いくつ受け取れるか分からないときは、ComfyUI 上で入力にマウスを重ねてツールチップを確認してください。

<Tip>
自動拡張は ComfyUI の V3 ノードスキーマの一部です。カスタムノードを書く場合は、[動的入力](/ja/custom-nodes/v3_migration#動的入力)の `Autogrow` テンプレート API を参照してください。
</Tip>
