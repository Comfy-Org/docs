左サイドバーの **Workflows** には、このマシンに保存したワークフローと最近開いたファイルが一覧されます。ここからタブで開き、空白ワークフローを作り、保存済み JSON を整理できます。

テンプレートは別入口（View の Browse Templates / Templates）です。[テンプレート](/ja/interface/features/template) を参照。

## 今後の追記候補

- 保存済みと最近
- 新タブで開く、名前変更、削除、複製
- Desktop / ポータブル / Cloud のパス差
- 上部タブバーとの関係
