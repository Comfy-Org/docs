HDRビューアは、ブラウザがノードプレビュー内に描画できないEXRおよびHDRファイルを表示します。画像を左、表示と検査のコントロールを右に配置したウィンドウ全体のダイアログとして開くため、浮動小数点画像を別のアプリケーションに渡す前に、その画像に実際に何が含まれているかを確認できます。

## HDRビューアを開く

浮動小数点画像を書き出すワークフローを実行します。たとえば、**format** を `exr` に設定した [Save Image (Advanced)](/ja/built-in-nodes/SaveImageAdvanced) です。`.exr` または `.hdr` ファイルの出力プレビューには、画像の代わりに太陽のアイコンと **HDR画像** が表示されます。プレビューをクリックすると、HDRビューアでファイルが開きます。ダイアログのタイトルは出力ファイル名で、ダイアログは最大化できます。

## 表示コントロール

これらのコントロールはファイルの表示方法を変更するものであり、ファイル自体を変更するものではありません。

| コントロール | 機能 |
| --- | --- |
| **露出** | 表示される明るさを -10 から +10 ストップの範囲で 0.1 刻みにシフトします。値を下げると、表示白を超えるハイライトが再び見えるようになります。 |
| **自動露出** | 画像内で最も明るいピクセルが表示白になるように露出を設定します。 |
| **チャンネル** | RGB、または R、G、B、A、輝度のいずれか1つのチャンネルを表示します。 |
| **ソースガマット** | sRGB または Rec.2020。ファイルを開くときにEXRのchromaticitiesタグから検出されます。タグがない、または誤ったタグが付いているファイルでは手動で切り替えてください。 |
| **ディザ** | デフォルトでオン。8ビットディスプレイで滑らかなグラデーションに現れるバンディングをスムーズにします。 |
| **クリップ警告** | デフォルトでオフ。表示白を超えるピクセルと黒を下回るピクセルを、それぞれ異なるパターンのハッチングで示すため、現在の露出で隠れているものを確認できます。 |

## 画像を検査する

サイドバーには、表示設定とは独立して、ファイルの内容も表示されます。

- **ピクセル値**: 画像にカーソルを合わせると、左上隅にカーソル位置の座標と生のRGBA値が表示されます。
- **ヒストグラム**: 選択したチャンネルの分布。
- **統計**: 解像度、最小値、最大値、平均値、標準偏差。ファイルに含まれる場合はNaNとInfの数も表示されます。
- **ナビゲーション**: スクロールでズーム、ドラッグでパン、**Fit** をクリックすると画像が枠に収まります。
- **画像をダウンロード** はオリジナルのファイルを保存します。
