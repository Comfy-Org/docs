クレジットは **Partner Nodes**（クローズドソースモデルへの API 呼び出し）を動かすために使います。ローカルのグラフ実行とオープンソースノードは引き続き完全に無料です。クレジットが必要なのは Partner Nodes や Cloud の課金機能を使うときだけです。

**設定 → ユーザー** でサインインしたあと、**設定 → ワークスペース → プランとクレジット** を開きます。Comfy Cloud では、プロフィールメニューの **Manage plan / プラン管理** からも同じパネルを開けます。

![プランとクレジット（Cloud）](/images/interface/setting/plan-credits-cloud-overview.jpg)

<Note>
ComfyUI はローカルユーザー向けに常に完全オープンソースかつ無料です。スクリーンショットの残高は説明用の例示データです。
</Note>

## プランとクレジットの内容

**設定 → ワークスペース → プランとクレジット** を開きます。ローカルインストールでは、サインイン後にサイドバーの Workspace 配下にプランとクレジットが表示されます（Members / Invoices はありません）：

![プランとクレジット（ローカル）](/images/interface/setting/plan-credits-local-overview.jpg)

| タブ | 内容 |
| --- | --- |
| **Credits（クレジット）** | 残高、チャージ、プラン概要（ローカルはクレジットパネルを埋め込み、Cloud はワークスペースのサブスクリプション表示） |
| **Activity（アクティビティ）** | クレジット消費の利用履歴 |
| **Invoices（請求書）** | Cloud のみ。ワークスペースのサブスクリプション管理権限があるユーザー向け — 次回請求と Stripe 履歴 |

![Activity タブ](/images/interface/setting/plan-credits-cloud-activity.jpg)

![Invoices タブ（Cloud）](/images/interface/setting/plan-credits-cloud-invoices.jpg)

</Note>

詳細な手順：

<Steps>

<Step title="ComfyUI アカウントにログインする">
**設定 → ユーザー** を開いてサインインします。
![ログインインターフェース](/images/interface/setting/user.jpg)
</Step>

<Step title="プランとクレジットを開く">
ログイン後、**設定 → ワークスペース → プランとクレジット**（または Cloud プロフィール → **Manage plan**）を開きます。
![プランとクレジット](/images/interface/setting/plan-credits-cloud-overview.jpg)
</Step>

<Step title="購入するクレジット量を設定する">
![購入金額を設定](/images/interface/setting/buy.jpg)
ポップアップで購入金額を設定し、**Buy** をクリックします。
</Step>

<Step title="Stripe で支払いを行う">
![Stripe 支払いページ](/images/interface/setting/stripe_payment.jpg)
支払いページで：
1. 支払い通貨を選択する
2. メールが ComfyUI アカウントのメールと一致することを確認する
3. 支払い方法を選ぶ
   - クレジットカード
   - WeChat（Comfy Credits で支払う場合のみ）
   - Alipay（Comfy Credits で支払う場合のみ）
4. **Pay** または **Generate QR Code** をクリックして完了する
</Step>

<Step title="残高を確認する">
![支払い成功](/images/interface/setting/purchase-2.jpg)
**プランとクレジット** に戻り、残高が更新されているか確認します。必要なら更新または再起動してください。
</Step>

</Steps>

## よくある質問

<AccordionGroup>
  <Accordion title="クレジットが負になることはありますか？">
    クレジットは与信枠としては意図されていません。Partner Nodes が実行後にコストを報告する場合があり、1 回の実行で一時的に負の残高になることがあります。残高が負のあいだは、チャージして正に戻るまで Partner Nodes は実行できません。
  </Accordion>

  <Accordion title="未使用のクレジットは返金できますか？">
  現時点では、未使用クレジットの返金はサポートしていません。
  </Accordion>

  <Accordion title="現在の残高と使用量を確認するには？">
  **設定 → ワークスペース → プランとクレジット** を開きます。残高は **Credits** タブ、利用履歴は **Activity** タブです。
  </Accordion>

  <Accordion title="クレジットを他のユーザーと共有できますか？">
  複数のデバイスで同じアカウントにログインすることはできます。他のユーザーアカウントとのクレジット共有はサポートしていません。Cloud Team ワークスペースでは、メンバーがオーナー設定の上限内でワークスペース残高を共有します。
  </Accordion>

  <Accordion title="ノードのコストを事前に知るには？">
  実行前に API / Partner Node の価格バッジを確認してください。実際のコストは画像サイズ、生成数、その他のパラメータで変わることがあります。
  </Accordion>

  <Accordion title="WeChat や Alipay の支払いオプションが表示されないのはなぜですか？">
  Comfy Credits での支払いを選んでください。WeChat と Alipay はその通貨パスでのみ利用できます。
  </Accordion>

  <Accordion title="クレジットに有効期限はありますか？">
  はい。種類によって異なります：
  - **月間クレジット**：請求期間の終了時に期限切れ
  - **チャージクレジット**：購入日から 1 年後に期限切れ
  </Accordion>
</AccordionGroup>
