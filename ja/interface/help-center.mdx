ヘルプセンターは、ComfyUIのサイドバー下部にある疑問符アイコンの背後にあるパネルです。エディターの外で探すことになるリンクやアクション、つまりリリースノート、ドキュメント、コミュニティとサポートのチャンネル、システムステータス、フィードバック、ComfyUIのアップデートアクションをここにまとめています。

## ヘルプセンターを開く

左サイドバーの下部にある疑問符アイコンをクリックします。ツールチップには**ヘルプセンター**と表示され、アイコンに赤いドットがある場合は新しく読むものがあることを示します。

もう一度アイコンをクリックするとパネルが閉じます。**アプリモード**（リニアモード）では、同じアイコンをクリックするとメニューではなくフィードバックフォームが直接開きます。

## メニュー項目

パネルには以下の項目が一覧表示されます。一部はComfy Cloudビルドでのみ表示され、一部はローカルインストールでのみ表示されます。

| 項目 | 機能 |
| --- | --- |
| **フィードバックを送信** | Comfy Cloudおよびナイトリービルドでフィードバックフォームを開きます。それ以外のビルドではサポート問い合わせフローを開始します。 |
| **ヘルプ＆サポート** | サポート問い合わせフローを開きます。 |
| **ドキュメント** | docs.comfy.orgを開きます。Comfy Cloudを利用中の場合は、Comfy Cloudのはじめにページを開きます。 |
| **Discord** | ComfyUI Discordサーバーを開きます。 |
| **Github** | ComfyUIリポジトリを開きます。 |
| **システムステータス** | status.comfy.orgのComfyステータスページを開きます。Comfy Cloudのみ。 |
| **マネージャー拡張** | カスタムノードマネージャーを開きます。ローカルインストールのみ。 |
| **ComfyUIをアップデート** | ComfyUIの更新をキューに追加します。新しいマネージャーを使用するローカルインストールのみで、デスクトップアプリは除きます。 |
| **その他...** | 追加の項目で、少なくとも1つ利用可能な場合にのみ表示されます。デスクトップアプリの場合：**デスクトップユーザーガイド**、**開発者ツールを開く**、**再インストール**。開発者モードがオンの場合：**オンボーディングをリプレイ**。 |

## 新着情報

メニューの下にある**新着情報**セクションには、最新のComfyUIリリースがバージョン番号とリリース日とともに一覧表示されます。リリースをクリックすると、[changelog](/ja/changelog)ページの該当項目が開きます。

このセクションは、設定の**Comfy**、続いて**通知設定**にある**バージョン更新を表示**設定に従います。この設定はデフォルトでオンになっています。オフにするとセクションが非表示になります。

## 赤いドット

読むものや解決すべきものがあると、サイドバーのアイコンに赤いドットが表示されます。

- **未読のリリースノート**：新しいバージョンが利用可能で、そのノートをまだ開いていない状態です。デスクトップアプリでは、**バージョン更新を表示**がオンのときのみこのマーカーが表示されます。
- **ノードの競合**：カスタムノードマネージャーがインストール済みのカスタムノードに問題を検出しました。たとえば、ComfyUIまたはフロントエンドバージョンの不一致、インポートに失敗したノード、お使いのオペレーティングシステムやGPUでサポートされていないパッケージなどです。

ドットは、リリースノートを開いたとき、およびノードの競合を確認したときに消えます。
