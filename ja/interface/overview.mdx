ビジュアル UI は多くの人が [ComfyUI Server](/ja/development/comfyui-server/comms_overview) を操作する手段です。このページはワークスペースの地図です。各パネルの詳細はリンク先を参照してください。

![ComfyUI Basic Interface](/images/interface/overview/comfyui_new_interface.jpg)

[ComfyUI フロントエンド](https://github.com/Comfy-Org/ComfyUI_frontend) は独立プロジェクトとして保守されています。

## ローカリゼーション

英語、中国語、ロシア語、フランス語、日本語、韓国語に対応しています。**設定**を開き、`Comfy` → `Locale` で言語を選びます。

![ComfyUI Localization Support](/images/interface/overview/locale.jpg)

## ワークスペース地図

![ComfyUI Workspace](/images/interface/overview/comfyui-new-interface-main.png)

| 領域 | 内容 |
| --- | --- |
| **左サイドバー** | Assets、Node Library、Model Library、Workflows、Apps、（有効時）Job History |
| **キャンバス** | ノードを配置・接続するグラフ |
| **右サイドパネル** | 選択中のパラメータ、ノード情報、設定、エラー |
| **トップバー** | 開いているワークフロー、Run / キュー、ログイン、プロパティ切り替え |
| **左下** | Help Center、ボトムパネル、設定 |
| **右下** | キャンバス操作：パン、ミニマップ、リンク表示、ズーム、フィット |

## 旧メニュー

新メニューが既定です。旧メニューにするには、設定で `Comfy` → `Menu` → `Use new menu` を `disabled` にします。

<Note>
旧メニューは英語のみです。
</Note>
