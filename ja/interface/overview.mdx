ビジュアル UI は多くの人が [ComfyUI Server](/ja/development/comfyui-server/comms_overview) を操作する手段です。このページは UI の地図です。各領域とコンポーネントの詳細はリンク先を参照してください。

![ComfyUI Basic Interface](/images/interface/overview/comfyui_new_interface.jpg)

[ComfyUI フロントエンド](https://github.com/Comfy-Org/ComfyUI_frontend) は独立プロジェクトとして保守されています。

## ローカリゼーション

英語、中国語、ロシア語、フランス語、日本語、韓国語に対応しています。**設定**を開き、`Comfy` → `Locale` で言語を選びます。

![ComfyUI Localization Support](/images/interface/overview/locale.jpg)

## ワークスペース地図

![番号 1–6 付きの ComfyUI ワークスペース](/images/interface/overview/comfyui-new-interface-main.png)

スクリーンショットの番号は下表の領域に対応します：

| # | 領域 | 内容 |
| --- | --- | --- |
| **1** | **左サイドバー** | Assets、Node Library、Model Library、Workflows、Apps、（有効時）Job History |
| **2** | **キャンバス** | ノードを配置・接続するグラフとキャンバス操作 |
| **3** | **右サイドパネル** | 選択中のパラメータ、ノード情報、設定、エラー（トップバーのプロパティ切り替えで開く） |
| **4** | **トップバー** | 開いているワークフロー、Run / キュー、ログイン、プロパティ切り替え |
| **5** | **左下** | Help Center、ボトムパネル、設定 |
| **6** | **右下** | キャンバス操作：パン、ミニマップ、リンク表示、ズーム、フィット |
