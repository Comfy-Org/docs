**アプリ** エントリは、アセット、ノードライブラリ、モデルライブラリ、ワークフローの後に左サイドバーへ登録されます。パッケージ化されたワークフローアプリ、つまりファイルのサフィックスが `.app.json` である保存済みワークフローを一覧表示します。タブのタイトルには **ベータ** バッジが付きます。

このサイドバーのカタログは [アプリモード](/ja/interface/app-mode) とは別物です。アプリモードはワークフロー向けのリニアで簡略化された実行 UI です。アプリサイドバーは、パッケージ化されたアプリを見つけて開き、新しいアプリを作り始めるための空のワークフローを作成し、それらの `.app.json` ファイルを通常のワークフローと同じように管理する場所です。また、Comfy が提供する既製のツールを一覧表示する Comfy デスクトップの **アプリ** ページとも異なります。詳しくは [Comfy デスクトップのアプリ](/ja/installation/desktop/usage/apps) を参照してください。


![ベータバッジ、作成ボタン、ブラウズに並ぶ保存済みアプリを備えたアプリパネル](/images/desktop/usage/comfy-desktop-apps-page.png)

## アプリパネルを開く

左サイドバーの **アプリ** アイコンをクリックします。パネルは [ワークフロー](/ja/interface/workflows) と同じレイアウトを使用します。検索、任意の **開く** セクション（開いているワークフローがサイドバーに設定されている場合）、**お気に入り**、**ブラウズ** ですが、すべての一覧は `.app.json` ファイルのみにフィルタされます。

## 空の状態と作成

まだアプリが保存されていない場合、ブラウズ領域には短いメッセージと **アプリを作成** ボタンを備えた空の状態が表示されます。ブラウズ一覧に結果がある場合は、パネルのヘッダーにも **作成** ボタンが表示されます。どちらのアクションも **新しい空のワークフロー**（`Comfy.NewBlankWorkflow`）を実行し、アプリモード用に設定してアプリとして保存できる空のグラフを開きます。

## アプリの操作

フィルタされた一覧に対するアクションはワークフローパネルと同じです。

- アプリをクリックすると開きます。
- ブックマーク、名前の変更、削除、複製、ドラッグは通常のワークフローと同じように行えます。
- コンテキストメニューでは、**複製** は常に使用できます。**挿入** はアプリモード外で使用できます。

アプリを簡略化されたリニア UI で実際に実行するには、アプリを開いてアプリモードに入ります。入力と出力の構築、レイアウトのプレビュー、グラフ編集とアプリスタイルの表示の切り替えについては、[アプリモード](/ja/interface/app-mode) を参照してください。

## アプリとワークフロー、テンプレートの関係

| 画面 | 一覧表示される内容 |
| --- | --- |
| [ワークフロー](/ja/interface/workflows) | 通常の保存済みグラフ（および開いているタブ）。一般的には `.json` |
| **アプリ**（このページ） | `.app.json` で終わるパッケージ化されたアプリ |
| [テンプレート](/ja/interface/features/template) | **テンプレートを参照** から取得する公式およびコミュニティのスターターグラフ。ローカルのアプリライブラリではありません |
