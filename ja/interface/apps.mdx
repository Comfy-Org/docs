**Apps** エントリは Assets、Node Library、Model Library、Workflows の後に左サイドバーへ登録されます。パッケージ化されたワークフローアプリ（サフィックスが `.app.json` の保存済みワークフロー）を一覧します。タブタイトルには **Beta** バッジが付きます。

このサイドバーのカタログは [APP モード](/ja/interface/app-mode) とは別物です。APP モードはワークフロー向けの線形で簡略化された実行 UI です。Apps サイドバーはパッケージアプリの検索・開く、新規用の空白ワークフロー作成、通常のワークフローと同じ方法での `.app.json` 管理に使います。

## Apps パネルを開く

左サイドバーの **Apps** アイコンをクリックします。レイアウトは [ワークフロー](/ja/interface/workflows) と同じ（検索、任意の **Open**、**Bookmarks**、**Browse**）ですが、各一覧は `.app.json` のみにフィルタされます。

## 空状態と Create

アプリがまだないとき、Browse に空状態メッセージと **Create app** ボタンが出ます。Browse に結果があるときはヘッダーにも **Create** が出ます。どちらも **New Blank Workflow**（`Comfy.NewBlankWorkflow`）を実行し、APP モード用に構成してアプリとして保存できる空白グラフを開きます。

## アプリの操作

フィルタ後の一覧での操作は Workflows と同じです。

- クリックして開く。
- ブックマーク、名前変更、削除、複製、ドラッグ。
- コンテキストメニューでは **Duplicate** は常に利用可能。**Insert** は App Mode 外で利用可能。

簡略化された線形 UI で実行するには、開いて APP モードに入ります。入出力の構築、レイアウトプレビュー、グラフ編集とアプリ表示の切り替えは [APP モード](/ja/interface/app-mode) を参照してください。

## Workflows / Templates との関係

| 画面 | 一覧内容 |
| --- | --- |
| [ワークフロー](/ja/interface/workflows) | 通常の保存グラフ（と開いているタブ）。多くは `.json` |
| **アプリ**（このページ） | `.app.json` で終わるパッケージアプリ |
| [テンプレート](/ja/interface/features/template) | **Browse Templates** の公式・コミュニティ用スターター。ローカルアプリライブラリではない |
