左サイドバーの **Models** からモデルライブラリを開きます。起動後、`ComfyUI/models`（と追加パス）で検出されたモデルが一覧されます。

名前検索、フォルダ種別（checkpoints、LoRA、VAE など）での閲覧、キャンバスへのドラッグで対応ローダーノードを追加できます。

実行中に新しいファイルを入れた場合は `r`（またはメニューからノード定義の更新）で反映します。

## 今後の追記候補

- フォルダ種別とローダーの対応
- 検索・フィルタ
- キャンバスへのドロップと既存ローダーへのドロップ
- 不足モデルと右サイドパネルの Errors
- Cloud: [モデルのインポート](/ja/cloud/import-models) との関係
