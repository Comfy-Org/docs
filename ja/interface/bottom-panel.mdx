下部パネルはキャンバスの下にドッキングされたワークスペース用の帯です。どのビルドでもキーボードショートカットのリファレンスタブがあり、セルフホストと Desktop ビルドでは **ログ** ストリーム、Desktop アプリのみ **ターミナル** があります。Comfy Cloud はターミナルタブを登録しません。ショートカットは引き続き使用できます。


![ショートカットタブを開いた下部パネル。必須の一覧が表示されている](/images/interface/bottom-panel/bottom_panel_shortcuts.png)

![セルフホスト環境で、ログタブに ComfyUI プロセスのランタイム出力が流れている](/images/interface/bottom-panel/bottom_panel_logs.png)

## パネルを開く

下部パネルはいくつかの方法で開けます。

- **ショートカット**: 左サイドバー下部付近のキーボードアイコンをクリックします（`Workspace.ToggleBottomPanel.Shortcuts`、既定は `Ctrl` + `Shift` + `K`）。これはショートカットパネルだけを切り替えます。
- **コンソール / ターミナルパネル**（非 Cloud）: 左サイドバー下部付近のターミナルアイコンをクリックします。これは **下部パネルを切り替え** を実行し、ログ/ターミナルタブが読み込まれていればターミナルパネルを優先し、そうでなければショートカットにフォールバックします。
- **表示** メニュー: **下部パネル**（`Workspace.ToggleBottomPanel`）。
- **ログのショートカット**（非 Cloud）: 既定の `Ctrl` + `` ` `` でログタブを切り替えます（`Workspace.ToggleBottomPanelTab.logs-terminal`）。

[フォーカスモード](/ja/interface/canvas-controls)がオンの間はパネルは隠れます。

## ショートカットタブ

ショートカットパネルには 2 つのタブが登録されます。

- **必須**: よく使う編集とキューのショートカット。
- **ビューコントロール**: ナビゲーションと表示に関するショートカット。

これらのパネルは、設定 → キーバインディングでカスタマイズできるのと同じコマンド/キーバインディングデータを反映しています。編集可能な一覧は[ショートカット](/ja/interface/shortcuts)を参照してください。

## ログ（セルフホストと Desktop）

非 Cloud ビルドでは、**ログ** タブに ComfyUI プロセスのランタイムログ出力が流れます。カスタムノード、サーバーエラー、バックエンドのメッセージをデバッグするときに、外部ターミナルへ切り替えずに使えます。

既定のショートカット: `Ctrl` + `` ` ``。

## ターミナル（Desktop のみ）

**Desktop** アプリでは、**ターミナル**（コマンドターミナル）タブがログの隣に登録されます。Desktop ユーザー向けのアプリ内シェルを提供します。ブラウザのみのセルフホストセッションや Comfy Cloud では登録されません。

![Desktop のターミナルタブ。ログの隣にアプリ内シェルが表示されている](/images/interface/bottom-panel/bottom_panel_terminal.png)

Cloud ビルドはログとターミナルの登録を完全にスキップし、ショートカットのみが残ります。
