ボトムパネルは左下コントロール、または View の `Workspace.ToggleBottomPanel` から開きます。主なタブ：

- **Shortcuts**：キーバインド一覧（[Shortcuts](/ja/interface/shortcuts) と同じデータ）
- **Logs**：非 Cloud ビルドの実行ログ
- **Command Terminal**：**Desktop** のみ

**Comfy Cloud** ではターミナルタブは登録されません。Shortcuts は残ります。
