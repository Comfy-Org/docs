下部パネルはキャンバス下にドックされるワークスペース帯です。どのビルドでもキーボードショートカット参照タブを備え、セルフホストと Desktop では **Logs** ストリーム、**Terminal** は Desktop アプリのみ登録されます。Comfy Cloud はターミナル系タブを登録しません。Shortcuts は利用できます。


![下部パネルの Shortcuts タブ。Essentials の一覧が表示される](/images/interface/bottom-panel/bottom_panel_shortcuts.png)

![セルフホスト環境で、Logs タブに ComfyUI プロセスの実行ログが流れる](/images/interface/bottom-panel/bottom_panel_logs.png)

## パネルを開く

下部パネルは次の方法で開けます。

- **Shortcuts**: 左サイドバー下部付近のキーボードアイコン（`Workspace.ToggleBottomPanel.Shortcuts`、既定 `Ctrl` + `Shift` + `K`）。ショートカットパネル専用の切替です。
- **Console / ターミナルパネル**（非 Cloud）: 左サイドバー下部付近のターミナルアイコン。**Toggle Bottom Panel** を実行し、Logs/Terminal タブが読み込み済みならターミナルパネルを優先、そうでなければ Shortcuts にフォールバックします。
- **View** メニュー: **Bottom Panel**（`Workspace.ToggleBottomPanel`）。
- **Logs ショートカット**（非 Cloud）: 既定 `Ctrl` + `` ` `` で Logs タブ（`Workspace.ToggleBottomPanelTab.logs-terminal`）を切り替えます。

[フォーカスモード](/ja/interface/canvas-controls) がオンの間はパネルが隠れます。

## Shortcuts タブ

Shortcuts は **shortcuts** パネルに 2 つのタブを登録します。

- **Essentials**: よく使う編集とキューのショートカット。
- **View Controls**: ナビゲーションと表示関連のショートカット。

これらのパネルは、設定 → キーバインディングでカスタマイズできるのと同じコマンド/キーバインディングデータを反映しています。編集可能な一覧は [ショートカット](/ja/interface/shortcuts) を参照してください。

## Logs（セルフホストと Desktop）

非 Cloud ビルドでは **Logs** タブが ComfyUI プロセスのランタイムログ出力を流します。カスタムノードやサーバーエラー、バックエンドメッセージを、外部ターミナルへ切り替えずにデバッグしたいときに使います。

既定のショートカット: `Ctrl` + `` ` ``。

## Terminal（Desktop のみ）

**Desktop** アプリでは、Logs の隣に **Terminal**（コマンドターミナル）タブが登録されます。Desktop ユーザー向けのアプリ内シェルを提供します。純粋なブラウザのセルフホストセッションや Comfy Cloud では登録されません。

![Desktop の Terminal タブ。Logs の隣にアプリ内シェルを表示](/images/interface/bottom-panel/bottom_panel_terminal.png)

Cloud ビルドは Logs と Terminal の登録を完全にスキップし、Shortcuts のみが残ります。
