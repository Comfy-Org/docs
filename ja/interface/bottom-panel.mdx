下部パネルはキャンバスの下にドッキングされたワークスペース帯です。どのビルドでもキーボードショートカットの参照タブがあり、セルフホストビルドと Desktop ビルドでは **ログ** のストリーム、Desktop アプリのみ **ターミナル** があります。Comfy Cloud はターミナルタブを登録しませんが、ショートカットは引き続き利用できます。


![ショートカットタブを開いた下部パネル。必須の一覧が表示されている](/images/interface/bottom-panel/bottom_panel_shortcuts.png)

![セルフホスト環境で、ログタブに ComfyUI プロセスのランタイム出力が流れている様子](/images/interface/bottom-panel/bottom_panel_logs.png)

## パネルを開く

下部パネルはいくつかの方法で開けます。

- **ショートカット**: 左サイドバーの下部付近にあるキーボードアイコンをクリックします（`Workspace.ToggleBottomPanel.Shortcuts`、既定 `Ctrl` + `Shift` + `K`）。これはショートカットパネル専用の切り替えです。
- **コンソール / ターミナルパネル**（非 Cloud）: 左サイドバーの下部付近にあるターミナルアイコンをクリックします。**下部パネルを切り替え** が実行され、ログ/ターミナルタブが読み込まれていればターミナルパネルを優先し、そうでなければショートカットにフォールバックします。
- **View** メニュー: **下部パネル**（`Workspace.ToggleBottomPanel`）。
- **ログのショートカット**（非 Cloud）: 既定 `Ctrl` + `` ` `` でログタブを切り替えます（`Workspace.ToggleBottomPanelTab.logs-terminal`）。

[フォーカスモード](/ja/interface/canvas-controls) がオンの間はパネルは隠れます。

## ショートカットタブ

ショートカットは **shortcuts** パネルに 2 つのタブを登録します。

- **必須**: 一般的な編集とキューのショートカット。
- **ビューコントロール**: ナビゲーションと表示に関連するショートカット。

これらのパネルは、設定 → キーバインディングでカスタマイズできるのと同じコマンド/キーバインディングデータを反映しています。編集可能な完全な一覧は [ショートカット](/ja/interface/shortcuts) を参照してください。

## ログ（セルフホストと Desktop）

非 Cloud ビルドでは、**ログ**タブが ComfyUI プロセスのランタイムログ出力をストリーミング表示します。カスタムノード、サーバーエラー、バックエンドのメッセージをデバッグするときに、外部ターミナルへ切り替えずに使えます。

既定のショートカット: `Ctrl` + `` ` ``。

## ターミナル（Desktop のみ）

**Desktop** アプリでは、**ターミナル**（コマンドターミナル）タブがログの隣に登録されます。Desktop ユーザー向けのアプリ内シェルを提供します。ブラウザのみのセルフホストセッションや Comfy Cloud では登録されません。

![Desktop のターミナルタブ。ログの隣にアプリ内シェルが表示されている](/images/interface/bottom-panel/bottom_panel_terminal.png)

Cloud ビルドはログとターミナルの登録を両方ともスキップし、ショートカットのみが残ります。
