## リンクはノードを接続する

ComfyUIでは、ノード間に描かれる線や曲線を **_リンク_**（**_接続_** またはワイヤとも呼ばれます）と呼びます。リンクはあるノードの出力から別のノードの入力へデータを運び、ワークフローの流れを定義します。

以下の操作はすべて、同じ対象を操作します。対象は、ノードの端にある色付きのサークルです。出力は右端、入力は左端にあります。

### 2つのノードを接続する

出力ポートから同じ色の入力ポートへドラッグします。ドラッグ中は互換性のあるポートが強調表示され、離すとリンクがスナップします。

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/connect-two-nodes.mp4"
></video>

色はデータ型を表すため、同じ色のポート同士だけが接続できます。[色分け](#カラーコーディング)を参照してください。

### 空のキャンバスにリンクをドロップする

キャンバス上の何もない場所でリンクを離すと、ノード追加用の検索が開き、すでにドラッグ中のデータ型で絞り込まれています。ノードを選ぶと、接続された状態でそのノードが作成されます。

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/release-on-empty-search.mp4"
></video>

![ドラッグ中のデータ型で絞り込まれたノード追加検索](/images/basic-concepts/links/add-node-search.png)

代わりに、離すときに `Shift` を押したままにすると、コンテキストメニューが表示されます。**ノードを追加**、**リルートを追加**、**検索**、およびそのデータを受け取れるノードタイプが並びます。

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/release-shift-context-menu.mp4"
></video>

![Shift を押しながらリンクを離したときのコンテキストメニュー](/images/basic-concepts/links/release-context-menu.png)

どちらの動作も **設定 → Lite Graph → リンク解除** で設定できます。修飾キーなしの解除用と `Shift` 用の2つの項目があります。

### リンクを隠す、または削除する

リンクを右クリックすると、そのリンクのメニューが開きます。

- **リンクを隠す** は接続を維持し、ワイヤだけを隠すため、データは引き続き流れます
- **削除** は接続を削除します
- **リルートを追加** はワイヤ上にリルートポイントを配置します
- **ノードを追加** はリンクにノードを挿入します

![リンクのコンテキストメニュー](/images/basic-concepts/links/link-menu.png)

### すべてのリンクを隠す

キャンバスツールバーのリンク表示切り替えを使うと、ワークフローを変更せずにすべてのワイヤを一度に隠せます。これは **リンクレンダーモード** を **隠す** に設定するのと同じで、再びオンにすると以前のスタイルに戻ります。

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/hide-links.mp4"
></video>

<Tip>
リンクを表示することは、ワークフローを学習したり、共有したり、デバッグしたりするときに特に役立ちます。データの流れを一目で確認できるようになります。編集する予定のない完成済みのワークフローでは、リンクを隠すことで見た目の煩雑さを軽減できます。
</Tip>

### リンクをリルートする

ワークフローが複雑になると、ワイヤが重なったり、ノードの背後を通ったりします。リンクメニューの **リルートを追加** を使うと、ワイヤ上にネイティブのリルートポイントが配置されます。このポイントを任意の場所にドラッグすると、他のノードを避けるようにワイヤを引き回せます。

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/link-menu-reroute.mp4"
></video>

ComfyUIには **リルート**ノードも同梱されており、グループに入れたり、バイパスしたり、再利用したりできる明示的なノードで同じ役割を果たします。新しいワークフローでは、ネイティブのリルートポイントで十分です。

![ComfyUI リルートノード](/images/interface/link/reroute.jpg)

## リンクレンダーモード

リンクは、曲線、直角、直線で描画したり、完全に非表示にしたりできます。

![リンクスタイル](/images/interface/link/link_styles.jpg)

スタイルは **設定 → Lite Graph → グラフ → リンクレンダーモード** で変更するか、キャンバスツールバーからリンクの表示切り替えを行えます。

![レンダーモード設定](/images/interface/link/render_mode.jpg)

## カラーコーディング

ComfyUI の各データ型には、それぞれ異なる色が割り当てられています。ノードの入力ポートと出力ポート、そしてそれらをつなぐ接続線は、すべてこの配色に従っています。**接続できるのは同じ色のポート同士だけです**。これにより、ワークフロー全体で型の安全性が保たれます。

![ComfyUI のノードのデータ型](/images/concepts/node/data_type.jpg)

| データ型                  | 色          |
|---------------------------|-------------|
| 拡散モデル                | ラベンダー  |
| CLIP モデル               | 黄色        |
| VAE モデル                | ローズ      |
| 条件付け                  | オレンジ    |
| 潜在画像                  | ピンク      |
| ピクセル画像              | 青          |
| マスク                    | 緑          |
| 数値（整数または浮動小数点） | グレー   |
| メッシュ                  | 明るい緑    |
