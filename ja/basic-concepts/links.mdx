## ノードを接続するリンク

ComfyUI では、ノード間に描かれる線や曲線は**_リンク_**と呼ばれます（**_接続_**やワイヤーとも呼ばれます）。リンクは、あるノードの出力から別のノードの入力へデータを運び、ワークフローの流れを定義します。

リンクは、曲線、直角、直線、または完全に非表示など、いくつかの視覚的なスタイルで表示できます。

![リンクスタイル](/images/interface/link/link_styles.jpg)

リンクスタイルを変更するには、**設定メニュー** → **表示 (Lite Graph)** → **グラフ** → **リンクレンダーモード**に移動します。

![レンダリングモード設定](/images/interface/link/render_mode.jpg)

**キャンバスメニュー**からすべてのリンクを一時的に非表示にすることもできます。

![キャンバスメニュー](/images/interface/link/canvas_menu.jpg)

<Tip>
リンクの表示は、ワークフローを学習するとき、共有するとき、デバッグするときにとくに役立ちます。データの流れを一目で確認できます。編集する予定のない完成したワークフローでは、リンクを非表示にすることで視覚的な煩雑さを減らせます。
</Tip>

### リルートノード

ワークフローが複雑になると、リンクのワイヤーが重なったりノードの背後を通ったりして、読みづらくなることがあります。**リルート**ノードを使うと、グラフの 2D 空間内の任意の点を経由するようにワイヤーを手動で引き回すことができ、レイアウトを整理された読みやすい状態に保てます。

![ComfyUI リルートノード](/images/interface/link/reroute.jpg)

ComfyUI には、グラフキャンバスに組み込みのネイティブなリルート機能もあります。新しいワークフローでは、こちらを使うことをお勧めします。

![ComfyUI ネイティブリルート](/images/interface/link/native_reroute.jpg)

## 色分け

ComfyUI のすべてのデータタイプには、それぞれ固有の色があります。ノードの入力ポートと出力ポート、およびそれらを接続するリンクのワイヤーは、すべてこの配色を共有しています。**同じ色のポート同士しか接続できません**。これにより、ワークフロー全体で型の安全性が確保されます。

![ComfyUI ノードデータタイプ](/images/concepts/node/data_type.jpg)

| データタイプ | 色 |
|---------------------------|-------------|
| 拡散モデル | ラベンダー |
| CLIP モデル | 黄色 |
| VAE モデル | ローズ |
| 条件付け | オレンジ |
| 潜在画像 | ピンク |
| ピクセル画像 | 青 |
| マスク | 緑 |
| 数値（整数または浮動小数点） | ライトグリーン |
| メッシュ | 明るい緑 |
