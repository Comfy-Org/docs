Topaz Image Enhance ノードは、業界標準のアップスケーリングと画像エンハンスメントを提供します。クラウドベースの AI モデルを使用して単一の入力画像を処理し、品質、ディテール、解像度を向上させます。このノードでは、クリエイティブなガイダンス、被写体へのフォーカス、顔の保持などのオプションを含め、エンハンスメントプロセスを詳細に制御できます。

このノードはレガシーバージョンであり、インターフェース上で非推奨としてマークされています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 画像エンハンスメントに使用する AI モデルです。 | COMBO | はい | `"Reimagine"` |
| `画像` | エンハンスする入力画像です。サポートされる画像は 1 枚だけです。 | IMAGE | はい | - |
| `プロンプト` | クリエイティブなアップスケーリングのガイダンス用の任意のテキストプロンプトです（デフォルト: 空）。 | STRING | いいえ | - |
| `被写体検出` | 画像のどの部分にエンハンスメントを集中させるかを制御します（デフォルト: "All"）。 | COMBO | いいえ | `"All"`<br />`"Foreground"`<br />`"Background"` |
| `顔強化` | 処理中に顔（存在する場合）をエンハンスします（デフォルト: True）。 | BOOLEAN | いいえ | - |
| `顔強化クリエイティビティ` | 顔エンハンスメントのクリエイティビティレベルを設定します（デフォルト: 0.0）。 | FLOAT | いいえ | 0.0 - 1.0 |
| `顔強化の強度` | エンハンスされた顔が背景に対してどれだけシャープになるかを制御します（デフォルト: 1.0）。 | FLOAT | いいえ | 0.0 - 1.0 |
| `クロップしてフィル` | デフォルトでは、出力アスペクト比が異なる場合、画像はレターボックス化されます。有効にすると、出力寸法を埋めるように画像をクロップします（デフォルト: False）。 | BOOLEAN | いいえ | - |
| `出力幅` | ゼロの値は自動計算を意味します（通常は元のサイズ、または指定されている場合は output_height になります）（デフォルト: 0）。 | INT | いいえ | 0 - 32000 |
| `出力高さ` | ゼロの値は、元の高さ、または output width と同じ高さで出力することを意味します（デフォルト: 0）。 | INT | いいえ | 0 - 32000 |
| `クリエイティビティ` | エンハンスメント全体のクリエイティビティレベルを制御します（デフォルト: 3）。 | INT | いいえ | 1 - 9 |
| `顔の保持` | 被写体の顔の同一性を保持します（デフォルト: True）。 | BOOLEAN | いいえ | - |
| `色の保持` | 元の色を保持します（デフォルト: True）。 | BOOLEAN | いいえ | - |

**注意:** このノードは単一の入力画像のみを処理できます。複数の画像のバッチを指定するとエラーになります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | エンハンスされた出力画像です。 | IMAGE |
