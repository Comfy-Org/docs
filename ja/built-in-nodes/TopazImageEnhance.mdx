Topaz Image Enhance ノードは、業界標準のアップスケーリングと画像強調を提供します。クラウドベースのAIモデルを使用して単一の入力画像を処理し、品質、ディテール、解像度を向上させます。このノードは、クリエイティブなガイダンス、被写体へのフォーカス、顔の保存など、強調処理を細かく制御するためのオプションを提供します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 画像強調に使用するAIモデル。 | COMBO | はい | `"Reimagine"` |
| `画像` | 強調する入力画像。サポートされる画像は1枚のみです。 | IMAGE | はい | - |
| `プロンプト` | クリエイティブなアップスケーリングのガイダンスに使用するオプションのテキストプロンプト（デフォルト: 空）。 | STRING | いいえ | - |
| `被写体検出` | 強調処理が焦点を当てる画像の部分を制御します（デフォルト: "All"）。 | COMBO | いいえ | `"All"`<br />`"Foreground"`<br />`"Background"` |
| `顔強化` | 処理中に（存在する場合）顔を強調します（デフォルト: True）。 | BOOLEAN | いいえ | - |
| `顔強化クリエイティビティ` | 顔強調のクリエイティビティレベルを設定します（デフォルト: 0.0）。 | FLOAT | いいえ | 0.0 - 1.0 |
| `顔強化の強度` | 背景に対する強調された顔のシャープネスを制御します（デフォルト: 1.0）。 | FLOAT | いいえ | 0.0 - 1.0 |
| `クロップしてフィル` | デフォルトでは、出力のアスペクト比が異なる場合、画像はレターボックス表示されます。有効にすると、出力サイズに合わせて画像が切り抜かれます（デフォルト: False）。 | BOOLEAN | いいえ | - |
| `出力幅` | ゼロの場合は自動計算されます（通常は元のサイズ、または output_height が指定されている場合はその値になります）（デフォルト: 0）。 | INT | いいえ | 0 - 32000 |
| `出力高さ` | ゼロの場合は元の高さ、または出力幅と同じ高さで出力されます（デフォルト: 0）。 | INT | いいえ | 0 - 32000 |
| `クリエイティビティ` | 強調処理の全体的なクリエイティビティレベルを制御します（デフォルト: 3）。 | INT | いいえ | 1 - 9 |
| `顔の保持` | 被写体の顔のアイデンティティを保持します（デフォルト: True）。 | BOOLEAN | いいえ | - |
| `色の保持` | 元の色を保持します（デフォルト: True）。 | BOOLEAN | いいえ | - |

**注:** このノードは単一の入力画像のみ処理できます。複数の画像のバッチを指定するとエラーが発生します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 強調処理された出力画像。 | IMAGE |
