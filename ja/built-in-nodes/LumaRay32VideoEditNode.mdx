## 概要

このノードは、Luma Ray 3.2 を使用して、新しいプロンプトで既存の動画を再レンダリングします。これにより、元の動きを保ちながら、スタイル変更、ライティング変更、要素の追加または削除ができます。ソース動画は最大18秒までで、編集後の動画はソースの元の長さを保持します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `ビデオ` | 編集するソース動画。最大18秒。 | VIDEO | はい | - |
| `プロンプト` | 目的の編集内容を説明します。 | STRING | はい | - |
| `解像度` | 編集後の動画の出力解像度。(デフォルト: "720p") | COMBO | はい | `"360p"`<br />`"540p"`<br />`"720p"`<br />`"1080p"` |
| `強度` | ソースをどの程度保持するか、または再解釈するかの強さ。"auto" は Ray 3.2 に選択させます。adhere_* は最も保持し、flex_* はバランスが取れており、reimagine_* は最も大きく変更します。(デフォルト: "auto") | COMBO | はい | `"auto"`<br />`"adhere_1"`<br />`"adhere_2"`<br />`"adhere_3"`<br />`"flex_1"`<br />`"flex_2"`<br />`"flex_3"`<br />`"reimagine_1"`<br />`"reimagine_2"`<br />`"reimagine_3"` |
| `シード` | 再現性のためのシード。 | INT | はい | - |

**注:** `prompt` は 1～6000 文字である必要があります。ソース動画の長さは 18 秒を超えてはいけません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `VIDEO` | 編集後の動画出力。 | VIDEO |
| `generation_id` | 生成リクエストの一意の識別子。 | STRING |
