このノードは、TripoのAPIを使用して、オブジェクトの異なるビュー（正面、左、背面、右）を表示する最大4枚の画像を処理し、3Dモデルを同期的に生成します。3Dモデルを構築するには、正面画像と少なくとも1つの追加ビュー（左、背面、または右）が必要です。テクスチャ、PBRマテリアル、ジオメトリ品質、出力形式はノードから制御できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | オブジェクトの正面ビュー画像。 | IMAGE | はい | - |
| `image_left` | オブジェクトの左ビュー画像。 | IMAGE | いいえ | - |
| `image_back` | オブジェクトの背面ビュー画像。 | IMAGE | いいえ | - |
| `image_right` | オブジェクトの右ビュー画像。 | IMAGE | いいえ | - |
| `model_version` | 生成に使用するモデルバージョン。 | COMBO | いいえ | 複数のオプションが利用可能 |
| `orientation` | 3Dモデルの向き設定（デフォルト: `"default"`）。 | COMBO | いいえ | 複数のオプションが利用可能 |
| `texture` | テクスチャマップを生成します。オフにするとベアジオメトリを返し、pbr を無視します。（デフォルト: True） | BOOLEAN | いいえ | - |
| `pbr` | PBRマテリアルマップ（ベースカラー、メタリック、ラフネス、ノーマル）。texture が必要です。（デフォルト: True） | BOOLEAN | いいえ | - |
| `model_seed` | モデル生成用のランダムシード（デフォルト: 42）。 | INT | いいえ | 0～2,147,483,647 |
| `texture_seed` | テクスチャ生成用のランダムシード（デフォルト: 42）。 | INT | いいえ | 0～2,147,483,647 |
| `texture_quality` | テクスチャ生成の品質レベル（デフォルト: `"standard"`）。`"detailed"` = HDテクスチャ、`"extreme"` = 8K Ultraテクスチャ。 | COMBO | いいえ | `"standard"`<br />`"detailed"`<br />`"extreme"` |
| `texture_alignment` | テクスチャをモデルに位置合わせするために使用する方法（デフォルト: `"original_image"`）。 | COMBO | いいえ | `"original_image"`<br />`"geometry"` |
| `face_limit` | 最大面数。-1 で Tripo が適応的に選択します（v3.x standard で約140万面、detailed で200万面）。Tripo は黙ってクランプします：v2.5 では 500,000、クアッドメッシュでは 150,000。（デフォルト: -1） | INT | いいえ | -1～2,000,000 |
| `quad` | クアッドメッシュ出力。Tripo はクアッドメッシュを FBX として提供するため、結果は FBX 出力に渡され、GLB 出力は空のままです。（デフォルト: False） | BOOLEAN | いいえ | - |
| `ジオメトリ品質` | ジオメトリ生成の品質レベル（デフォルト: `"standard"`）。 | COMBO | いいえ | `"standard"`<br />`"detailed"` |
| `smart_low_poly` | クリーンで手作り風のトポロジーを持つ低ポリメッシュ（500～20,000面、クアッドは500～10,000面）。単純な被写体に最適ですが、複雑な被写体では失敗する可能性があります。（デフォルト: False） | BOOLEAN | いいえ | - |
| `auto_size` | テクスチャ付きモデルを実世界のサイズ（メートル）にスケーリングします。Tripo はサイズをモデルのシーン変換として保存し、モデルが変換、リグ、リターゲットされるときにベイクします。テクスチャがない場合は無視されます。（デフォルト: False） | BOOLEAN | いいえ | - |

**注:** 正面画像（`image`）は常に必須であり、`image_left`、`image_back`、または `image_right` のうち少なくとも1つも指定する必要があります。`texture` をオフにすると、`pbr` はテクスチャを必要とするため、`pbr` も自動的にオフになります。`smart_low_poly` が有効で、`face_limit` が -1 のままでない場合、`face_limit` は三角形メッシュでは 500～20,000、クアッドメッシュでは 500～10,000 の間である必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `モデルファイル` | 生成された3Dモデルのファイルパスまたは識別子（後方互換性のみ）。 | STRING |
| `モデルタスクID` | モデル生成プロセスを追跡するためのタスク識別子。 | MODEL_TASK_ID |
| `GLB` | 生成された3Dモデルファイル（GLB形式）。`quad` が有効な場合は空になります。 | FILE3DGLB |
| `FBX` | 生成された3Dモデルファイル（FBX形式）。`quad` が有効な場合にのみ設定されます。 | FILE3DFBX |
