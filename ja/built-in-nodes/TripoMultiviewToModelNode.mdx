このノードは、Tripo の API を使用して、オブジェクトの異なるビュー（前面、左面、背面、右面）を示す最大4枚の画像を処理し、3Dモデルを同期的に生成します。3Dモデルを構築するには、前面画像と、左面・背面・右面のうち少なくとも1つの追加ビューが必要です。テクスチャ、PBRマテリアル、ジオメトリ品質、出力形式はノードから制御できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | オブジェクトの前面ビュー画像です。 | IMAGE | 必須 | - |
| `image_left` | オブジェクトの左面ビュー画像です。 | IMAGE | 任意 | - |
| `image_back` | オブジェクトの背面ビュー画像です。 | IMAGE | 任意 | - |
| `image_right` | オブジェクトの右面ビュー画像です。 | IMAGE | 任意 | - |
| `model_version` | 生成に使用するモデルバージョンです。 | COMBO | 任意 | 選択肢は複数あります |
| `orientation` | 3Dモデルの向きの設定です（デフォルト: `"default"`）。 | COMBO | 任意 | 選択肢は複数あります |
| `texture` | テクスチャマップを生成します。オフにすると素のジオメトリが返され、pbr は無視されます（デフォルト: True）。 | BOOLEAN | 任意 | - |
| `pbr` | PBRマテリアルマップ（ベースカラー、メタリック、ラフネス、ノーマル）です。テクスチャが必要です（デフォルト: True）。 | BOOLEAN | 任意 | - |
| `model_seed` | モデル生成用のランダムシードです（デフォルト: 42）。 | INT | 任意 | 0 ～ 2,147,483,647 |
| `texture_seed` | テクスチャ生成用のランダムシードです（デフォルト: 42）。 | INT | 任意 | 0 ～ 2,147,483,647 |
| `texture_quality` | テクスチャ生成の品質レベルです（デフォルト: `"standard"`）。`"detailed"` は HD テクスチャ、`"extreme"` は 8K Ultra テクスチャです。 | COMBO | 任意 | `"standard"`<br />`"detailed"`<br />`"extreme"` |
| `texture_alignment` | テクスチャをモデルに位置合わせする方法です（デフォルト: `"original_image"`）。 | COMBO | 任意 | `"original_image"`<br />`"geometry"` |
| `face_limit` | 最大面数です。-1 を指定すると、Tripo が適応的に選択します（v3.x standard では約140万面、detailed では200万面）。Tripo は制限を自動適用します（v2.5 では 500,000、クアッドメッシュでは 150,000）。デフォルト: -1 | INT | 任意 | -1 ～ 2,000,000 |
| `quad` | クアッドメッシュ出力です。Tripo はクアッドメッシュを FBX として提供するため、結果は FBX 出力に格納され、GLB 出力は空のままになります（デフォルト: False）。 | BOOLEAN | 任意 | - |
| `ジオメトリ品質` | ジオメトリ生成の品質レベルです（デフォルト: `"standard"`）。 | COMBO | 任意 | `"standard"`<br />`"detailed"` |
| `smart_low_poly` | クリーンで手作業風トポロジーのローポリメッシュです（500〜20,000 フェイス、クアッドは 500〜10,000）。単純な対象に最適で、複雑な対象では失敗する場合があります（デフォルト: False）。 | BOOLEAN | 任意 | - |
| `auto_size` | テクスチャ付きモデルをメートル単位の実寸にスケーリングします。Tripo はサイズをモデルのシーントランスフォームとして保存し、モデルの変換、リギング、リターゲティングの際に焼き込みます。テクスチャなしの場合は無視されます（デフォルト: False）。 | BOOLEAN | 任意 | - |

**注:** 前面画像（`image`）は常に必須です。さらに、`image_left`、`image_back`、`image_right` のうち少なくとも1つも指定する必要があります。`texture` をオフにすると、`pbr` はテクスチャを必要とするため、自動的に `pbr` もオフになります。`smart_low_poly` が有効で、`face_limit` が -1 以外の場合、`face_limit` は三角形メッシュでは 500〜20,000、クアッドメッシュでは 500〜10,000 の範囲でなければなりません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `モデルファイル` | 生成された3Dモデルのファイルパスまたは識別子です（後方互換性のため）。 | STRING |
| `モデルタスクID` | モデル生成プロセスを追跡するためのタスク識別子です。 | MODEL_TASK_ID |
| `GLB` | 生成された3Dモデルの GLB 形式ファイルです。`quad` が有効な場合は空になります。 | FILE3DGLB |
| `FBX` | 生成された3Dモデルの FBX 形式ファイルです。`quad` が有効な場合にのみ値が設定されます。 | FILE3DFBX |
