Recraft V4 および V4.1 モデルを使用して、テキストプロンプトから画像を生成します。プロンプトと選択した設定を Recraft API に送信し、生成された画像または画像群を返します。スタイル参照画像を使用する場合、作成されたスタイル ID も返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 生成に使用するモデルです。recraftv4_styles モデルはスタイル一貫性のある生成向けに構築されており、常に style_id または style_references が必要です。`recraftv4_1_flash` は最速かつ最も低コストなモデルで、スタイルをまったくサポートしません。 | DYNAMIC_COMBO | はい | "recraftv4_1"<br />"recraftv4_1_flash"<br />"recraftv4_1_utility"<br />"recraftv4_1_pro"<br />"recraftv4_1_utility_pro"<br />"recraftv4"<br />"recraftv4_pro"<br />"recraftv4_styles"<br />"recraftv4_styles_pro" |
| `prompt` | 画像生成用のプロンプトです。最大 10,000 文字です。 | STRING | はい | 1～10000文字 |
| `negative_prompt` | この入力は無視されます。Recraft V4 および V4.1 モデルではネガティブプロンプトはサポートされていません。 | STRING | はい | N/A |
| `n` | 生成する画像の数です（デフォルト: 1）。 | INT | はい | 1～6 |
| `seed` | ノードを再実行するかどうかを決めるためのシードです。シードに関係なく、実際の結果は非決定的です（デフォルト: 0）。 | INT | はい | 0～18446744073709551615 |
| `recraft_controls` | Recraft Controls ノードを介した、生成に対する任意の追加コントロールです。 | CUSTOM | いいえ | N/A |
| `style_id` | 適用する Recraft V4 スタイルの UUID です（例: Recraft V4 Create Style ノード、または前回の実行の style_id 出力から取得）。style_references と組み合わせることはできません（デフォルト: 空）。 | STRING | いいえ | 有効な UUID 文字列 |
| `style_match` | スタイルにどの程度忠実に従うかです。precise は細部まで再現し、flexible は全体的な見た目に合わせます。スタイルが指定された場合にのみ使用されます（デフォルト: "precise"）。 | COMBO | いいえ | "precise"<br />"flexible" |

### recraftv4_1、recraftv4_1_flash、recraftv4_1_utility、recraftv4、および recraftv4_styles 入力

これらのモデルは同じ `size` パラメータを共有します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `size` | 生成される画像のサイズです（デフォルト: "1024x1024"）。 | COMBO | はい | 複数のオプションが利用可能（標準の Recraft V4 サイズ、"1024x1024" を含む） |

### recraftv4_1_pro、recraftv4_1_utility_pro、recraftv4_pro、および recraftv4_styles_pro 入力

これらのモデルは同じ `size` パラメータを共有します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `size` | 生成される画像のサイズです（デフォルト: "2048x2048"）。 | COMBO | はい | 複数のオプションが利用可能（pro Recraft V4 サイズ、"2048x2048" を含む） |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `style_references` | オンザフライでスタイルを作成するための参照画像です。生成とは別に課金されます。作成されたスタイルは再利用のために style_id として返されます。style_id と組み合わせることはできません。拡張可能スロット: 1..N 個の画像を接続します（style_reference_1、style_reference_2、...）。 | IMAGE | いいえ | 0 ～ Recraft API で許可される参照画像の最大数。合計エンコードサイズは 10 MB を超えてはなりません |

**注記:** `size` パラメータは動的入力であり、利用可能なオプションは選択した `model` によって変わります。`recraftv4_styles` および `recraftv4_styles_pro` モデルでは常にスタイルが必要です。スタイル参照画像を接続するか、`style_id` を指定してください。`style_id` 入力と `style_references` 入力は相互排他的です。いずれか一方のみを指定してください。`style_id` は有効な UUID である必要があります。`style_match` 入力は、スタイルが指定された場合にのみ使用されます。スタイル参照画像には生成とは別に課金され、それらの合計エンコードサイズは 10 MB を超えてはなりません。`seed` 値は画像出力の再現性を保証しません。Infinite Style Library のスタイル ID を使用する場合は、Vector art スタイルではないことを確認してください。Vector art スタイルの場合、画像ではなく SVG データが返されることがあります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された画像、または画像のバッチです。 | IMAGE |
| `style_id` | この生成で使用または作成されたスタイル ID です。スタイル参照画像が提供された場合、作成されたスタイルは再利用のためにここに返されます。スタイルが使用されていない場合は空文字列です。 | STRING |
