Recraft V4 および V4.1 モデルを使用して、テキストプロンプトから画像を生成します。プロンプトと選択した設定を Recraft API に送信し、生成された画像（1 枚または複数枚）を返します。スタイル参照画像を使用した場合は、作成されたスタイル ID も返されます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 生成に使用するモデルです。recraftv4_styles モデルはスタイル一貫性のある生成用に作られており、常に style_id または style_references が必要です。 | DYNAMIC_COMBO | はい | "recraftv4_1"<br />"recraftv4_1_utility"<br />"recraftv4_1_pro"<br />"recraftv4_1_utility_pro"<br />"recraftv4"<br />"recraftv4_pro"<br />"recraftv4_styles"<br />"recraftv4_styles_pro" |
| `prompt` | 画像生成用のプロンプトです。最大 10,000 文字。 | STRING | はい | 1～10000文字 |
| `negative_prompt` | この入力は無視されます。ネガティブプロンプトは Recraft V4 および V4.1 モデルではサポートされていません。 | STRING | はい | N/A |
| `n` | 生成する画像の数（デフォルト: 1）。 | INT | はい | 1～6 |
| `seed` | ノードを再実行するかどうかを判断するためのシードです。実際の結果はシードに関係なく非決定的です（デフォルト: 0）。 | INT | はい | 0～18446744073709551615 |
| `recraft_controls` | Recraft Controls ノードを介した、生成に対する任意の追加コントロールです。 | CUSTOM | いいえ | N/A |
| `style_id` | 適用する Recraft V4 スタイルの UUID です。たとえば、Recraft V4 Create Style ノード、または以前の実行の style_id 出力から取得します。style_references と組み合わせることはできません（デフォルト: 空）。 | STRING | いいえ | 有効な UUID 文字列 |
| `style_match` | スタイルにどの程度厳密に従うか: precise は細部まで再現し、flexible は全体的な見た目に合わせます。スタイルが指定されている場合にのみ使用されます（デフォルト: "precise"）。 | COMBO | いいえ | "precise"<br />"flexible" |

### recraftv4_1、recraftv4_1_utility、recraftv4、および recraftv4_styles 入力

これらのモデルは同じ `size` パラメータを共有します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `size` | 生成される画像のサイズ（デフォルト: "1024x1024"）。 | COMBO | はい | 複数のオプションが利用可能（標準 Recraft V4 サイズ。"1024x1024" を含む） |

### recraftv4_1_pro、recraftv4_1_utility_pro、recraftv4_pro、および recraftv4_styles_pro 入力

これらのモデルは同じ `size` パラメータを共有します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `size` | 生成される画像のサイズ（デフォルト: "2048x2048"）。 | COMBO | はい | 複数のオプションが利用可能（pro Recraft V4 サイズ。"2048x2048" を含む） |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `style_references` | オンザフライでスタイルを作成するための参照画像です。生成とは別に課金されます。作成されたスタイルは再利用のために style_id として返されます。style_id と組み合わせることはできません。拡張可能スロット: 1..N 枚の画像を接続します（style_reference_1、style_reference_2、...）。 | IMAGE | いいえ | 0 から Recraft API で許可される参照画像の最大数まで。エンコード後の合計サイズは 10 MB を超えてはなりません |

**注記:** `size` パラメータは動的入力であり、利用可能なオプションは選択した `model` に基づいて変わります。`recraftv4_styles` および `recraftv4_styles_pro` モデルは常にスタイルが必要です。スタイル参照画像を接続するか、`style_id` を指定してください。`style_id` と `style_references` 入力は同時に使用できません。どちらか一方のみを指定してください。`style_id` は有効な UUID である必要があります。`style_match` 入力は、スタイルが指定されている場合にのみ使用されます。スタイル参照画像は生成とは別に課金され、そのエンコード後の合計サイズは 10 MB を超えてはなりません。`seed` 値は再現可能な画像出力を保証するものではありません。Infinite Style Library のスタイル ID を使用する場合は、Vector art スタイルではないことを確認してください。画像ではなく SVG データが返される可能性があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された画像、または画像のバッチです。 | IMAGE |
| `style_id` | この生成で使用または作成されたスタイル ID です。スタイル参照画像が提供された場合、作成されたスタイルが再利用のためにここに返されます。スタイルが使用されていない場合は空文字列です。 | STRING |
