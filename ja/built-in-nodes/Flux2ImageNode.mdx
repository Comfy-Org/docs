Flux.2 [pro] または Flux.2 [max] モデルを使用して、テキストプロンプトとオプションの参照画像から画像を生成します。このノードはリクエストを BFL API に送信し、結果をポーリングして、生成された画像をテンソルとして返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 使用する Flux.2 モデルのバージョン。モデルを選択すると、幅、高さ、およびオプションの参照画像に関する追加パラメータが利用可能になります。 | DYNAMIC_COMBO | はい | "Flux.2 [pro]"<br />"Flux.2 [max]" |
| `プロンプト` | 画像生成または編集のプロンプト（デフォルト: 空文字列）。 | STRING | はい | N/A |
| `シード` | ノイズ生成に使用されるランダムシード。各生成後にランダム化するよう設定できます（デフォルト: 0）。 | INT | はい | 0 から 18446744073709551615 |

### Flux.2 [pro] および Flux.2 [max] 入力

両モデルに共通です。パラメータセットは同一です。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `幅` | 生成画像の幅（ピクセル単位）（デフォルト: 1024）。 | INT | はい | 256 から 2048（ステップ 32） |
| `高さ` | 生成画像の高さ（ピクセル単位）（デフォルト: 768）。 | INT | はい | 256 から 2048（ステップ 32） |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model.images` | 画像間生成用のオプションの参照画像。最大8枚。拡張可能スロット: 1〜8個のアイテムを接続できます（`image_1`...`image_8`）。 | IMAGE | いいえ | 0 から 8 枚 |

**注記:**
- 参照画像の最大数は8枚です。8枚を超える画像が提供された場合は、エラーが発生します。
- `model.width` と `model.height` の値は生成コストに影響します。コストは選択したモデルと参照画像が提供されたかどうかにも依存します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | BFL API の結果からダウンロードされた、テンソル形式の生成画像。 | IMAGE |
