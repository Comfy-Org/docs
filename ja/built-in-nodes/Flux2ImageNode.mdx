テキストプロンプトとオプションの参照画像から、Flux.2 [pro] または Flux.2 [max] モデルを使用して画像を生成します。このノードはリクエストを BFL API に送信し、結果の準備ができるまでポーリングして、生成された画像を返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 使用する Flux.2 モデルバージョン。モデルを選択すると、幅、高さ、およびオプションの参照画像用の追加パラメータが利用可能になります。 | DYNAMIC_COMBO | はい | "Flux.2 [pro]"<br />"Flux.2 [max]" |
| `プロンプト` | 画像生成または編集のためのプロンプト（デフォルト：空文字列）。 | STRING | はい | N/A |
| `シード` | ノイズ生成に使用される乱数シード（デフォルト：0）。生成後制御オプションをサポートしており、実行ごとに値をランダム化できます。 | INT | はい | 0～18446744073709551615 |

### Flux.2 [pro] および Flux.2 [max] 入力

両方のモデルで共有されます。パラメータセットは同一です。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `幅` | 生成画像の幅（ピクセル単位）（デフォルト：1024）。 | INT | はい | 256～2048（ステップ32） |
| `高さ` | 生成画像の高さ（ピクセル単位）（デフォルト：768）。 | INT | はい | 256～2048（ステップ32） |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model.images` | 画像から画像への生成用のオプションの参照画像。最大8枚。拡張可能スロット：1～8個のアイテム（`image_1`...`image_8`）を接続します。 | IMAGE | いいえ | 0～8 画像 |

**注意：**
- 参照画像の最大数は8です。9枚以上指定するとエラーが発生します。バッチ画像はこの制限にカウントされます。バッチ内の各画像が個別にカウントされるためです。
- 参照画像は、API に送信される前に、総ピクセル数が 2048 x 2048 を超えないようにリサイズされます。
- `model.width` と `model.height` の値は生成コストに影響します。コストは、選択したモデルと参照画像が提供されているかどうかにも依存します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | BFL API の結果からダウンロードされた、テンソルとしての生成画像。 | IMAGE |
