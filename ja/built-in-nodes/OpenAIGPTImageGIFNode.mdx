## 概要

OpenAI GPT Image 2.6 GIF は、OpenAI の GPT Image モデルを使用してプロンプトからアニメーション GIF を生成し、フレームバッチとフレームレートとして返します。そのため、そのまま動画またはアニメーション画像保存ノードに渡すことができます。利用可能なモデルは `gpt-image-2.6-flare` と `gpt-image-2.6-sunburst` の 2 つです。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | アニメーションに使用する GPT Image モデルです。 | DYNAMIC_COMBO | はい | `"gpt-image-2.6-flare"`<br />`"gpt-image-2.6-sunburst"` |

### gpt-image-2.6-flare および gpt-image-2.6-sunburst 入力

両方のモデルは同じパラメータを共有します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model.prompt` | アニメーション化する内容です。（デフォルト: `""`） | STRING | はい | 該当なし |
| `model.size` | 各フレームのサイズです。大きなサイズは、フレーム数が少ない場合にのみ使用できます。（デフォルト: `"512x512"`） | COMBO | はい | `"384x384"`<br />`"512x512"`<br />`"640x640"`<br />`"720x720"`<br />`"768x768"`<br />`"960x960"`<br />`"512x288"`<br />`"288x512"`<br />`"1024x576"`<br />`"576x1024"`<br />`"1280x720"`<br />`"720x1280"` |
| `model.frame_count` | フレーム数です。フレームは次のステップ単位で課金されます: 2～8、9、10～12、13～16。（デフォルト: `9`） | INT | はい | 2～16 |
| `model.frame_duration_ms` | 各フレームが表示される時間（ミリ秒）です。（デフォルト: `200`） | INT | はい | 20～2000（ステップ 10） |
| `model.background` | フレームの背景です。透明度は、vp9 を使用した Save WEBM、Save Animated WEBP、および Save Animated PNG で保持されます。（デフォルト: `"opaque"`） | COMBO | はい | `"opaque"`<br />`"transparent"` |
| `model.quality` | 画像品質です。高いレベルほどコストが増え、時間もかかります。（デフォルト: `"low"`） | COMBO | はい | `"low"`<br />`"medium"`<br />`"high"`<br />`"xhigh"`<br />`"max"` |
| `model.complexity` | モデルがレンダリング前にアニメーションをどの程度計画するかです。（デフォルト: `"high"`） | COMBO | はい | `"low"`<br />`"medium"`<br />`"high"` |
| `model.seed` | ノードを再実行するかどうかを制御します。結果はシードに関係なく非決定的です。（デフォルト: `42`） | INT | はい | 0～2147483647 |

**パラメータの制約と制限事項:**

- フレームレートは `model.frame_duration_ms` から計算されます。200 ms の場合、5 fps になります。
- 大きな `model.size` と多い `model.frame_count` の組み合わせは利用できません。その場合、価格バッジに「Size too large for this frame count」と表示されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `frames` | フレームのバッチとしてのアニメーションです。動画またはアニメーション画像保存ノードですぐに使用できます。 | IMAGE |
| `fps` | 1 秒あたりのフレーム数です。返された GIF のフレーム継続時間から読み取られます。 | FLOAT |
