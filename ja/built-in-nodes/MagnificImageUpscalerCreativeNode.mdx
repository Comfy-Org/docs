このノードは、Magnific AI サービスを使用して画像をアップスケールし、クリエイティブに拡張します。テキストプロンプトで拡張をガイドし、最適化する特定のスタイルを選択できるほか、ディテール、元画像との類似度、スタイライズの強さなど、クリエイティブプロセスのさまざまな側面を制御できます。このノードは、選択した倍率（2x、4x、8x、または16x）でアップスケールした画像を出力します。最大出力サイズは25.3メガピクセルです。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | アップスケールおよび拡張する入力画像です。 | IMAGE | はい | - |
| `プロンプト` | 画像のクリエイティブな拡張をガイドするテキスト記述です。オプションです（デフォルト: 空）。 | STRING | いいえ | - |
| `拡大倍率` | 画像の寸法をアップスケールする倍率です。 | COMBO | はい | `"2x"`<br />`"4x"`<br />`"8x"`<br />`"16x"` |
| `最適化対象` | 拡張プロセスを最適化するためのスタイルまたはコンテンツタイプです。 | COMBO | はい | `"standard"`<br />`"soft_portraits"`<br />`"hard_portraits"`<br />`"art_n_illustration"`<br />`"videogame_assets"`<br />`"nature_n_landscapes"`<br />`"films_n_photography"`<br />`"3d_renders"`<br />`"science_fiction_n_horror"` |
| `クリエイティビティ` | 画像に適用されるクリエイティブな解釈のレベルを制御します（デフォルト: 0）。 | INT | いいえ | -10〜10 |
| `HDR` | 明瞭さとディテールのレベルです（デフォルト: 0）。 | INT | いいえ | -10〜10 |
| `類似度` | 元画像との類似度のレベルです（デフォルト: 0）。 | INT | いいえ | -10〜10 |
| `フラクタリティ` | プロンプトの強さと1平方ピクセルあたりの複雑さです（デフォルト: 0）。 | INT | いいえ | -10〜10 |
| `エンジン` | 処理に使用する特定のAIエンジンです。上級者向けパラメータです。 | COMBO | はい | `"automatic"`<br />`"magnific_illusio"`<br />`"magnific_sharpy"`<br />`"magnific_sparkle"` |
| `自動ダウンスケール` | 出力が最大ピクセル数を超える場合に、入力画像を自動的にダウンスケールします（デフォルト: False）。上級者向けパラメータです。 | BOOLEAN | いいえ | - |

**制約事項：**

* 入力 `image` は正確に1枚の画像でなければなりません。
* 入力画像の高さと幅は最低160ピクセル必要です。
* 入力画像のアスペクト比は1:3〜3:1の範囲内である必要があります。
* 最終出力サイズ（入力寸法×`scale_factor`）は25,300,000ピクセルを超えることはできません。この制限を超える場合：
  - `auto_downscale` が有効な場合、ノードは自動的に入力画像サイズを縮小するか（最大2倍まで）、またはより低い `scale_factor` を使用して、出力が制限内に収まるようにします。
  - `auto_downscale` が無効な場合、ノードはエラーを発生させます。
