このノードは、Wan 2.7 モデルを使用してテキスト記述からビデオを生成します。プロンプトを Wan 動画生成 API に送信し、タスクの完了を待って、結果のビデオを返します。オプションでオーディオクリップを接続して、ビデオの動きやタイミングに影響を与えることができます。オーディオが提供されない場合、モデルは自動的に一致するオーディオを生成します。

## 入力

### 共通入力

これらの入力は、ノードの最上位レベルで常に利用可能です。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | ビデオ生成に使用する特定のモデル。 | DYNAMIC_COMBO | はい | `"wan2.7-t2v"` |
| `オーディオ` | ビデオ生成を駆動するためのオーディオ（例：リップシンク、ビートに合わせた動き）。長さ：3秒～30秒。指定しない場合、モデルは自動的に一致する背景音楽や効果音を生成します。 | AUDIO | いいえ | - |
| `シード値` | 生成に使用するシード（デフォルト：0）。 | INT | はい | 0〜2147483647 |
| `プロンプト拡張` | AI支援でプロンプトを拡張するかどうか（デフォルト：True）。 | BOOLEAN | はい | True<br />False |
| `ウォーターマーク` | 結果にAI生成の透かしを追加するかどうか（デフォルト：False）。 | BOOLEAN | はい | True<br />False |

### wan2.7-t2v 入力

これらの設定は、`wan2.7-t2v` モデルが選択されているときに表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要素と視覚的特徴を説明するプロンプト。英語と中国語に対応しています。 | STRING | はい | - |
| `negative_prompt` | 避けたい内容を説明するネガティブプロンプト。デフォルトは空文字列です。 | STRING | いいえ | - |
| `resolution` | 出力ビデオの解像度。 | COMBO | はい | `"720P"`<br />`"1080P"` |
| `ratio` | 出力ビデオのアスペクト比。 | COMBO | はい | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | ビデオの長さ（秒）（デフォルト：5）。 | INT | はい | 2〜15 |

**注記：** `prompt` 入力は空にしないでください。`audio` 入力はオプションです。指定する場合、ノードは1.5秒から60秒のオーディオを受け付けます（ツールチップでは3秒～30秒を推奨していますが）。オーディオが提供されない場合、モデルは自動的に一致するオーディオを生成します。`negative_prompt` が空の場合は、APIに送信されません。`prompt_extend` と `watermark` は高度なオプションです。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成されたビデオファイル。 | VIDEO |
