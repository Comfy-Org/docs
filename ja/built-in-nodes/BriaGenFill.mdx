このノードは、Bria API を使用して、画像内のマスクされた領域にオブジェクトまたは背景を生成します。画像とマスクをアップロードし、プロンプトを Bria のジェネレーティブフィルサービスに送信して、操作の完了を待機し、編集された画像を返します。これは有料の API 操作です（リクエストあたり米ドル 0.0429）。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 編集する入力画像。 | IMAGE | 必須 | - |
| `mask` | 白い領域は生成されたコンテンツで塗りつぶされ、黒い領域は保持されます。マスクは送信前に2値化されるため、部分的に塗られた領域は白として扱われます。画像と同じアスペクト比である必要があります。 | MASK | 必須 | - |
| `prompt` | マスクされた領域内に生成する内容の説明。少なくとも1文字以上必要です。（デフォルト: ""） | STRING | 必須 | - |
| `negative_prompt` | 生成結果に含めたくない内容を説明するプロンプト。空のままにすると、API には送信されません。（デフォルト: ""） | STRING | 必須 | - |
| `refine_prompt` | より良い結果を得るためにプロンプトを自動調整します。無効にすると、プロンプトが記述されたとおりに使用されます。（デフォルト: true） | BOOLEAN | 必須 | true<br />false |
| `seed` | 生成プロセスのシード値。（デフォルト: 42） | INT | 必須 | 1 から 2147483647 |
| `モデレーション` | モデレーション設定。「true」に設定すると、以下のモデレーションオプションが適用されます。（デフォルト: "false"） | DYNAMIC_COMBO | 必須 | "false"<br />"true" |

### モデレーション入力（`moderation` = "true" の場合）

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | プロンプトにコンテンツモデレーションを適用します。（デフォルト: false） | BOOLEAN | 任意 | true<br />false |
| `visual_input_moderation` | 入力画像にコンテンツモデレーションを適用します。（デフォルト: false） | BOOLEAN | 任意 | true<br />false |
| `visual_output_moderation` | 出力画像にコンテンツモデレーションを適用します。（デフォルト: false） | BOOLEAN | 任意 | true<br />false |

**注記:** `prompt` は空にできません。`mask` は `image` と同じアスペクト比である必要があります。マスクは不透明度50%で2値化されるため、半分未満の不透明度で塗られた領域は無視されます。2値化後にマスクに白い領域が含まれない場合、ノードはエラーを発生させます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | マスクされた領域が生成されたコンテンツで塗りつぶされた結果画像。 | IMAGE |
