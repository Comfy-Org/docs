このノードは、Bria APIを使用して、画像のマスク領域内にオブジェクトやシーンを生成します。画像とマスクをアップロードし、プロンプトをBriaジェネレーティブフィルサービスに送信して、操作が完了するのを待ち、編集された画像を返します。これは有料のAPI操作です（1リクエストあたりUS$0.0429）。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|------|---------|------|------|
| `image` | 編集する入力画像。 | IMAGE | 必須 | - |
| `mask` | 白い領域は生成されたコンテンツで塗りつぶされ、黒い領域は保持されます。マスクは送信前に二値化されるため、部分的に塗られた領域も白として扱われます。画像と同じアスペクト比である必要があります。 | MASK | 必須 | - |
| `prompt` | マスク領域内に生成する内容の説明。1文字以上である必要があります。 | STRING | 必須 | - |
| `negative_prompt` | 生成結果で避けたい内容を説明するプロンプト。空のままにすると、APIには送信されません。 | STRING | 必須 | - |
| `refine_prompt` | より良い結果を得るためにプロンプトを自動的に調整します。無効にすると、プロンプトが記述されたとおりに使用されます。（デフォルト：true） | BOOLEAN | 必須 | true<br />false |
| `seed` | 生成プロセスのシード値。（デフォルト：42） | INT | 必須 | 1 〜 2147483647 |
| `moderation` | リクエストのモデレーション設定。"true"に設定すると、後述のネストされたモデレーションオプションが適用されます。（デフォルト："false"） | COMBO | 必須 | "false"<br />"true" |

注：`prompt`は空にできません。また、`mask`は`image`と同じアスペクト比である必要があります。

`moderation`が"true"に設定されている場合、以下のネストされたブールオプションが使用可能です：
- `prompt_content_moderation`（デフォルト：false）：プロンプトにコンテンツモデレーションを適用します。
- `visual_input_moderation`（デフォルト：false）：入力画像にコンテンツモデレーションを適用します。
- `visual_output_moderation`（デフォルト：false）：出力画像にコンテンツモデレーションを適用します。

## 出力

| 出力名 | 説明 | データ型 |
|--------|------|---------|
| `image` | マスク領域が生成されたコンテンツで塗りつぶされた結果の画像。 | IMAGE |
