プロンプトから FLUX 3 Image が読み取るレイアウトテーブルを構築します。Create Bounding Boxes ノードで描画された要素を取得し、それぞれに id、座標、説明を持つボックスのリストとしてプロンプトに追加します。プロンプト内でボックスを `<obj_N>` として引用すると、単語をその領域に紐付けられます。その後、出力を FLUX 3 Image ノードの `prompt` 入力に接続します。要素が接続されていない場合、プロンプトは変更されずに返されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `prompt` | プロンプトテキストです。ボックス N を `<obj_N>` として引用すると、単語をそのボックスに紐付けられます。 | STRING | はい | - |
| `element` | レイアウトに配置する要素で、Create Bounding Boxes ノードから取得します。カラーパレットは使用されないため、代わりに説明文で色を記述してください。 | ARRAY | はい | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `prompt` | ボックスレイアウトテーブルが追加されたプロンプトです。FLUX 3 Image ノードにそのまま入力できます。 | STRING |
