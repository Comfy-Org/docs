このノードは、単一の conditioning を safetensors ファイルとして output フォルダに保存します。保存されたファイルは models/embeddings フォルダに移動でき、後で Load Conditioning を使って読み込むことができます。たとえば、テキストエンコーダをスキップする場合などに利用できます。このノードは conditioning を変更せずにそのまま通過させるため、ワークフローの後半でも引き続き使用できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `conditioning` | 保存する conditioning です。単一の conditioning エントリのみがサポートされています。 | CONDITIONING | はい | - |
| `filename_prefix` | 出力ファイル名を構築するために使用されるプレフィックスです。ファイルは output フォルダに書き込まれ、数値カウンタが付加されます。デフォルト: `conditioning/ComfyUI` | STRING | はい | - |

**注意:**

- `conditioning` 入力に複数のエントリが含まれている場合（たとえば、conditioning を結合した後など）、ノードはエラーを発生させます："Save Conditioning supports a single conditioning entry, save it before combining."
- conditioning のオプションで、テンソル、テンソルのリスト/タプル、ブール値、整数、浮動小数点数、または文字列であるものは、conditioning とともに保存されます。`None` であるオプションはスキップされます。その他のオプション型は、そのオプションを保存できないことを示すエラーを発生させます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `conditioning` | 渡された conditioning と同じもので、変更されていません。 | CONDITIONING |
