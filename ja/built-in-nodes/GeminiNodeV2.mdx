Google の Gemini モデルでテキスト応答を生成します。テキストプロンプトを提供し、必要に応じて 1 つ以上の画像、音声クリップ、動画、またはファイルをマルチモーダルコンテキストとして提供できます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 応答の生成に使用する Gemini モデルです。 | DYNAMIC_COMBO | はい | `"Gemini 3.7 Flash"`<br />`"Gemini 3.5 Flash"`<br />`"Gemini 3.1 Pro"`<br />`"Gemini 3.1 Flash-Lite"` |
| `prompt` | モデルへのテキスト入力です。詳細な指示、質問、またはコンテキストを含めてください。少なくとも 1 つの空白以外の文字を含める必要があります。（デフォルト: ""） | STRING | はい |  |
| `seed` | サンプリング用のシードです。ランダムシードにするには 0 に設定します。決定的な出力は保証されません。（デフォルト: 42） | INT | はい | 0～2147483647 |
| `system_prompt` | モデルの動作を決定する基本的な指示です。（デフォルト: ""） | STRING | いいえ |  |

### Gemini 3.7 Flash 入力

これらの入力は、`model` が `"Gemini 3.7 Flash"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `thinking_level` | 回答前にモデルが内部的に推論する程度です。HIGH にすると難しいタスクでの品質が向上しますが、(思考用) トークンをより多く消費し、処理が遅くなります。（デフォルト: "MEDIUM"） | COMBO | はい | `"LOW"`<br />`"MEDIUM"`<br />`"HIGH"` |
| `temperature` | ランダム性を制御します。値が低いほど、より焦点が定まり決定的になり、値が高いほど、より創造的になります。（デフォルト: 1.0） | FLOAT | はい | 0.0～2.0 |
| `top_p` | 核サンプリング：累積確率が top_p に達する最小のトークンセットからサンプリングします。（デフォルト: 0.95） | FLOAT | はい | 0.0～1.0 |
| `max_output_tokens` | 生成する最大トークン数です。モデルの内部的な思考も含まれます。thinking_level が HIGH の場合、値が低いと回答の余地がなくなる可能性があります。応答が空または途中で切れて返ってくる場合は、この値を上げてください。モデルは完了すると早期に停止するため、上限を高く設定しても短い応答では追加コストはかかりません。（デフォルト: 32768） | INT | はい | 16～65536 |

### メディアおよびファイル入力

以下の入力は 4 つのモデルすべてで共通であり、モデル固有の入力とともに表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | 拡張可能スロット：1～16 枚の画像（`image_1` ... `image_16`）を接続します。モデルのコンテキストとして使用するオプションの画像です。最大 16 枚まで。 | IMAGE | いいえ | 0～16 枚 |
| `audio` | 拡張可能スロット：1 つの音声クリップ（`audio_1`）を接続します。モデルのコンテキストとして使用するオプションの音声クリップです。 | AUDIO | いいえ | 0～1 クリップ |
| `video` | 拡張可能スロット：1 つの動画クリップ（`video_1`）を接続します。モデルのコンテキストとして使用するオプションの動画クリップです。 | VIDEO | いいえ | 0～1 クリップ |
| `files` | モデルのコンテキストとして使用するオプションのファイルです。Gemini Input Files ノードからの入力を受け付けます。 | GEMINI_INPUT_FILES | いいえ |  |

**注記:** メディア（画像、音声、動画）が添付されている場合、ノードは最初の 10 個のメディアアイテムを ComfyAPI ストレージにアップロードし、URL として渡します。この URL 予算はすべてのメディアタイプで共有され、順に消費されます（動画、次に音声、次に画像の順）。残りのメディアは base64 データとしてインラインでエンコードされ、インラインペイロードの合計は最大 18 MB です。インラインペイロードが 18 MB を超える場合、ノードはエラーを発生させます。`prompt` パラメータには少なくとも 1 つの空白以外の文字を含める必要があります。`seed` を 0 に設定すると、ランダムシードが要求されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | Gemini モデルによって生成されたテキスト応答です。モデルがテキストを生成しなかった場合、文字列「Empty response from Gemini model...」が返されます。 | STRING |
