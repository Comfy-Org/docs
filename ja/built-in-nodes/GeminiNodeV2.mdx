Google の Gemini モデルを使用してテキスト応答を生成します。テキストプロンプトと、任意で 1 つ以上の画像、オーディオクリップ、動画、またはファイルをマルチモーダルコンテキストとして提供します。このノードは、プロンプトと添付されたメディアを選択したモデルに送信し、モデルのテキスト応答を返します。

**注：** このノードはソースコード上で非推奨としてマークされています。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 応答の生成に使用する Gemini モデルです。モデルを選択すると、そのモデル固有の入力セットが以下に表示されます。 | DYNAMIC_COMBO | はい | `"Gemini 3.8 Flash"`<br />`"Gemini 3.7 Flash"`<br />`"Gemini 3.5 Flash"`<br />`"Gemini 3.1 Pro"`<br />`"Gemini 3.1 Flash-Lite"` |
| `prompt` | モデルへのテキスト入力です。詳細な指示、質問、またはコンテキストを含めてください。（デフォルト: ""） | STRING | はい | 空白以外の文字を少なくとも 1 文字含む必要があります |
| `seed` | サンプリング用のシードです。0 に設定するとランダムシードになります。決定論的な出力は保証されません。（デフォルト: 42） | INT | はい | 0〜2147483647 |
| `system_prompt` | モデルの動作を規定する基礎的な指示です。（デフォルト: ""） | STRING | いいえ |  |

### Gemini 3.8 Flash 入力

これらの入力は、`model` が `"Gemini 3.8 Flash"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `thinking_level` | モデルが回答前に内部でどれだけ推論するかを指定します。HIGH は難しいタスクの品質を向上させますが、より多くの（思考）トークンを消費し、遅くなります。（デフォルト: "MEDIUM"） | COMBO | はい | `"LOW"`<br />`"MEDIUM"`<br />`"HIGH"` |
| `max_output_tokens` | 生成する最大トークン数（モデルの内部思考を含む）です。`thinking_level` が HIGH の場合、値が低いと回答の余地がなくなることがあります。応答が空または切り捨てられて返される場合は、この値を増やしてください。モデルは完了時に早期停止するため、短い返答では上限を高くしても追加コストは発生しません。（デフォルト: 32768） | INT | はい | 16〜65536 |

**注：** このモデルは `temperature` または `top_p` のサンプリング制御を公開していません。

### メディアとファイル入力

以下の入力はすべてのモデルで共有され、モデル固有の入力と並んで表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | 拡張可能スロット：1～16 枚の画像（`image_1` ... `image_16`）を接続します。モデルのコンテキストとして使用する任意の画像です。最大 16 枚の画像。 | IMAGE | いいえ | 0〜16 images |
| `audio` | 拡張可能スロット：1 つのオーディオクリップ（`audio_1`）を接続します。モデルのコンテキストとして使用する任意のオーディオクリップです。 | AUDIO | いいえ | 0〜1 clip |
| `video` | 拡張可能スロット：1 つの動画クリップ（`video_1`）を接続します。モデルのコンテキストとして使用する任意の動画クリップです。 | VIDEO | いいえ | 0〜1 clip |
| `files` | モデルのコンテキストとして使用する任意のファイルです。Gemini Input Files ノードからの入力を受け付けます。 | GEMINI_INPUT_FILES | いいえ |  |

**注：** メディア（画像、オーディオ、または動画）が添付されている場合、このノードは最初の 10 個のメディア項目を ComfyAPI ストレージにアップロードし、それらを URL として渡します。この URL バジェットはすべてのメディアタイプで共有され、順番に消費されます（最初に動画、次にオーディオ、最後に画像）。残りのメディアは base64 データとしてインラインでエンコードされ、インラインペイロードは合計最大 18 MB です。インラインペイロードが 18 MB を超える場合、このノードはエラーを発生させます。`prompt` パラメータには、空白以外の文字を少なくとも 1 文字含める必要があります。`seed` を 0 に設定すると、ランダムシードを要求します。
