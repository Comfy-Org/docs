TextEncodeAceStepAudio ノードは、タグと歌詞をトークンに結合し、調整可能な歌詞の強度でエンコードすることにより、オーディオ条件付け用のテキスト入力を処理します。CLIP モデルをテキスト記述および歌詞とともに受け取り、それらをまとめてトークン化し、オーディオ生成タスクに適した条件付けデータを生成します。このノードは、最終出力への影響を制御する強度パラメータを通じて、歌詞の影響を微調整できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `clip` | トークン化とエンコードに使用される CLIP モデル | CLIP | はい | - |
| `タグ` | オーディオ条件付け用のテキストタグまたは説明（複数行の入力と動的プロンプトに対応） | STRING | はい | - |
| `歌詞` | オーディオ条件付け用の歌詞テキスト（複数行の入力と動的プロンプトに対応） | STRING | はい | - |
| `歌詞強度` | 条件付け出力に対する歌詞の影響の強さを制御します（デフォルト: 1.0、ステップ: 0.01） | FLOAT | はい | 0.0 - 10.0 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `conditioning` | 処理されたテキストトークンと適用された歌詞の強度を含むエンコード済みの条件付けデータ | CONDITIONING |
