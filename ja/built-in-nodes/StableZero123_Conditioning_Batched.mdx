StableZero123_Conditioning_Batched ノードは、単一の入力画像から3Dモデルを生成するためのコンディショニングデータを準備します。CLIPビジョンモデルとVAEを使用して画像をエンコードし、視覚特徴と仰角および方位角から構築されたカメラ埋め込みを組み合わせて、バッチ内の各サンプルについてポジティブおよびネガティブのコンディショニングと潜在テンソルを生成します。`batch_size` が1より大きい場合、仰角と方位角は各バッチ項目に対してバッチ増分値だけ増加します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `クリップビジョン` | 入力画像のエンコードに使用されるCLIPビジョンモデル | CLIP_VISION | はい | - |
| `初期画像` | 処理およびエンコードされる初期入力画像 | IMAGE | はい | - |
| `vae` | 画像ピクセルを潜在空間にエンコードするために使用されるVAEモデル | VAE | はい | - |
| `幅` | 処理された画像の出力幅（デフォルト: 256） | INT | はい | 16 to MAX_RESOLUTION (step of 8) |
| `高さ` | 処理された画像の出力高さ（デフォルト: 256） | INT | はい | 16 to MAX_RESOLUTION (step of 8) |
| `バッチサイズ` | バッチ内で生成するコンディショニングサンプル数（デフォルト: 1） | INT | はい | 1〜4096 |
| `高度` | カメラの初期仰角（度）（デフォルト: 0.0） | FLOAT | はい | -180.0〜180.0 |
| `方位角` | カメラの初期方位角（度）（デフォルト: 0.0） | FLOAT | はい | -180.0〜180.0 |
| `高度バッチ増分` | 各バッチ項目の仰角を増分する量（デフォルト: 0.0） | FLOAT | はい | -180.0〜180.0 |
| `方位角バッチ増分` | 各バッチ項目の方位角を増分する量（デフォルト: 0.0） | FLOAT | はい | -180.0〜180.0 |

**注:** `width` と `height` の値は8の倍数である必要があります。このノードは潜在テンソルを構築する際にこれらの次元を内部的に8で割るためです。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `ポジティブ` | 各バッチ項目の画像埋め込みとカメラ埋め込みを含むポジティブなコンディショニングデータ | CONDITIONING |
| `ネガティブ` | ゼロ初期化された埋め込みを持つネガティブなコンディショニングデータ | CONDITIONING |
| `潜在` | batch_size x 4 x height/8 x width/8 の次元を持つゼロ初期化された潜在テンソルと、バッチインデックス情報 | LATENT |
