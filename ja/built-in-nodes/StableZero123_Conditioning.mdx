StableZero123_Conditioning ノードは、入力画像とカメラ角度を処理して、3D モデル生成用のコンディショニングデータと潜在表現を生成します。CLIP vision モデルを使用して画像特徴をエンコードし、仰角と方位角に基づくカメラ埋め込み情報と組み合わせ、下流の 3D 生成タスク向けに positive と negative のコンディショニング、および潜在表現を出力します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `クリップビジョン` | 画像特徴のエンコードに使用する CLIP vision モデル | CLIP_VISION | はい | - |
| `初期画像` | 処理およびエンコード対象となる入力画像 | IMAGE | はい | - |
| `vae` | ピクセルを潜在空間へエンコードするために使用する VAE モデル | VAE | はい | - |
| `幅` | 潜在表現の出力幅（デフォルト: 256、ステップ: 8） | INT | はい | 16 ～ MAX_RESOLUTION |
| `高さ` | 潜在表現の出力高さ（デフォルト: 256、ステップ: 8） | INT | はい | 16 ～ MAX_RESOLUTION |
| `バッチサイズ` | バッチ内で生成するサンプル数（デフォルト: 1） | INT | はい | 1 ～ 4096 |
| `高度` | カメラの仰角（度単位、デフォルト: 0.0、ステップ: 0.1） | FLOAT | はい | -180.0 ～ 180.0 |
| `方位角` | カメラの方位角（度単位、デフォルト: 0.0、ステップ: 0.1） | FLOAT | はい | -180.0 ～ 180.0 |

**注記:** `width` と `height` パラメータはステップ 8 を使用するため、値は 8 刻みで設定されます。ノードはこれらを 8 で割って潜在表現の次元を決定します。画像は VAE エンコード前に、中心クロップを伴う双線形アップスケーリングによって指定された `width` と `height` に再スケーリングされます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | 画像特徴とカメラ埋め込みを組み合わせた positive コンディショニングデータ。連結する潜在表現として、VAE でエンコードされた入力画像を含みます | CONDITIONING |
| `negative` | ゼロで初期化された特徴とゼロで初期化された潜在表現を持つ negative コンディショニングデータ | CONDITIONING |
| `latent` | 次元 [batch_size, 4, height//8, width//8] を持つゼロで初期化された潜在表現 | LATENT |
