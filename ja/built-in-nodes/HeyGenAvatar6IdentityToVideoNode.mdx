Avatar 6 を使用した HeyGen アバターのトーキング動画を生成します。Avatar 6 をサポートする組み込みルックから 1 つ選択するか、独自の HeyGen アバター ID を貼り付け、テキストスクリプトまたは独自の音声でアバターを動かします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | モデルセレクターです。`"heygen-avatar-6-turbo"` はより安価で高速なティアです。どちらのモデルも同じ入力と解像度を受け付けます。 | COMBO | はい | `"heygen-avatar-6"`<br />`"heygen-avatar-6-turbo"` |
| `avatar` | 表示するアバターのルックです。Avatar 6 をサポートする 19 種類の組み込みルックが直接一覧表示されます。`custom avatar` を選ぶと、HeyGen で作成したルック用の `custom_avatar_id` が表示されます。 | DYNAMIC_COMBO | はい | 19 種類の組み込みルック<br />`custom avatar` |
| `speech` | テキストスクリプト（HeyGen のテキスト読み上げ）または独自の音声でアバターを動かします。表示名：スピーチソース。 | DYNAMIC_COMBO | はい | `"script"`<br />`"audio"` |
| `resolution` | 出力動画の解像度です。デフォルト：`"1080p"`。 | COMBO | はい | `"1080p"`<br />`"2k"` |

| `motion_prompt` | ジェスチャー、表情、姿勢、カメラワークに関する任意の指示です。デフォルト：空文字列。 | STRING | はい | 複数行テキスト |

### `custom avatar` 入力

これらの入力は、`avatar` が `custom avatar` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `custom_avatar_id` | Avatar 6 をサポートする HeyGen アバタールック ID です（HeyGen Create Avatar で作成したものなど）。デフォルト：空文字列。 | STRING | はい | - |

### `script` スピーチ入力

これらの入力は、`speech` が `"script"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `text` | アバターが話すテキストです。デフォルト：空文字列。 | STRING | はい | 最大 5000 文字 |
| `voice` | スクリプト用の音声です。デフォルトのオプションでは、HeyGen がアバターに割り当てた音声を使用します。HeyGen Create Avatar で作成したアバターには音声がないため、そのようなアバターには音声を選択してください。 | COMBO | はい | `"(avatar's default voice)"` に加えて HeyGen の一般音声リスト |
| `custom_voice_id` | 任意の HeyGen 音声 ID です。設定すると、上で選択した音声を上書きします。デフォルト：空文字列。 | STRING | いいえ | - |
| `voice_speed` | 話速の倍率です。デフォルト：1.0。 | FLOAT | いいえ | 0.5～1.5（ステップ 0.05） |

### `audio` スピーチ入力

これらの入力は、`speech` が `"audio"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `audio` | アバターのスピーチです。動画の長さは音声に従います。 | AUDIO | はい | 0.5 秒～10 分 |

**制約と動作：**

* `custom avatar` には空でないアバター ID が必要です。そうでない場合、ノードはエラーを発生させます。
* スクリプトは 5000 文字、音声は 10 分に制限されます。
* 料金は出力動画の秒単位で計算され、モデルと解像度によって異なります。
