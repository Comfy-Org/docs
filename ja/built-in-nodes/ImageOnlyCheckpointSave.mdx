このノードは、モデルをその CLIP vision エンコーダーおよび VAE と一緒にまとめたチェックポイントファイルを保存します。ファイルは safetensors 形式で出力ディレクトリに書き込まれ、指定されたファイル名プレフィックスを使用するため、モデルの画像関連コンポーネントを単一のチェックポイントとして保存できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | チェックポイントに保存するモデル | MODEL | はい | - |
| `clip_vision` | チェックポイントに保存する CLIP vision エンコーダー | CLIP_VISION | はい | - |
| `vae` | チェックポイントに保存する VAE（変分オートエンコーダー） | VAE | はい | - |
| `ファイル名プレフィックス` | 出力ファイル名のプレフィックス（デフォルト: "checkpoints/ComfyUI"） | STRING | はい | - |
| `prompt` | ワークフローのプロンプトデータを受け取る非表示パラメータ | PROMPT | いいえ | - |
| `extra_pnginfo` | 追加の PNG メタデータを受け取る非表示パラメータ | EXTRA_PNGINFO | いいえ | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| - | このノードは出力を返しません | - |
