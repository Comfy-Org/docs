このノードは、LTX 2.5 モデルを使用して、開始画像からプロフェッショナル品質の動画を生成します。テキストプロンプトで動画の内容を記述し、モデルバリアントを選択して、長さ、解像度、フレームレート、音声生成を調整します。オプションで最終フレームを指定して、動画の終端を定義できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | 動画に使用する最初のフレーム。 | IMAGE | はい | 画像1枚のみ |
| `モデル` | モデル設定グループ。使用する LTX 2.5 モデルバリアントを選択します。 | COMBO | はい | "LTX-2.5 (Fast)"<br />"LTX-2.5 (Pro)" |
| `長さ` | 生成される動画の長さ（秒）。 | INT | はい | INT |
| `解像度` | 生成される動画の解像度。利用可能なオプションは、選択したモデルによって異なる場合があります。 | COMBO | はい | "1280x720"<br />"720x1280"<br />"1920x1080"<br />"1080x1920"<br />"2560x1440"<br />"1440x2560"<br />"3840x2160"<br />"2160x3840" |
| `fps` | 生成される動画のフレームレート。 | INT | はい | 整数（デフォルト: 25） |
| `オーディオ生成` | 動画の音声を生成するかどうか。 | BOOLEAN | はい | True<br />False（デフォルト: True） |
| `プロンプト` | 生成する動画コンテンツのテキスト記述。1～10000文字である必要があります。 | STRING | はい | 1～10000文字 |
| `シード` | 再現可能な生成のためのシード値。同じ設定で同じシードを使用すると、同じ結果が生成されます。 | INT | はい | 整数（デフォルト: 42） |
| `ラストフレーム` | 動画に使用する最後のフレーム。 | IMAGE | いいえ | 画像1枚のみ |

**注意:** `image` では画像を1枚のみサポートします。`last_frame` を指定する場合、これにも画像を1枚だけ含める必要があります。利用可能な `model.resolution` オプションは、選択した `model` バリアントによって異なる場合があります。1回の実行の料金は、選択した `model`、`model.duration`、`model.resolution` によって異なります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | 提供された開始画像と生成設定に基づいて生成された動画。 | VIDEO |
