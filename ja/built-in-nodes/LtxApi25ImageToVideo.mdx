このノードは、LTX 2.5 モデルを使用して、開始画像からプロ品質のビデオを生成します。テキストプロンプトでビデオの内容を説明し、モデルバリアントを選択して、長さ、解像度、フレームレート、音声生成を調整します。オプションで最終フレームを指定して、ビデオの終了を定義することもできます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | ビデオに使用される最初のフレーム。 | IMAGE | はい | 正確に1枚の画像 |
| `モデル` | モデル設定グループ。使用する LTX 2.5 モデルバリアントを選択します。 | COMBO | はい | "LTX-2.5 (Fast)"<br />"LTX-2.5 (Pro)" |
| `長さ` | 生成されるビデオの長さ（秒）。 | INT | はい | Integer |
| `解像度` | 生成されるビデオの解像度。利用可能なオプションは、選択したモデルによって異なる場合があります。 | COMBO | はい | "1280x720"<br />"720x1280"<br />"1920x1080"<br />"1080x1920"<br />"2560x1440"<br />"1440x2560"<br />"3840x2160"<br />"2160x3840" |
| `fps` | 生成されるビデオのフレームレート。 | INT | はい | Integer (default: 25) |
| `オーディオ生成` | ビデオの音声を生成するかどうか。 | BOOLEAN | はい | True<br />False (default: True) |
| `プロンプト` | 生成するビデオコンテンツのテキストによる説明。1文字以上10000文字以下である必要があります。 | STRING | はい | 1〜10000 characters |
| `シード` | 再現可能な生成のためのシード値。同じシードと設定を使用すると、同じ結果が生成されます。 | INT | はい | Integer (default: 42) |
| `ラストフレーム` | ビデオに使用される最後のフレーム。 | IMAGE | いいえ | 正確に1枚の画像 |

**注:** `image` には画像が1枚のみサポートされています。`last_frame` を指定する場合も、正確に1枚の画像を含める必要があります。利用可能な `model.resolution` オプションは、選択した `model` バリアントによって異なる場合があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | 指定された開始画像と生成設定に基づいて生成されたビデオ。 | VIDEO |
