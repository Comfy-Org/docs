LTXVAddGuideノードは、入力画像またはビデオをエンコードし、それらをキーフレームとして条件付けデータに組み込むことで、潜在シーケンスにビデオ条件付けガイダンスを追加します。このノードはVAEエンコーダーを介して入力を処理し、結果の潜在表現を指定されたフレーム位置に戦略的に配置しながら、ポジティブ条件付けとネガティブ条件付けの両方をキーフレーム情報で更新します。また、フレーム配置の制約を処理し、条件付けの影響の強さを制御できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ポジティブ` | キーフレームガイダンスで変更されるポジティブ条件付け入力 | CONDITIONING | はい | - |
| `ネガティブ` | キーフレームガイダンスで変更されるネガティブ条件付け入力 | CONDITIONING | はい | - |
| `vae` | 入力画像/ビデオフレームのエンコードに使用されるVAEモデル | VAE | はい | - |
| `潜在` | 条件付けフレームを受け取る入力潜在シーケンス | LATENT | はい | - |
| `画像` | 潜在ビデオを条件付けるための画像またはビデオ。8*n + 1フレームである必要があります。ビデオが8*n + 1フレームでない場合、最も近い8*n + 1フレームにクロップされます。 | IMAGE | はい | - |
| `フレームインデックス` | 条件付けを開始するフレームインデックス。単一フレームの画像または1〜8フレームのビデオの場合、任意のframe_idx値が許容されます。9フレーム以上のビデオの場合、frame_idxは8で割り切れる必要があり、そうでない場合は最も近い8の倍数に切り捨てられます。負の値はビデオの末尾から数えます。（デフォルト：0） | INT | はい | -9999〜9999 |
| `強度` | 条件付けの影響の強さ。1.0で完全な条件付けが適用され、0.0で条件付けが適用されません（デフォルト：1.0） | FLOAT | はい | 0.0〜10.0 |
| `アテンションマスク` | オプションのピクセル空間マスク。セルフアテンションを介して領域ごとの条件付けの影響を制御し、strengthで乗算されます。 | MASK | いいえ | - |
| `iclora_parameters` | Get IC-LoRA ParametersノードからのオプションのIC-LoRAパラメータ。特定のIC-LoRA（reference_downscale_factor > 1など）で必要とされるガイド処理の調整に使用されます。チェーン化された場合、各LTXVAddGuideはそれに接続されたパラメータのみを使用します。 | IC_LORA_PARAMETERS | いいえ | - |

**注記：** 入力画像/ビデオは、8*n + 1パターン（例：1、9、17、25フレーム）に従ったフレーム数である必要があります。入力がこのパターンを超える場合、最も近い有効なフレーム数に自動的にクロップされます。

**`iclora_parameters`に関する注記：** `reference_downscale_factor`が1より大きいIC-LoRAパラメータを使用する場合、潜在表現の空間次元（幅と高さ）はその係数で割り切れる必要があります。この条件が満たされない場合、ノードはエラーを発生させます。
