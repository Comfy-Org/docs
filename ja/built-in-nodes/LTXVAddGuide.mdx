LTXVAddGuideノードは、入力画像または動画をVAEエンコーダーを通じてエンコードし、ガイドキーフレームとして潜在動画シーケンスに追加します。ポジティブ条件付けとネガティブ条件付けの両方を更新し、変更された潜在を返します。開始フレーム、条件付けの強度、オプションのアテンションマスク、およびオプションのIC-LoRAパラメータを設定するオプションがあります。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `ポジティブ` | キーフレームガイダンスで変更されるポジティブ条件付け入力。 | CONDITIONING | はい | - |
| `ネガティブ` | キーフレームガイダンスで変更されるネガティブ条件付け入力。 | CONDITIONING | はい | - |
| `vae` | 入力画像/動画フレームのエンコードに使用されるVAEモデル。 | VAE | はい | - |
| `潜在` | 条件付けフレームを受け取る入力潜在シーケンス。 | LATENT | はい | - |
| `画像` | 潜在動画を条件付けるための画像または動画。8*n + 1フレームである必要があります。動画が8*n + 1フレームでない場合、最も近い8*n + 1フレームにクロップされます。 | IMAGE | はい | - |
| `フレームインデックス` | 条件付けを開始するフレームインデックス。単一フレーム画像または1～8フレームの動画の場合、任意のframe_idx値が許容されます。9フレーム以上の動画の場合、frame_idxは8で割り切れる必要があり、そうでない場合は最も近い8の倍数に切り捨てられます。負の値は動画の末尾から数えられます。デフォルト: 0。 | INT | はい | -9999～9999 |
| `強度` | 条件付けの影響の強度。1.0で完全な条件付けが適用され、0.0で条件付けが適用されません。デフォルト: 1.0。 | FLOAT | はい | 0.0～10.0 |
| `アテンションマスク` | オプションのピクセル空間空間マスク。自己アテンションを介して領域ごとの条件付けの影響を制御し、strengthで乗算されます。 | MASK | いいえ | - |
| `iclora_parameters` | Get IC-LoRA ParametersノードからのオプションのIC-LoRAパラメータ。特定のIC-LoRA（例: reference_downscale_factor > 1のもの）で必要とされるガイド処理の調整に使用されます。チェーン接続された場合、各LTXVAddGuideは自身に接続されたパラメータのみを使用します。 | IC_LORA_PARAMETERS | いいえ | - |

**注意:** 入力画像/動画のフレーム数は8*n + 1のパターン（例: 1、9、17、25フレーム）に従う必要があります。入力がこのパターンを超える場合、最も近い有効なフレーム数に自動的にクロップされます。

**`iclora_parameters`に関する注意:** `reference_downscale_factor`が1より大きいIC-LoRAパラメータを使用する場合、潜在の空間次元（幅と高さ）はその係数で割り切れる必要があります。この条件が満たされない場合、ノードはエラーを発生させます。

**注意:** エンコードされたガイドフレームは、選択されたフレーム位置で潜在シーケンス内に収まる必要があります。条件付けされたフレームが潜在シーケンスの長さを超える場合、ノードはエラーを発生させます。

**注意:** 音声チャンネルと動画チャンネルを組み合わせた潜在にガイドを追加することはサポートされておらず、エラーを発生させます。
