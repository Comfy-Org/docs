テキスト指示を使用して、既存のオーディオサンプルの一部を変換します。このノードでは、説明的なプロンプトを指定することでオーディオの特定の区間を変更でき、残りの部分を保持したまま、選択した部分を実質的に「インペインティング」または再生成できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | オーディオインペインティングに使用するAIモデルです。 | STRING | はい | `"stable-audio-2.5"` |
| `prompt` | オーディオをどのように変換するかを導くテキスト記述（デフォルト: 空）。最大長は10,000文字です。 | STRING | はい |  |
| `audio` | 変換する入力オーディオファイル。オーディオは6秒以上190秒以下である必要があります。 | AUDIO | はい |  |
| `duration` | 生成されるオーディオの長さを秒単位で制御します（デフォルト: 190）。 | INT | いいえ | 1 ～ 190 |
| `seed` | 生成に使用する乱数シード（デフォルト: 0）。 | INT | いいえ | 0 ～ 4294967294 |
| `steps` | サンプリングステップ数を制御します（デフォルト: 8）。 | INT | いいえ | 4 ～ 8 |
| `mask_start` | 変換するオーディオ区間の開始位置（秒）（デフォルト: 30）。 | INT | いいえ | 0 ～ 190 |
| `mask_end` | 変換するオーディオ区間の終了位置（秒）（デフォルト: 190）。 | INT | いいえ | 0 ～ 190 |

**注意:** `mask_end` の値は `mask_start` の値より大きい必要があります。入力オーディオの長さは6秒以上190秒以下である必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `audio` | プロンプトに従って指定された区間が変更された、変換後のオーディオ出力です。 | AUDIO |
