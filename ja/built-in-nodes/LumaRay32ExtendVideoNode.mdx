Luma Ray 3.2 Extend Video は、以前の Luma Ray 3.2 ビデオ生成を継続し、元のクリップの後（前方）または前（後方）に新しい5秒セグメントを作成します。以前の Luma Ray 3.2 ノードの `generation_id` 出力を接続して、そのクリップを拡張の開始フレーム（前方）または終了フレーム（後方）として使用します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `source_generation_id` | 拡張する以前のRay 3.2ビデオの生成ID。別のLuma Ray 3.2ノードの `generation_id` 出力を接続します。この値は必須であり、空にすることはできません。 | STRING | はい | - |
| `direction` | 前方は前のクリップの後に続き、後方は前のクリップの前に追加されます。「Forward (continue after)」を選択すると `loop` オプションも追加されます。 | COMBO | はい | "Forward (continue after)"<br />"Backward (lead-in before)" |
| `loop` | 拡張されたビデオをシームレスにループします（前方拡張のみ）。`direction` が「Forward (continue after)」の場合のみ使用できます。デフォルト：False。 | BOOLEAN | いいえ | True<br />False |
| `prompt` | 新しいコンテンツのテキストプロンプト。1〜6000文字の間である必要があります。 | STRING | はい | - |
| `resolution` | 拡張されたビデオセグメントの出力解像度。デフォルト："720p"。 | COMBO | はい | "540p"<br />"720p"<br />"1080p" |
| `seed` | 再現可能な生成結果のためのランダムシード。 | INT | はい | - |

**注記:** `loop`パラメータは、`direction`が「Forward (continue after)」に設定されている場合のみ使用可能です。「Backward (lead-in before)」を使用する場合、ループオプションは利用できません。`prompt`は1文字以上6000文字以下である必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `generation_id` | 生成された5秒の拡張動画セグメント。 | VIDEO |
| `generation_id` | この生成の一意の識別子。別のLuma Ray 3.2 Extend Videoノードに接続して、さらに拡張することができます。 | STRING |
