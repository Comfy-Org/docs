ByteDance Seedream 5.0 Pro Layer Separation は、画像を背景プレートと最大16枚の透明レイヤーに分解します。各レイヤーは、独自のスタック順、バウンディングボックス、名前、説明を持ちます。背景、レイヤーごとの画像とマスク、配置ボックス、そしてすぐに編集可能なレイヤースタックを返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 分離する画像。正確に1枚の画像で、少なくとも512x512ピクセル、アスペクト比は1:16から16:1の間。約4MPより大きい入力はアップロード前にダウンスケールされます。 | IMAGE | はい | Single image |
| `prompt` | 画像を分離する方法。空のままにすると、主要な要素を自動検出してすべて分離します。分離を制御するには要素を自然言語で記述するか、`<bbox>left top right bottom&lt;/bbox>` タグ（0〜1000のパーミル座標）で正確な領域を指定します。デフォルト: 空文字列。 | STRING | はい | Multiline text |
| `size` | 出力解像度レベル。"auto" は入力画像サイズに従います（1K〜2Kの範囲にクランプされます）。デフォルト: "auto"。 | STRING | はい | "auto"<br />"1K"<br />"1.5K"<br />"2K" |
| `seed` | 生成に使用するシード。デフォルト: 0。 | INT | はい | 0〜2147483647 |
| `prompt_optimization` | プロンプト最適化モード:"standard" は高品質、"fast" は生成時間が短くなります。デフォルト: "standard"。 | STRING | いいえ | "standard"<br />"fast" |
| `watermark` | 画像に「AI生成」透かしを追加するかどうか。デフォルト: false。 | BOOLEAN | いいえ | false<br />true |
| `crop_layers` | レイヤー/マスクのバッチ出力の形状（layer_stack は影響を受けず、常にタイトなままです）。フルキャンバスモード: 各レイヤーはベースサイズのキャンバス上のバウンディングボックス位置に配置され、ImageCompositeMasked で直接再合成できます。最小サイズモード: 各レイヤーはバウンディングボックスにクロップされ（バッチ化のため最大レイヤーにパディング）、テンソルがはるかに小さくなります。配置の再構築は、bboxes 出力を Layers From Bounding Boxes に渡して行います。デフォルト: false（フルキャンバス）。 | BOOLEAN | いいえ | false (full canvas)<br />true (minimal size) |

注: 入力画像は1枚である必要があります。バッチには対応していません。画像は少なくとも512x512ピクセルで、アスペクト比が1:16から16:1の間である必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `base_image` | レイヤーが積み重なるベース画像（背景プレート）。 | IMAGE |
| `base_mask` | ベース画像の透明度（1 = 透明、LoadImage の規則）。現在は常に完全不透明です。 | MASK |
| `layers` | 下から上へ並んだ透明レイヤー。フルキャンバスモード: ベースサイズの黒いキャンバス上のバウンディングボックス位置に配置されます。最小サイズモード: バウンディングボックスにクロップされ、左上基準で最大レイヤーにパディングされます。 | IMAGE |
| `masks` | レイヤーごとの透明度。layers バッチとインデックスが一致します（1 = 透明、LoadImage の規則）。ImageCompositeMasked スタイルの合成には、先に InvertMask を追加してください。 | MASK |
| `bboxes` | レイヤーごとに1つの配置ボックス。layers バッチとインデックスが一致します（両方とマスクを Layers From Bounding Boxes に渡すと、レイヤーごとの配置を再構築できます）: `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`。`content_rect = [left, top, width, height]` は、そのレイヤー自身のフレーム内でのコンテンツ領域です。キャンバス上では、ボックス位置にそのオフセットを加えた位置に配置されます。 | BOUNDING_BOX |
| `layer_stack` | Create Layered Image 用の編集可能なレイヤードキュメント: ベースプレートと、各要素が独自の名前付きタイトクロップレイヤーとして、実際の位置とスタック順で含まれます。直接接続するか、Add Layer で拡張できます。 | LAYERS |
