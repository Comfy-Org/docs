ByteDance Seedream 5.0 Pro レイヤー分離は、画像を背景プレートと最大16個の透明レイヤーに分解します。各レイヤーには、独自のスタック順序、バウンディングボックス、名前、説明が付与されます。背景、レイヤーごとのマスク付き画像、配置ボックス、そして編集可能なレイヤースタックを返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 分離する画像。画像は1枚のみで、512x512ピクセル以上、アスペクト比は1:16から16:1の範囲である必要があります。約4MPを超える入力は、アップロード前にダウンスケールされます。 | IMAGE | はい | Single image |
| `prompt` | 画像を分離する方法。空のままにすると、主要な要素を自動検出してすべて分離します。自然言語で要素を記述して分離を制御するか、`<bbox>left top right bottom</bbox>` タグ（0〜1000のパーミル座標）で正確な領域を指定できます。デフォルト：空文字列。 | STRING | はい | Multiline text |
| `size` | 出力解像度レベル。"auto"は入力画像サイズに従います（1K〜2K範囲にクランプされます）。デフォルト："auto"。 | COMBO | はい | "auto"<br />"1K"<br />"1.5K"<br />"2K" |
| `seed` | 生成に使用するシード。デフォルト：0。 | INT | はい | 0〜2147483647 |
| `prompt_optimization` | プロンプト最適化モード："standard"は高品質、"fast"は生成時間が短くなります。デフォルト："standard"。 | COMBO | いいえ | "standard"<br />"fast" |
| `watermark` | 画像に「AI生成」透かしを追加するかどうか。デフォルト：false。 | BOOLEAN | いいえ | false<br />true |
| `crop_layers` | レイヤー/マスクのバッチ出力の形状です（`layer_stack` は影響を受けず、常にタイトな状態です）。フルキャンバス：各レイヤーをベースサイズのキャンバス上のバウンディングボックス位置に配置します。ImageCompositeMasked で直接再合成できます。最小サイズ：各レイヤーをバウンディングボックスにクロップします（バッチ処理のため最大レイヤーにパディングされます）。テンソルがはるかに小さくなります。配置を再構築するには、`bboxes` 出力を使用して Layers From Bounding Boxes に入力します。デフォルト：false（フルキャンバス）。 | BOOLEAN | いいえ | false (full canvas)<br />true (minimal size) |

注：入力 `image` は単一画像である必要があります。バッチはサポートされていません。画像は512x512ピクセル以上で、アスペクト比が1:16から16:1の間である必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `base_image` | レイヤーが積み重なるベース画像（背景プレート）。 | IMAGE |
| `base_mask` | ベース画像の透明度（1 = 透明、LoadImage の規則）。現在は常に完全不透明です。 | MASK |
| `layers` | 下から上へ順に並んだ透明レイヤー。フルキャンバスモードでは、ベースサイズの黒キャンバス上のバウンディングボックス位置に配置されます。最小サイズモードでは、バウンディングボックスにクロップされ、左上に配置され、最大レイヤーにパディングされます。 | IMAGE |
| `masks` | レイヤーごとの透明度。`layers` バッチとインデックスが対応します（1 = 透明、LoadImage の規則）。ImageCompositeMasked スタイルの合成では、最初に InvertMask を追加してください。 | MASK |
| `bboxes` | レイヤーごとに1つの配置ボックス。`layers` バッチとインデックスが対応します（layers と bboxes を masks と一緒に Layers From Bounding Boxes に入力すると、レイヤーごとの配置を再構築できます）：`{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`。`content_rect = [left, top, width, height]` は、レイヤー自身のフレーム内におけるコンテンツ領域です。キャンバス上では、ボックス位置にそのオフセットを加えた位置に配置されます。 | BOUNDING_BOX |
| `layer_stack` | Create Layered Image 用の編集可能なレイヤードキュメント。ベースプレートと、各要素がそれぞれ名前付きのタイトクロップされたレイヤーとして、実際の位置とスタック順で含まれます。直接接続するか、Add Layer で拡張できます。 | LAYERS |
