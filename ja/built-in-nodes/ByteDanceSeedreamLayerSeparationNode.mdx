ByteDance Seedream 5.0 Pro Layer Separation は、画像を背景プレートと最大16枚の再配置可能な透明レイヤーに分解します。各レイヤーには重なり順、バウンディングボックス、名前、説明があります。背景、マスク付きのレイヤーごとの画像、配置ボックス、すぐに編集できるレイヤースタックを返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 分離する画像。画像はちょうど1枚で、少なくとも512x512ピクセル、アスペクト比は1:16～16:1である必要があります。約4MPを超える入力は、アップロード前にダウンスケールされます。 | IMAGE | はい | 単一画像 |
| `prompt` | 画像をどのように分離するか。空のままにすると、主要な要素を自動検出してすべて分離します。自然言語で要素を記述して分離を制御するか、`<bbox>left top right bottom</bbox>` タグ（0～1000のパーミル座標）で正確な領域を指定できます。デフォルト：空文字列。 | STRING | はい | 複数行テキスト |
| `size` | 出力解像度レベル。"auto" は入力画像サイズに従います（1K～2K の範囲にクランプされます）。デフォルト："auto"。 | COMBO | はい | "auto"<br />"1K"<br />"1.5K"<br />"2K" |
| `seed` | 生成に使用するシード。デフォルト：0。 | INT | はい | 0～2147483647 |
| `prompt_optimization` | プロンプト最適化モード："standard" はより高品質に、"fast" はより短い生成時間になります。デフォルト："standard"。 | COMBO | いいえ | "standard"<br />"fast" |
| `watermark` | 画像に「AI generated」ウォーターマークを追加するかどうか。デフォルト：false。 | BOOLEAN | いいえ | false<br />true |
| `crop_layers` | layers/masks バッチ出力のジオメトリ（layer_stack は影響を受けず、常に余白がありません）。フルキャンバス：各レイヤーを、そのバウンディングボックス位置に配置したベースサイズのキャンバス上に置きます - ImageCompositeMasked で直接再合成できます。最小サイズ：各レイヤーをそのバウンディングボックスにクロップします（バッチ処理のため最大レイヤーにパディングされます） - はるかに小さいテンソルになります。bboxes 出力を使用して Layers From Bounding Boxes で配置を再構築してください。デフォルト：false（フルキャンバス）。 | BOOLEAN | いいえ | false（フルキャンバス）<br />true（最小サイズ） |

注：入力 `image` は単一画像である必要があり、バッチはサポートされていません。画像は少なくとも512x512ピクセルで、アスペクト比は1:16～16:1である必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `base_image` | レイヤーが重ねられるベース画像（背景プレート）。 | IMAGE |
| `base_mask` | ベース画像の透明度（1 = 透明、LoadImage の規約）。現在は常に完全に不透明です。 | MASK |
| `layers` | 下から上へ並んだ透明レイヤー。フルキャンバスモード：ベースサイズの黒いキャンバス上に、それぞれのバウンディングボックス位置に配置されます。最小サイズモード：それぞれのバウンディングボックスにクロップされ、左上を基準に配置され、最大レイヤーに合わせてパディングされます。 | IMAGE |
| `masks` | レイヤーごとの透明度。layers バッチとインデックスが揃っています（1 = 透明、LoadImage の規約）。ImageCompositeMasked 形式の合成を行う場合は、先に InvertMask を追加してください。 | MASK |
| `bboxes` | レイヤーごとに1つの配置ボックス。layers バッチとインデックスが揃っています（レイヤーごとの配置を再構築するには、layers と bboxes の両方、さらに masks を Layers From Bounding Boxes に渡します）：`{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`。`content_rect = [left, top, width, height]` は、レイヤー自身のフレーム内におけるコンテンツ領域です。これは、ボックス位置にそのオフセットを加えた位置でキャンバス上に配置されます。 | BOUNDING_BOX |
| `layer_stack` | Create Layered Image 用のすぐに編集できるレイヤードキュメント：ベースプレートと、各要素をそれぞれ名前付きの、余白を除いてクロップされたレイヤーとして、実際の位置と重なり順で含みます。直接接続するか、Add Layer で拡張できます。 | LAYERS |
