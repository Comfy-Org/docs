SamplerSASolver ノードは、拡散モデル用のカスタムサンプラーを作成および設定します。設定可能な予測子-修正子スキームと確率微分方程式（SDE）設定を備えた `sa_solver` サンプリングアルゴリズムを使用し、サンプリングノードに接続できるサンプラーオブジェクトを返します。`sde_start_percent` と `sde_end_percent` の値は、接続されたモデルのサンプリングスケジュールを使用してシグマ値に変換され、確率的成分が適用される区間を定義します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | サンプラーの構築に使用するサンプリングスケジュールを持つ拡散モデル | MODEL | はい | - |
| `eta` | SDE ソルバーのステップサイズスケーリング係数を制御します（デフォルト: 1.0） | FLOAT | いいえ | 0.0 - 10.0 |
| `sde_start_percent` | 確率的（SDE）成分が開始するサンプリングプロセスの開始割合。モデルのスケジュールを使用してシグマ値に変換されます（デフォルト: 0.2） | FLOAT | いいえ | 0.0 - 1.0 |
| `sde_end_percent` | 確率的（SDE）成分が停止するサンプリングプロセスの終了割合。モデルのスケジュールを使用してシグマ値に変換されます（デフォルト: 0.8） | FLOAT | いいえ | 0.0 - 1.0 |
| `s_noise` | サンプリング中に追加されるノイズ量を制御します（デフォルト: 1.0） | FLOAT | いいえ | 0.0 - 100.0 |
| `predictor_order` | ソルバーにおける予測子成分の次数（デフォルト: 3） | INT | いいえ | 1 - 6 |
| `corrector_order` | ソルバーにおける修正子成分の次数（デフォルト: 4） | INT | いいえ | 0 - 6 |
| `use_pece` | PECE（Predict-Evaluate-Correct-Evaluate）法を有効にします（デフォルト: 無効） | BOOLEAN | いいえ | - |
| `simple_order_2` | 簡略化された2次計算を有効にします（デフォルト: 無効） | BOOLEAN | いいえ | - |

すべてのオプション入力は、インターフェース上で詳細設定としてマークされています。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `sampler` | サンプリングノードで使用できる、設定済みのサンプラーオブジェクト（`sa_solver` アルゴリズムを使用） | SAMPLER |
