Tripoサービスを使用して、テキスト記述から3Dモデルを生成します。このノードはプロンプトと設定をTripoに送信し、生成タスクが完了するのを待って、完成した3Dファイルをタスク識別子とともに返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成するモデルのテキスト記述。空にすることはできません。 | STRING | はい | 複数行テキスト |
| `negative_prompt` | 生成されたモデルに含めるべきでない内容を記述したテキスト。最大255文字。 | STRING | いいえ | 複数行テキスト、最大255文字 |
| `model_version` | 生成に使用するTripoモデルバージョン（デフォルト: `v3.1_20260211`）。 | COMBO | いいえ | サポートされているTripoモデルバージョンのリスト |
| `texture` | テクスチャマップを生成します。オフにするとテクスチャなしのジオメトリを返し、`pbr` を無視します（デフォルト: True）。 | BOOLEAN | いいえ | True<br />False |
| `pbr` | PBRマテリアルマップ（ベースカラー、メタリック、ラフネス、ノーマル）。`texture` が必要です（デフォルト: True）。 | BOOLEAN | いいえ | True<br />False |
| `image_seed` | 画像生成用のシード値（デフォルト: 42）。 | INT | いいえ | 0～2147483647 |
| `model_seed` | モデル生成用のシード値（デフォルト: 42）。 | INT | いいえ | 0～2147483647 |
| `texture_seed` | テクスチャ生成用のシード値（デフォルト: 42）。 | INT | いいえ | 0～2147483647 |
| `texture_quality` | テクスチャの詳細レベル（デフォルト: "standard"）。"detailed" = HDテクスチャ、"extreme" = 8K Ultraテクスチャ。 | COMBO | いいえ | `"standard"`<br />`"detailed"`<br />`"extreme"` |
| `face_limit` | 最大フェイス数。-1 を指定すると、Tripoが適応的に選択します（v3.x standard では約1.4Mフェイス、detailed では2M）。Tripoは通知なしでクランプします: v2.5 では500,000、quadメッシュでは150,000（デフォルト: -1）。 | INT | いいえ | -1～2000000 |
| `quad` | クアッドメッシュ出力。TripoはクアッドメッシュをFBXとして提供するため、結果はFBX出力に格納され、GLB出力は空のままになります（デフォルト: False）。 | BOOLEAN | いいえ | True<br />False |
| `geometry_quality` | ジオメトリの詳細レベル（デフォルト: "standard"）。 | COMBO | いいえ | `"standard"`<br />`"detailed"` |
| `smart_low_poly` | クリーンで手作り風のトポロジーを持つローポリメッシュ（500～20,000フェイス、quadでは500～10,000）。単純な被写体に最適ですが、複雑なものは失敗する可能性があります（デフォルト: False）。 | BOOLEAN | いいえ | True<br />False |
| `auto_size` | テクスチャ付きモデルを実世界のサイズ（メートル）にスケーリングします。Tripoはサイズをモデルのシーントランスフォームとして保存し、モデルが変換、リギング、またはリターゲットされるときにベイクします。テクスチャがない場合は無視されます（デフォルト: True）。 | BOOLEAN | いいえ | True<br />False |

### 注意事項

- `prompt` は必須で、空または空白のみにすることはできません。
- `texture` がFalseに設定されている場合、`pbr` は強制的にオフになり、`auto_size` は効果がありません。
- `smart_low_poly` が有効で、`face_limit` が -1 でない場合、`face_limit` は三角形メッシュでは500～20,000、`quad` が有効な場合は500～10,000の範囲でなければなりません。
- `quad` が有効な場合、TripoはFBXファイルを返すため、`GLB` 出力は空のままになり、`FBX` 出力にデータが格納されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model task_id` | モデルを生成したTripo生成タスクの識別子。 | MODEL_TASK_ID |
| `GLB` | GLB形式で生成されたモデル。`quad` が有効な場合は空です。 | FILE3D_GLB |
| `FBX` | FBX形式で生成されたモデル。`quad` が有効な場合のみ格納されます。 | FILE3D_FBX |
