The Magnific Image Upscale (Precise V2) ノードは、シャープネス、グレイン、ディテール強調を細かく制御しながら、高忠実度の画像アップスケールを実行します。外部APIを通じて画像を処理し、最大出力解像度は10060×10060ピクセルまで対応しています。このノードは異なる処理スタイルを提供し、要求された出力が最大許容サイズを超える場合、入力画像を自動的にダウンスケールすることもできます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | アップスケールする入力画像です。画像は1枚のみ必要です。最小寸法は160x160ピクセルです。アスペクト比は1:3から3:1の間である必要があります。 | IMAGE | はい | - |
| `拡大倍率` | 希望するアップスケール倍率です。 | COMBO | はい | `"2x"`<br />`"4x"`<br />`"8x"`<br />`"16x"` |
| `フレーバー` | 処理スタイルです。sublime は一般的な用途、photo は写真、photo_denoiser はノイズの多い写真向けです。 | COMBO | はい | `"sublime"`<br />`"photo"`<br />`"photo_denoiser"` |
| `シャープネス` | 画像のシャープネスの強度です。値を高くすると、エッジの定義と明瞭さが向上します。デフォルト: 7。 | INT | いいえ | 0 から 100 |
| `スマートグレイン` | 画像が滑らかすぎたり、人工的に見えたりするのを防ぐための、インテリジェントなグレイン/テクスチャ強調です。デフォルト: 7。 | INT | いいえ | 0 から 100 |
| `ウルトラディテール` | アップスケール中に追加される微細なディテール、テクスチャ、マイクロディテールを制御します。デフォルト: 30。 | INT | いいえ | 0 から 100 |
| `自動ダウンスケール` | 出力が最大解像度を超える場合に、入力画像を自動的にダウンスケールします。デフォルト: False。 | BOOLEAN | いいえ | - |

**注:** `auto_downscale` が無効で、要求された出力サイズ（入力寸法 × `scale_factor`）が10060×10060ピクセルを超える場合、ノードはエラーを発生させます。`auto_downscale` が有効な場合、ノードは品質損失を最小限に抑える最適なスケールファクターを探します。

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | アップスケール後の結果画像です。 | IMAGE |
