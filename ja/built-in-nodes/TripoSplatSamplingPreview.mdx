このノードは TripoSplat モデルにパッチを適用し、標準の KSampler ノードで使用すると、各サンプリングステップでデコードされたガウシアンスプラットのライブプレビューが表示されます。その仕組みは、サンプラーのコールバックをラップして、毎ステップ後にモデルの出力をプレビュー画像へデコードするというものです。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | ライブプレビュー用にパッチを適用する TripoSplat モデル | MODEL | はい | |
| `vae` | TripoSplat VAE デコーダー | VAE | はい | |
| `octree_level` | プレビューデコードのオクツリー深度（低いほど軽量/粗くなります）。デフォルト: 5 | INT | いいえ | 2〜8 |
| `num_gaussians` | プレビュー用に生成するガウシアンの数（32の倍数に丸められます）。デフォルト: 16384 | INT | いいえ | 1024〜262144 (step: 32) |
| `yaw` | プレビューカメラのヨー（度単位）。デフォルト: 90.0 | FLOAT | いいえ | -360.0〜360.0 (step: 1.0) |
| `pitch` | プレビューカメラのピッチ（度単位）。デフォルト: 15.0 | FLOAT | いいえ | -89.0〜89.0 (step: 1.0) |
| `point_size` | スプラットの最大半径（ピクセル単位）。各ガウシアンはスケールに基づいてサイズが決まり、ここで上限が設定されます。低いほど細かく/点状になり、高いほど塊状になります。デフォルト: 3 | INT | いいえ | 1〜16 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `MODEL` | ライブプレビュー機能が追加された、パッチ適用済みの TripoSplat モデル | MODEL |
