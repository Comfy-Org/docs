ComfyMathExpression ノードは、テキストとして記述した数式を評価します。数式は、`a`、`b`、`c` などの文字名を使用してノードの入力値を参照でき、拡張可能な `values` グループを通じて必要なだけ入力値を追加できます。計算結果は、浮動小数点数、整数、およびブール値として同時に返されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `式` | 評価する数式をテキストとして記述します（例：`a + b`）。入力値の文字名を変数として使用します。複数行入力です。（デフォルト: "a + b"） | STRING | はい | N/A |
| `値` | 数式の変数を提供する拡張可能な入力値のグループです。グループに追加された各値には、`a` から始まる次の小文字の名前（`a`、`b`、`c`、...）が自動的に付けられ、その名前を `expression` 内で使用できます。各項目は数値（INT または FLOAT）またはブール値（TRUE/FALSE）を受け付けます。 | FLOAT, INT, BOOLEAN | はい | 1 〜 26 values, named `a` to `z` |

### 注意事項と制約

- `expression` は空にすることも、空白のみを含めることもできません。
- 数式は数値結果（INT または FLOAT）またはブール結果（TRUE/FALSE）に評価される必要があります。ブール結果は TRUE を 1、FALSE を 0 として扱います。結果がテキストなど別の型の場合、ノードはエラーを発生させます。
- 数値結果は有限で、float に変換可能である必要があります。大きすぎる結果や非有限の結果はエラーを引き起こします。
- 入力値のセット全体は、変数名 `values` として（リストとして）数式内でも使用できるため、`sum(values)` のような数式も可能です。
- 数式内では以下の数学関数を使用できます：`sum`、`min`、`max`、`abs`、`round`、`pow`、`sqrt`、`ceil`、`floor`、`log`、`log2`、`log10`、`sin`、`cos`、`tan`、`int`、`float`。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `FLOAT` | 数式の結果を浮動小数点数として表したものです。 | FLOAT |
| `INT` | 数式の結果を整数に変換したもので、小数部分は切り捨てられます。 | INT |
| `BOOL` | 結果をブール値に変換したものです。数値結果がゼロでない場合は TRUE、ゼロの場合は FALSE になります。 | BOOLEAN |
