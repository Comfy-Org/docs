ComfyMathExpression ノードは、テキストで記述した数式を評価します。数式では、`a`、`b`、`c` などの英字名を使ってノードの入力値を参照できます。必要な入力値は、拡張可能な `values` グループを通じて必要な数だけ追加できます。計算結果は、浮動小数点数・整数・ブール値として同時に返されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `式` | 評価する数式をテキストで記述します（例：`a + b`）。入力値の英字名を変数として使用できます。複数行入力可能です（デフォルト: "a + b"）。 | STRING | はい | N/A |
| `値` | 数式で使用する変数を提供する、拡張可能な入力値グループです。グループに追加された各値には、自動的に `a` から始まる次の小文字英字名（`a`、`b`、`c`、...）が割り当てられ、その名前を `expression` 内で使用できます。各項目は数値（INT または FLOAT）またはブール値（TRUE/FALSE）を受け入れます。 | FLOAT, INT, BOOLEAN | はい | 1～26個の値。`a` から `z` まで命名されます |

### 注記と制約

- `expression` を空文字列にしたり、空白のみにしたりすることはできません。
- 数式は数値結果（INT または FLOAT）に評価される必要があります。結果がテキストなどの別の型になる場合は、ノードはエラーを発生させます。
- 数値結果は有限であり、float に変換可能である必要があります。大きすぎる結果や非有限の結果はエラーになります。
- すべての入力値一式は、式内で `values` という変数名（リストとして）でも参照できます。したがって、`sum(values)` のような式も可能です。
- 式内では、以下の数学関数が利用できます：`sum`、`min`、`max`、`abs`、`round`、`pow`、`sqrt`、`ceil`、`floor`、`log`、`log2`、`log10`、`sin`、`cos`、`tan`、`int`、`float`。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `FLOAT` | 式の結果を浮動小数点数として返します。 | FLOAT |
| `INT` | 式の結果を整数に変換したものです。小数部は切り捨てられます。 | INT |
| `BOOL` | 結果をブール値に変換したものです。数値結果が 0 以外の場合は TRUE、0 の場合は FALSE になります。 | BOOLEAN |
