ChromaRadianceOptions ノードは、Chroma Radiance モデルの詳細設定を構成できます。既存のモデルにラッパーをアタッチし、現在の sigma 値が設定された範囲内にある場合にのみ、選択したオプションをデノイジング処理中に適用します。これにより、NeRF タイルサイズとテキストトークン ID の処理を制御できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | Chroma Radiance オプションを適用するモデル | MODEL | はい | - |
| `ラッパーを保持` | 有効にすると、既存のモデル関数ラッパーが存在する場合、それに委譲します。通常は有効のままにしてください。（デフォルト: True） | BOOLEAN | いいえ | - |
| `開始シグマ` | これらのオプションが有効になる最初の sigma 値。（デフォルト: 1.0） | FLOAT | いいえ | 0.0～1.0 |
| `終了シグマ` | これらのオプションが有効になる最後の sigma 値。（デフォルト: 0.0） | FLOAT | いいえ | 0.0～1.0 |
| `NeRFタイルサイズ` | デフォルトの NeRF タイルサイズを上書きできます。-1 はデフォルト（32）の使用を意味します。0 は非タイリングモードの使用を意味します（大量の VRAM を必要とする場合があります）。（デフォルト: -1） | INT | いいえ | -1 以上 |
| `force_sequential_txt_ids` | ゼロではなく連続したテキストトークン ID の使用を強制します。2026-05-22 から 2026-06-01 までのチェックポイントで、この方法でトレーニングされているが、state dict に __sequential__ キーが含まれていない場合に使用する必要があります。（デフォルト: False） | BOOLEAN | いいえ | - |

**注:** Chroma Radiance オプションは、現在の sigma 値が `end_sigma` と `start_sigma` の間（両端を含む）にある場合にのみ有効になります。`nerf_tile_size` オプションは、0 以上に設定された場合にのみ適用されます（-1 の場合はデフォルトのタイルサイズ 32 を使用し、上書き設定を保存しません）。`force_sequential_txt_ids` オプションは、True に設定された場合にのみ適用されます。`nerf_tile_size` が -1 で `force_sequential_txt_ids` が False の場合、オプションは構成されず、モデルはラッパーが適用されないまま変更されずに返されます。

**注:** `model` 以外のすべての入力は詳細オプションです。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model` | Chroma Radiance オプションが適用されたモデル、または有効なオプションがない場合は変更されていないモデル | MODEL |
