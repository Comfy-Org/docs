ChromaRadianceOptions ノードを使用すると、Chroma Radiance モデルの高度な設定を構成できます。既存のモデルをラップし、シグマ値に基づいてノイズ除去プロセス中に特定のオプションを適用することで、NeRF タイルサイズやその他のラディアンス関連パラメータを細かく制御できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | Chroma Radiance オプションを適用するモデル | MODEL | 必須 | - |
| `ラッパーを保持` | 有効にすると、既存のモデル関数ラッパーが存在する場合に委譲します。通常は有効のままにしておく必要があります。(デフォルト: True) | BOOLEAN | 任意 | - |
| `開始シグマ` | これらのオプションが有効になる最初のシグマ値。(デフォルト: 1.0) | FLOAT | 任意 | 0.0〜1.0 |
| `終了シグマ` | これらのオプションが有効になる最後のシグマ値。(デフォルト: 0.0) | FLOAT | 任意 | 0.0〜1.0 |
| `NeRFタイルサイズ` | デフォルトの NeRF タイルサイズを上書きできます。-1 はデフォルト (32) を使用することを意味します。0 は非タイリングモードを使用することを意味します（多くの VRAM を必要とする場合があります）。(デフォルト: -1) | INT | 任意 | -1 and above |
| `force_sequential_txt_ids` | ゼロの代わりにシーケンシャルなテキストトークン ID の使用を強制します。2026-05-22 から 2026-06-01 までのチェックポイントで、この方法でトレーニングされているが、state dict に `__sequential__` キーが含まれていない場合に使用する必要があります。(デフォルト: False) | BOOLEAN | 任意 | - |

**注記:** Chroma Radiance オプションは、現在のシグマ値が `end_sigma` と `start_sigma` の間（両端を含む）にある場合にのみ有効になります。`nerf_tile_size` パラメータは、0 以上の値に設定されている場合にのみ適用されます。`force_sequential_txt_ids` パラメータは、True に設定されている場合にのみ適用されます。`nerf_tile_size` が -1 で `force_sequential_txt_ids` が False の場合、オプションは設定されず、モデルはラッパーが適用されずにそのまま返されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model` | Chroma Radiance オプションが適用されたモデル、またはオプションが有効でない場合は変更されていないモデル | MODEL |
