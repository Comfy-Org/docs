Google の Veo 3 API を使用して、テキストプロンプトから動画を生成します。このノードは、fast および lite バリアントを含む複数の Veo 3 モデルをサポートしており、動画の解像度、長さ、オーディオ生成を指定できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 動画のテキストによる説明（デフォルト: ""） | STRING | 必須 | - |
| `アスペクト比` | 出力動画のアスペクト比（デフォルト: "16:9"） | COMBO | 必須 | "16:9"<br />"9:16" |
| `解像度` | 出力動画の解像度。4K は veo-3.1-lite モデルでは利用できません。（デフォルト: "720p"） | COMBO | 任意 | "720p"<br />"1080p"<br />"4k" |
| `ネガティブプロンプト` | 動画で避けるべき内容を指定するためのネガティブテキストプロンプト（デフォルト: ""） | STRING | 任意 | - |
| `秒数` | 出力動画の長さ（秒）（デフォルト: 8） | INT | 任意 | 4 - 8（ステップ 2） |
| `プロンプトの強化` | このパラメータは非推奨であり、無視されます。（デフォルト: True） | BOOLEAN | 任意 | - |
| `人物生成` | 動画内に人物を生成することを許可するかどうか（デフォルト: "ALLOW"） | COMBO | 任意 | "ALLOW"<br />"BLOCK" |
| `シード` | 動画生成のシード（0 はランダム）（デフォルト: 0） | INT | 任意 | 0 - 4294967295 |
| `画像` | 動画生成をガイドするためのオプションの参照画像 | IMAGE | 任意 | - |
| `モデル` | 動画生成に使用する Veo 3 モデル（デフォルト: "veo-3.1-generate"） | COMBO | 任意 | "veo-3.1-generate"<br />"veo-3.1-fast-generate"<br />"veo-3.1-lite" |
| `オーディオ生成` | 動画のオーディオを生成します。すべての Veo 3 モデルでサポートされています。（デフォルト: False） | BOOLEAN | 任意 | - |

**注記:** `enhance_prompt` パラメータは非推奨であり、その値は無視されます。ノードは常にプロンプトを内部で強化します。veo-3.1-lite モデルで "4k" 解像度を選択した場合、ノードはエラーを発生させます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された動画ファイル | VIDEO |
