ModelMergeMOSSImage ノードは、2 つの MOSS 画像モデルを、対応する重みをブロックごとにブレンドすることでマージします。これにより、結果の一部をベースモデルから、残りをファインチューンまたは 2 番目のモデルから取得できます。アーキテクチャの主要コンポーネントごとに個別の比率があります。ビデオエンベッダー、テキストエンベッダー、時間埋め込み、共有ブロック変調、42 個すべての Transformer レイヤー、および出力ヘッドです。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model1` | マージする最初のモデルです。2 番目のモデルが寄与しない部分はすべてこのモデルから保持されます | MODEL | はい | - |
| `model2` | マージする 2 番目のモデルです。その重みは、以下の比率に従ってブレンドされます | MODEL | はい | - |
| `video_embedder.` | ビデオエンベッダーブロックのブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |
| `text_embedder.proj.` | テキストエンベッダーの投影層のブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |
| `text_embedder.blocks.0.` と `text_embedder.blocks.1.` | 2 つのテキストエンベッダーブロックそれぞれのブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |
| `time_embedding.` | 時間埋め込みブロックのブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |
| `shared_block_modulation.` | Transformer ブロックで使用される共有変調層のブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |
| `layers.0.` から `layers.41.` まで | 42 個の Transformer レイヤーそれぞれのブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |
| `final_norm_video.` | ビデオストリームの最終正規化のブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |
| `final_linear_video.` | ビデオストリームの最終線形層のブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |
| `video_head_modulation.` | ビデオ出力ヘッドの変調層のブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |

比率 0.0 はそのコンポーネントを `model1` のまま保持し、比率 1.0 は完全に `model2` から取得し、中間の値は重み付きブレンドを生成します。両方の入力は同じアーキテクチャの MOSS 画像モデルである必要があります。上記のどのプレフィックスにも一致しない重みは、`video_embedder.` の比率にフォールバックします。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `MODEL` | 指定された比率に従って両方の入力を組み合わせた、マージ済みモデルです | MODEL |
