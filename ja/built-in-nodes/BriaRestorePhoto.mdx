このノードは、Bria API を通じて古い写真や損傷した写真を修復します。粒子、傷、ぼけを除去し、経年による色かぶりを中和し、台紙やスタジオ枠を切り落とす場合があり、顔を描き直します。結果は約1メガピクセルで再レンダリングされるため、入力とピクセル単位では位置合わせされません。

## 入力

### 共通入力

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `画像` | 修復する写真です。アップロード前にアルファチャンネルは削除されます。 | IMAGE | はい | - |
| `モデレーション` | リクエストのモデレーション設定です。`"true"` を選択すると、追加の2つのブール値トグルが表示されます。`"false"` を選択すると、モデレーションフラグは送信されません。デフォルト: `"false"`。 | DYNAMIC_COMBO | はい | `"false"`<br />`"true"` |

### モデレーション入力

これらの入力は、`moderation` が `"true"` に設定されている場合にのみ表示されます。

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | 入力画像に対する視覚コンテンツのモデレーションを有効にします。デフォルト: false。 | BOOLEAN | いいえ | true<br />false |
| `visual_output_moderation` | 出力画像に対する視覚コンテンツのモデレーションを有効にします。デフォルト: false。 | BOOLEAN | いいえ | true<br />false |

**注意:** このノードはフレーム全体を約1メガピクセルで再レンダリングするため、結果は入力とピクセル単位では位置合わせされません。このノードの代わりに、Bria Increase Resolution ノードを使用して画像を拡大してください。

## 出力

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `IMAGE` | Bria から返される修復済みの写真です。 | IMAGE |
| `structured_prompt` | 編集済み画像の構造化された説明です。Bria FIBO Image Edit による後続の編集に使用します。 | STRING |
