LTXVImgToVideo は、入力画像をビデオ生成モデル用のビデオ潜在表現に変換します。画像を指定された幅と高さにリサイズし、VAE でエンコードして、エンコードされたフレームを、ゼロで満たされたビデオサイズの潜在表現の先頭に配置します。strength コントロールは、ビデオ生成中に元の画像コンテンツがどの程度保持されるか、または変更されるかを決定します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ポジティブ` | ビデオ生成を導くためのポジティブ条件付けプロンプト | CONDITIONING | 必須 | - |
| `ネガティブ` | ビデオ内の特定の要素を避けるためのネガティブ条件付けプロンプト | CONDITIONING | 必須 | - |
| `vae` | 入力画像を潜在空間にエンコードするために使用される VAE モデル | VAE | 必須 | - |
| `画像` | ビデオフレームに変換される入力画像 | IMAGE | 必須 | - |
| `幅` | 出力ビデオの幅（ピクセル単位）（デフォルト: 768、ステップ: 32） | INT | 任意 | 64 to MAX_RESOLUTION |
| `高さ` | 出力ビデオの高さ（ピクセル単位）（デフォルト: 512、ステップ: 32） | INT | 任意 | 64 to MAX_RESOLUTION |
| `長さ` | 生成されるビデオのフレーム数（デフォルト: 97、ステップ: 8） | INT | 任意 | 9 to MAX_RESOLUTION |
| `バッチサイズ` | 同時に生成するビデオの数（デフォルト: 1） | INT | 任意 | 1〜4096 |
| `強度` | 生成されたビデオの最初のフレームに、元の画像コンテンツがどの程度保持されるかを制御します。1.0 の値は元の画像を完全に保持し、0.0 は最大限の変更を許可します（デフォルト: 1.0） | FLOAT | 任意 | 0.0〜1.0 |

注: `width` と `height` は 32 ピクセル単位で変化し、`length` は 8 フレーム単位で変化します。これはビデオ潜在表現の圧縮（空間次元で 32 倍、時間次元で 8 倍）に対応しています。ビデオ潜在表現には ((length - 1) // 8) + 1 フレームが含まれます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `ポジティブ` | 生成された潜在表現と共に使用するために、変更されずに渡されるポジティブ条件付け | CONDITIONING |
| `ネガティブ` | 生成された潜在表現と共に使用するために、変更されずに渡されるネガティブ条件付け | CONDITIONING |
| `潜在` | エンコードされた画像フレームと、ビデオ生成中に条件付けが適用される強度を制御するノイズマスクを含むビデオ潜在表現 | LATENT |
