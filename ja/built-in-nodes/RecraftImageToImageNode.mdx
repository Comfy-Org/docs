このノードは、テキストプロンプトと強度パラメータに基づいて既存の画像を変更します。Recraft V3 API を使用して、指定された説明に従って入力画像を変換しつつ、強度設定によって元の画像との類似性をある程度維持します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | 変更対象の入力画像です。 | IMAGE | はい | - |
| `プロンプト` | 画像生成用のプロンプトです（デフォルト: 空文字、最大長: 1000文字）。 | STRING | はい | - |
| `生成数` | 生成する画像の枚数です（デフォルト: 1）。 | INT | はい | 1-6 |
| `強度` | 元画像との差を定義します。[0, 1] の範囲で指定し、0はほぼ同一、1は類似性がほとんどないことを意味します（デフォルト: 0.5）。 | FLOAT | はい | 0.0-1.0 |
| `シード` | ノードを再実行するかどうかを決定するシードです。シードに関係なく、実際の結果は非決定的です（デフォルト: 0）。 | INT | はい | 0-18446744073709551615 |
| `recraft_style` | 画像生成に使用するオプションのスタイル選択です。指定しない場合、`realistic_image` がデフォルトになります。 | STYLEV3 | いいえ | - |
| `ネガティブプロンプト` | 画像内の望ましくない要素のオプションのテキスト記述です（デフォルト: 空文字）。 | STRING | いいえ | - |
| `recraft_controls` | Recraft Controls ノードによる生成への追加のオプション制御です。 | CONTROLS | いいえ | - |

**注記:** `seed` パラメータはノードの再実行をトリガーするだけであり、決定論的な結果を保証するものではありません。`strength` パラメータは内部で小数点第2位に丸められます。`prompt` は検証され、1000文字を超えてはなりません。空の `negative_prompt` はネガティブプロンプトなしとして扱われます。`recraft_style` が指定されない場合、ノードは `realistic_image` スタイルをデフォルトとして使用します。Infinite Style Library の `style_id` を使用する場合、それが Vector アートスタイルでないことを確認してください。Vector アートスタイルを使用すると、ノードが画像ではなく SVG データを受け取り、エラーが発生する可能性があります。入力 `image` がバッチの場合、バッチ内の各画像は個別に処理され、すべての結果がまとめて返されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 入力画像とプロンプトに基づいて生成された画像です。 | IMAGE |
