このノードは、テキストプロンプトと強度設定に基づいて既存の画像を変更します。画像を Recraft V3 API に送信し、プロンプトに従いつつ、強度値に応じて元画像との類似度が変わる新しい画像を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | 変更対象の入力画像。画像のバッチが指定された場合、各画像は個別に処理されます。 | IMAGE | はい | - |
| `プロンプト` | 画像生成用のプロンプト。デフォルト: 空文字列。最大長: 1000 文字。 | STRING | はい | - |
| `生成数` | 生成する画像の数。デフォルト: 1。 | INT | はい | 1-6 |
| `強度` | 元画像との差分を定義します。[0, 1] の範囲で指定する必要があり、0 はほぼ同一、1 はほとんど類似していないことを意味します。デフォルト: 0.5。 | FLOAT | はい | 0.0-1.0 （ステップ 0.01） |
| `シード` | ノードを再実行するかどうかを決めるシード。実際の結果はシードに関係なく非決定的です。デフォルト: 0。 | INT | はい | 0-18446744073709551615 |
| `recraft_style` | 画像生成用のオプションのスタイル選択。指定しない場合、デフォルトは `realistic_image` です。 | STYLEV3 | いいえ | - |
| `ネガティブプロンプト` | 画像上で望ましくない要素を表すオプションのテキスト記述。デフォルト: 空文字列。入力ソケットとして提供されます。 | STRING | いいえ | - |
| `recraft_controls` | Recraft Controls ノードを介した、生成に対するオプションの追加制御。 | CONTROLS | いいえ | - |

**注:** `seed` パラメータはノードの再実行をトリガーするだけであり、決定的な結果を保証するものではありません。`strength` パラメータは内部的に小数点以下 2 桁に丸められます。`prompt` は検証され、1000 文字を超えてはいけません。空の `negative_prompt` はネガティブプロンプトなしとして扱われます。`recraft_style` が指定されない場合、ノードはデフォルトで `realistic_image` スタイルになります。Infinite Style Library の `style_id` を使用する場合は、ベクターアートスタイルでないことを確認してください。ベクターアートスタイルの場合、ノードが画像ではなく SVG データを受け取り、エラーになる可能性があります。入力 `image` がバッチの場合、バッチ内の各画像が個別に処理され、すべての結果がまとめて返されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 入力画像、プロンプト、強度に基づいて生成された画像。 | IMAGE |
