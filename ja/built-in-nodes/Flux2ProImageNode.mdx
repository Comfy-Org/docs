プロンプトと明示的な出力寸法を指定し、必要に応じて参照画像にガイドされながら、BFL API を介して Flux.2 [pro] で画像を生成します。

**注:** このノードはソースコード上で非推奨としてマークされています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 画像生成または編集のためのプロンプト。 | STRING | はい | - |
| `幅` | 生成画像の幅（ピクセル、デフォルト: 1024）。 | INT | はい | 256 〜 2048 （ステップ 32） |
| `高さ` | 生成画像の高さ（ピクセル、デフォルト: 768）。 | INT | はい | 256 〜 2048 （ステップ 32） |
| `シード` | ノイズの生成に使用される乱数シード（デフォルト: 0）。 | INT | はい | 0 〜 18446744073709551615 |
| `プロンプトアップサンプリング` | プロンプトに対してアップサンプリングを実行するかどうか。有効にすると、より創造的な生成のためにプロンプトが自動的に変更されます（デフォルト: `True`）。これは詳細設定です。 | BOOLEAN | はい | True / False |
| `画像` | 画像から画像への生成用の任意の参照画像。各画像はアップロード前に最大 2048x2048 ピクセルに縮小されます。 | IMAGE | いいえ | 0 〜 9 枚の画像 |

**制約:**

* 9 枚を超える参照画像を接続するとエラーが発生します。
* 出力サイズはメガピクセル単位で課金されるため、`width` と `height` の値が大きいほどコストが高くなります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | 生成された画像。 | IMAGE |
