# ByteDance First-Last-Frame to Video

このノードは、テキストプロンプトと画像の最初および最後のフレームを使用してビデオを生成します。これにより、2つのフレーム間に滑らかな遷移が生まれ、完全なビデオシークエンスが作成されます。このノードは、ビデオの解像度、アスペクト比、長さ、および追加の生成パラメータをカスタマイズするためのオプションを提供します。

## 入力

|-----------|-------------|-----------|----------|-------|
| `モデル` | ビデオ生成に使用するモデル。利用可能なオプションから選択してください（デフォルト: `"seedance-1-5-pro-251215"`）。 | COMBO | はい | `"seedance-1-5-pro-251215"`<br />`"seedance-1-0-pro-250528"` |
| `プロンプト` | ビデオ生成に使用するテキストプロンプト。このプロンプトには、解像度、比率、長さ、シード、カメラ固定、ウォーターマークなどの特定のパラメータを含めるべきではありません。 | STRING | はい | - |

## 注意事項

- `model`パラメータは、ビデオ生成プロセスの機能と制限を決定します。
- `prompt`は創造的で明確であるべきであり、ビデオ生成を導きます。
- `first_frame`および`last_frame`の画像は、望むビデオコンテンツを代表するものを選んでください。
- `resolution`および`aspect_ratio`パラメータは、最終出力ビデオの品質と寸法に影響を与えます。
- `duration`パラメータは、ビデオの長さを設定し、最小3秒から最大12秒です。
- `seed`パラメータはオプションであり、ビデオ生成プロセスの再現性を目的に使用できます。
- `camera_fixed`パラメータは、期待される効果が常に得られない可能性のある高度なオプションです。
- `watermark`パラメータは、ビデオにウォーターマークを追加して、AIによって生成されたことを示すことができます。
- `generate_audio`パラメータは、現在、`seedance-1-5-pro-251215`モデル以外のすべてのモデルでは無視されます。
