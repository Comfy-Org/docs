このノードは、テキストプロンプトと最初および最後のフレーム画像を使用して動画を生成します。説明文と2つのキーフレームを受け取り、それらの間を遷移する完全な動画シーケンスを作成します。このノードは、動画の解像度、アスペクト比、長さ、その他の生成パラメータを制御するためのさまざまなオプションを提供します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | 動画生成に使用するモデル（デフォルト: `"seedance-1-5-pro-251215"`）。 | COMBO | はい | `"seedance-1-5-pro-251215"`<br />`"seedance-1-0-pro-250528"` |
| `プロンプト` | 動画を生成するために使用するテキストプロンプト。空であってはならず、予約済みのパラメータキーワード（`resolution`、`ratio`、`duration`、`seed`、`camerafixed`、`watermark`）を含めることはできません。 | STRING | はい | - |
| `最初のフレーム` | 動画に使用する最初のフレーム。300x300～6000x6000ピクセルの範囲で、アスペクト比は0.4～2.5である必要があります。 | IMAGE | はい | - |
| `最後のフレーム` | 動画に使用する最後のフレーム。300x300～6000x6000ピクセルの範囲で、アスペクト比は0.4～2.5である必要があります。 | IMAGE | はい | - |
| `解像度` | 出力動画の解像度。 | COMBO | はい | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `アスペクト比` | 出力動画のアスペクト比。 | COMBO | はい | `"adaptive"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"` |
| `再生時間` | 出力動画の長さ（秒単位）。`seedance-1-5-pro-251215` を使用する場合、最小の長さは4秒です。（デフォルト: 5） | INT | はい | 3 - 12 |
| `シード` | 生成に使用するシード。（デフォルト: 0） | INT | いいえ | 0 - 2147483647 |
| `カメラ固定` | カメラを固定するかどうかを指定します。プラットフォームはプロンプトにカメラを固定する指示を追加しますが、実際の効果を保証するものではありません。（デフォルト: False） | BOOLEAN | いいえ | - |
| `ウォーターマーク` | 動画に「AI generated」ウォーターマークを追加するかどうか。（デフォルト: False） | BOOLEAN | いいえ | - |
| `generate_audio` | このパラメータは `seedance-1-5-pro-251215` 以外のモデルでは無視されます。（デフォルト: False） | BOOLEAN | いいえ | - |

**注意:** `seedance-1-5-pro-251215` モデルでは、`duration` は4秒以上である必要があります。`first_frame` と `last_frame` はどちらも300x300～6000x6000ピクセルの範囲で、アスペクト比が0.4～2.5である必要があります。`prompt` は予約済みのパラメータキーワードが含まれているとチェックされ、拒否されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | 生成された動画ファイル。 | VIDEO |
