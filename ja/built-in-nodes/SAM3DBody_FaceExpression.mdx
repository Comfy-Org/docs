このノードは、MediaPipe Face Landmarker を使用して画像内の顔を検出し、検出された各顔を追跡中の人物に照合し、52個の ARKit ブレンドシェイプを MHR の72軸の表情パラメータにマッピングすることで、SAM3D ボディに表情を追加します。その後、ボディモデルを再実行して、出力されるメッシュ頂点とキーポイントが新しい表情に一致するようにします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `sam3d_body_model` | 顔の検出に使用する顔ランドマーク検出器を含み、ボディメッシュを再生成するための SAM3D ボディモデル。 | SAM3D_BODY_MODEL | 必須 | - |
| `mhr_pose_data` | フレームごとの追跡人物をバウンディングボックス、キーポイント、表情パラメータとともに含むポーズデータ。このノードは、検出された各顔を人物に照合し、更新された表情パラメータをこのデータに書き込みます。 | MHR_POSE_DATA | 必須 | - |
| `image` | 顔の検出に使用する画像フレーム。画像バッチのフレーム数がポーズデータより少ない場合、残りのフレームには最後のフレームが再利用されます。 | IMAGE | 必須 | - |
| `strength` | すべてのブレンドシェイプに適用されるグローバルな倍率。1より大きいと誇張されます。デフォルト: 1.0。 | FLOAT | 任意 | 0.0〜4.0 (step 0.05, default 1.0) |
| `mouth_strength` | 口・あごのシェイプに適用される倍率。MediaPipe の jawOpen は 1.0 付近で飽和します。デフォルト: 1.0。 | FLOAT | 任意 | 0.0〜4.0 (step 0.05, default 1.0) |
| `eye_strength` | 目のシェイプに適用される倍率。MediaPipe はめったに0.5を超えません。2〜3倍が必要になることがよくあります。デフォルト: 2.0。 | FLOAT | 任意 | 0.0〜4.0 (step 0.05, default 2.0) |
| `brow_strength` | 眉・頬・鼻のしわのシェイプに適用される倍率。MediaPipe の出力は約0.1〜0.3です。2〜3倍にします。デフォルト: 2.0。 | FLOAT | 任意 | 0.0〜4.0 (step 0.05, default 2.0) |
| `input_threshold` | MediaPipe の生の出力に対する不感帯（しきい値未満はゼロ、以上は線形に再マップ）。デフォルト: 0.02。 | FLOAT | 任意 | 0.0〜0.5 (step 0.01, default 0.02) |
| `blendshape_smooth_window` | MHR マッピング前に MediaPipe のフレームごとの信号に適用するガウス窓。MediaPipe の生の出力は、静止した顔でもフレーム間で30〜70%変動します。1 は無効です。奇数の値を使用してください。デフォルト: 7。 | INT | 任意 | 1〜31 (step 2, default 7) |

注: クリップ内の少なくとも30フレームで人物が検出された場合にのみ、クリップごとのベースライン減算が適用されます。人物ごとに最大12フレームまでの検出ギャップは補間によって補完されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `mhr_pose_data` | 更新後のポーズデータ。各追跡人物の表情パラメータはマッピングされた顔の表情に置き換えられ、メッシュ頂点とキーポイントがそれに合わせて再生成されます。 | MHR_POSE_DATA |
