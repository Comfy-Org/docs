このノードは、MediaPipe Face Landmarkerで画像内の顔を検出し、検出された各顔を追跡対象人物に照合し、52個のARKitブレンドシェイプをMHRの72軸表情パラメータにマッピングすることにより、SAM3Dボディに表情を追加します。その後、ボディモデルを再実行して、出力メッシュ頂点とキーポイントが新しい表情を反映するようにします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `sam3d_body_model` | 顔の検出とボディメッシュの再生成に使用される顔ランドマーク検出器を含むSAM3Dボディモデル。 | SAM3D_BODY_MODEL | はい | - |
| `mhr_pose_data` | 各フレームの追跡対象人物のバウンディングボックス、キーポイント、表情パラメータを含むポーズデータ。このノードは検出された各顔を人物に照合し、更新された表情パラメータをこのデータに書き込みます。 | MHR_POSE_DATA | はい | - |
| `image` | 顔の検出に使用される画像フレーム。画像バッチのフレーム数がポーズデータより少ない場合、残りのフレームには最後のフレームが再利用されます。 | IMAGE | はい | - |
| `strength` | すべてのブレンドシェイプに適用されるグローバル乗数。1より大きいと誇張されます。デフォルト: 1.0。 | FLOAT | いいえ | 0.0～4.0（ステップ0.05、デフォルト1.0） |
| `mouth_strength` | 口/顎のシェイプに適用される乗数。MediaPipeのjawOpenは1.0付近で飽和します。デフォルト: 1.0。 | FLOAT | いいえ | 0.0～4.0（ステップ0.05、デフォルト1.0） |
| `eye_strength` | 目のシェイプに適用される乗数。MediaPipeは0.5を超えることはほとんどなく、しばしば2～3倍が必要です。デフォルト: 2.0。 | FLOAT | いいえ | 0.0～4.0（ステップ0.05、デフォルト2.0） |
| `brow_strength` | 眉/頬/鼻のしわのシェイプに適用される乗数。MediaPipeは約0.1～0.3を出力するため、2～3倍。デフォルト: 2.0。 | FLOAT | いいえ | 0.0～4.0（ステップ0.05、デフォルト2.0） |
| `input_threshold` | MediaPipeの生出力に対するデッドゾーン（未満はゼロ、以上は線形再マッピング）。デフォルト: 0.02。 | FLOAT | いいえ | 0.0～0.5（ステップ0.01、デフォルト0.02） |
| `blendshape_smooth_window` | MHRマッピング前のMediaPipeのフレームごとの信号に適用するガウス窓。静止した顔では、MediaPipeの生出力がフレーム間で30～70%変動します。1 = 無効。奇数値を使用してください。デフォルト: 7。 | INT | いいえ | 1～31（ステップ2、デフォルト7） |

注記: クリップ内で少なくとも30フレームに検出された人物が含まれる場合にのみ、クリップごとのベースライン減算が適用されます。人物ごとに最大12フレームの検出ギャップは補間によって補われます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `mhr_pose_data` | 更新されたポーズデータ。各追跡対象人物の表情パラメータはマッピングされた顔表情で置き換えられ、メッシュ頂点とキーポイントはそれに合わせて再生成されます。 | MHR_POSE_DATA |
