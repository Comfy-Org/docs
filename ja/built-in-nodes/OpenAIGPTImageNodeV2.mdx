このノードは、OpenAI の GPT Image API を使用して画像を生成します。複数のモデル（`gpt-image-2`、`gpt-image-1.5`、`gpt-image-1`）をサポートし、編集用の参照画像を提供したり、マスクを使用して画像のどの部分を変更するかを指定したりできます。

| --- | --- | --- | --- | --- |
| `モデル` | 使用する OpenAI GPT Image モデルです。モデルを選択すると、そのモデルに固有の追加パラメータが表示されます。 | DYNAMIC_COMBO | 必須 | `"gpt-image-2"`<br />`"gpt-image-1.5"`<br />`"gpt-image-1"` |
| `プロンプト` | GPT Image へのテキストプロンプトです（デフォルト: `""`）。 | STRING | 必須 | N/A |
| `n` | 生成する画像の枚数です（デフォルト: `1`）。 | INT | 必須 | 1〜8 |
| `シード` | 再現性のためのシードです（デフォルト: `0`）。バックエンドではまだ実装されていません。 | INT | 必須 | 0〜2147483647 |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model.images` | 拡張可能スロットです。1..N 個のアイテム（例: `image_1`...`image_16`）を接続します。すべてのモデルで最大 16 枚の参照画像を使用できます。 | IMAGE | 任意 | 1〜16 |
| `model.mask` | インペインティング用のオプションのマスクです（白い部分が置き換えられます）。参照画像が正確に 1 枚必要です。 | MASK | 任意 | N/A |

**パラメータの制約と制限事項:**

- `model.size` が "Custom"（gpt-image-2 のみ）の場合、`model.custom_width` と `model.custom_height` は両方とも 16 の倍数である必要があります。最長辺は 3840 を超えてはならず、アスペクト比は 3:1 を超えてはならず、総ピクセル数は 655,360 から 8,294,400 の間である必要があります。
- `model.mask` を使用するには、`model.images` 内に参照画像が正確に 1 枚必要です。画像なしでは使用できず、複数の画像があっても使用できません。
- `model.mask` を使用する場合、その寸法は参照画像の寸法と一致している必要があります。
- `model.images` が指定されている場合、ノードは画像編集モードで動作します。`model.images` がない場合は、プロンプトのみから画像を生成します。
- 参照画像は API に送信される前に縮小されます。
- `seed` は現在バックエンドで実装されていません。
