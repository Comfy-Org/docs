このノードは、MiniMax H3 Context IR を使用して、テキストによる説明と添付されたメディアを分析し、より強力で構造化された動画プロンプトを生成します。返されたプロンプトは、MiniMax H3 ビデオノードのプロンプト入力に接続するように設計されています。そこにメディアを添付する場合は、同じメディアを同じ順序で添付してください。拡張されたプロンプトはメディアを位置で参照するためです。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | プロンプト拡張に使用するモデル。 | COMBO | 必須 | `"MiniMax H3"` |
| `prompt` | 生成しようとしている動画の説明。空にすることはできません。（デフォルト: `""`） | STRING | 必須 | 任意のテキスト |
| `duration` | 生成しようとしている動画の長さ（秒単位、4～15）。（デフォルト: 5） | INT | 必須 | 4 ～ 15 |
| `ratio` | 生成しようとしている動画のアスペクト比。`"adaptive"` は、画像・動画・音声の入力を少なくとも1つ必要とします。（デフォルト: `"adaptive"`） | COMBO | 必須 | `"adaptive"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"` |
| `reference_images` | 被写体またはスタイルの参照画像。接続順にプロンプト内で「Image 1」～「Image 9」として参照されます。最大9枚まで指定できます。 | IMAGE | 任意 | 0 ～ 9 枚 |
| `reference_videos` | モーションまたはシーンの参照動画。接続順にプロンプト内で「Video 1」～「Video 3」として参照されます。最大3本（各2～15秒、合計15秒以内）まで指定できます。 | VIDEO | 任意 | 0 ～ 3 本 |
| `reference_audios` | 音声参照。接続順にプロンプト内で「Audio 1」～「Audio 3」として参照されます。最大3クリップ（各2～15秒、合計15秒以内）まで指定できます。参照画像または参照動画なしでは使用できません。 | AUDIO | 任意 | 0 ～ 3 クリップ |
| `first_frame` | 生成しようとしている動画の最初のフレーム。参照メディアと併用することはできません。 | IMAGE | 任意 | 単一画像 |
| `last_frame` | 生成しようとしている動画の最後のフレーム。参照メディアと併用することはできません。 | IMAGE | 任意 | 単一画像 |

### パラメータ制約

- `prompt`、`duration`、`ratio`、`reference_images`、`reference_videos`、および `reference_audios` の各入力は、`model` オプショングループの一部です。
- `first_frame` と `last_frame` は、参照メディアと併用することはできません。
- `reference_audios` は、`reference_image` または `reference_video` が少なくとも1つ接続されていない限り使用できません。
- フレームと参照メディアのいずれも接続されていない場合、`ratio` は `"adaptive"` に設定できません。
- 参照動画は、各2～15秒で合計15秒以内である必要があります。フレームレートは23.9～60.5 FPSである必要があります。
- 参照音声は、各2～15秒で合計15秒以内である必要があります。
- `first_frame`、`last_frame`、およびすべての参照画像は、少なくとも256x256ピクセルで、アスペクト比が0.4～2.5の範囲内である必要があります。
