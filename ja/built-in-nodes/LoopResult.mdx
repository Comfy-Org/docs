LoopResult は、ループブロックの終了点を示す開発者専用の出力ノードです。順番に受け取った値（`output0`、`output1` などと命名）を収集し、close ID で識別される外部実行ブロックを解放します。入力フィンガープリンティングが常に NaN を返すため、このノードは常に変更されたものとして扱われ、実行ごとに再実行されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `close_id` | 閉じるループブロックの識別子。リストの最初の値のみが使用されます | STRING | はい | - |
| `output0`, `output1`, ... | ループブロックから収集された値。このノードは任意の追加入力を受け入れ、`output0` から始まる連続した順序でそれらを収集し、最初の欠落インデックスで停止します | 任意の型 | いいえ | - |

注意: このノードはすべての入力を受け入れます（`accept_all_inputs`）。`close_id` 以外の入力は収集されたループ値として扱われ、結果に含めるには `output0`、`output1`、`output2` などのように欠番なく命名する必要があります。

## 出力

このノードは出力を返しません。`close_id` に関連付けられた外部実行ブロックを解放するだけです。
