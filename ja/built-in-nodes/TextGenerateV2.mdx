Generate Text ノードは、CLIP モデルを使用してプロンプトからテキストを生成します。従来の単一添付ノードとは異なり、画像、動画、音声ファイルの拡張可能なスタックを追加コンテキストとして受け取れるため、1 つのノードで参照セット全体を入力できます。出力長、サンプリングを使用するかどうか、モデル自体のチャットテンプレートと思考モードを適用するかどうかを制御できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `clip` | プロンプトをトークン化し、テキストを生成するために使用される CLIP モデルです。 | CLIP | はい | - |
| `prompt` | 生成を導くプロンプトです。複数行および動的プロンプトをサポートします（デフォルト: 空文字列）。 | STRING | はい | - |
| `images` | 最大 50 枚の画像（`image1`～`image50`）からなる拡張可能なグループで、モデルの視覚コンテキストとして使用されます。 | AUTOGROW | いいえ | 0～50 枚の画像 |
| `videos` | 最大 100 本の動画入力（`video1`～`video100`）からなる拡張可能なグループです。各動画は 24 FPS と想定されるフレームのバッチであり、内部的に 1 FPS にサブサンプリングされます。 | AUTOGROW | いいえ | 0～100 本の動画 |
| `audios` | 最大 100 個の音声入力（`audio1`～`audio100`）からなる拡張可能なグループで、モデルの音声コンテキストとして使用されます。 | AUTOGROW | いいえ | 0～100 個の音声ファイル |
| `max_length` | 生成するトークンの最大数です（デフォルト: 512）。 | INT | はい | 1～32768 |
| `sampling_mode` | `on` は出力をサンプリングし、以下のサンプリングパラメータを表示します。`off` はランダムサンプリングを行わずに貪欲法で生成します。 | DYNAMIC_COMBO | はい | `"on"`<br />`"off"` |
| `thinking` | モデルがサポートしている場合、思考モードで動作します（デフォルト: False）。 | BOOLEAN | いいえ | True または False |
| `use_default_template` | モデルに組み込みのシステムプロンプトまたはチャットテンプレートがある場合、それを使用します（デフォルト: True）。詳細パラメータです。 | BOOLEAN | いいえ | True または False |
| `mtp` | チェックポイントのマルチトークン予測ヘッドを使用した投機的デコーディングです。MTP の重みがない場合は効果がありません。`"auto"` は観測されたトークン一致と実行コストに応じてドラフトの深さと幅を適応させ、`"2"`～`"5"` は一定のドラフト深さに固定し、`tree` モードは幅と深さの両方を固定します。サンプリングされた出力は正しい分布を保ちますが、同じシードでは MTP 以外の出力と異なります（デフォルト: `"auto"`）。 | COMBO | いいえ | `"auto"`<br />`"off"`<br />`"2"`<br />`"3"`<br />`"4"`<br />`"5"`<br />`"tree2s1"`<br />`"tree2s2"`<br />`"tree3s1"`<br />`"tree4s1m8"` |
| `system_prompt` | モデルのチャットテンプレート内のシステムプロンプトを置き換えます。デフォルトテンプレートを使用しない場合は無視されます。ノード内で入力する代わりに STRING 入力を接続します（デフォルト: 空）。 | STRING | いいえ | - |

### サンプリングパラメータ（`sampling_mode` が `"on"` の場合）

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `temperature` | 出力のランダム性を制御します。値を小さくすると出力はより予測可能になり、値を大きくするとより創造的になります（デフォルト: 0.7）。 | FLOAT | はい | 0.01～2.0 |
| `top_k` | 次に来る可能性が高い上位 K 個のトークンにサンプリング対象を制限します。値が 0 の場合はフィルタが無効になります（デフォルト: 64）。 | INT | はい | 0～1000 |
| `top_p` | 核サンプリング: 累積確率がこの値に達する、最も可能性の高いトークンの最小集合を保持します（デフォルト: 0.95）。 | FLOAT | はい | 0.0～1.0 |
| `min_p` | トークンが対象に残るために達する必要がある最小確率です（デフォルト: 0.05）。 | FLOAT | はい | 0.0～1.0 |
| `repetition_penalty` | すでに生成されたトークンにペナルティを与え、繰り返しを減らします。値が 1.0 の場合はペナルティを適用しません（デフォルト: 1.05）。 | FLOAT | はい | 0.0～5.0 |
| `presence_penalty` | これまでにテキスト内に出現したかどうかに基づいて新しいトークンにペナルティを与え、モデルが新しい話題に移るよう促します（デフォルト: 0.0）。 | FLOAT | はい | 0.0～5.0 |
| `seed` | 再現可能な結果を得るために乱数生成器を初期化する数値です（デフォルト: 0）。 | INT | はい | 0～18446744073709551615 |

**注:** 上記のサンプリングパラメータは、`sampling_mode` が `"on"` の場合にのみ存在します。`"off"` の場合、ノードはランダムサンプリングなしでテキストを生成し、パラメータは非表示になります。

**注:** モデルの出力が `<think>` で推論ブロックを開始する場合、ノードはそれを分割します。`generated_text` には回答が入り、`thinking` には開始タグが除去された推論が入ります。それ以外の場合、`generated_text` にはモデルが生成したすべてが入り、`thinking` は空になります。`max_length` によって打ち切られた推論は `generated_text` に残ります。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `generated_text` | モデルが生成したテキストです。推論ブロックがある場合は `thinking` 出力に分離されます。 | STRING |
| `thinking` | モデルが生成した推論ブロックです。開始タグ `<think>` は除去されます。モデルが推論ブロックを生成しなかった場合は空です。 | STRING |
