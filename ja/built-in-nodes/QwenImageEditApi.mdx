このノードは、Qwen-Image 3.0 モデルを使用して、テキストプロンプトに従って最大3枚の参照画像を編集または合成します。モデルを選択し、プロンプトと参照画像を指定すると、ノードは1枚以上の生成画像を返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 使用するモデル。この選択には、テキストプロンプト、最大3つの参照画像入力、およびオプションのネガティブプロンプトも含まれます。 | DYNAMIC_COMBO | はい | "qwen-image-3.0-pro"<br />"qwen-image-3.0" |
| `size` | 出力解像度。"match input" は最初の参照画像のサイズを再利用し、"auto" は同じアスペクト比でモデルにサイズを選択させ、"custom" は明示的な幅と高さを設定します。 | DYNAMIC_COMBO | はい | "match input"<br />"auto"<br />"custom" |
| `n` | 生成する画像数。バッチとして返されます。(デフォルト: 1) | INT | いいえ | 1 ～ 6 |
| `seed` | 生成に使用するシード値。(デフォルト: 42) | INT | いいえ | 0 ～ 2147483647 |
| `prompt_extend` | AI支援によりプロンプトを拡張するかどうか。(デフォルト: True) | BOOLEAN | いいえ | True<br />False |
| `watermark` | 結果にAI生成ウォーターマークを追加するかどうか。(デフォルト: False) | BOOLEAN | いいえ | True<br />False |

### qwen-image-3.0-pro および qwen-image-3.0 入力

両モデルとも同じサブパラメータを共有します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 編集の指示。英語と中国語に対応し、入力画像への @Image1 形式の参照も使用できます。(デフォルト: "") | STRING | はい | - |
| `negative_prompt` | 避けるべき内容を記述するネガティブプロンプト。(デフォルト: "") | STRING | いいえ | - |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | 追加可能スロット: 1～3枚の参照画像（`image_1`、`image_2`、`image_3`）を接続します。プロンプト内では @Image1、@Image2、@Image3 として参照します。番号は入力順に対応します。バッチ入力は画像1枚につき1回として数えられます。 | IMAGE | はい | 1 ～ 3 |

### カスタムサイズ入力

`size` が "custom" に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `width` | 出力幅。総ピクセル面積は512x512以上2560x2560以下である必要があります。アスペクト比は1:8から8:1の間である必要があります。(デフォルト: 1024) | INT | はい（`size` が "custom" の場合） | 256 ～ 2560、ステップ 16 |
| `height` | 出力高さ。総ピクセル面積は512x512以上2560x2560以下である必要があります。アスペクト比は1:8から8:1の間である必要があります。(デフォルト: 1024) | INT | はい（`size` が "custom" の場合） | 256 ～ 2560、ステップ 16 |

### 制約事項

- テキストプロンプトは必須であり、少なくとも1文字含む必要があります。
- 参照画像は最大3枚まで対応しています。それ以上指定するとエラーが発生します（バッチ入力は画像1枚につき1回として数えられます）。
- `size` が "custom" に設定されている場合、明示的な幅と高さの値を指定する必要があり、次の検証が行われます。総ピクセル面積は262,144（512x512）以上6,553,600（2560x2560）以下であり、アスペクト比は1:8から8:1の間である必要があります。
- `size` が "match input" に設定されている場合、最初の参照画像の寸法が使用されるため、少なくとも1枚の参照画像が必要です。寸法は対応可能な面積とアスペクト比の範囲に合わせてスケーリングされます。
- `size` が "auto" に設定されている場合、モデルは入力のアスペクト比を維持しながら出力サイズ（1.9～4.2メガピクセル）を選択します。
- プロンプト内の参照は @Image1、@Image2、@Image3 を使用し、番号は入力順に対応します。接続された画像数を超えるインデックスを参照するとエラーが発生します。タグは単語境界でのみ認識されるため、user@image1.com のようなアドレスは変更されません。
- 入力参照画像は、APIに送信される前に最大2048x2048ピクセルに縮小されます。PNGエンコーディングがAPIのサイズ制限を超える場合は、代わりにJPEGエンコーディングが使用されます。
