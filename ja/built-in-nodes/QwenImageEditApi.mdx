このノードは Qwen-Image 3.0 モデルを使用し、テキストプロンプトに従って最大3枚の参照画像を編集または合成します。モデルを選択し、プロンプトと参照画像を指定すると、ノードは1枚以上の生成画像を返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 使用するモデル。この選択には、テキストプロンプト、最大3つの参照画像入力、およびオプションのネガティブプロンプトも含まれます。 | DYNAMIC_COMBO | はい | "qwen-image-3.0-pro"<br />"qwen-image-3.0" |
| `size` | 出力解像度。"match input" は最初の参照画像のサイズを再利用し、"auto" は同じアスペクト比でモデルにサイズを選択させ、"custom" は明示的な幅と高さを設定します。 | DYNAMIC_COMBO | はい | "match input"<br />"auto"<br />"custom" |
| `n` | 生成する画像の枚数。バッチとして返されます。（デフォルト: 1） | INT | いいえ | 1～6 |
| `seed` | 生成に使用するシード。（デフォルト: 42） | INT | いいえ | 0～2147483647 |
| `prompt_extend` | AI支援でプロンプトを拡張するかどうか。（デフォルト: True） | BOOLEAN | いいえ | True<br />False |
| `watermark` | 結果にAI生成の透かしを追加するかどうか。（デフォルト: False） | BOOLEAN | いいえ | True<br />False |

### qwen-image-3.0-pro と qwen-image-3.0 入力

両モデルは同じサブパラメータを共有します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 編集指示。英語と中国語、および入力画像への @Image1 形式の参照をサポートします。（デフォルト: ""） | STRING | はい | - |
| `negative_prompt` | 回避したい内容を記述するネガティブプロンプト。（デフォルト: ""） | STRING | いいえ | - |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | 拡張可能なスロット: 1～3枚の参照画像（`image_1`、`image_2`、`image_3`）を接続します。プロンプト内では @Image1、@Image2、@Image3 として参照します。入力順に番号が付けられ、バッチ入力は画像1枚につき1回として数えます。 | IMAGE | はい | 1～3 |

### カスタムサイズ入力

`size` が "custom" に設定されているときに表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `width` | 出力幅。合計ピクセル面積は 512x512 ～ 2560x2560 の範囲内である必要があり、その範囲内であれば任意のアスペクト比を使用できます。（デフォルト: 1024） | INT | はい（`size` が "custom" の場合） | 256～2560、ステップ16 |
| `height` | 出力高さ。合計ピクセル面積は 512x512 ～ 2560x2560 の範囲内である必要があり、その範囲内であれば任意のアスペクト比を使用できます。（デフォルト: 1024） | INT | はい（`size` が "custom" の場合） | 256～2560、ステップ16 |

### 制約

- テキストプロンプトは必須であり、少なくとも1文字を含む必要があります。
- 参照画像は最大3枚までサポートされます。それ以上指定するとエラーが発生します（バッチ入力は画像1枚につき1回として数えます）。
- `size` が "custom" に設定されている場合、明示的な幅と高さを指定する必要があり、検証されます。合計ピクセル面積は 262,144（512x512）～ 6,553,600（2560x2560）ピクセルの範囲内で、アスペクト比は 1:8 ～ 8:1 の範囲内である必要があります。
- `size` が "match input" に設定されている場合、最初の参照画像の寸法が使用されるため、少なくとも1枚の参照画像が必要です。寸法は、サポートされる面積とアスペクト比の範囲に収まるようにスケーリングされます。
- `size` が "auto" に設定されている場合、モデルは入力のアスペクト比を維持しながら出力サイズ（1.9～4.2メガピクセル）を選択します。
- プロンプト参照では @Image1、@Image2、@Image3 を使用し、入力順に番号が付けられます。接続されている画像数より大きいインデックスを参照するとエラーが発生します。タグは単語境界でのみ認識されるため、user@image1.com のようなアドレスは変更されません。
- 入力参照画像は API に送信される前に最大 2048x2048 ピクセルにダウンスケールされます。PNG エンコーディングが API のサイズ制限を超える場合は、代わりに JPEG エンコーディングが使用されます。
