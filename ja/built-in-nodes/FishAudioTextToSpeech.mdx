このノードは、Fish Audio のテキスト読み上げモデルを使用して、書かれたテキストを音声に変換します。テキストに埋め込まれたキューをサポートしています。s2.1-pro では [happy] と [whispering]、s1 では (happy)、drama-3 では平易な言葉による [directions] と `<whisper>...</whisper>` 単語タグです。複数の音声が接続されている場合、マルチスピーカー対話では @Voice1/@Voice2 タグを使用します。利用可能なモデルは3つあります。drama-3 と s2.1-pro はどちらも最大5つの音声とマルチスピーカー対話をサポートし、s1 は単一のオプション音声を使用します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `text` | 音声に変換するテキストです。2つ以上の音声が接続されている場合、@Voice1、@Voice2 などで話者の変更をマークします。（デフォルト: 空） | STRING | はい | 空でない任意のテキスト |
| `model` | テキスト読み上げに使用するモデルです。 | DYNAMIC_COMBO | はい | "drama-3"<br />"s2.1-pro"<br />"s1" |
| `seed` | `seed` は、ノードを再実行するかどうかを制御します。結果はシード値に関係なく非決定的です。（デフォルト: 42） | INT | はい | 0～2147483647 |

### drama-3 および s2.1-pro 入力

これらの入力は、`drama-3` または `s2.1-pro` モデルが選択されている場合に表示されます。パラメータセットは同一です。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `voices` | 拡張可能なスロット: 0～5 個の音声アイテム（`voice_1`、`voice_2`、...）を接続します。合成に使用する音声です。空のままにするとランダムな音声を使用します。2つ以上の音声がある場合、テキスト内で @Voice1、@Voice2 などにより話者の変更をマークします。 | FISHAUDIO_VOICE | いいえ | 0～5 音声 |
| `temperature` | 表現力。値が高いほど変化に富み、低いほど一貫性が高くなります。（デフォルト: 0.7） | FLOAT | はい | 0.0～1.0 |
| `top_p` | ニュークリアスサンプリングによる多様性。（デフォルト: 0.7） | FLOAT | はい | 0.01～1.0 |
| `speed` | 話速。1.0 が標準で、&lt;1.0 は遅く、>1.0 は速くなります。（デフォルト: 1.0） | FLOAT | はい | 0.5～2.0 |
| `volume` | デシベル単位の音量調整。0 は変更なしです。（デフォルト: 0.0） | FLOAT | はい | -10.0～10.0 |
| `normalize` | 英語と中国語の数値とテキストを正規化し、数値や日付の安定性を向上させます。（デフォルト: true） | BOOLEAN | はい | true / false |

### s1 入力

これらの入力は、s1 モデルが選択されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `voice` | 合成に使用する音声。未接続のままにするとランダムな音声を使用します。 | FISHAUDIO_VOICE | いいえ | オプションの単一音声 |
| `temperature` | 表現力。値が高いほど変化に富み、低いほど一貫性が高くなります。（デフォルト: 0.7） | FLOAT | はい | 0.0～1.0 |
| `top_p` | ニュークリアスサンプリングによる多様性。（デフォルト: 0.7） | FLOAT | はい | 0.01～1.0 |
| `speed` | 話速。1.0 が標準で、&lt;1.0 は遅く、>1.0 は速くなります。（デフォルト: 1.0） | FLOAT | はい | 0.5～2.0 |
| `volume` | デシベル単位の音量調整。0 は変更なしです。（デフォルト: 0.0） | FLOAT | はい | -10.0～10.0 |
| `normalize` | 英語と中国語の数値とテキストを正規化し、数値や日付の安定性を向上させます。（デフォルト: true） | BOOLEAN | はい | true / false |

**注記:** `text` 入力は空にできません。話者タグ（@Voice1、@Voice2 など）は大文字と小文字を区別せず、接続されている音声を参照する必要があります。接続されていない音声にタグを付けるとエラーが発生します。2つ以上の音声が接続されている場合、テキストは接続されているすべての音声を少なくとも1回参照する必要があります。そうでない場合、ノードは不足しているタグを報告します。drama-3 と s2.1-pro では、0 個の音声を接続するとランダムな音声を使用し、1 個の音声はその音声のみを使用し、2 個以上でマルチスピーカー対話が有効になります。s1 では、単一のオプション音声が使用され、未接続のままにするとランダムな音声を使用します。テキストにはキューを配置できます。s2.1-pro では [happy] と [whispering]、s1 では (happy)、drama-3 では平易な言葉による [directions] と `<whisper>...</whisper>` 単語タグです。
