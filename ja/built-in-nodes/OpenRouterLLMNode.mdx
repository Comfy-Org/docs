OpenRouter LLM ノードは、OpenRouter サービスを通じて利用できる人気の言語モデル群にテキストプロンプトを送信し、生成されたテキスト応答を返します。Anthropic (Claude)、OpenAI (GPT)、Google (Gemini)、xAI (Grok)、DeepSeek、Qwen、Mistral、Z.AI (GLM)、Moonshot (Kimi)、Perplexity Sonar のモデルをサポートしており、リクエストに画像やビデオを参照入力として任意に含めることもできます。

## 入力

`model` セレクターでモデルを選択すると、ノードは選択したモデルの機能に応じて、共通入力の上にモデル固有のウィジェット（推論エフォート、Web検索サイズ、参照メディアスロットなど）を表示します。

### 共通入力

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | モデルへのテキスト入力。 | STRING | はい | N/A |
| `model` | 応答の生成に使用される OpenRouter モデル。 | DYNAMIC_COMBO | はい | 選択可能な複数のオプションがあります（下記のモデルセクションを参照） |
| `seed` | サンプリング用のシード。0 を指定すると省略されます。ほとんどのモデルではヒントとしてのみ扱われます。（デフォルト: 0） | INT | はい | 0〜2147483647 |
| `system_prompt` | モデルの動作を決定する基本指示。（デフォルト: ""） | STRING | No | N/A |

- **画像・ビデオの制限：** 参照画像と参照ビデオの最大数は選択したモデルによって異なります。提供された画像またはビデオの合計数がモデルの上限を超えると、ノードはエラーを発生させます。画像またはビデオに対応していないモデルでは、対応する参照スロットは表示されません。

- **推論動作：** `reasoning_effort` が "off" 以外に設定されている場合、リクエストはプロバイダーに対して、推論トレースを返さずに内部で推論するよう要求します。

- **シード動作：** `seed` パラメータには "control_after_generate" 動作があります。つまり、ユーザーのウィジェット設定に応じて、ノード実行のたびに自動的に変更（例：ランダム化、インクリメント、固定）するよう設定できます。

- **システムプロンプト：** `system_prompt` パラメータはオプションであり、ユーザーインターフェースでは詳細パラメータとしてマークされています。

- **エラーケース：** ノードは、空白を除去した後にプロンプトが空の場合、OpenRouter がエラーを返した場合、選択したモデルが応答を拒否した場合、または応答に choices や message が含まれない場合にエラーを発生させます。ノード上の価格バッジには、選択したモデルに基づく1Kトークンあたりのおおよそのコスト見積もりが表示されます。
