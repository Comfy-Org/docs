WanTrackToVideo ノードは、モーション トラッキング データをビデオ シーケンスに変換し、トラック ポイントを処理して対応するビデオ フレームを生成します。トラッキング座標を入力として受け取り、ビデオ生成に使用できるビデオ条件付けと潜在表現を生成します。トラックが提供されない場合は、標準の画像間ビデオ変換にフォールバックします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `positive` | ビデオ生成のためのポジティブ条件付け | CONDITIONING | はい | - |
| `negative` | ビデオ生成のためのネガティブ条件付け | CONDITIONING | はい | - |
| `vae` | エンコードおよびデコード用の VAE モデル | VAE | はい | - |
| `tracks` | JSON 形式のトラッキング データを含む複数行の文字列（デフォルト："[]"）。各トラックは固定長 121 ポイントにパディングまたは切り詰められます。 | STRING | はい | - |
| `width` | 出力ビデオの幅（ピクセル単位）（デフォルト：832、ステップ：16） | INT | はい | 16 ～ MAX_RESOLUTION |
| `height` | 出力ビデオの高さ（ピクセル単位）（デフォルト：480、ステップ：16） | INT | はい | 16 ～ MAX_RESOLUTION |
| `length` | 出力ビデオのフレーム数（デフォルト：81、ステップ：4） | INT | はい | 1 ～ MAX_RESOLUTION |
| `batch_size` | 同時に生成するビデオの数（デフォルト：1） | INT | はい | 1 ～ 4096 |
| `temperature` | モーション パッチングの温度パラメータ（デフォルト：220.0、ステップ：0.1） | FLOAT | はい | 1.0 ～ 1000.0 |
| `topk` | モーション パッチングの Top-k 値（デフォルト：2） | INT | はい | 1 ～ 10 |
| `start_image` | ビデオ生成用の開始画像 | IMAGE | いいえ | - |
| `clip_vision_output` | 追加の条件付け用の CLIP ビジョン出力 | CLIP_VISION_OUTPUT | いいえ | - |

**注記：** `tracks` に有効なトラッキング データが含まれている場合、ノードはモーション トラックを処理してビデオを生成します。`tracks` が空の場合は、標準の画像間ビデオモードに切り替わります。`start_image` が提供された場合は、ビデオ シーケンスの最初のフレームを初期化し、モーション パッチングの結果がポジティブ条件付けとネガティブ条件付けの両方に追加されます。`clip_vision_output` が提供された場合は、それもポジティブ条件付けとネガティブ条件付けの両方に追加されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | モーション トラック情報が適用されたポジティブ条件付け | CONDITIONING |
| `negative` | モーション トラック情報が適用されたネガティブ条件付け | CONDITIONING |
| `latent` | 生成されたビデオの潜在表現 | LATENT |
