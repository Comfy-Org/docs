このノードは、Kling V3 モデルを使用して動画を生成します。テキスト記述から動画を作成する text-to-video と、既存の画像をアニメーション化する image-to-video をサポートします。また、ストーリーボードプロンプトを使用して複数セグメントの動画を作成し、オプションで音声を生成することもできます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `マルチショット` | 個別のプロンプトと長さを持つ一連の動画セグメントを生成します。ストーリーボードオプションに設定すると、各ストーリーボードのプロンプトと長さに対応する追加入力が表示されます。 | DYNAMIC_COMBO | はい | `"disabled"`<br />`"1 storyboard"`<br />`"2 storyboards"`<br />`"3 storyboards"`<br />`"4 storyboards"`<br />`"5 storyboards"`<br />`"6 storyboards"` |
| `オーディオ生成` | 有効にすると、ノードは動画の音声を生成します。注：`"kling-3.0-turbo"` は常にネイティブ音声を生成するため、そのモデルでは音声トグルは無視されます。デフォルトは True です。 | BOOLEAN | はい | True<br />False |
| `モデル` | モデルと生成設定。モデルを選択すると、その解像度とアスペクト比のサブパラメータが表示されます。 | DYNAMIC_COMBO | はい | `"kling-v3"`<br />`"kling-3.0-turbo"` |
| `シード` | シードはノードを再実行するかどうかを制御します。シードに関係なく結果は非決定的です。デフォルトは 0 です。 | INT | はい | 0～2147483647 |
| `開始フレーム` | オプションの開始フレーム画像。接続すると image-to-video モードに切り替わります。 | IMAGE | いいえ | - |

### マルチショット入力

**`multi_shot` が `"disabled"` に設定されている場合：**

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 動画の主要なテキスト記述。1～2500文字である必要があります。 | STRING | はい | 1～2500文字 |
| `negative_prompt` | 動画に表示されるべきでないものを説明するテキスト。空のままにできます。 | STRING | いいえ | - |
| `duration` | 動画の長さ（秒）。デフォルトは 5 です。 | INT | はい | 3～15 |

**`multi_shot` がストーリーボードオプション（例：`"3 storyboards"`）に設定されている場合：**

各ストーリーボードセグメント N（1 から選択したストーリーボード数まで）について、次の入力が表示されます：

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | ストーリーボードセグメント N のプロンプト。最大512文字。 | STRING | はい | 1～512文字 |
| `storyboard_N_duration` | ストーリーボードセグメント N の長さ（秒）。デフォルトは 4 です。 | INT | はい | 1～15 |

**制約と動作：**

- `start_frame` が接続されていない場合は text-to-video モードが使用され、`start_frame` が接続されている場合は image-to-video モードが使用されます。image-to-video モードでは、`model.aspect_ratio` は無視され、入力画像は少なくとも 300x300 ピクセルで、アスペクト比が 1:2.5 から 2.5:1 の間である必要があります。
- ストーリーボードモードでは、メインの `prompt` と `negative_prompt` は使用されません。すべてのストーリーボードの長さの合計は 3～15 秒でなければなりません。
- `negative_prompt` は `kling-v3` でのみ使用されます。`kling-3.0-turbo` が選択されている場合は無視されます。
- `kling-v3` では、各ストーリーボードは個別のセグメントとして API に送信されます。`kling-3.0-turbo` では、ストーリーボードのプロンプトと長さが単一のマルチショットプロンプトに結合されます。
- `kling-3.0-turbo` では、このモデルが常にネイティブ音声を生成するため、`generate_audio` は無視されます。
