このノードは、Kling V3 モデルを使用して動画を生成します。テキスト読み込みモード（テキスト記述から動画を作成）と、画像読み込みモード（既存の画像をアニメーション化）をサポートしています。また、各パートに個別のプロンプトを設定できるマルチセグメント動画の作成（ストーリーボード）や、オプションで動画に付随する音声を生成するなどの高度な機能も提供します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `マルチショット` | 個別のプロンプトと時間を指定して、一連の動画セグメントを生成します。ストーリーボードオプションに設定すると、各ストーリーボードのプロンプトと時間の追加入力が表示されます。 | DYNAMIC_COMBO | はい | `"disabled"`<br />`"1 storyboard"`<br />`"2 storyboards"`<br />`"3 storyboards"`<br />`"4 storyboards"`<br />`"5 storyboards"`<br />`"6 storyboards"` |
| `モデル` | モデルと生成設定。モデルを選択すると、解像度とアスペクト比のサブパラメータが表示されます。 | DYNAMIC_COMBO | はい | `"kling-v3"`<br />`"kling-3.0-turbo"` |
| `オーディオ生成` | 有効にすると、ノードは動画の音声を生成します。注: `"kling-3.0-turbo"` は常にネイティブ音声を生成するため、このモデルではこのトグルは無視されます。デフォルトは True です。 | BOOLEAN | はい | True<br />False |
| `シード` | シードはノードを再実行するかどうかを制御します。シードに関係なく結果は非決定的です。デフォルトは 0 です。 | INT | はい | 0〜2147483647 |

### マルチショット入力

**`multi_shot` が `"disabled"` に設定されている場合:**

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 動画のメインテキスト記述。1 から 2500 文字の間で指定する必要があります。 | STRING | はい | 1〜2500 characters |
| `negative_prompt` | 動画に表示すべきでない内容を記述するテキスト。空のままにすることができます。 | STRING | いいえ | - |
| `duration` | 動画の長さ（秒単位）。デフォルトは 5 です。 | INT | はい | 3〜15 |

**`multi_shot` がストーリーボードオプション（例：`"3 storyboards"`）に設定されている場合:**

各ストーリーボードセグメント N（1 から選択したストーリーボード数まで）について、以下の入力が表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | ストーリーボードセグメント N のプロンプト。最大 512 文字。 | STRING | はい | 1〜512 characters |
| `storyboard_N_duration` | ストーリーボードセグメント N の長さ（秒単位）。デフォルトは 4 です。 | INT | はい | 1〜15 |

**制約と動作:**

- テキスト読み込みモードは `start_frame` が接続されていない場合に使用され、画像読み込みモードは `start_frame` が接続されている場合に使用されます。画像読み込みモードでは、`model.aspect_ratio` は無視され、入力画像は少なくとも 300x300 ピクセルで、アスペクト比が 1:2.5 から 2.5:1 の間である必要があります。
- ストーリーボードモードでは、メインの `prompt` と `negative_prompt` は使用されません。すべてのストーリーボードの時間の合計は 3 秒から 15 秒の間である必要があります。
- `negative_prompt` は `kling-v3` でのみ使用され、`kling-3.0-turbo` が選択されている場合は無視されます。
- `kling-v3` の場合、各ストーリーボードは API に個別のセグメントとして送信されます。`kling-3.0-turbo` の場合、ストーリーボードのプロンプトと時間は単一のマルチショットプロンプトに結合されます。
- `kling-3.0-turbo` の場合、このモデルは常にネイティブ音声を生成するため、`generate_audio` は無視されます。
