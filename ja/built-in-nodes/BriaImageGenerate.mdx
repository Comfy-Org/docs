Bria FIBO 2.0 を使用して、テキストプロンプト、構造化 JSON プロンプト、または単一の参照画像から新しい画像を生成します。このノードはリクエストを Bria API に送信し、生成が完了するまで待機して、画像と、後の実行で画像を再現または微調整するために使用できる構造化プロンプトを返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成する画像を平易な言葉で説明します（デフォルト: 空）。 | STRING | はい | 複数行テキスト |
| `structured_prompt` | 以前の Bria FIBO の結果から得られた JSON 構造化プロンプトです。同じ seed でその画像を再現します。JSON を変更するか、プロンプトを追加して微調整できます（デフォルト: 空）。 | STRING | はい | 複数行テキスト |
| `aspect_ratio` | 出力のアスペクト比（デフォルト: `"1:1"`）。`"16:10"` 以降の比率は、以下に示す追加要件がある FIBO 2.0 のサイズです。 | COMBO | はい | `"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"`<br />`"16:10"`<br />`"10:16"`<br />`"2:1"`<br />`"1:2"`<br />`"21:9"`<br />`"9:21"`<br />`"3:1"`<br />`"1:3"`<br />`"4:1"`<br />`"1:4"`<br />`"5:1"`<br />`"1:5"` |
| `resolution` | 出力解像度（メガピクセル単位、デフォルト: `"1MP"`）。 | COMBO | はい | `"1MP"`<br />`"4MP"` |
| `seed` | 生成を初期化するシード（デフォルト: 42）。 | INT | はい | 1～2147483647 |
| `moderation` | モデレーション設定。`"true"` を選択すると、以下に示すモデレーション入力が表示されます。 | DYNAMIC_COMBO | はい | `"false"`<br />`"true"` |
| `image` | 任意の参照画像で、これを基に描画します。結果は選択したアスペクト比の新しい画像であり、この画像の編集ではありません。 | IMAGE | いいえ | - |

### モデレーション入力

`moderation` が `"true"` に設定されている場合、次の追加入力が利用可能になります:

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | プロンプトテキストをモデレーションするかどうか。モデレーションが拒否した場合、リクエストは失敗します（デフォルト: false）。 | BOOLEAN | いいえ | `true`<br />`false` |
| `visual_input_moderation` | 参照画像をモデレーションするかどうか。モデレーションが拒否した場合、リクエストは失敗します（デフォルト: false）。 | BOOLEAN | いいえ | `true`<br />`false` |
| `visual_output_moderation` | 生成画像をモデレーションするかどうか。モデレーションが拒否した場合、リクエストは失敗します（デフォルト: false）。 | BOOLEAN | いいえ | `true`<br />`false` |

**重要な制約:**

- `prompt`、`structured_prompt`、または参照用の `image` のうち少なくとも 1 つを指定してください。3 つすべてが空の場合、ノードはエラーを発生させます。
- 参照画像は `structured_prompt` と組み合わせられません。どちらか一方のみを使用してください。
- FIBO 2.0 の比率（`"16:10"`、`"10:16"`、`"2:1"`、`"1:2"`、`"21:9"`、`"9:21"`、`"3:1"`、`"1:3"`、`"4:1"`、`"1:4"`、`"5:1"`、`"1:5"`）には `resolution` `"1MP"` と、`prompt` または `structured_prompt` のいずれか 1 つのみが必要です。
- このノードは有料 API ノードです。ComfyUI は実行ごとに約 0.0572 USD を請求します。

| 出力名 | 説明 | データ型 |
