このノードは、画像のリストを ComfyUI の出力ディレクトリ内の指定したフォルダーに保存します。設定可能なファイル名プレフィックスを使用して、各画像を PNG ファイルとしてディスクに書き込みます。このノードは非推奨であり、既存の Save Image ノードに置き換えられています。そこでは、対象フォルダーをファイル名プレフィックス内で指定できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | 保存する画像のリスト。 | IMAGE | はい | N/A |
| `folder_name` | 画像を保存するフォルダー名（出力ディレクトリ内）。デフォルト: "dataset"。 | STRING | いいえ | N/A |
| `filename_prefix` | 保存する画像ファイル名のプレフィックス。デフォルト: "image"。詳細パラメータ。 | STRING | いいえ | N/A |
| `モード` | 既存のファイルを上書きするか、上書きを避けるためにファイル名をインクリメントするかを指定します。デフォルト: "overwrite"。 | COMBO | いいえ | "overwrite"<br />"increment" |

**注記:**

- `images` 入力はリストであるため、1回の実行で複数の画像を保存できます。
- `folder_name`、`filename_prefix`、`mode` パラメータはスカラー値です。リストが接続されている場合、そのリストの最初の値のみが使用されます。
- `folder_name` は ComfyUI の出力ディレクトリ内の場所に解決される必要があります。出力ディレクトリの外へ出る値（たとえば、`..` を含むパス、絶対パス、ドライブレター、シンボリックリンクによる脱出など）はエラーとして拒否されます。
- "overwrite" モードでは、ファイルは `{prefix}_00000.png`、`{prefix}_00001.png` などの名前で保存され、既存のファイルを置き換えます。"increment" モードでは、ファイル名にカウンターが挿入されるため、既存のファイルは上書きされません。
- PNG 出力のみサポートされています。

## 出力

このノードには出力がありません。ファイルシステムへの保存操作を行う出力ノードです。
