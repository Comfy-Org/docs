Bria Eraser は、Bria API を使用して画像からオブジェクトまたは領域を削除します。削除する領域を示す画像とマスクを指定します。ノードは両方を Bria にアップロードし、消去ジョブを実行して完了を待ち、マスクされた領域が消去された編集済み画像を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 削除するオブジェクトまたは領域を含む入力画像です。 | IMAGE | はい | - |
| `mask` | 白い領域は消去され、黒い領域は保持されます。マスクは送信前に二値化されるため、部分的に描画された領域は白として扱われます。画像と同じアスペクト比である必要があります。 | MASK | はい | - |
| `mask_type` | マスクのソースタイプです。"manual" は手描きまたはブラシによるマスク用で、"automatic" は SAM などのセグメンテーションモデルによって生成されたマスク用です。 | COMBO | はい | "manual"<br />"automatic" |
| `moderation` | モデレーション設定です。"true" に設定すると、入力画像および/または出力画像に対して視覚コンテンツモデレーションを有効にします。 | DYNAMIC_COMBO | はい | "false"<br />"true" |

`moderation` が "true" に設定されている場合、2 つの追加のブール設定が利用可能になります:

- `visual_input_moderation` — 入力画像に視覚コンテンツモデレーションを適用します（デフォルト: false）
- `visual_output_moderation` — 出力画像に視覚コンテンツモデレーションを適用します（デフォルト: false）

注意: マスクは画像と同じアスペクト比である必要があり、そうでない場合はリクエストが失敗します。マスクは API に送信される前にバイナリ（白黒）マスクに変換されます。不透明度が半分未満で描画された領域は無視され、部分的に描画された領域は白として扱われ、消去されます。マスクには少なくともある程度の白い領域が含まれている必要があります。空のマスクは消去するものがないため、リクエストが失敗します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | マスクされたオブジェクトまたは領域が削除された編集済み画像です。 | IMAGE |
