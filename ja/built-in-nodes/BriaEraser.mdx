Bria Eraser は、Bria API を使用して画像からオブジェクトや領域を削除します。削除する領域を指定した画像とマスクを提供すると、ノードはその両方を Bria にアップロードし、消去ジョブを実行して完了を待ち、マスクされた領域が消去された編集済み画像を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 削除するオブジェクトや領域を含む入力画像です。 | IMAGE | はい | - |
| `mask` | 白い領域は削除され、黒い領域は保持されます。マスクは送信前に2値化されるため、部分的に塗られた領域も白として扱われます。画像と同じアスペクト比である必要があります。 | MASK | はい | - |
| `mask_type` | マスクの作成方法を選択します。"manual" は手描きまたはブラシによるマスク用です。"automatic" は SAM などのセグメンテーションモデルによって生成されたマスク用です。 | STRING | はい | "manual"<br />"automatic" |
| `moderation` | モデレーション設定です。"true" に設定すると、入力画像や出力画像に対してコンテンツモデレーションが有効になります。 | STRING | はい | "false"<br />"true" |

注意: `moderation` を "true" に設定すると、追加のブール設定が2つ利用可能になります。

- `visual_input_moderation` — 入力画像にビジュアルコンテンツモデレーションを適用します（デフォルト: false）
- `visual_output_moderation` — 出力画像にビジュアルコンテンツモデレーションを適用します（デフォルト: false）

マスクは画像のアスペクト比と一致している必要があります。一致しない場合、リクエストは失敗します。マスクは API に送信される前に2値（白黒）マスクに変換されるため、部分的に塗られた領域は白として扱われ、削除されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | マスクされたオブジェクトや領域が削除された編集済み画像です。 | IMAGE |
