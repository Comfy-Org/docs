Bria Eraser は、Bria API を使用して画像からオブジェクトや領域を削除します。削除対象のオブジェクトや領域を含む画像と、その領域を指定するマスクを入力すると、ノードは両方を Bria にアップロードし、消去ジョブを実行して完了を待ち、マスクされた領域が消去された編集済み画像を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 削除するオブジェクトや領域を含む入力画像。 | IMAGE | はい | - |
| `mask` | 白い領域は消去され、黒い領域は保持されます。マスクは送信前に2値化されるため、部分的に描画された領域は白として扱われます。画像と同じアスペクト比である必要があります。 | MASK | はい | - |
| `mask_type` | マスクの作成方法を選択します。「manual」は手描きまたはブラシマスク用です。「automatic」はSAMなどのセグメンテーションモデルによって生成されたマスク用です。 | COMBO | はい | "manual"<br />"automatic" |
| `moderation` | モデレーション設定。入力画像および/または出力画像のビジュアルコンテンツモデレーションを有効にするには「true」に設定します。 | DYNAMIC_COMBO | はい | "false"<br />"true" |

注：`moderation` を「true」に設定すると、以下の2つの追加ブール設定が利用可能になります。

- `visual_input_moderation` — 入力画像にビジュアルコンテンツモデレーションを適用します（デフォルト：false）
- `visual_output_moderation` — 出力画像にビジュアルコンテンツモデレーションを適用します（デフォルト：false）

マスクは画像のアスペクト比と一致している必要があります。一致しない場合、リクエストは失敗します。マスクはAPIに送信される前に2値（白黒）マスクに変換されます。不透明度が半分未満で描画された領域は無視され、部分的に描画された領域は白として扱われ消去されます。マスクには少なくともある程度の白い領域が含まれている必要があります。空のマスクは消去するものが何もないため、リクエストが失敗します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | マスクされたオブジェクトや領域が削除された編集済み画像。 | IMAGE |
