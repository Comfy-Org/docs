Grok Video ノードは、テキスト記述から短い動画を生成します。プロンプトを使用してゼロから動画を作成することも、単一の入力画像から動画を生成することもできます。このノードはリクエストを外部 API に送信し、生成された動画を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 動画生成に使用するモデル（デフォルト: `"grok-imagine-video-1.5-lite"`）。 | COMBO | はい | `"grok-imagine-video"`<br />`"grok-imagine-video-1.5"`<br />`"grok-imagine-video-1.5-lite"` |
| `プロンプト` | 生成したい動画のテキスト記述。入力画像が提供されている場合、`grok-imagine-video-1.5` モデルでは省略可能です。 | STRING | はい | - |
| `解像度` | 出力動画の解像度。`1080p` は `grok-imagine-video` では利用できません。 | COMBO | はい | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `アスペクト比` | 出力動画のアスペクト比。入力画像が提供されている場合は無視され、動画は画像のアスペクト比に従います。 | COMBO | はい | `"auto"`<br />`"16:9"`<br />`"4:3"`<br />`"3:2"`<br />`"1:1"`<br />`"2:3"`<br />`"3:4"`<br />`"9:16"` |
| `再生時間` | 出力動画の長さ（秒単位）（デフォルト: 6）。 | INT | はい | 1 ～ 15 |
| `シード値` | ノードを再実行するかどうかを決定するためのシード。実際の結果はシードに関係なく非決定的です（デフォルト: 0）。 | INT | はい | 0 ～ 2147483647 |
| `image` | オプションの開始画像。省略した場合、動画はテキストプロンプトのみから生成されます。 | IMAGE | いいえ | - |

**注:** `image` が提供される場合、サポートされる入力画像は 1 枚のみです。複数の画像を提供するとエラーになります。画像が提供されない場合、または `grok-imagine-video` を使用する場合は画像があっても、`prompt` は空白を除去した後に空でない必要があります。`grok-imagine-video-1.5` モデルでは、入力画像が提供される場合に限り、`prompt` は省略可能です。`1080p` 解像度は `grok-imagine-video` では利用できません。`aspect_ratio` が `"auto"` に設定されている場合、アスペクト比はサービスによって自動的に選択されます。入力画像が提供される場合、`aspect_ratio` は無視され、動画は画像のアスペクト比に従います。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された動画。 | VIDEO |
