Grok Video ノードは、テキスト記述から短い動画を生成します。プロンプトを使用してゼロから動画を作成したり、単一の入力画像から動画を生成したりできます。このノードはリクエストを外部 API に送信し、生成された動画を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 動画生成に使用するモデル。 | COMBO | はい | `"grok-imagine-video"`<br />`"grok-imagine-video-1.5"` |
| `プロンプト` | 希望する動画のテキスト記述。入力画像が提供されている場合、`grok-imagine-video-1.5` では省略可能です。 | STRING | はい | - |
| `解像度` | 出力動画の解像度。1080p は `grok-imagine-video-1.5` でのみ利用可能です。 | COMBO | はい | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `アスペクト比` | 出力動画のアスペクト比。 | COMBO | はい | `"auto"`<br />`"16:9"`<br />`"4:3"`<br />`"3:2"`<br />`"1:1"`<br />`"2:3"`<br />`"3:4"`<br />`"9:16"` |
| `再生時間` | 出力動画の長さ（秒単位、デフォルト: 6）。 | INT | はい | 1 ～ 15 |
| `シード値` | ノードを再実行するかどうかを決定するシード。実際の結果はシードに関係なく非決定的です（デフォルト: 0）。 | INT | はい | 0 ～ 2147483647 |
| `image` | オプションの開始画像。省略した場合、動画はテキストプロンプトのみから生成されます。 | IMAGE | いいえ | - |

**注記:** `image` が提供される場合、対応する入力画像は 1 枚のみです。複数の画像を提供するとエラーが発生します。`prompt` は、画像が提供されていない場合、または `grok-imagine-video` を使用する場合は画像があっても、空白を除去した後に空であってはなりません。`grok-imagine-video-1.5` の場合、`prompt` は入力画像が提供されている場合にのみ省略可能です。`1080p` 解像度は `grok-imagine-video-1.5` でのみ利用可能です。`aspect_ratio` が `"auto"` に設定されている場合、アスペクト比はサービスによって自動的に選択されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された動画。 | VIDEO |
