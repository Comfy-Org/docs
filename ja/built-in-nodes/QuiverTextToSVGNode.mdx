The Quiver Text to SVG ノードは、Quiver AI のモデルを使用して、テキスト記述から Scalable Vector Graphic（SVG）画像を生成します。オプションで参照画像とスタイル指示を提供し、生成プロセスをガイドできます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成したい SVG 出力のテキスト記述。何を生成するかを指定する主な指示です。 | STRING | はい | N/A |
| `instructions` | 追加のスタイルまたはフォーマットに関するガイダンス。これはオプションの高度なパラメータです。 | STRING | いいえ | N/A |
| `reference_images` | 生成をガイドするための最大 4 枚の参照画像。これはオプションの入力です。 | IMAGE | いいえ | 0～4 枚の画像 |
| `model` | SVG 生成に使用するモデル。モデルを選択すると、そのモデル固有の追加パラメータ（`temperature`、`top_p`、`presence_penalty`）が表示されます。 | DYNAMIC_COMBO | はい | `"arrow-2"`<br />`"arrow-2-telos"`<br />`"arrow-1.1"`<br />`"arrow-1.1-max"`<br />`"arrow-preview"` |
| `seed` | ノードを再実行するかどうかを決定するためのシード。実際の結果はシードに関係なく非決定的です。デフォルト: 0。 | INT | はい | 0～2147483647 |
| `reasoning_effort` | モデルが描画前に費やす推論の量。レベルを上げると詳細が向上し、より多くのトークンを消費します。Arrow 2 モデルでのみ使用されます（デフォルト: `"high"`）。 | COMBO | いいえ | `"low"`<br />`"medium"`<br />`"high"`<br />`"xhigh"` |

**注:** `reference_images` 入力は最大 4 枚の画像を受け付けます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `SVG` | 生成された Scalable Vector Graphic（SVG）画像。 | SVG |
