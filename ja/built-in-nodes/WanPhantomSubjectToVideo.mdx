The WanPhantomSubjectToVideo ノードは、Wan 動画生成用の conditioning データと latent を準備します。指定された `width`、`height`、`length`、バッチサイズから空の latent 動画を作成し、参照画像が指定された場合は VAE でエンコードして、時間次元の視覚的ガイダンスとして conditioning に追加します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ポジティブ` | 動画生成を誘導するためのポジティブ conditioning 入力 | CONDITIONING | はい | - |
| `ネガティブ` | 特定の特徴を避けるためのネガティブ conditioning 入力 | CONDITIONING | はい | - |
| `VAE` | 参照画像が指定された際にそれらをエンコードするために使用される VAE モデル | VAE | はい | - |
| `幅` | 出力動画の幅（ピクセル単位、デフォルト: 832） | INT | はい | 16 to MAX_RESOLUTION （ステップ 16） |
| `高さ` | 出力動画の高さ（ピクセル単位、デフォルト: 480） | INT | はい | 16 to MAX_RESOLUTION （ステップ 16） |
| `長さ` | 生成される動画のフレーム数（デフォルト: 81） | INT | はい | 1 to MAX_RESOLUTION （ステップ 4） |
| `バッチサイズ` | 同時に生成する動画の数（デフォルト: 1） | INT | はい | 1 〜 4096 |
| `画像` | 時間次元の視覚的ガイダンスとして使用されるオプションの参照画像 | IMAGE | いいえ | - |

**注意:** `images` が指定された場合、それらは指定された `width` と `height` に一致するように自動的にアップスケールされ、最初の `length` 枚の画像のみが処理に使用されます。各画像は `vae` でエンコードされて時間次元に沿って連結され、各画像の RGB チャンネルのみが使用されます。`images` が指定されない場合、3 つの conditioning 出力はすべて入力 conditioning から変更されずに返されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | 画像が指定された場合は、エンコードされた参照画像を時間次元に連結したポジティブ conditioning。それ以外の場合は入力 `positive` が変更されずに返されます | CONDITIONING |
| `negative_text` | 画像が指定された場合は、エンコードされた参照画像を時間次元に連結したネガティブ conditioning。それ以外の場合は入力 `negative` が変更されずに返されます | CONDITIONING |
| `negative_img_text` | 画像が指定された場合は、ゼロ埋めされた時間次元の連結を持つネガティブ conditioning。それ以外の場合は入力 `negative` が変更されずに返されます | CONDITIONING |
| `latent` | 16 チャンネルのゼロ埋めされた latent 動画テンソル。そのフレーム数は `length` から、空間次元は `height` と `width` から導出されます | LATENT |
