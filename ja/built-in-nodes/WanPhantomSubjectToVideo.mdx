WanPhantomSubjectToVideo ノードは、Wan 動画生成用の conditioning データと潜在変数（latent）を準備します。指定された width、height、length、batch_size に基づいて空の潜在動画を作成し、参照画像が提供された場合には、それらを VAE でエンコードして、時間次元の視覚的ガイダンスとして conditioning に追加します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ポジティブ` | 動画生成を導くためのポジティブ conditioning 入力です。 | CONDITIONING | はい | - |
| `ネガティブ` | 特定の特徴を避けるためのネガティブ conditioning 入力です。 | CONDITIONING | はい | - |
| `VAE` | 参照画像が提供された場合に、それらをエンコードするために使用される VAE モデルです。 | VAE | はい | - |
| `幅` | 出力動画の幅（ピクセル単位）です（デフォルト: 832、16 の倍数である必要があります）。 | INT | はい | 16 to MAX_RESOLUTION |
| `高さ` | 出力動画の高さ（ピクセル単位）です（デフォルト: 480、16 の倍数である必要があります）。 | INT | はい | 16 to MAX_RESOLUTION |
| `長さ` | 生成される動画のフレーム数です（デフォルト: 81、4 の倍数である必要があります）。 | INT | はい | 1 to MAX_RESOLUTION |
| `バッチサイズ` | 同時に生成する動画の数です（デフォルト: 1）。 | INT | はい | 1〜4096 |
| `画像` | 時間次元の視覚的ガイダンスとして使用されるオプションの参照画像です。 | IMAGE | いいえ | - |

**注記:** `images` が提供された場合、それらは指定された `width` と `height` に合わせて自動的にアップスケールされ、処理には最初の `length` 個の画像のみが使用されます。各画像は `vae` でエンコードされ、時間次元に沿って連結されます。また、各画像の RGB チャンネルのみが使用されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `ポジティブ` | 画像が提供された場合は、エンコードされた参照画像を時間次元で連結したポジティブ conditioning です。それ以外の場合は、入力 `positive` がそのまま返されます。 | CONDITIONING |
| `ネガティブテキスト` | 画像が提供された場合は、エンコードされた参照画像を時間次元で連結したネガティブ conditioning です。それ以外の場合は、入力 `negative` がそのまま返されます。 | CONDITIONING |
| `ネガティブ画像テキスト` | 画像が提供された場合は、ゼロ埋めされた時間次元の連結を持つネガティブ conditioning です。それ以外の場合は、入力 `negative` がそのまま返されます。 | CONDITIONING |
| `潜在表現` | 16 チャンネルのゼロ埋め潜在動画テンソルです。フレーム数は `length` から、空間次元は `height` と `width` から導出されます。 | LATENT |
