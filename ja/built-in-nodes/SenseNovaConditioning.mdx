SenseNova コンディショニングを、画像生成用またはテキストと画像のインターリーブ出力用に準備します。`task` セレクターはプロンプトテンプレートと停止動作を設定し、ノードはモデルが画像を要求しているかどうかを報告します。これによりループは、サンプラーを実行すべきタイミングを判断できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `clip` | CLIP Text Encode から接続される SenseNova CLIP モデル。入力されるコンディショニングがすでに完了している場合を除き、すべてのタスクで必要です。 | CLIP | いいえ | - |
| `conditioning` | CLIP Text Encode からの SenseNova テキストコンディショニング。 | CONDITIONING | はい | - |
| `negative` | オプションのネガティブコンディショニング。`interleave` タスクと `self-correction` タスクでは更新されて返されます。 | CONDITIONING | いいえ | - |
| `task` | 実行するタスク。`"image"` は標準サンプラー用にプロンプトをエンコードし、`"image thinking"` はモデルが応答する前に考えさせ、`"interleave"` はテキストと画像を 1 回のパスで生成し、`"self-correction"` はモデルが自身の以前の出力を修正できるようにします。 | DYNAMIC_COMBO | はい | `"image"`<br />`"image thinking"`<br />`"interleave"`<br />`"self-correction"` |
| `max_tokens` | この呼び出し中に生成される最大トークン数。デフォルト：1024。 | INT | はい | 1～8192 |

### `interleave` 入力

これらの入力は、`task` が `"interleave"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `thinking` | モデルが応答する前に考えさせます。デフォルト：True。 | BOOLEAN | はい | True<br />False |
| `samples` | 前回のサンプラー出力。画像要求の後に続行する場合に接続します。 | LATENT | いいえ | - |

### `self-correction` 入力

これらの入力は、`task` が `"self-correction"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `samples` | 前回のサンプラー出力。画像要求の後に続行する場合に接続します。 | LATENT | いいえ | - |

**制約と動作：**

* `clip` 入力には CLIP Text Encode の SenseNova CLIP 出力が必要です。それ以外の CLIP はエラーを発生させます。
* `"image thinking"` にはポジティブコンディショニングのエントリが 1 つだけ必要です。`"interleave"` と `"self-correction"` にはポジティブとネガティブのエントリが 1 つずつ必要です。
* モデルが画像を待機している場合、前のサンプラーの LATENT 出力を `samples` に接続します。画像が要求される前にサンプルを渡すとエラーになります。
* 入力されるコンディショニングがすでに完了している場合、ノードはそれを変更せずに返し、`generated_text` は空、`image_requested` は False に設定されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `conditioning` | サンプラー用のコンディショニング。この呼び出しで生成されたテキストで拡張されています。 | CONDITIONING |
| `generated_text` | この呼び出しで生成されたテキスト。完全な結果を得るには SenseNova Interleave Decode を使用してください。 | STRING |
| `negative` | `interleave` タスクと `self-correction` タスク用に更新されたネガティブコンディショニング。 | CONDITIONING |
| `image_requested` | モデルが画像を要求した場合は True になります。サンプラーを実行し、その後ループをこのノードに戻してください。 | BOOLEAN |
