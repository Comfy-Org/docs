接続したテキスト、画像、音声、または動画に対して、自身で指定したオプションから 1 つを選び、選択されたオプション、その位置、および信頼度を取得します。`choice` を、同じオプション名を入力に持つ Branch ノードに接続するか、`option_index` に基づいてルーティングしてください。Branch ノードは最大 32 個の入力を受け付けるため、より大きなオプションセットは `option_index` でルーティングしてください。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 使用するモデルです（デフォルト: `"gemini-decision-1"`）。 | COMBO | はい | `"gemini-decision-1"` |
| `question` | オプションが回答する質問です。最大 5000 文字です（デフォルト: "What style is the image?"）。 | STRING | はい | 1～5000 文字 |
| `options` | 1 行に 1 つのオプションを指定し、入力されたとおりに使用されます。各オプションは最大 128 文字です。どのオプションにも当てはまらない入力用に、`other` などのオプションを追加してください（デフォルト: `photo`、`illustration`、`3d render`、`anime`、`sketch`、`other`）。 | STRING | はい | 2～255 個のオプション |
| `images` | 分類する画像です。追加可能なスロット（`image_1` ... `image_16`）全体で最大 16 枚です。バッチ化された画像は、画像ごとに 1 枚として数えられます。 | IMAGE | いいえ | 最大 16 枚の画像 |
| `audio` | 分類する音声クリップです。 | AUDIO | いいえ | - |
| `video` | 分類する動画クリップです。 | VIDEO | いいえ | - |
| `text` | 質問の対象となるテキストです。プロンプトや LLM の応答などで、最大 20000 文字です。 | STRING | いいえ | 最大 20000 文字 |

オプションは 2 個以上 255 個以下で指定し、同じものを重複して記載しないでください。それ以外の場合、ノードはエラーを発生させます。`text`、`images`、`audio`、`video` のうち少なくとも 1 つを接続し、複数の画像を使用する場合は質問内で `image_1`、`image_2` などの名前を付けてください。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `choice` | 選択されたオプションです。`options` に記述されたとおりの値です。 | STRING |
| `option_index` | `options` 内での選択されたオプションの位置です。0 から始まります。 | INT |
| `confidence` | 選択に対する信頼度です。0～1 の範囲です。 | FLOAT |
