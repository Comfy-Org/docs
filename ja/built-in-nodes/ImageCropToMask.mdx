画像をマスクの境界ボックスに合わせて切り抜き、選択した背景色の上に中央寄せされた被写体を生成します。このノードは、マスクされた画像を選択した背景の上に合成し、指定された出力寸法にリサイズすることで、固定解像度で中央寄せされた背景なしの被写体を必要とする3Dパイプラインに適した結果を提供します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | クロップする入力画像または画像のバッチ。 | IMAGE | はい | — |
| `マスク` | 被写体領域を定義するマスクまたはマスクのバッチ。単一のマスクはすべての画像に適用されます。それ以外の場合、マスクのバッチサイズは画像のバッチサイズと一致する必要があります。マスクの解像度が画像の解像度と異なる場合は、マスクは自動的にリサイズされます。 | MASK | はい | — |
| `幅` | 出力幅（ピクセル単位）。（デフォルト: 1024） | INT | はい | 64〜4096 (step 8) |
| `高さ` | 出力高さ（ピクセル単位）。（デフォルト: 1024） | INT | はい | 64〜4096 (step 8) |
| `pad_factor` | マスクの境界ボックス周囲の余白を拡大するための乗数。（デフォルト: 1.0） | FLOAT | はい | 1.0〜2.0 (step 0.01) |
| `grow_mask` | クロップ前にマスクをこのピクセル数だけ拡大または縮小します。正の値はマスクを拡大し、負の値は縮小します。（デフォルト: 0） | INT | はい | -32〜32 (step 1) |
| `背景` | マスクされた被写体の背後にある背景色。（デフォルト: #000000） | COLOR | はい | — |

注：クロップ領域はマスクの境界ボックスを中心とし、そのアスペクト比は `width` / `height` に一致します。このノードは、反転したマスク（境界に沿った前景ピクセルと中央の背景）を自動的に検出して修正します。マスクに前景ピクセルが含まれない場合、ノードは反転したマスクを試します。それも空の場合は、警告をログに記録して画像全体をクロップします。マスクのバッチサイズが画像のバッチサイズと一致せず、単一のマスクでもない場合には、エラーが発生します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `画像` | クロップされた合成画像（選択した背景色の上にマスクされた被写体）で、`width` x `height` にリサイズされます。バッチサイズは入力画像バッチと一致します。 | IMAGE |
