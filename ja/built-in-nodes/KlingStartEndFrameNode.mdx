このノードは、指定した開始画像と終了画像の間で遷移する動画シーケンスを作成します。最初のフレームから最後のフレームへ滑らかに変化するよう、その間のすべてのフレームを生成します。このノードは image-to-video API を呼び出しますが、`image_tail` リクエストフィールドで機能する入力オプションのみをサポートします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | 参照画像 - URL または Base64 エンコード文字列。10MB を超えることはできません。解像度は 300*300px 以上、アスペクト比は 1:2.5 ～ 2.5:1 の範囲である必要があります。Base64 には data:image プレフィックスを含めないでください。 | IMAGE | はい | - |
| `end_frame` | 参照画像 - 終了フレームの制御。URL または Base64 エンコード文字列。10MB を超えることはできません。解像度は 300*300px 以上である必要があります。Base64 には data:image プレフィックスを含めないでください。 | IMAGE | はい | - |
| `prompt` | ポジティブテキストプロンプト。空にできず、500 文字を超えることはできません。 | STRING | はい | - |
| `negative_prompt` | ネガティブテキストプロンプト。500 文字を超えることはできません。空の場合、リクエストから省略されます。 | STRING | はい | - |
| `cfg_scale` | プロンプトガイダンスの強度を制御します（デフォルト: 0.5）。 | FLOAT | はい | 0.0-1.0 |
| `aspect_ratio` | 生成される動画のアスペクト比（デフォルト: "16:9"）。 | COMBO | はい | "16:9"<br />"9:16"<br />"1:1" |
| `mode` | 動画生成に使用する設定。形式は mode / duration / model_name です。（デフォルト: "pro mode / 5s duration / kling-v2-5-turbo"） | COMBO | はい | "pro mode / 5s duration / kling-v2-5-turbo"<br />"pro mode / 10s duration / kling-v2-5-turbo" |

**画像の制約:**

- `start_frame` と `end_frame` はどちらも必須で、ファイルサイズは 10MB を超えることはできません。
- 最小解像度: 両方の画像で 300×300 ピクセル。
- `start_frame` のアスペクト比は 1:2.5 ～ 2.5:1 の範囲である必要があります。
- Base64 エンコードされた画像には "data:image" プレフィックスを含めないでください。

**プロンプトの制約:**

- `prompt` は空にできず、500 文字を超えることはできません。
- `negative_prompt` は 500 文字を超えることはできません。空の場合、リクエストとともに送信されません。

**モードに関する注意:**

- どちらのモードオプションも pro mode と kling-v2-5-turbo モデルを使用し、長さ（5 秒または 10 秒）のみが異なります。
- ノードの価格バッジに表示される生成ごとの料金: 5 秒モードは $0.35 USD、10 秒モードは $0.70 USD です。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された動画シーケンス。 | VIDEO |
| `video_id` | 生成された動画の一意の識別子。 | STRING |
| `duration` | 生成された動画の長さ。 | STRING |
