WanFirstLastFrameToVideo ノードは、開始フレームと終了フレームをテキストプロンプトと組み合わせて、ビデオ生成用のコンディショニングを準備します。フレーム画像を潜在空間にエンコードし、ビデオモデルにどのフレームが既知かを伝えるマスクを作成し、CLIPビジョン特徴が提供された場合にはそれを添付します。このノードは、更新されたポジティブおよびネガティブコンディショニングと、生成するビデオのサイズと長さを定義する空の潜在変数を出力します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ポジティブ` | ビデオ生成をガイドするために使用されるポジティブなテキストコンディショニング。 | CONDITIONING | はい | - |
| `ネガティブ` | ビデオ生成をガイドするために使用されるネガティブなテキストコンディショニング。 | CONDITIONING | はい | - |
| `vae` | 結合されたフレーム画像を潜在空間にエンコードするために使用されるVAEモデル。 | VAE | はい | - |
| `幅` | 生成されるビデオの幅（ピクセル単位、デフォルト: 832、ステップ: 16）。 | INT | はい | 16 to MAX_RESOLUTION |
| `高さ` | 生成されるビデオの高さ（ピクセル単位、デフォルト: 480、ステップ: 16）。 | INT | はい | 16 to MAX_RESOLUTION |
| `長さ` | ビデオシーケンスのフレーム数（デフォルト: 81、ステップ: 4）。 | INT | はい | 1 to MAX_RESOLUTION |

| `clipビジョン終了画像` | 終了画像から抽出されたCLIPビジョン特徴。開始と終了の両方のCLIPビジョン入力が提供された場合、それらの特徴は結合されます。 | CLIP_VISION_OUTPUT | いいえ | - |
| `開始画像` | ビデオシーケンスの開始フレーム画像。その最初の `length` フレームが使用され、`width` × `height` にリサイズされます。 | IMAGE | いいえ | - |
| `終了画像` | ビデオシーケンスの終了フレーム画像。その最後の `length` フレームが使用され、`width` × `height` にリサイズされます。 | IMAGE | いいえ | - |

**注記:** `start_image` または `end_image` の少なくとも一方が提供されると、ノードは結合フレームシーケンスを構築します。開始フレームと終了フレームが埋められ、残りのフレームにはニュートラルグレー（0.5）のプレースホルダーが使用されます。マスクは、埋められた領域を既知、プレースホルダー領域を未知としてマークし、ビデオモデルが中間フレームを生成できるようにします。開始画像が提供された場合、既知領域は画像の3フレーム分も拡張されます。エンコードされたフレーム画像とマスクは、`positive` と `negative` の両方のコンディショニングに添付されます。両方のCLIPビジョン入力が提供された場合は、それらの隠れ状態が連結されます。一方のみが提供された場合は、そのまま使用されます。潜在ビデオの長さは、時間圧縮後に `length` から導出されます: `((length - 1) // 4) + 1`。
