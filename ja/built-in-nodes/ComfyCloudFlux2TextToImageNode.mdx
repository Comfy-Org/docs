Flux 2 dev の text-to-image モデルを Comfy Cloud GPU 上で実行し、生成された画像を返します。`turbo` オプションは、短いスケジュールで Turbo LoRA を適用し、多少の忠実度と引き換えに大幅に高速化して実行します。オフにすると、LoRA なしでフルレングスの dev パスを実行します。これはベータ版のノードセットで、実行時間に応じてクレジットで課金されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成する画像を説明するテキストプロンプトです。送信前に先頭と末尾の空白は削除されます。 | STRING | はい | 1 〜 4096 characters |
| `seed` | 再現性のために生成結果を制御するランダムシードです（デフォルト：42）。 | INT | はい | 0 〜 18446744073709551615 |
| `aspect_ratio` | 出力画像のアスペクト比です（デフォルト："1:1"）。 | COMBO | はい | "1:1"<br />"3:4"<br />"2:3"<br />"3:2"<br />"4:3"<br />"16:9"<br />"9:16"<br />"21:9" |
| `megapixels` | 合計ピクセル予算です。正方形比では 1.0 は約 1024x1024 に相当します（デフォルト：1.0）。 | FLOAT | はい | 0.1 〜 16.0 （ステップ 0.1） |
| `turbo` | 短いスケジュールで Turbo LoRA を実行し、多少の忠実度と引き換えに大幅に高速化して実行します。オフにすると、LoRA なしでフルレングスの dev パスを実行します（デフォルト：True）。 | BOOLEAN | はい | True / False |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | テキストプロンプトから生成された画像で、他のノードに渡すことができる ComfyUI の画像テンソルとして返されます。 | IMAGE |
