WanCameraImageToVideo ノードは、画像からのビデオ生成に必要な conditioning データと latent データを準備します。このノードは、ポジティブおよびネガティブの conditioning プロンプトに加えて、オプションの開始画像とオプションのカメラコントロールを受け取り、変更された conditioning と、ビデオモデルが入力するための空の latent テンソルを出力します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ポジティブ` | ビデオ生成のためのポジティブ conditioning プロンプトです。 | CONDITIONING | はい | - |
| `ネガティブ` | ビデオ生成で回避するためのネガティブ conditioning プロンプトです。 | CONDITIONING | はい | - |
| `VAE` | 画像を latent 空間にエンコードするための VAE モデルです。 | VAE | はい | - |
| `幅` | 出力ビデオの幅（ピクセル単位）です（デフォルト: 832、ステップ: 16）。 | INT | はい | 16 から MAX_RESOLUTION |
| `高さ` | 出力ビデオの高さ（ピクセル単位）です（デフォルト: 480、ステップ: 16）。 | INT | はい | 16 から MAX_RESOLUTION |
| `長さ` | ビデオシーケンス内のフレーム数です（デフォルト: 81、ステップ: 4）。 | INT | はい | 1 から MAX_RESOLUTION |
| `バッチサイズ` | 同時に生成するビデオの数です（デフォルト: 1）。 | INT | はい | 1 から 4096 |
| `CLIPビジョン出力` | 追加 conditioning のためのオプションの CLIP vision 出力です。 | CLIP_VISION_OUTPUT | いいえ | - |
| `開始画像` | ビデオシーケンスを初期化するためのオプションの開始画像です。指定すると、ビデオの最初のフレームはこの画像に基づき、開始フレームと生成コンテンツをブレンドするためのマスクが適用されます。画像は指定された幅と高さにリサイズされます。 | IMAGE | いいえ | - |
| `カメラ条件` | ビデオ生成のためのオプションのカメラ埋め込み条件です。指定すると、これらの条件はポジティブとネガティブの両方の conditioning に適用されます。 | WAN_CAMERA_EMBEDDING | いいえ | - |

**注記:** `start_image` が指定された場合、入力画像の最初の `length` フレームのみがビデオシーケンスの初期化に使用され、ノードはこれらの開始フレームと生成コンテンツをブレンドするためのマスクを適用します。`camera_conditions` と `clip_vision_output` パラメータはオプションですが、指定された場合は、ポジティブとネガティブの両方のプロンプトの conditioning が変更されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `ポジティブ` | カメラ条件、CLIP vision 出力、および/または開始画像データが適用された、変更済みのポジティブ conditioning です。 | CONDITIONING |
| `ネガティブ` | カメラ条件、CLIP vision 出力、および/または開始画像データが適用された、変更済みのネガティブ conditioning です。 | CONDITIONING |
| `潜在変数` | ビデオモデルで使用するために生成された空のビデオ latent 表現です。latent テンソルの次元は [batch_size, 16, frames, height/8, width/8] で、frames は ((length - 1) // 4) + 1 として計算されます。 | LATENT |
