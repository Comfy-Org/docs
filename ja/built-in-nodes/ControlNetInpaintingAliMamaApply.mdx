ControlNetInpaintingAliMamaApply ノードは、ポジティブおよびネガティブな conditioning をコントロール画像とマスクと組み合わせることで、インペインティングタスク用の ControlNet conditioning を適用します。入力画像とマスクを処理して、生成プロセスを導く修正済みの conditioning を作成し、画像のどの領域をインペイントするかを正確に制御できます。このノードは、生成プロセスのさまざまな段階で ControlNet の影響を微調整するための強度調整とタイミング制御をサポートしています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ポジティブ` | 生成を望ましいコンテンツへ導くポジティブな conditioning | CONDITIONING | はい | - |
| `ネガティブ` | 生成を望ましくないコンテンツから遠ざけるネガティブな conditioning | CONDITIONING | はい | - |
| `コントロールネット` | 生成に対する追加の制御を提供する ControlNet モデル | CONTROL_NET | はい | - |
| `vae` | 画像のエンコードとデコードに使用される VAE（変分オートエンコーダー） | VAE | はい | - |
| `画像` | ControlNet の制御ガイダンスとして機能する入力画像 | IMAGE | はい | - |
| `マスク` | 画像のどの領域をインペイントするかを定義するマスク | MASK | はい | - |
| `強度` | ControlNet 効果の強さ（デフォルト: 1.0、ステップ: 0.01） | FLOAT | はい | 0.0〜10.0 |
| `開始パーセント` | 詳細パラメータ。生成中に ControlNet の影響が始まる開始点（パーセンテージ）（デフォルト: 0.0、ステップ: 0.001） | FLOAT | はい | 0.0〜1.0 |
| `終了パーセント` | 詳細パラメータ。生成中に ControlNet の影響が終了する終了点（パーセンテージ）（デフォルト: 1.0、ステップ: 0.001） | FLOAT | はい | 0.0〜1.0 |

**注記:** ControlNet で `concat_mask` が有効な場合、マスクは反転されて処理前に画像に適用され、反転されたマスクは ControlNet に送信される追加の連結データに含まれます。
