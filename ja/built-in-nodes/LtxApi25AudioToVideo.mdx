このノードは、LTX 2.5 モデルを使用して、オーディオトラックに合わせた動画を生成します。オーディオが動画の長さ（2秒から20秒）を決定し、オプションで最初のフレームとして使用する画像を指定できます。動画は LTX 2.5 API サービスを通じて生成されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `オーディオ` | 動画を駆動するオーディオトラック。その長さ（2〜20秒）が動画の長さを設定します。 | AUDIO | はい | 2-20 seconds |
| `モデル` | 使用する LTX 2.5 モデルのバージョン。動画の解像度（1920x1080 または 1080x1920）はモデルとともに選択されます。どちらのモデルも同じ解像度オプションを提供します。 | COMBO | はい | "LTX-2.5 (Fast)"<br />"LTX-2.5 (Pro)" |
| `プロンプト` | 生成される動画の内容をガイドするテキスト記述（デフォルト: ""）。1文字以上、10000文字以下である必要があります。 | STRING | はい | 1-10000 characters |
| `シード` | 生成のランダム性を制御する数値。同じシードは同じ結果を生成します（デフォルト: 42）。 | INT | はい | Any integer |
| `画像` | 動画に使用するオプションの最初のフレーム。サポートされるのは1枚のみです。 | IMAGE | いいえ | Single image |

制約に関する注意事項：
- オーディオの長さは2秒以上20秒以下である必要があります。この範囲外の場合はノードがエラーを発生させます。
- プロンプトは必須であり、空にすることはできません。1文字以上10000文字以下である必要があります。
- `image` が指定された場合、入力画像は1枚のみ受け付けられます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | 指定されたオーディオトラックに合わせて生成された動画。 | VIDEO |
