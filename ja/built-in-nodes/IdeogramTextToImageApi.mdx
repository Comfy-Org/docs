Ideogram 4.5 でテキストプロンプトから画像を生成します。プロンプトには Ideogram の構造化 JSON キャプションも指定できます。たとえば、以前の実行で返された `final_prompt` などです。これにより、テキスト文字列、色、レイアウトを正確に制御できます。ノードは、生成された画像と、その画像が実際に生成された元のキャプションを返します。

### パラメータ制約

- **プロンプト必須:** プロンプトには少なくとも1つの空白以外の文字を含める必要があり、最大10000文字までです。独自の JSON キャプションや正確な表現を指定する場合は、`magic_prompt` を `"off"` に設定してください。
- **サイズ:** `"auto"` はモデルに選択させます。`(2K)` プリセットは約300万〜400万画素、`(1K)` プリセットは約100万画素です。階層ラベルは固定の長辺ではなく画素数の目安を表します。プリセットのアスペクト比が尊重されます。API にはプリセットのピクセルサイズ部分のみが送信されます。
- **再現性:** `magic_prompt` が `"auto"` または `"on"` の場合、実行のたびにプロンプトが書き換えられるため、同じシードでも異なる画像が生成されることがあります。画像を再現するには、その `final_prompt` を、`magic_prompt` を `"off"` に設定して同じシードとともに再度入力します。
- **コンテンツセーフティ:** Ideogram のコンテンツセーフティフィルターが生成をブロックした場合、ノードは画像を返す代わりにエラーを発生させます。
