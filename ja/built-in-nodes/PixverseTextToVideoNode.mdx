テキストプロンプトと各種生成パラメータに基づいて動画を生成します。このノードはPixVerse APIを使用して動画コンテンツを作成し、アスペクト比、品質、再生時間、モーションスタイルなどを制御できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 動画生成用のプロンプト（デフォルト：""） | STRING | はい | - |
| `アスペクト比` | 生成される動画のアスペクト比 | COMBO | はい | `"16:9"`<br />`"9:16"`<br />`"1:1"` |
| `品質` | 動画の品質設定（デフォルト："540p"） | COMBO | はい | `"540p"`<br />`"1080p"` |
| `秒数` | 生成される動画の長さ（秒） | COMBO | はい | `"5"`<br />`"10"` |
| `モーションモード` | 動画生成時のモーションスタイル | COMBO | はい | `"normal"`<br />`"fast"` |
| `シード` | 動画生成用のシード（デフォルト：0） | INT | はい | 0〜2147483647 |
| `ネガティブプロンプト` | 画像内で望ましくない要素の任意のテキスト説明（デフォルト：""） | STRING | いいえ | - |
| `PixVerse テンプレート` | PixVerse Template ノードで作成される、生成スタイルに影響を与える任意のテンプレート | CUSTOM | いいえ | - |

**注意:** `prompt` は少なくとも1文字以上必要です。1080p品質を使用する場合、モーションモードは自動的に `normal` に設定され、再生時間は5秒に制限されます。5秒以外の再生時間の場合も、モーションモードは自動的に `normal` に設定されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された動画ファイル | VIDEO |
