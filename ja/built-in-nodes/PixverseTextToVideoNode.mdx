PixVerse API を使用して、テキストプロンプトから動画を生成します。このノードでは、動画の形状、品質、長さ、モーションスタイルを制御でき、必要に応じて保存済みのスタイルテンプレートを適用できます。リクエストを送信し、生成が完了するまで待機して、完成した動画を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 動画生成用のプロンプト（デフォルト: ""） | STRING | はい | 1文字以上である必要があります |
| `アスペクト比` | 生成される動画のアスペクト比 | COMBO | はい | `"16:9"`<br />`"9:16"`<br />`"1:1"` |
| `品質` | 動画品質の設定（デフォルト: "540p"） | COMBO | はい | `"540p"`<br />`"1080p"` |
| `秒数` | 生成される動画の長さ（秒） | COMBO | はい | `"5"`<br />`"10"` |
| `モーションモード` | 動画生成のモーションスタイル | COMBO | はい | `"normal"`<br />`"fast"` |
| `シード` | 動画生成用のシード（デフォルト: 0） | INT | はい | 0～2147483647 |
| `ネガティブプロンプト` | 画像上の望ましくない要素を説明する任意のテキスト（デフォルト: ""） | STRING | いいえ | - |
| `PixVerse テンプレート` | 生成スタイルに影響を与える任意のテンプレートで、PixVerse Template ノードによって作成されます | CUSTOM | いいえ | - |

**注：** `prompt` は少なくとも1文字以上である必要があります。1080p 品質を選択した場合、モーションモードは自動的に `normal` に設定され、長さは5秒に制限されます。5秒以外の長さの場合も、モーションモードは自動的に `normal` に設定されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された動画ファイル | VIDEO |
