PatchModelAddDownscale (Kohya Deep Shrink) は、選択したブロックで中間特徴量を縮小し、その後元のサイズに戻すことで、Kohya Deep Shrink 技術をモデルに適用します。縮小はノイズ除去プロセスの選択された部分でのみ行われるため、最終結果を元の結果に近い状態に保ちながら、処理コストを削減できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | ダウンスケールパッチを適用するモデル | MODEL | はい | - |
| `ブロック番号` | ダウンスケーリングを適用する特定のブロック番号（デフォルト: 3） | INT | はい | 1-32 |
| `ダウンスケール係数` | 特徴量をダウンスケールする係数（デフォルト: 2.0） | FLOAT | はい | 0.1-9.0 |
| `開始パーセント` | ノイズ除去プロセスにおいてダウンスケーリングを開始する開始点（デフォルト: 0.0） | FLOAT | はい | 0.0-1.0 |
| `終了パーセント` | ノイズ除去プロセスにおいてダウンスケーリングを停止する終了点（デフォルト: 0.35） | FLOAT | はい | 0.0-1.0 |
| `スキップ後のダウンスケール` | スキップ接続の後にダウンスケーリングを適用するかどうか（デフォルト: True） | BOOLEAN | はい | - |
| `ダウンスケール方法` | ダウンスケーリング操作に使用される補間方法（デフォルト: "bicubic"） | COMBO | はい | "bicubic"<br />"nearest-exact"<br />"bilinear"<br />"area"<br />"bislerp" |
| `アップスケール方法` | アップスケーリング操作に使用される補間方法（デフォルト: "bicubic"） | COMBO | はい | "bicubic"<br />"nearest-exact"<br />"bilinear"<br />"area"<br />"bislerp" |

ダウンスケールパッチは、現在のノイズ除去ステップが `start_percent` と `end_percent` で定義された範囲内にある場合にのみ適用され、かつ `block_number` で選択されたブロックでのみ適用されます。`downscale_after_skip` が有効な場合、パッチはスキップ接続の後に適用されます。無効な場合、スキップ接続の前に適用されます。その後、特徴量は元のサイズに戻されますが、これは現在の特徴量サイズがダウンスケーリング前に記録されたサイズと一致しなくなった場合にのみ行われます。

パラメータ `block_number`、`start_percent`、`end_percent`、`downscale_after_skip` は、ノードインターフェースで詳細オプションとしてマークされています。
