WanAnimate2ToVideo は、参照画像のキャラクターを、別のポーズ動画から顔の表情、体の動き、手のジェスチャーを転送してアニメーション化します。動画生成サンプラーがアニメーションを生成するために使用するコンディショニングデータと開始用の潜在変数を構築します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 動画生成用のポジティブコンディショニングです。 | CONDITIONING | はい | N/A |
| `negative` | 動画生成用のネガティブコンディショニングです。 | CONDITIONING | はい | N/A |
| `vae` | 参照画像と動画フレームを潜在空間にエンコードするために使用される VAE です。 | VAE | はい | N/A |
| `width` | 出力動画の幅（ピクセル単位）です。(デフォルト: 832) | INT | はい | 16〜MAX_RESOLUTION (ステップ 16) |
| `height` | 出力動画の高さ（ピクセル単位）です。(デフォルト: 480) | INT | はい | 16〜MAX_RESOLUTION (ステップ 16) |
| `length` | 生成するフレーム数です。(デフォルト: 81) | INT | はい | 1〜MAX_RESOLUTION (ステップ 4) |
| `batch_size` | 同時に生成する動画の数です。(デフォルト: 1) | INT | はい | 1〜4096 |
| `reference_image` | アニメーション化するキャラクターです。省略すると黒い画像が使用されます。 | IMAGE | いいえ | N/A |
| `pose_video` | 動きが参照キャラクターに転送される動画です。フレーム数が `length` より少ない場合、不足しているフレームを埋めるために最後のフレームが繰り返されます。 | IMAGE | いいえ | N/A |
| `clip_vision_output` | 参照画像のCLIPビジョンです。 | CLIP_VISION_OUTPUT | いいえ | N/A |
| `positive_pose` | ポーズ動画ブランチ用のプロンプトで、キャラクターではなく動きを説明します。デフォルトは `positive` です。cond パスと uncond パスの両方で使用されます。 | CONDITIONING | いいえ | N/A |
| `clip_vision_output_pose` | ポーズ動画の最初のフレームのCLIPビジョンです。デフォルトは `clip_vision_output` です。 | CLIP_VISION_OUTPUT | いいえ | N/A |
| `continue_motion` | 時間的一貫性を保つために引き継ぐ前回のモーションシーケンスです。このシーケンスの最後のフレームのみが開始モーションフレームとして使用されます。 | IMAGE | いいえ | N/A |
| `video_frame_offset` | ポーズ動画内でシークするフレーム数です。動画を延長する場合は、前のノードの `video_frame_offset` 出力に接続します。(デフォルト: 0) | INT | はい | 0〜MAX_RESOLUTION |
| `pose_strength` | ポーズ動画がモーションに与える影響をスケーリングします。1.0 は学習時の動作です。1.0未満では追従が弱くなり、1.0超では増幅されます。0.0 は影響をミュートしますが、完全には除去しません。(デフォルト: 1.0) | FLOAT | はい | 0.00〜10.00 (ステップ 0.01) |
| `pose_start_percent` | ポーズの影響が開始されるサンプリング進行率です。この範囲外ではポーズブランチが完全にスキップされ、それらのステップも高速化されます。(デフォルト: 0.0) | FLOAT | はい | 0.00〜1.00 (ステップ 0.01) |
| `pose_end_percent` | ポーズの影響が終了するサンプリング進行率です。モーションは主に序盤で確立されるため、例えば 0.7 にすると、振り付けを保ちつつ細部の再現を緩めることができます。(デフォルト: 1.0) | FLOAT | はい | 0.00〜1.00 (ステップ 0.01) |
| `reference_image_strength` | 生成フレームが参照画像の潜在フレームにどれだけ強く注意を向けるかをスケーリングします。1.0 未満では、アイデンティティ/外見の追従が緩くなり（例: プロンプトでスタイルを変更できるようにするため）、1.0 超では、ドリフトに対する追従が強くなります。(デフォルト: 1.0) | FLOAT | はい | 0.00〜10.00 (ステップ 0.01) |

**検証ノート:**

- `pose_start_percent` は `pose_end_percent` より大きくすることはできません。そうでない場合、ノードは ValueError を発生させます。
- `pose_video` が指定されている場合、そのフレーム数は `video_frame_offset` より大きくなければなりません。そうでない場合、ノードは ValueError を発生させます。

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `positive` | 参照画像、マスク、および任意のポーズデータが付加された、サンプリング用のポジティブコンディショニングです。 | CONDITIONING |
