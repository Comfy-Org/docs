## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `動画` | 拡張される入力ビデオファイル。 | VIDEO | はい | - |
| `アップスケーラー有効` | ビデオアップスケーリング機能を有効または無効にします（デフォルト: True）。 | BOOLEAN | はい | - |
| `アップスケーラーモデル` | ビデオのアップスケーリングに使用されるAIモデル。 | COMBO | はい | `"Starlight (Astra) Fast"`<br />`"Starlight (Astra) Creative"`<br />`"Starlight Precise 2.5"` |
| `アップスケーラー解像度` | アップスケーリングされたビデオのターゲット解像度。 | COMBO | はい | `"FullHD (1080p)"`<br />`"4K (2160p)"` |
| `アップスケーラー創造性` | 創造性レベル（Starlight (Astra) Creative にのみ適用されます）。（デフォルト: "low"） | COMBO | いいえ | `"low"`<br />`"middle"`<br />`"high"` |
| `補間有効` | フレーム補間機能を有効または無効にします（デフォルト: False）。 | BOOLEAN | いいえ | - |
| `補間モデル` | フレーム補間に使用されるモデル（デフォルト: "apo-8"）。 | COMBO | いいえ | `"apo-8"` |
| `スローモーション補間` | 入力ビデオに適用されるスローモーション係数。たとえば、2 にすると出力は 2 倍遅くなり、長さも 2 倍になります。（デフォルト: 1） | INT | いいえ | 1 から 16 |
| `補間フレームレート` | 出力フレームレート。（デフォルト: 60） | INT | いいえ | 15 から 240 |
| `重複フレーム除去` | 入力を分析して重複フレームを検出し、削除します。（デフォルト: False） | BOOLEAN | いいえ | - |
| `重複検出感度` | 重複フレームの検出感度。（デフォルト: 0.01） | FLOAT | いいえ | 0.001 から 0.1 |
| `動的圧縮レベル` | CQP レベル。（デフォルト: "Low"） | COMBO | いいえ | `"Low"`<br />`"Mid"`<br />`"High"` |

**注記:** 少なくとも1つの拡張機能を有効にする必要があります。`upscaler_enabled` と `interpolation_enabled` の両方が False に設定されている場合、ノードはエラーを発生させます。入力ビデオは MP4 形式である必要があります。`upscaler_creativity` 設定は、`upscaler_model` が "Starlight (Astra) Creative" に設定されている場合にのみ適用されます。マルチパートアップロードが必要な非常に大きなビデオファイルはサポートされていません。
