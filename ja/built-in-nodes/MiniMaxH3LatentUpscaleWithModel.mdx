MiniMax H3 Latent Upscale With Model は、MiniMax H3 latent の映像部分を、latent アップスケールモデルを使用して指定した幅と高さにリサイズします。音声 latent はそのまま保持されるため、クリップは音声を保ち、再サンプリングも不要です。クリップをより大きく出力したい場合は、MiniMax H3 サンプリング後、H3 VAE デコード前に使用してください。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | latent アップスケールモデル。通常は Load Latent Upscale Model で読み込みます。MiniMax H3 の 3D 畳み込み latent アップスケーラーである必要があります。 | LATENT_UPSCALE_MODEL | はい | - |
| `samples` | リサイズ対象の MiniMax H3 latent。ネストされた latent は音声部分をそのまま保持します。 | LATENT | はい | - |
| `width` | ピクセル単位の対象映像幅。latent は `width / 16` 列にリサイズされるため、値は 16 の倍数に切り捨てられます。（デフォルト: 2560） | INT | はい | 32 〜 16384 （ステップ 32） |
| `height` | ピクセル単位の対象映像高さ。こちらも 16 の倍数に切り捨てられます。（デフォルト: 1440） | INT | はい | 32 〜 16384 （ステップ 32） |

要求されたサイズがすでに latent と一致している場合、入力 latent は変更されずに返されます。サイズ変更された latent には `noise_mask` が含まれないため、部分的にマスクされた latent はマスクを失います。ネットワークは 3D 畳み込みを時間方向のスラブ単位で実行するため、長いクリップでもメモリ使用量は単一スラブの場合に近い値に抑えられます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `LATENT` | リサイズされた latent。H3 VAE デコードに使用できます。 | LATENT |
