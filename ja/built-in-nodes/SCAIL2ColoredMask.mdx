このノードは、SAM3 トラッキングデータを、WanSCAILToVideo ノードで使用されるカラーマスクにレンダリングします。ドライビングポーズ動画、およびオプションで参照画像からのトラッキングデータを処理し、両方の出力において各トラッキング対象人物に一貫した色を割り当てます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `ドライビングトラックデータ` | ドライビングポーズ動画の SAM3 トラック。`pose_video_mask` 出力にレンダリングされます。 | SAM3_TRACK_DATA | はい | - |
| `リファレンストラックデータ` | 参照画像の SAM3 トラック（オブジェクトごとに1つのアイデンティティ、バッチ順に色付け）、または参照被写体のプレーンな MASK（単一のアイデンティティとしてレンダリング）。 | SAM3_TRACK_DATA または MASK | いいえ | - |
| `オブジェクトインデックス` | 含める人物インデックスのカンマ区切りリスト（例：'0,2,3'）。参照マスクとポーズ動画マスクの両方に適用されます。空 = すべて。（デフォルト：""） | STRING | はい | - |
| `並び順` | パレットの色がトラッキング対象オブジェクトに割り当てられる順序（参照とポーズ動画の両方に適用され、各アイデンティティが同じ色を保ちます）。より早いフレームに現れるオブジェクトが常に先になります。フレーム内では、left_to_right = 最も左のオブジェクト（最初に現れた時点の重心による）が最初の色を取得し、area = 最大のオブジェクト（最初に現れた時点のマスク面積による）が最初の色を取得します。none = SAM3 の順序を維持します。（デフォルト："left_to_right"） | COMBO | はい | `"none"`<br />`"left_to_right"`<br />`"area"` |
| `置換モード` | False = アニメーションモード（`pose_video_mask` は黒背景、`reference_image_mask` は白背景）。True = 置換モード（`pose_video_mask` は白背景、`reference_image_mask` は黒背景）。（デフォルト：False） | BOOLEAN | はい | False<br />True |

注：`object_indices` はカンマ区切りの数字のみを受け付けます。非数値のエントリおよび範囲外のインデックスは無視されます。`ref_track_data` が提供されない場合、`reference_image_mask` 出力は参照背景色（アニメーションモードでは白、置換モードでは黒）による単色塗りつぶしになります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `pose_video_mask` | ドライビングポーズ動画のトラッキングデータからレンダリングされたカラーマスク。背景色は `replacement_mode` 設定に従います。 | IMAGE |
| `reference_image_mask` | 参照画像のトラッキングデータからレンダリングされたカラーマスク。背景は置換モードでは黒、アニメーションモードでは白です。参照データが提供されない場合、参照背景色に一致する単色塗りつぶしを返します。 | IMAGE |
