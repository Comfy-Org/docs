このノードは、MiniMax H3 モデルを使用してビデオを生成し、参照画像・ビデオ・オーディオを利用して結果を導きます。参照メディアは、接続順に「Image 1」「Image 2」「Video 1」「Audio 1」のようにプロンプト内で参照されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | ビデオ生成に使用するモデルです（デフォルト: "MiniMax H3"）。"MiniMax H3" を選択すると、以下の `prompt`、`duration`、`resolution`、`ratio`、`reference_images`、`reference_videos`、`reference_audios` の各設定が提供されます。 | STRING | はい | "MiniMax H3" |
| `prompt` | 生成するビデオのテキストによる説明です。参照メディアは、順序に従って「Image 1」「Image 2」「Video 1」「Audio 1」のように参照できます。 | STRING | はい | 最小長さ：1 文字（空白をトリミングした後） |
| `duration` | 生成されるビデオの長さ（秒）です。 | INT | はい | 複数のオプションから選択可能 |
| `resolution` | 生成されるビデオの出力解像度です。 | STRING | はい | 複数のオプションから選択可能 |
| `ratio` | 生成されるビデオのアスペクト比です。 | STRING | はい | 複数のオプションから選択可能 |
| `reference_images` | 被写体またはスタイルの参照画像です。接続順に「Image 1」～「Image 9」としてプロンプト内で参照されます。最大9枚です。 | IMAGE | いいえ | 0〜9枚 |
| `reference_videos` | 動きまたはシーンの参照ビデオです。接続順に「Video 1」～「Video 3」としてプロンプト内で参照されます。最大3本で、各2〜15秒、合計15秒以内です。 | VIDEO | いいえ | 0〜3本 |
| `reference_audios` | オーディオ参照です。接続順に「Audio 1」～「Audio 3」としてプロンプト内で参照されます。最大3クリップで、各2〜15秒、合計15秒以内です。参照画像または参照ビデオなしでは使用できません。 | AUDIO | いいえ | 0〜3クリップ |

| `ウォーターマーク` | ビデオに AIGC 透かしを追加するかどうかです（デフォルト: false）。 | BOOLEAN | いいえ | true<br />false |

### パラメータの制約

- 参照画像または参照ビデオが少なくとも1つ必要です。参照オーディオのみでは受け付けられません。
- 各参照画像のアスペクト比は、およそ0.4〜2.5（2:5〜5:2）の範囲内で、幅と高さがそれぞれ256ピクセル以上である必要があります。
- 各参照ビデオは、長さ2〜15秒で、フレームレートが23.976〜60 FPSの範囲内である必要があります。すべての参照ビデオの合計時間は15秒を超えることはできません。
- 各参照オーディオクリップは、長さ2〜15秒である必要があります。すべての参照オーディオクリップの合計時間は15秒を超えることはできません。
