このノードは、MiniMax H3 モデルを使用してビデオを生成し、参照画像・ビデオ・オーディオを使用して結果を条件付けます。参照素材は、プロンプト内で接続順に「Image 1」「Image 2」「Video 1」「Audio 1」のように参照されます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | ビデオ生成に使用するモデル（デフォルト: "MiniMax H3"）。「MiniMax H3」を選択すると、以下の `prompt`、`resolution`、`ratio`、`duration`、`reference_images`、`reference_videos`、`reference_audios` 設定が提供されます。 | DYNAMIC_COMBO | 必須 | "MiniMax H3" |
| `シード` | 乱数シード。同じシードで同じリクエストを行うと、類似した結果が得られますが、同一の結果が保証されるわけではありません（デフォルト: 42）。 | INT | 必須 | 0 ～ 4294967295 |
| `ウォーターマーク` | ビデオにAIGC透かしを追加するかどうか（デフォルト: false）。 | BOOLEAN | 任意 | true<br />false |

### MiniMax H3 入力

これらの入力は、モデルとして「MiniMax H3」を選択した場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | ビデオ生成のためのテキストプロンプト。参照メディアは、その順序で「Image 1」「Image 2」「Video 1」「Audio 1」のように参照できます。 | STRING | 必須 | Min length: 1 character |
| `resolution` | 出力ビデオの解像度（デフォルト: "768P"）。 | STRING | 必須 | "768P"<br />"2K" |
| `ratio` | 出力ビデオのアスペクト比（デフォルト: "adaptive"）。 | STRING | 必須 | "adaptive"<br />"16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 出力ビデオの長さ（秒）（デフォルト: 5）。 | INT | 必須 | 4 ～ 15 |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 拡張可能スロット: 1..9 個のアイテム（`image_1`...`image_9`）を接続します。被写体またはスタイルの参照画像です。接続順に「Image 1」..「Image 9」としてプロンプト内で参照されます。最大9枚まで。 | IMAGE | 任意 | 0 〜 9 images |
| `reference_videos` | 拡張可能スロット: 1..3 個のアイテム（`video_1`...`video_3`）を接続します。動きやシーンの参照ビデオです。接続順に「Video 1」..「Video 3」としてプロンプト内で参照されます。最大3本まで。各2〜15秒、合計15秒以内。 | VIDEO | 任意 | 0 〜 3 videos |
| `reference_audios` | 拡張可能スロット: 1..3 個のアイテム（`audio_1`...`audio_3`）を接続します。オーディオ参照です。接続順に「Audio 1」..「Audio 3」としてプロンプト内で参照されます。最大3クリップまで。各2〜15秒、合計15秒以内。参照画像またはビデオなしでは使用できません。 | AUDIO | 任意 | 0 〜 3 clips |

### パラメータの制約

- 参照画像または参照ビデオが少なくとも1つ必要です。参照オーディオのみでは受け付けられません。
- 各参照画像のアスペクト比は、およそ0.4〜2.5（2:5〜5:2）の範囲内である必要があります。また、幅と高さは最低256ピクセルが必要です。
- 各参照ビデオの長さは2〜15秒、フレームレートは23.976〜60 FPSの範囲内である必要があります。すべての参照ビデオの合計時間は15秒を超えることはできません。
- 各参照オーディオクリップの長さは2〜15秒である必要があります。すべての参照オーディオクリップの合計時間は15秒を超えることはできません。
