MiniMax H3 Reference to Video ノードは、MiniMax H3 の参照動画生成に必要なテキストconditioningと、空のaudio-video latentを作成します。プロンプトに加えて、オプションの参照画像、参照動画、参照オーディオクリップを指定すると、ノードはこれらの参照を、モデルが生成中に使用できるトークンにエンコードします。プロンプトは `<Picture i>`、`<Video k>`、`<Audio j>` タグで参照を指定します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `clip` | プロンプトをトークン化し、参照メディアをconditioningトークンにエンコードするために使用するCLIPモデルです。 | CLIP | はい | |
| `vae` | 参照画像と参照動画のフレームを潜在空間にエンコードするために使用するVAEです。 | VAE | はい | |
| `audio_vae` | 参照オーディオを潜在空間にエンコードするために使用するVAEです。オーディオは、オーディオVAEのサンプルレート（デフォルトでは32kHz）にリサンプリングされます。 | VAE | はい | |
| `プロンプト` | 動画用のテキストプロンプトです。参照メディアは `<Picture i>`、`<Video k>`、`<Audio j>` タグで指定できます（各タイプごとに1始まり）。複数行プロンプトと動的プロンプトに対応しています。 | STRING | はい | |
| `幅` | 生成される動画の幅（ピクセル単位、デフォルト: 1344）です。 | INT | はい | 32〜16384 (step 32) |
| `高さ` | 生成される動画の高さ（ピクセル単位、デフォルト: 768）です。 | INT | はい | 32〜16384 (step 32) |
| `長さ` | 24fpsでのフレーム数です。124で約5秒、学習済み範囲は約124〜362です（デフォルト: 124）。 | INT | はい | 5〜3600 (step 17) |
| `リファレンス画像サイズ` | 参照画像のサイズ指定です。`match` は、各参照画像をアスペクト比を保ったまま生成画像のピクセル面積に縮小のみ行います。`max` は参照パイプラインの2048px短辺を使用するため、アイデンティティの忠実度が最も高くなります。参照トークンはすべてのサンプリングステップで保持されるため、`max` は数倍遅くなる可能性があります（デフォルト: `match`）。 | COMBO | はい | `"match"`<br />`"max"` |
| `リファレンス画像` | 拡張可能スロット: 参照画像を1〜9枚接続します（`ref_image_1` ... `ref_image_9`）。各画像は、2048px短辺を超える場合は2048px短辺に縮小され、拡大されることはありません。 | IMAGE | いいえ | 0〜9 |
| `リファレンス動画` | 拡張可能スロット: 参照動画を1〜3本接続します（`ref_video_1` ... `ref_video_3`）。参照動画は24fps（2〜15秒）です。 | IMAGE | いいえ | 0〜3 |
| `リファレンス動画音声` | 拡張可能スロット: サウンドトラックを1〜3つ接続します（`ref_video_audio_1` ... `ref_video_audio_3`）。同じ番号の参照動画のサウンドトラックです。 | AUDIO | いいえ | 0〜3 |
| `リファレンス音声` | 拡張可能スロット: 単体の参照オーディオクリップを1〜3つ接続します（`ref_audio_1` ... `ref_audio_3`）。 | AUDIO | いいえ | 0〜3 |

注記：

- プロンプトでは、参照メディアをタイプごとに1始まりのタグで指定します。画像は `<Picture i>`、動画は `<Video k>`、オーディオは `<Audio j>` です。参照はモデルに固定の順序で渡されます。最初に画像、次に動画（各サウンドトラックの `<Audio j>` ラベルは対応する `<Video k>` の直前に置かれます）、最後に単体のオーディオです。
- 参照動画には少なくとも5フレーム（24fpsで約0.2秒）が含まれている必要があります。含まれていない場合、ノードはエラーを発生させます。また、動画フレームは選択した `length` を上限とし、サポートされているフレーム数に切り詰められます。
- 要求された `length` は、latentが作成される前に、サポートされているフレーム数に合わせて調整されます。

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `ポジティブ` | エンコードされたプロンプトと、エンコードされた参照画像・動画・オーディオのトークンを含むconditioningです。MiniMax H3モデルが使用します。 | CONDITIONING |
| `latent` | 要求された `width`、`height`、`length`（フレーム数）の空のaudio-video latentです。 | LATENT |
