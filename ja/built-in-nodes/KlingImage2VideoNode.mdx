Kling Image to Video ノードは、開始フレームとして参照画像を使用して短い動画を生成します。このノードは、画像をテキストプロンプトおよび生成設定と組み合わせ、結果の動画をそのIDと長さとともに返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | 動画生成に使用する参照画像です。画像は300x300ピクセル以上で、アスペクト比が1:2.5から2.5:1の間である必要があります。 | IMAGE | はい | - |
| `prompt` | ポジティブなテキストプロンプトです。空にすることはできません。最大500文字です。 | STRING | はい | - |
| `negative_prompt` | ネガティブなテキストプロンプトです。最大500文字です。使用しない場合は空のままにします。 | STRING | はい | - |
| `model_name` | 動画生成に使用するモデルです（デフォルト: `"kling-v2-5-turbo"`）。 | COMBO | はい | `"kling-v2-5-turbo"` |
| `cfg_scale` | プロンプトにどれだけ忠実に動画を生成するかを制御します。値が大きいほど忠実度が高くなります（デフォルト: 0.8）。 | FLOAT | はい | 0.0〜1.0 |
| `mode` | 生成モードです（デフォルト: `"pro"`）。 | COMBO | はい | `"pro"` |
| `aspect_ratio` | 生成される動画のアスペクト比です（デフォルト: `"16:9"`）。 | COMBO | はい | `"16:9"`<br />`"9:16"`<br />`"1:1"` |
| `duration` | 生成される動画の長さ（秒）です（デフォルト: `"5"`）。 | COMBO | はい | `"5"`<br />`"10"` |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された動画出力です。 | VIDEO |
| `video_id` | 生成された動画の一意の識別子です。 | STRING |
| `duration` | 生成された動画の長さ情報です。 | STRING |
