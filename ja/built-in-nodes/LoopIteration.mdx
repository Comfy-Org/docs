このノードは、ループ形式のワークフロー向けにイテレーションのメタデータを提供します。リストベースの入力を受け取り、各リストの最初の要素をそのまま渡します。これにより、ループは現在のインデックス、最初または最後のステップかどうか、現在のリスト項目、および実行中のイテレーション値を追跡できます。キャッシュ動作は `reuse_cache` フラグで制御されます。このノードは開発者専用としてマークされています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `iteration_index` | 現在のイテレーションのインデックス。リストとして提供されます。最初の要素が出力にそのまま渡されます。 | INT | はい | - |
| `is_first` | 現在のイテレーションが最初のものかどうかを示します。リストとして提供されます。最初の要素が出力にそのまま渡されます。 | BOOLEAN | はい | - |
| `is_last` | 現在のイテレーションが最後のものかどうかを示します。リストとして提供されます。最初の要素が出力にそのまま渡されます。 | BOOLEAN | はい | - |
| `list_item` | このイテレーションでリストから取得された項目。任意です。指定された場合は最初の要素が出力にそのまま渡され、それ以外の場合は None が返されます。 | ANY | いいえ | - |
| `current_iteration_value` | 現在のイテレーションで保持されている値。任意です。指定された場合は値全体が出力にそのまま渡され、それ以外の場合は None が返されます。 | ANY | いいえ | - |
| `reuse_cache` | 結果をキャッシュから再利用できるかどうかを制御します。有効にすると、ノードは安定したフィンガープリントを保持するため、キャッシュされた結果を再利用できます。無効にすると、一致しないフィンガープリントが生成され、各イテレーションでノードが再実行されます。 | BOOLEAN | はい | - |

注: このノードはリスト入力が有効です。つまり、各入力はリストとして渡されることを想定しており、ノードは各リストの最初の要素のみを出力します（`current_iteration_value` を除きます。これはリストとしてそのまま渡されます）。また、ここに記載されている以外の追加入力も受け付けます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-----------|-----------|
| `iteration_index` | 現在のイテレーションのインデックス。 | INT |
| `is_first` | 現在のイテレーションが最初のものかどうか。 | BOOLEAN |
| `is_last` | 現在のイテレーションが最後のものかどうか。 | BOOLEAN |
| `list_item` | このイテレーションでリストから取得された項目。項目が指定されなかった場合は None。 | ANY |
| `current_iteration_value` | 現在のイテレーションで保持されている値。値が指定されなかった場合は None。この出力はリストとして返されます。 | ANY |
