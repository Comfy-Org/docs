メッシュの UV レイアウトを画像としてレンダリングします。接続された各 UV 領域（チャート）はそれぞれ異なる色で塗りつぶされ、チャートの境界エッジは暗い灰色の背景に黒で輪郭が描かれます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|------|--------|------|------|
| `メッシュ` | UV レイアウトをレンダリングする 3D メッシュ。メッシュには UV 座標が必要です。そうでない場合、ノードはエラー「mesh has no UVs to render. Run UnwrapMesh first.」を発生させます。 | MESH | はい | - |
| `解像度` | レンダリングされる正方形画像の幅と高さ（ピクセル単位、デフォルト: 1024）。 | INT | はい | 64～4096（ステップ64） |

注: メッシュにバッチ次元（3D UV またはフェイス配列）が含まれる場合、バッチ内の最初の項目のみがレンダリングされます。

## 出力

| 出力名 | 説明 | データ型 |
|--------|------|----------|
| `image` | レンダリングされた UV アトラス画像。単一画像のバッチとして返されます。各 UV チャートは色分けされ、チャートの境界エッジは黒で輪郭表示されます。 | IMAGE |
