メッシュのUVレイアウトを画像としてレンダリングします。それぞれの接続されたUV領域（チャート）は異なる色で塗りつぶされ、チャートの境界線は暗灰色の背景上に黒で描画されます。

## 入力

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `メッシュ` | UVレイアウトをレンダリングする3Dメッシュ。メッシュにはUV座標が必須です。ない場合はエラーが発生します。 | MESH | はい | - |
| `解像度` | レンダリング画像の幅と高さ（ピクセル単位、デフォルト：1024）。 | INT | はい | 64〜4096 (step 64) |

注：メッシュにUV座標がない場合、ノードはエラー「mesh has no UVs to render. Run UnwrapMesh first.」を発生させます。メッシュにバッチ次元（3D UVまたは面配列）が含まれる場合、バッチ内の最初の項目のみがレンダリングされます。

## 出力

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `画像` | レンダリングされたUVアトラス画像。各チャートが色付けされ、チャート境界のエッジが黒で描画されます。 | IMAGE |
