このノードは、指定された開始フレームと終了フレームの間を補間し、テキストプロンプトに従って動画を生成します。Vidu Q3 モデルを使用して、2つの画像間のシームレスな遷移を作成し、指定した長さと解像度の動画を生成します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 動画生成に使用するモデル。オプションを選択すると、`resolution`、`duration`、`audio` の追加設定パラメータが表示されます。 | DYNAMIC_COMBO | 必須 | `"viduq3-pro"`<br />`"viduq3-turbo"` |
| `開始フレーム` | 動画シーケンスの開始画像。 | IMAGE | 必須 | - |
| `終了フレーム` | 動画シーケンスの終了画像。 | IMAGE | 必須 | - |
| `プロンプト` | プロンプトの説明（最大2000文字）。 | STRING | 必須 | - |
| `シード` | 生成のランダム性を制御するシード値（デフォルト: 1）。 | INT | 必須 | 0 から 2147483647 |

### viduq3-pro および viduq3-turbo 入力

以下のパラメータは、両方のモデルオプション（`viduq3-pro` と `viduq3-turbo`）で共通です。これらはモデルを選択した後に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 出力動画の解像度。このパラメータは `model` を選択した後に表示されます。 | COMBO | 必須 | `"720p"`<br />`"1080p"` |
| `duration` | 出力動画の長さ（秒）（デフォルト: 5）。このパラメータは `model` を選択した後に表示されます。 | INT | 必須 | 1 から 16 |
| `audio` | 有効にすると、音声付きの動画（会話や効果音を含む）を出力します（デフォルト: False）。このパラメータは `model` を選択した後に表示されます。 | BOOLEAN | 必須 | `True`<br />`False` |

**注:** `first_frame` と `end_frame` の画像のアスペクト比は類似している必要があります。2つの画像のアスペクト比は、互いの80%から125%以内（相対的な近さが0.8から1.25）である必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | 生成された動画ファイル。 | VIDEO |
