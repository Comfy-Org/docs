このノードは、Bria RMBG 2.0 サービスを使用して画像から背景を削除します。画像を外部 API に送信して処理し、背景が削除された結果を返します。

## 入力

`moderation` セレクターを `"true"` に設定すると、追加のモデレーションオプションが表示されます。

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | 背景を削除する入力画像です。 | IMAGE | はい | - |
| `モデレーション` | モデレーション設定です。`"true"` に設定すると、追加のモデレーションオプションが利用可能になります。 | DYNAMIC_COMBO | はい | `"false"`<br />`"true"` |
| `シード` | シードは、ノードを再実行するかどうかを制御します。結果はシードに関係なく非決定的です。デフォルト: `0`。 | INT | はい | 0 〜 2147483647 |

### Moderation が「true」の場合の入力

これらのパラメータは、`moderation` が `"true"` に設定されている場合にのみ表示されます。`"false"` オプションでは追加の入力はありません。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | 入力画像に対する視覚コンテンツモデレーションを有効にします。デフォルト: `False`。 | BOOLEAN | いいえ | - |
| `visual_output_moderation` | 出力画像に対する視覚コンテンツモデレーションを有効にします。デフォルト: `True`。 | BOOLEAN | いいえ | - |

**注:** `visual_input_moderation` および `visual_output_moderation` パラメータは、`moderation` パラメータに依存します。これらは `moderation` が `"true"` に設定されている場合にのみ有効になります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 背景が削除された処理済み画像です。 | IMAGE |
