TextEncodeQwenImage21 ノードは、Qwen-Image 2.1 モデル用のプロンプトとネガティブプロンプトをエンコードし、必要に応じて参照画像を添付します。参照画像はテキストエンコーダーによって参照され、VAE が接続されている場合は潜在表現としてもエンコードされてシーケンスに結合されます。そのため、コンディショニングはテキスト指示と視覚的参照の両方を保持します。このノードは、ポジティブコンディショニングとネガティブコンディショニング、および最初の参照画像に合わせたサイズの空の潜在表現を返し、サンプリング可能な状態にします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `clip` | プロンプトをトークン化およびエンコードするために使用される Qwen-Image 2.1 テキストエンコーダー。 | CLIP | はい | - |
| `prompt` | 生成する画像または適用する編集を記述するテキストプロンプト。複数行入力と動的プロンプトをサポートします。 | STRING | はい | 任意のテキスト |
| `negative_prompt` | 結果で避けるべき内容を記述するテキストプロンプト。複数行入力と動的プロンプトをサポートします。 | STRING | はい | 任意のテキスト |
| `vae` | 参照画像を参照潜在表現にエンコードするために使用される VAE。省略した場合、参照画像はテキストエンコーダーのみを通じて結果を条件付けます。 | VAE | いいえ | - |
| `resolution` | 参照画像は、アスペクト比を維持しながら、32 の倍数で約 `resolution` x `resolution` ピクセルにリサイズされます。0 を指定すると、各参照画像は自身のサイズのまま（32 の倍数に丸められます）に保たれます（デフォルト：1024）。 | INT | はい | 0～4096（ステップ32） |
| `images` | テキストエンコーダーによって参照され、VAE 潜在表現としてシーケンスに結合される参照画像。拡張可能なスロット：最大 16 枚の画像を接続できます（`image_1` ... `image_16`）。 | IMAGE | いいえ | 0～16 枚の画像 |

空の潜在表現出力は、最初に接続された参照画像のサイズ、または参照画像が接続されていない場合は `resolution` のサイズに合わせられます。このノードが返す潜在表現でサンプリングしてください。それ以外のサイズでは編集がずれます。VAE が接続されている場合、同じ参照潜在表現がポジティブコンディショニングとネガティブコンディショニングの両方に付加されるため、1 回のサンプラーステップで両方をデノイズできます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | プロンプトのエンコード済みコンディショニング。VAE が接続されている場合は参照潜在表現を保持します。 | CONDITIONING |
| `negative` | ネガティブプロンプトのエンコード済みコンディショニング。同じ参照潜在表現を持ちます。 | CONDITIONING |
| `latent` | 最初の参照画像のサイズの空の潜在表現。参照画像が接続されていない場合は 1024 x 1024 になります。 | LATENT |
