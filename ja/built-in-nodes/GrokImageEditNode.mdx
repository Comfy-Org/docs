Grok Image Edit ノードは、テキストプロンプトに基づいて既存の画像を編集します。Grok API を使用して、入力画像のバリエーションとなる新しい画像を1枚以上生成し、指定された説明に従って編集します。このノードは非推奨としてマークされています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 画像編集に使用する特定のAIモデル。 | COMBO | はい | `"grok-imagine-image-quality"`<br />`"grok-imagine-image-pro"`<br />`"grok-imagine-image"` |
| `image` | 編集する入力画像。 | IMAGE | はい |  |
| `プロンプト` | 画像を生成するために使用するテキストプロンプト。複数行テキスト。空白以外の文字を少なくとも1文字含む必要があります。 | STRING | はい |  |
| `解像度` | 出力画像の解像度。 | COMBO | はい | `"1K"`<br />`"2K"` |
| `生成画像数` | 生成する編集済み画像の数（デフォルト: 1）。 | INT | はい | 1 から 10 |
| `シード値` | ノードを再実行するかどうかを決定するシード。実際の結果はシードに関係なく非決定的です（デフォルト: 0）。 | INT | はい | 0 から 2147483647 |
| `アスペクト比` | 出力画像のアスペクト比。`image` 入力に複数の画像が接続されている場合のみ設定できます（デフォルト: `"auto"`）。 | COMBO | いいえ | `"auto"`<br />`"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"9:16"`<br />`"16:9"`<br />`"9:19.5"`<br />`"19.5:9"`<br />`"9:20"`<br />`"20:9"`<br />`"1:2"`<br />`"2:1"` |

**重要な制約事項：**
- `image` 入力は最大3画像までサポートします。ただし、`grok-imagine-image-pro` モデルを使用する場合、入力画像は1枚のみサポートされます。
- `aspect_ratio` パラメータは、`image` 入力に複数の画像が接続されている場合にのみ、カスタム値（`"auto"` 以外）を設定できます。単一の入力画像でカスタムのアスペクト比を設定すると、エラーが発生します。
- `prompt` には、空白以外の文字が少なくとも1文字含まれている必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | ノードによって生成された編集済み画像。複数の画像が生成された場合、それらの画像は単一のバッチに連結されます。 | IMAGE |
