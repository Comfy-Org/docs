Grok Image Edit ノードは、テキストプロンプトに基づいて既存の画像を変更します。入力画像と説明を Grok API に送信し、プロンプトに従って新しく生成された1つ以上の画像を返します。このノードは非推奨としてマークされています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 画像編集に使用する特定の AI モデル。 | COMBO | はい | `"grok-imagine-image-quality"`<br />`"grok-imagine-image-pro"`<br />`"grok-imagine-image"` |
| `image` | 編集する入力画像。 | IMAGE | はい |  |
| `プロンプト` | 画像を生成するために使用するテキストプロンプト。複数行テキスト。少なくとも1つの空白以外の文字を含む必要があります。 | STRING | はい |  |
| `解像度` | 出力画像の解像度。 | COMBO | はい | `"1K"`<br />`"2K"` |
| `生成画像数` | 生成する編集済み画像の数（デフォルト: 1）。 | INT | はい | 1 〜 10 |
| `シード値` | ノードを再実行するかどうかを決定するためのシードです。シードに関係なく、実際の結果は非決定的です（デフォルト: 0）。 | INT | はい | 0 〜 2147483647 |
| `アスペクト比` | 出力画像のアスペクト比。複数の画像が `image` 入力に接続されている場合にのみ許可されます（デフォルト: "auto"）。 | COMBO | いいえ | `"auto"`<br />`"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"9:16"`<br />`"16:9"`<br />`"9:19.5"`<br />`"19.5:9"`<br />`"9:20"`<br />`"20:9"`<br />`"1:2"`<br />`"2:1"` |

**重要な制約:**
- `image` 入力は最大3枚の画像をサポートしますが、`grok-imagine-image-pro` モデルを使用する場合は例外で、入力画像は1枚のみをサポートします。
- `aspect_ratio` パラメータは、複数の画像が `image` 入力に接続されている場合にのみ、カスタム値（"auto" 以外）に設定できます。単一の入力画像でカスタムアスペクト比を設定すると、エラーが発生します。
- `prompt` は少なくとも1つの空白以外の文字を含む必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | ノードによって生成された編集済み画像。複数の画像が生成された場合、画像は単一のバッチに連結されます。 | IMAGE |
