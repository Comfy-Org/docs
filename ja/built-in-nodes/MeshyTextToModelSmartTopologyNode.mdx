このノードは、Meshy T2.5 を使用して、目標の面数でゲームで使用可能な三角形メッシュを生成します。トポロジーは、生成後に間引くのではなく、指定されたポリゴン数で構築されるため、別途リトポロジ処理を行わなくてもゲームエンジンで使用できる結果が得られます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 生成に使用する Meshy モデルバージョン。 | COMBO | はい | `"meshy-t2.5"` |
| `prompt` | 生成する 3D モデルのテキスト説明。 | STRING | はい | 1 〜 800 文字 |
| `target_polycount` | 生成されるメッシュ内の三角形の概算数。デフォルト: 15000。 | INT | はい | 100 〜 30000 |
| `pose_mode` | 生成されるキャラクターのポーズ。空文字列を指定すると、特定のポーズを要求しません。これは高度な設定です。デフォルト: `""`（空文字列）。 | COMBO | はい | `""`<br />`"A-pose"`<br />`"T-pose"` |
| `seed` | `seed` はノードを再実行するかどうかを制御します。シードに関係なく、結果は非決定的です。デフォルト: 42。 | INT | はい | 0 〜 2147483647 |

**制約事項:**

* `prompt` は 1～800 文字である必要があります。
* `target_polycount` は、メッシュの構築に使用される三角形の数であり、生成後に適用される上限ではありません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `meshy_task_id` | Meshy API タスクの一意の識別子。 | MESHY_TASK_ID |
| `GLB` | GLB 形式の生成された 3D モデル。 | FILE3DGLB |
| `FBX` | FBX 形式の生成された 3D モデル。 | FILE3DFBX |
