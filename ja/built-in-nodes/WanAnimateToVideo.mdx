WanAnimateToVideo は、参照画像、ポーズ、顔、背景、前のチャンクからのオプションのモーションなどの入力を使用して、Wan でアニメーションビデオを生成するためのコンディショニングデータと初期潜在テンソルを準備します。また、`video_frame_offset` 値を読み取って更新することで、ビデオをチャンク単位で長く生成することもできます。このノードは実験的としてマークされています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ポジティブ` | 生成を望ましいコンテンツへ導くためのポジティブコンディショニング。 | CONDITIONING | 必須 | - |
| `ネガティブ` | 生成を望ましくないコンテンツから遠ざけるためのネガティブコンディショニング。 | CONDITIONING | 必須 | - |
| `vae` | 画像およびビデオ入力を潜在空間にエンコードするために使用される VAE モデル。 | VAE | 必須 | - |
| `幅` | 生成されるビデオの幅（ピクセル単位）（デフォルト: 832、ステップ: 16）。 | INT | 必須 | 16 to MAX_RESOLUTION |
| `高さ` | 生成されるビデオの高さ（ピクセル単位）（デフォルト: 480、ステップ: 16）。 | INT | 必須 | 16 to MAX_RESOLUTION |
| `長さ` | 生成するフレーム数（デフォルト: 77、ステップ: 4）。 | INT | 必須 | 1 to MAX_RESOLUTION |
| `バッチサイズ` | 1 回のバッチで生成するビデオの数（デフォルト: 1）。 | INT | 必須 | 1〜4096 |
| `クリップビジョン出力` | ポジティブおよびネガティブコンディショニングの両方に追加されるオプションの CLIP ビジョン出力。 | CLIP_VISION_OUTPUT | 任意 | - |
| `参照画像` | 生成されるビデオの外観の開始点として使用される参照画像。指定されない場合は、黒画像が使用されます。 | IMAGE | 任意 | - |
| `顔動画` | 表情のガイドを提供するビデオ入力。内部的に 512x512 にリサイズされ、-1.0 から 1.0 の範囲にスケーリングされます。 | IMAGE | 任意 | - |
| `ポーズ動画` | ポーズとモーションのガイドを提供するビデオ入力。 | IMAGE | 任意 | - |
| `継続モーション最大フレーム数` | 前のモーションシーケンスから引き継がれるフレームの最大数（デフォルト: 5、ステップ: 4）。 | INT | 必須 | 1 to MAX_RESOLUTION |
| `背景動画` | フレーム内のキャラクター以外の部分を埋めるために使用される背景ビデオ。 | IMAGE | 任意 | - |
| `キャラクターマスク` | キャラクター領域を定義するマスク。キャラクターを背景から分離するために使用されます。 | MASK | 任意 | - |
| `継続モーション` | 以前に生成されたチャンクとの時間的一貫性を保つために、続きから使用する前のモーションフレーム。 | IMAGE | 任意 | - |
| `動画フレームオフセット` | すべての入力ビデオでシークするフレーム数。チャンク単位でより長いビデオを生成するために使用されます。ビデオを延長するには、前のノードの `video_frame_offset` 出力に接続します。（デフォルト: 0、ステップ: 1） | INT | 必須 | 0 to MAX_RESOLUTION |

**パラメータの制約:**

- `continue_motion` が指定された場合、その最後の `continue_motion_max_frames` フレームのみが使用されます。
- 入力ビデオ（`face_video`、`pose_video`、`background_video`、`character_mask`）は、使用前に `video_frame_offset` の分だけオフセットされます。オフセットが入力のフレーム数以上の場合、その入力は無視されます。ただし、単一フレームの `character_mask` は例外です。
- `character_mask` が1フレームしかない場合、そのフレームは出力のすべてのフレームに対して繰り返されます。
- `pose_video` が `length` より短い場合、残りのフレームを埋めるために最後のフレームが繰り返されます。出力の長さは変更されません。
- `clip_vision_output` が指定された場合、ポジティブコンディショニングとネガティブコンディショニングの両方に追加されます。
- `reference_image` が指定されない場合、黒画像（すべてゼロ値）がデフォルトの参照として使用されます。
- `continue_motion` が指定されない場合、初期モーションフレームは一定のグレー（強度0.5）のフレームで埋められます。
- `continue_motion` を使用する場合、次のチャンクのオフセットが計算される前に、`video_frame_offset` は引き継がれたフレーム数だけ減らされます。これにより、重複するフレームが2回処理されることはありません。
- `background_video` は、参照モーション部分の後のモーションフレームを埋めます。参照画像や引き継がれた `continue_motion` フレームを置き換えることはありません。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `ポジティブ` | CLIP ビジョン出力、ポーズビデオの潜在表現、顔ビデオのピクセル、連結された潜在画像、連結されたマスクなど、追加のビデオコンテキストを含む変更後のポジティブコンディショニング。 | CONDITIONING |
| `ネガティブ` | CLIP ビジョン出力、ポーズビデオの潜在表現、空白の顔ピクセル、連結された潜在画像、連結されたマスクなど、追加のビデオコンテキストを含む変更後のネガティブコンディショニング。 | CONDITIONING |
| `潜在変数` | 生成されるビデオの初期潜在テンソル（すべてゼロのサンプル）。形状は `[batch_size, 16, latent_length + trim_latent, latent_height, latent_width]`。 | LATENT |

| `トリム画像` | 先頭からトリミングする画像フレーム数。参照モーションフレームに対応します。 | INT |
| `動画フレームオフセット` | 入力オフセットと処理されたフレーム数に基づく、次のチャンクで使用する更新されたフレームオフセット。 | INT |
