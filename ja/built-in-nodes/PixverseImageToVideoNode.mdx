静止画像とテキストプロンプトから PixVerse を使用して動画を生成します。このノードは入力画像をアップロードし、選択された品質、長さ、モーション設定を適用して、生成完了後に結果の動画を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | 動画に変換する入力画像 | IMAGE | はい | - |
| `プロンプト` | 動画生成用のプロンプト（デフォルト：空文字列） | STRING | はい | - |
| `品質` | 動画品質設定（デフォルト：res_540p） | COMBO | はい | `res_540p`<br />`res_1080p` |
| `継続時間（秒）` | 生成される動画の長さ（秒） | COMBO | はい | `dur_2`<br />`dur_5`<br />`dur_10` |
| `モーションモード` | 動画生成に適用されるモーションスタイル | COMBO | はい | `normal`<br />`fast`<br />`slow`<br />`zoom_in`<br />`zoom_out`<br />`pan_left`<br />`pan_right`<br />`pan_up`<br />`pan_down`<br />`tilt_up`<br />`tilt_down`<br />`roll_clockwise`<br />`roll_counterclockwise` |
| `シード` | 動画生成用のシード（デフォルト：0） | INT | はい | 0-2147483647 |
| `ネガティブプロンプト` | 画像上で望ましくない要素を指定する任意のテキスト記述（デフォルト：空文字列） | STRING | いいえ | - |
| `PixVerseテンプレート` | PixVerse Template ノードで作成された、生成スタイルに影響を与える任意のテンプレート | CUSTOM | いいえ | - |

**注意：** 1080p 品質を使用する場合、モーションモードは自動的に normal に設定され、長さは5秒に制限されます。5秒以外の長さでは、モーションモードも自動的に normal に設定されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 入力画像とパラメータに基づいて生成された動画 | VIDEO |
