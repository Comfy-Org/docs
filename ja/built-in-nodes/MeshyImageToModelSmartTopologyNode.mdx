## 入力

このノードは、Meshy T2.5 を使用して、参照画像から目標フェイス数でゲームにそのまま使用できる三角形メッシュを生成します。トポロジーは要求されたポリゴン数で構築され、後からデシメーションされるわけではないため、別途リトポロジー処理を行わなくてもゲームエンジンで使用できる結果になります。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 生成に使用する Meshy モデルのバージョンです。 | COMBO | はい | `"meshy-t2.5"` |
| `image` | モデルの生成元となる参照画像です。 | IMAGE | はい | - |
| `target_polycount` | 生成されるメッシュ内の三角形の概算数です。デフォルト: 15000。 | INT | はい | 100 〜 30000 |
| `should_texture` | テクスチャを生成するかどうかを決定します。`"false"` はテクスチャ処理をスキップし、テクスチャなしのメッシュを返します。 | DYNAMIC_COMBO | はい | `"true"`<br />`"false"` |
| `enable_pbr` | ベースカラーに加えて PBR マップ（メタリック、ラフネス、ノーマル）を生成します。この入力は `should_texture` が `"true"` に設定されている場合にのみ使用できます。デフォルト: `False`。 | BOOLEAN | いいえ | - |
| `texture_prompt` | テクスチャ処理を導くためのテキストプロンプトです。最大 800 文字です。`texture_image` と同時に使用できません。この入力は `should_texture` が `"true"` に設定されている場合にのみ使用できます。デフォルト: `""`（空文字列）。 | STRING | いいえ | 1 〜 800 文字 |
| `texture_image` | テクスチャ処理用の参照画像です。`texture_image` または `texture_prompt` のいずれか一方のみを同時に使用できます。この入力は `should_texture` が `"true"` に設定されている場合にのみ使用できます。 | IMAGE | いいえ | - |
| `texture_resolution` | テクスチャ解像度です。解像度が高いほど、より多くの表面ディテールを捉えます。この入力は `should_texture` が `"true"` に設定されている場合にのみ使用できます。 | COMBO | いいえ | `"2k"`<br />`"4k"`<br />`"8k"` |
| `pose_mode` | 生成されるキャラクターのポーズです。空文字列は特定のポーズを要求しないことを示します。これは詳細設定です。デフォルト: `""`（空文字列）。 | COMBO | はい | `""`<br />`"A-pose"`<br />`"T-pose"` |
| `seed` | シードはノードを再実行するかどうかを制御します。シードに関係なく結果は非決定的です。デフォルト: 42。 | INT | はい | 0 〜 2147483647 |

**注:** `enable_pbr`、`texture_prompt`、`texture_image`、`texture_resolution` の入力は、`should_texture` が `"true"` に設定されている場合にのみ使用できます。

**制約:**

* `target_polycount` はメッシュの構築元となる三角形の数であり、生成後に適用される制限ではありません。
* `should_texture` が `"true"` に設定されている場合、`texture_prompt` と `texture_image` を同時に使用できません。両方が指定された場合、ノードはエラーを発生させます。
* `texture_prompt` の最大長は 800 文字です。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `meshy_task_id` | Meshy API タスクの一意の識別子です。 | MESHY_TASK_ID |
| `GLB` | GLB 形式で生成された 3D モデルです。 | FILE3DGLB |
| `FBX` | FBX 形式で生成された 3D モデルです。 | FILE3DFBX |
