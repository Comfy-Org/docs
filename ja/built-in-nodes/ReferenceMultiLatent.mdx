このノードは、1つ以上の参照画像をエンコードし、その潜在変数を編集モデルが使用するコンディショニングに追加します。これは Set Reference Latent の複数画像版であり、VAE といくつかの参照画像を接続すると、ノードはエンコードされたすべての潜在変数をポジティブ コンディショニングに追加し、ネガティブ コンディショニングが接続されている場合はそちらにも追加します。モデルが単一の潜在変数ではなく複数の参照画像を一度に要求する場合に使用します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `positive` | 参照潜在変数で変更するポジティブ コンディショニング。 | CONDITIONING | はい | - |
| `negative` | 同じ参照潜在変数を受け取るオプションのネガティブ コンディショニング。接続しないままにすると、`negative` 出力で変更済みのポジティブ コンディショニングを再利用します。 | CONDITIONING | いいえ | - |
| `vae` | 接続された参照画像をエンコードするために使用する VAE。VAE が接続されていない場合、参照画像は無視されます。 | VAE | いいえ | - |
| `resolution` | 各参照画像をエンコード前にどのように準備するか。`"keep resolution"` は受信時のサイズでエンコードします。`"resize"` はアスペクト比を維持しながら目標のメガピクセル数に拡大縮小し、`megapixels` を表示します。（デフォルト: "keep resolution"） | DYNAMIC_COMBO | はい | `"keep resolution"`<br />`"resize"` |
| `images` | 追加可能なスロット: 参照として使用する 1 つ以上の参照画像（`image_1`、`image_2`、...）を接続します。画像はスロット順にエンコードされ、その順序でコンディショニングに追加されます。 | IMAGE | いいえ | 1～100 |

### リサイズ入力

これらのオプションは、`resolution` が `"resize"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `megapixels` | アスペクト比を維持した各参照画像の目標サイズ。1.0 は約 1024 x 1024 ピクセルです。（デフォルト: 1.0） | FLOAT | はい | 0.01～16.0 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | エンコードされた参照潜在変数が追加されたポジティブ コンディショニング。 | CONDITIONING |
| `negative` | 同じ参照潜在変数が追加されたネガティブ コンディショニング。ネガティブ コンディショニングが接続されていない場合は、`positive` 出力を返します。 | CONDITIONING |
| `empty_latent` | 最初の参照潜在変数に 0.0 を乗算したもので、サンプラーをシードする準備が整っています。参照潜在変数が生成されない場合は、選択した解像度の正方形の空の潜在変数が返されます。 | LATENT |

## 注記

- 潜在変数は置き換えられるのではなく追加されるため、複数の Set Reference Multi Latent ノードを連結すると参照が蓄積されます。
- 接続された各画像は個別にエンコードされるため、参照画像のサイズを揃える必要はありません。
- VAE が接続されていない場合、または画像が接続されていない場合、`positive` と `negative` は変更されずに返され、`empty_latent` は正方形の空の潜在変数になります。1024 x 1024、または `resolution` が `"resize"` のときは `megapixels` から算出したサイズです。
