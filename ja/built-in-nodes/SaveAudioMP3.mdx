SaveAudioMP3 ノードは、音声データを MP3 ファイルとして保存します。音声入力を受け取り、カスタマイズ可能なファイル名と品質設定を使用して出力ディレクトリにエクスポートし、ファイル名の処理と MP3 形式への変換を自動的に行います。**このノードは非推奨であり、将来のバージョンで削除される可能性があります。**

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `audio` | MP3 ファイルとして保存する音声データ | AUDIO | はい | - |
| `filename_prefix` | 出力ファイル名のプレフィックス（デフォルト: "audio/ComfyUI"） | STRING | いいえ | - |
| `quality` | MP3 ファイルの音声品質設定（デフォルト: "V0"） | COMBO | いいえ | `"V0"`<br />`"128k"`<br />`"320k"` |
| `prompt` | 内部プロンプトデータ。システムによって自動的に提供されます | PROMPT | いいえ | - |
| `extra_pnginfo` | 追加の PNG 情報。システムによって自動的に提供されます | EXTRA_PNGINFO | いいえ | - |

**注意:** 入力 `audio` が None の場合（たとえば、ソース動画に音声トラックがない場合など）、このノードは ValueError を発生させます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `audio` | MP3 ファイルに保存された音声データ | AUDIO |
