SaveAudioMP3 ノードは、オーディオデータをMP3ファイルとして保存します。オーディオ入力を受け取り、カスタマイズ可能なファイル名と品質設定を使用して出力ディレクトリにエクスポートし、ファイル名の処理とMP3形式の変換を自動的に行います。**このノードは非推奨であり、将来のバージョンで削除される可能性があります。**

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `audio` | MP3ファイルとして保存されるオーディオデータ | AUDIO | はい | - |
| `filename_prefix` | 出力ファイル名のプレフィックス（デフォルト: "audio/ComfyUI"） | STRING | いいえ | - |
| `quality` | MP3ファイルのオーディオ品質設定（デフォルト: "V0"） | COMBO | いいえ | `"V0"`<br />`"128k"`<br />`"320k"` |
| `prompt` | 内部プロンプトデータ。システムによって自動的に提供されます | PROMPT | いいえ | - |
| `extra_pnginfo` | 追加のPNG情報。システムによって自動的に提供されます | EXTRA_PNGINFO | いいえ | - |

**注：** 入力 `audio` が None の場合（例えば、ソースビデオにオーディオトラックがない場合）、ノードは ValueError を発生させます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `audio` | MP3ファイルに保存されたオーディオデータ | AUDIO |
