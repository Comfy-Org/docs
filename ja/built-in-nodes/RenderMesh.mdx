このノードは、単一ビューをレイキャストして 3D メッシュを 2D 画像にレンダリングします。テクスチャ付きメッシュ、頂点カラー、ソリッドシェーディングされたサーフェス、サーフェス法線、または深度を出力できます。カメラとオプションのモデル変換は Load3D / Preview3D ビューアーから取得できます。カメラが接続されていない場合は、デフォルトの正面ビューが自動でフレーミングされます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `メッシュ` | レンダリングする 3D メッシュ。 | MESH | はい | — |
| `モード` | レンダリングする内容。auto: テクスチャがある場合はテクスチャ、なければ頂点カラー、それもなければシェーディングされたクレイ。(デフォルト: "auto") | COMBO | はい | `"auto"`<br />`"texture"`<br />`"vertex colors"`<br />`"solid"`<br />`"normal"`<br />`"depth"` |
| `幅` | レンダリングされる画像の幅（ピクセル単位）。(デフォルト: 1024) | INT | はい | 64～4096（ステップ8） |
| `高さ` | レンダリングされる画像の高さ（ピクセル単位）。(デフォルト: 1024) | INT | はい | 64～4096（ステップ8） |
| `背景` | メッシュで覆われていないピクセルに使用する背景色。(デフォルト: "#000000") | COLOR | はい | — |
| `model_3d_info` | 同じ Load3D / Preview3D ビューアーからのモデル変換。ビューアーのフレーミングに合わせるには `camera_info` と一緒に接続します。 | LOAD3D_MODEL_INFO | いいえ | — |
| `camera_info` | Load3D / Preview3D ビューアーまたは Create Camera Info ノードからのカメラ。接続されていない場合は、デフォルトの正面ビューが自動でフレーミングされます。 | LOAD3D_CAMERA | いいえ | — |

注意: バッチ化されたメッシュの最初の項目のみがレンダリングされます。メッシュバッチに複数の項目が含まれる場合、ノードは警告をログに記録し、最初の項目を使用します。`texture` モードではメッシュにテクスチャと UV の両方が必要で、`vertex colors` モードでは頂点カラーが必要です。選択したモードのデータが利用できない場合、ノードはソリッドシェーディングレンダーにフォールバックします。`normal` モードでは、存在する場合はメッシュのスムーズ頂点法線を使用し、そうでない場合は面ごとの法線を使用します。`depth` モードでは、近いサーフェスほど明るく表示され（near = white）、メッシュで覆われていないピクセルは黒のままです。`model_3d_info` と `camera_info` は、レンダーをビューアーのフレーミングに一致させるために、同じ Load3D / Preview3D ビューアーから一緒に接続することを意図しています。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | メッシュのレンダリング画像。 | IMAGE |
| `mask` | メッシュがレンダリングされた場所で 1.0、それ以外で 0.0 となるマスク。 | MASK |
