このノードは、MiniMax H3 モデルファミリー（MiniMax H3、MiniMax H3 Max、MiniMax H3 Max Turbo）を使用して、テキストプロンプトから動画を生成します。モデルを選択し、テキストプロンプトを入力して、解像度、アスペクト比、尺（長さ）などの設定を調整します。ノードは MiniMax API にリクエストを送信し、生成タスクの完了を待ってから、結果の動画を返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 動画生成に使用するモデル（デフォルト: "MiniMax H3"）。モデルを選択すると、後述のセクションに記載されているモデル固有の設定も表示されます。 | DYNAMIC_COMBO | はい | "MiniMax H3"<br />"MiniMax H3 Max"<br />"MiniMax H3 Max Turbo" |
| `シード` | 乱数シード。同じシードで同じリクエストを行うと、類似した結果が得られますが、同一の結果が保証されるわけではありません（デフォルト: 42）。 | INT | はい | 0〜4294967295 |
| `ウォーターマーク` | 動画に AIGC 透かしを追加するかどうか（デフォルト: false）。有効にすると、"MiniMax H3" モデルのみがサポートされます。 | BOOLEAN | いいえ | true<br />false |

### MiniMax H3 入力

これらの設定は、"MiniMax H3" モデルを選択したときに表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 動画生成用のテキストプロンプト。空白以外の文字を少なくとも1文字含む必要があります。 | STRING | はい | 任意のテキスト |
| `resolution` | 出力動画の解像度。 | COMBO | はい | "768P"<br />"2K" |
| `ratio` | 出力動画のアスペクト比（デフォルト: "16:9"）。 | COMBO | はい | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 出力動画の長さ（秒）。4〜15秒（デフォルト: 5）。 | INT | はい | 4〜15 |

### MiniMax H3 Max および MiniMax H3 Max Turbo 入力

これらの設定は、"MiniMax H3 Max" モデルと "MiniMax H3 Max Turbo" モデルで共有され、どちらかのモデルを選択したときに表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 動画生成用のテキストプロンプト。空白以外の文字を少なくとも1文字含む必要があり、最大50,000文字まで指定できます。 | STRING | はい | 最大50000文字 |
| `resolution` | 出力動画の解像度（デフォルト: "768P"）。 | COMBO | はい | "480P"<br />"768P" |
| `ratio` | 出力動画のアスペクト比（デフォルト: "16:9"）。 | COMBO | はい | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 出力動画の長さ（秒）。5〜15秒（デフォルト: 5）。 | INT | はい | 5〜15 |
| `prompt_expansion_mode` | 生成前にプロンプトの書き換えに費やす労力の度合い（デフォルト: "balanced"）。 | COMBO | はい | "balanced"<br />"quality" |

### 注記

- すべてのモデルで、プロンプトには空白以外の文字が少なくとも1文字含まれている必要があります。
- `watermark` 設定は "MiniMax H3" のみでサポートされています。"MiniMax H3 Max" または "MiniMax H3 Max Turbo" で有効にするとエラーが発生します。
- "MiniMax H3 Max" モデルと "MiniMax H3 Max Turbo" モデルでは、プロンプトが50,000文字に制限されています。
- 解像度と長さの制限は選択されたモデルによって異なります。"MiniMax H3" は "768P" と "2K" の解像度、および4〜15秒の動画をサポートします。一方、"MiniMax H3 Max" と "MiniMax H3 Max Turbo" は "480P" と "768P" の解像度、および5〜15秒の動画をサポートします。
- このノードに表示される推定料金は、選択したモデル、解像度、長さに基づいて計算されます。
