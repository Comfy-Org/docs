このノードは、MiniMax H3 ファミリーのモデル（MiniMax H3、MiniMax H3 Max、MiniMax H3 Max Turbo）を使用して、テキストプロンプトから動画を生成します。モデルを選択し、テキストプロンプトを入力して、解像度、アスペクト比、長さなどの設定を調整します。ノードはリクエストを MiniMax API に送信し、生成タスクが完了するまで待機して、生成された動画を返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 動画生成に使用するモデル（デフォルト: "MiniMax H3"）。モデルを選択すると、以下のセクションで説明するモデル固有の設定も表示されます。 | DYNAMIC_COMBO | はい | "MiniMax H3"<br />"MiniMax H3 Max"<br />"MiniMax H3 Max Turbo" |
| `シード` | ランダムシード。同じシードで同じリクエストを実行すると、類似しますが、同一であることは保証されない結果が得られます（デフォルト: 42）。 | INT | はい | 0～4294967295 |
| `ウォーターマーク` | 動画に AIGC ウォーターマークを追加するかどうか（デフォルト: false）。有効にした場合、"MiniMax H3" モデルのみがサポートされます。 | BOOLEAN | いいえ | true<br />false |

### MiniMax H3 入力

これらの設定は、"MiniMax H3" モデルが選択されたときに表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 動画生成用のテキストプロンプト。少なくとも1つの空白以外の文字を含める必要があります。 | STRING | はい | 任意のテキスト |
| `resolution` | 出力動画の解像度。 | COMBO | はい | "768P"<br />"2K" |
| `ratio` | 出力動画のアスペクト比（デフォルト: "16:9"）。 | COMBO | はい | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 出力動画の長さ（秒）（4～15）（デフォルト: 5）。 | INT | はい | 4～15 |

### MiniMax H3 Max および MiniMax H3 Max Turbo 入力

これらの設定は、"MiniMax H3 Max" と "MiniMax H3 Max Turbo" モデルで共有され、どちらかのモデルが選択されたときに表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 動画生成用のテキストプロンプト。少なくとも1つの空白以外の文字を含める必要があり、最大 50,000 文字まで指定できます。 | STRING | はい | 最大 50000 文字 |
| `resolution` | 出力動画の解像度（デフォルト: "768P"）。 | COMBO | はい | "480P"<br />"768P" |
| `ratio` | 出力動画のアスペクト比（デフォルト: "16:9"）。 | COMBO | はい | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 出力動画の長さ（秒）（5～15）（デフォルト: 5）。 | INT | はい | 5～15 |
| `prompt_expansion_mode` | 生成前にプロンプトを書き換えるために費やす労力（デフォルト: "balanced"）。 | COMBO | はい | "balanced"<br />"quality" |

### 注意事項

- すべてのモデルで、プロンプトには少なくとも1つの空白以外の文字を含める必要があります。
- `watermark` 設定は "MiniMax H3" でのみサポートされます。"MiniMax H3 Max" または "MiniMax H3 Max Turbo" で有効にするとエラーが発生します。
- "MiniMax H3 Max" および "MiniMax H3 Max Turbo" モデルでは、プロンプトは 50,000 文字に制限されています。
- 解像度と長さの制限は、選択したモデルによって異なります。"MiniMax H3" は "768P" と "2K" 解像度、および 4～15 秒の動画をサポートし、"MiniMax H3 Max" と "MiniMax H3 Max Turbo" は "480P" と "768P" 解像度、および 5～15 秒の動画をサポートします。
- このノードに表示される推定価格は、選択したモデル、解像度、長さから計算されます。
