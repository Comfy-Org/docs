HappyHorseモデルを使用して、テキストプロンプトに基づいてビデオを生成します。このノードは、プロンプトと設定をHappyHorse APIに送信し、ビデオの生成が完了するのを待ってから、結果をダウンロードします。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 生成に使用するHappyHorseモデルと、そのサブパラメータ。モデルを選択すると、利用可能なサブパラメータが決まります（以下のモデルセクションを参照）。 | DYNAMIC_COMBO | 必須 | "happyhorse-1.1-t2v"<br />"happyhorse-1.0-t2v" |
| `シード` | 生成に使用するシード。同じシードと同一の入力を使うと、同じ結果が生成されます。（デフォルト: 0） | INT | 必須 | 0 〜 2147483647 |
| `ウォーターマーク` | 結果にAI生成の透かしを追加するかどうか。（デフォルト: False） | BOOLEAN | 必須 | True / False |

### happyhorse-1.1-t2v 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要素と視覚的特徴を説明するプロンプト。英語と中国語に対応しています。（デフォルト: ""） | STRING | 必須 | - |
| `resolution` | 出力ビデオの解像度。 | COMBO | 必須 | "720P"<br />"1080P" |
| `ratio` | 出力ビデオのアスペクト比。 | COMBO | 必須 | "16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4"<br />"21:9"<br />"9:21"<br />"5:4"<br />"4:5" |
| `duration` | ビデオの長さ（秒）。（デフォルト: 5、最小: 3、最大: 15、ステップ: 1） | INT | 必須 | 3 〜 15 |

### happyhorse-1.0-t2v 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要素と視覚的特徴を説明するプロンプト。英語と中国語に対応しています。（デフォルト: ""） | STRING | 必須 | - |
| `resolution` | 出力ビデオの解像度。 | COMBO | 必須 | "720P"<br />"1080P" |
| `ratio` | 出力ビデオのアスペクト比。 | COMBO | 必須 | "16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4" |
| `duration` | ビデオの長さ（秒）。（デフォルト: 5、最小: 3、最大: 15、ステップ: 1） | INT | 必須 | 3 〜 15 |

注: プロンプトは空にできません。プロンプトが指定されていない場合はエラーが発生します。どちらのモデルも3〜15秒のビデオ時間に対応しています。`happyhorse-1.1-t2v`モデルでは、`happyhorse-1.0-t2v`では利用できない追加のアスペクト比（`21:9`、`9:21`、`5:4`、`4:5`）を提供しています。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `VIDEO` | 生成されたビデオファイル。 | VIDEO |
