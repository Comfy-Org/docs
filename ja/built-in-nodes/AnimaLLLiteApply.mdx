AnimaLLLiteApply は、拡散モデルに軽量なアニメーションパッチを適用し、調整可能な強度とタイミングで制御された image-to-image 生成を可能にします。事前設定されたモデルパッチを入力画像およびオプションのマスクと統合し、モデルのアテンション層と MLP 層を変更して生成プロセスに影響を与えます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | パッチを適用するベース拡散モデル | MODEL | はい | |
| `モデルパッチ` | 適用する事前設定済みのアニメーションパッチ | MODEL_PATCH | はい | |
| `画像` | 生成を導く参照画像。最初の3つのカラーチャネル（RGB）のみが使用されます | IMAGE | はい | |
| `強度` | パッチ効果の強度（デフォルト: 1.0、ステップ: 0.01） | FLOAT | はい | -10.0 〜 10.0 |
| `開始パーセント` | パッチが効果を発揮し始めるデノイジングプロセスの割合（デフォルト: 0.0、ステップ: 0.001） | FLOAT | はい | 0.0 〜 1.0 |
| `終了パーセント` | パッチが効果を停止するデノイジングプロセスの割合（デフォルト: 1.0、ステップ: 0.001） | FLOAT | はい | 0.0 〜 1.0 |
| `マスク` | パッチ効果を画像の特定領域に限定するためのオプションのマスク | MASK | いいえ | |

**パラメータ制約に関する注意：** `model_patch` が4つの入力チャネルを持ち、`mask` が提供されない場合、画像の寸法に合わせてゼロマスクが自動的に作成されます。`model_patch` が4つの入力チャネルを持たない場合、`mask` パラメータは無視され、`None` に設定されます。入力画像の最初の3つのカラーチャネルのみが使用されます。このノードは ComfyUI で実験的（experimental）としてマークされています。
