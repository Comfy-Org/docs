### AnimaLLLiteApply の説明

AnimaLLLiteApply は、拡散モデルに軽量なアニメーションパッチを適用し、調整可能な強度とタイミングで制御された画像間生成を可能にします。事前設定済みのモデルパッチを入力画像とオプションのマスクと統合し、モデルのアテンション層とMLP層を変更して生成プロセスに影響を与えます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | パッチを適用するベース拡散モデル。 | MODEL | はい | |
| `モデルパッチ` | 適用する事前設定済みのアニメーションパッチ。 | MODEL_PATCH | はい | |
| `画像` | 生成をガイドする参照画像。最初の3つのカラーチャンネル（RGB）のみが使用されます。 | IMAGE | はい | |
| `強度` | パッチ効果の強度（デフォルト: 1.0）。 | FLOAT | はい | -10.0 ～ 10.0 |
| `開始パーセント` | パッチが効果を発揮し始めるデノイジングプロセスのパーセンテージ（デフォルト: 0.0）。 | FLOAT | はい | 0.0 ～ 1.0 |
| `終了パーセント` | パッチが効果を停止するデノイジングプロセスのパーセンテージ（デフォルト: 1.0）。 | FLOAT | はい | 0.0 ～ 1.0 |
| `マスク` | パッチ効果を画像の特定領域に制限するためのオプションのマスク。 | MASK | いいえ | |

**パラメータ制約に関する注意:** `model_patch` が4つの入力チャンネルを持ち、`mask` が指定されていない場合、画像寸法に合わせてゼロマスクが自動的に作成されます。`model_patch` が4つの入力チャンネルを持たない場合、`mask` パラメータは無視され、`None` に設定されます。このノードは ComfyUI では実験的としてマークされています。
