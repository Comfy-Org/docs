Preview Point Cloud ノードは、3D ポイントクラウドファイルを ComfyUI の出力ディレクトリに保存せずに、ComfyUI インターフェース上で表示できます。このノードはポイントクラウドを一時的な場所に保存して 3D プレビューウィンドウに表示し、同時にモデルデータ、モデル情報、カメラ情報、プレビューの寸法を後続の処理に渡します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | ポイントクラウドファイル（.ply） | FILE3D | はい | - |
| `model_3d_info` | 3D モデルに関する情報 | LOAD3DMODELINFO | いいえ | - |
| `viewport_state` | 3D ビューポートの現在の状態 | LOAD3D | はい | - |
| `camera_info` | 3D ビューのカメラ情報 | LOAD3DCAMERA | いいえ | - |
| `width` | プレビューウィンドウの幅（デフォルト：1024） | INT | はい | 1 〜 4096 |
| `height` | プレビューウィンドウの高さ（デフォルト：1024） | INT | はい | 1 〜 4096 |

注：`model_3d_info` と `camera_info` はオプションの高度な入力です。これらが接続されていない場合、ノードは `viewport_state` に保存されている対応する値にフォールバックします。ポイントクラウドファイルは、出力ディレクトリではなく ComfyUI の一時ディレクトリに書き込まれます。これは出力（終端）ノードであるため、主にインターフェースでプレビューを表示するために使用されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_3d` | ポイントクラウドのモデルデータ | FILE3D |
| `model_3d_info` | 3D モデルに関する情報 | LOAD3DMODELINFO |
| `camera_info` | 3D ビューのカメラ情報 | LOAD3DCAMERA |
| `width` | プレビューウィンドウの幅 | INT |
| `height` | プレビューウィンドウの高さ | INT |
