Preview Point Cloudノードを使用すると、ComfyUIの出力ディレクトリに保存せずに、3DポイントクラウドファイルをComfyUIインターフェースで直接表示できます。このノードはポイントクラウドを一時的な場所に保存し、3Dプレビューウィンドウに表示すると同時に、モデルデータ、カメラ情報、ビューポート状態を後続の処理に渡します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | ポイントクラウドファイル（.ply） | FILE3D | はい | - |
| `model_3d_info` | 3Dモデルに関する情報 | LOAD3DMODELINFO | いいえ | - |
| `viewport_state` | 現在のビューポート状態 | LOAD3D | はい | - |
| `camera_info` | 3Dビューのカメラ情報 | LOAD3DCAMERA | いいえ | - |
| `width` | プレビューウィンドウの幅（デフォルト：1024） | INT | はい | 1〜4096 |
| `height` | プレビューウィンドウの高さ（デフォルト：1024） | INT | はい | 1〜4096 |

注：`camera_info`または`model_3d_info`が接続されていない場合、ノードは`viewport_state`に保存されている対応する値にフォールバックします。ポイントクラウドファイルはComfyUIの一時ディレクトリに保存され、出力ディレクトリには書き込まれません。これは出力ノードです。そのため、主にインターフェースでプレビュー結果を表示するために使用されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_3d` | ポイントクラウドモデルデータ | FILE3D |
| `model_3d_info` | 3Dモデルに関する情報 | LOAD3DMODELINFO |
| `camera_info` | 3Dビューのカメラ情報 | LOAD3DCAMERA |
| `width` | プレビューウィンドウの幅 | INT |
| `height` | プレビューウィンドウの高さ | INT |
