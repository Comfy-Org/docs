SenseNova Conditioning が残したインターリーブ履歴を、使用可能なテキスト、画像、思考に変換します。ループの最後で、End Loop accumulate を無効にした状態で実行すると、モデルが 1 回のパスで生成したすべての内容を収集できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 生成されたトークンをデコードするために使用する SenseNova CLIP モデルです。 | CLIP | はい | - |
| `conditioning` | SenseNova Conditioning からのインターリーブ条件付けです。 | CONDITIONING | はい | - |
| `samples` | 最後の KSampler のピクセル潜在です。ループが画像リクエストで終了した場合に必要です。 | LATENT | いいえ | - |

**制約と動作:**

* 条件付けは、`interleave` または `self-correction` タスクの SenseNova Conditioning からのものである必要があります。それ以外の場合はエラーが発生します。
* モデルが画像を待機している場合は、サンプラーの LATENT 出力を `samples` に接続してください。
* 実行開始時に接続された参照画像は出力から除外され、画像が生成されなかった場合は画像コンシューマーはスキップされます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `text` | インターリーブ履歴からデコードされたテキストです。画像マーカーは空行に置き換えられます。 | STRING |
| `images` | 実行中にモデルが生成した画像です。 | IMAGE |
| `thinking` | モデルが推論テキストを生成した場合の、その推論テキストです。 | STRING |
