このノードは、Bria を使用して画像から背景を削除し、プロンプトで記述した内容を保持します。元のピクセルは再レンダリングされるのではなく、新しいアルファチャンネル付きでフル解像度のまま返されるため、細部やエッジが保持されます。何にも一致しないプロンプトを指定すると、完全に透明な画像が返されます。ガイダンスなしの単純な切り抜きを行う場合は、Bria Remove Image Background の方がコストを抑えられます。

## 入力

`moderation` セレクターを `"true"` に設定すると、追加のモデレーションオプションが表示されます。

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 切り抜く画像です。 | IMAGE | はい | - |
| `prompt` | 保持する内容です。必要に応じて、削除する内容や対象を絞り込む内容も指定できます。例：「マットと植物を持っている人」「ランプのない机にいる女性」「椅子だけ」。空にしないでください。プロンプトに一致するものがない場合、結果は完全に透明になります。デフォルト：`""`（空文字列）。 | STRING | はい | 1文字以上 |
| `moderation` | モデレーション設定です。`"true"` に設定すると、以下のビジュアルモデレーションフラグが利用可能になります。 | DYNAMIC_COMBO | はい | `"false"`<br />`"true"` |

### モデレーション「true」入力

これらのパラメータは、`moderation` が `"true"` に設定されている場合にのみ表示されます。`"false"` オプションでは追加の入力はありません。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | 入力画像のコンテンツモデレーションを有効にします。デフォルト：`False`。 | BOOLEAN | いいえ | True / False |
| `visual_output_moderation` | 生成画像のコンテンツモデレーションを有効にします。デフォルト：`False`。 | BOOLEAN | いいえ | True / False |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 切り抜かれた画像です。元のピクセルに新しいアルファチャンネルが付いたものです。 | IMAGE |
