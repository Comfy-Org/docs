このノードは、画像、短いクリップ、音声、またはサウンドトラック付きクリップを、MiniMax H3 動画の任意のフレームにアンカーします。選択したフレームインデックスのコンディショニングにガイドキーフレームを追加します。また、複数のこのノードを連結して、同じ動画内の複数のフレームをアンカーできます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `positive` | ガイドキーフレームを付加するコンディショニング。 | CONDITIONING | はい | - |
| `vae` | 動画用 VAE。画像が接続されている場合に必要です。 | VAE | いいえ | - |
| `audio_vae` | 音声用 VAE。音声が接続されている場合に必要です。 | VAE | いいえ | - |
| `latent` | 対象の動画を定義する MiniMax H3 のオーディオビデオ潜在表現。MiniMax H3 AV 潜在表現（ネストされ、2 つの 5D テンソルを持ち、動画テンソルは 24 チャンネル）である必要があります。 | LATENT | はい | - |
| `image` | アンカーする画像または動画フレーム。複数フレームのバッチはクリップとしてアンカーされ、モデルの有効なクリップ長である 5、22、39...（17k + 5）フレームに切り詰められます。5 フレーム未満のバッチでは、最初の画像のみが使用されます。 | IMAGE | いいえ | - |
| `audio` | 同じフレームインデックスからアンカーするサウンドトラック。動画の残りの長さに合わせて切り詰められます。 | AUDIO | いいえ | - |
| `frame_idx` | 画像またはクリップの最初のフレームをアンカーするフレームインデックス。負の値は動画の末尾から数えられます。（デフォルト: 0） | INT | はい | -9999 ～ 9999 |

**制約事項:**
- `image` または `audio` の少なくとも一方を指定する必要があります。そうでない場合、ノードはエラーを発生させます。
- `image` が接続されている場合、`vae` が必要です。
- `audio` が接続されている場合、`audio_vae` が必要です。
- 5 フレーム未満の `image` バッチでは最初の画像のみが使用されます。5 フレーム以上のバッチは、有効なクリップ長（5、22、39 など）に切り詰められます。
- `frame_idx` は、ガイドを動画のフレーム範囲内に配置する必要があり、複数フレームのクリップは動画内に完全に収まる必要があります。そうでない場合、ノードはエラーを発生させます。
- 音声が接続されている場合、フレームインデックスは動画のオーディオトラックの終端を超えてはなりません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `positive` | ガイドキーフレームが追加されたコンディショニング。解決されたフレームインデックスと、指定されている場合はエンコードされた画像または音声の潜在表現を含みます。 | CONDITIONING |
