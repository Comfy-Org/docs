## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `positive` | ガイドキーフレームがアタッチされる conditioning を指定します。 | CONDITIONING | はい | - |
| `latent` | ターゲットビデオを定義する MiniMax H3 オーディオ・ビデオ latent です。MiniMax H3 AV latent（ネスト構造で、それぞれ24チャンネルの2つの5Dテンソル）である必要があります。 | LATENT | はい | - |
| `frame_idx` | 画像またはクリップの先頭フレームをアンカーするフレームインデックスです。負の値はビデオの末尾から数えます。（デフォルト：0） | INT | はい | -9999 〜 9999 |
| `vae` | ビデオ VAE です。画像が接続されている場合に必要です。 | VAE | いいえ | - |
| `audio_vae` | オーディオ VAE です。音声が接続されている場合に必要です。 | VAE | いいえ | - |
| `image` | アンカーする画像またはビデオフレームです。複数フレームのバッチはクリップとしてアンカーされ、モデルの有効なクリップ長（5、22、39...(17k + 5) フレーム）に切り詰められます。5 フレーム未満のバッチは最初の画像のみ使用されます。 | IMAGE | いいえ | - |
| `audio` | 同じフレームインデックスからアンカーするサウンドトラックです。ビデオの残り時間に合わせて切り詰められます。 | AUDIO | いいえ | - |

**制約事項：**
- `image` または `audio` の少なくとも一方を指定する必要があります。指定しない場合、ノードはエラーを発生させます。
- `vae` は `image` が接続されている場合に必要です。
- `audio_vae` は `audio` が接続されている場合に必要です。
- `image` バッチが 5 フレーム未満の場合は最初の画像のみ使用されます。5 フレーム以上のバッチは、有効なクリップ長（5、22、39 など）に切り詰められます。
- `frame_idx` は、ガイドがビデオのフレーム範囲内に収まる位置を指定する必要があります。また、複数フレームのクリップはビデオ内に完全に収まる必要があります。満たされない場合、ノードはエラーを発生させます。
- 音声が接続されている場合、フレームインデックスはビデオのオーディオトラックの末尾を超えてはなりません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `positive` | ガイドキーフレームが追加された conditioning です。解決されたフレームインデックスと、指定された場合はエンコードされた画像またはオーディオ latent が含まれます。 | CONDITIONING |
