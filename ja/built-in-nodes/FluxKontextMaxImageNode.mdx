プロンプトとアスペクト比に基づいて、BFL API を介して Flux.1 Kontext [max] で画像を生成または編集します。`input_image` が接続されている場合、プロンプトは編集内容を記述します。接続されていない場合、ノードはプロンプトのみから新しい画像を生成します。Flux.1 Kontext [pro] Image と同じ入力を公開します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 画像生成のためのプロンプトです。入力画像を伴う場合は、何をどのように編集するかを指定します。 | STRING | はい | - |
| `アスペクト比` | 画像のアスペクト比です。1:4 から 4:1 の間である必要があります（デフォルト：`"16:9"`）。 | STRING | はい | - |
| `ガイダンス` | 画像生成プロセスのガイダンス強度です（デフォルト：3.0）。 | FLOAT | はい | 0.1 〜 99.0 （ステップ 0.1） |
| `ステップ数` | 画像生成プロセスのステップ数です（デフォルト：50）。 | INT | はい | 1 〜 150 |
| `シード` | ノイズの作成に使用される乱数シードです（デフォルト：1234）。 | INT | はい | 0 〜 18446744073709551615 |
| `プロンプトアップサンプリング` | プロンプトに対してアップサンプリングを実行するかどうかです。有効にすると、より創造的な生成のためにプロンプトが自動的に変更されますが、結果は非決定的であるため、同じシードでもまったく同じ結果にはなりません（デフォルト：`False`）。これは詳細設定です。 | BOOLEAN | はい | True / False |
| `入力画像` | 編集する画像（オプション）です。省略された場合、プロンプトが空でないことを確認するために検証されます。 | IMAGE | いいえ | - |

**注:** このノードは BFL にリクエストを送信し、画像の準備ができるまでポーリングします。BFL のコンテンツモデレーションによって拒否されたリクエストは、画像を返さずに失敗します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | 生成または編集された画像です。 | IMAGE |
