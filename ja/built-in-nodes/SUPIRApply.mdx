SUPIRApply ノードは、拡散モデルに SUPIR モデルパッチを適用します。このパッチを使用してモデルの動作を変更し、サンプリングプロセス中に入力画像からのガイダンスを組み込むことを可能にします。また、このノードは、時間の経過に伴うこのガイダンスの強さを調整するためのコントロールを提供し、元の入力に対する忠実度を維持するためのオプション機能も含まれます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | SUPIR パッチが適用されるベース拡散モデル。 | MODEL | はい | - |
| `model_patch` | モデルを変更するための重みと設定を含む SUPIR モデルパッチ。 | MODELPATCH | はい | - |
| `vae` | 入力画像を潜在表現にエンコードするために使用される VAE（変分オートエンコーダ）。 | VAE | はい | - |
| `image` | 生成プロセスをガイドするために使用される入力画像。最初の3つのカラーチャンネル（RGB）のみが使用されます。 | IMAGE | はい | - |
| `strength_start` | サンプリング開始時（高シグマ）の制御強度。画像ガイダンスの影響はこの値から始まります。（デフォルト: 1.0） | FLOAT | はい | 0.0 - 10.0 |
| `strength_end` | サンプリング終了時（低シグマ）の制御強度。開始値から線形に補間されます。画像ガイダンスの影響はこの値で終了します。（デフォルト: 1.0） | FLOAT | はい | 0.0 - 10.0 |
| `restore_cfg` | ノイズ除去された出力を入力潜在変数に向かって引き寄せます。値が大きいほど入力への忠実度が強くなります。0 で無効化されます。（デフォルト: 4.0） | FLOAT | はい | 0.0 - 20.0 |
| `restore_cfg_s_tmin` | `restore_cfg` が無効になるシグマ閾値。（デフォルト: 0.05） | FLOAT | はい | 0.0 - 1.0 |

*注記:* `image` 入力は、RGB チャンネルのみを抽出するように処理されます。アルファチャンネル付きの画像が提供された場合、アルファチャンネルは無視されます。

*注記:* `restore_cfg` は、0 より大きい値に設定された場合のみ有効になります。0 に設定すると、リストア後処理が完全に無効になります。有効な場合、補正は現在のシグマ値が `restore_cfg_s_tmin` より高い間のみ適用されます。

*注記:* このノードは ComfyUI では実験的としてマークされています。
