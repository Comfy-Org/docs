SUPIRApply ノードは、SUPIR モデルパッチを拡散モデルに適用します。このパッチを使用してモデルの動作を変更し、サンプリング処理中に入力画像からのガイダンスを取り込めるようにします。また、このノードは時間経過に伴うガイダンスの強度を調整するためのコントロールを提供し、元の入力への忠実度を維持するのに役立つオプション機能も備えています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | SUPIR パッチを適用するベースの拡散モデル。 | MODEL | はい | - |
| `model_patch` | モデルを変更するための重みと設定を含む SUPIR モデルパッチ。 | MODEL_PATCH | はい | - |
| `vae` | 入力画像を潜在表現にエンコードするために使用される VAE（Variational Autoencoder）。 | VAE | はい | - |
| `image` | 生成処理をガイドするために使用される入力画像。最初の 3 つのカラーチャンネル（RGB）のみが使用されます。 | IMAGE | はい | - |
| `strength_start` | サンプリング開始時（高シグマ）の制御強度。画像ガイダンスの影響はこの値から始まります。（デフォルト: 1.0） | FLOAT | はい | 0.0 - 10.0 |
| `strength_end` | サンプリング終了時（低シグマ）の制御強度。開始値から線形補間されます。画像ガイダンスの影響はこの値で終了します。（デフォルト: 1.0） | FLOAT | はい | 0.0 - 10.0 |
| `restore_cfg` | ノイズ除去後の出力を入力潜在表現に引き寄せます。値が大きいほど入力への忠実度が高くなります。0 で無効化。（デフォルト: 4.0、詳細設定） | FLOAT | はい | 0.0 - 20.0 |
| `restore_cfg_s_tmin` | `restore_cfg` が無効になるシグマしきい値。（デフォルト: 0.05、詳細設定） | FLOAT | はい | 0.0 - 1.0 |

*注:* `image` 入力は RGB チャンネルのみを抽出するように処理されます。アルファチャンネル付きの画像が提供された場合、アルファチャンネルは無視されます。

*注:* SUPIR モデルパッチがノイズ除去エンコーダの重みを提供する場合、入力画像は通常の VAE エンコーダではなく、それらの重みを使用してエンコードされます。

*注:* `restore_cfg` は 0 より大きい値に設定した場合にのみ有効になります。0 に設定すると、復元後処理が完全に無効になります。有効な場合、補正は現在のシグマ値が `restore_cfg_s_tmin` を上回っている間だけ適用されます。

*注:* このノードは ComfyUI で実験的機能としてマークされています。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `model` | SUPIR パッチが適用され、追加の post-CFG 関数が設定された、入力モデルの複製コピー。 | MODEL |
