このノードは、Luma Ray 3.2 を使用して、タイムライン上の特定の位置にそれぞれ固定された一連のガイド画像間を補間する動画を生成します。Luma Ray 3.2 Keyframe ノードを使用してキーフレームシーケンスを構築し、少なくとも 2 つのキーフレームを接続してアニメーションを定義してください。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 動画生成のためのテキストプロンプト（デフォルト：空文字列）。 | STRING | はい | 1～6000文字 |
| `解像度` | 生成される動画の出力解像度（デフォルト："720p"）。 | STRING | はい | `"360p"`<br />`"540p"`<br />`"720p"`<br />`"1080p"` |
| `長さ` | 生成される動画の長さ（デフォルト："5s"）。 | STRING | はい | `"5s"`<br />`"10s"` |
| `シード` | 再現性を制御するための乱数生成用シード。 | INT | はい | 0～4294967295 |
| `キーフレーム` | Luma Ray 3.2 Keyframe ノードからのキーフレームシーケンス（少なくとも 2 つ）。 | LUMA_RAY32_KEYFRAME | はい | 2～64 キーフレーム |

**注記：** キーフレームシーケンスには少なくとも 2 つ、最大 64 個のキーフレームを含める必要があります。各キーフレームは、タイムライン上で異なる位置を持つ必要があります。キーフレーム位置は、選択した duration に基づいて出力フレームインデックスに解決されます（5s の場合は 120 フレーム、10s の場合は 240 フレーム）。秒モードでのキーフレーム位置は、動画全体の長さを超えてはなりません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | 生成された動画の出力。 | VIDEO |
| `generation_id` | 生成リクエストの一意の識別子。 | STRING |
