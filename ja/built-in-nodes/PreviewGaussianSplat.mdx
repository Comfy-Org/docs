PreviewGaussianSplat ノードは、3D ガウシアンスプラットファイルを ComfyUI の出力ディレクトリに保存せずにプレビューウィンドウに表示します。様々なガウシアンスプラット形式の3Dモデルファイルを受け入れ、プレビュー用の一時コピーを保存し、後続の処理のためにモデルデータをそのままワークフローに渡します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | ガウシアンスプラット形式の3Dファイル。 | FILE3D | はい | splat<br />ply<br />spz<br />ksplat |
| `model_3d_info` | 3Dモデルに関するオプションのメタデータ情報。接続されていない場合、ノードは `viewport_state` のモデル情報を使用します。 | LOAD3DMODELINFO | いいえ | - |
| `viewport_state` | 3Dビューポートの現在の状態（カメラ情報とモデル情報を含む）。 | LOAD3D | はい | - |
| `camera_info` | プレビュー用のオプションのカメラ情報。接続されていない場合、ノードは `viewport_state` のカメラ情報を使用します。 | LOAD3DCAMERA | いいえ | - |
| `width` | プレビューレンダーの幅（ピクセル単位、デフォルト: 1024）。 | INT | はい | 1 〜 4096 |
| `height` | プレビューレンダーの高さ（ピクセル単位、デフォルト: 1024）。 | INT | はい | 1 〜 4096 |

注：`camera_info` または `model_3d_info` が提供されていない場合、ノードは `viewport_state` に保存されているカメラ情報とモデル情報を使用します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_3d` | 入力された3Dガウシアンスプラットファイルを、変更せずにそのまま渡します。 | FILE3D |
| `model_3d_info` | 入力またはビューポートの状態から取得した3Dモデルに関するメタデータ情報。 | LOAD3DMODELINFO |
| `camera_info` | 入力またはビューポートの状態から取得したプレビュー用のカメラ情報。 | LOAD3DCAMERA |
| `width` | プレビューレンダーの幅。 | INT |
| `height` | プレビューレンダーの高さ。 | INT |
