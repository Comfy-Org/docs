PreviewGaussianSplat ノードは、3D ガウシアン スプラットファイルをプレビューウィンドウに表示しますが、ComfyUI の出力ディレクトリには保存しません。さまざまなガウシアン スプラット形式の 3D モデルファイルを受け入れ、プレビュー用の一時コピーを保存し、ワークフロー内の後続処理のためにモデルデータをそのまま渡します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | ガウシアン スプラット 3D ファイルです。 | FILE3D | はい | splat<br />ply<br />spz<br />ksplat |
| `model_3d_info` | 3D モデルに関するオプションのメタデータ情報です。接続されていない場合、ノードは `viewport_state` からモデル情報を使用します。 | LOAD3DMODELINFO | いいえ | - |
| `viewport_state` | 3D ビューポートの現在の状態です。カメラとモデルの情報が含まれます。 | LOAD3D | はい | - |
| `camera_info` | プレビュー用のオプションのカメラ情報です。接続されていない場合、ノードは `viewport_state` からカメラ情報を使用します。 | LOAD3DCAMERA | いいえ | - |
| `width` | プレビュー レンダリングの幅（ピクセル単位）です（デフォルト: 1024）。 | INT | はい | 1〜4096 |
| `height` | プレビュー レンダリングの高さ（ピクセル単位）です（デフォルト: 1024）。 | INT | はい | 1〜4096 |

注：`camera_info` または `model_3d_info` が指定されていない場合は、ノードは `viewport_state` に格納されているカメラ情報とモデル情報をフォールバックとして使用します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_3d` | 入力された 3D ガウシアン スプラットファイルを、変更せずにそのまま渡します。 | FILE3D |
| `model_3d_info` | 3D モデルに関するメタデータ情報です。入力から取得されるか、ビューポートの状態から導出されます。 | LOAD3DMODELINFO |
| `camera_info` | プレビュー用のカメラ情報です。入力から取得されるか、ビューポートの状態から導出されます。 | LOAD3DCAMERA |
| `width` | プレビュー レンダリングの幅です。 | INT |
| `height` | プレビュー レンダリングの高さです。 | INT |
