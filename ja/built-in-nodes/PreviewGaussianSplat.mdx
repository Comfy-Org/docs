PreviewGaussianSplat ノードは、3D ガウシアンスプラットファイルを ComfyUI 出力ディレクトリに保存せずにプレビューウィンドウに表示します。さまざまなガウシアンスプラット形式の 3D モデルファイルを受け取り、プレビュー用に一時コピーを保存し、ワークフローでさらに処理するためにモデルデータをそのまま渡します。このノードは実験的としてマークされており、出力ノードとして機能します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | ガウシアンスプラットの 3D ファイル。 | FILE3D | はい | splat<br />ply<br />spz<br />ksplat |
| `model_3d_info` | 3D モデルに関するオプションのメタデータ情報。接続されていない場合、ノードは `viewport_state` からのモデル情報を使用します。 | LOAD3DMODELINFO | いいえ | - |
| `viewport_state` | カメラ情報とモデル情報を含む、3D ビューポートの現在の状態。 | LOAD3D | はい | - |
| `camera_info` | プレビュー用のオプションのカメラ情報。接続されていない場合、ノードは `viewport_state` からのカメラ情報を使用します。 | LOAD3DCAMERA | いいえ | - |
| `width` | プレビューレンダリングの幅（ピクセル単位、デフォルト: 1024）。 | INT | はい | 1 〜 4096 |
| `height` | プレビューレンダリングの高さ（ピクセル単位、デフォルト: 1024）。 | INT | はい | 1 〜 4096 |

注: `camera_info` または `model_3d_info` が指定されていない場合、ノードは `viewport_state` に保存されているカメラ情報とモデル情報にフォールバックします。`viewport_state` が有効なビューポート状態オブジェクトでない場合、空として扱われます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_3d` | 入力された 3D ガウシアンスプラットファイル。変更されずにそのまま渡されます。 | FILE3D |
| `model_3d_info` | 入力から、またはビューポート状態から取得された、3D モデルに関するメタデータ情報。 | LOAD3DMODELINFO |
| `camera_info` | 入力から、またはビューポート状態から取得された、プレビュー用のカメラ情報。 | LOAD3DCAMERA |
| `width` | プレビューレンダリングの幅。 | INT |
| `height` | プレビューレンダリングの高さ。 | INT |
