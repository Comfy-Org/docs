人物の静止画像を、HeyGenのAvatar IVテクノロジーを使用してリップシンク付きのトーキングビデオにアニメーション化します。HeyGenが音声に変換するテキストスクリプトでアニメーションを駆動するか、アバターがリップシンクするための独自のオーディオを提供することができます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | アニメーション化する人物の画像。2Kより大きい場合は自動的にダウンスケールされます。 | IMAGE | はい | - |
| `音声` | テキストスクリプト（HeyGenテキスト読み上げ）または独自のオーディオでアバターを駆動します。 | COMBO | はい | `"script"`<br />`"audio"` |
| `text` | アバターが話すテキスト（最大5000文字）。生成された音声は少なくとも1秒以上の長さである必要があります。（デフォルト：空） | STRING | はい（speechが`"script"`の場合） | - |
| `voice` | スクリプト用の音声（HeyGenで最も人気のある音声）。 | COMBO | はい（speechが`"script"`の場合） | 複数のオプションが利用可能 |
| `custom_voice_id` | オプションのHeyGenボイスID。設定すると、上で選択した音声を上書きします。HeyGenのライブラリ（2000以上）から任意の音声を使用できます。（デフォルト：空） | STRING | いいえ | - |
| `voice_speed` | 音声速度の倍率（デフォルト：1.0）。 | FLOAT | いいえ | 0.5〜1.5 |
| `audio` | アバターがリップシンクするためのオーディオ（最大10分）。 | AUDIO | はい（speechが`"audio"`の場合） | - |
| `解像度` | 出力ビデオの解像度（デフォルト：`"1080p"`）。 | COMBO | いいえ | `"720p"`<br />`"1080p"` |
| `アスペクト比` | 出力のアスペクト比。`"auto"`は入力画像に従います（デフォルト：`"auto"`）。 | COMBO | いいえ | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:5"`<br />`"5:4"` |
| `表現力` | アニメーション化された顔とジェスチャーの表現力（デフォルト：`"low"`）。 | COMBO | いいえ | `"low"`<br />`"medium"`<br />`"high"` |
| `シード` | HeyGenには送信されません。再実行を強制するために変更します（デフォルト：42）。 | INT | いいえ | 0〜2147483647 |

注：`speech`は音声ソースを選択する動的入力です。`"script"`に設定すると、`text`と`voice`が必須になり、`custom_voice_id`と`voice_speed`はオプションになります。`"audio"`に設定すると、代わりに`audio`が必須になります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | リップシンクされた音声付きのアニメーション化されたトーキングフォトの生成ビデオ。 | VIDEO |
