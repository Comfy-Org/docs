WAN Context Windows (Manual) ノードを使用すると、Wan スタイルのビデオモデル用にコンテキストウィンドウを手動で設定できます。サンプリング中にこれらの設定を適用し、モデルがビデオを処理する際に使用するウィンドウ長、オーバーラップ、スケジューリング、融合方法を制御できます。コンテキスト長とオーバーラップは実フレーム単位で指定され、モデルの2D処理用に内部で変換されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | サンプリング中にコンテキストウィンドウを適用するモデルです。 | MODEL | はい | - |
| `コンテキスト長` | 実フレームでのコンテキストウィンドウの長さです。4*n + 1 である必要があります（デフォルト: 81）。 | INT | はい | 1〜16384 (MAX_RESOLUTION), step 4 |
| `コンテキストオーバーラップ` | 実フレームでのコンテキストウィンドウのオーバーラップです（デフォルト: 30）。 | INT | はい | 0 or higher |
| `コンテキストスケジュール` | コンテキストウィンドウのステップ依存スケジューリングアルゴリズムです（デフォルト: "uniform_standard"）。 | COMBO | はい | `"static_standard"`<br />`"uniform_standard"`<br />`"uniform_looped"`<br />`"batched"` |
| `コンテキストストライド` | コンテキストウィンドウのストライドです。uniform スケジュールにのみ適用されます（デフォルト: 1）。 | INT | はい | 1 or higher |
| `クローズドループ` | コンテキストウィンドウのループを閉じるかどうかです。looped スケジュールにのみ適用されます（デフォルト: False）。 | BOOLEAN | はい | - |
| `融合方法` | コンテキストウィンドウを融合するために使用する方法です（デフォルト: "pyramid"）。 | COMBO | はい | `"pyramid"`<br />`"gaussian"`<br />`"average"`<br />`"overlap"` |
| `フリーノイズ` | FreeNoise ノイズシャッフリングを適用するかどうかです。ウィンドウのブレンドが向上します（デフォルト: True）。 | BOOLEAN | はい | - |
| `retain_first_frame` | すべてのコンテキストウィンドウで最初の I2V フレームを保持します（初期参照の維持に役立つ場合があります）（デフォルト: False）。 | BOOLEAN | はい | - |
| `split_conds_to_windows` | ConditionCombine で作成された複数のコンディショニングを、リージョンインデックスに基づいて各ウィンドウに分割するかどうかです（デフォルト: False）。 | BOOLEAN | はい | - |

**注記:** `context_stride` は uniform スケジュールにのみ影響し、`closed_loop` は looped スケジュールにのみ適用されます。コンテキスト長とオーバーラップは実フレームで指定され、処理中に自動的に最小有効値に変換およびクランプされます（`context_length` は ((length - 1) / 4) + 1 に、`context_overlap` は overlap / 4 になります）。`context_length` は 4*n + 1 の形式に従う必要があります。`retain_first_frame` は image-to-video での使用を想定しています。`split_conds_to_windows` は、ConditionCombine ノードで作成された複数のコンディショニングを想定しています。`fuse_method` パラメータには "pyramid" 以外にも複数のオプションがあります。
