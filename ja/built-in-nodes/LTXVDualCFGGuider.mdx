このノードは、LTXV-AVモデル用のガイド付きサンプリングオブジェクト（CFGガイダー）を作成します。パックされた潜在表現のビデオ部分とオーディオ部分にそれぞれ別のガイダンススケールを適用し、各モダリティに対するconditioningの影響を個別に制御できます。2つのスケールが等しい場合、または潜在表現にビデオとオーディオの別々のコンポーネントが含まれていない場合は、単一の全体スケールが使用されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | サンプリング時に使用するモデル。 | MODEL | はい | - |
| `positive` | 生成を目的の方向へ導くためのポジティブconditioning。 | CONDITIONING | はい | - |
| `negative` | 生成を避ける方向へ導くためのネガティブconditioning。 | CONDITIONING | はい | - |
| `video_cfg` | 潜在表現のビデオモダリティに適用されるガイダンスの強さ（デフォルト：3.0）。 | FLOAT | はい | 0.0～100.0 |
| `audio_cfg` | 潜在表現のオーディオモダリティに適用されるガイダンスの強さ（デフォルト：7.0）。 | FLOAT | はい | 0.0～100.0 |

注：`video_cfg` と `audio_cfg` が同じ値の場合、ガイダーはその値を潜在表現全体に対する単一のCFGスケールとして使用します。潜在表現がパックされたLTXV-AV潜在表現でない場合は、`video_cfg` の値のみが使用されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `guider` | サンプラーノードに渡すための設定済みCFGガイダー。 | GUIDER |
