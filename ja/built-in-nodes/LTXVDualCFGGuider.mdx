このノードは、LTXV-AV モデル用のガイド付きサンプリングオブジェクト（CFG guider）を作成します。これは、パックされた LTXV-AV 潜在のビデオ部分とオーディオ部分に別々のガイダンススケールを適用し、各モダリティに対するコンディショニングの影響を個別に制御できるようにします。2つのスケールが等しい場合、または潜在に別々のビデオ成分とオーディオ成分が含まれていない場合は、代わりに単一の全体スケールが使用されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | サンプリング時に使用するモデルです。 | MODEL | はい | - |
| `positive` | 生成を誘導する対象となるポジティブコンディショニングです。 | CONDITIONING | はい | - |
| `negative` | 生成を遠ざけるネガティブコンディショニングです。 | CONDITIONING | はい | - |
| `video_cfg` | 潜在のビデオモダリティに適用されるガイダンス強度（デフォルト: 3.0）。 | FLOAT | はい | 0.0 〜 100.0 |
| `audio_cfg` | 潜在のオーディオモダリティに適用されるガイダンス強度（デフォルト: 7.0）。 | FLOAT | はい | 0.0 〜 100.0 |

注: `video_cfg` と `audio_cfg` が等しい（または値が非常に近い）場合、guider はその値を潜在全体に対する単一の CFG スケールとして使用します。潜在がパックされた LTXV-AV 潜在でない場合は、`video_cfg` の値のみが使用されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `guider` | サンプラーノードに渡すために設定された CFG guider です。 | GUIDER |
