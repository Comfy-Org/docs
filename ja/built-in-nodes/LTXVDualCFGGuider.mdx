このノードは、LTXV-AV モデル用のガイド付きサンプリングオブジェクト（CFG guider）を作成します。パックされた潜在表現のビデオ部分とオーディオ部分にそれぞれ個別のガイダンススケールを適用し、各モダリティに対する条件付けの影響を独立して制御できます。2つのスケールが等しい場合、または潜在表現にビデオとオーディオの成分が分離されていない場合は、単一の全体スケールが使用されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | サンプリング時に使用するモデル。 | MODEL | はい | - |
| `positive` | 生成を誘導するためのポジティブ条件付け。 | CONDITIONING | はい | - |
| `negative` | 生成を遠ざけるためのネガティブ条件付け。 | CONDITIONING | はい | - |
| `video_cfg` | 潜在表現のビデオモダリティに適用されるガイダンス強度（デフォルト: 3.0）。 | FLOAT | はい | 0.0 から 100.0 |
| `audio_cfg` | 潜在表現のオーディオモダリティに適用されるガイダンス強度（デフォルト: 7.0）。 | FLOAT | はい | 0.0 から 100.0 |

注：`video_cfg` と `audio_cfg` の値が等しいか非常に近い場合、ガイダーはその値を潜在表現全体の単一のCFGスケールとして使用します。潜在表現がパックされたLTXV-AV潜在表現でない場合は、`video_cfg` の値のみが使用されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `guider` | サンプラーノードに渡す設定済みのCFG guider。 | GUIDER |
