このノードは、MiniMax H3 Fun ControlNet をモデルパッチとしてテキストから動画へのモデルに適用します。オプションの制御ビデオとオプションのマスクを使用して生成を誘導でき、さらなるサンプリング用にパッチ適用済みのモデルのコピーを返します。`strength` が 0 に設定されている場合、または制御ビデオもマスクも提供されていない場合、入力モデルは変更されずに返されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | MiniMax H3 Fun ControlNet パッチを適用する拡散モデルです。 | MODEL | はい | N/A |
| `model_patch` | 制御信号がモデルに注入される MiniMax H3 Fun ControlNet パッチです。指定された `model` と互換性がある必要があります。 | MODEL_PATCH | はい | N/A |
| `vae` | 制御ビデオとソースビデオのフレームを、モデルが期待する潜在空間にエンコードするために使用される VAE です。 | VAE | はい | N/A |
| `strength` | ControlNet 効果の全体的な強度です。0 に設定すると、ノードは何もせず、入力モデルを変更せずに返します。（デフォルト: 1.0） | FLOAT | はい | min 0.0, max 10.0, step 0.01 |
| `start_percent` | ControlNet が有効なサンプリング範囲の開始位置を、サンプリングスケジュールのパーセンテージで表したものです。内部的に相当するシグマ値に変換されます。これは詳細設定です。（デフォルト: 0.0） | FLOAT | はい | min 0.0, max 1.0, step 0.001 |
| `end_percent` | ControlNet が有効なサンプリング範囲の終了位置を、サンプリングスケジュールのパーセンテージで表したものです。内部的に相当するシグマ値に変換されます。これは詳細設定です。（デフォルト: 1.0） | FLOAT | はい | min 0.0, max 1.0, step 0.001 |
| `control_video` | ControlNet の視覚的なヒントとして使用されるオプションのビデオフレームです。フレームは生成されるビデオに合わせてリサイズされ、`vae` でエンコードされます。 | IMAGE | いいえ | N/A |
| `mask` | 1 は再生成する領域をマークします。0.5 を超えるマスク値はマークされた領域として扱われます。 | MASK | いいえ | N/A |
| `source_video` | マスクの背後にあるビデオです。マスクが指定されている場合にのみ読み取られます。 | IMAGE | いいえ | N/A |

注: パッチを効果的に機能させるには、`strength` が 0 より大きい必要があり、`control_video` または `mask` の少なくとも一方を指定する必要があります。`mask` が指定されない限り、`source_video` は無視されます。`source_video` なしで `mask` が指定された場合、マスクされた領域の背後のコンテンツは黒として扱われます。`control_video` と `mask` の両方が指定された場合、制御ヒントは制御ビデオの特徴とマスクされたソースコンテンツを組み合わせます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model` | MiniMax H3 Fun ControlNet が適用された、入力モデルのパッチ適用済みクローンです。`strength` が 0 の場合、または制御ビデオもマスクも指定されていない場合、元のモデルが変更されずに返されます。 | MODEL |
