UltraTex LoRA を適用した FLUX.2 Klein 9B を条件付けし、参照画像の見た目をメッシュにペイントします。出力はビューごとに 1 枚の画像です。ビューは Render Mesh の `world normal` モードで、4 方向に top と bottom を加えた Create Camera Orbit からレンダリングし、その結果を Bake Texture From Views でベイクします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `conditioning` | テキスト条件付けです。UltraTex は空のプロンプトでトレーニングされています。 | CONDITIONING | はい | - |
| `vae` | 法線、ビュー、参照をエンコードするために使用する VAE です。 | VAE | はい | - |
| `normals` | Render Mesh の `world normal` 画像です。6 つの正規ビュー、または 4 つの側面ビューのいずれかです。 | IMAGE | はい | - |
| `masks` | 同じビューの Render Mesh マスクです。ビューごとに 1 枚です。 | MASK | はい | - |
| `reference` | 前面カメラ側から見た、オブジェクトのあるべき姿です。 | IMAGE | はい | - |
| `reference_mask` | 参照のオブジェクトマスクです。オブジェクト部分は白です。デフォルト：完全な白。 | MASK | いいえ | - |
| `extra_views` | 追加の参照です。他のビューから見たオブジェクトで、それぞれが参照を前面に紐付けるのと同様に、そのビューに紐付きます。デフォルト：`"off"`。 | DYNAMIC_COMBO | はい | `"off"`<br />`"on"` |

### 追加ビュー `"on"` 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `right` | 右ビューから見たオブジェクトです。 | IMAGE | いいえ | - |
| `back` | 背面ビューから見たオブジェクトです。 | IMAGE | いいえ | - |
| `left` | 左ビューから見たオブジェクトです。 | IMAGE | いいえ | - |
| `top` | 上面ビューから見たオブジェクトです。 | IMAGE | いいえ | - |
| `bottom` | 下面ビューから見たオブジェクトです。 | IMAGE | いいえ | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `conditioning` | UltraTex が必要とするビューグリッド、参照潜在、トークンマスクを保持する条件付けです。 | CONDITIONING |

注：`normals` には、6 つの正規ビュー（`count` 4 と `poles` の top および bottom を指定した Create Camera Orbit）または 4 つの側面ビューのいずれかを格納する必要があり、`masks` はそのビュー数と一致している必要があります。
