SaveImage ノードは、入力された画像を PNG ファイルとして ComfyUI の出力ディレクトリに保存します。プロンプトなどのワークフローメタデータを各保存ファイルに埋め込むことができ、画像は変更されずに返されるため、他のノードでも引き続き使用できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `画像` | 保存する画像。 | IMAGE | はい | - |
| `ファイル名_プレフィックス` | 保存するファイルのプレフィックスです。ノードの値を含めるための `%date:yyyy-MM-dd%` や `%Empty Latent Image.width%` などのフォーマット情報を含めることができます（デフォルト: "ComfyUI"）。 | STRING | はい | - |

このノードは、`prompt` と `extra_pnginfo` という2つの隠し入力も受け取ります。これらは ComfyUI によってワークフロープロンプトと追加 PNG 情報で自動的に設定されます。メタデータが有効な場合、この情報は保存された各 PNG ファイルにテキストメタデータとして埋め込まれます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `images` | 元の入力画像。ディスクに保存された後、変更されずに返されます。 | IMAGE |
| `ui` | UI 専用の結果で、保存された画像ファイルのリスト（ファイル名、サブフォルダ、タイプ）を含み、フロントエンドで表示するために使用されます。 | UI_RESULT |
