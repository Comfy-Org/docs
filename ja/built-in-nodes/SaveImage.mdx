SaveImage ノードは、入力画像を PNG ファイルとして ComfyUI の出力ディレクトリに保存します。保存される各ファイルには、プロンプトなどのワークフローメタデータを埋め込むことができ、画像は変更されずに返されるため、他のノードでも引き続き使用できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `画像` | 保存する画像です。 | IMAGE | はい | - |
| `ファイル名_プレフィックス` | 保存するファイルのプレフィックスです。`%date:yyyy-MM-dd%` や `%Empty Latent Image.width%` などのフォーマット情報を含めることができ、ノードから値を取り込めます（デフォルト: "ComfyUI"）。 | STRING | はい | - |

このノードはさらに、2 つの非表示入力 `prompt` と `extra_pnginfo` を受け取ります。これらは ComfyUI によってワークフローのプロンプトおよび追加の PNG 情報で自動的に設定されます。メタデータが有効な場合、この情報は保存される各 PNG ファイルにテキストメタデータとして埋め込まれます。

保存される各画像のファイル名は、`filename_prefix`、バッチ内での画像の位置に置き換えられるオプションの `%batch_num%` プレースホルダー、および 5 桁のカウンターから構成されます。例: `ComfyUI_00001_.png`。画像は PNG 圧縮レベル 4 で書き込まれます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `images` | ディスクに保存された後、変更されずに返される元の入力画像です。 | IMAGE |
| `ui` | 保存された画像ファイルのリスト（ファイル名、サブフォルダー、種類）を含み、フロントエンドに表示するための UI 専用の結果です。 | UI_RESULT |
