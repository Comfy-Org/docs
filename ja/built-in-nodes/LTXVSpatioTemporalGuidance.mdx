このノードは、各サンプリングステップで追加のパスを1回実行することで、LTXV ビデオ生成の空間的な詳細とモーションの一貫性を向上させます。このパスでは、選択された Transformer ブロックの self-attention が値のパススルーに劣化され、生成はその劣化した結果から離れるようにガイドされます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 時空間ガイダンスを適用するベースモデル。モデルは複製され、複製先に post-CFG ガイダンス関数がアタッチされます。 | MODEL | はい | — |
| `scale` | ノイズ除去された結果に適用されるガイダンスの強度。0 に設定すると、ガイダンスは効果を発揮しません。（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 100.0 （ステップ 0.01） |
| `blocks` | 摂動させる Transformer ブロックのインデックスをカンマ区切りで指定します。数値のみが使用され、その他の文字は無視されます。（デフォルト: "29"） | STRING | はい | — |
| `start_percent` | ガイダンスを開始するサンプリングプロセスの割合。これは上級者向けパラメータです。（デフォルト: 0.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.001） |
| `end_percent` | ガイダンスを終了するサンプリングプロセスの割合。これは上級者向けパラメータです。（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.001） |

注: ガイダンスは `start_percent` と `end_percent` の間のサンプリング区間でのみ適用されます。その区間外では、元のノイズ除去結果が変更されずに返されます。`scale` が 0 の場合、または `blocks` に数値が含まれていない場合、ガイド付きパスはサンプリングプロセスに影響を与えません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `MODEL` | 時空間ガイダンス関数がアタッチされた複製モデル。 | MODEL |
