SamplerCustomAdvanced ノードは、カスタムノイズ、ガイダンス、およびサンプリング設定を使用して、高度な潜在空間サンプリングを実行します。ノイズ生成とシグマスケジュールをカスタマイズ可能なガイド付きサンプリングプロセスを通じて潜在画像を処理し、最終的なサンプリング出力と、利用可能な場合にはノイズ除去されたバージョンの両方を生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ノイズ` | サンプリングプロセスに初期ノイズパターンとシードを提供するノイズジェネレーターです。 | NOISE | はい | - |
| `ガイダー` | サンプリングプロセスを目的の出力へ導くガイダンスモデルです。 | GUIDER | はい | - |
| `サンプラー` | 生成中に潜在空間をどのように移動するかを定義するサンプリングアルゴリズムです。 | SAMPLER | はい | - |
| `シグマ` | サンプリングステップ全体のノイズレベルを制御するシグマスケジュールです。 | SIGMAS | はい | - |
| `潜在イメージ` | サンプリングの開始点となる初期潜在表現です。オプションの `noise_mask` による選択的ノイズ除去、および高度な潜在変数処理のためのオプションの `downscale_ratio_spacial` キーと `downscale_ratio_temporal` キーをサポートします。 | LATENT | はい | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `出力` | サンプリングプロセス完了後の最終的なサンプリング済み潜在表現です。入力潜在変数に含まれる `downscale_ratio_spacial` キーと `downscale_ratio_temporal` キーは、この出力から削除されます。 | LATENT |
| `ノイズ除去出力` | サンプリングプロセスが中間的なクリーン予測 (x0) を生成する場合の出力のノイズ除去バージョンです。それ以外の場合は、出力と同じものを返します。利用可能な場合、これは各ステップにおけるクリーンな潜在変数のモデルによる最良推定値を表します。 | LATENT |
