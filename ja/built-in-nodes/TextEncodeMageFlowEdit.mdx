## 概要

このノードは、Mage-Flow-Edit モデル向けに、編集指示（プロンプト）と 1 つ以上の参照画像をエンコードします。すべての参照画像を目的の出力解像度にリサイズし、VAE が提供されている場合はそれらを潜在空間にエンコードして、参照潜在変数を conditioning 出力に付加します。また、サンプリングに適した正しい次元を持つ空の潜在テンソルを生成し、そのサイズが常に出力幅と高さに一致することを保証します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|------|----------|------|------|
| `clip` | テキストプロンプトをトークン化およびエンコードするために使用される CLIP モデル。 | CLIP | はい | |
| `prompt` | 適用する編集指示（ポジティブプロンプト）。 | STRING | はい | 複数行、動的プロンプト有効 |
| `negative_prompt` | 避けたい内容を示すネガティブプロンプト。デフォルト：空文字列（ブランクの場合、内部ではスペースが使用されます）。 | STRING | いいえ | 複数行、動的プロンプト有効 |
| `vae` | 参照画像を潜在空間にエンコードする VAE モデル。提供されない場合、参照潜在変数は conditioning に追加されません。 | VAE | いいえ | |
| `images` | 編集する 1 つ以上の参照画像。すべての画像はエンコード前に出力解像度にリサイズされます。 | IMAGE（自動増加） | いいえ | 最大 16 枚の画像（`image_1` … `image_16` として命名）、最低 0 枚 |
| `width` | 出力幅（ピクセル）。0 に設定すると、最初の参照画像の幅が使用されます。常に 16 の倍数に切り捨てられます。デフォルト：0。 | INT | はい | 0 ～ 8192（ステップ 16） |
| `height` | 出力高さ（ピクセル）。幅と同じフォールバック動作。デフォルト：0。 | INT | はい | 0 ～ 8192（ステップ 16） |
| `batch_size` | 生成する潜在サンプルの数。デフォルト：1。 | INT | はい | 1 ～ 4096 |

**パラメータの依存関係に関する注意事項：**
- `width` または `height`（またはその両方）が 0 で、参照画像が提供されていない場合、それぞれ 1024 にフォールバックします。
- `vae` パラメータはオプションです。VAE が接続されている場合にのみ、参照潜在変数が生成され conditioning に付加されます。
- `negative_prompt` フィールドはオプションです。空のままにすると、内部では 1 つのスペースがネガティブテキストとして使用されます。

## 出力

| 出力名 | 説明 | データ型 |
|--------|------|----------|
| `positive` | ポジティブプロンプトのトークンと、（VAE が提供された場合）エンコードされた参照潜在変数を含む conditioning 出力。 | CONDITIONING |
| `negative` | ネガティブプロンプトのトークンと、（VAE が提供された場合）同じ参照潜在変数を含む conditioning 出力。 | CONDITIONING |
| `latent` | サンプリング中の初期ノイズとして使用する、形状 `[batch_size, 128, height÷16, width÷16]` の空の潜在テンソル。 | LATENT |
