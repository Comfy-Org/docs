このノードは、FLUX 3を使用して既存のビデオクリップを継続します。新しいクリップは、提供されたビデオの最後のフレームから続きが再生されます。ソースクリップをアップロードし、プロンプトと設定を生成サービスに送信し、準備ができ次第、結果の継続ビデオを返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `video` | 継続するクリップ。 | VIDEO | はい | 単一のビデオクリップ |
| `プロンプト` | 継続動画に表示する内容。プロンプトは生成前に解釈・拡張されます。（デフォルト: ""） | STRING | はい | 非空のテキスト（1文字以上） |
| `アスペクト比` | 出力アスペクト比。「auto」はプロンプトと入力から自動的に選択します。（デフォルト: "auto"） | COMBO | はい | "auto"（デフォルト）<br />複数の定義済みオプション |
| `長さ` | クリップの長さ（秒）。「auto」はコンテンツに合わせて長さを調整します。（デフォルト: "auto"） | COMBO | はい | "auto"（デフォルト）<br />秒単位の数値 |
| `解像度` | 出力解像度。（デフォルト: "720p"） | COMBO | はい | "720p"（デフォルト）<br />"1080p"<br />その他の定義済みオプション |
| `音声生成` | 同期オーディオ（環境音、音声、効果音）を生成します。オフにするとオーディオトラックのないビデオが生成されます。（デフォルト: true） | BOOLEAN | はい | true<br />false |
| `安全許容度` | モデレーションの許容度で、0が最も厳格です。画像やビデオを送信するリクエストは、ここで設定した値にかかわらず2に制限されます。（詳細パラメータ、デフォルト: 2） | INT | はい | 0 - 4（実効最大値: 2、ビデオリクエストの場合） |
| `シード` | ノードを再実行するかどうかを決定するシード。FLUX 3は独自のシードを選択するため、この値に関係なく実際の結果は非決定的になります。（詳細パラメータ、デフォルト: 42） | INT | はい | 0 - 4294967295 (0xFFFFFFFF) |

### 注記

- `prompt` は少なくとも1文字を含む必要があります。そうでないと生成が失敗します。このフィールドはデフォルトでは空文字列ですが、ノードを実行するには空でないプロンプトが必要です。
- `safety_tolerance` は0から4までの任意の値を受け入れますが、このノードはAPIにビデオを送信するため、選択した値に関係なく実効許容度は2に制限されます。
- `duration` に数値を設定すると、整数の秒数に変換されます。特別な値「auto」を使用すると、サービスがコンテンツに合わせて長さを調整します。
- `aspect_ratio`、`duration`、`resolution` の正確なオプションリストはノードによって内部的に定義されています。解像度オプションには少なくとも「720p」（デフォルト）と「1080p」が含まれます。料金は選択した `resolution` と `duration` に基づいて計算されます。「1080p」は毎秒$0.7579、その他の解像度は毎秒$0.5863で請求されます。
- 認証およびノード識別フィールド（`auth_token_comfy_org`、`api_key_comfy_org`、`unique_id`）は非表示であり、プラットフォームによって自動的に処理されます。
