このノードは、FLUX 3 を使って既存の動画クリップを継続します。新しいクリップは、指定した動画の最終フレームから続きます。ソースクリップをアップロードし、プロンプトと設定を生成サービスに送信して、準備が整い次第、生成された継続動画を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `video` | 継続するクリップ。 | VIDEO | はい | 単一の動画クリップ |
| `プロンプト` | 継続で表示すべき内容。プロンプトは生成前に解釈・拡張されます。（デフォルト: ""） | STRING | はい | 空でないテキスト（最低1文字） |
| `アスペクト比` | 出力のアスペクト比。「auto」はプロンプトと入力から選択します。（デフォルト: "auto"） | COMBO | はい | "auto"（デフォルト）<br />複数の定義済みオプション |
| `長さ` | クリップの長さ（秒）。「auto」はコンテンツに合わせて長さを調整します。（デフォルト: "auto"） | COMBO | はい | "auto"（デフォルト）<br />秒単位の数値 |
| `解像度` | 出力解像度。（デフォルト: "720p"） | COMBO | はい | "720p"（デフォルト）<br />"1080p"<br />その他の定義済みオプション |
| `音声生成` | 同期されたオーディオ（環境音、音声、効果音）を生成します。オフにすると、音声トラックのない動画が生成されます。（デフォルト: true） | BOOLEAN | はい | true<br />false |
| `安全許容度` | モデレーションの許容度。0 が最も厳しくなります。画像や動画を送信するリクエストでは、ここで設定した値にかかわらず上限が 2 になります。（高度なパラメータ、デフォルト: 2） | INT | はい | 0 - 4（動画リクエストの実効上限: 2） |
| `シード` | ノードを再実行するかどうかを決めるシード。FLUX 3 は独自にシードを選択するため、この値にかかわらず実際の結果は非決定的です。（デフォルト: 42） | INT | はい | 0 - 4294967295 (0xFFFFFFFF) |

### 注意事項

- `prompt` には少なくとも1文字が必要で、そうでない場合は生成が失敗します。このフィールドのデフォルトは空文字列ですが、ノードを実行するには空でないプロンプトが必要です。
- `safety_tolerance` は 0 から 4 までの任意の値を受け付けますが、このノードは動画を API に送信するため、選択した値にかかわらず実効的な許容度は 2 に制限されます。
- `duration` に数値を設定すると、整数の秒数に変換されます。特別な値「auto」を指定すると、サービスがコンテンツに合わせて長さを調整します。
- `aspect_ratio`、`duration`、`resolution` の正確なオプション一覧は、ノード内部で定義されています。解像度のオプションには少なくとも「720p」（デフォルト）と「1080p」が含まれます。料金は選択した `resolution` と `duration` から計算され、「1080p」は毎秒 $0.7579、その他の解像度は毎秒 $0.5863 で課金されます。
- `seed` はノードを再実行するかどうかの制御にのみ使用され、生成サービスには送信されません。
- 認証およびノード識別用のフィールド（`auth_token_comfy_org`、`api_key_comfy_org`、`unique_id`）は非表示で、プラットフォームによって自動的に処理されます。
