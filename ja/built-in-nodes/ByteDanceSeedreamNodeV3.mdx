ByteDance Seedream 4.5 & 5.0 は、テキストプロンプトから画像を生成（テキストから画像へ）するか、オプションの参照画像に基づいて画像を生成・編集します。ByteDance Seedream 4.0、4.5、5.0 モデルを最大 4K 解像度で使用します。このノードは、プロンプトと参照画像を ByteDance API に送信し、生成タスクの完了を待って、結果の画像テンソル（1 つまたは複数）を返します。

|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 画像の作成または編集に使用するテキストプロンプトです。前後の空白を除去した後も空にすることはできません。 | STRING | はい | Multiline text |
| `モデル` | 使用する Seedream モデルを選択します。各モデルは、以下に示す独自のサブパラメータと制限を持ちます。 | DYNAMIC_COMBO | はい | "seedream 5.0 pro"<br />"seedream 5.0 lite"<br />"seedream-4-5-251128"<br />"seedream-4-0-250828" |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | 拡張可能なスロット: 画像から画像への生成やマルチ参照生成のためのオプションの参照画像です。1..N 個の画像（例: `image_1`、`image_2`、...）を接続できます。数の上限はモデルごとに異なります（下記の注記を参照）。接続した画像がバッチを含む場合、バッチ内のすべての画像が上限にカウントされます。 | IMAGE | いいえ | 0〜10 (Seedream 5.0 Pro, Seedream 4.5, Seedream 4.0)<br />0〜14 (Seedream 5.0 Lite) |

**注記:**

- `prompt` は前後の空白を除去した後も空にすることはできません。
- 参照画像の最大数: Seedream 5.0 Pro、Seedream 4.5、Seedream 4.0 では 10、Seedream 5.0 Lite では 14 です。
- 各参照画像のアスペクト比は 1:3 から 3:1 の間である必要があります。
- `max_images` が 1 より大きい場合（Seedream 5.0 Pro では利用不可）、参照画像と生成画像の合計数は 15 を超えることはできません。
- `thinking` はテキストから画像への生成の場合にのみ無効にできます。参照画像が提供されている場合は、`thinking` を有効にする必要があります。
- `width` と `height` は、`size_preset` が "Custom" に設定されている場合にのみ使用されます。
- `prompt_optimization` は Seedream 5.0 Pro でのみ利用可能です。
- `max_images` と `fail_on_partial` は Seedream 5.0 Lite、Seedream 4.5、Seedream 4.0 でのみ利用可能です。Seedream 5.0 Pro は常に単一の画像を要求します。
- 解像度の要件（幅 × 高さ）:
  - Seedream 5.0 Pro: 0.92MP（921,600 ピクセル）から 4.19MP（4,194,304 ピクセル）の間。
  - Seedream 5.0 Lite と Seedream 4.5: 最低 3.68MP（3,686,400 ピクセル）。
  - Seedream 4.0: 最低 0.92MP（921,600 ピクセル）。
  - Pro 以外のすべてのモデル: 最大 16.78MP（16,777,216 ピクセル）。
