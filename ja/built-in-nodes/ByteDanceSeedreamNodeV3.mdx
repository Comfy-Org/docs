ByteDance Seedream 4.5 & 5.0 は、テキストプロンプトから画像を生成する（text-to-image）か、任意の参照画像に導かれて画像を生成／編集します。ByteDance Seedream 4.0、4.5、5.0 モデルを最大 4K 解像度で使用します。このノードはプロンプトと参照画像を ByteDance API に送信し、生成タスクの完了を待って、結果の画像テンソルまたは複数のテンソルを返します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 画像を作成または編集するためのテキストプロンプト。空白を除去した後に空であってはなりません。 | STRING | はい | 複数行テキスト |
| `モデル` | 使用する Seedream モデルを選択します。各モデルには、以下に示す独自のサブパラメータと制限があります。 | DYNAMIC_COMBO | はい | "seedream 5.0 pro"<br />"seedream 5.0 flash"<br />"seedream 5.0 lite"<br />"seedream-4-5-251128"<br />"seedream-4-0-250828" |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | 増設可能なスロット: image-to-image またはマルチ参照生成用の任意の参照画像。1..N 枚の画像（例: `image_1`、`image_2`、...）を接続します。枚数制限はモデルごとに異なります（以下の注記を参照）。接続された画像に画像のバッチが含まれる場合、バッチ内のすべての画像が制限にカウントされます。 | IMAGE | いいえ | 0～10（Seedream 5.0 Pro、Seedream 5.0 Flash、Seedream 4.5、Seedream 4.0）<br />0～14（Seedream 5.0 Lite） |

**注記:**

- `prompt` は空白を除去した後に空であってはなりません。
- 参照画像の最大数: Seedream 5.0 Pro、Seedream 5.0 Flash、Seedream 4.5、Seedream 4.0 では 10、Seedream 5.0 Lite では 14 です。
- 各参照画像のアスペクト比は 1:16 から 16:1 の間である必要があります。
- `max_images` が 1 より大きい場合（Seedream 5.0 Pro および Seedream 5.0 Flash では使用できません）、参照画像と生成画像の合計数は 15 を超えることはできません。
- `thinking` は text-to-image 生成の場合にのみ無効化できます。参照画像が提供される場合、`thinking` は有効でなければなりません。Seedream 5.0 Flash には `thinking` 入力がありません。
- `width` と `height` は、`size_preset` が "Custom" に設定されている場合にのみ使用されます。
- `prompt_optimization` は Seedream 5.0 Pro でのみ使用できます。
- `max_images` と `fail_on_partial` は Seedream 5.0 Lite、Seedream 4.5、Seedream 4.0 でのみ使用できます。Seedream 5.0 Pro と Seedream 5.0 Flash は常に 1 枚の画像を要求します。
- 解像度要件（幅 x 高さ）:
  - Seedream 5.0 Pro および Seedream 5.0 Flash: 0.92MP（921,600 ピクセル）から 4.62MP（4,624,220 ピクセル）の間。
  - Seedream 5.0 Lite および Seedream 4.5: 少なくとも 3.68MP（3,686,400 ピクセル）。
  - Seedream 4.0: 少なくとも 0.92MP（921,600 ピクセル）。
  - Seedream 5.0 Lite、Seedream 4.5、Seedream 4.0: 最大 16.78MP（16,777,216 ピクセル）。
