Wan 2.7 Image to Video ノードは、最初のフレーム画像から始まるビデオを生成します。必要に応じて最後のフレーム画像を指定すると、その2つの間の遷移を作成したり、オーディオファイルを指定してビデオの動きとタイミングをガイドしたりできます。このノードは、テキストによる説明に基づいてAIモデルを使用し、シーンをアニメーション化します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | ビデオ生成に使用するAIモデル。 | DYNAMIC_COMBO | はい | `"wan2.7-i2v"` |
| `first_frame` | 最初のフレーム画像。出力のアスペクト比はこの画像から導出されます。 | IMAGE | はい | - |
| `last_frame` | 最後のフレーム画像。モデルは最初のフレームから最後のフレームへ遷移するビデオを生成します。 | IMAGE | いいえ | - |
| `audio` | ビデオ生成を駆動するためのオーディオ（例：リップシンク、ビートに合わせたモーション）。長さ：2秒〜30秒。指定しない場合、モデルは自動的に一致する背景音楽や効果音を生成します。 | AUDIO | いいえ | - |
| `seed` | 生成に使用するシード（デフォルト：0）。 | INT | はい | 0 から 2147483647 |
| `prompt_extend` | AI支援でプロンプトを拡張するかどうか（デフォルト：True）。これは高度な設定です。 | BOOLEAN | はい | True<br />False |
| `watermark` | 結果にAI生成の透かしを追加するかどうか（デフォルト：False）。これは高度な設定です。 | BOOLEAN | はい | True<br />False |

### wan2.7-i2v 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `prompt` | 要素と視覚的特徴を説明するプロンプト。英語と中国語に対応しています。（デフォルト：空） | STRING | はい | - |
| `negative_prompt` | 避けるべき内容を説明するネガティブプロンプト。（デフォルト：空） | STRING | はい | - |
| `resolution` | 出力ビデオの解像度。 | COMBO | はい | `"720P"`<br />`"1080P"` |
| `duration` | 生成されるビデオの長さ（秒）。（デフォルト：5） | INT | はい | 2 から 15 |

**注：** `audio` 入力には長さの制約があります。指定する場合、オーディオファイルは2秒から30秒の間である必要があります。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | 生成されたビデオファイル。 | VIDEO |
