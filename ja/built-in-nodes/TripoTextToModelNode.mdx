Tripo の API を使用して、テキストによる説明から完成した 3D モデルを生成します。ノードは生成が完了するまで待機し、必要に応じてテクスチャと PBR マテリアルを含むモデルファイルを返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成する 3D モデルのテキストによる説明（複数行）。このパラメータは必須であり、空にすることはできません。 | STRING | 必須 | - |
| `negative_prompt` | 生成モデルで避けたい内容のテキストによる説明（複数行）。255文字まで。空でない場合にのみ API に送信されます。 | STRING | 任意 | 255文字まで |
| `model_version` | 生成に使用する Tripo モデルのバージョン（デフォルト: v3.1-20260211）。 | COMBO | 任意 | 複数のオプションから選択可能 |
| `style` | 生成モデルに適用されるスタイル（デフォルト: None）。Tripo ではサポートされなくなったため無視されます。以前のワークフロー向けに残されています。 | COMBO | 任意 | 複数のオプションから選択可能 |
| `texture` | テクスチャマップを生成するかどうか。オフの場合は素のジオメトリを返し、`pbr` は無視されます（デフォルト: True）。 | BOOLEAN | 任意 | true / false |
| `pbr` | PBR マテリアルマップ（ベースカラー、メタリック、ラフネス、ノーマル）を生成するかどうか。`texture` が必要です。`texture` がオフの場合は強制的にオフになります（デフォルト: True）。 | BOOLEAN | 任意 | true / false |
| `image_seed` | 画像生成段階で使用するシード（デフォルト: 42）。 | INT | 任意 | 0〜2147483647 |
| `model_seed` | モデル生成段階で使用するシード（デフォルト: 42）。 | INT | 任意 | 0〜2147483647 |
| `texture_seed` | テクスチャ生成段階で使用するシード（デフォルト: 42）。 | INT | 任意 | 0〜2147483647 |
| `texture_quality` | 生成されるテクスチャの品質。detailed は HD テクスチャ、extreme は 8K Ultra テクスチャです（デフォルト: standard）。 | COMBO | 任意 | "standard"<br />"detailed"<br />"extreme" |
| `face_limit` | 最大面数。-1 を指定すると、Tripo が適応的に選択します（v3.x の standard では約140万面、detailed では約200万面）。Tripo は v2.5 では 500,000、クアッドメッシュでは 150,000 に自動的にクランプします（デフォルト: -1）。 | INT | 任意 | -1〜2000000 |
| `quad` | クアッドメッシュ出力。Tripo はクアッドメッシュを FBX として提供するため、結果は FBX 出力に格納され、GLB 出力は空のままになります（デフォルト: False）。 | BOOLEAN | 任意 | true / false |
| `ジオメトリ品質` | 生成されるジオメトリの品質（デフォルト: standard）。 | COMBO | 任意 | "standard"<br />"detailed" |
| `smart_low_poly` | クリーンでハンドクラフト風のトポロジーを持つローポリメッシュ（500〜20,000面、クアッドでは500〜10,000面）。単純な被写体に最適です。複雑な被写体は失敗することがあります（デフォルト: False）。 | BOOLEAN | 任意 | true / false |
| `auto_size` | テクスチャ付きモデルをメートル単位の実世界サイズにスケールします。Tripo はサイズをモデルのシーントランスフォームとして保存し、モデルの変換、リギング、またはリターゲティング時に焼き込みます。テクスチャなしでは無視されます（デフォルト: True）。 | BOOLEAN | 任意 | true / false |

**注記：**
- `prompt` パラメータは必須です。空のプロンプトを指定すると、ノードはエラーを発生させます。
- `pbr` には `texture` が必要です。`texture` がオフの場合、ノードは `pbr` を強制的にオフにし、その値を無視します。`auto_size` も `texture` がない場合は効果がありません。
- `smart_low_poly` が有効で、`face_limit` が -1 以外の値に設定されている場合、面数の制限は三角形出力では 500〜20,000、`quad` が有効な場合は 500〜10,000 の範囲内でなければなりません。そうでない場合、ノードはエラーを発生させます。
- `quad` が有効な場合、生成されたクアッドメッシュは FBX として提供されるため、FBX 出力にデータが格納され、GLB 出力は空のままになります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `モデルファイル` | 生成された 3D モデルファイル。後方互換性のためだけに保持されています。 | STRING |
| `モデルタスクID` | モデル生成処理の一意のタスク識別子。 | MODEL_TASK_ID |
| `GLB` | GLB 形式の生成された 3D モデル。`quad` が有効な場合は空になります。 | FILE3DGLB |
| `FBX` | FBX 形式の生成された 3D モデル。`quad` が有効な場合にのみデータが格納されます。 | FILE3DFBX |
