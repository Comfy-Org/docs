Tripo: Image to Multiview の結果のビューを、ビューごとに個別のテキスト指示を使用して編集します。指示のないビューは変更されません。編集済みの画像は、3Dモデルを作成するために Tripo: Multiview to Model に接続することを想定しています。編集済みのマルチビューセットは再度編集できません。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `multiview_task_id` | 編集するビューの基になる Tripo: Image to Multiview 結果のタスクID。Tripo: Image to Multiview ノードから取得する必要があります。 | MULTIVIEW_TASK_ID | はい | タスクID |
| `front_prompt` | 正面ビューに適用する編集を記述したテキスト指示。空の場合、正面ビューは変更されません。デフォルト: 空文字列。 | STRING | いいえ | 複数行テキスト |
| `left_prompt` | 左ビューに適用する編集を記述したテキスト指示。空の場合、左ビューは変更されません。デフォルト: 空文字列。 | STRING | いいえ | 複数行テキスト |
| `back_prompt` | 背面ビューに適用する編集を記述したテキスト指示。空の場合、背面ビューは変更されません。デフォルト: 空文字列。 | STRING | いいえ | 複数行テキスト |
| `right_prompt` | 右ビューに適用する編集を記述したテキスト指示。空の場合、右ビューは変更されません。デフォルト: 空文字列。 | STRING | いいえ | 複数行テキスト |

注: 4つのプロンプト（`front_prompt`、`left_prompt`、`back_prompt`、`right_prompt`）のうち少なくとも1つは空でないテキストを含む必要があります。空白のみのテキストは空として扱われ、すべてのプロンプトが空の場合、ノードはエラーを発生させます。

注: 編集指示があるビューごとに約0.05 USDのコストがかかります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `front` | 編集済みの正面ビュー画像。 | IMAGE |
| `left` | 編集済みの左ビュー画像。 | IMAGE |
| `back` | 編集済みの背面ビュー画像。 | IMAGE |
| `right` | 編集済みの右ビュー画像。 | IMAGE |
