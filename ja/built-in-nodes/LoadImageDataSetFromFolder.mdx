このノードは、ComfyUI のメイン入力ディレクトリ内で選択したサブフォルダから複数の画像を読み込み、それらをリストとして返します。選択したフォルダをスキャンして PNG、JPG、JPEG、WEBP 形式の画像ファイルを検出するため、バッチ処理や画像データセットの準備に役立ちます。

## 入力

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `フォルダ` | 画像を読み込むフォルダです。選択肢は、ComfyUI のメイン入力ディレクトリ内に存在するサブフォルダです。 | COMBO | はい | Multiple options available |

注意：選択したフォルダは、ComfyUI のメイン入力ディレクトリのサブフォルダである必要があります。その外部を指す値（例えば、`..`、絶対パス、ドライブレター、シンボリックリンクの使用など）は拒否されます。読み込まれるのは拡張子が .png、.jpg、.jpeg、.webp のファイルのみで、拡張子のチェックは大文字と小文字を区別しません。読み込まれた画像は RGB に変換され、0～1 の範囲にスケーリングされます。選択したフォルダに有効な画像ファイルが含まれていない場合、このノードはエラーを発生させます。このノードは実験的としてマークされています。

## 出力

| Output Name | Description | Data Type |
| --- | --- | --- |
| `images` | 読み込まれた画像のリストです。このノードは、選択したフォルダ内で見つかったすべての有効な画像ファイル（PNG、JPG、JPEG、WEBP）を読み込みます。 | IMAGE |
