このノードは、PixVerse V6 モデルを使用して入力画像をアニメーション化し、動画を返します。オプションでネイティブ音声トラックも付与できます。出力動画は入力画像のアスペクト比を維持します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | アニメーション化する入力画像。 | IMAGE | はい | Single image |
| `モデル` | モデルと生成設定。 | DYNAMIC_COMBO | はい | "PixVerse V6" |

### PixVerse V6 入力

これらの設定は、"PixVerse V6" モデルが選択されているときに表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 動画生成用のプロンプト（デフォルト: 空）。 | STRING | はい | 1 〜 5000 characters |
| `quality` | 出力解像度。長辺を設定します。360p は 640px、540p は 1024px、720p は 1280px、1080p は 1920px です（デフォルト: "720p"）。 | COMBO | はい | "360p"<br />"540p"<br />"720p"<br />"1080p" |
| `duration_seconds` | 生成される動画の長さ（秒）（デフォルト: 5）。 | INT | はい | 1 〜 15 |
| `generate_audio` | 動画と一緒にネイティブ音声トラックを生成します（デフォルト: true）。 | BOOLEAN | はい | true or false |
| `multi_clip` | モデルに、動画を1つの連続したテイクではなく複数のショットに分割させます（デフォルト: false）。 | BOOLEAN | はい | true or false |
| `seed` | 動画生成用のシード。PixVerse はこれを記録しますが、そこから実行を再現することはありません（デフォルト: 42、生成後のコントロールは有効です）。 | INT | はい | 0 〜 2147483647 |
| `negative_prompt` | 動画内で望ましくない要素の任意のテキスト記述（デフォルト: 空）。 | STRING | いいえ | 最大 2048 文字 |
| `style` | 動画全体に適用される任意のビジュアルスタイル（デフォルト: なし）。 | COMBO | いいえ | Multiple options available (PixVerse V6 style presets) |

注記: プロンプトには少なくとも1つの空白以外の文字を含める必要があり、最大5000文字までです。ネガティブプロンプトを指定する場合は、最大2048文字までにする必要があります。出力動画は常に入力画像のアスペクト比と一致するため、アスペクト比の設定は不要です。入力画像は1枚のみ受け付けます。PixVerse は、コンテンツモデレーションに失敗した場合、プロバイダーアカウントのクレジットが不足している場合、または同時生成の最大数がすでに実行中である場合に、リクエストを拒否することがあります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | 生成された動画。`generate_audio` が有効な場合はネイティブ音声トラックを含みます。アスペクト比は入力画像と一致します。 | VIDEO |
