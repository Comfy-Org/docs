このノードは、PixVerse V6 モデルを使用して入力画像をアニメーション化し、オプションでネイティブのオーディオトラックを含むビデオを返します。出力ビデオは、入力画像のアスペクト比を維持します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|------|---------|------|------|
| `モデル` | モデルと生成設定です。 | DYNAMIC_COMBO | はい | "PixVerse V6" |
| `画像` | アニメーション化する入力画像です。 | IMAGE | はい | 単一画像 |

### PixVerse V6 入力

これらの設定は、「PixVerse V6」モデルが選択されたときに表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|------|---------|------|------|
| `prompt` | 動画生成のためのプロンプトです（デフォルト: 空）。 | STRING | はい | 1〜5000文字 |
| `quality` | 出力解像度です。長辺を設定します: 360p は 640px、540p は 1024px、720p は 1280px、1080p は 1920px（デフォルト: "720p"）。 | COMBO | はい | "360p"<br />"540p"<br />"720p"<br />"1080p" |
| `duration_seconds` | 生成される動画の長さ（秒単位）です（デフォルト: 5）。 | INT | はい | 1〜15 |
| `generate_audio` | 動画と一緒にネイティブのオーディオトラックを生成します（デフォルト: true）。 | BOOLEAN | はい | true or false |
| `multi_clip` | モデルに、1回の連続テイクではなく、動画を複数のショットにカットさせます（デフォルト: false）。 | BOOLEAN | はい | true or false |
| `seed` | 動画生成のシードです。PixVerse はそれを記録しますが、それから実行を再現することはありません（デフォルト: 42、生成後のコントロールが有効）。 | INT | はい | 0〜2147483647 |
| `negative_prompt` | 動画内の望ましくない要素に関する任意のテキスト説明です（デフォルト: 空）。 | STRING | いいえ | 最大2048文字 |
| `style` | 動画全体に適用される任意の視覚スタイルです（デフォルト: なし）。 | COMBO | いいえ | 複数のオプションあり（PixVerse V6 スタイルプリセット） |

注: プロンプトには、空白以外の文字が少なくとも1文字以上、最大5000文字まで含まれている必要があります。ネガティブプロンプトを指定する場合、最大2048文字までです。出力ビデオは常に入力画像のアスペクト比に一致するため、アスペクト比の設定は不要です。受け付けられる入力画像は1枚のみです。PixVerse は、コンテンツモデレーションに失敗した場合、プロバイダーアカウントのクレジットが不足している場合、または同時生成の最大数がすでに実行されている場合に、リクエストを拒否することがあります。

## 出力

| 出力名 | 説明 | データ型 |
|--------|------|---------|
| `video` | 生成されたビデオです。`generate_audio` が有効な場合は、ネイティブのオーディオトラックも含まれます。アスペクト比は入力画像に一致します。 | VIDEO |
