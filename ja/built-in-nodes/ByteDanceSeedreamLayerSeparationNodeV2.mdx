ByteDance Seedream 5.0 Layer Separation は、画像を背景プレートと最大16個の再配置可能な透明レイヤーに分解します。各レイヤーにはスタッキング順序、バウンディングボックス、名前、説明があります。背景、マスク付きのレイヤーごとの画像、配置ボックス、すぐに編集できるレイヤースタックを返します。`model` セレクターで Seedream 5.0 Pro と、より高速な Seedream 5.0 Flash を選択できます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 分離に使用する Seedream モデル。"seedream 5.0 pro"（デフォルト）は最高の分離品質を提供し、`prompt_optimization` コントロールも公開します。"seedream 5.0 flash" はより高速で安価ですが、プロンプト最適化コントロールはありません。 | DYNAMIC_COMBO | はい | "seedream 5.0 pro"<br />"seedream 5.0 flash" |

### Seedream 5.0 Pro および 5.0 Flash 入力

これらの入力は両方のモデルで使用できます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 分離する画像。画像はちょうど1枚で、少なくとも512x512ピクセル、アスペクト比は1:16から16:1の範囲である必要があります。約4MPを超える入力はアップロード前にダウンスケールされます。 | IMAGE | はい | 単一画像 |
| `prompt` | 画像をどのように分離するか。空のままにすると、主要な要素を自動検出してすべて分離します。自然言語で要素を記述して分離を制御するか、`<bbox>left top right bottom</bbox>` タグ（0～1000のパーミル座標）で正確な領域を指定します。デフォルト：空文字列。 | STRING | はい | 複数行テキスト |
| `size` | 出力解像度レベル。"auto" は入力画像サイズに従います（1K～2Kの範囲にクランプ）。デフォルト："auto"。 | COMBO | はい | "auto"<br />"1K"<br />"1.5K"<br />"2K" |
| `seed` | 生成に使用するシード。デフォルト：42。 | INT | はい | 0～2147483647 |
| `watermark` | 画像に「AI generated」ウォーターマークを追加するかどうか。デフォルト：false。 | BOOLEAN | はい | false<br />true |
| `crop_layers` | レイヤー/マスクのバッチ出力のジオメトリ（layer_stack は影響を受けず、常にタイトです）。フルキャンバス：各レイヤーはベースサイズのキャンバス上にそのバウンディングボックス位置で配置されます。ImageCompositeMasked で直接再合成できます。最小サイズ：各レイヤーはバウンディングボックスにクロップされます（バッチ処理用に最大レイヤーまでパディング）。はるかに小さいテンソルになります。bboxes 出力を使用して Layers From Bounding Boxes で配置を再構築してください。デフォルト：false（フルキャンバス）。 | BOOLEAN | はい | false（フルキャンバス）<br />true（最小サイズ） |

### Seedream 5.0 Pro 専用入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt_optimization` | プロンプト最適化モード："standard" はより高品質、"fast" はより短い生成時間。Seedream 5.0 Pro でのみ使用できます。デフォルト："standard"。 | COMBO | はい | "standard"<br />"fast" |

**注：** 入力 `image` は単一画像である必要があり、バッチはサポートされていません。画像は少なくとも512x512ピクセルで、アスペクト比は1:16から16:1の範囲である必要があります。Seedream 5.0 Flash には `prompt_optimization` 入力がありません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `base_image` | レイヤーが重なるベース画像（背景プレート）。 | IMAGE |
| `base_mask` | ベース画像の透明性（1 = 透明、LoadImage の規約）。現在は常に完全不透明です。 | MASK |
| `layers` | 下から上へ並んだ透明レイヤー。フルキャンバスモード：ベースサイズの黒いキャンバス上にそのバウンディングボックス位置で配置されます。最小サイズモード：バウンディングボックスにクロップされ、左上を基準にアンカーされ、最大レイヤーまでパディングされます。 | IMAGE |
| `masks` | レイヤーごとの透明性。layers バッチとインデックスが対応します（1 = 透明、LoadImage の規約）。ImageCompositeMasked 形式の合成では、先に InvertMask を追加してください。 | MASK |
| `bboxes` | レイヤーごとに1つの配置ボックス。layers バッチとインデックスが対応します（両方と masks を Layers From Bounding Boxes に入力すると、レイヤーごとの配置を再構築できます）：`{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`。`content_rect = [left, top, width, height]` は、そのレイヤー自身のフレーム内におけるコンテンツ領域です。これは、ボックス位置にそのオフセットを加えた位置でキャンバス上に配置されます。 | BOUNDING_BOX |
| `layer_stack` | Create Layered Image 用のすぐに編集できるレイヤードキュメント：ベースプレートと、各要素を独自の名前付き、タイトクロップされたレイヤーとして、真の位置とスタッキング順序で含みます。直接接続するか、Add Layer で拡張できます。 | LAYERS |
