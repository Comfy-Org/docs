Cosmos Predict2 の画像から動画へのワークフロー用の動画潜在変数を作成します。このノードは、指定されたサイズと長さの空の動画潜在変数を生成することも、エンコード済みの開始画像および/または終了画像をシーケンスに挿入して、生成時にそれらのフレームが保持されるようにすることもできます。提供された画像は、要求された `width` と `height` にリサイズされ、提供された VAE でエンコードされた後、潜在変数シーケンスの先頭および/または末尾に配置されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `vae` | 開始画像と終了画像を潜在空間にエンコードするために使用される VAE モデル | VAE | はい | - |
| `width` | 出力動画の幅（ピクセル単位、デフォルト: 848、16 の倍数である必要があります） | INT | はい | 16～MAX_RESOLUTION |
| `height` | 出力動画の高さ（ピクセル単位、デフォルト: 480、16 の倍数である必要があります） | INT | はい | 16～MAX_RESOLUTION |
| `length` | 動画シーケンス内のフレーム数（デフォルト: 93） | INT | はい | 1～MAX_RESOLUTION |
| `batch_size` | 生成する動画シーケンスの数（デフォルト: 1） | INT | はい | 1～4096 |
| `start_image` | 動画シーケンスの任意の開始画像 | IMAGE | いいえ | - |
| `end_image` | 動画シーケンスの任意の終了画像 | IMAGE | いいえ | - |

**注記:** `start_image` も `end_image` も指定されていない場合、このノードは要求されたサイズと長さの空の潜在変数を返すだけです。片方または両方の画像が指定された場合、それらは `width` と `height` にリサイズされ、`vae` でエンコードされて、潜在変数シーケンスの先頭および/または末尾に配置されます。対応する領域はノイズマスク内でマークされ、生成時に保持されます。エンコードされた潜在変数は Wan 2.1 の潜在形式に変換され、結果の潜在変数とマスクは `batch_size` 回繰り返されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `LATENT` | 生成された動画潜在変数。`samples`（動画潜在変数シーケンス）を含み、`start_image` または `end_image` の少なくとも一方が指定された場合は、生成時に保持すべきフレームを示す `noise_mask` も含みます | LATENT |
