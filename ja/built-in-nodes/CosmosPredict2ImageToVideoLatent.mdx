CosmosPredict2ImageToVideoLatent は、画像から動画生成用のビデオ潜在表現を作成します。空白のビデオ潜在表現を生成したり、開始画像と終了画像を組み込んで、指定した寸法と長さのビデオシーケンスを作成できます。このノードは、ビデオ処理に適した潜在空間フォーマットへの画像のエンコードを処理します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `vae` | 画像を潜在空間にエンコードするために使用されるVAEモデル | VAE | はい | - |
| `width` | 出力ビデオの幅（ピクセル単位）(デフォルト: 848、16で割り切れる必要があります) | INT | はい | 16 to MAX_RESOLUTION |
| `height` | 出力ビデオの高さ（ピクセル単位）(デフォルト: 480、16で割り切れる必要があります) | INT | はい | 16 to MAX_RESOLUTION |
| `length` | ビデオシーケンス内のフレーム数（デフォルト: 93、ステップ: 4） | INT | はい | 1 to MAX_RESOLUTION |
| `batch_size` | 生成するビデオシーケンスの数（デフォルト: 1） | INT | はい | 1〜4096 |
| `start_image` | ビデオシーケンス用の開始画像（オプション） | IMAGE | いいえ | - |
| `end_image` | ビデオシーケンス用の終了画像（オプション） | IMAGE | いいえ | - |

**注記:** `start_image` と `end_image` の両方が指定されていない場合、ノードは空白のビデオ潜在表現を生成します。一方または両方の画像が指定された場合、それらは `width` と `height` にリサイズされ、潜在空間にエンコードされて、ビデオシーケンスの先頭および/または末尾に配置されます。対応する領域はノイズマスク内でマークされ、生成中に保持されます。結果の潜在表現とマスクは `batch_size` 回繰り返されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `samples` | 生成されたビデオ潜在表現。エンコードされたビデオシーケンスを含みます。 | LATENT |
| `noise_mask` | 生成中に潜在表現のどの部分を保持すべきかを示すマスク。`start_image` または `end_image` の少なくとも一方が指定された場合にのみ存在します。 | LATENT |
