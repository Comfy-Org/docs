Wan22FunControlToVideo ノードは、Wan ビデオモデルを使用したビデオ生成のために、コンディショニングデータと空の潜在テンソルを準備します。オプションの参照画像と制御ビデオを潜在空間にエンコードし、それらを positive および negative コンディショニングに付加し、要求されたビデオに適した空間次元と時間次元を持つゼロ埋めされた潜在テンソルを作成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ポジティブ` | ビデオ生成を誘導するための positive コンディショニング入力 | CONDITIONING | はい | - |
| `ネガティブ` | ビデオ生成を誘導するための negative コンディショニング入力 | CONDITIONING | はい | - |
| `vae` | 画像を潜在空間にエンコードするために使用される VAE モデル | VAE | はい | - |
| `幅` | 出力ビデオの幅（ピクセル単位、デフォルト: 832、ステップ: 16） | INT | はい | 16～MAX_RESOLUTION |
| `高さ` | 出力ビデオの高さ（ピクセル単位、デフォルト: 480、ステップ: 16） | INT | はい | 16～MAX_RESOLUTION |
| `長さ` | ビデオシーケンス内のフレーム数（デフォルト: 81、ステップ: 4） | INT | はい | 1～MAX_RESOLUTION |
| `バッチサイズ` | 生成するビデオシーケンスの数（デフォルト: 1） | INT | はい | 1～4096 |
| `参照画像` | 生成のための視覚的ガイダンスを提供するオプションの参照画像 | IMAGE | いいえ | - |
| `制御動画` | 生成プロセスを誘導するオプションの制御ビデオ | IMAGE | いいえ | - |

**注:** `length` パラメータは 4 フレーム単位で処理され、ノードは潜在空間を構築する際に時間スケーリングを自動的に適用します。`ref_image` が指定された場合、その最初のフレームのみがエンコードされ（`width` x `height` にリサイズされます）、参照潜在としてコンディショニングに付加されます。`control_video` が指定された場合、`length` フレームにトリミングされ、リサイズ、エンコードされ、コンディショニングで使用される concat 潜在に配置されます。連結された潜在はチャネル次元に沿って複製され、そのチャネルレイアウトは VAE の潜在チャネル数に依存します（48 チャネルの場合は Wan 2.2 形式、それ以外の場合は Wan 2.1 形式）。`start_image` パラメータは実行ロジックで参照されますが、ノードの入力スキーマには公開されていないため、ノードインターフェイスから設定できません。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | ビデオ固有の潜在データが追加された positive コンディショニング。concat 潜在、マスク、およびオプションの参照潜在を含みます | CONDITIONING |
| `negative` | ビデオ固有の潜在データが追加された negative コンディショニング。concat 潜在、マスク、およびオプションの参照潜在を含みます | CONDITIONING |
| `latent` | ビデオ生成用に準備された空の潜在テンソル。バッチサイズ、潜在チャネル数、length、height、width に応じたサイズです | LATENT |
