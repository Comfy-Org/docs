Wan22FunControlToVideo ノードは、Wan ビデオモデルを使用したビデオ生成用に、条件付けデータと空の潜在テンソルを準備します。オプションの参照画像と制御ビデオを潜在空間にエンコードし、それらをポジティブ条件付けとネガティブ条件付けに付加し、要求されたビデオに適した空間的・時間的次元を持つゼロ埋めされた潜在テンソルを作成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ポジティブ` | ビデオ生成を導くためのポジティブ条件付け入力です。 | CONDITIONING | はい | - |
| `ネガティブ` | ビデオ生成を導くためのネガティブ条件付け入力です。 | CONDITIONING | はい | - |
| `vae` | 画像を潜在空間にエンコードするために使用される VAE モデルです。 | VAE | はい | - |
| `幅` | 出力ビデオの幅（ピクセル単位）です（デフォルト: 832、ステップ: 16）。 | INT | はい | 16 から MAX_RESOLUTION |
| `高さ` | 出力ビデオの高さ（ピクセル単位）です（デフォルト: 480、ステップ: 16）。 | INT | はい | 16 から MAX_RESOLUTION |
| `長さ` | ビデオシーケンスのフレーム数です（デフォルト: 81、ステップ: 4）。 | INT | はい | 1 から MAX_RESOLUTION |
| `バッチサイズ` | 生成するビデオシーケンスの数です（デフォルト: 1）。 | INT | はい | 1 から 4096 |
| `参照画像` | 生成のための視覚的なガイダンスを提供するオプションの参照画像です。 | IMAGE | いいえ | - |
| `制御動画` | 生成プロセスを導くオプションの制御ビデオです。 | IMAGE | いいえ | - |

**注記:** `length` パラメータは 4 フレーム単位で処理され、ノードは潜在空間を構築する際に時間的スケーリングを自動的に適用します。`ref_image` が指定された場合、その最初のフレームのみがエンコードされ、参照潜在変数として条件付けに付加されます。`control_video` が指定された場合、`length` フレームにトリミングされ、エンコードされて、条件付けで使用される連結潜在変数に配置されます。`start_image` パラメータは実行ロジック内で参照されていますが、ノードの入力スキーマには公開されていません。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `ポジティブ` | 連結潜在変数、マスク、およびオプションの参照潜在変数を含む、ビデオ固有の潜在データが追加されたポジティブ条件付けです。 | CONDITIONING |
| `ネガティブ` | 連結潜在変数、マスク、およびオプションの参照潜在変数を含む、ビデオ固有の潜在データが追加されたネガティブ条件付けです。 | CONDITIONING |
| `潜在変数` | バッチサイズ、潜在チャンネル数、長さ、高さ、幅に基づいてサイズ設定された、ビデオ生成用に準備された空の潜在テンソルです。 | LATENT |
