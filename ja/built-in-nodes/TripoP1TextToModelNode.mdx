Tripo P1 text-to-3D です。このノードは、Tripo P1 API を使用してテキスト記述から 3D モデルを生成します。安定したトポロジを持つローポリゴンでゲーム向けのメッシュの作成に最適化されており、リアルタイムアプリケーションに適しています。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `出力モード` | 生成されるモデルにジオメトリのみを含めるか、カラー/PBR テクスチャも含めるかを制御します。「Geometry only」はテクスチャなしのメッシュを返します。「Textured」はカラー/PBR マップを追加し、以下のテクスチャオプションを表示します。 | DYNAMIC_COMBO | はい | `"Geometry only"`<br />`"Textured"` |
| `プロンプト` | 生成したい 3D モデルのテキスト記述です。最大 1024 文字です。必須で、空にはできません。 | STRING | はい | 最大 1024 文字 |
| `ネガティブプロンプト` | 生成されるモデルに含めたくない内容のテキスト記述です。最大 255 文字です。デフォルト: 未設定。 | STRING | いいえ | 最大 255 文字 |
| `画像シード` | ランダム性を制御するために使用されるシード値です。デフォルト: 42。 | INT | いいえ | 0～2147483647 |
| `面数制限` | 目標フェイス数（48～20000）。-1 を指定すると Tripo が適応的に選択します。デフォルト: -1。 | INT | いいえ | -1～20000 |
| `モデルシード` | ランダム性を制御するために使用されるシード値です。デフォルト: 42。 | INT | いいえ | 0～2147483647 |
| `自動サイズ調整` | 出力を現実世界のメートルに近似するようスケーリングします。デフォルト: False。 | BOOLEAN | いいえ | True / False |
| `UVエクスポート` | 生成中に UV 展開を行います。ジオメトリのみの実行を高速化するにはオフにしてください。デフォルト: True。 | BOOLEAN | いいえ | True / False |

### Geometry only 入力

`output_mode` が `"Geometry only"` に設定されている場合、追加の入力はありません。このモードでは、テクスチャ関連のパラメータは Tripo に送信されません。

### Textured 入力

これらの入力は、`output_mode` が `"Textured"` に設定されている場合にのみ表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `pbr` | PBR マップを含めます。オンの場合、ベーステクスチャも強制的にオンになります。デフォルト: True。 | BOOLEAN | はい | True / False |
| `texture_quality` | テクスチャ品質プリセット。detailed = HD テクスチャ、extreme = 8K Ultra テクスチャ。デフォルト: "standard"。 | COMBO | はい | `"standard"`<br />`"detailed"`<br />`"extreme"` |
| `texture_seed` | テクスチャ生成用のシード値で、ランダム性を制御するために使用されます。デフォルト: 42。 | INT | はい | 0～2147483647 |
