Load 3D (Advanced) ノードは、ComfyUI の `input/3d` ディレクトリから3Dモデルファイルを読み込み、3Dビューアのビューポート状態で取得されたモデルの配置とカメラ情報とともに、モデルデータを提供します。一般的な3Dファイル形式をサポートし、ビューポートのレンダリング幅と高さをピクセル単位で設定できます。このノードは実験的です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_file` | 読み込む3Dモデルファイル。"none" を選択するとモデルファイルの読み込みをスキップします。ウィジェットからファイルをアップロードすることもできます。 | COMBO | はい | `"none"`<br />`input/3d` ディレクトリで利用可能な3Dモデルファイル |
| `viewport_state` | 3Dビューアからのカメラ情報とモデル情報を含む現在のビューポート状態。 | LOAD3D | はい | - |
| `width` | ビューポートのレンダリング幅（ピクセル単位、デフォルト: 1024）。 | INT | はい | 最小: 1<br />最大: 4096<br />デフォルト: 1024<br />ステップ: 1 |
| `height` | ビューポートのレンダリング高さ（ピクセル単位、デフォルト: 1024）。 | INT | はい | 最小: 1<br />最大: 4096<br />デフォルト: 1024<br />ステップ: 1 |

**パラメータに関する注意事項:**
- `model_file` パラメータには、以下の拡張子を持つファイルのみが一覧表示されます: .gltf, .glb, .obj, .fbx, .stl
- ファイルは ComfyUI インストールの `input/3d` ディレクトリに配置する必要があります。サブフォルダも検索され、ファイルパスは入力ディレクトリからの相対パスで表示されます
- `model_file` が "none" の場合、モデルデータは読み込まれず、`model_3d` 出力は空になります
- `model_file` が存在しないファイルに設定されている場合、ノードはバリデーションエラーを返します: "Invalid 3D model file: &#123;model_file&#125;"
- `viewport_state` が有効なビューポート状態オブジェクトでない場合、空として扱われるため、`model_3d_info` は空のリストになり、`camera_info` は空で返されます

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_3d` | 読み込まれた3Dモデルファイル（glb/obj/stlなど）。モデルファイルが選択されていない場合は空になります。 | FILE3DANY |
| `model_3d_info` | シーン内の各モデルの配置：位置、回転、スケール（Y-upワールド空間）。 | LOAD3DMODELINFO |
| `camera_info` | ビューポートカメラ情報：位置、注視点、ズーム、種類。 | LOAD3DCAMERA |
| `width` | ビューポートのレンダリング幅（ピクセル単位）。 | INT |
| `height` | ビューポートのレンダリング高さ（ピクセル単位）。 | INT |
