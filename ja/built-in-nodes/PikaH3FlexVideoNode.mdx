このノードは、テキストプロンプトから同期音声付きの動画を生成します。オプションで最初のフレーム、最後のフレーム、またはその両方をアンカーとして使用できます。Pika H3 Flex は Pika のポストトレーニング済み MiniMax H3 モデルです。映像とその音声を 1 パスでレンダリングし、解像度、アスペクト比、長さを設定できます。フレームを接続しない場合、ノードはテキストから動画を実行します。フレームを接続すると、画像から動画に切り替わります。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 動画内で何が起こるかと、希望する音声を含めて指定します。空にできません。デフォルト: ""（空文字列）。 | STRING | はい | 1～8000 文字 |
| `first_frame` | 開始フレームとして使用するオプションの画像です。接続すると、テキストから動画ではなく画像から動画を実行します。 | IMAGE | いいえ | - |
| `last_frame` | 終了フレームとして使用するオプションの画像です。`first_frame` と併用することも、単独で使用することもできます。 | IMAGE | いいえ | - |
| `resolution` | 出力解像度。`"1080p"` 以上は 768p でレンダリングし、1 回アップスケールします。同じシードでも 480p では異なる動画になります。デフォルト: `"768p"`。 | COMBO | はい | `"480p"`<br />`"768p"`<br />`"1080p"`<br />`"2k"`<br />`"4k"` |
| `aspect_ratio` | 出力アスペクト比。`"auto"` は最初に接続されたフレームに従い、それ以外の場合はプロンプトに従います。デフォルト: `"auto"`。 | COMBO | はい | `"auto"`<br />`"21:9"`<br />`"16:9"`<br />`"3:2"`<br />`"4:3"`<br />`"5:4"`<br />`"1:1"`<br />`"4:5"`<br />`"3:4"`<br />`"2:3"`<br />`"9:16"`<br />`"9:21"` |
| `duration` | クリップの長さ（秒）。出力の長さはフレームグリッドに従います。5 秒は 124 フレームになり、約 5.17 秒です。デフォルト: 5。 | INT | はい | 5～15 秒 |
| `rewrite_prompt` | Pika に最初にプロンプトを拡張させます。その場合、同じシードでも実行ごとに異なる動画が生成されます。デフォルト: False。 | BOOLEAN | はい | true<br />false |
| `seed` | サンプリング用のシード。`rewrite_prompt` がオフの場合、同じシードでは同じ動画が正確に再現されますが、同じシードでのローカル実行では異なる結果になります。デフォルト: 42。 | INT | はい | 0～2147483647 |

**制約事項:**

* プロンプトは 1～8000 文字の範囲である必要があります。
* 課金は選択した解像度とクリップの長さに基づき、出力の秒数単位で計算されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `VIDEO` | 同期音声付きの生成されたクリップ。 | VIDEO |
