3DメッシュのUVアトラスを生成します。メッシュ表面はチャートに分割され、各チャートは2次元に平坦化され、平坦化されたチャートは[0,1]のUVアトラスにパックされます。チャートのシーム上にある頂点は複製されるため、出力メッシュには入力メッシュよりも多くの頂点が含まれる場合があります。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | アンラップする入力メッシュです。単一のメッシュまたはメッシュのバッチを受け入れます。 | MESH | はい | — |
| `segmenter` | 使用するチャート化アルゴリズムです。`pec`: GPU上で高速な並列エッジ収縮チャート化を実行します。`adaptive`: CPU上で実行されるため低速です。（デフォルト: "pec"） | COMBO | はい | "pec"<br />"adaptive" |
| `resolution` | テクセル密度の自動スケーリング用の目標アトラス解像度です（0 = コンテンツにフィット）。（デフォルト: 1024） | INT | はい | 0 〜 8192 (ステップ 256) |
| `padding` | チャート間のテクセルパディングです。（デフォルト: 1） | INT | はい | 0 〜 16 |
| `weld_distance` | メッシュ範囲に対する一致頂点のマージ半径の比率です（0 = 自動）。三角形ごとのチャート（未結合の入力）が生成される場合は、約0.001まで上げてください。（デフォルト: 0.0） | FLOAT | はい | 0.0 〜 1.0 (ステップ 0.0001) |

注：入力メッシュに未結合の頂点が含まれる場合、ノードは面の隣接性が低いことを警告し、面ごとのUVチャートを生成することがあります。`weld_distance` を大きくすると、アンラップ前に一致する頂点がマージされます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `mesh` | [0,1]の範囲で生成されたUVアトラスを持つ入力メッシュです。シーム上の頂点は複製されるため、出力の頂点数は入力を超えることがあります。入力メッシュの頂点カラーとテクスチャは保持されます。 | MESH |
