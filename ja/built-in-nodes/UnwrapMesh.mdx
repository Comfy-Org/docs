3D メッシュの UV アトラスを生成します。サーフェスはチャートに分割され、各チャートは 2 次元に展開され、結果は [0,1] の UV アトラスにパックされます。チャートのシーム上の頂点は複製されるため、出力メッシュには入力メッシュよりも多くの頂点が含まれる場合があります。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 展開する入力メッシュ。単一メッシュまたはメッシュのバッチを受け入れます。 | MESH | はい | — |
| `segmenter` | 使用するチャート分割アルゴリズム。pec: GPU 上での高速な並列エッジ収縮チャート分割。adaptive: CPU、低速。（デフォルト: "pec"） | COMBO | はい | "pec"<br />"adaptive" |
| `resolution` | テクセル密度の自動スケールにおけるターゲットアトラス解像度（0 = コンテンツにフィット）。（デフォルト: 1024） | INT | はい | 0 ～ 8192（ステップ 256） |
| `padding` | チャート間のテクセルパディング。（デフォルト: 1） | INT | はい | 0 ～ 16 |
| `weld_distance` | メッシュ範囲に対する一致頂点のマージ半径（0 = 自動）。三角形ごとのチャート（未溶着入力）が生成される場合は、約 0.001 に引き上げてください。（デフォルト: 0.0） | FLOAT | はい | 0.0 ～ 1.0（ステップ 0.0001） |

注: 入力メッシュに未溶着の頂点（三角形スープ）が含まれている場合、ノードは面の隣接性が低いことを警告し、面ごとの UV チャートを生成することがあります。`weld_distance` を増やすと、展開前に一致する頂点がマージされます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `mesh` | 生成された [0,1] の UV アトラスを持つ入力メッシュ。シーム頂点は複製されるため、出力頂点数は入力メッシュの頂点数を超えることがあります。入力メッシュの頂点カラーとテクスチャは保持されます。 | MESH |
