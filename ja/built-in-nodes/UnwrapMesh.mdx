3DメッシュのUVアトラスを生成します。メッシュ表面はチャートに分割され、各チャートは2次元に平坦化され、平坦化されたチャートは[0,1]のUVアトラスにパッキングされます。チャートのシーム上の頂点は複製されます（チャートごとに1つのコピー、同じ位置、独自のUV）。そのため、出力メッシュの頂点数は入力メッシュより多くなる場合があり、出力の面数は入力と異なる場合があります。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 展開する入力メッシュ。単一のメッシュまたはメッシュのバッチを受け付けます。バッチは1項目ずつ処理されます。 | MESH | はい | — |
| `segmenter` | 使用するチャート分割アルゴリズム。`pec`: GPU上の高速な並列エッジ縮約チャート分割。`adaptive`: CPU、より低速。(デフォルト: "pec") | COMBO | はい | "pec"<br />"adaptive" |
| `resolution` | テクセル密度の自動スケール用のターゲットアトラス解像度（0 = コンテンツにフィット）。(デフォルト: 1024) | INT | はい | 0 〜 8192 （ステップ 256） |
| `padding` | チャート間のテクセルパディング。(デフォルト: 1) | INT | はい | 0 〜 16 |
| `weld_distance` | メッシュの広がりに対する割合としての一致頂点マージ半径（0 = 自動）。三角形ごとのチャートが生成される場合（未溶接の入力）、約0.001まで上げてください。(デフォルト: 0.0) | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.0001） |

注: 入力メッシュに未溶接の頂点が含まれている場合、ノードは面の隣接性が低いことを警告し、面ごとのUVチャートを生成することがあります。`weld_distance` を増やすと、展開前に一致する頂点がマージされます。縮退面（同じ頂点インデックスを再利用する面）は処理中に削除されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `mesh` | 入力メッシュに、[0,1]の範囲のUVアトラスを生成したもの。シーム頂点は複製されるため、出力頂点数は入力を超える場合があります。入力メッシュの頂点カラーとテクスチャは保持されます。 | MESH |
