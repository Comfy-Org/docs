このノードは、Quiver AI のベクトル化モデルを使用して、ラスター画像をスケーラブルベクターグラフィックス（SVG）に変換します。画像を外部 API に送信し、API が処理した後、ベクトル化された結果を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | ベクトル化する入力画像。 | IMAGE | はい | N/A |
| `auto_crop` | 主要な被写体に自動的にクロップします（デフォルト: False）。 | BOOLEAN | はい | True<br />False |
| `model` | SVG ベクトル化に使用するモデル。モデルを選択すると、そのモデルに固有の追加パラメータが表示されます：`target_size`（ピクセル単位の正方形リサイズターゲット。0 はソース画像のサイズを維持し、それ以外は 128～4096）、`temperature`、`top_p`、`presence_penalty`。 | DYNAMIC_COMBO | はい | `"arrow-2"`<br />`"arrow-2-telos"`<br />`"arrow-1.1"`<br />`"arrow-1.1-max"`<br />`"arrow-preview"` |
| `seed` | ノードを再実行する必要があるかどうかを決定するシード。実際の結果は、シード値に関係なく非決定的です。このパラメータには「生成後の制御」機能があります（デフォルト: 0）。 | INT | はい | 0 〜 2147483647 |
| `reasoning_effort` | モデルが描画前に費やす推論の量。レベルが高いほど詳細が向上しますが、より多くのトークンを消費します。Arrow 2 モデルでのみ使用されます（デフォルト: "high"）。 | COMBO | いいえ | `"low"`<br />`"medium"`<br />`"high"`<br />`"xhigh"` |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `SVG` | ベクトル化された SVG 出力。 | SVG |
