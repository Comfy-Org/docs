プレーンテキストで記述された別のオブジェクトに、画像内のオブジェクトを置き換えます。Bria のテキストガイドによる画像編集を使用します。Bria はフレーム全体を約 1 メガピクセルで再レンダリングするため、結果は入力とピクセル単位では位置合わせされません。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | 置き換えるオブジェクトを含む画像です。画像がアップロードされる前に、アルファチャンネルは破棄されます。 | IMAGE | はい | - |
| `指示` | 何を何に置き換えるか（例：「赤いリンゴを緑の洋ナシに置き換える」）。少なくとも 1 文字以上である必要があります。 | STRING | はい | 複数行テキスト; デフォルト: ""（空） |
| `シード` | Bria はここではシードを受け取らず、呼び出しごとに編集を再構想するため、繰り返し実行すると結果が異なる場合があります。この値は送信されません。これはこのノードのキャッシュキーを変更するだけであり、それ以外は同一のグラフがキャッシュされた結果を返す代わりに編集を再実行するようにします。 | INT | はい | 0 から 2147483647、ステップ 1; デフォルト: 42; 生成後の制御が有効 |

### モデレーション入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデレーション` | モデレーション設定です。「true」を選択すると、以下に示すモデレーションのサブオプションが表示されます。それ以外の場合は表示されません。 | DYNAMIC_COMBO | はい | `"false"`<br />`"true"` |
| `visual_input_moderation` | 入力画像のモデレーションを有効にします。`moderation` が "true" に設定されている場合にのみ使用できます。 | BOOLEAN | いいえ | `true` / `false`; デフォルト: false |
| `visual_output_moderation` | 生成された出力画像のモデレーションを有効にします。`moderation` が "true" に設定されている場合にのみ使用できます。 | BOOLEAN | いいえ | `true` / `false`; デフォルト: false |

注: `instruction` はリクエストが送信される前に検証され、少なくとも 1 文字以上を含む必要があります。`seed` の値は Bria に送信されません。これは、ノードが編集を再実行するか、キャッシュされた結果を返すかにのみ影響します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 記述されたオブジェクト置換が適用された、編集済みの画像です。 | IMAGE |
| `structured_prompt` | 編集済み画像の構造化された説明です。Bria FIBO Image Edit での後続の編集に使用します。 | STRING |
