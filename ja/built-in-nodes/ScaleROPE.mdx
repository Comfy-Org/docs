ScaleROPE ノードを使用すると、モデルの X、Y、T（時間）コンポーネントに個別のスケーリング係数とシフト係数を適用することで、モデルの Rotary Position Embedding（ROPE）を変更できます。これは、モデルの位置エンコーディング動作を調整するための高度な実験的ノードです。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | ROPE パラメータが変更されるモデルです。 | MODEL | はい | - |
| `X軸スケール` | ROPE の X コンポーネントに適用するスケーリング係数です（デフォルト: 1.0）。 | FLOAT | はい | 0.0 - 100.0 (step 0.1) |
| `X軸シフト` | ROPE の X コンポーネントに適用するシフト値です（デフォルト: 0.0）。 | FLOAT | はい | -256.0 - 256.0 (step 0.1) |
| `Y軸スケール` | ROPE の Y コンポーネントに適用するスケーリング係数です（デフォルト: 1.0）。 | FLOAT | はい | 0.0 - 100.0 (step 0.1) |
| `Y軸シフト` | ROPE の Y コンポーネントに適用するシフト値です（デフォルト: 0.0）。 | FLOAT | はい | -256.0 - 256.0 (step 0.1) |
| `時間軸スケール` | ROPE の T（時間）コンポーネントに適用するスケーリング係数です（デフォルト: 1.0）。 | FLOAT | はい | 0.0 - 100.0 (step 0.1) |
| `時間軸シフト` | ROPE の T（時間）コンポーネントに適用するシフト値です（デフォルト: 0.0）。 | FLOAT | はい | -256.0 - 256.0 (step 0.1) |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `model` | 新しい ROPE スケーリングパラメータとシフトパラメータが適用されたモデルです。 | MODEL |
