このノードは、ハイポリメッシュからローポリメッシュの UV レイアウトへ接空間法線マップをベイクし、デシメーション時に失われた表面ディテールをキャプチャします。UV 展開済みのローポリメッシュと、その元になったハイポリメッシュを接続すると、ノードは Apply Texture To Mesh の `normal_map` 入力にそのまま使用できる画像を出力します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | ベイクされたディテールを受け取る、UV 展開済みのローポリメッシュ。既存の UV が必要です。ノードが自動で UV 展開することはありません。 | MESH | はい | — |
| `high_poly` | 表面ディテールがローポリの UV レイアウトにベイクされるハイポリメッシュ。 | MESH | はい | — |
| `resolution` | 正方形の出力法線マップの辺の長さ（ピクセル単位、デフォルト: 1024）。 | INT | はい | 64 から 8192（ステップ 64） |
| `cage_distance` | サーフェス探索幅を、バウンディングボックスの対角線に対する割合で指定します。強いデシメーション下でパッチがずれる/欠ける場合は上げ、ギャップをまたいで拾ってしまう場合は下げます。デフォルト: 0.05。 | FLOAT | はい | 0.001 から 0.5（ステップ 0.001） |
| `ignore_backfaces` | テクセルから見て裏を向いているハイポリサーフェスをスキップし、隙間や閉鎖空間が反対側の壁を拾わないようにします。ハイポリのワインディングが一貫していない場合にのみ無効にしてください。デフォルト: true。 | BOOLEAN | はい | true / false |

注記: `low_poly` には UV 座標が必要です。UV がない場合、ノードは既存の UV レイアウトにベイクし、メッシュの UV 展開は行わないため、エラーを発生させます。`low_poly` がバッチの場合、各項目は順番にベイクされます。`high_poly` に 1 項目しか含まれていない場合、その項目はバッチ内のすべての項目で再利用されます。バッチ内の空のメッシュは警告付きでスキップされ、フラットなミッドグレー（0.5）の法線マップを生成します。ローポリの UV が [0,1] 範囲外にはみ出す場合、それらは一様に [0,1] にフィットされます（レイアウトがタイリング/UDIM に見える場合は警告が出ます）。そのため、ベイクと Apply Texture To Mesh は同じ UV を使用します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `normal_map` | ベイクされた接空間法線マップ（glTF/OpenGL +Y 規約）で、解像度 × 解像度の正方形 RGB 画像、値の範囲は [0,1] です。Apply Texture To Mesh の `normal_map` 入力に接続してください。 | IMAGE |
