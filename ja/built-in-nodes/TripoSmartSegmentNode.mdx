3Dモデルを意味のある部分に分割し、各部分に名前を付けます。既存のモデル（タスクIDで提供）をセグメント化するか、まず画像からモデルを生成してからセグメント化することができます。結果として得られる `segment task_id` は、Complete Mesh Parts、Retopology、Texture model、Convert model などの他の Tripo ノードで、Tripo: Segment Model の結果と同じように使用できます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `ソース` | 既存のモデルをセグメント化するか、画像からモデルを生成してセグメント化します。選択したオプションによって、表示される追加入力が決まります。 | DYNAMIC_COMBO | はい | `"model"`<br />`"image"` |

### モデル入力

`source` が `"model"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | GLB の結果です。クアッド（FBX）メッシュは、先に Tripo: Convert model (GLTF) を通す必要があります。 | MODEL_TASK_ID | はい | - |
| `granularity` | モデルをどの程度細かく部分に分割するか（デフォルト: `"medium"`）。 | COMBO | いいえ | `"coarse"`<br />`"medium"`<br />`"fine"` |
| `hint` | 探す部分の名前を指定する任意のテキスト。例: 「剣と鎧を装備したゲームキャラクター」（デフォルト: 空）。 | STRING | いいえ | - |

### 画像入力

`source` が `"image"` に設定されている場合に表示されます。Tripo はまず画像からモデルを生成し、その後セグメント化します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | セグメント化されるモデルを生成するために使用する画像。 | IMAGE | はい | - |
| `granularity` | モデルをどの程度細かく部分に分割するか（デフォルト: `"medium"`）。 | COMBO | いいえ | `"coarse"`<br />`"medium"`<br />`"fine"` |
| `hint` | 探す部分の名前を指定する任意のテキスト。例: 「剣と鎧を装備したゲームキャラクター」（デフォルト: 空）。 | STRING | いいえ | - |

**注意:**

- `granularity` と `hint` は両方の `source` オプションで共有され、任意です。`hint` を空のままにすると、サービスにヒントは送信されません。
- `source` が `"model"` の場合、GLB モデルのみを受け付けます。クアッド（FBX）メッシュなど他の形式は、先に Tripo: Convert model (GLTF) で変換する必要があります。
- タスクは終了状態に達するまでポーリングされます。所要時間の目安は約180秒です。Tripo が不完全なセグメント化結果を返した場合、ノードはエラーを報告します。
- 価格バッジ: `source` が `"image"` の場合で約0.85 USD、`source` が `"model"` の場合で約0.55 USD です（値は概算として表示されます）。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `segment task_id` | セグメント化タスクのタスクID。他の Tripo ノードへの入力として使用できます。 | SEGMENT_TASK_ID |
| `model task_id` | セグメント化されたモデル（画像から生成されたもの、またはインポートされたもの）。 | MODEL_TASK_ID |
| `GLB` | セグメント化された3Dモデルファイル。 | FILE3DGLB |
| `part_names` | 部分の名前をカンマ区切りにしたもの。 | STRING |
| `parts` | Tripo が検出した部分の説明。 | STRING |
| `mask` | セグメント化によって生成されたマスク画像。 | IMAGE |
