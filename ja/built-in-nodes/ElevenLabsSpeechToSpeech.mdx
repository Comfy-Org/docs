ElevenLabs Speech to Speech ノードは、入力オーディオファイルを別の音声に変換します。ElevenLabs API を使用して、元のコンテンツと感情的なトーンを保持したまま音声を変換します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 音声から音声への変換に使用するモデル。選択したモデルによって、以下に記載されている利用可能な音声設定が決まります。 | DYNAMIC_COMBO | はい | `eleven_multilingual_sts_v2`<br />`eleven_english_sts_v2` |
| `ターゲットボイス` | 変換のターゲットとなる音声。Voice Selector または Instant Voice Clone から接続します。 | CUSTOM | はい | - |
| `音声` | 変換するソースオーディオ。 | AUDIO | はい | - |
| `安定性` | 音声の安定性。値が低いほど感情表現の幅が広がり、値が高いほど一貫性が高まりますが、単調になる可能性があります（デフォルト: 0.5）。 | FLOAT | はい | 0.0 - 1.0 |
| `出力フォーマット` | オーディオ出力形式（デフォルト: "mp3_44100_192"）。 | COMBO | はい | `"mp3_44100_192"`<br />`"opus_48000_192"` |
| `シード` | 再現性のためのシード値（デフォルト: 0）。 | INT | はい | 0 - 4294967295 |
| `バックグラウンドノイズ除去` | オーディオ分離を使用して、入力オーディオから背景ノイズを除去します（デフォルト: False）。 | BOOLEAN | はい | - |

### eleven_multilingual_sts_v2 および eleven_english_sts_v2 入力

両モデルとも、以下の同じ音声設定を提供します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `speed` | 音声の速度。1.0 は通常、&lt;1.0 は遅い、>1.0 は速い（デフォルト: 1.0）。 | FLOAT | はい | 0.7 - 1.3 |
| `similarity_boost` | 類似性ブースト。値が高いほど、音声が元の音声により似てきます（デフォルト: 0.75）。 | FLOAT | はい | 0.0 - 1.0 |
| `use_speaker_boost` | 元の話者の音声への類似性をブーストします（デフォルト: False）。 | BOOLEAN | はい | - |
| `style` | スタイルの誇張。値が高いほどスタイル表現が強化されますが、安定性が低下する可能性があります（デフォルト: 0.0）。 | FLOAT | はい | 0.0 - 0.2 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `audio` | 指定された出力形式での変換後のオーディオファイル。 | AUDIO |
