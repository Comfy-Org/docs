互換性のある 2 つの MiniMax H3 モデルをコンポーネント単位でマージします。アーキテクチャの各部分ごとに個別の比率を指定できます。各比率は `model1` の割合であるため、あるモデルのパッチ投影とリファインメントブロックを維持しつつ、Transformer ブロックを別のモデルのものに置き換えられます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model1` | 1 つ目の MiniMax H3 モデルです。すべてのコンポーネントはこのモデルを起点とし、各比率によってそのコンポーネントのどれだけを代わりに `model2` から取得するかが決まります。 | MODEL | はい | - |
| `model2` | ブレンドするコンポーネントを供給する 2 つ目の MiniMax H3 モデルです。 | MODEL | はい | - |
| `video_patch_proj.` | 映像パッチ投影に対する `model1` の割合です（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |
| `audio_patch_proj.` | 音声パッチ投影に対する `model1` の割合です（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |
| `condition_proj.` | 条件付け投影に対する `model1` の割合です（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |
| `time_embedder.` | 時間埋め込みに対する `model1` の割合です（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |
| `token_refiner.blocks.0.` | 最初のトークンリファイナブロックに対する `model1` の割合です（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |
| `token_refiner.blocks.1.` | 2 番目のトークンリファイナブロックに対する `model1` の割合です（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |
| `token_refiner.final_norm.` | トークンリファイナの最終正規化に対する `model1` の割合です（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |
| `blocks.0.` から `blocks.49.` | 50 個の Transformer ブロックそれぞれに対する `model1` の割合です（各ブロックに 1 つのウィジェット、デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |
| `final_layer.norm.` | 最終層の正規化に対する `model1` の割合です（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |
| `final_layer.adaln_proj.` | 最終適応正規化投影に対する `model1` の割合です（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |
| `final_layer.video_out.` | 映像出力層に対する `model1` の割合です（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |
| `final_layer.audio_out.` | 音声出力層に対する `model1` の割合です（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ 0.01） |

1.0（デフォルト）の比率ではそのコンポーネントを完全に `model1` から保持し、0.0 では完全に `model2` から取得します。中間の値では 2 つをブレンドします。正規化統計など比率を持たないテンソルは、常に `model1` から取得されます。両方の入力は同じアーキテクチャの MiniMax H3 モデルである必要があります。そうでない場合、マージによって実行できないモデルが生成されます。
