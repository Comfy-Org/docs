Kling Image Generation Node は、テキストプロンプトから画像を生成し、参照画像をガイドとして使用するオプションも提供します。テキストの説明と参照設定に基づいて1つ以上の画像を生成し、生成された画像を出力として返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | ポジティブテキストプロンプト | STRING | はい | 最大500文字 |
| `ネガティブプロンプト` | ネガティブテキストプロンプト | STRING | はい | 最大500文字 |
| `画像タイプ` | 画像参照タイプの選択（上級設定）。参照画像を指定する場合に必要です。 | COMBO | はい | `"subject_reference"`<br />`"style_reference"` |
| `画像忠実度` | ユーザーがアップロードした画像の参照強度（デフォルト: 0.5、上級設定） | FLOAT | はい | 0.0 - 1.0 |
| `人物忠実度` | 被写体参照の類似度（デフォルト: 0.45、上級設定） | FLOAT | はい | 0.0 - 1.0 |
| `モデル名` | 画像生成用のモデル選択（デフォルト: "kling-v3"） | COMBO | はい | `"kling-v3"` |
| `アスペクト比` | 生成画像のアスペクト比（デフォルト: "16:9"） | COMBO | はい | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"`<br />`"21:9"`<br />`"9:21"` |
| `生成画像数` | 生成する画像数（デフォルト: 1） | INT | はい | 1 - 9 |
| `画像` | オプションの参照画像 | IMAGE | いいえ | - |
| `シード` | シードはノードの再実行を制御します。結果はシードに関係なく非決定的です（デフォルト: 0） | INT | いいえ | 0 - 2147483647 |

**パラメータの制約:**

- `image` パラメータはオプションです。参照画像を指定する場合、`image_type` パラメータによって、参照が被写体参照として使用されるか、スタイル参照として使用されるかが決まります。
- 参照画像が指定されていない場合、参照関連の設定（`image_type`、`image_fidelity`、`human_fidelity`）は結果に影響しません。
- `prompt` と `negative_prompt` の最大長は500文字です。
- `seed` パラメータはオプションであり、決定的な結果を保証しません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 入力パラメータに基づいて生成された画像。`n` が1より大きい場合、複数の画像がバッチとして返されます。 | IMAGE |
