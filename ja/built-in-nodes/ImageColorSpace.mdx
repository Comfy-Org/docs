ImageColorSpace ノードは、画像を sRGB（Rec.709）、リニア Rec.709、HDR（Rec.2020 HLG）、HDR PQ（Rec.2020 PQ）、HDR LogC3、リニア ACEScg、HDR ACEScct の色空間間で変換します。LogC3 は Rec.709 原色で EI 800 カーブを使用し、コードは [0, 1] にクランプされます。ACEScg は D60 白色点を持つシーンリニアな AP1 で、ACEScct はその対数エンコーディングであり、どちらもブラッドフォード適応によって D65 に変換されます。SDR 出力への変換時、または HDR PQ から HDR への変換時には、バッチ全体にわたる過剰な輝度をトーンマッピングし、色域外の色を圧縮します。リニア、ACEScg、ACEScct 出力、ならびにリニアから HDR への変換は、拡張値を保持します。HLG および PQ 出力は負のチャンネルをクリップします。変換は float32 で計算され、アルファチャンネルはそのまま通過します。

## 注意

- リニア 1.0 と ACEScg 1.0 は sRGB と同じ 203 nit の基準白色を使用します。HLG は 1000 nit の基準ディスプレイを使用します。
- リニア、ACEScg、ACEScct 出力は拡張値を保持します。リニアから HDR への変換は、トーンマッピングなしでハイライトを保持します。
- SDR 出力および PQ から HLG への変換は、バッチ全体にわたる過剰な輝度をトーンマッピングし（フレームごとに露出が変化しないよう、1 つの白色点を共有します）、色域外の色を圧縮します。HLG および PQ 出力は負のチャンネルをクリップします。
- 変換は float32 で計算され、中間デバイスと dtype を返します。
- LogC3 と ACEScct はカメラログエンコーディングです。ACEScg EXR 保存用にはリニア ACEScg（AP1）に、Rec.709 EXR 保存用にはリニア（Rec.709）に変換するか、動画保存前に sRGB/HDR/HDR PQ に変換してください。
- ストレートアルファは色変換されません。RGB チャンネルのみが変換されます。
- `source` と `destination` が同じ場合、色変換は適用されません。画像は中間デバイスと dtype に移動されるだけです。
