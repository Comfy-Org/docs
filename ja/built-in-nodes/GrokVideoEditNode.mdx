このノードは Grok API を使用し、テキストプロンプトに基づいて既存の動画を編集します。動画をアップロードし、説明に従って動画を変更するよう AI モデルにリクエストを送信し、新しく生成された動画を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 動画編集に使用する AI モデル（デフォルト: "grok-imagine-video"）。 | COMBO | はい | "grok-imagine-video" |
| `プロンプト` | 希望する動画のテキスト記述。 | STRING | はい | N/A |
| `動画` | 編集対象の入力動画。サポートされる最大長は8.7秒、最大ファイルサイズは50MBです。 | VIDEO | はい | N/A |
| `シード値` | ノードを再実行するかどうかを決めるシード。実際の結果はシードに関係なく非決定的です（デフォルト: 0）。 | INT | いいえ | 0 ～ 2147483647 |

**制約条件:**

* `prompt` は空にできません。
* 入力 `video` の長さは1秒以上8.7秒以下である必要があります。
* 入力 `video` のファイルサイズは50MBを超えてはいけません。

**注:** このノードは API ノードであり、実行には Comfy.org アカウントと API キーが必要です。使用量は動画1秒あたり約$0.06で課金されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | AI モデルによって生成された編集済み動画。 | VIDEO |
