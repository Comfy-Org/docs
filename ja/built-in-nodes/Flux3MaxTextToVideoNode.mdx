FLUX 3 Max Text to Video は、テキストプロンプトから同期音声付きの動画を生成します。プロンプトはレンダリング前に FLUX 3 Max によって解釈および展開され、ノードはレンダリングの完了を待って、完成したクリップを返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | クリップに何を表示するかを平易な言葉で指定します。レイヤー化された音声のために、環境音、音楽、発話を個別に説明してください（デフォルト: 空）。 | STRING | はい | 複数行テキスト |
| `aspect_ratio` | 出力アスペクト比です。テキストプロンプトの場合、`"auto"` は 16:9 になります（デフォルト: `"auto"`）。 | COMBO | はい | `"auto"`<br />`"21:9"`<br />`"2:1"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"` |
| `duration` | クリップの長さ（秒）（デフォルト: `"5"`）。 | COMBO | はい | `"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"`<br />`"11"`<br />`"12"`<br />`"13"`<br />`"14"`<br />`"15"`<br />`"16"`<br />`"17"`<br />`"18"`<br />`"19"`<br />`"20"` |
| `resolution` | 出力解像度（デフォルト: `"720p"`）。 | COMBO | はい | `"720p"`<br />`"1080p"` |
| `reasoning_level` | 生成前にモデルがプロンプトについてどれだけ推論し、展開するかを指定します。`"high"` は時間がかかりますが、価格は同じです（デフォルト: `"high"`）。 | COMBO | はい | `"low"`<br />`"high"` |
| `generate_audio` | 同期音声を生成します。オフにすると、音声トラックのない動画を生成します（デフォルト: true）。 | BOOLEAN | はい | `true`<br />`false` |
| `seed` | ノードを再実行するかどうかを制御するシードです。この値に関係なく、結果は非決定的です（デフォルト: 42）。 | INT | はい | 0～2147483646 |

注: `prompt` は少なくとも1文字以上である必要があります。表示される価格は `resolution` と `duration` に基づきます。720p は 2026年11月7日まで 1秒あたり $0.060775、1080p は 1秒あたり $0.103675 で、その日付以降はそれぞれ 1秒あたり $0.2431 と $0.4147 です。クリップの推定総コストは UI に表示されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | 生成された動画クリップです。`generate_audio` が有効な場合は同期音声が含まれます。 | VIDEO |
