TripoRetargetNode は、既にリギング済みの 3D モデルにプリセットアニメーションを適用します。以前にリギングされたモデルのタスク ID を受け取り、Tripo API にリターゲットリクエストを送信し、生成されたアニメーションファイルをダウンロードします。アニメーション付きモデルは、GLB または FBX として返すことができ、メッシュジオメトリの有無や、その場での再生の有無も選択できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `original_model_task_id` | リターゲット対象となる、以前にリギングされた 3D モデルのタスク ID。参照するタスクはリグタスクである必要があります。モデルバージョン v1.0 で Mixamo 仕様に基づいて作成されたリグは、リターゲットに使用できません。 | RIG_TASK_ID | はい | - |
| `animation` | リギング済みモデルに適用するアニメーションのプリセット。`preset:*` アニメーションは両方のリグモデルで動作します。`preset:biped:*` アニメーションは、モデル v1.0-20240301 で作成されたリグが必要です。 | COMBO | はい | `"preset:idle"`<br />`"preset:walk"`<br />`"preset:run"`<br />`"preset:dive"`<br />`"preset:climb"`<br />`"preset:jump"`<br />`"preset:slash"`<br />`"preset:shoot"`<br />`"preset:hurt"`<br />`"preset:fall"`<br />`"preset:turn"`<br />`"preset:quadruped:walk"`<br />`"preset:hexapod:walk"`<br />`"preset:octopod:walk"`<br />`"preset:serpentine:march"`<br />`"preset:aquatic:march"`<br />さらに、UI に表示される追加の `"preset:biped:*"` オプション |
| `out_format` | 出力ファイル形式。結果は対応する出力に届きます。(デフォルト: glb) | COMBO | いいえ | `"glb"`<br />`"fbx"` |
| `export_with_geometry` | エクスポートにメッシュを含めます。オフの場合はアニメーション付きスケルトンのみをエクスポートします。(デフォルト: True) | BOOLEAN | いいえ | True<br />False |
| `animate_in_place` | ルートの移動を伴わずに、その場でアニメーションを再生します。(デフォルト: False) | BOOLEAN | いいえ | True<br />False |
| `auth_token_comfy_org` | Comfy.org API アクセス用の認証トークン(非表示パラメータ)。 | AUTH_TOKEN_COMFY_ORG | いいえ | - |
| `api_key_comfy_org` | Comfy.org サービスアクセス用の API キー(非表示パラメータ)。 | API_KEY_COMFY_ORG | いいえ | - |
| `unique_id` | 操作を追跡するための一意の識別子(非表示パラメータ)。 | UNIQUE_ID | いいえ | - |

注: `preset:*` グループのアニメーションは両方のリグモデルで動作しますが、`preset:biped:*` グループのアニメーションはモデル v1.0-20240301 で作成されたリグが必要です。参照したリグが Mixamo 仕様とバージョンが `v1.0` で始まるモデルで作成された場合、リターゲット呼び出しはエラーで失敗します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `リターゲットタスクID` | 生成されたアニメーション付き 3D モデルファイル(下位互換性のためのみ)。 | STRING |
| `リターゲット タスクID` | リターゲット操作を追跡するためのタスク ID。 | RETARGET_TASK_ID |
| `GLB` | GLB 形式のアニメーション付き 3D モデル。`out_format` が glb の場合に値が設定されます。 | FILE3DGLB |
| `FBX` | FBX 形式のアニメーション付き 3D モデル。`out_format` が fbx の場合に値が設定されます。 | FILE3DFBX |
