MiniMax H3 Image を使用して、プロンプトをコンディショニングと静止画用の空の潜在変数に変換します。画像がない場合はテキストから画像への生成を行い、画像が接続されている場合はそれらを編集します。プロンプトでは、それらを `<Picture 1>`、`<Picture 2>` などとして参照します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `clip` | MiniMax H3 Image の CLIP モデルです。参照画像がある場合はプロンプトをそれらとともにトークン化し、コンディショニングをエンコードします。 | CLIP | はい | - |
| `vae` | MiniMax H3 Image の VAE です。これを使用すると、画像は参照潜在変数としても固定されます。使用しない場合、画像はテキストエンコーダーの条件付けにのみ寄与します。 | VAE | いいえ | - |
| `prompt` | 生成する内容、または参照画像を編集する方法を指定します。 | STRING | はい | 複数行テキスト |
| `width` | 出力幅（ピクセル単位）です。0 の場合、`image_1` の参照スケーリング後の幅を使用します。画像がない場合は 2048 を使用します。デフォルト: 0。 | INT | はい | 0～MAX_RESOLUTION（ステップ 32） |
| `height` | 出力高さ（ピクセル単位）です。0 の場合、`image_1` の参照スケーリング後の高さを使用します。画像がない場合は 2048 を使用します。デフォルト: 0。 | INT | はい | 0～MAX_RESOLUTION（ステップ 32） |
| `images` | 参照画像の追加可能なグループで、`image_1` から始まります。`image_1` は編集対象の画像です。プロンプトでは、それらを `<Picture n>` として参照します。 | AUTOGROW | いいえ | 0～100 枚の画像 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | MiniMax H3 Image サンプラー用のコンディショニングです。画像が接続されている場合は、参照潜在変数が付加されます。 | CONDITIONING |
| `latent` | 1 枚の画像用の空の潜在変数です。出力サイズの 16 分の 1 で、24 チャンネルです。 | LATENT |

注: このモデルは面積 2048x2048 ピクセル向けに調整されています。そのため、異なるキャンバスが必要な場合を除き、`width` と `height` は 0 のままにしてください。
