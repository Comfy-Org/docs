Hunyuan Video 15 Latent Upscale With Model ノードは、潜在画像表現の解像度を高めます。まず、選択した補間方法を使用して潜在サンプルを指定サイズにアップスケールし、次に専用の Hunyuan Video 1.5 アップスケールモデルを使用してアップスケール結果をリファインし、品質を向上させます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | アップスケールされたサンプルをリファインするために使用される Hunyuan Video 1.5 latent upscale モデルです。 | LATENT_UPSCALE_MODEL | はい | N/A |
| `サンプル` | アップスケールする潜在画像表現です。 | LATENT | はい | N/A |
| `アップスケール方法` | 初期アップスケール手順で使用される補間アルゴリズムです（デフォルト：`"bilinear"`）。 | COMBO | はい | `"nearest-exact"`<br />`"bilinear"`<br />`"area"`<br />`"bicubic"`<br />`"bislerp"` |
| `幅` | アップスケールされた latent のターゲット幅（ピクセル単位）。値 0 を指定すると、ターゲット高さと元のアスペクト比に基づいて幅が自動計算されます。最終的な出力幅は 16 の倍数になります（デフォルト：1280）。 | INT | はい | 0～16384（ステップ: 8） |
| `高さ` | アップスケールされた latent のターゲット高さ（ピクセル単位）。値 0 を指定すると、ターゲット幅と元のアスペクト比に基づいて高さが自動計算されます。最終的な出力高さは 16 の倍数になります（デフォルト：720）。 | INT | はい | 0～16384（ステップ: 8） |
| `切り抜き` | ターゲット寸法に合わせるために、アップスケールされた latent をどのようにクロップするかを決定します。 | COMBO | はい | `"disabled"`<br />`"center"` |

**寸法に関する注意：** `width` と `height` の両方が 0 に設定されている場合、ノードは入力 `samples` を変更せずに返します。一方の寸法のみが 0 に設定されている場合、もう一方の寸法は元のアスペクト比を保持するように計算されます。両方の値は最小 64 にクランプされ、補間手順に渡されるアップスケールターゲットは `width // 16` × `height // 16` であるため、要求された寸法は実質的に 16 の倍数に切り捨てられます。
