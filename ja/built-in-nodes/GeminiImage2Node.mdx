Google Vertex AI Gemini API を通じて、画像を同期的に生成または編集します。テキストプロンプトを指定し、必要に応じて参照画像や Gemini 入力ファイルを添付できます。このノードは生成された画像を返し、選択した応答モードに応じてテキスト応答も返します。

## 入力

|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 生成する画像または適用する編集内容を説明するテキストプロンプトです。モデルが従うべき制約、スタイル、詳細を含めてください。プロンプトは、空白を除去した後に少なくとも 1 文字含まれている必要があります。 | STRING | はい | N/A |
| `モデル` | 生成に使用する Gemini モデルです。「Nano Banana 2 (Gemini 3.1 Flash Image)」オプションは `gemini-3.1-flash-image` として送信され、「gemini-3-pro-image-preview」は `gemini-3-pro-image` として送信されます。 | COMBO | はい | "gemini-3-pro-image-preview"<br />"Nano Banana 2 (Gemini 3.1 Flash Image)" |
| `シード` | シードを特定の値に固定すると、モデルは繰り返しリクエストに対して同じ応答を返すよう最善を尽くします。決定論的な出力は保証されません。また、モデルや temperature などのパラメータ設定を変更すると、同じシード値を使用しても応答が変動することがあります。デフォルトでは、ランダムなシード値が使用されます。デフォルト: 42。 | INT | はい | 0 ～ 18446744073709551615 |

| `ファイル` | モデルのコンテキストとして使用するオプションのファイルです。Gemini Generate Content Input Files ノードからの入力を受け付けます。 | GEMINI_INPUT_FILES | いいえ | N/A |
| `システムプロンプト` | AI の動作を規定する基本的な指示です。デフォルト: 画像生成用に事前定義されたシステムプロンプト。詳細設定です。 | STRING | いいえ | N/A |

**制約事項:**

* `images` 入力は最大 14 枚の画像をサポートします。それより多く指定された場合は、エラーが発生します。
* 10 枚を超える画像が指定された場合、最初の 10 枚は URL 参照としてアップロードされ、残りの画像はリクエスト内でインライン送信されます。
* `files` 入力は、`GEMINI_INPUT_FILES` データ型を出力するノードに接続する必要があります。
* `response_modalities` が `"IMAGE"` に設定されている場合、画像のみが返され、テキスト出力は空になります。
* `prompt` 入力は検証され、空白を除去した後に少なくとも 1 文字含まれている必要があります。
