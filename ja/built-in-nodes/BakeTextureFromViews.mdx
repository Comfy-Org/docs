レンダリング済みの画像をメッシュの UV レイアウトに再投影します。Render Mesh でメッシュをレンダリングし、画像を編集または再生成してから、同じメッシュとカメラでベイクします。どのビューにも覆われないテクセルは、メッシュ自身のテクスチャまたは頂点カラーを保持します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `mesh` | レンダリングされた UV 展開済みメッシュです。 | MESH | はい | - |
| `images` | カメラごとに 1 枚の画像をカメラ順で指定します（Batch Images）。レンダリングと同じアスペクト比であれば任意の解像度を使用でき、高いほどベイクがシャープになります。 | IMAGE | はい | - |
| `camera_info` | 画像のレンダリングに使用したカメラです。Render Mesh に接続したものと同じです。リグは Batch Cameras で結合します。None の場合：Render Mesh の自動フレーミングされた正面ビューを使用します。 | LOAD3D_CAMERA | いいえ | - |
| `resolution` | 正方形テクスチャの解像度です。0 の場合はメッシュの現在のテクスチャサイズを維持し、テクスチャがない場合は 2048 になります。それ以外の場合は、現在のテクスチャがその解像度にリサンプリングされます。デフォルト：0。 | INT | いいえ | 0～8192（ステップ 64） |
| `blend_exponent` | ビューは cos(ビュー角度)^指数 で重み付けされます。値を大きくすると最も正対したビューが優先され（シャープになりますが、継ぎ目がより目立ちます）、値を小さくするとより多くのビューが平均されます（よりソフトになります）。デフォルト：4.0。 | FLOAT | いいえ | 0.0～32.0（ステップ 0.5） |
| `fill_unseen` | どのビューからも見えないテクセルには、メッシュ自身のテクスチャや頂点カラーではなく、見えている表面から拡張された色を適用します。ビューでテクスチャ全体を置き換える場合に使用します。デフォルト：false。 | BOOLEAN | いいえ | true<br />false |
| `mask` | ビューごとの編集領域です。マスクされたピクセルのみが投影されます。単一のマスクはすべてのビューに適用されます。 | MASK | いいえ | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `base_color` | ベイクされたテクスチャです。Apply Texture to Mesh で使用します。 | IMAGE |
| `confidence` | テクセルごとに、最良のビューがどれだけ正対して見たかを示します。0 は未観測を意味します。 | MASK |

注：ビューアのモデル変換を使用して作成されたレンダリングはベイクと位置が一致せず、バッチ内の最初のメッシュのみが使用されます。
