OpenAI の DALL·E 2 エンドポイントを介して画像を同期的に生成します。

## 動作の仕組み

このノードは OpenAI の DALL·E 2 API に接続し、テキストの説明に基づいて画像を生成します。テキストプロンプトを指定すると、ノードはそれを OpenAI のサーバーに送信し、サーバーが対応する画像を生成して ComfyUI に返します。ノードは 2 つのモードで動作できます。テキストプロンプトのみを使用する標準の画像生成モードと、画像とマスクの両方が提供された場合の画像編集モードです。編集モードでは、マスクを使用して元の画像のどの部分を変更するかを決定し、他の領域は変更しないままにします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `プロンプト` | DALL·E 用のテキストプロンプト（デフォルト: 空） | STRING | はい | - |
| `シード` | バックエンドではまだ実装されていません（デフォルト: 0） | INT | いいえ | 0 から 2147483647 |
| `サイズ` | 画像サイズ（デフォルト: "1024x1024"） | COMBO | いいえ | "256x256"<br />"512x512"<br />"1024x1024" |
| `生成数` | 生成する画像の数（デフォルト: 1） | INT | いいえ | 1 から 8 |
| `画像` | 画像編集用のオプションの参照画像。 | IMAGE | いいえ | - |
| `マスク` | インペインティング用のオプションのマスク（白い領域が置き換えられます） | MASK | いいえ | - |

**注記:** 画像編集モードは、`image` と `mask` の両方が同時に指定された場合にのみ有効になります。どちらか一方だけが指定された場合は、エラーが発生します。`mask` は `image` と同じサイズである必要があります。そうでない場合はエラーが発生します。編集モードでは、マスクの白い領域が置き換えられる領域を示します。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `IMAGE` | DALL·E 2 によって生成または編集された画像（複数可） | IMAGE |
