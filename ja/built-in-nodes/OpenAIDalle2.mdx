OpenAI の DALL·E 2 エンドポイントを介して画像を同期的に生成します。このノードはテキストプロンプトを OpenAI の DALL·E 2 API に送信し、生成された画像を ComfyUI に返します。`image` と `mask` の両方が一緒に指定された場合は、既存の画像を編集することもできます。

## 仕組み

このノードは OpenAI の DALL·E 2 API に接続し、テキストによる説明に基づいて画像を生成します。テキストプロンプトを指定すると、ノードはそれを OpenAI のサーバーに送信し、対応する画像を生成して ComfyUI に返します。このノードは 2 つのモードで動作します。テキストプロンプトのみを使用する標準の画像生成モードと、画像とマスクの両方が指定された場合の画像編集モードです。編集モードでは、マスクを使用して元の画像のどの部分を変更し、その他の領域を変更せずに保持するかを決定します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `prompt` | DALL·E 用のテキストプロンプト（デフォルト：空） | STRING | はい | - |
| `seed` | バックエンドではまだ実装されていません（デフォルト：0） | INT | いいえ | 0 〜 2147483647 |
| `size` | 画像サイズ（デフォルト："1024x1024"） | COMBO | いいえ | "256x256"<br />"512x512"<br />"1024x1024" |
| `n` | 生成する画像の数（デフォルト：1） | INT | いいえ | 1 〜 8 |
| `image` | 画像編集用のオプションの参照画像。 | IMAGE | いいえ | - |
| `mask` | インペインティング用のオプションのマスク（白い領域が置き換えられます） | MASK | いいえ | - |

**注記：** 画像編集モードは、`image` と `mask` の両方が一緒に指定された場合にのみ有効になります。どちらか一方しか指定されていない場合はエラーが発生します。`mask` は `image` と同じサイズである必要があります。そうでない場合はエラーが発生します。編集モードでは、マスクの白い領域が置き換えられる領域を示します。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `IMAGE` | DALL·E 2 によって生成または編集された画像 | IMAGE |
