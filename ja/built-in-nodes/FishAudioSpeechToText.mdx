このノードは、Fish Audio の音声テキスト変換サービスを使用して音声をテキストに文字起こしします。音声の言語を自動検出し、必要に応じて単語レベルのタイムスタンプ付きセグメントを JSON として返すことができます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 文字起こしする音声。 | AUDIO | はい | — |
| `language` | ISO 639-1 言語ヒント（例: 'en'、'zh'）。言語はヒントに関係なく自動検出されます。デフォルト: ""（空文字列）。 | STRING | いいえ | 任意の ISO 639-1 言語コード（例: `en`、`zh`）。自動検出の場合は空文字列 |
| `precise_timestamps` | 単語レベルのタイムスタンプ付きセグメントを返します。デフォルト: false。 | BOOLEAN | いいえ | true または false |

注: `language` パラメータは単なるヒントです — 言語は常に音声から自動検出されます。`precise_timestamps` が false（デフォルト）の場合、単語レベルのタイムスタンプは返されません。true の場合、出力セグメントに単語レベルのタイムスタンプが含まれます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `text` | 文字起こしされたテキスト。 | STRING |
| `language_code` | 音声で検出された ISO 639-1 言語コード。 | STRING |
| `segments_json` | 文字起こしセグメントを含む JSON 文字列。`precise_timestamps` が有効な場合は、単語レベルのタイムスタンプが含まれます。 | STRING |
