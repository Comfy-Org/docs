このノードは、Fish Audioの音声文字起こしサービスを使用して、オーディオをテキストに文字起こしします。オーディオの言語を自動的に検出し、必要に応じて単語レベルのタイムスタンプ付きセグメントをJSONとして返すこともできます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 文字起こしするオーディオ。 | AUDIO | はい | — |
| `language` | ISO 639-1言語ヒント（例: 'en', 'zh'）。言語は常に自動検出されます。デフォルト: ""（空文字列）。 | STRING | いいえ | 任意のISO 639-1言語コード（例: `en`, `zh`）。自動検出の場合は空文字列 |
| `precise_timestamps` | 単語レベルのタイムスタンプ付きセグメントを返します。デフォルト: false。 | BOOLEAN | いいえ | true または false |

注: `language` パラメータはヒントに過ぎません。言語は常にオーディオから自動検出されます。`precise_timestamps` が false（デフォルト）の場合、単語レベルのタイムスタンプは返されません。true の場合、出力セグメントには単語レベルのタイムスタンプが含まれます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `text` | 文字起こしされたテキスト。 | STRING |
| `language_code` | オーディオから検出されたISO 639-1言語コード。 | STRING |
| `segments_json` | 文字起こしセグメントを含むJSON文字列。`precise_timestamps` が有効な場合、単語レベルのタイムスタンプが含まれます。 | STRING |
