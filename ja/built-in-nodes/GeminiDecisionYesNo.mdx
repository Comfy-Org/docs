接続したテキスト、画像、音声、または動画について yes/no の質問をすると、ルーティングに使用できる boolean が得られます。`result` を If/Else Switch ノードに接続すると、実行を 2 つのパスのいずれかに振り分けることができ、`answer` と `probability` を読み取ることで、モデルがそのように回答した理由を確認できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 使用するモデル（デフォルト：`"gemini-decision-1"`）。 | COMBO | はい | `"gemini-decision-1"` |
| `question` | 接続されている内容についての yes/no の質問で、最大 5000 文字です。"yes" が実際に対処したいケースになるように質問してください（デフォルト："Is there a person in the image?"）。 | STRING | はい | 1～5000 文字 |
| `threshold` | `result` が true になる "yes" の確率です。明確な yes の回答は約 0.85～0.92 のスコアになるため、0.9 以上に設定すると多くの回答が却下されます（デフォルト：0.5）。 | FLOAT | はい | 0.01～0.99（ステップ 0.01） |
| `images` | 質問対象の画像で、拡張可能なスロット（`image_1` ... `image_16`）全体で最大 16 枚です。バッチ化された画像は 1 枚ごとに 1 回としてカウントされます。 | IMAGE | いいえ | 最大 16 枚の画像 |
| `audio` | 質問対象の音声クリップ。 | AUDIO | いいえ | - |
| `video` | 質問対象の動画クリップ。 | VIDEO | いいえ | - |
| `text` | 質問の対象となるテキストで、プロンプトや LLM の応答など、最大 20000 文字です。 | STRING | いいえ | 最大 20000 文字 |

`text`、`images`、`audio`、`video` のうち少なくとも 1 つを接続してください。参照する対象がない場合、ノードはエラーを発生させます。複数の画像を使用する場合は、質問内で `image_1`、`image_2` などの名前を付けてください。バッチはフレームごとに展開されるため、番号は接続順にスロット全体の個々のフレームをカウントします。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `result` | 「yes」の確率が `threshold` に達した場合に true、それ以外は false になります。 | BOOLEAN |
| `answer` | 判定結果を文字列 `"yes"` または `"no"` で表したもので、`result` と同じ `threshold` に従います。 | STRING |
| `probability` | 0～1 の間の「yes」の確率です。 | FLOAT |
