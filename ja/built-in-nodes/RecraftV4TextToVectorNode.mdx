Recraft V4 Text to Vector ノードは、Recraft V4 および V4.1 モデルを使用して、テキストの説明から Scalable Vector Graphics（SVG）イラストを生成します。Recraft API に接続して、プロンプトに基づいて1つ以上の SVG ファイルを生成し、既存のベクタースタイルを適用したり、参照画像から新しいスタイルを作成したりできます。参照画像を使用した場合、作成されたスタイルは再利用のために `style_id` として返されます。

## 入力

### 共通入力

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | 生成に使用するモデルです。recraftv4_styles モデルはスタイルの一貫性を保った生成のために作られており、常に style_id または style_references が必要です。モデルを選択すると、利用可能な `size` のオプションが変わります。 | DYNAMIC_COMBO | はい | `"recraftv4_1_vector"`<br />`"recraftv4_1_utility_vector"`<br />`"recraftv4_1_pro_vector"`<br />`"recraftv4_1_utility_pro_vector"`<br />`"recraftv4"`<br />`"recraftv4_pro"`<br />`"recraftv4_styles_vector"`<br />`"recraftv4_styles_pro_vector"` |

### 参照入力

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `style_references` | オンザフライでベクタースタイルを作成するための参照画像です。生成とは別に課金されます。作成されたスタイルは再利用のために style_id として返されます。style_id と組み合わせることはできません。 | IMAGE | いいえ | Growable slot：1～N 枚の参照画像を接続します（ノードの最大数まで） |

**注意：** `size` パラメータは動的入力であり、利用可能なオプションは選択した `model` に基づいて変わります。`seed` の値は外部 API からの再現可能な結果を保証するものではありません。`recraftv4_styles_vector` および `recraftv4_styles_pro_vector` モデルでは常にスタイルが必要です。`style_id` を指定するか、少なくとも1枚の `style_references` 画像を接続してください。`style_id` と `style_references` は同時に使用できません。両方を指定するとエラーが発生し、`style_id` は有効な UUID である必要があります。スタイル参照画像には枚数の制限があり、その合計エンコードサイズは10 MBを超えてはなりません。

## 出力

| Output Name | Description | Data Type |
