Recraft V4 Text to Vector ノードは、Recraft V4 および V4.1 モデルを使用して、テキストの説明から Scalable Vector Graphics（SVG）イラストを生成します。Recraft API に接続して、プロンプトに基づいて1つ以上の SVG ファイルを生成し、既存のベクタースタイルを適用したり、参照画像から新しいスタイルを作成したりできます。参照画像を使用した場合、作成されたスタイルは再利用のための `style_id` として返されます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 生成に使用するモデルです。recraftv4_styles モデルはスタイル一貫性のある生成向けに構築されており、常に style_id または style_references が必要です。モデルを選択すると、利用可能な `size` オプションが変わります。 | DYNAMIC_COMBO | はい | `"recraftv4_1_vector"`<br />`"recraftv4_1_utility_vector"`<br />`"recraftv4_1_pro_vector"`<br />`"recraftv4_1_utility_pro_vector"`<br />`"recraftv4"`<br />`"recraftv4_pro"`<br />`"recraftv4_styles_vector"`<br />`"recraftv4_styles_pro_vector"` |
| `prompt` | 画像生成のプロンプトです。最大10,000文字です。 | STRING | はい | N/A |
| `negative_prompt` | この入力は無視されます。Recraft V4 および V4.1 モデルではネガティブプロンプトはサポートされていません。 | STRING | はい | N/A |
| `n` | 生成する画像の数です（デフォルト: 1）。 | INT | はい | 1〜6 |
| `seed` | ノードを再実行するかどうかを決定するためのシードです。実際の結果はシードに関係なく非決定的です（デフォルト: 0）。 | INT | はい | 0〜18446744073709551615 |
| `recraft_controls` | Recraft Controls ノードを介した生成に関する追加のオプション制御です。 | CUSTOM | いいえ | N/A |

| `style_match` | スタイルへの追従度です。precise は詳細まで再現し、flexible は全体的な雰囲気に合わせます。スタイルが指定された場合にのみ使用されます（デフォルト: "precise"）。 | COMBO | いいえ | `"precise"`<br />`"flexible"` |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `style_references` | その場でベクタースタイルを作成するための参照画像です。生成費用に加算して請求されます。作成されたスタイルは再利用のための style_id として返されます。style_id とは併用できません。 | IMAGE | いいえ | 拡張可能スロット: 参照画像を1..N枚接続（ノードの最大数まで） |

**注記:** `size` パラメータは動的入力であり、選択した `model` に応じて利用可能なオプションが変わります。`seed` の値は外部 API の再現可能な結果を保証するものではありません。`recraftv4_styles_vector` および `recraftv4_styles_pro_vector` モデルは常にスタイルを必要とします。`style_id` を指定するか、少なくとも1枚の `style_references` 画像を接続してください。`style_id` と `style_references` は併用できません。両方を指定するとエラーが発生します。また、`style_id` は有効な UUID である必要があります。参照画像の枚数には制限があり、エンコード後の合計サイズが10 MBを超えてはなりません。

## 出力
