SaveWEBMノードは、一連の画像をWEBMビデオファイルとして保存します。複数の入力画像を受け取り、VP9またはAV1コーデックを使用して、設定可能な品質設定とフレームレートでビデオにエンコードします。生成されたビデオファイルは、プロンプト情報を含むメタデータとともに出力ディレクトリに保存されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | RGBA画像は、アルファチャンネルを透明度として保存します（vp9コーデックのみ）。 | IMAGE | 必須 | - |
| `ファイル名の接頭辞` | 出力ファイル名のプレフィックス（デフォルト: "ComfyUI"）。 | STRING | 任意 | - |
| `コーデック` | エンコードに使用するビデオコーデック。 | COMBO | 必須 | "vp9"<br />"av1" |
| `fps` | 出力ビデオのフレームレート（デフォルト: 24.0）。 | FLOAT | 任意 | 0.01-1000.0 |
| `crf` | CRFが高いほど品質が低くなりファイルサイズが小さくなります。CRFが低いほど品質が高くなりファイルサイズが大きくなります（デフォルト: 32.0）。 | FLOAT | 任意 | 0-63.0 |

**アルファチャンネルに関する注意:** RGBA画像のアルファチャンネルは、VP9コーデック使用時のみ保持されます。AV1コーデック使用時は、アルファチャンネルは無視され、RGBデータのみがエンコードされます。

**ファイル名に関する注意:** ビデオは `{filename_prefix}_{counter:05}_.webm` として出力ディレクトリに保存されます。カウンターは既存ファイルの上書きを避けるために自動的に増加します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `images` | 入力画像。ビデオ保存後、変更されずにそのまま渡されます。 | IMAGE |
| UI preview | 保存されたWEBMファイルを表示するビデオプレビュー。 | PREVIEW |
