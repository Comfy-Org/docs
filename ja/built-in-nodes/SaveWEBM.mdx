SaveWEBMノードは、一連の画像をWEBM動画ファイルとして保存します。複数の入力画像を受け取り、設定可能な品質設定とフレームレートで、VP9またはAV1コーデックを使用して動画にエンコードします。生成された動画ファイルは、プロンプト情報を含むメタデータとともに出力ディレクトリに保存されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | RGBA画像は、アルファチャンネルを透過情報として保存します（vp9コーデックのみ）。 | IMAGE | はい | - |
| `ファイル名の接頭辞` | 出力ファイル名のプレフィックス（デフォルト: "ComfyUI"）。 | STRING | いいえ | - |
| `コーデック` | エンコードに使用するビデオコーデック。 | COMBO | はい | "vp9"<br />"av1" |
| `fps` | 出力動画のフレームレート（デフォルト: 24.0）。 | FLOAT | いいえ | 0.01-1000.0 |
| `crf` | crfが高いほど品質は低下しファイルサイズは小さくなり、crfが低いほど品質は高くファイルサイズは大きくなります（デフォルト: 32.0）。 | FLOAT | いいえ | 0-63.0 |

**アルファチャンネルに関する注意:** RGBA画像のアルファチャンネルは、VP9コーデックを使用する場合にのみ保持されます。AV1コーデックを使用する場合、アルファチャンネルは無視され、RGBデータのみがエンコードされます。

**ファイル名に関する注意:** 動画は出力ディレクトリに `{filename_prefix}_{counter:05}_.webm` として保存されます。ここで、counter は既存ファイルの上書きを避けるために自動的に増加します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-----------|-----------|
| `images` | 入力画像。動画保存後、変更されずにそのまま渡されます。 | IMAGE |
| UI preview | 保存されたWEBMファイルを表示する動画プレビュー。 | PREVIEW |
