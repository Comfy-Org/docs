HeyGen アバターからトーキングプレゼンター動画を生成します。このノードは、HeyGen のレンダリングエンジンを使用して、提供したテキストを話す、または自分の音声にリップシンクする AI アバターの動画を作成します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `エンジン` | レンダリングエンジン。各選択肢には、それをサポートするアバターのみが一覧表示されます。`"auto"` はすべてのアバターを提供し、最適なエンジンを選択します（Avatar IV が優先されます）。Avatar V は最高忠実度で、Avatar III は最も手頃です。 | DYNAMIC_COMBO | はい | `"auto"`<br />`"avatar_iv"`<br />`"avatar_iii"`<br />`"avatar_v"` |
| `カスタムアバターID` | オプションの HeyGen アバタールック ID。設定すると、上で選択したアバターを上書きします。HeyGen の 3000 以上の公開ルック（またはプライベートアバター）を使用できます。デフォルト: `""`。 | STRING | いいえ |  |
| `スピーチ` | テキストスクリプト（HeyGen のテキスト読み上げ）または自分の音声でアバターを動作させます。表示名: 「speech source」。 | DYNAMIC_COMBO | はい | `"script"`<br />`"audio"` |

| `背景色` | オプションの単色背景色（16進コード、例: `"#00ff00"`）。空のままにすると、アバター自身の背景になります。指定する場合、値は `#` で始まる必要があります。デフォルト: `""`。 | STRING | いいえ |  |

### `script` 入力

`speech` が `"script"` の場合、次のサブパラメータを使用できます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |

注: `engine` と `speech` はセレクターであり、選択した値に応じて異なるサブパラメータを表示します。`speech` セレクターには相互に排他的な 2 つのモードがあります。`"script"` モードでは `text` が必須です。`custom_voice_id` が指定されている場合は、`voice` を上書きします。`"audio"` モードでは、アバターは提供された音声クリップにリップシンクします。`background_color` を指定する場合は、`#` で始まる 16 進カラーコードである必要があります。`custom_avatar_id` が設定されている場合は、`avatar` の選択を上書きし、選択した `engine` はそのアバタールックでサポートされている必要があります。そうでない場合、`engine` が `"auto"` でない限りエラーが発生します。
