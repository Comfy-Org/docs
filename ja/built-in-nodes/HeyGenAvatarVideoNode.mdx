HeyGen アバターからトーキングプレゼンタービデオを生成します。このノードは、HeyGen のレンダリングエンジンを使用して、提供されたテキストを話す AI アバターのビデオ、または独自のオーディオにリップシンクするビデオを作成します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `エンジン` | レンダリングエンジン。各選択肢には、それをサポートするアバターのみが表示されます。`"auto"` はすべてのアバターを提供し、そのアバターに最適なエンジン（Avatar IV を優先）を選択します。Avatar V は最高忠実度で、Avatar III は最も手頃な価格です。 | DYNAMIC_COMBO | はい | `"auto"`<br />`"avatar_iv"`<br />`"avatar_iii"`<br />`"avatar_v"` |
| `カスタムアバターID` | オプションの HeyGen アバタールック ID。設定すると、上で選択したアバターを上書きします。HeyGen の 3000 以上の公開ルック（または非公開アバター）のいずれかを使用できます。デフォルト: `""`。 | STRING | いいえ |  |
| `スピーチ` | テキストスクリプト（HeyGen テキスト読み上げ）または独自のオーディオでアバターを駆動します。表示名: "speech source"。 | DYNAMIC_COMBO | はい | `"script"`<br />`"audio"` |

| `背景色` | オプションの単色背景色を16進コードで指定します（例: `"#00ff00"`）。空のままにすると、アバター自身の背景が使用されます。指定する場合、値は `#` で始まる必要があります。デフォルト: `""`。 | STRING | いいえ |  |

注: `engine` と `speech` は、選択した値に応じて異なるサブパラメータを表示するセレクタです。`speech` セレクタには、相互に排他的な2つのモードがあります。`"script"` モードでは `text` が必須です。`custom_voice_id` が指定されている場合は `voice` を上書きします。`"audio"` モードでは、アバターは提供されたオーディオクリップにリップシンクします。`background_color` を指定する場合は、`#` で始まる16進カラーコードである必要があります。`custom_avatar_id` が設定されている場合、それは `avatar` の選択を上書きし、選択した `engine` がそのアバタールックでサポートされている必要があります。そうでない場合、`engine` が `"auto"` でない限りエラーが発生します。
