WanImageToVideo ノードは、ビデオ生成タスク用のコンディショニングと潜在表現を準備します。ビデオ生成用の空の潜在空間を作成し、オプションで開始画像と CLIP ビジョン出力を組み込んで、ビデオ生成プロセスをガイドできます。このノードは、提供された画像とビジョンデータに基づいて、ポジティブとネガティブの両方のコンディショニング入力を変更します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ポジティブ` | 生成をガイドするためのポジティブコンディショニング入力 | CONDITIONING | はい | - |
| `ネガティブ` | 生成をガイドするためのネガティブコンディショニング入力 | CONDITIONING | はい | - |
| `vae` | 画像を潜在空間にエンコードするための VAE モデル | VAE | はい | - |
| `幅` | 出力ビデオの幅（デフォルト：832、ステップ：16） | INT | はい | 16〜MAX_RESOLUTION |
| `高さ` | 出力ビデオの高さ（デフォルト：480、ステップ：16） | INT | はい | 16〜MAX_RESOLUTION |
| `長さ` | ビデオのフレーム数（デフォルト：81、ステップ：4） | INT | はい | 1〜MAX_RESOLUTION |
| `バッチサイズ` | 1 回のバッチで生成するビデオの数（デフォルト：1） | INT | はい | 1〜4096 |
| `clipビジョン出力` | 追加のコンディショニング用のオプションの CLIP ビジョン出力 | CLIP_VISION_OUTPUT | いいえ | - |
| `開始画像` | ビデオ生成を初期化するためのオプションの開始画像。指定された場合、画像は指定された幅と高さにリサイズされ、ビデオの最初のフレームがこの画像から初期化されます。残りのフレームはニュートラルグレー（0.5）の値で埋められます。`length` を超えるフレームは無視されます。 | IMAGE | いいえ | - |

**注記：** `start_image` が指定された場合、ノードは VAE を使用して画像シーケンスをエンコードし、コンディショニング入力にマスクを適用します。マスクは開始画像で初期化されたフレーム以外のすべてのフレームをカバーし、提供された画像に基づいて生成を構築できるようにします。エンコード時には、画像の最初の 3 つのカラーチャンネル（RGB）のみが使用されます。`clip_vision_output` パラメータが指定された場合、ポジティブとネガティブの両方の入力にビジョンベースのコンディショニングを追加します。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `ポジティブ` | 画像およびビジョンデータが組み込まれた修正済みポジティブコンディショニング | CONDITIONING |
| `ネガティブ` | 画像およびビジョンデータが組み込まれた修正済みネガティブコンディショニング | CONDITIONING |
| `潜在` | ビデオ生成用の空の潜在空間テンソル。形状は [batch_size, 16, ((length-1)//4)+1, height//8, width//8] | LATENT |
