WanImageToVideo ノードは、動画生成用の conditioning と latent 表現を準備します。動画用の空の latent 空間を作成し、必要に応じて開始画像と CLIP vision 出力を取り込んで生成をガイドできます。positive と negative の両方の conditioning 入力は、指定された画像と vision データで更新されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ポジティブ` | 生成をガイドするために使用される positive conditioning 入力 | CONDITIONING | はい | - |
| `ネガティブ` | 生成をガイドするために使用される negative conditioning 入力 | CONDITIONING | はい | - |
| `vae` | 画像を latent 空間にエンコードするために使用される VAE モデル | VAE | はい | - |
| `幅` | 生成される動画の幅（デフォルト: 832、ステップ: 16） | INT | はい | 16～MAX_RESOLUTION |
| `高さ` | 生成される動画の高さ（デフォルト: 480、ステップ: 16） | INT | はい | 16～MAX_RESOLUTION |
| `長さ` | 動画内のフレーム数（デフォルト: 81、ステップ: 4） | INT | はい | 1～MAX_RESOLUTION |
| `バッチサイズ` | 1 つのバッチで生成する動画の数（デフォルト: 1） | INT | はい | 1～4096 |
| `clipビジョン出力` | positive と negative の両方の入力に追加の conditioning として追加されるオプションの CLIP vision 出力 | CLIP_VISION_OUTPUT | いいえ | - |
| `開始画像` | 動画を初期化するために使用されるオプションの開始画像。指定された `width` と `height` にリサイズされ、フレームシーケンスの先頭に配置されます。`length` を超えるフレームは無視されます。残りのフレームは中立グレー（0.5）値で埋められます。 | IMAGE | いいえ | - |

**注:** `start_image` が指定されると、フレームシーケンスは VAE でエンコードされ、conditioning にマスクが適用されます。マスクは、開始画像でカバーされるフレームには 0、残りのフレームには 1 に設定されるため、指定された画像から生成が継続されます。エンコード時には、画像の最初の 3 つのカラーチャンネル（RGB）のみが使用されます。positive と negative の両方の conditioning は、同じ連結された latent 画像、マスク、および（指定されている場合は）CLIP vision 出力を受け取ります。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | 画像と vision データで更新された positive conditioning | CONDITIONING |
| `negative` | 画像と vision データで更新された negative conditioning | CONDITIONING |
| `latent` | 動画生成に使用できる空の latent tensor。形状は [batch_size, 16, ((length-1)//4)+1, height//8, width//8] | LATENT |
