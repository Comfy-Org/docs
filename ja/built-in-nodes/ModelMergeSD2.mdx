ModelMergeSD2 ノードは、2つの Stable Diffusion 2.x モデルを、一致するコンポーネントをブレンドしてマージします。時間埋め込み、ラベル埋め込み、および各入力・中間・出力ブロックに対して個別の重みを持ちます。ブロックレイアウトは ModelMergeSD1 と同じであるため、両ノードは同じ比率のセットを公開します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル1` | マージする最初のモデルです。2番目のモデルが寄与しない部分はすべてこのモデルから保持されます | MODEL | はい | - |
| `モデル2` | マージする2番目のモデルです。その重みは以下の比率に従ってブレンドされます | MODEL | はい | - |
| `time_embed.` | 時間埋め込み層のブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |
| `label_emb.` | ラベル埋め込み層のブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |
| `input_blocks.0.` から `input_blocks.11.` まで | 12個の各入力ブロックのブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |
| `middle_block.0.` から `middle_block.2.` まで | 3個の各中間ブロックのブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |
| `output_blocks.0.` から `output_blocks.11.` まで | 12個の各出力ブロックのブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |
| `out.` | 出力層のブレンド比率（デフォルト: 1.0） | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |

比率 0.0 はそのコンポーネントを `model1` の状態のまま保持し、比率 1.0 は完全に `model2` から取得します。中間の値は重み付きブレンドを生成します。両方の入力は、同じブロック構造を持つ Stable Diffusion 2.x モデルである必要があります。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `MODEL` | 指定された比率に従って両方の入力を組み合わせた、マージ済みモデルです | MODEL |
