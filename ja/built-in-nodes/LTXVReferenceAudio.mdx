LTXV Reference Audio は、参照音声クリップから話者の声のアイデンティティを生成音声に転送します。参照音声をコンディショニングにエンコードし、必要に応じてモデルをアイデンティティガイダンスでパッチ処理します。これにより、各ステップで参照なしの追加フォワードパスが実行され、話者性の効果が増幅されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | アイデンティティガイダンスでパッチ処理されるモデル。 | MODEL | はい | - |
| `positive` | ポジティブなコンディショニング入力。 | CONDITIONING | はい | - |
| `negative` | ネガティブなコンディショニング入力。 | CONDITIONING | はい | - |
| `reference_audio` | 話者の声のアイデンティティを転送する元となる参照音声クリップ。約5秒を推奨（トレーニング時の長さ）。これより短い・長いクリップでは、声のアイデンティティ転送が低下する場合があります。 | AUDIO | はい | - |
| `audio_vae` | エンコードに使用するLTXV Audio VAE。 | VAE | はい | - |
| `identity_guidance_scale` | アイデンティティガイダンスの強さ。各ステップで参照なしの追加フォワードパスを実行し、話者性の効果を増幅します。0に設定すると無効になります（追加パスなし）。（デフォルト: 3.0） | FLOAT | はい | 0.0 - 100.0 |
| `start_percent` | アイデンティティガイダンスが有効なシグマ範囲の開始位置。（デフォルト: 0.0） | FLOAT | はい | 0.0 - 1.0 |
| `end_percent` | アイデンティティガイダンスが有効なシグマ範囲の終了位置。（デフォルト: 1.0） | FLOAT | はい | 0.0 - 1.0 |

注：アイデンティティガイダンスは、`identity_guidance_scale` が0より大きく、現在のサンプリングステップが `start_percent` と `end_percent` で定義された範囲内にある場合にのみ適用されます。参照音声は、オーディオVAEのサンプルレートと異なる場合、そのサンプルレートにリサンプリングされます。
