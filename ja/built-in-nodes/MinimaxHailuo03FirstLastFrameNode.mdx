このノードは、MiniMax H3 モデルを使用して、最初のフレーム画像と、必要に応じて最後のフレーム画像からビデオを生成します。`model` セレクターによって、適用される生成設定と制約が変わり、生成されるビデオのアスペクト比は提供された画像に従います。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | ビデオ生成に使用するモデル。モデルを選択すると、そのモデル固有の設定が下に表示されます。 | DYNAMIC_COMBO | はい | "MiniMax H3"<br />"MiniMax H3 Max"<br />"MiniMax H3 Max Turbo" |
| `最初のフレーム` | ビデオの最初のフレーム画像。生成されるビデオは、この画像のアスペクト比に従います。 | IMAGE | はい | - |
| `最後のフレーム` | ビデオの最後のフレーム画像（オプション）。指定すると、最初のフレームからこの最後のフレームに向かうビデオが生成されます。 | IMAGE | いいえ | - |
| `シード` | 乱数シード。同じシードを使用した同じリクエストは、類似した結果を生成しますが、同一であることは保証されません。「生成後制御」オプションを含みます。デフォルト: 42。 | INT | はい | 0 から 4294967295 |
| `ウォーターマーク` | ビデオに AIGC 透かしを追加するかどうか。これは高度なパラメータです。`MiniMax H3` モデルでのみサポートされています。デフォルト: False。 | BOOLEAN | はい | True<br />False |

### MiniMax H3 入力

これらの設定は、`model` セレクターで `MiniMax H3` を選択したときに表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | ビデオ生成用のテキストプロンプト。必ず空白以外の文字を1文字以上含める必要があります。 | STRING | はい | 複数行テキスト |
| `resolution` | 出力ビデオの解像度。 | COMBO | はい | "768P"<br />"2K" |
| `duration` | 出力ビデオの長さ（秒）。デフォルト: 5。 | INT | はい | 4 から 15 |

### MiniMax H3 Max および MiniMax H3 Max Turbo 入力

これらの設定は、`model` セレクターで `MiniMax H3 Max` または `MiniMax H3 Max Turbo` のいずれかを選択したときに表示されます。両方のモデルは同じ設定を公開しています。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | ビデオ生成用のテキストプロンプト。空文字または空白のみにすることはできません。また、50,000文字に制限されています。 | STRING | はい | 複数行テキスト |
| `resolution` | 出力ビデオの解像度。デフォルト: 768P。 | COMBO | はい | "480P"<br />"768P" |
| `duration` | 出力ビデオの長さ（秒）。デフォルト: 5。 | INT | はい | 5 から 15 |
| `prompt_expansion_mode` | 生成前にプロンプトの書き換えに費やす労力。デフォルト: balanced。 | COMBO | はい | "balanced"<br />"quality" |

**制約に関する注意事項:**

- プロンプトにはテキストが含まれている必要があります。空または空白のみのプロンプトは拒否されます。
- 提供されるフレーム画像は、幅256ピクセル以上、高さ256ピクセル以上で、幅と高さのアスペクト比が0.4から2.5（約2:5から5:2）の間である必要があります。この要件は `first_frame` と、提供される場合は `last_frame` に適用されます。
- `last_frame` が省略された場合、ビデオは最初のフレームのみから生成されます。
- 出力ビデオは、提供された画像のアスペクト比に従います。
- `watermark` は `MiniMax H3` でのみサポートされています。`MiniMax H3 Max` または `MiniMax H3 Max Turbo` で有効にするとエラーが発生します。
- 動画の長さは、`MiniMax H3` では4秒から15秒、`MiniMax H3 Max` および `MiniMax H3 Max Turbo` では5秒から15秒の範囲です。
