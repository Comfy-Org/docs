このノードは、MiniMax H3 モデルを使用して、最初のフレーム画像と、必要に応じて最後のフレーム画像からビデオを生成します。ビデオは提供された画像のアスペクト比に従い、最後のフレームが指定されている場合は、最初のフレームから最後のフレームに向かってアニメーションします。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | ビデオ生成に使用するモデル。モデルを選択すると、そのモデル固有の設定（プロンプト、解像度、期間）が表示されます。 | DYNAMIC_COMBO | 必須 | "MiniMax H3" |
| `最初のフレーム` | ビデオの最初のフレーム画像。生成されるビデオのアスペクト比はこの画像に従います。画像は256x256ピクセル以上で、幅と高さのアスペクト比が0.4～2.5の範囲である必要があります。 | IMAGE | 必須 | - |
| `最後のフレーム` | ビデオの任意の最後のフレーム画像。指定すると、ビデオは最初のフレームから始まり、この画像で終わります。`first_frame` と同じサイズとアスペクト比の要件を満たす必要があります。 | IMAGE | 任意 | - |
| `シード` | 乱数シード。同じシードを使用した同じリクエストは類似した結果になりますが、同一の結果になるとは保証されません。生成ごとにランダム化するための「生成後のコントロール」オプションが含まれます。デフォルト: 42。 | INT | 必須 | 0 ～ 4294967295 |
| `ウォーターマーク` | ビデオにAIGC透かしを追加するかどうか。詳細設定パラメータです。デフォルト: False。 | BOOLEAN | 必須 | True<br />False |

### MiniMax H3 入力

これらの入力は、`model` セレクターで「MiniMax H3」を選択したときに表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | ビデオ生成用のテキストプロンプト。空白以外の文字を少なくとも1つ含む必要があります。 | STRING | 必須 | - |
| `resolution` | 出力ビデオの解像度。 | COMBO | 必須 | "768P"<br />"2K" |
| `duration` | 出力ビデオの長さ（秒）（4～15）。デフォルト: 5。 | INT | 必須 | 4 ～ 15 |

**制約に関する注意:**
- `model` コンボ内のテキストプロンプトは空にできません。空白のみのプロンプトは拒否されます。
- 提供されるフレーム画像（`first_frame` と、使用する場合は `last_frame`）は、幅256ピクセル以上、高さ256ピクセル以上で、幅と高さのアスペクト比が0.4～2.5（おおよそ2:5～5:2）である必要があります。
- `last_frame` はオプションです。省略した場合、ビデオは最初のフレームのみから生成されます。
- 出力ビデオのアスペクト比は、別の比率設定ではなく、提供された画像によって決まります。
