JsonExtractString ノードは、テキスト文字列を走査して最初の有効な JSON オブジェクトを見つけ、特定のキーに関連付けられた値を文字列に変換して抽出します。JSON オブジェクトの前後にあるテキストは無視されるため、Markdown コードブロックや、JSON を追加の文章で包んだモデルの応答にも使用できます。有効な JSON オブジェクトが見つからない場合、キーが見つからない場合、または値が null の場合は、ノードは空文字列を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `json_string` | JSON オブジェクトを検索するテキスト。このフィールドは複数行入力に対応しており、周囲の文章や Markdown コードフェンスを含む場合があります。 | STRING | はい | N/A |
| `key` | JSON オブジェクトから値を抽出したい特定のキー。このフィールドは単一行入力のみに対応しています。 | STRING | はい | N/A |

**注記:** ノードは JSON オブジェクト（辞書）からのみ値を抽出します。入力内の各 `{` を順番に試し、有効な JSON オブジェクトを生成できる最初の位置からデコードするため、前後のテキストはスキップされます。JSON オブジェクトをデコードできない場合、または指定したキーがその中に存在しない場合、出力は空文字列になります。キーに関連付けられた値が `null` の場合も、ノードは空文字列を返します。文字列以外の値は、その文字列表現として返されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | 指定したキーについて JSON から抽出された文字列値。抽出に失敗した場合は空文字列。 | STRING |
