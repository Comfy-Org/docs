LoraModelLoader ノードは、トレーニング済みの LoRA（Low-Rank Adaptation）ウェイトを拡散モデルに適用します。トレーニング済みの LoRA モデルから LoRA ウェイトを読み込み、その影響度を調整することでベースモデルを変更します。これにより、ゼロから再トレーニングすることなく拡散モデルの動作をカスタマイズでき、ベースモデルのウェイトを変更しないバイパスモードも利用できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | LoRA が適用される拡散モデル。 | MODEL | はい | - |
| `LoRA` | 拡散モデルに適用する LoRA モデル。 | LORA_MODEL | はい | - |
| `モデル強度` | 拡散モデルをどの程度強く変更するか。この値は負の値にすることもできます（デフォルト: 1.0）。 | FLOAT | はい | -100.0〜100.0 |
| `バイパス` | 有効にすると、ベースモデルのウェイトを変更せずに LoRA をバイパスモードで適用します。トレーニング時やモデルウェイトがオフロードされている場合に便利です（デフォルト: False）。 | BOOLEAN | はい | True or False |

**注記:** `strength_model` が 0 に設定されている場合、ノードは LoRA の変更を適用せずに元のモデルを返します。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `model` | LoRA ウェイトが適用された変更後の拡散モデル。 | MODEL |
