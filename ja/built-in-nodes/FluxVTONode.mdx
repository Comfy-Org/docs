このノードは、指定した衣装画像を人物に着せる仮想試着を行います。人物画像と衣装画像を BFL Flux VTO サービスに送信し、その人物が衣装を着ているリアルな画像を生成します。任意のテキスト指示で、衣装のフィット感や見え方を指定できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `人物` | 衣装を着せる人物の画像。 | IMAGE | はい | - |
| `衣服` | 適用する衣装の画像。 | IMAGE | はい | - |
| `プロンプト` | 任意の自然言語によるスタイリング指示（例：衣装のフィット感）。デフォルトは空文字列です。 | STRING | いいえ | - |
| `シード` | ノイズ生成に使用する乱数シード。デフォルト：0。 | INT | いいえ | 0～18446744073709551615 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 提供された衣装を着ている人物を表す結果画像。 | IMAGE |
