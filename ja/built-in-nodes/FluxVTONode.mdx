このノードは、提供された衣類画像を人物に着せて仮想試着を実行します。BFL Flux VTO API を使用して、指定された衣類を着用した人物のリアルな画像を生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `人物` | 着せ替え対象の人物の画像。 | IMAGE | はい | - |
| `衣服` | 適用する衣類の画像。 | IMAGE | はい | - |
| `プロンプト` | 任意の自然言語によるスタイリング指示（例：衣類のフィット感など）。（デフォルト：空） | STRING | いいえ | - |
| `シード` | ノイズ生成に使用されるランダムシード。（デフォルト：0） | INT | いいえ | 0〜18446744073709551615 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 提供された衣類を着用した人物を示す結果画像。 | IMAGE |
