このノードは、画像の背景を Bria によって生成された新しい背景に置き換えます。新しい背景は、テキストプロンプトで記述するか、参照画像で誘導できます。被写体のピクセルは保持されたまま、その周囲に背景が生成されます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | 背景を置き換える入力画像。 | IMAGE | はい | |
| `背景` | プロンプトで新しい背景を記述するか、参照画像で誘導します。 | DYNAMIC_COMBO | はい | `"prompt"`<br />`"reference images"` |
| `元の品質` | 結果を約1メガピクセルにスケーリングする代わりに、入力の正確なピクセルサイズを返します。大きな入力は大きな画像を返します。（デフォルト: false） | BOOLEAN | いいえ | `true`<br />`false` |
| `シード` | 同じ `seed` は通常同じ背景を返しますが、自動プロンプト改善によって変動する場合があります。（デフォルト: 42） | INT | いいえ | 0～2147483647 |
| `モデレーション` | モデレーション設定。（デフォルト: "false"） | DYNAMIC_COMBO | いいえ | `"false"`<br />`"true"` |

### プロンプト入力

`background` が `"prompt"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 新しい背景の説明。#FF5733 などの16進カラーコードを指定すると、単色の背景が生成されます。少なくとも1文字以上である必要があります。 | STRING | はい | |
| `mode` | `high_control` はプロンプトに最も忠実に従い、`base` はバランスの取れたデフォルトで、`fast` は速度と引き換えに詳細を犠牲にします。 | COMBO | はい | `"high_control"`<br />`"base"`<br />`"fast"` |
| `refine_prompt` | より良い結果を得るためにプロンプトを書き換えます。英語以外のプロンプトも翻訳されます。オフにすると、書かれたとおりにプロンプトを送信します。（デフォルト: true） | BOOLEAN | いいえ | `true`<br />`false` |

### 参照画像入力

`background` が `"reference images"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `ref_images` | 拡張可能なスロット: 新しい背景を導く1～10枚の画像を接続します。サイズが揃っている必要はありません。各参照は結果を変えるため、矛盾の多い参照より一貫性のある少数の参照の方が優れています。バッチ入力は画像ごとに1回としてカウントされます。 | IMAGE | はい | 1～10枚の画像 |
| `enhance_ref_images` | より良い結果を得るために参照画像を追加処理します。（デフォルト: true） | BOOLEAN | いいえ | `true`<br />`false` |

### モデレーション入力

`moderation` が `"true"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | プロンプト内容のモデレーションを有効にします。（デフォルト: false） | BOOLEAN | いいえ | `true`<br />`false` |
| `visual_input_moderation` | 視覚入力のモデレーションを有効にします。（デフォルト: false） | BOOLEAN | いいえ | `true`<br />`false` |
| `visual_output_moderation` | 視覚出力のモデレーションを有効にします。（デフォルト: false） | BOOLEAN | いいえ | `true`<br />`false` |

**注意:** `ref_images` 入力は最大10枚の画像を受け付けます。10枚を超えて指定するとエラーが返されます。`prompt` フィールドには少なくとも1文字以上を含める必要があります。`original_quality` が false の場合、入力画像は処理前に約1メガピクセルにダウンスケールされます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 新しい背景を持つ画像。 | IMAGE |
| `refined_prompt` | Bria が生成の基にしたプロンプト。参照画像パスでは空です。 | STRING |
