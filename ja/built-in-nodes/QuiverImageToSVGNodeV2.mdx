Quiver AI を使用して、ラスター画像をスケーラブルベクターグラフィック（SVG）にベクター化します。画像は Quiver AI の API に送信され、ベクター化された結果が返されます。

`model` を選択すると、以下に示すモデル固有のパラメータが表示されます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | SVG ベクター化に使用するモデル。 | DYNAMIC_COMBO | はい | `"arrow-2"`<br />`"arrow-2-telos"` |
| `image` | ベクター化する入力画像。 | IMAGE | はい | N/A |
| `auto_crop` | 主要な被写体に自動でクロップします。詳細設定パラメータ（デフォルト: False）。 | BOOLEAN | はい | `True`<br />`False` |
| `target_size` | ベクター化前に入力画像に適用する正方形リサイズ（ピクセル単位）。0 はソースのサイズを維持し、強制的にリサイズするよりもきれいにベクター化できます。128 未満のその他の値は 128 にクランプされます。これは出力キャンバスを設定するものではありません。その用途には `width` と `height` を使用してください。詳細設定パラメータ（デフォルト: 0）。 | INT | はい | 0 ～ 4096 |
| `width` | 出力 SVG キャンバス（viewBox）の幅（ユーザー単位）。出力サイズとアスペクト比を制御するには `width` と `height` の両方を設定します。どちらかを 0 のままにするとモデルに選択させますが、通常は正方形のキャンバスになります。詳細設定パラメータ（デフォルト: 0）。 | INT | はい | 0 ～ 8192 |
| `height` | 出力 SVG キャンバス（viewBox）の高さ（ユーザー単位）。出力サイズとアスペクト比を制御するには `width` と `height` の両方を設定します。どちらかを 0 のままにするとモデルに選択させますが、通常は正方形のキャンバスになります。詳細設定パラメータ（デフォルト: 0）。 | INT | はい | 0 ～ 8192 |
| `seed` | ノードを再実行するかどうかを決定するシード。実際の結果はシード値に関係なく非決定的です。このパラメータには「生成後の制御」機能があります（デフォルト: 42）。 | INT | はい | 0 ～ 2147483647 |

### モデル固有の入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | モデルが描画前に費やす推論の量。高いレベルほど詳細が向上し、より多くのトークンを消費します。`"arrow-2"` および `"arrow-2-telos"` モデルでのみ使用されます（デフォルト: `"high"`）。 | COMBO | はい | `"low"`<br />`"medium"`<br />`"high"`<br />`"xhigh"` |
| `temperature` | ランダム性の制御。値が高いほどランダム性が増します。`"arrow-2-telos"` モデルでは使用されません。詳細設定パラメータ（デフォルト: 1.0）。 | FLOAT | はい | 0.0 ～ 2.0（ステップ 0.1） |
| `top_p` | Nucleus サンプリングパラメータ。`"arrow-2-telos"` モデルでは使用されません。詳細設定パラメータ（デフォルト: 1.0）。 | FLOAT | はい | 0.05 ～ 1.0（ステップ 0.05） |
| `presence_penalty` | トークン存在ペナルティ。`"arrow-2-telos"` モデルでは使用されません。詳細設定パラメータ（デフォルト: 0.0）。 | FLOAT | はい | -2.0 ～ 2.0（ステップ 0.1） |

**注:** `target_size` はベクター化前に適用され、出力キャンバスは変更しません。`width` または `height` を 0 のままにすると、モデルにキャンバスサイズを選択させます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `SVG` | ベクター化された SVG 出力。 | SVG |
