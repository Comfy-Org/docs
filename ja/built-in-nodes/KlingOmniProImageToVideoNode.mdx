このノードは、Kling AI モデルを使用して、テキストプロンプトと最大 7 枚の参照画像に基づいて動画を生成します。動画のアスペクト比、再生時間、解像度を制御でき、任意でストーリーボードを使用したり音声を生成したりできます。このノードはリクエストを外部 API に送信し、生成された動画を返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | 動画生成に使用する特定の Kling モデル（デフォルト：`"kling-v3-omni"`）。 | COMBO | はい | `"kling-v3-omni"`<br />`"kling-video-o1"` |
| `プロンプト` | 動画内容を説明するテキストプロンプト。肯定的な説明と否定的な説明の両方を含めることができます。ストーリーボードが有効な場合は無視されます。`@image` や `@video`（任意で番号付き）などのプレースホルダーは、API 互換形式に自動変換されます。1～2500文字である必要があります（ストーリーボードが有効な場合は空でもかまいません）。 | STRING | はい | 1 〜 2500 characters (0 〜 2500 when storyboards are enabled) |
| `アスペクト比` | 生成される動画の希望アスペクト比。 | COMBO | はい | `"16:9"`<br />`"9:16"`<br />`"1:1"` |
| `継続時間` | 動画の長さ（秒）。スライダーで調整します（デフォルト：5）。 | INT | はい | 3 〜 15 |
| `リファレンス画像` | 最大7枚の参照画像。各画像は少なくとも 300x300 ピクセルで、アスペクト比が 1:2.5～2.5:1 の範囲である必要があります。 | IMAGE | はい | 1 〜 7 images |
| `解像度` | 動画の出力解像度（デフォルト：`"1080p"`）。 | COMBO | いいえ | `"4k"`<br />`"1080p"`<br />`"720p"` |
| `ストーリーボード` | 個別のプロンプトと再生時間を持つ一連の動画セグメントを生成します。`kling-v3-omni` でのみサポートされています。有効にすると、グローバルな `prompt` は無視され、すべてのストーリーボードセグメントの合計再生時間はグローバルな `duration` と等しくなければなりません（デフォルト：`"disabled"`）。 | DYNAMIC_COMBO | いいえ | `"disabled"`<br />`"1 storyboard"`<br />`"2 storyboards"`<br />`"3 storyboards"`<br />`"4 storyboards"`<br />`"5 storyboards"`<br />`"6 storyboards"` |
| `音声を生成` | 動画の音声を生成します。`kling-v3-omni` でのみサポートされています（デフォルト：false）。 | BOOLEAN | いいえ | `true`<br />`false` |
| `シード` | シードはノードを再実行するかどうかを制御します。シードに関係なく、結果は非決定的です（デフォルト：0）。 | INT | いいえ | 0 〜 2147483647 |

### ストーリーボード入力

`storyboards` が有効な場合、選択されたストーリーボードセグメントごとに次の入力が表示されます。N は 1 から、選択したストーリーボード数までの範囲です。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | ストーリーボードセグメント N のプロンプト。最大512文字。 | STRING | はい | 1 〜 512 characters |
| `storyboard_N_duration` | ストーリーボードセグメント N の再生時間（秒）（デフォルト：4）。 | INT | はい | 1 〜 15 |

**注記：** `reference_images` 入力は最大 7 枚の画像を受け付けます。それより多く指定された場合、ノードはエラーを発生させます。各画像は最小寸法（300x300 ピクセル）とアスペクト比（1:2.5～2.5:1 の範囲）について検証されます。

**モデル固有の制約：**
- `kling-video-o1` は 10 秒を超える再生時間をサポートしていません。
- `kling-video-o1` は音声生成をサポートしていません。
- `kling-video-o1` は 4k 解像度をサポートしていません。
- `kling-video-o1` はストーリーボードをサポートしていません。

**ストーリーボードの制約：** すべてのストーリーボードセグメントの合計再生時間は、グローバルな `duration` 値と等しくなければなりません。合計が一致しない場合、ノードはエラーを発生させます。
