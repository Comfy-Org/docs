このノードは、Kling AIモデルを使用して、テキストプロンプトと最大7枚の参照画像に基づいてビデオを生成します。ビデオのアスペクト比、長さ、解像度を制御でき、必要に応じてストーリーボードを使用したり、音声を生成したりすることもできます。ノードはリクエストを外部APIに送信し、生成されたビデオを返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | ビデオ生成に使用する具体的なKlingモデル（デフォルト: `"kling-v3-omni"`）。 | COMBO | はい | `"kling-v3-omni"`<br />`"kling-video-o1"` |
| `プロンプト` | ビデオの内容を説明するテキストプロンプト。ポジティブな記述とネガティブな記述の両方を含めることができます。ストーリーボードが有効な場合は無視されます。`@image` や `@video`（必要に応じて番号付き）などのプレースホルダーは、API互換の形式に自動変換されます。1文字以上2500文字以内である必要があります（ストーリーボードが有効な場合は空にできます）。 | STRING | はい | 1〜2500文字 |
| `アスペクト比` | 生成されるビデオの希望するアスペクト比。 | COMBO | はい | `"16:9"`<br />`"9:16"`<br />`"1:1"` |
| `継続時間` | ビデオの長さ（秒単位）。スライダーで調整します（デフォルト: 5）。 | INT | はい | 3〜15 |
| `リファレンス画像` | 最大7枚の参照画像。各画像は300x300ピクセル以上で、アスペクト比が1:2.5から2.5:1の間である必要があります。 | IMAGE | はい | 1〜7枚 |
| `解像度` | ビデオの出力解像度（デフォルト: `"1080p"`）。 | COMBO | いいえ | `"4k"`<br />`"1080p"`<br />`"720p"` |
| `ストーリーボード` | 個別のプロンプトと長さを持つ一連のビデオセグメントを生成します。`kling-v3-omni` でのみサポートされています。有効にすると、グローバルな `prompt` は無視され、すべてのストーリーボードセグメントの合計時間がグローバルな `duration` と等しくなければなりません（デフォルト: `"disabled"`）。 | DYNAMIC_COMBO | いいえ | `"disabled"`<br />`"1 storyboard"`<br />`"2 storyboards"`<br />`"3 storyboards"`<br />`"4 storyboards"`<br />`"5 storyboards"`<br />`"6 storyboards"` |
| `音声を生成` | ビデオの音声を生成します。`kling-v3-omni` でのみサポートされています（デフォルト: false）。 | BOOLEAN | いいえ | `true`<br />`false` |
| `シード` | シードはノードを再実行するかどうかを制御します。シードに関係なく結果は非決定的です（デフォルト: 0）。 | INT | いいえ | 0〜2147483647 |

### ストーリーボード入力

`storyboards` が有効な場合、選択した各ストーリーボードセグメントに対して次の入力が表示されます。N は 1 から選択したストーリーボード数までの範囲です。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | ストーリーボードセグメントNのプロンプト。最大512文字。 | STRING | はい | 1〜512文字 |
| `storyboard_N_duration` | ストーリーボードセグメントNの長さ（秒単位）（デフォルト: 4）。 | INT | はい | 1〜15 |

**注:** `reference_images` 入力は最大7枚の画像を受け付けます。それ以上提供された場合、ノードはエラーを発生させます。各画像は最小寸法とアスペクト比について検証されます。

**モデル固有の制約:**
- `kling-video-o1` は10秒を超える長さをサポートしていません。
- `kling-video-o1` は音声生成をサポートしていません。
- `kling-video-o1` は4K解像度をサポートしていません。
- `kling-video-o1` はストーリーボードをサポートしていません。
