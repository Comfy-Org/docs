The Tencent HY Image: Text to Image ノードは、Tencent の Hunyuan Image モデルを使用して、テキスト記述から画像を生成します。プロンプトは API に送信され、レンダリング前に API によって書き換え・拡張され、完成した画像は画像バッチとして返されます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 生成に使用するモデルです。選択したモデルによって、表示される追加入力が決まります。 | DYNAMIC_COMBO | はい | `"hy-image-3.5-preview"` |

### hy-image-3.5-preview 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成する画像を記述します。モデルはレンダリング前にこれを書き換え・拡張します。空にできません（デフォルト: 空）。 | STRING | はい | 任意のテキスト |
| `aspect_ratio` | 出力のアスペクト比です。`"auto"` はプロンプトからモデルに比率を選ばせ、4K では使用できません。`resolution` が `"custom"` の場合、無視されます。 | COMBO | はい | `"auto"`<br />`"1:1"`<br />`"3:2"`<br />`"2:3"`<br />`"4:3"`<br />`"3:4"`<br />`"16:9"`<br />`"9:16"`<br />`"21:9"`<br />`"9:21"`（デフォルト: `"auto"`） |
| `resolution` | 画像のピクセル領域です。1K は約 1024x1024、2K は約 2048x2048、4K は約 4096x4096 です。2K を超えるものは 2K でレンダリングされ、モデルによってアップスケールされます。プリセット領域の代わりに `width` と `height` を使用するには、`"custom"` に設定します。 | COMBO | はい | `"1K"`<br />`"2K"`<br />`"4K"`<br />`"custom"`（デフォルト: `"2K"`） |
| `width` | 画像の幅（ピクセル単位）です。`resolution` が `"custom"` の場合にのみ使用されます。 | INT | はい | 256-8192、16 刻み（デフォルト: 2048） |
| `height` | 画像の高さ（ピクセル単位）です。`resolution` が `"custom"` の場合にのみ使用されます。 | INT | はい | 256-8192、16 刻み（デフォルト: 2048） |
| `seed` | 生成に使用するシードです。同じシードでも実行ごとに結果は変動します。 | INT | はい | 0-2147483647（デフォルト: 42） |
| `watermark` | 結果に AI 生成のウォーターマークを追加するかどうかです。これは詳細設定パラメータです。 | BOOLEAN | いいえ | true<br />false（デフォルト: false） |

`prompt` は空にできません。`"custom"` 解像度では、`width` と `height` はどちらも 16 の倍数である必要があり、それらの積は 4096 x 4096 ピクセルの領域上限（約 16.7 メガピクセル）を超えてはなりません。任意のアスペクト比が使用できますが、およそ 6:1 を超えるとモデルは被写体を繰り返し始めます。`"auto"` アスペクト比はモデルにサイズを選択させる必要があるため、2K の領域上限内でのみ機能します。4K では、明示的なアスペクト比を選択するか、`"custom"` を使用してください。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | 生成された画像です。 | IMAGE |
