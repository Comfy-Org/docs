Kling 4.0 モデルでテキストプロンプトから音声付きの動画を生成します。このノードは、プロンプトと生成設定を Kling API に送信し、タスクが完了するまで待機して、完成した動画を返します。参照メディアを使わず、説明だけからクリップを作成する必要がある場合に使用します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | モデルセレクターです。`"kling-4.0"` は最大 1080p、30 秒までサポートします。`"kling-4.0-flash"` は 720p、20 秒に制限されています。モデルを選択すると、その入力が以下に表示されます。 | DYNAMIC_COMBO | はい | `"kling-4.0"`<br />`"kling-4.0-flash"` |

### kling-4.0 入力

これらの入力は、`model` が `"kling-4.0"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成する動画のテキスト説明です。1～26000 文字である必要があります。 | STRING | はい | 1～26000 文字 |
| `resolution` | 出力動画の解像度です。デフォルト: `"720p"`。 | COMBO | はい | `"720p"`<br />`"1080p"` |
| `aspect_ratio` | 出力動画のアスペクト比です。デフォルト: `"16:9"`。 | COMBO | はい | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `duration` | 生成される動画の長さ（秒）です。デフォルト: 5。 | INT | はい | 3～30 |
| `seed` | シードはノードを再実行するかどうかを制御します。シードに関係なく結果は非決定的です。デフォルト: 42。 | INT | はい | 0～2147483647 |

### kling-4.0-flash 入力

これらの入力は、`model` が `"kling-4.0-flash"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成する動画のテキスト説明です。1～26000 文字である必要があります。 | STRING | はい | 1～26000 文字 |
| `resolution` | 出力動画の解像度です。Flash は 720p のみでレンダリングします。デフォルト: `"720p"`。 | COMBO | はい | `"720p"` |
| `aspect_ratio` | 出力動画のアスペクト比です。デフォルト: `"16:9"`。 | COMBO | はい | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `duration` | 生成される動画の長さ（秒）です。デフォルト: 5。 | INT | はい | 3～20 |
| `seed` | シードはノードを再実行するかどうかを制御します。シードに関係なく結果は非決定的です。デフォルト: 42。 | INT | はい | 0～2147483647 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | 生成された動画です。タスク完了後にプロバイダーからダウンロードされます。 | VIDEO |
