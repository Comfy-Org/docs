Kling 4.0 モデルを使用し、音声を含む動画をテキストプロンプトから生成します。このノードはプロンプトと生成設定を Kling API に送信し、タスクの完了を待って、完成した動画を返します。参照メディアを使用せず、説明文だけからクリップを作成する必要がある場合に使用します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | モデルセレクター。`"kling-4.0"` は最大 4K HDR と 30 秒をサポートします。`"kling-4.0-flash"` は 720p と 20 秒に制限されます。モデルを選択すると、その入力が下に表示されます。 | DYNAMIC_COMBO | はい | `"kling-4.0"`<br />`"kling-4.0-flash"` |

### kling-4.0 入力

これらの入力は、`model` が `"kling-4.0"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成する動画のテキスト説明。1～26000 文字である必要があります。 | STRING | はい | 1～26000 文字 |
| `resolution` | 出力動画の解像度。名前に `HDR` を含むオプションは HDR 動画を返します。デフォルト: `"720p"`。 | COMBO | はい | `"720p"`<br />`"1080p"`<br />`"4k"`<br />`"1080p HDR"`<br />`"4k HDR"` |
| `aspect_ratio` | 出力動画のアスペクト比。デフォルト: `"16:9"`。 | COMBO | はい | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 生成される動画の長さ（秒）。デフォルト: 5。 | INT | はい | 3～30 |
| `seed` | シードは、ノードを再実行するかどうかを制御します。結果はシードに関係なく非決定的です。デフォルト: 42。 | INT | はい | 0～2147483647 |

### kling-4.0-flash 入力

これらの入力は、`model` が `"kling-4.0-flash"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成する動画のテキスト説明。1～26000 文字である必要があります。 | STRING | はい | 1～26000 文字 |
| `resolution` | 出力動画の解像度。Flash は 720p のみをレンダリングします。デフォルト: `"720p"`。 | COMBO | はい | `"720p"` |
| `aspect_ratio` | 出力動画のアスペクト比。デフォルト: `"16:9"`。 | COMBO | はい | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 生成される動画の長さ（秒）。デフォルト: 5。 | INT | はい | 3～20 |
| `seed` | シードは、ノードを再実行するかどうかを制御します。結果はシードに関係なく非決定的です。デフォルト: 42。 | INT | はい | 0～2147483647 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | タスク完了後にプロバイダーからダウンロードされる、生成された動画。 | VIDEO |
