ByteDance Image to Video ノードは、入力画像とテキストプロンプトを使用してByteDanceのAPIを利用してビデオを生成します。提供された説明を視覚的に表現するビデオシークエンスを作成し、出力の解像度、アスペクト比、長さ、その他のパラメータをカスタマイズするオプションがあります。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 范囲 |
|------------|------|----------|------|-------|
| `model` | ビデオ生成に使用するByteDanceのモデルです。利用可能なオプションは：<br />`"seedance-1-5-pro-251215"`<br />`"seedance-1-0-pro-250528"`<br />`"seedance-1-0-pro-fast-251015"` | STRING | はい | 上記に記載の通り |
| `prompt` | ビデオ生成に使用するテキストプロンプトです。スペースを削除した後でも少なくとも1文字以上である必要があります。 | STRING | はい | - |
| `image` | ビデオの最初のフレームとして使用される画像です。画像は300x300から6000x6000ピクセルの間で、アスペクト比は0.4から2.5の間でなければなりません。 | IMAGE | はい | - |
| `resolution` | 出力ビデオの解像度です。利用可能なオプションは：<br />`"480p"`<br />`"720p"`<br />`"1080p"` | STRING | はい | 上記に記載の通り |
| `aspect_ratio` | 出力ビデオのアスペクト比です。利用可能なオプションは：<br />`"adaptive"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"` | STRING | はい | 上記に記載の通り |
| `duration` | 出力ビデオの長さ（秒）です。`seedance-1-5-pro-251215`モデルの場合、サポートされる最小長さは4秒です。 | INT | はい | 3 - 12 |
| `seed` | 生成に使用するシードです。オプションで、デフォルト値は0です。 | INT | いいえ | 0 - 2147483647 |
| `camera_fixed` | カメラを固定するかどうかを指定します。プラットフォームはプロンプトにカメラを固定する指示を追加しますが、実際の効果を保証しません。オプションで、デフォルト値はFalseです。 | BOOLEAN | いいえ | - |
| `watermark` | ビデオに「AI生成」というウォーターマークを追加するかどうかを指定します。オプションで、デフォルト値はFalseです。 | BOOLEAN | いいえ | - |
| `generate_audio` | このパラメータは`seedance-1-5-pro-251215`以外のモデルでは無視されます。オプションで、デフォルト値はFalseです。 | BOOLEAN | いいえ | - |

**注意:** プロンプトには以下の単語（大文字小文字を区別しない）を含めないでください：`resolution`、`ratio`、`duration`、`seed`、`camerafixed`、`watermark`。これらのパラメータは専用の入力で設定されます。

## 出力

| 出力名 | 説明 | データ型 |
|--------|------|----------|
| `output` | 入力画像とプロンプトパラメータに基づいて生成されたビデオファイルです。 | VIDEO |
