WanVaceToVideo ノードは、VACE 制御の動画生成モデル用の動画コンディショニングデータを準備します。ポジティブおよびネガティブコンディショニングを、オプションの制御動画、制御マスク、参照画像と組み合わせ、VAE を通してエンコードし、更新されたコンディショニング、空の LATENT テンソル、トリム値を出力します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ポジティブ` | 生成をガイドするためのポジティブコンディショニング入力 | CONDITIONING | はい | - |
| `ネガティブ` | 生成をガイドするためのネガティブコンディショニング入力 | CONDITIONING | はい | - |
| `vae` | 画像および動画フレームのエンコードに使用する VAE モデル | VAE | はい | - |
| `幅` | 出力動画の幅（ピクセル単位、デフォルト: 832、ステップ: 16） | INT | はい | 16～MAX_RESOLUTION |
| `高さ` | 出力動画の高さ（ピクセル単位、デフォルト: 480、ステップ: 16） | INT | はい | 16～MAX_RESOLUTION |
| `長さ` | 動画のフレーム数（デフォルト: 81、ステップ: 4） | INT | はい | 1～MAX_RESOLUTION |
| `バッチサイズ` | 同時に生成する動画の数（デフォルト: 1） | INT | はい | 1～4096 |
| `強度` | VACE 制御の条件強度（デフォルト: 1.0、ステップ: 0.01）。これは LoRA 強度ではありません。LoRA の重みは別個の LoRA ノードを通じて適用されます。 | FLOAT | はい | 0.0～1000.0 |
| `コントロールビデオ` | 制御コンディショニングに使用するオプションの入力動画。指定しない場合は、ニュートラルグレーの動画が自動的に作成されます。 | IMAGE | いいえ | - |
| `コントロールマスク` | 制御動画のどの部分をアクティブにするかを決定するオプションのマスク。指定しない場合は、全面が白のマスクが使用されます。 | MASK | いいえ | - |
| `参照画像` | 追加のコンディショニング用のオプションの参照画像。指定すると、エンコードされて潜在シーケンスの先頭に追加されます。最初の画像のみが使用されます。 | IMAGE | いいえ | - |

**注記:** `control_video` が指定された場合、`length` フレームに切り詰められ、指定された `width` と `height` にアップスケールされます。`length` よりフレーム数が少ない場合、不足分のフレームはニュートラルグレー（値 0.5）でパディングされます。指定されない場合は、`length` フレームのニュートラルグレー動画が自動的に作成されます。`control_masks` は指定された `width` と `height` にアップスケールされ、`length` フレームに切り詰められ、短い場合は値 1.0 でパディングされます。マスクは制御動画を非アクティブ部分と反応部分に分離し、それぞれが VAE エンコードされてチャネル次元に沿って連結されます。マスクは潜在解像度にもダウンサンプリングされます。`reference_image` が指定された場合、その最初の画像が VAE エンコードされて潜在シーケンスの先頭に追加され、`trim_latent` は追加された潜在フレーム数を報告します。潜在フレーム数は `((length - 1) // 4) + 1` として計算され、潜在空間次元は `height / 8` および `width / 8` です。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | 動画制御データ（vace_frames、vace_mask、vace_strength）が適用されたポジティブコンディショニング | CONDITIONING |
| `negative` | 動画制御データ（vace_frames、vace_mask、vace_strength）が適用されたネガティブコンディショニング | CONDITIONING |
| `latent` | 形状 [batch_size, 16, latent_length, height/8, width/8] の、動画生成用の空の LATENT テンソル | LATENT |
| `trim_latent` | 参照画像が使用された場合にトリムする潜在フレーム数。参照画像が指定されない場合は 0 | INT |
