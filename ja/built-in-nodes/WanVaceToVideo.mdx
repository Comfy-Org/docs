WanVaceToVideo ノードは、ビデオ生成モデル向けのビデオ条件付けデータを準備します。このノードは、ポジティブ条件付け入力とネガティブ条件付け入力に加えて、オプションの制御ビデオ、マスク、参照画像を受け取り、ビデオ生成を導く潜在表現にエンコードします。また、アップスケーリング、パディング、マスキング、VAE エンコードを処理して、ビデオモデルに適した条件付け構造を構築します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `ポジティブ` | 生成を導くためのポジティブ条件付け入力 | CONDITIONING | はい | - |
| `ネガティブ` | 生成を導くためのネガティブ条件付け入力 | CONDITIONING | はい | - |
| `vae` | 画像とビデオフレームのエンコードに使用される VAE モデル | VAE | はい | - |
| `幅` | 出力ビデオの幅（ピクセル単位）（デフォルト: 832、ステップ: 16） | INT | はい | 16 to MAX_RESOLUTION |
| `高さ` | 出力ビデオの高さ（ピクセル単位）（デフォルト: 480、ステップ: 16） | INT | はい | 16 to MAX_RESOLUTION |
| `長さ` | ビデオのフレーム数（デフォルト: 81、ステップ: 4） | INT | はい | 1 to MAX_RESOLUTION |
| `バッチサイズ` | 同時に生成するビデオの数（デフォルト: 1） | INT | はい | 1〜4096 |
| `強度` | VACE 制御の条件強度（デフォルト: 1.0、ステップ: 0.01）。これは LoRA の強度ではありません。LoRA の重みは別の LoRA ノードを通じて適用されます。 | FLOAT | はい | 0.0〜1000.0 |
| `コントロールビデオ` | 制御条件付けに使用されるオプションの入力ビデオ。指定しない場合は、ニュートラルグレーのビデオが自動的に作成されます。 | IMAGE | いいえ | - |
| `コントロールマスク` | 制御ビデオのどの部分をアクティブにするかを決定するオプションのマスク。指定しない場合は、全面白のマスクが使用されます。 | MASK | いいえ | - |
| `参照画像` | 追加の条件付けのためのオプションの参照画像。指定すると、エンコードされて潜在シーケンスの先頭に追加されます。 | IMAGE | いいえ | - |

**注記:** `control_video` が指定された場合、`length` フレームに切り詰められ、指定された `width` と `height` に拡大されます。フレーム数が `length` より少ない場合は、不足フレームがニュートラルグレー（値 0.5）でパディングされます。指定されない場合は、`length` フレームのニュートラルグレーのビデオが自動的に作成されます。`control_masks` は指定された `width` と `height` に拡大され、`length` フレームに切り詰められ、短い場合は値 1.0 でパディングされます。マスクは制御ビデオを非アクティブ部分とリアクティブ部分に分け、それぞれが VAE エンコードされてチャンネル次元に沿って連結されます。マスクも潜在解像度にダウンサンプリングされます。`reference_image` が指定された場合、VAE エンコードされて潜在シーケンスの先頭に追加されます。潜在フレーム数は `((length - 1) // 4) + 1` として計算され、潜在空間の次元は `height / 8` と `width / 8` になります。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `ポジティブ` | ビデオ制御データ（vace_frames、vace_mask、vace_strength）が適用されたポジティブ条件付け | CONDITIONING |
| `ネガティブ` | ビデオ制御データ（vace_frames、vace_mask、vace_strength）が適用されたネガティブ条件付け | CONDITIONING |
| `latent` | 形状 [batch_size, 16, latent_length, height/8, width/8] の、ビデオ生成用の空の潜在テンソル | LATENT |
| `トリムlatent` | 参照画像を使用する場合にトリミングする潜在フレーム数。参照画像が指定されていない場合は 0 | INT |
