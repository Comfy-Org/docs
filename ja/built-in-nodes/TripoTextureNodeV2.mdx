このノードは、以前の生成ステップのタスク ID によって識別される、Tripo ワークフロー内の既存の 3D モデルにテクスチャを追加します。PBR マテリアルマップまたは単色テクスチャを生成でき、結果はテキストプロンプト、スタイル画像、または参照画像でガイドできます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | 以前の Tripo ノード（モデル生成またはモデルセグメンテーション）によって生成されたソースモデルのタスク ID。 | MODEL_TASK_ID / SEGMENT_TASK_ID | はい | - |
| `pbr` | PBR マテリアルマップ（ベースカラー、メタリック、ラフネス、ノーマル）。オフにすると単色テクスチャになります。（デフォルト：true） | BOOLEAN | いいえ | true<br />false |
| `texture_seed` | テクスチャ生成に使用されるシード。（デフォルト：42）詳細入力。 | INT | いいえ | 0〜2147483647 |
| `texture_quality` | 生成されるテクスチャの品質。`detailed` = HD テクスチャ、`extreme` = 8K Ultra テクスチャ。（デフォルト："standard"）詳細入力。 | COMBO | いいえ | "standard"<br />"detailed"<br />"extreme" |
| `texture_alignment` | テクスチャをモデルにどのように位置合わせするか。（デフォルト："original_image"）詳細入力。 | COMBO | いいえ | "original_image"<br />"geometry" |
| `texture_prompt` | テクスチャリング用の任意のテキストガイダンス。ソース画像を持たず色を推測できないインポートモデル（Tripo: Import Model）では、実質的に必須です。参照画像と組み合わせることはできません。（デフォルト：空） | STRING | いいえ | - |
| `model_version` | テクスチャモデル：v3.x で生成されたメッシュには v3.0、v2.5 で生成されたメッシュには v2.5 を使用します。（デフォルト：v3_0_20250812） | COMBO | いいえ | Tripo テクスチャモデルのバージョン、デフォルト "v3_0_20250812" |
| `style_image` | テクスチャの芸術的スタイルの参照画像。`texture_prompt` と一緒に使用した場合にのみ有効です。 | IMAGE | いいえ | - |
| `reference` | テクスチャをガイドする参照画像。`texture_prompt` または `style_image` と組み合わせることはできません。（デフォルト："none"） | DYNAMIC_COMBO | いいえ | "none"<br />"image"<br />"multiview" |
| `part_names` | Tripo: Segment Model からテクスチャリングするパーツ名のカンマ区切りリスト。空の場合はすべてのパーツにテクスチャを適用します。（デフォルト：空）詳細入力。 | STRING | いいえ | - |

### 画像参照入力

`reference` が "image" に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | テクスチャが従うべき単一の参照画像。 | IMAGE | はい | - |

### マルチビュー参照入力

`reference` が "multiview" に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image_front` | 正面ビュー（0°）。 | IMAGE | はい | - |
| `image_left` | 左ビュー（90°）。 | IMAGE | はい | - |
| `image_back` | 背面ビュー（180°）。 | IMAGE | はい | - |
| `image_right` | 右ビュー（270°）。 | IMAGE | はい | - |

**パラメータ制約に関する注意：**

- 参照画像（参照モード "image" または "multiview"）は、`texture_prompt` または `style_image` と組み合わせることはできません。
- `style_image` を使用するには、`texture_prompt` を指定する必要があります。
- `texture_prompt` が指定されていない場合、ソースモデルは text-to-model、image-to-model、multiview-to-model、または texture-model タスクから生成されたものでなければなりません。ソース画像を持たないモデル（インポート済み、セグメント化済み、完了済み、またはリトポロジー済みモデル）には `texture_prompt` が必要です。Tripo が参照画像を受け入れるのは、Tripo 自身が生成したモデルのみであるためです。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model task_id` | テクスチャ操作のタスク ID。他の Tripo ノードに渡すことができます。 | MODEL_TASK_ID |
| `GLB` | GLB 形式のテクスチャ済みモデル。ソースがクアッドメッシュまたは FBX インポートの場合は空になります。 | FILE_3D_GLB |
| `FBX` | FBX 形式のテクスチャ済みモデル。Tripo はクアッドメッシュおよび FBX インポートに対して FBX を返します。それ以外の場合は空になります。 | FILE_3D_FBX |
