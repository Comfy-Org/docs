ByteDance テキストからビデオノードは、テキストのプロンプトに基づいて API を通じて ByteDance モデルを使用してビデオを生成します。テキストの説明とさまざまなビデオ設定を入力として受け取り、提供された仕様に一致するビデオを作成します。ノードは API 通信を処理し、生成されたビデオを出力として返します。

## 概要

ByteDance テキストからビデオノードは、テキストのプロンプトをビデオに変換するために ByteDance の AI 機能を使用するように設計されています。ユーザーはモデル、解像度、アスペクト比、長さ、その他のパラメータを指定してビデオ生成プロセスを制御できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 范囲 |
|------------|------|----------|------|-------|
| `モデル` | 生成に使用する ByteDance モデル | STRING | はい | 
  - "seedance-1-5-pro-251215"
  - "seedance-1-0-pro-250528"
  - "seedance-1-0-pro-fast-251015" |
| `プロンプト` | ビデオ生成に使用するテキストプロンプト | STRING | はい | 多行テキスト入力 |
| `解像度` | 出力ビデオの解像度 | STRING | はい | 
  - "480p"
  - "720p"
  - "1080p" |
| `アスペクト比` | 出力ビデオのアスペクト比 | STRING | はい | 
  - "16:9"
  - "4:3"
  - "1:1"
  - "3:4"
  - "9:16"
  - "21:9" |
| `長さ` | 出力ビデオの長さ（秒） | INT | はい | 3秒から12秒 |
| `シード` | 生成に使用するシード | INT | いいえ | 0から2,147,483,647 |
| `カメラ固定` | カメラを固定するかどうかを指定 | BOOLEAN | いいえ | - |
| `透かし` | ビデオに「AI 生成」というウォーターマークを追加するかどうか | BOOLEAN | いいえ | - |
| `generate_audio` | このパラメータは `seedance-1-5-pro-251215` 以外のモデルでは無視されます | BOOLEAN | いいえ | - |

**パラメータ制約：**

- `prompt` は、スペースを削除した後でも少なくとも1文字含まれている必要があります。
- `prompt` には、以下のテキストパラメータを含めることはできません：「resolution」、「ratio」、「duration」、「seed」、「camerafixed」、「watermark」。
- `duration` は、3秒から12秒の範囲で限定されます。
- `seedance-1-5-pro-251215` モデルの場合、最小サポート長さは4秒です。
- `seed` は、0から2,147,483,647の値を受け入れます。
- `generate_audio` パラメータは、`model` が `seedance-1-5-pro-251215` に設定されている場合にのみ効果があります；他のすべてのモデルでは無視されます。
