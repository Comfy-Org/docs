The ByteDance Text to Video ノードは、テキストプロンプトに基づき、ByteDance モデルを API 経由で使用して動画を生成します。プロンプトを入力し、モデル、解像度、アスペクト比、長さなどの設定を選択すると、ノードが生成リクエストを送信し、生成された動画を返します。

**注記:** BytePlus は 2026 年 11 月 11 日に Seedance 1.5 Pro モデルを終了するため、このノードでは選択できなくなり、このモデルで保存したワークフローは実行できません。代わりに `seedance-1-0-pro-250528`、`seedance-1-0-pro-fast-251015`、または [Seedance 2.5 パートナーノード](https://docs.comfy.org/ja/tutorials/partner-nodes/bytedance/seedance-2-5) を使用してください。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 動画の生成に使用する ByteDance モデル（デフォルト: `"seedance-1-0-pro-fast-251015"`）。 | COMBO | はい | `"seedance-1-0-pro-250528"`<br />`"seedance-1-0-pro-fast-251015"` |
| `プロンプト` | 動画の生成に使用するテキストプロンプト。 | STRING | はい | - |
| `解像度` | 出力動画の解像度。 | COMBO | はい | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `アスペクト比` | 出力動画のアスペクト比。 | COMBO | はい | `"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"` |
| `長さ` | 出力動画の長さ（秒）（デフォルト: 5）。 | INT | はい | 3〜12 |
| `シード` | 生成に使用するシード（デフォルト: 0）。 | INT | いいえ | 0〜2147483647 |
| `カメラ固定` | カメラを固定するかどうかを指定します。プラットフォームはカメラを固定する指示をプロンプトに追加しますが、実際の効果は保証されません（デフォルト: False）。 | BOOLEAN | いいえ | - |
| `透かし` | 動画に「AI 生成」の透かしを追加するかどうか（デフォルト: False）。 | BOOLEAN | いいえ | - |
| `generate_audio` | AI 生成の音声トラックを追加します。残りのモデルではこの入力は無視されます（デフォルト: False）。 | BOOLEAN | いいえ | - |

**パラメータの制約事項:**

- `prompt` パラメータには、空白を除去した後に少なくとも1文字が含まれている必要があります。
- `prompt` パラメータには、次のテキストパラメータを含めることはできません: "resolution", "ratio", "duration", "seed", "camerafixed", "watermark"。
- ノードは、選択した `resolution`、`aspect_ratio`、`duration`、`seed`、`camera_fixed`、`watermark` の各設定をプロンプトテキストに追加して、最終的なプロンプトを構築します。
- `duration` パラメータは 3 秒から 12 秒の範囲に制限されます。
- `seed` パラメータは 0 から 2,147,483,647 の値を受け入れます。
- `generate_audio` パラメータは互換性のために残されていますが、残りのモデルでは無視されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された動画ファイル | VIDEO |
