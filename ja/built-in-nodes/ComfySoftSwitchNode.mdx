Soft Switch ノードは、ブール条件に基づいて2つの入力値のいずれかを選択します。`switch` が true の場合は `on_true` 入力の値を出力し、`switch` が false の場合は `on_false` 入力の値を出力します。このノードは遅延評価（lazy）になるよう設計されており、switch の状態に基づいて必要な入力のみを評価します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `switch` | どの入力を通過させるかを決定するブール条件です。true の場合は `on_true` 入力が選択され、false の場合は `on_false` 入力が選択されます。 | BOOLEAN | はい | True or False |
| `on_false` | `switch` 条件が false の場合に出力する値です。この入力は任意ですが、`on_false` と `on_true` の少なくともいずれか一方を接続する必要があります。 | MATCH_TYPE | いいえ | Same data type as `on_true` |
| `on_true` | `switch` 条件が true の場合に出力する値です。この入力は任意ですが、`on_false` と `on_true` の少なくともいずれか一方を接続する必要があります。 | MATCH_TYPE | いいえ | Same data type as `on_false` |

**注記:** `on_false` と `on_true` の入力は、ノードの内部テンプレートで定義されているように、同じデータ型である必要があります。ノードが機能するには、これらの2つの入力のうち少なくとも1つを接続する必要があります。このノードは遅延評価のため、接続されている入力が1つだけの場合、`switch` の状態に関係なく、常にその入力の値を出力します。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | 選択された値です。接続されている `on_false` または `on_true` 入力のデータ型と一致します。両方の入力が接続されている場合は、`switch` が true なら `on_true` を、false なら `on_false` を出力します。 | MATCH_TYPE |
