選択可能なスタイルを使用して、3D身体ポーズデータを画像にレンダリングします。このノードは、SAM3Dボディトラッカー（MHR）からのポーズデータ、またはKimodoなどの外部Y-upリグからのポーズデータを受け入れ、結果をオプションの背景画像（指定がない場合は黒いキャンバス）上に合成できます。利用可能なレンダースタイルには、シェーディングされた3Dメッシュ、バイナリシルエット、2Dおよび3DのOpenPose形式スケルトン、SCAIL形式のボディカプセルが含まれます。

### 注記

- `width` と `height` の両方が 0 の場合、出力はポーズデータのネイティブ画像サイズを使用します。一方のみが設定されている場合、もう一方は元のアスペクト比を維持して導出されます。接続された `background` は、レンダー解像度に合わせてリサイズされます。
- `camera_info` が接続されている場合、ポーズは予測されたカメラではなく、そのカメラを通して再投影されます。
- メッシュモードでは、`rainbow_tilt_z` と `rainbow_tilt_x` は、`shader` が "rainbow"、"rainbow_face_normal"、または "rainbow_face_semantic" に設定されている場合のみ使用できます。
- メッシュモードで `region` が "hands_only" の場合、手領域フィルターはポーズデータに手頂点マスクが含まれている必要があります。マスクが存在しない場合は、代わりに完全なメッシュがレンダリングされます。
- scailモードでは、手は3Dカプセルとしてではなく、3Dカプセル身体の上に2D OpenPoseオーバーレイとして描画されます。`hand_style` を "disabled" に設定すると完全に削除されます。
- 出力解像度がポーズデータのネイティブ解像度と異なる場合、openpose_2d のマーカーとスティックのサイズは比例してスケーリングされます。
- 背景のフレーム数がポーズデータより少ない場合、最後の背景フレームが残りのフレームに再利用されます。
- 出力には入力ポーズフレームごとに1フレームが含まれます。ポーズデータにフレームが含まれていない場合は、単一の黒い画像が返されます。
