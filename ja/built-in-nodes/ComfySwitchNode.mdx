If/Else Switch ノードは、ブール条件に基づいて 2 つの候補入力のいずれかを選択します。`switch` が有効（true）の場合、`on_true` 入力をそのまま出力に渡します。無効（false）の場合、`on_false` を渡します。入力は遅延評価されるため、選択された分岐だけが評価され、もう一方の入力は接続する必要がありません。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `スイッチ` | 出力に渡す入力を決定するブール条件です。有効（true）の場合、`on_true` 入力が選択されます。無効（false）の場合、`on_false` 入力が選択されます。 | BOOLEAN | はい |  |
| `偽の場合` | `switch` が無効（false）のときに出力へ渡すデータです。この入力は `switch` が false の場合にのみ要求されます。 | MATCH_TYPE | いいえ |  |
| `真の場合` | `switch` が有効（true）のときに出力へ渡すデータです。この入力は `switch` が true の場合にのみ要求されます。 | MATCH_TYPE | いいえ |  |

**入力要件に関する注意:** `on_false` と `on_true` 入力は条件付きで要求されます。このノードは、`switch` が true の場合にのみ `on_true` を要求し、`switch` が false の場合にのみ `on_false` を要求します。両方の入力は同じデータ型である必要があり、その型は出力データ型と一致している必要があります。選択された入力が接続されていない場合、ノードは値を出力しません。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | 選択されたデータです。`switch` が true の場合は `on_true` の値、`switch` が false の場合は `on_false` の値になります。 | MATCH_TYPE |
