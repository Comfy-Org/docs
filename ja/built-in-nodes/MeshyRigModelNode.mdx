「Meshy: Rig Model ノード」は、以前の Meshy タスクで生成された3Dモデルを受け取り、自動的にスケルトンを作成します。これにより、ポーズやアニメーションを設定できるリグ付きキャラクターが生成されます。このノードは、リグ付きモデルを GLB 形式と FBX 形式の両方で出力します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `meshy_task_id` | リグを設定するモデルを生成した、以前の Meshy 操作（例：テキストから3D、画像から3D）の一意なタスク ID。 | STRING | はい | N/A |
| `height_meters` | キャラクターモデルのおおよその高さ（メートル単位）。スケーリングとリギングの精度を高めるために使用します（デフォルト：1.7）。 | FLOAT | はい | 0.1〜15.0 |
| `texture_image` | モデルのUV展開されたベースカラーテクスチャ画像。 | IMAGE | いいえ | N/A |

**注記：** 現在のオートリギング処理は、テクスチャのないメッシュ、人型以外のアセット、または手足や体の構造が不明瞭な人型アセットには適していません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_file` | 後方互換性のためのレガシー出力です。GLB モデルのファイル名を含みます。 | STRING |
| `rig_task_id` | このリギング操作の一意なタスク ID。結果を参照するために使用できます。 | STRING |
| `GLB` | GLB ファイル形式で保存された、リグ付き3Dキャラクターモデル。 | FILE3DGLB |
| `FBX` | FBX ファイル形式で保存された、リグ付き3Dキャラクターモデル。 | FILE3DFBX |
