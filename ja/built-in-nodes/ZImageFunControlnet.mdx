ZImageFunControlnet は、特殊なコントロールネットワークを適用して、画像生成または編集プロセスに影響を与えます。ベースモデル、モデルパッチ、VAE を使用し、コントロール効果の強さを調整できます。このノードは、ベース画像、インペイント画像、マスクと組み合わせることで、より対象を絞った編集が可能です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | 生成プロセスで使用されるベースモデルです。 | MODEL | 必須 | - |
| `モデルパッチ` | コントロールネットワークのガイダンスを適用する特殊なパッチモデルです。 | MODEL_PATCH | 必須 | - |
| `vae` | 画像のエンコードとデコードに使用される変分オートエンコーダーです。 | VAE | 必須 | - |
| `強度` | コントロールネットワークの影響の強さです。正の値を指定すると効果が適用され、負の値を指定すると反転できます（デフォルト: 1.0）。 | FLOAT | 必須 | -10.0〜10.0 |
| `画像` | 生成プロセスを導くためのオプションのベース画像です。 | IMAGE | 任意 | - |
| `インペイント画像` | マスクで定義された領域のインペイントに使用されるオプションの画像です。 | IMAGE | 任意 | - |
| `マスク` | 画像内のどの領域を編集またはインペイントするかを定義するオプションのマスクです。 | MASK | 任意 | - |

**注記:** `inpaint_image` パラメータは通常、インペイントする内容を指定するために `mask` と組み合わせて使用します。ノードの動作は、指定されたオプション入力によって変化することがあります（例: ガイダンスに `image` を使用する場合、インペイントに `image`、`mask`、`inpaint_image` を使用する場合など）。
