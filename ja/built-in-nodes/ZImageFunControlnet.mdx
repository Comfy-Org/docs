ZImageFunControlnet は、ベースモデルに制御ネットワークパッチを適用して、画像生成または編集プロセスをガイドできるようにします。モデル、モデルパッチ、VAE を組み合わせ、制御効果が結果に与える影響の強さを制御できます。オプションの `image`、`inpaint_image`、`mask` 入力により、より対象を絞った編集が可能になります。このノードは、Z-Image ControlNet パッチ、および Load Model Patch ノードを通じて読み込まれる Qwen Image 2.1 Fun ControlNet パッチで動作します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | 生成プロセスに使用されるベースモデル。 | MODEL | はい | - |
| `モデルパッチ` | 制御ネットワークのガイダンスを適用する専用パッチモデル。 | MODEL_PATCH | はい | - |
| `vae` | 画像のエンコードとデコードに使用される変分オートエンコーダ。 | VAE | はい | - |
| `強度` | 制御ネットワークの影響の強さ。正の値は効果を適用し、負の値は効果を反転できます（デフォルト: 1.0）。 | FLOAT | はい | -10.0 ～ 10.0（ステップ 0.01） |
| `画像` | 生成プロセスをガイドするためのオプションのベース画像。 | IMAGE | いいえ | - |
| `インペイント画像` | `mask` で定義された領域のインペイントに特化して使用されるオプションの画像。 | IMAGE | いいえ | - |
| `マスク` | 画像のどの領域を編集またはインペイントするかを定義するオプションのマスク。 | MASK | いいえ | - |
| `start_percent` | デノイズ処理のうち、制御ネットワークが効果を発揮し始める地点を、合計サンプリングステップに対する割合で指定します（デフォルト: 0.0）。 | FLOAT | いいえ | 0.0 ～ 1.0（ステップ 0.001） |
| `end_percent` | 制御ネットワークが効果を及ぼすのを止めるデノイズ処理内の地点（デフォルト: 1.0）。 | FLOAT | いいえ | 0.0 ～ 1.0（ステップ 0.001） |

**注記:** `inpaint_image` パラメータは通常、`mask` と組み合わせて使用され、インペイントする内容を指定します。ノードの動作は、どのオプション入力が提供されるかによって変化する場合があります（例：ガイダンスに `image` を使用する場合、またはインペイントに `image`、`mask`、`inpaint_image` を使用する場合）。`start_percent` と `end_percent` の値は、制御ネットワークをデノイズ処理のある区間に制限し、その区間外ではモデルはパッチなしでサンプリングされます。`strength` が 0 の場合、または `image`、`inpaint_image`、`mask` のいずれも接続されていない場合、ノードはベースモデルを変更せずに返します。Z-Image Control パッチでは、指定されたマスクは使用前に反転（1.0 - mask）されますが、Qwen Image 2.1 Fun ControlNet パッチはマスクをそのまま使用します。このノードは実験的としてフラグ付けされています。
