Tripo API を使用して、1枚の入力画像から被写体の正面、左、背面、右のビューを生成します。画像がアップロードされ、マルチビュー生成タスクが開始されて完了するまでポーリングされ、得られた4つのビューがタスク ID とともに返されます。これは約 0.10 USD で課金される有料タスクです。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | Tripo が正面、左、背面、右のビューを生成する元となる被写体のソース画像です。バッチが指定された場合でも、リクエストには1枚の画像のみが使用されます。 | IMAGE | はい | 単一画像 |

注記：このノードは Tripo のクラウド API を呼び出し、生成タスクが完了するまで待機します。一般的なタスクは約25秒かかります。認証はノードの隠し入力を通じて自動的に処理されるため、ワークフローで Tripo API キーを指定する必要はありません。このノードは Tripo のレスポンスに含まれる4つのビュー URL（`front_view_url`、`left_view_url`、`back_view_url`、`right_view_url`）をすべて必要とし、いずれかのビューが欠けている場合はエラーとなり実行が失敗します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `multiview task_id` | マルチビュー画像生成リクエストに対して Tripo から返されるタスク識別子です。完了したタスクを参照するために使用でき、たとえば Tripo: Edit Multiview でビューを調整する際に利用できます。 | MULTIVIEW_TASK_ID |
| `front` | 生成された被写体の正面ビューです。 | IMAGE |
| `left` | 生成された被写体の左側ビューです。 | IMAGE |
| `back` | 生成された被写体の背面ビューです。 | IMAGE |
| `right` | 生成された被写体の右側ビューです。 | IMAGE |
