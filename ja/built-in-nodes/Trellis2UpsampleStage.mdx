このノードは、最初のシェイプステージのサンプリングパスで生成された512解像度のシェイプ潜在変数を受け取り、それをより高いターゲット解像度にアップスケールし、2回目のシェイプステージのサンプリングパスに必要なコンディショニングと潜在変数を準備します。また、ステージごとのメタデータをコンディショニングに付加して、生成中にモデルがそれを利用できるようにします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `positive` | アップサンプリングステージのシェイプメタデータが付加されるポジティブコンディショニングです。 | CONDITIONING | はい | |
| `negative` | アップサンプリングステージのシェイプメタデータが付加されるネガティブコンディショニングです。 | CONDITIONING | はい | |
| `shape_latent` | 最初のシェイプステージのKSamplerから出力された512解像度のシェイプ潜在変数です。 | LATENT | はい | |
| `vae` | シェイプ潜在変数を高解像度のスパース座標にデコードするために使用されるTrellis2 VAEです。 | VAE | はい | |
| `target_resolution` | アップスケールされたシェイプのボクセル解像度です。数値が高いほど詳細になり、VRAMを多く消費します。デフォルトは1024です。 | INT | はい | 1024 - 2048 (step 128) |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `positive` | アップサンプリングステージのシェイプメタデータが付加されたポジティブコンディショニングです。 | CONDITIONING |
| `negative` | アップサンプリングステージのシェイプメタデータが付加されたネガティブコンディショニングです。 | CONDITIONING |
| `latent` | ターゲット解像度での2回目のシェイプステージのサンプリングパスに備えて準備されたゼロ埋め潜在変数です。アップスケールされた座標と解像度メタデータを保持します。 | LATENT |
