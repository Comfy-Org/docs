このノードは、512 解像度の形状潜在変数を高解像度スパース座標へアップスケールし、ターゲット解像度で第2形状ステージサンプリングパスを準備します。モデルが生成時に利用できるよう、コンディショニングにステージごとのメタデータを付加します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `positive` | アップサンプリング段階の形状メタデータが付加されるポジティブコンディショニング。 | CONDITIONING | はい | |
| `negative` | アップサンプリング段階の形状メタデータが付加されるネガティブコンディショニング。 | CONDITIONING | はい | |
| `shape_latent` | 最初の形状ステージ KSampler から出力される 512 解像度の形状潜在変数。 | LATENT | はい | |
| `vae` | 形状潜在変数を高解像度スパース座標へデコードするために使用される Trellis2 VAE。 | VAE | はい | |
| `target_resolution` | アップサンプリング後の形状のボクセル解像度。高いほど詳細が増えますが、VRAM 消費も増えます。デフォルト: 1024。 | INT | はい | 1024 - 2048 （ステップ 128） |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `positive` | アップサンプリング段階の形状メタデータが付加されたポジティブコンディショニング。 | CONDITIONING |
| `negative` | アップサンプリング段階の形状メタデータが付加されたネガティブコンディショニング。 | CONDITIONING |
| `latent` | ターゲット解像度での第2形状ステージサンプリングパス用に準備されたゼロ埋め潜在変数。アップサンプリングされた座標、サンプルごとの座標数、および座標解像度メタデータを保持します。 | LATENT |
