SV3D_Conditioning は、SV3Dモデルを使用して3D動画生成用のコンディショニングデータを準備します。初期画像を受け取り、CLIP visionエンコーダーとVAEエンコーダーで処理して、ポジティブコンディショニングとネガティブコンディショニング、および潜在表現を作成します。このノードは、指定された動画フレーム数に基づいて、マルチフレーム動画生成用のカメラの仰角（elevation）と方位角（azimuth）のシーケンスを生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `クリップビジョン` | 入力画像のエンコードに使用されるCLIP visionモデル | CLIP_VISION | はい | - |
| `初期画像` | 3D動画生成の開始点となる初期画像 | IMAGE | はい | - |
| `vae` | 画像を潜在空間にエンコードするために使用されるVAEモデル | VAE | はい | - |
| `幅` | 生成される動画フレームの出力幅（デフォルト: 576、8で割り切れる必要があります） | INT | はい | 16 to MAX_RESOLUTION |
| `高さ` | 生成される動画フレームの出力高さ（デフォルト: 576、8で割り切れる必要があります） | INT | はい | 16 to MAX_RESOLUTION |
| `ビデオフレーム` | 動画シーケンス用に生成するフレーム数（デフォルト: 21） | INT | はい | 1〜4096 |
| `高度` | 3Dビューにおけるカメラの仰角（度）（デフォルト: 0.0） | FLOAT | はい | -90.0〜90.0 |

注：カメラの方位角は0度から始まり、各フレームで一定量ずつ増加し、生成されたフレーム全体でカメラがオブジェクトの周りを360度一周するようにします。`elevation` の値はすべてのフレームで一定です。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `ポジティブ` | 生成用の画像埋め込みとカメラパラメータを含むポジティブコンディショニングデータ | CONDITIONING |
| `ネガティブ` | 対照的な生成のためのゼロ化された埋め込みと潜在変数を含むネガティブコンディショニングデータ | CONDITIONING |
| `潜在` | 指定された動画フレーム数と解像度に一致する次元を持つ空の潜在テンソル | LATENT |
