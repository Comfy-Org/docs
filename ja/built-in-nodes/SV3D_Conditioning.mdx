SV3D_Conditioning は、SV3D モデルを使用した 3D 動画生成用のコンディショニングデータを準備します。初期画像を受け取り、CLIP vision エンコーダーと VAE エンコーダーを通して処理することで、ポジティブおよびネガティブコンディショニングと潜在表現を生成します。このノードは、指定された動画フレーム数に基づいて、マルチフレーム動画生成用のカメラ仰角および方位角のシーケンスを生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `クリップビジョン` | 入力画像のエンコードに使用される CLIP vision モデル | CLIP_VISION | はい | - |
| `初期画像` | 3D 動画生成の開始点となる初期画像 | IMAGE | はい | - |
| `vae` | 画像を潜在空間にエンコードするために使用される VAE モデル | VAE | はい | - |
| `幅` | 生成される動画フレームの出力幅（デフォルト: 576、8 刻み） | INT | はい | 16 to MAX_RESOLUTION |
| `高さ` | 生成される動画フレームの出力高さ（デフォルト: 576、8 刻み） | INT | はい | 16 to MAX_RESOLUTION |
| `ビデオフレーム` | 動画シーケンスで生成するフレーム数（デフォルト: 21） | INT | はい | 1 〜 4096 |
| `高度` | 3D ビューのカメラ仰角（度単位）（デフォルト: 0.0、0.1 刻み） | FLOAT | はい | -90.0 〜 90.0 |

注: カメラの方位角は 0 度から始まり、フレームごとに一定量ずつ増加し、生成されたフレーム全体でカメラがオブジェクトの周囲を完全に 360 度周回するようにします。フレームごとの増分は 360 を (`video_frames` - 1) で割った値として計算され、フレームが 1 つだけ要求された場合は最小除数 2 を使用します。`elevation` の値はすべてのフレームで一定に保たれます。

`init_image` は VAE エンコード前に指定された `width` と `height` にスケーリングされ、返される latent の次元は `video_frames` x 4 x (`height` // 8) x (`width` // 8) です。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | 生成用の画像埋め込みとカメラパラメータを含むポジティブコンディショニングデータ | CONDITIONING |
| `negative` | 対照的生成用のゼロ化された埋め込みと latent を持つネガティブコンディショニングデータ | CONDITIONING |
| `latent` | 指定された動画フレームと解像度に一致する次元を持つ空の latent テンソル | LATENT |
