LTXVImgToInplace は、入力画像を潜在空間にエンコードし、そのエンコードされたフレームを既存の潜在ビデオの先頭に配置します。`strength` の値は、エンコードされた画像がこれらの初期フレームにどの程度強く条件付けするかを制御します。`bypass` が有効な場合、入力潜在変数は変更されずに返されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `vae` | 入力画像を潜在空間にエンコードするために使用される VAE モデル。 | VAE | はい | - |
| `画像` | エンコードされ、ビデオ潜在変数の条件付けに使用される入力画像。 | IMAGE | はい | - |
| `latent` | 変更対象のターゲットとなる潜在ビデオ表現。 | LATENT | はい | - |
| `強度` | エンコードされた画像が潜在変数の初期フレームに条件付けする強度を制御します。値が 1.0 の場合、初期フレームはエンコードされた画像で完全に条件付けされます。値が低いほど、条件付けは弱くなります。初期フレームのノイズマスクは `1.0 - strength` に設定されます。（デフォルト: 1.0） | FLOAT | いいえ | 0.0 - 1.0 |
| `バイパス` | 条件付けをバイパスします。有効にすると、ノードは入力潜在変数を変更せずに返します。（デフォルト: False） | BOOLEAN | いいえ | True または False |

**注意：** `image` は、`latent` 入力の幅と高さに基づいて、`vae` がエンコードに必要とする空間次元に合わせて自動的にリサイズされます。エンコードには `image` の RGB チャンネルのみが使用されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `latent` | 結果の潜在ビデオ表現。バイパスが無効の場合、更新された `samples` と、初期フレームに条件付けの強度を適用する `noise_mask` が含まれます。バイパスが有効な場合は、入力潜在変数が変更されずに返されます。 | LATENT |
