このノードは、ByteDance Seedance モデルを使用して、必須の最初のフレーム画像とオプションの最後のフレーム画像から動画を生成します。テキストプロンプトで動画を記述すると、最初のフレームが動画の開始を、最後のフレームが終了を導きます。Seedance 2.5 と Seedance 2.0 ファミリー（Seedance 2.0、Seedance 2.0 Fast、Seedance 2.0 Mini）をサポートしています。

**パラメータの制約**

- 最初のフレームは、`first_frame` 画像または `first_frame_asset_id` のいずれかで指定する必要があります。両方を指定するとエラーが発生し、どちらも指定しない場合もエラーになります。
- `last_frame` と `last_frame_asset_id` の入力はオプションですが、同じフレームに対して両方を指定することはできません。
- アセット ID は、既存のアクティブな Seedance Image アセットを参照している必要があります。
- `prompt` 入力は必須であり、空にすることはできません。
- `Seedance 2.5` では、出力アスペクト比は常に adaptive となり、最初のフレーム自体のアスペクト比に従うため、`ratio` 入力は表示されません。
- Seedance 2.0 ファミリーのモデルとローカルフレーム画像を使用する場合、画像は生成前に中央トリミングされ、ターゲットの出力解像度と比率にリサイズされます。`ratio` が `adaptive` の場合、入力画像に最も近い対応比率が使用されます。
- ローカルフレーム画像は、対応するアスペクト比とサイズについて検証されます。大きすぎる画像はダウンスケールされます。
