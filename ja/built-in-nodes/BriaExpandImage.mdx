Bria Expand Image は、Bria を使用して新しいコンテンツを生成し、画像を元の境界を超えて拡張します。ターゲットのアスペクト比、カスタム比率、または元の画像を手動で配置するキャンバスを選択できます。拡張はテキストプロンプトでガイドでき、プロンプトを空のままにすると、Bria が自動的にプロンプトを生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 拡張する入力画像。 | IMAGE | 必須 | — |
| `expand_mode` | 拡張画像のターゲット形状: プリセットのアスペクト比、カスタム比率、またはキャンバス上への元画像の手動配置。手動モードは、1:2 より縦長のキャンバスに到達できる唯一のモードです。`custom_ratio` を選択すると `ratio_width` と `ratio_height` が表示されます。`manual` を選択すると、キャンバスと画像配置パラメータが表示されます。 | COMBO | 必須 | `"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"`<br />`"custom_ratio"`<br />`"manual"` |
| `ratio_width` | ターゲット比率の幅側: 21 と 9 で 21:9 になります。デフォルト: 21。 | INT | 条件付き | 1–100 |
| `ratio_height` | ターゲット比率の高さ側: 21 と 9 で 21:9 になります。Bria は幅/高さの比率が 0.5～3.0 の間のみ受け付けるため、1:2 より縦長の場合は手動モードを使用する必要があります。デフォルト: 9。 | INT | 条件付き | 1–100 |
| `canvas_width` | 出力キャンバスの幅（ピクセル）。デフォルト: 1000。 | INT | 条件付き | 64–5000 |
| `canvas_height` | 出力キャンバスの高さ（ピクセル）。デフォルト: 1000。 | INT | 条件付き | 64–5000 |
| `image_width` | キャンバス内の元画像の幅。デフォルト: 500。 | INT | 条件付き | 1–5000 |
| `image_height` | キャンバス内の元画像の高さ。デフォルト: 500。 | INT | 条件付き | 1–5000 |
| `image_x` | キャンバス内での画像の左上隅の X 位置。キャンバスの外側に配置すると、画像が切り取られます。デフォルト: 250。 | INT | 条件付き | -5000–5000 |
| `image_y` | キャンバス内での画像の左上隅の Y 位置。キャンバスの外側に配置すると、画像が切り取られます。デフォルト: 250。 | INT | 条件付き | -5000–5000 |
| `prompt` | 拡張するシーンのオプションの説明。空の場合、Bria が画像から自動生成します。デフォルト: 空文字列。 | STRING | 任意 | 任意の文字列 |
| `negative_prompt` | 拡張に使用するオプションのネガティブプロンプト。デフォルト: 空文字列。 | STRING | 任意 | 任意の文字列 |
| `seed` | ランダム生成プロセスのシード。デフォルト: 42。 | INT | 任意 | 1–2147483647 |
| `moderation` | モデレーション設定。`true` に設定すると、追加のモデレーションオプションが表示されます。 | COMBO | 任意 | `"false"`<br />`"true"` |
| `prompt_content_moderation` | 有効にすると、プロンプトの内容をモデレーションします。デフォルト: false。`moderation` が `true` の場合のみ使用可能です。 | BOOLEAN | 条件付き | true/false |
| `visual_input_moderation` | 有効にすると、視覚的な入力をモデレーションします。デフォルト: false。`moderation` が `true` の場合のみ使用可能です。 | BOOLEAN | 条件付き | true/false |
| `visual_output_moderation` | 有効にすると、視覚的な出力をモデレーションします。デフォルト: false。`moderation` が `true` の場合のみ使用可能です。 | BOOLEAN | 条件付き | true/false |

`expand_mode` が `custom_ratio` の場合、`ratio_width` と `ratio_height` がターゲットのアスペクト比を定義します。Bria は幅と高さの比率が 0.5～3.0 の間のみ受け付けます。この範囲外の場合はエラーが発生し、代わりに `manual` モードを使用する必要があります。

`expand_mode` が `manual` の場合、元の画像は指定されたサイズと位置でキャンバス上に配置されます。画像がキャンバスの外側に広がる場合は、その外側の部分が切り取られます。

`moderation` が `true` の場合、3 つのモデレーションブール値が Bria に送信されます。`moderation` が `false` の場合、これらは無視されます。
