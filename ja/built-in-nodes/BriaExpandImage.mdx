Bria Expand Image は、Bria を使用して新しいコンテンツを生成することで、画像を元の境界を超えて拡張します。ターゲットのアスペクト比、カスタム比率、または元の画像を手動で配置するキャンバスを定義できます。拡張はテキストプロンプトでガイドでき、プロンプトを空のままにすると、Bria が自動的にプロンプトを生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 拡張する入力画像です。 | IMAGE | はい | — |
| `expand_mode` | 拡張画像のターゲット形状です。プリセットのアスペクト比、カスタム比率、またはキャンバス上への元画像の手動配置から選択できます。Manual は、1:2 より縦長のキャンバスに到達できる唯一のモードです。`custom_ratio` を選択すると `ratio_width` と `ratio_height` が表示されます。`manual` を選択すると、キャンバスと画像配置のパラメータが表示されます。 | DYNAMIC_COMBO | はい | `"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"`<br />`"custom_ratio"`<br />`"manual"` |
| `ratio_width` | ターゲット比率の幅側です。21 と 9 で 21:9 になります。デフォルト: 21。 | INT | 条件付き | 1–100 |
| `ratio_height` | ターゲット比率の高さ側です。21 と 9 で 21:9 になります。Bria は 0.5 から 3.0 の間の幅/高さのみを受け付けるため、1:2 より縦長の場合は manual モードが必要です。デフォルト: 9。 | INT | 条件付き | 1–100 |
| `canvas_width` | 出力キャンバスの幅（ピクセル単位）です。デフォルト: 1000。 | INT | 条件付き | 64–5000 |
| `canvas_height` | 出力キャンバスの高さ（ピクセル単位）です。デフォルト: 1000。 | INT | 条件付き | 64–5000 |
| `image_width` | キャンバス内の元画像の幅です。デフォルト: 500。 | INT | 条件付き | 1–5000 |
| `image_height` | キャンバス内の元画像の高さです。デフォルト: 500。 | INT | 条件付き | 1–5000 |
| `image_x` | キャンバス内における画像の左上隅の X 位置です。キャンバスの外側に配置すると、画像が切り取られます。デフォルト: 250。 | INT | 条件付き | -5000–5000 |
| `image_y` | キャンバス内における画像の左上隅の Y 位置です。キャンバスの外側に配置すると、画像が切り取られます。デフォルト: 250。 | INT | 条件付き | -5000–5000 |
| `prompt` | 拡張シーンのオプションの説明です。空の場合、Bria が画像から説明を生成します。デフォルト: 空文字列。 | STRING | いいえ | 任意の文字列 |
| `negative_prompt` | 拡張用のオプションのネガティブプロンプトです。デフォルト: 空文字列。 | STRING | いいえ | 任意の文字列 |
| `seed` | ランダム生成プロセスのシードです。デフォルト: 42。 | INT | いいえ | 1–2147483647 |
| `moderation` | モデレーション設定です。`true` に設定すると、追加のモデレーションオプションが表示されます。 | DYNAMIC_COMBO | いいえ | `"false"`<br />`"true"` |
| `prompt_content_moderation` | 有効にすると、プロンプトの内容をモデレーションします。デフォルト: false。`moderation` が `true` の場合のみ利用可能です。 | BOOLEAN | 条件付き | true/false |
| `visual_input_moderation` | 有効にすると、視覚入力をモデレーションします。デフォルト: false。`moderation` が `true` の場合のみ利用可能です。 | BOOLEAN | 条件付き | true/false |
| `visual_output_moderation` | 有効にすると、視覚出力をモデレーションします。デフォルト: false。`moderation` が `true` の場合のみ利用可能です。 | BOOLEAN | 条件付き | true/false |

`expand_mode` が `custom_ratio` の場合、`ratio_width` と `ratio_height` がターゲットのアスペクト比を定義します。Bria は 0.5 から 3.0 の間の幅と高さの比率のみを受け付けます。比率がこの範囲外の場合、エラーが発生し、代わりに `manual` モードを使用する必要があります。

`expand_mode` が `manual` の場合、元の画像は指定されたサイズと位置でキャンバス上に配置されます。画像がキャンバスの外側にはみ出すことがあり、その場合は外側の部分が切り取られます。

`moderation` が `true` の場合、3 つのモデレーションブール値が Bria に送信されます。`moderation` が `false` の場合、これらは無視されます。

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | Bria によって生成された拡張画像です。 | IMAGE |
| `prompt` | 拡張に使用されたプロンプトです。プロンプト入力が空の場合、Bria によって自動生成されます。 | STRING |
