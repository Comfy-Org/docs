Bria Expand Image は、Bria で新しいコンテンツを生成することにより、画像を元の境界を超えて拡張します。ターゲットのアスペクト比、カスタム比率を選択したり、元の画像を手動で配置してキャンバスを定義したりできます。拡張はテキストプロンプトで誘導でき、プロンプトを空のままにすると Bria が自動的に生成します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 拡張する入力画像。 | IMAGE | はい | — |
| `expand_mode` | 拡張後の画像のターゲット形状: プリセットのアスペクト比、カスタム比率、またはキャンバス上への元画像の手動配置。手動は、1:2 より縦長のキャンバスに到達できる唯一のモードです。`custom_ratio` を選択すると `ratio_width` と `ratio_height` が表示されます。`manual` を選択するとキャンバスと画像配置パラメータが表示されます。 | DYNAMIC_COMBO | はい | `"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"`<br />`"custom_ratio"`<br />`"manual"` |
| `prompt` | 拡張シーンの任意の説明。空の場合、Bria が画像から生成します。デフォルト: 空文字列。 | STRING | はい | 任意の文字列 |
| `negative_prompt` | 拡張用の任意のネガティブプロンプト。デフォルト: 空文字列。 | STRING | はい | 任意の文字列 |
| `seed` | ランダム生成プロセスのシード。デフォルト: 42。 | INT | はい | 1–2147483647 |
| `moderation` | モデレーション設定。`true` に設定すると、追加のモデレーションオプションが表示されます。 | DYNAMIC_COMBO | はい | `"false"`<br />`"true"` |

### カスタム比率入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `ratio_width` | ターゲット比率の幅側: 21 と 9 で 21:9 になります。デフォルト: 21。 | INT | はい | 1–100 |
| `ratio_height` | ターゲット比率の高さ側: 21 と 9 で 21:9 になります。Bria は幅/高さが 0.5 から 3.0 の間のみ受け付けるため、1:2 より縦長のものは手動モードが必要です。デフォルト: 9。 | INT | はい | 1–100 |

### 手動入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `canvas_width` | 出力キャンバスの幅（ピクセル単位）。デフォルト: 1000。 | INT | はい | 64–5000 |
| `canvas_height` | 出力キャンバスの高さ（ピクセル単位）。デフォルト: 1000。 | INT | はい | 64–5000 |
| `image_width` | キャンバス内の元画像の幅。デフォルト: 500。 | INT | はい | 1–5000 |
| `image_height` | キャンバス内の元画像の高さ。デフォルト: 500。 | INT | はい | 1–5000 |
| `image_x` | キャンバス内の画像の左上隅の X 位置。キャンバス外になる場合があり、その場合は画像がクロップされます。デフォルト: 250。 | INT | はい | -5000–5000 |
| `image_y` | キャンバス内の画像の左上隅の Y 位置。キャンバス外になる場合があり、その場合は画像がクロップされます。デフォルト: 250。 | INT | はい | -5000–5000 |

### モデレーション入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | 有効にすると、プロンプトコンテンツをモデレートします。デフォルト: false。`moderation` が `true` の場合にのみ使用できます。 | BOOLEAN | はい | true/false |
| `visual_input_moderation` | 有効にすると、視覚入力をモデレートします。デフォルト: false。`moderation` が `true` の場合にのみ使用できます。 | BOOLEAN | はい | true/false |
| `visual_output_moderation` | 有効にすると、視覚出力をモデレートします。デフォルト: false。`moderation` が `true` の場合にのみ使用できます。 | BOOLEAN | はい | true/false |

プリセットのアスペクト比オプション（`1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`4:5`、`5:4`、`9:16`、`16:9`）には追加の入力はありません。

`expand_mode` が `custom_ratio` の場合、`ratio_width` と `ratio_height` がターゲットのアスペクト比を定義します。Bria は幅と高さの比率が 0.5 から 3.0 の間のみ受け付けます。比率がこの範囲外の場合、エラーが発生するため、代わりに `manual` モードを使用してください。

`expand_mode` が `manual` の場合、元の画像は指定されたサイズと位置でキャンバス上に配置されます。画像はキャンバス外にはみ出す場合があり、その場合、外側の部分はクロップされます。

`moderation` が `true` の場合、3 つのモデレーション用ブール値が Bria に送信されます。`false` の場合、無視されます。
