ByteDance Image Edit ノードは、API を通じて ByteDance の AI モデルを使用して画像を変更できます。入力画像と、希望する変更を記述したテキストプロンプトを提供すると、ノードは指示に従って画像を処理します。ノードは API 通信を自動的に処理し、編集済み画像を返します。

## 入力

| パラメータ | 説明 | データ型 | 入力タイプ | デフォルト | 範囲 |
| --- | --- | --- | --- | --- | --- |
| `model` | モデル名 | MODEL | COMBO | seededit_3 | Image2ImageModelName options |
| `image` | 編集対象のベース画像 | IMAGE | IMAGE | - | - |
| `prompt` | 画像を編集するための指示 | STRING | STRING | "" | - |
| `seed` | 生成に使用するシード | INT | INT | 0 | 0-2147483647 |
| `guidance_scale` | 値を大きくすると、画像がプロンプトにより忠実に従います | FLOAT | FLOAT | 5.5 | 1.0-10.0 |
| `watermark` | 画像に「AI generated」ウォーターマークを追加するかどうか | BOOLEAN | BOOLEAN | True | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `IMAGE` | ByteDance API から返された編集済み画像 | IMAGE |
