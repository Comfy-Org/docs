このノードは、画像または画像のバッチの上にテキストを描画します。設定可能なフォントサイズ、色、垂直位置、水平方向の配置、およびオプションの黒い縁取りを使用してテキストオーバーレイを作成し、そのオーバーレイを元の画像ピクセルと合成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | テキストを描画する対象の入力画像または画像のバッチ | IMAGE | はい | |
| `テキスト` | 画像に重ねるテキスト（デフォルト: ""）。複数行に対応しています。`\n` および `\t` のエスケープシーケンスは改行とタブに変換され、長い行は画像の幅に収まるように自動的に折り返されます。 | STRING | はい | |
| `フォントサイズ` | 画像の高さに対するパーセンテージで指定するフォントサイズ（デフォルト: 5.0） | FLOAT | はい | 0.5 ～ 50.0（ステップ 0.5） |
| `色` | テキストの色（デフォルト: "#ffffff"） | COLOR | はい | |
| `位置` | 画像上でのテキストの垂直位置（デフォルト: "top"） | COMBO | はい | "top"<br />"bottom" |
| `整列` | テキストの水平方向の配置（デフォルト: "left"） | COMBO | はい | "left"<br />"center"<br />"right" |
| `アウトライン` | テキストの周囲に黒い縁取りを描画します（デフォルト: True） | BOOLEAN | はい | |

注: `text` が空または空白文字のみの場合、このノードは入力画像をそのまま返します。テキストオーバーレイは一度だけレンダリングされ、バッチ内のすべての画像に適用されます。レンダリングされたテキストブロックが利用可能な画像領域より高い場合、収まるか最小サイズに達するまでフォントサイズが自動的に縮小されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `images` | テキストオーバーレイが上に合成された入力画像 | IMAGE |
