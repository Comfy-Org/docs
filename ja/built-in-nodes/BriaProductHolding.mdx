このノードは、Briaを使用して商品を人物の手に持たせます。人物の本人性、ポーズ、背景は維持されたまま、シーンは約100万画素で再レンダリングされるため、結果は入力写真とピクセル単位では位置合わせされません。すべての商品画像は、同じ商品を異なる角度または段階から示したものです。

## 入力

`moderation` セレクターを `"true"` に設定すると、追加のモデレーションオプションが表示されます。

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `person_image` | 商品を持つ人物の写真です。画像がアップロードされる前にアルファチャンネルは削除されます。 | IMAGE | はい | - |
| `product_images` | 1つの商品につき1～3枚の画像：商品自体、そのパッケージ、別の角度、または付属品です。バッチ入力の場合は画像ごとに1回として数えられ、透明領域は白として扱われます。 | AUTOGROW | はい | 1～3枚 |
| `instruction` | Briaの組み込み指示に追加される任意の追加指示です。どちらの手を使うか、ラベルをどちらに向けるかなどを指定できます。デフォルト: `""`（空文字列）。 | STRING | はい | - |
| `aspect_ratio` | `"auto"` は人物写真の構図を約100万画素で維持します。固定比率では0.6～1メガピクセルを返します。たとえば `"3:4"` では768x1024です。デフォルト: `"auto"`。 | COMBO | はい | `"auto"`<br />`"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"` |
| `seed` | リクエストとともにBriaへ送信されるシードです。デフォルト: 42。 | INT | はい | 1～2147483647 |
| `moderation` | モデレーション設定です。`"true"` に設定すると、下記のモデレーションフラグが使用可能になります。 | DYNAMIC_COMBO | はい | `"false"`<br />`"true"` |

### Moderation "true" 入力

このパラメータは、`moderation` が `"true"` に設定されている場合にのみ表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `visual_output_moderation` | 生成画像に対するコンテンツモデレーションを有効にします。デフォルト: `False`。 | BOOLEAN | いいえ | True / False |

**制約:**

* `product_images` は最大3枚の画像を受け付け、入力がバッチの場合は画像ごとに数えます。
* 商品画像内の透明ピクセルは、アップロード前に白に合成されます。
* `person_image` のアルファチャンネルは、アップロード前に削除されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 商品が人物の手に配置された編集済み写真です。 | IMAGE |
