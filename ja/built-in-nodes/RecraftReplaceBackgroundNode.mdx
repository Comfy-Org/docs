提供されたプロンプトに基づいて画像の背景を置き換えます。このノードは Recraft API を使用して、テキスト記述に従って画像の新しい背景を生成し、主要な被写体をそのまま維持しながら背景を完全に変換できます。入力バッチ内の各画像は個別に処理され、結果は単一の出力バッチに結合されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | 処理する入力画像 | IMAGE | はい | - |
| `プロンプト` | 画像生成用のプロンプト（デフォルト: 空） | STRING | はい | - |
| `生成数` | 生成する画像の数（デフォルト: 1） | INT | はい | 1-6 |
| `シード` | ノードを再実行するかどうかを決定するシード。実際の結果はシードに関係なく非決定的です（デフォルト: 0） | INT | はい | 0-18446744073709551615 |
| `Recraftスタイル` | 生成される背景のオプションのスタイル選択。指定しない場合、デフォルトで "realistic_image" スタイルになります | STYLEV3 | いいえ | - |
| `ネガティブプロンプト` | 画像上で望ましくない要素を指定するオプションのテキスト記述（デフォルト: 空） | STRING | いいえ | - |

**注意:**
- `seed` パラメータはノードが再実行されるタイミングを制御しますが、外部 API の性質上、決定的な結果を保証するものではありません。
- `recraft_style` が接続されていないか空の場合、ノードは `realistic_image` スタイルにフォールバックします。
- `negative_prompt` が空の場合、リクエストに含まれません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | 背景が置き換えられた生成画像。各入力画像について、生成される結果の数は `n` によって決まります。 | IMAGE |
