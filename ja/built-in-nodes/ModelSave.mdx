ModelSave ノードは、MODEL を `.safetensors` チェックポイントファイルとしてコンピューターのストレージに保存します。指定したファイル名プレフィックスを使用して、ComfyUI の出力ディレクトリにファイルを書き込み、利用可能な場合はワークフローのプロンプト情報とモデルのメタデータを保存ファイルに埋め込みます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | ディスクに保存するモデル | MODEL | はい | - |
| `ファイル名プレフィックス` | 保存するモデルファイルのファイル名とパスのプレフィックス（デフォルト: "diffusion_models/ComfyUI"） | STRING | はい | - |
| `prompt` | ワークフローのプロンプト情報（自動的に提供されます） | PROMPT | いいえ | - |
| `extra_pnginfo` | 追加のワークフローメタデータ（自動的に提供されます） | EXTRA_PNGINFO | いいえ | - |

注: 保存されるファイル名は、`filename_prefix` の値に続けて5桁のカウンターを付けたものになります（例: `diffusion_models/ComfyUI_00001_.safetensors`）。同じプレフィックスのファイルがすでに存在する場合、新しいファイルが一意の名前になるようにカウンターが増加します。利用可能な場合、ワークフローのプロンプト、追加メタデータ、およびモデルアーキテクチャ情報（例: Stable Diffusion XL、SDXL Refiner、Stable Video Diffusion、Stable Diffusion 3）が保存ファイルに埋め込まれます。ComfyUI のコマンドライン設定でメタデータの保存が無効になっている場合、プロンプトと追加メタデータはファイルに書き込まれません。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| *None* | このノードは出力値を返しません | - |
