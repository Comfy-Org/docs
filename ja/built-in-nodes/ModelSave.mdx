ModelSave ノードは、モデルをコンピュータのストレージに `.safetensors` チェックポイントファイルとして保存します。モデルを入力として受け取り、指定したファイル名プレフィックスを使用して出力ディレクトリに書き込みます。利用可能な場合は、ワークフローのプロンプト情報と追加のメタデータも保存されたファイルに埋め込みます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | ディスクに保存されるモデル | MODEL | はい | - |
| `ファイル名プレフィックス` | 保存されるモデルファイルのファイル名とパスのプレフィックス（デフォルト："diffusion_models/ComfyUI"） | STRING | はい | - |
| `prompt` | ワークフローのプロンプト情報（自動的に提供されます） | PROMPT | いいえ | - |
| `extra_pnginfo` | 追加のワークフローメタデータ（自動的に提供されます） | EXTRA_PNGINFO | いいえ | - |

注：保存されるファイル名は、`filename_prefix` の値に5桁のカウンターを続けて構成されます（例：`diffusion_models/ComfyUI_00001_.safetensors`）。同じプレフィックスのファイルが既に存在する場合は、カウンターが増加され、新しいファイルが一意の名前になるようにします。利用可能な場合は、ワークフローのプロンプト、追加のメタデータ、モデルアーキテクチャ情報が保存されたファイルに埋め込まれます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| *None* | このノードは出力値を返しません | - |
