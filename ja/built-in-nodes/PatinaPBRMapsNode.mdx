既存のテクスチャ画像から、ベースカラー、ノーマル、ラフネス、メタルネス、ハイトの PBR マテリアルマップ一式を導出します。有効にしたマップごとに処理コストが増えるため、必要なマップだけを有効にしてください。まだマテリアルマップがないテクスチャを完成させる場合や、壊れたマップを 1 つ再構築する場合に使用します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | PBR マップの導出元となる写真またはレンダリング画像です。 | IMAGE | はい | - |
| `basecolor` | ベースカラー（アルベド）マップを生成します。デフォルト: True。 | BOOLEAN | はい | true<br />false |
| `normal` | ノーマルマップを生成します。デフォルト: True。 | BOOLEAN | はい | true<br />false |
| `roughness` | ラフネスマップを生成します。デフォルト: False。 | BOOLEAN | はい | true<br />false |
| `metalness` | メタルネスマップを生成します。デフォルト: False。 | BOOLEAN | はい | true<br />false |
| `height` | ハイト（ディスプレイスメント）マップを生成します。デフォルト: False。 | BOOLEAN | はい | true<br />false |
| `seed` | 再現可能なノイズ除去のためのシードです。デフォルト: 42。 | INT | はい | 0 〜 2147483646 |
| `safety_checker` | リクエストに対してプロバイダーのコンテンツ安全性チェックを実行します。詳細設定です。デフォルト: False。 | BOOLEAN | はい | true<br />false |
| `auto_downscale` | 入力画像の長辺がモデルの入力上限である 2048 ピクセルを超える場合、アスペクト比を維持したまま自動的にダウンスケールします。小さい画像はそのままにします。無効にすると、代わりに大きすぎる画像でエラーを発生させます。詳細設定です。デフォルト: True。 | BOOLEAN | いいえ | true<br />false |

**制約と動作:**

* 少なくとも 1 つのマップを有効にする必要があります。そうでない場合、実行は失敗します。
* 入力画像は長辺が 2048 ピクセルに制限されています。`auto_downscale` で縮小するか、さもなければサイズ超過画像では実行が失敗します。
* 無効にした各マップも出力を返しますが、1x1 のプレースホルダー画像になります。そのため、実際に生成した出力だけを接続してください。
