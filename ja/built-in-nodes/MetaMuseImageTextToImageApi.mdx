Meta Muse Image Text to Image は、Meta の Muse Image モデルを使用してテキストプロンプトから画像を生成します。このモデルはレンダリング前にプロンプトについて推論し、画像を計画する間にウェブ検索、画像検索、コード実行を利用できます。このノードは Muse Image API を呼び出し、結果の画像または複数の画像を返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 使用するモデル。 | DYNAMIC_COMBO | はい | `"muse-image-1.0"` |

リストでモデルを選択すると、そのモデルがサポートする設定が表示されます。使用できるモデルは `muse-image-1.0` のみです。その設定を以下に示します。

### muse-image-1.0 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 画像を記述するプロンプト。モデルはレンダリング前にプロンプトについて推論し、組み込みのウェブ検索および画像検索を使用する場合があります。 | STRING | はい | 複数行テキスト、最小1文字 |
| `aspect_ratio` | 出力のアスペクト比。画像は約2.5メガピクセルでレンダリングされます（1:1 は 1600x1600、16:9 は 2048x1152）。`"auto"` はモデルにプロンプトから選択させます。 | COMBO | はい | `"auto"`<br />`"1:1"`<br />`"3:2"`<br />`"2:3"`<br />`"4:3"`<br />`"3:4"`<br />`"5:4"`<br />`"4:5"`<br />`"16:9"`<br />`"9:16"`<br />`"21:9"`<br />`"9:21"`<br />`"2:1"`<br />`"1:2"` |
| `reasoning_strength` | モデルがレンダリング前にどれだけ考え、計画し、自己改善するか。 | COMBO | はい | `"high"`<br />`"low"` |
| `enable_web_search` | 画像を計画する際に、モデルが事実や最新情報をウェブ検索できるようにします。 | BOOLEAN | いいえ | True<br />False（デフォルト: True） |
| `enable_image_search` | 画像を計画する際に、モデルが参照画像を検索できるようにします。 | BOOLEAN | いいえ | True<br />False（デフォルト: True） |
| `enable_shell` | 計画中にモデルがコードを実行できるようにします。正確なレイアウト、チャート、図表のためです。オフの場合、数量と配置は近似されます。 | BOOLEAN | いいえ | True<br />False（デフォルト: True） |
| `seed` | ノードを再実行するかどうかを決定するシード。API にはシードがないため、この値に関係なく実際の結果は非決定的です。 | INT | はい | 0 – 2147483647（デフォルト: 42） |

注: プロンプトには少なくとも1文字が必要です。`aspect_ratio` が `"auto"` に設定されている場合、明示的なサイズは API に送信されず、モデルがプロンプトから出力サイズを決定します。`seed` パラメータはノードが再実行されるタイミングのみを制御します。API には送信されないため、生成結果は非決定的です。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | API から返された生成画像。デコードされ、バッチ画像として提供されます。API レスポンスに複数の画像が含まれる場合、それらは1つのバッチにまとめられます。 | IMAGE |
