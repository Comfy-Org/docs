HeyGen Voice 1.0 Instant Clone でクローンした音声でテキストを読み上げます。このノードはテキストと音声IDを HeyGen に送信し、生成されたスピーチを音声として返します。`heygen-voice-1` と、より高速でコストが低い `heygen-voice-1-turbo` の2つのモデルを利用できます。

`model` を選択すると、そのモデル固有のパラメータが表示されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 使用するモデルです。`heygen-voice-1-turbo` はより高速で、コストは低くなります。モデルを選択すると、そのモデル固有のパラメータ（`voice_id`、`text`、`language`、`expressiveness_boost`）が表示されます。 | DYNAMIC_COMBO | はい | `"heygen-voice-1"`<br />`"heygen-voice-1-turbo"` |
| `voice_id` | HeyGen Voice 1.0 Instant Clone の音声です（デフォルト：空）。 | STRING | はい | N/A |
| `text` | 読み上げるテキストです。最大5000文字です。約12分を超えるスピーチは失敗するため、非常に長い中国語や日本語のテキストは分割してください（デフォルト：空）。 | STRING | はい | 1～5000文字 |
| `language` | テキストの言語です。セルビア語やマレー語など、自動検出が混同しやすい近縁言語では設定してください（デフォルト：`"auto"`）。 | COMBO | はい | `"auto"`<br />複数の言語プリセット |
| `expressiveness_boost` | 値が高いほど表現力が豊かになり、値が低いほど元の音声に近づきます（デフォルト：0.5）。 | FLOAT | はい | 0.0～1.0（ステップ0.05） |

**注：** `voice_id` は HeyGen Voice 1.0 Instant Clone で作成した音声である必要があります。空の場合、ノードはエラーで停止します。`text` は少なくとも1文字を含む必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `AUDIO` | テキストから生成されたスピーチで、クローンした音声で読み上げられます。 | AUDIO |
