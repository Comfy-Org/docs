Save Image-Text (to Folder) は、画像とテキストキャプションのペアのデータセットを、ComfyUI の出力ディレクトリ内のフォルダーに保存します。各画像は PNG ファイルとして書き出され、対応するキャプションは同じベースファイル名の TXT ファイルとして書き出されるため、すべての画像がその説明とペアになります。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | 保存する画像のリスト。 | IMAGE | はい | - |
| `texts` | 保存するテキストキャプションのリスト。この入力はオプションです。 | STRING | いいえ | - |
| `folder_name` | 画像を保存するフォルダー名（出力ディレクトリ内）。(デフォルト: "dataset") | STRING | はい | - |
| `filename_prefix` | 保存する画像ファイル名のプレフィックス。(デフォルト: "image") | STRING | はい | - |
| `モード` | 既存のファイルを上書きするか、上書きを避けるためにファイル名をインクリメントするか。(デフォルト: "overwrite") | COMBO | はい | "overwrite"<br />"increment" |

**注意:** `images` 入力はリストであり、ノードは `images` と `texts` の両方をリストとして受け取ります。`texts` 入力はオプションです。指定する場合はテキストキャプションのリストとし、`images` と同じ数の項目を含める必要があります。各キャプションは、対応する画像とペアになる `.txt` ファイルとして保存されます。`overwrite` モードでは、ファイルは `{filename_prefix}_{index}.png` という名前になり、同じ名前の既存ファイルを置き換えます。`increment` モードでは、既存ファイルが上書きされないように、ファイル名に一意のカウンターが追加されます。`folder_name` は出力ディレクトリ内のパスに解決される必要があり、それを脱出しようとするフォルダー名（たとえば `..` を使用するもの）は拒否されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| - | このノードはデータを返しません。ファイルをファイルシステムに直接保存します。 | - |
