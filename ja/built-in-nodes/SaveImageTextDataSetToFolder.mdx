Save Image-Text (to Folder) は、画像のリストとそれに対応するテキストキャプションを、ComfyUI の出力ディレクトリ内の指定フォルダに保存します。PNG ファイルとして保存される各画像について、同じベース名を持つ対応する TXT ファイルが作成され、キャプションが保存されます。これにより、生成画像とその説明文をペアにした整理されたデータセットを作成する際に役立ちます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | 保存する画像のリスト。 | IMAGE | はい | - |
| `texts` | 保存するテキストキャプションのリスト。この入力はオプションです。 | STRING | いいえ | - |
| `folder_name` | 画像の保存先フォルダ名（出力ディレクトリ内）。デフォルト: "dataset" | STRING | はい | - |
| `filename_prefix` | 保存する画像ファイル名のプレフィックス。デフォルト: "image" | STRING | はい | - |
| `モード` | 既存ファイルを上書きするか、ファイル名を増分して上書きを避けるかを指定します。デフォルト: "overwrite" | COMBO | はい | "overwrite"<br />"increment" |

**注記:** `images` 入力はリストです。`texts` 入力はオプションであり、指定する場合はテキストキャプションのリストで、`images` と同じ項目数である必要があります。各キャプションは、対応する画像とペアになる `.txt` ファイルとして保存されます。`overwrite` モードでは、ファイルは `{filename_prefix}_{index}.png` という名前で保存され、同じ名前の既存ファイルがあれば置き換えられます。`increment` モードでは、既存ファイルを上書きしないように、ファイル名に一意のカウンタが追加されます。`folder_name` は出力ディレクトリ内のパスに解決される必要があり、出力ディレクトリから抜け出そうとするフォルダ名（例: `..`）は拒否されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| - | このノードはデータを返しません。ファイルをファイルシステムに直接保存します。 | - |
