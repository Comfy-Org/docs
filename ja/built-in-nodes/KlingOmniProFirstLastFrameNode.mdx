このノードは、最新のKling AIモデルを使用して、開始フレーム、オプションの終了フレーム、または参照画像からビデオを生成します。単一のビデオや、各セグメントに個別のプロンプトと長さを持つ複数ショットのストーリーボードを作成できます。このノードはこれらの入力を処理し、指定された長さと解像度のビデオを生成し、オプションでオーディオを生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | ビデオ生成に使用する特定のKling AIモデル。 | COMBO | 必須 | `"kling-v3-omni"`<br />`"kling-video-o1"` |
| `プロンプト` | ビデオの内容を説明するテキストプロンプト。ポジティブな説明とネガティブな説明の両方を含めることができます。ストーリーボードが有効な場合は無視されます。 | STRING | 必須 | - |
| `継続時間` | 生成されるビデオの希望の長さ（秒単位）（デフォルト: 5）。 | INT | 必須 | 3〜15 |
| `開始フレーム` | ビデオシーケンスの開始画像。 | IMAGE | 必須 | - |
| `終了フレーム` | ビデオのオプションの終了フレーム。`reference_images` と同時に使用することはできません。ストーリーボードでは機能しません。 | IMAGE | 任意 | - |
| `リファレンス画像` | 最大6枚の追加参照画像。 | IMAGE | 任意 | - |
| `解像度` | 生成されるビデオの出力解像度（デフォルト: "1080p"）。 | COMBO | 任意 | `"4k"`<br />`"1080p"`<br />`"720p"` |
| `ストーリーボード` | 個別のプロンプトと長さを持つ一連のビデオセグメントを生成します。`kling-v3-omni` でのみサポートされます。 | DYNAMIC_COMBO | 任意 | `"disabled"`<br />`"1 storyboard"`<br />`"2 storyboards"`<br />`"3 storyboards"`<br />`"4 storyboards"`<br />`"5 storyboards"`<br />`"6 storyboards"` |
| `音声を生成` | ビデオのオーディオを生成します（デフォルト: False）。`kling-v3-omni` でのみサポートされます。 | BOOLEAN | 任意 | True / False |
| `シード` | シードはノードを再実行するかどうかを制御します。シードに関係なく結果は非決定的です（デフォルト: 0）。 | INT | 任意 | 0〜2147483647 |

### ストーリーボード入力

`storyboards` が `"disabled"` 以外の値に設定されている場合、選択した各セグメントに対して次の入力が追加されます（N は 1 から選択したストーリーボード数まで）。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | ストーリーボードセグメント N のプロンプト。最大512文字。（デフォルト: ""） | STRING | 必須 | - |
| `storyboard_N_duration` | ストーリーボードセグメント N の長さ（秒単位）（デフォルト: 4）。 | INT | 必須 | 1〜15 |

**重要な制約事項:**

* `end_frame` 入力は `reference_images` 入力と同時に使用できません。
* `end_frame` 入力はストーリーボードと同時に使用できません。
* `kling-video-o1` モデルは、10秒を超える長さ、オーディオ生成、4k解像度、ストーリーボードをサポートしていません。
* `kling-video-o1` モデルで `end_frame` または `reference_images` を提供しない場合、`duration` は5秒または10秒のみに設定できます。
* すべての入力画像（`first_frame`、`end_frame`、および任意の `reference_images`）は、幅と高さの両方が最低300ピクセルである必要があります。
* すべての入力画像のアスペクト比は、1:2.5 から 2.5:1 の間でなければなりません。
* `reference_images` 入力では、最大6枚の画像を提供できます。
* `prompt` テキストの長さは1文字以上2500文字以下でなければなりません（ストーリーボードが有効な場合は0文字も許可されます）。
* プロンプトでは、プレースホルダー `@image`、`@image1`、`@image2` などを使用して入力画像を参照できます。これらは自動的にAPI互換の画像参照形式に変換されます。
* ストーリーボードが有効な場合、すべてのストーリーボードセグメントの合計長さは、グローバルな `duration` 値と等しくなければなりません。
* 各ストーリーボードのプロンプトの長さは1文字以上512文字以下でなければなりません。
