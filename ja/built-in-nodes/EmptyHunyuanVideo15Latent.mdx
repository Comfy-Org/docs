このノードは、HunyuanVideo 1.5 モデルで使用するために特別にフォーマットされた空の潜在テンソルを作成します。モデルの潜在空間に適した正しいチャンネル数と空間次元を持つゼロのテンソルを割り当てることで、動画生成の空白の開始点を生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `幅` | 動画フレームの幅（ピクセル単位）。 | INT | はい | - |
| `高さ` | 動画フレームの高さ（ピクセル単位）。 | INT | はい | - |
| `長さ` | 動画シーケンス内のフレーム数。 | INT | はい | - |
| `バッチサイズ` | バッチ内で生成する動画サンプルの数（デフォルト: 1）。 | INT | いいえ | - |

**注:** 生成される潜在テンソルの空間次元は、入力 `width` と `height` を 16 で割ることで計算されます（このノードは 8 ではなく 16 の空間スケール係数を使用します）。時間次元（フレーム数）は `((length - 1) // 4) + 1` として計算されます。これらの計算では整数除算が使用されるため、切り捨てを避けるには `width` と `height` を 16 の倍数にする必要があります。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `samples` | HunyuanVideo 1.5 モデルに適した次元を持つ空の潜在テンソル。テンソルの形状は `[batch_size, 32, ((length - 1) // 4) + 1, height // 16, width // 16]` です。出力には `downscale_ratio_spacial` の値 16 も含まれます。 | LATENT |
