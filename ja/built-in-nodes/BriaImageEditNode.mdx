Bria FIBO Image Edit ノードは、テキストによる指示を使用して既存の画像を編集します。画像とプロンプトを Bria API に送信し、FIBO モデルが編集版を生成します。オプションのマスクを使用すると、変更を特定の領域に限定できます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 画像編集に使用するモデルバージョン。 | COMBO | はい | `"FIBO"` |
| `画像` | 編集したい入力画像。 | IMAGE | はい | - |
| `プロンプト` | 画像を編集するための指示（デフォルト: 空）。 | STRING | はい | - |
| `ネガティブプロンプト` | 編集後の画像に表示させたくない内容を説明するテキスト（デフォルト: 空）。 | STRING | はい | - |
| `構造化プロンプト` | JSON 形式の構造化編集プロンプトを含む文字列。通常のプロンプトの代わりにこれを使用すると、正確かつプログラム的な制御が可能になります（デフォルト: 空）。 | STRING | はい | - |
| `シード` | ランダム生成を初期化するために使用する数値。結果を再現可能にします（デフォルト: 1）。 | INT | はい | 1〜2147483647 |
| `ガイダンススケール` | 値を高くすると、画像がプロンプトにより忠実に従うようになります（デフォルト: 3）。 | FLOAT | はい | 3.0〜5.0 |
| `ステップ数` | モデルが実行するノイズ除去ステップの数（デフォルト: 50）。 | INT | はい | 20〜50 |
| `モデレーション` | モデレーション設定。`"true"` を選択すると、追加のモデレーションオプションが表示されます。 | DYNAMIC_COMBO | はい | `"false"`<br />`"true"` |
| `マスク` | 省略した場合、編集は画像全体に適用されます。 | MASK | いいえ | - |

### モデレーション入力

`moderation` が `"true"` に設定されている場合、以下の追加入力が使用可能になります：

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | 不適切なコンテンツがないかプロンプトテキストをモデレーションするかどうか（デフォルト: false）。 | BOOLEAN | いいえ | `true`<br />`false` |
| `visual_input_moderation` | 不適切なコンテンツがないか入力画像をモデレーションするかどうか（デフォルト: false）。 | BOOLEAN | いいえ | `true`<br />`false` |
| `visual_output_moderation` | 不適切なコンテンツがないか編集後の出力画像をモデレーションするかどうか（デフォルト: true）。 | BOOLEAN | いいえ | `true`<br />`false` |

**重要な制約事項：**

- `prompt` または `structured_prompt` の少なくとも一方は空でない必要があります。両方が空の場合、ノードはエラーを発生させます。
- `moderation` が `"true"` に設定されている場合、上記の3つのモデレーション入力が表示されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | Bria API によって返された編集済み画像。 | IMAGE |
| `構造化プロンプト` | 編集プロセス中に使用または生成された構造化プロンプト。 | STRING |
