このノードは、2つの Qwen 画像モデルを、個々のコンポーネントを調整可能な重みでブレンドすることによってマージします。各重みは、2番目のモデルの対応する部分がマージ結果にどれだけ寄与するかを制御し、位置埋め込み、テキスト処理層、画像入力層、60個すべての transformer ブロック、出力投影を個別に混ぜ合わせることができます。最終結果は単一の MODEL であり、通常のモデルが期待される場所であればどこでも使用できます。

| --- | --- | --- | --- | --- |

| `model2` | マージする2番目のモデル | MODEL | はい | - |
| `pos_embeds.` | 位置埋め込みをブレンドするための重み（デフォルト：1.0） | FLOAT | はい | 0.0～1.0（ステップ：0.01） |
| `img_in.` | 画像入力処理をブレンドするための重み（デフォルト：1.0） | FLOAT | はい | 0.0～1.0（ステップ：0.01） |
| `txt_norm.` | テキスト正規化をブレンドするための重み（デフォルト：1.0） | FLOAT | はい | 0.0～1.0（ステップ：0.01） |
| `txt_in.` | テキスト入力処理をブレンドするための重み（デフォルト：1.0） | FLOAT | はい | 0.0～1.0（ステップ：0.01） |
| `time_text_embed.` | 時間およびテキスト埋め込みをブレンドするための重み（デフォルト：1.0） | FLOAT | はい | 0.0～1.0（ステップ：0.01） |
