Topaz Image Enhance は、Topaz モデルを使用して、単一の入力画像に業界標準のアップスケーリングと画像補正を適用します。画像を Topaz API に送信し、選択したモデルで処理して、補正後の結果を返します。Reimagine、Bloom 2、Wonder 3.5 の3つのモデルから選択できます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | 補正する入力画像です。入力画像は1枚のみサポートされます。 | IMAGE | はい | 単一画像 |
| `モデル` | 使用する Topaz 補正モデルです。選択したモデルによって、表示されるモデル固有の設定が決まります。 | DYNAMIC_COMBO | はい | `"Reimagine"`<br />`"Bloom 2"`<br />`"Wonder 3.5"` |
| `出力幅` | 0 を指定すると自動計算されます（通常は元のサイズになるか、`output_height` が指定されている場合はそれに比例して拡大縮小されます）。Wonder 3.5 は 1x から 6x までのアップスケール倍率のみをサポートします。Bloom 2 と Wonder 3.5 は入力のアスペクト比を維持し、要求されたサイズを目標値として扱います。(デフォルト: 0) | INT | いいえ | 0 〜 32000 |
| `出力高さ` | 0 を指定すると、元の高さと同じ高さで出力するか、`output_width` が指定されている場合はそれに比例して拡大縮小することを意味します。Wonder 3.5 は 1x から 6x までのアップスケール倍率のみをサポートします。Bloom 2 と Wonder 3.5 は入力のアスペクト比を維持し、要求されたサイズを目標値として扱います。(デフォルト: 0) | INT | いいえ | 0 〜 32000 |

### Reimagine 入力

これらの設定は、`model` が `"Reimagine"` に設定されている場合に適用されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | クリエイティブなアップスケーリングのガイダンスに使用する任意のテキストプロンプトです。(デフォルト: "") | STRING | はい | 任意のテキスト |
| `creativity` | 補正の創造性レベルです。(デフォルト: 3) | INT | はい | 1 〜 9 |
| `subject_detection` | 被写体検出モード（詳細設定）です。 | COMBO | はい | `"All"`<br />`"Foreground"`<br />`"Background"` |
| `face_enhancement` | 処理中に（存在する場合）顔を補正します。(デフォルト: True) | BOOLEAN | はい | true<br />false |
| `face_enhancement_creativity` | 顔補正の創造性レベルを設定します。(デフォルト: 0.0) | FLOAT | はい | 0.0 〜 1.0 |
| `face_enhancement_strength` | 補正された顔が背景に対してどれだけシャープになるかを制御します。(デフォルト: 1.0) | FLOAT | はい | 0.0 〜 1.0 |
| `face_preservation` | 被写体の顔の同一性を保持します。(デフォルト: True) | BOOLEAN | はい | true<br />false |
| `color_preservation` | 元の色を保持します。(デフォルト: True) | BOOLEAN | はい | true<br />false |
| `crop_to_fill` | デフォルトでは、出力のアスペクト比が異なる場合、画像はレターボックス化されます。有効にすると、出力サイズを埋めるように画像をクロップします。(デフォルト: False) | BOOLEAN | はい | true<br />false |

### Bloom 2 入力

これらの設定は、`model` が `"Bloom 2"` に設定されている場合に適用されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成用の任意のテキストプロンプトです。空のままにすると、入力画像からプロンプトが自動生成されます。(デフォルト: "") | STRING | はい | 任意のテキスト |
| `creativity` | 1 は抑制された補正、9 は新たに生成されたディテールを伴う顕著な再解釈です。(デフォルト: 3) | INT | はい | 1 〜 9 |
| `seed` | 再現可能な生成のためのシードです。(デフォルト: 2) | INT | はい | 1 〜 2000 |
| `color_preservation` | 元の色を保持します。(デフォルト: True) | BOOLEAN | はい | true<br />false |
| `grain` | 出力画像にグレインを追加します。(デフォルト: False) | BOOLEAN | はい | true<br />false |
| `grain_model` | 使用するグレインモデルです。grain が無効な場合は無視されます。 | COMBO | はい | `"silver"`<br />`"gaussian"`<br />`"grey"` |
| `grain_strength` | グレイン効果の強さです。grain が無効な場合は無視されます。(デフォルト: 0.5) | FLOAT | はい | 0.0 〜 1.0 |
| `grain_size` | グレイン粒子のサイズです。grain が無効な場合は無視されます。(デフォルト: 1.0) | FLOAT | はい | 1.0 〜 5.0 |
| `grain_density` | グレイン効果の強度です。grain が無効な場合は無視されます。(デフォルト: 0.5) | FLOAT | はい | 0.0 〜 1.0 |

### Wonder 3.5 入力

これらの設定は、`model` が `"Wonder 3.5"` に設定されている場合に適用されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `enhancement_strength` | さまざまな入力条件に応じた補正レベルです。(デフォルト: "high") | COMBO | はい | `"low"`<br />`"medium"`<br />`"high"` |
| `grain` | 出力画像にグレインを追加します。(デフォルト: False) | BOOLEAN | はい | true<br />false |
| `grain_model` | 使用するグレインモデルです。grain が無効な場合は無視されます。 | COMBO | はい | `"silver"`<br />`"gaussian"`<br />`"grey"` |
| `grain_strength` | グレイン効果の強さです。grain が無効な場合は無視されます。(デフォルト: 0.5) | FLOAT | はい | 0.0 〜 1.0 |
| `grain_size` | グレイン粒子のサイズです。grain が無効な場合は無視されます。(デフォルト: 1.0) | FLOAT | はい | 1.0 〜 5.0 |
| `grain_density` | グレイン効果の強度です。grain が無効な場合は無視されます。(デフォルト: 0.5) | FLOAT | はい | 0.0 〜 1.0 |

**注記:** 入力画像は1枚のみサポートされます。入力バッチに複数の画像が含まれている場合、ノードはエラーを発生させます。グレイン設定（`grain_model`、`grain_strength`、`grain_size`、`grain_density`）は、`grain` が有効でない限り無視されます。Bloom 2 では、`prompt` を空のままにすると、入力画像からプロンプトが自動生成されます。Wonder 3.5 は 1x から 6x までのアップスケール倍率のみをサポートします。Bloom 2 と Wonder 3.5 は入力のアスペクト比を維持し、要求されたサイズを目標値として扱います。
