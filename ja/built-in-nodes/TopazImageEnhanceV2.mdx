Topaz Image Enhance は、Topaz モデルを使用して、単一の入力画像に業界標準のアップスケーリングと画像強調を適用します。画像を Topaz API に送信し、選択したモデルで処理して、強調された結果を返します。Reimagine、Bloom 2、Wonder 3.5 の3つのモデルから選択できます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | 強調する入力画像。サポートされる入力画像は1つのみです。 | IMAGE | はい | 単一画像 |
| `モデル` | 使用する Topaz 強調モデル。選択したモデルに応じて、モデル固有の設定が表示されます。 | DYNAMIC_COMBO | はい | `"Reimagine"`<br />`"Bloom 2"`<br />`"Wonder 3.5"` |
| `出力幅` | ゼロの場合は自動計算されます（通常は元のサイズか、`output_height` が指定されている場合はそれに比例してスケーリングされます）。Wonder 3.5 は 1x から 6x までのアップスケール係数のみサポートします。Bloom 2 と Wonder 3.5 は入力のアスペクト比を維持し、リクエストされたサイズを目標値として扱います。（デフォルト: 0） | INT | いいえ | 0〜32000 |
| `出力高さ` | ゼロの場合は、元の高さで出力されるか、`output_width` が指定されている場合はそれに比例してスケーリングされます。Wonder 3.5 は 1x から 6x までのアップスケール係数のみサポートします。Bloom 2 と Wonder 3.5 は入力のアスペクト比を維持し、リクエストされたサイズを目標値として扱います。（デフォルト: 0） | INT | いいえ | 0〜32000 |

### Reimagine 入力

これらの設定は、`model` が `"Reimagine"` に設定されている場合に適用されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | クリエイティブなアップスケーリングのガイダンスに使用するオプションのテキストプロンプト。（デフォルト: ""） | STRING | はい | 任意のテキスト |
| `creativity` | 強調のクリエイティビティレベル。（デフォルト: 3） | INT | はい | 1〜9 |
| `subject_detection` | 被写体検出モード。 | COMBO | はい | `"All"`<br />`"Foreground"`<br />`"Background"` |
| `face_enhancement` | 処理中に顔（存在する場合）を強調します。（デフォルト: True） | BOOLEAN | はい | true<br />false |
| `face_enhancement_creativity` | 顔強調のクリエイティビティレベルを設定します。（デフォルト: 0.0） | FLOAT | はい | 0.0〜1.0 |
| `face_enhancement_strength` | 強調された顔が背景に対してどの程度シャープかを制御します。（デフォルト: 1.0） | FLOAT | はい | 0.0〜1.0 |
| `face_preservation` | 被写体の顔の同一性を保持します。（デフォルト: True） | BOOLEAN | はい | true<br />false |
| `color_preservation` | 元の色を保持します。（デフォルト: True） | BOOLEAN | はい | true<br />false |
| `crop_to_fill` | デフォルトでは、出力アスペクト比が異なる場合、画像はレターボックス化されます。有効にすると、画像をクロップして出力寸法に合わせて埋めます。（デフォルト: False） | BOOLEAN | はい | true<br />false |

### Bloom 2 入力

これらの設定は、`model` が `"Bloom 2"` に設定されている場合に適用されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成に使用するオプションのテキストプロンプト。空のままにすると、入力画像からプロンプトが自動生成されます。（デフォルト: ""） | STRING | はい | 任意のテキスト |
| `creativity` | 1 は控えめな強調、9 は新しく生成されたディテールを伴う顕著な再解釈です。（デフォルト: 3） | INT | はい | 1〜9 |
| `seed` | 再現可能な生成のためのシード。（デフォルト: 2） | INT | はい | 1〜2000 |
| `color_preservation` | 元の色を保持します。（デフォルト: True） | BOOLEAN | はい | true<br />false |
| `grain` | 出力画像にグレインを追加します。（デフォルト: False） | BOOLEAN | はい | true<br />false |
| `grain_model` | 使用するグレインモデル。`grain` が無効の場合は無視されます。 | COMBO | はい | `"silver"`<br />`"gaussian"`<br />`"grey"` |
| `grain_strength` | グレイン効果の強さ。`grain` が無効の場合は無視されます。（デフォルト: 0.5） | FLOAT | はい | 0.0〜1.0 |
| `grain_size` | グレイン粒子のサイズ。`grain` が無効の場合は無視されます。（デフォルト: 1.0） | FLOAT | はい | 1.0〜5.0 |
| `grain_density` | グレイン効果の密度。`grain` が無効の場合は無視されます。（デフォルト: 0.5） | FLOAT | はい | 0.0〜1.0 |

### Wonder 3.5 入力

これらの設定は、`model` が `"Wonder 3.5"` に設定されている場合に適用されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `enhancement_strength` | さまざまな入力条件に対する強調レベル。（デフォルト: "high"） | COMBO | はい | `"low"`<br />`"medium"`<br />`"high"` |
| `grain` | 出力画像にグレインを追加します。（デフォルト: False） | BOOLEAN | はい | true<br />false |
| `grain_model` | 使用するグレインモデル。`grain` が無効の場合は無視されます。 | COMBO | はい | `"silver"`<br />`"gaussian"`<br />`"grey"` |
| `grain_strength` | グレイン効果の強さ。`grain` が無効の場合は無視されます。（デフォルト: 0.5） | FLOAT | はい | 0.0〜1.0 |
| `grain_size` | グレイン粒子のサイズ。`grain` が無効の場合は無視されます。（デフォルト: 1.0） | FLOAT | はい | 1.0〜5.0 |
| `grain_density` | グレイン効果の密度。`grain` が無効の場合は無視されます。（デフォルト: 0.5） | FLOAT | はい | 0.0〜1.0 |

**注:** サポートされる入力画像は1つのみです。グレイン設定（`grain_model`、`grain_strength`、`grain_size`、`grain_density`）は、`grain` が有効でない限り無視されます。Bloom 2 では、`prompt` を空のままにすると入力画像からプロンプトが自動生成されます。Wonder 3.5 は 1x から 6x までのアップスケール係数のみサポートします。Bloom 2 と Wonder 3.5 は入力のアスペクト比を維持し、リクエストされたサイズを目標値として扱います。
