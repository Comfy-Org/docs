Topaz Image Enhance は、業界標準のアップスケーリングと画像強調を、Topaz モデルを使用して単一の入力画像に適用します。画像を Topaz API に送信し、選択したモデルで処理して、強調された結果を返します。Reimagine、Bloom 2、Wonder 3.5 の3つのモデルから選択できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 強調する入力画像。入力画像は1つのみサポートされています。 | IMAGE | はい | Single image |
| `model` | 使用する Topaz 強調モデル。選択したモデルに応じて、モデル固有の設定が表示されます。 | STRING | はい | `"Reimagine"`<br />`"Bloom 2"`<br />`"Wonder 3.5"` |
| `output_width` | ゼロの場合は自動計算されます（通常は元のサイズ、または `output_height` が指定されている場合はそれに比例してスケーリングされます）。Wonder 3.5 は 1x から 6x までのアップスケール係数のみサポートしています。Bloom 2 と Wonder 3.5 は入力のアスペクト比を維持し、要求されたサイズをターゲットとして扱います。（デフォルト: 0） | INT | いいえ | 0 to 32000 |
| `output_height` | ゼロの場合は元の高さ、または `output_width` が指定されている場合はそれに比例してスケーリングされた高さで出力されます。Wonder 3.5 は 1x から 6x までのアップスケール係数のみサポートしています。Bloom 2 と Wonder 3.5 は入力のアスペクト比を維持し、要求されたサイズをターゲットとして扱います。（デフォルト: 0） | INT | いいえ | 0 to 32000 |

### Reimagine 設定

これらの設定は、`model` が `"Reimagine"` に設定されている場合に適用されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 創造的なアップスケーリングのガイダンスに使用するオプションのテキストプロンプト。（デフォルト: ""） | STRING | はい | Any text |
| `creativity` | 強調処理の創造性レベル。（デフォルト: 3） | INT | はい | 1 to 9 |
| `subject_detection` | 被写体検出モード。 | STRING | はい | `"All"`<br />`"Foreground"`<br />`"Background"` |
| `face_enhancement` | 処理中に（存在する場合）顔を強調します。（デフォルト: True） | BOOLEAN | はい | true<br />false |
| `face_enhancement_creativity` | 顔強調の創造性レベルを設定します。（デフォルト: 0.0） | FLOAT | はい | 0.0 to 1.0 |
| `face_enhancement_strength` | 強調された顔が背景と比較してどれだけシャープであるかを制御します。（デフォルト: 1.0） | FLOAT | はい | 0.0 to 1.0 |
| `face_preservation` | 被写体の顔の同一性を保持します。（デフォルト: True） | BOOLEAN | はい | true<br />false |
| `color_preservation` | 元の色を保持します。（デフォルト: True） | BOOLEAN | はい | true<br />false |
| `crop_to_fill` | デフォルトでは、出力アスペクト比が異なる場合、画像はレターボックス表示になります。有効にすると、出力サイズに合わせて画像をトリミングします。（デフォルト: False） | BOOLEAN | はい | true<br />false |

### Bloom 2 設定

これらの設定は、`model` が `"Bloom 2"` に設定されている場合に適用されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|

| `creativity` | 1 は控えめな強調、9 は新しく生成されたディテールを伴う顕著な再解釈です。（デフォルト: 3） | INT | はい | 1 to 9 |
| `seed` | 再現可能な生成のためのシード値。（デフォルト: 2） | INT | はい | 1 to 2000 |
| `color_preservation` | 元の色を保持します。（デフォルト: True） | BOOLEAN | はい | true<br />false |
| `grain` | 出力画像にグレイン（粒状ノイズ）を追加します。（デフォルト: False） | BOOLEAN | はい | true<br />false |
| `grain_model` | 使用するグレインモデル。グレインが無効の場合は無視されます。 | STRING | はい | `"silver"`<br />`"gaussian"`<br />`"grey"` |
| `grain_strength` | グレイン効果の強さ。グレインが無効の場合は無視されます。（デフォルト: 0.5） | FLOAT | はい | 0.0 to 1.0 |
| `grain_size` | グレイン粒子のサイズ。グレインが無効の場合は無視されます。（デフォルト: 1.0） | FLOAT | はい | 1.0 to 5.0 |
| `grain_density` | グレイン効果の強度。グレインが無効の場合は無視されます。（デフォルト: 0.5） | FLOAT | はい | 0.0 to 1.0 |
