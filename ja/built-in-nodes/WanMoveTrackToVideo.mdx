WanMoveTrackToVideo ノードは、オプションのモーショントラッキング情報を組み込み、ビデオ生成用のコンディショニングおよび潜在空間データを準備します。開始画像シーケンスを潜在表現にエンコードし、オブジェクトトラックの位置データをブレンドして、生成されたビデオのモーションをガイドできます。このノードは、ビデオモデルに使用できる空の潜在テンソルとともに、変更されたポジティブコンディショニングとネガティブコンディショニングを出力します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `positive` | 変更されるポジティブコンディショニング入力です。 | CONDITIONING | はい | - |
| `negative` | 変更されるネガティブコンディショニング入力です。 | CONDITIONING | はい | - |
| `vae` | 開始画像を潜在空間にエンコードするために使用される VAE モデルです。 | VAE | はい | - |
| `トラック` | オブジェクトのパスを含むオプションのモーショントラッキングデータです。 | TRACKS | いいえ | - |
| `強度` | トラックコンディショニングの強さです。（デフォルト：1.0） | FLOAT | はい | 0.0 - 100.0 |
| `幅` | 出力ビデオの幅です。16 で割り切れる必要があります。（デフォルト：832） | INT | はい | 16 - MAX_RESOLUTION |
| `高さ` | 出力ビデオの高さです。16 で割り切れる必要があります。（デフォルト：480） | INT | はい | 16 - MAX_RESOLUTION |
| `長さ` | ビデオシーケンスのフレーム数です。4 刻みで指定します。（デフォルト：81） | INT | はい | 1 - MAX_RESOLUTION |
| `バッチサイズ` | 潜在出力のバッチサイズです。（デフォルト：1） | INT | はい | 1 - 4096 |
| `開始画像` | エンコードする開始画像または画像シーケンスです。 | IMAGE | はい | - |
| `clip_vision_output` | コンディショニングに追加するオプションの CLIP ビジョンモデル出力です。 | CLIP_VISION_OUTPUT | いいえ | - |

**注記：** `strength` パラメータは、`tracks` が指定され、かつ `strength` が 0.0 より大きい場合にのみ効果があります。トラックコンディショニングは、`start_image` も指定されている場合にのみ適用されます。`tracks` が指定されていない場合、または `strength` が 0.0 の場合は、トラックブレンドはスキップされます。トラックブレンドが有効な場合、ポジティブコンディショニングはトラックブレンド済みの潜在画像を受け取り、ネガティブコンディショニングは変更されていない潜在画像を受け取ります。`start_image` が指定されていない場合、潜在画像およびマスクのコンディショニングは作成されません。ポジティブおよびネガティブコンディショニングは変更されずにそのまま渡され（`clip_vision_output` が指定されている場合は引き続き追加されます）、ノードは空の潜在テンソルを出力します。

**注記：** `start_image` が指定されている場合、画像シーケンスはターゲットの `width` と `height` にリサイズされ、最初の `length` フレームに切り詰められます。シーケンスが `length` より短い場合、VAE エンコードの前に、残りのフレームがニュートラルグレー（値 0.5）で埋められます。結果のコンディショニングには `concat_mask` が含まれ、開始画像フレームに対応する時間的位置では値が 0、それ以外では 1 になります。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | 変更されたポジティブコンディショニングです。`concat_latent_image`、`concat_mask`、`clip_vision_output` を含む可能性があります。 | CONDITIONING |
| `negative` | 変更されたネガティブコンディショニングです。`concat_latent_image`、`concat_mask`、`clip_vision_output` を含む可能性があります。 | CONDITIONING |
| `latent` | `batch_size`、`length`、`height`、`width` の入力によって決定される、形状 `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]` の空の潜在テンソルです。 | LATENT |
