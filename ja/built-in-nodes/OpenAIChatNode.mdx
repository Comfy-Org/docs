このノードは、OpenAIモデルからテキスト応答を生成します。モデルにテキストプロンプトを提供し、オプションで画像やファイルをコンテキストとして使用して、その情報をOpenAIモデルに送信します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 范囲 |
|------------|------|----------|------|-------|
| `プロンプト` | モデルに提供するテキスト入力、応答を生成するために使用されます。モデルに応答を求めるテキストです。 | STRING | はい | - |
| `コンテキストの永続化` | このパラメータは廃止され、効果はありません。後方互換性のために含まれていますが、ノードの動作に影響を与えません。 | BOOLEAN | いいえ | - |
| `モデル` |応答を生成するために使用されるモデル。利用可能なOpenAIモデルから選択してください。 | COMBO | はい | gpt-6-astra<br />gpt-5.6-sol<br />gpt-5.6-terra<br />gpt-5.6-luna<br />gpt-5.5-pro<br />gpt-5.5<br />gpt-5<br />gpt-5-mini<br />gpt-5-nano<br />gpt-4.1<br />gpt-4.1-mini<br />gpt-4.1-nano<br />o4-mini<br />o3<br />o1-pro<br />o1 |
| `画像` | モデルにコンテキストとして使用するオプションの画像。複数の画像を含めるには、Batch Imagesノードを使用してください。 | IMAGE | いいえ | - |
| `ファイル` | モデルにコンテキストとして使用するオプションのファイル。OpenAI Chat Input Filesノードからの入力を受け入れます。 | OPENAI_INPUT_FILES | いいえ | - |
| `詳細オプション` | モデルの詳細な設定を行うためのオプション。OpenAI Chat Advanced Optionsノードからの入力を受け入れます。 | OPENAI_CHAT_CONFIG | いいえ | - |

## 出力

| 出力名 | 説明 | データ型 |
|--------|------|----------|
| `output_text` | OpenAIモデルによって生成されたテキスト応答。これは、入力プロンプトとコンテキストに基づいて生成されたテキストです。 | STRING |

## ノート

- `persist_context`パラメータは廃止され、効果はありません。後方互換性のために含まれていますが、使用すべきではありません。
- `images`入力は、モデルに追加のコンテキストを提供するために使用できます。複数の画像が提供された場合、これらはBatch Imagesノードを使用して接続する必要があります。
- `files`入力は、ファイルの形で追加のコンテキストを提供するために使用できます。これらのファイルはOpenAI Chat Input Filesノードから接続する必要があります。
- `advanced_options`入力は、モデルの動作を詳細に設定するために使用できます。これはOpenAI Chat Advanced Optionsノードから接続する必要があります。
