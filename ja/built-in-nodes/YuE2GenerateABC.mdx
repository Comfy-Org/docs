このノードは、YuE2 text-and-lyrics モデルを使用して、スタイルの説明と歌詞に基づく楽曲の ABC 記譜法を生成します。生成された `abc` 出力は、YuE2 Generate Music ノードに接続して音声を生成できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `clip` | スタイルと歌詞をトークン化し、ABC 記譜法を生成するために使用される YuE2 モデル。 | CLIP | はい | - |
| `style` | 楽曲の音楽スタイルを説明するテキスト。複数行入力とダイナミックプロンプトに対応。 | STRING | はい | - |
| `lyrics` | 楽曲の歌詞を含むテキスト。複数行入力とダイナミックプロンプトに対応。 | STRING | はい | - |
| `シード` | 生成に使用されるランダムシード。変更すると異なる結果が生成されます。デフォルト: 0。 | INT | はい | 0 〜 18446744073709551615 |
| `モード` | full: メロディーとコードを生成します。melody: メロディーのみを生成し、カバーに推奨されます。 | COMBO | はい | "full"<br />"melody" |
| `max_abc_tokens` | ABC 記譜法用に生成されるトークンの最大数。デフォルト: 8192。詳細設定。 | INT | はい | 1 〜 20000 |
| `temperature` | 生成されるトークンのランダム性を制御します。値が高いほど出力が多様になります。デフォルト: 0.7。詳細設定。 | FLOAT | はい | 0.0〜5.0 |
| `top_p` | 核サンプリングのしきい値。累積確率がこのしきい値内のトークンのみが考慮されます。デフォルト: 0.9。詳細設定。 | FLOAT | はい | 0.01〜1.0 |
| `top_k` | トークンの選択を確率上位 K 個に制限します。デフォルト: 30。詳細設定。 | INT | はい | 1〜32768 |
| `repetition_penalty` | 生成時に繰り返しトークンに適用されるペナルティ。デフォルト: 1.005。詳細設定。 | FLOAT | はい | 0.01〜10.0 |
| `penalty_window` | 繰り返しのペナルティ計算に使用される最近の ABC トークン数。デフォルト: 100。詳細設定。 | INT | はい | 1〜20000 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `abc` | 生成された楽曲の ABC 記譜法。YuE2 Generate Music ノードに接続できます。 | STRING |
