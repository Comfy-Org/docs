このノードは、既存の Tripo 3D モデルを受け取り、リグ付きバージョンを作成します。つまり、モデルにアニメーション化できるようにスケルトンが付与されます。リグ対象モデルのタスク ID を指定し、リグバージョン、スケルトンタイプ、ボーン命名スタイル、出力ファイル形式を選択すると、ノードがジョブを Tripo に送信し、完了するまで待機して、ダウンロードした結果を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `original_model_task_id` | リグを付ける元の 3D モデルのタスク ID です。通常、以前の Tripo モデル生成ノードで生成された ID です。 | MODEL_TASK_ID | はい | - |
| `model_version` | 使用するリグモデルバージョンです。v1.0: ヒューマノイド（biped）キャラクターのみ、90 以上のアニメーションプリセット。v2.5: 非ヒューマノイドのクリーチャー（quadruped、hexapod、octopod、avian、serpentine、aquatic）。デフォルト: `v1.0-20240301`。 | COMBO | いいえ | "v1.0-20240301"<br />"v2.5-20260210" |
| `rig_type` | スケルトンタイプです。"auto" は最初に Tripo の無料リグチェックを実行し、推奨タイプを使用します。デフォルト: "auto"。 | COMBO | いいえ | "auto"<br />"biped"<br />"quadruped"<br />"hexapod"<br />"octopod"<br />"avian"<br />"serpentine"<br />"aquatic" |
| `spec` | ボーン命名: Tripo ネイティブまたは Mixamo 互換。Tripo は、mixamo spec で作成された v1.0 リグに自身のアニメーションプリセットをリターゲットできません。Tripo: Retarget rigged model では tripo を使用してください。デフォルト: "tripo"。 | COMBO | いいえ | "tripo"<br />"mixamo" |
| `out_format` | 出力ファイル形式です。結果は一致する出力に渡されます。デフォルト: "glb"。 | COMBO | いいえ | "glb"<br />"fbx" |

**注:** v1.0 モデルバージョン（`v1.0-20240301`）は、biped スケルトンのみをサポートします。このバージョンで biped 以外の `rig_type` を使用すると、ノードはエラーを発生させ、代わりに `v2.5-20260210` を使用するよう指示します。

**注:** `rig_type` が "auto" の場合、Tripo はまずモデルにリグを付けられるかどうかを確認し、推奨されるスケルトンタイプを選択します。Tripo がモデルにリグを付けられないと報告した場合、ノードはエラーで失敗します。

**注:** このノードは、Tripo が GLB または FBX ファイルを返すことを想定しています。Tripo がその他のファイル形式を返した場合、ノードはエラーを発生させます。

**注:** `out_format` に一致する出力のみが設定されます: `out_format` が "glb" の場合は `GLB`、`out_format` が "fbx" の場合は `FBX` です。もう一方の 3D 出力は空です。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_file` | 生成されたリグ付きモデルのファイル名（タスク ID と形式拡張子）。後方互換性のためにのみ保持されています。 | STRING |
| `rig task_id` | リグ生成プロセスを追跡するためのタスク ID です。 | RIG_TASK_ID |
| `GLB` | リグ付きモデルの GLB 3D ファイルです。`out_format` が "glb" の場合に設定されます。 | FILE3DGLB |
| `FBX` | リグ付きモデルの FBX 3D ファイルです。`out_format` が "fbx" の場合に設定されます。 | FILE3DFBX |
