`CLIPTextEncodeFlux` は、Flux アーキテクチャ向けに設計された高度なテキストエンコードノードです。CLIP-L と T5XXL の異なるエンコーダーを通じて2つの別々のテキスト入力を処理し、それらをガイダンススケールと組み合わせて、画像生成のための統合されたコンディショニング出力を生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `クリップ` | Flux アーキテクチャをサポートする CLIP モデル。CLIP-L と T5XXL の両方のエンコーダーを含みます。 | CLIP | はい | - |
| `クリップ_l` | CLIP-L エンコーダーによって処理されるテキスト入力。スタイルやテーマなど、簡潔なキーワード記述に適しています。複数行入力と動的プロンプトに対応しています。 | STRING | はい | - |
| `t5xxl` | T5XXL エンコーダーによって処理されるテキスト入力。複雑なシーンや詳細を表現する、詳細な自然言語記述に適しています。複数行入力と動的プロンプトに対応しています。 | STRING | はい | - |
| `ガイダンス` | 生成プロセスにおけるテキスト条件の影響を制御します。値が大きいほどテキストにより厳密に従います。デフォルト: 3.5。0.1 刻みで調整可能です。 | FLOAT | はい | 0.0 - 100.0 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `CONDITIONING` | 両方のエンコーダーからの融合された埋め込みとガイダンスパラメータを含み、条件付き画像生成に使用されます。 | CONDITIONING |
