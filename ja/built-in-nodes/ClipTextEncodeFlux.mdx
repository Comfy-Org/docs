`CLIPTextEncodeFlux` は、Flux アーキテクチャ向けに設計されたテキストエンコードノードです。2つの個別のテキスト入力を受け取り、異なるエンコーダー——CLIP-L と T5XXL——で処理し、ガイダンススケールと組み合わせて、画像生成用の統合されたコンディショニング出力を生成します。

## 入力

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `クリップ` | Flux アーキテクチャをサポートする CLIP モデルで、CLIP-L と T5XXL の両方のエンコーダーを含みます。 | CLIP | はい | - |
| `クリップ_l` | CLIP-L エンコーダーによって処理されるテキスト入力です。スタイルやテーマなど、簡潔なキーワード記述に適しています。複数行入力と動的プロンプトをサポートします。 | STRING | はい | - |
| `t5xxl` | T5XXL エンコーダーによって処理されるテキスト入力です。複雑なシーンや詳細を表現する、詳細な自然言語記述に適しています。複数行入力と動的プロンプトをサポートします。 | STRING | はい | - |
| `ガイダンス` | 生成プロセスに対するテキスト条件の影響度を制御します。値が大きいほど、テキストにより厳密に従うことを意味します。デフォルト：3.5。0.1 刻みで調整可能です。 | FLOAT | はい | 0.0 - 100.0 |

## 出力

| Output Name | Description | Data Type |
| --- | --- | --- |
| `CONDITIONING` | 両方のエンコーダーからの融合された埋め込みと、ガイダンスパラメータを含み、条件付き画像生成に使用されます。 | CONDITIONING |
