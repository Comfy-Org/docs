このノードは、メッシュに既存のUVレイアウトを使用してPBRテクスチャを3Dメッシュにベイクします。UV空間でメッシュをラスタライズし、各テクセルでスパースボクセルボリュームから色とマテリアル属性をサンプリングして、ベースカラー画像とメタリックマップ、ラフネスマップを出力します。メッシュのUV展開は行わないため、上流にUV展開ノードを接続する必要があります。生成される画像は、ApplyTextureToMeshで同じメッシュと組み合わせてGLBとして保存することを想定しています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | テクスチャをベイクする3Dメッシュ。既にUVレイアウトが必要です。上流にUV展開ノードを接続する必要があります。 | MESH | はい | |
| `voxel_colors` | ボクセルごとの色と、任意のPBR属性（メタリックチャンネルとラフネスチャンネル）を含むスパースボクセルボリューム。 | VOXEL | はい | |
| `texture_size` | 正方形UVアトラスの解像度（表示名: "resolution"、デフォルト: 2048）。 | INT | はい | 64～8192 |
| `reference_mesh` | 任意の高密度な間引き前メッシュ。サンプリング前に各テクセルをその真のサーフェスへ逆投影し、粗いメッシュでのファセット状のベイクを除去します。 | MESH | いいえ | |

注記:

- 入力メッシュにはUVが必要です。UVがない場合、ノードはエラーを発生させます。UVは頂点と1:1である必要があります（頂点ごとに1つのUV）。
- メッシュとボクセル座標にバッチ次元が含まれる場合、各バッチ項目は個別にベイクされます。バッチ項目にボクセルまたはフェイスがない場合、その項目はスキップされ、黒いテクスチャが出力されます。
- バッチに対して `reference_mesh` が指定された場合、単一メッシュのみを含む場合を除き、バッチインデックスによって対応付けられます。単一メッシュのみの場合は、そのメッシュがすべての項目に使用されます。
- どのUV三角形にも覆われていないテクセルは、最も近い被覆済みテクセルから埋められるため、テクスチャの継ぎ目に黒が引き込まれません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `base_color` | RGBベースカラーテクスチャマップ。値は0～1の範囲のfloatです。 | IMAGE |
| `metallic` | グレースケールのメタリックマップ（float、0～1）。ボクセルカラーにメタリックチャンネルが含まれない場合は黒になります。 | IMAGE |
| `roughness` | グレースケールのラフネスマップ（float、0～1）。ボクセルカラーにラフネスチャンネルが含まれない場合は黒になります。 | IMAGE |
