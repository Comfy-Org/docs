このノードは、メッシュの既存のUVレイアウトを使用して、PBRテクスチャを3Dメッシュにベイクします。各テクセルでスパースボクセルボリュームから色とマテリアル属性をサンプリングし、ベースカラー画像とメタリックマップ、ラフネスマップを出力します。メッシュのUV展開は行わないため、上流にUV展開ノードを接続する必要があります。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|---|---|---|---|---|
| `mesh` | テクスチャをベイクする3Dメッシュ。あらかじめUVレイアウトが設定されている必要があります。上流にUV展開ノードを接続する必要があります。 | MESH | はい | |
| `voxel_colors` | ボクセルごとの色と、オプションのPBR属性（メタリックチャンネルとラフネスチャンネル）を含むスパースボクセルボリューム。 | VOXEL | はい | |
| `texture_size` | 正方形UVアトラスの解像度（表示名: "resolution"、デフォルト: 2048）。 | INT | はい | 64〜8192 |
| `reference_mesh` | 任意指定の、デシメーション前の高密度メッシュ。各テクセルを本来のサーフェスに逆投影してからサンプリングするため、粗いメッシュでのファセット状のベイクを防ぎます。 | MESH | いいえ | |

注記:

- 入力メッシュにはUVが必要です。UVがない場合、ノードはエラーを発生させます。UVは頂点と1:1（頂点ごとに1つのUV）である必要があります。
- メッシュとボクセル座標にバッチ次元が含まれる場合、各バッチ項目は個別にベイクされます。バッチ項目にボクセルがない場合や面がない場合はスキップされ、その項目には黒いテクスチャが出力されます。
- バッチに対して`reference_mesh`が指定された場合、バッチインデックスによって対応付けられます。ただし、`reference_mesh`が単一のメッシュのみを含む場合は、そのメッシュがすべてのバッチ項目に対して使用されます。

## 出力

| 出力名 | 説明 | データ型 |
|---|---|---|
| `base_color` | RGBベースカラーテクスチャマップ。値は0〜1の範囲の浮動小数点数です。 | IMAGE |
| `metallic` | グレースケールのメタリックマップ（float、0〜1）。ボクセルカラーにメタリックチャンネルが含まれていない場合は黒になります。 | IMAGE |
| `roughness` | グレースケールのラフネスマップ（float、0〜1）。ボクセルカラーにラフネスチャンネルが含まれていない場合は黒になります。 | IMAGE |
