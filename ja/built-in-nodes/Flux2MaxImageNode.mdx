プロンプトと明示的な出力サイズを指定して、BFL API を通じて Flux.2 [max] で画像を生成します。オプションで参照画像によるガイダンスを利用することもできます。Flux.2 [pro] Image と同じ入力を持ちます。

**注意：** このノードはソースコード上で非推奨（deprecated）としてマークされています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 画像の生成または編集を行うためのプロンプトです。 | STRING | はい | - |
| `幅` | 生成画像の幅（ピクセル単位、デフォルト：1024）。 | INT | はい | 256 〜 2048 （ステップ 32） |
| `高さ` | 生成画像の高さ（ピクセル単位、デフォルト：768）。 | INT | はい | 256 〜 2048 （ステップ 32） |
| `シード` | ノイズ生成に使用する乱数シード（デフォルト：0）。 | INT | はい | 0 〜 18446744073709551615 |
| `プロンプトアップサンプリング` | プロンプトのアップサンプリングを実行するかどうか。有効にすると、より創造的な生成のためにプロンプトが自動的に変更されます（デフォルト：`True`）。これは上級者向けの設定です。 | BOOLEAN | はい | True / False |
| `画像` | image-to-image 生成用の参照画像（オプション）。各画像はアップロード前に最大 2048x2048 ピクセルにダウンスケールされます。 | IMAGE | いいえ | 0 〜 9 枚の画像 |

**制約：**

* 9 枚を超える参照画像を接続するとエラーが発生します。
* 出力サイズはメガピクセル単位で課金されるため、`width` と `height` の値が大きいほどコストが高くなります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | 生成された画像です。 | IMAGE |
