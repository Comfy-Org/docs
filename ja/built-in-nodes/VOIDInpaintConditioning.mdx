VOIDInpaintConditioning ノードは、CogVideoX モデルでインペインティングに必要なコンディショニングデータを準備します。ソース動画と前処理済みの quadmask を受け取り、それらを VAE でエンコードし、モデルがマスク領域を埋めるために使用する 32 チャンネルのコンディショニング信号（マスクからの 16 チャンネル + マスクされた動画からの 16 チャンネル）に結合します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `positive` | インペインティング latent 情報で拡張される positive コンディショニング | CONDITIONING | はい | - |
| `negative` | インペインティング latent 情報で拡張される negative コンディショニング | CONDITIONING | はい | - |
| `vae` | マスクとマスクされた動画を latent 空間にエンコードするために使用する VAE モデル | VAE | はい | - |
| `video` | ソース動画フレーム [T, H, W, 3] | IMAGE | はい | - |
| `quadmask` | VOIDQuadmaskPreprocess からの前処理済み quadmask [T, H, W] | MASK | はい | - |
| `width` | 動画とマスクのリサイズ先の幅（デフォルト: 672） | INT | はい | 16 ～ MAX_RESOLUTION（ステップ: 8） |
| `height` | 動画とマスクのリサイズ先の高さ（デフォルト: 384） | INT | はい | 16 ～ MAX_RESOLUTION（ステップ: 8） |
| `length` | 処理するピクセルフレーム数。CogVideoX-Fun-V1.5（patch_size_t=2）では、latent_t は偶数でなければなりません — 奇数 latent_t を生成する長さは切り捨てられます（例: 49 → 45）（デフォルト: 45） | INT | はい | 1 ～ MAX_RESOLUTION（ステップ: 1） |
| `batch_size` | 出力ノイズ latent のバッチサイズ（デフォルト: 1） | INT | はい | 1 ～ 64 |

**注意:** CogVideoX-Fun-V1.5 は `patch_size_t=2` を使用するため、エンコードされた latent の時間次元は偶数でなければなりません。`length` が奇数 `latent_t` を生成する場合、ノードは自動的に最も近い有効な値へ切り捨て、警告をログに記録します。奇数 `latent_t` を使用すると、循環パディングによって最後のフレームが破損し、デコードされた動画の終盤で目に見えるジッターや被写体の消失が発生することがあります。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `positive` | インペインティング latent 情報が追加された positive コンディショニング | CONDITIONING |
| `negative` | インペインティング latent 情報が追加された negative コンディショニング | CONDITIONING |
| `latent` | 形状 [batch_size, 16, latent_t, latent_h, latent_w] のゼロで埋められたノイズ latent テンソル | LATENT |
