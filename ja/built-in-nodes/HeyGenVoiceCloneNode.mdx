HeyGen の Voice 1.0 エンジンを使用して、1人の話者の録音から音声をクローンします。このノードは録音をアップロードし、インスタント音声クローンを作成し、HeyGen が処理を完了するまで待機して、`voice_id` を返します。これを HeyGen Voice 1.0 Text to Speech に接続するか、HeyGen Avatar Video と HeyGen Talking Photo の `custom_voice_id` に接続してください。クローンの作成は無料です。音声を使用して生成したスピーチに対して課金されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 1人の話者の録音。少なくとも10秒間の明瞭な音声を使用してください。最初の3分間のみが使用されます。 | AUDIO | はい | N/A |
| `language` | 録音で話されている言語（デフォルト："auto"）。 | COMBO | はい | `"auto"`<br />複数の言語プリセット |
| `similarity` | 音声が録音にどれだけ忠実に従うか（デフォルト："max"）。 | COMBO | はい | `"medium"`<br />`"high"`<br />`"extra_high"`<br />`"max"` |
| `remove_background_noise` | クローン作成前に録音のバックグラウンドノイズを除去します（デフォルト：True）。 | BOOLEAN | はい | True<br />False |
| `seed` | シードを変更すると録音を再度クローンします。各クローンはわずかに異なる音声になります（デフォルト：42）。 | INT | はい | 0 ～ 2147483647 |

**注意：** 音声は HeyGen アカウント内に「ComfyUI Voice」として作成され、ノードは UI に `voice_id` を出力するため、再利用用にコピーできます。話者が密接に関連する言語と混同されやすい言語を話している場合を除き、`language` は "auto" のままにしてください。`seed` 入力には UI で固定の Control After Generate コントロールが含まれているため、別のクローンが必要な場合は手動で変更してください。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `voice_id` | クローンされた音声の ID。HeyGen Voice 1.0 Text to Speech ノードで再利用するか、`custom_voice_id` として使用できます。 | STRING |
