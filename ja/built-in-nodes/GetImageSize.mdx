GetImageSize は入力画像を読み取り、その幅・高さ・バッチサイズを返します。また、ノードはこれらの測定値をノードインターフェース上に直接表示します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | 幅・高さ・バッチサイズを抽出する入力画像 | IMAGE | はい | - |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `width` | 入力画像の幅（ピクセル単位） | INT |
| `height` | 入力画像の高さ（ピクセル単位） | INT |
| `batch_size` | 入力バッチに含まれる画像の数 | INT |
