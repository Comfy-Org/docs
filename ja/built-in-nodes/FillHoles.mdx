このノードは、開いた境界エッジを検出し、新しい面を作成して閉じることで、3Dメッシュの穴を埋めます。GPU上で実行され、既存のジオメトリとUVを保持し、単一メッシュ、メッシュのリスト、またはメッシュのバッチを処理できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 処理対象の3Dメッシュ。単一メッシュ、メッシュのリスト、またはバッチ化されたメッシュを受け付けます。 | MESH | はい | - |
| `max_perimeter` | 埋める穴の最大周長。0 にすると無効になります。（デフォルト: 0.03） | FLOAT | はい | 0.0 to no upper limit （ステップ 0.0001） |
| `weld_epsilon_rel` | 事前ウェルド許容値（バウンディングボックス対角線に対する割合）。境界検出にはウェルド済みの頂点が必要です。0 にするとスキップします。（デフォルト: 1e-5） | FLOAT | はい | 0.0 to no upper limit (step 1e-6) |
| `max_vertices` | サイクルあたりの境界頂点数上限。セントロイドファンは、小さなほぼ平面の穴にのみ有効です。16以下に保ってください。（デフォルト: 16） | INT | はい | 3 〜 1024 |
| `fill_chains` | 開いたチェーンも埋めます（サイクルだけでなく）。ノイズが多くなります。OFF にすると cumesh と一致します。（デフォルト: False） | BOOLEAN | はい | True or False |

注記: `max_perimeter` が 0 より大きい場合、ノードは穴を埋めます。0 の場合、穴埋めは完全にスキップされます。`weld_epsilon_rel` が 0 より大きい場合、ノードは穴を検出する前に重複頂点を事前ウェルドします。ウェルド許容値は、指定されたバウンディングボックス対角線の割合から開始し、メッシュがウェルド済みと見なされるか、許容値が 1e-2 の上限に達するまで、倍々に自動増加します。境界頂点が 8 を超える穴はセントロイドファン充填（新しいセントロイド頂点を挿入）を使用し、より小さい穴は既存の境界頂点を再利用する頂点ファン充填を使用します。デフォルトでは閉じた境界サイクルのみが埋められます。開いたチェーンも閉じるには、`fill_chains` を True に設定します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `mesh` | 穴が埋められたメッシュ。入力のバッチ形式と一致します。 | MESH |
