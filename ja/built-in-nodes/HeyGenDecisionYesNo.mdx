接続したテキスト、画像、音声、または動画について「はい/いいえ」の質問をすると、分岐に使用するブール値が得られます。`result` を If/Else Switch ノードに接続して 2 つの経路から選択し、`answer` と `probability` を確認すると、回答がどれだけ明確だったかがわかります。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 使用するモデルです。`heygen-decision-1-turbo` は `heygen-decision-1` より高速でコストも低くなります（デフォルト: `"heygen-decision-1"`）。 | COMBO | はい | `"heygen-decision-1"`<br />`"heygen-decision-1-turbo"` |
| `question` | 接続内容についての「はい/いいえ」の質問です。最大 5000 文字です。"yes" が実際に対処したいケースになるように質問してください（デフォルト: "Is there a person in the image?"）。 | STRING | はい | 1～5000 文字 |
| `threshold` | `result` が true になる「"yes"」の確率です。明確な回答では 0 または 1 に近くなります（デフォルト: 0.5）。 | FLOAT | はい | 0.01～0.99（ステップ 0.01） |
| `images` | 質問対象の画像です。バッチの各フレームも数えて合計最大 4 枚です。ソケットをまたいで順番に `image_1` から `image_4` までの番号が付けられます。 | IMAGE | いいえ | 最大 4 枚の画像 |
| `audio_1` | 質問対象の音声です。最大 30 分です。 | AUDIO | いいえ | 最大 30 分 |
| `video_1` | 質問対象の動画です。最大 60 秒です。 | VIDEO | いいえ | 最大 60 秒 |
| `text` | 質問対象のテキストです。プロンプトや LLM の応答などで、最大 20000 文字です。 | STRING | いいえ | 最大 20000 文字 |

`text`、`images`、`audio_1`、`video_1` のうち少なくとも 1 つを接続し、質問の中でソケット名を使ってそれらを参照してください。例:「image_2 は image_1 と同じ人物を写していますか？」。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `result` | `"yes"` の確率が `threshold` に達したときに True、それ以外は False です。 | BOOLEAN |
| `answer` | 判定結果を文字列 `"yes"` または `"no"` で表します。`result` と同じ `threshold` に従います。 | STRING |
| `probability` | `"yes"` の確率で、0～1 の範囲です。 | FLOAT |
