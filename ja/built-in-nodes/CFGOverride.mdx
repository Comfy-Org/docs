CFG Override ノードを使用すると、サンプリング処理の特定の範囲（合計ステップ数のパーセンテージで指定）に対して、固定の CFG（Classifier-Free Guidance）スケール値を設定できます。複数の CFG Override ノードが接続されている場合、チェーン内でサンプラーに最も近いノードが、重複する範囲に対して優先されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | CFG オーバーライドを適用するモデル | MODEL | はい | |
| `cfg` | オーバーライド範囲中に使用する固定 CFG スケール値（デフォルト: 1.0） | FLOAT | はい | 0.0 から 100.0 |
| `開始パーセント` | サンプリング処理のパーセンテージとしての、オーバーライド範囲の開始点（デフォルト: 0.0） | FLOAT | はい | 0.0 から 1.0 |
| `終了パーセント` | サンプリング処理のパーセンテージとしての、オーバーライド範囲の終了点（デフォルト: 1.0） | FLOAT | はい | 0.0 から 1.0 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `MODEL` | CFG オーバーライドラッパーが適用されたモデル | MODEL |
