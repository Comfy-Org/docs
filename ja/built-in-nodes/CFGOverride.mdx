CFG Override ノードは、サンプリングプロセスの割合（sigma）範囲にわたって、CFG（Classifier-Free Guidance）スケールを固定値にオーバーライドします。複数の CFG Override ノードを使用する場合、範囲が重複する部分では、サンプラーに最も近いオーバーライドが優先されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | CFG オーバーライドを適用するモデルです。 | MODEL | はい | |
| `cfg` | オーバーライド範囲で使用する固定の CFG スケール値です。デフォルト: 1.0。 | FLOAT | はい | 0.0 〜 100.0 （ステップ 0.1） |
| `開始パーセント` | サンプリングプロセスの割合で表したオーバーライド範囲の開始点です。デフォルト: 0.0。 | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.001） |
| `終了パーセント` | サンプリングプロセスの割合で表したオーバーライド範囲の終了点です。デフォルト: 1.0。 | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.001） |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `MODEL` | CFG オーバーライドラッパーが適用されたモデルです。 | MODEL |
