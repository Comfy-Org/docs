Save Text ノードは、テキストコンテンツを出力ディレクトリ内のファイルに書き込みます。.txt、.csv、.md、.json 形式での保存をサポートし、有効な JSON が指定された場合は、JSON のプリティプリント処理を自動的に行います。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `text` | ファイルに保存するテキストコンテンツ。この入力は、他のノードから接続する必要があります。 | STRING | 必須 | - |
| `filename_prefix` | 出力ファイル名のプレフィックス。既存ファイルの上書きを防ぐため、5桁のカウンタが追加されます（デフォルト: "ComfyUI"）。 | STRING | 任意 | - |
| `format` | テキストを保存するファイル形式（デフォルト: "txt"）。"json" が選択された場合、有効な JSON テキストは2スペースのインデントでプリティプリントされます。それ以外の場合は、テキストはそのまま保存されます。 | COMBO | 任意 | `"txt"`<br />`"csv"`<br />`"md"`<br />`"json"` |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `text` | ファイルに保存された元のテキストコンテンツ | STRING |
