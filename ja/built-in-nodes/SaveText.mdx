Save Textノードは、テキストコンテンツを出力ディレクトリ内のファイルに書き込みます。.txt、.md、または.json形式での保存をサポートしており、有効なJSONが提供された場合は自動的にJSONのプリティプリントを処理します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `text` | ファイルに保存するテキスト内容。この入力は別のノードから接続する必要があります。 | STRING | はい | - |
| `filename_prefix` | 出力ファイル名のプレフィックス。既存ファイルの上書きを防ぐために5桁のカウンターが追加されます（デフォルト："ComfyUI"）。 | STRING | いいえ | - |
| `format` | テキストを保存するファイル形式（デフォルト："txt"）。"json"を選択すると、有効なJSONテキストが2スペースのインデントで整形され出力されます。それ以外の場合はテキストがそのまま保存されます。 | COMBO | いいえ | `"txt"`<br />`"md"`<br />`"json"` |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `text` | ファイルに保存された元のテキストコンテンツ | STRING |
