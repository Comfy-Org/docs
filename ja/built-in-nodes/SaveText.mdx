Save Text ノードは、テキストコンテンツを出力ディレクトリ内のファイルに書き込みます。.txt、.csv、.md、または .json 形式での保存に対応しており、"json" 形式を選択した場合、有効な JSON テキストは自動的に2スペースインデントで整形されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `text` | ファイルに保存するテキストコンテンツです。この入力は別のノードから接続する必要があります。 | STRING | はい | - |
| `filename_prefix` | 出力ファイル名のプレフィックスです。既存ファイルの上書きを防ぐために、5桁のカウンターが末尾に追加されます（デフォルト: "ComfyUI"）。 | STRING | いいえ | - |
| `format` | テキストを保存するファイル形式です（デフォルト: "txt"）。"json" の場合、有効な JSON テキストは自動的に2スペースインデントで整形されます。無効な JSON およびその他の形式はそのまま保存されます。記載されているオプションのみがサポートされています。 | COMBO | いいえ | `"txt"`<br />`"csv"`<br />`"md"`<br />`"json"` |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `text` | ファイルに保存された元のテキストコンテンツです。 | STRING |
