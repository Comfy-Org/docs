Save Text ノードは、テキストコンテンツを出力ディレクトリ内のファイルに書き込みます。.txt、.csv、.md、.json 形式での保存をサポートし、有効な JSON が指定された場合は JSON の整形出力を自動的に処理します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `text` | ファイルに保存するテキストコンテンツ。この入力は別のノードから接続する必要があります。 | STRING | はい | - |
| `filename_prefix` | 出力ファイル名のプレフィックス。既存ファイルへの上書きを防ぐため、5桁のカウンターが付加されます（デフォルト: "ComfyUI"）。 | STRING | いいえ | - |
| `format` | テキストを保存するファイル形式（デフォルト: "txt"）。"json" を選択した場合、有効な JSON テキストは 2 スペースのインデントで整形出力されます。それ以外の場合、テキストはそのまま保存されます。 | COMBO | いいえ | `"txt"`<br />`"csv"`<br />`"md"`<br />`"json"` |

### 注意事項

- `text` は強制入力であり、別のノードに接続する必要があります。直接入力することはできません。
- 保存されるファイル名は `<filename_prefix>_<5-digit counter>.<extension>` で、ComfyUI の出力ディレクトリ（プレフィックスから派生したサブフォルダ内）に書き込まれます。
- `"json"` 形式を選択すると、テキストを JSON として解析しようとします。解析に成功した場合、内容は 2 スペースのインデントで整形出力されて書き込まれます。解析に失敗した場合、生のテキストが変更されずに書き込まれます。
- ノードは保存されたファイルをインターフェースに報告するため、他の生成された出力ファイルと一緒に表示されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `text` | ファイルに保存された元のテキストコンテンツ | STRING |
