SVG ファイルをディスクに保存します。このノードは SVG データを入力として受け取り、ComfyUI の出力ディレクトリに書き込みます。ファイル名には連番のサフィックスが自動的に付けられます。ワークフローのプロンプト情報が利用可能な場合、メタデータ要素として SVG ファイル内に直接埋め込まれます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `svg` | ディスクに保存する SVG データ | SVG | はい | - |
| `ファイル名プレフィックス` | 保存するファイルのプレフィックス。%date:yyyy-MM-dd% や %Empty Latent Image.width% など、ノードの値を含めるための書式情報を含めることができます。（デフォルト: "svg/ComfyUI"） | STRING | はい | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `svg` | 保存後にそのまま渡される元の SVG データ | SVG |
| `ui` | ComfyUI インターフェースでの表示用の、ファイル名、サブフォルダー、種類を含む保存済みファイル情報 | DICT |

**注:** このノードは、利用可能な場合、ワークフローのメタデータ（プロンプトおよび追加の PNG 情報）を SVG ファイルに自動的に埋め込みます。メタデータは、SVG の metadata 要素内に CDATA セクションとして挿入されます。ファイルは `filename_prefix_00001_.svg` というパターンで保存されます。バッチを処理する場合、プレフィックス内の `%batch_num%` は現在のバッチ項目のインデックスに置き換えられます。このノードは出力ノードであるため、ファイル自体は画像プレビューとして表示されませんが、出力フォルダーに保存結果を生成します。
