ハイポリメッシュからアンビエントオクルージョンマップをベイクし、ローポリメッシュのUVレイアウトに書き込みます。出力はグレースケール画像で、白いテクセルは開いた領域、暗いテクセルは隙間やくぼみを表します。これは Apply Texture To Mesh ノードのオクルージョン入力用です。UV展開されたローポリメッシュと、その元となったハイポリメッシュを接続してください。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | ベイク先となるUV展開済みのローポリメッシュ。UVが必要です。UVがない場合はノードがエラーを発生させます。 | MESH | はい | - |
| `high_poly` | ローポリメッシュの元となったハイポリメッシュ。オクルージョンのソースジオメトリとして使用されます。 | MESH | はい | - |
| `resolution` | テクスチャの解像度（ピクセル単位）。各テクセルがオクルージョン値を受け取ります。デフォルト: 1024。 | INT | はい | 64 ～ 8192（ステップ 64） |
| `samples` | テクセルあたりのレイ数。多いほど滑らかになりますが、処理は遅くなります。ノイズが多い場合は増やしてください。デフォルト: 64。 | INT | はい | 4 ～ 1024（ステップ 4） |
| `max_distance` | レイの長さ。バウンディングボックスの対角線に対する割合です。小さいほど、より局所的で密接なオクルージョンになります。デフォルト: 0.5。 | FLOAT | はい | 0.01 ～ 2.0（ステップ 0.01） |
| `strength` | オクルージョンの強さをスケーリングします。1 より大きいと暗く、1 より小さいと明るくなります。デフォルト: 1.0。 | FLOAT | はい | 0.0 ～ 2.0（ステップ 0.05） |
| `bias` | サーフェスからのレイ起点の持ち上げ量。バウンディングボックスの対角線に対する割合です。平面に暗い斑点や穴が現れる場合は増やしてください。デフォルト: 0.01。 | FLOAT | はい | 0.0001 ～ 0.2（ステップ 0.0005） |

注意: `low_poly` にはUV座標が必要です。このノードはメッシュを展開しません。`high_poly` にバッチアイテムが1つしかない場合、そのアイテムは `low_poly` のすべてのバッチアイテムに対して再利用されます。また、`low_poly` のバッチアイテムに面がない場合はスキップされ、代わりに全面白の画像が出力され、警告が記録されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `occlusion` | 値が [0,1] の範囲のグレースケール・アンビエントオクルージョン画像（白 = 開いた領域、暗 = 隙間）。`low_poly` のバッチアイテムごとに1枚の画像が生成されます。Apply Texture To Mesh ノードのオクルージョン入力（ORM マップ / occlusionTexture にパックされます）用です。 | IMAGE |
