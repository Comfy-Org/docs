ハイポリメッシュからアンビエントオクルージョンマップをローポリメッシュの UV レイアウトにベイクします。出力はグレースケール画像で、白いテクセルは開いている部分、暗いテクセルは隙間を表します。これは Apply Texture To Mesh ノードの occlusion 入力用です。UV 展開済みのローポリメッシュと、そのデシメーション元であるハイポリメッシュを接続してください。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | ベイク先となる UV 展開済みのローポリメッシュ。UV が必要で、存在しない場合はノードがエラーを発生させます。 | MESH | はい | - |
| `high_poly` | ローポリのデシメーション元であるハイポリメッシュ。オクルージョンのソースジオメトリとして使用されます。 | MESH | はい | - |
| `resolution` | テクスチャ解像度（ピクセル単位）。各テクセルにオクルージョン値が格納されます。デフォルト: 1024。 | INT | はい | 64 〜 8192 （ステップ 64） |
| `samples` | テクセルあたりのレイ数。多いほど滑らかになりますが遅くなります。ざらつく場合は増やしてください。デフォルト: 64。 | INT | はい | 4 〜 1024 （ステップ 4） |
| `max_distance` | レイの長さ。バウンディングボックスの対角線に対する割合です。小さいほどタイトで、より局所的なオクルージョンになります。デフォルト: 0.5。 | FLOAT | はい | 0.01 〜 2.0 （ステップ 0.01） |
| `strength` | オクルージョンをスケーリングします。1 より大きいと暗く、1 より小さいと明るくなります。デフォルト: 1.0。 | FLOAT | はい | 0.0 〜 2.0 （ステップ 0.05） |
| `bias` | サーフェスから持ち上げるレイ原点のオフセット。バウンディングボックスの対角線に対する割合です。平坦な面にも暗い斑点/穴が現れる場合は増やしてください。デフォルト: 0.01。 | FLOAT | はい | 0.0001 〜 0.2 （ステップ 0.0005） |

注: `low_poly` には UV 座標が必要です。このノードはメッシュの UV 展開を決して行いません。`high_poly` にバッチ項目が 1 つだけ含まれる場合、それは `low_poly` の各バッチ項目に対して再利用されます。面を持たない `low_poly` のバッチ項目はスキップされ、警告がログに記録されたうえで、全面白の画像に置き換えられます。`low_poly` の UV が 0-1 の範囲外にはみ出す場合、それらは均一に範囲内へフィットし直され、タイル/UDIM 形式のレイアウトが検出されると警告がログに記録されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `occlusion` | グレースケールのアンビエントオクルージョン画像で、値は [0,1] の範囲です（白 = 開いている部分、暗い = 隙間）。`low_poly` のバッチ項目ごとに 1 枚の画像です。Apply Texture To Mesh ノードの occlusion 入力用です（ORM マップ / occlusionTexture にパックされます）。 | IMAGE |
