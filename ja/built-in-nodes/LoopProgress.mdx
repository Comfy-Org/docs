LoopProgress は、ループの進捗を ComfyUI サーバーインターフェースに報告する開発専用のヘルパーノードです。実行のたびにテキスト「Iteration X / Y」をクライアントへ送信し、現在のイテレーション位置を変更せずに返します。これにより、データフローを変更することなくループ内にインラインで配置できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `start_id` | 進捗メッセージが属するプロンプト/ループインスタンスの識別子です。指定されたリストの最初の項目は、進捗テキストを正しい実行中インスタンスへルーティングするために使用されます。 | STRING | はい | - |
| `position` | 現在のイテレーション位置（インデックス）です。指定されたリストの最初の項目は進捗メッセージに使用され、出力としても返されます。 | INT | はい | - |
| `total` | イテレーションの総数です。`position` と一緒に使用して「Iteration X / Y」進捗メッセージを構築します。 | INT | はい | - |

注：このノードはリスト入力（`is_input_list=True`）として宣言されており、すべての入力を受け付けるため、接続された各値はリストとして扱われ、最初の要素だけが読み取られます。このノードは常に実行され（入力フィンガープリントは固定です）、そのためループが1周するたびに再実行されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `position` | 現在のイテレーション位置です。`position` 入力から変更されずにそのまま渡されます。 | INT |
