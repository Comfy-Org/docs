Anthropic の Claude モデルからテキスト応答を生成します。テキストプロンプトを指定し、必要に応じてマルチモーダルコンテキスト用の画像を1枚以上追加すると、ノードはモデルが生成したテキスト応答を返します。

## 入力

入力は、共通設定、モデル選択時に表示されるモデル固有設定、任意の参照画像にグループ化されています。

### パラメータの制約

- **画像の制限:** 1リクエストあたり最大20枚の画像を提供できます。20枚を超える画像を接続するとエラーが発生します。
- **プロンプトの要件:** プロンプトには、少なくとも1つの空白以外の文字が含まれている必要があります。空のプロンプトは検証エラーになります。
- **温度の扱い:** 思考が有効な場合、Anthropic API では `temperature` を未設定にする必要があります（デフォルトの1.0になります）。Opus 5、Opus 4.8、Fable 5、Sonnet 5 は温度設定を公開していません。Opus 4.7 は `temperature` を無視し、`reasoning_effort` が `"low"`、`"medium"`、`"high"` に設定されているモデルでも無視されます。
- **推論・思考の動作:** `reasoning_effort` 設定は、思考を有効にするかどうかを制御します。Opus 5 と Fable 5 は常に推論が有効です。Haiku 4.5 は推論をサポートしていません。思考が有効な場合、ノードは選択されたモデルに応じて、適応型または予算ベースの適切な思考モードを使用します。予算モードでは、実際の応答に少なくとも1024トークンを残すために、推論トークンの予算に上限が設定されます。
- **安全性による拒否:** Claude が安全性の理由でリクエストへの回答を拒否した場合、ノードはプロンプトを言い換えるか、別のモデルを試すよう求めるエラーを発生させます。
- **出力テキスト:** 思考・推論ブロックは出力に含まれません。生成されたテキストのみが返されます。
