Anthropic の Claude モデルからテキスト応答を生成します。テキストプロンプトと、必要に応じてマルチモーダルコンテキスト用の1枚以上の画像を提供すると、ノードはモデルによって生成されたテキスト応答を返します。

## 入力

入力は、共通設定、モデルを選択したときに表示されるモデル固有の設定、および省略可能な参照画像にグループ化されています。

|-----------|-------------|-----------|----------|-------|
| `モデル` | 応答の生成に使用する Claude モデル。モデルを選択すると、以下に対応するモデル固有の設定が表示されます。 | DYNAMIC_COMBO | はい | `"Opus 5.5"`<br />`"Opus 5"`<br />`"Opus 4.8"`<br />`"Fable 5.1"`<br />`"Fable 5"`<br />`"Sonnet 5"`<br />`"Opus 4.7"`<br />`"Opus 4.6"`<br />`"Sonnet 4.6"`<br />`"Sonnet 4.5"`<br />`"Haiku 4.5"` |

### パラメータの制約

- **画像の上限:** 1リクエストにつき最大20枚の画像を指定できます。20枚を超える画像を接続するとエラーが発生します。
- **プロンプト必須:** プロンプトには空白以外の文字が少なくとも1文字含まれている必要があります。空のプロンプトは検証エラーを発生させます。
- **temperature の扱い:** 思考が有効な場合、Anthropic API では temperature を未設定にする必要があります（デフォルトでは 1.0 になります）。Opus 5.5、Opus 5、Opus 4.8、Fable 5.1、Fable 5、Sonnet 5 は temperature 設定を公開していません。Opus 4.7 は `temperature` を無視し、`reasoning_effort` が `"off"` 以外に設定されたすべてのモデルも同様に無視します。
- **推論/思考の動作:** `reasoning_effort` 設定は、思考を有効にするかどうかを制御します。Opus 5.5、Opus 5、Fable 5.1、Fable 5 では推論が常に有効です。Haiku 4.5 は推論をサポートしていません。思考が有効な場合、ノードは選択したモデルに適した思考モード（適応型または予算ベース）を使用します。予算モードでは、実際の応答用に少なくとも 1024 トークンを残すように、推論トークン予算が上限設定されます。
- **安全性による拒否:** Claude が安全上の理由でリクエストへの回答を拒否した場合、ノードはプロンプトを言い換えるか、別のモデルを試すよう求めるエラーを発生させます。
- **出力テキスト:** 思考ブロックおよび推論ブロックは出力に含まれません。返されるのは生成されたテキストのみです。
