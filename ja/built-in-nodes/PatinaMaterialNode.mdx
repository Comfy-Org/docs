テキスト記述から、完全でシームレスにタイル可能な PBR マテリアルを生成します。ベーステクスチャと最大 5 枚のマテリアルマップを生成し、必要に応じてマップの SeedVR アップスケーリングも行います。入力画像を指定すると image-to-image パスとして結果を制御でき、入力画像とマスクを組み合わせると inpaint パスになります。実際のマテリアルをスキャンすることなく、ゲーム向けまたは 3D 向けのサーフェスを生成するために使用できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成するマテリアルまたはテクスチャの説明。 | STRING | はい | 複数行テキスト |
| `image_size` | 出力テクスチャサイズ。`"custom"` を指定すると `width` と `height` 入力が表示されます。デフォルト: `"1:1 (1024x1024)"`。 | DYNAMIC_COMBO | はい | `"1:1 (1024x1024)"`<br />`"1:1 (512x512)"`<br />`"4:3 (1024x768)"`<br />`"3:4 (768x1024)"`<br />`"16:9 (1024x576)"`<br />`"9:16 (576x1024)"`<br />`"custom"` |
| `basecolor` | basecolor（アルベド）マップを生成します。デフォルト: True。 | BOOLEAN | はい | true<br />false |
| `normal` | normal マップを生成します。デフォルト: True。 | BOOLEAN | はい | true<br />false |
| `roughness` | roughness マップを生成します。デフォルト: False。 | BOOLEAN | はい | true<br />false |
| `metalness` | metalness マップを生成します。デフォルト: False。 | BOOLEAN | はい | true<br />false |
| `height` | height（ディスプレイスメント）マップを生成します。デフォルト: False。 | BOOLEAN | はい | true<br />false |
| `upscale_factor` | PBR マップをシームレスに SeedVR アップスケーリングします。ベーステクスチャはアップスケーリングされず、4x では 2048 ピクセルのマップが 8K になります。デフォルト: 0（オフ）。 | INT | はい | 0 から 4（ステップ 2） |
| `seed` | 再現可能な生成のためのシード。デフォルト: 42。 | INT | はい | 0 から 2147483646 |
| `tiling_mode` | タイリング方向：全方向、水平、または垂直。詳細設定。デフォルト: `"both"`。 | COMBO | はい | `"both"`<br />`"horizontal"`<br />`"vertical"` |
| `num_inference_steps` | テクスチャ生成のデノイジングステップ数。詳細設定。デフォルト: 8。 | INT | はい | 1 から 8 |
| `tile_size` | 潜在空間でのタイルサイズ。64 は 512 ピクセル、128 は 1024 ピクセルを意味します。詳細設定。デフォルト: 128。 | INT | はい | 32 から 256（ステップ 2） |
| `tile_stride` | 潜在空間でのタイルストライド。詳細設定。デフォルト: 64。 | INT | はい | 16 から 128（ステップ 2） |
| `image` | オプションのソース画像。単独では image-to-image を実行し、マスクと組み合わせると inpaint パスを実行します。 | IMAGE | いいえ | - |
| `mask` | オプションの inpaint マスク。入力画像が必要です。白い領域は再生成され、黒い領域は保持されます。 | MASK | いいえ | - |
| `strength` | 入力画像をどの程度変換するか。画像が接続されている場合にのみ使用されます。詳細設定。デフォルト: 0.6。 | FLOAT | はい | 0.01 から 1.0（ステップ 0.01） |
| `prompt_expansion` | 言語モデルでプロンプトを拡張し、テクスチャの詳細をより豊かにします。デフォルトではオフです。拡張によりプロンプトが写真として再構成され、metalness マップが薄くなる傾向があるためです。詳細設定。 | BOOLEAN | はい | true<br />false |
| `safety_checker` | リクエストに対してプロバイダーのコンテンツ安全チェックを実行します。詳細設定。デフォルト: False。 | BOOLEAN | はい | true<br />false |

### カスタム画像サイズ入力

これらの入力は、`image_size` が `"custom"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | テクスチャの幅（ピクセル）。デフォルト: 1024。 | INT | はい | 512 から 2048（ステップ 16） |
| `image_size.height` | テクスチャの高さ（ピクセル）。デフォルト: 1024。 | INT | はい | 512 から 2048（ステップ 16） |

**制約と動作：**

* マテリアルマップを 1 つも有効にしないことも可能です。その場合、ノードはベーステクスチャのみを返し、すべてのマップ出力は 1x1 のプレースホルダーのままになります。
* マスクには入力画像が必要です。マスク単体ではエラーが発生します。
* 8K の結果は、単一の 8K 生成によるものではなく、2048 ピクセルのレンダリングのマップを 4x アップスケーリングすることで得られます。
