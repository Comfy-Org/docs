テキスト記述から、完全にシームレスにタイリングするPBRマテリアルを生成します。ベーステクスチャと最大5つのマテリアルマップを出力し、オプションでマップのSeedVRアップスケーリングを行います。入力画像を指定するとimage-to-imageパスとして結果を制御でき、マスク付きの入力画像を指定するとインペイントパスになります。実際のマテリアルをスキャンせずに、ゲーム向けまたは3D向けのサーフェスを生成するために使用できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成するマテリアルまたはテクスチャの説明。 | STRING | はい | 複数行テキスト |
| `image_size` | 出力テクスチャのサイズ。`"custom"` を指定すると `width` と `height` の入力が表示されます。デフォルト: `"1:1 (1024x1024)"`。 | DYNAMIC_COMBO | はい | `"1:1 (1024x1024)"`<br />`"1:1 (512x512)"`<br />`"4:3 (1024x768)"`<br />`"3:4 (768x1024)"`<br />`"16:9 (1024x576)"`<br />`"9:16 (576x1024)"`<br />`"custom"` |
| `basecolor` | basecolor（アルベド）マップを生成します。デフォルト: True。 | BOOLEAN | はい | true<br />false |
| `normal` | ノーマルマップを生成します。デフォルト: True。 | BOOLEAN | はい | true<br />false |
| `roughness` | ラフネスマップを生成します。デフォルト: False。 | BOOLEAN | はい | true<br />false |
| `metalness` | メタルネスマップを生成します。デフォルト: False。 | BOOLEAN | はい | true<br />false |

| `tiling_mode` | タイリング方向: omnidirectional、horizontal、vertical。詳細設定。デフォルト: `"both"`。 | COMBO | はい | `"both"`<br />`"horizontal"`<br />`"vertical"` |
| `num_inference_steps` | テクスチャ生成のデノイジングステップ数。詳細設定。デフォルト: 8。 | INT | はい | 1 〜 8 |
| `tile_size` | 潜在空間におけるタイルサイズ。64は512ピクセル、128は1024ピクセルを意味します。詳細設定。デフォルト: 128。 | INT | はい | 32 〜 256 （ステップ 2） |
| `tile_stride` | 潜在空間におけるタイルストライド。詳細設定。デフォルト: 64。 | INT | はい | 16 〜 128 （ステップ 2） |
| `image` | オプションのソース画像。単独ではimage-to-imageを実行し、マスクと組み合わせるとインペイントパスを実行します。 | IMAGE | いいえ | - |
| `mask` | オプションのインペイントマスク。入力画像が必要です。白い領域は再生成され、黒い領域は保持されます。 | MASK | いいえ | - |
| `strength` | 入力画像をどの程度変換するか。画像が接続されている場合にのみ使用されます。詳細設定。デフォルト: 0.6。 | FLOAT | はい | 0.01 〜 1.0 （ステップ 0.01） |

| `safety_checker` | リクエストに対してプロバイダーのコンテンツ安全性チェックを実行します。詳細設定。デフォルト: False。 | BOOLEAN | はい | true<br />false |

### カスタム画像サイズ入力

これらの入力は、`image_size` が `"custom"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | テクスチャの幅（ピクセル）。デフォルト: 1024。 | INT | はい | 512 〜 2048 （ステップ 16） |
| `image_size.height` | テクスチャの高さ（ピクセル）。デフォルト: 1024。 | INT | はい | 512 〜 2048 （ステップ 16） |

**制約と動作:**

* 少なくとも1つのマテリアルマップを有効にする必要があります。そうでない場合、実行は失敗します。
* マスクには入力画像が必要です。マスク単独ではエラーが発生します。
* 8Kの結果は、2048ピクセルのレンダリングのマップを4倍にアップスケーリングしたものであり、単一の8K生成によるものではありません。
