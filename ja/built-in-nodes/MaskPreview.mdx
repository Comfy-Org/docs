MaskPreview ノードは、マスクデータのビジュアルプレビューを ComfyUI インターフェース内に直接表示します。出力ディレクトリには保存しません。これにより、ワークフロー内の任意の時点でマスクを確認できます。また、マスクはノードをそのまま通過するため、ダウンストリームで引き続き使用できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mask` | プレビューするマスクデータ | MASK | はい | - |
| `filename_prefix` | プレビューに使用するファイル名のプレフィックス（デフォルト："ComfyUI"） | STRING | いいえ | - |
| `prompt` | メタデータ用のプロンプト情報（自動的に提供されます） | PROMPT | いいえ | - |
| `extra_pnginfo` | メタデータ用の追加 PNG 情報（自動的に提供されます） | EXTRA_PNGINFO | いいえ | - |

接続する必要がある表示可能な入力は `mask` のみです。`filename_prefix`、`prompt`、`extra_pnginfo` パラメータはシステムによって提供されます。`filename_prefix` はデフォルト値にフォールバックし、`prompt` と `extra_pnginfo` は非表示で、ComfyUI ランタイムによって自動的に提供されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `mask` | プレビューされたのと同じマスクデータです。ワークフロー内の他の場所で使用できるように、変更されずに返されます | MASK |
