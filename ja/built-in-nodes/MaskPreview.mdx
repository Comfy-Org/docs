MaskPreview ノードは、マスクデータを出力ディレクトリに保存せず、ComfyUI インターフェース上に直接視覚的なプレビューを表示します。これにより、ワークフローの任意の時点でマスクを確認できます。また、マスクはノードをそのまま通過するため、後続の処理でも引き続き使用できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mask` | プレビューするマスクデータ | MASK | はい | - |
| `filename_prefix` | プレビューに使用されるファイル名プレフィックス（デフォルト： "ComfyUI"） | STRING | いいえ | - |
| `prompt` | メタデータ用のプロンプト情報（自動的に提供されます） | PROMPT | いいえ | - |
| `extra_pnginfo` | メタデータ用の追加PNG情報（自動的に提供されます） | EXTRA_PNGINFO | いいえ | - |

接続が必要な可視の入力は `mask` のみです。`filename_prefix`、`prompt`、`extra_pnginfo` の各パラメータはシステムによって提供されます。`filename_prefix` はデフォルト値にフォールバックし、`prompt` と `extra_pnginfo` は非表示であり、ComfyUI ランタイムによって自動的に提供されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `mask` | プレビューされたものと同じマスクデータが、変更されずに返されます。ワークフローの他の場所で使用できます。 | MASK |
