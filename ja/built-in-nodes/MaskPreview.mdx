MaskPreview ノードは、マスクデータの視覚的なプレビューを出力ディレクトリに保存せずに、ComfyUI インターフェースに直接表示します。これにより、ワークフローの任意の時点で正確なマスク値を確認できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mask` | プレビューするマスクデータ | MASK | はい | - |
| `filename_prefix` | プレビューファイル名のプレフィックス（デフォルト："ComfyUI"） | STRING | いいえ | - |
| `prompt` | メタデータ用のプロンプト情報（自動的に提供されます） | PROMPT | いいえ | - |
| `extra_pnginfo` | メタデータ用の追加PNG情報（自動的に提供されます） | EXTRA_PNGINFO | いいえ | - |

`prompt` と `extra_pnginfo` の入力は非表示であり、ComfyUI システムによって自動的に供給されます。手動で接続する必要はありません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `mask` | プレビューされたマスクデータ。ワークフローでさらに使用するために変更されずに返されます | MASK |
