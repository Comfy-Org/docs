このノードは、MiniMax H3 768Pのビデオ出力を2K解像度で再レンダリングします。ソース動画とその生成に使用された正確なプロンプトをアップロードし、MiniMax H3の再生成ジョブを開始して、再レンダリングされた2K動画を返します。元の生成で最初または最後のフレーム、または参照メディアを使用した場合は、同じ入力を添付してください。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 動画の再生成に使用するモデル。このモデルを選択すると、以下に記載されているプロンプト、解像度、および参照メディアの設定が表示されます。 | COMBO | 必須 | "MiniMax H3" |
| `prompt` | ソース動画の生成に使用した正確なプロンプト。空にすることはできません。 | STRING | 必須 | Text |
| `resolution` | ソース動画を再レンダリングする解像度。 | COMBO | 必須 | "2K" |
| `reference_images` | 元の生成で使用した参照画像。同じ順序で指定します。最大9枚。 | IMAGE | 任意 | 0-9 images |
| `reference_videos` | 元の生成で使用した参照動画。同じ順序で指定します。最大3本、各2〜15秒、合計15秒まで。 | VIDEO | 任意 | 0-3 videos |
| `reference_audios` | 元の生成で使用した参照オーディオ。同じ順序で指定します。最大3クリップ、各2〜15秒、合計15秒まで。参照画像または参照動画がない場合は使用できません。 | AUDIO | 任意 | 0-3 clips |
| `video` | 再レンダリングするMiniMax H3 768Pの出力動画。MiniMax H3ビデオノードの未変更の出力（24 FPS、4〜15秒）を接続してください。2K出力は使用できません。 | VIDEO | 必須 | 24 FPS, 4-15 seconds |
| `first_frame` | 元の生成で使用した場合の最初のフレーム画像。 | IMAGE | 任意 | Image |
| `last_frame` | 元の生成で使用した場合の最後のフレーム画像。 | IMAGE | 任意 | Image |
| `watermark` | 動画にAIGC透かしを追加するかどうか。デフォルトはfalseです。 | BOOLEAN | 必須 | false / true |

### 制約

- ソースの`video`は、未変更のMiniMax H3 768P出力である必要があります。幅と高さが32で割り切れ、総ピクセル数が最大1,032,192、24 FPS、フレーム数が17刻みで107〜362（24 FPSで4〜15秒）である必要があります。2K出力はソースとして使用できません。
- `first_frame` / `last_frame`と参照メディア（`reference_images`、`reference_videos`、`reference_audios`）は相互に排他的です。画像から動画へのプロンプトにはフレームを使用し、参照から動画へのプロンプトには参照メディアを使用します。
- `reference_audios`を使用するには、`reference_images`または`reference_videos`の入力が少なくとも1つ必要です。
- `reference_images`: 各画像のアスペクト比は0.4〜2.5の間で、256x256ピクセル以上である必要があります。
- `reference_videos`: 各動画は23.976〜60 FPSで、長さが2〜15秒である必要があります。合計時間は15秒を超えることはできません。
- `reference_audios`: 各クリップは2〜15秒の長さである必要があります。合計時間は15秒を超えることはできません。
