このノードは、Z-Image Turbo モデルを使用してテキストプロンプトから画像を生成します。生成はわずか8ステップで完了します。生成は Comfy Cloud の GPU 上でリモート実行され、実行時間に応じて課金されるため、画像アイデアを試行錯誤するための、ここで最も迅速かつ低コストな選択肢の1つです。生成が完了すると、ノードは完成した画像をダウンロードし、ワークフローで使用できるようにします。このノードは Comfy Cloud ノードセットの一部であり、BETA とマークされています。オプションは追加または削除される可能性があり、ワークフローが廃止される場合があります。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 生成する画像を説明するテキストプロンプト。複数行入力を受け付け、送信前にトリミングされます。トリミング後に空であってはなりません。デフォルト: ""（空）。 | STRING | はい | 1 - 4096 characters |
| `シード` | 生成の再現性を制御するために使用されるランダムシード。変更すると異なるバリエーションが生成されます。生成後の制御オプションが含まれます。デフォルト: 42。 | INT | いいえ | 0 - 18446744073709551615 |
| `aspect_ratio` | 生成される画像のアスペクト比。デフォルト: "1:1"。 | COMBO | いいえ | "1:1"<br />"3:4"<br />"2:3"<br />"3:2"<br />"4:3"<br />"16:9"<br />"9:16"<br />"21:9" |
| `megapixels` | 総ピクセル予算。正方形比率では、1.0 は約 1024x1024 です。デフォルト: 1.0。 | FLOAT | いいえ | 0.1 - 16.0<br />(step of 0.1) |

注: 入力値は生成が送信される前に検証されます。`prompt` は空白をトリミングした後に1～4,096文字である必要があり、`aspect_ratio` は一覧にあるオプションのいずれかである必要があり、`megapixels` は0.1刻みで入力する必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | 生成された画像は画像テンソルとして返され、さらなる画像処理ノードや保存ノードで使用できます。 | IMAGE |
