ConditioningSetAreaPercentageVideo ノードは、ビデオ生成用に特定の領域と時間的範囲を定義することで、conditioning データを変更します。全体の寸法に対するパーセント値を使用して、conditioning が適用される領域の位置、サイズ、および時間的な長さを設定します。これは、ビデオシーケンスの特定の部分に生成を集中させる場合に役立ちます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `条件設定` | 変更する conditioning データ | CONDITIONING | はい | - |
| `幅` | 全体の幅に対する領域の幅（パーセント値、デフォルト: 1.0） | FLOAT | はい | 0.0 - 1.0 (step 0.01) |
| `高さ` | 全体の高さに対する領域の高さ（パーセント値、デフォルト: 1.0） | FLOAT | はい | 0.0 - 1.0 (step 0.01) |
| `時間的` | ビデオ全体の長さに対する領域の時間的な長さ（パーセント値、デフォルト: 1.0） | FLOAT | はい | 0.0 - 1.0 (step 0.01) |
| `x` | 領域の水平方向の開始位置（パーセント値、デフォルト: 0.0） | FLOAT | はい | 0.0 - 1.0 (step 0.01) |
| `y` | 領域の垂直方向の開始位置（パーセント値、デフォルト: 0.0） | FLOAT | はい | 0.0 - 1.0 (step 0.01) |
| `z` | ビデオのタイムラインに対する領域の時間的な開始位置（パーセント値、デフォルト: 0.0） | FLOAT | はい | 0.0 - 1.0 (step 0.01) |
| `強度` | 定義された領域内の conditioning に適用される強度の乗数（デフォルト: 1.0） | FLOAT | はい | 0.0 - 10.0 (step 0.01) |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `conditioning` | 指定された領域と強度設定が適用された、変更後の conditioning データ | CONDITIONING |
