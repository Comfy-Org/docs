Tripo: Retopology は、以前の Tripo ノードで生成された高ポリゴン3Dモデルを受け取り、クリーンなトポロジーを持つ低ポリゴン版として再構築します。モデルを Tripo リトポロジーサービスに送信し、タスクの完了を待ってから、完成したモデルをダウンロードし、他の Tripo ノードで使用できるようにタスク ID を公開します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | ソース高ポリゴンモデルのタスク ID。Tripo 生成ノードのモデルタスク ID、または Tripo: Segment Model のセグメントタスク ID を受け付けます。 | STRING | はい | Tripo task ID |
| `face_limit` | 目標面数: 500～20,000 三角形、または 500～10,000 四角形。-1 の場合、Tripo が選択します。（デフォルト: -1） | INT | はい | -1 (automatic)<br />500 〜 20,000 (triangles)<br />500 〜 10,000 (quads) |
| `quad` | 四角形メッシュ出力。Tripo は四角形メッシュを FBX として提供するため、結果は FBX 出力に到着し、GLB 出力は空のままです。（デフォルト: False） | BOOLEAN | はい | True<br />False (default) |
| `bake` | ソーステクスチャを低ポリゴンメッシュにベイクします。（デフォルト: True） | BOOLEAN | いいえ | True (default)<br />False |
| `part_names` | Tripo: Segment Model からのカンマ区切りのパーツ名。空の場合はモデル全体を処理します。（デフォルト: ""） | STRING | いいえ | Model part names or empty |

注: `face_limit` が -1 に設定されている場合、Tripo が面数を自動的に決定します。`quad` が有効な場合、最大面数は 20,000 三角形ではなく 10,000 四角形となり、結果は FBX として提供されます（GLB 出力は空のままです）。`part_names` が空の場合、モデル全体が処理されます。`face_limit` が -1 以外で、許容範囲外の場合は、ノードがエラーを発生させます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_file` | 完了したモデルファイルを識別する後方互換用の出力です。新しいワークフローでは、代わりに GLB または FBX 出力を使用してください。 | STRING |
| `model task_id` | 完了したリトポロジー結果のタスク ID。他の Tripo ノードに渡して、このモデルを参照できます。 | STRING |
| `GLB` | リトポロジーされた低ポリゴンモデル（GLB 形式）。`quad` が有効な場合は空です。 | GLB FILE |
| `FBX` | リトポロジーされた低ポリゴンモデル（FBX 形式）。`quad` が有効な場合にのみ設定されます。 | FBX FILE |
