音声クローニングとリップシンクを使用して、音声付きの動画を別の言語に翻訳します。このノードは、元の話者の声をクローンし、翻訳された音声に合わせて口の動きを再アニメーション化することで、自然な見た目の結果を生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|------|----------|------|------|
| `ビデオ` | 翻訳する音声を含む動画です。 | VIDEO | はい | - |
| `出力言語` | 翻訳された動画のターゲット言語です。 | STRING | はい | "Arabic"<br />"Bengali"<br />"Chinese"<br />"Danish"<br />"Dutch"<br />"English"<br />"French"<br />"German"<br />"Greek"<br />"Hindi"<br />"Indonesian"<br />"Italian"<br />"Japanese"<br />"Korean"<br />"Malay"<br />"Polish"<br />"Portuguese"<br />"Russian"<br />"Spanish"<br />"Swedish"<br />"Tamil"<br />"Telugu"<br />"Thai"<br />"Turkish"<br />"Ukrainian"<br />"Vietnamese" |
| `モード` | 'speed' はより高速で、'precision' は2倍のコストでより高品質なリップシンクを生成します。(デフォルト: "speed") | STRING | はい | "speed"<br />"precision" |
| `音声のみ翻訳` | 音声トラックのみを交換し、元の口の動きを維持します（リップシンクなし）。(デフォルト: False) | BOOLEAN | いいえ | True<br />False |
| `話者数` | 動画内の話者の数です。0 は自動検出を意味します。0 より大きい値は話者数として API に送信されます。(デフォルト: 0) | INT | いいえ | 0 to 10 |
| `シード` | HeyGen には送信されません。変更すると再実行が強制されます。(デフォルト: 42) | INT | いいえ | 0 to 2147483647 |

## 出力

| 出力名 | 説明 | データ型 |
|--------|------|----------|
| `ビデオ` | 音声クローニングとリップシンクが適用された翻訳済み動画です。 | VIDEO |
