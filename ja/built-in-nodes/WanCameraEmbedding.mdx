このノードは、選択したカメラパスに対して Plücker 埋め込みを使用してカメラ軌道埋め込みを生成します。パン、ズーム、回転などの動きをシミュレートするカメラポーズのシーケンスを構築し、それらを動画生成パイプラインで使用できる埋め込みテンソルに変換します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `カメラポーズ` | シミュレートするカメラ移動の種類（デフォルト: "Static"） | COMBO | はい | "Static"<br />"Pan Up"<br />"Pan Down"<br />"Pan Left"<br />"Pan Right"<br />"Zoom In"<br />"Zoom Out"<br />"Anti Clockwise (ACW)"<br />"ClockWise (CW)" |
| `幅` | 出力の幅（ピクセル単位、デフォルト: 832、ステップ: 16） | INT | はい | 16 to MAX_RESOLUTION |
| `高さ` | 出力の高さ（ピクセル単位、デフォルト: 480、ステップ: 16） | INT | はい | 16 to MAX_RESOLUTION |
| `長さ` | カメラ軌道シーケンスの長さ（デフォルト: 81、ステップ: 4） | INT | はい | 1 to MAX_RESOLUTION |
| `速度` | カメラ移動の速度（デフォルト: 1.0、ステップ: 0.1） | FLOAT | いいえ | 0.0 〜 10.0 |
| `fx` | 焦点距離 x パラメータ（デフォルト: 0.5、ステップ: 0.000000001） | FLOAT | いいえ | 0.0 〜 1.0 |
| `fy` | 焦点距離 y パラメータ（デフォルト: 0.5、ステップ: 0.000000001） | FLOAT | いいえ | 0.0 〜 1.0 |
| `cx` | 主点 x 座標（デフォルト: 0.5、ステップ: 0.01） | FLOAT | いいえ | 0.0 〜 1.0 |
| `cy` | 主点 y 座標（デフォルト: 0.5、ステップ: 0.01） | FLOAT | いいえ | 0.0 〜 1.0 |

注: `fx`、`fy`、`cx`、`cy` は高度なカメラ内部パラメータです。`speed` パラメータは、選択したカメラモーションの回転角度と並進距離をスケーリングします。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `camera_embedding` | 軌道シーケンスを含む、生成されたカメラ埋め込みテンソル | TENSOR |
| `width` | 処理に使用された幅の値 | INT |
| `height` | 処理に使用された高さの値 | INT |
| `length` | 処理に使用された長さの値 | INT |
