Flux 3 Image は、プロンプトから FLUX 3 で画像を生成するか、参照画像を編集および結合します。指示として生成したい内容を記述し、最大10枚の参照画像を接続して、プロンプト内で image 1、image 2 などとして参照してください。プロンプトは生成前に解釈および拡張され、結果は選択したアスペクト比と解像度でレンダリングされます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成する内容、または実行する編集。プロンプトは生成前に解釈および拡張されます。接続した参照画像は image 1、image 2 などとして参照してください。（デフォルト: ""） | STRING | はい | 1～15000文字 |
| `images` | 参照画像用の追加可能なスロット。合計最大10枚まで接続できます。各画像は少なくとも256x256ピクセルである必要があり、アスペクト比は64:1より極端にすることはできません。 | IMAGE | いいえ | 0～10画像 |
| `bounding_boxes` | Create Bounding Boxes ノードから得られる任意のボックスで、出力内にオブジェクトやテキストを配置します。位置はキャンバスを基準とするため、ノードに出力のアスペクト比を指定してください。 | ARRAY | いいえ | - |
| `aspect_ratio` | 生成画像のアスペクト比。"auto" は最初の参照画像に従うか、プロンプトから比率を選択します。（デフォルト: "auto"） | COMBO | はい | `"auto"`<br />`"21:9"`<br />`"2:1"`<br />`"16:9"`<br />`"3:2"`<br />`"7:5"`<br />`"4:3"`<br />`"5:4"`<br />`"1:1"`<br />`"4:5"`<br />`"3:4"`<br />`"5:7"`<br />`"2:3"`<br />`"9:16"`<br />`"1:2"`<br />`"9:21"` |
| `resolution` | 選択したアスペクト比での出力サイズ: 0.75K は約0.6メガピクセル、1K は1 MP、1.5K は2.4 MP、2K は4.2 MP、4K は16.8 MPです。（デフォルト: "2K"） | COMBO | はい | `"0.75K"`<br />`"1K"`<br />`"1.5K"`<br />`"2K"`<br />`"4K"` |
| `grounding` | 生成前に、モデルがウェブ検索と画像検索でプロンプトを調査できるようにします。（デフォルト: True） | BOOLEAN | はい | True<br />False |
| `safety_tolerance` | モデレーション許容度。0が最も厳格です。（デフォルト: 4） | INT | はい | 0～4 |
| `seed` | ノードを再実行すべきか判断するためのシード。FLUX 3 は独自のシードを選択するため、この値に関係なく実際の結果は非決定的です。（デフォルト: 42） | INT | はい | 0～4294967295 |

`safety_tolerance` は詳細入力であり、`seed` には UI で Control After Generate コントロールが含まれます。

参照画像はリクエストが送信される前にアップロードされます。1つのスロットでバッチを保持でき、各バッチのすべてのフレームが10枚の画像制限にカウントされます。

`bounding_boxes` の行はプロンプトに追加されるため、プロンプトとボックスの説明を合わせて15000文字以下にする必要があります。

表示価格は `resolution` によって異なります: 0.75K で $0.05863、1K で $0.06864、1.5K で $0.1001、2K で $0.143、4K で $0.86801。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | FLUX 3 の結果からダウンロードされた生成画像。 | IMAGE |
