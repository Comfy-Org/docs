MOSS-Image が読み取るレイアウトプロンプトを構築します。Create Bounding Boxes ノードで描画された要素を受け取り、ボックスごとに1つのエントリを持つ JSON レイアウトを出力します。各エントリには、ラベル、キャプション、およびターゲットキャンバスのピクセル空間における矩形が含まれます。`width` と `height` を生成予定の画像サイズに設定し、出力をテキストエンコーダーのプロンプト入力に接続します。要素が接続されていない場合、プロンプトテキストは変更されずに返されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `prompt` | 画像全体の説明。レイアウトのキャプションになります。 | STRING | はい | - |
| `element` | 配置する要素。Create Bounding Boxes ノードから取得します。各ボックスはそのキャプションを提供し、テキストボックスはそのテキストも提供し、カラーパレットを持つボックスはそれを保持します。 | ARRAY | はい | - |
| `width` | 生成画像の幅（ピクセル単位）。ボックスはこのピクセルグリッドに変換されるため、生成予定の画像サイズを使用してください（デフォルト: 1024）。 | INT | はい | 16 〜 16384 （ステップ 16） |
| `height` | 生成画像の高さ（ピクセル単位）。ボックスはこのピクセルグリッドに変換されるため、生成予定の画像サイズを使用してください（デフォルト: 1024）。 | INT | はい | 16 〜 16384 （ステップ 16） |
| `character_boxes` | オブジェクトではなくキャラクターとしてラベル付けするボックスの番号。Create Bounding Boxes のプレビューでタグ付けされたものに対応します（例: "1, 3"）。文字列内のすべての数値が読み取られるため、任意の区切り文字を使用できます（デフォルト: 空）。 | STRING | はい | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `prompt` | レイアウトプロンプト。キャプション、ボックスごとのエントリ、およびボックス座標形式を保持する JSON オブジェクトです。要素が接続されていない場合は、入力テキストがそのまま渡されます。 | STRING |

## 注意

ボックスの矩形は、Create Bounding Boxes から 0～1000 の正規化座標として渡され、レイアウトにはキャンバス中心を基準としたピクセル単位で、`yxyx` の順序で書き込まれます。したがって、`width` と `height` の値は生成する画像と一致している必要があり、そうでない場合、ボックスは正しくない位置に配置されます。

テキストを保持するボックスは常にテキストとしてラベル付けされ、番号が `character_boxes` に記載されているボックスはキャラクターとしてラベル付けされ、その他のすべてのボックスはオブジェクトとしてラベル付けされます。
