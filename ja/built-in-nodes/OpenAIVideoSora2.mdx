OpenAIVideoSora2 ノードは、OpenAI の Sora モデルを使用して動画を生成します。テキストプロンプトと、オプションの入力参照画像に基づいて動画コンテンツを作成し、生成された動画を出力として提供します。このノードは、選択したモデルに応じて異なる動画の長さと解像度をサポートしています。

**非推奨のお知らせ:** OpenAI は 2026 年 9 月に Sora v2 API の提供を終了します。その時点で、このノードは ComfyUI から削除されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | 動画生成に使用する OpenAI Sora モデル（デフォルト: "sora-2"） | COMBO | はい | "sora-2"<br />"sora-2-pro" |
| `プロンプト` | 動画生成をガイドするテキスト。入力画像がある場合は空でも構いません（デフォルト: 空） | STRING | はい | - |
| `サイズ` | 生成される動画の解像度（デフォルト: "1280x720"） | COMBO | はい | "720x1280"<br />"1280x720"<br />"1024x1792"<br />"1792x1024" |
| `長さ` | 生成される動画の秒数（デフォルト: 8） | COMBO | はい | 4<br />8<br />12 |
| `画像` | 動画生成に使用されるオプションの入力参照画像（フィット、キャラクター、シーン参照など）。対応しているのは単一の画像のみです | IMAGE | いいえ | - |
| `シード` | ノードを再実行するかどうかを決定するシード。実際の結果は、シードの値に関係なく非決定的です（デフォルト: 0） | INT | いいえ | 0 から 2147483647 |

**制約と制限事項:**

- "sora-2" モデルは "720x1280" と "1280x720" の解像度のみをサポートしています。"1024x1792" と "1792x1024" のオプションは "sora-2-pro" モデルでのみ有効です
- 画像を接続する場合、画像は正確に1枚である必要があります。複数の画像を接続するとエラーが発生します
- 結果はシード値に関係なく非決定的です

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | OpenAI Sora によって生成された動画ファイル | VIDEO |
