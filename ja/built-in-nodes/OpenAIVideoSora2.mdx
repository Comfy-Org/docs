OpenAIVideoSora2 ノードは、OpenAI の Sora モデルを使用して動画を生成します。テキストプロンプトと、任意で 1 枚の参照画像を受け取り、リクエストを OpenAI に送信し、生成の完了を待って、結果の動画を返します。サポートされる再生時間と解像度は、選択したモデルによって異なります。

**非推奨のお知らせ:** OpenAI は 2026 年 9 月に Sora v2 API の提供を終了します。このノードはその時点で ComfyUI から削除されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | 動画生成に使用する OpenAI Sora モデル（デフォルト: "sora-2"） | COMBO | はい | "sora-2"<br />"sora-2-pro" |
| `プロンプト` | ガイド用のテキスト。入力画像がある場合は空でもかまいません（デフォルト: 空文字列） | STRING | はい | - |
| `サイズ` | 生成される動画の解像度（デフォルト: "1280x720"） | COMBO | はい | "720x1280"<br />"1280x720"<br />"1024x1792"<br />"1792x1024" |
| `長さ` | 生成される動画の長さ（秒）（デフォルト: 8） | COMBO | はい | 4<br />8<br />12 |
| `画像` | 動画生成に使用するオプションの入力参照画像。サポートされる画像は 1 枚のみです | IMAGE | いいえ | - |
| `シード` | ノードを再実行するかどうかを決めるシード。実際の結果はシード値に関係なく非決定的です（デフォルト: 0） | INT | いいえ | 0 から 2147483647 |

**制約と制限:**

- "sora-2" モデルは "720x1280" と "1280x720" のサイズのみをサポートします。"sora-2" で "1024x1792" または "1792x1024" を選択するとエラーが発生します。より大きなサイズは "sora-2-pro" でのみ利用できます。
- 画像が接続されている場合、含める画像は正確に 1 枚でなければなりません。複数の画像を接続するとエラーが発生します。
- 結果は `seed` の値に関係なく非決定的です。
- 表示される価格見積もりは、選択した `model`、`size`、`duration` によって異なります。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | OpenAI Sora によって生成された動画 | VIDEO |
