Vidu2 Text-to-Video Generation ノードは、テキスト記述から動画を生成します。外部 API に接続して、プロンプトに基づく動画コンテンツを生成し、動画の長さ、視覚スタイル、フォーマットを制御できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | 動画生成に使用する AI モデルです。現在、利用可能なモデルは 1 つだけです。 | COMBO | はい | `"viduq2"` |
| `prompt` | 動画生成用のテキスト記述です。最大長は 2000 文字です。 | STRING | はい | - |
| `duration` | 生成される動画の長さ（秒単位）です。値はスライダーで調整できます（デフォルト：5）。 | INT | いいえ | 1 〜 10 |
| `seed` | 生成のランダム性を制御するために使用される数値で、再現可能な結果を得られます。生成後にも制御できます（デフォルト：1）。 | INT | いいえ | 0 〜 2147483647 |
| `aspect_ratio` | 動画の幅と高さの比率です。 | COMBO | いいえ | `"16:9"`<br />`"9:16"`<br />`"3:4"`<br />`"4:3"`<br />`"1:1"` |
| `resolution` | 生成される動画のピクセル寸法です。これは詳細設定パラメータです。 | COMBO | いいえ | `"720p"`<br />`"1080p"` |
| `background_music` | 生成された動画に BGM を追加するかどうか（デフォルト：False）。これは詳細設定パラメータです。 | BOOLEAN | いいえ | - |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | 生成された動画ファイルです。 | VIDEO |
