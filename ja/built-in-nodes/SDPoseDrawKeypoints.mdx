SDPoseDrawKeypoints ノードは、ポーズ推定データ（キーポイント）を受け取り、空白のキャンバス上に視覚的なスケルトンとして描画します。このノードを使用すると、身体、頭、手、顔、足など、ポーズの異なる部分を選択的に描画でき、線の太さや点のサイズもカスタマイズできます。生成された画像は、可視化や、ポーズ画像を必要とする他のノードへの入力として使用できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `キーポイント` | 描画するポーズのキーポイントデータです。このデータは通常、ポーズ検出ノードから取得され、1つ以上のフレームを含むことができます。 | POSE_KEYPOINT | はい | - |
| `ボディを描画` | メインの身体スケルトンを描画するかどうかを制御します（デフォルト: True）。 | BOOLEAN | いいえ | - |
| `手を描画` | 手のキーポイントを描画するかどうかを制御します（デフォルト: True）。 | BOOLEAN | いいえ | - |
| `顔を描画` | 顔のキーポイントを描画するかどうかを制御します（デフォルト: True）。 | BOOLEAN | いいえ | - |
| `足を描画` | 足のキーポイントを描画するかどうかを制御します（デフォルト: False）。 | BOOLEAN | いいえ | - |
| `スティック幅` | 身体と頭のスケルトンを描画するために使用される線の太さ（デフォルト: 4）。 | INT | いいえ | 1〜10 |
| `顔ポイントサイズ` | 顔のキーポイントを描画するための点のサイズ（デフォルト: 3）。 | INT | いいえ | 1〜10 |
| `スコア閾値` | キーポイントが描画されるために必要な最小の信頼度スコアです。この値未満のスコアのキーポイントは無視されます（デフォルト: 0.3）。 | FLOAT | いいえ | 0.0〜1.0 |
| `頭部を描く` | 頭部のキーポイント（鼻、目、耳）を描画するかどうかを制御します（デフォルト: True）。 | BOOLEAN | いいえ | - |

**注記:** `keypoints` 入力が空または `None` の場合、ノードは空白の64x64画像を出力します。

**注記:** `draw_body` と `draw_head` は独立して動作します。`draw_head` が無効の場合、`draw_body` が有効でも頭部のキーポイントは描画されません。`draw_body` が無効で `draw_head` が有効の場合、頭部のキーポイントと首のポイントのみが描画されます。両方とも無効の場合は、身体または頭部のキーポイントは描画されません。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `output` | 描画されたポーズのキーポイントを含む画像です。画像の寸法は、入力キーポイントデータで指定された `canvas_height` と `canvas_width` に一致します。入力に複数のフレームが含まれる場合、画像のバッチが返されます。 | IMAGE |
