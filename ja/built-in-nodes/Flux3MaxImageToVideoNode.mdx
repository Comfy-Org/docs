FLUX 3 Max Image to Video は、FLUX 3 Max を使用して1～10枚の画像をアニメーション化します。各画像はクリップのフレームになります。1枚の画像はクリップの冒頭を開き、2枚の場合は最初と最後のフレームになり、それ以上はクリップ全体に分散されるか、指定した時刻に固定されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | シーンがどのように動き、どのような音になるか（デフォルト：空）。 | STRING | はい | 複数行テキスト |
| `keyframes` | 拡張可能なスロット：再生順に1～10枚のキーフレーム画像を接続します（例：`image_1`、`image_2` など）。各画像はクリップのフレームになります。 | IMAGE | はい | 1～10枚の画像 |
| `placement` | `"spread across the clip"` は最初の画像を冒頭に、最後の画像を末尾に配置し、残りをその間に均等に配置します。`"at times"` は各画像を指定した秒に固定します（デフォルト：`"spread across the clip"`）。 | DYNAMIC_COMBO | はい | `"spread across the clip"`<br />`"at times"` |
| `aspect_ratio` | 出力アスペクト比。`"auto"` は最初のキーフレーム画像に従います（デフォルト：`"auto"`）。 | COMBO | はい | `"auto"`<br />`"21:9"`<br />`"2:1"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"` |
| `duration` | クリップの長さ（秒）（デフォルト：`"5"`）。 | COMBO | はい | `"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"`<br />`"11"`<br />`"12"`<br />`"13"`<br />`"14"`<br />`"15"`<br />`"16"`<br />`"17"`<br />`"18"`<br />`"19"`<br />`"20"` |
| `resolution` | 出力解像度（デフォルト：`"720p"`）。 | COMBO | はい | `"720p"`<br />`"1080p"` |
| `reasoning_level` | 生成前にモデルがプロンプトについてどれだけ推論し、拡張するか。`"high"` は時間がかかりますが、価格は同じです（デフォルト：`"high"`）。 | COMBO | はい | `"low"`<br />`"high"` |
| `generate_audio` | 同期された音声を生成します。オフにすると、音声トラックのないビデオが生成されます（デフォルト：true）。 | BOOLEAN | はい | `true`<br />`false` |
| `seed` | ノードを再実行するかどうかを制御するシード。この値に関係なく、結果は非決定的です（デフォルト：42）。 | INT | はい | 0 〜 2147483646 |

### at times 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `times` | 画像ごとに1つの時刻を秒単位で指定します。カンマ区切りで昇順にします（例："0, 2.5, 5"）。`placement` が `"at times"` の場合にのみ表示されます。 | STRING | いいえ | カンマ区切りの秒数 |

注：`prompt` は少なくとも1文字含む必要があります。`keyframes` は少なくとも1枚の画像を保持する必要があり、10枚を超えることはできません。バッチ入力は画像1枚につき1回として数えられます。

`placement` が `"spread across the clip"` の場合、1枚または2枚の画像は開始画像および任意の終了画像として送信され、3枚以上の場合は24 fpsでクリップ全体に均等に分散されたキーフレームに配置されます。

`placement` が `"at times"` の場合、`times` は画像ごとに1つの値を指定する必要があり、それらの値は増加している必要があります。負の値は使用できず、最後の時刻はクリップの終了時点を超えることはできません。

表示される価格は `resolution` と `duration` に基づきます。720p は 2026年11月7日まで毎秒 $0.060775、1080p は毎秒 $0.103675 で、その日付以降はそれぞれ毎秒 $0.2431 と $0.4147 です。クリップの推定合計コストは UI に表示されます。
