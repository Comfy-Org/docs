このノードでは、Google の Gemini AI モデルと対話してテキスト応答を生成できます。テキスト、画像、音声、動画、ファイルなど複数の種類の入力をコンテキストとして提供し、モデルがより関連性が高く意味のある応答を生成できるようにします。このノードは API 通信と応答の解析をすべて自動で処理します。

**注:** このノードはソースコード上で非推奨としてマークされています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | モデルへのテキスト入力で、応答の生成に使用されます。詳細な指示、質問、またはモデルへのコンテキストを含めることができます。デフォルト: 空文字列。 | STRING | はい | - |
| `モデル` | 応答生成に使用する Gemini モデル。デフォルト: gemini-3-1-pro。 | COMBO | はい | "gemini-2.5-pro"<br />"gemini-2.5-flash"<br />"gemini-3-pro-preview"<br />"gemini-3-1-pro"<br />"gemini-3-1-flash-lite" |
| `シード` | `seed` を特定の値に固定すると、モデルは繰り返しのリクエストに対して同じ応答を提供するよう最善を尽くします。決定論的な出力は保証されません。また、モデルや temperature などのパラメータ設定を変更すると、同じ `seed` 値を使用しても応答が変化する場合があります。デフォルトでは、ランダムな `seed` 値が使用されます。デフォルト: 42。 | INT | はい | 0 から 18446744073709551615 |
| `画像` | モデルのコンテキストとして使用するオプションの画像。複数の画像を含めるには、Batch Images ノードを使用できます。デフォルト: なし。 | IMAGE | いいえ | - |
| `音声` | モデルのコンテキストとして使用するオプションの音声。デフォルト: なし。 | AUDIO | いいえ | - |
| `動画` | モデルのコンテキストとして使用するオプションの動画。デフォルト: なし。 | VIDEO | いいえ | - |
| `ファイル` | モデルのコンテキストとして使用するオプションのファイル。Gemini Generate Content Input Files ノードからの入力を受け付けます。デフォルト: なし。 | GEMINI_INPUT_FILES | いいえ | - |
| `システムプロンプト` | AI の動作を規定する基本的な指示。デフォルト: 空文字列。これは高度なパラメータです。 | STRING | いいえ | - |

接続されたすべての画像はコンテキストとして使用されます。10 枚を超える画像が提供された場合、最初の 10 枚はファイル参照としてアップロードされ、残りの画像は API にインラインで送信されます。

このノードは、リストに記載された選択済みのモデル名をそのまま使用します。一部のエントリは、リクエストが送信される前に、内部的に現在の API モデル識別子へマッピングされます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `STRING` | Gemini モデルによって生成されたテキスト応答。モデルがテキストを生成しない場合、ノードは「Empty response from Gemini model...」を返します。 | STRING |
