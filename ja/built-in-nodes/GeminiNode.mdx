このノードを使用すると、Google の Gemini AI モデルと対話し、テキスト応答を生成できます。テキスト、画像、音声、動画、ファイルなど、複数の種類の入力をモデルのコンテキストとして提供できるため、より関連性が高く有意義な応答を生成できます。このノードは、API 通信と応答の解析をすべて自動的に処理します。

**注:** このノードは、ソースコード内で非推奨としてマークされています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | モデルへのテキスト入力で、応答を生成するために使用します。詳細な指示、質問、またはモデルのコンテキストを含めることができます。デフォルト: 空文字列。 | STRING | はい | - |
| `モデル` | 応答の生成に使用する Gemini モデル。デフォルト: gemini-3-1-pro。 | COMBO | はい | "gemini-2.5-pro"<br />"gemini-2.5-flash"<br />"gemini-3-pro-preview"<br />"gemini-3-1-pro"<br />"gemini-3-1-flash-lite" |
| `シード` | シード値を特定の値に固定すると、モデルは繰り返しのリクエストに対して同じ応答を提供するよう最善を尽くします。ただし、決定的な出力は保証されません。また、モデルや temperature などのパラメータ設定を変更すると、同じシード値を使用しても応答にばらつきが生じることがあります。デフォルトでは、ランダムなシード値が使用されます。デフォルト: 42。 | INT | はい | 0〜18446744073709551615 |
| `画像` | モデルのコンテキストとして使用するオプションの画像。複数の画像を含めるには、Batch Images ノードを使用できます。デフォルト: なし。 | IMAGE | いいえ | - |
| `音声` | モデルのコンテキストとして使用するオプションの音声。デフォルト: なし。 | AUDIO | いいえ | - |
| `動画` | モデルのコンテキストとして使用するオプションの動画。デフォルト: なし。 | VIDEO | いいえ | - |
| `ファイル` | モデルのコンテキストとして使用するオプションのファイル。Gemini Generate Content Input Files ノードからの入力を受け入れます。デフォルト: なし。 | GEMINI_INPUT_FILES | いいえ | - |
| `システムプロンプト` | AI の動作を規定する基本的な指示。デフォルト: 空文字列。これは詳細設定パラメータです。 | STRING | いいえ | - |

接続されているすべての画像がコンテキストとして使用されます。10 枚を超える画像が提供された場合、最初の 10 枚はファイル参照としてアップロードされ、残りの画像はインラインで API に送信されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `STRING` | Gemini モデルによって生成されたテキスト応答。モデルがテキストを生成しなかった場合、ノードは「Empty response from Gemini model...」を返します。 | STRING |
