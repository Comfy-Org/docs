Flux 3 Image to Video は、FLUX 3 を使用して1〜10枚の画像をアニメーション化します。各画像はクリップのフレームになります。1枚の画像でクリップが始まり、2枚の場合は最初の画像から2番目の画像へとモーフィングし、3枚以上の場合はクリップ全体に分散されるか、選択した時刻に固定されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | シーンがどのように動き、音が出るかを指定します。プロンプトは生成前に解釈および展開されます。少なくとも1文字以上含める必要があります。 | STRING | 必須 | 複数行テキスト（デフォルト: 空） |
| `キーフレーム` | 再生順に並べた1〜10枚の画像です。各画像は256×256ピクセル以上である必要があります。グロウアブル入力：`image_1`、`image_2` のように画像を接続します。 | IMAGE | 必須 | 1〜10枚の画像 |
| `配置` | "spread across the clip" を選択すると、FLUX 3 が画像を配置します（1枚の場合はクリップを開始し、2枚の場合は開始と終了になります）。"at times" を選択すると、各画像を選択した秒に固定します。 | DYNAMIC_COMBO | 必須 | `"spread across the clip"`（デフォルト）<br />`"at times"` |
| `times` | 画像ごとに1つの秒数を、カンマ区切りで増加する順に指定します（例: "0, 2.5, 5"）。`placement` が "at times" の場合にのみ表示されます。各キーフレーム画像には1つの時刻が必要です。 | STRING | 任意 | カンマ区切りの秒数（デフォルト: "0"） |
| `アスペクト比` | 出力のアスペクト比です。"auto" はプロンプトと入力からアスペクト比を選択します。 | COMBO | 必須 | `"auto"`（デフォルト）<br />その他の利用可能なアスペクト比 |
| `長さ` | クリップの長さ（秒）です。"auto" はコンテンツに合わせて長さを調整します。 | COMBO | 必須 | `"auto"`（デフォルト）<br />その他の利用可能な長さ |
| `解像度` | 出力の解像度です。 | COMBO | 必須 | `"720p"`（デフォルト）<br />`"1080p"` |
| `音声生成` | 同期されたオーディオ（環境音、音声、効果音）を生成します。オフにすると、オーディオトラックのないビデオが生成されます。 | BOOLEAN | 必須 | true / false（デフォルト: true） |
| `安全許容度` | モデレーションの許容度で、0が最も厳格です。画像またはビデオを送信するリクエストは、ここで設定した値に関係なく2に制限されます。 | INT | 必須 | 0〜4（デフォルト: 2、上級者向け設定） |
| `シード` | ノードを再実行するかどうかを決定するシードです。FLUX 3 は独自のシードを選択するため、実際の結果はこの値に関係なく非決定的です。 | INT | 必須 | 0〜4294967295（デフォルト: 42、control-after-generate） |

注：`keyframes` には少なくとも1枚の画像を含める必要があります。画像が接続されていない場合、ノードはエラーを発生させます。各キーフレーム画像は256×256ピクセル以上である必要があり、アスペクト比は64:1より極端であってはなりません。

`placement` が "spread across the clip" で、3つ以上のキーフレームが接続されている場合、`duration` は "auto" ではなく明示的な値に設定する必要があります。そうしないとノードはエラーを発生させます。

`placement` が "at times" の場合、`times` には画像ごとに1つの秒数を指定する必要があります。時刻は増加し、負の値は指定できず、最後の時刻はクリップの終わりを超えることはできません（`duration` が "auto" の場合、最大20秒です）。

このノードは画像を送信するため、`safety_tolerance` は設定した値に関係なく2に制限されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | 選択したアスペクト比、長さ、解像度、オーディオ設定で、キーフレーム画像から生成されたビデオクリップです。 | VIDEO |
