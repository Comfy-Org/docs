このノードは、完了した Tripo 3D モデルタスクの ID を Tripo API に送信し、そのモデルがリギング可能かどうかを確認します。確認が完了するまで待機し、はい/いいえの結果と、Tripo がそのモデルに推奨する骨格タイプを返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | 分析対象モデルの Tripo タスク ID です。以前に生成、インポート、またはその他の方法で Tripo タスクを通じて作成されたモデルを識別します。 | MODEL_TASK_ID | はい | N/A |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `riggable` | モデルがリギング可能かどうか。 | BOOLEAN |
| `rig_type` | 推奨される骨格: biped、quadruped、hexapod、octopod、avian、serpentine、aquatic。モデルがリギング可能でない場合は 'others'。 | STRING |
