このノードは、開始時間と継続時間を設定して、動画を指定した時間ウィンドウにカットします。要求された継続時間を実現できない場合にエラーを発生させる strict モードも提供します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `video` | トリミングする動画。 | VIDEO | はい | — |
| `trim` | 開始/終了フレームを使用してトリミング ウィンドウを指定します。このウィンドウは、開始時間（動画の先頭からの秒数）と継続時間（秒）に変換されます。開始時間と継続時間の両方が 0 の場合、動画はトリミングされずに返されます。 | VIDEO_EDIT | はい | start_time: >= 0, default 0<br />duration: >= 0, default 0 |
| `strict_duration` | True の場合、指定した継続時間が不可能なときにエラーが発生します。（デフォルト: False） | BOOLEAN | いいえ | true<br />false |

注記: トリミングの継続時間は 0 以上である必要があり、負の値はエラーを発生させます。要求されたトリミング ウィンドウは、ソース動画内に収まる必要があります。トリミングを適用できない場合は、ソースの継続時間、開始時間、およびターゲットの継続時間を報告するエラーが発生します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | トリミングされた動画。トリミング ウィンドウが空（開始時間と継続時間がともに 0）の場合、元の動画が変更されずに返されます。 | VIDEO |
