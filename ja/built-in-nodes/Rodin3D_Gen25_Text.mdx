## 概要

Rodin Gen-2.5 API を使用して、テキストプロンプトから 3D モデルを生成します。生成速度と出力品質のバランスを取るため、異なる品質モード（Fast、Regular、Extreme-High）から選択できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 3D モデル用のテキストプロンプトです。 | STRING | はい | 1～1024 文字 |
| `モード` | 生成品質と速度のモードです。「Fast」は最速で、「Extreme-High」は最も高品質ですが時間がかかります。 | COMBO | はい | `"Fast"`<br />`"Regular"`<br />`"Extreme-High"` |
| `マテリアル` | 生成される 3D モデルのマテリアルスタイルです。 | COMBO | はい | `"PBR"`<br />`"Matte"`<br />`"Shiny"` |
| `ジオメトリファイル形式` | 出力される 3D モデルのファイル形式です。 | COMBO | はい | `"glb"`<br />`"obj"`<br />`"stl"`<br />`"usdz"` |
| `テクスチャモード` | テクスチャ生成モードです。「None」はテクスチャを生成せず、「Generated」は標準テクスチャを生成し、「Generated+HD」は高精細テクスチャを生成します。 | COMBO | はい | `"None"`<br />`"Generated"`<br />`"Generated+HD"` |
| `シード` | 再現性のある結果を得るための乱数シードです。同じ入力で同じシードを使用すると、同じ出力が生成されます。 | INT | はい | 0～2147483647 |
| `T/Aポーズ` | 生成されるモデルに T ポーズ（腕を広げた姿勢）を適用するかどうか。 | BOOLEAN | はい | True または False |
| `高精細テクスチャ` | モデル用の高精細テクスチャを生成するかどうか。 | BOOLEAN | はい | True または False |
| `テクスチャデライト` | モデルにテクスチャ delight（テクスチャ品質の向上）を適用するかどうか。 | BOOLEAN | はい | True または False |
| `HighPackアドオン` | 標準モデルに加えて、高ポリゴンバージョンのモデルを生成するかどうか。 | BOOLEAN | はい | True または False |
| `バウンディングボックス幅` | ワールド単位でのバウンディングボックスの幅です。 | INT | はい | 1～1000 |
| `バウンディングボックス高さ` | ワールド単位でのバウンディングボックスの高さです。 | INT | はい | 1～1000 |
| `バウンディングボックス長さ` | ワールド単位でのバウンディングボックスの長さです。 | INT | はい | 1～1000 |
| `高さ（cm）` | 生成されるモデルの高さ（センチメートル）です。 | INT | はい | 1～300 |

**注:** `prompt` パラメータは 1～1024 文字の長さである必要があります。`seed` パラメータは指定しない場合、デフォルトで 0（ランダム）になります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `モデルファイル` | 指定された形式で生成された 3D モデルファイルです。 | FILE3DANY |
