Qwen Image 3 Text to Image は、Qwen-Image 3.0 モデルを使用して、テキストプロンプトから1枚以上の画像を生成します。モデルを選択してプロンプトを指定すると、ノードは生成された画像をバッチとして返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 使用するモデル（デフォルト: "qwen-image-3.0-pro"）。この複合セレクターでは、プロンプト、ネガティブプロンプト、画像の幅、画像の高さも指定できます。 | DYNAMIC_COMBO | はい | "qwen-image-3.0-pro"<br />"qwen-image-3.0" |
| `n` | 生成する画像の数。バッチとして返されます（デフォルト: 1）。 | INT | いいえ | 1～6 |
| `seed` | 生成に使用するシード（デフォルト: 42）。各生成後に自動更新するように設定できます。 | INT | いいえ | 0～2147483647 |
| `prompt_extend` | AI による支援でプロンプトを強化するかどうか（デフォルト: true）。詳細オプションです。 | BOOLEAN | いいえ | true<br />false |
| `watermark` | 結果に AI 生成のウォーターマークを追加するかどうか（デフォルト: false）。詳細オプションです。 | BOOLEAN | いいえ | true<br />false |

### qwen-image-3.0-pro および qwen-image-3.0 入力

qwen-image-3.0-pro と qwen-image-3.0 で共有されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 画像を説明するプロンプト。英語と中国語をサポートします。少なくとも1文字必要です。 | STRING | はい | 自由テキスト |
| `negative_prompt` | 避ける内容を記述するネガティブプロンプト（デフォルト: ""）。 | STRING | いいえ | 自由テキスト |
| `width` | 総ピクセル面積は512x512から2560x2560の間である必要があります。その範囲内であれば任意のアスペクト比を使用できます。（デフォルト: 1024） | INT | いいえ | 256～2560（ステップ16） |
| `height` | 総ピクセル面積は512x512から2560x2560の間である必要があります。その範囲内であれば任意のアスペクト比を使用できます。（デフォルト: 1024） | INT | いいえ | 256～2560（ステップ16） |

注: `model` 入力は複合セレクターで、サブフィールドとして `model`（モデルID）、`prompt`（必須、少なくとも1文字必要）、`negative_prompt`（オプション）、`width`、`height` があります。`width` と `height` の合計ピクセル面積は262,144ピクセル（512x512）から6,553,600ピクセル（2560x2560）の間である必要があり、アスペクト比は1:8から8:1の範囲に収める必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 生成された画像（1枚または複数）。バッチとして返されます。 | IMAGE |
