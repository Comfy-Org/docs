latent と degrade_sigma の値を CONDITIONING に付加することで、PiD デコードやアップスケーリングに使用できるようにします。これにより、処理前に latent をどの程度劣化させるかを制御できます。

## 入力

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `ポジティブ` | latent と degrade sigma を付加する対象の conditioning データです。 | CONDITIONING | はい | - |
| `latent` | conditioning に付加する latent（VAEEncode または KSampler からの出力）です。 | LATENT | はい | - |
| `latent_format` | latent のフォーマットです。"flux" の場合、Flux1（16チャンネル）と Flux2（128チャンネル）の latent はチャンネル次元から自動検出されます。SD3（16チャンネル）、SDXL（4チャンネル）、QwenImage（16チャンネル）の場合は手動で選択してください（デフォルト: "flux"）。 | COMBO | はい | `"flux"`<br />`"sd3"`<br />`"sdxl"`<br />`"qwenimage"` |
| `degrade_sigma` | 適用する劣化の量です。0 はクリーンな latent を意味します。破損した latent 出力をノイズ除去するには、この値を大きくしてください（デフォルト: 0.0）。 | FLOAT | はい | 0.0 〜 1.0 （ステップ 0.01） |

注: `latent_format` が `"flux"` に設定されている場合、ノードはチャンネル次元から latent の種類を自動検出します。128チャンネルは Flux2 latent として、16チャンネルは Flux1 latent として扱われます。

注: サポートされていない `latent_format` の値はエラーを発生させますが、利用可能なすべてのオプションはこのノードで処理されます。

## 出力

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `CONDITIONING` | latent と degrade sigma の値が付加された元の conditioning データです。 | CONDITIONING |
