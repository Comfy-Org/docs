このノードは、ByteDance の Seedance 2.5 または 2.0 モデルを使用して、テキストプロンプトから動画を生成します。プロンプトを選択したモデルに送信し、動画の処理が完了するまで待機して、生成された動画ファイルを返します。`Seedance 2.5 Draft` モデルを選択すると、代わりに高速な 480p プレビューがレンダリングされます。得られた `draft_task_id` を ByteDance Seedance 2.5 Draft to Final Video ノードに接続すると、1080p の最終動画をレンダリングできます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 動画生成に使用する Seedance モデルです。Seedance 2.5 は最新モデルで、最大 30 秒の動画と mp4 出力をサポートします。Seedance 2.5 Draft は高速な 480p プレビューをレンダリングし、その `draft_task_id` 出力を ByteDance Seedance 2.5 Draft to Final Video ノードで使用すると 1080p の最終動画をレンダリングできます。Seedance 2.0 は最高品質と 4k 向けです。Seedance 2.0 Fast は速度最適化向けです。Seedance 2.0 Mini は最速かつ最低コストの生成向けです。モデルを選択すると、プロンプト、解像度、アスペクト比、長さ、音声生成の追加入力が表示されます。 | DYNAMIC_COMBO | はい | `"Seedance 2.5"`<br />`"Seedance 2.5 Draft"`<br />`"Seedance 2.0"`<br />`"Seedance 2.0 Fast"`<br />`"Seedance 2.0 Mini"` |
| `シード` | ノードを再実行するかどうかを制御します。`seed` の値に関係なく、結果は非決定的です。（デフォルト: 0） | INT | いいえ | 0〜2147483647 |
| `ウォーターマーク` | 動画にウォーターマークを追加するかどうか。（デフォルト: False）これは詳細設定です。 | BOOLEAN | いいえ | True / False |

### Seedance 2.0 Fast および Seedance 2.0 Mini 入力

Seedance 2.0 Fast と Seedance 2.0 Mini で共有されます。両モデルは同じパラメータを公開します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 動画生成用のテキストプロンプトです。 | STRING | はい | — |
| `resolution` | 出力動画の解像度。 | COMBO | はい | `"480p"`<br />`"720p"` |
| `ratio` | 出力動画のアスペクト比。（デフォルト: `"16:9"`） | COMBO | はい | `"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"`<br />`"adaptive"` |
| `duration` | 出力動画の長さ（秒単位）。（デフォルト: 7） | INT | はい | 4〜15 |
| `generate_audio` | 出力動画の音声生成を有効にします。（デフォルト: True） | BOOLEAN | はい | True / False |

**注:** `model` セレクターは動的です。各モデルセクションに表示される入力は、そのモデルを選択したときに表示されます。プロンプトは、空白を除去した後で 1 文字以上である必要があります。解像度と長さの制限は選択したモデルによって異なります。Seedance 2.5 は 480p/720p/1080p と 4～30 秒をサポートし、Seedance 2.0 は 480p/720p/1080p/4k と 4～15 秒をサポートします。また、Seedance 2.0 Fast と Seedance 2.0 Mini は 480p/720p のみ、4～15 秒をサポートします。Seedance 2.5 Draft は 480p のみ、4～30 秒をサポートします。すべての実行はタスク ID を `draft_task_id` として返しますが、ByteDance Seedance 2.5 Draft to Final Video ノードでレンダリングできるのは `Seedance 2.5 Draft` 実行の ID だけです。そのため、他のモデルを使用する場合、この出力は未接続のままにしておく必要があります。そうしないと実行が失敗します。`seed` の値はノードを再実行するかどうかのみを制御し、結果を決定的にするものではありません。
