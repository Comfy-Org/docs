このノードは、ByteDance の Seedance 2.5 または 2.0 モデルを使用して、テキストプロンプトからビデオを生成します。プロンプトを選択したモデルに送信し、ビデオの処理が完了するまで待機して、生成されたビデオファイルを返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | ビデオ生成に使用する Seedance モデル。Seedance 2.5 は最新モデルで、最大30秒のビデオと mp4/mov 出力に対応しています。Seedance 2.0 は最高品質と4k出力向けです。Seedance 2.0 Fast は速度最適化用、Seedance 2.0 Mini は最速・最低コストでの生成用です。モデルを選択すると、プロンプト、解像度、アスペクト比、長さ、音声生成に関する追加入力が表示されます。 | DYNAMIC_COMBO | はい | `"Seedance 2.5"`<br />`"Seedance 2.0"`<br />`"Seedance 2.0 Fast"`<br />`"Seedance 2.0 Mini"` |
| `シード` | ノードを再実行するかどうかを制御します。シード値に関係なく、結果は非決定的です。（デフォルト：0） | INT | いいえ | 0〜2147483647 |
| `ウォーターマーク` | ビデオに透かしを追加するかどうか。（デフォルト：False）これは上級者向けの設定です。 | BOOLEAN | いいえ | True / False |

### Seedance 2.5 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | ビデオ生成用のテキストプロンプト。台詞を二重引用符で囲むと、生成されるダイアログの内容を指定できます。 | STRING | はい | — |
| `resolution` | 出力ビデオの解像度。（デフォルト：`"720p"`） | COMBO | はい | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `ratio` | 出力ビデオのアスペクト比。（デフォルト：`"16:9"`） | COMBO | はい | `"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"`<br />`"adaptive"` |
| `duration` | 出力ビデオの長さ（秒）。（デフォルト：5） | INT | はい | 4〜30 |
| `generate_audio` | 出力ビデオの音声生成を有効にします。（デフォルト：True） | BOOLEAN | はい | True / False |
| `output_format` | 出力ビデオのコンテナ形式。（デフォルト：`"mp4"`） | COMBO | はい | `"mp4"` |

### Seedance 2.0 Fast および Seedance 2.0 Mini 入力

Seedance 2.0 Fast と Seedance 2.0 Mini で共通です。両モデルとも同じパラメータを公開します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | ビデオ生成用のテキストプロンプト。 | STRING | はい | — |
| `resolution` | 出力ビデオの解像度。 | COMBO | はい | `"480p"`<br />`"720p"` |
| `ratio` | 出力ビデオのアスペクト比。（デフォルト：`"16:9"`） | COMBO | はい | `"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"`<br />`"adaptive"` |
| `duration` | 出力ビデオの長さ（秒）。（デフォルト：7） | INT | はい | 4〜15 |
| `generate_audio` | 出力ビデオの音声生成を有効にします。（デフォルト：True） | BOOLEAN | はい | True / False |

**注記：** `model` セレクタは動的です。各モデルセクションに表示される入力は、そのモデルが選択されたときに表示されます。プロンプトは、空白を除去した後に少なくとも1文字以上である必要があります。解像度と長さの制限は選択したモデルによって異なります。Seedance 2.5 は 480p/720p/1080p と 4〜30 秒に対応し、Seedance 2.0 は 480p/720p/1080p/4k と 4〜15 秒に対応し、Seedance 2.0 Fast と Seedance 2.0 Mini は 480p/720p と 4〜15 秒のみに対応します。`seed` 値はノードを再実行するかどうかのみを制御し、結果を決定的にするものではありません。
