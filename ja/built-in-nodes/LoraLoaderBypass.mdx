LoraLoaderBypass ノードは、特殊な「バイパス」モードで LoRA（Low-Rank Adaptation）を拡散モデルと CLIP モデルに適用します。標準の LoRA ローダーとは異なり、この方法はベースモデルの重みを永続的に変更しません。代わりに、モデルの通常のフォワードパスに LoRA の寄与を加算して結果を計算します。これは、トレーニング時や、重みがオフロードされているモデルを扱う場合に役立ちます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | LoRA を適用する拡散モデル。 | MODEL | はい | - |
| `clip` | LoRA を適用する CLIP モデル。 | CLIP | はい | - |
| `lora_name` | LoRA の名前。利用可能な LoRA ファイルは `loras` フォルダーから読み込まれます。 | COMBO | はい | 利用可能な LoRA ファイルのリスト |
| `strength_model` | 拡散モデルをどの程度強く変更するか。この値は負の値にできます（デフォルト: 1.0）。 | FLOAT | はい | -100.0 〜 100.0 （ステップ 0.01） |
| `strength_clip` | CLIP モデルをどの程度強く変更するか。この値は負の値にできます（デフォルト: 1.0）。 | FLOAT | はい | -100.0 〜 100.0 （ステップ 0.01） |

**注意:** `strength_model` と `strength_clip` の両方が 0 に設定されている場合、このノードは元の、変更されていない `model` と `clip` 入力を処理せずに返します。

**注意:** 選択した LoRA ファイルは、最初に読み込まれた後にキャッシュされます。別の `lora_name` が選択された場合にのみ、ディスクから再読み込みされます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `MODEL` | 変更された拡散モデル。 | MODEL |
| `CLIP` | 変更された CLIP モデル。 | CLIP |
