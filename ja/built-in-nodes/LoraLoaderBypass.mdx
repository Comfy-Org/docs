LoraLoaderBypass ノードは、特別な「バイパス」モードで拡散モデルと CLIP モデルに LoRA（低ランク適応）を適用します。標準の LoRA ローダーとは異なり、この方式ではベースモデルの重みを永続的に変更しません。その代わりに、LoRA の効果をモデルの通常のフォワードパスに加算して出力を計算します。これは、トレーニング時や重みがオフロードされたモデルを扱う場合に役立ちます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `model` | LoRA が適用される拡散モデル。 | MODEL | はい | - |
| `clip` | LoRA が適用される CLIP モデル。 | CLIP | はい | - |
| `lora_name` | LoRA の名前。利用可能な LoRA ファイルは `loras` フォルダから読み込まれます。 | COMBO | はい | 利用可能な LoRA ファイルのリスト |
| `strength_model` | 拡散モデルを変更する強さ。この値は負の値にできます（デフォルト：1.0）。 | FLOAT | はい | -100.0〜100.0 (step: 0.01) |
| `strength_clip` | CLIP モデルを変更する強さ。この値は負の値にできます（デフォルト：1.0）。 | FLOAT | はい | -100.0〜100.0 (step: 0.01) |

**注記：** `strength_model` と `strength_clip` の両方が 0 に設定されている場合、ノードは処理を行わずに元の未変更の `model` および `clip` 入力を返します。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `MODEL` | 変更された拡散モデル。 | MODEL |
| `CLIP` | 変更された CLIP モデル。 | CLIP |

**注記：** このノードは実験的機能としてマークされています。
