このノードは、Fish Audio API を使用して、音声録音からプライベートなクローン音声を作成します。1つ以上の音声サンプルを提供すると、ノードはテキスト読み上げにすぐに使用できるカスタム音声を構築します。1〜20件の録音を受け付け、各録音の推奨長さは10〜30秒で、合計の上限は270秒です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `files` | 音声クローン作成用の録音データです。これは拡張可能な入力です。1つ以上の音声アイテム（例：`audio_1`、`audio_2`など）を接続して音声サンプルを提供します。 | AUDIO | はい | 1〜20 recordings |
| `enhance_audio_quality` | トレーニング前に参照音声の品質を向上させます（デフォルト：True）。 | BOOLEAN | はい | True<br />False |

**注記：** すべての参照音声の合計時間は270秒未満である必要があります。合計時間が270秒以上の場合、ノードはエラーを返します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `voice` | 新しく作成されたクローン音声。Fish Audio API から返される一意の音声 ID によって識別されます。この音声はテキスト読み上げに使用できます。 | FISHAUDIO_VOICE |
