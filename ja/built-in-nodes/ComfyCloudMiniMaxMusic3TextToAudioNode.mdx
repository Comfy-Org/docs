Comfy Cloud GPU 上で MiniMax Music 3 ワークフローを実行し、生成された楽曲を返します。プロンプトはスタイル、楽器編成、ムードを指定します。歌詞は説明されるのではなく歌唱され、歌詞が空の場合はトラックはインストゥルメンタルになります。これはベータ版ノードであり、GPU 秒単位で課金されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 楽曲の説明：スタイル、楽器編成、ムード。送信前に先頭と末尾の空白が削除されます。 | STRING | はい | 1～4096文字 |
| `歌詞` | 歌唱する歌詞。インストゥルメンタルにする場合は空のままにします。 | STRING | いいえ | 0～4096文字 |
| `シード` | 生成結果を制御するランダムシード（デフォルト：42）。 | INT | はい | 0～9223372036854775807 |
| `max_duration` | トラックの最大再生時間（秒、デフォルト：120.0）。モデルは曲を予定より早く終了できます。 | FLOAT | はい | 0.04～360.0（ステップ 0.04） |
| `audio_quality` | 出力ビットレート。`"V0"` は可変ビットレートで、3つの中で最高品質です（デフォルト：`"V0"`）。 | COMBO | はい | `"V0"`<br />`"128k"`<br />`"320k"` |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `AUDIO` | 生成された楽曲。 | AUDIO |
