Kling 4.0 モデルで、一連のキーフレームから音声付きの動画を生成します。最初のフレーム、最大 8 個の中間フレーム、最後のフレームが順番に送信され、中間フレームはクリップ全体に均等に配置されます。出力は最初のキーフレームのアスペクト比を引き継ぎます。1 枚の画像をアニメーション化する場合や、一連の重要な瞬間を通してショットを制御する場合に使用します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | モデルセレクター。`"kling-4.0"` は最大 1080p、30 秒までサポートします。`"kling-4.0-flash"` は 720p、20 秒、および単一の最初のフレームに制限されます。モデルを選択すると、その入力項目が以下に表示されます。 | DYNAMIC_COMBO | はい | `"kling-4.0"`<br />`"kling-4.0-flash"` |

### kling-4.0 入力

これらの入力は、`model` が `"kling-4.0"` に設定されている場合に表示されます。フレーム入力のうち少なくとも 1 つを接続する必要があります。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 動画の開始フレーム（任意）。 | IMAGE | いいえ | - |
| `middle_frames` | 最初と最後のフレームの間にあるフレーム用の任意の追加可能スロット（最大 8 個）です。これらはクリップ全体に均等に配置されます。 | AUTOGROW | いいえ | 0～8 枚の画像 |
| `last_frame` | 動画の終了フレーム（任意）。 | IMAGE | いいえ | - |
| `prompt` | モーションの説明（任意）。接続したフレームは、最初のフレーム、中間フレーム、最後のフレームの順に `@Image1`、`@Image2` などのように参照します。デフォルト：空文字列。 | STRING | はい | 複数行テキスト |
| `resolution` | 出力動画の解像度。デフォルト：`"720p"`。 | COMBO | はい | `"720p"`<br />`"1080p"` |
| `duration` | 生成動画の長さ（秒）。デフォルト：5。 | INT | はい | 3～30 |
| `seed` | シードは、ノードを再実行すべきかどうかを制御します。シード値にかかわらず結果は非決定的です。デフォルト：42。 | INT | はい | 0～2147483647 |

### kling-4.0-flash 入力

これらの入力は、`model` が `"kling-4.0-flash"` に設定されている場合に表示されます。Flash は単一の最初のフレームをアニメーション化します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 動画の開始フレーム。 | IMAGE | はい | - |
| `prompt` | モーションの説明（任意）。最初のフレームは `@Image1` として参照します。デフォルト：空文字列。 | STRING | はい | 複数行テキスト |
| `resolution` | 出力動画の解像度。Flash は 720p のみをレンダリングします。デフォルト：`"720p"`。 | COMBO | はい | `"720p"` |
| `duration` | 生成動画の長さ（秒）。デフォルト：5。 | INT | はい | 3～20 |
| `seed` | シードは、ノードを再実行すべきかどうかを制御します。シード値にかかわらず結果は非決定的です。デフォルト：42。 | INT | はい | 0～2147483647 |

**制約と動作：**

* 最初のフレーム、各中間フレーム、最後のフレームを含めて、合計で最大 10 フレームまで接続できます。
* 動画は最初のキーフレームのアスペクト比を引き継ぐため、アスペクト比の入力は不要です。
* 各フレームは少なくとも 300×300 ピクセルで、アスペクト比が 2:5～5:2 の範囲内である必要があります。
* `@ImageN` に言及するプロンプトは、接続されているフレーム数が N 未満の場合にエラーになります。

|-------------|-------------|-----------|
