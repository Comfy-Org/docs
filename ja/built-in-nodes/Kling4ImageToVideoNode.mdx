Kling 4.0 モデルを使用して、一連のキーフレームから音声を含む動画を生成します。最初のフレーム、最大 8 枚の中間フレーム、最後のフレームが順番に送信され、中間フレームはクリップ全体に均等に配置されます。出力は最初のキーフレームのアスペクト比になります。1 枚の画像をアニメーション化したり、一連の重要な瞬間を通じてショットを誘導したりするのに使用します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | モデルセレクター。`"kling-4.0"` は最大 4K HDR および 30 秒をサポートします。`"kling-4.0-flash"` は 720p、20 秒、単一の最初のフレームに制限されます。モデルを選択すると、以下の対応する入力が表示されます。 | DYNAMIC_COMBO | はい | `"kling-4.0"`<br />`"kling-4.0-flash"` |

### kling-4.0 入力

これらの入力は、`model` が `"kling-4.0"` に設定されている場合に表示されます。フレーム入力のうち少なくとも 1 つを接続する必要があります。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 動画の開始フレーム（任意）。 | IMAGE | いいえ | - |
| `middle_frames` | 最初と最後のフレームの間のフレーム用の、最大 8 個まで拡張可能な任意スロットです。クリップ全体に均等に配置されます。 | AUTOGROW | いいえ | 0～8 枚の画像 |
| `last_frame` | 動画の終了フレーム（任意）。 | IMAGE | いいえ | - |
| `prompt` | 動きの説明（任意）。接続されたフレームは、最初のフレーム、中間フレーム、最後のフレームの順に、`@Image1`、`@Image2` などとして参照します。デフォルト：空文字列。 | STRING | はい | 複数行テキスト |
| `resolution` | 出力動画の解像度。名前に `HDR` を含むオプションは HDR 動画を返します。デフォルト：`"720p"`。 | COMBO | はい | `"720p"`<br />`"1080p"`<br />`"4k"`<br />`"1080p HDR"`<br />`"4k HDR"` |
| `duration` | 生成される動画の長さ（秒）。デフォルト：5。 | INT | はい | 3～30 |
| `seed` | シードはノードを再実行するかどうかを制御します。結果はシードに関係なく非決定的です。デフォルト：42。 | INT | はい | 0～2147483647 |

### kling-4.0-flash 入力

これらの入力は、`model` が `"kling-4.0-flash"` に設定されている場合に表示されます。Flash は単一の最初のフレームをアニメーション化します。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 動画の開始フレーム。 | IMAGE | はい | - |
| `prompt` | 動きの説明（任意）。最初のフレームは `@Image1` として参照します。デフォルト：空文字列。 | STRING | はい | 複数行テキスト |
| `resolution` | 出力動画の解像度。Flash は 720p のみをレンダリングします。デフォルト：`"720p"`。 | COMBO | はい | `"720p"` |
| `duration` | 生成される動画の長さ（秒）。デフォルト：5。 | INT | はい | 3～20 |
| `seed` | シードはノードを再実行するかどうかを制御します。結果はシードに関係なく非決定的です。デフォルト：42。 | INT | はい | 0～2147483647 |

**制約と動作：**

* 最初のフレーム、各中間フレーム、最後のフレームを数えて、合計で最大 10 フレームまで接続できます。
* 動画は最初のキーフレームのアスペクト比になるため、アスペクト比の入力は不要です。
* 各フレームは少なくとも 300x300 ピクセルで、アスペクト比が 2:5～5:2 の間である必要があります。
* `@ImageN` に言及するプロンプトは、接続されているフレーム数が N 未満の場合にエラーを発生させます。

|-------------|-------------|-----------|
