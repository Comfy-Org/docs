Kling 4.0 モデルを使用して、一連のキーフレームから音声付きの動画を生成します。最初のフレーム、最大8つの中間フレーム、最後のフレームが順番に送信され、中間フレームはクリップ全体に均等に配置されます。出力は最初のキーフレームのアスペクト比になります。1枚の画像をアニメーション化する場合や、一連の重要な瞬間を通してショットを誘導する場合に使用できます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | モデルセレクターです。`"kling-4.0"` のみ使用できます。これを選択すると、以下の入力が表示されます。 | DYNAMIC_COMBO | はい | `"kling-4.0"` |

### kling-4.0 入力

これらの入力は、`model` が `"kling-4.0"` に設定されている場合に表示されます。少なくとも1つのフレーム入力が接続されている必要があります。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 動画の開始フレーム（任意）です。 | IMAGE | いいえ | - |
| `middle_frames` | 最初のフレームと最後のフレームの間にあるフレーム用の、任意の追加可能なスロットです（最大8個）。これらのフレームはクリップ全体に均等に配置されます。 | AUTOGROW | いいえ | 0 〜 8 枚の画像 |
| `last_frame` | 動画の終了フレーム（任意）です。 | IMAGE | いいえ | - |
| `prompt` | 動きの説明（任意）です。接続されたフレームは、最初のフレーム、中間フレーム、最後のフレームの順に、`@Image1`、`@Image2` などとして参照します。デフォルト: 空文字列。 | STRING | はい | Multiline text |
| `resolution` | 出力動画の解像度です。デフォルト: `"720p"`。 | COMBO | はい | `"720p"`<br />`"1080p"` |
| `duration` | 生成される動画の長さ（秒）です。デフォルト: 5。 | INT | はい | 3 〜 30 |
| `seed` | シードは、ノードを再実行するかどうかを制御します。シードに関係なく、結果は非決定的です。デフォルト: 42。 | INT | はい | 0 〜 2147483647 |

**制約と動作:**

* 最初のフレーム、各中間フレーム、最後のフレームを数えて、合計で最大10フレームまで接続できます。
* 動画は最初のキーフレームのアスペクト比を引き継ぐため、アスペクト比の入力は不要です。
* 各フレームは少なくとも 300x300 ピクセルで、アスペクト比が 2:5 から 5:2 の間である必要があります。
* `@ImageN` に言及するプロンプトは、接続されているフレーム数が N 未満の場合にエラーを発生させます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | 生成された動画です。タスクが完了すると、プロバイダーからダウンロードされます。 | VIDEO |
