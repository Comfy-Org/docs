## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | テクスチャリングジョブに使用するAIモデル。現在利用可能なのは「meshy-7」のみです。 | COMBO | 必須 | `"meshy-7"` |
| `meshy_task_id` | テクスチャリング対象となる、以前作成した3DモデルのタスクID。 | MESHY_TASK_ID | 必須 | — |
| `multiview_images` | 同じオブジェクトの参照ビュー。最初の画像が正面（プライマリ）ビューとして使用され、残りの画像の順序は問いません。Growableスロット：1〜4枚の画像（`image_1` ～ `image_4`）を接続できます。 | IMAGE | 必須 | 1〜4枚 |
| `enable_original_uv` | 新しいUVを生成せず、モデルの元のUVを使用します。有効にすると、Meshyはアップロードされたモデルの既存テクスチャを保持します。モデルに元のUVがない場合、出力品質が低下する可能性があります。（デフォルト: True） | BOOLEAN | 任意 | True / False |
| `pbr` | PBR（物理ベースレンダリング）テクスチャの生成を有効にします。（デフォルト: False） | BOOLEAN | 任意 | True / False |
| `texture_resolution` | ベースカラーテクスチャの解像度。解像度が高いほど、より詳細なサーフェス情報を取得できます。 | COMBO | 必須 | `"2k"`<br />`"4k"`<br />`"8k"` |

**注:** `multiview_images` には1〜4枚の画像を含める必要があります。ノードは実行時にこれを検証し、範囲外の場合はエラーを発生させます。接続された画像に複数の画像が含まれるバッチが含まれている場合、バッチ内の各画像が上限にカウントされます。最初の画像が正面（プライマリ）ビューとして使用され、残りの画像の順序は問いません。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_file` | モデルファイル名。この出力は後方互換性のためにのみ保持されています。 | STRING |
| `meshy_task_id` | テクスチャリングジョブのタスクID。 | MESHY_TASK_ID |
| `GLB` | GLB形式でダウンロードされたテクスチャ付き3Dモデル。 | GLB |
| `FBX` | FBX形式でダウンロードされたテクスチャ付き3Dモデル。 | FBX |
