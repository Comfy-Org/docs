このノードは、ModelPatchLoader で読み込んだ LTX 2.4 デュレーションヘッドを使用して、テキストプロンプトに対する自然なショット時間を予測し、その結果を VAE の 8k+1 フレームグリッドに揃えます。予測結果は、選択したフレームレートと最小・最大時間制限を使用してフレーム数に変換されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | テキスト埋め込みの前処理とデュレーションヘッドの実行に使用されるモデル。 | MODEL | はい | N/A |
| `positive` | デュレーション予測にプロンプトのテキスト埋め込みとメタデータを提供するコンディショニング。 | CONDITIONING | はい | N/A |
| `duration_head` | ModelPatchLoader で読み込まれた LTX 2.4 デュレーションヘッド。LTX デュレーションヘッドである必要があります。 | MODEL_PATCH | はい | N/A |
| `frame_rate` | 秒をフレーム数に変換するために使用するフレームレート（1秒あたりのフレーム数、デフォルト: 24.0）。 | FLOAT | はい | 1.0 〜 120.0 |
| `min_seconds` | 予測結果をフレーム数に変換する際に使用する最小時間（秒、デフォルト: 1.0）。 | FLOAT | はい | 0.5 〜 120.0 |
| `max_seconds` | 予測結果をフレーム数に変換する際に使用する最大時間（秒、デフォルト: 20.0）。 | FLOAT | はい | 0.5 〜 120.0 |

注: `duration_head` 入力は、LTX デュレーションヘッドを含むモデルパッチである必要があります。接続されたモデルパッチが LTX デュレーションヘッドでない場合、ノードは ValueError を発生させます。使用されるのは最初のコンディショニングエントリのみです。`positive` に複数のプロンプトのバッチが含まれる場合、ノードは最初のプロンプトのみを評価します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `num_frames` | 予測された時間をフレーム数に変換し、VAE の 8k+1 フレームグリッドに揃えた値。 | INT |
| `seconds` | 生の（クランプされていない）予測時間。フレームグリッドに揃える前の値。 | FLOAT |
