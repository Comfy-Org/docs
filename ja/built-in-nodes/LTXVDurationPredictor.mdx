このノードは、LTX 2.4 duration headを使用して、プロンプトに対するショットの自然な時間長を予測します。予測された時間長は、指定されたフレームレートと最小/最大時間長の制限を使用して、VAEのフレームグリッドに適合するフレーム数に変換されます。

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | テキスト埋め込みを前処理し、duration headを実行するために使用されるモデル。 | MODEL | はい | N/A |
| `positive` | 時間長予測のために、プロンプトのテキスト埋め込みとメタデータを提供するconditioning。 | CONDITIONING | はい | N/A |
| `duration_head` | ModelPatchLoaderで読み込まれたLTX 2.4 duration head。LTX duration headである必要があります。 | MODEL_PATCH | はい | N/A |
| `frame_rate` | 秒をフレームに変換するために使用される、1秒あたりのフレーム数（デフォルト: 24.0）。 | FLOAT | はい | 1.0 〜 120.0 |
| `min_seconds` | 予測をフレーム数に変換する際に使用される最小時間長（秒）（デフォルト: 1.0）。 | FLOAT | はい | 0.5 〜 120.0 |
| `max_seconds` | 予測をフレーム数に変換する際に使用される最大時間長（秒）（デフォルト: 20.0）。 | FLOAT | はい | 0.5 〜 120.0 |

注：`duration_head`入力は、ModelPatchLoaderで読み込まれたLTX 2.4 duration headである必要があります。接続されたモデルパッチがLTX duration headでない場合、ノードはValueErrorを発生させます。

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `num_frames` | 予測された時間長をフレーム数に変換し、VAEの8k+1フレームグリッドに合わせて調整した値。 | INT |
| `seconds` | 生の（クランプされていない）予測時間長。フレームグリッドに調整する前の値です。 | FLOAT |
