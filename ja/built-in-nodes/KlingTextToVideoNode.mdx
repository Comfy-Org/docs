Kling Text to Video ノードは、Kling 動画生成 API を使用してテキスト記述から動画を生成します。プロンプトと設定（アスペクト比、生成モード、CFG スケール）を API に送信し、生成タスクが完了するまで待機してから、生成された動画をその ID と長さとともに返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | ポジティブテキストプロンプト | STRING | はい | 最大 2500 文字 |
| `ネガティブプロンプト` | ネガティブテキストプロンプト | STRING | いいえ | 最大 2500 文字 |
| `cfg_scale` | 動画がプロンプトにどれだけ忠実に従うかを制御する設定スケール値（デフォルト: 1.0） | FLOAT | いいえ | 0.0～1.0 |
| `アスペクト比` | 動画のアスペクト比設定（デフォルト: "16:9"） | COMBO | いいえ | "16:9"<br />"9:16"<br />"1:1" |
| `モード` | 動画生成に使用する設定。形式: mode / duration / model_name（デフォルト: "pro mode / 5s duration / kling-v2-5-turbo"） | COMBO | いいえ | "pro mode / 5s duration / kling-v2-5-turbo"<br />"pro mode / 10s duration / kling-v2-5-turbo" |

注: `prompt` パラメータは必須で、空にできません。`prompt` と `negative_prompt` はどちらも最大 2500 文字に制限されています。10 秒の `mode` オプションは 5 秒のオプションよりコストが高くなります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された動画出力 | VIDEO |
| `video_id` | 生成された動画の一意の識別子 | STRING |
| `duration` | 生成された動画の長さ情報 | STRING |
