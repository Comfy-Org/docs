Kling Text to Video ノードは、Kling ビデオ生成 API を使用して、テキストの説明から動画を生成します。プロンプトと設定（アスペクト比、生成モード、CFG スケール）をAPIに送信し、生成タスクの完了を待ってから、結果の動画をIDと再生時間とともに返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 生成したい動画内容を説明するポジティブなテキストプロンプト | STRING | はい | 最大 2500 文字 |
| `ネガティブプロンプト` | 動画で避けたい内容を説明するネガティブなテキストプロンプト | STRING | いいえ | 最大 2500 文字 |
| `cfg_scale` | 動画がプロンプトにどの程度忠実に従うかを制御する構成スケール値（デフォルト: 1.0） | FLOAT | いいえ | 0.0 ～ 1.0 |
| `アスペクト比` | 動画のアスペクト比設定（デフォルト: "16:9"） | COMBO | いいえ | "16:9"<br />"9:16"<br />"1:1" |
| `モード` | 動画生成に使用する設定。形式: mode / duration / model_name（デフォルト: "pro mode / 5s duration / kling-v2-5-turbo"） | COMBO | いいえ | "pro mode / 5s duration / kling-v2-5-turbo"<br />"pro mode / 10s duration / kling-v2-5-turbo" |

注: `prompt` パラメータは必須であり、空にすることはできません。`prompt` と `negative_prompt` はどちらも最大 2500 文字に制限されています。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 生成された動画出力 | VIDEO |
| `video_id` | 生成された動画の一意の識別子 | STRING |
| `継続時間` | 生成された動画の再生時間情報 | STRING |
