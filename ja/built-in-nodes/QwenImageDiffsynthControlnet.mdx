QwenImageDiffsynthControlnet は、拡散合成コントロールネットワークパッチをベースモデルに適用します。入力画像とオプションのマスクを使用して、調整可能な強度でモデルの生成プロセスをガイドし、コントロールネットワークの影響を組み込んだパッチ適用済みモデルを生成することで、より制御された画像合成を実現します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | コントロールネットワークでパッチ適用するベースモデル | MODEL | はい | - |
| `モデルパッチ` | ベースモデルに適用するコントロールネットワークパッチモデル | MODEL_PATCH | はい | - |
| `vae` | 拡散プロセスで使用されるVAE（Variational Autoencoder） | VAE | はい | - |
| `画像` | コントロールネットワークをガイドするために使用される入力画像。最初の3つのカラーチャンネル（RGB）のみが使用され、追加チャンネルは破棄されます | IMAGE | はい | - |
| `強度` | コントロールネットワークの影響の強さ（デフォルト: 1.0） | FLOAT | はい | -10.0〜10.0 |
| `マスク` | コントロールネットワークを適用する領域を定義するオプションのマスク。使用前にマスクは内部で反転されます | MASK | No | - |

**注:** マスクが指定された場合、自動的に反転（1.0 - mask）され、コントロールネットワーク処理の期待される寸法に合わせてリシェイプされます。このノードは、モデルパッチがZImage Controlタイプか標準のDiffSynthコントロールネットワークかに応じて、異なる内部処理メソッドを使用します。このノードは実験的とフラグ付けされています。

## 出力
