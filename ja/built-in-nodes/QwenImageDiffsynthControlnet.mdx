QwenImageDiffsynthControlnet は、拡散合成制御ネットワークパッチをベースモデルに適用します。入力画像とオプションのマスクを使用し、調整可能な強度でモデルの生成プロセスをガイドして、制御ネットワークの影響を組み込んだパッチ適用済みモデルを生成し、より制御された画像合成を実現します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | 制御ネットワークでパッチを適用するベースモデルです | MODEL | はい | - |
| `モデルパッチ` | ベースモデルに適用する制御ネットワークパッチモデルです | MODEL_PATCH | はい | - |
| `vae` | 拡散プロセスで使用される VAE（Variational Autoencoder）です | VAE | はい | - |
| `画像` | 制御ネットワークをガイドするために使用される入力画像です。最初の 3 つのカラーチャンネル（RGB）のみが使用され、それ以外のチャンネルは破棄されます | IMAGE | はい | - |
| `強度` | 制御ネットワークの影響の強さです（デフォルト: 1.0） | FLOAT | はい | -10.0～10.0（ステップ 0.01） |
| `マスク` | 制御ネットワークを適用する領域を定義するオプションのマスクです。DiffSynth および Z-Image パッチでは、使用前にマスクが内部で反転されます | MASK | いいえ | - |
| `start_percent` | ノイズ除去プロセスにおいて、全サンプリングステップに対する割合として、制御ネットワークが効果を発揮し始める時点です（デフォルト: 0.0） | FLOAT | いいえ | 0.0～1.0（ステップ 0.001） |
| `end_percent` | ノイズ除去プロセスにおいて、制御ネットワークが効果を及ぼすのを停止する時点です（デフォルト: 1.0） | FLOAT | いいえ | 0.0～1.0（ステップ 0.001） |

**注記:** `start_percent` と `end_percent` の値は、制御ネットワークをノイズ除去プロセスの一定のウィンドウに制限します。そのウィンドウ外では、モデルはパッチなしでサンプリングされます。`strength` が 0 に設定されている場合、ノードは変更されていないベースモデルを返します。マスクが指定されている場合、Z-Image Control パスおよび標準 DiffSynth パスではマスクが反転（1.0 - mask）され、形状が変更されますが、Qwen Image 2.1 Fun ControlNet パッチでは指定されたマスクがそのまま使用されます。ノードはロードされたモデルパッチから内部パッチ実装を選択するため、同じ入力でも Z-Image Control、Qwen Image 2.1 Fun ControlNet、および標準 DiffSynth チェックポイントでは動作が多少異なります。このノードは実験的としてフラグが付けられています。
