ElevenLabs Text to Speech ノードは、ElevenLabs API を使用して、書き込まれたテキストを音声に変換します。特定の音声を選択し、安定性、速度、スタイルなどのさまざまな音声特性を微調整して、カスタマイズされた音声出力を生成できます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | テキスト読み上げに使用するモデル。モデルを選択すると、そのモデル固有のパラメータが表示されます。 | DYNAMIC_COMBO | いいえ | `"eleven_multilingual_v2"`<br />`"eleven_v3"` |
| `voice` | 音声合成に使用する音声。Voice Selector または Instant Voice Clone から接続します。 | CUSTOM | はい | N/A |
| `text` | 読み上げるテキスト。少なくとも1文字以上含む必要があります。 | STRING | はい | N/A |
| `stability` | 音声の安定性。値が低いと感情表現の幅が広がり、値が高いと一貫性が高まりますが、単調になりがちです（デフォルト: 0.5）。 | FLOAT | いいえ | 0.0 - 1.0 |
| `apply_text_normalization` | テキスト正規化モード。'auto' はシステムが自動的に決定し、'on' は常に正規化を適用し、'off' は正規化をスキップします。 | COMBO | いいえ | `"auto"`<br />`"on"`<br />`"off"` |
| `language_code` | ISO-639-1 または ISO-639-3 の言語コード（例: 'en'、'es'、'fra'）。自動検出の場合は空のままにします（デフォルト: ""）。 | STRING | いいえ | N/A |
| `seed` | 再現性のためのシード（決定性は保証されません）（デフォルト: 1）。 | INT | いいえ | 0 - 2147483647 |
| `output_format` | 音声出力形式。 | COMBO | いいえ | `"mp3_44100_192"`<br />`"opus_48000_192"` |

### eleven_multilingual_v2 入力

これらのパラメータは、`model` が `"eleven_multilingual_v2"` に設定されている場合に使用できます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `speed` | 話す速度。1.0 が通常で、&lt;1.0 は遅く、>1.0 は速くなります（デフォルト: 1.0）。 | FLOAT | いいえ | 0.7 - 1.3 |
| `similarity_boost` | 類似性の強調。値が高いほど元の音声により似せることができます（デフォルト: 0.75）。 | FLOAT | いいえ | 0.0 - 1.0 |
| `use_speaker_boost` | 元の話者音声への類似性を強調します（デフォルト: False）。 | BOOLEAN | いいえ | True / False |
| `style` | スタイルの誇張。値が高いほど様式的な表現が増えますが、安定性が低下する可能性があります（デフォルト: 0.0）。 | FLOAT | いいえ | 0.0 - 0.2 |

### eleven_v3 入力

これらのパラメータは、`model` が `"eleven_v3"` に設定されている場合に使用できます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `speed` | 話す速度。1.0 が通常で、&lt;1.0 は遅く、>1.0 は速くなります（デフォルト: 1.0）。 | FLOAT | いいえ | 0.7 - 1.3 |
| `similarity_boost` | 類似性の強調。値が高いほど元の音声により似せることができます（デフォルト: 0.75）。 | FLOAT | いいえ | 0.0 - 1.0 |

|-------------|-------------|-----------|
| `audio` | テキスト読み上げ変換によって生成された音声。 | AUDIO |
