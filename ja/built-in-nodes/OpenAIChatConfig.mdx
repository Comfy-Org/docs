OpenAI ChatGPT 高機能オプションノードは、OpenAI Chat ノードに対して追加の設定を行うことができます。このノードは、モデルが応答を生成する方法を制御する包括的な設定を提供し、応答の切り詰め行為、出力長制限、カスタム指示などが含まれます。

## 概要

OpenAI ChatGPT 高機能オプションノードは、ユーザーが高度な設定オプションを指定することで、OpenAI Chat ノードの機能を強化するために設計されています。これらの設定は、モデルの応答生成を特定の要件に合わせるのに役立ちます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 范囲 |
|-----------|-------------|-----------|----------|-------|
| `切り捨て` | モデル応答に対する切り詰め戦略を指定します。auto: この応答の文脈と前の応答がモデルの文脈ウィンドウサイズを超えた場合、モデルは会話の途中で入力アイテムをドロップして文脈ウィンドウにフィットさせるために応答を切り詰めます。disabled: モデル応答が文脈ウィンドウサイズを超える場合、リクエストは400エラーより失敗します（デフォルト: "auto"） | STRING | はい | "auto"<br />"disabled" |
| `最大出力トークン数` | 响答に対して生成できるトークンの数の上限を設定します。表示可能なトークンと推論トークンを含みます（デフォルト: 4096） | INT | いいえ | 16〜16384 |
| `指示` | モデルに対して応答を生成する方法に関する指示（マルチライン入力がサポートされています） | STRING | いいえ | - |
| `reasoning_effort` | 偉大に答える前にモデルが推論する量を指定します。'default'はモデルに選択を任せます。サポートされるレベルはモデルごとに異なります：GPT-6 Astra low-max、GPT-5.6 none-max（最小限なし）、GPT-5.5 none-xhigh、GPT-5.5 Pro medium-xhigh、GPT-5 minimal-high、o-series low-high；GPT-4.1は推論がありません。サポートされないレベルはリクエスト送信前に拒否されます（デフォルト: "default"） | STRING | いいえ | "default"<br />"none"<br />"minimal"<br />"low"<br />"medium"<br />"high"<br />"xhigh"<br />"max" |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `OPENAI_CHAT_CONFIG` | 指定された設定を OpenAI Chat ノードで使用するための設定オブジェクト | OPENAI_CHAT_CONFIG |

## 注意事項

- `max_output_tokens` パラメータは、表示可能なトークンと推論トークンを含むトークンの合計数の上限を設定します。
- `reasoning_effort` パラメータは、モデルが応答を生成する前に適用する推論のレベルを指定できます。サポートされるレベルは使用されるモデルによって異なります。
- `instructions` パラメータは、モデルに対して応答生成プロセスをガイドする詳細な指示を提供するために使用できます。
- `truncation` パラメータは、モデルが文脈ウィンドウサイズを超えた場合に自動的に応答を切り詰めるか、400エラーより失敗するかを決定します。
