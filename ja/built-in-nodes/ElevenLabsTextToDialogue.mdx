ElevenLabs Text to Dialogue ノードは、テキストから複数話者のオーディオダイアログを生成します。異なるテキスト行と各参加者に異なる音声を指定することで、会話を作成できます。このノードはダイアログリクエストを ElevenLabs API に送信し、生成されたオーディオを返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `安定性` | 音声の安定性。値が低いほど感情表現の幅が広がり、値が高いほど一貫性のある音声になりますが、単調になる可能性があります。（デフォルト: 0.5） | FLOAT | 任意 | 0.0 - 1.0 |
| `テキスト正規化適用` | テキスト正規化モード。'auto' はシステムが自動的に決定し、'on' は常に正規化を適用し、'off' は正規化をスキップします。 | COMBO | 任意 | `"auto"`<br />`"on"`<br />`"off"` |
| `モデル` | ダイアログ生成に使用するモデル。 | COMBO | 任意 | `"eleven_v3"` |
| `入力数` | ダイアログエントリの数。数値を選択すると、その数のテキスト入力フィールドと音声入力フィールドが生成されます。 | DYNAMIC_COMBO | 必須 | `"1"`<br />`"2"`<br />`"3"`<br />`"4"`<br />`"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"` |
| `言語コード` | ISO-639-1 または ISO-639-3 言語コード（例: 'en'、'es'、'fra'）。自動検出の場合は空のままにします。（デフォルト: 空） | STRING | 任意 | - |
| `シード値` | 再現性のためのシード。（デフォルト: 1） | INT | 任意 | 0 - 4294967295 |
| `出力フォーマット` | オーディオ出力形式。 | COMBO | 任意 | `"mp3_44100_192"`<br />`"opus_48000_192"` |

**注記:** `inputs` パラメータは動的です。数値（例: "3"）を選択すると、ノードには対応する3つの `text` 入力フィールドと `voice` 入力フィールド（例: `text1`、`voice1`、`text2`、`voice2`、`text3`、`voice3`）が表示されます。各 `text` フィールドには少なくとも1文字の入力が必要です。各 `voice` フィールドには、Voice Selector または Instant Voice Clone ノードから接続された音声が必要です。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `audio` | 選択した出力形式で生成された、複数話者ダイアログのオーディオ。 | AUDIO |
