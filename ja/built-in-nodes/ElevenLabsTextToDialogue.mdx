ElevenLabs Text to Dialogue ノードは、テキストから複数話者の音声対話を生成します。異なるテキスト行と参加者ごとに異なる音声を指定することで、会話を作成できます。このノードは対話リクエストを ElevenLabs API に送信し、生成された音声を返します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `安定性` | 音声の安定性。値が低いほど感情の幅が広がり、値が高いほど一貫性が高くなりますが、単調になる可能性があります。（デフォルト: 0.5） | FLOAT | はい | 0.0 - 1.0 |
| `テキスト正規化適用` | テキスト正規化モード。'auto' はシステムに判断を任せ、'on' は常に正規化を適用し、'off' はスキップします。 | COMBO | はい | `"auto"`<br />`"on"`<br />`"off"` |
| `モデル` | 対話生成に使用するモデル。 | COMBO | はい | `"eleven_v3"` |
| `入力数` | 対話エントリ数。数値を選択すると、その数だけテキストと音声の入力ペアが作成されます。 | DYNAMIC_COMBO | はい | `"1"`<br />`"2"`<br />`"3"`<br />`"4"`<br />`"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"` |
| `言語コード` | ISO-639-1 または ISO-639-3 言語コード（例: 'en'、'es'、'fra'）。空欄にすると自動検出になります。（デフォルト: 空） | STRING | はい | - |
| `シード値` | 再現性のためのシード。（デフォルト: 1） | INT | はい | 0 - 4294967295 |
| `出力フォーマット` | 音声出力形式。 | COMBO | はい | `"mp3_44100_192"`<br />`"opus_48000_192"` |

### 対話エントリ入力

すべての `inputs` オプションで共有されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `text1` ... `text10` | 対応する対話エントリのテキスト内容。選択した対話エントリごとに `text` フィールドが1つ作成されます。各テキスト値には少なくとも1文字含める必要があります。 | STRING | はい | - |
| `voice1` ... `voice10` | 対応する対話エントリの音声。Voice Selector または Instant Voice Clone ノードから接続します。選択した対話エントリごとに `voice` フィールドが1つ作成されます。 | ELEVENLABS_VOICE | はい | - |

**注:** `inputs` セレクターでは最大10件の対話エントリを作成できます。各エントリには `text` フィールドと `voice` フィールドの両方が必要です。`text` の値は空にできません。`voice` 入力には、互換性のある ElevenLabs 音声ノードから提供される音声 ID が必要です。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `audio` | 選択した出力形式で生成された複数話者の対話音声。 | AUDIO |
