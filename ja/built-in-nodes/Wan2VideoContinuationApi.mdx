Wan 2.7 Video Continuation ノードは、入力ビデオクリップの終端から継続する新しいビデオセグメントを生成します。Wan 2.7 モデルを使用してテキストプロンプトに基づいて継続部分を合成し、オプションで終端を特定のターゲットフレームへ誘導することもできます。

## 入力

### 共通入力

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | 使用するビデオ生成モデル。 | DYNAMIC_COMBO | 必須 | `"wan2.7-i2v"` |
| `最初のクリップ` | 継続元となる入力ビデオ。長さ: 2秒〜10秒。出力のアスペクト比はこのビデオから取得されます。 | VIDEO | 必須 | 2秒〜10秒 |
| `ラストフレーム` | 最後のフレーム画像。継続部分はこのフレームに向かって遷移します。 | IMAGE | 任意 | - |
| `シード値` | 生成に使用するシード値。(デフォルト: 0) | INT | 必須 | 0 〜 2147483647 |
| `プロンプト拡張` | AI支援でプロンプトを拡張するかどうか。(デフォルト: True) | BOOLEAN | 必須 | - |
| `ウォーターマーク` | 結果にAI生成ウォーターマークを追加するかどうか。(デフォルト: False) | BOOLEAN | 必須 | - |

### wan2.7-i2v 入力

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要素と視覚的特徴を説明するプロンプト。英語と中国語に対応しています。(デフォルト: 空文字列) | STRING | 必須 | - |
| `negative_prompt` | 避けるべき内容を説明するネガティブプロンプト。(デフォルト: 空文字列) | STRING | 必須 | - |
| `resolution` | 出力ビデオの解像度。 | COMBO | 必須 | `"720P"`<br />`"1080P"` |
| `duration` | 出力全体の長さ（秒）。モデルは、入力クリップ後の残り時間を埋める継続部分を生成します。(デフォルト: 5) | INT | 必須 | 2 〜 15 |

**注:** 入力ビデオ `first_clip` の長さは2秒から10秒の間である必要があります。

## 出力

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `output` | 生成されたビデオの継続部分。 | VIDEO |
