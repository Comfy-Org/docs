このノードは、深度マップを逆投影し、得られた点群を三角形分割することにより、DA3_GEOMETRY パケットを 3D メッシュに変換します。バッチ内の単一画像を処理し、3D レンダリングに適したテクスチャ付きまたはテクスチャなしのメッシュを生成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `da3_geometry` | 深度マップ、オプションの信頼度マップ、オプションの空マップ、およびソース画像を含む DA3_GEOMETRY パケット | DA3_GEOMETRY | はい | - |
| `batch_index` | バッチ内のどの画像を変換するか。画像ごとに頂点数が異なるため、バッチはスタックできません（デフォルト: 0）。入力ジオメトリのバッチサイズ未満である必要があり、そうでない場合はエラーが発生します | INT | はい | 0 〜 4096 |
| `decimation` | 頂点ストライド。1 = フル解像度、2 = 半分など（デフォルト: 1） | INT | はい | 1 〜 8 |
| `discontinuity_threshold` | 3x3 の深度スパンがこの割合を超える三角形を破棄します。0 = オフ（デフォルト: 0.04） | FLOAT | はい | 0.0 〜 1.0 |
| `confidence_threshold` | 画像ごとに正規化された信頼度がこの値未満のピクセルを除外します。0 = すべて保持、1 = 最も信頼度の高い単一ピクセルのみ保持。ジオメトリに信頼度マップがある場合（Small/Base モデル）に使用されます（デフォルト: 0.1） | FLOAT | はい | 0.0 〜 1.0 |
| `use_sky_mask` | 空確率のピクセル（sky >= 0.5）をメッシュから除外します。ジオメトリに空マップがある場合（Mono/Metric モデル）に使用されます（デフォルト: True） | BOOLEAN | はい | True or False |
| `texture` | ソース画像をベースカラーテクスチャとして使用します（デフォルト: True） | BOOLEAN | はい | True or False |

非有限、ゼロ、または負の深度値を持つピクセルは常にメッシュから除外されます。結果のメッシュが空の場合はエラーが発生します。エラーメッセージでは、`discontinuity_threshold` を上げる、`confidence_threshold` を下げる、または `use_sky_mask` を無効にすることを提案します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `MESH` | 頂点、面、UV 座標、およびオプションのテクスチャを持つ三角形分割された 3D メッシュ | MESH |
