このノードは、Ideogram Vector を使用してテキストプロンプトから編集可能な SVG を生成します。最大5枚の参照画像で任意にガイドできます。結果はラスター画像ではなくベクターマークアップであるため、図形はベクターエディタで編集可能なままです。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 使用するモデル。デフォルト: `"ideogram-vector-1"`。 | DYNAMIC_COMBO | はい | `"ideogram-vector-1"` |
| `images` | オプションの参照画像。画像1がメインのソースで、画像2〜5は追加の参照です。プロンプト内で `@Image1`、`@Image2` などとして言及してください。バッチ入力の場合は画像ごとに1回としてカウントされます。 | AUTOGROW | いいえ | 0〜5枚の画像 |
| `prompt` | SVG の説明。入力画像への `@Image1` 形式の参照をサポートします。 | STRING | はい | 1〜9500文字 |
| `aspect_ratio` | `"auto"` は画像1に従い、画像が接続されていない場合はプロンプトに従います。デフォルト: `"auto"`。 | COMBO | はい | `"auto"`<br />`"1:3"`<br />`"1:2"`<br />`"9:16"`<br />`"10:16"`<br />`"2:3"`<br />`"3:4"`<br />`"4:5"`<br />`"1:1"`<br />`"5:4"`<br />`"4:3"`<br />`"3:2"`<br />`"16:10"`<br />`"16:9"`<br />`"2:1"`<br />`"3:1"` |
| `quality` | 品質ティア。ティアが高いほどコストが増え、時間がかかります。デフォルト: `"medium"`。 | COMBO | はい | `"low"`<br />`"medium"`<br />`"high"` |
| `seed` | 生成用のシード。同じプロンプト、画像、設定、シードであれば同じ SVG が得られます。デフォルト: 42。 | INT | はい | 0〜2147483647 |

**制約:**

* プロンプトは1〜9500文字である必要があります。
* `images` は最大5枚の画像を受け付け（入力がバッチの場合は画像ごとにカウントされます）、各画像のアスペクト比は1:6〜6:1である必要があります。
* 最長辺が2048ピクセルを超える画像は、アップロード前にダウンスケールされます。
* 接続されていない画像を参照すると、たとえば2枚しか画像が指定されていない状態で `@Image4` を参照すると、エラーが発生します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `SVG` | 生成された SVG を編集可能なベクターマークアップとして出力します。 | SVG |
