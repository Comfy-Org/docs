MiniMax H3 の最初と最後のフレームを使用するワークフローを Comfy Cloud GPU 上で実行し、2つのキーフレーム間の動きを一致するサウンドトラック付きで返します。開始フレームと終了フレームを指定すると、モデルがその間のショットを補完します。最後のフレームは任意です。省略すると、代わりに最初のフレームから離れるように動きが生成されます。これはベータ版ノードであり、GPU秒単位で課金されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 動画の開始元となる画像です。ワークフローの実行前に、最大2048x2048ピクセルでアップロードされます。 | IMAGE | はい | - |
| `last_frame` | 任意の終了フレームです。接続すると、生成される動きはこの画像で終了します。接続しない場合、動きは`first_frame`から離れるように生成されます。 | IMAGE | いいえ | - |
| `prompt` | 動きと、ショットに含めるべき音のテキスト説明です。送信前に先頭と末尾の空白は削除されます。 | STRING | はい | 1～4096文字 |
| `seed` | 生成結果を制御する乱数シードです（デフォルト: 42）。 | INT | はい | 0～18446744073709551615 |
| `aspect_ratio` | 生成動画のアスペクト比です（デフォルト: `"1:1"`）。 | COMBO | はい | `"1:1"`<br />`"3:4"`<br />`"2:3"`<br />`"3:2"`<br />`"4:3"`<br />`"16:9"`<br />`"9:16"`<br />`"21:9"` |
| `resolution` | フレームサイズの設定です（デフォルト: `"480p"`）。720pは480pと比べて約2倍のGPU秒を消費します。 | COMBO | はい | `"480p"`<br />`"720p"` |
| `duration_seconds` | 長さ（秒）です（デフォルト: 5）。パイプラインは24 fpsで17フレーム単位に量子化するため、クリップの長さはこの値から約3分の2秒以内に収まります。 | INT | はい | 5～15 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `VIDEO` | 生成された動画とそのサウンドトラックです。 | VIDEO |
