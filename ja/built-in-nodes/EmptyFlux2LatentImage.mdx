Empty Flux 2 Latent ノードは、空の潜在表現を作成します。ゼロで満たされたテンソルを生成し、Flux モデルのデノイジングプロセスの開始点として機能します。潜在表現の次元は、入力された `width` と `height` によって決定され、16分の1にスケールダウンされます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `幅` | 生成する最終画像の幅です。潜在表現の幅は、この値を16で割った値になります。デフォルト値は1024です。 | INT | 必須 | 16〜8192 |
| `高さ` | 生成する最終画像の高さです。潜在表現の高さは、この値を16で割った値になります。デフォルト値は1024です。 | INT | 必須 | 16〜8192 |
| `バッチサイズ` | 1回のバッチで生成する潜在表現サンプルの数です。デフォルト値は1です。 | INT | 任意 | 1〜4096 |

**注記:** `width` と `height` の入力は16で割り切れる必要があります。ノードは内部的にこの値で除算して潜在表現の次元を作成するためです。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `samples` | ゼロで満たされた潜在テンソルです。形状は `[batch_size, 128, height // 16, width // 16]` です。 | LATENT |
