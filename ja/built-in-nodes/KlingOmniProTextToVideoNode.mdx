このノードは、最新のKling AIモデルを使用して、テキスト記述から動画を生成します。プロンプトをリモートAPIに送信し、生成された動画を返します。このノードでは、動画の長さ、形状、品質を制御でき、マルチショットのストーリーボードを作成することもできます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | 動画生成に使用する特定のKlingモデル（デフォルト：`"kling-v3-omni"`）。 | COMBO | はい | `"kling-v3-omni"`<br />`"kling-video-o1"` |
| `プロンプト` | 動画の内容を説明するテキストプロンプト。肯定的な説明と否定的な説明の両方を含めることができます。ストーリーボードが有効な場合は無視されます。 | STRING | はい | 0〜2500文字 |
| `アスペクト比` | 生成する動画の形状または寸法。 | COMBO | はい | `"16:9"`<br />`"9:16"`<br />`"1:1"` |
| `継続時間` | 動画の長さ（秒単位、デフォルト：5）。 | INT | はい | 3〜15秒 |
| `解像度` | 動画の品質またはピクセル解像度（デフォルト：`"1080p"`）。内部的に標準、プロ、または4K品質にマッピングされます。 | COMBO | いいえ | `"4k"`<br />`"1080p"`<br />`"720p"` |
| `ストーリーボード` | 個々のプロンプトと時間を持つ一連の動画セグメントを生成します。o1モデルでは無視されます。 | DYNAMIC_COMBO | いいえ | `"disabled"`<br />`"1 storyboard"`<br />`"2 storyboards"`<br />`"3 storyboards"`<br />`"4 storyboards"`<br />`"5 storyboards"`<br />`"6 storyboards"` |
| `音声を生成` | 動画のオーディオを生成するかどうか（デフォルト：False）。 | BOOLEAN | いいえ | True / False |
| `シード` | シードはノードを再実行するかどうかを制御します。シードに関係なく結果は非決定的です（デフォルト：0）。 | INT | いいえ | 0〜2147483647 |

### ストーリーボードのサブ入力

`storyboards` が `"disabled"` 以外の値に設定されている場合、各ストーリーボードセグメントに対して以下の入力が表示されます。以下のパラメータ名において、`{i}` はセグメント番号で、選択したストーリーボード数に応じて1から始まります。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_{i}_prompt` | ストーリーボードセグメント &#123;i&#125; のプロンプト。最大512文字。 | STRING | はい | 1〜512文字 |
| `storyboard_{i}_duration` | ストーリーボードセグメント &#123;i&#125; の長さ（秒単位、デフォルト：4）。 | INT | はい | 1〜15秒 |

### パラメータの制約と制限

- **モデル固有の制限：**
  - `kling-video-o1` モデルは、**5秒または10秒**の時間のみをサポートします。
  - `kling-video-o1` モデルはオーディオ生成を**サポートしていません**。
  - `kling-video-o1` モデルは4K解像度を**サポートしていません**。
  - `kling-video-o1` モデルはストーリーボードを**サポートしていません**。
- **ストーリーボードの制約：**
  - ストーリーボードが有効な場合、`prompt` フィールドは無視されます。
  - 各ストーリーボードには、独自のプロンプト（1〜512文字）と時間が必要です。
  - すべてのストーリーボードの合計時間は、グローバルな `duration` パラメータと正確に一致する必要があります。
- **プロンプトの要件：**
  - ストーリーボードが**無効**の場合、`prompt` フィールドは必須です（最小1文字）。
  - ストーリーボードが**有効**の場合、`prompt` フィールドは空（0文字）にできます。
