このノードは、ComfyUI の出力ディレクトリにファイルを保存せずに、UI 上で3Dモデルのプレビューを表示します。モデルを一時ファイルに保存し、モデルデータ、モデル情報、カメラ情報、プレビュー寸法を下流の処理にそのまま渡します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 上流の3Dノードからの3Dモデルファイル。 | FILE3D | はい | GLB、GLTF、FBX、OBJ、STL、USDZ、または対応する3D形式 |
| `3Dモデル情報` | オプションのモデル情報メタデータ。高度なオプションです。 | LOAD3DMODELINFO | いいえ | - |
| `viewport_state` | カメラとモデル情報を含む現在のビューポートの状態。 | LOAD3D | はい | - |
| `カメラ情報` | 3Dビューのオプションのカメラ設定。高度なオプションです。 | LOAD3DCAMERA | いいえ | - |
| `幅` | プレビューの幅（ピクセル単位）。デフォルト: 1024。 | INT | はい | 1 ～ 4096 |
| `高さ` | プレビューの高さ（ピクセル単位）。デフォルト: 1024。 | INT | はい | 1 ～ 4096 |

注：`camera_info` または `model_3d_info` が接続されていない場合、利用可能であればそれらの値は `viewport_state` から取得されます。`viewport_state` にモデル情報がない場合、`model_3d_info` は空のリストにデフォルト設定されます。`viewport_state` が辞書でない場合は、空として扱われます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_file` | 入力から渡された3Dモデルファイル。 | FILE3D |
| `カメラ情報` | 入力またはビューポートの状態からのモデル情報メタデータ。 | LOAD3DMODELINFO |
| `3Dモデル情報` | 入力またはビューポートの状態からのカメラ設定。 | LOAD3DCAMERA |
| `幅` | プレビューの幅（ピクセル単位）。 | INT |
| `高さ` | プレビューの高さ（ピクセル単位）。 | INT |
