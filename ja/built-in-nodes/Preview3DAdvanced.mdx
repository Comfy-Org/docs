このノードは、ComfyUI の出力ディレクトリにファイルを保存せずに、UI 上で 3D モデルのプレビューを表示します。モデルを一時ファイルに保存し、モデルデータ、モデル情報、カメラ情報、プレビュー寸法を下流の処理のためにそのままパススルーします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 上流の3Dノードからの3Dモデルファイルです。 | FILE3D | はい | GLB, GLTF, FBX, OBJ, STL, USDZ, or any supported 3D format |
| `3Dモデル情報` | シーン内の各モデルの配置（位置、回転、スケール。Y軸上方向のワールド空間）です。任意指定です。高度なオプションです。 | LOAD3DMODELINFO | いいえ | - |
| `viewport_state` | カメラとモデルの情報を含む現在のビューポートの状態です。 | LOAD3D | はい | - |
| `カメラ情報` | ビューポートのカメラ情報（位置、注視点、ズーム、タイプ）です。任意指定です。高度なオプションです。 | LOAD3DCAMERA | いいえ | - |
| `幅` | ビューポートのレンダリング幅（ピクセル単位）です。デフォルト: 1024。 | INT | はい | 1〜4096 |
| `高さ` | ビューポートのレンダリング高さ（ピクセル単位）です。デフォルト: 1024。 | INT | はい | 1〜4096 |

注：`camera_info` または `model_3d_info` が接続されていない場合、利用可能であれば、それらの値は `viewport_state` から取得されます。`viewport_state` にカメラ情報が含まれていない場合、`camera_info` は None になります。`viewport_state` にモデル情報がない場合、`model_3d_info` はデフォルトで空のリストになります。`viewport_state` が辞書でない場合は空として扱われます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_file` | 上流の3Dノードからの3Dモデルファイル（glb/obj/stl など）です。変更されずにそのまま渡されます。 | FILE3D |
| `カメラ情報` | シーン内の各モデルの配置（位置、回転、スケール。Y軸上方向のワールド空間）です。入力値を使用するか、`viewport_state` に保存された値にフォールバックします。 | LOAD3DMODELINFO |
| `3Dモデル情報` | ビューポートのカメラ情報（位置、注視点、ズーム、タイプ）です。入力値を使用するか、`viewport_state` に保存された値にフォールバックします。 | LOAD3DCAMERA |
| `幅` | ビューポートのレンダリング幅（ピクセル単位）です。 | INT |
| `高さ` | ビューポートのレンダリング高さ（ピクセル単位）です。 | INT |
