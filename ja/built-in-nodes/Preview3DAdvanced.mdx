このノードは、ComfyUI の出力ディレクトリにファイルを保存せずに、UI 上で3Dモデルのプレビューを表示します。モデルを一時ファイルに保存し、モデルデータ、モデル情報、カメラ情報、プレビューの寸法を後続の処理にパススルーします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 上流の3Dノードからの3Dモデルファイルです。 | FILE3D | はい | GLB, GLTF, FBX, OBJ, STL, USDZ, or any supported 3D format |
| `3Dモデル情報` | 任意のモデル情報メタデータです。上級者向けオプションです。 | LOAD3DMODELINFO | いいえ | - |
| `viewport_state` | カメラ情報とモデル情報を含む現在のビューポート状態です。 | LOAD3D | はい | - |
| `カメラ情報` | 3Dビュー用の任意のカメラ設定です。上級者向けオプションです。 | LOAD3DCAMERA | いいえ | - |
| `幅` | プレビューの幅（ピクセル単位）です。デフォルト: 1024。 | INT | はい | 1 〜 4096 |
| `高さ` | プレビューの高さ（ピクセル単位）です。デフォルト: 1024。 | INT | はい | 1 〜 4096 |

注意: `camera_info` または `model_3d_info` が接続されていない場合、利用可能であればそれらの値は `viewport_state` から取得されます。`viewport_state` にカメラ情報が含まれていない場合は、`camera_info` は None になります。`viewport_state` にモデル情報がない場合は、`model_3d_info` はデフォルトで空のリストになります。`viewport_state` が辞書でない場合は、空として扱われます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_file` | 入力からパススルーされた3Dモデルファイルです。 | FILE3D |
| `カメラ情報` | 入力またはビューポート状態からのモデル情報メタデータです。 | LOAD3DMODELINFO |
| `3Dモデル情報` | 入力またはビューポート状態からのカメラ設定です。 | LOAD3DCAMERA |
| `幅` | プレビューの幅（ピクセル単位）です。 | INT |
| `高さ` | プレビューの高さ（ピクセル単位）です。 | INT |
