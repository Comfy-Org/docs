このノードは、Gemini 画像モデルを通じてテキストプロンプトを Google の Vertex AI API に送信し、画像を生成または編集します。説明文から新しい画像を作成したり、オプションの参照画像を使用して既存の画像を変更したりします。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 使用する Gemini 画像モデルを選択します。選択したモデルによって、利用可能な解像度オプションとモデル固有の入力が決まります。 | DYNAMIC_COMBO | 必須 | `"Nano Banana 2 (Gemini 3.1 Flash Image)"`<br />`"Nano Banana 2 Lite"` |
| `プロンプト` | 生成する画像や適用する編集内容を説明するテキストプロンプトです。モデルが従うべき制約、スタイル、詳細を含めてください。空にすることはできません。（デフォルト: 空） | STRING | 必須 | N/A |
| `シード` | シードを特定の値に固定すると、モデルは繰り返しのリクエストに対して同じ応答を返すよう最善を尽くします。ただし、決定論的な出力は保証されません。また、同じシード値でも、モデルや temperature などのパラメータ設定を変更すると、応答にばらつきが生じる可能性があります。デフォルトでは、ランダムなシード値が使用されます。（デフォルト: 42） | INT | 必須 | 0〜18446744073709551615 |
| `応答モダリティ` | 応答形式を決定します。IMAGE は画像のみを返し、IMAGE+TEXT は画像とテキスト応答を返します。（デフォルト: IMAGE）高度なパラメータです。 | COMBO | 必須 | `"IMAGE"`<br />`"IMAGE+TEXT"` |
| `システムプロンプト` | AI の動作を決定づける基盤となる指示です。デフォルトでは、モデルに常に画像を生成するよう指示する組み込みプロンプトが使用されます。高度なパラメータです。 | STRING | 任意 | N/A |
| `temperature` | 生成時のランダム性を制御します。値が低いほど、より集中的かつ決定論的な出力になります。（デフォルト: 1.0）高度なパラメータです。 | FLOAT | 任意 | 0.0〜2.0 (step 0.01) |
| `top_p` | ニュークリアスサンプリングのしきい値です。値が低いほど集中度が高く、高いほど多様性が高くなります。（デフォルト: 0.95）高度なパラメータです。 | FLOAT | 任意 | 0.0〜1.0 (step 0.01) |

### 参照入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `images` | オプションの参照画像です。合計14枚まで指定できます。拡張可能スロット: `image_1` から `image_14` までを接続できます。 | IMAGE | 任意 | 0〜14枚 |
| `files` | モデルのコンテキストとして使用するオプションのファイルです。Gemini Generate Content Input Files ノードからの入力を受け付けます。 | GEMINI_INPUT_FILES | 任意 | N/A |

**注:** `images` 入力には最大14枚の参照画像を接続できます。この制限を超えるとエラーが発生します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | 生成または編集された画像。 | IMAGE |
| `STRING` | モデルによって生成されたテキストによる説明やキャプション。`response_modalities` が `IMAGE` に設定されている場合など、テキストが返されないときは空になります。 | STRING |
| `思考画像` | モデルの思考プロセスから得られた最初の画像。`thinking_level` が HIGH かつ IMAGE+TEXT モダリティの場合にのみ利用できます。 | IMAGE |

**注:** `response_modalities` が `IMAGE` に設定されている場合、`STRING` 出力は空になります。このモードでモデルが画像を生成しない場合、ノードはエラーを発生させ、モデルの推論を確認するために IMAGE+TEXT への切り替えを提案します。
