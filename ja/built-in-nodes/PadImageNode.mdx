画像を単色または端のミラーコピーでパディングします。パディングは、各辺の正確なピクセル数、サイズ倍率、または幅と高さが指定した数で割り切れるようにする最小量として設定できます。これは保存やタイリングの前に便利です。元の画像は位置を保ちます。`left` と `top` のパディングは画像の前に追加され、`right` と `bottom` は画像の後に追加されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `image` | パディングする画像です。 | IMAGE | はい | - |
| `padding_type` | 追加するパディング量の指定方法です。各辺の正確な量には `"pad dimensions"`、入力に対する出力サイズには `"pad by multiplier"`、次の倍数に到達させるには `"pad to multiple"` を指定します。オプションを選択すると、そのパラメータが表示されます。 | DYNAMIC_COMBO | はい | `"pad dimensions"`<br />`"pad by multiplier"`<br />`"pad to multiple"` |
| `left` | 左側に追加するピクセル数です。`padding_type` が `"pad dimensions"` のときに使用できます（デフォルト: 0）。 | INT | はい | 0 〜 16384 |
| `top` | 上側に追加するピクセル数です。`padding_type` が `"pad dimensions"` のときに使用できます（デフォルト: 0）。 | INT | はい | 0 〜 16384 |
| `right` | 右側に追加するピクセル数です。`padding_type` が `"pad dimensions"` のときに使用できます（デフォルト: 0）。 | INT | はい | 0 〜 16384 |
| `bottom` | 下側に追加するピクセル数です。`padding_type` が `"pad dimensions"` のときに使用できます（デフォルト: 0）。 | INT | はい | 0 〜 16384 |
| `multiplier` | 入力に対する出力サイズです。たとえば 1.5 では各辺に 25% が追加されます。パディングは対向する辺に均等に分割されます。`padding_type` が `"pad by multiplier"` のときに使用できます（デフォルト: 1.0）。 | FLOAT | はい | 1.0 〜 8.0 （ステップ 0.01） |
| `multiple` | 幅と高さがこの数で割り切れるようにパディングします。パディングは対向する辺に均等に分割され、余分なピクセルは右辺と下辺に割り当てられます。`padding_type` が `"pad to multiple"` のときに使用できます（デフォルト: 32）。 | INT | はい | 1 〜 16384 |
| `padding_style` | パディング領域を何で埋めるかを指定します。`"color"` または `"mirror image"` を選択します。オプションを選択すると、そのパラメータが表示されます。 | DYNAMIC_COMBO | はい | `"color"`<br />`"mirror image"` |
| `color` | パディング領域の塗りつぶし色です。アルファ値は無視されます。`padding_style` が `"color"` のときに使用できます（デフォルト: `"#000000"`）。 | COLOR | はい | - |
| `feathering` | パディングされた辺で、画像の端のこのピクセル数を塗りつぶし色にブレンドします。0 の場合は境界がはっきりしたままになります。`padding_style` が `"color"` のときに使用できます（デフォルト: 0）。 | INT | はい | 0 〜 16384 |

`"mirror image"` は画像の端を色で埋めるのではなく、端を反射させます。端のピクセルは繰り返されず、パディングが画像自体より幅広または高くなった場合は、残りの領域を覆うようにミラー画像が繰り返されます。すべてのパディング量が 0 になる場合、入力画像は変更されずに返されます。
