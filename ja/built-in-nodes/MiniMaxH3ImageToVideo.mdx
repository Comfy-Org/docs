このノードは、MiniMax H3モデルでビデオを生成するために必要なconditioningと空の潜在変数を準備します。テキストプロンプトと、オプションでビデオの最初または最後のフレーム（あるいはその両方）の画像を受け取り、それらをモデル入力に変換します。キーフレーム画像はリサイズされ、エンコードされて、ビデオの開始時と終了時にconditioningに添付されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `clip` | プロンプトをトークン化し、キーフレーム画像をconditioningにエンコードするために使用されるCLIPモデル。 | CLIP | はい |  |
| `vae` | キーフレーム画像が提供された場合に、キーフレーム画像を潜在空間にエンコードするために使用されるVAEモデル。 | VAE | はい |  |
| `プロンプト` | 生成するビデオを説明するテキストプロンプト。複数行と動的プロンプトに対応。 | STRING | はい |  |
| `幅` | ビデオの幅（ピクセル単位、デフォルト: 1344）。 | INT | はい | 32 to MAX_RESOLUTION (step 32) |
| `高さ` | ビデオの高さ（ピクセル単位、デフォルト: 768）。 | INT | はい | 32 to MAX_RESOLUTION (step 32) |
| `長さ` | 24fpsでのフレーム数。モデルの17k+5グリッドに切り上げられます（124 = 約5秒。トレーニング範囲は約124〜362で、それより長い場合は未テスト）（デフォルト: 124）。 | INT | はい | 5〜3600 (step 17) |
| `最初のフレーム` | ビデオの最初のフレームとして使用されるオプションの画像。キャンバス全体のサイズに引き伸ばされるため、アスペクト比は維持されません。入力バッチの最初の画像のみが使用されます。 | IMAGE | いいえ |  |
| `最後のフレーム` | ビデオの最後のフレームとして使用されるオプションの画像。アスペクト比を維持しながらキャンバスを覆うようにクロップされます。入力バッチの最初の画像のみが使用されます。 | IMAGE | いいえ |  |

`first_frame` または `last_frame`（あるいはその両方）が提供された場合、キーフレーム画像はVAEでエンコードされ、それぞれフレーム0と最終フレームのconditioningに添付されます。どちらも提供されない場合、ノードはプロンプトのみで動作します。要求された `length` は最も近い有効なフレーム数（17k + 5）に切り上げられるため、実際のフレーム数は要求よりもわずかに高くなることがあります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `ポジティブ` | エンコードされたプロンプトと、キーフレーム画像が提供された場合はエンコードされたキーフレームおよびMiniMax H3モデルのフレーム数を含むconditioning。 | CONDITIONING |
| `latent` | 要求された幅、高さ、フレーム数で、生成するコンテンツを表す空のオーディオ・ビデオ潜在変数。 | LATENT |
