このノードは、MiniMax H3モデルで動画を生成するために必要なコンディショニングと空の潜在変数を準備します。テキストプロンプトと、必要に応じて動画の最初または最後のフレームの画像を受け取り、モデル入力に変換します。キーフレーム画像はリサイズされ、エンコードされて、動画の開始時と終了時にコンディショニングに添付されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `clip` | プロンプトのトークン化と、キーフレーム画像のコンディショニングへのエンコードに使用されるCLIPモデル。 | CLIP | はい |  |
| `vae` | キーフレーム画像が提供されたときに、それらを潜在空間にエンコードするために使用されるVAEモデル。 | VAE | はい |  |
| `プロンプト` | 生成する動画を説明するテキストプロンプト。複数行や動的プロンプトに対応しています。 | STRING | はい |  |
| `幅` | 動画の幅（ピクセル単位、デフォルト: 1344）。 | INT | はい | 32〜MAX_RESOLUTION (ステップ 32) |
| `高さ` | 動画の高さ（ピクセル単位、デフォルト: 768）。 | INT | はい | 32〜MAX_RESOLUTION (ステップ 32) |
| `長さ` | 24 fpsでのフレーム数。モデルの17k+5グリッドに合わせて切り上げられます（124 = 約5秒; 学習範囲は約124〜362、それ以上は未テスト）（デフォルト: 124）。 | INT | はい | 5〜3600 (ステップ 17) |
| `最初のフレーム` | 動画の最初のフレームとして使用されるオプションの画像。キャンバス全体に引き伸ばされるため、アスペクト比は保持されません。入力バッチの最初の画像のみが使用されます。 | IMAGE | いいえ |  |
| `最後のフレーム` | 動画の最後のフレームとして使用されるオプションの画像。アスペクト比を保持しながらキャンバスを覆うようにクロップされます。入力バッチの最初の画像のみが使用されます。 | IMAGE | いいえ |  |

`first_frame` または `last_frame`（あるいはその両方）が提供された場合、キーフレーム画像はVAEでエンコードされ、それぞれフレーム0と最終フレームのコンディショニングに添付されます。どちらも提供されない場合、ノードはプロンプトのみから動作します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `ポジティブ` | エンコードされたプロンプトと、キーフレーム画像が提供された場合はエンコードされたキーフレームとフレーム数を含む、MiniMax H3モデル用のコンディショニング。 | CONDITIONING |
| `latent` | 要求された幅、高さ、フレーム数を持つ、生成する動画を表す空の潜在変数。 | LATENT |
