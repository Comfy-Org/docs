このノードは、MiniMax H3 モデルで動画を生成するために必要なコンディショニングと空の潜在表現を準備します。テキストプロンプトと、必要に応じて動画の最初および/または最後のフレーム用の画像を受け取り、それらをモデル入力に変換します。キーフレーム画像はリサイズおよびエンコードされ、動画の先頭と末尾のコンディショニングに付加されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `clip` | プロンプトをトークン化し、キーフレーム画像をコンディショニングにエンコードするために使用される CLIP モデルです。 | CLIP | はい |  |
| `vae` | キーフレーム画像が提供された場合に、それらを潜在空間へエンコードするために使用される VAE モデルです。 | VAE | はい |  |
| `プロンプト` | 生成する動画を説明するテキストプロンプトです。複数行および動的プロンプトをサポートします。 | STRING | はい |  |
| `幅` | 動画の幅（ピクセル単位、デフォルト: 1344）。 | INT | はい | 32 to MAX_RESOLUTION （ステップ 32） |
| `高さ` | 動画の高さ（ピクセル単位、デフォルト: 768）。 | INT | はい | 32 to MAX_RESOLUTION （ステップ 32） |
| `長さ` | 24 fps でのフレーム数。モデルの 17k+5 グリッドに切り上げられます（124 = 約5秒、学習済み範囲は約124～362、それより長いものは未検証）（デフォルト: 124）。 | INT | はい | 5 〜 3600 （ステップ 17） |
| `最初のフレーム` | 動画の最初のフレームとして使用される任意の画像です。キャンバス全体のサイズに引き伸ばされるため、アスペクト比は保持されません。入力バッチの最初の画像のみが使用されます。 | IMAGE | いいえ |  |
| `最後のフレーム` | 動画の最後のフレームとして使用される任意の画像です。アスペクト比を保持しながらキャンバスを覆うようにクロップされます。入力バッチの最初の画像のみが使用されます。 | IMAGE | いいえ |  |

`first_frame` および/または `last_frame` が指定された場合、キーフレーム画像は VAE でエンコードされ、それぞれフレーム 0 と最終フレームのコンディショニングに付加されます。どちらも指定されない場合、ノードはプロンプトのみから処理します。要求された `length` は最も近い有効なフレーム数（17k + 5）に切り上げられるため、実効フレーム数は要求値よりわずかに大きくなる場合があります。

オーディオ・ビデオ潜在表現は、要求された `width`、`height`、および切り上げ後のフレーム数に一致する空のペアとして作成されます。オーディオ部分は同じフレーム数から、毎秒 40 オーディオフレームとしてサイズ設定されます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `positive` | エンコードされたプロンプトと、キーフレーム画像が提供された場合は MiniMax H3 モデル用のエンコード済みキーフレームおよびフレーム数を含むコンディショニングです。 | CONDITIONING |
| `latent` | 生成される内容を表す空のオーディオ・ビデオ潜在表現で、要求された幅、高さ、フレーム数を持ちます。 | LATENT |
