DualCFGGuider ノードは、デュアル分類器フリーガイダンスサンプリングのためのガイダンスシステムを作成します。2つの条件付け入力と1つのネガティブ条件付け入力を組み合わせ、2つの個別のガイダンススケールを適用して、各条件付けが生成出力に与える影響の強さを制御します。このガイダンススケールの組み合わせ方として、"regular" と "nested" の2つのスタイルをサポートしています。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | ガイダンスに使用するモデル | MODEL | はい | - |
| `cond1` | 最初のポジティブ条件付け入力 | CONDITIONING | はい | - |
| `cond2` | 2番目の条件付け入力。最初のポジティブ条件付けとネガティブ条件付けの間の参照として使用されます。 | CONDITIONING | はい | - |
| `ネガティブ` | ネガティブ条件付け入力 | CONDITIONING | はい | - |
| `cfg_conds` | 最初のポジティブ条件付けに適用されるガイダンススケール（デフォルト: 8.0） | FLOAT | はい | 0.0 - 100.0 |
| `cfg_cond2_negative` | 2番目の条件付けとネガティブ条件付けの間に適用されるガイダンススケール（デフォルト: 8.0） | FLOAT | はい | 0.0 - 100.0 |
| `style` | 適用するガイダンススタイル（デフォルト: "regular"）。"nested" に設定すると、ガイダンスが入れ子方式で適用されます。 | COMBO | はい | "regular"<br />"nested" |

注: `regular` スタイルでは、`cfg_cond2_negative` は `cond2` と `negative` の間に適用され、`cfg_conds` は `cond1` と `cond2` の間に適用されます。`nested` スタイルでは、`cfg_conds` が最初に `cond1` と `cond2` の間に適用され、その後、得られた予測が `cfg_cond2_negative` を使用して `negative` から離れるようにガイダンスが適用されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `GUIDER` | サンプリングで使用するための設定済みガイダンスシステム | GUIDER |
