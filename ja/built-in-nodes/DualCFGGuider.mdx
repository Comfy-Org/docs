Dual CFG Guider ノードは、2 つのコンディショニング入力と 1 つのネガティブコンディショニング入力を併用するサンプリング用のガイダンスシステムを作成します。2 つの個別のガイダンススケールを適用して、各コンディショニングが生成結果に与える影響の強さを制御し、それらのスケールを組み合わせる 2 つの方法（"regular" と "nested"）をサポートします。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | ガイダンスに使用するモデル | MODEL | はい | - |
| `cond1` | 最初のポジティブコンディショニング入力 | CONDITIONING | はい | - |
| `cond2` | 2 番目のコンディショニング入力。最初のポジティブコンディショニングとネガティブコンディショニングの間の参照として使用されます | CONDITIONING | はい | - |
| `ネガティブ` | ネガティブコンディショニング入力 | CONDITIONING | はい | - |
| `cfg_conds` | 最初のポジティブコンディショニングに適用されるガイダンススケール（デフォルト: 8.0） | FLOAT | はい | 0.0 - 100.0 |
| `cfg_cond2_negative` | 2 番目のコンディショニングとネガティブコンディショニングの間に適用されるガイダンススケール（デフォルト: 8.0） | FLOAT | はい | 0.0 - 100.0 |
| `style` | 適用するガイダンススタイル（デフォルト: "regular"）。"nested" に設定すると、ガイダンスはネスト方式で適用されます | COMBO | はい | "regular"<br />"nested" |

注: `regular` スタイルでは、`cfg_cond2_negative` は `cond2` と `negative` の間に適用され、`cfg_conds` は `cond1` と `cond2` の間に適用されます。`nested` スタイルでは、`cfg_conds` が最初に `cond1` と `cond2` の間に適用され、その結果得られた予測は `cfg_cond2_negative` を使用して `negative` から遠ざかるようにガイドされます。

注: `regular` スタイルでは、`cfg_cond2_negative` が 1.0 に等しい場合、ネガティブコンディショニングはスキップされ、`cfg_conds` も 1.0 に等しい場合、2 番目のコンディショニングもスキップされます。これにより、実行されるモデル評価の回数が削減されます。
