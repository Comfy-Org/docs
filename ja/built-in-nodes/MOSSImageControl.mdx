MOSS-Image カラー/デプス制御アダプターのカラー領域マップとデプスマップをコンディショニングに追加します。ポジティブとネガティブのコンディショニング、VAE、およびいずれか一方または両方のマップを接続します。マップは潜在表現にエンコードされ、カラー/デプス制御信号として結合され、選択したサンプリング区間のコンディショニングに付加されます。LoRA ローダーで読み込んだ MOSS-Image 制御アダプターと組み合わせて使用します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 制御信号を付加するポジティブコンディショニングです。 | CONDITIONING | はい | N/A |
| `negative` | 制御信号を付加するネガティブコンディショニングです。 | CONDITIONING | はい | N/A |
| `vae` | マップを潜在表現にエンコードするために使用する VAE です。 | VAE | はい | N/A |
| `color_map` | 出力サイズで、領域ごとに 1 つのフラットカラーを指定します。色は領域 ID としてのみ使用されます。 | IMAGE | いいえ | N/A |
| `depth_map` | 出力サイズのデプスマップです。近いほど白になります。 | IMAGE | いいえ | N/A |
| `strength` | マップの画像トークンへの寄与をスケーリングします。0.0 はマップなしと同じで、1.0 は学習時の強度です（デフォルト: 1.0）。 | FLOAT | はい | 0.0～10.0（ステップ0.01） |
| `start_percent` | 制御を開始するサンプリングパーセントです（デフォルト: 0.0）。 | FLOAT | はい | 0.0～1.0（ステップ0.001） |
| `end_percent` | 制御を終了するサンプリングパーセントです。早めに終了するとレイアウトとデプスを維持しつつ、残りのステップで形状が緩くなります（デフォルト: 1.0）。 | FLOAT | はい | 0.0～1.0（ステップ0.001） |

**注記:** `color_map` と `depth_map` の少なくとも一方を接続してください。どちらもない場合、ノードはコンディショニングを変更せずに返します。不足しているマップはゼロで置き換えられるため、カラーのみおよびデプスのみの構成でも動作します。2 つのマップのサイズが異なる場合、小さい方が他方のサイズに拡大されます。このノードは ComfyUI では実験的としてマークされています。
