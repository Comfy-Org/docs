Reve Image Edit ノードは、自然言語のテキスト指示に基づいて既存の画像を変更します。入力画像と指示内容を Reve API に送信し、要求された編集が適用された新しい画像が返されます。

## 入力

`model` セレクターは、表示されるモデル固有の入力を決定します。`upscale` セレクターは、アップスケール係数の入力が利用可能かどうかを制御します。

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | 編集する画像です。 | IMAGE | はい | - |
| `編集指示` | 画像の編集方法を説明するテキストです。最大2560文字です。 | STRING | はい | - |
| `モデル` | 編集に使用するモデルバージョンです。 | DYNAMIC_COMBO | はい | `"reve-edit@20250915"`<br />`"reve-edit-fast@20251030"` |
| `アップスケール` | 生成された画像をアップスケールします。追加コストがかかる場合があります。(デフォルト: "disabled") | DYNAMIC_COMBO | いいえ | `"disabled"`<br />`"enabled"` |
| `背景を削除` | 生成された画像から背景を削除します。追加コストがかかる場合があります。(デフォルト: False) | BOOLEAN | いいえ | `true`<br />`false` |
| `シード` | シードはノードを再実行するかどうかを制御します。結果はシードに関係なく非決定的です。(デフォルト: 0) | INT | いいえ | 0〜2147483647 |

### モデル入力（`reve-edit@20250915` と `reve-edit-fast@20251030` で共通）

両方のモデルバージョンで、同じモデル固有の入力が公開されています。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `アスペクト比` | 出力画像のアスペクト比です。"auto" に設定すると、アスペクト比は自動的に決定されます。 | COMBO | いいえ | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"3:2"`<br />`"2:3"`<br />`"4:3"`<br />`"3:4"`<br />`"1:1"` |
| `テスト時スケーリング` | 上級者向けオプションです。値が大きいほど高品質な画像が生成されますが、より多くのクレジットを消費します。(デフォルト: 1) | INT | いいえ | 1〜5 |

### アップスケール入力（`upscale` が "enabled" に設定されている場合）

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `upscale.upscale_factor` | アップスケール係数（2倍、3倍、または4倍）です。(デフォルト: 2) | INT | いいえ | 2〜4 |

**注意：**

- `upscale.upscale_factor` は、`upscale` が "enabled" に設定されている場合にのみ適用されます。アップスケーリングと背景除去は、同時に、または個別に有効にすることができます。
- `edit_instruction` は空にすることはできず、2560文字を超えることもできません。
- `model.aspect_ratio` が "auto" に設定されている場合、固定のアスペクト比は API に送信されず、アスペクト比が自動的に選択されます。
- `model.test_time_scaling` は、値が1より大きい場合にのみ API に送信されます。デフォルト値の1は API のデフォルト動作を維持します。
- 結果はシード値に関係なく非決定的です。シードはノードが再実行されるかどうかのみを制御します。
- このノードは非推奨としてマークされています。
- おおよその費用（USD、ノードの価格バッジによる）：`reve-edit-fast@20251030` は `$0.01001`、`reve-edit@20250915` はアップスケールなしで `$0.0572`、2倍アップスケールで `$0.0686`、3倍アップスケールで `$0.0819`、4倍アップスケールで `$0.0991` です。

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 指示に基づいて生成された編集済み画像です。 | IMAGE |
