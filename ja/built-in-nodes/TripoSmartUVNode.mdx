Tripo: Smart UV はモデルの UV を再展開し、そのテクスチャ、リグ、アニメーションを新しいレイアウトに再マッピングします。モデル本来の UV レイアウトが使用できない場合、たとえばリトポロジ後やテクスチャの継ぎ目をやり直す必要がある場合に使用します。入力モデルは 80,000 三角形以下である必要があります（クアッドは 2 三角形として数えます）。そのため、より大きなモデルは先に Tripo: Retopology または `face_limit` で削減してください。

> **注意:** Tripo はタスク記録をサーバー上に 7 日間保持します（2026年12月1日より有効）。それより古いタスク ID は解決できなくなるため、保持期間を過ぎて保存済みワークフローを再実行すると、このノードで失敗します。新しいタスク ID を作成するには、前段の Tripo ノードを再度実行するか、ダウンロード済みのモデルを **Tripo: Import Model** で再インポートしてください。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | 再展開するモデルのタスク ID。Tripo 生成ノードからのモデルタスク ID、またはリグ、リターゲット、セグメントのタスク ID を受け付けます。 | MODEL_TASK_ID | はい | Tripo タスク ID |
| `bake` | 既存のテクスチャを新しい UV レイアウトにベイクします。オフにするとベイクをスキップし、カラーテクスチャのないモデルを返します（デフォルト: True）。 | BOOLEAN | はい | `True`<br />`False` |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model task_id` | 完了した UV タスクのタスク ID。他の Tripo ノード（例: Tripo: Texture）に渡すことができます。 | MODEL_TASK_ID |
| `GLB` | 再展開されたモデル（GLB 形式）。ソースモデルが FBX の場合は空になります。 | GLB FILE |
| `FBX` | 再展開されたモデル（FBX 形式）。ソースモデルが FBX の場合（例: クアッドメッシュ）にのみ設定されます。 | FBX FILE |
| `UV atlas` | モデルの UV レイアウトを画像としてレンダリングしたもの。 | IMAGE |
