Tripo: Smart UV は、モデルの UV を再展開し、そのテクスチャ、リグ、アニメーションを新しいレイアウトに再マッピングします。モデル本来の UV レイアウトが使用できない場合（たとえばリトポロジー後や、テクスチャの継ぎ目をやり直す必要がある場合）に使用します。入力モデルは 80,000 三角形を超えてはいけません（クアッドは 2 三角形として数えます）。そのため、より大きなモデルは先に Tripo: Retopology または `face_limit` で削減してください。

> **注意:** Tripo はタスクレコードをサーバー上に 7 日間保持します（2026年12月1日より有効）。それより古いタスク ID は解決できなくなるため、保存されたワークフローをこの期間の経過後に再実行すると、このノードで失敗します。タスクを生成した上流の Tripo ノードを再実行するか、ダウンロード済みのモデルを **Tripo: Import Model** で再インポートしてください。期間が終了する前にモデルをダウンロードしてください。期限切れのアセットはタスクレコードから復元できません。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | 再展開するモデルのタスク ID。Tripo の生成ノードからのモデルタスク ID、またはリグ、リターゲット、セグメントのタスク ID を受け付けます。 | MODEL_TASK_ID | はい | Tripo タスク ID |
| `bake` | 既存のテクスチャを新しい UV レイアウトにベイクします。オフにするとベイクをスキップし、カラーテクスチャを含まないモデルを返します（デフォルト: True）。 | BOOLEAN | はい | `True`<br />`False` |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model task_id` | 完了した UV タスクのタスク ID。他の Tripo ノード（例: Tripo: Texture）に渡せます。 | MODEL_TASK_ID |
| `GLB` | UV 再展開済みのモデル（GLB 形式）。ソースモデルが FBX の場合は空です。 | FILE_3D_GLB |
| `FBX` | UV 再展開済みのモデル（FBX 形式）。ソースモデルが FBX の場合（たとえばクアッドメッシュ）にのみ設定されます。 | FILE_3D_FBX |
| `UV atlas` | モデルの UV レイアウトを画像としてレンダリングしたもの。 | IMAGE |
