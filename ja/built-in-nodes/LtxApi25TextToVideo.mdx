LTX 2.5 Text To Video は、LTX 2.5 モデルを使用してテキスト記述からプロフェッショナル品質の動画を生成する API ノードです。プロンプトを入力し、モデルティア、動画の長さ、解像度、フレームレート、音声を含めるかどうかなどの生成設定を選択します。ノードはタスクを LTX API に送信し、生成された動画を返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 動画生成に使用する LTX 2.5 モデルティア。 | STRING | 必須 | "LTX-2.5 (Fast)"<br />"LTX-2.5 (Pro)" |
| `長さ` | 生成される動画の長さ。 | INT | 必須 | Integer |
| `解像度` | 動画の出力解像度。選択した `model` によって利用可能なオプションが異なります。 | STRING | 必須 | With "LTX-2.5 (Fast)":<br />"1280x720"<br />"720x1280"<br />"1920x1080"<br />"1080x1920"<br />"2560x1440"<br />"1440x2560"<br />"3840x2160"<br />"2160x3840"<br />With "LTX-2.5 (Pro)":<br />"1280x720"<br />"720x1280"<br />"1920x1080"<br />"1080x1920" |
| `fps` | 生成される動画のフレームレート（デフォルト: 25）。 | INT | 任意 | Integer |
| `オーディオ生成` | 動画と一緒に音声を生成するかどうか（デフォルト: True）。 | BOOLEAN | 任意 | True<br />False |
| `プロンプト` | 生成する動画のテキスト記述。10,000 文字以内の空でないプロンプトが必要です（デフォルト: ""）。 | STRING | 必須 | 1〜10000 characters |
| `シード` | 再現性のある生成に使用するシード値（デフォルト: 42）。 | INT | 任意 | Integer |

注: 利用可能な `model.resolution` オプションは、選択した `model` によって異なります。「LTX-2.5 (Fast)」は 2160x3840 までの解像度をサポートし、「LTX-2.5 (Pro)」は 1920x1080 までの解像度をサポートします。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `video` | LTX API によって返された生成動画。ワークフロー内でさらに使用する準備ができています。音声生成が有効な場合、動画には同期された音声が含まれます。 | VIDEO |
