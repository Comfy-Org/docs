SaveLatent は、潜在テンソルを `.latent` ファイルとしてディスクに保存し、後で再利用または共有できるようにします。潜在サンプルを受け取り、自動生成された名前で出力フォルダに書き込み、プロンプトなどのワークフローメタデータを保存ファイルに埋め込むことができます。同じ潜在サンプルは、そのまま変更されずに後続の処理へ渡されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `サンプル` | ディスクに保存する潜在サンプル。 | LATENT | はい | - |
| `ファイル名_プレフィックス` | 出力ファイル名を作成するために使用されるプレフィックスです。サブフォルダを含めることができます。例: "latents/ComfyUI"（デフォルト: "latents/ComfyUI"）。 | STRING | はい | - |
| `prompt` | ワークフロープロンプト。JSONとしてシリアライズされ、保存ファイルのメタデータに格納されます（隠しパラメータで、自動的に供給されます）。 | PROMPT | いいえ | - |
| `extra_pnginfo` | 追加のワークフロー情報。JSONとしてシリアライズされ、保存ファイルのメタデータに格納されます（隠しパラメータで、自動的に供給されます）。 | EXTRA_PNGINFO | いいえ | - |

注: 各保存ファイルはプレフィックスと5桁のカウンターを使用して命名されます。例: `ComfyUI_00001_.latent` のように出力ディレクトリに配置されます。ファイルには潜在テンソルと潜在フォーマットのバージョンマーカーが含まれます。メタデータは、メタデータサポートが有効な場合、つまり ComfyUI が `--disable-metadata` オプションを指定せずに起動された場合にのみ、保存ファイルに埋め込まれます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `samples` | 入力として提供されたものと同じ潜在サンプルを、変更せずにそのまま渡します。 | LATENT |
| `ui` | 保存ファイルを説明するインターフェース表示データ：ファイル名、サブフォルダ、出力タイプ（"output"）。 | UI |
