プロンプトと解像度に基づいて画像を同期的に生成します。このノードは Recraft API に接続し、指定された寸法とオプションのスタイル・コントロールパラメータを使用して、テキスト記述から画像を作成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `プロンプト` | 画像生成用のプロンプト。(デフォルト: "") | STRING | はい | - |
| `サイズ` | 生成される画像のサイズ。(デフォルト: "1024x1024") | COMBO | はい | "1024x1024"<br />"1152x896"<br />"896x1152"<br />"1216x832"<br />"832x1216"<br />"1344x768"<br />"768x1344"<br />"1536x640"<br />"640x1536" |
| `枚数` | 生成する画像の数。(デフォルト: 1) | INT | はい | 1-6 |
| `シード` | ノードを再実行するかどうかを決定するシード。実際の結果はシードに関係なく非決定的です。(デフォルト: 0) | INT | はい | 0-18446744073709551615 |
| `recraft_style` | 画像生成用のオプションのスタイル選択。指定しない場合、デフォルトで "realistic_image" スタイルになります。 | RECRAFT_STYLE | いいえ | 複数のオプションが利用可能 |
| `ネガティブプロンプト` | 画像上の望ましくない要素のオプションのテキスト説明。(デフォルト: "") | STRING | いいえ | - |
| `Recraftコントロール` | Recraft Controls ノードによる生成へのオプションの追加コントロール。 | RECRAFT_CONTROLS | いいえ | 複数のオプションが利用可能 |

**注記:** `seed` パラメータはノードが再実行されるタイミングを制御するだけで、画像生成を決定的にするものではありません。同じシード値でも実際の出力画像は異なります。

**注記:** `prompt` パラメータの長さは 1 文字以上 1000 文字以下である必要があります。

**注記:** Infinite Style Library の `style_id` を使用する場合、Vector アートスタイルではないことを確認してください。Vector アートスタイルの場合、画像の代わりに SVG データが返され、エラーが発生します。

**注記:** これは有料の API ノードです。コストは `n` の値に基づき、生成画像 1 枚あたり $0.04 です。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | バッチテンソル出力としての生成画像。複数の画像が生成された場合 (n > 1)、バッチ次元に沿って連結されます。 | IMAGE |
