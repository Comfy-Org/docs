3DモデルをComfyUIの出力ディレクトリ内のファイルに保存し、保存されたシーンのプレビューを生成します。また、3Dモデル、シーン内での配置、カメラ情報、ビューポートの寸法を下流ノードへ渡します。モデル配置またはカメラ情報が接続されていない場合、ノードはビューポート状態に保存されている値を使用します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 上流の3Dノードからの3Dモデルファイル。 | FILE3D | はい | GLB<br />GLTF<br />FBX<br />OBJ<br />STL<br />USDZ<br />Any |
| `filename_prefix` | 保存されるファイル名に使用されるプレフィックス（デフォルト: "3d/ComfyUI"）。 | STRING | はい | 自由テキスト |
| `viewport_state` | カメラとモデル配置の情報を含むビューポート状態。通常は Load 3D ノードから取得されます。 | LOAD3D | はい | - |
| `model_3d_info` | シーン内の各モデルの配置：位置、回転、スケール（Y-up ワールド空間）。接続されている場合、`viewport_state` に保存されているモデル配置を上書きします。 | LOAD3DMODELINFO | いいえ | - |
| `camera_info` | ビューポートカメラ情報：位置、注視点、ズーム、タイプ。接続されている場合、`viewport_state` に保存されているカメラ情報を上書きします。 | LOAD3DCAMERA | いいえ | - |
| `width` | ビューポートのレンダリング幅（ピクセル単位、デフォルト: 1024）。 | INT | はい | 1 〜 4096 |
| `height` | ビューポートのレンダリング高さ（ピクセル単位、デフォルト: 1024）。 | INT | はい | 1 〜 4096 |

注: `model_3d_info` と `camera_info` はオプションです。どちらかの入力が接続されていない場合、ノードは `viewport_state` に保存されている対応する値にフォールバックします。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_3d` | 入力からそのまま渡された3Dモデルファイル。 | FILE3D |
| `model_3d_info` | シーン内の各モデルの配置：位置、回転、スケール（Y-up ワールド空間）。 | LOAD3DMODELINFO |
| `camera_info` | ビューポートカメラ情報：位置、注視点、ズーム、タイプ。 | LOAD3DCAMERA |
| `width` | 入力からそのまま渡されたレンダリング幅の値。 | INT |
| `height` | 入力からそのまま渡されたレンダリング高さの値。 | INT |
