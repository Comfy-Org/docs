WeVisOne-VL Detect は、テキストプロンプトに基づいて画像内のオブジェクトを検出し、選択したタスクに応じてボックス、アルファマット、ポイント、またはモデル自身の回答を返します。オープンボキャブラリ検出とセグメンテーション、参照表現、ポインティング、カウント、OCR グラウンディングをカバーし、バッチ内の画像ごとに 1 つのプロンプトを実行します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `clip` | チェックポイントを読み込む WeVisOne-VL テキストエンコーダーです。 | CLIP | はい | - |
| `image` | 検索対象の画像または画像バッチです。 | IMAGE | はい | - |
| `task` | ノードが返す内容です。segmentation はボックスとアルファマットを返します。detection、referring、ocr、ocr_grounding はボックスを返します。point と count_point はポイントを返します。count_box はボックス付きでカウントします。visual_prompt は `bboxes` 内の参照ボックスに類似したオブジェクトを検出します。freeform はクエリを変更せずに送信し、テキストのみを返します（デフォルト："segmentation"）。 | COMBO | はい | `"segmentation"`<br />`"detection"`<br />`"referring"`<br />`"point"`<br />`"count_box"`<br />`"count_point"`<br />`"ocr"`<br />`"ocr_grounding"`<br />`"visual_prompt"`<br />`"freeform"` |
| `query` | 見つける対象を平易な言葉で指定します（例："the red mug"）。`detection` と `point` は 1 行につき 1 つのラベルを読み取ります。`count_box` と `count_point` は指定した対象をカウントします。`ocr_grounding` はこの正確なテキストを探します。`visual_prompt` は代わりに `bboxes` を使用します。`freeform` はこれをプロンプト全体として送信します。`ocr` はこれを無視します。 | STRING | はい | - |
| `bboxes` | `visual_prompt` が検出対象オブジェクトの例として使用する参照ボックスです。 | BOUNDING_BOX | いいえ | - |
| `individual_masks` | フレームごとに 1 つの結合マットを返す代わりに、`bboxes` 出力の検出ボックスごとに 1 つのマットをフレーム単位で返します（デフォルト: false）。 | BOOLEAN | いいえ | true<br />false |
| `max_length` | モデルが回答のために生成できるトークンの最大数です（デフォルト: 4096）。 | INT | はい | 1～32768 |

**注記:** マットに値が入るのは、モデルがオブジェクト参照を含む回答を返した場合のみです。これは segmentation タスクが求める内容です。その他のタスクは、空のマットとともにボックス、ポイント、またはテキストを返します。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `masks` | 一致したオブジェクトのアルファマットです。デフォルトではフレームごとに 1 つ、`individual_masks` を指定するとボックスごとに 1 つです。 | MASK |
| `bboxes` | 各画像で見つかったボックスです。`x`、`y`、`width`、`height`、`label` として保存されます。 | BOUNDING_BOX |
| `points` | ピクセル単位の JSON 形式のポイントです。形状は `[{"x", "y", "label", "frame"}]` で、`point` および `count_point` タスクによって埋められます。 | STRING |
| `text` | モデルの生の回答です。画像ごとに 1 行です。 | STRING |
