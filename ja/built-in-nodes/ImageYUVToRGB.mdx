# イメージ YUV から RGB

ImageYUVToRGB ノードは、イメージを YUV 色空間から RGB 色空間に変換するために設計されています。これを行うために、イメージの Y（輝度）、U（青色プロジェクション）、V（赤色プロジェクション）チャンネルを表す3つの異なる入力イメージを取得し、これらのチャンネルを色空間変換技術を使用して単一の RGB イメージに組み合わせます。

## 概要

ImageYUVToRGB ノードは、YUV イメージを RGB イメージに変換することで、これら二つの標準間の色空間変換が必要なアプリケーションに有用です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 范囲 |
|------------|------|----------|------|-------|
| `Y`        | Yチャンネルの入力イメージ、輝度情報を表す。 | IMAGE | はい | - |
| `U`        | Uチャンネルの入力イメージ、青色差分を表す。 | IMAGE | はい | - |
| `V`        | Vチャンネルの入力イメージ、赤色差分を表す。 | IMAGE | はい | - |

**注意:** Y、U、Vチャンネルは一緒に提供され、正確な変換を確保するために同じサイズである必要があります。

## 出力

| 出力名 | 説明 | データ型 |
|--------|------|----------|
| `output` | YUVからRGB変換後の結果となるRGBイメージ。 | IMAGE |

出力イメージは、入力のY、U、Vイメージと同じサイズですが、RGB色空間で色情報が表現されます。
