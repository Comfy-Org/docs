### Remesh Mesh

Remesh Mesh は、元のサーフェスの周囲にある狭帯域距離フィールドをサンプリングし、Dual Contouring（デュアルコンタリング）で抽出することで、クリーンで均一なテッセレーションを持つメッシュを再構築します。これにより、乱雑な非多様体、または自己交差するトポロジーが正規化され、正確な面数を達成するために Decimate Mesh の前に実行することを目的としています。処理はアクティブな計算デバイス上で実行され、出力メッシュは溶接された状態を維持します。

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|------|----------|------|------|
| `mesh` | リメッシュする入力メッシュ。 | MESH | はい | — |
| `resolution` | ボクセルグリッド解像度（出力密度）。256で約10万面、512で約100万面。正確な面数を求める場合は、後続の Decimate Mesh を使用してください。（デフォルト: 512） | INT | はい | 32 - 2048 |
| `sign_mode` | サーフェス抽出に使用する符号付き距離モード。「udf」は乱雑な/非多様体の入力に対して堅牢です。「sdf」はQEF（二次誤差関数）によるシャープな特徴の復元を備えたクリーンな単一サーフェスを生成しますが、一貫した巻き方向が必要です。モードを選択すると、そのモード固有のサブオプションが表示されます。（デフォルト: "udf"） | DYNAMIC_COMBO | はい | "udf"<br />"sdf" |
| `band` | ボクセル単位での狭帯域幅。UDFモードではサーフェスもオフセットします。（上級者向け、デフォルト: 1.0） | FLOAT | はい | 0.5 - 4.0 |
| `project_back` | 頂点を元のサーフェスに向かって線形補間します（0 = 純粋なDC、1 = スナップ）。（上級者向け、デフォルト: 0.0） | FLOAT | はい | 0.0 - 1.0 |
| `fix_poles` | 価数3の頂点ペアを崩します（DC Tジャンクションのアーティファクト）。（上級者向け、デフォルト: false） | BOOLEAN | はい | true / false |
| `smooth_iters` | Taubinスムージングの反復回数（0 = オフ）。2〜3回でDCの階段状アーティファクトが除去されます。それ以上ではQEFエッジを過剰にスムージングします。（デフォルト: 0） | INT | はい | 0 - 20 |
| `drop_small_components` | 最大コンポーネントの面数に対するこの割合未満のコンポーネントを削除します。0で無効化。（上級者向け、デフォルト: 0.01） | FLOAT | はい | 0.0 - 0.5 |
| `precluster_max_verts` | フィールドクエリ前に入力頂点数を制限します。これを超える入力は、最初にクラスタ間引きでこの数まで減らされます。巨大なメッシュでのOOM（メモリ不足）を防ぎます。（上級者向け、デフォルト: 20,000,000） | INT | はい | 0 - 100,000,000 |

### "udf" モード入力

これらのパラメータは、`sign_mode` が `"udf"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|------|----------|------|------|
| `qef` | シャープなエッジを実現するQEF（二次誤差関数）によるデュアル頂点配置。（デフォルト: false） | BOOLEAN | いいえ | true / false |
| `drop_inverted_components` | 内向き法線（負の体積）を持つ閉じたコンポーネント（UDF内部シェル）を削除します。（デフォルト: false） | BOOLEAN | いいえ | true / false |
| `drop_enclosed_components` | 最大コンポーネントのバウンディングボックス内にあって、メッシュ内外判定のレイキャストに失敗したコンポーネントを削除します。正当な入れ子構造の部品がある場合は無効にしてください。（デフォルト: false） | BOOLEAN | いいえ | true / false |

### "sdf" モード入力

これらのパラメータは、`sign_mode` が `"sdf"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|------|----------|------|------|
| `qef` | QEF（二次誤差関数）によるデュアル頂点配置（シャープな特徴を復元）と、エッジ交差重心のどちらを使用するか。（デフォルト: true） | BOOLEAN | いいえ | true / false |
| `manifold` | 多様体デュアルコンタリング：マルチシートの場合、ボクセルあたり1〜4個のデュアル頂点を使用します。低速です。（デフォルト: false） | BOOLEAN | いいえ | true / false |

注：`qef` オプションのデフォルトは選択されたモードによって異なります — "udf" モードでは false、"sdf" モードでは true です。`precluster_max_verts` が0より大きく、入力メッシュの頂点数がこの値より多い場合、フィールドクエリの前にメッシュはその目標値までクラスタ間引きされます。処理後、ノードには入力から出力への面数の変化が表示されます（例: "faces: 1.23M → 200K (-84%)"）。
