Remesh Mesh は、元のサーフェス周辺のナローバンド距離場をサンプリングし、Dual Contouring で抽出することで、メッシュをクリーンで均一なテッセレーションに再構築します。これにより、乱れた非多様体（non-manifold）や自己交差するトポロジーが正規化され、正確な面数に到達するために Decimate Mesh の前に実行することを想定しています。処理はアクティブな計算デバイス上で実行され、出力メッシュは溶接（welded）された状態を維持します。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 再メッシュ化する入力メッシュ。 | MESH | はい | — |
| `resolution` | ボクセルグリッド解像度（出力密度）。256 で約 10 万面、512 で約 100 万面。正確な面数が必要な場合は、続けて Decimate Mesh を使用します。（デフォルト: 512） | INT | はい | 32 - 2048 |
| `sign_mode` | サーフェス抽出モード。“udf” は乱れた非多様体入力に対してロバストで、“sdf” は QEF（二次誤差関数）によるシャープな特徴の復元を備えたクリーンな単一サーフェスを生成しますが、一貫した巻き方向が必要です。モードを選択すると、そのモード固有のサブオプションが表示されます。（デフォルト: "udf"） | DYNAMIC_COMBO | はい | "udf"<br />"sdf" |
| `band` | ナローバンドの幅（ボクセル単位）。UDF モードではサーフェスをオフセットする効果もあります。（詳細設定、デフォルト: 1.0） | FLOAT | はい | 0.5 - 4.0 |
| `project_back` | 頂点を元のサーフェスに向けて線形補間します（0 = 純粋な DC、1 = スナップ）。（詳細設定、デフォルト: 0.0） | FLOAT | はい | 0.0 - 1.0 |
| `fix_poles` | valence-3 の頂点ペアを畳み込むことで、DC に起因する T-junction（T字継ぎ目）のアーティファクトを除去します。（詳細設定、デフォルト: false） | BOOLEAN | はい | true / false |
| `smooth_iters` | Taubin スムージングの反復回数（0 = オフ）。2 〜 3 回で DC の階段状のアーティファクトを除去し、それ以上では QEF エッジを平滑化しすぎます。（デフォルト: 0） | INT | はい | 0 - 20 |
| `drop_small_components` | 最大コンポーネントの面数に対する比率より小さいコンポーネントを削除します。0 で無効化。（詳細設定、デフォルト: 0.01） | FLOAT | はい | 0.0 - 0.5 |
| `precluster_max_verts` | フィールドクエリの前に入力頂点数を制限します。この値を超える入力は、まずクラスターデシメーションでこの値まで削減されます。巨大なメッシュでのメモリ不足（OOM）を防ぎます。（詳細設定、デフォルト: 20,000,000） | INT | はい | 0 - 100,000,000 |

### "udf" モード入力

これらのパラメータは、`sign_mode` が `"udf"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `qef` | よりシャープなエッジを実現するための QEF（二次誤差関数）によるデュアル頂点配置。（デフォルト: false） | BOOLEAN | いいえ | true / false |
| `drop_inverted_components` | 内側を向いた法線（負のボリューム）を持つ閉コンポーネント（UDF の内部シェル）を削除します。（デフォルト: false） | BOOLEAN | いいえ | true / false |
| `drop_enclosed_components` | 最大コンポーネントのバウンディングボックス内にあり、メッシュ内外判定（point-in-mesh）のレイキャストを通過しないコンポーネントを削除します。正当な入れ子状のパーツがある場合は無効にしてください。（デフォルト: false） | BOOLEAN | いいえ | true / false |

### "sdf" モード入力

これらのパラメータは、`sign_mode` が `"sdf"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `qef` | QEF（二次誤差関数）によるデュアル頂点配置（シャープな特徴を復元）と、エッジ交差重心（edge-crossing centroid）による配置のどちらを使用するかを選択します。（デフォルト: true） | BOOLEAN | いいえ | true / false |
| `manifold` | Manifold Dual Contouring: マルチシート（多層）ケースではボクセルあたり 1 〜 4 個のデュアル頂点を生成します。低速です。（デフォルト: false） | BOOLEAN | いいえ | true / false |

注: `qef` オプションのデフォルトは選択されたモードによって異なります——“udf” モードでは false、“sdf” モードでは true です。`precluster_max_verts` が 0 より大きく、入力メッシュの頂点数がこの値を超えている場合、フィールドクエリの前にメッシュはこの値までクラスターデシメーションされます。処理後、ノードは入力から出力への面数の変化をノード上に表示します（例: "faces: 1.23M → 200K (-84%)"）。
