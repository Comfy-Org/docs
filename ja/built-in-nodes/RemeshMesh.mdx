Remesh Mesh は、元のサーフェス周囲の狭帯域距離場をサンプリングし、Dual Contouring で抽出することにより、クリーンで均一なテッセレーションを持つメッシュを再構築します。これにより、乱雑な、非多様体、または自己交差したトポロジーが正規化され、正確な面数に到達するために Decimate Mesh の前に実行することを意図しています。処理はアクティブなコンピュートデバイス上で実行され、出力メッシュは溶接された状態のままです。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 再メッシュ化する入力メッシュ。 | MESH | はい | — |
| `resolution` | ボクセルグリッド解像度（出力密度）。256 で約 100k 面、512 で約 1M 面。正確な面数が必要な場合は、続けて Decimate Mesh を使用してください。（デフォルト: 512） | INT | はい | 32 - 2048 |
| `sign_mode` | サーフェス抽出モード。"udf" は乱雑な/非多様体入力に対して堅牢です。"sdf" は QEF（二次誤差関数）によるシャープフィーチャ復元を伴うクリーンな単一サーフェスを生成しますが、一貫した巻き方向が必要です。モードを選択すると、そのモード固有のサブオプションが表示されます。（デフォルト: "udf"） | DYNAMIC_COMBO | はい | "udf"<br />"sdf" |
| `band` | ボクセル単位の狭帯域幅。UDF モードではサーフェスもオフセットします。（詳細設定、デフォルト: 1.0） | FLOAT | はい | 0.5 - 4.0 |
| `project_back` | 頂点を元のサーフェスに向かって線形補間します（0 = 純粋な DC、1 = スナップ）。（詳細設定、デフォルト: 0.0） | FLOAT | はい | 0.0 - 1.0 |
| `fix_poles` | 価数 3 の頂点ペア（DC T ジャンクションアーティファクト）を折りたたみます。（詳細設定、デフォルト: false） | BOOLEAN | はい | true / false |
| `smooth_iters` | Taubin スムージングの反復回数（0 = オフ）。2～3 で DC の階段状アーティファクトをきれいにします。それ以上では QEF エッジを過剰にスムージングします。（デフォルト: 0） | INT | はい | 0 - 20 |
| `drop_small_components` | 最大コンポーネントの面数に対するこの割合を下回るコンポーネントを削除します。0 で無効になります。（詳細設定、デフォルト: 0.01） | FLOAT | はい | 0.0 - 0.5 |
| `precluster_max_verts` | フィールドクエリの前に、入力頂点数に上限を設定します。これを超える入力は、まずこの値までクラスタ間引きされます。巨大なメッシュでの OOM を防ぎます。（詳細設定、デフォルト: 20,000,000） | INT | はい | 0 - 100,000,000 |

### "udf" モード入力

これらのパラメータは、`sign_mode` が `"udf"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `qef` | よりシャープなエッジのための QEF（二次誤差関数）デュアル頂点配置。（詳細設定、デフォルト: false） | BOOLEAN | いいえ | true / false |
| `drop_inverted_components` | 内向き法線（負の体積）の閉じたコンポーネント — UDF 内部シェル — を削除します。（詳細設定、デフォルト: false） | BOOLEAN | いいえ | true / false |
| `drop_enclosed_components` | 最大コンポーネントの bbox 内にあり、point-in-mesh レイキャストに失敗するコンポーネントを削除します。正当なネストされたパーツでは無効にしてください。（詳細設定、デフォルト: false） | BOOLEAN | いいえ | true / false |

### "sdf" モード入力

これらのパラメータは、`sign_mode` が `"sdf"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `qef` | QEF（二次誤差関数）デュアル頂点配置（シャープなフィーチャを復元）を使用するか、エッジ交差重心を使用するか。（デフォルト: true） | BOOLEAN | いいえ | true / false |
| `manifold` | マニフォールド Dual Contouring：マルチシートの場合、1 ボクセルあたり 1～4 個のデュアル頂点。処理は遅くなります。（デフォルト: false） | BOOLEAN | いいえ | true / false |

注: `qef` オプションのデフォルト値は、選択したモードによって異なります — "udf" モードでは false、"sdf" モードでは true です。`precluster_max_verts` が 0 より大きく、入力メッシュの頂点数がこの値より多い場合、フィールドクエリの前にメッシュはそのターゲットまでクラスタ間引きされます。処理後、ノードは入力から出力への面数の変化をノード上に表示します（例: "faces: 1.23M → 200K (-84%)"）。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `mesh` | 均一なテッセレーションと溶接されたトポロジーを持つ再メッシュ化されたメッシュ。入力に頂点カラーが存在する場合は保持されます。UV、法線、タンジェントは引き継がれません。 | MESH |
