このノードは、Bria を使用して画像の前景を削除し、その場所に新しい背景を生成します。Bria が前景として識別したものはすべて削除され、人物だけに限られません。また、未変更のピクセルは保持されます。結果は約1メガピクセルに近い標準サイズで再レンダリングされます。

これは Bria のサービス上で実行される有料 API ノードであるため、各実行で Comfy API 認証情報が使用されます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | 前景が削除され、生成された背景に置き換えられる画像。カラーチャネルのみが送信され、アルファチャンネルはアップロード前に破棄されます。 | IMAGE | はい | - |
| `モデレーション` | モデレーション設定。モデレーションフラグを付けずに画像を送信するには `"false"` を選択し、以下のコンテンツモデレーション切り替えを表示するには `"true"` を選択します。デフォルト: `"false"`。 | DYNAMIC_COMBO | はい | `"false"`<br />`"true"` |

### `"false"` 入力

追加の入力はありません。リクエストはコンテンツモデレーションフラグなしで送信されます。

### `"true"` 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | 入力画像でコンテンツモデレーションを有効にします。デフォルト: false。 | BOOLEAN | はい | true<br />false |
| `visual_output_moderation` | 生成された出力画像でコンテンツモデレーションを有効にします。デフォルト: false。 | BOOLEAN | はい | true<br />false |

### 注意

- 出力は約1メガピクセルに近い標準サイズで再レンダリングされるため、返される画像の寸法は入力と異なる場合があります。
- このノードは有料 API ノードです。実行ごとに約 0.0572 USD のコストがかかります。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `IMAGE` | 前景が消去され、その場所に新しく生成された背景が配置された入力画像。 | IMAGE |
