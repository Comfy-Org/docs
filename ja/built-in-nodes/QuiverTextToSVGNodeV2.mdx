Quiver AI を使用して、テキストプロンプトからスケーラブルベクターグラフィック（SVG）を生成します。任意の参照画像とスタイル指示によって生成をガイドできます。

`model` を選択すると、以下に示すモデル固有のパラメータが表示されます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `モデル` | SVG 生成に使用するモデル。 | DYNAMIC_COMBO | はい | `"arrow-2"`<br />`"arrow-2-telos"` |
| `prompt` | 生成する SVG 出力のテキスト記述。少なくとも1文字以上が必要です（デフォルト: 空）。 | STRING | はい | 任意のテキスト |
| `instructions` | 追加のスタイルまたは書式設定のガイダンス。オプションの詳細パラメータです（デフォルト: 空）。 | STRING | いいえ | 任意のテキスト |
| `reference_images` | 拡張可能なスロット: 生成をガイドする1つ以上のオプションの参照画像（`ref_1`、`ref_2`、...）を接続します。画像の最大数は14です。 | IMAGE | いいえ | 最大14 |
| `width` | 出力 SVG キャンバス（viewBox）の幅（ユーザー単位）。出力サイズとアスペクト比を制御するには、`width` と `height` の両方を設定してください。どちらかを 0 のままにするとモデルに選択を任せ、通常は正方形のキャンバスになります。詳細パラメータです（デフォルト: 0）。 | INT | はい | 0～8192 |
| `height` | 出力 SVG キャンバス（viewBox）の高さ（ユーザー単位）。出力サイズとアスペクト比を制御するには、`width` と `height` の両方を設定してください。どちらかを 0 のままにするとモデルに選択を任せ、通常は正方形のキャンバスになります。詳細パラメータです（デフォルト: 0）。 | INT | はい | 0～8192 |
| `seed` | ノードを再実行すべきかを決定するシード。実際の結果はシード値に関係なく非決定的です。このパラメータには「生成後の制御」機能があります（デフォルト: 42）。 | INT | はい | 0～2147483647 |

### モデル固有の入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | モデルが描画前に費やす推論の量。レベルが高いほど詳細が向上し、より多くのトークンを消費します。`"arrow-2"` モデルと `"arrow-2-telos"` モデルでのみ使用されます（デフォルト: `"high"`）。 | COMBO | はい | `"low"`<br />`"medium"`<br />`"high"`<br />`"xhigh"` |
| `temperature` | ランダム性の制御。値が高いほどランダム性が増します。`"arrow-2-telos"` モデルでは使用されません。詳細パラメータです（デフォルト: 1.0）。 | FLOAT | はい | 0.0～2.0（ステップ0.1） |
| `top_p` | Nucleus サンプリングパラメータ。`"arrow-2-telos"` モデルでは使用されません。詳細パラメータです（デフォルト: 1.0）。 | FLOAT | はい | 0.05～1.0（ステップ0.05） |
| `presence_penalty` | トークンの存在ペナルティ。`"arrow-2-telos"` モデルでは使用されません。詳細パラメータです（デフォルト: 0.0）。 | FLOAT | はい | -2.0～2.0（ステップ0.1） |

**注記:** `reference_images` の最大数は14です。 `width` または `height` を 0 のままにすると、モデルがキャンバスサイズを選択します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `SVG` | 生成された SVG 出力。 | SVG |
