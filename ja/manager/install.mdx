## デスクトップ版ユーザー

Comfy Desktop は ComfyUI のインストールごとに ComfyUI-Manager を導入し、`--enable-manager` 付きで起動するため、あなたがインストールするものは何もありません。マネージャーはアプリ内からインストールごとに設定します:

<Steps>
  <Step title="そのインストールの Manage パネルを開く">
  Comfy Desktop でインストールを開き、**Manage パネル**に移動してから **Startup Args** タブに切り替えます。
  </Step>
  <Step title="マネージャーのオプションを設定する">
  - **Manager Security Level** は、マネージャーがインストールを許可するノードパックを決定します: **Strict**、**Standard**（推奨）、**Relaxed**、**Permissive**。`--listen` で ComfyUI をネットワークに公開している場合は、より厳格なレベルが特に重要になります
  - **Manager Network Mode** は、マネージャーがノードレジストリにアクセスする方法を決定します: **Public**（デフォルト）、**Private**、**Offline**、**Personal cloud**（自分で管理しているマシンのみを対象とします）

  どちらのオプションも、次にそのインストールを起動したときに適用されます。
  </Step>
  <Step title="マネージャーが起動時に使用するフラグを変更する（任意）">
  同じタブの **Startup Arguments** は、そのインストールの起動時に使用するフラグを制御します。`--enable-manager` を削除するとマネージャーなしで ComfyUI を実行でき、そのままにして `--disable-manager-ui` を追加すると、バックグラウンドのタスクを続けたままマネージャーの UI を非表示にできます。
  </Step>
</Steps>

インストールごとのその他の設定については [Startup Args タブ](/ja/installation/desktop/usage/manage#スタートアップ引数タブ) を、マネージャーのフラグについては [起動フラグのリファレンス](/ja/development/comfyui-server/startup-flags) を参照してください。

## ポータブル版ユーザー

[Windows ポータブル版](/ja/installation/comfyui_portable_windows) を使用しているユーザーの場合、新しい ComfyUI-Manager は ComfyUI コアに組み込まれていますが、有効化する必要があります。

1. マネージャー機能の依存関係をインストールします：
   ```bash
   .\python_embeded\python.exe -m pip install -r ComfyUI\manager_requirements.txt
   ```

2. マネージャー機能を有効にして ComfyUI を起動します：
   ```bash
   .\python_embeded\python.exe -s ComfyUI\main.py --windows-standalone-build --enable-manager
   pause
   ```

## 手動インストールユーザー

[手動インストール](/ja/installation/manual_install) を行っているユーザーの場合、新しい ComfyUI-Manager は ComfyUI コアに組み込まれていますが、有効化する必要があります。

1. 仮想環境をアクティブにします：
   ```bash
   # Windows の場合
   venv\Scripts\activate
   
   # Linux/macOS の場合
   source venv/bin/activate
   ```

2. マネージャー機能の依存関係をインストールします：
   ```bash
   pip install -r manager_requirements.txt
   ```

3. ComfyUI 実行時に `--enable-manager` フラグを使用してマネージャー機能を有効にします：
   ```bash
   python main.py --enable-manager
   ```

### コマンドラインオプション

| フラグ | 説明 |
|------|-------------|
| `--enable-manager` | ComfyUI-Manager を有効にします |
| `--enable-manager-legacy-ui` | 新版 UI の代わりに旧版マネージャー UI を使用します（`--enable-manager` が必要） |
| `--disable-manager-ui` | バックグラウンド機能を維持しつつ、マネージャー UI とエンドポイントを無効にします（`--enable-manager` が必要） |

### 新旧 UI の切り替え

以下のバージョン更新は pip インストールのみをサポートします。カスタムノード経由でインストールされたバージョンは、新版 UI への切り替えをサポートしません。

<Tabs>
<Tab title="デスクトップ版以外のユーザー">
新版 UI を使用する場合：
```bash
python main.py --enable-manager
```

旧版 UI を使用する場合：
```bash
python main.py --enable-manager --enable-manager-legacy-ui
```

</Tab>
<Tab title="デスクトップ版ユーザー">
デスクトップ版ユーザーは、**サーバー設定 → UI 設定 → 旧版マネージャーインターフェースを使用**で旧版 UI に切り替えることができます
![旧版 UI に切り替え](/images/manager/manager_use_legacy_manager_ui.png)
</Tab>
</Tabs>

## ComfyUI-Manager の更新

ComfyUI-Manager は ComfyUI 本体とは別の Python パッケージで、ComfyUI 本体は対応するバージョンを `manager_requirements.txt` で固定しています。マネージャーの更新方法は ComfyUI のインストール方法によって異なります：

<Tabs>
<Tab title="デスクトップ">
デスクトップにはマネージャーが含まれており、Comfy Desktop の更新に合わせて最新の状態に保たれます。[管理パネル](/ja/installation/desktop/usage/manage#更新タブ)から ComfyUI エンジンを更新してください。
</Tab>
<Tab title="ポータブル版と手動インストール">
ComfyUI を更新しても、インストール済みのマネージャーパッケージは更新されないことがあります。ComfyUI を起動する環境でマネージャーの依存関係をインストールし、`--enable-manager` を付けて ComfyUI を再起動してください：

```bash
# ポータブル版（Windows）
.\python_embeded\python.exe -m pip install -r ComfyUI\manager_requirements.txt
.\python_embeded\python.exe -s ComfyUI\main.py --windows-standalone-build --enable-manager

# 手動インストール
pip install -r manager_requirements.txt
python main.py --enable-manager
```
</Tab>
<Tab title="Git クローン">
マネージャーを自分で `custom_nodes` にクローンした場合:

```bash
cd ComfyUI/custom_nodes/comfyui-manager
git pull
```

その後、ComfyUI を再起動してください。
</Tab>
</Tabs>

## レガシーなインストール方法

<Accordion title="方法 1: Git clone（一般インストール）">
既存の ComfyUI インストールに追加して ComfyUI-Manager をインストールする場合：

1. ターミナルで `ComfyUI/custom_nodes` ディレクトリに移動します
2. リポジトリをクローンします：
   ```bash
   git clone https://github.com/Comfy-Org/ComfyUI-Manager comfyui-manager
   ```
3. マネージャー機能の依存関係をインストールします：
   ```bash
   cd comfyui-manager
   pip install -r requirements.txt
   ```
4. ComfyUI を再起動します
</Accordion>

<Accordion title="方法 2: ポータブル版（Windows）">
1. [Git for Windows](https://git-scm.com/download/win) をインストールします（スタンドアロン版、「Use windows default console window」を選択）
2. [install-manager-for-portable-version.bat](https://github.com/Comfy-Org/ComfyUI-Manager/raw/main/scripts/install-manager-for-portable-version.bat) を `ComfyUI_windows_portable` ディレクトリにダウンロードします
3. バッチファイルをダブルクリックしてインストールします
</Accordion>

<Accordion title="方法 3: comfy-cli（新規インストール推奨）">
comfy-cli は、CLI から ComfyUI を管理するためのさまざまな機能を提供します。

**前提条件**: Python 3、Git

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
pip install comfy-cli
comfy install
```

**Linux/macOS:**
```bash
python -m venv venv
. venv/bin/activate
pip install comfy-cli
comfy install
```

参照：[comfy-cli ドキュメント](/ja/comfy-cli/getting-started)
</Accordion>

<Accordion title="方法 4: Linux + venv">
**前提条件**: python-is-python3、python3-venv、git

1. [install-comfyui-venv-linux.sh](https://github.com/comfy-org/ComfyUI-Manager/raw/main/scripts/install-comfyui-venv-linux.sh) を空のインストールディレクトリにダウンロードします
2. 実行します：
   ```bash
   chmod +x install-comfyui-venv-linux.sh
   ./install-comfyui-venv-linux.sh
   ```
3. `./run_gpu.sh` または `./run_cpu.sh` で ComfyUI を実行します
</Accordion>

<Warning>
**インストール時の注意事項：**
- ComfyUI-Manager のファイルは正確にパス `ComfyUI/custom_nodes/comfyui-manager` に配置されている必要があります
- `ComfyUI/custom_nodes` に直接解凍しないでください（`__init__.py` などのファイルはそのディレクトリに存在すべきではありません）
- `ComfyUI/custom_nodes/ComfyUI-Manager/ComfyUI-Manager` や `ComfyUI/custom_nodes/ComfyUI-Manager-main` などのパスにはインストールしないでください
</Warning>
