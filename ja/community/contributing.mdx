あらゆる種類のコントリビューションを歓迎しています。コードを書かなくても協力できます。

## コントリビューションの方法

- **ワークフローを共有する**：作成したワークフローを公開すると、他のユーザーが実行して学べます。
- **カスタムノードを開発する**：ノードを開発して [Comfy Registry](/ja/registry/overview) に公開します。
- **ノードのドキュメントを改善する**：組み込みノードのドキュメントは [embedded-docs リポジトリ](https://github.com/Comfy-Org/embedded-docs) で管理されており、カスタムノードは独自の[ヘルプページ](/ja/custom-nodes/help_page)を同梱できます。
- **不具合の報告や機能の提案**：[ComfyUI リポジトリ](https://github.com/Comfy-Org/ComfyUI/issues) で issue を作成します。
- **質問に答える**：[コミュニティリンク](/ja/community/links)に掲載されているチャンネルで他のユーザーを支援します。

[Comfy-Org GitHub 組織](https://github.com/Comfy-Org) で、プロジェクトが管理しているすべてのリポジトリを確認できます。
