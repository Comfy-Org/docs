## Wan 3.0 テキストから動画へのワークフロー

#### プロンプトのヒント

1. **再生時間**: 2〜30秒に設定するか、`auto` にすると、モデルがプロンプトに合った再生時間を選択します
2. **解像度と比率**: ワークフローは `adaptive` 比率の 720p で提供されます。特定のフォーマット向けに 1080p や `16:9` などの固定比率に切り替えてください
3. **オーディオ**: オーディオはデフォルトで生成されます。`audio` オプションを無効にすると、無音のビデオが出力されます
4. **プロンプト拡張**: プロンプトの強化はデフォルトでオンになっており、より良い結果を得るためにプロンプトを書き換えます。正確な文言が必要な場合は、高度な機能の設定でオフにしてください

#### プロンプトのヒント

1. **最初のフレーム**: `first_frame` 入力は必須です。`last_frame` 入力はオプションで、モデルは2つのフレーム間の動きを生成します
2. **アダプティブ比率**: `adaptive` を使用すると、出力サイズは入力画像に追従します
3. **プロンプト**: 何がどのように動くか、さらに希望するオーディオを記述します。モデルに変更させたい場合を除き、被写体と構図はそのまま維持してください。

#### プロンプト作成のヒント

1. **タグによる参照**：プロンプト内の各入力は `@Image1`、`@Video1`、`@Audio1` のように、タイプごとに入力順に番号を付けて参照します。サンプルプロンプトでは、シューズのデザインを `@Image1`、キャラクターを `@Image2` に割り当てています。
2. **制限**：参照画像は最大10枚、参照ビデオは最大5本、参照オーディオクリップは最大5本です。各参照ビデオまたはオーディオクリップは15秒以内である必要があり、すべての参照ビデオの合計再生時間も15秒以内（オーディオも同様）に収める必要があります。参照ビデオと出力の合計再生時間は30秒を超えてはなりません。
3. **ジョブの割り当て**：各参照が何を制御するか（プロダクトデザイン、キャラクターの同一性、スタイル、モーション、音声）と、何を変更しないかを明記します。明示的な割り当てにより、より一貫した結果が得られます。
4. **プロンプトまたは参照が必須**：プロンプトまたは少なくとも1つの参照入力を指定してください。指定しない場合、ノードはエラーを返します。

## Get started

1. Update ComfyUI to the latest version, or use the latest [Comfy Desktop](https://www.comfy.org/download)
2. Go to Template Library, search for `Wan 3.0`
3. Load one of the three workflows (text-to-video, image-to-video, or reference-to-video)
4. Log in with your Comfy account and ensure you have enough [credits](/interface/credits)
5. Connect the input materials (first frame or reference images) and run
