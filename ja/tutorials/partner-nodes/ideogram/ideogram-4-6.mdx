**Ideogram 4.6**は、ネイティブ4K出力に対応したIdeogramの画像生成・編集モデルです。1回のパスで最大4096x4096をレンダリングするため、ポスターやパッケージ、商品写真に別途アップスケールを適用する必要はありません。Precise Edit は、変更を指示していないピクセルの色とディテールを維持します。

3つのComfyUIパートナーノード（**Ideogram Text to Image**、**Ideogram Edit**、**Ideogram Precise Edit**）でモデルオプションとして動作します。いずれかのノードで`model`を`ideogram-4.6`に設定し、同じリストから`ideogram-4.5`を選択すると旧モデルを使用できます。旧モデルには[専用ページ](/ja/tutorials/partner-nodes/ideogram/ideogram-4-5)があります。

## テキストから画像生成

1K、2K、または4Kのキャンバスで、テキストプロンプトから画像を生成します。

<img src="https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/templates/api_ideogram_v4_6_t2i-1.webp" alt="Ideogram 4.6 text to image workflow preview" />

<Card title="ワークフローをダウンロード" icon="download" href="https://github.com/Comfy-Org/workflow_templates/blob/main/templates/api_ideogram_v4_6_t2i.json">
  JSONをダウンロードするか、テンプレートライブラリで「Ideogram 4.6: Text to Image」を検索してください
</Card>

![Ideogram 4.6 text to image example output](https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/output/api_ideogram_v4_6_t2i.png)

**Ideogram Text to Image** ノードは次の入力を受け取ります。

| 入力 | 値 | 効果 |
| --- | --- | --- |
| `prompt` | 最大10000文字 | 画像の説明。構造化されたJSONキャプションも使用できます。たとえば、以前の実行で得られた `final_prompt` などです |
| `size` | `auto`、1K、2K、4Kのプリセット、または `custom` | `auto` はプロンプトに適したキャンバスを選択します。プリセットには、縦長の `1:3` や `9:23` から横長の `3:1` や `23:9` までの1K、2K、4Kキャンバスが含まれます。例: `(2K) 2048x2048 (1:1)`、`(4K) 5120x2880 (16:9)` |
| `width`、`height` | 256から8192、ステップ32 | `size` が `custom` のときのみ使用されます。2つの寸法は16777216ピクセル（4096x4096）以内、かつアスペクト比6:1以内に収まる必要があります |
| `quality` | `very_low`、`low`、`medium`（デフォルト）、`high` | 上位のティアほどコストが高く、時間もかかります。`very_low` は4194304ピクセル（2048x2048）に制限されています |
| `background` | `auto`（デフォルト）、`opaque`、`transparent` | `transparent` はアルファチャンネル付きの画像を返し、`opaque` は不透明な背景を強制し、`auto` はプロンプトに従います |
| `magic_prompt` | `auto`（デフォルト）、`on`、`off` | 生成前にプロンプトを詳細な構造化キャプションに書き換えます。`off` は文言をできるだけそのまま保持します |
| `seed` | 整数 | プロンプトが実行ごとに書き換えられるため、テキストから画像生成はシードだけでは再現できません |

このノードは、画像の生成元となった構造化キャプションである `final_prompt` も出力します。画像を再現するには、そのキャプションを、`magic_prompt` を `off` に設定し同じシードを使って入力し直します。

## 画像編集

1つの指示で最大5枚の画像を編集または結合できます。`image_1` は編集対象の画像で、画像2〜5はデザイン、マテリアル、色の参照として使用します。プロンプトでは `@Image1`、`@Image2` などの形式で指定します。

**入力マテリアル**

<Card title="retro_crt_room.png" icon="image" href="https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/input/retro_crt_room.png">
  Ideogram Editノードの `image_1` スロットに読み込む

このテンプレートは **Build JSON Prompt** ノードで指示を組み立てるため、画像内の領域をマークしてキャプションを付けることができます。エディタが表示されない場合は [Nodes 2.0](/ja/interface/nodes-2) をオンにしてください。

`ideogram-4.6` を指定した **Ideogram Edit** ノードでは、以下が追加されます:

| 入力 | 値 | 効果 |
| --- | --- | --- |
| `size` | `auto`（デフォルト）、`source`、プリセット、`custom` | `auto` は画像とプロンプトから約2Kのキャンバスを選択します。`source` は `image_1` のサイズを維持します。アスペクト比が異なるプリセットではシーンが再構成されます。`custom` は下記の `width` と `height` を使用します |
| `width`, `height` | 256〜8192、ステップ32 | `size` が `custom` のときのみ使用されます。2つの寸法は16777216ピクセル（4096x4096）以内、かつアスペクト比6:1以内に収める必要があります |
| `quality` | `very_low`、`low`、`medium`（デフォルト）、`high` | 上位のティアほどコストが高く、時間もかかります |
| `background` | `auto`（デフォルト）、`opaque`、`transparent` | `transparent` はアルファチャンネル付きの画像を返します |
| `seed` | 整数 | 同じ画像、プロンプト、設定、シードであれば同じ結果が得られます |

16.7 MP を超える入力、または1辺が8192ピクセルを超える入力は、アップロード前に縮小されます。また、各画像のアスペクト比は1:6〜6:1の範囲内である必要があります。

Editは画像全体を再レンダリングするため、編集内容に合わせてフレーミングや未編集の領域も変化する可能性があります。残りの部分をまったく変えずに保つ必要がある場合は、Precise Edit を使用してください。

## 精密編集

プロンプトで指示した内容だけを変更します。触れていないピクセルは同一のまま保持され、出力は `image_1` のサイズを維持します。領域を指定せず、ソースが 16.7 MP または一辺 8192 ピクセルを超える場合は、先に縮小されます。編集中の画像に加えて最大 4 枚の参照画像を指定できます。マスクを使う場合は最大 3 枚です。

**入力素材**

<Card title="carbon_fibre_controller.png" icon="image" href="https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/input/carbon_fibre_controller.png">
  Ideogram Precise Edit ノードの `image_1` スロットに読み込みます

Precise Edit は、参照スロット、`@Image1` による指定、`quality`、`seed` の各コントロールを Edit と共有しています。サイズのコントロールはありません。領域を指定した場合、出力は `image_1` のサイズを維持し、指定しない場合は 16.7 MP または一辺 8192 ピクセルを超えるソースが先に縮小されます。

### 1 つの領域だけを編集する

ネイティブ解像度で 1 つの領域を編集するには、`context_window` を設定します:

| `context_window` | 追加の入力 | 編集される領域 |
| --- | --- | --- |
| `none` | なし | 画像全体（16.7 MP を超える場合は縮小） |
| `auto`（デフォルト） | `mask` | マスクが示す領域。マスクが接続されていない場合は画像全体 |
| `custom` | `context_window_bboxes` | 接続されたすべてのボックスを囲む 1 つの矩形（離れたボックス間の空間も含まれ、編集される場合があります）。たとえば **バウンディングボックスを作成** ノードから生成します |

領域は一辺最大 8192 ピクセル、約 16.7 MP、アスペクト比は最大 6:1 までです。領域を指定した場合、`image_1` 自体は任意のアスペクト比で最大 8192x8192 ピクセルまで使用でき、領域外のピクセルは変更されずにそのままコピーされます。

製品の色変更、マテリアルの差し替え、写真の他の部分の照明・背景・構図をそのまま保つ必要がある修正などに使用します。

## はじめる

1. ComfyUIを最新バージョンにアップデートします。
2. **ワークフロー** > **テンプレートを参照** を開き、「Ideogram 4.6」を検索するか、上記のワークフローをダウンロードしてキャンバスにドラッグします。
3. Ideogram 4.5のワークフローから始めた場合は、ノードで `model` を `ideogram-4.6` に設定します。
