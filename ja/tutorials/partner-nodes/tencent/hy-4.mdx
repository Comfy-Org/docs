**Tencent HY4** は Tencent の大規模言語モデルで、ComfyUI では `Tencent HY` パートナーノードを通じて利用できます。このノードはテキストプロンプトと最大 20 枚の画像を受け取り、テキストを返します。参照画像から作成したアートプロンプト、キャプション、チャートの内訳、その他依頼した任意の回答などです。

Hy4 は 2026 年 11 月 4 日にリリースされました。視覚的理解を備えた初の Hy 世代であり、Tencent によれば Hy4 プレビューと比較して、指示への追従性、長文コンテキストの理解、長期的なエージェントタスクにおいて改善が見られます。このノードは Comfy API を通じてモデルを呼び出すため、モデルのダウンロードやローカル GPU は必須ではありません。

ここで扱うテンプレートは画像からプロンプトへの変換例です。写真を読み取り、画像モデルに貼り付けられるカンマ区切りのプロンプトを生成します。

## Tencent HY ノードが得意なこと

- **画像からプロンプト**: 被写体、構図、カメラ、ライティング、色、質感、スタイルを網羅する構造化プロンプトを生成します
- **画像理解**: 写真、スクリーンショット、ドキュメントに対するキャプション、チャートや図の分解、細部の確認
- **1リクエストで複数画像**: 1回の呼び出しで最大20枚の画像を処理でき、バッチ内の各画像は1回としてカウントされます
- **指示の制御**: `system_prompt` は常設の役割を保持し、`prompt` は今回の実行におけるタスクを担います
- **推論の切り替え**: `reasoning` を有効にすると、必要なタスクでモデルが回答前に思考します
- **長い回答**: `max_tokens` は最大64000トークンまで受け付けます

### ワークフローを実行する手順

1. `LoadImage` ノードに画像を読み込んでください。ダウンロードしたワークフローは `blue_poppies_field.png` を名前で参照しているため、そのファイルをアップロードするまでノードは空のままです
2. `Text (User Prompt)` ノードを編集してください。そのテキストは `prompt` としてモデルに送信され、テンプレートはすでにカンマ区切りのポジティブプロンプトのみを要求しています。他の出力を得たい場合は書き換えてください。例えば `Describe this chart and list the trends it shows`
3. （任意）ステップバイステップの思考が必要なタスクでは `reasoning` をオンにしてください。回答には時間がかかり、より多くのトークンを使用します
4. （任意）長い回答が必要な場合は `max_tokens` をデフォルトの `32000` から増やし（最大 `64000`）、バリエーションを減らしたり増やしたりしたい場合は `temperature` を `1.0`（範囲 0〜1.4）から変更してください
5. `Run` をクリックするか、`Ctrl(cmd) + Enter` を押してください
6. `Preview Any` で回答を確認してください。`Save Text` がプロンプトと回答を `output/Hy4/` 配下の `.txt` ファイルに書き出します

### プロンプト作成のヒント

- 出力形式を明示してください。テンプレートの `Only output positive prompt, no extra explanations` という行が、回答をそのまま貼り付けられる状態に保つ役割を果たします
- 複数の画像を接続する場合は、順番に言及してください（`the first image`、`the second image`）。そうすることで詳細が正しい画像に紐づきます
- 繰り返し使う指示は `system_prompt` に置き、`prompt` はタスク用に残してください。例えば `You write photography prompts for a stock library`
- `seed` はノードを再実行するかどうかだけを決めます。回答は実行ごとに変わります

## はじめる

1. ComfyUIを最新バージョンにアップデートします
2. テンプレートライブラリに移動し、`Tencent: Hy4` を検索します
3. 画像からプロンプトを生成するワークフローを開き、実行します

Tencent HY4はAPIのトークン使用量に基づいて課金されます。Hy4の料金については[料金表](/ja/tutorials/partner-nodes/pricing)をご覧ください。
