Tencent Hunyuan Image 3.5 Preview（HY Image 3.5 Preview）は、ComfyUI のパートナーノードで利用できる Tencent のプレビュー版画像モデルです。テキストから画像を生成し、指示に従って既存の画像を編集します。多言語のテキスト描画、フォトリアリズム、参照画像と編集結果の一貫性に重点を置いています。

従来の Hunyuan 画像モデルと比べて、HY Image 3.5 Preview は 3 つの領域を強化しています。広告、インフォグラフィック、UI デザイン向けの多言語テキスト描画と組版。シネマティック、コミック、商業写真、イラストにわたるフォトリアリズムとスタイルの幅。そして背景、服装、スタイルを変更しても人物や製品の主要な特徴を保つ編集の一貫性です。

ワークフローは 2 つ用意されています。`Tencent HY Image: Text to Image` はプロンプトから画像を生成し、`Tencent HY Image: Edit` は最大 5 枚の参照画像を編集または合成します。どちらも Comfy API を通じて Tencent のサーバー上で実行されるため、モデルのダウンロードやローカル GPU は不要です。

## HY Image 3.5 Preview が得意なこと

- **多言語のテキストと組版**: 単なる情景画像ではなく、ポスター、インフォグラフィック、UI モックアップ向けに読みやすいテキストを描画します
- **フォトリアリズムの幅**: 短いプロンプトからシネマティックなカット、コミック調、商業写真、イラストまで対応します
- **編集の一貫性**: 背景、服装、スタイルを変更しても人物や製品の特徴を保ちます
- **最大 5 枚の参照画像**: 1 回の編集で複数の画像を組み合わせ、プロンプトでそれぞれを参照できます
- **最大 4K 出力**: ネイティブで最大 2K をレンダリングし、4K 出力は 2K のレンダリング結果からアップスケールします

### ワークフローの実行手順

1. `Tencent HY Image: Text to Image` ノードの `prompt` を編集します。
2. （オプション）`aspect_ratio` を設定して出力の形を制御します。`auto` ではモデルがプロンプトからアスペクト比を選びますが、4K では `auto` は使用できません。
3. （オプション）`resolution` をデフォルトの `2K` から変更します。`1K` は約 1024x1024、`2K` は約 2048x2048 ピクセルです。`4K` 出力は 2K でレンダリングした後にモデルがアップスケールします。
4. （オプション）`resolution` を `custom` に切り替えて、正確な `width` と `height` を指定します。どちらも 16 の倍数である必要があり、合計ピクセル数は最大 4096x4096 です。アスペクト比が約 6:1 を超えると、モデルが被写体を繰り返し始めます。
5. `Run` をクリックするか `Ctrl(cmd) + Enter` を押して画像を生成します。
6. `Save Image` ノードで結果を確認します。

### ワークフローの実行手順

1. `Tencent HY Image: Edit` ノードの `images` 入力に 1〜5 枚の画像を接続します。
2. `prompt` に編集の指示を書きます。入力した順に `@Image1`、`@Image2` のように参照します。バッチ入力は画像 1 枚につき 1 回として数えます。
3. （オプション）`aspect_ratio` と `resolution` を設定します。`auto` では出力が最初の参照画像のアスペクト比に従います。`4K` 出力は 2K でレンダリングした後にモデルがアップスケールします。
4. （オプション）`reference_detail` を `high` にすると、モデルは参照画像を 1024x1024 ではなく最大 2048x2048 ピクセルで参照します。小さな文字や細部をより保てますが、時間がかかります。
5. `Run` をクリックするか `Ctrl(cmd) + Enter` を押して画像を生成します。
6. `Save Image` ノードで結果を確認します。

### プロンプトのヒント

- 変更する部分と、変更せずに保つ部分を分けて書きます。例: `@Image1 change the background to a night market, keep the subject and jacket unchanged`
- 参照画像の番号は接続した順になります。プロンプト内の番号は入力順と一致させてください
- `watermark` はノードの詳細オプションにあり、既定ではオフです。オンにすると出力に AI 生成のウォーターマークが追加されます
