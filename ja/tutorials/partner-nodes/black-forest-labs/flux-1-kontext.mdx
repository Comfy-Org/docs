FLUX.1 Kontext は、Black Forest Labs が開発したプロフェッショナルな画像から画像への編集モデルであり、画像の文脈を知的に理解し、高精度な編集を実現することに重点を置いています。
複雑な説明を必要とせずに、オブジェクトの変更、スタイル転送、背景の置換、キャラクターの一貫性を保った編集、テキスト編集など、多様な編集タスクを実行できます。
Kontext の核心的な強みは、優れた文脈理解能力とキャラクターの一貫性維持能力にあります。これにより、複数回の編集を経ても、キャラクターの特徴や構図のレイアウトといった重要な要素が安定して保持されます。

現在、ComfyUI では Flux.1 Kontext の以下の2つのモデルがサポートされています：

* **Kontext Pro**：編集・合成・リミックスに最適です。
* **Kontext Max**：タイポグラフィ、プロンプトの正確性、および処理速度の限界に挑戦します。

## Flux.1 Kontext が得意なこと

- **複雑な説明を必要としない汎用性の高い編集**: オブジェクトの変更、スタイル転送、背景の置き換え、キャラクターの一貫性を維持した編集、テキスト編集
- **コンテキスト理解**: 画像のコンテキストをインテリジェントに理解することで、正確で的を絞った編集が可能になります
- **キャラクターの一貫性**: 編集を複数回繰り返した後でも、キャラクターの特徴と構図レイアウトが安定して維持されます
- **複数画像の入力**: `Image Stitch` ノードは、複数の画像を1枚の画像につなぎ合わせて、Flux.1 Kontext での編集に使用できるようにします
- **2つのモデルティア**: Kontext Pro は編集、合成、リミックス用。Kontext Max はタイポグラフィ、プロンプトの精度、スピード用

## Flux.1 Kontext 複数画像入力ワークフロー

複数画像入力ワークフローをサポートするよう更新しました。新しい `Image Stitch` ノードを使用すると、複数の画像を 1 枚の画像に結合し、Flux.1 Kontext で編集できます。

### 1. ワークフローファイルのダウンロード

以下の画像の `metadata` にはワークフロー情報が含まれています。ダウンロードして ComfyUI にドラッグすると、対応するワークフローを読み込むことができます。

![ComfyUI Flux.1 Kontext プロ Image パートナーノードワークフロー](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/bfl/multiple_image_input/multiple_image_input.png)

入力用として以下の画像をダウンロードするか、ご自身の画像をご利用ください：

![ComfyUI Flux.1 Kontext プロ Image パートナーノードワークフロー](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/bfl/multiple_image_input/girl.jpg)
![ComfyUI Flux.1 Kontext プロ Image パートナーノードワークフロー](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/bfl/multiple_image_input/dog.jpg)
![ComfyUI Flux.1 Kontext プロ Image パートナーノードワークフロー](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/bfl/multiple_image_input/sofa.jpg)

### 2. ワークフローを手順通りに完了させる

![ComfyUI Flux.1 Kontext プロ Image パートナーノードワークフローステップ](/images/tutorial/api_nodes/bfl/flux_1_kontext_multiple_image_input_guide.jpg)

画像中の番号順に従って、ワークフローを完了させることができます：

1. `Load image` ノードで、提供された画像をアップロードします
2. `Flux.1 Kontext Pro Image` の必要なパラメータを変更します：
    - `prompt` 編集したい画像のプロンプトを入力します
    - `aspect_ratio` オリジナル画像のアスペクト比を設定します。1:4 から 4:1 の範囲である必要があります
    - `prompt_upsampling` プロンプトのアップサンプリングを使用するかどうかを設定します。有効にすると、より豊かな結果を得るためにプロンプトが自動的に変更されますが、結果は再現できません
3. `Run` ボタンをクリックするか、ショートカット `Ctrl(cmd) + Enter` を使用して画像編集を実行します
4. API が結果を返すのを待つと、`Save Image` ノードで編集済み画像を確認できます。また、対応する画像は `ComfyUI/output/` ディレクトリにも保存されます

<Tip>
   以降の 2 つのワークフローは、使用するパートナーノードのみが異なります。実際には、複数画像入力ワークフローをベースに変更するだけで、大きな違いはありません
</Tip>
