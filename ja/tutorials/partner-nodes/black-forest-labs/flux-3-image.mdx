FLUX 3 は Black Forest Labs のマルチモーダル基盤モデルで、2026年7月23日に発表され、現在はアーリーアクセス中です。画像、ビデオ、オーディオを、Self-Flow を基盤とした単一のアーキテクチャ内で学習します。Self-Flow は、同じモデル内でマルチモーダル生成と理解を整合させる彼らのアプローチです。FLUX 3 Image はそのうち、静止画像の生成と編集を担当する部分です。アーリーアクセスの展開中に、機能と制限は変更される可能性があります。

FLUX 3 Image は、テキストプロンプトから画像を生成するか、最大10枚の参照画像を編集・合成します。参照画像はプロンプト内で `image 1`、`image 2` のように指定し、モデルはプロンプトを解釈・拡張してから生成します。Web と画像検索のグラウンディングはデフォルトで有効なので、指定した被写体を検索できます。出力は単一の画像で、16種類のアスペクト比と、0.75K（約0.6メガピクセル）から4K（約16.8メガピクセル）までの5段階の解像度に対応します。

ComfyUI では、FLUX 3 Image は **Flux 3 Image** パートナーノードを通じて実行され、生成した画像1枚ごとに、解像度に応じてクレジットで課金されます。テキストから画像、複数参照画像の編集、バウンディングボックスによるレイアウト制御の3つのテンプレートがあります。

## FLUX 3 Image が得意なこと

- **テキストから画像**：プロンプトから画像を1枚生成します。モデルがまずプロンプトを解釈・拡張します
- **複数参照画像の編集**：最大10枚の参照画像を編集・合成し、プロンプト内で `image 1` から `image 10` として指定します
- **バウンディングボックスによるレイアウト制御**：Create Bounding Boxes ノードが生成するボックスで、オブジェクトやテキストを任意の位置に配置します
- **検索グラウンディング**：Web と画像検索がデフォルトで有効で、描画前に指定した被写体を調べられます
- **柔軟な出力**：16種類のアスペクト比と、0.75K から 4K までの5段階の解像度
- **タイポグラフィとレイアウト**：ポスター、見出し、キャプション、レイアウト主体のデザイン作業に適しています

### テキストから画像の手順

1. **Flux 3 Image** ノードにプロンプトを入力します
2. `resolution`（0.75K から 4K）を設定し、必要なら `aspect_ratio` を `auto` 以外にします
3. `grounding` を有効のままにして、指定した被写体を Web と画像で検索させます
4. **Queue** をクリックして画像を生成します

### 画像編集の手順

1. 参照画像を **Load Image** ノードにアップロードし、Autogrow スロットで最大10枚まで追加します
2. **Flux 3 Image** ノードで編集内容を記述し、各参照画像を `image 1`、`image 2` などと指定します
3. 出力の `resolution` と `aspect_ratio` を設定します
4. **Queue** をクリックして編集後の画像を生成します

### バウンディングボックス編集の手順

1. 画像を **Load Image** ノードにアップロードします
2. **Create Bounding Boxes** でボックスを描き、それぞれに説明を付けます
3. **Flux 3 Image** ノードに全体の指示を書きます
4. ボックスを描いたキャンバスに合わせて `aspect_ratio` を設定します
5. **Queue** をクリックして画像を生成します
