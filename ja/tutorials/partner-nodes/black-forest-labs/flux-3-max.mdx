**FLUX 3 Max** は、FLUX 3 基盤上に構築された Black Forest Labs のビデオモデルで、fal 経由で提供され、ComfyUI ではパートナーノードとして利用できます。テキストプロンプトからクリップを生成するほか、複数の静止画像を1つの連続したショットにアニメーション化できます。

スタンダードな FLUX 3 ビデオノードとの違いは、タイムラインを制御できる点です。イメージ・トゥ・ビデオは1〜10枚のキーフレーム画像を受け取ります。1枚ならクリップの冒頭を開き、2枚なら最初と最後のフレームになり、それ以上はクリップ全体に均等に配置するか、指定した秒にピン留めできます。各実行では、環境音、音声、効果音を含む同期オーディオも生成されます。

どちらのノードもクラウドAPIノードです。クレジット付きのComfyアカウントが必要で、モデルをダウンロードせず、出力の秒単位で課金されます。料金については[パートナーノードの料金](/ja/tutorials/partner-nodes/pricing)を参照してください。

## FLUX 3 Max が得意なこと

- **キーフレーム制御**: タイムラインに最大10枚の画像を配置し、モデルにその間の動きを補完させます
- **ネイティブオーディオ**: すべてのクリップには、同期された環境音、音声、エフェクトが付属します。オーディオトラックをオフにすることもできます
- **5～20秒のクリップ**: 1回の生成で、つなぎ合わせたセグメントではなく、1つの完全なショットをカバーします
- **プロンプト拡張**: `reasoning_level` は、生成前にモデルがプロンプトをどの程度書き換え、計画するかを決定します。どちらの場合も価格は同じです
- **柔軟なフレーミング**: 24 fpsで720pまたは1080p、21:9から9:16まで、または入力画像に合わせる`auto`

## FLUX 3 Max テキストから動画へのワークフロー

ショットを説明し、長さを選択して実行します。サウンド、モーション、カメラの動きは同じプロンプトからまとめて生成されるため、希望するオーディオはアクションと同じ段落で説明してください。

**使い方**

1. **プロンプトを書く**: まずシーンを説明し、そのあとにサウンドを説明します。環境音、音楽、音声は分けて記述し、オーディオのレイヤー同士が干渉しないようにしてください。
2. **クリップを設定する**: `duration` は 5〜20 秒、`resolution` は `720p` または `1080p`、`aspect_ratio` のデフォルトは `auto` です。
3. **カットや複数の被写体を含む複雑なプロンプトでは、`reasoning_level` を `high` のままにしてください**。処理には時間がかかりますが、コストは `low` と同じです。
4. **実行**し、結果を `SaveVideo` で保存します。

## FLUX 3 Max 画像から動画へのワークフロー

**使い方**

1. **画像を追加**: `keyframes` 入力に、再生順に1〜10枚の画像を接続します。
2. **配置を選択**: `spread across the clip` は最初の画像を先頭に、最後の画像を末尾に、残りを均等に配置します。`at times` では、各画像を秒単位で指定した時刻にピン留めできます。カンマ区切りで増加する値、例えば `0, 2.5, 5` のように入力します。
3. **動きとサウンドを記述**: プロンプトでシーンの動きとサウンドをモデルに伝えます。カットは `SHOT ONE`、`HARD CUT`、`SHOT TWO` のように明示的に記述します。
4. **クリップを設定**: `duration`、`resolution`、`aspect_ratio` はテキストから動画へのノードと同様に機能します。
5. **実行**して、結果を `SaveVideo` で保存します。

## ノードのコントロール

両方のノードは次の入力を共有します:

| コントロール | 値 | 効果 |
| --- | --- | --- |
| `prompt` | 最大50,000文字 | ショット、カメラの動き、オーディオ |
| `aspect_ratio` | `auto`、`21:9`、`2:1`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16` | `auto` はテキストプロンプトでは16:9、それ以外では最初の画像に従います |
| `duration` | 5〜20秒 | クリップの長さ |
| `resolution` | `720p`、`1080p` | 24 fpsでの出力解像度 |
| `reasoning_level` | `low`、`high` | 生成前にモデルがプロンプトをどれだけ拡張するか。価格は変わりません |
| `generate_audio` | デフォルトでオン | サイレントビデオにする場合はオフにします |
| `seed` | デフォルト42 | 変更するとノードが再実行されます。結果はシードに関係なく非決定的です |

画像からビデオでは、`keyframes`（1〜10枚の画像）と`placement`（`spread across the clip` または `at times`）が追加されます。

## 制限 {#limits}

- クリップは24 fpsで5～20秒です。これらのノードには継続用の入力がないため、より長い作品は個別の生成になります。
- キーフレーム画像は最大10枚で、少なくとも1つ必要です。
- `at times` を使う場合は、画像ごとにちょうど1つの時間を昇順で指定し、最後の時間がクリップ内に収まるようにしてください。
- オーディオはビデオと一緒に生成されるため、戻ってくる前に個別に編集することはできません。
- シードを指定しても実行結果は再現されません。同じグラフを再実行すると異なる結果になります。
