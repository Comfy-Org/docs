FLUX 1.1 Pro Ultra は、BlackForestLabs による高性能な AI 画像生成ツールで、超高解像度と効率的な生成能力を特徴としています。標準版の4倍にあたる最大4MPの解像度をサポートしながら、1枚あたりの画像生成時間を10秒未満に抑えています。これは同クラスの高解像度モデルと比べて2.5倍高速です。

このツールには2つの主要モードがあります：
- **Ultra モード**：高解像度が求められる用途向けに設計されており、細部の拡大表示が重要となる広告やEコマースに最適です。プロンプトを正確に反映しながら、生成速度も維持します。
- **Raw モード**：自然なリアリズムに重点を置き、肌の色調、ライティング、風景の細部を最適化します。「AI らしさ」を抑え、写真表現やリアルなスタイルの制作に最適です。

## Flux 1.1 Pro Ultra Image が得意なこと

- **ウルトラ高解像度**: 最大 4MP の画像を生成し、スタンダードバージョンの 4 倍の解像度
- **高速生成**: 1 枚の画像生成時間を 10 秒未満に保ち、同様の高解像度モデルより 2.5 倍高速
- **大規模でも正確なプロンプト反映**: Ultra Mode は生成速度を維持しながらプロンプトを正確に反映し、広告や e コマースの業務に適している
- **自然なリアリズム**: Raw Mode は肌の色、照明、風景の詳細を最適化し、「AI らしさ」を軽減
- **画像から画像へのリミックス**: `image_prompt` 入力が入力画像の特徴をブレンドし、`image_prompt_strength` がブレンド比率を制御する

### 2. ワークフロー手順の実行

![ワークフロー手順](/images/tutorial/api_nodes/bfl/flux_1_1_pro_t2i_step_guide.jpg)

番号付きの手順に従って、基本的なワークフローを完了してください:

1. （任意）`Flux 1.1 [pro] Ultra Image` ノードのプロンプトを変更します
2. （任意）よりリアルな出力を得るには、`raw` パラメータを `false` に設定します
3. `Run` をクリックするか、ショートカット `Ctrl（macOS の場合 Cmd）+ Enter` を押して画像を生成します
4. API が結果を返した後、`Save Image` ノードで生成された画像を確認します。画像は `ComfyUI/output/` ディレクトリに保存されます

## Flux 1.1[pro] 画像から画像へのチュートリアル

ノード入力に `image_prompt` を追加すると、出力は入力画像の特徴をブレンドします（Remix）。`image_prompt_strength` の値はブレンド比率に影響し、値が高いほど出力は入力画像に似たものになります。

### 1. ワークフローファイルをダウンロード

次のファイルをダウンロードして ComfyUI にドラッグするか、テキストから画像へのワークフロー内のパープルノードを右クリックして `mode` を `always` に設定し、`image_prompt` 入力を有効にします：

![Flux 1.1 pro 画像から画像への Remix](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/bfl/flux_1_1_pro_i2i.png)

この画像を入力として使用します：
![入力画像](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/openai-dall-e-3/text2image.png)

### 2. ワークフローの手順を完了する

![ワークフローの手順](/images/tutorial/api_nodes/bfl/flux_1_1_pro_i2i_step_guide.jpg)

以下の番号付きの手順に従ってください：
1. `Load Image` ノードの **Upload** をクリックして入力画像をアップロードします
2. （任意）`Flux 1.1 [pro] Ultra Image` 内の `image_prompt_strength` を調整してブレンド比率を変更します
3. `Run` をクリックするか、ショートカット `Ctrl(cmd) + Enter` を使用して画像を生成します
4. API が結果を返した後、`Save Image` ノードで生成された画像を確認します。画像は `ComfyUI/output/` ディレクトリに保存されます
