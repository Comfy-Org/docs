FLUX Video Edit は、Black Forest Labs が提供するテキスト駆動のビデオ編集エンドポイントで、ComfyUI ではパートナーノードとして利用できます。ソースクリップと自然言語の指示を渡すと、その指示に合わせて映像を書き換えます。

この編集は、ショット内で何が起きるかを変更するものであり、どのように撮影されるかを変えるものではありません。長さ、フレーミング、カメラの動き、オーディオトラックはすべてソースクリップから引き継がれるため、結果は何かと再同期することなく編集に戻してカットできます。そのため、オブジェクトの削除、追加、置き換え、映像のスタイル変更、設定の変更、画面上のテキストの書き換え、セリフの置き換えなどに役立ちます。

このノードは、Comfy API を通じて Black Forest Labs のサーバー上で完全に実行されます。モデルのダウンロードやローカル GPU は不要です。クレジットを登録した Comfy API アカウントが必要です。

## FLUX Video Edit が得意なこと

- **指示のみ**: 変更内容を言葉で記述するだけで、マスク、参照画像、制御入力は不要
- **構造を保持**: 長さ、フレーミング、カメラの動き、オーディオはソースクリップから引き継がれる
- **オブジェクト単位の編集**: オブジェクト、キャラクター、背景要素の削除、追加、置き換え
- **リスタイル**: 手持ちの映像の見た目、ライティング、設定を変更
- **テキストとセリフ**: 画面上のテキストを書き換え、話されるセリフを置き換え
- **最大15秒**: 0.7秒から15秒のソースクリップを受け付け

## 編集指示の書き方

プロンプトが唯一のクリエイティブなコントロールなので、丁寧に書く価値があります。

- 画面上で変化するものだけを記述します。言及しなかった部分は、元のまま維持される想定です。
- 被写体と結果を同じ文で示します。たとえば「ギタリストを同じポーズのゴリラに置き換える」のように書きます。
- 指示は平易な言葉で、最大4096文字まで書けます。形状、マテリアル、動作に関する詳細が、おおよそモデルがどれだけ変化するかに対応します。
- 差し替えるセリフは、オリジナルの音声の長さに近づけてください。新しいセリフは、オリジナルの音声が占める時間にフィットする必要があるからです。無音のクリップは無音のままです。
- シードがあっても実行が再現可能になるわけではありません。FLUX は独自にシードを選択するため、同じクリップに同じ指示を使っても異なる結果が返ることがあります。

## ノードオプションリファレンス

| オプション | 値 | デフォルト | 備考 |
| ------ | ------ | ------- | ----- |
| `video` | ソースクリップ | 必須 | 0.7～15秒、最小160x160ピクセル |
| `prompt` | テキスト | 空 | 変更したい内容を平易な言葉で、最大4096文字 |
| `auto_downscale` | on / off | on | アップロード前に、1280x704を超える面積のソースをアスペクト比を維持したまま縮小します |
| `safety_tolerance` | 0～4 | 4 | 高度な機能。モデレーションの許容値で、`0` が最も厳格です |
| `seed` | 0～4294967295 | 42 | FLUX は独自にシードを選択するため、この値に関係なく結果は非決定的です |

## 制限

- ソースクリップの長さは 0.7 秒から 15 秒で、少なくとも 160x160 ピクセルである必要があります。
- 出力は 24 fps でレンダリングされ、1 フレームあたり約 0.9 メガピクセル（1280x704）に制限されるため、大きなソースはより小さなサイズで返されます。
- 課金はクリップの秒単位です。詳しくは[パートナーノードクレジット](/ja/tutorials/partner-nodes/pricing)をご覧ください。
