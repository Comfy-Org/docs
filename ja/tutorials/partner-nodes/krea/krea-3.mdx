Krea 3 は、[Krea](https://www.krea.ai) が提供するホステッド画像モデルです。指示に基づく編集のために作られており、変更したい部分とそのままにしたい部分を記述すると、モデルが編集後の画像を返します。画像を接続しなければ、代わりにテキストから生成します。

Krea 3 はパートナーノードとして ComfyUI 内で動作するため、ダウンロードする重みファイルはなく、自分の GPU で実行される処理もありません。このノードはプロンプトと参照画像を Krea のサーバーに送信し、完成した画像をワークフローに返します。

## Krea 3 が得意なこと

- **指示による編集**: 変更内容を平易な言葉で書く（「緑の車をオレンジの車に置き換える」）と、Krea 3 は変更を求めていない部分をそのまま保ちながら、画像全体を返します
- **同じノードからの Text to image**: 画像の入力欄を空のままにすると、ノードはプロンプトだけで生成します
- **最大 8 枚の参照画像**: 参照したい順番で接続し、プロンプト内で `@Image1`、`@Image2` のように記述して呼び出します
- **2 つの思考モード**: `fast` がデフォルトで推奨設定であり、`high` は複雑な編集をより詳細に計画するため時間がかかります
- **精密な編集**: `precise_edit` をオンにすると、編集領域の外側をすべて変更せずに保ちます
- **解像度の制御**: 1K または 2K の出力で、`auto` のアスペクト比は最初の参照画像に従います

## Krea 3 テキストから画像へのワークフロー {#api_krea3_t2i}

プロンプトだけで画像を生成します。Krea 3 Image ノードには画像が接続されていないため、プロンプトとアスペクト比の設定が使用されます。

1. **Krea 3 Image** ノードにプロンプトを記述します。同梱のサンプルは、被写体、ライティング、構図を説明する1つの詳細な文です
2. `aspect_ratio` を設定します。プロンプトに従う場合は `auto` のままにするか、サポートされている10種類の比率から1つを選択します
3. `resolution` を選択します。テンプレートには `1K` が同梱されており、`2K` はより高いコストでより大きなキャンバスを提供します
4. `thinking_mode` は `fast` のままにするか、プロンプトが複雑なシーンを記述している場合は `high` に切り替えます
5. **Queue** をクリックします。画像は `SaveImageAdvanced` ノードによって `ComfyUI/output/` に保存されます

<img src="https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/input/wide_format_digital_render.png" alt="wide_format_digital_render.png" style={{width: '100%', height: 'auto'}} />

1. 編集したい画像を `LoadImage` ノードに読み込み、**Krea 3 Image** ノードに接続します
2. 編集内容を指示として記述します。付属の例では、シーン内の緑の車をオレンジの車に置き換え、変更してはいけない要素（構図、背景、建物、砂埃、ライティング、パースペクティブ）を列挙しています
3. 編集領域の外側をすべて保持する必要がある場合は `precise_edit` をオンにします。少なくとも1つの参照画像が必要です
4. 出力キャンバスに合わせて `aspect_ratio` と `resolution` を調整します
5. **Queue** をクリックし、入力と結果を比較します

**その他の参照画像**

このノードは最大 8 枚の画像を受け付けます。参照したい順に追加し、プロンプト内でそれぞれを `@Image1`、`@Image2` のように記述します。

## Krea 3 ノードのパラメータ

**Krea 3 Image** ノード（`Krea3ImageNode`）は以下の設定を公開しています。

- `image_1` ... `image_8`: 最大8枚の参照画像で、接続順に番号が付けられます。text to image の場合は空のままにしてください
- `prompt`: 指示またはシーンの説明。参照は `@Image1`、`@Image2` のように指定します
- `aspect_ratio`: `auto`、または `1:1`、`4:5`、`3:4`、`2:3`、`9:16`、`5:4`、`4:3`、`3:2`、`16:9`、`21:9` のいずれか。`auto` は最初の参照画像に従い、画像が接続されていない場合はプロンプトに従います
- `resolution`: `1K` または `2K` の出力
- `thinking_mode`: `fast` が推奨です。`high` は複雑な編集をより詳細に計画し、時間がかかります
- `precise_edit`: 編集領域の外側をすべて変更せずに保持します。少なくとも1つの参照画像が必要です
- `seed`: リクエストのシード。Krea は生成前にプロンプトを書き換えるため、同じシードでも同じ画像は再現されません

## 注意事項と制限

- **プロンプトの書き換え**: Krea は生成の前にプロンプトを書き換えるため、同じシードを使い回しても同じ画像は再現されません
- **参照のサイズ**: 各参照画像はアップロードされる前に出力のピクセルバジェットに合わせてスケーリングされるため、2K 設定のほうが 1K よりも参照のディテールを多く保持できます
- **課金**: Krea 3 はパートナーノードであるため、実行ごとにあなたの Comfy アカウントに課金されます。料金については [パートナーノードクレジット](/ja/tutorials/partner-nodes/pricing) を、同時に実行できるリクエスト数については [同時実行数の上限](/ja/tutorials/partner-nodes/concurrency-limits) を参照してください
- **バージョン**: Krea 3 Image ノードは ComfyUI [PR #17067](https://github.com/comfyanonymous/ComfyUI/pull/17067) に含まれており、2 つのテンプレートは `workflow_templates` 0.11.84 以降のテンプレートライブラリに含まれています
