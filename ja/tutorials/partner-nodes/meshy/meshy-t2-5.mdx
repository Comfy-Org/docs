**Meshy T2.5** は、指定した三角形数で直接3Dメッシュを生成します。従来のパイプラインでは高密度のメッシュを生成してから後でリトポロジを行うため、ディテールが失われ、アセットを出荷する前にクリーンアップが必要でした。T2.5は最初からポリゴン予算を狙うため、15000三角形のプロップはおよそ15000三角形で返ってきて、そのままエンジンに持ち込めます。

ComfyUIでは、これを2つのパートナーノードで利用できます。**Meshy: Text to Model (Smart Topology)** と **Meshy: Image to Model (Smart Topology)** です。どちらもクラウドAPIノードで、クレジット付きのComfyアカウントが必要であり、モデルファイルをローカルにダウンロードしません。それぞれGLBファイルとFBXファイルを返し、テンプレートではSave GLBノードでGLBを書き出します。

T2.5は、三角形数を予測できることが重要なプロップ、環境装飾、ローポリのゲームアセット向けのモードです。リギング、アニメーション、アセット制作の全工程には、代わりに[Meshy 7](/ja/tutorials/partner-nodes/meshy/meshy-7)を使用してください。

`texture_prompt` と `texture_image` は同時に使用できません。どちらか一方でテクスチャを誘導するか、両方とも空にしてソース画像に任せてください。

## ノードのコントロール

| コントロール | 値 | 適用対象 | 効果 |
| --- | --- | --- | --- |
| `model` | `meshy-t2.5` | 両方のノード | Smart Topology モデルのリリース |
| `prompt` | テキスト、最大800文字 | Text to Model | 構築するオブジェクトの説明 |
| `image` | 1枚の画像 | Image to Model | メッシュの生成元となるソース画像 |
| `target_polycount` | 100〜30000、デフォルト 15000 | 両方のノード | 結果のおおよその三角形数 |
| `pose_mode` | 空、`A-pose`、`T-pose` | 両方のノード | キャラクターの立ち姿勢を固定します。プロップの場合は空のままにします |
| `should_texture` | `true`、`false` | Image to Model | 生成後にメッシュへテクスチャを適用するかどうか |
| `enable_pbr` | デフォルトはオフ | Image to Model、テクスチャ有効時 | ベースカラーにメタリック、ラフネス、ノーマルマップを追加します |
| `texture_prompt` | テキスト、最大800文字 | Image to Model、テクスチャ有効時 | テクスチャのテキストガイダンス。`texture_image` と併用できません |
| `texture_image` | 1枚の画像 | Image to Model、テクスチャ有効時 | テクスチャの画像ガイダンス。`texture_prompt` と併用できません |
| `texture_resolution` | `2k`、`4k`、`8k` | Image to Model、テクスチャ有効時 | 生成されるテクスチャの解像度 |
| `seed` | 整数 | 両方のノード | ノードを再実行するかどうかを制御します。Meshy の出力はシードに関係なく非決定的です |

ノードは `meshy_task_id`、`GLB`、`FBX` を出力します。Save GLB は、タスク ID や FBX 出力ではなく、`GLB` 出力からファイルを書き出します。

## プロンプトのヒント

- **オブジェクトとシルエットを指定する。** `Standalone game prop, clean silhouette, no text` を指定すると、モデルがシーンや台座、文字を勝手に追加するのを防げるため、後から削除する手間が省けます。
- **生成する前にポリゴン数の予算を決める。** 後から `target_polycount` を変更すると再生成になるため、そのアセットが主役級の小道具なのか背景用なのかを先に決めてください。
- **ライティングリグではなくマテリアルを説明する。** `weathered wood, iron banding, rusted lock plate` のような表面を表す言葉はメッシュとテクスチャに反映されます。スタジオライティングの言葉はプレビューの見え方にしか影響しません。
- **`pose_mode` はキャラクターにのみ使う。** A-pose や T-pose はリグに適した姿勢になります。プロップは空のままにしておくのがおすすめです。
- **形状が正しくなってからテクスチャを付ける。** まずテクスチャなしで一度実行してシルエットを確認し、最終パスで `should_texture` をオンにします。
- **同じメッシュが二度得られるとは期待しない。** シードはノードを再実行するかどうかを決めるだけなので、再実行すれば新しい結果になります。
