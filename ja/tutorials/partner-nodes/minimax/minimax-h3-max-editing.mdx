MiniMax H3 Maxの編集系ノード6種は、ビデオや静止画を出発点としてそのマテリアルを編集します。他のH3 APIノードと同様にComfy APIアカウントを通じて実行され、ComfyUI 0.44.0で追加されました。

このうち3つにはワークフローテンプレートが付属しています。**Cast Swap**（`api_minimax_h3_max_recast`）、**Aspect Ratio Reframe**（`api_minimax_h3_max_reframe`）、**Camera Control**（`api_minimax_h3_max_camera_control`）です。残りの3つは**Partner Nodes > video > MiniMax**のノードライブラリにあり、自身のワークフローにそのまま追加できます。最初の2つは以下で解説します。[Camera Controlのテンプレート](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/api_minimax_h3_max_camera_control.json)は静止画の周りをカメラが周回し、クリップに音楽を重ねます。

MiniMax H3、H3 Max、H3 Max Turboでの生成については、[MiniMax H3 API ビデオ生成](/ja/tutorials/partner-nodes/minimax/minimax-h3)を参照してください。

## MiniMax H3 Max: キャストスワップ

ご自身のクリップを読み込み、新しい人物1人につき1枚、最大4枚までの写真を接続します。デフォルトでは、写真はクリップ内の主要な人物を左から右へ置き換えるため、希望する順番に接続してください。プロンプトは任意です。写真を `@Image1` から `@Image4` として指定し、誰が誰になるのか、また変わらずに保つ必要があるものを記述してください。

- **ソースクリップ**: 5～30秒、1カットが15秒を超えないこと、アスペクト比は0.4～2.5の範囲であること
- **参照写真**: 最小 256 x 256 ピクセル、最大4枚
- **解像度**: 768P または 1080P
- **リアリズムを強化**: デフォルトはオフ。より自然な肌の質感とシーンへのより良いなじみを得るにはオンにします

同梱のデモでは、垂直のポートレートクリップを 16:9 のフレームに変換します。ご自身のクリップを読み込み、目標のアスペクト比と解像度を選択し、プロンプトで新しい領域を何で埋めるかを記述してください。たとえば、被写体の両側にすでに存在する背景を続けるよう指定します。

- **ソースクリップ**: 0.5〜300 秒
- **アスペクト比**: 16:9、9:16、1:1、4:3、3:4、21:9、9:21
- **解像度**: 480P、768P、1080P

## MiniMax H3 Max 編集ノード

| ノード | 機能 | 入力メディア |
| :--- | :----------- | :------------- |
| **MiniMax H3 Max Recast** | ビデオ内の人物を参照写真の人物に置き換えます。動き、カメラワーク、カット、ソースのサウンドは維持されます | 5-30秒のビデオ、1-4枚の写真 |
| **MiniMax H3 Max Extend Video** | プロンプトで記述した新しい映像でビデオを続けます | 1.625-60秒のビデオ（H3 Max または H3 Max Turbo） |
| **MiniMax H3 Max Reframe Video** | ビデオを新しいアスペクト比に収め、その周囲の領域を生成します。タイミングとサウンドは維持されます | 0.5-300秒のビデオ |
| **MiniMax H3 Max Insert Video** | 2つのタイムスタンプの間の区間を、新しく生成したシーンに置き換えます | 最大60秒のビデオ、および開始時刻と再開時刻 |
| **MiniMax H3 Max Lip Sync** | 静止画像をアニメーション化し、口元がオーディオトラックに合わせて動くようにします | 画像1枚、5-899秒のオーディオ |
| **MiniMax H3 Max Camera Control** | 静止画像内の被写体の周りをカメラが周回します | 画像1枚、および終了角度と距離 |

Recast、Extend Video、Insert Videoのプロンプトでは、接続した参照を `@Image1`、`@Video1`、`@Audio1` として参照します。番号は接続順に付けられます。Recast は `@Image` タグを、Extend Video は `@Audio` タグを、Insert Video は `@Image` と `@Video` のタグを検査します。検査対象のタグが、その種類で接続した参照の範囲を超えると、エラーで実行が停止します。それ以外の種類のタグはそのまま渡されます。[Reference to Video](/ja/tutorials/partner-nodes/minimax/minimax-h3#minimax-h3-参照からビデオへ) 生成ノードは3種類すべてのタグを解決します。

ノードおよび解像度ごとの料金は [Minimax料金表](/ja/tutorials/partner-nodes/pricing) に記載されています。
