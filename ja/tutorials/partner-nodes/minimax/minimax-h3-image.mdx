MiniMax H3 Image は MiniMax の画像モデルで、ComfyUI では **MiniMax H3 Image** パートナーノードから利用できます。テキストから画像への生成と画像編集は同じノードを使います。参照画像を接続しない場合はプロンプトから生成し、参照画像を接続した場合はそれらを編集または合成します。

ワークフローは Comfy API アカウントを通じて MiniMax のサーバー上で実行されるため、モデルのダウンロードやローカル GPU の管理は不要です。

## MiniMax H3 Image が得意なこと

- **2K・4K 出力**: サイズティアとアスペクト比を選ぶか、幅と高さを正確に指定できます
- **画像編集**: 最大 16 枚の参照画像を編集または結合できます。プロンプト内では `@Image1` から `@Image16` として指定します
- **プロンプトの書き換え**: MiniMax はデフォルトで短いプロンプトを詳細なシーン説明へと展開し、書き換え後のプロンプトを画像とともに返します
- **ポスター品質のディテール**: 読みやすいテキストと緻密なディテールが求められるポスター、パッケージ、エディトリアル画像に適しています

## オプション

| 入力 | 値 | 備考 |
| :---- | :----- | :---- |
| `model` | `MiniMax-H3-Image`、`MiniMax-H3-Image-Highspeed` | テンプレートでは `model` ドロップダウンを変更して切り替えます |
| `size` | `2K`、`4K`、`custom` | 2K と 4K はアスペクト比から幅と高さを導出します。`custom` は幅と高さをそれぞれ 512〜7680 px の範囲で受け取り、合計は 655,360〜20,000,000 px、アスペクト比は最大 3:1 です |
| `aspect_ratio` | `auto` と 15 種類の固定比率 | `auto` はプロンプトに従うか、参照画像が接続されている場合はその参照画像に従います |
| `enhance_prompt` | デフォルトでオン | MiniMax はまずプロンプトを詳細なシーン記述に書き換えます。編集では常に拡張が行われるため、オフにしても影響するのはテキストからの画像生成のみで、その場合は固定比率またはカスタムサイズが必要です |
| `images` | 最大 16 枚 | 編集や合成のための参照画像です。プロンプト内では接続順に `@Image1`、`@Image2` などのように参照します |

参照画像が接続されている場合、プロンプトは最大 8,000 文字まで使用できます。ノードは画像とともに、書き換えられた `revised_prompt` も返します。
