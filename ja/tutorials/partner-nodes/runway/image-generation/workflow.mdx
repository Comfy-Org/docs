## Runway Imageのテキストから画像ワークフロー

### 1. ワークフローファイルのダウンロード

以下の画像には、`metadata`にワークフロー情報が含まれています。画像をダウンロードしてComfyUIにドラッグし、対応するワークフローを読み込んでください。

![ComfyUI Runway Image テキストから画像](https://raw.githubusercontent.com/Comfy-Org/example_workflows/refs/heads/main/api_nodes/runway/image/text_to_image.png)

### 2. ワークフロー実行をステップバイステップで完了する

![ComfyUI Runway Image テキストから画像 ステップガイド](/images/tutorial/api_nodes/runway/runway_text_to_image_step_guide.jpg)

画像の番号を参照して、基本的なテキストから画像ワークフローの実行を完了できます：

1. `Runway Text to Image`ノードで、`prompt`フィールドにプロンプトを入力します
2. （任意）`ratio`設定を調整すると、出力のアスペクト比を変更できます
3. `Run`ボタンをクリックするか、ショートカット`Ctrl(cmd) + Enter`を使用して画像生成を実行します。
4. APIが結果を返すのを待った後、`Save Image`ノードで生成された画像を確認できます（右クリックで保存）。対応する画像は`ComfyUI/output/`ディレクトリにも保存されます。

## Runway Imageの参照から画像生成ワークフロー

### 1. ワークフローと入力画像のダウンロード

以下の画像には、`metadata`にワークフロー情報が含まれています。画像をダウンロードしてComfyUIにドラッグし、対応するワークフローを読み込んでください。

![ComfyUI Runway Image 参照から画像生成](https://raw.githubusercontent.com/Comfy-Org/example_workflows/refs/heads/main/api_nodes/runway/image/reference_to_image/runway_reference_to_image.png)

入力用に以下の画像をダウンロードしてください

![ComfyUI Runway Image 参照から画像生成 入力画像](https://raw.githubusercontent.com/Comfy-Org/example_workflows/refs/heads/main/api_nodes/runway/image/reference_to_image/input.png)

### 2. ワークフロー実行をステップバイステップで完了する

![ComfyUI Runway Image 参照から画像生成 ステップガイド](/images/tutorial/api_nodes/runway/runway_reference_to_image_step_guide.jpg)

画像の番号を参照して、基本的な参照から画像生成ワークフローの実行を完了できます：

1. `Load Image`ノードで、提供された入力画像を読み込みます
2. `Runway Text to Image`ノードで、`prompt`フィールドにプロンプトを入力し、サイズを調整します
3. `Run`ボタンをクリックするか、ショートカット`Ctrl(cmd) + Enter`を使用して画像生成を実行します。
4. APIが結果を返すのを待った後、`Save Image`ノードで生成された画像を確認できます（右クリックで保存）。対応する画像は`ComfyUI/output/`ディレクトリにも保存されます。
