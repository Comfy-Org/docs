Runway は、生成AIに特化した企業であり、強力な動画生成機能を提供しています。現在、ComfyUI には Runway API が統合されており、関連ノードを ComfyUI 上で直接利用して動画を生成できます。

現在、ComfyUI では以下の Runway 動画生成モデルがネイティブ対応しています：
- Runway Gen4 turbo

<Warning>
  **サービス終了（EOL）**：**Runway Gen3a Turbo** と **Runway 最初-最後フレームから動画生成** は **2026年7月30日** にサービス終了しました。Runway は同日に Gen-3 Alpha Turbo を廃止しました。関連パートナーノード（`RunwayImageToVideoNodeGen3a`、`RunwayFirstLastFrameNode`）およびワークフローテンプレートは非推奨となり、サポート対象外です。
</Warning>

## Runway 動画生成が得意なこと

- **画像から動画への生成**：`Runway Gen4 turbo` ノードは、入力画像と動画コンテンツを説明するテキストプロンプトからビデオを生成します。
- **調整可能なビデオの長さ**：`duration`（再生時間）パラメーターを変更して、ビデオの長さを設定します。
- **調整可能なアスペクト比**：`ratio`（比率）パラメーターを変更して、ビデオのアスペクト比を設定します。
