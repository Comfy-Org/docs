**Breeze TTS 2** は、Breeze Blue のオープンウェイト音声合成モデルです。英語と中国語をネイティブにサポートし、51言語をカバーする多言語バリアントも用意されています。

ComfyUI ではパートナーノードを通じて実行します。**Breeze Text to Speech** は、選択した音声でスクリプトを読み上げます。**Breeze Voice Selector** は、注目の音声、または所有している任意の音声 ID を選択します。さらに4つのノードで音声を作成・調整できます。**Breeze Voice Clone** は録音から音声をコピーし、**Breeze Voice Design** は説明から音声を生成し、**Breeze Voice Remix** は既存の音声を変化させ、**Breeze Voice Localize** は音声を別の言語に移します。いずれもクラウド API ノードです。クレジット付きの Comfy アカウントが必要で、ローカルモデルはダウンロードされません。料金は[パートナーノードの料金ページ](/ja/tutorials/partner-nodes/pricing)に記載されています。

## テキスト読み上げ

セリフを書き、声を選択すると、ノードがそのセリフを読み上げたオーディオを返します。`(sighs)` や `(laughs)` といった音声タグは、読み上げられるのではなく演じられます。そのため、ポーズや笑い声は、ページ上のテキストとしてではなくモデルから出力されます。

このテンプレートはクローンした声で読み上げます。`breeze_tts2_tts_clone_audio.wav` は **Breeze Voice Clone** を通り、返された voice id が、`language` を `custom` に設定した **Breeze Voice Selector** に入力され、それが **Breeze Text to Speech** を動かします。代わりに注目の声を使うには、テンプレート内のもう一方の **Breeze Voice Selector**（言語 `English`、声 `Elizabeth`）を **Breeze Text to Speech** の `voice` 入力に接続してください。これはワークフローに含まれていますが、接続されていません。

さらに2つのグループがバイパスされた状態で含まれています。**Breeze Voice Remix** は既にある声を変化させ、**Breeze Voice Design** は説明から声を作ります。どちらも `voice` 出力で voice id を返しますが、その出力は接続されていません。**Preview as Text** ノードに接続して id を読み取るか、**Breeze Text to Speech** の `voice` 入力に直接接続してください。グループのノードを選択し、**Ctrl+B** を押してバイパスを解除してワークフローを実行し、その id を `language` を `custom` に設定した **Breeze Voice Selector** に貼り付けてください。

## デリバリー制御

`delivery` は、セリフの読み上げ方を設定します：

- `neutral` は、声をその声本来のサウンドに近づけます。`speaker_boost` は、よりオリジナルに近い状態を保ちます。
- `directed` は、記述された `instructions` に従います。例：「温かく、急がず、最後の言葉で微笑む」。指示はテキストと同じ言語で書き、`strength` を設定して、声がどの程度文字通りに指示に従うかを制御します。

`speed` は、ピッチを変えずにテンポを 0.5 から 2.0 まで変更します。

## ボイスの作成

| ノード | 入力 | 得られるもの |
| --- | --- | --- |
| Breeze Voice Clone | 話者 1 人、最低 3 秒。ファイルの最初の 60 秒のみが読み取られ、Breeze は最も良い 30 秒を保持します。`remove_background_noise` は、雑音の多いスマートフォンでの録音に役立ちます | 新しいボイス ID とオーディオプレビュー |
| Breeze Voice Design | 3〜500 文字の `description`（年齢、性別、アクセント、トーン、ペース）と `preview_text` の一行。ボイスはその行から作成されるため、対象言語で書いてください | 新しいボイス ID とオーディオプレビュー |
| Breeze Voice Remix | 既存のボイスと、言葉で説明した `change`、または年齢、性別、ピッチ、ペース、エネルギー、感情、ロールプレイ、話し方にわたる 27 種類のプリセットのいずれか。`strength` は 1〜10 で、どれだけ変化させるかを設定します | 変更されたボイスのコピー |
| Breeze Voice Localize | 既存のボイスと対象言語 | 同じボイスが別の言語を話すもの |

Remix はオリジナルの言語を維持します。言語をまたぐ場合は Localize を使用してください。クローンには、再現する権利のあるボイスのみを使用してください。同意が必須です。

## ノードの操作

| コントロール | 値 | 対象 | 効果 |
| --- | --- | --- | --- |
| `voice` | 注目の音声、またはカスタムID | テキスト読み上げ | 読み上げに使用する音声。Breeze Voice Selector または他の音声生成ノードから指定します |
| `text` | 最大1000文字 | テキスト読み上げ | 読み上げるセリフ。括弧内のオーディオタグは演出として反映されます |
| `language` | 8つの注目言語、または`custom` | Voice Selector | 注目の音声をグループ化します。注目の音声がない言語では、`custom`に音声IDを指定する必要があります（Breeze Voice Localize で作成したものなど） |
| `language` | 51言語 | テキスト読み上げ、Design | テキストの言語。英語と中国語はどちらのモデルも使用でき、その他の言語は多言語モデルを使用します |
| `model` | `Breeze TTS 2`、`Breeze TTS 2 Multilingual` | テキスト読み上げ、Design | 英語と中国語の場合にのみ表示されます。この2言語は両方のモデルで動作します |
| `delivery` | `neutral`、`directed` | テキスト読み上げ | そのままの読み上げ、または記述された指示に従った読み上げ |
| `speed` | 0.5～2.0 | テキスト読み上げ | テンポ。ピッチは変わりません |
| `seed` | 整数 | すべての音声ノード | ノードを再実行するかどうかを制御します。結果は実行ごとに異なります |

音声はその言語で最も自然に聞こえます。聞き慣れた声で別の言語を話させるには、まず Breeze Voice Localize を通してください。
