PixVerse は、テキストと画像からシネマティックなビデオを生成する AI ビデオ生成プラットフォームで、現在は ComfyUI のパートナーノードとして統合されています。**V5.6**、**V6**、**C1**、**R1** モデルをサポートし、**テキストから動画へ**、**画像から動画へ**、**テンプレート画像から動画へ** のモードにより、別途 API キーや外部セットアップなしで、迅速かつ再現性のあるビデオ制作を可能にします。

<ReqHint/>
<UpdateReminder/>

## 主な機能

- **テキストから動画へ**: テキストプロンプトからオリジナルビデオを生成します。コンセプトの可視化、ストーリーボード作成、迅速なクリエイティブ探索に最適です。
- **画像から動画へ**: 被写体の同一性とシーン構成を保ちながら参照画像をアニメートし、自然な動きで静止画に命を吹き込みます。
- **テンプレート画像から動画へ**: 入力画像に定義済みのモーションテンプレートを適用し、制作パイプラインに適した予測可能で再現可能なアニメーションスタイルを実現します。
