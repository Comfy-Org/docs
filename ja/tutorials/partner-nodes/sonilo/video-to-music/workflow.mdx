このガイドでは、ComfyUI で Sonilo 動画から音楽生成ワークフローを実行する方法を説明します。このサービスの概要や得意分野については、[Sonilo 動画から音楽生成の概要](/ja/tutorials/partner-nodes/sonilo/video-to-music) を参照してください。

## はじめる

<Steps>
  <Step title="ComfyUI をアップデート">
    ComfyUI を最新バージョンにアップデートするか、[Comfy Cloud](https://www.comfy.org/cloud) を使用してください。
  </Step>
  <Step title="Sonilo ワークフローを見つける">
    **ワークフローライブラリ** を開き、**テンプレート** をブラウズして、"Sonilo" を検索すると、すぐに使えるワークフローが見つかります。
  </Step>
  <Step title="ワークフローを実行">
    ビデオソースを接続し、プロンプトを更新して、**Run** ボタンをクリックするか、`Ctrl(Cmd) + Enter` を使用して生成します。
  </Step>
</Steps>

### Sonilo: ビデオサウンドトラック生成 {#api_sonilo_v2m}

ビデオ映像から同期したサウンドトラックを生成します。ビデオを入力すると、そのテンポや感情表現に合った音楽を生成します。

<img src="https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/templates/api_sonilo_v2m-1.webp" alt="Sonilo: ビデオサウンドトラック生成ワークフローのプレビュー" />

<CardGroup cols={2}>
  <Card title="Comfy Cloud で実行" icon="cloud" href="https://cloud.comfy.org/?template=api_sonilo_v2m&utm_source=docs&utm_medium=referral&utm_campaign=video-to-music">
    Comfy Cloud で開く
  </Card>
  <Card title="ワークフローをダウンロード" icon="download" href="https://github.com/Comfy-Org/workflow_templates/blob/main/templates/api_sonilo_v2m.json">
    JSON をダウンロードするか、テンプレートライブラリで &quot;Sonilo: Video Soundtrack Generation&quot; を検索してください。
  </Card>
</CardGroup>

**入力素材**

このファイルを対応する `LoadVideo` ノードにアップロードします:

<CardGroup cols={2}>
  <Card title="leopard_rider.mp4" icon="video" href="https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/input/leopard_rider.mp4">
    `LoadVideo` ノード 705 · `leopard_rider.mp4`
  </Card>
</CardGroup>

1. 入力ノードにビデオを読み込みます。
2. (任意) 生成する音楽のスタイルや雰囲気を指定するテキストプロンプトを追加します。
3. **Run** ボタンをクリックするか、ショートカット `Ctrl(Cmd) + Enter` を使用して音楽生成を開始します。
4. 生成されたオーディオは `ComfyUI/output/audio` ディレクトリに保存されます。

### Sonilo: テキストから音楽生成 {#api_sonilo_t2m}

テキストプロンプトから高品質で本番利用可能な音楽を生成します。

<img src="https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/templates/api_sonilo_t2m-1.webp" alt="Sonilo: テキストから音楽生成ワークフローのプレビュー" />

<CardGroup cols={2}>
  <Card title="Comfy Cloud で実行" icon="cloud" href="https://cloud.comfy.org/?template=api_sonilo_t2m&utm_source=docs&utm_medium=referral&utm_campaign=video-to-music">
    Comfy Cloud で開く
  </Card>
  <Card title="ワークフローをダウンロード" icon="download" href="https://github.com/Comfy-Org/workflow_templates/blob/main/templates/api_sonilo_t2m.json">
    JSON をダウンロードするか、テンプレートライブラリで &quot;Sonilo: Text to Music Generation&quot; を検索してください。
  </Card>
</CardGroup>

**プロンプト例:**

- `Dreamy ambient electronic music, gentle rhythm, suitable for short videos`
- `Futuristic electronic instrumental, sci-fi sense, ethereal and deep`
- `Lazy jazz instrumental, saxophone, relaxing cafe atmosphere`

1. 生成したい音楽を説明するテキストプロンプトを入力します。
2. **Run** ボタンをクリックするか、ショートカット `Ctrl(Cmd) + Enter` を使用してオーディオ生成を開始します。
3. 生成されたオーディオは `ComfyUI/output/audio` ディレクトリに保存されます。
