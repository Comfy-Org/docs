[LTX-2.5](https://ltx.io/model/ltx-2-5) は、Lightricks のオープンウェイトのビデオおよびワールドモデルで、ComfyUI では LTX-2.5 APIノードを通じて利用できます。APIワークフローは Lightricks のサーバー上で生成を実行するため、モデルのダウンロードやローカル GPU は必須ではなく、生成済みビデオ 1 秒ごとに Comfy API アカウントへ請求されます。

LTX-2.5 API は 2 つのモデルティアを提供します。最大品質向けの **LTX-2.5 (Pro)** と、蒸留モデルによる高速生成向けの **LTX-2.5 (Fast)** です。どちらのティアも、ネイティブのマルチショットシーンによるオーディオとビデオの同期生成をサポートし、Fast ティアでは最大 4K 解像度の出力に対応します。

## LTX-2.5 が得意なこと

- **オーディオとビデオの同期**: 両ティアともオーディオとビデオを同時に生成し、ネイティブのマルチショットシーンに対応します
- **2つのモデルティア**: LTX-2.5 (プロ) は最高品質、LTX-2.5 (Fast) は蒸留モデルによる高速生成を提供します
- **最大4K出力**: Fast ティアは最大4K解像度で出力します
- **ローカルGPUは必須ではありません**: 生成はLightricksのサーバー上で実行され、モデルのダウンロードは不要です
- **複数の生成モード**: テキストから動画へ、画像から動画へ、最初と最後のフレームから動画生成

## LTX-2.5 APIワークフロー

テンプレートライブラリには、3つのAPIサンプルワークフローが含まれています:

- **テキストからビデオへ**: テキストプロンプトからビデオを生成します
- **画像からビデオへ**: 1枚の開始画像からビデオを生成します
- **FLF2V**: 最初と最後のフレーム画像の間のビデオを生成します

#### プロンプトのヒント

1. **モデル**: 最高品質には`LTX-2.5 (Pro)`、高速生成には`LTX-2.5 (Fast)`を選択します
2. **再生時間**: Proは2〜10秒、Fastは2〜20秒に対応しています。10秒を超える再生時間には720pまたは1080pの解像度と24/25 FPSが必要です
3. **解像度と比率**: `1280x720`（横）や`720x1280`（縦）などの解像度プリセットを選択します。Fastでは`2560x1440`と`3840x2160`のオプションが追加されます
4. **FPS**: Fastでは24、25、48、50 FPSから、Proでは24、25、50 FPSから選択できます
5. **オーディオ**: オーディオ生成はデフォルトでオンです。無音ビデオのみが必要な場合は、ノードの高度な機能設定で無効にできます
6. **プロンプト**: ショット、アクション、キャラクター、カメラの動き、希望するオーディオを含むシーン全体を、1つの流れるような段落で説明します

#### プロンプトのヒント

1. **モデル**: このワークフローは高速なイテレーションのために`LTX-2.5 (Fast)`が選択済みです。最大品質にするには`LTX-2.5 (Pro)`に切り替えます
2. **画像は1枚のみ**: 画像入力には開始画像を1枚だけ指定できます
3. **プロンプト**: 開始画像から続く動き、カメラの動き、音など、次に何が起こるかを説明します。「提供された開始画像を最初のフレームとして使用する」のような表現は、生成の基準を固定するのに役立ちます
4. **再生時間と解像度**: Fastティアは最大20秒、4Kまでの解像度に対応しています。10秒を超える再生時間には24/25 FPSでの720p/1080pが必要です

#### プロンプトのヒント

1. **フレーム**: ワークフローは最初の画像を`image`入力に、2番目の画像を`last_frame`入力に接続します。モデルはそれらの間の動きを生成します
2. **フレームを揃える**: スムーズな補間のために、同じアスペクト比の画像を使用します
3. **モデル**: このワークフローは`LTX-2.5 (Pro)`が選択済みです。高速生成には`LTX-2.5 (Fast)`に切り替えます
4. **プロンプト**: フレーム間の遷移と、希望するオーディオ（会話、効果音、音楽）を説明します
