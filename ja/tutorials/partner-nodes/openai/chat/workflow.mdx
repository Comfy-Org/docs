## ワークフローの実行をステップバイステップで完了する

![OpenAI Chat ステップガイド](/images/tutorial/api_nodes/openai/openai_chat_step_guide.jpg)

<Note>
対応するテンプレートには、プロンプト生成を分析するための役割設定が組み込まれています。
</Note>

画像内の番号を参照して、基本的なテキストから画像へのワークフローの実行を完了できます：
1. `Load Image` ノードで、AI に解釈させたい画像を読み込みます
2. (オプション) 必要に応じて、`OpenAI Chat Advanced Options` の設定を変更して、AI に特定のタスクを実行させることができます
3. `OpenAI Chat` ノードで、`Prompt` を変更して会話プロンプトを設定したり、`model` を変更して異なるモデルを選択したりできます
4. `Run` ボタンをクリックするか、ショートカット `Ctrl(cmd) + Enter` を使用して会話を実行します
5. API が結果を返すのを待った後、`Preview Any` ノードで AI が返した対応するコンテンツを確認できます

## 補足説明

- 現時点では、ファイル入力ノード `OpenAI Chat Input Files` は、ファイルをあらかじめ `ComfyUI/input/` ディレクトリにアップロードしておく必要があります。このノードは現在改善中であり、更新後にテンプレートを修正します
- このワークフローは、入力に `Batch Images` を使用した例を示しています。AIによる解釈が必要な画像が複数ある場合は、ステップ図を参照し、右クリックで対応するノードのモードを `Always` に設定して有効にできます
