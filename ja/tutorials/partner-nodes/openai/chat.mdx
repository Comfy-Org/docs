OpenAIは生成AIに特化した企業であり、強力な会話機能を提供しています。現在、ComfyUIはOpenAI APIを統合しており、ComfyUI内の関連ノードを直接使用することで会話機能を実現できます。

## OpenAI Chat が得意なこと

- **インテリジェントな会話**: ComfyUI 内で直接 OpenAI の高度な言語モデルとやり取りできます
- **画像理解**: AI が解釈して応答できるように画像を読み込みます
- **タスク制御**: `OpenAI Chat Advanced Options` を調整して、画像の分析やプロンプトの生成など、特定のタスクを AI に実行させます
- **モデル選択**: `OpenAI Chat` ノードからさまざまな OpenAI モデルを選択できます
- **複数画像の入力**: 複数の画像に AI による解釈が必要な場合は、複数の画像をまとめてバッチ処理できます

## ワークフローの実行をステップバイステップで完了する

![OpenAI Chatのステップガイド](/images/tutorial/api_nodes/openai/openai_chat_step_guide.jpg)

<Note>
対応するテンプレートでは、プロンプト生成を分析するための役割設定を組み込んでいます。
</Note>

画像内の番号を参照して、基本的なテキストから画像へのワークフローの実行を完了できます：
1. `Load Image` ノードで、AIに解釈させたい画像を読み込みます。
2. (任意) 必要に応じて、`OpenAI Chat Advanced Options` の設定を変更して、AIに特定のタスクを実行させることができます。
3. `OpenAI Chat` ノードでは、`Prompt` を変更して会話プロンプトを設定したり、`model` を変更して異なるモデルを選択したりできます。
4. `Run` ボタンをクリックするか、ショートカットキー `Ctrl(cmd) + Enter` を押して会話を実行します。
5. APIが結果を返すのを待った後、`Preview Any` ノードで、AIが返したコンテンツを確認できます。

## 補足

- 現在、ファイル入力ノード `OpenAI Chat Input Files` では、ファイルを先に `ComfyUI/input/` ディレクトリへアップロードする必要があります。このノードは改良中であり、更新後にテンプレートを変更する予定です
- このワークフローでは、入力に `Batch Images` を使用した例を提供しています。AIによる解釈が必要な画像が複数ある場合は、手順の図を参照し、右クリックで対応するノードのモードを `Always` に設定して有効にできます
