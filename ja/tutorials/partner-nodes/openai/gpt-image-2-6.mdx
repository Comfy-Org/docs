GPT Image 2.6 は OpenAI の画像モデルファミリーで、ComfyUI では **OpenAI GPT Image 2.6** パートナーノードから利用できます。2 つのバリエーションがあります。

- **Flare** (`gpt-image-2.6-flare`): 数秒でドラフトを返し、文字密度の高いポスターや商品撮影でもレイアウトを崩さずに保ちます。コンセプトの確認、ムードボード、タイポグラフィ中心のドラフトに使用してください
- **Sunburst** (`gpt-image-2.6-sunburst`): レンダリングの予算を細かなテクスチャ、小さい文字、素材感に費やし、複数回の生成にわたって被写体とライティングの一貫性を保ちます。仕上げのビジュアルや、細部まで作り込む必要がある高密度なレイアウトに使用してください

どちらのバリエーションもテキストから画像の生成と画像編集に対応しており、最大 16 枚の参照画像、ローカル編集用のオプションの注釈レイヤー、`low` から `max` までの品質レベル、そしてレンダリング前にモデルがどれだけ画像を計画するかを設定する `complexity` コントロールを備えています。このノードは 1 回の実行につき 1 枚の画像を返します。**OpenAI GPT Image** ノードは同じ 2.6 と 2.5 のバリエーションを `n` 最大 8 とマスク inpainting で利用でき、GPT Image 2 と GPT Image 1.5 もそこで選択します。

## はじめに

1. ComfyUI を 0.44.2 より後の nightly ビルドにアップデートします。注釈レイヤー、GIF ノード、SVG ノードは 0.44.2 以前のビルドには含まれていません。Desktop では更新チャンネルを **Latest on GitHub** に切り替えてください
2. ノードライブラリで**OpenAI GPT Image 2.6**を検索し、ノードを追加します
3. `model`を`gpt-image-2.6-flare`または`gpt-image-2.6-sunburst`に設定します
4. ノードの画像出力をSave Imageノードに接続するか、以下の4つのテンプレートのいずれかを開きます

## ノード設定

- **model**: 高速な反復には `gpt-image-2.6-flare`、ディテール重視のレンダリングには `gpt-image-2.6-sunburst`
- **prompt**: 生成する内容。参照画像が接続されている場合は編集指示
- **size**: `auto`、`1024x1024` や `3840x2160` などのプリセット、または `Custom`
- **custom_width / custom_height**: `size` が `Custom` のときのみ使用。480 から 3840 まで 16 刻み
- **background**: `auto`、`opaque`、または `transparent`
- **quality**: `low`、`medium`、`high`、`xhigh`、または `max`。コストと生成時間に影響します
- **complexity**: `low`、`medium`、または `high`(デフォルト)。レンダリング前にモデルがどれだけ画像を計画するか
- **images**: 編集用の任意の参照画像。最大 16 枚
- **markup / markup_alpha**: ローカル編集用の任意の注釈レイヤー。最初の参照画像の上に描いた注釈画像を `markup` に、変更する領域全体ではなく注釈として描いたピクセルを白で示したマスクを `markup_alpha` に接続します。どちらも接続するか、どちらも空にするかのどちらかで、サイズは参照画像と同じである必要があります。Painter ノードのマスク出力はそのまま `markup_alpha` に接続できます。Load Image のマスクは、先に Invert Mask が必要です
- **seed**: API 互換性のために保持されていますが、バックエンドではまだ使用されていません

Flare は、うまくいくプロンプトを見つけるための安価な方法です。構図が固まるまで `low` または `medium` 品質で実行し、その後、勝ち残ったプロンプトを Sunburst で再実行して最終画像を生成します。

## GPT Image 2.6 GIF: アニメーション出力

**OpenAI GPT Image 2.6 GIF** ノードはプロンプトからアニメーション GIF を生成し、フレームとフレームレートを返します。`frames` と `fps` を **Save Animated WEBP**、**Save Animated PNG**、**Save WEBM** に接続するとファイルとして保存できます。

- **model**: `gpt-image-2.6-flare` または `gpt-image-2.6-sunburst`
- **size**: `384x384` から `1280x720` または `720x1280` までの 12 種類のフレームサイズ。デフォルトは `512x512`。サイズが大きいほど使えるフレーム数は少なくなります
- **frame_count**: 2 から 16 フレーム、デフォルトは 9。課金は 2-8、9、10-12、13-16 の段階に分かれます
- **frame_duration_ms**: 各フレームの表示時間。20 から 2000 ミリ秒、デフォルトは 200。`fps` はこの値から算出され、200 ミリ秒は 5 fps になります
- **background**: `opaque` または `transparent`。透過は Save Animated WEBP、Save Animated PNG、vp9 の Save WEBM で保持されます
- **quality** と **complexity**: 各フレームの品質と、レンダリング前にモデルがアニメーションをどれだけ計画するか
- **seed**: ノードを再実行するかどうかを制御します。seed の値にかかわらず結果は非決定的です

## GPT Image 2.6 SVG: ベクター出力

**OpenAI GPT Image 2.6 SVG** ノードはプロンプトから編集可能な SVG を生成します。結果はベクターマークアップなので、図形とテキストはベクターエディタで編集できます。`svg` 出力を **Save SVG** に接続すると `.svg` ファイルとして保存できます。

- **model**: `gpt-image-2.6-flare` または `gpt-image-2.6-sunburst`
- **size**: `1024x1024`、`1024x1536`、または `1536x1024`
- **background**: `auto`、`opaque`、または `transparent`
- **quality** と **complexity**: SVG の元になる参照画像の品質と、モデルがどれだけ計画するか
- **seed**: ノードを再実行するかどうかを制御します。seed の値にかかわらず結果は非決定的です
