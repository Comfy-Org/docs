OpenAI DALL·E 3 は、ComfyUI パートナーノードシリーズの一部であり、ユーザーが OpenAI の **DALL·E 3** モデルを用いて画像を生成できるようにします。このノードはテキストから画像を生成する機能をサポートしています。

![OpenAI DALL·E 3 ノードのスクリーンショット](/images/built-in-nodes/api_nodes/openai/openai-dall-e-3.jpg)

DALL·E 3 は OpenAI の最新の画像生成モデルであり、テキストプロンプトに基づいて詳細かつ高品質な画像を作成できます。ComfyUI 内のこのノードを通じて、ComfyUI インターフェースを離れることなく、DALL·E 3 の生成機能に直接アクセスできます。

**OpenAI DALL·E 3** ノードは、OpenAI の画像生成 API を用いて同期的に画像を生成します。テキストプロンプトを入力すると、その説明に合致する画像が出力されます。

## DALL·E 3 が得意なこと

- **テキストから画像への生成**: テキストプロンプトから詳細かつ高品質な画像を生成します。画像の内容を詳細に説明する複数行のプロンプトをサポートしています
- **品質の制御**: 「standard」と「hd」の出力から選択できます。「hd」を選択すると、より高品質な画像が生成されます
- **スタイルの制御**: 超現実的でドラマチックな画像には vivid を、より自然で誇張の少ない画像には natural を選択できます
- **柔軟なサイズ**: さまざまな向きの正方形または長方形の画像を生成できます（1024×1024、1024×1792、1792×1024）
