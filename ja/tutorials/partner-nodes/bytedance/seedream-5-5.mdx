Seedream 5.5 は ByteDance Seed の画像モデルで、Seedream 5.0 Pro の後継として2026年11月9日にリリースされました。ComfyUI ではパートナーAPIを通じて実行されるため、ダウンロードするものはありません。各実行はお客様の Comfy API アカウントに課金されます。

5.0 Pro から変わった点は3つあります。編集されていない領域は長い編集チェーンを通してもピクセルレベルで維持されるため、数十回のラウンドを経ても画像は色に偏りが出たり顔が崩れたりしません。モデルは偽の背景ではなく本物の透過を返します。そして画像内のテキストがより確実にレンダリングされるようになり、これはポスターやパッケージ、ステッカーで重要になります。ByteDance によると、5.5 シリーズの Pro バージョンも今後登場する予定です。

## 機能

- **テキストから画像生成**: プロンプト1つを入力すると画像1枚を出力します。1Kから2Kまでの任意のプリセットに対応します
- **画像編集**: 最大10枚の参照画像から1枚を出力します。サイズを入力し直すとソースの解像度が維持されます
- **透過出力**: ノードで `transparent` を選択すると、返される画像にアルファチャンネルが付与されます
- **文字組み**: キャプション、ラベル、見出しテキストが画像内に描画され、別途オーバーレイする工程は不要です
- **1回の実行で1枚**: このモデルではバッチ生成や連続生成は公開されていません

## サイズと透過

サイズプリセットは 1K、1.5K、2K をそれぞれ8種類のアスペクト比でカバーし、さらに `Custom` があります。`Custom` の幅と高さには 240〜8594 px を指定できますが、モデルが実際にレンダリングするのは 0.92 MP から 4.62 MP の範囲のみであるため、小さなキャンバスはリクエストが送信される前に拒否されます。アスペクト比は 1:16 から 16:1 の範囲内である必要があります。4.62 MP の上限では、正方形は最大で約 2150 x 2150 px までしか出力できません。そのため、最大の正方形プリセットは `(2K) 2048x2048` です。

編集テンプレートはその下限を継承します。0.92 MP 未満のソース画像は、編集する前に拡大する必要があります。

`background` には3つの値があります。`auto` はプロンプトから判断し、主にステッカーやロゴで透過を返します。`opaque` は背景を塗り、`transparent` はアルファチャンネルを強制します。`transparent` は、プロンプトが無地の背景に孤立した被写体を記述しているときに最も効果を発揮します。結果を PNG として保存するとアルファチャンネルが保持されます。JPEG では失われます。

## はじめる

1. ComfyUIを0.45.0以降にアップデートします。
2. テンプレートライブラリを開き、`Seedream 5.5` を検索して、いずれかのワークフローを開きます。
3. ノード上でモデル `seedream 5.5` とサイズプリセットを選択し、実行します。

ノードのモデルドロップダウンを別のSeedreamバージョンに切り替えると、同じワークフローを再利用できます。Seedream 5.0 ProとFlashも引き続き選択可能なプリセットのままで、5.0 Liteと4.5では3Kと4Kの行が表示されます。
