## 画像モデルでできること

- **テキストから画像へ**: テキストプロンプトから画像を生成
- **画像編集**: 既存の画像を変更（コンテンツの変更、スタイル変更、または参照への追従）
- **画像から画像へ**: 構造を維持しながら、入力画像を新しいバージョンに変換
- **アップスケーリングと画質向上**: 解像度を上げたり、品質を向上させたりする
- **ユーティリティワークフロー**: 背景除去、再ライティングなど

## タスク別のモデル選択

### 汎用テキストから画像へ

シンプルなテキストプロンプトから最高の総合品質を得たい場合は、次のいずれかから始めてください：

- **Flux.1 Kontext**（Black Forest Labs）: プロンプトへの高い追従性を備えた最先端の生成。コンテキストを認識した編集のため、複数の入力画像をサポート。
- **Flux 1.1 Pro Ultra**（Black Forest Labs）: Fluxファミリーのハイエンドな生成。
- **GPT-Image-2 / GPT-Image-1**（OpenAI）: 単一のAPIで強力なテキストから画像への生成と画像編集を実現。
- **Qwen Image 3.0 Pro**（Qwen）: AlibabaのQwenファミリーによる高速・高品質な生成。

### 画像編集とインペインティング

これらのモデルは、既存の画像を変更するように設計されています：

- **Nano Banana Pro / Nano Banana 2 / Nano Banana 2 Lite**（Google）: GoogleのGeminiベースの画像編集・生成。会話内でのフォローアップ編集に最適。
- **Luma Uni-1**（Luma）: 自然言語の指示で画像を作成・変更。
- **Muse Image 1.0**（Meta）: 最大 10 枚の参照画像を 1 回の編集で組み合わせられる、指示ベースの画像編集。
- **Ideogram 4.0**（Ideogram）: 画像内のテキスト描画に強み。画像入力を使用した編集に対応。

### 背景除去とユーティリティ

- **Bria Background Removal**（Bria）: 画像の背景をきれいに削除。
- **Bria Fibo / Bria Image Editing**（Bria）: 編集および復元のユーティリティ。
- **Topaz画像強化 Wonder 3.5 / Bloom 2**（Topaz）: 画像品質のアップスケールと復元。

### 速度と予算

- **Nano Banana 2 Lite**（Google）: Nano Bananaファミリーのより軽量で高速なバリアント。
- **Recraft V4 / Recraft Text-to-Image**（Recraft）: スタイルコントロールを備えたデザイン志向の生成。
- **Seedream 5.0 Pro / Lite**（ByteDance）: ByteDanceによる高速生成。
