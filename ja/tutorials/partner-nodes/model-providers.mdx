このページでは、Comfy のパートナーノードを支えるモデルプロバイダーを 1 つの表にまとめています。検証状況、クラウドおよびローカル利用における商用ライセンス、データレジデンシーです。これは現在も記入を進めている途中の構成であり、完成したリファレンスではありません。一部の列は現時点で確認済みの事実を反映していますが、その他は各プロバイダーと詳細を確認するまでのプレースホルダーです。

プロバイダー別の料金については、[パートナーノードの料金](/ja/tutorials/partner-nodes/pricing) を参照してください。

このページでは、パートナーノードを支えるプロバイダーを扱います。Comfy がパートナーノードの入力と出力をどのくらいの期間保存するかについては、[データ保持](/ja/tutorials/partner-nodes/data-retention) を参照してください。各 Comfy Router モデルを提供しているプロバイダーについては、[提供プロバイダー](/ja/development/comfy-router/providers) を参照してください。

## 各列の意味

- **Verified**: 「はい」は、Comfy がこのプロバイダーと契約を締結していることを意味します。契約では、Comfy 経由でこのプロバイダーのモデルを使用する際、あなたのコンテンツがモデルのトレーニングや改善に使用されないことが定められています。契約には IP 補償も含まれます。「いいえ」は、プロバイダー自身の利用規約とプライバシーポリシーが適用されることを意味します。これは、プロバイダーがあなたのデータでトレーニングを行うことを意味するものではありません。
- **Commercial License (Cloud)**: そのプロバイダーのモデルについて、Comfy Cloud を通じた商用利用が確認済みかどうか。
- **Commercial License (Local)**: そのプロバイダーのモデルについて、ローカルでの自己ホスト利用における商用利用が確認済みかどうか。「Request」は、商用利用が自動的に含まれるのではなく、別途リクエストまたはライセンスが必要であることを意味します。
- **Data Residency**: 現時点でプロバイダーがデフォルトでデータを処理する場所。「Pending」（保留中）は、そのプロバイダーと場所についてまだ確認できていないことを意味します。

ライセンス列の「Pending」（保留中）は、そのライセンスがまだ確認できていないことを意味します。これは各パートナーシップの確認が進むにつれて、チェックマーク、ダッシュ、または「Request」に変わります。
