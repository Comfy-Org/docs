FIBO 2.0 は、1 組の重みで画像の生成と編集の両方をこなす Bria の 8B モデルで、ComfyUI ではパートナーノードとして利用できます。FIBO シリーズの土台である構造化キャプションの学習も引き継いでいます。プロンプトは Visual GenAI Language (VGL) のキャプションに展開され、ライティング、構図、色、カメラ、被写界深度が個別のフィールドとして扱われます。両ノードはそのキャプションを `structured_prompt` の JSON 文字列として返します。

この JSON があるからこそ FIBO の結果は予測できます。同じ seed と一緒に戻せば画像を再現でき、1 つのフィールドを変えれば微調整になり、プログラムから組み立てることもできます。FIBO 2.0 は同じモデルに指示ベースの編集を加えました。変更内容を自然言語で伝えるか、構造化プロンプトをそのまま渡せば、指定していない部分はそのまま残ります。

どちらのノードもクラウド API ノードです。クレジットのある Comfy アカウントが必要で、モデルのダウンロードはなく、実行ごとに課金されます。料金は[パートナーノードの料金](/ja/tutorials/partner-nodes/pricing)を参照してください。このページでは、Bria Expand Image ノードを使うアウトペインティングのテンプレートも扱います。

## Bria FIBO 2.0 が得意なこと

- **1 つのモデルで両方向**: 同じ FIBO 2.0 の重みで、新しい画像の生成も既存画像の編集もできます
- **構造化された制御**: ライティング、構図、カメラ、スタイルは推測ではなく明示的な JSON フィールドです
- **崩れない編集**: 変更を依頼していない領域では、被写体の同一性、レイアウト、ライティング、細部が保たれます
- **文字と質感**: 画像内の文字が読みやすく、素材の表面が説明的で、人体の描写も従来の FIBO より安定しています
- **ライセンス済みデータ**: ライセンス済みデータのみで学習しており、商用利用に必要な来歴を備えています

FIBO 2.0 がよく対応する編集:

- **時間帯とライティングの変更**: 場面を作り直さずに時刻や光源を変えられます
- **素材と質感の差し替え**: 布地、金属、表面加工、衣類
- **マスク領域の編集**: 変更を描いた領域に限定し、それ以外はピクセル単位で維持します
- **テキストの調整**: 画像内の文字を書き換える、または別の見た目にします
- **スタイル変換**: 写真を別のアートディレクションで描き直します
- **ポスターと表紙**: 見出しを文字どおりに描画する必要がある、文字主体のレイアウト

### Bria: FIBO 2.0 テキストから画像 {#api_bria_fibo2_t2i}

画像を説明し、比率を選んで実行するだけです。FIBO 2.0 はプロンプトを構造化キャプションに展開し、1MP または 4MP で生成して、そのキャプションを画像と一緒に返します。後から再現したり微調整したりできます。

**使い方**

1. **プロンプトを書く**: `prompt` に画像を説明します。FIBO 2.0 は長く具体的な指示に忠実で、画像内に入れたい文言もそのまま反映します。
2. **比率を選ぶ**: `aspect_ratio` の既定値は `1:1` で、プリセットには `16:9`、`9:16`、`4:3`、`3:2` のほか、より横長な `2:1`、`21:9`、`3:1`、`5:1` があります。
3. **解像度を選ぶ**: `resolution` は `1MP` または `4MP` です。
4. **任意の参照画像**: 写真を `image` につなぐとスタイルや内容を誘導できます。結果は選んだ比率の新しい構図で、その写真の編集ではなく、`structured_prompt` との併用はできません。
5. **実行と反復**: `seed` で結果を再現できます。`structured_prompt` 出力には JSON キャプションが入るので、別の FIBO 2.0 ノードに渡して 1 つのフィールドだけ変えたり、後で同じ画像を再生成したりできます。

<Note>
FIBO 2.0 の拡張プリセット（`16:10`、`10:16`、`2:1`、`1:2`、`21:9`、`9:21`、`3:1`、`1:3`、`4:1`、`1:4`、`5:1`、`1:5`）は `1MP` のみで、`prompt` か `structured_prompt` のどちらか一方だけを受け付けます。バナーやソーシャル用ヘッダーには横長の比率を使ってください。標準の比率では両方を同時に使えます。
</Note>

### Bria: FIBO 2.0 画像編集 {#api_bria_image_edit}

変更内容を伝えて編集します。マスクを使えば変更を 1 つの領域に限定できます。FIBO 2.0 は編集領域の外側の同一性、レイアウト、細部を保ち、その編集の構造化プロンプトを返すので、JSON から再現や微調整ができます。

**使い方**

1. **画像を読み込む**: `LoadImage` にアップロードし、`BriaImageEditNode` につなぎます。
2. **変更を伝える**: `prompt` に変更内容を書きます。例: `Modern architectural photography at night, blue hour`。不要な要素は `negative_prompt` で除外します。
3. **JSON を使う場合**: 以前の FIBO 2.0 の結果に含まれる `structured_prompt` を貼り付けると、正確で再現性のある制御ができます。`prompt` と `structured_prompt` はどちらか一方のみで、同時には指定できません。
4. **任意のマスク**: 再生成したい領域を描いて `mask` につなぎます。マスクを付けない場合は画像全体が編集対象になり、画像とサイズが一致しないマスクは拒否されます。
5. **調整して実行**: `guidance_scale` は 3 から 5（高いほどプロンプトに忠実）、`steps` は 20 から 50 です。`seed` で結果を再現できます。
