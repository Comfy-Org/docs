**HeyGen Avatar 6** は、写真、短いキャラクタービデオ、または HeyGen アバターのルックを、提供した音声または記述したセリフにリップシンクさせたトーキングクリップに変換します。

ComfyUI では 2 つのパートナーノードを通じて実行されます。**HeyGen Avatar 6 Reference to Video** は、写真またはスタイライズされたキャラクターを独自のオーディオトラックに合わせてアニメーション化します。**HeyGen Avatar 6 Identity to Video** は、選択した声で、記述したスクリプトからストックまたはカスタムのアバターをレンダリングします。どちらもクラウド API ノードです。クレジット付きの Comfy アカウントが必要で、ローカルモデルはダウンロードされません。料金は[パートナーノードの料金ページ](/ja/tutorials/partner-nodes/pricing)に記載されています。

すべての実行は 1080p または 2K で、16:9、9:16、1:1、4:5、5:4 のいずれかでレンダリングされ、クリップの長さは音声に合わせて決まります。`heygen-avatar-6` がデフォルトのエンジンです。`heygen-avatar-6-turbo` はより高速で安価なオプションです。

## 利用可能なワークフロー

### 写真またはビデオからビデオへ

1枚の写真、スタイライズされたキャラクターの短いビデオ、またはその両方を、自分のオーディオで話すクリップに変換します。レンダーの長さはオーディオによって決まります。

- 写真はアイデンティティとシーンを設定します。最初のフレームとしては使用されません。モデルがポーズを再構成するため、腕を組んだ写真はポーズを変えて返されます。
- 参照ビデオはキャラクターの話し方や動きを示すもので、長さは最低2秒です。より長いクリップは最初の30秒にトリミングされます。実在の人物を写したビデオは拒否されます。代わりにその人物の写真を接続してください。
- オーディオの長さは1.5秒から10分までです。

### アイデンティティからビデオへ

撮影なしでプレゼンターをレンダリングします。ストックのルックまたは自分で作成したアバターを選び、セリフを書き、ボイスを選択します。`speech` が `script` のときは何も接続する必要はありません。`audio` のときは Load Audio ノードを `audio` 入力に接続してください。

`speech` には2つのモードがあります。**script** はセリフを `text`（最大5000文字）に書き込み、選択した `voice` で読み上げます。任意で `voice_speed` の倍率を指定できます。**audio** は0.5秒から10分までの自分のクリップを使用し、クリップの長さがレンダーの長さになります。

このテンプレートには、独自のアバターとボイスを作成する2つのバイパスされたグループも含まれています。グループのノードを選択して **Ctrl+B** でバイパスを解除し、**実行** または **Ctrl+Enter** でワークフローを実行してから、保存された ID を再利用してください。保存されるテキストはプレフィックスと ID を連結したものなので、先に **Concatenate Text** の `string_a` のプレフィックスを消すか、作成ノードの出力から生の ID をコピーしてください:

- **Avatar**: `source` を `photo` に設定した `HeyGen Create Avatar` がルック ID を返します。メインノードで `avatar` を `custom avatar` に設定し、その ID を `custom_avatar_id` に貼り付けます。`pink_hair_portrait.png` はテンプレートに同梱されています。
- **Voice**: `HeyGen Voice 1.0 Instant Clone` は、少なくとも10秒のクリーンな単一話者のオーディオからボイス ID を返します。それを `custom_voice_id` に貼り付けてください。空でない限り、`voice` ドロップダウンを上書きします。`avatar6_voice_sample.mp3` はテンプレートに同梱されています。

## ノードのコントロール

| コントロール | 値 | 対象 | 効果 |
| --- | --- | --- | --- |
| `model` | `heygen-avatar-6`, `heygen-avatar-6-turbo` | 両方のノード | エンジン。Turbo は安価で高速 |
| `resolution` | `1080p`, `2k` | 両方のノード | 16:9 の場合、`1080p` では 1920x1080、`2k` では 2880x1620 でレンダリング |
| `aspect_ratio` | `auto`, `16:9`, `9:16`, `1:1`, `4:5`, `5:4` | 両方のノード | `auto` は写真に従い、写真が接続されていない場合はビデオに従う。Identity to Video ではアバターのソース映像に従う。その他の値はシーンを再フレーミングする |
| `motion_prompt` | テキスト、最大 1200 文字 | 両方のノード | ジェスチャー、表情、姿勢、カメラの動き |
| `motion_expressiveness` | `less`, `default` | 両方のノード | `less` はジェスチャーを抑える。重複する部分ではモーションプロンプトが優先される |
| `seed` | 整数 | 両方のノード | ノードを再実行するかどうかを制御する。結果は実行ごとに変わる |
| `image` | 写真 1 枚 | Reference to Video | クリップのアイデンティティとシーン。最初のフレームとしては使用されない |
| `video` | クリップ 1 本、2〜30 秒 | Reference to Video | キャラクターの話し方と動き方。実在の人物は拒否される |
| `audio` | 1.5 秒〜10 分 | Reference to Video | リップシンクする音声、およびクリップの長さ |
| `avatar` | ストックルック、`custom avatar` | Identity to Video | プレゼンター。`custom avatar` を指定すると `custom_avatar_id` が表示される |
| `speech` | `script`, `audio` | Identity to Video | 選択したボイスによる台本、または自分のオーディオクリップ |

Reference to Video は画像、ビデオ、またはその両方を接続する必要があります。Identity to Video は `script` モードでは入力の接続が不要で、`audio` モードではオーディオ入力が必要です。

## プロンプトのヒント

- **`motion_prompt` で演技を指示する**。アバターがどのように話し、動くかを指定します。キーワードに合わせたジェスチャー、リラックスした肩、わずかな首の傾き、カメラへのゆっくりとしたプッシュインなどです。ニュートラルな演出にしたい場合は空のままにします。
- **フレームがタイトなときはジェスチャーを小さくする**。頭と肩のクロップでは `motion_expressiveness` を `less` に設定します。大きなジェスチャーはフレームからはみ出してしまうためです。
- **クリーンな単一話者のオーディオを使う**。背景音楽や2人目の声がトラックに含まれていると、リップシンクに現れてしまいます。ボイスクローンなら、10秒の連続した発話で十分です。
- **写真は接続する前にフレーミングする**。`auto` は写真の形状を維持するため、後からフレーミングし直すのではなく、希望するアスペクト比にクロップしてください。
