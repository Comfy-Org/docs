**HeyGen Voice 1.0** は、1人の話者の短い録音を再利用できる声に変換し、その声で任意の台本を読み上げます。学習待ちはありません。接続したクリップからクローンが作成され、返される `voice_id` がテキスト読み上げノードに必要な情報のすべてです。自分の声でのナレーション、キャラクターのセリフ、多言語のボイスオーバーに向いています。

ComfyUI では、この機能は2つのパートナーノードで実行します。**HeyGen Voice 1.0 Instant Clone** が録音を受け取って `voice_id` を返し、**HeyGen Voice 1.0 Text to Speech** がその声でテキストを読み上げます。どちらもクラウド API ノードで、クレジット付きの Comfy アカウントが必要となり、ローカルモデルはダウンロードしません。クローンは無料で、テキスト読み上げは1K文字あたりの課金です。料金は[パートナーノードの料金](/ja/tutorials/partner-nodes/pricing)を参照してください。

テンプレートは2つのノードを1つのワークフローにまとめ、音声と `voice_id` を記録したテキストファイルの両方を保存します。次回はクローンし直さずに同じ声を再利用できます。

## HeyGen Voice 1.0 が得意なこと

- **短い録音からクローン**: 10秒のクリアな音声で十分で、クリップの最初の3分までが使われます
- **声の再利用**: `voice_id` 出力はテキスト読み上げに接続でき、HeyGen Avatar Video と HeyGen Talking Photo の `custom_voice_id` にも指定できます
- **2つの速度**: `heygen-voice-1-turbo` は高速で、料金は `heygen-voice-1` の約4分の1です
- **表現力の調整**: `expressiveness_boost` は低い値で録音に近づき、高い値で感情が増します

### 実行手順

1. **録音を読み込む**: **LoadAudio** ノードに、1人の話者の10秒以上のクリアな音声を接続します。最初の3分までが使われます
2. **声をクローンする**: **HeyGen Voice 1.0 Instant Clone** で `language` を録音の言語に設定し、`similarity` を選びます。`seed` を変えると再クローンされ、少し違う声になります
3. **台本を書く**: **HeyGen Voice 1.0 Text to Speech** の `text` に5000文字までのプレーンテキストを入力し、クローンノードの `voice_id` 出力を `voice_id` 入力に接続します
4. **表現力を設定する**: `expressiveness_boost` は0から1までです。`0` が録音に最も近く、`1` が最も感情豊かになります
5. **Queue をクリック**するか `Ctrl+Enter` を押して生成します
6. **結果を保存する**: テンプレートは **SaveAudioAdvanced** で音声を、**SaveText** で声の ID を `output/HeyGen_Voice_id/` に保存します

## ノードのコントロール

### HeyGen Voice 1.0 Instant Clone

| コントロール | 値 | 効果 |
| --- | --- | --- |
| `audio` | 音声1本 | 1人の話者の録音。10秒以上が推奨で、最初の3分までが使われます |
| `language` | `auto` または言語 | 録音で話されている言語 |
| `similarity` | `medium`、`high`、`extra_high`、`max`（デフォルト） | クローンした声が録音にどれだけ近づくか |
| `remove_background_noise` | デフォルトでオン | クローン前に録音をクリーンアップします |
| `seed` | デフォルト 42 | 変更すると再クローンされ、毎回少し違う声になります |

### HeyGen Voice 1.0 Text to Speech

| コントロール | 値 | 効果 |
| --- | --- | --- |
| `model` | `heygen-voice-1`、`heygen-voice-1-turbo` | turbo は高速で、料金は約4分の1です |
| `voice_id` | クローン済みの声の ID | Instant Clone ノードの出力 |
| `text` | 1〜5000文字 | 読み上げる台本。約12分を超える音声は失敗するため、非常に長い中国語や日本語のテキストは分割してください |
| `language` | `auto` または言語 | セルビア語やマレー語など、自動判定が混同しやすい言語では明示的に設定します |
| `expressiveness_boost` | 0.0〜1.0、デフォルト 0.5 | 値が高いほど表現豊かになり、低いほど元の声に近づきます |

## 制限

- クローンには録音の最初の3分までが使われ、実用上は10秒以上のクリアな音声が必要です。
- テキストは5000文字、約12分の音声までです。プレーンテキストのみを受け付け、それ以外は拒否されます。
- インスタントボイスはテキスト読み上げの `seed`、`speed`、`pitch` を無視します。話し方は `expressiveness_boost` のみで調整します。
- `voice_id` はクローンから取得する必要があります。空の ID はエラーになります。
- クローンは無料で、テキスト読み上げはモデルの料率で1K文字あたりの課金です。
