[OpenRouter](https://openrouter.ai) は大規模言語モデル向けの統合ルーティングプラットフォームです。単一 API で複数プロバイダーにアクセスでき、連携方式を変えずにモデルを切り替えられます。ComfyUI では **OpenRouter LLM** パートナーノードから接続し、Claude、GPT、Gemini、Grok、DeepSeek、Qwen、Mistral、GLM、Kimi、Perplexity Sonar など、厳選されたテキスト／マルチモーダルモデルを 1 つのノードで選べます。

<ReqHint/>
<UpdateReminder/>

## できること

- **テキストチャット** — `prompt` と任意の `system_prompt` で役割やタスクを指定
- **ビジョン** — 対応モデルで参照画像を接続（スロット数はモデル依存）
- **動画入力** — Gemini 3.5 Flash、Qwen 3.6 Plus/Flash で参照動画（任意）
- **推論** — 推論／フロンティア推論モデルで `reasoning_effort`（`off`、`low`、`medium`、`high`）
- **ウェブ検索** — Perplexity Sonar で `search_context_size` により根拠付き回答

トークン料金は [パートナーノード料金](/ja/tutorials/partner-nodes/pricing#openrouter) を参照してください。

## モデルごとに変わる入力

**model** は動的コンボです。モデルを変えると表示される入力が変わります。

- **画像スロット** — ビジョン対応モデルのみ。上限までスロット表示
- **動画スロット** — Gemini 3.5 Flash、Qwen 3.6 Plus/Flash のみ
- **推論 effort** — 推論／フロンティア推論モデル
- **検索コンテキストサイズ** — Perplexity Sonar 系

テキスト専用モデルでは画像・動画入力は表示されません。

### OpenRouter LLM (`api_openrouter_llm`)

OpenRouter の厳選リスト（Claude、GPT、Gemini など）からモデルを選択します。ビジョン対応モデルでは必要に応じてメディア（画像や動画）をアップロードしてテキスト応答を生成します。

<Note>
このサンプルでは、ワークフローが参照画像を分析し、下流の画像ノード用にテキストから画像へのプロンプトを返します。**Load Image** ノードを省略したり、プロンプトを変更したり、グラフ全体を作り直して独自のユースケースに活用できます。
</Note>

テンプレートを参考にする場合、一般的な実行手順は以下の通りです：

1. **Load Image** で参照画像を読み込む（テキスト専用の場合はスキップ）
2. **OpenRouter LLM** で画像を `image_1` に接続する（モデルが対応している場合はさらにスロットが表示されます）
3. **prompt** を設定する（例：モデルに画像を分析させ、生成用のプロンプトを出力させる）
4. （オプション）高度な機能のオプションで **system_prompt** を設定する（トーン、形式、制約の指定）
5. **model** を選択する。表示されたら **reasoning_effort** または **search_context_size** を調整する
6. **Run** をクリック、または `Ctrl(cmd) + Enter` を押す
7. **Preview Any** で応答を表示する

### 補足

- **seed** — `0` に設定すると省略されます。ほとんどのモデルでは単なるヒントとして扱われます。
- 参照画像や動画はワークフロー実行時に自動的にアップロードされます。ノードには ComfyUI の画像/動画出力を接続するだけで OK です。
- モデルごとの価格は、[OpenRouterの価格ページ](/ja/tutorials/partner-nodes/pricing#openrouter) を参照してください。
