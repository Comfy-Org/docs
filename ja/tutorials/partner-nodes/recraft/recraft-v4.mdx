Recraft V4 は、プロフェッショナルなデザイン作業向けに開発された画像生成モデルです。デザイナーとの共同開発により、構図、ライティング、色の関係性、マテリアルのリアリズムに最適化されています。Recraft V4.1 は、このモデルファミリーの最新アップデートであり、短いプロンプトを解釈し、さまざまな出力スタイルにわたって自然なフォトリアリズムを生成するように設計されています。

## Recraft V4 が得意とする分野

- **1つのモデルでラスターとベクターを両立**: フォトリアリスティックな画像、スタイライズされたイラスト、プロダクション対応のSVGを同じモデルから生成
- **より優れたディテール**: クリーンなテクスチャ、より正確な照明、より精密なジオメトリ。複雑なシーンでも崩れない
- **破綻しない顔と解剖学**: 複数の被写体やアクションポーズでも、安定したプロポーションと表情を実現
- **テキストレンダリング**: 看板、パッケージ、インフォグラフィック向けの読みやすいテキスト。短いフレーズや中程度の長さのフレーズを得意とする
- **SVG出力**: クリーンなラインと適切な色のセグメンテーションを持つ編集可能なベクター。プロダクション品質のベクター出力
- **プロンプト精度**: 空間関係、マテリアル、反射などを含む詳細なクリエイティブディレクションに忠実に従う
- **V4 Pro**: 同じモデルでより高い解像度を実現。印刷や大判制作向けに2048×2048で出力

### ワークフローの実行手順

1. （任意）`Recraft Style` ノードを変更して、ビジュアルスタイルを制御します
2. （任意）`Recraft Text to Image` ノード内の `prompt` パラメーターを編集します

## Recraft V4 スタイル

Recraft V4 / V4.1 生成ノードでは、再利用可能なスタイルを適用できます。`style_id` を渡すか、スタイル参照画像を接続すると、すべての出力を同じルックで統一できます。

- **Recraft V4 Create Style**: 1〜10枚の参照画像から再利用可能なスタイルを作成し、`style_id` を返します。このスタイルは、同じ出力タイプ（ラスターまたはベクター）のすべてのRecraft V4 / V4.1モデルで利用でき、参照画像の合計サイズは10 MBに制限されます
- **スタイル必須モデル**: `recraftv4_styles` と `recraftv4_styles_pro` モデル、およびそのベクター版は、常に `style_id` またはスタイル参照画像が必要です。他のV4モデルではスタイルはオプション入力です
- **スタイル入力**: `style_id` と `style_references` は同じ実行で併用できません。スタイル参照画像は生成料金に追加で請求され、ノードは作成された `style_id` を再利用のために返します
- **スタイルマッチ**: `precise` はスタイルを詳細に再現し、`flexible` は全体的なルックに合わせます

### Recraft V4 スタイル参照ワークフロー

Recraft V4 Styles を使用すると、1つ以上の参照画像のスタイルで画像を生成できます。このテンプレートは、Recraft V4 Create Style ノードを使用して4つの参照画像から再利用可能な `style_id` を作成し、それを Recraft V4 テキストから画像生成に渡します。トレーニングやファインチューニングは不要です。スタイルは参照画像だけでテクスチャ、構図、レンダリングをキャプチャします。

## 補足情報

- **Recraft Style**：写真風、デジタルアート、ロゴデザインなど、さまざまなプリセットスタイルを提供します  
- **Seed パラメーター**：ノードを再実行するかどうかを判断するためだけに使用されます。実際の生成結果はシード値の影響を受けません
