## Recraft テキストから画像パートナーノードワークフロー

### 1. ワークフローファイルをダウンロード

ワークフロー情報は、下の画像のメタデータに含まれています。ダウンロードして ComfyUI にドラッグすると、ワークフローを読み込めます。

![Recraft テキストから画像ワークフロー](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/recraft/t2i/recraft_t2i.png)

### 2. ワークフローを実行する手順に従う

![Recraft テキストから画像ワークフローの手順](/images/tutorial/api_nodes/recraft/recraft_t2v_step_guide.jpg)

以下の番号付きの手順に従って、基本ワークフローを実行します。
1. (任意) `Color` ノードの `Recraft Color RGB` を好みの色に変更します
2. (任意) `Recraft Style` ノードを変更して、デジタルアート、リアルな写真、ロゴデザインなどの視覚スタイルを制御します。このグループには、必要に応じて有効にできる他のスタイルノードも含まれています
3. (任意) `Recraft Text to Image` ノードの `prompt` パラメータを編集します。`size` パラメータも変更できます
4. `Run` ボタンをクリックするか、ショートカット `Ctrl(cmd) + Enter` を使用して画像を生成します
5. API が結果を返した後、`Save Image` ノードで生成済み画像を表示できます。画像は `ComfyUI/output/` ディレクトリにも保存されます

> (任意) ワークフローには **SVG に変換** グループが含まれています。このグループの `Recraft Vectorize Image` ノードは追加クレジットを消費するため、生成した画像を SVG 形式に変換する必要がある場合にのみ有効にしてください

### 3. 補足

- **Recraft Style**: リアルな写真、デジタルアート、ロゴデザインなど、さまざまなプリセットスタイルを提供します
- **シードパラメータ**: ノードを再度実行するかどうかを決定するためにのみ使用されます。実際の生成結果はシード値の影響を受けません
