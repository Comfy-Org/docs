### ワークフローを実行する手順

1. （任意）ビジュアルスタイルを調整するには、`Recraft Style` ノードを変更します
2. （任意）`Recraft Text to Image` ノードの `prompt` パラメータを編集します
3. （任意）出力サイズを変更するには、`size` パラメータを変更します
4. `Run` ボタンをクリックするか、ショートカットキー `Ctrl(cmd) + Enter` を使用して画像を生成します
5. API が結果を返した後、`Save Image` ノードで生成済みの画像を確認します

## Recraft V4 スタイル

Recraft V4 および V4.1 の生成ノードは、再利用可能なスタイルを適用できます。`style_id` を渡すか、スタイル参照画像を接続することで、すべての出力を同じ外観に統一できます。

- **Recraft V4 Create Style**: 1〜10枚の参照画像から再利用可能なスタイルを作成し、`style_id` を返します。このスタイルは、同じ出力タイプ（ラスターまたはベクター）のすべてのRecraft V4およびV4.1モデルで機能し、参照画像の合計サイズは10 MBに制限されています。
- **スタイル必須モデル**: `recraftv4_styles` および `recraftv4_styles_pro` モデルは、そのベクター版も含め、常に `style_id` またはスタイル参照画像が必要です。他のV4モデルでは、スタイルをオプションの入力として受け付けます。
- **スタイル入力**: `style_id` と `style_references` は1回の実行で組み合わせることはできません。スタイル参照画像は生成に加えて課金され、ノードは再利用のための `style_id` を返します。
- **スタイルマッチ**: `precise` はスタイルを詳細に再現し、`flexible` は一般的な外観に合わせます。

## 補足

- **Recraft Style**: リアルな写真、デジタルアート、ロゴデザインなど、さまざまなプリセットスタイルを提供します
- **シードパラメータ**: ノードを再度実行するかどうかの判断にのみ使用されます。実際の生成結果はシード値に影響されません
