HappyHorse 1.1は、アリババのプロダクショングレードビデオ生成モデルの最新リリースであり、ComfyUIでパートナーノードとして利用可能になりました。短編エピソードシリーズ、ECコマーシャル、ブランドマーケティングコンテンツ、ゲームのカットシーンなど、実際のクリエイティブ制作のために設計されています。

際立った特徴は**ネイティブ同期オーディオ生成**です。HappyHorse 1.1は、セリフ、効果音、BGMを1回のレンダリングパスで生成し、オーディオはビジュアルタイムラインに密接に同期されます。オーディオのための追加ステップは不要です。

バージョン1.1は、制作に不可欠な5つのコア機能をターゲットにしています: ダイナミックで表現力豊かなモーション、一貫性のあるキャラクターレンダリング、信頼性の高いプロンプト遵守、安定したテキストレンダリング、本格的な映画的フレーミングです。

## HappyHorse 1.1 が得意なこと

- **ネイティブなオーディオ・ビデオ同期**: セリフ、SFX、背景音楽を1パスで処理（追加の手順は不要）
- **3つの生成パス**: テキストから動画へ（T2V）、画像から動画へ（I2V）、参照から動画へ（R2V）
- **複数画像R2V**: 1回の生成につき最大**9枚の参照画像**を、アイデンティティを保持したまま使用可能
- **マルチキャラクターの一貫性**: 複数のキャラクター参照が視覚的に混ざり合うことなく、それぞれ明確に区別されたまま維持される
- **キャラクター×シーンの分離**: キャラクターとシーンを独立した参照として入力できる。背景が変わってもキャラクターの一貫性を維持する
- **長文コンテキストのプロンプト**: 2,500文字を超えるプロンプトに対応。1つのプロンプトで連続する6〜8シーンを記述でき、モデルが自律的に時間を配分してカメラアングルを切り替える
- **映画的表現**: ショット・リバース・ショット、トラッキングショット、ショット間の一貫したトランジションとテンポを完全サポート
- **柔軟な出力**: 720p / 1080p、3〜15秒、アスペクト比16:9 / 9:16 / 1:1 / 4:3 / 3:4 / 21:9などに対応
- **本番対応の画質**: v1.0のテカリ肌や過度なシャープニングの問題を修正し、自然なクローズアップやシリーズコンテンツを実現する

## はじめに

1. ComfyUIを最新バージョンに更新する
2. ノードライブラリで「HappyHorse」のノードを検索するか、テンプレートライブラリから既製のテンプレートを読み込む
3. モードを選択: テキストから動画、画像から動画、参照から動画
4. プロンプトと参照画像を接続して実行する
5. 出力は720pまたは1080pでオーディオが組み込まれた状態で届きます
