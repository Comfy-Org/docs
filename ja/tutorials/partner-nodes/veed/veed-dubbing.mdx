VEED Dubbing は、クリップ内の音声を別の言語に翻訳します。各話者の声はクローンされ、唇の動きも翻訳に合わせて再同期されるため、字幕としてではなく、ターゲット言語で話しているように見えます。

ComfyUI では **VEED Dubbing** ノードとして利用でき、2つのモデルティアがあります。`standard` はより安価なティアで、モノラルオーディオ、85 のターゲット言語に対応し、スペイン語はラテンアメリカ版、ポルトガル語はブラジル版として扱われます。`pro` は地域アクセントとステレオオーディオを追加し、`English (UK)`、`Spanish (Mexico)`、`Chinese (Taiwan)` などのバリアントを含む 101 のターゲット言語に到達します。

これはクラウド API ノードです。クレジット付きの Comfy アカウントが必要で、モデルファイルのダウンロードは行わず、出力の秒単位で課金されます。現在の料金については[パートナーノードの料金](/ja/tutorials/partner-nodes/pricing)をご覧ください。

## ノードのコントロール

| コントロール | 値 | 効果 |
| --- | --- | --- |
| `model` | `standard`, `pro` | 吹き替えのティア。`standard` はモノラルで 85 言語に対応し、`pro` は地域アクセントとステレオオーディオを加えて 101 言語に対応 |
| `video` | クリップ | 吹き替える映像。最大 599 秒で、顔が写っており、音声トラックに発話が含まれていること |
| `target_language` | 言語リスト | 吹き替え先の言語。リストはティアによって異なり、`pro` にはアクセントのバリエーションが含まれる |
| `source_language` | `auto` または言語 | ビデオ内で話されている言語。デフォルトは `auto` |
| `seed` | 整数 | 再実行の制御のみ。結果は非決定的なまま |

## ヒント

- **話者が映っている映像を送信します。** 吹き替えは見える内容に基づいて機能するため、カメラの方を向いた1人の人物が確実なケースです。後頭部、手、商品のショット、群衆のシーンは吹き替えされません。
- **オーディオに実際に発話が含まれていることを確認します。** ナレーション、対話、インタビューはいずれも機能します。音楽、効果音、無音にはモデルが翻訳できるものがありません。
- **`auto` が聞き間違える場合はソース言語を指定します。** `auto` はクリーンな録音を処理しますが、短いクリップや強いアクセントでは、`source_language` を自分で設定するとより正確に吹き替えられます。
- **アクセントが重要な場合は `pro` を選択します。** スタンダードティアでは言語ごとに1つのバリエーションのみが提供されるため、イギリス英語やメキシコのスペイン語のリクエストは `pro` でのみ利用できます。
- **まず長さ制限に収まるようにカットします。** ノードは最大599秒のビデオを受け付け、出力はオーディオトラックと同じ長さになるため、実行後にトリミングするのではなく実行前にトリミングしてください。

## はじめる

1. ComfyUIを最新バージョンにアップデートします
2. テンプレートライブラリに移動し、`VEED Dubbing` を検索します
3. `LoadVideo` ノードにトーキングヘッドのクリップを読み込みます
4. `model` でティアを選択し、`target_language` を設定してから、ワークフローを実行します
