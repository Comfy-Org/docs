## FLUX.3 [klein] について

FLUX.3 [klein] は、Black Forest Labs によるローカル ComfyUI 向けのオープンウェイト FLUX.3 画像モデルです。テキストから画像への生成と、指示に基づく画像編集を1つのファミリーで扱い、フルのチェックポイントと、4〜16 ステップの高速実行に向けたステップ蒸留版を用意しています。重みは FLUX Kommunity License のもと Hugging Face で公開されており、一度ダウンロードすれば自分の GPU で実行できます。APIキーも画像ごとのクレジットも不要です。

ホスト型を使いたい場合は、Partner Node の [FLUX 3 Image](/ja/tutorials/partner-nodes/black-forest-labs/flux-3-image)（画像単位課金）もあります。自分の GPU ではローカルの klein 重みを、ダウンロードなしでホスト型モデルを使いたいときは Partner Node を選びます。

**モデルの特長:**

- 同じ重みでテキストから画像への生成と画像編集が可能。編集では指示プロンプトと参照画像を入力
- 2つのチェックポイント: フルの Flux.3 Image Klein と、ガイダンスなしの 4〜16 ステップサンプリング向け Distilled
- `<ref_image_0>`、`<ref_image_1>` などによる複数参照のプロンプティング
- 短いリクエストを生成前に完全なキャプションへ拡張する、任意の Qwen3.5 9B プロンプトアップサンプラー
- bf16、int8（convrot）、nvfp4 の単一ファイルチェックポイント、Qwen3-VL-4B テキストエンコーダーと Flux 2 VAE

**ライセンス**: [FLUX Kommunity License](https://huggingface.co/black-forest-labs/flux-3-image-klein-comfy/blob/main/LICENSE.md)

**バージョン要件**: Flux.3 Klein テンプレートには ComfyUI 0.41.0 以降が必要です（0.41.1 のバックポート、ComfyUI#17070 に収録）。

## Flux.3 Image Klein ワークフロー

### Flux.3 Image Klein: テキストから画像 {#image_flux3_klein_t2i}

プロンプトだけで画像を生成します。入力ファイルは不要です。このワークフローはサブグラフです。開くと、ローダー、サンプラー、キャンバスサイズにアクセスできます。

1. サブグラフのポジティブプロンプトウィジェットにプロンプトを入力します
2. `width` と `height` を設定するか、`ResolutionSelector` からフレームを選択します（デフォルトは 1:1 の正方形）
3. `steps`（デフォルトは 25）と `cfg`（デフォルトは 3.5）を調整します。テンプレートには、より高品質にするために 50 ステップを試すようメモが付いています
4. 自分の言葉で生成する場合は `enable_prompt_upsampler` をオフのままにし、オンにすると Qwen3.5 9B アップサンプラーで先にプロンプトを展開します
5. **Queue** をクリックします。画像は `SaveImage` ノードによって `ComfyUI/output/` に保存されます

### Flux.3 Image Klein Distilled: テキストから画像 {#image_flux3_klein_distilled_t2i}

4. **Queue** をクリックして生成します

## プロンプティングと参照のヒント

- **書くのは「変更内容」ではなく「結果」です。** 画像編集テンプレートは、編集を織り込んだ完成画像の完全なキャプションを想定しています。そのため例では、「これを変更する」と述べる代わりに、新しいオブジェクトを詳細に説明しています。
- **参照は両方の conditioning に追加されます。** 追加の画像を順番に `Set Reference Multi Latent` に接続し、`<ref_image_0>`、`<ref_image_1>` などとして参照し、参照パイプラインが行うのと同じように、それぞれをポジティブプロンプトとネガティブプロンプトの両方に追加します。
- **参照のサイズはコストの調整ダイヤルです。** テンプレートは各参照を約1メガピクセルにリサイズし、出力潜在はそのサイズになります。Black Forest Labs 自身のパイプラインが最大約16メガピクセルまで対応しているように、参照をネイティブサイズのままにしておくと、より高いコストと引き換えに編集でより多くのディテールを保てます。
- **ステップ数はチェックポイントによって異なります。** テンプレートでは、フルのチェックポイントは25ステップ、ガイダンス3.5で実行され、より良い品質のために50ステップを試すよう注記されています。ステップ蒸留版のチェックポイントは15または16ステップ、ガイダンスは1に固定で実行され、高速に処理したいときに使うのはこちらです。
- **テンプレートには `Create Bounding Boxes` ノードが付属しています。** これは領域ごとの編集を計画するためにソース画像の上にボックスを描画するもので、そのボックスのリストは `Preview Any` ノードに表示されるので、領域をプロンプトに織り込むことができます。
