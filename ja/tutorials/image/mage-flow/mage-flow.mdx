**Mage-Flow**は、Microsoft Researchが開発したコンパクトな4Bスケールの生成スタックで、効率的なテキストから画像への生成と指示ベースの画像編集を実現します。このスタックは、軽量高忠実度潜在トークナイザである[Mage-VAE](https://huggingface.co/microsoft/Mage-VAE)と、整流フローマッチングで学習されたNative-Resolution Multimodal Diffusion Transformer（NR-MMDiT）の2つの共設計コンポーネントで構成されています。ネイティブ解像度パッキングと組み合わせることで、この共有スタックは2つのモデルインスタンス化を実現します：テキストから画像を生成するMage-Flowと、指示ベースの画像編集を行うMage-Flow-Editです。それぞれ、Base、RLアライメント済み、および4ステップTurboのバリアントが用意されています。

Mage-Flowは、512〜2048ピクセル（一辺あたり）のネイティブ解像度を、4：1のような極端なアスペクト比も含む任意のアスペクト比でサポートします。

ワークフローはいくつかの部分で構成されています：

1. **Text to Image (Mage-Flow) サブグラフ**：コアとなる生成パイプライン。モデルのロード、プロンプト処理、ネイティブ解像度の潜在表現生成、サンプリング、VAEデコードを含みます。

### ワンクリック生成

最もシンプルな使い方では、サブグラフにテキストプロンプトを入力し、希望の解像度を設定して、**Queue Prompt**をクリックするだけです。デフォルト設定で、最小限の構成で高品質な画像を生成できます。

### ワークフローの使用方法

1. **プロンプトを入力する** — サブグラフのプロンプト入力欄にテキストによる説明を入力します。
2. **解像度を設定する** — 幅と高さを調整して、希望の出力サイズを指定します。Mage-Flowは512〜2048ピクセル（一辺あたり）のネイティブ解像度をサポートします。
3. **設定を調整する** — 必要に応じてシード値とネガティブプロンプトを設定します。
4. **Queueをクリックする** — `Ctrl+Enter`を押して生成を開始します。

画像編集ワークフローはMage-Flow-Editを使用します。これは、自然言語による説明を使用して画像を編集する指示ベースのモデルです。1つ以上の参照画像をアップロードし、希望する編集内容を記述します。

ワークフローはいくつかの部分で構成されています：

1. **LoadImage**：参照画像をアップロードします（最大3枚）。
2. **Image Edit (Mage-Flow-Edit) サブグラフ**：コアとなる編集パイプライン。モデルのロード、参照画像の条件付け、プロンプト処理、サンプリングを含みます。
3. **ImageCompare**：元の画像と編集後の画像を並べて比較表示します。
4. **SaveImage**：編集結果を保存します。

### 画像編集の使用方法

1. **参照画像をアップロードする** — **LoadImage**ノードを使用して、編集したい画像を読み込みます（最大3枚）。
2. **編集指示を入力する** — 適用したい編集内容をテキストで記述します（例：「背景をビーチシーンに置き換える」「これを水彩画に変換する」など）。
3. **設定を調整する** — 解像度、シード値、その他のパラメータを設定します。
4. **Queueをクリックする** — `Ctrl+Enter`を押して生成を開始します。
