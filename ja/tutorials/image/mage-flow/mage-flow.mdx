**Mage-Flow** は、効率的なテキストから画像への生成と指示ベースの画像編集のためにMicrosoft Researchが開発した、コンパクトな4Bスケールの生成スタックです。このスタックは、共同設計された2つのコンポーネント、すなわち軽量で高忠実度の潜在トークナイザーである [Mage-VAE](https://huggingface.co/microsoft/Mage-VAE) と、整流フロー・マッチングでトレーニングされたネイティブ解像度のマルチモーダルDiffusion Transformer (NR-MMDiT) で構成されています。この共有スタックは、ネイティブ解像度パッキングとともに、テキストから画像への生成用のMage-Flowと、指示ベースの画像編集用のMage-Flow-Editという2つのモデル実装を実現します。各モデルは、Base、RLアライメント済み、4ステップTurboの各バリアントで提供されます。

Mage-Flowは、4:1のような極端な寸法を含む、任意のアスペクト比で各辺512〜2048ピクセルのネイティブ解像度をサポートします。

ワークフローはいくつかの部分で構成されています：

1. **Text to Image (Mage-Flow) サブグラフ**：モデルの読み込み、プロンプト処理、ネイティブ解像度での潜在生成、サンプリング、VAEデコードを含む中核となる生成パイプライン
2. **SaveImageAdvanced**：生成済み画像を保存

### ワンクリック生成

最も簡単な方法は、サブグラフにテキストプロンプトを入力し、希望の解像度を設定して、**キューのプロンプト**をクリックするだけです。デフォルトのままで、最小限の設定しか必要とせずに高品質な画像を生成できます。

### ワークフローの使用方法

1. **プロンプトを入力**：サブグラフのプロンプト入力にテキストの説明を入力します
2. **解像度を設定**：希望する出力サイズに合わせて幅と高さを調整します。Mage-Flow は一辺 512 〜 2048 ピクセルのネイティブ解像度をサポートしています。
3. **設定を調整**：必要に応じてシードとネガティブプロンプトを設定します
4. **キューをクリック**：`Ctrl+Enter` を押して生成します

画像編集ワークフローは、自然言語による説明で画像を編集する命令ベースのモデルであるMage-Flow-Editを使用します。1つ以上の参照画像をアップロードし、希望する編集内容を説明します。

ワークフローはいくつかのパートで構成されています:

1. **LoadImage**: 参照画像をアップロードします（最大3枚）
2. **Image Edit（Mage-Flow-Edit）サブグラフ**: モデルの読み込み、参照画像の条件付け、プロンプト処理、サンプリングを含むコア編集パイプライン
3. **ImageCompare**: オリジナル画像と編集後画像を並べて比較します
4. **SaveImage**: 編集後の出力を保存します

### 画像編集の使用方法

1. **参照画像をアップロード**: **LoadImage** ノードを使用して、編集したい画像を読み込みます（最大3枚）
2. **編集指示を入力**: 適用したい編集内容のテキストによる説明を入力します（例：「背景をビーチシーンに置き換える」、「これを水彩画にする」）
3. **設定を調整**: 解像度、シード、その他のパラメータを設定します
4. **キューをクリック**: `Ctrl+Enter` を押して生成します
