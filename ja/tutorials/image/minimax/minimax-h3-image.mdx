**MiniMax-H3-Image** は MiniMax のオープンウェイト画像モデルで、1つの checkpoint がテキストから画像への生成と画像編集の両方をカバーします。diffusion transformer は BF16 で 33.1B パラメータを持ち、CFG を使わない 6 ステップのサンプラーに蒸留されています。出力は約 16 MP のネイティブ解像度なので、4096 x 4096 の画像はアップスケールの連鎖ではなく 1 回のパスで生成できます。

## 主な機能

- **テキストから画像生成と編集を1つのcheckpointで**: 編集用のモデルやアダプターを別途読み込む必要はありません
- **6ステップのサンプリング**: ガイダンスは1に固定されているため、CFGパスもネガティブプロンプトもありません
- **ネイティブで約16 MP**: アップスケール処理なしで4096 x 4096、最大6272 x 2688まで
- **複数の参照**: 最大16枚の入力画像を、プロンプト内で `<Picture 1>` 以降として指定
- **オプションのプロンプトエキスパンダー**: 短いリクエストを、モデルが最もよく読み取る詳細なキャプションに変換します
- **オープンウェイト**: ComfyUIで完全なローカル制御が可能

テキストから画像へのテンプレートは、正方形のキャンバスで 4 MP で開きます。これは意図的にモデルのネイティブ解像度より低く設定されており、VRAM の少ないマシンでメモリ不足が発生しないようにしています。GPU に余裕がある場合は、解像度セレクターでサイズを上げてください。

画像編集テンプレートは、ソースを `<Picture 1>` として読み込み、指示から参照を認識するキャプションを構築し、最後に前後の比較ノードで仕上げます。どちらのテンプレートもテンプレートライブラリにサンプル出力が表示されるため、最初のキュー実行で変更を加えることなくモデルを実演できます。

## サンプリングとキャンバスサイズ

どちらのテンプレートも蒸留スケジュールを搭載しています:

| 設定 | 値 |
| --- | --- |
| サンプラー | euler |
| スケジューラー | simple |
| ステップ数 | 6 |
| ガイダンス（CFG） | 1 |
| デノイズ | 1 |

ガイダンスが1の場合、classifier-free guidance のパスは実行されないため、テンプレートにはネガティブプロンプトがありません。避けたい事項を含め、希望する内容はすべてポジティブプロンプトに記述してください。

ネイティブ出力は約16 MPです。各辺は32 pxの倍数で生成され、任意の幅と高さを指定できます。次のサイズは一般的な比率に対応しています:

| アスペクト比 | サイズ（幅 x 高さ） |
| --- | --- |
| 1:1 | 4096 x 4096 |
| 4:3 | 4736 x 3552 |
| 3:4 | 3552 x 4736 |
| 3:2 | 5024 x 3360 |
| 2:3 | 3360 x 5024 |
| 16:9 | 5472 x 3072 |
| 9:16 | 3072 x 5472 |
| 21:9 | 6272 x 2688 |

より小さいキャンバスも使用でき、所要時間も短くなります。テキストから画像へのテンプレートでは、解像度セレクターがアスペクト比と目標メガピクセル数を個別に設定するため、4 MPは上限ではなく出発点です。

## 画像編集での参照画像

画像編集テンプレートは、ソース画像を `<Picture 1>` としてモデルに送信します。追加の画像は `<Picture 2>`、`<Picture 3>` のように順番にラベル付けされ、最大16枚の参照画像まで指定できます。プロンプトはそれぞれのラベルで参照します。最初の画像が編集対象で、残りは被写体の同一性、小道具、素材、構図を補います。短い指示で十分です。たとえば、`<Picture 1>` の車両を `<Picture 2>` の車両に置き換える、といったものです。

参照画像を追加するには、ワークフローに別の `Load Image` ノードを配置し、プロンプト生成ステップと条件付けノードの両方に接続します。参照画像の準備は不要です。テンプレートはソースを32 pxの倍数に丸め、ComfyUI は内部コピーを独自にスケーリングします。ビジョン側は短辺1024 px、VAE 側は短辺を1024～2048 pxの範囲にクランプし、いずれも32 pxのグリッドに沿います。

編集時にメモリが不足する場合は、テンプレートの `Resize Image/Mask` ノードを有効にし、サンプリング前にメガピクセルを下げてください。

## プロンプトエキスパンダー

どちらのテンプレートも、サンプラーの手前にテキスト生成ステップを備えています。テキストから画像へのテンプレートでは、プロンプトを詳細な英語のキャプションに書き換え、キャンバスのアスペクト比を選択します。画像編集テンプレートでは、短い指示を、完成した画像を参照情報に基づいて説明する記述に変換します。

MiniMax-H3-Image の公式エキスパンダーは Qwen3.8-27B FP4 モデルで、[MiniMaxAI/MiniMax-H3-Image-PE](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image-PE) として公開されています。テンプレートでは代わりに、より軽量な Qwen3.5 9B W4A8 ビルドを使用しているため、エキスパンダーは 21 GB の diffusion モデルと同じ GPU 上に収まります。

テキストから画像へのテンプレートはエキスパンダーがオフの状態で提供されるため、入力したプロンプトはそのままモデルに渡ります。キャプションの書き換えとアスペクト比の自動選択を行いたい場合はオンに切り替えてください。画像編集テンプレートはオンの状態で提供されます。
