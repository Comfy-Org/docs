**MiniMax-H3-Image** は MiniMax のオープンウェイト画像モデルで、1つの checkpoint がテキストから画像への生成と画像編集の両方をカバーします。diffusion transformer は BF16 で 33.1B パラメータを持ち、CFG を使わない 6 ステップのサンプラーに蒸留されています。出力は約 16 MP のネイティブ解像度なので、4096 x 4096 の画像はアップスケールの連鎖ではなく 1 回のパスで生成できます。

- [MiniMaxAI/MiniMax-H3-Image (Hugging Face)](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image)：公式のモデルカードと重み

- [Comfy-Org/MiniMax-H3-Image (Hugging Face)](https://huggingface.co/Comfy-Org/MiniMax-H3-Image): diffusion モデルと画像 VAE
- [Comfy-Org/MiniMax-H3 (Hugging Face)](https://huggingface.co/Comfy-Org/MiniMax-H3): このモデルが使用する Qwen3-VL-32B text encoder
- [MiniMaxAI/MiniMax-H3-Image-PE (Hugging Face)](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image-PE): 公式の prompt expander

## 主な機能

- **テキストから画像生成と編集を1つのcheckpointで**: 編集用のモデルを別途読み込む必要はありません
- **6ステップのサンプリング**: ガイダンスは1に固定されているため、CFGパスもネガティブプロンプトもありません
- **ネイティブで約16 MP**: アップスケール処理なしで4096 x 4096、最大6272 x 2688まで
- **複数の参照**: 最大16枚の入力画像を、プロンプト内で `<Picture 1>` 以降として指定
- **オプションのプロンプトエキスパンダー**: 短いリクエストを、モデルが最もよく読み取る詳細なキャプションに変換します
- **オープンウェイト**: ComfyUIで完全なローカル制御が可能

## テンプレート

このモデルには 3 つのテンプレートワークフローが付属しています。いずれも ComfyUI **0.45.0+** が必要です。テキストから画像生成と画像編集のテンプレートにはテンプレートパック **0.11.104+**、キャラクター置き換えには **0.11.115+** が必要です。

### MiniMax-H3-Image テキストから画像生成 {#image_minimax_h3_image_t2i}

テキストプロンプトから画像を生成します。テンプレートはモデルのネイティブ解像度である 16 MP（1:1 で 4096 x 4096）で開きます。VRAM が少ない場合や高速に実行したい場合は、解像度セレクターで `megapixels` を 4 MP 程度まで下げてください。

### MiniMax-H3-Image キャラクター置き換え {#image_minimax_h3_image_character_swap}

写真の中の人物を、参照画像のキャラクターに置き換えます。テンプレートは写真を `<Picture 1>`、キャラクターを `<Picture 2>` として読み込み、元の写真のポーズ、構図、ライティングを保ったまま、参照キャラクターの顔、衣装、素材を引き継ぎます。同じ checkpoint に、強度 1.0 のキャラクター置き換えアダプターを重ねて実行します。

## サンプリングとキャンバスサイズ

すべてのテンプレートが蒸留スケジュールを搭載しています:

| 設定 | 値 |
| --- | --- |
| サンプラー | euler |
| スケジューラー | simple |
| ステップ数 | 6 |
| ガイダンス（CFG） | 1 |
| デノイズ | 1 |

ガイダンスが1の場合、classifier-free guidance のパスは実行されないため、テンプレートにはネガティブプロンプトがありません。避けたい事項を含め、希望する内容はすべてポジティブプロンプトに記述してください。

ネイティブ出力は約16 MPです。各辺は32 pxの倍数で生成され、任意の幅と高さを指定できます。次のサイズは一般的な比率に対応しています:

| アスペクト比 | サイズ（幅 x 高さ） |
| --- | --- |
| 1:1 | 4096 x 4096 |
| 4:3 | 4736 x 3552 |
| 3:4 | 3552 x 4736 |
| 3:2 | 5024 x 3360 |
| 2:3 | 3360 x 5024 |
| 16:9 | 5472 x 3072 |
| 9:16 | 3072 x 5472 |
| 21:9 | 6272 x 2688 |

より小さいキャンバスも使用でき、所要時間も短くなります。テキストから画像へのテンプレートでは、解像度セレクターがアスペクト比と目標メガピクセル数を個別に設定するため、4 MP 以上、セレクターの上限である 16 MP までの任意のサイズは 1 か所の設定で指定できます。

## 画像編集での参照画像

画像編集テンプレートは、ソース画像を `<Picture 1>` としてモデルに送信します。追加の画像は `<Picture 2>`、`<Picture 3>` のように順番にラベル付けされ、最大16枚の参照画像まで指定できます。プロンプトはそれぞれのラベルで参照します。最初の画像が編集対象で、残りは被写体の同一性、小道具、素材、構図を補います。短い指示で十分です。たとえば、`<Picture 1>` の車両を `<Picture 2>` の車両に置き換える、といったものです。

参照画像を追加するには、ワークフローに別の `Load Image` ノードを配置し、プロンプト生成ステップと条件付けノードの両方に接続します。参照画像の準備は不要です。テンプレートはソースを32 pxの倍数に丸め、ComfyUI は内部コピーを独自にスケーリングします。ビジョン側は短辺1024 px、VAE 側は短辺を1024～2048 pxの範囲にクランプし、いずれも32 pxのグリッドに沿います。

編集時にメモリが不足する場合は、テンプレートの `Resize Image/Mask` ノードを有効にし、サンプリング前にメガピクセルを下げてください。

## プロンプトエキスパンダー

テキストから画像生成と画像編集のテンプレートは、サンプラーの手前にテキスト生成ステップを備えています。テキストから画像へのテンプレートでは、プロンプトを詳細な英語のキャプションに書き換えます。画像編集テンプレートでは、短い指示を、完成した画像を参照情報に基づいて説明する記述に変換します。

MiniMax-H3-Image の公式エキスパンダーは Qwen3.8-27B FP4 モデルで、[MiniMaxAI/MiniMax-H3-Image-PE](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image-PE) として公開されています。テンプレートでは代わりに、より軽量な Qwen3.5 9B W4A8 ビルドを使用しているため、エキスパンダーは 21 GB の diffusion モデルと同じ GPU 上に収まります。

テキストから画像生成と画像編集のテンプレートは、エキスパンダーがオンの状態で提供されるため、プロンプトはサンプリング前に書き換えられます。オフにすると入力したプロンプトがそのままモデルに渡ります。
