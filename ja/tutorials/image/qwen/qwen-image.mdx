**Qwen-Image**は、AlibabaのQwenチームがリリースした初の画像生成基盤モデルです。Apache 2.0ライセンスのもとでオープンソース化された、20BパラメータのMMDiT（マルチモーダル拡散トランスフォーマー）モデルです。**複雑なテキストレンダリング**と**精密な画像編集**で大きな進歩を遂げ、英語・中国語を含む複数言語で高忠実度の出力を実現しています。

**モデルの特徴**：
- **優れた多言語テキストレンダリング**：英語・中国語・韓国語・日本語など複数言語で高精度なテキスト生成に対応し、フォントの細部とレイアウトの一貫性を維持します
- **多彩なアートスタイル**：フォトリアルなシーンから印象派の絵画、アニメ風からミニマリストデザインまで、さまざまなクリエイティブプロンプトに柔軟に対応します

**関連リンク**：
 - [GitHub](https://github.com/QwenLM/Qwen-Image)
 - [Hugging Face](https://huggingface.co/Qwen/Qwen-Image)
 - [ModelScope](https://modelscope.cn/models/qwen/Qwen-Image)

現在、Qwen-Imageでは複数のControlNetサポートオプションが利用できます：
- [Qwen-Image-DiffSynth-ControlNets/model_patches](https://huggingface.co/Comfy-Org/Qwen-Image-DiffSynth-ControlNets/tree/main/split_files/model_patches)：canny、depth、inpaintモデルを含みます
- [qwen_image_union_diffsynth_lora.safetensors](https://huggingface.co/Comfy-Org/Qwen-Image-DiffSynth-ControlNets/blob/main/split_files/loras/qwen_image_union_diffsynth_lora.safetensors)：canny、depth、pose、lineart、softedge、normal、openposeに対応する画像構造制御LoRA
- InstantX ControlNet：更新予定

### 3. ワークフローの使い方

![Step Guide](/images/tutorial/image/qwen/image_qwen_image-guide.jpg)

1. `Load Diffusion Model`ノードに`qwen_image_fp8_e4m3fn.safetensors`がロードされていることを確認します
2. `Load CLIP`ノードに`qwen_2.5_vl_7b_fp8_scaled.safetensors`がロードされていることを確認します
3. `Load VAE`ノードに`qwen_image_vae.safetensors`がロードされていることを確認します
4. `EmptySD3LatentImage`ノードに正しい画像サイズが設定されていることを確認します
5. `CLIP Text Encoder`ノードにプロンプトを設定します。現在、少なくとも英語・中国語・韓国語・日本語・イタリア語などに対応しています
6. lightx2vの8ステップ高速化LoRAを有効にしたい場合は、ノードを選択して`Ctrl + B`で有効化し、ステップ8の説明に従ってKsamplerの設定を変更します
7. `Queue`ボタンをクリックするか、ショートカット`Ctrl(cmd) + Enter`でワークフローを実行します
8. モデルのバージョンやワークフローに応じて、KSamplerのパラメータを調整してください

<Note>
 蒸留モデルとlightx2vの8ステップ高速化LoRAは同時に使用できないようです。さまざまな組み合わせを試して、併用できるかどうか確認してください。
</Note>

### 3. ワークフローの使い方

現在、diffsynthにはCanny、Depth、Inpaintの3つのパッチモデルがあります。

ControlNet関連のワークフローを初めて使う場合は、制御画像をモデルが使用・認識できるように、対応する画像形式に前処理しておく必要があることを理解してください。

![Input Type Diagram](/images/tutorial/image/qwen/controlnet_input_types.jpg)

- Canny：cannyエッジ検出で処理された線画輪郭
- Depth：空間関係を示す前処理済みの深度マップ
- Inpaint：再描画が必要な領域をMaskで指定する必要があります

このパッチモデルは3つの異なるモデルに分かれているため、入力時に正しい前処理タイプを選択して、適切な画像前処理を行う必要があります。

**Cannyモデル ControlNet の使い方**

![Canny Workflow](/images/tutorial/image/qwen/image_qwen_image_controlnet_patch-canny.jpg)
1. `qwen_image_canny_diffsynth_controlnet.safetensors`がロードされていることを確認します
2. 後続の処理用に入力画像をアップロードします
3. Cannyノードはネイティブの前処理ノードで、設定したパラメータに従って入力画像を前処理し、生成を制御します
4. 必要に応じて、`QwenImageDiffsynthControlnet`ノードの`strength`を変更して、線画制御の強度を調整できます
5. `Run`ボタンをクリックするか、ショートカット`Ctrl(cmd) + Enter`でワークフローを実行します

> qwen_image_depth_diffsynth_controlnet.safetensorsを使用する場合は、画像を深度マップに前処理し、`image processing`部分を置き換える必要があります。この使い方については、このドキュメントのInstantXの処理方法を参照してください。その他の部分はCannyモデルの使い方と同様です。

**Inpaintモデル ControlNet の使い方**
![Inpaint Workflow](/images/tutorial/image/qwen/image_qwen_image_controlnet_patch-inpaint.jpg)

Inpaintモデルでは、[マスクエディター](/ja/interface/maskeditor)を使ってマスクを描き、それを入力制御条件として使用する必要があります。

1. `ModelPatchLoader`に`qwen_image_inpaint_diffsynth_controlnet.safetensors`モデルがロードされていることを確認します
2. 画像をアップロードし、[マスクエディター](/ja/interface/maskeditor)でマスクを描きます。対応する`Load Image`ノードの`mask`出力を`QwenImageDiffsynthControlnet`の`mask`入力に接続して、対応するマスクがロードされるようにする必要があります
3. `Ctrl-B`ショートカットでワークフロー内の元のCannyをバイパスモードに設定し、対応するCannyノードの処理を無効にします
4. `CLIP Text Encoder`に、マスク領域をどのように変更したいかを入力します
5. 必要に応じて、`QwenImageDiffsynthControlnet`ノードの`strength`を変更して、対応する制御強度を調整できます
6. `Run`ボタンをクリックするか、ショートカット`Ctrl(cmd) + Enter`でワークフローを実行します

### 1. ワークフローと入力画像

ComfyUIを更新すると、テンプレートからワークフローファイルを見つけることができます。また、上のワークフロープレビューをComfyUIにドラッグして読み込むこともできます。

### 2. モデルリンク

以下のモデルをダウンロードしてください。これはLoRAモデルなので、`ComfyUI/models/loras/`フォルダに保存する必要があります
-  [qwen_image_union_diffsynth_lora.safetensors](https://huggingface.co/Comfy-Org/Qwen-Image-DiffSynth-ControlNets/blob/main/split_files/loras/qwen_image_union_diffsynth_lora.safetensors)：canny、depth、pose、lineart、softedge、normal、openposeに対応する画像構造制御LoRA

### 3. ワークフローの使い方

このモデルはcanny、depth、pose、lineart、softedge、normal、openpose制御に対応する統合制御LoRAです。多くの画像前処理ネイティブノードが完全にはサポートされていないため、[comfyui_controlnet_aux](https://github.com/Fannovel16/comfyui_controlnet_aux)などを使ってその他の画像前処理を行ってください。

![Union Control LoRA](/images/tutorial/image/qwen/image_qwen_image_union_control_lora.jpg)

1. `LoraLoaderModelOnly`に`qwen_image_union_diffsynth_lora.safetensors`モデルが正しくロードされていることを確認します
2. 入力画像をアップロードします
3. 必要に応じて、`Canny`ノードのパラメータを調整できます。入力画像によって異なるパラメータ設定が必要になるため、対応するパラメータ値を調整して詳細を増減してみてください
4. `Run`ボタンをクリックするか、ショートカット`Ctrl(cmd) + Enter`でワークフローを実行します

> その他のタイプの制御についても、画像処理部分を置き換える必要があります。
