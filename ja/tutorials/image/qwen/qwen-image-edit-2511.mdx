**Qwen-Image-Edit-2511** は、Qwen-Image-Edit-2509 の強化版であり、一貫性の大幅な向上を含む複数の改良が施されています。このモデルは、Qwen-Image 固有のテキストレンダリング機能を編集タスクへと拡張し、意味的および外観的な両面から精密なテキスト編集を可能にします。

**Qwen-Image-Edit-2511 の主な強化点**:
- **画像ドリフトの軽減**: 編集操作中の安定性が向上
- **キャラクターの一貫性の向上**: 創意工夫を伴う編集において、人物のアイデンティティおよび視覚的特徴をより適切に保持
- **多人物間の一貫性**: 複数の人物画像を高忠実度で融合し、自然なグループショットを生成
- **LoRA 機能の統合**: 人気のあるコミュニティ製 LoRA をベースモデルに直接組み込み
- **産業デザイン生成機能の強化**: 大量の工業製品設計およびマテリアル置換をより効率的にサポート
- **幾何学的推論能力の強化**: デザインやアノテーション用の補助構成線を直接生成

#### カメラアングルの操作

**Camera Angle** ノードは数値入力の集まりではなく、それ自体が 3D ビューです。ここで視点を選ぶと、`front view eye-level shot medium shot` のようなショット記述がワークフローのプロンプトに書き込まれるため、角度を手入力する必要はありません。視点を変えるとプロンプトも追従します。

- **Camera / Object**：**Camera** は被写体のまわりを移動し、**Object** はレンズ越しに被写体の向きを変えます。
- **Horizontal angle / Vertical angle / Shot size**：`Front` から `Back left`、`Low angle` から `High angle`、`Wide shot` から `Close-up` まで名称で選べます。プレビュー内のドラッグでも同じ値が入ります。
- **Preview**：カメラのフレームに何が入るかをピクチャーインピクチャーで表示します。

ノードの任意の画像入力に画像を接続すると、被写体の正面に表示され、回り込み中に左右が分かりやすくなります。

Turbo モードは既定でオンで、4 ステップでサンプリングします。サブグラフでオフにすると 40 ステップで生成します。
