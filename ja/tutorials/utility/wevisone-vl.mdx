WeVisOne-VL は、文章ではなく図形で答えを返すコンパクトなビジョン言語モデルです。画像と短いテキストクエリを渡すと、ボックス、ポイント、またはインスタンスごとのアルファマットを1回のパスで返します。アノテーションも、オブジェクトごとのプロンプトも不要です。

ComfyUI では **WeVisOne-VL Detect** ノードとして動作します。以下のテンプレートはこれをサブグラフでラップし、マット、ソース画像上に描画したボックス、前景と背景の切り抜きをプレビューするので、マットをそのまま背景除去、マスキング、合成のチェーンに渡せます。

重みは Apache-2.0 の Tencent リリースを ComfyUI 向けに再パッケージしたもので、[Comfy-Org/WeVisOne-VL](https://huggingface.co/Comfy-Org/WeVisOne-VL) で公開されています。サポートは [ComfyUI #17632](https://github.com/Comfy-Org/ComfyUI/pull/17632) で追加され、テンプレートには ComfyUI 0.45.0 以降が必要です。

## 画像セグメンテーション: WeVisOne-VL {#utility_image_segment_wevisone_vl}

切り抜きたい対象を `query` に入力して実行します。デフォルトの `segmentation` タスクとクエリ `human` では、見つけた人物をまとめた1枚のマットと、そのボックスを返します。人物ごとに分けるには、ノードの `individual_masks` をオンにします。

## タスク

`task`ウィジェットは、クエリをcheckpointが学習した指示に書き換えます。各タスクは、クエリをそれぞれ少し異なる形式で受け取ります。

| `task` | クエリ形式 | 戻り値 |
| :--- | :--- | :--- |
| `segmentation` | `human` のような短い名詞句を1つ | アルファマットとボックス（`individual_masks` がオフなら1枚の結合マット） |
| `detection` | 1行に1つのラベル | ボックスのみ |
| `referring` | `the cup on the left` のような説明句 | ボックス |
| `point` | 1行に1つのラベル | JSON形式の中心点 |
| `count_box` | 数える対象 | カウントと、各インスタンスのボックス |
| `count_point` | 数える対象 | カウントと、各インスタンスの点 |
| `ocr` | なし | 画像内のすべての単語のボックス |
| `ocr_grounding` | 見つける正確な文字列 | その文字列を囲むボックス |
| `visual_prompt` | なし（`bboxes`入力を使用） | 参照ボックスに似たオブジェクトのボックス |
| `freeform` | 任意 | 生の回答（クエリがプロンプト全体） |

クエリは短くしてください。完全な文にすると`segmentation`が長々と出力してしまい、対象を名指しする句のほうが、その説明よりも適切に機能します。

## モデル

このワークフローは 2B INT8 テキストエンコーダーを読み込みます。残りの3つのファイルは、`CLIPLoader` ノード（`stable_diffusion` タイプ）の `clip_name` にそのまま差し替えられるものです。4B のペアはより大きく低速で、BF16 ファイルはサイズと引き換えに精度を得られます。

## ノードをさらに細かく制御する

- **`individual_masks`**: on の場合、ボックスごとに1つのマスク。off の場合、フレームごとに1つの結合マスク
- **`max_length`**: 回答の長さの上限。デフォルトは 4096 トークンで、最大 32768 まで
- **出力**: `masks`、`bboxes`、`points`（x、y、label、frame を含む JSON）、および `text`（生の回答）
