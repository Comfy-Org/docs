YuE2 は、Multimodal Art Projection（m-a-p）によるオープンソースの音楽生成モデルで、スタイルプロンプトと歌詞から、ボーカルと楽器の伴奏を備えた完成した楽曲を生成します。3B パラメータのモデルであり、イントロ、バース、サビ、ブリッジ、アウトロなどのセクションからなる完全な楽曲構造を生成し、英語、中国語、日本語を含む複数の歌唱言語に対応しています。

YuE2 がほとんどのテキストtoミュージックシステムと異なる点は、編集可能な作曲ステップです。オーディオを生成する前に、YuE2 はまず ABC 記譜法によるシンボリックな音楽プラン（メロディ、任意でコード付き）を書き出すことができ、これを確認して編集できます。最終的な楽曲はそのプランからレンダリングされます。これにより、ワンショットのオーディオ生成よりも結果を操作しやすくなり、以下のカバーワークフローも実現します。そこでは、参照楽曲が同じ記譜法に採譜され、新しいスタイルと歌詞で歌い直されます。

YuE2 は ComfyUI でネイティブにサポートされています。開始する前に [ComfyUI](https://github.com/comfyanonymous/ComfyUI) を最新バージョンに更新してください。ComfyUI v0.35.0 以降が必須で、AMD GPU では v0.35.1 以降が推奨されます。

## テキストから音楽 {#audio_yue2_text2music}

音楽スタイルの説明と自分の歌詞から、完全な楽曲を生成します。ABC プランニングを有効にすると、YuE2 はまず編集可能なシンボリック音楽プラン（メロディ、および任意でコード）を作成し、そのプランから最終的なオーディオを生成します。

### 1. 実行手順

1. **Style** に、希望する音楽の説明を書きます
2. `[Verse]` や `[Chorus]` などのセクションタグを使って、**Lyrics** に歌詞を入力します
3. プランニングの **Mode** を選択します。`full` はメロディとコードを生成し、`melody` はメロディのみを生成します
4. 楽曲の **Max Duration** を設定します
5. ワークフローをキューに入れて楽曲を生成します

### 3. スタイルの書き方

主な音楽的特徴を説明します。役立つ要素は次のとおりです:

- **ジャンル**: ポップ、ジャズ、ロック、エレクトロニック、フォーク
- **ボーカル**: 温かみのある女性ボーカル、表現豊かな男性ボーカル、ソフトなボーカル
- **言語**: 英語、中国語、日本語など
- **テンポ**: 90 BPM、スロー、アップビート
- **楽器**: ピアノ、エレクトリックギター、ベース、ドラム、シンセ

例:

> 英語、温かみのある女性ボーカル、コンテンポラリーポップ、96 BPM、ピアノ、丸みのあるエレクトリックベース、抑制の効いたドラム、明瞭な発音

音楽的な指示は歌詞ではなく **Style** に記述してください。

### 4. 歌詞の書き方

セクションタグを使って楽曲の構成を記述します:

```
[Verse]
Morning light across the window
City waking down below

[Chorus]
Run with me into the sunlight
Leave the shadows far behind
```

`[Verse]`、`[Chorus]`、`[Bridge]`、`[Outro]` などのセクションで楽曲を構成できます。歌詞フィールドには、歌われることを意図した歌詞のみを入力してください。

### 5. ABC プランニング

**Mode** オプションはシンボリックプランニングのステップを制御します:

- **full**: 楽曲を生成する前にメロディとコードを含むプランを作成します。一般的なテキストからの音楽生成に推奨されます。
- **melody**: メロディのみのプランを作成し、伴奏をより自由に生成させます。

**abc** 入力を空のままにするとプランニングが無効になり、Style と Lyrics から直接音楽を生成します。

### 6. Max Duration

**Max Duration** は、生成される楽曲の最大の長さを秒単位で設定します。生成された楽曲の構成や歌詞によっては、楽曲が早く終了することがあります。

### 3. カバーの仕組み

このワークフローは参照オーディオを YuE2 に直接渡すことはありません。代わりに次のように処理します:

```
Reference Audio
    ↓
SheetSage2 (transcription)
    ↓
Melody ABC score
    ↓
YuE2 (generation with new Style and Lyrics)
```

オリジナル楽曲とのつながりはメロディであるため、カバーは新しい歌詞がオリジナルのフレージングと音節数にほどよく近い場合に最も効果を発揮します。

### 4. Style と Lyrics の書き方

ターゲットとする音楽スタイルを明確に記述します。ジャンル、ボーカルの種類、言語、テンポ、楽器、雰囲気などの要素が役立ちます:

> 英語、ソウルフルなジャズポップ、表現力豊かな男性ボーカル、リラックスした 88 BPM、Rhodes ピアノ、アップライトベース、ブラシドラム、温かみのあるサックス、親密な深夜の雰囲気

テキストから音楽を生成するワークフローと同じ `[Verse]` / `[Chorus]` / `[Bridge]` / `[Outro]` セクションタグを使用します。メロディのマッチングを良くするには、新しい歌詞の長さをオリジナルの行に近づけてください。
