[MiniMax H3](https://www.minimax.io/blog/minimax-h3) は MiniMax のオープンウェイト omni-modal モデルです。テキスト、画像、ビデオ、オーディオを単一コンテキストで理解し、**ネイティブステレオオーディオ**付きのビデオ（音声、SFX、音楽を一体）を 1 パスで生成します。オープンウェイトは約 100 万ピクセル（短辺 768px）、24fps、最長約 15 秒が目安です。2K はホスト型サービスの出力で、ComfyUI では別途アップスケールが必要です。

ドキュメントは 6 ページに分かれています:

- **概要**（このページ）: 機能、はじめに、各ワークフローガイドへのリンク
- **[ネイティブワークフロー](/ja/tutorials/video/minimax/minimax-h3-native)**: T2V、I2V、R2V とネイティブノードのテクニック
- **[マルチフレーム参照](/ja/tutorials/video/minimax/minimax-h3-multiframe)**: タイムライン上の参照フレームを固定
- **[Fun ControlNet Union](/ja/tutorials/video/minimax/minimax-h3-fun-controlnet)**: コントロールビデオまたはマスクによるインペイント
- **[プロンプトガイド](/ja/tutorials/video/minimax/minimax-h3-prompt-guide)**: 公式ガイド、ヒント、埋め込み
- **[FastH3](/ja/tutorials/video/minimax/minimax-h3-fastvideo)**: FastVideo スパースアテンションのチェックポイント

<Note>

## 主な機能

- **ネイティブステレオオーディオ**: 会話、SFX、音楽を 1 つの MP4 に
- **マルチモーダルコンテキスト**: テキスト、画像、ビデオ、オーディオ参照を組み合わせ
- **参照駆動生成**: 参照からアイデンティティ、スタイル、モーション、カメラ、声を固定
- **指示への追従**: 参照とショットの関係を自然言語で記述
- **正確なテキストレンダリング**: 綴りとブランド要素をクリアに
- **オープンウェイト**: ComfyUI でローカルにフル制御

## はじめに

各機能に必要な ComfyUI の最低バージョン:

| 機能 | 最低バージョン |
| --- | --- |
| 基本 T2V、I2V、R2V テンプレート | **0.30.0+** |
| マルチフレーム参照 | **0.34.0+** |
| Fun ControlNet Union、スパースアテンション、Model Attention Backend | **0.35.0+** |
| FastH3 | **0.36.0+** |
| Fun ControlNet Union 2.0 | **0.38.0+** |

1. ワークフローに必要な ComfyUI バージョンに更新します。
2. **テンプレートライブラリ** > **ビデオ** から MiniMax H3 ワークフローを選びます。
3. ポップアップからモデルをダウンロードします（数十 GB。時間とディスク容量を確保）。

ウェイトは [Comfy-Org/MiniMax-H3](https://huggingface.co/Comfy-Org/MiniMax-H3) にあります。

## 商用ライセンス

H3 のオープンウェイトは無料でダウンロードして実行できます。ローカル生成した出力を商用利用するには、唯一の公式販売代理店である Comfy を通じて販売される [MiniMax 商用ライセンス](https://comfy.org/minimax/license) が必要です。Comfy Cloud 上の生成にはすでに商用利用権が含まれているため、ライセンスが必要になるのはローカル利用の場合のみです。

ライセンスは必要ですか？

- **Comfy Cloud**：商用利用が含まれています。購入は不要です。
- **米国、EU、英国、韓国以外で自社ハードウェア上で実行し、年間売上が 2,000 万米ドル未満**：MiniMax の無料コミュニティライセンスで商用利用がカバーされます。"Powered by MiniMax H3" のクレジットを表示してください。同じ地域ルールは出力の利用地にも適用されます。
- **米国、EU、英国、韓国で自社ハードウェア上で実行する、または年間売上が 2,000 万米ドル超**：以下の 2 つのライセンスのいずれかが必要です。

ライセンスは 2 つのティアがあります：

|                           | Professional           | Enterprise                                                   |
| ------------------------- | ---------------------- | ------------------------------------------------------------ |
| 価格                      | 月額 $5,000 から       | カスタム。年間契約、利用量に応じた価格                       |
| 契約期間                  | 月次                   | 最短 12 か月                                                 |
| ライセンスユーザー        | 最大 10 人             | 上限なし                                                     |
| ドメイン                  | 1                      | カスタム                                                     |
| モデルバージョン          | Distilled オープンウェイト | 全バージョン（非 Distilled ウェイトと新リリースを含む） |
| 出力の商用利用            | 完全な商用利用権       | 完全な商用利用権                                             |
| ファインチューニングと LoRA | 含む                 | 含む                                                         |
| クライアントおよび下流の作業 | 含む                  | 含む                                                         |

Professional は月額 $5,000 からです。Enterprise には定価がなく、生成量とチーム規模に応じて見積もります。いずれのティアも、1 つの契約で MiniMax H3 と MiniMax Audio & Music をカバーします。[ライセンスをリクエスト](https://comfy.org/contact) して見積もりを取得してください。
