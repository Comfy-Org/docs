H3 は 1 つのマルチモーダルプロンプトにショット、カメラ、台詞、SFX を載せます。このページは公式ガイド、ワークフロー横断のヒント、ショット・カメラワーク・台詞のルール、スタイル埋め込みをまとめます。

## 公式ガイド

- [ベースモード](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md)（T2VA、I2VA、FL2VA、L2VA）: 時間軸ショット、カメラ、オーディオ
- [フルリファレンスモード](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md)（R2V）: リライト構造、参照ラベル、保持マーカー

インストール可能な [H3 skills](https://github.com/MiniMax-AI/MiniMax-H3/tree/main/skills) がエージェント向けにパッケージ化しています。

テンプレート別: [T2V/I2V](/ja/tutorials/video/minimax/minimax-h3-native)、[R2V](/ja/tutorials/video/minimax/minimax-h3-native#minimax-h3-リファレンスからビデオ-r2v)、[マルチフレーム](/ja/tutorials/video/minimax/minimax-h3-multiframe#プロンプト作成ガイド)、[Fun ControlNet](/ja/tutorials/video/minimax/minimax-h3-fun-controlnet#プロンプトのヒント)。

## 一般的なヒント

I2VA は固定の画像位置合わせ行で始まり、空行を挟んで本文フィールドが続きます。FL2VA/L2VA はそれぞれ独自の位置合わせ行を使用し、T2VA はフィールドから直接始まります:

```text
integrated_multimodal_description: [Shot 1] ...
overall_soundscape: ...
non_diegetic_music: ...
```

プロンプトは**英語**で記述します。台詞/歌詞は `<d>` タグ内に、画面に表示する文字は元の言語のまま逐語的に記述します。

1. **シーンを先に**: まず全体のシーンを書き、次に `integrated_multimodal_description` の `[Shot 1]` 内に時間指定付きのショットを書く
2. **1 つのブロック**: ショット、カメラ、オーディオをまとめて記述する
3. **解像度**: 16:9 でネイティブ **1344×768**、**32** の倍数
4. **長さ**: `length` は 24fps のフレーム数（既定 **124** ≈ 5s）で、**17k+5** にスナップされる
5. **画面文字**: 各文字列を英語の二重引用符で囲み、原文のまま記述する（例: `A red neon sign reading "营业中"`）。話される台詞には `<d>` を使用し、引用符は使わない
6. **R2V オーディオマーカー**: 保持分析では、クリップの使われ方に合わせて各オーディオ参照を `fully_copy`、`partially_copy`、`reference`、`weak_reference` のいずれかでマークする（公式の ref ガイドの表を参照）
7. **オーディオフィールド**: `overall_soundscape` = 環境音/SFX/非言語音（1〜4 文。`N/A` は本当に無音の場合のみ）。台詞とダイジェティック音楽はショット内に残す。`non_diegetic_music` = スコアのみ（1〜3 文。なければ `N/A`）。不要な発話が現れる場合は、両方のフィールドを明示的に埋める
8. **ネガティブは使わない**: `BasicGuider` は `cfg` 1 で動作し、ネガティブ分岐はない。禁止リストは不要な概念を追加してしまう。表示すべき内容を記述する（または R2V の保持フィールド `fully_preserved`、`partially_preserved` などを使用する）
9. **参照シート（R2V）**: 1 枚の画像に複数のパネルを含めることができる。シート自体に専用の `<Picture N>` を付け（`<Subject N>` 内だけに書かない）、パネルを説明し、ショットからパネルを指定する（例: `<Picture 2>` の正面全身）。パネルには明確にラベルを付ける

ワークフロー固有のタグとコントロールは各ワークフローページにあります。

## ショットとカット

`[Shot 1]` は 0.00s から; 以降はカット時刻で開始:

```text
[Shot 2] At 00:03.500, the camera cuts to...
```

- 時刻は増加し `length` 内
- 単一時刻（`At 00:05.000`）、範囲不可
- `the camera cuts to` など; 必要ならディゾルブ/フェード

被写体・空間・状態・視点・時間が変わるときに新ショット。微リフレームは 1 ショットでカメラモーション。

## カメラワーク

1 ショットに 1 つの動きだけを、そのショットの段落に、何に対して動くかと一緒に書く。振幅と速度は任意で、使えるフレーズは 4 つだけ: `with small amplitude`、`with large amplitude`、`at slow speed`、`at fast speed`。中程度の振幅と通常速度にはフレーズがなく、省略すると中程度・通常の意味になる。

```text
The camera pushes in with small amplitude at slow speed toward the folded letter in her hands.
```

モデルが受け付けるカメラワークのフレーズ:

| 動き | 効果 |
| :--- | :--- |
| `Zoom In` / `Zoom Out` | 焦点距離のみ変更、カメラ位置は固定 |
| `Push In` / `Pull Out` | カメラが前後へ移動 |
| `Pan Left` / `Pan Right` | 位置は固定、レンズが左右に振れる |
| `Truck Left` / `Truck Right` | カメラが左右に平行移動 |
| `Tilt Up` / `Tilt Down` | 位置は固定、レンズが上下に振れる |
| `Pedestal Up` / `Pedestal Down` | カメラ全体が上下に移動 |
| `Arc Shot` | 被写体の周りを弧を描いて移動 |
| `Tracking Shot` | 動く被写体を追従 |
| `Static Shot` | カメラもレンズも動かない |
| `Shake Slightly` / `Shake Strongly` | 弱い/強いカメラの揺れ |
| `POV` | 被写体の視点 |
| `Roll Clockwise` / `Roll Counterclockwise` | レンズ軸まわりの回転 |

弧を描きながら寄るなど 2 つを同時に書くと、通常は片方だけが反映され、尺に収まらない動きはその尺に圧縮される。正確に再現したいトラックは文字ではなくガイドで渡す。スタンドインが軌道を動くクリップをレンダリングし、[`Add Guide for MiniMax H3`](/ja/built-in-nodes/MiniMaxH3AddGuide) の `image` に `vae` を接続して `frame_idx` 0 でつなぐ。配線は [H3 ネイティブワークフロー](/ja/tutorials/video/minimax/minimax-h3-native) のガイド固定の節を参照。クリップは 5 フレーム以上、動画より長くしない。5 フレーム未満のバッチは静止画として扱われる。ガイドは 5・22・39 フレームに切り詰められ、末尾を超えるクリップはエラーになる。

## セリフと話者

- **話者 ID**: `(S1)`、`(S2)`…（オフ画面/歌唱含む）; デュエット `(S1,S2)`
- **`<d>`**: ID・動作・演技はタグ外; タグ内は言語タグと原文
- **`<d>` 内句読点**: `, . ? !` を保持; 文末は `.` `?` `!`; 不明は `[unclear]`; 省略号は避ける
- **ボイスオーバー**: `says in an off-screen voiceover` と唇が閉じたまま; 跨ぎは `<scenetrans>`
- **複数話者 + オーディオ参照**: 誤割当あり; タイムコードより可視イベントに結び付け; 必要なら話者別に外部生成して参照
