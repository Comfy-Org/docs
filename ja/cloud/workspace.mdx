## 概要

ワークスペースは、Comfy Cloud での作業におけるアカウントの境界です。ワークフロー、アップロードしたファイル、出力、クレジットは単一のユーザーではなくワークスペースに属するため、ワークスペースを切り替えると、表示されるファイルと、実行で消費されるクレジットが切り替わります。

すべてのユーザーには**個人**ワークスペースが付与されます。他のユーザーと一緒に作業するには、**チーム**ワークスペースを作成して招待します。

チームワークスペースに招待されている場合、何かを作成する必要はありません。招待メールを開き、その送信先のアドレスでログインし、そのワークスペースに切り替えてください。詳しくは[ワークスペースの切り替え](#ワークスペースを切り替える)を参照してください。

## 個人ワークスペースとチームワークスペース

| 種類 | 内容 |
|------|-------------|
| **個人** | すべてのユーザーに対して自動的に作成され、シートは1つだけです。アクセスできるのはあなただけです。削除することはできず、退出することもできません。 |
| **チーム** | あなたが作成した、または招待された共有ワークスペースです。メンバーはワークスペースのファイルを閲覧でき、そのクレジットを共有します。 |

チームワークスペースの作成は無料です。メンバーを招待するには、ワークスペースにシートが必要です。チームプランに加入していないワークスペースにはシートが1つだけあり、それはオーナーに属します。チームプランにはメンバーごとに1つのシートが含まれます。

## ワークスペースごとに分離されるもの {#what-is-separate-per-workspace}

各ワークスペースは次のものを個別に保持します。

- **ファイルと出力**: アップロード、生成済み画像、ジョブ、履歴
- **ワークフロー**: そのワークスペースに表示されるワークフローライブラリ
- **プランとクレジット**: 独自のサブスクリプションとクレジット残高
- **ユーザー**: メンバー、ロール、保留中の招待
- **アクセス**: ワークスペースの API キー、およびエンタープライズワークスペースではメンバーが実行できるパートナーモデル

ワークスペースを切り替えると、これらすべてが一度に切り替わり、ワークスペース間で自動的にコピーされるものはありません。

## チームワークスペースを作成

<Steps>
  <Step title="プロフィールメニューを開く">
    右上隅にあるプロフィール画像をクリックします。
  </Step>
  <Step title="ワークスペース一覧を開く">
    メニュー内のワークスペース名をクリックします。一覧には、あなたが所属するすべてのワークスペースと、その中でのあなたの役割が表示されます。

    ![ワークスペース一覧。最下部に [新しいワークスペースを作成] があります](/images/cloud/workspace/workspace-list.png)
  </Step>
  <Step title="ワークスペースを作成する">
    一覧の最下部にある **新しいワークスペースを作成** をクリックします。
  </Step>
  <Step title="名前を付ける">
    名前を入力して **作成** をクリックします。名前は1〜50文字で、英字または数字で始まる必要があり、英字、数字、スペース、および `- _ ' . , ( ) & +` の文字を使用できます。

    ![新しいワークスペースを作成ダイアログ](/images/cloud/workspace/create-workspace.png)
  </Step>
</Steps>

Comfy Cloud は新しいワークスペースに切り替え、ページを再読み込みします。

<Note>
  個人ワークスペースを含め、合計で最大 **10 個のワークスペース** を所有できます。メンバーとして参加できるワークスペースの数に制限はありません。
</Note>

ワークスペース一覧を直接開くには、Comfy Cloud の URL に `?create_workspace=1` を追加します。たとえば `https://cloud.comfy.org/?create_workspace=1` です。チームワークスペースダイアログが開き、ワークスペースの一覧と、**新しいワークスペース** フィールド、**ワークスペースを作成** ボタンが表示されます。

## メンバーを招待

ワークスペースのオーナーのみがメンバーを招待できます。チームプランにはメンバーごとに 1 つのシートが含まれており、**メンバー**タブには使用中のシート数が表示されます。例えば `3 of 20 members` のようになります。保留中の招待もこの上限にカウントされます。

![招待ボタンがあるワークスペース設定のメンバーセクション](/images/cloud/workspace/workspace-members.png)

メンバーを招待するには:

<Steps>
  <Step title="ワークスペース設定を開く">
    プロフィールメニューで **ワークスペース設定** をクリックします。
  </Step>
  <Step title="メンバーセクションを開く">
    **メンバー** を選択します。
  </Step>
  <Step title="招待を送信する">
    **招待** をクリックし、1 つまたは複数のメールアドレスをカンマで区切って入力してから、ダイアログで **招待** をクリックします。
  </Step>
</Steps>

![2 つのメールアドレスを入力した招待メンバーダイアログ](/images/cloud/workspace/invite-members.png)

<Note>
  **招待** をクリックしてもダイアログが開かない場合、ワークスペースに空きシートがありません。チームプラン以外のワークスペースにはシートが 1 つだけあり、満員のチームではメンバー上限のツールチップが表示されます。**プランとクレジット** を開いてチームプランにアップグレードするか、メンバーを増やす必要がある場合はエンタープライズについてお問い合わせください。
</Note>

Comfy Cloud は各メンバーに参加用のリンクをメールで送信します。招待は送信先のアドレスに紐付けられているため、受信者は同じアドレスでログインするか、そのアドレスでアカウントを作成する必要があります。リンクを開いたときにログインしていない場合は、先にログインするよう求められ、その後で招待が適用されます。

まだ承認されていない招待は、メンバーセクションの **保留中** タブに有効期限とともに表示されます。このタブはオーナーにのみ表示され、メンバーにはすでに参加した人のリストだけが表示されます。そこからオーナーは次の操作を行えます:

- **招待リンクをコピー**: メールを待たずにリンクを直接共有できます
- **招待を再送信**: 新しいリンクでメールを再送信します
- **招待をキャンセル**: 招待を取り消します

招待は送信から 30 日後に期限切れになります。

![招待日と有効期限が表示された保留中の招待](/images/cloud/workspace/pending-invites.png)

## 役割と権限

| 役割 | できること |
|------|--------|
| **オーナー** | メンバーの招待と削除、役割の変更、ワークスペースの名前変更と削除、ワークスペースのプランとクレジットの管理。 |
| **メンバー** | ワークスペース内でワークフローを実行し、メンバーリストを表示できます。メンバーの招待、保留中の招待の確認、ワークスペース設定の変更、請求管理はできません。 |

オーナーは「メンバー」セクションからメンバーの役割を変更できます。これにより、メンバーをオーナーに昇格させたり、オーナーをメンバーに降格させたりできます。ワークスペースには常に少なくとも1人のオーナーが必要なため、最後に残ったオーナーは降格も削除もできません。Comfy Cloud の一部のメッセージではオーナーをワークスペース管理者と呼びますが、同じ役割です。

メンバーは**ワークスペース設定**を開いて、ワークスペースのプランとメンバーリストを確認できますが、そこでは何も変更できません。オーナーがメンバーを削除すると、そのユーザーはワークスペースのファイルとワークフローへのアクセスを失い、シートが解放され、そのユーザーが作成したワークスペースの API キーは機能しなくなります。メンバーは自分自身を削除できません。その代わり、ワークスペースから退出します。

## ワークスペースを管理

プロフィールメニューから**ワークスペース設定**を開きます。設定ダイアログの**ワークスペース**グループには次のセクションがあります。

- **プランとクレジット**: ワークスペースのプラン、クレジット残高、トップアップ。変更できるのはオーナーだけです。
- **メンバー**: メンバー一覧、ロール、保留中の招待。保留中の招待はオーナーに表示されます。
- **パートナーモデル**: ワークスペースのオーナーに表示されます。メンバーが実行できるプロバイダーのモデルを制限する機能は、エンタープライズプランの機能です。**すべてのパートナーモデルを許可する**をオフにすると、メンバーが実行できるプロバイダーとモデルを選択できます。後から追加されたモデルは、有効にするまで無効のままです。変更がワークスペース全体に適用されるまで最大 10 分かかることがあります。

メンバーセクションのメニューでは、オーナーが次の操作を行えます。

- **ワークスペースの詳細を編集**: ワークスペースの名前を変更します
- **ワークスペースを削除**: ワークスペースに有効なサブスクリプションがない場合に利用できます。[チームワークスペースを削除](#チームワークスペースを削除)を参照してください。
- **ワークスペースを退出**: チームワークスペースを退出します。自分が唯一のオーナーであるワークスペースからは退出できません。

![ワークスペースメニュー: ワークスペースの詳細を編集、ワークスペースを削除、ワークスペースを退出](/images/cloud/workspace/workspace-menu.png)

メンバーにもこのメニューは表示されますが、**ワークスペースを退出**の項目のみです。

### チームワークスペースを削除

チームワークスペースを削除できるのはオーナーだけであり、ワークスペースに有効なサブスクリプションがあってはなりません。ワークスペースの削除は永続的です。未使用のクレジットと保存されていないアセットは失われ、ワークスペースを復元することはできません。個人ワークスペースは削除できず、エンタープライズワークスペースは弊社のセールスチームが管理します。

<Steps>
  <Step title="プランをキャンセルする">
    **ワークスペース設定** → **プランとクレジット**で、三点メニューを開き、**プランをキャンセル**を選択します。ワークスペースにサブスクリプションがない場合は、この手順をスキップしてください。
  </Step>
  <Step title="ワークスペースを削除する">
    **ワークスペース設定** → **メンバー**で、三点メニューを開き、**ワークスペースを削除**を選択し、ダイアログで確認します。
  </Step>
</Steps>

## ワークスペースを切り替える

1. プロフィールメニューを開きます。
2. ワークスペース名をクリックすると、ワークスペースの一覧が開きます。
3. 作業したいワークスペースを選択します。

![プロフィールメニュー。ここでワークスペース名をクリックするとワークスペースの一覧が開きます](/images/cloud/workspace/profile-menu.png)

Comfy Cloud は選択したワークスペースでページを再読み込みし、次回ログインしたときにそのワークスペースを記憶します。

| URL パラメータ | 動作 |
|------|--------|
| `?create_workspace=1` | ワークスペースの一覧を開き、**新しいワークスペース** 入力欄と **ワークスペースを作成** ボタンを表示します |
| `?invite=TOKEN` | ワークスペースの招待を承認します |

## ワークスペースの課金方法

プランとクレジットは個人アカウントではなく、ワークスペースに属します。

**個人ワークスペース**は自身のプランを使用し、そのクレジットを消費するのはあなただけです。

**チームワークスペース**は、オーナーが設定するクレジットサブスクリプションを使用します:

- オーナーは**Choose a Plan**(**For Teams**)で、クレジットスライダーを使ってワークスペースの月額クレジット量を選択します。価格は選択した量に応じて決まり、選択するクレジット量が多いほど実質的な料率が下がります。各請求期間ごとに、その量がプールに補充されます。
- 年額契約は月額よりも安く、ワークスペースは1年分のクレジットを前もって受け取ります。
- メンバーは個別に請求されず、メンバーを追加または削除しても価格は変わりません。プランにはワークスペースのシート数が含まれます。プランに含まれる数を超えるメンバーが必要な場合は、エンタープライズについてお問い合わせください。
- すべてのメンバーが同じクレジットプールを消費します。
- サブスクリプションのクレジットが先に消費され、トップアップクレジットは12か月間有効です。
- ワークスペースを個人プランに変更すると、他のすべてのメンバーが即座に削除されるため、切り替える前に共有作業を移動してください。

現在の料金と割引については[Comfy Cloudの料金](https://www.comfy.org/cloud/pricing)を、チームプランの設定については[Comfy Cloudにサブスクライブ](/ja/support/subscription/subscribing)を、プラン変更については[Comfy Cloudプランの変更](/ja/support/subscription/changing-plan)をご覧ください。

## FAQ

<AccordionGroup>
  <Accordion title="複数のチームワークスペースに所属できますか？">
    はい。個人ワークスペースを含めて最大10個のワークスペースを所有でき、招待されたワークスペースにはいくつでもメンバーとして参加できます。
  </Accordion>

  <Accordion title="チームワークスペースに参加するには自分のサブスクリプションが必要ですか？">
    いいえ。メンバーに個別の課金は行われません。ワークスペース内での実行にはワークスペースのクレジットが使用され、そのクレジットはワークスペースのオーナーが管理します。
  </Accordion>

  <Accordion title="招待メールが届きません。どうすればよいですか？">
    ワークスペースのオーナーに **招待を再送信** を使ってもらうか、メンバーセクションの **保留中** タブから **招待リンクをコピー** して送ってもらうよう依頼してください。招待は送信から30日後に期限切れになるため、古い招待は再送信が必要な場合があります。
  </Accordion>

  <Accordion title="個人ワークスペースを削除できますか？">
    いいえ。個人ワークスペースは永続的で、既定のワークスペースとして機能します。
  </Accordion>

  <Accordion title="個人ワークスペースに誰かを招待できますか？">
    いいえ。個人ワークスペースは席数が1つだけで、メンバー管理もありません。
  </Accordion>

  <Accordion title="チームワークスペースから退出するとどうなりますか？">
    ワークスペースはワークスペース一覧から消え、そのファイルやワークフローにアクセスできなくなります。そのワークスペース用に作成したワークスペース API キーは機能しなくなります。個人ワークスペースとその内容は影響を受けません。
  </Accordion>

  <Accordion title="ワークスペースのクレジットが不足するとどうなりますか？">
    オーナーがクレジットを追加するまで、メンバーはワークフローを実行できません。ワークスペースのサブスクリプションが無効な場合や支払いに失敗した場合も同様です。ワークスペースのオーナーにプランまたは支払い方法を修正するよう依頼してください。
  </Accordion>

  <Accordion title="ワークスペースを削除できないのはなぜですか？">
    ワークスペースにまだ有効なサブスクリプションが残っています。まず **プランとクレジット** で **プランをキャンセル** してから、ワークスペースを削除してください。**ワークスペースを削除** はプランをキャンセルするとすぐに使用できるようになり、請求期間の終了を待つ必要はありません。個人ワークスペースはまったく削除できず、エンタープライズワークスペースは弊社の営業チームを通じて終了します。
  </Accordion>

  <Accordion title="削除したワークスペースは復元できますか？">
    いいえ。ワークスペースの削除は永続的です。
  </Accordion>
</AccordionGroup>
