## 一般質問

<Accordion title="Comfy Desktop とレガシー Desktop の違いは？">
Comfy Desktop は完全に書き直された**マルチインストレーションマネージャー**です。シングルインストールのアプリケーションだったレガシー Desktop とは異なり、複数の ComfyUI バージョンを同時にインストール、管理、実行できます。スナップショットやモデルのダウンロード管理も追加されています。

レガシー Desktop をご利用の方は、既存のセットアップを移行するために[移行ガイド](/ja/installation/desktop/usage/migrate)を参照してください。
</Accordion>
<Accordion title="Comfy Desktop はオープンソースですか？">
はい。ソースは [GitHub](https://github.com/Comfy-Org/Comfy-Desktop) で公開されています。Comfy Desktop はデュアルライセンスです：[AGPL-3.0-or-later](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/LICENSE)、または Comfy Org の商用ライセンス（`licensing@comfy.org`）。
</Accordion>
<Accordion title="Comfy Desktop は Portable/手動インストールを置き換えますか？">
Comfy Desktop は複数のインストール方法の一つです。**Portable（Windows）** インストール、**手動インストール**、または **Comfy Cloud** も、必要に応じて引き続き利用できます。Desktop は使いやすさと、ワンクリックアップデートやスナップショット管理といった機能から、ほとんどのユーザーに推奨されています。
</Accordion>
<Accordion title="アップデートの確認をオフにできますか？">
いいえ。Comfy Desktop は起動直後と、その後 10 分ごとに新しいバージョンを確認し、この確認をオフにする方法はありません。唯一のアップデート設定は **Desktop Settings → Updates** の **Automatically install Desktop updates** で、既定でオンになっています。

- **オンの場合**：新しいバージョンはバックグラウンドでダウンロードされ、確認なしでインストールされます。ダウンロード中はタイトルバーに **Downloading update…**、適用の準備ができると **Desktop Update Ready** が表示されます。
- **オフの場合**：タイトルバーに **Desktop Update**、Updates カードに **Update … available** が表示されます。アップデートは引き続きバックグラウンドでダウンロードされますが、自動では何もインストールされません。終了時にも次回起動時にも適用されません。準備ができたら **Desktop Update Ready** のピルをクリックし、**Restart & Update** を選択してください。

ビルド内の ComfyUI バージョンは別に更新します。ビルドの **Overview** タブで **Stable** または **Latest on GitHub** チャンネルを選択してください。

Linux では、アプリ内アップデーターは `.deb` インストールには適用されません。[ユニバーサルダウンロードリンク](https://dl.todesktop.com/241130tqe9q3y)から新しいパッケージをダウンロードし、`sudo apt install ./*.deb` でインストールしてください。
</Accordion>

## インストールとセットアップ

<Accordion title="システム要件は？">
詳細は[システム要件](/ja/installation/system_requirements)を参照してください。

- **Windows：** Windows 10+、x64 または ARM64。専用 GPU（NVIDIA / AMD）が推奨されますが、必須ではありません。
- **macOS：** macOS 13+ (Ventura)、Apple Silicon (M1+)
- **Linux：** 公式の `.deb` および AppImage パッケージは [Comfyデスクトップ リポジトリ](https://github.com/Comfy-Org/Comfy-Desktop) を通じて配布されています。専用 GPU が推奨されます。
- **ディスク：** スタンドアロンインストールごとに最低 4.85 GB
- **RAM：** 最低 8 GB、推奨 16 GB
</Accordion>
<Accordion title="管理者権限なしで Comfyデスクトップをインストールできますか？">
**Windows** のスタンドアロンインストールは管理者権限を必要としません。**macOS** は、システム全体への初回インストール時に管理者権限が必要です。**Linux** では `.deb` パッケージのインストールに `sudo` が必要です。AppImage は管理者権限なしでユーザースペースで実行できます。
</Accordion>
<Accordion title="Comfyデスクトップをダウンロードするには？">
公式 [ComfyUI ダウンロードページ](https://comfy.org/download) から最新の Windows または macOS ビルドをダウンロードしてください。Linux では [Comfyデスクトップ リポジトリ](https://github.com/Comfy-Org/Comfy-Desktop) の[ユニバーサルダウンロードリンク](https://dl.todesktop.com/241130tqe9q3y)から `.deb` または AppImage を入手できます。ソースから実行する場合は [Linux インストールガイド](/ja/installation/desktop/overview#osに合わせてcomfyデスクトップをインストール) を参照してください。
</Accordion>
<Accordion title="レガシーデスクトップと Comfyデスクトップの両方をインストールできますか？">
はい、共存できます。ただし、インストール済みの環境を新しい Comfyデスクトップに移行し、最終的にレガシーデスクトップをアンインストールすることを推奨します。[移行ガイド](/ja/installation/desktop/usage/migrate) を参照してください。
</Accordion>

## 使用方法

<Accordion title="新しい ComfyUI のインストールを追加するには？">
**ビルド**ページを開き、**新規ビルド**をクリックして、このコンピューターに新しいビルドをインストールします。すでにあるビルドを追加するには、**新規ビルド**の横にある矢印（**その他のビルドオプション**）をクリックし、**既存のビルドを追加**を選択します。代わりに Comfy Cloud で ComfyUI を実行するには、**Comfy Cloud** ビルドを開きます。

- **新規ビルド**: Comfy Desktop がセットアップする新しいインストール。
- **既存のビルドを追加**: すでにインストールした ComfyUI（git clone やポータブルインストールなど）を追跡します。
- **Comfy Cloud**: このコンピューターに何もインストールせずに、クラウドの GPU で ComfyUI を実行します。

すべてのオプションについては[ビルド](/ja/installation/desktop/usage/instance-management)を参照してください。
</Accordion>
<Accordion title="複数の ComfyUI バージョンを同時に実行できますか？">
はい！Comfy Desktop はそのために設計されています。各ビルドは、独自の Python と依存関係を持つ分離された環境で実行されます。別々のウィンドウで同時に起動できます。
</Accordion>
<Accordion title="自分のモデル、カスタムノード、設定はどこに保存されますか？">
モデルはデフォルトでビルド間で共有されます。共有フォルダーは[デスクトップ設定 → フォルダー](/ja/installation/desktop/usage/settings#storage)で設定します。

- **スタンドアロン:** インストール自体はそのビルドフォルダーにあります。カスタムノードと Python 環境はビルドごとに独立しています。モデルは通常、共有モデルフォルダーから取得されます。
- **Git クローン / ポータブル（追跡対象）:** データはその既存のフォルダー（`models/`、`custom_nodes/`、`user/`）に保持されます。共有モデル、入力、出力を利用することもできます。
</Accordion>
<Accordion title="スナップショットはどのように機能しますか？">
Comfy Desktop は、主要なイベント時にスナップショットを自動的に作成します。起動と再起動のたび、更新の前後、および復元の後です。スナップショットには、ビルドの ComfyUI バージョン、カスタムノードとそのバージョン、および環境内のすべての pip パッケージが記録されます。モデルファイル、入力、出力はスナップショットに含まれません。

ビルドの**スナップショット**タブから、スナップショットの閲覧、復元、エクスポート、共有ができます。詳細は[スナップショットの保存と復元](/ja/installation/desktop/usage/instance-management#スナップショットの保存と復元)を参照してください。
</Accordion>

### Comfy Desktop の停止・終了方法

実行中の ComfyUI ビルドを停止し、Comfy Desktop を開いたままにするには：

1. **サイドバー**または**ビルド**ページから、そのビルドのページを開きます。
2. **停止**をクリックします。
3. ダイアログで確認します。

Comfy Desktop を終了するには、**タイトルバー**の**メニュー**を開いて**デスクトップを終了**を選択するか、最後のウィンドウを閉じます。最後のウィンドウを閉じると Comfy Desktop が終了します。バックグラウンドで実行し続けるトレイモードはありません。ComfyUI を実行しているウィンドウには、**メニュー**に**ウィンドウを閉じる**もあり、これを選ぶとそのウィンドウが閉じ、実行中のビルドが停止します。

## トラブルシューティング

<Accordion title="インストール後にアプリが起動しない">
1. **Windows：** 一度管理者として実行してみてください
2. **macOS：** セキュリティ警告が表示されたら、**システム設定 → プライバシーとセキュリティ** に移動し、**このまま開く** をクリック
3. **Linux：** FUSE 2 をインストール：Ubuntu 24.04 以降は `libfuse2t64`、22.04 は `libfuse2`
4. [ダウンロードページ](https://comfy.org/download) で最新版を確認
</Accordion>
<Accordion title="更新後に Comfy Desktop が勝手に終了する（Windows）">
Windows では、更新のダウンロードが完了しなかった場合に Comfy Desktop 1.0.46 以前が起動できなくなることがあります。アプリは更新画面を一瞬表示した後、エラーを出さずに終了します。これは起動のたびに繰り返され、修正版をダウンロードする前にアプリが終了してしまいます。バージョン 1.0.47 以降ではこの問題は修正されています。

復旧するには、最新バージョンを手動でインストールしてください：

1. [最新の Windows インストーラー](https://dl.todesktop.com/241130tqe9q3y/windows)をダウンロードするか、[ダウンロードページ](https://comfy.org/download)から入手してください。
2. インストーラーを実行します。古いバージョンを先にアンインストールする必要はありません。
3. Comfy Desktop を起動します。

インストール、モデル、設定はそのまま保持されます。
</Accordion>
<Accordion title="GPU が検出されない">
- NVIDIA ドライバーが最新であることを確認
- Linux では CUDA toolkit がインストールされているか確認
- インストールタイプが GPU をサポートしているか確認（Standalone と Git Clone は対応、Cloud 接続はリモート GPU を使用）
</Accordion>
<Accordion title="インストールの更新に失敗する">
- インターネット接続を確認
- 再試行する前に、ビルドの **Snapshots** タブで手動スナップショットを作成してください
- 問題が続く場合は、以前のスナップショットに復元して再試行してください
</Accordion>

<Accordion title="インストールや更新で Operation failed と表示される">
進行状況画面は開いたままになり、**Operation failed**、エラー、および（利用可能な場合は）自動で開く **View logs** パネルが表示されます。

- **Reboot**：同じ操作を再試行します（起動に失敗した場合は **Restart ComfyUI**）。
- **Back**：確認なしで **Home** に戻ります。失敗したインストールはディスクに残ります。
- ステップの実行中に離れるとキャンセルになります。**Back to Home** では **Cancel current operation?** を確認します。インストールをキャンセルすると作成途中のフォルダーを削除しようとし、削除に失敗した場合はファイルが残ることがあります。

繰り返し失敗する場合は、ネットワークを確認してから、**デスクトップ設定 → ログ → ログフォルダーを開く** で `app.log`（および `app.log_*.log` があればそれも）を取得してください。初回インストール時は、**タイトルバー**の **Menu** を開いて **Skip onboarding** を選択すると、先に **Home** に移動できます。詳しくは [Comfy Desktop の起動ログを確認するには？](#comfy-desktop-の起動ログを確認するには) を参照してください。
</Accordion>
<Accordion title="Low disk space や Not Enough Space for Template Models と表示される">
**新規ビルド**の作成中、Comfy Desktop はインストール先ドライブの空き容量を確認します。**Low disk space** は警告です。続行するには **Continue anyway** を選択するか、別のフォルダーを選択してください。詳しくは[新しいビルドのインストール](/ja/installation/desktop/usage/instance-management#新しいビルドをインストール)を参照してください。
</Accordion>
<Accordion title="Comfy Desktop の起動ログを確認するには？">
Desktop アプリはローテーションする `app.log` ファイルに書き込みます。いちばん早い確認方法は **デスクトップ設定 → ログ → ログフォルダーを開く** です（サイドバーの最下部）。

デフォルトのログフォルダー：

- **Windows:** `%APPDATA%\Comfy Desktop\logs`
- **macOS:** `~/Library/Logs/Comfy Desktop`
- **Linux:** `~/.config/Comfy Desktop/logs`

`app.log` を探してください。以前のセッションはタイムスタンプ付きの `app.log_*.log` ファイルにローテーションされます。

ComfyUI プロセスの出力（Desktop アプリ本体ではない）を確認するには、ビルドのページを開き、**ターミナル** タブを使用してください。[ビルドの管理](/ja/installation/desktop/usage/instance-management#ビルドの管理)を参照してください。
</Accordion>
<Accordion title="ComfyUI で Ollama を使えますか？">
ComfyUI は拡散モデルのバックエンドとして [Ollama](https://ollama.ai) をネイティブ統合していません。ただし、ComfyUI Manager レジストリで利用できる**カスタムノード**を通じて、Ollama が提供する LLM をプロンプト生成やテキスト処理に利用できます。

LLM サービスへの接続については、[カスタムノードのインストール](/ja/installation/install_custom_node)を参照してください。
</Accordion>
<Accordion title="Comfy Desktop をアンインストールするには？">
Comfy Desktop とそのインストールはディスク上で分離されています。アプリとインストールをアンインストールするには：

1. **アプリ内からインストールを削除**（右クリック → 削除）するか、インストールフォルダーを手動で削除
2. **アプリをアンインストール**：システム標準の方法で（Windows はプログラムの追加と削除、macOS はゴミ箱にドラッグ、Linux はパッケージマネージャー）

アプリ設定、ログ、共有モデル、出力は削除されません。残ったフォルダーと完全なクリーンアップについては、[Windows](/ja/installation/desktop/overview#comfyデスクトップのアンインストール)、[macOS](/ja/installation/desktop/overview#comfyデスクトップのアンインストール)、[Linux](/ja/installation/desktop/overview#comfyデスクトップのアンインストール) を参照してください。
</Accordion>
<Accordion title="Comfy Desktop をヘッドレスまたはサーバーモードで実行できますか？">
できません。Comfy Desktop はローカル GUI アプリケーションとして設計されており、ヘッドレスモード、サーバーのみのモード、またはリモート操作をサポートしていません。ComfyUI インスタンスを起動・管理するにはグラフィカルなデスクトップ環境が必要です。

ヘッドレスまたはサーバー展開の場合は、**手動 ComfyUI インストール** または **Windows Portable ビルド** を使用してください。
</Accordion>
