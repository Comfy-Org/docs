Comfyデスクトップは、ComfyUI を実行するために使うアプリです。実行先は、このコンピューターにインストールされたコピー（ローカルビルド）でも、クラウドの GPU 上で動作しどのコンピューターでも使える Comfy Cloud でもかまいません。ComfyUI に必要なものをすべてダウンロードしてセットアップするため、インストールするアプリは Comfyデスクトップだけです。このページでは、Comfyデスクトップをダウンロードし、初回起動時に開くセットアップ画面を確認して、ComfyUI を開きます。

![左側にサイドバー、ウェルカム見出し、アプリの行、右上に ComfyUI を開くボタン、そして Comfy Cloud カードと新しいビルドタイルを含むビルド行がある Comfyデスクトップのホーム画面](/images/desktop/installation/comfy-desktop-landing-page.png)

<Note>
  Comfyデスクトップは、ComfyUI の各コピーをビルドと呼びます。以前のバージョンの Comfyデスクトップを使用していた場合、インスタンスは同じモデルと設定を引き継いだビルドとして表示されます。
</Note>

## ComfyUIを実行する場所を選択

Comfyデスクトップでは、ComfyUIを2つの場所で実行できます。このコンピューター上のローカルビルド、または[Comfy Cloud](https://comfy.org/cloud)です。初回起動時のセットアップ画面ではローカルビルドがインストールされるため、開始前にどちらを使用するかを選択してください。

| | ローカルビルド | Comfy Cloud |
| --- | --- | --- |
| 実行環境 | このコンピューター | クラウド上のGPUで動作するため、どのコンピューターでも使用できます |
| セットアップ | 初回起動時にセットアップ画面でインストールされます | 不要です。**ホーム**に**Comfy Cloud**カードが表示されます |
| コスト | 無料 | Comfyクレジット。GPUの実行中にのみ消費されます |
| 必要なもの | インストール用の空きディスク容量（必要な量はセットアップ画面に表示されます） | Comfyアカウント |

Comfy Cloudのみを使用する場合は、セットアップ画面が開いたときにインストールをスキップしてください。その方法は[ComfyデスクトップでComfy Cloudを開く](#comfyデスクトップでcomfy-cloudを開く)で説明しています。

## Comfyデスクトップのダウンロード

ダウンロードページでは、Windows、macOS、Linux用のインストーラーを提供しています。

1. [comfy.org/download](https://comfy.org/download) にアクセスします。
2. **DOWNLOAD DESKTOP** をクリックします。このボタンは、ページが検出したオペレーティングシステム用のインストーラーをダウンロードします。インストーラーの名前はボタンのテキストの下に表示されます。
3. 別のインストーラーを選択するには、ボタンの横にある矢印（**All installers**）をクリックし、インストーラーを選択します。リストには **Windows x64**、**Windows ARM64 (NVIDIA only)**、**macOS (Apple Silicon)**、**Linux x64 (AppImage)** が表示されます。

   ![macOS (Apple Silicon) がボタンのテキストの下に表示された DOWNLOAD DESKTOP ボタンと、その下に開かれた All installers リスト（Windows x64、Windows ARM64 (NVIDIA only)、macOS (Apple Silicon)、Linux x64 (AppImage)）](/images/desktop/installation/comfy-desktop-install.png)

## OSに合わせてComfyデスクトップをインストール

お使いのOSのタブを選択し、要件を確認して、ダウンロードしたファイルをインストールしてください。

<Tabs>
  <Tab title="Windows">
    **システム要件**

    - Windows 10以降（x64またはARM64）。
    - 専用のNVIDIAまたはAMD GPUを推奨しますが、必須ではありません。ARM64の場合、ローカルビルドにはNVIDIA GPUが必要です。
    - 各ビルドにつき少なくとも4.85 GBの空きディスク容量が必要です。

    **インストール**

    1. ダウンロードした `.exe` インストーラーを実行し、画面の指示に従ってください。
    2. **スタート**メニューまたはデスクトップのショートカットからComfyデスクトップを開きます。

    ![Windowsで実行中のComfyデスクトップインストーラー](/images/desktop/installation/windows_1_install.png)
  </Tab>
  <Tab title="macOS">
    **システム要件**

    - macOS 13（Ventura）以降。
    - Appleシリコン（M1以降）搭載のMac。
    - 各ビルドにつき少なくとも4.85 GBの空きディスク容量が必要です。

    **インストール**

    1. ダウンロードした `.dmg` ファイルを開きます。
    2. **Comfyデスクトップ**を**アプリケーション**フォルダーにドラッグします。
    3. LaunchpadまたはSpotlightからComfyデスクトップを開きます。

    ![macOS上のComfyデスクトップのディスクイメージ（アプリアイコンとアプリケーションフォルダー）](/images/desktop/installation/mac_1_install.png)

    初回起動時にmacOSがセキュリティ警告を表示した場合は、**システム設定** > **プライバシーとセキュリティ** に移動し、**このまま開く**をクリックします。
  </Tab>
  <Tab title="Linux">
    **システム要件**

    - x64上のLinux。Ubuntu 22.04以降を推奨します。
    - 専用のNVIDIAまたはAMD GPUを推奨しますが、必須ではありません。
    - 各ビルドにつき少なくとも4.85 GBの空きディスク容量が必要です。

    ダウンロードページではAppImageを提供しています。DebianおよびUbuntu向けの `.deb` パッケージも、プラットフォームを自動検出する[ユニバーサルダウンロードリンク](https://dl.todesktop.com/241130tqe9q3y)から入手できます。

    **.debパッケージをインストール**

    ```bash
    sudo apt install ./*.deb
    ```

    このパッケージはComfyデスクトップを `/opt/Comfy Desktop` にインストールし、APTソースを追加するため、新しいリリースは通常のシステムアップデート（`sudo apt update` と `sudo apt upgrade`）で入手できます。Ubuntu 24.04以降では、Electronのサンドボックスが機能するようにAppArmorプロフィールもインストールします。Ubuntu 22.04でパッケージをインストールしてから24.04にアップグレードした場合は、プロフィールを追加するために `sudo apt reinstall comfyui-desktop-2` を実行します。

    **AppImageを実行**

    1. AppImageに必要なFUSE 2をインストールします。Ubuntu 24.04以降では `sudo apt install libfuse2t64` を実行します。Ubuntu 22.04では `sudo apt install libfuse2` を実行します。
    2. ファイルに実行権限を付与して実行します：

       ```bash
       chmod +x ./*.AppImage
       ./*.AppImage
       ```

    AppImageは、起動したファイルを置き換えることで自身を更新するため、ユーザーアカウントが書き込み可能なフォルダーに配置してください。ディストリビューションがElectronのサンドボックスをブロックしているために起動に失敗する場合は、`--no-sandbox` を付けて実行してください。このフラグはすべてのプロセスでサンドボックスを無効にするため、通常の起動が失敗した場合にのみ使用してください。

    <Accordion title="ソースからビルドして実行">
      開発用に、Comfyデスクトップを[リポジトリ](https://github.com/Comfy-Org/Comfy-Desktop#development)から実行します。Node.js 24、Corepack経由のpnpm 10、`build-essential`、および`git`が必要です。

      ```bash
      sudo apt install build-essential git
      nvm install 24 && nvm use 24
      corepack enable
      git clone https://github.com/Comfy-Org/Comfy-Desktop.git
      cd Comfy-Desktop
      pnpm run init
      ./linux-dev.sh
      ```

      ソースチェックアウトは自身を更新しません。更新するには、`git pull` と `pnpm run init` を実行してから、再度 `./linux-dev.sh` を起動します。
    </Accordion>
  </Tab>
</Tabs>

次に、Comfyデスクトップを開きます。初回起動時にはセットアップ画面が表示されます。

<Tip>
  中国語のダウンロードページ、[comfy.org/zh-CN/download](https://comfy.org/zh-CN/download) でも同じインストーラーを提供しています。ボタンには **下载桌面版** と表示されます。中国国内のミラーからComfyUIのファイルをダウンロードするには、[セットアップ画面を確認](#セットアップ画面を確認する) を参照してください。
</Tip>

## セットアップ画面を確認する

Comfyデスクトップは初回起動時にセットアップ画面を開きます。タイトルはmacOSでは**このMacにComfyUIをインストール**、Windowsでは**このPCにComfyUIをインストール**、Linuxでは**このコンピューターにComfyUIをインストール**です。**インストール**をクリックするまで何もダウンロードされません。

![「このMacにComfyUIをインストール」というタイトルのセットアップ画面。Apple M5 Proの検出パネルとその変更ボタン、ハードウェア・保存場所・バージョンの行、利用規約ボックスが空の3つの同意チェックボックス、インストールボタンの横にダウンロードサイズが表示されている](/images/desktop/installation/comfy-desktop-first-time.png)

Comfyデスクトップはお使いのコンピューターに合わせて設定を選択します。インストールする前に確認してください：

- **検出されました**：上部のパネルに、Comfyデスクトップが検出したGPUまたはプロセッサーとそのメモリが表示されます。
- **ハードウェア**：ビルドの対象となるハードウェアです。**GPUアクセラレーションなし**は、ComfyUIがプロセッサー上で動作することを意味します。
- **バージョン**：ComfyUIバージョンとそのリリースチャンネル（**Stable**など）です。
- **保存場所**：ビルドのインストール先フォルダーと、そのドライブの空き容量です。

セットアップ画面では、**インストール**の横にダウンロードサイズが表示されます。その横の情報アイコンにポインターを合わせると、インストールに必要なディスク容量を確認できます。

別の設定を選ぶには、**変更**をクリックし、**セットアップの変更**画面で編集して、**変更を保存**をクリックします。

<Tip>
  初回インストールでは、Comfyデスクトップが選択した設定をそのままにしてください。[ビルド](/ja/installation/desktop/usage/instance-management)では、変更できるすべての設定について説明しています。
</Tip>

インストールするには：

1. **EULAと利用規約に同意します。** にチェックを入れます。**EULA**または**利用規約**をクリックすると、それぞれの内容を読むことができます。
2. **インストール**をクリックします。

残りの2つのチェックボックスは任意です：

- **匿名の使用状況データを共有してComfyの改善に協力する**：匿名の使用状況データを送信します。**詳細を学ぶ**をクリックするとプライバシーポリシーが開きます。
- **ベータ機能にオプトインして今後のリリースのテストに協力する**：このコンピューター上のビルドでComfyUIの早期機能を有効にできます。データ共有がオンの場合にのみオンにできます。

利用規約のボックスにチェックを入れる前に**インストール**をクリックすると、その横に**インストールに同意してください。**と表示されます。

<Note>
  Comfyデスクトップが中国語で動作している場合、**インストール**をクリックした後に**中国のミラーを有効にしますか?**と確認されます。**ミラーを有効にする**を選ぶと、`gitcode.com`、`mirrors.aliyun.com`、`mirrors.cloud.tencent.com`からダウンロードします。**今はしない**を選ぶと、`github.com`と`pypi.org`のままになります。
</Note>

### 既存のビルドを保持するか移行する

- **自分のビルドを使う**：このコンピューターにレガシーデスクトップ以外のローカルビルドが既にある場合、**インストール**の横に表示されます。利用規約のボックスにチェックを入れてこれをクリックすると、インストールをスキップします。**ホーム**が既存のビルドで開きます。
- **移行**：Comfyデスクトップがレガシーデスクトップのインストールを検出すると、**インストール**がこれに置き換わります。[レガシーデスクトップからの移行](/ja/installation/desktop/usage/migrate)に、移動される内容が記載されています。

## Homeでインストールの進行状況を確認する {#watch-the-install-on-home}

セットアップ画面が閉じると、**Home**が開きます。ビルド行にあるビルドのカードには、**ComfyUIをインストール中 · 60%**、続いて**ComfyUIを起動中**などの進行状況が表示されます。

![Homeのビルド行にあるビルドカード。ComfyUIをインストール中 · 60%、ビルド名ComfyUI、カード下部の進行状況バーが表示されている](/images/desktop/installation/comfy-desktop-installing-build.png)

インストールの実行中、カードには古いComfyUIバージョンが表示されることがあります。インストールの最後のステップで、ビルドがセットアップ画面に表示されていたバージョンに更新されます。

デフォルトでは、準備ができるとComfyUIは専用のウィンドウで開き、カードには**実行中**と表示されます。

インストールまたは起動に失敗した場合は、[トラブルシューティング](#トラブルシューティング)を参照してください。

#

### ローカルインストールをスキップしてホームへ移動

セットアップ画面には、ビルドがすでに存在しない限りスキップボタンはありません。**ホーム**に移動してComfy Cloudのみを使用するには:

1. セットアップ画面で、利用規約のボックスにチェックを入れます。
2. **検出されました**パネルで、**変更**をクリックします。
3. **タイトルバー**で**メニュー**をクリックし、**オンボーディングをスキップ**を選択します。

**ホーム**が開き、**ビルド**行に**Comfy Cloud**カードが表示されます。

### ログインしてComfy Cloudを開く

ログインするまで、**Comfy Cloud**カードには**使用するにはログイン**と表示されます。

<Warning>
  Comfy CloudはGPUの実行中にComfyクレジットを消費します。開く前に**クレジット**残高を確認してください。
</Warning>

1. **サイドバー**の**Comfyにログイン**カードで、**ログイン**をクリックします。カードには**ブラウザで続ける**と表示されます。

   ![Comfyデスクトップのサイドバー。ホーム、アプリ、アセット、およびビルドの下のComfy Cloud、下部にログインボタンを備えたComfyにログインカード](/images/desktop/installation/comfy-desktop-sign-in-sidebar.png)

2. ブラウザでログインを完了します。**サイドバー**に**クレジット**残高が表示され、アカウントが機能していることが確認できます。
3. **ホーム**で**Comfy Cloud**カードをクリックします。

Comfy Cloudが専用のウィンドウで開きます。

<Tip>
  代わりにブラウザでComfy Cloudを使用するには、[cloud.comfy.org](https://cloud.comfy.org/)を開きます。
</Tip>

## ComfyUI を開く

初回インストール後、**ホーム**からビルドを起動して ComfyUI を開きます。

- 右上の **ComfyUI を開く** をクリックします。最新のビルドが開きます。別のビルドを開くには、ボタン右側の矢印（**開くビルドを選択**）をクリックし、ビルドを選択します。
- または、ビルド行にあるビルドのカードをクリックします。

**ビルド**ページでビルドのタイルをクリックするか、ビルドのページで **開始** をクリックしても開けます。**サイドバー**でビルドをクリックするとそのページが開くだけで、ビルドは起動しません。

ComfyUI の起動中、ビルドには **起動中…** と表示されます。準備ができると ComfyUI が専用のウィンドウで開き、ビルドには **実行中** と表示され、**サイドバー**で緑のドットが付きます。後でウィンドウを再表示するには、実行中のビルドをもう一度クリックします。

ComfyUI が起動しない場合は、[失敗したビルドを修正する](/ja/installation/desktop/usage/instance-management#ビルドの失敗を修正する) を参照してください。**ホーム**と**サイドバー**のその他の機能については、[Comfy Desktop の画面構成](/ja/installation/desktop/usage/overview) を参照してください。最初の画像を生成するには、[ComfyUI で最初の画像を生成する](/ja/get_started/first_generation) に従ってください。

## Comfyデスクトップのアンインストール

Comfyデスクトップをアンインストールすると削除されるのはアプリのみです。ビルド、共有モデルと出力、設定、ログは、削除するまでコンピューター上に残ります。特定のビルドだけを削除する場合は、[ビルドの削除](/ja/installation/desktop/usage/instance-management#ビルドを削除する)を参照してください。

<Warning>
  以下のフォルダーには、ビルド、モデル、出力、設定といったあなた自身のデータが含まれています。削除すると元に戻せません。
</Warning>

macOSおよびLinuxでは、先に[デスクトップ設定](/ja/installation/desktop/usage/settings#storage)の**Remove Comfy Desktop data**でアプリのログ、キャッシュ、一時ファイルを消去できます。

<Tabs>
  <Tab title="Windows">
    1. **設定** > **アプリ** > **インストールされているアプリ**に移動します。
    2. **Comfyデスクトップ**を見つけて、**アンインストール**をクリックします。

    ![Windowsのインストールされているアプリの一覧に表示されたComfyデスクトップとアンインストールオプション](/images/desktop/installation/windows_2_uninstall.png)

    | データ | デフォルトの場所 |
    | --- | --- |
    | ビルド | `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Installs`(古いビルド: `%USERPROFILE%\ComfyUI-Installs`)、および選択した任意のフォルダー |
    | 共有モデル、入力、出力 | `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared`(古いバージョン: `%USERPROFILE%\ComfyUI-Shared`) |
    | 設定とビルドの一覧 | `%APPDATA%\Comfy Desktop` |
    | ログ | `%APPDATA%\Comfy Desktop\logs` |

    すべてを削除するには、これらのフォルダーを削除します。共有フォルダーは、そのモデルと出力が不要になった場合にのみ削除してください。
  </Tab>
  <Tab title="macOS">
    1. Finderで**アプリケーション**フォルダーを開きます。
    2. **Comfyデスクトップ**を右クリックし、**ゴミ箱に入れる**を選択します。

    ![macOSのアプリケーションフォルダーに表示されたComfyデスクトップとメニューのゴミ箱に入れる](/images/desktop/installation/mac_2_uninstall.png)

    | データ | デフォルトの場所 |
    | --- | --- |
    | ビルド | `~/ComfyUI-Installs`、および選択した任意のフォルダー |
    | 共有モデル、入力、出力 | `~/ComfyUI-Shared` |
    | 設定とビルドの一覧 | `~/Library/Application Support/Comfy Desktop` |
    | ログ | `~/Library/Logs/Comfy Desktop` |

    すべてを削除するには、これらのフォルダーを削除します。共有フォルダーは、そのモデルと出力が不要になった場合にのみ削除してください。
  </Tab>
  <Tab title="Linux">
    - **.deb**: `sudo apt remove comfyui-desktop-2` を実行します。AppArmorプロファイルも削除されます。APTソースも削除するには、`sudo apt purge comfyui-desktop-2` を使用します。
    - **AppImage**: `.AppImage` ファイルを削除します。

    | データ | デフォルトの場所 |
    | --- | --- |
    | ビルド | `~/ComfyUI-Installs`、および選択した任意のフォルダー |
    | 共有モデル、入力、出力 | `~/ComfyUI-Shared` |
    | 設定 | `~/.config/comfyui-desktop-2` |
    | ビルドの一覧を含むアプリデータ | `~/.local/share/comfyui-desktop-2` |
    | キャッシュ | `~/.cache/comfyui-desktop-2` |
    | 状態 | `~/.local/state/comfyui-desktop-2` |
    | ログ | `~/.config/Comfy Desktop/logs` |

    すべてを削除するには、これらのフォルダーを削除するか、リポジトリの[reset-linux.sh](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/scripts/reset-linux.sh)スクリプトを実行します。このスクリプトはアプリのフォルダーを消去し、`~/ComfyUI-Installs` と `~/ComfyUI-Shared` はそのまま残します。共有フォルダーは、そのモデルと出力が不要になった場合にのみ削除してください。
  </Tab>
</Tabs>

## トラブルシューティング

セットアップ画面やインストールが想定どおりに進まない場合は、以下の項目を参照してください。

<AccordionGroup>
  <Accordion title="インストールボタンを押しても何も起こらない場合の修正">
    - **ハードウェア**の行に**サポート対象外**と表示される場合: Comfy Cloudを使用してください。[ローカルインストールをスキップしてホームに移動](#ローカルインストールをスキップしてホームへ移動)し、続いて[ログインしてComfy Cloudを開く](#ログインしてcomfy-cloudを開く)を行います。
    - **ComfyUIのダウンロードサーバーに接続できませんでした**と表示される場合: インターネット接続を確認してから、**再試行**をクリックしてください。
    - 利用規約ボックスの横に**インストールに同意します。**と表示される場合: [セットアップ画面の確認](#セットアップ画面を確認する)を参照してください。
  </Accordion>
  <Accordion title="ディスク容量を解放する">
    ドライブの空き容量が不足している場合、**場所**の行に**空き容量が…しかなく、インストールには約…必要です**と表示されます。より容量の大きいドライブに[場所を変更する](#セットアップ画面を確認する)か、このドライブの空き容量を解放してください。
  </Accordion>
  <Accordion title="インストールに失敗したビルドの修正">
    インストールが完了しない場合、**ホーム**のビルドカードに**インストール失敗**と表示されます。

    <Warning>
      アンインストールすると、ビルドとそのすべてのファイルが完全に削除されます。他のビルドには影響しません。保持したいものは、先にビルドのフォルダーからコピーしてください。
    </Warning>

    1. ビルドカードをクリックします。ビルドのページが開きます。
    2. **その他**をクリックし、**アンインストール**を選択します。**アンインストール**で確定します。
    3. **ホーム**で**新規ビルド**をクリックして、新しいビルドをインストールします。
  </Accordion>
  <Accordion title="セットアップを閉じた後の復元">
    セットアップ中にComfyデスクトップを閉じると、**セットアップを終了しますか?**と確認されます。**セットアップを終了**をクリックすると、Comfyデスクトップは選択内容を保存しません。次回Comfyデスクトップを起動したときに、セットアップ画面が再び開きます。
  </Accordion>
  <Accordion title="起動しなかったビルドの修正">
    ComfyUIが起動しない場合、**ホーム**のビルドカードに**起動しませんでした**と表示されます。

    1. ビルドカードをクリックします。**ComfyUIが起動しませんでした**というタイトルのダイアログが開きます。
    2. **ログを表示**をクリックして、何が問題だったかを確認します。
    3. **再試行**をクリックします。
  </Accordion>
  <Accordion title="macOSでComfyデスクトップが壊れた状態で起動する">
    手動更新後、Comfyデスクトップがスタイルなし、テキストの欠落、ボタンを押しても何も起こらないといった状態で開くことがあります。通常、前のバージョンのプロフィールまたはキャッシュされた更新が原因です。

    1. 問題を報告する可能性がある場合は、リセットによってそのフォルダーが削除されるため、`app.log`を`~/Library/Logs/Comfy Desktop`からコピーしておいてください。
    2. Comfyデスクトップを終了します。
    3. [リセットスクリプト](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/scripts/reset-mac.sh)を実行します。削除するすべてのパスが一覧表示され、削除前に確認を求められます:

       ```bash
       curl -fsSLO https://raw.githubusercontent.com/Comfy-Org/Comfy-Desktop/main/scripts/reset-mac.sh && bash reset-mac.sh
       ```

    `~/ComfyUI-Installs`内のビルドと`~/ComfyUI-Shared`内のモデルは残りますが、ビルドの一覧は削除されます。[既存のビルドを追加](/ja/installation/desktop/usage/instance-management#既存のcomfyuiを追加する)で追加し直してください。問題を報告する場合は、[Comfy DesktopのIssueトラッカー](https://github.com/Comfy-Org/Comfy-Desktop/issues)に`app.log`を添付してください。
  </Accordion>
</AccordionGroup>
