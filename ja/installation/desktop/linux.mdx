**Comfyデスクトップ**は、単一のランチャーから複数のComfyUIインスタンスを実行できるマルチインストールマネージャーです。Linux向けビルドは、`.deb`（Debian/Ubuntu）とAppImageとして配布されています。

## システム要件

- **OS:** Debian系Linux（Ubuntu 22.04以降を推奨）
- **アーキテクチャ:** x64
- **GPU:** 専用GPU（NVIDIA / AMD）を推奨しますが、必須ではありません
- **ディスク容量:** インストールごとに少なくとも4.85 GBを推奨

## インストール

### Debian / Ubuntu（`.deb`）

パッケージをダウンロードしたディレクトリで次を実行します:

```bash
sudo apt install ./*.deb
```

次に、アプリケーションメニューから**Comfyデスクトップ**を起動します。

### AppImage

```bash
chmod +x ./*.AppImage
./*.AppImage
```

Chromium がサンドボックスを作成できず AppImage が起動しない場合は、`--no-sandbox` で再試行してください:

```bash
./*.AppImage --no-sandbox
```

<Warning>`--no-sandbox` はすべてのプロセスで Electron のサンドボックスを無効にします。このフラグなしでは起動できない場合にだけ使ってください。よくある AppImage のパッケージ制限であり、推奨の起動方法ではありません。</Warning>

AppImageが起動しない場合は、FUSE 2をインストールしてください:

```bash
sudo apt install libfuse2
```

ソースからビルドすることもできます。[Comfyデスクトップリポジトリ](https://github.com/Comfy-Org/Comfy-Desktop)を参照してください。

## アンインストール

### Comfyデスクトップの削除

- **`.deb`:** システムのパッケージマネージャー（`apt`、`dpkg`、またはデスクトップのソフトウェアセンター）でパッケージを削除します。
- **AppImage:** `.AppImage`ファイルを削除します

### アプリのアンインストールで削除されないもの

Comfyデスクトップのアンインストールでは、ランチャーアプリ自体のみが削除されます。以下のデータは削除されず、完全にクリーンアップするには手動で削除する必要があります:

| データ | デフォルトの場所 | 説明 |
|------|-----------------|-------------|
| インストール | `~/ComfyUI-Installs` | 作成した各ComfyUIインストール（アプリ内からも削除可能）。カスタムインストールパスも削除されません。 |
| 共有モデルと出力 | `~/ComfyUI-Shared` | 共有モデルライブラリ、入力/出力ディレクトリ |
| アプリ設定 | `~/.config/comfyui-desktop-2` | 設定とインストール記録 |
| アプリデータ | `~/.local/share/comfyui-desktop-2` | 永続的なアプリデータ |
| キャッシュ | `~/.cache/comfyui-desktop-2` | ダウンロードキャッシュなどの非必須ファイル |
| 状態 | `~/.local/state/comfyui-desktop-2` | ポートロックなどの実行時状態 |
| ログ | `~/.config/comfyui-desktop-2/logs` | デスクトップアプリのログ（`app.log`） |

すべてを完全に削除するには:

1. **設定フォルダーを削除**: `~/.config/comfyui-desktop-2`
2. **データ、キャッシュ、状態フォルダーを削除**: `~/.local/share/comfyui-desktop-2`、`~/.cache/comfyui-desktop-2`、`~/.local/state/comfyui-desktop-2`
3. **個々のインストールを削除**: アプリ内から削除するか、`~/ComfyUI-Installs` と設定したカスタムインストールディレクトリを手動で削除します
4. **共有モデルライブラリを削除**: `~/ComfyUI-Shared`の共有モデルライブラリを削除（これらのファイルが不要な場合のみ）
