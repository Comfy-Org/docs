**Comfy Desktop** は Linux で動作します。公式の `.deb` パッケージ（Debian/Ubuntu）と AppImage は [Comfy Desktop リポジトリ](https://github.com/Comfy-Org/Comfy-Desktop) を通じて配布されています。[ユニバーサルダウンロードリンク](https://dl.todesktop.com/241130tqe9q3y)（プラットフォームを自動判別）からダウンロードしてください。ほとんどのユーザーはこれらのパッケージの利用を推奨します。ソースから実行したい場合は、リポジトリをクローンして以下の手順に従ってください。

## システム要件

- **OS:** Linux（Ubuntu 22.04 以降を推奨）
- **アーキテクチャ:** x64
- **Node.js:** v22 LTS 以降（ソースビルドのみ）
- **pnpm:** v10 以降、Corepack で有効化（ソースビルドのみ）
- **ビルドツール:** `build-essential` と `git`（ソースビルドのみ）
- **GPU:** 専用 GPU（NVIDIA / AMD）を推奨しますが、必須ではありません
- **ディスク容量:** ComfyUI インストールごとに少なくとも 4.85 GB を推奨

## 公式パッケージのインストール

[ユニバーサルダウンロードリンク](https://dl.todesktop.com/241130tqe9q3y)（プラットフォームを自動判別）から Linux パッケージをダウンロードしてインストールします:

```bash
sudo apt install ./*.deb
```

`.deb` パッケージは Comfy Desktop を `/opt/Comfy Desktop` にインストールし、インストール時に Comfy Desktop のパッケージリポジトリ用の APT ソースも追加するため、以降のリリースはシステムのパッケージマネージャー経由で届きます。詳しくは[アップデート](#更新)を参照してください。

AppArmor が有効で、そのパーサーが同梱プロファイルを受け入れる場合（Ubuntu 24.04 以降。この版では非特権ユーザー名前空間が制限されます）、インストール時にアプリ用の AppArmor プロファイルも `/etc/apparmor.d/comfyui-desktop-2` に配置されます。そのため、これらのシステムでは追加のフラグなしで Electron のサンドボックスが動作します。それより前のディストリビューションでは、AppArmor がプロファイルを読み込めず、もともとサンドボックスが動作するためスキップします。非特権ユーザー名前空間がまったく使えない環境では、代わりに同梱の `chrome-sandbox` が setuid に設定されます。

プロファイルが配置されたか確認するには:

```bash
ls /etc/apparmor.d/comfyui-desktop-2
```

このプロファイルは、パッケージのインストールスクリプトがインストール時とアップグレード時に書き込みます。Ubuntu 22.04 で `.deb` をインストールした後にシステムを 24.04 へアップグレードした場合は、インストールスクリプトをもう一度実行してください:

```bash
sudo apt reinstall comfyui-desktop-2
```

AppImage の場合:

```bash
chmod +x ./*.AppImage
./*.AppImage
```

AppImage はパッケージのインストールスクリプトを実行しないため、AppArmor プロファイルも APT ソースも追加しません。アプリメニューから起動する場合はすでに `--no-sandbox` が付きます。ファイルを直接実行して起動に失敗する場合は、ディストリビューションが Electron のサンドボックスをブロックしている可能性があるため、フラグを付けて起動してください:

```bash
./*.AppImage --no-sandbox
```

このフラグはすべてのプロセスで Electron のサンドボックスを無効にするため、サンドボックス有効の起動が失敗する場合のみ使ってください。

## ソースからビルドして実行

これらの手順は、リポジトリ README の [Development](https://github.com/Comfy-Org/Comfy-Desktop#development) と同じです。

### 前提条件

まずビルドツールと git をインストールします。新規インストールした Ubuntu にはこれらが含まれておらず、`pnpm run init` は `node-pty` などのネイティブモジュールをコンパイルするため、`build-essential` がないと `Error: not found: make` で失敗します:

```bash
sudo apt install build-essential git
```

次に Node.js 22 をインストールし、pnpm を有効にします:

```bash
nvm install 22 && nvm use 22
corepack enable
```

nvm を使わない場合は、[nodejs.org](https://nodejs.org/) から Node.js 22 をインストールしてください。

### クローンとインストール

```bash
git clone https://github.com/Comfy-Org/Comfy-Desktop.git
cd Comfy-Desktop
pnpm run init
```

`pnpm run init` は依存関係をインストールし、同梱の bootstrap Python をビルドします。

### アプリを起動

```bash
./linux-dev.sh
```

開発モードで Comfy Desktop を起動します。スクリプトは `ELECTRON_DISABLE_SANDBOX=1` を設定します。Linux の開発環境では Electron のサンドボックスが失敗しやすいためです。

## 更新

Comfy Desktop の更新方法はインストール方法によって異なります。

### .deb インストール

`.deb` をインストールすると APT ソース（`/etc/apt/sources.list.d/comfyui-desktop-2.sources`）と対応する unattended-upgrades のエントリも追加されるため、新しいリリースは通常のシステム更新で届きます:

```bash
sudo apt update
sudo apt upgrade
```

リリースごとに `.deb` をダウンロードし直す必要はありません。`sudo apt remove comfyui-desktop-2` は APT ソースを残し、`sudo apt purge comfyui-desktop-2` は unattended-upgrades のエントリとともに削除します。

### AppImage

AppImage は自動で更新されます。Comfy Desktop は新しいビルドをダウンロードし、起動した `.AppImage` ファイルを置き換えます。そのため、自分のアカウントで書き込めるフォルダーに置いてください。読み取り専用の場所にあると、更新で置き換えられません。

### ソース実行

ソースチェックアウトにはアプリ内の自動更新はありません。最新コードを pull して再起動します:

```bash
git pull
pnpm run init
./linux-dev.sh
```

## オプション: ローカルパッケージ

自分用の `.deb` または AppImage を作る場合（Comfy Org の公式ダウンロードではありません）:

```bash
pnpm run build:linux
```

成果物は `dist/` に出力されます。AppImage が Chromium のサンドボックス作成に失敗する場合は `--no-sandbox` で再試行してください。このフラグはすべてのプロセスで Electron のサンドボックスを無効にします。

## 残データの削除

アプリの削除とデータの削除は別の作業です。まずアプリをアンインストールします:

- **`.deb`**: `sudo apt remove comfyui-desktop-2`。アンインストール時に `/etc/apparmor.d/comfyui-desktop-2` の AppArmor プロファイルも削除されます。`sudo apt purge comfyui-desktop-2` を使うと APT ソースと unattended-upgrades のエントリも削除されます。
- **AppImage**: `.AppImage` ファイルを削除します。

どちらも ComfyUI のインストールやアプリデータには触れません。完全にクリーンアップしたい場合のみ、次のフォルダーを削除してください:

| データ | デフォルトの場所 | 説明 |
|------|-----------------|-------------|
| インストール | `~/ComfyUI-Installs` | 作成した各ComfyUIインストール（アプリ内からも削除可能）。カスタムインストールパスも削除されません。 |
| 共有モデルと出力 | `~/ComfyUI-Shared` | 共有モデルライブラリ、入力/出力ディレクトリ |
| アプリ設定 | `~/.config/comfyui-desktop-2` | 設定とインストール記録 |
| アプリデータ | `~/.local/share/comfyui-desktop-2` | 永続的なアプリデータ |
| キャッシュ | `~/.cache/comfyui-desktop-2` | ダウンロードキャッシュなどの非必須ファイル |
| 状態 | `~/.local/state/comfyui-desktop-2` | ポートロックなどの実行時状態 |
| ログ | `~/.config/comfyui-desktop-2/logs` | デスクトップアプリのログ（`app.log`） |

すべてを完全に削除するには:

1. **`Comfy-Desktop` のクローンを削除**
2. **設定フォルダーを削除**: `~/.config/comfyui-desktop-2`
3. **データ、キャッシュ、状態フォルダーを削除**: `~/.local/share/comfyui-desktop-2`、`~/.cache/comfyui-desktop-2`、`~/.local/state/comfyui-desktop-2`
4. **個々のインストールを削除**: アプリ内から削除するか、`~/ComfyUI-Installs` と設定したカスタムインストールディレクトリを手動で削除します
5. **共有モデルライブラリを削除**: `~/ComfyUI-Shared`の共有モデルライブラリを削除（これらのファイルが不要な場合のみ）

`.deb` または AppImage でインストールした場合、アプリのプロファイルとログは `~/.config/Comfy Desktop` にも保存されます。リポジトリの [reset-linux.sh](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/scripts/reset-linux.sh) を実行すると、既知のアプリデータをすべて削除できます（`~/ComfyUI-Installs` はそのまま残ります）。
