このページでは、ビルドページの**スナップショット**タブについて説明します。ビルドのインストール、追加、接続については[ビルド](/ja/installation/desktop/usage/instance-management)を参照してください。

## スナップショットの保存と復元

スナップショットは、ビルドのComfyUIバージョン、カスタムノード、Pythonパッケージを記録するため、アップデート後やカスタムノードがビルドを壊した後に元の状態に戻せます。モデル、入力、出力はスナップショットに含まれません。**スナップショット**タブは、インストール済みのStandaloneビルドに表示されます。

![Standalone ビルドの Snapshots タブ。番号付き: 1 Import、2 Export all、3 Create snapshot、4 スナップショットの操作メニュー](/images/desktop/usage/comfy-desktop-snapshots.png)

1. **Import**: ファイルからスナップショットを追加します。
2. **Export all**: すべてのスナップショットをフォルダーに書き出します。
3. **Create snapshot**: いまのビルドの状態を保存します。
4. スナップショットの **More actions**: そのスナップショットで使える操作（復元や削除など）です。

### Comfyデスクトップがスナップショットを保存するタイミング

Comfyデスクトップはスナップショットを自動で保存し、それぞれに保存理由のタグを付けます。

| タグ | 保存されるタイミング |
| --- | --- |
| **起動** | ComfyUIが起動し、最後のスナップショット以降にセットアップが変更されたとき。および初回インストール後に1回 |
| **マネージャー** | ComfyUI ManagerがComfyUIを再起動したとき |
| **更新**, **更新済み** | ComfyUIのアップデートまたはPyTorchの変更の前後 |
| **復元済み** | スナップショットを復元した後 |
| **手動** | **スナップショットを作成**をクリックしたとき |

Comfyデスクトップは**起動**と**マネージャー**のスナップショットを最大200個保持し、それを超えると最も古いものから削除します。ラベルが付いたスナップショットを削除することはありません。

### タイムラインを確認する

**スナップショット**タブでは、スナップショットが新しい順に表示され、**最新:** の下に最後のスナップショットが保存されてからの経過時間が表示されます。最新のスナップショットは自動的に開きます。ほかのスナップショットをクリックすると開き、**このスナップショットの変更内容**をクリックすると、追加、削除、変更されたカスタムノードとパッケージを確認できます。スナップショットにラベルがある場合はラベルが表示され、アップデート後には **v0.42.1 → v0.46.2** のようなバージョン変更が表示されます。

### スナップショットを作成する

新しいカスタムノードなど、リスクのある操作を試す前にスナップショットを保存してください。

1. **スナップショットを作成**をクリックします。
2. **スナップショットを作成**で、必要に応じて `before-experiment` などのラベルを入力します。ラベル付きのスナップショットは、容量を空けるために削除されることはありません。
3. **スナップショットを作成**をクリックします。

### スナップショットを復元する

1. スナップショットの**復元**をクリックします。最新のスナップショットには**復元**がありません。ビルドがすでにそのスナップショットと一致しているためです。
2. **このスナップショットを復元しますか？**で変更内容を確認し、確定します。

Comfyデスクトップは最初にビルドをバックアップします。ビルドが実行中の場合は停止し、スナップショットを復元してから再び起動します。スナップショットが別のPyTorchを使用していた場合、復元によってPyTorchも変更されます。そのPyTorchが利用できない場合、Comfyデスクトップは現在のPyTorchを維持するか、何も変更せずに停止します。

復元が完了すると、ビルドに**スナップショットを復元しました**と表示されます。失敗した場合は、**再試行**または**閉じる**をクリックします。

[クイックアクションメニュー](/ja/installation/desktop/usage/instance-management#ビルドリストからのクイックアクション)からビルドのスナップショットを開くこともできます。**スナップショットを復元**を選択します。

### スナップショットのエクスポート、インポート、削除

- **1つのスナップショットをエクスポート**: スナップショットの**その他のアクション**（**⋯**）をクリックし、**エクスポート**を選択します。タブを開かずに最新のスナップショットをエクスポートするには、クイックアクションメニューまたはビルドページの[**その他**メニュー](/ja/installation/desktop/usage/build-management#その他メニューを使う)で**スナップショットをエクスポート**を選択します。
- **すべてエクスポート**: ビルドのすべてのスナップショットをファイルに保存します。
- **インポート**: スナップショットファイルを選択します。**スナップショットをインポートしますか？**で確認を求められ、その後Comfyデスクトップはビルドをそのスナップショットにすぐに復元します。スナップショットが別のPyTorchを使用している場合、ダイアログに**スナップショットが別のPyTorchを使用しています**と警告が表示されます。
- **削除**: スナップショットの**その他のアクション**（**⋯**）をクリックし、**削除**を選択して確認します。ビルドとそのほかのスナップショットは変更されません。

Comfyデスクトップは、ビルドのスナップショットをビルドのフォルダー内の `.launcher/snapshots` フォルダーに保存します。

### スナップショットファイルからビルドを作成する

スナップショットファイルを使うと、たとえばチームメイトがエクスポートしたファイルなどから、同じComfyUIバージョン、カスタムノード、パッケージの新しいビルドをセットアップできます。

1. **ビルド**ページで、**新規ビルド**の横にある矢印（**その他のビルドオプション**）をクリックし、**スナップショットを読み込む**を選択します。ページに**ビルドをインストールするには、スナップショットファイルを読み込んでください。**と表示されます。
2. `.json` ファイルをページにドロップするか、**ブラウズ**をクリックして選択します。
3. **名前**、**リリース**、**ハードウェア**を確認します。スナップショットが異なるハードウェア向けに作成されている場合、ページに警告が表示されます。
4. **ビルドを作成**をクリックします。

新しいStandaloneビルドがインストールされ、インストールが完了すると起動します。
