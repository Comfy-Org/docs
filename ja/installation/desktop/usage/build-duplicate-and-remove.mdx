このページでは、ビルドの複製、一覧からの削除、アンインストールについて説明します。ビルドのインストール、追加、接続については[ビルド](/ja/installation/desktop/usage/instance-management)を参照してください。

## ビルドを複製する {#duplicate-a-build}

複製とは、オリジナルに影響を与えずに変更できるビルドのコピーです。**Standalone** ビルドまたはチームのワークスペースにある Developer Platform ビルドを複製できます。

1. [クイックアクションメニュー](/ja/installation/desktop/usage/instance-management#ビルドリストからのクイックアクション)または **More** メニューで、**Duplicate** を選択します。
2. **Duplicate build** で、コピーの名前を入力します。
3. **Duplicate** をクリックします。

Comfy Desktop はオリジナルの隣にコピーを作成します。コピーの準備ができると、Comfy Desktop はコピーのビルドページを開きます。ビルドをコピーして一度に変更するには、[ComfyUIをアップデート](/ja/installation/desktop/usage/build-management#comfyuiをアップデート)の **Copy & update**、または [PyTorchを変更](/ja/installation/desktop/usage/build-management#pytorchを変更する)の **Copy & change PyTorch** を使用します。

## ビルドを削除する

ビルドを削除する操作は 2 つあります。**Forget** はファイルをディスクに残します。**Uninstall** はファイルを削除します。

**Forget** は Comfy Desktop からビルドを削除します。フォルダーはコンピューターに残り、[**Add existing build**](/ja/installation/desktop/usage/instance-management#既存のcomfyuiを追加する) で再び追加できます。

1. [ビルドページ](/ja/installation/desktop/usage/instance-management#ビルドの管理) を開き、**More** をクリックします。
2. **Forget** を選択し、**Forget build** で確認します。

リモートビルドの場合、**Forget** は接続を削除します。サーバーは変更されません。Comfy Desktop が Legacy Desktop から作成した **Standalone** ビルドには **Forget** がありません。

**Uninstall** はこのコンピューターからビルドを削除します。リモートビルドの場合、Comfy Desktop からビルドを削除し、サーバーは変更しません。

<Warning>
  **Uninstall** はビルドとそのすべてのファイルを完全に削除し、元に戻すことはできません。他のビルドには影響しません。アンインストールをキャンセルしても、Comfy Desktop がすでに削除したファイルを復元することはできません。
</Warning>

1. ビルドが実行中の場合は停止します。
2. [クイックアクションメニュー](/ja/installation/desktop/usage/instance-management#ビルドリストからのクイックアクション) または **More** メニューで、**Uninstall** を選択します。
3. ダイアログに表示されるフォルダーを確認し、**Uninstall** をクリックします。

ビルドには **Uninstalling** とパーセントが表示されます。完了すると、ビルドは**サイドバー**と **Builds** ページから消えます。

アンインストールを停止するには：

1. クイックアクションメニューで、**Cancel** を選択します。
2. **Stop uninstalling** をクリックします。

ビルドはビルド一覧に残ります。Comfy Desktop がすでに削除したファイルは復元できないため、完了するにはビルドを再度アンインストールします。アンインストールに失敗した場合は、[失敗したビルドを修正する](/ja/installation/desktop/usage/build-troubleshooting#ビルドの失敗を修正する) を参照してください。
