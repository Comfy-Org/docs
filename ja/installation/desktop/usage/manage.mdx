## 管理パネル

管理パネルの内容はインスタンスの種類によって異なります。このページのスクリーンショットは**ローカルスタンドアロンインストール**のものです。クラウドインスタンスとリモートインスタンスでは、タブと設定が少なくなります。

インスタンスの**Manage**を選択すると、設定パネルが開きます。

![ローカルインスタンスの管理パネル: 更新、起動引数、スナップショット、ストレージ、ターミナル、情報](/images/desktop/usage/instance_settings_00.png)

- **Chooser**ビュー（すべてのインスタンスを一覧表示するホーム画面）を開きます
- インスタンスカードの⋮アイコンをクリックします
- コンテキストメニューから**Manage**を選択します

パネルには次の6つのタブがあります。

### 更新タブ

![管理パネルの更新タブ: インストール済みバージョンと最新バージョンを示す ComfyUI 更新カードと、その下の PyTorch パッケージカード](/images/desktop/usage/instance_settings_01_update.png)

このタブには ComfyUI 用と PyTorch 用のカードが 1 枚ずつあります。どちらも同じ構成です。見出しに現在のバージョン、ドロップダウンでチャンネルまたは torch スタックを選び、カードの下のボタンが選択内容に対して動作します。

#### ComfyUI

見出しには ComfyUI のバージョンが表示され、選択中のチャンネルに新しいリリースがない間は **Up to date** バッジが付きます。新しいリリースがあると見出しがそのバージョンに変わり **Update available** バッジが付き、カードに **Installed Version** と **Latest Version** の行が追加されます。**Last checked** は Comfy Desktop が最後に確認してからの経過時間で、ホバーすると正確な日時が表示されます。

- **Update Channel**: **Stable**（テスト済みのリリース、デフォルト）または **Latest on GitHub**（master ブランチの最新コミット）。ドロップダウンでは、インスタンスが現在使用しているチャンネルに **Current** が付きます。
- **Check for updates**: 選択中のチャンネルに新しいリリースがないときに表示され、すぐに再確認します。この確認は Comfy Desktop も自動で実行します。[FAQ](/ja/installation/desktop/faq#一般質問)を参照してください。
- **Update Now**: 選択中のチャンネルに新しいリリースがあるときだけ表示されます。確認ダイアログには切り替える新旧のバージョン（または切り替え先のチャンネル）と、そのチャンネルが公開しているリリースノートが表示され、スナップショットタブを参照するよう案内します。Comfy Desktop は更新前にスナップショットを保存するため、新しいバージョンでカスタムノードが壊れた場合はそこから元の状態に戻せます。
- **Copy & Update**: インスタンスをコピーし、コピーだけを更新します。元のインスタンスは変更されません。既存のノード構成のまま新しいバージョンを試したいときに使います。
- **Switch Channel**: 選択したチャンネルにインストールできる更新がないときに表示され、更新は行わずにインスタンスをそのチャンネルへ切り替えます。

安定版より新しいコミットで動いているインスタンスで **Stable** を選ぶとロールバックになります。確認ダイアログにもその旨が表示され、新しいコミットは削除されます。

#### PyTorch

カードにはインストール済みの torch ビルドが表示され、このインスタンスにインストールできる公式スタックが一覧になります。複数のバックエンドにまたがる場合は、もう 1 つのドロップダウンでバックエンドを先に選びます（**CUDA 13.0**、**CUDA 12.8** などに加えて **ROCm**、**Intel XPU**、**CPU**）。各オプションには torchvision と torchaudio のバージョンが表示され、バンドルとして配布される場合はダウンロードサイズも表示されます。torchaudio を含まないスタックでは警告が出ます。切り替えると torchaudio が削除され、それを必要とするカスタムノードが動作しなくなるためです。

- **Change PyTorch**: このインスタンスを選択したスタックに切り替えます。確認ダイアログにダウンロード内容が表示され、切り替え中は現在の環境がバックアップされ、失敗した場合は自動的に復元されます。
- **Copy & Change PyTorch**: インスタンスの新しいコピーに対して同じ切り替えを行い、元のインスタンスは変更しません。

ナイトリー版は不安定として表示されます。ピッカーに表示されるのは公開日からおよそ 45 日間で、PyTorch がそのナイトリーをインデックスから削除するおよそ 60 日より前に一覧から外れます。

### スタートアップ引数タブ

![インスタンスの起動引数とベータ引数を設定する Manage の起動引数タブ](/images/desktop/usage/instance_settings_02_startup_args.png)

起動時の CLI 引数、マネージャーのポリシー、起動モード、ブラウザキャッシュの共有、ポート競合時の動作、環境変数を設定します。

- **起動引数**: ComfyUI 用のカスタム CLI 引数（例: `--listen`）。歯車アイコンをクリックすると、カテゴリ別のフラグが表示されます。ベータ機能が有効な場合、フィールドの隣に **+N ベータ** ピルが表示され、実行中のセッションで Comfy Desktop が追加したベータ引数、または次回の起動で対象となるベータ引数が一覧されます。
- **マネージャーのセキュリティレベル**: このインスタンスで ComfyUI-Manager がインストールできるノードパックを制御します。次回の起動時に適用されます。
  - **厳格**: すべてのノードパックのインストール、更新、アンインストールをブロックします。マネージャーは読み取り専用になります。
  - **スタンダード（推奨）**: 登録済みのノードパックを許可します。未登録のソース（任意の git URL など）からのインストールはブロックします。
  - **緩和**: スタンダードと同様ですが、ComfyUI がこのマシンからのみ到達可能な場合に限り、未登録ソースからのインストールも許可します。`--listen` を指定すると再びブロックされます。
  - **許可**: すべてのリスク階層を許可します。ComfyUI が `--listen` で公開されている場合でも、インストールには**個人クラウド**ネットワークモードが必要です。
- **マネージャーのネットワークモード**: マネージャーがノードレジストリと通信する方法です。
  - **パブリック（デフォルト）**: パブリックレジストリを使用します。`--listen` を指定すると、すべてのセキュリティレベルでノードパックのインストールがブロックされます。
  - **プライベート**: 自分で設定したプライベートなノードデータベースを使用します。
  - **オフライン**: 外部ネットワークを使用しません。ダウンロードは利用できません。
  - **個人クラウド**: このマシンを信頼できるリモートボックスとして扱い、`--listen` によるインストールのブロックを解除します。選択したセキュリティレベルは引き続き適用されます。自分で管理しているマシンでのみ使用してください。
- **起動モード**: **アプリウィンドウ**（組み込み）または**コンソールのみ**（アプリウィンドウなし。ComfyUI はコンソールプロセスとして実行されます）。
- **ブラウザキャッシュ**: **このインスタンス専用** または **共有**。
- **ポートが使用中の場合**: **動作を確認する**、または**次に利用可能なポートを使用（--port が設定されている場合は確認する）**。
- **環境変数**: **+ 変数を追加**ボタンでカスタム環境変数を追加します。

### スナップショットタブ

![インスタンスのリストアポイントを一覧表示する管理画面のスナップショットタブ](/images/desktop/usage/instance_settings_03_snapshots.png)

スナップショットの表示、インポート、エクスポート、作成ができます。各エントリにはバージョンの変更とパッケージの統計が表示されます。

- **タイムライン**: すべてのスナップショットを時系列で一覧表示し、バージョンの変更と統計を表示します。
- **最新**: 最新のスナップショットが作成された日時を表示します。
- **インポート**: ファイルからスナップショットをインポートします。
- **すべてエクスポート**: すべてのスナップショットをバックアップとしてエクスポートします。
- **スナップショットを作成**: いつでも手動で新しいスナップショットを作成できます。
- 各スナップショットのエントリには以下が表示されます:
  - バージョンの変更 (例: `v0.20.1 → v0.24.1`)
  - パッケージの変更
  - ノードとパッケージの数
  - **エクスポート** と **削除** ボタン

### ストレージタブ

![インスタンスごとのモデルパスと入出力パスを管理するストレージタブ](/images/desktop/usage/instance_settings_04_storage.png)

このインスタンスがグローバル共有フォルダーを使用するかどうかを設定し、このインスタンスにのみ適用される追加のモデルディレクトリを登録します。

- **共有ディレクトリを含める**: このインスタンスが[デスクトップ設定 → ストレージ](/ja/installation/desktop/usage/settings#ストレージ)のグローバル共有モデルディレクトリをスキャンするかどうかを切り替えます。
- **共有入力フォルダーを使用**: 有効にすると、このインスタンスはグローバル共有入力フォルダーから入力ファイルを読み込みます。無効にすると、このインスタンス独自の入力フォルダーを使用します。
- **共有出力フォルダーを使用**: 有効にすると、このインスタンスは生成済みの出力をグローバル共有出力フォルダーに書き込みます。無効にすると、このインスタンス独自の出力フォルダーを使用します。
- **モデルディレクトリ**: このインスタンス専用の追加モデルディレクトリで、共有モデルディレクトリに加えて検索されます。
- **入力ディレクトリ** / **出力ディレクトリ**: 上記の共有トグルがオフのときに使用される、このインスタンス独自のフォルダーです。

### ターミナルタブ

![インスタンスのコンソールを表示している管理パネルのターミナルタブ](/images/desktop/usage/instance_settings_05_console.png)

このインスタンスのフォルダー内で動作するインタラクティブシェルです。ComfyUI が実行中でも停止中でも動作します。

- 起動ログ、エラー、Python の出力を確認するために使用します。
- コピー、貼り付け、すべて選択は OS のショートカットに従います。同じアクションはターミナルを右クリックしても実行できます。

### 情報タブ

![管理パネルの情報タブ: 編集できるインスタンス名、インスタンス情報、インストールパス](/images/desktop/usage/instance_settings_05_about.png)

情報タブには、Comfy Desktop がそのインスタンスについて把握している情報がまとまります。パスをクリックするとファイルマネージャーで開き、横のコピーボタンでそのパスをコピーできます。

情報はグループに分かれ、内容があるグループだけが表示されます。

- **Instance details**: ComfyUI バージョン、ハードウェア、Python と PyTorch のバージョン。リモート接続の場合は、このグループに接続 URL と追加日が入ります。
- **Running details**: ComfyUI が待ち受けているポート。インスタンスの実行中のみ表示されます。
- **Location & storage**: ディスク上のインストールパス全体と、インストールが使用している容量。ファイルがこのマシン上にあるのはローカルインストールだけなので、Cloud とリモート接続にはこのグループがありません。
- **Lineage**: このインスタンスのコピー元と、その日時。**Duplicate Instance**、バージョンや PyTorch を変えたコピー、レガシーデスクトップからの移行、その場での引き継ぎで作成したインスタンスに表示されます。

#### インスタンス名を変更する

![情報タブでインスタンス名と、ホバー時に表示される鉛筆ボタンが強調表示されている様子](/images/desktop/usage/instance_settings_06_rename.png)

情報タブ上部のインスタンス名をクリックし、新しい名前を入力して Enter を押すか別の場所をクリックします。名前の上にマウスを置くと鉛筆ボタンが現れ、クリックすると同じフィールドにカーソルが入ります。Esc を押すと編集を取り消して元の名前のままになり、名前が空の場合や現在と同じ名前の場合も何も変更されません。

管理パネルの **More** メニューにある **Rename** も同じ操作で、**Name** フィールドを持つ **Rename Instance** ダイアログが開きます。

他のインスタンスが使用している名前は拒否され、別の名前を選ぶよう求められます。Comfy Cloud のエントリは名前を保持し、鉛筆ボタンもありません。名前を変更できるのは、ローカル、リモート、トラッキングのインスタンスです。

#### リモート接続の URL を変更する

![リモート接続の情報タブで接続 URL と鉛筆ボタンが強調表示されている様子](/images/desktop/usage/instance_settings_07_remote_url.png)

リモート接続のアドレスは、情報タブの **URL** 行です。URL またはその横の鉛筆ボタンをクリックし、新しいアドレスを入力して Enter を押すか別の場所をクリックします。スキームのないアドレスは `http://` として解釈され、保存時に末尾のスラッシュは削除されます。

インスタンスの接続中に変更した URL は次回の起動時に反映されます。再起動するまでその行には **Restart to apply** が表示され、実行中のセッションは古いアドレスを使い続けます。Comfy Desktop が解釈できないアドレスは保存されず、行は元の値に戻ります。

## インストール操作

インストールカードを右クリック（または ⋮ アイコンをクリック）して操作を実行。詳細は[インスタンス管理](/ja/installation/desktop/usage/instance-management)ページを参照。
