## 管理パネル

管理パネルの内容はインスタンスの種類によって異なります。このページのスクリーンショットは**ローカルスタンドアロンインストール**のものです。クラウドインスタンスとリモートインスタンスでは、タブと設定が少なくなります。

インスタンスで**管理**を選択すると、設定パネルが開きます。

![ローカルインスタンスの管理パネル: 更新、起動引数、スナップショット、ストレージ、ターミナル、情報](/images/desktop/usage/instance_settings_00.png)

- **Chooser**ビュー（すべてのインスタンスを表示するホーム画面）を開きます
- インスタンスカードの ⋮ アイコンをクリックします
- コンテキストメニューから**管理**を選択します

パネルには6つのタブがあります:

### 更新タブ

![管理の更新タブ: ComfyUIバージョン、更新チャンネル、PyTorchパッケージ](/images/desktop/usage/instance_settings_01_update.png)

このタブには現在のバージョンが表示され、アップデートを確認したり、更新チャンネルを設定したりできます。

- **バージョン**: 現在インストール済みのバージョンと、最新かどうかを表示します。
- **最終確認日時**: アップデートを最後に確認した日時を表示します。
- **アップデートを確認**: 新しいバージョンを手動で確認します。
- **更新チャンネル**: ドロップダウンから更新チャンネルを選択します:
  - **安定版**: テスト済みのリリースで、ほとんどのユーザーに推奨されます。デフォルトのオプションです。
  - **GitHubの最新**: masterブランチの最新コミット。### 起動引数タブ

![インスタンスの起動引数とベータ引数に関する、管理パネルの起動引数タブ](/images/desktop/usage/instance_settings_02_startup_args.png)

起動時の CLI 引数、マネージャーポリシー、起動モード、ブラウザキャッシュの共有、ポート競合時の動作、環境変数を設定します。

- **起動引数**: ComfyUI 用のカスタム CLI 引数（例: `--listen`）。歯車アイコンをクリックすると、カテゴリ別に整理されたフラグを確認できます。ベータ機能が有効な場合、フィールドの隣にある **+N beta** ピルに、実行中のセッションで Comfy Desktop が追加したベータ引数、または次回の起動で対象となるベータ引数が一覧表示されます。
- **マネージャーのセキュリティレベル**: このインスタンスに対して ComfyUI-Manager がインストールできるノードパックを制御します。次回起動時に適用されます。
  - **厳格**: すべてのノードパックのインストール、更新、アンインストールをブロックします。マネージャーは読み取り専用になります。
  - **スタンダード（推奨）**: 登録済みのノードパックを許可します。未登録のソース（たとえば任意の git URL）からのインストールはブロックします。
  - **緩和**: スタンダードと同様ですが、ComfyUI がこのマシンからのみ到達可能な場合に限り、未登録ソースからのインストールも許可します。`--listen` を指定すると再びブロックされます。
  - **寛容**: すべてのリスク階層を許可します。ComfyUI が `--listen` で公開されている場合でも、インストールには**個人クラウド**ネットワークモードが必要です。
- **マネージャーのネットワークモード**: マネージャーがノードレジストリと通信する方法。
  - **パブリック（デフォルト）**: パブリックレジストリを使用します。`--listen` を指定すると、すべてのセキュリティレベルでノードパックのインストールがブロックされます。
  - **プライベート**: 自分で設定するプライベートなノードデータベースを使用します。
  - **オフライン**: 外部ネットワークを使用しません。ダウンロードは利用できません。
  - **個人クラウド**: このマシンを信頼されたリモートボックスとして扱い、`--listen` によるインストールブロックを解除します。選択したセキュリティレベルは引き続き適用されます。自分が管理するマシンでのみ使用してください。
- **起動モード**: **アプリウィンドウ**（埋め込み）または**コンソールのみ**（アプリウィンドウなし。ComfyUI はコンソールプロセスとして実行されます）。
- **ブラウザキャッシュ**: **このインスタンス専用**または**共有**。
- **ポートが使用中の場合**: **どうするか確認する**、または**次に使用可能なポートを使用（--port が設定されている場合は確認）**。
- **環境変数**: **+ Add Variable** ボタンでカスタム環境変数を追加します。

![インスタンスの復元ポイントを一覧表示するスナップショットの管理タブ](/images/desktop/usage/instance_settings_03_snapshots.png)

スナップショットの表示、インポート、エクスポート、作成を行えます。各エントリにはバージョンの変更とパッケージの統計が表示されます。

- **タイムライン**: すべてのスナップショットを時系列で一覧表示し、バージョンの変更と統計を表示します。
- **最新**: 最も新しいスナップショットがいつ作成されたかを表示します。
- **インポート**: ファイルからスナップショットをインポートします。
- **すべてエクスポート**: すべてのスナップショットをバックアップとしてエクスポートします。
- **スナップショットを作成**: いつでも手動で新しいスナップショットを作成できます。
- 各スナップショットのエントリには次の情報が表示されます:
  - バージョンの変更（例: `v0.20.1 → v0.24.1`）
  - パッケージの変更
  - ノードとパッケージの数
  - **エクスポート** と **削除** ボタン

</CardGroup>### ストレージタブ

![インスタンスごとのモデルおよびI/Oパスを管理するストレージタブ](/images/desktop/usage/instance_settings_04_storage.png)

このインスタンスがグローバル共有フォルダーを使用するかどうかを設定し、このインスタンスだけに適用される追加のモデルディレクトリを追加します。

- **共有ディレクトリを含める**: このインスタンスが[デスクトップ設定 → ストレージ](/ja/installation/desktop/usage/settings#ストレージ)のグローバル共有モデルディレクトリをスキャンするかどうかを切り替えます。
- **共有入力フォルダーを使用**: 有効にすると、このインスタンスはグローバル共有入力フォルダーから入力ファイルを読み取ります。無効にすると、このインスタンス独自の入力フォルダーを使用します。
- **共有出力フォルダーを使用**: 有効にすると、このインスタンスは生成済みの出力をグローバル共有出力フォルダーに書き込みます。無効にすると、このインスタンス独自の出力フォルダーを使用します。
- **モデルディレクトリ**: このインスタンス専用の追加モデルディレクトリで、共有モデルディレクトリに加えて検索されます。
- **入力ディレクトリ** / **出力ディレクトリ**: 上記の共有トグルがオフの場合に使用される、このインスタンス独自のフォルダーです。### ターミナルタブ

![インスタンスのコンソールを表示する管理パネルのターミナルタブ](/images/desktop/usage/instance_settings_05_console.png)

このインスタンスのフォルダー内で動作する対話型シェルです。ComfyUI の実行中でも停止中でも使用できます。

- 起動ログ、エラー、Python の出力を確認するために使用します。
- コピー、貼り付け、すべて選択は OS のショートカットに従います。ターミナルを右クリックしても同じ操作を行えます。### 情報タブ

![インスタンスのパスとバージョンの詳細を表示する管理の情報タブ](/images/desktop/usage/instance_settings_05_about.png)

インストールの詳細（ComfyUIバージョン、ハードウェア、PythonとPyTorchのバージョン、ディスクパス、使用状況）を確認できます。

- **Current Version**: インストール済みのComfyUIバージョン。
- **Hardware**: 検出されたハードウェア（例: `Apple Silicon (MPS)`）。
- **Python**: 同梱のPythonバージョン。
- **PyTorch**: インストール済みのPyTorchビルド。**Change PyTorch** は、このインストールタイプでテスト済みの公式スタック（CUDA、ROCm、Intel XPU、CPU、または Apple MPS）に切り替えます。その他の環境はそのまま保持されます。ナイトリー版は不安定としてマークされます。
- **Location**: ディスク上の完全なインストールパス。コピーボタンをクリックするとコピーできます。
- **Disk Usage**: インストールが使用するディスク容量。

## インストール操作

インストールカードを右クリック（または ⋮ アイコンをクリック）して操作を実行。詳細は[インスタンス管理](/ja/installation/desktop/usage/instance-management)ページを参照。
