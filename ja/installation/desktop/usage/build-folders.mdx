このページでは、ビルドページの**フォルダー**タブについて説明します。ビルドのインストール、追加、接続については[ビルド](/ja/installation/desktop/usage/instance-management)を参照してください。

## ビルドが使用するフォルダーを選択

ビルドページの**フォルダー**タブでは、ビルドがモデルを探す場所、入力を読み取る場所、出力を保存する場所を設定します。**モデル**、**入力**、**出力**の3つのセクションがあります。デフォルトでは、3つとも**デスクトップ設定**の共有フォルダーを使用します。

![Standalone ビルドの Folders タブ。番号付き: 1 Include shared directories、2 Add models folder、3 Use shared input、4 Use shared output](/images/desktop/usage/comfy-desktop-folders.png)

1. **Include shared directories**: このビルドで共有モデルフォルダーを使うかどうかを切り替えます。
2. **Add models folder**: このビルド専用のフォルダーを追加します。
3. **Use shared input**: 共有 input フォルダーから入力を読み込みます。
4. **Use shared output**: 出力を共有 output フォルダーに保存します。

- **モデル**: **共有ディレクトリを含める**は、このビルドで共有モデルフォルダーを有効または無効にします。一覧には次のものが表示されます。
  - **共有**のタグが付いた共有フォルダー。
  - **ビルド**のタグが付いた、ビルド専用のモデルフォルダー。ビルドは常にこれを使用します。
  - **モデルフォルダーを追加**で、このビルド専用に追加したフォルダー。
  - ビルドに`extra_model_paths.yaml`ファイルがある場合の、**YAML**のタグが付いた行。
- **入力**: **共有入力を使用**がオンの場合、ビルドは共有入力フォルダーから入力を読み取ります。オフにすると、ビルド専用の入力フォルダーを使用します。
- **出力**: **共有出力を使用**がオンの場合、ビルドは共有出力フォルダーに出力を保存します。オフにすると、ビルド専用の出力フォルダーを使用します。

**モデル**一覧では:

- **ダウンロード**のタグが付いたフォルダーが、新しいモデルのダウンロード先になります。
- フォルダーのメニューには、そのフォルダーで許可されているアクション（**モデルのダウンロードに使用**、**フォルダーを変更**、**削除**など）が表示されます。
- 共有フォルダーでは、**デスクトップ設定で共有ディレクトリを管理**を選択すると共有フォルダーを変更できます。

**YAML**の行をクリックすると**カスタムモデルパス**が開きます。これは`extra_model_paths.yaml`が追加するフォルダーの読み取り専用リストです。これらのフォルダーを変更するには:

1. **カスタムモデルパス**で**extra_model_paths.yamlを表示**をクリックして、ファイルの場所を確認します。
2. ファイルを編集して保存します。
3. **ステータスを更新**をクリックします。

変更後、タブには**これらの変更を有効にするには、アプリケーションを再起動してください（または閉じて再度開いてください）。**と表示されます。

### リモートビルドとComfy Cloudビルドの出力オプションを設定する

リモートビルドの**起動引数**タブと、Comfy Cloudビルドの**ストレージ**タブに、次の設定があります。

![Comfy Cloudビルドのフォルダータブ: ブラウザーキャッシュが共有、出力を自動ダウンロードがオン、共有出力ディレクトリを使用がオン、右上にCloudを開く](/images/desktop/usage/comfy-desktop-cloud-storage.png)

- **ブラウザーキャッシュ**: デフォルトでは**共有**、または**このビルド専用**。
- **出力を自動ダウンロード**: デフォルトでオン。各実行の出力をこのコンピューターにダウンロードします。
- **共有出力ディレクトリを使用**: **出力を自動ダウンロード**がオンのときに表示され、出力を共有出力フォルダーに保存します。このビルド用のフォルダーを選択するには、オフにします。
