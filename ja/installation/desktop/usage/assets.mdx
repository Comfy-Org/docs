Comfy Desktop の **アセット** ページには、ビルドや Comfy Cloud が生成したファイル（画像、ビデオ、オーディオ、3D モデル）が表示されます。一度に 1 か所のみ表示され、たとえば Comfy Cloud や 1 つのビルドの出力フォルダーなどです。開くには、**サイドバー** の **アセット** をクリックします。

<Note>
  これは Comfy Desktop 独自のページです。実行中の ComfyUI 内では、**アセット** パネルはそのビルド専用の別のギャラリーです。詳しくは [ComfyUI のアセット](/ja/interface/assets) を参照してください。
</Note>

## 参照する場所を選択する

ページ左上のメニューで、ファイルを表示する場所を選びます。このメニューには 2 つのグループがあります。

- **Comfy Cloud**: Comfy Cloud の出力です。ログインしている必要があります。メニューには、その下にワークスペース名が表示されます。
- **This computer**: ローカルビルドがデフォルトで使用する共有出力フォルダーである **Shared folder** と、それぞれ独自の出力フォルダーに保存する各ローカルビルドです。メニューには各フォルダーのパスが表示されます。場所の横にあるフォルダーボタンをクリックすると、Finder または Explorer で開きます。

アセットには、**サイドバー**で選択したワークスペース内の場所が一覧表示されます。リモートビルドは一覧に表示されません。リモートビルドで**Auto-download outputs**がオンの場合、その出力はダウンロード先のフォルダーの下に表示されます。詳しくは[リモートビルドと Comfy Cloud ビルドの出力オプションを設定する](/ja/installation/desktop/usage/instance-management#リモートビルドと-comfy-cloud-ビルドの出力設定)を参照してください。

## ファイルを探す

- **タイプ**: **すべて**、**画像**、**動画**、**3D**、**オーディオ**。
- **名前で検索…**: 入力した文字を名前に含むファイルを検索します。
- **アセットを更新**: リストを再読み込みします。ビルドで新しいファイルが保存された後にクリックしてください。

Comfy Cloud では、タイプフィルタは現在の並び順で最新 50,000 件の出力をチェックし、その旨がリストの下に表示されます。

## 表示の変更

**表示オプション**をクリックして、以下を設定します。

- **レイアウト**: **Masonry** または**グリッド**。
- **並べ替え条件**: **最新順**または**古い順**。
- **表示**: 各ファイルの下に**ファイル名**と**ファイルの詳細**を表示します。

Comfy Desktop はこれらのオプションを記憶します。ページの下部では、ページ間を移動したり、1ページに表示するファイル数を 50、100、200 から選択したりできます。

## ファイルをプレビュー

ファイルをクリックするとビューアで開きます。ビューアにはファイルが大きく表示され、種類、**作成**日、サイズ、寸法が表示されます。このコンピューター上のファイルの場合は、**保存先**としてフォルダーも表示されます。

- 左右の矢印キーを押すと、前へまたは次のファイルに移動します。
- 画像の場合は、**フィット**またはズームレベルを選択します。
- 100 MBまでの3Dモデルは3Dビューで開きます。より大きいモデルの場合、ビューアには**この3Dモデルは表示できません。ダウンロードして3Dアプリで開いてください。**と表示されます。
- **タグ**にはファイルのタグが表示されます。タグの編集はComfyUIで行います。

## ファイルに対する操作

ファイルにポインタを合わせると主要なアクションが表示されます。その他のアクションは、**その他のアクション** (**⋯**) をクリックするか、ファイルを右クリックすると表示されます。

| アクション | 場所 | 動作 |
| --- | --- | --- |
| **開く** | このコンピューター上の画像、ビデオ、オーディオ | デフォルトのアプリでファイルを開きます。 |
| **Finder で表示**、**エクスプローラーで表示**、または**フォルダーで表示** | このコンピューター上のファイル | ファイルのフォルダーを開きます。名前はお使いのオペレーティングシステムによって異なります。 |
| **ダウンロード** | Comfy Cloud | このコンピューターにコピーを保存します。[Comfy Cloud からのダウンロード](#comfy-cloud-からダウンロード)を参照してください。 |
| **コピー** | 画像 | 画像をクリップボードにコピーします。 |
| **削除** | このコンピューター上のファイル | **{name} を削除しますか?** と確認してから、ファイルをごみ箱に移動します (macOS では Trash、Windows ではごみ箱)。 |

操作できるのは一度に 1 ファイルです。Comfy Cloud のファイルは Comfy Desktop から削除できません。

## ファイルを作成したワークフローを開く

画像、ビデオ、オーディオのファイルにそのファイルを作成したワークフローが含まれている場合、ビューアーに **ワークフローを開く** が表示されます。

- Comfy Cloud のファイルの場合、ワークフローは Comfy Cloud で開きます。
- このコンピューター上のファイルの場合、ワークフローはそのファイルを含むフォルダーを持つビルドで開きます。複数のビルドが同じフォルダーを共有している場合は、**開く場所** でビルドを選択してください。

Comfy Desktop は、ビルドが実行されていない場合はビルドを起動します。ワークフローが開かない場合、ページには **ワークフローを開けませんでした** と表示されます。

## Comfy Cloud からダウンロード

1. 左上のメニューで **Comfy Cloud** を選択します。
2. ファイルにポインタを合わせてから、**ダウンロード** をクリックします。
3. フォルダーを選択します。保存ダイアログは、最後に保存したフォルダー、またはダウンロードフォルダーで開きます。

ダウンロードしたファイルは [ダウンロード](/ja/installation/desktop/usage/downloads) トレイに表示されます。

## ファイルの保存場所

- **このコンピューター**: 出力は共有出力フォルダー、またはビルド独自の出力フォルダーに保存されます。共有フォルダーは[デスクトップ設定](/ja/installation/desktop/usage/settings)で、ビルドのフォルダーは[フォルダータブ](/ja/installation/desktop/usage/instance-management#ビルドが使うフォルダを選択する)で設定します。
- **Comfy Cloud**: 出力はダウンロードするまで Comfy Cloud に残ります。
