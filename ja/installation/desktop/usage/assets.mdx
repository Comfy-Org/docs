Comfy Desktop の **アセット** ページには、ビルドと Comfy Cloud が生成したファイルが表示されます。画像、ビデオ、オーディオ、3D モデルなどです。一度に 1 つの場所（Comfy Cloud、または 1 つのビルドの出力フォルダーなど）のみを表示します。開くには、**サイドバー** で **アセット** をクリックします。

<Note>
  これは Comfy Desktop 独自のページです。実行中の ComfyUI 内では、**アセット** パネルはそのビルド専用の別のギャラリーです。詳しくは [ComfyUI のアセット](/ja/interface/assets) を参照してください。
</Note>

## 参照する場所を選択

ページ左上のメニューで、表示するファイルの場所を選択します。グループは2つあります:

- **Comfy Cloud**: Comfy Cloud の出力。ログインが必要です。メニューにはその下にワークスペース名が表示されます。
- **このコンピューター**: ローカルビルドがデフォルトで使用する共有出力フォルダーである **共有フォルダー** と、独自の出力フォルダーに保存する各ローカルビルド。メニューには各フォルダーのパスが表示されます。場所の横にあるフォルダーボタンをクリックすると、Finder または Explorer で開きます。

アセットには、**サイドバー** で選択したワークスペース内の場所が一覧表示されます。リモートビルドは一覧に表示されません。リモートビルドで **出力の自動ダウンロード** がオンの場合、その出力はダウンロード先のフォルダーの下に表示されます。[リモートビルドと Comfy Cloud ビルドの出力オプションを設定する](/ja/installation/desktop/usage/instance-management#set-output-options-for-remote-and-comfy-cloud-builds)を参照してください。

## ファイルを探す

- **タイプ**: **すべて**、**画像**、**動画**、**3D**、**オーディオ**。
- **名前で検索…**: 入力した文字を名前に含むファイルを検索します。
- **アセットを更新**: リストを再読み込みします。ビルドで新しいファイルが保存された後にクリックしてください。

Comfy Cloud では、タイプフィルタは現在の並び順で最新の 50,000 件の出力を対象にチェックし、その旨がリストの下に表示されます。

## 表示を変更する

**表示オプション**をクリックして、次の項目を設定します。

- **レイアウト**: **メイソンリー**または**グリッド**。
- **並べ替え条件**: **最新順**または**古い順**。
- **表示**: 各ファイルの下に**ファイル名**と**ファイルの詳細**。

Comfy Desktop はこれらのオプションを記憶します。ページの下部でページ間を移動し、1ページに表示するファイル数を50、100、200から選択できます。

## ファイルをプレビュー

ファイルをクリックすると、ビューアーで開きます。ビューアーではファイルが大きく表示され、種類、**作成日**、サイズ、寸法が表示されます。このコンピューター上のファイルの場合、**保存先**としてフォルダーも表示されます。

- 左右の矢印キーを押すと、前へまたは次のファイルに移動します。
- 画像の場合は、**フィット**またはズームレベルを選択します。
- 100 MBまでの3Dモデルは3Dビューで開きます。より大きなモデルの場合、ビューアーには**この3Dモデルは表示できません。ダウンロードして3Dアプリで開いてください。**と表示されます。
- **タグ**にはファイルのタグが表示されます。タグはComfyUIで編集します。

## ファイルに対する操作

ファイルにポインタを合わせると主なアクションが表示されます。それ以外のアクションを表示するには、**その他のアクション**（**⋯**）をクリックするか、ファイルを右クリックします。

| アクション | 表示場所 | 動作 |
| --- | --- | --- |
| **開く** | このコンピューター上の画像、ビデオ、オーディオ | 既定のアプリでファイルを開きます。 |
| **Finderで表示**、**エクスプローラーで表示**、または**フォルダーで表示** | このコンピューター上のファイル | ファイルのフォルダーを開きます。名称はお使いのオペレーティングシステムによって異なります。 |
| **ダウンロード** | Comfy Cloud | このコンピューターにコピーを保存します。詳しくは[Comfy Cloudからのダウンロード](#comfy-cloud-からダウンロード)を参照してください。 |
| **コピー** | 画像 | 画像をクリップボードにコピーします。 |
| **削除** | このコンピューター上のファイル | **{name}を削除しますか?**と確認したうえで、ファイルをゴミ箱に移動します（Windowsではごみ箱 / Recycle Bin）。 |

操作できるのは一度に1つのファイルです。Comfy CloudのファイルをComfy Desktopから削除することはできません。

## ファイルを作成したワークフローを開く

画像、ビデオ、オーディオファイルにそのファイルを作成したワークフローが含まれている場合、ビューアーに **ワークフローを開く** が表示されます。

- Comfy Cloud のファイルの場合、ワークフローは Comfy Cloud で開きます。
- このコンピューター上のファイルの場合、そのファイルが入っているフォルダーを持つビルドでワークフローが開きます。複数のビルドが同じフォルダーを共有している場合は、**Open in** でビルドを選択します。

Comfy Desktop は、ビルドが実行されていなければ起動します。ワークフローが開かない場合、ページには **Couldn't open workflow** と表示されます。

## Comfy Cloud からダウンロード

1. 左上のメニューで **Comfy Cloud** を選択します。
2. ファイルにポインタを合わせ、**ダウンロード**をクリックします。
3. フォルダーを選択します。保存ダイアログは、前回保存したフォルダー、またはダウンロードフォルダーで開きます。

ダウンロードは[ダウンロード](/ja/installation/desktop/usage/downloads)トレイに表示されます。

## ファイルの保存場所

- **このコンピューター**: 出力は共有出力フォルダー、またはビルド独自の出力フォルダーに保存されます。共有フォルダーは[デスクトップ設定](/ja/installation/desktop/usage/settings)で、ビルドのフォルダーはその[フォルダータブ](/ja/installation/desktop/usage/instance-management#choose-which-folders-the-build-uses)で設定します。
- **Comfy Cloud**: 出力はダウンロードするまで Comfy Cloud に残ります。

## トラブルシューティング

<AccordionGroup>
  <Accordion title="アセットがまだない">
    選択した場所にはまだファイルがありません。ビルドでワークフローまたは[アプリ](/ja/installation/desktop/usage/apps)を実行してから、**アセットを更新**をクリックしてください。
  </Accordion>
  <Accordion title="一致するアセットがない">
    種類または検索によってすべてのファイルが非表示になっています。**すべて**を選択するか、**名前で検索…**をクリアしてください。
  </Accordion>
  <Accordion title="アセットを表示するにはログインしてください">
    **Comfy Cloud** が選択されていますが、ログインしていません。**Comfy Cloud にログイン**をクリックしてください。
  </Accordion>
  <Accordion title="このワークスペースには Comfy Cloud ビルドがありません">
    **サイドバー**で選択されているワークスペースには Comfy Cloud ビルドがありません。Comfy Desktop を再起動して Comfy Cloud を追加し直してください。
  </Accordion>
  <Accordion title="アセットを読み込めませんでした">
    Comfy Desktop がリストを読み取れませんでした。Comfy Cloud の場合は、インターネット接続を確認してください。その後、**アセットを更新**をクリックしてください。
  </Accordion>
</AccordionGroup>
