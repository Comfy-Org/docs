このページでは、ビルドが失敗したときに Comfy Desktop が表示するメッセージと、それぞれの対処方法を説明します。ビルドのインストール、追加、接続については[ビルド](/ja/installation/desktop/usage/instance-management)を参照してください。

## ビルドの失敗を修正する

ビルドが失敗すると、Comfy Desktop はいくつかの場所でそれを示します:

- **サイドバー**: 赤い点。ツールチップには、たとえば **クラッシュしました（終了コード 1）** や **起動しませんでした:** とその理由が表示されます。
- **ビルド一覧ページ**: タイル上のステータスチップ（**起動しませんでした**、**クラッシュ**、**エラー** など）。
- **クイックアクションメニュー**: **エラーを表示**。これを選ぶと詳細が開きます。
- **ビルドページ**: 名前の横の赤いチップ。クリックすると詳細が開きます。
- **ホーム**: ビルドカードに **起動しませんでした** と表示されるか、**インストールに失敗しました** や **フォルダーが見つかりません** などビルドの問題が示されます。クラッシュはカードには表示されません。

表示されているメッセージを以下から探してください。

<AccordionGroup>
  <Accordion title="ComfyUIがインストールされなかった">
    インストールが完了する前に停止しました。**ComfyUIをインストール中** ダイアログに **ComfyUIがインストールされませんでした** と表示され、失敗したステップが示されます。ダイアログの **ログを表示** をクリックすると出力を確認できます。

    その後、ビルドには **インストールに失敗しました** と表示されます: **このビルドのインストールは完了しませんでした。アンインストールして再インストールしてください。** ビルドを [**アンインストール**](/ja/installation/desktop/usage/build-duplicate-and-remove#ビルドを削除する) してから、[再度インストール](/ja/installation/desktop/usage/instance-management#新しいビルドをインストール) してください。
  </Accordion>
  <Accordion title="ComfyUIが起動しなかった">
    ビルドの起動に失敗しました。ビルドページに **ComfyUIが起動しませんでした** と理由が表示されます。

    1. ビルドページの **ログを表示** をクリックするか、クイックアクションメニューで **エラーを表示** を選択して、何が問題だったかを確認します。
    2. 原因を修正します。開いたダイアログで **再試行** をクリックします。
  </Accordion>
  <Accordion title="ComfyUIが予期せず終了した">
    ComfyUIが実行中に停止しました。**サイドバー** のツールチップには終了コードまたはシグナルとともに **クラッシュ** と表示され、ビルドページには **ComfyUIが予期せず終了しました** と表示されます。

    - クイックアクションメニューで **エラーを表示** を選択すると、メッセージとComfyUIが出力した最後の行を確認できます。
    - ComfyUIウィンドウで **ComfyUIを再起動** をクリックすると再び起動します。**ホームに戻る** をクリックするとホームに戻ります。

    Windowsでは、クラッシュ時にメモリアクセス違反が報告されることがあります。メッセージにMicrosoft Visual C++ 再頒布可能パッケージの一部のファイルが不足していると思われる旨も含まれている場合は、最新の再頒布可能パッケージを修復またはインストールしてから、ビルドを再起動してください。
  </Accordion>
  <Accordion title="フォルダーが見つからない、またはフォルダーへのアクセスが拒否された">
    Comfy Desktopがビルドのフォルダーにアクセスできません。

    - **フォルダーが見つかりません**: **ビルドフォルダーが見つかりません。ドライブを再接続するかフォルダーを復元してから、再試行してください。**
    - **フォルダーへのアクセスが拒否されました**: **ビルドフォルダーにアクセスできません。読み取り権限があること（またはドライブがオンラインであること）を確認してから、再試行してください。**

    クイックアクションメニューで **エラーを表示** を選択すると、メッセージとフォルダーのパスを確認できます。
  </Accordion>
  <Accordion title="アンインストールが完了しなかった">
    ビルドページに **アンインストールが完了しませんでした** と理由が表示されます。ファイルが使用中の場合、理由にはそのファイルを保持しているプログラム名が示されるか、Comfy Desktopがそれを特定できなかった旨が示されます。そのプログラムを閉じてから、**再試行** をクリックしてください。メッセージを閉じるには **閉じる** をクリックします。

    以前のアンインストールが中断されていた場合、ビルドには **アンインストールが中断されました** と表示されます: **このビルドの以前のアンインストールが中断されました。ビルドを開いてアンインストールを再開するか、再試行してください。** ビルドページを開いてから、もう一度 [アンインストール](/ja/installation/desktop/usage/build-duplicate-and-remove#ビルドを削除する) してください。
  </Accordion>
  <Accordion title="ポートが既に使用中">
    ComfyUIはポートで待ち受けます。ビルドの起動引数で `--port` を設定していない限り `8188` です。他のプログラムがそのポートを使用している場合、何が起こるかは [ウィンドウ、キャッシュ、ポートの設定](/ja/installation/desktop/usage/build-startup-arguments#ウィンドウ、キャッシュ、ポートを設定する) の **ポートがビジーな場合** 設定によって決まります:

    - **次に使用可能なポートを使用（--port が設定されている場合は確認）**: **スタンドアロン** ビルドと **ポータブル** ビルドのデフォルトです。Comfy Desktopは空いている次のポートでビルドを起動し、起動の進行状況にビジー状態のポートと代わりに使用するポートが表示されます。
    - **どうするか確認**: 他のビルドタイプのデフォルトです。

    **ポートがビジーな場合** が **どうするか確認** のとき、起動引数で `--port` が設定されているとき、またはComfy Desktopが空きポートを見つけられないときは、Comfy Desktopは **ポートが既に使用中** ダイアログを開き、そのポートを保持しているプログラム名を表示します。

    <Warning>
      **プロセスを停止して再試行** はもう一方のComfyUIを停止し、その未保存の作業は失われます。
    </Warning>

    - **次に使用可能なポートを使用**: 空いている次のポートでこのビルドを起動します。
    - **プロセスを停止して再試行**: ポートを保持しているプログラムを停止してから、ビルドを再度起動します。このオプションは、そのプログラムがComfyUIらしい場合にのみ表示されます。

    起動をキャンセルするにはダイアログを閉じてください。

    ビルドの起動引数に `--enable-assets` が含まれている場合、Comfy Desktopはそのポートがこの同じビルドを実行している別のComfyUIに保持されていないかも確認します。保持されている場合、両方のComfyUIが同じデータベースを使用することになるため、Comfy Desktopは別のポートを提示しません。先にそのもう一方のコピーを停止するか、それを起動したアプリを閉じてください。
  </Accordion>
  <Accordion title="以前のComfyUIがまだ実行中">
    以前のComfy Desktopセッションが、このビルド用のComfyUIを実行したままにしています。そのComfyUIがビルドのデータベースを保持しているため、このビルド用の新しいComfyUIは起動できません。

    <Warning>
      **停止してこのビルドを起動** は、以前のComfyUIが処理中のプロンプトをキャンセルします。
    </Warning>

    - **ComfyUIがまだプロンプトを実行中**: **停止してこのビルドを起動** をクリックすると停止してプロンプトをキャンセルします。実行を続けたまま、この起動をキャンセルすることもできます。
    - **以前のComfyUIのプロセスがまだ実行中**: メッセージにプロセスIDが一覧表示されます。**それらを停止してこのビルドを起動** をクリックしてください。
    - 以前のComfyUIが終了しない場合は、ご自身でプロセスを終了してから、ビルドを再度起動してください。
  </Accordion>
  <Accordion title="別のComfyUIがこのビルドのデータベースを使用している">
    別のComfyUIがこのビルドのデータベースを使用しているため、このビルドのComfyUIを起動できません。その別のComfyUI、またはそれを起動したアプリを閉じてから、ビルドを再度起動してください。両方を同時に実行するには、`--database-url` 起動引数でいずれか一方に独自のデータベースの場所を指定してください。
  </Accordion>
</AccordionGroup>
