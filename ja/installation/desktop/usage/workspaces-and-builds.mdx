Comfy Desktop は、チームが Comfy Developer Platform 上で共有している ComfyUI セットアップをインストールできます。たとえば、選択したモデルとカスタムノードを含む、承認済みの 1 つのビルドなどです。Developer Platform では、このセットアップはワークスペースが番号付きのバージョンとして公開する Developer Platform Build であり、Comfy Desktop はそのうちの 1 つのバージョンをチームビルドとしてお使いのコンピューターにインストールします。ワークスペースを選択し、そのビルドをインストールし、チームが新しいバージョンを公開したら更新し、自分のビルドを Developer Platform にアップロードします。

Developer Platform で Build を作成し、そのバージョンを公開する方法については、[Comfy Cloud へのカスタムビルドの追加](/ja/development/deploy/cloud-custom-builds)を参照してください。

## ビルドを表示するワークスペースを選択する

各ワークスペースにはそれぞれ独自の Developer Platform Builds があり、Comfy Desktop は一度に 1 つのワークスペースのみを表示します。チームのビルドを表示するには、先にログインしてください。[ログインして Comfy Cloud を開く](/ja/installation/desktop/overview#ログインしてcomfy-cloudを開く) に従ってください。

**サイドバー**の下部で選択済みのワークスペースによって、表示される内容が決まります:

- **ホーム**、**サイドバー**、**ビルド**ページ、および各ビルドページには、そのワークスペースのビルドのみが一覧表示されます。
- **新規ビルド**では、**チームのビルド**の下にそのワークスペースの Developer Platform Builds が表示されます。**個人**ワークスペースには独自のビルドがあります。

ワークスペースを切り替えるには、[ワークスペースメニューを使用する](/ja/installation/desktop/usage/overview#ワークスペースメニューを使用する) を参照してください。Comfy Desktop は選択したワークスペースを記憶し、次回はそのワークスペースで起動します。

<Tip>
  Comfy Desktop を開いている間にチームがビルドを公開した場合は、**ビルド**ページで **ワークスペースを更新** をクリックしてください。ワークスペースとその Developer Platform Builds が再読み込みされます。
</Tip>

## チームのビルドをインストールする

Developer Platform のビルドは、お使いのコンピューターのオペレーティングシステムと GPU 向けのビルドを含むバージョンが公開されると、Comfy Desktop に表示されます。インストールすると、このコンピューターにチームのビルドが追加されます。**New build** ダイアログのうち、すべてのビルドで共通の項目（**Name** や **Location** など）については、[新しいビルドをインストールする](/ja/installation/desktop/usage/instance-management#新しいビルドをインストール)を参照してください。

<Steps>
  <Step title="New build ダイアログを開く">
    **Builds** ページで **New build** をクリックします。

    ログインしている場合、ダイアログはワークスペースのビルドが表示された状態で開き、最初のビルドが選択されています。ワークスペースにインストールできるビルドがない場合は、代わりに **Official release** が表示された状態で開きます。
  </Step>
  <Step title="ビルドとハードウェアを確認する">
    概要には、インストールされる内容が表示されます。

    - **Release**: ビルドの名前と、その説明、**Release v{version}**、**By {creator}**。
    - **Hardware**: お使いのコンピューターのオペレーティングシステムと GPU 向けのビルドターゲット（NVIDIA と CUDA 12.8 など）と、そのリリースバージョン。

    **Name** ボックスにはビルド名の候補が表示されます。
  </Step>
  <Step title="別のビルドを選択する（任意）">
    **Change** をクリックして **Change setup** を開きます。

    - **Source**: **Your team's builds** を選択します。ログインしていない場合はブラウザが開いてログインを求められ、ダイアログには **Continue in your browser** と表示されます。
    - **Release**: ビルドを選択します。リストには、このコンピューターにインストールできるビルドのみが表示されます。**View builds online** をクリックすると、ブラウザで Developer Platform のワークスペースのビルドが開きます。**Refresh builds** をクリックすると、リストが再読み込みされます。
    - **Hardware**: ビルドターゲットを選択します。このコンピューターに推奨されるターゲットが自動的に選択されています。

    Comfy Desktop がワークスペースに切り替わる間、ダイアログには **Waiting for workspace authorization… Complete authorization in your browser if prompted.** と表示されます。

    **Save changes** をクリックすると、概要に戻ります。
  </Step>
  <Step title="ビルドをインストールする">
    **Install** をクリックします。インストールの進行状況を確認するには、[新しいビルドをインストールする](/ja/installation/desktop/usage/instance-management#新しいビルドをインストール)を参照してください。
  </Step>
</Steps>

インストールが完了すると、**Builds** ページのビルドのタイルに、インストールしたバージョンである **Build v{version}** が表示されます。ビルドがリストにない場合は、[トラブルシューティング](#troubleshoot)を参照してください。

## チームビルドを更新する

チームビルドは、そのDeveloper Platform Buildのバージョン間でのみ移動します。チームが新しいバージョンを公開したら、ビルドを更新してそのバージョンを取得します。ビルドページの**概要**タブに**ビルドバージョン**セクションが表示されます。

1. **サイドバー**でチームビルドをクリックして、そのビルドページを開きます。更新が利用可能な場合、**概要**タブにドットが表示され、ビルドのタイルに**更新が利用可能**と表示されます。
2. **概要**で**ビルドバージョン**セクションを確認します。**インストール済み**、**最新公開バージョン**、**最終確認**が表示され、**更新が利用可能**または**最新の状態**のいずれかが示されます。もう一度確認するには、**アップデートを確認**をクリックします。
3. **v{version} に更新**をクリックします。[クイックアクションメニュー](/ja/installation/desktop/usage/instance-management#ビルドリストからのクイックアクション)で**更新**を選択することもできます。
4. **ビルドを更新**ダイアログで、移動するバージョン間を確認し、**今すぐ更新**をクリックします。

更新すると、ビルドの環境が新しいバージョンに置き換えられ、ワークフローと既にステージ済みのモデルは保持されます。実行中は、進行状況が**v{version} に更新中**と表示されます。完了すると、**インストール済み**に新しいバージョンが表示されます。

## ビルドをDeveloper Platformにアップロードする

**ビルドをアップロード**は、このコンピュータ上のビルドからDeveloper Platform Buildを開始します。これにより、ワークスペースから公開できるようになり、チームがインストールできるようになります。ログインしている必要があり、ビルドはこのコンピュータにインストール済みである必要があります。Comfy Cloudとリモートビルドはアップロードできません。

1. **サイドバー**でビルドを右クリックするか、**ビルド**ページのタイル、または**ホーム**のカードを右クリックします。
2. **ビルドをアップロード**を選択します。ヒントには**このビルドをComfy Developer Platformにアップロードします。**と表示されます。

実行中、項目には**作成中…**と表示されます。その後、Comfy Desktopは次の処理を行います。

1. ビルドの手動スナップショットを保存します。これはビルドの**スナップショット**タブに表示されます。[スナップショットの保存と復元](/ja/installation/desktop/usage/instance-management#スナップショットを保存して復元する)を参照してください。
2. スナップショットを下書きとして、ビルドが属するワークスペース内でDeveloper Platformに送信します。**個人**ワークスペース内のビルドは**個人**ワークスペースに送られます。
3. 下書きをブラウザで開きます。ビルドページには**下書き**と**デスクトップスナップショットを受信しました**と表示されます。

下書きは、そのバージョンが公開され、Developer Platform上でのビルドが完了するまで、**チームのビルド**には表示されません。公開するには、[ビルドを公開する](/ja/development/deploy/cloud-custom-builds#ビルドを公開する)を参照してください。

ビルド上で別のタスクが実行中の場合、**ビルドをアップロード**はグレー表示になります。ポインタを合わせると、**このビルドの現在のタスクが完了するまでお待ちください。**と表示されます。

## トラブルシューティング {#troubleshoot}

<AccordionGroup>
  <Accordion title="リリースに「No compatible Builds are available to install」と表示される">
    Comfy Desktop は、Developer Platform Build の最新公開バージョンがビルドを完了しており、このコンピューターのオペレーティングシステムと GPU 向けのビルドが存在する場合にのみ、その Build を一覧に表示します。**サイドバー**で選択済みのワークスペースが、チームが公開先としているワークスペースであることを確認してください。**View builds online** をクリックして Developer Platform 上でビルドを確認し、続いて **Refresh builds** をクリックしてください。
  </Accordion>
  <Accordion title="ダイアログに「Couldn't load builds. Retry」と表示される">
    Comfy Desktop がワークスペースのビルドを読み込めませんでした。**Couldn't load builds. Retry** をクリックすると、再度読み込みます。
  </Accordion>
  <Accordion title="ビルドをアップロードできなかった場合">
    **Could not upload build** アラートに理由が表示されます。たとえば **Could not create a draft in Comfy Developer Platform.** などです。**Upload build** を再度選択してください。
  </Accordion>
</AccordionGroup>
