このページでは、ビルドページの**起動引数**タブについて説明します。ビルドのインストール、追加、接続については[ビルド](/ja/installation/desktop/usage/instance-management)を参照してください。

## 起動引数を設定する

ビルドページの **起動引数** タブでは、このビルドで ComfyUI がどのように起動するかを制御します。コマンドラインフラグ、ComfyUI Manager のポリシー、ウィンドウ、環境などです。

![Standalone ビルドの Startup arguments タブ。番号付き: 1 Startup arguments、2 Manager security level、3 Launch mode、4 Browser cache](/images/desktop/usage/comfy-desktop-startup-arguments.png)

1. **Startup arguments**: ComfyUI の起動時に渡すコマンドライン引数です。
2. **Manager security level**: ComfyUI-Manager がインストールできる範囲です。
3. **Launch mode**: 専用のアプリウィンドウか、コンソールで実行します。
4. **Browser cache**: 他のビルドと共有するか、このビルド専用にします。

変更はすべて、次回のビルド起動時に適用されます。ビルドの実行中にフィールドを変更すると、そのフィールドには **適用するには再起動** と表示され、ヘッダーのボタンには **変更を適用するには再起動** と表示されます。これをクリックすると、新しい設定でビルドが再起動します。

### リストからフラグを選択する

**起動引数** フィールドには、`--listen` など、ComfyUI に渡されるコマンドライン引数が入ります。直接入力することも、カテゴリ別に並んだリストから選択することもできます。ベータ機能によって引数が追加される場合、フィールドの横にある **+N ベータ** ピルにそれらが一覧表示されます。フラグの一覧については、[起動フラグのリファレンス](/ja/development/comfyui-server/startup-flags)を参照してください。

1. **起動引数** の横にある歯車（**引数を設定**）をクリックします。
2. カテゴリ内のフラグを切り替えるか、**生の引数** を編集します。どちらもこのビルドの同じ引数を変更します。
3. **戻る** をクリックしてタブに戻ります。

### ComfyUI Manager がインストールする内容を制御する

2 つの設定で、このビルドに対して ComfyUI Manager がインストールできるノードパックが決まります。まず **マネージャーのセキュリティレベル** を設定します：

- **厳格**: すべてのノードパックのインストール、更新、アンインストールをブロックします。ComfyUI Manager は読み取り専用になります。
- **スタンダード（推奨）**: 登録済みのノードパックを許可し、任意の git URL など、未登録のソースからのインストールをブロックします。これがデフォルトです。
- **緩和**: スタンダードと同様ですが、ComfyUI にこのコンピューターからしかアクセスできない場合に、未登録ソースからのインストールも許可します。`--listen` を指定すると再びブロックされます。
- **寛容**: すべてのリスク階層を許可します。

次に、ComfyUI Manager がノードレジストリにアクセスする方法を決める **マネージャーのネットワークモード** を設定します。

<Warning>
  **個人クラウド** は `--listen` によるインストールブロックを解除します。自分で管理しているコンピューターでのみ選択してください。
</Warning>

- **パブリック（デフォルト）**: パブリックレジストリを使用します。`--listen` を指定すると、すべてのセキュリティレベルでノードパックのインストールがブロックされます。
- **プライベート**: 自分で設定するプライベートなノードデータベースを使用します。
- **オフライン**: 外部ネットワーク接続を行いません。ダウンロードが必要なインストールと更新は利用できません。
- **個人クラウド**: このコンピューターを自分専用の信頼できるリモートマシンとして扱い、`--listen` によるインストールブロックを解除します。セキュリティレベルは引き続き適用されます。

### ウィンドウ、キャッシュ、ポートを設定する

これらの設定は、ビルドの起動方法と、ポートが使用中の場合の動作を決定します。

- **起動モード**: **アプリウィンドウ**（デフォルト）または **コンソールのみ**。
- **ブラウザキャッシュ**: **このビルド専用** または他のビルドと **共有**。新しいスタンドアロンビルドは **このビルド専用** で開始されます。
- **ポートが使用中の場合**: **どうするか確認する** または **次に使用可能なポートを使用する（--port が設定されている場合は確認する）**。スタンドアロンビルドとポータブルビルドはデフォルトで **次に使用可能なポートを使用する（--port が設定されている場合は確認する）** を使用し、git ビルドは **どうするか確認する** を使用します。

### 環境変数を追加する

環境変数は、ビルドの起動時に追加の設定を ComfyUI に渡します。

<Warning>
  Comfyデスクトップは環境変数の値を暗号化せずにディスクに保存します。API キー、トークン、パスワードは追加しないでください。
</Warning>

- **環境変数** の下で **変数を追加** をクリックし、名前と値を入力します。

認証情報のように見える名前（`HF_TOKEN` など）の値は、表示するまで隠されたままです。名前が重複すると **キーが重複しています** と表示されます。
