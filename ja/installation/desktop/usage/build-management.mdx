各ビルドには専用のページがあり、そのページでビルドを管理します。ビルドのインストール、追加、接続については[ビルド](/ja/installation/desktop/usage/instance-management)を参照してください。

ビルドページは次のいずれかの方法で開きます:

- **サイドバー**の**ビルド**で、目的のビルドをクリックします。
- [クイックアクション](/ja/installation/desktop/usage/instance-management#ビルドリストからのクイックアクション)で、**管理**を選択します。

![ComfyUI という Standalone ビルドのページ。番号付き: 1 Overview タブ、2 Folders、3 Startup arguments、4 Snapshots、5 Terminal、6 Start ボタン、7 More ボタン](/images/desktop/usage/comfy-desktop-manage-build.png)

1. **Overview**（概要）
2. **Folders**（フォルダー）
3. **Startup arguments**（起動引数）
4. **Snapshots**（スナップショット）
5. **Terminal**（ターミナル）
6. **Start**: 実行中は **Open** になります。
7. **More**（**⋯**）: ビルド全体の操作。

## ビルドページ

ヘッダーには、そのビルドが何であるかと、実行中かどうかが表示されます。左から右へ：

- **名前**：クリックするか、鉛筆アイコン（**ビルド名を編集**）をクリックすると、ビルドの名前を変更できます。新しい名前を入力して `Enter` を押すか、`Esc` を押すと元の名前のままになります。スタンドアロン、ポータブル、git、リモートのビルドは名前を変更できますが、Comfy Cloud とレガシーデスクトップのビルドは変更できません。各ビルドには、他のどのビルドとも重複しない名前が必要です。
- **ステータスチップ**：**実行中**、**起動中…**、**停止中…**、またはビルドがクラッシュしたか起動しなかった場合の失敗ラベル。失敗ラベルをクリックするとエラーを確認できます。
- **メタ行**：ビルドが動作する場所（**このコンピューター**、**クラウド**、**リモート**）、種類、バージョンがドットで区切られて表示されます。
- **メインボタン**：ローカルビルドが停止しているときは**起動**、実行中は**開く**、Comfy Cloud では**Cloudを開く**、リモートビルドでは**リモートを開く**。
- **その他**（**⋯**）：ビルド全体に対するアクション。[「その他」メニューを使う](#その他メニューを使う)を参照してください。

ヘッダーの下では、各タブが1種類の設定をまとめています。タブは、そのビルドに対応する設定がある場合にのみ表示されます：

| ビルド | タブ |
| --- | --- |
| スタンドアロン | **概要**、**フォルダー**、**起動引数**、**スナップショット**、**ターミナル** |
| リモート | **概要**、**起動引数** |
| Comfy Cloud | **概要**、**ストレージ** |

ポータブルやgitビルドなどその他のローカルビルドでは、対応する設定があるタブに加えて**ターミナル**が表示されます。各タブには対応するセクションがあり、このページまたは「セクション」列に示すページにあります：

| タブ | そこで行うこと | セクション |
| --- | --- | --- |
| **概要** | ビルドが実行する内容の確認、ComfyUIのアップデート、アップデートチャンネルの切り替え、PyTorchの変更、リモートビルドのURLの変更 | [ComfyUIをアップデート](#comfyuiをアップデート) |
| **フォルダー** | モデル、入力、出力フォルダーの選択 | [ビルドが使用するフォルダーを選択する](/ja/installation/desktop/usage/build-folders#ビルドが使用するフォルダーを選択) |
| **起動引数** | フラグ、ComfyUI Managerポリシー、ウィンドウ、ポート、環境変数の設定 | [起動引数を設定する](/ja/installation/desktop/usage/build-startup-arguments#起動引数を設定する) |
| **スナップショット** | ビルドのセットアップの保存と復元 | [スナップショットを保存・復元する](/ja/installation/desktop/usage/build-snapshots#スナップショットの保存と復元) |
| **ターミナル** | ビルドのPython環境でコマンドを実行 | [ターミナルでコマンドを実行する](/ja/installation/desktop/usage/build-terminal#ターミナルでコマンドを実行する) |
| **ストレージ**（Comfy Cloud） | ブラウザーのキャッシュと出力のダウンロード | [出力オプションを設定する](/ja/installation/desktop/usage/build-folders#リモートビルドとcomfy-cloudビルドの出力オプションを設定する) |

## 「その他」メニューを使う

**起動**または**開く**の隣にある**その他**（**⋯**）ボタンには、ビルド全体に対するアクションがまとまっています。スタンドアロンビルドでは、次の項目が表示されます：

- **停止**：ビルドの実行中に表示されます。
- **名前を変更**：ヘッダーの名前が選択状態になります。
- **複製**：[ビルドを複製する](/ja/installation/desktop/usage/build-duplicate-and-remove#duplicate-a-build)を参照してください。
- **Finderに表示**、**エクスプローラーに表示**、**フォルダーに表示**：お使いのオペレーティングシステムに応じた名前になります。
- **スナップショットをエクスポート**：[スナップショット](/ja/installation/desktop/usage/build-snapshots#スナップショットの保存と復元)を参照してください。
- **忘れる** と **アンインストール**：[ビルドを削除する](/ja/installation/desktop/usage/build-duplicate-and-remove#ビルドを削除する)を参照してください。

リモートビルドでは**名前を変更**と**忘れる**が表示され、実行中はさらに**停止**が加わります。Comfy Cloud のビルドでは、**その他**ボタンはグレー表示になります。

## ComfyUIをアップデート

**概要**には、ビルドが実行している内容と、どこでアップデートするかが表示されます。スタンドアロンビルドでは、**ComfyUI** カードとタイルの行が表示されます:

- **PyTorch**: インストール済みのPyTorchバージョン、対象ハードウェア、および **変更** メニュー。[PyTorchの変更](#pytorchを変更する)を参照してください。
- **ディスク上**: ビルドが使用している容量。その下に `{size} free` と表示されます。
- **Python**: Pythonバージョンとビルドの種類。
- 詳細タイル: ビルドの **場所**、フォルダーを開くボタンと **パスをコピー** ボタン、ビルド実行中のポート。別のビルドからコピーしたビルドでは、**コピー元** など、コピー元の情報も表示されます。

その他のビルドでは、**概要**にビルドの情報がグループごとに表示されます: **ビルドの詳細**、**実行時の詳細** (ビルドの実行中)、**場所とストレージ** (ローカルビルドのみ)、**系譜** (別のビルドからコピーしたビルド)。

アップデートすると、ビルドはそのチャンネルの最新のComfyUIになります。**概要**タブのドットは、アップデートが利用可能であることを示します。**ComfyUI** カードの下部にある行に、ビルドの状態が表示されます:

| 行の表示 | 意味 | ボタン |
| --- | --- | --- |
| **{version} が利用可能**、**先にスナップショットを保存 · 確認日時 {time}** | このチャンネルに新しいバージョンがあります。 | **更新** |
| **最新の状態**、**確認日時 {time}** | ビルドはこのチャンネルの最新バージョンです。 | **アップデートを確認** |
| **まだ確認していません** | Comfy Desktopにこのチャンネルのバージョン情報がありません。 | **アップデートを確認** |

ビルドをアップデートするには:

1. **概要**で **更新** をクリックします。[クイックアクションメニュー](/ja/installation/desktop/usage/instance-management#ビルドリストからのクイックアクション)の **更新** を選択することもできます。
2. **ComfyUIをアップデート** ダイアログで、ビルドが移行するバージョンと **リリースノート** を確認し、**今すぐ更新** をクリックします。

更新の実行中は、タブの代わりに進捗カードが表示されます。失敗した場合は、カードに **再試行** と **閉じる** が表示されます。

Comfy Desktopはアップデートの前にスナップショットを保存します。アップデートによってカスタムノードが壊れた場合は、**スナップショット** タブからそのスナップショットを復元してください。[スナップショット](/ja/installation/desktop/usage/build-snapshots#スナップショットの保存と復元)を参照してください。

このビルドに触れずに新しいバージョンを試すには、代わりにコピーをアップデートします:

1. **更新** の横の矢印 (**その他の更新オプション**) をクリックし、**コピーして更新** を選択します。
2. コピーの名前を入力し、**コピーして更新** をクリックします。

### アップデートチャンネルを切り替える

チャンネルは、アップデートの取得元を決定します。

<Warning>
  Stableリリースより先行しているビルドで **Stable** を選択すると、ビルドはロールバックされ、新しいコミットが削除されます。
</Warning>

**ComfyUI** カードでチャンネル名をクリックして **アップデートチャンネル** ドロップダウンを開き、いずれかを選択します:

- **Stable**: テスト済みのリリース。ほとんどのビルドにはこれを使用します。ビルドはデフォルトでこのチャンネルを使用します。
- **Latest on GitHub**: masterブランチの最新のコミット。

ビルドが使用していないチャンネルを選択すると、行には **{channel} に切り替え** と表示されます:

- そのチャンネルに新しいバージョンがある場合は、**更新** をクリックしてビルドをそのチャンネルに移行します。
- 新しいバージョンがない場合は、**チャンネルを切り替え** をクリックして、アップデートせずにビルドを移行します。
- Comfy Desktopにそのチャンネルのバージョン情報がない場合、行には **このチャンネルを選択してアップデートを確認すると、バージョン情報が表示されます。** と表示されます。**アップデートを確認** をクリックします。

### PyTorchを変更する

PyTorchを変更すると、ビルドは別のPyTorchバージョンやバックエンド (より新しいCUDAバージョンなど) を使用できるようになります。**変更** メニューは、Comfy Desktopがビルドにインストールできるバージョンを認識すると、**PyTorch** タイルに表示されます。PyTorchを変更する前に、ビルドの環境全体のコピーを保存できる空き容量がディスクにあることを確認してください。

<Warning>
  torchaudioを含まないバージョンに変更するとtorchaudioが削除され、それに依存しているカスタムノードが動作しなくなります。メニューにはこれらのバージョンが表示されます。
</Warning>

1. **概要**で **PyTorch** タイルの **変更** をクリックします。
2. 目的のバージョンにポインタを合わせます。
3. 次のいずれかを選択します:
   - **PyTorchを変更**: このビルドを変更します。**PyTorchを変更** ダイアログには変更内容と、バンドルの場合はそのダウンロードサイズが表示されます。Comfy Desktopは変更中に現在の環境をバックアップし、失敗した場合は復元します。
   - **PyTorchをコピーして変更**: このビルドのコピーに対して変更を行い、オリジナルはそのまま残します。コピーの名前を入力し、**PyTorchをコピーして変更** をクリックします。

**変更** メニューでは、バージョンはバックエンドごとにグループ化され、インストール済みのバージョンには **使用中** と表示されます。ナイトリー版は **Nightly (unstable)** で終わる見出しの下に配置され、古いナイトリー版はメニューから外れます。

### リモートビルドのURLを変更する

リモートビルドは、URLのComfyUIサーバーに接続します。別のアドレスを指定するには:

1. **概要**の **ビルドの詳細** で **URL** をクリックするか、その横の鉛筆アイコン (**接続URLを編集**) をクリックします。
2. 新しいアドレスを入力し、`Enter` キーを押すか、別の場所をクリックします。

スキームを省略した場合、Comfy Desktopは `http://` を使用します。Comfy Desktopがアドレスを読み取れない場合は、前のアドレスが維持されます。ビルドの接続中は、行に **再起動して適用** と表示され、実行中のセッションは再起動するまで古いアドレスを使い続けます。
