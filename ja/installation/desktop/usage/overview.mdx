Comfy Desktop は **ComfyUI** の公式デスクトップアプリケーションです。ComfyUI のインストール、更新、複数の独立したセットアップの並行管理を一手に引き受けます。

関係を簡単に言うと：**Comfy Desktop** が **ComfyUI** インスタンスを管理・起動するアプリです。ComfyUI を別途インストールする必要はありません。Comfy Desktop が各インスタンスのインストール、Python 環境、依存関係を自動的に処理します。

### 主な特長

- **[マルチインスタンス管理](/ja/installation/desktop/usage/instance-management)**：複数の ComfyUI インスタンスを並行実行。それぞれが独自のバージョン、カスタムノード、設定を持てます
- **[スナップショット](/ja/installation/desktop/usage/manage#スナップショットタブ)**：インスタンスの完全な状態（ComfyUI バージョン、カスタムノード、Python パッケージ）を保存・復元。ロールバックや環境の再現が容易
- **[共有ストレージ](/ja/installation/desktop/usage/settings#ストレージ)**：モデルはデフォルトですべてのインスタンス間で共有され、ディスク容量を節約。外部モデルフォルダの追加も可能
- **自動更新**：タイトルバーの **Desktop Update** で Comfy Desktop を更新します。Manage パネルの[更新タブ](/ja/installation/desktop/usage/manage#更新タブ)で、選択中の ComfyUI インスタンスを更新します。
- **クラウド連携**：Chooser ビューから直接 Comfy Cloud インスタンスを起動・接続
- **[既存インストールの追跡](/ja/installation/desktop/usage/instance-management#既存インストールの追跡)**：既存の portable や git clone の ComfyUI インストールを Comfy Desktop に追加して一元管理

このガイドではこれらの機能の使い方を説明します。

### アプリケーションメニュー

左上のハンバーガーメニュー（☰）からアプリケーションメニューを開きます。アプリレベルの操作はすべてここにあります：

- **Open Dashboard**：Dashboard を新しいウィンドウで開きます。実行中のインスタンスはそのまま動作し続けます。
- **New Instance** と **Add Existing Instance**：新しいインスタンスを作成するか、既存の ComfyUI インストールを登録します。
- **Load Snapshot**：他のユーザーが共有したスナップショットファイルからインスタンスを作成します。
- **Log in**：Comfy アカウントにサインインします。この項目は未サインインのときだけ表示されます。
- **Performance Tests**：インスタンスに対して計測付きのワークフローを実行します。詳しくは[パフォーマンステストとベンチマーク](/ja/installation/desktop/usage/performance-tests)を参照してください。
- **Benchmarks**：保存されたパフォーマンステストの結果を、ハードウェア、ワークフロー、インスタンスごとに比較します。
- **Desktop Settings**：自動更新、プロキシ/ミラー、共有ストレージ、データの保存場所に関するグローバル設定です。
- **Send Feedback**：フィードバックパネルを開きます。
- **Close Window** と **Quit Desktop**：現在のウィンドウを閉じるか、アプリを終了します。インスタンスのウィンドウを閉じるとそのウィンドウが実行している ComfyUI インスタンスが停止し、最後のウィンドウを閉じると Comfy Desktop が終了します。

状況に応じてのみ表示される項目が 2 つあります：ComfyUI ビューがズームされているときの **Reset Zoom (N%)** と、初回セットアップ中の **Skip Onboarding** です。初回セットアップが表示されている間は、**Skip Onboarding** がメニュー内の唯一の項目です。

macOS では、アプリケーションメニューと編集、ウインドウの各メニューを含むシステムメニューバーも維持されます。Windows と Linux のビルドにはシステムメニューバーがありません。

### インスタンス切り替え

中央のピルには、現在アクティブな ComfyUI インスタンスの名前が表示されます。クリックすると**インスタンスピッカー**が開きます。このポップオーバーには、インストール済みのすべてのインスタンスとその実行状態が一覧表示され、インスタンスの切り替えや新規起動ができます。

### 右側のボタン

タイトルバー右側に配置されたボタン群は、次の操作へのクイックアクセスを提供します：

- **Desktop Update**：Comfy Desktop の新しいバージョンが利用可能になると、ここにピルが表示されます。クリックして更新をダウンロードし、適用します。
- **Feedback**：Comfy Desktop チームにフィードバックを送信します。
- **Downloads**：ダウンロードトレイを開き、進行中および最近のダウンロードを確認します。

### 検索ボックス

検索ボックスで、インストール済みインスタンスを名前でフィルタリングできます。インスタンスが多い場合に、目的の設定を簡単に見つけられます。

### Chooser（インスタンス一覧）

ダッシュボードのメインエリアは **Chooser** と呼ばれ、すべての ComfyUI インスタンスがカードとして表示されます。**任意のインスタンスカードをクリックすると、そのインスタンスが起動するか、そのインスタンスに切り替わります。**

ここからは次の操作が可能です：

- **＋ 新しいインスタンス**：新しいスタンドアロンの ComfyUI インスタンスを作成します。
- **Comfy Cloud**：クラウドインスタンスに接続または起動します。無料の Cloud 実行が利用可能な場合、カードに **TRY FREE** ピルが表示されることがあります。
- **アカウントチップ**（右上）：Comfy アカウントでサインインすると、ワークスペース内の ComfyUI Build を閲覧できます。サインイン後、チップはワークスペース切り替えになります。
- **ワークスペースの Build**：サインインすると、ワークスペースに公開された ComfyUI Build がグリッドに表示されます。タイルをクリックするとインストールして起動します。
- **既存のインスタンスカード**：各カードにはインスタンス名、ステータス、タイプが表示されます。右クリック（または ⋮ アイコンをクリック）で、インスタンスの管理、更新、スナップショット、削除が行えます。
