Comfy Desktop は **ComfyUI** の公式デスクトップアプリケーションです。ComfyUI のインストール、更新、複数の独立したセットアップの並行管理を一手に引き受けます。

関係を簡単に言うと：**Comfy Desktop** が **ComfyUI** インスタンスを管理・起動するアプリです。ComfyUI を別途インストールする必要はありません。Comfy Desktop が各インスタンスのインストール、Python 環境、依存関係を自動的に処理します。

### 主な特長

- **[マルチインスタンス管理](/ja/installation/desktop/usage/instance-management)**：複数の ComfyUI インスタンスを並行実行。それぞれが独自のバージョン、カスタムノード、設定を持てます
- **[スナップショット](/ja/installation/desktop/usage/manage#スナップショットタブ)**：インスタンスの完全な状態（ComfyUI バージョン、カスタムノード、Python パッケージ）を保存・復元。ロールバックや環境の再現が容易
- **[共有ストレージ](/ja/installation/desktop/usage/settings#ストレージ)**：モデルはデフォルトですべてのインスタンス間で共有され、ディスク容量を節約。外部モデルフォルダの追加も可能
- **自動更新**：タイトルバーの **Desktop Update** で Comfy Desktop を更新します。Manage パネルの[更新タブ](/ja/installation/desktop/usage/manage#更新タブ)で、選択中の ComfyUI インスタンスを更新します。
- **クラウド連携**：Chooser ビューから直接 Comfy Cloud インスタンスを起動・接続
- **[既存インストールの追跡](/ja/installation/desktop/usage/instance-management#既存インストールの追跡)**：既存の portable や git clone の ComfyUI インストールを Comfy Desktop に追加して一元管理

このガイドではこれらの機能の使い方を説明します。

### アプリケーションメニュー

![タイトルバーから開いたアプリメニュー（Performance Tests、Benchmarks、Desktop Settings を含む）](/images/desktop/usage/comfy_desktop_app_menu.png)

左上のハンバーガーメニュー（☰）からアプリケーションメニューを開きます。アプリレベルの操作はすべてここにあります：

- **Open Dashboard**：Dashboard を新しいウィンドウで開きます。実行中のインスタンスはそのまま動作し続けます。
- **New Instance** と **Add Existing Instance**：新しいインスタンスを作成するか、既存の ComfyUI インストールを登録します。
- **Load Snapshot**：他のユーザーが共有したスナップショットファイルからインスタンスを作成します。
- **Log in**：Comfy アカウントにサインインします。この項目は未サインインのときだけ表示されます。
- **Performance Tests**：インスタンスに対して計測付きのワークフローを実行します。詳しくは[パフォーマンステストとベンチマーク](/ja/installation/desktop/usage/performance-tests)を参照してください。
- **Benchmarks**：保存されたパフォーマンステストの結果を、ハードウェア、ワークフロー、インスタンスごとに比較します。
- **Desktop Settings**：自動更新、プロキシ/ミラー、共有ストレージ、データの保存場所に関するグローバル設定です。
- **Send Feedback**：フィードバックパネルを開きます。
- **Close Window** と **Quit Desktop**：現在のウィンドウを閉じるか、アプリを終了します。インスタンスのウィンドウを閉じるとそのウィンドウが実行している ComfyUI インスタンスが停止し、最後のウィンドウを閉じると Comfy Desktop が終了します。

状況に応じてのみ表示される項目が 2 つあります：ComfyUI ビューがズームされているときの **Reset Zoom (N%)** と、初回セットアップ中の **Skip Onboarding** です。初回セットアップが表示されている間は、**Skip Onboarding** がメニュー内の唯一の項目です。

macOS では、アプリケーションメニューと編集、ウインドウの各メニューを含むシステムメニューバーも維持されます。Windows と Linux のビルドにはシステムメニューバーがありません。

### インスタンス切り替え

中央のピルには、そのウィンドウで実行中の ComfyUI インスタンス名が表示されます。Dashboard では代わりにアプリ名が表示されます。クリックすると**インスタンスピッカー**が開きます。そのインスタンスで新しい ComfyUI バージョンが利用可能な場合は、ピルに **Update** チップも表示されます。チップをクリックすると、そのインスタンスの Update タブでピッカーが開き、更新を確認できる状態になります。

![インスタンスピッカー：(1) ソースの絞り込み、(2) インスタンス一覧、(3) 選択中のインスタンスの設定、(4) New Instance、(5) 選択中のインスタンスに対する主要な操作](/images/desktop/usage/instance_picker_overview.png)

ピッカーは 3 つの領域で構成されています。

- **上部の検索と絞り込み**。検索ボックスはインスタンス名に一致するものを探します。絞り込みチップはソースで一覧を絞ります。**All** は常に表示され、**Local**、**Cloud**、**Remote** はその種類のインスタンスが 1 つ以上ある場合に表示されます。
- **左側のインスタンス一覧**は、最後に起動した順（新しいものが先）に並びます。一度も起動していないインスタンスは最後になります。各行には種類のアイコン、名前、最後に起動した時期が表示され、このウィンドウで実行中のインスタンスには **Current** が付きます。アイコン上のドットが状態を示します。緑は実行中、オレンジは更新あり、回転中のマークは更新やスナップショットの復元などバックグラウンド処理の進行中です。下部の **New Instance** で[New Instance ウィザード](/ja/installation/desktop/usage/instance-management)が開きます。
- **右側には選択中のインスタンスの設定**が、[Manage パネル](/ja/installation/desktop/usage/manage)と同じタブで表示されます。行を選択しても何も起動しません。そのインスタンスの設定がペインに表示されるだけなので、現在のウィンドウを離れずに別のインスタンスの起動引数、ストレージ、スナップショットを変更できます。

ペイン下部の主ボタンは選択中のインスタンスに作用し、ラベルで何が起きるかが分かります。

- **Start**：選択中のローカルインスタンスをこのウィンドウで開きます。Dashboard で表示されるラベルで、その場合インスタンスがウィンドウを引き継ぎます。
- **Restart**：このウィンドウで実行中のインスタンスを再起動します。
- **Switch**：このウィンドウのインスタンスを選択中のものに置き換えます。選択中のインスタンスがすでに別のウィンドウで実行中の場合は、**Switch** はそのウィンドウを前面に表示します。
- **Open in new window**：現在のインスタンスを実行したまま、選択中のインスタンスを別ウィンドウで開きます。主ボタン横のキャレットに、2 つ目のウィンドウを開ける選択肢のときに表示されます。
- **Open Cloud**（リモート接続では **Open Remote**）：選択中の Cloud または Remote インスタンスを開きます。Dashboard ではそのウィンドウを引き継ぎ、インスタンスウィンドウから開く場合はローカルインスタンスを実行したまま新しいウィンドウで開きます。

実行中のローカルインスタンスを再起動するとき、またはそこから切り替えるときは、そのインスタンスが停止するため確認が入ります。**Restart** では、ワークフローの未保存の変更が失われる旨が表示されます。インスタンスウィンドウでの切り替えは 3 択の確認になります。**Switch** は現在のインスタンスを停止して選択中のものをこのウィンドウに読み込み、**Open in new window** は現在のインスタンスを実行したままにし、キャンセルなら何も変わりません。Cloud または Remote インスタンスを表示しているウィンドウでは、ローカルプロセスが止まらないため確認は出ません。すでに別のウィンドウで実行中のインスタンスを前面に出す場合も何も停止しないため、確認は入りません。

ピッカーから開始した操作（更新、複製、スナップショットの復元など）の実行中は、ペインに進捗が表示されます。中断できる操作には **Cancel** も表示されます。失敗した場合は **Try Again** で再試行し、**Dismiss** でエラーを閉じられます。

インスタンスウィンドウでは、ピッカーの絞り込みチップの隣に **Open Dashboard** も表示されます。Dashboard を新しいウィンドウで開き、実行中のインスタンスはそのまま動き続けます。

### 右側のボタン

![タイトルバー右側のボタン：新機能（ベル）、フィードバック、ダウンロード](/images/desktop/usage/title_bar_trailing.png)

タイトルバー右側のコントロールから、次の操作へ素早くアクセスできます：

- **Desktop Update**：Comfy Desktop の新しいバージョンが利用可能になると、ここにピルが表示されます。クリックして更新をダウンロードし、適用します。
- **Reset Zoom**：ComfyUI ビューのズームが 100% 以外のとき、現在のズーム率を示すピルが表示されます。クリックすると 100% に戻ります。
- **What's new**：お知らせパネルを開きます。お知らせでは、ComfyUI の新機能や Comfy 製品のリリースを、短い動画、ハイライト、詳細へのリンクとともに紹介します。未確認のお知らせがあるとベルにドットが表示され、パネルを開くとドットが消えます。
- **Feedback**：Comfy Desktop チームにフィードバックを送信します。
- **Downloads**：ダウンロードトレイを開きます。バッジは実行中のダウンロード数を示し、失敗したダウンロードや未確認のダウンロードを強調します。トレイでは失敗したダウンロードの再試行や、実行中のダウンロードのキャンセルができます。**View All Downloads** で一覧を開くと、一時停止と再開もできます。

### 検索ボックス

検索ボックスで、インストール済みインスタンスを名前でフィルタリングできます。インスタンスが多い場合に、目的の設定を簡単に見つけられます。

### Chooser（インスタンス一覧）

ダッシュボードのメインエリアは **Chooser** と呼ばれ、すべての ComfyUI インスタンスがカードとして表示されます。**任意のインスタンスカードをクリックすると、そのインスタンスが起動するか、そのインスタンスに切り替わります。**

ここからは次の操作が可能です：

- **＋ 新しいインスタンス**：新しいスタンドアロンの ComfyUI インスタンスを作成します。
- **Comfy Cloud**：クラウドインスタンスに接続または起動します。無料の Cloud 実行が利用可能な場合、カードに **TRY FREE** ピルが表示されることがあります。
- **アカウントチップ**（右上）：Comfy アカウントでサインインします。サインインすると、チップにアバターとメールアドレスが表示され、グリッドの上にワークスペース切り替えが表示されます。
- **ワークスペースの Build**：サインインすると、選択したワークスペースに公開された ComfyUI Build を新規インスタンスのフローからインストールできます。詳しくは[ワークスペースと ComfyUI Build](/ja/installation/desktop/usage/workspaces-and-builds)を参照してください。
- **既存のインスタンスカード**：各カードにはインスタンス名、ステータス、タイプが表示されます。右クリック（または ⋮ アイコンをクリック）で、インスタンスの管理、更新、スナップショット、削除が行えます。
