このページでは、Comfy Desktop を初めて起動した後に使う画面を紹介します。**Home**、ガイド付きツアー、**サイドバー**、**タイトルバー**、ワークスペース、**クレジット**です。Comfy Desktop と最初のビルドのインストールについては、[Comfy Desktop](/ja/installation/desktop/overview) を参照してください。

## ホームから始める

**ホーム**は、Comfyデスクトップが起動時に開くページです。**ホーム**から、ワンクリックでComfyUIを開けます。**ホーム**には上から順に次のものが表示されます。

- **ComfyUIを開く**: 右上隅にあるボタンです。ツールチップに表示されているビルドでComfyUIを開きます。ビルドが複数ある場合は、ボタンの横にある矢印をクリックして、開くビルドを選択します。
- **[アプリ](/ja/installation/desktop/usage/apps)**: **アプリ**がオンの場合に表示される、すぐに使えるツールの行です。**すべてのアプリを表示**をクリックすると、**アプリ**ページが開きます。
- **サンプルワークフロー**: **アプリ**がオフの場合、この行には代わりにサンプルのワークフローが表示されます。中央のカードをクリックすると、ブラウザで comfy.org 上のそのページが開きます。
- **[ビルド](/ja/installation/desktop/usage/instance-management)**: 最大3つのビルドが、それぞれカードとして表示されます。カードをクリックするとビルドを起動するか、実行中の場合はそのビルドを開きます。**すべてのビルド**をクリックすると、すべてのビルドが表示されます。ローカルビルドがまだない場合、行の末尾に**新規ビルド**タイルが表示されます。クリックするとビルドを開始できます。

Comfy Cloudのカードは、[ログイン](/ja/installation/desktop/overview#ログインしてcomfy-cloudを開く)するまで**ログインして使用**と表示されます。

![ようこそタイトル、右上隅のComfyUIを開くボタン、See all appsがその下にあるアプリの行、Comfy Cloudカードと新規ビルドタイルがあるビルドの行を表示したComfyデスクトップのホーム](/images/desktop/installation/comfy-desktop-landing-page.png)

ページタイトルが**Welcome. Let's create!**と表示されていれば、**ホーム**にいます。

## ガイドツアーを開始する

**ホーム**を初めて開くと、短いツアーがページの各部分と**サイドバー**を指し示します。ビルドとは何か、Comfy Cloud とローカルビルドのカード、すべてのビルドを表示して新しいビルドを開始する場所、そして**アセット**について説明します。以前にComfyデスクトップを使用したことがある場合、ツアーは**インスタンスはビルドになりました**から始まります。

- 次のステップに進むには**次へ**を、前のステップに戻るには**戻る**を、ツアーを閉じるには**スキップ**をクリックします。`Esc`を押してもスキップできます。

ツアーは**1/6**のような位置を表示し、画面にない部分はスキップします。最後のステップには**戻る**と**完了**だけがあります。ツアーを閉じるには**完了**をクリックします。

![Comfyデスクトップのホームで表示されるガイドツアー。最初のステップがビルド行を指し、ステップのタイトル、説明テキスト、1/N のカウント、スキップと次へボタンが表示されています](/images/desktop/installation/comfy-desktop-guided-tour.png)

### ツアーをもう一度見る

ツアーをもう一度見るには:

1. **タイトルバー**で、ベル（**新着情報**）をクリックします。
2. **ツアーを開始**を選択します。

**ホーム**が開き、ツアーが再び始まります。

## サイドバーの使い方

**Home**ウィンドウの左側にある**サイドバー**を使って、ページ間を移動します。

![Comfyデスクトップのサイドバー上部。ホーム、アプリ、アセット、および緑の点でマークされたComfyUIビルドを含むビルド一覧、そしてComfy Cloudが表示されています](/images/desktop/installation/comfy-desktop-builds-sidebar.png)

各項目をクリックすると、対応するページが開きます:

| 項目 | 開くページ |
| --- | --- |
| **ホーム** | **ホーム**。**サイドバー**を展開しているときは、上部のComfyロゴをクリックしても開きます。 |
| **アプリ** | [**アプリ**](/ja/installation/desktop/usage/apps)ページ。ここでは**アプリを検索**でアプリを検索して開きます。この項目は**アプリ**がオンのときだけ表示されます。 |
| **アセット** | [**アセット**](/ja/installation/desktop/usage/assets)。ビルドやComfy Cloudが生成したものをブラウズできます。 |
| **ビルド** | すべてのビルド。 |

**ビルド**の下に、**サイドバー**が各ビルドを一覧表示します:

- ビルドをクリックすると、そのビルドページが開きます。
- ビルドを右クリックすると、アクションのメニューが表示されます。
- 新しいビルドを開始するには、ポインタを**ビルド**の上に置き、プラス（**+**）ボタン（**新規ビルド**）をクリックします。

ビルドに緑の点が付いている場合は実行中です。赤い点は、クラッシュしたか起動しなかったことを意味します。理由を確認するには、ビルドにポインタを合わせます。

**サイドバー**の下部:

![ログイン時のComfyデスクトップのサイドバー下部: デスクトップ設定、クレジット残高、メニューボタン付きの個人ワークスペース](/images/desktop/installation/comfy-desktop-signed-in-sidebar.png)

- **デスクトップの更新**: Comfyデスクトップの更新が利用可能なときに表示されます。クリックしてから、**ダウンロード**をクリックします。**デスクトップの更新の準備ができました**と表示されたら、クリックしてから**再起動して更新**をクリックします。
- **デスクトップ設定**: Comfyデスクトップの設定を開きます。詳しくは[Comfyデスクトップの設定](/ja/installation/desktop/usage/settings)を参照してください。
- **クレジット**: ログイン後の残高。詳しくは[クレジットを確認する](#クレジットを確認する)を参照してください。
- **Comfyにログイン**: ログインに使用するカード。ログインすると、その場所にワークスペースが表示されます。詳しくは[ログインしてComfy Cloudを開く](/ja/installation/desktop/overview#ログインしてcomfy-cloudを開く)を参照してください。

スペースを確保するには、サイドバー上部の**サイドバーを折りたたむ**をクリックします。各項目はアイコンだけが残り、**Comfyにログイン**カードは**ログイン**アイコンになります。ページを専用のウィンドウで開くには、その項目を右クリックして**新しいウィンドウで開く**を選択します。

## タイトルバーを使用する

**タイトルバー**は、すべてのComfyデスクトップウィンドウの上部に表示されます。

![Comfyデスクトップのタイトルバー右端: 新着情報のベル、ダウンロード、メニュー](/images/desktop/usage/comfy-desktop-title-bar.png)

右側のボタンは、スクリーンショットの番号に対応しています。

- **1** **新着情報**（ベル）: **ツアーを開始**を含むメニューを開きます。[ツアーをもう一度見る](#ツアーをもう一度見る)を参照してください。
- **2** **ダウンロード**: ダウンロードトレイを開きます。バッジには、進行中のダウンロード、失敗したダウンロード、まだ確認していない完了済みのダウンロードの数が表示されます。
- **3** **メニュー**: タイトルバーメニューを開きます。

**ホーム**では、**メニュー**に**パフォーマンステスト**と**ベンチマーク**が含まれます。ComfyUIを実行しているウィンドウでは、**メニュー**に以下も含まれます。

- **デスクトップ設定**: Comfyデスクトップの設定を開きます。
- **ズームをリセット (N%)**: ComfyUIを拡大または縮小したときに表示されます。選択すると100%に戻ります。
- **ウィンドウを閉じる**: このウィンドウを閉じます。
- **デスクトップを終了**: Comfyデスクトップを終了します。

ComfyUIを実行しているウィンドウでは、**タイトルバー**の左側に**ホーム**ボタンも表示されます。クリックすると**ホーム**に戻ります。

初回起動時のセットアップ中は、**メニュー**に**オンボーディングをスキップ**のみが含まれます。

## ワークスペースメニューを使用する

ログインすると Comfy Cloud を利用でき、クレジットが表示されます。ログインするには、[ログインして Comfy Cloud を開く](/ja/installation/desktop/overview#ログインしてcomfy-cloudを開く) に従ってください。

ログインすると、**サイドバー**の下部にある **Log in to Comfy** カードがワークスペースに置き換わります。クリックするとメニューが表示されます。

- 上部のワークスペース名をクリックすると、別のワークスペースに切り替えられます。**Home** と**サイドバー**には、そのワークスペースのビルドが一覧表示されます。
- **ワークスペース設定**と**プランとクレジットを管理**はブラウザで開きます。
- メニューにはメールアドレスと**ログアウト**も表示されます。

## クレジットを確認する

**サイドバー**の下部、ワークスペースの上にある**クレジット**は、残高を表示します。**クレジット**にポインタを合わせると、残高が更新されます。

- クレジットを追加するかプランを変更するには、**クレジット**をクリックします。ブラウザでワークスペースの**プランとクレジットの管理**ページが開きます。

## トラブルシューティング

**ホーム**または**サイドバー**の一部が読み込まれない場合は、以下の項目を参照してください。

<AccordionGroup>
  <Accordion title="サンプルワークフローが読み込まれない">
    **ホーム**に**サンプルワークフローを読み込めませんでした。接続を確認して再試行してください。**と表示されます。インターネット接続を確認してから、**再試行**をクリックしてください。
  </Accordion>
  <Accordion title="アプリが読み込まれない">
    **ホーム**に**アプリを読み込めませんでした。接続を確認して再試行してください。**と表示されます。インターネット接続を確認してから、**再試行**をクリックしてください。
  </Accordion>
  <Accordion title="クレジットに「残高を読み込めません」と表示される">
    Comfyデスクトップが残高を読み取れません。**クレジット**にポインタを合わせると再読み込みされます。
  </Accordion>
</AccordionGroup>
