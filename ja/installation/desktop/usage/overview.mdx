Comfy Desktop は ComfyUI の**ビルド**を管理します。ビルドとは、独自のバージョン、カスタムノード、モデルを持つ 1 つの ComfyUI 環境です。複数のビルドを並べて保持し、どのビルドも 1 つのウィンドウから起動できます。

ComfyUI を自分でインストールする必要はありません。Comfy Desktop が Python 環境の作成、ComfyUI ソースのコピー、各ビルドの更新を行います。

バージョン 1.2 では各環境を**ビルド**と呼びます。このセクションの一部のページでは**インスタンス**と書かれていますが、同じものを指します。

### 主な機能

- **[複数のビルド](/ja/installation/desktop/usage/instance-management)**：各ビルドは独自の ComfyUI バージョン、カスタムノード、設定を持ちます。
- **[スナップショット](/ja/installation/desktop/usage/manage#スナップショットタブ)**：ComfyUI バージョン、カスタムノード、Python パッケージを含むビルドの状態を保存し、復元します。
- **[共有モデル](/ja/installation/desktop/usage/settings#ストレージ)**：モデルフォルダーは既定で共有されるため、1 つのモデルをすべてのビルドで使えます。
- **アップデート**：タイトルバーは Comfy Desktop 自体を更新します。各ビルドはそれぞれの[アップデートタブ](/ja/installation/desktop/usage/manage#更新タブ)から更新します。
- **Comfy Cloud**：ローカルビルドなしで、同じワークフローをクラウドのハードウェアで実行できます。
- **[既存のインストール](/ja/installation/desktop/usage/instance-management)**：すでにあるポータブル版や git クローンした ComfyUI フォルダーを追加できます。

## ウィンドウ

![左にサイドバー、右に 3 つのビルドが並ぶビルドページを表示した Comfy Desktop](/images/desktop/interface/interface_desktop_dashboard.png)

ウィンドウは 2 つに分かれます。左のサイドバーと、それが開く右側のページです。上部のタイトルバーにウィンドウの操作が並びます。

### サイドバー

- **Home**：ランディングページ。ビルドを開き、どのビルドが準備完了かを確認し、サンプルワークフローを閲覧します。
- **Apps**：公開された Comfy アプリ。この行はアプリが有効なときだけ表示されます。
- **Assets**：ビルドが生成した画像、動画、ワークフローを 1 つのライブラリにまとめたもの。
- **Builds**：ビルドの一覧。見出しの横の **+** で新規作成し、各ビルドは行になり、実行中または失敗したときにステータスドットが付きます。
- 下部に **Desktop settings** と Comfy アカウントがあります。サインアウト中は **Log in to Comfy** と表示されます。

### Home

Home は Comfy Desktop を開いたときの最初のページです。挨拶の下に、各ビルドがステータス付きのカードで並び、クリックすると起動します。**All builds** でビルドページに移動し、右上の **Open ComfyUI** は最近使ったビルドを開きます。別のビルドはそのメニューから選べます。カードの上のカルーセルにはサンプルワークフロー、アプリが有効な場合はアプリが並びます。

### ビルド

ビルドページはすべてのビルドをカードで一覧表示し、名前、種類、ステータスを示します。

- **New build** はこのコンピューターに ComfyUI をインストールします。横の矢印から **More build options** が開き、**Add existing build** と **Load snapshot** を選べます。
- **Where it runs** は一覧を All、This computer、Cloud、Remote で絞り込みます。Cloud と Remote は該当するビルドがある場合だけ表示されます。
- **Sort** は **Last used** か **Name** で並べ替え、検索ボックスは名前で絞り込みます。
- カードをクリックするとそのビルドが起動します。カードの **More actions** ボタンまたは右クリックでビルドメニューが開きます。停止中のビルドでは先頭が **Start**、実行中は **View logs**、**Restart**、**Stop** です。その下に **Auto start**、**Manage**、**Update**、**Migrate to Standalone**、**Duplicate**、**Show in Finder**（Windows は **Show in Explorer**、Linux は **Show in folder**）、**Export snapshot**、**Restore snapshot**、**Upload build**、**Uninstall** が並びます。そのビルドに当てはまらない項目は表示されません。

### アプリメニュー

タイトルバー右端の **☰** ボタンでアプリメニューが開きます。項目はウィンドウによって変わります。

- **Home またはビルドページ**：Performance tests と Benchmarks。
- **ビルドウィンドウ**：Performance tests、Benchmarks、Desktop settings、表示がズーム中の Reset zoom (N%)、Close window、Quit Desktop。
- **初回セットアップ中**：Skip onboarding のみ。

ビルドのウィンドウを閉じてもそのビルドは停止しません。最後のウィンドウを閉じると Comfy Desktop が終了しますが、macOS ではローカルビルドが動作している間はアプリが開いたままになります。**Quit Desktop** は実行中のビルドを停止します。

macOS ではアプリ、Edit、Window からなる標準のシステムメニューバーも残ります。Windows と Linux のビルドにはシステムメニューバーがありません。

### タイトルバー

- **Home** はビルドウィンドウから Home に戻ります。
- **Reset zoom (N%)** はビルドの表示が 100% 以外のときに現れ、クリックで戻ります。
- **Refresh** は ComfyUI の表示を再読み込みします。
- **What's new** は短いメニューを開き、**Take the tour** で紹介ツアーを再生できます。
- **Downloads** はダウンロードトレイを開きます。バッジは実行中の件数を示し、失敗または未確認のダウンロードを強調します。詳しくは[ダウンロード](/ja/installation/desktop/usage/downloads)を参照してください。
