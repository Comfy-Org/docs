このページでは、初回起動後に Comfy Desktop で使用する画面を紹介します。**ホーム**、ガイドツアー、**サイドバー**、**タイトルバー**、ワークスペース、**クレジット**です。Comfy Desktop と最初のビルドのインストール方法については、[Comfy Desktop](/ja/installation/desktop/overview) を参照してください。

## ホームから始める

**ホーム**はComfyデスクトップが起動時に開くページです。**ホーム**から、ワンクリックでComfyUIを開けます。**ホーム**には上から順に次のものが表示されます:

- **ComfyUIを開く**: 右上隅のボタンです。ツールチップに表示されたビルドでComfyUIを開きます。ビルドが複数ある場合は、隣の矢印をクリックして開くビルドを選択します。
- **[アプリ](/ja/installation/desktop/usage/apps)**: **アプリ**が有効な場合に表示される、すぐに使えるツールの行です。**すべてのアプリを見る**をクリックすると**アプリ**ページが開きます。
- **サンプルワークフロー**: **アプリ**が有効でない場合、この行には代わりにサンプルのワークフローが表示されます。中央のカードをクリックすると、ブラウザでcomfy.org上のそのページが開きます。
- **[ビルド](/ja/installation/desktop/usage/instance-management)**: 最大3つのビルドがそれぞれカードとして表示されます。カードをクリックするとビルドを起動するか、実行中のビルドを開きます。**すべてのビルド**をクリックするとすべてのビルドが表示されます。ローカルビルドがまだない場合、行の最後に**新規ビルド**のタイルが表示されます。クリックするとビルドを開始できます。

Comfy Cloudのカードは、[ログイン](/ja/installation/desktop/overview#ログインしてcomfy-cloudを開く)するまで**使用するにはログイン**と表示されます。

![ようこそタイトル、右上隅のComfyUIを開くボタン、その下に「すべてのアプリを見る」があるアプリの行、Comfy Cloudカードと新規ビルドタイルがあるビルドの行を備えたComfyデスクトップのホーム](/images/desktop/installation/comfy-desktop-landing-page.png)

ページタイトルが**ようこそ。作成を始めましょう！**と表示されていれば、**ホーム**にいます。

## ガイドツアーを見る

**ホーム**が初めて開かれると、ページの各部位と**サイドバー**を指し示す短いツアーが表示されます。ビルドとは何か、Comfy Cloud とローカルビルドのカード、すべてのビルドを確認して新しいビルドを開始する場所、そして**アセット**について説明します。以前に Comfy デスクトップを使用したことがある場合、ツアーは **インスタンスはビルドになりました** から始まります。

- **次へ**をクリックすると次のステップに進み、**戻る**で前のステップに戻り、**スキップ**でツアーを閉じます。`Esc` キーを押してもスキップできます。

ツアーには **1 of 6** のような位置が表示され、画面に表示されていない部分はスキップされます。最後のステップには**戻る**と**完了**だけが表示されます。**完了**をクリックするとツアーが閉じます。

![Comfy デスクトップのホームで表示されるガイドツアー。最初のステップがビルド行を指し示し、ステップのタイトル、説明テキスト、1 of N のカウント、スキップと次へボタンが表示されている](/images/desktop/installation/comfy-desktop-guided-tour.png)

### ツアーを再表示する

ツアーをもう一度見るには:

1. **タイトルバー**でベル（**新着情報**）をクリックします。
2. **ツアーを開始**を選択します。

**ホーム**が開き、ツアーが再び開始されます。

## サイドバーの構成

**ホーム**ウィンドウの左側にある**サイドバー**は、ページを切り替えるためのものです。

![ホーム、アプリ、アセット、緑のドットで示されたComfyUIビルドを含むビルドリスト、Comfy Cloudが表示されたComfyデスクトップのサイドバー上部](/images/desktop/installation/comfy-desktop-builds-sidebar.png)

各項目から次のページを開けます:

| 項目 | 開くページ |
| --- | --- |
| **ホーム** | **ホーム**。**サイドバー**が展開されているときは、上部のComfyロゴをクリックしても開きます。 |
| **アプリ** | [**アプリ**](/ja/installation/desktop/usage/apps)ページ。**アプリを検索**でアプリを探して開きます。この項目は、**アプリ**が有効になっている場合にのみ表示されます。 |
| **アセット** | [**アセット**](/ja/installation/desktop/usage/assets)。ビルドとComfy Cloudが生成したものをブラウズできます。 |
| **ビルド** | すべてのビルド。 |

**ビルド**の下には、**サイドバー**に各ビルドが一覧表示されます:

- ビルドをクリックすると、そのビルドページが開きます。
- ビルドを右クリックすると、アクションのメニューが表示されます。
- 新しいビルドを開始するには、**ビルド**にポインタを合わせ、プラス（**+**）ボタン（**新規ビルド**）をクリックします。

ビルドに付いた緑のドットは、そのビルドが実行中であることを示します。赤のドットは、クラッシュしたか起動しなかったことを示します。理由を確認するには、ビルドにポインタを合わせてください。

**サイドバー**の下部:

![ログイン時のComfyデスクトップのサイドバー下部: デスクトップ設定、クレジット残高、メニューボタン付きの個人ワークスペース](/images/desktop/installation/comfy-desktop-signed-in-sidebar.png)

- **デスクトップの更新**: Comfyデスクトップの更新が利用可能になると表示されます。これをクリックし、次に**ダウンロード**をクリックします。**デスクトップの更新準備完了**と表示されたら、これをクリックし、次に**再起動して更新**をクリックします。
- **デスクトップ設定**: Comfyデスクトップの設定を開きます。[Comfyデスクトップの設定](/ja/installation/desktop/usage/settings)を参照してください。
- **クレジット**: ログイン後の残高です。[クレジットを確認する](#クレジットを確認する)を参照してください。
- **Comfyにログイン**: ログインに使用するカードです。ログインすると、そのカードの場所にワークスペースが表示されます。[ログインしてComfy Cloudを開く](/ja/installation/desktop/overview#ログインしてcomfy-cloudを開く)を参照してください。

場所を空けるには、サイドバー上部の**サイドバーを折りたたむ**をクリックします。各項目はアイコンのみになり、**Comfyにログイン**カードは**ログイン**アイコンになります。ページを専用のウィンドウで開くには、その項目を右クリックし、**新しいウィンドウで開く**を選択します。

## タイトルバーを使用する

**タイトルバー**は、すべてのComfyデスクトップウィンドウの上部に沿って表示されます。

![Comfyデスクトップのタイトルバーの右端: 新着情報のベル、ダウンロード、メニュー](/images/desktop/usage/comfy-desktop-title-bar.png)

右側のボタンは次のとおりです:

- **新着情報**（ベル）: **ツアーを開始**を含むメニューを開きます。詳細は[ツアーを再実行](#ツアーを再表示する)を参照してください。
- **ダウンロード**: ダウンロードトレイを開きます。バッジには、進行中のダウンロード、失敗したダウンロード、まだ確認していない完了済みのダウンロードが表示されます。
- **メニュー**: タイトルバーのメニューを開きます。

**ホーム**では、**メニュー**に**パフォーマンステスト**と**ベンチマーク**が含まれます。ComfyUIを実行しているウィンドウでは、**メニュー**にはさらに次の項目が含まれます:

- **デスクトップ設定**: Comfyデスクトップの設定を開きます。
- **ズームをリセット（N%）**: ComfyUIを拡大または縮小すると表示されます。選択すると100%に戻ります。
- **ウィンドウを閉じる**: このウィンドウを閉じます。
- **デスクトップを終了**: Comfyデスクトップを終了します。

ComfyUIを実行しているウィンドウには、**タイトルバー**の左側に**ホーム**ボタンもあります。クリックすると**ホーム**に戻ります。

初回起動時のセットアップ中は、**メニュー**には**オンボーディングをスキップ**のみが含まれます。

## ワークスペースメニューを使用する

ログインすると Comfy Cloud を利用でき、クレジットが表示されます。ログインするには、[ログインして Comfy Cloud を開く](/ja/installation/desktop/overview#ログインしてcomfy-cloudを開く) に従ってください。

ログインすると、**サイドバー**の下部にある **Comfy にログイン** カードがワークスペースに置き換わります。クリックするとメニューが表示されます:

- 上部のワークスペース名をクリックすると、別のワークスペースに切り替えられます。**ホーム**と**サイドバー**には、そのワークスペースのビルドが一覧表示されます。
- **ワークスペース設定**と**プランとクレジットを管理**はブラウザで開きます。
- メニューにはメールアドレスと**ログアウト**も表示されます。

## クレジットを確認する

**サイドバー**の下部、ワークスペースの上にある**クレジット**に残高が表示されます。**クレジット**にポインタを合わせると残高が更新されます。

- クレジットを追加する、またはプランを変更するには、**クレジット**をクリックします。ワークスペースの**プランとクレジットを管理**ページがブラウザで開きます。

## トラブルシューティング {#troubleshoot}

**ホーム**または**サイドバー**の一部が読み込まれない場合は、以下の項目を参照してください。

<AccordionGroup>
  <Accordion title="サンプルワークフローが読み込まれない">
    **ホーム**に**サンプルワークフローを読み込めませんでした。接続を確認して、もう一度お試しください。**と表示されます。インターネット接続を確認してから、**再試行**をクリックしてください。
  </Accordion>
  <Accordion title="アプリが読み込まれない">
    **ホーム**に**アプリを読み込めませんでした。接続を確認して、もう一度お試しください。**と表示されます。インターネット接続を確認してから、**再試行**をクリックしてください。
  </Accordion>
  <Accordion title="クレジットに「残高を読み込めません」と表示される">
    Comfyデスクトップは残高を読み取れません。**クレジット**にポインタを合わせると、再度読み込まれます。
  </Accordion>
</AccordionGroup>

Comfyデスクトップの問題は[GitHub](https://github.com/Comfy-Org/Comfy-Desktop/issues)で報告してください。このドキュメントの問題は[ドキュメントリポジトリ](https://github.com/Comfy-Org/docs/issues)で報告してください。
