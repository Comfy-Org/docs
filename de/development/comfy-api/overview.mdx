Die öffentliche API zum Ausführen von ComfyUI ohne UI hat sich im Laufe der Zeit weiterentwickelt. Für neue Integrationen verwenden Sie [Comfy API v2](/api-reference/v2/overview). Sie wird im Open-Source-ComfyUI über den [API Proxy](/de/development/comfyui-server/api-proxy), in Comfy Cloud und in [Comfy API-Bereitstellungen auf der Developer Platform](/de/development/serverless/overview) unterstützt. Zu den älteren Versionen gehört die [v1 Cloud API](/de/development/cloud/overview), die veraltet ist.
