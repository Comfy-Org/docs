ComfyUI ist eine modulare GenAI-Inferenz-Engine, die als Server betrieben, über die API angesprochen, mit Custom Nodes erweitert und über die Befehlszeile verwaltet werden kann. Die meisten API-Aufgaben folgen zwei Schritten: ComfyUI irgendwo zum Laufen bringen und dann aus Ihrer Anwendung heraus Workflows darauf ausführen.
