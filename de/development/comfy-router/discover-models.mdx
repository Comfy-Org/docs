Jedes Router-Modell wird über eine ID der Form `{provider}/{model}` adressiert. Suchen Sie diese ID im Katalog und rufen Sie dann `POST /v2/models/{provider}/{model}` auf.

## Katalog entdecken

Listen Sie Modelle mit demselben API-Schlüssel auf, der auch für die Generierung verwendet wird:

```bash
curl -H "X-API-Key: $COMFY_API_KEY" \
  "https://api.comfy.org/v2/models?limit=50"
```

Eine verkürzte Katalogantwort:

```json
{
  "data": [
    {
      "id": "bfl/flux-2-pro",
      "provider": "bfl",
      "model": "flux-2-pro",
      "billing": { "charges_on_policy_rejection": "no" }
    }
  ],
  "has_more": true,
  "next_cursor": "example-cursor",
  "limit": 50
}
```

Verwenden Sie `id` im Aufrufpfad. Das Objekt `billing` enthält Abrechnungsfakten, keinen Preis. Lesen Sie [Abrechnung bei Policy-Ablehnung](/de/development/comfy-router/billing#model-billing-facts), bevor Sie sich darauf verlassen.

### Paginierung

- Wenn `has_more` gleich `true` ist, übergeben Sie den zurückgegebenen `next_cursor` als `cursor`. Hören Sie auf, wenn `has_more` gleich `false` ist, auch wenn eine frühere Seite kürzer war als angefordert.
- Behandeln Sie Cursor als undurchsichtige Werte. Kodieren Sie den Wert für die URL, zum Beispiel mit cURL `--get --data-urlencode "cursor=$NEXT_CURSOR"`; berechnen Sie keine Offsets und verändern Sie den Cursor nicht.
- `limit` ist standardmäßig 20 und ist auf 100 begrenzt. Werte über der Obergrenze werden gekappt; null und negative Werte wählen den Standardwert. Die Antwort meldet das tatsächlich verwendete Limit.
- Ein ungültiger Cursor gibt `400` / `invalid_input` zurück. Die Liste wird dabei nicht stillschweigend neu gestartet.
- Ein Cursor kann über Katalogaktualisierungen hinweg gültig bleiben, aber der Durchlauf ist keine Momentaufnahme: Ein Modell, das vor Ihrer aktuellen Position hinzugefügt wurde, erscheint in diesem Durchlauf möglicherweise nicht.

`503` / `service_unavailable` ist vorübergehend. Versuchen Sie es mit Backoff erneut; behandeln Sie die Antwort nicht als leeren Katalog. Die run-Methoden des SDK rufen das ausgewählte Modell direkt auf.

## Einzelnes Modell abrufen

Rufen Sie einen Katalogeintrag direkt ab, wenn Sie die Modell-ID kennen:

```bash
curl -H "X-API-Key: $COMFY_API_KEY" \
  https://api.comfy.org/v2/models/bfl/flux-2-pro
```

Der Endpunkt für Modelldetails vermeidet das Durchlaufen des gesamten Katalogs. Die vollständigen Felder eines Eintrags finden Sie in der [API-Referenz](/de/development/comfy-router/reference).
