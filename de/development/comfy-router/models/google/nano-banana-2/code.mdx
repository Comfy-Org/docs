## Anbieter für die Bereitstellung

Dieses Modell wird direkt von Comfy Router bereitgestellt, sofern die Anfrage keinen anderen Anbieter nennt. Die folgenden Anbieter stellen es ebenfalls bereit, am selben Endpunkt und mit derselben Modell-ID, ausgewählt über den Query-Parameter `model_provider`.

- **Comfy** (Standard): `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image`
- **fal**, als `fal/fal-nano-banana-2`: `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image?model_provider=fal`
- **MiniMax**, als `minimax/minimax-nano-banana-2`: `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image?model_provider=minimax`
- **Pika**, als `pika/pika-nano-banana-2`: `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image?model_provider=pika`
- **Runware**, als `runware/runware-nano-banana-2`: `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image?model_provider=runware`
- **WaveSpeed**, als `wavespeed/wavespeed-nano-banana-2`: `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image?model_provider=wavespeed`

`strict_mode` ist standardmäßig false, daher übersetzt Router den auf dieser Seite dokumentierten nativen Request-Body in das eigene Schema des Anbieters und übersetzt anschließend die Antwort zurück. Siehe [`model_provider`, `strict_mode` und `fallback_provider`](/de/development/comfy-router/reference#post-v2modelsprovidermodel) in der API-Referenz und [Anbieter für die Bereitstellung](/de/development/comfy-router/providers) für jedes Modell, das auf diese Weise geroutet wird.

### Ausgaben

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [
          {
            "inlineData": {
              "mimeType": "image/png",
              "data": "PGJhc2U2ND4="
            }
          }
        ]
      },
      "finishReason": "STOP"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 12,
    "candidatesTokenCount": 1290
  }
}
```

Standardmäßig enthalten generierte Bildteile Base64-Bytes in `inlineData.data` und einen Medientyp in `inlineData.mimeType`. Dekodieren Sie die Bytes und speichern Sie sie in einer Datei. Mit `uploadImagesToStorage: true` verwenden hochgeladene Bilder stattdessen `fileData.fileUri` für eine signierte URL und `fileData.mimeType` für den Medientyp. Laden Sie diese Bilder herunter, bevor die URLs ablaufen, 24 Stunden nach ihrer Erstellung. Ein Fehler beim Hochladen belässt dieses Bild inline, daher sollten Sie jeden Teil auf `inlineData` oder `fileData` prüfen. Textteile können ebenfalls auftreten, und es ist nicht garantiert, dass das Bild der erste Teil ist. Der Pfad `candidates[0].content.parts[0].inlineData.data` in den oben aufgeführten Quickstart-Beispielen liest den einzelnen Inline-Teil der Beispielantwort auf dieser Seite. Bei einer echten Antwort durchsuchen Sie `parts` nach dem gewünschten Schlüssel, statt Position 0 zu indizieren.
