API-Referenz für Wan 2.6 R2V. Wan 2.6 Reference-to-Video überträgt die Subjekte aus einem bis drei Referenzvideos in eine neue Szene, die im Prompt als character1, character2 und so weiter adressiert werden.

**Eingabe:** Bild, Video, Text · **Ausgabe:** Video + Audio

## Schnellstart

Erstellen Sie in [Ihrem Comfy-Workspace](https://platform.comfy.org/profile/api-keys?onboarding=router) einen Schlüssel und exportieren Sie ihn als `COMFY_API_KEY`. Die Python- und TypeScript-Snippets verwenden die Comfy SDKs (`pip install comfy-sdk` und `npm install @comfyorg/sdk`); das cURL-Snippet ist derselbe Aufruf über reines HTTP.

**Endpunkt:** `POST https://api.comfy.org/v2/models/wan/wan2.6-r2v`

                    "duration": 5,
                },

        print("request_id:", handle.request_id)  # zusammen mit der Modell-ID alles, was ein anderer Prozess braucht

        # Abfragen, bis die Anfrage abgeschlossen ist, und dabei das vom Server genannte Retry-After abwarten.

Er wandelt die Auflösung vor der Prüfung in Großbuchstaben um und reicht den großgeschriebenen Wert weiter, gibt 400 für einen Wert außerhalb dieses Enums zurück und gibt 400 für 480P zurück (egal ob als resolution oder als 480P-size gesendet) bei den oben aufgeführten wan2.6-, wan2.7- und happyhorse-1.0-Modellen, für die kein 480P-Support gilt.

  Possible values: `480P`, `720P`, `1080P`
</ParamField>

<ParamField body="parameters.size" type="string">

Für wan2.5 T2V: 480P (480*832, 832*480, 624*624), 720P, 1080P als Größen
Für wan2.6 T2V/R2V (kein 480P):
