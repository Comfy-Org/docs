API-Referenz für HappyHorse 1.0 R2V. HappyHorse 1.0 Reference-to-Video hält die Motive aus einer oder mehreren Referenzbildern über eine neue Szene hinweg konsistent; im Prompt werden sie als character1, character2 und so weiter adressiert.

**Eingabe:** Bild, Text · **Ausgabe:** Video

## Schnellstart

Die Python- und TypeScript-Snippets verwenden die Comfy SDKs (`pip install comfy-sdk` und `npm install @comfyorg/sdk`); das cURL-Snippet ist derselbe Aufruf über reines HTTP.

- happyhorse-1.1-* (t2v, i2v, r2v): 480P, 720P, 1080P
Dieser Proxy lehnt Video-Generierungsanfragen ab, die weder resolution noch size
angeben, da die Auflösungsstufe den Abrechnungstarif bestimmt. Er wandelt
resolution vor der Prüfung in Großbuchstaben um und leitet den großgeschriebenen
Wert weiter, gibt 400 für einen Wert außerhalb dieser Enum zurück und gibt 400
für 480P zurück (egal ob als resolution oder als size mit 480P gesendet) bei den
oben aufgeführten wan2.6-, wan2.7- und happyhorse-1.0-Modellen, für die kein 480P
angegeben ist.

  Mögliche Werte: `480P`, `720P`, `1080P`
</ParamField>

<ParamField body="parameters.seed" type="integer">

</ParamField>

<ParamField body="parameters.shot_type" type="string" default="&quot;single&quot;">

Für wan2.6- und wan2.7-r2v-Modelle.
- single: Video aus einer einzigen Aufnahme (Standard)
- multi: Video aus mehreren Aufnahmen

  Mögliche Werte: `multi`, `single`
</ParamField>

<ParamField body="parameters.size" type="string">
  Videoauflösung im Format Breite*Höhe. Die unterstützten Auflösungen variieren je nach Modell:
Für wan2.5 T2V: 480P (480*832, 832*480, 624*624), 720P, 1080P
Für wan2.6 T2V/R2V (kein 480P):
  720P: 1280*720, 720*1280, 960*960, 1088*832, 832*1088
  1080P: 1920*1080, 1080*1920, 1440*1440, 1632*1248, 1248*1632
Wenn sowohl size als auch resolution gesendet werden, bestimmt size die
abgerechnete Stufe, und resolution muss weiterhin ein Wert sein, den dieser
Proxy für das Modell akzeptiert. Eine size mit 480P führt bei jedem Modell, das
laut Auflösungsbeschreibung kein 480P unterstützt, zu 400.
</ParamField>

<ParamField body="parameters.watermark" type="boolean" default="false">
