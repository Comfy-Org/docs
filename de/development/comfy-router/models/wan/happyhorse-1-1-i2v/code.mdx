API-Referenz für HappyHorse 1.1 I2V. HappyHorse 1.1 Bild zu Video animiert ein Standbild als erstes Frame und rendert synchronisierten Dialog, Effekte und Musik im selben Durchlauf.

**Eingabe:** Bild, Text · **Ausgabe:** Video

## Schnellstart

Erstellen Sie einen Schlüssel in [Ihrem Comfy Workspace](https://platform.comfy.org/profile/api-keys?onboarding=router) und exportieren Sie ihn als `COMFY_API_KEY`. Die Python- und TypeScript-Snippets verwenden die Comfy SDKs (`pip install comfy-sdk` und `npm install @comfyorg/sdk`); das cURL-Snippet ist derselbe Aufruf über eine direkte HTTP-Anfrage.

**Modell-ID:** `wan/happyhorse-1.1-i2v`

**Endpunkt:** `POST https://api.comfy.org/v2/models/wan/happyhorse-1.1-i2v`

        handle = await client.models.submit(

                },
            },
        )
        print("request_id:", handle.request_id)  # zusammen mit der Modell-ID alles, was ein anderer Prozess braucht

        # Fragen Sie ab, bis die Anfrage abgeschlossen ist, und warten Sie dabei das Retry-After ab, das der Server angibt.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Die eigene Payload des Anbieters, derselbe Wert, den models.run() zurückgibt.
