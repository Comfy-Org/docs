```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Liest COMFY_API_KEY aus der Umgebung.
# Jeder submit()-Aufruf erzeugt einen eigenen Idempotency-Key und verwendet ihn bei automatischen Wiederholungsversuchen erneut.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "wan/wan2.5-i2i-preview",
            {
                "input": {
                    "images": ["https://example.invalid/red-maple-leaf.png"],
                    "prompt": "Make the leaf golden.",
                },
                "parameters": {
                    "n": 1,
                    "size": "768*768",
                },
            },
        )
        print("request_id:", handle.request_id)  # zusammen mit der Modell-ID alles, was ein anderer Prozess braucht

        # Pollen, bis die Anfrage abgeschlossen ist, und dabei den Retry-After abwarten, den der Server nennt.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Die eigene Payload des Anbieters, derselbe Wert, den models.run() zurückgibt.
        # Eine fehlgeschlagene oder abgebrochene Anfrage löst hier den typisierten Router-Fehler aus.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Liest COMFY_API_KEY aus der Umgebung.
// Jeder submit()-Aufruf erzeugt einen eigenen Idempotency-Key und verwendet ihn bei automatischen Wiederholungsversuchen erneut.
const handle = await comfy.models.submit("wan/wan2.5-i2i-preview", {
  input: {
    images: ["https://example.invalid/red-maple-leaf.png"],
    prompt: "Make the leaf golden.",
  },
  parameters: {
    n: 1,
    size: "768*768",
  },
});
console.log("requestId:", handle.requestId); // zusammen mit der Modell-ID alles, was ein anderer Prozess braucht

// Pollen, bis die Anfrage abgeschlossen ist, und dabei den Retry-After abwarten, den der Server nennt.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Dasselbe Ergebnis, das models.run() zurückgibt. Eine fehlgeschlagene oder abgebrochene Anfrage wird hier abgelehnt.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Absenden. Router antwortet mit 201 und request_id, status_url, response_url und cancel_url.
curl https://api.comfy.org/v2/models/wan/wan2.5-i2i-preview/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"input\": {\"images\":[\"https://example.invalid/red-maple-leaf.png\"],\"prompt\":\"Make the leaf golden.\"}, \"parameters\": {\"n\":1,\"size\":\"768*768\"}}"

# 2. Pollen, bis der Status COMPLETED ist, und dabei die Retry-After-Sekunden abwarten, die jede Antwort nennt.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/wan/wan2.5-i2i-preview/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Abholen. 200 mit der nativen Ausgabe des Modells, 202 mit dem Status-Body, solange der Lauf noch läuft.
curl https://api.comfy.org/v2/models/wan/wan2.5-i2i-preview/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

### Eingaben

<ParamField body="input" type="object" required>
  Geben Sie grundlegende Informationen ein, etwa Prompt-Wörter, Bilder usw.
</ParamField>

<ParamField body="input.images" type="string[]" required>
  Array aus 1 bis 3 Bild-URLs für die Bild-zu-Bild-Generierung
</ParamField>

<ParamField body="input.negative_prompt" type="string">
  Negativer Prompt zur Beschreibung von Inhalten, die Sie nicht im Bild sehen möchten. Er zählt auf dasselbe Eingabe-Budget wie der Prompt.
</ParamField>

<ParamField body="input.prompt" type="string" required>
  Positiver Prompt zur Beschreibung der erwarteten Bildelemente und visuellen Merkmale. Unterstützt Chinesisch und Englisch. Ein Prompt, der länger ist als das Modell liest, wird gekürzt und nicht abgelehnt. Der Anbieter lehnt eine Anfrage ab, bei der prompt und negative_prompt zusammen länger als etwa 60,850 Bytes UTF-8-Text sind (etwa 20,000 chinesische Zeichen), und antwortet mit InvalidParameter `Range of input length should be [1, 61440]`.
</ParamField>

<ParamField body="model" type="string">
  Die ID des Modells, das für die Bild-zu-Bild-Generierung aufgerufen wird. Auf dieser Komponente NICHT eingeschränkt: Comfy Router füllt sie aus dem Pfadsegment `{model}` von `POST /v2/models/wan/{model}`. Ein direkter v1-Aufruf von `POST /proxy/wan/api/v1/services/aigc/image2image/image-synthesis` MUSS sie angeben, und das Enum der akzeptierten Schreibweisen liegt auf der eigenen Komponente dieser Operation, `WanImage2ImageGenerationRequest`.
</ParamField>

<ParamField body="parameters" type="object">
  Parameter für die Bildverarbeitung
</ParamField>

<ParamField body="parameters.n" type="integer" default="1">
  Anzahl der generierten Bilder. Bereich 1-4. Wenn der Body es auslässt, sendet Comfy 1 an den Anbieter und berechnet 1 Bild

  Bereich: `1` bis `4`
</ParamField>

<ParamField body="parameters.seed" type="integer">
  Zufallszahlen-Seed zur Steuerung der Zufälligkeit. Bereich [0, 2147483647]

  Bereich: `0` bis `2147483647`
</ParamField>

<ParamField body="parameters.size" type="string" default="&quot;1280*1280&quot;">
  Die Auflösung des Ausgabebilds im Format Breite*Höhe. Standard ist 1280*1280. Die API akzeptiert eine Pixelfläche zwischen 589824 (768*768) und 1638400 (1280*1280) mit einem Seitenverhältnis zwischen 1:4 und 4:1
</ParamField>

<ParamField body="parameters.watermark" type="boolean" default="false">
  Ob ein Wasserzeichen-Logo in der unteren rechten Ecke hinzugefügt wird
</ParamField>
