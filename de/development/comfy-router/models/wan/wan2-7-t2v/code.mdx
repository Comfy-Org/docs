API-Referenz für Wan 2.7 T2V. Wan 2.7 Text zu Video erzeugt aus einem Prompt allein ein kurzes Video mit 720P oder 1080P und 2 bis 15 Sekunden Länge.

**Eingabe:** Text · **Ausgabe:** Video + Audio

## Schnellstart

Die Python- und TypeScript-Snippets verwenden die Comfy SDKs (`pip install comfy-sdk` und `npm install @comfyorg/sdk`); das cURL-Snippet ist derselbe Aufruf über rohes HTTP.

**Modell-ID:** `wan/wan2.7-t2v`

**Endpunkt:** `POST https://api.comfy.org/v2/models/wan/wan2.7-t2v`

import asyncio
from comfy_sdk import AsyncComfy

# Liest COMFY_API_KEY aus der Umgebung.
# Jeder submit()-Aufruf erzeugt einen eigenen Idempotency-Key und verwendet ihn bei automatischen Wiederholungsversuchen erneut.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "wan/wan2.7-t2v",
            {
                "input": {
                    "prompt": "a single red maple leaf falling onto still water, slow motion, shallow depth of field",
                },
                "parameters": {
                    "resolution": "720P",
                    "duration": 5,
                },
            },
        )
        print("request_id:", handle.request_id)  # zusammen mit der Modell-ID alles, was ein anderer Prozess benötigt

        # Abfragen, bis die Anfrage abgeschlossen ist, dabei wird das vom Server genannte Retry-After abgewartet.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Die Payload des Anbieters selbst, derselbe Wert, den models.run() zurückgibt.
        # Eine Anfrage, die fehlgeschlagen oder abgebrochen wurde, löst hier den typisierten Router-Fehler aus.
        result = await handle.get()

    print("video:", result["output"]["video_url"])

asyncio.run(main())

  input: {
    prompt: "a single red maple leaf falling onto still water, slow motion, shallow depth of field",
  },
  parameters: {
    resolution: "720P",
    duration: 5,
  },
});
console.log("requestId:", handle.requestId); // zusammen mit der Modell-ID alles, was ein anderer Prozess benötigt

// Abfragen, bis die Anfrage abgeschlossen ist, dabei wird das vom Server genannte Retry-After abgewartet.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Dasselbe Ergebnis, das models.run() zurückgibt. Eine Anfrage, die fehlgeschlagen oder abgebrochen wurde, wird hier abgelehnt.
const result = await handle.get();
if (result.kind !== "json") throw new Error("expected a JSON result");

console.log("video:", result.data.output.video_url);
