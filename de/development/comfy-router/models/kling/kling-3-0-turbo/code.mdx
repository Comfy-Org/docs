```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Liest COMFY_API_KEY aus der Umgebung.
# Jeder submit()-Aufruf erzeugt einen eigenen Idempotency-Key und verwendet ihn für automatische Wiederholungsversuche erneut.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "kling/kling-3.0-turbo",
            {
                "prompt": "A neon-lit alley in the rain, slow dolly forward.",
                "settings": {
                    "aspect_ratio": "16:9",
                    "duration": 5,
                    "resolution": "1080p",
                },
            },
        )
        print("request_id:", handle.request_id)  # zusammen mit der Model ID alles, was ein anderer Prozess braucht

        # Abfragen, bis die Anfrage abgeschlossen ist, dabei das vom Server genannte Retry-After abwarten.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Die eigene Payload des Anbieters, derselbe Wert, den models.run() zurückgibt.
        # Eine fehlgeschlagene oder abgebrochene Anfrage löst hier den typisierten Router-Fehler aus.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Liest COMFY_API_KEY aus der Umgebung.
// Jeder submit()-Aufruf erzeugt einen eigenen Idempotency-Key und verwendet ihn für automatische Wiederholungsversuche erneut.
const handle = await comfy.models.submit("kling/kling-3.0-turbo", {
  prompt: "A neon-lit alley in the rain, slow dolly forward.",
  settings: {
    aspect_ratio: "16:9",
    duration: 5,
    resolution: "1080p",
  },
});
console.log("requestId:", handle.requestId); // zusammen mit der Model ID alles, was ein anderer Prozess braucht

// Abfragen, bis die Anfrage abgeschlossen ist, dabei das vom Server genannte Retry-After abwarten.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Dasselbe Ergebnis, das models.run() zurückgibt. Eine fehlgeschlagene oder abgebrochene Anfrage wird hier abgelehnt.
const result = await handle.get();

console.log(result.data);
```

## Bereitstellende Anbieter

Dieses Modell wird direkt von Comfy Router bereitgestellt, sofern die Anfrage keinen anderen Anbieter angibt. Die folgenden Anbieter stellen es ebenfalls bereit, über denselben Endpunkt und mit derselben Modell-ID, ausgewählt über den Query-Parameter `model_provider`.

- **Comfy** (Standard): `POST https://api.comfy.org/v2/models/kling/kling-3.0-turbo`
- **Higgsfield**, als `higgsfield/higgsfield-kling-3-turbo`: `POST https://api.comfy.org/v2/models/kling/kling-3.0-turbo?model_provider=higgsfield`

`strict_mode` ist standardmäßig false, daher übersetzt Router den auf dieser Seite dokumentierten nativen Request-Body in das eigene Schema des Anbieters und übersetzt die Antwort zurück. Siehe [`model_provider`, `strict_mode` und `fallback_provider`](/de/development/comfy-router/reference#post-v2modelsprovidermodel) in der API-Referenz und [Bereitstellende Anbieter](/de/development/comfy-router/providers) für jedes Modell, das auf diese Weise geroutet wird.
