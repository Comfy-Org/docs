import { comfy } from "@comfyorg/sdk";

}

// Dasselbe Ergebnis, das models.run() zurückgibt. Eine fehlgeschlagene oder abgebrochene Anfrage wird hier abgelehnt.

## Schema

### Eingaben

<ParamField body="aspect_ratio" type="string">
  Nur Text zu Bild. Seitenverhältnis der Ausgabe. Standard 1:1.

  Mögliche Werte: `1:1`, `16:9`, `9:16`, `21:9`, `9:21`, `3:2`, `2:3`, `5:4`, `4:5`
</ParamField>

<ParamField body="image" type="string (uri)">
  Nur `stability/generate-ultra`. Eine von Comfy signierte Asset-URL eines Quellbilds; senden Sie sie, wechselt der Aufruf zu Bild zu Bild und erfordert `strength`. Bei `stability/generate-core` wird sie mit 400 abgelehnt.

  Format: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Was im Bild nicht vorkommen soll.
</ParamField>

<ParamField body="output_format" type="string">
  Ohne Angabe wird `png` verwendet. `jpeg` und `webp` werden nur ausgeliefert, solange der Ausgabeformat-Schalter der Bereitstellung aktiv ist; andernfalls werden sie mit einem 400 abgelehnt, bevor eine Aufgabe ausgeführt wird. Das Format ändert nie den Preis.

  Mögliche Werte: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="prompt" type="string" required>
  Was generiert werden soll.
</ParamField>

<ParamField body="seed" type="integer">
  0 oder keine Angabe wählt einen zufälligen Seed.

  Bereich: `0` bis `4294967294`
</ParamField>

<ParamField body="strength" type="number">
  Nur für Bild zu Bild mit `stability/generate-ultra`. Wie weit Sie sich vom Quellbild entfernen; 1 ignoriert es. Bei `stability/generate-core` wird der Wert mit 400 abgelehnt.

  Bereich: `0` bis `1`
</ParamField>

<ParamField body="style_preset" type="string">
  Stil-Preset von Stability, zum Beispiel `photographic`.
</ParamField>
