## Schema

### Eingaben

<ParamField body="grow_mask" type="integer">
  Um wie viele Pixel die Maskierung erweitert wird. Standardwert 5.

  Reichweite: `0` bis `20`
</ParamField>

<ParamField body="image" type="string (uri)" required>
  Eine von Comfy signierte Asset-URL des Quellbildes.

  Format: `uri`
</ParamField>

<ParamField body="mask" type="string (uri)">
  Eine von Comfy signierte Asset-URL der Maskierung. Weiß markiert den zu löschenden Bereich. Wird sie weggelassen, dient das Alpha des Bildes selbst als Maskierung.

  Format: `uri`
</ParamField>

<ParamField body="output_format" type="string">
  Wird nichts angegeben, ist der Wert `png`. `jpeg` und `webp` werden nur ausgeliefert, solange der Output-Format-Schalter von stability in der jeweiligen Bereitstellung aktiv ist; andernfalls werden sie mit einem 400 abgelehnt, bevor eine Aufgabe startet. Das Format ändert nie den Preis.

  Mögliche Werte: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="seed" type="integer">
  `0` oder weggelassen wählt einen zufälligen Seed.

  Reichweite: `0` bis `4294967294`
</ParamField>
