  Eine von Comfy signierte Asset-URL des Quellbilds.

<ParamField body="negative_prompt" type="string">
  Was aus dem hochskalierten Bild herausgehalten werden soll.
</ParamField>

<ParamField body="output_format" type="string">
  Ohne Angabe wird `png` verwendet. `jpeg` und `webp` werden nur ausgeliefert, solange der Ausgabeformat-Schalter für Stability in der Deployment-Konfiguration aktiv ist; andernfalls werden sie mit einem 400 abgelehnt, bevor eine Aufgabe startet. Das Format ändert nie den Preis.

  Mögliche Werte: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="prompt" type="string" required>
  Was das hochskalierte Bild zeigt.
</ParamField>

<ParamField body="seed" type="integer">
  0 oder keine Angabe wählt einen zufälligen Seed.

  Bereich: `0` bis `4294967294`
</ParamField>

<ParamField body="style_preset" type="string">
  Ein Stil, der auf `prompt` und `negative_prompt` angewendet wird.

  Mögliche Werte: `3d-model`, `analog-film`, `anime`, `cinematic`, `comic-book`, `digital-art`, `enhance`, `fantasy-art`, `isometric`, `line-art`, `low-poly`, `modeling-compound`, `neon-punk`, `origami`, `photographic`, `pixel-art`, `tile-texture`
