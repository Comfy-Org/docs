  Wie stark die Generierung dem Prompt folgt. Higgsfield dokumentiert 0-1 in Schritten von 0.01, hier wird jedoch nur die Grenze 0-1 deklariert: Ein `multipleOf: 0.01` würde in binärer Gleitkommaarithmetik ausgewertet und gewöhnliche Werte wie 0.3 zurückweisen, daher wird ein feiner aufgelöster Wert AKZEPTIERT und weitergeleitet statt zurückgewiesen, genauso wie `prompt` seine nicht deklarierte Längenobergrenze mit einem Hinweis versieht.

  Bereich: `0` bis `1`
</ParamField>

<ParamField body="prompt" type="string">

</ParamField>
