Derselbe Body, gesendet an `POST https://api.comfy.org/v2/models/fal/patina/requests`. Router antwortet mit `201` und einer `request_id`, sobald der Lauf angenommen ist, und das Ergebnis wird abgeholt, sobald es bereit ist, aus diesem Prozess oder aus einem anderen. [Zustellung über die Warteschlange](/de/development/comfy-router/queue) beschreibt Status, Abbruch und Abholung.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Liest COMFY_API_KEY aus der Umgebung.
# Jeder submit()-Aufruf erzeugt einen eigenen Idempotenzschlüssel und verwendet ihn für automatische Wiederholungsversuche erneut.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "fal/patina",
            {
                "image_url": "https://storage.googleapis.com/falserverless/gallery/patina-blog-hero-render.png",
            },
        )
        print("request_id:", handle.request_id)  # zusammen mit der Modell-ID alles, was ein anderer Prozess benötigt

        # Abfragen, bis die Anfrage abgeschlossen ist, und dabei die vom Server genannten Retry-After abwarten.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Die Payload des Anbieters selbst, derselbe Wert, den models.run() zurückgibt.
        # Eine Anfrage, die fehlgeschlagen oder abgebrochen wurde, löst hier den typisierten Router-Fehler aus.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Liest COMFY_API_KEY aus der Umgebung.
// Jeder submit()-Aufruf erzeugt einen eigenen Idempotenzschlüssel und verwendet ihn für automatische Wiederholungsversuche erneut.
const handle = await comfy.models.submit("fal/patina", {
  image_url: "https://storage.googleapis.com/falserverless/gallery/patina-blog-hero-render.png",
});
console.log("requestId:", handle.requestId); // zusammen mit der Modell-ID alles, was ein anderer Prozess benötigt

// Abfragen, bis die Anfrage abgeschlossen ist, und dabei die vom Server genannten Retry-After abwarten.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Dasselbe Ergebnis, das models.run() zurückgibt. Eine Anfrage, die fehlgeschlagen oder abgebrochen wurde, wird hier abgelehnt.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Absenden. Router antwortet mit 201 sowie request_id, status_url, response_url und cancel_url.
curl https://api.comfy.org/v2/models/fal/patina/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"image_url\": \"https://storage.googleapis.com/falserverless/gallery/patina-blog-hero-render.png\"}"

# 2. Abfragen, bis der Status COMPLETED ist, und dabei die Retry-After-Sekunden abwarten, die jede Antwort nennt.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/fal/patina/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Abholen. 200 mit der nativen Ausgabe des Modells, 202 mit dem Status-Body, solange es noch läuft.
curl https://api.comfy.org/v2/models/fal/patina/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```
