import { comfy } from "@comfyorg/sdk";

### Eingaben

<ParamField body="apply_text_normalization" type="string" default="&quot;auto&quot;">
  Steuert die Textnormalisierung mit drei Modi:
'auto' - das System entscheidet automatisch, ob Textnormalisierung angewendet wird
'on' - Textnormalisierung wird immer angewendet
'off' - Textnormalisierung wird übersprungen

  Mögliche Werte: `auto`, `on`, `off`
</ParamField>

<ParamField body="inputs" type="object[]" required>
  Eine Liste von Dialog-Eingaben, die jeweils Text und eine Voice-ID enthalten und in Sprache umgewandelt werden.
Die maximale Anzahl eindeutiger Voice-IDs beträgt 10.
</ParamField>

<ParamField body="inputs[].text" type="string" required>
  Der Text, der in Sprache umgewandelt werden soll.
</ParamField>

<ParamField body="inputs[].voice_id" type="string" required>
  Die ID der Stimme, die für die Generierung verwendet wird.
</ParamField>

<ParamField body="language_code" type="string">
  Sprachcode (ISO 639-1), mit dem eine Sprache für das Modell und die Textnormalisierung erzwungen wird.
Wenn das Modell den angegebenen Sprachcode nicht unterstützt, wird ein Fehler zurückgegeben.
</ParamField>

<ParamField body="model_id" type="string">
  Bezeichner des Modells, das verwendet wird. Diese Route akzeptiert
'eleven_v3', 'eleven_v4' und 'eleven_v4_turbo' und nichts anderes;
jeder andere Wert wird mit 400 abgelehnt, bevor die Anfrage ElevenLabs
erreicht.
Der Hinweis von ElevenLabs, GET /v1/models für die verfügbare Auswahl
abzufragen, beschreibt diese Route NICHT, die ausschließlich diese
Modelle bedient.
Er steht NICHT in der `required`-Liste dieses Schemas, weil Comfy Router
ihn aus dem `{model}`-Pfadsegment von
/v2/models/elevenlabs/\{model} füllt, sodass ein Router-Aufrufer ihn weglässt.
</ParamField>

<ParamField body="pronunciation_dictionary_locators" type="object[]">
  Eine Liste von Locators für Aussprachewörterbücher (id, version_id), die auf den Text angewendet werden.
Sie werden in der angegebenen Reihenfolge angewendet. Sie können bis zu 3 Locators pro Anfrage verwenden.
</ParamField>

<ParamField body="pronunciation_dictionary_locators[].pronunciation_dictionary_id" type="string" required>
  Die ID des Aussprachewörterbuchs
</ParamField>

<ParamField body="pronunciation_dictionary_locators[].version_id" type="string" required>
  Die Versions-ID des Aussprachewörterbuchs
</ParamField>

<ParamField body="seed" type="integer">
  Wenn angegeben, versucht unser System, so deterministisch wie möglich zu samplen.
Wiederholte Anfragen mit demselben Seed und denselben Parametern sollten dasselbe Ergebnis liefern.
Muss eine ganze Zahl zwischen 0 und 4294967295 sein.

  Bereich: `0` bis `4294967295`
</ParamField>

<ParamField body="settings" type="object">
  Einstellungen, die die Dialoggenerierung steuern
</ParamField>

<ParamField body="settings.stability" type="number" default="0.5">
  Bestimmt, wie stabil die Stimme ist und wie viel Zufall zwischen den einzelnen Generierungen liegt.
Niedrigere Werte erweitern die emotionale Bandbreite der Stimme.
Höhere Werte können zu einer monotonen Stimme mit begrenzter Emotion führen.

  Format: `double`
</ParamField>
