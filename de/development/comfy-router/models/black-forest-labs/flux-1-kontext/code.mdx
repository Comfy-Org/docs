API-Referenz für FLUX.1 Kontext. FLUX.1 Kontext ist das anweisungsgesteuerte Bildbearbeitungsmodell von Black Forest Labs: Sie senden ein Bild und eine Textanweisung und erhalten das bearbeitete Bild zurück, wobei der Rest der Szene erhalten bleibt.

**Eingabe:** Bild, Text · **Ausgabe:** Bild

## Schnellstart

Erstellen Sie einen Schlüssel in [Ihrem Comfy Workspace](https://platform.comfy.org/profile/api-keys?onboarding=router) und exportieren Sie ihn als `COMFY_API_KEY`. Die Python- und TypeScript-Snippets verwenden die Comfy SDKs (`pip install comfy-sdk` und `npm install @comfyorg/sdk`); das cURL-Snippet ist derselbe Aufruf über reines HTTP.

Wählen Sie das Modell aus, das Sie aufrufen möchten. Alles Folgende, von den Snippets bis zum Schema und den Beispielen, richtet sich nach Ihrer Wahl.

import asyncio
import base64
from comfy_sdk import AsyncComfy

with open("input.jpg", "rb") as f:
    input_image = base64.b64encode(f.read()).decode()

# Liest COMFY_API_KEY aus der Umgebung.

import { readFile } from "node:fs/promises";

const inputImage = (await readFile("input.jpg")).toString("base64");

// Liest COMFY_API_KEY aus der Umgebung.

  Format: `double`
</ResponseField>

<ResponseField name="result.prompt" type="string">
  Der Prompt, mit dem die Generierung tatsächlich lief, nach einem eventuellen Prompt-Upsampling.
</ResponseField>

<ResponseField name="result.sample" type="string (uri)">
  Signierte URL für das generierte Asset. Router hostet das Asset auf den Comfy-Speicher um und schreibt dieses Feld neu, daher ist es normalerweise eine von Comfy gehostete URL, die bis zu 24 Stunden gültig ist: beim Ausstellen für 24 Stunden signiert und aus einem 23-Stunden-Memo wiedergegeben, sodass eine spätere Abfrage eine URL zurückgeben kann, von der nur noch etwa eine Stunde übrig ist. Ein Leaf, dessen Re-Host nicht durchgeführt werden konnte, behält stattdessen BFLs eigene kurzlebige Auslieferungs-URL: etwa zwei Stunden für Video, etwa zehn Minuten für Bilder. So oder so läuft der Link ab, daher sollten Sie das Asset herunterladen, statt die URL zu speichern.

  Format: `uri`
</ResponseField>

<ResponseField name="result.seed" type="integer">
  Der Seed, den die Generierung verwendet hat, ob geliefert oder vom Anbieter gewählt. Als `int64` deklariert, weil BFL Seeds über 2^31 zurückgibt (z. B. 2784347701), die ein unformatiertes `integer` in vielen SDK-Generatoren als 32-Bit-Feld erzeugt.

  Format: `int64`
</ResponseField>

<ResponseField name="result.start_time" type="number">
  Vom Anbieter gemeldeter Startzeitpunkt der Generierung in Sekunden seit der Unix-Epoche. `double`, nicht `float`: Der float32-Abstand nahe einem heutigen Epochenwert liegt bei ~128 Sekunden, wodurch die gesamte Spanne einer Generierung auf einen einzigen dekodierten Wert zusammenfällt.

  Format: `double`
</ResponseField>

<ResponseField name="status" type="string" required>
  Task-Status: Pending, Reasoning, Generating, Ready, Request Moderated, Content Moderated, Error oder Task not found.
</ResponseField>

</ResponseField>

<ResponseField name="result.duration" type="number">
  Vom Anbieter gemeldete Dauer der Generierung in Sekunden.

  Format: `double`
</ResponseField>

<ResponseField name="result.end_time" type="number">
  Vom Anbieter gemeldeter Abschlusszeitpunkt der Generierung in Sekunden seit der Unix-Epoche. `double` aus demselben Grund wie `start_time`.

  Format: `double`
</ResponseField>

<ResponseField name="result.prompt" type="string">
  Der Prompt, mit dem die Generierung tatsächlich lief, nach einem eventuellen Prompt-Upsampling.
</ResponseField>

<ResponseField name="result.sample" type="string (uri)">
  Signierte URL für das generierte Asset. Router hostet das Asset auf den Comfy-Speicher um und schreibt dieses Feld neu, daher ist es normalerweise eine von Comfy gehostete URL, die bis zu 24 Stunden gültig ist: beim Ausstellen für 24 Stunden signiert und aus einem 23-Stunden-Memo wiedergegeben, sodass eine spätere Abfrage eine URL zurückgeben kann, von der nur noch etwa eine Stunde übrig ist. Ein Leaf, dessen Re-Host nicht durchgeführt werden konnte, behält stattdessen BFLs eigene kurzlebige Auslieferungs-URL: etwa zwei Stunden für Video, etwa zehn Minuten für Bilder. So oder so läuft der Link ab, daher sollten Sie das Asset herunterladen, statt die URL zu speichern.

  Format: `uri`
</ResponseField>

<ResponseField name="result.seed" type="integer">
  Der Seed, den die Generierung verwendet hat, ob geliefert oder vom Anbieter gewählt. Als `int64` deklariert, weil BFL Seeds über 2^31 zurückgibt (z. B. 2784347701), die ein unformatiertes `integer` in vielen SDK-Generatoren als 32-Bit-Feld erzeugt.

  Format: `int64`
</ResponseField>

<ResponseField name="result.start_time" type="number">
  Vom Anbieter gemeldeter Startzeitpunkt der Generierung in Sekunden seit der Unix-Epoche. `double`, nicht `float`: Der float32-Abstand nahe einem heutigen Epochenwert liegt bei ~128 Sekunden, wodurch die gesamte Spanne einer Generierung auf einen einzigen dekodierten Wert zusammenfällt.

  Format: `double`
</ResponseField>

<ResponseField name="status" type="string" required>
  Task-Status: Pending, Reasoning, Generating, Ready, Request Moderated, Content Moderated, Error oder Task not found.
</ResponseField>
