API-Referenz für Flux 1.1 Pro Ultra Image. FLUX 1.1 [pro] ist ein Text zu Bild-Modell von Black Forest Labs. Der Ultra-Modus generiert Bilder mit bis zu 4 MP Auflösung.

## Schnellstart

Die Python- und TypeScript-Snippets verwenden die Comfy SDKs (`pip install comfy-sdk` und `npm install @comfyorg/sdk`); das cURL-Snippet ist derselbe Aufruf über rohes HTTP.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Liest COMFY_API_KEY aus der Umgebung.
# Jeder submit()-Aufruf erzeugt einen eigenen Idempotency-Key und verwendet ihn für automatische Wiederholungen erneut.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bfl/flux-pro-1.1-ultra",
            {
                "prompt": "a single red maple leaf on a plain white background, studio lighting",
                "aspect_ratio": "16:9",
                "raw": False,
            },
        )
        print("request_id:", handle.request_id)  # zusammen mit der Modell-ID alles, was ein anderer Prozess braucht

        # Fragen Sie ab, bis die Anfrage abgeschlossen ist, und warten Sie dabei die vom Server genannte Retry-After-Zeit ab.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Die eigene Payload des Anbieters, derselbe Wert, den models.run() zurückgibt.
        # Eine fehlgeschlagene oder abgebrochene Anfrage löst hier den typisierten Router-Fehler aus.
        result = await handle.get()

    print("image:", result["result"]["sample"])

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Liest COMFY_API_KEY aus der Umgebung.
// Jeder submit()-Aufruf erzeugt einen eigenen Idempotency-Key und verwendet ihn für automatische Wiederholungen erneut.
type Result = { result: { sample: string } };
const handle = await comfy.models.submit<Result>("bfl/flux-pro-1.1-ultra", {

  raw: false,

// Fragen Sie ab, bis die Anfrage abgeschlossen ist, und warten Sie dabei die vom Server genannte Retry-After-Zeit ab.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Dasselbe Ergebnis, das models.run() zurückgibt. Eine fehlgeschlagene oder abgebrochene Anfrage wird hier abgelehnt.

console.log("image:", result.data.result.sample);
```

  Format: `double`
</ResponseField>

<ResponseField name="result.prompt" type="string">
  Der Prompt, mit dem die Generierung tatsächlich ausgeführt wurde, nach einem eventuellen Prompt-Upsampling.
</ResponseField>

<ResponseField name="result.sample" type="string (uri)">
  Signierte URL für das generierte Asset. Router hostet das Asset auf Comfy-Speicher neu und schreibt dieses Feld neu, daher ist es normalerweise eine von Comfy gehostete URL, die bis zu 24 Stunden gültig ist: beim Ausstellen für 24 Stunden signiert und aus einem 23-Stunden-Memo erneut ausgegeben, sodass eine spätere Abfrage eine URL zurückgeben kann, die nur noch eine Stunde gültig ist; ein Blatt, dessen Re-Hosting nicht durchgeführt werden konnte, behält stattdessen BFLs eigene kurzlebige Auslieferungs-URL, etwa zwei Stunden für Video und etwa zehn Minuten für Bilder. In jedem Fall läuft der Link ab, laden Sie das Asset daher herunter, anstatt die URL zu speichern.

  Format: `uri`
</ResponseField>

<ResponseField name="result.seed" type="integer">
  Der Seed, den die Generierung verwendet hat, ob angegeben oder vom Anbieter gewählt. Als `int64` deklariert, weil BFL Seeds über 2^31 zurückgibt (z. B. 2784347701), die ein unformatiertes `integer` in vielen SDK-Generatoren als 32-Bit-Feld erzeugt.

  Format: `int64`
</ResponseField>

<ResponseField name="result.start_time" type="number">
  Vom Anbieter gemeldeter Startzeitpunkt der Generierung, in Sekunden seit der Unix-Epoche. `double`, nicht `float`: Der float32-Abstand nahe einem heutigen Epochenwert beträgt ~128 Sekunden, was die gesamte Spanne einer Generierung auf einen einzigen dekodierten Wert zusammenfallen lässt.

  Format: `double`
</ResponseField>

<ResponseField name="status" type="string" required>
  Aufgabenstatus: Pending, Reasoning, Generating, Ready, Request Moderated, Content Moderated, Error oder Task not found.
</ResponseField>
