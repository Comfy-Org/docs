## Schnellstart

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Liest COMFY_API_KEY aus der Umgebung.
# Jeder submit()-Aufruf erzeugt einen eigenen Idempotency-Key und verwendet ihn bei automatischen Wiederholungsversuchen erneut.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bfl/video-upscale-v1",
            {
                "input_video": "https://your-host.example/clip.mp4",
                "upscale_factor": 2,
                "creativity": 1,
            },
        )
        print("request_id:", handle.request_id)  # zusammen mit der Model ID alles, was ein anderer Prozess benötigt

        # Abfragen, bis die Anfrage abgeschlossen ist, und dabei das vom Server genannte Retry-After abwarten.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Die eigene Payload des Anbieters, derselbe Wert, den models.run() zurückgibt.
        # Eine fehlgeschlagene oder abgebrochene Anfrage löst hier den typisierten Router-Fehler aus.
        result = await handle.get()

    print("video:", result["result"]["sample"])

asyncio.run(main())
```

## Schema

### Eingaben

<ParamField body="creativity" type="integer" default="1">
  0 bewahrt die Quelle präzise und schärft sie; 1 erlaubt eine kreative Detailanreicherung, die Gesichter oder Produkte nicht streng erhält.

  Bereich: `0` bis `1`
</ParamField>

<ParamField body="input_video" type="string" required>
  Das zu skalierende Video, entweder eine HTTP(S)-URL oder ein base64-kodiertes MP4. Höchstens 20 Sekunden Ausgangsmaterial, 50MB und 2560x1440 (3.7 Megapixel) pro Frame; skalieren Sie eine größere Quelle herunter, bevor Sie sie übermitteln.
</ParamField>

<ParamField body="prompt" type="string">
  Optionale Beschreibung des Inhalts des Clips, die die verstärkten Details steuert. Leer lassen für ein neutrales Upscaling.
</ParamField>

<ParamField body="safety_tolerance" type="integer" default="2">
  Toleranzstufe für die Moderation von Prompt und Ausgabeframes, wobei 0 am strengsten ist.

  Bereich: `0` bis `4`
</ParamField>

<ParamField body="upscale_factor" type="number" default="2">
  Skalierung der Ausgabe relativ zur Auflösung der Quelle. Die Ausgabe behält das Seitenverhältnis der Quelle bei und ist auf etwa 14.4 Megapixel pro Frame begrenzt, daher werden sehr große Quellen um weniger als den angeforderten Faktor skaliert. Es gibt keine Auflösungsoption; um 2K (2560x1440) oder 4K (3840x2160) zu erreichen, dividieren Sie die Zielhöhe durch die Höhe der Quelle. Eine 720p-Quelle erreicht 2K bei 2 und 4K bei 3; eine 1080p-Quelle erreicht 4K bei 2, kann 2K aber nicht erreichen, dafür wäre 1.33 nötig.

  Bereich: `1.5` bis `3`

  Format: `float`
</ParamField>

<ParamField body="webhook_secret" type="string">
  Optionales Secret für die Verifizierung der Webhook-Signatur.
</ParamField>

<ParamField body="webhook_url" type="string (uri)">
  URL zum Empfang von Webhook-Benachrichtigungen.

  Format: `uri`
</ParamField>

  Signierte URL für das generierte Asset. Router hostet das Asset auf Comfy-Speicher neu und schreibt dieses Feld um, daher ist es normalerweise eine von Comfy gehostete URL, die bis zu 24 Stunden gültig ist: beim Ausstellen für 24 Stunden signiert und aus einem 23-Stunden-Memo erneut ausgegeben, sodass eine spätere Abfrage eine URL zurückgeben kann, die nur noch eine Stunde gültig ist; ein Leaf, dessen Re-Hosting nicht durchgeführt werden konnte, behält stattdessen BFLs eigene kurzlebige Auslieferungs-URL: etwa zwei Stunden für Video, etwa zehn Minuten für Bilder. So oder so läuft der Link ab, laden Sie das Asset also herunter, statt die URL zu speichern.

</ResponseField>

<ResponseField name="result.seed" type="integer">
  Der Seed, den die Generierung verwendet hat, ob bereitgestellt oder vom Anbieter gewählt. Als `int64` deklariert, weil BFL Seeds über 2^31 zurückgibt (z. B. 2784347701), die ein unformatiertes `integer` in vielen SDK-Generatoren als 32-Bit-Feld erzeugt.

  Format: `double`
</ResponseField>

</ResponseField>

## Beispiele

### Eingaben

{
  "input_video": "https://your-host.example/clip.mp4",
  "upscale_factor": 2,
  "creativity": 1
}

### Ausgaben

```json
{
  "id": "0a1b2c3d-...",
  "status": "Ready",
  "result": {
    "sample": "https://.../upscaled.mp4"
  }
}
```

`result.sample` ist normalerweise eine von Comfy gehostete signierte URL, die ab ihrer Erstellung bis zu 24 Stunden gültig ist. Eine erneute Wiedergabe kann eine ältere URL zurückgeben, und ein Asset, das nicht erneut gehostet werden konnte, behält seine Anbieter-URL mit kürzerer Lebensdauer. Laden Sie die MP4-Datei zeitnah herunter, statt den Link zu speichern.
