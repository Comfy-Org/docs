```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Liest COMFY_API_KEY aus der Umgebung.
# Jeder submit()-Aufruf erzeugt einen eigenen Idempotency-Key und verwendet ihn bei automatischen Wiederholungsversuchen erneut.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bfl/flux-3-video",
            {
                "mode": "t2v",
                "prompt": "a single red maple leaf falling onto still water, slow motion",
                "duration": 5,
                "aspect_ratio": "16:9",
                "generate_audio": True,
            },
        )
        print("request_id:", handle.request_id)  # zusammen mit der Modell-ID alles, was ein anderer Prozess braucht

        # Abfragen, bis die Anfrage abgeschlossen ist, und dabei die vom Server genannte Retry-After-Zeit abwarten.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Die eigene Payload des Anbieters, derselbe Wert, den models.run() zurückgibt.
        # Eine fehlgeschlagene oder abgebrochene Anfrage löst hier den typisierten Router-Fehler aus.
        result = await handle.get()

    print("video:", result["result"]["sample"])

asyncio.run(main())
```

// Jeder submit()-Aufruf erzeugt einen eigenen Idempotency-Key und verwendet ihn bei automatischen Wiederholungsversuchen erneut.

// Abfragen, bis die Anfrage abgeschlossen ist, und dabei die vom Server genannte Retry-After-Zeit abwarten.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Dasselbe Ergebnis, das models.run() zurückgibt. Eine fehlgeschlagene oder abgebrochene Anfrage wird hier abgelehnt.
const result = await handle.get();

console.log("video:", result.data.result.sample);

  Seitenverhältnis der Ausgabe: auto, 21:9, 2:1, 16:9, 4:3, 1:1, 3:4 oder 9:16. auto lässt BFL anhand des Prompts und etwaiger Referenzen wählen.
</ParamField>

<ParamField body="draft" type="boolean" default="false">
  Entwurfsmodus: erzeugt eine schnelle Vorschau, deren Ergebnis eine Download-URL für draft_cache enthält. Senden Sie dieses Bundle mit mode draft_enhance zurück, um die Version derselben Generierung in voller Qualität zu rendern.
</ParamField>

<ParamField body="draft_cache" type="string">
  Nur draft_enhance. Verschlüsseltes Draft-Cache-Bundle aus einer vorherigen Entwurfsgenerierung, als base64-kodiertes heruntergeladenes Bundle oder als dessen noch gültige http(s)-URL. Die ursprünglichen Eingaben sind im Bundle eingebettet.
</ParamField>

<ParamField body="duration" type="integer | string" default="&quot;auto&quot;">
  Videodauer in Sekunden (jede ganze Sekunde von 5 bis 20) oder auto, um sie dem Inhalt anzupassen.

  Bereich: `5` bis `20`
</ParamField>

<ParamField body="generate_audio" type="boolean" default="true">
  Synchronisiertes Audio zusammen mit dem Video generieren.
</ParamField>

<ParamField body="keyframes" type="string | number | string[] | string[] | number | string[][]">
  Nur i2v. Bilder, die zu Frames des Videos werden, jeweils eine http(s)-URL oder base64, insgesamt ein bis zehn. Akzeptiert ein einzelnes Bild, eine Liste von Bildern (eines startet das Video, zwei starten und beenden es, mehr werden gleichmäßig verteilt und benötigen eine feste Dauer) oder mit Zeitstempeln versehene [Sekunden, Bild]-Paare in zeitlicher Reihenfolge, z. B. [[0, "..."], [3.5, "..."]]. Ein Paar ist ein Array aus zwei Elementen: zuerst die Anzahl der Sekunden, dann das Bild.
</ParamField>

<ParamField body="mode" type="string" required>
  Generierungsmodus: t2v (Text zu Video), i2v (Bildfortsetzung), v2v (Videofortsetzung) oder draft_enhance (Rendering eines vorherigen Entwurfs in voller Qualität). Ausgeschriebene Aliase wie text-to-video werden akzeptiert.
</ParamField>

<ParamField body="prompt" type="string">
  Freier Prompt, der das Video beschreibt. Erforderlich für jeden Modus außer draft_enhance.
</ParamField>

<ParamField body="resolution" type="string">
  Auflösungsklasse des Videos: hd (720p) oder fhd (1080p), qhd (2K) oder uhd (4K) für ein höher aufgelöstes Ergebnis, das vom Video-Upsampler fertiggestellt wird. Standard ist hd für t2v, i2v und v2v und fhd für draft_enhance. Die genauen Abmessungen variieren mit dem Seitenverhältnis.

  Mögliche Werte: `hd`, `fhd`, `qhd`, `uhd`
</ParamField>

<ParamField body="safety_tolerance" type="integer" default="2">
  Toleranzstufe für die Moderierung schädlicher Eingaben und Ausgaben, 0 ist am strengsten. Sexuelle Inhalte sind unabhängig von der angeforderten Toleranz auf Stufe 3 begrenzt und Hassinhalte auf Stufe 2; Anfragen mit Konditionierungsmedien sind auf Stufe 2 begrenzt.

  Bereich: `0` bis `4`
</ParamField>

<ParamField body="start_video" type="string">
  Nur v2v. Das Video, das fortgesetzt wird, eine http(s)-URL oder base64-MP4; der generierte Clip setzt ab seinen letzten Frames fort.
</ParamField>

<ParamField body="version" type="string" default="&quot;latest&quot;">
  Endpunktversion. latest liefert die aktuelle Veröffentlichung; datierte, festlegbare Release-Tags werden hinzugefügt, sobald sie veröffentlicht werden.
</ParamField>

```json

  "status": "Ready",
  "result": {
    "sample": "https://.../out.mp4"
  }

```

`result.sample` ist normalerweise eine von Comfy gehostete signierte URL, die ab der Erstellung bis zu 24 Stunden gültig ist. Eine erneute Ausführung kann eine ältere URL zurückgeben, und ein Asset, das nicht erneut gehostet werden konnte, behält die kurzlebige URL des Anbieters. Laden Sie das MP4 zeitnah herunter, statt die URL zu speichern. Lesen Sie bei `draft: true` `result.draft_cache`, statt `result.sample` zu erwarten.
