  Signierte URL für das generierte Asset. Der Router hostet das Asset erneut auf dem Comfy-Speicher und schreibt dieses Feld um, daher ist es normalerweise eine von Comfy gehostete URL, die bis zu 24 Stunden gültig ist: beim Ausstellen für 24 Stunden signiert und aus einem 23-Stunden-Memo erneut ausgegeben, sodass eine spätere Abfrage eine URL zurückgeben kann, die nur noch eine Stunde gültig ist; ein Leaf, dessen erneutes Hosting nicht durchgeführt werden konnte, behält stattdessen BFLs eigene kurzlebige Auslieferungs-URL: etwa zwei Stunden für Video, etwa zehn Minuten für Bilder.
