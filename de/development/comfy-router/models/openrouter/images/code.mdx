API-Referenz für `openrouter/images`, bereitgestellt von Comfy Router aus Openrouter.

**Eingabe:** Text, Bild · **Ausgabe:** Bild

## Anfrage einrichten

Erstellen Sie einen Schlüssel in [Ihrem Comfy-Workspace](https://platform.comfy.org/profile/api-keys?onboarding=router) und exportieren Sie ihn als `COMFY_API_KEY`. Führen Sie für Python `pip install comfy-sdk` aus. Führen Sie für TypeScript `npm install @comfyorg/sdk` aus. cURL verwendet reines HTTP.

**Modell-ID:** `openrouter/images`

**Endpunkt:** `POST https://api.comfy.org/v2/models/openrouter/images`

<Note>
Für dieses Modell gibt es kein ausführbares Anfragebeispiel. Stellen Sie den Body anhand der untenstehenden Eingabedokumentation zusammen und verwenden Sie ihn dann mit dem [Router-Schnellstart](/de/development/comfy-router/quickstart).
</Note>
