Derselbe Body, gesendet an `POST https://api.comfy.org/v2/models/viggle/text-to-motion/requests`. Router antwortet mit `201` und einer `request_id`, sobald der Lauf angenommen ist, und das Ergebnis wird abgeholt, sobald es bereit ist, aus diesem Prozess oder aus einem anderen. [Queued delivery](/development/comfy-router/queue) führt durch Status, Abbruch und Abholung.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Liest COMFY_API_KEY aus der Umgebung.
# Jeder submit()-Aufruf erzeugt einen eigenen Idempotency-Key und verwendet ihn für automatische Wiederholungsversuche erneut.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "viggle/text-to-motion",
            {
                "duration_seconds": 5,
                "text": "a person waves with the right hand",
            },
        )
        print("request_id:", handle.request_id)  # zusammen mit der Modell-ID alles, was ein anderer Prozess braucht

        # Abfragen, bis die Anfrage abgeschlossen ist, und dabei das Retry-After abwarten, das der Server nennt.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Die eigene Payload des Anbieters, derselbe Wert, den models.run() zurückgibt.
        # Eine Anfrage, die fehlgeschlagen oder abgebrochen wurde, wirft hier den typisierten Router-Fehler.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Liest COMFY_API_KEY aus der Umgebung.
// Jeder submit()-Aufruf erzeugt einen eigenen Idempotency-Key und verwendet ihn für automatische Wiederholungsversuche erneut.
const handle = await comfy.models.submit("viggle/text-to-motion", {
  duration_seconds: 5,
  text: "a person waves with the right hand",
});
console.log("requestId:", handle.requestId); // zusammen mit der Modell-ID alles, was ein anderer Prozess braucht

// Abfragen, bis die Anfrage abgeschlossen ist, und dabei das Retry-After abwarten, das der Server nennt.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Dasselbe Ergebnis, das models.run() zurückgibt. Eine Anfrage, die fehlgeschlagen oder abgebrochen wurde, wird hier abgelehnt.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Absenden. Router antwortet mit 201 und request_id, status_url, response_url und cancel_url.
curl https://api.comfy.org/v2/models/viggle/text-to-motion/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"duration_seconds\": 5, \"text\": \"a person waves with the right hand\"}"

# 2. Abfragen, bis der Status COMPLETED lautet, und dabei in jeder Antwort die genannten Retry-After-Sekunden abwarten.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/viggle/text-to-motion/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Abholen. 200 mit der nativen Ausgabe des Modells, 202 mit dem Status-Body, solange es noch läuft.
curl https://api.comfy.org/v2/models/viggle/text-to-motion/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```
