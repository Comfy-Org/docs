API-Referenz für MiniMax H3. MiniMax H3 (Hailuo 03) ist ein omni-modales Videomodell. Es erzeugt das Bild und seine Tonspur in einem einzigen Durchgang, sodass ein fertiger Clip bereits Dialoge, Toneffekte und Musik enthält.

**Eingabe:** Text, Bild · **Ausgabe:** Video + Audio

## Schnellstart

Erstellen Sie einen Schlüssel in [Ihrem Comfy Workspace](https://platform.comfy.org/profile/api-keys?onboarding=router) und exportieren Sie ihn als `COMFY_API_KEY`. Die Python- und TypeScript-Snippets verwenden die Comfy SDKs (`pip install comfy-sdk` und `npm install @comfyorg/sdk`); das cURL-Snippet ist derselbe Aufruf über reines HTTP.

**Modell-ID:** `minimax/minimax-h3`

**Endpoint:** `POST https://api.comfy.org/v2/models/minimax/minimax-h3`

import asyncio
from comfy_sdk import AsyncComfy

# Liest COMFY_API_KEY aus der Umgebung.
# Jeder submit()-Aufruf erzeugt seinen eigenen Idempotency-Key und verwendet ihn für automatische Wiederholungsversuche erneut.
async def main():

        handle = await client.models.submit(
            "minimax/minimax-h3",

                    {
                        "text": "A single red maple leaf resting on a plain white background.",
                        "type": "text",

                "resolution": "768P",
            },
        )
        print("request_id:", handle.request_id)  # zusammen mit der Modell-ID alles, was ein anderer Prozess benötigt

        # Pollen, bis die Anfrage abgeschlossen ist, und dabei das vom Server genannte Retry-After abwarten.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Die eigene Payload des Anbieters, derselbe Wert, den models.run() zurückgibt.
        # Eine fehlgeschlagene oder abgebrochene Anfrage löst hier den typisierten Router-Fehler aus.
        result = await handle.get()

    print("video:", result["task"]["content"]["url"])

asyncio.run(main())

**Die MP4-Datei enthält eine generierte Audiospur.** H3 ist omni-modal: Stimme, Soundeffekte und Musik werden gemeinsam mit dem Bild in einem einzigen Forward-Pass synthetisiert, nicht nachträglich darübergelegt, und das Ergebnis ist eine einzelne MP4-Datei mit nativem Stereo-Audio. Nichts im obigen Request-Body schaltet das ab: Die dokumentierten Felder sind der Prompt-Inhalt, `duration`, `ratio`, `resolution`, `seed`, `aigc_watermark` und `callback_url`, und keines davon wählt ein stummes Rendering aus. Eine Pipeline, die ihr eigenes Voiceover über den Clip legen möchte, muss daher die zurückgegebene Tonspur zuerst stummschalten oder entfernen, andernfalls wird über einen Clip gemuxt, der bereits spricht. Der Prompt steuert das Audio: Beschreiben Sie den Dialog, die Soundeffekte und die Musik im selben Prompt-Block wie den Shot. Wie Sie einen solchen aufbauen, erfahren Sie im [MiniMax H3 Prompt-Leitfaden](/de/tutorials/video/minimax/minimax-h3-prompt-guide); was das Modell in ComfyUI macht, steht in der [MiniMax H3 Übersicht](/de/tutorials/video/minimax/minimax-h3).

Die Video-URL läuft ab. Router hostet die MP4-Datei erneut und liefert eine von Comfy signierte URL, die 12 Stunden lang gültig ist; wenn das erneute Hosten fehlschlägt, wird auf MiniMax' eigenen kurzlebigeren Link zurückgegriffen. Die Beschreibung von `task.content.url` im obigen Response-Schema weist Sie an, erneut abzufragen, um eine aktualisierte URL zu erhalten: Das ist MiniMax' eigene Formulierung für ihre API, unverändert übernommen, und Router stellt MiniMax' Task-Query-Route nicht bereit. Das erneute Lesen der Ergebnis-Route einer Anfrage in der Warteschlange gibt das gespeicherte Ergebnisdokument zurück, solange die Anfrage [24 Stunden nach ihrem Abschluss aufbewahrt wird](/de/development/comfy-router/queue#idempotency-and-billing), aber nichts dokumentiert, dass dieses Lesen eine neu signierte URL ausstellt. Laden Sie die MP4 zeitnah herunter, anstatt den Link zu speichern.
