NO_OP ist terminal; es wurde kein Lip-Sync angewendet, `outputUrl` ist das unveränderte Eingabevideo (zuzüglich eventuell generierter Sprache), Sync berechnet keine Kosten für Lip-Sync und Comfy stellt dem Aufrufer keine Kosten in Rechnung.
</ResponseField>

<ResponseField name="synthesizedAudioUrl" type="string">
  Die URL des aus einer Texteingabe (TTS) synthetisierten Audios
</ResponseField>

<ResponseField name="webhookUrl" type="string">
  Die URL des Webhook-Endpunkts
</ResponseField>

### Eingaben

{
