Higgsfield veranstaltet eine [Cashback-Aktion auf die API-Ausgaben](https://higgsfield.ai). Wir werden nicht versuchen, Sie davon abzubringen.

Bringen Sie Ihren eigenen Higgsfield-Schlüssel zu Comfy Router, und Ihre Generierungen laufen über **Ihr** Higgsfield-Konto. Damit zählen sie als Ihre Higgsfield-Ausgaben, und welchen Wert diese Aktion für Sie hat, bleibt Ihnen erhalten. Sie bekommen weiterhin einen Endpoint, einen Client und dieselbe Anfrageform wie bei jedem anderen Modell auf Router.

<Note>
  Higgsfield ist Eigentümer der Aktion und ihrer Nutzungsbedingungen. Prüfen Sie das aktuelle Angebot auf deren Website, bevor Sie Ihre Planung darauf ausrichten.
</Note>

## Was sich ändert, wenn Sie einen eigenen Schlüssel mitbringen

| | Ihr Comfy-Schlüssel | Ihr Higgsfield-Schlüssel |
| --- | --- | --- |
| Abrechnung über | Ihre Comfy-Credits | Ihr Higgsfield-Konto |
| Comfy-Credits werden berechnet | Ja | **Keine** |
| Endpoint, Request-Body, Antwort | Identisch | Identisch |

Alles andere am Aufruf ist identisch. Sie ändern Ihren Code nicht, um zu wechseln: Sie speichern einen Schlüssel, und Router verwendet ihn.

<Steps>
  <Step title="Higgsfield-API-Schlüssel abrufen">
    Erstellen Sie einen Schlüssel in Ihrem [Higgsfield-Konto](https://higgsfield.ai). Higgsfield stellt ihn als **ID- und Secret-Paar** aus, und Comfy speichert ihn als einzelnen String `id:secret`. Behalten Sie den Doppelpunkt bei und teilen Sie den Wert nicht in zwei Felder auf.
  </Step>

  <Step title="Schlüssel in Comfy speichern">
    Öffnen Sie [**Provider keys**](https://platform.comfy.org/profile/provider-keys) in Ihrem Comfy-Profil, wählen Sie **Higgsfield** und fügen Sie den Wert `id:secret` ein.

    Ihr Schlüssel wird im Ruhezustand verschlüsselt und nach dem Speichern niemals von der API zurückgegeben. Router liest ihn nur, um Ihre eigenen Aufrufe zu signieren.
  </Step>

  <Step title="Comfy API-Schlüssel erstellen">
    Dies ist der Schlüssel, der Sie bei Comfy authentifiziert, getrennt vom Higgsfield-Schlüssel. Erstellen Sie ihn in [Ihrem Comfy-Workspace](https://platform.comfy.org/profile/api-keys) und legen Sie dann fest:

    ```bash
    export COMFY_API_KEY="comfyui-..."
    ```

    Bewahren Sie API-Schlüssel auf Ihrem Server oder in Ihrer lokalen Umgebung auf. Diese Beispiele sind für ein Terminal oder einen Server gedacht, nicht für JavaScript im Browser.
  </Step>

  <Step title="Modell ausführen">
    Kopieren Sie einen der Code-Snippets unten für Ihr ausgewähltes Modell und fügen Sie ihn ein.
  </Step>
</Steps>

## Modelle

<Tabs><Tab title="Kling 3.0 std">
    Ausgewogene Qualität und Geschwindigkeit. `duration` akzeptiert 3–15 Sekunden.

    <CodeGroup>

    ```bash cURL
    curl --max-time 660 \
      https://api.comfy.org/v2/models/higgsfield/higgsfield-kling-3-std \
      -H "X-API-Key: $COMFY_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "prompt": "A cinematic glass pavilion in a misty pine forest at sunrise",
        "duration": 5,
        "aspect_ratio": "16:9",
        "cfg_scale": 0.5,
        "sound": "on"
      }'
    ```

    ```python Python
    # Python 3.10+
    # Installieren: python -m pip install "comfy-sdk>=0.3.0"

    from comfy_sdk import Comfy

    # Comfy liest COMFY_API_KEY aus der Umgebung.
    with Comfy() as client:
        result = client.models.run(
            "higgsfield/higgsfield-kling-3-std",
            {
                "prompt": "A cinematic glass pavilion in a misty pine forest at sunrise",
                "duration": 5,
                "aspect_ratio": "16:9",
                "cfg_scale": 0.5,
                "sound": "on",
            },
            timeout=660.0,
        )

    print("video:", result["video"]["url"])
    ```

    ```typescript TypeScript
    // Node.js 22+
    // Installieren: npm install "@comfyorg/sdk@>=0.4.0" --save-dev tsx

    import { comfy } from "@comfyorg/sdk";

    type HiggsfieldResult = { video: { url: string } };

    const { data } = await comfy.models.run<HiggsfieldResult>(
      "higgsfield/higgsfield-kling-3-std",
      {
        prompt: "A cinematic glass pavilion in a misty pine forest at sunrise",
        duration: 5,
        aspect_ratio: "16:9",
        cfg_scale: 0.5,
        sound: "on",
      },
      { timeoutMs: 660_000 },
    );

    console.log("video:", data.video.url);
    ```

## Ergebnis lesen

`run` gibt das eigene Abschlussdokument von Higgsfield zurück. Die Download-URL steht unter `video.url`:

```json
{
  "status": "completed",
  "request_id": "0c4a9e17-5b82-4d66-9a3f-7c1e08b45d29",
  "video": { "url": "https://example.com/generated.mp4" }
}
```

Speichern Sie es umgehend:

```bash
curl --fail --location "PASTE_VIDEO_URL_HERE" --output out.mp4
```

Der Router fragt Higgsfield für Sie ab, daher erreichen Sie `queued` und `in_progress` nie. Sie erhalten das fertige Dokument oder einen Fehler. `nsfw`, `failed` und `canceled` sind die abschließenden Fehlerfälle; `failed` enthält Details in `error`.

## Hinweise

- **Die Validierung erfolgt, bevor Higgsfield aufgerufen wird.** Ein Request-Body außerhalb der veröffentlichten Grenzen wird mit `422` zurückgegeben, wobei das betroffene Feld genannt wird, und es wird nichts an den Upstream gesendet. Eine fehlerhafte Anfrage kostet Sie also nichts.
- **Ihr Schlüssel wird nur für Modelle verwendet, für die Sie einen Schlüssel besitzen.** Das Speichern eines Higgsfield-Schlüssels ändert nichts daran, wie ein anderer Anbieter auf Router abgerechnet wird.
- Vollständige Schemata für Requests und Responses zu jedem Modell finden Sie in der [Comfy Router-Referenz](/de/development/comfy-router/reference).
