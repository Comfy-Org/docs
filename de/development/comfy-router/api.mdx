Wählen Sie ein Modell, prüfen Sie dessen Schema und rufen Sie `POST /v2/models/{provider}/{model}` auf. Route und Authentifizierung bleiben über alle Modelle hinweg gleich. Jedes Modell akzeptiert einen eigenen nativen Request-Body und gibt ein eigenes natives Ergebnis zurück.
