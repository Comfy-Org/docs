Comfy Router berechnet den Listenpreis des Modellherstellers. Jeder Aufruf wird über Ihre Workspace-Credits abgerechnet, und 211 Credits = $1 USD.

<Info>
**Die Preise von Comfy Router finden Sie jetzt auf [router.comfy.org](https://router.comfy.org).** Dort können Sie aktuelle Preise prüfen und Modelle vergleichen.
</Info>

<Card title="Router-Preise auf router.comfy.org ansehen" icon="coins" href="https://router.comfy.org">
  Aktuelle Preise pro Modell für Comfy Router.
</Card>

Nicht veröffentlichte Preise bedeuten nicht, dass die Nutzung kostenlos ist.

Fakten zur Abrechnung pro Modell, etwa ob eine Ablehnung durch eine Richtlinie in Rechnung gestellt wird, entnehmen Sie dem Feld `billing` aus `GET /v2/models` oder der Antwort mit den Modelldetails. Dieses Feld enthält keine Preise. Wenn Sie einen bestimmten Aufruf bepreisen möchten, bevor Sie ihn ausführen, verwenden Sie `POST /v2/models/{provider}/{model}/estimate`. Siehe [Abrechnung](/de/development/comfy-router/billing#fakten-zur-modellabrechnung) und die [API-Referenz](/de/development/comfy-router/reference).
