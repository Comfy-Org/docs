## Benutzerdefinierte Builds auf Comfy Cloud

Verpacken Sie Ihren eigenen ComfyUI-Workflow als benutzerdefinierten Build, stellen Sie ihn auf Comfy Cloud bereit und rufen Sie ihn aus Ihrem Code auf.

<CardGroup cols={2}>
  <Card title="Einen Workflow bereitstellen" icon="cloud-arrow-up" href="/de/development/deploy/cloud-custom-builds">
    Erstellen Sie einen Build, veröffentlichen Sie ihn und starten Sie eine verwaltete Bereitstellung.
  </Card>
  <Card title="Compute auswählen" icon="microchip" href="/de/development/serverless/overview#change-the-gpu-or-region">
    Prüfen Sie die verfügbaren Regionen und GPU-Klassen, bevor Sie bereitstellen.
  </Card>
  <Card title="Einen bereitgestellten Workflow ausführen" icon="play" href="/de/development/deploy/cloud#einen-workflow-auf-einem-benutzerdefinierten-build-ausführen">
    Senden Sie einen Workflow im API-Format ab und laden Sie seine Ausgänge herunter.
  </Card>
  <Card title="Das SDK verwenden" icon="code" href="/de/development/api-development/sdks#comfy-api-deployment">
    Richten Sie das Python- oder TypeScript-SDK auf Ihre Bereitstellung aus.
  </Card>
</CardGroup>
