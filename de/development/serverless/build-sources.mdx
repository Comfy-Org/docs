Sie haben bereits einen Desktop-Snapshot oder einen Workflow? Nutzen Sie den passenden Weg unten, um einen Build zu starten, und prüfen Sie anschließend dessen Inhalt, bevor Sie ein Release erstellen.

## Comfy Desktop-Snapshot

Mit einem Snapshot übernehmen Sie die ComfyUI-Version, die Custom Nodes und die Python-Pakete einer Desktop-Instanz in einen Build.

1. Öffnen Sie in Comfy Desktop das Panel **Manage** der Instanz und wählen Sie **Snapshots** aus. Wählen Sie den Snapshot für die Umgebung aus, die Sie erstellen möchten, und klicken Sie auf die Schaltfläche **Export**. Wenn der aktuelle Zustand nicht aufgeführt ist, erstellen Sie zuerst einen manuellen Snapshot. Siehe [Schritte für Desktop-Snapshots](/de/installation/desktop/usage/snapshots#tab-snapshots-im-überblick).
2. Öffnen Sie den [Comfy API Build Wizard](https://platform.comfy.org/?onboarding=comfyapi) und importieren Sie die Snapshot-Datei.
3. Prüfen Sie den Inhalt des Builds und ergänzen oder korrigieren Sie fehlende Modelle oder Abhängigkeiten, bevor Sie ein Release erstellen.

![Comfy Desktop Snapshots-Tab mit hervorgehobener Export-Schaltfläche des ausgewählten Snapshots](/images/development/serverless/build-sources-desktop-snapshot.png)

## Workflow-JSON

Mit einer gespeicherten Workflow-Datei konfigurieren Sie einen Build im Build Wizard:

1. Öffnen Sie den [Comfy API Build Wizard](https://platform.comfy.org/?onboarding=comfyapi).
2. Ziehen Sie das Workflow-JSON in den Import-Schritt.
3. Prüfen Sie den Inhalt des Builds und ergänzen oder korrigieren Sie fehlende Modelle oder Abhängigkeiten, bevor Sie ein Release erstellen.

![Comfy API Build Wizard mit importiertem Workflow-JSON und Schritten zur Build-Einrichtung](/images/development/serverless/build-sources-workflow-import.png)

Der Wizard prüft den Workflow und schlägt Build-Einstellungen vor, bevor Sie fortfahren.
