ComfyUI läuft standardmäßig als HTTP-Server auf Ihrem Rechner. Sie können ihn programmatisch aufrufen, um Workflows abzusenden, Dateien hochzuladen, Ausgänge herunterzuladen und den Fortschritt zu überwachen, ganz ohne den Browser zu öffnen.

## Server starten

Wenn Sie ComfyUI starten, wird automatisch ein HTTP-Server unter `http://127.0.0.1:8188` gestartet.

Um ComfyUI als Headless-Server ohne Browser auszuführen:

<CodeGroup>
```bash
# Ohne Öffnen des Browsers ausführen
python main.py --disable-auto-launch
```

```bash
# Einen benutzerdefinierten Port angeben
python main.py --port 8288
```

```bash
# Auf allen Netzwerkschnittstellen lauschen (für Fernzugriff)
python main.py --listen 0.0.0.0
```
</CodeGroup>

<Tip>
  Eine vollständige Liste der Startparameter finden Sie mit `python main.py --help` oder in der [Referenz zu den Startparametern](/development/comfyui-server/startup-flags).
</Tip>

## So funktioniert der Server

Der Comfy-Server läuft auf dem [aiohttp-Framework](https://docs.aiohttp.org/), das wiederum [asyncio](https://pypi.org/project/asyncio/) verwendet.

Nachrichten vom Server an den Client werden als Socket-Nachrichten über die Methode `send_sync` des Servers gesendet, der eine Instanz von `PromptServer` ist (definiert in `server.py`). Sie werden von einem Socket-Event-Listener verarbeitet, der in `api.js` registriert ist. Siehe [Nachrichten](/development/comfyui-server/comms_messages).

Nachrichten vom Client an den Server werden mit der in `api.js` definierten Methode `api.fetchApi()` gesendet und von HTTP-Routen verarbeitet, die der Server bereitstellt. Siehe [Routen](/development/comfyui-server/comms_routes).

<Tip>
  Der Client übermittelt den gesamten Workflow (inklusive aller Widget-Werte), wenn Sie eine Anfrage in die Warteschlange einreihen.
  Änderungen, die Sie nach dem Senden einer Anfrage an die Warteschlange vornehmen, erhält der Server nicht.
  Wenn Sie das Verhalten des Servers während der Ausführung ändern möchten, benötigen Sie Routen.
</Tip>
