ComfyUI läuft standardmäßig als HTTP-Server auf Ihrem Rechner. Sie können es programmatisch aufrufen, um Workflows abzusenden, Dateien hochzuladen, Ausgänge herunterzuladen und den Fortschritt zu überwachen. Ganz ohne Browser.
