Ein API-Schlüssel ist Ihr Zugangsnachweis für die Dienste von Comfy Platform, darunter:

- [Cloud API](/development/cloud/overview): Comfy Cloud-Endpunkte programmatisch aufrufen
- [Partner Node API Integration](/development/comfyui-server/api-key-integration): kostenpflichtige Partner-Nodes in Ihren lokalen Workflows verwenden
- [Agent Tools / MCP](/de/agent-tools): über MCP eine Verbindung zu Comfy herstellen
- [Lokal bei ComfyUI anmelden](/de/interface/user#logging-in-with-an-api-key): sich mit einem API-Schlüssel statt per E-Mail authentifizieren

## Ihre API-Schlüssel verwalten

Nach der Anmeldung können Sie alle Ihre API-Schlüssel auf [platform.comfy.org](https://platform.comfy.org) anzeigen und verwalten.

- **Vorhandene Schlüssel anzeigen**: Name und Erstellungsdatum jedes Schlüssels sehen
- **Einen Schlüssel löschen**: Wenn ein Schlüssel kompromittiert ist oder nicht mehr benötigt wird, löschen Sie ihn sofort
- **Weitere Schlüssel erstellen**: Sie können mehrere API-Schlüssel für verschiedene Anwendungen haben

<Warning>
  API-Schlüssel werden bei der Erstellung nur einmal angezeigt. Speichern Sie ihn sofort an einem sicheren Ort. Wenn Sie einen Schlüssel verlieren, löschen Sie ihn und erstellen Sie einen neuen.
</Warning>

## Ihren API-Schlüssel verwenden

Sobald Sie einen API-Schlüssel besitzen, können Sie:

1. **Lokal bei ComfyUI anmelden**: Gehen Sie zu **Einstellungen → Benutzer** und wählen Sie die Anmeldung „Comfy API Key“
2. **Partner-Node-APIs aufrufen**: Fügen Sie den Schlüssel beim Senden von Workflows in `extra_data.api_key_comfy_org` ein
3. **Cloud API nutzen**: Fügen Sie den Schlüssel in den Request-Headern für Cloud API-Endpunkte ein

Teilen Sie Ihren API-Schlüssel aus Sicherheitsgründen niemals und checken Sie ihn nicht in die Versionsverwaltung ein.
