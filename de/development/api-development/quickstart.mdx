Führen Sie einen vollständigen Workflow aus Code aus und speichern Sie dessen Ausgabe als `first-result.png`. Dieses Beispiel erzeugt mit zwei integrierten Nodes ein **durchgehend blaues Bild mit 512 × 512 Pixeln**. Es überprüft die Authentifizierung, die Ausführung des Workflows und das Herunterladen der Ausgabe, ohne dass ein Modell, ein Eingabebild oder Custom Nodes erforderlich sind.

Um ein Bild zu generieren, indem Sie ein gehostetes Modell direkt aufrufen, beginnen Sie mit dem [Comfy Router Schnellstart](/de/development/comfy-router/quickstart).

Dieses Beispiel läuft auf Comfy Cloud. Weitere Hosting-Optionen, einschließlich Comfy API-Bereitstellungen und Self-Hosting, finden Sie unter [ComfyUI bereitstellen](/de/development/deploy/overview).

## Bevor Sie beginnen

- Einen [Comfy API-Schlüssel](/de/development/api-development/getting-an-api-key).
- Ein [kostenpflichtiges Comfy Cloud-Abonnement](/de/development/deploy/cloud). Der API-Zugriff auf Cloud-Workflows ist im kostenlosen Tarif nicht enthalten.
- Python 3.10 oder neuer bzw. Node.js 22.18 oder neuer für das TypeScript-Beispiel.

Diese Anleitung verwendet Comfy Cloud, das Standardziel der SDKs. Wenn Sie zuvor `COMFY_BASE_URL` festgelegt haben, heben Sie die Festlegung auf, um Cloud zu verwenden. Für eine bestehende Comfy API-Bereitstellung oder eine selbst gehostete Instanz siehe [Basis-URL wählen](/de/development/api-development/sdks#choosing-a-base-url).

## 1. Beispiel herunterladen

Erstellen Sie einen Ordner für das Beispiel. Laden Sie [workflow_api.json](/files/api-first-result/workflow_api.json) und das Skript für Ihre Sprache in diesen Ordner herunter:

- [Python: first_workflow.py](/files/api-first-result/first_workflow.py)
- [TypeScript: first_workflow.mts](/files/api-first-result/first_workflow.mts)

Der Workflow liegt bereits im API-Format vor. Node `"1"` erzeugt das blaue Bild und Node `"2"` speichert es. Die Skripte lesen die Ausgaben genau aus diesem SaveImage-Node, daher müssen Sie keine Node-ID suchen oder bearbeiten.

## 2. SDK installieren und API-Schlüssel festlegen

Öffnen Sie ein Terminal in dem Ordner, in dem Sie die Dateien gespeichert haben.

<CodeGroup>
```bash Python
python -m venv .venv
source .venv/bin/activate
python -m pip install comfy-sdk
```

```bash TypeScript
npm init -y
npm install @comfyorg/sdk
```
</CodeGroup>

Aktivieren Sie unter Windows die Python-Umgebung in PowerShell mit `.venv\Scripts\Activate.ps1`.

Legen Sie Ihren API-Schlüssel im selben Terminal fest:

<CodeGroup>
```bash macOS / Linux
export COMFY_API_KEY="comfyui-your-key"
```

```powershell Windows PowerShell
$env:COMFY_API_KEY = "comfyui-your-key"
```
</CodeGroup>

Bewahren Sie Ihren API-Schlüssel in Ihrer Serverumgebung auf. Fügen Sie ihn nicht in Browser-Code ein und committen Sie ihn nicht in die Versionsverwaltung.

## 3. Ausführen und Ergebnis ansehen

<CodeGroup>
```bash Python
python first_workflow.py
```

```bash TypeScript
node first_workflow.mts
```
</CodeGroup>

Das Skript sendet den Workflow ab, wartet auf dessen Fertigstellen und lädt das Bild herunter. Wenn es `Saved` gefolgt von einem Pfad ausgibt, öffnen Sie `first-result.png` an dieser Stelle. Sie sollten ein einfarbig blaues Quadrat sehen. Wenn Sie das Beispiel erneut ausführen, wird diese lokale Datei ersetzt.

<Note>
  Dies ist eine Prüfung der Workflow-Verbindung. Es wird kein generatives Modell verwendet. Dieselben Schritte zum Absenden, Warten und Herunterladen funktionieren auch mit Ihren eigenen Generierungs-Workflows.
</Note>

### Wenn die Anfrage fehlschlägt

- **Fehlender Schlüssel oder nicht autorisiert:** Prüfen Sie, ob `COMFY_API_KEY` in dem Terminal gesetzt ist, in dem das Skript läuft, und ob er einen aktiven Schlüssel enthält.
- **Zugriffs- oder Credit-Fehler:** Prüfen Sie Ihr Cloud-Abonnement und Ihre verfügbaren Credits, bevor Sie es erneut versuchen.
- **Workflow-Datei nicht gefunden:** Behalten Sie `workflow_api.json` im selben Verzeichnis wie das heruntergeladene Skript.
- **Unerwarteter Endpunkt:** Prüfen Sie `COMFY_BASE_URL`. Entfernen Sie die Variable für dieses Cloud-Beispiel.
- **Eine Aufgabe schlägt bei einem Comfy API-Deployment fehl:** Der Fehler kann eine Kategorie enthalten, die den Grund angibt. Siehe [Fehlerkategorien](/de/development/api-development/sdks#failure-categories).

Zur Fehlerbehandlung und zum Fortschritt von Aufgaben siehe den [SDK-Leitfaden](/de/development/api-development/sdks).

## 4. Eigenen Generierungsworkflow ausführen

Erstellen oder wählen Sie einen Workflow im ComfyUI-Editor aus, führen Sie ihn dort erfolgreich aus und [exportieren Sie ihn im API-Format](/de/development/api-development/workflow-api-format). Ersetzen Sie `workflow_api.json` durch Ihren Export und aktualisieren Sie `get_outputs("2")` in Python bzw. `getOutputs("2")` in TypeScript auf die Node-ID des SaveImage-Node Ihres Workflows. Prüfen Sie, ob die Zielumgebung die Modelle und Custom Nodes enthält, die Ihr Workflow verwendet.

Um Workflows mit Ihren eigenen Modellen und Custom Nodes auszuführen, siehe [Einen Workflow in einem benutzerdefinierten Build ausführen](/de/development/deploy/cloud#einen-workflow-auf-einem-benutzerdefinierten-build-ausführen). Um Workflow-Eingänge zu ändern, Dateien hochzuladen oder den Fortschritt zu verfolgen, fahren Sie mit [Comfy SDKs](/de/development/api-development/sdks) fort.
