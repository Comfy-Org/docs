Workflows, die über die Comfy Cloud API übermittelt werden, nutzen dieselben Credits und Parallelitätslimits wie andere Cloud-Workflows.

## Credits und Nutzung

API-Anfragen greifen auf dasselbe monatliche Credit-Kontingent zu wie die Comfy Cloud Web-UI. Es gibt keinen separaten API-Credit-Pool. Die in jeder Stufe enthaltenen Credits, die Aufladeoptionen und die Laufzeitobergrenzen pro Workflow gelten für API-Aufträge genauso wie für UI-Aufträge.

Die monatlichen Credit-Mengen und Aufladeoptionen finden Sie auf der [Preisseite](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api). Aufladungen können Sie in Ihrem Account-Dashboard erwerben.

## Parallelitätslimits {#concurrency-limits}

Sie können mehrere Workflows absenden, ohne auf den Abschluss vorheriger Aufträge zu warten. Aufträge laufen parallel bis zum Limit Ihres Abonnements:

| Tarif    | Parallele Workflows |
| :------- | :------------------ |
| Standard | 1                   |
| Creator  | 3                   |
| Pro      | 5                   |

Team-Tarife führen pro Mitglied mehr parallele Workflows aus als Pro. Unter [platform.comfy.org](https://platform.comfy.org) sehen Sie die Parallelität Ihres Kontos. Zusätzliche Aufträge werden in die Warteschlange eingereiht und ausgeführt, sobald Slots frei werden.

Ist die Warteschlange voll, versuchen es die SDKs innerhalb eines begrenzten Kontingents erneut, bevor sie `QueueFull` auslösen.

Bei Team- und Enterprise-Tarifen gilt die Parallelität pro Mitglied: Jedes Mitglied im Workspace hat sein eigenes Parallelitätslimit, sodass laufende Aufträge eines Mitglieds nie die eines anderen blockieren.

<Info>
  Mehr als einen Auftrag gleichzeitig auszuführen wird nur über die API unterstützt. Die Comfy Cloud UI führt pro Person jeweils einen Workflow aus, und im Editor eingereihte Workflows laufen der Reihe nach ab. Details zu den Abonnements finden Sie unter [Preispläne](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api).
</Info>

## Laufzeit- und Warteschlangenlimits {#runtime-and-queue-limits}

Jeder Cloud-Workflow hat eine maximale Laufzeit. Ein Auftrag, der das Limit überschreitet, wird automatisch abgebrochen:

| Tarif    | Maximale Laufzeit |
| :------- | :---------------- |
| Standard | 30 Minuten        |
| Creator  | 30 Minuten        |
| Pro      | 1 Stunde          |

Sie können bis zu 100 Workflows gleichzeitig in der Warteschlange haben. Um das Parallelitätslimit eines Teams zu erhöhen, [kontaktieren Sie den Support](https://support.comfy.org/).

## Bestehende v1-Integrationen

Die veraltete [v1 Cloud API](/development/cloud/overview) läuft ebenfalls gegen Comfy Cloud. Verwenden Sie sie für bestehende Integrationen oder Cloud-Funktionen, die in der [Comfy API v2](/api-reference/v2/overview) noch nicht verfügbar sind. Ausführbare Beispiele finden Sie in der veralteten [Cloud API Reference](/de/development/cloud/api-reference).
