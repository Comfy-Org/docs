Comfy Cloud ist eine vollständig verwaltete, jederzeit verfügbare ComfyUI-Umgebung. Erstellen Sie Workflows im Browser oder führen Sie sie über das SDK aus. Es gibt keinen Build und kein Deployment, das Sie anlegen müssen.

<Note>
  Neu bei Comfy Cloud? Beginnen Sie mit der [Einführung in Comfy Cloud](/de/get_started/cloud). Dieser Schnellstart zeigt, wie Sie Workflows aus einer App heraus ausführen.
</Note>

## Schnellstart

Erfordert ein kostenpflichtiges Abonnement, einen [API-Schlüssel](/de/development/api-development/getting-an-api-key) und einen Workflow im API-Format. Die [Comfy SDKs](/de/development/api-development/sdks) verwenden standardmäßig Cloud als Ziel.

<Steps>
  <Step title="API-Schlüssel erstellen">
    Erstellen Sie einen API-Schlüssel unter [platform.comfy.org](https://platform.comfy.org). Details finden Sie unter [Getting an API Key](/de/development/api-development/getting-an-api-key).
  </Step>
  <Step title="SDK installieren">
    <CodeGroup>
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    </CodeGroup>
  </Step>
  <Step title="Workflow im API-Format exportieren">
    Speichern Sie Ihren getesteten Workflow im Cloud-Editor mit `File → Export Workflow (API)` als `workflow_api.json`. Siehe [Workflow API Format](/de/development/api-development/workflow-api-format).
  </Step>
  <Step title="Workflow ausführen">
    <CodeGroup>
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")  # Comfy Cloud ist das Standardziel

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." }); // Comfy Cloud ist das Standardziel

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    </CodeGroup>

    `"9"` ist die ID des Ausgabe-Nodes. Eingänge, Fortschritt und Fehlerbehandlung finden Sie im [SDK-Leitfaden](/de/development/api-development/sdks).
  </Step>
</Steps>

Derselbe SDK-Code kann auch [Comfy API Deployments](/development/serverless/quickstart) und [selbst gehostetes ComfyUI](/de/development/deploy/self-hosting) ansprechen. Siehe [Workflows ausführen](/de/development/run-workflows/overview).
