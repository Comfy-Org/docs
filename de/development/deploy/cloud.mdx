Sie können einen Workflow, den Sie im Comfy Cloud-Editor erstellt haben, mit den [Comfy SDKs](/de/development/api-development/sdks) aus Ihrer eigenen Anwendung heraus ausführen, etwa aus einem Backend-Dienst oder einem Batch-Skript. Comfy Cloud führt Workflows auf einem Standard-Build mit einem Standardsatz an Custom Nodes aus. Wenn ein Workflow Custom Nodes oder Modelle benötigt, die im Standard-Build nicht enthalten sind, erstellen Sie einen benutzerdefinierten Build: ein Paket Ihrer eigenen Custom Nodes und Modelle, das Comfy Cloud für Sie ausführt. Diese Seite zeigt, wie Sie einen Workflow über die API auf dem Standard-Build ausführen und anschließend denselben Code auf einen benutzerdefinierten Build ausrichten.

## Bevor Sie beginnen

Um Comfy Cloud aus Ihrem Code aufzurufen, stellen Sie sicher, dass Folgendes vorhanden ist:

- **Ein kostenpflichtiges Comfy Cloud-Abonnement**
- **Ein Workflow, der im Comfy Cloud-Editor ausgeführt wird**: Testen Sie ihn im Editor, bevor Sie ihn aus Ihrem Code ausführen. Wenn er Custom Nodes oder Modelle benötigt, die in der Standardversion nicht enthalten sind, [erstellen Sie zuerst einen benutzerdefinierten Build](/de/development/deploy/cloud-custom-builds).
- **Python 3.10 oder neuer bzw. Node 22 oder neuer**: Das SDK, das Sie installieren, benötigt eine dieser Versionen.

Wenn Sie Comfy Cloud noch nicht verwendet haben, beginnen Sie mit [Comfy Cloud](/de/get_started/cloud).

## Einen Workflow im Standard-Build ausführen

Der Standard-Build führt jeden Workflow aus, der ausschließlich Custom Nodes verwendet, die Comfy Cloud unterstützt. Um einen Workflow aus Ihrem Code heraus auszuführen, erstellen Sie einen API-Schlüssel, installieren das SDK und exportieren den Workflow im API-Format.

<Steps>
  <Step title="API-Schlüssel erstellen">
    Ihre Anwendung sendet den Schlüssel bei jeder Anfrage mit. Erstellen Sie daher einen Schlüssel für Ihre Anwendung auf der Developer Platform.

    1. Melden Sie sich bei [platform.comfy.org](https://platform.comfy.org) an und klicken Sie anschließend auf **API Keys**.
    2. Klicken Sie auf **New API key**, geben Sie einen Namen ein und klicken Sie dann auf **Generate key**.
    3. Kopieren Sie den Schlüssel und bewahren Sie ihn an einem sicheren Ort auf. Die Developer Platform zeigt ihn nur einmal an.

    Der Schlüssel beginnt mit `comfyui-`. Wie Sie Schlüssel verwalten, erfahren Sie unter [Getting an API Key](/de/development/api-development/getting-an-api-key).
  </Step>
  <Step title="SDK installieren">
    <CodeGroup>
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    </CodeGroup>
  </Step>
  <Step title="Workflow im API-Format exportieren">
    Das SDK sendet das API-Format eines Workflows, nicht die Datei, die der Editor speichert.

    - Öffnen Sie den Workflow im Comfy Cloud Editor, wählen Sie **File** > **Export (API)** und speichern Sie die Datei als `workflow_api.json`.

    Was die Datei enthält, erfahren Sie unter [Workflow API Format](/de/development/api-development/workflow-api-format).
  </Step>
  <Step title="Workflow ausführen">
    Das SDK sendet Anfragen an Comfy Cloud, sofern Sie keine andere Basis-URL festlegen. Übergeben Sie daher nur Ihren API-Schlüssel:

    <CodeGroup>
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." });

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    </CodeGroup>

    - Ersetzen Sie `"9"` durch die ID des Ausgabe-Nodes in Ihrer `workflow_api.json`.
    - `run()` wartet, bis die Aufgabe abgeschlossen ist, und anschließend schreibt der Code die Ausgaben auf die Festplatte.

    Wie Sie Eingänge festlegen, den Fortschritt verfolgen und Fehler behandeln, erfahren Sie unter [Comfy SDKs](/de/development/api-development/sdks).
  </Step>
</Steps>

## Einen Workflow auf einem benutzerdefinierten Build ausführen

Wenn Sie einen benutzerdefinierten Build bereitstellen, erhalten Sie ein Deployment mit eigener URL. Ihr Code aus dem vorherigen Abschnitt läuft auf dem Deployment, sobald Sie die Basis-URL ändern.

<Warning>
  Ein Deployment verursacht GPU-Zeit, solange seine Worker laufen, und Speicherkosten, bis Sie es löschen. Wenn Sie mit den Tests fertig sind, stoppen oder löschen Sie es. Siehe [Bereinigen](/development/serverless/overview#clean-up).
</Warning>

<Steps>
  <Step title="Build erstellen und bereitstellen">
    Folgen Sie [Benutzerdefinierte Builds](/de/development/deploy/cloud-custom-builds), um einen Build aus Ihrem Workflow zu erstellen und bereitzustellen.
  </Step>
  <Step title="Deployment-URL kopieren">
    1. Öffnen Sie auf der Developer Platform die Seite des Deployments.
    2. Warten Sie, bis der Status des Deployments **Bereit** lautet.
    3. Kopieren Sie unter **Run via API** die **Deployment URL**.

    Eine Deployment-URL hat die Form `https://dep-<id>.run.comfy.app`.
  </Step>
  <Step title="Basis-URL festlegen">
    Legen Sie `COMFY_BASE_URL` auf die Deployment-URL fest:

    ```bash
    export COMFY_BASE_URL="https://dep-<id>.run.comfy.app"
    ```
  </Step>
  <Step title="Workflow ausführen">
    Führen Sie den Code aus [Einen Workflow auf dem Standard-Build ausführen](#einen-workflow-im-standard-build-ausführen) mit Ihrem API-Schlüssel aus. Das SDK sendet die Aufgabe nun an Ihr Deployment.
  </Step>
</Steps>

<Tip>
  Um das Deployment zuerst in einem Terminal zu testen, führen Sie aus:

  ```bash
  comfy deploy run --deployment <deployment-id> --workflow workflow_api.json
  ```
</Tip>
