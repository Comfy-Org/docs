Selbst hosten bedeutet, ComfyUI selbst zu betreiben und als API anzusprechen. Sie verwalten die Hardware, die Modelle und die Custom Nodes und erhalten dafür die volle Kontrolle: jede GPU, jedes Modell, jedes Node-Paket, und Ihre Daten verlassen Ihre Infrastruktur nie.

ComfyUI läuft standardmäßig als HTTP-Server, daher ist jede funktionierende Installation bereits ein API-Endpunkt. Die folgenden Optionen unterscheiden sich nur darin, wo diese Installation liegt.

## Eigene Hardware

Das einfachste Deployment ist der Rechner vor Ihnen. Installieren Sie ComfyUI, und es stellt sofort `http://127.0.0.1:8188` bereit:

- [Manuelle Installation](/de/installation/manual_install) für Linux, macOS und Windows und die Standardwahl für Server
- [Comfy Desktop](/de/installation/desktop/overview) oder der [portable Windows-Build](/de/installation/comfyui_portable_windows) für die lokale Entwicklung

Für den Headless-Betrieb (ohne Browser) oder um auf einer anderen als der Standardadresse zu lauschen, siehe die [Server-Startparameter](/de/development/comfyui-server/startup-flags). Zum Beispiel:

```bash
python main.py --listen 0.0.0.0 --port 8188
```

<Warning>
  Der ComfyUI-Server hat standardmäßig keine Authentifizierung. Binden Sie ihn nur in einem vertrauenswürdigen Netzwerk an eine Nicht-Loopback-Adresse, oder schalten Sie einen Reverse-Proxy mit Authentifizierung davor.
</Warning>

## GPU-Cloud-Anbieter

Wenn Sie keine eigene GPU besitzen, können Sie eine mieten und ComfyUI darauf betreiben. Häufig von der Community genutzte Anbieter sind:

- **[Runpod](https://www.runpod.io)**: GPU-Pods mit vorkonfigurierten ComfyUI-Vorlagen aus der Community.
- **[Vast.ai](https://vast.ai)**: ein GPU-Marktplatz; auch hier gibt es ComfyUI-Vorlagen aus der Community.

Bei diesen Anbietern starten Sie typischerweise von einer Vorlage oder einem Image aus der Community und fügen dann Ihre Modelle und Custom Nodes hinzu. Das Ergebnis ist ein normales selbst gehostetes ComfyUI mit einer öffentlichen URL oder einem SSH-Tunnel davor.

<Note>
  Diese Vorlagen werden von der Community gepflegt und nicht vom ComfyUI-Team veröffentlicht oder unterstützt. Prüfen Sie, was eine Vorlage installiert, bevor Sie Zugangsdaten oder private Modelle darauf verwenden.
</Note>

Wenn Sie eine verwaltete Version dieses Workflows möchten, folgen Sie [Custom Builds](/de/development/deploy/cloud-custom-builds), um ihn auf Comfy Cloud zu erstellen und bereitzustellen.

## Docker-Images aus der Community

<DockerNotice />

Ein containerisiertes ComfyUI verhält sich wie jede andere selbst gehostete Installation: Geben Sie den Server-Port frei und sprechen Sie es wie gewohnt an.
