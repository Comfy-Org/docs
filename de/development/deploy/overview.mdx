Sie können Ihre ComfyUI Workflows auf Comfy Cloud, in Ihrer eigenen Comfy API-Bereitstellung oder auf einem Server ausführen, den Sie selbst verwalten. Comfy Cloud und Comfy API laufen auf Comfy GPUs und benötigen daher keine GPU auf Ihrem Computer. Wählen Sie die Option, die zu Ihrem Workflow passt, und beginnen Sie mit der zugehörigen Karte.

<CardGroup cols={2}>
  <Card title="Auf Comfy Cloud bereitstellen" icon="cloud" href="/de/development/deploy/cloud">
    Führen Sie Workflows aus Ihrem Code auf dem Standard-Build von Comfy Cloud aus oder auf einem benutzerdefinierten Build.
  </Card>
  <Card title="Benutzerdefinierte Builds auf Comfy Cloud" icon="puzzle-piece" href="/de/development/deploy/cloud-custom-builds">
    Führen Sie Workflows, die eigene Custom Nodes und Modelle benötigen, im Editor von Comfy Cloud aus, mit einem Build, den Sie in Ihrem Browser erstellen.
  </Card>
  <Card title="Deployments verwalten" icon="cloud-arrow-up" href="/de/development/serverless/overview">
    Veröffentlichen Sie Build-Versionen, ändern Sie GPUs und Worker und rufen Sie ein Deployment aus Ihrer Anwendung auf.
  </Card>
  <Card title="Selbst hosten" icon="server" href="/de/development/deploy/self-hosting">
    Führen Sie ComfyUI auf einer Maschine aus, die Sie selbst verwalten, und stellen Sie es mit `--listen` in Ihrem Netzwerk bereit.
  </Card>
</CardGroup>

Um eine dieser Optionen aus Ihrem eigenen Code aufzurufen, senden Sie den Workflow im [API-Format](/de/development/api-development/workflow-api-format).

## Aus der ComfyUI-App bereitstellen

In ComfyUI auf Ihrem Computer oder in Comfy Desktop startet die Karte **In Comfy API bereitstellen** einen Build aus dem geöffneten Workflow.

<Warning>
  Das Veröffentlichen einer Version ist kostenlos. Wenn der Build abgeschlossen ist, zeigt die Zeile **Serverless-Build** eine Schaltfläche **Bereitstellen**. Das Bereitstellen kostet Speicher ab dem Zeitpunkt der Bereitstellung sowie GPU-Zeit, solange ein Worker läuft. Der Bereitstellungsdialog zeigt die geschätzten Kosten an, bevor Sie bestätigen.
</Warning>

<Steps>
  <Step title="Menü „Workflow-Aktionen“ öffnen">
    Klicken Sie in der **oberen Leiste** mit der rechten Maustaste auf den Tab des Workflows. Sie können auch auf die Schaltfläche **Workflow-Aktionen** oben links auf dem **Canvas** klicken.

    ![Geöffnetes Menü „Workflow-Aktionen“ von einem Workflow-Tab aus, mit „In Comfy API bereitstellen“ und dem NEW-Badge unterhalb von Export (API)](/images/development/deploy/deploy-to-comfy-api.png)
  </Step>
  <Step title="„In Comfy API bereitstellen“ auswählen">
    Wählen Sie **In Comfy API bereitstellen** aus. Der Eintrag ist mit **NEW** markiert. Die Karte **In Comfy API bereitstellen** wird geöffnet und zählt die Node-Pakete, Modelle und Node-Klassen, die der Workflow verwendet.

    ![Karte „In Comfy API bereitstellen“ mit einem Produktvideo, den Anzahlen von Node-Paketen, Modellen und Node-Klassen sowie der Schaltfläche „Auf der Plattform bereitstellen“](/images/development/deploy/deploy-api-ui.png)
  </Step>
  <Step title="Auf der Developer Platform fortfahren">
    Klicken Sie auf **Auf der Plattform bereitstellen**. Die Developer Platform unter [platform.comfy.org](https://platform.comfy.org) wird in einem neuen Tab geöffnet.
  </Step>
</Steps>

Auf der Developer Platform erstellen Sie einen Build aus dem Workflow, veröffentlichen eine Version und stellen sie bereit. [Einen Build starten](/de/development/serverless/overview#einen-build-aus-comfy-desktop-einer-workflow-datei-oder-comfyui-starten) behandelt das Starten eines Builds aus einer Workflow-Datei, und [Auf Comfy Cloud bereitstellen](/de/development/deploy/cloud#einen-workflow-auf-einem-benutzerdefinierten-build-ausführen) behandelt das Aufrufen der Bereitstellung aus Ihrem Code.

## Deployment aus dem Cloud-Editor ausführen

Wie Sie ein Deployment aus dem Editor von Comfy Cloud erstellen, Ihre Workflows darauf ausführen und es stoppen oder löschen, erfahren Sie unter [Benutzerdefinierte Builds zu Comfy Cloud hinzufügen](/de/development/deploy/cloud-custom-builds).

## Workflows aus Ihrer Anwendung ausführen

Wenn ein Deployment **Bereit** ist, lesen Sie [Workflows ausführen](/de/development/run-workflows/overview), um es aus Ihrer Anwendung aufzurufen. Die [Comfy SDKs](/de/development/api-development/sdks) funktionieren mit Comfy Cloud und mit Ihren Deployments. Ein selbst gehostetes ComfyUI benötigt den [API-Proxy](/de/development/comfyui-server/api-proxy), um Comfy API v2 bereitzustellen.
