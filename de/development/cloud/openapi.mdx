# Comfy Cloud API-Spezifikation

Diese Seite bietet die vollständige OpenAPI 3.0-Spezifikation für die Comfy Cloud API.

<Note>
  **Abonnement erforderlich:** Das Ausführen von Workflows über die API erfordert ein aktives Comfy Cloud-Abonnement. Weitere Informationen finden Sie unter [Preispläne](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api).
</Note>

## Die Spezifikation verwenden

Die OpenAPI-Spezifikation können Sie für folgende Zwecke nutzen:

- **Client-Bibliotheken generieren** in jeder Sprache mit Tools wie [OpenAPI Generator](https://openapi-generator.tech/)
- **In API-Tools importieren** wie Postman, Insomnia oder Paw
- **Dokumentation generieren** mit Tools wie Redoc oder Swagger UI
- **Anfragen validieren** in Ihrer Anwendung

## Authentifizierung

Alle API-Anfragen erfordern einen API-Schlüssel, der im Header `X-API-Key` übergeben wird.

### API-Schlüssel erhalten

Schritt-für-Schritt-Anweisungen mit Screenshots finden Sie unter [API-Schlüssel erhalten](/de/development/api-development/getting-an-api-key).

### API-Schlüssel verwenden

```yaml
X-API-Key: your-api-key
```

## WebSocket-Verbindung

Für Echtzeit-Aktualisierungen stellen Sie eine Verbindung zum WebSocket-Endpunkt her:

```
wss://cloud.comfy.org/ws?clientId={uuid}&token={api_key}
```

Nachrichtentypen und deren Verarbeitung finden Sie in der [Cloud API-Referenz](/de/development/cloud/api-reference#websocket-for-real-time-progress).
