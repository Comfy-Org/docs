## Comfy Cloud abonnieren

Sie können Comfy Cloud ohne Abonnement durchsuchen. Zum Ausführen von Workflows benötigen Sie einen kostenpflichtigen Tarif.

Der Dialog **Plan auswählen** bietet zwei Bereiche:

- **Für den persönlichen Gebrauch**: Einzeltarife (etwa Standard, Creator und Pro) mit einer festen Menge monatlicher Credits.
- **Für Teams**: ein Team-Tarif für den Workspace. Die Menge der monatlichen Credits legen Sie mit einem Schieberegler fest. Höhere Credit-Mengen können einen größeren Rabatt enthalten.

Die jährliche Abrechnung ist pro Monat in der Regel günstiger als die monatliche.

1. Rufen Sie [cloud.comfy.org](https://cloud.comfy.org/?utm_source=docs) auf und melden Sie sich an.
2. Öffnen Sie das Profil-Menü und klicken Sie auf **Tarife & Preise** oder auf **Abonnieren**.
3. Wählen Sie in **Plan auswählen** den Bereich **Für den persönlichen Gebrauch** oder **Für Teams**.

<Tabs>
  <Tab title="Für den persönlichen Gebrauch">
    Persönliche Tarife sind für die individuelle Nutzung gedacht. Wählen Sie einen benannten Tarif mit einer festen Menge monatlicher Credits.

    1. Wählen Sie einen Abrechnungszyklus: **Jährlich** oder **Monatlich**.
    2. Wählen Sie Ihren Tarif und klicken Sie auf **Abonnieren**.
    3. Prüfen Sie **Zahlung bestätigen**, fügen Sie bei Bedarf eine Zahlungsmethode hinzu und klicken Sie dann auf **Abonnieren** für den jeweiligen Tarif.
  </Tab>
  <Tab title="Für Teams">
    Team-Tarife gelten für Ihren Workspace. Sie legen fest, wie viele monatliche Credits der Workspace erhält.

    1. Wählen Sie einen Abrechnungszyklus: **Jährlich** oder **Monatlich**.
    2. Ziehen Sie den Credit-Schieberegler, um die Menge der monatlichen Credits festzulegen.
    3. Klicken Sie auf **Team-Jahresabo abonnieren** oder **Team-Monatsabo abonnieren**.
    4. Prüfen Sie **Zahlung bestätigen**, fügen Sie bei Bedarf eine Zahlungsmethode hinzu und klicken Sie dann auf **Abonnieren** für den jeweiligen Tarif.
  </Tab>
</Tabs>

<Note>
Tarifpreise, Credit-Mengen und Rabattsätze können sich ändern. Verwenden Sie die Beträge, die in **Plan auswählen** oder auf [comfy.org/cloud/pricing](https://www.comfy.org/cloud/pricing) angezeigt werden.
</Note>

## Promo-Code einlösen

Wenn die Kasse ein Feld **Promo-Code** anzeigt, geben Sie Ihren Code ein und lösen Sie ihn ein, bevor Sie bezahlen. Ein gültiger Code aktualisiert den Gesamtbetrag. Promo-Codes können ablaufen oder Nutzungsgrenzen haben.

## Verlängerung des Abonnements

Ihr Abonnement verlängert sich automatisch am selben Tag und zur selben Uhrzeit wie bei der ersten Buchung. Monatliche Tarife verlängern sich jeden Monat, jährliche Tarife jedes Jahr.

Jährliche Tarife erhalten ihre Credits für das gesamte Jahr im Voraus. Alle Comfy Cloud Abonnement-Tarife verlängern sich automatisch, sofern Sie Ihren Plan nicht zur Kündigung vormerken.
