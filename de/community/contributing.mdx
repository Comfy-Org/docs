Wir freuen uns über Beiträge jeder Art, und Sie müssen keinen Code schreiben, um zu helfen.

## Beitragen

- **Workflow teilen**: Veröffentlichen Sie einen Workflow, den Sie erstellt haben, damit andere Nutzer ihn ausführen und daraus lernen können.
- **Custom Node entwickeln**: Erstellen Sie einen Node und veröffentlichen Sie ihn in der [Comfy Registry](/de/registry/overview).
- **Node-Dokumentation verbessern**: Die Dokumentation der integrierten Nodes liegt im [embedded-docs-Repository](https://github.com/Comfy-Org/embedded-docs), und Custom Nodes können eigene [Hilfeseiten](/de/custom-nodes/help_page) mitliefern.
- **Fehler melden oder Funktion vorschlagen**: Erstellen Sie ein Issue im [ComfyUI-Repository](https://github.com/Comfy-Org/ComfyUI/issues).
- **Fragen beantworten**: Helfen Sie anderen Nutzern in den Kanälen, die unter [Community-Links](/de/community/links) aufgeführt sind.

Auf der [GitHub-Organisation Comfy-Org](https://github.com/Comfy-Org) können Sie alles durchsuchen, was das Projekt pflegt.
