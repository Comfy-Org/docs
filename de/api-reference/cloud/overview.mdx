<Warning>
  **Experimentelle API:** Diese API ist experimentell und kann sich ändern. Endpunkte, Anforderungs- und Antwortformate sowie das Verhalten können ohne Vorankündigung geändert werden.
</Warning>

Die Comfy Cloud API bietet programmatischen Zugriff, um Workflows auf der Comfy-Cloud-Infrastruktur auszuführen.

<Note>
  **Abonnement erforderlich:** Der API-Zugriff ist in den Tarifen **Standard**, **Creator** und **Pro** verfügbar. Der kostenlose Tarif enthält keinen API-Zugriff. Details finden Sie unter [Preispläne](https://www.comfy.org/cloud/pricing?utm_source=docs).
</Note>

## Endpunkt-Kategorien

| Kategorie | Beschreibung |
|----------|-------------|
| Workflow | Workflows zur Ausführung absenden |
| Aufgabe | Aufgabenstatus überwachen und die Warteschlange verwalten |
| Asset | Dateien hochladen und herunterladen |
| Modell | Verfügbare KI-Modelle durchsuchen |
| Node | Informationen zu verfügbaren Nodes abrufen |
| Benutzer | Kontoinformationen und persönliche Daten |
| System | Serverstatus und Zustandsprüfungen |
