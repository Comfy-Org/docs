## Über FLUX.3 [klein]

FLUX.3 [klein] ist das Open-Weights-Bildmodell FLUX.3 von Black Forest Labs für lokales ComfyUI: Text zu Bild und instruktionsgesteuerte Bildbearbeitung in einer Familie, mit einem vollständigen Checkpoint und einer schrittweise destillierten Variante für schnellere Läufe mit 4–16 Schritten. Die Gewichte sind auf Hugging Face unter der FLUX Kommunity License verfügbar. Einmal herunterladen, auf Ihrer eigenen GPU ausführen: kein API-Schlüssel und keine Credits pro Bild.

Sie benötigen stattdessen den gehosteten Weg? FLUX.3 läuft auch als Partner Node über [FLUX 3 Image](/de/tutorials/partner-nodes/black-forest-labs/flux-3-image) (Abrechnung pro Bild). Verwenden Sie die lokalen klein-Gewichte auf Ihrer GPU; verwenden Sie den Partner Node, wenn Sie das gehostete Modell ohne Download möchten.

**Modell-Highlights:**

- Text zu Bild und Bildbearbeitung mit denselben Gewichten; Bearbeitungen benötigen einen Instruktions-Prompt plus Referenzbilder
- Zwei Checkpoints: das vollständige FLUX 3 Image Klein und Distilled für Guidance-freies Sampling in 4–16 Schritten
- Multi-Referenz-Prompting über `<ref_image_0>`, `<ref_image_1>` und so weiter
- Optionaler Qwen3.5 9B Prompt-Upsampler, der kurze Anfragen vor der Generierung zu vollständigen Bildbeschreibungen erweitert
- Einzeldatei-Checkpoints in bf16, int8 (convrot) und nvfp4, mit einem Qwen3-VL-4B Text Encoder und dem FLUX.2 VAE

**Lizenz**: [FLUX Kommunity License](https://huggingface.co/black-forest-labs/flux-3-image-klein-comfy/blob/main/LICENSE.md)

**Versionsanforderung**: FLUX 3 Klein-Vorlagen benötigen ComfyUI 0.41.0 oder neuer (im 0.41.1-Backport enthalten, ComfyUI#17070).

## FLUX 3 Image Klein Workflows

### FLUX 3 Image Klein: Text zu Bild {#image_flux3_klein_t2i}

Generieren Sie ein Bild allein aus einem Prompt, ohne Eingabedateien. Der Workflow ist ein Subgraph: Öffnen Sie ihn, um die Loader, den Sampler und die Größe des Canvas zu erreichen.

<img src="https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/templates/image_flux3_klein_t2i-1.webp" alt="Vorschau des Workflows FLUX 3 Image Klein Text zu Bild" />

1. Geben Sie Ihren Prompt in das Widget für den positiven Prompt des Subgraph ein
2. Legen Sie `width` und `height` fest oder wählen Sie ein Format aus `ResolutionSelector` (standardmäßig 1:1 quadratisch)
3. Passen Sie `steps` (standardmäßig 50) und `cfg` (standardmäßig 3.5) an
4. Der Prompt-Upsampler ist standardmäßig aktiv, daher wird ein kurzer Prompt vor dem Sampling vom Qwen3.5 9B Upsampler erweitert. Schalten Sie `enable_prompt_upsampler` aus, um stattdessen aus Ihren eigenen Worten zu generieren
5. Klicken Sie auf **Queue**. Das Bild wird vom Node `SaveImage` in `ComfyUI/output/` gespeichert

### FLUX 3 Image Klein Distilled: Text zu Bild {#image_flux3_klein_distilled_t2i}

Generieren Sie mit dem schrittweise destillierten Checkpoint ein Bild aus einem Prompt. Er läuft in 16 Schritten ohne Guidance. Prompt-Upsampling ist standardmäßig aktiviert, sodass ein kurzer Prompt vor dem Sampling zu einer vollständigen Bildbeschreibung erweitert wird.

## Tipps für Prompting und Referenzen

- **Beschreiben Sie das Ergebnis, nicht die Änderung.** Die Bildbearbeitungs-Vorlagen erwarten eine vollständige Bildbeschreibung des fertigen Bildes, in die die Änderung eingebettet ist. Deshalb beschreiben die Beispiele das neue Objekt ausführlich, statt „change this“ zu sagen.
- **Das Prompt-Feld ist `FLUX 3 Image Layout Prompt`.** In beiden Bildbearbeitungs-Vorlagen kommt der Text von `Positive Prompt` über eine Verbindung an, daher hat dieser Node kein eigenes Feld. Geben Sie den Text im Layout-Prompt-Node ein: Standardmäßig schreibt der Upsampler Ihren Text zuerst in eine Bildbeschreibung um, und wenn Sie den `If/Else Switch` einschalten, wird er unverändert an den Sampler weitergegeben.
- **Referenzen werden beiden Conditionings hinzugefügt.** Verbinden Sie zusätzliche Bilder der Reihe nach mit `Set Reference Multi Latent`, sprechen Sie sie als `<ref_image_0>`, `<ref_image_1>` und so weiter an, und fügen Sie jedes davon sowohl dem positiven als auch dem negativen Prompt hinzu, so wie es die Referenz-Pipeline tut.
- **Die Referenzgröße ist ein Kostenfaktor.** Die Vorlagen ändern die Größe jeder Referenz auf etwa 1 Megapixel, und das Ausgabe-Latent übernimmt diese Größe. Belassen Sie Referenzen in ihrer nativen Größe, was die eigene Pipeline von Black Forest Labs bis etwa 16 Megapixel tut, bleibt mehr Detail in der Bearbeitung erhalten, allerdings zu höheren Kosten.
- **Die Schrittzahl hängt vom Checkpoint ab.** Der vollständige Checkpoint läuft in den Vorlagen mit 50 Schritten, mit Guidance 3.5 bei Text zu Bild und 1 bei der Bildbearbeitung. Der schrittdestillierte Checkpoint läuft mit 16 Schritten und fest eingestellter Guidance von 1, und diesen verwenden Sie, wenn Sie einen schnellen Durchlauf möchten.
- **Die Vorlagen enthalten einen `Create Bounding Boxes`-Node.** Er zeichnet Begrenzungsrahmen über das Quellbild, um regionale Bearbeitungen zu planen, und seine Liste der Begrenzungsrahmen wird im `Preview Any`-Node angezeigt, sodass Sie die Regionen in den Prompt einbeziehen können.
