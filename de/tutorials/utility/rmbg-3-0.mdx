RMBG 3.0 ist Brias drittes Modell zur Hintergrundentfernung und das erste, das auf einem generativen Modell statt auf einem Segmentierungsnetzwerk basiert. Es erzeugt eine weiche Graustufen-Alphamaske statt einer harten binären Maskierung, sodass Haare, Fell, Mesh, Schleier und Bewegungsunschärfe teilweise transparent bleiben.

Die Basis ist Fibo 2.0 mit einem 8B-Diffusion-Transformer und einem Qwen3-VL-4B-Prompt- und Bild-Encoder, destilliert auf 4 Sampling-Schritte ohne classifier-free Guidance. Der Support in ComfyUI kam mit [ComfyUI #17240](https://github.com/Comfy-Org/ComfyUI/pull/17240), und die Vorlage erfordert ComfyUI 0.46.0 oder später.

Der Workflow nimmt ein Bild entgegen und liefert drei Ausgänge: einen RGBA-Freisteller, ein Hintergrundbild und die verarbeitete Maskierung.

1. Ziehen Sie Ihr Foto in den Node `LoadImage`.
2. Aktivieren Sie `auto_prompt`, das in der mitgelieferten Vorlage deaktiviert ist. Ist es deaktiviert, sendet der Node die feste Anweisung und `subject_note` wird nicht verwendet.
3. Optional: Schreiben Sie einen kurzen Satz über das Material in `subject_note`, zum Beispiel `Clear glass bottle, paper label, metal cap`.
4. Führen Sie den Workflow aus. `SaveImage` schreibt beide Ergebnisse unter `ComfyUI/output/rmbg3/`.

## Workflow-Steuerung

- `auto_prompt`: Wenn aktiviert, schreibt ein Vision-Modell die Matting-Anweisung aus dem Bild und Ihrem `subject_note`. Wenn deaktiviert, wird die feste Anweisung, mit der das Modell trainiert wurde, unverändert gesendet und `subject_note` ignoriert.
- `cfg`: Behalten Sie ihn bei 1.0. Das Modell wurde ohne Guidance destilliert, daher tauscht ein höherer Wert die Treue zur Quelle gegen Transparenz ein.
- `alpha_brightness`, `alpha_contrast`, `mask_threshold`, `hard_mask`: Matte-Nachbearbeitung. Lassen Sie `hard_mask` ausgeschaltet, um weiche Kanten zu behalten.
- `mask_expand`, `mask_tapered_corners`: Vergrößern und runden Sie die Matte, bevor sie angewendet wird.

## Wenn der Freisteller nicht stimmt

| Symptom | Lösung |
| :--- | :--- |
| Glas, Schleier oder Rauch werden deckend wiedergegeben | Aktivieren Sie `auto_prompt`, beschreiben Sie das Material in `subject_note` und erhöhen Sie dann `cfg` auf 1.5 oder 2.0 |
| Grauer Schleier über dem Hintergrund | Senken Sie `alpha_brightness` oder aktivieren Sie `hard_mask` |
| Farbiges Glas bleibt undurchsichtig | Senken Sie `alpha_brightness` oder bemalen Sie diesen Bereich von Hand |

Zwei Einschränkungen ergeben sich aus dem Modell selbst: Sehr unruhige oder kontrastarme Szenen können Gras, Requisiten oder ein Wasserzeichen neben dem Motiv mit einbeziehen, und feine Strukturen wie Insektenflügel können Pixel verlieren.
