# Einführung in ComfyUI Depth Anything 3

[Depth Anything 3 (DA3)](https://github.com/ByteDance-Seed/Depth-Anything-3) von ByteDance Seed ist ein Vision Transformer, der aus beliebigen visuellen Eingaben räumlich konsistente Geometrie rekonstruiert, mit oder ohne bekannte Kameraposen. Ein einzelner reiner DINO-Encoder und eine einheitliche Depth-Ray-Repräsentation ermöglichen es, dass eine einzige Modellfamilie monokulare Tiefe, Multi-View-Tiefe, Kameraposenschätzung und 3D-Rekonstruktion abdeckt.

Wichtigste Funktionen:

- **Einheitliche monokulare und Multi-View-Tiefe**: Tiefe aus einem einzelnen Bild oder aus mehreren Ansichten schätzen
- **Kameraposenschätzung**: Kamerapositionen aus ungeordneten Bildsätzen rekonstruieren
- **3D-Rekonstruktion** aus Multi-View-Eingaben
- **Video-Tiefenschätzung**: Tiefensequenzen pro Frame für Videoeingaben
- **Mehrere Modellvarianten**: Small, Base, Mono/Metric Large

<UpdateReminder/>

<Tip>
ComfyUI unterstützt die Depth Anything 3 Nodes jetzt nativ. Stellen Sie sicher, dass Sie auf die neueste Version von [ComfyUI](https://github.com/Comfy-Org/ComfyUI) aktualisiert haben, bevor Sie beginnen.
</Tip>

## Modelle installieren

Laden Sie die Checkpoints von Depth Anything 3 herunter und speichern Sie sie im entsprechenden ComfyUI-Ordner:

- **Small** ([depth_anything_3_small.safetensors](https://huggingface.co/Comfy-Org/Depth-Anything-3/blob/main/geometry_estimation/depth_anything_3_small.safetensors)): Lightweight, fast inference
- **Base** ([depth_anything_3_base.safetensors](https://huggingface.co/Comfy-Org/Depth-Anything-3/blob/main/geometry_estimation/depth_anything_3_base.safetensors)): Balanced performance
- **Mono-Large** ([depth_anything_3_mono_large.safetensors](https://huggingface.co/Comfy-Org/Depth-Anything-3/blob/main/geometry_estimation/depth_anything_3_mono_large.safetensors)): Best for monocular depth, includes sky detection
- **Metric-Large** ([depth_anything_3_metric_large.safetensors](https://huggingface.co/Comfy-Org/Depth-Anything-3/blob/main/geometry_estimation/depth_anything_3_metric_large.safetensors)): Metric scale depth in metres, includes sky detection

```
ComfyUI/
├── models/
│   ├── geometry_estimation/
│   │   ├── depth_anything_3_small.safetensors
│   │   ├── depth_anything_3_base.safetensors
│   │   ├── depth_anything_3_mono_large.safetensors
│   │   └── depth_anything_3_metric_large.safetensors
```

### Schritte zum Ausführen

1. **LoadImage**: Laden Sie Ihr Eingabebild.
2. **LoadDA3Model**: Wählen Sie eine Variante von Depth Anything 3 aus.
3. **Run**: Klicken Sie auf Warteschlange oder verwenden Sie `Cmd+Enter`.
4. Der Workflow gibt eine Tiefenkarte und einen direkten Vergleich aus.

## Modellvarianten

| Variante | head_type | has_sky | has_confidence | camera_decoder | Geeignet für |
|---------|-----------|:-------:|:--------------:|:--------------:|----------|
| **Small** | dualdpt | ❌ | ✅ | ✅ | Schnelle Inferenz, Mobilgeräte/Edge |
| **Base** | dualdpt | ❌ | ✅ | ✅ | Ausgewogene Leistung |
| **Mono-Large** | dpt | ✅ | ❌ | ❌ | Monokulare Tiefe mit Himmelsererkennung |
| **Metric-Large** | dpt | ✅ | ❌ | ❌ | Physikalische metrische Tiefe in Metern |

- **Small** und **Base** verwenden den `dualdpt`-Head-Typ mit Konfidenzschätzung und Kamera-Decoder-Support für Multi-View-Anwendungen.
- **Mono-Large** und **Metric-Large** verwenden den `dpt`-Head-Typ mit Himmelsererkennung. Metric-Large gibt die Roh-Tiefe in Metern aus.
