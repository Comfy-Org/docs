BiRefNet (Bilateral Reference Network) ist ein hochwertiges Modell zur Hintergrundentfernung bei Bildern. Es erzeugt saubere, detaillierte Masken für eine breite Palette von Motiven, darunter Personen, Produkte, Tiere und komplexe Objekte mit feinen Details wie Haaren oder Fell.

BiRefNet wird in ComfyUI nativ unterstützt (PR [#12747](https://github.com/Comfy-Org/ComfyUI/pull/12747)). Die Modellgewichte sind unter der [MIT License](https://github.com/ZhengPeng7/BiRefNet/blob/main/LICENSE) verfügbar.

[BiRefNet auf Hugging Face](https://huggingface.co/ZhengPeng7/BiRefNet) | [Comfy-Org Model Repository](https://huggingface.co/Comfy-Org/BiRefNet) | [Paper (arXiv)](https://arxiv.org/abs/2401.00807)

### Wichtige Stärken

- **Hochwertige Masken**: präzise Kantenerkennung für Haare, Fell und feine Details
- **Vielseitige Motiverkennung**: funktioniert gut bei Personen, Produkten, Tieren und komplexen Szenen
- **Einfacher Ein-Klick-Workflow**: Sie laden nur ein Bild, den Rest übernimmt das Modell
- **RGBA-Ausgabe**: erzeugt ein Bild mit transparentem Hintergrund, bereit für Compositing

> **Einschränkungen:** Bei extrem unruhigen Hintergründen oder Motiven, die mit dem Hintergrund verschmelzen, können die Masken weniger präzise ausfallen. Das Modell verarbeitet immer nur ein Bild gleichzeitig.

## BiRefNet-Workflow zur Hintergrundentfernung

### 1. Workflow herunterladen

Aktualisieren Sie Ihr ComfyUI auf die neueste Version, gehen Sie anschließend zu `Workflow` -> `Browse Templates` und suchen Sie „BiRefNet: Remove Background“ in der Kategorie Utility.

### BiRefNet: Remove Background {#utility_birefnet_remove_background}

Laden Sie ein Bild mit einem beliebigen Hintergrund hoch. Generieren Sie eine Version mit entferntem Hintergrund sowie eine präzise Segmentierungsmaskierung.

### 2. Modelle herunterladen

Das BiRefNet-Modell wird im [BiRefNet-Modell-Repository von Comfy-Org](https://huggingface.co/Comfy-Org/BiRefNet) gehostet.

- [birefnet.safetensors](https://huggingface.co/Comfy-Org/BiRefNet/blob/main/background_removal/birefnet.safetensors)

Legen Sie es in der folgenden Verzeichnisstruktur ab:

```
📂 ComfyUI/
└── 📂 models/
    └── 📂 background_removal/
        └── birefnet.safetensors
```

### 3. Workflow verwenden

- **Bild**: Laden Sie ein Bild über den `Load Image`-Node (legen Sie es im Ordner `input/` von ComfyUI ab)
- Der Subgraph `Remove Background (BiRefNet)` verarbeitet das Bild und gibt aus:
  - **IMAGE**: das Ergebnis mit transparentem Hintergrund (RGBA)
  - **mask**: die extrahierte Vordergrundmaskierung

Die Ausgänge können in der Vorschau angezeigt und als Eingänge für andere Nodes verwendet werden, etwa für Compositing, weitere Bearbeitung oder zum Speichern.

## Zusätzliche Hinweise

- **Modellverzeichnis**: Das Modell muss in `ComfyUI/models/background_removal/` abgelegt werden, nicht im Ordner `checkpoints`.
- **Aktualisierung erforderlich**: Die Unterstützung für BiRefNet ist in neueren ComfyUI-Versionen verfügbar. Stellen Sie sicher, dass Ihr ComfyUI auf dem neuesten Stand ist.
- **RGBA-Ausgabe**: Das Ergebnis mit transparentem Hintergrund kann direkt auf neue Hintergründe komponiert oder in nachgelagerten Workflows verwendet werden.
