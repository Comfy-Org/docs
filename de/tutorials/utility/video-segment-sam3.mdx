[SAM 3](https://ai.meta.com/sam3) (Segment Anything Model 3) ist Metas einheitliches Foundation-Modell für promptbare Segmentierung in Bildern und Videos. Es kann Objekte mithilfe von Text- oder visuellen Prompts wie Punkten, Rechtecken und Masken erkennen, segmentieren und verfolgen. Im Vergleich zu seinem Vorgänger [SAM 2](https://github.com/facebookresearch/sam2) führt SAM 3 die Möglichkeit ein, alle Instanzen eines Open-Vocabulary-Konzepts, das durch eine kurze Textphrase angegeben wird, vollständig zu segmentieren.

[SAM 3.1 Multiplex](https://github.com/facebookresearch/sam3) ist das neueste Checkpoint-Release, das einen Shared-Memory-Ansatz für gemeinsames Multi-Objekt-Tracking einführt: deutlich schneller, ohne Genauigkeit einzubüßen.

SAM 3.1 wird in ComfyUI nativ unterstützt (PR [#13408](https://github.com/Comfy-Org/ComfyUI/pull/13408)), und die Modellgewichte sind unter der [SAM License](https://github.com/facebookresearch/sam3/blob/main/LICENSE) verfügbar.

[SAM 3 GitHub](https://github.com/facebookresearch/sam3) | [Paper (arXiv)](https://arxiv.org/abs/2604.02296) | [🤗 Model Hub](https://huggingface.co/Comfy-Org/sam3.1)

SAM 3.1 segmentiert und verfolgt Objekte über Videoframes hinweg auf Basis von Text-Prompts. Das obige Beispiel zeigt die Segmentierungsausgabe mit Masken, die im gesamten Video auf die Zielobjekte angewendet werden.

### Wichtige Stärken

- **Textgesteuerte Segmentierung**: Beschreiben Sie in natürlicher Sprache, was segmentiert werden soll. Manuelle Punkt- oder Rechteck-Annotationen sind nicht erforderlich.
- **Unterstützung für Bilder und Videos**: funktioniert sowohl bei einzelnen Bildern als auch bei Videosequenzen mit Tracking über Frames hinweg
- **Multi-Objekt-Unterstützung**: segmentieren und verfolgen Sie mehrere Objekte gleichzeitig mit durch Kommas getrennten Prompts
- **Open-Vocabulary**: verarbeitet eine deutlich größere Menge an Open-Vocabulary-Konzepten als frühere Arbeiten

> **Einschränkungen:** Das Modell hat ein maximales Token-Limit von 32 für Text-Prompts. Für beste Ergebnisse halten Sie Prompts kurz und spezifisch für das Zielobjekt.

### 3. Workflows verwenden

**Bildsegmentierung:**

- **Bild**: Laden Sie ein Bild über den `Load Image` Node (legen Sie es im Ordner `input/` von ComfyUI ab)
- **Objekt-Prompt**: Eine kurze Textbeschreibung des zu segmentierenden Objekts bzw. der Objekte, z. B. `person`, `car`, `cat`
- Die Ausgabe ist eine auf das Bild angewendete Maske, mit einer RGBA-Vorschau, die das Segmentierungsergebnis zeigt

**Videosegmentierung:**

- **Video**: Laden Sie ein Video über den `Load Video` Node
- **Objekt-Prompt**: Wie beim Bild ein kurzer Text-Prompt, der beschreibt, was über die Frames hinweg verfolgt und segmentiert werden soll
- Die Ausgabe liefert Masken und Begrenzungsrahmen für jedes Frame

**Prompt-Format:**

| Prompt | Rolle |
|--------|------|
| SAM3-Objekt-Prompt | Kurze Beschreibung davon, **was** segmentiert werden soll. Max. 32 Tokens. |

Um mehrere Motive getrennt anzugeben, trennen Sie sie durch Kommas und verwenden Sie `:N`, um die maximale Anzahl der pro Prompt erkannten Objekte festzulegen:
`eye:2, window panels:4`

## Zusätzliche Hinweise

- **Prompts kurz und spezifisch halten**: Das Modell hat ein Limit von 32 Tokens pro Prompt
- **Erkennung mehrerer Objekte**: Verwenden Sie Kommas, um verschiedene Objekttypen zu trennen, und `:N`, um die Erkennungen pro Typ zu begrenzen
- **Segmentierungsmasken**: Die Ausgabemaske kann als Eingabe für andere Workflows verwendet werden (z. B. Inpainting, Hintergrundentfernung)
- **Aktualisierung erforderlich**: Stellen Sie sicher, dass ComfyUI auf die neueste Version aktualisiert ist, um die Unterstützung für SAM 3.1 zu nutzen
