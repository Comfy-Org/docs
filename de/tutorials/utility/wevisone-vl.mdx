WeVisOne-VL ist ein kompaktes Sprach-Bild-Modell, das in Formen statt in Prosa antwortet. Sie geben ihm ein Bild und eine kurze Textabfrage, und es liefert Boxen, Punkte oder eine Alpha-Matte pro Instanz in einem einzigen Durchlauf: keine Annotation, kein Prompting pro Objekt.

In ComfyUI läuft es als Node **WeVisOne-VL Detect**. Die folgende Vorlage verpackt es in einen Subgraph und zeigt die Matte, die über das Quellbild gezeichneten Boxen sowie Freistellungen von Vordergrund und Hintergrund in der Vorschau an, sodass die Matte direkt in eine Kette zur Hintergrundentfernung, zum Masking oder zum Compositing passt.

Die Gewichte sind die Apache-2.0-Releases von Tencent, für ComfyUI neu verpackt in [Comfy-Org/WeVisOne-VL](https://huggingface.co/Comfy-Org/WeVisOne-VL). Der Support ist in [ComfyUI #17632](https://github.com/Comfy-Org/ComfyUI/pull/17632) eingeflossen, und die Vorlage setzt ComfyUI 0.45.0 oder neuer voraus.

## Bildsegmentierung: WeVisOne-VL {#utility_image_segment_wevisone_vl}

Geben Sie in `query` ein, was ausgeschnitten werden soll, und führen Sie den Workflow aus. Mit der Standardaufgabe `segmentation` und der Abfrage `human` gibt der Graph eine kombinierte Maske der gefundenen Personen sowie deren Boxen zurück. Aktivieren Sie `individual_masks` am Node, um eine separate Maske pro Person zu erhalten.

## Aufgaben

Das Widget `task` formuliert Ihre Abfrage in die Instruktion um, auf die der Checkpoint trainiert wurde. Jede Aufgabe erwartet ihre Abfrage in einer etwas anderen Form:

| `task` | Abfrageform | Rückgabe |
| :--- | :--- | :--- |
| `segmentation` | Eine kurze Nominalphrase, etwa `human` | Alpha-Matte plus Rechtecke (eine kombinierte Matte, sofern `individual_masks` nicht aktiv ist) |
| `detection` | Ein Label pro Zeile | Nur Rechtecke |
| `referring` | Eine beschreibende Phrase, etwa `the cup on the left` | Rechtecke |
| `point` | Ein Label pro Zeile | Mittelpunkte als JSON |
| `count_box` | Das zu zählende Objekt | Eine Anzahl, mit einem Rechteck an jeder Instanz |
| `count_point` | Das zu zählende Objekt | Eine Anzahl, mit einem Punkt an jeder Instanz |
| `ocr` | Nichts | Ein Rechteck um jedes Wort im Bild |
| `ocr_grounding` | Die exakt zu findende Zeichenkette | Ein Rechteck um diese Zeichenkette |
| `visual_prompt` | Nichts, verwendet die Eingabe `bboxes` | Rechtecke für Objekte, die den Referenz-Rechtecken ähneln |
| `freeform` | Beliebig | Die Rohantwort, wobei die Abfrage den gesamten Prompt bildet |

Halten Sie die Abfrage kurz. Ein vollständiger Satz lässt `segmentation` abschweifen, und eine Phrase, die das Objekt benennt, funktioniert besser als eine Beschreibung davon.

## Mehr Kontrolle über den Node

- **`individual_masks`**: on, eine Maskierung pro Rechteck; off, eine kombinierte Maskierung pro Frame
- **`max_length`**: Obergrenze für die Antwortlänge, standardmäßig 4096 Tokens und bis zu 32768
- **Ausgänge**: `masks`, `bboxes`, `points` (JSON mit x, y, label und frame) und `text` (die unverarbeitete Antwort)
