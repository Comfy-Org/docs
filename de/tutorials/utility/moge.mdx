# ComfyUI MoGe: Einführung

[MoGe](https://github.com/microsoft/MoGe) (CVPR 2025, von Microsoft Research) ist ein leistungsstarkes Modell zur Rekonstruktion der 3D-Geometrie aus monokularen Bildern aus offenen Domänen. Es schätzt metrische Punktkarten, metrische Tiefenkarten, Normal Maps und das Sichtfeld der Kamera: alles in einem einzigen Vorwärtsdurchlauf.

Wichtige Funktionen:

- **Präzise 3D-Geometrieschätzung**: Punktkarten, Tiefenkarten und Normal Maps aus einem einzigen Bild: ein Modell, ein Vorwärtsdurchlauf
- **Metrischer Maßstab** (MoGe-2, MoGe-3): Punktkarten und Tiefenkarten im realen Maßstab
- **Flexible Auflösungsunterstützung**: funktioniert mit verschiedenen Auflösungen und Seitenverhältnissen (2:1 bis 1:2)
- **Schnelle Inferenz**: ~60ms pro Bild auf A100 / RTX 3090 (FP16, ViT-L)
- **Mesh-Generierung** sowohl aus perspektivischen als auch aus panoramischen Bildern

ComfyUI liefert Checkpoints für drei MoGe-Versionen:

| Datei | Version | Metrischer Maßstab | Normal Maps | Parameter |
|------|---------|:------------:|:-----------:|:-----:|
| `moge_1_vitl_fp16` | **MoGe-1** | - | - | 314M |
| `moge_2_vitl_normal_fp16` | **MoGe-2** | ✅ | ✅ | 331M |
| `moge_3_vitl_fp16` | **MoGe-3** | ✅ | ✅ | 370M |
| `moge_3_vitg_fp16` | **MoGe-3** | ✅ | ✅ | 1.25B |

> MoGe-2 ergänzt den metrischen Maßstab sowie eine hochwertige Normal-Map-Schätzung mit schärferen visuellen Details und geringerer Inferenzlatenz. **MoGe-2 mit Normal Map (`moge_2_vitl_normal_fp16`) ist der empfohlene Checkpoint.**
>
> MoGe-3 behält die Architektur von MoGe-2 bei und ergänzt eine selbstgesteuerte, sparse volumetrische Verfeinerungsstufe für eine deutlich verbesserte feinkörnige Punktkarten-Geometrie. Es ist als ViT-L-Checkpoint (`moge_3_vitl_fp16`) und als größerer ViT-g-Checkpoint (`moge_3_vitg_fp16`) verfügbar.

<UpdateReminder/>

<Tip>
ComfyUI unterstützt MoGe-Nodes jetzt nativ. Stellen Sie vor dem Start sicher, dass Sie auf die neueste Version von [ComfyUI](https://github.com/Comfy-Org/ComfyUI) aktualisiert haben.

Generierte Modelle im `.glb`-Format werden im Ordner `ComfyUI/output/mesh` ausgegeben.
</Tip>

## Modell installieren

Laden Sie die MoGe-Checkpoints herunter und speichern Sie sie im entsprechenden ComfyUI-Ordner:

- **MoGe-2 (empfohlen)**: [moge_2_vitl_normal_fp16.safetensors](https://huggingface.co/Comfy-Org/MoGe/blob/main/geometry_estimation/moge_2_vitl_normal_fp16.safetensors)
- **MoGe-1 (Baseline)**: [moge_1_vitl_fp16.safetensors](https://huggingface.co/Comfy-Org/MoGe/blob/main/geometry_estimation/moge_1_vitl_fp16.safetensors)
- **MoGe-3 (höchste Detailtreue)**: [moge_3_vitg_fp16.safetensors](https://huggingface.co/Comfy-Org/MoGe/blob/main/geometry_estimation/moge_3_vitg_fp16.safetensors) (1.25B) oder [moge_3_vitl_fp16.safetensors](https://huggingface.co/Comfy-Org/MoGe/blob/main/geometry_estimation/moge_3_vitl_fp16.safetensors) (370M)

```
ComfyUI/
├── models/
│   ├── geometry_estimation/
│   │   ├── moge_2_vitl_normal_fp16.safetensors
│   │   ├── moge_1_vitl_fp16.safetensors
│   │   ├── moge_3_vitg_fp16.safetensors
│   │   └── moge_3_vitl_fp16.safetensors
```

Nur für MoGe-3-Checkpoints: Die Nodes `Run MoGe Inference` und `Run MoGe Panorama Inference` bieten eine erweiterte `refine_steps`-Steuerung (0 bis 8, Standard 3), die sparse volumetrische Verfeinerungsdurchläufe über die vorhergesagte Tiefe ausführt. `0` deaktiviert die Verfeinerung, und mehr Durchläufe schärfen feine Details und Kanten zu ungefähr linearen Kosten. MoGe-1- und MoGe-2-Checkpoints ignorieren diese Einstellung.

1. Stellen Sie sicher, dass im Node `LoadMoGeModel` ein MoGe-Checkpoint geladen ist

### MoGe 3: Geometrieschätzung {#utility_moge3_geometry_estimation}

Schätzen Sie mit MoGe 3 fein detaillierte Geometrie aus einem einzelnen Bild. Die MoGe-3-Checkpoints heben die grobe Punktkarte auf eine dünn besetzte Voxel-Hülle an und verfeinern die Tiefe mit leichtgewichtigen, dünn besetzten 3D-Faltungen. Dadurch bleiben dünne Strukturen und Tiefenunstetigkeiten erhalten, die bildraumbasierte Decoder verwischen.

### 4.1 Schritte zur Ausführung

1. Stellen Sie sicher, dass im Subgraph `Geometry Estimation (MoGe 3)` ein MoGe 3 Checkpoint ausgewählt ist: Die Vorlage enthält `moge_3_vitg_fp16.safetensors`, und `moge_3_vitl_fp16.safetensors` ist im selben Dropdown-Menü verfügbar.
2. Laden Sie ein Bild im Node `Load Image`.
3. (Optional) Ändern Sie `output` am Subgraph-Node, um eine andere Map zu rendern: `mask` ist die Standardeinstellung, und `depth`, `depth_colored`, `normal_opengl` und `normal_directx` sind die weiteren Optionen.
4. Klicken Sie auf `Queue`, oder verwenden Sie `Ctrl(cmd) + Enter`, um den Workflow auszuführen.
