[MediaPipe](https://github.com/google-ai-edge/mediapipe) ist Googles Open-Source-Lösung für maschinelles Lernen zur Echtzeit-Wahrnehmung. In ComfyUI bietet MediaPipe Face Detection **BlazeFace**-Erkennung, **FaceMesh v2**-Landmarken-Schätzung und **ARKit-52-Blendshapes**, und das alles in einem einzigen einheitlichen Workflow.

MediaPipe Face Detection wird in ComfyUI nativ unterstützt (PR [#14009](https://github.com/Comfy-Org/ComfyUI/pull/14009)), und die Modellgewichte sind unter der [Apache-2.0-Lizenz](https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE) verfügbar.

[MediaPipe GitHub](https://github.com/google-ai-edge/mediapipe) | [Comfy-Org Modell-Repository](https://huggingface.co/Comfy-Org/mediapipe)

### Wichtige Funktionen

- **Schnelle Gesichtserkennung**: BlazeFace-basierter Detektor mit Varianten für kurze (~2 m) und volle (~5 m) Reichweite
- **478 Gesichts-Landmarken**: dichte FaceMesh v2-Keypoints pro erkanntem Gesicht
- **ARKit-52-Blendshapes**: Echtzeit-Koeffizienten für Gesichtsausdrücke
- **Masken für Gesichtsbereiche**: Masken pro Region für Gesichtsoval, Lippen, Augen und Iris
- **Begrenzungsrahmen für Gesichter**: Ausgaben kompatibel mit `DrawBBoxes` zur Visualisierung von Begrenzungsrahmen

> **Umfang:** Nur Gesichtserkennung: BlazeFace + FaceMesh v2 + ARKit-Blendshapes. Hand-, Pose- oder Holistic-Erkennung sind hiermit nicht abgedeckt.

### 1. Workflow herunterladen

Aktualisieren Sie ComfyUI auf die neueste Version, gehen Sie dann zu `Workflow` → `Browse Templates` und suchen Sie „Mediapipe: Image Face Detection“ in der Kategorie Utility.

### 2. Modell herunterladen

Das MediaPipe Face Detection-Modell wird im [MediaPipe-Modellrepository von Comfy-Org](https://huggingface.co/Comfy-Org/mediapipe) gehostet.

- [mediapipe_face_fp32.safetensors](https://huggingface.co/Comfy-Org/mediapipe/blob/main/detection/mediapipe_face_fp32.safetensors)

Legen Sie es in der folgenden Verzeichnisstruktur ab:

```
📂 ComfyUI/
└── 📂 models/
    └── 📂 detection/
        └── mediapipe_face_fp32.safetensors
```

### 3. Workflow verwenden

Dieser Workflow verwendet einen **Subgraph**-Node, der Gesichtserkennung, Visualisierung und Maskengenerierung orchestriert. Der Subgraph stellt die folgenden Steuerelemente bereit:

<Card title="Mehr über Subgraph erfahren" icon="book-open" href="/interface/features/subgraph">
  Dieser Workflow verwendet Subgraph-Nodes für modulare Verarbeitung. In der Subgraph-Dokumentation erfahren Sie, wie Sie den Workflow anpassen und erweitern.
</Card>

**Subgraph-Eingänge:**

| Eingabe | Beschreibung |
|-------|-------------|
| **image** | Batch von Eingabebildern zur Analyse |
| **face_landmarker** | Optional. Leer lassen, um den integrierten Modell-Loader zu verwenden. Verbinden Sie einen externen `FACE_DETECTION_MODEL`-Ausgang, um ihn zu überschreiben |

**Subgraph-Parameter:**

| Parameter | Standard | Beschreibung |
|-----------|:-------:|-------------|
| **model_name** | `mediapipe_face_fp32.safetensors` | Checkpoint in `ComfyUI/models/detection/`. Fehlt er, laden Sie das oben genannte Modell herunter |
| **detector_variant** | `short` | **short**: auf nahe/große Gesichter abgestimmt (~2 m Reichweite). **full**: deckt kleinere/weiter entfernte Gesichter ab (~5 m), langsamer. **both**: führt beide Detektoren aus und behält denjenigen, der pro Frame mehr Gesichter gefunden hat (~2× Kosten) |
| **num_faces** | `1` | Maximale Anzahl an Gesichtern, die pro Frame zurückgegeben werden. `0` = keine Obergrenze (alle erkannten zurückgeben). Bereich: 0–16 |
| **custom_face_oval** | `false` | Gesichtsumrissbereich in die Maskenausgabe einschließen |
| **custom_lips** | `false` | Lippen in die Maske einschließen (Vereinigung mit anderen aktivierten Bereichen) |
| **custom_left_eye** | `false` | Bereich des linken Auges in die Maske einschließen |
| **custom_right_eye** | `false` | Bereich des rechten Auges in die Maske einschließen |
| **custom_irises** | `false` | Irisbereiche in die Maske einschließen |

Die Masken-Schalter verwenden intern den benutzerdefinierten Modus: Nur aktivierte Bereiche werden gefüllt; mehrere eingeschaltete Bereiche werden pro Frame zu einer Maske **vereinigt**.

**Subgraph-Ausgänge:**

| Ausgabe | Typ | Beschreibung |
|--------|------|-------------|
| **face_landmarks** | `FACE_LANDMARKS` | Gesichter pro Frame mit 478 2D/3D-Landmarken, ARKit-52-Blendshapes, Mesh-Topologiedaten. Werden an Visualisierungs- und Masken-Nodes weitergegeben |
| **bboxes** | `BOUNDING_BOX` | Begrenzungsrahmen der Gesichter: kompatibel mit dem `DrawBBoxes`-Node |
| **mask** | `MASK` | Binäre Maske aus den aktivierten Bereichsschaltern |

### 4. Workflow ausführen

1. Stellen Sie sicher, dass die Modelldatei in `ComfyUI/models/detection/` liegt
2. Laden Sie ein Bild im Node `Load Image`
3. Passen Sie die Erkennungsparameter bei Bedarf an
4. Klicken Sie auf `Queue` oder verwenden Sie `Ctrl(Cmd) + Enter`, um den Workflow auszuführen
5. Der Workflow gibt die Mesh-Überlagerung, die Begrenzungsrahmen und die Maskenvorschau aus
