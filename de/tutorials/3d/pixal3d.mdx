**Pixal3D** ist ein Open-Source-Image-to-3D-Modell von Tencent ARC, vorgestellt auf der SIGGRAPH 2026. Es verwandelt ein einzelnes Bild in ein detailgetreues 3D-Asset mit vollständigen PBR-Materialien.

Die meisten 3D-nativen Generatoren synthetisieren Formen in einem kanonischen Raum und speisen Bildhinweise über Attention ein, wodurch die Zuordnung von Pixeln zu 3D mehrdeutig bleibt. Pixal3D setzt stattdessen auf pixelgenaue Generierung: Über Rückprojektion stellt es eine direkte Pixel-zu-3D-Korrespondenz her, sodass die Vorderseite des generierten Modells 1:1 zu Ihrem Eingabebild passt, ohne verzerrte oder falsch ausgerichtete Texturen.

### Pixal3D: Bild zu 3D-Modell {#pixal3d}

Laden Sie ein einzelnes Bild hoch. Generieren Sie ein detailgetreues 3D-Modell mit vollständigen PBR-Texturen, ausgerichtet an Ihrer Eingabeansicht.

Dieser Workflow enthält außerdem die TRELLIS.2-Pipeline. Der Node `Boolean (Switch to Trellis2)` ist standardmäßig auf `false` gesetzt, wodurch die Pixal3D-Pipeline ausgeführt und das Pixal3D-Modell automatisch geladen wird.

## So funktioniert es

Pixal3D kombiniert kamerabewusste, pixelgenaue Generierung mit einer vollständigen Nachbearbeitungspipeline für Meshes:

1. **Hintergrundentfernung**: BiRefNet entfernt den Hintergrund aus dem Eingabebild, und der Workflow schneidet das Motiv auf einen zentrierten Canvas zu. Ein Schalter ermöglicht das Überspringen der Hintergrundentfernung
2. **Kameraschätzung**: MoGe schätzt die Geometrie und das Sichtfeld (FOV) der Kamera aus dem Bild. Das FOV steuert die pixelgenaue Konditionierung
3. **Strukturgenerierung**: Ein spärliches Struktur-Latent wird gesampelt und zu Voxeln dekodiert und anschließend in ein grobes Mesh umgewandelt
4. **Formverfeinerung**: Die Formstufe und die Upsampling-Stufe verfeinern das Mesh bis zur Zielauflösung (1536)
5. **Texturgenerierung**: Eine Textur-Diffusionsstufe erzeugt PBR-Material-Voxel (Grundfarbe, Metallic, Roughness)
6. **Nachbearbeitung**: DC-Remesh, QEM-Dezimation, UV-Unwrapping und Backen von Grundfarb-, Normal- und Ambient-Occlusion-Maps in das finale texturierte Mesh

## Schritte zum Ausführen

1. **Bild laden**: Verwenden Sie den Node `LoadImage`, um ein einzelnes Bild des Objekts zu laden.
2. **Workflow in die Warteschlange stellen**: Drücken Sie Strg (unter macOS Cmd) + Enter.
3. **Auf die Pipeline warten**: Die Stufen Struktur, Form und Textur werden nacheinander ausgeführt, gefolgt von der Nachbearbeitung.
4. **Ergebnis anzeigen**: Prüfen Sie das Mesh im Node `Preview3DAdvanced`. Das 3D-Modell wird unter `ComfyUI/output/3d/ComfyUI/` gespeichert.
