# Einführung in ComfyUI Bernini-R

[Bernini-R](https://github.com/bytedance/Bernini) ist ByteDances **reines Renderer-Modell** von Wan 2.2 für die In-Context-Konditionierung mit Bildern und Videos. Es verwendet mehrere Konditionierungs-Streams (Quellvideo, Referenzbilder, Referenzvideo), um die Generierung zu steuern. Ein LoRA-Training oder Fine-Tuning ist nicht erforderlich.

Wichtigste Funktionen:

- **Mehrere Aufgabentypen in einem Modell**: Bild- und Videogenerierung, Bearbeitung, Relighting, Restyling, Einfügen von Motiven
- **In-Context-Konditionierung**: Referenzbilder und -videos wirken als visuelle Prompts und werden als Tokens injiziert
- **Leichtgewichtig**: reines Renderer-Modell. Kein diffusionsbasiertes Text-zu-Video-Backbone.
- **Flexible Eingänge**: einzelne oder mehrere Referenzbilder, Video zu Video, referenzgestützte Bearbeitung

Bernini-R unterstützt die folgenden Aufgabentypen:

| Aufgabe | Eingänge | Beschreibung |
|------|--------|-------------|
| **t2v** | Text-Prompt | Text-zu-Video-Generierung |
| **v2v** | Quellvideo | Video-zu-Video-Restyling |
| **rv2v** | Quellvideo + Referenzbild(er) | Referenzgestützte Videobearbeitung (Relighting, Einfügen von Motiven) |
| **r2v** | Nur Referenzbild(er) | Referenz-zu-Video-Generierung |
| **img** | Quellbild + Text-Prompt | Bildbearbeitung (Relighting, Restyling, Einfügen von Motiven) |
| **ads2v** | Quellvideo + Referenzvideo | Bild- oder Videoinhalt in das Quellvideo einfügen |

<Tip>
ComfyUI unterstützt Bernini-R-Nodes jetzt nativ. Stellen Sie sicher, dass Sie vor dem Start auf die neueste Version von [ComfyUI](https://github.com/Comfy-Org/ComfyUI) aktualisiert haben.
</Tip>

**text_encoders:**
- [umt5_xxl_fp8_e4m3fn_scaled.safetensors](https://huggingface.co/Comfy-Org/Wan_2.1_ComfyUI_repackaged/blob/main/split_files/text_encoders/umt5_xxl_fp8_e4m3fn_scaled.safetensors?download=true)

- [Wan2_1_VAE_bf16.safetensors](https://huggingface.co/Kijai/WanVideo_comfy/blob/main/Wan2_1_VAE_bf16.safetensors?download=true)

- [lightx2v_T2V_14B_cfg_step_distill_v2_lora_rank64_bf16.safetensors](https://huggingface.co/Kijai/WanVideo_comfy/blob/main/lightx2v_T2V_14B_cfg_step_distill_v2_lora_rank64_bf16.safetensors?download=true)

### Schritte zum Ausführen

1. **Aufgabentyp auswählen**: Wählen Sie Ihre Aufgabe (Image Editing, Subject to Image usw.).
2. **Eingänge verbinden**: Laden Sie das Quellbild und optionale Referenzbilder.
3. **Prompt schreiben**: Beschreiben Sie die gewünschte Bearbeitung.
4. **Ausführen**: Klicken Sie auf Warteschlange oder verwenden Sie `Cmd+Enter`.

**Eingabe „Referenzbild“:** Verwenden Sie diese für **Subject to Image**, wenn Sie ein oder mehrere Referenzbilder benötigen (Motiv, Outfit, Szene, Requisiten). Verwenden Sie im Prompt `image0`, `image1`, …, um auf jedes Bild zu verweisen. Für **Image Editing** ist diese Eingabe nicht erforderlich: Diese Aufgabe verwendet stattdessen `source_image`.

### Schritte zum Ausführen

1. **Quellvideo laden**: Verbinden Sie Ihr Eingabevideo.
2. **(Optional) Referenzen laden**: Referenzbilder oder Referenzvideo
3. **Aufgabentyp auswählen**: v2v, rv2v, r2v oder ads2v
4. **Prompt schreiben**: Beschreiben Sie die gewünschte Bearbeitung.
5. **Ausführen**: Klicken Sie auf Warteschlange oder verwenden Sie `Cmd+Enter`.

**Eingabe „Reference Image“:** Verwenden Sie diese, wenn eine Aufgabe ein oder mehrere Referenzbilder benötigt (rv2v, r2v, Outfits aus mehreren Teilen). Jedes gebündelte Bild wird zu einem eigenen In-Context-Token. Nennen Sie `image0`, `image1`, … im Prompt, wenn die Referenzen unterschiedliche Rollen spielen.
