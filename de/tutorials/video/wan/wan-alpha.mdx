Wan-Alpha ist ein spezialisiertes Text-zu-Video-Modell, das hochwertige Videos mit Alpha-Kanal-Transparenz erzeugt. Aufbauend auf dem Basismodell Wan2.1-14B-T2V erstellt es Videos mit transparentem Hintergrund und halbtransparenten Objekten und eignet sich damit ideal für Compositing-Workflows.

Das Modell zeichnet sich bei der Erzeugung transparenter Hintergründe, halbtransparenter Objekte (Blasen, Glas, Wasser), leuchtender Effekte und feiner Details mit korrektem Alpha-Kanal (Haare, Rauch, Partikel) aus.

### 3. Workflow Schritt für Schritt abschließen

1. Stellen Sie sicher, dass im Node `Load Diffusion Model` das richtige Diffusionsmodell geladen ist
2. Stellen Sie sicher, dass im Node `Load CLIP` die Datei `umt5_xxl_fp8_e4m3fn_scaled.safetensors` geladen ist
3. Stellen Sie sicher, dass im Node `Load VAE` für RGB die Datei `wan_alpha_2.1_vae_rgb_channel.safetensors` geladen ist
4. Stellen Sie sicher, dass im zweiten Node `Load VAE` für Alpha die Datei `wan_alpha_2.1_vae_alpha_channel.safetensors` geladen ist
5. Stellen Sie sicher, dass im Node `LoRA Loader` die Datei `wan_alpha_2.1_rgba_lora.safetensors` geladen ist
6. (Optional) Laden Sie `lightx2v_T2V_14B_cfg_step_distill_v2_lora_rank64_bf16.safetensors` im Lightning-LoRA-Node für eine schnellere Generierung
7. Legen Sie Ihren positiven Prompt im Node `CLIP Text Encode (Positive Prompt)` fest
8. (Optional) Ändern Sie die Videoabmessungen im Node `EmptyHunyuanLatentVideo`
9. Klicken Sie auf die Schaltfläche `Run` oder verwenden Sie `Ctrl(Cmd) + Enter`, um die Generierung auszuführen
