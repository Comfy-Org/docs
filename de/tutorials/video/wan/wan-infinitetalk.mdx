**Wan2.1 InfiniteTalk** ist ein quelloffenes, audiogesteuertes Videogenerierungsmodell auf Basis von Wan2.1, das von [MeiGen-AI](https://github.com/MeiGen-AI/InfiniteTalk) entwickelt wurde. Damit können Sie Ganzkörpervideos einer sprechenden Person aus einem einzigen Referenzbild und einer Audioeingabe generieren. Die Mund- und Körperbewegungen der Figur werden automatisch an das bereitgestellte Audio angepasst synchronisiert.

**Wichtige Funktionen**:
- **Audiogesteuerter Lip-Sync**: Generiert natürliche Mundbewegungen, die zum eingegebenen Audio passen
- **Ganzkörperbewegung**: Bewahrt Identität, Hintergrund und Kamerabewegung und ergänzt synchronisierte Körperbewegungen
- **Dualer Modus**: Unterstützt sowohl Szenarien mit einer als auch mit mehreren Personen
- **ComfyUI Native**: Integrierter `WanInfiniteTalkToVideo`-Node, keine Custom Nodes erforderlich

## Workflow-Schritte

1. **Eingabebild laden**: Ziehen Sie das Referenzbild der Figur auf den Node `Load Image`. Für Szenarien mit mehreren Figuren verwenden Sie den Maskeneditor, um für jede Figur eine Maskierung zu zeichnen.
2. **Audiospuren laden**: Verbinden Sie Audiodateien mit den Nodes `Load Audio` (eine pro Figur).
3. **Diffusionsmodell laden**: Stellen Sie sicher, dass der Node `Load Diffusion Model` `Wan2_1-I2V-14B-480p_fp8_e4m3fn_scaled_KJ.safetensors` verwendet.
4. **Modell-Patches laden**: Laden Sie den passenden InfiniteTalk-Patch (Variante `single` oder `multi`) über den Node `ModelPatchLoader`.
5. **InfiniteTalk konfigurieren**: Passen Sie die Parameter des Nodes `WanInfiniteTalkToVideo` an, etwa `length` (Videolänge in Frames), `motion_frame_count` (vorherige Frames, die als Bewegungskontext dienen) und `audio_scale`.
6. **Generieren**: Führen Sie den Workflow aus. Das Modell erzeugt ein Ganzkörper-Video einer sprechenden Person, das mit dem eingegebenen Audio synchronisiert ist.

### Videolänge erweitern

Jede Gruppe **Video Extend** verlängert das Video um etwa 3,24 Sekunden (81 Frames bei 25 fps). Wenn Ihr Audio länger ist, können Sie:

1. Die Gruppe „Video Extend“ per Rechteckauswahl markieren
2. `Ctrl-C` drücken (Kopieren), dann `Ctrl-Shift-V` (Einfügen mit Verbindungen)
3. Den `IMAGE`-Ausgang des vorherigen Nodes `InfiniteTalk (Base Generation)` mit dem Eingang `previous_frames` des neuen Nodes `WanInfiniteTalkToVideo` verbinden
4. Den `IMAGE`-Ausgang des Nodes `Batch Images` mit dem Bild-Eingang des neuen Nodes `Batch Images` verbinden
