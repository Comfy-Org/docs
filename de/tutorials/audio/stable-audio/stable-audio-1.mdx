**Stable Audio 1.0** ist das erste Open-Source-Modell von Stability AI zur Audiogenerierung. Es nimmt einen Text-Prompt entgegen und erzeugt einen Audioclip. In ComfyUI funktioniert es wie eine Standard-Pipeline für Text zu Audio: CLIP kodiert den Prompt, ein KSampler entrauscht das Latent, und das VAE dekodiert es zu Audio.

**Verwandte Links**:
- [Hugging Face (stabilityai/stable-audio-open-1.0)](https://huggingface.co/stabilityai/stable-audio-open-1.0)

Der Workflow verwendet **Standard-Nodes von ComfyUI**: Es sind keine Custom Nodes erforderlich. Er lädt den Checkpoint von Stable Audio 1.0, kodiert Ihren Prompt über einen CLIP-Textencoder (t5-base), entrauscht das Latent-Audio mit einem KSampler und dekodiert es über das VAE des Modells zu Audio.

**Verwendung**:
1. **Checkpoint laden**: Der Node `CheckpointLoaderSimple` verwendet `stable-audio-open-1.0.safetensors`
2. **Prompt schreiben**: Geben Sie Ihre Beschreibung im Node `CLIPTextEncode` ein (z. B. „heaven church electronic dance music“)
3. **Dauer festlegen**: Passen Sie den Wert für die Länge im Node `EmptyLatentAudio` an (Standard: 47.6 Sekunden)
4. Klicken Sie auf **Run** (`Ctrl/Cmd + Enter`), um zu generieren. Das Audio wird unter `ComfyUI/output/audio/` gespeichert.

## Modell herunterladen

Beim Laden des Workflows zeigt ComfyUI Ihnen Download-Links für alle fehlenden Modelle an. Für die manuelle Einrichtung laden Sie die unten aufgeführten Dateien herunter und legen sie in den richtigen Ordnern ab.

### Checkpoint

<Card title="stable-audio-open-1.0.safetensors" icon="download" href="https://huggingface.co/StabilityAI/stable-audio-open-1.0/blob/main/stable-audio-open-1.0.safetensors">
    2.3GB. In models/checkpoints/ ablegen.
  </Card>

Legen Sie den Checkpoint hier ab:

```
📂 ComfyUI/
├── 📂 models/
│   └── 📂 checkpoints/
│       └── stable-audio-open-1.0.safetensors
```

### Text-Encoder

<Card title="t5-base.safetensors" icon="download" href="https://huggingface.co/Comfy-Org/t5-base/blob/main/t5-base.safetensors">
    Text-Encoder für die Prompt-Konditionierung. In models/text_encoders/ ablegen.
  </Card>

Legen Sie den Text-Encoder hier ab:

```
📂 ComfyUI/
├── 📂 models/
│   └── 📂 text_encoders/
│       └── t5-base.safetensors
```

Nachdem Sie die Dateien abgelegt haben, drücken Sie in ComfyUI **R**, um die Nodes zu aktualisieren und die neuesten Modelle zu laden.
