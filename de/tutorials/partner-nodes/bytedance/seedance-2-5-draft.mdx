Der Draft-Modus von Seedance 2.5 rendert eine schnelle, kostengünstige 480p-Vorschau, bevor Sie sich für ein vollständiges 1080p- oder 4K-Rendering entscheiden. So können Sie einen Prompt, ein erstes Frame oder eine Reihe von Referenzbildern überarbeiten, ohne für Generierungen in voller Auflösung zu bezahlen.

Der Draft-Modus ist in drei Seedance 2.5-Workflows verfügbar. Wählen Sie **Seedance 2.5 Draft** als Modell im Node Text to Video, First-Last-Frame to Video oder Reference to Video:

- **Text to video (T2V)**: Prompt und Dauer überarbeiten
- **Image to video (I2V)**: das erste Frame überarbeiten
- **Reference to video (R2V)**: Referenzbilder und Storyboard überarbeiten

Im Draft-Modus ist die Auflösung auf 480p festgelegt, und jeder Lauf liefert sowohl die Vorschau als auch eine `draft_task_id`, die das finale Rendering verwendet. Der Node für das finale Rendering bietet 1080p und 4K.

## So funktionieren die beiden Phasen

Jeder Draft-Workflow läuft in zwei Phasen ab:

1. **Draft erstellen**: Führen Sie den Node Seedance 2.5 mit dem Modell **Seedance 2.5 Draft** aus, um die 480p-Vorschau und die zugehörige `draft_task_id` zu erhalten. Der Node **Save Text** schreibt diese in eine `.txt`-Datei im Ausgabeordner. Führen Sie den Vorgang mit einem anderen Prompt oder einer anderen Eingabe erneut aus, bis der Draft passt.
2. **Finale rendern**: Kopieren Sie die `draft_task_id` aus dieser `.txt`-Datei in das Feld `draft_task_id` des Nodes **ByteDance Seedance 2.5 Draft to Final Video**, setzen Sie `resolution` auf 1080p oder 4K und führen Sie ihn aus. Der Node rendert das Finale und übernimmt alles, womit der Draft erstellt wurde, einschließlich Prompt, Eingabe, Dauer, Seitenverhältnis und Audio-Einstellung, sodass nichts erneut eingegeben werden muss.

Jede Vorlage legt die beiden Phasen in getrennten Node-Gruppen ab, benannt **Stage 1: Create and preview the draft video** und **Stage 2: Render the final video from the draft task ID**. Lassen Sie Stage 1 im Bypass, sobald Sie mit dem Draft zufrieden sind, denn ein zweiter Lauf des Draft-Nodes erstellt einen neuen Draft, statt den geprüften wiederzuverwenden.

## Tipps

- **Führen Sie nur die Phase aus, die Sie benötigen**: Wählen Sie die Nodes aus Stage 1 aus und drücken Sie `Ctrl+B` (`Cmd+B` unter macOS), um sie zu umgehen. Wählen Sie dann die Nodes aus Stage 2 aus und drücken Sie erneut `Ctrl+B`, um sie zu aktivieren, sodass nur das finale Rendering ausgeführt wird
- **Behalten Sie die Task-ID des Entwurfs**: Der **Save Text**-Node schreibt sie in eine `.txt`-Datei im Ausgabeordner, und Stage 2 liest sie von dort
- **Entwürfe bleiben 7 Tage nach ihrer Erstellung renderbar**, rendern Sie das finale Ergebnis also innerhalb dieses Zeitraums
