Seed Audio 1.0 ist ByteDances universelles Modell zur Audiogenerierung und jetzt als integrierter Node in ComfyUI verfügbar. Anders als traditionelle Text-to-Speech-Systeme, die nur Wörter vorlesen, versteht Seed Audio das gesamte Klangspektrum. Es kann Sprache, Musik, Soundeffekte, Umgebungsatmosphären und Dialoge mit mehreren Sprechenden aus einem einzigen Text-Prompt generieren.

## Wofür Seed Audio 1.0 geeignet ist

- **Multimodale Audioerzeugung**: Sprache, Musik, Soundeffekte und Umgebungsaudio aus einem einzigen Prompt. Beschreiben Sie, was Sie hören, und Seed Audio erzeugt es.
- **Stimmklonen**: Klonen Sie Stimmen aus bis zu 3 Referenzclips (im Prompt mit `@Audio1`, `@Audio2`, `@Audio3` gekennzeichnet) für Dialoge mit mehreren Figuren oder eine konsistente Erzählstimme.
- **Preset-Stimmen**: Wählen Sie aus den integrierten TTS 2.0-Stimmen, wenn Sie eine zuverlässige, hochwertige Narration ohne Referenzclip benötigen.
- **Bildgesteuerte Stimme**: Leiten Sie eine Stimme aus einem Charakterbild ab und stimmen Sie Tonfall und Stil auf das visuelle Motiv ab.
- **Feingranulare Steuerung**: Passen Sie Sprechgeschwindigkeit, Tonhöhe, Lautstärke und Samplerate für jede Generierung unabhängig an.
- **Dialoge mit mehreren Sprechern**: Benennen Sie Figuren direkt im Prompt, und Seed Audio übernimmt die Stimmzuweisung, die Sprecherwechsel und die emotionale Darbietung.
- **Bis zu 2 Minuten pro Durchlauf**: Generieren Sie längere Audioclips, die sich für Narration, Podcast-Ausschnitte, Videovertonung und Sounddesign eignen.

Mit diesen Fähigkeiten eignet sich Seed Audio 1.0 für ein breites Spektrum an Anwendungsfällen, darunter Video-Voiceovers, mehrfigurige Hörspiele, Produktdemos, E-Learning-Narration, Audio-Prototyping für Spiele und barrierefreie Inhalte.

## Seed Audio 1.0 in ComfyUI verwenden

Seed Audio 1.0 ist als integrierter Node **ByteDanceSeedAudio** verfügbar. Sie finden ihn im Node-Menü unter ByteDance.

### Referenzmodus auswählen

Der Node bietet vier Referenzmodi, die festlegen, wie die generierte Stimme konditioniert wird:

| Modus | Beschreibung | Wann verwenden |
|------|-------------|-------------|
| **Text only** | Beschreiben Sie alles (Stimmstil, Emotion, Atmosphäre und Dialog) im Prompt | Schnelle Generierung ohne Referenzmaterial |
| **Audio reference** | Verbinden Sie bis zu 3 Referenzaudioclips (max. 30s pro Clip) und kennzeichnen Sie sie im Prompt als `@Audio1`, `@Audio2`, `@Audio3` | Bestimmte Stimmen klonen oder Dialoge mit mehreren Charakteren erstellen |
| **Image reference** | Verbinden Sie ein Charakterbild; das Modell leitet daraus eine Stimme ab | Eine Stimme aus einem visuellen Charakterdesign ableiten |
| **Preset voice** | Wählen Sie im Dropdown-Menü eine integrierte TTS 2.0-Stimme aus | Zuverlässige Narration ohne Klonen |

### Prompt-Struktur

Für die besten Ergebnisse sollten Sie Ihren Prompt so aufbauen, dass er die Audioszene beschreibt:

- **Stimme und Emotion**: Beschreiben Sie Tonfall, Alter, Geschlecht, Akzent oder emotionale Darbietung
- **Atmosphäre und Hintergrund**: Beschreiben Sie die akustische Umgebung (ruhiges Studio, belebte Straße, Konzertsaal)
- **Soundeffekte**: Beschreiben Sie bestimmte Geräusche zum richtigen Zeitpunkt auf der Zeitachse
- **Dialogzeilen**: Schreiben Sie die zu sprechenden Zeilen und benennen Sie die Charaktere für Szenen mit mehreren Sprechern

**Beispiel: Narration mit Atmosphäre**
> „Eine ruhige, warme männliche Stimme spricht selbstbewusst. Sanfter Regen fällt im Hintergrund, gelegentlich ferner Donner. ‚Seed Audio 1.0 erzeugt natürliche Sprache mit voller Kontrolle über Tempo, Tonhöhe und Präsenz.'"

**Beispiel: Dialog mit mehreren Sprechern und Audioreferenzen**
> @Audio1 sagt nervös in einem leisen, schnellen Flüstern: „Hast du das gesehen?" @Audio2 antwortet ruhig und gedehnt: „Was gesehen? Es ist nur der Wind." Durchgehend leichte Windgeräusche.

### Parameter abstimmen

Nachdem Sie Ihre Eingänge verbunden haben, stimmen Sie diese Parameter auf das gewünschte Ergebnis ab:

- **Speech rate**: Standard 0 (normal). Reichweite -50 (0.5x) bis 100 (2.0x). Verwenden Sie negative Werte für entspannte Narration, positive für energetische Voiceovers
- **Pitch**: Verschiebung in Halbtönen (-12 bis +12). Nützlich für Charakterstimmen oder um einen bestimmten Stimmumfang zu treffen
- **Loudness**: Standard 0 (normal). Reichweite -50 (0.5x) bis 100 (2.0x). Anpassen für gleichbleibende Lautstärke bei unterschiedlichem Ausgangsmaterial
- **Sample rate**: Wählen Sie zwischen 8kHz und 48kHz. 24kHz ist ein guter Standard für Sprache; 44.1kHz oder 48kHz für Musik
- **Seed**: Steuert, ob der Node erneut ausgeführt wird; die Ergebnisse sind unabhängig vom Seed-Wert nicht deterministisch

### Sonderfälle und Einschränkungen

- **Dauer der Referenzclips**: Audioreferenzclips sind auf jeweils 30 Sekunden begrenzt. Bei längerem Referenzmaterial kürzen oder bearbeiten Sie den Clip, bevor Sie ihn verbinden
- **Reihenfolge der Audioreferenzen**: Referenzeingänge müssen lückenlos nacheinander verbunden werden (1, 2, 3)
- **Tag-Limit**: Pro Prompt werden maximal 3 `@AudioN`-Tags unterstützt
- **Zeichenlimit**: Prompts sind auf 3000 Zeichen begrenzt
- **Dauerlimit**: Maximal 2 Minuten Audio pro Lauf

## Loslegen

1. ComfyUI aktualisieren Sie auf die neueste Version
2. Fügen Sie den Node **ByteDanceSeedAudio** über das Node-Menü hinzu, oder öffnen Sie eine der oben genannten Workflow-Vorlagen
3. Wählen Sie Ihren Referenzmodus und verbinden Sie die Eingänge
4. Schreiben Sie Ihren Prompt, der die Audio-Szene und den Dialog beschreibt
5. Führen Sie den Workflow aus
