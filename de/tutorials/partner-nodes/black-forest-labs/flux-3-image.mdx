FLUX 3 ist das multimodale Grundlagenmodell von Black Forest Labs, angekündigt am 23. Juli 2026 und im Early Access verfügbar. Es lernt aus Bildern, Video und Audio in einer einzigen Architektur, die auf Self-Flow basiert, ihrem Ansatz, multimodale Generierung und Verständnis in einem Modell zu vereinen. FLUX 3 Image ist der Teil davon, der Standbilder generiert und bearbeitet. Funktionen und Grenzen können sich während der Early-Access-Phase noch ändern.

FLUX 3 Image verwandelt einen Text-Prompt in ein Bild oder bearbeitet und kombiniert bis zu 10 Referenzbilder. Sie verweisen im Prompt mit `image 1`, `image 2` und so weiter auf die Referenzen; das Modell interpretiert und erweitert den Prompt, bevor es generiert. Grounding per Web- und Bildsuche ist standardmäßig aktiv, sodass es die von Ihnen genannten Motive nachschlagen kann. Es liefert ein einzelnes Bild in einem von sechzehn Seitenverhältnissen und in einer von fünf Auflösungsstufen, von 0.75K (etwa 0.6 Megapixel) bis 4K (etwa 16.8 Megapixel).

In ComfyUI läuft FLUX 3 Image über den Partner-Node **FLUX 3 Image** und wird in Credits pro generiertem Bild abgerechnet, abhängig von der Auflösung. Drei Vorlagen decken Text zu Bild, Bearbeitung mit mehreren Referenzen und Layout-Steuerung per Rechteck ab.

## Was FLUX 3 Image gut kann

- **Text zu Bild**: erzeugt ein Bild aus einem Prompt, den das Modell zuerst interpretiert und erweitert
- **Bearbeitung mit mehreren Referenzen**: bearbeitet oder kombiniert bis zu 10 Referenzbilder, die im Prompt als `image 1` bis `image 10` adressiert werden
- **Layoutsteuerung mit Begrenzungsrahmen**: platziert Objekte und Text mit den Rechtecken aus dem Node Create Bounding Boxes genau dort, wo Sie sie haben möchten
- **Grounding über die Suche**: Web- und Bildersuche sind standardmäßig aktiviert, sodass das Modell benannte Motive recherchieren kann, bevor es zeichnet
- **Flexible Ausgabe**: sechzehn Seitenverhältnisse und fünf Auflösungsstufen, von 0.75K bis 4K
- **Typografie und Layout**: eignet sich für Poster, Überschriften, Bildunterschriften und layoutorientierte Designarbeit

## FLUX 3 Image Text-zu-Bild-Workflow

Generieren Sie ein Bild aus einem Text-Prompt. FLUX 3 Image interpretiert und erweitert den Prompt und rendert ihn anschließend in der von Ihnen gewählten Auflösung. Es sind keine Eingabedateien erforderlich.

### Schritte für Text zu Bild

1. Geben Sie einen Prompt im Node **FLUX 3 Image** ein
2. Legen Sie `resolution` (0.75K bis 4K) und bei Bedarf ein von `auto` abweichendes `aspect_ratio` fest
3. Lassen Sie `grounding` aktiviert, damit das Modell das Web und Bilder nach den von Ihnen genannten Motiven durchsuchen kann
4. Klicken Sie auf **Queue**, um das Bild zu generieren

### Schritte zur Bildbearbeitung

1. Laden Sie Ihre Referenzbilder in den Node **Load Image** hoch und fügen Sie über die Autogrow-Slots bis zu 10 weitere hinzu
2. Beschreiben Sie die Bearbeitung im Node **FLUX 3 Image** und benennen Sie jede Referenz als `image 1`, `image 2` und so weiter
3. Legen Sie `resolution` und `aspect_ratio` für die Ausgabe fest
4. Klicken Sie auf **Warteschlange**, um das bearbeitete Bild zu generieren

## FLUX 3 Image: Workflow zum Bearbeiten mit Begrenzungsrahmen

Platzieren Sie Objekte und Text an exakten Positionen, indem Sie Rechtecke aus dem Node **Create Bounding Boxes** in den Node **FLUX 3 Image** einspeisen. Die Rechtecke beziehen sich auf den Canvas, stellen Sie die Ausgabe daher auf dasselbe Seitenverhältnis ein. Jedes Rechteck trägt eine eigene Beschreibung, die dem Prompt hinzugefügt wird.

### Schritte zum Bearbeiten mit Begrenzungsrahmen

1. Laden Sie das Bild in den Node **Load Image** hoch
2. Zeichnen Sie Rechtecke mit **Create Bounding Boxes** und geben Sie jedem eine Beschreibung
3. Schreiben Sie die übergeordnete Anweisung in den Node **FLUX 3 Image**
4. Setzen Sie `aspect_ratio` auf das Seitenverhältnis des Canvas, auf dem die Rechtecke gezeichnet wurden
5. Klicken Sie auf **Queue**, um das Bild zu generieren
