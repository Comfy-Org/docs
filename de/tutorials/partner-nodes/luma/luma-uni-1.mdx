In **ComfyUI** erscheint Luma **Uni-1** als **Partner-Nodes** für die einheitliche Bildarbeit: **Create**-Graphen generieren neue Bilder aus Prompts (mit optionalen Referenzen); **Modify**-Graphen nehmen ein vorhandenes Bild als Eingabe und bearbeiten es direkt. Beides steuern Sie über den gewohnten Workflow: Verbinden Sie **Load Image** / **Save Image**, legen Sie Prompts, Seeds, Seitenverhältnis und Referenz-Slots am Luma-Node fest und stellen Sie den Graphen dann lokal in die Warteschlange oder öffnen Sie eine Vorlage auf **Comfy Cloud**.

Luma beschreibt Uni-1 als ein nicht auf Diffusion basierendes, Decoder-only autoregressives Modell, das Ihren Prompt durchdenkt, bevor es zeichnet. Auf dem Canvas kommt es vor allem darauf an, **Create vs Modify** zu wählen, Referenzen klar zu benennen und mit Seeds zu iterieren.

## Was Uni-1 unterscheidet

- **Zwei klare Modi**: Create Image (etwas Neues generieren) und Modify Image (etwas Bestehendes bearbeiten)
- **Bis zu 9 Referenzbilder**, jeweils mit einer definierten Rolle
- **Starke Kontrolle über Nischen- und spezifische visuelle Stile**
- **Seed-Unterstützung** für Reproduzierbarkeit und kontrollierte Iteration
- **Neun Seitenverhältnisse**, von ultrahoch bis ultrabreit
- **Textwiedergabe**, die tatsächlich lesbar ist
- **Verankerung in der Websuche** für realen Kontext
- **Mehrsprachige Prompts**
- **Multi-Panel-Ausgabe** mit zeitlicher Konsistenz

Wenn Sie die Modi und die Steuerung von Referenzen verstehen, verstehen Sie Uni-1.

## Was Luma Uni-1 besonders gut kann

Uni-1 zeichnet sich in einer Vielzahl von Aufgaben aus:

- **Fotorealismus** mit materialgetreuer Genauigkeit
- **Illustration und stilisierte Kunst** mit starker ästhetischer Kontrolle
- **Restaurierung alter Fotos** und Reproduktion von Vintage-Optik
- **Surreale und konzeptionelle** Kompositionen
- **Textdarstellung**: lesbarer Text in Bildern, ideal für Infografiken und Poster
- **Bildbearbeitung** und mehrstufige Verfeinerung
- **Referenzgestützte Generierung** mit Erhalt der Identität
- **Mehrteilige Ausgabe**: konsistente Figuren und Szenen über mehrere Bilder hinweg

## Die zentrale Unterscheidung: Create oder Modify

Alles in Uni-1 beginnt mit einer Frage: **Erstelle ich etwas Neues oder ändere ich etwas, das bereits existiert?**

| Modus | Funktion | Verwendung |
| --- | --- | --- |
| **Create Image** | Erzeugt eine völlig neue Komposition. Kann durch Referenzen inspiriert sein. | „Eine neue Szene im Stil dieses Fotos erstellen“ |
| **Modify Image** | Bearbeitet ein bestimmtes Eingabebild. Behält Komposition und Struktur bei, sofern nicht anders angegeben. | „Dieses Foto wie eine Nachtaufnahme aussehen lassen“ |

Wenn Sie unsicher sind:

- Wenn die Ausgabe wie eine **Version Ihrer Eingabe** aussehen soll, verwenden Sie Modify.
- Wenn sie **inspiriert, aber neu** wirken soll, verwenden Sie Create.

Der Workflow ist einfach: **Prompt → bewerten → verfeinern**. Lassen Sie den Seed beim Erkunden leer. Sobald Sie etwas Gutes gefunden haben, fixieren Sie den Seed und iterieren von dort aus weiter.

## Kernparameter

| Parameter | Beschreibung |
| --- | --- |
| **Prompt** | Ihr wichtigstes Steuerungselement. Bis zu 6,000 Zeichen. Formulieren Sie präzise. |
| **Aspect ratio** | Steuert den Bildausschnitt, nicht die Qualität. Die Wahl richtet sich nach dem Anwendungsfall. |
| **Seed** | Gleicher Seed + gleicher Prompt → gleiches Ergebnis. Gleicher Seed + geänderter Prompt → kontrollierte Variation. Kein Seed → Exploration. |
| **Reference images** (Create) | Bis zu 9 Bilder zur Steuerung verschiedener Aspekte. |
| **Source image** (Modify) | Das Bild, das Sie bearbeiten. Die Abmessungen werden automatisch beibehalten. |

## Mit Referenzbildern arbeiten

Referenzen wirken nur, wenn Sie dem Modell sagen, wofür sie gedacht sind. Nutzen Sie diese Struktur:

```text
Use IMAGE1 ([description]) as a [ROLE] reference.
```

Mögliche Rollen: **Style**, **Character**, **Composition**, **Color palette**, **Lighting**, **Texture**, **Mood**.

Ohne Rollenangabe rät das Modell, und Raten ist unzuverlässig.

### Beispiele für den Create-Modus

**Style-Referenz**

```text
Use IMAGE1 (impressionist oil painting with loose brushwork and warm
sunset tones) as a STYLE reference. Create a portrait of a woman in her
30s applying IMAGE1's color palette and painterly texture. The subject
should be new.
```

**Character-Referenz**

```text
Use IMAGE1 (woman with short copper-red hair, freckles) as a CHARACTER
reference. Preserve her features. Generate a new scene: she's sitting
in a softly lit café.
```

**Mehrere Referenzen**

```text
Use IMAGE1 as a COLOR PALETTE reference, IMAGE2 as LIGHTING, IMAGE3 as
COMPOSITION. Create a lone figure walking through a rain-slicked street
at night.
```

### Beispiele für den Modify-Modus

Im Modify-Modus entscheidet Klarheit. Geben Sie immer an, **was geändert werden soll** und **was unverändert bleiben muss**.

```text
Change the time of day to golden hour. Update sky, light direction,
shadows, and color temperature. Keep all subjects and composition
unchanged.
```

```text
Make the rain heavier and add reflections on the ground. Keep all other
elements unchanged.
```

## Prompting-Richtlinien

Empfohlene Längen:

- **Text zu Bild** → 80–250 Wörter
- **Referenzgesteuert** → 100–300 Wörter
- **Modify** → 30–100 Wörter

Vermeiden Sie vage Begriffe („beautiful“, „amazing“), redundante Formulierungen und widersprüchliche Anweisungen. Verwenden Sie stattdessen konkrete, klar benannte Ästhetiken:

- `Golden hour, 85mm lens, shallow depth of field`
- `1970s Italian giallo film poster, high-contrast color blocking`

Präzision schlägt Allgemeinheit.

## Seitenverhältnisse

Wählen Sie das Seitenverhältnis danach, wo das Bild verwendet wird:

| Seitenverhältnis | Anwendungsfall |
| --- | --- |
| 1:1 | Social-Media-Beiträge |
| 9:16 | Vertikales Video |
| 16:9 | Breitbild |
| 3:2 / 2:3 | Fotografie |
| 2:1 / 3:1 | Cinematic / Panorama |
| 1:2 / 1:3 | Ultra-hoch |

Im Modify-Modus ist das Seitenverhältnis auf das Quellbild festgelegt.

## Seeds: Kontrolle und Reproduzierbarkeit

Mit Seeds werden aus Experimenten Systeme.

- **Fester Seed** → Konsistenz
- **Kein Seed** → Exploration

Workflow:

1. Ohne Seed explorieren
2. Ein starkes Ergebnis finden
3. Den Seed fixieren
4. Immer nur eine Variable ändern

Speichern Sie Prompt und Seed gemeinsam. Das ist Ihr wiederverwendbares Rezept.

## Erweiterte Techniken

### Charakterkonsistenz

1. Generieren Sie ein sauberes, frontales Referenzbild
2. Verwenden Sie es in jeder Szene erneut als `IMAGE1 (CHARACTER)`
3. Behalten Sie die Bezeichnung in allen Prompts identisch bei

### Architektur mit mehreren Referenzen

Weisen Sie jedem Bild eine Rolle zu:

- IMAGE1 → Charakter
- IMAGE2 → Stil
- IMAGE3 → Beleuchtung
- IMAGE4 → Umgebung

Beenden Sie den Prompt mit:

```text
Treat each reference as having authority over its assigned layer only.
```

### Kette Erstellen → Ändern

Nutzen Sie Create, um Kompositionen zu erkunden, und Modify, um Details zu verfeinern. Das ist einer der leistungsfähigsten Workflows.

### Iterative Verfeinerung

1. Explorieren (ohne Seed)
2. Seed fixieren
3. Pro Generierung nur eine Variable ändern
4. Ergebnisse dokumentieren

Es fühlt sich langsamer an, ist aber tatsächlich schneller, weil Sie immer wissen, was sich geändert hat.

## Fehlerbehebung

| Problem | Lösung |
| --- | --- |
| Referenzen werden ignoriert | Versehen Sie jede mit einer eindeutigen Bezeichnung |
| Ändern verändert zu viel | Geben Sie ausdrücklich an, was unverändert bleiben muss |
| Inkonsistente Ausgänge | Seed fixieren |
| Prompt wird teilweise ignoriert | Konflikte entfernen oder in Schritte aufteilen |
| Ausgabe sieht wie das Referenzbild aus | Möglicherweise befinden Sie sich im Ändern-Modus |
| Inkonsistenz bei Charakteren | Ein kanonisches Referenzbild wiederverwenden |

## Schnellreferenz

**Create Image**

- Neue Kompositionen
- Text + bis zu 9 Referenzen
- Beschreibende Prompts

**Modify Image**

- Bearbeitet vorhandene Bilder
- Quellbild + Referenzen
- Direkte, präzise Prompts

## Die goldenen Regeln

1. Geben Sie jeder Referenz ein Label
2. Geben Sie im Modify-Modus immer an, was sich **nicht** ändern soll
3. Ändern Sie beim Verfeinern jeweils nur eine Variable
4. Speichern Sie Prompt + Seed für die Reproduzierbarkeit
5. Create = neue Szenen, Modify = Änderungen

## Das Wichtigste

Uni-1 zu beherrschen, hängt an drei Dingen: **den passenden Modus wählen → Referenzen steuern → gezielt iterieren**. Wenn diese Punkte sitzen, raten Sie nicht mehr, sondern führen Regie.
