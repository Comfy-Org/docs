**Breeze TTS 2** ist das Open-Weight-Stimmmodell von Breeze Blue für Text to Speech, mit muttersprachlichem Englisch und Chinesisch sowie einer mehrsprachigen Variante, die 51 Sprachen abdeckt.

In ComfyUI läuft es über Partner-Nodes. **Breeze Text to Speech** rendert ein Skript mit einer gewählten Stimme. **Breeze Voice Selector** wählt eine vorgestellte Stimme oder eine beliebige Voice-ID, die Sie besitzen. Vier weitere Nodes erstellen und passen Stimmen an: **Breeze Voice Clone** kopiert eine Stimme aus einer Aufzeichnung, **Breeze Voice Design** erfindet eine Stimme aus einer Beschreibung, **Breeze Voice Remix** verändert eine vorhandene Stimme, und **Breeze Voice Localize** überträgt eine Stimme in eine andere Sprache. Alle sind Cloud-API-Nodes: Sie benötigen ein Comfy-Konto mit Credits, und es wird kein lokales Modell heruntergeladen. Die Preise finden Sie auf der [Preisseite für Partner-Nodes](/de/tutorials/partner-nodes/pricing).

## Text zu Sprache

Schreiben Sie die Zeile, und der Node gibt Audio zurück, in dem sie mit der ausgewählten Stimme gesprochen wird. Audio-Tags wie `(sighs)` oder `(laughs)` werden ausgeführt und nicht vorgelesen, sodass eine Pause oder ein Lachen aus dem Modell kommt und nicht von der Seite.

Die Vorlage spricht mit einer geklonten Stimme. `breeze_tts2_tts_clone_audio.wav` läuft durch **Breeze Voice Clone**, und die zurückgegebene Voice-ID speist **Breeze Voice Selector** mit `language` auf `custom`, was **Breeze Text to Speech** ansteuert. Um stattdessen eine vorgestellte Stimme zu verwenden, verbinden Sie den anderen **Breeze Voice Selector** in der Vorlage (Sprache `English`, Stimme `Elizabeth`) mit dem `voice`-Eingang von **Breeze Text to Speech**; er ist im Workflow enthalten, aber nicht verbunden.

Zwei weitere Gruppen werden im umgangenen Zustand mitgeliefert: **Breeze Voice Remix** ändert eine Stimme, die Sie bereits haben, und **Breeze Voice Design** erstellt eine aus einer Beschreibung. Beide geben eine Voice-ID an ihrem `voice`-Ausgang zurück, der nicht verbunden ist. Verbinden Sie diesen Ausgang mit einem **Preview as Text**-Node, um die ID zu lesen, oder direkt mit dem `voice`-Eingang von **Breeze Text to Speech**. Wählen Sie die Nodes der Gruppe aus, drücken Sie **Ctrl+B**, um die Umgehung aufzuheben, führen Sie den Graphen aus und fügen Sie dann die ID in **Breeze Voice Selector** ein, wobei `language` auf `custom` gesetzt ist.

## Sprechweise steuern

`delivery` legt fest, wie die Zeile gelesen wird:

- `neutral` hält die Stimme nah an ihrem eigenen Ton. `speaker_boost` hält sie näher am Original.
- `directed` folgt geschriebenen `instructions`, etwa „warm und ohne Eile, beim letzten Wort lächelnd“. Schreiben Sie sie in derselben Sprache wie den Text und legen Sie `strength` fest, um zu steuern, wie wörtlich die Stimme ihnen folgt.

`speed` ändert das Tempo von 0.5 bis 2.0, ohne die Tonhöhe zu ändern.

## Stimmen erstellen

| Node | Eingabe | Ergebnis |
| --- | --- | --- |
| Breeze Voice Clone | Ein Sprecher, mindestens 3 Sekunden. Es werden nur die ersten 60 Sekunden der Datei gelesen, und Breeze behält die besten 30 Sekunden. `remove_background_noise` hilft bei einer rauen Handyaufnahme | Eine neue Stimmen-ID sowie eine Audio-Vorschau |
| Breeze Voice Design | `description` mit 3 bis 500 Zeichen (Alter, Geschlecht, Akzent, Ton, Tempo) und eine Zeile `preview_text`. Die Stimme wird aus dieser Zeile erzeugt, schreiben Sie sie daher in der Zielsprache | Eine neue Stimmen-ID sowie eine Audio-Vorschau |
| Breeze Voice Remix | Eine bestehende Stimme und entweder eine in Worten beschriebene `change`-Angabe oder eines von 27 Presets aus den Bereichen Alter, Geschlecht, Tonhöhe, Tempo, Energie, Emotion, Rollenspiel und Vortragsweise. `strength` von 1 bis 10 legt fest, wie stark die Veränderung ausfällt | Eine veränderte Kopie der Stimme |
| Breeze Voice Localize | Eine bestehende Stimme und eine Zielsprache | Dieselbe Stimme, die eine andere Sprache spricht |

Der Stimmenremix behält die Originalsprache bei; verwenden Sie die Sprachlokalisierung, um in eine andere Sprache zu wechseln. Verwenden Sie beim Klonen nur eine Stimme, die Sie reproduzieren dürfen: Eine Einwilligung ist erforderlich.

## Node-Steuerungen

| Steuerung | Werte | Gilt für | Wirkung |
| --- | --- | --- | --- |
| `voice` | hervorgehobene Stimmen oder eine benutzerdefinierte ID | Text to Speech | Die Stimme, mit der gesprochen wird, aus der Breeze-Stimmauswahl oder einem anderen Node, der Stimmen erzeugt |
| `text` | bis zu 1000 Zeichen | Text to Speech | Die Zeile, die gesprochen wird. Audio-Tags in Klammern werden umgesetzt |
| `language` | acht hervorgehobene Sprachen oder `custom` | Stimmauswahl | Gruppiert die hervorgehobenen Stimmen. Sprachen ohne hervorgehobene Stimme benötigen eine Stimm-ID in `custom`, etwa eine, die mit der Breeze-Sprachlokalisierung erstellt wurde |
| `language` | 51 Sprachen | Text to Speech, Design | Sprache des Textes. Englisch und Chinesisch können beide Modelle verwenden; jede andere Sprache nutzt das mehrsprachige Modell |
| `model` | `Breeze TTS 2`, `Breeze TTS 2 Multilingual` | Text to Speech, Design | Wird nur für Englisch und Chinesisch angezeigt, die auf beiden Modellen laufen |
| `delivery` | `neutral`, `directed` | Text to Speech | Schlichtes Vorlesen oder ein Vorlesen, das geschriebenen Anweisungen folgt |
| `speed` | 0.5 bis 2.0 | Text to Speech | Tempo, wobei die Tonhöhe unverändert bleibt |
| `seed` | Ganzzahl | alle Stimmen-Nodes | Steuert, ob der Node erneut ausgeführt wird; die Ergebnisse variieren zwischen den Läufen |

Eine Stimme klingt in ihrer eigenen Sprache am besten. Um eine andere Sprache in einer vertrauten Stimme zu sprechen, führen Sie sie zuerst durch die Breeze-Sprachlokalisierung.
