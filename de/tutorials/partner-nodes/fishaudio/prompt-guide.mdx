Mit Fish Audio TTS steuern Sie direkt, wie die Sprachausgabe klingt, indem Sie Inline-Tags im Text selbst verwenden. Diese Anleitung behandelt alle Tag-Kategorien, die das Modell versteht, wo Sie sie platzieren und wie Sie sie kombinieren. Die folgenden Tags gelten für `s2.1-pro` und `s1`. Drama 3 verwendet stattdessen Anweisungen in einfacher Sprache und gepaarte Wort-Tags, die auf der Seite [Fish Audio Drama 3](/de/tutorials/partner-nodes/fishaudio/drama-3) beschrieben werden.

Die folgenden Beispiele funktionieren im Node Fish Audio Text to Speech. Geben Sie sie direkt in das Feld `text` ein und ersetzen Sie das Beispielskript durch Ihren eigenen Text. Informationen zur Node-Einrichtung, zu Workflow-Vorlagen und zur Preisgestaltung finden Sie unter [Fish Audio: Text zu Sprache, Stimmklonen und Sprache zu Text](/de/tutorials/partner-nodes/fishaudio/fish-audio).

## So funktionieren Tags

Die Modelle von Fish Audio S2 interpretieren Hinweise in natürlicher Sprache, die Sie in eckigen Klammern in Ihren Text schreiben:

```text
[happy] What a beautiful day!
[sad] I'm sorry to hear that.
[excited] This is amazing news!
```

Drei Eigenschaften machen dieses System flexibel:

- **Die Position bestimmt die Bedeutung.** Ein Tag gilt von der Stelle, an der er erscheint, bis zum nächsten Tag oder bis zum Ende des Satzes. `[whispering] I didn't want to go inside` flüstert die gesamte Zeile. `I didn't want to go [whispering] inside` beginnt bei „inside“ zu flüstern.
- **Freie Beschreibungen funktionieren.** Sie sind nicht auf einen festen Tag-Satz beschränkt. Wenn Sie es einem Synchronsprecher beschreiben können, schreiben Sie es in eckigen Klammern: `[tired, end of a long shift]`, `[voice rough from crying, trying to sound normal]`, `[professional broadcast tone]`.
- **Tags funktionieren in Ihrer Sprache.** Schreiben Sie die Hinweise in derselben Sprache wie Ihr Skript: `[低声说] 不要让他们听见`, `[ため息をついて] もう一度やり直そう`.

Das ältere Modell `s1` verwendet dieselben Emotionsnamen, setzt sie aber in Klammern mit einem festen Tag-Satz: `(happy) What a beautiful day!` Das aktuelle Modell `s2.1-pro` akzeptiert Klammer-Hinweise und freie Beschreibungen.

## Tonmarker

Tonmarker steuern Lautstärke, Intensität und Betonung. Setzen Sie `[emphasis]` direkt vor das Wort oder die Phrase, die Sie betonen möchten:

```text
This is [emphasis] really important.
```

| Tag | Wirkung | Wann verwenden |
|-----|----------|-------------|
| `[in a hurry tone]` | Gehetzt, dringend | Zeitkritische Informationen |
| `[shouting]` | Laut, rufend | Aufmerksamkeit erregen |
| `[screaming]` | Sehr laut, panisch | Notfälle, Angst |
| `[whispering]` | Sehr leise, verschwörerisch | Geheimnisse, ruhige Szenen |
| `[soft tone]` | Sanft, leise | Trost, Schlaflieder |
| `[emphasis]` | Ein Wort oder eine Phrase betonen | Hervorheben wichtiger Wörter |

## Audioeffekte

Audioeffekt-Tags fügen natürliche menschliche Laute hinzu. Fügen Sie dem Tag den passenden Text hinzu, wo er vorgeschlagen wird:

| Tag | Beschreibung | Empfohlener Text nach dem Tag |
|-----|-------------|------------------------------|
| `[laughing]` | Volles Lachen | Ha, ha, ha |
| `[chuckling]` | Leichtes Lachen | Heh, heh |
| `[sobbing]` | Starkes Weinen | Optionaler Text |
| `[crying loudly]` | Intensives Weinen | Optionaler Text |
| `[sighing]` | Ausatmen aus Erleichterung oder Frustration | sigh |
| `[groaning]` | Geräusch der Frustration | ugh |
| `[panting]` | Außer Atem | huff, puff |
| `[gasping]` | Scharfes Einatmen | gasp |
| `[yawning]` | Müder Ton | yawn |
| `[snoring]` | Schlafgeräusch | zzz |
| `[clear throat]` | Räuspern | ahem |

## Pausen und Spezialeffekte

| Tag | Beschreibung |
|-----|-------------|
| `[break]` | Kurze Pause beim Sprechen |
| `[long-break]` | Verlängerte Pause beim Sprechen |
| `[short pause]` | Kurzer Takt zwischen den Zeilen |
| `[long pause]` | Verlängerte Stille |
| `[audience laughing]` | Lachendes Publikum |
| `[background laughter]` | Lachen im Hintergrund |
| `[crowd laughing]` | Lachen einer großen Gruppe |

Auch einfache Pausenwörter formen den Rhythmus ganz ohne Tags: „um“, „uh“, „嗯“, „啊“.

## Tags kombinieren

**Kombinieren Sie einen physischen Tag mit einem Emotions-Tag.** Physische Tags wie `[panting]` oder `[whispering]` wirken schon für sich, zusammen mit einer Emotion ergeben sie aber konsistentere und natürlichere Ergebnisse:

```text
[panting] [tired] I've been running for twenty minutes.
[whispering] [scared] Don't move. Don't make a sound.
[shouting] [angry] I told you this would happen!
```

**Schichten Sie Emotionen für komplexe Ausdrücke.** Verwenden Sie pro Satz höchstens drei Tags:

```text
[sad][whispering] I miss you so much.
[angry][shouting] Get out of here now!
[excited][laughing] We won! Ha ha!
```

**Schreiben Sie Emotionswechsel** als natürlichen Verlauf über mehrere Sätze:

```text
[happy] I got the promotion!
[uncertain] But... it means relocating.
[sad] I'll miss everyone here.
[hopeful] Though it's a great opportunity.
[determined] I'm going to make it work!
```

**Fügen Sie Hintergrundeffekte** für Atmosphäre hinzu:

```text
The comedy show was amazing [audience laughing]
```

**Modulieren Sie die Intensität** mit beschreibenden Zusätzen:

```text
[slightly sad] I'm a bit disappointed.
[very excited] This is absolutely amazing!
[extremely angry] This is unacceptable!
```

## Bewährte Vorgehensweisen

**Empfohlen:**

- Verwenden Sie eine primäre Emotion pro Satz
- Passen Sie Emotionen logisch an den Kontext an
- Fügen Sie nach Soundeffekten Text hinzu, zum Beispiel „Ha ha“ nach `[laughing]`
- Lassen Sie zwischen emotionalen Wechseln Abstand, um Realismus zu erzeugen
- Testen Sie verschiedene Kombinationen mit derselben Stimme

**Nicht empfohlen:**

- Verwenden Sie Tags in kurzem Text nicht übermäßig
- Mischen Sie keine widersprüchlichen Emotionen in einem Satz
- Schreiben Sie Beschreibungen in eckigen Klammern nicht so lang, dass sie den Fluss unterbrechen
- Lassen Sie einen beschreibenden Tag nicht ohne nachfolgenden Text
- Platzieren Sie Emotionshinweise auf Satzebene nicht weit entfernt von dem Satz, den sie steuern

Wenn die Ausgabe unnatürlich klingt, lassen Sie mehr Abstand zwischen emotionalen Wechseln, verringern Sie die Intensität oder versuchen Sie eine andere Stimme: Derselbe Tag wirkt auf verschiedenen Stimmen anders.

## Dialog mit mehreren Sprechern

Verbinden Sie zwei oder mehr Stimmen mit dem Node Fish Audio Text to Speech und markieren Sie Sprecherwechsel im Text mit `@Voice1`, `@Voice2` und so weiter. Jede verbundene Stimme muss mindestens einmal im Text vorkommen, sonst meldet der Node einen Fehler. Das Verbinden von Stimmen wird in [Fish Audio: Text to Speech, Voice Cloning, and Speech to Text](/de/tutorials/partner-nodes/fishaudio/fish-audio#stimmen-verbinden) beschrieben.

```text
@Voice1 [nervous] You're sure no one followed you?
@Voice2 [calm] Relax. I took the long way, exactly like you asked.
@Voice1 [sighing][relieved] Good. Then let's see what's inside.
@Voice2 [curious] You don't even know what it is?
```

## Phonemsteuerung

Phonem-Tags legen die exakte Aussprache für Namen, Homographen, Akronyme und Fachbegriffe fest. Setzen Sie die Ersatzaussprache in die Tags `<|phoneme_start|>` und `<|phoneme_end|>`. Phonem-Tags bleiben bei der Textnormalisierung erhalten, lassen Sie `normalize` daher aktiviert.

**Englisch** (CMU-Arpabet, ersetzt ein Wort):

```text
I am an <|phoneme_start|>EH1 N JH AH0 N IH1 R<|phoneme_end|>.
```

**Chinesisch** (Pinyin mit Tonnummer, ersetzt ein Zeichen oder eine Silbe, nützlich für mehrdeutige Zeichen und Namen):

```text
我是一个<|phoneme_start|>gong1<|phoneme_end|><|phoneme_start|>cheng2<|phoneme_end|><|phoneme_start|>shi1<|phoneme_end|>。
```

**Japanisch** (OpenJTalk-Romaji mit Ziffern für den Tonhöhenakzent):

```text
<|phoneme_start|>ha0shi1ga0<|phoneme_end|>見えます。
```

Die Phonemsteuerung lässt sich im selben Text mit anderen Tags kombinieren:

```text
I am, um, an [break] <|phoneme_start|>EH1 N JH AH0 N IH1 R<|phoneme_end|>.
```

## Parameteroptimierung

Die Standardwerte sind gut abgestimmt. Ändern Sie sie nur, wenn Sie es benötigen:

| Parameter | Standard | Wirkung |
|-----------|---------|--------|
| `temperature` | 0.7 | Ausdrucksstärke. Höher ist variierter, niedriger ist konsistenter |
| `top_p` | 0.7 | Vielfalt durch Nucleus-Sampling |
| `speed` | 1.0 | Sprechgeschwindigkeit, 0.5 bis 2.0 |
| `volume` | 0.0 | Lautstärkeanpassung in Dezibel, -10 bis 10 |
| `normalize` | true | Erweitert Zahlen und Datumsangaben für eine natürliche Aussprache. Eingeschaltet lassen, außer die Normalisierung schreibt Text um, den Sie wörtlich vorgelesen haben möchten |

Der `seed` steuert, ob der Node erneut ausgeführt wird; die Ergebnisse sind unabhängig vom Seed-Wert nicht deterministisch.

## Qualität des Voice-Clonings

Beim Node Fish Audio Instant Voice Clone entscheidet die Qualität der Referenzaufzeichnung über das Ergebnis. Die Grenzen für Aufzeichnungen sind in [Fish Audio: Text to Speech, Voice Cloning, and Speech to Text](/de/tutorials/partner-nodes/fishaudio/fish-audio#grenzen-beim-klonen-von-stimmen) beschrieben:

- Nehmen Sie 2 bis 3 Clips von je 15 bis 20 Sekunden auf, insgesamt unter 270 Sekunden
- Nur eine sprechende Person, gleichmäßige Lautstärke, gleichbleibender Ton und gleichbleibende Emotion
- Kurze Pausen zwischen den Sätzen, etwa eine halbe Sekunde
- Ruhiger Raum, Mikrofon etwa eine Handbreit vom Mund entfernt
- Ein Handy-Rekorder oder ein Headset-Mikrofon reicht; vermeiden Sie Hintergrundmusik, Fernseher und Echo

Wenn die geklonte Stimme robotisch klingt, nehmen Sie mehr Material auf, insgesamt 30 bis 60 Sekunden, und sprechen Sie natürlich mit Pausen.

Klonen Sie nur Stimmen, für die Sie eine Berechtigung haben: Ihre eigene Stimme oder die Stimme einer Person, die Ihnen ausdrücklich die Erlaubnis dazu gegeben hat.
