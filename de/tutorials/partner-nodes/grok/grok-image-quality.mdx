Grok Imagine Image Quality war xAIs Bildmodell mit höherer Detailtreue, verfügbar in ComfyUI über die Grok Partner-Nodes. Es bot verbesserte Details, eine bessere Textwiedergabe und eine stärkere kreative Kontrolle im Vergleich zum Standard-Bildmodell von Grok.

## Was Grok Imagine Image Quality gut kann

- **Verbesserte Details**: Ausgabe mit höherer Detailtreue als das Standard-Bildmodell von Grok
- **Bessere Textwiedergabe**: verarbeitet Prompts, die Text enthalten, der im Bild dargestellt werden soll
- **Stärkere kreative Kontrolle**: mehr Kontrolle über das generierte Ergebnis im Vergleich zum Standardmodell
- **Auflösungsoptionen**: Ausgabe in 1K oder 2K

### Workflow-Übersicht

Dieser Workflow verwendet zwei Nodes:

- **GrokImageNode**: der zentrale Node, konfiguriert mit dem Modell `grok-imagine-image-quality`
- **SaveImage**: speichert das generierte Bild

### So führen Sie den Workflow aus

1. **Prompt eingeben**: Beschreiben Sie im **GrokImageNode** die Szene und jeden Text, der im Bild dargestellt werden soll
2. **Seitenverhältnis wählen**: wählen Sie aus den verfügbaren Seitenverhältnissen
3. **Auflösung festlegen**: `1K` oder `2K`
4. **Auf Queue klicken**: drücken Sie `Ctrl+Enter`, um zu generieren
