[OpenRouter](https://openrouter.ai) ist eine einheitliche Routing-Plattform für große Sprachmodelle. Sie stellt viele Anbieter über eine einzige API bereit, sodass Sie Modelle wechseln können, ohne Ihre Integration zu ändern. ComfyUI verbindet sich über den Partner-Node **OpenRouter LLM**, der eine kuratierte Liste von Text- und multimodalen Modellen (Claude, GPT, Gemini, Grok, Meta Muse, DeepSeek, Qwen, Mistral, GLM, Kimi und Perplexity Sonar) in einem einzigen Node anbietet.

## Wofür OpenRouter LLM geeignet ist

- **Text-Chat**: Prompts und optional `system_prompt` für Rollen- oder Aufgabenanweisungen
- **Vision**: Referenzbilder bei unterstützten Modellen anhängen (die Anzahl der Slots hängt vom Modell ab)
- **Videoeingabe**: Gemini 3.5 Flash, Qwen 3.6 Plus/Flash und die Meta Muse Modelle akzeptieren optionale Referenzvideos
- **Reasoning**: `reasoning_effort` bei Reasoning-/Frontier-Reasoning-Modellen (`off`, `low`, `medium`, `high`). Die Meta Muse Modelle führen immer Reasoning aus, daher beginnen ihre Stufen bei `minimal` und es gibt kein `off`
- **Websuche**: Perplexity Sonar Modelle stellen `search_context_size` für fundierte Antworten bereit

Die Token-Preise sind unter [Partner-Node-Preise](/tutorials/partner-nodes/pricing#openrouter) aufgeführt.

## Modellspezifische Eingaben

Das Dropdown **model** ist eine dynamische Combobox. Wenn Sie das Modell ändern, aktualisiert der Node, welche Eingaben angezeigt werden:

- **Image slots**: nur bei visionsfähigen Modellen sichtbar; die Anzahl der Slots entspricht dem Limit des Modells
- **Video slots**: nur bei Gemini 3.5 Flash und Qwen 3.6 Plus/Flash sichtbar
- **Reasoning effort**: bei Reasoning- und Frontier-Reasoning-Modellen sichtbar
- **Search context size**: bei Perplexity-Sonar-Modellen sichtbar

Nur-Text-Modelle blenden Bild- und Videoeingaben aus.

Wenn Sie die Vorlage als Referenz verwenden, sieht ein typischer Durchlauf so aus:

1. Laden Sie in **Load Image** das Referenzbild (für reinen Text-Chat überspringen)
2. Verbinden Sie in **OpenRouter LLM** das Bild mit `image_1` (weitere Slots werden angezeigt, wenn das Modell sie unterstützt)
3. Legen Sie im Feld **prompt** z. B. fest, dass das Modell das Bild analysieren und einen Prompt zur Generierung ausgeben soll
4. (Optional) Legen Sie **system_prompt** in den erweiterten Optionen für Tonfall, Format oder Einschränkungen fest
5. Wählen Sie im Feld **model** ein Modell aus; passen Sie **reasoning_effort** oder **search_context_size** an, wenn sie angezeigt werden
6. Klicken Sie auf **Run** oder drücken Sie `Ctrl(cmd) + Enter`
7. Sehen Sie sich die Antwort in **Preview Any** an

### Zusätzliche Hinweise

- **seed**: Auf `0` setzen, um ihn wegzulassen; die meisten Modelle behandeln ihn nur als Hinweis
- Referenzbilder und -videos werden beim Ausführen des Workflows automatisch hochgeladen; Sie verbinden lediglich die Bild- und Videoausgänge von ComfyUI mit dem Node
- Die Preise pro Modell finden Sie unter [OpenRouter auf der Preisseite](/tutorials/partner-nodes/pricing#openrouter)
