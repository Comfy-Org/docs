**Tencent HY4** ist das große Sprachmodell von Tencent, verfügbar in ComfyUI über den Partner-Node `Tencent HY`. Der Node nimmt einen Text-Prompt und bis zu 20 Bilder entgegen und gibt Text zurück: einen aus einem Referenzbild geschriebenen Kunst-Prompt, eine Bildbeschreibung, eine Diagramm-Aufschlüsselung oder jede andere Antwort, die Sie anfordern.

Hy4 wurde am 4. November 2026 veröffentlicht. Es ist die erste Hy-Generation mit visuellem Verständnis, und Tencent meldet Verbesserungen gegenüber Hy4 preview bei der Befolgung von Anweisungen, beim Verständnis langer Kontexte und bei langfristigen agentischen Aufgaben. Der Node ruft das Modell über die Comfy API auf, daher sind weder Modell-Downloads noch eine lokale GPU erforderlich.

Die hier behandelte Vorlage ist das Beispiel „Image to Prompt“: Sie liest ein Foto und schreibt einen durch Kommas getrennten Prompt, den Sie in ein Bildmodell einfügen können.

## Wofür der Tencent HY Node geeignet ist

- **Bild zu Prompt**: schreibt einen strukturierten Prompt, der Motiv, Komposition, Kamera, Beleuchtung, Farbe, Textur und Stil abdeckt
- **Bildverständnis**: Bildunterschriften, Analysen von Diagrammen und Schemata sowie Detailprüfungen von Fotos, Screenshots und Dokumenten
- **Mehrere Bilder pro Anfrage**: bis zu 20 Bilder in einem Aufruf, wobei jedes Bild in einem Batch einmal zählt
- **Anweisungssteuerung**: `system_prompt` enthält eine feste Rolle, während `prompt` die Aufgabe für diesen Lauf übernimmt
- **Reasoning-Umschalter**: `reasoning` lässt das Modell vor der Antwort nachdenken, für Aufgaben, die das erfordern
- **Lange Antworten**: `max_tokens` akzeptiert bis zu 64000 Tokens

### Schritte zum Ausführen des Workflows

Dieser Workflow zeigt, wie Sie mit Tencent HY eine Antwort generieren und diese Konversation optional in ComfyUI speichern. Laden Sie ein Referenzbild, führen Sie den Graphen aus und lesen Sie die Antwort anschließend in `Preview Any`. Wenn Sie eine gespeicherte Kopie möchten, behalten Sie `Save Text`, damit der Prompt und die Antwort unter `output/Hy4/` geschrieben werden; überspringen oder entfernen Sie diesen Node, wenn Sie nicht speichern müssen.

### Tipps zum Prompting

- Geben Sie das Ausgabeformat an. Die Zeile `Only output positive prompt, no extra explanations` in der Vorlage sorgt dafür, dass sich die Antwort direkt einfügen lässt
- Wenn Sie mehrere Bilder verbinden, verweisen Sie der Reihenfolge nach auf sie (`the first image`, `the second image`), damit die Details beim richtigen Bild landen
- Legen Sie wiederkehrende Anweisungen in `system_prompt` ab und lassen Sie `prompt` für die Aufgabe, zum Beispiel `You write photography prompts for a stock library`
- `seed` entscheidet nur, ob der Node erneut ausgeführt wird. Die Antworten variieren weiterhin zwischen den Läufen

## Loslegen

Aktualisieren Sie ComfyUI, suchen Sie in der Vorlagenbibliothek nach `Tencent: Hy4` und öffnen Sie den Workflow Image to Prompt.

Die Abrechnung von Tencent HY4 basiert auf der API-Token-Nutzung. Die Preise für Hy4 finden Sie in der [Preistabelle](/de/tutorials/partner-nodes/pricing).
