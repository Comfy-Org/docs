Anthropic Claude ist eine Familie leistungsstarker KI-Modelle, die für starkes Reasoning, Sicherheit und Fähigkeiten mit langem Kontext bekannt sind. ComfyUI hat die Anthropic Claude API über Partner-Nodes integriert, sodass Sie Claude direkt in Ihren Workflows für Konversations- und Bildanalyse-Aufgaben verwenden können.

## Wofür Anthropic Claude geeignet ist

- **Starkes Reasoning**: Eine Modellfamilie, die für starkes Reasoning, Sicherheit und Langkontextfähigkeiten bekannt ist
- **Konversations- und Bildanalyseaufgaben**: Verwenden Sie Claude direkt in Ihren ComfyUI-Workflows über Partner-Nodes
- **Multimodale Eingabe**: Jedes unterstützte Modell akzeptiert reine Text- und Text+Bild-Eingaben, mit bis zu 20 Bildern pro Anfrage
- **Ein Modell für jede Arbeitslast**: Von der Opus-Flaggschiffreihe bis zum schnellen, kosteneffizienten Haiku für Anwendungsfälle mit hohem Durchsatz

<Note>
In der entsprechenden Vorlage ist ein Prompt zum Analysieren und Erzeugen von Rollen-Prompts enthalten, mit dem Ihre Bilder in entsprechende Zeichen-Prompts interpretiert werden.
</Note>

Folgen Sie den nummerierten Schritten im Workflow-Bild, um die grundlegende Ausführung des Workflows abzuschließen:
1. Laden Sie im Node `Load Image` das Bild, das die KI interpretieren soll (optional: bei reinen Textanfragen überspringen)
2. Ändern Sie im Node `Anthropic Claude` den `prompt`, um Ihren Konversations-Prompt festzulegen, oder ändern Sie `model`, um ein anderes Claude-Modell auszuwählen
3. (Optional) Legen Sie den `system_prompt` fest, um die Verhaltensanweisungen des Modells zu definieren
4. Klicken Sie auf `Run` oder drücken Sie `Ctrl(cmd) + Enter`, um die Konversation auszuführen
5. Nachdem die API Ergebnisse zurückgegeben hat, sehen Sie die Antwort der KI im Node `Preview Any`

### Weitere Hinweise

- Passen Sie `max_tokens` (bis zu 32768) und `temperature` (0.0 bis 1.0) in den erweiterten Optionen des Nodes an. `temperature` ist nicht verfügbar, wenn Thinking aktiviert ist, oder bei `Opus 4.7`
- Der Parameter `seed` steuert, ob der Node erneut ausgeführt wird: Die Ergebnisse sind unabhängig vom Seed-Wert nicht deterministisch
