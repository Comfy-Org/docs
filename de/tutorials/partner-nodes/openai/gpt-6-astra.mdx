**GPT-6 Astra** ist OpenAIs leistungsfähigstes Modell und für die schwierigsten End-to-End-Aufgaben konzipiert: komplexes Reasoning, Coding, Computer Use, Recherche und das Erstellen von Dokumenten. Es wurde am 3. September 2026 veröffentlicht und unterstützt ein Kontextfenster von 1.050.000 Tokens, Text- und Bildeingabe sowie Reasoning-Stufen von `low` bis `max`.

In ComfyUI läuft GPT-6 Astra über den Node `OpenAI Chat`: Wählen Sie `gpt-6-astra` im Dropdown-Menü `model` des Nodes aus. Diese Seite konzentriert sich darauf, wie Sie das Modell in ComfyUI-Workflows verwenden. Die Grundlagen des Nodes, die für alle Modelle gelten, finden Sie im [OpenAI Chat-Tutorial](/de/tutorials/partner-nodes/openai/chat).

## Wann Sie GPT-6 Astra wählen sollten

Der Node `OpenAI Chat` bietet viele Modelle, von `gpt-5-nano` bis `gpt-6-astra`. GPT-6 Astra ist die stärkste, aber auch die teuerste Option. Sie eignet sich daher für Aufgaben, an denen günstigere Modelle scheitern:

- **Bildanalyse mit langem Kontext**: viele Bilder (über `Batch Images`) oder große Prompt-Dateien einspeisen und in einem Durchlauf eine strukturierte Analyse anfordern
- **Prompt-Engineering**: aus einem Referenzbild oder einer groben Idee einen detaillierten, durch Kommas getrennten positiven Prompt für Bild- oder Videomodelle machen
- **Agentische Workflows**: mehrstufige Aufgaben wie eine Dataset-Beschreibung analysieren, dann einen Generierungsplan schreiben und anschließend die Prompts selbst entwerfen
- **Komplexe Anweisungen befolgen**: präzise Ausgabeformate (JSON, YAML, feste Reihenfolge der Abschnitte), die kleinere Modelle häufig nicht einhalten

Für einfache Bildbeschreibungen oder kurze Antworten liefern `gpt-5` oder `gpt-5-mini` gute Ergebnisse zu einem Bruchteil der Kosten. Die Preise pro Modell finden Sie in der [Preistabelle](/tutorials/partner-nodes/pricing).

## Das Modell im Node OpenAI Chat verwenden

Der Node `OpenAI Chat` nimmt folgende Eingaben entgegen:

- `prompt`: die Anweisung. Beschreiben Sie bei Aufgaben zur Prompt-Generierung genau, was aus dem Bild extrahiert werden soll und welches Ausgabeformat Sie wünschen
- `images`: optionaler Bildkontext. Verbinden Sie einen `LoadImage`-Node oder `Batch Images` für mehrere Bilder; jedes verbundene Bild wird an das Modell gesendet
- `files`: optionale Dokumente aus dem Node `OpenAI Chat Input Files`
- `advanced_options`: optionale Konfiguration aus dem Node `OpenAI Chat Advanced Options`

Die Ausgabe ist ein `String`. Typische Möglichkeiten zur Weiterverwendung:

- In einen Node `Preview Any`, um die Antwort zu lesen
- In `Save Text`, um den generierten Prompt in eine `.txt`-Datei zu schreiben
- In den Eingang für den positiven Prompt eines Nodes `CLIP Text Encode`, wodurch vollautomatische Pipelines zur Bild- oder Videogenerierung entstehen, bei denen das LLM den Prompt schreibt
- In Texteingänge von Partner-Nodes, zum Beispiel um vor der Videogenerierung eine Szenenbeschreibung zu entwerfen

## Reasoning-Aufwand

GPT-6 Astra ist ein Reasoning-Modell. Verbinden Sie einen `OpenAI Chat Advanced Options`-Node und setzen Sie `reasoning_effort`, um die Abwägung zwischen Antwortqualität und Kosten zu steuern:

| Stufe | Verhalten |
|-------|----------|
| `default` | Das Modell wählt automatisch |
| `low` | Am schnellsten und günstigsten, geeignet für unkomplizierte Analysen |
| `medium` | Ausgewogener Standard für die Prompt-Generierung |
| `high` | Gründliche Analyse komplexer Bilder oder Anweisungen |
| `xhigh` | Tiefgehendes mehrstufiges Reasoning |
| `max` | Maximales Reasoning für die schwierigsten Aufgaben |

Derselbe Node bietet außerdem `max_output_tokens` (16 bis 16384, einschließlich Reasoning-Tokens) und ein `instructions`-Feld, das als dauerhafter System-Prompt wirkt und sich eignet, ein Ausgabeformat über viele Läufe hinweg festzulegen.

## GPT-6 Astra-Vorlage

Eine separate Vorlage zeigt, wie GPT-6 Astra ein Bild analysiert und daraus einen strukturierten KI-Kunst-Prompt generiert. Der Workflow lädt ein Bild, sendet einen Analyse-Prompt an den `OpenAI Chat`-Node, wobei `model` auf `gpt-6-astra` gesetzt ist, und schreibt das Ergebnis mit dem `Save Text`-Node in eine Textdatei.

Schritte:

1. Laden Sie Ihr Bild in den `LoadImage`-Node.
2. Passen Sie im `OpenAI Chat`-Node den Analyse-Prompt an oder wechseln Sie bei Bedarf den Wert von `model`. Der Prompt der Vorlage fordert das Modell auf, Motiv, Komposition, Kamera, Beleuchtung, Farbpalette, Textur und Stil zu extrahieren und anschließend ausschließlich einen durch Kommas getrennten positiven Prompt auszugeben.
3. Klicken Sie auf `Run`. Der generierte Prompt erscheint in der Vorschau und wird vom `Save Text`-Node in einer `.txt`-Datei gespeichert.

Wenn Sie weiterarbeiten möchten, kopieren Sie den gespeicherten Prompt in einen `CLIP Text Encode`-Node oder in einen Node für ein Bild- oder Videomodell und generieren Sie direkt aus der Ausgabe des Modells.

GPT-6 Astra wird anhand der API-Token-Nutzung abgerechnet, zu einem höheren Satz als bei anderen OpenAI Chat-Modellen. Details finden Sie in der [Preistabelle](/tutorials/partner-nodes/pricing).
