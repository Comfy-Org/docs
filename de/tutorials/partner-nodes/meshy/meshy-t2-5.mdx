**Meshy T2.5** erstellt ein 3D-Mesh direkt mit der von Ihnen vorgegebenen Dreiecksanzahl. Ältere Pipelines erzeugen ein dichtes Mesh und retopologisieren es anschließend, wodurch Details verloren gehen und eine Nachbearbeitung nötig ist, bevor das Asset ausgeliefert werden kann. T2.5 arbeitet von Anfang an auf das Dreiecksbudget hin, sodass ein Prop mit 15000 Dreiecken mit ungefähr 15000 Dreiecken zurückkommt und direkt in eine Engine übernommen werden kann.

ComfyUI stellt es über zwei Partner-Nodes bereit: **Meshy: Text to Model (Smart Topology)** und **Meshy: Image to Model (Smart Topology)**. Beide sind Cloud-API-Nodes, die ein Comfy-Konto mit Credits erfordern und keine Modelldateien lokal herunterladen. Jeder gibt eine GLB-Datei und eine FBX-Datei zurück, und die Vorlagen schreiben die GLB-Datei mit einem Save GLB-Node.

T2.5 ist der Modus für Props, Umgebungsgestaltung und Low-Poly-Spiel-Assets, bei denen eine vorhersehbare Dreiecksanzahl wichtig ist. Für Rigging, Animation und die vollständige Asset-Pipeline verwenden Sie stattdessen [Meshy 7](/de/tutorials/partner-nodes/meshy/meshy-7).

## Node-Steuerung

| Steuerung | Werte | Gilt für | Wirkung |
| --- | --- | --- | --- |
| `model` | `meshy-t2.5` | beide Nodes | Das Release des Smart-Topology-Modells |
| `prompt` | Text, bis zu 800 Zeichen | Text to Model | Beschreibung des Objekts, das erstellt werden soll |
| `image` | ein Bild | Image to Model | Das Quellbild, aus dem das Mesh erstellt wird |
| `target_polycount` | 100 bis 30000, Standard 15000 | beide Nodes | Ungefähre Dreiecksanzahl des Ergebnisses |
| `pose_mode` | leer, `A-pose`, `T-pose` | beide Nodes | Legt eine Körperhaltung für Charaktere fest. Für Requisiten leer lassen |
| `should_texture` | `true`, `false` | Image to Model | Ob das Mesh nach der Generierung texturiert wird |
| `enable_pbr` | standardmäßig aus | Image to Model, Texturierung aktiv | Fügt der Basisfarbe Metallic-, Rauheits- und Normal-Maps hinzu |
| `texture_prompt` | Text, bis zu 800 Zeichen | Image to Model, Texturierung aktiv | Text-Guidance für die Textur. Kann nicht mit `texture_image` kombiniert werden |
| `texture_image` | ein Bild | Image to Model, Texturierung aktiv | Bild-Guidance für die Textur. Kann nicht mit `texture_prompt` kombiniert werden |
| `texture_resolution` | `2k`, `4k`, `8k` | Image to Model, Texturierung aktiv | Auflösung der generierten Texturen |
| `seed` | Ganzzahl | beide Nodes | Steuert, ob der Node erneut ausgeführt wird. Die Ausgabe von Meshy ist unabhängig vom Seed nicht deterministisch |

Der Node gibt `meshy_task_id`, `GLB` und `FBX` aus. Save GLB schreibt die Datei aus dem Ausgang `GLB`, nicht aus der Task-ID oder dem FBX-Ausgang.

## Prompting-Tipps

- **Benennen Sie das Objekt und die Silhouette.** `Standalone game prop, clean silhouette, no text` hält das Modell davon ab, eine Szene, eine Basis oder einen Schriftzug hinzuzufügen, sodass Sie diese anschließend entfernen müssen.
- **Legen Sie das Budget vor dem Generieren fest.** Eine nachträgliche Änderung von `target_polycount` bedeutet eine neue Generierung. Entscheiden Sie daher zuerst, ob das Asset ein Hero-Prop oder Hintergrunddekoration ist.
- **Beschreiben Sie Material, nicht Licht-Setups.** Oberflächenbegriffe wie `weathered wood, iron banding, rusted lock plate` bleiben im Mesh und in der Textur erhalten. Wörter zur Studio-Beleuchtung beeinflussen nur, wie die Vorschau wirkt.
- **Verwenden Sie `pose_mode` nur für Charaktere.** A-Pose oder T-Pose ergeben eine rig-freundliche Haltung. Bei Props lassen Sie den Wert besser leer.
- **Texturieren Sie erst, wenn die Form stimmt.** Führen Sie den Node einmal ohne Texturierung aus, prüfen Sie die Silhouette und aktivieren Sie dann `should_texture` für den letzten Durchlauf.
- **Erwarten Sie nicht zweimal dasselbe Mesh.** Der Seed entscheidet nur, ob der Node erneut ausgeführt wird. Ein erneuter Lauf liefert daher ein neues Ergebnis.
