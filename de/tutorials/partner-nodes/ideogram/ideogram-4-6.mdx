**Ideogram 4.6** ist Ideograms Modell für Bildgenerierung und Bildbearbeitung mit nativer 4K-Ausgabe. Es rendert bis zu 4096x4096 in einem Durchgang, sodass Poster, Verpackungen und Produktaufnahmen kein separates Upscale benötigen. Precise Edit behält die Farben und Details der Pixel bei, die Sie nicht ändern wollten.

Es läuft als Modelloption in drei ComfyUI Partner-Nodes: **Ideogram Text to Image**, **Ideogram Edit** und **Ideogram Precise Edit**. Setzen Sie `model` in einem beliebigen davon auf `ideogram-4.6`, und wählen Sie in derselben Liste `ideogram-4.5`, um das ältere Modell zu verwenden, das [eine eigene Seite](/de/tutorials/partner-nodes/ideogram/ideogram-4-5) hat.

## Text zu Bild

Generieren Sie aus einem Text-Prompt ein Bild auf einem 1K-, 2K- oder 4K-Canvas.

![Beispielausgabe von Ideogram 4.6 Text zu Bild](https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/output/api_ideogram_v4_6_t2i.png)

Der Node **Ideogram Text to Image** nimmt folgende Eingaben:

| Eingabe | Werte | Auswirkung |
| --- | --- | --- |
| `prompt` | bis zu 10000 Zeichen | Die Bildbeschreibung. Eine strukturierte JSON-Beschriftung funktioniert ebenfalls, zum Beispiel ein `final_prompt` aus einem früheren Lauf |
| `size` | `auto`, eine 1K-, 2K- oder 4K-Voreinstellung oder `custom` | `auto` wählt einen Canvas, der zum Prompt passt. Die Voreinstellungen decken 1K-, 2K- und 4K-Canvas von Hochformat `1:3` und `9:23` bis Querformat `3:1` und `23:9` ab, zum Beispiel `(2K) 2048x2048 (1:1)` und `(4K) 5120x2880 (16:9)` |
| `width`, `height` | 256 bis 8192, Schrittweite 32 | Wird nur verwendet, wenn `size` auf `custom` steht. Die beiden Abmessungen müssen innerhalb von 16777216 Pixeln (4096x4096) und innerhalb eines Seitenverhältnisses von 6:1 bleiben |
| `quality` | `very_low`, `low`, `medium` (Standard), `high` | Höhere Stufen kosten mehr und dauern länger. `very_low` ist auf 4194304 Pixel (2048x2048) begrenzt |
| `background` | `auto` (Standard), `opaque`, `transparent` | `transparent` liefert das Bild mit einem Alphakanal, `opaque` erzwingt einen einfarbigen Hintergrund, `auto` folgt dem Prompt |
| `magic_prompt` | `auto` (Standard), `on`, `off` | Schreibt den Prompt vor der Generierung in eine detaillierte strukturierte Beschriftung um. `off` hält Ihre Formulierung so wörtlich wie möglich |
| `seed` | Ganzzahl | Text zu Bild ist allein anhand des Seeds nicht reproduzierbar, da der Prompt bei jedem Lauf neu geschrieben wird |

Der Node gibt außerdem `final_prompt` aus, die strukturierte Beschriftung, aus der das Bild generiert wurde. Um ein Bild zu reproduzieren, geben Sie diese Beschriftung erneut ein, mit `magic_prompt` auf `off` und demselben Seed.

## Bildbearbeitung

Bearbeiten oder kombinieren Sie bis zu fünf Bilder mit einer Anweisung. `image_1` ist das Bild, das bearbeitet wird; die Bilder 2 bis 5 liefern Design-, Material- oder Farbreferenzen. Sprechen Sie sie im Prompt als `@Image1`, `@Image2` und so weiter an.

Die Vorlage erstellt ihre Anweisung mit einem Node **Build JSON Prompt**, sodass Sie einen Bereich des Bildes markieren und beschriften können. Aktivieren Sie [Nodes 2.0](/de/interface/nodes-2), wenn der Editor nicht erscheint.

Der Node **Ideogram Edit** mit `ideogram-4.6` ergänzt:

| Eingabe | Werte | Wirkung |
| --- | --- | --- |
| `size` | `auto` (Standard), `source`, eine Voreinstellung oder `custom` | `auto` wählt anhand der Bilder und des Prompts einen Canvas von etwa 2K. `source` behält die Größe von `image_1` bei. Eine Voreinstellung mit einem anderen Seitenverhältnis setzt die Szene neu zusammen. `custom` verwendet die `width` und `height` unten |
| `width`, `height` | 256 bis 8192, Schrittweite 32 | Wird nur verwendet, wenn `size` auf `custom` steht. Die beiden Abmessungen müssen zusammen innerhalb von 16777216 Pixeln (4096x4096) und innerhalb eines Seitenverhältnisses von 6:1 bleiben |
| `quality` | `very_low`, `low`, `medium` (Standard), `high` | Höhere Stufen kosten mehr und dauern länger |
| `background` | `auto` (Standard), `opaque`, `transparent` | `transparent` gibt das Bild mit einem Alpha-Kanal zurück |
| `seed` | Ganzzahl | Dieselben Bilder, derselbe Prompt, dieselben Einstellungen und derselbe Seed ergeben dasselbe Ergebnis |

Eingaben über 16,7 MP oder 8192 Pixel pro Seite werden vor dem Hochladen herunterskaliert, und jedes Bild muss zwischen 1:6 und 6:1 liegen.

Edit rendert das gesamte Bild neu, daher können sich der Bildausschnitt und die unbearbeiteten Bereiche zusammen mit Edit verschieben. Verwenden Sie Precise Edit, wenn der Rest des Bildes exakt unverändert bleiben muss.

## Precise Edit

Ändern Sie nur, was der Prompt vorgibt. Unberührte Pixel bleiben identisch, und die Ausgabe behält die Größe von `image_1` bei, sofern die Quelle nicht über 16,7 MP oder 8192 Pixel pro Seite liegt und kein Bereich festgelegt ist. Akzeptiert bis zu vier Referenzbilder zusätzlich zum zu bearbeitenden Bild, oder drei mit einer Maskierung.

Precise Edit teilt die Referenz-Slots, die `@Image1`-Adressierung sowie die Steuerelemente `quality` und `seed` mit Edit. Sie hat keine Größensteuerung: Mit einem Bereich behält die Ausgabe die Größe von `image_1`, ohne einen Bereich wird eine Quelle über 16,7 MP oder 8192 Pixel pro Seite zuerst herunterskaliert.

### Einen einzelnen Bereich bearbeiten

Legen Sie `context_window` fest, um einen Bereich in nativer Auflösung zu bearbeiten:

| `context_window` | Zusätzliche Eingabe | Bearbeiteter Bereich |
| --- | --- | --- |
| `none` | keine | Das gesamte Bild, über 16,7 MP herunterskaliert |
| `auto` (Standard) | `mask` | Der von der Maskierung markierte Bereich, oder das gesamte Bild, wenn keine Maskierung verbunden ist |
| `custom` | `context_window_bboxes` | Ein umschließendes Rechteck um alle verbundenen Boxen (der Raum zwischen getrennten Boxen ist enthalten und kann bearbeitet werden), zum Beispiel aus dem Node **Create Bounding Boxes** |

Ein Bereich kann bis zu 8192 Pixel pro Seite und etwa 16,7 MP groß sein, bei höchstens 6:1. Mit einem Bereich kann `image_1` selbst bis zu 8192x8192 Pixel bei jedem Seitenverhältnis groß sein, und Pixel außerhalb des Bereichs werden unverändert übernommen.

Verwenden Sie dies für Produktumfärbungen, Materialaustausch und Retuschen, bei denen Beleuchtung, Hintergrund und Bildausschnitt des restlichen Fotos unverändert bleiben müssen.

## Loslegen

1. Aktualisieren Sie ComfyUI auf die neueste Version.
2. Öffnen Sie **Workflow** > **Vorlagen durchsuchen** und suchen Sie nach „Ideogram 4.6“, oder laden Sie einen der oben aufgeführten Workflows herunter und ziehen Sie ihn auf den Canvas.
3. Setzen Sie im Node `model` auf `ideogram-4.6`, wenn Sie mit einem Ideogram 4.5-Workflow begonnen haben.
