Ideogram 4.0 ist ein Text zu Bild-Modell von Ideogram, das fotorealistische Qualität, präzise Textwiedergabe und fein abgestimmte Stilsteuerung bietet. Sie können entweder einfache natürliche Sprache oder **strukturierte JSON-Prompts** verwenden, um Layout, Farben und Text im Bild gezielt zu steuern. Ideogram 4.5 ist das neuere Modell der Familie und hat eine eigene Seite: [Ideogram 4.5 in ComfyUI](/de/tutorials/partner-nodes/ideogram/ideogram-4-5).

## Was Ideogram 4.0 gut kann

- **Fotorealistische Qualität**: Überlegener Fotorealismus bei generierten Bildern
- **Präzise Textwiedergabe**: Gibt wörtlichen Text im Bild wieder, gut geeignet für posterartige Kompositionen
- **Präzise Stilsteuerung**: Strukturierte JSON-Prompts steuern die Stilpalette, die Platzierung von Elementen (`bbox`) und die Farbpaletten pro Element
- **Flexibles Prompting**: Akzeptiert einfache natürliche Sprache für schnelle Ideen oder strukturiertes JSON für die Feinsteuerung
- **Keine negativen Prompts erforderlich**: Verwendet asymmetrische classifier-free Guidance statt eines separaten negativen Prompt-Strings

### Prompt-Format

Der Node Ideogram V4 unterstützt zwei Prompt-Formate:

1. **Natürliche Sprache**: Einfach und intuitiv, ideal für schnelle Ideen.
2. **Strukturiertes JSON**: Bietet feingranulare Kontrolle über Stilpalette, Elementplatzierung (`bbox`) und die wörtliche Textdarstellung im Bild. Empfohlen für posterartige Kompositionen.

Das Standard-Workflow-Beispiel verwendet einen strukturierten JSON-Prompt, der Folgendes enthält:
- `high_level_description`: Gesamtbeschreibung der Szene
- `style_description`: Ästhetik, Beleuchtung, Medium, Farbpalette
- `compositional_deconstruction`: Begrenzungsrahmen, Beschreibungen und Farbpaletten pro Element

### Workflow-Schritte

1. Laden Sie die Workflow-Datei herunter und ziehen Sie sie in ComfyUI
2. Der Node `Ideogram V4` enthält bereits einen standardmäßigen strukturierten JSON-Prompt: Sie können ihn bearbeiten oder einfach natürliche Sprache schreiben
3. Klicken Sie auf `Run` oder verwenden Sie die Tastenkombination `Ctrl(cmd) + Enter`, um das Bild zu generieren
4. Nachdem die API Ergebnisse zurückgegeben hat, sehen Sie das generierte Bild im Node `Save Image`. Die Bilder werden im Verzeichnis `ComfyUI/output/` gespeichert

### Den JSON Prompt Builder verwenden (optional)

Der Workflow enthält einen integrierten **Gemini**-Node (Gemini 3.1 Pro), mit dem Sie strukturierte JSON-Prompts erstellen können:

1. Beschreiben Sie Ihre Idee im Benutzer-Prompt-Feld des Gemini-Nodes
2. Das Modell generiert einen JSON-Prompt, der dem Schema entspricht
3. Verbinden Sie die Ausgabe `STRING` mit der Eingabe `prompt` des Nodes `Ideogram V4`
4. Führen Sie den Workflow aus

## Zusätzliche Hinweise

- **Negative Prompts sind nicht erforderlich**: Das Modell Ideogram 4.0 nutzt eine asymmetrische Classifier-Free-Guidance, bei der der unbedingte Durchlauf Text-Tokens verwirft, statt einen separaten String für den Negative Prompt zu benötigen.
- **Modellgestützter Prompt-Aufbau**: Ziehen Sie den **Ideogram 4 Prompt Builder** (KJNodes) in Betracht, um den Prompt-Aufbau in ComfyUI visuell zu steuern.
