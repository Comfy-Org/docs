Krea 3 ist das gehostete Bildmodell von [Krea](https://www.krea.ai). Es ist für anweisungsgesteuerte Bearbeitung ausgelegt: Sie beschreiben, was sich ändern soll und was gleich bleiben soll, und das Modell liefert das bearbeitete Bild zurück. Wenn Sie kein Bild verbinden, generiert es stattdessen aus Text.

Krea 3 läuft in ComfyUI als Partner Node. Es gibt daher keine Gewichte zum Herunterladen, und nichts läuft auf Ihrer eigenen GPU. Der Node sendet Ihren Prompt und Ihre Referenzbilder an die Server von Krea und gibt das fertige Bild an Ihren Workflow zurück.

## Was Krea 3 gut kann

- **Anweisungsbasierte Bearbeitungen**: Schreiben Sie die Änderung in normaler Sprache („ersetzen Sie das grüne Auto durch ein orangefarbenes“) und Krea 3 gibt das gesamte Bild zurück, wobei alles erhalten bleibt, was Sie nicht ändern wollten
- **Text zu Bild aus demselben Node**: Lassen Sie die Bildeingänge leer, und der Node generiert allein aus dem Prompt
- **Bis zu 8 Referenzbilder**: Verbinden Sie sie in der Reihenfolge, in der Sie sie ansprechen möchten, und nennen Sie sie dann im Prompt als `@Image1`, `@Image2` und so weiter
- **Drei Denkmodi**: `fast` ist die Standardeinstellung und die empfohlene Einstellung, `high` plant komplexe Bearbeitungen detaillierter und dauert länger, und `ultra` generiert mehrere Kandidaten und gibt den besten zurück
- **Präzise Bearbeitungen**: Aktivieren Sie `precise_edit`, damit alles außerhalb des bearbeiteten Bereichs unverändert bleibt
- **Auflösungskontrolle**: 1K- oder 2K-Ausgabe, wobei das Seitenverhältnis `auto` dem ersten Referenzbild folgt

## Krea 3 Text-zu-Bild-Workflow {#api_krea3_t2i}

Generieren Sie ein Bild allein anhand eines Prompts. Der Node **Krea 3 Image** hat kein verbundenes Bild und verwendet daher den Prompt und die Einstellung für das Seitenverhältnis.

1. Schreiben Sie Ihren Prompt in den Node **Krea 3 Image**. Das mitgelieferte Beispiel ist ein einzelner detaillierter Satz, der das Motiv, die Beleuchtung und den Bildausschnitt beschreibt
2. Legen Sie `aspect_ratio` fest. Behalten Sie `auto` bei, um dem Prompt zu folgen, oder wählen Sie eines der zehn unterstützten Seitenverhältnisse
3. Wählen Sie `resolution`: Die Vorlage wird mit `1K` ausgeliefert, und `2K` liefert eine größere Canvas zu höheren Kosten
4. Belassen Sie `thinking_mode` auf `fast`, oder wechseln Sie zu `high`, wenn der Prompt eine komplexe Szene beschreibt
5. Klicken Sie auf **Warteschlange**. Das Bild wird vom Node `SaveImageAdvanced` unter `ComfyUI/output/` gespeichert.

1. Laden Sie das Bild, das Sie bearbeiten möchten, im `LoadImage`-Node und verbinden Sie es mit dem Node **Krea 3 Image**
2. Formulieren Sie die Bearbeitung als Instruktion. Das mitgelieferte Beispiel ersetzt das grüne Auto in der Szene durch ein oranges und listet auf, was unverändert bleiben muss: Komposition, Hintergrund, Gebäude, Staub, Beleuchtung und Perspektive
3. Aktivieren Sie `precise_edit`, wenn alles außerhalb des bearbeiteten Bereichs erhalten bleiben muss. Es benötigt mindestens ein Referenzbild
4. Passen Sie `aspect_ratio` und `resolution` für die Ausgabe-Canvas an
5. Klicken Sie auf **Warteschlange** und vergleichen Sie die Eingabe mit dem Ergebnis

**Weitere Referenzbilder**

Der Node akzeptiert bis zu 8 Bilder. Fügen Sie sie in der Reihenfolge hinzu, in der Sie auf sie verweisen möchten, und nennen Sie dann jedes im Prompt als `@Image1`, `@Image2` und so weiter.

Für eine tiefgreifende Bearbeitung setzen Sie `thinking_mode` auf `ultra`. Dieser Modus erzeugt mehrere Kandidaten und gibt den besten zurück, liefert immer 2K, benötigt mindestens ein Referenzbild und lässt sich nicht mit `precise_edit` kombinieren.

## Krea 3 Node-Parameter

Der Node **Krea 3 Image** (`Krea3ImageNode`) bietet die folgenden Einstellungen:

- `image_1` ... `image_8`: bis zu 8 Referenzbilder, nummeriert in der Reihenfolge ihrer Verbindung. Lassen Sie sie für Text zu Bild leer
- `prompt`: die Anweisung oder die Beschreibung der Szene. Verweisen Sie auf Referenzen als `@Image1`, `@Image2` und so weiter
- `aspect_ratio`: `auto` oder eines von `1:1`, `4:5`, `3:4`, `2:3`, `9:16`, `5:4`, `4:3`, `3:2`, `16:9`, `21:9`. `auto` folgt dem ersten Referenzbild oder, wenn kein Bild verbunden ist, dem Prompt
- `resolution`: Ausgabe in `1K` oder `2K`
- `thinking_mode`: `fast` ist empfohlen, `high` plant komplexe Bearbeitungen detaillierter und dauert länger, `ultra` generiert mehrere Kandidaten und gibt den besten zurück. `ultra` benötigt mindestens ein Referenzbild, gibt immer 2K aus und kann nicht mit `precise_edit` kombiniert werden
- `precise_edit`: lässt alles außerhalb des bearbeiteten Bereichs unverändert. Es benötigt mindestens ein Referenzbild
- `seed`: Seed für die Anfrage. Krea schreibt den Prompt vor der Generierung neu, daher erzeugt derselbe Seed nicht dasselbe Bild

## Hinweise und Einschränkungen

- **Prompt-Umschreibung**: Krea schreibt Ihren Prompt vor der Generierung um. Deshalb führt ein wiederholter Seed nicht zu einem wiederholten Bild.
- **Referenzgröße**: Jede Referenz wird vor dem Upload auf das Pixelbudget der Ausgabe skaliert. Daher behält die 2K-Einstellung mehr Referenzdetail als 1K.
- **Abrechnung**: Krea 3 ist ein Partner-Node, daher wird jeder Lauf mit Ihrem Comfy-Konto abgerechnet. Die Tarife finden Sie unter [Preise für Partner-Nodes](/tutorials/partner-nodes/pricing) und unter [Concurrency-Limits](/de/tutorials/partner-nodes/concurrency-limits) erfahren Sie, wie viele Anfragen Sie gleichzeitig laufen lassen können.
- **Version**: Der Node Krea 3 Bild wird mit ComfyUI [PR #17067](https://github.com/comfyanonymous/ComfyUI/pull/17067) ausgeliefert, und die beiden Vorlagen sind ab `workflow_templates` 0.11.84 Teil der Vorlagenbibliothek.
