**Ming Image 0.1 Design** ist ein Text-zu-Bild-Modell mit 6B Parametern und offenen Gewichten von inclusionAI (Ant Group), veröffentlicht unter der MIT-Lizenz. Es zielt auf Designarbeit statt auf fotografischen Realismus: UI-Screens, Infografiken, Poster und andere Layouts, die viel Text tragen. Die Ausgaben sind RGBA mit einem echten Alpha-Kanal, sodass ein transparentes Ergebnis direkt in eine Designdatei übernommen werden kann.

Der Workflow setzt eine Stufe zur Prompt-Umschreibung vor den Sampler. Qwen3.8-27B erweitert eine kurze Idee vor dem Sampling zu einer strukturierten Layout-Beschreibung, und der Enhancer lässt sich abschalten, wenn Sie Ihren Text genau wie eingegeben senden möchten.

## Was Ming Image 0.1 Design gut kann

- **Lange, strukturierte Layouts**: Seiten, Poster und Infografiken mit vielen Abschnitten, die Abschnitt für Abschnitt zusammengesetzt werden
- **Textwiedergabe**: im Prompt in Anführungszeichen gesetzte Zeichenketten werden genau befolgt, sodass Beschriftungen, Preise und Überschriften lesbar bleiben
- **Transparente Ausgabe**: RGBA-Bilder mit einem echten Alpha-Kanal für das Compositing isolierter Elemente
- **Prompt-Umschreibung**: ein instruktionsfolgendes Vision-Sprachmodell erweitert ein kurzes Briefing zu einer detaillierten Layout-Beschreibung
- **Offene Gewichte**: MIT-lizenziert, sodass die Checkpoints frei verwendet und feinabgestimmt werden können

### Schritte zum Ausführen des Workflows

1. Wechseln Sie über die Schaltfläche **Enter subgraph** am unteren Rand des Nodes in das Subgraph **Text to Image (Ming Image 0.1 Design)**
2. Schreiben Sie Ihren Prompt in das Feld `prompt`, beschreiben Sie das Layout Abschnitt für Abschnitt und setzen Sie jeden Text, der gerendert werden soll, in Anführungszeichen
3. Wählen Sie das Canvas mit dem Node `ResolutionSelector`: 2048 x 2048 liefert die beste Qualität, 1024 x 1024 ist schneller
4. Lassen Sie den Prompt-Enhancer aktiviert, damit Qwen3.8-27B Ihren Prompt erweitert, oder schalten Sie `enable_PE` aus, um Ihren Text genau wie eingegeben zu senden
5. Stellen Sie den Prompt in die Warteschlange. Das dekodierte Bild erscheint im Node `PreviewImage`
6. Für einen transparenten Hintergrund stellen Sie Ihrem Prompt eine RGBA-Phrase voran, zum Beispiel `RGBA, 4-channel, transparent background`

1. Aktualisieren Sie ComfyUI auf die neueste Version. Der Support für Ming Image 0.1 ist in den neuesten ComfyUI-Builds enthalten.

Comfy Desktop und Comfy Cloud folgen den stabilen Releases. Ein Modell, das nur in den neuesten ComfyUI-Builds unterstützt wird, ist dort daher möglicherweise noch nicht verfügbar.
