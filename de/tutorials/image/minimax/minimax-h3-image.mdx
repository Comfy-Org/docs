**MiniMax-H3-Image** ist das Open-Weights-Bildmodell von MiniMax, und ein Checkpoint deckt sowohl Text zu Bild als auch Bildbearbeitung ab. Der Diffusion-Transformer hat 33,1B Parameter in BF16 und ist auf einen 6-Schritt-Sampler ohne CFG destilliert. Die Ausgabe erfolgt nativ mit etwa 16 MP, sodass ein 4096 x 4096 großes Bild in einem einzigen Durchlauf entsteht und keine Upscale-Kette benötigt.

## Hauptfunktionen

- **Text zu Bild und Bearbeitung in einem Checkpoint**: kein separates Bearbeitungsmodell oder Adapter zum Laden nötig
- **6-Schritt-Sampling**: Die Guidance ist fest auf 1 gesetzt, daher gibt es keinen CFG-Durchlauf und keinen Negativ-Prompt
- **Nativ etwa 16 MP**: 4096 x 4096 bis 6272 x 2688 ohne Upscale-Durchlauf
- **Mehrere Referenzen**: bis zu 16 Eingabebilder, im Prompt als `<Picture 1>` aufwärts adressiert
- **Optionaler Prompt-Expander**: verwandelt eine kurze Anfrage in die ausführliche Beschreibung, die das Modell am besten versteht
- **Offene Gewichte**: volle lokale Kontrolle in ComfyUI

## Sampling und Canvas-Größe

Beide Vorlagen verwenden den destillierten Zeitplan:

| Einstellung | Wert |
| --- | --- |
| Sampler | euler |
| Scheduler | simple |
| Schritte | 6 |
| Guidance (CFG) | 1 |
| Denoise | 1 |

Bei einer Guidance von 1 gibt es keinen classifier-free-guidance-Durchlauf, daher enthalten die Vorlagen keinen Negativ-Prompt. Schreiben Sie alles, was Sie möchten, einschließlich der Dinge, die vermieden werden sollen, in den positiven Prompt.

Die native Ausgabe liegt bei etwa 16 MP. Jede Kante wird auf einem Vielfachen von 32 px generiert, und jede Breite und Höhe werden akzeptiert. Diese Größen decken die gängigen Seitenverhältnisse ab:

| Seitenverhältnis | Größe (Breite x Höhe) |
| --- | --- |
| 1:1 | 4096 x 4096 |
| 4:3 | 4736 x 3552 |
| 3:4 | 3552 x 4736 |
| 3:2 | 5024 x 3360 |
| 2:3 | 3360 x 5024 |
| 16:9 | 5472 x 3072 |
| 9:16 | 3072 x 5472 |
| 21:9 | 6272 x 2688 |

Kleinere Canvas funktionieren ebenfalls und kosten weniger Zeit. In der Text-zu-Bild-Vorlage legt die Auflösungsauswahl das Seitenverhältnis und die Ziel-Megapixel getrennt fest, sodass jedes Ziel von etwa 4 MP bis zur Obergrenze von 16 MP der Auswahl nur eine Einstellung entfernt ist.

## Referenzbilder in der Bildbearbeitung

Die Vorlage zur Bildbearbeitung sendet das Quellbild als `<Picture 1>` an das Modell. Weitere Bilder werden in der Reihenfolge `<Picture 2>`, `<Picture 3>` bis zu 16 Referenzen gekennzeichnet, und der Prompt bezieht sich über die jeweilige Kennzeichnung auf jedes davon. Das erste Bild ist dasjenige, das bearbeitet wird; die übrigen liefern Identität, Requisiten, Materialien oder Komposition. Eine kurze Anweisung genügt, zum Beispiel das Fahrzeug in `<Picture 1>` durch das in `<Picture 2>` zu ersetzen.

Um eine Referenz hinzuzufügen, platzieren Sie einen weiteren `Load Image`-Node im Workflow und verbinden Sie ihn sowohl mit dem Prompt-Erzeugungsschritt als auch mit dem Konditionierungs-Node. Referenzbilder müssen nicht vorbereitet werden: Die Vorlage rundet die Quelle auf ein Vielfaches von 32 px, und ComfyUI skaliert die internen Kopien selbst, eine kurze Kante von 1024 px für die Vision-Seite und eine kurze Kante, die für die VAE-Seite zwischen 1024 und 2048 px begrenzt wird, beide auf dem 32-px-Raster.

Wenn bei einer Bearbeitung der Speicher nicht ausreicht, aktivieren Sie den `Resize Image/Mask`-Node in der Vorlage und verringern Sie seine Megapixel vor dem Sampling.

## Prompt-Expander

Beide Vorlagen enthalten einen Textgenerierungsschritt vor dem Sampler. In der Vorlage für Text zu Bild schreibt er den Prompt in eine ausführliche englische Bildbeschreibung um. In der Vorlage zur Bildbearbeitung macht er aus einer kurzen Anweisung eine referenzbewusste Beschreibung des fertigen Bildes.

Der offizielle Expander für MiniMax-H3-Image ist ein Qwen3.8-27B-FP4-Modell, veröffentlicht als [MiniMaxAI/MiniMax-H3-Image-PE](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image-PE). Die Vorlagen verwenden stattdessen einen leichteren Qwen3.5-9B-W4A8-Build, sodass der Expander neben dem 21 GB großen Diffusionsmodell auf eine einzige GPU passt.

Bei beiden Vorlagen ist der Expander eingeschaltet, sodass Ihr Prompt vor dem Sampling umgeschrieben wird. Schalten Sie ihn aus, um Ihren Prompt genau so, wie Sie ihn eingegeben haben, an das Modell zu senden.
