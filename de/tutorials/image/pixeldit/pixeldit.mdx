**PixelDiT** ist NVIDIAs Diffusion-Transformer im Pixelraum für die Text-zu-Bild-Generierung mit 1024px. Anders als traditionelle Diffusionsmodelle, die im Latent-Raum arbeiten, erzeugt PixelDiT Bilder direkt im Pixelraum mit einer Dual-Level-DiT-Architektur: ein Patch-Level-DiT kombiniert mit einem Pixel-Level-DiT, dazu MM-DiT-Fusion für gemeinsame Attention zwischen Text- und Bild-Tokens.

**Modell-Highlights**:
- **VAE-frei**: erzeugt direkt im Pixelraum; kein traditionelles VAE-Kodieren/Dekodieren
- **Dual-Level-DiT**: Patch-Level-DiT + Pixel-Level-DiT für hochwertige Generierung
- **Mehrere Seitenverhältnisse**: Basisauflösung von 1024px mit Unterstützung für mehrere Seitenverhältnisse
- **~1.3 Mrd. Parameter**: effizient genug für Consumer-GPUs
- **Lizenz**: NSCLv1 (nur nicht-kommerzielle Forschung/Evaluierung)

**Verwandte Links**:
- [Offizielles Modell auf Hugging Face](https://huggingface.co/nvidia/PixelDiT-1300M-1024px)
- [Comfy-Org/PixelDiT](https://huggingface.co/Comfy-Org/PixelDiT)

Der Workflow besteht aus drei Haupt-Nodes:

1. **ResolutionSelector**: Wählen Sie die gewünschte Ausgabeauflösung.
2. **Text to Image (PixelDiT) Subgraph**: der zentrale Node für die Generierung mit sichtbaren Steuerelementen für Prompt, Seed, Modellauswahl und Auflösung.
3. **SaveImage**: speichert das generierte Bild.

<Card title="Mehr über Subgraphs erfahren" icon="book-open" href="/interface/features/subgraph">
  Dieser Workflow verwendet Subgraph-Nodes für die modulare Verarbeitung. Lesen Sie die Subgraph-Dokumentation, um zu erfahren, wie Sie den Workflow anpassen und erweitern.
</Card>

### Steuerelemente des Workflows

Die sichtbaren Steuerelemente des Subgraph-Nodes **Text to Image (PixelDiT)** umfassen:

| Steuerelement | Beschreibung |
|---------|-------------|
| **Positive Prompt** | Der Text-Prompt, der beschreibt, welches Bild Sie generieren möchten |
| **Negative Prompt** | Text, der beschreibt, was im generierten Bild vermieden werden soll |
| **Seed** | Zufälliger Seed für die Reproduzierbarkeit |
| **UNet Model** | Auswahl des PixelDiT-Modell-Checkpoints |
| **CLIP Model** | Auswahl des Text-Encoder-Modells |
