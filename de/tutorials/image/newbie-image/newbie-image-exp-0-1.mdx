**NewBie-image-Exp0.1** ist ein DiT-Modell mit 3,5B Parametern, das von NewBieAI Lab für die Text zu Bild-Generierung im Anime-Stil entwickelt wurde. Es basiert auf der Next-DiT-Architektur und erzeugt bemerkenswert detaillierte und visuell beeindruckende Anime-Bilder.

**Wichtigste Merkmale**:
- **Modell mit 3,5B Parametern**: Effiziente und zugleich leistungsstarke Modellgröße für hochwertige Anime-Generierung
- **Next-DiT-Architektur**: Basiert auf Forschung zur Lumina-Architektur mit einer neu entwickelten NewBie-Architektur
- **Zwei Text-Encoder**: Verwendet Gemma3-4B-it als primären Encoder und Jina CLIP v2 für ein besseres Verständnis der Prompts
- **FLUX VAE**: Nutzt den FLUX.1-dev VAE mit 16 Kanälen für sattere Farben und feinere Texturdetails
- **XML-strukturierte Prompts**: Unterstützt das XML-Format für eine bessere Attention-Bindung und Entflechtung von Attributen

## Prompt-Format

NewBie-image ist ein Anime-Bildgenerierungsmodell, das für die Charaktergenerierung optimiert ist. Es verwendet XML-strukturierte Prompts für das Training, wobei jedes `<>`-Tag eine Kategorie definiert (z. B. `<appearance>`, `<clothing>`) und `</>` sie schließt. Die Tags darin sind Standard-Tags von Danbooru. Diese Struktur ermöglicht eine präzise Kontrolle über Szenen mit mehreren Charakteren und eine bessere Bindung der Attribute.

Die vollständige Anleitung zum Schreiben von Prompts finden Sie in der [offiziellen Dokumentation](https://ai.feishu.cn/wiki/NZl9wm7V1iuNzmkRKCUcb1USnsh).

NewBie-image-Exp0.1 unterstützt drei Prompt-Formate:
- **Natürliche Sprache**: Standard-Textbeschreibungen
- **Tags**: Tags im Danbooru-Stil
- **XML-strukturiertes Format**: Empfohlen für Szenen mit mehreren Charakteren

### XML-strukturierter Prompt

Bei Szenen mit mehreren Charakteren führen XML-strukturierte Prompts in der Regel zu genaueren Ergebnissen bei der Bilderzeugung, mit besserer Attention-Bindung und besserer Trennung der Attribute.

```xml
<character_1>
<n>$character_1$</n>
<gender>1girl</gender>
<appearance>chibi, red_eyes, blue_hair, long_hair, hair_between_eyes, head_tilt, tareme, closed_mouth</appearance>
<clothing>school_uniform, serafuku, white_sailor_collar, white_shirt, short_sleeves, red_neckerchief, bow, blue_skirt, miniskirt, pleated_skirt, blue_hat, mini_hat, thighhighs, grey_thighhighs, black_shoes, mary_janes</clothing>
<expression>happy, smile</expression>
<action>standing, holding, holding_briefcase</action>
<position>center_left</position>
</character_1>

<character_2>
<n>$character_2$</n>
<gender>1girl</gender>
<appearance>chibi, red_eyes, pink_hair, long_hair, very_long_hair, multi-tied_hair, open_mouth</appearance>
<clothing>school_uniform, serafuku, white_sailor_collar, white_shirt, short_sleeves, red_neckerchief, bow, red_skirt, miniskirt, pleated_skirt, hair_bow, multiple_hair_bows, white_bow, ribbon_trim, ribbon-trimmed_bow, white_thighhighs, black_shoes, mary_janes, bow_legwear, bare_arms</clothing>
<expression>happy, smile</expression>
<action>standing, holding, holding_briefcase, waving</action>
<position>center_right</position>
</character_2>

<general_tags>
<count>2girls, multiple_girls</count>
<style>anime_style, digital_art</style>
<background>white_background, simple_background</background>
<atmosphere>cheerful</atmosphere>
<quality>high_resolution, detailed</quality>
<objects>briefcase</objects>
<other>alternate_costume</other>
</general_tags>
```

### Referenz der XML-Tags

| Tag | Beschreibung |
|-----|-------------|
| `<n>` | Name/Bezeichner des Charakters |
| `<gender>` | Geschlecht des Charakters (1girl, 1boy usw.) |
| `<appearance>` | Körperliche Merkmale (Haare, Augen, Körperbau) |
| `<clothing>` | Outfit und Accessoires |
| `<expression>` | Gesichtsausdruck |
| `<action>` | Pose und Aktionen |
| `<position>` | Position im Bild |
| `<count>` | Anzahl der Charaktere |
| `<style>` | Kunststil |
| `<background>` | Beschreibung des Hintergrunds |
| `<atmosphere>` | Gesamtstimmung |
| `<quality>` | Qualitäts-Tags |
| `<objects>` | Objekte in der Szene |
| `<other>` | Zusätzliche Tags |
