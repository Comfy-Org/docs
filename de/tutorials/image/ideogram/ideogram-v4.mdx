Ideogram 4.0 ist das neueste Text-zu-Bild-Modell von Ideogram und wurde als Open-Source-Modell veröffentlicht, das vollständig auf Ihrer eigenen Hardware läuft. Es liefert überragende fotorealistische Qualität, präzise Textwiedergabe und eine exakte Stilsteuerung. Sie können entweder einfache natürliche Sprache oder **strukturierte JSON-Prompts** verwenden, um Layout, Farben und Text im Bild fein abzustimmen.

### Prompt-Format

Der Open-Source-Workflow unterstützt zwei Prompt-Modi:

1. **Natürliche Sprache**: Schnell und einfach, ideal für einfache Ideen
2. **Strukturiertes JSON**: Für präzise Kontrolle über Layout, Farben und Stil

Der Workflow enthält eine Vorlage zum Aufbau von Prompts, die Sie mit jedem LLM verwenden können, um passende JSON-Prompts zu generieren.

Ein Hinweis im Workflow erläutert:
> Das Modell ist auf strukturierten JSON-Captions trainiert (Szenenzusammenfassung, Stil-Block, Hintergrund und optionale Beschreibungen pro Objekt mit Begrenzungsrahmen und Hex-Farbpaletten). Die offizielle Inferenz validiert Prompts gegen dieses Schema.

### Workflow-Schritte

1. Laden Sie die Modelle herunter und legen Sie sie in den richtigen Verzeichnissen ab (siehe Tabelle oben)
2. Laden Sie die Workflow-Datei herunter und ziehen Sie sie in ComfyUI
3. Geben Sie Ihren Prompt (natürliche Sprache oder strukturiertes JSON) im Subgraph-Node Ideogram4 ein
4. (Optional) Passen Sie die Auflösung mit dem Node `ResolutionSelector` an
5. Klicken Sie auf `Run` oder verwenden Sie die Tastenkombination `Ctrl(cmd) + Enter`, um das Bild zu generieren
6. Sehen Sie sich das Ergebnis im Node `Save Image` an. Die Ausgabedateien werden in `ComfyUI/output/` gespeichert

### Hinweis zum Sicherheitsfilter

Wenn Sie „Image blocked by safety filter“ sehen, handelt es sich um den integrierten Sicherheitsfilter von Ideogram 4.0. Nicht-JSON-Prompts (reiner Text) haben eine höhere Falsch-Positiv-Rate. Mit strukturierten JSON-Prompts verringern Sie die Wahrscheinlichkeit, dass Ihr Prompt blockiert wird.

Weitere Details finden Sie im [offiziellen Prompting-Leitfaden von Ideogram 4](https://github.com/ideogram-oss/ideogram4/blob/main/docs/prompting.md#safety-filter).
