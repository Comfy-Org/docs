HiDream-O1-Image ist ein einheitliches generatives Bild-Grundlagenmodell, das HiDream-ai am 8. Mai 2026 als Open Source veröffentlicht hat. Es basiert auf einem Pixel-level Unified Transformer (UiT) und kommt ohne externe VAEs oder getrennte Text-Encoder aus. Es unterstützt **Text zu Bild**, **anweisungsbasierte Bildbearbeitung**, **subjektgesteuerte Personalisierung** und **Storyboard-Generierung** mit einer Auflösung von bis zu 2.048 × 2.048.

HiDream-O1-Image wird unter der [MIT License](https://github.com/HiDream-ai/HiDream-O1-Image?tab=MIT-1-ov-file) veröffentlicht und in ComfyUI nativ unterstützt (PR [#13817](https://github.com/Comfy-Org/ComfyUI/pull/13817)).

### 3. Workflow verwenden

- Stellen Sie sicher, dass `CheckpointLoaderSimple` Ihren gewählten Checkpoint lädt
- Geben Sie Ihren Prompt im Node `CLIPTextEncode` ein
- **Text-zu-Bild-Modus:** setzen Sie den Schalter **„Switch to Image Edit“** auf **aus** (Standard). Der Sampler verwendet dann Ihren Text-Prompt direkt.
- **Bildbearbeitungsmodus:** setzen Sie **„Switch to Image Edit“** auf **an**, laden Sie anschließend ein Referenzbild im Node `Load Image` hoch und verbinden Sie es mit `HiDreamO1ReferenceImages`.

> **Hinweis:** Der O1-Sampler gibt Latent-Samples aus, die über einen Node `VAEDecode` mit dem von `CheckpointLoaderSimple` geladenen VAE dekodiert werden müssen.

## Zusätzliche Hinweise

- **Lange Texte rendern:** HiDream-O1-Image ist besonders gut darin, Text in Bildern darzustellen. Geben Sie Textinhalt, Schriftstil, Farbe und Positionierung im Prompt an, um beste Ergebnisse zu erzielen.

  ![Lange Texte rendern & Layout-Steuerung](https://raw.githubusercontent.com/HiDream-ai/HiDream-O1-Image/main/assets/text-layout.webp)

- **Bildskalierung:** Wenn Ihr Referenzbild zu groß ist, aktivieren Sie den Node `ImageScaleToTotalPixels` (Strg+B), um es auf 4MP zu skalieren.

- **Patch-Seam-Smoothing (Experimentell):** Der Node `HiDreamO1PatchSeamSmoothing` reduziert sichtbare Nahtartefakte während des Samplings. Im Workflow Full ist er standardmäßig aktiviert.
