## Node-Dokumentation mit Markdown

Custom Nodes können umfangreiche Markdown-Dokumentation enthalten, die in der UI anstelle der allgemeinen Node-Beschreibung angezeigt wird. Das bietet Benutzern detaillierte Informationen zur Funktionsweise Ihres Nodes, zu seinen Parametern und zu Anwendungsbeispielen.

Wenn Sie bereits Tooltips für jeden Parameter in der Node-Definition hinzugefügt haben, sind diese Basisinformationen direkt über das Node-Dokumentationspanel verfügbar.
Es muss keine zusätzliche Node-Dokumentation hinzugefügt werden, und Sie können sich die zugehörige Implementierung von [ContextWindowsManualNode](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy_extras/nodes_context_windows.py#L7) ansehen.

## Einrichtung

So fügen Sie Dokumentation für Ihre Custom Nodes oder mehrsprachige Dokumentation hinzu:

1. Erstellen Sie einen `docs`-Ordner in Ihrem `WEB_DIRECTORY`
2. Fügen Sie Markdown-Dateien hinzu, die nach Ihren Nodes benannt sind (die Namen Ihrer Nodes sind die Dictionary-Schlüssel im Dictionary `NODE_CLASS_MAPPINGS`, das zur Registrierung der Nodes verwendet wird):
   - `WEB_DIRECTORY/docs/NodeName.md` - Standarddokumentation
   - `WEB_DIRECTORY/docs/NodeName/en.md` - Englische Dokumentation
   - `WEB_DIRECTORY/docs/NodeName/zh.md` - Chinesische Dokumentation
   - Fügen Sie bei Bedarf weitere Gebietsschemata hinzu (z. B. `fr.md`, `de.md` usw.)

Das System lädt automatisch die passende Dokumentation auf Basis des Gebietsschemas des Benutzers und greift auf `NodeName.md` zurück, wenn keine lokalisierte Version verfügbar ist.

## Unterstützte Markdown-Funktionen

- Standard-Markdown-Syntax (Überschriften, Listen, Codeblöcke usw.)
- Bilder mit Markdown-Syntax: `![alt text](image.png)`
- HTML-Medienelemente mit bestimmten Attributen:
  - `<video>`- und `<source>`-Tags
  - Erlaubte Attribute: `controls`, `autoplay`, `loop`, `muted`, `preload`, `poster`

## Beispielstruktur

```
my-custom-node/
├── __init__.py
├── web/              # WEB_DIRECTORY
│   ├── js/
│   │   └── my-node.js
│   └── docs/
│       ├── MyNode.md           # Fallback documentation
│       └── MyNode/
│           ├── en.md           # English version
│           └── zh.md           # Chinese version
```

## Beispielhafte Markdown-Datei

```markdown
# My Custom Node

This node processes images using advanced algorithms.

## Parameters

- **image**: Input image to process
- **strength**: Processing strength (0.0 - 1.0)

## Usage

![example usage](example.png)

<video controls loop muted>
  <source src="demo.mp4" type="video/mp4">
</video>
```
