## Rechtsklick-Menüs

### Hintergrundmenü

Das Haupt-Hintergrundmenü (Rechtsklick auf den Canvas) wird durch einen Aufruf von
`LGraphCanvas.getCanvasMenuOptions` erzeugt. Der übliche Weg, es anzupassen, besteht darin, die Methode `getCanvasMenuItems` in Ihrer Erweiterung zu implementieren:

```javascript
app.registerExtension({
  name: "MyExtension",
  getCanvasMenuItems(canvas) {
    const items = []
    items.push(null) // fügt einen Trenner ein
    items.push({
      content: "The text for the menu",
      callback: async () => {
        // beliebige Aktion ausführen
      }
    })
    return items
  }
});
```

### Node-Menü

Wenn Sie mit der rechten Maustaste auf einen Node klicken, wird das Menü auf ähnliche Weise durch `node.getExtraMenuOptions` erzeugt.
Der übliche Weg ist, die Methode `getNodeMenuItems` in Ihrer Erweiterung zu implementieren:

```javascript
app.registerExtension({
  name: "MyExtension",
  getNodeMenuItems(node) {
    const items = []

    // Bei Bedarf können Sie nach Node-Typ filtern
    if (node.comfyClass === "MyNodeClass") {
      items.push({
        content: "Do something fun",
        callback: async () => {
          // unterhaltsame Aktion
        }
      })
    }

    return items
  }
});
```

### Untermenüs

Wenn Sie ein Untermenü benötigen, verwenden Sie die Eigenschaft `submenu` mit einem `options`-Array:

```javascript
app.registerExtension({
  name: "MyExtension",
  getCanvasMenuItems(canvas) {
    const items = []
    items.push({
      content: "Menu with options",
      submenu: {
        options: [
          {
            content: "option 1",
            callback: (v) => {
              // etwas mit v anstellen
            }
          },
          {
            content: "option 2",
            callback: (v) => {
              // etwas mit v anstellen
            }
          },
          {
            content: "option 3",
            callback: (v) => {
              // etwas mit v anstellen
            }
          }
        ]
      }
    })
    return items
  }
});
```

## UI-Events erfassen

Das funktioniert genau wie erwartet: Suchen Sie das UI-Element im DOM und
fügen Sie einen eventListener hinzu. `setup()` ist ein guter Ort dafür, da die Seite 
zu diesem Zeitpunkt vollständig geladen ist. Um beispielsweise einen Klick auf die Schaltfläche „Queue“ zu erkennen:

```Javascript
function queue_button_pressed() { console.log("Queue button was pressed!") }
document.getElementById("queue-button").addEventListener("click", queue_button_pressed);
```

## Erkennen, wann ein Workflow startet

Dies ist eines von vielen `api`-Events:

```javascript
import { api } from "../../scripts/api.js";
/* in setup() */
    function on_execution_start() { 
        /* beliebige Aktion ausführen */
    }
    api.addEventListener("execution_start", on_execution_start);
```

## Erkennen eines unterbrochenen Workflows

<Note>
**Veraltet:** Das unten gezeigte Muster zum Abfangen der API ist veraltet und kann sich in naher Zukunft jederzeit ändern. Verwenden Sie nach Möglichkeit die offiziellen [Erweiterungs-Hooks](/de/custom-nodes/js/javascript_hooks) und API-Event-Listener.
</Note>

Ein einfaches Beispiel für das Abfangen der API:

```Javascript
import { api } from "../../scripts/api.js";
/* in setup() */
    const original_api_interrupt = api.interrupt;
    api.interrupt = function () {
        /* Etwas tun, bevor die ursprüngliche Methode aufgerufen wird */
        original_api_interrupt.apply(this, arguments);
        /* Oder danach */
    }
```

## Klicks auf Ihren Node abfangen

<Note>
**Veraltet:** Das unten gezeigte Muster zum Abfangen von Node-Methoden ist veraltet und kann sich in naher Zukunft jederzeit ändern. Verwenden Sie nach Möglichkeit die offiziellen [Erweiterungs-Hooks](/de/custom-nodes/js/javascript_hooks).
</Note>

`node` verfügt über eine mouseDown-Methode, die Sie abfangen können. 
Diesmal achten wir darauf, jeden Rückgabewert weiterzugeben.

```javascript
async nodeCreated(node) {
    if (node?.comfyClass === "My Node Name") {
        const original_onMouseDown = node.onMouseDown;
        node.onMouseDown = function( e, pos, canvas ) {
            alert("ouch!");
            return original_onMouseDown?.apply(this, arguments);
        }        
    }
}
```
