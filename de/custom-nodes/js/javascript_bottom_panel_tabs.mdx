Die Bottom Panel Tabs API ermöglicht es Erweiterungen, benutzerdefinierte Tabs zum unteren Panel der ComfyUI-Oberfläche hinzuzufügen. Das ist nützlich für Funktionen wie Protokolle, Debugging-Werkzeuge oder benutzerdefinierte Panels.

## Grundlegende Nutzung

```javascript
app.registerExtension({
  name: "MyExtension",
  bottomPanelTabs: [
    {
      id: "customTab",
      title: "Custom Tab",
      type: "custom",
      render: (el) => {
        el.innerHTML = '<div>This is my custom tab content</div>';
      }
    }
  ]
});
```

## Tab-Konfiguration

Jeder Tab benötigt eine `id`, einen `title` und einen `type` sowie eine Render-Funktion:

```javascript
{
  id: string,              // Eindeutige Kennung für den Tab
  title: string,           // Angezeigter Titel des Tabs
  type: string,            // Tab-Typ (normalerweise "custom")
  icon?: string,           // Symbol-Klasse (optional)
  render: (element) => void // Funktion, die den Inhalt des Tabs füllt
}
```

Die Funktion `render` erhält ein DOM-Element, in das Sie den Inhalt Ihres Tabs einfügen.

## Interaktive Elemente

Sie können interaktive Elemente wie Schaltflächen hinzufügen:

```javascript
app.registerExtension({
  name: "InteractiveTabExample",
  bottomPanelTabs: [
    {
      id: "controlsTab",
      title: "Controls",
      type: "custom",
      render: (el) => {
        el.innerHTML = `
          <div style="padding: 10px;">
            <button id="runBtn">Run Workflow</button>
          </div>
        `;
        
        // Event-Listener hinzufügen
        el.querySelector('#runBtn').addEventListener('click', () => {
          app.queuePrompt();
        });
      }
    }
  ]
});
```

## React-Komponenten verwenden

Sie können React-Komponenten in Tabs des unteren Panels mounten:

```javascript
// React-Abhängigkeiten in Ihrer Erweiterung importieren
import React from "react";
import ReactDOM from "react-dom/client";

// Einfache React-Komponente
function TabContent() {
  const [count, setCount] = React.useState(0);
  
  return (
    <div style={{ padding: "10px" }}>
      <h3>React Component</h3>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
}

// Erweiterung mit React-Inhalt registrieren
app.registerExtension({
  name: "ReactTabExample",
  bottomPanelTabs: [
    {
      id: "reactTab",
      title: "React Tab",
      type: "custom",
      render: (el) => {
        const container = document.createElement("div");
        container.id = "react-tab-container";
        el.appendChild(container);
        
        // React-Komponente mounten
        ReactDOM.createRoot(container).render(
          <React.StrictMode>
            <TabContent />
          </React.StrictMode>
        );
      }
    }
  ]
});
```

## Standalone-Registrierung

Sie können Tabs auch außerhalb von `registerExtension` registrieren:

```javascript
app.extensionManager.registerBottomPanelTab({
  id: "standAloneTab",
  title: "Stand-Alone Tab",
  type: "custom",
  render: (el) => {
    el.innerHTML = '<div>This tab was registered independently</div>';
  }
});
```
