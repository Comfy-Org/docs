Das ComfyUI-Frontend installiert PrimeVue nicht mehr. Die Host-App ruft `app.use(PrimeVue)` nicht auf, daher verlieren Erweiterungen drei Dinge, auf die sie sich möglicherweise verlassen haben:

- die globale Eigenschaft `$primevue` der Host-Vue-App;
- das PrimeVue-Design-Stylesheet, sodass PrimeVue-Komponenten, die eine Erweiterung in der Host-App rendert, ohne Styling dargestellt werden; und
- jede globale CSS-Variable `--p-*`, wie z. B. `--p-primary-color`, `--p-surface-*`, `--p-text-color`, `--p-content-background` und `--p-form-field-border-color`.

## Erweiterungen, die PrimeVue-Komponenten rendern

Verlassen Sie sich nicht auf die PrimeVue-Instanz der Host-App. Ersetzen Sie die PrimeVue-Komponenten entweder durch eigenes Markup, oder erstellen Sie eine eigene Vue-App für Ihre UI und installieren Sie PrimeVue samt Design in dieser App.

## Erweiterungen, die `--p-*`-Variablen lesen

Ersetzen Sie sie durch die Designvariablen des Design-Systems. Diese folgen dem aktiven hellen oder dunklen Design und der aktiven Farbpalette:

| PrimeVue-Variable                                         | Designvariable       |
| --------------------------------------------------------- | -------------------- |
| `--p-primary-color`                                       | `--primary`          |
| `--p-text-color`                                          | `--foreground`       |
| `--p-text-muted-color`                                    | `--muted-foreground` |
| `--p-content-background`                                  | `--background`       |
| `--p-surface-*` (Panels, erhöhte Bereiche)                | `--secondary`        |
| `--p-content-border-color`, `--p-form-field-border-color` | `--border`           |

## Tooltips

Die globale Direktive `v-tooltip` gibt es nicht mehr, und Tooltips rendern nicht mehr das PrimeVue-DOM:

- `.p-tooltip` und `.p-tooltip-text`
- das Attribut `data-pd-tooltip`
- die Elementeigenschaften `$_pttooltip*`

Ein geöffneter Tooltip rendert jetzt ein Element mit `data-slot="tooltip-content"`, das an das Ende von `document.body` portalt wird. Es existiert nur, solange der Tooltip geöffnet ist. Erweiterungen, die Tooltips während ihrer eigenen UI ausblenden, sollten auf `[data-slot="tooltip-content"]` statt auf `.p-tooltip` zielen.

Die CSS-Variablen `--node-component-tooltip*` wurden ebenfalls aus dem Stylesheet des Designsystems entfernt. Verwenden Sie stattdessen die Design-Variablen: `--background`, `--foreground` und `--border`. Die älteren Namen `--base-background`, `--base-foreground` und `--border-default` sind veraltet; siehe [Veraltete Variablennamen](#veraltete-variablennamen).

## Veraltete Variablennamen

Frühere Versionen dieser Hinweise verwiesen auf ältere Namen des Designsystems. Sie werden weiterhin aufgelöst, sind aber veraltet und werden in einer zukünftigen Version entfernt. Wechseln Sie jetzt zur Designvariable:

| Veralteter Name               | Designvariable |
| ----------------------------- | -------------- |
| `--base-background`           | `--background` |
| `--base-foreground`           | `--foreground` |
| `--border-default`            | `--border`     |
| `--primary-background`        | `--primary`    |
| `--secondary-background`      | `--secondary`  |
| `--component-node-background` | `--node`       |

PrimeIcons werden weiterhin geladen, daher funktionieren bestehende `pi pi-*`-Symbolklassen weiter; sie werden jedoch schrittweise abgeschafft. Fügen Sie keine neuen Verwendungen hinzu.
