Die Topbar Menu API ermöglicht es Erweiterungen, benutzerdefinierte Menüeinträge zur oberen Menüleiste von ComfyUI hinzuzufügen. Das ist hilfreich, um Zugriff auf erweiterte Funktionen oder seltener verwendete Befehle zu bieten.

## Grundlegende Nutzung

```javascript
app.registerExtension({
  name: "MyExtension",
  // Befehle definieren
  commands: [
    { 
      id: "myCommand", 
      label: "My Command", 
      function: () => { alert("Command executed!"); } 
    }
  ],
  // Befehle zum Menü hinzufügen
  menuCommands: [
    { 
      path: ["Extensions", "My Extension"], 
      commands: ["myCommand"] 
    }
  ]
});
```

Befehlsdefinitionen folgen demselben Muster wie in der [API für Befehle und Tastenkürzel](./javascript_commands_keybindings). Weitere Informationen zum Definieren von Befehlen finden Sie auf dieser Seite.

## Command Configuration

Each command requires an `id`, `label`, and `function`:

```javascript
{
  id: string,              // Unique identifier for the command
  label: string,           // Display name for the command
  function: () => void     // Function to execute when command is triggered
}
```

## Menükonfiguration

Das `menuCommands`-Array definiert, wo Befehle in der Menüstruktur platziert werden:

```javascript
{
  path: string[],          // Array, das die Menühierarchie repräsentiert
  commands: string[]       // Array von Befehls-IDs, die an dieser Stelle hinzugefügt werden
}
```

Das `path`-Array gibt die Menühierarchie an. Beispielsweise würde `["File", "Export"]` Befehle zum Untermenü „Export“ unter dem Menü „File“ hinzufügen.

## Menübeispiele

### Zu bestehenden Menüs hinzufügen

```javascript
app.registerExtension({
  name: "MenuExamples",
  commands: [
    { 
      id: "saveAsImage", 
      label: "Save as Image", 
      function: () => { 
        // Code zum Speichern des Canvas als Bild
      } 
    },
    { 
      id: "exportWorkflow", 
      label: "Export Workflow", 
      function: () => { 
        // Code zum Exportieren des Workflows
      } 
    }
  ],
  menuCommands: [
    // Zum File-Menü hinzufügen
    { 
      path: ["File"], 
      commands: ["saveAsImage", "exportWorkflow"] 
    }
  ]
});
```

### Untermenüstruktur erstellen

```javascript
app.registerExtension({
  name: "SubmenuExample",
  commands: [
    { 
      id: "option1", 
      label: "Option 1", 
      function: () => { console.log("Option 1"); } 
    },
    { 
      id: "option2", 
      label: "Option 2", 
      function: () => { console.log("Option 2"); } 
    },
    { 
      id: "suboption1", 
      label: "Sub-option 1", 
      function: () => { console.log("Sub-option 1"); } 
    }
  ],
  menuCommands: [
    // Eine verschachtelte Menüstruktur erstellen
    { 
      path: ["Extensions", "My Tools"], 
      commands: ["option1", "option2"] 
    },
    { 
      path: ["Extensions", "My Tools", "Advanced"], 
      commands: ["suboption1"] 
    }
  ]
});
```

### Mehrere Menüpositionen

Sie können denselben Befehl an mehreren Menüpositionen hinzufügen:

```javascript
app.registerExtension({
  name: "MultiLocationExample",
  commands: [
    { 
      id: "helpCommand", 
      label: "Get Help", 
      function: () => { window.open("https://docs.example.com", "_blank"); } 
    }
  ],
  menuCommands: [
    // Zum Help-Menü hinzufügen
    { 
      path: ["Help"], 
      commands: ["helpCommand"] 
    },
    // Auch zum Extensions-Menü hinzufügen
    { 
      path: ["Extensions"], 
      commands: ["helpCommand"] 
    }
  ]
});
```

Befehle können mit anderen ComfyUI-APIs wie den Einstellungen zusammenarbeiten. Weitere Informationen zur Settings-API finden Sie in der Dokumentation zur [Settings API](./javascript_settings).
