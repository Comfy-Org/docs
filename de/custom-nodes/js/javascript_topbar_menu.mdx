Die Topbar Menu API ermöglicht es Erweiterungen, benutzerdefinierte Menüeinträge zur oberen Menüleiste von ComfyUI hinzuzufügen. Das ist hilfreich, um Zugriff auf erweiterte Funktionen oder seltener verwendete Befehle zu bieten.

## Grundlegende Nutzung

```javascript
app.registerExtension({
  name: "MyExtension",
  // Befehle definieren
  commands: [
    { 
      id: "myCommand", 
      label: "My Command", 
      function: () => { alert("Command executed!"); } 
    }
  ],
  // Befehle zum Menü hinzufügen
  menuCommands: [
    { 
      path: ["Extensions", "My Extension"], 
      commands: ["myCommand"] 
    }
  ]
});
```

Befehlsdefinitionen folgen demselben Muster wie in der [API für Befehle und Tastenkürzel](./javascript_commands_keybindings). Ausführlichere Informationen zum Definieren von Befehlen finden Sie auf dieser Seite.

## Befehle konfigurieren

Jeder Befehl erfordert eine `id`, ein `label` und eine `function`:

```javascript
{
  id: string,              // Eindeutige Kennung für den Befehl
  label: string,           // Anzeigename für den Befehl
  function: () => void     // Funktion, die ausgeführt wird, wenn der Befehl ausgelöst wird
}
```


## Menükonfiguration

Das Array `menuCommands` legt fest, wo Befehle in der Menüstruktur platziert werden:

```javascript
{
  path: string[],          // Array, das die Menühierarchie beschreibt
  commands: string[]       // Array der Befehl-IDs, die an dieser Stelle hinzugefügt werden
}
```

Das Array `path` legt die Menühierarchie fest. Zum Beispiel würde `["File", "Export"]` Befehle zum Untermenü „Export“ unter dem Menü „File“ hinzufügen.

## Menübeispiele

### Zu vorhandenen Menüs hinzufügen

```javascript
app.registerExtension({
  name: "MenuExamples",
  commands: [
    { 
      id: "saveAsImage", 
      label: "Save as Image", 
      function: () => { 
        // Code, um das Canvas als Bild zu speichern
      } 
    },
    { 
      id: "exportWorkflow", 
      label: "Export Workflow", 
      function: () => { 
        // Code, um den Workflow zu exportieren
      } 
    }
  ],
  menuCommands: [
    // Zum Menü „File“ hinzufügen
    { 
      path: ["File"], 
      commands: ["saveAsImage", "exportWorkflow"] 
    }
  ]
});
```

### Untermenüstruktur erstellen

```javascript
app.registerExtension({
  name: "SubmenuExample",
  commands: [
    { 
      id: "option1", 
      label: "Option 1", 
      function: () => { console.log("Option 1"); } 
    },
    { 
      id: "option2", 
      label: "Option 2", 
      function: () => { console.log("Option 2"); } 
    },
    { 
      id: "suboption1", 
      label: "Sub-option 1", 
      function: () => { console.log("Sub-option 1"); } 
    }
  ],
  menuCommands: [
    // Eine verschachtelte Menüstruktur erstellen
    { 
      path: ["Extensions", "My Tools"], 
      commands: ["option1", "option2"] 
    },
    { 
      path: ["Extensions", "My Tools", "Advanced"], 
      commands: ["suboption1"] 
    }
  ]
});
```

### Mehrere Menüpositionen

Sie können denselben Befehl an mehreren Positionen im Menü hinzufügen:

```javascript
app.registerExtension({
  name: "MultiLocationExample",
  commands: [
    { 
      id: "helpCommand", 
      label: "Get Help", 
      function: () => { window.open("https://docs.example.com", "_blank"); } 
    }
  ],
  menuCommands: [
    // Zum Menü „Help“ hinzufügen
    { 
      path: ["Help"], 
      commands: ["helpCommand"] 
    },
    // Auch zum Menü „Extensions“ hinzufügen
    { 
      path: ["Extensions"], 
      commands: ["helpCommand"] 
    }
  ]
});
```

Befehle können mit anderen ComfyUI-APIs wie den Einstellungen zusammenarbeiten. Weitere Informationen zur Settings API finden Sie in der Dokumentation zur [Settings API](./javascript_settings).
