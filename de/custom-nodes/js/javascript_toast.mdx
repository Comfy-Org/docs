Die Toast API bietet eine Möglichkeit, Benutzern nicht blockierende Benachrichtigungen anzuzeigen. Sie eignet sich, um Feedback zu geben, ohne den Workflow zu unterbrechen.

## Grundlegende Nutzung

### Einfacher Toast

```javascript
// Einen einfachen Info-Toast anzeigen
app.extensionManager.toast.add({
  severity: "info",
  summary: "Information",
  detail: "Operation completed successfully",
  life: 3000
});
```

### Toast-Typen

```javascript
// Erfolgs-Toast
app.extensionManager.toast.add({
  severity: "success",
  summary: "Success",
  detail: "Data saved successfully",
  life: 3000
});

// Warnungs-Toast
app.extensionManager.toast.add({
  severity: "warn",
  summary: "Warning",
  detail: "This action may cause problems",
  life: 5000
});

// Fehler-Toast
app.extensionManager.toast.add({
  severity: "error",
  summary: "Error",
  detail: "Failed to process request",
  life: 5000
});
```

### Alert-Helfer

```javascript
// Kurzform zum Erstellen eines Alert-Toasts
app.extensionManager.toast.addAlert("This is an important message");
```

## API-Referenz

### Toast-Nachricht

```javascript
app.extensionManager.toast.add({
  severity?: "success" | "info" | "warn" | "error" | "secondary" | "contrast", // Schweregrad der Nachricht (Standard: "info")
  summary?: string,         // Kurzer Titel für den Toast
  detail?: any,             // Detaillierter Inhalt der Nachricht
  closable?: boolean,       // Ob der Benutzer den Toast schließen kann (Standard: true)
  life?: number,            // Dauer in Millisekunden vor dem automatischen Schließen
  group?: string,           // Gruppenkennung für die Verwaltung zusammengehöriger Toasts
  styleClass?: any,         // Style-Klasse der Nachricht
  contentStyleClass?: any   // Style-Klasse des Inhalts
});
```

### Alert-Helfer

```javascript
app.extensionManager.toast.addAlert(message: string);
```

### Weitere Methoden

```javascript
// Einen bestimmten Toast entfernen
app.extensionManager.toast.remove(toastMessage);

// Alle Toasts entfernen
app.extensionManager.toast.removeAll();
```
