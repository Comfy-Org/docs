Die Sidebar Tabs API ermöglicht es Erweiterungen, benutzerdefinierte Tabs zur Seitenleiste der ComfyUI-Oberfläche hinzuzufügen. Das ist nützlich für Funktionen, die dauerhafte Sichtbarkeit und schnellen Zugriff erfordern.

## Basic Usage

```javascript
app.extensionManager.registerSidebarTab({
  id: "customSidebar",
  icon: "icon-[lucide--compass]",
  title: "Custom Tab",
  tooltip: "My Custom Sidebar Tab",
  type: "custom",
  render: (el) => {
    el.innerHTML = '<div>This is my custom sidebar content</div>';
  }
});
```

## Tab-Konfiguration

Jeder Tab erfordert mehrere Eigenschaften:

```javascript
{
  id: string,              // Eindeutige Kennung für den Tab
  icon: string,            // Symbolklasse für die Tab-Schaltfläche
  title: string,           // Titeltext für den Tab
  tooltip?: string,        // Tooltip-Text beim Hovern (optional)
  type: string,            // Tab-Typ (normalerweise "custom")
  render: (element) => void // Funktion, die den Inhalt des Tabs füllt
}
```

Die Funktion `render` erhält ein DOM-Element, in das Sie den Inhalt Ihres Tabs einfügen.

## Symboloptionen

Symbole für Seitenleisten-Tabs verwenden [Lucide](https://lucide.dev/icons/)-Symbolklassen in der Form
`icon-[lucide--<icon-name>]` (z. B. `icon-[lucide--compass]`).

Das Frontend erzeugt diese Klassen beim Build, daher sind nur die Lucide-Symbole verfügbar, die
das Frontend selbst verwendet. Wenn ein Symbol nicht dargestellt wird, wählen Sie ein anderes
Symbol oder definieren Sie eine eigene Symbolklasse in einem Stylesheet, das Ihre Erweiterung lädt.

PrimeIcons (`pi pi-*`) und Material Design Icons (`mdi mdi-*`) werden derzeit noch
dargestellt, aber sie werden auslaufen. Verwenden Sie sie nicht in neuem Code. Siehe
[Migration zur Entfernung von PrimeVue](/de/custom-nodes/js/primevue-removal-migration).

## Stateful Tab Example

Sie können Tabs erstellen, die ihren Zustand beibehalten:

```javascript
app.extensionManager.registerSidebarTab({
  id: "statefulTab",
  icon: "icon-[lucide--list]",
  title: "Notes",
  type: "custom",
  render: (el) => {
    // Create elements
    const container = document.createElement('div');
    container.style.padding = '10px';
    
    const notepad = document.createElement('textarea');
    notepad.style.width = '100%';
    notepad.style.height = '200px';
    notepad.style.marginBottom = '10px';
    
    // Load saved content if available
    const savedContent = localStorage.getItem('comfyui-notes');
    if (savedContent) {
      notepad.value = savedContent;
    }
    
    // Auto-save content
    notepad.addEventListener('input', () => {
      localStorage.setItem('comfyui-notes', notepad.value);
    });
    
    // Assemble the UI
    container.appendChild(notepad);
    el.appendChild(container);
  }
});
```

## React-Komponenten verwenden

Sie können React-Komponenten in Seitenleisten-Tabs einbinden:

```javascript
// React-Abhängigkeiten in Ihrer Erweiterung importieren
import React from "react";
import ReactDOM from "react-dom/client";

// Seitenleisten-Tab mit React-Inhalt registrieren
app.extensionManager.registerSidebarTab({
  id: "reactSidebar",
  icon: "icon-[lucide--blocks]",
  title: "React Tab",
  type: "custom",
  render: (el) => {
    const container = document.createElement("div");
    container.id = "react-sidebar-container";
    el.appendChild(container);
    
    // Eine einfache React-Komponente definieren
    function SidebarContent() {
      const [count, setCount] = React.useState(0);
      
      return (
        <div style={{ padding: "10px" }}>
          <h3>React Sidebar</h3>
          <p>Count: {count}</p>
          <button onClick={() => setCount(count + 1)}>
            Increment
          </button>
        </div>
      );
    }
    
    // React-Komponente einbinden
    ReactDOM.createRoot(container).render(
      <React.StrictMode>
        <SidebarContent />
      </React.StrictMode>
    );
  }
});
```

Ein reales Beispiel einer React-Anwendung, die als Seitenleisten-Tab integriert ist, finden Sie im [ComfyUI-Copilot-Projekt auf GitHub](https://github.com/AIDC-AI/ComfyUI-Copilot).

## Dynamic Content Updates

Sie können den Inhalt der Seitenleiste als Reaktion auf Diagrammänderungen aktualisieren:

```javascript
app.extensionManager.registerSidebarTab({
  id: "dynamicSidebar",
  icon: "icon-[lucide--activity]",
  title: "Stats",
  type: "custom",
  render: (el) => {
    const container = document.createElement('div');
    container.style.padding = '10px';
    el.appendChild(container);
    
    // Function to update stats
    function updateStats() {
      const stats = {
        nodes: app.graph._nodes.length,
        connections: Object.keys(app.graph.links).length
      };
      
      container.innerHTML = `
        <h3>Workflow Stats</h3>
        <ul>
          <li>Nodes: ${stats.nodes}</li>
          <li>Connections: ${stats.connections}</li>
        </ul>
      `;
    }
    
    // Initial update
    updateStats();
    
    // Listen for graph changes
    const api = app.api;
    api.addEventListener("graphChanged", updateStats);
    
    // Clean up listeners when tab is destroyed
    return () => {
      api.removeEventListener("graphChanged", updateStats);
    };
  }
});
```
