Die About Panel Badges API ermöglicht Erweiterungen, der About-Seite von ComfyUI benutzerdefinierte Badges hinzuzufügen. Diese Badges können Informationen zu Ihrer Erweiterung anzeigen und Links zu Dokumentation, Quellcode oder anderen Ressourcen enthalten.

## Grundlegende Nutzung

```javascript
app.registerExtension({
  name: "MyExtension",
  aboutPageBadges: [
    {
      label: "Documentation",
      url: "https://example.com/docs",
      icon: "icon-[lucide--file]"
    },
    {
      label: "GitHub",
      url: "https://github.com/username/repo",
      icon: "icon-[lucide--github]"
    }
  ]
});
```

## Badge-Konfiguration

Jeder Badge benötigt alle diese Eigenschaften:

```javascript
{
  label: string,           // Text, der auf dem Badge angezeigt wird
  url: string,             // URL, die beim Klick auf den Badge geöffnet wird
  icon: string             // Symbolklasse (z. B. "icon-[lucide--github]")
}
```

## Symboloptionen

Badge-Symbole verwenden [Lucide](https://lucide.dev/icons/)-Symbolklassen in der Form
`icon-[lucide--<icon-name>]`. Hier sind einige häufig verwendete Symbole:

- Dokumentation: `icon-[lucide--file]` oder `icon-[lucide--book-open]`
- GitHub: `icon-[lucide--github]`
- Externer Link: `icon-[lucide--external-link]`
- Information: `icon-[lucide--info]`
- Herunterladen: `icon-[lucide--download]`
- Website: `icon-[lucide--globe]`

Das Frontend generiert diese Klassen beim Build, daher sind nur die Lucide-Symbole
verfügbar, die das Frontend selbst verwendet. Wenn ein Symbol nicht dargestellt wird,
wählen Sie ein anderes Symbol oder definieren Sie Ihre eigene Symbolklasse in einem
Stylesheet, das Ihre Erweiterung lädt.

PrimeIcons-Klassen wie `pi pi-file` werden derzeit noch dargestellt, aber sie werden
schrittweise abgeschafft. Verwenden Sie sie nicht in neuem Code. Siehe [Migration zur
Entfernung von PrimeVue](/de/custom-nodes/js/primevue-removal-migration).

## Beispiel

```javascript
app.registerExtension({
  name: "BadgeExample",
  aboutPageBadges: [
    {
      label: "Website",
      url: "https://example.com",
      icon: "icon-[lucide--globe]"
    },
    {
      label: "Donate",
      url: "https://example.com/donate",
      icon: "icon-[lucide--heart]"
    },
    {
      label: "Documentation",
      url: "https://example.com/docs",
      icon: "icon-[lucide--book-open]"
    }
  ]
});
```

Badges erscheinen im About-Panel des Einstellungen-Dialogs, den Sie über das Zahnrad-Symbol oben rechts in der ComfyUI-Oberfläche erreichen.
