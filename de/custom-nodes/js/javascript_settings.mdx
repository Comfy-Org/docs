Sie können ComfyUI ein Einstellungenobjekt übergeben, das angezeigt wird, wenn der Benutzer das Einstellungen-Panel von ComfyUI öffnet.

## Grundlegende Bedienung

### Einstellung hinzufügen

```javascript
import { app } from "../../scripts/app.js";

app.registerExtension({
    name: "My Extension",
    settings: [
        {
            id: "example.boolean",
            name: "Example boolean setting",
            type: "boolean",
            defaultValue: false,
        },
    ],
});
```

Die `id` muss über alle Erweiterungen hinweg eindeutig sein und wird zum Abrufen von Werten verwendet.

Wenn Sie keine [Kategorie angeben](#categories), wird die `id` anhand von `.` aufgeteilt, um zu bestimmen, wo sie im Einstellungsbereich erscheint.

- Wenn Ihre `id` keinen `.` enthält, erscheint sie in der Kategorie „Other“ und Ihre `id` wird als Abschnittsüberschrift verwendet.
- Wenn Ihre `id` mindestens einen `.` enthält, wird der am weitesten links stehende Teil als Kategorie der Einstellung und der zweite Teil als Abschnittsüberschrift verwendet. Alle weiteren Teile werden ignoriert.

### Einstellung auslesen

```javascript
import { app } from "../../scripts/app.js";

if (app.extensionManager.setting.get('example.boolean')) {
    console.log("Setting is enabled.");
} else {
    console.log("Setting is disabled.");
}
```

### Auf Änderungen reagieren

Der Event-Handler `onChange()` wird aufgerufen, sobald der Benutzer die Einstellung im Einstellungsbereich ändert.

Er wird außerdem beim Registrieren der Erweiterung aufgerufen, und zwar bei jedem Laden der Seite.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Einstellung schreiben

```javascript
import { app } from "../../scripts/app.js";

try {
    await app.extensionManager.setting.set("example.boolean", true);
} catch (error) {
    console.error(`Error changing setting: ${error}`);
}
```

### Zusätzliche Konfiguration

Jeder Einstellungstyp rendert eine Formularkomponente des ComfyUI-Frontends. Sie können dieser Komponente zusätzliche Props in einem `attrs`-Feld übergeben. Die von den einzelnen Typen unterstützten Props sind unter [Typen](#types) aufgeführt.

Dies beschränkt beispielsweise eine Zahleneingabe auf einen Bereich und eine Schrittweite:

```javascript
{
    id: "example.number",
    name: "Example number setting",
    type: "number",
    defaultValue: 0,
    attrs: {
        min: 0,
        max: 100,
        step: 5,
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

Wenn Ihre Erweiterung PrimeVue-Props wie `showButtons`, `maxFractionDigits`, `editable` oder `filter` übergeben hat, lesen Sie die [Migration zur Entfernung von PrimeVue](/de/custom-nodes/js/primevue-removal-migration). Der Einstellungsbereich verwendet keine PrimeVue-Komponenten mehr, daher haben diese Props keine Auswirkung.

## Types

### Boolean

This shows an on/off toggle.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Text

This is freeform text.

```javascript
{
    id: "example.text",
    name: "Example text setting",
    type: "text",
    defaultValue: "Foo",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Number

Damit werden Zahlen eingegeben.

Die Eingabe zeigt immer Schaltflächen zum Erhöhen und Verringern. Unterstützte `attrs` sind
`min`, `max`, `step` und `formatOptions`. `formatOptions` erwartet
[`Intl.NumberFormatOptions`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat#options),
`maximumFractionDigits` steuert also, wie viele Nachkommastellen angezeigt werden.

```javascript
{
    id: "example.number",
    name: "Example number setting",
    type: "number",
    defaultValue: 42,
    attrs: {
        step: 0.1,
        formatOptions: { maximumFractionDigits: 1 },
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Slider

Damit kann eine Zahl direkt oder über einen Schieberegler eingegeben werden.

Unterstützte `attrs` sind `min`, `max` und `step`. Bereiche werden nicht unterstützt.

```javascript
{
    id: "example.slider",
    name: "Example slider setting",
    type: "slider",
    attrs: {
        min: -10,
        max: 10,
        step: 0.5,
    },
    defaultValue: 0,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Combo

Damit wird ein Wert aus einer Dropdown-Liste ausgewählt.

Optionen können als einfacher String oder als Objekt mit den Feldern `text`
und `value` angegeben werden. Bei einem einfachen String wird dieser Wert
für beide Felder verwendet.

Mit dem Attribut `searchable: true` kann die Liste durchsucht werden.
Gruppen und freie Texteingabe werden nicht unterstützt.

```javascript
{
    id: "example.combo",
    name: "Example combo setting",
    type: "combo",
    defaultValue: "first",
    options: [
        { text: "My first option", value: "first" },
        "My second option",
    ],
    attrs: {
        searchable: true,
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Color

Damit wird eine Farbe über einen Farbwähler oder eine Hex-Referenz ausgewählt.

Das Format erfordert sechs vollständige Hex-Ziffern (oder acht mit Alpha). Die
Kurzform mit drei Ziffern funktioniert nicht.

```javascript
{
    id: "example.color",
    name: "Example color setting",
    type: "color",
    defaultValue: "ff0000",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Image

Damit wird ein Bild hochgeladen.

Die Einstellung wird als [data
URL](https://developer.mozilla.org/en-US/docs/Web/URI/Schemes/data) gespeichert.

```javascript
{
    id: "example.image",
    name: "Example image setting",
    type: "image",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Hidden

Versteckte Einstellungen erscheinen nicht im Einstellungsfenster, können aber
im Code gelesen und geschrieben werden.

```javascript
{
    id: "example.hidden",
    name: "Example hidden setting",
    type: "hidden",
}
```

## Other

### Categories

Die Kategorisierung einer Einstellung lässt sich getrennt von der `id` angeben.
So können Sie Kategorisierung und Benennung ändern, ohne die `id` zu ändern und
die bereits gesetzten Werte zu verlieren.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    category: ["Category name", "Section heading", "Setting label"],
}
```

### Tooltips

Mit dem Feld `tooltip` lässt sich zusätzliche kontextuelle Hilfe ergänzen. Damit
erscheint hinter dem Feldnamen ein kleines ℹ︎-Symbol, das den Hilfetext beim
Überfahren anzeigt.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    tooltip: "This is some helpful information",
}
```
