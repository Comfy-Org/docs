Sie können ComfyUI ein Einstellungen-Objekt übergeben, das angezeigt wird, wenn der Benutzer das Einstellungen-Panel von ComfyUI öffnet.

## Grundlegende Verwendung

### Einstellung hinzufügen

```javascript
import { app } from "../../scripts/app.js";

app.registerExtension({
    name: "My Extension",
    settings: [
        {
            id: "example.boolean",
            name: "Example boolean setting",
            type: "boolean",
            defaultValue: false,
        },
    ],
});
```

Die `id` muss über alle Erweiterungen hinweg eindeutig sein und wird zum Abrufen von Werten verwendet.

Wenn Sie keine [Kategorie angeben](#categories), wird die `id` anhand von `.` aufgeteilt, um zu bestimmen, wo sie im Einstellungsbereich erscheint.

- Wenn Ihre `id` keinen `.` enthält, erscheint sie in der Kategorie „Other“ und Ihre `id` wird als Abschnittsüberschrift verwendet.
- Wenn Ihre `id` mindestens einen `.` enthält, wird der am weitesten links stehende Teil als Kategorie der Einstellung und der zweite Teil als Abschnittsüberschrift verwendet. Alle weiteren Teile werden ignoriert.

### Einstellung auslesen

```javascript
import { app } from "../../scripts/app.js";

if (app.extensionManager.setting.get('example.boolean')) {
    console.log("Setting is enabled.");
} else {
    console.log("Setting is disabled.");
}
```

### Auf Änderungen reagieren

Der Event-Handler `onChange()` wird aufgerufen, sobald der Benutzer die Einstellung im Einstellungsbereich ändert.

Er wird außerdem beim Registrieren der Erweiterung aufgerufen, und zwar bei jedem Laden der Seite.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Einstellung schreiben

```javascript
import { app } from "../../scripts/app.js";

try {
    await app.extensionManager.setting.set("example.boolean", true);
} catch (error) {
    console.error(`Error changing setting: ${error}`);
}
```

### Zusätzliche Konfiguration

Jeder Einstellungstyp rendert eine Formularkomponente des ComfyUI-Frontends. Sie können dieser Komponente zusätzliche Props in einem `attrs`-Feld übergeben. Die von den einzelnen Typen unterstützten Props sind unter [Typen](#types) aufgeführt.

Dies beschränkt beispielsweise eine Zahleneingabe auf einen Bereich und eine Schrittweite:

```javascript
{
    id: "example.number",
    name: "Example number setting",
    type: "number",
    defaultValue: 0,
    attrs: {
        min: 0,
        max: 100,
        step: 5,
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

Wenn Ihre Erweiterung PrimeVue-Props wie `showButtons`, `maxFractionDigits`, `editable` oder `filter` übergeben hat, lesen Sie die [Migration zur Entfernung von PrimeVue](/de/custom-nodes/js/primevue-removal-migration). Der Einstellungsbereich verwendet keine PrimeVue-Komponenten mehr, daher haben diese Props keine Auswirkung.

## Types

### Boolean

This shows an on/off toggle.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Text

This is freeform text.

```javascript
{
    id: "example.text",
    name: "Example text setting",
    type: "text",
    defaultValue: "Foo",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Number

This for entering numbers.

The input always shows increment and decrement buttons. Supported `attrs` are
`min`, `max`, `step` and `formatOptions`. `formatOptions` takes
[`Intl.NumberFormatOptions`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat#options),
so `maximumFractionDigits` controls how many decimal places are shown.

```javascript
{
    id: "example.number",
    name: "Example number setting",
    type: "number",
    defaultValue: 42,
    attrs: {
        step: 0.1,
        formatOptions: { maximumFractionDigits: 1 },
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Slider

This lets the user enter a number directly or via a slider.

Supported `attrs` are `min`, `max` and `step`. Ranges are not supported.

```javascript
{
    id: "example.slider",
    name: "Example slider setting",
    type: "slider",
    attrs: {
        min: -10,
        max: 10,
        step: 0.5,
    },
    defaultValue: 0,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Combo

This lets the user pick from a drop-down list of values.

You can provide options either as a plain string or as an object with `text`
and `value` fields. If you only provide a plain string, then it will be used
for both.

You can let the user search the list by supplying the `searchable: true`
attribute. Groups and freeform text entry are not supported.

```javascript
{
    id: "example.combo",
    name: "Example combo setting",
    type: "combo",
    defaultValue: "first",
    options: [
        { text: "My first option", value: "first" },
        "My second option",
    ],
    attrs: {
        searchable: true,
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Color

This lets the user select a color from a color picker or type in a hex
reference.

Note that the format requires six full hex digits (or eight, with alpha). Three
digit shorthand does not work.

```javascript
{
    id: "example.color",
    name: "Example color setting",
    type: "color",
    defaultValue: "ff0000",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Image

This lets the user upload an image.

The setting will be saved as a [data
URL](https://developer.mozilla.org/en-US/docs/Web/URI/Schemes/data).

```javascript
{
    id: "example.image",
    name: "Example image setting",
    type: "image",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Hidden

Hidden settings aren't displayed in the settings panel, but you can read and
write to them from your code.

```javascript
{
    id: "example.hidden",
    name: "Example hidden setting",
    type: "hidden",
}
```

## Other

### Categories

You can specify the categorisation of your setting separately to the `id`.
This means you can change the categorisation and naming without changing the
`id` and losing the values that have already been set by users.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    category: ["Category name", "Section heading", "Setting label"],
}
```

### Tooltips

You can add extra contextual help with the `tooltip` field. This adds a small ℹ︎
icon after the field name that will show the help text when the user hovers
over it.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    tooltip: "This is some helpful information",
}
```
