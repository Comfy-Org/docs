Sie können ComfyUI ein Objekt mit Einstellungen übergeben, das angezeigt wird, wenn der Benutzer das Einstellungen-Panel von ComfyUI öffnet.

## Grundlegende Bedienung

### Einstellung hinzufügen

```javascript
import { app } from "../../scripts/app.js";

app.registerExtension({
    name: "My Extension",
    settings: [
        {
            id: "example.boolean",
            name: "Example boolean setting",
            type: "boolean",
            defaultValue: false,
        },
    ],
});
```

Die `id` muss über alle Erweiterungen hinweg eindeutig sein und wird zum Abrufen von Werten verwendet.

Wenn Sie keine [Kategorie angeben](#kategorien), wird die `id` anhand von `.` aufgeteilt, um zu bestimmen, wo sie im Einstellungsbereich erscheint.

- Wenn Ihre `id` keinen `.` enthält, erscheint sie in der Kategorie „Other“ und Ihre `id` wird als Abschnittsüberschrift verwendet.
- Wenn Ihre `id` mindestens einen `.` enthält, wird der am weitesten links stehende Teil als Kategorie der Einstellung und der zweite Teil als Abschnittsüberschrift verwendet. Alle weiteren Teile werden ignoriert.

### Einstellung auslesen

```javascript
import { app } from "../../scripts/app.js";

if (app.extensionManager.setting.get('example.boolean')) {
    console.log("Setting is enabled.");
} else {
    console.log("Setting is disabled.");
}
```

### Auf Änderungen reagieren

Der Event-Handler `onChange()` wird aufgerufen, sobald der Benutzer die Einstellung im Einstellungsbereich ändert.

Er wird auch beim Registrieren der Erweiterung aufgerufen, und zwar bei jedem Laden der Seite.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Einstellung schreiben

```javascript
import { app } from "../../scripts/app.js";

try {
    await app.extensionManager.setting.set("example.boolean", true);
} catch (error) {
    console.error(`Error changing setting: ${error}`);
}
```

### Zusätzliche Konfiguration

Jeder Einstellungstyp rendert eine Formularkomponente des ComfyUI-Frontends. Sie können dieser Komponente zusätzliche Props in einem `attrs`-Feld übergeben. Die von den einzelnen Typen unterstützten Props sind unter [Typen](#typen) aufgeführt.

Dies beschränkt beispielsweise eine Zahleneingabe auf einen Bereich und eine Schrittweite:

```javascript
{
    id: "example.number",
    name: "Example number setting",
    type: "number",
    defaultValue: 0,
    attrs: {
        min: 0,
        max: 100,
        step: 5,
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

Wenn Ihre Erweiterung PrimeVue-Props wie `showButtons`, `maxFractionDigits`, `editable` oder `filter` übergeben hat, lesen Sie die [Migration zur Entfernung von PrimeVue](/de/custom-nodes/js/primevue-removal-migration). Der Einstellungsbereich verwendet keine PrimeVue-Komponenten mehr, daher haben diese Props keine Auswirkung.

## Typen

### Boolean

Dies zeigt einen Ein-/Aus-Schalter.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Text

Dies ist Freitext.

```javascript
{
    id: "example.text",
    name: "Example text setting",
    type: "text",
    defaultValue: "Foo",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Zahl

Damit geben Sie Zahlen ein.

Die Eingabe zeigt immer Schaltflächen zum Erhöhen und Verringern. Unterstützte `attrs` sind `min`, `max`, `step` und `formatOptions`. `formatOptions` akzeptiert [`Intl.NumberFormatOptions`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat#options), sodass `maximumFractionDigits` steuert, wie viele Nachkommastellen angezeigt werden.

```javascript
{
    id: "example.number",
    name: "Example number setting",
    type: "number",
    defaultValue: 42,
    attrs: {
        step: 0.1,
        formatOptions: { maximumFractionDigits: 1 },
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Slider

Damit kann der Benutzer eine Zahl direkt oder über einen Slider eingeben.

Unterstützte `attrs` sind `min`, `max` und `step`. Bereiche werden nicht unterstützt.

```javascript
{
    id: "example.slider",
    name: "Example slider setting",
    type: "slider",
    attrs: {
        min: -10,
        max: 10,
        step: 0.5,
    },
    defaultValue: 0,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Combo

Damit kann der Benutzer einen Wert aus einer Drop-down-Liste auswählen.

Sie können Optionen entweder als einfachen String oder als Objekt mit den Feldern `text` und `value` angeben. Wenn Sie nur einen einfachen String angeben, wird dieser für beide verwendet.

Sie können dem Benutzer die Suche in der Liste ermöglichen, indem Sie das Attribut `searchable: true` angeben. Gruppen und Freitexteingabe werden nicht unterstützt.

```javascript
{
    id: "example.combo",
    name: "Example combo setting",
    type: "combo",
    defaultValue: "first",
    options: [
        { text: "My first option", value: "first" },
        "My second option",
    ],
    attrs: {
        searchable: true,
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Farbe

Damit kann der Benutzer eine Farbe über eine Farbauswahl wählen oder eine Hex-Referenz eingeben.

Beachten Sie, dass das Format sechs vollständige Hex-Ziffern erfordert (oder acht, mit Alpha). Die Kurzform mit drei Ziffern funktioniert nicht.

```javascript
{
    id: "example.color",
    name: "Example color setting",
    type: "color",
    defaultValue: "ff0000",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Bild

Damit kann der Benutzer ein Bild hochladen.

Die Einstellung wird als [Data-URL](https://developer.mozilla.org/en-US/docs/Web/URI/Schemes/data) gespeichert.

```javascript
{
    id: "example.image",
    name: "Example image setting",
    type: "image",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Ausgeblendet

Ausgeblendete Einstellungen werden nicht im Einstellungsbereich angezeigt, Sie können sie aber aus Ihrem Code lesen und schreiben.

```javascript
{
    id: "example.hidden",
    name: "Example hidden setting",
    type: "hidden",
}
```


## Sonstiges

### Kategorien

Sie können die Kategorisierung Ihrer Einstellung getrennt von der `id` angeben. Dadurch können Sie die Kategorisierung und Benennung ändern, ohne die `id` zu ändern und die Werte zu verlieren, die Benutzer bereits festgelegt haben.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    category: ["Category name", "Section heading", "Setting label"],
}
```

### Tooltips

Sie können zusätzliche kontextbezogene Hilfe über das Feld `tooltip` hinzufügen. Dadurch wird nach dem Feldnamen ein kleines ℹ︎-Symbol eingefügt, das den Hilfetext anzeigt, wenn der Benutzer den Mauszeiger darüber bewegt.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    tooltip: "This is some helpful information",
}
```
