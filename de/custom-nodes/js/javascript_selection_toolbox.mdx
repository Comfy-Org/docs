Die Selection Toolbox API ermöglicht es Erweiterungen, benutzerdefinierte Aktionsschaltflächen hinzuzufügen, die erscheinen, wenn Nodes auf dem Canvas ausgewählt sind. Dies bietet schnellen Zugriff auf kontextbezogene Befehle für ausgewählte Elemente (Nodes, Gruppen usw.).

## Basic Usage

To add commands to the selection toolbox, your extension needs to:
1. Define commands with the standard [command interface](https://docs.comfy.org/custom-nodes/js/javascript_commands_keybindings)
2. Implement the `getSelectionToolboxCommands` method to specify which commands appear in the toolbox

Note: The `getSelectionToolboxCommands` method is called for each item in the selection set whenever a new selection is made.

```javascript
app.registerExtension({
  name: "MyExtension",
  commands: [
    {
      id: "my-extension.duplicate-special",
      label: "Duplicate Special",
      icon: "icon-[lucide--copy]",
      function: (selectedItem) => {
        // Your command logic here
        console.log("Duplicating selected nodes with special behavior");
      }
    }
  ],
  getSelectionToolboxCommands: (selectedItem) => {
    // Return array of command IDs to show in the toolbox
    return ["my-extension.duplicate-special"];
  }
});
```

## Befehlsdefinition

Befehle für die Auswahl-Toolbox verwenden die standardmäßige ComfyUI-Befehlsschnittstelle:

```javascript
{
  id: string,          // Eindeutige Kennung für den Befehl
  label: string,       // Anzeigetext für den Tooltip der Schaltfläche
  icon?: string,       // Symbolklasse für die Schaltfläche (optional)
  function: (selectedItem) => void  // Funktion, die beim Klicken ausgeführt wird
}
```

Die `function` erhält das ausgewählte Element oder die ausgewählten Elemente als Parameter, sodass Sie Aktionen für die aktuelle Auswahl ausführen können.

## Symboloptionen

Schaltflächen der Auswahl-Toolbox verwenden [Lucide](https://lucide.dev/icons/)-Symbolklassen in der Form `icon-[lucide--<icon-name>]` (z. B. `icon-[lucide--star]`).

Das Frontend generiert diese Klassen beim Build, daher sind nur die Lucide-Symbole verfügbar, die das Frontend selbst verwendet. Wenn ein Symbol nicht gerendert wird, wählen Sie ein anderes Symbol oder definieren Sie eine eigene Symbolklasse in einem Stylesheet, das Ihre Erweiterung lädt.

Die Klassen von PrimeIcons (`pi pi-*`) und Material Design Icons (`mdi mdi-*`) werden vorerst noch gerendert, aber sie werden schrittweise entfernt. Verwenden Sie sie nicht in neuem Code. Siehe [Migration zur Entfernung von PrimeVue](/de/custom-nodes/js/primevue-removal-migration).

## Dynamic Command Visibility

The `getSelectionToolboxCommands` method is called each time the selection changes, allowing you to show different commands based on what's selected:

```javascript
app.registerExtension({
  name: "ContextualCommands",
  commands: [
    {
      id: "my-ext.align-nodes",
      label: "Align Nodes",
      icon: "icon-[lucide--align-start-vertical]",
      function: () => {
        // Align multiple nodes
      }
    },
    {
      id: "my-ext.configure-single",
      label: "Configure",
      icon: "icon-[lucide--settings]",
      function: () => {
        // Configure single node
      }
    }
  ],
  getSelectionToolboxCommands: (selectedItem) => {
    const selectedItems = app.canvas.selectedItems;
    const itemCount = selectedItems ? selectedItems.size : 0;
    
    if (itemCount > 1) {
      // Show alignment command for multiple items
      return ["my-ext.align-nodes"];
    } else if (itemCount === 1) {
      // Show configuration for single item
      return ["my-ext.configure-single"];
    }
    
    return [];
  }
});
```

## Working with Selected Items

Access information about selected items through the app's canvas object. The `selectedItems` property is a Set that includes nodes, groups, and other canvas elements:

```javascript
app.registerExtension({
  name: "SelectionInfo",
  commands: [
    {
      id: "my-ext.show-info",
      label: "Show Selection Info",
      icon: "icon-[lucide--info]",
      function: () => {
        const selectedItems = app.canvas.selectedItems;
        
        if (selectedItems && selectedItems.size > 0) {
          console.log(`Selected ${selectedItems.size} items`);
          
          // Iterate through selected items
          selectedItems.forEach(item => {
            if (item.type) {
              console.log(`Item: ${item.type} (ID: ${item.id})`);
            }
          });
        }
      }
    }
  ],
  getSelectionToolboxCommands: () => ["my-ext.show-info"]
});
```

## Complete Example

Here's a simple example showing various selection toolbox features:

```javascript
app.registerExtension({
  name: "SelectionTools",
  commands: [
    {
      id: "selection-tools.count",
      label: "Count Selection",
      icon: "icon-[lucide--tag]",
      function: () => {
        const count = app.canvas.selectedItems?.size || 0;
        app.extensionManager.toast.add({
          severity: "info",
          summary: "Selection Count",
          detail: `You have ${count} item${count !== 1 ? 's' : ''} selected`,
          life: 3000
        });
      }
    },
    {
      id: "selection-tools.copy-ids",
      label: "Copy IDs",
      icon: "icon-[lucide--copy]",
      function: () => {
        const items = Array.from(app.canvas.selectedItems || []);
        const ids = items.map(item => item.id).filter(id => id !== undefined);
        
        if (ids.length > 0) {
          navigator.clipboard.writeText(ids.join(', '));
          app.extensionManager.toast.add({
            severity: "success",
            summary: "Copied",
            detail: `Copied ${ids.length} IDs to clipboard`,
            life: 2000
          });
        }
      }
    },
    {
      id: "selection-tools.log-types",
      label: "Log Types",
      icon: "icon-[lucide--info]",
      function: () => {
        const items = Array.from(app.canvas.selectedItems || []);
        const typeCount = {};
        
        items.forEach(item => {
          const type = item.type || 'unknown';
          typeCount[type] = (typeCount[type] || 0) + 1;
        });
        
        console.log("Selection types:", typeCount);
      }
    }
  ],
  
  getSelectionToolboxCommands: (selectedItem) => {
    const selectedItems = app.canvas.selectedItems;
    const itemCount = selectedItems ? selectedItems.size : 0;
    
    if (itemCount === 0) return [];
    
    const commands = ["selection-tools.count", "selection-tools.log-types"];
    
    // Only show copy command if items have IDs
    const hasIds = Array.from(selectedItems).some(item => item.id !== undefined);
    if (hasIds) {
      commands.push("selection-tools.copy-ids");
    }
    
    return commands;
  }
});
```

## Hinweise

- Die Auswahl-Toolbox muss in den Einstellungen aktiviert werden: `Comfy.Canvas.SelectionToolbox`
- Befehle müssen im `commands`-Array definiert werden, bevor sie in `getSelectionToolboxCommands` referenziert werden
- Die Toolbox wird automatisch aktualisiert, wenn sich die Auswahl ändert
- Die Methode `getSelectionToolboxCommands` wird für jedes Element in der Auswahlmenge aufgerufen, sobald eine neue Auswahl getroffen wird
- Verwenden Sie `app.canvas.selectedItems` (ein Set), um auf alle ausgewählten Elemente zuzugreifen, einschließlich Nodes, Gruppen und anderer Canvas-Elemente
- Aus Gründen der Abwärtskompatibilität existiert `app.canvas.selected_nodes` weiterhin, enthält aber nur Nodes
