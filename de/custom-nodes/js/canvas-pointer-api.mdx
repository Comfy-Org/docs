Der Canvas leitet Zeigereingaben über einen `CanvasPointer`. Er entscheidet, ob aus einem Druck ein Klick, ein Doppelklick oder ein Ziehen wird, und führt die Callbacks aus, die Sie für diesen Druck zuweisen. Auf dem Canvas gezeichnete Widgets verwenden ihn über `onPointerDown`.

## Standardverhalten

- Das Ziehen mehrerer ausgewählter Elemente erfordert nicht mehr das Halten von Shift. Ein Klick auf ein Element, während mehrere ausgewählt sind, hebt die Auswahl der übrigen weiterhin auf.
- Durch Klicken auf eine verbundene Verbindung an einer Eingabe wird diese nicht mehr getrennt und neu verbunden.
- Eine geringe Bewegung zwischen dem Drücken und dem Loslassen des Zeigers gilt weiterhin als Klicken. Sobald der Zeiger die Klick-Drift-Grenze überschreitet, wird das Drücken zum Ziehen. Die Zeit beeinflusst diese Entscheidung nicht.
- Ein Doppelklick erfordert zwei Drückvorgänge innerhalb der Doppelklick-Zeit, die höchstens das Dreifache des Klick-Drifts auseinanderliegen. Nur ein Drückvorgang, der `onDoubleClick` zuweist, kann einen Doppelklick abschließen.

Sie legen den Klick-Drift und die Doppelklick-Zeit in den Einstellungen fest
(`Comfy.Pointer.ClickDrift` und `Comfy.Pointer.DoubleClickTime`).

### Mehrere Elemente auswählen

- `Ctrl` + Ziehen: beginnt eine Mehrfachauswahl
- `Ctrl` + `Shift` + Ziehen: fügt zur Auswahl hinzu
- `Ctrl` + Ziehen, dann `Shift`: fügt zur Auswahl hinzu
- `Ctrl` + Ziehen, dann `Alt`: entfernt aus der Auswahl

## Zeigereingaben auf einem Widget verarbeiten

Weisen Sie einem Widget `onPointerDown` zu. Der Callback läuft beim Drücken des Zeigers und erhält den Zeiger, den Node und den Canvas. Weisen Sie auf dem Zeiger die benötigten Callbacks zu; der Canvas führt beim Abschluss des Drucks die passenden aus:

```js
widget.onPointerDown = function (pointer, node, canvas) {
  const e = pointer.eDown
  const offsetFromNode = [e.canvasX - node.pos[0], e.canvasY - node.pos[1]]

  pointer.onClick = (upEvent) => {
    console.log(pointer.eDown, pointer.eMove, pointer.eUp)
  }
  pointer.onDoubleClick = (upEvent) => this.customFunction(upEvent)

  pointer.onDragStart = () => {}
  pointer.onDrag = (moveEvent) => {}
  pointer.onDragEnd = (upEvent) => {}
  pointer.onDragCancel = () => {}

  pointer.finally = () => {}

  return true
}
```

- `onClick` und `onDoubleClick` laufen nie im selben Druck wie `onDragStart`, `onDragEnd` oder `onDragCancel`. `onDrag` kann in einem Druck laufen, der als Klick endet, weil er auch Bewegungen innerhalb der Klick-Toleranz erhält.
- `onDragStart` läuft einmal pro Ziehen, wenn der Zeiger die Klick-Toleranz erstmals überschreitet. Wird der Zeiger jenseits der Toleranz losgelassen, bevor ein Bewegungsereignis gemeldet wird, läuft `onDragStart` beim Loslassen, direkt danach `onDragEnd`, und `onDrag` läuft nicht.
- Wenn ein Druck sowohl `onClick` als auch `onDoubleClick` zuweist, führt das Loslassen des ersten Drucks eines Doppelklicks `onClick` aus. Der zweite Druck führt `onDoubleClick` statt `onClick` aus, gestalten Sie `onClick` daher sicher für den ersten Lauf. Der erste Klick kann auch auf einem nahe gelegenen Element statt auf Ihrem Widget landen, sodass `onDoubleClick` laufen kann, ohne dass Ihr `onClick` gelaufen ist.
- `onDragEnd` erhält das Loslassen-Ereignis eines Ziehens. Stattdessen läuft `onDragCancel`, wenn das Ziehen unterbrochen wird, zum Beispiel wenn der Pointer-Capture verloren geht.
- `finally` läuft einmal, wenn der Druck endet. Das Zuweisen von `pointer.finally` führt den ersetzten Callback sofort aus. Wenn `onPointerDown` nicht `true` zurückgibt, weist der Canvas sein eigenes `finally` zu, sodass Ihres während des Zeigerdrückens läuft. Geben Sie `true` zurück, wenn Sie `finally` für die Bereinigung nutzen.
- `pointer.eDown`, `pointer.eMove` und `pointer.eUp` geben jedem Callback Zugriff auf die gesamte Ereignisfolge.
- Geben Sie `true` zurück, damit der Canvas den Druck nicht selbst verarbeitet.
- Entfernen Sie jeden alten `widget.mouse`-Handler, wenn Sie `onPointerDown` hinzufügen. Gibt `onPointerDown` `true` zurück, verfolgt der Canvas das Widget nach dem Loslassen weiter und ruft `widget.mouse` bei jeder Zeigerbewegung weiter auf.

Der Canvas löst Doppelklicks und Ziehbewegungen für Sie auf, ein Widget muss also keine separaten Zeigerereignisse mehr timen oder messen. Er berücksichtigt außerdem die Klick-Toleranz und die Doppelklick-Einstellungen der Nutzer.

## Canvas-Cursor steuern

`canvas.state.hoveringOver` enthält Bit-Flags für die Elementtypen unter dem Zeiger, etwa Node, Gruppe, Umleitung oder Verbindung. Setzen Sie `canvas.state.shouldSetCursor` auf `false`, damit der Canvas den Cursorstil nicht mehr selbst setzt, und legen Sie ihn dann selbst fest:

```js
canvas.state.shouldSetCursor = false
canvas.canvas.style.cursor = 'pointer'
```

Wird die Größenänderung eines Nodes gestartet, setzt der Canvas trotzdem einen Cursor zum Ändern der Größe, solange `shouldSetCursor` `false` ist. Setzen Sie Ihren Cursor nach Abschluss der Größenänderung erneut.
