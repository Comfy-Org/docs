## Den Comfy-Client erweitern

Comfy kann über einen Erweiterungsmechanismus geändert werden. Um eine Erweiterung hinzuzufügen, müssen Sie:

- `WEB_DIRECTORY` aus Ihrem Python-Modul exportieren,
- eine oder mehrere `.js`-Dateien in dieses Verzeichnis legen,
- `app.registerExtension` verwenden, um Ihre Erweiterung zu registrieren.

Diese drei Schritte sind unten beschrieben. Wenn Sie wissen, wie Sie eine Erweiterung hinzufügen, sehen Sie sich die verfügbaren [Hooks](/de/custom-nodes/js/javascript_hooks) an, mit denen Ihr Code aufgerufen wird, lesen Sie die Beschreibung der verschiedenen [Comfy-Objekte](/de/custom-nodes/js/javascript_objects_and_hijacking), die Sie möglicherweise benötigen, oder springen Sie direkt zu einigen [Beispielcode-Snippets](/de/custom-nodes/js/javascript_examples).

### `WEB_DIRECTORY` exportieren

Der Comfy-Webclient kann erweitert werden, indem Sie ein Unterverzeichnis in Ihrem Custom-Node-Verzeichnis erstellen, das üblicherweise `js` genannt wird, und `WEB_DIRECTORY` exportieren. Ihre `__init_.py` enthält dann etwa Folgendes:
```python
WEB_DIRECTORY = "./js"
__all__ = ["NODE_CLASS_MAPPINGS", "NODE_DISPLAY_NAME_MAPPINGS", "WEB_DIRECTORY"]
```

### `.js`-Dateien einbinden

<Tip>Alle JavaScript-`.js`-Dateien werden vom Browser geladen, während die Comfy-Webseite geladen wird. Sie müssen die Datei, in der sich Ihre Erweiterung befindet, nicht angeben.</Tip>

_Nur_ `.js`-Dateien werden der Webseite hinzugefügt. Auf andere Ressourcen (etwa `.css`-Dateien) können Sie unter `extensions/custom_node_subfolder/the_file.css` zugreifen und sie programmgesteuert hinzufügen.

<Warning>Dieser Pfad enthält _nicht_ den Namen des Unterordners. Der Wert von `WEB_DIRECTORY` wird vom Server eingefügt.</Warning>

### Eine Erweiterung registrieren

Die grundlegende Struktur einer Erweiterung besteht darin, das Hauptobjekt `app` von Comfy zu importieren und `app.registerExtension` aufzurufen. Dabei übergeben Sie ein Objekt mit einem eindeutigen `name` und einer oder mehreren Funktionen, die von Hooks im Comfy-Code aufgerufen werden.

Eine vollständige, triviale und nervige Erweiterung könnte so aussehen:
```Javascript
import { app } from "../../scripts/app.js";
app.registerExtension({ 
	name: "a.unique.name.for.a.useless.extension",
	async setup() { 
		alert("Setup complete!")
	},
})
```
