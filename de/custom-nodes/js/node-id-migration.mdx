Das ComfyUI-Frontend normalisiert lokale Node-IDs an internen Grenzen inzwischen auf den gebrandeten String-Typ `NodeId`. Serialisierte Workflows und API-Payloads können weiterhin numerische IDs enthalten, aber Node-IDs in litegraph, etwa `node.id`, `LLink.origin_id` und `LLink.target_id`, sollten nach dem Eintritt in das Frontend als Strings behandelt werden. Verbindungs-IDs (`LLink.id`) und Umleitungs-IDs bleiben Zahlen.

Autorinnen und Autoren von Erweiterungen sollten numerische Vergleiche mit Node-IDs vermeiden. Insbesondere werden die Grenzmarker von Subgraphen als gebrandete String-IDs bereitgestellt:

- `SUBGRAPH_INPUT_ID` wird aus `-10` serialisiert
- `SUBGRAPH_OUTPUT_ID` wird aus `-20` serialisiert

Vergleichen Sie mit den Strings `'-10'` und `'-20'`, oder normalisieren Sie beide Seiten auf Strings, bevor Sie ältere Werte vergleichen.
