## pytorch, Tensoren und torch.Tensor

Die gesamte Kernrechenarbeit in Comfy erledigt [pytorch](https://pytorch.org/). Wenn Ihre Custom Nodes bis in die Eingeweide von Stable Diffusion vordringen sollen, müssen Sie sich mit dieser Bibliothek vertraut machen, was den Rahmen dieser Einführung bei Weitem sprengt.

Viele Custom Nodes müssen jedoch Bilder, Latents und Masken bearbeiten, die intern jeweils als `torch.Tensor` dargestellt werden. Setzen Sie sich also ein Lesezeichen auf die
[Dokumentation für torch.Tensor](https://pytorch.org/docs/stable/tensors.html).

### Was ist ein Tensor?

`torch.Tensor` repräsentiert einen Tensor, also die mathematische Verallgemeinerung eines Vektors oder einer Matrix auf eine beliebige Anzahl von Dimensionen.
Der _Rang_ eines Tensors ist die Anzahl seiner Dimensionen (ein Vektor hat _Rang_ 1, eine Matrix _Rang_ 2); seine _Form_ beschreibt die
Größe jeder Dimension.

Ein RGB-Bild (mit der Höhe H und der Breite W) kann man sich also als drei Arrays (eines pro Farbkanal) vorstellen, die jeweils H x W groß sind,
was sich als Tensor mit der _Form_ `[H,W,3]` darstellen lässt. In Comfy kommen Bilder fast immer in einem Batch (auch wenn der Batch
nur ein einziges Bild enthält). `torch` stellt die Batch-Dimension immer an die erste Stelle, daher haben Comfy-Bilder die _Form_ `[B,H,W,3]`,
üblicherweise geschrieben als `[B,H,W,C]`, wobei C für Channels (Kanäle) steht.

### squeeze, unsqueeze und reshape

Wenn ein Tensor eine Dimension der Größe 1 hat (eine sogenannte kollabierte Dimension), dann entspricht er demselben Tensor ohne diese Dimension
(ein Batch mit 1 Bild ist einfach ein Bild). Das Entfernen einer solchen kollabierten Dimension nennt man Squeezing,
das Einfügen Unsqueezing.

<Warning>
  Manche torch-Codes und manche Autoren von Custom Nodes geben einen gesqueezten Tensor zurück, wenn eine Dimension kollabiert ist,
etwa wenn ein Batch nur ein einziges Element enthält. Das ist eine häufige Ursache für Bugs!
</Warning>

Dieselben Daten in einer anderen Form darzustellen, nennt man Reshaping. Das erfordert oft, dass Sie die
zugrunde liegende Datenstruktur kennen, gehen Sie also vorsichtig damit um!

### Wichtige Notation

`torch.Tensor` unterstützt den Großteil der Python-Slice-Notation, Iteration und andere gängige listenähnliche Operationen. Ein Tensor
hat außerdem ein Attribut `.shape`, das seine Größe als `torch.Size` zurückgibt (eine Unterklasse von `tuple`, die auch so
behandelt werden kann).

Es gibt noch einige andere wichtige Notationselemente, die Sie häufig sehen werden (einige davon sind eher ungewöhnliche
Standard-Python-Notation, die Ihnen im Umgang mit Tensoren aber viel häufiger begegnet):

- `torch.Tensor` unterstützt die Verwendung von `None` in der Slice-Notation,
um das Einfügen einer Dimension der Größe 1 anzuzeigen.

- `:` wird beim Slicen eines Tensors häufig verwendet; das bedeutet einfach „die gesamte Dimension behalten“.
Es ist wie `a[start:end]` in Python, nur dass Start- und Endpunkt weggelassen werden.

- `...` steht für „die Gesamtheit einer nicht näher bestimmten Anzahl von Dimensionen“. `a[0, ...]` würde also das erste
Element eines Batches extrahieren, unabhängig von der Anzahl der Dimensionen.

- Bei Methoden, die eine Form als Argument erwarten, wird diese oft als `tuple` der Dimensionen übergeben,
wobei eine einzelne Dimension die Größe `-1` erhalten kann, was bedeutet, dass die Größe dieser Dimension
anhand der Gesamtgröße der Daten berechnet werden soll.

```python
>>> a = torch.Tensor((1,2))
>>> a.shape
torch.Size([2])
>>> a[:,None].shape 
torch.Size([2, 1])
>>> a.reshape((1,-1)).shape
torch.Size([1, 2])
```

### Elementweise Operationen

Viele binäre Operatoren auf `torch.Tensor` (darunter '+', '-', '*', '/' und '==') werden elementweise angewendet (unabhängig auf jedes Element).
Die Operanden müssen _entweder_ zwei Tensoren gleicher Form _oder_ ein Tensor und ein Skalar sein. Also:

```python
>>> import torch
>>> a = torch.Tensor((1,2))
>>> b = torch.Tensor((3,2))
>>> a*b
tensor([3., 4.])
>>> a/b
tensor([0.3333, 1.0000])
>>> a==b
tensor([False,  True])
>>> a==1
tensor([ True, False])
>>> c = torch.Tensor((3,2,1)) 
>>> a==c
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
RuntimeError: The size of tensor a (2) must match the size of tensor b (3) at non-singleton dimension 0
```

### Wahrheitswert von Tensoren

<Warning>
  Der „Wahrheitswert“ eines Tensors ist nicht derselbe wie der einer Python-Liste.
</Warning>

Vielleicht kennen Sie den Wahrheitswert einer Python-Liste: `True` für jede nicht leere Liste und `False` für `None` oder `[]`.
Ein `torch.Tensor` (mit mehr als einem Element) hat dagegen keinen definierten Wahrheitswert. Stattdessen müssen Sie
`.all()` oder `.any()` verwenden, um die elementweisen Wahrheitswerte zu kombinieren:

```python
>>> a = torch.Tensor((1,2))
>>> print("yes" if a else "no")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
RuntimeError: Boolean value of Tensor with more than one value is ambiguous
>>> a.all()
tensor(False)
>>> a.any()
tensor(True)
```

Das bedeutet auch, dass Sie `if a is not None:` statt `if a:` verwenden müssen, um festzustellen, ob eine Tensor-Variable gesetzt wurde.
