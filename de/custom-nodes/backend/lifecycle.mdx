## So lädt ComfyUI Custom Nodes

Wenn ComfyUI startet, durchsucht es das Verzeichnis `custom_nodes` nach Python-Modulen und versucht, sie zu laden. 
Wenn das Modul `NODE_CLASS_MAPPINGS` exportiert, wird es als Custom Node behandelt.
<Tip>
  Ein Python-Modul ist ein Verzeichnis, das eine Datei `__init__.py` enthält.
Das Modul exportiert alles, was im Attribut `__all__` aufgeführt ist, das in `__init__.py` definiert wurde.</Tip>

### __init__.py

`__init__.py` wird ausgeführt, wenn ComfyUI versucht, das Modul zu importieren. Damit ein Modul als ein Modul mit Definitionen von Custom Nodes erkannt wird, muss es `NODE_CLASS_MAPPINGS` exportieren. Wenn es das tut (und beim Importieren nichts schiefgeht), sind die im Modul definierten Nodes in ComfyUI verfügbar. Wenn in Ihrem Code ein Fehler auftritt, fährt ComfyUI fort, meldet das Modul aber als fehlgeschlagen beim Laden. Prüfen Sie also die Python-Konsole!

Eine sehr einfache Datei `__init__.py` sieht so aus:
```python
from .python_file import MyCustomNode
NODE_CLASS_MAPPINGS = { "My Custom Node" : MyCustomNode }
__all__ = ["NODE_CLASS_MAPPINGS"]
```

#### NODE_CLASS_MAPPINGS

`NODE_CLASS_MAPPINGS` muss ein `dict` sein, das Namen von Custom Nodes (eindeutig in der gesamten ComfyUI-Installation) den entsprechenden Node-Klassen zuordnet. 

#### NODE_DISPLAY_NAME_MAPPINGS

`__init__.py` kann außerdem `NODE_DISPLAY_NAME_MAPPINGS` exportieren. Dieses ordnet denselben eindeutigen Namen einen Anzeigenamen für den Node zu.
Wenn `NODE_DISPLAY_NAME_MAPPINGS` nicht bereitgestellt wird, verwendet ComfyUI den eindeutigen Namen als Anzeigenamen.

#### WEB_DIRECTORY

Wenn Sie clientseitigen Code bereitstellen, müssen Sie außerdem den Pfad relativ zum Modul exportieren, unter dem die JavaScript-Dateien zu finden sind. Üblicherweise werden diese in einem Unterverzeichnis Ihres Custom Nodes namens `js` abgelegt.
<Tip>
  *Nur* `.js`-Dateien werden ausgeliefert; `.css` oder andere Dateitypen können Sie auf diese Weise nicht bereitstellen.</Tip>

<Warning>
  In früheren Versionen von ComfyUI musste `__init__.py` die JavaScript-Dateien in das Haupt-Web-Unterverzeichnis von ComfyUI kopieren. Sie werden weiterhin Code sehen, der dies tut. Tun Sie das nicht.</Warning>
