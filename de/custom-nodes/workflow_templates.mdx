Wenn Sie Beispiel-Workflow-Dateien für Ihre Custom Nodes haben,
kann ComfyUI diese dem Benutzer im Vorlagen-Browser (`Workflow`/`Browse Templates`-Menü) anzeigen.
Workflow-Vorlagen sind eine großartige Möglichkeit, Benutzer bei den ersten Schritten mit Ihren Nodes zu unterstützen.

Als Node-Entwickler müssen Sie lediglich einen Ordner `example_workflows` erstellen und die `json`-Dateien dort ablegen.
Optional können Sie `jpg`-Dateien mit demselben Namen ablegen, die als Thumbnail der Vorlage angezeigt werden.

Intern stellt ComfyUI diese Dateien statisch bereit, zusammen mit einem Endpoint (`/api/workflow_templates`),
der die Sammlung der Workflow-Vorlagen zurückgibt.

<Note>

Die folgenden Ordnernamen werden ebenfalls akzeptiert, wir empfehlen jedoch weiterhin `example_workflows`:
- workflow
- workflows
- example
- examples
</Note>

## Beispiel

Im Verzeichnis `ComfyUI-MyCustomNodeModule/example_workflows/`:
 - `My_example_workflow_1.json`
 - `My_example_workflow_1.jpg`
 - `My_example_workflow_2.json`

In diesem Beispiel zeigt der Vorlagen-Browser von ComfyUI eine Kategorie namens `ComfyUI-MyCustomNodeModule` mit zwei Einträgen, von denen einer ein Thumbnail hat.

Ein Beispiel aus der Praxis finden Sie im [example_workflows-Ordner von ComfyUI-Impact-Pack](https://github.com/ltdrdata/ComfyUI-Impact-Pack/tree/Main/example_workflows).
