Wenn Sie wiederverwendbare Subgraph-Komponenten besitzen, die zu Ihren Custom Nodes gehören, kann ComfyUI diese Benutzern als globale Subgraph-Blueprints zur Verfügung stellen. Mit Subgraph-Blueprints können Benutzer vorgefertigte Node-Gruppen schnell über das Subgraph-Menü hinzufügen.

Als Node-Entwickler müssen Sie lediglich einen Ordner `subgraphs` in Ihrem Custom-Node-Verzeichnis anlegen und die `.json`-Dateien dort ablegen.

Im Hintergrund durchsucht ComfyUI alle Custom-Node-Verzeichnisse nach Subgraph-Dateien und stellt sie über den API-Endpunkt `/global_subgraphs` bereit.

## Beispiel

Im Verzeichnis `ComfyUI-MyCustomNodeModule/subgraphs/`:
 - `My_upscale_subgraph.json`
 - `My_effects_subgraph.json`

In diesem Beispiel zeigt der Subgraph-Browser von ComfyUI Blueprints aus `ComfyUI-MyCustomNodeModule` an, die Benutzer ihren Workflows hinzufügen können.

## Eine Subgraph-JSON-Datei erstellen {#creating-a-subgraph-json-file}

Subgraph-JSON-Dateien verwenden dasselbe Format wie Workflow-JSON-Dateien. Der einfachste Weg, eine zu erstellen:

1. Bauen Sie Ihren Subgraph in ComfyUI
2. Wählen Sie die Nodes aus, die Sie einbeziehen möchten
3. Wandeln Sie sie in einen Subgraph um
4. Exportieren Sie den Subgraph als JSON
5. Legen Sie die JSON-Datei in Ihrem Ordner `subgraphs/` ab
