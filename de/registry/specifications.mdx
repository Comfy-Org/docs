# Spezifikationen

Die Datei `pyproject.toml` enthält zwei Hauptabschnitte für ComfyUI Custom Nodes: `[project]` und `[tool.comfy]`. Im Folgenden finden Sie die Spezifikationen für jeden Abschnitt.

## Abschnitt [project]

### name (erforderlich)
Die Node-ID identifiziert das Custom Node eindeutig und wird in URLs der Registry verwendet. Benutzer können das Node installieren, indem sie diesen Namen angeben:

```bash
comfy node install <node-id>
```

**Anforderungen:**
- Muss kürzer als 100 Zeichen sein
- Darf nur alphanumerische Zeichen, Bindestriche, Unterstriche und Punkte enthalten
- Darf keine aufeinanderfolgenden Sonderzeichen enthalten
- Darf nicht mit einer Zahl oder einem Sonderzeichen beginnen
- Vergleich ohne Beachtung der Groß-/Kleinschreibung

**Bewährte Vorgehensweisen:**
- Verwenden Sie einen kurzen, beschreibenden Namen
- Nehmen Sie „ComfyUI“ nicht in den Namen auf
- Halten Sie ihn einprägsam und leicht zu tippen

**Beispiele:**
```toml
name = "image-processor"      # ✅ Gut: Einfach und klar
name = "super-resolution"     # ✅ Gut: Beschreibt die Funktionalität
name = "ComfyUI-enhancer"    # ❌ Schlecht: Enthält ComfyUI
name = "123-tool"            # ❌ Schlecht: Beginnt mit einer Zahl
```

Weitere Details finden Sie in der offiziellen [Python-Dokumentation](https://packaging.python.org/en/latest/guides/writing-pyproject-toml/#name).

### version (erforderlich)
Verwendet [Semantic Versioning](https://semver.org/) mit einer dreistelligen Versionsnummer X.Y.Z:

- X (**MAJOR**): Inkompatible Änderungen
- Y (**MINOR**): Neue Funktionen (abwärtskompatibel)
- Z (**PATCH**): Fehlerbehebungen

**Beispiele:**
```toml
version = "1.0.0"    # Erstes Release
version = "1.1.0"    # Neue Funktionen hinzugefügt
version = "1.1.1"    # Fehlerbehebung
version = "2.0.0"    # Inkompatible Änderungen
```

### license (optional)
Legt die Lizenz für Ihr Custom Node fest. Die Angabe kann auf zwei Arten erfolgen:

1. **Dateireferenz:**
```toml
license = { file = "LICENSE" }     # ✅ Verweist auf die Datei LICENSE
license = { file = "LICENSE.txt" } # ✅ Verweist auf LICENSE.txt
license = "LICENSE"                # ❌ Falsches Format
```

2. **Lizenzname:**
```toml
license = { text = "MIT License" }  # ✅ Richtiges Format
license = { text = "Apache-2.0" }   # ✅ Richtiges Format
license = "MIT LICENSE"             # ❌ Falsches Format
```

Häufige Lizenzen: [MIT](https://opensource.org/license/mit), [GPL](https://www.gnu.org/licenses/gpl-3.0.en.html), [Apache](https://www.apache.org/licenses/LICENSE-2.0)

### description (empfohlen)
Eine kurze Beschreibung dessen, was Ihr Custom Node tut.

```toml
description = "A super resolution node for enhancing image quality"
```

### repository (erforderlich)
Links zu zugehörigen Ressourcen:

```toml
[project.urls]
Repository = "https://github.com/username/repository"
```

### urls (empfohlen)
Links zu zugehörigen Ressourcen:

```toml
[project.urls]
Documentation = "https://github.com/username/repository/wiki"
"Bug Tracker" = "https://github.com/username/repository/issues"
```

### requires-python (empfohlen)
Gibt die Python-Versionen an, die Ihr Node unterstützt:

```toml
requires-python = ">=3.8"        # Python 3.8 oder höher
requires-python = ">=3.8,<3.11"  # Python 3.8 bis (ausschließlich) 3.11
```

### Kompatibilität mit Frontend-Versionen (optional)
Wenn Ihr Node bestimmte Anforderungen an die unterstützten ComfyUI-Frontend-Versionen hat, können Sie dies über die Abhängigkeit `comfyui-frontend-package` angeben. Dieses Paket wird auf [PyPI](https://pypi.org/project/comfyui-frontend-package/) veröffentlicht.

Verwenden Sie dieses Feld zum Beispiel, wenn:
- Ihr Custom Node Frontend-APIs verwendet, die in einer bestimmten Version eingeführt wurden
- Sie Inkompatibilitäten zwischen Ihrem Node und bestimmten Frontend-Versionen festgestellt haben
- Ihr Node bestimmte UI-Funktionen benötigt, die nur in neueren Frontend-Versionen verfügbar sind

```toml
[project]
dependencies = [
    "comfyui-frontend-package>=1.20.0"       # Erfordert Frontend 1.20.0 oder neuer
    "comfyui-frontend-package<=1.21.6"       # Beschränkt auf Frontend-Versionen bis 1.21.6
    "comfyui-frontend-package>=1.19,<1.22"   # Funktioniert mit Frontend 1.19 bis 1.21.x
    "comfyui-frontend-package~=1.20.0"       # Kompatibel mit 1.20.x, aber nicht mit 1.21.0
    "comfyui-frontend-package!=1.21.3"       # Funktioniert mit jeder Version außer 1.21.3
]
```

### classifiers (empfohlen)
Verwenden Sie Classifier, um die Kompatibilität mit Betriebssystemen und GPU-Beschleunigern anzugeben. Diese Informationen helfen Benutzern, das richtige Node für ihr System zu finden.

```toml
[project]
classifiers = [
    # Für betriebssystemunabhängige Nodes (funktioniert auf allen Betriebssystemen)
    "Operating System :: OS Independent",

    # ODER für betriebssystemabhängige Nodes: Geben Sie die unterstützten Systeme an:
    "Operating System :: Microsoft :: Windows",  # Windows-spezifisch
    "Operating System :: POSIX :: Linux",  # Linux-spezifisch
    "Operating System :: MacOS",  # macOS-spezifisch
    
    # Unterstützung für GPU-Beschleuniger
    "Environment :: GPU :: NVIDIA CUDA",    # NVIDIA-CUDA-Support
    "Environment :: GPU :: AMD ROCm",       # AMD-ROCm-Support
    "Environment :: GPU :: Intel Arc",      # Intel-Arc-Support
    "Environment :: NPU :: Huawei Ascend",  # Huawei-Ascend-Support
    "Environment :: GPU :: Apple Metal",    # Apple-Metal-Support
]
```


## [tool.comfy] Abschnitt

### PublisherId (erforderlich)
Ihre eindeutige Herausgeber-ID, die in der Regel Ihrem GitHub-Benutzernamen entspricht.

**Beispiele:**
```toml
PublisherId = "john-doe"        # ✅ Entspricht dem GitHub-Benutzernamen
PublisherId = "image-wizard"    # ✅ Eindeutige Kennung
```

### DisplayName (optional)
Ein benutzerfreundlicher Name für Ihren Custom Node.

```toml
DisplayName = "Super Resolution Node"
```

### Icon (optional)
URL zum Symbol Ihres Custom Node, das im ComfyUI Registry und in ComfyUI-Manager angezeigt wird.

**Anforderungen:**
- Dateitypen: SVG, PNG, JPG oder GIF
- Maximale Auflösung: 400px × 400px
- Das Seitenverhältnis sollte quadratisch sein

```toml
Icon = "https://raw.githubusercontent.com/username/repo/main/icon.png"
```

### Banner (optional)
URL zu einem größeren Bannerbild, das im ComfyUI Registry und in ComfyUI-Manager angezeigt wird.

**Anforderungen:**
- Dateitypen: SVG, PNG, JPG oder GIF
- Seitenverhältnis: 21:9

```toml
Banner = "https://raw.githubusercontent.com/username/repo/main/banner.png"
```

### requires-comfyui (optional)
Gibt an, mit welcher Version von ComfyUI Ihr Node kompatibel ist. So können Benutzer sicherstellen, dass sie die richtige Version von ComfyUI installiert haben.

**Unterstützte Operatoren:** `<`, `>`, `<=`, `>=`, `~=`, `<>`, `!=` und Bereiche

```toml
requires-comfyui = ">=1.0.0"        # ComfyUI 1.0.0 oder höher
requires-comfyui = ">=1.0.0,<2.0.0"  # ComfyUI 1.0.0 bis (aber nicht einschließlich) 2.0.0
requires-comfyui = "~=1.0.0"         # Kompatible Release: Version 1.0.0 oder neuer, aber nicht Version 2.0.0
requires-comfyui = "!=1.2.3"         # Jede Version außer 1.2.3
requires-comfyui = ">0.1.3,<1.0.0"   # Größer als 0.1.3 und kleiner als 1.0.0
```

### includes (optional)
Gibt an, ob bestimmte Ordner zwangsweise eingebunden werden sollen. In manchen Situationen, etwa bei Custom Nodes in Frontend-Projekten, kann der endgültig gepackte Ausgabeordner in .gitignore enthalten sein. In solchen Fällen müssen wir ihn für die Verwendung im Registry zwangsweise einbinden.

```toml
includes = ['dist']
```

<Tip>Informationen zum Ausschließen von Dateien aus dem veröffentlichten Archiv (die Umkehrung von `includes`) finden Sie unter [`.comfyignore`](/de/registry/publishing#dateien-mit-comfyignore-ausschließen) auf der Seite zur Veröffentlichung.</Tip>

## Vollständiges Beispiel
```toml
[project]
name = "super-resolution-node"
version = "1.0.0"
description = "Enhance image quality using advanced super resolution techniques"
license = { file = "LICENSE" }
requires-python = ">=3.8"
dependencies = [
    "comfyui-frontend-package<=1.21.6"  # Kompatibilität mit der Frontend-Version
]
classifiers = [
    "Operating System :: OS Independent"  # Funktioniert auf allen Betriebssystemen
]
dynamic = ["dependencies"]

[tool.setuptools.dynamic]
dependencies = {file = ["requirements.txt"]}

[project.urls]
Repository = "https://github.com/username/super-resolution-node"
Documentation = "https://github.com/username/super-resolution-node/wiki"
"Bug Tracker" = "https://github.com/username/super-resolution-node/issues"

[tool.comfy]
PublisherId = "image-wizard"
DisplayName = "Super Resolution Node"
Icon = "https://raw.githubusercontent.com/username/super-resolution-node/main/icon.png"
Banner = "https://raw.githubusercontent.com/username/super-resolution-node/main/banner.png"
requires-comfyui = ">=1.0.0"  # Kompatibilität mit der ComfyUI-Version
```
