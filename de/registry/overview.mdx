## Einführung

Die Registry ist eine öffentliche Sammlung von Custom Nodes und bildet die Grundlage für [ComfyUI-Manager](https://github.com/Comfy-Org/ComfyUI-Manager). Entwickler können ihre Custom Nodes veröffentlichen, versionieren, als veraltet markieren und Metriken dazu verfolgen. ComfyUI-Nutzer können Custom Nodes aus der Registry über ComfyUI-Manager entdecken, installieren und bewerten.

## Warum das Registry verwenden?

Das Comfy Registry hilft der Community, indem es die Entwicklung von Custom Nodes standardisiert:

<Icon icon="timeline" iconType="solid" size={20}/>&nbsp; **Node-Versionierung:** Entwickler veröffentlichen häufig neue Versionen ihrer Custom Nodes, die oft Workflows brechen, die auf ihnen basieren. Da Registry-Nodes [semantisch versioniert](https://semver.org/) sind, können Sie Node-Versionen jetzt sicher upgraden, als veraltet markieren oder an ihrer Stelle fixieren und wissen im Voraus, wie sich Ihre Aktionen auf Ihre Workflows auswirken. Die Workflow-JSON speichert die Version des verwendeten Nodes, sodass Sie Ihre Workflows jederzeit zuverlässig reproduzieren können.

<Icon icon="shield" iconType="solid" size={20}/>&nbsp; **Node-Sicherheit:** Das Registry dient als Backend für den [ComfyUI-manager](https://github.com/Comfy-Org/ComfyUI-Manager). Alle Nodes werden auf schädliches Verhalten wie benutzerdefinierte pip-Wheels, beliebige Systemaufrufe usw. geprüft. Nodes, die diese Prüfungen bestehen, erhalten neben ihrem Namen im UI-Manager ein Verifizierungs-Symbol (<Icon icon="check" iconType="solid" />). Eine Liste der Sicherheitsstandards finden Sie unter [Standards](/de/registry/standards).

<Icon icon="magnifying-glass" iconType="solid" size={20}/>&nbsp; **Suche:** Durchsuchen Sie alle Nodes im Registry, um vorhandene Nodes für Ihren Workflow zu finden.

## Häufig gestellte Fragen

<AccordionGroup>
  <Accordion title="Haben Registry-Nodes eindeutige Bezeichner?">
    Ja, ein Custom Node in der Registry hat einen global eindeutigen Namen. Dadurch können Comfy Workflow JSON-Dateien jeden Custom Node eindeutig und ohne Kollisionen identifizieren.
  </Accordion>
  <Accordion title="Gibt es Einschränkungen dabei, was ich veröffentlichen kann?">
    Weitere Informationen finden Sie in den [Standards](/de/registry/standards).
  </Accordion>

  <Accordion title="Wie wird die Stabilität der Nodes gewährleistet?">
    Sobald eine Version eines Custom Node veröffentlicht wurde, kann sie nicht mehr geändert werden. Dadurch können sich Nutzer langfristig auf die Stabilität des Custom Node verlassen.
  </Accordion>

  <Accordion title="Wie werden Nodes versioniert?">
    Custom Nodes werden mit [semantischer Versionierung](https://semver.org/) versioniert. So können Nutzer die Auswirkungen eines Upgrades auf eine neue Version einschätzen.
  </Accordion>

  <Accordion title="Wie erkläre ich eine Node-Version als veraltet?">
    Sie können eine Version auf der Website der Comfy Registry als veraltet markieren, indem Sie auf **More Actions > Deprecate** klicken. Nutzern, die diese Version installiert haben, wird die Meldung zur Veraltung angezeigt und sie werden dazu angehalten, auf eine neuere Version zu upgraden.

    Das Markieren von Versionen als veraltet ist nützlich, wenn nach dem Veröffentlichen ein Problem entdeckt wird.
  </Accordion>

</AccordionGroup>
