## Häufige Probleme

### Benutzerdefinierter Pfad zur Git-Programmdatei

Wenn Ihre `git.exe` an einem anderen Ort als dem Systemstandard installiert ist:

1. Installieren Sie ComfyUI-Manager und starten Sie ComfyUI einmal
2. Öffnen Sie `<USER_DIRECTORY>/default/ComfyUI-Manager/config.ini`
3. Geben Sie bei `git_exe =` den vollständigen Pfad einschließlich des Dateinamens an

```ini
git_exe = C:\Program Files\Git\bin\git.exe
```

### Update von ComfyUI-Manager schlägt fehl

Wenn das Aktualisieren von ComfyUI-Manager selbst fehlschlägt, wechseln Sie in das Verzeichnis von ComfyUI-Manager und führen Sie Folgendes aus:

```bash
git update-ref refs/remotes/origin/main a361cc1 && git fetch --all && git pull
```

### Windows: Fehler „Overlapped Object“

Wenn die Meldung `Overlapped Object has pending operation at deallocation on ComfyUI Manager load` auftritt:

Bearbeiten Sie `config.ini` und fügen Sie Folgendes hinzu:

```ini
windows_selector_event_loop_policy = True
```

### SSL-Zertifikatsprüfung fehlgeschlagen

Wenn der Fehler `SSL: CERTIFICATE_VERIFY_FAILED` auftritt:

Bearbeiten Sie `config.ini` und fügen Sie Folgendes hinzu:

```ini
bypass_ssl = True
```

## Probleme bei der Installation

### Falscher Installationspfad

Die Dateien von ComfyUI-Manager müssen sich in `ComfyUI/custom_nodes/comfyui-manager` befinden.

**Häufige Fehler, die Sie vermeiden sollten:**

| Problem | Beschreibung |
|-------|---------|
| Dateien am falschen Ort | Manager-Dateien wie `__init__.py` werden direkt im Verzeichnis `custom_nodes` abgelegt |
| Doppelt verschachtelter Ordner | Installiert als `custom_nodes/ComfyUI-Manager/ComfyUI-Manager` |
| Falscher Ordnername | Installiert als `custom_nodes/ComfyUI-Manager-main` |
| Komprimiertes Format | Installation aus einer komprimierten Datei ohne ordnungsgemäße Entpackung |

<Warning>
Bei einer falschen Installation kann ComfyUI-Manager scheinbar funktionieren, wird aber nicht für Aktualisierungen erkannt und kann doppelte Installationen verursachen. Entfernen Sie ihn und installieren Sie ihn ordnungsgemäß neu über `git clone`.
</Warning>

## Netzwerkprobleme

### Probleme beim Zugriff auf GitHub

Wenn Sie nur eingeschränkten Zugriff auf GitHub haben, setzen Sie die Umgebungsvariable `GITHUB_ENDPOINT`:

```bash
GITHUB_ENDPOINT=https://mirror.ghproxy.com/https://github.com
```

### Probleme beim Zugriff auf Hugging Face

Wenn Sie nur eingeschränkten Zugriff auf Hugging Face haben, setzen Sie die Umgebungsvariable `HF_ENDPOINT`:

```bash
HF_ENDPOINT=https://some-hf-mirror.com
```

## Fehlerbehebung beim Scanner

Wenn Sie das Skript `scan.sh` ausführen:

- Es aktualisiert `extension-node-map.json`, indem es die in `custom-node-list.json` aufgelisteten Custom Nodes per Pull oder Clone nach `~/.tmp/default` holt
- Es aktualisiert `github-stats.json` über die GitHub API

| Option | Beschreibung |
|--------|-------------|
| `--skip-update` | Aktualisieren von extension-node-map.json überspringen |
| `--skip-stat-update` | Aktualisieren von github-stats.json überspringen |
| `--skip-all` | Beide Aktualisierungsschritte überspringen |

<Tip>
Um die Ratenlimits der GitHub API zu vermeiden, setzen Sie Ihren Token: `export GITHUB_TOKEN=your_token_here`
</Tip>

Wenn Sie anstelle von `~/.tmp/default` einen anderen Pfad angeben möchten, führen Sie `python scanner.py [path]` direkt statt `scan.sh` aus.

## Sicherheitsrichtlinie

Wenn beim Installieren von Custom Nodes über eine Git-URL oder bei der Verwendung der Nightly-Version der Fehler `This action is not allowed with this security level configuration` auftritt, müssen Sie die Sicherheitsstufe in Ihrer Datei `config.ini` anpassen.

Die Datei `config.ini` befindet sich unter:
- **ComfyUI v0.3.76+**: `<USER_DIRECTORY>/__manager/config.ini`
- **Ältere Versionen**: `<USER_DIRECTORY>/default/ComfyUI-Manager/config.ini`

Dabei ist `<USER_DIRECTORY>` standardmäßig `ComfyUI/user`. Weitere Details finden Sie unter [Konfiguration](/de/manager/configuration).

Konfigurieren Sie die Sicherheitsstufen in `config.ini`:

```ini
security_level = normal
```

| Stufe | Beschreibung |
|-------|-------------|
| `strong` | Erlaubt keine riskanten Funktionen der hohen und mittleren Stufe |
| `normal` | Erlaubt keine riskanten Funktionen der hohen Stufe; Funktionen der mittleren Stufe sind verfügbar |
| `normal-` | Erlaubt keine riskanten Funktionen der hohen Stufe, wenn `--listen` angegeben ist und nicht mit `127.` beginnt; Funktionen der mittleren Stufe sind verfügbar |
| `weak` | Alle Funktionen verfügbar |

### Risikostufen für Funktionen

| Risikostufe | Funktionen |
|------------|----------|
| **Hoch** | Installation per Git-URL, pip install, Installation von Custom Nodes, die nicht im Standard-Kanal enthalten sind, Custom Nodes reparieren |
| **Mittel** | Deinstallieren/Aktualisieren, Installation von Custom Nodes im Standard-Kanal, Snapshot wiederherstellen/entfernen, Neustarten |
| **Niedrig** | ComfyUI aktualisieren |

<Tip>
Um Custom Nodes per Git-URL oder Nightly-Versionen zu installieren, setzen Sie `security_level = weak` in Ihrer `config.ini`.
</Tip>

## Hilfe erhalten

Wenn weiterhin Probleme auftreten:

1. Prüfen Sie die [ComfyUI-Manager GitHub-Probleme](https://github.com/Comfy-Org/ComfyUI-Manager/issues) auf ähnliche Fälle.
2. Sehen Sie sich die Startprotokollmeldungen an, um Details zu Fehlern zu erhalten.
3. Treten Sie dem [ComfyUI Discord](https://discord.com/invite/comfyorg) bei, um Support aus der Community zu erhalten.
