## Konfigurationspfade

Ab V3.38 verwendet der Manager einen geschützten Systempfad für erhöhte Sicherheit.

| ComfyUI-Version | Manager-Pfad |
|-----------------|--------------|
| v0.3.76+ (mit System User API) | `<USER_DIRECTORY>/__manager/` |
| Ältere Versionen | `<USER_DIRECTORY>/default/ComfyUI-Manager/` |

<Note>
Wenn Sie den Manager ohne Optionen ausführen, ist der Pfad `<USER_DIRECTORY>` standardmäßig `ComfyUI/user`. Er lässt sich mit `--user-directory <USER_DIRECTORY>` festlegen.
</Note>

### Konfigurationsdateien

| Datei | Beschreibung |
|------|-------------|
| `config.ini` | Grundlegende Konfiguration |
| `channels.list` | Konfigurierbare Kanallisten |
| `pip_overrides.json` | Benutzerdefinierte pip-Paketzuordnungen |
| `pip_blacklist.list` | Pakete, deren Installation verhindert wird |
| `pip_auto_fix.list` | Pakete, die automatisch wiederhergestellt werden |
| `snapshots/` | Gespeicherte Snapshot-Dateien |
| `startup-scripts/` | Startup-Skript-Dateien |
| `components/` | Komponentendateien |

## Optionen in config.ini

Ändern Sie die Datei `config.ini`, um Einstellungen anzuwenden. Der Pfad wird in den Protokollmeldungen beim Start angezeigt.

```ini
[default]
git_exe = <path to git executable>
use_uv = <True/False - use uv instead of pip>
default_cache_as_channel_url = <True/False - retrieve DB designated as channel_url at startup>
bypass_ssl = <True/False - disable SSL if errors occur>
file_logging = <True/False - create log file>
windows_selector_event_loop_policy = <True/False - fix event loop errors on Windows>
model_download_by_agent = <True/False - use agent for model downloads>
downgrade_blacklist = <comma-separated list of packages to prevent downgrades>
security_level = <strong|normal|normal-|weak>
always_lazy_install = <True/False - perform dependency installation on restart>
network_mode = <public|private|offline>
```

### Netzwerkmodi

| Modus | Beschreibung |
|------|-------------|
| `public` | Standardmäßige öffentliche Netzwerkumgebung |
| `private` | Geschlossenes Netzwerk mit privater Node-DB, konfiguriert über `channel_url` (nutzt den Cache, falls verfügbar) |
| `offline` | Keine externen Verbindungen (nutzt den Cache, falls verfügbar) |

### Sicherheitsstufen

| Stufe | Beschreibung |
|-------|-------------|
| `strong` | Erlaubt keine risikoreichen Funktionen der hohen und mittleren Stufe |
| `normal` | Erlaubt keine risikoreichen Funktionen der hohen Stufe; Funktionen der mittleren Stufe sind verfügbar |
| `normal-` | Erlaubt keine risikoreichen Funktionen der hohen Stufe, wenn `--listen` angegeben ist und nicht mit `127.` beginnt; Funktionen der mittleren Stufe sind verfügbar |
| `weak` | Alle Funktionen verfügbar |

#### Risikostufen für Funktionen

| Risikostufe | Funktionen |
|------------|----------|
| **Hoch** | Installation per Git-URL, pip install, Installation von Custom Nodes außerhalb des Standardkanals, Custom Nodes reparieren |
| **Mittel** | Deinstallieren/Aktualisieren, Installation von Custom Nodes im Standardkanal, Snapshot wiederherstellen/entfernen, Neustarten |
| **Niedrig** | ComfyUI aktualisieren |

## Environment variables

| Variable | Description |
|----------|-------------|
| `COMFYUI_PATH` | Installation path of ComfyUI |
| `GITHUB_ENDPOINT` | Reverse proxy for GitHub access |
| `HF_ENDPOINT` | Reverse proxy for Hugging Face access |

### Examples

Redirecting GitHub requests through a proxy:
```bash
GITHUB_ENDPOINT=https://mirror.ghproxy.com/https://github.com
```

Changing Hugging Face endpoint:
```bash
HF_ENDPOINT=https://some-hf-mirror.com
```

## Erweiterte Konfiguration

### Downgrade bestimmter Pakete verhindern

Listen Sie die Paketnamen im Abschnitt `downgrade_blacklist` der Datei `config.ini` auf, getrennt durch Kommas:

```ini
downgrade_blacklist = diffusers, kornia
```

### Benutzerdefiniertes pip-Mapping

Erstellen Sie eine Datei `pip_overrides.json`, um die Installation bestimmter pip-Pakete durch benutzerdefinierte Installationen zu ersetzen. Informationen zum Format finden Sie in `pip_overrides.json.template`.

### Installation bestimmter pip-Pakete verhindern

Listen Sie die Paketnamen jeweils in einer eigenen Zeile in der Datei `pip_blacklist.list` auf.

### pip-Installation automatisch wiederherstellen

Listen Sie die pip-Spezifikationsanforderungen in `pip_auto_fix.list` auf (ähnlich wie `requirements.txt`). Die angegebenen Versionen werden automatisch wiederhergestellt, wenn ComfyUI gestartet wird oder wenn die Versionen während der Installation von Custom Nodes nicht übereinstimmen. `--index-url` kann verwendet werden.

### aria2 als Downloader verwenden

Für schnellere Downloads können Sie ComfyUI-Manager so konfigurieren, dass aria2 verwendet wird. Siehe die [aria2-Einrichtungsanleitung](https://github.com/Comfy-Org/ComfyUI-Manager/blob/main/docs/en/use_aria2.md).

## extra_model_paths.yaml konfigurieren

Die folgenden Einstellungen werden anhand des als `is_default` markierten Abschnitts angewendet:

- `custom_nodes`: Pfad zum Installieren von Custom Nodes
- `download_model_base`: Pfad zum Herunterladen von Modellen

## CLI-Werkzeuge

ComfyUI-Manager stellt `cm-cli` bereit, ein Befehlszeilenwerkzeug, mit dem Sie Manager-Funktionen nutzen können, ohne ComfyUI auszuführen. Dies ist nützlich, um die Installation von Custom Nodes zu automatisieren und Installationen in Headless-Umgebungen zu verwalten.

Eine ausführliche Dokumentation zu cm-cli finden Sie im [offiziellen cm-cli-Leitfaden](https://github.com/Comfy-Org/ComfyUI-Manager/blob/main/docs/en/cm-cli.md).

Für eine umfassendere Nutzung der CLI können Sie [comfy-cli](/comfy-cli/getting-started) in Betracht ziehen.
