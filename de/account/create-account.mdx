Ihr Comfy-Konto gibt Ihnen Zugriff auf [Partner-Nodes (Partner Node)](/de/tutorials/partner-nodes/overview) und [Cloud-Abonnements](https://www.comfy.org/cloud), sodass Sie Premium-Funktionen und -Dienste auf der gesamten ComfyUI-Plattform nutzen können.

## Comfy-Konto in Comfy Cloud erstellen

Sie können ein Comfy-Konto für ComfyUI direkt in Comfy Cloud erstellen:

1. Rufen Sie [Comfy Cloud](https://www.comfy.org) auf
2. Klicken Sie auf **Registrieren** oder **Konto erstellen**
3. Wählen Sie eine der folgenden Anmeldemethoden:
   - **E-Mail**: Geben Sie Ihre E-Mail-Adresse ein und legen Sie ein Passwort fest
   - **Google**: Registrieren Sie sich mit Ihrem Google-Konto
   - **GitHub**: Registrieren Sie sich mit Ihrem GitHub-Konto
4. Schließen Sie die Registrierung ab
5. Bestätigen Sie Ihre E-Mail-Adresse, wenn Sie sich per E-Mail registriert haben

## Comfy-Konto lokal erstellen

Wenn Sie ComfyUI lokal installiert haben, können Sie ein Comfy-Konto über die Anwendung erstellen:

1. Öffnen Sie ComfyUI auf Ihrem lokalen Rechner
2. Wechseln Sie in der Oberfläche zu **Einstellungen**
3. Öffnen Sie den Bereich **Benutzer** (Details finden Sie unter [Benutzereinstellungen](/de/interface/user))
4. Klicken Sie auf **Konto erstellen** oder **Registrieren**
5. Wählen Sie eine der folgenden Anmeldemethoden:
   - **E-Mail**: Geben Sie Ihre E-Mail-Adresse ein und legen Sie ein Passwort fest
   - **Google**: Registrieren Sie sich mit Ihrem Google-Konto
   - **GitHub**: Registrieren Sie sich mit Ihrem GitHub-Konto
6. Schließen Sie die Registrierung ab

![Oberfläche der Benutzereinstellungen](/images/interface/setting/user.jpg)

## Nächste Schritte

Sobald Ihr Konto erstellt und bestätigt ist:
- [Melden Sie sich bei Ihrem Konto an](/de/account/login)
- Richten Sie Ihre Profileinstellungen ein
- Nutzen Sie die Funktionen von ComfyUI
- Entdecken Sie Tutorials und Dokumentation

## Fehlerbehebung

Wenn bei der Kontoerstellung Probleme auftreten:
- Stellen Sie sicher, dass Ihre E-Mail-Adresse gültig und noch nicht registriert ist
- Prüfen Sie, ob Ihr Passwort die Mindestanforderungen erfüllt
- Leeren Sie den Browser-Cache und versuchen Sie es erneut
- Wenden Sie sich an den [Support](/de/support/contact-support), wenn die Probleme weiterhin bestehen
