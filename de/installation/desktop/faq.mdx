## Allgemeine Fragen

<Accordion title="Worin unterscheidet sich Comfy Desktop von Legacy Desktop?">
Comfy Desktop ist eine vollständige Neuentwicklung und fungiert als **Multi-Installations-Manager**. Anders als Legacy Desktop, eine Anwendung mit nur einer Installation, können Sie mit Comfy Desktop mehrere ComfyUI-Versionen parallel installieren, verwalten und ausführen. Außerdem bietet es Snapshots und die Verwaltung von Modell-Downloads.

Wenn Sie Legacy Desktop verwendet haben, finden Sie im [Migrationsleitfaden](/de/installation/desktop/usage/migrate), wie Sie Ihre bestehende Einrichtung übertragen.
</Accordion>
<Accordion title="Ist Comfy Desktop Open Source?">
Ja. Die Quelle ist auf [GitHub](https://github.com/Comfy-Org/Comfy-Desktop) verfügbar. Comfy Desktop ist dual-lizenziert: [AGPL-3.0-or-later](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/LICENSE) oder eine kommerzielle Lizenz von Comfy Org (`licensing@comfy.org`).
</Accordion>
<Accordion title="Ersetzt Comfy Desktop die Portable- bzw. manuelle Installation?">
Comfy Desktop ist eine von mehreren Installationsoptionen. Je nach Bedarf können Sie weiterhin die **Portable (Windows)**-Installation, die **manuelle Installation** oder **Comfy Cloud** verwenden. Für die meisten Nutzer ist Desktop aufgrund der einfachen Bedienung und Funktionen wie Updates mit einem Klick und Snapshot-Verwaltung empfohlen.
</Accordion>
<Accordion title="Kann ich die Update-Prüfung deaktivieren?">
Nein. Comfy Desktop prüft kurz nach dem Start und dann alle 10 Minuten auf eine neue Version, und diese Prüfung lässt sich nicht abschalten. Die einzige Update-Einstellung ist **Desktop-Updates automatisch installieren** unter **Desktop-Einstellungen → Updates**, und sie ist standardmäßig aktiv.

- **Ein**: Eine neue Version wird im Hintergrund heruntergeladen und ohne Nachfrage installiert. Während des Downloads zeigt die Titelleiste **Update wird heruntergeladen…**, danach, sobald das Update bereitsteht, **Desktop-Update bereit**.
- **Aus**: Die Titelleiste zeigt **Desktop-Update** und die Updates-Karte zeigt **Update … verfügbar**. Das Update wird weiterhin im Hintergrund heruntergeladen, aber es wird nichts von selbst installiert. Es wird weder beim Beenden noch beim nächsten Start angewendet. Sobald es bereit ist, klicken Sie auf die Schaltfläche **Desktop-Update bereit** und wählen Sie **Neustarten & Aktualisieren**.

Die ComfyUI-Version innerhalb einer Instanz wird separat aktualisiert. Verwenden Sie die Registerkarte **Update** der Instanz und wählen Sie dort den Kanal **Stable** oder **Latest on GitHub**.

Unter Linux gilt der In-App-Updater nicht für `.deb`-Installationen. Laden Sie das neue Paket über den [universellen Download-Link](https://dl.todesktop.com/241130tqe9q3y) herunter und installieren Sie es mit `sudo apt install ./*.deb`.
</Accordion>

## Installation und Einrichtung

<Accordion title="Was sind die Systemanforderungen?">
Alle Details finden Sie unter [Systemanforderungen](/de/installation/system_requirements).

- **Windows:** Windows 10+, x64 oder ARM64. Eine dedizierte GPU (NVIDIA / AMD) wird empfohlen, ist aber nicht erforderlich.
- **macOS:** macOS 13+ (Ventura), Apple Silicon (M1+)
- **Linux:** Offizielle `.deb`- und AppImage-Pakete werden über das [Comfy Desktop Repository](https://github.com/Comfy-Org/Comfy-Desktop) verteilt. Eine dedizierte GPU wird empfohlen.
- **Festplatte:** Mindestens 4.85 GB pro Standalone-Installation
- **RAM:** Mindestens 8 GB, 16 GB empfohlen
</Accordion>
<Accordion title="Kann Comfy Desktop ohne Administratorrechte installiert werden?">
Unter **Windows** erfordert die Standalone-Installation keine Administratorrechte. Unter **macOS** benötigen Sie Administratorrechte für die erste systemweite Installation. Unter **Linux** erfordert die Installation des `.deb`-Pakets `sudo`; das AppImage läuft im Benutzerbereich ohne Administratorrechte.
</Accordion>
<Accordion title="Wie lässt sich Comfy Desktop herunterladen?">
Laden Sie die neueste Windows- oder macOS-Version von der offiziellen [ComfyUI-Downloadseite](https://comfy.org/download) herunter. Unter Linux laden Sie das `.deb`-Paket oder das AppImage über den [universellen Download-Link](https://dl.todesktop.com/241130tqe9q3y) aus dem [Comfy Desktop Repository](https://github.com/Comfy-Org/Comfy-Desktop) herunter. Wenn Sie stattdessen aus dem Quellcode starten möchten, lesen Sie die [Linux-Installationsanleitung](/de/installation/desktop/overview#comfy-desktop-für-ihr-betriebssystem-installieren).
</Accordion>
<Accordion title="Können Legacy Desktop und Comfy Desktop parallel installiert werden?">
Ja, beide können parallel existieren. Wir empfehlen jedoch, Ihre Installationen auf das neue Comfy Desktop zu migrieren und Legacy Desktop schließlich zu deinstallieren. Weitere Informationen finden Sie in der [Migrationsanleitung](/de/installation/desktop/usage/migrate).
</Accordion>

## Nutzung

<Accordion title="Wie füge ich eine neue ComfyUI-Installation hinzu?">
Klicken Sie im Dashboard auf **New Instance**, um eine eigenständige Instanz zu erstellen, oder öffnen Sie **New Instance** und wählen Sie **Add Existing Instance**, um einen git clone oder eine Windows-Portable-Installation zu verfolgen. Mit der **Comfy Cloud**-Karte verbinden Sie sich mit Cloud.

- **Standalone**: Neuinstallation mit mitgeliefertem Python
- **Add Existing Instance**: git clone oder Portable-Installation verfolgen
- **Cloud**: Mit Comfy Cloud verbinden
</Accordion>
<Accordion title="Kann ich mehrere ComfyUI-Versionen gleichzeitig ausführen?">
Ja! Comfy Desktop ist genau dafür ausgelegt. Jede Installation läuft in ihrer eigenen isolierten Umgebung mit eigenem Python und eigenen Abhängigkeiten. Sie können sie gleichzeitig in separaten Fenstern starten.
</Accordion>
<Accordion title="Wo werden meine Modelle, Custom Nodes und Einstellungen gespeichert?">
Modelle werden standardmäßig von allen Instanzen gemeinsam genutzt. Gemeinsame Ordner konfigurieren Sie unter [Desktop-Einstellungen → Speicher](/de/installation/desktop/usage/settings#storage).

- **Standalone:** Die Installation selbst liegt in ihrem Installationsordner. Custom Nodes und die Python-Umgebung gelten pro Installation. Modelle stammen in der Regel aus den gemeinsamen Modellverzeichnissen.
- **Git clone / portable (tracked):** Die Daten verbleiben in diesem vorhandenen Ordner (`models/`, `custom_nodes/`, `user/`). Sie können trotzdem weiterhin gemeinsame Modelle, Eingaben und Ausgaben aktivieren.
</Accordion>
<Accordion title="Wie funktionieren Snapshots?">
Comfy Desktop erstellt Snapshots automatisch bei wichtigen Ereignissen: bei jedem Start und Neustart, vor und nach einem Update sowie nach einer Wiederherstellung. Ein Snapshot zeichnet die ComfyUI-Version der Instanz, die Custom Nodes mit ihren Versionen und alle pip-Pakete in der Umgebung auf. Modelldateien, Eingaben und Ausgaben sind nicht Teil eines Snapshots.

Sie können Snapshots im Tab **Snapshots** der Instanz durchsuchen, wiederherstellen, exportieren und teilen. Weitere Informationen finden Sie unter [Snapshots speichern und wiederherstellen](/de/installation/desktop/usage/instance-management#save-and-restore-snapshots).
</Accordion>
### Comfy Desktop stoppen und beenden

So stoppen Sie eine laufende ComfyUI-Instanz (das Python-Backend wird beendet, die App bleibt geöffnet):

1. Klicken Sie auf das **⋮-Menü (Kebab-Menü)** auf der Instanzkarte
2. Wählen Sie **Stop**
3. Bestätigen Sie im Dialog

Dadurch wird der ComfyUI-Python-Prozess beendet, das Fenster der Desktop-App bleibt jedoch geöffnet, sodass Sie jederzeit neu starten können. Um die Desktop-App vollständig zu beenden, öffnen Sie das **☰-Menü** oben links und wählen Sie **Quit Desktop** (oder verwenden Sie den entsprechenden Beenden-Befehl Ihres Betriebssystems). Wenn Sie das letzte Fenster schließen, kehren Sie zum Dashboard zurück, sofern Sie die App nicht beendet haben.

## Fehlerbehebung

<Accordion title="Die App startet nach der Installation nicht">
1. **Windows:** Führen Sie die App einmal als Administrator aus.
2. **macOS:** Wenn eine Sicherheitswarnung angezeigt wird, gehen Sie zu **Systemeinstellungen → Datenschutz & Sicherheit** und klicken Sie auf **Trotzdem öffnen**.
3. **Linux:** Installieren Sie FUSE 2: `libfuse2t64` unter Ubuntu 24.04 und neuer, `libfuse2` unter 22.04.
4. Rufen Sie die neueste Version auf der [Downloadseite](https://comfy.org/download) ab.
</Accordion>
<Accordion title="Comfy Desktop beendet sich nach einem Update von selbst (Windows)">
Unter Windows kann Comfy Desktop 1.0.46 und früher hängen bleiben, wenn ein Update-Download nicht abgeschlossen wurde. Die App zeigt kurz einen Update-Bildschirm und schließt sich dann ohne Fehlermeldung. Das wiederholt sich bei jedem Start, und die App beendet sich, bevor sie die Korrektur herunterladen kann. Version 1.0.47 und später beheben das Problem.

Um das Problem zu beheben, installieren Sie die neueste Version manuell:

1. Laden Sie den [neuesten Windows-Installer](https://dl.todesktop.com/241130tqe9q3y/windows) herunter oder rufen Sie ihn über die [Downloadseite](https://comfy.org/download) ab.
2. Führen Sie das Installationsprogramm aus. Sie müssen die alte Version nicht zuerst deinstallieren.
3. Starten Sie Comfy Desktop.

Ihre Installationen, Modelle und Einstellungen bleiben erhalten.
</Accordion>
<Accordion title="Meine GPU wird nicht erkannt">
- Stellen Sie sicher, dass Ihre NVIDIA-Treiber aktuell sind.
- Prüfen Sie unter Linux, ob das CUDA Toolkit installiert ist.
- Prüfen Sie, ob der Installationstyp GPU unterstützt (Standalone und Git Clone unterstützen GPU; Cloud-Verbindungen verwenden eine Remote-GPU).
</Accordion>
<Accordion title="Eine Installation lässt sich nicht aktualisieren">
- Prüfen Sie Ihre Internetverbindung.
- Erstellen Sie vor dem erneuten Versuch einen manuellen Snapshot im Tab **Snapshots** der Instanz.
- Wenn das Problem weiterhin besteht, stellen Sie einen früheren Snapshot wieder her und versuchen Sie es erneut.
</Accordion>

<Accordion title="Installation oder Update zeigt Operation failed">
Der Fortschrittsbildschirm bleibt geöffnet und zeigt **Operation failed**, die Fehlermeldung und (falls verfügbar) ein automatisch geöffnetes **View logs**-Panel.

- **Reboot** wiederholt denselben Vorgang (**Restart ComfyUI**, wenn ein Start fehlgeschlagen ist).
- **Back** kehrt ohne Nachfrage zum Dashboard zurück und belässt eine fehlgeschlagene Installation auf dem Datenträger.
- Wenn Sie den Bildschirm verlassen, während Schritte noch ausgeführt werden, wird der Vorgang abgebrochen: **Return to Dashboard** fragt nach **Cancel current operation?**. Beim Abbrechen einer Installation wird versucht, den halbfertigen Ordner zu löschen (Dateien können verbleiben, wenn das Löschen fehlschlägt).

Schlägt es weiterhin fehl, prüfen Sie das Netzwerk und sammeln Sie dann `app.log` (und alle `app.log_*.log`) über **Desktop-Einstellungen → Logs → Diagnose → Log-Ordner öffnen**. Bei einer Erstinstallation bietet das Menü möglicherweise nur **Skip Onboarding** an. Wählen Sie zuerst **Back** und öffnen Sie dann die Einstellungen über das Dashboard. Siehe auch [Wie prüfe ich die Startprotokolle von Comfy Desktop?](#wie-prüfe-ich-die-startprotokolle-von-comfy-desktop).
</Accordion>
<Accordion title="Low Disk Space oder Not Enough Space for Template Models wird angezeigt">
Während **New Instance** prüft Comfy Desktop den freien Speicherplatz auf dem Installationslaufwerk. **Low Disk Space** ist eine Warnung: Wählen Sie **Continue Anyway**, um fortzufahren, oder wählen Sie einen anderen Pfad. **Not Enough Space for Template Models** blockiert diese Vorlage; wählen Sie einen leichteren Workflow oder geben Sie Speicherplatz frei. Bei sehr kleinen Datenträgern kann der Vorlagenschritt übersprungen werden. Siehe [Eine neue Instanz erstellen](/de/installation/desktop/usage/instance-management#install-a-new-build).
</Accordion>
<Accordion title="Wie prüfe ich die Startprotokolle von Comfy Desktop?">
Die Desktop-App schreibt eine rotierende Datei `app.log`. Am schnellsten finden Sie sie über **Desktop-Einstellungen → Logs → Diagnose → Log-Ordner öffnen** (☰-Menü oben links).

Standardordner für Logs:

- **Windows:** `%APPDATA%\Comfy Desktop\logs`
- **macOS:** `~/Library/Logs/Comfy Desktop`
- **Linux:** `~/.config/Comfy Desktop/logs`

Suchen Sie nach `app.log`. Vorherige Sitzungen werden in Dateien `app.log_*.log` mit Zeitstempel rotiert.

Für die Prozessausgabe von ComfyUI (nicht die Desktop-App selbst) öffnen Sie das **Manage**-Panel der Instanz und verwenden Sie den Tab **Terminal**. Siehe [Builds verwalten](/de/installation/desktop/usage/instance-management#manage-builds).
</Accordion>
<Accordion title="Kann ich Ollama mit ComfyUI verwenden?">
ComfyUI ist nicht nativ mit [Ollama](https://ollama.ai) für Diffusionsmodell-Backends integriert. Sie können jedoch von Ollama bereitgestellte LLMs über **Custom Nodes** aus der Registry des ComfyUI Manager für die Prompt-Generierung und Textverarbeitung verwenden.

Informationen zum Verbinden von ComfyUI mit LLM-Diensten finden Sie unter [Custom Nodes installieren](/de/installation/install_custom_node).
</Accordion>
<Accordion title="Wie deinstalliere ich Comfy Desktop?">
Comfy Desktop und seine Installationen sind auf dem Datenträger getrennt. So deinstallieren Sie die App und ihre Installationen:

1. **Löschen Sie die Installationen** in der App (Rechtsklick → Entfernen) oder löschen Sie die Installationsordner manuell.
2. **Deinstallieren Sie die App** mit der Standardmethode Ihres Systems (Programme hinzufügen/entfernen unter Windows, in den Papierkorb ziehen unter macOS, Paketmanager unter Linux).

Dadurch werden keine App-Einstellungen, Logs, gemeinsam genutzten Modelle oder Ausgaben gelöscht. Informationen zu zurückbleibenden Ordnern und zur vollständigen Bereinigung finden Sie unter [Windows](/de/installation/desktop/windows#was-das-deinstallieren-der-app-nicht-entfernt), [macOS](/de/installation/desktop/macos#was-beim-deinstallieren-der-app-nicht-entfernt-wird) oder [Linux](/de/installation/desktop/linux#restdaten-entfernen).
</Accordion>
<Accordion title="Kann ich Comfy Desktop im Headless- oder Servermodus ausführen?">
Nein. Comfy Desktop ist als lokale GUI-Anwendung konzipiert und unterstützt keine Headless-, reinen Server- oder Remotebetriebsmodi. Es erfordert eine grafische Desktopumgebung, um ComfyUI-Instanzen zu starten und zu verwalten.

Für Headless- oder Server-Bereitstellungen verwenden Sie stattdessen eine **manuelle ComfyUI-Installation** oder den **Windows Portable**-Build.
</Accordion>
