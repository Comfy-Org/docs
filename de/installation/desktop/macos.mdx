**Comfy Desktop** ist ein Verwaltungsprogramm für mehrere Installationen, mit dem Sie mehrere ComfyUI-Instanzen über einen einzigen Launcher ausführen können. Diese Anleitung beschreibt, wie Sie Comfy Desktop unter macOS installieren und deinstallieren.

## Systemanforderungen

- **Betriebssystem:** macOS 13 (Ventura) oder neuer
- **Hardware:** Apple Silicon (M1 oder neuer)
- **Speicherplatz:** Mindestens 4.85 GB pro Installation empfohlen

<Card title="Comfy Desktop herunterladen" icon="download" href="https://comfy.org/download">
    Laden Sie das neueste Installationsprogramm für macOS herunter. Die Seite erkennt Ihre Plattform automatisch.
</Card>

## Installation

1. Öffnen Sie die heruntergeladene `.dmg`-Datei
2. Ziehen Sie **Comfy Desktop** in den Ordner **Applications**
3. Starten Sie die App über Launchpad oder Spotlight

![Desktop MacOS](/images/desktop/installation/mac_1_install.png)
Beim ersten Start zeigt macOS möglicherweise eine Sicherheitswarnung an. Gehen Sie zu **Systemeinstellungen → Datenschutz & Sicherheit** und klicken Sie auf **Dennoch öffnen**, um die App zuzulassen.

## Deinstallieren

### Comfy Desktop entfernen

1. Öffnen Sie den Ordner **Applications** im Finder
2. Klicken Sie mit der rechten Maustaste auf **Comfy Desktop** und wählen Sie **Move to Trash**

![Comfy Desktop unter macOS deinstallieren](/images/desktop/installation/mac_2_uninstall.png)

### Was beim Deinstallieren der App NICHT entfernt wird

Beim Deinstallieren von Comfy Desktop wird nur die Launcher-App selbst entfernt. Die folgenden Daten werden **nicht** entfernt und müssen manuell gelöscht werden, wenn Sie eine vollständige Bereinigung wünschen:

| Daten | Standardpfad | Beschreibung |
|------|-----------------|-------------|
| Installationen | `~/ComfyUI-Installs` | Jede von Ihnen erstellte ComfyUI-Installation (kann auch innerhalb der App gelöscht werden). Benutzerdefinierte Installationspfade werden ebenfalls nicht entfernt. |
| Gemeinsam genutzte Modelle & Ausgänge | `~/ComfyUI-Shared` | Gemeinsam genutzte Modellbibliothek, Eingabe-/Ausgabeverzeichnisse |
| App-Einstellungen & Registry | `~/Library/Application Support/Comfy Desktop` | Einstellungen und Installationsdatensätze |
| Protokolle | `~/Library/Logs/Comfy Desktop` | Protokolle der Desktop-App (`app.log`) |

<Warning>
  Die oben aufgeführten Verzeichnisse enthalten Ihre **persönlichen ComfyUI-Daten** (Modelle, Ausgänge, Einstellungen und Installationen). Es handelt sich **nicht** um Anwendungsdateien von Comfy Desktop. Wenn Sie sie löschen, werden Ihre Daten dauerhaft entfernt.
</Warning>

So entfernen Sie alles vollständig:

1. **Löschen Sie den App-Datenordner**: `~/Library/Application Support/Comfy Desktop`
2. **Löschen Sie den Protokollordner**: `~/Library/Logs/Comfy Desktop`
3. **Löschen Sie einzelne Installationen** innerhalb der App, oder löschen Sie `~/ComfyUI-Installs` sowie alle benutzerdefinierten Installationsverzeichnisse, die Sie konfiguriert haben, manuell
4. **Löschen Sie die gemeinsam genutzte Modellbibliothek** unter `~/ComfyUI-Shared` (nur wenn Sie diese Dateien nicht mehr benötigen)

## Wenn Comfy Desktop fehlerhaft startet

Ein manuelles Update kann dazu führen, dass Comfy Desktop ohne Styling, mit fehlenden Übersetzungen oder mit Schaltflächen und Dropdown-Menüs startet, die nichts bewirken. Die übliche Ursache ist ein Chromium-Profil oder ein zwischengespeichertes ausstehendes Update, das von der vorherigen Version hinterlassen wurde.

Beenden Sie zuerst Comfy Desktop und führen Sie dann das Skript zum Zurücksetzen aus dem [Comfy-Desktop-Repository](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/scripts/reset-mac.sh) aus:

```bash
curl -fsSLO https://raw.githubusercontent.com/Comfy-Org/Comfy-Desktop/main/scripts/reset-mac.sh && bash reset-mac.sh
```

Das Skript listet jeden Pfad auf, den es löschen will, und fragt vor dem Löschen nach. Es löscht die Einstellungen, Caches und das Chromium-Profil der App für die aktuelle Version und für die früheren App-Namen, sodass ein von einem älteren Build hinterlassenes Profil nicht zurückkehren kann. Es verweigert die Ausführung, solange Comfy Desktop geöffnet ist. Da der Protokollordner einer der Pfade ist, die es löscht, kopieren Sie das Protokoll zuerst an einen anderen Ort, falls Sie das Problem eventuell melden müssen; siehe [Wo das App-Protokoll liegt](#where-the-app-log-is).

Ihre ComfyUI-Installationen in `~/ComfyUI-Installs` und Ihre gemeinsam genutzten Modelle in `~/ComfyUI-Shared` bleiben auf der Festplatte erhalten, aber die Datei, die die Installationen auflistet, wird zusammen mit den übrigen App-Daten gelöscht, daher müssen Sie sie beim nächsten Start möglicherweise mit **Add Existing Instance** erneut hinzufügen. Das Skript meldet außerdem alle zusätzlichen Kopien der App, die es auf dem Mac findet, ohne sie zu löschen, denn eine zweite Kopie im Dock ist ein häufiger Grund dafür, dass ein Zurücksetzen nichts zu ändern scheint.

### Wo das App-Protokoll liegt {#where-the-app-log-is}

Wenn das Zurücksetzen das Problem nicht behebt und Sie es im [Comfy-Desktop-Issue-Tracker](https://github.com/Comfy-Org/Comfy-Desktop/issues) melden möchten, ist die anzuhängende Datei `app.log` in `~/Library/Logs/Comfy Desktop`. Dieser Ordner ist einer der Pfade, die das Zurücksetzen löscht, kopieren Sie ihn daher an einen anderen Ort, bevor Sie das Skript ausführen. Comfy Desktop schreibt bei jedem Start eine neue `app.log` und bewahrt daneben die 50 neuesten früheren Dateien als `app.log_<timestamp>.log` auf, wählen Sie daher die Datei aus der Sitzung, die fehlgeschlagen ist. Jede Datei wird rotiert, sobald sie 5 MB erreicht, sodass sich eine lange Sitzung über mehr als eine Datei erstrecken kann.
