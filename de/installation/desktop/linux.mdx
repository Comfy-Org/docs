**Comfy Desktop** kann unter Linux ausgeführt werden. Offizielle `.deb`-Pakete (Debian/Ubuntu) und AppImage-Pakete werden über das [Comfy Desktop-Repository](https://github.com/Comfy-Org/Comfy-Desktop) bereitgestellt. Laden Sie sie über den [universellen Download-Link](https://dl.todesktop.com/241130tqe9q3y) herunter, der Ihre Plattform automatisch erkennt. Die meisten Benutzer sollten eines dieser Pakete verwenden. Wenn Sie die App stattdessen aus dem Quellcode ausführen möchten, klonen Sie das Repository und befolgen Sie die unten stehenden Schritte.

## Systemanforderungen

- **Betriebssystem:** Linux (Ubuntu 22.04 oder neuer empfohlen)
- **Architektur:** x64
- **Node.js:** v24 LTS oder neuer (nur beim Build aus dem Quellcode)
- **pnpm:** v10 oder neuer, aktiviert mit Corepack (nur beim Build aus dem Quellcode)
- **Build-Tools:** `build-essential` und `git` (nur beim Build aus dem Quellcode)
- **GPU:** Eine dedizierte GPU (NVIDIA / AMD) wird empfohlen, ist aber nicht erforderlich
- **Speicherplatz:** Mindestens 4.85 GB pro ComfyUI-Installation empfohlen

## Offizielles Paket installieren

Laden Sie das Linux-Paket über den [universellen Download-Link](https://dl.todesktop.com/241130tqe9q3y) herunter (er erkennt Ihre Plattform automatisch), und installieren Sie es anschließend:

```bash
sudo apt install ./*.deb
```

Das `.deb`-Paket installiert Comfy Desktop unter `/opt/Comfy Desktop` und fügt während der Installation eine APT-Quelle für das Paket-Repository von Comfy Desktop hinzu, sodass spätere Releases über Ihren System-Paketmanager eintreffen. Weitere Informationen finden Sie unter [Aktualisieren](#aktualisieren).

Wenn AppArmor aktiviert ist und sein Parser das mitgelieferte Profil akzeptiert (Ubuntu 24.04 und später, wo unprivilegierte Benutzer-Namespaces eingeschränkt sind), installiert das Paket außerdem ein AppArmor-Profil für die App unter `/etc/apparmor.d/comfyui-desktop-2`. Die Sandbox von Electron funktioniert auf diesen Systemen daher ohne zusätzliche Flags. Ältere Distributionen überspringen das Profil, weil ihr AppArmor es nicht laden kann; dort funktioniert die Sandbox auch ohne es. Wenn unprivilegierte Benutzer-Namespaces überhaupt nicht funktionieren, markiert das Paket seinen `chrome-sandbox`-Helfer stattdessen als setuid.

So prüfen Sie, ob das Profil installiert wurde:

```bash
ls /etc/apparmor.d/comfyui-desktop-2
```

Die Installationsskripte des Pakets schreiben das Profil, wann immer das Paket installiert oder aktualisiert wird. Wenn Sie das `.deb` unter Ubuntu 22.04 installiert und das System später auf 24.04 aktualisiert haben, führen Sie die Installationsskripte erneut aus:

```bash
sudo apt reinstall comfyui-desktop-2
```

Installieren Sie für das AppImage zuerst FUSE 2. Das AppImage lädt `libfuse.so.2`, das Ubuntu standardmäßig nicht installiert:

- Ubuntu 24.04 und später: `sudo apt install libfuse2t64`
- Ubuntu 22.04: `sudo apt install libfuse2`

Machen Sie es dann ausführbar und führen Sie es aus:

```bash
chmod +x ./*.AppImage
./*.AppImage
```

Das AppImage führt keine Paketinstallationsskripte aus, daher fügt es weder das AppArmor-Profil noch die APT-Quelle hinzu. Beim Start über das App-Menü wird `--no-sandbox` bereits übergeben. Wenn Sie die Datei direkt starten und der Start fehlschlägt, blockiert Ihre Distribution möglicherweise die Sandbox von Electron. Fügen Sie dann das Flag hinzu:

```bash
./*.AppImage --no-sandbox
```

Dieses Flag deaktiviert die Sandbox von Electron für jeden Prozess. Verwenden Sie es daher nur, wenn der Start in der Sandbox fehlschlägt.

## Aus dem Quellcode bauen und starten

Diese Schritte entsprechen dem Abschnitt [Development](https://github.com/Comfy-Org/Comfy-Desktop#development) in der README des Repositorys.

### Voraussetzungen

Installieren Sie zuerst die Build-Tools und git. Eine frische Ubuntu-Installation bringt sie nicht mit, und `pnpm run init` kompiliert native Module wie `node-pty`, was mit `Error: not found: make` fehlschlägt, wenn `build-essential` fehlt:

```bash
sudo apt install build-essential git
```

Installieren Sie dann Node.js 24 und aktivieren Sie pnpm:

```bash
nvm install 24 && nvm use 24
corepack enable
```

Die `.nvmrc` des Repositorys legt die exakte Version fest. Wenn Sie nvm nicht verwenden, installieren Sie stattdessen Node.js 24 von [nodejs.org](https://nodejs.org/).

### Klonen und installieren

```bash
git clone https://github.com/Comfy-Org/Comfy-Desktop.git
cd Comfy-Desktop
pnpm run init
```

`pnpm run init` installiert die Abhängigkeiten und baut das mitgelieferte Bootstrap-Python.

### App starten

```bash
./linux-dev.sh
```

Damit starten Sie Comfy Desktop im Entwicklungsmodus. Das Skript setzt `ELECTRON_DISABLE_SANDBOX=1`, weil Electrons Sandbox in Linux-Entwicklungsumgebungen oft fehlschlägt.

## Aktualisieren

Wie Comfy Desktop aktualisiert wird, hängt davon ab, wie Sie es installiert haben.

### .deb-Installationen

Die Installation des `.deb` fügt außerdem eine APT-Quelle (`/etc/apt/sources.list.d/comfyui-desktop-2.sources`) und einen unattended-upgrades-Eintrag dafür hinzu, sodass neue Versionen mit Ihren normalen System-Updates eintreffen:

```bash
sudo apt update
sudo apt upgrade
```

Sie müssen das `.deb` nicht für jede Version erneut herunterladen. `sudo apt remove comfyui-desktop-2` lässt die APT-Quelle auf dem Datenträger; `sudo apt purge comfyui-desktop-2` entfernt sie zusammen mit dem unattended-upgrades-Eintrag.

### AppImage

Das AppImage aktualisiert sich selbst: Comfy Desktop lädt den neuen Build herunter und ersetzt die `.AppImage`-Datei, die Sie gestartet haben. Bewahren Sie sie deshalb in einem Ordner auf, in den Ihr Benutzerkonto schreiben kann. Liegt die Datei an einem schreibgeschützten Ort, kann das Update sie nicht ersetzen.

### Quellcode-Checkout

Für einen Quellcode-Checkout gibt es kein automatisches Update in der App. Rufen Sie den neuesten Code ab und starten Sie die App erneut:

```bash
git pull
pnpm run init
./linux-dev.sh
```


## Optional: lokales Paket

Um ein lokales `.deb` oder AppImage für Ihren eigenen Bedarf zu erstellen (kein offizieller Download von Comfy Org):

```bash
pnpm run build:linux
```

Die Artefakte landen in `dist/`. Wenn ein AppImage fehlschlägt, weil Chromium keine Sandbox erstellen kann, versuchen Sie es mit `--no-sandbox` erneut. Dieses Flag deaktiviert die Electron-Sandbox für jeden Prozess.

## Restdaten entfernen

Das Entfernen der App und das Entfernen Ihrer Daten sind zwei getrennte Schritte. Deinstallieren Sie zuerst die App:

- **`.deb`**: `sudo apt remove comfyui-desktop-2`. Die Deinstallation löscht außerdem das AppArmor-Profil unter `/etc/apparmor.d/comfyui-desktop-2`. Mit `sudo apt purge comfyui-desktop-2` entfernen Sie zusätzlich die APT-Quelle und den Eintrag für unattended-upgrades.
- **AppImage**: Löschen Sie die Datei `.AppImage`.

Beides berührt Ihre ComfyUI-Installationen und App-Daten nicht. Löschen Sie diese Ordner nur, wenn Sie eine vollständige Bereinigung durchführen möchten:

| Daten | Standardspeicherort | Beschreibung |
|------|-----------------|-------------|
| Installationen | `~/ComfyUI-Installs` | Jede ComfyUI-Installation, die Sie erstellt haben (kann auch in der App gelöscht werden). Benutzerdefinierte Installationspfade werden ebenfalls nicht entfernt. |
| Gemeinsame Modelle & Ausgaben | `~/ComfyUI-Shared` | Gemeinsame Modellbibliothek, Eingabe-/Ausgabeverzeichnisse |
| App-Konfiguration | `~/.config/comfyui-desktop-2` | Einstellungen (`settings.json`) |
| App-Daten | `~/.local/share/comfyui-desktop-2` | Persistente App-Daten, einschließlich der Installationsliste (`installations.json`) |
| Cache | `~/.cache/comfyui-desktop-2` | Download-Cache und andere nicht wesentliche Dateien |
| Zustand | `~/.local/state/comfyui-desktop-2` | Laufzeitzustand wie etwa Port-Sperren |
| Protokolle | `~/.config/Comfy Desktop/logs` (`~/.config/comfyui-desktop-2/logs` bei einem Source-Checkout) | Protokolle der Desktop-App (`app.log`) |

So entfernen Sie alles vollständig:

1. **Löschen Sie den Klon** von `Comfy-Desktop`
2. **Löschen Sie den Konfigurationsordner**: `~/.config/comfyui-desktop-2`
3. **Löschen Sie die Daten-, Cache- und Zustandsordner**: `~/.local/share/comfyui-desktop-2`, `~/.cache/comfyui-desktop-2` und `~/.local/state/comfyui-desktop-2`
4. **Löschen Sie einzelne Installationen** in der App, oder löschen Sie `~/ComfyUI-Installs` sowie alle benutzerdefinierten Installationsverzeichnisse, die Sie konfiguriert haben, manuell
5. **Löschen Sie die gemeinsame Modellbibliothek** unter `~/ComfyUI-Shared` (nur wenn Sie diese Dateien nicht mehr benötigen)

Paketierte Installationen (`.deb` oder AppImage) speichern das App-Profil und die Protokolle zusätzlich in `~/.config/Comfy Desktop`. Um all das zu leeren, führen Sie das Skript [reset-linux.sh](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/scripts/reset-linux.sh) aus dem Repository aus. Es löscht die Konfigurations-, Cache-, Daten- und Zustandsordner der App für den aktuellen Build und für die früheren App-Namen und lässt `~/ComfyUI-Installs` und `~/ComfyUI-Shared` unberührt. Die Installationsliste wird dabei mitgelöscht, daher müssen Sie Ihre Installationen möglicherweise mit **Add Existing Instance** erneut hinzufügen.
