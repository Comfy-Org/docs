**Comfy Desktop** ist ein Manager für mehrere Installationen, mit dem Sie mehrere ComfyUI-Instanzen über einen einzigen Launcher ausführen können. Diese Anleitung erläutert, wie Sie Comfy Desktop unter Windows installieren und deinstallieren.

## Systemanforderungen

- **OS:** Windows 10 oder höher
- **Architektur:** x64 oder ARM64
- **GPU:** Eine dedizierte GPU (NVIDIA / AMD) wird für gute Leistung empfohlen, ist aber nicht erforderlich
- **Speicherplatz:** Mindestens 4.85 GB pro Installation empfohlen

<Card title="Comfy Desktop herunterladen" icon="download" href="https://comfy.org/download">
    Laden Sie das neueste Installationsprogramm für Windows herunter. Die Seite erkennt Ihre Plattform automatisch.
</Card>

## Installation

Führen Sie das heruntergeladene `.exe`-Installationsprogramm (NSIS-Installationsprogramm) aus und folgen Sie den Anweisungen. Starten Sie Comfy Desktop nach der Installation über das Startmenü oder die Desktop-Verknüpfung.

![Windows-Einrichtung](/images/desktop/installation/windows_1_install.png)
Beim ersten Öffnen der App wählt der Einrichtungsbildschirm einen lokalen Build für diesen Computer aus. Welche Einstellungen dabei angezeigt werden, erfahren Sie unter [Einrichtungsbildschirm bestätigen](/de/installation/desktop/overview#einrichtungsbildschirm-bestätigen).

## Deinstallieren

### Comfy Desktop entfernen

1. Öffnen Sie **Settings → Apps → Installed apps**
2. Suchen Sie **Comfy Desktop** und klicken Sie auf **Uninstall**

![Comfy Desktop unter Windows deinstallieren](/images/desktop/installation/windows_2_uninstall.png)

### Was das Deinstallieren der App NICHT entfernt

Beim Deinstallieren von Comfy Desktop wird nur die Launcher-App selbst entfernt. Die folgenden Daten werden **nicht** entfernt und müssen manuell gelöscht werden, wenn Sie eine vollständige Bereinigung wünschen:

| Daten | Standardpfad | Beschreibung |
|------|-----------------|-------------|
| Installationen | `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Installs` | Jede ComfyUI-Installation, die Sie erstellt haben (kann auch innerhalb der App gelöscht werden). Benutzerdefinierte Installationspfade werden ebenfalls nicht entfernt. Ältere Installationen können sich noch in `%USERPROFILE%\ComfyUI-Installs` befinden. |
| Gemeinsame Modelle & Ausgänge | `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared` | Gemeinsame Modellbibliothek, Eingabe- und Ausgabeverzeichnisse. Ältere Installationen verwenden möglicherweise noch `%USERPROFILE%\ComfyUI-Shared`. |
| App-Einstellungen & Registry | `%APPDATA%\Comfy Desktop` | Einstellungen und Installationsdatensätze |
| Protokolle | `%APPDATA%\Comfy Desktop\logs` | Protokolle der Desktop-App (`app.log`) |

<Warning>
  Die oben aufgeführten Verzeichnisse enthalten Ihre **persönlichen ComfyUI-Daten** (Modelle, Ausgaben, Einstellungen und Installationen). Es handelt sich **nicht** um Anwendungsdateien von Comfy Desktop. Wenn Sie diese löschen, werden Ihre Daten dauerhaft entfernt.
</Warning>

So entfernen Sie alles vollständig:

1. **Löschen Sie den Ordner mit den App-Daten**: `%APPDATA%\Comfy Desktop`
2. **Löschen Sie einzelne Installationen** innerhalb der App, oder löschen Sie `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Installs` manuell (oder `%USERPROFILE%\ComfyUI-Installs`, falls die Installationen dort erstellt wurden). Löschen Sie außerdem alle benutzerdefinierten Installationsverzeichnisse, die Sie konfiguriert haben
3. **Löschen Sie die gemeinsame Modellbibliothek** unter `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared` (oder `%USERPROFILE%\ComfyUI-Shared`) nur, wenn Sie diese Dateien nicht mehr benötigen
