Comfy Desktop kann sich mit Ihrem Comfy-Konto verbinden. Die Anmeldung ergänzt den Chooser um Workspace-Funktionen: Wechseln Sie zwischen Ihrem Persönlichen Workspace und jedem Team-Workspace, dem Sie angehören, sehen Sie die Instanzen, die zum ausgewählten Workspace gehören, und installieren Sie ComfyUI Builds, die für ihn veröffentlicht wurden. Sie können außerdem eine lokale Instanz in einen Build umwandeln, den andere Mitglieder des Workspace installieren können.

Die Anmeldung ist optional. Lokale Instanzen, Snapshots und Einstellungen funktionieren ohne Konto.

## Anmelden

Der Account-Chip befindet sich oben rechts im Chooser.

- **Abgemeldet**: Der Chip zeigt die Schaltfläche **Log in**. Klicken Sie darauf, um den Anmeldeablauf im Browser zu öffnen, und kehren Sie anschließend zur App zurück.
- **Angemeldet**: Der Chip zeigt Ihren Avatar und Ihre E-Mail-Adresse. Klicken Sie darauf, um ein Menü mit **Sign out** zu öffnen.

Das Abmelden beendet nur die Sitzung. Ihre Instanzen bleiben bestehen. Wenn eine Installation in Bearbeitung ist, warnt Sie Comfy Desktop, dass das Abmelden sie abbricht, bevor es fortfährt.

## Workspace wechseln

Oberhalb des Rasters der Instances befindet sich eine Workspace-Leiste:

- **Workspace switcher**: Ihr **Persönlich**-Workspace und jeder Team-Workspace, dem Sie angehören. Klicken Sie darauf, um zu wechseln.
- **Refresh workspaces**: erscheint, sobald Sie angemeldet sind. Damit laden Sie die Workspace-Liste und den Builds-Katalog des ausgewählten Workspace neu.
- **INSTANCES**: die Anzahl der Instances, die zum ausgewählten Workspace gehören.

Der ausgewählte Workspace bestimmt den Umfang des Chooser. Das Raster zeigt nur die Instances, die zu ihm gehören, und der New Instance-Ablauf bietet die Builds dieses Workspace an. Comfy Desktop merkt sich den von Ihnen ausgewählten Workspace und stellt ihn beim nächsten Öffnen der App wieder her.

## Einen Build installieren

Ein Build ist eine paketierte ComfyUI-Umgebung, die in einem Workspace veröffentlicht wird. Der Assistent für neue Instanzen zeigt die Release-Version des Builds, den Ersteller, das Hardware-Ziel und eine Schätzung des benötigten Speicherplatzes an. Wenn Sie einen Build installieren, erhalten Sie genau diese Umgebung als lokale Instanz statt einer einfachen ComfyUI-Installation.

1. Klicken Sie im Chooser auf die **+**-Karte, um den Assistenten für neue Instanzen zu öffnen.
2. Wählen Sie in der Methodenzeile **Managed Builds** aus. Wenn Sie noch nicht angemeldet sind, fordert Comfy Desktop Sie auf, sich zuerst anzumelden.
3. Wählen Sie unter **Release** den Build aus, den Sie installieren möchten. Es werden nur Builds aufgeführt, die bereit zur Installation und mit Ihrem Rechner kompatibel sind. Verwenden Sie **View builds online**, um die Seite mit den Builds in Ihrem Browser zu öffnen, oder die Schaltfläche zum Aktualisieren, um die Liste neu zu laden.
4. Wählen Sie unter **Hardware** das Release-Ziel für Ihren Rechner aus, zum Beispiel Windows mit NVIDIA (CUDA 12.8). Das für Ihre Hardware empfohlene Ziel ist bereits vorausgewählt.
5. Fahren Sie im Assistenten fort, um die Instanz zu installieren.

Wenn Sie angemeldet sind, startet der Assistent mit **Managed Builds** und greift auf **Public Builds** zurück, wenn der ausgewählte Workspace keinen kompatiblen Build enthält. **Public Builds** ist die Standardinstallation von ComfyUI für Ihre erkannte Hardware.

## Ein Build aus einer Instanz erstellen

Sie können eine lokale Instanz als Build veröffentlichen, damit andere Mitglieder ihres Workspace sie installieren können.

1. Melden Sie sich bei Ihrem Comfy-Konto an.
2. Öffnen Sie im Chooser das **⋮-Menü** der Instanz und wählen Sie **Create Build**.
3. Comfy Desktop erstellt in der Comfy Developer Platform einen Build-Entwurf aus dieser Instanz. Der Entwurf gehört zu dem Workspace, zu dem die Instanz gehört.

**Create Build** wird für lokale Instanzen angeboten, die installiert sind und einen Installationspfad auf dem Datenträger haben. Für Cloud- oder Remote-Instanzen wird es nicht angeboten. Der Build beginnt als Entwurf, sodass Sie seinen Inhalt prüfen können, bevor Sie ihn freigeben.

Den vollständigen Build-Workflow, einschließlich der Erstellung eines Builds aus einem Desktop-Snapshot oder einer Workflow-JSON-Datei, finden Sie unter [Andere Wege zum Erstellen eines Comfy API Builds](/de/development/serverless/build-sources).
