Die Seite **Assets** in Comfy Desktop zeigt die Dateien, die Ihre Builds und Comfy Cloud generiert haben: Bilder, Video, Audio und 3D-Modelle. Sie zeigt jeweils nur einen Speicherort an, etwa Comfy Cloud oder den Ausgabeordner eines Builds. Um sie zu öffnen, klicken Sie in der **Seitenleiste** auf **Assets**.

<Note>
  Dies ist eine eigene Seite von Comfy Desktop. In einem laufenden ComfyUI ist das Panel **Assets** eine separate Galerie für diesen Build. Weitere Informationen finden Sie unter [Assets in ComfyUI](/de/interface/assets).
</Note>

## Auswählen, wo Sie nachsehen

Mit dem Menü oben links auf der Seite wählen Sie den Ort aus, dessen Dateien Sie sehen. Es enthält zwei Gruppen:

- **Comfy Cloud**: Ihre Ausgänge von Comfy Cloud. Sie müssen angemeldet sein. Das Menü zeigt darunter Ihren Workspace-Namen an.
- **This computer**: **Shared folder**, der gemeinsame Ausgabeordner, den Ihre lokalen Builds standardmäßig verwenden, sowie jeder lokale Build, der in einem eigenen Ausgabeordner speichert. Das Menü zeigt den Pfad jedes Ordners an. Klicken Sie auf die Ordnerschaltfläche neben einem Ort, um ihn im Finder oder Explorer zu öffnen.

Assets listet die Orte in dem Workspace auf, der in der **Seitenleiste** ausgewählt ist. Remote-Builds werden nicht aufgeführt. Wenn **Auto-download outputs** für einen Remote-Build aktiviert ist, erscheinen seine Ausgänge unter dem Ordner, in den sie heruntergeladen werden. Siehe [Ausgabeoptionen für Remote- und Comfy Cloud-Builds festlegen](/de/installation/desktop/usage/instance-management#set-output-options-for-remote-and-comfy-cloud-builds).

## Datei finden

- **Type**: **All**, **Images**, **Videos**, **3D** oder **Audio**.
- **Search by name…**: findet Dateien, deren Name den eingegebenen Text enthält.
- **Refresh assets**: lädt die Liste erneut. Klicken Sie darauf, nachdem ein Build neue Dateien gespeichert hat.

In Comfy Cloud prüft ein Typfilter Ihre neuesten 50.000 Ausgänge in der aktuellen Sortierreihenfolge; die Seite weist unter der Liste darauf hin.

## Ansicht ändern

Klicken Sie auf **View options**, um Folgendes festzulegen:

- **Layout**: **Masonry** oder **Grid**.
- **Sort by**: **Newest first** oder **Oldest first**.
- **Show**: **File name** und **File details** unter jeder Datei.

Comfy Desktop merkt sich diese Optionen. Am unteren Rand der Seite wechseln Sie zwischen den Seiten und wählen Sie, wie viele Dateien eine Seite anzeigt: 50, 100 oder 200.

## Datei in der Vorschau anzeigen

Klicken Sie auf eine Datei, um sie im Viewer zu öffnen. Der Viewer zeigt die Datei groß an, mit ihrem Typ, dem Datum **Erstellt**, der Größe und den Abmessungen. Bei einer Datei auf diesem Computer zeigt er außerdem **Gespeichert in** mit dem Ordner an.

- Drücken Sie die Pfeiltasten nach links und rechts, um zur vorherigen oder nächsten Datei zu wechseln.
- Wählen Sie für ein Bild **Einpassen** oder eine Zoomstufe.
- Ein 3D-Modell bis zu 100 MB wird in einer 3D-Ansicht geöffnet. Bei einem größeren Modell lautet die Meldung im Viewer: **Dieses 3D-Modell kann nicht angezeigt werden. Laden Sie es herunter, um es in einer 3D-App zu öffnen.**
- **Tags** zeigen die Tags der Datei an. Die Tags bearbeiten Sie in ComfyUI.

## Aktionen für eine Datei

Bewegen Sie den Zeiger über eine Datei, um ihre Hauptaktion anzuzeigen. Klicken Sie für die übrigen Aktionen auf **More actions** (**⋯**) oder mit der rechten Maustaste auf die Datei:

| Aktion | Wo | Was sie bewirkt |
| --- | --- | --- |
| **Open** | Bilder, Videos und Audio auf diesem Computer | Öffnet die Datei in der Standard-App. |
| **Show in Finder**, **Show in Explorer** oder **Show in folder** | Dateien auf diesem Computer | Öffnet den Ordner der Datei. Der Name richtet sich nach Ihrem Betriebssystem. |
| **Download** | Comfy Cloud | Speichert eine Kopie auf diesem Computer. Siehe [Herunterladen von Comfy Cloud](#von-comfy-cloud-herunterladen). |
| **Copy** | Bilder | Kopiert das Bild in die Zwischenablage. |
| **Delete** | Dateien auf diesem Computer | Zeigt **Delete {name}?** an und verschiebt die Datei anschließend in den Papierkorb bzw. unter Windows in den Recycle Bin. |

Sie können Aktionen immer nur für eine Datei ausführen. Comfy-Cloud-Dateien können Sie nicht aus Comfy Desktop löschen.

## Den Workflow öffnen, mit dem eine Datei erstellt wurde

Wenn eine Bild-, Video- oder Audiodatei den Workflow enthält, der sie erzeugt hat, zeigt der Viewer **Open workflow** an.

- Bei einer Datei in Comfy Cloud wird der Workflow in Comfy Cloud geöffnet.
- Bei einer Datei auf diesem Computer wird der Workflow in dem Build geöffnet, dessen Ordner die Datei enthält. Wenn mehrere Builds denselben Ordner verwenden, wählen Sie den Build unter **Open in** aus.

Comfy Desktop startet den Build, falls er nicht läuft. Wenn der Workflow nicht geöffnet wird, zeigt die Seite **Couldn't open workflow** an.

## Von Comfy Cloud herunterladen

1. Wählen Sie **Comfy Cloud** im Menü oben links aus.
2. Fahren Sie mit dem Zeiger über eine Datei und klicken Sie dann auf **Download**.
3. Wählen Sie einen Ordner aus. Der Speichern-Dialog öffnet sich in dem Ordner, in dem Sie zuletzt gespeichert haben, oder in Ihrem Downloads-Ordner.

Der Download erscheint im [Downloads](/de/installation/desktop/usage/downloads)-Bereich.

## Wo Dateien gespeichert werden

- **Dieser Computer**: Ausgaben landen im gemeinsamen Ausgabeordner oder im eigenen Ausgabeordner eines Builds. Legen Sie den gemeinsamen Ordner in den [Desktop-Einstellungen](/de/installation/desktop/usage/settings) fest und den Ordner eines Builds auf dessen [Tab „Folders“](/de/installation/desktop/usage/instance-management#choose-which-folders-the-build-uses).
- **Comfy Cloud**: Ausgaben verbleiben in Comfy Cloud, bis Sie sie herunterladen.

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Noch keine Assets">
    Am ausgewählten Ort befinden sich noch keine Dateien. Führen Sie einen Workflow in einem Build oder eine [App](/de/installation/desktop/usage/apps) aus und klicken Sie anschließend auf **Refresh assets**.
  </Accordion>
  <Accordion title="Keine passenden Assets">
    Der Typ oder die Suche blendet jede Datei aus. Wählen Sie **All** oder leeren Sie **Search by name…**.
  </Accordion>
  <Accordion title="Anmelden, um Ihre Assets zu sehen">
    **Comfy Cloud** ist ausgewählt und Sie sind nicht angemeldet. Klicken Sie auf **Log in to Comfy Cloud**.
  </Accordion>
  <Accordion title="Dieser Workspace hat keinen Comfy Cloud Build">
    Der in der **Seitenleiste** ausgewählte Workspace hat keinen Comfy Cloud Build. Starten Sie Comfy Desktop neu, damit Comfy Cloud wieder hinzugefügt wird.
  </Accordion>
  <Accordion title="Assets konnten nicht geladen werden">
    Comfy Desktop konnte die Liste nicht lesen. Prüfen Sie bei Comfy Cloud Ihre Internetverbindung. Klicken Sie anschließend auf **Refresh assets**.
  </Accordion>
</AccordionGroup>
