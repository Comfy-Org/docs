Die Installation von ComfyUI gliedert sich im Wesentlichen in mehrere Schritte:
1. Eine virtuelle Umgebung erstellen (um die Python-Umgebung auf Systemebene nicht zu verunreinigen)
2. Das Code-Repository von ComfyUI klonen
3. Abhängigkeiten installieren
4. ComfyUI starten

Sie können zur Installation von ComfyUI auch die [ComfyUI CLI](/de/comfy-cli/getting-started) verwenden. Sie ist ein Befehlszeilen-Werkzeug, mit dem Sie ComfyUI einfach installieren und seine Abhängigkeiten verwalten können.

## Virtuelle Umgebung erstellen

<Tip>
    Unabhängige virtuelle Umgebungen sind notwendig, da die Abhängigkeiten von ComfyUI mit anderen Abhängigkeiten auf dem System in Konflikt geraten können. Außerdem lässt sich so vermeiden, dass die Python-Umgebung auf Systemebene verunreinigt wird.
</Tip>

<Conda />

## ComfyUI-Code-Repository klonen

Stellen Sie sicher, dass Sie [Git](https://git-scm.com/downloads) auf Ihrem System installiert haben. Öffnen Sie zunächst das Terminal (die Kommandozeile) und klonen Sie anschließend das Code-Repository.
<Tabs>
<Tab title="Windows">
<Warning>Wenn Sie Microsoft Visual C++ Redistributable nicht installiert haben, installieren Sie es bitte [hier.](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)</Warning>
</Tab>
<Tab title="Linux">
Öffnen Sie die Terminal-Anwendung.
</Tab>
<Tab title="MacOS">
Öffnen Sie die [Terminal-Anwendung](https://support.apple.com/guide/terminal/open-or-quit-terminal-apd5265185d-f365-44cb-8b09-71a064a42125/mac).
</Tab>
</Tabs>

```bash
git clone https://github.com/Comfy-Org/ComfyUI.git
```

## ComfyUI aktualisieren

<Steps>
    <Step title="Neuesten Code abrufen">
    Wechseln Sie über die Kommandozeile in das Installationsverzeichnis von ComfyUI und rufen Sie den neuesten Code ab.
    ```bash
    cd <installation path>/ComfyUI
    git pull
    ```
    </Step>
    <Step title="Abhängigkeiten installieren">
    Wechseln Sie über die Kommandozeile in das Installationsverzeichnis von ComfyUI und installieren Sie die Abhängigkeiten.
    <Warning>
    Sie müssen sicherstellen, dass die aktuelle Python-Umgebung die virtuelle Umgebung von ComfyUI ist. Andernfalls werden die Abhängigkeiten in die systemweite Python-Umgebung installiert und verunreinigen diese.
    </Warning>
    ```bash
        pip install -r requirements.txt
    ```
    </Step>
</Steps>
