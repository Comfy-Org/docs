In dieser Anleitung stellen wir Ihnen die Systemanforderungen für die Installation von ComfyUI vor. Da ComfyUI häufig aktualisiert wird, kann dieses Dokument nicht immer zeitnah aktualisiert werden. Beachten Sie die entsprechenden Anweisungen in [ComfyUI](https://github.com/Comfy-Org/ComfyUI).

Unabhängig davon, welche Version von ComfyUI Sie verwenden, läuft es in einer eigenen Python-Umgebung.

### Unterstützte Betriebssysteme

Derzeit unterstützen wir die folgenden Betriebssysteme:
- Windows
- Linux
- macOS (unterstützt Apple Silicon, z. B. die M-Serie)

Die folgenden Links enthalten Installationsanweisungen für Ihr Betriebssystem und Ihr Setup.

### Python-Version

- **Python 3.13** wird sehr gut unterstützt und ist empfohlen
- Python 3.14 funktioniert, aber bei einigen Custom Nodes kann es Probleme geben. Die Free-Threaded-Variante funktioniert, aber einige Abhängigkeiten aktivieren den GIL, daher ist sie nicht vollständig unterstützt
- Python 3.12 ist ein guter Fallback, wenn Sie unter 3.13 Probleme mit den Abhängigkeiten einiger Custom Nodes haben

### Browser-Anforderungen

Für die beste Erfahrung verwenden Sie **Google Chrome Version 143 oder neuer**. Ältere Versionen von Chrome (142 und älter) haben bekannte Probleme, die zu visuellen Fehlern und Leistungsproblemen in ComfyUI führen können.

### Unterstützte Hardware

- **NVIDIA GPU** - Installieren Sie das stabile PyTorch mit CUDA 13.0: `pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130`
- **AMD GPU (Linux)** - ROCm 7.2 Stable oder Nightly
- **AMD GPU (Windows)** - ROCm 10.0 über die Multi-Architektur-PyTorch-Pakete von AMD. Unterstützt RDNA 2, RDNA 3, RDNA 3.5 und RDNA 4; eine separate Installation des HIP SDK ist nicht erforderlich
- **Intel GPU** - Arc-Serie mit nativer PyTorch-Unterstützung für torch.xpu
- **Apple Silicon** - M1/M2/M3/M4-Serie mit Metal-Beschleunigung
- **Ascend NPU** - Über die Erweiterung torch_npu
- **Cambricon MLU** - Über die Erweiterung torch_mlu
- **Iluvatar Corex** - Über die Iluvatar Extension for PyTorch
- **CPU** - Verwenden Sie den Parameter `--cpu` (langsamer)

Detaillierte Installationsschritte finden Sie im Abschnitt zur [manuellen Installation von ComfyUI unter Windows und Linux](https://github.com/Comfy-Org/ComfyUI?tab=readme-ov-file#manual-install-windows-linux).

<Note>
PyTorch 2.7 und höher wird unterstützt, aber die Verwendung einer neueren Version wird dringend empfohlen. Auf Nvidia-Karten der 20er-Serie und neuer ist eine PyTorch-Version mit cu130 oder höher erforderlich. Einige Funktionen und Optimierungen funktionieren möglicherweise nur mit neueren Versionen. Im Allgemeinen empfehlen wir die neueste Hauptversion von PyTorch mit der neuesten CUDA-Version, sofern diese nicht weniger als 2 Wochen alt ist.

Der portable Windows-Build enthält derzeit Python 3.13 und PyTorch CUDA 13.0. Aktualisieren Sie Ihre Nvidia-Treiber, wenn er nicht startet.
</Note>

### Abhängigkeiten

- Installieren Sie PyTorch (Version passend zu Ihrer Hardware)
- Installieren Sie alle Abhängigkeiten aus der requirements.txt von ComfyUI: `pip install -r requirements.txt`

## FAQ

<Accordion title="Unterstützt ComfyUI MLX (Apples Framework für maschinelles Lernen)?">
ComfyUI verwendet MLX nicht direkt. Auf Macs mit Apple Silicon (M1/M2/M3/M4) nutzt ComfyUI PyTorch mit dem **MPS (Metal Performance Shaders)**-Backend, das Apples Metal-Grafikframework für die GPU-Beschleunigung nutzt.

MLX ist ein separates Array-Framework für maschinelles Lernen, das für Apple Silicon entwickelt wurde. Die auf PyTorch basierende Architektur von ComfyUI verwendet stattdessen MPS.

So prüfen Sie, ob MPS auf Ihrem Mac funktioniert:
```bash
python -c "import torch; print(torch.backends.mps.is_available())"
```
</Accordion>
