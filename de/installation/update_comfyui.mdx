Die Aktualisierung von ComfyUI für die verschiedenen Installationsmethoden wird bereits in diversen Abschnitten behandelt. Dieser umfassende Leitfaden fasst jedoch alle Aktualisierungsverfahren zusammen, damit Sie klar nachvollziehen können, wie Sie ComfyUI aktualisieren.

## ComfyUI aktualisieren

<Tabs>
<Tab title="Portable">
 ComfyUI Portable bietet praktische Batch-Skripte für einfache Updates.

 ### Speicherort der Update-Skripte
 Im Ordner `update` in Ihrem Portable-Installationsverzeichnis finden Sie die folgenden Update-Skripte:

 ```
 ComfyUI_windows_portable
 └─ 📂update
    ├── update.py
    ├── update_comfyui.bat                           // Auf die neueste Entwicklungsversion aktualisieren
    ├── update_comfyui_stable.bat                    // Auf die neueste stabile Version aktualisieren
    └── update_comfyui_and_python_dependencies.bat   // ⚠️ GEFAHR: Installiert Abhängigkeiten neu - kann Konflikte verursachen
```
<Warning>
  Stellen Sie während der Aktualisierung eine stabile Internetverbindung sicher.</Warning>

<Warning>
**⚠️ GEFAHR: Verwenden Sie `update_comfyui_and_python_dependencies.bat` mit äußerster Vorsicht!**

Dieses Skript ist gründlicher als reguläre Updates und führt folgende Aktionen aus:
- ✅ Aktualisiert den ComfyUI-Code selbst
- ✅ Aktualisiert PyTorch für das **Standard-Nvidia-Portable** (derzeit **CUDA 13.0 / cu130**, Python 3.13)
- ✅ Installiert ALLE Python-Abhängigkeiten neu

**Legacy Nvidia portable (CUDA 12.6 / cu126):** Wenn Sie das separate Portable-Paket für Nvidia-**10-Serie und ältere GPUs** installiert haben, verwendet dieser Build **CUDA 12.6** und Python 3.12. Betrachten Sie cu130 nicht als das richtige Ziel für dieses Paket. Installieren Sie PyTorch mit dem zu diesem Portable passenden cu126-Wheel-Index neu oder aktualisieren Sie es damit. Alternativ können Sie das cu126-Paket erneut über die [Anleitung zur Portable-Installation](/de/installation/comfyui_portable_windows) herunterladen.

**Risiken:**
- Kann Abhängigkeitskonflikte mit Ihrer bestehenden Umgebung verursachen
- Kann Custom Nodes unbrauchbar machen, die auf bestimmte Paketversionen angewiesen sind
- Kann manuell konfigurierte Pakete überschreiben
- Bei einem cu126-Portable (oder einem anderen Portable außerhalb von cu130) kann das blinde Erzwingen eines cu130-Wheels den GPU-Start verhindern

**⚠️ Verwenden Sie dieses Skript nur, wenn:**
- Sie Abhängigkeitsprobleme beheben müssen
- Sie größere Versionsupdates durchführen
- Verwenden Sie für tägliche Updates stattdessen `update_comfyui.bat`

**Bevor Sie dieses Skript ausführen:**
1. **Sichern Sie Ihre gesamte ComfyUI-Installation**
2. Dokumentieren Sie alle benutzerdefinierten Paketversionen, die Sie installiert haben
3. Bestätigen Sie, welches Portable-Paket Sie besitzen (cu130 Standard vs. cu126 Legacy). Siehe [ComfyUI Portable for Windows](/de/installation/comfyui_portable_windows)
4. Seien Sie darauf vorbereitet, Custom Nodes bei Bedarf neu zu installieren
</Warning>
</Tab>
<Tab title="Desktop">
Um ComfyUI zu aktualisieren, öffnen Sie das [Manage-Panel](/de/installation/desktop/usage/manage#update-tab) und verwenden Sie den Tab Update. Sie können zwischen den Update-Kanälen **Stable** (Standard) und **Latest on GitHub** wählen.

Die Desktop-App selbst aktualisiert sich automatisch und ist von den Updates der ComfyUI-Instanz getrennt.
</Tab>
<Tab title="Manuelle Installation">
Bei einer manuell installierten ComfyUI sind Git-Befehle erforderlich, um Updates durchzuführen.

### Voraussetzungen für das Update
Stellen Sie sicher, dass [Git](https://git-scm.com/downloads) auf Ihrem System installiert ist und dass ComfyUI über einen Git-Clone installiert wurde.

### Update durchführen
<Steps>
<Step title="Virtuelle Umgebung aktivieren">
Aktivieren Sie zunächst die virtuelle Python-Umgebung von ComfyUI (falls Sie eine verwenden):
```bash
# Für die Conda-Umgebung
conda activate comfyui

# Für die venv-Umgebung
# Windows
venv\Scripts\activate
# macOS/Linux  
source venv/bin/activate
```
</Step>
<Step title="Neuesten Code abrufen">
Wechseln Sie in Ihr ComfyUI-Installationsverzeichnis und rufen Sie den neuesten Code ab:
```bash
cd <ComfyUI-installation-path>
git pull
```
</Step>
<Step title="Abhängigkeiten aktualisieren">
Installieren oder aktualisieren Sie die Abhängigkeitspakete von ComfyUI:
```bash
pip install -r requirements.txt
```
<Warning>
Stellen Sie sicher, dass Sie sich in der virtuellen Umgebung von ComfyUI befinden, um eine Verunreinigung der Python-Umgebung auf Systemebene zu vermeiden
</Warning>
</Step>
<Step title="ComfyUI neustarten">
Starten Sie ComfyUI nach dem Update neu:
```bash
python main.py
```
</Step>
</Steps>

### Version wechseln (optional)
Um zu einer bestimmten Version zu wechseln, verwenden Sie diese Befehle:
```bash
# Commit-Verlauf anzeigen
git log --oneline

# Zu einem bestimmten Commit wechseln
git checkout <commit-hash>

# Zur neuesten Version zurückkehren
git checkout master
```
<Tip>
  Regelmäßige Updates werden für die neuesten Funktionen und Sicherheitskorrekturen empfohlen, stabile Versionen hingegen für die Systemstabilität</Tip>

## Was muss beim Aktualisieren von ComfyUI aktualisiert werden?

Ein Update von ComfyUI besteht im Wesentlichen aus zwei Komponenten:
1. Den Kerncode von ComfyUI aktualisieren
2. Die Kernabhängigkeiten von ComfyUI aktualisieren, einschließlich der erforderlichen Python-Abhängigkeiten und der funktionalen Abhängigkeitspakete von ComfyUI

**Kerncode**: Neue Nodes, Unterstützung neuer Modelle, neue Funktionen usw.
**Kernabhängigkeiten**: Umfassen hauptsächlich die Frontend-Funktionalität von ComfyUI, Workflow-Vorlagen, die Node-Hilfedokumentation usw.

```
comfyui-frontend-package   # Frontend-Funktionalität von ComfyUI
comfyui-workflow-templates # Workflow-Vorlagen von ComfyUI  
comfyui-embedded-docs      # Node-Hilfedokumentation von ComfyUI
comfy-kitchen              # Zentrale Dienstprogramme von ComfyUI
comfy-aimdo                # Zentrale Dienstprogramme von ComfyUI
```

Diese Kernabhängigkeiten werden in separaten Repositories gepflegt:
- [ComfyUI_frontend](https://github.com/Comfy-Org/ComfyUI_frontend/) - Frontend-Oberfläche und interaktive Funktionen
- [workflow_templates](https://github.com/Comfy-Org/workflow_templates) - Vorgefertigte Workflow-Vorlagen
- [comfyui-embedded-docs](https://github.com/Comfy-Org/embedded-docs) - Node-Hilfedokumentation
- [comfy-kitchen](https://github.com/Comfy-Org/comfy-kitchen) - Schnelle Kernel-Bibliothek für Diffusion-Inferenz mit mehreren Compute-Backends
- [comfy-aimdo](https://github.com/Comfy-Org/comfy-aimdo) - AI Model Demand Offloading Allocator

Wichtig ist, den Unterschied zwischen Entwicklungsversionen (nightly) und stabilen Versionen (release) zu verstehen:
- **Entwicklungsversion (nightly)**: Code des neuesten Commits, der Ihnen Zugriff auf die neuesten Funktionen bietet, aber potenzielle Probleme enthalten kann
- **Stabile Version (release)**: Basiert auf stabilen Releases, liegt in der Regel hinter den Entwicklungsversionen zurück, bietet aber höhere Stabilität. Wir unterstützen stabile Versionen, sobald Funktionen getestet und stabilisiert sind.

Viele Benutzer stellen bei Updates häufig fest, dass sie sich auf Release-Versionen oder im Standard-Kanal **Stable** von Desktop befinden, benötigte Funktionen aber nur in Entwicklungs-/Nightly-Builds verfügbar sind. Wechseln Sie in **Desktop** unter [Manage → Update](/de/installation/desktop/usage/manage#update-tab) zu **Latest on GitHub**. Bei portablen oder manuellen Installationen prüfen Sie, ob Ihre lokale Datei `ComfyUI/requirements.txt` mit den [Abhängigkeiten der Nightly-Version](https://github.com/Comfy-Org/ComfyUI/blob/master/requirements.txt) übereinstimmt, um festzustellen, ob alle Abhängigkeiten die neuesten Funktionen unterstützen.

## Häufige Probleme beim Aktualisieren

### Fehlendes oder veraltetes Frontend, fehlende Workflow-Vorlagen oder Nodes nach Aktualisierungen

<Tabs><Tab title="Abhängigkeiten nicht korrekt aktualisiert">
    Häufig verwenden Benutzer nur den Befehl `git pull`, um den ComfyUI-Code zu aktualisieren, **vernachlässigen jedoch die Aktualisierung der Kernabhängigkeiten**, was zu folgenden Problemen führt:

  - Fehlende oder fehlerhafte Frontend-Funktionalität
  - Neu hinzugefügte Workflow-Vorlagen werden nicht gefunden
  - Veraltete oder fehlende Hilfe-Dokumentation für Nodes
  - Neue Funktionen haben keine entsprechende Frontend-Unterstützung

  Verwenden Sie nach dem Befehl `git pull` die entsprechende ComfyUI-Umgebung, um mit `pip install -r requirements.txt` die Abhängigkeiten zu aktualisieren.
  </Tab><Tab title="Fehler beim Aktualisieren von Abhängigkeiten">
    Wenn das Aktualisieren von Abhängigkeiten fehlschlägt, liegt das häufig an Netzwerk- oder Berechtigungsproblemen des Computers. Treten während einer Aktualisierung Fehler bei Kernabhängigkeiten auf, greift das System auf ältere Versionen zurück. Üblicherweise sehen Sie beim Start Logs wie diese:
    ```
    Falling back to the default frontend.
    ComfyUI frontend version: xxx
    ```

    Gehen Sie bei der Fehlerbehebung so vor:
    1. Verwenden Sie `pip list` in der passenden Umgebung, um die aktuell installierten Abhängigkeitspakete anzuzeigen. Wenn Sie Versionsinkonsistenzen feststellen, verwenden Sie `pip install -r requirements.txt` in der ComfyUI-Umgebung, um die Aktualisierung der Abhängigkeiten erneut zu versuchen.
    2. Wenn die Probleme nach der Aktualisierung bestehen bleiben, prüfen Sie Ihre Netzwerkverbindung. Nutzer in Festlandchina müssen möglicherweise einen Proxy konfigurieren, um zuverlässig auf GitHub-Repositories zugreifen zu können.
    3. Wenn die Probleme weiterhin auftreten, prüfen Sie die Berechtigungen des Computers. Wenn Administratorrechte erforderlich sind, führen Sie die Befehlszeile mit Administratorrechten aus.
  </Tab>
</Tabs>

### Fehlerbehebung beim Aktualisieren der Kernabhängigkeiten

Wenn das Aktualisieren der Kernabhängigkeiten fehlschlägt, gehen Sie so vor:

<Steps>
  <Step title="Netzwerkverbindung prüfen">
    Wenn Sie sich in Festlandchina befinden, stellen Sie sicher, dass Sie auf PyPI zugreifen können, oder konfigurieren Sie einen inländischen Spiegel:
    ```bash
    # Tsinghua-Universität-Spiegel verwenden
    pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
    ```
  </Step>
  <Step title="Kernpakete einzeln installieren">
    Wenn die Batch-Installation fehlschlägt, versuchen Sie, die Pakete einzeln zu installieren. **Prüfen Sie zuerst die Versionsanforderungen in `ComfyUI/requirements.txt`**:
    
    **Installieren Sie dann gemäß den angegebenen Versionen (verwenden Sie die Versionsnummern aus Ihrer requirements.txt):**
    ```bash
    pip install comfyui-frontend-package==<version> 
    pip install comfyui-workflow-templates==<version>
    pip install comfyui-embedded-docs==<version>
    pip install comfy-kitchen==<version>
    pip install comfy-aimdo==<version>
    ```
    <Warning>
    Es wird empfohlen, die exakten Versionsnummern zu verwenden, die in `ComfyUI/requirements.txt` angegeben sind. Führen Sie kein eigenständiges Upgrade auf die neuesten Versionen durch, da dies zu Kompatibilitätsproblemen führen kann.
    </Warning>
  </Step>
</Steps>

### Warum finde ich nach dem Aktualisieren keine neuen Funktionen?

Das ist eines der häufigsten Probleme:
- Wenn Sie **Desktop** im Update-Kanal **Stable** verwenden, können Funktionen hinter neueren GitHub-Commits zurückliegen. Wechseln Sie im Tab [Manage → Update](/de/installation/desktop/usage/manage#update-tab) den Kanal zu **Latest on GitHub**, wenn Sie neuere Funktionen benötigen (Latest kann weniger stabil sein).
- Bei Portable- oder manuellen Installationen stellen Sie sicher, dass Sie die **Entwicklungsversion (Nightly)** und nicht die **stabile Version (Release)** verwenden, wenn Sie die neuesten Commits benötigen.

Stellen Sie außerdem sicher, dass die entsprechenden Abhängigkeiten während des Aktualisierungsvorgangs erfolgreich aktualisiert wurden. Wenn die Probleme nach der Aktualisierung weiterhin bestehen, lesen Sie den Abschnitt [Fehlerbehebung beim Aktualisieren der Kernabhängigkeiten](#fehlerbehebung-beim-aktualisieren-der-kernabhängigkeiten), um die Probleme zu diagnostizieren.

### Zwischen Entwicklungsversion (Nightly) und stabiler Version (Release) wechseln

Unterschiede zwischen den Versionen:

<Tabs>
  <Tab title="Entwicklungsversion (Nightly)">
    - **Merkmale**: Enthält den neuesten Commit-Code
    - **Vorteile**: Neue Funktionen und Verbesserungen zuerst erleben
    - **Risiken**: Kann unentdeckte Bugs oder instabile Faktoren enthalten
    - **Geeignet für**: Entwickler, Tester und Nutzer, die die neuesten Funktionen ausprobieren möchten
  </Tab>
  <Tab title="Stabile Version (Release)">
    - **Merkmale**: Getesteter und verifizierter stabiler Code
    - **Vorteile**: Hohe Stabilität, geeignet für Produktionsumgebungen
    - **Nachteile**: Funktionsupdates sind verzögert, können Wochen oder Monate hinter Entwicklungsversionen zurückliegen
    - **Geeignet für**: Nutzer, die Stabilität benötigen, sowie Nutzer in Produktionsumgebungen
  </Tab>
</Tabs>

<Tabs>
  <Tab title="Portable">
    Verwenden Sie `update_comfyui.bat` anstelle von `update_comfyui_stable.bat`:
    ```
    # Development version (latest features)
    double-click: update_comfyui.bat
    
    # Stable version
    double-click: update_comfyui_stable.bat
    ```
  </Tab>
  <Tab title="Manuelle Installation">
    ```bash
    # Zur Entwicklungsversion wechseln
    git checkout master
    git pull
    
    # Zur neuesten stabilen Version wechseln
    git fetch --tags
    git checkout $(git describe --tags `git rev-list --tags --max-count=1`)
    ```
  </Tab>
  <Tab title="Desktop">
    Öffnen Sie das [Manage-Panel](/de/installation/desktop/usage/manage#update-tab) und wechseln Sie im Tab Update den Kanal:
    - **Stable** (Standard): getestete Releases, können hinter neueren GitHub-Commits zurückliegen
    - **Latest on GitHub**: folgt neueren Commits auf GitHub; kann weniger stabil sein

    Verwenden Sie **Switch Channel**, **Update Now** oder **Copy & Update**, je nachdem, ob der ausgewählte Kanal einen neueren Build hat. Details finden Sie auf der Seite [Manage-Update-Tab](/de/installation/desktop/usage/manage#update-tab).
  </Tab>
</Tabs>

### Was tun, wenn nach dem Aktualisieren Fehler auftreten?

1. **Abhängigkeiten prüfen**: Führen Sie `pip install -r requirements.txt` aus, um sicherzustellen, dass alle Abhängigkeiten aktualisiert sind
2. **Custom Nodes prüfen**: Einige Custom Nodes sind möglicherweise mit neuen Versionen nicht kompatibel
3. **Version zurücksetzen**: Bei schwerwiegenden Problemen können Sie auf eine vorherige stabile Version zurückkehren

Wenn Probleme auftreten, finden Sie Lösungen auf unserer Seite zur Fehlerbehebung.
