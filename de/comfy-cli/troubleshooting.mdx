Die meisten Fehler in der Comfy CLI entstehen durch eine fehlende Voraussetzung oder einen übersprungenen Einrichtungsschritt. Prüfen Sie die folgenden Punkte, bevor Sie ein Problem melden.

## Voraussetzungen

Comfy CLI benötigt [git](https://git-scm.com/downloads), das auf Ihrem System installiert ist. Installieren Sie es zuerst, damit `comfy install` und `comfy update` ComfyUI und die zugehörigen Custom Nodes klonen können.

## ComfyUI in einer virtuellen Umgebung installieren

`comfy install` installiert ComfyUI in die aktive Python-Umgebung, die Python 3.10 oder neuer sein muss. Erstellen und aktivieren Sie eine virtuelle Umgebung, bevor Sie den Befehl ausführen:

```bash
python3 -m venv comfy-env
source comfy-env/bin/activate
comfy install
```

## Die zu Ihrer GPU passende PyTorch-Version installieren

`comfy install` fragt, welche GPU Sie haben, und installiert die passende PyTorch-Version. Beantworten Sie die Frage, oder übergeben Sie ein GPU-Flag, damit der Befehl unbeaufsichtigt läuft:

| Plattform | Was `comfy install` installiert | Was Sie noch benötigen |
| --- | --- | --- |
| NVIDIA | PyTorch mit CUDA-Runtime (pip-Wheel) | Aktueller GPU-Treiber (nicht das vollständige CUDA Toolkit) |
| AMD Linux | ROCm-PyTorch-Wheels | ROCm-fähiger AMD-GPU-Treiber/Stack für diese Wheels |
| AMD Windows | `torch-directml` | ComfyUI unterstützt DirectML nicht mehr. Installieren Sie stattdessen die ROCm-PyTorch-Version; sie erfordert eine AMD-GPU der RDNA-2-Generation oder neuer (siehe [Systemanforderungen](/de/installation/system_requirements)) |
| Apple silicon | PyTorch-Nightly-Wheels (CPU-Index; Metal/MPS) | macOS auf Apple Silicon |
| Intel Arc | PyTorch-XPU-Wheels | Kompatible Intel Arc GPU / XPU-Stack |
| CPU | CPU-PyTorch-Wheels | Keine dedizierte GPU erforderlich |

```bash
comfy install --nvidia
```

Übergeben Sie `--skip-torch-or-directml`, wenn Sie PyTorch selbst installieren. `comfy env` zeigt die Python-Umgebung und den Workspace an, die ComfyUI verwendet.

## Comfy Cloud ohne Browser einrichten

`comfy setup` meldet sich über Ihren Browser an und kann daher in CI, einem Devcontainer oder auf einem Headless-Server nicht abgeschlossen werden. Übergeben Sie stattdessen einen API-Schlüssel und führen Sie den Befehl nicht-interaktiv aus:

```bash
comfy setup --where cloud --api-key comfyui-... --non-interactive
```
