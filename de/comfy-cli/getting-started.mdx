## Überblick

`comfy-cli` ist ein [Kommandozeilen-Werkzeug](https://github.com/Comfy-Org/comfy-cli), das die Installation und Verwaltung von Comfy vereinfacht und Ihnen skriptbasierten Zugriff mit einem einzigen Befehl auf das gesamte ComfyUI-Ökosystem ermöglicht, lokal oder in der Cloud.

Es erfüllt drei Hauptfunktionen:

1. **Eine lokale ComfyUI-Installation verwalten**: ComfyUI und Custom Nodes installieren, starten, aktualisieren, als Snapshot sichern und bisecten.
2. **Auf gehostete Partner-Nodes zugreifen**: Bilder, Video, Audio und 3D von Anbietern wie Seedance, Nano Banana (Gemini), Grok, Flux, Ideogram, DALL·E, Recraft, Stability, Kling, Luma, Runway, Pika, Vidu, Hailuo, Moonvalley und anderen mit einzelnen Befehlen generieren.
3. **Vollständige Workflows auf Comfy Cloud ausführen**: Workflow-Graphen absenden, die kuratierte Vorlagen-Galerie durchsuchen, Workflows per Slot bearbeiten und Aufträge bis zum Abschluss beobachten, ohne lokale GPU.

## Workflows ausführen {#comfy run}

Über einzelne Partner-Aufrufe hinaus sendet `comfy run` einen vollständigen ComfyUI-Workflow-Graphen ab. Der Befehl akzeptiert sowohl JSON im API-Format als auch exportiertes JSON im UI-Format (UI-Workflows werden clientseitig in das API-Format umgewandelt) und leitet wie jeder andere Befehl an lokal oder Cloud weiter. Er ist **standardmäßig asynchron**. Er gibt in Millisekunden eine `prompt_id` zurück, während ein Hintergrund-Watcher den Fortschritt verfolgt. Mit `--wait` blockiert der Befehl stattdessen.

```bash
# Absenden; kehrt sofort mit einer prompt_id zurück
RES=$(comfy --json run --workflow my_workflow.json)
PROMPT_ID=$(echo "$RES" | jq -r .data.prompt_id)

# Bis zum Endzustand beobachten, dann Ausgänge einsammeln
comfy --json jobs watch "$PROMPT_ID" | comfy download
```

Sie bevorzugen einen einzelnen blockierenden Aufruf? Verwenden Sie `--wait`:

```bash
comfy run --workflow my_workflow.json --wait | comfy download
```

Aufgaben verfolgen und verwalten:

```bash
comfy jobs ls                 # lokale asynchrone Absendungen + Warteschlange/Verlauf des Servers
comfy jobs status <prompt_id> # eine Aufgabe
comfy jobs wait <id1> <id2>   # blockieren, bis ALLE einen Endzustand erreichen
comfy jobs cancel <prompt_id> # idempotent
```

<Tip>
  Validieren Sie, bevor Sie absenden. So erkennen Sie unbekannte Nodes, fehlende Modelle und fehlerhafte Verbindungen, bevor Sie Cloud-Compute verbrauchen:

  ```bash
  comfy validate --workflow my_workflow.json
  ```
</Tip>

## Mit einer Vorlage starten

Die kuratierte Galerie `Comfy-Org/workflow_templates` ist der schnellste Weg, um einen bewährten Workflow für eine bestimmte Aufgabe zu erhalten. Sie müssen nicht von Grund auf neu beginnen.

```bash
comfy templates ls --type image --tag "Text to Image"   # Durchsuchen
comfy templates show <name>                              # Vollständige Metadaten
comfy templates fetch <name> --out my.json               # Workflow-JSON abrufen
```

Das heruntergeladene JSON liegt im Frontend-Format vor. `comfy run --where cloud` konvertiert es beim Absenden automatisch in das API-Format.

## Workflows direkt bearbeiten {#edit-workflows-in-place}

`comfy workflow` legt die agentenanpassbaren Slots in jedem Workflow im Frontend-Format offen und ermöglicht es Ihnen, sie zu überschreiben. Kein manuelles Bearbeiten der JSON-Datei.

```bash
comfy workflow slots my.json                 # adressierbare Slots auflisten
comfy workflow set-slot my.json 6.text="a fox in the snow"
comfy workflow vary my.json \
    --slot positive.text='["a cat","a dog","a fox"]' \
    --out-dir ./variants                     # N Varianten erzeugen
```

Gespeicherte Workflows auf Comfy Cloud:

```bash
comfy workflow list                          # Ihre gespeicherten Workflows
comfy workflow get <id> --out my.json
comfy workflow save my.json --name "My Flow"
comfy workflow delete <id>
```

Für komplexe mehrstufige Pipelines können Sie kleine, wiederverwendbare Fragmente zu einem Graphen zusammensetzen:

```bash
comfy workflow compose blueprints/my_pipeline.yaml -o workflows/my_pipeline.json
comfy workflow decompose my.json             # umgekehrt: einen Workflow in ein Fragment projizieren
```


## Nodes und Modelle entdecken

Untersuchen Sie alles, was auf dem aufgelösten Backend verfügbar ist.

**Nodes:**

```bash
comfy nodes search "checkpoint"              # unscharfe Suche
comfy nodes show KSampler                    # vollständiges Schema: Eingänge, Ausgänge, Standardwerte
comfy nodes ls --produces IMAGE --limit 10   # nach Ausgabetyp filtern
comfy nodes ls --api-only                    # nur Partner-API-Nodes
```

**Modelle:**

```bash
comfy models list-folders                    # alle Modellordner
comfy models search --text "wan2.2" --type lora
comfy models show wan2.2_vae.safetensors     # vollständige Metadaten
```


## Dateien hochladen und herunterladen

```bash
comfy upload photo.png video.mp4             # → Eingabeverzeichnis des Servers
comfy download <prompt_id>                   # → ./outputs/
```

<Tip>
  **Die idiomatische Pipe:**

  ```bash
  comfy run --workflow flux.json --wait | comfy download
  ```

  `comfy download` liest die prompt_id und die Ausgabe-URLs automatisch aus der per Pipe übergebenen Standardeingabe. Kein manuelles Extrahieren von Schlüsseln, kein `jq`.
</Tip>

## JSON-Ausgabe für Skripte und Agenten

Jeder Befehl akzeptiert `--json` und gibt dieselbe Hüllstruktur aus, wodurch die CLI vollständig skriptbar und agentenfreundlich ist:

```json
{
  "ok": true,
  "command": "...",
  "version": "1.11.1",
  "where": "local | cloud | null",
  "data": { },
  "error": null
}
```

Wenn `error` vorhanden ist, lesen Sie `hint` und reagieren Sie entsprechend:

```bash
comfy --json run --workflow my.json | jq '.error.hint'
```

Die für Agenten ausgelegte Oberfläche ist vollständig selbsterklärend. Geben Sie den gesamten Befehlsbaum, die Ausgabeschemata und die Fehlercodes aus:

```bash
comfy --json discover
```

## Analytics

Die Nutzungsverfolgung hilft, die CLI zu verbessern. Sie können sie deaktivieren mit:

```bash
comfy tracking disable
```

Nutzungsverfolgung wieder aktivieren:

```bash
comfy tracking enable
```

Sie können die Nutzungsverfolgung auch dauerhaft über die Umgebungsvariablen `DO_NOT_TRACK` oder `COMFY_NO_TELEMETRY` abwählen.
