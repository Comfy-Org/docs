Ein Comfy Cloud Node ist ein regulärer ComfyUI-Node, der seinen Job auf den GPUs von Comfy ausführen lässt statt auf der lokalen Maschine. Fügen Sie ihn wie jeden anderen Node in einen Graphen ein. Ein Abonnement ist nicht erforderlich: Ein Konto und Credits genügen, genau wie bei jedem anderen Partner-Node.

<Note>
Comfy Cloud Nodes führen Open-Source-Modelle in der Cloud aus. Nicht zu verwechseln mit Partner-Nodes.
</Note>

## Was es ist

Jeder Comfy Cloud Node führt einen festen Workflow mit einer fest angehefteten Modellversion aus, sodass ein gespeicherter Graph über die Zeit dieselben Ergebnisse liefert. Ihr Graph, Ihre Prompts und Ihre Eingaben bleiben auf Ihrer Maschine, abgesehen von dem, was der Node zum Ausführen des Jobs sendet.

## Erste Schritte

Comfy Cloud Nodes sind in ComfyUI **v0.34.5 oder höher** enthalten. Sie sind Teil des ComfyUI-Kerns, es gibt also nichts separat zu installieren.

<Steps>
  <Step title="ComfyUI aktualisieren">
    Aktualisieren Sie auf v0.34.5 oder höher. Siehe [ComfyUI aktualisieren](/de/installation/update_comfyui) für die portable, die Desktop- und die manuelle Installation.
  </Step>
  <Step title="ComfyUI neustarten">
    Die Nodes werden nur beim Start registriert, daher erscheinen sie erst nach einem Neustart.
  </Step>
  <Step title="Node finden">
    Suchen Sie in der Node-Bibliothek nach **Comfy Cloud** und verbinden Sie einen Node dann wie jeden anderen mit Ihrem Graphen. Jeder Node trägt in seinem Anzeigenamen das Suffix `[BETA]`.
  </Step>
</Steps>

## Verfügbare Nodes

Zum Start acht Nodes, für Bild, Video und Audio:

| Node | Modalität |
| --- | --- |
| Comfy Cloud Flux 2 Text to Image | Bild |
| Comfy Cloud Mage Flow Text to Image | Bild |
| Comfy Cloud Mage Flow Turbo Text to Image | Bild |
| Comfy Cloud Z-Image Turbo Text to Image | Bild |
| Comfy Cloud MiniMax H3 Text to Video | Video |
| Comfy Cloud MiniMax H3 Image to Video | Video |
| Comfy Cloud MiniMax H3 First-Last Frame to Video | Video |
| Comfy Cloud MiniMax Music 3 Text to Audio | Audio |

## Abrechnung

Comfy Cloud Nodes werden pro GPU-Sekunde in Credits abgerechnet, angezeigt am Node, bevor Sie ihn ausführen. Es gibt kein Abonnement und keine monatliche Grundgebühr.

## Einschränkungen

- Noch kein eigenes LoRA oder eigener Checkpoint. Jeder Node bietet einen festen Satz gehosteter Gewichte. Der direkte Upload ist ein geplanter nächster Schritt und in dieser Version nicht verfügbar.
