[**Comfy Skills**](https://github.com/Comfy-Org/comfy-skills) ist die Heimat der Skills und Plugins für Coding-Agents. Skills sind paketiertes Wissen, das ein Agent bei Bedarf lädt: Modell-Guidance, Workflow-Muster und fertige Befehle.

Das Repository beherbergt:

- **Claude Code Plugins**: zum Beispiel **comfy-cloud**, das die Comfy Cloud MCP-Verbindung und die Slash-Befehle `/comfy-cloud:*` mit einer einzigen Installation hinzufügt.
- **Agent-Skills**: gezielte Anweisungen für bestimmte Aufgaben, etwa aktuelle Modell-Empfehlungen und Know-how zum Erstellen von Workflows, die bei Modelländerungen aktuell gehalten werden.
- **Community-Beiträge**: Skills und Plugins aus der Comfy-Community.

So verwenden Sie es in Claude Code:

```
/plugin marketplace add Comfy-Org/comfy-skills
/plugin install comfy-cloud@comfy-skills
```

Die Slash-Befehle des Plugins und Details zur Einrichtung finden Sie unter [Comfy MCP](/de/agent-tools/mcp).
