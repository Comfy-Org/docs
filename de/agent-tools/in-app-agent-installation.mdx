## Ihr Setup wählen

Sie benötigen ein Comfy-Konto.

- **Comfy Cloud:** Comfy Agent ist allgemein verfügbar. [Bei Cloud anmelden](https://cloud.comfy.org): keine lokale Installation und keine Warteliste nötig.
- **Comfy Desktop:** Comfy Agent für lokales ComfyUI ist demnächst verfügbar. [Der Warteliste beitreten](https://links.comfy.org/agentalpha), um benachrichtigt zu werden.

## Ihr erstes Bild erstellen {#make-your-first-image}

### Agent öffnen

Öffnen Sie einen leeren Workflow und wählen Sie dann **Agent** ganz rechts in der Tableiste, neben Ihrem Avatar. Lesen und akzeptieren Sie den Einwilligungshinweis, falls er angezeigt wird. Verwenden Sie **Workflow auswählen** im Agent-Panel, um den leeren Workflow auszuwählen.

### Workflow erstellen

Senden Sie diese Nachricht:

> Erstellen Sie einen Text zu Bild Workflow für einen roten Sneaker auf einem neutralen grauen Hintergrund. Verwenden Sie ein verfügbares Modell und fügen Sie einen **Save Image** Node hinzu. Prüfen Sie den Workflow auf Fehler, aber führen Sie ihn noch nicht aus.

Der Agent erstellt den Workflow auf dem Canvas, füllt den Prompt und die Modelleinstellungen aus und prüft die Node-Verbindungen und erforderlichen Eingänge. Sie sollten einen verbundenen Workflow sehen, der mit einem **Save Image** Node endet.

Wenn der Agent ein fehlendes Modell oder eine fehlende Datei meldet, stellen Sie es bereit oder fragen Sie nach einer Alternative, die in Ihrer Installation verfügbar ist. Bitten Sie ihn, den Workflow vor dem Fortfahren erneut zu prüfen.

### Bild generieren

Öffnen Sie **Ausführungsfreigaben** neben dem Nachrichtenfeld, wählen Sie **Nachfragen** und klicken Sie auf **Save changes**, wenn Sie die Einstellung geändert haben.

Senden Sie „Führen Sie diesen Workflow aus.“ Wenn der Agent um Bestätigung bittet, wählen Sie **Run**. Wählen Sie stattdessen **Cancel**, wenn Sie diesen Lauf nicht starten möchten.

Wenn die Generierung abgeschlossen ist, gibt der Agent die Ausgabe im Gesprächsverlauf zurück. Das Bild erscheint außerdem im **Save Image** Node. Klicken Sie dort mit der rechten Maustaste auf das Bild, um es auf Ihrem Computer zu speichern.

### Änderung vornehmen

Senden Sie „Ändern Sie den Hintergrund auf Weiß und behalten Sie das Modell und die übrigen Einstellungen bei.“ Der Agent aktualisiert den bestehenden Workflow. Bitten Sie ihn, erneut auszuführen, um das Ergebnis zu vergleichen.

## Fehlerbehebung

### Die Schaltfläche „Agent“ fehlt

Melden Sie sich bei Ihrem Comfy-Konto an. In Comfy Desktop [aktualisieren Sie die Anwendung](/de/installation/update_comfyui) und starten Sie die Anwendung neu. Wenn die Schaltfläche weiterhin fehlt, prüfen Sie den Agent-Zugriff Ihres Kontos über den [Support](/de/support/contact-support).

### Der Agent kann den erwarteten Workflow nicht bearbeiten

Wählen Sie im Agent-Panel den gewünschten Workflow aus und senden Sie Ihre Nachricht erneut. Siehe [Workflow zum Bearbeiten auswählen](/de/agent-tools/in-app-agent#workflow-zum-bearbeiten-auswählen).

### Der Agent fragt nach einer Eingabe

Wählen Sie **Datei anhängen** aus oder ziehen Sie die angeforderte Datei in das Nachrichtenfeld, und bitten Sie den Agent dann, fortzufahren.

### Eine lokale Unterhaltung ist in Cloud nicht auffindbar

Lokaler und Cloud-Verlauf sind getrennt. Siehe [Daten und Datenschutz](/de/agent-tools/in-app-agent-data-privacy#chatverlauf-und-synchronisierung).
