## Kurzfassung

Comfy Agent verwendet Ihre Nachricht, den ausgewählten Workflow, die ausgewählten Nodes und Anhänge. Wenn Sie mit einer lokalen ComfyUI-Installation arbeiten, wird der Chatverlauf auf diesem Rechner gespeichert. Ihre Nachricht und die zur Beantwortung nötigen Informationen werden über den Online-Dienst von Comfy gesendet.

## Welche Daten der Agent verwendet

| Daten | Nutzen |
| --- | --- |
| Ihre Nachricht | Teilt dem Agent mit, was Sie tun möchten. |
| Ausgewählter Workflow und ausgewählte Nodes | Zeigen, welchen Workflow und welche Nodes Sie erklärt oder geändert haben möchten. |
| Bildanhang | Ermöglicht dem Agent, das Bild zu prüfen und in einem Workflow zu verwenden. |
| Video- oder Audioanhang | Ermöglicht dem Agent, Medieneigenschaften zu lesen und Inhalte zu extrahieren oder zu konvertieren. |
| Workflow- und Ausführungsfehler | Helfen dem Agent, einen fehlgeschlagenen Workflow zu erklären und zu beheben. |
| Persönlicher Skill | Liefert wiederverwendbare Anweisungen. |

Die [Datenschutzerklärung](https://www.comfy.org/privacy-policy?utm_source=docs) und die [Nutzungsbedingungen](https://www.comfy.org/terms-of-service?utm_source=docs) gelten für Ihre Nutzung von Comfy.

## Datenfluss in Cloud und lokal

| Wo Sie Comfy Agent verwenden | Was passiert |
| --- | --- |
| **Comfy Cloud** | Comfy Cloud speichert Unterhaltungen, Workflows und Assets. Ihre Nachrichten werden vom Online-Dienst von Comfy verarbeitet, und Workflows laufen auf Cloud-GPUs. |
| **Lokales ComfyUI in Desktop** | Die lokale Installation speichert Chatverlauf, Workflows und Dateien. Ihre Nachrichten und relevante Workflow-Informationen werden vom Online-Dienst von Comfy verarbeitet. Lokale Workflow-Nodes laufen auf Ihrer Hardware; Partner-Nodes nutzen ihre Online-Anbieter. |

## Chatverlauf und Synchronisierung

Unterhaltungen mit dem Cloud-Agent werden bei Comfy Cloud gespeichert. Unterhaltungen mit dem lokalen Agent werden auf dem Rechner gespeichert, auf dem ComfyUI läuft. Die beiden Verläufe werden nicht synchronisiert. Das hängt davon ab, ob Sie Cloud oder eine lokale Installation verwenden, und nicht davon, in welchem Anwendungsfenster Sie den Agent öffnen.

## Skills und Guidance

Persönliche Skills enthalten Anweisungen, die Sie für den Agent erstellen. Sie werden in Ihrem Konto gespeichert und verwendet, wenn Ihre Anfrage zu ihnen passt oder Sie sie benennen.

Integrierte Guidance und Skills des Agent für externe Coding-Agents sind von Ihren persönlichen Agent-Skills getrennt.

## Aufbewahrung und Löschung

Details zur Aufbewahrung finden Sie in der [Datenschutzerklärung](https://www.comfy.org/privacy-policy?utm_source=docs) und unter [Datenaufbewahrung](/de/support/data-retention).

Für Anfragen zur Konto- oder Datenlöschung wenden Sie sich an [support@comfy.org](mailto:support@comfy.org).
