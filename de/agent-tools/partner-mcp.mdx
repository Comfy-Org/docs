Comfy Partner MCP ist ein lokaler MCP-Server, der KI-Agenten einheitliche Generierungswerkzeuge über **30+ Partneranbieter** bietet, darunter BFL, Ideogram, Kling, Runway, Veo, Meshy, ElevenLabs und weitere. Er verwendet eine einzige kanonische Anfrageform für alle Generierungstypen.

**Wichtige Funktionen:**
- 🎨 **6 Generierungsmodalitäten**: Bild, Video, 3D, SVG, Audio und Musik
- 🔌 **30+ Anbieter** unter einer einheitlichen Schnittstelle
- 💻 **Lokaler Server**: läuft auf Ihrem Rechner und verbindet sich mit der Comfy API
- 🔍 **Integrierte Modellsuche** mit BM25-Textsuche
- 🧩 **Direkt kompatibel** mit Claude Desktop, Claude Code und Amp

---

## Anforderungen

- **Node.js 20+**
- **pnpm 10**
- **[Comfy API-Schlüssel](/de/development/api-development/getting-an-api-key)** (beginnt mit `comfyui-`). Sie erhalten ihn im Partner-Dashboard von Comfy.

---

## Installation

```bash
git clone <repo-url> partner-mcp
cd partner-mcp
pnpm install
pnpm build
```

Nach dem Build befindet sich der Launcher des MCP-Servers unter `packages/mcp/dist/bin.js`.

## Konfiguration

Fügen Sie den Server Ihrer MCP-Client-Konfiguration hinzu. Dasselbe JSON-Format funktioniert in Claude Desktop, Claude Code und Amp:

```json
{
  "mcpServers": {
    "comfy-partner": {
      "command": "node",
      "args": ["/ABSOLUTE/PATH/TO/partner-mcp/packages/mcp/dist/bin.js"],
      "env": {
        "COMFY_API_KEY": "comfyui-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX"
      }
    }
  }
}
```

**Speicherorte der Client-Konfiguration:**

| Client | Konfigurationsdatei |
|--------|---------------------|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) / `%APPDATA%/Claude/claude_desktop_config.json` (Windows) |
| Claude Code | `~/.claude/mcp.json` (oder `claude mcp add` ausführen) |
| Amp | Einstellungen → MCP Servers, oder `~/.config/amp/settings.json` |

Nachdem Sie die Konfiguration hinzugefügt haben, starten Sie Ihren MCP-Client neu. Sie sollten **10 Tools** sehen, die unter dem Server `comfy-partner` registriert sind.

Um zu überprüfen, ob der Server korrekt startet, bevor Sie ihn in einen Client einbinden, führen Sie ihn direkt aus: Er sollte den JSON-RPC-Handshake ausgeben und danach im Leerlauf bleiben:

```bash
COMFY_API_KEY=comfyui-... node /ABSOLUTE/PATH/TO/partner-mcp/packages/mcp/dist/bin.js
```

## Umgebungsvariablen

| Variable | Erforderlich | Zweck |
|----------|----------|---------|
| `COMFY_API_KEY` | Ja | API-Schlüssel (`comfyui-…`). Wird als Header `X-API-Key` gesendet. |
| `COMFY_API_BASE_URL` | Nein | Überschreibt den Proxy-Host (Standard: produktive Comfy API). |
| `COMFY_INLINE_LIMIT_KB` | Nein | Obergrenze (KB) für das Inline-Einbetten von Bild-Bytes in Werkzeug-Ergebnissen. Standard `600`. |
| `COMFY_MCP_RESOURCE_LINKS` | Nein | Erzwingt `resource_link`-Inhaltsblöcke ein/aus. Standardmäßig gilt eine Allowlist (`claude-*`, `mcp-inspector`). |

## Verfügbare Werkzeuge

Der MCP-Server stellt **10 Werkzeuge** bereit. Nach einer erfolgreichen Installation sollte Ihr MCP-Client alle 10 unter dem Server `comfy-partner` registriert anzeigen.

| Werkzeug | Beschreibung |
|------|-------------|
| `generate_image` | Standbilder generieren: Text zu Bild, Bearbeiten oder Upscale |
| `generate_video` | Videoclips generieren: Text zu Video, Bild zu Video oder Lipsync |
| `generate_3d` | 3D-Meshes (GLB/FBX/OBJ) aus Text oder einem Referenzbild generieren |
| `generate_svg` | SVG-Vektorillustrationen aus einem Text-Prompt generieren |
| `generate_audio` | Sprache, Stimmklone oder Soundeffekte aus Text generieren |
| `generate_music` | Instrumental- oder Vokalmusik aus einem Prompt generieren |
| `media_upload` | Eine Datei (Bild/Video/Audio) hochladen und eine `media:<id>`-Referenz zur Verwendung in `generate_*`-Aufrufen erhalten |
| `read_media` | Ein Medienartefakt abrufen und inline rendern: akzeptiert eine HTTPS-URL oder ein `media:…`-Token |
| `models_explore` | Modelle entdecken, nach Fähigkeit suchen und die vollständige Aufrufform eines Modells lesen |
| `balance` | Das verbleibende Guthaben des aktuellen Kontos in USD abrufen |
