<Note>
  **Comfy Agent ist in Comfy Cloud allgemein verfügbar**. Der Agent in Comfy Desktop auf lokalen Installationen folgt in Kürze. [Der Warteliste beitreten](https://links.comfy.org/agentalpha), um benachrichtigt zu werden.
</Note>

Beschreiben Sie direkt in ComfyUI, was Sie möchten. Der Agent plant, erstellt und führt Workflows aus. Er bearbeitet den Canvas während Sie arbeiten und gestaltet so Seite an Seite mit Ihnen. Wenn Sie zum ersten Mal dabei sind, wählen Sie das Info-Symbol neben dem Titel von Comfy Agent, um eine kurze Tour zu starten.

## Was er kann

- Vorlagen, Modelle und Nodes finden, die in Ihrer ComfyUI-Umgebung verfügbar sind.
- Einen Workflow aus einer Vorlage erstellen und dessen Prompts und Einstellungen anpassen.
- Einen Teil des aktuellen Workflows ändern, ohne den Rest neu aufzubauen.
- Nodes hinzufügen, verbinden, konfigurieren und entfernen.
- Einen Workflow validieren, bevor Sie ihn ausführen.
- Bilder untersuchen und Eigenschaften von Video oder Audio auslesen.
- Workflows ausführen und ihre Ausgänge zurückgeben.
- Während der Agent antwortet, können Sie weiter auf dem Canvas arbeiten. Sie müssen nicht warten, bis er fertig ist, und er arbeitet mit dem, was Sie aktuell geöffnet haben.
- Einen Skill in einfacher Sprache erstellen oder den Agent bitten, einen der öffentlichen Skills von Comfy zu verwenden, anstatt nur Ihre eigenen. Siehe [Agent-Skills](/de/agent-tools/in-app-agent-skills).
- Mehr als einen Chat gleichzeitig öffnen. Jeder Chat ist eine eigene Sitzung mit eigener Historie und eigenem Kontext.

## Wo Sie es verwenden können

| Wo Sie Comfy Agent verwenden | Was Sie erwartet                                                                                                                                                                        |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Comfy Cloud**           | Allgemein verfügbar. Agent, Workflows und Assets nutzen Ihr Comfy-Cloud-Konto. Es gibt kein lokales Paket, das Sie installieren müssen.                                                             |
| **Comfy Desktop**         | **Demnächst verfügbar.** [Der Warteliste beitreten](https://links.comfy.org/agentalpha), um benachrichtigt zu werden, wenn Comfy Agent für lokales ComfyUI verfügbar ist, einschließlich Ihrer eigenen Modelle und Custom Nodes. |

In beiden Fällen nutzen Agent-Anfragen Comfy-Dienste über das Netzwerk. Siehe [Daten und Datenschutz](/de/agent-tools/in-app-agent-data-privacy).

Comfy Agent ist unabhängig von [Comfy MCP](/de/agent-tools/mcp) und [Comfy CLI](/de/agent-tools/cli). MCP verbindet einen externen KI-Client mit Comfy. Die CLI ist für Terminal- und Skript-Workflows gedacht. Comfy Agent arbeitet in der ComfyUI-Oberfläche.

Um Ihr erstes Bild zu erstellen, folgen Sie [Loslegen mit Comfy Agent](/de/agent-tools/in-app-agent-installation#ihr-erstes-bild-erstellen).

## Was es kostet

Kostenlose Start-Tokens stehen jetzt allen zur Verfügung, um mehrere Comfy Agent-Chats auszuprobieren. Danach berechnet Comfy Agent aus demselben Comfy-Credits-Pool, den Sie bereits für Generierungen nutzen.
Sie benötigen ein positives Guthaben in Comfy Credits, um den Agent weiter zu betreiben, aber Sie benötigen nicht unbedingt ein Abonnement. Details zu den Tarifen finden Sie unter [Abonnement- und Aufladepläne](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=agent).

## Demnächst lokal verfügbar

Sobald Comfy Agent für Comfy Desktop verfügbar ist, arbeitet es mit Ihrer eigenen GPU, Ihren Modellen und Custom Nodes und führt Sie durch die Einrichtung. Außerdem wird es über das hinausgehen, was heute in der Cloud verfügbar ist: Es erstellt benutzerdefinierte Bearbeitungswerkzeuge direkt auf dem Canvas für Sie, etwa ein einmaliges Maskierungs- oder Compositing-Werkzeug, das Sie nicht installieren mussten.

## Workflow zum Bearbeiten auswählen

Verwenden Sie die Workflow-Auswahl im Agent-Panel, um den zu bearbeitenden Workflow auszuwählen, und senden Sie dann Ihre Nachricht. Wenn Sie während der Antwort des Agent zu einem anderen Tab wechseln, werden seine Bearbeitungen nicht umgeleitet.

Der Agent kann selbst weder Tabs erstellen noch wechseln. Um woanders zu arbeiten, öffnen Sie den anderen Workflow, wählen Sie ihn im Agent-Panel aus und senden Sie eine neue Nachricht.

Der Agent kann einen anderen geöffneten oder gespeicherten Workflow zum Vergleich lesen, ohne ihn in den aktuellen Tab zu laden. Zum Beispiel:

> Vergleichen Sie diesen Workflow mit meinem Porträt-Workflow und verwenden Sie hier dieselben Sampler-Einstellungen.

## Workflows erstellen und bearbeiten {#build-and-edit-workflows}

Für einen neuen Workflow öffnen Sie einen leeren Workflow-Tab und wählen Sie diesen im Agent-Panel aus. Der Agent sucht nach einer passenden Vorlage, bevor er aus einzelnen Nodes aufbaut. Eine Vorlage enthält einen verbundenen Graphen und einen Ausgabe-Node.

Für Änderungen an einem bestehenden Workflow benennen Sie den Teil, den Sie ändern möchten, und was gleich bleiben soll:

- „Ändern Sie den Prompt in eine Aquarelllandschaft. Behalten Sie die Modell- und Sampler-Einstellungen.“
- „Fügen Sie nach der Bilderzeugung eine Upscaling-Stufe hinzu.“
- „Wechseln Sie diesen Workflow mit den hier installierten Modellen zu Flux.“

Der Agent baut in Echtzeit auf dem Canvas auf, während Sie den Canvas weiter bearbeiten.

## Vor der Ausführung validieren

Der Agent prüft Node-Verbindungen, Modellnamen, erforderliche Werte und Ausgabe-Nodes vor einer Ausführung. Er trennt Workflow-Fehler von Eingaben, die nur Sie bereitstellen können.

Wenn der Workflow gültig ist, aber noch ein Bild, ein Video oder eine andere Eingabe benötigt, hängen Sie die Datei an und bitten Sie den Agent, fortzufahren.

## Mit Medien arbeiten

Der Agent kann die sichtbaren Inhalte und Abmessungen eines Standbilds prüfen. Bei Video kann er Dauer, Abmessungen, Bildrate und Format auslesen. Bei Audio kann er Dauer, Format und Audiospuren auslesen.

Verwenden Sie **Bilder oder Dateien hochladen** im Menü „Zum Prompt hinzufügen“, ziehen Sie Dateien in die Unterhaltung oder ziehen Sie ein Asset aus dem Asset-Panel hinein. Bilder, Video, Audio, 3D-Modelle und Textdateien können alle hinzugefügt werden.

Alles, was Sie hinzufügen, erscheint in der Asset-Ablage oben im Nachrichtenfeld. Fahren Sie mit der Maus über ein Element, um den Dateinamen zu sehen, und bei Bildern, Video und Audio eine größere Vorschau. Mit dem × entfernen Sie ein Element. Ein Asset in der Ablage wird mit Ihrer Nachricht gesendet, auch wenn Sie es im Text nicht referenzieren.

| Zur Unterhaltung hinzufügen | Nachfragen | Ergebnis |
| --- | --- | --- |
| Ein Bild | „Beschreiben Sie die Beleuchtung in diesem Bild.“ | Eine Beschreibung, mit der Sie Ihren Prompt verfeinern können. |
| Ein Video | „Kürzen Sie dieses Video auf die ersten fünf Sekunden.“ | Eine verkürzte Videodatei. |
| Zwei Videoclips | „Fügen Sie Clip A und danach Clip B zusammen.“ | Ein Video mit beiden Clips in dieser Reihenfolge. |
| Ein Video und eine Audiodatei | „Fügen Sie dieses Audio zum Video hinzu.“ | Ein Video mit dem bereitgestellten Audio. |

Die Medienbearbeitung erfordert, dass die Medienwerkzeuge in Ihrer Installation verfügbar sind. In Cloud werden bearbeitete Dateien in Ihrer Asset-Bibliothek gespeichert. Der Agent gibt eine Vorschau oder einen Link zur Datei in der Unterhaltung zurück.

## Nodes, Workflows und Assets referenzieren

Geben Sie `@` in das Nachrichtenfeld ein, um etwas anhand seines Namens zu referenzieren, statt es zu beschreiben:

- **Nodes**: Wählen Sie einen Node aus der Liste oder wählen Sie **Zum Prompt hinzufügen** im Menü und klicken Sie auf einen oder mehrere Nodes auf dem Canvas. Der Agent liest die referenzierten Nodes als Teil Ihrer Nachricht.
- **Workflows**: Wählen Sie einen anderen geöffneten oder gespeicherten Workflow aus, damit der Agent ihn zum Vergleich oder zur Wiederverwendung lesen kann. Der Workflow wird nicht in Ihren aktuellen Tab geladen.
- **Assets**: Wählen Sie ein Asset aus der Asset-Ablage aus, um es anhand seines Namens zu referenzieren. Sie können dasselbe Asset beliebig oft referenzieren.

Der Ziel-Workflow folgt dem Tab, den Sie gerade ansehen, bis Sie ein Ziel auswählen, Nodes referenzieren oder eine Nachricht senden. Durch das Referenzieren von Nodes wird dieser Workflow für den Rest des Chats fixiert.

## Ausführungsfreigaben

Wählen Sie neben dem Nachrichtenfeld eine Ausführungsfreigabe aus:

- **Nachfragen** fordert vor jeder Workflow-Ausführung eine Genehmigung an.
- **Automatisch** führt Workflows aus, ohne für jede Ausführung nachzufragen.

Ihre Auswahl wird sofort nach dem Auswählen wirksam. Wählen Sie im Modus „Nachfragen“ in der Genehmigungsnachricht **Run**, um den Workflow zu starten, oder **Abbrechen**, um diese Ausführung abzulehnen.

Nachfragen und Automatisch steuern die Workflow-Ausführungen. Der Agent kann den ausgewählten Workflow in beiden Modi bearbeiten.

## Was der Agent nutzen kann

In einer Chat-Sitzung verwendet der Agent normalerweise Ihre Nachricht, den ausgewählten Workflow, die ausgewählten Nodes, Anhänge und Workflow-Fehler. Er kann außerdem einen anderen Workflow lesen, wenn Sie ihn bitten, Einstellungen zu vergleichen oder wiederzuverwenden.
Darüber hinaus hat der Agent Zugriff auf die gespeicherten Workflows, die verfügbaren Modelle und die verfügbaren Nodes im aktuellen Workspace sowie auf öffentliche Vorlagen-Workflows und öffentliche/private Skills, die bei Bedarf alle herangezogen werden.

Informationen zum Datenfluss bei Cloud und lokal, zum Chatverlauf und zu den Datenschutzeinstellungen finden Sie unter [Daten und Datenschutz bei Comfy Agent](/de/agent-tools/in-app-agent-data-privacy).

## Stoppen oder abbrechen

Wählen Sie im Nachrichtenfeld **Stop**, um die aktuelle Antwort des Agent zu stoppen. Die Workflow-Ausführung verfügt über separate Steuerelemente im [Bereich zum Ausführen und für die Warteschlange](/de/interface/overview). Verwalten Sie damit einen Workflow, der bereits übermittelt wurde.

## Chatverlauf

Unterhaltungen werden gespeichert, sodass Sie jederzeit zu einer früheren Unterhaltung zurückkehren können.

- **Neuer Chat** in der Kopfzeile des Panels startet eine neue Unterhaltung.
- **Chatverlauf anzeigen** öffnet die Liste der gespeicherten Unterhaltungen, gruppiert in Aktuell, Heute, Gestern und Früher. Wählen Sie eine Unterhaltung aus, um sie erneut zu öffnen, oder verwenden Sie die Optionen einer Unterhaltung, um sie umzubenennen, zu kopieren oder zu löschen.

Wo Unterhaltungen gespeichert werden, hängt von Ihrer Einrichtung ab. Siehe [Chatverlauf und Synchronisierung](/de/agent-tools/in-app-agent-data-privacy#chatverlauf-und-synchronisierung).
