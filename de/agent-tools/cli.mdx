[comfy-cli](https://github.com/Comfy-Org/comfy-cli) ist das Kommandozeilenwerkzeug von Comfy. Neben [MCP-Servern](/de/agent-tools) bietet es Agenten und Entwicklern eine weitere Möglichkeit, Comfy außerhalb der UI zu steuern.

Nutzen Sie es für den **Zugriff über Terminal oder Skripte**: Batch-Aufträge, CI-Pipelines, Workflow-Automatisierung und die Kombination mit Coding-Agenten über die mitgelieferten CLI-Skills.

<Info>
  **Kurzreferenz für Agenten.** Diese Seite ist eine gekürzte Übersicht: genug, um sich neben MCP zu orientieren und gängige `comfy generate`-Aufrufe auszuführen. Die **vollständige CLI-Dokumentation** (lokale Installation, `comfy setup`, `comfy run`, Vorlagen, Workflow-Bearbeitung, Erkennung von Nodes und Modellen und mehr) finden Sie unter [Erste Schritte mit Comfy CLI](/de/comfy-cli/getting-started).
</Info>

## Zusammenspiel mit MCP

| | Comfy MCP (Cloud) | Comfy CLI |
|---|---|---|
| **Schnittstelle** | Chat mit einem MCP-Client (Claude Code, Claude Desktop, …) | Terminalbefehle und Skripte |
| **Ideal für** | Interaktive Agent-Workflows im Chat | Automatisierung, Batch-Läufe, CI, Shell-Pipelines |
| **Authentifizierung** | OAuth in MCP-Clients oder API-Schlüssel (headless) | `comfy cloud login` (OAuth) oder API-Schlüssel (CI) |
| **Ausgabe** | Rückgabe in der Chat-Sitzung | Auf der Festplatte gespeichert (`--download`) oder als JSON (`--json`) |

Informationen zur MCP-Einrichtung, zur Installation, zu den Werkzeuglisten und zu den Authentifizierungsmethoden finden Sie unter [Comfy MCP](/de/agent-tools/mcp).

## Was die CLI macht

1. **Lokales ComfyUI**: installieren, starten, aktualisieren und Custom Nodes verwalten
2. **Partner-Generierung**: `comfy generate` für einmalige Bild-, Video-, Audio- und 3D-Aufrufe an die Partner-API
3. **Cloud-Workflows**: `comfy run`, Vorlagen, Slot-Bearbeitung und Überwachen von Aufgaben auf Comfy Cloud

## Installieren und einrichten

```bash

```

Verwenden Sie `-y` für nicht-interaktive Installationen in CI oder Skripten. Die vollständige Tabelle der Flags von `comfy setup` finden Sie unter [Comfy CLI – Erste Schritte](/de/comfy-cli/getting-started#quick-setup-recommended).

Melden Sie sich bei Comfy Cloud an:

```bash
comfy cloud login
comfy cloud whoami
```

## Verfügbare Modelle

`comfy generate` umfasst Partnermodelle für Bild und Video. Finden Sie heraus, welche Modelle in Ihrer CLI-Version verfügbar sind:

```bash
comfy generate list                            # alle Modelle
comfy generate list --category text-to-video   # nach Kategorie filtern
comfy generate list --partner kling            # nach Partner filtern
comfy generate schema flux-kontext             # Parameter für ein Modell
```

Gängige Aliase sind:

| Kategorie | Beispiele |
|---|---|
| **Bild** | `flux-pro`, `flux-ultra`, `flux-kontext`, `nano-banana`, `grok`, `grok-edit`, `ideogram-edit`, `dalle`, `recraft`, `stability` |
| **Video** | `seedance`, `kling`, `luma`, `runway`, `pika`, `vidu`, `hailuo`, `moonvalley`, `grok-video` |

Führen Sie `comfy generate list` aus, um die vollständige Liste in Ihrer Umgebung zu erhalten.

## Nutzungsbeispiele

### Text zu Bild

```bash
comfy generate nano-banana \
    --prompt "a watercolor of a sleeping fox" \
    --download fox.png
```

## Über `comfy generate` hinaus

Alles oben ist die auf Agenten ausgerichtete Zusammenfassung. Der vollständige Leitfaden führt durch jeden Befehl im Detail:

- `comfy run`, `comfy jobs` und `comfy validate` für vollständige Workflows
- `comfy templates` und `comfy workflow` zum Bearbeiten von Slots
- `comfy nodes` / `comfy models` zum Entdecken
- `--json`-Envelopes und `comfy --json discover` für Agenten
