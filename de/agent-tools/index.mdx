## Welche Option sollten Sie verwenden?

| | Comfy MCP<br />Cloud-Verbindung | Comfy MCP<br />Lokale Verbindung | Comfy Agent |
|---|---|---|---|
| **Was ist es** | Comfy-Cloud-Workflows mit Ihrem eigenen Agenten ausführen. | Ihr eigenes lokales ComfyUI mit Ihrem eigenen Agenten steuern. | Im Chat mit einem Agenten in ComfyUI einen ausgewählten Workflow verstehen, erstellen, bearbeiten und ausführen. |
| **Am besten geeignet für** | Einsteiger, die ComfyUI nicht lokal einrichten möchten.<br />Personen, die Workflows teilen möchten. | Personen, die ComfyUI lokal betreiben.<br />Personen, die private Custom Nodes haben.<br />Personen, die mit dem lokalen Dateisystem interagieren müssen. | Workflows erstellen und bearbeiten, während Sie den Canvas im Blick haben. |
| **Voraussetzungen** | Einen eigenen Agenten.<br />Ein aktives Comfy-Cloud-Abonnement. | Einen eigenen Agenten.<br />Eine lokale ComfyUI-Installation. | Ein Comfy-Konto. Keine Warteliste bei Cloud; Comfy Desktop ist demnächst verfügbar. |
| **GPU** | Cloud-GPUs (keine Hardware-Anforderungen) | Ihre lokale GPU | Heute Cloud-GPUs. Lokale Hardware, sobald Comfy Desktop unterstützt wird. |
| **Modelle** | Modelle von Comfy Cloud.<br />Sie können eigene Modelle importieren. | Lokal auf Ihren Rechner heruntergeladene Modelle. | Heute Cloud-Modelle. Lokale Modelle, sobald Comfy Desktop unterstützt wird. |
| **Custom Nodes** | Die auf Comfy Cloud unterstützten Custom Nodes. | Sie können beliebige Custom Nodes installieren. | Heute von Cloud unterstützte Nodes. Jeder lokale Node, sobald Comfy Desktop unterstützt wird. |

Beide MCP-Spalten beschreiben **dasselbe Produkt und dieselbe Seite**. Unter [Comfy MCP](/de/agent-tools/mcp) erfahren Sie, wie Sie sich entscheiden. Sie können beide gleichzeitig verbinden.

## Was ist MCP?

Das **Model Context Protocol (MCP)** ist ein offener Standard, über den KI-Assistenten mit externen Tools und Diensten über eine standardisierte Schnittstelle interagieren können. Statt dass ein KI-Agent die individuellen API-Formate jedes einzelnen Dienstes kennen muss, bietet MCP eine einheitliche Möglichkeit, Tools bereitzustellen.

Wenn Sie einen MCP-Server mit Claude Desktop, Claude Code, Cursor oder Amp verbinden, kann der KI-Assistent:

- **Bilder generieren** aus Textbeschreibungen
- **Videos erstellen** aus Text oder Bildern
- **3D-Modelle generieren** aus Text oder Bildern
- **Audio und Musik generieren** mit KI-Modellen
- **Modelle und Vorlagen durchsuchen**, um die richtigen Tools für Ihre Aufgabe zu finden

...und das alles in natürlicher Sprache, ohne API-Aufrufe manuell zu schreiben.
