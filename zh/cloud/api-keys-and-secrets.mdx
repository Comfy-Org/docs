## 概述

**API 密钥与机密**是 Comfy Cloud 的设置面板，用于存储 Comfy Cloud 代为使用的提供商 API 密钥。保存时，机密值会被加密，且该值本身不会再次显示。

该面板保存两类凭据：

- **模型提供商凭据**：Hugging Face 或 Civitai token，用于在导入期间下载私有和受限模型。完整的导入流程请参阅[导入模型](/zh/cloud/import-models)。
- **BYOK 提供商密钥**：Runway 或 Google Gemini 密钥，使合作伙伴节点调用在你的提供商账户上运行。请参阅 [BYOK 提供商密钥](#byok-provider-keys)。

## 打开机密面板

1. 登录 [Comfy Cloud](https://cloud.comfy.org)。
2. 使用 `Ctrl + ,`（在 macOS 上为 `Cmd + ,`）打开设置对话框，或在 Comfy Cloud 菜单中点击 **设置**。
3. 在设置侧边栏中选择 **密钥**。

该面板对已登录且启用机密的账户显示。

![Comfy Cloud 设置对话框中的机密部分](/images/cloud/import_model/setting_secerts-1.png)

列表会显示每个已存储的机密，包括其名称、提供商、创建日期，以及在有相关信息时显示的最后使用日期。

## 添加机密

<Steps>
  <Step title="开始创建新的机密">
    点击 **添加机密**。
  </Step>
  <Step title="选择提供商">
    从 **提供商** 下拉菜单中选择提供商。该列表由 Comfy Cloud 加载，因此之后新增的提供商会自动显示在这里。选择某个提供商后，会显示它自己的引导，例如在哪里找到你的 Runway API 密钥，或如何在 Google AI Studio 中生成 Google Gemini 密钥。
  </Step>
  <Step title="选择凭证类型">
    接受多种凭证的提供商会显示 **凭证类型** 选择器。大多数提供商接受以文本形式提供的单个 API 密钥。有些则接受 JSON 凭证：粘贴 JSON 或上传文件，该 JSON 对象最大为 1 MB。
  </Step>
  <Step title="为机密命名">
    输入你自定义的名称，最多 255 个字符。名称必须唯一，且每个提供商只能保存一个机密。
  </Step>
  <Step title="输入值">
    粘贴密钥或凭证。该值在保存时会被加密，之后无法再次查看，请自行留存一份副本。
  </Step>
  <Step title="保存">
    点击 **保存**。Comfy Cloud 可立即使用该凭证。
  </Step>
</Steps>

![添加机密对话框，包含名称、提供商和机密值字段](/images/cloud/import_model/setting_secerts-2.png)

## 管理机密

- **编辑**：点击机密上的编辑图标即可重命名机密或替换其值。将值留空则保留当前值，且机密创建后无法更改提供商和凭证类型。如需将凭据迁移到其他提供商，请删除该机密并新建一个。
- **删除**：点击删除图标并确认。删除机密是永久操作，无法撤销。

## BYOK 提供商密钥 {#byok-provider-keys}

自带密钥（BYOK）让你使用自己的提供商账号运行合作伙伴节点，而不是消耗 Comfy 积分。

- 在 Comfy Cloud 中，合作伙伴节点目前支持 **Runway** 和 **Google Gemini** 的 BYOK。对于企业版客户，可以按需添加其他提供商。
- BYOK 按工作区开启，使用你自己的密钥运行的合作伙伴节点调用由该提供商直接计费，不会扣除你的 Comfy 积分。
- 要为某个工作区启用 BYOK，请[提交企业版申请](https://www.comfy.org/contact)。

为工作区启用 BYOK 后，在机密面板中添加该提供商的 API 密钥。此后，该工作区中针对该提供商的合作伙伴节点调用都会使用你的密钥运行。

## 私有模型的凭证

存储在机密中的 Hugging Face 或 Civitai token 会在你导入模型时自动使用，私有仓库和受限仓库正是通过这种方式下载的。该 token 需要对你所导入的仓库具有读取权限，并且只能导入 `.safetensors` 文件。详细的分步流程、支持的模型文件夹以及导入限制请参见[导入模型](/zh/cloud/import-models)。

<Note>
  机密面板用于存储第三方提供商的凭证。它与你用于对 Comfy Cloud API 的调用进行身份验证的 Comfy API 密钥是相互独立的。请参见[获取 API 密钥](/zh/development/api-development/getting-an-api-key)。
</Note>

## FAQ

<AccordionGroup>
  <Accordion title="使用自己的密钥是否仍会消耗 Comfy 积分？">
    不会。使用你自己的 BYOK 密钥运行的合作伙伴节点调用由该提供商直接计费，因此不会消耗你的 Comfy 积分。
  </Accordion>

  <Accordion title="BYOK 可以使用哪些提供商？">
    在 Comfy Cloud 中，合作伙伴节点目前支持 Runway 和 Google Gemini。企业版客户可以通过[企业版申请表单](https://www.comfy.org/contact)按需添加其他提供商。
  </Accordion>

  <Accordion title="如何为我的工作区启用 BYOK？">
    BYOK 按工作区启用。[提交企业版申请](https://www.comfy.org/contact)，我们会为你完成设置，然后你在机密面板中添加提供商密钥。
  </Accordion>

  <Accordion title="保存之后可以读取机密值吗？">
    不可以。机密经过加密，存储的值永远不会返回给界面，因此请自行保存一份机密副本。你可以随时通过 **编辑** 替换该值，或删除该机密并添加新的机密。
  </Accordion>

  <Accordion title="为什么无法为同一个提供商添加第二个机密？">
    每个提供商只能保存一个机密。可以通过编辑该提供商现有的机密来更新密钥；如果你希望有单独的条目，请先删除它。
  </Accordion>

  <Accordion title="为什么我的凭据无法保存？">
    常见原因包括：缺少名称、名称超过 255 个字符、名称已被使用，或该提供商已有机密。对于 JSON 凭据，内容必须能解析为 JSON 对象，且大小不超过 1 MB。
  </Accordion>

  <Accordion title="我的 token 已保存，但私有模型导入仍然失败，该怎么办？">
    请确认该 token 对你正在导入的那个仓库具有读取权限。没有私有或受限仓库访问权限的 token 无法下载该模型。
  </Accordion>
</AccordionGroup>
