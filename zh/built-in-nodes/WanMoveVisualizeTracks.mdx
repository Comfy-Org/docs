WanMoveVisualizeTracks 节点将运动跟踪数据叠加到一系列图像或视频帧上。它会绘制被跟踪点的可视化表示，包括其运动路径和当前位置，使运动数据可见且更易于分析。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要在其上可视化轨迹的输入图像或视频帧序列。 | IMAGE | 是 | - |
| `轨道` | 包含点路径和可见性信息的运动跟踪数据。如果未提供，则输入图像将原样传递。 | TRACKS | 否 | - |
| `线条分辨率` | 为每个轨迹绘制尾迹路径线时使用的先前帧数（默认值：24）。 | INT | 是 | 1 - 1024 |
| `圆环尺寸` | 在每个轨迹当前位置绘制的圆的大小（默认值：12）。标记为高级参数。 | INT | 是 | 1 - 128 |
| `不透明度` | 绘制的轨迹叠加层的不透明度（默认值：0.75）。 | FLOAT | 是 | 0.0 - 1.0 |
| `线条宽度` | 用于绘制轨迹路径的线条宽度（默认值：16）。标记为高级参数。 | INT | 是 | 1 - 128 |

**注意：** 如果输入图像的数量与所提供的 `tracks` 数据中的帧数不匹配，图像序列将被重复以匹配轨迹长度。

**注意：** 轨迹点使用一组有限且重复的颜色绘制；当某个点在某帧的可见性标志为零时，该点在该帧中会被跳过。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `IMAGE` | 带有以叠加层形式可视化的运动跟踪数据的图像序列。如果未提供 `tracks`，则返回原始输入图像。 | IMAGE |
