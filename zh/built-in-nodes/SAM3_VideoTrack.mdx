使用 SAM3 基于记忆的跟踪器跨视频帧跟踪对象。此节点处理一系列视频帧，并在各帧之间保持对象身份；您可以使用初始掩码或文本提示来指定要跟踪的对象，还可以通过文本条件在跟踪过程中检测新对象。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `图像` | 视频帧，以批量图像形式提供 | IMAGE | 是 | 批量视频帧 |
| `model` | 用于跟踪的 SAM3 模型 | MODEL | 是 | SAM3 模型 |
| `初始 mask` | 用于第一帧跟踪的掩码（每个对象一个掩码） | MASK | 否 | 每个对象一个掩码 |
| `条件` | 用于在跟踪过程中检测新对象的文本条件 | CONDITIONING | 否 | 文本条件 |
| `检测阈值` | 文本提示检测的分数阈值（默认值：0.5） | FLOAT | 否 | 0.0 到 1.0 （步长：0.01） |
| `最大对象数` | 最大跟踪对象数。初始掩码也计入此上限。0 表示使用内部上限 64。（默认值：4） | INT | 否 | 0 到 64 |
| `检测间隔` | 每隔 N 帧运行一次检测（1 表示每帧都检测）。值越大越节省算力。（默认值：1） | INT | 否 | 1 或更高 |

**注意：** 必须提供 `initial_mask` 或 `conditioning` 中的至少一个。如果两者都省略，节点会报错。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `track_data` | 跟踪数据，包含所有视频帧中的对象掩码和元数据 | SAM3_TRACK_DATA |
