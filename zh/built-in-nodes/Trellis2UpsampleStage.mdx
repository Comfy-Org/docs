此节点将 512 分辨率的形状 latent 上采样为高分辨率稀疏坐标，并在目标分辨率下准备第二阶段形状采样的第二次采样过程。它会将各阶段的元数据附加到 conditioning 上，以便模型在生成过程中使用。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `正面` | 正向 conditioning，上采样阶段的形状元数据将附加到其上。 | CONDITIONING | 是 | |
| `负面` | 负向 conditioning，上采样阶段的形状元数据将附加到其上。 | CONDITIONING | 是 | |
| `shape_latent` | 来自第一阶段形状 KSampler 的 512 分辨率形状 latent 输出。 | LATENT | 是 | |
| `vae` | 用于将形状 latent 解码为高分辨率稀疏坐标的 Trellis2 VAE。 | VAE | 是 | |
| `target_resolution` | 上采样后形状的体素分辨率。数值越高 = 细节越多，显存占用越大。默认值：1024。 | INT | 是 | 1024 - 2048 （步长：128） |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `positive` | 附加了上采样阶段形状元数据的正向 conditioning。 | CONDITIONING |
| `negative` | 附加了上采样阶段形状元数据的负向 conditioning。 | CONDITIONING |
| `latent` | 为目标分辨率下第二阶段形状采样准备的零填充 latent，其中携带上采样后的坐标、每样本坐标数量以及坐标分辨率元数据。 | LATENT |
