此节点使用 Ideogram Vector 根据文本提示生成可编辑的 SVG，并可选地由最多 5 张参考图像作为引导。其结果是矢量标记而非光栅图像，因此其中的形状在矢量编辑器中仍可编辑。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|------|------|----------|------|------|
| `model` | 要使用的模型。默认：`"ideogram-vector-1"`。 | DYNAMIC_COMBO | 是 | `"ideogram-vector-1"` |
| `images` | 可选的参考图像。图像 1 是主要来源，图像 2 至 5 是额外的参考图像；请在提示中以 `@Image1`、`@Image2` 等方式引用它们。批量输入时每张图像计为一次。 | AUTOGROW | 否 | 0 至 5 张图像 |
| `prompt` | SVG 的描述。支持以 `@Image1` 形式引用输入图像。 | STRING | 是 | 1 至 9500 个字符 |
| `aspect_ratio` | `"auto"` 表示跟随图像 1，若未连接图像则跟随提示。默认：`"auto"`。 | COMBO | 是 | `"auto"`<br />`"1:3"`<br />`"1:2"`<br />`"9:16"`<br />`"10:16"`<br />`"2:3"`<br />`"3:4"`<br />`"4:5"`<br />`"1:1"`<br />`"5:4"`<br />`"4:3"`<br />`"3:2"`<br />`"16:10"`<br />`"16:9"`<br />`"2:1"`<br />`"3:1"` |
| `quality` | 质量等级。更高的等级费用更高、耗时更长。默认：`"medium"`。 | COMBO | 是 | `"low"`<br />`"medium"`<br />`"high"` |
| `seed` | 生成所用的随机种子。相同的提示、图像、设置和种子会生成相同的 SVG。默认：42。 | INT | 是 | 0 至 2147483647 |

**限制条件：**

* 提示必须包含 1 至 9500 个字符。
* `images` 最多接受 5 张图像，当输入为批量时按每张图像计数，且每张图像的宽高比必须在 1:6 与 6:1 之间。
* 最长边超过 2048 像素的图像会在上传前被缩小。
* 引用未连接的图像（例如仅提供两张图像时引用 `@Image4`）会引发错误。

## 输出

| 输出名 | 描述 | 数据类型 |
|--------|------|----------|
| `SVG` | 生成的 SVG，为可编辑的矢量标记。 | SVG |
