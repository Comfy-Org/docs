此节点使用 Wan 3.0 模型根据首帧图像生成视频。您可以选择提供尾帧图像来控制视频的结束方式；模型会生成一段从首帧过渡到尾帧的视频。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 选择要使用的 Wan 3.0 模型变体，并决定下方显示哪些模型专属设置。 | DYNAMIC_COMBO | 是 | "wan3.0-video"<br />"wan3.0-video-prime" |
| `首帧` | 首帧图像。恰好需要一张图像。 | IMAGE | 是 | 单张图像 |
| `末帧` | 尾帧图像。模型会生成一段从首帧到尾帧过渡的视频。可选；如果提供，则恰好需要一张图像。 | IMAGE | 否 | 单张图像 |
| `种子` | 用于生成的种子（默认值：42）。 | INT | 是 | 0 - 2147483647 |
| `水印` | 是否在结果中添加 AI 生成的水印（默认：false）。 | BOOLEAN | 是 | true<br />false |

### wan3.0-video 和 wan3.0-video-prime 输入

这些模型专属设置由两个模型选项共用，并在选择模型后显示。

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述画面元素和视觉特征的提示词。支持英文和中文。可以为空（默认：空）。 | STRING | 是 | 最多 20000 个字符 |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | "1080P"<br />"720P"<br />"480P" |
| `ratio` | 输出视频的宽高比。使用 “adaptive” 时，输出尺寸根据首帧推导。 | COMBO | 是 | "adaptive"<br />"16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4" |
| `duration` | 输出视频的时长（秒）。使用 “auto” 时，模型会选择与提示词匹配的时长。 | COMBO | 是 | "auto"<br />"2" - "30" |
| `audio` | 输出视频是否包含音轨（默认：true）。 | BOOLEAN | 是 | true<br />false |
| `prompt_extend` | 是否通过 AI 辅助增强提示词（默认：true）。 | BOOLEAN | 是 | true<br />false |

注意：本节点恰好接受一张 `first_frame` 图像，并可选择接受一张 `last_frame` 图像。如果任一输入连接了多张图像，则会引发错误。当提供 `last_frame` 时，生成的视频会从首帧过渡到尾帧。`prompt` 的长度限制为 20,000 个字符。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 生成的视频。当启用 `audio` 选项时，包含音轨。 | VIDEO |
