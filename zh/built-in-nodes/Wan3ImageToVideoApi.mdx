此节点使用 Wan 3.0 模型从首帧图像生成视频。您可以选择提供末帧图像来控制视频的结束方式；随后模型会生成一段从首帧过渡到末帧的视频。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 选择要使用的 Wan 3.0 模型变体，并决定下方显示哪些模型特定设置。 | DYNAMIC_COMBO | 是 | "wan3.0-video"<br />"wan3.0-video-prime" |
| `首帧` | 首帧图像。必须恰好提供一张图像。 | IMAGE | 是 | 单张图像 |
| `末帧` | 末帧图像。模型会生成从首帧过渡到末帧的视频。可选；如果提供，必须恰好一张图像。 | IMAGE | 否 | 单张图像 |
| `种子` | 用于生成的种子（默认：42）。 | INT | 是 | 0 - 2147483647 |
| `水印` | 是否为结果添加 AI 生成水印（默认：false）。 | BOOLEAN | 是 | true<br />false |

### wan3.0-video 和 wan3.0-video-prime 输入

这些模型特定设置由两个模型选项共享，并在选择模型时显示。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述元素和视觉特征的提示词。支持英文和中文。可以留空（默认：空）。 | STRING | 是 | 最多 20000 个字符 |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | "1080P"<br />"720P"<br />"480P" |
| `ratio` | 输出视频的宽高比。使用 "adaptive" 时，输出尺寸从首帧推导。 | COMBO | 是 | "adaptive"<br />"16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4" |
| `duration` | 输出时长（秒）。使用 "auto" 时，模型会选择适合提示词的时长。 | COMBO | 是 | "auto"<br />"2" - "30" |
| `audio` | 输出视频是否包含音轨（默认：true）。 | BOOLEAN | 是 | true<br />false |
| `prompt_extend` | 是否使用 AI 辅助增强提示词（默认：true）。 | BOOLEAN | 是 | true<br />false |

注意：此节点接受恰好一张 `first_frame` 图像，并可选接受一张 `last_frame` 图像。如果任一输入连接了多于一张图像，则会引发错误。当提供了 `last_frame` 时，生成的视频会从首帧过渡到末帧。`prompt` 限制为 20,000 个字符。每次运行的价格取决于所选的 `model`、`resolution` 和 `duration`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 生成的视频。当 `audio` 选项启用时，包含音轨。 | VIDEO |
