VAEDecodeTiled 节点使用分块方式将潜在表示解码为图像，以高效处理大图像。它通过以较小的分块进行处理来管理内存占用，同时保持图像质量。该节点还通过以带重叠的分块方式处理时间帧来支持视频 VAE，以实现平滑过渡。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `Latent` | 要解码为图像的潜在表示 | LATENT | 是 | - |
| `vae` | 用于解码潜在样本的 VAE 模型 | VAE | 是 | - |
| `分块尺寸` | 每个分块的处理大小（默认值：512） | INT | 是 | 64-4096 （步长：32） |
| `重叠` | 相邻分块之间的重叠量（默认值：64） | INT | 是 | 0-4096 （步长：32） |
| `时间尺寸` | 仅用于视频 VAE：一次解码的帧数（默认值：64） | INT | 是 | 8-4096 （步长：4） |
| `时间重叠` | 仅用于视频 VAE：重叠的帧数（默认值：8） | INT | 是 | 4-4096 （步长：4） |

**注意：** `tile_size`、`overlap`、`temporal_size` 和 `temporal_overlap` 输入被标记为高级设置。

**注意：** 如果重叠值超过实际限制，节点会自动调整它们。如果 `tile_size` 小于 `overlap` 的 4 倍，则重叠会减小为分块大小的四分之一。类似地，如果 `temporal_size` 小于 `temporal_overlap` 的 2 倍，则时间重叠会减半。节点在计算空间和时间维度的分块大小与重叠大小时，还会考虑 VAE 的内部压缩比。如果输入的 latent 是嵌套的 latent 批次，则只解码该批次中的第一项。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `IMAGE` | 从潜在表示解码生成的图像。解码视频 latent 时，输出是一系列图像帧。 | IMAGE |
