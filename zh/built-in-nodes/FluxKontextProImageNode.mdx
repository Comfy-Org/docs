通过 BFL API 使用 Flux.1 Kontext [pro] 根据提示词和宽高比生成或编辑图像。连接 `input_image` 时，提示词描述编辑操作；未连接时，节点仅根据提示词生成全新图像。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 用于图像生成的提示词。连接输入图像时，指定要编辑的内容和编辑方式。 | STRING | 是 | - |
| `宽高比` | 图像的宽高比；必须介于 1:4 和 4:1 之间（默认：`"16:9"`）。 | STRING | 是 | - |
| `引导强度` | 图像生成过程的引导强度（默认：3.0）。 | FLOAT | 是 | 0.1 到 99.0 （步长：0.1） |
| `步数` | 图像生成过程的步数（默认：50）。 | INT | 是 | 1 到 150 |
| `种子` | 用于生成噪声的随机种子（默认：1234）。 | INT | 是 | 0 到 18446744073709551615 |
| `提示词上采样` | 是否对提示词进行上采样。如果启用，提示词会自动修改以获得更具创造性的生成，但结果不确定，因此相同种子不会产生完全相同的结果（默认：`False`）。这是一个高级设置。 | BOOLEAN | 是 | True / False |
| `输入图像` | 要编辑的可选图像。省略时，会校验提示词以确保其不为空。 | IMAGE | 否 | - |

**注意：** 节点会将请求发送到 BFL，并轮询直到图像就绪。被 BFL 内容审核拒绝的请求会失败，而不会返回图像。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `IMAGE` | 生成或编辑后的图像。 | IMAGE |
