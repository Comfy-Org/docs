此节点使用 Fish Audio 文本转语音模型将书面文本转换为语音音频。它支持嵌入文本中的提示音：[happy] 和 [whispering] 用于 s2.1-pro，(happy) 用于 s1，以及 drama-3 上的自然语言 [directions] 和 `<whisper>...</whisper>` 单词标签。当连接多个语音时，多说话人对话使用 @Voice1/@Voice2 标签。共有三个模型可用：drama-3 和 s2.1-pro 均支持最多五个语音和多说话人对话，而 s1 使用单个可选语音。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `文本` | 要转换为语音的文本。当连接两个或更多语音时，使用 @Voice1、@Voice2 等标记说话人变化。（默认值：空） | STRING | 是 | 任意非空文本 |
| `模型` | 用于文本转语音的模型。 | DYNAMIC_COMBO | 是 | "drama-3"<br />"s2.1-pro"<br />"s1" |
| `种子` | 种子控制节点是否应重新运行；无论种子如何，结果都是非确定性的。（默认值：42） | INT | 是 | 0 到 2147483647 |

### drama-3 和 s2.1-pro 输入

当选择 `drama-3` 或 `s2.1-pro` 模型时，会出现这些输入。参数集完全相同。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `voices` | 可增长的插槽：连接 0 到 5 个语音项（`voice_1`、`voice_2`、……）。用于合成的语音。留空则使用随机语音。当连接两个或更多语音时，在文本中使用 @Voice1、@Voice2 等标记说话人变化。 | FISHAUDIO_VOICE | 否 | 0 到 5 个语音 |
| `temperature` | 表现力。值越高变化越多，值越低越一致。（默认值：0.7） | FLOAT | 是 | 0.0 到 1.0 |
| `top_p` | 通过核采样实现的多样性。（默认值：0.7） | FLOAT | 是 | 0.01 到 1.0 |
| `speed` | 语速。1.0 为正常，&lt;1.0 更慢，>1.0 更快。（默认值：1.0） | FLOAT | 是 | 0.5 到 2.0 |
| `volume` | 以分贝为单位的音量调整。0 表示无变化。（默认值：0.0） | FLOAT | 是 | -10.0 到 10.0 |
| `normalize` | 对英文和中文的数字和文本进行归一化，提高数字和日期的稳定性。（默认值：true） | BOOLEAN | 是 | true / false |

### s1 输入

当选择 s1 模型时，会出现这些输入。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `voice` | 用于合成的语音。不连接则使用随机语音。 | FISHAUDIO_VOICE | 否 | 可选单个语音 |
| `temperature` | 表现力。值越高变化越多，值越低越一致。（默认值：0.7） | FLOAT | 是 | 0.0 到 1.0 |
| `top_p` | 通过核采样实现的多样性。（默认值：0.7） | FLOAT | 是 | 0.01 到 1.0 |
| `speed` | 语速。1.0 为正常，&lt;1.0 更慢，>1.0 更快。（默认值：1.0） | FLOAT | 是 | 0.5 到 2.0 |
| `volume` | 以分贝为单位的音量调整。0 表示无变化。（默认值：0.0） | FLOAT | 是 | -10.0 到 10.0 |
| `normalize` | 对英文和中文的数字和文本进行归一化，提高数字和日期的稳定性。（默认值：true） | BOOLEAN | 是 | true / false |

**注意：** `text` 输入不能为空。说话人标签（@Voice1、@Voice2 等）不区分大小写，并且必须引用已连接的语音；标记未连接的语音会引发错误。当连接两个或更多语音时，文本必须至少引用每个已连接的语音一次，否则节点会报告缺失的标签。在 drama-3 和 s2.1-pro 上，连接 0 个语音使用随机语音，连接 1 个语音仅使用该语音，连接 2 个或更多语音则启用多说话人对话。在 s1 上，使用单个可选语音，不连接则使用随机语音。提示音可以放置在文本中：[happy] 和 [whispering] 用于 s2.1-pro，(happy) 用于 s1，以及自然语言 [directions] 和 `<whisper>...</whisper>` 单词标签用于 drama-3。

|-------------|-------------|-----------|
| `audio` | 生成的语音，作为音频文件。 | AUDIO |
