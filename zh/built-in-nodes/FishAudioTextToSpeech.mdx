此节点使用 Fish Audio 文本转语音模型将书面文本转换为语音音频。它支持嵌入文本中的情感提示（s2.1-pro 上的 [happy]、[whispering]；s1 上的 (happy)），并在连接多个音色时支持使用 @Voice1/@Voice2 标签进行多说话人对话。提供两个模型：s2.1-pro 支持最多五个音色和多说话人对话，s1 使用单个可选音色。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `文本` | 要转换为语音的文本。连接两个或更多音色时，使用 @Voice1、@Voice2 等标记说话人切换。（默认：空） | STRING | 是 | Any non-empty text |
| `模型` | 用于文本转语音的模型。 | DYNAMIC_COMBO | 是 | "s2.1-pro"<br />"s1" |
| `种子` | 种子控制节点是否应重新运行；无论种子如何，结果都是非确定性的。（默认：42） | INT | 是 | 0 到 2147483647 |

### s2.1-pro 输入

这些输入在选择 s2.1-pro 模型时出现。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `voices` | 可增长槽位：连接 0 到 5 个音色项（`voice_1`、`voice_2`、...）。用于合成的音色。留空则使用默认音色。使用两个或更多音色时，在文本中使用 @Voice1、@Voice2 等标记说话人切换。 | FISHAUDIO_VOICE | 否 | 0 到 5 voices |
| `temperature` | 表现力。较高值更多变，较低值更一致。（默认：0.7） | FLOAT | 是 | 0.0 到 1.0 |
| `top_p` | 通过核采样控制多样性。（默认：0.7） | FLOAT | 是 | 0.01 到 1.0 |
| `speed` | 语速。1.0 为正常，&lt;1.0 较慢，>1.0 较快。（默认：1.0） | FLOAT | 是 | 0.5 到 2.0 |
| `volume` | 音量调整，单位为分贝。0 表示无变化。（默认：0.0） | FLOAT | 是 | -10.0 到 10.0 |
| `normalize` | 对英文和中文的数字及文本进行归一化，提高数字和日期的稳定性。（默认：true） | BOOLEAN | 是 | true / false |

### s1 输入

这些输入在选择 s1 模型时出现。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `voice` | 用于合成的音色。未连接则使用默认音色。 | FISHAUDIO_VOICE | 否 | Optional single voice |
| `temperature` | 表现力。较高值更多变，较低值更一致。（默认：0.7） | FLOAT | 是 | 0.0 到 1.0 |
| `top_p` | 通过核采样控制多样性。（默认：0.7） | FLOAT | 是 | 0.01 到 1.0 |
| `speed` | 语速。1.0 为正常，&lt;1.0 较慢，>1.0 较快。（默认：1.0） | FLOAT | 是 | 0.5 到 2.0 |
| `volume` | 音量调整，单位为分贝。0 表示无变化。（默认：0.0） | FLOAT | 是 | -10.0 到 10.0 |
| `normalize` | 对英文和中文的数字及文本进行归一化，提高数字和日期的稳定性。（默认：true） | BOOLEAN | 是 | true / false |

**注意：** `text` 输入不能为空。说话人标签（@Voice1、@Voice2 等）不区分大小写，并且必须引用已连接的音色；标记未连接的音色会引发错误。连接两个或更多音色时，文本必须至少引用每个已连接音色一次，否则节点会报告缺失的标签。在 s2.1-pro 上，连接 0 个音色使用默认音色，1 个音色单独使用该音色，2 个或更多音色启用多说话人对话。在 s1 上，使用单个可选音色，未连接则使用默认音色。情感提示可放在文本中：s2.1-pro 上为 [happy] 和 [whispering]，s1 上为 (happy)。
