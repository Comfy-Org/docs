将渲染的图像重新投影到网格的 UV 布局上。使用 Render Mesh 渲染网格，编辑或重新生成图像，然后使用相同的网格和相机进行烘焙。没有视图覆盖的纹素将保留网格自身的纹理或顶点颜色。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `mesh` | 已渲染的 UV 展开网格。 | MESH | 是 | - |
| `images` | 每个相机对应一张图像，按相机顺序排列（Batch Images）。任意分辨率，但需与渲染的宽高比一致；分辨率越高，烘焙结果越清晰。 | IMAGE | 是 | - |
| `camera_info` | 渲染这些图像时使用的相机，与 Render Mesh 连接的相机相同。使用 Batch Cameras 合并相机装置。无：Render Mesh 自动取景的正视图。 | LOAD3D_CAMERA | 否 | - |
| `resolution` | 方形纹理分辨率。0 表示保持网格当前的纹理尺寸；如果网格没有纹理，则使用 2048；否则会将当前纹理重采样到该分辨率。默认：0。 | INT | 否 | 0 到 8192（步长：64） |
| `blend_exponent` | 各视图按 cos(视角)^指数 进行加权。较高的值更偏向最正对的视图（更清晰，接缝更硬）；较低的值会平均更多视图（更柔和）。默认：4.0。 | FLOAT | 否 | 0.0 到 32.0（步长：0.5） |
| `fill_unseen` | 没有任何视图看到的纹素将使用从可见表面生长填充的颜色，而不是网格自身的纹理或顶点颜色。当这些视图要替换整个纹理时使用此项。默认：false。 | BOOLEAN | 否 | true<br />false |
| `mask` | 每个视图的编辑区域；只有被遮罩的像素会被投影。单个遮罩会应用于所有视图。 | MASK | 否 | - |

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `base_color` | 烘焙后的纹理，用于 Apply Texture to Mesh。 | IMAGE |
| `confidence` | 每个纹素上，最佳视图观察该纹素的正对程度；0 表示未被看到。 | MASK |

注意：使用查看器模型变换进行的渲染不会与烘焙结果对齐，并且只会使用批次中的第一个网格。
