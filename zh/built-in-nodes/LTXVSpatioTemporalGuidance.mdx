此节点通过在每一步采样时额外执行一次传递，来提升 LTXV 视频生成的空间细节与运动连贯性。在该传递过程中，所选 transformer 块的自注意力被降级为值直通（value-passthrough），并引导生成过程远离降级后的结果。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要应用时空引导的基础模型。该模型会被克隆，并附加一个后 CFG 引导函数进行修改。 | MODEL | 是 | — |
| `scale` | 应用于去噪结果的引导强度。设置为 0 时，引导不产生效果。（默认值：1.0） | FLOAT | 是 | 0.0 至 100.0（步长 0.01） |
| `blocks` | 要扰动的 transformer 块索引，以逗号分隔。仅使用数值；其他任何字符均被忽略。（默认值："29"） | STRING | 是 | — |
| `start_percent` | 引导开始的采样过程比例。（默认值：0.0） | FLOAT | 是 | 0.0 至 1.0（步长 0.001） |
| `end_percent` | 引导结束的采样过程比例。（默认值：1.0） | FLOAT | 是 | 0.0 至 1.0（步长 0.001） |

注意：引导仅在 `start_percent` 和 `end_percent` 之间的采样区间内应用。如果 `scale` 为 0，或 `blocks` 中不包含任何数值，则引导传递对采样过程没有影响。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `MODEL` | 附加了时空引导函数的克隆模型。 | MODEL |
