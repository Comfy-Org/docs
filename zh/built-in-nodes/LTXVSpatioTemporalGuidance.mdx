此节点通过在每个采样步骤额外运行一次前向传播，提升 LTXV 视频生成的空间细节与运动连贯性。在这额外的一次前向传播中，所选 transformer 块的自注意力被退化为值直通（value passthrough），并引导生成远离该退化结果。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要应用时空引导的基础模型。该模型会被克隆，并在克隆体上附加一个 post-CFG 引导函数。 | MODEL | 是 | — |
| `scale` | 应用于去噪结果的引导强度。设为 0 时，引导不产生任何效果。（默认值：1.0） | FLOAT | 是 | 0.0 到 100.0（步长 0.01） |
| `blocks` | 以逗号分隔的要扰动的 transformer 块索引。仅使用数值，其他字符都会被忽略。（默认值："29"） | STRING | 是 | — |
| `start_percent` | 采样过程中引导开始的比例位置。这是一个高级参数。（默认值：0.0） | FLOAT | 是 | 0.0 到 1.0（步长 0.001） |
| `end_percent` | 采样过程中引导结束的比例位置。这是一个高级参数。（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0（步长 0.001） |

注意：仅在 `start_percent` 与 `end_percent` 之间的采样区间内才会应用引导。在该区间之外，返回未经修改的原始去噪结果。如果 `scale` 为 0 或 `blocks` 中不包含任何数值，则被引导的那次前向传播对采样过程没有影响。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `MODEL` | 附加了时空引导函数的克隆模型。 | MODEL |
