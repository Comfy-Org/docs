此节点可使用 Pika 根据文本描述和可选歌词生成音乐，也可对您提供的歌曲进行翻唱。选择 `"text to music"` 可按您设定的长度创作一首新歌，选择 `"cover"` 可重新录制一首歌曲并保持其长度不变。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `mode` | 节点执行的操作：`"text to music"` 创作一首新歌，`"cover"` 重新录制提供的歌曲。每种模式会在下方显示各自的输入项。默认：`"text to music"`。 | DYNAMIC_COMBO | 是 | `"text to music"`<br />`"cover"` |

### 文本生成音乐输入

当 `mode` 设置为 `"text to music"` 时，会显示这些输入项。

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 音乐应呈现的风格与听感。不能为空。默认：""（空字符串）。 | STRING | 是 | 1 到 4000 个字符 |
| `lyrics` | 可选歌词。允许使用 `[Verse]` 和 `[Chorus]` 等段落标签。默认：""（空字符串）。 | STRING | 是 | 0 到 8000 个字符 |
| `duration` | 歌曲长度，单位为秒。默认：30.0。 | FLOAT | 是 | 10.0 到 360.0（步长：0.1） |
| `rewrite_prompt` | 在生成前使用模型扩写简短或含糊的提示词。默认：False。 | BOOLEAN | 是 | true<br />false |
| `seed` | 采样种子。默认：42。 | INT | 是 | 0 到 2147483647 |

### 翻唱输入

当 `mode` 设置为 `"cover"` 时，会显示这些输入项。

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `source_audio` | 要翻唱的歌曲。结果长度与之一致，并限制在 5 到 360 秒之间。 | AUDIO | 是 | - |
| `prompt` | 翻唱应呈现的风格与听感。不能为空。默认：""（空字符串）。 | STRING | 是 | 1 到 4000 个字符 |
| `lyrics` | 可选歌词。允许使用 `[Verse]` 和 `[Chorus]` 等段落标签。默认：""（空字符串）。 | STRING | 是 | 0 到 8000 个字符 |
| `rewrite_prompt` | 在生成前使用模型扩写简短或含糊的提示词。默认：False。 | BOOLEAN | 是 | true<br />false |
| `seed` | 采样种子。默认：42。 | INT | 是 | 0 到 2147483647 |

**约束条件：**

* 提示词长度必须在 1 到 4000 个字符之间，歌词长度不得超过 8000 个字符。
* 翻唱模式会忽略 `duration`：输出长度与 `source_audio` 一致，并限制在 5 到 360 秒之间。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `AUDIO` | 生成的歌曲，或所提供音轨的翻唱版本。 | AUDIO |
