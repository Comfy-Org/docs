`WanFunInpaintToVideo` 节点为修复式视频生成准备 conditioning 和 latent 数据，并使用可选的起始图像和结束图像来引导结果。它的工作方式是将提供的 conditioning、VAE 和图像帧传入与首尾帧视频生成相同的逻辑，并返回更新后的 conditioning 以及用于采样的空 latent。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `正向` | 用于视频生成的正向条件提示 | CONDITIONING | 是 | - |
| `负向` | 用于在视频生成中避免的反向条件提示 | CONDITIONING | 是 | - |
| `vae` | 用于编码和解码视频帧的 VAE 模型 | VAE | 是 | - |
| `宽度` | 输出视频宽度，单位为像素（默认值：832，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 输出视频高度，单位为像素（默认值：480，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `长度` | 视频序列中的帧数（默认值：81，步长：4） | INT | 是 | 1 to MAX_RESOLUTION |
| `批量大小` | 一批中生成的视频数量（默认值：1） | INT | 是 | 1 到 4096 |
| `CLIP视觉输出` | 可选的 CLIP 视觉输出，用作起始图像的条件 | CLIP_VISION_OUTPUT | 否 | - |
| `起始图像` | 用于视频生成的可选起始帧图像 | IMAGE | 否 | - |
| `结束图像` | 用于视频生成的可选结束帧图像 | IMAGE | 否 | - |
