WanFunInpaintToVideo 节点通过在起始图像和结束图像之间进行修补来创建视频序列。它接受正向和负向条件输入以及可选的帧图像，以生成视频潜在表示。该节点使用可配置的尺寸和长度参数来处理视频生成。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `正向` | 用于视频生成的正向条件提示 | CONDITIONING | 是 | - |
| `负向` | 视频生成中要避免的负向条件提示 | CONDITIONING | 是 | - |
| `vae` | 用于编码/解码操作的 VAE 模型 | VAE | 是 | - |
| `宽度` | 输出视频宽度（像素）（默认值：832，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 输出视频高度（像素）（默认值：480，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `长度` | 视频序列中的帧数（默认值：81，步长：4） | INT | 是 | 1 to MAX_RESOLUTION |
| `批量大小` | 每批生成的视频数量（默认值：1） | INT | 是 | 1 到 4096 |
| `CLIP视觉输出` | 可选，用作开始图像条件的 CLIP 视觉输出 | CLIP_VISION_OUTPUT | 否 | - |
| `起始图像` | 可选，视频生成的起始帧图像 | IMAGE | 否 | - |
| `结束图像` | 可选，视频生成的结束帧图像 | IMAGE | 否 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `正向` | 处理后的正向条件输出 | CONDITIONING |
| `负向` | 处理后的负向条件输出 | CONDITIONING |
| `latent` | 生成的视频潜在表示 | LATENT |
