Hunyuan3Dv2ConditioningMultiView 节点将来自最多四个视角（前、左、后、右）的 CLIP 视觉输出合并为单一的多视角条件输入。每个提供的视角都会在其 CLIP 视觉嵌入中添加位置编码，然后将生成的嵌入拼接起来。该节点基于合并后的嵌入输出正向条件输入，并输出一个形状相同但填充为零的负向条件输入。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `前` | 前视图的 CLIP 视觉输出。可选视图输入。 | CLIP_VISION_OUTPUT | 否 | - |
| `左` | 左视图的 CLIP 视觉输出。可选视图输入。 | CLIP_VISION_OUTPUT | 否 | - |
| `后` | 后视图的 CLIP 视觉输出。可选视图输入。 | CLIP_VISION_OUTPUT | 否 | - |
| `右` | 右视图的 CLIP 视觉输出。可选视图输入。 | CLIP_VISION_OUTPUT | 否 | - |

**注意：** 节点运行时至少需要提供一个视图输入。节点仅处理包含有效 CLIP 视觉输出数据的视图，并跳过未连接的视图。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `正向` | 包含合并后多视图嵌入及位置编码的正向条件输入。 | CONDITIONING |
| `反向` | 与正向条件输入形状相同、填充为零的负向条件输入。 | CONDITIONING |
