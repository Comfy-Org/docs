Hunyuan3Dv2ConditioningMultiView 节点会将最多四个视角（front、left、back 和 right）的 CLIP 视觉输出组合成单个多视角条件。每个提供的视角都会在其 CLIP 视觉嵌入上添加位置编码，然后将得到的嵌入拼接起来。该节点基于组合后的嵌入输出一个正向条件，并输出一个用相同形状的零填充的负向条件。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `前` | 用于 `front` 视角的 CLIP 视觉输出。可选视角输入。 | CLIP_VISION_OUTPUT | 否 | - |
| `左` | 用于 `left` 视角的 CLIP 视觉输出。可选视角输入。 | CLIP_VISION_OUTPUT | 否 | - |
| `后` | 用于 `back` 视角的 CLIP 视觉输出。可选视角输入。 | CLIP_VISION_OUTPUT | 否 | - |
| `右` | 用于 `right` 视角的 CLIP 视觉输出。可选视角输入。 | CLIP_VISION_OUTPUT | 否 | - |

**注意：** 必须至少提供一个视角输入，节点才能工作。该节点仅处理包含有效 CLIP 视觉输出数据的视角，并跳过未连接的视角。每个视角会根据其槽位（`front`、`left`、`back`、`right`）接收固定的位置编码，并且所有已提供视角处理后的嵌入会沿序列维度拼接在一起。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 包含带有位置编码的组合多视角嵌入的正向条件。 | CONDITIONING |
| `negative` | 与正向条件形状匹配的零值负向条件。 | CONDITIONING |
