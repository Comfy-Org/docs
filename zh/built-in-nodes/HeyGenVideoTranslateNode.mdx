将带语音的视频翻译成另一种语言，并应用声音克隆和唇形同步。此节点克隆原始说话者的声音，并重新驱动嘴部动画以匹配翻译后的语音，生成自然逼真的效果。

## 输入
| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `视频` | 包含待翻译语音的视频。 | VIDEO | 是 | - |
| `目标语言` | 翻译后视频的目标语言。 | COMBO | 是 | "Arabic"<br />"Bengali"<br />"Chinese"<br />"Danish"<br />"Dutch"<br />"English"<br />"French"<br />"German"<br />"Greek"<br />"Hindi"<br />"Indonesian"<br />"Italian"<br />"Japanese"<br />"Korean"<br />"Malay"<br />"Polish"<br />"Portuguese"<br />"Russian"<br />"Spanish"<br />"Swedish"<br />"Tamil"<br />"Telugu"<br />"Thai"<br />"Turkish"<br />"Ukrainian"<br />"Vietnamese" |
| `模式` | “speed”模式速度更快；“precision”模式可生成更高质量的唇形同步，但成本更高。（默认值："speed"） | COMBO | 是 | "speed"<br />"precision" |
| `仅翻译音频` | 仅替换音轨，保留原始嘴部动作（不进行唇形同步）。（默认值：False） | BOOLEAN | 否 | True<br />False |
| `说话人数` | 视频中的说话者数量。0 = 自动检测。大于 0 的值将作为说话者数量发送到 API。（默认值：0） | INT | 否 | 0 到 10 |
| `随机种子` | 不会发送到 HeyGen；更改它以强制重新运行。（默认值：42） | INT | 否 | 0 到 2147483647 |

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 已应用声音克隆和唇形同步的翻译后视频。 | VIDEO |
