Topaz Image Enhance 使用 Topaz 模型对单张输入图像应用行业标准的放大和图像增强处理。它将图像发送到 Topaz API，使用所选模型进行处理，并返回增强后的结果。您可以从三种模型中选择：Reimagine、Bloom 2 和 Wonder 3.5。

## 输入
| 参数 | 描述 | 数据类型 | 是否必需 | Range |
|-----------|-------------|-----------|----------|-------|
| `image` | 要增强的输入图像。仅支持一张输入图像。 | IMAGE | 是 | Single image |
| `model` | 要使用的 Topaz 增强模型。所选模型决定了显示哪些模型特定设置。 | STRING | 是 | `"Reimagine"`<br />`"Bloom 2"`<br />`"Wonder 3.5"` |
| `output_width` | 零值表示自动计算（通常为原始尺寸，或如果指定了 `output_height`，则按比例缩放）。Wonder 3.5 仅支持 1x 到 6x 的放大倍数。Bloom 2 和 Wonder 3.5 保持输入宽高比，并将请求的尺寸视为目标。（默认值：0） | INT | 否 | 0 to 32000 |
| `output_height` | 零值表示输出与原始高度相同，或如果指定了 `output_width`，则按比例缩放。Wonder 3.5 仅支持 1x 到 6x 的放大倍数。Bloom 2 和 Wonder 3.5 保持输入宽高比，并将请求的尺寸视为目标。（默认值：0） | INT | 否 | 0 to 32000 |
