Topaz Image Enhance 使用 Topaz 模型对单个输入图像执行行业标准的放大和图像增强。它将图像发送到 Topaz API，使用所选模型进行处理，并返回增强后的结果。您可以从三个模型中选择：Reimagine、Bloom 2 和 Wonder 3.5。

## 输入
### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|------|------|---------|------|------|
| `image` | 要增强的输入图像。仅支持单个输入图像。 | IMAGE | 是 | 单个图像 |
| `model` | 要使用的 Topaz 增强模型。所选模型决定显示哪些模型特定设置。 | DYNAMIC_COMBO | 是 | `"Reimagine"`<br />`"Bloom 2"`<br />`"Wonder 3.5"` |
| `output_width` | 零值表示自动计算（通常为原始大小，或如果指定了 `output_height`，则按比例缩放）。Wonder 3.5 仅支持 1x 到 6x 的放大倍数。Bloom 2 和 Wonder 3.5 保持输入纵横比，并将请求的尺寸视为目标。（默认：0） | INT | 否 | 0 到 32000 |
| `output_height` | 零值表示输出与原始高度相同，或如果指定了 `output_width`，则按比例缩放。Wonder 3.5 仅支持 1x 到 6x 的放大倍数。Bloom 2 和 Wonder 3.5 保持输入纵横比，并将请求的尺寸视为目标。（默认：0） | INT | 否 | 0 到 32000 |

| `creativity` | 增强的创意级别。（默认：3） | INT | 是 | 1 到 9 |
| `subject_detection` | 主体检测模式。 | COMBO | 是 | `"All"`<br />`"Foreground"`<br />`"Background"` |
| `face_enhancement` | 在处理过程中增强面部（如果存在）。（默认：True） | BOOLEAN | 是 | true<br />false |
| `face_enhancement_creativity` | 设置面部增强的创意级别。（默认：0.0） | FLOAT | 是 | 0.0 到 1.0 |
| `face_enhancement_strength` | 控制增强后的面部相对于背景的锐利程度。（默认：1.0） | FLOAT | 是 | 0.0 到 1.0 |
| `face_preservation` | 保留主体的面部身份。（默认：True） | BOOLEAN | 是 | true<br />false |
| `color_preservation` | 保留原始颜色。（默认：True） | BOOLEAN | 是 | true<br />false |
| `crop_to_fill` | 默认情况下，当输出宽高比不同时，图像会添加黑边。启用后，将裁剪图像以填充输出尺寸。（默认：False） | BOOLEAN | 是 | true<br />false |

| `grain_strength` | 颗粒效果的强度。如果禁用颗粒，则忽略此项。（默认：0.5） | FLOAT | 是 | 0.0 到 1.0 |
| `grain_size` | 颗粒粒子的大小。如果禁用颗粒，则忽略此项。（默认：1.0） | FLOAT | 是 | 1.0 到 5.0 |
| `grain_density` | 颗粒效果的密度。如果禁用颗粒，则忽略此项。（默认：0.5） | FLOAT | 是 | 0.0 到 1.0 |

### Wonder 3.5 输入

这些设置适用于 `model` 设置为 `"Wonder 3.5"` 时。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|------|------|---------|------|------|
| `enhancement_strength` | 针对不同输入条件的增强级别。（默认："high"） | COMBO | 是 | `"low"`<br />`"medium"`<br />`"high"` |
| `grain` | 向输出图像添加颗粒感。（默认：False） | BOOLEAN | 是 | true<br />false |
| `grain_model` | 要使用的颗粒模型。如果禁用颗粒，则忽略此项。 | COMBO | 是 | `"silver"`<br />`"gaussian"`<br />`"grey"` |
| `grain_strength` | 颗粒效果的强度。如果禁用颗粒，则忽略此项。（默认：0.5） | FLOAT | 是 | 0.0 到 1.0 |
| `grain_size` | 颗粒粒子的大小。如果禁用颗粒，则忽略此项。（默认：1.0） | FLOAT | 是 | 1.0 到 5.0 |
| `grain_density` | 颗粒效果的密度。如果禁用颗粒，则忽略此项。（默认：0.5） | FLOAT | 是 | 0.0 到 1.0 |

**注意：** 仅支持单个输入图像。除非启用 `grain`，否则颗粒设置（`grain_model`、`grain_strength`、`grain_size`、`grain_density`）将被忽略。对于 Bloom 2，将 `prompt` 留空会自动从输入图像生成提示。Wonder 3.5 仅支持 1x 到 6x 的放大倍数；Bloom 2 和 Wonder 3.5 保持输入纵横比，并将请求的尺寸视为目标。
