此节点从静态图像开始生成视频，同时将相机移动到主体周围的新角度和距离。方位角、仰角和距离描述相机最终的位置；第一帧保持与提供时完全一致。当未提供提示词时，场景保持冻结，仅相机移动。

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 用于视频生成的模型。 | DYNAMIC_COMBO | 是 | "MiniMax H3 Max" |

### MiniMax H3 Max 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `image` | 视频的第一帧，至少 256x256 像素。宽高比必须在 0.4 到 2.5 之间。 | IMAGE | 是 | 单张图像 |
| `camera_info` | 可选的结束相机，例如来自 Create Camera Info 或 Compose Camera Angle Prompt，以图像作为前视图。连接后，它会设置方位角和仰角。 | LOAD3D_CAMERA | 否 | 相机信息 |
| `prompt` | 可选。当为空时，场景保持冻结，仅相机移动。 | STRING | 是 | 0 到 50000 个字符 |
| `azimuth` | 视频结束时围绕主体的水平环绕角度，以图像为基准，单位为度（默认值：90）。正值将相机向右移动，因此主体转向画面左侧。这是一个目标值：90 度的环绕通常实际落在 30 到 90 度之间。当连接 `camera_info` 时忽略。 | INT | 是 | -360 到 360 |
| `elevation` | 视频结束时的垂直相机角度，单位为度（默认值：0）。正值从上方俯视，负值从下方仰视。当连接 `camera_info` 时忽略。 | INT | 是 | -90 到 90 |
| `distance` | 视频结束时相机相对于图像的相机距离：1 保持距离，小于 1 拉近，大于 1 拉远（默认值：1.0）。 | FLOAT | 是 | 0.1 到 10.0 |
| `duration` | 输出视频的时长，单位为秒（默认值：5）。 | INT | 是 | 1 到 15 |
| `resolution` | 输出视频的分辨率（默认值："768P"）。 | COMBO | 是 | "480P"<br />"768P"<br />"1080P" |
| `prompt_expansion_mode` | 生成前重写提示词所投入的精力（默认值："balanced"）。 | COMBO | 是 | "disabled"<br />"balanced"<br />"quality" |
| `seed` | 随机种子。相同的请求搭配相同的种子会产生相似但不保证完全相同的结果（默认值：42）。 | INT | 是 | 0 到 4294967295 |
