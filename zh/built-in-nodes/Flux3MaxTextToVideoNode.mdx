FLUX 3 Max Text to Video 可根据文本提示词生成带同步音频的视频。FLUX 3 Max 会在渲染前解释并扩展提示词，节点会等待渲染完成，然后返回生成的片段。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 片段应展示的内容，使用自然语言描述。若要获得分层音频，请分别描述环境声、音乐和语音（默认：空）。 | STRING | 是 | 多行文本 |
| `aspect_ratio` | 输出宽高比。对于文本提示词，`"auto"` 为 16:9（默认：`"auto"`）。 | COMBO | 是 | `"auto"`<br />`"21:9"`<br />`"2:1"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"` |
| `duration` | 片段长度，单位为秒（默认：`"5"`）。 | COMBO | 是 | `"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"`<br />`"11"`<br />`"12"`<br />`"13"`<br />`"14"`<br />`"15"`<br />`"16"`<br />`"17"`<br />`"18"`<br />`"19"`<br />`"20"` |
| `resolution` | 输出分辨率（默认：`"720p"`）。 | COMBO | 是 | `"720p"`<br />`"1080p"` |
| `reasoning_level` | 生成前模型对提示词进行推理和扩展的程度。`"high"` 耗时更长；价格相同（默认：`"high"`）。 | COMBO | 是 | `"low"`<br />`"high"` |
| `generate_audio` | 生成同步音频。关闭后生成的视频没有音轨（默认：true）。 | BOOLEAN | 是 | `true`<br />`false` |
| `seed` | 控制节点是否重新运行的种子。无论此值如何，结果都是非确定性的（默认：42）。 | INT | 是 | 0 到 2147483646 |

注意：`prompt` 必须至少包含一个字符。显示的价格基于 `resolution` 和 `duration`：在 2026 年 11 月 7 日之前，720p 按每秒 $0.060775 计费，1080p 按每秒 $0.103675 计费；该日期之后分别按每秒 $0.2431 和 $0.4147 计费。界面中会显示该片段的预计总费用。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 生成的视频片段；启用 `generate_audio` 时包含同步音频。 | VIDEO |
