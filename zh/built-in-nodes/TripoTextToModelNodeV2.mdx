使用 Tripo 服务根据文本描述生成 3D 模型。此节点将提示词和设置发送到 Tripo，等待生成任务完成，并返回完成的 3D 文件以及任务标识符。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要生成模型的文本描述。不能为空。 | STRING | 是 | 多行文本 |
| `negative_prompt` | 描述生成模型中不应出现内容的文本。最多 255 个字符。 | STRING | 否 | 多行文本，最多 255 个字符 |
| `model_version` | 用于生成模型的 Tripo 模型版本（默认：`v3.1_20260211`）。 | COMBO | 否 | 支持的 Tripo 模型版本列表 |
| `texture` | 生成纹理贴图。关闭时返回裸几何体并忽略 `pbr`（默认：True）。 | BOOLEAN | 否 | True<br />False |
| `pbr` | PBR 材质贴图（基础色、金属度、粗糙度、法线）。需要启用 `texture`（默认：True）。 | BOOLEAN | 否 | True<br />False |
| `image_seed` | 图像生成的种子值（默认：42）。 | INT | 否 | 0 到 2147483647 |
| `model_seed` | 模型生成的种子值（默认：42）。 | INT | 否 | 0 到 2147483647 |
| `texture_seed` | 纹理生成的种子值（默认：42）。 | INT | 否 | 0 到 2147483647 |
| `texture_quality` | 纹理细节级别（默认：`"standard"`）。`"detailed"` = HD 纹理，`"extreme"` = 8K Ultra 纹理。 | COMBO | 否 | `"standard"`<br />`"detailed"`<br />`"extreme"` |
| `face_limit` | 最大面数。-1 让 Tripo 自适应选择（v3.x standard 约 140 万面，detailed 约 200 万面）。Tripo 会静默限制：v2.5 为 500,000，`quad` 网格为 150,000（默认：-1）。 | INT | 否 | -1 到 2000000 |
| `quad` | 四边形网格输出。Tripo 以 FBX 格式提供四边形网格，因此结果会出现在 FBX 输出中，而 GLB 输出保持为空（默认：False）。 | BOOLEAN | 否 | True<br />False |
| `geometry_quality` | 几何细节级别（默认：`"standard"`）。 | COMBO | 否 | `"standard"`<br />`"detailed"` |
| `smart_low_poly` | 具有干净、手工风格拓扑的低多边形网格（500-20,000 面，`quad` 为 500-10,000）。最适合简单主体；复杂主体可能会失败（默认：False）。 | BOOLEAN | 否 | True<br />False |
| `auto_size` | 将带纹理模型缩放为其真实世界尺寸（米）。Tripo 将尺寸存储为模型的场景变换，并在模型转换、绑定或重定向时将其烘焙进去；没有纹理时忽略（默认：True）。 | BOOLEAN | 否 | True<br />False |

### 说明

- `prompt` 为必填项，不能为空或仅包含空白字符。
- 当 `texture` 设为 False 时，`pbr` 会被强制关闭，且 `auto_size` 无效。
- 当启用 `smart_low_poly` 且 `face_limit` 不为 -1 时，对于三角形网格，`face_limit` 必须介于 500 和 20,000 之间；启用 `quad` 时，必须介于 500 和 10,000 之间。
- 启用 `quad` 时，Tripo 返回 FBX 文件，因此 `GLB` 输出保持为空，而 `FBX` 输出会被填充。

## 输出

| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model task_id` | 生成该模型的 Tripo 生成任务的标识符。 | MODEL_TASK_ID |
| `GLB` | 以 GLB 格式生成的模型。启用 `quad` 时为空。 | FILE3D_GLB |
| `FBX` | 以 FBX 格式生成的模型。仅在启用 `quad` 时填充。 | FILE3D_FBX |
