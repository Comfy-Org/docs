LTXVConditioning 节点为视频生成模型的正向和负向 conditioning 输入添加帧率信息。它接收已有的 conditioning 数据，并将指定的帧率值应用于两个 conditioning 集合，使其适用于视频模型处理。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `正面条件` | 将接收帧率信息的正向 conditioning 输入 | CONDITIONING | 是 | - |
| `负面条件` | 将接收帧率信息的负向 conditioning 输入 | CONDITIONING | 是 | - |
| `帧率` | 应用于两个 conditioning 集合的帧率值（默认：25.0） | FLOAT | 是 | 0.0 - 1000.0 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `正面条件` | 已应用帧率信息的正向 conditioning | CONDITIONING |
| `负面条件` | 已应用帧率信息的负向 conditioning | CONDITIONING |
