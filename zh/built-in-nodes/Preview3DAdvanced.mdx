此节点在界面中显示 3D 模型预览，而无需将文件保存到 ComfyUI 输出目录。它会将模型保存到临时文件，并将模型数据、模型信息、相机信息和预览尺寸传递给下游节点以进行进一步处理。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 来自上游 3D 节点的 3D 模型文件。 | FILE3D | 是 | GLB, GLTF, FBX, OBJ, STL, USDZ 或任何受支持的 3D 格式 |
| `3D 模型信息` | 可选的模型信息元数据。高级选项。 | LOAD3DMODELINFO | 否 | - |
| `viewport_state` | 当前视口状态，包含相机和模型信息。 | LOAD3D | 是 | - |
| `相机信息` | 3D 视图的可选相机配置。高级选项。 | LOAD3DCAMERA | 否 | - |
| `宽度` | 预览宽度（像素）。默认值：1024。 | INT | 是 | 1 到 4096 |
| `高度` | 预览高度（像素）。默认值：1024。 | INT | 是 | 1 到 4096 |

注意：当 `camera_info` 或 `model_3d_info` 未连接时，若 `viewport_state` 可用，则从中获取其值。如果 `viewport_state` 没有模型信息，`model_3d_info` 默认为空列表。如果 `viewport_state` 不是字典，则按空值处理。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `模型文件` | 从输入传递的 3D 模型文件。 | FILE3D |
| `相机信息` | 模型信息元数据，来自输入或视口状态。 | LOAD3DMODELINFO |
| `3D 模型信息` | 相机配置，来自输入或视口状态。 | LOAD3DCAMERA |
| `宽度` | 预览宽度（像素）。 | INT |
| `高度` | 预览高度（像素）。 | INT |
