此节点在 UI 中显示 3D 模型预览，而无需将文件保存到 ComfyUI 输出目录。它将模型保存到临时文件，并传递模型数据、模型信息、相机信息和预览尺寸，以供下游进一步处理。

## 输入

| 参数 | 说明 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 来自上游 3D 节点的 3D 模型文件。 | FILE3D | 是 | GLB、GLTF、FBX、OBJ、STL、USDZ 或任何支持的 3D 格式 |
| `3D 模型信息` | 每个模型在场景中的放置：位置、旋转和缩放（Y 轴向上世界空间）。可选。高级选项。 | LOAD3DMODELINFO | 否 | - |
| `viewport_state` | 包含相机和模型信息的当前视口状态。 | LOAD3D | 是 | - |
| `相机信息` | 视口相机信息：位置、注视目标、缩放和类型。可选。高级选项。 | LOAD3DCAMERA | 否 | - |
| `宽度` | 视口的渲染宽度（像素）。默认值：1024。 | INT | 是 | 1到4096 |
| `高度` | 视口的渲染高度（像素）。默认值：1024。 | INT | 是 | 1到4096 |

注意：当 `camera_info` 或 `model_3d_info` 未连接时，其值会尽可能从 `viewport_state` 中获取。如果 `viewport_state` 不包含相机信息，则 `camera_info` 为 None。如果 `viewport_state` 没有模型信息，则 `model_3d_info` 默认为空列表。如果 `viewport_state` 不是字典，则将其视为空。

## 输出

| 输出名称 | 说明 | 数据类型 |
|-------------|-------------|-----------|
| `模型文件` | 来自上游 3D 节点的 3D 模型文件（glb/obj/stl 等），保持不变地传递。 | FILE3D |
| `相机信息` | 每个模型在场景中的放置：位置、旋转和缩放（Y 轴向上世界空间）。使用输入值，或回退到 `viewport_state` 中存储的值。 | LOAD3DMODELINFO |
| `3D 模型信息` | 视口相机信息：位置、注视目标、缩放和类型。使用输入值，或回退到 `viewport_state` 中存储的值。 | LOAD3DCAMERA |
| `宽度` | 视口的渲染宽度（像素）。 | INT |
| `高度` | 视口的渲染高度（像素）。 | INT |
