LatentCutToBatch 节点会沿所选维度（时间、宽度或高度）将潜空间表示分割为指定大小的切片，并将它们堆叠成新的批次。每个切片成为批次中的一个单独项，因此潜空间样本的不同部分可以独立处理。

## 输入
| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `Latent` | 要分割并批处理的潜空间表示。 | LATENT | 是 | - |
| `维度` | 用于切割潜空间样本的维度。`"t"` 表示时间（帧）维度，`"x"` 表示宽度，`"y"` 表示高度。 | COMBO | 是 | `"t"`<br />`"x"`<br />`"y"` |
| `碎片大小` | 从指定维度切割的每个切片的大小。如果该维度的大小不能被此值整除，则丢弃余数。（默认值：1） | INT | 是 | 1 到 16384 (max resolution) |

注意：`"t"` 选项仅在潜空间包含时间维度时生效。如果所选维度映射到批次或通道位置，或者不存在（例如，在没有帧的潜空间上选择 `"t"`），节点将原样返回输入。如果 `slice_size` 大于所选维度的大小，则整个维度将作为单个切片使用。当维度大小不能被 `slice_size` 整除时，末尾的剩余部分将被丢弃。输出批次大小等于输入批次大小乘以切片数量，且被切分的维度本身缩减为 `slice_size`。

## 输出
| Output Name | Description | Data Type |
| --- | --- | --- |
| `samples` | 包含切分并堆叠后的样本的最终潜空间批次。 | LATENT |
