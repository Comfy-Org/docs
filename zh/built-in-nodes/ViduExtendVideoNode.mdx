Vidu Video Extension 节点可生成额外帧，以延长现有视频的长度。它使用指定的 AI 模型，基于源视频和可选文本提示来创建延续内容。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频延长的模型。选择模型后会显示其特定的时长和分辨率设置。 | DYNAMIC_COMBO | 是 | `"viduq2-pro"`<br />`"viduq2-turbo"` |
| `video` | 要延长的源视频。 | VIDEO | 是 | - |
| `prompt` | 用于延长视频的可选文本提示（最多 2000 个字符；默认：空）。 | STRING | 是 | - |
| `seed` | 用于控制生成随机性的种子值（默认：1）。 | INT | 是 | 0 到 2147483647 |
| `end_frame` | 可选图像，用作延长后的目标结束帧。 | IMAGE | 否 | - |

### viduq2-pro 和 viduq2-turbo 输入

这些设置由两个模型共享。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `duration` | 延长后视频的时长（秒）（默认：4）。此设置在选择模型后出现。 | INT | 是 | 1 到 7 |
| `resolution` | 输出视频的分辨率。此设置在选择模型后出现。 | COMBO | 是 | `"720p"`<br />`"1080p"` |

**注意：** 源 `video` 的时长必须介于 4 到 55 秒之间。如果提供了 `end_frame`，其宽高比必须介于 1:4 到 4:1 之间，且宽度和高度都必须至少为 128 像素。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 新生成的视频文件，包含延长后的画面。 | VIDEO |
