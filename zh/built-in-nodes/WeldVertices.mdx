Weld Vertices 节点会合并 3D 网格中的重合顶点，使原本各自拥有独立角点的面最终共享相同的顶点。它基于网格边界框的容差，通过网格量化对邻近顶点进行分组，并对每个合并组内的顶点颜色取平均值。当网格以未焊接状态导入（即每个面拥有自己的顶点且没有共享边）时，此节点非常有用，并且可以作为 FillHoles 或 DecimateMesh 等拓扑感知操作之前的预处理步骤。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `网格` | 输入的 3D 网格，其重合顶点将被合并。 | MESH | 是 | - |
| `epsilon_rel` | 焊接容差（边界框对角线的比例）。1e-5 用于浮点去重；1e-3 用于视觉上接近但不同的顶点。默认：1e-5。 | FLOAT | 是 | 0.0 to unlimited (step 1e-6) |
| `epsilon_abs` | 绝对焊接容差（当大于 0 时覆盖 `epsilon_rel`）。默认：0.0。 | FLOAT | 是 | 0.0 to unlimited (step 1e-6) |

注意：当 `epsilon_abs` 大于 0 时，它的优先级高于 `epsilon_rel`，相对容差将被忽略。当 `epsilon_abs` 为 0 时，将使用相对容差 `epsilon_rel`，并通过将其与网格边界框对角线相乘来转换为绝对距离。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mesh` | 焊接后的网格，包含合并的顶点、更新后的面索引以及平均后的顶点颜色（如果输入网格带有颜色）。 | MESH |
