Weld Vertices（焊接顶点）合并 3D 网格中重合的顶点，使之前拥有独立角点的面最终共享相同的顶点。它使用基于网格包围盒的容差进行网格量化来分组邻近顶点，并对每个合并组取顶点颜色的平均值。当网格未焊接（即每个面都有自己的顶点且没有共享边）时，此功能非常有用。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `网格` | 输入 3D 网格，其重合顶点将被合并。 | MESH | 是 | - |
| `epsilon_rel` | 焊接容差（包围盒对角线的比例）。1e-5 用于浮点去重；1e-3 用于视觉上接近但不同的顶点。默认值：1e-5。 | FLOAT | 是 | 0.0 至无限 |
| `epsilon_abs` | 绝对焊接容差（当 > 0 时覆盖 `epsilon_rel`）。默认值：0.0。 | FLOAT | 是 | 0.0 至无限 |

注意：当 `epsilon_abs` 大于 0 时，它将优先于 `epsilon_rel`，相对容差将被忽略。当 `epsilon_abs` 为 0 时，使用相对容差 `epsilon_rel`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `网格` | 焊接后的网格，包含合并的顶点、更新的面索引以及平均顶点颜色（如果输入网格带有颜色）。 | MESH |
