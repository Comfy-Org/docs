使用 Kling 4.0 生成一张长图：完整的网页设计，或电商产品详情页。选择与你想要的布局相匹配的 `skill`，节点会显示该布局对应的输入。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `skill` | 要生成的布局。`"webpage"` 围绕可选的风格图像和主体设计一个完整页面；`"ecommerce"` 根据产品照片构建产品详情页。 | DYNAMIC_COMBO | 是 | `"webpage"`<br />`"ecommerce"` |

### `webpage` 输入

当 `skill` 设置为 `"webpage"` 时，这些输入会出现。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `style_image` | 用于参考视觉风格和布局的可选图像。在提示词中通过 `@Image1` 引用。 | IMAGE | 否 | 单张图像 |
| `subject_image` | 需要保留并围绕其设计页面的可选主体。通过 `@Image2` 引用。 | IMAGE | 否 | 单张图像 |
| `prompt` | 对页面的可选描述。通过 `@Image1` 引用风格图像，通过 `@Image2` 引用主体图像，并指明页面文字所使用的语言，例如 "All visible text must be in English only."。默认值：空字符串。 | STRING | 是 | 多行文本 |
| `resolution` | 输出图像的分辨率。默认：`"1K"`。 | COMBO | 是 | `"1K"`<br />`"2K"` |
| `seed` | 种子控制节点是否应重新运行；无论种子为何，结果都是非确定性的。默认：42。 | INT | 是 | 0 到 2147483647 |

### `ecommerce` 输入

当 `skill` 设置为 `"ecommerce"` 时，这些输入会出现。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `product_images` | 用于产品照片的可增长槽位（`image_1` ... `image_3`）。在提示词中分别通过 `@Image1`、`@Image2`、`@Image3` 引用。 | AUTOGROW | 是 | 1 到 3 张图像 |
| `prompt` | 对页面的可选描述。通过 `@Image1`、`@Image2`、`@Image3` 引用产品图像。默认值：空字符串。 | STRING | 是 | 多行文本 |
| `length` | 生成页面的长度。默认：`"medium"`。 | COMBO | 是 | `"short"`<br />`"medium"`<br />`"long"` |
| `resolution` | 输出图像的分辨率。默认：`"1K"`。 | COMBO | 是 | `"1K"`<br />`"2K"` |
| `seed` | 种子控制节点是否应重新运行；无论种子为何，结果都是非确定性的。默认：42。 | INT | 是 | 0 到 2147483647 |

**约束与行为：**

* 在 `ecommerce` 模式下最多可连接 3 张产品图像。
* 每张图像必须至少为 300x300 像素，宽高比在 2:5 到 5:2 之间。
* 在 `webpage` 模式下，若提示词提及 `@Image1` 或 `@Image2`，而对应图像未连接，则会报错。
* 一次调用的价格取决于 skill、分辨率，以及在 `ecommerce` 模式下的页面长度。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 生成的长图，任务完成后从 Kling 下载。 | IMAGE |
