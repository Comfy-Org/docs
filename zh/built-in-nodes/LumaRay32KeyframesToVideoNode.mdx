此节点使用 Luma Ray 3.2 生成一段视频，该视频通过一系列引导图像进行插值，每张引导图像都锚定到时间轴上的特定位置。使用 Luma Ray 3.2 Keyframe 节点构建关键帧序列，连接至少 2 个关键帧以定义动画。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 用于视频生成的文本提示（默认：空字符串）。 | STRING | 是 | 1 到 6000 个字符 |
| `分辨率` | 生成视频的输出分辨率（默认："720p"）。 | STRING | 是 | `"360p"`<br />`"540p"`<br />`"720p"`<br />`"1080p"` |
| `时长` | 生成视频的时长（默认："5s"）。 | STRING | 是 | `"5s"`<br />`"10s"` |
| `种子` | 用于随机数生成的种子，以控制可复现性。 | INT | 是 | 0 到 4294967295 |
| `关键帧` | 来自 Luma Ray 3.2 Keyframe 节点的关键帧序列（至少 2 个）。 | LUMA_RAY32_KEYFRAME | 是 | 2 到 64 个关键帧 |

**注意：** 关键帧序列必须包含至少 2 个关键帧，最多 64 个关键帧。每个关键帧在时间轴上必须具有不同的位置。关键帧位置会根据所选时长解析为输出帧索引（5s 为 120 帧，10s 为 240 帧）。秒模式下的关键帧位置不得超过视频总时长。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-----------|-----------|
| `video` | 生成的视频输出。 | VIDEO |
| `generation_id` | 生成请求的唯一标识符。 | STRING |
