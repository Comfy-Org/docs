PixVerse V6 文生视频节点使用 PixVerse 的 V6 模型，根据文本提示生成视频。该节点会将提示词以及您选择的分辨率、时长、宽高比和其他设置发送到 PixVerse，等待生成完成后，返回生成的视频——当启用音频生成时，视频会包含原生音轨。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必需 | 取值范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 模型及生成设置。选择模型并配置其生成选项。 | DYNAMIC_COMBO | 是 | "PixVerse V6" |

### PixVerse V6 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 取值范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 视频生成的提示词。（默认值：""） | STRING | 是 | 1–5000 个字符 |
| `aspect_ratio` | 输出宽高比。选择 PixVerse V6 支持的一种宽高比。 | COMBO | 是 | 多个可用选项 |
| `quality` | 输出分辨率。设置长边：360p 为 640px，540p 为 1024px，720p 为 1280px，1080p 为 1920px。（默认值："720p"） | COMBO | 是 | "360p"<br />"540p"<br />"720p"<br />"1080p" |
| `duration_seconds` | 生成视频的时长（秒）。（默认值：5） | INT | 是 | 1–15 |
| `generate_audio` | 与视频一起生成原生音轨。（默认值：True） | BOOLEAN | 是 | True<br />False |
| `multi_clip` | 让模型将视频剪辑为多个镜头，而不是连续拍摄。（默认值：False） | BOOLEAN | 是 | True<br />False |
| `seed` | 视频生成的随机种子。PixVerse 会记录该值，但不会据此复现同一次生成。支持在生成后进行随机化。（默认值：42） | INT | 是 | 0–2147483647 |
| `negative_prompt` | 对视频中不需要的元素的可选文本描述。（默认值：""） | STRING | 否 | 0–2048 个字符 |
| `style` | 应用于整个视频的可选视觉风格。（默认值："none"） | COMBO | 否 | 多个可用选项 |

**注意：** `prompt` 为必填项，去除首尾空白后不得为空；其最大长度为 5000 个字符。`negative_prompt` 限制为 2048 个字符。将 `style` 设置为 "none"（默认值）表示不应用任何视觉风格。`seed` 会被 PixVerse 记录，但无法用于复现同一次运行。节点会等待 PixVerse 完成视频生成后下载视频；如果请求失败——例如 PixVerse 已达到最大并发生成数量、提供商账户余额不足，或内容审核拒绝该提示词——节点将返回错误。

| `VIDEO` | 生成的视频。如果启用了 `generate_audio`，视频将包含原生音轨。 | VIDEO |
