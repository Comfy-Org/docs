LTX 2.5 文生视频是一个 API 节点，使用 LTX 2.5 模型根据文本描述生成专业品质的视频。您提供提示词并选择生成设置，例如模型档位、时长、分辨率、帧率以及是否包含音频；该节点将任务提交至 LTX API 并返回生成的视频。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于视频生成的 LTX 2.5 模型档位。 | STRING | 是 | "LTX-2.5 (Fast)"<br />"LTX-2.5 (Pro)" |
| `时长` | 生成视频的时长。 | INT | 是 | Integer |
| `分辨率` | 视频的输出分辨率。可用选项取决于所选的 `model`。 | STRING | 是 | 使用 "LTX-2.5 (Fast)" 时：<br />"1280x720"<br />"720x1280"<br />"1920x1080"<br />"1080x1920"<br />"2560x1440"<br />"1440x2560"<br />"3840x2160"<br />"2160x3840"<br />使用 "LTX-2.5 (Pro)" 时：<br />"1280x720"<br />"720x1280"<br />"1920x1080"<br />"1080x1920" |
| `帧率` | 生成视频的帧率（默认值：25）。 | INT | 否 | Integer |
| `生成音频` | 是否在生成视频的同时生成音频（默认值：True）。 | BOOLEAN | 否 | True<br />False |
| `提示词` | 要生成的视频的文本描述。需要提供不超过 10,000 个字符的非空提示词（默认值：""）。 | STRING | 是 | 1 到 10000 个字符 |
| `种子` | 用于可重现生成的种子值（默认值：42）。 | INT | 否 | Integer |

注意：可用的 `model.resolution` 选项取决于所选的 `model`。"LTX-2.5 (Fast)" 最高支持 2160x3840 分辨率，而 "LTX-2.5 (Pro)" 最高支持 1920x1080 分辨率。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | LTX API 返回的生成视频，可直接用于工作流中的后续处理。如果启用了音频生成，视频将包含同步音频。 | VIDEO |
