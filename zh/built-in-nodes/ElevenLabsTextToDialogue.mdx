ElevenLabs Text to Dialogue 节点根据文本生成多说话人音频对话。它允许你通过为每位参与者指定不同的文本行和不同的语音来创建对话。该节点会将对话请求发送到 ElevenLabs API，并返回生成的音频。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `稳定性` | 语音稳定性。较低的值提供更广泛的情感范围，较高的值会产生更一致但可能单调的语音。（默认值：0.5） | FLOAT | 是 | 0.0 - 1.0 |
| `应用文本规范化` | 文本规范化模式。'auto' 让系统决定，'on' 始终应用规范化，'off' 跳过规范化。 | COMBO | 是 | `"auto"`<br />`"on"`<br />`"off"` |
| `模型` | 用于对话生成的模型。 | COMBO | 是 | `"eleven_v3"` |
| `对话条数` | 对话条目数量。选择一个数字会创建对应数量的文本和语音输入对。 | DYNAMIC_COMBO | 是 | `"1"`<br />`"2"`<br />`"3"`<br />`"4"`<br />`"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"` |
| `语言代码` | ISO-639-1 或 ISO-639-3 语言代码（例如 'en'、'es'、'fra'）。留空以自动检测。（默认值：空） | STRING | 是 | - |
| `种子` | 用于可复现性的种子。（默认值：1） | INT | 是 | 0 - 4294967295 |
| `输出格式` | 音频输出格式。 | COMBO | 是 | `"mp3_44100_192"`<br />`"opus_48000_192"` |

### 对话条目输入

由所有 `inputs` 选项共享。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `text1` ... `text10` | 对应对话条目的文本内容。该节点会为每个选中的对话条目创建一个 `text` 字段。每个文本值必须至少包含一个字符。 | STRING | 是 | - |
| `voice1` ... `voice10` | 对应对话条目的语音。从 Voice Selector 或 Instant Voice Clone 节点连接。该节点会为每个选中的对话条目创建一个 `voice` 字段。 | ELEVENLABS_VOICE | 是 | - |

**注意：** `inputs` 选择器最多可以创建 10 个对话条目。每个条目都需要一个 `text` 字段和一个 `voice` 字段。`text` 值不能为空。`voice` 输入需要一个由兼容的 ElevenLabs 语音节点提供的语音 ID。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `audio` | 以所选输出格式生成的多人对话音频。 | AUDIO |
