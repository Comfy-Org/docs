WanCameraEmbedding 节点使用基于相机运动参数的 Plücker 嵌入生成相机轨迹嵌入。它会创建一系列相机姿态来模拟不同的相机运动，并将其转换为适用于视频生成管线的嵌入张量。

## 输入
| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `相机姿态` | 要模拟的相机运动类型（默认："Static"） | COMBO | 是 | "Static"<br />"Pan Up"<br />"Pan Down"<br />"Pan Left"<br />"Pan Right"<br />"Zoom In"<br />"Zoom Out"<br />"Anti Clockwise (ACW)"<br />"ClockWise (CW)" |
| `宽度` | 输出的宽度，单位为像素（默认：832，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 输出的高度，单位为像素（默认：480，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `长度` | 相机轨迹序列的长度（默认：81，步长：4） | INT | 是 | 1 to MAX_RESOLUTION |
| `速度` | 相机移动的速度（默认：1.0，步长：0.1） | FLOAT | 否 | 0.0 到 10.0 |
| `fx` | 焦距 x 参数（默认：0.5，步长：0.000000001） | FLOAT | 否 | 0.0 到 1.0 |
| `fy` | 焦距 y 参数（默认：0.5，步长：0.000000001） | FLOAT | 否 | 0.0 到 1.0 |
| `cx` | 主点 x 坐标（默认：0.5，步长：0.01） | FLOAT | 否 | 0.0 到 1.0 |
| `cy` | 主点 y 坐标（默认：0.5，步长：0.01） | FLOAT | 否 | 0.0 到 1.0 |

注意：`fx`、`fy`、`cx` 和 `cy` 是高级相机内参参数。`speed` 参数用于缩放所选相机运动的旋转角度和平移距离。

## 输出
| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `相机嵌入` | 生成的包含轨迹序列的相机嵌入张量 | TENSOR |
| `宽度` | 用于处理的宽度值 | INT |
| `高度` | 用于处理的高度值 | INT |
| `长度` | 用于处理的长度值 | INT |
