HunyuanVideo15SuperResolution 节点为视频超分辨率过程准备条件数据。它接收视频的潜在表示，并可选择接收起始图像，然后将它们与噪声增强和 CLIP 视觉数据一起打包成一种格式，供模型生成更高分辨率的输出。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `正面条件` | 要与潜在变量和增强数据一起修改的正向条件输入。 | CONDITIONING | 是 | 不适用 |
| `负面条件` | 要与潜在变量和增强数据一起修改的负向条件输入。 | CONDITIONING | 是 | 不适用 |
| `vae` | 用于对可选的 `start_image` 进行编码的 VAE。如果提供了 `start_image`，则为必填项。 | VAE | 否 | 不适用 |
| `图像` | 可选的起始图像，用于引导超分辨率。如果提供，它会被放大并编码到条件潜在变量中。 | IMAGE | 否 | 不适用 |
| `CLIP视觉输出` | 可选的 CLIP 视觉嵌入，用于添加到条件中。 | CLIP_VISION_OUTPUT | 否 | 不适用 |
| `latent` | 输入潜在视频表示，将合并到条件中。 | LATENT | 是 | 不适用 |
| `噪波增强` | 应用于条件的噪声增强强度（默认：0.70）。这是一个高级参数。 | FLOAT | 否 | 0.0 - 1.0（步长 0.01） |

**注意：** 如果提供了 `start_image`，则还必须连接一个 `vae` 以便对其进行编码。`start_image` 会自动放大到输入 `latent` 空间尺寸（宽度和高度）的 16 倍，然后被编码并放入条件潜在变量中。仅使用 `start_image` 的 RGB 通道进行编码。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `正面条件` | 修改后的正向条件，现在包含拼接的潜在变量、噪声增强和可选的 CLIP 视觉数据。 | CONDITIONING |
| `负面条件` | 修改后的负向条件，现在包含拼接的潜在变量、噪声增强和可选的 CLIP 视觉数据。 | CONDITIONING |
| `Latent` | 输入潜在变量保持不变地传递。 | LATENT |
