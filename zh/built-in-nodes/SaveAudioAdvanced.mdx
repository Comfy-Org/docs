将输入音频保存到你的 ComfyUI 输出目录。此节点允许你以多种格式导出音频，包括 FLAC、MP3 和 Opus，并可配置质量设置。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 要保存的音频。 | AUDIO | 是 | - |
| `filename_prefix` | 要保存文件的前缀。可包含格式化标记，如 `%date:yyyy-MM-dd%`。（默认值："audio/ComfyUI"） | STRING | 是 | - |
| `format` | 保存音频时使用的文件格式。 | DYNAMIC_COMBO | 是 | "flac"<br />"mp3"<br />"opus" |

### MP3 输入

当选择 "mp3" 作为格式时，以下设置变为可用。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `quality` | 输出 MP3 文件的编码质量。（默认值："V0"） | COMBO | 否 | "V0"<br />"128k"<br />"320k" |

### Opus 输入

当选择 "opus" 作为格式时，以下设置变为可用。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `quality` | 输出 Opus 文件的编码质量。（默认值："128k"） | COMBO | 否 | "64k"<br />"96k"<br />"128k"<br />"192k"<br />"320k" |

注意：`quality` 设置仅在选中对应格式时可用。当选择 "flac" 时，没有可用的额外质量设置。

## 输出

| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `audio` | 输入音频，在保存后原样传递。 | AUDIO |

该节点还会返回包含已保存音频文件信息的 UI 信息。
