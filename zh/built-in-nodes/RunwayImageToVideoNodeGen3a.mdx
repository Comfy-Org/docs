Runway Image to Video (Gen3a Turbo) 节点使用 Runway 的 Gen3a Turbo 模型，从单个起始帧生成视频。它接收文本提示和初始图像帧，然后根据指定的时长和宽高比创建视频序列。生成过程通过 Runway 的 API 远程处理。此节点已标记为弃用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 用于生成的文本提示（默认值：""） | STRING | 是 | N/A |
| `起始帧` | 用于视频的起始帧 | IMAGE | 是 | N/A |
| `时长` | 生成视频的时长，单位为秒（默认值："5"） | COMBO | 是 | `"5"`<br />`"10"` |
| `比例` | 生成视频的宽高比（默认值："768:1280"） | COMBO | 是 | `"768:1280"`<br />`"1280:768"` |
| `种子` | 用于生成的随机种子（默认值：0） | INT | 是 | 0 到 4294967295 |

**参数约束：**

- `prompt` 必须至少包含一个字符（不能为空）。
- `start_frame` 接受单张图像（最多 1 张）。
- `start_frame` 的尺寸不得超过 7999 x 7999 像素。
- `start_frame` 的宽高比必须在 1:2 到 2:1 之间（0.5 到 2.0）。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 生成的视频序列 | VIDEO |
