为 MiniMax H3 模型设置视频和音频流偏移值。视频偏移控制采样器的 sigma 调度，两个偏移值都会传递给模型的内部 transformer，供其从共享的基础网格中推导音频调度。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要应用 sigma 偏移补丁的模型。此节点会克隆模型，因此原始模型保持不变。 | MODEL | 是 | - |
| `视频偏移` | 视频流偏移值。它驱动采样器的 sigma 调度。默认值：12.0。 | FLOAT | 是 | 0.01 to 100.0 |
| `音频偏移` | 音频流偏移值。模型使用它来推导音频调度。默认值：3.0。 | FLOAT | 是 | 0.01 to 100.0 |

## 输出
| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `MODEL` | 已应用视频和音频 sigma 偏移设置的克隆模型。 | MODEL |
