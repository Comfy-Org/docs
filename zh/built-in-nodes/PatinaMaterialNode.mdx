从文本描述生成完整、无缝平铺的 PBR 材质：一张基础贴图加上最多五张材质贴图，并可选择对贴图进行 SeedVR 放大。输入图像可作为图生图（image-to-image）处理来引导结果，而带遮罩的输入图像则会将流程转为内补（inpaint）处理。借助此节点，无需扫描真实材质即可得到可直接用于游戏或 3D 的表面。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要生成的材质或纹理的描述。 | STRING | 是 | 多行文本 |
| `image_size` | 输出纹理尺寸。设置为 `"custom"` 会显示 `width` 和 `height` 输入。默认：`"1:1 (1024x1024)"`。 | DYNAMIC_COMBO | 是 | `"1:1 (1024x1024)"`<br />`"1:1 (512x512)"`<br />`"4:3 (1024x768)"`<br />`"3:4 (768x1024)"`<br />`"16:9 (1024x576)"`<br />`"9:16 (576x1024)"`<br />`"custom"` |
| `basecolor` | 生成 basecolor（反照率）贴图。默认：True。 | BOOLEAN | 是 | true<br />false |

### 自定义图像尺寸输入

当 `image_size` 设置为 `"custom"` 时，这些输入会出现。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | 纹理宽度（像素）。默认：1024。 | INT | 是 | 512 到 2048（步长：16） |
| `image_size.height` | 纹理高度（像素）。默认：1024。 | INT | 是 | 512 到 2048（步长：16） |

**约束与行为：**

* 允许不启用任何材质贴图：此时节点只返回基础贴图，并且每个贴图输出都保持为 1x1 占位符。
* 遮罩需要输入图像；单独提供遮罩会引发错误。
* 8K 结果来自对 2048 像素渲染结果中的贴图进行 4x 放大，而不是来自单次 8K 生成。
