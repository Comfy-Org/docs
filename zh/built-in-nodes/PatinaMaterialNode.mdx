根据文本描述生成完整、可无缝平铺的 PBR 材质：一个基础纹理以及最多五个材质贴图，并可选择使用 SeedVR 对贴图进行放大。输入图像可作为图生图流程来驱动结果，而带有 `mask` 的输入图像会将其转为内补（inpaint）流程。可使用它生成可直接用于游戏或 3D 的表面，而无需扫描真实材质。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|

| `image_size` | 输出纹理尺寸。`"custom"` 会显示 `width` 和 `height` 输入。默认：`"1:1 (1024x1024)"`。 | DYNAMIC_COMBO | 是 | `"1:1 (1024x1024)"`<br />`"1:1 (512x512)"`<br />`"4:3 (1024x768)"`<br />`"3:4 (768x1024)"`<br />`"16:9 (1024x576)"`<br />`"9:16 (576x1024)"`<br />`"custom"` |

### 自定义图像尺寸输入

当 `image_size` 设置为 `"custom"` 时，会出现这些输入。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | 纹理宽度（像素）。默认：1024。 | INT | 是 | 512 到 2048 （步长：16） |
| `image_size.height` | 纹理高度（像素）。默认：1024。 | INT | 是 | 512 到 2048 （步长：16） |

**约束与行为：**

* 必须至少启用一个材质贴图，否则运行会失败。
* `mask` 需要输入图像；单独提供 `mask` 会报错。
* 8K 结果来自对 2048 像素渲染结果的贴图进行 4x 放大，而不是来自单次 8K 生成。
