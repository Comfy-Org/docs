此节点提供一种专用采样方法，将潜在一致性模型（LCM）采样与渐进式图像放大相结合。在采样过程中，图像会使用选定的插值方法逐步放大至目标缩放比例，从而在单次采样中实现更高分辨率的结果。该节点输出一个已配置的采样器对象，可连接到采样节点使用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `缩放比例` | 放大过程中应用的总缩放系数。值为 1.0 时保持原始分辨率（默认值：1.0） | FLOAT | 是 | 0.1 - 20.0 |
| `缩放步数` | 用于放大过程的步数。使用 -1 可根据采样调度自动计算（默认值：-1） | INT | 是 | -1 - 1000 |
| `缩放方法` | 每个放大步骤中用于放大图像的插值方法（默认值："bislerp"） | COMBO | 是 | "bislerp"<br />"nearest-exact"<br />"bilinear"<br />"area"<br />"bicubic" |

`scale_ratio` 和 `scale_steps` 是高级参数。图像会在放大步骤中从原始尺寸逐步放大至目标 `scale_ratio`。当 `scale_steps` 为 -1 时，放大步数会自动计算为采样步数的一半左右，且最小为 2；当给出正值时，节点会在内部对其进行调整，并根据采样总步数加以限制。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `sampler` | 一个已配置的采样器对象，执行带渐进式放大的 LCM 采样，可直接用于采样流程 | SAMPLER |
