SamplerLCMUpscale 节点提供一种专门的采样方法，将潜在一致性模型（LCM）采样与图像放大功能相结合。它在采样过程中使用多种插值方法逐步放大图像，从而能在单次采样中生成更高分辨率的输出。输出是一个配置好的采样器对象，可连接到采样节点。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `缩放比例` | 放大过程中应用的总缩放比例。值为 1.0 时保持原始分辨率（默认：1.0） | FLOAT | 是 | 0.1 - 20.0 |
| `缩放步数` | 放大过程所使用的步数。使用 -1 根据采样计划自动计算（默认：-1） | INT | 是 | -1 - 1000 |
| `缩放方法` | 在每一步放大中用于放大图像的插值方法（默认："bislerp"） | COMBO | 是 | "bislerp"<br />"nearest-exact"<br />"bilinear"<br />"area"<br />"bicubic" |

`scale_ratio` 和 `scale_steps` 是高级参数。图像从原始尺寸逐步放大到目标 `scale_ratio`，放大过程分布在各个放大步中。当 `scale_steps` 为 -1 时，放大步数会根据采样步数自动计算，约为采样步数的一半，且最小为 2；当给定正值时，节点会在内部调整该值，并基于总采样步数进行限制。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `sampler` | 一个配置好的采样器对象，可执行带渐进式放大的 LCM 采样，可直接用于采样流程 | SAMPLER |
