此节点将每个输入图像裁剪为黑色背景上的居中正方形，并添加填充以达到指定的输出大小。它旨在通过确保一致的正方形构图和可选的 alpha 遮罩腐蚀来防止边缘伪影，从而为 TripoSplat 3D 模型准备图像。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 要预处理的输入图像。 | IMAGE | 是 | - |
| `mask` | 图像的 Alpha 遮罩，用于确定裁剪区域。 | MASK | 是 | - |
| `erode_radius` | 在裁剪之前按此像素半径腐蚀 alpha 遮罩（避免边缘渗色）。默认值：1。设置为 0 可禁用腐蚀。 | INT | 是 | 0 到 16 |
| `size` | 正方形图像大小。模型在 1024 分辨率下训练；其他尺寸也可运行，但会偏离训练分布。默认值：1024。 | INT | 是 | 256 到 4096 (step of 16) |

**注意：** `mask` 输入为必需项，必须提供。如果 mask 的批次大小与图像不同，则会自动重复以匹配。如果 mask 的尺寸与图像尺寸不同，则会使用双线性插值将 mask 调整为与图像匹配。输出大小会自动向下取整为最接近的 16 的倍数（最小为 16），以确保与 DINOv3 patch 和 Flux2 VAE 步长要求兼容。如果 mask 不包含任何前景像素（空 mask），节点将引发错误。当 `erode_radius` 为 0 时，不进行腐蚀。正方形裁剪以 mask 的 alpha 边界框为中心，大小设置为较大边界框尺寸的 1.2 倍；图像边界之外的任何区域均填充为黑色。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 预处理后的图像，裁剪为黑色背景上的居中正方形并带有填充，分辨率按所请求的 `size` 尺寸输出。 | IMAGE |
