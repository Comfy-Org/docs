GITSScheduler 节点为 GITS（生成式迭代时间步）采样方法生成噪声调度 sigma。它根据系数参数和步数计算 sigma 值，并提供一个可选的降噪因子，以减少使用的总步数。该节点使用预定义的噪声水平和插值来创建最终的 sigma 调度。

## 输入
| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `系数` | 控制噪声调度曲线的系数值（默认值：1.20）。该值四舍五入到两位小数，并用于选择所使用的预定义噪声水平表。 | FLOAT | 是 | 0.80 - 1.50 (step 0.05) |
| `步数` | 要为其生成 sigma 的采样步总数（默认值：10） | INT | 是 | 2 - 1000 |
| `降噪` | 用于减少所用步数的降噪因子（默认值：1.0） | FLOAT | 是 | 0.0 - 1.0 |

**注意：** 当 `denoise` 为 0.0 或更小时，节点返回一个空张量。当 `denoise` 小于 1.0 时，实际使用的步数按 `round(steps * denoise)` 计算，并且只保留调度中对应的最后部分。对于 2 到 20 之间的步数，节点会选择匹配的预定义噪声调度。对于大于 20 的步数，节点使用对数线性插值将预定义的噪声水平扩展到所需的步数。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `sigmas` | 为噪声调度生成的 sigma 值。对于 N 步，返回 N+1 个 sigma 值，且最后一个 sigma 设置为 0。 | SIGMAS |
