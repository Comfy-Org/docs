GITSScheduler 节点为 GITS（Generative Iterative Time Steps，生成式迭代时间步）采样方法生成噪声调度 sigmas。它根据系数参数和步数计算 sigma 值，并提供一个可减少总使用步数的去噪因子。该节点使用预定义的噪声水平表和插值来生成最终的 sigma 调度。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `系数` | 高级参数。控制噪声调度曲线的系数值（默认值：1.20）。该值会四舍五入到两位小数，并用于选择使用哪一张预定义的噪声水平表。 | FLOAT | 是 | 0.80 - 1.50 （步长：0.05） |
| `步数` | 要为其生成 sigmas 的采样总步数（默认值：10）。 | INT | 是 | 2 - 1000 |
| `降噪` | 去噪因子，用于减少实际使用的步数（默认值：1.0）。 | FLOAT | 是 | 0.0 - 1.0 （步长：0.01） |

**注意：** 当 `denoise` 为 0.0 或更小时，该节点返回空张量。当 `denoise` 小于 1.0 时，实际使用的步数按 `round(steps * denoise)` 计算，并且只保留调度中对应的最后一部分。当步数在 2 到 20 之间时，该节点会选择一张匹配的预定义噪声调度表。当步数大于 20 时，该节点使用对数线性插值将预定义的噪声水平扩展到所需的步数。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `sigmas` | 为噪声调度生成的 sigma 值。对于 N 个采样步数，将返回 N+1 个 sigma 值，且最后一个 sigma 设为 0。 | SIGMAS |
