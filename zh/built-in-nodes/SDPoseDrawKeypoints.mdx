SDPoseDrawKeypoints 节点接收姿态估计数据（关键点）并将其绘制在空白画布上，形成可视化骨架。它允许你选择性绘制姿态的不同部分，如身体、头部、手部、面部和脚部，并支持自定义线条宽度和点的大小。生成的图像可用于可视化，或作为需要姿态图像的其他节点的输入。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `keypoints` | 要绘制的姿态关键点数据。该数据通常来自姿态检测节点，可包含一帧或多帧。 | POSE_KEYPOINT | 是 | - |
| `draw_body` | 控制是否绘制主身体骨架（默认值：True）。 | BOOLEAN | 否 | - |
| `draw_hands` | 控制是否绘制手部关键点（默认值：True）。 | BOOLEAN | 否 | - |
| `draw_face` | 控制是否绘制面部关键点（默认值：True）。 | BOOLEAN | 否 | - |
| `draw_feet` | 控制是否绘制脚部关键点（默认值：False）。 | BOOLEAN | 否 | - |
| `stick_width` | 用于绘制身体和头部骨架的线条宽度（默认值：4）。 | INT | 否 | 1 到 10 |
| `face_point_size` | 用于绘制面部关键点的点大小（默认值：3）。 | INT | 否 | 1 到 10 |
| `score_threshold` | 关键点被绘制所需的最低置信度分数。低于此值的关键点将被忽略（默认值：0.3）。 | FLOAT | 否 | 0.0 到 1.0 |
| `绘制头部` | 控制是否绘制头部关键点（鼻子、眼睛、耳朵）（默认值：True）。 | BOOLEAN | 否 | - |

**注意：** 如果 `keypoints` 输入为空或为 `None`，节点将输出一张空白的 64x64 图像。

**注意：** `draw_body` 和 `draw_head` 独立工作。当 `draw_head` 禁用时，即使启用 `draw_body` 也不会绘制头部关键点。当 `draw_body` 禁用但 `draw_head` 启用时，仅绘制头部关键点和颈部点。如果两者均禁用，则不绘制任何身体或头部关键点。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `output` | 绘制了姿态关键点的图像。图像尺寸与输入关键点数据中指定的 `canvas_height` 和 `canvas_width` 一致。当输入包含多帧时，返回一批图像。 | IMAGE |
