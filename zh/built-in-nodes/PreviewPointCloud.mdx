预览点云节点允许您在 ComfyUI 界面中查看 3D 点云文件，而无需将其保存到 ComfyUI 输出目录。它会将点云保存到临时位置，并在 3D 预览窗口中显示，同时将模型数据、模型信息、相机信息和预览尺寸传递下去以供进一步处理。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 点云文件 (.ply) | FILE3D | 是 | - |
| `model_3d_info` | 3D 模型的信息 | LOAD3DMODELINFO | 否 | - |
| `viewport_state` | 3D 视口的当前状态 | LOAD3D | 是 | - |
| `camera_info` | 3D 视图的相机信息 | LOAD3DCAMERA | 否 | - |
| `width` | 预览窗口的宽度（默认值：1024） | INT | 是 | 1 到 4096 |
| `height` | 预览窗口的高度（默认值：1024） | INT | 是 | 1 到 4096 |

注意：`model_3d_info` 和 `camera_info` 是可选的高级输入。当它们未连接时，节点会回退到 `viewport_state` 中存储的相应值。点云文件会写入 ComfyUI 的临时目录，而非输出目录。这是一个输出（终端）节点，因此主要用于在界面中显示预览。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model_3d` | 点云模型数据 | FILE3D |
| `model_3d_info` | 3D 模型的信息 | LOAD3DMODELINFO |
| `camera_info` | 3D 视图的相机信息 | LOAD3DCAMERA |
| `width` | 预览窗口的宽度 | INT |
| `height` | 预览窗口的高度 | INT |
