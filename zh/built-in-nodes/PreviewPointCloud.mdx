预览点云节点允许您直接在 ComfyUI 界面中查看 3D 点云文件，而无需将其保存到 ComfyUI 输出目录。它会将点云保存到临时位置，并在 3D 预览窗口中显示，同时传递模型数据、相机信息和视口状态以供进一步处理。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 点云文件 (.ply) | FILE3D | 是 | - |
| `model_3d_info` | 关于 3D 模型的信息 | LOAD3DMODELINFO | 否 | - |
| `viewport_state` | 当前视口状态 | LOAD3D | 是 | - |
| `camera_info` | 用于 3D 视图的相机信息 | LOAD3DCAMERA | 否 | - |
| `width` | 预览窗口的宽度（默认：1024） | INT | 是 | 1 到 4096 |
| `height` | 预览窗口的高度（默认：1024） | INT | 是 | 1 到 4096 |

注意：当 `camera_info` 或 `model_3d_info` 未连接时，节点将回退到 `viewport_state` 中存储的对应值。点云文件将保存到 ComfyUI 的临时目录，不会写入输出目录。这是一个输出节点，因此主要用于在界面中显示预览结果。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model_3d` | 点云模型数据 | FILE3D |
| `model_3d_info` | 关于 3D 模型的信息 | LOAD3DMODELINFO |
| `camera_info` | 用于 3D 视图的相机信息 | LOAD3DCAMERA |
| `width` | 预览窗口的宽度 | INT |
| `height` | 预览窗口的高度 | INT |
