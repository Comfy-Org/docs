使用 MiniMax Hailuo-02 模型根据文本提示词生成视频。你可以选择提供一张起始图像作为第一帧，从而生成一段从该图像继续的视频。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示文本` | 用于引导视频生成的文本提示词（默认：空）。 | STRING | 是 | - |
| `种子` | 用于创建噪声的随机种子（默认：0）。 | INT | 否 | 0 到 18446744073709551615 |
| `第一帧图像` | 可选图像，用作生成视频的第一帧。 | IMAGE | 否 | - |
| `提示优化器` | 在需要时优化提示词以提高生成质量（默认：True）。 | BOOLEAN | 否 | True<br />False |
| `时长` | 输出视频的时长，单位为秒（默认：6）。 | COMBO | 否 | 6<br />10 |
| `分辨率` | 视频显示尺寸。1080p 为 1920x1080，768p 为 1366x768（默认："768P"）。 | COMBO | 否 | "768P"<br />"1080P" |

**注意：** 当 `resolution` 设置为 "1080P" 时，`duration` 限制为 6 秒。当未提供 `first_frame_image` 时，`prompt_text` 不能为空。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 生成的视频文件。 | VIDEO |
