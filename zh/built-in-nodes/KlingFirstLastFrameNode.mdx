此节点使用 Kling 3.0 模型生成视频。它根据文本提示、指定时长以及提供的两个图像（起始帧和结束帧）创建视频。该节点还可以为视频生成伴随音频。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 模型和生成设置。选择此选项会显示嵌套的 `resolution` 参数。 | DYNAMIC_COMBO | 否 | `"kling-v3"` |
| `提示词` | 指导视频生成的文本描述。长度必须介于 1 到 2500 个字符之间。 | STRING | 是 | N/A |
| `时长` | 视频长度（以秒为单位，默认：5）。 | INT | 否 | 3 到 15 |
| `首帧` | 视频的起始图像。必须至少为 300x300 像素，且宽高比介于 1:2.5 和 2.5:1 之间。 | IMAGE | 是 | N/A |
| `末帧` | 视频的结束图像。必须至少为 300x300 像素，且宽高比介于 1:2.5 和 2.5:1 之间。 | IMAGE | 是 | N/A |
| `生成音频` | 控制是否为视频生成音频（默认：True）。 | BOOLEAN | 否 | N/A |
| `种子` | 种子控制节点是否应重新运行；无论种子为何值，结果都是非确定性的（默认：0）。 | INT | 否 | 0 到 2147483647 |

### Kling V3 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 生成视频的分辨率（默认：`"1080p"`）。 | COMBO | 否 | `"4k"`<br />`"1080p"`<br />`"720p"` |

**注意：** `first_frame` 和 `end_frame` 图像必须至少为 300x300 像素，且宽高比介于 1:2.5 和 2.5:1 之间，节点才能正常运行。`prompt` 必须介于 1 到 2500 个字符之间。`resolution` 选项对应 Kling 生成模式：`"4k"`、`"1080p"`（专业版）和 `"720p"`（标准版）。
