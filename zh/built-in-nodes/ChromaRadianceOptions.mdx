ChromaRadianceOptions 节点允许您为 Chroma Radiance 模型配置高级设置。它会包装现有模型，并根据 sigma 值在去噪过程中应用特定选项，从而实现对 NeRF 瓦片大小及其他辐射相关参数的精细控制。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要应用 Chroma Radiance 选项的模型 | MODEL | 是 | - |
| `保留包装器` | 启用后，如果存在现有的模型函数包装器，则将委托给该包装器。通常应保持启用。（默认值：True） | BOOLEAN | 否 | - |
| `起始sigma` | 这些选项生效时的第一个 sigma 值。（默认值：1.0） | FLOAT | 否 | 0.0 到 1.0 |
| `结束sigma` | 这些选项生效时的最后一个 sigma 值。（默认值：0.0） | FLOAT | 否 | 0.0 到 1.0 |
| `NeRF瓦片大小` | 允许覆盖默认的 NeRF 瓦片大小。-1 表示使用默认值（32）。0 表示使用非平铺模式（可能占用大量显存）。（默认值：-1） | INT | 否 | -1 and above |
| `强制顺序文本ID` | 强制使用顺序文本令牌 ID 而不是零值。适用于 2026-05-22 至 2026-06-01 期间以这种方式训练、但 state dict 中不包含 `__sequential__` 键的检查点。（默认值：False） | BOOLEAN | 否 | - |

**注意：** Chroma Radiance 选项仅在当前 sigma 值位于 `end_sigma` 和 `start_sigma`（含）之间时生效。`nerf_tile_size` 参数仅在设置为 0 或更高值时应用。`force_sequential_txt_ids` 参数仅在设置为 True 时应用。当 `nerf_tile_size` 为 -1 且 `force_sequential_txt_ids` 为 False 时，不配置任何选项，模型将原样返回，不应用任何包装器。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model` | 已应用 Chroma Radiance 选项的模型；如果没有选项处于活动状态，则返回未更改的模型 | MODEL |
