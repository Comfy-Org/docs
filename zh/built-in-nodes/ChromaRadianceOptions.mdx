ChromaRadianceOptions 节点允许你为 Chroma Radiance 模型配置高级设置。它会将包装器附加到现有模型，并且仅在当前 sigma 值落在配置范围内时，在去噪过程中应用所选选项，从而控制 NeRF 瓦片大小和文本 token ID 处理。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要应用 Chroma Radiance 选项的模型 | MODEL | 是 | - |
| `保留包装器` | 启用后，如果存在现有的模型函数包装器，则会委托给它。通常应保持启用。（默认：True） | BOOLEAN | 否 | - |
| `起始sigma` | 这些选项生效的第一个 sigma 值。（默认：1.0） | FLOAT | 否 | 0.0 到 1.0 |
| `结束sigma` | 这些选项生效的最后一个 sigma 值。（默认：0.0） | FLOAT | 否 | 0.0 到 1.0 |
| `NeRF瓦片大小` | 允许覆盖默认的 NeRF 瓦片大小。-1 表示使用默认值（32）。0 表示使用非分块模式（可能需要大量 VRAM）。（默认：-1） | INT | 否 | -1 and above |
| `强制顺序文本ID` | 强制使用顺序文本 token ID 而非零。应用于 2026-05-22 至 2026-06-01 的检查点，这些检查点以这种方式训练，但状态字典中不包含 `__sequential__` 键。（默认：False） | BOOLEAN | 否 | - |

**注意：** Chroma Radiance 选项仅在当前 sigma 值落在 `end_sigma` 和 `start_sigma` 之间（包含边界）时生效。`nerf_tile_size` 选项仅在设置为 0 或更高值时才应用（值为 -1 时使用默认瓦片大小 32，并且不存储覆盖值）。`force_sequential_txt_ids` 选项仅在设置为 True 时才应用。当 `nerf_tile_size` 为 -1 且 `force_sequential_txt_ids` 为 False 时，不会配置任何选项，模型将原样返回，不应用任何包装器。

**注意：** 除 `model` 之外的所有输入都是高级选项。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model` | 应用了 Chroma Radiance 选项的模型；如果没有选项生效，则为未更改的模型 | MODEL |
