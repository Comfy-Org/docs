ImageAddNoise 节点会向输入图像添加随机噪声。它使用指定的随机种子来生成一致的噪声图案，并允许控制噪声效果的强度。生成的图像保持与输入相同的尺寸，但会增加视觉纹理。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `图像` | 将要添加噪声的输入图像 | IMAGE | 是 | - |
| `种子` | 用于创建噪声的随机种子（默认值：0）。此参数支持 “control after generate” 功能。 | INT | 是 | 0 到 18446744073709551615 |
| `强度` | 控制噪声效果的强度（默认值：0.5，步长：0.01） | FLOAT | 是 | 0.0 到 1.0 |

**注意：** 噪声值会添加到图像中，结果会被裁剪到 0.0–1.0 范围。如果输入图像具有 alpha 通道（4 个通道），则原始 alpha 通道保持不变——噪声仅应用于颜色通道。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `image` | 应用了添加噪声后的输出图像 | IMAGE |
