此节点使用 FLUX 3 延续现有的视频片段，使新片段从您提供的视频的最后一帧继续。它会上传您的源片段，将提示词和设置发送到生成服务，并在准备就绪后返回生成的续接视频。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `video` | 要延续的视频片段。 | VIDEO | 是 | 单个视频片段 |
| `prompt` | 续接内容应展示的内容；提示词会在生成前被解释和扩展。（默认：""） | STRING | 是 | 非空文本（最少 1 个字符） |
| `aspect_ratio` | 输出宽高比。'auto' 会根据提示词和输入自动选择一个。（默认："auto"） | STRING | 是 | 多个预定义选项（默认："auto"） |
| `duration` | 片段长度（秒）。'auto' 会根据内容自动调整长度。（默认："auto"） | STRING | 是 | "auto"（默认）<br />以秒为单位的数值 |
| `resolution` | 输出分辨率。（默认："720p"） | STRING | 是 | 多个预定义选项（默认："720p"） |
| `generate_audio` | 生成同步音频（环境声、语音、效果声）。关闭时生成不带音轨的视频。（默认：true） | BOOLEAN | 是 | true<br />false |
| `safety_tolerance` | 审核容忍度，0 为最严格。无论此处设置为何值，发送图像或视频的请求上限为 2。（高级参数，默认：2） | INT | 是 | 0 - 4（视频请求的有效上限：2） |
| `seed` | 用于确定节点是否应重新运行的种子；FLUX 3 会自行选择种子，因此无论此值如何，实际结果都是不确定的。（高级参数，默认：42） | INT | 是 | 0 - 4294967295 (0xFFFFFFFF) |

### 备注

- `prompt` 必须至少包含一个字符，否则生成会失败。虽然该字段默认为空字符串，但运行节点需要非空提示词。
- `safety_tolerance` 接受 0 到 4 之间的任意值，但由于此节点会向 API 发送视频，因此无论选择哪个值，有效容忍度上限均为 2。
- 当 `duration` 设置为数字时，会转换为整数秒。特殊值 "auto" 让服务根据内容调整长度。
- `aspect_ratio`、`duration` 和 `resolution` 的确切选项列表由节点内部定义。分辨率选项至少包括 "720p"（默认）和 "1080p"，后者使用不同的定价费率。
- 身份验证和节点标识字段（`auth_token_comfy_org`、`api_key_comfy_org`、`unique_id`）已隐藏，由平台自动处理。
