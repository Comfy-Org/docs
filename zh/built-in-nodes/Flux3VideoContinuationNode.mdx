此节点使用 FLUX 3 续写现有视频片段：新片段会从您提供视频的最后几帧继续。它会上传源片段，将提示词和设置发送到生成服务，并在完成后返回生成的续写视频。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `video` | 要继续的片段。 | VIDEO | 是 | 单个视频片段 |
| `prompt` | 续写内容应展示什么；在生成前会对提示词进行解释和扩展。（默认值：""） | STRING | 是 | 非空文本（至少 1 个字符） |
| `aspect_ratio` | 输出宽高比。"auto" 会根据提示词和输入选择一种。（默认值："auto"） | COMBO | 是 | "auto"（默认）<br />多个预定义选项 |
| `duration` | 片段长度，以秒为单位。"auto" 会根据内容调整长度。（默认值："auto"） | COMBO | 是 | "auto"（默认）<br />以秒为单位的数值 |
| `resolution` | 输出分辨率。（默认值："720p"） | COMBO | 是 | "720p"（默认）<br />"1080p"<br />其他预定义选项 |
| `generate_audio` | 生成同步音频（环境音、语音、音效）。关闭后生成无音轨的视频。（默认值：true） | BOOLEAN | 是 | true<br />false |
| `safety_tolerance` | 审核容忍度，0 为最严格。发送图像或视频的请求无论此处设置为何，上限均为 2。（高级参数，默认值：2） | INT | 是 | 0 - 4（视频请求的有效上限：2） |
| `seed` | 用于决定节点是否重新运行的种子；FLUX 3 会选择自己的种子，因此无论此值如何，实际结果都是不确定的。（默认值：42） | INT | 是 | 0 - 4294967295 (0xFFFFFFFF) |

### 说明

- `prompt` 必须至少包含一个字符，否则生成会失败。尽管该字段默认值为空字符串，但运行此节点需要提供非空提示词。
- `safety_tolerance` 接受 0 到 4 之间的任意值，但由于此节点会向 API 发送视频，因此无论选择何值，有效容忍度上限均为 2。
- 当 `duration` 设置为数字时，会转换为整数秒。特殊值 "auto" 会让服务根据内容调整长度。
- `aspect_ratio`、`duration` 和 `resolution` 的确切选项列表由节点内部定义。分辨率选项至少包括 "720p"（默认）和 "1080p"。定价根据所选的 `resolution` 和 `duration` 计算；"1080p" 按每秒 $0.7579 计费，其他分辨率按每秒 $0.5863 计费。
- `seed` 仅控制节点是否重新运行；它不会发送到生成服务。
- 身份验证和节点标识字段（`auth_token_comfy_org`、`api_key_comfy_org`、`unique_id`）是隐藏的，并由平台自动处理。
