此节点使用 FLUX 3 续接现有视频片段：新片段从您提供的视频的最后一帧继续。它会上传源视频片段，将提示词和设置发送至生成服务，并在就绪后返回生成的续接视频。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `video` | 要续接的视频片段。 | VIDEO | 是 | 单个视频片段 |
| `prompt` | 续接内容应展示的内容；该提示词会在生成前被解释和扩展。（默认：""） | STRING | 是 | 非空文本（至少 1 个字符） |
| `aspect_ratio` | 输出宽高比。“auto” 会根据提示词和输入自动选择一个。（默认："auto"） | COMBO | 是 | "auto"（默认）<br />多个预定义选项 |
| `duration` | 片段长度（秒）。“auto” 会根据内容自动匹配长度。（默认："auto"） | COMBO | 是 | "auto"（默认）<br />以秒为单位的数值 |
| `resolution` | 输出分辨率。（默认："720p"） | COMBO | 是 | "720p"（默认）<br />"1080p"<br />其他预定义选项 |
| `generate_audio` | 生成同步音频（环境声、语音、音效）。关闭后生成的视频将不包含音轨。（默认：true） | BOOLEAN | 是 | true<br />false |
| `safety_tolerance` | 审核宽容度，0 为最严格。发送图片或视频的请求，无论此处设置为何值，上限均为 2。（高级参数，默认：2） | INT | 是 | 0 - 4（视频请求的有效上限：2） |
| `seed` | 用于决定节点是否应重新运行的种子；FLUX 3 会自行选择种子，因此无论该值如何，实际结果都是非确定性的。（高级参数，默认：42） | INT | 是 | 0 - 4294967295 (0xFFFFFFFF) |

### 备注

- `prompt` 必须至少包含一个字符，否则生成会失败。虽然该字段默认是空字符串，但运行节点时仍需要提供非空的提示词。
- `safety_tolerance` 接受 0 到 4 之间的任意值，但由于此节点会向 API 发送视频，无论选择什么值，实际生效的宽容度上限均为 2。
- 当 `duration` 设置为数字时，会转换为整数秒。特殊值 "auto" 可让服务根据内容自动匹配长度。
- `aspect_ratio`、`duration` 和 `resolution` 的完整选项列表由节点内部定义。分辨率选项至少包括 "720p"（默认）和 "1080p"。价格根据所选的 `resolution` 和 `duration` 计算；"1080p" 按每秒 $0.7579 计费，其他分辨率按每秒 $0.5863 计费。
- 认证和节点标识字段（`auth_token_comfy_org`、`api_key_comfy_org`、`unique_id`）已隐藏，并由平台自动处理。
