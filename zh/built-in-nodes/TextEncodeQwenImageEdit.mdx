TextEncodeQwenImageEdit 节点将文本提示和可选图像转换为用于图像生成或编辑的条件数据。它使用 CLIP 模型对输入进行分词，并可选地使用 VAE 对参考图像进行编码以生成参考潜变量。当提供图像时，会自动调整其大小以保持一致的处理尺度。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 用于文本和图像分词的 CLIP 模型 | CLIP | 是 | - |
| `提示词` | 用于条件生成的文本提示，支持多行输入和动态提示 | STRING | 是 | - |
| `vae` | 可选 VAE 模型，用于将参考图像编码为潜变量 | VAE | 否 | - |
| `图像` | 可选的输入图像，用于参考或编辑目的 | IMAGE | 否 | - |

**注意：** 当提供图像时，会调整其大小，使其总像素数保持在 1,048,576（1024 × 1024）附近，并且仅使用其 RGB 通道。调整后的图像会与提示一起传递给 CLIP 分词器。当同时提供 `image` 和 `vae` 时，该节点还会将图像编码为参考潜变量，并将其附加到条件输出中。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `CONDITIONING` | 包含文本令牌和可选参考潜变量的条件数据，用于图像生成 | CONDITIONING |
