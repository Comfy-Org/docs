为 3D 网格生成 UV 图集。网格表面被分割为多个图块（chart），每个图块被展平为二维，展平后的图块被打包到 [0,1] 范围的 UV 图集中。图块接缝处的顶点会被复制，因此输出网格可能包含比输入网格更多的顶点。

## 输入

| 参数 | 说明 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `网格` | 要展开的输入网格。接受单个网格或一批网格。 | MESH | 是 | — |
| `分割器` | 用于图块划分的算法。`pec`：在 GPU 上使用的快速并行边折叠图块划分算法。`adaptive`：在 CPU 上运行，速度较慢。（默认值："pec"） | COMBO | 是 | "pec"<br />"adaptive" |
| `分辨率` | 用于纹素密度自动缩放的图集目标分辨率（0 = 适应内容大小）。（默认值：1024） | INT | 是 | 0 到 8192 (步长 256) |
| `边距` | 图块之间的纹素边距。（默认值：1） | INT | 是 | 0 到 16 |
| `weld_distance` | 重合顶点合并半径，以网格范围的比例表示（0 = 自动）。如果得到逐三角形的图块（输入网格未焊接），请将此值提高到约 0.001。（默认值：0.0） | FLOAT | 是 | 0.0 到 1.0 (步长 0.0001) |

注意：如果输入网格包含未焊接的顶点，节点可能会提示面邻接度较低，并生成逐面的 UV 图块；增大 `weld_distance` 可在展开前合并重合顶点。

## 输出

| 输出名称 | 说明 | 数据类型 |
|-------------|-------------|-----------|
| `网格` | 带有已生成 [0,1] 范围 UV 图集的输入网格。接缝顶点会被复制，因此输出顶点数可能超过输入网格。输入网格中的顶点颜色和纹理均会保留。 | MESH |
