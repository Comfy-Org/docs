为 3D 网格生成 UV 图集。网格表面会被分割成多个展开块（chart），每个展开块被展平到二维，随后这些展平后的展开块被打包到一个 [0,1] 范围的 UV 图集中。位于展开块接缝上的顶点会被复制（每个展开块一份，位置相同，但拥有各自的 UV），因此输出网格的顶点数可能多于输入网格，且输出面数可能与输入不同。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `网格` | 要展开的输入网格。接受单个网格或一批网格；批处理会逐个处理每一项。 | MESH | 是 | — |
| `分割器` | 要使用的展开块划分算法。`pec`：在 GPU 上执行快速并行边折叠的展开块划分。`adaptive`：CPU，速度较慢。（默认值："pec"） | COMBO | 是 | "pec"<br />"adaptive" |
| `分辨率` | 目标图集分辨率，用于纹素密度自动缩放（0 = 适配内容）。（默认值：1024） | INT | 是 | 0 到 8192 （步长：256） |
| `边距` | 展开块之间的纹素边距。（默认值：1） | INT | 是 | 0 到 16 |
| `weld_distance` | 重合顶点合并半径，表示为网格范围的比例（0 = 自动）。如果得到按三角形划分的展开块（未焊接的输入），请提高到约 0.001。（默认值：0.0） | FLOAT | 是 | 0.0 到 1.0 （步长：0.0001） |

注意：如果输入网格包含未焊接的顶点，此节点可能会警告面邻接性较低，并生成按面划分的 UV 展开块；增大 `weld_distance` 会在展开前合并重合顶点。退化面（复用相同顶点索引的面）会在处理过程中被丢弃。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mesh` | 输入网格，生成范围为 [0,1] 的 UV 图集。接缝顶点会被复制，因此输出顶点数可能超过输入。输入网格的顶点颜色和纹理会保留。 | MESH |
