生成 3D 网格的 UV 图集。曲面被分割为多个分片，每个分片展平为二维，然后将结果打包到 [0,1] UV 图集中。分片接缝处的顶点会被复制，因此输出网格可能包含比输入网格更多的顶点。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `网格` | 要展开的输入网格。接受单个网格或一批网格。 | MESH | 是 | — |
| `分割器` | 使用的分片算法。pec：GPU 上快速的平行边折叠分片算法。adaptive：CPU，较慢。（默认值：`"pec"`） | COMBO | 是 | `"pec"`<br />`"adaptive"` |
| `分辨率` | 用于纹素密度自动缩放的图集目标分辨率（0 表示自适应内容）。（默认值：1024） | INT | 是 | 0 到 8192（步长 256） |
| `边距` | 分片之间的纹素间距。（默认值：1） | INT | 是 | 0 到 16 |
| `weld_distance` | 重合顶点合并半径，以网格范围为比例（0 为自动）。如果得到按三角形拆分的分片（输入未焊接），请将其提高到约 0.001。（默认值：0.0） | FLOAT | 是 | 0.0 到 1.0（步长 0.0001） |

注意：如果输入网格包含未焊接的顶点（三角形汤），节点可能会提示面邻接性较低，并生成按面划分的 UV 分片；增大 `weld_distance` 会在展开前合并重合顶点。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `网格` | 带有生成的 [0,1] UV 图集的输入网格。接缝顶点会被复制，因此输出顶点数可能超过输入。输入网格的顶点颜色和纹理将保留。 | MESH |
