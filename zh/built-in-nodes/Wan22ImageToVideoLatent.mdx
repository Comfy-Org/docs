Wan22ImageToVideoLatent 根据图像创建视频潜空间表示。它生成具有指定宽度、高度、帧长度和批大小的空白视频潜空间，并可选地将起始图像序列编码到起始帧中。当提供了起始图像时，该节点将其编码到潜空间中，并创建相应的噪声掩码，标记生成过程中哪些区域应被去噪。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `VAE` | 用于将起始图像编码到潜空间中的 VAE 模型 | VAE | 是 | - |
| `宽度` | 输出视频的宽度（像素）（默认值：1280，步长：32） | INT | 是 | 32 to MAX_RESOLUTION |
| `高度` | 输出视频的高度（像素）（默认值：704，步长：32） | INT | 是 | 32 to MAX_RESOLUTION |
| `长度` | 视频序列中的帧数（默认值：49，步长：4） | INT | 是 | 1 to MAX_RESOLUTION |
| `批次大小` | 要生成的视频潜空间数量（默认值：1） | INT | 是 | 1 到 4096 |
| `起始图像` | 可选的起始图像序列，用于编码到视频潜空间的起始帧中（使用前 `length` 帧） | IMAGE | 否 | - |

**注意：** 当提供了 `start_image` 时，图像序列会被放大到目标 `width` 和 `height`，使用 VAE 编码，并放入潜空间的第一帧。这些帧的噪声掩码设置为 0（保留），而其余帧的掩码值为 1（待去噪）。潜空间始终有 48 个通道，空间维度为 `height / 16` × `width / 16`，时间维度为 `((length - 1) // 4) + 1`。`width` 和 `height` 必须能被 16 整除（通过步长 32 强制实现），`length` 以 4 为步长增加时间维度。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `samples` | 生成的视频潜空间表示，对批次中的每个项目重复 | LATENT |
| `noise_mask` | 噪声掩码，指示哪些区域应被去噪（值 1），哪些区域保留编码后的起始图像（值 0） | LATENT |

两个字段一起在单个 LATENT 输出中返回。
