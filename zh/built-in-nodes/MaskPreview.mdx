MaskPreview 节点会直接在 ComfyUI 界面中显示掩码数据的视觉预览，而不会将其保存到输出目录中。这样您就可以在工作流的任意位置检查确切的掩码值。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `遮罩` | 要预览的掩码数据 | MASK | 是 | - |
| `filename_prefix` | 预览文件名的前缀（默认值："ComfyUI"） | STRING | 否 | - |
| `prompt` | 用于元数据的提示信息（自动提供） | PROMPT | 否 | - |
| `extra_pnginfo` | 用于元数据的额外 PNG 信息（自动提供） | EXTRA_PNGINFO | 否 | - |

`prompt` 和 `extra_pnginfo` 输入是隐藏的，由 ComfyUI 系统自动提供；您无需手动连接它们。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mask` | 已预览的掩码数据，原样返回以供在工作流中进一步使用 | MASK |
