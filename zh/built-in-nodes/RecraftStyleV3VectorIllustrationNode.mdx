此节点为 Recraft API 选择一个风格，具体来说属于矢量插画（vector illustration）风格类别。你还可以选择性地在该类别下挑选一个更具体的子风格。此节点会输出一个风格配置对象，可传递给其他 Recraft 节点。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `substyle` | 矢量插画类别中更具体的风格。可用选项为 Recraft API 为 `vector_illustration` 风格定义的子风格。如果未选择子风格，则使用基础的 `vector_illustration` 风格。 | COMBO | 是 | 有多个可用选项（为 `vector_illustration` 风格动态加载的子风格列表） |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `recraft_style` | 一个 Recraft 风格配置对象，包含所选的矢量插画风格以及可选的子风格。可连接到其他 Recraft 节点。 | STYLEV3 |
