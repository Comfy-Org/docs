此节点将生成的图像与原始调整大小后的图像对齐，并应用可选的色彩校正。它接收 SeedVR2 放大处理的输出，并调整其以匹配原始参考图像的颜色和尺寸。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `images` | 要处理的生成图像。 | IMAGE | 是 | - |
| `original_resized_images` | 预处理前的原始调整大小图像，用作参考。 | IMAGE | 是 | - |
| `color_correction_method` | 使生成图像颜色与原始图像匹配的方法。lab：在 CIELAB 色彩空间中传递颜色，保留细节（最忠实）。wavelet：传递低频颜色，保留放大后的高频细节。adain：匹配每通道的均值/标准差（最快，全局色调）。none：跳过颜色传递（仅几何对齐）。（默认值："lab"） | COMBO | 是 | `"lab"`<br />`"wavelet"`<br />`"adain"`<br />`"none"` |

**注意：** 两个输入可以是 4 维（批次、高度、宽度、通道）或 5 维（批次、帧数、高度、宽度、通道）张量。节点会将两者裁剪到最小的批次、帧数、高度和宽度，因此它们不必完全匹配。输出的高度和宽度向下取整为偶数。如果参考图像带有 alpha 通道（4 通道），该 alpha 通道会被保留并应用到输出中。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `images` | 对齐并经过色彩校正后的图像。 | IMAGE |
