LTXVAddGuide 节点通过编码输入图像或视频，并将其作为关键帧合并到条件数据中，为潜在序列添加视频条件引导。它通过 VAE 编码器处理输入，并将生成的潜在表示策略性地放置到指定的帧位置，同时用关键帧信息更新正向和负向条件。该节点处理帧对齐约束，并允许控制条件影响的强度。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `正向` | 将使用关键帧引导修改的正向条件输入 | CONDITIONING | 是 | - |
| `负向` | 将使用关键帧引导修改的负向条件输入 | CONDITIONING | 是 | - |
| `vae` | 用于编码输入图像/视频帧的 VAE 模型 | VAE | 是 | - |
| `潜在空间` | 将接收条件帧的输入 latent 序列 | LATENT | 是 | - |
| `图像` | 用于对潜在视频进行条件约束的图像或视频。必须是 8*n + 1 帧。如果视频不是 8*n + 1 帧，则会被裁剪到最近的 8*n + 1 帧。 | IMAGE | 是 | - |
| `帧索引` | 开始条件约束的帧索引。对于单帧图像或 1-8 帧的视频，任何 frame_idx 值均可接受。对于 9 帧及以上的视频，frame_idx 必须可被 8 整除，否则将向下舍入到最接近的 8 的倍数。负值从视频末尾开始计数。（默认值：0） | INT | 是 | -9999 到 9999 |
| `强度` | 条件约束影响的强度，其中 1.0 表示完全应用条件约束，0.0 表示不应用条件约束（默认值：1.0） | FLOAT | 是 | 0.0 到 10.0 |
| `attention_mask` | 可选的像素空间掩码。通过自注意力控制每个区域的条件约束影响，并与 strength 相乘。 | MASK | 否 | - |
| `iclora_parameters` | 来自 Get IC-LoRA Parameters 节点的可选 IC-LoRA 参数。用于根据某些 IC-LoRA（例如 reference_downscale_factor > 1 的 IC-LoRA）的要求调整引导处理。当链接时，每个 LTXVAddGuide 仅使用连接到它的参数。 | IC_LORA_PARAMETERS | 否 | - |

**注意：** 输入图像/视频的帧数必须符合 8*n + 1 模式（例如 1、9、17、25 帧）。如果输入超出此模式，将自动裁剪到最接近的有效帧数。

**关于 `iclora_parameters` 的说明：** 当使用的 IC-LoRA 参数的 `reference_downscale_factor` 大于 1 时，潜在表示的空间尺寸（宽度和高度）必须能被该因子整除。如果不满足此条件，节点将引发错误。
