The LTXVAddGuide 节点通过 VAE 编码器对输入图像或视频进行编码，并将它们作为引导关键帧添加到潜空间视频序列中。它更新正向和负向条件，并返回修改后的潜空间，提供设置起始帧、条件强度、可选注意力掩码和可选 IC-LoRA 参数的选项。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `正向` | 用于通过关键帧引导进行修改的正向条件输入。 | CONDITIONING | 是 | - |
| `负向` | 用于通过关键帧引导进行修改的负向条件输入。 | CONDITIONING | 是 | - |
| `vae` | 用于编码输入图像/视频帧的 VAE 模型。 | VAE | 是 | - |
| `潜在空间` | 将接收条件帧的输入潜空间序列。 | LATENT | 是 | - |
| `图像` | 用于对潜空间视频进行条件化的图像或视频。必须为 8*n + 1 帧。如果视频不是 8*n + 1 帧，将裁剪到最接近的 8*n + 1 帧。 | IMAGE | 是 | - |
| `帧索引` | 开始条件化的帧索引。对于单帧图像或具有 1-8 帧的视频，任何 `frame_idx` 值均可接受。对于具有 9+ 帧的视频，`frame_idx` 必须能被 8 整除，否则将向下舍入到最接近的 8 的倍数。负值从视频末尾开始计数。默认值：0。 | INT | 是 | -9999 到 9999 |
| `强度` | 条件影响的强度，其中 1.0 应用完整条件化，0.0 不应用条件化。默认值：1.0。 | FLOAT | 是 | 0.0 到 10.0 |
| `attention_mask` | 可选的像素空间空间掩码。通过自注意力控制逐区域的条件影响，并乘以 `strength`。 | MASK | 否 | - |
| `iclora_parameters` | 可选的 IC-LoRA 参数，来自 Get IC-LoRA Parameters 节点。用于根据某些 IC-LoRA（例如 `reference_downscale_factor` > 1 的 IC-LoRA）的要求调整引导处理。当链式连接时，每个 LTXVAddGuide 仅使用连接到它的参数。 | IC_LORA_PARAMETERS | 否 | - |

**注意：** 输入图像/视频的帧数必须遵循 8*n + 1 模式（例如 1、9、17、25 帧）。如果输入超过此模式，将自动裁剪到最接近的有效帧数。

**关于 `iclora_parameters` 的注意：** 当使用 `reference_downscale_factor` 大于 1 的 IC-LoRA 参数时，潜空间维度（宽度和高度）必须能被该因子整除。如果不满足此条件，节点将引发错误。

**注意：** 编码后的引导帧必须在选定帧位置处适配于潜空间序列内。如果条件化帧超出潜空间序列的长度，节点将引发错误。

**注意：** 不支持向组合音频和视频通道的潜空间添加引导，否则将引发错误。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `positive` | 已更新关键帧引导信息的正向条件。 | CONDITIONING |
| `negative` | 已更新关键帧引导信息的负向条件。 | CONDITIONING |
| `latent` | 已纳入条件化帧并更新噪声掩码的潜空间序列。 | LATENT |
