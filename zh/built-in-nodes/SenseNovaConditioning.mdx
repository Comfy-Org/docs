为图像生成或交错文本与图像输出准备 SenseNova conditioning。`task` 选择器设置提示词模板和停止行为，节点会报告模型是否请求图像，从而让循环知道何时运行采样器。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `clip` | SenseNova CLIP 模型。请连接同时供给 CLIP Text Encode 的 CLIP 加载器，编码器的输出接到 `conditioning`。除传入的 conditioning 已完成外，每个任务都必需。 | CLIP | 否 | - |
| `conditioning` | 来自 CLIP Text Encode 的 SenseNova 文本 conditioning。 | CONDITIONING | 是 | - |
| `negative` | 可选的负面 conditioning。对于 `interleave` 和 `self-correction` 任务，它会被更新并返回。 | CONDITIONING | 否 | - |
| `task` | 要运行的任务。`"image"` 为标准采样器编码提示词，`"image thinking"` 让模型在回答前思考，`"interleave"` 在一次处理中生成文本和图像，`"self-correction"` 让模型修正自己之前的输出。 | DYNAMIC_COMBO | 是 | `"image"`<br />`"image thinking"`<br />`"interleave"`<br />`"self-correction"` |
| `max_tokens` | 本次调用期间生成的最大 token 数。默认：1024。 | INT | 是 | 1 到 8192 |

### `interleave` 输入

当 `task` 设置为 `"interleave"` 时，这些输入会出现。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `thinking` | 让模型在回答前思考。默认：True。 | BOOLEAN | 是 | True<br />False |
| `samples` | 之前的采样器输出，在图像请求之后继续时连接。 | LATENT | 否 | - |

### `self-correction` 输入

当 `task` 设置为 `"self-correction"` 时，这些输入会出现。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `samples` | 之前的采样器输出，在图像请求之后继续时连接。 | LATENT | 否 | - |

**约束与行为：**

* `clip` 输入接收 SenseNova CLIP 模型本身，而不是 CLIP Text Encode 的输出（那是 `CONDITIONING`）。`clip` 缺失或不是 SenseNova CLIP 时，节点会报错。
* `"image thinking"` 需要恰好一个正面 conditioning 条目；`"interleave"` 和 `"self-correction"` 需要一个正面和一个负面条目。
* 当模型正在等待图像时，将前一个采样器的 LATENT 输出连接到 `samples`。在请求图像之前传入 `samples` 是错误的。
* 当传入的 conditioning 已经完成时，节点会原样返回它，`generated_text` 为空，`image_requested` 设置为 False。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `conditioning` | 用于采样器的 conditioning，已用本次调用生成的文本扩展。 | CONDITIONING |
| `generated_text` | 本次调用生成的文本。完整结果请使用 SenseNova Interleave Decode。 | STRING |
| `negative` | 为 `interleave` 和 `self-correction` 任务更新的负面 conditioning。 | CONDITIONING |
| `image_requested` | 当模型请求图像时为 True：运行采样器，然后将循环重新输入此节点。 | BOOLEAN |
