SaveLatent 将潜在张量以 `.latent` 文件形式保存到磁盘，以便后续复用或共享。它接收潜在样本，以自动生成的名称将其写入输出文件夹，并可嵌入工作流元数据（如提示词）到保存的文件中。相同的潜在样本也会原样传递，以供进一步处理。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `Latent` | 要保存到磁盘的潜在样本。 | LATENT | 是 | - |
| `文件名前缀` | 用于构建输出文件名的前缀。可包含子文件夹，例如 "latents/ComfyUI"（默认："latents/ComfyUI"）。 | STRING | 是 | - |
| `prompt` | 工作流提示词，序列化为 JSON 并存储在保存的文件元数据中（隐藏参数，自动提供）。 | PROMPT | 否 | - |
| `extra_pnginfo` | 额外工作流信息，序列化为 JSON 并存储在保存的文件元数据中（隐藏参数，自动提供）。 | EXTRA_PNGINFO | 否 | - |

注意：每个保存的文件使用前缀和 5 位计数器命名，例如 `ComfyUI_00001_.latent`，并放置在输出目录中。文件包含潜在张量和潜在格式版本标记。仅当元数据支持启用时（即 ComfyUI 未使用 `--disable-metadata` 选项启动），元数据才会嵌入到保存的文件中。

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `samples` | 与输入相同的潜在样本，原样传递，不做任何更改。 | LATENT |
| `ui` | 界面显示数据，描述所保存文件的信息：文件名、子文件夹和输出类型（"output"）。 | UI |
