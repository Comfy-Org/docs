此节点创建一个空白的潜空间张量，其格式专为 HunyuanVideo 1.5 模型而设计。它通过分配一个通道数和空间维度均符合该模型潜空间要求的零张量，为视频生成生成一个空白起点。

## 输入

| 参数 | 说明 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `宽度` | 视频帧的宽度（以像素为单位）。 | INT | 是 | - |
| `高度` | 视频帧的高度（以像素为单位）。 | INT | 是 | - |
| `时长` | 视频序列中的帧数。 | INT | 是 | - |
| `批次大小` | 一批中生成的视频样本数量（默认值：1）。 | INT | 否 | - |

**注意：** 生成的潜空间张量的空间维度通过将输入的 `width` 和 `height` 除以 16 来计算。时间维度（帧数）的计算公式为 `((length - 1) // 4) + 1`。这些计算使用整数除法，因此 `width` 和 `height` 应为 16 的倍数，以避免截断。

## 输出

| 输出名称 | 说明 | 数据类型 |
| --- | --- | --- |
| `samples` | 一个空白的潜空间张量，其维度适用于 HunyuanVideo 1.5 模型。该张量的形状为 `[batch_size, 32, frames, height//16, width//16]`。输出还包含一个值为 16 的 `downscale_ratio_spacial`。 | LATENT |
