此节点创建一个专为与 HunyuanVideo 1.5 模型配合使用而格式化好的空 latent 张量。它通过为模型的 latent 空间分配一个具有正确通道数和空间维度的全零张量，为视频生成创建一个空白起点。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `宽度` | 视频帧的宽度（以像素为单位）。 | INT | 是 | - |
| `高度` | 视频帧的高度（以像素为单位）。 | INT | 是 | - |
| `时长` | 视频序列中的帧数。 | INT | 是 | - |
| `批次大小` | 一批中要生成的视频样本数量（默认：1）。 | INT | 否 | - |

**注意：** 生成的 latent 张量的空间维度通过将输入的 `width` 和 `height` 除以 16 来计算（此节点使用 16 的空间缩放因子，而不是 8）。时间维度（帧数）按 `((length - 1) // 4) + 1` 计算。这些计算使用整数除法，因此 `width` 和 `height` 应为 16 的倍数，以避免截断。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `samples` | 一个空 latent 张量，其维度适用于 HunyuanVideo 1.5 模型。该张量的形状为 `[batch_size, 32, ((length - 1) // 4) + 1, height // 16, width // 16]`。输出还包含一个值为 16 的 `downscale_ratio_spacial`。 | LATENT |
