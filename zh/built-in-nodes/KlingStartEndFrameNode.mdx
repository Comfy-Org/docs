此节点创建一段视频序列，在您提供的起始图像和结束图像之间进行过渡。它会生成中间的所有帧，从而产生从第一帧到最后一帧的平滑变换。此节点调用 image-to-video API，但仅支持可与 `image_tail` 请求字段配合使用的输入选项。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `起始帧` | 参考图像 - URL 或 Base64 编码字符串，不能超过 10MB，分辨率不低于 300*300px，宽高比在 1:2.5 ~ 2.5:1 之间。Base64 不应包含 data:image 前缀。 | IMAGE | 是 | - |
| `end_frame` | 参考图像 - 结束帧控制。URL 或 Base64 编码字符串，不能超过 10MB，分辨率不低于 300*300px。Base64 不应包含 data:image 前缀。 | IMAGE | 是 | - |
| `提示词` | 正向文本提示词。不能为空，且不能超过 500 个字符。 | STRING | 是 | - |
| `负面提示词` | 负向文本提示词。不能超过 500 个字符。如果留空，则从请求中省略。 | STRING | 是 | - |
| `CFG` | 控制提示词引导的强度（默认值：0.5）。 | FLOAT | 是 | 0.0-1.0 |
| `宽高比` | 生成视频的宽高比（默认值："16:9"）。 | COMBO | 是 | "16:9"<br />"9:16"<br />"1:1" |
| `模式` | 用于视频生成的配置，格式为：mode / duration / model_name。（默认值："pro mode / 5s duration / kling-v2-5-turbo"） | COMBO | 是 | "pro mode / 5s duration / kling-v2-5-turbo"<br />"pro mode / 10s duration / kling-v2-5-turbo" |

**图像约束：**

- `start_frame` 和 `end_frame` 均为必填项，且文件大小不能超过 10MB。
- 两张图像的最小分辨率：300×300 像素。
- `start_frame` 的宽高比必须在 1:2.5 到 2.5:1 之间。
- Base64 编码图像不应包含 "data:image" 前缀。

**提示词约束：**

- `prompt` 不能为空，且不能超过 500 个字符。
- `negative_prompt` 不能超过 500 个字符；留空时，不会随请求发送。

**模式说明：**

- 两个模式选项均使用 pro mode 和 kling-v2-5-turbo 模型，仅在时长上不同（5 秒或 10 秒）。
- 每次生成的定价，如节点价格徽章所示：5s 模式费用为 $0.35 USD，10s 模式费用为 $0.70 USD。
