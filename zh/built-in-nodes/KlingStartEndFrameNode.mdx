此节点创建一个在您提供的开始图像和结束图像之间过渡的视频序列。它生成中间的所有帧，以产生从第一帧到最后一帧的平滑变换。该节点调用图像转视频 API，但仅支持与 `image_tail` 请求字段兼容的输入选项。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `起始帧` | 参考图像 - URL 或 Base64 编码字符串，不能超过 10MB，分辨率不低于 300*300px，宽高比在 1:2.5 ~ 2.5:1 之间。Base64 不应包含 data:image 前缀。 | IMAGE | 是 | - |
| `end_frame` | 参考图像 - 结束帧控制。URL 或 Base64 编码字符串，不能超过 10MB，分辨率不低于 300*300px。Base64 不应包含 data:image 前缀。 | IMAGE | 是 | - |
| `提示词` | 正向文本提示词。不得为空，且不能超过 500 个字符。 | STRING | 是 | - |
| `负面提示词` | 负向文本提示词。不能超过 500 个字符。如果留空，则在请求中省略。 | STRING | 是 | - |
| `CFG` | 控制提示词引导的强度（默认：0.5） | FLOAT | 是 | 0.0-1.0 |
| `宽高比` | 生成视频的宽高比（默认："16:9"） | COMBO | 是 | "16:9"<br />"9:16"<br />"1:1" |
| `模式` | 用于视频生成的配置，格式为：mode / duration / model_name。（默认："pro mode / 5s duration / kling-v2-5-turbo"） | COMBO | 是 | "pro mode / 5s duration / kling-v2-5-turbo"<br />"pro mode / 10s duration / kling-v2-5-turbo" |

**图像约束：**

- `start_frame` 和 `end_frame` 均为必填项，文件大小不能超过 10MB。
- 两张图像的最低分辨率均为：300×300 像素。
- `start_frame` 的宽高比必须在 1:2.5 到 2.5:1 之间。
- Base64 编码图像不应包含 "data:image" 前缀。

**提示词约束：**

- `prompt` 不得为空，且不能超过 500 个字符。
- `negative_prompt` 不能超过 500 个字符；为空时不会随请求发送。

**模式说明：**

- 两种模式选项均使用 pro 模式和 kling-v2-5-turbo 模型，仅时长不同（5 秒或 10 秒）。
- 每次生成的定价，如节点的价格标签所示：5s 模式费用为 0.35 美元，10s 模式费用为 0.70 美元。
