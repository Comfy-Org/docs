此节点根据文字描述创建一个新的 Breeze 音色。请提供音色描述以及让其朗读的一句话；音色将基于该预听内容构建，并保存到你的账户中。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `description` | 对音色的描述，3 到 500 个字符：年龄、性别、口音、语气、语速。默认：空。 | STRING | 是 | 3 到 500 个字符 |
| `preview_text` | 新音色在预听中朗读的句子，最多 500 个字符。请使用所选语言书写，因为音色是基于这段预听内容构建的。默认：空。 | STRING | 是 | 1 到 500 个字符 |
| `language` | 预听文本的语言。English 和 Chinese 可使用任一模型；其他语言使用 Breeze TTS 2 Multilingual。 | DYNAMIC_COMBO | 是 | 多个可用选项 |
| `strength` | 音色遵循描述的程度。默认：4.0。 | FLOAT | 否 | 1.0 到 10.0（步长：0.1） |
| `seed` | 控制节点是否重新运行；无论种子如何，结果都是不确定的。默认：42。 | INT | 否 | 0 到 2147483647 |

### 语言为 "English" 和 "Chinese" 时的输入

仅当 `language` 为 English 或 Chinese 时显示。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | `Breeze TTS 2` 或 `Breeze TTS 2 Multilingual`。默认：`"Breeze TTS 2"`。 | COMBO | 是 | `"Breeze TTS 2"`<br />`"Breeze TTS 2 Multilingual"` |

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `voice` | 新的 Breeze 音色，以描述命名。 | BREEZE_VOICE |
| `preview` | 所设计音色的音频预听。 | AUDIO |
