读取图像或视频 latent，并返回其宽度、高度、帧数和批次大小，以便无需解码 latent 即可复用其几何信息。可用它来确定噪声遮罩的尺寸、对齐分辨率，或在平铺采样器时计算重叠区域。测量值也会直接显示在节点本身上。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `latent` | 要检查的图像或视频 latent。当 latent 包含多个流时，将测量第一个流。 | LATENT | 是 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `width` | latent 的宽度，以 latent 单元而非像素为单位。 | INT |
| `height` | latent 的高度，以 latent 单元而非像素为单位。 | INT |
| `frames` | latent 中的帧数。图像 latent 只有一帧。 | INT |
| `batch_size` | 批次中的 latent 数量。 | INT |
