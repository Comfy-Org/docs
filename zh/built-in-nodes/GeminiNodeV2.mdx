使用 Google 的 Gemini 模型生成文本回复。提供一个文本提示词，并可选地提供一个或多个图像、音频片段、视频或文件作为多模态上下文。此节点会将提示词及任何附加的媒体发送给所选模型，并返回模型的文本回答。

**注意：** 此节点在源代码中已被标记为弃用。

## 输入

### 通用输入

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于生成回复的 Gemini 模型。选择某个模型后，下方会显示该模型自身的一组输入。 | DYNAMIC_COMBO | 是 | `"Gemini 3.8 Flash"`<br />`"Gemini 3.7 Flash"`<br />`"Gemini 3.5 Flash"`<br />`"Gemini 3.1 Pro"`<br />`"Gemini 3.1 Flash-Lite"` |
| `prompt` | 输入给模型的文本。可包含详细说明、问题或上下文。（默认值：""） | STRING | 是 | 必须包含至少一个非空白字符 |
| `seed` | 采样种子。设为 0 表示随机种子。不保证输出具有确定性。（默认值：42） | INT | 是 | 0 至 2147483647 |
| `system_prompt` | 用于规定模型行为的基础指令。（默认值：""） | STRING | No |  |

### 媒体与文件输入

以下输入由所有模型共享，并与各模型专属输入一同显示。

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `images` | 可扩展插槽：连接 1 至 16 张图像（`image_1` ... `image_16`）。可选的图像，用作模型的上下文。最多 16 张图像。 | IMAGE | No | 0 至 16 张图像 |
| `audio` | 可扩展插槽：连接一个音频片段（`audio_1`）。可选的音频片段，用作模型的上下文。 | AUDIO | No | 0 至 1 个片段 |
| `video` | 可扩展插槽：连接一个视频片段（`video_1`）。可选的视频片段，用作模型的上下文。 | VIDEO | No | 0 至 1 个片段 |
| `files` | 可选的文件，用作模型的上下文。接受来自 Gemini Input Files 节点的输入。 | GEMINI_INPUT_FILES | No |  |

**注意：** 当附加媒体（图像、音频或视频）时，此节点会将前 10 个媒体项上传至 ComfyAPI 存储，并以 URL 的形式传递它们；该 URL 配额由所有媒体类型共享，并按顺序消耗（先是视频，然后是音频，最后是图像）。其余媒体将以 base64 数据的形式内联编码，内联负载合计最大为 18 MB。如果内联负载超过 18 MB，此节点会报错。`prompt` 参数必须包含至少一个非空白字符。将 `seed` 设为 0 表示请求随机种子。
