ImageOnlyCheckpointSave 节点保存包含模型、CLIP 视觉编码器和 VAE 的 checkpoint 文件。它使用指定的文件名前缀创建一个 safetensors 文件，并将其存储在输出目录中。该节点专为将图像相关的模型组件一起保存到单个 checkpoint 文件而设计。

## 输入
| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `模型` | 要保存在 checkpoint 中的模型 | MODEL | 是 | - |
| `clip视觉` | 要保存在 checkpoint 中的 CLIP 视觉编码器 | CLIP_VISION | 是 | - |
| `vae` | 要保存在 checkpoint 中的 VAE（变分自动编码器） | VAE | 是 | - |
| `文件名前缀` | 输出文件名的前缀（默认值："checkpoints/ComfyUI"） | STRING | 是 | - |
| `prompt` | 用于工作流提示数据的隐藏参数 | PROMPT | No | - |
| `extra_pnginfo` | 附加的 PNG 元数据 | EXTRA_PNGINFO | No | - |

## 输出
| Output Name | Description | Data Type |
| --- | --- | --- |
| - | 此节点不返回任何输出 | - |
