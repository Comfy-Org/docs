此节点用于保存一个检查点文件，将模型与其 CLIP 视觉编码器和 VAE 打包在一起。该文件以 safetensors 格式写入输出目录，并使用给定的文件名前缀，从而可以将模型的图像相关组件作为单个检查点进行存储。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要保存在检查点中的模型 | MODEL | 是 | - |
| `clip视觉` | 要保存在检查点中的 CLIP 视觉编码器 | CLIP_VISION | 是 | - |
| `vae` | 要保存在检查点中的 VAE（变分自编码器） | VAE | 是 | - |
| `文件名前缀` | 输出文件名的前缀（默认："checkpoints/ComfyUI"） | STRING | 是 | - |
| `prompt` | 接收工作流提示数据的隐藏参数 | PROMPT | 否 | - |
| `extra_pnginfo` | 接收额外 PNG 元数据的隐藏参数 | EXTRA_PNGINFO | 否 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| - | 此节点不返回任何输出 | - |
