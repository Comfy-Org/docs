Smooth SAM3D Body Pose Data 节点通过对运动进行时间平均，减少 3D 身体姿态序列中的逐帧抖动。它对相机数据和外观数据应用完全平滑，同时在主体快速旋转时降低对网格几何体的平滑程度，因此快速旋转不会被压平。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `mhr_pose_data` | 要平滑的 MHR 姿态数据序列，包含模型参数、形状参数、表情参数、MHR70 关键点布局以及相关网格数据。 | MHR_POSE_DATA | 是 | — |
| `强度` | 平滑强度。0 = 原始，1 = 平滑。（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0 (step 0.05) |
| `方法` | gaussian：对称加权平均，最佳通用平滑器。<br />savgol：滑动多项式拟合，可保留尖锐峰值。（默认值："savgol"） | COMBO | 是 | "gaussian"<br />"savgol" |
| `窗口` | 时间窗口（以帧为单位，取奇数值）。（默认值：7） | INT | 是 | 1 到 51 (odd values, step 2) |
| `旋转阈值（度）` | 为保留快速旋转，当根节点旋转速率（度/帧）达到此值时禁用平滑。30° 适合大多数内容；较低的值可能会对普通抖动禁用平滑，并在不知不觉中影响质量。0 = 禁用。（默认值：30.0） | FLOAT | 是 | 0.0 到 90.0 (step 1.0) |

注意：当 `strength` 为 0.0 或更低，或 `window` 为 1 或更低时，节点将原样返回输入数据。输入必须至少包含 2 帧数据和关键点数据；否则节点将原样返回输入数据。当 `rotation_threshold_degrees` 为 0.0 时，基于旋转的平滑回退机制将被禁用。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mhr_pose_data` | 平滑后的 MHR 姿态数据序列，逐帧抖动已减少。 | MHR_POSE_DATA |
