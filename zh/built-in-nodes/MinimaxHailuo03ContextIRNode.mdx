此节点使用 MiniMax H3 Context IR 分析您的文本描述和任何附加媒体，然后生成一个更强、结构化的视频提示。返回的提示旨在连接到 MiniMax H3 视频节点的 `prompt` 输入；如果在那里附加媒体，请以相同的顺序附加相同的媒体，因为增强后的提示会按位置引用媒体。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于提示增强的模型。 | COMBO | 是 | `"MiniMax H3"` |
| `prompt` | 您打算生成的视频的描述。不能为空。（默认：`""`） | STRING | 是 | 任意文本 |
| `duration` | 您打算生成的视频的时长，以秒为单位（4-15）。（默认：5） | INT | 是 | 4 到 15 |
| `ratio` | 您打算生成的视频的宽高比。`"adaptive"` 需要至少一个图像、视频或音频输入。（默认：`"adaptive"`） | COMBO | 是 | `"adaptive"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"` |
| `reference_images` | 主题或风格参考图像，按连接顺序在提示中称为“Image 1”至“Image 9”。最多 9 张图像。 | IMAGE | 否 | 0 到 9 张图像 |
| `reference_videos` | 运动或场景参考视频，按连接顺序在提示中称为“Video 1”至“Video 3”。最多 3 个视频，每个 2-15 秒，总时长不超过 15 秒。 | VIDEO | 否 | 0 到 3 个视频 |
| `reference_audios` | 音频参考，按连接顺序在提示中称为“Audio 1”至“Audio 3”。最多 3 个片段，每个 2-15 秒，总时长不超过 15 秒。如果没有参考图像或参考视频，则无法使用。 | AUDIO | 否 | 0 到 3 个片段 |
| `first_frame` | 您打算生成的视频的首帧。不能与参考媒体组合使用。 | IMAGE | 否 | 单张图像 |
| `last_frame` | 您打算生成的视频的末帧。不能与参考媒体组合使用。 | IMAGE | 否 | 单张图像 |

### 参数约束

- `prompt`、`duration`、`ratio`、`reference_images`、`reference_videos` 和 `reference_audios` 输入属于 `model` 选项组。
- `first_frame` 和 `last_frame` 不能与任何参考媒体组合使用。
- 除非同时连接至少一个 `reference_image` 或 `reference_video`，否则不能使用 `reference_audios`。
- 当未连接任何帧且未连接任何参考媒体时，`ratio` 不能设置为 `"adaptive"`。
- 每个参考视频的时长必须约为 2-15 秒，总时长不超过 15 秒。其帧率必须介于 23.9 到 60.5 FPS 之间。
- 每个参考音频的时长必须约为 2-15 秒，总时长不超过 15 秒。
- `first_frame`、`last_frame` 以及每张参考图像必须至少为 256x256 像素，且宽高比在 0.4 到 2.5 之间。
