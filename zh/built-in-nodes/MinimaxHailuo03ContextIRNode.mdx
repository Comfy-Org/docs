此节点使用 MiniMax H3 Context IR 分析您的文本描述及任何附加媒体，然后生成一个更强大、结构化的视频提示词。返回的提示词设计用于连接到 MiniMax H3 视频节点的 prompt 输入；如果在那里附加媒体，请以相同顺序附加相同媒体，因为增强后的提示词按位置引用媒体。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于提示词增强的模型。 | DYNAMIC_COMBO | 是 | `"MiniMax H3"` |
| `first_frame` | 您计划生成的视频的首帧。不能与参考媒体组合使用。 | IMAGE | 否 | 单张图像 |
| `last_frame` | 您计划生成的视频的末帧。不能与参考媒体组合使用。 | IMAGE | 否 | 单张图像 |

### MiniMax H3 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 您计划生成的视频的描述。不能为空。（默认：`""`） | STRING | 是 | 任意文本（不能为空） |
| `duration` | 您计划生成的视频的时长（秒）（4-15）。（默认：5） | INT | 是 | 4 到 15 |
| `ratio` | 您计划生成的视频的宽高比。`"adaptive"` 需要至少一个图像、视频或音频输入。（默认：`"adaptive"`） | COMBO | 是 | `"adaptive"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"` |

### 参考输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 主题或风格参考图像，在提示词中按连接顺序称为 "Image 1" 至 "Image 9"。最多 9 张图像。可增长插槽：连接 `image_1`...`image_9`。 | IMAGE | 否 | 0 到 9 张图像 |
| `reference_videos` | 动作或场景参考视频，在提示词中按连接顺序称为 "Video 1" 至 "Video 3"。最多 3 个视频，每个 2-15 秒，总计 15 秒。可增长插槽：连接 `video_1`...`video_3`。 | VIDEO | 否 | 0 到 3 个视频 |
| `reference_audios` | 音频参考，在提示词中按连接顺序称为 "Audio 1" 至 "Audio 3"。最多 3 个片段，每个 2-15 秒，总计 15 秒。没有参考图像或视频时不能使用。可增长插槽：连接 `audio_1`...`audio_3`。 | AUDIO | 否 | 0 到 3 个片段 |

### 参数约束

- `prompt`、`duration`、`ratio`、`reference_images`、`reference_videos` 和 `reference_audios` 输入属于 `model` 选项组的一部分，并在选择“MiniMax H3”时显示。
- `first_frame` 和 `last_frame` 不能与任何参考媒体组合使用。
- 除非至少连接了一个 `reference_image` 或 `reference_video`，否则不能使用 `reference_audios`。
- 当未连接任何帧和参考媒体时，`ratio` 不能设置为 `"adaptive"`。
- 参考视频每个必须约为 2-15 秒，总时长不超过 15 秒。其帧速率必须在 23.9 到 60.5 FPS 之间。
- 参考音频每个必须约为 2-15 秒，总时长不超过 15 秒。
- `first_frame`、`last_frame` 和每个参考图像必须至少为 256x256 像素，并且宽高比在 0.4 到 2.5 之间。
