自定义组合节点允许您使用自己的文本选项列表创建自定义下拉菜单。该节点是一个专注于前端的节点，同时包含后端表示以保持工作流兼容性。当您从下拉菜单中选择一个选项时，节点会将该文本作为字符串及其索引位置输出。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `选择` | 从自定义下拉菜单中选择的文本选项。可用选项列表由用户在前端界面中定义。 | COMBO | 是 | 用户定义 |
| `index` | 可用于指定索引的整数值。默认值：0。 | INT | 否 | 任意整数（默认值：0） |

**注意：** 该节点输入的验证功能被有意禁用。这允许您在前端编写任意自定义文本选项，而无需后端检查您的选择是否匹配预定义列表。除组合下拉菜单外的其他组件完全在前端定义。此节点被标记为实验性。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `STRING` | 从自定义组合框中选择的选项的文本字符串。 | STRING |
| `索引` | 所选选项在下拉列表中的索引位置。 | INT |
