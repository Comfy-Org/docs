Custom Combo 节点允许你为下拉菜单定义自己的文本选项列表，而不是从固定值中选择。它是以前端为重点的节点，同时也具有后端表示，因此包含它的工作流可保持兼容。当你选择一个选项时，该节点会输出所选文本及其索引位置。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `选择` | 从自定义下拉菜单中选择的文本选项。可用选项列表由用户在节点的前端界面中定义。 | COMBO | 是 | User-defined |
| `index` | 一个整数值，可用于指定索引。默认：0。 | INT | 否 | Any integer (default: 0) |

**注意：** 此节点输入的验证被有意禁用。这允许你在前端编写任意自定义文本选项，而后端不会检查你的选择是否与预定义列表匹配。除 combo 下拉菜单以外的控件完全在前端定义。此节点被标记为实验性。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `STRING` | 从自定义组合框中所选选项的文本字符串。 | STRING |
| `INDEX` | 所选选项在下拉列表中的索引位置。 | INT |
