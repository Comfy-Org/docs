SaveLoRA 节点将 LoRA（低秩自适应）模型保存到文件中。它接收一个 LoRA 模型作为输入，并将其写入输出目录下的 `.safetensors` 文件。您可以指定文件名前缀和可选的步数，以包含在最终文件名中。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `LoRA` | 要保存的 LoRA 模型。请勿使用已带有 LoRA 层的模型。 | LORA_MODEL | 是 | N/A |
| `前缀` | 用于保存的 LoRA 文件的前缀（默认值："loras/ComfyUI_trained_lora"）。 | STRING | 是 | N/A |
| `步数` | 可选：LoRA 已训练的步数，用于命名保存的文件。 | INT | 否 | N/A |

**注意：** `lora` 输入必须是纯 LoRA 模型。请勿提供已应用 LoRA 层的基础模型。

**注意：** 文件将以 `.safetensors` 扩展名保存到 ComfyUI 输出目录中。文件名由 `prefix` 和零填充计数器（5 位数字）组成，以避免覆盖现有文件。当提供 `steps` 时，步数也会包含在文件名中（例如，1000 步对应 `1000_steps`）。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| *None* | 此节点不会向工作流输出任何数据。它是一个将文件保存到磁盘的输出节点。 | N/A |
