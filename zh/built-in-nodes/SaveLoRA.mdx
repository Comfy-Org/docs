SaveLoRA 节点将 LoRA（低秩适应）模型保存到文件中。它接收一个 LoRA 模型作为输入，并将其写入输出目录中的 `.safetensors` 文件。你可以指定文件名前缀以及可选的步数，步数将包含在最终文件名中。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `LoRA` | 要保存的 LoRA 模型。不要使用带有 LoRA 层的模型。 | LORA_MODEL | 是 | N/A |
| `前缀` | 保存的 LoRA 文件使用的前缀（默认："loras/ComfyUI_trained_lora"）。 | STRING | 是 | N/A |
| `步数` | 可选：LoRA 已训练的步数，用于命名保存的文件。 | INT | 否 | N/A |

**注意：** `lora` 输入必须是纯 LoRA 模型。不要提供已经应用了 LoRA 层的基础模型。

**注意：** 文件保存在 ComfyUI 输出目录中，扩展名为 `.safetensors`。文件名由 `prefix` 和一个补零计数器（5 位数字）构成，以避免覆盖现有文件。提供 `steps` 时，步数也会包含在文件名中（例如，1000 步对应 `1000_steps`）。

**注意：** 此节点标记为实验性。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| *None* | 此节点不向工作流输出任何数据。它是一个将文件保存到磁盘的输出节点。 | N/A |
