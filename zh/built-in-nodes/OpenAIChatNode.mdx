此节点从 OpenAI 模型生成文本响应。它会将您的文本提示，以及可选的图像或文件，发送到 OpenAI 模型，并返回生成的文本响应。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 模型的文本输入，用于生成响应（默认：空字符串）。 | STRING | 是 | - |
| `保持上下文` | 此参数已弃用且无任何效果（默认：False）。 | BOOLEAN | 是 | - |
| `模型` | 用于生成响应的模型（默认：`gpt-5`） | COMBO | 是 | `gpt-6-astra`<br />`gpt-6-sol`<br />`gpt-6-luna`<br />`gpt-5.6-sol`<br />`gpt-5.6-terra`<br />`gpt-5.6-luna`<br />`gpt-5.5-pro`<br />`gpt-5.5`<br />`gpt-5`<br />`gpt-5-mini`<br />`gpt-5-nano`<br />`gpt-4.1`<br />`gpt-4.1-mini`<br />`gpt-4.1-nano`<br />`o4-mini`<br />`o3`<br />`o1-pro`<br />`o1` |
| `图像` | 可选的图像，用作模型的上下文。要包含多张图像，可以使用 Batch Images 节点。 | IMAGE | 否 | - |
| `文件` | 可选的文件，用作模型的上下文。接受来自 OpenAI Chat Input Files 节点的输入。 | OPENAI_INPUT_FILES | 否 | - |
| `高级设置` | 可选的模型配置。接受来自 OpenAI Chat Advanced Options 节点的输入。 | OPENAI_CHAT_CONFIG | 否 | - |

注意：当连接了设置推理强度的 `advanced_options` 配置时，所选的 `model` 必须支持该强度值。例如，gpt-4.1 系列模型不支持任何推理强度，`gpt-6-sol` 和 `gpt-6-luna` 支持 none、low、medium、high、xhigh 和 max，`gpt-5.5` 支持 none、low、medium、high 和 xhigh，而 `gpt-5.5-pro` 支持 medium、high 和 xhigh。如果所选模型不支持该推理强度，此节点将抛出错误。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output_text` | 由 OpenAI 模型生成的文本响应。 | STRING |
