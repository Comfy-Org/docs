此节点从 OpenAI 模型生成文本响应。它会将您的文本提示（可选地附带图像或文件）发送到 OpenAI 模型，并返回生成的文本响应。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 发送给模型的文本输入，用于生成响应（默认：空） | STRING | 是 | - |
| `保持上下文` | 此参数已弃用，不产生任何效果（默认：False） | BOOLEAN | 是 | - |
| `模型` | 用于生成响应的模型（默认：`gpt-5`） | COMBO | 是 | `gpt-5.6-sol`<br />`gpt-5.6-terra`<br />`gpt-5.6-luna`<br />`gpt-5.5-pro`<br />`gpt-5.5`<br />`gpt-5`<br />`gpt-5-mini`<br />`gpt-5-nano`<br />`gpt-4.1`<br />`gpt-4.1-mini`<br />`gpt-4.1-nano`<br />`o4-mini`<br />`o3`<br />`o1-pro`<br />`o1` |
| `图像` | 可选的图像，用作模型的上下文。如需包含多张图像，可使用 Batch Images 节点 | IMAGE | 否 | - |
| `文件` | 可选的文件，用作模型的上下文。接受来自 OpenAI Chat Input Files 节点的输入 | OPENAI_INPUT_FILES | 否 | - |
| `高级设置` | 模型的可选配置。接受来自 OpenAI Chat Advanced Options 节点的输入 | OPENAI_CHAT_CONFIG | 否 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output_text` | OpenAI 模型生成的文本响应 | STRING |
