GetImageSize 节点读取输入图像，并返回其宽度、高度和批次大小。该节点还会直接在节点界面上显示这些测量值。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 输入图像，将从中提取宽度、高度和批次大小 | IMAGE | 是 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `宽度` | 输入图像的宽度（以像素为单位） | INT |
| `高度` | 输入图像的高度（以像素为单位） | INT |
| `批处理大小` | 输入批次中包含的图像数量 | INT |
