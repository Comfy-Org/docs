TextEncodeQwenImageEditPlus 节点处理一个文本提示词以及最多三张可选图像，用于生成图像生成或编辑任务所需的 conditioning 数据。它使用一个专用模板，先要求模型描述输入图像的关键特征，然后说明用户的文本指令应如何改变这些特征，因此编码结果既能理解图像内容，也能理解所要求的修改。当提供 VAE 时，该节点还会根据输入图像创建参考 latent。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 用于分词和编码的 CLIP 模型 | CLIP | 是 | - |
| `提示词` | 描述所需图像修改的文本指令（支持多行输入和动态提示词） | STRING | 是 | - |
| `vae` | 可选，用于从输入图像生成参考 latent 的 VAE 模型 | VAE | 否 | - |
| `图像1` | 可选的第一张输入图像，用于分析和修改 | IMAGE | 否 | - |
| `图像2` | 可选的第二张输入图像，用于分析和修改 | IMAGE | 否 | - |
| `图像3` | 可选的第三张输入图像，用于分析和修改 | IMAGE | 否 | - |

**注意：** 当提供 VAE 时，该节点会根据所有提供的输入图像生成参考 latent。一次最多可处理三张图像。用于视觉-语言处理时，图像会被缩放到目标面积 384x384 像素（保持宽高比）；用于 VAE 编码时，则会缩放到能被 8 整除的尺寸（目标面积 1024x1024 像素）。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `CONDITIONING` | 编码后的 conditioning 数据，包含文本 token 以及用于图像生成的可选参考 latent | CONDITIONING |
