TextEncodeQwenImageEditPlus 节点处理文本提示和可选图像，为图像生成或编辑任务生成 conditioning 数据。它使用专用模板分析输入图像，理解文本指令应如何修改这些图像，然后将此信息编码以供后续生成步骤使用。该节点最多可处理三张输入图像，并在提供 VAE 时可选地生成参考潜变量。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 用于分词和编码的 CLIP 模型 | CLIP | 是 | - |
| `提示词` | 描述所需图像修改的文本指令（支持多行输入和动态提示） | STRING | 是 | - |
| `vae` | 可选的 VAE 模型，用于从输入图像生成参考潜变量 | VAE | 否 | - |
| `图像1` | 第一个可选的输入图像，用于分析和修改 | IMAGE | 否 | - |
| `图像2` | 第二个可选的输入图像，用于分析和修改 | IMAGE | 否 | - |
| `图像3` | 第三个可选的输入图像，用于分析和修改 | IMAGE | 否 | - |

**注意：** 提供 VAE 时，节点会从所有提供的输入图像生成参考潜变量。一次最多可处理三张图像。图像会缩放至 384x384 像素的目标区域（保持宽高比）用于视觉-语言处理，并缩放至可被 8 整除的尺寸（目标面积为 1024x1024 像素）用于 VAE 编码。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `CONDITIONING` | 包含文本 token 和可选参考潜变量的编码 conditioning 数据，用于图像生成 | CONDITIONING |
