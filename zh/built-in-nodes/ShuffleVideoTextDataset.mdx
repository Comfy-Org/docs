此节点会随机打乱列表中“视频-文本”对的顺序，确保每个视频仍与其对应的文本配对。它接收两个长度相等的列表，并对两者应用相同的随机排列，从而在打乱后保持原始配对关系。种子（`seed`）值控制打乱顺序，以便结果可复现。

## 输入
| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `视频` | 要打乱的视频列表。 | VIDEO | 是 | 视频项列表 |
| `文本` | 要打乱的文本列表（与视频配对的字幕）。 | STRING | 是 | 文本字符串列表 |
| `随机种子` | 决定打乱顺序的随机种子（默认：0）。 | INT | 是 | 0 到 18446744073709551615 |

注意：`videos` 和 `texts` 的长度必须相同，因为节点会将每个视频与同一位置上的文本配对，并在打乱时保持这些配对关系。内部会先将 `seed` 值对 4294967295（2^32 - 1）取模，再生成随机顺序，因此非常大的种子值可能产生与较小种子相同的打乱结果。

## 输出
| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `视频` | 按新随机顺序打乱后的视频。 | VIDEO |
| `文本` | 与视频顺序一致、按相同新顺序打乱后的文本。 | STRING |
