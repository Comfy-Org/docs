此节点随机打乱视频-文本对的顺序，确保每个视频仍与其对应的文本配对。它接收两个长度相等的列表，并对两者应用相同的随机排列，从而保证打乱后原始配对关系保持不变。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|------|------|---------|------|------|
| `视频` | 要打乱的视频列表。 | VIDEO | 是 | 视频项目列表 |
| `文本` | 要打乱的文本列表。 | STRING | 是 | 文本字符串列表 |
| `随机种子` | 用于控制打乱顺序的随机种子（默认值：0）。 | INT | 是 | 0 到 18446744073709551615 |

## 输出

| 输出名 | 描述 | 数据类型 |
|--------|------|---------|
| `视频` | 按随机新顺序打乱后的视频。 | VIDEO |
| `文本` | 与视频相同新顺序打乱后的文本。 | STRING |
