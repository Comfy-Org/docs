此节点为使用 Boogu 进行图像编辑准备 conditioning。它处理参考图像以生成正向和负向 conditioning 输出。参考图像被使用两次：来自图像的视觉 tokens 仅添加到正向 conditioning 中以增强编辑指令，而 VAE 参考潜空间则同时添加到正向和负向 conditioning 中，使其在 CFG 下相互抵消，从而保留原始图像特征；分词器会根据是否存在图像和空负向提示词自动选择合适的系统提示词。

## ## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 用于文本编码的 CLIP 模型 | CLIP | 是 | |
| `prompt` | 描述所需编辑的文本提示。支持多行文本和动态提示词。 | STRING | 是 | |
| `negative_prompt` | 描述编辑中需避免内容的文本提示。可留空以放弃负向 conditioning。高级参数。 | STRING | 是 | |
| `vae` | 用于将参考图像编码为潜空间的 VAE 模型。需要用于向 conditioning 输出添加参考潜空间。 | VAE | 否 | |
| `images` | 待编辑的参考图像。Boogu 每个样本聚焦于一个参考图像；允许多个。 | IMAGE | 否 | 最多 16 张图像 |
仅当 `vae` 与至少一张参考 `image` 一起提供时，参考潜空间才会添加到两个 conditioning 输出中。如果省略 `vae`，正向输出仍会收到参考图像的视觉 tokens，但两个输出都不包含参考潜空间。

## ## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `positive` | 包含文本提示（含视觉 tokens）和参考潜空间的 conditioning | CONDITIONING |
| `negative` | 包含负向文本提示和参考潜空间的 conditioning | CONDITIONING |
