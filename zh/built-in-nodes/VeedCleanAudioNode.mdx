使用 VEED 从语音中移除背景噪声。它专为任意语言的语音而构建：语音下方的噪声会被清理，停顿会被完全清理，音乐和音效会被移除而不是保留。输出为 48 kHz 单声道音频。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `audio` | 语音录音，时长少于 30 分钟。 | AUDIO | 是 | 最长 1799 秒 |
| `strength` | 语音下方噪声被移除的程度。较低的值会在语音后方保留更多房间底噪；词与词之间的停顿始终会被完全清理，高于默认值的取值变化不大。（默认值：0.874） | FLOAT | 是 | 0.0 到 1.0（步长 0.001） |
| `loudness` | 是否对输出响度进行归一化。`"normalize"` 会将输出设置为 `target_lufs`；`"keep input level"` 会保持原有电平不变。选择某个选项后会显示其参数。（默认值：`"normalize"`） | DYNAMIC_COMBO | 是 | `"normalize"`<br />`"keep input level"` |
| `target_lufs` | 输出的综合响度，单位为 LUFS。峰值上限为 -1.1 dBTP，因此较高的目标值会提前停止（对于典型语音约为 -15 LUFS）。当 `loudness` 为 `"normalize"` 时可用（默认值：-19.0）。 | FLOAT | 是 | -40.0 到 -8.0（步长 0.1） |

当录音时长超过 1799 秒时，该节点会报错停止。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `AUDIO` | 清理后的语音，为 48 kHz 单声道音频。 | AUDIO |
