此节点根据文本提示和遮罩修改图像的特定区域。它使用 Recraft API 智能地仅编辑遮罩区域，同时保持图像其余部分不变。

## 输入
| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要修改的输入图像 | IMAGE | 是 | - |
| `遮罩` | 定义图像中需要修改区域的遮罩 | MASK | 是 | - |
| `提示词` | 图像生成提示词（默认：空字符串，最大长度：1000 个字符） | STRING | 是 | - |
| `数量` | 要生成的图像数量（默认：1，最小值：1，最大值：6） | INT | 是 | 1-6 |
| `种子` | 种子，用于决定节点是否应重新运行；实际结果不受种子影响，始终为非确定性（默认：0） | INT | 是 | 0-18446744073709551615 |
| `Recraft风格` | Recraft API 的可选样式参数。如果未提供，默认为“realistic_image”样式 | STYLEV3 | 否 | - |
| `反向提示词` | 可选的图像中不需要元素的文本描述（默认：空字符串） | STRING | 否 | - |

*注意：`image` 和 `mask` 必须同时提供，修复（inpainting）操作才能生效。遮罩会自动调整大小以匹配图像尺寸。`prompt` 会经过校验，最大长度为 1000 个字符。如果使用 Infinite Style Library 中的 `style_id`，请确保它不是矢量艺术样式，否则 API 可能返回 SVG 数据而不是图像。*

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 根据提示词和遮罩生成的修改后图像。返回的图像数量为输入图像数乘以 `n` 参数 | IMAGE |
