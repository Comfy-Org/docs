Runway First-Last-Frame to Video 节点使用起始帧、结束帧和文本提示生成视频。它使用 Runway 的 gen3a_turbo 模型在提供的两个关键帧之间创建平滑过渡。对于结束帧与起始帧完全不同的复杂过渡，它尤其有用。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 用于生成的文本提示（默认：空字符串） | STRING | 是 | N/A |
| `起始帧` | 用于视频的起始帧 | IMAGE | 是 | N/A |
| `结束帧` | 用于视频的结束帧。仅 gen3a_turbo 支持。 | IMAGE | 是 | N/A |
| `时长` | 生成视频的时长（秒）。较长的 10 秒时长为生成提供更多时间，使起始帧和结束帧之间平滑过渡（默认："5"）。 | COMBO | 是 | `"5"`<br />`"10"` |
| `比例` | 生成视频的宽高比（默认："768:1280"） | COMBO | 是 | `"768:1280"`<br />`"1280:768"` |
| `种子` | 生成的随机种子。设置为 0 表示随机种子（默认：0）。 | INT | 否 | 0 到 4294967295 |

**参数约束：**

- `prompt` 必须至少包含 1 个字符
- `start_frame` 和 `end_frame` 的最大尺寸必须为 7999x7999 像素
- `start_frame` 和 `end_frame` 的宽高比必须在 0.5 到 2.0 之间
- `end_frame` 参数仅在使用 gen3a_turbo 模型时支持

**备注：**

- 生成成本基于所选时长：每秒 0.0715 美元（5 秒为 0.3575 美元，10 秒为 0.715 美元）
- 此节点标记为已弃用

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 在起始帧和结束帧之间过渡的生成视频 | VIDEO |
