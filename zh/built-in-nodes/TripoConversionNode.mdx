此节点将现有的 Tripo 3D 模型转换为另一种 3D 文件格式。它接收先前由 Tripo 操作（例如模型生成、骨骼绑定、重定向或分割）创建或处理的模型的任务 ID，向 Tripo API 提交转换任务，等待该任务完成，然后返回转换后的模型文件。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `原始模型任务ID` | 要转换的 Tripo 模型的任务 ID。它必须来自先前的 Tripo 模型生成、骨骼绑定、重定向或分割任务。如果该 ID 缺失或为空，节点会引发错误。 | STRING | 是 | MODEL_TASK_ID<br />RIG_TASK_ID<br />RETARGET_TASK_ID<br />SEGMENT_TASK_ID |
| `格式` | 转换后的 3D 模型的目标文件格式。 | COMBO | 是 | GLTF<br />USDZ<br />FBX<br />OBJ<br />STL<br />3MF |
| `四边形` | 启用时将三角形转换为四边形（默认值：False）。 | BOOLEAN | 否 | True or False |
| `面数限制` | 转换后模型的最大面数。设为 -1 表示不限制（默认值：-1）。 | INT | 否 | -1 到 2000000 |
| `纹理大小` | 输出纹理的分辨率（像素）（默认值：4096）。 | INT | 否 | 128 到 8192 |
| `纹理格式` | 导出纹理使用的文件格式（默认值：JPEG）。 | COMBO | 否 | BMP<br />DPX<br />HDR<br />JPEG<br />OPEN_EXR<br />PNG<br />TARGA<br />TIFF<br />WEBP |
| `强制对称` | 启用时强制模型对称（默认值：False）。 | BOOLEAN | 否 | True or False |
| `平滑底部` | 启用时展平模型底部（默认值：False）。 | BOOLEAN | 否 | True or False |
| `平滑底部阈值` | 与 `flatten_bottom` 配合使用的展平深度（默认值：0.01）。仅当启用 `flatten_bottom` 时才应用此值。 | FLOAT | 否 | 0.01 到 1.0 |
| `对齐底部中心` | 启用时将轴心点移动到模型底部中心（默认值：False）。 | BOOLEAN | 否 | True or False |
| `缩放系数` | 应用于转换后模型的缩放因子（默认值：1.0）。 | FLOAT | 否 | 0.01 及以上 |
| `加入动画` | 保留已绑定骨骼或重定向模型的骨架和动画（默认值：True）。 | BOOLEAN | 否 | True or False |
| `打包uv` | 启用时重新打包 UV 坐标（默认值：False）。 | BOOLEAN | 否 | True or False |
| `烘焙` | 将高级材质烘焙到基础纹理中，以获得更广泛的兼容性（默认值：True）。 | BOOLEAN | 否 | True or False |
| `部件名称` | 要发送到转换操作的模型部件名称列表，以逗号分隔。空项会被忽略，重复名称会被移除。留空以省略此选项（默认值：空）。 | STRING | 否 | 以逗号分隔的部件名称列表 |
| `fbx预设` | FBX 兼容性预设。`bake_scale` 会将缩放变换烘焙到几何体中（默认值：blender）。 | COMBO | 否 | blender<br />mixamo<br />3dsmax<br />bake_scale |
| `导出顶点色` | 启用时导出顶点颜色（默认值：False）。 | BOOLEAN | 否 | True or False |
| `导出朝向` | 导出模型的前向轴。default 会保留 Tripo 的 +x（默认值：default）。 | COMBO | 否 | default<br />+x<br />-x<br />+y<br />-y |
| `原地动画` | 启用时让模型原地动画（默认值：False）。 | BOOLEAN | 否 | True or False |

**注意：** 除 `original_model_task_id` 和 `format` 外，所有输入均为可选的高级设置。大多数保持默认值的设置会从转换请求中省略，以便 Tripo API 使用其标准行为。`with_animation` 和 `bake` 选项始终会被发送。仅当启用 `flatten_bottom` 时，才会应用 `flatten_bottom_threshold`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model_3d` | 按请求格式转换后的模型。OBJ 由 Tripo 以 ZIP 压缩包形式交付（包含网格、材质和纹理）。 | FILE_3D |
