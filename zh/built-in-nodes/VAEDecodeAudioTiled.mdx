此节点使用变分自编码器（VAE）将压缩的音频表示（潜在样本）转换回音频波形。它通过较小的重叠区块（tiles）处理数据以管理内存使用，适用于处理较长的音频序列。解码后的音频还会进行归一化，以保持其音量水平一致。

## 输入

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `样本` | 待解码音频的压缩潜在表示。 | LATENT | 是 | N/A |
| `vae` | 用于执行解码的变分自编码器模型。 | VAE | 是 | N/A |
| `分块大小` | 每个处理区块的大小。音频按此长度分块解码，以节省内存（默认：512）。 | INT | 是 | 32 到 8192 |
| `重叠` | 相邻区块重叠的样本数。这有助于减少区块边界处的伪影（默认：64）。 | INT | 是 | 0 到 1024 |

## 输出

| Output Name | Description | Data Type |
| --- | --- | --- |
| `output` | 解码后的音频波形，包括其采样率信息。 | AUDIO |

如果输入 `samples` 中包含采样率，则输出采样率取自该处；否则，将从 VAE 模型中读取（默认为 44100 Hz）。
