## 概述

OpenAI GPT Image 2.6 使用 OpenAI 的 GPT Image 模型，根据提示词生成图像，并在连接参考图像时对它们进行编辑。此节点提供四种模型：`gpt-image-2.6-flare`、`gpt-image-2.6-sunburst`、`gpt-image-2.5-flare` 和 `gpt-image-2.5-sunburst`。在第一张参考图像上绘制标注，并将它们作为标记对连接，即可向模型准确指示需要编辑的位置。

**参数约束与限制：**

- 当 `model.size` 设为 "Custom" 时，`model.custom_width` 和 `model.custom_height` 都必须是 16 的倍数，最长边不得超过 3840，宽高比不得超过 3:1，总像素数必须在 655,360 到 8,294,400 之间。
- `model.markup` 和 `model.markup_alpha` 必须一同连接。标记需要至少一张参考图像，且其宽度和高度必须与第一张参考图像一致。
- 不连接 `model.images` 时，节点仅根据提示词生成图像；连接参考图像时，则会对这些图像进行编辑和组合。
- 参考图像在发送至 API 之前会被缩小。
- `model.complexity` 仅存在于 `gpt-image-2.6-flare` 和 `gpt-image-2.6-sunburst` 上；2.5 模型使用固定的规划深度。
