创建语音副本，使其能像母语一样说另一种语言，而不是用原来的口音朗读外语。副本会保存到你的账户，并随音频预览一起返回。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `voice` | 要复制的 Breeze 语音。 | BREEZE_VOICE | 是 | - |
| `language` | 新语音所说的语言。默认：`"English"`。 | COMBO | 是 | 多个选项可用 |
| `seed` | 控制节点是否重新运行；无论种子如何，结果都是非确定性的。默认：42。 | INT | 否 | 0 到 2147483647 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `voice` | 语音的本地化副本，以原始语音和语言命名。 | BREEZE_VOICE |
| `preview` | 本地化语音的音频预览。 | AUDIO |
