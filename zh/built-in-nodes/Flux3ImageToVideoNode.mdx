Flux 3 图像转视频节点使用 FLUX 3 将 1 到 10 张图像动画化。每张图像成为剪辑的一个帧：单张图像作为开头，两张图像从第一张渐变到第二张，更多图像则均匀分布在整个剪辑中，或固定在你选择的时间点上。

## 输入
| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 场景应如何运动和发声；提示词在生成前会被解释和扩展。必须至少包含一个字符。 | STRING | 是 | 多行文本（默认：空） |
| `keyframes` | 1 到 10 张图像，按播放顺序排列。每张图像至少 256x256 像素。每个关键帧成为剪辑中的一个点。 | IMAGE | 是 | 1 到 10 张图像 |
| `placement` | 'spread across the clip' 让 FLUX 3 放置图像（一张图像作为剪辑开头，两张图像成为剪辑的开始和结束）；'at times' 将每张图像固定到你选择的秒数。 | STRING | 是 | `"spread across the clip"`（默认）<br />`"at times"` |
| `times` | 每张图像对应一个以秒为单位的时间，用逗号分隔且递增，例如 '0, 2.5, 5'。当 `placement` 为 `"at times"` 时需要。 | STRING | 否 | 逗号分隔的秒数（默认："0"） |
| `aspect_ratio` | 输出宽高比。'auto' 会根据提示词和输入选择一个宽高比。 | STRING | 是 | `"auto"`（默认）<br />以及其他可用选项 |
| `duration` | 剪辑长度（秒）。'auto' 会根据内容调整长度。 | STRING | 是 | `"auto"`（默认）<br />以及其他可用选项 |
| `resolution` | 输出分辨率。 | STRING | 是 | `"720p"`（默认）<br />`"1080p"` |
| `generate_audio` | 生成同步音频（环境音、语音、音效）。关闭时生成没有音轨的视频。 | BOOLEAN | 是 | true / false（默认：true） |
| `safety_tolerance` | 审核容忍度，0 为最严格。发送图像或视频的请求无论此处设置为何值，都将限制为 2。 | INT | 是 | 0 到 4（默认：2，高级设置） |
| `seed` | 用于确定节点是否应重新运行的种子；FLUX 3 会自行选择种子，因此无论此值如何，实际结果都是不确定的。 | INT | 是 | 0 到 4294967295（默认：42，带生成后控制） |

注意：`keyframes` 是必需的——如果没有连接关键帧图像，节点将报错。当 `placement` 为 `"spread across the clip"` 且提供 3 张或更多图像时，`duration` 必须设置为显式值（不能为 `"auto"`）；否则节点将报错。当 `placement` 为 `"at times"` 时，`times` 必须为每张图像提供一个以秒为单位的时间，且按递增顺序排列。无论设置为何值，发送图像的请求都被限制为安全容忍度 2。

## 输出
| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 根据所选宽高比、时长、分辨率和音频设置，由关键帧图像生成的视频剪辑。 | VIDEO |
