Flux 3 Image to Video 使用 FLUX 3 为 1 到 10 张图像制作动画。每张图像都会成为片段中的一帧：一张图像可开启片段，两张图像会从第一张过渡到第二张，更多图像则会分布在整个片段中，或固定到你选择的时间点。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `placement` | "spread across the clip" 允许 FLUX 3 放置图像（一张开启片段，两张成为其起始和结束）；"at times" 将每张图像固定到你选择的秒数。 | DYNAMIC_COMBO | 是 | `"spread across the clip"`（默认）<br />`"at times"` |
| `prompt` | 场景应如何运动和发声；提示词在生成前会被解释和扩展。必须包含至少一个字符。 | STRING | 是 | 多行文本（默认：空） |
| `aspect_ratio` | 输出宽高比。"auto" 会根据提示词和输入选择一个。 | COMBO | 是 | `"auto"`（默认）<br />其他可用宽高比 |
| `duration` | 片段长度（秒）。"auto" 会根据内容适配长度。 | COMBO | 是 | `"auto"`（默认）<br />其他可用时长 |
| `resolution` | 输出分辨率。 | COMBO | 是 | `"720p"`（默认）<br />`"1080p"` |
| `generate_audio` | 生成同步音频（环境声、语音、效果）。关闭会生成没有音轨的视频。 | BOOLEAN | 是 | true / false（默认：true） |
| `safety_tolerance` | 审核容忍度，0 最严格。发送图像或视频的请求无论此处设置如何，上限均为 2。 | INT | 是 | 0 到 4（默认：2，高级设置） |
| `seed` | 用于确定节点是否应重新运行的种子；FLUX 3 会选择自己的种子，因此无论此值如何，实际结果都是不确定的。 | INT | 是 | 0 到 4294967295（默认：42，生成后控制） |

### spread across the clip 输入

此放置选项没有其他参数。

### at times 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `times` | 每张图像一个以秒为单位的时间，用逗号分隔并递增，例如 "0, 2.5, 5"。仅在 `placement` 为 "at times" 时出现；每个关键帧图像都需要一个时间。 | STRING | 否 | 逗号分隔的秒数（默认："0"） |

### 参考输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `keyframes` | 可扩展槽位：按播放顺序连接 1 到 10 张关键帧图像，例如 `image_1`、`image_2` 等。每张图像都会成为片段的一帧。每张至少 256x256 像素；宽高比不能比 64:1 更极端。 | IMAGE | 是 | 1 到 10 张图像 |

注意：`keyframes` 必须包含至少一张图像；如果没有连接任何图像，节点会引发错误。每张关键帧图像必须至少为 256x256 像素，其宽高比不能比 64:1 更极端。

当 `placement` 为 "spread across the clip" 且连接了 3 张或更多关键帧时，`duration` 必须设置为显式值，不能为 "auto"；否则节点会引发错误。

当 `placement` 为 "at times" 时，`times` 必须为每张图像提供一个以秒为单位的时间。时间必须递增，不能为负，最后一个时间不能超过片段结尾（当 `duration` 为 "auto" 时最多为 20 秒）。

由于此节点会发送图像，无论你设置什么值，`safety_tolerance` 都上限为 2。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 根据所选宽高比、时长、分辨率和音频设置，由关键帧图像生成的视频片段。 | VIDEO |
