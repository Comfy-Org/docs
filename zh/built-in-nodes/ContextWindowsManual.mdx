Context Windows (Manual) 节点允许你在采样过程中为模型手动配置上下文窗口，创建具有指定长度、重叠大小和调度模式的重叠上下文片段，以便将数据划分为可管理的数据块进行处理，同时保持各片段之间的连续性。它提供了用于控制上下文窗口应用方式的高级选项，包括噪声重排、条件保留和因果窗口修复。此节点为实验性节点。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 采样期间要应用上下文窗口的模型。 | MODEL | 是 | - |
| `上下文长度` | 上下文窗口的长度（默认值：16）。 | INT | 是 | 1+ |
| `上下文重叠` | 上下文窗口的重叠大小（默认值：4）。 | INT | 是 | 0+ |
| `上下文调度` | 上下文窗口的随步骤变化的调度算法（默认值：STATIC_STANDARD）。 | COMBO | 是 | `STATIC_STANDARD`<br />`UNIFORM_STANDARD`<br />`UNIFORM_LOOPED`<br />`BATCHED` |
| `上下文步幅` | 上下文窗口的步长；仅适用于均匀调度（默认值：1）。 | INT | 是 | 1+ |
| `闭环` | 是否闭合上下文窗口循环；仅适用于循环调度（默认值：False）。 | BOOLEAN | 是 | - |
| `融合方法` | 用于融合上下文窗口的方法（默认值：PYRAMID）。 | COMBO | 是 | 静态融合方法（参见 `ContextFuseMethods.LIST_STATIC`） |
| `维度` | 要应用上下文窗口的维度（默认值：0）。 | INT | 是 | 0-5 |
| `Freenoise` | 是否应用 FreeNoise 噪声重排，以改善窗口混合（默认值：False）。 | BOOLEAN | 是 | - |
| `cond_retain_index_list` | 要在每个窗口的条件张量中保留的潜变量索引列表。对于拼接式（concat-style）I2V 模型（例如 Wan I2V、HunyuanVideo I2V、Cosmos I2V、SVD），编码后的起始图像位于 `c_concat` 条件通道中；将此参数设置为 `'0'` 会在每个窗口的 sub-pos 0 处保留该起始图像内容（默认值：""）。 | STRING | 否 | - |
| `split_conds_to_windows` | 是否根据区域索引将多个条件（由 ConditionCombine 创建）拆分到各个窗口（默认值：False）。 | BOOLEAN | 否 | - |
| `latent_retain_index_list` | 要在每个窗口的噪声潜变量本身中保留的潜变量索引列表。适用于参考内容（例如起始图像）直接位于噪声潜变量中而不是单独条件通道中的工作流（例如 LTXV、AnimateDiff 等 inplace 风格 I2V）。与 `cond_retain_index_list` 相互独立（默认值：""）。 | STRING | 否 | - |
| `causal_window_fix` | 是否向非 0 索引的上下文窗口添加因果修复帧（默认值：True）。 | BOOLEAN | 否 | - |

**参数约束：**

- `context_stride` 仅在选择了均匀调度（`UNIFORM_STANDARD` 或 `UNIFORM_LOOPED`）时使用。
- `closed_loop` 仅适用于循环调度（`UNIFORM_LOOPED`）。
- `dim` 必须介于 0 到 5（含）之间。
- `cond_retain_index_list` 和 `latent_retain_index_list` 需要以字符串形式提供逗号分隔的整数索引列表（例如 "0,1,2"）。
- `latent_retain_index_list` 独立于 `cond_retain_index_list`。
