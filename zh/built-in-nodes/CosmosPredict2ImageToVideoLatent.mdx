CosmosPredict2ImageToVideoLatent 根据图像创建用于视频生成的视频潜在表示。它可以生成空白视频潜在变量，或结合开始图像和结束图像，创建具有指定尺寸和时长的视频序列。该节点负责将图像编码为适合视频处理的潜在空间格式。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `vae` | 用于将图像编码到潜在空间的 VAE 模型 | VAE | 是 | - |
| `宽度` | 输出视频的宽度（像素，默认值：848，必须能被 16 整除） | INT | 是 | 16 到 MAX_RESOLUTION |
| `高度` | 输出视频的高度（像素，默认值：480，必须能被 16 整除） | INT | 是 | 16 到 MAX_RESOLUTION |
| `长度` | 视频序列中的帧数（默认值：93，步长：4） | INT | 是 | 1 到 MAX_RESOLUTION |
| `批次大小` | 要生成的视频序列数量（默认值：1） | INT | 是 | 1 到 4096 |
| `起始图像` | 视频序列的可选开始图像 | IMAGE | 否 | - |
| `结束图像` | 视频序列的可选结束图像 | IMAGE | 否 | - |

**注意：** 当未提供 `start_image` 和 `end_image` 时，节点会生成空白视频潜在变量。当提供其中一个或两个图像时，它们会被调整为 `width` 和 `height`，编码到潜在空间，并放置在视频序列的开头和/或结尾，同时在噪声掩码中标记相应区域，以便在生成过程中保留这些区域。生成的潜在变量和掩码会重复 `batch_size` 次。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `samples` | 生成的视频潜在表示，包含编码后的视频序列 | LATENT |
| `noise_mask` | 指示生成过程中应保留潜在变量哪些部分的掩码。仅当至少提供了 `start_image` 或 `end_image` 之一时才会存在。 | LATENT |
