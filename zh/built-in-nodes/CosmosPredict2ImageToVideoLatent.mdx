为 Cosmos Predict2 图像到视频工作流创建视频潜变量。此节点可以生成指定尺寸和长度的空视频潜变量，或将编码后的起始和/或结束图像插入序列，以便在生成过程中保留这些帧。任何提供的图像都会调整为请求的 `width` 和 `height`，并使用提供的 VAE 编码，然后放置在潜变量序列的开头和/或末尾。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `vae` | 用于将起始和结束图像编码到潜空间的 VAE 模型 | VAE | 是 | - |
| `宽度` | 输出视频的宽度（像素）（默认值：848，必须是 16 的倍数） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 输出视频的高度（像素）（默认值：480，必须是 16 的倍数） | INT | 是 | 16 to MAX_RESOLUTION |
| `长度` | 视频序列中的帧数（默认值：93） | INT | 是 | 1 to MAX_RESOLUTION |
| `批次大小` | 要生成的视频序列数量（默认值：1） | INT | 是 | 1 到 4096 |
| `起始图像` | 视频序列的可选起始图像 | IMAGE | 否 | - |
| `结束图像` | 视频序列的可选结束图像 | IMAGE | 否 | - |

**注意：** 当未提供 `start_image` 和 `end_image` 时，此节点仅返回请求尺寸和长度的空潜变量。当提供其中一个或两个图像时，它们会被调整为 `width` 和 `height`，使用 `vae` 编码，并放置在潜变量序列的开头和/或末尾。相应区域会在噪声掩码中标记，以便在生成期间保留它们。编码后的潜变量会转换为 Wan 2.1 latent 格式，生成的潜变量和掩码会重复 `batch_size` 次。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `LATENT` | 生成的视频潜变量，包含 `samples`（视频潜变量序列），并且当提供 `start_image` 或 `end_image` 中的至少一个时，还包含一个 `noise_mask`，用于标记生成过程中应保留的帧 | LATENT |
