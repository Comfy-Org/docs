ComfyMathExpression 节点会计算你以文本形式编写的数学公式。该公式可以使用 `a`、`b`、`c` 等字母名称来引用节点的输入值，并且你可以通过可增长的 `values` 组添加任意数量的输入值。计算结果会同时以浮点数、整数和布尔值的形式返回。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `表达式` | 要计算的数学公式，以文本形式书写（例如 `a + b`），使用输入值的字母名称作为变量。多行输入。（默认值："a + b"） | STRING | 是 | N/A |
| `数值` | 可增长的输入值组，为表达式提供变量。添加到该组中的每个值会自动获得下一个以小写字母命名的名称，从 `a` 开始（`a`、`b`、`c`、...），然后该名称可以在 `expression` 内使用。每一项接受数字（INT 或 FLOAT）或布尔值（TRUE/FALSE）。 | FLOAT, INT, BOOLEAN | 是 | 1 到 26 values, named `a` to `z` |

### 注意事项和约束

- `expression` 不能为空或仅包含空白字符。
- 表达式必须计算为数值结果（INT 或 FLOAT）或布尔结果（TRUE/FALSE）。布尔结果在 TRUE 时视为 1，在 FALSE 时视为 0。如果结果是其他类型，例如文本，节点会引发错误。
- 数值结果必须是有限值且可转换为 float。结果过大或非有限会导致错误。
- 整组输入值也可以在表达式中通过变量名 `values`（作为列表）使用，因此诸如 `sum(values)` 的表达式是可行的。
- 表达式中可以使用以下数学函数：`sum`、`min`、`max`、`abs`、`round`、`pow`、`sqrt`、`ceil`、`floor`、`log`、`log2`、`log10`、`sin`、`cos`、`tan`、`int`、`float`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `FLOAT` | 表达式的结果，作为浮点数。 | FLOAT |
| `INT` | 表达式的结果转换为整数，小数部分截断。 | INT |
| `BOOL` | 结果转换为布尔值：当数值结果不为零时为 TRUE，为零时为 FALSE。 | BOOLEAN |
