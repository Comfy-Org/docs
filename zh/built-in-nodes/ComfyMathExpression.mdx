ComfyMathExpression 节点会对您以文本形式书写的数学公式进行计算。该公式可以使用字母名称（例如 `a`、`b`、`c`）引用节点的输入值，并且您可以通过可增长的 `values` 组根据需求添加任意数量的输入值。计算结果会同时以浮点数、整数和布尔值的形式返回。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `表达式` | 要计算的数学公式，以文本形式书写（例如 `a + b`），使用输入值的字母名称作为变量。支持多行输入。（默认值："a + b"） | STRING | 是 | N/A |
| `数值` | 可增长的输入值组，为表达式提供变量。添加到该组的每个值都会自动按顺序获得从 `a` 开始的小写字母名称（`a`、`b`、`c`, ...），该名称随后即可在 `expression` 中使用。每个条目接受一个数字（INT 或 FLOAT）或一个布尔值（TRUE/FALSE）。 | FLOAT, INT, BOOLEAN | 是 | 1 到 26 values, named `a` to `z` |

### 备注与限制

- `expression` 不能为空，也不能仅包含空白字符。
- 表达式的计算结果必须是数值类型（INT 或 FLOAT）。如果结果为其他类型（例如文本），节点将报错。
- 数值结果必须是有限值，并且可以转换为浮点数。结果过大或为非有限值会导致错误。
- 所有输入值也可以作为一个列表，在表达式内部通过变量名 `values` 访问，因此可以使用诸如 `sum(values)` 的表达式。
- 表达式内部可使用以下数学函数：`sum`、`min`、`max`、`abs`、`round`、`pow`、`sqrt`、`ceil`、`floor`、`log`、`log2`、`log10`、`sin`、`cos`、`tan`、`int`、`float`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `FLOAT` | 表达式的计算结果，以浮点数形式返回。 | FLOAT |
| `INT` | 表达式的计算结果转换为整数，小数部分被截断。 | INT |
| `布尔值` | 将结果转换为布尔值：当数值结果不为零时为 TRUE，为零时为 FALSE。 | BOOLEAN |
