DualCFGGuider 节点为双无分类器引导采样创建了一个引导系统。它组合两个条件输入和一个负条件输入，并应用两个独立的引导比例来控制每个条件对生成输出的影响强度。它支持两种组合这些引导比例的方式："regular" 和 "nested"。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 用于引导的模型 | MODEL | 是 | - |
| `条件1` | 第一个正向条件输入 | CONDITIONING | 是 | - |
| `条件2` | 第二个条件输入，用作第一个正向条件与负条件之间的参考 | CONDITIONING | 是 | - |
| `负面条件` | 负条件输入 | CONDITIONING | 是 | - |
| `cfg_条件1` | 应用于第一个正向条件的引导比例（默认：8.0） | FLOAT | 是 | 0.0 - 100.0 |
| `cfg_条件2_负面` | 应用于第二个条件与负条件之间的引导比例（默认：8.0） | FLOAT | 是 | 0.0 - 100.0 |
| `样式` | 要应用的引导风格（默认："regular"）。当设置为"nested"时，以嵌套方式应用引导 | COMBO | 是 | "regular"<br />"nested" |

注意：在 `regular` 风格中，`cfg_cond2_negative` 应用于 `cond2` 和 `negative` 之间，`cfg_conds` 应用于 `cond1` 和 `cond2` 之间。在 `nested` 风格中，`cfg_conds` 首先应用于 `cond1` 和 `cond2` 之间，然后使用 `cfg_cond2_negative` 将得到的预测引导远离 `negative`。

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `GUIDER` | 配置好的引导系统，可直接用于采样 | GUIDER |
