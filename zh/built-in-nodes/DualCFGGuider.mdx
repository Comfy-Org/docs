Dual CFG Guider 节点创建了一个用于采样的引导系统，它同时使用两个条件输入和一个负面条件输入。它对两个条件分别应用独立的引导强度，以控制每个条件对生成结果的影响程度，并支持两种组合这些强度缩放的方式："regular" 和 "nested"。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 用于引导的模型 | MODEL | 是 | - |
| `条件1` | 第一个正面条件输入 | CONDITIONING | 是 | - |
| `条件2` | 第二个条件输入，用作第一个正面条件与负面条件之间的参考 | CONDITIONING | 是 | - |
| `负面条件` | 负面条件输入 | CONDITIONING | 是 | - |
| `cfg_条件1` | 应用于第一个正面条件的引导强度（默认值：8.0） | FLOAT | 是 | 0.0 - 100.0 |
| `cfg_条件2_负面` | 应用于第二个条件与负面条件之间的引导强度（默认值：8.0） | FLOAT | 是 | 0.0 - 100.0 |
| `样式` | 要应用的引导风格（默认值："regular"）。设置为 "nested" 时，引导将以嵌套方式应用 | COMBO | 是 | "regular"<br />"nested" |

注意：在 `regular` 风格中，`cfg_cond2_negative` 应用于 `cond2` 与 `negative` 之间，`cfg_conds` 应用于 `cond1` 与 `cond2` 之间。在 `nested` 风格中，`cfg_conds` 先应用于 `cond1` 与 `cond2` 之间，然后使用 `cfg_cond2_negative` 将得到的预测结果引导远离 `negative`。

注意：在 `regular` 风格中，当 `cfg_cond2_negative` 等于 1.0 时会跳过负面条件；当 `cfg_conds` 也等于 1.0 时，第二个条件同样会被跳过。这减少了执行的模型评估次数。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `GUIDER` | 一个已配置好的引导系统，可直接用于采样 | GUIDER |
