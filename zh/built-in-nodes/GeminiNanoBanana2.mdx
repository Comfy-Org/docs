Nano Banana 2 节点通过 Google Vertex API 使用 Gemini 3.1 Flash Image 模型同步生成或编辑图像。它发送文本提示词，以及可选的参考图像或文件，并返回生成的图像、任何附带文本，以及可选地返回模型思考过程中的图像。此节点已标记为弃用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 文本提示词，描述要生成的图像或要应用的编辑。包含模型应遵循的任何约束、风格或细节。不能为空或仅包含空白字符。（默认：空） | STRING | 是 | N/A |
| `模型` | 用于图像生成的 Gemini 模型。 | COMBO | 是 | "Nano Banana 2 (Gemini 3.1 Flash Image)" |
| `种子` | 当 `seed` 固定为特定值时，模型会尽力为重复请求提供相同的响应。不保证确定性输出。此外，更改模型或参数设置（例如 `temperature`）即使使用相同的 `seed` 值，也可能导致响应变化。默认使用随机 `seed` 值。（默认：42） | INT | 是 | 0 到 18446744073709551615 |
| `宽高比` | 如果设置为 'auto'，则匹配输入图像的宽高比；如果未提供图像，通常会生成 16:9 的图像。（默认："auto"） | COMBO | 是 | "auto"<br />"1:1"<br />"2:3"<br />"3:2"<br />"3:4"<br />"4:3"<br />"4:5"<br />"5:4"<br />"9:16"<br />"16:9"<br />"21:9" |

**注意：** `images` 输入最多支持 14 张图像。如果提供更多，节点会报错。`prompt` 输入不能为空或仅包含空白字符。
