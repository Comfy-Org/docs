此节点使用 HappyHorse 模型从单张起始图像生成短视频。您提供首帧图像和描述所需运动与场景的文本提示，该节点将创建从该图像继续的视频。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频生成的 HappyHorse 模型。 | DYNAMIC_COMBO | 是 | `"happyhorse-1.1-i2v"`<br />`"happyhorse-1.0-i2v"` |
| `first_frame` | 首帧图像。输出宽高比由此图像决定。 | IMAGE | 是 | 300×300 px min; 1:2.5 到 2.5:1 |
| `seed` | 用于生成的种子。（默认：0） | INT | 是 | 0 到 2147483647 |
| `watermark` | 是否在结果中添加 AI 生成的水印。（高级选项；默认：False） | BOOLEAN | 是 | True / False |

### happyhorse-1.1-i2v 和 happyhorse-1.0-i2v 输入

两个模型版本共享相同的参数集。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述元素和视觉特征的提示词。支持英语和中文。（默认：""） | STRING | 否 | N/A |
| `resolution` | 输出视频分辨率。（默认：`"720P"`） | COMBO | 是 | `"720P"`<br />`"1080P"` |
| `duration` | 生成视频的时长（秒）。（默认：5） | INT | 是 | 3 到 15 |

注意：`first_frame` 图像必须至少为 300×300 像素，且其宽高比必须在 1:2.5 到 2.5:1 之间。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 生成的视频文件。 | VIDEO |
