选择一个精选的 Breeze 语音，或任意 Breeze 语音 id，并将其传递给 Breeze 文本转语音节点。此节点仅解析 id，不会发起 API 调用。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `language` | 精选语音所属的语言分组，或使用 `custom` 以手动输入 id。默认：`"English"`。 | DYNAMIC_COMBO | 是 | `"English"`<br />`"Chinese"`<br />`"Japanese"`<br />`"custom"` |

### 语言 "English"、"Chinese" 和 "Japanese" 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `voice` | 该语言下的精选语音。 | COMBO | 是 | 有多个选项可用 |

### 语言 "custom" 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `voice_id` | 任意 Breeze 语音 id，例如由其他 Breeze 节点创建的语音。仅允许字母、数字、`_` 和 `-`。默认：空。 | STRING | 是 | Breeze 语音 id |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `voice` | 所选的 Breeze 语音。 | BREEZE_VOICE |
