使用针对每个视图的单独文本指令编辑 Tripo: Image to Multiview 结果的视图。没有指令的视图保持不变。编辑后的图像旨在连接到 Tripo: Multiview to Model 以创建 3D 模型；编辑后的多视图集无法再次编辑。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `multiview_task_id` | 将被编辑视图的 Tripo: Image to Multiview 结果的任务 ID。必须来自 Tripo: Image to Multiview 节点。 | MULTIVIEW_TASK_ID | 是 | Task ID |
| `front_prompt` | 描述要应用于前视图的编辑的文本指令。为空时，前视图保持不变。默认值：空字符串。 | STRING | 否 | Multiline text |
| `left_prompt` | 描述要应用于左视图的编辑的文本指令。为空时，左视图保持不变。默认值：空字符串。 | STRING | 否 | Multiline text |
| `back_prompt` | 描述要应用于后视图的编辑的文本指令。为空时，后视图保持不变。默认值：空字符串。 | STRING | 否 | Multiline text |
| `right_prompt` | 描述要应用于右视图的编辑的文本指令。为空时，右视图保持不变。默认值：空字符串。 | STRING | 否 | Multiline text |

注意：四个提示词（`front_prompt`、`left_prompt`、`back_prompt`、`right_prompt`）中至少有一个必须包含非空文本；仅包含空白的文本被视为空，如果所有提示词都为空，节点将引发错误。

注意：每个带有编辑指令的视图费用约为 0.05 美元。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `front` | 编辑后的前视图图像。 | IMAGE |
| `left` | 编辑后的左视图图像。 | IMAGE |
| `back` | 编辑后的后视图图像。 | IMAGE |
| `right` | 编辑后的右视图图像。 | IMAGE |
