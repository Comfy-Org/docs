此节点使用腾讯的 Hy4 模型生成文本回复。它发送文本提示，并可选地发送一张或多张图像作为上下文，然后将模型的回答以文本形式返回。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于生成回答的模型。选择它会展开显示其下方的输入。默认：`"Hy4"`。 | DYNAMIC_COMBO | 是 | `"Hy4"` |

### Hy4 输入

当 `model` 设置为 `"Hy4"` 时，会显示这些输入。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要发送给模型的消息。不能为空。默认：""（空字符串）。 | STRING | 是 | 至少 1 个字符 |
| `images` | 最多 20 张图像。批次中的每张图像都计入。默认：无图像。 | AUTOGROW | 否 | 0 到 20 张图像 |
| `seed` | 种子控制节点是否应重新运行；无论种子如何，结果都是非确定性的。默认：42。 | INT | 是 | 0 到 2147483647 |
| `system_prompt` | 规定模型行为的基础指令。默认：""（空字符串）。 | STRING | 否 | - |
| `reasoning` | 模型在回答前进行思考。回答需要更长时间并使用更多 token，且非常困难的任务可能会超时。默认：False。 | BOOLEAN | 是 | True<br />False |
| `temperature` | 控制随机性。即使为 0，结果仍会变化。默认：1.0。 | FLOAT | 是 | 0.0 到 1.4（步长：0.01） |
| `max_tokens` | 要生成的最大 token 数，当 `reasoning` 开启时包括推理 token。非常长的回答可能会超时。默认：32000。 | INT | 是 | 1 到 64000 |

**约束：**

* 每次请求最多接受 20 张图像，批次中的每张图像都计入。
* 腾讯的内容过滤器可能会阻止请求，从而引发错误。
* 如果答案完成前 `max_tokens` 用完，节点会引发错误：请增大 `max_tokens` 或关闭 `reasoning`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `STRING` | 来自 Hy4 模型的文本回答。 | STRING |
