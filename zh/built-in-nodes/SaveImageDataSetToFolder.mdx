此节点将图像列表保存到 ComfyUI 输出目录内的指定文件夹中。它使用可配置的文件名前缀将每张图像作为 PNG 文件写入磁盘。此节点已弃用，并被现有的 Save Image 节点取代，在现有节点中可以在文件名前缀中指定目标文件夹。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要保存的图像列表。 | IMAGE | 是 | N/A |
| `文件夹名` | 保存图像到的文件夹名称（在输出目录内）。默认："dataset"。 | STRING | 否 | N/A |
| `文件名前缀` | 已保存图像文件名的前缀。默认："image"。高级参数。 | STRING | 否 | N/A |
| `模式` | 是覆盖现有文件还是递增文件名以避免覆盖。默认："overwrite"。 | COMBO | 否 | "overwrite"<br />"increment" |

**注意：**

- `images` 输入是一个列表，因此可以在单次运行中保存多张图像。
- `folder_name`、`filename_prefix` 和 `mode` 参数是标量值；如果连接了列表，则仅使用该列表中的第一个值。
- `folder_name` 必须解析为 ComfyUI 输出目录内的位置。任何逃逸输出目录的值（例如包含 `..` 的路径、绝对路径、驱动器号或符号链接逃逸）都会被拒绝并报错。
- 在 "overwrite" 模式下，文件保存为 `{prefix}_00000.png`、`{prefix}_00001.png` 等，替换任何现有文件。在 "increment" 模式下，文件名中会插入计数器，因此不会覆盖现有文件。
- 仅支持 PNG 输出。

## 输出

此节点没有任何输出。它是一个输出节点，执行对文件系统的保存操作。
