此节点会将图像列表保存到 ComfyUI 输出目录内的指定文件夹中。它会使用可配置的文件名前缀，将每张图像以 PNG 文件形式写入磁盘。此节点已弃用，已被现有的 Save Image 节点取代；在这些节点中，可以在文件名前缀中指定目标文件夹。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 取值范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要保存的图像列表。 | IMAGE | 是 | N/A |
| `文件夹名` | 用于保存图像的文件夹名称（位于输出目录内）。默认值："dataset"。 | STRING | 否 | N/A |
| `文件名前缀` | 保存的图像文件名的前缀。默认值："image"。高级参数。 | STRING | 否 | N/A |
| `模式` | 是否覆盖现有文件，或递增文件名以避免覆盖。默认值："overwrite"。 | COMBO | 否 | "overwrite"<br />"increment" |

**注意：**

- `images` 输入是一个列表，因此单次运行可保存多张图像。
- `folder_name`、`filename_prefix` 和 `mode` 参数是标量值；如果连接了列表，则只使用该列表中的第一个值。
- `folder_name` 必须解析为 ComfyUI 输出目录内的位置。超出输出目录的值（例如包含 `..` 的路径或绝对路径）将被拒绝并报错。
- 在 "overwrite" 模式下，文件将保存为 `{prefix}_00000.png`、`{prefix}_00001.png` 等，并替换任何现有文件。在 "increment" 模式下，文件名中会加入计数器，从而避免覆盖现有文件。

## 输出

此节点没有任何输出。它是一个输出节点，用于执行保存到文件系统的操作。
