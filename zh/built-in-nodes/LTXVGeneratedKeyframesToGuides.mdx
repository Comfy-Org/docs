LTXV Generated Keyframes to Guides 节点将来自较早阶段生成的关键帧固定为后续画布上的冻结图像引导。它会将关键帧解码为独立帧，必要时调整其大小，并以噪声掩码 0 写入它们，使其不会再次被去噪。在时间上采样后，记录的索引会从生成它们所在的画布缩放到当前画布；使用 `override_frame_indices` 可显式设置位置。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `正面条件` | 要添加关键帧引导的正向条件。 | CONDITIONING | 是 | |
| `负面条件` | 要添加关键帧引导的负向条件。 | CONDITIONING | 是 | |
| `vae` | 如果需要调整大小，用于解码关键帧的 VAE。 | VAE | 是 | |
| `潜空间` | 要添加引导的目标视频 latent，例如时间上采样后的那个。 | LATENT | 是 | |
| `关键帧` | LTXV Separate Generated Keyframes 的 `keyframes` 输出，携带每个关键帧生成时的像素帧索引。 | LATENT | 是 | |
| `强度` | 引导强度。1.0 为硬固定；较低值会放松它。（默认：1.0） | FLOAT | 是 | 0.0 - 10.0 （步长：0.01） |
| `override_frame_indices` | 可选 — 固定到这些像素帧，而不是记录的（或自动缩放的）位置。为每个关键帧提供一个索引。留空以复用记录的位置，或当目标画布长度不同时（例如时间 x2 后）缩放它们。（默认：""） | STRING | 否 | |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `positive` | 将关键帧固定为图像引导的正向条件。 | CONDITIONING |
| `negative` | 将关键帧固定为图像引导的负向条件。 | CONDITIONING |
| `latent` | 将关键帧添加为冻结引导的目标视频 latent。 | LATENT |

## 备注

- `keyframes` 输入必须连接到 LTXV Separate Generated Keyframes 的 `keyframes` 输出。如果 latent 不携带生成的关键帧位置，节点会报错。
- `positive` 和 `negative` 条件输入必须来自 LTXV Separate Generated Keyframes 的 positive 和 negative 输出。如果正向条件仍携带生成的关键帧，节点会报错。
- `latent` 输入必须是普通视频 latent（5D 张量）。必须在使用 Concat AV Latent 合并视频和音频 latent 之前添加引导。
- 仅支持批次大小为 1。每个引导都从一个图像编码而来，因此它不能在不同批次元素之间有所差异。
- `keyframes` latent 中的关键帧数量必须与记录的位置数量匹配；否则会报错。
- 如果 `override_frame_indices` 留空，则使用记录的位置。如果目标画布的帧数与生成关键帧所在的画布不同，记录的索引会自动缩放。
- 如果提供了 `override_frame_indices`，它必须为每个关键帧包含一个整数索引，以逗号或空格分隔。索引必须唯一，并且介于 1 和（目标 latent 中的像素帧数 - 1）之间。否则会报错。
- 如果任何最终关键帧索引大于或等于目标 latent 中的像素帧数，节点会报错。当目标在生成关键帧之后进行了时间尺寸调整时，可能会发生这种情况。
- `strength` 参数的最小值为 0.0，最大值为 10.0。
