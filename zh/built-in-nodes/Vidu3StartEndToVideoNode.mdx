此节点通过在提供的起始帧和结束帧之间进行插值并依据文本提示来生成视频。它使用 Vidu Q3 模型在两幅图像之间创建无缝过渡，生成指定时长和分辨率的视频。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于视频生成的模型。选择一个选项会显示 `resolution`、`duration` 和 `audio` 的附加配置参数。 | DYNAMIC_COMBO | 是 | `"viduq3-pro"`<br />`"viduq3-turbo"` |
| `起始帧` | 视频序列的起始图像。 | IMAGE | 是 | - |
| `结束帧` | 视频序列的结束图像。 | IMAGE | 是 | - |
| `提示词` | 提示描述（最多 2000 个字符）。 | STRING | 是 | - |
| `种子` | 用于控制生成随机性的种子值（默认：1）。 | INT | 是 | 0 到 2147483647 |

### viduq3-pro 和 viduq3-turbo 输入

以下参数由两个模型选项（`viduq3-pro` 和 `viduq3-turbo`）共享。选择模型后会显示这些参数。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 输出视频的分辨率。选择 `model` 后显示此参数。 | COMBO | 是 | `"720p"`<br />`"1080p"` |
| `duration` | 输出视频的时长（秒）（默认：5）。选择 `model` 后显示此参数。 | INT | 是 | 1 到 16 |
| `audio` | 启用后，输出带声音的视频（包括对话和音效）（默认：False）。选择 `model` 后显示此参数。 | BOOLEAN | 是 | `True`<br />`False` |

**注意：** `first_frame` 和 `end_frame` 图像必须具有相似的宽高比。两张图像的宽高比必须相互在 80% 到 125% 之间（相对接近度在 0.8 到 1.25 之间）。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 生成的视频文件。 | VIDEO |
