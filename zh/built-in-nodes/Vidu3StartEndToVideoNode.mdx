此节点通过在起始帧和结束帧之间创建过渡来生成视频，并由文本提示词引导。它使用 Vidu Q3 模型在两幅图像之间进行插值，并以选定的时长和分辨率生成视频。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于视频生成的模型。选择某个选项后会显示 `resolution`、`duration` 和 `audio` 的附加配置参数。 | DYNAMIC_COMBO | 是 | `"viduq3-pro"`<br />`"viduq3-turbo"` |
| `起始帧` | 视频序列的起始图像。 | IMAGE | 是 | - |
| `结束帧` | 视频序列的结束图像。 | IMAGE | 是 | - |
| `提示词` | 提示词描述（最多 2000 个字符）。 | STRING | 是 | 最多 2000 个字符 |
| `种子` | 用于控制生成随机性的种子值。具有生成后控制选项（默认值：1）。 | INT | 是 | 0 到 2147483647 |

### viduq3-pro 和 viduq3-turbo 输入

以下参数由两个模型选项（`viduq3-pro` 和 `viduq3-turbo`）共享。它们会在选择模型后出现。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | `"720p"`<br />`"1080p"` |
| `duration` | 输出视频的时长，单位为秒（默认值：5）。 | INT | 是 | 1 到 16 |
| `audio` | 启用后，输出带声音的视频（包括对话和音效）（默认值：False）。 | BOOLEAN | 是 | `True`<br />`False` |

**注意：** `first_frame` 和 `end_frame` 图像必须具有相似的宽高比。两张图像的宽高比必须保持在彼此的 80% 到 125% 以内（相对接近度在 0.8 到 1.25 之间）。

**注意：** 对于 `viduq3-turbo`，720p 下价格为每秒 0.06 美元，1080p 下为每秒 0.08 美元。对于 `viduq3-pro`，720p 下价格为每秒 0.15 美元，1080p 下为每秒 0.16 美元。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 生成的视频文件。 | VIDEO |
