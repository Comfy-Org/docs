SaveImage 节点将输入的图像以 PNG 文件的形式保存到你的 ComfyUI 输出目录中。它可以将工作流元数据（例如提示词）嵌入到每个保存的文件中，并原样返回图像，以便其他节点仍可继续使用这些图像。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `图片` | 要保存的图像。 | IMAGE | 是 | - |
| `文件名前缀` | 保存文件的前缀。其中可以包含格式化信息，例如 `%date:yyyy-MM-dd%` 或 `%Empty Latent Image.width%`，以引用来自其他节点的值（默认值："ComfyUI"）。 | STRING | 是 | - |

该节点还会接收两个隐藏输入：`prompt` 和 `extra_pnginfo`，它们由 ComfyUI 自动填充工作流提示词和额外的 PNG 信息。当启用元数据时，这些信息会作为文本元数据嵌入到每个保存的 PNG 文件中。

每张保存图像的文件名由 `filename_prefix`、一个可选的 `%batch_num%` 占位符（会被替换为该图像在批次中的位置）以及一个五位计数器组成，例如 `ComfyUI_00001_.png`。图像以 PNG 压缩级别 4 写入。

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `images` | 原始的输入图像，在保存到磁盘后原样返回。 | IMAGE |
| `ui` | 仅供 UI 使用的结果，包含已保存图像文件的列表（文件名、子文件夹和类型），用于在前端展示。 | UI_RESULT |
