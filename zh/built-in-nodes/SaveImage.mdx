SaveImage 节点将输入图像以 PNG 文件格式保存到您的 ComfyUI 输出目录中。它可以将工作流元数据（如提示词）嵌入到每个保存的文件中，并原样返回图像，以便它们仍可供其他节点使用。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `图片` | 要保存的图像。 | IMAGE | 是 | - |
| `文件名前缀` | 要保存文件的前缀。可包含格式化信息，如 `%date:yyyy-MM-dd%` 或 `%Empty Latent Image.width%`，以引用来自节点的值（默认值："ComfyUI"）。 | STRING | 是 | - |

该节点还接收两个隐藏输入 `prompt` 和 `extra_pnginfo`，ComfyUI 会自动使用工作流提示词和额外的 PNG 信息填充它们。当元数据功能启用时，这些信息将作为文本元数据嵌入到每个保存的 PNG 文件中。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `images` | 原始输入图像，保存到磁盘后原样返回。 | IMAGE |
| `ui` | 仅用于界面的结果，包含已保存图像文件的列表（文件名、子文件夹和类型），用于在前端显示。 | UI_RESULT |
