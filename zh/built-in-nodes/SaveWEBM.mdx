SaveWEBM 节点将一系列图像保存为 WEBM 视频文件。它接收多张输入图像，并使用 VP9 或 AV1 编解码器，按照可配置的质量设置和帧率将其编码为视频。生成的视频文件会保存到输出目录，并带有包括提示信息在内的元数据。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | RGBA 图像会将其 Alpha 通道作为透明度保存（仅限 VP9 编解码器）。 | IMAGE | 是 | - |
| `文件名前缀` | 输出文件名的前缀（默认值："ComfyUI"）。 | STRING | 否 | - |
| `编解码器` | 用于编码的视频编解码器。 | COMBO | 是 | "vp9"<br />"av1" |
| `帧率` | 输出视频的帧率（默认值：24.0）。 | FLOAT | 否 | 0.01-1000.0 |
| `crf` | `crf` 越高，质量越低且文件越小；`crf` 越低，质量越高且文件越大（默认值：32.0）。 | FLOAT | 否 | 0-63.0 |

**关于 Alpha 通道的说明：** 仅在使用 VP9 编解码器时，才会保留 RGBA 图像中的 Alpha 通道。使用 AV1 编解码器时，Alpha 通道会被忽略，仅编码 RGB 数据。

**关于文件命名的说明：** 视频会以 `{filename_prefix}_{counter:05}_.webm` 保存到输出目录，其中计数器会自动递增，以避免覆盖现有文件。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `images` | 输入图像，在视频保存后原样传递。 | IMAGE |
| UI preview | 显示已保存 WEBM 文件的视频预览。 | PREVIEW |
