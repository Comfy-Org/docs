SaveWEBM 节点将一系列图像保存为 WEBM 视频文件。它接收多个输入图像，并使用 VP9 或 AV1 编码器将它们编码为视频，可配置质量设置和帧率。生成的视频文件将保存到输出目录，并附带包含提示信息的元数据。

## 输入
| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | RGBA 图像会将其 alpha 通道保存为透明度（仅限 vp9 编码器）。 | IMAGE | 是 | - |
| `文件名前缀` | 输出文件名的前缀（默认值："ComfyUI"）。 | STRING | 否 | - |
| `编解码器` | 用于编码的视频编解码器。 | COMBO | 是 | "vp9"<br />"av1" |
| `帧率` | 输出视频的帧率（默认值：24.0）。 | FLOAT | 否 | 0.01-1000.0 |
| `crf` | 较高的 `crf` 值意味着较低的质量和较小的文件大小，较低的 `crf` 值意味着较高的质量和较大的文件大小（默认值：32.0）。 | FLOAT | 否 | 0-63.0 |

**关于 alpha 通道的说明：** RGBA 图像中的 alpha 通道仅在使用 VP9 编码器时保留。使用 AV1 编码器时，alpha 通道将被忽略，仅编码 RGB 数据。

**关于文件命名的说明：** 视频保存到输出目录时，文件名为 `{filename_prefix}_{counter:05}_.webm`，其中计数器会自动递增以避免覆盖现有文件。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `images` | 输入图像，在视频保存后原样传递。 | IMAGE |
| UI preview | 显示已保存 WEBM 文件的视频预览。 | PREVIEW |
