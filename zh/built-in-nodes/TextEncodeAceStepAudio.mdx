TextEncodeAceStepAudio 节点通过将标签（tags）和歌词（lyrics）组合为 token 来处理用于音频条件化的文本输入，并使用可调节的歌词强度进行编码。该节点接收一个 CLIP 模型以及文本描述和歌词，将它们一起 tokenize，并生成适用于音频生成任务的条件化数据。该节点允许通过一个强度参数微调歌词的影响，该参数控制歌词对最终输出的作用程度。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 用于 tokenize 和编码的 CLIP 模型 | CLIP | 是 | - |
| `标签` | 用于音频条件化的文本标签或描述（支持多行输入和动态提示） | STRING | 是 | - |
| `歌词` | 用于音频条件化的歌词文本（支持多行输入和动态提示） | STRING | 是 | - |
| `歌词强度` | 控制歌词对条件化输出影响的强度（默认值：1.0，步长：0.01） | FLOAT | 是 | 0.0 - 10.0 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `conditioning` | 编码后的条件化数据，包含已处理并应用了歌词强度的文本 token | CONDITIONING |
