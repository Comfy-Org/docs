`ModelSamplingStableCascade` 节点通过向采样参数应用 `shift` 值，将 Stable Cascade 采样设置应用到模型中。它返回一个带有自定义 Stable Cascade 采样配置的输入模型修补副本，原始模型保持不变。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要应用 Stable Cascade 采样的输入模型 | MODEL | 是 | - |
| `移位` | 应用于采样参数的 `shift` 值（默认值：2.0） | FLOAT | 是 | 0.0 - 100.0 （步长：0.01） |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `model` | 已应用 Stable Cascade 采样的修改后模型 | MODEL |
