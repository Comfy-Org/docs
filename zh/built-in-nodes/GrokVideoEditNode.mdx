此节点使用 Grok API 根据文本提示编辑现有视频。它会上传您的视频，向 AI 模型发送请求以根据您的描述对其进行修改，然后返回新生成的视频。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频编辑的 AI 模型（默认值："grok-imagine-video"）。 | COMBO | 是 | "grok-imagine-video" |
| `prompt` | 所需视频的文本描述。 | STRING | 是 | N/A |
| `video` | 要编辑的输入视频。最大支持时长 8.7 秒，文件大小不超过 50MB。 | VIDEO | 是 | N/A |
| `seed` | 用于确定节点是否应重新运行的种子；无论种子为何，实际结果都是不确定的（默认值：0）。 | INT | 否 | 0 到 2147483647 |

**约束条件：**

* `prompt` 不能为空。
* 输入 `video` 的时长必须在 1 到 8.7 秒之间。
* 输入 `video` 的文件大小不得超过 50MB。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 由 AI 模型生成的编辑后视频。 | VIDEO |
