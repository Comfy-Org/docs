此节点使用 Grok API 根据文本提示编辑现有视频。它会上传你的视频，向 AI 模型发送请求以根据你的描述进行修改，并返回新生成的视频。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频编辑的 AI 模型（默认："grok-imagine-video"）。 | COMBO | 是 | "grok-imagine-video" |
| `prompt` | 所需视频的文本描述。 | STRING | 是 | N/A |
| `video` | 要编辑的输入视频。支持的最大时长为 8.7 秒，文件大小为 50MB。 | VIDEO | 是 | N/A |
| `seed` | 用于确定节点是否应重新运行的种子；无论种子如何，实际结果都是非确定性的（默认：0）。 | INT | 否 | 0 到 2147483647 |

**约束：**

* `prompt` 不能为空。
* 输入 `video` 的时长必须在 1 到 8.7 秒之间。
* 输入 `video` 文件大小不得超过 50MB。

**注意：** 此节点是 API 节点，需要 Comfy.org 账户和 API 密钥才能运行。使用费用约为每秒视频 $0.06。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | AI 模型生成的编辑后的视频。 | VIDEO |
