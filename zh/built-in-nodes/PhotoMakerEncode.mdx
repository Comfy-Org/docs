PhotoMakerEncode 节点将参考图像与文本提示词相结合，为图像生成创建条件数据。当文本包含单词 "photomaker" 时，该节点使用 PhotoMaker 模型将参考图像的视觉身份插入到提示词中该位置处的条件数据中。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `photomaker` | 用于处理参考图像并生成基于图像的嵌入向量的 PhotoMaker 模型 | PHOTOMAKER | 是 | - |
| `图像` | 为条件数据提供视觉特征的参考图像 | IMAGE | 是 | - |
| `clip` | 用于文本分词和文本编码的 CLIP 模型 | CLIP | 是 | - |
| `文本` | 用于生成条件数据的文本提示词。支持多行文本和动态提示词（默认："photograph of photomaker"） | STRING | 是 | Any string |

**注意：** 当文本包含独立单词 "photomaker" 时，节点会从编码后的提示词中移除该单词，并使用 PhotoMaker 模型在该位置应用参考图像的视觉身份。如果文本中未找到 "photomaker"，节点将返回不包含图像影响的标准文本条件数据。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `CONDITIONING` | 包含用于引导图像生成的文本和图像嵌入向量的条件数据，以及来自 CLIP 文本编码器的池化输出 | CONDITIONING |
