使用 Kling 4.0 模型通过文本提示编辑现有视频，可选地由参考视频和参考图像引导。结果保持输入视频的长度。使用它来改变片段中发生的事情、重新设计风格或替换元素，同时保持原始时间不变。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 模型选择器。仅 `"kling-4.0"` 可用；选择它会显示下方的输入。 | DYNAMIC_COMBO | 是 | `"kling-4.0"` |

### kling-4.0 输入

当 `model` 设置为 `"kling-4.0"` 时，这些输入会显示。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `video_1` | 要编辑的视频，长度为 3 到 30 秒。输出保持其长度。 | VIDEO | 是 | 3 到 30 秒 |
| `reference_videos` | 参考视频的可增长槽位，最多 4 个。在提示中将其称为 `@Video2` 等。每个视频和所有视频合计长度必须为 3 到 30 秒。 | AUTOGROW | 否 | 0 到 4 个视频 |
| `reference_images` | 参考图像的可增长槽位，最多 10 个。在提示中将其称为 `@Image1`、`@Image2` 等。 | AUTOGROW | 否 | 0 到 10 张图像 |
| `prompt` | 描述要更改什么以及要保留什么。将被编辑的视频称为 `@Video1`，将参考视频称为 `@Video2` 等，将图像称为 `@Image1` 等。 | STRING | 是 | 1 到 26000 个字符 |
| `resolution` | 输出视频的分辨率。默认：`"720p"`。 | COMBO | 是 | `"720p"`<br />`"1080p"` |
| `aspect_ratio` | 输出视频的宽高比。`"adaptive"` 保持输入视频的宽高比。默认：`"adaptive"`。 | COMBO | 是 | `"adaptive"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `seed` | 种子控制节点是否应重新运行；无论种子如何，结果都是不确定的。默认：42。 | INT | 是 | 0 到 2147483647 |

**约束和行为：**

* 输入视频和每个参考视频必须为 3 到 30 秒长，至少 700x700 且最多 4553x4553 像素，总计不超过 8,294,400 像素，宽高比在 2:5 到 5:2 之间，帧率至少 24 fps。所有视频合计不得超过 30 秒。
* 每张参考图像必须至少为 300x300 像素，宽高比在 2:5 到 5:2 之间，并且最多可连接 10 张图像。
* 当连接的该类输入少于 N 个时，提示中提到 `@VideoN` 或 `@ImageN` 会引发错误。
