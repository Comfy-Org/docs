此节点使用 Tripo 的 API 同步生成 3D 模型，通过处理最多四张展示物体不同视图的图像（前、左、后、右）来实现。它需要一张前视图图像以及至少一个额外视图（左、后或右）来构建 3D 模型。纹理、PBR 材质、几何质量和输出格式均可从该节点控制。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 物体的前视图图像。 | IMAGE | 是 | - |
| `左侧图像` | 物体的左视图图像。 | IMAGE | 否 | - |
| `背面图像` | 物体的后视图图像。 | IMAGE | 否 | - |
| `右侧图像` | 物体的右视图图像。 | IMAGE | 否 | - |
| `模型版本` | 用于生成的模型版本。 | COMBO | 否 | 多个可用选项 |
| `朝向` | 3D 模型的方向设置（默认：`"default"`）。 | COMBO | 否 | 多个可用选项 |
| `纹理` | 生成纹理贴图。关闭时返回裸几何体并忽略 `pbr`。（默认：True） | BOOLEAN | 否 | - |
| `PBR` | PBR 材质贴图（基础色、金属度、粗糙度、法线）。需要 `texture`。（默认：True） | BOOLEAN | 否 | - |
| `模型种子` | 模型生成的随机种子（默认：42）。 | INT | 否 | 0 到 2,147,483,647 |
| `纹理种子` | 纹理生成的随机种子（默认：42）。 | INT | 否 | 0 到 2,147,483,647 |
| `纹理质量` | 纹理生成的质量级别（默认：`"standard"`）。`"detailed"` = HD 纹理，`"extreme"` = 8K 超高清纹理。 | COMBO | 否 | `"standard"`<br />`"detailed"`<br />`"extreme"` |
| `纹理对齐` | 用于将纹理与模型对齐的方法（默认：`"original_image"`）。 | COMBO | 否 | `"original_image"`<br />`"geometry"` |
| `面数限制` | 最大面数。-1 让 Tripo 自适应选择（v3.x standard 约 140 万面，detailed 约 200 万面）。Tripo 会静默限制：v2.5 为 500,000，四边形网格为 150,000。（默认：-1） | INT | 否 | -1 到 2,000,000 |
| `四边形` | 四边形网格输出。Tripo 以 FBX 格式交付四边形网格，因此结果会出现在 FBX 输出上，而 GLB 输出保持为空。（默认：False） | BOOLEAN | 否 | - |
| `几何质量` | 几何体生成的质量级别（默认：`"standard"`）。 | COMBO | 否 | `"standard"`<br />`"detailed"` |
| `smart_low_poly` | 具有干净、手工制作风格拓扑的低多边形网格（500-20,000 面，四边形 500-10,000）。最适合简单主体；复杂主体可能会失败。（默认：False） | BOOLEAN | 否 | - |
| `auto_size` | 将带纹理的模型缩放到以米为单位的真实世界尺寸。Tripo 将该尺寸存储为模型的场景变换，并在模型被转换、绑定或重定向时烘焙进去；没有纹理时忽略。（默认：False） | BOOLEAN | 否 | - |

**注意：** 前视图图像（`image`）始终必需，并且还必须提供 `image_left`、`image_back` 或 `image_right` 中的至少一个。关闭 `texture` 会自动关闭 `pbr`，因为 `pbr` 需要纹理。当启用 `smart_low_poly` 且 `face_limit` 未保持为 -1 时，三角形网格的 `face_limit` 必须介于 500 和 20,000 之间，四边形网格必须介于 500 和 10,000 之间。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `模型文件` | 生成的 3D 模型的文件路径或标识符（仅用于向后兼容）。 | STRING |
| `模型任务ID` | 用于跟踪模型生成过程的任务标识符。 | MODEL_TASK_ID |
| `GLB` | 生成的 GLB 格式 3D 模型文件。启用 `quad` 时为空。 | FILE3DGLB |
| `FBX` | 生成的 FBX 格式 3D 模型文件。仅在启用 `quad` 时填充。 | FILE3DFBX |
