构建 MOSS-Image 读取的布局提示。它接收在 Create Bounding Boxes 节点中绘制的元素，并输出一个 JSON 布局，每个框对应一个条目：其标签、其说明以及其在目标画布像素空间中的矩形。将 `width` 和 `height` 设置为你计划生成的图像尺寸，然后将输出连接到文本编码器的提示输入。如果没有连接任何元素，则原样返回提示文本。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `prompt` | 整个图像的描述。它成为布局的说明。 | STRING | 是 | - |
| `element` | 要放置的元素，来自 Create Bounding Boxes 节点。每个框提供其说明；文本框还提供其文本，带有调色板的框会保留调色板。 | ARRAY | 是 | - |
| `width` | 生成图像的宽度（像素）。框会转换到此像素网格，因此请使用你计划生成的图像尺寸（默认值：1024）。 | INT | 是 | 16 到 16384（步长 16） |
| `height` | 生成图像的高度（像素）。框会转换到此像素网格，因此请使用你计划生成的图像尺寸（默认值：1024）。 | INT | 是 | 16 到 16384（步长 16） |
| `character_boxes` | 要标记为角色而非对象的框的编号，如 Create Bounding Boxes 预览中所标记，例如 "1, 3"。字符串中的每个数字都会被读取，因此任何分隔符都有效（默认值：空）。 | STRING | 是 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `prompt` | 布局提示：一个 JSON 对象，包含说明、每个框的条目以及框坐标格式。当没有连接任何元素时，输入文本会直接传递。 | STRING |

## 说明

框矩形从 Create Bounding Boxes 以 0 到 1000 之间的归一化坐标传入，并以相对于画布中心的像素写入布局，顺序为 `yxyx`。因此，`width` 和 `height` 值必须与你生成的图像匹配，否则框会落在错误的位置。

包含文本的框始终标记为文本，编号列在 `character_boxes` 中的框标记为角色，其他所有框都标记为对象。
