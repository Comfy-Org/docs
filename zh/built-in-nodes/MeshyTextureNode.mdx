Meshy：纹理节点可将 AI 生成的纹理应用于 3D 模型。它接收来自先前 Meshy 3D 生成或转换节点的任务 ID，并使用文本描述或参考图像为模型创建新纹理。该节点以 GLB 和 FBX 文件格式输出带纹理的模型。

## 输入
| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 用于纹理处理的 AI 模型版本。 | COMBO | 是 | `"meshy-7"`<br />`"meshy-6"`<br />`"latest"` |
| `meshy_task_id` | 来自先前 Meshy 3D 生成或转换任务的唯一标识符（任务 ID）。它提供要进行纹理处理的基础 3D 模型。 | MESHY_TASK_ID | 是 | - |
| `启用原始UV` | 使用模型的原始 UV，而不是生成新的 UV。启用时（默认：`True`），Meshy 会保留上传模型中的现有纹理。如果模型没有原始 UV，输出质量可能不佳。这是一个高级选项。 | BOOLEAN | 否 | true / false |
| `PBR` | 为带纹理的模型启用基于物理的渲染（PBR）材质输出（默认：`False`）。这是一个高级选项。 | BOOLEAN | 否 | true / false |
| `文本风格提示` | 使用文本描述您期望的对象纹理风格。最多 600 个字符。不能与 `image_style` 同时使用。 | STRING | 否 | - |
| `图像风格` | 用于引导纹理处理过程的 2D 图像。不能与 `text_style_prompt` 同时使用。 | IMAGE | 否 | - |
| `纹理分辨率` | 基础颜色纹理分辨率。更高的分辨率能捕捉更多表面细节。 | COMBO | 是 | `"2k"`<br />`"4k"`<br />`"8k"` |

**参数约束：**

* 必须提供 `text_style_prompt` 或 `image_style` 中的一项，但不能同时提供两者。
* `text_style_prompt` 最多限制为 600 个字符。

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `模型文件` | 生成的 GLB 模型的文件名。此输出仅用于向后兼容。 | STRING |
| `meshy_task_id` | 此纹理处理作业的唯一任务标识符，可用于引用结果。 | MESHY_TASK_ID |
| `GLB` | 以 GLB 文件格式保存的带纹理 3D 模型。 | FILE3DGLB |
| `FBX` | 以 FBX 文件格式保存的带纹理 3D 模型。 | FILE3DFBX |
