此节点根据 MoGe 几何对象中存储的相机内参推导视场角和焦距。它可以返回垂直、水平或对角线方向的视场角，单位可选角度或弧度。垂直视场角输出可用于，例如，为 SAM3DBody_Predict 节点提供输入。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 取值范围 |
|-----------|-------------|-----------|----------|-------|
| `moge_geometry` | MoGe 几何对象。它必须包含内参矩阵，以及 image、points 或 depth 数据中的至少一种，用于读取像素高度以进行焦距转换。 | MOGE_GEOMETRY | 是 | — |
| `轴` | 计算视场角的轴："vertical"（fov_y）、"horizontal"（fov_x）或"diagonal"（默认值："vertical"）。 | COMBO | 是 | "vertical"<br />"horizontal"<br />"diagonal" |
| `单位` | 视场角的输出单位（默认值："degrees"）。 | COMBO | 是 | "degrees"<br />"radians" |

注意：如果 `moge_geometry` 不包含内参（全景几何对象没有内参），或者不包含 image、points 和 depth 数据中的任何一种，节点将引发错误。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `视场` | 沿所选轴方向的视场角，单位为所选单位（角度或弧度）。 | FLOAT |
| `焦距（像素）` | 镜头的焦距（以像素为单位），由垂直内参和像素高度推导得出。 | FLOAT |
