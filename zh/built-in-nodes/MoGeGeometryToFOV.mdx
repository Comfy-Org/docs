此节点从存储在 MoGe 几何对象中的相机内参推导出视场角（FOV）和焦距。它能够以度或弧度返回垂直、水平或对角线 FOV。例如，垂直 FOV 输出可用于馈送给 SAM3DBody_Predict 节点。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `moge_geometry` | MoGe 几何对象。它必须包含内参矩阵，以及 `image`、`points` 或 `depth` 数据中的至少一项，用于读取像素高度以完成焦距换算。 | MOGE_GEOMETRY | 是 | — |
| `轴` | 计算 FOV 所沿的轴："vertical"（fov_y）、"horizontal"（fov_x）或 "diagonal"（默认："vertical"）。 | COMBO | 是 | "vertical"<br />"horizontal"<br />"diagonal" |
| `单位` | FOV 的输出单位（默认："degrees"）。 | COMBO | 是 | "degrees"<br />"radians" |

注意：如果 `moge_geometry` 不包含内参（全景几何没有内参），或者既不包含 `image`、`points` 也不包含 `depth` 数据，该节点会报错。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `fov` | 沿所选轴的视场角，以所选单位（度或弧度）表示。 | FLOAT |
| `focal_pixels` | 镜头焦距（以像素为单位），由垂直内参和像素高度推导得出。 | FLOAT |
