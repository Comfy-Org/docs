此节点使用 Fish Audio 语音转文本服务将音频转录为文本。它会自动检测音频的语言，并可选地以 JSON 形式返回词级时间戳片段。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `音频` | 要转录的音频。 | AUDIO | 是 | — |
| `语言` | ISO 639-1 语言提示（例如 'en'、'zh'）。无论如何都会自动检测语言。默认值：""（空字符串）。 | STRING | 否 | 任意 ISO 639-1 语言代码，例如 `en`、`zh`；空字符串表示自动检测 |
| `precise_timestamps` | 返回词级时间戳片段。默认值：false。 | BOOLEAN | 否 | true or false |

注意：`language` 参数只是一个提示——语言始终会根据音频自动检测。当 `precise_timestamps` 为 false（默认值）时，不会返回词级时间戳；当为 true 时，输出片段会包含词级时间戳。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `text` | 转录得到的文本。 | STRING |
| `language_code` | 为音频检测到的 ISO 639-1 语言代码。 | STRING |
| `segments_json` | 包含转录片段的 JSON 字符串。当启用 `precise_timestamps` 时，会包含词级时间戳。 | STRING |
