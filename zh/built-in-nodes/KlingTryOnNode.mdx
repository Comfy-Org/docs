使用 Kling 的虚拟试衣功能为人物穿上服装。连接一张人物照片和一张服装照片，节点会返回该人物穿着该服装的新图像。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `person_image` | 一张人物照片，最好是正面或四分之三视角。必须至少为 300x300 像素；任一边超过 2048 像素的图像会先被缩小。 | IMAGE | 是 | N/A |
| `garment_image` | 要穿上的服装：商品图、平铺图、模特图或穿在模特身上的照片。穿在模特身上的照片可能会保留该套穿搭的其余部分。必须至少为 300x300 像素。仅支持服装；不支持鞋子、包和配饰。 | IMAGE | 是 | N/A |
| `keep_pose` | 关闭后可允许姿势发生变化，以获得更好的服装展示效果。高级参数（默认值：True）。 | BOOLEAN | 是 | `True`<br />`False` |
| `seed` | 种子控制节点是否应重新运行；无论种子如何，结果都是非确定性的。此参数具有“生成后控制”功能（默认值：42）。 | INT | 是 | 0 到 2147483647 |

**注意：** 结果尺寸与 `person_image` 相同，最长边限制为 2048 像素。两个输入都会上传到 Kling 的 API，可能需要一些时间。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `IMAGE` | 人物穿着该服装后的图像。 | IMAGE |
