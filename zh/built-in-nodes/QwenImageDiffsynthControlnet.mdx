QwenImageDiffsynthControlnet 会将扩散合成控制网络补丁应用到基础模型上。它使用输入图像和可选遮罩，以可调节的强度引导模型的生成过程，输出一个已应用该控制网络影响的修补后模型，从而实现更可控的图像合成。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要应用控制网络补丁的基础模型 | MODEL | 是 | - |
| `模型补丁` | 要应用到基础模型上的控制网络补丁模型 | MODEL_PATCH | 是 | - |
| `vae` | 扩散过程中使用的 VAE（变分自编码器） | VAE | 是 | - |
| `图像` | 用于引导控制网络的输入图像。仅使用前三个颜色通道（RGB），任何额外的通道都会被丢弃 | IMAGE | 是 | - |
| `强度` | 控制网络影响的强度（默认值：1.0） | FLOAT | 是 | -10.0 到 10.0 （步长：0.01） |
| `遮罩` | 可选遮罩，用于定义应应用控制网络的区域。对于 DiffSynth 和 Z-Image 补丁，遮罩在使用前会在内部进行反转 | MASK | 否 | - |
| `start_percent` | 去噪过程中控制网络开始生效的位置，以总采样步数的比例表示（默认值：0.0） | FLOAT | 否 | 0.0 到 1.0 （步长：0.001） |
| `end_percent` | 去噪过程中控制网络停止生效的位置（默认值：1.0） | FLOAT | 否 | 0.0 到 1.0 （步长：0.001） |

**注意：** `start_percent` 和 `end_percent` 的值将控制网络限制在去噪过程的某个窗口内；在该窗口之外，模型将不使用补丁进行采样。如果 `strength` 设为 0，节点将返回未修改的基础模型。当提供遮罩时，对于 Z-Image Control 和标准 DiffSynth 路径，遮罩会被反转（1.0 - mask）并重塑形状；而 Qwen Image 2.1 Fun ControlNet 补丁则按原样使用遮罩。节点会根据所加载的模型补丁选择其内部补丁实现，因此相同的输入在 Z-Image Control、Qwen Image 2.1 Fun ControlNet 和标准 DiffSynth 检查点上会表现出细微差异。此节点被标记为实验性功能。

| --- | --- | --- |
| `model` | 已应用扩散合成控制网络补丁的修改后模型 | MODEL |
