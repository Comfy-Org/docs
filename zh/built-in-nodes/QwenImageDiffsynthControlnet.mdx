QwenImageDiffsynthControlnet 将一个扩散合成控制网络补丁应用到基础模型上。它使用输入图像和可选掩码，以可调强度引导模型的生成过程，生成一个融合了控制网络影响的补丁模型，从而实现更可控的图像合成。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要应用控制网络补丁的基础模型 | MODEL | 是 | - |
| `模型补丁` | 要应用到基础模型的控制网络补丁模型 | MODEL_PATCH | 是 | - |
| `vae` | 扩散过程中使用的 VAE（变分自编码器） | VAE | 是 | - |
| `图像` | 用于引导控制网络的输入图像。仅使用前三个颜色通道（RGB）；任何额外的通道将被丢弃 | IMAGE | 是 | - |
| `强度` | 控制网络影响的强度（默认值：1.0） | FLOAT | 是 | -10.0 到 10.0 |
| `遮罩` | 可选掩码，定义控制网络应应用的区域。该掩码在内部使用前会被反转 | MASK | 否 | - |

**注意：** 当提供掩码时，它会自动反转（1.0 - mask）并重新调整形状，以匹配控制网络处理所需的预期尺寸。根据模型补丁是 ZImage Control 类型还是标准 DiffSynth 控制网络，此节点使用不同的内部处理方法。此节点标记为实验性。

## 输出

| --- | --- | --- |
| `model` | 应用了扩散合成控制网络补丁的修改后模型 | MODEL |
