此节点使用 Bria RMBG 2.0 服务移除图像背景。它会将图像发送至外部 API 进行处理，并返回移除背景后的结果。

## 输入

当 `moderation` 设置为 `"true"` 时，该选择器会显示额外的审核选项。

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `内容审核` | 审核设置。当设置为 `"true"` 时，额外的审核选项将变为可用。 | DYNAMIC_COMBO | 是 | `"false"`<br />`"true"` |
| `图像` | 要移除背景的输入图像。 | IMAGE | 是 | - |
| `种子` | 种子控制节点是否应重新运行；无论种子如何，结果都是非确定性的。默认值：`0`。 | INT | 是 | 0 到 2147483647 |

### `moderation` 为 `"true"` 时的输入

这些参数仅在 `moderation` 设置为 `"true"` 时出现。`"false"` 选项不会添加额外的输入。

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | 对输入图像启用视觉内容审核。默认值：`False`。 | BOOLEAN | 否 | - |
| `visual_output_moderation` | 对输出图像启用视觉内容审核。默认值：`True`。 | BOOLEAN | 否 | - |

**注意：** `visual_input_moderation` 和 `visual_output_moderation` 参数依赖于 `moderation` 参数。它们仅在 `moderation` 设置为 `"true"` 时处于活动状态。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 已处理并移除背景的图像。 | IMAGE |
