此节点使用 Pika 根据文本描述生成音效。描述声音内容及其持续时间，节点将返回一段音频片段。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 音效应表现的内容。不能为空。默认值：""（空字符串）。 | STRING | 是 | 1 到 4000 个字符 |
| `duration` | 音效时长（秒）。默认值：5.0。 | FLOAT | 是 | 1.0 到 20.0（步长：0.1） |
| `seed` | 用于采样的种子。默认值：42。 | INT | 是 | 0 到 2147483647 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `AUDIO` | 生成的音效。 | AUDIO |
