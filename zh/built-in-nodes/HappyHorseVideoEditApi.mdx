使用 HappyHorse 模型，通过文本指令或参考图像编辑视频。输出时长为 3-15 秒，并与输入视频保持一致；超过 15 秒的输入视频会被截断。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的 HappyHorse 视频编辑模型。此选择决定可用的提示词、分辨率、宽高比和参考图像选项。 | DYNAMIC_COMBO | 是 | "happyhorse-1.0-video-edit" |
| `video` | 要编辑的视频。 | VIDEO | 是 | 3 到 60 seconds |
| `seed` | 用于生成的种子（默认：0）。 | INT | 是 | 0 到 2147483647 |
| `watermark` | 是否在结果中添加 AI 生成的水印（默认：False）。高级参数。 | BOOLEAN | 是 | True<br />False |

### happyhorse-1.0-video-edit 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 编辑指令或风格迁移要求。必须至少包含 1 个字符。 | STRING | 是 | - |
| `resolution` | 输出分辨率。 | COMBO | 是 | "720P"<br />"1080P" |
| `ratio` | 宽高比。如果未更改，则近似于输入视频的宽高比。 | COMBO | 是 | "16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4" |

### 参考输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可扩展插槽：连接 0 到 5 张参考图像（`image1`...`image5`）以引导编辑。 | IMAGE | 否 | 0 到 5 images |

**注意：** 输入视频时长必须为 3 到 60 秒。输出时长为 3-15 秒，并与输入视频保持一致；超过 15 秒的输入视频会被截断。`prompt` 必须至少包含 1 个字符。

## 输出

| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 编辑后的视频输出。 | VIDEO |
