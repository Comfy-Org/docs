此节点通过将视频置于新画布上并生成周围区域，将其适配为新的宽高比。源视频的时序与声音保持不变。可用它将横屏片段转换为竖屏，或反之，而无需裁掉画面中的主体。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 取值范围 |
| --- | --- | --- | --- | --- |
| `model` | 用于视频生成的模型。 | DYNAMIC_COMBO | 是 | "MiniMax H3 Max" |

### MiniMax H3 Max 输入

| 参数 | 描述 | 数据类型 | 必需 | 取值范围 |
| --- | --- | --- | --- | --- |
| `video` | 待重新构图（reframe）的源视频，时长 0.5 至 300 秒。 | VIDEO | 是 | 0.5 至 300 秒 |
| `aspect_ratio` | 输出画布的宽高比（默认："9:16"）。 | COMBO | 是 | "16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4"<br />"21:9"<br />"9:21" |
| `resolution` | 输出视频的分辨率（默认："768P"）。 | COMBO | 是 | "480P"<br />"768P"<br />"1080P" |
| `prompt` | 用于指导生成周围区域的可选提示词。 | STRING | 是 | 0 至 50000 个字符 |
| `seed` | 随机种子。相同种子下的相同请求会得到相似但不保证完全相同的结果（默认：42）。 | INT | 是 | 0 至 4294967295 |
