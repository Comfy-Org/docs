SD_4XUpscale_Conditioning 节点用于为使用扩散模型放大图像准备条件数据。它会按所选比例缩放输入图像，添加可选的噪声增强，并返回修改后的正向与负向条件数据，以及一个与放大后尺寸匹配的空 latent。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `图片` | 待放大的输入图像。 | IMAGE | 是 | - |
| `正面条件` | 正向条件数据，引导生成朝向期望的内容。 | CONDITIONING | 是 | - |
| `负面条件` | 负向条件数据，引导生成远离不想要的内容。 | CONDITIONING | 是 | - |
| `缩放比例` | 在准备放大后的条件数据和 latent 时，应用于输入图像尺寸的乘数（默认值：4.0）。 | FLOAT | 是 | 0.0 - 10.0 （步长：0.01） |
| `噪波增强` | 放大过程中添加的噪声量（默认值：0.0）。 | FLOAT | 是 | 0.0 - 1.0 （步长：0.001） |

注意：`noise_augmentation` 是高级参数，在节点界面中位于“Advanced”开关下显示。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 应用了缩放后的图像数据和噪声增强设置后的修改版正向条件数据。 | CONDITIONING |
| `negative` | 应用了缩放后的图像数据和噪声增强设置后的修改版负向条件数据。 | CONDITIONING |
| `latent` | 与放大后尺寸匹配的空 latent 表示。 | LATENT |
