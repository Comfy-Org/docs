此节点让静态图像动起来，使嘴部动作跟随提供的音频轨道。图像和音频上传后，会轮询 Hailuo 03 Max 唇形同步任务，并以你选择的分辨率返回说话视频。输出视频的时长与音频一致。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 用于视频生成的模型。 | DYNAMIC_COMBO | 是 | "MiniMax H3 Max" |

### MiniMax H3 Max 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `image` | 要制作动画的图像，至少 256x256 像素。宽高比必须在 0.4 到 2.5 之间。 | IMAGE | 是 | 单张图像 |
| `audio` | 用于唇形同步的音频，时长为 5 到 899 秒。 | AUDIO | 是 | 5 到 899 秒 |
| `resolution` | 输出分辨率（默认："768P"）。宽高比采用与图像最接近的受支持比例。 | COMBO | 是 | "480P"<br />"768P"<br />"1080P"<br />"2K" |
| `transcription` | 转录音频以引导唇形同步（默认：false）。 | BOOLEAN | 否 | true<br />false |
| `seed` | 随机种子。使用相同种子的相同请求会得到相似但不保证完全相同的结果（默认：42）。 | INT | 是 | 0 到 2147483647 |

## 输出
