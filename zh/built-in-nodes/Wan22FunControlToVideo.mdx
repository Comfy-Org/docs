Wan22FunControlToVideo 节点为 Wan 视频模型的视频生成准备条件数据和一个空的潜空间张量。它将可选参考图像和控制视频编码到潜空间中，将它们附加到正向和负向条件上，并为所请求的视频创建一个具有正确空间和时间维度的零填充潜空间张量。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `正面提示词` | 用于引导视频生成的正向条件输入 | CONDITIONING | 是 | - |
| `负面提示词` | 用于引导视频生成的负向条件输入 | CONDITIONING | 是 | - |
| `VAE` | 用于将图像编码到潜空间的 VAE 模型 | VAE | 是 | - |
| `宽度` | 输出视频的宽度（像素）（默认值：832，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 输出视频的高度（像素）（默认值：480，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `长度` | 视频序列中的帧数（默认值：81，步长：4） | INT | 是 | 1 to MAX_RESOLUTION |
| `批次大小` | 要生成的视频序列数量（默认值：1） | INT | 是 | 1 到 4096 |
| `参考图像` | 为生成提供视觉指导的可选参考图像 | IMAGE | 否 | - |
| `控制视频` | 引导生成过程的可选控制视频 | IMAGE | 否 | - |

**注意：** `length` 参数按 4 帧的步长处理，节点在构建潜空间时会自动应用时间缩放。当提供 `ref_image` 时，仅对其第一帧进行编码，并作为参考潜空间附加到条件中。当提供 `control_video` 时，它会被裁剪为 `length` 帧，进行编码，并放入条件所使用的 concat 潜空间中。`start_image` 参数在执行逻辑中被引用，但未在节点的输入模式中公开。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `正向提示` | 添加了视频特定潜空间数据的正向条件，包括 concat 潜空间、掩码和可选的参考潜空间 | CONDITIONING |
| `负向提示` | 添加了视频特定潜空间数据的负向条件，包括 concat 潜空间、掩码和可选的参考潜空间 | CONDITIONING |
| `潜变量` | 为视频生成准备的空潜空间张量，其大小根据批大小、潜空间通道、长度、高度和宽度确定 | LATENT |
