PixVerse V6 First-Last-Frame to Video 使用 PixVerse 生成从首帧过渡到尾帧的视频，并可选生成原生音频。提供的两张图像会发送到 PixVerse API，该 API 生成过渡视频并以视频文件形式返回。输出保持首帧的宽高比。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `首帧` | 视频的起始图像。 | IMAGE | 是 | — |
| `尾帧` | 视频的结束图像。 | IMAGE | 是 | — |
| `模型` | 模型和生成设置。选择 PixVerse 模型并显示其生成参数。 | DYNAMIC_COMBO | 是 | "PixVerse V6" |

### PixVerse V6 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述过渡的提示词。 | STRING | 是 | 最多 5000 个字符 |
| `quality` | 输出分辨率。设置长边：360p 为 640px，540p 为 1024px，720p 为 1280px，1080p 为 1920px。（默认：720p） | COMBO | 是 | "360p"<br />"540p"<br />"720p"<br />"1080p" |
| `duration_seconds` | 生成视频的时长，以秒为单位。（默认：5） | INT | 是 | 1 到 15 |
| `generate_audio` | 与视频一起生成原生音轨。（默认：true） | BOOLEAN | 是 | true<br />false |
| `seed` | 视频生成的种子。PixVerse 会记录它，但不会根据它复现一次运行。（默认：42） | INT | 是 | 0 到 2147483647 |
| `negative_prompt` | 对视频中不希望出现元素的可选文本描述。 | STRING | 否 | 最多 2048 个字符 |
| `style` | 应用于整个视频的可选视觉风格。（默认：none） | COMBO | 否 | 多个可用选项（默认："none"） |

注意：去除空白字符后，提示词不能为空，且限制为 5000 个字符。提供负向提示词时，其限制为 2048 个字符。时长必须在 1 到 15 秒之间。输出视频保持首帧的宽高比。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 生成的视频，从首帧过渡到尾帧；当启用 `generate_audio` 时包含音轨。 | VIDEO |
