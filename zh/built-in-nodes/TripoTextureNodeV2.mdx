此节点为 Tripo 工作流中已有的 3D 模型添加纹理，该模型通过前一步生成过程中的任务 ID 来标识。它可以生成 PBR 材质贴图或纯色纹理，并且结果可以通过文本提示、风格图像或参考图像来引导。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | 源模型的任务 ID，由之前的 Tripo 节点（模型生成或模型分割）生成。 | MODEL_TASK_ID / SEGMENT_TASK_ID | 是 | - |
| `pbr` | PBR 材质贴图（基础颜色、金属度、粗糙度、法线）；关闭则生成纯色纹理。（默认值：true） | BOOLEAN | 否 | true<br />false |
| `texture_seed` | 用于纹理生成的种子。（默认值：42）高级输入。 | INT | 否 | 0 到 2147483647 |
| `texture_quality` | 生成纹理的质量。`detailed` = 高清纹理，`extreme` = 8K 超高清纹理。（默认值："standard"）高级输入。 | COMBO | 否 | "standard"<br />"detailed"<br />"extreme" |
| `texture_alignment` | 纹理与模型的对齐方式。（默认值："original_image"）高级输入。 | COMBO | 否 | "original_image"<br />"geometry" |
| `texture_prompt` | 可选的纹理生成文本指导。对于导入的模型（Tripo: Import Model）实际上必需，因为这些模型没有源图像可用于推断颜色。不能与参考图像结合使用。（默认值：空） | STRING | 否 | - |
| `model_version` | 纹理模型：v3.0 用于使用 v3.x 生成的网格，v2.5 用于使用 v2.5 生成的网格。（默认值：v3_0_20250812） | COMBO | 否 | Tripo texture model versions, default "v3_0_20250812" |
| `style_image` | 用于纹理艺术风格的参考图像。仅与 `texture_prompt` 一起使用。 | IMAGE | 否 | - |
| `reference` | 引导纹理的参考图像。不能与 `texture_prompt` 或 `style_image` 结合使用。（默认值："none"） | DYNAMIC_COMBO | 否 | "none"<br />"image"<br />"multiview" |
| `part_names` | 来自 Tripo: Segment Model 的逗号分隔部件名称，用于指定要纹理化的部件。为空则为每个部件添加纹理。（默认值：空）高级输入。 | STRING | 否 | - |

### 图像参考输入

当 `reference` 设置为 "image" 时显示。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | 纹理应遵循的单个参考图像。 | IMAGE | 是 | - |

### 多视图参考输入

当 `reference` 设置为 "multiview" 时显示。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image_front` | 前视图（0°）。 | IMAGE | 是 | - |
| `image_left` | 左视图（90°）。 | IMAGE | 是 | - |
| `image_back` | 后视图（180°）。 | IMAGE | 是 | - |
| `image_right` | 右视图（270°）。 | IMAGE | 是 | - |

**参数约束说明：**

- 参考图像（参考模式 "image" 或 "multiview"）不能与 `texture_prompt` 或 `style_image` 结合使用。
- `style_image` 需要提供 `texture_prompt`。
- 当未提供 `texture_prompt` 时，源模型必须来自文本生成模型、图像生成模型、多视图生成模型或纹理模型任务。没有源图像的模型（导入、分割、完成或重拓扑的模型）需要 `texture_prompt`，因为 Tripo 仅接受由其自身生成的模型的参考图像。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model task_id` | 纹理操作的任务 ID，可以传递给其他 Tripo 节点。 | MODEL_TASK_ID |
| `GLB` | GLB 格式的带纹理模型。当源为四边形网格或 FBX 导入时为空。 | FILE_3D_GLB |
| `FBX` | FBX 格式的带纹理模型。Tripo 对四边形网格和 FBX 导入返回 FBX；否则为空。 | FILE_3D_FBX |
