使用 UltraTex LoRA 对 FLUX.2 Klein 9B 进行条件化，将参考图像的外观绘制到网格上，每个视角生成一张图像。使用 Render Mesh 以 `world normal` 模式渲染这些视角，相机来自 Create Camera Orbit（4 个）加上顶部和底部，然后使用 Bake Texture From Views 烘焙结果。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `conditioning` | 文本条件。UltraTex 训练时使用的是空提示词。 | CONDITIONING | 是 | - |
| `vae` | 用于编码法线、视角和参考图的 VAE。 | VAE | 是 | - |
| `normals` | Render Mesh 的 `world normal` 图像：6 个标准视角，或 4 个侧面视角。 | IMAGE | 是 | - |
| `masks` | 相同视角的 Render Mesh 遮罩，每个视角一个。 | MASK | 是 | - |
| `reference` | 物体应有的外观，从正面相机一侧观察。 | IMAGE | 是 | - |
| `reference_mask` | 参考图的物体遮罩，物体部分为白色。默认：全白。 | MASK | 否 | - |
| `extra_views` | 更多参考图：从其他视角观察的物体，每张都与其视角绑定，就像参考图绑定到正面一样。默认：`"off"`。 | DYNAMIC_COMBO | 是 | `"off"`<br />`"on"` |

### Extra Views "on" 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `right` | 从右视角观察的物体。 | IMAGE | 否 | - |
| `back` | 从后视角观察的物体。 | IMAGE | 否 | - |
| `left` | 从左视角观察的物体。 | IMAGE | 否 | - |
| `top` | 从顶视角观察的物体。 | IMAGE | 否 | - |
| `bottom` | 从底视角观察的物体。 | IMAGE | 否 | - |

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `conditioning` | 携带视角网格、参考潜变量以及 UltraTex 所需的 token 遮罩的条件。 | CONDITIONING |

注意：`normals` 必须包含 6 个标准视角（Create Camera Orbit，`count` 为 4，`poles` 为顶部和底部）或 4 个侧面视角，并且 `masks` 的视角数量必须与之匹配。
