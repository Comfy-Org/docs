StableCascade_StageB_Conditioning 节点通过将现有的 conditioning 信息与 Stage C 生成的先验潜在表示相结合，为 Stable Cascade Stage B 生成准备 conditioning 数据。它会复制每一条 conditioning 条目，并将 Stage C 的 latent 样本存入其中，这样后续的生成步骤就能使用这一先验信息，从而获得更连贯的结果。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `条件` | 需要用 Stage C 先验信息进行修改的 conditioning 数据。列表中的每一条条目都会被复制，并赋予 Stage C 样本。 | CONDITIONING | 是 | - |
| `阶段c` | 来自 Stage C 的潜在表示。其 `samples` 值将作为先验信息添加到 conditioning 中。 | LATENT | 是 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `CONDITIONING` | 已整合 Stage C 先验信息的修改后的 conditioning 数据。 | CONDITIONING |
