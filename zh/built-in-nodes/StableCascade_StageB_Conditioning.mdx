StableCascade_StageB_Conditioning 节点通过将现有 conditioning 信息与 Stage C 生成的先前潜空间表示相结合，为 Stable Cascade Stage B 生成准备 conditioning 数据。它会复制每条 conditioning 条目，并将 Stage C 的潜空间样本添加到其中，从而使生成过程能够利用该先前信息生成更连贯的输出。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `条件` | 待使用 Stage C 先前信息修改的 conditioning 数据 | CONDITIONING | 是 | - |
| `阶段c` | 包含用于 conditioning 的先前样本的 Stage C 潜空间表示 | LATENT | 是 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `CONDITIONING` | 已集成 Stage C 先前信息的修改后 conditioning 数据 | CONDITIONING |
