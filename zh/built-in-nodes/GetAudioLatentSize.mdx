读取音频 latent 并返回其长度、音频通道数和批次大小，这样无需解码音频即可复用这些值。可使用它在采样前调整噪声遮罩的尺寸，或匹配音频与视频的长度。测量得到的值也会打印在节点本身上。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `latent` | 要检查的音频或音频/视频 latent。当 latent 包含多个流时，会测量音频流。 | LATENT | 是 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `length` | 音频 latent 的长度，以 latent 单元而非音频采样数计。 | INT |
| `audio_channels` | 音频通道数。没有音频通道维度的 latent 会报告为一个通道。 | INT |
| `batch_size` | 批次中 latent 的数量。 | INT |
