OpenRouter LLM 节点将文本提示词发送给通过 OpenRouter 服务提供的一组精选热门语言模型，并返回生成的文本响应。它支持来自 Anthropic (Claude)、OpenAI (GPT)、Google (Gemini)、xAI (Grok)、DeepSeek、Qwen、Mistral、Z.AI (GLM)、Moonshot (Kimi) 以及 Perplexity Sonar 的模型，并且可以选择在请求中包含图片或视频作为参考输入。

## 输入
在 `model` 选择器中选中某个模型后，节点会根据所选模型的能力，在通用输入上方显示模型专属小部件——推理强度、网页搜索大小和/或参考媒体槽位。

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 输入给模型的文本。 | STRING | 是 | N/A |
| `model` | 用于生成响应的 OpenRouter 模型。 | DYNAMIC_COMBO | 是 | 有多个可用选项（参见下方各模型部分） |

- **图片和视频限制：** 参考图片和视频的最大数量取决于所选模型。如果提供的图片或视频总数超过模型限制，节点会报错。不支持图片或视频的模型不会显示相应的参考输入槽位。

- **推理行为：** 当 `reasoning_effort` 设置为 "off" 以外的任何值时，请求会要求提供商在内部进行推理，而不返回推理轨迹。

- **Seed 行为：** `seed` 参数具有 `control_after_generate` 行为，即根据用户的小部件设置，在每次节点执行后可以自动更改（例如随机化、递增或固定）。

- **系统提示：** `system_prompt` 参数为可选项，并在用户界面中标记为高级参数。

- **错误情况：** 如果提示词在去除首尾空白后为空、OpenRouter 返回错误、所选模型拒绝响应，或响应中不包含任何 choices 或 message，节点都会报错。节点上的价格徽章会根据所选模型显示每 1K 个 token 的近似成本估算。
