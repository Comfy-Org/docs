TextGenerateLTX2Prompt 节点将简短的用户提示词扩展为详细、音视频兼备的描述，适用于 LTX-2 系列视频模型生成视频。它会自动添加任务相关的系统指令，将格式化后的提示词发送给语言模型，然后返回增强后的文本。当提供了可选的参考图像时，节点会切换到图生视频模式，并基于该图像的内容开始扩展提示词。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 用于文本编码的 CLIP 模型。节点会检查模型的分词器名称以选择匹配的指令：基于 Gemma 4 的模型使用 LTX-2.4 格式，其他模型使用 LTX-2（Gemma 3）格式。 | CLIP | 是 |  |
| `提示词` | 描述场景或概念的原始文本输入，将被扩展为详细的视频生成提示词。 | STRING | 是 |  |
| `最大长度` | 语言模型允许生成的最大 token 数量。 | INT | 是 |  |
| `采样模式` | 文本生成期间用于选择下一个 token 的采样策略。 | COMBO | 是 | `"greedy"`<br />`"top_k"`<br />`"top_p"`<br />`"temperature"` |
| `图像` | 可选的输入图像，用作视频的第一帧。提供后，节点切换到图生视频模式，并使用系统提示词基于图像内容扩展用户提示词。 | IMAGE | 否 |  |
| `思考模式` | 启用后，模型在回答前会先进行推理。任何推理块都会从返回的输出中移除（默认：False）。 | BOOLEAN | 否 |  |
| `use_default_template` | 启用后，节点使用默认聊天模板进行格式化（默认：True）。 | BOOLEAN | 否 |  |
| `视频` | 可选的视频输入，可用作生成的额外上下文。 | VIDEO | 否 |  |
| `音频` | 可选的音频输入，可用作生成的额外上下文。 | AUDIO | 否 |  |

**注意：** 节点的行为会根据其输入而变化：

- 如果提供了 `image`，生成的提示词将针对图生视频任务进行格式化，使用描述如何基于图像内容扩展提示词的系统提示词。如果没有提供图像，则针对文生视频任务进行格式化，使用将提示词扩展为详细视频生成描述的系统提示词。
- 如果 CLIP 分词器名称包含“gemma4”，节点使用 LTX-2.4 系统提示词和 Gemma 4 聊天格式。否则，使用 LTX-2（Gemma 3）系统提示词和聊天格式。
- 如果语言模型在移除推理块后没有生成可用的文本，节点将返回原始 `prompt`。
