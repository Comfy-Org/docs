FreeU_V2 通过对扩散模型的 U-Net 架构应用基于频率的修改来提升图像生成质量。它使用可配置的缩放系数来调整不同块中的特征通道，无需额外训练即可改善输出。该节点通过修补模型的输出块并过滤隐藏状态的高频分量来工作。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要应用 FreeU 增强的扩散模型 | MODEL | 是 | - |
| `b1` | 第一个块的主干特征缩放系数（默认值：1.3） | FLOAT | 是 | 0.0 - 10.0 |
| `b2` | 第二个块的主干特征缩放系数（默认值：1.4） | FLOAT | 是 | 0.0 - 10.0 |
| `s1` | 第一个块的跳跃特征缩放系数（默认值：0.9） | FLOAT | 是 | 0.0 - 10.0 |
| `s2` | 第二个块的跳跃特征缩放系数（默认值：0.2） | FLOAT | 是 | 0.0 - 10.0 |

注意：`b1`、`b2`、`s1` 和 `s2` 是高级参数，默认隐藏在节点的 UI 中。它们可以在 0.0 - 10.0 范围内以 0.01 为步长设置。`b1` 和 `s1` 控制通道数最多的 U-Net 块（为模型基础通道数的四倍），而 `b2` 和 `s2` 控制通道数减半的块（为模型基础通道数的两倍）。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `model` | 应用了 FreeU 修改后的增强扩散模型 | MODEL |
