ImageColorSpace 节点可在 sRGB（Rec.709）、线性 Rec.709、HDR（Rec.2020 HLG）、HDR PQ（Rec.2020 PQ）、HDR LogC3 和 HDR ACEScct 色彩空间之间转换图像。LogC3 使用 EI 800 曲线、Rec.709 原色，并将码值钳制在 [0, 1]；ACEScct 使用 AP1 原色和 D60 白点，并通过 Bradford 变换适应到 D65。当转换为 SDR 输出，或从 HDR PQ 转换为 HDR 时，它会在整个批次上对超出范围的亮度进行色调映射，并压缩超出色域的颜色；线性和 ACEScct 输出，以及线性到 HDR 的转换，会保留扩展值。HLG 和 PQ 输出会裁剪负通道。转换以 float32 计算，任何 alpha 通道都原样传递。

## 备注

- 线性 1.0 使用与 sRGB 相同的 203 尼特参考白；HLG 使用 1000 尼特参考显示。
- 线性和 ACEScct 输出会保留扩展值；线性到 HDR 的转换会保留高光而不进行色调映射。
- SDR 输出和 PQ 到 HLG 的转换会在整个批次上对超出范围的亮度进行色调映射（共享一个白点，因此曝光不会逐帧变化），并压缩超出色域的颜色。HLG 和 PQ 输出会裁剪负通道。
- 转换以 float32 计算，并返回中间设备和 dtype。
- LogC3 和 ACEScct 是相机对数编码：在保存 EXR 时将它们转换为线性，或在保存视频之前转换为 sRGB/HDR/HDR PQ。
- Straight alpha 不会进行色彩变换；仅转换 RGB 通道。
- 如果 `source` 和 `destination` 相同，则不应用色彩变换——图像仅移动到中间设备和 dtype。
