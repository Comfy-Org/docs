`EmptyLTXVLatentVideo` 节点使用你指定的 `width`、`height`、`length` 和 `batch_size` 创建一个空（填零）的潜在视频张量。它为 LTXV 视频生成工作流提供空白起点，潜在维度会相对于请求的视频尺寸自动压缩。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `宽度` | 潜在视频张量的宽度（默认值：768，步长：32） | INT | 是 | 64 至 MAX_RESOLUTION |
| `高度` | 潜在视频张量的高度（默认值：512，步长：32） | INT | 是 | 64 至 MAX_RESOLUTION |
| `长度` | 潜在视频中的帧数（默认值：97，步长：8） | INT | 是 | 1 至 MAX_RESOLUTION |
| `批量大小` | 批次中要生成的潜在视频数量（默认值：1） | INT | 是 | 1 至 4096 |

注意：与请求的尺寸相比，潜在视频会被压缩：空间维度（`width` 和 `height`）除以 32，帧数（`length`）除以 8 并向上取整到最接近的整数。`width`、`height` 和 `length` 的步长值有助于保持这些除法结果为整数。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `samples` | 生成的空潜在张量，在指定维度上为零值，并具有 32 的空间下采样比例 | LATENT |
