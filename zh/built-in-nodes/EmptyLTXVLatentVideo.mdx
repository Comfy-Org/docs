EmptyLTXVLatentVideo 节点会创建一个用于视频处理的空 latent 张量。它生成一个指定宽度、高度、长度和批量大小的空白起点，可用作视频生成工作流的输入。该节点产生一个零填充的 latent 表示，其空间维度是所配置宽度和高度的 1/32，帧数压缩为原来的 1/8。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `宽度` | latent 视频张量的宽度（默认值：768，步长：32） | INT | 是 | 64 to MAX_RESOLUTION |
| `高度` | latent 视频张量的高度（默认值：512，步长：32） | INT | 是 | 64 to MAX_RESOLUTION |
| `长度` | latent 视频中的帧数（默认值：97，步长：8） | INT | 是 | 1 to MAX_RESOLUTION |
| `批量大小` | 同一批次中生成的 latent 视频数量（默认值：1） | INT | 是 | 1 到 4096 |

注意：latent 视频相对于输入尺寸进行了压缩：空间维度（宽度和高度）除以 32，帧数（长度）除以 8 并向上取整为最接近的整数。宽度、高度和长度的步长值有助于确保这些除法运算得到整数结果。

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `samples` | 生成的在指定维度上填零的空 latent 张量，并带有 32 的空间缩放比例 | LATENT |
