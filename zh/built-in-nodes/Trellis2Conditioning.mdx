Trellis2Conditioning 将输入图像转换为 TRELLIS.2 模型的条件数据。它使用 CLIP 视觉模型将图像编码为两组特征（512 和 1024 尺度），并将其打包为正条件对，同时创建匹配的零填充负条件对，作为空参考。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `clip_vision_model` | 用于将图像编码为条件特征的 CLIP 视觉模型。 | CLIP_VISION | 是 | 任何可用的 CLIP 视觉模型 |
| `图像` | 来自 ImageCropToMask 的预处理图像（TRELLIS.2 使用 pad_factor=1.0）。 | IMAGE | 是 | 任意图像 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `正向` | 包含 512 和 1024 尺度下编码图像特征的条件数据，用作 TRELLIS.2 模型的正条件。 | CONDITIONING |
| `负向` | 与正条件形状相同的零填充条件数据，用作空的负参考。 | CONDITIONING |
