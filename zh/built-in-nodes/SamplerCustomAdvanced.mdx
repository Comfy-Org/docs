SamplerCustomAdvanced 节点使用自定义噪声、引导和采样配置来执行高级潜空间采样。它通过一个带有可自定义噪声生成和 sigma 调度的引导采样过程来处理潜空间图像，在可用时同时生成最终采样输出和去噪版本。

## 输入
| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `噪波` | 提供采样过程初始噪声模式和种子的噪声生成器 | NOISE | 是 | - |
| `引导器` | 引导采样过程朝向所需输出的引导模型 | GUIDER | 是 | - |
| `采样器` | 定义生成过程中如何遍历潜空间的采样算法 | SAMPLER | 是 | - |
| `西格玛` | 控制整个采样步骤中噪声水平的 sigma 调度 | SIGMAS | 是 | - |
| `Latent图像` | 作为采样起点的初始潜空间表示。支持可选的 `noise_mask` 用于选择性去噪，以及可选的 `downscale_ratio_spacial` 和 `downscale_ratio_temporal` 键，用于高级潜空间处理 | LATENT | 是 | - |

## 输出
| Output Name | Description | Data Type |
| --- | --- | --- |
| `Latent` | 采样过程完成后的最终采样潜空间表示。输入潜空间中的任何 `downscale_ratio_spacial` 或 `downscale_ratio_temporal` 键都会从该输出中移除 | LATENT |
| `降噪Latent` | 当采样过程产生中间干净预测（x0）时，输出去噪版本；否则与输出相同。可用时，这表示模型在每个步骤中对干净潜空间的最佳估计 | LATENT |
