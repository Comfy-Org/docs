The OpenAIChatConfig 节点定义了用于控制 OpenAI Chat 节点如何生成响应的高级选项。它允许你设置截断策略、限制输出 token 数量、提供自定义指令，并选择模型在回答前应投入多少推理努力。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `截断` | 用于模型响应的截断策略。auto：如果此响应及先前响应的上下文超过模型的上下文窗口大小，模型将通过丢弃对话中间部分的输入项来截断响应，以适配上下文窗口。disabled：如果模型响应将超过模型的上下文窗口大小，请求将失败并返回 400 错误（默认："auto"） | COMBO | 是 | "auto"<br />"disabled" |
| `Token输出上限` | 响应可生成的 token 数量上限，包括可见输出 token 和推理 token（默认：4096） | INT | 否 | 16 到 16384 |
| `指令` | 给模型的指令，说明如何生成响应（支持多行输入） | STRING | 否 | - |
| `reasoning_effort` | 模型在回答前进行多少推理。"default" 将选择权留给模型。支持的级别因模型而异：GPT-6 Astra low-max、GPT-5.6 none-max（无 minimal）、GPT-5.5 none-xhigh、GPT-5.5 Pro medium-xhigh、GPT-5 minimal-high、o-series low-high；GPT-4.1 没有推理。不支持的级别会在请求发送前被拒绝。（默认："default"） | COMBO | 否 | "default"<br />"none"<br />"minimal"<br />"low"<br />"medium"<br />"high"<br />"xhigh"<br />"max" |

注意：虽然 `top_p` 和 `temperature` 在 API 规范中被列为属性，但并非所有模型都支持它们，因此未作为输入公开。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `OPENAI_CHAT_CONFIG` | 包含指定高级设置的配置对象，供 OpenAI Chat 节点使用 | OPENAI_CHAT_CONFIG |
