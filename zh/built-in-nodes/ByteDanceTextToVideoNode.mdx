ByteDance 文本转视频节点通过基于文本提示的 API 使用 ByteDance 模型生成视频。它接受文本描述和多种视频设置作为输入，然后创建符合提供规格的视频。该节点处理 API 通信，并将生成的视频作为输出返回。

## 概述

ByteDance 文本转视频节点旨在利用 ByteDance 的 AI 能力将文本提示转换为视频。用户可以指定模型、分辨率、宽高比、时长以及其他参数，以控制视频生成过程。

## 输入

| 参数 | 描述 | 数据类型 | 必选 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于生成的 ByteDance 模型。 | STRING | 是 | 
  - "seedance-1-5-pro-251215"
  - "seedance-1-0-pro-250528"
  - "seedance-1-0-pro-fast-251015" |
| `提示` | 用于生成视频的文本提示。 | STRING | 是 | 多行文本输入 |
| `分辨率` | 输出视频的分辨率。 | STRING | 是 | 
  - "480p"
  - "720p"
  - "1080p" |
| `宽高比` | 输出视频的宽高比。 | STRING | 是 | 
  - "16:9"
  - "4:3"
  - "1:1"
  - "3:4"
  - "9:16"
  - "21:9" |
| `时长` | 输出视频的时长（秒）。 | INT | 是 | 3 到 12 秒 |
| `种子` | 用于生成的种子。 | INT | 否 | 0 到 2,147,483,647 |
| `固定相机` | 指定是否固定相机。 | BOOLEAN | 否 | - |
| `水印` | 是否在视频上添加“AI生成”水印。 | BOOLEAN | 否 | - |
| `generate_audio` | 此参数除 `seedance-1-5-pro-251215` 模型外均被忽略。 | BOOLEAN | 否 | - |

**参数约束：**

- `prompt` 必须在去除空白后至少包含 1 个字符。
- `prompt` 不能包含以下文本参数：“resolution”、“ratio”、“duration”、“seed”、“camerafixed”、“watermark”。
- `duration` 限制在 3 到 12 秒之间。
- 对于 `seedance-1-5-pro-251215` 模型，最小支持的时长为 4 秒。
- `seed` 接受从 0 到 2,147,483,647 的值。
- `generate_audio` 参数仅在 `model` 设置为 `seedance-1-5-pro-251215` 时有效；对于其他所有模型均被忽略。
