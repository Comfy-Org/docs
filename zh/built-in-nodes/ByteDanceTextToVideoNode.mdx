字节跳动文本转视频节点通过 API 基于文本提示词，使用字节跳动模型生成视频。您提供提示词并选择模型、分辨率、宽高比和时长等设置；该节点会提交生成请求并返回生成的视频。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 取值范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于生成视频的字节跳动模型（默认值：`"seedance-1-0-pro-fast-251015"`）。 | COMBO | 是 | `"seedance-1-5-pro-251215"`<br />`"seedance-1-0-pro-250528"`<br />`"seedance-1-0-pro-fast-251015"` |
| `提示` | 用于生成视频的文本提示词。 | STRING | 是 | - |
| `分辨率` | 输出视频的分辨率。 | COMBO | 是 | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `宽高比` | 输出视频的宽高比。 | COMBO | 是 | `"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"` |
| `时长` | 输出视频的时长（秒，默认值：5）。 | INT | 是 | 3到12 |
| `种子` | 用于生成视频的种子值（默认值：0）。 | INT | 否 | 0到2147483647 |
| `固定相机` | 指定是否固定镜头。平台会向您的提示词附加一条固定镜头的指令，但不保证实际效果（默认值：False）。 | BOOLEAN | 否 | - |
| `水印` | 是否为视频添加“AI 生成”水印（默认值：False）。 | BOOLEAN | 否 | - |
| `generate_audio` | 此参数对除 `seedance-1-5-pro-251215` 之外的任何模型都会忽略（默认值：False）。 | BOOLEAN | 否 | - |

**参数约束：**

- `prompt` 参数在去除空格后必须至少包含 1 个字符。
- `prompt` 参数不能包含以下文本参数：“resolution”、“ratio”、“duration”、“seed”、“camerafixed”、“watermark”。
- 节点会将所选 `resolution`、`aspect_ratio`、`duration`、`seed`、`camera_fixed` 和 `watermark` 设置附加到提示词文本之后，从而构建最终提示词。
- `duration` 参数限制为 3到12 秒之间的值。对于 `seedance-1-5-pro-251215` 模型，支持的最短时长为 4 秒。
- `seed` 参数接受从 0到2,147,483,647 的值。
- `generate_audio` 参数仅在 `model` 设置为 `seedance-1-5-pro-251215` 时生效；对于所有其他模型，该参数会被忽略。
