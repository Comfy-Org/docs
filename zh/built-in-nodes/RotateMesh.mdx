使用欧拉 XYZ 角度（以度为单位）或四元数围绕世界轴旋转 3D 网格。在欧拉 XYZ 模式下，旋转按 X、Y、Z 的顺序应用；在四元数模式下，(w, x, y, z) 四元数会自动归一化。旋转应用于网格的顶点，法线和切线也会随之旋转，以确保光照和着色保持正确。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模式` | 要使用的旋转模式。`"euler_xyz"` 按 X、Y、Z 的角度绕世界轴应用旋转（以度为单位）。`"quaternion"` 使用自动归一化的 (w, x, y, z) 四元数。 | DYNAMIC_COMBO | 是 | `"euler_xyz"`<br />`"quaternion"` |
| `网格` | 要旋转的 3D 网格。 | MESH | 是 | — |

### euler_xyz 输入

当 `mode` 设置为 `"euler_xyz"` 时，这些输入会出现。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `angle_x` | 绕 X 轴旋转的角度（以度为单位）。（默认值：0.0） | FLOAT | 否 | -360.0 到 360.0 （步长：0.1） |
| `angle_y` | 绕 Y 轴旋转的角度（以度为单位）。（默认值：0.0） | FLOAT | 否 | -360.0 到 360.0 （步长：0.1） |
| `angle_z` | 绕 Z 轴旋转的角度（以度为单位）。（默认值：0.0） | FLOAT | 否 | -360.0 到 360.0 （步长：0.1） |

### quaternion 输入

当 `mode` 设置为 `"quaternion"` 时，这些输入会出现。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `qw` | 四元数 (w, x, y, z) 的 W 分量。（默认值：1.0） | FLOAT | 否 | -1.0 到 1.0 （步长：0.001） |
| `qx` | 四元数 (w, x, y, z) 的 X 分量。（默认值：0.0） | FLOAT | 否 | -1.0 到 1.0 （步长：0.001） |
| `qy` | 四元数 (w, x, y, z) 的 Y 分量。（默认值：0.0） | FLOAT | 否 | -1.0 到 1.0 （步长：0.001） |
| `qz` | 四元数 (w, x, y, z) 的 Z 分量。（默认值：0.0） | FLOAT | 否 | -1.0 到 1.0 （步长：0.001） |

**注意：** 当 `mode` 为 `"euler_xyz"` 且三个角度均为 0.0 时，或者当 `mode` 为 `"quaternion"` 且四元数为单位四元数 (1, 0, 0, 0) 时，网格将原样返回。四元数在使用前会自动归一化；如果其模长低于 1e-8，节点将报错。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mesh` | 旋转后的网格。顶点会被旋转，法线作为方向进行旋转。切线的 X、Y、Z 分量会被旋转，而 W（手性）分量保持不变。 | MESH |
