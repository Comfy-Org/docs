此节点使用 Fish Audio API 从您的音频录音中创建私有克隆语音。您提供一个或多个音频样本，节点将构建一个自定义语音，可立即用于文本转语音。它接受 1 到 20 个录音，每个录音建议长度为 10 到 30 秒，总时长限制为 270 秒。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `files` | 用于语音克隆的音频录音。这是一个可增长的输入：连接一个或多个音频项（例如 `audio_1`、`audio_2` 等）以提供语音样本。 | AUDIO | 是 | 1 到 20 recordings |
| `enhance_audio_quality` | 在训练前增强参考音频质量（默认：True）。 | BOOLEAN | 是 | True<br />False |

**注意：** 所有参考音频的总时长必须低于 270 秒。如果合计时长达到或超过 270 秒，节点将返回错误。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `voice` | 新创建的克隆语音，由 Fish Audio API 返回的唯一语音 ID 标识。此语音可用于文本转语音。 | FISHAUDIO_VOICE |
