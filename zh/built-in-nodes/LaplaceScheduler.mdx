LaplaceScheduler 节点生成一系列遵循拉普拉斯分布的 sigma 值，用于扩散采样。它创建一条噪声水平计划，从最大值逐渐减小到最小值，通过拉普拉斯分布参数控制变化过程。该调度器通常用于自定义采样工作流中，为扩散模型定义噪声计划。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `步数` | 计划中的采样步数（默认值：20） | INT | 是 | 1 到 10000 |
| `sigma_max` | 计划开始时的最大 sigma 值（默认值：14.614642） | FLOAT | 是 | 0.0 到 5000.0 |
| `sigma_min` | 计划结束时的最小 sigma 值（默认值：0.0291675） | FLOAT | 是 | 0.0 到 5000.0 |
| `mu` | 拉普拉斯分布的均值参数（默认值：0.0） | FLOAT | 是 | -10.0 到 10.0 |
| `beta` | 拉普拉斯分布的尺度参数（默认值：0.5） | FLOAT | 是 | 0.0 到 10.0 |

注意：`sigma_max`、`sigma_min`、`mu` 和 `beta` 是高级参数。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `SIGMAS` | 遵循拉普拉斯分布计划的 sigma 值序列 | SIGMAS |
