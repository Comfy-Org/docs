此节点使用 Bria API 在图像的遮罩区域内生成物体或场景。它上传图像和遮罩，将提示词发送到 Bria 生成填充服务，等待操作完成，然后返回编辑后的图像。这是一项付费 API 操作（每次请求 US$0.0429）。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 要编辑的输入图像。 | IMAGE | 是 | - |
| `mask` | 白色区域将被生成的内容填充，黑色区域保持不变。遮罩在发送前会进行二值化处理，因此部分绘制的区域会被视为白色。遮罩必须与图像具有相同的宽高比。 | MASK | 是 | - |
| `prompt` | 描述要在遮罩区域内生成的内容。至少包含 1 个字符。（默认：""） | STRING | 是 | - |
| `negative_prompt` | 描述生成结果中要避免的内容的提示词。如果留空，则不会发送到 API。（默认：""） | STRING | 是 | - |
| `refine_prompt` | 自动调整提示词以获得更好的结果；禁用后则完全按照原样使用提示词。（默认：true） | BOOLEAN | 是 | true<br />false |
| `seed` | 生成过程的随机种子。（默认：42） | INT | 是 | 1 到 2147483647 |
| `内容审核` | 审核设置。当设置为“true”时，将应用下方的内容审核选项。（默认：“false”） | DYNAMIC_COMBO | 是 | "false"<br />"true" |

### 审核输入（当 `moderation` = "true" 时）

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | 对提示词应用内容审核。（默认：false） | BOOLEAN | 否 | true<br />false |
| `visual_input_moderation` | 对输入图像应用内容审核。（默认：false） | BOOLEAN | 否 | true<br />false |
| `visual_output_moderation` | 对输出图像应用内容审核。（默认：false） | BOOLEAN | 否 | true<br />false |

**注意：** `prompt` 不能为空。`mask` 必须与 `image` 具有相同的宽高比。遮罩会以 50% 不透明度进行二值化，因此不透明度低于一半的绘制区域将被忽略；如果二值化后遮罩不含任何白色区域，节点将报错。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 遮罩区域被生成内容填充后得到的结果图像。 | IMAGE |
