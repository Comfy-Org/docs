此节点使用 Bria API 在图像的遮罩区域内生成物体或场景。它会上传图像和遮罩，将提示词发送到 Bria 生成式填充服务，等待操作完成，然后返回编辑后的图像。这是一项付费 API 操作（每次请求 0.0429 美元）。

## 输入
| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `image` | 要编辑的输入图像。 | IMAGE | 是 | - |
| `mask` | 白色区域将填充生成内容，黑色区域保持不变。遮罩在发送前会进行二值化处理，因此部分涂绘的区域也会被视为白色。必须与图像具有相同的宽高比。 | MASK | 是 | - |
| `prompt` | 描述在遮罩区域内生成内容的提示词。必须至少包含 1 个字符。 | STRING | 是 | - |
| `negative_prompt` | 描述在生成结果中需要避免的内容的提示词。如果留空，则不会发送到 API。 | STRING | 是 | - |
| `refine_prompt` | 自动调整提示词以获得更佳效果；禁用后则完全按照写入的提示词使用。（默认值：true） | BOOLEAN | 是 | true<br />false |
| `seed` | 生成过程的随机种子。（默认值：42） | INT | 是 | 1 到 2147483647 |
| `moderation` | 请求的审核设置。设置为 "true" 时，将应用下面描述的嵌套审核选项。（默认值："false"） | COMBO | 是 | "false"<br />"true" |

注意：`prompt` 不能为空，且 `mask` 必须与 `image` 具有相同的宽高比。

当 `moderation` 设置为 "true" 时，可使用以下嵌套布尔选项：
- `prompt_content_moderation`（默认值：false）：对提示词应用内容审核。
- `visual_input_moderation`（默认值：false）：对输入图像应用内容审核。
- `visual_output_moderation`（默认值：false）：对输出图像应用内容审核。

## 输出
| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `image` | 遮罩区域被生成内容填充后得到的结果图像。 | IMAGE |
