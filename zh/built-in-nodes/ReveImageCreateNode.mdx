Reve Image Create 节点使用 Reve AI 模型根据文本描述生成图像。它向 Reve API 发送文本提示词，并返回生成的图像，同时提供宽高比控制以及可选的后期处理（如放大和背景移除）。此节点已弃用。

## 输入
### 通用输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 用于生成所使用的模型版本。 | DYNAMIC_COMBO | 是 | `"reve-create@20250915"` |
| `prompt` | 所需图像的文本描述。最多 2560 个字符。 | STRING | 是 | 1 到 2560 characters |
| `upscale` | 对生成的图像进行放大。可能会产生额外费用。默认值："disabled"。 | DYNAMIC_COMBO | 否 | `"disabled"`<br />`"enabled"` |
| `remove_background` | 从生成的图像中移除背景。可能会产生额外费用。默认值：False。 | BOOLEAN | 否 | N/A |
| `seed` | `seed` 参数控制节点是否应重新运行；无论 seed 值如何，结果都是非确定性的。默认值：0。 | INT | 否 | 0 到 2147483647 |

### reve-create@20250915 输入

当 `model` 设置为 `"reve-create@20250915"` 时可用的选项：

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | 输出图像的宽高比。 | COMBO | 是 | `"3:2"`<br />`"16:9"`<br />`"9:16"`<br />`"2:3"`<br />`"4:3"`<br />`"3:4"`<br />`"1:1"` |
| `test_time_scaling` | 数值越高，生成的图像质量越好，但消耗的积分也越多。默认值：1。高级选项。 | INT | 否 | 1 到 5 |

### 放大输入

当 `upscale` 设置为 `"enabled"` 时可用的选项：

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `upscale_factor` | 放大倍数（2 倍、3 倍或 4 倍）。默认值：2。 | INT | 否 | 2 到 4 |

**注意：** `seed` 参数不保证确定性的输出。`upscale` 参数控制是否将放大作为后处理步骤应用，并且可能会产生额外费用。`prompt` 必须包含 1 到 2560 个字符。

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `image` | Reve 模型根据输入提示词生成的图像。 | IMAGE |
