WanAnimate2ToVideo 通过将参考图像中的人物的面部表情、身体动作和手势从单独的姿态视频中转移，从而对参考图像中的人物进行动画化。它构建条件数据以及一个起始潜在表示，供视频生成采样器用于创建动画。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 用于视频生成的正向条件。 | CONDITIONING | 是 | 不适用 |
| `negative` | 用于视频生成的负向条件。 | CONDITIONING | 是 | 不适用 |
| `vae` | 用于将参考图像和视频帧编码到潜在空间中的 VAE。 | VAE | 是 | 不适用 |
| `width` | 输出视频宽度（像素）。（默认值：832） | INT | 是 | 16 到 MAX_RESOLUTION（步长 16） |
| `height` | 输出视频高度（像素）。（默认值：480） | INT | 是 | 16 到 MAX_RESOLUTION（步长 16） |
| `length` | 要生成的帧数。（默认值：81） | INT | 是 | 1 到 MAX_RESOLUTION（步长 4） |
| `batch_size` | 同时生成的视频数量。（默认值：1） | INT | 是 | 1 到 4096 |
| `reference_image` | 要制作动画的人物。如果省略，则使用黑色图像。 | IMAGE | 否 | 不适用 |
| `pose_video` | 其运动被转移到参考人物的视频。如果其帧数少于 `length`，则最后一帧将重复以填补缺失帧。 | IMAGE | 否 | 不适用 |
| `clip_vision_output` | 参考图像的 CLIP 视觉特征。 | CLIP_VISION_OUTPUT | 否 | 不适用 |
| `positive_pose` | 用于姿态视频分支的提示，描述运动而非人物。默认为 `positive`。同时用于 cond 和 uncond 传递。 | CONDITIONING | 否 | 不适用 |
| `clip_vision_output_pose` | 姿态视频第一帧的 CLIP 视觉特征。默认为 `clip_vision_output`。 | CLIP_VISION_OUTPUT | 否 | 不适用 |
| `continue_motion` | 用于延续时间一致性的先前运动序列。仅使用该序列的最后一帧作为起始运动帧。 | IMAGE | 否 | 不适用 |
| `video_frame_offset` | 在姿态视频中向前跳过的帧数。扩展视频时连接到前一节点的 `video_frame_offset` 输出。（默认值：0） | INT | 是 | 0 到 MAX_RESOLUTION |
| `pose_strength` | 缩放姿态视频对运动的影响程度。1.0 为训练时的行为；低于此值会减弱遵循程度，高于此值会增强。0.0 会使其静音，但不会完全移除。 （默认值：1.0） | FLOAT | 是 | 0.00 到 10.00（步长 0.01） |
| `pose_start_percent` | 姿态影响开始的采样百分比。在该窗口之外，姿态分支被完全跳过，这也会加速这些步骤。（默认值：0.0） | FLOAT | 是 | 0.00 到 1.00（步长 0.01） |
| `pose_end_percent` | 姿态影响结束的采样百分比。运动通常在早期就已确立，因此例如 0.7 可以在保持编排的同时放宽精细细节。（默认值：1.0） | FLOAT | 是 | 0.00 到 1.00（步长 0.01） |
| `reference_image_strength` | 缩放生成帧对参考图像潜在帧的注意力强度。低于 1.0 会放宽身份/外观遵循度（例如允许提示重新造型），高于此值则会防止漂移而收紧。（默认值：1.0） | FLOAT | 是 | 0.00 到 10.00（步长 0.01） |

**验证说明：**

- `pose_start_percent` 不得大于 `pose_end_percent`；否则节点会引发 ValueError。
- 如果提供了 `pose_video`，其帧数必须大于 `video_frame_offset`；否则节点会引发 ValueError。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `positive` | 用于采样的正向条件，附带了参考图像、掩码和可选姿态数据。 | CONDITIONING |
| `negative` | 用于采样的负向条件，附带了相同的参考图像、掩码和可选姿态数据。 | CONDITIONING |
| `latent` | 用于视频采样器的零填充起始潜在表示；在解码前应移除前 `trim_latent` 帧。 | LATENT |
| `trim_latent` | 解码前应裁剪的潜在帧数。 | INT |
| `trim_image` | 扩展视频时重叠的图像帧数。 | INT |
| `video_frame_offset` | 在姿态视频中向前跳过的帧数；等于调整后的输入偏移量加上已生成的帧数。 | INT |
