LTXVImgToVideoInplace 将输入图像编码到潜在空间，并将这些编码帧放置在现有潜在视频的开头。`strength` 值控制编码图像对这些初始帧的条件化强度，当启用 `bypass` 时，将原样返回输入的 latent。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `vae` | 用于将输入图像编码到潜在空间的 VAE 模型。 | VAE | 是 | - |
| `图像` | 要编码并用于引导视频 latents 的输入图像。 | IMAGE | 是 | - |
| `潜空间` | 要修改的目标潜在视频表示。 | LATENT | 是 | - |
| `强度` | 控制编码图像对 latent 初始帧的条件化强度。值为 1.0 时，初始帧完全由编码图像条件化；值越低，条件化越弱。初始帧的噪声掩码设置为 `1.0 - strength`。（默认值：1.0） | FLOAT | 否 | 0.0 - 1.0 |
| `跳过` | 绕过条件化。启用后，节点将原样返回输入的 latent。（默认值：False） | BOOLEAN | 否 | True or False |

**注意：** `image` 将根据 `latent` 输入的宽度和高度自动调整大小，以匹配 `vae` 编码所需的空间尺寸。编码时仅使用 `image` 的 RGB 通道。

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `潜空间` | 结果中的潜在视频表示。当 bypass 禁用时，它包含更新后的 `samples` 和一个将条件化强度应用于初始帧的 `noise_mask`。当 bypass 启用时，它是原样返回的输入 latent。 | LATENT |
