此节点将 Trellis2 形状潜在表示解码为 3D 网格。它使用 VAE 将稀疏形状潜在数据转换为网格几何体，并同时输出解码过程中生成的形状细分数据。该节点支持单个和批量潜在输入，并自动将网格方向调整为预期的坐标框架。

## 输入

| 参数 | 描述 | 数据类型 | 是否必须 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `样本` | 要解码的潜在样本，包括样本张量和稀疏坐标数据。潜在字典还可能包含可选字段：用于批量形状的 `coord_counts`、用于控制网格分辨率的 `coord_resolution`，以及用于坐标方向的 `model_frame`。 | LATENT | 是 | None |
| `vae` | 用于将形状潜在解码为网格的 VAE 模型。 | VAE | 是 | None |

### 关于 `samples` 的说明

- `samples` 输入是一个潜在字典，必须包含 `samples` 张量和 `coords` 稀疏坐标。
- 如果存在 `coord_counts`，它必须是包含非负整数的一维张量，且所有计数的总和必须等于坐标行的总数。每个计数代表批次中的一个形状。
- 如果提供了 `coord_resolution`，网格分辨率计算为 `coord_resolution * 16`。否则，使用 VAE 内置的分辨率缓冲区（默认值：1024）。
- 如果 `model_frame` 设置为 `"z_up"`，则解码后的网格顶点会从 Z-up 坐标系旋转到 glTF 使用的 Y-up 约定。默认值为 `"y_up"`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `网格` | 解码后的 3D 网格，包含顶点位置和面索引。 | MESH |
| `形状细分` | 解码过程各阶段生成的形状细分数据。 | SHAPE_SUBDIVIDES |
