此节点将 Trellis2 形状潜在表示解码为 3D 网格。它使用 VAE 将稀疏形状潜在数据转换为网格几何体，并同时输出解码过程中生成的形状细分数据。此节点支持单个和批量潜在输入，并自动将网格朝向调整到预期的坐标框架。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `样本` | 要解码的潜在样本，包括样本张量和稀疏坐标数据。潜在字典还可能包含可选字段：用于批量形状的 `coord_counts`、用于控制网格分辨率的 `coord_resolution`，以及用于坐标朝向的 `model_frame`。 | LATENT | 是 | None |
| `vae` | 用于将形状潜在表示解码为网格的 VAE 模型。 | VAE | 是 | None |

### 关于 `samples` 的说明

- `samples` 输入是一个潜在字典，必须包含 `samples` 张量和 `coords` 稀疏坐标。
- 如果存在 `coord_counts`，它必须是非负整数的一维张量，并且所有计数的总和必须等于坐标行的总数。每个计数表示批次中的一个形状。
- 如果提供了 `coord_resolution`，则网格分辨率按 `coord_resolution * 16` 计算。否则，使用 VAE 内置的分辨率缓冲区（默认值：1024）。
- 如果 `model_frame` 设置为 `"z_up"`，则解码后的网格顶点会从 Z-up 坐标系旋转为 glTF 使用的 Y-up 约定。默认值为 `"y_up"`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mesh` | 解码后的 3D 网格，包含顶点位置和面索引。解码多个形状时，如果所有网格形状相同，则作为单个堆叠张量返回；否则作为打包的变尺寸批次返回。 | MESH |
| `shape_subdivides` | 在解码过程各阶段生成的形状细分数据。 | SHAPE_SUBDIVIDES |
