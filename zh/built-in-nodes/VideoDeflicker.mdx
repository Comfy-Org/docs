从处理过的视频中去除时间闪烁，使每一帧在跟随相邻帧运动的同时保留自身细节。它适用于在放大或逐帧处理后出现脉动的素材：连接光流模型和闪烁帧，并可选地连接源素材的稳定副本作为引导。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `optical_flow` | 来自 Load Optical Flow Model 节点的光流模型（torchvision RAFT-large）。 | OPTICAL_FLOW | 是 | - |
| `images` | 要稳定的闪烁帧，例如经过放大或逐帧处理的视频。 | IMAGE | 是 | - |
| `guide` | 稳定的源帧，用于跟随其运动，分辨率任意。默认使用 `images`，这会去除较少的闪烁。其运动补偿后的帧间差异也参与平滑权重：当 `guide` 的变化无法用估计的运动解释时，即使运动估计正确，平滑也会减弱。 | IMAGE | 否 | - |
| `strength` | 每一帧跟随相邻帧的强度（默认：1.0）。值越高，去除的闪烁越多，也会柔化更多精细细节；0 表示原样返回帧。 | FLOAT | 是 | 0.0 到 100.0（步长：0.1） |
| `direction` | 处理方向。`bidirectional` 会对前向和后向处理取平均，从而避免滞后于运动；`forward` 运行单次处理。（默认：`bidirectional`） | COMBO | 是 | `"bidirectional"`<br />`"forward"` |
| `threshold` | 帧与其运动补偿后的相邻帧之间大于此值的差异会被视为真实变化，并较少平滑（默认：0.1）。0 会对所有变化一视同仁地平滑。 | FLOAT | 是 | 0.0 到 1.0（步长：0.01） |

**说明：**

- 光流在 `guide` 的缩小副本上计算，因此不必与 `images` 同尺寸；`guide` 的像素不会混入输出。
- 超出 `images` 与 `guide` 中较短者的帧不会被去闪烁。`guide` 较短时，其余帧原样返回。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `IMAGE` | 去闪烁后的帧，其尺寸和帧数与 `images` 相同。 | IMAGE |
