此节点通过检测开放边界边并创建新面来闭合它们，从而填充 3D 网格中的孔洞。它在 GPU 上运行，保留现有几何体和 UV，并可处理单个网格、网格列表或网格批次。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 要处理的 3D 网格。接受单个网格、网格列表或批次网格。 | MESH | 是 | - |
| `max_perimeter` | 要填充的最大孔洞周长。0 表示禁用。（默认值：0.03） | FLOAT | 是 | 0.0 到无上限（步长 0.0001） |
| `weld_epsilon_rel` | 预焊接容差（边界框对角线的比例）；边界检测需要已焊接的顶点。0 表示跳过。（默认值：1e-5） | FLOAT | 是 | 0.0 到无上限（步长 1e-6） |
| `max_vertices` | 限制每个周期的边界顶点数；质心扇形填充仅适用于小型近平面孔洞。保持 ≤16。（默认值：16） | INT | 是 | 3 到 1024 |
| `fill_chains` | 同时填充开放链（不仅仅是闭合环）。可能产生噪声；OFF 与 cumesh 一致。（默认值：False） | BOOLEAN | 是 | True or False |

注意：当 `max_perimeter` 大于 0 时，节点会填充孔洞；当其为 0 时，会完全跳过孔洞填充。当 `weld_epsilon_rel` 大于 0 时，节点会在检测孔洞前预焊接重复顶点。焊接容差从给定的边界框对角线比例开始，并自动翻倍增加，直到网格被视为已焊接，或容差达到上限 1e-2。边界顶点超过 8 个的孔洞使用质心扇形填充（插入新的质心顶点），而较小的孔洞使用复用现有边界顶点的顶点扇形填充。默认仅填充闭合边界环；将 `fill_chains` 设为 True 也会闭合开放链。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mesh` | 已填充孔洞的网格，与输入批次格式匹配。 | MESH |
