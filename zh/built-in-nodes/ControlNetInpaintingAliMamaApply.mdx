ControlNetInpaintingAliMamaApply 节点通过将正向和负向条件与控制图像和遮罩相结合，为图像修复任务应用 ControlNet 条件。它处理输入图像和遮罩以创建修改后的条件，从而引导生成过程，允许控制图像中哪些区域被修复。该节点支持强度调整和时间控制，以微调 ControlNet 在生成过程不同阶段的影响。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `正面条件` | 正向条件，引导生成过程趋向所需内容 | CONDITIONING | 是 | - |
| `负面条件` | 负向条件，引导生成过程远离不想要的内容 | CONDITIONING | 是 | - |
| `ControlNet` | 提供对生成额外控制的 ControlNet 模型 | CONTROL_NET | 是 | - |
| `vae` | 用于编码和解码图像的 VAE（变分自编码器） | VAE | 是 | - |
| `图像` | 用作 ControlNet 控制引导的输入图像 | IMAGE | 是 | - |
| `遮罩` | 定义图像中哪些区域应被修复的遮罩 | MASK | 是 | - |
| `强度` | ControlNet 效果的强度（默认值：1.0，步长：0.01） | FLOAT | 是 | 0.0 到 10.0 |
| `开始百分比` | 高级参数。生成过程中 ControlNet 影响开始的时间点（以百分比表示）（默认值：0.0，步长：0.001） | FLOAT | 是 | 0.0 到 1.0 |
| `结束百分比` | 高级参数。生成过程中 ControlNet 影响结束的时间点（以百分比表示）（默认值：1.0，步长：0.001） | FLOAT | 是 | 0.0 到 1.0 |

**注意：** 当 ControlNet 启用 `concat_mask` 时，遮罩会在处理前被反转并应用到图像上，而反转后的遮罩会包含在发送给 ControlNet 的额外拼接数据中。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 应用了 ControlNet 进行图像修复后的修改版正向条件 | CONDITIONING |
| `negative` | 应用了 ControlNet 进行图像修复后的修改版负向条件 | CONDITIONING |
