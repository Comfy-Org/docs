将图像裁剪到其遮罩的边界框，在纯色背景上生成居中主体。该节点将遮罩后的图像合成到所选背景上，并将结果调整到指定的输出尺寸，适用于要求固定分辨率下居中、无背景主体的 3D 流程。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要裁剪的输入图像或图像批次。 | IMAGE | 是 | — |
| `遮罩` | 定义主体区域的遮罩或遮罩批次。单个遮罩将应用于所有图像；否则遮罩批次大小必须与图像批次大小匹配。如果遮罩分辨率与图像分辨率不同，遮罩会自动调整大小以匹配。 | MASK | 是 | — |
| `宽度` | 输出宽度（像素）。（默认值：1024） | INT | 是 | 64 到 4096（步长 8） |
| `高度` | 输出高度（像素）。（默认值：1024） | INT | 是 | 64 到 4096（步长 8） |
| `pad_factor` | 遮罩边界框周围的额外边距倍数。（默认值：1.0） | FLOAT | 是 | 1.0 到 2.0（步长 0.01） |
| `grow_mask` | 裁剪前将遮罩扩大或缩小指定像素数。正值扩大遮罩，负值缩小遮罩。（默认值：0） | INT | 是 | -32 到 32（步长 1） |
| `背景` | 遮罩主体后面的背景颜色。（默认值：#000000） | COLOR | 是 | — |

注意：裁剪区域以遮罩的边界框为中心，其宽高比与 `width` / `height` 一致。节点会自动检测并纠正反向遮罩（前景像素沿边界分布，背景在中心）。如果遮罩不包含任何前景像素，节点会尝试反向遮罩；如果反向遮罩也为空，则记录警告并裁剪整个图像。当遮罩批次大小与图像批次大小不匹配且不是单个遮罩时，会引发错误。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `图像` | 裁剪后的合成图像（遮罩主体叠加在所选背景颜色上），已调整至 `width` x `height`。批次大小与输入图像批次一致。 | IMAGE |
