裁剪图像到其掩码的边界框，在纯色背景上生成居中的主体。该节点将经过掩码的图像合成到所选背景上，并将结果调整为指定的输出尺寸，使其适用于需要固定分辨率下居中、无背景主体的 3D 管线。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要裁剪的输入图像或图像批次。 | IMAGE | 是 | — |
| `遮罩` | 定义主体区域的掩码或掩码批次。单个掩码会应用于所有图像；否则掩码批次大小必须与图像批次大小匹配。如果掩码分辨率与图像分辨率不同，掩码会自动调整大小以匹配。 | MASK | 是 | — |
| `宽度` | 输出宽度（像素）。（默认：1024） | INT | 是 | 64 至 4096（步长 8） |
| `高度` | 输出高度（像素）。（默认：1024） | INT | 是 | 64 至 4096（步长 8） |
| `pad_factor` | 围绕掩码边界框的额外边距，以倍数表示。（默认：1.0） | FLOAT | 是 | 1.0 至 2.0（步长 0.01） |
| `grow_mask` | 在裁剪前按此像素数扩展或收缩掩码。正值扩展掩码，负值收缩掩码。（默认：0） | INT | 是 | -32 至 32（步长 1） |
| `背景` | 经过掩码的主体后面的背景颜色。（默认：#000000） | COLOR | 是 | — |

注意：裁剪区域以掩码的边界框为中心，其宽高比与 `width` / `height` 匹配。该节点会自动检测并纠正反相的掩码（边框处为前景像素，中心为背景）。如果掩码不包含前景像素，节点会尝试反相掩码；如果该掩码也为空，则记录警告并裁剪整个图像。当掩码批次大小与图像批次大小不匹配且不是单个掩码时，会引发错误。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `images` | 裁剪后的合成图像（经过掩码的主体位于所选背景颜色之上），调整为 `width` x `height`。批次大小与输入图像批次匹配。 | IMAGE |
