VEED Dubbing 使用 VEED 将视频中的语音翻译成另一种语言，它会克隆每位说话者的声音，并让口型与译文同步。上传片段后轮询 VEED 任务，配音后的视频会以 25 fps 返回，时长与其新的音轨一致。使用它可以对已完成的片段进行本地化，无需重拍或重新录制语音。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 配音模型。`"standard"` 更便宜，返回单声道音频，支持拉丁美洲西班牙语和巴西葡萄牙语；`"pro"` 增加了地区口音和立体声音频。选择模型后会显示 `video`、`target_language`、`source_language` 和 `seed`。 | DYNAMIC_COMBO | 是 | `"standard"`<br />`"pro"` |

### standard 输入

当 `model` 设置为 `"standard"` 时，这些输入会出现。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `video` | 包含可见面部并带有语音的视频，最长 599 秒。输出时长与其音轨一致，并以 25 fps 播放。 | VIDEO | 是 | 最长 599 秒 |
| `target_language` | 要配音成的目标语言，为 85 种语言之一。（默认值：`"English"`） | COMBO | 是 | 85 种语言 |
| `source_language` | 视频中使用的语言，或使用 `"auto"` 自动检测。（默认值：`"auto"`） | COMBO | 是 | `"auto"`<br />85 种语言 |
| `seed` | 种子控制节点是否应重新运行；无论种子为何，结果都是非确定性的。（默认值：42） | INT | 是 | 0 到 2147483647 |

### pro 输入

当 `model` 设置为 `"pro"` 时，这些输入会出现。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `video` | 包含可见面部并带有语音的视频，最长 599 秒。输出时长与其音轨一致，并以 25 fps 播放。 | VIDEO | 是 | 最长 599 秒 |
| `target_language` | 要配音成的目标语言或地区口音：87 种语言外加 14 种口音，例如 `"English (UK)"`、`"Spanish (Mexico)"` 和 `"Portuguese (Brazil)"`。（默认值：`"English (US)"`） | COMBO | 是 | 101 个选项 |
| `source_language` | 视频中使用的语言，或使用 `"auto"` 自动检测。（默认值：`"auto"`） | COMBO | 是 | `"auto"`<br />91 种语言 |
| `seed` | 种子控制节点是否应重新运行；无论种子为何，结果都是非确定性的。（默认值：42） | INT | 是 | 0 到 2147483647 |

当视频没有音轨、片段时长超过 599 秒或 VEED 任务失败时，节点会报错停止。

| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `VIDEO` | 配音后的视频：带有翻译后语音和匹配口型动作的原始画面。 | VIDEO |
