根据提示词和分辨率同步生成图像。此节点连接到 Recraft API，根据文本描述创建图像，并支持指定尺寸以及可选的样式和控制参数。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 取值范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 用于图像生成的提示词。（默认：""） | STRING | 是 | - |
| `尺寸` | 生成的图像尺寸。（默认："1024x1024"） | COMBO | 是 | "1024x1024"<br />"1152x896"<br />"896x1152"<br />"1216x832"<br />"832x1216"<br />"1344x768"<br />"768x1344"<br />"1536x640"<br />"640x1536" |
| `n` | 要生成的图像数量。（默认：1） | INT | 是 | 1-6 |
| `随机种` | 用于确定节点是否应重新运行的种子；无论种子如何，实际结果都是不确定的。（默认：0） | INT | 是 | 0-18446744073709551615 |
| `Recraft风格` | 用于图像生成的可选样式。未提供时，默认为 "realistic_image" 样式。 | RECRAFT_STYLE | 否 | 提供多个选项 |
| `负面提示词` | 图像中不需要的元素的可选文本描述。（默认：""） | STRING | 否 | - |
| `Recraft控制` | 通过 Recraft Controls 节点对生成过程进行的可选额外控制。 | RECRAFT_CONTROLS | 否 | 提供多个选项 |

**注意：** `seed` 参数仅控制节点何时重新运行，并不会使图像生成具有确定性。即使使用相同的种子值，实际输出的图像也会有所不同。

**注意：** `prompt` 参数的长度必须在 1 到 1000 个字符之间。

**注意：** 如果使用 Infinite Style Library 中的 `style_id`，请确保它不是矢量艺术样式，否则将返回 SVG 数据而不是图像，从而导致错误。

**注意：** 这是一个付费 API 节点。每生成一张图像的费用为 $0.04，费用基于 `n` 的值计算。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `IMAGE` | 生成的图像，以批处理张量输出。当生成多张图像（n > 1）时，它们会在批次维度上进行拼接。 | IMAGE |
