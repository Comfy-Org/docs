使用 Mirelo SFX 生成跟随视频的音效。上传片段后，模型会跟随屏幕上的动作，并返回音效混音，以及一条单独分离出的语音分轨（其中的对白从音轨中提取）。可用它为无声或部分无声的片段添加拟音、环境声和冲击音效。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 要使用的模型。选择模型后会显示其专属参数：`video`、`audio`、`prompt`、`negative_prompt`、`preserve_speech` 和 `seed`。 | DYNAMIC_COMBO | 是 | `"sfx-2.0"` |
| `video` | 要为其生成音效的视频。将为整个片段生成声音，时长为 1 到 600 秒。 | VIDEO | 是 | 1 到 600 秒 |
| `audio` | 用于 `preserve_speech` 以及 `speech` 输出的对白音轨，替代视频自身的音轨。保持未连接状态时，使用视频中嵌入的声音。 | AUDIO | 否 | - |
| `prompt` | 期望的声音效果。可以留空（默认：空），因为模型会自行描述视频，并且它并不总是遵循提示词。最多 2000 个字符。 | STRING | 是 | 最多 2000 个字符 |
| `negative_prompt` | 要避免的声音，以简短的逗号分隔列表表示。可以留空（默认：空）。最多 1000 个字符。 | STRING | 是 | 最多 1000 个字符 |
| `preserve_speech` | 将对话混合到生成的音效之下。关闭时仅返回音效。（默认：True） | BOOLEAN | 是 | false<br />true |
| `seed` | 请求的种子。结果是非确定性的，因此相同的种子不会重复生成同一个片段。（默认：42） | INT | 是 | 0 到 4294967295 |

当片段短于 1 秒或长于 600 秒时，节点会报错停止。已连接的 `audio` 音轨会设定 `preserve_speech` 保留的对白，以及 `speech` 输出分离出的对白；若未连接，则对白来自视频自身的音轨。

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `audio` | 该片段的音效混音；当 `preserve_speech` 开启时，对白会混合在其下。 | AUDIO |
| `speech` | 从音轨中分离出的对白。当未找到语音或语音分离未返回任何内容时，为静音，且采样率与 `audio` 相同。 | AUDIO |
