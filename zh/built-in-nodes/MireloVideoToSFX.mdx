生成跟随视频的音效，可使用 Mirelo SFX 完成。上传视频片段后，模型会跟随画面中的动作，返回一条音效混音，并额外提供一条单独的语音轨，其中包含从音轨中分离出的对白。可用它为无声或部分无声的片段添加拟音、环境声和冲击音效。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 要使用的模型。选择模型后会显示该模型专属的参数：`video`、`audio`、`prompt`、`negative_prompt`、`preserve_speech`、`seed` 和 `auto_downscale`。 | DYNAMIC_COMBO | 是 | `"sfx-2.0"` |
| `video` | 要为其生成音效的视频。音效将针对整个片段生成，时长 1 到 600 秒。 | VIDEO | 是 | 1 到 600 秒 |
| `audio` | 用于 `preserve_speech` 和 `speech` 输出的对白轨，替代视频自带的音轨。保持未连接则使用视频内嵌的声音。 | AUDIO | 否 | - |
| `prompt` | 音效应呈现的效果。可以留空（默认：空），因为模型会自行描述视频，且并不总是遵循提示词。最多 2000 个字符。 | STRING | 是 | 最多 2000 个字符 |
| `negative_prompt` | 需要避免的声音，以简短的逗号分隔列表表示。可以留空（默认：空）。最多 1000 个字符。 | STRING | 是 | 最多 1000 个字符 |
| `preserve_speech` | 将对话混入生成的音效之下。关闭时仅返回音效。（默认：True） | BOOLEAN | 是 | False<br />True |
| `seed` | 用于该请求的种子。结果不确定，因此相同的种子不会重复生成相同的片段。（默认：42） | INT | 是 | 0 到 4294967295 |
| `auto_downscale` | 在上传前对短边超过 2160 像素的片段进行缩小，并保持其宽高比；较小的片段不做处理（默认：True）。 | BOOLEAN | 否 | `True`<br />`False` |

当片段短于 1 秒或长于 600 秒时，该节点会报错停止。连接的 `audio` 轨道会设定 `preserve_speech` 所保留、并由 `speech` 输出分离出的对白；若未连接，则对白来自视频自带的音轨。

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `audio` | 该片段的音效混音；当 `preserve_speech` 开启时，对白会混入其中。 | AUDIO |
| `speech` | 从音轨中分离出的对白。当未检测到语音或语音分离未返回任何内容时，为静音，且采样率与 `audio` 相同。 | AUDIO |
