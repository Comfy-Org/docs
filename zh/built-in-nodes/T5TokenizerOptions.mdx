T5TokenizerOptions 节点可为各种 T5 模型类型配置分词器设置。它会为多个 T5 模型变体（包括 `t5xxl`、`pile_t5xl`、`t5base`、`mt5xl` 和 `umt5xxl`）设置最小填充值和最小长度参数。该节点接收一个 CLIP 输入，将设置应用到其副本上，并返回修改后的 CLIP。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 要为其配置分词器选项的 CLIP 模型 | CLIP | 是 | - |
| `最小填充` | 要为所有 T5 模型类型设置的最小填充值（默认值：0） | INT | 是 | 0 到 10000 |
| `最小长度` | 要为所有 T5 模型类型设置的最小长度值（默认值：0） | INT | 是 | 0 到 10000 |

注意：此节点在 ComfyUI 中被标记为实验性节点。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `output` | 已将更新后的分词器选项应用于所有 T5 变体的修改后 CLIP 模型 | CLIP |
