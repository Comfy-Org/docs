LatentCut 节点沿选定的维度从潜在样本中提取特定部分。它通过指定维度（"x"、"y" 或 "t"）、起始位置以及要提取的数量，从潜在表示中切出一部分。该节点支持正向和负向索引，并会自动调整提取数量，使其保持在可用范围内。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 取值范围 |
| --- | --- | --- | --- | --- |
| `样本` | 要从中提取的输入潜在样本 | LATENT | 是 | - |
| `维度` | 沿其切割潜在样本的维度。"x" 沿最后一个轴切割（通常是宽度），"y" 沿倒数第二个轴（通常是高度），"t" 沿倒数第三个轴（通常是视频潜在表示中的帧） | COMBO | 是 | "x"<br />"y"<br />"t" |
| `索引` | 切割的起始位置（默认值：0）。正值从起始处计数，负值从末尾计数。节点会将 `index` 限制在潜在样本的有效范围内 | INT | 是 | -16384 到 16384 |
| `数量` | 沿指定维度提取的元素数量（默认值：1）。必须至少为 1。如果该值超过起始索引之后可用的数据量，节点会自动减小该值 | INT | 是 | 1 到 16384 |

注意：`index` 和 `amount` 的值会调整以适配潜在样本在所选维度上的实际大小。如果 `index` 大于维度大小，则会被限制到最后一个有效位置。如果 `index` 为负，则按绝对值将其限制在维度大小内，并限制 `amount`，使其不会超出数据末尾。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `output` | 提取出的潜在样本部分 | LATENT |
