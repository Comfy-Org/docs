`PreviewGaussianSplat` 节点用于在预览窗口中显示 3D 高斯溅射（gaussian splat）文件，而无需将其保存到 ComfyUI 输出目录。该节点接受多种格式的 3D 模型文件，保存一个临时副本用于预览，并将模型数据透传给工作流中的后续处理。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 一个高斯溅射 3D 文件。 | FILE3D | 是 | splat<br />ply<br />spz<br />ksplat |
| `model_3d_info` | 有关 3D 模型的可选元数据信息。未连接时，节点将使用 `viewport_state` 中的模型信息。 | LOAD3DMODELINFO | 否 | - |
| `viewport_state` | 3D 视口的当前状态，包括相机和模型信息。 | LOAD3D | 是 | - |
| `camera_info` | 用于预览的可选相机信息。未连接时，节点将使用 `viewport_state` 中的相机信息。 | LOAD3DCAMERA | 否 | - |
| `width` | 预览渲染的宽度，单位为像素（默认值：1024）。 | INT | 是 | 1 至 4096 |
| `height` | 预览渲染的高度，单位为像素（默认值：1024）。 | INT | 是 | 1 至 4096 |

注意：当未提供 `camera_info` 或 `model_3d_info` 时，节点将回退使用 `viewport_state` 中存储的相机和模型信息。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model_3d` | 输入的 3D 高斯溅射文件，原样透传。 | FILE3D |
| `model_3d_info` | 有关 3D 模型的元数据信息，来自输入或从视口状态中派生。 | LOAD3DMODELINFO |
| `camera_info` | 用于预览的相机信息，来自输入或从视口状态中派生。 | LOAD3DCAMERA |
| `width` | 预览渲染的宽度。 | INT |
| `height` | 预览渲染的高度。 | INT |
