PreviewGaussianSplat 节点在预览窗口中显示 3D 高斯泼溅文件，而不会将其保存到 ComfyUI 输出目录。它接受各种高斯泼溅格式的 3D 模型文件，保存一份临时副本用于预览，并将模型数据传递出去，以便在工作流中进一步处理。此节点被标记为实验性节点，并作为输出节点使用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 高斯泼溅 3D 文件。 | FILE3D | 是 | splat<br />ply<br />spz<br />ksplat |
| `model_3d_info` | 关于 3D 模型的可选元数据信息。未连接时，节点使用来自 `viewport_state` 的模型信息。 | LOAD3DMODELINFO | 否 | - |
| `viewport_state` | 3D 视口的当前状态，包括相机和模型信息。 | LOAD3D | 是 | - |
| `camera_info` | 用于预览的可选相机信息。未连接时，节点使用来自 `viewport_state` 的相机信息。 | LOAD3DCAMERA | 否 | - |
| `width` | 预览渲染的宽度，单位为像素（默认值：1024）。 | INT | 是 | 1 到 4096 |
| `height` | 预览渲染的高度，单位为像素（默认值：1024）。 | INT | 是 | 1 到 4096 |

注意：当未提供 `camera_info` 或 `model_3d_info` 时，节点会回退到存储在 `viewport_state` 中的相机和模型信息。如果 `viewport_state` 不是有效的视口状态对象，则将其视为空。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model_3d` | 输入的 3D 高斯泼溅文件，原样传递。 | FILE3D |
| `model_3d_info` | 关于 3D 模型的元数据信息，来自输入或从视口状态推导得到。 | LOAD3DMODELINFO |
| `camera_info` | 用于预览的相机信息，来自输入或从视口状态推导得到。 | LOAD3DCAMERA |
| `width` | 预览渲染的宽度。 | INT |
| `height` | 预览渲染的高度。 | INT |
