从 Anthropic 的 Claude 模型生成文本回复。提供一个文本提示词，并可选地提供一张或多张图像作为多模态上下文，节点将返回模型生成的文本回复。

### 参数约束

- **图像限制：** 每次请求最多可提供 20 张图像。连接超过 20 张图像会引发错误。
- **`prompt` 必填：** `prompt` 必须至少包含一个非空白字符。空提示词会引发验证错误。
- **温度处理：** 启用思考时，Anthropic API 要求不设置 `temperature`（默认为 1.0）。Opus 5.5、Opus 5、Opus 4.8、Fable 5.1、Fable 5 和 Sonnet 5 不提供 `temperature` 设置。Opus 4.7 会忽略 `temperature`，并且任何将 `reasoning_effort` 设置为 `"off"` 以外值的模型也会忽略它。
- **推理/思考行为：** `reasoning_effort` 设置控制是否启用思考。Opus 5.5、Opus 5、Fable 5.1 和 Fable 5 始终启用推理。Haiku 4.5 不支持推理。启用思考时，节点会为所选模型使用适当的思考模式，即自适应模式或基于预算的模式。在预算模式下，推理 token 预算会被限制，以便为实际回复保留至少 1024 个 token。
- **安全拒绝：** 如果 Claude 出于安全原因拒绝回答请求，节点会引发错误，要求你重新表述提示词或尝试其他模型。
- **输出文本：** 思考与推理块不会包含在输出中；仅返回生成的文本。
