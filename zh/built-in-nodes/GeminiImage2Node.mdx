通过 Google Vertex AI Gemini API 同步生成或编辑图像。您提供文本提示，并可以选择附加参考图像或 Gemini 输入文件。该节点会返回生成的图像，并根据所选的响应模式返回文本响应。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 文本提示，描述要生成或要应用的编辑。包括模型应遵循的任何约束、风格或细节。去除空白字符后，提示必须至少包含一个字符。 | STRING | 是 | N/A |
| `模型` | 用于生成的 Gemini 模型。"Nano Banana 2 (Gemini 3.1 Flash Image)" 选项会以 `gemini-3.1-flash-image` 发送；"gemini-3-pro-image-preview" 会以 `gemini-3-pro-image` 发送。 | COMBO | 是 | "gemini-3-pro-image-preview"<br />"Nano Banana 2 (Gemini 3.1 Flash Image)" |
| `随机种` | 当 `seed` 固定为特定值时，模型会尽力为重复请求提供相同的响应。不保证输出具有确定性。此外，即使使用相同的 `seed` 值，更改模型或参数设置（例如 temperature）也可能导致响应发生变化。默认情况下，使用随机 `seed` 值。默认值：42。 | INT | 是 | 0 到 18446744073709551615 |
| `宽高比` | 如果设置为 'auto'，则匹配输入图像的宽高比；如果未提供图像，通常生成 16:9 的图像。默认值："auto"。 | COMBO | 是 | "auto"<br />"1:1"<br />"2:3"<br />"3:2"<br />"3:4"<br />"4:3"<br />"4:5"<br />"5:4"<br />"9:16"<br />"16:9"<br />"21:9" |
| `分辨率` | 目标输出分辨率。对于 2K/4K，使用原生 Gemini 放大器。 | COMBO | 是 | "1K"<br />"2K"<br />"4K" |
| `响应模态` | 选择 'IMAGE' 仅输出图像，或选择 'IMAGE+TEXT' 同时返回生成的图像和文本响应。高级设置。 | COMBO | 是 | "IMAGE+TEXT"<br />"IMAGE" |
| `图像` | 可选的参考图像。要包含多张图像，请使用 Batch Images 节点（最多 14 张）。 | IMAGE | 否 | N/A |
| `文件` | 可选的文件，用作模型的上下文。接受来自 Gemini Generate Content Input Files 节点的输入。 | GEMINI_INPUT_FILES | 否 | N/A |
| `系统提示词` | 决定 AI 行为的基础指令。默认值：用于图像生成的预定义系统提示。高级设置。 | STRING | 否 | N/A |

**约束：**

* `images` 输入最多支持 14 张图像。如果提供的图像超过此数量，将引发错误。
* 当提供的图像超过 10 张时，前 10 张会作为 URL 引用上传，其余图像会在请求中内联发送。
* `files` 输入必须连接到输出 `GEMINI_INPUT_FILES` 数据类型的节点。
* 当 `response_modalities` 设置为 `"IMAGE"` 时，仅返回图像，文本输出为空。
* `prompt` 输入会经过验证，去除空白字符后必须至少包含一个字符。

## 输出

| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 由 Gemini 模型生成或编辑的图像。 | IMAGE |
| `string` | 来自模型的文本响应。如果 `response_modalities` 设置为 `"IMAGE"`，此输出为空。 | STRING |
