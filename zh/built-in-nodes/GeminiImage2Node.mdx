GeminiImage2Node 使用 Google Vertex AI Gemini 模型生成或编辑图像。您可以提供文本提示词，并可选择提供参考图像或文件；节点会将这些内容发送到 API，返回生成的图像，并在请求时返回文本响应。

## 输入

| 参数 | 说明 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 文本提示词，描述要生成的图像或要应用的编辑。包括模型应遵循的任何约束、样式或细节。提示词在去除空白后必须至少包含一个字符。 | STRING | 是 | N/A |
| `模型` | 用于生成的具体 Gemini 模型。“Nano Banana 2 (Gemini 3.1 Flash Image)”选项在内部映射到 `gemini-3.1-flash-image` 模型，“gemini-3-pro-image-preview”映射到 `gemini-3-pro-image`。 | COMBO | 是 | `"gemini-3-pro-image-preview"`<br />`"Nano Banana 2 (Gemini 3.1 Flash Image)"` |
| `随机种` | 当 `seed` 固定为特定值时，模型会尽力为重复请求提供相同响应。但不保证确定性输出。此外，更改模型或参数设置（如温度）即使在相同种子值下也可能导致响应变化。默认情况下使用随机种子值。默认值：42。 | INT | 是 | 0 到 18446744073709551615 |
| `宽高比` | 若设置为“auto”，将匹配输入图像的纵横比；如果未提供图像，通常生成 16:9 的画面。默认值：“auto”。 | COMBO | 是 | `"auto"`<br />`"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"`<br />`"21:9"` |
| `分辨率` | 目标输出分辨率。对于 2K/4K，使用 Gemini 原生超分辨率器。 | COMBO | 是 | `"1K"`<br />`"2K"`<br />`"4K"` |
| `响应模态` | 选择“IMAGE”仅输出图像，或选择“IMAGE+TEXT”同时返回生成的图像和文本响应。 | COMBO | 是 | `"IMAGE+TEXT"`<br />`"IMAGE"` |
| `图像` | 可选的参考图像。若要包含多张图像，请使用 Batch Images 节点（最多 14 张）。 | IMAGE | 否 | N/A |
| `文件` | 可选的文件，用作模型的上下文。接受来自 Gemini Generate Content Input Files 节点的输入。 | GEMINI_INPUT_FILES | 否 | N/A |
| `系统提示词` | 规定 AI 行为的基础指令。默认值：用于图像生成的预定义系统提示词。 | STRING | 否 | N/A |

**约束：**

* `images` 输入最多支持 14 张图像。如果提供更多，将引发错误。
* 当提供超过 10 张图像时，前 10 张作为 URL 引用上传，其余图像在请求中以内联方式发送。
* `files` 输入必须连接到输出 `GEMINI_INPUT_FILES` 数据类型的节点。
* 当 `response_modalities` 设置为“IMAGE”时，仅返回图像，文本输出为空。

## 输出

|-------------|-------------|-----------|
| `image` | 由 Gemini 模型生成或编辑的图像。 | IMAGE |
| `string` | 来自模型的文本响应。如果 `response_modalities` 设置为“IMAGE”，此输出将为空。 | STRING |
