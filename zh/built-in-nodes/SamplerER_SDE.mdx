SamplerER_SDE 节点为扩散模型提供专门的采样方法，支持不同的求解器类型：ER-SDE、Reverse-time SDE 和 ODE。它允许你控制采样过程的随机行为以及计算阶段的数量。该节点会根据所选的求解器类型自动调整设置，以确保采样器正常工作。

## 输入
| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `求解器` | 用于采样的求解器类型。决定扩散过程的数学方法（默认值："ER-SDE"）。 | COMBO | 是 | "ER-SDE"<br />"Reverse-time SDE"<br />"ODE" |
| `最大阶段` | 采样过程的最大阶段数（默认值：3）。控制计算复杂度和质量。 | INT | 是 | 1-3 |
| `eta` | SDE 的随机强度。<br />当 eta=0 时，它们退化为确定性 ODE。<br />较大的 eta 值可能导致无效输出。如果出现这种情况，请尝试减小该值。（默认值：1.0） | FLOAT | 是 | 0.0-10.0 (step: 0.01) |
| `s_noise` | 采样过程的噪声缩放因子（默认值：1.0）。控制采样期间应用的噪声量。 | FLOAT | 是 | 0.0-100.0 (step: 0.01) |

**参数约束：**

- 当 `solver_type` 设置为 "ODE" 或 `eta` 为 0 时，节点会切换到 ODE 模式，并将 `s_noise` 设置为 0.0，无论为 `s_noise` 输入了什么值。
- `eta` 参数控制 “ER-SDE” 和 “Reverse-time SDE” 两种求解器类型的随机强度。当求解器以 ODE 模式运行时，该参数无效。

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `sampler` | 一个已配置的采样器对象，可在采样流程中按指定的求解器设置使用。 | SAMPLER |
