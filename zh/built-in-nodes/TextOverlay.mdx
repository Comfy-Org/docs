此节点在图像或一批图像上绘制文本。它使用可配置的字体大小、颜色、垂直位置、水平对齐方式以及可选的黑色轮廓创建文本叠加层，然后将叠加层与原始图像像素合成。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要在其上绘制文本的输入图像或一批图像 | IMAGE | 是 | |
| `文字` | 要叠加到图像上的文本（默认值：""）。支持多行：`\n` 和 `\t` 转义序列会转换为换行符和制表符，长行会自动换行以适应图像宽度。 | STRING | 是 | |
| `字体大小` | 字体大小，以图像高度的百分比表示（默认值：5.0） | FLOAT | 是 | 0.5 到 50.0 （步长：0.5） |
| `颜色` | 文本颜色（默认值："#ffffff"） | COLOR | 是 | |
| `位置` | 文本在图像上的垂直位置（默认值："top"） | COMBO | 是 | "top"<br />"bottom" |
| `对齐` | 文本的水平对齐方式（默认值："left"） | COMBO | 是 | "left"<br />"center"<br />"right" |
| `描边` | 在文本周围绘制黑色轮廓（默认值：True） | BOOLEAN | 是 | |

注意：如果 `text` 为空或仅包含空白字符，此节点将原样返回输入图像。文本叠加层仅渲染一次，并应用于批次中的每张图像。如果渲染后的文本块高于可用图像区域，字体大小会自动缩小，直到适合或达到最小尺寸。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `images` | 已合成文本叠加层的输入图像 | IMAGE |
