Flux Video Upscale 使用 FLUX 超分辨率将视频片段放大 1.5 到 3 倍。在 creative 模式下，它会恢复并创造精细细节；在 precise 模式下，它会锐化源视频而不改变它。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `视频` | 时长 1 到 20 秒、宽高比在 1:4 到 4:1 之间的源视频片段。输出以 24 fps 渲染，每帧上限约为 14.4 兆像素。 | VIDEO | 是 | 1 到 20 秒时长；宽高比在 1:4 到 4:1 之间；最小 64x64 像素 |
| `upscale_factor` | 相对于源视频的输出尺寸。由于每帧上限，非常大的源视频实际放大倍数会低于请求的倍数。（默认值：2.0） | FLOAT | 是 | 1.5 到 3.0（步长 0.1） |
| `模式` | 'creative' 会恢复并创造精细细节，最适合生成素材、纹理和场景。'precise' 会锐化源视频而不改变它，适用于人脸、产品和实拍素材。（默认值："creative"） | COMBO | 是 | "creative"<br />"precise" |
| `提示词` | 可选的片段描述，用于引导增强后的细节。留空则进行中性放大。（默认值：空） | STRING | 是 | 多行文本 |
| `auto_downscale` | 自动缩小面积大于 3840x2160 像素的源视频，以符合输入限制。保持宽高比；较小的视频不受影响。（默认值：true） | BOOLEAN | 是 | true<br />false |
| `safety_tolerance` | 内容审核容忍度，0 最严格。（默认值：2，高级参数） | INT | 是 | 0 到 4 |
| `种子` | 用于确定节点是否应重新运行的种子；FLUX 会自行选择种子，因此无论此值如何，实际结果都是非确定性的。（默认值：42） | INT | 是 | 0 到 4294967295 |

注意：源视频时长必须在 1 到 20 秒之间，尺寸至少为 64x64 像素，并且宽高比在 1:4 到 4:1 之间。如果禁用 `auto_downscale`，且视频面积超过 3840x2160 像素，节点会报错。输出视频以 24 fps 渲染，每帧上限约为 14.4 兆像素，因此非常大的源视频实际放大倍数可能低于请求的倍数。

| `video` | 放大后的视频片段。 | VIDEO |
