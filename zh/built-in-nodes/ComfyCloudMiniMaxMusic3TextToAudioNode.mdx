在 Comfy Cloud GPU 上运行 MiniMax Music 3 工作流，并返回生成的歌曲。`prompt` 承载风格、配器和情绪；歌词是被演唱出来的，而非描述出来的，空的歌词会使曲目成为纯器乐。此节点为测试版节点，按 GPU 秒计费。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 歌曲描述：风格、配器和情绪。提交前会移除首尾空白。 | STRING | 是 | 1 到 4096 个字符 |
| `歌词` | 要演唱的歌词。留空则为纯器乐。 | STRING | 否 | 0 到 4096 个字符 |
| `种子` | 控制生成结果的随机种子（默认值：42）。 | INT | 是 | 0 到 9223372036854775807 |
| `最大时长` | 曲目可能运行的最长时长，以秒为单位（默认值：120.0）。模型可以提前结束歌曲。 | FLOAT | 是 | 0.04 到 360.0（步长 0.04） |
| `音频质量` | 输出比特率。`"V0"` 为可变比特率，且是三者中质量最高的（默认值：`"V0"`）。 | COMBO | 是 | `"V0"`<br />`"128k"`<br />`"320k"` |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `AUDIO` | 生成的歌曲。 | AUDIO |
