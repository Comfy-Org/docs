此节点使用 PixVerse V6 模型对现有视频进行续写，并可在续写的同时选择生成原生音轨。源视频时长必须短于 40 秒，宽度和高度均不超过 1920 像素。输出保持源视频的分辨率，因此质量设置控制的是续写内容的渲染精细度，而非画面尺寸。

## 输入
### 通用输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `视频` | 要续写的视频。 | VIDEO | 是 | 不超过 40 秒；宽度和高度均不超过 1920 像素 |
| `模型` | 模型与生成设置。 | DYNAMIC_COMBO | 是 | "PixVerse V6" |

### PixVerse V6 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述视频应如何继续生成的提示词。（默认：空） | STRING | 是 | 1–5000 字符 |
| `quality` | 生成续写内容的渲染质量：1080p 明显优于 540p 或 360p。该参数不会调整尺寸——输出保持源视频的分辨率。（默认："720p"） | COMBO | 是 | "360p"<br />"540p"<br />"720p"<br />"1080p" |
| `duration_seconds` | 生成视频的时长（秒）。（默认：5） | INT | 是 | 1–15 |
| `generate_audio` | 连同视频一起生成原生音轨。（默认：true） | BOOLEAN | 是 | true / false |
| `seed` | 视频生成的随机种子。PixVerse 会记录该值，但无法用它复现某次生成。（默认：42） | INT | 是 | 0–2147483647 |
| `negative_prompt` | 对视频中不想要元素的可选文字描述。（默认：空） | STRING | 否 | 最多 2048 字符 |
| `style` | 应用于整个视频的可选视觉风格。（默认："none"） | COMBO | 否 | 多个选项可选；默认值为 "none" |

**注意：** 源 `video` 必须短于 40 秒，且宽度和高度均不超过 1920 像素；更长或更大的视频将被拒绝。生成的输出保持源视频的分辨率，因此 `quality` 改变的是渲染保真度，而非输出画面尺寸。`prompt` 为必填项，去除首尾空白后必须包含 1 到 5000 个字符。`negative_prompt` 如提供则限制为 2048 个字符。`seed` 会被 PixVerse 记录，但无法用于复现同一运行。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 生成的续写视频，分辨率与源视频相同。 | VIDEO |
