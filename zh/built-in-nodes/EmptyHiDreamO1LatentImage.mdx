此节点为 HiDream-O1-Image 模型在像素空间中创建一个空潜空间图像。它生成一个填充零的空白张量，作为图像生成的起点，其尺寸由 `width`、`height` 和 `batch_size` 输入定义。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `宽度` | 潜空间图像的宽度，以像素为单位。默认值：2048。该值必须是 32 的倍数。模型在约 4 百万像素下训练；较低分辨率可能会明显降低质量。 | INT | 是 | 64 到 4096 （步长：32） |
| `高度` | 潜空间图像的高度，以像素为单位。默认值：2048。该值必须是 32 的倍数。模型在约 4 百万像素下训练；较低分辨率可能会明显降低质量。 | INT | 是 | 64 到 4096 （步长：32） |
| `批量大小` | 在单个批次中生成的潜空间图像数量。默认值：1。 | INT | 是 | 1 到 64 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `samples` | 一个填充零的张量，表示空潜空间图像，形状为 (batch_size, 3, height, width)。 | LATENT |

## 说明

- HiDream-O1-Image 模型在大约 4 百万像素下进行训练。使用显著较低的分辨率可能会导致图像质量明显下降。
- 训练分辨率包括：2048x2048, 2304x1728, 1728x2304, 2560x1440, 1440x2560, 2496x1664, 1664x2496, 3104x1312, 1312x3104, 2304x1792, 1792x2304。
