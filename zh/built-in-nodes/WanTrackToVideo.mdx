WanTrackToVideo 节点通过处理轨迹点并生成相应的视频帧，将运动跟踪数据转换为视频序列。它以跟踪坐标作为输入，生成可用于视频生成的视频条件（conditioning）和潜在（latent）表示。当未提供轨迹时，它会回退到标准的图像到视频转换。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `正面条件` | 用于视频生成的正向条件 | CONDITIONING | 是 | - |
| `负面条件` | 用于视频生成的负向条件 | CONDITIONING | 是 | - |
| `vae` | 用于编码和解码的 VAE 模型 | VAE | 是 | - |
| `tracks` | JSON 格式的跟踪数据，以多行字符串形式表示（默认：`"[]"`）。每条轨迹会被填充或截断至固定长度 121 个点。 | STRING | 是 | - |
| `宽度` | 输出视频宽度（像素）（默认：832，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 输出视频高度（像素）（默认：480，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `长度` | 输出视频的帧数（默认：81，步长：4） | INT | 是 | 1 to MAX_RESOLUTION |
| `批次大小` | 同时生成的视频数量（默认：1） | INT | 是 | 1 到 4096 |
| `温度` | 运动修补的温度参数（默认：220.0，步长：0.1） | FLOAT | 是 | 1.0 到 1000.0 |
| `topk` | 运动修补的 Top-k 值（默认：2） | INT | 是 | 1 到 10 |
| `图像` | 用于视频生成的起始图像 | IMAGE | 否 | - |
| `CLIP视觉输出` | 用于额外条件的 CLIP 视觉输出 | CLIP_VISION_OUTPUT | 否 | - |

**注意：** 当 `tracks` 包含有效的跟踪数据时，节点会处理运动轨迹以生成视频。当 `tracks` 为空时，它会切换到标准图像到视频模式。如果提供了 `start_image`，它将初始化视频序列的第一帧，并将运动修补结果添加到正向和负向条件中。如果提供了 `clip_vision_output`，它也会被添加到正向和负向条件中。

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `正面提示词` | 已应用运动轨迹信息的正向条件 | CONDITIONING |
| `负面提示词` | 已应用运动轨迹信息的负向条件 | CONDITIONING |
| `latent` | 生成的视频潜在表示 | LATENT |
