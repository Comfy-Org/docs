此节点使用 Bria 将图像移动到另一个季节。整个场景会被重新渲染，因此景物可能会发生超出季节本身的变化。Bria 会以约 1 百万像素重新渲染整帧，因此结果不会与输入图像像素级对齐。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要移动到另一个季节的图像。发送图像前会移除任何 Alpha 通道。 | IMAGE | 是 | - |
| `季节` | 要应用的季节。 | COMBO | 是 | `"spring"`<br />`"summer"`<br />`"autumn"`<br />`"winter"` |
| `内容审核` | 审核设置。选择是否为此请求配置内容审核选项。 | DYNAMIC_COMBO | 是 | `"false"`<br />`"true"` |

### 审核输入

当 `moderation` 设置为 `"true"` 时，会出现这些选项。

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | 对输入图像启用内容审核（默认：false）。 | BOOLEAN | 否 | true<br />false |
| `visual_output_moderation` | 对生成的输出图像启用内容审核（默认：false）。 | BOOLEAN | 否 | true<br />false |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `IMAGE` | 所选季节下重新渲染的图像。 | IMAGE |
| `structured_prompt` | 编辑后图像的结构化描述，用于通过 Bria FIBO Image Edit 进行后续编辑。 | STRING |
