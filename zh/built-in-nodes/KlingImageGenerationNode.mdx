Kling 图像生成节点从文本提示词生成图像，并可以选择使用参考图像进行引导。它根据您的文本描述和参考设置创建一张或多张图像，然后返回生成的图像作为输出。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 正向文本提示词。必需，长度必须在 1 到 500 个字符之间。 | STRING | 是 | 最多 500 个字符 |
| `负面提示词` | 负向文本提示词。 | STRING | 是 | 最多 500 个字符 |
| `图像类型` | 图像参考类型选择（高级）。提供参考图像时必需。 | COMBO | 是 | `"subject_reference"`<br />`"style_reference"` |
| `图像参考强度` | 用户上传图像的参考强度（默认值：0.5，高级） | FLOAT | 是 | 0.0 - 1.0 |
| `主体参考强度` | 主体参考相似度（默认值：0.45，高级） | FLOAT | 是 | 0.0 - 1.0 |
| `模型` | 用于图像生成的模型选择（默认值："kling-v3"） | COMBO | 是 | `"kling-v3"` |
| `宽高比` | 生成图像的宽高比（默认值："16:9"） | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"`<br />`"21:9"`<br />`"9:21"` |
| `图像数量` | 生成图像数量（默认值：1） | INT | 是 | 1 - 9 |
| `图像` | 可选参考图像 | IMAGE | 否 | - |
| `种子` | `seed` 控制节点是否应重新运行；无论 `seed` 如何，结果都是非确定性的（默认值：0） | INT | 否 | 0 - 2147483647 |

**参数约束：**

- `image` 参数是可选的。当提供参考图像时，`image_type` 参数决定该参考是用作主体参考还是风格参考。
- 当未提供参考图像时，参考相关设置（`image_type`、`image_fidelity`、`human_fidelity`）对结果没有影响。
- `prompt` 和 `negative_prompt` 的最大长度为 500 个字符。
- `seed` 参数是可选的，并且不保证确定性结果。
- `n` 参数控制生成多少张图像，同时也决定请求的价格。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 基于输入参数生成的图像。当 `n` 大于 1 时，多张图像将作为批次返回。 | IMAGE |
