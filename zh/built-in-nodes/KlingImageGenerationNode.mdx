Kling 图像生成节点根据文本提示生成图像，并可选择使用参考图像进行引导。该节点会根据你的文本描述和参考设置生成一张或多张图像，然后将生成的图像作为输出返回。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 正向文本提示 | STRING | 是 | 最多 500 个字符 |
| `负面提示词` | 负向文本提示 | STRING | 是 | 最多 500 个字符 |
| `图像类型` | 图像参考类型选择（高级）。当提供参考图像时为必填项。 | COMBO | 是 | `"subject_reference"`<br />`"style_reference"` |
| `图像参考强度` | 用户上传图像的参考强度（默认：0.5，高级） | FLOAT | 是 | 0.0 - 1.0 |
| `主体参考强度` | 主体参考相似度（默认：0.45，高级） | FLOAT | 是 | 0.0 - 1.0 |
| `模型` | 图像生成的模型选择（默认："kling-v3"） | COMBO | 是 | `"kling-v3"` |
| `宽高比` | 生成图像的宽高比（默认："16:9"） | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"`<br />`"21:9"`<br />`"9:21"` |
| `图像数量` | 生成图像数量（默认：1） | INT | 是 | 1 - 9 |
| `图像` | 可选的参考图像 | IMAGE | 否 | - |
| `种子` | 种子控制节点是否重新运行；无论种子如何，结果都是非确定性的（默认：0） | INT | 否 | 0 - 2147483647 |

**参数约束：**

- `image` 参数是可选的。当提供参考图像时，`image_type` 参数决定参考图像是作为主体参考还是风格参考使用。
- 当未提供参考图像时，与参考相关的设置（`image_type`、`image_fidelity`、`human_fidelity`）对结果没有影响。
- `prompt` 和 `negative_prompt` 的最大长度为 500 个字符。
- `seed` 参数是可选的，并且不保证确定性结果。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 根据输入参数生成的图像。当 `n` 大于 1 时，多个图像作为一批返回。 | IMAGE |
