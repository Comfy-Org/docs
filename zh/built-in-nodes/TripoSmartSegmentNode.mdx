将一个 3D 模型拆分为具有语义意义的部分，并为每个部分命名。它既可以分割已有模型（通过任务 ID 提供），也可以先从图像生成模型，然后再将其分割。生成的 `segment task_id` 可供其他 Tripo 节点使用，例如 Complete Mesh Parts、Retopology、Texture model 和 Convert model，其使用方式与 Tripo: Segment Model 的结果相同。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `来源` | 分割已有模型，或从图像生成模型并对其进行分割。所选选项决定显示哪些额外输入。 | DYNAMIC_COMBO | 是 | `"model"`<br />`"image"` |

### 模型输入

当 `source` 设置为 `"model"` 时显示。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | 一个 GLB 结果。四边形（FBX）网格必须先经过 Tripo: Convert model (GLTF) 处理。 | MODEL_TASK_ID | 是 | - |
| `granularity` | 模型被分割成部分的精细程度（默认："medium"）。 | COMBO | 否 | `"coarse"`<br />`"medium"`<br />`"fine"` |
| `hint` | 可选文本，用于指出要查找的部分名称，例如 '手持剑与盔甲的游戏角色'（默认为空）。 | STRING | 否 | - |

### 图像输入

当 `source` 设置为 `"image"` 时显示。Tripo 会先从图像生成模型，然后再对其进行分割。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 用于生成将要被分割的模型的图像。 | IMAGE | 是 | - |
| `granularity` | 模型被分割成部分的精细程度（默认："medium"）。 | COMBO | 否 | `"coarse"`<br />`"medium"`<br />`"fine"` |
| `hint` | 可选文本，用于指出要查找的部分名称，例如 '手持剑与盔甲的游戏角色'（默认为空）。 | STRING | 否 | - |

**说明：**

- `granularity` 和 `hint` 为两种 `source` 选项共用，且均为可选。当 `hint` 留空时，不会向服务发送任何提示。
- 当 `source` 为 `"model"` 时，仅接受 GLB 模型。其他格式，例如四边形（FBX）网格，必须先使用 Tripo: Convert model (GLTF) 进行转换。
- 任务会轮询直到达到终止状态，预计耗时约 180 秒。如果 Tripo 返回不完整的分割结果，节点会报告错误。
- 价格标记：当 `source` 为 `"image"` 时约为 0.85 USD，当 `source` 为 `"model"` 时约为 0.55 USD（数值为近似值）。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `segment task_id` | 分割任务的任务 ID，可用作其他 Tripo 节点的输入。 | SEGMENT_TASK_ID |
| `model task_id` | 被分割的模型（由图像生成，或导入的模型）。 | MODEL_TASK_ID |
| `GLB` | 分割后的 3D 模型文件。 | FILE3DGLB |
| `part_names` | 以逗号分隔的各部分名称。 | STRING |
| `parts` | Tripo 对其找到的部分的描述。 | STRING |
| `mask` | 分割生成的遮罩图像。 | IMAGE |
