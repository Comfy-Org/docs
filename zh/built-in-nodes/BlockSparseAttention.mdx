## 概述

Block Sparse Attention 节点将块稀疏注意力机制应用于 ComfyUI 模型，通过允许每个查询块仅精确地关注所选子集的关键块，从而减少注意力计算。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要应用块稀疏注意力的 ComfyUI 模型。 | MODEL | 是 | N/A |
| `selection` | 选择要关注哪些关键块的选取方法。 | DYNAMIC_COMBO | 是 | 选项：Sol-Attn (自适应 tau)，top-k (SLA)，VSA (FastVideo) |
| `tau` | Sol-Attn (自适应 tau) 选取中用于分数分布 sigmas 的阈值。 | FLOAT | 否 | 默认：1.3，最小：0.0，最大：4.0，步长：0.05 |
| `keep_percent` | top-k (SLA) 选取中每个查询块精确保留的关键块百分比。 | FLOAT | 否 | 默认：10.0，最小：0.5，最大：95.0，步长：0.5 |
| `start_percent` | 模型在哪个时间表百分比之前使用密集注意力。 | FLOAT | 否 | 默认：0.2，最小：0.0，最大：1.0，步长：0.01 |
| `end_percent` | 模型在哪个时间表百分比之后使用密集注意力。 | FLOAT | 否 | 默认：1.0，最小：0.0，最大：1.0，步长：0.01 |
| `dense_blocks` | 表示始终运行密集注意力的 Transformer 块的字符串。 | STRING | 否 | 默认："" |
| `min_tokens` | 模型使用密集注意力的序列中令牌的最小数量。 | INT | 否 | 默认：12288，最小：0，最大：1 &lt;&lt; 20，步长：512 |
| `extra_tokens` | 每个查询块在其所选块之外关注的额外最高分令牌数量。 | INT | 否 | 默认：256，最小：0，最大：256，步长：64 |
| `sink_conditioning` | 用于 sink conditioning 的 MiniMax-H3 条件行。 | COMBO | 否 | 选项：exact_kv，exact_kv_and_rows，off |
| `verbose` | 是否启用详细日志记录。 | BOOLEAN | 否 | 默认：False |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model` | 应用了块稀疏注意力的 ComfyUI 模型。 | MODEL |

### 注意事项

- `selection` 参数确定如何选择关键块。选项包括：
  - Sol-Attn (自适应 tau)：每个查询块根据自适应阈值关注所选子集的关键块。
  - top-k (SLA)：每个查询块精确保留固定百分比的关键块。
  - VSA (FastVideo)：每个查询块精确保留固定百分比的视频立方体，使用 FastH3-VSA 的立方体贴图和粗分支。
- `dense_blocks` 参数允许您指定始终运行密集注意力的 Transformer 块。
- `min_tokens` 参数设置模型使用密集注意力的序列中令牌的最小数量。
- `extra_tokens` 参数允许您指定每个查询块在其所选块之外关注的额外最高分令牌数量。
- `sink_conditioning` 参数确定用于 sink conditioning 的 MiniMax-H3 条件行。
- `verbose` 参数启用详细日志记录。
