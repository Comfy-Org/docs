Meshy: Text to Model 节点使用 Meshy API 根据文本描述生成 3D 模型。它会使用你的提示词和设置向 API 发送请求，然后等待生成完成并下载生成的模型文件。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 指定用于生成的 AI 模型版本。 | COMBO | 是 | `"meshy-7"`<br />`"meshy-6"`<br />`"latest"` |
| `prompt` | 你想要生成的 3D 模型的文本描述。长度必须在 1 到 600 个字符之间。默认值为空字符串。 | STRING | 是 | 1 - 600 characters |
| `style` | 生成的 3D 模型的艺术风格。 | COMBO | 是 | `"realistic"` |
| `should_remesh` | 当设置为 false 时，返回未处理的三角网格。选择 "true" 会显示用于拓扑和目标多边形数量的额外参数。 | DYNAMIC_COMBO | 是 | `"true"`<br />`"false"` |
| `topology` | 重新网格化模型的目标多边形类型。此参数仅在 `should_remesh` 设置为 "true" 时可用。 | COMBO | 否* | `"triangle"`<br />`"quad"` |
| `target_polycount` | 重新网格化模型的目标多边形数量。默认值为 300000。此参数仅在 `should_remesh` 设置为 "true" 时可用。 | INT | 否* | 100 - 300000 |
| `symmetry_mode` | 控制生成模型中的对称性。这是一个高级参数。选项为 `"auto"`、`"on"` 和 `"off"`。 | COMBO | 是 | `"auto"`<br />`"on"`<br />`"off"` |
| `pose_mode` | 指定生成模型的姿态模式。空字符串表示不请求特定姿态。这是一个高级参数。 | COMBO | 是 | `""`<br />`"A-pose"`<br />`"T-pose"` |
| `seed` | `seed` 控制节点是否应重新运行；无论 `seed` 如何，结果都是非确定性的。默认值为 0。 | INT | 是 | 0 - 2147483647 |
| `超精细模式` | 运行额外的细化处理，以获得具有更精细表面细节的高保真几何体。默认值为 false。 | BOOLEAN | 是 | true<br />false |

*注意：`topology` 和 `target_polycount` 参数为条件可用。仅当 `should_remesh` 参数设置为 "true" 时才会出现。

当启用 `ultra_mode` 时，`model` 参数必须设置为 `"meshy-7"` 或 `"latest"`。如果与 `ultra_mode` 一起选择了任何其他模型，节点会引发错误。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model_file` | 生成的 GLB 模型的文件名。提供此输出是为了向后兼容。 | STRING |
| `meshy_task_id` | Meshy API 任务的唯一标识符。 | MESHY_TASK_ID |
| `GLB` | 以 GLB 格式生成的 3D 模型文件。 | FILE3DGLB |
| `FBX` | 以 FBX 格式生成的 3D 模型文件。 | FILE3DFBX |
