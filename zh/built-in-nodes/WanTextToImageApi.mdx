Wan 文本到图像节点根据文本描述生成图像。它使用 AI 模型从书面提示中创建视觉内容，支持英文和中文文本输入。该节点提供多种控制，用于调整输出图像的大小、质量和风格偏好。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要使用的模型（默认："wan2.5-t2i-preview"） | STRING | 是 | "wan2.5-t2i-preview" |
| `提示词` | 描述元素和视觉特征的提示。支持英文和中文（默认：空） | STRING | 是 | - |
| `负面提示词` | 描述要避免的内容的负面提示（默认：空） | STRING | 否 | - |
| `宽度` | 图像宽度（像素）（默认：1024，步长：32） | INT | 否 | 768-1440 |
| `高度` | 图像高度（像素）（默认：1024，步长：32） | INT | 否 | 768-1440 |
| `种子` | 用于生成的种子（默认：0） | INT | 否 | 0-2147483647 |
| `提示词增强` | 是否使用 AI 辅助增强提示（默认：True） | BOOLEAN | 否 | - |
| `水印` | 是否向结果添加 AI 生成的水印（默认：False） | BOOLEAN | 否 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 基于文本提示生成的图像 | IMAGE |
