LatentOperationSharpen 节点使用基于高斯的内核为潜在表示创建锐化操作。它会对潜在数据进行归一化，通过卷积应用自定义锐化内核，然后恢复原始亮度，从而增强潜在空间表示中的细节和边缘。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `锐化半径` | 锐化内核的半径，用于控制锐化所使用区域的大小（默认值：9） | INT | 是 | 1-31 |
| `西格玛` | 用于构建锐化内核的高斯核的标准差（默认值：1.0） | FLOAT | 是 | 0.1-10.0 |
| `阿尔法` | 锐化强度系数；数值越高，锐化效果越强（默认值：0.1） | FLOAT | 是 | 0.0-5.0 |

这三个输入均为高级参数，且都有默认值，因此可以在不修改它们的情况下使用该节点。此节点被标记为实验性功能。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `operation` | 返回一个可应用于潜在数据的锐化操作 | LATENT_OPERATION |
