LatentOperationSharpen 节点使用高斯核为潜在表示创建锐化操作。它归一化潜在数据，通过卷积应用自定义锐化核，然后恢复原始亮度。这增强了潜在空间表示中的细节和边缘。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `锐化半径` | 锐化核的半径，控制用于锐化的区域大小（默认值：9） | INT | 是 | 1-31 |
| `西格玛` | 用于构建锐化核的高斯核的标准差（默认值：1.0） | FLOAT | 是 | 0.1-10.0 |
| `阿尔法` | 锐化强度因子；数值越高，锐化效果越强（默认值：0.1） | FLOAT | 是 | 0.0-5.0 |

所有三个输入均为高级参数，且具有默认值，因此在不更改它们的情况下也可以使用该节点。此节点被标记为实验性。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `operation` | 返回一个可应用于潜在数据的锐化操作 | LATENT_OPERATION |
