使用 Kling 4.0 模型，基于参考图像和参考视频生成带音频的视频。参考素材用于驱动主体、风格和运动，可选的首帧和尾帧则锁定片段的开始与结束。当需要在提示词中描述动作、同时让某个角色或场景在整段镜头中保持一�致时，可以使用此节点。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 模型选择器。`"kling-4.0"` 支持最高 4K HDR、30 秒片段以及尾帧；`"kling-4.0-flash"` 仅限 720p 和 20 秒，且没有 `last_frame` 输入。选择模型后，下方会显示其对应的输入项。 | DYNAMIC_COMBO | 是 | `"kling-4.0"`<br />`"kling-4.0-flash"` |

### kling-4.0-flash 输入

当 `model` 设为 `"kling-4.0-flash"` 时，将显示以下输入项。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |

| `reference_videos` | 可增长的参考视频插槽，最多 5 个。在提示词中以 `@Video1`、`@Video2` 等引用。每个视频以及所有视频的总时长必须为 3 到 20 秒。 | AUTOGROW | 否 | 0 到 5 个视频 |

| `prompt` | 要生成视频的描述。以 `@Image1`、`@Image2` 等以及 `@Video1`、`@Video2` 等引用输入项。 | STRING | 是 | 1 到 26000 个字符 |
| `resolution` | 输出视频的分辨率。Flash 仅渲染 720p。默认：`"720p"`。 | COMBO | 是 | `"720p"` |
| `aspect_ratio` | 输出视频的宽高比。`"adaptive"` 会跟随提示词，其次是首帧或参考视频，否则回退为 16:9。默认：`"adaptive"`。 | COMBO | 是 | `"adaptive"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 生成视频的时长（秒）。默认：5。 | INT | 是 | 3 到 20 |
| `seed` | 种子控制节点是否应重新运行；无论种子为何，结果都是不确定的。默认：42。 | INT | 是 | 0 到 2147483647 |

**约束与行为：**

* 图像总数限制为 10 张，参考图像、首帧和尾帧都计入其中。
* 每张图像必须至少为 300x300 像素，宽高比在 2:5 到 5:2 之间。
* 每个参考视频必须为 3 到 30 秒（使用 `kling-4.0-flash` 时为 3 到 20 秒），分辨率至少 700x700 且不超过 4553x4553 像素，总像素数不超过 8,294,400，宽高比在 2:5 到 5:2 之间，帧率至少 24 fps。所有参考视频合计也不得超过相同的限制。
* 如果提示词中提及 `@ImageN` 或 `@VideoN`，但已连接的该类输入少于 N 个，则会报错。
* 当连接了首帧或尾帧时，节点会添加一条指令，要求视频恰好从该帧开始或在该帧结束。
