使用 Kling 4.0 模型，根据参考图像和参考视频生成带有音频的视频。这些参考素材决定主体、风格和动作，可选的首帧和尾帧则固定片段的开头与结尾。当需要在某个镜头中保持角色或场景一致，同时在提示词中描述动作时，可使用此节点。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 模型选择器。`"kling-4.0"` 支持最高 1080p、30 秒片段以及尾帧；`"kling-4.0-flash"` 限制为 720p 和 20 秒，且没有 `last_frame` 输入。选择模型后，其下方的输入项会相应显示。 | DYNAMIC_COMBO | 是 | `"kling-4.0"`<br />`"kling-4.0-flash"` |

| `duration` | 生成视频的时长，单位为秒。默认：5。 | INT | 是 | 3 到 20 |
| `seed` | 种子决定节点是否应重新运行；无论种子如何，结果都是非确定性的。默认：42。 | INT | 是 | 0 到 2147483647 |

**约束与行为：**

* 图像总数限制为 10 张，包括参考图像、首帧和尾帧。
* 每张图像必须至少为 300x300 像素，宽高比在 2:5 到 5:2 之间。
* 每段参考视频必须为 3 到 30 秒（`kling-4.0-flash` 为 3 到 20 秒），至少 700x700 像素且不超过 4553x4553 像素，总像素数不超过 8,294,400，宽高比在 2:5 到 5:2 之间，帧率至少为 24 fps。所有参考视频合计也不得超过同样的限制。
* 如果提示词中提及 `@ImageN` 或 `@VideoN`，而连接的该类输入少于 N 个，则会引发错误。
* 连接首帧或尾帧时，节点会添加一条指令，要求视频精确地从该帧开始或结束。
