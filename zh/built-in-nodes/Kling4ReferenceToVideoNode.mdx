使用 Kling 4.0 模型，根据参考图像和参考视频生成带音频的视频。参考素材用于驱动主体、风格和运动，可选的首帧和尾帧则固定片段的起始与结束。它适合在描述提示词中的动作时，让角色或场景在整个镜头中保持一致。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 模型选择器。仅有 `"kling-4.0"` 可选；选中后会展开下方列出的输入项。 | DYNAMIC_COMBO | 是 | `"kling-4.0"` |

### kling-4.0 输入

当 `model` 设为 `"kling-4.0"` 时，这些输入项会出现。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可增长槽位，用于放置参考图像，最多 10 张。在提示词中按连接顺序以 `@Image1`、`@Image2` 等方式引用它们。 | AUTOGROW | 否 | 0 到 10 张图像 |
| `reference_videos` | 可增长槽位，用于放置参考视频，最多 5 个。在提示词中以 `@Video1`、`@Video2` 等方式引用它们。每个视频以及所有视频的总时长必须为 3 到 30 秒。 | AUTOGROW | 否 | 0 到 5 个视频 |
| `first_frame` | 可选，视频起始帧。与参考图像一同计入 10 张图像的上限。 | IMAGE | 否 | - |
| `last_frame` | 可选，视频结束帧。与参考图像一同计入 10 张图像的上限。 | IMAGE | 否 | - |
| `prompt` | 对要生成视频的描述。以 `@Image1`、`@Image2` 等方式引用图像输入，以 `@Video1`、`@Video2` 等方式引用视频输入。 | STRING | 是 | 1 到 26000 个字符 |
| `resolution` | 输出视频的分辨率。默认：`"720p"`。 | COMBO | 是 | `"720p"`<br />`"1080p"` |
| `aspect_ratio` | 输出视频的宽高比。`"adaptive"` 会优先遵循提示词，其次是首帧或参考视频，否则回退到 16:9。默认：`"adaptive"`。 | COMBO | 是 | `"adaptive"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `duration` | 生成视频的时长，以秒为单位。默认：5。 | INT | 是 | 3 到 30 |
| `seed` | 种子控制节点是否应重新运行；无论种子如何，结果都是不确定的。默认：42。 | INT | 是 | 0 到 2147483647 |

**约束与行为：**

* 图像总数限制为 10 张，包括参考图像、首帧和尾帧。
* 每张图像必须至少为 300x300 像素，宽高比介于 2:5 与 5:2 之间。
* 每个参考视频时长必须为 3 到 30 秒，至少 700x700 像素、至多 4553x4553 像素，总像素不超过 8,294,400，宽高比介于 2:5 与 5:2 之间，帧率至少为 24 fps。所有参考视频的时长合计不得超过 30 秒。
* 当提示词中提及 `@ImageN` 或 `@VideoN`，而实际连接的该类输入少于 N 个时，会报错。
* 当接入了首帧或尾帧时，节点会添加一条指令，要求视频恰好从该帧开始或在该帧结束。
