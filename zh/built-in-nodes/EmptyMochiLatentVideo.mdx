EmptyMochiLatentVideo 会根据你指定的尺寸创建一个空的潜在视频张量。它会生成一个以零填充的潜在表示，可作为视频生成工作流的起点。此节点允许你定义潜在视频张量的 `width`、`height`、`length` 和 `batch_size`。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `宽度` | 潜在视频的宽度，单位为像素（默认值：848，取值以 16 为步长递增） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 潜在视频的高度，单位为像素（默认值：480，取值以 16 为步长递增） | INT | 是 | 16 to MAX_RESOLUTION |
| `长度` | 潜在视频中的帧数（默认值：25，取值以 6 为步长递增，从 7 开始） | INT | 是 | 7 to MAX_RESOLUTION |
| `批量大小` | 一批中要生成的潜在视频数量（默认值：1） | INT | 否 | 1 到 4096 |

**注意：** 实际的潜在维度按 `width`/8 和 `height`/8 计算，时间维度按 `((length - 1) // 6) + 1` 计算，并且该张量有 12 个通道。由于 `length` 从 7 开始以 6 为步长递增，因此有效值为 7、13、19、25，依此类推。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `samples` | 一个具有指定尺寸、全部为零的空潜在视频张量 | LATENT |
