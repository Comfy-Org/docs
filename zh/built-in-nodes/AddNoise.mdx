此节点使用指定的噪声生成器和 sigma 值向潜空间图像添加受控噪声。它通过模型的采样系统处理输入，根据给定的 sigma 范围应用适当的噪声缩放，并返回添加噪声后的新潜空间表示。此节点目前被标记为实验性。

## 输入
| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 包含采样参数和处理函数的模型 | MODEL | 是 | - |
| `噪波` | 生成基础噪声模式的噪声生成器 | NOISE | 是 | - |
| `Sigmas` | 控制噪声缩放强度的 sigma 值。如果为空，节点将返回未修改的原始潜空间图像。当提供多个 sigma 值时，噪声缩放值将计算为第一个和最后一个 sigma 值之间的绝对差值。当仅提供一个 sigma 值时，该值将直接用作缩放值。 | SIGMAS | 是 | - |
| `Latent` | 将要添加噪声的输入潜空间表示。空的潜空间图像（仅包含零）在处理过程中不会发生偏移。 | LATENT | 是 | - |

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `LATENT` | 添加噪声后的修改潜空间表示。输出中的任何 NaN 或无穷值都会被转换为零，以确保稳定性。 | LATENT |
