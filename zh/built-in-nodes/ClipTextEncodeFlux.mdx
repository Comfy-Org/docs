`CLIPTextEncodeFlux` 是一个专为 Flux 架构设计的文本编码节点。它通过不同的编码器——CLIP-L 和 T5XXL——处理两个独立的文本输入，并将它们与 guidance 缩放系数结合，生成统一的 conditioning 输出，用于图像生成。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 支持 Flux 架构的 CLIP 模型，包含 CLIP-L 和 T5XXL 两个编码器。 | CLIP | 是 | - |
| `clip_l` | 由 CLIP-L 编码器处理的文本输入。适用于简洁的关键词描述，例如风格或主题。支持多行输入和动态提示词。 | STRING | 是 | - |
| `t5xxl` | 由 T5XXL 编码器处理的文本输入。适用于详细的自然语言描述，可表达复杂的场景和细节。支持多行输入和动态提示词。 | STRING | 是 | - |
| `引导` | 控制文本条件对生成过程的影响程度。值越高表示越严格地遵循文本。默认值：3.5。可按 0.1 的增量调整。 | FLOAT | 是 | 0.0 - 100.0 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `CONDITIONING` | 包含来自两个编码器的融合嵌入以及 guidance 参数，用于条件图像生成。 | CONDITIONING |
