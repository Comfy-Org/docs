此节点将图像背景替换为由 Bria 生成的新背景。新背景可以通过文本提示来描述，或由参考图像引导。主体的像素会被保留，同时围绕它们生成背景。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 输入图像，其背景将被替换。 | IMAGE | 是 | |
| `背景` | 使用提示描述新背景，或用参考图像引导它。 | DYNAMIC_COMBO | 是 | `"prompt"`<br />`"reference images"` |
| `原始质量` | 返回输入的精确像素尺寸，而不是将结果缩放到约 1 百万像素。这样大输入会返回大图像。（默认：false） | BOOLEAN | 否 | `true`<br />`false` |
| `种子` | 相同的种子通常返回相同的背景；自动提示优化仍可能使其变化。（默认：42） | INT | 否 | 0 到 2147483647 |
| `内容审核` | 审核设置。（默认："false"） | DYNAMIC_COMBO | 否 | `"false"`<br />`"true"` |

### 提示输入

当 `background` 设置为 `"prompt"` 时显示。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 新背景的描述。诸如 #FF5733 的十六进制颜色代码会生成纯色背景。长度必须至少为 1 个字符。 | STRING | 是 | |
| `mode` | `high_control` 最严格遵循提示，`base` 是平衡的默认值，`fast` 以细节换取速度。 | COMBO | 是 | `"high_control"`<br />`"base"`<br />`"fast"` |
| `refine_prompt` | 重写提示以获得更好的结果，这也会翻译非英语提示。关闭它会按原样发送提示。（默认：true） | BOOLEAN | 否 | `true`<br />`false` |

### 参考图像输入

当 `background` 设置为 `"reference images"` 时显示。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `ref_images` | 可增长插槽：连接 1 到 10 张图像来引导新背景；它们不需要尺寸一致。每个参考都会改变结果，因此少量一致的参考胜过大量相互冲突的参考。批量输入中的每张图像各计一次。 | IMAGE | 是 | 1 到 10 张图像 |
| `enhance_ref_images` | 对参考图像进行额外处理以获得更好的结果。（默认：true） | BOOLEAN | 否 | `true`<br />`false` |

### 审核输入

当 `moderation` 设置为 `"true"` 时显示。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | 启用提示内容审核。（默认：false） | BOOLEAN | 否 | `true`<br />`false` |
| `visual_input_moderation` | 启用视觉输入审核。（默认：false） | BOOLEAN | 否 | `true`<br />`false` |
| `visual_output_moderation` | 启用视觉输出审核。（默认：false） | BOOLEAN | 否 | `true`<br />`false` |

**注意：** `ref_images` 输入最多接受 10 张图像；提供超过 10 张会返回错误。`prompt` 字段必须至少包含 1 个字符。当 `original_quality` 为 false 时，输入图像在处理前会下采样到约 1 百万像素。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 带有新背景的图像。 | IMAGE |
| `refined_prompt` | Bria 据此生成的提示，在参考图像路径下为空。 | STRING |
