Creatify Aurora 2.0 Avatar 可将一张照片与一段语音或歌曲片段转化为说话或演唱视频。视频时长与所连接的音频一致，并保持该音频不变。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 待动画化的人物照片。每边至少 256 像素，宽高比在 1:4 到 4:1 之间；视频会保持照片的宽高比。 | IMAGE | 是 | - |
| `audio` | 驱动口型和视频长度的语音或歌曲。最长 60 秒，在 `"2k"` 下为 14 秒；按已开始的秒数计费。 | AUDIO | 是 | 最长 60 秒 |
| `resolution` | 输出视频的分辨率（默认：`"720p"`）。 | COMBO | 是 | `"480p"`<br />`"720p"`<br />`"1080p"`<br />`"2k"` |
| `text_prompt` | 镜头的场景、机位、灯光、表情或动作。留空则保持照片原样（默认：空字符串）。 | STRING | 是 | 任意文本 |
| `seed` | 种子控制此节点是否重新运行。无论种子如何，结果都是非确定性的（默认：42）。 | INT | 是 | 0 到 2147483647 |

**约束：** 若照片任一边小于 256 像素，或宽高比超出 1:4 到 4:1 的范围，则会报错。超过所选分辨率对应时长上限的音频将被拒绝：通常为 60 秒，在 `"2k"` 下为 14 秒。

## 输出

| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `VIDEO` | 说话或演唱视频，包含所连接的音频。 | VIDEO |
