从输入视频中随机裁剪一段连续的帧。裁剪长度由 `length` 参数控制，起始位置使用随机种子选择。该节点以惰性方式运行，意味着在输出被下游使用之前不会处理整个视频。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|------|------|----------|------|------|
| `视频` | 输入视频。 | VIDEO | 是 | – |
| `保留帧数` | 保留的帧数。（默认值：16） | INT | 是 | 最小值：1，最大值：99999 |
| `随机种子` | 随机种子。（默认值：0） | INT | 是 | 最小值：0，最大值：0xFFFFFFFFFFFFFFFF |

## 输出

| 输出名 | 描述 | 数据类型 |
|--------|------|----------|
| `视频` | 裁剪后的视频（惰性）。 | VIDEO |
