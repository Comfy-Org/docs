Save Text 节点将文本内容写入输出目录中的文件。它支持以 .txt、.csv、.md 或 .json 格式保存，并在提供有效 JSON 时自动进行 JSON 美化打印。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `text` | 要保存到文件的文本内容。此输入必须从另一个节点连接。 | STRING | 是 | - |
| `filename_prefix` | 输出文件名的前缀。会自动附加一个 5 位计数器，以防止覆盖现有文件（默认："ComfyUI"）。 | STRING | 否 | - |
| `format` | 保存文本所用的文件格式（默认："txt"）。选择 "json" 时，有效的 JSON 文本会以 2 个空格缩进进行美化打印；否则，文本将按原样保存。 | COMBO | 否 | `"txt"`<br />`"csv"`<br />`"md"`<br />`"json"` |

### 说明

- `text` 是强制输入，必须连接到另一个节点；无法直接输入。
- 保存的文件命名为 `<filename_prefix>_<5-digit counter>.<extension>`，并写入 ComfyUI 输出目录（位于由前缀派生的子文件夹中）。
- 选择 `"json"` 格式时会尝试将文本解析为 JSON。如果解析成功，内容将以 2 个空格缩进进行美化打印后写入；如果解析失败，则按原样写入原始文本。
- 该节点会将已保存的文件回报给界面，使其与其他生成的输出文件一起显示。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `text` | 保存到文件的原始文本内容 | STRING |
