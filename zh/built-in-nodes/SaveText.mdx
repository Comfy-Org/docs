保存文本节点将文本内容写入输出目录中的文件。它支持保存为 .txt、.csv、.md 或 .json 格式，当选择“json”格式时，有效的 JSON 文本会自动以 2 空格缩进进行美化打印。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `text` | 要保存到文件中的文本内容。此输入必须由另一个节点连接提供。 | STRING | 是 | - |
| `filename_prefix` | 输出文件名的前缀。会附加一个 5 位计数器以防止覆盖现有文件（默认值："ComfyUI"）。 | STRING | 否 | - |
| `format` | 将文本保存为的文件格式（默认值："txt"）。选择 "json" 时，有效的 JSON 文本会以 2 空格缩进进行美化打印；无效的 JSON 和所有其他格式将按原样保存。仅支持列出的选项。 | COMBO | 否 | `"txt"`<br />`"csv"`<br />`"md"`<br />`"json"` |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `text` | 已保存到文件的原始文本内容 | STRING |
