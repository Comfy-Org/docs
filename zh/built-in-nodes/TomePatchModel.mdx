TomePatchModel 会对扩散模型应用 Token Merging (ToMe)，以降低推理过程中的计算开销。其工作方式是在模型的注意力机制内部合并相似的 token，这样模型处理的 token 更少，同时基本保持输出质量不变。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要应用 token 合并的扩散模型 | MODEL | 是 | - |
| `比率` | 要合并的 token 比例（默认：0.3）。更高的值会合并更多 token，这可以带来更大的加速，但可能降低质量。 | FLOAT | 是 | 0.0 - 1.0 |

注意：如果某个注意力块中的 token 数量足够少，无需下采样，则合并函数会被替换为 no-op，模型在该块中保持不变运行。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `model` | 应用了 token 合并后的修改模型 | MODEL |
