此节点为 Hunyuan3Dv2 3D 生成模型创建一批空的（全零）潜空间样本。它会生成形状正确的潜空间张量，作为 3D 生成工作流的起点，并将该潜空间标记为 "hunyuan3dv2" 类型。

## 输入

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `分辨率` | 要创建的潜空间的分辨率维度（默认值：3072） | INT | 是 | 1 - 8192 |
| `批次大小` | 批次中潜空间图像的数量（默认值：1） | INT | 是 | 1 - 4096 |

## 输出

| Output Name | Description | Data Type |
| --- | --- | --- |
| `LATENT` | 形状为 [batch_size, 64, resolution] 的空潜空间张量，包含以零填充的样本，并标记为 "hunyuan3dv2" 类型 | LATENT |
