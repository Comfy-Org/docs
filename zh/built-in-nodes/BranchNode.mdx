Branch 节点按名称选择多个已连接输入中的一个，并将其透传到输出。它如同一个惰性开关：只有被选中的分支会被求值，因此其他分支可以保持未连接，或保留你不想计算其输出的分支。每次新增连接都会添加一个分支输入，输入可通过双击重命名，活动分支由 `branch` 选择器选择。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `autogrow` | 已连接的分支。每次连接都会新增一个分支输入，最多 32 个；所有分支必须使用相同的数据类型，该类型将成为输出类型。 | AUTOGROW | 是 | 1 到 32 个分支 |
| `branch` | 透传到输出的分支名称。选项为已连接分支输入的名称，可通过双击输入对其进行重命名。 | STRING | 是 | 已连接分支的名称 |
| `branch_names` | 已连接分支名称的内部列表，由前端保持同步。它将所选名称映射到其分支，不应当手动编辑。 | ARRAY | 是 | - |

**注意：** 仅请求选中的分支，因此其他分支不会被求值。当所选名称未连接时，该节点会报错。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `output` | 所选分支的值，原样透传。 | MATCH_TYPE |
