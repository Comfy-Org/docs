Generate Text 节点使用 CLIP 模型根据提示词生成文本。与旧版的单附件节点不同，它接受可增长堆叠的图像、视频和音频文件作为额外上下文，因此你可以在一个节点中传入整套参考素材。你可以控制输出长度、是否使用采样，以及是否应用模型自带的聊天模板和思考模式。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 用于对提示词进行分词并生成文本的 CLIP 模型。 | CLIP | 是 | - |
| `prompt` | 引导生成的提示词。支持多行和动态提示词（默认：空字符串）。 | STRING | 是 | - |
| `images` | 可增长图像组，最多 50 张图像，从 `image1` 到 `image50`，用作模型的视觉上下文。 | AUTOGROW | 否 | 0 到 50 张图像 |
| `videos` | 可增长视频输入组，最多 100 个视频输入，从 `video1` 到 `video100`。每个视频是一批帧，假定为 24 FPS，并在内部下采样到 1 FPS。 | AUTOGROW | 否 | 0 到 100 个视频 |
| `audios` | 可增长音频输入组，最多 100 个音频输入，从 `audio1` 到 `audio100`，用作模型的音频上下文。 | AUTOGROW | 否 | 0 到 100 个音频文件 |
| `max_length` | 要生成的最大 token 数量（默认：512）。 | INT | 是 | 1 到 32768 |
| `sampling_mode` | `"on"` 时对输出进行采样，并显示下方的采样参数。`"off"` 时以贪婪方式生成，不使用随机采样。 | DYNAMIC_COMBO | 是 | `"on"`<br />`"off"` |
| `thinking` | 如果模型支持，则以思考模式运行（默认：False）。 | BOOLEAN | 否 | True 或 False |
| `use_default_template` | 如果模型自带系统提示词或聊天模板，则使用内置版本（默认：True）。高级参数。 | BOOLEAN | 否 | True 或 False |
| `mtp` | 使用检查点中的多 token 预测头进行投机解码。没有 MTP 权重时不起作用。`"auto"` 会根据观测到的 token 匹配情况和执行开销自适应调整草稿深度与广度，`"2"` 到 `"5"` 固定一个常量草稿深度，而 `tree` 模式同时固定广度和深度。采样输出保持正确的分布，但对于相同种子会与非 MTP 输出不同（默认：`"auto"`）。 | COMBO | 否 | `"auto"`<br />`"off"`<br />`"2"`<br />`"3"`<br />`"4"`<br />`"5"`<br />`"tree2s1"`<br />`"tree2s2"`<br />`"tree3s1"`<br />`"tree4s1m8"` |
| `system_prompt` | 替换模型聊天模板中的系统提示词。当未使用默认模板时忽略此项。请连接 STRING 输入，而不是在节点中手动输入（默认：空）。 | STRING | 否 | - |

### 采样参数（当 `sampling_mode` 为 `"on"` 时）

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `temperature` | 控制输出的随机性。较低的值使输出更可预测，较高的值使输出更具创造性（默认：0.7）。 | FLOAT | 是 | 0.01 到 2.0 |
| `top_k` | 将采样池限制为最可能的 K 个下一个 token。值为 0 时禁用该过滤（默认：64）。 | INT | 是 | 0 到 1000 |
| `top_p` | 核采样：保留累积概率达到该值的最小最可能 token 集合（默认：0.95）。 | FLOAT | 是 | 0.0 到 1.0 |
| `min_p` | token 要留在采样池中必须达到的最小概率（默认：0.05）。 | FLOAT | 是 | 0.0 到 1.0 |
| `repetition_penalty` | 惩罚已经生成的 token 以减少重复。值为 1.0 时不施加惩罚（默认：1.05）。 | FLOAT | 是 | 0.0 到 5.0 |
| `presence_penalty` | 根据新 token 是否已在当前文本中出现过对其进行惩罚，促使模型转向新话题（默认：0.0）。 | FLOAT | 是 | 0.0 到 5.0 |
| `seed` | 用于初始化随机数生成器以获得可复现结果的数字（默认：0）。 | INT | 是 | 0 到 18446744073709551615 |

**注意：** 上述采样参数仅在 `sampling_mode` 为 `"on"` 时存在。当为 `"off"` 时，节点在不进行随机采样的情况下生成文本，这些参数会被隐藏。

**注意：** 当模型的输出以 `<think>` 开启一个推理块时，节点会将其拆分：`generated_text` 携带答案，`thinking` 携带移除了起始标签的推理内容。否则 `generated_text` 携带模型产生的全部内容，而 `thinking` 为空。被 `max_length` 截断的推理内容会保留在 `generated_text` 中。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `generated_text` | 模型生成的文本，其中任何推理块都会被分离到 `thinking` 输出中。 | STRING |
| `thinking` | 模型产生的推理块，已移除起始 `<think>` 标签。当模型未产生推理块时为空。 | STRING |
