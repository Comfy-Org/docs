SaveGLB 节点将 3D 网格数据或 3D 文件输入保存到输出目录。它接受网格数据和常见 3D 文件格式（GLB、GLTF、OBJ、FBX、STL、USDZ、PLY、SPLAT、SPZ、KSPLAT），并使用指定的文件名前缀将其导出。网格输入会以 GLB 文件形式写入，每个批次项目一个文件；而 3D 文件输入则保留其原始格式进行保存。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `网格` | 要保存的网格或 3D 文件 | MESH 或 FILE3D | 是 | Mesh data<br />GLB<br />GLTF<br />OBJ<br />FBX<br />STL<br />USDZ<br />PLY<br />SPLAT<br />SPZ<br />KSPLAT<br />Any splat format<br />Any point cloud format<br />Any 3D file format |
| `文件名前缀` | 输出文件名的前缀（默认值："3d/ComfyUI"）。前缀可包含子文件夹路径，因此默认情况下文件会保存到输出目录的 "3d" 子文件夹中 | STRING | 否 | - |

注意：当 `mesh` 输入为 3D 文件时，节点使用其原始格式扩展名保存文件（如果文件没有格式，则使用 GLB）。当输入为网格数据时，批次中的每个项目都会保存为单独的 `.glb` 文件；空项目（没有顶点或面）会被跳过并发出警告。输出文件名遵循 `{filename_prefix}_{counter:05}_.{ext}` 模式，带有递增计数器。启用元数据功能时，工作流元数据（提示词和额外 PNG 信息）会嵌入到保存的文件中。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `ui` | 在用户界面中显示已保存的 3D 文件，包含文件名、子文件夹和类型信息 | UI |
