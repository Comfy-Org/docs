Empty Latent Audio 节点会创建一个用于音频处理的空潜空间张量。该节点会生成一个具有指定时长和批次大小的空白音频潜空间表示，可用作音频生成或处理工作流的起点。该节点会根据音频时长和采样率自动计算合适的潜空间维度。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |

| `秒` | 音频时长（以秒为单位）（默认值：47.6） | FLOAT | 是 | 1.0 - 1000.0 |
| `批量大小` | 批次中潜空间图像的数量（默认值：1） | INT | 是 | 1 - 4096 |

| 输出名称 | 描述 | 数据类型 |

| `LATENT` | 返回一个用于音频处理的空潜空间张量，具有指定的时长和批次大小。该张量的形状为 [batch_size, 64, length]，其中 length 由音频时长和采样率计算得出。输出还包含指示类型为 "audio" 的元数据，以及时间维下采样比例 2048。 | LATENT |
