此节点使用 PixVerse V6 模型对输入图像进行动画处理，并返回视频，可选附带原生音轨。输出视频保持输入图像的宽高比。

## 输入

### 通用输入

| 参数 | 说明 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 模型及生成设置。 | DYNAMIC_COMBO | 是 | "PixVerse V6" |
| `图像` | 用于动画处理的输入图像。 | IMAGE | 是 | 单个图像 |

### PixVerse V6 输入

选择“PixVerse V6”模型时会出现以下设置。

| 参数 | 说明 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 视频生成的提示词（默认值：空）。 | STRING | 是 | 1 到 5000 个字符 |
| `quality` | 输出分辨率。设置长边：360p 为 640px，540p 为 1024px，720p 为 1280px，1080p 为 1920px（默认值："720p"）。 | COMBO | 是 | "360p"<br />"540p"<br />"720p"<br />"1080p" |
| `duration_seconds` | 生成视频的长度（秒）（默认值：5）。 | INT | 是 | 1 到 15 |
| `generate_audio` | 随视频一起生成原生音轨（默认值：true）。 | BOOLEAN | 是 | true 或 false |
| `multi_clip` | 让模型将视频切成多个镜头，而不是一个连续的长镜头（默认值：false）。 | BOOLEAN | 是 | true 或 false |
| `seed` | 视频生成的种子。PixVerse 会记录该种子，但不会用它复现生成结果（默认值：42，已启用生成后控制）。 | INT | 是 | 0 到 2147483647 |
| `negative_prompt` | 视频中不希望出现的内容的可选文本描述（默认值：空）。 | STRING | 否 | 最多 2048 个字符 |
| `style` | 应用于整个视频的可选视觉风格（默认值：无）。 | COMBO | 否 | 多个可用选项（PixVerse V6 风格预设） |

注意：提示词必须至少包含一个非空白字符，且最多不超过 5000 个字符；负向提示词如果提供，则最多不超过 2048 个字符。输出视频始终与输入图像的宽高比一致，因此无需设置宽高比。仅接受单个输入图像。当内容审核未通过、提供方账户额度不足，或同时生成的请求数已达上限时，PixVerse 可能会拒绝请求。

## 输出

| 输出名称 | 说明 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 生成的视频；当 `generate_audio` 启用时，包含原生音轨。宽高比与输入图像一致。 | VIDEO |
