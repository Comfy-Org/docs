此节点使用 PixVerse V6 模型为输入图像添加动画，并返回视频，可选带原生音轨。输出视频保持输入图像的宽高比。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要添加动画的输入图像。 | IMAGE | 是 | 单张图像 |
| `模型` | 模型和生成设置。 | DYNAMIC_COMBO | 是 | "PixVerse V6" |

### PixVerse V6 输入

当选择 "PixVerse V6" 模型时，会显示这些设置。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 视频生成的提示词（默认：空）。 | STRING | 是 | 1 到 5000 个字符 |
| `quality` | 输出分辨率。设置长边：360p 为 640px，540p 为 1024px，720p 为 1280px，1080p 为 1920px（默认："720p"）。 | COMBO | 是 | "360p"<br />"540p"<br />"720p"<br />"1080p" |
| `duration_seconds` | 生成视频的长度，以秒为单位（默认：5）。 | INT | 是 | 1 到 15 |
| `generate_audio` | 与视频一起生成原生音轨（默认：true）。 | BOOLEAN | 是 | true 或 false |
| `multi_clip` | 让模型将视频切分为多个镜头，而不是一个连续镜头（默认：false）。 | BOOLEAN | 是 | true 或 false |
| `seed` | 视频生成的种子。PixVerse 会记录它，但不会根据它复现运行（默认：42，生成后控制已启用）。 | INT | 是 | 0 到 2147483647 |
| `negative_prompt` | 视频中不希望出现的元素的可选文本描述（默认：空）。 | STRING | 否 | 最多 2048 个字符 |
| `style` | 应用于整个视频的可选视觉风格（默认：无）。 | COMBO | 否 | 多个可用选项（PixVerse V6 风格预设） |

注意：`prompt` 必须至少包含一个非空白字符且最多 5000 个字符；如果提供 `negative_prompt`，其长度最多为 2048 个字符。输出视频始终与输入图像的宽高比匹配，因此无需设置宽高比。仅接受单张输入图像。当内容审核失败、提供商账户余额不足或同时生成的数量已达到上限时，PixVerse 可能会拒绝请求。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 生成的视频，当启用 `generate_audio` 时包含原生音轨。宽高比与输入图像匹配。 | VIDEO |
