使用 VEED 从视频语音中移除背景噪音。仅音轨发生变化：它被替换为清理后的 48 kHz 单声道语音，而画面、分辨率和帧率保持不变。它适用于任意语言的语音，并且音乐和音效会被移除而非保留。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `video` | 带有语音音轨的视频，时长少于 30 分钟。视频必须包含音轨。 | VIDEO | 是 | 最长 1799 秒 |
| `strength` | 语音下方噪音的移除程度。较低的值会在人声背后保留更多环境音；词间停顿始终会被完全清理，高于默认值的取值变化不大。（默认值：0.874） | FLOAT | 是 | 0.0 到 1.0（步长 0.001） |
| `loudness` | 是否对语音响度进行标准化。`"normalize"` 将其设置为 `target_lufs`；`"keep input level"` 保持原电平不变。选择某个选项后会显示其参数。（默认值：`"normalize"`） | DYNAMIC_COMBO | 是 | `"normalize"`<br />`"keep input level"` |
| `target_lufs` | 清理后语音的综合响度，单位为 LUFS。峰值被限制在 -1.1 dBTP，因此较高的目标值会提前停止（对于典型语音约为 -15 LUFS）。当 `loudness` 为 `"normalize"` 时可用（默认值：-19.0）。 | FLOAT | 是 | -40.0 到 -8.0（步长 0.1） |

当片段长度超过 1799 秒，或视频没有音轨时，该节点会报错停止。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `VIDEO` | 输入视频，其音轨被替换为清理后的语音。 | VIDEO |
