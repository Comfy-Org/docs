使用 HeyGen 的声音朗读文本。此节点将文本和声音 ID 发送至 HeyGen，并将生成的语音以音频形式返回。提供两个模型：`heygen-voice-1` 和速度更快、成本更低的 `heygen-voice-1-turbo`。若要使用通过录音克隆的声音，请使用 HeyGen Voice 1.0 Instant Clone Text to Speech 节点。

选择 `model` 后会显示该模型特有的参数。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的模型。`heygen-voice-1-turbo` 速度更快，成本更低。选择模型后会显示其特有参数：`voice_id`、`text`、`language` 和 `expressiveness_boost`。 | DYNAMIC_COMBO | 是 | `"heygen-voice-1"`<br />`"heygen-voice-1-turbo"` |
| `voice_id` | HeyGen 声音的 ID，例如来自 HeyGen 声音库（默认：空）。 | STRING | 是 | 不适用 |
| `text` | 要朗读的文本。最多 5000 个字符；超过约 12 分钟的语音会失败，因此请拆分非常长的中文或日文文本（默认：空）。 | STRING | 是 | 1 至 5000 个字符 |
| `language` | 文本的语言。对于塞尔维亚语或马来语等自动检测容易混淆的近似语言，请手动设置（默认："auto"）。 | COMBO | 是 | `"auto"`<br />多种语言预设 |
| `expressiveness_boost` | 值越高表现力越强；值越低越接近原始声音（默认：0.5）。 | FLOAT | 是 | 0.0 至 1.0（步长 0.05） |

**注意：** `voice_id` 不能为空；缺失时节点会报错停止。`text` 必须至少包含一个字符。

## 输出

| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `AUDIO` | 根据文本生成的语音，以所选声音朗读。 | AUDIO |
