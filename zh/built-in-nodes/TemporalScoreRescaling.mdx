这个节点对扩散模型应用时间分数重缩放（TSR）。它通过去噪过程中重缩放预测的噪声或分数来修改模型的采样行为，从而可以控制生成输出的多样性。该功能作为 CFG（分类器自由引导）后置函数实现。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要应用 TSR 函数进行补丁（patch）的扩散模型。 | MODEL | 是 | - |
| `TSR_K` | 控制重缩放强度。在图像生成中，较低的 k 会产生更详细的细节，较高的 k 会产生更平滑的结果。设置 k = 1 会禁用重缩放。（默认：0.95） | FLOAT | 是 | 0.01 - 100.0 |
| `tsr_sigma` | 控制重缩放生效的早晚。数值越大，生效越早。（默认：1.0） | FLOAT | 是 | 0.01 - 100.0 |

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `模型` | 输入的模型，现已将其采样过程应用了时间分数重缩放函数。 | MODEL |
