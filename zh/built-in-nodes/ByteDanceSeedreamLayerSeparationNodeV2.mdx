ByteDance Seedream 5.0 Layer Separation 将图像分解为一个背景底板以及最多 16 个可重新定位的透明图层，每个图层都包含堆叠顺序、边界框、名称和描述。它返回背景、带掩码的逐层图像、放置框，以及可直接编辑的图层堆栈。`model` 选择器可在 Seedream 5.0 Pro 和更快的 Seedream 5.0 Flash 之间进行选择。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于分离的 Seedream 模型。"seedream 5.0 pro"（默认）提供最高分离质量，并且还提供 `prompt_optimization` 控制项；"seedream 5.0 flash" 更快、更便宜，且没有提示优化控制项。 | DYNAMIC_COMBO | 是 | "seedream 5.0 pro"<br />"seedream 5.0 flash" |

### Seedream 5.0 Pro 和 5.0 Flash 输入

这些输入在两个模型中都可用。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 要分离的图像。必须恰好一张图像，至少 512x512 像素，宽高比在 1:16 到 16:1 之间。大于约 4MP 的输入在上传前会被缩小。 | IMAGE | 是 | 单张图像 |
| `prompt` | 如何分离图像。留空可自动检测并分离所有主要元素。用自然语言描述元素以控制分离，或使用 `<bbox>left top right bottom</bbox>` 标签定位精确区域（0-1000 千分比坐标）。默认：空字符串。 | STRING | 是 | 多行文本 |
| `size` | 输出分辨率级别。"auto" 跟随输入图像大小（限制在 1K-2K 范围内）。默认："auto"。 | COMBO | 是 | "auto"<br />"1K"<br />"1.5K"<br />"2K" |
| `seed` | 用于生成的种子。默认：42。 | INT | 是 | 0 到 2147483647 |
| `watermark` | 是否在图像上添加 "AI generated" 水印。默认：false。 | BOOLEAN | 是 | false<br />true |
| `crop_layers` | 图层/掩码批次输出的几何形式（`layer_stack` 不受影响，且始终紧贴）。完整画布：每个图层位于基础尺寸画布上其边界框位置——可直接使用 ImageCompositeMasked 重新合成。最小尺寸：每个图层裁剪到其边界框（为批处理填充到最大图层）——张量小得多；使用 `bboxes` 输出通过 Layers From Bounding Boxes 重建放置。默认：false（完整画布）。 | BOOLEAN | 是 | false（完整画布）<br />true（最小尺寸） |

### Seedream 5.0 Pro 专用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt_optimization` | 提示优化模式："standard" 提供更高质量，"fast" 缩短生成时间。仅在 Seedream 5.0 Pro 中可用。默认："standard"。 | COMBO | 是 | "standard"<br />"fast" |

**注意：** 输入 `image` 必须是单张图像；不支持批次。图像必须至少为 512x512 像素，宽高比在 1:16 到 16:1 之间。Seedream 5.0 Flash 没有 `prompt_optimization` 输入。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `base_image` | 图层堆叠到其上的基础图像（背景底板）。 | IMAGE |
| `base_mask` | 基础图像的透明度（1 = 透明，LoadImage 约定）；目前始终完全不透明。 | MASK |
| `layers` | 透明图层，按从下到上排序。完整画布模式：放置在黑色基础尺寸画布上其边界框位置。最小尺寸模式：裁剪到其边界框，左上角锚定，填充到最大图层。 | IMAGE |
| `masks` | 逐层透明度，与 `layers` 批次按索引对齐（1 = 透明，LoadImage 约定）。对于 ImageCompositeMasked 风格的合成，请先添加 InvertMask。 | MASK |
| `bboxes` | 每个图层一个放置框，与 `layers` 批次按索引对齐（将两者以及 `masks` 馈送到 Layers From Bounding Boxes 以重建逐层放置）：`{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`。`content_rect = [left, top, width, height]` 是图层自身框架内的内容区域；它会落在画布上框位置加上该偏移处。 | BOUNDING_BOX |
| `layer_stack` | 用于 Create Layered Image 的可直接编辑图层文档：基础底板加上每个元素作为其自己命名的、紧密裁剪的图层，位于真实位置并保持堆叠顺序。可直接连接，或使用 Add Layer 扩展。 | LAYERS |
