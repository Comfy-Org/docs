此节点使用变分自编码器（VAE）将音频潜空间表示转换回可播放的音频波形。它接收编码后的样本，通过所选的 VAE 对其进行解码，然后对生成的波形进行归一化处理，使整体音量水平保持一致。输出的音频使用 VAE 的音频采样率（默认为 44100 Hz），如果输入样本中存储了采样率，则使用该采样率。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `Latent` | 潜空间中已编码的音频样本，将被解码回音频波形。如果这些样本自带采样率，则输出将使用该值。 | LATENT | 是 | - |
| `vae` | 用于将潜空间样本解码为音频的变分自编码器模型。当输入样本未指定采样率时，其音频输出采样率（默认 44100 Hz）决定生成波形的采样率。 | VAE | 是 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `AUDIO` | 解码后的音频波形，音量已归一化，随其采样率一同返回（如果输入 `samples` 中包含采样率，则使用该采样率；否则使用 VAE 的音频采样率，默认为 44100 Hz）。 | AUDIO |
