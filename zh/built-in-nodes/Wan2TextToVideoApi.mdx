此节点使用 Wan 2.7 模型根据文本描述生成视频。它会将您的提示词发送到 Wan 视频生成 API，等待任务完成后返回生成的视频。您可以选择连接音频片段来影响视频的运动和时序；如果未提供音频，模型会自动生成匹配的音频。

## 输入
### 通用输入

以下输入始终在节点的顶层可用。

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频生成的特定模型。 | DYNAMIC_COMBO | 是 | `"wan2.7-t2v"` |
| `audio` | 用于驱动视频生成的音频（例如，唇形同步、节拍匹配的动作）。时长：3秒-30秒。如果未提供，模型会自动生成匹配的背景音乐或音效。 | AUDIO | No | - |
| `seed` | 用于生成的种子（默认：0）。 | INT | 是 | 0 到 2147483647 |
| `prompt_extend` | 是否使用 AI 辅助增强提示词（默认：True）。 | BOOLEAN | 是 | True<br />False |
| `watermark` | 是否在结果中添加 AI 生成的水印（默认：False）。 | BOOLEAN | 是 | True<br />False |

### wan2.7-t2v 输入

当选择 `wan2.7-t2v` 模型时，将显示以下设置。

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述元素和视觉特征的提示词。支持英文和中文。 | STRING | 是 | - |
| `negative_prompt` | 描述需要避免的内容的负面提示词。默认为空字符串。 | STRING | No | - |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | `"720P"`<br />`"1080P"` |
| `ratio` | 输出视频的宽高比。 | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 视频的时长（秒）（默认：5）。 | INT | 是 | 2 到 15 |

**注意：** `prompt` 输入不能为空。`audio` 输入是可选的；如果提供，节点接受 1.5 到 60 秒之间的音频，尽管工具提示建议 3 秒到 30 秒。如果未提供音频，模型会自动生成匹配的音频。当 `negative_prompt` 留空时，不会发送到 API。`prompt_extend` 和 `watermark` 是高级选项。

## 输出
| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `output` | 生成的视频文件。 | VIDEO |
