RelayVSR Conditioning 为 RelayVSR 视频放大准备条件数据和空 latent。RelayVSR 仅对视频片段中每第 15 帧以及最后一帧运行其单步 Wan 2.2 模型，因此它返回的 latent 只包含这些关键帧。VSR Decode 随后会补全它们之间的帧。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | RelayVSR 扩散模型，通过 Load Model 加载：`relayvsr_x2_lightx2v_int8_convrot.safetensors` 或 `relayvsr_x4_int8_convrot.safetensors`。 | MODEL | 是 | N/A |
| `images` | 原始分辨率的低质量视频。模型的上采样倍率决定最终结果的尺寸。 | IMAGE | 是 | N/A |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 携带所选关键帧作为低质量引导的条件。 | CONDITIONING |
| `latent` | 空 latent，每个关键帧一帧，可直接供采样器使用。 | LATENT |

## 使用

以 CFG 1、一步对 `latent` 进行采样：图中没有提示词，也没有文本编码器。将采样器的输出、同一组 `images` 以及 RelayVSR Flash VAE 送入 VSR Decode，并保持配对一致：x2 模型搭配 x2 解码器，x4 模型搭配 x4 解码器。

仅对关键帧进行采样，因此一段 150 帧的视频片段会变成 11 帧的 latent。采样器只处理视频的一小部分，VSR Decode 会恢复其余部分。
