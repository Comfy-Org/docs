将 SenseNova Conditioning 留下的交错历史转换为可用的文本、图像和思考内容。请在循环结束时运行此节点，并禁用 End Loop 的 accumulate，以便一次性收集模型产出的全部内容。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 用于解码已生成 token 的 SenseNova CLIP 模型。 | CLIP | 是 | - |
| `conditioning` | 来自 SenseNova Conditioning 的交错条件。 | CONDITIONING | 是 | - |
| `samples` | 最后一个 KSampler 像素潜空间，当循环以图像请求结束时需要提供。 | LATENT | 否 | - |

**约束与行为：**

* 该条件必须来自 SenseNova Conditioning 的 `interleave` 或 `self-correction` 任务；其他来源会引发错误。
* 当模型正在等待图像时，将采样器的 LATENT 输出连接到 `samples`。
* 运行开始时连接的参考图像不会包含在输出中；当没有生成任何图像时，图像使用方会被跳过。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `text` | 从交错历史中解码出的文本，其中的图像标记会被替换为空行。 | STRING |
| `images` | 模型在本次运行期间生成的图像。 | IMAGE |
| `thinking` | 模型的推理文本（当模型产生了推理内容时）。 | STRING |
