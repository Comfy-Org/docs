LTXVCropGuides 节点用于从视频生成工作流中移除关键帧引导数据。它会统计正向条件中记录的关键帧数量，从潜空间样本和噪声遮罩的末尾裁剪掉相应数量的帧，并清除两个条件输入中的关键帧索引和引导注意力条目。当未找到关键帧时，条件输入将原样返回，潜空间则通过克隆的样本张量及其噪声遮罩直接传递。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `正向` | 正向条件输入，包含用于生成的引导信息。其持有的关键帧数量决定了从潜空间中裁剪多少帧。 | CONDITIONING | 是 | - |
| `负向` | 负向条件输入，包含用于生成中应避免内容的引导信息。其关键帧数据会与正向条件一起被清除。 | CONDITIONING | 是 | - |
| `潜在空间` | 潜空间表示，包含图像样本和噪声遮罩数据。当存在关键帧时，末尾的关键帧会从样本和噪声遮罩中一并移除。 | LATENT | 是 | - |

注意：仅当在正向条件中检测到关键帧索引时才会执行裁剪。如果未检测到关键帧，正向和负向条件将原样返回，而潜空间仍会以克隆的样本张量和显式噪声遮罩返回（如果输入潜空间没有噪声遮罩，则会创建一个全为 1 的遮罩）。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 已处理的正向条件，其中的关键帧索引和引导注意力条目已被清除 | CONDITIONING |
| `negative` | 已处理的负向条件，其中的关键帧索引和引导注意力条目已被清除 | CONDITIONING |
| `latent` | 已裁剪的潜空间表示，其样本和噪声遮罩已调整，关键帧部分已被移除 | LATENT |
