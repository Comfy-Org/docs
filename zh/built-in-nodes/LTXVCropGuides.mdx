LTXVCropGuides 节点通过移除关键帧信息并调整潜在维度，来处理用于视频生成的条件输入和潜在输入。它会裁剪潜在图像和噪声掩码，以排除关键帧部分，同时从正向和负向条件输入中清除关键帧索引及引导注意力条目。这为无需关键帧引导的视频生成工作流准备好数据。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `正向` | 包含生成引导信息的正向条件输入。其关键帧索引决定了从潜在表示中裁剪多少帧。 | CONDITIONING | 是 | - |
| `负向` | 包含生成时需要避免的内容的负向条件输入。其关键帧数据会与正向条件一同被清除。 | CONDITIONING | 是 | - |
| `潜在空间` | 包含图像样本和噪声掩码数据的潜在表示。当正向条件中存在关键帧时，最后一组关键帧帧会从样本和噪声掩码中移除。 | LATENT | 是 | - |

注意：仅当正向条件包含关键帧索引时才会进行裁剪。如果未检测到关键帧，正向条件、负向条件以及潜在表示将原样通过。

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `正向` | 已处理的正向条件，其中的关键帧索引和引导注意力条目已被清除 | CONDITIONING |
| `负向` | 已处理的负向条件，其中的关键帧索引和引导注意力条目已被清除 | CONDITIONING |
| `潜在空间` | 裁剪后的潜在表示，其样本和噪声掩码已调整，移除了关键帧部分 | LATENT |
