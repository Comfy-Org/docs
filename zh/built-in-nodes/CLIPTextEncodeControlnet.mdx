CLIP Text Encode (Controlnet) 节点使用 CLIP 模型对文本提示进行编码，并将生成的文本编码添加到现有的条件数据中。它将文本嵌入作为 controlnet 交叉注意力参数存储在每个条件条目内，因此返回的条件数据会携带该额外的 controlnet 信息。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 用于文本分词和编码的 CLIP 模型 | CLIP | 是 | - |
| `条件` | 要与 CLIP 文本编码组合的现有条件数据 | CONDITIONING | 是 | - |
| `文本` | 由 CLIP 模型处理的文本提示。支持多行文本和动态提示 | STRING | 是 | - |

**注意：** 所有三个输入（`clip`、`conditioning` 和 `text`）都是此节点运行所必需的。`text` 输入支持多行文本和动态提示，以实现灵活的文本处理。此节点在源代码中被标记为实验性。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `CONDITIONING` | 增强的条件数据，包含从 CLIP 文本编码派生的新增 controlnet 交叉注意力参数（`cross_attn_controlnet` 和 `pooled_output_controlnet`） | CONDITIONING |
