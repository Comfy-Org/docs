CLIPTextEncodeControlnet 节点使用 CLIP 模型处理文本提示，并将生成的文本编码与现有的条件数据（conditioning）相结合。它将从文本派生的嵌入作为 controlnet 交叉注意力参数添加到每个条件数据条目中，从而为 controlnet 应用生成增强的条件数据输出。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 用于文本分词和编码的 CLIP 模型 | CLIP | 是 | - |
| `条件` | 要与 CLIP 文本编码组合的现有条件数据 | CONDITIONING | 是 | - |
| `文本` | 要由 CLIP 模型处理的文本提示。支持多行文本和动态提示 | STRING | 是 | - |

**注意：** 此节点正常运行需要所有三个输入（`clip`、`conditioning` 和 `text`）。`text` 输入支持多行文本和动态提示，以实现灵活的文本处理。此节点在源代码中标记为实验性。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `CONDITIONING` | 增强的条件数据，其中包含从 CLIP 文本编码派生的 controlnet 交叉注意力参数（`cross_attn_controlnet` 和 `pooled_output_controlnet`） | CONDITIONING |
