此节点使用 VAE 的结构解码器，将 Trellis 结构潜在样本转换为 3D 体素网格。它仅读取潜在变量的前 8 个通道，重建体素占用情况，并按要求将输出分辨率调整为 32 或 64。

## 输入
| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `样本` | 待解码结构的潜在表示。解码时仅使用潜在变量的前 8 个通道。 | LATENT | 是 | - |
| `vae` | 其结构解码器将潜在变量转换为体素网格的 VAE。解码按批次执行。 | VAE | 是 | - |
| `分辨率` | 输出体素网格的目标空间分辨率（默认："32"）。如果解码后的网格分辨率不同，则进行下采样以匹配。 | COMBO | 是 | "32"<br />"64" |

注意：当解码后的体素网格分辨率与所选 `resolution` 不同时，将使用 3D 最大池化将该网格下采样到请求的大小。

## 输出
| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `体素` | 一个二值体素占用网格，以形状为 [batch, depth, height, width] 的浮点张量表示。占用体素的值为 1.0，空体素的值为 0.0。 | VOXEL |
