使用 Kling 4.0 模型从一组关键帧生成带音频的视频。首帧、最多八个中间帧和末帧会按顺序发送，中间帧在片段中均匀分布，输出采用第一个关键帧的宽高比。可用于为单张图像制作动画，或通过一系列关键时刻引导镜头走向。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 模型选择器。仅 `"kling-4.0"` 可用；选择后会显示下方输入。 | DYNAMIC_COMBO | 是 | `"kling-4.0"` |

### kling-4.0 输入

当 `model` 设为 `"kling-4.0"` 时会出现这些输入。至少需要连接一个帧输入。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 可选，视频起始的帧。 | IMAGE | 否 | - |
| `middle_frames` | 可选的可增长槽位，用于首帧与末帧之间的帧，最多 8 个。它们在整个片段中均匀分布。 | AUTOGROW | 否 | 0 到 8 张图像 |
| `last_frame` | 可选，视频结束的帧。 | IMAGE | 否 | - |
| `prompt` | 可选，对运动的描述。请按首帧、中间帧、末帧的顺序，将连接的帧称为 `@Image1`、`@Image2` 等。默认：空字符串。 | STRING | 是 | 多行文本 |
| `resolution` | 输出视频的分辨率。默认：`"720p"`。 | COMBO | 是 | `"720p"`<br />`"1080p"` |
| `duration` | 生成视频的长度（秒）。默认：5。 | INT | 是 | 3 到 30 |
| `seed` | 种子控制节点是否重新运行；无论种子如何，结果都是非确定性的。默认：42。 | INT | 是 | 0 到 2147483647 |

**约束与行为：**

* 计算首帧、每个中间帧和末帧在内，总共最多可连接 10 帧。
* 视频采用第一个关键帧的宽高比，因此无需宽高比输入。
* 每一帧必须至少为 300x300 像素，宽高比介于 2:5 和 5:2 之间。
* 当连接的帧数少于 N 时，提及 `@ImageN` 的提示词会引发错误。

|-------------|-------------|-----------|
| `video` | 生成的视频，任务完成后从提供方下载。 | VIDEO |
