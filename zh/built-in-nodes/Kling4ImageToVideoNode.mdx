使用 Kling 4.0 模型从一组关键帧生成带音频的视频。首帧、最多八个中间帧和末帧会按顺序发送，中间帧会在片段中均匀分布，输出采用首个关键帧的宽高比。可用于为单张图像制作动画，或通过一系列关键瞬间来引导镜头。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 模型选择器。`"kling-4.0"` 支持最高 1080p 和 30 秒；`"kling-4.0-flash"` 仅限 720p、20 秒和单个首帧。选择模型后会在下方显示其对应的输入项。 | DYNAMIC_COMBO | 是 | `"kling-4.0"`<br />`"kling-4.0-flash"` |

### kling-4.0 输入

当 `model` 设置为 `"kling-4.0"` 时显示这些输入项。至少需要连接一个帧输入。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 视频起始的可选帧。 | IMAGE | 否 | - |
| `middle_frames` | 位于首帧和末帧之间的可选可扩展槽位，最多 8 个。它们会在片段中均匀分布。 | AUTOGROW | 否 | 0 到 8 张图像 |
| `last_frame` | 视频结束的可选帧。 | IMAGE | 否 | - |
| `prompt` | 对动作的可选描述。请按照首帧、中间帧、末帧的顺序，以 `@Image1`、`@Image2` 等引用所连接的帧。默认：空字符串。 | STRING | 是 | 多行文本 |
| `resolution` | 输出视频的分辨率。默认：`"720p"`。 | COMBO | 是 | `"720p"`<br />`"1080p"` |
| `duration` | 生成视频的时长，单位为秒。默认：5。 | INT | 是 | 3 到 30 |
| `seed` | 种子用于控制节点是否应重新运行；无论种子为何，结果都是非确定性的。默认：42。 | INT | 是 | 0 到 2147483647 |

### kling-4.0-flash 输入

当 `model` 设置为 `"kling-4.0-flash"` 时显示这些输入项。Flash 会为单个首帧制作动画。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 视频起始的帧。 | IMAGE | 是 | - |
| `prompt` | 对动作的可选描述。请以 `@Image1` 引用首帧。默认：空字符串。 | STRING | 是 | 多行文本 |
| `resolution` | 输出视频的分辨率。Flash 仅渲染 720p。默认：`"720p"`。 | COMBO | 是 | `"720p"` |
| `duration` | 生成视频的时长，单位为秒。默认：5。 | INT | 是 | 3 到 20 |
| `seed` | 种子用于控制节点是否应重新运行；无论种子为何，结果都是非确定性的。默认：42。 | INT | 是 | 0 到 2147483647 |

**约束与行为：**

* 总共最多可连接 10 帧，计入首帧、每个中间帧和末帧。
* 视频采用首个关键帧的宽高比，因此无需宽高比输入。
* 每一帧必须至少为 300x300 像素，且宽高比介于 2:5 和 5:2 之间。
* 当提示词中提及 `@ImageN` 而连接的帧数少于 N 时，会引发错误。
