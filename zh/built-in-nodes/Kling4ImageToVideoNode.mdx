使用 Kling 4.0 模型从一组关键帧生成带音频的视频。首帧、最多八个中间帧和尾帧按顺序传入，中间帧在片段中均匀分布，输出的宽高比取自首个关键帧。可用它将单张图像制作成动画，或通过一系列关键时刻引导镜头运动。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 模型选择器。`"kling-4.0"` 支持最高 4K HDR 和 30 秒；`"kling-4.0-flash"` 限制为 720p、20 秒且仅支持单个首帧。选择模型后会在下方显示其对应的输入。 | DYNAMIC_COMBO | 是 | `"kling-4.0"`<br />`"kling-4.0-flash"` |

### kling-4.0 输入

当 `model` 设置为 `"kling-4.0"` 时显示这些输入。至少需要连接一个帧输入。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 视频起始的可选帧。 | IMAGE | 否 | - |
| `middle_frames` | 首帧与尾帧之间帧的可选可扩展槽位，最多 8 个。它们在片段中均匀分布。 | AUTOGROW | 否 | 0 到 8 张图像 |
| `last_frame` | 视频结束的可选帧。 | IMAGE | 否 | - |
| `prompt` | 对运动的可选描述。按首帧、中间帧、尾帧的顺序，以 `@Image1`、`@Image2` 等引用所连接的帧。默认：空字符串。 | STRING | 是 | 多行文本 |
| `resolution` | 输出视频的分辨率；名称中包含 `HDR` 的选项会返回 HDR 视频。默认：`"720p"`。 | COMBO | 是 | `"720p"`<br />`"1080p"`<br />`"4k"`<br />`"1080p HDR"`<br />`"4k HDR"` |
| `duration` | 生成视频的长度，单位为秒。默认：5。 | INT | 是 | 3 到 30 |
| `seed` | 种子控制节点是否应重新运行；无论种子如何，结果都是不确定的。默认：42。 | INT | 是 | 0 到 2147483647 |

### kling-4.0-flash 输入

当 `model` 设置为 `"kling-4.0-flash"` 时显示这些输入。Flash 仅对单个首帧制作动画。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 视频起始帧。 | IMAGE | 是 | - |
| `prompt` | 对运动的可选描述。以 `@Image1` 引用首帧。默认：空字符串。 | STRING | 是 | 多行文本 |
| `resolution` | 输出视频的分辨率。Flash 仅渲染 720p。默认：`"720p"`。 | COMBO | 是 | `"720p"` |
| `duration` | 生成视频的长度，单位为秒。默认：5。 | INT | 是 | 3 到 20 |
| `seed` | 种子控制节点是否应重新运行；无论种子如何，结果都是不确定的。默认：42。 | INT | 是 | 0 到 2147483647 |

**约束与行为：**

* 最多可连接 10 帧，包括首帧、每个中间帧和尾帧。
* 视频的宽高比取自首个关键帧，因此无需宽高比输入。
* 每个帧必须至少为 300x300 像素，宽高比在 2:5 到 5:2 之间。
* 如果提示中提及 `@ImageN`，而连接的帧数少于 N，则会引发错误。
