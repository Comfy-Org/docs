`CLIPTextEncodeHunyuanDiT` 节点将文本描述转换为 HunyuanDiT 模型能够理解的格式。它是一个为 HunyuanDiT 双文本编码器架构设计的高级 conditioning 节点，通过不同的分词器处理两个独立的文本输入，并将其结果组合为单个 conditioning 输出。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 用于文本分词和编码的 CLIP 模型实例，是生成 condition 的核心。 | CLIP | 是 | - |
| `bert` | 通过 BERT 分词器进行编码的文本输入。建议使用短语和关键词。支持多行和动态提示。 | STRING | 是 | - |
| `mt5xl` | 通过 mT5-XL 分词器进行编码的文本输入。支持多行和动态提示（多语言）。可以使用完整句子和复杂描述。 | STRING | 是 | - |
