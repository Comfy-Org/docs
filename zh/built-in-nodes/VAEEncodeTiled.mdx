VAEEncodeTiled 通过将图像分解为较小的图块并使用变分自编码器对其进行编码来处理图像。这种分块处理方法可以处理可能超出内存限制的大尺寸图像。该节点同时支持图像和视频 VAE，并为空间和时间维度提供独立的分块控制。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `像素` | 要编码的输入图像数据 | IMAGE | 是 | - |
| `vae` | 用于编码的变分自编码器模型 | VAE | 是 | - |
| `分块尺寸` | 空间处理的每个图块的大小（默认值：512） | INT | 是 | 64-4096（步长：64） |
| `重叠` | 相邻图块之间的重叠量（默认值：64） | INT | 是 | 0-4096（步长：32） |
| `时间尺寸` | 仅用于视频 VAE：每次编码的帧数（默认值：64） | INT | 是 | 8-4096（步长：4） |
| `时间重叠` | 仅用于视频 VAE：重叠的帧数（默认值：8） | INT | 是 | 4-4096（步长：4） |

**注意：** `temporal_size` 和 `temporal_overlap` 参数仅在视频 VAE 下相关，对标准图像 VAE 没有影响。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `LATENT` | 输入图像的编码后潜在表示 | LATENT |
