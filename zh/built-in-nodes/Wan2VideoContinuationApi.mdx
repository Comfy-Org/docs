Wan 2.7 视频续接节点用于生成一段新视频，该视频从输入视频片段的结尾处继续延伸。它使用 Wan 2.7 模型根据文本提示词合成续接内容，并可选地将结尾引导至特定的目标帧。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的视频生成模型。 | DYNAMIC_COMBO | 是 | `"wan2.7-i2v"` |
| `first_clip` | 用于续接的输入视频。时长：2 秒至 10 秒。输出宽高比从此视频派生。 | VIDEO | 是 | 2秒至10秒 |
| `last_frame` | 最后一帧图像。生成的续接画面将向此帧过渡。 | IMAGE | 否 | - |
| `seed` | 用于生成的随机种子。（默认值：0） | INT | 是 | 0 到 2147483647 |
| `prompt_extend` | 是否使用 AI 辅助增强提示词。（默认值：True） | BOOLEAN | 是 | - |
| `watermark` | 是否在结果中添加 AI 生成的水印。（默认值：False） | BOOLEAN | 是 | - |

### wan2.7-i2v 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述元素和视觉特征的提示词。支持英文和中文。（默认值：空字符串） | STRING | 是 | - |
| `negative_prompt` | 描述需要避免内容的负面提示词。（默认值：空字符串） | STRING | 是 | - |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | `"720P"`<br />`"1080P"` |
| `duration` | 输出视频的总时长（秒）。模型会生成续接画面，以填充输入片段之后的剩余时间。（默认值：5） | INT | 是 | 2 到 15 |

**注意：**`first_clip` 输入视频的时长必须在 2 到 10 秒之间。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 生成的视频续接内容。 | VIDEO |
