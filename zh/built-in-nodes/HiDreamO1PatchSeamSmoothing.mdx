此节点通过在采样过程的后期对模型在多个偏移的 patch 网格位置上的输出进行平均，来减少 HiDream-O1 模型生成图像中可见的接缝。它的工作原理是多次运行模型，每次使用略微不同的图像对齐方式，并将结果混合在一起，这有助于消除可能出现在 patch 边界处的网格状伪影。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要应用接缝平滑的 HiDream-O1 模型。 | MODEL | 是 | - |
| `起始百分比` | 采样进度（0=开始，1=结束），在该进度下平滑效果开启（默认：0.8）。 | FLOAT | 是 | 0.0 到 1.0 (step: 0.01) |
| `结束百分比` | 采样进度，在该进度下平滑效果关闭（默认：1.0）。 | FLOAT | 是 | 0.0 到 1.0 (step: 0.01) |
| `模式` | 偏移网格位置的布局。`single_shift`：一次在自然 patch 网格上，其余各次偏移。`symmetric`：所有 pass 都在网格外，偏移围绕原点对称分布（默认：`"single_shift"`）。 | COMBO | 是 | `"single_shift"`<br />`"symmetric"` |
| `遍数` | 每个门控步骤的 pass 次数（即模型运行次数）。`2` 和 `4` 是固定次数。`ramp_2_4` 和 `ramp_2_4_8` 在采样接近结束时增加 pass 次数，在接缝最明显的地方提供更多平滑（默认：`"2"`）。 | COMBO | 是 | `"2"`<br />`"4"`<br />`"ramp_2_4"`<br />`"ramp_2_4_8"` |
| `混合方式` | 用于合并每次 pass 结果的方法。`average`：所有 pass 的等权平均。`window`：使用 Hann 窗口为每次 pass 的中心赋予更大权重，减少边界伪影。`median`：取逐像素中位数，可以剔除因环绕（wraparound）导致的异常 pass（默认：`"average"`）。 | COMBO | 是 | `"average"`<br />`"window"`<br />`"median"` |
| `强度` | 控制原始模型输出（0.0）与完全平滑结果（1.0）之间的插值（默认：1.0）。 | FLOAT | 是 | 0.0 到 1.0 (step: 0.01) |

**参数约束说明：**
- 如果 `strength` 小于或等于 0.0，或者 `end_percent` 小于或等于 `start_percent`，则不会应用平滑效果。在这些情况下，节点将原样返回模型。
- `passes` 参数的 ramp 选项（`ramp_2_4`、`ramp_2_4_8`）仅在 `start_percent` 和 `end_percent` 定义了一个范围时才有意义，因为随着采样在该范围内推进，pass 次数会增加。
