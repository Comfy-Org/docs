此节点通过在采样过程的后段，对模型在多个偏移后的 patch 网格位置上的输出进行平均，来减少 HiDream-O1 模型生成图像中的可见接缝。它会在图像对齐方式略有差异的情况下多次运行模型，并将结果混合在一起，从而有助于抵消可能出现在 patch 边界处的网格状伪影。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 取值范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要应用接缝平滑的模型。 | MODEL | 是 | - |
| `起始百分比` | 混合开启时的采样进度（0=开始，1=结束）。默认值：0.8 | FLOAT | 是 | 0.0 到 1.0 （步长：0.01） |
| `结束百分比` | 混合关闭时的采样进度。默认值：1.0 | FLOAT | 是 | 0.0 到 1.0 （步长：0.01） |
| `模式` | 偏移布局。`single_shift`：一次按自然 patch 网格进行，其余按偏移进行。`symmetric`：所有 pass 均偏离网格，偏移围绕原点对称分布。默认值："single_shift" | COMBO | 是 | `"single_shift"`<br />`"symmetric"` |
| `遍数` | 每个受门控步骤的 pass 数量。`2`/`4` = 固定值。`ramp_*`：随着采样接近结束，pass 数量逐渐增加（在接缝最明显的地方进行更强的平滑）。默认值："2" | COMBO | 是 | `"2"`<br />`"4"`<br />`"ramp_2_4"`<br />`"ramp_2_4_8"` |
| `混合方式` | `average`：等权平均值。`window`：Hann 窗加权，使每个 pass 在远离其 patch 边界处获得更高权重。`median`：逐像素中位数，可排除产生环绕异常的 pass。默认值："average" | COMBO | 是 | `"average"`<br />`"window"`<br />`"median"` |
| `强度` | 在自然网格预测结果（0）与平均结果（1）之间进行插值。默认值：1.0 | FLOAT | 是 | 0.0 到 1.0 （步长：0.01） |

**参数约束说明：**
- 如果 `strength` 为 0.0 或更低，或者 `end_percent` 小于或等于 `start_percent`，则不会应用平滑效果。在这些情况下，节点会原样返回该模型。
- `passes` 参数的 ramp 选项（`ramp_2_4`、`ramp_2_4_8`）仅在 `end_percent` 大于 `start_percent` 时才有意义，因为随着采样在该区间内推进，pass 数量会逐渐增加。
