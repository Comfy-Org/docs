此节点为 LTXV-AV 模型创建引导采样对象（CFG guider）。它对打包的 LTXV-AV latent 的视频部分和音频部分分别应用不同的引导系数，让你可以独立控制条件对每种模态的影响。如果两个系数相等，或者 latent 不包含分离的视频和音频组件，则改为使用一个统一的总体系数。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 采样时要使用的模型。 | MODEL | 是 | - |
| `positive` | 正向条件，引导生成朝向其方向。 | CONDITIONING | 是 | - |
| `negative` | 负向条件，引导生成远离其方向。 | CONDITIONING | 是 | - |
| `video_cfg` | 应用于 latent 视频模态的引导强度（默认值：3.0）。 | FLOAT | 是 | 0.0 到 100.0 |
| `audio_cfg` | 应用于 latent 音频模态的引导强度（默认值：7.0）。 | FLOAT | 是 | 0.0 到 100.0 |

注意：当 `video_cfg` 和 `audio_cfg` 相等（或数值非常接近）时，guider 会将该值用作整个 latent 的单一 CFG 系数。如果 latent 不是打包的 LTXV-AV latent，则只使用 `video_cfg` 的值。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `guider` | 配置好的 CFG guider，可传递给采样器节点。 | GUIDER |
