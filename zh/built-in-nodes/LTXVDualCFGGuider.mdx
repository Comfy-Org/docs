此节点为 LTXV-AV 模型创建一个引导采样对象（CFG 引导器）。它对打包后的潜在变量中的视频部分和音频部分分别应用不同的引导强度，让您能够独立控制每种模态上条件的影响。如果两个强度相等，或潜在变量不包含独立的视频和音频组件，则使用单个整体强度。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 取值范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 采样时要使用的模型。 | MODEL | 是 | - |
| `positive` | 用于引导生成朝向的正向条件。 | CONDITIONING | 是 | - |
| `negative` | 用于引导生成远离的负向条件。 | CONDITIONING | 是 | - |
| `video_cfg` | 应用于潜在变量视频模态的引导强度（默认：3.0）。 | FLOAT | 是 | 0.0 至 100.0 |
| `audio_cfg` | 应用于潜在变量音频模态的引导强度（默认：7.0）。 | FLOAT | 是 | 0.0 至 100.0 |

注意：当 `video_cfg` 和 `audio_cfg` 相等或非常接近时，引导器会将该值作为整个潜在变量的单一 CFG 强度使用。如果潜在变量不是打包的 LTXV-AV 潜在变量，则仅使用 `video_cfg` 的值。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `guider` | 配置好的 CFG 引导器，用于传递给采样器节点。 | GUIDER |
