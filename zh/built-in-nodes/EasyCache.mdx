EasyCache 节点为扩散模型添加了原生缓存系统，通过复用先前计算步骤的结果来加速采样，而不是重新计算每一步。它仅在采样过程中可配置的起始点和结束点之间激活，并在估计输出变化低于用户定义阈值时跳过步骤。这是一个实验性节点，用于高级调试。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要添加 EasyCache 的模型。 | MODEL | 是 | - |
| `重用阈值` | 复用缓存步骤的阈值（默认值：0.2）。 | FLOAT | 是 | 0.0 - 3.0 |
| `开始位置` | 开始使用 EasyCache 的相对采样步骤（默认值：0.15）。 | FLOAT | 是 | 0.0 - 1.0 |
| `结束位置` | 结束使用 EasyCache 的相对采样步骤（默认值：0.95）。 | FLOAT | 是 | 0.0 - 1.0 |
| `调试信息` | 是否记录详细日志信息（默认值：False）。 | BOOLEAN | 是 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `model` | 添加了 EasyCache 功能的模型。 | MODEL |
