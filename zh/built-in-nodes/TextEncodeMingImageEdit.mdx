Text Encode Ming Image Edit 将文本提示词编码为用于 Ming 图像编辑的 CONDITIONING，并可选择混入参考图像。提示词和参考图像由 CLIP 模型进行分词；当连接 VAE 时，参考图像还会被编码为追加到 CONDITIONING 的 latent 帧。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 用于对提示词和参考图像进行分词的 CLIP 模型。 | CLIP | 是 | - |
| `vae` | 可选 VAE，用于将参考图像编码为追加到 CONDITIONING 的 latent 帧。没有 VAE 时，图像仅通过视觉塔（vision tower）对文本编码器进行条件化。 | VAE | 否 | - |
| `prompt` | 要编码的文本提示词。支持多行输入和动态提示词。 | STRING | 是 | 多行文本 |
| `images` | 可增长槽位：可选的参考图像，会由文本编码器读取，并作为干净帧追加到 latent 序列中。连接 1..8 张图像（`image_1`、`image_2`、...）；后续图像会缩放到第一张图像的大小，且采样的 latent 应与其尺寸匹配。仅使用 RGB 通道。 | IMAGE | 否 | 0 到 8 |

**注意：** 参考图像按其槽位名称的数字顺序读取，空槽位会被忽略。仅当同时提供 `vae` 和至少一张图像时，才会生成参考 latent。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `CONDITIONING` | 包含已编码提示词的 CONDITIONING，以及在提供 VAE 和参考图像时附加的参考 latent。 | CONDITIONING |
