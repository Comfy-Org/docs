## 概述

此节点使用 Luma Ray 3.2 在新提示词下重新渲染现有视频，允许你在保留原始运动的同时重新设计风格、重新打光、添加或移除元素。源视频最长可达 18 秒，编辑后的视频保持源视频的原始时长。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `视频` | 要编辑的源视频。最长 18 秒。 | VIDEO | 是 | - |
| `提示词` | 描述所需的编辑。 | STRING | 是 | - |
| `分辨率` | 编辑后视频的输出分辨率。（默认："720p"） | COMBO | 是 | `"360p"`<br />`"540p"`<br />`"720p"`<br />`"1080p"` |
| `强度` | 保留源视频与重新想象之间的强度。"auto" 让 Ray 3.2 自行选择；adhere_* 最大程度保留源视频，flex_* 均衡，reimagine_* 改动最大。（默认："auto"） | COMBO | 是 | `"auto"`<br />`"adhere_1"`<br />`"adhere_2"`<br />`"adhere_3"`<br />`"flex_1"`<br />`"flex_2"`<br />`"flex_3"`<br />`"reimagine_1"`<br />`"reimagine_2"`<br />`"reimagine_3"` |
| `种子` | 用于可重现性的种子。 | INT | 是 | - |

**注意：** `prompt` 必须介于 1 到 6000 个字符之间。源视频时长不得超过 18 秒。
