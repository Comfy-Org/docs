WanMoveTracksFromCoords 节点从 JSON 格式的坐标字符串创建运动轨迹。它将坐标数据转换为可供其他视频处理节点使用的张量格式，并且可以选择性地应用蒙版来控制轨迹随时间变化的可见性。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `轨道坐标` | 包含轨迹坐标数据的 JSON 格式字符串。默认值为空列表（`"[]"`）。该输入为强制输入，因此必须在界面中连接。 | STRING | 否 | N/A |
| `轨道遮罩` | 可选的蒙版。提供时，节点使用它来确定每帧轨迹的可见性：在蒙版包含任何非零像素的帧中，轨迹可见。未提供时，所有轨迹在所有帧中均可见。 | MASK | 否 | N/A |

**注意：** `track_coords` 输入需要特定的 JSON 结构。它应为轨迹列表，其中每个轨迹是一个帧列表，每个帧是一个包含 `x` 和 `y` 坐标的对象。所有轨迹的帧数必须一致，并且至少提供一个轨迹。

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `tracks` | 生成的轨迹数据，包含每条轨迹的路径坐标和可见性信息。 | TRACKS |
| `轨道长度` | 生成轨迹中的总帧数。 | INT |
