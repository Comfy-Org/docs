WanMoveTracksFromCoords 节点根据 JSON 格式的坐标字符串创建运动轨迹。它将坐标数据转换为可供其他视频处理节点使用的轨迹格式，并且可以选择应用遮罩来控制轨迹随时间的可见性。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `轨道坐标` | 包含轨迹坐标数据的 JSON 格式字符串。默认值为空列表（`"[]"`）。此输入是强制输入，因此必须在 UI 中连接。 | STRING | 否 | N/A |
| `轨道遮罩` | 可选遮罩。提供后，节点会使用它来确定每帧轨迹的可见性：在遮罩包含任何非零像素的帧中，轨迹可见。未提供时，所有轨迹在所有帧中都可见。 | MASK | 否 | N/A |

**注意：** `track_coords` 输入需要特定的 JSON 结构。它应该是一个轨迹列表，其中每条轨迹是一个帧列表，每个帧是一个包含 `x` 和 `y` 坐标的对象。所有轨迹的帧数必须一致，并且必须至少提供一条轨迹。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `tracks` | 生成的轨迹数据，包含每条轨迹的路径坐标和可见性信息。 | TRACKS |
| `track_length` | 生成的轨迹中的总帧数。 | INT |
