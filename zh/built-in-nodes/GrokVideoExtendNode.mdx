Grok Video Extend 节点基于文本提示扩展现有视频并实现无缝续接。提供一段简短的源视频并描述接下来应该发生什么；该节点会返回一段从原视频继续的新视频片段。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于视频扩展的模型。选择 `"grok-imagine-video"` 选项会显示其模型特定设置。 | DYNAMIC_COMBO | 是 | `"grok-imagine-video"` |
| `提示词` | 视频中接下来应该发生什么的文本描述。 | STRING | 是 | N/A |
| `视频` | 要扩展的源视频。MP4 格式，2-15 秒。 | VIDEO | 是 | MP4, 2-15 seconds, maximum 50MB |
| `种子` | 用于确定节点是否应重新运行的种子；无论种子如何，实际结果都是非确定性的（默认：0）。 | INT | 是 | 0 到 2147483647 |

### grok-imagine-video 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `duration` | 扩展时长（秒）（默认：8）。 | INT | 是 | 2 到 10 |

**参数约束：**
*   `video` 输入必须是长度在 2 到 15 秒之间的 MP4 文件，且文件大小不能超过 50MB。
*   `prompt` 在去除空白后必须至少包含一个字符。
*   `model` 参数是动态组合。选择 `"grok-imagine-video"` 选项会显示嵌套的 `duration` 参数。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 新生成的视频扩展。 | VIDEO |
