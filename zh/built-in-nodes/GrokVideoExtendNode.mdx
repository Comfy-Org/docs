Grok Video Extend 节点使用 AI 模型为现有视频创建无缝续接。你提供一个短视频和一段描述后续内容的文本提示，该节点会生成一段衔接原视频的新视频片段。

## 输入
### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于视频扩展的模型。 | DYNAMIC_COMBO | 是 | `"grok-imagine-video"` |
| `提示词` | 描述视频接下来应发生内容的文本。 | STRING | 是 | N/A |
| `视频` | 要扩展的源视频。MP4 格式，2-15 秒。 | VIDEO | 是 | N/A |
| `种子` | 用于确定节点是否应重新运行的种子；无论种子如何，实际结果都是不确定的（默认值：0）。 | INT | 是 | 0 到 2147483647 |

### grok-imagine-video 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `duration` | 扩展片段的长度（以秒为单位，默认值：8）。 | INT | 是 | 2 到 10 |

**参数约束：**
*   `video` 输入必须是时长在 2 到 15 秒之间且文件大小不超过 50MB 的 MP4 文件。
*   `prompt` 在去除首尾空白后必须至少包含一个字符。
*   `model` 参数是一个动态组合框。选择 “grok-imagine-video” 选项会显示嵌套的 `duration` 参数。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 新生成的视频扩展片段。 | VIDEO |
