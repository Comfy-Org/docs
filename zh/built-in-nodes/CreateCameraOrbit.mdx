在第一个相机的目标周围构建一组相机装置：默认是转台，当设置 `pitch` 时为倾斜扫掠，并可选正下方和正上方视图。Render Mesh 会为每台相机渲染一张图像，Bake Texture From Views 会将这些图像投影回网格。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `camera_info` | 轨道的第一台相机。若输入的是相机列表，则会围绕列表中的每台相机进行轨道运动。 | LOAD3D_CAMERA | 是 | - |
| `count` | 沿扫掠路径均匀分布的相机数量。默认：4。 | INT | 是 | 1 到 64 |
| `yaw` | 绕目标的总旋转角度，方向遵循 Create Camera Info 的 `yaw` 方向。整圈旋转会在到达第一台相机前一步停止；其他扫掠则止于最后一台相机。默认：360.0。 | FLOAT | 是 | -720.0 到 720.0（步长：1.0） |
| `pitch` | 越过目标的总倾斜角度，正值上升，方向与 Create Camera Info 的 `pitch` 相同；超过 90 后，相机会从顶部越过。整圈旋转会像 `yaw` 一样循环。默认：0.0。 | FLOAT | 是 | -720.0 到 720.0（步长：1.0） |
| `poles` | 从目标正下方和/或正上方观察的视图，在轨道之后添加。其图像顶部背向第一台相机。默认：`"none"`。 | COMBO | 是 | `"none"`<br />`"top"`<br />`"bottom"`<br />`"top and bottom"` |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `camera_info` | 该相机装置的相机列表，按轨道顺序排列，后面跟随极点视图。 | LOAD3D_CAMERA |
