Bria Eraser 使用 Bria API 从图像中移除物体或区域。您需要提供一张图像和一个标记待移除区域的蒙版；节点会将两者上传到 Bria，运行擦除任务，等待任务完成，并返回已擦除蒙版区域的编辑后图像。

## 输入
| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 包含要移除的物体或区域的输入图像。 | IMAGE | 是 | - |
| `mask` | 白色区域将被擦除，黑色区域将被保留。该蒙版在发送前会被二值化，因此部分绘制的区域也会被视为白色。必须与图像具有相同的宽高比。 | MASK | 是 | - |
| `mask_type` | 选择蒙版的创建方式。"manual" 表示手绘或画笔蒙版；"automatic" 表示由分割模型（如 SAM）生成的蒙版。 | COMBO | 是 | "manual"<br />"automatic" |
| `moderation` | 审核设置。设置为 "true" 可对输入和/或输出图像启用视觉内容审核。 | DYNAMIC_COMBO | 是 | "false"<br />"true" |

注意：当 `moderation` 设置为 "true" 时，会出现两个额外的布尔设置：

- `visual_input_moderation` — 对输入图像应用视觉内容审核（默认值：false）
- `visual_output_moderation` — 对输出图像应用视觉内容审核（默认值：false）

蒙版必须与图像的宽高比匹配，否则请求将失败。蒙版在发送到 API 之前会被转换为二值（黑白）蒙版：不透明度低于一半的绘制区域将被忽略，部分绘制的区域被视为白色并会被擦除。蒙版必须至少包含一些白色区域；空蒙版会导致请求失败，因为没有可擦除的内容。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 已移除蒙版物体或区域的编辑后图像。 | IMAGE |
