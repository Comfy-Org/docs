此节点使用 Z-Image Turbo 模型根据文本提示生成图像，仅需 8 步即可完成。生成在 Comfy Cloud GPU 上远程运行，并按运行时长计费，这使其成为此处用于迭代图像创意的最快且最便宜的选择之一。生成完成后，节点会下载已完成图像，以供你在工作流中使用。此节点属于 Comfy Cloud 节点集，该节点集标记为 BETA：选项可能会增加或移除，工作流可能会被停用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 描述要生成的图像的文本提示。接受多行输入，并在提交前去除首尾空白。去除空白后不能为空。默认值：""（空）。 | STRING | 是 | 1 - 4096 个字符 |
| `种子` | 用于控制生成可重复性的随机种子。更改它会生成不同的变体。包含生成后控制选项。默认值：42。 | INT | 否 | 0 - 18446744073709551615 |
| `宽高比` | 生成图像的宽高比。默认值："1:1"。 | COMBO | 否 | "1:1"<br />"3:4"<br />"2:3"<br />"3:2"<br />"4:3"<br />"16:9"<br />"9:16"<br />"21:9" |
| `百万像素` | 总像素预算。在方形比例下，1.0 约为 1024x1024。默认值：1.0。 | FLOAT | 否 | 0.1 - 16.0<br />（步长 0.1） |

注意：提交生成之前会验证输入值。`prompt` 在去除空白后必须包含 1 到 4,096 个字符，`aspect_ratio` 必须是列出的选项之一，`megapixels` 必须以 0.1 为增量输入。
