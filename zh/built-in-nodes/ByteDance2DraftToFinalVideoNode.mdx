此节点用于渲染 Seedance 2.5 Draft 的 1080p 最终视频。草稿是一种快速的 480p 预览：在 Seedance 2.5 视频节点（文本到视频、首尾帧到视频或参考到视频）中，将 `model` 设置为 `Seedance 2.5 Draft`，运行该节点，然后将其 `draft_task_id` 输出连接到这里。最终视频会保留草稿的场景和运动，并复用生成该草稿时使用的提示词、参考、时长、宽高比和音频设置。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `draft_task_id` | 使用 Seedance 2.5 Draft 模型运行的 Seedance 2.5 节点的 `draft_task_id` 输出，或粘贴的草稿任务 ID。当你重新运行生成该草稿的节点时，将其 `seed` 控制设置为 fixed，否则下一次运行会生成新的草稿，而不是复用你已查看的草稿。 | STRING | 是 | - |
| `watermark` | 是否向视频添加水印。默认值为 False。这是一个高级设置。 | BOOLEAN | 否 | True / False |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `video` | 渲染完成的 1080p 最终视频，在渲染任务完成后从提供商处下载。 | VIDEO |

**注意：** 草稿在创建后 7 天内可以渲染。草稿任务 ID 本身即可标识该草稿，因此无需再次传入提示词、参考、时长、宽高比和音频设置。
