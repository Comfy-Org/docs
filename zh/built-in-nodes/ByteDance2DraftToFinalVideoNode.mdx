此节点用于将 Seedance 2.5 草稿渲染为 1080p 或 4k 的最终视频，4k 对所有账户开放。草稿是一种快速的 480p 预览：在 Seedance 2.5 视频节点（文本转视频、首尾帧转视频或参考图转视频）中，将 `model` 设置为 `Seedance 2.5 Draft` 并运行，然后将其 `draft_task_id` 输出连接到此节点。最终视频会保留草稿的场景和运动，并复用生成该草稿时使用的提示词、参考素材、时长、宽高比和音频设置。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `draft_task_id` | 使用 Seedance 2.5 Draft 模型运行的 Seedance 2.5 节点的 `draft_task_id` 输出，或粘贴的草稿任务 ID。重新运行生成节点时，请将其种子控制设置为固定值，否则下一次运行会生成新的草稿，而不会复用你已经查看过的草稿。 | STRING | 是 | - |
| `水印` | 是否为视频添加水印。默认值为 False。这是一个高级设置。 | BOOLEAN | 否 | True / False |
| `resolution` | 最终视频的分辨率。`"4k"` 对所有账户开放；取值必须为小写的 `"4k"`。默认值：`"1080p"`。 | COMBO | 否 | `"1080p"`<br />`"4k"` |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `video` | 渲染完成的最终视频，在渲染任务完成后从服务商处下载。 | VIDEO |

**注意：** 草稿在创建后的 7 天内可以渲染。草稿任务 ID 本身即可标识该草稿，因此无需再次传入提示词、参考素材、时长、宽高比和音频设置。
