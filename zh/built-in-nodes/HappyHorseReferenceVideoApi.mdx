此节点使用 HappyHorse 模型，根据参考图像生成包含人物或物体的视频。它支持单角色表演和多角色互动。参考图像被上传并用于表示生成视频中的角色。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于生成的 HappyHorse 参考转视频模型。 | DYNAMIC_COMBO | 是 | `"happyhorse-1.1-r2v"`<br />`"happyhorse-1.0-r2v"` |
| `seed` | 用于生成的种子（默认值：0）。可设置为每次生成后自动更改。 | INT | 是 | 0 到 2147483647 |
| `watermark` | 是否在结果中添加 AI 生成的水印（默认值：False）。 | BOOLEAN | 是 | True 或 False |

### HappyHorse 1.1 输入 (happyhorse-1.1-r2v)

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述视频的提示词。使用诸如 'character1' 和 'character2' 等标识符来指代参考角色。 | STRING | 是 | N/A |
| `resolution` | 生成视频的分辨率。 | COMBO | 是 | `"720P"`<br />`"1080P"` |
| `ratio` | 生成视频的宽高比。 | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"`<br />`"21:9"`<br />`"9:21"`<br />`"5:4"`<br />`"4:5"` |
| `duration` | 生成视频的时长（秒）（默认值：5）。 | INT | 是 | 3 到 15 |

### HappyHorse 1.0 输入 (happyhorse-1.0-r2v)

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述视频的提示词。使用诸如 'character1' 和 'character2' 等标识符来指代参考角色。 | STRING | 是 | N/A |
| `resolution` | 生成视频的分辨率。 | COMBO | 是 | `"720P"`<br />`"1080P"` |
| `ratio` | 生成视频的宽高比。 | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 生成视频的时长（秒）（默认值：5）。 | INT | 是 | 3 到 15 |

### 参考输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可扩展插槽：连接 1 到 9 张要在视频中呈现的人物或物体的参考图像。必须至少提供一张参考图像。 | IMAGE | 是 | 1 到 9（每个模型） |

注意：必须至少提供一张参考图像，否则节点将引发错误。每张参考图像至少为 400 x 400 像素，并且宽高比需在 1:2.5 到 2.5:1 之间。提示词不能为空。
