此节点使用 Meshy T2.5 以目标面数生成可用于游戏的三角网格。拓扑结构按照请求的面数直接构建，而非在生成后再进行减面处理，因此结果可直接用于游戏引擎，无需额外进行重拓扑处理。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于生成的 Meshy 模型版本。 | COMBO | 是 | `"meshy-t2.5"` |
| `prompt` | 要生成的 3D 模型的文本描述。 | STRING | 是 | 1 到 800 个字符 |
| `target_polycount` | 生成网格中三角形的近似数量。默认值：15000。 | INT | 是 | 100 到 30000 |
| `pose_mode` | 生成角色的姿势。空字符串表示不指定特定姿势。此为高级设置。默认值：`""`（空字符串）。 | COMBO | 是 | `""`<br />`"A-pose"`<br />`"T-pose"` |
| `seed` | 种子控制节点是否重新运行；无论种子为何值，结果都是非确定性的。默认值：42。 | INT | 是 | 0 到 2147483647 |

**约束条件：**

* prompt 必须包含 1 到 800 个字符。
* `target_polycount` 是构建网格所用的三角形数量，而不是生成后施加的限制。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `meshy_task_id` | Meshy API 任务的唯一标识符。 | MESHY_TASK_ID |
| `GLB` | 生成的 GLB 格式 3D 模型。 | FILE3DGLB |
| `FBX` | 生成的 FBX 格式 3D 模型。 | FILE3DFBX |
