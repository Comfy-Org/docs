此节点通过使用 MediaPipe Face Landmarker 检测图像中的人脸，将每张检测到的人脸与跟踪到的人物进行匹配，并将 52 个 ARKit 混合形状映射到 MHR 的 72 轴表情参数上，从而为 SAM3D 身体添加面部表情。然后它会重新运行身体模型，使输出网格顶点和关键点反映新的表情。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `sam3d_body_model` | 包含面部关键点检测器的 SAM3D 身体模型，用于检测人脸并重新生成身体网格。 | SAM3D_BODY_MODEL | 是 | - |
| `mhr_pose_data` | 姿态数据，包含每帧跟踪到的人物及其边界框、关键点和表情参数。此节点将每张检测到的人脸与人物进行匹配，并将更新后的表情参数写入此数据。 | MHR_POSE_DATA | 是 | - |
| `image` | 用于检测人脸的图像帧。如果图像批次的帧数少于姿态数据，则对剩余的帧复用最后一帧。 | IMAGE | 是 | - |
| `strength` | 所有混合形状的全局乘数。>1 表示夸张。默认：1.0。 | FLOAT | 否 | 0.0 到 4.0（步长 0.05，默认 1.0） |
| `mouth_strength` | 嘴部/下颌形状的乘数。MediaPipe 的 jawOpen 接近 1.0 时趋于饱和。默认：1.0。 | FLOAT | 否 | 0.0 到 4.0（步长 0.05，默认 1.0） |
| `eye_strength` | 眼部形状的乘数。MediaPipe 很少超过 0.5；通常需要 2-3 倍。默认：2.0。 | FLOAT | 否 | 0.0 到 4.0（步长 0.05，默认 2.0） |
| `brow_strength` | 眉毛/脸颊/皱鼻形状的乘数。MediaPipe 输出约为 0.1-0.3；需要 2-3 倍。默认：2.0。 | FLOAT | 否 | 0.0 到 4.0（步长 0.05，默认 2.0） |
| `input_threshold` | MediaPipe 原始输出的死区（低于该值归零，高于该值进行线性重映射）。默认：0.02。 | FLOAT | 否 | 0.0 到 0.5（步长 0.01，默认 0.02） |
| `blendshape_smooth_window` | 在 MHR 映射之前对 MediaPipe 每帧信号应用的高斯窗口。MediaPipe 的原始输出在静态人脸上逐帧波动 30-70%。1 表示禁用。请使用奇数值。默认：7。 | INT | 否 | 1 到 31（步长 2，默认 7） |

注意：仅当片段中至少有 30 帧包含检测到的人物时，才会应用逐片段基线减法。每个人物最多 12 帧的检测间隙通过插值填补。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mhr_pose_data` | 更新后的姿态数据。每个跟踪到的人物的表情参数都被替换为映射后的面部表情，并重新生成网格顶点和关键点以与之匹配。 | MHR_POSE_DATA |
