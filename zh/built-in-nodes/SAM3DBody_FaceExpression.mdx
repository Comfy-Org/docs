此节点通过在图像中利用 MediaPipe Face Landmarker 检测人脸、将每张检测到的人脸与跟踪人物进行匹配，并将 52 个 ARKit 混合变形映射到 MHR 的 72 轴表情参数上，从而为 SAM3D 身体添加面部表情。随后，节点会重新运行身体模型，使输出的网格顶点和关键点与新表情相匹配。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `sam3d_body_model` | 包含用于检测人脸并重新生成身体网格的人脸关键点检测器的 SAM3D 身体模型。 | SAM3D_BODY_MODEL | 是 | - |
| `mhr_pose_data` | 包含逐帧跟踪人物（含边界框、关键点和表情参数）的姿势数据。此节点将每个检测到的人脸与人物进行匹配，并将更新后的表情参数写入该数据。 | MHR_POSE_DATA | 是 | - |
| `image` | 用于检测人脸的图像帧。如果图像批次中的帧数少于姿势数据，则最后一帧将用于剩余帧。 | IMAGE | 是 | - |
| `strength` | 所有混合变形（blendshape）的全局倍数。>1 增强效果。默认值：1.0。 | FLOAT | 否 | 0.0 到 4.0（步长 0.05，默认值 1.0） |
| `mouth_strength` | 嘴部/下颌形状的倍数。MediaPipe 的 jawOpen 在接近 1.0 时饱和。默认值：1.0。 | FLOAT | 否 | 0.0 到 4.0（步长 0.05，默认值 1.0） |
| `eye_strength` | 眼部形状的倍数。MediaPipe 很少超过 0.5；通常需要 2-3 倍。默认值：2.0。 | FLOAT | 否 | 0.0 到 4.0（步长 0.05，默认值 2.0） |
| `brow_strength` | 眉毛/脸颊/嗤鼻形状的倍数。MediaPipe 输出约 0.1-0.3；通常需要 2-3 倍。默认值：2.0。 | FLOAT | 否 | 0.0 到 4.0（步长 0.05，默认值 2.0） |
| `input_threshold` | MediaPipe 原始输出的死区（低于该值设为零，高于该值进行线性重映射）。默认值：0.02。 | FLOAT | 否 | 0.0 到 0.5（步长 0.01，默认值 0.02） |
| `blendshape_smooth_window` | MHR 映射之前对 MediaPipe 逐帧信号进行的高斯窗口平滑。MediaPipe 的原始输出在静止人脸上逐帧波动 30-70%。1 表示禁用。使用奇数值。默认值：7。 | INT | 否 | 1 到 31（步长 2，默认值 7） |

注：仅当片段中至少 30 帧包含检测到的人物时，才会应用逐片段基线减法。每个人最多 12 帧的检测间隙将通过插值填充。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mhr_pose_data` | 更新后的姿势数据。每个被跟踪人物的表情参数将被替换为映射后的人脸表情，并重新生成网格顶点和关键点以与之匹配。 | MHR_POSE_DATA |
