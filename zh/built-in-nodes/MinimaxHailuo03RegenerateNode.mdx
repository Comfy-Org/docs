此节点将以 2K 分辨率重新渲染 MiniMax H3 768P 视频输出。它会上传未经修改的 768P 视频和用于生成该视频的原始提示词，启动 MiniMax H3 重新生成任务，并返回重新渲染后的 2K 视频。如果原始生成使用了首帧、末帧或参考媒体，请附加相同的输入。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频重新生成的模型。选择“MiniMax H3”会显示提示词、分辨率和参考媒体设置。 | DYNAMIC_COMBO | 是 | "MiniMax H3" |
| `video` | 要重新渲染的 MiniMax H3 768P 输出视频。请连接 MiniMax H3 视频节点的未经修改的输出（24 FPS，4-15 秒）。不能使用 2K 输出。 | VIDEO | 是 | 24 FPS，4-15 秒 |
| `first_frame` | 原始生成中使用的首帧图像（如果使用了的话）。 | IMAGE | 否 | 图像 |
| `last_frame` | 原始生成中使用的末帧图像（如果使用了的话）。 | IMAGE | 否 | 图像 |
| `watermark` | 是否在视频中添加 AIGC 水印。默认值为 false。 | BOOLEAN | 是 | false / true |

### MiniMax H3 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 用于生成源视频的原始提示词。不能为空。 | STRING | 是 | 文本（多行） |
| `resolution` | 重新渲染源视频的分辨率。 | COMBO | 是 | "2K" |

### 参考输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可增长插槽：连接 `image_1` 至 `image_9`（最多 9 张图像）。原始生成中的参考图像，按相同顺序排列。 | IMAGE | 否 | 0-9 张图像 |
| `reference_videos` | 可增长插槽：连接 `video_1` 至 `video_3`（最多 3 个视频）。原始生成中的参考视频，按相同顺序排列。 | VIDEO | 否 | 0-3 个视频 |
| `reference_audios` | 可增长插槽：连接 `audio_1` 至 `audio_3`（最多 3 个片段）。原始生成中的音频参考，按相同顺序排列。如果没有参考图像或视频，则无法使用。 | AUDIO | 否 | 0-3 个片段 |

### 约束条件

- `prompt` 不能为空。
- 源 `video` 必须是未经修改的 MiniMax H3 768P 输出：24 FPS，宽高均能被 32 整除，总像素不超过 1,032,192，帧数为 107 至 362 帧且按 17 的步长递增（24 FPS 下为 4 至 15 秒）。2K 输出不能用作源视频。
- `first_frame` 和 `last_frame` 与参考媒体（`reference_images`、`reference_videos`、`reference_audios`）互斥。图像到视频的提示词使用帧，参考到视频的提示词使用参考媒体。
- `reference_audios` 需要至少一个 `reference_images` 或 `reference_videos` 输入。
- `first_frame`、`last_frame` 以及每个 `reference_image` 的宽高比必须在 0.4 到 2.5 之间，并且至少为 256x256 像素。
- `reference_videos`：每个视频的帧率必须在 23.976 到 60 FPS 之间，时长为 2-15 秒；总时长不能超过 15 秒。
- `reference_audios`：每个片段时长必须为 2-15 秒；总时长不能超过 15 秒。

## 输出

|-------------|-------------|-----------|
