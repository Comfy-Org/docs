此节点以 2K 分辨率重新渲染 MiniMax H3 768P 视频输出。它会上传源视频以及用于创建该视频的精确提示词，启动 MiniMax H3 重新生成任务，并返回重新渲染后的 2K 视频。如果原始生成使用了首帧/末帧或参考媒体，请附加相同的输入。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频重新生成的模型。选择此模型将显示下方记录的提示词、分辨率和参考媒体设置。 | COMBO | 是 | "MiniMax H3" |
| `prompt` | 用于生成源视频的精确提示词。不能为空。 | STRING | 是 | Text |
| `resolution` | 重新渲染源视频的分辨率。 | COMBO | 是 | "2K" |
| `reference_images` | 来自原始生成的参考图像，顺序相同。最多 9 张。 | IMAGE | 否 | 0-9 images |
| `reference_videos` | 来自原始生成的参考视频，顺序相同。最多 3 个视频，每个 2-15 秒，总时长 15 秒。 | VIDEO | 否 | 0-3 videos |
| `reference_audios` | 来自原始生成的音频参考，顺序相同。最多 3 个片段，每个 2-15 秒，总时长 15 秒。没有参考图像或视频时不能使用。 | AUDIO | 否 | 0-3 clips |
| `video` | 要重新渲染的 MiniMax H3 768P 输出视频。连接 MiniMax H3 视频节点的未修改输出（24 FPS，4-15 秒）。不能使用 2K 输出。 | VIDEO | 是 | 24 FPS, 4-15 seconds |
| `first_frame` | 原始生成中使用的首帧图像（如果使用了的话）。 | IMAGE | 否 | Image |
| `last_frame` | 原始生成中使用的末帧图像（如果使用了的话）。 | IMAGE | 否 | Image |
| `watermark` | 是否在视频中添加 AIGC 水印。默认值为 false。 | BOOLEAN | 是 | false / true |

### 约束

- 源 `video` 必须是未经修改的 MiniMax H3 768P 输出：宽和高可被 32 整除，总像素数不超过 1,032,192，24 FPS，帧数为 107 到 362，且以 17 为步长（24 FPS 下为 4 至 15 秒）。不能将 2K 输出作为源。
- `first_frame` / `last_frame` 与参考媒体（`reference_images`、`reference_videos`、`reference_audios`）互斥。对于图像转视频提示词，请使用帧；对于参考转视频提示词，请使用参考媒体。
- `reference_audios` 至少需要一个 `reference_images` 或 `reference_videos` 输入。
- `reference_images`：每个图像的宽高比必须在 0.4 到 2.5 之间，且至少为 256x256 像素。
- `reference_videos`：每个视频的帧率必须为 23.976 至 60 FPS，时长 2-15 秒；总时长不能超过 15 秒。
- `reference_audios`：每个片段时长必须为 2-15 秒；总时长不能超过 15 秒。

## 输出
| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 重新渲染的 MiniMax H3 视频，分辨率为 2K。 | VIDEO |
