此节点将 MiniMax H3 768P 视频输出重新渲染为 2K 分辨率。它会上传未经修改的 768P 视频以及生成该视频时使用的精确提示词，启动 MiniMax H3 重新生成任务，并返回重新渲染后的 2K 视频。如果原始生成使用了首帧或尾帧或参考媒体，请附加相同的输入。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频重新生成的模型。选择 "MiniMax H3" 会显示提示词、分辨率和参考媒体设置。 | DYNAMIC_COMBO | 是 | "MiniMax H3" |
| `video` | 要重新渲染的 MiniMax H3 768P 输出视频。连接 MiniMax H3 视频节点未经修改的输出（24 FPS，4-15 秒）。不能使用 2K 输出。 | VIDEO | 是 | 24 FPS, 4-15 seconds |
| `first_frame` | 原始生成时使用的首帧图像（如果使用了）。 | IMAGE | 否 | Image |
| `last_frame` | 原始生成时使用的尾帧图像（如果使用了）。 | IMAGE | 否 | Image |
| `watermark` | 是否向视频添加 AIGC 水印。默认值为 false。 | BOOLEAN | 是 | false / true |

### MiniMax H3 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 用于生成源视频的精确提示词。不能为空。 | STRING | 是 | Text (multiline) |
| `resolution` | 重新渲染源视频时使用的分辨率。 | COMBO | 是 | "2K" |

### 参考输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可扩展槽位：连接 `image_1` 到 `image_9`（最多 9 张图像）。原始生成时使用的参考图像，顺序相同。 | IMAGE | 否 | 0-9 images |
| `reference_videos` | 可扩展槽位：连接 `video_1` 到 `video_3`（最多 3 个视频）。原始生成时使用的参考视频，顺序相同。 | VIDEO | 否 | 0-3 videos |
| `reference_audios` | 可扩展槽位：连接 `audio_1` 到 `audio_3`（最多 3 个音频片段）。原始生成时使用的音频参考，顺序相同。不能在没有参考图像或视频的情况下使用。 | AUDIO | 否 | 0-3 clips |

### 约束

- `prompt` 不能为空。
- 源 `video` 必须是未经修改的 MiniMax H3 768P 输出：24 FPS，宽高可被 32 整除，总像素数最多为 1,032,192，帧数为 107 到 362，步长为 17（24 FPS 下为 4 到 15 秒）。不能将 2K 输出用作源视频。
- `first_frame` 和 `last_frame` 与参考媒体（`reference_images`、`reference_videos`、`reference_audios`）互斥。图生视频提示词使用帧，参考生视频提示词使用参考媒体。
- `reference_audios` 至少需要一个 `reference_images` 或 `reference_videos` 输入。
- `first_frame`、`last_frame` 以及每个 `reference_image` 的宽高比必须在 0.4 到 2.5 之间，并且至少为 256x256 像素。
- `reference_videos`：每个视频必须为 23.976 到 60 FPS，时长 2-15 秒；总时长不能超过 15 秒。
- `reference_audios`：每个音频片段必须为 2-15 秒长；总时长不能超过 15 秒。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 重新渲染后的 2K 分辨率 MiniMax H3 视频。 | VIDEO |
