使用 Tripo API 从单张输入图像生成主体的正面、左侧、背面和右侧视图。图像会被上传，多视图生成任务会被启动并轮询直到完成，四个生成的视图会与任务 ID 一起返回。这是一项付费任务，计费约为 0.10 美元。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 主体的源图像，Tripo 据此生成正面、左侧、背面和右侧视图。即使提供批次，请求中也只会使用一张图像。 | IMAGE | 是 | Single image |

注意：此节点会调用 Tripo 的云 API，并等待生成任务完成。典型任务大约需要 25 秒。身份验证通过节点的隐藏输入自动处理，因此无需在工作流中提供 Tripo API 密钥。此节点要求 Tripo 响应中包含全部四个视图 URL（`front_view_url`、`left_view_url`、`back_view_url`、`right_view_url`）；如果缺少任何视图，执行将失败并报错。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `multiview task_id` | Tripo 针对多视图图像生成请求返回的任务标识符。可用于引用已完成的任务，例如使用 Tripo: Edit Multiview 优化视图时。 | MULTIVIEW_TASK_ID |
| `front` | 生成的主体正面视图。 | IMAGE |
| `left` | 生成的主体左侧视图。 | IMAGE |
| `back` | 生成的主体背面视图。 | IMAGE |
| `right` | 生成的主体右侧视图。 | IMAGE |
