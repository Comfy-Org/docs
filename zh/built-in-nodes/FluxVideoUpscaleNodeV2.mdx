Flux Video Upscale 使用 FLUX 超分辨率放大视频，可放大到固定的 1080p、2K 或 4K 帧尺寸，或放大 1.5 至 3 倍。创意模式（`"creative"`）可恢复并生成精细细节，适合生成素材；精确模式（`"precise"`）可锐化源视频而不改变内容，适合人脸、产品和真实素材。上传片段后，会轮询 BFL 任务，完成的视频以 24 fps 返回。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `video` | 源片段，时长 1 至 20 秒、最大 50 MB，至少 64x64 像素，宽高比在 1:4 到 4:1 之间。输出以 24 fps 渲染，每帧上限约 14.4 百万像素。 | VIDEO | 是 | 时长 1 至 20 秒；宽高比在 1:4 到 4:1 之间；最小 64x64 像素 |
| `target_resolution` | 输出尺寸。`"1080p"`、`"2K"` 和 `"4K"` 会将结果适配到 1920x1080、2560x1440 或 3840x2160 像素以内，竖屏片段会相应旋转尺寸；`"by factor"` 则使用 `upscale_factor`。 | DYNAMIC_COMBO | 是 | `"2K"`<br />`"4K"`<br />`"1080p"`<br />`"by factor"` |
| `mode` | `"creative"` 可恢复并生成精细细节，最适合生成素材、纹理和风景。`"precise"` 可锐化源视频而不改变内容，适合人脸、产品和真实素材。（默认：`"creative"`） | COMBO | 是 | `"creative"`<br />`"precise"` |
| `prompt` | 可选的片段描述，用于引导增强细节。留空则进行中性放大。（默认：空） | STRING | 是 | 多行文本 |
| `auto_downscale` | 对过大的源进行缩小处理，而不是拒绝：面积超过 2560x1440 像素，或超过目标分辨率的三分之二。保持宽高比。（默认：true） | BOOLEAN | 是 | true<br />false |
| `safety_tolerance` | 审核容忍度，0 为最严格。（默认：2，高级参数） | INT | 是 | 0 到 4 |
| `seed` | 种子控制节点是否应重新运行；FLUX 会自行选择种子，因此无论此值如何，实际结果都是不确定的。（默认：42） | INT | 是 | 0 到 4294967295 |

### by factor 输入

当 `target_resolution` 设置为 `"by factor"` 时，这些输入会出现。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `upscale_factor` | 相对于源的输出尺寸。由于每帧上限，非常大的源会以低于请求倍数的比例放大。（默认：2.0） | FLOAT | 是 | 1.5 到 3.0（步长 0.1） |

目标尺寸会作为放大倍数应用，并限制在 1.5–3.0 之间，因此过小的源即使以 3 倍放大也无法填满目标框，最终输出会小于请求的分辨率；而只需不到 1.5 倍即可适配目标框的源会先被缩小。关闭 `auto_downscale` 时，节点会报错停止，而不会进行缩小。输出为 24 fps，每帧上限约 14.4 百万像素，因此非常大的源可能以低于请求倍数的比例放大。
