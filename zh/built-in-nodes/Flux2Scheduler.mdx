Flux2Scheduler 生成用于去噪过程的噪声水平序列（sigmas），专门针对 Flux 模型定制。它根据去噪步数和目标图像尺寸计算调度，这会影响图像生成过程中噪声去除的进程。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `步数` | 要执行的去噪步数。较高的值通常会产生更详细的结果，但处理时间更长（默认值：20）。 | INT | 是 | 1 到 4096 |
| `宽度` | 要生成的图像宽度（以像素为单位）。该值会影响噪声调度计算（默认值：1024）。 | INT | 是 | 16 到 16384 |
| `高度` | 要生成的图像高度（以像素为单位）。该值会影响噪声调度计算（默认值：1024）。 | INT | 是 | 16 到 16384 |

注意：调度是根据图像序列长度计算的，该长度由 `width` 和 `height` 推导得出，即 `(width * height) / 256`，反映了模型的 16 倍潜在空间下采样。较大的图像会产生较长的序列，从而相应地改变噪声调度。

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `sigmas` | 定义采样器去噪调度的噪声水平值（sigmas）序列。 | SIGMAS |
