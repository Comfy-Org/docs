Kling Text to Video 节点使用 Kling 视频生成 API 根据文本描述生成视频。它会将提示词和设置（宽高比、生成模式和 CFG 缩放）发送到 API，等待生成任务完成，然后返回生成的视频及其 ID 和时长。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 正向文本提示词 | STRING | 是 | 最多 2500 个字符 |
| `负面提示词` | 负向文本提示词 | STRING | 否 | 最多 2500 个字符 |
| `CFG` | 配置缩放值，控制视频遵循提示词的程度（默认值：1.0） | FLOAT | 否 | 0.0 到 1.0 |
| `宽高比` | 视频宽高比设置（默认值："16:9"） | COMBO | 否 | "16:9"<br />"9:16"<br />"1:1" |
| `模式` | 用于视频生成的配置，遵循以下格式：mode / duration / model_name（默认值："pro mode / 5s duration / kling-v2-5-turbo"） | COMBO | 否 | "pro mode / 5s duration / kling-v2-5-turbo"<br />"pro mode / 10s duration / kling-v2-5-turbo" |

注意：`prompt` 参数为必需项，且不能为空。`prompt` 和 `negative_prompt` 均限制为最多 2500 个字符。10 秒的 `mode` 选项比 5 秒选项费用更高。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 生成的视频输出 | VIDEO |
| `video_id` | 生成视频的唯一标识符 | STRING |
| `duration` | 生成视频的时长信息 | STRING |
