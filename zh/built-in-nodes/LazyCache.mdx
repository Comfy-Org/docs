LazyCache 是 EasyCache 的一个实验性、自制版本，它在采样期间添加缓存以减少计算量。它旨在与 ComfyUI 中的模型实现通用兼容，但通常比 EasyCache 表现更差，可能仅在极少数情况下效果更好。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要添加 LazyCache 的模型。 | MODEL | 是 | - |
| `重用阈值` | 复用缓存步骤的阈值。默认值：0.2。 | FLOAT | 是 | 0.0 - 3.0 （步长：0.01） |
| `起始百分比` | 开始使用 LazyCache 的相对采样步数。默认值：0.15。 | FLOAT | 是 | 0.0 - 1.0 （步长：0.01） |
| `结束百分比` | 结束使用 LazyCache 的相对采样步数。默认值：0.95。 | FLOAT | 是 | 0.0 - 1.0 （步长：0.01） |
| `详细模式` | 是否记录详细日志信息。默认值：False。 | BOOLEAN | 是 | - |

注意：`reuse_threshold`、`start_percent`、`end_percent` 和 `verbose` 被标记为高级输入。
