ModelMergeQwenImage 通过以可调整的权重合并两个 AI 模型的组件，将两个模型融合在一起。它允许你混合 Qwen 图像模型的特定部分，包括 transformer 块、位置嵌入和文本处理组件。你可以控制每个模型在合并结果的不同部分中各自具有多大的影响力。

| `模型2` | 要合并的第二个模型 | MODEL | 是 | - |
| `pos_embeds.` | 位置嵌入混合权重（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0（步长：0.01） |

| `txt_norm.` | 文本归一化混合权重（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0（步长：0.01） |
