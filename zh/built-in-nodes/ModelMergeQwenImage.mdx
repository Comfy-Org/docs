此节点通过使用可调权重混合两个 Qwen 图像模型的各个组件来合并它们。每个权重控制第二个模型中对应部分对合并结果的贡献程度，让你可以分别混合位置嵌入、文本处理层、图像输入层、全部 60 个 transformer 块以及输出投影。最终结果是一个单一的 MODEL，可在任何需要普通模型的地方使用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `模型1` | 要合并的第一个模型 | MODEL | 是 | - |
| `模型2` | 要合并的第二个模型 | MODEL | 是 | - |
| `pos_embeds.` | 用于混合位置嵌入的权重（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0 （步长：0.01） |
| `img_in.` | 用于混合图像输入处理的权重（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0 （步长：0.01） |
| `txt_norm.` | 用于混合文本归一化的权重（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0 （步长：0.01） |
| `txt_in.` | 用于混合文本输入处理的权重（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0 （步长：0.01） |
| `time_text_embed.` | 用于混合时间与文本嵌入的权重（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0 （步长：0.01） |
| `transformer_blocks.0.` 到 `transformer_blocks.59.` | 用于混合每个 transformer 块的权重（默认值：1.0）。该节点为全部 60 个 transformer 块中的每一个都提供一个权重。 | FLOAT | 是 | 0.0 到 1.0 （步长：0.01） |
| `proj_out.` | 用于混合输出投影的权重（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0 （步长：0.01） |

注意：所有权重输入均为必需项，并且共享相同的限制——默认值为 1.0，有效范围为 0.0 到 1.0，可按 0.01 的步长调整。

## 输出

| --- | --- | --- |
