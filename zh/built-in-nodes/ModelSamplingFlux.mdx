ModelSamplingFlux 节点根据图像尺寸计算移位参数，对给定模型应用 Flux 模型采样。它会创建一种专门的采样配置，根据指定的宽度、高度和移位参数调整模型的行为，然后返回已应用新采样设置的修改后模型。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要应用 Flux 采样的模型 | MODEL | 是 | - |
| `最大移位` | 采样计算的最大移位值（默认：1.15） | FLOAT | 是 | 0.0 - 100.0 (step 0.01) |
| `基础移位` | 采样计算的基础移位值（默认：0.5） | FLOAT | 是 | 0.0 - 100.0 (step 0.01) |
| `宽度` | 目标图像的宽度（像素，默认：1024） | INT | 是 | 16 - MAX_RESOLUTION (step 8) |
| `高度` | 目标图像的高度（像素，默认：1024） | INT | 是 | 16 - MAX_RESOLUTION (step 8) |

`max_shift` 和 `base_shift` 是高级参数。应用于采样配置的移位值根据图像尺寸计算：潜在分辨率按 `width × height / 256` 计算，移位值在潜在分辨率为 256 时的 `base_shift` 与潜在分辨率为 4096 时的 `max_shift` 之间插值。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `model` | 应用了 Flux 采样配置的修改后模型 | MODEL |
