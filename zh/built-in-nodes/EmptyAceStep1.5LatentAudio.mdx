The Empty Ace Step 1.5 Latent Audio 节点创建一个为音频处理设计的空潜在张量。它会生成指定时长和批次大小的静音音频潜在表示，可用作 ComfyUI 中音频生成工作流的起点。该节点根据输入的秒数和固定采样率计算潜在长度。

## 输入
| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `seconds` | 要生成的音频时长（以秒为单位），默认值为 120.0。 | FLOAT | 是 | 1.0 - 1000.0 |
| `batch_size` | 批次中的潜在图像数量，默认值为 1。 | INT | 是 | 1 - 4096 |

## 输出
| Output Name | Description | Data Type |
| --- | --- | --- |
| `LATENT` | 表示静音音频的空潜在张量，类型标识符为 "audio"。输出还包含一个 `downscale_ratio_temporal` 值，即 1764，用于音频处理中的时间维度下采样。 | LATENT |
