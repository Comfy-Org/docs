此节点使用最新的 Kling AI 模型根据文本描述生成视频。它将您的提示词发送到远程 API 并返回生成的视频。您可以控制视频的时长、形状和质量，还可以选择构建多镜头分镜脚本。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于视频生成的特定 Kling 模型（默认：`"kling-v3-omni"`）。 | COMBO | 是 | `"kling-v3-omni"`<br />`"kling-video-o1"` |
| `提示词` | 描述视频内容的文本提示词。可以同时包含正面和负面描述。启用分镜脚本时忽略此项。 | STRING | 是 | 0 到 2500 字符 |
| `宽高比` | 要生成的视频的形状或尺寸。 | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"` |
| `时长` | 视频的时长，以秒为单位（默认：5）。 | INT | 是 | 3 到 15 秒 |
| `分辨率` | 视频的质量或像素分辨率（默认：`"1080p"`）。内部映射为 standard、pro 或 4k 质量。 | COMBO | 否 | `"4k"`<br />`"1080p"`<br />`"720p"` |
| `分镜` | 生成一系列具有独立提示词和时长的视频片段。对 o1 模型忽略此项。 | DYNAMIC_COMBO | 否 | `"disabled"`<br />`"1 storyboard"`<br />`"2 storyboards"`<br />`"3 storyboards"`<br />`"4 storyboards"`<br />`"5 storyboards"`<br />`"6 storyboards"` |
| `生成音频` | 是否为视频生成音频（默认：False）。 | BOOLEAN | 否 | True / False |
| `种子` | 种子控制节点是否应重新运行；无论种子如何，结果都是非确定性的（默认：0）。 | INT | 否 | 0 到 2147483647 |

### 分镜脚本子输入

当 `storyboards` 设置为 `"disabled"` 以外的值时，以下输入会为每个分镜片段显示。在下面的参数名中，`{i}` 是片段编号，从 1 到所选的分镜脚本数量。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_{i}_prompt` | 分镜片段 &#123;i&#125; 的提示词。最多 512 字符。 | STRING | 是 | 1 到 512 字符 |
| `storyboard_{i}_duration` | 分镜片段 &#123;i&#125; 的时长，以秒为单位（默认：4）。 | INT | 是 | 1 到 15 秒 |

### 参数约束和限制

- **特定模型限制：**
  - `kling-video-o1` 模型仅支持 **5 或 10 秒** 的时长。
  - `kling-video-o1` 模型**不**支持音频生成。
  - `kling-video-o1` 模型**不**支持 4k 分辨率。
  - `kling-video-o1` 模型**不**支持分镜脚本。
- **分镜脚本约束：**
  - 启用分镜脚本时，`prompt` 字段将被忽略。
  - 每个分镜脚本需要自己的提示词（1 到 512 字符）和时长。
  - 所有分镜脚本的总时长必须恰好等于全局 `duration` 参数。
- **提示词要求：**
  - 当分镜脚本**禁用**时，`prompt` 字段为必填（最少 1 字符）。
  - 当分镜脚本**启用**时，`prompt` 字段可以为空（0 字符）。
