OptimalStepsScheduler 节点创建一个用于扩散采样期间的噪声调度（一系列 sigma 值）。它根据所选的模型类型选择基础噪声水平，在仅部分应用去噪时调整调度，并对这些水平进行插值，使返回的 sigmas 与请求的步数相匹配。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 用于噪声水平计算的扩散模型类型。每个选项使用其各自预定义的噪声水平表。 | COMBO | 是 | "FLUX"<br />"Wan"<br />"Chroma" |
| `步数` | 要计算的采样总步数（默认：20）。 | INT | 是 | 3 到 1000 |
| `去噪` | 控制去噪强度，用于调整有效步数（默认：1.0）。 | FLOAT | 是 | 0.0 到 1.0（步长：0.01） |

**注意：** 当所选 `model_type` 的基础噪声水平表长度不等于 `steps + 1` 时，会使用对数线性插值对其重采样，因此输出始终与请求的步数相匹配。

**注意：** 当 `denoise` 小于 1.0 时，节点使用 `round(steps * denoise)` 作为有效总步数，并只保留调度中相匹配的尾部部分。如果 `denoise` 为 0.0 或更低，节点将返回一个空张量。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `sigmas` | 代表扩散采样噪声调度的一系列 sigma 值。序列中的最后一个值始终设为 0。 | SIGMAS |
