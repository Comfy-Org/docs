使用 HeyGen Video 1.0 将图像动画化为带有同步对白和声音的视频。连接的图像用作第一帧，生成的视频保持其宽高比。在提示词中描述应该发生什么，包括任何台词。该节点上传图像、创建视频任务、等待其完成并返回生成的视频。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于生成的模型版本。（默认值：`"heygen-video-1"`） | DYNAMIC_COMBO | 是 | `"heygen-video-1"` |
| `image` | 视频的第一帧。必须正好提供一张图像；会拒绝批次。请裁剪图像以更改视频形状，因为输出会保持此图像的宽高比。 | IMAGE | 是 | 1 张图像，宽高比 1:4 到 4:1 |
| `prompt` | 视频中发生情况的描述，包括任何对白。（默认值：空字符串） | STRING | 是 | 1 到 32000 个字符 |
| `duration` | 输出视频的时长，单位为秒。（默认值：5） | INT | 是 | 5 到 15 |
| `resolution` | 输出分辨率。（默认值：`"768p"`） | COMBO | 是 | `"768p"`<br />`"480p"` |
| `seed` | 用于生成的种子。即使使用相同的 `seed`，不同运行之间的结果仍可能不同。（默认值：42） | INT | 是 | 0 到 4294967295 |

### 参数约束

- **单张图像：** `image` 必须正好包含一张图像。连接批次会引发错误。
- **图像宽高比：** 图像宽度不得超过其高度的 4 倍，高度不得超过其宽度的 4 倍（介于 1:4 到 4:1 之间）；否则运行会失败。
- **提示词必填：** `prompt` 必须至少包含一个非空白字符，且最多包含 32000 个字符。
- **`seed`：** `seed` 仅决定该节点是否重新运行；使用相同 `seed` 无法复现结果。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `VIDEO` | 带有同步对白和声音的生成视频，采用输入图像的宽高比。 | VIDEO |
