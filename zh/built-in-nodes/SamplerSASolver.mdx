SamplerSASolver 节点为扩散模型创建并配置自定义采样器。它使用 `sa_solver` 采样算法，并带有可配置的预测-校正方案和随机微分方程（SDE）设置，返回一个可接入采样节点的采样器对象。`sde_start_percent` 和 `sde_end_percent` 的值会使用所连接模型的采样调度转换为 sigma 值，以定义应用随机成分的区间。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 使用其采样调度来构建采样器的扩散模型 | MODEL | 是 | - |
| `eta` | 控制 SDE 求解器的步长缩放因子（默认值：1.0） | FLOAT | 否 | 0.0 - 10.0 |
| `SDE 起始百分比` | 采样过程中随机（SDE）成分开始的起始百分比；使用模型调度转换为 sigma 值（默认值：0.2） | FLOAT | 否 | 0.0 - 1.0 |
| `SDE 结束百分比` | 采样过程中随机（SDE）成分停止的结束百分比；使用模型调度转换为 sigma 值（默认值：0.8） | FLOAT | 否 | 0.0 - 1.0 |
| `s_noise` | 控制采样期间添加的噪声量（默认值：1.0） | FLOAT | 否 | 0.0 - 100.0 |
| `预测器阶数` | 求解器中预测器成分的阶数（默认值：3） | INT | 否 | 1 - 6 |
| `校正器阶数` | 求解器中校正器成分的阶数（默认值：4） | INT | 否 | 0 - 6 |
| `使用 PECE` | 启用 PECE（预测-评估-校正-评估）方法（默认：禁用） | BOOLEAN | 否 | - |
| `简单二阶` | 启用简化的二阶计算（默认：禁用） | BOOLEAN | 否 | - |

所有可选输入在界面中均标记为高级。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `sampler` | 一个已配置的采样器对象（使用 `sa_solver` 算法），可供采样节点使用 | SAMPLER |
