SamplerSASolver 节点实现了扩散模型的自定义采样算法。它采用预测-校正方法，配合可配置的阶数设置和随机微分方程（SDE）参数，从输入模型生成样本。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 用于采样的扩散模型 | MODEL | 是 | - |
| `eta` | 控制步长缩放因子（默认：1.0） | FLOAT | 否 | 0.0 - 10.0 |
| `SDE 起始百分比` | SDE 采样的起始百分比（默认：0.2） | FLOAT | 否 | 0.0 - 1.0 |
| `SDE 结束百分比` | SDE 采样的结束百分比（默认：0.8） | FLOAT | 否 | 0.0 - 1.0 |
| `s_noise` | 控制采样期间添加的噪声量（默认：1.0） | FLOAT | 否 | 0.0 - 100.0 |
| `预测器阶数` | 求解器中预测器组件的阶数（默认：3） | INT | 否 | 1 - 6 |
| `校正器阶数` | 求解器中校正器组件的阶数（默认：4） | INT | 否 | 0 - 6 |
| `使用 PECE` | 启用或禁用 PECE（预测-评估-校正-评估）方法 | BOOLEAN | 否 | - |
| `简单二阶` | 启用或禁用简化的二阶计算 | BOOLEAN | 否 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `sampler` | 一个配置好的采样器对象，可用于扩散模型 | SAMPLER |
