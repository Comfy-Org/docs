Frame Interpolate 节点会在图像序列中的现有帧之间创建新帧，从而有效提高帧率。它使用 AI 模型预测中间帧的外观，可用于创建平滑的慢动作效果，或提升视频的流畅度。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `插值模型` | 用于生成中间帧的帧插值模型 | INTERP_MODEL | 是 | - |
| `图像` | 一批连续图像（帧），将在它们之间进行插值。至少需要 2 张图像。如果提供的帧少于 2 帧，该节点将原样返回输入图像。 | IMAGE | 是 | - |
| `倍数` | 帧数要乘以的倍数。例如，倍数为 2 会使帧数翻倍。（默认值：2） | INT | 是 | 2 到 16 |

**注意：** 该节点要求至少 2 个输入帧，并且 `multiplier` 至少为 2。如果任一条件不满足，输入图像将原样返回。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `IMAGE` | 一批新的图像，其中插值帧被插入到原始帧之间，从而形成更平滑的序列。输出帧总数为 `(number of input frames - 1) * multiplier + 1`。 | IMAGE |
