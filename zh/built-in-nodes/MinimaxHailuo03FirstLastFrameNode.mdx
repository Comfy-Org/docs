此节点使用 MiniMax H3 模型，根据首帧图像和可选的末帧图像生成视频。视频遵循所提供图像的宽高比；若提供了末帧，则视频从首帧开始向末帧动态过渡。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频生成的模型。选择模型后会显示其特定设置（提示词、分辨率、时长）。 | DYNAMIC_COMBO | 是 | "MiniMax H3" |
| `first_frame` | 视频的首帧图像。生成视频的宽高比遵循该图像。图像至少为 256x256 像素，且宽高比需在 0.4 到 2.5 之间。 | IMAGE | 是 | - |
| `last_frame` | 视频的可选末帧图像。提供后，视频将从首帧开始，以该图像结束。必须满足与 `first_frame` 相同的尺寸和宽高比要求。 | IMAGE | 否 | - |
| `seed` | 随机种子。使用相同种子和相同请求会得到相似但不保证完全一致的结果。包含“生成后控制”选项，可在每次生成后随机化种子。默认值：42。 | INT | 是 | 0 到 4294967295 |
| `watermark` | 是否向视频添加 AIGC 水印。这是一个高级参数。默认值：False。 | BOOLEAN | 是 | True<br />False |

### MiniMax H3 输入

当在 `model` 选择器中选择“MiniMax H3”时，会显示这些输入。

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 用于视频生成的文本提示词。必须至少包含一个非空白字符。 | STRING | 是 | - |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | "768P"<br />"2K" |
| `duration` | 输出视频的时长（秒），范围为 4-15。默认值：5。 | INT | 是 | 4 到 15 |

**关于约束的说明：**
- `model` 下拉框中的文本提示词不能为空；仅包含空白字符的提示词会被拒绝。
- 任何提供的帧图像（`first_frame` 以及（如果使用）`last_frame`）必须至少为 256 像素宽和 256 像素高，且宽高比需在 0.4 到 2.5 之间（约为 2:5 到 5:2）。
- `last_frame` 是可选的。省略时，视频将仅根据首帧生成。
- 输出视频的宽高比由提供的图像决定，不由单独的比例设置决定。
