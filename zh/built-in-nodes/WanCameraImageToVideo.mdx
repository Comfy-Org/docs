WanCameraImageToVideo 节点用于根据图像准备视频生成所需的条件数据和潜空间数据。它接收正向和负向条件提示词，以及可选的起始图像和可选相机控制，输出修改后的条件数据以及一个可供视频模型填充的空潜空间张量。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `正面提示词` | 用于视频生成的正向条件提示词 | CONDITIONING | 是 | - |
| `负面提示词` | 视频生成中需要避免的负向条件提示词 | CONDITIONING | 是 | - |
| `VAE` | 用于将图像编码到潜空间的 VAE 模型 | VAE | 是 | - |
| `宽度` | 输出视频宽度（像素）（默认值：832，步长：16） | INT | 是 | 16 至 MAX_RESOLUTION |
| `高度` | 输出视频高度（像素）（默认值：480，步长：16） | INT | 是 | 16 至 MAX_RESOLUTION |
| `长度` | 视频序列中的帧数（默认值：81，步长：4） | INT | 是 | 1 至 MAX_RESOLUTION |
| `批次大小` | 同时生成的视频数量（默认值：1） | INT | 是 | 1 至 4096 |
| `CLIP视觉输出` | 可选的 CLIP 视觉输出，用于额外的条件控制 | CLIP_VISION_OUTPUT | 否 | - |
| `起始图像` | 可选的起始图像，用于初始化视频序列。提供时，视频的前几帧将基于该图像生成，并应用蒙版将起始帧与生成内容混合。图像会被调整大小以匹配指定的宽度和高度。 | IMAGE | 否 | - |
| `相机条件` | 可选的相机嵌入条件，用于视频生成。提供时，这些条件会同时应用到正向和负向条件数据中。 | WAN_CAMERA_EMBEDDING | 否 | - |

**注意：** 当提供 `start_image` 时，仅使用输入图像的前 `length` 帧来初始化视频序列，并且节点会应用蒙版将这些起始帧与生成内容混合。`camera_conditions` 和 `clip_vision_output` 参数是可选的，但提供时，它们会同时修改正向和负向提示词的条件数据。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `正面提示词` | 修改后的正向条件数据，包含应用的相机条件、CLIP 视觉输出和/或起始图像数据 | CONDITIONING |
| `负面提示词` | 修改后的负向条件数据，包含应用的相机条件、CLIP 视觉输出和/或起始图像数据 | CONDITIONING |
| `潜空间` | 生成的空视频潜空间表示，用于视频模型。潜空间张量的维度为 [batch_size, 16, frames, height/8, width/8]，其中 frames 的计算方式为 ((length - 1) // 4) + 1。 | LATENT |
