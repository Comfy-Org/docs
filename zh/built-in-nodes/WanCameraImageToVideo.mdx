WanCameraImageToVideo 节点用于为基于图像的相机控制视频生成准备条件和潜空间数据。它接收正向和负向条件提示，以及可选输入（如起始图像、CLIP 视觉输出和相机条件），并输出更新后的条件以及可供视频模型填充的空潜空间张量。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `正面提示词` | 用于视频生成的正向条件提示 | CONDITIONING | 是 | - |
| `负面提示词` | 用于视频生成中需要避免的负向条件提示 | CONDITIONING | 是 | - |
| `VAE` | 用于将图像编码到潜空间的 VAE 模型 | VAE | 是 | - |
| `宽度` | 输出视频宽度（像素）（默认值：832，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 输出视频高度（像素）（默认值：480，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `长度` | 视频序列中的帧数（默认值：81，步长：4） | INT | 是 | 1 to MAX_RESOLUTION |
| `批次大小` | 同时生成的视频数量（默认值：1） | INT | 是 | 1 到 4096 |
| `CLIP视觉输出` | 可选的 CLIP 视觉输出，用于附加条件 | CLIP_VISION_OUTPUT | 否 | - |
| `起始图像` | 可选的起始图像，用于初始化视频序列。当提供时，仅使用前 `length` 帧，并将图像调整为指定的 `width` 和 `height`。序列的起始帧会被编码到潜空间中，并应用掩码将起始帧与生成内容混合。 | IMAGE | 否 | - |
| `相机条件` | 用于视频生成的可选相机嵌入条件。当提供时，这些条件会同时应用于 `positive` 和 `negative` 条件。 | WAN_CAMERA_EMBEDDING | 否 | - |

**注意：** 当提供 `start_image` 时，节点会在 `positive` 和 `negative` 条件上设置 `concat_latent_image` 和 `concat_mask` 值。`camera_conditions` 和 `clip_vision_output` 参数是可选的，但提供后，它们会修改正向和负向提示的条件。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 修改后的正向条件，已应用相机条件、CLIP 视觉输出和/或起始图像数据 | CONDITIONING |
| `negative` | 修改后的负向条件，已应用相机条件、CLIP 视觉输出和/或起始图像数据 | CONDITIONING |
| `latent` | 用于视频模型的空视频潜空间表示。该潜空间张量的维度为 [batch_size, 16, frames, height/8, width/8]，其中 frames 的计算方式为 ((length - 1) // 4) + 1。 | LATENT |
