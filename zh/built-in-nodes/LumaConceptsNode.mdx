保存一个或多个相机概念，用于 Luma 文本转视频和 Luma 图像转视频节点。此节点允许您选择最多四个相机概念，并可选择将其与现有概念链组合。

**注意：** 此节点在源代码中已被标记为弃用。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `概念1` | 从可用 Luma 概念中选择第一个相机概念 | STRING | 是 | 提供多个选项<br />包含"None"选项 |
| `概念2` | 从可用 Luma 概念中选择第二个相机概念 | STRING | 是 | 提供多个选项<br />包含"None"选项 |
| `概念3` | 从可用 Luma 概念中选择第三个相机概念 | STRING | 是 | 提供多个选项<br />包含"None"选项 |
| `概念4` | 从可用 Luma 概念中选择第四个相机概念 | STRING | 是 | 提供多个选项<br />包含"None"选项 |
| `Luma概念` | 可选的相机概念，用于添加到此节点选择的相机概念中 | LUMA_CONCEPTS | 否 | 不适用 |

**注意：** 如果不需要使用全部四个概念槽位，所有概念参数（`concept1` 至 `concept4`）均可设置为"None"。此节点会将任何提供的 `luma_concepts` 与所选概念合并，以创建组合的概念链。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `Luma概念` | 包含所有选定概念的组合相机概念链 | LUMA_CONCEPTS |
