Vidu Q3 文生视频节点可根据文本描述生成视频。它使用 Vidu Q3 Pro 或 Q3 Turbo 模型，根据您的提示词生成视频内容，并允许您控制视频的时长、分辨率、宽高比以及是否包含音频。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 用于视频生成的模型。选择模型后会显示额外的配置参数，包括宽高比、分辨率、时长和音频。 | DYNAMIC_COMBO | 是 | `"viduq3-pro"`<br />`"viduq3-turbo"` |
| `prompt` | 用于视频生成的文本描述，最大长度为 2000 个字符。 | STRING | 是 | 不适用 |
| `seed` | 用于控制生成随机性的种子值（默认值：1）。 | INT | 是 | 0 到 2147483647 |

### viduq3-pro 和 viduq3-turbo 输入

以下配置参数由 `viduq3-pro` 和 `viduq3-turbo` 模型共用。

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | 输出视频的宽高比。 | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"3:4"`<br />`"4:3"`<br />`"1:1"` |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | `"720p"`<br />`"1080p"` |
| `duration` | 输出视频的时长（秒）（默认值：5）。 | INT | 是 | 1 到 16 |
| `audio` | 启用后，输出带有声音（包括对话和音效）的视频（默认值：False）。 | BOOLEAN | 是 | True/False |

**注意：** 一旦选择了 `model`，参数 `aspect_ratio`、`resolution`、`duration` 和 `audio` 即为必填项，因为它们是模型配置的一部分。`prompt` 不能为空，且不能超过 2000 个字符。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `video` | 生成的视频文件。 | VIDEO |
