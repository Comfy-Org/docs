SenseNova Sampling Options 用于在模型上设置 SenseNova flow shift。它会克隆输入模型，使用所选的 flow shift 值附加 SenseNova 模型采样配置，并返回修补后的模型，供采样过程中使用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|------|------|---------|------|------|
| `model` | 要应用 SenseNova flow shift 采样配置的模型。 | MODEL | 是 | - |
| `shift` | 在 SenseNova 模型采样上设置的 flow shift 值（默认值：3.0；UI 步长：0.01）。 | FLOAT | 是 | 未定义最小值或最大值 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|---------|------|---------|
| `MODEL` | 应用了 SenseNova flow shift 采样配置的输入模型克隆。 | MODEL |
