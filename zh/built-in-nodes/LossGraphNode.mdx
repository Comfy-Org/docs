LossGraphNode 创建训练损失值随训练步数变化的折线图，并将其显示为预览图像。它从训练节点读取损失值，将其绘制到带有轴标签以及最小/最大损失值的图表上，并在 UI 中返回该图表作为图像预览。此节点被标记为实验性节点，并且是一个输出节点。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `损失` | 来自训练节点的损失映射。它必须包含一个 `loss` 键，其值为数值型损失值列表。 | LOSS_MAP | 是 | - |
| `文件名前缀` | 保存的损失图表图像的前缀。（默认值："loss_graph"） | STRING | 是 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `ui.images` | 生成的损失图表图像，以预览形式显示。 | IMAGE |
