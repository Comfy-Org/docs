CLIPMergeAdd 节点通过将第二个模型中的补丁添加到第一个模型来合并两个 CLIP 模型。该节点会创建第一个 CLIP 模型的副本，并选择性地整合第二个模型中的关键补丁，同时排除位置 ID 和 logit scale 参数。这样，您可以在保留基础模型结构的同时合并 CLIP 模型组件。

## 输入
| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `clip1` | 作为合并基础的基础 CLIP 模型，将被克隆并使用 | CLIP | 是 | - |
| `clip2` | 提供要添加到基础模型的关键补丁的辅助 CLIP 模型 | CLIP | 是 | - |

## 输出
| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `CLIP` | 合并后的 CLIP 模型，包含基础模型结构以及来自辅助模型的附加补丁 | CLIP |
