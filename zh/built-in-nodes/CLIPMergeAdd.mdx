CLIPMergeAdd 节点通过将第二个模型的补丁添加到第一个模型中来组合两个 CLIP 模型。它会创建第一个 CLIP 模型的副本，并有选择地融入第二个模型中的关键补丁，同时排除位置 ID 和 logit scale 参数。这样，您就可以在保留基础模型结构的同时合并 CLIP 模型组件。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 取值范围 |
| --- | --- | --- | --- | --- |
| `clip1` | 基础 CLIP 模型，将被克隆并作为合并的基础 | CLIP | 是 | - |
| `clip2` | 次要 CLIP 模型，提供要添加到基础模型中的关键补丁 | CLIP | 是 | - |

来自 `clip2` 的以 `.position_ids` 或 `.logit_scale` 结尾的键会被跳过，因此这些参数将保留 `clip1` 中的值。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `CLIP` | 合并后的 CLIP 模型，包含基础模型结构以及从次要模型添加的补丁 | CLIP |
