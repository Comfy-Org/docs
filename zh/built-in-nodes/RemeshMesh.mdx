Remesh Mesh 通过在原始表面周围采样窄带距离场，并使用 Dual Contouring 提取，以干净、均匀的细分方式重建网格。此操作可规范化杂乱、非流形或自交的拓扑结构，并且应在 Decimate Mesh 之前运行，以达到精确的面数。处理过程在活动计算设备上运行，输出网格保持焊接状态。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `网格` | 要重新网格化的输入网格。 | MESH | 是 | — |
| `分辨率` | 体素网格分辨率（输出密度）。256 约 10 万面，512 约 100 万面。如需精确面数，请随后使用 Decimate Mesh。（默认值：512） | INT | 是 | 32 - 2048 |
| `符号模式` | 表面提取模式。"udf" 对杂乱/非流形输入具有鲁棒性；"sdf" 通过 QEF（二次误差函数）锐利特征恢复生成干净的单一表面，但需要一致的环绕方向。选择模式后会显示其特定的子选项。（默认值："udf"） | DYNAMIC_COMBO | 是 | "udf"<br />"sdf" |
| `带宽` | 窄带宽度（以体素为单位）。在 UDF 模式下还会偏移表面。（高级，默认值：1.0） | FLOAT | 是 | 0.5 - 4.0 |
| `project_back` | 将顶点线性插值到原始表面（0 = 纯 DC，1 = 完全贴合）。（高级，默认值：0.0） | FLOAT | 是 | 0.0 - 1.0 |
| `fix_poles` | 折叠价数为 3 的顶点对（DC T 型连接伪影）。（高级，默认值：false） | BOOLEAN | 是 | true / false |
| `smooth_iters` | Taubin 平滑迭代次数（0 = 关闭）。2-3 次可清除 DC 阶梯状伪影；更高会过度平滑 QEF 边缘。（默认值：0） | INT | 是 | 0 - 20 |
| `drop_small_components` | 删除低于最大组件面数此比例的组件。0 表示禁用。（高级，默认值：0.01） | FLOAT | 是 | 0.0 - 0.5 |
| `precluster_max_verts` | 在字段查询前限制输入顶点数；高于此值的输入会先被聚类抽取到此上限。防止巨大网格上出现内存不足。（高级，默认值：20,000,000） | INT | 是 | 0 - 100,000,000 |

### "udf" 模式输入

当 `sign_mode` 设置为 `"udf"` 时，显示以下参数。

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `qef` | 使用 QEF（二次误差函数）双顶点放置以获得更锐利的边缘。（默认值：false） | BOOLEAN | 否 | true / false |
| `drop_inverted_components` | 删除向内法线（负体积）的闭合组件——即 UDF 内壳。（默认值：false） | BOOLEAN | 否 | true / false |
| `drop_enclosed_components` | 删除位于最大组件边界框内且未通过网格内部点射线投射检查的组件。对于合法的嵌套部分请禁用。（默认值：false） | BOOLEAN | 否 | true / false |

### "sdf" 模式输入

当 `sign_mode` 设置为 `"sdf"` 时，显示以下参数。

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `qef` | 使用 QEF（二次误差函数）双顶点放置（可恢复锐利特征），而非跨边质心。（默认值：true） | BOOLEAN | 否 | true / false |
| `manifold` | 流形 Dual Contouring：每个体素生成 1-4 个双顶点以处理多薄片情况。速度较慢。（默认值：false） | BOOLEAN | 否 | true / false |

注意：`qef` 选项的默认值取决于所选模式——在 "udf" 模式下为 false，在 "sdf" 模式下为 true。当 `precluster_max_verts` 大于 0 且输入网格的顶点数超过该值时，网格会在字段查询前先被聚类抽取到该目标值。处理完成后，节点会显示输入到输出的面数变化（例如："faces: 1.23M → 200K (-84%)"）。

| 输出名称 | 描述 | 数据类型 |
