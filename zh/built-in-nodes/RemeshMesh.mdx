Remesh Mesh 通过在原曲面周围采样窄带距离场，并使用 Dual Contouring 提取，从而以干净、均匀的曲面细分重建网格。这可以规范化杂乱、非流形或自相交的拓扑结构，并应在运行 Decimate Mesh 之前执行，以达到精确的面数。处理在活动计算设备上运行，输出网格保持焊接状态。

## 输入
### 通用输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `网格` | 要重新网格化的输入网格。 | MESH | 是 | — |
| `分辨率` | 体素网格分辨率（输出密度）。256 对应约 10 万面，512 对应约 100 万面。如需精确面数，请随后使用 Decimate Mesh。（默认值：512） | INT | 是 | 32 - 2048 |
| `符号模式` | 用于表面提取的有符号距离模式。“udf”对杂乱/非流形输入具有鲁棒性；“sdf”可通过 QEF（二次误差函数）恢复尖锐特征，生成干净的单一表面，但需要一致的绕序。选择模式后会显示其特定的子选项。（默认值：“udf”） | DYNAMIC_COMBO | 是 | “udf”<br />“sdf” |
| `带宽` | 以体素为单位的窄带宽度。在 UDF 模式下还会偏移表面。（高级，默认值：1.0） | FLOAT | 是 | 0.5 - 4.0 |
| `project_back` | 将顶点线性插值回原始表面（0 = 纯 DC，1 = 吸附）。（高级，默认值：0.0） | FLOAT | 是 | 0.0 - 1.0 |
| `fix_poles` | 折叠价数为 3 的顶点对（DC T 型连接伪影）。（高级，默认值：false） | BOOLEAN | 是 | true / false |
| `smooth_iters` | Taubin 平滑迭代次数（0 = 关闭）。2-3 次可清除 DC 阶梯状伪影；更高次数会过度平滑 QEF 边缘。（默认值：0） | INT | 是 | 0 - 20 |
| `drop_small_components` | 丢弃面数低于最大组件面数该比例的组件。0 表示禁用。（高级，默认值：0.01） | FLOAT | 是 | 0.0 - 0.5 |
| `precluster_max_verts` | 在字段查询之前限制输入顶点数；超过此值的输入会先被聚类抽取到此上限。可防止巨大网格上的内存不足（OOM）。（高级，默认值：20,000,000） | INT | 是 | 0 - 100,000,000 |

### “udf” 模式输入

当 `sign_mode` 设置为 `"udf"` 时，显示以下参数。

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `qef` | 使用 QEF（二次误差函数）对偶顶点放置以获取更锐利的边缘。（默认值：false） | BOOLEAN | 否 | true / false |
| `drop_inverted_components` | 丢弃内向法线（负体积）的闭合组件——即 UDF 内壳。（默认值：false） | BOOLEAN | 否 | true / false |
| `drop_enclosed_components` | 丢弃位于最大组件包围盒内但未通过网格内点射线测试的组件。对于合法的嵌套零件，请禁用此选项。（默认值：false） | BOOLEAN | 否 | true / false |

### “sdf” 模式输入

当 `sign_mode` 设置为 `"sdf"` 时，显示以下参数。

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `qef` | 使用 QEF（二次误差函数）对偶顶点放置（可恢复尖锐特征），而非使用边交叉质心。（默认值：true） | BOOLEAN | 否 | true / false |
| `manifold` | 流形 Dual Contouring：针对多薄片情况为每个体素生成 1-4 个对偶顶点。速度较慢。（默认值：false） | BOOLEAN | 否 | true / false |

注意：`qef` 选项的默认值因所选模式而异——在“udf”模式下为 false，在“sdf”模式下为 true。当 `precluster_max_verts` 大于 0 且输入网格的顶点数超过该值时，网格会在字段查询之前被聚类抽取到该目标值。处理完成后，节点会在节点上显示输入到输出的面数变化（例如，“faces: 1.23M → 200K (-84%)”）。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `网格` | 具有均匀曲面细分和焊接拓扑的重新网格化网格。如果输入带有顶点色，则会保留；任何 UV、法线和切线均不会保留。 | MESH |
