Tripo P1：图像转模型使用 Tripo P1 API 将单个 2D 图像转换为 3D 模型。该节点针对生成低多边形、可直接用于游戏的网格进行了优化，并允许您选择仅几何体网格或带 PBR 贴图的纹理模型。最终生成的模型以 GLB 文件格式返回。

## 输入

### 通用输入

这些参数始终可用。

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `输出模式` | 选择结果类型。“Geometry only”返回未带纹理的网格；“Textured”会添加颜色和 PBR 贴图，并显示额外的纹理设置。 | DYNAMIC_COMBO | 是 | `"Geometry only"`<br />`"Textured"` |
| `图像` | 用于生成 3D 模型的源 2D 图像。该节点需要单个图像，若未提供则会报错。 | IMAGE | 是 | - |
| `启用图像自动修复` | 对输入图像进行预处理，以提高生成质量。（默认值：False） | BOOLEAN | 否 | True<br />False |
| `面数限制` | 目标面数，范围为 48-20000。-1 表示让 Tripo 自动选择。（默认值：-1） | INT | 否 | -1 到 20000 |
| `模型种子` | 用于几何体生成的种子，以便结果可重现。（默认值：42） | INT | 否 | 0 到 2147483647 |
| `自动缩放` | 将输出缩放为近似真实世界的米制尺寸。（默认值：False） | BOOLEAN | 否 | True<br />False |
| `导出 UV` | 在生成过程中进行 UV 展开。对于仅几何体的运行可关闭，以加快速度。（默认值：True） | BOOLEAN | 否 | True<br />False |
| `压缩几何体` | 应用 meshopt 几何压缩（EXT_meshopt_compression）。文件更小，但 ComfyUI 的 3D 预览无法显示它们；编辑前请先解压缩。（默认值：False） | BOOLEAN | 否 | True<br />False |

### 纹理输入

当 `output_mode` 设置为“Textured”时，会显示这些参数。“Geometry only”模式没有额外参数。

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `pbr` | 包含 PBR 贴图。开启后，基础纹理也会被强制启用。（默认值：True） | BOOLEAN | 否 | True<br />False |
| `texture_quality` | 纹理分辨率级别。“detailed”表示高清纹理，“extreme”表示 8K 超高清纹理。（默认值：`"standard"`） | COMBO | 否 | `"standard"`<br />`"detailed"`<br />`"extreme"` |
| `texture_alignment` | 优先保持与源图像的视觉相似度，还是与网格几何体对齐。（默认值：`"original_image"`） | COMBO | 否 | `"original_image"`<br />`"geometry"` |
| `orientation` | 旋转输出以匹配源图像。仅在启用纹理时生效。（默认值：`"default"`） | COMBO | 否 | `"default"`<br />`"align_image"` |
| `texture_seed` | 用于纹理生成的种子，以便纹理化结果可重现。（默认值：42） | INT | 否 | 0 到 2147483647 |

注意：当 `output_mode` 为“Geometry only”时，该请求会禁用纹理处理。在“Textured”模式下，始终会请求颜色纹理；关闭 `pbr` 会移除 PBR 贴图，但保留基础颜色纹理，而开启 `pbr` 也会强制启用基础纹理。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `模型文件` | 生成的 3D 模型结果。仅为向后兼容保留。 | STRING |
| `模型任务 ID` | Tripo API 为已完成的生成任务返回的唯一任务 ID。 | MODEL_TASK_ID |
| `GLB` | 以 GLB 格式生成的 3D 模型。 | FILE3DGLB |
