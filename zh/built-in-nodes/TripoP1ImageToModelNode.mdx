Tripo P1: Image to Model 使用 Tripo P1 API 将单张 2D 图像转换为 3D 模型。它针对生成低多边形、游戏就绪的网格进行了优化，并允许你在仅几何体网格或带 PBR 贴图的纹理模型之间进行选择。完成的模型以 GLB 文件形式返回。

## 输入

### 通用输入

这些参数始终可用。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `输出模式` | 选择结果类型。"Geometry only" 返回无纹理网格；"Textured" 添加颜色/PBR 贴图并显示额外的纹理设置。 | DYNAMIC_COMBO | 是 | `"Geometry only"`<br />`"Textured"` |
| `图像` | 用于生成 3D 模型的源 2D 图像。需要提供单张图像；如果未提供，节点会报错。 | IMAGE | 是 | - |
| `启用图像自动修复` | 对输入图像进行预处理，以获得更好的生成质量。（默认值：False） | BOOLEAN | 否 | True<br />False |
| `面数限制` | 目标面数，48-20000。-1 让 Tripo 自适应选择。（默认值：-1） | INT | 否 | -1 到 20000 |
| `模型种子` | 用于几何体生成的种子，以便结果可复现。（默认值：42） | INT | 否 | 0 到 2147483647 |
| `自动缩放` | 将输出缩放至接近真实世界的米制尺寸。（默认值：False） | BOOLEAN | 否 | True<br />False |
| `导出 UV` | 在生成期间进行 UV 展开。关闭可加快仅几何体运行速度。（默认值：True） | BOOLEAN | 否 | True<br />False |
| `压缩几何体` | 应用 meshopt 几何压缩（EXT_meshopt_compression）。文件更小，但 ComfyUI 的 3D 预览无法显示它们；编辑前请先解压。（默认值：False） | BOOLEAN | 否 | True<br />False |

### Geometry only 输入

没有其他参数。输出为无纹理网格。

### Textured 输入

当 `output_mode` 设置为 "Textured" 时，这些参数会出现。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `pbr` | 包含 PBR 贴图。开启时，基础纹理也会被强制开启。（默认值：True） | BOOLEAN | 是 | True<br />False |
| `texture_quality` | detailed = 高清纹理，extreme = 8K 超高清纹理。（默认值："standard"） | COMBO | 是 | `"standard"`<br />`"detailed"`<br />`"extreme"` |
| `texture_alignment` | 优先考虑与源图像的视觉保真度，或与网格几何体的对齐。（默认值："original_image"） | COMBO | 是 | `"original_image"`<br />`"geometry"` |
| `orientation` | 旋转输出以匹配源图像。仅在纹理模式下适用。（默认值："default"） | COMBO | 是 | `"default"`<br />`"align_image"` |
| `texture_seed` | 用于纹理生成的种子，以便纹理结果可复现。（默认值：42） | INT | 是 | 0 到 2147483647 |

注意：当 `output_mode` 为 "Geometry only" 时，请求中的纹理功能会被禁用。在 "Textured" 模式下，始终会请求颜色纹理；禁用 `pbr` 会移除 PBR 贴图，但保留基础颜色纹理，而启用 `pbr` 会同时强制开启基础纹理。`texture_alignment` 和 `orientation` 仅在 "Textured" 模式下可用。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model_file` | 一个包含生成的模型文件名的字符串（`<task_id>.glb`）。仅为向后兼容而保留。 | STRING |
| `model task_id` | Tripo API 为完成的生成任务返回的唯一任务 ID。 | MODEL_TASK_ID |
| `GLB` | 生成的 GLB 格式 3D 模型。 | FILE3DGLB |
