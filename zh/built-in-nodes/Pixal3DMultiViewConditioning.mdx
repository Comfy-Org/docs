Pixal3D Multi-View Conditioning 节点从固定的轨道相机 rig 构建条件数据：前、左、后、右四个视图彼此相隔 90 度，并完全按照取景构图使用。至少连接对象的一个方形视图，它就会为 Pixal3D 模型准备匹配的正向和负向条件。

### 说明

- 至少必须连接一个视图；如果四个视图输入均为空，节点会报错。
- 按 `front`、`left`、`back`、`right` 顺序，第一个连接的视图会被视为正面，网格会以该视图为正面摆姿势。如果第一个连接的视图不是 `front`，则会记录一条警告，说明网格将以该视图作为其正面来摆姿势。
- 视图按 `front`、`left`、`back`、`right` 的顺序读取，并以其相对于第一个连接视图的固定方位角放置在轨道上。
- 带 alpha 通道的输入视图会将 alpha 合成到黑色背景上。非 1024 x 1024 的视图会调整为 1024 x 1024。
- 批大小取自第一个连接的视图。如果连接的视图具有不同的批大小，则较小的视图会循环以匹配。
