使用 Kling 4.0 模型根据文本提示生成视频，并包含音频。此节点将提示和生成设置发送到 Kling API，等待任务完成，然后返回生成的视频。当你只需要根据描述创建片段、没有参考媒体时，可以使用此节点。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 模型选择器。`"kling-4.0"` 支持最高 1080p 和 30 秒；`"kling-4.0-flash"` 限于 720p 和 20 秒。选择模型后会在下方显示其输入。 | DYNAMIC_COMBO | 是 | `"kling-4.0"`<br />`"kling-4.0-flash"` |

### kling-4.0 输入

当 `model` 设置为 `"kling-4.0"` 时，会显示这些输入。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要生成的视频的文本描述。长度必须在 1 到 26000 个字符之间。 | STRING | 是 | 1 到 26000 个字符 |
| `resolution` | 输出视频的分辨率。默认：`"720p"`。 | COMBO | 是 | `"720p"`<br />`"1080p"` |
| `aspect_ratio` | 输出视频的宽高比。默认：`"16:9"`。 | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `duration` | 生成视频的长度（秒）。默认：5。 | INT | 是 | 3 到 30 |
| `seed` | 种子控制节点是否应重新运行；无论种子如何，结果都是不确定的。默认：42。 | INT | 是 | 0 到 2147483647 |

### kling-4.0-flash 输入

当 `model` 设置为 `"kling-4.0-flash"` 时，会显示这些输入。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要生成的视频的文本描述。长度必须在 1 到 26000 个字符之间。 | STRING | 是 | 1 到 26000 个字符 |
| `resolution` | 输出视频的分辨率。Flash 仅渲染 720p。默认：`"720p"`。 | COMBO | 是 | `"720p"` |
| `aspect_ratio` | 输出视频的宽高比。默认：`"16:9"`。 | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `duration` | 生成视频的长度（秒）。默认：5。 | INT | 是 | 3 到 20 |
| `seed` | 种子控制节点是否应重新运行；无论种子如何，结果都是不确定的。默认：42。 | INT | 是 | 0 到 2147483647 |
