使用 Kling 4.0 模型根据文本提示词生成带音频的视频。此节点会将提示词和生成设置发送至 Kling API，等待任务完成，然后返回生成的视频。当仅凭一段描述、没有任何参考媒体就需要创建视频片段时，请使用此节点。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 模型选择器。`"kling-4.0"` 支持最高 4K HDR 和 30 秒；`"kling-4.0-flash"` 仅限 720p 和 20 秒。选择模型后，其下方会显示相应的输入项。 | DYNAMIC_COMBO | 是 | `"kling-4.0"`<br />`"kling-4.0-flash"` |

### kling-4.0 输入

当 `model` 设置为 `"kling-4.0"` 时，会显示这些输入项。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要生成视频的文本描述。长度必须在 1 到 26000 个字符之间。 | STRING | 是 | 1 到 26000 个字符 |
| `resolution` | 输出视频的分辨率；名称中包含 `HDR` 的选项会返回 HDR 视频。默认：`"720p"`。 | COMBO | 是 | `"720p"`<br />`"1080p"`<br />`"4k"`<br />`"1080p HDR"`<br />`"4k HDR"` |
| `aspect_ratio` | 输出视频的宽高比。默认：`"16:9"`。 | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 生成视频的时长（秒）。默认：5。 | INT | 是 | 3 到 30 |
| `seed` | 种子控制节点是否应重新运行；无论种子为何，结果都是非确定性的。默认：42。 | INT | 是 | 0 到 2147483647 |

### kling-4.0-flash 输入

当 `model` 设置为 `"kling-4.0-flash"` 时，会显示这些输入项。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要生成视频的文本描述。长度必须在 1 到 26000 个字符之间。 | STRING | 是 | 1 到 26000 个字符 |
| `resolution` | 输出视频的分辨率。Flash 仅渲染 720p。默认：`"720p"`。 | COMBO | 是 | `"720p"` |
| `aspect_ratio` | 输出视频的宽高比。默认：`"16:9"`。 | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 生成视频的时长（秒）。默认：5。 | INT | 是 | 3 到 20 |
| `seed` | 种子控制节点是否应重新运行；无论种子为何，结果都是非确定性的。默认：42。 | INT | 是 | 0 到 2147483647 |
