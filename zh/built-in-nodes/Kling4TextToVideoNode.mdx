使用 Kling 4.0 模型根据文本提示生成视频，包含音频。此节点将提示和生成设置发送至 Kling API，等待任务完成，并返回生成的视频。适用于仅凭描述、无参考媒体即可创建片段的情况。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 模型选择器。仅 `"kling-4.0"` 可用；选择后会显示下方输入项。 | DYNAMIC_COMBO | 是 | `"kling-4.0"` |

### kling-4.0 输入

当 `model` 设置为 `"kling-4.0"` 时，将显示这些输入项。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要生成视频的文本描述。长度必须在 1 到 26000 个字符之间。 | STRING | 是 | 1 到 26000 个字符 |
| `resolution` | 输出视频的分辨率。默认值：`"720p"`。 | COMBO | 是 | `"720p"`<br />`"1080p"` |
| `aspect_ratio` | 输出视频的宽高比。默认值：`"16:9"`。 | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `duration` | 生成视频的时长（秒）。默认值：5。 | INT | 是 | 3 到 30 |
| `seed` | 种子控制节点是否应重新运行；无论种子如何，结果均具有不确定性。默认值：42。 | INT | 是 | 0 到 2147483647 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 生成的视频，任务完成后从提供商处下载。 | VIDEO |
