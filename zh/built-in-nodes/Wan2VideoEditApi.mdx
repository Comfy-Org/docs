Wan 2.7 视频编辑节点使用文本指令、参考图像或风格迁移来编辑视频。它将输入视频（以及任何参考图像）发送到 Wan 2.7 视频编辑服务，并根据所选分辨率、宽高比和时长设置返回新生成的视频。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频编辑的模型。每个选项都会公开自己的一组子参数。 | DYNAMIC_COMBO | 是 | `"wan2.7-videoedit"` |
| `video` | 要编辑的视频。 | VIDEO | 是 | - |
| `seed` | 用于生成的种子。（默认值：0） | INT | 是 | 0 到 2147483647 |
| `audio_setting` | 'auto'：模型根据提示决定是否重新生成音频。'origin'：保留输入视频中的原始音频。（默认值："auto"） | COMBO | 是 | `"auto"`<br />`"origin"` |
| `watermark` | 是否在结果中添加 AI 生成水印。（默认值：False） | BOOLEAN | 是 | - |

### wan2.7-videoedit 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 编辑指令或风格迁移要求。（默认值：空字符串） | STRING | 是 | - |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | `"720P"`<br />`"1080P"` |
| `ratio` | 宽高比。如果未更改，则近似为输入视频的宽高比。 | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 输出时长（秒）。'auto' 与输入视频时长匹配。指定值会从视频开头开始截断。（默认值："auto"） | COMBO | 是 | `"auto"`<br />`"2"`<br />`"3"`<br />`"4"`<br />`"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"` |

### 参考输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可增长插槽：连接 0 到 4 张图像（`image1`...`image4`）以引导编辑。对于 wan2.7-videoedit 模型，数量限制为 4。 | IMAGE | 否 | 0 到 4 项 |

**约束条件：**
*   `audio_setting` 和 `watermark` 是高级选项。
*   `prompt` 必须至少包含 1 个字符。
*   输入 `video` 的时长必须在 2 到 10 秒之间。
*   `reference_images` 可增长插槽最多接受 4 张图像。

|-------------|-------------|-----------|
