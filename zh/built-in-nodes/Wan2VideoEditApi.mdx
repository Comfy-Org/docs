Wan2VideoEditApi 节点使用 Wan 2.7 模型，根据文本指令、参考图像或风格迁移来编辑视频。它处理输入视频，并根据分辨率、时长和宽高比等指定参数生成新视频。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频编辑的模型。 | DYNAMIC_COMBO | 是 | `"wan2.7-videoedit"` |
| `video` | 要编辑的视频。 | VIDEO | 是 | - |
| `seed` | 用于生成的种子。(默认: 0) | INT | 是 | 0 到 2147483647 |
| `audio_setting` | 'auto'：模型根据提示词决定是否重新生成音频。'origin'：保留输入视频的原始音频。(默认: "auto") | COMBO | 是 | `"auto"`<br />`"origin"` |
| `watermark` | 是否在结果中添加 AI 生成的水印。(默认: False) | BOOLEAN | 是 | - |

### wan2.7-videoedit 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |

| `resolution` | 输出视频的分辨率。 | COMBO | 是 | `"720P"`<br />`"1080P"` |

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|

*   输入 `video` 的时长必须在 2 到 10 秒之间。
*   `reference_images` 可增长槽位最多接受 4 张图像。
