将 3D 身体姿态数据以可选样式渲染到图像中。该节点接受来自 SAM3D 身体追踪器（MHR）或外部 Y-up 骨骼（如 Kimodo）的姿态数据，并可将结果合成到可选背景图像上（未提供时为黑色画布）。可用的渲染样式包括着色 3D 网格、二值剪影、2D 和 3D OpenPose 风格骨架，以及 SCAIL 风格身体胶囊。

## 输入

### 说明

- 如果 `width` 和 `height` 都为 0，则输出使用姿态数据的原生图像尺寸。若仅设置其中一个，另一个按原始宽高比推导。已连接的 `background` 会被缩放以匹配渲染分辨率。
- 当连接 `camera_info` 时，姿态改为通过该相机重新投影，而不是使用预测相机。
- 在网格模式下，`rainbow_tilt_z` 和 `rainbow_tilt_x` 仅在 `shader` 设置为 "rainbow"、"rainbow_face_normal" 或 "rainbow_face_semantic" 时可用。
- 在网格模式下，当 `region` 为 "hands_only" 时，手部区域过滤要求姿态数据包含手部顶点掩码；若缺少该掩码，则渲染完整网格。
- 在 scail 模式下，手部始终以 2D 叠加层绘制；没有 3D 手部胶囊。
- 当输出分辨率与姿态数据的原生分辨率不同时，openpose_2d 的标记点和线段尺寸会按比例缩放。
- 如果背景帧数少于姿态数据帧数，则最后一帧背景会重复用于剩余帧。
- 输出为每个输入姿态帧生成一帧。如果姿态数据不包含任何帧，则返回一张黑色图像。
