此节点从 ComfyUI 输入目录中的所选子文件夹加载视频文件及其关联的文本描述，并将它们作为两个列表返回：视频和描述。视频条目是惰性引用，因此仅当下游节点需要时才解码帧。支持的格式包括 MP4、AVI、MOV、WEBM、MKV 和 FLV，同时支持带有重复计数前缀的嵌套文件夹（例如 `5_classname/`，如 kohya-ss/sd-scripts 等工具所使用的）。

## 输入
| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `文件夹` | 包含视频文件和 .txt 描述文件的文件夹。 | STRING | 是 | Combo: ComfyUI 输入目录中所有子文件夹的动态列表 |

如果所选文件夹中不包含任何具有受支持视频扩展名的文件，节点将引发错误。文件夹名称必须解析到 ComfyUI 输入目录内的位置；试图越出该目录的文件夹名称（例如使用 `..` 或绝对路径）也会引发错误。对于名称以数字开头后跟下划线的嵌套文件夹（例如 `5_classname`），该文件夹中的每个视频都会按此前缀指定的次数包含在数据集中。直接放在所选文件夹中的视频将包含一次。

## 输出
| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `视频` | 惰性视频引用；仅在下游需要时才解码帧。文件夹中找到的每个视频文件对应一个条目。 | VIDEO (list) |
| `文本` | 文本描述列表。每个视频对应一个描述；如果视频没有匹配的 `.txt` 文件，则其描述为空字符串。 | STRING (list) |
