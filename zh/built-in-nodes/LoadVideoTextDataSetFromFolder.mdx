此节点从 ComfyUI 输入目录内的选定子文件夹加载视频文件及其关联的文本描述，并作为两个列表返回：视频和描述。视频条目是惰性引用，因此仅在下游节点需要时才会解码帧。支持的格式包括 MP4、AVI、MOV、WEBM、MKV 和 FLV。带重复计数前缀的嵌套文件夹（例如 `5_classname/`，如 kohya-ss/sd-scripts 等工具使用的格式）同样受支持。

## 输入
| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `文件夹` | 包含视频文件和 .txt 描述的文件夹。 | STRING | 是 | Combo：ComfyUI 输入目录内所有子文件夹的动态列表 |

## 输出
| 输出名称 | 描述 | 数据类型 |
如果所选文件夹中没有受支持的视频扩展名的文件，节点将引发错误。对于名称以数字加下划线开头的嵌套文件夹（例如 `5_classname`），该文件夹中的每个视频都会按该前缀给定的次数包含在数据集中。
|-------------|-------------|-----------|
| `视频` | 惰性视频引用；仅在下游需要时才会解码帧。文件夹中找到的每个视频文件对应一个条目。 | VIDEO (list) |
| `文本` | 文本描述列表。每个视频对应一条描述；如果视频没有匹配的 `.txt` 文件，其描述为空字符串。 | STRING (list) |
