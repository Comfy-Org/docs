此节点从 ComfyUI 输入目录内的指定子文件夹加载视频文件及其对应的文本描述。它返回两个列表：懒加载视频引用（仅在后续需要时才解码帧）以及它们对应的描述。该节点支持常见的视频格式，如 MP4、AVI、MOV、WEBM、MKV 和 FLV，并且还可以处理具有重复计数前缀（例如 `5_classname/`）的嵌套文件夹结构，此类结构常用于 kohya‑ss/sd‑scripts 等工具。

## 输入
| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `文件夹` | 包含视频文件和 `.txt` 描述文件的子文件夹。从 ComfyUI 输入目录中的可用子文件夹中选择。 | STRING | 是 | Combo: dynamic list of all subdirectories inside the ComfyUI input folder |

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `视频` | 已加载视频文件的懒加载引用。仅当连接到下游处理节点时才会解码帧。每个元素对应输入文件夹中的一个视频。 | VIDEO (list) |
| `文本` | 文本描述列表，每个视频对应一个。如果视频没有匹配的 `.txt` 文件，其描述为空字符串。 | STRING (list) |
