Kandinsky5ImageToVideo 节点使用 Kandinsky 模型为视频生成准备 conditioning 和潜空间数据。它会创建一个空的视频潜张量，并可选地将起始图像编码，以引导生成视频的初始帧，相应修改正向和负向 conditioning。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `正面条件` | 用于引导视频生成的正向 conditioning 提示。 | CONDITIONING | 是 | N/A |
| `负面条件` | 用于引导视频生成远离某些概念的负向 conditioning 提示。 | CONDITIONING | 是 | N/A |
| `vae` | 用于将可选的起始图像编码到潜空间中的 VAE 模型。 | VAE | 是 | N/A |
| `宽度` | 输出视频的宽度（以像素为单位，默认值：768）。 | INT | 是 | 16 到 16384（步长 16） |
| `高度  ` | 输出视频的高度（以像素为单位，默认值：512）。 | INT | 是 | 16 到 16384（步长 16） |
| `时长` | 视频中的帧数（默认值：121）。 | INT | 是 | 1 到 16384（步长 4） |
| `批次大小` | 同时生成的视频序列数量（默认值：1）。 | INT | 是 | 1 到 4096 |
| `初始图象` | 可选的起始图像或帧批次。如果提供，则将其编码并用于替换模型输出潜变量的噪声起始部分。 | IMAGE | 否 | N/A |

**注意：** 提供 `start_image` 时，会自动使用双线性插值将其缩放到指定的 `width` 和 `height`。仅使用图像批次的前 `length` 帧进行编码；多余的帧将被忽略。如果图像批次的帧数少于 `length`，则仅使用这些帧。仅对图像的 RGB 通道进行编码。编码后的潜变量随后被注入到 `positive` 和 `negative` conditioning 中，以引导视频的初始外观，并且干净的编码帧会替换模型输出潜变量的噪声起始部分。

| 输出名称 | 描述 | 数据类型 |

| `负面条件` | 修改后的负向 conditioning，可能已更新为包含编码后的起始图像数据。 | CONDITIONING |
| `Latent` | 空的视频潜变量。一个填充为零的潜张量，其形状符合指定的尺寸。 | LATENT |
