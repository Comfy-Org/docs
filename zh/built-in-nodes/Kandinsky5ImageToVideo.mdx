Kandinsky5ImageToVideo 节点使用 Kandinsky 模型为视频生成准备条件数据和 latent 数据。它会创建按请求的 `width`、`height`、`length` 和 `batch_size` 设定尺寸的空视频 latent，并且可以选择性地对起始图像进行编码，通过更新 `positive` 和 `negative` 条件数据来引导生成视频的初始帧。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `正面条件` | 用于引导视频生成的正向条件提示。 | CONDITIONING | 是 | N/A |
| `负面条件` | 用于引导视频生成远离某些概念的负向条件提示。 | CONDITIONING | 是 | N/A |
| `vae` | 用于将可选起始图像编码到潜空间的 VAE 模型。 | VAE | 是 | N/A |
| `宽度` | 输出视频的宽度，以像素为单位（默认值：768）。 | INT | 是 | 16 到 16384 （步长：16） |
| `高度  ` | 输出视频的高度，以像素为单位（默认值：512）。 | INT | 是 | 16 到 16384 （步长：16） |
| `时长` | 视频的帧数（默认值：121）。 | INT | 是 | 1 到 16384 （步长：4） |
| `批次大小` | 同时生成的视频序列数量（默认值：1）。 | INT | 是 | 1 到 4096 |
| `初始图象` | 可选的起始图像或帧批次。如果提供，它会被编码并用于替换模型输出 latent 的噪声起始部分。 | IMAGE | 否 | N/A |

**注意：** 当提供 `start_image` 时，它会自动使用双线性插值调整大小，以匹配指定的 `width` 和 `height`。图像批次中仅前 `length` 帧用于编码；任何额外的帧都会被忽略。如果图像批次的帧数少于 `length`，则仅使用这些帧。仅图像的 RGB 通道会被编码。然后，编码后的 latent 会被注入到 `positive` 和 `negative` 条件数据中，以引导视频的初始外观，并且干净的编码帧会替换模型输出 latent 的噪声起始部分。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 修改后的正向条件数据，当提供 `start_image` 时，会使用编码后的起始图像数据更新。 | CONDITIONING |
| `negative` | 修改后的负向条件数据，当提供 `start_image` 时，会使用编码后的起始图像数据更新。 | CONDITIONING |
| `latent` | 空视频 latent。一个用零填充的 latent 张量，形状符合指定维度。 | LATENT |
| `cond_latent` | 干净的编码起始图像，用于替换模型输出 latent 的噪声起始部分。未提供 `start_image` 时为空。 | LATENT |
