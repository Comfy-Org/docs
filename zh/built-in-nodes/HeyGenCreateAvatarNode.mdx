从人物照片或描述要生成角色的文本提示创建可复用的 HeyGen 虚拟形象。生成的 `avatar_id` 可用于 HeyGen Avatar Video 节点，并应保存以供将来工作流复用。

## 输入
### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `来源` | 从文本提示生成新角色，或从连接的人物照片创建虚拟形象。 | DYNAMIC_COMBO | 是 | `"prompt"`<br />`"photo"` |

### 提示输入

当 `source` 设置为 `"prompt"` 时可用。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要生成的虚拟形象的描述（最多 1000 个字符）。必须至少包含 1 个非空白字符。默认值：空字符串。 | STRING | 是 | 1 到 1000 characters |

### 照片输入

当 `source` 设置为 `"photo"` 时可用。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `identity_photo` | 要转换为虚拟形象的人物照片。如果大于 2K，会自动缩小。 | IMAGE | 是 | Single image |

### 参考输入

当 `source` 设置为 `"prompt"` 时可用。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可增长插槽：连接最多 3 张图像（`ref_image_1`...`ref_image_3`）以引导生成的外观。如果图像大于 2K，会自动缩小。 | IMAGE | 否 | 0 到 3 images |

**注意：** `source` 参数用于在两种互斥模式之间切换。在 `"prompt"` 模式下，`prompt` 为必填项，并可选择连接最多 3 张参考图像。在 `"photo"` 模式下，`identity_photo` 为必填项。照片和参考图像大于 2K 时会自动缩小；不接受超过 3 张参考图像。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `avatar_id` | 虚拟形象外观 ID。将其传给 HeyGen Avatar Video 节点的 `custom_avatar_id`；保存它以便以后复用。 | STRING |
| `预览` | 生成虚拟形象的预览图。 | IMAGE |
