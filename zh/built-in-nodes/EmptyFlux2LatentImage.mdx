Empty Flux 2 Latent 节点创建一个空白、空的潜在表示。它生成一个填充为零的张量，作为 Flux 模型去噪过程的起始点。潜在的维度由输入的 `width` 和 `height` 决定，按 16 的因子缩小。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `width` | 要生成的最终图像的宽度。潜在宽度将是该值除以 16。默认值为 1024。 | INT | 是 | 16 到 8192 |
| `height` | 要生成的最终图像的高度。潜在高度将是该值除以 16。默认值为 1024。 | INT | 是 | 16 到 8192 |
| `batch_size` | 单个批次中要生成的潜在样本数量。默认值为 1。 | INT | 否 | 1 到 4096 |

**注意：** `width` 和 `height` 输入必须能被 16 整除，因为节点会在内部将它们除以该因子以创建潜在维度。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `samples` | 一个填充为零的潜在张量。形状为 `[batch_size, 128, height // 16, width // 16]`。 | LATENT |
