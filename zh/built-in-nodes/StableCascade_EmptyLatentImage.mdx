StableCascade_EmptyLatentImage 节点为 Stable Cascade 模型创建空的潜空间张量。它生成两个独立的潜空间表示——一个用于 stage C，另一个用于 stage B——其维度根据输入分辨率和压缩设置计算。此节点为 Stable Cascade 生成流程提供起点。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `宽度` | 输出图像的宽度（像素）（默认值：1024，步长：8） | INT | 是 | 256 to MAX_RESOLUTION |
| `高度` | 输出图像的高度（像素）（默认值：1024，步长：8） | INT | 是 | 256 to MAX_RESOLUTION |
| `压缩` | 决定 stage C 潜空间维度的压缩因子（默认值：42，步长：1）。这是一个高级参数。 | INT | 是 | 4 到 128 |
| `批量大小` | 一个批次中要生成的潜空间样本数量（默认值：1） | INT | 是 | 1 到 4096 |

注意：`compression` 值控制 stage C 潜空间尺寸：其高度和宽度分别是输入 `height` 和 `width` 除以 `compression`。stage B 潜空间始终使用固定压缩值 4。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `stage_c` | 具有维度 [batch_size, 16, height//compression, width//compression] 的 stage C 潜空间张量 | LATENT |
| `stage_b` | 具有维度 [batch_size, 4, height//4, width//4] 的 stage B 潜空间张量 | LATENT |
