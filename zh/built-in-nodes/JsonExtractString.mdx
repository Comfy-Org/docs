JsonExtractString 节点会扫描文本字符串中的第一个有效 JSON 对象，并提取与指定键关联的值，再将其转换为字符串。JSON 对象之前或之后的任何文本都会被忽略，因此该节点也适用于 Markdown 代码块，以及将 JSON 包裹在额外文字中的模型回复。如果未找到有效 JSON 对象、未找到该键，或值为 null，则该节点返回空字符串。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `json_string` | 要搜索 JSON 对象的文本。此字段支持多行输入，并且可以包含周围的说明文字或 Markdown 代码围栏。 | STRING | 是 | N/A |
| `key` | 要从 JSON 对象中提取其值的特定键。此字段仅支持单行输入。 | STRING | 是 | N/A |

**注意：** 该节点仅从 JSON 对象（字典）中提取值。它会按顺序尝试输入中的每个 `{`，并从第一个能够解码出有效 JSON 对象的位置开始解码，因此开头或结尾的文本会被跳过。如果无法解码出任何 JSON 对象，或其中不存在指定的键，则输出为空字符串。如果与该键关联的值为 `null`，该节点也会返回空字符串。非字符串值会以其字符串表示形式返回。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `output` | 从 JSON 中为指定键提取的字符串值；如果提取失败，则为空字符串。 | STRING |
