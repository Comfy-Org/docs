EmptySD3LatentImage 创建一个空白的（全零）潜空间图像，其布局符合 Stable Diffusion 3 模型的要求。由于该潜空间图像是空白的，它通常用作生成工作流的起点，由工作流用图像填充。您选择的 `width` 和 `height` 决定最终图像的尺寸。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `宽度` | 潜空间图像的宽度（以像素为单位）（默认值：1024）。数值以 16 为步长递增。 | INT | 是 | 16 to MAX_RESOLUTION （步长：16） |
| `高度` | 潜空间图像的高度（以像素为单位）（默认值：1024）。数值以 16 为步长递增。 | INT | 是 | 16 to MAX_RESOLUTION （步长：16） |
| `批量大小` | 批次中要生成的潜空间图像数量（默认值：1）。 | INT | 是 | 1 到 4096 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `LATENT` | 一个潜空间张量，包含空白（全零）样本，采用 SD3 兼容格式。该张量具有 16 个通道，相对于 `width` 和 `height` 缩小 8 倍，并带有 8 的空间下采样比率。 | LATENT |
