此节点使用 Qwen-Image 3.0 模型，根据文本提示编辑或组合最多 3 张参考图像。您提供文本提示和参考图像，节点将生成的结果作为一张或多张图像返回。

## 输入
| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的模型。此选择还包括文本提示、最多 3 个参考图像输入以及可选的负面提示。 | COMBO | 是 | "qwen-image-3.0-pro"<br />"qwen-image-3.0" |
| `size` | 输出分辨率。“match input” 复用第一张参考图像的尺寸，“auto” 让模型选择保持相同宽高比的尺寸，“custom” 设置明确的宽度和高度。 | COMBO | 是 | "match input"<br />"auto"<br />"custom" |
| `n` | 要生成的图像数量，作为批次返回。（默认值：1） | INT | 否 | 1 到 6 |
| `seed` | 用于生成的随机种子。（默认值：42） | INT | 否 | 0 到 2147483647 |
| `prompt_extend` | 是否使用 AI 辅助增强提示词。（默认值：True） | BOOLEAN | 否 | True<br />False |
| `watermark` | 是否在结果中添加 AI 生成的水印。（默认值：False） | BOOLEAN | 否 | True<br />False |

### 约束

- 文本提示为必填项，且必须至少包含一个字符。
- 最多支持 3 张参考图像；如果提供更多图像，则会引发错误（批量输入按每张图像计数一次）。
- 当 `size` 设置为 "custom" 时，必须提供明确的宽度和高度值，并经过验证。
- 当 `size` 设置为 "match input" 时，至少需要一张参考图像，因为会使用第一张参考图像的尺寸。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| IMAGE | 生成的一张或多张图像，以批次形式返回。最多返回 `n` 张图像。 | IMAGE |
