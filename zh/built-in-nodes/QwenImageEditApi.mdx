此节点使用 Qwen-Image 3.0 模型，在文本提示词的引导下编辑或组合最多 3 张参考图像。您选择一个模型，提供提示词和参考图像，节点返回一张或多张生成的图像。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的模型。此选择还包括文本提示词、最多 3 个参考图像输入以及可选的反向提示词。 | DYNAMIC_COMBO | 是 | "qwen-image-3.0-pro"<br />"qwen-image-3.0" |
| `size` | 输出分辨率。"match input" 复用第一张参考图像的尺寸，"auto" 让模型选择具有相同宽高比的尺寸，"custom" 设置明确的宽度和高度。 | DYNAMIC_COMBO | 是 | "match input"<br />"auto"<br />"custom" |
| `n` | 要生成的图像数量，以批次返回。（默认值：1） | INT | 否 | 1 到 6 |

### 约束

- 文本提示词为必需项，且必须至少包含一个字符。
- 最多支持 3 张参考图像；如果提供更多图像，则会引发错误（批次输入中每张图像计为一次）。
- 当 `size` 设置为 "custom" 时，必须提供明确的宽度和高度值，并且会对其进行验证：总像素面积必须介于 262,144（512x512）和 6,553,600（2560x2560）像素之间，宽高比必须介于 1:8 和 8:1 之间。
- 当 `size` 设置为 "match input" 时，至少需要一张参考图像，因为会使用第一张参考图像的尺寸；这些尺寸会被缩放以适配支持的面积和宽高比范围。
- 当 `size` 设置为 "auto" 时，模型会选择输出尺寸（1.9-4.2 百万像素），同时保留输入宽高比。
- 提示词引用使用 @Image1、@Image2、@Image3，按输入顺序编号；如果引用的索引高于已连接图像的数量，则会引发错误。标签仅在单词边界处识别，因此像 user@image1.com 这样的地址会保持不变。
- 输入参考图像在发送到 API 之前会被缩小到至多 2048x2048 像素。如果 PNG 编码超过 API 大小限制，则改用 JPEG 编码。
