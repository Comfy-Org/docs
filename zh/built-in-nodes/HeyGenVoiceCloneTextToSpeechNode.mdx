使用 HeyGen Voice 1.0，从一段单人说话录音中克隆声音，并用该声音朗读文本。此节点会上传录音、合成语音并以音频形式返回，因此仅凭一个节点即可完成从声音样本到成品语音的全过程。

选择 `model` 后会显示其专属参数：`audio`、`text`、`language`、`expressiveness_boost`、`recording_language`、`similarity`、`remove_background_noise` 和 `seed`。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的模型。`heygen-voice-1-turbo` 速度更快且成本更低（默认：`"heygen-voice-1"`）。 | DYNAMIC_COMBO | 是 | `"heygen-voice-1"`<br />`"heygen-voice-1-turbo"` |
| `audio` | 用于克隆的单人说话录音。请使用至少 10 秒的清晰语音；仅使用前 3 分钟。 | AUDIO | 是 | - |
| `text` | 要朗读的文本，最多 5000 个字符。超过约 12 分钟的语音会失败，因此请拆分超长的中文或日文文本（默认：空）。 | STRING | 是 | 1 到 5000 个字符 |
| `language` | 文本的语言。对于塞尔维亚语、马来语等自动检测容易混淆的相近语言，请手动设置（默认：`"auto"`）。 | COMBO | 是 | `"auto"`<br />多个语言预设 |
| `expressiveness_boost` | 数值越高表现力越强；数值越低越接近原始声音（默认：0.5）。 | FLOAT | 是 | 0.0 到 1.0（步长：0.05） |
| `recording_language` | 录音中所说的语言，可将克隆限定为该语言（默认：`"auto"`）。 | COMBO | 是 | `"auto"`<br />多个语言预设 |
| `similarity` | 声音与录音的接近程度（默认：`"max"`）。 | COMBO | 是 | `"medium"`<br />`"high"`<br />`"extra_high"`<br />`"max"` |
| `remove_background_noise` | 在克隆前清除录音中的背景噪声（默认：True）。 | BOOLEAN | 是 | `True`<br />`False` |
| `seed` | 种子控制节点是否重新运行；无论种子为何，结果都是非确定性的（默认：42）。 | INT | 是 | 0 到 2147483647 |

`text` 必须至少包含一个字符，且 `audio` 为必填项：包含多位说话人的录音，或噪声过大而无法克隆的录音，都会得到较差的音色。当样本语言不明显时，请设置 `recording_language`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `AUDIO` | 以克隆声音朗读的文本。 | AUDIO |
