从输入图像的一个区域中提取无缝平铺的 PBR 材质，并通过提示词指明要提取的内容：墙面、地板、织物。它返回提取出的基础纹理以及最多五张材质贴图，并可选择对贴图进行 SeedVR 放大。用它可将真实表面的照片转换为可复用、可平铺的材质。

### custom 图像尺寸输入

当 `image_size` 设置为 `"custom"` 时，会出现这些输入。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | 纹理宽度，单位为像素。默认：1024。 | INT | 是 | 512 到 2048 （步长：16） |
| `image_size.height` | 纹理高度，单位为像素。默认：1024。 | INT | 是 | 512 到 2048 （步长：16） |

**约束和行为：**

* 允许不启用任何材质贴图：此时节点仅返回基础纹理，并且每个贴图输出都保持为 1x1 占位符。
* 提示词为必填项且不能为空；请尽可能精确地命名要提取的区域。
* 8K 结果来自对 2048 像素渲染结果的贴图进行 4x 放大，而不是来自单次 8K 生成。
