ElevenLabs 文本转语音节点使用 ElevenLabs API 将书面文本转换为语音音频。您可以指定音色，并微调稳定性、语速和风格等语音特性，以生成自定义音频输出。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于文本转语音的模型。选择模型后会显示其特定参数。 | DYNAMIC_COMBO | 否 | `"eleven_multilingual_v2"`<br />`"eleven_v3"` |
| `voice` | 用于语音合成的音色。从音色选择器或即时音色克隆中连接。 | CUSTOM | 是 | 无 |
| `text` | 要转换为语音的文本。必须至少包含一个字符。 | STRING | 是 | 无 |
| `stability` | 语音稳定性。数值越低，情感范围越广；数值越高，语音越一致，但也可能显得单调（默认值：0.5）。 | FLOAT | 否 | 0.0 - 1.0 |
| `apply_text_normalization` | 文本规范化模式。“auto” 让系统自行决定，“on” 始终应用规范化，“off” 跳过规范化。 | COMBO | 否 | `"auto"`<br />`"on"`<br />`"off"` |
| `language_code` | ISO-639-1 或 ISO-639-3 语言代码（例如 “en”、“es”、“fra”）。留空表示自动检测（默认值：“”）。 | STRING | 否 | 无 |
| `seed` | 用于可复现性的种子（不保证确定性）（默认值：1）。 | INT | 否 | 0 - 2147483647 |
| `output_format` | 音频输出格式。 | COMBO | 否 | `"mp3_44100_192"`<br />`"opus_48000_192"` |

### eleven_multilingual_v2 输入

当 `model` 设置为 `"eleven_multilingual_v2"` 时，以下参数可用。

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `speed` | 语速。1.0 为正常语速，&lt;1.0 为慢速，>1.0 为快速（默认值：1.0）。 | FLOAT | 否 | 0.7 - 1.3 |
| `similarity_boost` | 相似度增强。数值越高，音色与原始声音越相似（默认值：0.75）。 | FLOAT | 否 | 0.0 - 1.0 |
| `use_speaker_boost` | 增强与原始说话人声音的相似度（默认值：False）。 | BOOLEAN | 否 | True / False |
| `style` | 风格夸张程度。数值越高，风格化表达越强，但可能会降低稳定性（默认值：0.0）。 | FLOAT | 否 | 0.0 - 0.2 |

### eleven_v3 输入

当 `model` 设置为 `"eleven_v3"` 时，以下参数可用。

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `speed` | 语速。1.0 为正常语速，&lt;1.0 为慢速，>1.0 为快速（默认值：1.0）。 | FLOAT | 否 | 0.7 - 1.3 |
| `similarity_boost` | 相似度增强。数值越高，音色与原始声音越相似（默认值：0.75）。 | FLOAT | 否 | 0.0 - 1.0 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `audio` | 文本转语音转换生成的音频。 | AUDIO |
