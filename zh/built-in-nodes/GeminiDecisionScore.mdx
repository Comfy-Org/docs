此节点为你连接的文本、图像、音频或视频按 1 到 10 打分，并返回分数以及一个在你设定的阈值处翻转的布尔值。可用它来过滤或排序输出，例如只保留分数至少为 7 的图像，并将 `result` 连接到 If/Else Switch 节点以据此执行操作。一次运行会对所连接的内容整体打分，因此若要逐张过滤图像，需要一次只对一张图像打分。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的模型（默认：`"gemini-decision-1"`）。 | COMBO | 是 | `"gemini-decision-1"` |
| `question` | 要评分的内容，并说明 1 和 10 分别代表什么（默认："Rate the technical quality of the image from 1 (worst) to 10 (best)."）。 | STRING | 是 | 1 到 5000 个字符 |
| `threshold` | 当分数至少达到该值时，`result` 为 true。干净、清晰的图像分数约为 7 到 8，严重损坏的图像约为 3 到 5（默认：6.0）。 | FLOAT | 是 | 1.0 到 10.0（步长：0.1） |
| `images` | 要评分的图像，通过可增长槽位（`image_1` ... `image_16`）最多可连接 16 张。批次图像中的每张图像各计一次。 | IMAGE | 否 | 最多 16 张图像 |
| `audio` | 要评分的音频片段。 | AUDIO | 否 | - |
| `video` | 要评分的视频片段。 | VIDEO | 否 | - |
| `text` | 问题所针对的文本，例如提示词或 LLM 回复，最多 20000 个字符。 | STRING | 否 | 最多 20000 个字符 |

至少连接 `text`、`images`、`audio` 或 `video` 中的一项；如果没有可评分的内容，节点会报错。连接多张图像时，请在问题中用 `image_1`、`image_2` 等名称来指代它们。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `result` | 当分数至少达到 `threshold` 时为 true，否则为 false。 | BOOLEAN |
| `score` | 1 到 10 的评分。 | FLOAT |
