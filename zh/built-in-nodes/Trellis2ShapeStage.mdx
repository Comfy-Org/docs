此节点用于设置 Trellis2 流水线的第一次形状生成采样阶段。它接收由 VaeDecodeStructureTrellis2 生成的稠密结构体素，提取已填充体素的稀疏坐标，创建空的稀疏潜在表示，并将采样元数据附加到 conditioning 上，以便模型在采样期间读取。对于上采样后的第二次形状阶段，请改用 Trellis2UpsampleStage，它将级联与第二阶段设置合并在一起。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `正面` | 要为此形状阶段准备的正向 conditioning。可以是标准的 Trellis2 conditioning，也可以是提供投影特征包的 Pixal3D conditioning；当存在投影特征时，会为所选阶段计算这些特征并附加到输出 conditioning。 | CONDITIONING | 是 | 任意 Trellis2 或 Pixal3D conditioning |
| `负面` | 要为此形状阶段准备的负向 conditioning。与正向 conditioning 一样，它也会附加相同的形状阶段元数据。 | CONDITIONING | 是 | 任意 Trellis2 或 Pixal3D conditioning |
| `体素` | 来自 VaeDecodeStructureTrellis2 的稠密结构体素。 | VOXEL | 是 | 任意体素网格；网格分辨率（每轴体素数）决定流水线阶段 |

### 备注

- 体素网格分辨率决定流水线阶段：分辨率小于或等于 32 时使用 `shape_generation_512` 模式和 `shape_512` 阶段；分辨率大于 32 时使用 `shape_generation` 模式和 `shape_1024` 阶段。
- 体素中必须至少包含一个已填充体素；空体素会引发错误。从体素中导出的批次索引必须为非负且连续。
- 当 `positive` conditioning 包含 `proj_feat_pack`（由 Pixal3D conditioning 提供）时，会为所选阶段计算投影特征，并将输出 latent 的模型帧设置为 `y_up`。否则，不附加投影特征，模型帧设置为 `z_up`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `正面` | 附加了形状阶段元数据的正向 conditioning，包括生成模式、稀疏坐标、每批坐标数量，以及当源 conditioning 提供时的投影特征。 | CONDITIONING |
| `负面` | 附加了相同形状阶段元数据的负向 conditioning。 | CONDITIONING |
| `latent` | 空的稀疏潜在张量（形状：批次大小、32、token 数量、1），以及提取的稀疏坐标、每批坐标数量、坐标分辨率、类型标记 `trellis2` 和模型帧方向。 | LATENT |
