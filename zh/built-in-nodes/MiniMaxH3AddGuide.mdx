此节点可将图像、短视频片段、音频或带音轨的视频片段锚定到 MiniMax H3 视频的任意选定帧。它会在指定帧索引处向 conditioning 添加一个引导关键帧，并且你可以串联多个此类节点，以在同一视频中锚定多个帧。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 附加引导关键帧的 conditioning。 | CONDITIONING | 是 | - |
| `latent` | 定义目标视频的 MiniMax H3 音视频 latent。必须是 MiniMax H3 AV latent（嵌套，包含两个 5D 张量，每个张量有 24 个通道）。 | LATENT | 是 | - |
| `frame_idx` | 锚定图像或片段第一帧的帧索引。负值从视频末尾倒数。（默认值：0） | INT | 是 | -9999 到 9999 |
| `vae` | 视频 VAE，当连接图像时需要。 | VAE | 否 | - |
| `audio_vae` | 音频 VAE，当连接音频时需要。 | VAE | 否 | - |
| `image` | 要锚定的图像或视频帧。多帧批次将作为片段锚定，并裁剪至模型的有效片段长度：5、22、39...（17k + 5）帧。少于 5 帧的批次仅使用第一张图像。 | IMAGE | 否 | - |
| `audio` | 要锚定的音轨，从同一帧索引开始，裁剪至视频的剩余时长。 | AUDIO | 否 | - |

**约束条件：**
- 必须提供 `image` 或 `audio` 中的至少一项；否则节点会引发错误。
- 当连接 `image` 时需要 `vae`。
- 当连接 `audio` 时需要 `audio_vae`。
- 少于 5 帧的 `image` 批次仅使用第一张图像；5 帧或以上的批次会裁剪至有效片段长度（5、22、39 等）。
- `frame_idx` 必须将引导置于视频的帧范围内，且多帧片段必须完全容纳在视频中；否则节点会引发错误。
- 当连接音频时，帧索引不能超过视频音轨的末尾。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `positive` | 添加了引导关键帧的 conditioning，其中包含解析后的帧索引，并在提供时包含编码后的图像或音频 latents。 | CONDITIONING |
