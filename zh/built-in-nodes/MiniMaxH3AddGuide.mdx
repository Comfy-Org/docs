此节点可将图像、短片段、音频，或带音轨的片段锚定到 MiniMax H3 视频的任意帧。它会在所选帧索引处向条件数据添加引导关键帧，并且你可以串联多个此类节点，以在同一视频中锚定多个帧。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `正向` | 引导关键帧所附加到的条件数据。 | CONDITIONING | 是 | - |
| `vae` | 视频 VAE，在连接图像时需要。 | VAE | 否 | - |
| `audio_vae` | 音频 VAE，在连接音频时需要。 | VAE | 否 | - |
| `潜空间` | 定义目标视频的 MiniMax H3 音视频 latent。必须是 MiniMax H3 AV latent（嵌套结构，包含两个 5D 张量，其中视频张量有 24 个通道）。 | LATENT | 是 | - |
| `image` | 要锚定的图像或视频帧。多帧批次会作为片段锚定，并裁剪到模型的有效片段长度：5、22、39...（17k + 5）帧。少于 5 帧的批次仅使用第一张图像。 | IMAGE | 否 | - |
| `audio` | 要从同一帧索引开始锚定的音轨，会裁剪到视频的剩余时长。 | AUDIO | 否 | - |
| `frame_idx` | 要锚定图像或片段第一帧的帧索引。负值从视频末尾计数。（默认：0） | INT | 是 | -9999 到 9999 |

**约束：**
- 必须至少提供 `image` 或 `audio` 之一；否则节点会报错。
- 连接 `image` 时，必须提供 `vae`。
- 连接 `audio` 时，必须提供 `audio_vae`。
- 少于 5 帧的 `image` 批次仅使用第一张图像；5 帧或更多帧的批次会裁剪到有效片段长度（5、22、39 等）。
- `frame_idx` 必须将引导放置在视频的帧范围内，且多帧片段必须完全位于视频内；否则节点会报错。
- 连接音频时，帧索引不得超出视频音轨的末尾。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `positive` | 已添加引导关键帧的条件数据，包含解析后的帧索引，并在提供时包含编码后的图像或音频 latent。 | CONDITIONING |
