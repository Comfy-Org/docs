在单个节点中把一组 LoRA 应用到扩散模型上。`loras` 的每一行保存一个 LoRA 文件、其强度以及一个开关，各行按从上到下的顺序应用，因此每一行都会在上方一行结果的基础上进行修改。当工作流需要向同一个模型应用一长串 LoRA 时，使用此节点，而不是串联多个单 LoRA 加载器。

## 输入

| 参数 | 说明 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 将要应用这些 LoRA 的扩散模型。 | MODEL | 是 | - |
| `loras` | 可增长的 LoRA 分组，按行顺序应用到模型（`loras.0`、`loras.1`，依此类推）。每个 LoRA 添加一行；每行包含一个文件、一个强度和一个开关。 | DYNAMIC_GROUP | 是 | 1 到 20 行 |

### `loras` 行字段

每一行都重复以下字段，且每个字段在提交的行中都是必填的。

| 参数 | 说明 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `lora_name` | 要应用的 LoRA 文件名称。 | COMBO | 是 | 多个可用选项 |
| `strength` | 此 LoRA 的应用强度。`0` 表示关闭，负值会反转效果。（默认：1.0） | FLOAT | 是 | -100 到 100 （步长：0.01） |
| `enabled` | 关闭后可在不改变其文件或强度的情况下跳过此 LoRA。（默认：true） | BOOLEAN | 是 | false / true |

### 参数约束

- **行数：** 至少必须提交一行，最多接受 20 行，因此最高行索引为 19。
- **跳过的行：** 当某一行的文件为空、`enabled` 处于关闭状态或 `strength` 为 `0` 时，该行会被跳过。负的强度会被照常传递，而不是被跳过。
- **行顺序：** 各行按出现的顺序应用，且每一行都以上一行返回的模型为起点。

## 输出

| 输出名称 | 说明 | 数据类型 |
| --- | --- | --- |
| `MODEL` | 已应用所有未被跳过的 LoRA 行后的扩散模型。 | MODEL |
