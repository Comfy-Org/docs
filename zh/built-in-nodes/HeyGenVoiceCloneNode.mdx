使用 HeyGen 的 Voice 1.0 引擎，从单人录音中克隆声音。此节点会上传录音、创建即时声音克隆、等待 HeyGen 完成处理，并返回 `voice_id`。可将该 ID 连接到 HeyGen Voice 1.0 Text to Speech，或作为 `custom_voice_id` 用于 HeyGen Avatar Video 和 HeyGen Talking Photo。创建克隆本身免费；仅按使用该声音生成的语音计费。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 单人录音。请使用至少 10 秒的清晰语音；仅使用前 3 分钟。 | AUDIO | 是 | N/A |
| `language` | 录音中使用的语言（默认值："auto"）。 | COMBO | 是 | `"auto"`<br />多个语言预设 |
| `similarity` | 声音与录音的相似程度（默认值："max"）。 | COMBO | 是 | `"medium"`<br />`"high"`<br />`"extra_high"`<br />`"max"` |
| `remove_background_noise` | 在克隆前清理录音中的背景噪声（默认值：True）。 | BOOLEAN | 是 | True<br />False |
| `seed` | 更改 `seed` 可重新克隆该录音；每次克隆都会生成略有差异的声音（默认值：42）。 | INT | 是 | 0 到 2147483647 |

**注意：** 该声音会以「ComfyUI Voice」的名称创建在你的 HeyGen 账户中，节点会在界面中打印 `voice_id`，方便你复制并复用。除非说话者使用的语言容易与其近亲语言混淆，否则请将 `language` 保持为 "auto"。`seed` 输入在界面中包含一个固定的 Control After Generate 控件，因此想要生成另一个克隆时请手动更改。

## 输出

| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `voice_id` | 克隆声音的 ID，可在 HeyGen Voice 1.0 Text to Speech 节点中复用，或用作 `custom_voice_id`。 | STRING |
