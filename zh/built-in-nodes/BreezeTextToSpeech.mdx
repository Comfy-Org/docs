使用 Breeze TTS 2 将文本转换为语音。选择一个 Breeze 音色，选择文本的语言，并可选地指定台词的演绎方式。英文和中文可以使用任一 Breeze TTS 2 模型；其他所有语言则使用 Breeze TTS 2 Multilingual。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `voice` | 用于朗读的 Breeze 音色，来自 Breeze Voice Selector 或任一 Breeze 音色创建节点。 | BREEZE_VOICE | 是 | - |
| `text` | 要朗读的文本，1 到 1000 个字符。诸如 `(laughs)` 或 `(sighs)` 的音频标签会被表演出来，而不会被读出。默认：空。 | STRING | 是 | 1 到 1000 个字符 |
| `language` | 文本的语言。英文和中文可以使用任一模型；其他语言则使用 Breeze TTS 2 Multilingual。音色在其自身语言中效果最佳，因此若要使用另一种语言，请使用通过 Breeze Voice Localize 制作的副本。 | DYNAMIC_COMBO | 是 | 提供多个选项 |
| `delivery` | 台词的演绎方式：`neutral` 保持音色原样，`directed` 遵循书面指令。默认：`"neutral"`。 | DYNAMIC_COMBO | 是 | `"neutral"`<br />`"directed"` |
| `speed` | 保持音高不变的语速倍率。默认：1.0。 | FLOAT | 否 | 0.5 到 2.0（步长：0.05） |
| `seed` | 控制节点是否重新运行；无论种子为何，结果都是非确定性的。默认：42。 | INT | 否 | 0 到 2147483647 |

### 语言 "English" 与 "Chinese" 输入

仅当 `language` 为 English 或 Chinese 时才会出现。

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | `Breeze TTS 2` 或 `Breeze TTS 2 Multilingual`。默认：`"Breeze TTS 2"`。 | COMBO | 是 | `"Breeze TTS 2"`<br />`"Breeze TTS 2 Multilingual"` |

### Delivery "neutral" 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `speaker_boost` | 让音色更接近其原始声音。默认：false。 | BOOLEAN | 否 | true<br />false |

### Delivery "directed" 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `instructions` | 如何演绎文本，需使用与文本相同的语言书写。默认：空。 | STRING | 否 | 多行文本 |
| `strength` | 音色遵循指令的强度。默认：4.0。 | FLOAT | 否 | 1.0 到 10.0（步长：0.1） |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `audio` | 生成的语音，格式为 WAV 音频。 | AUDIO |
