Kling 图像转视频节点使用起始图像作为第一帧生成短视频。它将图像与文本提示和生成设置相结合，然后返回生成的视频及其 ID 和时长。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `起始帧` | 用于生成视频的参考图像。图像必须至少为 300x300 像素，宽高比在 1:2.5 到 2.5:1 之间。 | IMAGE | 是 | - |
| `提示词` | 正向文本提示。不能为空。最多 500 个字符。 | STRING | 是 | - |
| `负面提示词` | 负向文本提示。最多 500 个字符。如果不用，请留空。 | STRING | 是 | - |
| `模型` | 用于视频生成的模型（默认：`"kling-v2-5-turbo"`）。 | COMBO | 是 | `"kling-v2-5-turbo"` |
| `CFG` | 控制视频跟随提示的紧密程度。数值越高表示遵循度越强（默认：0.8）。 | FLOAT | 是 | 0.0 到 1.0 |
| `模式` | 生成模式（默认：`"pro"`）。 | COMBO | 是 | `"pro"` |
| `宽高比` | 生成视频的宽高比（默认：`"16:9"`）。 | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"` |
| `时长` | 生成视频的时长（秒）（默认：`"5"`）。 | COMBO | 是 | `"5"`<br />`"10"` |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 生成的视频输出。 | VIDEO |
| `视频ID` | 生成的视频的唯一标识符。 | STRING |
| `时长` | 生成的视频的时长信息。 | STRING |
