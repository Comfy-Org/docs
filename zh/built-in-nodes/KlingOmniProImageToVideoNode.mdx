此节点使用 Kling AI 模型，根据文本提示和最多七张参考图像生成视频。您可以控制视频的长宽比、时长和分辨率，还可以选择使用故事板或生成音频。该节点将请求发送到外部 API，并返回生成的视频。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于视频生成的特定 Kling 模型（默认值：`"kling-v3-omni"`）。 | COMBO | 是 | `"kling-v3-omni"`<br />`"kling-video-o1"` |
| `提示词` | 描述视频内容的文本提示。可同时包含正面和负面描述。启用故事板时忽略。诸如 `@image` 或 `@video`（可选择编号）之类的占位符会自动转换为与 API 兼容的格式。长度必须在 1 到 2500 个字符之间（启用故事板时可为空）。 | STRING | 是 | 1 到 2500 个字符 |

### 故事板输入

启用 `storyboards` 后，每个选定的故事板片段都会出现以下输入。N 的范围从 1 到选定的故事板数量。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | 故事板片段 N 的提示。最多 512 个字符。 | STRING | 是 | 1 到 512 个字符 |
| `storyboard_N_duration` | 故事板片段 N 的时长（秒）（默认值：4）。 | INT | 是 | 1 到 15 |

**注意：** `reference_images` 输入最多接受 7 张图像。如果提供更多，节点将引发错误。每张图像都会验证最小尺寸和长宽比。

**模型特定约束：**
- `kling-video-o1` 不支持超过 10 秒的时长。
- `kling-video-o1` 不支持生成音频。
- `kling-video-o1` 不支持 4k 分辨率。
- `kling-video-o1` 不支持故事板。
