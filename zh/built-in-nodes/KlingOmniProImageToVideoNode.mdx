此节点使用 Kling AI 模型，根据文本提示词和最多七张参考图像生成视频。你可以控制视频的宽高比、时长和分辨率，并可选使用分镜或生成音频。该节点将请求发送到外部 API，并返回生成的视频。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |

| `提示词` | 描述视频内容的文本提示词。可包含正向和负向描述。启用分镜时忽略此项。诸如 `@image` 或 `@video`（可选带编号）的占位符会自动转换为 API 兼容格式。长度必须介于 1 到 2500 个字符之间（启用分镜时可为空）。 | STRING | 是 | 1 到 2500 个字符（启用 `storyboards` 时为 0 到 2500） |

### 分镜输入

启用 `storyboards` 时，每个选中的分镜片段都会出现以下输入。N 的范围从 1 到所选分镜的数量。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | 分镜片段 N 的提示词。最多 512 个字符。 | STRING | 是 | 1 到 512 个字符 |
| `storyboard_N_duration` | 分镜片段 N 的时长（秒）（默认：4）。 | INT | 是 | 1 到 15 |

**注意：** `reference_images` 输入最多接受 7 张图像。如果提供的图像更多，节点会报错。每张图像都会验证最小尺寸（300x300 像素）和宽高比（介于 1:2.5 和 2.5:1 之间）。

**特定模型约束：**
- `kling-video-o1` 不支持大于 10 秒的时长。
- `kling-video-o1` 不支持音频生成。
- `kling-video-o1` 不支持 4k 分辨率。
- `kling-video-o1` 不支持分镜。

**分镜约束：** 所有分镜片段的总时长必须等于全局 `duration` 值。如果总和不匹配，节点会报错。
