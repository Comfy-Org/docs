将 MOSS-Image 颜色/深度控制适配器的颜色区域图和深度图添加到条件化中。连接正向和负向条件化、一个 VAE 以及其中一张或两张图：这些图会被编码为潜在表示，合并为颜色/深度控制信号，并附加到条件化中，作用于你选择的采样部分。请与通过 LoRA 加载器加载的 MOSS-Image 控制适配器配合使用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 要附加控制信号的正向条件化。 | CONDITIONING | 是 | N/A |
| `negative` | 要附加控制信号的负向条件化。 | CONDITIONING | 是 | N/A |
| `vae` | 用于将图编码为潜在表示的 VAE。 | VAE | 是 | N/A |
| `color_map` | 每个区域一种纯色，尺寸为输出尺寸。颜色仅作为区域 ID。 | IMAGE | 否 | N/A |
| `depth_map` | 输出尺寸的深度图，近处为白色。 | IMAGE | 否 | N/A |
| `strength` | 缩放这些图对图像 token 的贡献。0.0 等同于不使用图，1.0 为训练强度（默认值：1.0）。 | FLOAT | 是 | 0.0 到 10.0 （步长：0.01） |
| `start_percent` | 控制开始的采样百分比（默认值：0.0）。 | FLOAT | 是 | 0.0 到 1.0 （步长：0.001） |
| `end_percent` | 控制结束的采样百分比。提前结束会保留布局和深度，而其余步骤会放松形状（默认值：1.0）。 | FLOAT | 是 | 0.0 到 1.0 （步长：0.001） |

**注意：** 至少连接 `color_map` 和 `depth_map` 中的一张；如果两者都没有，该节点会原样返回条件化。缺失的图会用零值替代，因此仅颜色和仅深度的设置都可以正常工作。当两张图尺寸不同时，较小的图会被放大到另一张图的尺寸。此节点在 ComfyUI 中标记为实验性功能。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `positive` | 已附加控制信号的正向条件化。 | CONDITIONING |
| `negative` | 已附加控制信号的负向条件化。 | CONDITIONING |
