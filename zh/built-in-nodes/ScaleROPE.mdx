ScaleROPE 节点允许你通过分别对 X、Y 和 T（时间）分量应用独立的缩放和偏移因子，来修改模型的旋转位置编码（ROPE）。这是一个高级实验性节点，用于调整模型的位置编码行为。

## 输入
| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 将修改其 ROPE 参数的模型。 | MODEL | 是 | - |
| `scale_x` | 应用于 ROPE 的 X 分量的缩放因子（默认值：1.0）。 | FLOAT | 是 | 0.0 - 100.0（步长 0.1） |
| `shift_x` | 应用于 ROPE 的 X 分量的偏移值（默认值：0.0）。 | FLOAT | 是 | -256.0 - 256.0（步长 0.1） |
| `scale_y` | 应用于 ROPE 的 Y 分量的缩放因子（默认值：1.0）。 | FLOAT | 是 | 0.0 - 100.0（步长 0.1） |
| `shift_y` | 应用于 ROPE 的 Y 分量的偏移值（默认值：0.0）。 | FLOAT | 是 | -256.0 - 256.0（步长 0.1） |
| `scale_t` | 应用于 ROPE 的 T（时间）分量的缩放因子（默认值：1.0）。 | FLOAT | 是 | 0.0 - 100.0（步长 0.1） |
| `shift_t` | 应用于 ROPE 的 T（时间）分量的偏移值（默认值：0.0）。 | FLOAT | 是 | -256.0 - 256.0（步长 0.1） |

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `model` | 已应用新的 ROPE 缩放和偏移参数的模型。 | MODEL |
