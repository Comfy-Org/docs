此节点使用 HappyHorse 模型根据文本提示生成视频。它会将您的提示和设置发送到 HappyHorse API，等待视频生成完成后下载结果。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于生成的 HappyHorse 模型及其子参数。选择模型会决定哪些子参数可用（请参阅下方的模型分节）。 | DYNAMIC_COMBO | 是 | "happyhorse-1.1-t2v"<br />"happyhorse-1.0-t2v" |
| `seed` | 用于生成的随机数种子。在输入相同的情况下使用相同的种子将产生相同的结果。（默认值：0）。 | INT | 是 | 0 到 2147483647 |
| `watermark` | 是否为结果添加 AI 生成的水印。（默认值：False）。 | BOOLEAN | 是 | True / False |

### happyhorse-1.1-t2v 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述画面元素和视觉特征的提示词。支持英文和中文。（默认值：""）。 | STRING | 是 | - |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | "720P"<br />"1080P" |
| `ratio` | 输出视频的宽高比。 | COMBO | 是 | "16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4"<br />"21:9"<br />"9:21"<br />"5:4"<br />"4:5" |
| `duration` | 视频长度（以秒为单位）。（默认值：5，最小值：3，最大值：15，步长：1）。 | INT | 是 | 3 到 15 |

### happyhorse-1.0-t2v 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述画面元素和视觉特征的提示词。支持英文和中文。（默认值：""）。 | STRING | 是 | - |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | "720P"<br />"1080P" |
| `ratio` | 输出视频的宽高比。 | COMBO | 是 | "16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4" |
| `duration` | 视频长度（以秒为单位）。（默认值：5，最小值：3，最大值：15，步长：1）。 | INT | 是 | 3 到 15 |

注意：提示词不能为空；如果未提供提示词，则会引发错误。两个模型均支持 3 到 15 秒的视频时长。`happyhorse-1.1-t2v` 模型提供了额外的宽高比（`21:9`、`9:21`、`5:4`、`4:5`），而 `happyhorse-1.0-t2v` 不支持这些比例。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `VIDEO` | 生成的视频文件。 | VIDEO |
