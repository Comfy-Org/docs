此节点使用 CLIP 模型将系统提示和用户提示编码为嵌入，该嵌入可用于引导扩散模型生成特定图像。它将预定义的 Lumina 2 系统提示与您的自定义文本提示相结合，并通过 CLIP 模型处理它们，为图像生成创建 conditioning 数据。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `系统提示词` | Lumina2 提供两种类型的系统提示：Superior：您是一名助手，旨在根据文本提示或用户提示生成具有卓越图像-文本对齐程度的卓越图像。Alignment：您是一名助手，旨在根据文本提示生成具有最高图像-文本对齐程度的高质量图像。 | COMBO | 是 | `"superior"`<br />`"alignment"` |
| `提示词` | 要编码的文本。支持多行输入和动态提示。 | STRING | 是 | N/A |
| `clip` | 用于编码文本的 CLIP 模型。 | CLIP | 是 | N/A |

**注意：**`clip` 输入是必需的，不能为 None。如果 clip 输入无效，节点将引发错误，提示检查点可能不包含有效的 CLIP 或文本编码器模型。

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `CONDITIONING` | 包含用于引导扩散模型的嵌入文本的 conditioning 数据。 | CONDITIONING |
