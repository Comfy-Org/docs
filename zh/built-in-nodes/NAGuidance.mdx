NAGuidance 节点将归一化注意力引导（Normalized Attention Guidance）应用于模型。该技术通过在采样过程中修改模型的注意力机制，使生成结果远离不期望的概念，从而让蒸馏模型或 schnell 模型也能使用负面提示词。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 要应用归一化注意力引导的模型。 | MODEL | 是 | - |
| `nag_scale` | 引导比例系数。值越高，生成结果越远离负面提示词。（默认值：5.0） | FLOAT | 是 | 0.0 - 50.0 |
| `nag_alpha` | 归一化注意力的混合系数。值为 1.0 时完全替换原始注意力，值为 0.0 时则不产生任何影响。（默认值：0.5） | FLOAT | 是 | 0.0 - 1.0 |
| `nag_tau` | 用于限制归一化比例的缩放系数。（默认值：1.5） | FLOAT | 是 | 1.0 - 10.0 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `model` | 已启用归一化注意力引导的修补后模型。 | MODEL |
