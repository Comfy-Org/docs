LTXVScheduler 节点为自定义采样流程生成 sigma 值。它根据输入 latent 中的 token 数量计算噪声调度参数，并应用 sigmoid 变换来创建采样调度。该节点可以选择性地拉伸生成的 sigma，以匹配指定的终止值。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `步数` | 采样步数（默认：20） | INT | 是 | 1-10000 |
| `最大移位` | sigma 计算的最大偏移值（默认：2.05） | FLOAT | 是 | 0.0-100.0 |
| `基础移位` | sigma 计算的基础偏移值（默认：0.95） | FLOAT | 是 | 0.0-100.0 |
| `拉伸` | 将 sigma 拉伸至 [terminal, 1] 范围（默认：True） | BOOLEAN | 是 | True/False |
| `终值` | 拉伸后 sigma 的终止值（默认：0.1） | FLOAT | 是 | 0.0-0.99 |
| `Latent` | 可选的 latent 输入，用于计算 sigma 调整所需的 token 数量 | LATENT | 否 | - |

**注意：** `latent` 参数是可选的。当未提供时，节点使用默认 token 数量 4096 进行计算。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `sigmas` | 为采样流程生成的 sigma 值 | SIGMAS |
