SamplerDPMAdaptative 节点实现了一种自适应 DPM（扩散概率模型）采样器，可在采样过程中自动调整步长。它使用基于容差的误差控制来确定最佳步长，在计算效率和采样精度之间取得平衡。这种自适应方法有助于保持质量，同时可能减少所需的步数。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `order` | 采样方法的阶数（默认：3） | INT | 是 | 2-3 |
| `rtol` | 误差控制的相对容差（默认：0.05） | FLOAT | 是 | 0.0-100.0 |
| `atol` | 误差控制的绝对容差（默认：0.0078） | FLOAT | 是 | 0.0-100.0 |
| `h_init` | 初始步长（默认：0.05） | FLOAT | 是 | 0.0-100.0 |
| `pcoeff` | 步长控制的比例系数（默认：0.0） | FLOAT | 是 | 0.0-100.0 |
| `icoeff` | 步长控制的积分系数（默认：1.0） | FLOAT | 是 | 0.0-100.0 |
| `dcoeff` | 步长控制的微分系数（默认：0.0） | FLOAT | 是 | 0.0-100.0 |
| `accept_safety` | 步长接受的安全系数（默认：0.81） | FLOAT | 是 | 0.0-100.0 |
| `eta` | 随机性参数（默认：0.0） | FLOAT | 是 | 0.0-100.0 |
| `s_noise` | 噪声缩放因子（默认：1.0） | FLOAT | 是 | 0.0-100.0 |

所有输入均为用于微调自适应采样行为的高级参数。
