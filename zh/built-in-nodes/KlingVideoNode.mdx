此节点使用 Kling V3 模型生成视频。它支持文本转视频模式（根据文本描述创建视频）和图像转视频模式（将现有图像动画化）。它还具有高级功能，例如创建多个视频片段，并为每个部分（故事板）设置单独的提示词，以及可选地生成伴随音频。

### 多镜头输入

**当 `multi_shot` 设置为 `"disabled"` 时：**

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 视频的主要文本描述。必须在 1 到 2500 个字符之间。 | STRING | 是 | 1 到 2500 个字符 |
| `negative_prompt` | 描述视频中不应出现内容的文本。可以为空。 | STRING | 否 | - |
| `duration` | 视频的时长（秒）。默认为 5。 | INT | 是 | 3 到 15 |

**当 `multi_shot` 设置为故事板选项（例如 `"3 storyboards"`）时：**

对于每个故事板片段 N（从 1 到所选故事板数量），会显示以下输入：

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | 故事板片段 N 的提示词。最多 512 个字符。 | STRING | 是 | 1 到 512 个字符 |
| `storyboard_N_duration` | 故事板片段 N 的时长（秒）。默认为 4。 | INT | 是 | 1 到 15 |

**约束和行为：**

- 当未连接 `start_frame` 时使用文本转视频模式；当连接 `start_frame` 时使用图像转视频模式。在图像转视频模式下，`model.aspect_ratio` 被忽略，输入图像必须至少为 300x300 像素，且宽高比在 1:2.5 到 2.5:1 之间。
- 在故事板模式下，主 `prompt` 和 `negative_prompt` 不适用。所有故事板时长的总和必须在 3 到 15 秒之间。
- `negative_prompt` 仅与 `kling-v3` 一起使用；当选择 `kling-3.0-turbo` 时会被忽略。
- 对于 `kling-v3`，每个故事板作为单独的片段发送到 API。对于 `kling-3.0-turbo`，故事板的提示词和时长会被合并为一个多镜头提示。
- 对于 `kling-3.0-turbo`，`generate_audio` 被忽略，因为该模型始终生成原生音频。
