此节点使用 Kling V3 模型生成视频。它支持文生视频（根据文本描述创建视频）和图生视频（让现有图像动起来）。它还可以使用分镜提示词创建多片段视频，并可选生成音频。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `多镜头` | 生成一系列具有各自提示词和时长的视频片段。当设置为某个分镜选项时，会出现每个分镜的提示词和时长的额外输入。 | DYNAMIC_COMBO | 是 | `"disabled"`<br />`"1 storyboard"`<br />`"2 storyboards"`<br />`"3 storyboards"`<br />`"4 storyboards"`<br />`"5 storyboards"`<br />`"6 storyboards"` |
| `生成音频` | 启用时，节点会为视频生成音频。注意：`"kling-3.0-turbo"` 始终生成原生音频，因此该模型会忽略音频开关。默认为 True。 | BOOLEAN | 是 | True<br />False |
| `模型` | 模型和生成设置。选择模型后会显示其分辨率和宽高比子参数。 | DYNAMIC_COMBO | 是 | `"kling-v3"`<br />`"kling-3.0-turbo"` |

### 多镜头输入

**当 `multi_shot` 设置为 `"disabled"` 时：**

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 视频的主要文本描述。必须介于 1 到 2500 个字符之间。 | STRING | 是 | 1 到 2500 characters |
| `negative_prompt` | 描述视频中不应出现内容的文本。可以留空。 | STRING | 否 | - |
| `duration` | 视频长度，以秒为单位。默认为 5。 | INT | 是 | 3 到 15 |

**当 `multi_shot` 设置为某个分镜选项时（例如 `"3 storyboards"`）：**

对于每个分镜片段 N（从 1 到所选分镜数量），会出现以下输入：

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | 分镜片段 N 的提示词。最多 512 个字符。 | STRING | 是 | 1 到 512 characters |
| `storyboard_N_duration` | 分镜片段 N 的时长，以秒为单位。默认为 4。 | INT | 是 | 1 到 15 |

**约束和行为：**

- 当未连接 `start_frame` 时使用文生视频模式；当连接 `start_frame` 时使用图生视频模式。在图生视频模式下，`model.aspect_ratio` 会被忽略，并且输入图像必须至少为 300x300 像素，宽高比介于 1:2.5 和 2.5:1 之间。
- 在分镜模式下，主 `prompt` 和 `negative_prompt` 不会被使用。所有分镜时长总和必须介于 3 到 15 秒之间。
- `negative_prompt` 仅与 `kling-v3` 一起使用；当选择 `kling-3.0-turbo` 时会被忽略。
- 对于 `kling-v3`，每个分镜都会作为单独片段发送到 API。对于 `kling-3.0-turbo`，分镜提示词和时长会合并为一个多镜头提示词。
- 对于 `kling-3.0-turbo`，`generate_audio` 会被忽略，因为该模型始终生成原生音频。
