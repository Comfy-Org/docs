此节点提取网格的烘焙纹理，并以独立图像的形式返回：基础颜色、金属度、粗糙度、环境光遮蔽和法线贴图。未烘焙的纹理通道将以中性默认值返回——环境光遮蔽为白色，法线贴图为平坦的蓝色。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `网格` | 要提取烘焙纹理的网格。网格必须具有基础颜色纹理；仅具有顶点颜色的网格（例如经过 PaintMesh 节点后）不含纹理，会导致错误。 | MESH | 是 | — |

注意：网格必须具有烘焙的基础颜色纹理。如果没有，节点将引发错误，并建议先运行 BakeTextureFromVoxel。当缺少金属度-粗糙度纹理时，`metallic` 和 `roughness` 输出为黑色（0）。除非网格包含烘焙的环境光遮蔽，否则 `occlusion` 输出为白色。当未烘焙法线贴图时，`normal_map` 输出为平坦的中性蓝色。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `基础颜色` | 网格的基础颜色纹理，以图像形式返回。 | IMAGE |
| `金属度` | 来自网格的环境光遮蔽-粗糙度-金属度纹理的金属度通道，以灰度图像表示。黑色（0）表示非金属，白色（1）表示完全金属。当纹理缺失时为黑色。 | IMAGE |
| `粗糙度` | 来自网格的环境光遮蔽-粗糙度-金属度纹理的粗糙度通道，以灰度图像表示。当纹理缺失时为黑色。 | IMAGE |
| `环境遮挡` | 来自网格的环境光遮蔽-粗糙度-金属度纹理的环境光遮蔽通道，以灰度图像表示。当未烘焙环境光遮蔽时为白色（无遮蔽）。 | IMAGE |
| `法线贴图` | 网格的法线贴图纹理。当未烘焙法线贴图时，输出平坦的中性法线贴图（0.5, 0.5, 1.0，显示为平坦的蓝色）。 | IMAGE |
