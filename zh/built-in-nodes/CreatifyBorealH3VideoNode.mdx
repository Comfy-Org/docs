Creatify Boreal-H3 Video 可将文本提示词转换为带声音的视频，使用 Creatify 针对视频广告后训练的 H3 模型。连接首帧可为静态图像添加动画，也可选连接尾帧，使镜头落在指定的图像上。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述视频的文本提示词。必须包含至少一个非空白字符。 | STRING | 是 | 任意非空文本 |
| `first_frame` | 视频起始的图像。连接后，请将 `aspect_ratio` 保持为 `"auto"`，以便视频跟随该图像。 | IMAGE | 否 | - |
| `last_frame` | 视频结束的图像。需要连接 `first_frame`。 | IMAGE | 否 | - |
| `resolution` | 输出视频的分辨率（默认：`"768p"`）。 | COMBO | 是 | `"768p"`<br />`"1088p"`<br />`"2k"` |
| `aspect_ratio` | 输出视频的宽高比。连接首帧时，`"auto"` 会跟随首帧；此时请保持为 `"auto"`（默认：`"auto"`）。 | COMBO | 是 | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 视频长度，单位为秒（默认：5）。在 `"2k"` 下最大为 14 秒。 | INT | 是 | 1 到 15（步长：1） |
| `prompt_enhancement` | Creatify 在渲染前如何改写提示词：`"auto"` 和 `"ads"` 会将其转换为视频广告提示词，并可能添加口播台词；`"general"` 会将其改写为适用于其他类型视频的提示词；`"none"` 则按原文渲染（默认：`"auto"`）。 | COMBO | 是 | `"auto"`<br />`"ads"`<br />`"general"`<br />`"none"` |
| `seed` | 种子控制此节点是否会重新运行。Creatify 会自行选择随机性，因此只有当 `prompt_enhancement` 设为 `"none"` 时，相同的输入才会生成相同的视频（默认：42）。 | INT | 是 | 0 到 2147483647 |

**约束：** 使用 `first_frame` 时，宽高比始终取自该图像，因此任何其他 `aspect_ratio` 值都会报错。没有 `first_frame` 的 `last_frame` 会被拒绝，并且在 `"2k"` 下 `duration` 超过 14 秒会被拒绝。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `VIDEO` | 生成的带声音视频。 | VIDEO |
