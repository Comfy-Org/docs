此节点根据提供的参考材料生成包含人物或对象的视频。它使用 Wan 2.7 模型根据文本提示创建视频，支持单角色表演和多角色交互。您必须至少提供一个参考视频或参考图像，生成才能正常工作。

## 输入
### 通用输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 用于视频生成的具体模型。 | DYNAMIC_COMBO | 是 | "wan2.7-r2v" |
| `seed` | 用于生成的种子值，有助于控制输出的随机性（默认值：0）。 | INT | 是 | 0 到 2147483647 |
| `watermark` | 是否在结果中添加 AI 生成的水印（默认值：False）。这是一个高级设置。 | BOOLEAN | 是 | True<br />False |

### wan2.7-r2v 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `prompt` | 描述视频的提示词。使用诸如 'character1' 和 'character2' 等标识符来指代参考角色。必须包含至少一个角色。 | STRING | 是 | - |
| `negative_prompt` | 描述应避免内容的负面提示词（默认值：空）。 | STRING | 否 | - |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | "720P"<br />"1080P" |
| `ratio` | 输出视频的宽高比。 | COMBO | 是 | "16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4" |
| `duration` | 生成视频的时长（秒）（默认值：5）。 | INT | 是 | 2 到 10 |

### 参考输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `reference_videos` | 可增长插槽：连接最多 3 个参考视频（插槽 `video1` 至 `video3`）。整体至少需要一个参考视频或图像。 | VIDEO | 否 | 0 到 3 项 |
| `reference_images` | 可增长插槽：连接最多 5 个参考图像（插槽 `image1` 至 `image5`）。整体至少需要一个参考视频或图像。 | IMAGE | 否 | 0 到 5 项 |

**重要约束：**

* 您必须在 `reference_videos` 或 `reference_images` 输入中至少提供一个参考视频或参考图像。
* 参考视频和参考图像的总数不能超过 5。
* `prompt` 输入必须包含至少一个角色。

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `output` | 生成的视频文件。 | VIDEO |
