在 Comfy Cloud GPU 上运行 MiniMax H3 首尾帧工作流，返回两个关键帧之间的运动画面，并附带匹配的配乐。提供起始帧和结束帧，模型便会补全两者之间的镜头。结束帧是可选的：不提供时，运动将从 `first_frame` 向外延伸。这是一个 beta 节点，按 GPU 秒计费。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 取值范围 |
|------|------|----------|------|----------|
| `first_frame` | 视频起始的图像。在工作流运行前，该图像会被上传，最大尺寸为 2048x2048 像素。 | IMAGE | 是 | - |
| `末帧` | 可选的结束帧。连接后，生成的运动会以该图像结束；不连接时，运动从 `first_frame` 向外延伸。 | IMAGE | 否 | - |
| `prompt` | 对运动和镜头应包含的声音的文字描述。提交前会移除首尾空白字符。 | STRING | 是 | 1 到 4096 个字符 |
| `seed` | 控制生成结果的随机种子（默认值：42）。 | INT | 是 | 0 到 18446744073709551615 |
| `aspect_ratio` | 生成视频的宽高比（默认：`"1:1"`）。 | COMBO | 是 | `"1:1"`<br />`"3:4"`<br />`"2:3"`<br />`"3:2"`<br />`"4:3"`<br />`"16:9"`<br />`"9:16"`<br />`"21:9"` |
| `resolution` | 帧尺寸预算（默认：`"480p"`）。720p 消耗的 GPU 秒数约为 480p 的两倍。 | COMBO | 是 | `"480p"`<br />`"720p"` |
| `duration_seconds` | 时长（秒，默认值：5）。该管线按 24 fps 下 17 帧为步长进行量化，因此成片时长与设定值的偏差约在三分之二秒以内。 | INT | 是 | 5 到 15 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|----------|------|----------|
| `VIDEO` | 生成的视频及其配乐。 | VIDEO |
