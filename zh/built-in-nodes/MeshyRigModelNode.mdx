Meshy：Rig Model 节点会从先前的 Meshy 任务中获取 3D 模型，并自动为其创建骨骼，生成一个可摆姿势和制作动画的绑定角色。该节点会同时以 GLB 和 FBX 两种文件格式输出绑定后的模型。

## 输入
| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `meshy_task_id` | 来自先前 Meshy 操作（如文本转 3D 或图像转 3D）的唯一任务 ID，用于生成需要绑定的模型。 | STRING | 是 | N/A |
| `height_meters` | 角色模型的近似高度（以米为单位）。这有助于提高缩放和绑定的准确性（默认值：1.7）。 | FLOAT | 是 | 0.1 到 15.0 |
| `texture_image` | 模型的 UV 展开基础颜色纹理图像。 | IMAGE | 否 | N/A |

**注意：** 当前自动绑定流程不适用于无纹理网格、非人形资源，或四肢和身体结构不清晰的人形资源。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `模型文件` | 用于向后兼容的旧版输出，包含 GLB 模型的文件名。 | STRING |
| `rig_task_id` | 此绑定操作的唯一任务 ID，可用于引用结果。 | STRING |
| `GLB` | 以 GLB 文件格式保存的绑定后 3D 角色模型。 | FILE3DGLB |
| `FBX` | 以 FBX 文件格式保存的绑定后 3D 角色模型。 | FILE3DFBX |
