Wan 2.7 图像转视频节点根据首帧图像生成视频。您可以选择提供末帧图像，以创建两者之间的过渡，或提供音频文件来引导视频的运动和时序。该节点使用 AI 模型根据您的文本描述对场景进行动画处理。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 用于视频生成的 AI 模型。 | DYNAMIC_COMBO | 是 | `"wan2.7-i2v"` |
| `first_frame` | 首帧图像。输出宽高比由此图像决定。 | IMAGE | 是 | - |
| `last_frame` | 末帧图像。模型会生成一个从首帧过渡到末帧的视频。 | IMAGE | 否 | - |
| `audio` | 用于驱动视频生成的音频（例如，唇形同步、节拍匹配运动）。时长：2 秒至 30 秒。如果未提供，模型会自动生成匹配的背景音乐或音效。 | AUDIO | 否 | - |
| `seed` | 用于生成的种子（默认值：0）。 | INT | 是 | 0 到 2147483647 |
| `prompt_extend` | 是否通过 AI 辅助增强提示词（默认值：True）。这是一个高级设置。 | BOOLEAN | 是 | True<br />False |
| `watermark` | 是否在结果中添加 AI 生成的水印（默认值：False）。这是一个高级设置。 | BOOLEAN | 是 | True<br />False |

### wan2.7-i2v 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `prompt` | 描述元素和视觉特征的提示词。支持英语和中文。（默认：空） | STRING | 是 | - |
| `negative_prompt` | 负面提示词，描述需要避免的内容。（默认：空） | STRING | 是 | - |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | `"720P"`<br />`"1080P"` |
| `duration` | 生成的视频长度（以秒为单位）（默认值：5）。 | INT | 是 | 2 到 15 |

**注意：** `audio` 输入有持续时间限制。如果提供，音频文件长度必须在 2 到 30 秒之间。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `output` | 生成的视频文件。 | VIDEO |
