ReplaceVideoLatentFrames 会用源潜在视频中的帧替换目标潜在视频中的一段帧范围，从指定的帧索引开始。如果未提供源潜在变量，则目标潜在变量将原样返回。该节点支持负索引，并在源帧无法放入目标时记录警告。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `目标Latent` | 目标潜在变量，其中的帧将被替换。 | LATENT | 是 | - |
| `来源Latent` | 提供帧以插入目标潜在变量的源潜在变量。如果未提供，则目标潜在变量将原样返回。 | LATENT | 否 | - |
| `序号` | 目标潜在变量中放置源潜在变量帧的起始潜在帧索引。负值从末尾开始计数（默认值：0）。 | INT | 是 | -MAX_RESOLUTION 到 MAX_RESOLUTION |

**约束条件：**

* 负的 `index` 会通过将其加到目标帧计数上来进行调整，因此它从目标潜在变量的末尾向前计数。
* 如果 `index` 指向超出目标帧计数的位置，或者源帧在 `index` 处无法放入目标中，则会记录警告并原样返回目标潜在变量。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `output` | 帧替换操作后得到的潜在视频。如果无法执行替换，则原样返回目标潜在变量。 | LATENT |
