WanVaceToVideo 节点为视频生成模型准备视频条件数据。它接收正向和负向条件输入，以及可选的控制视频、遮罩和参考图像，并将它们编码为用于引导视频生成的潜在表示。该节点处理缩放、填充、遮罩和 VAE 编码，以构建适合视频模型的条件结构。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `正面条件` | 用于引导生成的正向条件输入 | CONDITIONING | 是 | - |
| `负面条件` | 用于引导生成的负向条件输入 | CONDITIONING | 是 | - |
| `vae` | 用于编码图像和视频帧的 VAE 模型 | VAE | 是 | - |
| `宽度` | 输出视频宽度（像素）（默认值：832，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 输出视频高度（像素）（默认值：480，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `长度` | 视频帧数（默认值：81，步长：4） | INT | 是 | 1 to MAX_RESOLUTION |
| `批量大小` | 同时生成的视频数量（默认值：1） | INT | 是 | 1 到 4096 |
| `强度` | VACE 控制的条件强度（默认值：1.0，步长：0.01）。此值不是 LoRA 强度。LoRA 权重通过单独的 LoRA 节点应用。 | FLOAT | 是 | 0.0 到 1000.0 |
| `控制视频` | 用于控制条件的可选输入视频。如果未提供，会自动创建中性灰色视频。 | IMAGE | 否 | - |
| `控制遮罩` | 用于确定控制视频中哪些部分处于活动状态的可选遮罩。如果未提供，则使用全白遮罩。 | MASK | 否 | - |
| `参考图像` | 用于附加条件的可选参考图像。提供时，它会被编码并前置到潜在序列中。 | IMAGE | 否 | - |

**注意：** 提供 `control_video` 时，它会被截断为 `length` 帧，并缩放到指定的 `width` 和 `height`；如果其帧数少于 `length`，缺失帧将用中性灰色（值 0.5）填充。未提供时，会自动创建长度为 `length` 帧的中性灰色视频。`control_masks` 会缩放到指定的 `width` 和 `height`，截断为 `length` 帧，如果不足则用值 1.0 填充。该遮罩将控制视频分为非活动部分和响应部分，各部分分别经 VAE 编码后在通道维度上拼接；遮罩也会被降采样到潜在分辨率。提供 `reference_image` 时，它会经 VAE 编码并前置到潜在序列中。潜在帧数按 `((length - 1) // 4) + 1` 计算，潜在空间维度为 `height / 8` 和 `width / 8`。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `正向` | 已应用视频控制数据（`vace_frames`、`vace_mask`、`vace_strength`）的正向条件 | CONDITIONING |
| `负向` | 已应用视频控制数据（`vace_frames`、`vace_mask`、`vace_strength`）的负向条件 | CONDITIONING |
| `latent` | 准备用于视频生成的空潜在张量，形状为 [batch_size, 16, latent_length, height/8, width/8] | LATENT |
| `裁剪latent` | 使用参考图像时需要修剪的潜在帧数；如果未提供参考图像则为 0 | INT |
