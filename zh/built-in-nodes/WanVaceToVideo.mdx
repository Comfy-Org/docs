WanVaceToVideo 节点为 VACE 控制的视频生成模型准备视频条件数据。它将正向和负向条件与可选的控制视频、控制蒙版和参考图像结合，通过 VAE 进行编码，并输出更新后的条件、空 latent 张量和 trim 值。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `正面条件` | 用于引导生成的正向条件输入 | CONDITIONING | 是 | - |
| `负面条件` | 用于引导生成的负向条件输入 | CONDITIONING | 是 | - |
| `vae` | 用于编码图像和视频帧的 VAE 模型 | VAE | 是 | - |
| `宽度` | 输出视频宽度（像素）（默认值：832，步长：16） | INT | 是 | 16 到 MAX_RESOLUTION |
| `高度` | 输出视频高度（像素）（默认值：480，步长：16） | INT | 是 | 16 到 MAX_RESOLUTION |
| `长度` | 视频中的帧数（默认值：81，步长：4） | INT | 是 | 1 到 MAX_RESOLUTION |
| `批量大小` | 同时生成的视频数量（默认值：1） | INT | 是 | 1 到 4096 |
| `强度` | VACE 控制的条件强度（默认值：1.0，步长：0.01）。这不是 LoRA 强度。LoRA 权重通过单独的 LoRA 节点应用。 | FLOAT | 是 | 0.0 到 1000.0 |
| `控制视频` | 用于控制条件的可选输入视频。如果未提供，则自动创建中性灰色视频。 | IMAGE | 否 | - |
| `控制遮罩` | 可选蒙版，决定控制视频的哪些部分处于活动状态。如果未提供，则使用全白蒙版。 | MASK | 否 | - |
| `参考图像` | 用于额外条件的可选参考图像。提供时，它会被编码并前置到 latent 序列中。仅使用第一张图像。 | IMAGE | 否 | - |

**注意：** 当提供 `control_video` 时，它会被截断为 `length` 帧，并上采样到指定的 `width` 和 `height`；如果它的帧数少于 `length`，则缺失的帧会用中性灰色（值 0.5）填充。当未提供时，会自动创建一个包含 `length` 帧的中性灰色视频。`control_masks` 会被上采样到指定的 `width` 和 `height`，截断为 `length` 帧，如果较短则用值 1.0 填充。蒙版将控制视频分为非活动部分和响应部分，各部分分别进行 VAE 编码，并沿通道维度拼接；蒙版还会下采样到 latent 分辨率。当提供 `reference_image` 时，其第一张图像会被 VAE 编码并前置到 latent 序列中，`trim_latent` 会报告添加的 latent 帧数。latent 帧数计算为 `((length - 1) // 4) + 1`，latent 空间维度为 `height / 8` 和 `width / 8`。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 已应用视频控制数据（vace_frames、vace_mask、vace_strength）的正向条件 | CONDITIONING |
| `negative` | 已应用视频控制数据（vace_frames、vace_mask、vace_strength）的负向条件 | CONDITIONING |
| `latent` | 可用于视频生成的空 latent 张量，形状为 [batch_size, 16, latent_length, height/8, width/8] | LATENT |
| `trim_latent` | 使用参考图像时要修剪的 latent 帧数；如果未提供参考图像，则为 0 | INT |
