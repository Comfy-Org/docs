Save Video 节点将输入视频保存到你的 ComfyUI 输出目录。你可以选择文件名前缀、容器格式、视频编解码器以及质量等编码选项。该节点使用计数器自动生成唯一文件名，并可将工作流元数据嵌入到保存的文件中。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `视频` | 要保存的视频。 | VIDEO | 是 | - |
| `文件名前缀` | 要保存的文件的前缀。可包含格式化信息，例如 `%date:yyyy-MM-dd%` 或 `%Empty Latent Image.width%`，以包含来自节点的值（默认：`video/ComfyUI`）。 | STRING | 是 | - |
| `格式` | 输出容器。`auto` 会为 Auto/H.264 使用 MP4，为 AV1 使用 WebM。MP4、MKV 和 WebM 会选择特定容器。选择格式还会决定可用的编解码器选项（默认：`auto`）。 | DYNAMIC_COMBO | 是 | `"auto"`<br />`"mp4"`<br />`"mkv"`<br />`"webm"` |
| `编码器` | 输出视频编解码器。`auto` 会保留兼容的源流。H.264 和 AV1 重新编码支持 SDR、HDR (HLG) 和 HDR PQ。此选择器嵌套在所选格式下（默认：`auto`）。 | DYNAMIC_COMBO | 否 | `"auto"`<br />`"h264"`<br />`"av1"`（不适用于 `webm` 格式） |

### H.264 输入

当 `codec` 为 `"h264"` 时，这些输入会出现，并且适用于 `auto`、`mp4` 和 `mkv` 格式。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `encoding` | `auto` 会保留兼容的 H.264 流。`re-encode` 会应用自定义编码选项。 | DYNAMIC_COMBO | 否 | `"auto"`<br />`"re-encode"` |
| `crf` | 较低的值会产生更高的质量和更大的文件。当 `encoding` 为 `"re-encode"` 时出现（默认：23.0）。 | FLOAT | 否 | 0.0 到 51.0 |

### AV1 输入

当 `codec` 为 `"av1"` 时，这些输入会出现，并且适用于 `auto`、`mp4`、`mkv` 和 `webm` 格式。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `encoding` | `auto` 会保留兼容的 AV1 流。`re-encode` 会应用自定义编码选项。 | DYNAMIC_COMBO | 否 | `"auto"`<br />`"re-encode"` |
| `crf` | 较低的值会产生更高的质量和更大的文件。当 `encoding` 为 `"re-encode"` 时出现（默认：30.0）。 | FLOAT | 否 | 0.0 到 63.0 |

注意：当 `format` 为 `"auto"` 时，保存的容器会自动选择：`av1` 生成 WebM，而 `auto` 和 `h264` 生成 MP4。`webm` 格式仅允许 `auto` 和 `av1` 编解码器。当 `codec` 为 `"auto"` 时，会保留源视频流而不是重新编码。保存的文件使用计数器后缀以避免覆盖现有文件。文件扩展名由解析后的容器决定。除非启动时禁用了元数据保存，否则工作流元数据（提示词和额外节点信息）会嵌入到保存的文件中。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `video` | 输入视频，保持不变。 | VIDEO |
| `ui` | 已保存视频文件的预览，包括文件路径和子文件夹信息，用于在 UI 中显示。 | PREVIEW_VIDEO |
