ByteDance Image Edit 节点允许你通过 API 使用 ByteDance 的 AI 模型来修改图像。你提供一张输入图像和一段描述所需修改的文本提示词，节点便会按照你的指令处理图像。该节点会自动处理 API 通信，并返回编辑后的图像。

## 输入

| 参数 | 描述 | 数据类型 | 输入类型 | 默认值 | 范围 |
| --- | --- | --- | --- | --- | --- |
| `model` | 模型名称 | MODEL | COMBO | seededit_3 | Image2ImageModelName options |
| `image` | 要编辑的基础图像 | IMAGE | IMAGE | - | - |
| `prompt` | 用于编辑图像的指令 | STRING | STRING | "" | - |
| `seed` | 生成时使用的种子 | INT | INT | 0 | 0-2147483647 |
| `guidance_scale` | 该值越高，图像越贴近提示词 | FLOAT | FLOAT | 5.5 | 1.0-10.0 |
| `watermark` | 是否在图像上添加「AI 生成」水印 | BOOLEAN | BOOLEAN | True | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `IMAGE` | 从 ByteDance API 返回的编辑后图像 | IMAGE |
