此节点使用网格现有的 UV 布局将 PBR 纹理烘焙到 3D 网格上。它在每个纹素处从稀疏体素体积中采样颜色和材质属性，并输出基色图像以及金属度和粗糙度贴图。它不会对网格进行 UV 展开，因此上游必须连接 UV 展开节点。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 要烘焙纹理的 3D 网格。必须已具有 UV 布局；上游必须连接 UV 展开节点。 | MESH | 是 | |
| `voxel_colors` | 包含逐体素颜色和可选 PBR 属性（金属度和粗糙度通道）的稀疏体素体积。 | VOXEL | 是 | |
| `texture_size` | 正方形 UV 图集分辨率（显示名称："resolution"，默认值：2048）。 | INT | 是 | 64 到 8192 |
| `reference_mesh` | 可选的密集预抽取网格；在采样前将每个纹素反向投影到其真实表面，从而消除粗糙网格上的面片化烘焙效果。 | MESH | 否 | |

注意：

- 输入网格必须具有 UV。如果不存在 UV，节点将引发错误。UV 必须与顶点一一对应（每个顶点一个 UV）。
- 当网格和体素坐标包含批次维度时，每个批次项将单独烘焙。如果某个批次项没有体素或没有面，则跳过该项并为其生成黑色纹理。
- 当为批次提供 `reference_mesh` 时，会按批次索引进行匹配；除非该 `reference_mesh` 仅包含单个网格，在这种情况下，该网格将用于所有批次项。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `base_color` | RGB 基色纹理贴图。值为 0–1 范围内的浮点数。 | IMAGE |
| `metallic` | 灰度金属度贴图（浮点数，0–1）。当体素颜色不包含金属度通道时，此图为黑色。 | IMAGE |
| `roughness` | 灰度粗糙度贴图（浮点数，0–1）。当体素颜色不包含粗糙度通道时，此图为黑色。 | IMAGE |
