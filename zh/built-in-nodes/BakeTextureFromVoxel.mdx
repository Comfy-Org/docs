此节点使用网格现有的 UV 布局将 PBR 纹理烘焙到 3D 网格上。它在 UV 空间中对网格进行光栅化，并在每个纹素处从稀疏体素体积中采样颜色和材质属性，输出基础颜色图像以及金属度和粗糙度贴图。它不会展开网格，因此必须在上游连接一个 UV 展开节点；生成的图像旨在与 ApplyTextureToMesh 中的同一网格配对，以保存为 GLB。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 要烘焙纹理的 3D 网格。必须已经有 UV 布局；必须在上游连接 UV 展开节点。 | MESH | 是 | |
| `voxel_colors` | 包含每体素颜色和可选 PBR 属性（金属度和粗糙度通道）的稀疏体素体积。 | VOXEL | 是 | |
| `texture_size` | 正方形 UV 图集分辨率（显示名称为 "resolution"，默认值为 2048）。 | INT | 是 | 64 到 8192 |
| `reference_mesh` | 可选的高密度、简化前网格；在采样前将每个纹素反投影到其真实表面，从而消除粗糙网格上的分面烘焙。 | MESH | 否 | |

注意：

- 输入网格必须具有 UV。如果不存在 UV，节点会抛出错误。UV 必须与顶点保持 1:1（每个顶点一个 UV）。
- 当网格和体素坐标包含批处理维度时，每个批次项会单独烘焙。如果某个批次项没有体素或没有面，则跳过该项，并为其输出黑色纹理。
- 当为某个批次提供 `reference_mesh` 时，它按批次索引进行匹配，除非它只包含单个网格；在这种情况下，该网格会用于所有项。
- 未被任何 UV 三角形覆盖的纹素会由最近的已覆盖纹素填充，以免纹理接缝出现黑色。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `base_color` | RGB 基础颜色纹理贴图。值为 0–1 范围内的浮点数。 | IMAGE |
| `metallic` | 灰度金属度贴图（浮点数，0–1）。当体素颜色不包含金属度通道时为黑色。 | IMAGE |
| `roughness` | 灰度粗糙度贴图（浮点数，0–1）。当体素颜色不包含粗糙度通道时为黑色。 | IMAGE |
