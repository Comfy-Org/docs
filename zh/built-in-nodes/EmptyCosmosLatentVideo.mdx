EmptyCosmosLatentVideo 创建一个具有指定维度的空潜空间视频张量。它生成一个零填充的潜空间表示，可用作视频生成工作流的起始点，可配置宽度、高度、长度和批次大小参数。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `宽度` | 潜空间视频的宽度（像素）（默认值：1280，增量为16） | INT | 是 | 16 到 MAX_RESOLUTION |
| `高度` | 潜空间视频的高度（像素）（默认值：704，增量为16） | INT | 是 | 16 到 MAX_RESOLUTION |
| `长度` | 潜空间视频的帧数（默认值：121，增量为8） | INT | 是 | 1 到 MAX_RESOLUTION |
| `批量大小` | 批次中生成的潜空间视频数量（默认值：1） | INT | 否 | 1 到 4096 |

注意：潜空间张量在高度和宽度上均按 8 倍进行空间下采样，并包含 16 个通道。潜空间时间帧数计算为 `((length - 1) // 8) + 1`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `samples` | 生成的零值空潜空间视频张量 | LATENT |
