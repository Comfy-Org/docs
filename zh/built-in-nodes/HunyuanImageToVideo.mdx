HunyuanImageToVideo 节点使用 Hunyuan 视频模型将图像转换为视频潜空间表示。它接收条件输入和可选的起始图像来生成视频潜空间，这些潜空间可被视频生成模型进一步处理。该节点支持不同的引导类型，用于控制起始图像影响视频生成过程的方式。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `正向` | 用于引导视频生成的正向条件输入 | CONDITIONING | 是 | - |
| `vae` | 用于将图像编码到潜空间的 VAE 模型 | VAE | 是 | - |
| `宽度` | 输出视频的宽度（像素） (默认：848，步长：16) | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 输出视频的高度（像素） (默认：480，步长：16) | INT | 是 | 16 to MAX_RESOLUTION |
| `长度` | 输出视频的帧数 (默认：53，步长：4) | INT | 是 | 1 to MAX_RESOLUTION |
| `批量大小` | 同时生成的视频数量 (默认：1) | INT | 是 | 1 到 4096 |
| `指导类型` | 将起始图像融入视频生成的方法（默认："v1 (concat)"）。高级选项 | COMBO | 是 | "v1 (concat)"<br />"v2 (replace)"<br />"custom" |
| `起始图像` | 可选的起始图像（或图像序列），用于初始化视频生成。仅使用前 `length` 帧和前 3 个颜色通道 | IMAGE | 否 | - |

**注意：** 当提供了 `start_image` 时，节点会根据所选的 `guidance_type` 使用不同的引导方法：

- "v1 (concat)"：将图像潜空间与视频潜空间拼接，并应用掩码将图像混合到视频中
- "v2 (replace)"：用图像潜空间替换视频的初始帧，并应用噪声掩码
- "custom"：将图像用作参考潜空间进行引导

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `正向` | 在提供 `start_image` 时，应用图像引导后的修改版正向条件输入 | CONDITIONING |
| `Latent` | 供视频生成模型进一步处理的视频潜空间表示 | LATENT |
