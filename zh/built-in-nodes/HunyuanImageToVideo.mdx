HunyuanImageToVideo 节点使用 Hunyuan 视频模型将图像转换为视频潜在表示。它接收条件输入和可选的起始图像，生成视频潜在表示，这些潜在表示可由视频生成模型进一步处理。该节点支持不同的引导类型，用于控制起始图像如何影响视频生成过程。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `正向` | 用于引导视频生成的正向条件输入 | CONDITIONING | 是 | - |
| `vae` | 用于将图像编码到潜在空间的 VAE 模型 | VAE | 是 | - |
| `宽度` | 输出视频的宽度（像素），默认值：848，步长：16 | INT | 是 | 16 到 MAX_RESOLUTION |
| `高度` | 输出视频的高度（像素），默认值：480，步长：16 | INT | 是 | 16 到 MAX_RESOLUTION |
| `长度` | 输出视频的帧数，默认值：53，步长：4 | INT | 是 | 1 到 MAX_RESOLUTION |
| `批量大小` | 同时生成的视频数量，默认值：1 | INT | 是 | 1 到 4096 |
| `指导类型` | 将起始图像纳入视频生成的方法，默认值："v1 (concat)"。高级选项 | COMBO | 是 | "v1 (concat)"<br />"v2 (replace)"<br />"custom" |
| `起始图像` | 可选的起始图像（或图像序列），用于初始化视频生成。仅使用前 `length` 帧和前 3 个颜色通道 | IMAGE | 否 | - |

**注意：** 当提供 `start_image` 时，节点根据所选的 `guidance_type` 使用不同的引导方法：

- "v1 (concat)"：将图像潜在表示与视频潜在表示拼接，并应用掩码将图像混合到视频中
- "v2 (replace)"：用图像潜在表示替换初始视频帧，并应用噪声掩码
- "custom"：将图像用作参考潜在表示进行引导

如果未提供 `start_image`，则不添加引导条件，并且 latent 以全零块的形式返回。

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 当提供 start_image 时，应用了图像引导的修改后的正向条件 | CONDITIONING |
| `latent` | 可供视频生成模型进一步处理的视频潜在表示 | LATENT |
