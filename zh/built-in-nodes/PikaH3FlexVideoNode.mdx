此节点根据文本提示生成带同步音频的视频，并可选地以首帧、尾帧或两者作为锚定。Pika H3 Flex 是 Pika 对 MiniMax H3 进行后训练得到的模型：它一次性渲染画面及其声音，你可以设置分辨率、宽高比和时长。未连接任何帧时，节点运行文本转视频；连接帧后会切换为图像转视频。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|------|------|----------|------|------|
| `prompt` | 视频中发生的事情，包括你想要的声音。不能为空。默认值：""（空字符串）。 | STRING | 是 | 1 到 8000 个字符 |
| `first_frame` | 可选的图像，用作开场帧。连接后会运行图像转视频，而不是文本转视频。 | IMAGE | 否 | - |
| `last_frame` | 可选的图像，用作结束帧。可以与 `first_frame` 一起使用，也可以单独使用。 | IMAGE | 否 | - |
| `resolution` | 输出分辨率。`"1080p"` 及以上先以 768p 渲染再放大一次。相同的种子在 480p 下会生成不同的视频。默认值：`"768p"`。 | COMBO | 是 | `"480p"`<br />`"768p"`<br />`"1080p"`<br />`"2k"`<br />`"4k"` |
| `aspect_ratio` | 输出宽高比。`"auto"` 跟随第一个连接的帧，否则跟随提示词。默认值：`"auto"`。 | COMBO | 是 | `"auto"`<br />`"21:9"`<br />`"16:9"`<br />`"3:2"`<br />`"4:3"`<br />`"5:4"`<br />`"1:1"`<br />`"4:5"`<br />`"3:4"`<br />`"2:3"`<br />`"9:16"`<br />`"9:21"` |
| `duration` | 片段长度，单位为秒。输出长度遵循帧网格：5 秒会得到 124 帧，约 5.17 秒。默认值：5。 | INT | 是 | 5 到 15 秒 |
| `rewrite_prompt` | 让 Pika 先扩展提示词。此时相同的种子在每次运行时都会生成不同的视频。默认值：False。 | BOOLEAN | 是 | true<br />false |
| `seed` | 用于采样的种子。关闭 `rewrite_prompt` 时，相同的种子会精确重复该视频，不过在本地使用相同种子运行会得到不同结果。默认值：42。 | INT | 是 | 0 到 2147483647 |

**约束：**

* 提示词长度必须在 1 到 8000 个字符之间。
* 计费依据所选分辨率和片段长度，按输出秒数计算。

## 输出

| 输出名 | 描述 | 数据类型 |
|--------|------|----------|
| `VIDEO` | 生成的片段及其同步音频。 | VIDEO |
