在 Comfy Cloud GPU 上运行 MiniMax H3 文生视频工作流，并返回带有匹配配乐的视频。画面与音频在同一次处理过程中生成，而非事后配音。这是一个 beta 节点，按 GPU 秒计费。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 视频的文本描述，包括镜头应携带的声音。提交前会移除首尾空白字符。 | STRING | 是 | 1 至 4096 个字符 |
| `种子` | 控制生成结果的随机种子（默认值：42）。 | INT | 是 | 0 至 18446744073709551615 |
| `宽高比` | 生成视频的宽高比（默认值：`"16:9"`）。 | COMBO | 是 | `"1:1"`<br />`"3:4"`<br />`"2:3"`<br />`"3:2"`<br />`"4:3"`<br />`"16:9"`<br />`"9:16"`<br />`"21:9"` |
| `分辨率` | 帧尺寸预算（默认值：`"480p"`）。720p 消耗的 GPU 秒数约为 480p 的两倍。 | COMBO | 是 | `"480p"`<br />`"720p"` |
| `时长（秒）` | 时长，单位为秒（默认值：5）。该管线在 24 fps 下按 17 帧为步长进行量化，因此生成的片段与该值的偏差约在三分之二秒以内。 | INT | 是 | 5 至 15 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `VIDEO` | 生成的视频及其配乐。 | VIDEO |
