此节点为 Trellis2 生成设置纹理阶段采样流程。它从传入的形状 latent 中读取坐标布局和逐体素形状 latent，在相同坐标布局上构建一个具有 32 个通道的空稀疏 latent，并将所需的纹理阶段元数据附加到条件上。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `正面` | 用于纹理生成流程的正向条件。纹理阶段元数据会附加到其上。 | CONDITIONING | 是 | - |
| `负面` | 用于纹理生成流程的负向条件。纹理阶段元数据会附加到其上。 | CONDITIONING | 是 | - |
| `shape_latent` | 由 Trellis2ShapeStage 或 Trellis2UpsampleStage 生成的 latent 字典。它必须包含 `coords`（坐标布局，形状为 [N, 4]）和 `samples`（逐体素形状 latent）；`coord_resolution` 和 `model_frame` 为可选。 | LATENT | 是 | - |

注意：
- `shape_latent` 必须是 Trellis2ShapeStage 或 Trellis2UpsampleStage 的输出；它提供纹理流程使用的坐标布局和逐体素形状 latent。
- 坐标布局会经过验证：`coords` 第一列中的 batch id 必须非负且连续，总行数必须与坐标计数匹配。
- 形状 latent 可以是 4D 稀疏张量（会与其坐标一起展平），也可以已经是展平形式。
- 当 `positive` 携带投影特征包（Pixal3D 条件）且 `shape_latent` 包含 `coord_resolution` 时，会计算 1024 纹理分辨率下的投影特征，并将其附加到条件上。
- 模型坐标系从 `shape_latent` 中读取；当缺失时，如果存在投影特征，则默认为 `"y_up"`，否则默认为 `"z_up"`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `positive` | 附加了纹理阶段元数据的正向条件（生成模式、坐标、坐标计数、形状 latent、模型坐标系，以及适用时的投影特征）。 | CONDITIONING |
| `negative` | 附加了相同纹理阶段元数据的负向条件。 | CONDITIONING |
| `latent` | 一个全新的空稀疏 latent，具有 32 个通道，并与传入形状 latent 的坐标布局相同。其字典包含 `samples`、`type`（"trellis2"）、`coords`、`coord_counts` 和 `model_frame`；当可用时会包含 `coord_resolution`。 | LATENT |
