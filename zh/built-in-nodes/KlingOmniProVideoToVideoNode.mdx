此节点使用 Kling AI 模型，基于输入视频和可选参考图像生成新视频。您需要提供描述所需内容的文本提示词，节点会相应地转换参考视频。它还可以融合最多四张额外参考图像，以引导输出的风格和内容。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于视频生成的特定 Kling 模型（默认：`"kling-v3-omni"`）。 | COMBO | 是 | `"kling-v3-omni"`<br />`"kling-video-o1"` |
| `提示词` | 描述视频内容的文本提示词。可以同时包含正向和负向描述。 | STRING | 是 | N/A |
| `宽高比` | 生成视频所需的宽高比。 | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"` |
| `时长` | 生成视频的长度，以秒为单位（默认：3）。 | INT | 是 | 3 到 10 |
| `参考视频` | 用作参考的视频。 | VIDEO | 是 | N/A |
| `保留原音频` | 决定是否在输出中保留参考视频的音频（默认：True）。 | BOOLEAN | 是 | N/A |
| `参考图像` | 最多 4 张额外参考图像。 | IMAGE | 否 | N/A |
| `分辨率` | 生成视频的分辨率（默认：`"1080p"`）。 | COMBO | 否 | `"1080p"`<br />`"720p"` |
| `seed` | `seed` 控制节点是否应重新运行；无论 `seed` 如何，结果都是非确定性的（默认：0）。 | INT | 否 | 0 到 2147483647 |

**参数约束：**

* `prompt` 的长度必须在 1 到 2500 个字符之间。
* `reference_video` 的时长必须在 3.0 到 10.05 秒之间。
* `reference_video` 的尺寸必须在 720x720 到 2160x2160 像素之间。
* 最多可以提供 4 张 `reference_images`。每张图像必须至少为 300x300 像素，并且宽高比必须在 1:2.5 到 2.5:1 之间。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 新生成的视频。 | VIDEO |
