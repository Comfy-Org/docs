WanImageToVideo 节点为视频生成准备条件和潜在表示。它为视频创建一个空的潜在空间，并可选地结合起始图像和 CLIP 视觉输出以引导生成。正向和负向条件输入都会使用提供的图像和视觉数据进行更新。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `正面` | 用于引导生成的正向条件输入 | CONDITIONING | 是 | - |
| `负面` | 用于引导生成的负向条件输入 | CONDITIONING | 是 | - |
| `vae` | 用于将图像编码到潜在空间的 VAE 模型 | VAE | 是 | - |
| `宽度` | 生成视频的宽度（默认值：832，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 生成视频的高度（默认值：480，步长：16） | INT | 是 | 16 to MAX_RESOLUTION |
| `长度` | 视频的帧数（默认值：81，步长：4） | INT | 是 | 1 to MAX_RESOLUTION |
| `批量大小` | 一次批次中生成的视频数量（默认值：1） | INT | 是 | 1 到 4096 |
| `clip视觉输出` | 作为额外条件添加到正向和负向输入的可选 CLIP 视觉输出 | CLIP_VISION_OUTPUT | 否 | - |
| `开始图像` | 用于初始化视频的可选起始图像。提供后，它会被调整到指定的 `width` 和 `height`，并放置在帧序列的开头；超出 `length` 的帧将被忽略。其余帧会用中性灰色（0.5）值填充。 | IMAGE | 否 | - |

**注意：** 当提供 `start_image` 时，帧序列会使用 VAE 编码，并对条件应用掩码。对于起始图像覆盖的帧，掩码设置为 0；对于其余帧，掩码设置为 1，因此生成会从提供的图像继续。编码期间仅使用图像的前三个颜色通道（RGB）。正向和负向条件都会接收相同的拼接潜在图像、掩码以及（如果提供）CLIP 视觉输出。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 正向条件，已使用图像和视觉数据更新 | CONDITIONING |
| `negative` | 负向条件，已使用图像和视觉数据更新 | CONDITIONING |
| `latent` | 准备用于视频生成的空潜在张量，形状为 [batch_size, 16, ((length-1)//4)+1, height//8, width//8] | LATENT |
