此节点使用 MiniMax H3 模型生成视频，并使用参考图像、视频和音频作为生成条件。在提示词中，参考内容按连接顺序引用："Image 1"、"Image 2"、"Video 1"、"Audio 1"，依此类推。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于视频生成的模型（默认值："MiniMax H3"）。选择 "MiniMax H3" 将提供下面的 `prompt`、`resolution`、`ratio`、`duration`、`reference_images`、`reference_videos` 和 `reference_audios` 设置。 | DYNAMIC_COMBO | 是 | "MiniMax H3" |
| `随机种子` | 随机种子。相同请求使用相同种子会产生相似但不保证完全相同的结果（默认值：42）。 | INT | 是 | 0 到 4294967295 |
| `水印` | 是否向视频添加 AIGC 水印（默认值：false）。 | BOOLEAN | 否 | true<br />false |

### MiniMax H3 输入

当选择 "MiniMax H3" 作为模型时，会出现这些输入。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 用于视频生成的文本提示词。可以按顺序引用参考媒体，例如 "Image 1"、"Image 2"、"Video 1" 或 "Audio 1"。 | STRING | 是 | Min length: 1 character |
| `resolution` | 输出视频的分辨率（默认值："768P"）。 | STRING | 是 | "768P"<br />"2K" |
| `ratio` | 输出视频的宽高比（默认值："adaptive"）。 | STRING | 是 | "adaptive"<br />"16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 输出视频的时长（秒）（默认值：5）。 | INT | 是 | 4 到 15 |

### 参考输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可增长插槽：连接 1..9 个项目（`image_1`...`image_9`）。主体或风格参考图像，按连接顺序在提示词中引用为 "Image 1".."Image 9"。最多 9 张图像。 | IMAGE | 否 | 0 到 9 images |
| `reference_videos` | 可增长插槽：连接 1..3 个项目（`video_1`...`video_3`）。动作或场景参考视频，按连接顺序在提示词中引用为 "Video 1".."Video 3"。最多 3 个视频，每个 2-15 秒，总时长 15 秒。 | VIDEO | 否 | 0 到 3 videos |
| `reference_audios` | 可增长插槽：连接 1..3 个项目（`audio_1`...`audio_3`）。音频参考，按连接顺序在提示词中引用为 "Audio 1".."Audio 3"。最多 3 个片段，每个 2-15 秒，总时长 15 秒。没有参考图像或视频时不能使用。 | AUDIO | 否 | 0 到 3 clips |

### 参数约束

- 至少需要一个参考图像或一个参考视频。仅提供参考音频不被接受。
- 每个参考图像的宽高比必须在约 0.4 到 2.5（2:5 到 5:2）之间，且最小宽度和高度为 256 像素。
- 每个参考视频的时长必须在 2 到 15 秒之间，帧率在 23.976 到 60 FPS 之间。所有参考视频的总时长不能超过 15 秒。
- 每个参考音频片段的时长必须在 2 到 15 秒之间。所有参考音频片段的总时长不能超过 15 秒。
