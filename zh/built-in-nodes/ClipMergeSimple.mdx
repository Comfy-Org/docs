`CLIPMergeSimple` 是一个模型合并节点，可根据指定比例合并两个 CLIP 文本编码器模型。它会克隆第一个 CLIP 模型，并应用来自第二个 CLIP 模型的加权补丁（跳过 position IDs 和 logit scale 组件），从而生成融合了两种来源特征的混合模型。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `clip1` | 要合并的第一个 CLIP 模型。它用作合并过程的基础模型。 | CLIP | 是 | - |
| `clip2` | 要合并的第二个 CLIP 模型。除 position IDs 和 logit scale 外，其关键补丁会根据指定比例应用到第一个模型。 | CLIP | 是 | - |
| `比例` | 决定将第二个模型的特征以多大比例融合到第一个模型中。ratio 为 1.0 表示完全采用第二个模型的特征，0.0 则仅保留第一个模型的特征。默认值：1.0。 | FLOAT | 是 | 0.0 - 1.0 (step: 0.01) |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `clip` | 合并后得到的 CLIP 模型，根据指定比例融合了两个输入模型的特征。 | CLIP |

## 合并机制说明

### 合并算法

该节点使用加权平均来合并两个模型：

1. **克隆基础模型**：首先克隆 `clip1` 作为基础模型
2. **获取补丁**：获取 `clip2` 的所有关键补丁
3. **过滤特殊键**：跳过以 `.position_ids` 和 `.logit_scale` 结尾的键
4. **应用加权合并**：使用公式 `(1.0 - ratio) * clip1 + ratio * clip2`

### ratio 参数说明

- **ratio = 0.0**：完全使用 clip1，忽略 clip2
- **ratio = 0.5**：两个模型各贡献 50%
- **ratio = 1.0**：完全使用 clip2，忽略 clip1

## 使用场景

1. **模型风格融合**：组合在不同数据上训练的 CLIP 模型的特征
2. **性能优化**：平衡不同模型的优缺点
3. **实验研究**：探索不同 CLIP 编码器的组合
