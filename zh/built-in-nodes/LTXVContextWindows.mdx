此节点在采样期间为类 LTXV 模型设置上下文窗口。它将生成过程划分为重叠的窗口，以帮助管理内存使用并提升时间连贯性。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 在采样期间要应用上下文窗口的模型。 | MODEL | 是 | - |
| `context_length` | 上下文窗口的长度（以实际帧为单位）。必须为 8*n + 1。（默认值：145） | INT | 是 | 最小值：1<br />最大值：nodes.MAX_RESOLUTION<br />步长：8 |
| `context_overlap` | 上下文窗口的重叠量（以实际帧为单位）。（默认值：40） | INT | 是 | 最小值：0<br />步长：8 |
| `context_schedule` | 用于上下文窗口的步数相关调度算法。（默认值："UNIFORM_STANDARD"） | COMBO | 是 | `"STATIC_STANDARD"`<br />`"UNIFORM_STANDARD"`<br />`"UNIFORM_LOOPED"`<br />`"BATCHED"` |
| `context_stride` | 上下文窗口的步幅；仅适用于均匀调度。（默认值：1） | INT | 是 | 最小值：1 |
| `closed_loop` | 是否闭合上下文窗口循环；仅适用于循环调度。（默认值：False） | BOOLEAN | 是 | True<br />False |
| `fuse_method` | 用于融合上下文窗口的方法。可用选项由 `ContextFuseMethods.LIST_STATIC` 定义。（默认值："PYRAMID"） | COMBO | 是 | 由 `ContextFuseMethods.LIST_STATIC` 定义 |
| `freenoise` | 是否应用 FreeNoise 噪声混洗，可改善窗口融合效果。（默认值：True） | BOOLEAN | 是 | True<br />False |
| `retain_first_frame` | 在每个上下文窗口中保留第一个潜空间帧（可能有助于保留初始参考）。（默认值：False） | BOOLEAN | 是 | True<br />False |
| `split_conds_to_windows` | 是否根据区域索引将多个条件（由 ConditionCombine 创建）拆分到各个窗口。（默认值：False） | BOOLEAN | 是 | True<br />False |

**注意：** `context_length` 的值以实际帧为单位提供，并在内部使用公式 `((context_length - 1) // 8) + 1` 转换为潜空间帧，最小值为 1。`context_overlap` 的值同样以实际帧为单位提供，并通过整数除以 8 转换为潜空间帧，最小值为 0。`context_length` 的工具提示表明它必须遵循 8*n + 1 的模式。

## 输出

|-------------|-------------|-----------|
| `MODEL` | 已应用上下文窗口以用于采样的模型。 | MODEL |
