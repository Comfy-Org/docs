此节点在采样期间为 LTXV 类模型设置上下文窗口。它将视频生成过程划分为多个重叠窗口，以管理内存使用并改善时间连贯性。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 采样期间要应用上下文窗口的模型。 | MODEL | 是 | - |
| `context_length` | 上下文窗口的长度，以实际帧为单位。必须满足 8*n + 1。（默认值：145） | INT | 是 | 最小：1<br />最大：nodes.MAX_RESOLUTION<br />步长：8 |
| `context_overlap` | 上下文窗口的重叠量，以实际帧为单位。（默认值：40） | INT | 是 | 最小：0<br />步长：8 |
| `context_schedule` | 上下文窗口的随采样步数变化的调度算法。（默认值：UNIFORM_STANDARD） | COMBO | 是 | `STATIC_STANDARD`<br />`UNIFORM_STANDARD`<br />`UNIFORM_LOOPED`<br />`BATCHED` |
| `context_stride` | 上下文窗口的步幅；仅适用于均匀（uniform）调度。（默认值：1） | INT | 否 | 最小：1 |
| `closed_loop` | 是否闭合上下文窗口的循环；仅适用于循环（looped）调度。（默认值：False） | BOOLEAN | 否 | True<br />False |
| `fuse_method` | 用于融合上下文窗口的方法。（默认值：PYRAMID） | COMBO | 是 | Options from comfy.context_windows.ContextFuseMethods.LIST_STATIC |
| `freenoise` | 是否应用 FreeNoise 噪声重排；可改善窗口混合效果。（默认值：True） | BOOLEAN | 否 | True<br />False |
| `retain_first_frame` | 在每个上下文窗口中保留第一个潜空间帧（可能有助于保留初始参考）。（默认值：False） | BOOLEAN | 否 | True<br />False |
| `split_conds_to_windows` | 是否根据区域索引，将 `ConditionCombine` 创建的多个 conditioning 拆分到每个窗口。（默认值：False） | BOOLEAN | 否 | True<br />False |

**注意：** `context_length` 参数必须满足公式 8*n + 1，其中 n 为正整数。节点会通过将实际帧转换为潜空间帧来自动调整该值，以满足此要求。`context_overlap` 也会从实际帧转换为潜空间帧（除以 8）。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `MODEL` | 已应用上下文窗口、可供采样使用的模型。 | MODEL |
