此节点使用 MiniMax H3 Max 或 MiniMax H3 Max Turbo 模型，以提示词和可选音频参考为引导，用新片段延续视频。源视频被上传、续写内容被生成，结果可以返回整个重新渲染的视频，也可以只返回新生成的片段。有两个模型可用：“MiniMax H3 Max”和“MiniMax H3 Max Turbo”，后者单位成本更低。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 用于延续视频的模型。两个模型均提供下方相同的输入。 | DYNAMIC_COMBO | 是 | "MiniMax H3 Max"<br />"MiniMax H3 Max Turbo" |

### 模型输入

这些输入适用于两个模型。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `video` | 要延长的视频，时长 1.625 至 60 秒，最大 50 MB。宽高比必须在 0.4 到 2.5 之间。 | VIDEO | 是 | 1.625 至 60 秒 |
| `prompt` | 接下来会发生什么。请描述续写内容，而非源视频。请以 `@Audio1`..`@Audio3` 引用参考音频，例如“@Audio1 用于人声”。 | STRING | 是 | 1 至 50000 个字符 |
| `reference_audios` | 可扩展槽位：最多连接 3 段音频片段（`audio_1`...`audio_3`）用于新片段，每段至少 2 秒，总计 14.5 秒。 | AUDIO | 否 | 0 至 3 个音频片段 |
| `duration` | 要添加的新片段秒数（默认值：5）。 | INT | 是 | 1 至 15 |
| `resolution` | 输出视频的分辨率（默认值："768P"）。 | COMBO | 是 | "480P"<br />"768P"<br />"1080P"<br />"2K" |
| `aspect_ratio` | 输出的宽高比。"auto" 跟随源视频；其他值会将视频裁剪为选定比例（默认值："auto"）。 | COMBO | 是 | "auto"<br />"21:9"<br />"16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16" |
| `output` | "extended" 返回整个视频，按所选分辨率重新渲染并包含新片段。"continuation" 仅返回新片段，并以源视频结尾的 1.6 秒重复内容开头（默认值："extended"）。 | COMBO | 是 | "extended"<br />"continuation" |

| `seed` | 随机种子。相同请求与相同种子会得到相似但不保证完全相同的结果（默认值：42）。 | INT | 是 | 0 至 4294967295 |

### 参数约束

- 在 2K 分辨率下，"extended" 输出总时长限制为 45 秒（源视频加上新片段）。更长的片段请使用 "continuation" 或更低的分辨率。
- 每段参考音频片段至少需 2 秒长，所有片段合计不得超过 14.5 秒。
