DecimateMesh 使用二次误差度量（QEM）简化将 3D 网格简化为目标面数，并在当前计算设备上执行计算。`"midpoint"` 放置模式是 cumesh-faithful 预设，可在保留头发等细薄特征的同时提供最佳质量；`"qem"` 则将顶点放置在 QEM 最优位置，并提供可选的线和特征边控制。输出网格保持焊接状态。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 要简化的 3D 网格。 | MESH | 是 | - |
| `target_face_count` | 目标最大面数。0 表示禁用。（默认值：200000） | INT | 是 | 0 到 50000000 |
| `placement_mode` | midpoint：cumesh-faithful（推荐）。qem：QEM 最优放置。（默认值：`"midpoint"`） | DYNAMIC_COMBO | 是 | `"midpoint"`<br />`"qem"` |

### Midpoint 输入

`"midpoint"` 放置模式不公开额外的子参数；它使用默认的 midpoint 放置预设。

### QEM 输入

以下子参数仅在 `placement_mode` 设置为 `"qem"` 时显示在界面中。

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `line_quadric_weight` | 每条边的线二次度量权重；保留尖锐的棱线/谷线。0 = 关闭。（默认值：0.0） | FLOAT | 否 | 0.0 到 100.0 |
| `feature_edge_quadric_weight` | 二面角特征边（折痕）上的额外二次度量权重。0 = 关闭。（默认值：0.0） | FLOAT | 否 | 0.0 到 1000.0 |
| `feature_edge_min_dihedral_deg` | 将边视为特征边所需的最小二面角（度）。（默认值：30.0） | FLOAT | 否 | 0.0 到 180.0 |
| `clamp_v_to_edge` | 将 QEM 最优位置投影到折叠后的边线段上。（默认值：true） | BOOLEAN | 否 | `true`<br />`false` |

注意：当 `target_face_count` 为 0，或网格的面数已经少于目标面数时，将跳过简化操作。该节点会在自身显示面数减少摘要，例如 `faces: 1.23M → 200K (-84%)`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mesh` | 简化后的网格，面数已减少；连接性保持焊接状态。 | MESH |
