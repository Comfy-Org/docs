此节点将高模的切线空间法线贴图烘焙到低模的 UV 布局中，捕捉减面过程中丢失的表面细节。连接已展开 UV 的低模网格及其来源的高模网格，节点将输出一张可直接用于 Apply Texture To Mesh 的 `normal_map` 输入的图像。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | 接收烘焙细节的已展开 UV 的低模网格。必须已有 UV；该节点不会自动展开。 | MESH | 是 | — |
| `high_poly` | 其表面细节被烘焙到低模 UV 布局中的高模网格。 | MESH | 是 | — |
| `resolution` | 正方形输出法线贴图的边长（像素），默认值：1024。 | INT | 是 | 64 到 8192（步长 64） |
| `cage_distance` | 表面搜索范围，以包围盒对角线比例表示。在重度减面后出现错误/缺失区域时增大该值；若发生跨间隙抓取则调低。默认值：0.05。 | FLOAT | 是 | 0.001 到 0.5（步长 0.001） |
| `ignore_backfaces` | 跳过背向纹素的高模表面，避免缝隙或封闭空间抓取到对面的壁面。仅在高模绕序不一致时关闭。默认值：true。 | BOOLEAN | 是 | true / false |

注意：`low_poly` 必须具有 UV 坐标。如果没有，节点会报错，因为它会在现有 UV 布局上烘焙，而不会对网格进行展开。当 `low_poly` 是一个批次时，每个条目按顺序烘焙；如果 `high_poly` 仅包含一个条目，则该条目会复用于批次中的每个条目。批次中的空网格会跳过并产生警告，输出一张平坦的中灰色（0.5）法线贴图。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `normal_map` | 烘焙得到的切线空间法线贴图（glTF/OpenGL +Y 约定），为 square resolution × resolution 的 RGB 图像，数值范围在 [0,1]。可连接到 Apply Texture To Mesh 的 `normal_map` 输入。 | IMAGE |
