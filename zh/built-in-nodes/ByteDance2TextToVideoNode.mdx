此节点使用字节跳动的 Seedance 2.5 或 2.0 模型，根据文本提示生成视频。它会将提示发送到所选模型，等待视频处理完成，然后返回生成的视频文件。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必填 | Range |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于视频生成的 Seedance 模型。Seedance 2.5 是最新模型，支持最长 30 秒的视频以及 mp4/mov 输出；Seedance 2.0 主打最高质量和 4k；Seedance 2.0 Fast 用于速度优化；Seedance 2.0 Mini 用于最快、最低成本的生成。选择某个模型后，会显示与该模型对应的 `prompt`、分辨率、宽高比、时长和音频生成等额外输入。 | DYNAMIC_COMBO | 是 | `"Seedance 2.5"`<br />`"Seedance 2.0"`<br />`"Seedance 2.0 Fast"`<br />`"Seedance 2.0 Mini"` |
| `种子` | 控制节点是否应重新运行；无论 `seed` 取值如何，结果都不具有确定性。（默认值：0） | INT | 否 | 0 至 2147483647 |
| `水印` | 是否向视频添加水印。（默认值：False）这是一项高级设置。 | BOOLEAN | 否 | True / False |

| 参数 | 描述 | 数据类型 | 是否必填 | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 用于视频生成的文本提示。将要说出的台词放在双引号中，以引导生成的对话内容。 | STRING | 是 | — |
| `resolution` | 输出视频的分辨率。（默认值：`"720p"`） | COMBO | 是 | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `ratio` | 输出视频的宽高比。（默认值：`"16:9"`） | COMBO | 是 | `"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"`<br />`"adaptive"` |
| `duration` | 输出视频的时长（秒）。（默认值：5） | INT | 是 | 4 至 30 |
| `generate_audio` | 为输出视频启用音频生成。（默认值：True） | BOOLEAN | 是 | True / False |
| `output_format` | 输出视频的封装格式。（默认值：`"mp4"`） | COMBO | 是 | `"mp4"` |

### Seedance 2.0 Fast 和 Seedance 2.0 Mini 输入

以下参数由 Seedance 2.0 Fast 和 Seedance 2.0 Mini 共用；两个模型都提供相同的参数。

| 参数 | 描述 | 数据类型 | 是否必填 | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 用于视频生成的文本提示。 | STRING | 是 | — |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | `"480p"`<br />`"720p"` |
| `ratio` | 输出视频的宽高比。（默认值：`"16:9"`） | COMBO | 是 | `"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"`<br />`"adaptive"` |
| `duration` | 输出视频的时长（秒）。（默认值：7） | INT | 是 | 4 至 15 |
| `generate_audio` | 为输出视频启用音频生成。（默认值：True） | BOOLEAN | 是 | True / False |

**注意：** `model` 选择器是动态的；每个模型部分下显示的输入会在选择该模型时出现。`prompt` 在去除空白字符后，长度必须至少为 1 个字符。分辨率和时长限制取决于所选模型：Seedance 2.5 支持 480p/720p/1080p 和 4 至 30 秒；Seedance 2.0 支持 480p/720p/1080p/4k 和 4 至 15 秒；Seedance 2.0 Fast 和 Seedance 2.0 Mini 仅支持 480p/720p 和 4 至 15 秒。`seed` 值仅控制节点是否重新运行；它不会使结果变得确定。
