使用 Ideogram 4.5 根据文本提示词生成图像。提示词也可以接受 Ideogram 结构化 JSON 描述（caption），例如先前某次运行返回的 `final_prompt`，它可精确控制文本字符串、颜色和布局。此节点返回生成的图像，以及图像实际生成时所依据的描述。

### 参数约束

- **提示词必填：** 提示词必须至少包含一个非空白字符，且最多 10000 个字符。在提供自己的 JSON 描述或精确表述时，请将 `magic_prompt` 设为 `"off"`。
- **尺寸：** `"auto"` 让模型自行选择。`(2K)` 预设约为 3 至 4 百万像素，`(1K)` 预设约为 1 百万像素，因此档位标签描述的是像素总量而非固定长边；预设的宽高比会被遵循。只有预设中的像素尺寸部分会发送给 API。
- **可复现性：** 当 `magic_prompt` 设为 `"auto"` 或 `"on"` 时，提示词会在每次运行时被重写，因此相同的种子仍可能生成不同的图像。要复现某张图像，请将其 `final_prompt` 回传，将 `magic_prompt` 设为 `"off"`，并使用相同的种子。
- **内容安全：** 如果 Ideogram 的内容安全过滤器拦截了生成，节点会抛出错误，而不是返回图像。
