使用 Ideogram 4.6 或 4.5 依据文本提示词生成图像。该提示词也接受 Ideogram 结构化 JSON 描述文本，例如之前某次运行返回的 `final_prompt`，它可以精确控制文本字符串、颜色和布局。此节点会返回图像，以及该图像实际生成时所依据的描述文本。

## 输入

选择 `model` 会决定显示哪些输入。Ideogram 4.6 新增了 `background`、`very_low` 质量档位、`(4K)` 尺寸以及自定义宽度和高度；4.5 则保留 `(1K)` 和 `(2K)` 预设。

### 参数约束

- **Prompt:** 至少包含一个非空白字符，最多 10000 个字符。当你自行提供 JSON 描述文本时，请将 `magic_prompt` 设为 `"off"`。
- **Custom size (4.6):** 宽度乘以高度不得超过 16,777,216 像素（4096x4096），每一边必须在 256 到 8192 之间并对齐为 32 的倍数，且较长边不得超过较短边的 6 倍。
- **`very_low` quality (4.6):** 限制为 4,194,304 像素（2048x2048）；更大的尺寸会报错。
- **可复现性：** 当 `magic_prompt` 设为 `"auto"` 或 `"on"` 时，每次运行都会改写提示词，因此相同的种子可能生成不同的图像。
- **内容安全：** 如果 Ideogram 的内容安全过滤器阻止了生成，节点会报错，而不是返回图像。
