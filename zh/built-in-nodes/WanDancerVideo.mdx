WanDancerVideo 节点为使用 WanDancer 模型的视频生成准备 conditioning 数据和空的 latent 张量。它将可选的起始图像、遮罩、CLIP vision 嵌入和音频特征附加到正向和负向 conditioning 上，以便它们能够引导生成的视频。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `正向` | 用于引导视频生成的正向 conditioning。 | CONDITIONING | 是 |  |
| `负向` | 用于引导视频生成的负向 conditioning。 | CONDITIONING | 是 |  |
| `vae` | 用于将起始图像编码到潜在空间的 VAE。 | VAE | 是 |  |
| `宽度` | 生成视频的宽度（以像素为单位，默认值：480）。 | INT | 是 | 16 to MAX_RESOLUTION (step: 16) |
| `高度` | 生成视频的高度（以像素为单位，默认值：832）。 | INT | 是 | 16 to MAX_RESOLUTION (step: 16) |
| `长度` | 生成视频的帧数。对于 WanDancer，应保持为 149（默认值：149）。 | INT | 是 | 1 to MAX_RESOLUTION (step: 4) |
| `clip视觉输出` | 第一帧的 CLIP vision 嵌入。 | CLIP_VISION_OUTPUT | 否 |  |
| `clip视觉参考输出` | 参考图像的 CLIP vision 嵌入。 | CLIP_VISION_OUTPUT | 否 |  |
| `起始图像` | 要编码的初始图像，可以是任意数量的帧。 | IMAGE | 否 |  |
| `掩码` | 起始图像的图像 conditioning 遮罩。白色区域被保留，黑色区域被生成。用于局部生成。 | MASK | 否 |  |
| `音频编码器输出` | 音频编码器输出，提供音频特征、帧率和注入比例值，当提供时会附加到 conditioning 上。 | AUDIO_ENCODER_OUTPUT | 否 |  |

### 参数行为说明

- `start_image` 是可选的。提供时，会将其调整为 `width` 和 `height`，由 `vae` 编码，并附加到正向和负向 conditioning 上。如果 `start_image` 的帧数多于 `length`，多余帧将被丢弃。如果帧数较少，缺失帧将用零值填充。
- `mask` 仅在同时提供 `start_image` 时生效。白色区域被保留，黑色区域被生成。
- 仅当同时提供 `clip_vision_output` 时，`clip_vision_output_ref` 才生效。
- 当提供 `audio_encoder_output` 时，会将音频嵌入、帧率和注入比例附加到正向和负向 conditioning 上。
