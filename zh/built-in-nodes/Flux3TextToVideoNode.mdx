使用 FLUX 3 根据文本提示词生成带有同步音频的视频。节点会将你的提示词发送到 FLUX 3 服务，等待生成完成后返回完整的视频片段。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 用自然语言描述你的需求；提示词会在生成前被解释和扩展。请分别描述环境音、音乐和语音，以获得分层音频。（默认值：""） | STRING | 是 | 多行文本 |
| `aspect_ratio` | 输出宽高比。选择“auto”时会根据提示词和输入自动选择。（默认值："auto"） | COMBO | 是 | 包含 `"auto"` 在内的多个选项 |
| `duration` | 片段时长（秒）。选择“auto”时会根据内容自动调整长度。（默认值："auto"） | COMBO | 是 | 包含 `"auto"` 在内的多个选项 |
| `resolution` | 输出分辨率。（默认值："720p"） | COMBO | 是 | `"720p"`<br />`"1080p"` |
| `generate_audio` | 生成同步音频（环境音、语音、音效）。关闭时生成的视频不包含音轨。（默认值：True） | BOOLEAN | 是 | True<br />False |
| `safety_tolerance` | 审核容忍度，0 表示最严格。无论此处设置为何值，包含图片或视频的请求一律按 2 处理。（默认值：2） | INT | 是 | 0 到 4 |
| `seed` | 用于决定节点是否重新运行的种子；FLUX 3 会自行选择种子，因此实际结果不由此值决定，具有不确定性。（默认值：42） | INT | 是 | 0 到 4294967295 |

注意：`seed` 输入在界面中包含“生成后控制”（Control After Generate）选项。显示的价格基于 `resolution` 和 `duration`：HD（720p）按每秒 $0.2431 计费，FHD（1080p）按每秒 $0.4147 计费。选择了固定时长时，会显示该片段的预估总费用；当 `duration` 为“auto”时，显示每秒费率。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 生成的视频片段，当 `generate_audio` 启用时包含同步音频。 | VIDEO |
