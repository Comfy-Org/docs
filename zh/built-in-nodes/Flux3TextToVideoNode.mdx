使用 FLUX 3 根据文本提示词生成带有同步音频的视频。此节点会将你的提示词发送到 FLUX 3 服务，等待生成完成，并返回完成的视频片段。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 你希望生成的内容，使用自然语言描述；提示词会在生成前被解释和扩展。若要获得分层音频，请分别描述环境音、音乐和语音。（默认值：""） | STRING | 是 | Multiline text |
| `aspect_ratio` | 输出宽高比。`"auto"` 会从提示词和输入中选择一个宽高比。（默认值："auto"） | COMBO | 是 | 多个可用选项，包括 `"auto"` |
| `duration` | 视频片段长度（秒）。`"auto"` 会根据内容调整长度。（默认值："auto"） | COMBO | 是 | 多个可用选项，包括 `"auto"` |
| `resolution` | 输出分辨率。（默认值："720p"） | COMBO | 是 | `"720p"`<br />`"1080p"` |
| `generate_audio` | 生成同步音频（环境音、语音、音效）。关闭时会生成没有音轨的视频。（默认值：True） | BOOLEAN | 是 | True<br />False |
| `safety_tolerance` | 审核容差，0 最严格。对于发送图像或视频的请求，无论此处设置为何，上限均为 2。（默认值：2） | INT | 是 | 0 到 4 |
| `seed` | 用于确定节点是否应重新运行的种子；FLUX 3 会自行选择种子，因此无论此值如何，实际结果都是不确定的。（默认值：42） | INT | 是 | 0 到 4294967295 |

注意：`safety_tolerance` 是高级输入。`seed` 输入在 UI 中包含 Control After Generate 控件。显示的价格基于 `resolution` 和 `duration`：HD (720p) 按每秒 $0.2431 计费，FHD (1080p) 按每秒 $0.4147 计费。选择固定时长时，会显示该视频片段的预计总费用；当 `duration` 为 `"auto"` 时，会显示每秒费率。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 生成的视频片段；当启用 `generate_audio` 时，会带有同步音频。 | VIDEO |
