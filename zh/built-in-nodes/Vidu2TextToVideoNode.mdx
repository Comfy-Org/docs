Vidu2 文本到视频生成节点可根据文本描述创建视频。它连接到外部 API，以根据你的提示词生成视频内容，让你可以控制视频的时长、视觉风格和格式。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 用于视频生成的 AI 模型。目前仅有一个模型可用。 | COMBO | 是 | `"viduq2"` |
| `提示词` | 用于视频生成的文本描述，最大长度为 2000 个字符。 | STRING | 是 | - |
| `时长` | 生成视频的长度（以秒为单位）。该值可通过滑块调整（默认：5）。 | INT | 否 | 1 到 10 |
| `种子` | 用于控制生成随机性的数字，以便获得可复现的结果。可在生成后进行控制（默认：1）。 | INT | 否 | 0 到 2147483647 |
| `宽高比` | 视频宽度和高度之间的比例关系。 | COMBO | 否 | `"16:9"`<br />`"9:16"`<br />`"3:4"`<br />`"4:3"`<br />`"1:1"` |
| `分辨率` | 生成视频的像素尺寸。这是一个高级参数。 | COMBO | 否 | `"720p"`<br />`"1080p"` |
| `背景音乐` | 是否为生成的视频添加背景音乐（默认：False）。这是一个高级参数。 | BOOLEAN | 否 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `output` | 生成的视频文件。 | VIDEO |
