获取网格信息（Get Mesh Info）用于报告网格中的顶点数和面数，以及其包含的属性（如 UV、顶点颜色、法线和纹理）。报告显示在节点上，并作为文本输出返回，而网格本身则原样通过。

## 输入
| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|------|------|----------|------|------|
| `网格` | 要检查的网格。该节点计算其顶点和面数，检测存在哪些属性，并原样通过网格。 | MESH | 是 | — |

注意：当输入包含多个网格（一个批次）时，报告将显示整个批次的顶点和面总数，以及每个网格的明细。对于零填充批次，将使用网格数据中存储的逐项计数。

## 输出
| 输出名称 | 描述 | 数据类型 |
|----------|------|----------|
| `网格` | 原始网格，未经任何修改直接通过。 | MESH |
| `信息` | 多行文本报告，包含顶点数、面数和检测到的属性（uvs、vertex_colors、normals、tangents、texture、metallic_roughness、normal_map）。较大的数字以逗号格式化，例如“1,234,567 (1.23M)”。相同文本也显示在节点上。 | STRING |
