Get Mesh Info 用于报告网格中的顶点数和面数，以及它所包含的属性（例如 UV、顶点颜色、法线、纹理）。该报告会显示在节点上，并作为文本输出返回，而网格本身则原样传递。

## 输入

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `网格` | 要检查的网格。该节点会统计其顶点数和面数，检测存在哪些属性，并将网格原样传递。 | MESH | 是 | — |

注意：当输入包含多个网格（一个批次）时，报告会显示整个批次的顶点和面数总计，并附上每个网格的明细。对于零填充的批次，将使用网格数据中存储的逐项计数。

## 输出

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `mesh` | 原始网格，未经任何修改地传递。 | MESH |
| `info` | 一份多行文本报告，包含顶点数、面数以及检测到的属性（uvs、vertex_colors、normals、tangents、texture、metallic_roughness、normal_map）。类似纹理的属性会显示其高度 × 宽度尺寸。较大的计数会使用逗号分隔格式，例如 "1,234,567 (1.23M)" 或 "12,345 (12.3K)"。同一文本也会显示在节点上。 | STRING |
