EmptyChromaRadianceLatentImage 节点创建一个指定尺寸的空白潜空间图像，用于色度辉光工作流。它生成一个填充零的张量，作为潜空间操作的起点。该节点允许您定义空白潜空间图像的宽度、高度和批次大小。

## 输入
| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `宽度` | 潜空间图像的宽度，以像素为单位（默认值：1024，必须能被16整除） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 潜空间图像的高度，以像素为单位（默认值：1024，必须能被16整除） | INT | 是 | 16 to MAX_RESOLUTION |
| `批次大小` | 批次中生成的潜空间图像数量（默认值：1） | INT | 否 | 1 到 4096 |

注意：`width` 和 `height` 以16为步长定义，因此它们必须是16的倍数。

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `samples` | 生成的空白潜空间图像张量，填充为零，形状为 batch_size x 3 x height x width | LATENT |
