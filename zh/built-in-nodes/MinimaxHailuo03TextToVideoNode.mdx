此节点使用 MiniMax H3 模型根据文本提示生成视频。它会将文本以及分辨率、宽高比和时长等视频设置发送到 MiniMax API，等待生成任务完成，然后返回生成的视频。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于视频生成的模型。（默认值："MiniMax H3"）。选择此模型后，还会提供生成视频的文本提示、分辨率、宽高比和时长设置（请参阅下方的 MiniMax H3 输入）。 | DYNAMIC_COMBO | 是 | `"MiniMax H3"` |
| `随机种子` | 随机种子。使用相同种子发起相同请求时，会生成相似但不保证完全相同的结果。（默认值：42） | INT | 是 | 0 到 4294967295 |
| `水印` | 是否向视频添加 AIGC 水印。（默认值：false） | BOOLEAN | 否 | true<br />false |

### MiniMax H3 输入

当选择“MiniMax H3”模型时，将显示以下设置。

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 用于视频生成的文本提示。 | STRING | 是 | 任意文本 |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | "768P"<br />"2K" |
| `ratio` | 输出视频的宽高比。（默认值："16:9"） | COMBO | 是 | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 输出视频的时长（秒）。（默认值：5） | INT | 是 | 4 到 15 |

注意：`model` 选项中包含的文本提示必须至少包含一个非空白字符。此节点显示的预计价格根据所选分辨率和视频时长计算。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `VIDEO` | 根据提供的文本提示生成的视频。 | VIDEO |
