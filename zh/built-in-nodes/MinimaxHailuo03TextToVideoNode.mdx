此节点使用 MiniMax H3 系列模型（MiniMax H3、MiniMax H3 Max 和 MiniMax H3 Max Turbo）根据文本提示生成视频。您可以选择模型、输入文本提示，并调整分辨率、宽高比和时长等设置。此节点将请求发送至 MiniMax API，等待生成任务完成，然后返回生成的视频。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于视频生成的模型（默认："MiniMax H3"）。选择模型还会显示下文各节中描述的模型专属设置。 | DYNAMIC_COMBO | 是 | "MiniMax H3"<br />"MiniMax H3 Max"<br />"MiniMax H3 Max Turbo" |
| `随机种子` | 随机种子。使用相同种子的相同请求会产生相似但不保证完全相同的结果（默认：42）。 | INT | 是 | 0 到 4294967295 |
| `水印` | 是否向视频添加 AIGC 水印（默认：false）。启用时，仅支持 "MiniMax H3" 模型。 | BOOLEAN | 否 | true<br />false |

### MiniMax H3 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 用于视频生成的文本提示。必须至少包含一个非空白字符。 | STRING | 是 | 任意文本 |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | "768P"<br />"2K" |
| `ratio` | 输出视频的宽高比（默认："16:9"）。 | COMBO | 是 | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 输出视频的时长，单位为秒（4-15）（默认：5）。 | INT | 是 | 4 到 15 |

### MiniMax H3 Max 和 MiniMax H3 Max Turbo 输入

这些设置由 "MiniMax H3 Max" 和 "MiniMax H3 Max Turbo" 模型共享，并在选择任一模型时显示。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 用于视频生成的文本提示。必须至少包含一个非空白字符，且最多可达 50,000 个字符。 | STRING | 是 | 最多 50000 个字符 |
| `resolution` | 输出视频的分辨率（默认："768P"）。 | COMBO | 是 | "480P"<br />"768P" |
| `ratio` | 输出视频的宽高比（默认："16:9"）。 | COMBO | 是 | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 输出视频的时长，单位为秒（5-15）（默认：5）。 | INT | 是 | 5 到 15 |
| `prompt_expansion_mode` | 生成前重写提示所投入的程度（默认："balanced"）。 | COMBO | 是 | "balanced"<br />"quality" |

### 说明

- 对于所有模型，`prompt` 必须至少包含一个非空白字符。
- `watermark` 设置仅受 "MiniMax H3" 支持。对 "MiniMax H3 Max" 或 "MiniMax H3 Max Turbo" 启用该设置会导致错误。
- "MiniMax H3 Max" 和 "MiniMax H3 Max Turbo" 模型将提示限制为 50,000 个字符。
- 分辨率和时长限制取决于所选模型："MiniMax H3" 支持 "768P" 和 "2K" 分辨率以及 4-15 秒视频，而 "MiniMax H3 Max" 和 "MiniMax H3 Max Turbo" 支持 "480P" 和 "768P" 分辨率以及 5-15 秒视频。
- 此节点显示的预估价格根据所选模型、分辨率和时长计算。
