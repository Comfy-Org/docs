此节点使用 MiniMax H3 模型根据文本提示生成视频。它将文本连同视频设置（如分辨率、时长和宽高比）一起发送到 MiniMax API，并返回生成的视频作为输出。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|------|------|---------|------|------|
| `模型` | 用于视频生成的模型。默认值："MiniMax H3"。此选择还包括用于生成视频的文本提示、分辨率、时长和宽高比设置。 | COMBO | 是 | `"MiniMax H3"` |
| `随机种子` | 随机种子。使用相同种子的相同请求会得到相似但不保证完全相同的结果。默认值：42 | INT | 是 | 0 到 4294967295 |
| `水印` | 是否向视频添加 AIGC 水印。默认值：false。这是一个高级选项。 | BOOLEAN | 否 | true<br />false |

注意：`model` 选项中的文本提示必须至少包含一个非空白字符。此节点显示的预估价格是根据所选视频时长计算的。

## 输出
