完成分段 3D 模型的各个部件，并修复网格中缺失或损坏的区域。它接收 Tripo 网格分割结果的任务 ID，向 Tripo 请求补全作业，并等待其完成。您可以选择将工作限制为特定的部件名称。完成的模型以 GLB 文件形式返回。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `segment_task_id` | Tripo 网格分割任务的任务 ID。将补全来自此任务的分段模型的各个部件。连接上一个 Tripo 网格分割节点的 SEGMENT_TASK_ID 输出。 | SEGMENT_TASK_ID | 是 | 单个任务 ID |
| `part_names` | 要补全的部件名称，用逗号分隔。留空则补全每个部件。默认值：空字符串。名称周围的额外空格会被移除，重复名称会被忽略。 | STRING | 否 | 自由文本或留空 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model_file` | 完成模型的文件名。此输出仅为向后兼容而存在。 | STRING |
| `model task_id` | 完成的 Tripo 网格补全任务的任务 ID。可用作其他需要模型任务 ID 的 Tripo 节点的输入。 | MODEL_TASK_ID |
| `GLB` | 修复了部件的完成 3D 模型，以 GLB 文件形式下载。 | GLB |
