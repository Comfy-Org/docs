此节点将 MoGe 点图转换为 3D 网格。它获取由 MoGe 深度估计节点生成的几何数据，并将其三角化为带有 UV 坐标和可选纹理的网格。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `moge_geometry` | 包含点图、深度以及可选源图像的 MoGe 几何数据。 | MOGE_GEOMETRY | 是 | N/A |
| `batch_index` | 要对一批 MoGe 几何数据中的哪张图像进行网格化。每张图像的顶点数不同，因此无法将一批数据堆叠为单个 MESH（默认值：0）。 | INT | 是 | 0 到 4096 |
| `decimation` | 顶点步长；1 = 完整分辨率（默认值：1）。 | INT | 是 | 1 到 8 |
| `discontinuity_threshold` | 丢弃 3x3 深度跨度超过此比例的像素。0 = 关闭（默认值：0.04）。 | FLOAT | 是 | 0.0 到 1.0 |
| `texture` | 将源图像作为 baseColor 纹理传递（默认值：True）。 | BOOLEAN | 是 | True/False |

注意：`batch_index` 必须小于输入 `moge_geometry` 的批次大小；选择超出范围的索引会引发错误。输入必须包含 points 输出，否则节点会引发错误。如果三角化生成空网格，节点会引发错误——将 `discontinuity_threshold` 设置为 0 会禁用深度不连续性过滤。输出网格会转换为 glTF 坐标：透视 MoGe 数据（X 向右、Y 向下、Z 向前）会翻转以匹配 glTF（Y 向上、Z 向后），而全景数据（没有内参的几何数据）会相应旋转并修正绕序。启用 `texture` 时，来自 `moge_geometry` 的源图像将用作 baseColor 纹理。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `MESH` | 带有顶点、面、UV 坐标以及来自源图像的可选 baseColor 纹理的 3D 网格。 | MESH |
