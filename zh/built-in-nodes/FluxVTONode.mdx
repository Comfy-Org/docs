此节点通过将人物放入提供的服装图像中来执行虚拟试穿。它使用 BFL Flux VTO API 生成人物穿着指定服装的逼真图像。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `人物` | 待穿衣的人物图像。 | IMAGE | 是 | - |
| `服装` | 要应用的服装图像。 | IMAGE | 是 | - |
| `提示词` | 可选的自然语言风格指令（例如服装应如何合身）。（默认：空） | STRING | 否 | - |
| `随机种子` | 用于创建噪声的随机种子。（默认：0） | INT | 否 | 0 到 18446744073709551615 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 显示人物穿着提供服装的结果图像。 | IMAGE |
