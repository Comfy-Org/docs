此节点通过将人物穿上所提供服装图像中的服装来执行虚拟试穿。它会将人物图像和服装图像发送到 BFL Flux VTO 服务，由该服务生成人物穿着该服装的逼真图像。可选的文本指令可以描述服装应如何合身或呈现。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `人物` | 要为其穿上服装的人物图像。 | IMAGE | 是 | - |
| `服装` | 要应用的服装图像。 | IMAGE | 是 | - |
| `提示词` | 可选的、用自然语言描述的造型指令（例如服装应如何合身）。默认值为空字符串。 | STRING | 否 | - |
| `随机种子` | 用于生成噪声的随机种子。默认值：0。 | INT | 否 | 0 到 18446744073709551615 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 生成的结果图像，展示人物穿着所提供的服装。 | IMAGE |
