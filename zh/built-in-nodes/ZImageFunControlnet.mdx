ZImageFunControlnet 将控制网络补丁应用于基础模型，使其能够引导图像生成或编辑过程。它组合模型、模型补丁和 VAE，并允许你控制控制效果对结果的影响强度。可选的 `image`、`inpaint_image` 和 `mask` 输入可实现更有针对性的编辑。该节点适用于 Z-Image ControlNet 补丁，以及通过 Load Model Patch 节点加载的 Qwen Image 2.1 Fun ControlNet 补丁。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 用于生成过程的基础模型。 | MODEL | 是 | - |
| `模型补丁` | 用于应用控制网络引导的专用补丁模型。 | MODEL_PATCH | 是 | - |
| `VAE` | 用于编码和解码图像的变分自编码器。 | VAE | 是 | - |
| `强度` | 控制网络影响的强度。正值会应用该效果，而负值可以将其反转（默认值：1.0）。 | FLOAT | 是 | -10.0 到 10.0 （步长：0.01） |
| `图像` | 可选的基础图像，用于引导生成过程。 | IMAGE | 否 | - |
| `重绘图像` | 可选的图像，专门用于修复由遮罩定义的区域。 | IMAGE | 否 | - |
| `遮罩` | 可选的遮罩，用于定义图像中应编辑或修复的区域。 | MASK | 否 | - |
| `start_percent` | 去噪过程中的一个点（占总采样步数的比例），控制网络从该点开始生效（默认值：0.0）。 | FLOAT | 否 | 0.0 到 1.0 （步长：0.001） |
| `end_percent` | 去噪过程中控制网络停止生效的点（默认值：1.0）。 | FLOAT | 否 | 0.0 到 1.0 （步长：0.001） |

**注意：** `inpaint_image` 参数通常与 `mask` 搭配使用，以指定用于图像修复的内容。节点的行为可能会根据提供的可选输入而变化（例如，使用 `image` 进行引导，或使用 `image`、`mask` 和 `inpaint_image` 进行图像修复）。`start_percent` 和 `end_percent` 值将控制网络限制在去噪过程的一个窗口内，在该窗口之外，模型将在不使用补丁的情况下采样。如果 `strength` 为 0，或者 `image`、`inpaint_image` 和 `mask` 均未连接，节点将原样返回基础模型。对于 Z-Image Control 补丁，提供的遮罩在使用前会被反转（1.0 - mask），而 Qwen Image 2.1 Fun ControlNet 补丁则按给定方式使用遮罩。此节点被标记为实验性。
