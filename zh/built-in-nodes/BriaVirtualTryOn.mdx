此节点使用 Bria 为人物穿上服装或配饰。它会保留人物身份、姿态和背景，同时以约 100 万像素重新渲染场景，因此结果不会与输入照片像素对齐。每张服装图像都会替换人物当前穿着的对应单品。

## 输入

当 `moderation` 选择器设置为 `"true"` 时，会显示一个额外的审核选项。

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `person_image` | 试穿服装的人物照片。图像上传前会丢弃 alpha 通道。 | IMAGE | 是 | - |
| `garment_images` | 1 到 3 件一起穿着的服装或配饰，每件都会替换人物当前穿着的对应单品。批量输入按每张图像计数，透明区域按白色处理。 | AUTOGROW | 是 | 1 到 3 张图像 |
| `instruction` | 可选附加指令，会添加到 Bria 的内置指令中，例如指定将哪件服装叠穿在上层。默认值：`""`（空字符串）。 | STRING | 是 | - |
| `aspect_ratio` | `"auto"` 会保持人物照片的构图，约为 100 万像素。固定比例会返回 0.6 至 1 百万像素的结果，例如 `"3:4"` 对应 768x1024。默认值：`"auto"`。 | COMBO | 是 | `"auto"`<br />`"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"` |
| `seed` | 随请求发送给 Bria 的种子。默认值：42。 | INT | 是 | 1 到 2147483647 |
| `moderation` | 审核设置。设置为 `"true"` 时，下方的审核标志将可用。 | DYNAMIC_COMBO | 是 | `"false"`<br />`"true"` |

### `moderation` 为 `"true"` 时的输入

仅当 `moderation` 设置为 `"true"` 时，此参数才会出现。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `visual_output_moderation` | 对生成的图像启用内容审核。默认值：`False`。 | BOOLEAN | 否 | True / False |

**约束：**

* `garment_images` 最多接受 3 张图像；当输入为批量时，按每张图像计数。
* 服装图像中的透明像素在上传前会合成到白色背景上。
* `person_image` 的 alpha 通道会在上传前丢弃。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 编辑后的照片，人物穿着所提供的服装。 | IMAGE |
