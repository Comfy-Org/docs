创建同一语言下某段声音的更改后副本，既可依据更改的文字描述，也可依据具名预设来生成。副本会保存到你的账户，并随音频预览一起返回。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `voice` | 要更改的 Breeze 声音。 | BREEZE_VOICE | 是 | - |
| `change` | `custom` 用文本描述更改内容，`preset` 选择某个具名更改。默认：`"custom"`。 | DYNAMIC_COMBO | 是 | `"custom"`<br />`"preset"` |
| `strength` | 数值越高，声音的变化越大。默认：4.0。 | FLOAT | 否 | 1.0 到 10.0（步长：0.1） |
| `seed` | 控制节点是否会重新运行；无论种子为何，结果都是不确定的。默认：42。 | INT | 否 | 0 到 2147483647 |

### 更改 "custom" 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `prompt` | 声音应如何变化，例如更苍老、更沙哑。默认：空。 | STRING | 是 | 多行文本 |

### 更改 "preset" 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `preset` | 具名更改，按年龄、性别、音高、语速、能量和情感分组。 | COMBO | 是 | 有多个可用选项 |

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `voice` | 更改后的声音副本。 | BREEZE_VOICE |
| `preview` | 混音后声音的音频预览。 | AUDIO |
