根据单个说话人的录音创建 Breeze 声音。该声音会保存到你的账户，并作为声音句柄返回，同时附带其声音效果的音频预览。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `audio` | 单个说话人的录音，时长至少 3 秒。仅使用前 60 秒。 | AUDIO | 是 | - |
| `remove_background_noise` | 在克隆前清理录音。默认：false。 | BOOLEAN | 否 | true<br />false |
| `seed` | 控制节点是否重新运行；无论 `seed` 为何，结果都是非确定性的。默认：42。 | INT | 否 | 0 到 2147483647 |

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `voice` | 新的 Breeze 声音，用于 Breeze Text to Speech。 | BREEZE_VOICE |
| `preview` | 克隆声音的音频预览。 | AUDIO |
