Luma Ray 3.2 Extend Video 通过创建新的 5 秒片段来延续先前的 Luma Ray 3.2 视频生成，该片段可以位于原始片段之后（forward）或之前（backward）。连接较早的 Luma Ray 3.2 节点的 `generation_id` 输出，以将该片段用作扩展的起始帧（forward）或结束帧（backward）。扩展始终为 5 秒长。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 取值范围 |
|-----------|-------------|-----------|----------|-------|
| `source_generation_id` | 要扩展的先前 Ray 3.2 视频的生成 ID。连接另一个 Luma Ray 3.2 节点的 `generation_id` 输出。默认值：""（空）。此值为必填项，且不能为空。 | STRING | 是 | – |
| `direction` | Forward 会接在先前的片段之后继续；Backward 会前置到其之前。Forward 将源片段用作起始帧；Backward 将其用作结束帧。选择 "Forward (continue after)" 会添加 `loop` 选项。 | DYNAMIC_COMBO | 是 | "Forward (continue after)"<br />"Backward (lead-in before)" |
| `prompt` | 用于新内容的文本提示词。默认值：""（空）。长度必须在 1 到 6000 个字符之间。 | STRING | 是 | 1 到 6000 characters |
| `resolution` | 扩展视频片段的输出分辨率。默认值："720p"。 | COMBO | 是 | "540p"<br />"720p"<br />"1080p" |
| `seed` | 用于确定节点是否应重新运行的种子；无论种子如何，结果都是非确定性的。默认值：0。 | INT | 是 | 0 到 0xFFFFFFFFFFFFFFFF (18446744073709551615) |

### Forward (continue after) 输入

| 参数 | 描述 | 数据类型 | 必填 | 取值范围 |
|-----------|-------------|-----------|----------|-------|
| `loop` | 使扩展视频无缝循环（仅限 forward 扩展）。默认值：False。 | BOOLEAN | 否 | True<br />False |

### Backward (lead-in before) 输入

此方向不添加任何额外参数。

**注意：** 扩展始终为 5 秒。仅当 `direction` 为 "Forward (continue after)" 时，`loop` 参数才可用；使用 "Backward (lead-in before)" 时，`loop` 选项不可用。`prompt` 的长度必须在 1 到 6000 个字符之间。`source_generation_id` 为必填项，并且必须连接自先前 Luma Ray 3.2 节点的 `generation_id` 输出。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `VIDEO` | 生成的 5 秒扩展视频片段。 | VIDEO |
| `generation_id` | 此生成的唯一标识符，可连接到另一个 Luma Ray 3.2 Extend Video 节点以进行进一步扩展。 | STRING |
