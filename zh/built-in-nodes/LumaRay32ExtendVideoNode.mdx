Luma Ray 3.2 Extend Video 通过创建新的 5 秒片段来延续之前的 Luma Ray 3.2 视频生成，该片段可位于原始片段之后（正向）或之前（反向）。连接较早 Luma Ray 3.2 节点的 `generation_id` 输出，将该片段用作扩展的起始帧（正向）或结束帧（反向）。

## ## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 取值范围 |
|------|------|----------|----------|----------|
| `source_generation_id` | 待扩展的先前 Ray 3.2 视频的生成 ID。连接另一个 Luma Ray 3.2 节点的 `generation_id` 输出。此值为必填，不能为空。 | STRING | 是 | - |
| `direction` | 正向表示在先前片段之后继续；反向表示在先前片段之前添加。选择"正向（之后继续）"还会添加 `loop` 选项。 | COMBO | 是 | "正向（之后继续）"<br />"反向（之前插入）" |
| `loop` | 使扩展后的视频无缝循环（仅限正向扩展）。仅当 `direction` 为"正向（之后继续）"时可用。默认值：False。 | BOOLEAN | 否 | True<br />False |
| `prompt` | 描述要生成的新内容的文本提示。长度必须在 1 到 6000 个字符之间。 | STRING | 是 | - |
| `resolution` | 扩展视频片段的输出分辨率。默认值："720p"。 | COMBO | 是 | "540p"<br />"720p"<br />"1080p" |
| `seed` | 用于可重复生成结果的随机种子。 | INT | 是 | - |

**注意：** `loop` 参数仅在 `direction` 设置为"正向（之后继续）"时可用。使用"反向（之前插入）"时，循环选项不可用。`prompt` 的长度必须在 1 到 6000 个字符之间。

## ## 输出

| 输出名称 | 描述 | 数据类型 |
|----------|------|----------|
| `VIDEO` | 生成的 5 秒扩展视频片段。 | VIDEO |
| `generation_id` | 本次生成的唯一标识符，可连接到另一个 Luma Ray 3.2 扩展视频节点以进行进一步扩展。 | STRING |
