Luma Ray 3.2 Extend Video 通过创建一段新的 5 秒片段（位于原始片段之后（向前）或之前（向后））来延续之前的 Luma Ray 3.2 视频生成。将较早的 Luma Ray 3.2 节点的 `generation_id` 输出连接起来，即可将该片段用作扩展的起始帧（向前）或结束帧（向后）。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `direction` | 向前将在先前片段之后继续；向后则会前置到其之前。向前使用源片段作为起始帧；向后将其用作结束帧。选择“Forward (continue after)”会添加 `loop` 选项。 | DYNAMIC_COMBO | 是 | "Forward (continue after)"<br />"Backward (lead-in before)" |
| `source_generation_id` | 要扩展的先前 Ray 3.2 视频的生成 ID。连接另一个 Luma Ray 3.2 节点的 `generation_id` 输出。此值为必填项，且不能为空。 | STRING | 是 | – |
| `prompt` | 新内容的文本提示。长度必须在 1 到 6000 个字符之间。 | STRING | 是 | 1 到 6000 个字符 |
| `resolution` | 扩展视频片段的输出分辨率。默认值："720p"。 | COMBO | 是 | "540p"<br />"720p"<br />"1080p" |
| `seed` | 用于确定节点是否应重新运行的种子；无论种子如何，结果都是不确定的。默认值：0。 | INT | 是 | 0 到 0xFFFFFFFFFFFFFFFF |

### 向前（之后继续）输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `loop` | 无缝循环扩展视频（仅限向前延续）。默认值：False。 | BOOLEAN | 否 | True<br />False |

### 向后（之前前置）输入

此方向不添加额外参数。

**注意：** 扩展长度始终为 5 秒。`loop` 参数仅在 `direction` 为“Forward (continue after)”时可用；使用“Backward (lead-in before)”时，`loop` 选项不可用。`prompt` 必须在 1 到 6000 个字符之间。`source_generation_id` 为必填项，且必须连接自先前 Luma Ray 3.2 节点的 `generation_id` 输出。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `VIDEO` | 生成的 5 秒扩展视频片段。 | VIDEO |
| `generation_id` | 此生成的唯一标识符，可连接到另一个 Luma Ray 3.2 Extend Video 节点以进行进一步扩展。 | STRING |
