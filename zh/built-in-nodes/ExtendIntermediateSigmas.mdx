ExtendIntermediateSigmas 节点接收现有 sigma 值序列，并在它们之间插入额外的中间 sigma 值。您可以通过该节点指定要添加的额外步数、插值时的间隔方法，以及可选的起始和结束 sigma 边界，以控制扩展在 sigma 序列中的发生范围。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `sigmas` | 需要插入中间值以进行扩展的输入 sigma 序列 | SIGMAS | 是 | - |
| `步数` | 控制每对现有 sigma 之间插入的中间 sigma 值数量。两个 sigma 之间的区间会被划分为 `steps` 段，每对产生 `steps - 1` 个新值（默认值：2，即每对插入一个值） | INT | 是 | 1 到 100 |
| `起始 sigma` | 扩展的 sigma 上限边界——仅扩展低于此值的 sigma（默认值：-1.0，表示无穷大） | FLOAT | 是 | -1.0 到 20000.0 |
| `结束 sigma` | 扩展的 sigma 下限边界——仅扩展高于此值的 sigma（默认值：12.0） | FLOAT | 是 | 0.0 到 20000.0 |
| `间距方式` | 用于中间 sigma 值间隔的插值方法（默认值：`"linear"`） | COMBO | 是 | `"linear"`<br />`"cosine"`<br />`"sine"` |

**注意：** 该节点仅在当前 sigma 小于或等于 `start_at_sigma` 且大于或等于 `end_at_sigma` 的现有 sigma 对之间插入中间 sigma。当 `start_at_sigma` 设置为 -1.0 时，它会被视为无穷大，这意味着只有 `end_at_sigma` 下限边界生效。

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `sigmas` | 扩展后的 sigma 序列，其中插入了额外的中间值 | SIGMAS |
