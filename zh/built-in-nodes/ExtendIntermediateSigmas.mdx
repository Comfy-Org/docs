ExtendIntermediateSigmas 节点接收现有的 sigma 值序列，并在它们之间插入额外的中间 sigma 值。它允许你指定要添加多少额外步数、用于插值的间距方法，以及可选的起始和结束 sigma 边界，以控制扩展在 sigma 序列中发生的位置。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `sigmas` | 用于通过中间值扩展的输入 sigma 序列 | SIGMAS | 是 | - |
| `步数` | 控制每对现有 sigma 之间插入的中间 sigma 值的数量。两个 sigma 之间的间隔被分成 `steps` 部分，每对生成 `steps - 1` 个新值（默认：2，即每对插入一个值） | INT | 是 | 1 到 100 |
| `起始 sigma` | 扩展的上 sigma 边界。只有起始 sigma 小于或等于此值的 sigma 间隔才会被扩展。当设为 -1.0 时，它被视为无穷大，意味着不应用上限。默认：-1.0 | FLOAT | 是 | -1.0 到 20000.0 |
| `结束 sigma` | 扩展的下 sigma 边界。只有起始 sigma 大于或等于此值的 sigma 间隔才会被扩展。默认：12.0 | FLOAT | 是 | 0.0 到 20000.0 |
| `间距方式` | 用于间隔中间 sigma 值的插值方法（默认：`"linear"`） | COMBO | 是 | `"linear"`<br />`"cosine"`<br />`"sine"` |

**注意：** 该节点仅会为起始 sigma 小于或等于 `start_at_sigma` 且大于或等于 `end_at_sigma` 的 sigma 间隔插入中间 sigma。当 `start_at_sigma` 设为 -1.0 时，它被视为无穷大，因此仅应用 `end_at_sigma` 下边界。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `sigmas` | 扩展后的 sigma 序列，其中插入了额外的中间值 | SIGMAS |
