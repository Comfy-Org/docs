将 Fibo 2.0 提示词编码为 conditioning 以及匹配的空 latent。该提示词可以是纯文本或结构化的 JSON 描述；连接图像后，它将成为编辑指令，或包含 `edit_instruction` 键的结果 JSON 描述，并且在连接 VAE 时，图像会作为两个输出的参考 latent。对 `latent` 输出进行采样，其尺寸为图像被裁剪后的尺寸。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 用于对提示词进行分词和编码的 Fibo 2.0 文本编码器。 | CLIP | 是 | - |
| `prompt` | 要据此生成的描述，或在连接图像时作为编辑指令。使用 `<image_1>`、`<image_2>` 等来引用图像。也可以使用预期结果的 JSON 描述，并在其 `edit_instruction` 键中描述更改。 | STRING | 是 | - |
| `negative_prompt` | 要避开的描述，编码为负向 conditioning。非空值会按原样放入 Fibo 2.0 的聊天模板中送出，不会像描述那样被清洗。空值表示 Fibo 2.0 在编辑工作流中做无分类器引导时使用的空描述（默认：空）。 | STRING | 是 | - |
| `vae` | 用于将图像编码为参考 latent 的 VAE。若不提供，图像仅用于调节文本编码。 | VAE | 否 | - |
| `images` | 要编辑的图像，最多 16 张。单张图像会被缩放并居中裁剪至结果尺寸，因为编辑会与其逐像素对齐；多张图像则各自缩放至其训练尺寸。 | IMAGE | 否 | 0 到 16 张图像 |
| `width` | 结果的宽度，向下取整为 16 的倍数。0 表示使用 Fibo 2.0 针对第一张图像宽高比训练时的尺寸，约 1 百万像素；无图像时为 1024（默认：0）。 | INT | 是 | 0 到 16384 （步长：16） |
| `height` | 结果的高度，向下取整为 16 的倍数。0 表示使用 Fibo 2.0 针对第一张图像宽高比训练时的尺寸，约 1 百万像素；无图像时为 1024（默认：0）。 | INT | 是 | 0 到 16384 （步长：16） |
| `batch_size` | 批次中要创建的 latent 数量（默认：1）。 | INT | 是 | 1 到 4096 |

参考 latent 会附加到两个输出上，因此图像随 conditioning 一起传递，而不仅仅跟随正向分支。当未连接 VAE 时，图像仅由文本编码器看到，不会添加参考 latent。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 提示词的 conditioning，在连接 VAE 和图像时包含参考 latent。 | CONDITIONING |
| `negative` | `negative_prompt` 的 conditioning，仅文本，带有相同的参考 latent。 | CONDITIONING |
| `latent` | 指定尺寸的空 latent，可供采样。 | LATENT |
