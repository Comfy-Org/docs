SaveAudioMP3 节点将音频数据保存为 MP3 文件。它接收音频输入，并通过可自定义的文件名和质量设置将其导出到输出目录，自动处理文件命名和 MP3 格式转换。**此节点已弃用，可能会在未来版本中移除。**

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 取值范围 |
|-----------|-------------|-----------|----------|-------|
| `音频` | 要保存为 MP3 文件的音频数据 | AUDIO | 是 | - |
| `文件名前缀` | 输出文件名的前缀（默认值："audio/ComfyUI"） | STRING | 否 | - |
| `质量` | MP3 文件的音频质量设置（默认值："V0"） | COMBO | 否 | `"V0"`<br />`"128k"`<br />`"320k"` |
| `prompt` | 内部提示数据，由系统自动提供 | PROMPT | 否 | - |
| `extra_pnginfo` | 附加 PNG 信息，由系统自动提供 | EXTRA_PNGINFO | 否 | - |

**注意：** 如果输入 `audio` 为 None（例如，当源视频没有音轨时），节点将引发 ValueError。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `audio` | 已保存为 MP3 文件的音频数据 | AUDIO |
