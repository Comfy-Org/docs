## 概述

此节点编码编辑指令（提示词）以及一个或多个参考图像，用于 Mage-Flow-Edit 模型。它会将所有参考图像调整为目标输出分辨率，如果提供了 VAE，则将它们编码到潜在空间，并将参考潜在向量附加到条件输出中。同时会生成一个尺寸与采样输入匹配的空白潜在张量，确保其宽高始终与输出宽度和高度一致。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 用于分词和编码文本提示词的 CLIP 模型。 | CLIP | 是 | |
| `prompt` | 要应用的编辑指令（正向提示词）。 | STRING | 是 | 多行，启用动态提示词 |
| `negative_prompt` | 用于避免生成的负向提示词。默认：空字符串（留空时内部使用空格）。 | STRING | 否 | 多行，启用动态提示词 |
| `vae` | 用于将参考图像编码到潜在空间的 VAE 模型。如未提供，则不会向条件输出添加参考潜在向量。 | VAE | 否 | |
| `images` | 一个或多个要编辑的参考图像。所有图像在编码前都会调整为输出分辨率。 | IMAGE（自动增长） | 否 | 最多 16 个图像（命名为 `image_1`…`image_16`），至少 0 个 |
| `width` | 输出宽度（像素）。如果设为 0，则使用第一个参考图像的宽度。始终向下取整为 16 的倍数。默认：0。 | INT | 是 | 0 到 8192（步长 16） |
| `height` | 输出高度（像素）。回落行为与宽度相同。默认：0。 | INT | 是 | 0 到 8192（步长 16） |
| `batch_size` | 要生成的潜在样本数量。默认：1。 | INT | 是 | 1 到 4096 |

**参数依赖说明：**
- 如果 `width` 和/或 `height` 为 0 且未提供参考图像，则各自回退为 1024。
- `vae` 参数为可选；仅当连接了 VAE 时，才会生成参考潜在向量并附加到条件输出中。
- `negative_prompt` 字段为可选——如果留空，内部默认使用一个空格作为负向文本。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `positive` | 条件输出，包含正向提示词标记，以及（如果提供了 VAE）编码后的参考潜在向量。 | CONDITIONING |
| `negative` | 条件输出，包含负向提示词标记，以及相同的参考潜在向量（如果提供了 VAE）。 | CONDITIONING |
| `latent` | 形状为 `[batch_size, 128, height÷16, width÷16]` 的空白潜在张量，用于采样时的初始噪声。 | LATENT |
