此节点对 LTXV-AV 模型应用跨模态（音频-视频）引导。在采样过程中，它每一步额外执行一次前向传播，并禁用音频到视频和视频到音频的交叉注意力连接，然后将结果推向耦合预测，以增强音视频同步，例如唇形同步。`modality_scale` 的参考默认值为 3.0；将其设置为 1.0 可禁用额外的前向传播，并且该节点可与 dual-CFG guider 和 STG 协同使用。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 将应用模态引导的基础模型。内部会克隆该模型，原始模型保持不变。 | MODEL | 是 | - |
| `modality_scale` | 音视频耦合引导的强度。默认为 3.0。设置为 1.0 可禁用额外的前向传播。 | FLOAT | 是 | 1.0 到 100.0 (default: 3.0) |
| `start_percent` | 采样过程中模态引导开始的点，以 0.0 到 1.0 的百分比表示。这是一个高级参数。默认为 0.0。 | FLOAT | 是 | 0.0 到 1.0 (default: 0.0) |
| `end_percent` | 采样过程中模态引导结束的点，以 0.0 到 1.0 的百分比表示。这是一个高级参数。默认为 1.0。 | FLOAT | 是 | 0.0 到 1.0 (default: 1.0) |

引导仅应用于 sigma 值落在 `start_percent` 和 `end_percent` 所定义范围内的采样步骤。在此范围之外，节点会原样返回去噪结果。`modality_scale` 设为 1.0 也会完全禁用额外的前向传播。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model` | 附有 post-CFG 引导函数的克隆模型。此修改后的模型会在采样过程中应用模态引导。 | MODEL |
