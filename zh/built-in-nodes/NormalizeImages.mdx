此节点通过根据指定的均值和标准差调整输入图像的像素值来归一化其颜色。每个像素减去均值，然后除以标准差，这是在其它处理之前标准化图像数据的常见步骤。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 要归一化的输入图像。 | IMAGE | 是 | - |
| `平均` | 用于归一化的均值（默认值：0.5）。 | FLOAT | 否 | 0.0 - 1.0 |
| `标准差` | 用于归一化的标准差（默认值：0.5）。 | FLOAT | 否 | 0.001 - 1.0 |

`mean` 和 `std` 参数控制应用于输入图像的归一化。两个参数的默认值均为 0.5。

注意：如果输入图像具有 Alpha（透明度）通道，该通道不会被归一化。它会原样复制到输出，因为 Alpha 存储的是透明度而非颜色。

注意：此节点适用于任意批次大小，因此可以一次处理多张图像。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 应用归一化过程后得到的图像。像素值使用指定的均值和标准差进行调整，并且 Alpha 通道（如果存在）会保留。 | IMAGE |
