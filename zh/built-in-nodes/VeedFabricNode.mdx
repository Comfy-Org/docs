使用 VEED Fabric 将静态图像和语音轨道转换为会说话、口型同步的视频。它适用于照片、插图和吉祥物，只要面部清晰可见即可；视频会保持图像的宽高比，其时长与音频长度相同。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 要使用的模型。选择模型后会显示该模型特有的参数：`image`、`audio` 和 `resolution`。 | DYNAMIC_COMBO | 是 | `"fabric-1.0"` |
| `image` | 面部清晰可见的图像。视频会保持其宽高比。 | IMAGE | 是 | - |
| `audio` | 用于进行口型同步的语音，最长 300 秒。决定视频长度。 | AUDIO | 是 | 最长 300 秒 |
| `resolution` | 输出尺寸类别：`"480p"` 时约为 0.4 兆像素（16:9 下为 864x480），`"720p"` 时约为 0.9 兆像素（16:9 下为 1312x736）。（默认值：`"720p"`） | COMBO | 是 | `"480p"`<br />`"720p"` |

当语音轨道超过 300 秒时，节点会报错停止。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `VIDEO` | 会说话的视频：输入图像经过动画处理以匹配语音轨道。 | VIDEO |
