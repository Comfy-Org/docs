此节点允许用户与 Google 的 Gemini AI 模型交互，以生成文本回复。您可以提供多种类型的输入，包括文本、图像、音频、视频和文件，作为模型的上下文，从而生成更相关、更有意义的回复。该节点会自动处理所有 API 通信和响应解析。

**注意：** 此节点在源代码中已标记为已弃用。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示` | 提供给模型的文本输入，用于生成回复。您可以包含详细说明、问题或模型所需的上下文。默认值：空字符串。 | STRING | 是 | - |
| `模型` | 用于生成回复的 Gemini 模型。默认值：gemini-3-1-pro。 | COMBO | 是 | "gemini-2.5-pro"<br />"gemini-2.5-flash"<br />"gemini-3-pro-preview"<br />"gemini-3-1-pro"<br />"gemini-3-1-flash-lite" |
| `种子` | 当 `seed` 固定为特定值时，模型会尽最大努力对重复请求提供相同的回复。但无法保证输出具有确定性。此外，更改模型或参数设置（例如 `temperature`）可能导致回复发生变化，即使使用相同的 `seed` 值也是如此。默认情况下，会使用随机 `seed` 值。默认值：42。 | INT | 是 | 0 到 18446744073709551615 |
| `图像` | 可选的图像，用作模型的上下文。要包含多张图像，可以使用 Batch Images 节点。默认值：None。 | IMAGE | 否 | - |
| `音频` | 可选的音频，用作模型的上下文。默认值：None。 | AUDIO | 否 | - |
| `视频` | 可选的视频，用作模型的上下文。默认值：None。 | VIDEO | 否 | - |
| `文件` | 可选的文件，用作模型的上下文。接受来自 Gemini Generate Content Input Files 节点的输入。默认值：None。 | GEMINI_INPUT_FILES | 否 | - |
| `系统提示词` | 用于规定 AI 行为的基础指令。默认值：空字符串。这是一个高级参数。 | STRING | 否 | - |

所有已连接的图像都会用作上下文。当提供的图像超过 10 张时，前 10 张会作为文件引用上传，其余图像则会以内联方式发送到 API。

该节点使用列表中给出的所选模型名称；部分条目会在请求发送前在内部映射为其当前的 API 模型标识符。
