此节点允许用户与 Google 的 Gemini AI 模型交互以生成文本响应。您可以提供多种类型的输入，包括文本、图像、音频、视频和文件，作为模型的上下文，以生成更相关、更有意义的响应。该节点会自动处理所有 API 通信和响应解析。

**注意：** 此节点在源代码中被标记为已弃用。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示` | 输入给模型的文本，用于生成响应。您可以包含详细的指令、问题或上下文。默认：空字符串。 | STRING | 是 | - |
| `模型` | 用于生成响应的 Gemini 模型。默认：gemini-3-1-pro。 | COMBO | 是 | "gemini-2.5-pro"<br />"gemini-2.5-flash"<br />"gemini-3-pro-preview"<br />"gemini-3-1-pro"<br />"gemini-3-1-flash-lite" |
| `种子` | 当种子值固定为特定值时，模型会尽力为重复请求提供相同的响应，但不保证确定性输出。此外，即使使用相同的种子值，更改模型或温度等参数设置也可能导致响应发生变化。默认情况下，会使用随机种子值。默认：42。 | INT | 是 | 0 到 18446744073709551615 |
| `图像` | 可选，用作模型上下文的图像。若要包含多张图像，可以使用 Batch Images 节点。默认：无。 | IMAGE | 否 | - |
| `音频` | 可选，用作模型上下文的音频。默认：无。 | AUDIO | 否 | - |
| `视频` | 可选，用作模型上下文的视频。默认：无。 | VIDEO | 否 | - |
| `文件` | 可选，用作模型上下文的文件。接受来自 Gemini Generate Content Input Files 节点的输入。默认：无。 | GEMINI_INPUT_FILES | 否 | - |
| `系统提示词` | 用于规定 AI 行为的基础指令。默认：空字符串。这是一个高级参数。 | STRING | 否 | - |

所有已连接的图像都会作为上下文使用。当提供的图像超过 10 张时，前 10 张将作为文件引用上传，其余图像则会以内联方式发送到 API。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `STRING` | Gemini 模型生成的文本响应。如果模型未生成任何文本，则节点返回“Empty response from Gemini model...”。 | STRING |
