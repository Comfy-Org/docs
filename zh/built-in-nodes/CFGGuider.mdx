CFG Guider 节点创建一个引导系统，用于控制图像生成中的采样过程。它接收一个模型以及正向和负向条件输入，然后应用无分类器指导系数来引导生成朝向期望内容，同时避免不需要的元素。此节点输出一个引导器（guider）对象，采样节点可使用该对象来控制图像生成方向。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 用于引导的模型 | MODEL | 是 | - |
| `正面条件` | 正向条件，引导生成朝向期望内容 | CONDITIONING | 是 | - |
| `负面条件` | 负向条件，使生成远离不需要的内容 | CONDITIONING | 是 | - |
| `CFG` | 无分类器指导系数，控制条件对生成的影响强度（默认值：8.0） | FLOAT | 是 | 0.0 到 100.0 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `GUIDER` | 一个引导器对象，可传递给采样节点以控制生成过程 | GUIDER |
