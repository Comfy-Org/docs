Creatify Boreal-H3 Reference to Video 可在参考图像、视频和音频的引导下生成带声音的视频，使用的是 Creatify 为视频广告而经后训练（post-trained）的 H3 模型。在提示词中以 `@Image1`、`@Video1` 和 `@Audio1` 命名各参考，即可控制每个参考所发挥的作用。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可增长的槽位，最多 9 张参考图像（`image_1` ... `image_9`），在提示词中按连接顺序以 `@Image1` ... `@Image9` 引用。至少需要一张图像或一个视频，参考总数最多 12 个。 | IMAGE | 否 | 最多 9 张图像 |
| `reference_videos` | 可增长的槽位，最多 3 个参考视频（`video_1` ... `video_3`），每个至少 1 秒长。当提示词要求延续其声音时会复用该声音；提示词中新写的一行会将其替换。计费的参考视频总时长最多为 15 秒。 | VIDEO | 否 | 最多 3 个视频 |
| `reference_audios` | 可增长的槽位，最多 3 段参考音频片段（`audio_1` ... `audio_3`）。语音引导的是音色而非具体词句，器乐音乐可以成为配乐。 | AUDIO | 否 | 最多 3 段音频片段 |
| `prompt` | 用于描述视频并引用所连接参考的文本提示词。必须包含至少一个非空白字符。 | STRING | 是 | 任意非空文本 |
| `resolution` | 输出视频的分辨率（默认：`"768p"`）。 | COMBO | 是 | `"768p"`<br />`"1088p"`<br />`"2k"` |
| `aspect_ratio` | 输出视频的宽高比。`"auto"` 跟随第一张参考图像；当没有连接图像时，跟随第一个参考视频（默认：`"auto"`）。 | COMBO | 是 | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 视频时长，单位为秒（默认：5）。在 `"2k"` 下最大为 14 秒。 | INT | 是 | 1 到 15（步长 1） |
| `prompt_enhancement` | Creatify 在渲染前如何重写提示词：`"auto"` 和 `"ads"` 会将其转换为视频广告提示词，并可能添加口播台词；`"general"` 会将其改写为适用于其他任意视频；`"none"` 则按原文渲染（默认：`"auto"`）。 | COMBO | 是 | `"auto"`<br />`"ads"`<br />`"general"`<br />`"none"` |
| `seed` | 种子控制节点是否重新运行。Creatify 会自行选择随机性，因此只有将 `prompt_enhancement` 设为 `"none"` 时，相同的输入才会生成相同的视频（默认：42）。 | INT | 是 | 0 到 2147483647 |

**约束：** 至少连接一张参考图像或一个参考视频；仅音频不被接受。指向的连接参考数量超出该类参考实际连接数量的参考标签会引发错误，参考总数超过 12 个同样会引发错误。当使用 `"1088p"` 和 `"auto"` 且没有参考图像时，宽高比取自第一个参考视频。
