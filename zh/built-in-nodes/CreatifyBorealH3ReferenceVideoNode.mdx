Creatify Boreal-H3 参考生视频节点可以借助参考图像、视频和音频，生成带声音的视频；它使用的是 Creatify 针对视频广告场景后训练得到的 H3 模型。请在提示词中用 `@Image1`、`@Video1` 和 `@Audio1` 来命名各参考内容，以控制每一项所起的作用。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 可增长的槽位，最多可容纳 9 张参考图像（`image_1` ... `image_9`），在提示词中按连接顺序以 `@Image1` ... `@Image9` 引用。至少需要一张图像或一段视频，参考内容总数最多为 12 个。 | IMAGE | 否 | 最多 9 张图像 |
| `reference_videos` | 可增长的槽位，最多可容纳 3 段参考视频（`video_1` ... `video_3`），每段至少 1 秒长。当提示词要求延续其声音时，会复用这些参考视频的声音；提示词中的新台词会将其替换。参考视频总计最多按 15 秒计费。 | VIDEO | 否 | 最多 3 段视频 |
| `reference_audios` | 可增长的槽位，最多可容纳 3 段参考音频片段（`audio_1` ... `audio_3`）。语音用于引导音色而非具体字词，器乐可作为配乐。 | AUDIO | 否 | 最多 3 段音频片段 |
| `prompt` | 用于描述视频并引用已连接参考内容的文本提示词。必须至少包含一个非空白字符。 | STRING | 是 | 任意非空文本 |
| `resolution` | 输出视频的分辨率（默认：`"768p"`）。 | COMBO | 是 | `"768p"`<br />`"1088p"`<br />`"2k"` |
| `aspect_ratio` | 输出视频的宽高比。`"auto"` 会跟随第一张参考图像。若仅连接了参考视频且分辨率为 `"1088p"`，节点会选择最接近第一段视频的受支持比例，这可能与其准确比例不同；在其他分辨率下，`"auto"` 会按原样传递给 Creatify（默认：`"auto"`）。 | COMBO | 是 | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 视频长度，单位为秒（默认：5）。在 `"2k"` 下最大为 14 秒。 | INT | 是 | 1 到 15（步长：1） |
| `prompt_enhancement` | Creatify 在渲染前重写提示词的方式：`"auto"` 和 `"ads"` 会将其转换为视频广告提示词，并且可能添加口播台词；`"general"` 会针对其他任何视频进行重写；`"none"` 会按原文渲染（默认：`"auto"`）。 | COMBO | 是 | `"auto"`<br />`"ads"`<br />`"general"`<br />`"none"` |
| `seed` | 种子控制该节点是否重新运行。Boreal-H3 不会接收到种子，因此使用相同输入重新运行可能会生成不同的视频（默认：42）。 | INT | 是 | 0 到 2147483647 |

**约束：** 至少连接一张参考图像或一段参考视频；仅音频不被接受。若参考标签指向的序号超过了该类型已连接参考的数量，则会引发错误；参考内容总数超过 12 个也会引发错误。当使用 `"1088p"` 和 `"auto"` 且未连接参考图像时，宽高比将取自第一段参考视频。
