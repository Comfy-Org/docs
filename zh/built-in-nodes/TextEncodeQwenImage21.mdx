TextEncodeQwenImage21 节点为 Qwen-Image 2.1 模型编码提示词和负面提示词，并可选择附加参考图像。参考图像会被文本编码器读取，并且在连接 VAE 时，还会被编码为 latent 并拼接到序列中，因此条件化数据同时携带文本指令和视觉参考。该节点返回正向和负向条件化数据，以及一个根据第一张参考图像调整大小的空 latent，可直接用于采样。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 用于对提示词进行分词和编码的 Qwen-Image 2.1 文本编码器。 | CLIP | 是 | - |
| `prompt` | 描述要生成的图像或要应用的编辑的文本提示词。支持多行输入和动态提示词。 | STRING | 是 | 任意文本 |
| `negative_prompt` | 描述结果应避免内容的文本提示词。支持多行输入和动态提示词。 | STRING | 是 | 任意文本 |
| `vae` | 用于将参考图像编码为参考 latent 的 VAE。省略时，参考图像仅通过文本编码器对结果进行条件化。 | VAE | 否 | - |
| `resolution` | 参考图像会被调整为大约 `resolution` x `resolution` 像素，尺寸为 32 的倍数，并保持宽高比。0 会保留每张参考图自身的尺寸，并舍入到 32 的倍数（默认：1024）。 | INT | 是 | 0 到 4096（步长 32） |
| `images` | 参考图像，会由文本编码器读取，并作为 VAE latent 拼接到序列中。可扩展槽位：最多可连接 16 张图像（`image_1` ... `image_16`）。 | IMAGE | 否 | 0 到 16 张图像 |

空 latent 输出的大小会根据第一张已连接的参考图像确定；如果未连接参考图像，则根据 `resolution` 确定。请使用此节点返回的 latent 进行采样：任何其他尺寸都会导致编辑偏移。连接 VAE 时，相同的参考 latent 会附加到正向和负向条件化数据上，因此单次采样器步骤即可对两者去噪。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 为提示词编码后的条件化数据；连接 VAE 时携带参考 latent。 | CONDITIONING |
| `negative` | 为负面提示词编码后的条件化数据，并带有相同的参考 latent。 | CONDITIONING |
| `latent` | 根据第一张参考图像尺寸生成的空 latent；未连接参考图像时为 1024 x 1024。 | LATENT |
