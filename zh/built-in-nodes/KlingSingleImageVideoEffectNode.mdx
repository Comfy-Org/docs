Kling Single Image Video Effect 节点基于单张参考图像创建具有不同特效的视频。它应用各种视觉效果和场景，将静态图像转换为动态视频内容。该节点支持不同的特效场景、模型选项和视频时长，以实现所需的视觉效果。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 参考图像。URL 或 Base64 编码字符串（不带 data:image 前缀）。文件大小不能超过 10MB，分辨率不低于 300x300px，宽高比介于 1:2.5 到 2.5:1 之间 | IMAGE | 是 | - |
| `effect_scene` | 要应用于视频生成的特效场景类型。某些特效可能定价不同。 | COMBO | 是 | `"dizzydizzy"`<br />`"bloombloom"`<br />`"neon"`<br />`"cartoon"`<br />`"sketch"`<br />`"oil"`<br />`"watercolor"`<br />`"3d"` |
| `model_name` | 用于生成视频特效的特定模型版本。 | COMBO | 是 | `"kling-v1-5"`<br />`"kling-v1-6"` |
| `duration` | 生成视频的长度，单位为秒。 | COMBO | 是 | `"5"`<br />`"10"` |

**注意：** `effect_scene` 参数会影响节点的定价。特效 `dizzydizzy` 和 `bloombloom` 每次生成费用为 0.49 美元，而所有其他特效每次生成费用为 0.28 美元。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 应用特效后生成的视频 | VIDEO |
| `video_id` | 生成视频的唯一标识符 | STRING |
| `duration` | 生成视频的时长 | STRING |
