此节点将引导图像锚定到 Luma Ray 3.2 输出视频时间线上的特定位置。将此节点连接到 Luma Ray 3.2 Keyframes to Video 节点的 `keyframes` 输入，并通过连接可选的 `keyframes` 输入将多个关键帧链接在一起。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 要放置在输出视频所选时刻的引导图像。 | IMAGE | 是 | - |
| `position` | 如何将此图像放置在输出视频的时间线上。 | DYNAMIC_COMBO | 是 | "Fraction of duration (0.0-1.0)"<br />"Absolute time (seconds)" |
| `keyframes` | 可选的更早关键帧，用于与此关键帧链接。 | LUMA_RAY32_KEYFRAME | 否 | - |

### Fraction of duration (0.0-1.0) 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `fraction` | 此图像应用于输出视频中的位置（0.0 = 开始，1.0 = 结束）。默认值：0.0。 | FLOAT | 是 | 0.0 到 1.0 （步长：0.01） |

### Absolute time (seconds) 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `seconds` | 从输出视频开始到应用此图像的时间（秒）。默认值：0.0。 | FLOAT | 是 | 0.0 到 10.0 （步长：0.1） |

`position` 参数决定使用哪个值来将图像放置在时间线上。仅显示和使用属于所选选项的子参数：`fraction` 用于 "Fraction of duration (0.0-1.0)"，`seconds` 用于 "Absolute time (seconds)"。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `keyframes` | 一个关键帧链，包含新关键帧与任何可选的更早关键帧组合。 | LUMA_RAY32_KEYFRAME |
