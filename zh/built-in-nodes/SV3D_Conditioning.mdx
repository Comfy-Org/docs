SV3D_Conditioning 使用 SV3D 模型为 3D 视频生成准备条件数据。它接收一张初始图像，并通过 CLIP vision 和 VAE 编码器对其进行处理，从而创建正向和负向条件数据，以及一个 latent 表示。该节点会根据指定的视频帧数，生成用于多帧视频生成的相机仰角和方位角序列。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 取值范围 |
| --- | --- | --- | --- | --- |
| `clip视觉` | 用于编码输入图像的 CLIP vision 模型 | CLIP_VISION | 是 | - |
| `初始图像` | 作为 3D 视频生成起点的初始图像 | IMAGE | 是 | - |
| `vae` | 用于将图像编码到 latent 空间的 VAE 模型 | VAE | 是 | - |
| `宽度` | 生成视频帧的输出宽度（默认值：576，步长为 8） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 生成视频帧的输出高度（默认值：576，步长为 8） | INT | 是 | 16 to MAX_RESOLUTION |
| `帧数` | 视频序列要生成的帧数（默认值：21） | INT | 是 | 1 到 4096 |
| `俯仰角` | 3D 视角的相机仰角，以度为单位（默认值：0.0，步长为 0.1） | FLOAT | 是 | -90.0 到 90.0 |

注意：相机方位角从 0 度开始，每帧按固定增量递增，使相机在生成的各帧中围绕物体完成一整圈 360 度的环绕。每帧增量按 360 除以（`video_frames` - 1）计算，当只请求一帧时除数最小取 2。`elevation` 值在每一帧中都保持不变。

在进行 VAE 编码之前，`init_image` 会被缩放到指定的 `width` 和 `height`，返回的 latent 维度为 `video_frames` x 4 x（`height` // 8）x（`width` // 8）。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 正向条件数据，包含用于生成的图像嵌入和相机参数 | CONDITIONING |
| `negative` | 负向条件数据，其嵌入和 latent 均置零，用于对比式生成 | CONDITIONING |
| `latent` | 空的 latent 张量，其维度与指定的视频帧数和分辨率相匹配 | LATENT |
