SV3D_Conditioning 使用 SV3D 模型为 3D 视频生成准备 conditioning 数据。它接收一张初始图像，并通过 CLIP vision 和 VAE 编码器处理，生成 positive 和 negative conditioning，以及一个 latent 表示。该节点根据指定的视频帧数，生成用于多帧视频生成的相机仰角（elevation）和方位角（azimuth）序列。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `clip视觉` | 用于对输入图像进行编码的 CLIP vision 模型 | CLIP_VISION | 是 | - |
| `初始图像` | 作为 3D 视频生成起点的初始图像 | IMAGE | 是 | - |
| `vae` | 用于将图像编码到 latent 空间的 VAE 模型 | VAE | 是 | - |
| `宽度` | 生成视频帧的输出宽度（默认值：576，必须能被 8 整除） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 生成视频帧的输出高度（默认值：576，必须能被 8 整除） | INT | 是 | 16 to MAX_RESOLUTION |
| `帧数` | 视频序列要生成的帧数（默认值：21） | INT | 是 | 1 到 4096 |
| `俯仰角` | 用于 3D 视图的相机仰角（单位：度）（默认值：0.0） | FLOAT | 是 | -90.0 到 90.0 |

注意：相机方位角从 0 度开始，并在每一帧增加一个固定量，从而使相机在生成的帧中围绕物体完成 360 度完整旋转。`elevation` 值在每一帧中保持不变。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `正面条件` | 包含图像嵌入和相机参数的 positive conditioning 数据，用于生成过程 | CONDITIONING |
| `负面条件` | 包含零值嵌入和 latent 的 negative conditioning 数据，用于对比生成 | CONDITIONING |
| `Latent` | 一个空 latent 张量，其维度与指定的视频帧数和分辨率匹配 | LATENT |
