LTXV Empty Latent Audio 节点创建一批空（零填充）的潜在音频张量。它读取连接的 Audio VAE 模型的配置，以确定正确的潜在维度，例如通道数和频率区间数，并根据帧数和帧率计算需要多少音频潜在。生成的空潜在可用作音频生成或操作工作流的起点。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `帧数` | 帧数。默认值为 97。 | INT | 是 | 1 到 1000 |
| `帧率` | 每秒帧数。默认值为 25.0。此输入接受 FLOAT 或 INT 值。 | FLOAT | 是 | 1.0 到 1000.0 |
| `批量大小` | 批次中潜在音频样本的数量。默认值为 1。 | INT | 是 | 1 到 4096 |
| `音频VAE` | 用于获取配置的 Audio VAE 模型。显示为 "Audio VAE"。 | VAE | 是 | N/A |

**注意：** `audio_vae` 输入是必填项。如果未提供，节点会抛出错误。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `Latent` | 一个空潜在音频张量，形状为 (batch_size, z_channels, num_audio_latents, audio_freq)，其中通道数和频率区间来自 Audio VAE，音频潜在数量由 `frames_number` 和 `frame_rate` 推导得出。输出还包含一个设置为 "audio" 的 `type` 字段。 | LATENT |
