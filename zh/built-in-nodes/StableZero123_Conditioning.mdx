StableZero123_Conditioning 节点处理输入图像和相机角度，为 3D 模型生成任务生成条件数据和潜空间表示。它使用 CLIP 视觉模型对图像特征进行编码，将图像特征与基于俯仰角和方位角的相机嵌入信息相结合，并输出正向条件、负向条件以及潜空间表示，供下游 3D 生成任务使用。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `clip视觉` | 用于编码图像特征的 CLIP 视觉模型 | CLIP_VISION | 是 | - |
| `初始图像` | 待处理和编码的输入图像 | IMAGE | 是 | - |
| `vae` | 用于将像素编码到潜空间的 VAE 模型 | VAE | 是 | - |
| `宽度` | 潜空间表示的输出宽度（默认值：256，步长：8） | INT | 是 | 16 to MAX_RESOLUTION |
| `高度` | 潜空间表示的输出高度（默认值：256，步长：8） | INT | 是 | 16 to MAX_RESOLUTION |
| `批量大小` | 批次中生成的样本数量（默认值：1） | INT | 是 | 1 到 4096 |
| `俯仰角` | 相机俯仰角，单位为度（默认值：0.0，步长：0.1） | FLOAT | 是 | -180.0 到 180.0 |
| `方位角` | 相机方位角，单位为度（默认值：0.0，步长：0.1） | FLOAT | 是 | -180.0 到 180.0 |

**注意：** `width` 和 `height` 参数的步长为 8，因此取值以 8 为单位递增。该节点会将它们除以 8 来确定潜空间表示的尺寸。在进行 VAE 编码之前，图像会通过中心裁剪的双线性上采样缩放到给定的 `width` 和 `height`。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 正向条件数据，结合了图像特征与相机嵌入，并包含经过 VAE 编码的输入图像作为待拼接的潜空间表示 | CONDITIONING |
| `negative` | 负向条件数据，其特征为初始化为零，潜空间表示也初始化为零 | CONDITIONING |
| `latent` | 初始化为零的潜空间表示，尺寸为 [batch_size, 4, height//8, width//8] | LATENT |
