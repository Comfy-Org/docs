此节点在源代码中标记为已弃用（旧版）；显示名称为 “Tripo: Texture model (Legacy)”。现有文档的参数表与当前源代码保持一致。这些参数表将被保留，并在概述中注明其旧版状态。

Tripo: Texture model (Legacy) 节点通过 Tripo API 为现有的 Tripo 3D 模型添加纹理。它接收由另一个 Tripo 节点创建的模型的 task ID，并在纹理任务完成后返回带纹理的 GLB 或 FBX 模型。你可以控制材质贴图、纹理质量、对齐方式和种子，并可通过文本提示、风格图像或参考图像来引导纹理生成。此节点是纹理工具的旧版版本。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型任务ID` | 要添加纹理的模型的 Tripo task ID。接受模型 task ID 和分割 task ID。 | MODEL_TASK_ID, SEGMENT_TASK_ID | 是 | - |
| `纹理` | 已忽略：此节点始终生成纹理。保留它是为了兼容较旧的工作流。（默认：True） | BOOLEAN | 否 | true<br />false |
| `PBR` | PBR 材质贴图（base color、metallic、roughness、normal）；关闭时生成纯色纹理。（默认：True） | BOOLEAN | 否 | true<br />false |
| `纹理种子` | 纹理生成的随机种子。（默认：42） | INT | 否 | 0 – 2147483647 |
| `纹理质量` | 纹理分辨率质量：detailed = HD 纹理，extreme = 8K Ultra 纹理。（默认："standard"）。大致费用：standard $0.10，detailed $0.20，extreme $0.30。 | COMBO | 否 | "standard"<br />"detailed"<br />"extreme" |
| `纹理对齐` | 用于将生成的纹理对齐到模型的方法。（默认："original_image"） | COMBO | 否 | "original_image"<br />"geometry" |
| `texture_prompt` | 用于纹理生成的可选文本引导。对于导入的模型（Tripo: Import Model）实际上必需，因为这些模型没有可用于推断颜色的源图像。不能与参考图像组合使用。（默认：""） | STRING | 否 | - |
| `model_version` | 纹理模型：v3.0 用于使用 v3.x 生成的网格，v2.5 用于使用 v2.5 生成的网格。（默认：v3.0_20250812） | COMBO | 否 | 提供多个选项 |
| `style_image` | 用于纹理艺术风格的参考图像。仅与 `texture_prompt` 一起使用。 | IMAGE | 否 | - |
| `reference` | 用于引导纹理的参考图像。不能与 `texture_prompt` 或 `style_image` 组合使用。（默认："none"） | DYNAMIC_COMBO | 否 | "none"<br />"image"<br />"multiview" |
| `part_names` | 来自 Tripo: Segment Model 的逗号分隔部件名称，用于指定要纹理化的部件。留空则为每个部件生成纹理。（默认：""） | STRING | 否 | - |

### `multiview` 参考输入

当 `reference` 设置为 `"multiview"` 时，这些输入可用。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image_front` | 前视图（0°）。 | IMAGE | 是 | - |
| `image_left` | 左视图（90°）。 | IMAGE | 是 | - |
| `image_back` | 后视图（180°）。 | IMAGE | 是 | - |
| `image_right` | 右视图（270°）。 | IMAGE | 是 | - |

**注意：** `"image"` 和 `"multiview"` 参考模式不能与非空的 `texture_prompt` 或 `style_image` 组合使用。`style_image` 输入要求 `texture_prompt` 非空。当 `texture_prompt` 留空时，源模型必须已经带有自己的源图像（例如，由文本到模型、图像到模型、多视图到模型或更早的纹理化任务生成的模型）。不携带源图像的模型——例如导入、分割、完成或重拓扑的模型——必须使用 `texture_prompt` 进行纹理化；参考图像仅适用于 Tripo API 自身生成的模型。`part_names` 输入可以留空，以便为每个部件生成纹理。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model_file` | 生成的模型文件（仅用于向后兼容）。 | STRING |
