LTXV Image To Video 节点可根据单张起始图像生成专业质量的视频。它使用外部 API，根据您的文本提示创建视频序列，并允许您自定义时长、分辨率和帧率。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `图像` | 用于视频的首帧图像。 | IMAGE | 是 | - |
| `模型` | 用于视频生成的 AI 模型。“Pro”模型针对质量进行优化，而“Fast”模型针对速度进行优化。 | COMBO | 是 | `"LTX-2 (Pro)"`<br />`"LTX-2 (Fast)"` |
| `提示词` | 用于指导生成视频内容和动作的文本描述（默认值为空）。 | STRING | 是 | - |
| `时长` | 视频的时长（以秒为单位，默认：8）。 | COMBO | 是 | `6`<br />`8`<br />`10`<br />`12`<br />`14`<br />`16`<br />`18`<br />`20` |
| `分辨率` | 生成视频的输出分辨率。 | COMBO | 是 | `"1920x1080"`<br />`"2560x1440"`<br />`"3840x2160"` |
| `帧率` | 视频的帧率，即每秒帧数（默认：25）。 | COMBO | 是 | `25`<br />`50` |
| `生成音频` | 当设为 true 时，生成的视频将包含与场景匹配的 AI 生成音频（默认：False）。 | BOOLEAN | 否 | - |

**重要约束：**

* `image` 输入必须且只能包含一张图像。
* `prompt` 的长度必须在 1 到 10,000 个字符之间。
* 如果您选择的 `duration` 超过 10 秒，则必须使用 **"LTX-2 (Fast)"** 模型、**"1920x1080"** 分辨率和 **25** FPS。生成较长视频时需要使用此组合。

**注意：** 此节点已标记为已弃用。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `video` | 生成的视频文件。 | VIDEO |
