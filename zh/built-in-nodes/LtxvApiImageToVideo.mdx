LTXV Image To Video 节点可从单张起始图像生成专业级质量的视频。它使用外部 API，根据你的文本提示词创建视频序列，并允许你自定义时长、分辨率和帧率。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `image` | 用于视频的首帧。 | IMAGE | 是 | - |
| `model` | 用于视频生成的 AI 模型。“Pro”模型针对质量进行了优化，而“Fast”模型针对速度进行了优化。 | COMBO | 是 | `"LTX-2 (Pro)"`<br />`"LTX-2 (Fast)"` |
| `prompt` | 引导生成视频内容和运动的文本描述（默认：空）。 | STRING | 是 | - |
| `duration` | 视频长度，以秒为单位（默认：8）。 | COMBO | 是 | `6`<br />`8`<br />`10`<br />`12`<br />`14`<br />`16`<br />`18`<br />`20` |
| `resolution` | 生成视频的输出分辨率。 | COMBO | 是 | `"1920x1080"`<br />`"2560x1440"`<br />`"3840x2160"` |
| `fps` | 视频的每秒帧数（默认：25）。 | COMBO | 是 | `25`<br />`50` |
| `generate_audio` | 当为 true 时，生成的视频将包含与场景匹配的 AI 生成音频（默认：False）。 | BOOLEAN | 否 | - |

**重要限制：**

* `image` 输入必须恰好包含一张图像。
* `prompt` 的字符长度必须介于 1 到 10,000 之间。
* 如果选择的 `duration` 超过 10 秒，则必须使用 **"LTX-2 (Fast)"** 模型、**"1920x1080"** 分辨率和 **25** FPS。较长的视频必须使用此组合。

**注意：** 此节点已被标记为已弃用。节点上显示的预估成本取决于所选的 `model`、`duration` 和 `resolution`。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `video` | 生成的视频文件。 | VIDEO |
