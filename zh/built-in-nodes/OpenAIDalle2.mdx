通过 OpenAI 的 DALL·E 2 端点同步生成图像。此节点将文本提示发送到 OpenAI 的 DALL·E 2 API，并将生成的图像返回到 ComfyUI。当同时提供 `image` 和 `mask` 时，它还可以编辑现有图像。

## 工作原理

此节点连接到 OpenAI 的 DALL·E 2 API，以根据文本描述创建图像。当你提供文本提示时，节点会将其发送到 OpenAI 的服务器，服务器生成相应的图像并将其返回给 ComfyUI。此节点可以在两种模式下运行：仅使用文本提示的标准图像生成模式，或同时提供图像和遮罩时的图像编辑模式。在编辑模式下，它使用遮罩来确定应修改原始图像的哪些部分，同时保持其他区域不变。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `prompt` | 用于 DALL·E 的文本提示（默认：空） | STRING | 是 | - |
| `seed` | 后端尚未实现（默认：0） | INT | 否 | 0 到 2147483647 |
| `size` | 图像尺寸（默认："1024x1024"） | COMBO | 否 | "256x256"<br />"512x512"<br />"1024x1024" |
| `n` | 要生成多少张图像（默认：1） | INT | 否 | 1 到 8 |
| `image` | 用于图像编辑的可选参考图像。 | IMAGE | 否 | - |
| `mask` | 用于图像修复的可选遮罩（白色区域将被替换） | MASK | 否 | - |

**注意：** 仅当同时提供 `image` 和 `mask` 时，才会激活图像编辑模式。如果只提供其中一个，则会引发错误。`mask` 必须与 `image` 尺寸相同；否则会引发错误。在编辑模式下，遮罩的白色区域表示将被替换的区域。
