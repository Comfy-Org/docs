使用 PixVerse API 根据文本提示词生成视频。此节点允许你控制视频的宽高比、质量、时长和运动风格，并可选择应用已保存的风格模板。它会提交请求，等待生成完成，并返回生成的视频。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 用于视频生成的提示词（默认值：""） | STRING | 是 | 必须至少包含 1 个字符 |
| `宽高比` | 生成视频的宽高比 | COMBO | 是 | `"16:9"`<br />`"9:16"`<br />`"1:1"` |
| `质量` | 视频质量设置（默认值："540p"） | COMBO | 是 | `"540p"`<br />`"1080p"` |
| `时长（秒）` | 生成视频的时长（秒） | COMBO | 是 | `"5"`<br />`"10"` |
| `运动模式` | 视频生成的运动风格 | COMBO | 是 | `"normal"`<br />`"fast"` |
| `种子` | 视频生成的随机种子（默认值：0） | INT | 是 | 0 到 2147483647 |
| `反向提示词` | 图像中不希望出现的元素的可选文本描述（默认值：""） | STRING | 否 | - |
| `PixVerse 模板` | 可选模板，用于影响生成风格，由 PixVerse Template 节点创建 | CUSTOM | 否 | - |

**注意：** `prompt` 必须至少包含 1 个字符。当选择 1080p 质量时，运动模式会自动设置为 `normal`，且时长限制为 5 秒。对于不是 5 秒的任何时长，运动模式也会自动设置为 `normal`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 生成的视频文件 | VIDEO |
