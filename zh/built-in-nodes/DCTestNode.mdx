DCTestNode 是一个逻辑节点，它会根据用户从动态组合框中选择的选项返回不同类型的数据。它充当条件路由器，所选选项决定哪个输入字段处于激活状态，以及节点将输出哪种类型的值。

## 输入

该节点使用动态组合选择器：`combo` 参数始终可见，其他输入字段仅在其对应选项被选中时才会显示。

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `combo` | 决定哪个输入字段激活以及节点将输出什么内容的主要选择。 | DYNAMIC_COMBO | 是 | `"option1"`<br />`"option2"`<br />`"option3"`<br />`"option4"` |

### option1 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `string` | 一个文本输入字段。仅当 `combo` 设置为 `"option1"` 时，此字段才激活且必填。 | STRING | 是 | - |

### option2 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `integer` | 一个整数输入字段。仅当 `combo` 设置为 `"option2"` 时，此字段才激活且必填。 | INT | 是 | - |

### option3 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `image` | 一个图像输入字段。仅当 `combo` 设置为 `"option3"` 时，此字段才激活且必填。 | IMAGE | 是 | - |

### option4 输入

当 `combo` 设置为 `"option4"` 时，节点会显示第二个动态组合选择器（`subcombo`），用于控制一组嵌套输入字段。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `subcombo` | 当 `combo` 设置为 `"option4"` 时出现的次级动态组合选择。它决定哪些嵌套输入字段处于激活状态。 | DYNAMIC_COMBO | 是 | `"opt1"`<br />`"opt2"` |
| `float_x` | 一个十进制数字输入字段。仅当 `combo` 设置为 `"option4"` 且 `subcombo` 设置为 `"opt1"` 时，此字段才激活且必填。 | FLOAT | 是 | - |
| `float_y` | 一个十进制数字输入字段。仅当 `combo` 设置为 `"option4"` 且 `subcombo` 设置为 `"opt1"` 时，此字段才激活且必填。 | FLOAT | 是 | - |
| `mask1` | 一个遮罩输入字段。仅当 `combo` 设置为 `"option4"` 且 `subcombo` 设置为 `"opt2"` 时，此字段才激活。此字段为可选。 | MASK | 否 | - |

**参数约束：**

* `combo` 参数控制所有其他输入字段的可见性和必填性。只有与所选 `combo` 选项关联的输入才会显示并成为必填项（`mask1` 除外，它是可选的）。
* 当 `combo` 设置为 `"option4"` 时，`subcombo` 参数变为必填项，并控制第二组嵌套输入（`float_x`/`float_y` 或 `mask1`）。

## 输出
