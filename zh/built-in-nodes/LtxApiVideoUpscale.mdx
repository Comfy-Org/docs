将视频放大到 1080p、4K 或 8K，同时保持其宽高比、帧率和音频。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `video` | 要放大的视频，短边至少为 480 像素，任意方向最大为 7680x4320。1080p 最多 2401 帧，4K 最多 601 帧，8K 最多 241 帧。 | VIDEO | 是 | - |
| `resolution` | 输出尺寸，最大可适配 1920x1080、3840x2160 或 7680x4320，并针对竖屏视频进行旋转。默认：`"4k"`。 | COMBO | 是 | `"1080p"`<br />`"4k"`<br />`"8k"` |
| `seed` | 控制节点是否重新运行；无论种子如何，结果都是不确定的。默认：42。 | INT | 否 | 0 到 4294967295 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `video` | 放大后的视频，保留其音频。 | VIDEO |
