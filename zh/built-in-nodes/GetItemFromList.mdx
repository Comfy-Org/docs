此节点从列表中返回单个项，并根据其位置进行选择。你提供列表以及所需项的索引编号，节点会输出该项。这使其适用于从一组值中挑选一个特定元素，例如从一批图像中挑选某一张图像。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `list` | 要从中选择值的列表。由于此节点被标记为接受列表输入，连接的值会作为一组项目处理。 | Any Type | 是 | 任意值列表 |
| `index` | 要返回项的位置。该值从 0 开始，因此 `0` 返回第一项，`1` 返回第二项，依此类推（默认值：0）。 | INT | 是 | 任意整数索引 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `OUTPUT` | 位于所提供的 `list` 中给定 `index` 处的单个项。 | Any Type |
