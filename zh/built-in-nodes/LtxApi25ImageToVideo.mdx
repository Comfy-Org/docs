此节点使用 LTX 2.5 模型，根据起始图像生成专业质量的视频。您可以通过文本提示描述视频内容，选择模型变体，并调整时长、分辨率、帧率和音频生成。可选地提供最后一帧以定义视频的结尾。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 用作视频的第一帧。 | IMAGE | 是 | 恰好一张图像 |
| `模型` | 模型设置组。选择要使用的 LTX 2.5 模型变体。 | COMBO | 是 | "LTX-2.5 (Fast)"<br />"LTX-2.5 (Pro)" |
| `时长` | 生成视频的时长（秒）。 | INT | 是 | 整数 |
| `分辨率` | 生成视频的分辨率。可用选项可能取决于所选模型。 | COMBO | 是 | "1280x720"<br />"720x1280"<br />"1920x1080"<br />"1080x1920"<br />"2560x1440"<br />"1440x2560"<br />"3840x2160"<br />"2160x3840" |
| `帧率` | 生成视频的帧率。 | INT | 是 | 整数（默认值：25） |
| `生成音频` | 是否为视频生成音频。 | BOOLEAN | 是 | True<br />False（默认值：True） |
| `提示词` | 要生成的视频内容的文本描述。长度必须在 1 到 10000 个字符之间。 | STRING | 是 | 1 到 10000 个字符 |
| `种子` | 用于可复现生成的种子值。使用相同的种子和相同设置将产生相同的结果。 | INT | 是 | 整数（默认值：42） |
| `末帧` | 用作视频的最后一帧。 | IMAGE | 否 | 恰好一张图像 |

**注意：** `image` 仅支持一张图像。如果提供了 `last_frame`，则它也必须恰好包含一张图像。可用的 `model.resolution` 选项可能因所选的 `model` 变体而异。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 根据提供的起始图像和生成设置生成的视频。 | VIDEO |
