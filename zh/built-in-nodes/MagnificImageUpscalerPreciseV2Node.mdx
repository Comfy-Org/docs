Magnific Image Upscale (Precise V2) 节点执行高保真图像放大，并可精细控制锐度、颗粒感和细节增强。它通过外部 API 处理图像，支持最高 10060×10060 像素的输出分辨率。该节点提供不同的处理风格，并且如果请求的输出尺寸超过最大允许大小，可以自动对输入图像进行降采样。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要放大的输入图像。需要且仅需要一张图像。最小尺寸为 160x160 像素。宽高比必须介于 1:3 和 3:1 之间。 | IMAGE | 是 | - |
| `放大倍数` | 所需的放大倍数。 | COMBO | 是 | `"2x"`<br />`"4x"`<br />`"8x"`<br />`"16x"` |
| `风格` | 处理风格：sublime 用于常规用途，photo 用于照片，photo_denoiser 用于有噪点的照片。 | COMBO | 是 | `"sublime"`<br />`"photo"`<br />`"photo_denoiser"` |
| `锐化` | 图像锐化强度。数值越高，边缘定义和清晰度越高。默认值：7。 | INT | 否 | 0 到 100 |
| `智能颗粒` | 智能颗粒/纹理增强，防止图像看起来过于平滑或人工化。默认值：7。 | INT | 否 | 0 到 100 |
| `超细节` | 控制放大过程中添加的精细细节、纹理和微细节。默认值：30。 | INT | 否 | 0 到 100 |
| `自动降采样` | 如果输出超出最大分辨率，自动对输入图像进行降采样。默认值：False。 | BOOLEAN | 否 | - |

**注意：** 如果禁用 `auto_downscale`，且请求的输出尺寸（输入尺寸 × `scale_factor`）超过 10060x10060 像素，节点将报错。启用 `auto_downscale` 后，节点将尝试找到使质量损失最小的最佳缩放系数。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 放大后的结果图像。 | IMAGE |
