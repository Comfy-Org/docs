# ByteDance 图像转视频节点

ByteDance 图像转视频节点使用 ByteDance 的 API，从输入图像和文本提示中生成视频。它创建一个视频序列，以视觉形式表示提供的描述，并提供自定义输出分辨率、宽高比、时长和其他参数的选项。

| `提示` | 用于生成视频的文本提示。去除空白字符后，必须至少有 1 个字符长。 | STRING | 是 | - |
