此节点将 MiniMax H3 Fun ControlNet 作为模型补丁应用于文本到视频模型。它可以使用可选的 control video 和可选的 mask 来引导生成，并返回模型的修补副本以供进一步采样。当 `strength` 设为 0，或既未提供 control video 也未提供 mask 时，输入模型将原样返回。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要应用 MiniMax H3 Fun ControlNet 补丁的扩散模型。 | MODEL | 是 | N/A |
| `model_patch` | MiniMax H3 Fun ControlNet 补丁，其控制信号会被注入到模型中；它必须与给定的 `model` 兼容。 | MODEL_PATCH | 是 | N/A |
| `vae` | 用于将控制视频帧和源视频帧编码为模型所需潜在空间的 VAE。 | VAE | 是 | N/A |
| `strength` | ControlNet 效果的整体强度。设为 0 时，此节点不执行任何操作，并原样返回输入模型。（默认值：1.0） | FLOAT | 是 | min 0.0, max 10.0, step 0.01 |
| `start_percent` | 采样范围的起点，以采样调度计划的百分比表示，在该范围内 ControlNet 处于活动状态。它会在内部转换为等效的 sigma 值。这是高级设置。（默认值：0.0） | FLOAT | 是 | min 0.0, max 1.0, step 0.001 |
| `end_percent` | 采样范围的终点，以采样调度计划的百分比表示，在该范围内 ControlNet 处于活动状态。它会在内部转换为等效的 sigma 值。这是高级设置。（默认值：1.0） | FLOAT | 是 | min 0.0, max 1.0, step 0.001 |
| `control_video` | 可选视频帧，用作 ControlNet 的视觉提示。这些帧会被调整大小以匹配生成的视频，并使用 `vae` 进行编码。 | IMAGE | 否 | N/A |
| `mask` | 1 标记要重新生成的区域。大于 0.5 的遮罩值会被视为标记区域。 | MASK | 否 | N/A |
| `source_video` | 遮罩后面的视频；仅在提供遮罩时读取。 | IMAGE | 否 | N/A |

注意：要使补丁生效，`strength` 必须大于 0，并且必须至少提供 `control_video` 或 `mask` 之一。除非提供了 `mask`，否则会忽略 `source_video`；如果给出了 `mask` 但没有提供 `source_video`，则遮罩区域后面的内容会被视为黑色。当同时提供 `control_video` 和 `mask` 时，控制提示会将控制视频特征与遮罩后的源内容结合起来。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model` | 应用了 MiniMax H3 Fun ControlNet 的输入模型修补克隆。如果 `strength` 为 0，或未提供控制视频或遮罩，则原样返回原始模型。 | MODEL |
