此节点通过 Bria API 修复老旧或损坏的照片。它会去除颗粒、划痕和模糊，中和与年代相关的色偏，可能会裁去卡纸装裱和影楼边框，并重新绘制人脸。结果会以约 100 万像素重新渲染，因此不会与输入像素对齐。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要修复的照片。上传前会丢弃 alpha 通道。 | IMAGE | 是 | - |
| `内容审核` | 请求的审核设置。选择 `"true"` 会显示两个额外的布尔开关；选择 `"false"` 不会发送任何审核标志。默认值：`"false"`。 | DYNAMIC_COMBO | 是 | `"false"`<br />`"true"` |

### 审核输入

仅当 `moderation` 设置为 `"true"` 时，这些输入才会出现。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | 启用对输入图像的视觉内容审核。默认值：false。 | BOOLEAN | 否 | true<br />false |
| `visual_output_moderation` | 启用对输出图像的视觉内容审核。默认值：false。 | BOOLEAN | 否 | true<br />false |

**注意：** 此节点会以约 100 万像素重新渲染整个画面，因此结果不会与输入像素对齐。若要放大图像，请使用 Bria Increase Resolution 节点，而不是此节点。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `IMAGE` | Bria 返回的修复后的照片。 | IMAGE |
| `structured_prompt` | 编辑后图像的结构化描述，用于通过 Bria FIBO Image Edit 进行后续编辑。 | STRING |
