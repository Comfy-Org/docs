**Higgsfield Genjutsu Motion Transfer** 节点可使用参考图像中的新角色、场景或风格重新演绎一段视频，同时保留源片段的运动、镜头运动、时间节奏和音频。连接要重新演绎的片段，以及一张或多张描述新外观的参考图像，然后在 `prompt` 中描述结果。请求会发送至 Higgsfield API，并返回生成的视频。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的模型。选择模型后会显示该模型特有的参数：`video`、`reference_images`、`prompt`、`resolution` 和 `seed`。 | DYNAMIC_COMBO | 是 | `"genjutsu-v1.0"` |
| `video` | 源视频，其运动、镜头运动、时间节奏和音频会被保留。至少 4 秒；仅使用前 30 秒。 | VIDEO | 是 | 4 到 30 秒 |
| `reference_images` | 可增长槽位：连接 1 到 8 张图像（`image_1`、`image_2`、...），用于指定要使用的角色、场景或风格。批量输入按每张图像分别计数。 | IMAGE | 是 | 1 到 8 张图像 |
| `prompt` | 可选。描述结果，例如哪张参考图替换哪个人物，或者新的场景。（默认：空） | STRING | 是 | 任意文本 |
| `resolution` | 输出视频的分辨率。（默认：`"720p"`） | COMBO | 是 | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `seed` | `seed` 控制节点是否应重新运行；无论种子如何，结果都是非确定性的。此参数具有“生成后控制”功能（默认值：42）。 | INT | 是 | 0 到 2147483647 |

发送请求前会验证源视频：短于 4 秒的片段会被拒绝，长于 30 秒的片段会被裁剪为前 30 秒。其音频会保留到结果中。参考图像会先上传，所有已连接槽位中的图像总数不能超过 8，即使该节点提供了八个槽位。Higgsfield 的内容审核可能会拒绝输入或结果，此时会抛出错误，而不是返回视频。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `VIDEO` | 重新演绎后的视频文件。 | VIDEO |
