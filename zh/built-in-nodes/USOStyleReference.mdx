USOStyleReference 节点通过将 CLIP 视觉特征与模型补丁相结合，将风格参考应用于模型，并返回输入模型的修补副本。视觉风格信息与模型的文本条件相结合，从而影响生成结果。此节点适用于 Flux 模型，并被标记为实验性功能。

## 输入

| 参数 | 说明 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 应用风格参考补丁的基础模型。 | MODEL | 是 | - |
| `模型补丁` | 包含投影模型的模型补丁，用于编码参考图像的特征。 | MODEL_PATCH | 是 | - |
| `CLIP视觉输出` | 从参考图像的 CLIP 视觉处理中提取的编码视觉特征。 | CLIP_VISION_OUTPUT | 是 | - |

注意：`clip_vision_output` 必须来自提供完整隐藏状态和倒数第二个隐藏状态的 CLIP 视觉模型。该节点将倒数第 20 个、倒数第 11 个以及倒数第二个隐藏状态合并为风格嵌入。`model_patch` 必须通过其 `model` 属性暴露一个投影模型，用于将这些图像特征转换为风格嵌入。在采样过程中，风格嵌入会被前置到文本条件中，从而影响生成，同时匹配的零位置文本 ID 会被前置到文本 ID 中，使标识符序列与扩展后的条件保持对齐。

## 输出

| 输出名称 | 说明 | 数据类型 |
| --- | --- | --- |
| `model` | 已应用风格参考补丁的修改后模型。 | MODEL |
