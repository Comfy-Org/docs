使用 Mirelo SFX 从文本描述生成音效。描述声音本身，而非其所属的画面，节点将返回一段所请求长度的单一音轨。可用于拟音、环境声、冲击音和短音乐质感，无需拍摄或上传视频。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 要使用的模型。选择模型后会显示其专属参数：`prompt`、`negative_prompt`、`duration` 和 `seed`。 | DYNAMIC_COMBO | 是 | `"sfx-2.0"` |
| `prompt` | 描述声音，而非画面。1 至 2000 个字符。 | STRING | 是 | 1 至 2000 个字符 |
| `negative_prompt` | 要避免的声音，以逗号分隔的简短列表。可以留空（默认：空）。最多 1000 个字符。 | STRING | 是 | 最多 1000 个字符 |
| `duration` | 声音长度，以秒为单位。（默认：5.0） | FLOAT | 是 | 0.1 至 600.0（步长 0.1） |
| `seed` | 请求的种子。结果是随机的，因此相同的种子不会重复生成相同的声音。（默认：42） | INT | 是 | 0 至 4294967295 |

当 `prompt` 为空或超过 2000 个字符时，以及 `negative_prompt` 超过 1000 个字符时，节点会报错停止。

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `AUDIO` | 生成的音效，长度与 `duration` 一致。 | AUDIO |
