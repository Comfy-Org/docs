PixVerse V6 Fusion (Reference to Video) 使用 PixVerse 根据参考主体、背景和视频合成视频。通过在提示词中指定名称来将参考内容放置到场景中，例如 `@Subject1 walks through @Background1`。连接参考视频会将模型切换到 Omni 模式，此时输出时长与最长的参考视频一致。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 模型和生成设置。选择模型并显示其生成设置。唯一可用的选项是“PixVerse V6”。 | DYNAMIC_COMBO | 是 | "PixVerse V6" |

### PixVerse V6 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 视频生成的提示词。将已连接的参考内容引用为 @Subject1、@Background1、@Video1。默认：空。 | STRING | 是 | 1 到 5000 characters |
| `aspect_ratio` | 输出宽高比。“auto”选项仅当至少连接一个参考视频时才允许使用。 | COMBO | 是 | "auto"<br />plus the predefined PixVerse V6 aspect ratios |
| `quality` | 输出分辨率。设置长边：360p 为 640px，540p 为 1024px，720p 为 1280px，1080p 为 1920px。默认：“720p”。 | COMBO | 是 | "360p"<br />"540p"<br />"720p"<br />"1080p" |
| `duration_seconds` | 生成视频的时长（秒）。当连接参考视频时，输出时长改为跟随最长的参考视频，此设置被忽略。默认：5。 | INT | 是 | 1 到 15 |
| `generate_audio` | 与视频一起生成本机音轨。默认：True。 | BOOLEAN | 是 | True<br />False |
| `seed` | 视频生成的种子。PixVerse 会记录该种子，但不会根据它复现生成结果。默认：42。 | INT | 是 | 0 到 2147483647 |
| `negative_prompt` | 可选文本描述，用于描述视频中不需要的元素。默认：空。 | STRING | 否 | Up to 2048 characters |
| `style` | 应用于整个视频的可选视觉风格。默认：“none”。 | COMBO | 否 | "none"<br />plus the predefined PixVerse V6 styles |

### 参考输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `主体` | 可扩展插槽：连接主体参考图像，以将其放入场景中。插槽命名为 subject1 到 subject8；在提示词中通过 @Subject1、@Subject2 等引用它们。 | IMAGE | 否 | 0 到 8 images |
| `背景` | 可扩展插槽：连接场景参考图像，主体将被放入这些场景中。插槽命名为 background1 到 background2；在提示词中通过 @Background1、@Background2 引用它们。 | IMAGE | 否 | 0 到 2 images |
| `视频` | 可扩展插槽：连接参考视频，以借鉴其主体、运动、构图或风格。插槽命名为 video1 到 video2；在提示词中通过 @Video1、@Video2 引用它们。每个视频最多 15 秒，总时长不得超过 15 秒。至少连接一个视频会将节点切换到 Omni 模式。 | VIDEO | 否 | 0 到 2 videos<br />15 seconds max each<br />15 seconds total |

注意：请至少连接一个主体、背景或参考视频。提示词中的参考标签（例如 @Subject1、@Background1、@Video1）必须与已连接的插槽匹配，否则请求将被拒绝。当至少连接一个参考视频时（Omni 模式），输出时长与最长的参考视频一致，`duration_seconds` 被忽略，`aspect_ratio` 可设置为“auto”，且最多可接受 10 张参考图像。如果没有参考视频，则最多接受 7 张参考图像（主体和背景合计），且不允许使用“auto”宽高比。
