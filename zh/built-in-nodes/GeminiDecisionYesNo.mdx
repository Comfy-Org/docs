此节点会对所连接的文本、图像、音频或视频提出一个是/否问题，并返回一个布尔值用于分支路由。将 `result` 连接到 If/Else Switch 节点，即可把运行导向两条路径之一；当你需要了解模型为何这样回答时，可读取 `answer` 和 `probability`。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的模型（默认：`"gemini-decision-1"`）。 | COMBO | 是 | `"gemini-decision-1"` |
| `question` | 关于所连接内容的 yes/no 问题，最多 5000 个字符。提问时应让 "yes" 对应你希望采取行动的情况（默认："Is there a person in the image?"）。 | STRING | 是 | 1 到 5000 个字符 |
| `threshold` | "yes" 的概率达到该值时 `result` 变为 true。明确的肯定答案得分约为 0.85 到 0.92，因此设为 0.9 或更高会拒绝其中许多答案（默认：0.5）。 | FLOAT | 是 | 0.01 到 0.99（步长 0.01） |
| `images` | 要询问的图像，最多可在可增长槽位（`image_1` ... `image_16`）中提供 16 张。批处理的图像按每张图像各计一次。 | IMAGE | 否 | 最多 16 张图像 |
| `audio` | 要询问的音频片段。 | AUDIO | 否 | - |
| `video` | 要询问的视频片段。 | VIDEO | 否 | - |
| `text` | 问题所针对的文本，例如提示词或 LLM 回复，最多 20000 个字符。 | STRING | 否 | 最多 20000 个字符 |

至少连接 `text`、`images`、`audio` 或 `video` 之一；当没有任何可供查看的内容时，节点会报错。使用多张图像时，请在问题中用 `image_1`、`image_2` 等名称来指代它们：批次会逐帧展开，因此这些编号按连接顺序跨槽位计算单帧。

## 输出

| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `result` | 当 "yes" 的概率达到 `threshold` 时为 true，否则为 false。 | BOOLEAN |
| `answer` | 判定结果，为字符串 `"yes"` 或 `"no"`，遵循与 `result` 相同的 `threshold`。 | STRING |
| `probability` | "yes" 的概率，介于 0 和 1 之间。 | FLOAT |
