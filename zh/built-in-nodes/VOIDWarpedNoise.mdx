为 VOID 视频细化过程的第二遍生成时间相关噪声。它接收 Pass 1 输出视频，并沿光流向量对高斯噪声进行变形，使噪声与视频内容一致地移动。得到的变形噪声用作 Pass 2 的起始 latent，从而改善最终输出的时间一致性。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `optical_flow` | 来自 OpticalFlowLoader 的光流模型（RAFT-large）。 | OPTICAL_FLOW | 是 | - |
| `video` | Pass 1 输出视频帧 [T, H, W, 3]。 | IMAGE | 是 | - |
| `width` | 目标宽度（像素，默认值：672）。输入视频会在生成噪声前缩放到该宽度，latent 宽度按 `width` ÷ 8 得出。 | INT | 是 | 16 to MAX_RESOLUTION （步长：8） |
| `height` | 目标高度（像素，默认值：384）。输入视频会在生成噪声前缩放到该高度，latent 高度按 `height` ÷ 8 得出。 | INT | 是 | 16 to MAX_RESOLUTION （步长：8） |
| `length` | 像素帧数。向下取整以使 `latent_t` 为偶数（`patch_size_t=2` 要求），例如 49 会变为 45（默认值：45）。 | INT | 是 | 1 to MAX_RESOLUTION （步长：1） |
| `batch_size` | 要生成的相同变形噪声序列数量（默认值：1）。生成的噪声会沿批次维度重复这么多次。 | INT | 是 | 1 到 64 |

**关于 `length` 参数的说明：** `length` 值会自动向下取整到最接近的、能产生偶数 `latent_t` 维度的值，这是 CogVideoX-Fun-V1.5 模型的 `patch_size_t=2` 约束所要求的（例如，49 会变成 45）。发生这种取整时，节点会记录一条警告。超出调整后 `length` 的帧会被忽略，噪声会重采样为得到的 latent 帧数。

**关于 `width` 和 `height` 的说明：** 这些值既用于调整传入视频帧的大小（双线性、中心裁剪），也用于确定最终 latent 分辨率（除以 8）。如果生成的噪声与请求的 latent 大小不匹配，则会调整其大小以适配。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `warped_noise` | 一个 5D 张量 (B, C, T, H, W)，包含经光流变形的高斯噪声，可用作 VOID Pass 2 的初始 latent。 | LATENT |
