为 VOID 视频细化过程的第二遍生成时间相关的噪声。它接收 Pass 1 输出的视频，并沿着光流向量扭曲高斯噪声，生成与视频内容一致运动的噪声。此扭曲噪声用作 Pass 2 的起始潜在变量，从而改善最终输出的时间一致性。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `optical_flow` | 来自 OpticalFlowLoader（RAFT-large）的光流模型。 | OPTICAL_FLOW | 是 | - |
| `video` | Pass 1 输出的视频帧 [T, H, W, 3]。 | IMAGE | 是 | - |
| `width` | 输出潜在变量的宽度（默认值：672）。 | INT | 是 | 16 到 MAX_RESOLUTION（步长 8） |
| `height` | 输出潜在变量的高度（默认值：384）。 | INT | 是 | 16 到 MAX_RESOLUTION（步长 8） |
| `length` | 像素帧数。向下取整以使 latent_t 为偶数（patch_size_t=2 要求），例如 49 → 45（默认值：45）。 | INT | 是 | 1 到 MAX_RESOLUTION（步长 1） |
| `batch_size` | 要生成的相同噪声序列数量（默认值：1）。 | INT | 是 | 1 到 64 |

**关于 `length` 参数的说明：** `length` 值会自动向下取整到能产生偶数 `latent_t` 维度的最近有效值。这是 CogVideoX-Fun-V1.5 模型的 `patch_size_t=2` 约束所要求的。发生取整时会记录一条警告。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `warped_noise` | 包含光流扭曲高斯噪声的 5D 张量（B, C, T, H, W），可直接用作 VOID Pass 2 的初始潜在变量。 | LATENT |
