此节点使用 LTX 2.5 模型生成跟随音轨的视频。音频决定视频时长（2 到 20 秒），你还可以选择提供一张图像作为首帧。视频通过 LTX 2.5 API 服务生成。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `音频` | 驱动视频的音轨。其长度（2-20 秒）决定视频时长。 | AUDIO | 是 | 2-20 seconds |
| `模型` | 要使用的 LTX 2.5 模型版本。选择模型后，还会显示该模型的 `resolution` 子选项。 | COMBO | 是 | "LTX-2.5 (Fast)"<br />"LTX-2.5 (Pro)" |
| `resolution` | 生成视频的输出分辨率。此子选项显示在所选 `model` 下方（默认："1920x1080"）。两个模型提供相同的分辨率选项。 | COMBO | 是 | "1920x1080"<br />"1080x1920" |
| `提示词` | 指导生成视频内容的文本描述（默认：""）。必须包含至少 1 个字符且最多 10000 个字符。 | STRING | 是 | 1-10000 characters |
| `种子` | 控制生成随机性的数字。相同的 `seed` 会产生相同的结果（默认：42）。 | INT | 是 | Any integer |
| `图像` | 可选的视频首帧。仅支持一张图像。 | IMAGE | 否 | Single image |

约束说明：
- 音频时长必须在 2 到 20 秒之间；如果超出此范围，节点会报错。
- `prompt` 为必填项，不能为空；长度必须在 1 到 10000 个字符之间。
- 提供 `image` 时，仅接受单张输入图像。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 由提供的音轨驱动的生成视频。 | VIDEO |
