使用 ByteDance 的 Seed 2.0 模型生成文本响应。提供文本提示，并可选地连接图像或视频，为模型提供额外上下文。模型从可用的 Seed 2.0 变体中选择，节点返回模型的文本回答。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 输入到模型的文本。（默认值：""） | STRING | 是 | N/A |
| `model` | 用于生成响应的 Seed 模型。此选择器还会公开模型的子参数。 | DYNAMIC_COMBO | 是 | `"Seed 2.0 Pro"`<br />`"Seed 2.0 Lite"`<br />`"Seed 2.0 Mini"` |
| `seed` | `seed` 控制节点是否应重新运行；无论 `seed` 如何，结果都是非确定性的。（默认值：0） | INT | 是 | 0 到 2147483647 |
| `system_prompt` | 决定模型行为的基础指令。（默认值：""） | STRING | 否 | N/A |

### 模型输入（Seed 2.0 Pro、Seed 2.0 Lite 和 Seed 2.0 Mini 共享）

所有三个 Seed 模型在被选中时都会公开相同的子参数。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `temperature` | 控制随机性。0.0 是确定性的，值越高越随机。（默认值：1.0） | FLOAT | 是 | 0.0 到 2.0 （步长：0.01） |

### 参考输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `images` | 可选的图像，用作模型的上下文。最多 20 张图像。可增长槽位：连接 1..20 个项目，例如 `image_1` 到 `image_20`。 | IMAGE | 否 | 0 到 20 images |
| `videos` | 可选的视频，用作模型的上下文。最多 4 个视频。可增长槽位：连接 1..4 个项目，例如 `video_1` 到 `video_4`。 | VIDEO | 否 | 0 到 4 videos |

**注意：** `model` 参数是一个动态组合，一旦选择模型，就会显示参考和温度子参数。`images` 和 `videos` 槽位可增长，因此你可以连接多个输入以提供多模态上下文。

- `prompt` 是必需的，并且必须包含至少一个非空白字符；否则会引发错误。
- 每次请求最多支持 20 张图像。此限制统计所有连接批次中的图像。
- 每次请求最多支持 4 个视频。
- 如果模型返回空响应，或模型拒绝响应（会报告拒绝文本），则会引发错误。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 来自 Seed 模型的生成文本响应。 | STRING |
