使用字节跳动的 Seed 2.0 模型生成文本响应。提供文本提示，并可选地包含图像或视频以提供多模态上下文。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于生成响应的 Seed 模型。 | DYNAMIC_COMBO | 是 | `"Seed 2.0 Pro"`<br />`"Seed 2.0 Lite"`<br />`"Seed 2.0 Mini"` |
| `prompt` | 输入到模型的文本。(默认："") | STRING | 是 | N/A |
| `seed` | Seed 控制节点是否应重新运行；无论种子如何，结果都是非确定性的。(默认：0) | INT | 是 | 0 到 2147483647 |
| `system_prompt` | 决定模型行为的基础指令。(默认："") | STRING | 否 | N/A |

### 模型输入（Seed 2.0 Pro、Seed 2.0 Lite 和 Seed 2.0 Mini 共享）

选择时，所有三个 Seed 模型都会公开相同的子参数。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `temperature` | 控制随机性。0.0 是确定性的，值越高随机性越强。(默认：1.0) | FLOAT | 是 | 0.0 到 2.0 (步长：0.01) |

### 参考输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `images` | 可选图像，用作模型的上下文。最多 20 张图像。可增长插槽：连接 1..20 个项目，例如 `image_1` 到 `image_20`。 | IMAGE | 否 | 0 到 20 images |
| `videos` | 可选视频，用作模型的上下文。最多 4 个视频。可增长插槽：连接 1..4 个项目，例如 `video_1` 到 `video_4`。 | VIDEO | 否 | 0 到 4 videos |

**注意：** `model` 参数是一个动态组合，当选择模型时会显示参考和温度子参数。您可以连接图像和视频输入到此参数以提供多模态上下文。每个请求最多支持 20 张图像和 4 个视频，且 `prompt` 是必需的，并且必须包含至少一个非空白字符。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 从 Seed 模型生成的文本响应。 | STRING |
