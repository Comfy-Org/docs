### 参考输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model.images` | 可增长插槽：连接 1..N 个项目（例如 `image_1`...`image_16`）；所有模型最多支持 16 张参考图像。 | IMAGE | 否 | 0 到 16 |

**参数约束与限制：**

- 当 `model.size` 为 "Custom" 时（仅 `gpt-image-2.6-flare`、`gpt-image-2.6-sunburst`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` 和 `gpt-image-2` 支持），`model.custom_width` 和 `model.custom_height` 必须都是 16 的倍数，最长边不能超过 3840，宽高比不能超过 3:1，且总像素数必须在 655,360 到 8,294,400 之间。
- `model.mask` 要求 `model.images` 中恰好有一张参考图像：没有图像时不能使用，有超过一张图像时也不能使用。
- 使用 `model.mask` 时，其高度和宽度必须与参考图像的高度和宽度一致。
- 当提供 `model.images` 时，节点以图像编辑模式运行；没有 `model.images` 时，仅根据提示词生成图像。
- 参考图像和遮罩在发送到 API 之前会被缩小。
- `"xhigh"` 和 `"max"` 质量等级仅适用于 `gpt-image-2.6-flare`、`gpt-image-2.6-sunburst`、`gpt-image-2.5-flare` 和 `gpt-image-2.5-sunburst`。
- `model.complexity` 仅适用于 `gpt-image-2.6-flare` 和 `gpt-image-2.6-sunburst`；其他模型使用固定的规划深度。
- `seed` 目前在后端尚未实现。
