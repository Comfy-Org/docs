此节点使用 OpenAI 的 GPT Image API 生成图像。它支持多个模型（`gpt-image-2`、`gpt-image-1.5` 和 `gpt-image-1`），允许您提供参考图像进行编辑，并可利用遮罩指定要修改的图像区域。

### 参考输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model.images` | 可扩展插槽：可连接 1..N 个项目（例如 `image_1`...`image_16`）；所有模型最多支持 16 张参考图像。 | IMAGE | 否 | 1 到 16 |
| `model.mask` | 用于局部重绘的可选遮罩（白色区域将被替换）。需要恰好一张参考图像。 | MASK | 否 | N/A |

**参数约束与限制：**

- 当 `model.size` 为 "Custom"（仅限 gpt-image-2）时，`model.custom_width` 和 `model.custom_height` 必须都是 16 的倍数，最长边不得超过 3840，宽高比不得超过 3:1，总像素数必须介于 655,360 和 8,294,400 之间。
- `model.mask` 需要恰好在 `model.images` 中提供一张参考图像：不能没有图像，也不能用于多张图像。
- 使用 `model.mask` 时，其尺寸必须与参考图像的尺寸一致。
- 当提供 `model.images` 时，节点运行在图像编辑模式；未提供 `model.images` 时，仅根据提示词生成图像。
- 参考图像在发送到 API 之前会被缩小。
- `seed` 目前尚未在后端实现。
