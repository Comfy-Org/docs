Ideogram 4 Scheduler 节点根据 Ideogram 4 参考调度，为扩散采样过程生成一系列 sigma 值（噪声水平）。它会创建一条可适应图像尺寸的自定义噪声调度，并允许通过统计参数进行微调。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `步数` | 要生成调度所需的采样步数（默认值：20）。输出包含 `steps + 1` 个 sigma 值。 | INT | 是 | 1 到 200 |
| `宽度` | 图像宽度（像素，默认值：1024）。相对于 512×512 参考图像的分辨率会移动噪声调度。 | INT | 是 | 256 到 8192 (step: 16) |
| `高度` | 图像高度（像素，默认值：1024）。相对于 512×512 参考图像的分辨率会移动噪声调度。 | INT | 是 | 256 到 8192 (step: 16) |
| `均值` | logit-normal 分布的均值参数，控制中心噪声水平。与分辨率项相加，构成 logSNR 偏移（默认值：0.0）。 | FLOAT | 是 | -10.0 到 10.0 (step: 0.05) |
| `标准差` | logit-normal 分布的标准差参数，控制噪声水平的分布范围（默认值：1.75）。 | FLOAT | 是 | 0.1 到 5.0 (step: 0.05) |

注意：该调度基于参考时间上的 logit-normal 分布推导得出。分辨率项等于 `0.5 * log((width × height) / (512 × 512))`，会加到 `mu` 上，因此当 `mu` 值相同时，更大或更小的图像会使调度相对于 512×512 参考发生移动。

## 输出

| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `SIGMAS` | 表示噪声调度的 sigma 值张量，长度为 `steps + 1`。这些值从高噪声到低噪声递减，最后一个值设为 0.0 以实现完全去噪。 | SIGMAS |
