Krea 3 Image 节点使用 Krea 3 编辑图像；当未连接图像时，则根据文本提示生成新图像。最多可连接 8 张图像，并描述要更改什么以及要保留什么，在提示中将它们称为 @Image1、@Image2 等。宽高比和分辨率用于设置输出尺寸，而思考模式会牺牲速度以换取更详细的规划。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 要使用的 Krea 3 模型。选择模型后会显示其接受的参数。 | DYNAMIC_COMBO | 是 | `"Krea 3"` |

### Krea 3 输入

当 `model` 设置为 `Krea 3` 时，这些输入会出现。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `model.images` | 要编辑的图像，按连接顺序编号。每连接一张图像都会计入 8 张的上限。留空则仅根据文本生成。 | IMAGE | 否 | 0 到 8 张图像 |
| `model.prompt` | 要更改什么以及要保留什么。使用 `@Image1`、`@Image2` 等来引用图像，或使用 image 1、image 2、……来引用。提示不能为空。 | STRING | 是 | - |
| `model.aspect_ratio` | 结果的宽高比。`"auto"` 会跟随第一张图像；如果未连接图像，则跟随提示。(默认值：`"auto"`) | COMBO | 是 | `"auto"`<br />`"1:1"`<br />`"4:5"`<br />`"3:4"`<br />`"2:3"`<br />`"9:16"`<br />`"5:4"`<br />`"4:3"`<br />`"3:2"`<br />`"16:9"`<br />`"21:9"` |
| `model.resolution` | 输出分辨率。`"2K"` 比 `"1K"` 耗时更长，并生成更大的图像。(默认值：`"2K"`) | COMBO | 是 | `"1K"`<br />`"2K"` |
| `model.thinking_mode` | Krea 3 在规划编辑上投入的工作量。推荐使用 `"fast"`，而 `"high"` 会更详细地规划复杂编辑，但耗时更长。`"ultra"` 会生成多个候选并返回最佳结果；它至少需要一张图像，始终输出 2K，且不支持 `precise_edit`。(默认值：`"fast"`) | COMBO | 是 | `"fast"`<br />`"high"`<br />`"ultra"` |
| `model.precise_edit` | 保持编辑区域之外的所有内容不变。需要至少连接一张图像。(默认值：False) | BOOLEAN | 是 | false<br />true |
| `model.seed` | 请求的种子（默认值：42）。Krea 在生成前会重写提示，因此相同的种子不会重复生成同一张图像。 | INT | 是 | 0 到 2147483647 |

诸如 `@Image3` 之类的引用只有在至少连接了三张图像时才会被接受，否则节点会报错。参考图像会在发送请求之前上传。

| `image` | 生成或编辑后的图像。 | IMAGE |
