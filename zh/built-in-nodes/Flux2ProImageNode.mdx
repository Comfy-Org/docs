通过 BFL API 使用 Flux.2 [pro] 根据提示词和显式输出尺寸生成图像，可选地由参考图像引导。

**注意：** 此节点在源代码中已标记为弃用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 用于图像生成或编辑的提示词。 | STRING | 是 | - |
| `宽度` | 生成图像的宽度，单位为像素（默认值：1024）。 | INT | 是 | 256 到 2048 （步长：32） |
| `高度` | 生成图像的高度，单位为像素（默认值：768）。 | INT | 是 | 256 到 2048 （步长：32） |
| `随机种` | 用于创建噪声的随机种子（默认值：0）。 | INT | 是 | 0 到 18446744073709551615 |
| `提示词上采样` | 是否对提示词执行上采样。如果启用，提示词会自动修改，以获得更具创造性的生成结果（默认值：`True`）。这是一个高级设置。 | BOOLEAN | 是 | True / False |
| `图像` | 用于图生图生成的可选参考图像。每张图像在上传前会缩小到最大 2048x2048 像素。 | IMAGE | 否 | 0 到 9 张图像 |

**约束：**

* 连接超过 9 张参考图像会引发错误。
* 输出尺寸按百万像素计费，因此较大的 `width` 和 `height` 值费用更高。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `IMAGE` | 生成的图像。 | IMAGE |
