将视频重新构图到新的分辨率和宽高比。原始视频之外的区域会根据其内容生成，因此竖屏片段可以变成横屏，反之亦然。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `video` | 要重新构图的视频，最长 60 秒、1800 帧，每边在 64 到 4096 像素之间。 | VIDEO | 是 | - |
| `resolution` | 输出尺寸和宽高比，可选 720p 或 1080p。默认：`"(1080p) 1080x1920 (9:16)"`。 | COMBO | 是 | `"(720p) 720x720 (1:1)"`<br />`"(720p) 720x900 (4:5)"`<br />`"(720p) 900x720 (5:4)"`<br />`"(720p) 720x1280 (9:16)"`<br />`"(720p) 1280x720 (16:9)"`<br />`"(1080p) 1080x1080 (1:1)"`<br />`"(1080p) 1080x1350 (4:5)"`<br />`"(1080p) 1350x1080 (5:4)"`<br />`"(1080p) 1080x1920 (9:16)"`<br />`"(1080p) 1920x1080 (16:9)"` |
| `placement` | 原始视频在新画面中的位置。视频始终填满画面的一侧，因此锚点只会沿另一侧移动视频。默认：`"center"`。 | DYNAMIC_COMBO | 是 | `"center"`<br />`"top"`<br />`"bottom"`<br />`"left"`<br />`"right"`<br />`"custom"` |
| `seed` | 控制节点是否重新运行；无论 `seed` 为何，结果都是非确定性的。默认：42。 | INT | 否 | 0 到 4294967295 |

### Placement "custom" 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `x` | 视频左边缘占输出宽度的比例。默认：0.25。 | FLOAT | 否 | 0.0 到 0.99（步长：0.01） |
| `y` | 视频上边缘占输出高度的比例。默认：0.25。 | FLOAT | 否 | 0.0 到 0.99（步长：0.01） |
| `width` | 视频宽度占输出宽度的比例；高度遵循视频的宽高比。视频必须保持在画面内，且最多可放大 2 倍。默认：0.5。 | FLOAT | 否 | 0.01 到 1.0（步长：0.01） |
