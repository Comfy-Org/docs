## 概述

SelectModelDevice 节点允许您手动选择扩散模型运行在哪个设备上（CPU 或特定的 GPU）。它可以将模型移动到其他设备，并自动处理与其他多 GPU 节点的冲突。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 要放置在特定设备上的扩散模型。 | MODEL | 是 |  |
| `device` | 模型的目标设备。选项根据可用的 GPU 动态生成。（默认值："default"） | COMBO | 是 | `"default"`<br />`"cpu"`<br />`"gpu:0"`<br />`"gpu:1"`<br />...（每个检测到的 GPU 对应一个 `"gpu:N"` 条目） |

**参数详情：**
- `"default"`：恢复由模型加载器分配的设备，即使之前的 SelectModelDevice 节点更改了该设备。
- `"cpu"`：将加载设备和卸载设备都固定为 CPU。
- `"gpu:N"`：将加载设备固定到第 N 个可用 GPU（例如，`"gpu:0"` 表示第一个 GPU）。卸载设备将恢复为加载器最初选择的设备。

**重要说明：**
- 如果当前机器上不存在请求的设备（例如，在双 GPU 机器上创建的工作流在单 GPU 机器上打开），节点将直接原样传递模型，并记录一条消息，而不会失败。
- 如果模型已经在请求的设备上，节点将采用快速路径，不会重新加载模型。
- 如果模型加载器不支持多 GPU（没有重新加载工厂），节点将直接原样传递模型，并记录一条警告。
- 当 MultiGPU CFG Split 克隆已经占用了所选设备时，该克隆将被剪除，以确保两个模型不会绑定到同一设备。
- 选择特定设备时，节点还会将模型的计算 dtype 调整为该设备支持的 dtype。
- 不建议将此节点放置在*已经使用过*该模型的节点（例如 KSampler）*之后*，因为如果设备与原始设备一致，则会观察到先前节点更改的任何状态。
