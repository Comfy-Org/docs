此节点将解码后的 Marigold V2 预测转换为可查看的图像。它接收原始预测张量，并根据预测类型进行格式化：归一化深度（近处物体显得明亮）、单位长度表面法线或 sRGB 反照率。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 要转换为可显示图像的解码后 Marigold V2 预测。 | IMAGE | 是 | - |
| `prediction` | 输入中包含的预测类型，它决定数据如何转换。`"depth"` 会归一化深度值，使近处表面明亮、远处表面黑暗，然后将结果复制到三个颜色通道。`"normals"` 会将值重新缩放到 -1..1 范围，将它们归一化为单位表面法线，并映射回 0..1。`"albedo"` 会对值应用线性到 sRGB 的转换。 | COMBO | 是 | `"depth"`<br />`"normals"`<br />`"albedo"` |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `IMAGE` | 以所选表示形式处理后的图像：归一化深度（灰度重复到三个通道）、单位表面法线或 sRGB 反照率。 | IMAGE |
