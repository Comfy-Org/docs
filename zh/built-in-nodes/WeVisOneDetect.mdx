WeVisOne-VL Detect 根据文本提示在图像中查找对象，并根据你选择的任务返回边界框、alpha 遮罩、点或模型自身的回答。它涵盖开放词汇检测与分割、指代表达、指向、计数以及 OCR 定位，并对批次中的每张图像各运行一次提示。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 用于加载检查点的 WeVisOne-VL 文本编码器。 | CLIP | 是 | - |
| `image` | 要搜索的图像或图像批次。 | IMAGE | 是 | - |
| `task` | 节点应返回的内容。segmentation 返回边界框加 alpha 遮罩；detection、referring、ocr 和 ocr_grounding 返回边界框；point 和 count_point 返回点；count_box 以边界框形式计数；visual_prompt 查找与 `bboxes` 中参考框相似的对象；freeform 原样发送查询并只返回文本（默认："segmentation"）。 | COMBO | 是 | `"segmentation"`<br />`"detection"`<br />`"referring"`<br />`"point"`<br />`"count_box"`<br />`"count_point"`<br />`"ocr"`<br />`"ocr_grounding"`<br />`"visual_prompt"`<br />`"freeform"` |
| `query` | 要查找的内容，用自然语言描述（例如 "the red mug"）。`detection` 和 `point` 每行读取一个标签，`count_box` 和 `count_point` 统计你指定的主体，`ocr_grounding` 查找这段确切的文本，`visual_prompt` 改用 `bboxes`，而 `freeform` 将其作为完整提示发送。`ocr` 会忽略它。 | STRING | 是 | - |
| `bboxes` | `visual_prompt` 用作待查找对象示例的参考框。 | BOUNDING_BOX | 否 | - |
| `individual_masks` | 按 `bboxes` 输出中的每个检测框逐帧返回一个遮罩，而不是每帧返回一个合并遮罩（默认：false）。 | BOOLEAN | 否 | true<br />false |
| `max_length` | 模型为其回答可生成的最大 token 数（默认：4096）。 | INT | 是 | 1 到 32768 |

**注意：** 只有在模型以对象引用作答时才会填充遮罩，这正是 segmentation 任务所要求的方式。其他任务返回边界框、点或文本，遮罩为空。

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `masks` | 匹配对象的 alpha 遮罩，默认每帧一个，或在使用 `individual_masks` 时每个框一个。 | MASK |
| `bboxes` | 每张图像中找到的边界框，以 `x`、`y`、`width`、`height` 和 `label` 存储。 | BOUNDING_BOX |
| `points` | 以像素为单位的 JSON 点，每个点一个对象，包含 `x`、`y`、`label` 和 `frame`，例如 `[{"x": 128, "y": 96, "label": "cup", "frame": 0}]`，由 `point` 和 `count_point` 任务填充。 | STRING |
| `text` | 模型的原始回答，用换行拼接；单条回答本身也可能包含换行。 | STRING |
