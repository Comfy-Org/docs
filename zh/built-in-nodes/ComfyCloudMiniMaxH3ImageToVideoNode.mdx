在 Comfy Cloud GPU 上运行 MiniMax H3 图生视频工作流，并返回带有匹配音轨的视频。该静帧会成为第一帧。将片段末帧再次作为输入传入可延续序列，因此串联多次运行可构建更长的镜头。此节点为 Beta 版节点，按 GPU 秒计费。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `首帧` | 视频起始所用的图像。运行工作流前，该图像会以最高 2048x2048 像素上传。 | IMAGE | 是 | - |
| `提示词` | 对镜头应包含的运动和声音的文字描述。提交前会移除首尾空白字符。 | STRING | 是 | 1 到 4096 个字符 |
| `种子` | 控制生成结果的随机种子（默认值：42）。 | INT | 是 | 0 到 18446744073709551615 |
| `宽高比` | 生成视频的宽高比（默认值：`"1:1"`）。 | COMBO | 是 | `"1:1"`<br />`"3:4"`<br />`"2:3"`<br />`"3:2"`<br />`"4:3"`<br />`"16:9"`<br />`"9:16"`<br />`"21:9"` |
| `分辨率` | 帧尺寸预算（默认值：`"480p"`）。720p 消耗的 GPU 秒数约为 480p 的两倍。 | COMBO | 是 | `"480p"`<br />`"720p"` |
| `时长（秒）` | 时长，单位为秒（默认值：5）。管线在 24 fps 下按 17 帧为步长进行量化，因此片段长度会落在此值约三分之二秒的范围内。 | INT | 是 | 5 到 15 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `VIDEO` | 生成的视频及其音轨。 | VIDEO |
