SAM3D 人体预测在输入图像上运行 3D 人体和手部姿态估计，每帧可检测一个或多个人。可以提供跟踪数据或边界框来提高检测效果；如果两者均未提供，节点将回退到全帧单人体检测。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `sam3d_body_model` | 用于预测的 SAM3D 身体模型。 | SAM3D_BODY_MODEL | 是 | — |
| `image` | 要执行身体预测的图像或图像批次。 | IMAGE | 是 | — |
| `track_data` | 来自 SAM3 视频跟踪的跟踪数据，多人检测时必需。 | SAM3_TRACK_DATA | 否 | — |
| `bboxes` | 逐帧边界框，用于改善检测效果。可作为跟踪数据的替代方案。 | BBOX | 否 | — |
| `run_hand_refinement` | 改进手部姿态，但会额外增加推理时间和内存使用。默认值：true。 | BOOLEAN | 否 | true<br />false |
| `fov` | 垂直视场角（度）。影响预测的深度和绝对尺度。0 = 回退至约 53°（16:9）。默认值：0.0。 | FLOAT | 否 | 0.0 或更大 |
| `batch_size` | 作为批次处理的最大人物裁剪数量。较大的值会使用更多 VRAM 以加快推理。默认值：64。 | INT | 否 | 1 到 512 |

注意：当提供了 `track_data` 时，其优先级高于 `bboxes`。如果既未提供 `track_data` 也未提供 `bboxes`，节点将回退到单人体全帧检测。边界框可以针对单个帧提供（应用于每一帧），也可以逐帧提供。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mhr_pose_data` | 包含逐帧姿态检测结果、面部几何、输入图像尺寸、规范顶点颜色及手部顶点掩码的身体姿态数据包。 | MHR_POSE_DATA |
