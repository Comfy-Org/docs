此节点提供用于图像生成的可配置采样器。它基于随机微分方程（SDE）求解器，并可根据其设置表现为多个特定采样器，包括 `seeds_2`、`exp_heun_2_x0` 和 `exp_heun_2_x0_sde`。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `求解器` | 选择采样器底层求解算法。 | COMBO | 是 | "phi_1"<br />"phi_2" |
| `eta` | 随机强度（默认：1.0）。 | FLOAT | 否 | 0.0 - 100.0 |
| `s_noise` | SDE 噪声乘数（默认：1.0）。 | FLOAT | 否 | 0.0 - 100.0 |
| `r` | 中间阶段（c2 节点）的相对步长（默认：0.5）。 | FLOAT | 否 | 0.01 - 1.0 |

**注意：** 节点描述定义了以下采样器预设：
- `seeds_2`：默认设置
- `exp_heun_2_x0`：`solver_type` = "phi_2"，`r` = 1.0，`eta` = 0.0
- `exp_heun_2_x0_sde`：`solver_type` = "phi_2"，`r` = 1.0，`eta` = 1.0，`s_noise` = 1.0

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `sampler` | 配置好的采样器对象，可传递给其他采样节点。 | SAMPLER |
