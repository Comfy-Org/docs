此节点使用 Bria 的 AI 服务移除视频背景，并输出抠图后的帧以及 Alpha 遮罩。将两个输出连接到合成节点，或将其馈送到 Save WEBM 节点以写入透明视频。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `视频` | 要处理的输入视频。视频时长必须为 60 秒或更短。 | VIDEO | 是 | - |
| `种子` | 种子控制节点是否应重新运行；无论种子如何，结果都是非确定性的（默认值：0） | INT | 是 | 0 到 2147483647 |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `图像` | 移除背景后的视频帧，为 RGB 图像，范围在 0.0 到 1.0 之间 | IMAGE |
| `mask` | 视频帧的 Alpha 遮罩，遵循 Load Image 约定，其中 1 表示透明 | MASK |
