APG（自适应投影引导）节点通过调整扩散过程中引导的应用方式来修改采样过程。它将引导向量相对于条件输出分解为平行分量和正交分量，从而实现更可控的图像生成。该节点提供了用于缩放引导、归一化其幅度以及应用动量以在扩散步骤之间实现更平滑过渡的参数。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要应用自适应投影引导的扩散模型 | MODEL | 是 | - |
| `eta` | 控制平行引导向量的缩放。设置为 1 时采用默认 CFG 行为（默认值：1.0）。 | FLOAT | 是 | -10.0 到 10.0 |
| `向量归一化` | 将引导向量归一化到此值，设置为 0 时禁用归一化（默认值：5.0）。 | FLOAT | 是 | 0.0 到 50.0 |
| `动量` | 控制扩散过程中引导的滑动平均值，设置为 0 时禁用（默认值：0.0）。 | FLOAT | 是 | -5.0 到 1.0 |

注意：当采样过程中噪声水平（`sigma`）增加时，动量滑动平均值将重置为零。如果模型仅提供单个条件输出（没有单独的无条件条件），则跳过引导调整并保持条件不变。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `model` | 返回已在其采样过程中应用自适应投影引导的修改后模型 | MODEL |
