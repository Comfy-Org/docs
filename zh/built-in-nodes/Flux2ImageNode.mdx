使用 Flux.2 [pro] 或 Flux.2 [max] 模型，根据文本提示和可选参考图像生成图像。此节点将请求发送到 BFL API，轮询直到结果准备就绪，并返回生成的图像。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要使用的 Flux.2 模型版本。选择模型会解锁宽度、高度及可选参考图像的附加参数。 | DYNAMIC_COMBO | 是 | "Flux.2 [pro]"<br />"Flux.2 [max]" |
| `提示词` | 用于图像生成或编辑的提示词（默认：空字符串）。 | STRING | 是 | N/A |
| `种子` | 用于创建噪声的随机种子（默认：0）。支持生成后控制选项，可在每次运行后随机化该值。 | INT | 是 | 0 到 18446744073709551615 |

### Flux.2 [pro] 和 Flux.2 [max] 输入

两个模型共享——参数集完全相同。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `宽度` | 生成图像的宽度，单位为像素（默认：1024）。 | INT | 是 | 256 到 2048 （步长：32） |
| `高度` | 生成图像的高度，单位为像素（默认：768）。 | INT | 是 | 256 到 2048 （步长：32） |

### 参考输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model.images` | 用于图像到图像生成的可选参考图像。最多 8 张图像。可增长槽位：连接 1..8 个项目（`image_1`...`image_8`）。 | IMAGE | 否 | 0 到 8 images |

**注意：**
- 参考图像的最大数量为 8。如果提供超过 8 张图像，则会引发错误。批量图像会计入此限制，因为批次中的每张图像都会单独计数。
- 参考图像在发送到 API 之前会被缩放，使总像素数不超过 2048 x 2048。
- `model.width` 和 `model.height` 的值会影响生成成本。成本还取决于所选模型以及是否提供了参考图像。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-----------|-----------|
| `image` | 从 BFL API 结果下载的生成图像，以张量形式返回。 | IMAGE |
