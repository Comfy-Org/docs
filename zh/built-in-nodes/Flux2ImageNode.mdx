使用 Flux.2 [pro] 或 Flux.2 [max] 模型，根据文本提示和可选参考图像生成图像。此节点将您的请求发送到 BFL API，轮询结果，并将生成的图像以张量形式返回。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要使用的 Flux.2 模型版本。选择模型后会解锁宽度、高度和可选参考图像的额外参数。 | DYNAMIC_COMBO | 是 | "Flux.2 [pro]"<br />"Flux.2 [max]" |
| `提示词` | 用于图像生成或编辑的提示词（默认：空字符串）。 | STRING | 是 | 不适用 |
| `种子` | 用于生成噪声的随机种子。可设置为每次生成后自动随机化（默认：0）。 | INT | 是 | 0 到 18446744073709551615 |

### Flux.2 [pro] 和 Flux.2 [max] 输入

两个模型共用——参数集完全相同。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `宽度` | 生成图像的宽度（以像素为单位，默认：1024）。 | INT | 是 | 256 到 2048（步长 32） |
| `高度` | 生成图像的高度（以像素为单位，默认：768）。 | INT | 是 | 256 到 2048（步长 32） |

### 参考输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model.images` | 用于图生图生成的可选参考图像。最多 8 张图像。可扩展插槽：可连接 1..8 个项目（`image_1`...`image_8`）。 | IMAGE | 否 | 0 到 8 张图像 |

**注意：**
- 参考图像的最大数量为 8。如果提供超过 8 张图像，将引发错误。
- `model.width` 和 `model.height` 的值会影响生成成本。成本还取决于所选模型以及是否提供参考图像。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 从 BFL API 结果下载的生成图像，以张量形式表示。 | IMAGE |
