将 `latent` 和 `degrade_sigma` 值附加到 CONDITIONING，以便用于 PiD 解码或放大。这使您可以控制 `latent` 在被处理前的降质程度。

## 输入

| 参数 | 描述 | 数据类型 | 必选 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `正向` | 要将 `latent` 和 `degrade_sigma` 附加到的 CONDITIONING 数据。 | CONDITIONING | 是 | - |
| `latent` | 要附加到条件数据中的 `latent`（来自 VAEEncode 或 KSampler）。 | LATENT | 是 | - |
| `latent 格式` | `latent` 的格式。在 `"flux"` 下，Flux1（16 通道）和 Flux2（128 通道）潜空间会根据通道维度自动检测。对于 SD3（16 通道）、SDXL（4 通道）或 QwenImage（16 通道），请手动选择（默认：`"flux"`）。 | COMBO | 是 | `"flux"`<br />`"sd3"`<br />`"sdxl"`<br />`"qwenimage"` |
| `degrade_sigma` | 要应用的降质程度。0 表示干净的 `latent`。增大此值可对损坏的 `latent` 输出进行降噪（默认：0.0）。 | FLOAT | 是 | 0.0 到 1.0（步长：0.01） |

注意：当 `latent_format` 设置为 `"flux"` 时，节点会根据通道维度自动检测 `latent` 类型：128 个通道视为 Flux2 潜空间，而 16 个通道视为 Flux1 潜空间。

注意：不支持的 `latent_format` 值会引发错误，但节点会处理所有可用选项。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `CONDITIONING` | 附加了 `latent` 和 `degrade_sigma` 值的原始条件数据。 | CONDITIONING |
