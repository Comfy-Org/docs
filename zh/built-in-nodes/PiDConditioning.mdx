将潜在图像和退化 sigma 值附加到 CONDITIONING 数据上。这用于 PiD（像素级细节）解码或放大，使您能够控制潜在图像在处理前被退化的程度。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `正向` | 要附加潜在图像和退化 sigma 的 conditioning 数据。 | CONDITIONING | 是 | - |
| `latent` | 要附加到 conditioning 上的潜在图像（来自 VAEEncode 或 KSampler）。 | LATENT | 是 | - |
| `latent 格式` | 潜在图像的格式。Flux1（16 通道）和 Flux2（128 通道）潜在图像会根据“flux”下的通道维度自动检测。对于 SD3（16 通道）、SDXL（4 通道）或 QwenImage（16 通道），请手动选择（默认值：“flux”）。 | COMBO | 是 | `"flux"`<br />`"sd3"`<br />`"sdxl"`<br />`"qwenimage"` |
| `degrade_sigma` | 要应用的退化量。0 表示干净的潜在图像。增加此值可对损坏的潜在图像输出进行去噪（默认值：0.0）。 | FLOAT | 是 | 0.0 到 1.0（步长：0.01） |

注意：当 `latent_format` 设置为 `"flux"` 时，节点会根据通道维度自动检测潜在图像类型：128 通道视为 Flux2 潜在图像，16 通道视为 Flux1 潜在图像。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `CONDITIONING` | 附加了潜在图像和退化 sigma 值的原始 conditioning 数据。 | CONDITIONING |
