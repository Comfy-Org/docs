ModelMergeSD2 节点通过混合两个 Stable Diffusion 2.x 模型中相互对应的组件来合并这两个模型，其中时间嵌入、标签嵌入以及每个输入块、中间块和输出块都各有一个独立的权重。其块布局与 ModelMergeSD1 相同，因此这两个节点暴露的比率集合也完全一致。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型1` | 要合并的第一个模型。第二个模型未参与贡献的所有内容都保留自该模型 | MODEL | 是 | - |
| `模型2` | 要合并的第二个模型。其权重会按照下方的比率混合进来 | MODEL | 是 | - |
| `time_embed.` | 时间嵌入层的混合比率（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0（步长：0.01） |
| `label_emb.` | 标签嵌入层的混合比率（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0（步长：0.01） |
| `input_blocks.0.` 到 `input_blocks.11.` | 12 个输入块各自的混合比率（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0（步长：0.01） |
| `middle_block.0.` 到 `middle_block.2.` | 3 个中间块各自的混合比率（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0（步长：0.01） |
| `output_blocks.0.` 到 `output_blocks.11.` | 12 个输出块各自的混合比率（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0（步长：0.01） |
| `出.` | 输出层的混合比率（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0（步长：0.01） |

比率为 0.0 时，该组件保持 `model1` 中的原样；比率为 1.0 时，该组件完全取自 `model2`；介于两者之间的值则会产生加权混合。两个输入都必须是具有相同块结构的 Stable Diffusion 2.x 模型。

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `MODEL` | 合并后的模型，按照指定的比率将两个输入组合在一起 | MODEL |
