此节点在参考图像、视频和音频片段的引导下，生成或编辑带有同步音频的视频。Pika H3 Flex 是 Pika 基于 MiniMax H3 进行后训练得到的模型。连接参考素材，并在提示词中按连接顺序使用 `@Image1`、`@Video1` 或 `@Audio1` 来引用它们。至少需要一张参考图像或一个参考视频，最多可连接 12 个参考素材。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 最多 9 张图像，在提示词中按连接顺序使用 `@Image1` 到 `@Image9` 来引用。至少需要一张图像或一个视频。 | AUTOGROW | 否 | 0 到 9 张图像 |
| `reference_videos` | 最多 3 个片段，在提示词中按连接顺序使用 `@Video1` 到 `@Video3` 来引用。每个片段必须为 2 到 15 秒，且所有片段总时长不得超过 15 秒。按秒计费。 | AUTOGROW | 否 | 0 到 3 个视频 |
| `reference_audios` | 最多 3 个片段，在提示词中使用 `@Audio1` 到 `@Audio3` 来引用。每个片段必须为 2 到 15 秒，且所有片段总时长不得超过 15 秒。复制到输出时，片段按连接顺序播放，并位于所连接视频的声音之前。 | AUTOGROW | 否 | 0 到 3 个音频片段 |
| `prompt` | 要生成的内容，或要进行的编辑。使用 `@Image1`、`@Video1`、`@Audio1`，或 `<Picture 1>`、`<Video 1>`、`<Audio 1>` 来引用参考素材。不能为空。默认值：""（空字符串）。 | STRING | 是 | 1 到 8000 个字符 |
| `reference_video_audio` | 将所连接视频的声音复制到输出。如果要使用新的环境声，或进行带新音乐的动作迁移，请将其关闭。此时，提示词中没有对话的说话人头像会被生成虚构的语音。默认值：True。 | BOOLEAN | 是 | true<br />false |
| `resolution` | 输出分辨率。`"1080p"` 及以上会以 768p 渲染并放大一次。相同的种子在 480p 下会生成不同的视频。默认值：`"768p"`。 | COMBO | 是 | `"480p"`<br />`"768p"`<br />`"1080p"`<br />`"2k"`<br />`"4k"` |
| `aspect_ratio` | 输出宽高比。`"auto"` 会跟随参考视频，否则跟随提示词。参考图像不会影响它。默认值：`"auto"`。 | COMBO | 是 | `"auto"`<br />`"21:9"`<br />`"16:9"`<br />`"3:2"`<br />`"4:3"`<br />`"5:4"`<br />`"1:1"`<br />`"4:5"`<br />`"3:4"`<br />`"2:3"`<br />`"9:16"`<br />`"9:21"` |
| `duration` | 片段长度（秒）。输出长度遵循帧网格：5 秒会得到 124 帧，约 5.17 秒。默认值：5。 | INT | 是 | 5 到 15 秒 |
| `rewrite_prompt` | 让 Pika 先扩展提示词。此时相同的种子在每次运行时会生成不同的视频。默认值：False。 | BOOLEAN | 是 | true<br />false |
| `seed` | 采样种子。关闭 `rewrite_prompt` 时，相同的种子会完全重复同一视频，不过使用相同种子的本地运行会得到不同结果。默认值：42。 | INT | 是 | 0 到 2147483647 |

**约束条件：**

* 至少需要一张参考图像或一个参考视频。
* 最多可连接 12 个参考素材，图像、视频和音频片段合计计算。
* 每个参考视频和音频片段必须为 2 到 15 秒；视频总时长不得超过 15 秒，音频片段总时长不得超过 15 秒。
* 提示词长度必须在 1 到 8000 个字符之间。
* 引用未连接的槽位（例如只提供了两张图像却引用 `@Image3`）会引发错误。
