根据提供的提示词替换图像背景。此节点使用 Recraft API 根据您的文本描述为图像生成新背景，让您可以在保持主体不变的情况下彻底改变背景。

## 输入
| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要处理的输入图像 | IMAGE | 是 | - |
| `提示词` | 图像生成的提示词（默认：空） | STRING | 是 | - |
| `数量` | 要生成的图像数量（默认：1） | INT | 是 | 1-6 |
| `种子` | 用于确定节点是否应重新运行的种子；无论种子如何，实际结果都是不确定的（默认：0） | INT | 是 | 0-18446744073709551615 |
| `recraft 风格` | 生成背景的可选样式。如果未提供，默认为 "realistic_image" 样式 | STYLEV3 | 否 | - |
| `反向提示词` | 对图像上不需要的元素的可选文本描述（默认：空） | STRING | 否 | - |

**注意：** `seed` 参数控制节点何时重新执行，但由于外部 API 的特性，不能保证结果具有确定性。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `IMAGE` | 生成的替换背景后的图像。对于每个输入图像，生成结果的数量由 `n` 决定。 | IMAGE |
