此节点使用 Bria 将产品放入人物手中。人物的身份、姿势和背景保持不变，同时场景会以约 1 百万像素重新渲染，因此结果不会与输入照片逐像素对齐。所有产品图像从不同角度或阶段描述同一产品。

## 输入

当 `moderation` 选择器设置为 `"true"` 时，会显示一个额外的审核选项。

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `person_image` | 手持产品的人物照片。图像上传前会丢弃 alpha 通道。 | IMAGE | 是 | - |
| `product_images` | 同一产品的 1 至 3 张图像：产品本身、其包装、另一个角度或配套物品。批处理输入时每张图像计数一次，透明区域视为白色。 | AUTOGROW | 是 | 1 至 3 张图像 |
| `instruction` | 添加到 Bria 内置指令的可选额外指示，例如使用哪只手或标签朝向哪边。默认：`""`（空字符串）。 | STRING | 是 | - |
| `aspect_ratio` | `"auto"` 保持人物照片的构图，约为 1 百万像素。固定比例返回 0.6 至 1 百万像素，例如 `"3:4"` 返回 768x1024。默认：`"auto"`。 | COMBO | 是 | `"auto"`<br />`"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"` |
| `seed` | 随请求发送给 Bria 的种子。默认：42。 | INT | 是 | 1 至 2147483647 |
| `moderation` | 审核设置。当设置为 `"true"` 时，下方的审核标志变为可用。 | DYNAMIC_COMBO | 是 | `"false"`<br />`"true"` |

### Moderation "true" 输入

此参数仅在 `moderation` 设置为 `"true"` 时出现。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `visual_output_moderation` | 对生成的图像启用内容审核。默认：`False`。 | BOOLEAN | 否 | True / False |

**约束条件：**

* `product_images` 最多接受 3 张图像，当输入为批处理时按每张图像计数。
* 产品图像中的透明像素在上传前会合成到白色背景上。
* `person_image` 的 alpha 通道在上传前会被丢弃。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 编辑后的照片，产品被放置在人物手中。 | IMAGE |
