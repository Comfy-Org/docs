MiniMax H3 Latent Upscale With Model 使用潜空间放大模型将 MiniMax H3 潜变量的视频部分缩放到目标宽度和高度。音频潜变量保持原样，因此片段会保留其声音，无需重新采样。当希望片段输出得更大时，可在 MiniMax H3 采样之后、H3 VAE 解码之前使用它。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 潜空间放大模型，通常使用 Load Latent Upscale Model 加载。它必须是 MiniMax H3 3D 卷积潜空间放大器。 | LATENT_UPSCALE_MODEL | 是 | - |
| `samples` | 要调整大小的 MiniMax H3 潜变量。嵌套潜变量会原样保留其音频部分。 | LATENT | 是 | - |
| `width` | 目标视频宽度（像素）。潜变量会被调整为 `width / 16` 列，因此该值会向下取整为 16 的倍数。（默认值：2560） | INT | 是 | 32 至 16384（步长 32） |
| `height` | 目标视频高度（像素），同样会向下取整为 16 的倍数。（默认值：1440） | INT | 是 | 32 至 16384（步长 32） |

当请求的尺寸已经与潜变量匹配时，会原样返回输入潜变量。被缩放的潜变量不携带 `noise_mask`，因此部分遮罩的潜变量会丢失其遮罩。该网络以时间分片的方式执行 3D 卷积，这使得长片段的内存占用接近单个分片的水平。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `LATENT` | 调整大小后的潜变量，可用于 H3 VAE 解码。 | LATENT |
