此节点通过反投影深度图并对生成的点云进行三角化，将 DA3_GEOMETRY 数据包转换为 3D 网格。它处理批次中的单张图像，并生成适用于 3D 渲染的带纹理或不带纹理的网格。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `da3_geometry` | 包含深度图、可选置信度图、可选天空图和源图像的 DA3_GEOMETRY 数据包 | DA3_GEOMETRY | 是 | - |
| `batch_index` | 要转换批次中的哪张图像。每张图像的顶点数量不同，因此批次无法堆叠（默认值：0）。必须小于输入几何数据的批次大小，否则会引发错误 | INT | 是 | 0 到 4096 |
| `decimation` | 顶点步长。1 = 全分辨率，2 = 一半，依此类推（默认值：1） | INT | 是 | 1 到 8 |
| `discontinuity_threshold` | 丢弃 3x3 深度跨度超过此比例的三角形。0 = 关闭（默认值：0.04） | FLOAT | 是 | 0.0 到 1.0 |
| `confidence_threshold` | 排除每张图像归一化置信度低于此值的像素。0 = 保留全部，1 = 仅保留置信度最高的单个像素。当几何数据包含置信度图时使用（Small/Base 模型）（默认值：0.1） | FLOAT | 是 | 0.0 到 1.0 |
| `use_sky_mask` | 从网格中排除天空概率像素（sky >= 0.5）。当几何数据包含天空图时使用（Mono/Metric 模型）（默认值：True） | BOOLEAN | 是 | True or False |
| `texture` | 将源图像用作基础颜色纹理（默认值：True） | BOOLEAN | 是 | True or False |

具有非有限、零或负深度值的像素始终会从网格中排除。如果生成的网格为空，则会引发错误；错误消息建议提高 `discontinuity_threshold`、降低 `confidence_threshold` 或禁用 `use_sky_mask`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `MESH` | 三角化的 3D 网格，包含顶点、面、UV 坐标和可选纹理 | MESH |
