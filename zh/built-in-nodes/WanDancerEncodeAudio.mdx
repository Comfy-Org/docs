此节点处理音频输入以提取可用于引导视频生成模型的特征。它会分析音频以检测节奏、节拍及其他音乐特性，然后将这些信息打包成适合用于条件约束视频模型的格式，从而使生成的视频能够与音频同步。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `音频` | 待分析和编码的音频输入。如果音频包含多个声道，则在特征提取前会将各声道平均为单声道。 | AUDIO | 是 | - |
| `视频帧` | 目标视频的帧数。用于计算同步的帧率（默认值：149）。 | INT | 是 | 最小值：1，最大值：268435456（MAX_RESOLUTION），步长：4 |
| `音频注入比例` | 音频特征注入视频模型时的缩放比例（默认值：1.0）。 | FLOAT | 是 | 最小值：0.0，最大值：10.0，步长：0.01 |

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `音频编码器输出` | 包含处理后的音频特征、计算得到的帧率（fps）以及音频注入比例的字典。该输出用于对视频生成模型进行条件约束。 | AUDIO_ENCODER_OUTPUT |
| `fps字符串` | 描述基于音频长度和视频帧数计算得到的帧率（fps）的文本字符串。该字符串旨在用于视频模型的提示词中。其格式为中文，以与参考流程保持一致。 | STRING |
