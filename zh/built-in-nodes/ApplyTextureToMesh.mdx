此节点将烘焙后的纹理图像附加到网格的 UV 布局上，以便它们可以通过 SaveGLB 节点与网格一起导出。请向它提供与烘焙纹理时相同的 UV 展开网格，以及烘焙后的图像贴图。可选的 `metallic`、`roughness` 和 `occlusion` 贴图会打包到单个 ORM 纹理中；如果提供法线贴图，还会存储正确着色所需的平滑顶点法线和切线基。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 将附加烘焙纹理的 UV 展开网格。必须与烘焙期间使用的网格相同；如果网格没有 UV，则会引发错误。 | MESH | 是 | — |
| `base_color` | 烘焙后的基础颜色图像。存储为网格的纹理，并限制在 0-1 范围内。 | IMAGE | 是 | — |
| `metallic` | 烘焙后的金属度贴图。用作组合 ORM 纹理的蓝色通道；未提供时默认为 0。 | IMAGE | 否 | — |
| `roughness` | 烘焙后的粗糙度贴图。用作组合 ORM 纹理的绿色通道；未提供时默认为 1。 | IMAGE | 否 | — |
| `occlusion` | 烘焙后的环境光遮蔽贴图。用作组合 ORM 纹理的红色通道；未提供时默认为 1。提供后，ORM 纹理还会被标记为 SaveGLB 的遮蔽纹理。 | IMAGE | 否 | — |
| `normal_map` | 烘焙后的切线空间法线贴图。提供后，节点会重新计算逐顶点切线，并导出平滑顶点法线，以便法线贴图正确着色。 | IMAGE | 否 | — |

注意：`mesh` 输入必须具有 UV 坐标；如果没有，节点会引发错误，要求你连接用于烘焙的同一 UV 展开网格。

注意：当 `metallic`、`roughness` 或 `occlusion` 中任意一个连接时，三者都会打包为单个 glTF ORM 纹理，通道为 R = occlusion，G = roughness，B = metallic。缺失的贴图会用默认值填充（occlusion 1、roughness 1、metallic 0），不同分辨率的贴图会调整大小为所提供贴图中最大的宽度和高度。

注意：当连接 `normal_map` 时，网格存储的法线会替换为计算得到的平滑顶点法线，并添加逐顶点切线基。落在 [0,1] 范围之外的 UV 坐标会统一缩放到 [0,1] 内，同时保持宽高比；如果 UV 跨度看起来像平铺/UDIM 布局，则会记录警告。对于批量网格，UV 归一化会使用与烘焙步骤相同的逻辑分别应用于批次中的每个项目，因此两者保持对齐。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mesh` | 已附加纹理图像到其 UV 布局的输入网格，可供 SaveGLB 保存。 | MESH |
