此节点会将烘焙的纹理图像附着到网格的 UV 布局上，以便它们可以由 SaveGLB 节点与网格一起导出。连接与烘焙时相同的 UV 展开网格，以及烘焙后的图像贴图。可选的金属度、粗糙度和环境光遮蔽贴图会被打包到单个 ORM 纹理中；提供法线贴图时，还会存储正确着色所需的平滑法线和切线。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 烘焙纹理将附着到的 UV 展开网格。必须与烘焙期间使用的网格相同；如果网格没有 UV，则会报错。 | MESH | 是 | — |
| `base_color` | 烘焙后的基础颜色图像。存储为网格的纹理，并限制在 0 到 1 范围内。 | IMAGE | 是 | — |
| `metallic` | 烘焙后的金属度贴图。用作组合 ORM 纹理的蓝色通道；未提供时默认为 0。 | IMAGE | 否 | — |
| `roughness` | 烘焙后的粗糙度贴图。用作组合 ORM 纹理的绿色通道；未提供时默认为 1。 | IMAGE | 否 | — |
| `occlusion` | 烘焙后的环境光遮蔽贴图。用作组合 ORM 纹理的红色通道；未提供时默认为 1。提供时，ORM 纹理还会被标记为 SaveGLB 的环境光遮蔽纹理。 | IMAGE | 否 | — |
| `normal_map` | 烘焙后的切线空间法线贴图。提供时，节点会重新计算逐顶点切线基，并导出平滑顶点法线，使法线贴图正确着色。 | IMAGE | 否 | — |

注意：当 `metallic`、`roughness` 或 `occlusion` 中任意一个连接时，三者会一起打包到单个 glTF ORM 纹理中，通道分配为 R = 环境光遮蔽、G = 粗糙度、B = 金属度。缺失的贴图将使用默认值填充（环境光遮蔽 1、粗糙度 1、金属度 0），分辨率不同的贴图会调整为最大的宽度和高度。连接 `normal_map` 时，网格的法线将被替换为计算出的平滑顶点法线，并添加切线基。超出 [0,1] 范围的 UV 坐标会在保持宽高比的同时均匀缩放到 [0,1]。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `mesh` | 带有纹理图像附着到 UV 布局的输入网格，可供 SaveGLB 直接保存。 | MESH |
