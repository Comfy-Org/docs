视频切片节点允许您从视频中提取特定片段。您可以定义开始时间和持续时间来裁剪视频，或者直接跳过开头帧。如果请求的持续时间超过剩余视频长度，该节点可以返回可用部分或引发错误。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `视频` | 要切片的输入视频。 | VIDEO | 是 | - |
| `起始时间` | 开始时间（秒，默认：0.0）。 | FLOAT | 是 | -1e5 到 1e5 |
| `时长` | 持续时间（秒），0 表示不限时长（默认：0.0）。 | FLOAT | 是 | 0.0 and above |
| `严格时长` | 如果为 True，当无法达到指定的持续时间时将引发错误（默认：False）。 | BOOLEAN | 是 | - |

**注意：** 如果无法按给定的 `start_time` 和 `duration` 对视频进行切片，节点会引发错误。当 `strict_duration` 为 False 时，如果请求的持续时间超过剩余长度，节点将返回视频的可用部分；为 True 时则改为引发错误。

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `video` | 裁剪后的视频片段。 | VIDEO |
