此节点将图像批次及其边界框转换为图层堆栈，为每一帧创建一个图层，并根据匹配的框放置每个图层。当某个节点以批次形式输出图层时，请使用此节点，因为批次仅为所有帧携带单一的放置信息，否则各个位置信息将会丢失。

## 输入
| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 图像批次；每一帧成为一个图层。 | IMAGE | 是 | — |
| `bboxes` | 放置框，与图像批次按索引对齐。接受边界框 (x, y, width, height)、归一化元素（带有 "bbox"——这些元素需要 `canvas_width`/`canvas_height` 才能解析为像素），或其中任意一种的 JSON 字符串。没有匹配框的帧将放置在原点。框的 width/height 会缩放图层以匹配该框。当存在 `metadata.name`（或 `desc`）和 `metadata.z_index` 时，会使用它们；`metadata.content_rect`（帧相对坐标）会将帧裁剪到其实际内容。 | BOUNDING_BOX, ARRAY, or STRING | 是 | — |
| `mask` | 逐帧透明度，与图像批次按索引对齐（1 = 透明，LoadImage 约定）。 | MASK | 否 | — |
| `layers` | 要追加到的图层堆栈。保持未连接以开始新的堆栈。 | LAYERS | 否 | — |
| `crop_to_content` | 当存在 `metadata.content_rect` 时，将每一帧裁剪到该矩形，并将内容放置在框的位置加上矩形偏移处。对于帧带有填充的批次，请保持开启——它只将实际内容保留在真实位置。（默认：true） | BOOLEAN | 否 | true<br />false |
| `canvas_width` | 文档画布宽度。0 表示从已放置的图层派生。（默认：0） | INT | 否 | 0 到 MAX_RESOLUTION |
| `canvas_height` | 文档画布高度。0 表示从已放置的图层派生。（默认：0） | INT | 否 | 0 到 MAX_RESOLUTION |

注意：

- `bboxes` 和 `mask` 必须与 `image` 按索引对齐：第 n 个框和第 n 个遮罩帧对应第 n 个图像帧。没有匹配框的帧将放置在原点。
- 当 `bboxes` 包含归一化元素（带有 "bbox"）时，必须提供 `canvas_width` 和 `canvas_height`，以便将这些归一化位置解析为像素。
- `canvas_width` 和 `canvas_height` 必须都大于 0 才能显式设置文档画布。如果任一为 0，则画布将从已放置的图层派生，或从连接的 `layers` 堆栈继承。
- 当 `layers` 已连接时，新图层会追加到该堆栈，并接收高于堆栈中已有最高 z-index 的 z-index 值。
- 当 `crop_to_content` 启用且帧具有 `metadata.content_rect` 时，该帧会被裁剪到该矩形，并且不应用框的 width/height 缩放；而是将矩形的偏移量添加到框的位置。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `LAYERS` | 图层堆栈，可直接用于 Create Layered Image。 | LAYERS |
