`CLIP Set Last Layer` 是 ComfyUI 中的一个核心节点，用于控制 CLIP 模型的处理深度。它允许用户精确控制 CLIP 文本编码器在何处停止处理，从而同时影响文本理解的深度和生成图像的风格。原始 CLIP 模型保持不变：该节点在副本上操作，并返回修改后的副本。

## Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `clip` | 要修改的 CLIP 模型 | CLIP | 是 | - |
| `停止在CLIP层` | 指定在哪一层停止。值 -1 使用所有层，而 -24 仅使用第一层（默认值：-1）。这是一个高级参数。 | INT | 是 | -24 到 -1（步长：1） |

这些值为负数，并从模型末尾向前计数：-1 指的是最后一层（最深），-24 指的是第一层（最浅），因此允许范围仅涵盖 -24 到 -1。

## Outputs

| Output Name | Description | Data Type |
| --- | --- | --- |
| `clip` | 修改后的 CLIP 模型（输入模型的克隆；原始 CLIP 模型不会被更改），并将指定层设置为最后一层 | CLIP |

## 为什么要设置最后一层

- **性能优化**：就像不需要博士学位就能理解简单句子一样，有时浅层理解已经足够，而且更快
- **风格控制**：不同层次的理解会产生不同的艺术风格
- **兼容性**：某些模型在特定层可能表现更好

将 CLIP 模型想象成一个 24 层的智能大脑：

- 浅层（1-8）：识别基本字母和单词
- 中层（9-16）：理解语法和句子结构
- 深层（17-24）：掌握抽象概念和复杂语义

`CLIP Set Last Layer` 就像一个 **“思考深度控制器”**：

- -1：使用全部 24 层（完整理解）
- -2：在第 23 层停止（略微简化）
- -12：在第 13 层停止（中等理解）
- -24：仅使用第 1 层（基础理解）
