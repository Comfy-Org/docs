使用 Bria 的文本引导图像编辑，将图像中的一个对象替换为用纯文本描述的其他对象。Bria 以约 1 兆像素重新渲染整个画面，因此结果与输入不是像素对齐的。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 包含要替换对象的图像。上传图像前会丢弃 alpha 通道。 | IMAGE | 是 | - |
| `指令` | 要替换什么以及替换为什么，例如“将红苹果替换为绿梨”。长度必须至少为 1 个字符。 | STRING | 是 | 多行文本；默认值：""（空） |
| `种子` | Bria 在此不接收 seed，每次调用都会重新构想编辑，因此重复运行可能会有所不同。该值永远不会被发送：它只会更改此节点的缓存键，以便在其它方面相同的图会再次运行编辑，而不是返回缓存的结果。 | INT | 是 | 0 到 2147483647，步长 1；默认值：42；生成后控制已启用 |

### 审核输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `内容审核` | 审核设置。选择 "true" 会显示下面的审核子选项，否则不会显示。 | DYNAMIC_COMBO | 是 | `"false"`<br />`"true"` |
| `visual_input_moderation` | 启用对输入图像的审核。仅当 `moderation` 设置为 "true" 时可用。 | BOOLEAN | 否 | `true` / `false`；默认值：false |
| `visual_output_moderation` | 启用对生成的输出图像的审核。仅当 `moderation` 设置为 "true" 时可用。 | BOOLEAN | 否 | `true` / `false`；默认值：false |

注意：`instruction` 在发送请求前会进行验证，并且必须至少包含 1 个字符。`seed` 值不会传输给 Bria；它只影响节点是重新运行编辑还是返回缓存结果。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 应用了所述对象替换后的已编辑图像。 | IMAGE |
| `structured_prompt` | 已编辑图像的结构化描述，用于使用 Bria FIBO Image Edit 进行后续编辑。 | STRING |
