Vidu Q3 图像转视频生成节点从输入图像开始创建视频序列。该节点使用 Vidu Q3 模型为图像添加动画效果，并可选地由文本提示引导，最终输出视频文件。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频生成的模型。 | DYNAMIC_COMBO | 是 | `"viduq3-pro"`<br />`"viduq3-turbo"` |
| `image` | 用作生成视频起始帧的图像。 | IMAGE | 是 | - |
| `prompt` | 用于视频生成的可选文本提示（最多 2000 个字符）（默认：空）。 | STRING | 是 | - |
| `seed` | 用于控制生成随机性的种子值（默认：1）。支持生成后控制。 | INT | 是 | 0 到 2147483647 |

### viduq3-pro 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | `"720p"`<br />`"1080p"`<br />`"2K"` |
| `duration` | 输出视频的时长（秒）（默认：5）。 | INT | 是 | 1 到 16 |
| `audio` | 启用后，输出带声音的视频（包括对话和音效）（默认：False）。 | BOOLEAN | 是 | `True`<br />`False` |

### viduq3-turbo 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | `"720p"`<br />`"1080p"` |
| `duration` | 输出视频的时长（秒）（默认：5）。 | INT | 是 | 1 到 16 |
| `audio` | 启用后，输出带声音的视频（包括对话和音效）（默认：False）。 | BOOLEAN | 是 | `True`<br />`False` |

**注意：** `image` 的长宽比必须在 1:4 到 4:1 之间（从竖屏到横屏）。`prompt` 为可选参数，但长度不能超过 2000 个字符。分辨率选项取决于所选模型：`"viduq3-pro"` 支持 `"720p"`、`"1080p"` 和 `"2K"`；`"viduq3-turbo"` 支持 `"720p"` 和 `"1080p"`。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 生成的视频文件。 | VIDEO |
