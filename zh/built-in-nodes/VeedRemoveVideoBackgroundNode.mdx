使用 VEED 从视频中抠出主体，并返回帧图像以及 Alpha 蒙版。可将这两个输出用于合成，或通过“Join Image with Alpha”和“Save WEBM”节点处理以写出透明视频。选择 `"standard"` 可在任意背景下获得最佳边缘效果，选择 `"fast"` 适合对速度有要求的场景，选择 `"green screen"` 则适用于在绿幕前拍摄的素材。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 要使用的分割模型：`"standard"` 适用于任意背景，边缘效果最佳，输出最高可达 3840x2160；`"fast"` 速度更快，输出最高可达 1920x1080；`"green screen"` 用于抠除绿色背景，输出最高可达 3840x2160。更大的视频会被缩小。选择某个选项后会显示其参数。 | DYNAMIC_COMBO | 是 | `"standard"`<br />`"fast"`<br />`"green screen"` |
| `video` | 要抠出主体的视频。最长 60 秒。 | VIDEO | 是 | 最长 60 秒 |
| `refine_foreground_edges` | 让头发、毛发和精细细节的边缘更干净。关闭此选项可降低费用。适用于 `"standard"` 和 `"fast"`（默认：True）。 | BOOLEAN | 是 | false<br />true |
| `subject_is_person` | 当主体是物体或动物时请关闭。适用于 `"standard"` 和 `"fast"`（默认：True）。 | BOOLEAN | 是 | false<br />true |
| `spill_suppression_strength` | 从主体上移除绿色溢色的强度。当仍有绿色残留时调高此值；当主体颜色发生偏移时调低此值。适用于 `"green screen"`（默认：0.8）。 | FLOAT | 是 | 0.0 到 1.0（步长 0.01） |

片段时长限制为 60 秒；更长的视频会被拒绝并报错。在背景被移除的位置，蒙版值为 1，因此若想保留主体，请在“Image Composite Masked”之前使用“Invert Mask”。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `images` | 已移除背景的视频帧。 | IMAGE |
| `mask` | 每帧中背景被移除的位置为 1。 | MASK |
