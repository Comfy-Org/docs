在 Comfy Cloud GPU 上运行 Flux 2 dev 文本到图像模型，并返回生成的图像。`turbo` 选项会以较短的调度应用 Turbo LoRA，从而大幅加快运行速度，代价是略微损失保真度；关闭该选项则会在不使用 LoRA 的情况下执行完整长度的 dev 流程。这是一个 beta 节点集，按运行时长以 credits 计费。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述要生成图像的文本提示词。提交前会移除首尾空白字符。 | STRING | 是 | 1 到 4096 个字符 |
| `seed` | 控制生成结果的随机种子，用于复现结果（默认值：42）。 | INT | 是 | 0 到 18446744073709551615 |
| `aspect_ratio` | 输出图像的宽高比（默认值："1:1"）。 | COMBO | 是 | "1:1"<br />"3:4"<br />"2:3"<br />"3:2"<br />"4:3"<br />"16:9"<br />"9:16"<br />"21:9" |
| `megapixels` | 总像素预算。在正方形比例下，1.0 约等于 1024x1024（默认值：1.0）。 | FLOAT | 是 | 0.1 到 16.0（步长 0.1） |
| `turbo` | 以较短的调度运行 Turbo LoRA，用略微的保真度损失换取大幅加快的运行速度。关闭时则在不使用 LoRA 的情况下执行完整的 dev 流程（默认值：True）。 | BOOLEAN | 是 | True / False |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `IMAGE` | 根据文本提示词生成的图像，以 ComfyUI 图像张量形式返回，可传递给其他节点。 | IMAGE |
