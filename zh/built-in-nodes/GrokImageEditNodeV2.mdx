基于文本提示修改一个或多个现有图像。此节点使用所选模型将连接的参考图像和提示发送至 Grok 图像编辑 API，然后返回编辑后的图像。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要使用的 Grok 图像模型。下方显示的子参数会随所选模型而变化。 | DYNAMIC_COMBO | 是 | "grok-imagine-image-2.0"<br />"grok-imagine-image-quality"<br />"grok-imagine-image-pro"<br />"grok-imagine-image" |
| `提示词` | 用于生成图像的文字提示。（默认值：""） | STRING | 是 | 不适用 |
| `种子` | 用于决定节点是否应重新运行的种子；实际结果与种子无关，具有不确定性。（默认值：0） | INT | 是 | 0 到 2147483647 |

### grok-imagine-image-2.0 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 编辑后图像的输出分辨率。 | COMBO | 是 | "1K"<br />"2K" |
| `number_of_images` | 要生成的编辑后图像数量。（默认值：1） | INT | 是 | 1 到 10 |
| `quality` | 生成图像的质量级别。 | COMBO | 是 | "medium"<br />"low" |
| `aspect_ratio` | 编辑后图像的宽高比。（默认值："auto"） | COMBO | 是 | "auto"<br />"1:1"<br />"2:3"<br />"3:2"<br />"3:4"<br />"4:3"<br />"9:16"<br />"16:9"<br />"9:19.5"<br />"19.5:9"<br />"9:20"<br />"20:9"<br />"1:2"<br />"2:1" |

### grok-imagine-image-quality 和 grok-imagine-image 输入

由 grok-imagine-image-quality 和 grok-imagine-image 共用。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |

| `aspect_ratio` | 仅在连接了多张图像时允许使用。（默认值："auto"） | COMBO | 是 | "auto"<br />"1:1"<br />"2:3"<br />"3:2"<br />"3:4"<br />"4:3"<br />"9:16"<br />"16:9"<br />"9:19.5"<br />"19.5:9"<br />"9:20"<br />"20:9"<br />"1:2"<br />"2:1" |

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 编辑后图像的输出分辨率。 | COMBO | 是 | "1K"<br />"2K" |
| `number_of_images` | 要生成的编辑后图像数量。（默认值：1） | INT | 是 | 1 到 10 |

### 参考输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `images` | 可增补插槽：连接 1 个或多个要编辑的参考图像。第一个插槽为 `image`，后续插槽为 `image_1`、`image_2`，依此类推。最大图像数量取决于所选模型。 | IMAGE | 是 | `grok-imagine-image-pro` 支持 1 张图像<br />`grok-imagine-image-2.0`、`grok-imagine-image-quality` 和 `grok-imagine-image` 支持 1 到 3 张图像 |

**关于限制的说明：**
- `prompt` 必须至少包含 1 个非空白字符。
- 编辑操作至少需要一张参考图像；如果未连接任何图像，节点将报错。
- `grok-imagine-image-pro` 的最大输入图像数量为 1，`grok-imagine-image-2.0`、`grok-imagine-image-quality` 和 `grok-imagine-image` 的最大输入图像数量为 3。连接超过模型支持数量的图像会报错。
- 对于 `grok-imagine-image-quality` 和 `grok-imagine-image`，自定义 `aspect_ratio`（即除 "auto" 以外的任何值）仅在连接多张图像时允许使用。当只有一张图像时，`aspect_ratio` 必须为 "auto"。
- 对于 `grok-imagine-image-2.0`，即使只有一张图像，也可以自由设置 `aspect_ratio`。
- `quality` 子参数仅在 `grok-imagine-image-2.0` 下可用。
