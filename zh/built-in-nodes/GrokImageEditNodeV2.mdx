基于文本提示修改一张或多张现有图像。此节点使用所选模型将连接的参考图像和提示发送到 Grok 图像编辑 API，然后返回编辑后的图像。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要使用的 Grok 图像模型。下面显示的子参数会随所选模型而变化。 | DYNAMIC_COMBO | 是 | "grok-imagine-image-2.0"<br />"grok-imagine-image-quality"<br />"grok-imagine-image-pro"<br />"grok-imagine-image" |
| `提示词` | 用于生成图像的文本提示。(默认: "") | STRING | 是 | N/A |
| `种子` | 用于确定节点是否应重新运行的种子；无论种子如何，实际结果都是非确定性的。(默认: 0) | INT | 是 | 0 到 2147483647 |

### grok-imagine-image-2.0 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 编辑后图像的输出分辨率。 | COMBO | 是 | "1K"<br />"2K" |
| `number_of_images` | 要生成的编辑图像数量。(默认: 1) | INT | 是 | 1 到 10 |
| `quality` | 生成图像的质量级别。 | COMBO | 是 | "medium"<br />"low" |
| `aspect_ratio` | 编辑后图像的宽高比。(默认: "auto") | COMBO | 是 | "auto"<br />"1:1"<br />"2:3"<br />"3:2"<br />"3:4"<br />"4:3"<br />"9:16"<br />"16:9"<br />"9:19.5"<br />"19.5:9"<br />"9:20"<br />"20:9"<br />"1:2"<br />"2:1" |

### 参考输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `images` | 可增长槽位：连接 1 到 N 张要编辑的参考图像。槽位使用模板名称 `image_1`、`image_2`、`image_3`；最大槽位数取决于所选模型。 | IMAGE | 是 | 1 张图像（适用于 `grok-imagine-image-pro`）<br />1 到 3 张图像（适用于 `grok-imagine-image-2.0`、`grok-imagine-image-quality` 和 `grok-imagine-image`） |

**约束说明：**
- `prompt` 必须包含至少 1 个非空白字符。
- 编辑时至少需要一张参考图像；如果未连接任何图像，节点会报错。
- 输入图像的最大数量为：`grok-imagine-image-pro` 为 1 张，`grok-imagine-image-2.0`、`grok-imagine-image-quality` 和 `grok-imagine-image` 为 3 张。连接超过模型支持数量的图像会报错。
- 图像限制会计算连接输入中的每一张图像，因此包含多张图像的批次会按多张图像计入限制。
- 对于 `grok-imagine-image-quality` 和 `grok-imagine-image`，仅当连接多张图像时，才允许自定义 `aspect_ratio`（任何非 "auto" 的值）。如果只有一张图像，`aspect_ratio` 必须为 "auto"。
- 对于 `grok-imagine-image-2.0`，即使只有一张图像，也可以自由设置 `aspect_ratio`。
- `quality` 子参数仅适用于 `grok-imagine-image-2.0`。
