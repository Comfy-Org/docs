Tripo: Smart UV 会重新展开模型的 UV，并将其纹理、绑定和动画重新映射到新的布局上。当模型的原始 UV 布局无法使用时可使用它，例如在重拓扑之后，或需要重做纹理接缝时。输入模型不得超过 80,000 个三角形（四边形按两个三角形计算），因此请先使用 Tripo: Retopology 或 `face_limit` 缩减较大的模型。

> **注意：** Tripo 会在其服务器上保留任务记录 7 天（自 2026 年 12 月 1 日起生效）。超过该期限的任务 ID 将无法再解析，因此在窗口期之后重新运行已保存的工作流时，此节点会失败。请重新运行生成该任务的上游 Tripo 节点，或使用 **Tripo: Import Model** 重新导入已下载的模型。请在窗口期关闭前下载模型：过期的资产无法从任务记录中恢复。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | 要重新展开 UV 的模型的任务 ID。接受来自 Tripo 生成节点的模型任务 ID，或绑定、重定向或分割任务 ID。 | MODEL_TASK_ID | 是 | Tripo 任务 ID |
| `bake` | 将现有纹理烘焙到新的 UV 布局上。关闭时会跳过烘焙并返回不带颜色纹理的模型（默认：True）。 | BOOLEAN | 是 | `True`<br />`False` |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model task_id` | 完成的 UV 任务的任务 ID。可传递给其他 Tripo 节点，例如 Tripo: Texture。 | MODEL_TASK_ID |
| `GLB` | 重新展开 UV 后的模型，格式为 GLB。当源模型为 FBX 时为空。 | FILE_3D_GLB |
| `FBX` | 重新展开 UV 后的模型，格式为 FBX。仅当源模型为 FBX（例如四边形网格）时才有值。 | FILE_3D_FBX |
| `UV atlas` | 模型渲染后的 UV 布局图像。 | IMAGE |
