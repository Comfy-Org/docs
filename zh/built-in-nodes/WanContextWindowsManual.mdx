```markdown
WAN 上下文窗口（手动）节点允许你手动为 Wan 风格视频模型配置上下文窗口。它会在采样过程中应用这些设置，让你能够控制窗口长度、重叠、调度以及模型处理视频时使用的融合方法。上下文长度和重叠以实际帧为单位指定，并在内部转换为模型的 2D 处理所需的值。

## 输入
| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 在采样期间要应用上下文窗口的模型。 | MODEL | 是 | - |
| `上下文长度` | 上下文窗口的长度，以实际帧为单位。必须为 4*n + 1（默认值：81）。 | INT | 是 | 1 到 16384 (MAX_RESOLUTION), step 4 |
| `上下文重叠` | 上下文窗口的重叠部分，以实际帧为单位（默认值：30）。 | INT | 是 | 0 or higher |
| `上下文调度` | 上下文窗口的按步骤调度算法（默认值："uniform_standard"）。 | COMBO | 是 | `"static_standard"`<br>`"uniform_standard"`<br>`"uniform_looped"`<br>`"batched"` |
| `上下文步长` | 上下文窗口的步幅；仅适用于均匀（uniform）调度（默认值：1）。 | INT | 是 | 1 or higher |
| `闭环` | 是否闭合上下文窗口循环；仅适用于循环（looped）调度（默认值：False）。 | BOOLEAN | 是 | - |
| `融合方法` | 用于融合上下文窗口的方法（默认值："pyramid"）。 | COMBO | 是 | `"pyramid"`<br>`"gaussian"`<br>`"average"`<br>`"overlap"` |
| `Freenoise` | 是否应用 FreeNoise 噪声重排，以改善窗口混合效果（默认值：True）。 | BOOLEAN | 是 | - |
| `retain_first_frame` | 在每个上下文窗口中保留第一个 I2V 帧（可能有助于保留初始参考）（默认值：False）。 | BOOLEAN | 是 | - |
| `split_conds_to_windows` | 是否根据区域索引将多个 conditioning（由 ConditionCombine 创建）拆分到每个窗口（默认值：False）。 | BOOLEAN | 是 | - |

**注意：** `context_stride` 仅影响均匀（uniform）调度，`closed_loop` 仅适用于循环（looped）调度。上下文长度和重叠以实际帧为单位指定，并在处理过程中自动转换并限制到最小有效值（`context_length` 变为 ((length - 1) / 4) + 1，`context_overlap` 变为 overlap / 4）。`context_length` 必须遵循 4*n + 1 的形式。`retain_first_frame` 用于图生视频（image-to-video）场景。`split_conds_to_windows` 需要由 ConditionCombine 节点创建的多个 conditioning。`fuse_method` 参数包含多个选项，而不仅仅是 "pyramid"。

## 输出
| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `model` | 应用了上下文窗口配置的模型。 | MODEL |
```
