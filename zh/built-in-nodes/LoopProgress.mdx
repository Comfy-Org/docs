LoopProgress 是一个仅用于开发的辅助节点，用于向 ComfyUI 服务器界面报告循环进度。每次执行时，它会向客户端发送文本 "Iteration X / Y"，并原样返回当前迭代位置，因此它可以内联放置在循环中，而不会改变数据流。

## 输入

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `start_id` | 进度消息所属的提示词/循环实例的标识符。传入列表中的第一个项用于将进度文本路由到正确的运行中执行实例。 | STRING | 是 | - |
| `position` | 当前迭代位置（索引）。传入列表中的第一个项会用于进度消息，并作为输出返回。 | INT | 是 | - |
| `total` | 迭代总次数。与 `position` 一起用于构建 "Iteration X / Y" 进度消息。 | INT | 是 | - |

注意：此节点使用列表输入声明（`is_input_list=True`）并接受所有输入，因此每个连接的值都会被视为列表，只读取其第一个元素。该节点始终运行（其输入指纹是固定的），因此每次循环轮次都会重新执行。

## 输出

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `position` | 当前迭代位置，从 `position` 输入原样传递。 | INT |
