CFG Override 节点可在采样过程的某个百分比（sigma）范围内，将 CFG（Classifier-Free Guidance，无分类器引导）缩放值覆盖为固定值。当使用多个 CFG Override 节点时，在范围重叠的部分，距离采样器最近的那个覆盖设置生效。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要应用 CFG 覆盖的模型。 | MODEL | 是 | |
| `cfg` | 在覆盖范围内使用的固定 CFG 缩放值。默认值：1.0。 | FLOAT | 是 | 0.0 至 100.0（步长：0.1） |
| `起始百分比` | 覆盖范围的起点，以采样过程的百分比表示。默认值：0.0。 | FLOAT | 是 | 0.0 至 1.0（步长：0.001） |
| `结束百分比` | 覆盖范围的终点，以采样过程的百分比表示。默认值：1.0。 | FLOAT | 是 | 0.0 至 1.0（步长：0.001） |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `MODEL` | 已应用 CFG 覆盖包装器的模型。 | MODEL |
