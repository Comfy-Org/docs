Bria Expand Image 通过使用 Bria 生成新内容，将图像扩展到其原始边界之外。它允许您选择目标宽高比、自定义比例，或通过手动放置原始图像来定义画布。扩展可以通过文本提示进行引导，如果提示留空，Bria 将自动生成一个。

## 输入

|-----------|-------------|-----------|----------|-------|
| `image` | 要扩展的输入图像。 | IMAGE | 是 | — |
| `expand_mode` | 扩展后图像的目标形状：预设宽高比、自定义比例，或手动将原始图像放置在画布上。手动是唯一可以达到高于 1:2 的画布的模式。选择 `custom_ratio` 会显示 `ratio_width` 和 `ratio_height`。选择 `manual` 会显示画布和图像放置参数。 | DYNAMIC_COMBO | 是 | `"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"`<br />`"custom_ratio"`<br />`"manual"` |

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|

### 审核输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | 如果启用，则审核提示内容。默认值：false。仅在 `moderation` 为 `true` 时可用。 | BOOLEAN | 是 | true/false |
| `visual_input_moderation` | 如果启用，则审核视觉输入。默认值：false。仅在 `moderation` 为 `true` 时可用。 | BOOLEAN | 是 | true/false |
| `visual_output_moderation` | 如果启用，则审核视觉输出。默认值：false。仅在 `moderation` 为 `true` 时可用。 | BOOLEAN | 是 | true/false |

预设宽高比选项（`1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`4:5`、`5:4`、`9:16`、`16:9`）没有额外的输入。

当 `expand_mode` 为 `custom_ratio` 时，`ratio_width` 和 `ratio_height` 定义目标宽高比。Bria 只接受宽度与高度的比例在 0.5 到 3.0 之间。如果比例超出此范围，将引发错误，应改用 `manual` 模式。

当 `expand_mode` 为 `manual` 时，原始图像会以指定的大小和位置放置在画布上。图像可能延伸到画布之外，在这种情况下，外部部分会被裁剪。

当 `moderation` 为 `true` 时，三个审核布尔值会发送给 Bria。当 `moderation` 为 `false` 时，它们会被忽略。
