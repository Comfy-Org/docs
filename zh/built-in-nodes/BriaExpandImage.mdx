Bria Expand Image 可让您通过 Bria 生成新内容，将图像扩展到原始边界之外。您可以选择目标宽高比、自定义宽高比，或通过手动放置原始图像来定义画布。扩展过程可使用文本提示进行引导；若提示留空，Bria 将自动生成提示。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 取值范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 要扩展的输入图像。 | IMAGE | 是 | — |
| `expand_mode` | 扩展图像的目标形状：预设宽高比、自定义宽高比，或在画布上手动放置原始图像。手动模式是唯一能达到高于 1:2 画布的模式。选择 `custom_ratio` 会显示 `ratio_width` 和 `ratio_height`。选择 `manual` 会显示画布和图像放置参数。 | DYNAMIC_COMBO | 是 | `"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"`<br />`"custom_ratio"`<br />`"manual"` |
| `ratio_width` | 目标宽高比的宽度侧：21 和 9 表示 21:9。默认值：21。 | INT | 条件必填 | 1–100 |
| `ratio_height` | 目标宽高比的高度侧：21 和 9 表示 21:9。Bria 仅接受宽度/高度在 0.5 到 3.0 之间的比例，因此任何高于 1:2 的比例都需要使用手动模式。默认值：9。 | INT | 条件必填 | 1–100 |
| `canvas_width` | 输出画布的宽度（像素）。默认值：1000。 | INT | 条件必填 | 64–5000 |
| `canvas_height` | 输出画布的高度（像素）。默认值：1000。 | INT | 条件必填 | 64–5000 |
| `image_width` | 原始图像在画布内的宽度。默认值：500。 | INT | 条件必填 | 1–5000 |
| `image_height` | 原始图像在画布内的高度。默认值：500。 | INT | 条件必填 | 1–5000 |
| `image_x` | 图像左上角在画布内的 X 位置；可能超出画布边界，导致图像被裁剪。默认值：250。 | INT | 条件必填 | -5000–5000 |
| `image_y` | 图像左上角在画布内的 Y 位置；可能超出画布边界，导致图像被裁剪。默认值：250。 | INT | 条件必填 | -5000–5000 |
| `prompt` | 扩展场景的可选描述；为空时，Bria 会根据图像自动生成描述。默认值：空字符串。 | STRING | 否 | 任意字符串 |
| `negative_prompt` | 扩展过程的可选负向提示。默认值：空字符串。 | STRING | 否 | 任意字符串 |
| `seed` | 随机生成过程的种子。默认值：42。 | INT | 否 | 1–2147483647 |
| `moderation` | 审核设置。设置为 `true` 时，会显示额外的审核选项。 | DYNAMIC_COMBO | 否 | `"false"`<br />`"true"` |
| `prompt_content_moderation` | 启用后，会对提示内容进行审核。默认值：false。仅在 `moderation` 为 `true` 时可用。 | BOOLEAN | 条件必填 | true/false |
| `visual_input_moderation` | 启用后，会对视觉输入进行审核。默认值：false。仅在 `moderation` 为 `true` 时可用。 | BOOLEAN | 条件必填 | true/false |
| `visual_output_moderation` | 启用后，会对视觉输出进行审核。默认值：false。仅在 `moderation` 为 `true` 时可用。 | BOOLEAN | 条件必填 | true/false |

当 `expand_mode` 为 `custom_ratio` 时，`ratio_width` 和 `ratio_height` 定义目标宽高比。Bria 仅接受宽度与高度之比在 0.5 到 3.0 之间的比例。如果比例超出此范围，则会引发错误，此时应改用 `manual` 模式。

当 `expand_mode` 为 `manual` 时，原始图像会以指定大小和位置放置在画布上。图像可能超出画布边界，此时超出部分将被裁剪。

当 `moderation` 为 `true` 时，三个审核布尔值会发送给 Bria。当 `moderation` 为 `false` 时，它们会被忽略。
