ByteDance Seedream 5.0 Pro 图层分离节点将图像分解为一个背景图层和最多 16 个透明图层，每个图层都有自己的堆叠顺序、边界框、名称和描述。它返回背景、带遮罩的逐层图像、放置框以及一个可直接编辑的图层堆栈。

## 输入
| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 要分离的图像。恰好一张图像，至少为 512x512 像素，宽高比在 1:16 到 16:1 之间。大于约 4MP 的输入在上传前会被缩小。 | IMAGE | 是 | 单张图像 |
| `prompt` | 如何分离图像。留空以自动检测并分离所有主要元素。用自然语言描述元素来控制分离，或使用 `<bbox>left top right bottom&lt;/bbox>` 标签定位精确区域（0-1000 千分比坐标）。默认值：空字符串。 | STRING | 是 | 多行文本 |
| `size` | 输出分辨率级别。“auto”遵循输入图像尺寸（限制在 1K-2K 范围内）。默认值：“auto”。 | STRING | 是 | "auto"<br />"1K"<br />"1.5K"<br />"2K" |
| `seed` | 用于生成的种子。默认值：0。 | INT | 是 | 0 到 2147483647 |
| `prompt_optimization` | 提示词优化模式：“standard”提供更高质量，“fast”生成时间更短。默认值：“standard”。 | STRING | 否 | "standard"<br />"fast" |
| `watermark` | 是否在图像上添加“AI 生成”水印。默认值：false。 | BOOLEAN | 否 | false<br />true |
| `crop_layers` | 图层/遮罩批量输出的几何形状（layer_stack 不受影响，始终为紧密裁剪）。完整画布：每个图层位于其边界框位置的基础尺寸画布上——可直接使用 ImageCompositeMasked 重新合成。最小尺寸：每个图层裁剪到其边界框（为批量处理填充到最大图层）——张量小得多；使用 Layers From Bounding Boxes 利用 bboxes 输出重建放置。默认值：false（完整画布）。 | BOOLEAN | 否 | false（完整画布）<br />true（最小尺寸） |

注意：输入图像必须为单张图像；不支持批量。图像必须至少为 512x512 像素，宽高比在 1:16 到 16:1 之间。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `base_image` | 图层堆叠到其上的基础图像（背景图层）。 | IMAGE |
| `base_mask` | 基础图像的透明度（1 = 透明，LoadImage 惯例）；目前始终完全不透明。 | MASK |
| `layers` | 自下而上排列的透明图层。完整画布模式：在基础尺寸的黑色画布上按边界框位置放置。最小尺寸模式：裁剪到其边界框，锚定左上角，填充到最大图层。 | IMAGE |
| `masks` | 逐层透明度，与 layers 批次索引对齐（1 = 透明，LoadImage 惯例）。对于 ImageCompositeMasked 风格的合成，请先添加 InvertMask。 | MASK |
| `bboxes` | 每个图层一个放置框，与 layers 批次索引对齐（将两者以及 masks 输入到 Layers From Bounding Boxes 中以重建每层放置）：`{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`。`content_rect = [left, top, width, height]` 是该图层在其自身框架内的内容区域；它会落在画布上该框位置加上该偏移量的位置。 | BOUNDING_BOX |
| `layer_stack` | 可用于 Create Layered Image 的直接编辑图层文档：包含基底图层，以及每个元素作为独立的、已命名的、紧密裁剪的图层，位于其真实位置和堆叠顺序。可直接连接，或使用 Add Layer 扩展。 | LAYERS |
