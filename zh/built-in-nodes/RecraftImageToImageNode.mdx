此节点根据文本提示和强度设置修改现有图像。它将图像发送到 Recraft V3 API，并返回一张遵循提示的新图像，同时根据强度值与原始图像保持或多或少的相似性。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要修改的输入图像。当提供一批图像时，每张图像都会单独处理。 | IMAGE | 是 | - |
| `提示词` | 用于图像生成的提示。默认：空字符串。最大长度：1000 个字符。 | STRING | 是 | - |
| `数量` | 要生成的图像数量。默认：1。 | INT | 是 | 1-6 |
| `强度` | 定义与原始图像的差异，应位于 [0, 1] 范围内，其中 0 表示几乎相同，1 表示相似度极低。默认：0.5。 | FLOAT | 是 | 0.0-1.0 （步长：0.01） |
| `种子` | 用于确定节点是否应重新运行的种子；无论种子如何，实际结果都是非确定性的。默认：0。 | INT | 是 | 0-18446744073709551615 |
| `Recraft风格` | 图像生成的可选风格选择。如果未提供，默认为 `realistic_image`。 | STYLEV3 | 否 | - |
| `反向提示词` | 图像上不希望出现的元素的可选文本描述。默认：空字符串。作为输入套接字提供。 | STRING | 否 | - |
| `Recraft控制` | 通过 Recraft Controls 节点对生成过程的可选额外控制。 | CONTROLS | 否 | - |

**注意：** `seed` 参数仅触发节点的重新执行，但不保证结果确定性。`strength` 参数在内部四舍五入到小数点后 2 位。`prompt` 会被验证，且不得超过 1000 个字符。空的 `negative_prompt` 视为没有负面提示。如果未提供 `recraft_style`，节点默认为 `realistic_image` 风格。如果使用来自 Infinite Style Library 的 `style_id`，请确保它不是 Vector art 风格，因为这可能导致节点收到 SVG 数据而不是图像，从而引发错误。当输入 `image` 是批次时，批次中的每张图像都会单独处理，所有结果会一起返回。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 基于输入图像、提示和强度生成的图像。 | IMAGE |
