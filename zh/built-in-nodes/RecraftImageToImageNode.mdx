此节点根据文本提示词和强度参数修改现有图像。它使用 Recraft V3 API 根据提供的描述对输入图像进行变换，同时通过强度设置保持与原图像的一定相似度。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要修改的输入图像 | IMAGE | 是 | - |
| `提示词` | 图像生成的提示词（默认：空字符串，最大长度：1000 个字符） | STRING | 是 | - |
| `数量` | 要生成的图像数量（默认：1） | INT | 是 | 1-6 |
| `强度` | 定义与原图像的差异程度，取值范围为 [0, 1]，其中 0 表示几乎相同，1 表示相似度极低（默认：0.5） | FLOAT | 是 | 0.0-1.0 |
| `种子` | 用于决定节点是否重新运行的种子；无论种子为何，实际结果都是不确定的（默认：0） | INT | 是 | 0-18446744073709551615 |
| `Recraft风格` | 图像生成的可选风格设置。若未提供，默认为 `realistic_image` | STYLEV3 | 否 | - |
| `反向提示词` | 图像中不想要元素的可选文本描述（默认：空字符串） | STRING | 否 | - |
| `Recraft控制` | 通过 Recraft Controls 节点对生成过程进行的可选额外控制 | CONTROLS | 否 | - |

**注意：** `seed` 参数仅触发节点重新执行，但不保证确定性结果。`strength` 参数在内部四舍五入到小数点后两位。`prompt` 会经过验证，且不得超过 1000 个字符。空的 `negative_prompt` 被视为没有负向提示词。若未提供 `recraft_style`，节点默认使用 `realistic_image` 风格。如果使用来自 Infinite Style Library 的 `style_id`，请确保其不是 Vector 艺术风格，否则可能导致节点收到 SVG 数据而非图像，从而引发错误。当输入 `image` 是批处理时，批次中的每个图像都会单独处理，并一并返回所有结果。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 根据输入图像和提示词生成的图像 | IMAGE |
