此节点可将多个图像图层合并为单个合成图像。它接收使用 Add Layer 节点构建的图层栈，并可选地应用合成器编辑器中保存的合成设置，根据各图层的位置、大小、旋转、不透明度和混合模式进行混合。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `layers` | 需要合成的图层栈；使用 Add Layer 节点构建。图层项按 z_index 堆叠，图层项内的批处理帧会展开为连续图层，图层项的位置、不透明度和混合模式决定初始合成效果。若未指定显式文档画布，则图层栈尺寸为已放置图层最大范围的尽力计算值。与当前输入匹配的已保存合成会优先。 | LAYERS | 是 | 最多 50 层 |
| `compositor` | 由合成器编辑器保存的分层合成。 | COMPOSITOR | 否 | 无 |

**约束说明：**

- 图层栈最多支持 50 层（展开后的帧）；超出限制会引发错误。
- 当前仅支持栅格图层；其他图层项类型会引发错误。
- `layers` 文档版本必须为 1；其他版本会引发错误。
- 已保存的 `compositor` 状态仅在其记录的上游输入指纹与当前图层栈匹配时才会被回放。若不匹配，节点将回退为按图层属性进行合成，并将该保存状态标记为过期。
- 图层不透明度将被限制在 0.0 到 1.0 的范围内。
- 图层水平/垂直位置（`x`、`y`）会被限制在最大分辨率限制内。
- 图层宽度和高度在设置为 0 或小于 0 时，回退为图像自然尺寸，并限制在最大分辨率上限之内。
- 合成画布尺寸不得超过最大分辨率限制。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| IMAGE | 合成后的图像。当合成结果包含透明区域（例如隐藏背景）时带有 Alpha 通道；否则为普通 RGB。 | IMAGE |
| MASK | 合成的透明度（1 = 完全透明）。当合成结果不透明时全为 0。 | MASK |
