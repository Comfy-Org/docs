此节点将多个图像图层合并为单个合成图像。它接收由 “Add Layer” 节点构建的图层堆栈，并可选择接收来自合成器编辑器的已保存合成，然后使用图层的放置、大小、旋转、不透明度和混合模式设置将图层混合在一起。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `layers` | 要合成的图层堆栈；使用 Add Layer 构建。项目按 z_index 堆叠，项目内的批量帧展开为连续图层，项目放置、不透明度和混合模式定义初始合成。如果没有显式的文档画布，尺寸是已放置图层最大范围的尽力估算。与当前输入匹配的已保存合成具有优先权。 | LAYERS | 是 | Maximum 50 layers |
| `compositor` | 由合成器编辑器保存的分层合成。 | COMPOSITOR | 否 | None |

**约束说明：**

- 图层堆栈最多支持 50 个图层（展开帧）；提供更多图层会引发错误。
- 当前仅支持栅格图层；其他图层项目类型会引发错误。
- `layers` 文档版本必须为 1；其他版本会引发错误。
- 仅当保存的 `compositor` 状态所记录的输入指纹与当前图层堆栈匹配时，才会重放该状态。如果不匹配，节点将回退到根据图层属性进行合成，并将保存的状态标记为过期。
- 图层不透明度被限制在 0.0 到 1.0 范围内。
- 图层水平/垂直放置（`x`、`y`）被限制在最大分辨率限制内。
- 图层宽度和高度在设置为零或更小值时回退到自然图像尺寸，并受最大分辨率限制约束。
- 合成画布尺寸不得超过最大分辨率限制。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `IMAGE` | 合成图像。当合成具有透明区域（例如隐藏背景）时带有 alpha 通道，否则为纯 RGB。 | IMAGE |
| `MASK` | 合成的透明度（1 = 完全透明）。当合成不透明时全为零。 | MASK |
