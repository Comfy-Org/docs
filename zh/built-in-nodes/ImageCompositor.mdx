此节点将多个图像图层合并为单个合成图像。它接收使用 Add Layer 节点构建的图层堆栈，并可选择应用合成器编辑器中保存的合成设置，根据图层的放置、大小、旋转、不透明度和混合模式来混合图层。与当前输入匹配的已保存合成将优先使用；否则，节点将根据图层属性进行合成，并将已保存状态标记为过期。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `layers` | 要合成的图层堆栈；使用 Add Layer 构建。项按 `z_index` 堆叠，项内的批量帧会展开为连续的图层，项的放置、不透明度和混合模式定义初始合成。如果没有显式的文档画布，大小将是已放置图层的最大范围（尽力而为）。与当前输入匹配的已保存合成将优先使用。 | LAYERS | 是 | 最多 50 层 |
| `compositor` | 由合成器编辑器保存的分层合成。 | COMPOSITOR | 否 | None |

**约束说明：**

- 图层堆栈最多支持 50 个展开图层；提供更多会引发错误。
- 目前仅支持光栅图层项；其他项类型会引发错误。
- `layers` 文档版本必须为 1；其他版本会引发错误。
- 仅当记录的输入指纹与当前图层堆栈匹配时，才会重放已保存的 `compositor` 状态。如果它们不匹配，节点将回退到根据图层属性进行合成，并将已保存状态标记为过期。
- 图层不透明度被限制在 0.0 到 1.0 的范围内。
- 图层的水平和垂直放置（`x`、`y`）被限制在最大分辨率限制内。
- 当图层宽度和高度设置为零或更小时，会回退到自然图像大小，并受最大分辨率限制。
- 合成画布大小不得超过最大分辨率限制。
- 当未提供图层时，返回 64x64 占位图像。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `IMAGE` | 合成图像。当合成具有透明区域（例如隐藏背景）时携带 Alpha 通道，否则为纯 RGB。 | IMAGE |
| `MASK` | 合成的透明度（1 = 完全透明）。当合成不透明时全为零。 | MASK |
