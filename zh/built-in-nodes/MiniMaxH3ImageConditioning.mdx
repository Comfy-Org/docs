使用 MiniMax H3 Image 将提示词转换为条件数据，并生成用于静态图像的空 latent。未连接图像时，它执行文生图；连接图像后，它会编辑这些图像，提示词通过 `<Picture 1>`、`<Picture 2>` 等来引用它们。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | MiniMax H3 Image CLIP 模型，它会将提示词与任意参考图像一起分词，并对条件进行编码。 | CLIP | 是 | - |
| `vae` | MiniMax H3 Image VAE。使用它时，图片还会作为参考 latent 进行锚定；不使用它时，图片仅对文本编码器进行条件化。 | VAE | 否 | - |
| `prompt` | 要生成的内容，或如何编辑参考图片。 | STRING | 是 | 多行文本 |
| `width` | 输出宽度（像素）。0 表示使用 `image_1` 经过参考缩放后的宽度；没有图像时使用 2048。默认值：0。 | INT | 是 | 0 到 MAX_RESOLUTION（步长：32） |
| `height` | 输出高度（像素）。0 表示使用 `image_1` 经过参考缩放后的高度；没有图像时使用 2048。默认值：0。 | INT | 是 | 0 到 MAX_RESOLUTION（步长：32） |
| `images` | 可扩展的参考图片组，从 `image_1` 开始向上编号；`image_1` 是要编辑的图片。提示词通过 `<Picture n>` 来引用它们。 | AUTOGROW | 否 | 0 到 100 张图像 |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 用于 MiniMax H3 Image 采样器的条件数据，连接图像时会附加参考 latent。 | CONDITIONING |
| `latent` | 单张图像的空 latent，24 通道，尺寸为输出尺寸的十六分之一。 | LATENT |

注意：该模型针对 2048x2048 像素面积进行了调优，因此除非需要不同画布，否则请将 `width` 和 `height` 保持为 0。
