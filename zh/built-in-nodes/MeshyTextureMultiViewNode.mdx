此节点使用同一对象的 1 到 4 张参考视图为先前创建的 3D 模型添加纹理。您提供原始模型的任务 ID 和参考图像；节点会将其发送到 Meshy 服务，等待任务完成，然后以 GLB 和 FBX 文件的形式返回带纹理的模型。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于纹理生成任务的 AI 模型。目前仅提供 "meshy-7"。 | COMBO | 是 | `"meshy-7"` |
| `Meshy 任务 ID` | 要添加纹理的先前创建的 3D 模型的任务 ID。 | MESHY_TASK_ID | 是 | — |
| `多视图图像` | 同一对象的参考视图。第一张图像是主要（正面）视图；其余视图的顺序无关紧要。可增长插槽：连接 1 到 4 张图像（`image_1` 至 `image_4`）。 | IMAGE | 是 | 1 到 4 张图像 |
| `启用原始 UV` | 使用模型的原始 UV，而不是生成新的 UV。启用后，Meshy 会保留上传模型中的现有纹理。如果模型没有原始 UV，输出质量可能不佳。（默认值：True） | BOOLEAN | 否 | True / False |
| `PBR` | 启用 PBR（基于物理的渲染）纹理生成。（默认值：False） | BOOLEAN | 否 | True / False |
| `纹理分辨率` | 基础颜色纹理分辨率。更高的分辨率可以捕捉更多表面细节。 | COMBO | 是 | `"2k"`<br />`"4k"`<br />`"8k"` |

**注意：** `multiview_images` 必须包含 1 到 4 张图像。节点会在运行时进行验证，如果数量超出此范围则引发错误。如果连接的图像包含多个图像的批次，则批次中的每张图像都计入上限。第一张图像用作主要（正面）视图；其余图像的顺序无关紧要。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `模型文件` | 模型文件名。此输出仅为向后兼容而保留。 | STRING |
| `Meshy 任务 ID` | 纹理生成任务的任务 ID。 | MESHY_TASK_ID |
| `GLB` | 以 GLB 格式下载的带纹理的 3D 模型。 | GLB |
| `FBX` | 以 FBX 格式下载的带纹理的 3D 模型。 | FBX |
