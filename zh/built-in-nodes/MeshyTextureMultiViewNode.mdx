此节点使用同一物体的 1 至 4 个参考视图，为先前创建的 3D 模型生成纹理。你需要提供原始模型的任务 ID 和参考图像；节点会将它们发送至 Meshy 服务，等待任务完成，并以 GLB 和 FBX 文件的形式返回带纹理的模型。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于纹理生成任务的 AI 模型。目前仅提供 `"meshy-7"`。 | COMBO | 是 | `"meshy-7"` |
| `Meshy 任务 ID` | 要进行纹理处理的先前创建的 3D 模型的任务 ID。 | MESHY_TASK_ID | 是 | — |
| `多视图图像` | 同一物体的参考视图。第一张图像是主视图（正面视图）；其余视图的顺序无关紧要。可扩展插槽：连接 1 至 4 张图像（`image_1` 至 `image_4`）。 | IMAGE | 是 | 1 至 4 张图像 |
| `启用原始 UV` | 使用模型的原始 UV，而不是生成新的 UV。启用后，Meshy 会保留上传模型中已有的纹理。如果模型没有原始 UV，输出质量可能不够理想。（默认值：True；高级选项） | BOOLEAN | 否 | True / False |
| `PBR` | 启用 PBR（基于物理的渲染）纹理生成。（默认值：False；高级选项） | BOOLEAN | 否 | True / False |
| `纹理分辨率` | 基础颜色纹理分辨率。更高的分辨率可以捕捉更多表面细节。 | COMBO | 是 | `"2k"`<br />`"4k"`<br />`"8k"` |

**注意：** `multiview_images` 必须包含 1 至 4 张图像。节点会在运行时对此进行验证，如果数量超出此范围则会报错。如果连接的图像包含一批多张图像，批次中的每张图像都会计入限制。第一张图像用作主视图（正面视图）；其余图像的顺序无关紧要。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `model_file` | 模型文件名。此输出仅为向后兼容而保留。 | STRING |
| `meshy_task_id` | 纹理生成任务的任务 ID。 | MESHY_TASK_ID |
| `GLB` | 以 GLB 格式下载的带纹理 3D 模型。 | FILE3DGLB |
| `FBX` | 以 FBX 格式下载的带纹理 3D 模型。 | FILE3DFBX |
