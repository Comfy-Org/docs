构建 FLUX 3 Image 从提示词中读取的布局表，把在 Create Bounding Boxes 节点中绘制的元素作为框列表追加到提示词中，每个框都包含一个 id、坐标和描述。在提示词中以 `<obj_N>` 引用某个框，即可将文字与该区域关联起来，然后将输出连接到 FLUX 3 Image 节点的 `prompt` 输入。未连接任何元素时，提示词将原样返回。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `prompt` | 提示词文本。以 `<obj_N>` 引用第 N 个框，将文字与其关联。 | STRING | 是 | - |
| `element` | 要放置在布局中的元素，取自 Create Bounding Boxes 节点。不使用颜色调色板，因此请改为在描述中说明颜色。 | ARRAY | 是 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `prompt` | 附加了框布局表的提示词，可直接输入到 FLUX 3 Image 节点。 | STRING |
