# 图像 YUV 到 RGB 转换

ImageYUVToRGB 节点旨在将图像从 YUV 颜色空间转换为 RGB 颜色空间。它通过接收三个分别代表图像的 Y（亮度）、U（蓝色分量）和 V（红色分量）通道的输入图像来实现。然后，使用颜色空间转换技术将这些通道组合成一个单一的 RGB 图像。

## 概述

ImageYUVToRGB 节点通过合并 Y、U 和 V 通道将 YUV 图像转换为 RGB 图像。这对于需要在 YUV 和 RGB 两种标准之间进行颜色空间转换的应用程序非常有用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `Y`       | Y 通道输入图像，表示亮度信息。 | IMAGE | 是 | - |
| `U`       | U 通道输入图像，表示蓝色色差。 | IMAGE | 是 | - |
| `V`       | V 通道输入图像，表示红色色差。 | IMAGE | 是 | - |

**注意：** Y、U 和 V 通道必须一起提供，并且应该具有相同的尺寸，以确保正确的转换。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output`    | YUV 到 RGB 转换后的结果 RGB 图像。 | IMAGE |

输出图像将具有与输入 Y、U 和 V 图像相同的尺寸，但使用 RGB 颜色空间表示颜色信息。
