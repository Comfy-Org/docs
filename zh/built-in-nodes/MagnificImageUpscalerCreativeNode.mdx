此节点使用 Magnific AI 服务对图像进行放大和创意增强。它允许你通过文本提示词引导增强过程，选择要优化的特定风格，并控制创意过程的各个方面，例如细节、与原图的相似度以及风格化强度。该节点会按照你选择的倍数（2x、4x、8x 或 16x）输出放大后的图像，最大输出尺寸为 2530 万像素。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要放大和增强的输入图像。 | IMAGE | 是 | - |
| `提示词` | 用于引导图像创意增强的文本描述。默认为空字符串（此时不会发送提示词）。 | STRING | 是 | - |
| `放大倍数` | 图像尺寸的放大倍数。 | COMBO | 是 | `"2x"`<br />`"4x"`<br />`"8x"`<br />`"16x"` |
| `优化目标` | 优化增强过程所针对的风格或内容类型。 | COMBO | 是 | `"standard"`<br />`"soft_portraits"`<br />`"hard_portraits"`<br />`"art_n_illustration"`<br />`"videogame_assets"`<br />`"nature_n_landscapes"`<br />`"films_n_photography"`<br />`"3d_renders"`<br />`"science_fiction_n_horror"` |
| `创意` | 控制应用于图像的创意诠释程度（默认值：0）。 | INT | 是 | -10 到 10 |
| `HDR` | 清晰度和细节水平（默认值：0）。 | INT | 是 | -10 到 10 |
| `相似度` | 与原始图像的相似度水平（默认值：0）。 | INT | 是 | -10 到 10 |
| `复杂度` | 提示词的强度以及每平方像素的复杂程度（默认值：0）。 | INT | 是 | -10 到 10 |
| `引擎` | 用于处理的特定 AI 引擎。这是一个高级参数。 | COMBO | 是 | `"automatic"`<br />`"magnific_illusio"`<br />`"magnific_sharpy"`<br />`"magnific_sparkle"` |
| `自动降采样` | 如果输出会超过最大像素限制，则自动缩小输入图像（默认值：False）。这是一个高级参数。 | BOOLEAN | 是 | - |

**约束条件：**

* 输入 `image` 必须恰好为一张图像。
* 输入图像的高度和宽度最小必须是 160 像素。
* 输入图像的宽高比必须在 1:3 到 3:1 之间。
* 最终输出尺寸（输入尺寸乘以 `scale_factor`）不能超过 25,300,000 像素。如果超过此限制：
  - 当启用 `auto_downscale` 时，节点会自动减小输入图像尺寸（额外的缩小最多为 2x）或使用较低的 `scale_factor`，以使输出保持在限制范围内。
  - 当禁用 `auto_downscale` 时，节点会报错。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 经过创意增强和放大的输出图像。 | IMAGE |
