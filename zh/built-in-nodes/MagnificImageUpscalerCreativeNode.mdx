此节点使用 Magnific AI 服务来放大并对图像进行创意增强。它允许您通过文本提示引导增强过程，选择特定的优化风格，并控制创意过程的各个方面，如细节、与原始图像的相似度以及风格化强度。该节点会按您选择的倍率（2x、4x、8x 或 16x）输出放大后的图像，最大输出尺寸为 25.3 百万像素。

## 输入
| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要放大和增强的输入图像。 | IMAGE | 是 | - |
| `提示词` | 用于引导图像创意增强的文本描述。此参数可选（默认：空）。 | STRING | 否 | - |
| `放大倍数` | 放大图像尺寸的倍率。 | COMBO | 是 | `"2x"`<br />`"4x"`<br />`"8x"`<br />`"16x"` |
| `优化目标` | 用于优化增强过程的风格或内容类型。 | COMBO | 是 | `"standard"`<br />`"soft_portraits"`<br />`"hard_portraits"`<br />`"art_n_illustration"`<br />`"videogame_assets"`<br />`"nature_n_landscapes"`<br />`"films_n_photography"`<br />`"3d_renders"`<br />`"science_fiction_n_horror"` |
| `创意` | 控制应用于图像的创意解读程度（默认：0）。 | INT | 否 | -10 到 10 |
| `HDR` | 清晰度和细节的级别（默认：0）。 | INT | 否 | -10 到 10 |
| `相似度` | 与原始图像的相似程度（默认：0）。 | INT | 否 | -10 到 10 |
| `复杂度` | 提示的强度以及每平方像素的精细度（默认：0）。 | INT | 否 | -10 到 10 |
| `引擎` | 用于处理的具体 AI 引擎。这是一个高级参数。 | COMBO | 是 | `"automatic"`<br />`"magnific_illusio"`<br />`"magnific_sharpy"`<br />`"magnific_sparkle"` |
| `自动降采样` | 如果输出将超过最大像素限制，则自动缩小输入图像（默认：False）。这是一个高级参数。 | BOOLEAN | 否 | - |

**约束：**

* 输入 `image` 必须恰好是一张图像。
* 输入图像的最小高度和宽度必须为 160 像素。
* 输入图像的宽高比必须在 1:3 到 3:1 之间。
* 最终输出尺寸（输入尺寸乘以 `scale_factor`）不能超过 25,300,000 像素。如果超出此限制：
  - 当启用 `auto_downscale` 时，节点会自动缩小输入图像尺寸（不超过 2 倍）或使用较低的 `scale_factor`，使输出保持在该限制内。
  - 当禁用 `auto_downscale` 时，节点会引发错误。
