将 SVG 文件保存到磁盘。此节点将 SVG 数据作为输入，并将其写入 ComfyUI 输出目录，自动使用计数器后缀处理文件命名。当工作流提示信息可用时，它会直接作为元数据元素嵌入到 SVG 文件中。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `svg` | 要保存到磁盘的 SVG 数据 | SVG | 是 | - |
| `文件名前缀` | 要保存的文件前缀。其中可包含格式化信息，例如 %date:yyyy-MM-dd% 或 %Empty Latent Image.width%，以包含来自节点的值。（默认值："svg/ComfyUI"） | STRING | 是 | - |

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `svg` | 保存后传递的原始 SVG 数据 | SVG |
| `ui` | 保存的文件信息，包括文件名、子文件夹和类型，用于在 ComfyUI 界面中显示 | DICT |

**注意：** 当可用时，此节点会自动将工作流元数据（提示和额外的 PNG 信息）嵌入 SVG 文件。元数据作为 CDATA 区段插入到 SVG 的 metadata 元素中。文件使用模式 `filename_prefix_00001_.svg` 保存；处理批次时，前缀中的 `%batch_num%` 会替换为当前批次项的索引。该节点是输出节点，因此即使文件本身不显示为图像预览，它也会在输出文件夹中生成保存结果。
