FreeU 节点会对模型的输出块应用频域修改，以提升图像生成质量。它通过缩放不同的通道组，并对特定特征图应用傅里叶滤波来工作，从而可以在生成过程中对模型行为进行精细控制。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要应用 FreeU 修改的模型 | MODEL | 是 | - |
| `b1` | 应用于通道数为 model_channels × 4 的特征图的主干缩放因子（默认值：1.1）。标记为高级设置。 | FLOAT | 是 | 0.0 - 10.0 |
| `b2` | 应用于通道数为 model_channels × 2 的特征图的主干缩放因子（默认值：1.2）。标记为高级设置。 | FLOAT | 是 | 0.0 - 10.0 |
| `s1` | 应用于通道数为 model_channels × 4 的特征图的跳跃连接缩放因子（默认值：0.9）。标记为高级设置。 | FLOAT | 是 | 0.0 - 10.0 |
| `s2` | 应用于通道数为 model_channels × 2 的特征图的跳跃连接缩放因子（默认值：0.2）。标记为高级设置。 | FLOAT | 是 | 0.0 - 10.0 |

注意：FreeU 调整仅应用于通道数等于 model_channels × 4（使用 `b1` 和 `s1`）或 model_channels × 2（使用 `b2` 和 `s2`）的特征图。傅里叶滤波器仅缩放跳跃连接特征图的中心低频区域（阈值为 1）；所有其他频率分量保持不变。所有四个缩放参数均接受 0.0 到 10.0 之间的值，步长为 0.01。

## 输出

| --- | --- | --- |
| `model` | 已应用 FreeU 补丁的修改后模型 | MODEL |
