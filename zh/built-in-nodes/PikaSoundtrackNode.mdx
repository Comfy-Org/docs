此节点使用 Pika 为视频生成同步配乐。画面和时长保持不变，仅替换音频。描述您想要的声音，或将 `instruction` 留空以根据画面推导。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `video` | 要为其制作配乐的片段。最长 10 分钟。 | VIDEO | 是 | - |
| `instruction` | 音频内容：音效、环境声、音乐或风格。留空则根据画面推导。默认：""（空字符串）。 | STRING | 是 | 0 到 10000 个字符 |
| `seed` | 用于采样的种子。默认：42。 | INT | 是 | 0 到 2147483647 |

**限制：**

* 输入视频必须不超过 10 分钟。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `VIDEO` | 用生成的配乐替换原始音频后的输入片段。 | VIDEO |
