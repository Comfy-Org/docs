Ideogram & Pruna P-Image 使用 Ideogram 的快速文本到图像模型，根据文本提示词生成图像。该模型以强大的排版和照片级真实感著称。它还支持 Ideogram 4.0 结构化 JSON 提示词，可精确控制文本字符串、颜色和布局。该节点返回生成的图像，以及实际用于生成图像的最终提示词。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 文本提示词。也接受 Ideogram 4.0 结构化 JSON 提示词（精确颜色以 #RRGGBB 十六进制值表示、精确文本字符串、边界框布局）——将 `prompt_upsampling` 设为 OFF 即可原样使用。不能为空。（默认：""） | STRING | 是 | 任意非空文本 |
| `quality` | 速度/价格/质量档位。MEDIUM 是日常默认值；HIGH 适用于复杂提示词、精细细节和困难文本；VERY_LOW/LOW 适用于大规模草稿。低于 MEDIUM 时，困难文本的渲染效果不佳。（默认："MEDIUM"） | COMBO | 是 | "VERY_LOW"<br />"LOW"<br />"MEDIUM"<br />"HIGH" |
| `resolution` | 输出尺寸等级（确切像素数随宽高比变化，例如 16:9 在 1K 下为 1280x720，在 2K 下为 2560x1440）。若要获得清晰的排版，建议优先选择 HIGH + 2K。（默认："1K"） | COMBO | 是 | "1K"<br />"2K" |
| `aspect_ratio` | 图像生成的宽高比。（默认："1:1"） | COMBO | 是 | "1:3"<br />"3:1"<br />"1:2"<br />"2:1"<br />"9:16"<br />"16:9"<br />"10:16"<br />"16:10"<br />"2:3"<br />"3:2"<br />"3:4"<br />"4:3"<br />"4:5"<br />"5:4"<br />"1:1" |
| `prompt_upsampling` | 在生成之前将短提示词扩展为详细的结构化提示词（重写后的提示词会作为 `final_prompt` 返回）。当提供自己的 JSON 提示词或精确措辞时，请设为 OFF。（默认："AUTO"） | COMBO | 是 | "AUTO"<br />"ON"<br />"OFF" |
| `seed` | 用于可重现生成的种子。当 `prompt_upsampling` 为 OFF 时，相同的种子和设置会返回相同的图像；为 ON/AUTO 时，提示词重写会因运行而异——要重现结果，请将 `final_prompt` 输出与 `prompt_upsampling` OFF 及相同种子一起重新使用。（默认：42） | INT | 否 | 0 到 2147483647 |

**约束说明：** 提示词必须至少包含一个非空白字符，否则节点将失败。当提供自己的结构化 JSON 提示词或精确措辞时，请将 `prompt_upsampling` 设为 OFF。当 `prompt_upsampling` 为 ON 或 AUTO 时，提示词会在生成前被重写，因此相同种子可能无法重现相同图像；若要重现图像，请将其 `final_prompt` 输出与 `prompt_upsampling` OFF 及相同种子一起重新使用。

## 输出
| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 生成的图像，以图像批次形式返回。如果 Ideogram 的内容安全过滤器拦截了生成，则会改为引发错误。 | IMAGE |
| `final_prompt` | 实际用于生成图像的提示词（当 `prompt_upsampling` 运行时，为重写的结构化提示词；否则为您的原始提示词）。将其与 `prompt_upsampling` OFF 及相同种子一起重新输入，即可重现此图像。 | STRING |
