CLIP Text Encode (Kandinsky 5) 节点为 Kandinsky 5 模型准备文本提示词。它接收两个独立的文本输入，使用提供的 CLIP 模型对其进行分词，并将它们组合成单个 conditioning 输出，用于指导图像生成过程。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 用于对文本提示词进行分词和编码的 CLIP 模型。 | CLIP | 是 |  |
| `clip_l` | 主文本提示词。此输入支持多行文本和动态提示词。 | STRING | 是 |  |
| `qwen25_7b` | 次要文本提示词。此输入支持多行文本和动态提示词。 | STRING | 是 |  |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `CONDITIONING` | 由两个文本提示词组合生成的 conditioning 数据，可直接输入 Kandinsky 5 模型以进行图像生成。 | CONDITIONING |
