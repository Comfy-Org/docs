此节点将音频数据保存为 FLAC 格式的文件。它接受音频输入，并使用指定的文件名前缀将其写入输出目录。此节点已弃用，应替换为当前的 Save Audio 节点。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `音频` | 要保存的音频数据 | AUDIO | 是 | - |
| `文件名前缀` | 输出文件名的前缀（默认值："audio/ComfyUI"） | STRING | 否 | - |

*注意：`prompt` 和 `extra_pnginfo` 参数是隐藏的，由系统自动处理。*

如果 `audio` 输入未收到数据（例如，当源视频没有音轨时），节点会引发错误，并且不会保存任何文件。

## 输出

| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `audio` | 提供给输入的音频数据，在文件保存后原样传递 | AUDIO |
