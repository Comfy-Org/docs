TextEncodeZImageOmni 将文本提示词与最多三张可选参考图像一起编码为图像生成模型的条件格式。提示词会使用 CLIP 模型进行分词和编码，每张连接的图像可以选择性地由视觉编码器和/或 VAE 处理，从而将视觉参考与文本一起嵌入。此节点标记为实验性。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `clip` | 用于对文本提示词进行分词和编码的 CLIP 模型。 | CLIP | 是 |  |
| `image_encoder` | 可选的视觉编码器模型。如果提供，则用于编码输入图像，并将生成的嵌入添加到条件化数据中。 | CLIP_VISION | 否 |  |
| `prompt` | 要编码的文本提示词。支持多行输入和动态提示词。 | STRING | 是 |  |
| `auto_resize_images` | 启用时（默认：True），输入图像会在 VAE 编码前自动调整大小，使其总像素面积接近 1024x1024，且尺寸会舍入为 8 的倍数。 | BOOLEAN | 是 | True<br />False |
| `vae` | 可选的 VAE 模型。如果提供，则用于将输入图像编码为潜空间表示，这些表示会作为参考 latent 添加到条件化数据中。 | VAE | 否 |  |
| `image1` | 第一张可选参考图像。 | IMAGE | 否 |  |
| `image2` | 第二张可选参考图像。 | IMAGE | 否 |  |
| `image3` | 第三张可选参考图像。 | IMAGE | 否 |  |

**注意：** 节点最多接受三张图像（`image1`、`image2`、`image3`）。仅当至少提供一张图像时，才会使用 `image_encoder` 和 `vae` 输入；当两者都连接时，每张图像都会由两者处理。当 `auto_resize_images` 为 True 且连接了 `vae` 时，图像会在编码前调整为总像素面积接近 1024x1024。如果未提供图像，则仅编码文本提示词。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `CONDITIONING` | 最终的条件化输出。它包含编码后的文本提示词；当提供图像时，还可能包含编码后的图像嵌入、参考 latent，以及从图像占位符模板衍生的额外文本嵌入。 | CONDITIONING |
