此节点使用字节跳动 Seedance 模型，从必需的首帧图像和可选的末帧图像生成视频。您可以通过文本提示描述视频；首帧引导视频的开头，末帧引导视频的结尾。它支持 Seedance 2.5 以及 Seedance 2.0 系列（Seedance 2.0、Seedance 2.0 Fast 和 Seedance 2.0 Mini）。

**参数约束**

- 您必须提供首帧，可以是 `first_frame` 图像，也可以是 `first_frame_asset_id`。同时提供两者会引发错误；两者都不提供也会引发错误。
- `last_frame` 和 `last_frame_asset_id` 输入是可选的，但不能为同一帧同时提供两者。
- Asset ID 必须引用现有且处于活动状态的 Seedance Image 资源。
- `prompt` 输入为必填项，且不能为空。
- 使用 `Seedance 2.5` 时，输出宽高比始终为自适应，并遵循首帧自身的宽高比，因此不显示 `ratio` 输入。
- 使用 Seedance 2.0 系列模型和本地帧图像时，图像会在生成前进行中心裁剪并调整大小为目标输出分辨率和宽高比。当 `ratio` 为 `adaptive` 时，使用与输入图像最接近的受支持比例。
- 本地帧图像会经过受支持宽高比和尺寸的验证；过大的图像会被缩小。
