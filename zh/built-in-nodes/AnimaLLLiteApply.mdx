AnimaLLLiteApply 将轻量级动画补丁应用于扩散模型，支持通过可调节的强度和时序进行受控的图像到图像生成。它将预配置的模型补丁与输入图像及可选遮罩集成，通过修改模型的注意力层和 MLP 层来影响生成过程。

## 输入
| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 要应用补丁的基础扩散模型 | MODEL | 是 | |
| `模型补丁` | 要应用的预配置动画补丁 | MODEL_PATCH | 是 | |
| `图像` | 用于引导生成的参考图像。仅使用前 3 个颜色通道（RGB） | IMAGE | 是 | |
| `强度` | 补丁效果的强度（默认值：1.0） | FLOAT | 是 | -10.0 到 10.0 |
| `起始百分比` | 补丁开始生效时的去噪过程百分比（默认值：0.0） | FLOAT | 是 | 0.0 到 1.0 |
| `结束百分比` | 补丁停止生效时的去噪过程百分比（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0 |
| `掩码` | 可选的遮罩，用于将补丁效果限制在图像的特定区域 | MASK | 否 | |

**关于参数约束的说明：** 如果 `model_patch` 具有 4 个输入通道且未提供 `mask`，则会自动创建一个与图像尺寸匹配的零遮罩。如果 `model_patch` 不具有 4 个输入通道，则 `mask` 参数将被忽略并设置为 `None`。此节点在 ComfyUI 中标记为实验性。

## 输出
| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `MODEL` | 已应用动画补丁的扩散模型 | MODEL |
