Qwen Image 3 Text to Image 节点使用 Qwen-Image 3.0 模型，根据文本提示生成一张或多张图像。您选择模型并提供提示词，节点将生成的图像作为批次返回。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的模型（默认值："qwen-image-3.0-pro"）。此复合选择器还提供提示词、图像宽度、图像高度以及可选的负面提示词。 | DYNAMIC_COMBO | 是 | "qwen-image-3.0-pro"<br />"qwen-image-3.0" |
| `n` | 要生成的图像数量，以批次形式返回（默认值：1）。 | INT | 否 | 1 到 6 |
| `seed` | 用于生成的种子值（默认值：42）。可设置为每次生成后自动更新。 | INT | 否 | 0 到 2147483647 |
| `prompt_extend` | 是否使用 AI 辅助增强提示词（默认值：true）。高级选项。 | BOOLEAN | 否 | true<br />false |
| `watermark` | 是否在结果中添加 AI 生成水印（默认值：false）。高级选项。 | BOOLEAN | 否 | true<br />false |

### qwen-image-3.0-pro 和 qwen-image-3.0 输入

由 qwen-image-3.0-pro 和 qwen-image-3.0 共享。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述图像的提示词。支持英文和中文。必须包含至少 1 个字符。 | STRING | 是 | 自由文本 |
| `negative_prompt` | 描述要避免的内容的负面提示词（默认值：""）。 | STRING | 否 | 自由文本 |
| `width` | 总像素面积必须在 512x512 到 2560x2560 之间；宽高比必须在 1:8 到 8:1 之间。（默认值：1024） | INT | 否 | 256 到 2560（步长 16） |
| `height` | 总像素面积必须在 512x512 到 2560x2560 之间；宽高比必须在 1:8 到 8:1 之间。（默认值：1024） | INT | 否 | 256 到 2560（步长 16） |

注意：`model` 输入是一个复合选择器，包含子字段 `model`（模型 ID）、`prompt`（必填，必须包含至少 1 个字符）、`width` 和 `height`（图像尺寸）以及 `negative_prompt`（可选）。`width` 和 `height` 的合并像素面积必须在 262,144 像素（512x512）到 6,553,600 像素（2560x2560）之间，且宽高比必须保持在 1:8 到 8:1 之间。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 生成的图像或图像批次。 | IMAGE |
