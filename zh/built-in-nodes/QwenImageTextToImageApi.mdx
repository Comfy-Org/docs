Qwen Image 3 Text to Image 节点使用 Qwen-Image 3.0 模型，根据文本提示生成一个或多个图像。您选择模型并提供提示，节点将生成的图像作为批次返回。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 要使用的模型（默认值："qwen-image-3.0-pro"）。此复合选择器还提供提示词、图像宽度、图像高度和可选的负面提示词。 | MODEL | 是 | "qwen-image-3.0-pro"<br />"qwen-image-3.0" |
| `n` | 要生成的图像数量，作为批次返回（默认值：1）。 | INT | 否 | 1 到 6 |
| `seed` | 用于生成的种子（默认值：42）。可设置为在每次生成后自动更新。 | INT | 否 | 0 到 2147483647 |
| `prompt_extend` | 是否使用 AI 辅助增强提示词（默认值：true）。高级选项。 | BOOLEAN | 否 | true<br />false |
| `watermark` | 是否在结果中添加 AI 生成的水印（默认值：false）。高级选项。 | BOOLEAN | 否 | true<br />false |

注意：`model` 输入是一个复合选择器，包含以下子字段：`model`（模型 ID）、`prompt`（文本提示词，必须至少包含 1 个字符）、`width` 和 `height`（图像尺寸，由节点验证）以及 `negative_prompt`（可选的负面提示词）。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 生成的单个或多个图像，作为批次返回。 | IMAGE |
