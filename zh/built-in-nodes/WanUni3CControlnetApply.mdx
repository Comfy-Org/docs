### 概述

此节点将一个 Uni3C ControlNet 应用于 Wan 视频扩散模型，利用渲染的引导视频（例如，扭曲的点云渲染）来影响模型的输出。它在特定的块层注入控制信号，从而在视频生成过程中实现基于相机轨迹的引导。

### 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 取值范围 |
|------|------|----------|----------|----------|
| `模型` | 待修补的 Wan 扩散模型。 | MODEL | 是 | – |
| `模型补丁` | 一个 Uni3C ControlNet 补丁（必须是 `comfy.ldm.wan.uni3c.WanUni3CControlnet` 的实例）。 | MODEL_PATCH | 是 | – |
| `vae` | 用于将引导视频编码为潜空间的 VAE。 | VAE | 是 | – |
| `渲染视频` | 根据相机轨迹渲染的引导视频，最常见的是输入图像的扭曲点云渲染。 | IMAGE | 是 | – |
| `强度` | 所施加控制信号的强度。 | FLOAT | 是 | -10.0 至 10.0（默认值：1.0） |
| `起始百分比` | 控制开始的去噪过程百分比。 | FLOAT | 是 | 0.0 至 1.0（默认值：0.0） |
| `结束百分比` | 控制结束的去噪过程百分比。 | FLOAT | 是 | 0.0 至 1.0（默认值：1.0） |

**注意：**
- `model_patch` 必须是一个 Uni3C ControlNet；否则节点会报错。
- ControlNet 的内部维度必须与 Wan 模型的维度匹配——若不一致则会报错。
- `render_video` 输入图像应为 RGB 格式（仅使用前 3 个通道）。

### 输出

| 输出名 | 描述 | 数据类型 |
|--------|------|----------|
| `MODEL` | 应用了 Uni3C ControlNet 后的修补版 Wan 模型。 | MODEL |
