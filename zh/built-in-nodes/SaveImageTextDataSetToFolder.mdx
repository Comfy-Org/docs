Save Image-Text (to Folder) 将一组图像及其对应的文本说明保存到 ComfyUI 输出目录内的指定文件夹中。每张图像保存为 PNG 文件时，还会生成一个同名基础名称的 TXT 文件来存储其说明，这使得它非常适合用于创建由生成图像及其描述配对组成的有组织数据集。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要保存的图像列表。 | IMAGE | 是 | - |
| `文本` | 要保存的文本说明列表。此输入为可选。 | STRING | 否 | - |
| `文件夹名` | 用于保存图像的文件夹名称（位于输出目录内）。（默认值："dataset"） | STRING | 是 | - |
| `文件名前缀` | 已保存图像文件名的前缀。（默认值："image"） | STRING | 是 | - |
| `模式` | 是否覆盖现有文件，或递增文件名以避免覆盖。（默认值："overwrite"） | COMBO | 是 | "overwrite"<br />"increment" |

**注意：** `images` 输入是一个列表。`texts` 输入为可选；如果提供，它应为文本说明列表，且其项数应与 `images` 相同。每个说明都会保存为与对应图像关联的 `.txt` 文件。在 `overwrite` 模式下，文件命名为 `{filename_prefix}_{index}.png`，并替换同名的任何现有文件。在 `increment` 模式下，文件名中会添加一个唯一计数器，从而避免覆盖现有文件。`folder_name` 必须解析为输出目录内的路径；试图逃离该目录的文件夹名称（例如包含 `..`）将被拒绝。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| - | 此节点不返回任何数据。它直接将文件保存到文件系统。 | - |
