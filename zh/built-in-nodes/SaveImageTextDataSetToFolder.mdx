Save Image-Text (to Folder) 将图像和文本描述对数据集保存到 ComfyUI 输出目录内的文件夹中。每张图像写入为 PNG 文件，其匹配的描述写入为具有相同基本文件名的 TXT 文件，因此每张图像最终都与其描述配对。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `图像` | 要保存的图像列表。 | IMAGE | 是 | - |
| `文本` | 要保存的文本描述列表。此输入为可选。 | STRING | 否 | - |
| `文件夹名` | 保存图像的文件夹名称（在输出目录内）。（默认："dataset"） | STRING | 是 | - |
| `文件名前缀` | 保存图像文件名的前缀。（默认："image"） | STRING | 是 | - |
| `模式` | 是覆盖现有文件，还是递增文件名以避免覆盖。（默认："overwrite"） | COMBO | 是 | "overwrite"<br />"increment" |

**注意：** `images` 输入是一个列表，节点接收 `images` 和 `texts` 均为列表。`texts` 输入是可选的；如果提供，它应该是一个文本描述列表，并且应包含与 `images` 相同数量的项。每个描述将保存为与其配对图像对应的 `.txt` 文件。在 `overwrite` 模式下，文件命名为 `{filename_prefix}_{index}.png` 并替换任何同名的现有文件。在 `increment` 模式下，文件名会添加唯一计数器，因此不会覆盖现有文件。`folder_name` 必须解析为输出目录内的路径；试图逃逸该目录的文件夹名（例如使用 `..`）会被拒绝。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| - | 此节点不返回数据。它直接将文件保存到文件系统。 | - |
