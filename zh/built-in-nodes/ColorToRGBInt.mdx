**ColorToRGBInt** 节点将十六进制格式（如 `#FF5733`）的颜色转换为单个 RGB 整数值。它从颜色字符串中提取红色、绿色和蓝色分量，将它们组合为一个整数，同时返回原始的十六进制表示以及 Alpha（不透明度）值。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 取值 |
|-----------|-------------|-----------|----------|-------|
| `颜色` | 十六进制格式的颜色值 `#RRGGBB` 或 `#RRGGBBAA`。长度必须为 7 或 9 个字符，且以 `#` 开头。 | COLOR | 是 | `#RRGGBB`<br />`#RRGGBBAA` |

**注意：** 输入 `color` 字符串必须符合 `#RRGGBB` 或 `#RRGGBBAA` 格式。如果长度不是 7 或 9 个字符、不以 `#` 开头或包含无效的十六进制字符，节点将引发错误。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `rgb整数` | 计算得到的 RGB 整数值，公式为：`(Red * 65536) + (Green * 256) + Blue`。 | INT |
| `hex` | 格式为 `#RRGGBB` 的十六进制颜色字符串。如果输入包含 Alpha 通道，则此输出将移除该通道。 | COLOR |
| `alpha` | 介于 0.0 和 1.0 之间的 Alpha（不透明度）值。当输入为 `#RRGGBB` 时等于 1.0；当输入为 `#RRGGBBAA` 时为 Alpha 通道值除以 255。 | FLOAT |
