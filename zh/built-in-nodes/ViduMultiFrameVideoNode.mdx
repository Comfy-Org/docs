此节点通过在多个关键帧之间创建过渡来生成视频。它从一张初始图像开始，依次经过用户定义的一系列结束图像和提示词进行动画过渡，最终输出单个视频文件。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 取值范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于视频生成的 Vidu 模型。 | COMBO | 是 | "viduq2-pro"<br />"viduq2-turbo" |
| `start_image` | 起始帧图像。宽高比必须在 1:4 到 4:1 之间。 | IMAGE | 是 | 宽高比 1:4 到 4:1 |
| `seed` | 用于随机数生成的种子值，以确保结果可复现（默认值：1）。 | INT | 是 | 0 到 2147483647 |
| `resolution` | 输出视频的分辨率。 | COMBO | 是 | "720p"<br />"1080p" |
| `frames` | 关键帧过渡的数量（2-9）。选择某个数值后会动态显示每一帧所需的输入项。 | DYNAMIC_COMBO | 是 | "2"<br />"3"<br />"4"<br />"5"<br />"6"<br />"7"<br />"8"<br />"9" |

### 帧输入（所有帧数选项共用）

当 `frames` 设置为某个数值时，会针对从 1 到该数值的每一帧 `i` 显示以下三个输入项。例如，选择 "3" 会添加 `prompt1` / `end_image1` / `duration1`、`prompt2` / `end_image2` / `duration2` 以及 `prompt3` / `end_image3` / `duration3`。

| 参数 | 描述 | 数据类型 | 必填 | 取值范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt{i}` | 第 &#123;i&#125; 帧过渡的文本提示词。多行文本字段。最多 2000 个字符。 | STRING | 是 | 最多 2000 个字符 |
| `end_image{i}` | 第 &#123;i&#125; 段的结束帧图像。宽高比必须在 1:4 到 4:1 之间。 | IMAGE | 是 | 宽高比 1:4 到 4:1 |
| `duration{i}` | 第 &#123;i&#125; 段的时长，单位为秒（默认值：4）。 | INT | 是 | 2 到 7 |

**说明：**

- 所有输入项均为必填。`seed` 有默认值，但仍是必填输入项。
- `start_image` 以及每个 `end_image{i}` 的宽高比必须在 1:4 到 4:1 之间。
- 每个 `prompt{i}` 的最大长度为 2000 个字符。
- 每个 `duration{i}` 必须在 2 到 7 秒之间。
- 帧数可以在 2 到 9 之间，因此可能的帧索引为 1 到 9。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 生成的视频文件，包含所有动画过渡。 | VIDEO |
