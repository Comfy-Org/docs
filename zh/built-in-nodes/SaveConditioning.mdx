此节点将单个 conditioning 保存到输出文件夹中，保存为 safetensors 文件。保存的文件可以移动到 models/embeddings 文件夹，并在之后通过 Load Conditioning 加载，例如用于跳过文本编码器。该节点会将 conditioning 原样传递，因此它之后仍可在工作流中使用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `conditioning` | 要保存的 conditioning。仅支持单个 conditioning 条目。 | CONDITIONING | 是 | - |
| `filename_prefix` | 用于构建输出文件名的前缀。文件会写入输出文件夹，并附加一个数字计数器。默认值：`conditioning/ComfyUI` | STRING | 是 | - |

**注意：**

- 如果 `conditioning` 输入包含多个条目（例如在组合 conditioning 之后），节点会报错："Save Conditioning supports a single conditioning entry, save it before combining."
- 类型为张量、张量列表/元组、布尔值、整数、浮点数或字符串的 conditioning 选项会与 conditioning 一起保存。为 `None` 的选项会被跳过。任何其他选项类型都会引发错误，指出该选项无法保存。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `conditioning` | 传入的同一个 conditioning，未做更改。 | CONDITIONING |
