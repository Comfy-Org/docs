The ModelSave 节点将 MODEL 保存到计算机存储中，作为 `.safetensors` checkpoint 文件。它会使用你提供的文件名前缀，将文件写入 ComfyUI 的输出目录，并在可用时将工作流提示信息和模型元数据嵌入到保存的文件中。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 取值范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要保存到磁盘的模型 | MODEL | 是 | - |
| `文件名前缀` | 保存模型文件的文件名和路径前缀（默认：`diffusion_models/ComfyUI`） | STRING | 是 | - |
| `prompt` | 工作流提示信息（自动提供） | PROMPT | 否 | - |
| `extra_pnginfo` | 额外的工作流元数据（自动提供） | EXTRA_PNGINFO | 否 | - |

注意：保存的文件名由 `filename_prefix` 值后跟一个五位计数器构成（例如 `diffusion_models/ComfyUI_00001_.safetensors`）。如果已存在使用相同前缀的文件，则计数器会递增，以便新文件获得唯一名称。在可用时，工作流提示、额外元数据以及模型架构信息（例如 Stable Diffusion XL、SDXL Refiner、Stable Video Diffusion 或 Stable Diffusion 3）会嵌入到保存的文件中。如果通过 ComfyUI 的命令行设置禁用了元数据保存，则提示和额外元数据不会写入文件。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| *None* | 此节点不返回任何输出值 | - |
