ModelSave 节点将模型以 `.safetensors` 检查点文件形式保存到计算机存储中。它以模型作为输入，并使用您指定的文件名前缀将其写入输出目录。如果可用，它还会将工作流提示信息和附加元数据嵌入到保存的文件中。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 要保存到磁盘的模型 | MODEL | 是 | - |
| `文件名前缀` | 保存模型文件的文件名和路径前缀（默认值："diffusion_models/ComfyUI"） | STRING | 是 | - |
| `prompt` | 工作流提示信息（自动提供） | PROMPT | 否 | - |
| `extra_pnginfo` | 附加的工作流元数据（自动提供） | EXTRA_PNGINFO | 否 | - |

注意：保存的文件名由 `filename_prefix` 值后跟一个五位计数器构成（例如，`diffusion_models/ComfyUI_00001_.safetensors`）。如果已经存在具有相同前缀的文件，计数器会增加，以便新文件获得唯一名称。如果可用，工作流提示、附加元数据和模型架构信息会嵌入到保存的文件中。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| *None* | 此节点不返回任何输出值 | - |
