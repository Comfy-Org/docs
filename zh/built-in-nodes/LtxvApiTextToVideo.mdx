LTXV Text To Video 节点根据文本描述生成专业质量的视频。它连接到外部 API，以创建可自定义时长、分辨率和帧率的视频。你还可以选择为视频添加 AI 生成的音频。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 用于视频生成的 AI 模型。“LTX-2 (Pro)”提供更高质量，而“LTX-2 (Fast)”则针对速度进行了优化。 | COMBO | 是 | `"LTX-2 (Pro)"`<br />`"LTX-2 (Fast)"` |
| `prompt` | AI 将用于生成视频的文本描述。此字段支持多行文本，且必须包含 1 到 10,000 个字符。默认值：""（空）。 | STRING | 是 | - |
| `duration` | 生成视频的时长（秒）（默认值：8）。 | COMBO | 是 | `6`<br />`8`<br />`10`<br />`12`<br />`14`<br />`16`<br />`18`<br />`20` |
| `resolution` | 输出视频的像素尺寸（宽 x 高）。 | COMBO | 是 | `"1920x1080"`<br />`"2560x1440"`<br />`"3840x2160"` |
| `fps` | 视频的帧率（每秒帧数）（默认值：25）。 | COMBO | 是 | `25`<br />`50` |
| `generate_audio` | 当为 true 时，生成的视频将包含与场景匹配的 AI 生成音频（默认值：False）。这是一个高级可选设置。 | BOOLEAN | 否 | - |

**重要约束：**

* `prompt` 长度必须在 1 到 10,000 个字符之间。
* 如果选择的 `duration` 大于 10 秒，则还必须使用 `"LTX-2 (Fast)"` 模型、`"1920x1080"` 分辨率以及 `25` 的 `fps`。较长的视频需要此组合。
* 定价取决于所选的 `model`、`duration` 和 `resolution`。

**注意：** 此节点已弃用。
