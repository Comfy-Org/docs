LTXV 文本转视频节点可根据文本描述生成专业品质的视频。它会连接外部 API，创建具有可自定义时长、分辨率和帧率的视频。您还可以选择在视频中添加 AI 生成的音频。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 用于视频生成的 AI 模型。“LTX-2 (Pro)”提供更高质量，而“LTX-2 (Fast)”针对速度进行了优化。 | COMBO | 是 | `"LTX-2 (Pro)"`<br />`"LTX-2 (Fast)"` |
| `提示词` | AI 用于生成视频的文本描述。此字段支持多行文本，且必须包含 1 到 10,000 个字符。 | STRING | 是 | - |
| `时长` | 生成视频的时长（以秒为单位，默认：8）。 | COMBO | 是 | `6`<br />`8`<br />`10`<br />`12`<br />`14`<br />`16`<br />`18`<br />`20` |
| `分辨率` | 输出视频的像素尺寸（宽 x 高）。 | COMBO | 是 | `"1920x1080"`<br />`"2560x1440"`<br />`"3840x2160"` |
| `帧率` | 视频的每秒帧数（默认：25）。 | COMBO | 是 | `25`<br />`50` |
| `生成音频` | 当为 true 时，生成的视频将包含与场景匹配的 AI 生成音频（默认：False）。这是一个高级可选设置。 | BOOLEAN | 否 | - |

**重要约束：**

* `prompt` 的长度必须在 1 到 10,000 个字符之间。
* 如果选择的 `duration` 大于 10 秒，则还必须使用 `"LTX-2 (Fast)"` 模型、`"1920x1080"` 分辨率和 `25` 的 `fps`。生成较长视频需要此组合。

**注意：** 此节点已弃用。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `output` | 生成的视频文件。 | VIDEO |
