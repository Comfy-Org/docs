通过 BFL API 使用 Flux.1 Kontext [max] 基于提示词和宽高比生成或编辑图像。连接 `input_image` 时，提示词描述编辑内容；不连接时，节点仅根据提示词生成一张新图像。它暴露的输入与 Flux.1 Kontext [pro] Image 相同。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `提示词` | 用于图像生成的提示词。提供输入图像时，指定要编辑什么以及如何编辑。 | STRING | 是 | - |
| `宽高比` | 图像的宽高比；必须在 1:4 和 4:1 之间（默认值：`"16:9"`）。 | STRING | 是 | - |
| `引导强度` | 图像生成过程的引导强度（默认值：3.0）。 | FLOAT | 是 | 0.1 到 99.0 （步长：0.1） |
| `步数` | 图像生成过程的步数（默认值：50）。 | INT | 是 | 1 到 150 |
| `种子` | 用于创建噪声的随机种子（默认值：1234）。 | INT | 是 | 0 到 18446744073709551615 |
| `提示词上采样` | 是否对提示词执行上采样。如果启用，提示词会被自动修改以获得更具创造性的生成结果，但结果是非确定性的，因此相同的种子不会产生完全相同的结果（默认值：`False`）。这是一个高级设置。 | BOOLEAN | 是 | True / False |
| `输入图像` | 可选的要编辑的图像。省略时，会验证提示词以确保其不为空。 | IMAGE | 否 | - |

**注意：** 节点会将请求发送到 BFL，并轮询直到图像准备就绪。被 BFL 内容审核拒绝的请求会失败，而不会返回图像。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `IMAGE` | 生成或编辑后的图像。 | IMAGE |
