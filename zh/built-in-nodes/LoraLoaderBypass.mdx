LoraLoaderBypass 节点以特殊的“旁路”（bypass）模式将 LoRA（低秩适应）应用于扩散模型和 CLIP 模型。与标准 LoRA 加载器不同，此方法不会永久修改基础模型的权重；而是将 LoRA 的效果添加到模型的正常前向传播中，从而计算输出。这在训练时或处理已将权重卸载（offloaded）的模型时非常有用。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 将应用 LoRA 的扩散模型。 | MODEL | 是 | - |
| `clip` | 将应用 LoRA 的 CLIP 模型。 | CLIP | 是 | - |
| `lora_name` | LoRA 的名称。可用的 LoRA 文件从 `loras` 文件夹中加载。 | COMBO | 是 | 可用 LoRA 文件列表 |
| `strength_model` | 对扩散模型的修改强度。该值可以为负（默认值：1.0）。 | FLOAT | 是 | -100.0 到 100.0（步长：0.01） |
| `strength_clip` | 对 CLIP 模型的修改强度。该值可以为负（默认值：1.0）。 | FLOAT | 是 | -100.0 到 100.0（步长：0.01） |

**注意：** 如果 `strength_model` 和 `strength_clip` 都设置为 0，节点将不经处理直接返回原始、未修改的 `model` 和 `clip` 输入。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `MODEL` | 修改后的扩散模型。 | MODEL |
| `CLIP` | 修改后的 CLIP 模型。 | CLIP |

**注意：** 此节点标记为实验性节点。
