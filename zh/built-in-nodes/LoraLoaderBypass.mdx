LoraLoaderBypass 节点以特殊的“bypass”模式将 LoRA（低秩适应）应用于扩散模型和 CLIP 模型。与标准 LoRA 加载器不同，此方法不会永久修改基础模型的权重。相反，它通过将 LoRA 的贡献添加到模型正常的前向传播中来计算结果，这对于训练或处理权重被卸载的模型很有用。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `model` | 要应用 LoRA 的扩散模型。 | MODEL | 是 | - |
| `clip` | 要应用 LoRA 的 CLIP 模型。 | CLIP | 是 | - |
| `lora_name` | LoRA 的名称。可用的 LoRA 文件从 `loras` 文件夹加载。 | COMBO | 是 | 可用 LoRA 文件列表 |
| `strength_model` | 修改扩散模型的强度。此值可以为负（默认值：1.0）。 | FLOAT | 是 | -100.0 到 100.0（步长：0.01） |
| `strength_clip` | 修改 CLIP 模型的强度。此值可以为负（默认值：1.0）。 | FLOAT | 是 | -100.0 到 100.0（步长：0.01） |

**注意：** 如果 `strength_model` 和 `strength_clip` 都设置为 0，则该节点会返回原始未修改的 `model` 和 `clip` 输入，而不进行处理。

**注意：** 所选 LoRA 文件在首次加载后会被缓存。仅当选择了不同的 `lora_name` 时，才会重新从磁盘读取。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `MODEL` | 修改后的扩散模型。 | MODEL |
| `CLIP` | 修改后的 CLIP 模型。 | CLIP |

**注意：** 此节点被标记为实验性。
