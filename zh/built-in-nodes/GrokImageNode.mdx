Grok Image 节点使用 Grok AI 模型根据文本描述生成一张或多张图像。它会将你的提示词发送到外部服务，并将生成的图像作为张量返回，这些张量可在你的工作流中使用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于图像生成的特定 Grok 模型。不同模型可能提供不同的质量、速度或功能。 | COMBO | 是 | `"grok-imagine-image-2.0"`<br />`"grok-imagine-image-quality"`<br />`"grok-imagine-image-pro"`<br />`"grok-imagine-image"` |
| `prompt` | 用于生成图像的文本提示词。此描述指导 AI 创建什么内容。长度必须至少为 1 个字符（不接受仅包含空白字符的文本）。 | STRING | 是 | N/A |
| `aspect_ratio` | 生成图像的期望宽高比。 | COMBO | 是 | `"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"9:16"`<br />`"16:9"`<br />`"9:19.5"`<br />`"19.5:9"`<br />`"9:20"`<br />`"20:9"`<br />`"1:2"`<br />`"2:1"` |
| `number_of_images` | 要生成的图像数量（默认值：1）。 | INT | 是 | 1 到 10 |
| `seed` | 用于确定节点是否应重新运行的种子；无论种子如何，实际结果都是非确定性的（默认值：0）。 | INT | 是 | 0 到 2147483647 |
| `分辨率` | 生成图像的期望输出分辨率（默认值："1K"）。 | COMBO | 否 | `"1K"`<br />`"2K"` |
| `质量` | 质量级别，仅由 `grok-imagine-image-2.0` 模型支持（默认值："medium"；"low" 是可用选项之一）。对于所有其他模型，此设置将被忽略。 | COMBO | 否 | 多种可用选项 |

**注意：** `seed` 参数主要用于控制节点在工作流中何时重新执行。由于外部 AI 服务的性质，即使种子完全相同，生成的图像在不同运行之间也无法重现或完全相同。

**关于定价的说明：** 生成图像的成本取决于所选的 `model`、`resolution`、`quality` 和 `number_of_images`。对于 `grok-imagine-image-2.0` 模型，"low" 质量在 1K 分辨率下每张图像花费 $0.04，在 2K 分辨率下每张图像花费 $0.06；其他质量级别在 1K 下每张图像花费 $0.06，在 2K 下每张图像花费 $0.08。`grok-imagine-image-quality` 模型在 1K 分辨率下每张图像花费 $0.05，在 2K 分辨率下每张图像花费 $0.07。`grok-imagine-image-pro` 模型每张图像花费 $0.07。`grok-imagine-image` 模型每张图像花费 $0.02。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `output` | 生成的图像或一批图像。如果 `number_of_images` 为 1，则返回单个图像张量。如果大于 1，则返回一批图像张量。 | IMAGE |
