使用 Bria 从视频中擦除逐帧遮罩覆盖的任何内容，并填补空缺。遮罩中要擦除的对象必须为白色，其他区域为黑色。Bria 接受最长 5.1 秒、帧率为 20 到 30 帧/秒且像素尺寸为偶数的片段；默认保留音频。返回的片段可能比输入少几帧。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `video` | 要从中擦除内容的片段。 | VIDEO | 是 | - |
| `mask` | 视频每帧对应一个遮罩，要擦除的对象所在区域为白色。请提供 `mask` 或 `mask_video` 中的其中一个，不要同时提供两者。 | MASK | 否 | - |
| `mask_video` | 已编码的遮罩视频，其尺寸和帧数与视频相同。请提供 `mask` 或 `mask_video` 中的其中一个，不要同时提供两者。 | VIDEO | 否 | - |
| `preserve_audio` | 保留输入的音频轨道。默认值：true。 | BOOLEAN | 否 | `true`<br />`false` |

**约束说明：**

- `mask` 或 `mask_video` 中必须且只能连接一个。如果两者都未提供，或两者都提供，都会引发错误。
- 视频长度必须不超过 5.1 秒，并且必须以 20 到 30 帧/秒运行。如有需要，可使用 Get Video Components 和 Create Video 重新调整片段时间。
- 视频的像素尺寸必须为偶数（宽度和高度可被 2 整除）。否则请先裁剪或缩放。
- 使用 `mask` 时，它必须为每个视频帧包含一个遮罩帧，并且其宽高比必须与视频匹配。遮罩会在 50% 处二值化：不透明度低于一半的绘制区域会被忽略，空遮罩会引发错误。如果遮罩分辨率与视频不同，则会将其调整为视频尺寸。
- 使用 `mask_video` 时，它必须与视频具有相同的尺寸和相同的帧数。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `video` | 经过编辑的片段，遮罩区域已被擦除并填补了空缺。可能比输入片段少几帧。 | VIDEO |
