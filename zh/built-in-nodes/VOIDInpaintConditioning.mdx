VOIDInpaintConditioning 节点用于准备使用 CogVideoX 模型进行局部重绘所需的 conditioning 数据。它接收源视频和预处理后的 quadmask，通过 VAE 对其进行编码，并将二者组合成一个 32 通道的 conditioning 信号（其中 16 个通道来自遮罩，16 个通道来自被遮罩的视频），模型使用该信号来填充被遮罩的区域。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 取值范围 |
| --- | --- | --- | --- | --- |
| `positive` | 需要加入局部重绘 latent 信息的正向 conditioning | CONDITIONING | 是 | - |
| `negative` | 需要加入局部重绘 latent 信息的负向 conditioning | CONDITIONING | 是 | - |
| `vae` | 用于将遮罩和被遮罩的视频编码到 latent 空间的 VAE 模型 | VAE | 是 | - |
| `video` | 源视频帧 [T, H, W, 3] | IMAGE | 是 | - |
| `quadmask` | 来自 VOIDQuadmaskPreprocess 的预处理 quadmask [T, H, W] | MASK | 是 | - |
| `width` | 将视频和遮罩调整到的宽度（默认值：672） | INT | 是 | 16 to MAX_RESOLUTION （步长：8） |
| `height` | 将视频和遮罩调整到的高度（默认值：384） | INT | 是 | 16 to MAX_RESOLUTION （步长：8） |
| `length` | 要处理的像素帧数量。对于 CogVideoX-Fun-V1.5（patch_size_t=2），latent_t 必须为偶数——会产生奇数 latent_t 的长度会被向下取整（例如 49 → 45）（默认值：45） | INT | 是 | 1 to MAX_RESOLUTION （步长：1） |
| `batch_size` | 输出噪声 latent 的批次大小（默认值：1） | INT | 是 | 1 到 64 |

**注意：** 由于 CogVideoX-Fun-V1.5 使用 `patch_size_t=2`，编码后的 latent 在时间维度上必须为偶数。如果 `length` 会产生奇数 `latent_t`，节点会自动将其向下取整到最近的有效值并记录一条警告。使用奇数 `latent_t` 会因为循环填充而破坏最后一帧，从而导致解码后的视频在接近结尾处出现可见的抖动或主体消失。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 已加入局部重绘 latent 信息的正向 conditioning | CONDITIONING |
| `negative` | 已加入局部重绘 latent 信息的负向 conditioning | CONDITIONING |
| `latent` | 一个形状为 [batch_size, 16, latent_t, latent_h, latent_w] 的零填充噪声 latent 张量 | LATENT |
