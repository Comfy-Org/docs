使用 Kling 4.0 从文本提示词和最多 10 张参考图像生成或编辑图像。既可以请求生成单张图像，也可以让节点返回一系列保持相同角色和风格的关联图像。

## 输入

| 参数名 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 用于参考图像的可增长槽位（`image_1` ... `image_10`）。可在提示词中以 `@Image1`、`@Image2` 等引用它们。 | AUTOGROW | 否 | 0 到 10 张图像 |
| `prompt` | 图像描述。以 `@Image1`、`@Image2`…… 引用已连接的图像。默认：空字符串。 | STRING | 是 | 多行文本 |
| `resolution` | 输出图像的分辨率。默认：`"2K"`。 | COMBO | 是 | `"2K"`<br />`"4K"`<br />`"8K"` |
| `aspect_ratio` | 输出图像的宽高比。`"auto"` 表示跟随参考图像，否则跟随提示词。默认：`"auto"`。 | COMBO | 是 | `"auto"`<br />`"9:16"`<br />`"2:3"`<br />`"3:4"`<br />`"1:1"`<br />`"4:3"`<br />`"3:2"`<br />`"16:9"`<br />`"21:9"` |
| `series_amount` | 生成一系列保持相同角色和风格的关联图像。`"auto"` 让模型自行选择 2 到 10 张图像。默认：`"disabled"`。 | COMBO | 是 | `"disabled"`<br />`"auto"`<br />`"2"`<br />`"3"`<br />`"4"`<br />`"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"` |
| `seed` | 种子控制节点是否需要重新运行；无论种子取何值，结果都是不确定的。默认：42。 | INT | 是 | 0 到 2147483647 |

**约束与行为：**

* 最多可连接 10 张参考图像。
* 每张图像必须至少为 300x300 像素，且宽高比在 2:5 到 5:2 之间。
* 如果提示词中提及 `@ImageN`，但已连接的图像数量少于 N，则会报错。
* 当 `series_amount` 设为 `"disabled"` 时，节点返回一张图像；设为其他任意值时，返回对应数量的图像批次。
* 调用价格随分辨率、参考图像数量以及系列中图像数量而增加。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 生成的图像；当启用 `series_amount` 时，则为一个图像批次。 | IMAGE |
