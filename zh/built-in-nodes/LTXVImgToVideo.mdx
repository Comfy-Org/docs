LTXVImgToVideo 将输入图像转换为用于视频生成模型的视频潜在表示。它会将图像调整到指定的宽度和高度，使用 VAE 进行编码，并将编码后的帧放置在视频尺寸的零值潜在张量的开头。强度控制决定在视频生成过程中保留多少原始图像内容以及修改多少。

## 输入

| 参数 | 描述 | 数据类型 | 是否必需 | 范围 |
| --- | --- | --- | --- | --- |
| `正面条件` | 用于引导视频生成的正向条件提示 | CONDITIONING | 是 | - |
| `负面条件` | 负向条件提示，用于避免视频中出现特定元素 | CONDITIONING | 是 | - |
| `vae` | 用于将输入图像编码到潜在空间的 VAE 模型 | VAE | 是 | - |
| `图像` | 要转换为视频帧的输入图像 | IMAGE | 是 | - |
| `宽度` | 输出视频宽度（像素）（默认值：768，步长：32） | INT | 否 | 64 to MAX_RESOLUTION |
| `高度` | 输出视频高度（像素）（默认值：512，步长：32） | INT | 否 | 64 to MAX_RESOLUTION |
| `长度` | 生成视频的帧数（默认值：97，步长：8） | INT | 否 | 9 to MAX_RESOLUTION |
| `批量大小` | 同时生成的视频数量（默认值：1） | INT | 否 | 1 到 4096 |
| `强度` | 控制生成视频的前几帧中保留多少原始图像内容。值 1.0 完全保留原始图像，而 0.0 允许最大程度修改（默认值：1.0） | FLOAT | 否 | 0.0 到 1.0 |

注意：`width` 和 `height` 以 32 像素为步长变化，`length` 以 8 帧为步长变化，这与视频潜在空间的压缩率（空间维度 32 倍，时间维度 8 倍）相匹配。视频潜在张量包含 ((length - 1) // 8) + 1 帧。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `正面条件` | 保持不变的正向条件，用于生成的潜在张量 | CONDITIONING |
| `负面条件` | 保持不变的负向条件，用于生成的潜在张量 | CONDITIONING |
| `Latent` | 包含编码图像帧和噪声掩码的视频潜在表示，噪声掩码控制视频生成过程中条件的作用强度。 | LATENT |
