LTXVImgToVideo 将输入图像转换为视频潜在表示，以供视频生成模型使用。它会将图像调整到指定的宽度和高度，使用 VAE 对其进行编码，并将编码后的帧放置在视频尺寸的全零 latent 的开头。`strength` 控制决定了在视频生成过程中保留多少原始图像内容、修改多少内容。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `正面条件` | 用于引导视频生成的正向条件提示 | CONDITIONING | 是 | - |
| `负面条件` | 用于避免视频中出现特定元素的负向条件提示 | CONDITIONING | 是 | - |
| `vae` | 用于将输入图像编码到潜在空间的 VAE 模型 | VAE | 是 | - |
| `图像` | 要转换为视频帧的输入图像 | IMAGE | 是 | - |
| `宽度` | 输出视频宽度（像素）（默认值：768，步长：32） | INT | 是 | 64 to MAX_RESOLUTION |
| `高度` | 输出视频高度（像素）（默认值：512，步长：32） | INT | 是 | 64 to MAX_RESOLUTION |
| `长度` | 生成视频中的帧数（默认值：97，步长：8） | INT | 是 | 9 to MAX_RESOLUTION |
| `批量大小` | 同时生成的视频数量（默认值：1） | INT | 是 | 1 到 4096 |
| `强度` | 控制生成视频的前几帧中保留多少原始图像内容。值为 1.0 时完全保留原始图像，值为 0.0 时允许最大程度的修改（默认值：1.0） | FLOAT | 是 | 0.0 到 1.0 |

注意：`width` 和 `height` 以 32 像素为步长变化，`length` 以 8 帧为步长变化，这与视频 latent 的压缩方式相匹配（空间维度压缩 32 倍，时间维度压缩 8 倍）。视频 latent 包含 ((length - 1) // 8) + 1 帧。输入图像会通过中心裁剪的双线性缩放调整到 `width` x `height`，并且仅使用前三个通道进行编码。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `positive` | 未经更改直接传递的正向条件，用于生成的 latent | CONDITIONING |
| `negative` | 未经更改直接传递的负向条件，用于生成的 latent | CONDITIONING |
| `latent` | 视频潜在表示，包含编码后的图像帧以及一个噪声掩码，该掩码控制视频生成过程中条件的施加强度 | LATENT |
