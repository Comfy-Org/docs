OpenAIVideoSora2 节点使用 OpenAI 的 Sora 模型生成视频。它根据文本提示和可选输入参考图像创建视频内容，并将生成的视频作为输出返回。该节点根据所选模型支持不同的视频时长和分辨率。

**弃用通知：** OpenAI 将于 2026 年 9 月停止提供 Sora v2 API。届时此节点将从 ComfyUI 中移除。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `模型` | 用于视频生成的 OpenAI Sora 模型（默认："sora-2"） | COMBO | 是 | "sora-2"<br />"sora-2-pro" |
| `提示词` | 引导文本；如果存在输入图像，可以为空（默认：空） | STRING | 是 | - |
| `尺寸` | 生成视频的分辨率（默认："1280x720"） | COMBO | 是 | "720x1280"<br />"1280x720"<br />"1024x1792"<br />"1792x1024" |
| `时长` | 生成视频的时长（秒）（默认：8） | COMBO | 是 | 4<br />8<br />12 |
| `图像` | 可选输入参考图像，用于视频生成（如外形、角色、场景参考等）；仅支持单张图像 | IMAGE | 否 | - |
| `随机种` | 用于确定节点是否应重新运行的种子；无论种子如何，实际结果都是不确定的（默认：0） | INT | 否 | 0 到 2147483647 |

**约束与限制：**

- "sora-2" 模型仅支持 "720x1280" 和 "1280x720" 两种分辨率；"1024x1792" 和 "1792x1024" 仅在与 "sora-2-pro" 模型配合使用时有效
- 当连接图像时，必须恰好包含一张图像；连接多张图像会引发错误
- 无论种子值如何，结果都是不确定的

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `output` | OpenAI Sora 生成的视频文件 | VIDEO |
