Flux 3 Image 可根据提示词使用 FLUX 3 生成图像，或编辑并组合参考图像。将你想要的内容写成指令，然后连接最多 10 张参考图像，并在提示词中以 image 1、image 2 等方式引用它们。提示词会在生成前被解析和扩展，结果将按你选择的宽高比和分辨率渲染。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 要生成的内容，或要进行的编辑。提示词会在生成前被解析和扩展。通过 image 1、image 2 等方式引用已连接的参考图像。（默认值：""） | STRING | 是 | 1 到 15000 个字符 |
| `images` | 用于参考图像的可扩展槽位；总共最多连接 10 张。每张图像必须至少为 256x256 像素，且其宽高比不能比 64:1 更极端。 | IMAGE | 否 | 0 到 10 张图像 |
| `bounding_boxes` | 来自 Create Bounding Boxes 节点的可选边界框，用于在输出中放置对象或文本。位置相对于画布，因此请为该节点提供输出的宽高比。 | ARRAY | 否 | - |
| `aspect_ratio` | 生成图像的宽高比。"auto" 会跟随第一张参考图像，或从提示词中选择一个比例。（默认值："auto"） | COMBO | 是 | `"auto"`<br />`"21:9"`<br />`"2:1"`<br />`"16:9"`<br />`"3:2"`<br />`"7:5"`<br />`"4:3"`<br />`"5:4"`<br />`"1:1"`<br />`"4:5"`<br />`"3:4"`<br />`"5:7"`<br />`"2:3"`<br />`"9:16"`<br />`"1:2"`<br />`"9:21"` |
| `resolution` | 在所选宽高比下的输出尺寸：0.75K 约为 0.6 百万像素，1K 为 1 MP，1.5K 为 2.4 MP，2K 为 4.2 MP，4K 为 16.8 MP。（默认值："2K"） | COMBO | 是 | `"0.75K"`<br />`"1K"`<br />`"1.5K"`<br />`"2K"`<br />`"4K"` |
| `grounding` | 让模型在生成前通过网页和图像搜索研究提示词。（默认值：True） | BOOLEAN | 是 | True<br />False |
| `safety_tolerance` | 审核容忍度，0 为最严格。（默认值：4） | INT | 是 | 0 到 4 |
| `seed` | 用于确定节点是否应重新运行的种子；FLUX 3 会自行选择种子，因此无论此值如何，实际结果都是非确定性的。（默认值：42） | INT | 是 | 0 到 4294967295 |

`safety_tolerance` 是高级输入，且 `seed` 在 UI 中包含 Control After Generate 控件。

参考图像会在发送请求之前上传。单个槽位可以承载一个批次，并且每个批次中的每一帧都会计入 10 张图像的限制。

`bounding_boxes` 的各行会追加到提示词中，因此提示词和边界框描述加在一起必须不超过 15000 个字符。

显示的价格取决于 `resolution`：0.75K 时为 $0.05863，1K 时为 $0.06864，1.5K 时为 $0.1001，2K 时为 $0.143，4K 时为 $0.86801。

|-------------|-------------|-----------|
| `IMAGE` | 生成的图像，从 FLUX 3 结果下载。 | IMAGE |
