`GenerateTracks` 节点为视频生成创建多条平行的运动路径（轨道）。它定义一条从起始位置到结束位置的主路径，然后生成一组与该路径平行的轨道，均匀间隔。您可以控制路径的形状（直线或贝塞尔曲线）、沿路径移动的速度以及轨道在哪些帧中可见。

## 输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `宽度` | 视频帧的宽度（以像素为单位）。默认值为 832。 | INT | 是 | 16 - 4096 |
| `高度` | 视频帧的高度（以像素为单位）。默认值为 480。 | INT | 是 | 16 - 4096 |
| `起始点X` | 起始位置的归一化 X 坐标（0-1）。默认值为 0.0。 | FLOAT | 是 | 0.0 - 1.0 |
| `起始点Y` | 起始位置的归一化 Y 坐标（0-1）。默认值为 0.0。 | FLOAT | 是 | 0.0 - 1.0 |
| `结束点X` | 结束位置的归一化 X 坐标（0-1）。默认值为 1.0。 | FLOAT | 是 | 0.0 - 1.0 |
| `结束点Y` | 结束位置的归一化 Y 坐标（0-1）。默认值为 1.0。 | FLOAT | 是 | 0.0 - 1.0 |
| `帧数` | 要生成轨道位置的总帧数。默认值为 81。 | INT | 是 | 1 - 1024 |
| `轨迹数` | 要生成的平行轨道数量。默认值为 5。 | INT | 是 | 1 - 100 |
| `轨道分布` | 轨道之间的归一化距离。轨道垂直于运动方向展开。默认值为 0.025。 | FLOAT | 是 | 0.0 - 1.0 |
| `贝塞尔曲线` | 启用贝塞尔曲线路径，使用中点作为控制点。默认值为 False。 | BOOLEAN | 是 | True / False |
| `中间点Y` | 贝塞尔曲线的归一化 X 控制点。仅在 `bezier` 启用时使用。默认值为 0.5。 | FLOAT | 是 | 0.0 - 1.0 |
| `中间点Y` | 贝塞尔曲线的归一化 Y 控制点。仅在 `bezier` 启用时使用。默认值为 0.5。 | FLOAT | 是 | 0.0 - 1.0 |
| `插值` | 控制沿路径移动的时序/速度（默认："linear"）：<br />"linear" - 匀速<br />"ease_in" - 缓慢开始并加速<br />"ease_out" - 快速开始并减速<br />"ease_in_out" - 平滑加速和减速<br />"constant" - 将所有位置保持在起始点 | COMBO | 是 | `"linear"`<br />`"ease_in"`<br />`"ease_out"`<br />`"ease_in_out"`<br />`"constant"` |
| `轨道遮罩` | 可选遮罩，用于指示可见帧。如果提供，遮罩中任何非零像素的帧都会被标记为对所有轨道可见。 | MASK | 否 | - |

**注意：** `mid_x` 和 `mid_y` 参数仅在 `bezier` 参数设置为 `True` 时使用。当 `bezier` 为 `False` 时，路径是从起点到终点的直线。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `TRACKS` | 一个轨道对象，包含所有轨道在所有帧上生成的路径坐标和可见性信息。 | TRACKS |
| `轨迹长度` | 生成轨道的帧数，与输入的 `num_frames` 一致。 | INT |
