将高模网格的环境光遮蔽贴图烘焙到低模网格的 UV 布局中。输出是一张灰度图像，其中白色纹素表示开放区域，深色纹素表示缝隙；它用于 Apply Texture To Mesh 节点的 `occlusion` 输入。连接已展开 UV 的低模网格及其减面来源的高模网格。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | 要烘焙到的已展开 UV 的低模网格。必须具有 UV；如果缺失，节点会报错。 | MESH | 是 | - |
| `high_poly` | 低模进行减面所依据的高模网格，用作遮蔽的源几何体。 | MESH | 是 | - |
| `resolution` | 纹理分辨率（像素）；每个纹素会接收一个遮蔽值。默认：1024。 | INT | 是 | 64 到 8192（步长 64） |
| `samples` | 每个纹素的射线数量。越多越平滑，也越慢。如果有颗粒感，请提高此值。默认：64。 | INT | 是 | 4 到 1024（步长 4） |
| `max_distance` | 射线长度，以包围盒对角线长度的比例表示。越小，遮蔽越紧凑、越局部。默认：0.5。 | FLOAT | 是 | 0.01 到 2.0（步长 0.01） |
| `strength` | 缩放遮蔽程度。大于 1 会变暗，小于 1 会变亮。默认：1.0。 | FLOAT | 是 | 0.0 到 2.0（步长 0.05） |
| `bias` | 射线起点从表面抬起的距离，以包围盒对角线长度的比例表示。如果平整表面也出现深色斑块/孔洞，请提高此值。默认：0.01。 | FLOAT | 是 | 0.0001 到 0.2（步长 0.0005） |

注意：`low_poly` 必须有 UV 坐标——此节点不会展开网格。如果 `high_poly` 只包含一个批次项，则它会复用于 `low_poly` 的每个批次项；`low_poly` 中没有面的批次项会被跳过，并替换为全白图像，同时记录一条警告。如果 `low_poly` 的 UV 超出 0-1 范围，它们会被统一适配回该范围；当检测到平铺/UDIM 风格布局时，会记录一条警告。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `occlusion` | 灰度环境光遮蔽图像，值在 [0,1] 范围内（白色 = 开放，深色 = 缝隙），`low_poly` 的每个批次项对应一张图像。用于 Apply Texture To Mesh 节点的 `occlusion` 输入（打包到 ORM 贴图 / occlusionTexture 中）。 | IMAGE |
