将高多边形网格的环境光遮蔽贴图烘焙到低多边形网格的 UV 布局中。输出为灰度图像，其中白色纹素代表开放区域，深色纹素代表裂缝处；此图像用于“Apply Texture To Mesh”节点的遮挡输入。请连接已展开 UV 的低多边形网格，以及用于生成该低多边形网格的高多边形网格。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|------|------|----------|------|------|
| `low_poly` | 要烘焙到的、已展开 UV 的低多边形网格。必须具有 UV；若缺少 UV，节点将报错。 | MESH | 是 | - |
| `high_poly` | 低多边形网格由高多边形网格抽取而来，作为遮挡的源几何体。 | MESH | 是 | - |
| `resolution` | 纹理分辨率（像素）；每个纹素接收一个遮蔽值。默认值：1024。 | INT | 是 | 64 到 8192（步长 64） |
| `samples` | 每个纹素的射线数。数值越大越平滑，但速度越慢；若出现颗粒感可增大该值。默认值：64。 | INT | 是 | 4 到 1024（步长 4） |
| `max_distance` | 射线长度，以边界框对角线的比例表示。数值越小，遮蔽范围越紧凑、越局部。默认值：0.5。 | FLOAT | 是 | 0.01 到 2.0（步长 0.01） |
| `strength` | 缩放遮蔽强度。>1 变暗，&lt;1 变亮。默认值：1.0。 | FLOAT | 是 | 0.0 到 2.0（步长 0.05） |
| `bias` | 射线起点抬离表面的距离，以边界框对角线的比例表示。若平整表面也出现暗斑或孔洞，可增大该值。默认值：0.01。 | FLOAT | 是 | 0.0001 到 0.2（步长 0.0005） |

注意：`low_poly` 必须具有 UV 坐标——此节点绝不会自动展开网格。如果 `high_poly` 仅包含一个批次项，则它会为 `low_poly` 的每个批次项重复使用；`low_poly` 中没有面的批次项会被跳过，并替换为全白图像，同时记录一条警告日志。

## 输出

| 输出名 | 描述 | 数据类型 |
|--------|------|----------|
| `occlusion` | 灰度环境光遮蔽图像，取值范围为 [0,1]（白色 = 开放，深色 = 裂缝），`low_poly` 的每个批次项对应一张图像。用于“Apply Texture To Mesh”节点的遮挡输入（打包到 ORM 贴图 / `occlusionTexture` 中）。 | IMAGE |
