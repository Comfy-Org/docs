Tencent HY Image: Edit 节点使用腾讯的 Hunyuan Image 模型，根据文本指令编辑或组合参考图像。连接一至五张图像，在提示词中描述更改，并将图像引用为 `@Image1`、`@Image2` 等。该节点上传参考图像，向 API 发送请求，并返回编辑后的结果。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于编辑的模型。所选模型决定显示哪些额外输入。 | DYNAMIC_COMBO | 是 | `"hy-image-3.5-preview"` |

| `aspect_ratio` | 输出的宽高比。`"auto"` 遵循第一张参考图像的宽高比，在 4K 下不可用。当 `resolution` 为 `"custom"` 时忽略。 | COMBO | 是 | `"auto"`<br />`"1:1"`<br />`"3:2"`<br />`"2:3"`<br />`"4:3"`<br />`"3:4"`<br />`"16:9"`<br />`"9:16"`<br />`"21:9"`<br />`"9:21"`（默认：`"auto"`） |

### 参考输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `images` | 要编辑或组合的参考图像。可增长槽位：连接 1 到 5 张图像（`image_1` 到 `image_5`）。在提示词中将它们引用为 `@Image1` ... `@Image5`，按输入顺序编号；批量输入中的每张图像分别计数。 | IMAGE | 是 | 1-5 张图像 |

`prompt` 不能为空，当仅连接 1 或 2 张图像时，像 `@Image3` 这样的提示词引用会报错。总共最多可使用 5 张参考图像，批量中的每张图像分别计数。使用 `"custom"` 分辨率时，`width` 和 `height` 必须都是 16 的倍数，且它们的乘积不得超过 4096 x 4096 像素面积限制（约 1670 万像素）；任何宽高比都可以，但超过约 6:1 后，模型会开始重复主体。`"auto"` 宽高比仅在 2K 面积限制内有效，因此在 4K 下请选择明确的宽高比或使用 `"custom"`。
