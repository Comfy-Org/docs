# 图像 RGB 到 YUV 转换

ImageRGBToYUV 节点执行 RGB 到 YUV 的颜色空间转换。它接受一个 RGB 图像作为输入，并输出三个分别代表 YUV 通道的独立图像：Y（亮度）、U（蓝差色度）和 V（红差色度）。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|------|------|----------|------|------|
| `图像` | 要转换为 YUV 颜色空间的输入 RGB 图像。这应该是一个 3 通道图像。 | IMAGE | 是 | - |

## 输出

| 输出名称 | 描述 | 数据类型 |
|----------|------|----------|
| `Y`      | Y 通道代表图像的亮度（亮度）。 | IMAGE |
| `U`      | U 通道代表蓝差色度分量。 | IMAGE |
| `V`      | V 通道代表红差色度分量。 | IMAGE |

输出图像将具有与输入图像相同的尺寸。
