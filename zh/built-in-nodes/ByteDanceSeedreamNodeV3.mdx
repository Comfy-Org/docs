ByteDance Seedream 4.5 与 5.0 可根据文本提示词生成图像（文生图），或在可选参考图像的引导下生成/编辑图像，使用 ByteDance Seedream 4.0、4.5 和 5.0 模型，分辨率最高可达 4K。此节点会将提示词和任何参考图像发送到 ByteDance API，等待生成任务完成，并返回生成的图像张量（一个或多个）。

### 参考输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |

**注意事项：**

- `prompt` 在去除空白字符后不能为空。
- 最大参考图像数量：Seedream 5.0 Pro、Seedream 4.5 和 Seedream 4.0 为 10；Seedream 5.0 Lite 为 14。
- 每张参考图像的宽高比必须在 1:3 到 3:1 之间。
- 当 `max_images` 大于 1 时（Seedream 5.0 Pro 不支持），参考图像数量加上生成图像总数不能超过 15。
- `thinking` 仅可在文生图生成时禁用。提供参考图像时，必须启用 `thinking`。
- 仅当 `size_preset` 设置为 "Custom" 时，才会使用 `width` 和 `height`。
- `prompt_optimization` 仅在 Seedream 5.0 Pro 上可用。
- `max_images` 和 `fail_on_partial` 仅在 Seedream 5.0 Lite、Seedream 4.5 和 Seedream 4.0 上可用；Seedream 5.0 Pro 始终只请求一张图像。
- 分辨率要求（宽 x 高）：
  - Seedream 5.0 Pro：介于 0.92MP（921,600 像素）和 4.19MP（4,194,304 像素）之间。
  - Seedream 5.0 Lite 和 Seedream 4.5：至少 3.68MP（3,686,400 像素）。
  - Seedream 4.0：至少 0.92MP（921,600 像素）。
  - 所有非 Pro 模型：最多 16.78MP（16,777,216 像素）。
