此节点使用 Bria 从图像中移除背景，并保留提示词所描述的内容。原始像素会以完整分辨率返回，并附带一个新的 alpha 通道，而不是被重新渲染，因此细节和边缘得以保留。如果提示词没有匹配到任何内容，则返回完全透明的图像。如果只需要单纯抠图而无需引导，使用 Bria Remove Image Background 成本更低。

## 输入

当 `moderation` 选择器设为 `"true"` 时，会显示额外的审核选项。

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image` | 要抠出的图像。 | IMAGE | 是 | - |
| `prompt` | 要保留的内容，并可选择指定要丢弃或缩小到范围的内容，例如 'the person with the mat and the plant'、'the woman at her desk without the lamp' 或 'only the chair'。不能为空。如果没有任何内容与提示词匹配，结果将完全透明。默认：`""`（空字符串）。 | STRING | 是 | 1 个字符或更多 |
| `moderation` | 审核设置。设为 `"true"` 时，下方的视觉审核开关即可用。 | DYNAMIC_COMBO | 是 | `"false"`<br />`"true"` |

### Moderation "true" 输入

这些参数仅在 `moderation` 设为 `"true"` 时出现。`"false"` 选项不会添加任何额外输入。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | 对输入图像启用内容审核。默认：`False`。 | BOOLEAN | 否 | True / False |
| `visual_output_moderation` | 对生成的图像启用内容审核。默认：`False`。 | BOOLEAN | 否 | True / False |

## 输出

| 输出名 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `image` | 抠出的图像：原始像素加上新的 alpha 通道。 | IMAGE |
