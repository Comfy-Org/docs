此节点使用 LTX 2.4 时长预测头，根据提示词预测自然镜头时长。它会将预测出的时长转换为符合 VAE 帧网格的帧数，并使用所提供的帧率以及最小/最大时长限制。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于预处理文本嵌入并运行时长预测头的模型。 | MODEL | 是 | 不适用 |
| `positive` | 为时长预测提供提示词文本嵌入和元数据的 conditioning。 | CONDITIONING | 是 | 不适用 |
| `duration_head` | 使用 ModelPatchLoader 加载的 LTX 2.4 时长预测头。必须是 LTX 时长预测头。 | MODEL_PATCH | 是 | 不适用 |
| `frame_rate` | 用于将秒转换为帧的帧率（帧/秒），默认值为 24.0。 | FLOAT | 是 | 1.0 至 120.0 |
| `min_seconds` | 将预测结果转换为帧数时使用的最小时长（秒），默认值为 1.0。 | FLOAT | 是 | 0.5 至 120.0 |
| `max_seconds` | 将预测结果转换为帧数时使用的最大时长（秒），默认值为 20.0。 | FLOAT | 是 | 0.5 至 120.0 |

注意：`duration_head` 输入必须是使用 ModelPatchLoader 加载的 LTX 2.4 时长预测头。如果连接的模型补丁不是 LTX 时长预测头，此节点将引发 ValueError。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `num_frames` | 将预测时长转换为帧数，并对齐到 VAE 的 8k+1 帧网格。 | INT |
| `seconds` | 原始（未裁剪）预测时长。这是对齐到帧网格之前的值。 | FLOAT |
