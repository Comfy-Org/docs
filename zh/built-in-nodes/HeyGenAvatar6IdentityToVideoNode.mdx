生成一段由 HeyGen 数字人（Avatar 6）出演的说话视频。选择一个支持 Avatar 6 的内置形象，或粘贴你自己的 HeyGen 形象 ID，然后用文本脚本或自己的音频来驱动它。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 模型选择器。`"heygen-avatar-6-turbo"` 是更便宜、更快的档位；两个模型接受相同的输入和分辨率。 | COMBO | 是 | `"heygen-avatar-6"`<br />`"heygen-avatar-6-turbo"` |
| `avatar` | 要展示的形象外观。直接列出 19 个支持 Avatar 6 的内置形象；`custom avatar` 会显示 `custom_avatar_id`，用于你在 HeyGen 中制作的形象。 | DYNAMIC_COMBO | 是 | 19 个内置形象<br />`custom avatar` |
| `speech` | 用文本脚本（HeyGen 文本转语音）或你自己的音频来驱动形象。显示名称：语音来源。 | DYNAMIC_COMBO | 是 | `"script"`<br />`"audio"` |
| `resolution` | 输出视频的分辨率。默认：`"1080p"`。 | COMBO | 是 | `"1080p"`<br />`"2k"` |
| `aspect_ratio` | 输出视频的宽高比。`"auto"` 跟随形象外观自身的素材。默认：`"auto"`。 | COMBO | 是 | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:5"`<br />`"5:4"` |
| `motion_prompt` | 用于指导手势、表情、姿态和镜头运动的可选提示。默认：空字符串。 | STRING | 是 | 多行文本 |
| `motion_expressiveness` | `"less"` 会产生更少、更小的手势。两者重叠时，motion prompt 优先。默认：`"default"`。 | COMBO | 是 | `"less"`<br />`"default"` |
| `seed` | 种子控制节点是否应重新运行；无论种子如何，结果都是不确定的。默认：42。 | INT | 是 | 0 到 2147483647 |

### `custom avatar` 输入

当 `avatar` 设为 `custom avatar` 时，会出现这些输入。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `custom_avatar_id` | 支持 Avatar 6 的 HeyGen 形象外观 ID，例如使用 HeyGen Create Avatar 制作的形象。默认：空字符串。 | STRING | 是 | - |

### `script` 语音输入

当 `speech` 设为 `"script"` 时，会出现这些输入。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `text` | 形象要朗读的文本。默认：空字符串。 | STRING | 是 | 最多 5000 个字符 |
| `voice` | 用于脚本的语音。默认选项使用 HeyGen 分配给该形象的语音；使用 HeyGen Create Avatar 制作的形象没有分配语音，因此需要为它们选择语音。 | COMBO | 是 | `"(avatar's default voice)"` 加上 HeyGen 的通用语音列表 |
| `custom_voice_id` | 可选的 HeyGen 语音 ID。设置后将覆盖上方选择的语音。默认：空字符串。 | STRING | 否 | - |
| `voice_speed` | 语音速度倍数。默认：1.0。 | FLOAT | 否 | 0.5 到 1.5（步长 0.05） |

### `audio` 语音输入

当 `speech` 设为 `"audio"` 时，会出现这些输入。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 供形象使用的语音。视频时长跟随音频。 | AUDIO | 是 | 0.5 秒到 10 分钟 |

**约束与行为：**

* `custom avatar` 需要非空的形象 ID，否则节点会报错。
* 脚本限制为 5000 个字符，音频限制为 10 分钟。
* 按输出视频的每秒时长计价，价格取决于模型和分辨率。
