Tripo: Retopology 接收由先前的 Tripo 节点生成的高多边形 3D 模型，并将其重建为具有干净拓扑的低多边形版本。它会将模型提交到 Tripo 重拓扑服务，等待任务完成，然后下载完成的模型，并暴露其任务 ID 以供其他 Tripo 节点使用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|------|------|----------|------|------|
| `model_task_id` | 源高多边形模型的任务 ID。接受来自 Tripo 生成节点的模型任务 ID，或来自 Tripo: Segment Model 的分割任务 ID。 | STRING | 是 | Tripo task ID |
| `face_limit` | 目标面数：500-20,000 个三角形或 500-10,000 个四边形。-1 表示让 Tripo 自行选择。（默认：-1） | INT | 是 | -1 (automatic)<br />500 到 20,000 (triangles)<br />500 到 10,000 (quads) |
| `quad` | 四边形网格输出。Tripo 以 FBX 格式提供四边形网格，因此结果会出现在 FBX 输出上，而 GLB 输出保持为空。（默认：False） | BOOLEAN | 是 | True<br />False (default) |
| `bake` | 将源纹理烘焙到低多边形网格上。（默认：True） | BOOLEAN | 否 | True (default)<br />False |
| `part_names` | 来自 Tripo: Segment Model 的逗号分隔部件名称。为空则处理整个模型。（默认：""） | STRING | 否 | 模型部件名称或留空 |

注意：当 `face_limit` 设置为 -1 时，Tripo 会自动决定面数。启用 `quad` 时，最大面数限制为 10,000 个四边形，而不是 20,000 个三角形，并且结果以 FBX 格式提供（GLB 输出保持为空）。当 `part_names` 为空时，将处理整个模型。如果 `face_limit` 不是 -1 且超出允许范围，节点会报错。

## 输出

| 输出名称 | 描述 | 数据类型 |
|----------|------|----------|
| `model_file` | 向后兼容的输出，用于标识已完成的模型文件。较新的工作流应改用 GLB 或 FBX 输出。 | STRING |
| `model task_id` | 完成的重拓扑结果的任务 ID。可传递给其他 Tripo 节点以引用此模型。 | STRING |
| `GLB` | 以 GLB 格式表示的重拓扑低多边形模型。启用 `quad` 时为空。 | GLB FILE |
| `FBX` | 以 FBX 格式表示的重拓扑低多边形模型。仅在启用 `quad` 时填充。 | FBX FILE |
