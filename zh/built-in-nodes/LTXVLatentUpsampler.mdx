LTXVLatentUpsampler 节点将视频 latent 表示的空间分辨率提高到两倍。它使用专用的放大模型处理 latent 数据，该数据首先会被反归一化，然后使用所提供的 VAE 的通道统计信息重新归一化。此节点专为 latent 空间中的视频工作流设计。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `样本` | 待放大的视频输入 latent 表示。 | LATENT | 是 |  |
| `放大模型` | 用于对 latent 数据执行 2 倍放大的已加载模型。 | LATENT_UPSCALE_MODEL | 是 |  |
| `vae` | 用于在放大前对输入 latent 进行反归一化，并在放大后对输出 latent 进行归一化的 VAE 模型。 | VAE | 是 |  |

注意：此节点在 ComfyUI 中标记为实验性。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `LATENT` | 放大后的 latent 表示，其空间维度是输入的两倍。输出 latent 的批次大小、通道数和时间长度与输入相同。输入中的 `noise_mask`（如果存在）会从输出中移除。 | LATENT |
