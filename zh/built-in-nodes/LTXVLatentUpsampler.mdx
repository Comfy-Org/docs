LTXVLatentUpsampler 节点将视频潜在表示的空间分辨率放大两倍。它使用专门的放大模型来处理潜在数据，首先取消归一化，然后使用所提供的 VAE 的通道统计信息重新归一化。此节点专为潜在空间内的视频工作流设计。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `样本` | 要放大的视频的输入潜在表示。 | LATENT | 是 |  |
| `放大模型` | 用于对潜在数据执行 2 倍放大的已加载模型。 | LATENT_UPSCALE_MODEL | 是 |  |
| `vae` | 用于在放大前对输入潜在变量进行反归一化，并在放大后对输出潜在变量进行归一化的 VAE 模型。 | VAE | 是 |  |

注意：此节点在 ComfyUI 中标记为实验性。

## 输出

| 输出名 | 描述 | 数据类型 |
| --- | --- | --- |
| `LATENT` | 放大后的潜在表示，其空间维度与输入相比加倍。输出潜在变量与输入具有相同的批次大小、通道数和时间长度。输入中的 `noise_mask`（如果存在）将从输出中移除。 | LATENT |
