Recraft V4 Text to Vector 节点可根据文本描述，使用 Recraft V4 和 V4.1 模型生成可缩放矢量图形（SVG）插图。它连接到 Recraft API，根据你的提示词生成一个或多个 SVG 文件，并可应用现有的矢量样式或根据参考图像创建新样式——使用参考图像时，创建的样式会以 `style_id` 形式返回，以便复用。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `model` | 用于生成的模型。recraftv4_styles 系列模型专为风格一致性生成而构建，始终需要 style_id 或 style_references。选择模型会改变可用的 `size` 选项。 | DYNAMIC_COMBO | 是 | `"recraftv4_1_vector"`<br />`"recraftv4_1_utility_vector"`<br />`"recraftv4_1_pro_vector"`<br />`"recraftv4_1_utility_pro_vector"`<br />`"recraftv4"`<br />`"recraftv4_pro"`<br />`"recraftv4_styles_vector"`<br />`"recraftv4_styles_pro_vector"` |

| `style_references` | 用于即时创建矢量样式的参考图像，在生成费用的基础上额外计费。创建的样式会以 style_id 形式返回，以便复用。不能与 `style_id` 同时使用。 | IMAGE | 否 | 可增长插槽：可连接 1..N 张参考图像（最多不超过节点的最大值） |
