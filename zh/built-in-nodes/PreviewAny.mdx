PreviewAny 可将任意输入值转换为可读文本，以便你进行检查。字符串会原样传递，数字和布尔值会变为纯文本，其他数据类型会尽可能序列化为 JSON（如果序列化失败，则回退为其普通字符串形式）。生成的文本会显示在用户界面中，同时也会作为 STRING 输出返回，以供进一步处理。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `源` | 接受任意输入数据类型用于预览显示。如果未提供值，预览会显示 'None'。 | ANY | 是 | Any data type |

**转换行为**

- STRING 类型的值会按提供的内容原样显示。
- INT、FLOAT 或 BOOLEAN 类型的值会转换为纯文本。
- 任何其他非空值都会转换为缩进为 4 个空格的 JSON 文本；如果该转换失败，节点会回退到该值的纯文本形式。如果这也失败，预览会显示消息 'source exists, but could not be serialized.'
- 如果未连接任何值，或者值为空，预览会显示 'None'。

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `result` | 转换为文本格式的输入值。相同文本也会显示在用户界面中。 | STRING |
