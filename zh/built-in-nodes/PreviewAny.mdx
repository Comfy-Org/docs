PreviewAny 可将任何输入值转换为可读文本，以便你进行查看。字符串会原样传递，数字和布尔值会转换为纯文本，其他数据类型则会在可能的情况下序列化为 JSON（如果序列化失败，则回退为其纯字符串形式）。生成的文本会显示在用户界面中，同时也会作为字符串输出返回，以供进一步处理。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
| --- | --- | --- | --- | --- |
| `源` | 接受任何输入数据类型以进行预览显示。如果未提供值，预览将显示 'None'。 | ANY | 是 | Any data type |

## 输出

| 输出名称 | 描述 | 数据类型 |
| --- | --- | --- |
| `result` | 已转换为文本格式的输入值。该文本同样会显示在用户界面中。 | STRING |
