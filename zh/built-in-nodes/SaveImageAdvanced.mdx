**Save Image (Advanced)** 节点将输入图像保存到您的 ComfyUI 输出目录，并可高级控制文件格式、位深度和色彩空间。它支持保存为 PNG、EXR 或 AVIF 文件（包括动画 AVIF），并可向保存的文件中嵌入工作流元数据。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `图像` | 要保存的图像。 | IMAGE | 是 | - |
| `文件名前缀` | 保存文件的前缀。可包含格式化标记，例如 `%date:yyyy-MM-dd%` 或 `%Empty Latent Image.width%`。（默认值："ComfyUI"） | STRING | 是 | - |
| `格式` | 保存图像的文件格式。选择某种格式会显示该格式的其他选项。 | DYNAMIC_COMBO | 是 | `"png"`<br />`"exr"`<br />`"avif"` |

### PNG 输入

当 `format` 设置为 `"png"` 时显示这些选项。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `bit_depth` | 保存的 PNG 文件的位深度。（默认值："8-bit"） | COMBO | 是（条件性） | `"8-bit"`<br />`"16-bit"` |
| `input_color_space` | 输入张量的色彩空间。PNG 格式仅支持 sRGB。（默认值："sRGB"） | COMBO | 是（条件性） | `"sRGB"` |

### EXR 输入

当 `format` 设置为 `"exr"` 时显示这些选项。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `bit_depth` | 保存的 EXR 文件的位深度。（默认值："32-bit float"） | COMBO | 是（条件性） | `"32-bit float"` |
| `input_color_space` | 输入张量的色彩空间。EXR 始终以匹配色域中的场景线性（scene-linear）写入。<br />`"sRGB"` — 输入为 sRGB 编码的 Rec.709；应用反向 sRGB EOTF。<br />`"HDR"` — 输入为 HLG 编码的 Rec.2020（BT.2100）；应用反向 HLG OETF 以获得场景线性光。<br />`"linear"` — 输入已经是场景线性（Rec.709 基色）；原样写入。用于渲染器/合成器输出。（默认值："sRGB"） | COMBO | 是（条件性） | `"sRGB"`<br />`"HDR"`<br />`"linear"` |

### AVIF 输入

当 `format` 设置为 `"avif"` 时显示这些选项。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `bit_depth` | 保存的 AVIF 文件的位深度。自动模式对 sRGB 使用 8-bit YUV420，对 HDR 使用 10-bit YUV420。（默认值："auto"） | COMBO | 是（条件性） | `"auto"`<br />`"8-bit YUV420"`<br />`"10-bit YUV420"` |
| `input_color_space` | 输入图像的色彩空间。HDR 选择 BT.2020/HLG，HDR PQ 选择 BT.2020/PQ。（默认值："sRGB"） | COMBO | 是（条件性） | `"sRGB"`<br />`"HDR"`<br />`"HDR PQ"` |
| `crf` | 值越低，质量越高，文件越大。（默认值：18） | INT | 是（条件性） | 1 到 63 |
| `save_mode` | AVIF 文件的保存模式。`"still images"` 将批次中的每张图像保存为独立的静态文件；`"animated"` 将整个批次保存为单个动画 AVIF 文件，并显示 `fps` 和 `loop_count`。（默认值："still images"） | DYNAMIC_COMBO | 是（条件性） | `"still images"`<br />`"animated"` |

### AVIF 动画选项

当 `save_mode` 设置为 `"animated"` 时显示这些选项。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |
| --- | --- | --- | --- | --- |
| `fps` | 动画的帧速率。（默认值：6.0） | FLOAT | 是（条件性） | 0.01 到 1000.0 |
| `loop_count` | 动画的循环次数。0 表示无限循环。（默认值：0） | INT | 是（条件性） | 0 到 1000 |

**参数依赖关系说明：**
- 特定格式的参数（`bit_depth`、`input_color_space`，以及 AVIF 的 `crf` 和 `save_mode`）仅在选择了特定 `format` 时可用。
- 对于 PNG 格式，仅支持 "8-bit" 和 "16-bit" 位深度，以及 "sRGB" 色彩空间。
- 对于 EXR 格式，仅支持 "32-bit float" 位深度，色彩空间为 "sRGB"、"HDR" 或 "linear"。
- 对于 AVIF 格式，`fps` 和 `loop_count` 仅在 `save_mode` 设置为 `"animated"` 时可用。
- PNG 和 EXR 图像必须具有 1（灰度）、3（RGB）或 4（RGBA）个通道；不支持其他通道数，否则会引发错误。
- AVIF 仅支持 1 通道灰度图像和 3 通道 RGB 图像；不支持 RGBA（alpha）图像，否则会引发错误。
