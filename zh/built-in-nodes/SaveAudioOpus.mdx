SaveAudioOpus 节点将音频数据保存为 Opus 格式文件，让您可以选择编码质量（比特率）以及导出文件的文件名前缀。此节点已弃用，并可能在将来的版本中移除。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `音频` | 要保存为 Opus 文件的音频数据。如果为 None（例如，当源视频没有音频轨道时），则会引发 ValueError。 | AUDIO | 是 | - |
| `文件名前缀` | 用于输出文件名的前缀（默认："audio/ComfyUI"）。 | STRING | 否 | - |
| `质量` | 用于编码 Opus 文件的比特率；值越高，质量越好，但文件越大（默认："128k"）。 | COMBO | 否 | `"64k"`<br />`"96k"`<br />`"128k"`<br />`"192k"`<br />`"320k"` |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `audio` | 已保存到 Opus 文件的音频数据。 | AUDIO |
