SaveAudioOpus 节点将音频数据保存为 Opus 格式的文件。它接收音频输入，并将其导出为具有可配置质量设置的压缩 Opus 文件。此节点已弃用，可能会在未来版本中移除。

## 输入

| 参数 | 描述 | 数据类型 | 是否必填 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `音频` | 要保存为 Opus 文件的音频数据。如果此值为 None（例如，源视频没有音轨时），将引发 ValueError。 | AUDIO | 是 | - |
| `文件名前缀` | 输出文件名的前缀（默认：`"audio/ComfyUI"`） | STRING | 否 | - |
| `质量` | 用于编码 Opus 文件的比特率；值越高，质量越好，但文件越大（默认：`"128k"`） | COMBO | 否 | `"64k"`<br />`"96k"`<br />`"128k"`<br />`"192k"`<br />`"320k"` |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `audio` | 已保存到 Opus 文件的音频数据 | AUDIO |
