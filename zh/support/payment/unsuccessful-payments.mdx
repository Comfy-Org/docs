如果 Comfy Cloud 付款失败，工作区订阅可能会暂停，直到未结清的发票结清。已购买的积分仍留在工作区。恢复流程从**计划与积分**开始：ComfyUI 不再显示单独的付款失败横幅。

## Comfy Cloud 付款失败时会发生什么

1. 已购买的积分仍留在工作区。余额用尽时，或工作区处于付款恢复状态时，运行会被拒绝。
2. 在欠费的工作区中，**计划与积分**里的积分不足横幅会提供**更新付款方式**；在未结清发票结清前，服务器会拒绝新的充值。此时点击**添加积分**会打开标题为**您的付款未成功**的付款恢复对话框，而不是充值流程。
3. 无法管理账单的工作区成员会被提示联系工作区所有者。

## 付款失败后如何更新付款方式

1. 访问 [cloud.comfy.org](https://cloud.comfy.org/?utm_source=docs) 并登录。
2. 通过档案菜单中的**管理订阅**，或通过**设置 → 工作区 → 计划与积分**打开**计划与积分**。
3. 点击积分不足横幅上的**更新付款方式**，或点击**账单与发票**打开 Stripe 账单门户。
4. 在 Stripe 中支付未结清的发票并更新付款方式，然后保存。

请参阅[编辑 Comfy Cloud 付款信息](/zh/support/payment/editing-payment-information)。

## 付款失败的常见原因

### 资金不足

- 您的卡片没有足够的可用余额或信用额度
- **解决方案**：添加资金或使用其他付款方式

### 卡片已过期

- 您的信用卡或借记卡已过有效期
- **解决方案**：使用有效卡片更新您的付款信息

### 信息不正确

- 卡号、CVV 或账单地址输入不正确
- **解决方案**：核实并更正您的付款详细信息

### 卡片被发卡机构拒绝

- 您的银行或发卡机构拒绝了交易
- **解决方案**：联系您的银行授权付款

### 国际限制

- 您的卡片不支持国际交易
- **解决方案**：启用国际付款或使用其他卡片

### 安全冻结

- 您的银行已将交易标记为可疑
- **解决方案**：联系您的银行验证并批准收费

## 防止未来付款失败

- 保持您的付款信息最新
- 确保您的卡片在账单日期之前有足够的资金
- 在到期之前更新您的卡片详细信息
- 请您的银行允许来自 Comfy Organization Inc 的收费

## 需要帮助？

如果您在尝试这些解决方案后仍遇到付款问题，请联系我们的[支持团队](https://support.comfy.org/)并提供：

- 您的账户电子邮件
- 您收到的报错信息
- 您尝试使用的付款方式
- 任何相关的交易 ID
