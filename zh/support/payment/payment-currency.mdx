Comfy Organization Inc 以多种货币处理付款。订阅价格默认以**美元（USD）**列出。

## 付款方式可用性

### 支付宝和微信支付

- **支付宝**支持本地 API 积分和 Comfy Cloud 订阅
- **微信支付**目前仅适用于本地 API 积分

两者均需使用 **USD** 支付。请参阅 [Comfy Cloud 接受的付款方式](/zh/support/payment/accepted-payment-methods)。

## 货币选择

您的付款货币通常由以下因素决定：

- 您的账户位置
- 您的账单地址
- 您的付款方式的默认货币

结账时，如需显示支付宝或微信支付选项，请选择 **USD**。

## 货币兑换

### 自动兑换

如果您的卡片货币与账单货币不同：

- 您的银行或发卡机构将自动兑换金额
- 兑换率由您的金融机构设定
- 可能会收取额外的货币兑换费

### 兑换费

- 货币兑换费由您的银行收取，而非 Comfy Organization Inc
- 这些费用通常为交易金额的 1-3%
- 请咨询您的银行了解具体的兑换费率

## 以您的货币查看费用

要查看以您当地货币计算的大致费用：

1. 查看您的银行或卡片对账单
2. 使用您银行的货币转换器
3. 请注意，汇率每天都在波动

## 更改您的账单货币

要更改现有订阅的账单货币，请联系我们的[支持团队](https://support.comfy.org/)并告知您偏好的货币。由于汇率原因，货币更改可能会影响收费金额。

## 按地区的价格差异

由于以下原因，订阅价格可能因地区而略有不同：

- 当地税收要求
- 货币汇率
- 区域定价调整

## 税费和增值税

根据您的位置，可能会收取额外费用：

- 销售税（美国客户）
- 增值税（欧洲客户）
- GST（澳大利亚、加拿大和其他适用地区）

这些税费根据您的账单地址计算，并添加到您的总额中。
