您在结账时看到的付款方式即为您所在地区和货币可用的付款方式。Comfy Organization Inc 通过 Stripe 处理付款。

## 信用卡和借记卡

我们接受以下主要信用卡和借记卡：

- Visa
- Mastercard
- American Express

## 数字钱包

您还可以使用数字钱包服务付款：

- Google Pay
- Link

## 其他付款方式

这些方法仅在您以**美元 (USD)** 付款时可用：

- **支付宝 (Alipay)**：本地 API 积分和 Comfy Cloud 订阅
- **微信支付 (WeChat Pay)**：仅限本地 API 积分

<Note>
微信支付和支付宝仅在特定地区可用。请查看 Stripe 文档中的 `Business locations` 部分，以确认您所在国家/地区的可用性：
- [Stripe 微信支付文档](https://docs.stripe.com/payments/wechat-pay#get-started)
- [Stripe 支付宝文档](https://docs.stripe.com/payments/alipay)
</Note>

要使用支付宝或微信支付，请在结账时选择**美元 (USD)** 作为付款货币。当这些选项在您所在地区可用时，它们会出现在付款方式列表中。

## 要求

要成功处理您的付款：

- 您的卡片必须有足够的资金或可用信用额度
- 您的账单地址必须与您的发卡机构存档的地址一致
- 接受国际卡，但您的银行可能会收取货币兑换费

## 安全性

Stripe 是 PCI 一级服务提供商，这是支付行业可获得的最严格认证级别。所有付款信息均使用行业标准加密技术安全处理。Comfy Organization Inc 不会在我们的服务器上存储您的完整卡详情。

## 付款处理

付款在订阅或续订时立即处理。付款成功处理后，您将收到确认电子邮件。

如果您在付款处理过程中遇到任何问题，请联系我们的[支持团队](https://support.comfy.org/)寻求帮助。
