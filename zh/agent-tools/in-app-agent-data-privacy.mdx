## 简要说明

Comfy Agent 会使用你的消息、已选择的工作流、已选择的节点以及附件。当你使用本地安装的 ComfyUI 时,聊天记录存储在该机器上。你的消息以及回答它所需的信息会通过 Comfy 的在线服务发送。

## Agent 使用的数据

| 数据 | 用途 |
| --- | --- |
| 你的消息 | 告诉 Agent 你想要做什么。 |
| 已选择的工作流和节点 | 指明你希望解释或修改哪个工作流和哪些节点。 |
| 图像附件 | 让 Agent 能够检查图像并在工作流中使用它。 |
| 视频或音频附件 | 让 Agent 能够读取媒体属性并提取或转换内容。 |
| 工作流和执行错误 | 帮助 Agent 解释并修复失败的工作流。 |
| 个人技能 | 提供可复用的指令。 |

[隐私政策](https://www.comfy.org/privacy-policy?utm_source=docs)和[服务条款](https://www.comfy.org/terms-of-service?utm_source=docs)约束你对 Comfy 的使用。

## 云端与本地的数据流

| 在哪里使用 Comfy Agent | 会发生什么 |
| --- | --- |
| **Comfy Cloud** | Comfy Cloud 存储对话、工作流和资产。你的消息由 Comfy 的在线服务处理,工作流在云端 GPU 上运行。 |
| **桌面版中的本地 ComfyUI** | 本地安装会存储聊天记录、工作流和文件。你的消息及相关工作流信息由 Comfy 的在线服务处理。本地工作流节点在你的硬件上运行;合作节点则使用其在线服务提供商。 |

## 聊天记录与同步

与云端 Agent 的对话存储在 Comfy Cloud 中。与本地 Agent 的对话存储在运行 ComfyUI 的机器上。这两份历史记录不会同步。这取决于你使用的是云端还是本地安装,而不是你在哪个应用程序窗口中打开它。

## 技能与引导

个人技能包含你为 Agent 创建的指令。它们会保存到你的账户,并在你的请求与之匹配或你明确指定它们时使用。

内置的 Agent 引导以及用于外部编码代理的技能,与你的个人 Agent 技能是分开的。

## 保留与删除

关于保留详情,请参阅[隐私政策](https://www.comfy.org/privacy-policy?utm_source=docs)和[数据保留](/zh/support/data-retention)。

如需申请账户或数据删除,请联系 [support@comfy.org](mailto:support@comfy.org)。
