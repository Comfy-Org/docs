**Comfy In-App Agent** 是 Comfy Cloud 中的智能体体验。在聊天中描述你的需求，智能体即可在你的图上构建或编辑工作流。

## 使用智能体

1. 在 Comfy Cloud 中打开一个工作流。
2. 在工作流栏中选择 **Ask Comfy Agent**。
3. 选择聊天要使用的工作流。无需访问节点图的问题，也可以选择 **Don't work in a workflow**。
4. 输入提示词。输入 `@` 引用节点，选择 **Add nodes from graph**，或附加图像、视频、音频文件、3D 模型或文本文件，为智能体提供更多上下文。
5. 查看建议的节点图更改和输出。智能体可能会出错，因此在运行工作流之前请检查它。

智能体会为你的每个工作流标签页保留独立的聊天。使用 **Chat history** 可以返回较早的对话、重命名对话，或将其复制为 Markdown。

## 运行权限

发送按钮旁的控件决定智能体何时可以运行工作流：

- **Ask before a workflow runs**：每次运行都需要你的批准。
- **Auto-run without approval**：智能体无需询问即可自动运行工作流。
- **Auto-run with limits**：仅在运行会超出你设定的积分限额时询问。

运行权限只影响执行，不影响编辑。智能体仍然可以修改选定的工作流。发送提示前，请检查此设置。

## 评价回复

在对话回合中，面板会显示智能体的进度以及它使用的工具。回复可以包含格式化文本、代码、已生成媒体、可下载资产，以及可打开工作流标签页的链接。

使用回复上的“点赞”或“点踩”控件即可评价回复。如需报告错误或分享更多细节，请使用下方的反馈链接。

## 当前 Alpha 版的边界

- 访问权限受功能开关控制，仅向选定的部分 Comfy Cloud 账户开放。
- 操作范围仅限于聊天中所选定的工作流。在请求编辑之前，请先检查工作流选择器。
- 智能体与人工编辑都可以更新同一个云端工作流，但大规模离线编辑，以及面向创作者的冲突解决界面，均不属于此次 Alpha 版的功能范围。
- 如果连接已中断，请先等待面板重新连接，再进行更多编辑。运行工作流之前，请先确认节点图的状态。
- 已停止或已中断的智能体回合不会自动恢复。如有需要，请开启一个新回合。
