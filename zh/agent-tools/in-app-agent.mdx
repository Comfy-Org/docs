</Note>

Comfy Agent 是 ComfyUI 中的助手。它可以构建和编辑工作流、解释节点、检查媒体、修复验证错误，并运行已完成的工作流。

## 加入候补名单

<Card title="加入内测候补名单" icon="list" href="https://links.comfy.org/agentalpha">
  申请获取 Comfy Agent 私密内测的访问权限。
</Card>

## 它可以做什么

- 查找你的 ComfyUI 环境中可用的模板、模型和节点。
- 基于模板构建工作流，并自定义其提示词和设置。
- 修改当前工作流的一部分，而无需重建其余部分。
- 添加、连接、配置和移除节点。
- 在运行之前验证工作流。
- 查看图像并读取视频或音频属性。
- 运行工作流并返回其输出。

## 你可以在哪里使用它

| 使用 Comfy Agent 的位置 | 预期情况 |
| --- | --- |
| **Comfy Cloud** | Agent、工作流和资产都使用你的 Comfy Cloud 账户。无需安装本地包。 |
| **Comfy Desktop** | Agent 与你机器上的 ComfyUI 安装配合使用，包括其工作流、模型和自定义节点。 |
| **网络连接** | Agent 的请求使用 Comfy 服务。请参阅[数据和隐私](/zh/agent-tools/in-app-agent-data-privacy)。 |

Comfy Agent 与 [Comfy MCP](/zh/agent-tools/mcp) 和 [Comfy CLI](/zh/agent-tools/cli) 是相互独立的。MCP 将外部 AI 客户端连接到 Comfy。CLI 用于终端和脚本工作流。Comfy Agent 在 ComfyUI 界面中工作。

要生成你的第一张图像，请按照[开始使用 Comfy Agent](/zh/agent-tools/in-app-agent-installation#制作你的第一张图像)操作。

## 选择要编辑的工作流

使用 Agent 面板中的工作流选择器选择要编辑的工作流，然后发送消息。在 Agent 响应期间切换到其他标签页不会重定向其编辑。

Agent 无法自行创建或切换标签页。若要在其他位置操作，请打开另一个工作流，在 Agent 面板中选择它，然后发送新消息。

Agent 可以读取另一个已打开或已保存的工作流用于比较，而无需将其加载到当前标签页。例如：

> 将此工作流与我的肖像工作流进行比较，并在此处使用相同的采样器设置。

## 构建和编辑工作流

对于新工作流，请打开一个空白工作流标签页，并在 Agent 面板中选择它。Agent 在从单个节点构建之前，会先搜索匹配的模板。模板包含一个连接式画面和一个输出节点。

若要修改现有工作流，请说明要更改的部分以及应保持不变的部分：

- “将提示词改为水彩风景。保留模型和采样器设置。”
- “在图像生成之后添加一个图像放大阶段。”
- “使用此处已安装的模型将此工作流切换为 Flux。”

## 运行前验证 {#validate-before-running}

Agent 会在运行前检查节点连接、模型名称、必填值以及输出节点。它会将工作流错误与只能由你提供的输入区分开来。

如果工作流有效但仍需要图像、视频或其他输入，请附加文件并让 Agent 继续。

## 处理媒体

Agent 可以检查静态图像的可见内容和尺寸。对于视频，它可以读取时长、尺寸、帧率和格式。对于音频，它可以读取时长、格式和音轨。

使用消息输入框中的 **附加文件** 来添加图像或文件。你也可以将媒体拖入对话。

| 添加到对话 | 提问 | 结果 |
| --- | --- | --- |
| 一张图像 | “描述这张图像中的光照。” | 一段可用于完善提示词的描述。 |
| 一个视频 | “将其裁剪为前五秒。” | 一个缩短后的视频文件。 |
| 两个视频片段 | “将片段 A 与紧随其后的片段 B 拼接。” | 一个按该顺序包含这两个片段的视频。 |
| 一个视频和一个音频文件 | “将此音频添加到视频中。” | 一个带有所提供音频的视频。 |

媒体编辑需要你的安装环境中具备媒体工具。在云端，编辑后的文件会保存到你的资产库。Agent 会在对话中返回预览或文件链接。

## 运行权限

在消息框旁边选择一个运行权限：

- **询问**：在每次运行工作流之前请求批准。
- **自动**：运行工作流时无需每次询问。

选择 **保存更改** 以应用你的选择。在询问模式下，选择审批消息中的 **运行** 以启动工作流，或选择 **取消** 以拒绝该次运行。

询问和自动用于控制工作流运行。在任一模式下，Agent 都可以编辑已选择的工作流。

## Agent 可以使用什么

Agent 会使用你的消息、已选择的工作流、已选择的节点、附件以及工作流错误。当你要求它比较或复用设置时，它还可以读取另一个工作流。

关于 Cloud 和本地数据流、聊天历史以及隐私控制，请参阅 [Comfy Agent 数据与隐私](/zh/agent-tools/in-app-agent-data-privacy)。

## 停止或取消

在消息框中点击 **Stop**，即可停止 Agent 当前的回复。工作流执行在[运行与队列区域](/zh/interface/overview)中有独立的控制项；若要管理已提交的工作流，请使用这些控件。
