## 什么是技能包？

技能包是一组可复用的指令，用于 Comfy Agent。每个技能包包含名称、一行说明触发时机的话，以及指令本身。

使用技能包可重复使用诸如“生成方形图像”“使用白色背景”或“运行前检查节点连接”之类的指令。

你创建的技能包只属于你的账户。当技能包的触发语句与你的请求匹配，或者你按名称请求该技能包时，Agent 会加载它。

## 在对话中创建技能

告诉 Agent 要保存什么、如何命名，以及何时使用：

> 将此保存为名为 product-shot 的技能：当我要求生成产品图像时，使用 1024 × 1024 的方形画布、中性灰色背景和一个 Save Image 节点。运行前验证工作流。

Agent 会保存该技能，供后续消息使用。新建或更新的技能会在你的下一条消息中生效。

## 使用技能

按名称请求技能：

> 使用我的 product-shot 技能，为一只红色运动鞋创建一个影棚照片工作流。

当触发语句与你的请求匹配时，Agent 也可以自动选择技能。要从列表里挑选，在输入框中输入 `/`，然后在菜单的 **Skills**（技能）分区中选择。

## 在设置中管理技能包

打开 **设置** → **技能包**，可以看到你账户中的所有技能包。每个技能包都会显示名称和大小。

- **添加技能包** 会打开新建表单。
- **编辑** 可修改已有技能包的触发语句或指令。技能包创建后无法改名。
- **删除** 会移除技能包，且无法撤销。

## 技能包字段

| 字段 | 作用 | 规则 |
| --- | --- | --- |
| **名称** | Agent 加载技能包时使用的标识。 | 最多 64 个字符，只能使用字母、数字、`.`、`_` 和 `-`。名称必须唯一，始终开启的内置技能包名称不可占用。 |
| **触发语句** | 一行说明何时加载该技能包。无论是否使用该技能包，它都会随每条消息一起发送。 | 单行，最多 1,024 个字符。请尽量简短。 |
| **指令** | 技能包加载后 Agent 遵循的内容。 | 必填。 |

## 体积限制

技能包列表会显示每个技能包的总字节大小。创建或编辑技能包时，表单会随输入显示指令的体积。所有技能包共同占用账户的体积额度。如果新技能包会超出额度，表单会拒绝保存，并提示你先删除一个技能包。

## 更新或删除技能

使用相同的技能名称来替换其指令：

> 将我的 product-shot 技能更新为使用白色背景和 1536 × 1536 的画布。

按名称删除技能：

> 删除我的 product-shot 技能。

## 保存现有的技能文件

将你的 `SKILL.md` 文件内容粘贴到对话中，并要求 Agent 将其保存为技能包。Agent 会从文件顶部的头部读取其名称和描述。保存的技能会在你的下一条消息中可用。

## 使用公共技能

公共技能是所有人均可使用的共享技能，而不只是你自己创建的技能。你可以按名称请求某个公共技能，也可以描述你想做的事情，Agent 会像使用你自己的技能一样使用它：

> 使用 product-shot 公共技能，制作一只位于中性灰色背景上的红色运动鞋。

## 内置引导与编码代理技能

Comfy Agent 包含用于构建工作流和选择模型的引导。技能包和公共技能会在该引导的基础上，为重复性任务添加指令。

[面向编码代理的技能](/zh/agent-tools/skills) 需要在 Claude Code 等工具中单独安装。在那里安装并不会将其添加到 Comfy Agent。

请勿在技能指令中包含 API 密钥、密码和访问令牌。关于数据处理，请参阅 [数据与隐私](/zh/agent-tools/in-app-agent-data-privacy#技能与引导)。
