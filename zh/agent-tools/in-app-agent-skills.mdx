## 什么是个人技能？

个人技能是一组可复用的指令，用于 Comfy Agent。它包含名称、一行说明（说明何时使用），以及指令本身。

使用个人技能可重复使用诸如“生成方形图像”“使用白色背景”或“运行前检查节点连接”之类的指令。

个人技能会保存到你的账户。当技能描述与你的请求匹配，或者你按名称请求该技能时，Agent 会加载它。

## 在对话中创建技能

告诉 Agent 要保存什么、如何命名，以及何时使用：

> 将此保存为名为 product-shot 的技能：当我要求生成产品图像时，使用 1024 × 1024 的方形画布、中性灰色背景和一个 Save Image 节点。运行前验证工作流。

Agent 会保存该技能，供后续消息使用。新建或更新的技能会在你的下一条消息中生效。

## 使用技能

按名称请求技能：

> 使用我的 product-shot 技能，为一只红色运动鞋创建一个影棚照片工作流。

当你的请求与其描述匹配时，Agent 也可以自动选择技能。

## 更新或删除技能

使用相同的技能名称来替换其指令：

> 将我的 product-shot 技能更新为使用白色背景和 1536 × 1536 的画布。

按名称删除技能：

> 删除我的 product-shot 技能。

## 保存现有的技能文件

将你的 `SKILL.md` 文件内容粘贴到对话中，并要求 Agent 将其保存为个人技能。Agent 会从文件顶部的头部读取其名称和描述。保存的技能会在你的下一条消息中可用。

## 内置引导与编码代理技能

Comfy Agent 包含用于构建工作流和选择模型的引导。个人技能可为你添加用于重复性任务的指令。

[面向编码代理的技能](/zh/agent-tools/skills) 需要在 Claude Code 等工具中单独安装。在那里安装并不会将其添加到 Comfy Agent。

请勿在技能指令中包含 API 密钥、密码和访问令牌。关于数据处理，请参阅 [数据与隐私](/zh/agent-tools/in-app-agent-data-privacy#技能与引导)。
