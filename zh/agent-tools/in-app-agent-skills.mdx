## 什么是个人技能？

个人技能是一组可复用的指令，用于 Comfy Agent。它包含名称、一行说明（说明何时使用），以及指令本身。

使用个人技能可重复使用诸如“生成方形图像”“使用白色背景”或“运行前检查节点连接”之类的指令。

个人技能会保存到你的账户。当技能描述与你的请求匹配，或者你按名称请求该技能时，Agent 会加载它。

## 在对话中创建技能

告诉 Agent 要保存什么、如何命名，以及何时使用：

> 将此保存为名为 product-shot 的技能：当我要求生成产品图像时，使用 1024 × 1024 的方形画布、中性灰色背景和一个 Save Image 节点。运行前验证工作流。

Agent 会保存该技能，供后续消息使用。新建或更新的技能会在你的下一条消息中生效。

## 在 Agent 面板中管理技能

消息框的 **+** 菜单里有一个**技能**子菜单，列出你的技能。选择一个即可将其附加到当前消息，也可以选择**管理技能**打开技能页面，在其中添加、编辑和删除技能。

![Agent 面板中的技能页面](/images/agent_tools/agent_skills_panel.png)

技能保存后名称不能修改；需要改名时，删除后重新添加。离开表单时如果没有保存，输入的内容会作为草稿保存在本机，直到你保存或丢弃。

## 技能字段

| 字段 | 作用 | 规则 |
| --- | --- | --- |
| **名称** | Agent 加载技能时使用的标识。 | 最多 64 个字符，只能使用 ASCII 字母、数字、`.`、`_` 和 `-`。名称必须唯一，始终加载的内置技能名称不可占用。 |
| **使用时机** | 一行说明何时加载该技能。无论是否使用该技能，它都会随每条消息一起发送。 | 单行，最多 1,024 个字符。请尽量简短。 |
| **指令** | 技能加载后 Agent 遵循的内容。 | 必填。 |

## 体积限制

列表会显示每个技能的字节大小。技能共同占用账户的体积额度，超出时表单会拒绝保存，并提示你先删除一个技能。

## 使用技能

按名称请求技能：

> 使用我的 product-shot 技能，为一只红色运动鞋创建一个影棚照片工作流。

当你的请求与其描述匹配时，Agent 也可以自动选择技能。要从列表里挑选，在输入框中输入 `/`，然后在菜单的**技能**分区中选择。

## 更新或删除技能

使用相同的技能名称来替换其指令：

> 将我的 product-shot 技能更新为使用白色背景和 1536 × 1536 的画布。

按名称删除技能：

> 删除我的 product-shot 技能。

## 保存现有的技能文件

将你的 `SKILL.md` 文件内容粘贴到对话中，并要求 Agent 将其保存为个人技能。Agent 会从文件顶部的头部读取其名称和描述。保存的技能会在你的下一条消息中可用。

## 使用公共技能

公共技能是所有人均可使用的共享技能，而不只是你自己创建的技能。你可以按名称请求某个公共技能，也可以描述你想做的事情，Agent 会像使用你自己的技能一样使用它：

> 使用 product-shot 公共技能，制作一只位于中性灰色背景上的红色运动鞋。

## 内置引导与编码代理技能

Comfy Agent 包含用于构建工作流和选择模型的引导。个人技能和公共技能会在该引导的基础上，为重复性任务添加指令。

[面向编码代理的技能](/zh/agent-tools/skills) 需要在 Claude Code 等工具中单独安装。在那里安装并不会将其添加到 Comfy Agent。

请勿在技能指令中包含 API 密钥、密码和访问令牌。关于数据处理，请参阅 [数据与隐私](/zh/agent-tools/in-app-agent-data-privacy#技能与引导)。
