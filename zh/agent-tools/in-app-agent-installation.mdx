## 选择你的安装方式

你需要一个拥有 Agent 访问权限的 Comfy 账户。如果你还没有访问权限，请[加入内测候补名单](https://links.comfy.org/agentalpha)。

- **Comfy Cloud：** [登录 Cloud](https://cloud.comfy.org)。无需本地安装。
- **Comfy Desktop：** 请按照 [Desktop 安装指南](/zh/installation/desktop/overview) 操作，然后登录。如果你已经安装过，请按照[更新 ComfyUI](/zh/installation/update_comfyui) 操作。

## 制作你的第一张图像

### 打开 Agent

打开一个空白工作流，然后在工作流栏中选择 **Ask Comfy Agent**。如有提示，请阅读并接受同意声明。在 Agent 面板中使用 **Choose a workflow** 选择该空白工作流。

### 构建工作流

发送以下消息：

> 构建一个文生图工作流，在纯灰色背景上生成一只红色运动鞋。使用可用的模型，并包含一个 Save Image 节点。检查工作流是否有错误，但先不要运行。

Agent 会在画布上构建工作流，填写提示词和模型设置，并检查节点连接和必填输入。你应该会看到一个以 **Save Image** 节点结尾的连接式工作流。

如果 Agent 报告模型或文件缺失，请提供该模型或文件，或要求改用你当前安装中可用的替代方案。在继续之前，请它再次检查工作流。

### 生成图像

打开消息框旁边的 **Run permissions**，选择 **Ask**，如果你更改了该设置，请选择 **Save changes**。

发送“运行此工作流。”当 Agent 请求批准时，选择 **Run**。如果你不想启动该次运行，请改为选择 **Cancel**。

生成完成后，Agent 会在对话中返回输出。图像也会出现在 **Save Image** 节点中。在那里右键点击图像，即可将其保存到你的电脑。

### 进行修改

发送“把背景改为白色，并保留模型和其他设置。”Agent 会更新现有工作流。请它再次运行，以比较结果。

## 故障排除

### Agent 按钮缺失

登录你的 Comfy 账户。在 Comfy Desktop 中，[更新应用程序](/zh/installation/update_comfyui)并重新启动它。如果按钮仍然缺失，请通过[支持](/zh/support/contact-support)检查你账户的 Agent 访问权限。

### Agent 无法编辑我预期的工作流

在 Agent 面板中选择目标工作流，然后重新发送你的消息。参见[选择要编辑的工作流](/zh/agent-tools/in-app-agent#选择要编辑的工作流)。

### Agent 要求提供输入

选择 **Attach a file**，或将请求的文件拖入消息框，然后让 Agent 继续。

### 我在云端找不到本地对话

本地和云端历史记录是分开的。参见[数据与隐私](/zh/agent-tools/in-app-agent-data-privacy#聊天记录与同步)。
