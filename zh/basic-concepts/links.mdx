## 连线连接节点

在 ComfyUI 中，节点之间绘制的线或曲线称为**_连线_**（也称为**_连接_**或线缆）。它们将数据从一个节点的输出传递到另一个节点的输入，从而定义工作流的数据流。

下文中的每种操作都针对同一个对象：节点边缘上的彩色圆形。输出位于右边缘，输入位于左边缘。

### 连接两个节点

从输出端口拖动到颜色相同的输入端口。拖动时兼容端口会高亮，释放后连线会自动吸附到输入端口。

<video

  className="w-full aspect-video"
  src="/images/basic-concepts/links/connect-two-nodes.mp4"
></video>

只有颜色相同的端口才能连接，因为颜色代表数据类型。请参见[颜色编码](#颜色编码)。

### 将连线放到画布空白处

将连线释放到画布空白处，添加节点搜索会打开，并已按你当前携带的数据类型进行筛选。选择节点后，会创建该节点并自动连接。

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/release-on-empty-search.mp4"
></video>

![按当前携带的数据类型筛选的添加节点搜索](/images/basic-concepts/links/add-node-search.png)

释放时按住 `Shift`，则会改为打开上下文菜单：**添加节点**、**添加重新路由**、**搜索**，以及接受该数据的节点类型。

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/release-shift-context-menu.mp4"
></video>

![按住 Shift 释放连线时的上下文菜单](/images/basic-concepts/links/release-context-menu.png)

这两种释放行为均可在 **设置 → 画面 → 释放链接** 中配置：一个条目用于普通释放，另一个用于 `Shift`。

### 隐藏或删除连线

右键点击连线可打开其菜单：

- **隐藏连线**会保留连接，仅隐藏线缆，因此数据仍会流动
- **删除**会移除连接
- **添加重新路由**会在连线上放置一个重新路由点
- **添加节点**会将节点插入到连线中

![连线上下文菜单](/images/basic-concepts/links/link-menu.png)

### 隐藏所有连线

画布工具栏中的连线可见性开关可一次隐藏所有线缆，而不会更改工作流。这等同于将 **连线渲染样式** 设为 **隐藏**，再次开启后会恢复上一个样式。

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/hide-links.mp4"
></video>

<Tip>
在学习、分享或调试工作流时，显示连线尤其有用。它们能让数据流一目了然。对于不打算编辑的已完成工作流，隐藏连线可以减少视觉杂乱。
</Tip>

### 重新路由连线

当工作流变得复杂时，线缆会重叠，或从节点后方穿过。连线菜单中的 **添加重新路由** 会在线缆上放置一个原生重新路由点；将该点拖到任意位置，即可让线缆绕开其他节点。

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/link-menu-reroute.mp4"
></video>

ComfyUI 还内置了 **重新路由** 节点，它通过一个显式节点完成相同的工作，你可以将该节点放入组中、绕过它或复用它。对于新建工作流，原生重新路由点已经足够。

![ComfyUI 重新路由节点](/images/interface/link/reroute.jpg)

## 连线渲染样式

连线可以绘制为曲线、直角折线、直线，或完全隐藏。

![连线样式](/images/interface/link/link_styles.jpg)

在 **设置 → 画面 → 画面 → 连线渲染样式** 中更改样式，或从画布工具栏切换连线可见性。

![渲染样式设置](/images/interface/link/render_mode.jpg)

## 颜色编码

ComfyUI 中的每种数据类型都有各自独特的颜色。节点输入与输出端口以及连接它们的连线，都遵循这套配色方案。**你只能连接颜色相同的端口**。这保证了整个工作流中的类型安全。

![ComfyUI 节点数据类型](/images/concepts/node/data_type.jpg)

| 数据类型           | 颜色   |
|-------------------|--------|
| Diffusion model   | 淡紫色 |
| CLIP model        | 黄色   |
| VAE model         | 玫瑰色 |
| Conditioning      | 橙色   |
| Latent Image      | 粉色   |
| Pixel image       | 蓝色   |
| Mask              | 绿色   |
| Number (integer or float) | 灰色 |
| Mesh              | 亮绿色 |
