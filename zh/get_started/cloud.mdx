## 什么是 Comfy Cloud？

ComfyUI Cloud 是 ComfyUI 的云端版本，具备与本地版本相同的功能。一切都已预装并可立即使用。

## 云端版本 vs 本地版本

ComfyUI 同时提供官方云端版本 [Comfy Cloud](https://comfy.org/cloud) 和开源自托管版本。如果你拥有强大的 GPU，在本地运行 ComfyUI 是一个很好的选择。而云端版本则是一项开箱即用的在线服务：只需打开 URL，无需安装或配置。

| 类别 | Comfy Cloud | 自托管（本地 ComfyUI） |
|------|-------------|----------------------|
| **成本** | 免费套餐与付费订阅方案 | 免费 |
| **GPU** | 强大的 Blackwell RTX 6000 Pro | 自备 GPU |
| **技术知识** | 无需技术知识。 | 桌面版和便携版提供了简单的入门方式，但你仍需要对自定义节点安装和本地安装问题进行故障排除。 |
| **自定义节点** | 使用预装的自定义节点，无需担心兼容性问题。 | 可安装任何你想要的自定义节点，但需要自行管理。 |
| **模型** | 使用预装模型。可从 Civitai 和 Hugging Face 导入模型。 | 可使用任何你想要的模型，但需要先下载。 |
| **显著差异** | 可通过[工作区](/zh/cloud/workspace)轻松让团队上手 | 可离线工作，无限可定制 |
| **开始使用** | [运行 ComfyUI Cloud](https://comfy.org/cloud) | [本地安装 ComfyUI](/zh/installation/system_requirements) |

## 如何使用 ComfyUI Cloud 

使用 ComfyUI Cloud 基本和你的本地 ComfyUI 使用方式相同，如果你是第一次使用 ComfyUI，这里有一些快速入门提示：

<Steps>
  <Step title="选择一个模板">
    点击左侧边栏的模板图标以浏览可用的工作流。
    ![打开工作流模板](/images/cloud/open_template.webp)
  </Step>
  
  <Step title="选择你要运行的工作流">
    点击你想要运行的模板
    ![选择工作流模板](/images/cloud/template_library.webp)
  </Step>
  
  <Step title="更新模板的输入">
    1. 在加载的工作流中，由于在云端版本中我们已经预置了所有的模型，所有模板都是加载后即可使用点击运行。
    2. 如果需要更新，你只需要提供图像输入或文本提示词部分，检查 `Load Image` 节点或 `CLIP Text Encode` 节点。
    ![检查输入](/images/cloud/workflow_input_or_loader.webp)
  </Step>
  
  <Step title="运行你的工作流">
    如果一切正确，点击 "Run" 图标或使用快捷键 "Ctrl + Enter" 运行工作流。
    ![运行工作流](/images/cloud/workflow_run_workflow.webp)
  </Step>

  <Step title="查看输出">
    点击运行后，我们的服务会开始为你的工作流分配机器，你可以在队列面板中查看该工作流的执行状态。
    ![查看队列](/images/cloud/workflow_check_queue.webp)
  </Step>

  <Step title="保存内容到本地">
    在工作流执行完成后，你可以将生成的内容保存到本地。根据不同的素材类型，保存方式如下：
    
    <Tabs>
      <Tab title="保存图片">
        在队列面板或者保存图像节点上使用右键点击生成的图片，选择"保存图片"即可将图片保存到本地。
        
        ![保存图片素材](/images/cloud/download_image_assets.jpg)
      </Tab>
      
      <Tab title="保存视频">
        在队列面板或者保存视频节点上：
        1. 点击浏览器播放组件的三个点，点击打开菜单
        2. 选择"下载"即可将视频保存到本地。
        
        ![保存视频素材](/images/cloud/download_video_assets.webp)
      </Tab>
      
      <Tab title="保存音频">
        在队列面板或者保存音频节点上：
        1. 点击浏览器播放组件的三个点，点击打开菜单
        2. 选择"下载"即可将音频保存到本地。        
        ![保存音频素材](/images/cloud/download_audio_assets.webp)
      </Tab>
      
      <Tab title="保存3D素材">
        在 3D 浏览器节点的菜单中选择 “Export” 选项，选择你想要保存的格式即可将3D文件保存到本地。
        
        ![保存3D素材](/images/cloud/download_3d_assets.webp)
      </Tab>
    </Tabs>
  </Step>
</Steps>

### 如何停止/退出 Comfy Cloud

云端会话仅在 GPU 运行时计费。关闭浏览器标签页即可自动停止会话，你可以随时关闭，就像关闭普通浏览器标签页一样。
