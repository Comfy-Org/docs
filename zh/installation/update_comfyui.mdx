## 如何更新 ComfyUI？

<Tabs>
<Tab title="便携版">
 ComfyUI 便携版提供了便捷的批处理脚本，可轻松完成更新。

 ### 更新脚本位置
 在便携版安装目录下的 `update` 文件夹中，可以找到以下更新脚本：

 ```
 ComfyUI_windows_portable
 └─ 📂update
    ├── update.py
    ├── update_comfyui.bat                           // 更新到最新开发版本
    ├── update_comfyui_stable.bat                    // 更新到最新稳定版本
    └── update_comfyui_and_python_dependencies.bat   // ⚠️ 危险：重装依赖，可能导致冲突
```
<Warning>更新过程中请保持网络连接稳定。</Warning>

<Warning>
**⚠️ 危险：请极其谨慎地使用 `update_comfyui_and_python_dependencies.bat`！**

这个脚本比普通更新更彻底，它会：
- ✅ 更新 ComfyUI 代码本身
- ✅ 为**标准 Nvidia 便携包**更新 PyTorch（当前为 **CUDA 13.0 / cu130**，Python 3.13）
- ✅ 重新安装所有 Python 依赖

**传统 Nvidia 便携包（CUDA 12.6 / cu126）：** 如果你安装的是面向 Nvidia **10 系及更早 GPU** 的单独便携包，该构建使用 **CUDA 12.6** 和 Python 3.12。请勿将 cu130 视为该包的正确目标：请使用与该便携包匹配的 cu126 wheel 索引重装或更新 PyTorch，或从 [便携版安装指南](/zh/installation/comfyui_portable_windows) 重新下载 cu126 包。

**风险：**
- 可能与现有配置产生依赖冲突
- 可能破坏依赖特定包版本的自定义节点
- 可能覆盖手动配置的包
- 在 cu126（或其他非 cu130）便携包上，盲目强制使用 cu130 wheel 可能导致 GPU 无法启动

**⚠️ 仅在以下情况下使用此脚本：**
- 需要修复依赖问题时
- 进行大版本更新时
- 日常更新时，请改用 `update_comfyui.bat`

**运行此脚本前：**
1. **备份整个 ComfyUI 安装目录**
2. 记录已安装的任何自定义包版本
3. 确认你使用的是哪种便携包（cu130 标准版还是 cu126 传统版）：参见 [Windows 版 ComfyUI 便携版](/zh/installation/comfyui_portable_windows)
4. 做好在需要时重装自定义节点的准备
</Warning>

### 更新前要求
确保系统已安装 [Git](https://git-scm.com/downloads)，并且 ComfyUI 是通过 Git 克隆安装的。

### 更新步骤
<Steps>
<Step title="激活虚拟环境">
首先，激活 ComfyUI 的 Python 虚拟环境（如果使用虚拟环境）：
```bash
# 对于 conda 环境
conda activate comfyui

# 对于 venv 环境
# Windows
venv\Scripts\activate
# macOS/Linux  
source venv/bin/activate
```
</Step>
<Step title="拉取最新代码">
进入 ComfyUI 安装目录并拉取最新代码：
```bash
cd <ComfyUI-installation-path>
git pull
```
</Step>
<Step title="更新依赖">
安装或更新 ComfyUI 的依赖包：
```bash
pip install -r requirements.txt
```
<Warning>
请确保当前处于 ComfyUI 的虚拟环境中，避免污染系统级 Python 环境
</Warning>
</Step>
<Step title="重新启动 ComfyUI">
更新完成后，重新启动 ComfyUI：
```bash
python main.py
```
</Step>
</Steps>

### 切换版本（可选）
如需切换到特定版本，请使用以下命令：
```bash
# 查看提交历史
git log --oneline

# 切换到特定提交
git checkout <commit-hash>

# 返回最新版本
git checkout master
```
<Tip>建议定期更新，以获得最新功能和安全修复；同时推荐使用稳定版本，以确保系统稳定性。</Tip>

## 在更新 ComfyUI 时都需要更新什么内容？

ComfyUI 的更新主要包含两个部分：
1. 更新 ComfyUI 的核心代码
2. 更新 ComfyUI 的核心依赖，包括必要的 Python 依赖和 ComfyUI 功能依赖包

**核心代码**：新增节点、新增模型支持、新增功能等。
**核心依赖**：主要包括 ComfyUI 的前端功能、工作流模板、节点帮助文档等。

```
comfyui-frontend-package   # ComfyUI 前端功能
comfyui-workflow-templates # ComfyUI 工作流模板  
comfyui-embedded-docs      # ComfyUI 节点帮助文档
comfy-kitchen              # ComfyUI 核心实用工具
comfy-aimdo                # ComfyUI 核心实用工具
```

这些核心依赖分别维护在独立仓库中：
- [ComfyUI_frontend](https://github.com/Comfy-Org/ComfyUI_frontend/) - 前端界面与交互功能
- [workflow_templates](https://github.com/Comfy-Org/workflow_templates) - 预置工作流模板
- [comfyui-embedded-docs](https://github.com/Comfy-Org/embedded-docs) - 节点帮助文档
- [comfy-kitchen](https://github.com/Comfy-Org/comfy-kitchen) - 支持多种计算后端的 Diffusion 推理快速内核库
- [comfy-aimdo](https://github.com/Comfy-Org/comfy-aimdo) - AI 模型按需卸载分配器

需要理解开发版本（nightly）与稳定版本（release）之间的区别：
- **开发版本（nightly）**：包含最新 commit 的代码，可让你体验最新功能，但可能存在潜在问题
- **稳定版本（release）**：基于稳定版本构建，通常滞后于开发版本，但稳定性更高。我们会在功能经过测试并稳定后对稳定版本提供支持

许多用户在更新时发现自己使用的是 release 版本，或桌面版默认的 **稳定版** 频道，但发现所需功能只在开发版 / nightly 构建中提供。**桌面版**用户可在 [管理 → 更新](/zh/installation/desktop/usage/instance-management#更新-comfyui) 中切换到 **GitHub 最新版**。便携版或手动安装的用户，请检查本地 `ComfyUI/requirements.txt` 是否与 [nightly 版本的依赖项](https://github.com/Comfy-Org/ComfyUI/blob/master/requirements.txt) 一致，以确定所有依赖是否都支持最新功能。

## 常见更新问题

### 更新后前端、工作流模板或节点缺失或过时


<Tabs>
  <Tab title="依赖关系未正确更新">
    用户常常只使用 `git pull` 指令来更新 ComfyUI 代码，却**忽略了核心依赖关系的更新**，从而导致以下问题：

  - 前端功能缺失或异常
  - 无法找到新增的工作流模板
  - 节点帮助文档过时或缺失
  - 新功能缺少相应的前端支持

  使用 `git pull` 指令之后，请在使用对应的 ComfyUI 环境时通过 `pip install -r requirements.txt` 来更新依赖项。
  </Tab>
  <Tab title="依赖关系更新失败">
    如果依赖关系更新失败，通常是由网络或计算机权限问题导致的。当更新过程中出现核心依赖关系失败时，系统会回退到旧版本。你通常会在启动时看到如下日志：
    ```
    Falling back to the default frontend.
    ComfyUI frontend version: xxx
    ```

    请按以下排查步骤操作：
    1. 在对应的环境中使用 `pip list` 查看当前已安装的依赖包。如果发现版本不一致，请在 ComfyUI 环境中使用 `pip install -r requirements.txt` 再次尝试更新依赖关系。
    2. 如果更新之后问题仍然存在，请检查网络连接。中国大陆的用户可能需要配置代理才能稳定访问 GitHub 仓库。
    3. 如果问题依旧，请检查计算机权限。如果需要管理员权限，请以管理员身份运行命令行。
  </Tab>
</Tabs>

### 如何正确更新核心依赖关系

### 核心依赖项更新问题排查 {#core-dependency-update-troubleshooting}

如果核心依赖项更新失败，请按以下排查步骤操作：

<Steps>
  <Step title="检查网络连接">
    如果您位于中国大陆，请确保能够访问 PyPI，或配置国内镜像源：
    ```bash
    # 使用清华大学镜像源
    pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
    ```
  </Step>
  <Step title="逐个安装核心包">
    如果批处理安装失败，请尝试逐个安装软件包。**首先检查 `ComfyUI/requirements.txt` 中的版本要求**：
    
    **然后按照指定的版本进行安装（使用您 requirements.txt 中的版本号）：**
    ```bash
    pip install comfyui-frontend-package==<version> 
    pip install comfyui-workflow-templates==<version>
    pip install comfyui-embedded-docs==<version>
    pip install comfy-kitchen==<version>
    pip install comfy-aimdo==<version>
    ```
    <Warning>
    推荐使用 `ComfyUI/requirements.txt` 中指定的确切版本号。请勿单独升级到最新版本，否则可能导致兼容性问题。
    </Warning>
  </Step>
</Steps>

### 更新后为什么找不到新功能？

这是最常见的问题之一：
- 如果你在 **稳定版** 更新通道上使用 **桌面版**，功能可能会落后于较新的 GitHub 提交。需要较新的功能时，请在[管理 → 更新](/zh/installation/desktop/usage/instance-management#更新-comfyui)标签页中将通道切换为 **GitHub 最新版**（最新版可能不太稳定）。
- 对于便携版或手动安装，在需要最新提交时，请确保你使用的是**开发版本（每夜版）**，而不是**稳定版本（发行版）**。

此外，请确保在更新过程中已成功更新相应的依赖关系。如果更新后问题仍然存在，请参阅[依赖关系更新故障排除](#常见更新问题)一节来诊断问题。

### 如何在开发版（每夜版）和稳定版（发布版）之间切换？

版本之间的差异：

<Tabs>
  <Tab title="开发版（每夜版）">
    - **特点**：包含最新的提交代码
    - **优势**：第一时间体验最新功能和改进
    - **风险**：可能包含未被发现的 bug 或不稳定因素
    - **适合人群**：开发者、测试人员、希望体验最新功能的用户
  </Tab>
  <Tab title="稳定版（发布版）">
    - **特点**：经过测试和验证的稳定代码
    - **优势**：稳定性高，适合生产环境
    - **劣势**：功能更新有延迟，可能落后开发版数周或数月
    - **适合人群**：对稳定性有要求的用户、生产环境用户
  </Tab>
</Tabs>

<Tabs>
  <Tab title="便携版">
    使用 `update_comfyui.bat` 代替 `update_comfyui_stable.bat`：
    ```
    # 开发版（最新功能）
    double-click: update_comfyui.bat
    
    # 稳定版
    double-click: update_comfyui_stable.bat
    ```
  </Tab>
  <Tab title="手动安装">
    ```bash
    # 切换到开发版
    git checkout master
    git pull
    
    # 切换到最新稳定版
    git fetch --tags
    git checkout $(git describe --tags `git rev-list --tags --max-count=1`)
    ```
  </Tab>
  <Tab title="桌面版">
    打开[管理面板](/zh/installation/desktop/usage/instance-management#更新-comfyui)，使用更新标签页切换通道：
    - **Stable**（默认）：经过测试的发布版本，可能落后于较新的 GitHub 提交
    - **Latest on GitHub**：跟踪 GitHub 上较新的提交；稳定性可能较低

    根据所选通道是否有更新的构建版本，使用**切换通道**、**立即更新**或**复制并更新**。详情请参阅[管理更新标签页](/zh/installation/desktop/usage/instance-management#更新-comfyui)页面。
  </Tab>
</Tabs>

### 更新后出现错误时该怎么办？

1. **检查依赖关系**：运行 `pip install -r requirements.txt` 以确保所有依赖项均已更新
2. **检查自定义节点**：部分自定义节点可能与新版本不兼容
3. **回滚版本**：如果问题较为严重，可以回滚到上一个稳定版本

如果出现问题，请参阅我们的故障排除页面以获取解决方案。
