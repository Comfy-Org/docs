**Comfy Desktop** 是一个桌面应用，让你从一个启动器中安装、管理和启动多个 ComfyUI 安装。

简单来说：**Comfy Desktop** 是管理并启动 **ComfyUI**（基于节点的生成式 AI 引擎）的应用。你不用单独安装 ComfyUI — Comfy Desktop 会自动处理安装、Python 环境和依赖。每个 ComfyUI 实例独立运行，拥有自己的版本、自定义节点和设置。

![Desktop 截图](/images/desktop/usage/01-homepage.png)

Comfy Desktop 支持 **Windows 10+**、**macOS 13+（Apple Silicon）** 和 **Linux**（官方 `.deb` 和 AppImage 安装包）。每个独立安装需要至少 **4.85 GB** 磁盘空间和 **8 GB 内存（推荐 16 GB）**。详细要求请查看各平台安装页面。

## 首次启动

首次打开 Comfy Desktop 时，会显示一个全屏初始化流程，询问**你想如何运行 Comfy？**，并在写入任何文件之前收集所需的选择。完成之前窗口会一直停留在这个流程中：如果你中途关闭应用，下次启动时会再次显示同一屏幕。

### 云端还是本地

两张卡片对应两种运行 ComfyUI 的方式：

- **云端**：ComfyUI 运行在 Comfy Cloud 的 GPU 上。本机不安装任何内容，也无需下载。有免费 Cloud 运行次数可用时，卡片上会显示 **免费试用** 标签。
- **本地**：在本机安装 ComfyUI。你可以控制 ComfyUI 版本、自定义节点和启动参数，并且可以离线运行。

如果 Comfy Desktop 检测到本机 GPU 不足以流畅运行大多数工作流，云端卡片会显示 **推荐用于你的硬件** 标记，并且两张卡片都不会被默认选中，让选择由你主动做出。未选中卡片前，**继续** 按钮不可用。

### 条款与数据共享

卡片下方有三个复选框：

- **我同意 EULA 和 服务条款**：必选。链接可打开 EULA、服务条款和隐私政策。每次运行此流程时都必须勾选此项，否则**继续**不会生效。
- **通过分享匿名使用数据帮助改进 Comfy**：可选，默认勾选。Comfy Desktop 只发送匿名使用数据，绝不会收集工作流内容、提示词、生成的媒体或个人身份信息。之后可在 [桌面设置](/zh/installation/desktop/usage/settings) 中更改。
- **加入 Beta 功能测试，帮助我们打磨新功能**：可选，默认勾选，仅在开启数据共享时可用。关闭数据共享会同时取消勾选此项。

### 快速安装

选择**本地**时，会出现 **使用推荐设置快速安装** 复选框。它默认未勾选，因此安装向导会先显示 ComfyUI 版本、安装位置和启动选项，再写入任何文件。勾选它可跳过该步骤，直接以推荐设置安装一个 Standalone 实例。勾选后 Comfy Desktop 会在复选框下方标出检测到的硬件，如果检测到的 GPU 不是你想要的，可以取消勾选。

### 迁移已有安装

如果 Comfy Desktop 在机器上发现 Legacy Desktop 安装，**迁移现有实例** 复选框会出现在快速安装旁边，并默认勾选。保持勾选即可在继续时把工作流、模型和设置一并迁移过来，迁移内容见 [从旧版迁移](/zh/installation/desktop/usage/migrate)。取消勾选则会全新安装一个实例。两个复选框都取消勾选时，Comfy Desktop 会在开始安装前再询问一次：选择 **迁移** 可以把 Legacy Desktop 安装迁移过来，选择 **全新开始** 则安装一个干净实例，原有项目留在原处。

### 中国镜像

当应用界面为中文时，此流程会在点击**继续**后追加一个问题：**启用中国镜像？** 选择 **启用镜像** 会让 Git 仓库从 `gitcode.com` 克隆、PyPI 包从阿里云和腾讯云镜像获取，而不是 `github.com` 和 `pypi.org`，在中国大陆速度更快。选择 **暂不** 则保留默认设置。无论选择哪一个，结果都会保存为 **使用中国镜像（Git 和 PyPI）** 设置，之后可以随时更改。

### 完成之后

**继续** 会保存你的选择，并短暂显示 **正在准备安装…**。

- **云端**：Comfy Desktop 关闭此流程并启动 Comfy Cloud。
- **本地**：除非勾选了快速安装，否则会进入安装向导；安装过程会显示进度，完成后实例会出现在 Dashboard 上。

如果 Comfy Desktop 已有独立安装、追踪安装或远程安装，它会跳过云端与本地的选择，在你同意条款后直接进入 Dashboard。每次运行此流程都需要重新同意条款。

此流程是全屏接管的：显示期间标题栏会被锁定；离开同意条款这一步后，应用菜单（☰）会缩减为唯一的 **跳过引导** 项，点击即可关闭引导并直接进入 Dashboard，不安装任何内容。
