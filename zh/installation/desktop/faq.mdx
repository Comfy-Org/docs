## 常规问题

<Accordion title="Comfy桌面版和传统桌面版有什么区别？">
Comfy桌面版是一次完全重写，充当**多安装管理器**。传统桌面版（Legacy Desktop）是单一安装的应用，而 Comfy桌面版允许你并行安装、管理和运行多个 ComfyUI 版本。它还增加了快照和模型下载管理功能。

传统桌面版的用户请查看[迁移指南](/zh/installation/desktop/usage/migrate)，以迁移现有设置。
</Accordion>
<Accordion title="Comfy桌面版是开源的吗？">
是的。源代码位于 [GitHub](https://github.com/Comfy-Org/Comfy-Desktop)。Comfy桌面版采用双重许可证：[AGPL-3.0-or-later](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/LICENSE)，或 Comfy Org 提供的商业许可证（`licensing@comfy.org`）。
</Accordion>
<Accordion title="Comfy桌面版会取代便携版/手动安装吗？">
Comfy桌面版是多种安装方式之一。你仍然可以根据需要选择**便携版（Windows）**安装、**手动安装**或 **Comfy Cloud**。对于大多数用户，推荐使用桌面版，因为它易于使用，并提供一键更新和快照管理等特色功能。
</Accordion>
<Accordion title="可以关闭更新检查吗？">
不可以。Comfy桌面版在启动后不久会检查一次新版本，之后每 10 分钟检查一次，这项检查无法关闭。唯一的更新设置是**桌面端设置 → 更新**中的**自动安装桌面版更新**，它默认开启。

- **开启**：新版本会在后台下载并自动安装，无需询问。下载期间标题栏显示 **正在下载更新…**，更新可以应用时显示 **桌面版更新已就绪**。
- **关闭**：标题栏显示 **桌面版更新**，更新卡片显示 **有可用更新 …**。更新仍会在后台下载，但不会自行安装，退出时或下次启动时都不会应用。更新就绪后，点击 **桌面版更新已就绪** 胶囊按钮，并选择 **重新启动并更新**。

构建版本中的 ComfyUI 版本会单独更新。请使用该构建版本的**概览**标签页，并在其中选择 **Stable** 或 **Latest on GitHub** 通道。

在 Linux 上，应用内更新器不适用于 `.deb` 安装。请通过[通用下载链接](https://dl.todesktop.com/241130tqe9q3y)下载新的软件包，并使用 `sudo apt install ./*.deb` 安装。
</Accordion>

## 安装与设置

<Accordion title="系统要求是什么？">
完整详情请参阅[系统要求](/zh/installation/system_requirements)。

- **Windows：** Windows 10+，x64 或 ARM64。推荐使用独立 GPU（NVIDIA / AMD），但并非必需。
- **macOS：** macOS 13+（Ventura），Apple Silicon（M1+）
- **Linux：** 官方 `.deb` 和 AppImage 安装包通过 [Comfy Desktop 仓库](https://github.com/Comfy-Org/Comfy-Desktop) 分发。推荐使用独立 GPU。
- **磁盘：** 每个独立安装至少 4.85 GB
- **内存：** 最低 8 GB，推荐 16 GB
</Accordion>
<Accordion title="没有管理员权限可以安装 Comfy Desktop 吗？">
在 **Windows** 上，独立安装不需要管理员权限。在 **macOS** 上，首次进行系统级安装时需要管理员权限。在 **Linux** 上，安装 `.deb` 包需要 `sudo`；AppImage 在用户空间运行，无需管理员权限。
</Accordion>
<Accordion title="如何下载 Comfy Desktop？">
请从官方 [ComfyUI 下载页面](https://comfy.org/download) 下载最新的 Windows 或 macOS 构建。Linux 用户请使用 [Comfy Desktop 仓库](https://github.com/Comfy-Org/Comfy-Desktop) 中的[通用下载链接](https://dl.todesktop.com/241130tqe9q3y)获取 `.deb` 或 AppImage。如需从源码运行，参见 [Linux 安装指南](/zh/installation/desktop/overview#为你的操作系统安装-comfy桌面版)。
</Accordion>
<Accordion title="可以同时安装 Legacy Desktop 和 Comfy Desktop 吗？">
可以共存。但我们建议将您的安装迁移到新的 Comfy Desktop，并最终卸载 Legacy Desktop。请参阅[迁移指南](/zh/installation/desktop/usage/migrate)。
</Accordion>

## 使用

<Accordion title="如何添加新的 ComfyUI 安装？">
打开 **构建** 页面并点击 **新建构建**，在此计算机上安装一个全新的构建。要添加已有的构建，请点击 **新建构建** 旁的箭头（**更多构建选项**）并选择 **添加现有构建**。要改为在 Comfy Cloud 上运行 ComfyUI，请打开 **Comfy Cloud** 构建。

- **新建构建**：由 Comfy Desktop 为你设置的全新安装。
- **添加现有构建**：跟踪你已安装的 ComfyUI，例如 Git 克隆或便携版安装。
- **Comfy Cloud**：在云端的 GPU 上运行 ComfyUI，无需在此计算机上安装任何内容。

有关所有选项，请参见[构建](/zh/installation/desktop/usage/instance-management)。
</Accordion>
<Accordion title="能同时运行多个 ComfyUI 版本吗？">
可以！Comfy Desktop 就是为此设计的。每个构建都在各自独立的隔离环境中运行，拥有自己的 Python 和依赖关系。你可以在单独的窗口中同时启动它们。
</Accordion>
<Accordion title="我的模型、自定义节点和设置存储在哪里？">
默认情况下，模型会在各个构建之间共享。在[桌面设置 → 文件夹](/zh/installation/desktop/usage/settings#storage)中配置共享文件夹。

- **独立安装：** 安装本身位于其构建文件夹中。自定义节点和 Python 环境按构建独立。模型通常来自共享的模型文件夹。
- **Git 克隆 / 便携版（已跟踪）：** 数据保留在该现有文件夹中（`models/`、`custom_nodes/`、`user/`）。你仍然可以选择共享模型、输入和输出。
</Accordion>
<Accordion title="快照如何工作？">
Comfy Desktop 会在关键事件发生时自动创建快照：每次启动和重新启动、更新之前和之后，以及恢复之后。快照会记录该构建的 ComfyUI 版本、自定义节点及其版本，以及环境中的所有 pip 包。模型文件、输入和输出不包含在快照中。

你可以在该构建的 **快照** 标签页中浏览、恢复、导出和分享快照。参见[保存和恢复快照](/zh/installation/desktop/usage/build-snapshots#保存和恢复快照)。
</Accordion>

### 如何停止/退出 Comfy Desktop

要停止正在运行的 ComfyUI 构建并保持 Comfy Desktop 打开：

1. 从 **侧边栏** 或 **构建** 页面打开该构建的页面。
2. 点击 **停止**。
3. 在对话框中确认。

要退出 Comfy Desktop，请打开 **标题栏** 中的 **菜单** 并选择 **退出桌面端**，或关闭最后一个窗口。在 Windows 和 Linux 上，关闭最后一个窗口会退出应用。在 macOS 上，只要本地构建仍在运行，关闭最后一个窗口后应用会继续运行，此时请从 macOS 菜单栏退出（Command+Q）。所有平台都没有托盘图标。运行 ComfyUI 的窗口在其 **菜单** 中还有 **关闭窗口**，这会关闭该窗口并停止它正在运行的构建。

## 故障排除

<Accordion title="安装后应用无法启动">
1. **Windows：** 尝试以管理员身份运行一次
2. **macOS：** 如果看到安全警告，前往 **系统设置 → 隐私与安全性**，点击 **仍要打开**
3. **Linux：** 安装 FUSE 2：Ubuntu 24.04 及更高版本用 `libfuse2t64`，22.04 用 `libfuse2`
4. 查看[下载页面](https://comfy.org/download)获取最新版本
</Accordion>
<Accordion title="更新后 Comfy Desktop 自动关闭（Windows）">
在 Windows 上，如果更新下载没有完成，Comfy Desktop 1.0.46 及更早版本可能会卡住。应用会短暂显示更新界面，然后在没有任何报错的情况下关闭。每次启动都会重复这一过程，而应用在下载到修复版本之前就已关闭。1.0.47 及更高版本已修复此问题。

要恢复，请手动安装最新版本：

1. 下载[最新的 Windows 安装程序](https://dl.todesktop.com/241130tqe9q3y/windows)，或从[下载页面](https://comfy.org/download)获取。
2. 运行安装程序。无需先卸载旧版本。
3. 启动 Comfy Desktop。

你的安装、模型和设置都会保留。
</Accordion>
<Accordion title="GPU 检测不到">
- 确保 NVIDIA 驱动为最新版本
- 在 Linux 上，确认 CUDA toolkit 已安装
- 确认安装类型支持 GPU（Standalone 和 Git Clone 支持；云端连接使用远程 GPU）
</Accordion>
<Accordion title="安装更新失败">
- 检查网络连接
- 重试前先在实例的 **Snapshots** 标签页手动创建快照
- 如果问题持续存在，恢复到上一个快照后重试
</Accordion>

<Accordion title="安装或更新显示「操作失败」">
进度界面会一直显示 **操作失败**、错误信息，以及（在可用时）自动打开的 **查看日志** 面板。

- **重启** 会重试同一操作（如果失败的是启动，按钮显示为 **重启 ComfyUI**）。
- **返回主页** 会不做任何询问直接回到 **主页**，失败的安装会留在磁盘上。
- 步骤仍在运行时离开即取消：**返回主页** 会询问 **取消当前操作？**。取消安装会尝试删除建到一半的文件夹（删除失败时可能残留文件）。

如果反复失败，请先检查网络，然后从 **桌面端设置 → 日志 → 诊断 → 打开日志文件夹** 中收集 `app.log`（以及同目录下的 `app.log_*.log`）。首次安装时，打开**标题栏**的**菜单**，选择**跳过引导**，先进入 **主页**。另见[如何查看 Comfy Desktop 启动日志？](#如何查看-comfy-desktop-启动日志)。
</Accordion>
<Accordion title="出现「磁盘空间不足」或「模板模型空间不足」">
在**新建实例**过程中，Comfy Desktop 会检查安装磁盘的可用空间。**磁盘空间不足**只是一条警告：选择 **仍然继续** 即可继续，或另选一个文件夹。参见[安装新实例](/zh/installation/desktop/usage/instance-management#安装新的构建)。
</Accordion>
<Accordion title="如何查看 Comfy Desktop 启动日志？">
Desktop 应用会写入轮转的 `app.log` 文件。最快的查找方式是 **桌面端设置 → 日志 → 诊断 → 打开日志文件夹**。**桌面端设置** 位于侧边栏底部。

默认日志文件夹：

- **Windows:** `%APPDATA%\Comfy Desktop\logs`
- **macOS:** `~/Library/Logs/Comfy Desktop`
- **Linux:** `~/.config/Comfy Desktop/logs`

查找 `app.log`。之前的会话会轮转为带时间戳的 `app.log_*.log` 文件。

ComfyUI 进程输出（不是 Desktop 应用本身）请打开实例页面，使用 **终端** 标签页。参见[管理实例](/zh/installation/desktop/usage/instance-management#管理构建)。
</Accordion>
<Accordion title="可以在 ComfyUI 中使用 Ollama 吗？">
ComfyUI 不会原生集成 [Ollama](https://ollama.ai) 作为扩散模型后端。不过你可以通过 ComfyUI Manager 注册表中提供的**自定义节点**，使用 Ollama 提供的 LLM 进行提示词生成和文本处理。

关于把 ComfyUI 接入 LLM 服务，参见[安装自定义节点](/zh/installation/install_custom_node)。
</Accordion>
<Accordion title="如何卸载 Comfy Desktop？">
Comfy Desktop 和它的安装在磁盘上是分开的。要卸载应用及其安装：

1. **从应用内删除安装**（右键 → 移除）或手动删除安装文件夹
2. **卸载应用**：使用系统标准方法（Windows 的添加/删除程序，macOS 拖到废纸篓，Linux 包管理器）

这不会删除应用设置、日志、共享模型或输出。关于残留文件夹和完整清理，参见 [Windows](/zh/installation/desktop/overview#卸载-comfy桌面版)、[macOS](/zh/installation/desktop/overview#卸载-comfy桌面版) 或 [Linux](/zh/installation/desktop/overview#卸载-comfy桌面版)。
</Accordion>
<Accordion title="Comfy Desktop 可以无头或服务器模式运行吗？">
不可以。Comfy Desktop 是本地 GUI 应用程序，不支持无头、纯服务器或远程操作模式。它需要图形桌面环境来启动和管理 ComfyUI 实例。

如需无头或服务器部署，请改用 **手动安装的 ComfyUI** 或 **Windows 便携版**。
</Accordion>
