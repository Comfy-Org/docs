## 常规问题

<Accordion title="Comfy桌面版和旧版 Desktop（Legacy）有什么区别？">
Comfy桌面版是全新重写的版本，是一个**多安装管理器**。与旧版 Desktop（单一安装）不同，Comfy桌面版允许你同时安装、管理和运行多个 ComfyUI 版本。它还增加了快照和模型下载管理功能。

旧版 Desktop（Legacy）的用户请查看[迁移指南](/zh/installation/desktop/usage/migrate)，以迁移你现有的设置。
</Accordion>
<Accordion title="Comfy桌面版是开源的吗？">
是的。源代码在 [GitHub](https://github.com/Comfy-Org/Comfy-Desktop) 上可用。Comfy桌面版采用双重许可证：[AGPL-3.0-or-later](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/LICENSE)，或从 Comfy Org 获取商业许可证（`licensing@comfy.org`）。
</Accordion>
<Accordion title="Comfy桌面版会取代便携版/手动安装吗？">
Comfy桌面版是多种安装方式之一。你仍然可以根据需要选择**便携版（Windows）**、**手动安装**或 **Comfy Cloud**。对于大多数用户，推荐使用 Comfy桌面版，因为它易于使用，并提供一键更新和快照管理等特色功能。
</Accordion>
<Accordion title="可以关闭更新检查吗？">
不可以。Comfy Desktop 启动后不久会检查一次新版本，之后每 10 分钟检查一次，这个检查无法关闭。唯一的更新设置是**桌面端设置 → 更新**里的**自动安装桌面端更新**，它默认开启。

- **开启时**：新版本会在后台下载并自动安装。下载期间标题栏显示 **正在下载更新…**，更新可以应用时显示 **桌面端更新已就绪**。
- **关闭时**：Comfy Desktop 仍会检查并通知你，但不再自行下载。标题栏改为显示 **桌面端更新** 胶囊按钮，点击它才会下载更新并提示重启。

实例内部的 ComfyUI 版本是单独更新的。请在实例的**更新**标签页中选择 **Stable** 或 **Latest on GitHub** 渠道进行更新。

在 Linux 上，应用内更新器不适用于 `.deb` 安装。请通过[通用下载链接](https://dl.todesktop.com/241130tqe9q3y)下载新的安装包，再使用 `sudo apt install ./*.deb` 安装。
</Accordion>

## 安装与设置

<Accordion title="系统要求是什么？">
完整详情请参阅[系统要求](/zh/installation/system_requirements)。

- **Windows：** Windows 10+，x64 或 ARM64。推荐使用独立 GPU（NVIDIA / AMD），但并非必需。
- **macOS：** macOS 13+ (Ventura)，Apple Silicon (M1+)
- **Linux：** 官方 `.deb` 和 AppImage 安装包通过 [Comfy Desktop 仓库](https://github.com/Comfy-Org/Comfy-Desktop) 分发。推荐使用独立 GPU。
- **磁盘：** 每个独立安装至少 4.85 GB
- **内存：** 最低 8 GB，推荐 16 GB
</Accordion>
<Accordion title="没有管理员权限可以安装 Comfy Desktop 吗？">
**Windows** 上独立安装不需要管理员权限。**macOS** 上首次进行系统级安装时需要管理员权限。**Linux** 上安装 `.deb` 包需要 `sudo`；AppImage 在用户空间运行，无需管理员权限。
</Accordion>
<Accordion title="如何下载 Comfy Desktop？">
请从官方 [ComfyUI 下载页面](https://comfy.org/download) 下载最新的 Windows 或 macOS 构建。Linux 用户请使用 [Comfy Desktop 仓库](https://github.com/Comfy-Org/Comfy-Desktop) 中的[通用下载链接](https://dl.todesktop.com/241130tqe9q3y)获取 `.deb` 或 AppImage。如需从源码运行，参见 [Linux 安装指南](/zh/installation/desktop/linux)。
</Accordion>
<Accordion title="可以同时安装 Legacy Desktop 和 Comfy Desktop 吗？">
可以共存。但我们建议将您的安装迁移到新的 Comfy Desktop，并最终卸载 Legacy Desktop。请参阅[迁移指南](/zh/installation/desktop/usage/migrate)。
</Accordion>

## 使用

<Accordion title="如何添加新的 ComfyUI 安装？">
在 Dashboard 上选择 **+** 卡片（或 ☰ 菜单里的 **New Instance**）新建独立实例。要纳入已有的安装，打开标题栏的 ☰ 菜单并选择 **Add Existing Instance**。使用 **Comfy Cloud** 卡片连接到云端。

- **Standalone**：全新安装，自带 Python
- **Add Existing Instance**：跟踪 Git 克隆或便携版安装
- **Cloud**：连接 Comfy Cloud
</Accordion>
<Accordion title="能同时运行多个 ComfyUI 版本吗？">
可以！Comfy Desktop 就是为此设计的。每个安装运行在独立的隔离环境中，拥有自己的 Python 和依赖关系，也各自拥有窗口。

当一个本地实例已在运行或正在启动时再启动另一个，Comfy Desktop 会先询问：**Run All** 让新实例和运行中的实例一起运行，**Close & Launch** 会先停止它们。在[桌面版设置](/zh/installation/desktop/usage/settings#偏好设置)里关闭 **Warn before running multiple instances** 可以跳过这个提示。
</Accordion>
<Accordion title="我的模型、自定义节点和设置存储在哪里？">
模型在实例之间默认共享。在 [桌面设置 → 存储](/zh/installation/desktop/usage/settings#存储) 中配置共享文件夹。

- **独立安装：** 安装本身位于其安装文件夹中。自定义节点和 Python 环境按安装独立。模型通常来自共享的模型目录。
- **Git 克隆 / 便携版（已跟踪）：** 数据保留在该现有文件夹（`models/`、`custom_nodes/`、`user/`）中。你仍然可以选择共享模型、输入和输出。
</Accordion>
<Accordion title="快照如何工作？">
Comfy Desktop 会在关键节点自动创建快照：每次启动和重启、更新前后，以及恢复之后。快照记录实例的 ComfyUI 版本、自定义节点及其版本，以及环境中的所有 pip 包。模型文件、输入和输出不包含在快照中。

你可以在实例的 **Snapshots** 标签页中浏览、恢复、导出和分享快照。参见[快照](/zh/installation/desktop/usage/snapshots)。
</Accordion>
### 如何停止/退出 Comfy Desktop

要停止正在运行的 ComfyUI 实例（停止 Python 后端但保持应用打开）：

1. 点击实例卡片上的 **⋮（kebab 菜单）**
2. 选择 **停止**
3. 在对话框中确认

这会停止 ComfyUI Python 进程，但桌面应用窗口保持打开，以便随时重新启动。要退出应用，请打开左上角的 **☰ 菜单**并选择 **Quit Desktop**（或等效的操作系统退出命令）。关闭实例窗口会停止该窗口运行的 ComfyUI，关闭最后一个窗口会退出 Comfy Desktop，所以关闭窗口不会回到 Dashboard。想留在应用里并让实例继续运行，请打开标题栏胶囊按钮的**实例选择器**并选择 **Open Dashboard**。详见[窗口、关闭与退出](/zh/installation/desktop/usage/overview#windows-closing-and-quitting)。

## 故障排除

<Accordion title="安装后应用无法启动">
1. **Windows：** 尝试以管理员身份运行一次
2. **macOS：** 如果看到安全警告，前往 **系统设置 → 隐私与安全性**，点击 **仍要打开**
3. **Linux：** 确保已安装 FUSE 2（`sudo apt install libfuse2`）
4. 查看[下载页面](https://comfy.org/download)获取最新版本
</Accordion>
<Accordion title="更新后 Comfy Desktop 自动关闭（Windows）">
在 Windows 上，如果更新没有下载完成，Comfy Desktop 1.0.46 及更早版本可能会卡住。应用会短暂显示更新界面，然后在没有任何报错的情况下关闭。每次启动都会这样，而且应用在下载到修复版本之前就会关闭。1.0.47 及更高版本已修复此问题。

要恢复，请手动安装最新版本：

1. 下载[最新的 Windows 安装程序](https://dl.todesktop.com/241130tqe9q3y/windows)，或从[下载页面](https://comfy.org/download)获取。
2. 运行安装程序。无需先卸载旧版本。
3. 启动 Comfy Desktop。

你的安装、模型和设置都会保留。
</Accordion>
<Accordion title="GPU 检测不到">
- 确保 NVIDIA 驱动是最新的
- 在 Linux 上，验证 CUDA toolkit 是否已安装
- 确认安装类型支持 GPU（Standalone 和 Git Clone 支持；云端连接使用远程 GPU）
</Accordion>
<Accordion title="安装更新失败">
- 检查网络连接
- 重试前先在实例的 **Snapshots** 标签页手动创建快照
- 如果问题持续，恢复到上一个快照再重试
</Accordion>
<Accordion title="出现「磁盘空间不足」或「磁盘空间不足以下载模板模型」怎么办？">
在**新建实例**过程中，Comfy Desktop 会检查安装磁盘的可用空间。**磁盘空间不足**是警告——可选择**仍然继续**，或改选其他路径。**磁盘空间不足以下载模板模型**会拦截该模板；请改选更轻量的工作流或释放空间。磁盘过小时可能跳过模板步骤。详见[创建新实例](/zh/installation/desktop/usage/instance-management#创建新实例)。
</Accordion>
<Accordion title="如何查看 Comfy Desktop 启动日志？">
Desktop 应用会写入轮转的 `app.log` 文件。最快的查找方式是 **桌面设置 → 日志 → 诊断 → 打开日志文件夹**（左上角 ☰ 菜单）。

默认日志文件夹：

- **Windows:** `%APPDATA%\Comfy Desktop\logs`
- **macOS:** `~/Library/Logs/Comfy Desktop`
- **Linux:** `~/.config/Comfy Desktop/logs`

查找 `app.log`。之前的会话会轮转为带时间戳的 `app.log_*.log` 文件。

ComfyUI 进程输出（不是 Desktop 应用本身）请打开实例的 **管理** 面板，使用 **终端** 标签页。参见[安装管理](/zh/installation/desktop/usage/manage)。
</Accordion>
<Accordion title="可以在 ComfyUI 中使用 Ollama 吗？">
ComfyUI 不会原生把 [Ollama](https://ollama.ai) 当作扩散模型后端。不过你可以通过 ComfyUI Manager 注册表中的**自定义节点**，用 Ollama 提供的 LLM 做提示词生成和文本处理。

关于把 ComfyUI 接到 LLM 服务，见[安装自定义节点](/zh/installation/install_custom_node)。
</Accordion>
<Accordion title="如何卸载 Comfy Desktop？">
Comfy Desktop 和它的安装在磁盘上是分开的。要卸载应用及其安装：

1. **从应用内移除安装**：在实例卡片的 ⋮ 菜单里选择 **Uninstall**，删除该实例及其磁盘文件；或在 Manage 面板的 **More** 菜单里选择 **Forget**，只把它从列表里移除，文件留在磁盘上（从 Legacy Desktop 迁移过来的安装是就地接管的，不提供 **Forget**）。也可以手动删除安装文件夹。
2. **卸载应用**：使用系统标准方法（Windows 的添加/删除程序，macOS 拖到废纸篓，Linux 包管理器）

这不会删除应用设置、日志、共享模型和输出。残留目录和完整清理步骤见 [Windows](/zh/installation/desktop/windows#卸载应用不会移除的内容)、[macOS](/zh/installation/desktop/macos#卸载应用不会删除的内容)、[Linux](/zh/installation/desktop/linux#清理残留数据)。
</Accordion>
<Accordion title="Comfy Desktop 可以无头或服务器模式运行吗？">
不可以。Comfy Desktop 是本地 GUI 应用程序，不支持无头（headless）模式、纯服务器模式或远程操作。它需要图形桌面环境来启动和管理 ComfyUI 实例。

如果需要无头或服务器部署，请使用 **手动安装的 ComfyUI** 或 **Windows 便携版**。
</Accordion>
