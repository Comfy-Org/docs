## 管理面板

管理面板的内容因实例类型而异。本页的截图展示的是**本地独立安装**。云端和远程实例的标签页和设置更少。

在实例上选择**管理**以打开设置面板。

![本地实例的管理面板：更新、启动参数、快照、存储、终端、关于](/images/desktop/usage/instance_settings_00.png)

- 打开**选择器**视图（显示所有实例的主界面）
- 点击实例卡片上的 ⋮ 图标
- 从上下文菜单中选择**管理**

该面板包含六个标签页：

### 更新标签页

![管理面板的更新标签页：ComfyUI 版本、更新通道和 PyTorch 软件包](/images/desktop/usage/instance_settings_01_update.png)

此标签页显示当前版本，可让你检查更新并配置更新通道。

- **版本**：显示当前已安装的版本以及是否为最新。
- **上次检查**：显示上次检查更新的日期。
- **检查更新**：手动检查新版本。
- **更新通道**：从下拉列表中选择更新通道：
  - **稳定版**：经过测试的发布版本，推荐大多数用户使用。默认选项。
  - **GitHub 最新版**：master 分支上的最新提交。

### 启动参数标签页

![用于实例启动参数与测试版参数的管理启动参数标签页](/images/desktop/usage/instance_settings_02_startup_args.png)

配置启动 CLI 参数、管理器策略、启动模式、浏览器缓存共享、端口冲突行为和环境变量。

- **启动参数**：为 ComfyUI 自定义 CLI 参数（例如 `--listen`）。点击齿轮图标可查看分类的标志。启用测试版功能后，该字段旁边的 **+N beta** 标签会列出 Comfy Desktop 为当前运行的会话添加的测试版参数，或下次启动可用的测试版参数。
- **管理器安全级别**：控制 ComfyUI-Manager 可以为此实例安装哪些节点包。在你下次启动时生效。
  - **Strict**：阻止所有节点包的安装、更新和卸载。管理器为只读。
  - **Standard（推荐）**：允许已注册的节点包。阻止来自未注册来源的安装（例如任意 git URL）。
  - **Relaxed**：与 Standard 相同，但当 ComfyUI 只能从本机访问时，还允许从未注册来源安装。`--listen` 会再次阻止这些安装。
  - **Permissive**：允许所有风险级别。如果 ComfyUI 通过 `--listen` 暴露，安装仍需要 **个人云端** 网络模式。
- **管理器网络模式**：管理器与节点注册表通信的方式。
  - **Public（默认）**：使用公共注册表。`--listen` 会在所有安全级别下阻止节点包的安装。
  - **Private**：使用你自己配置的私有节点数据库。
  - **Offline**：无外部网络。无法下载。
  - **个人云端**：将此机器视为受信任的远程盒子，并解除 `--listen` 的安装限制。所选安全级别仍然适用。仅在你可控制的机器上使用此选项。
- **启动模式**：**应用窗口**（嵌入式）或**仅控制台**（无应用窗口；ComfyUI 作为控制台进程运行）。
- **浏览器缓存**：**此实例专用**或**共享**。
- **如果端口被占用**：**询问要执行的操作**，或**使用下一个可用端口（若设置了 --port 则询问）**。
- **环境变量**：使用 **+ 添加变量** 按钮添加自定义环境变量。

### 快照标签页

![管理“快照”标签页，列出该实例的还原点](/images/desktop/usage/instance_settings_03_snapshots.png)

查看、导入、导出和创建快照。每个条目都会显示版本变更和包统计信息。

- **时间线**：按时间顺序列出所有快照，并显示版本变更和统计信息。
- **最新**：显示最近一次快照的拍摄时间。
- **导入**：从文件导入快照。
- **导出全部**：将所有快照导出为备份。
- **创建快照**：随时手动创建新的快照。
- 每个快照条目都会显示：
  - 版本变更（例如 `v0.20.1 → v0.24.1`）
  - 包变更
  - 节点和包的数量
  - **导出**和**删除**按钮

### 存储选项卡

![用于每个实例模型和 I/O 路径的管理存储选项卡](/images/desktop/usage/instance_settings_04_storage.png)

配置此实例是否使用全局共享文件夹，并添加仅适用于此实例的额外模型目录。

- **包含共享目录**：切换此实例是否扫描来自[桌面设置 → 存储](/zh/installation/desktop/usage/settings#存储)的全局共享模型目录。
- **使用共享输入文件夹**：启用后，此实例从全局共享输入文件夹读取输入文件。禁用则使用此实例自己的输入文件夹。
- **使用共享输出文件夹**：启用后，此实例将已生成的输出写入全局共享输出文件夹。禁用则使用此实例自己的输出文件夹。
- **模型目录**：仅适用于此实例的额外模型目录，在共享模型目录之外一并搜索。
- **输入目录** / **输出目录**：当上方的共享开关关闭时，此实例自己的文件夹。

### 终端标签页

![管理终端标签页，显示实例控制台](/images/desktop/usage/instance_settings_05_console.png)

此实例文件夹中的交互式 shell。无论 ComfyUI 正在运行还是已停止，它都能正常工作。

- 用它来检查启动日志、错误和 Python 输出。
- 复制、粘贴和全选遵循操作系统的快捷键。右键点击终端可执行相同的操作。

### 关于标签页

![包含实例路径与版本详情的“管理”关于标签页](/images/desktop/usage/instance_settings_05_about.png)

查看安装详情：ComfyUI 版本、硬件、Python 和 PyTorch 版本、磁盘路径以及使用情况。

- **当前版本**：已安装的 ComfyUI 版本。
- **硬件**：检测到的硬件（例如 `Apple Silicon (MPS)`）。
- **Python**：内置的 Python 版本。
- **PyTorch**：已安装的 PyTorch 构建版本。**更改 PyTorch** 会切换到此安装类型经过测试的官方技术栈（CUDA、ROCm、Intel XPU、CPU 或 Apple MPS）。环境的其余部分保持不变。每夜构建会被标记为不稳定。
- **位置**：磁盘上的完整安装路径。点击复制按钮即可复制。
- **磁盘占用**：该安装所使用的磁盘空间大小。
