Comfy Desktop 会为你的构建下载所需的模型，并集中跟踪所有传输。当构建需要本地还没有、且 ComfyUI 提供了下载链接的模型时，桌面端会下载它并把文件保存到模型文件夹，你不需要手动放置这个文件。

点击标题栏中的 **下载** 图标，可以查看进度、重试失败的下载，或打开已完成文件所在的文件夹。

## 下载列表中会出现什么

- **缺失模型**：当 ComfyUI 报告缺失模型并带有下载链接时，下载会经由 Comfy Desktop 完成，文件保存到对应的模型文件夹，例如 `checkpoints`、`diffusion_models`、`text_encoders`、`loras` 或 `vae`。没有下载链接的模型只能手动放进对应文件夹。桌面端支持 `.safetensors`、`.sft`、`.ckpt`、`.pth` 和 `.pt`。
- **示例工作流的模型**：在 **性能测试** 中，示例工作流会在后台下载它需要的模型，这些传输和其他下载一样出现在托盘里。
- **Cloud 与远程构建的输出**：在 Cloud 或远程构建中保存输出时，桌面端会把它下载到本地输出文件夹。关闭 **自动下载输出** 可以停用此行为。
- **你自己下载的资产**：来自 Cloud 构建、在 **资产** 页面保存的资源。详见[下载资产](#下载资产)。

## 下载资产

**资产** 页面同时列出 Cloud 构建和本机构建里的资产。Cloud 资产还不在你的磁盘上，需要下载到你选的文件夹；本机资产已经在磁盘上，同一个菜单会直接打开它。

1. 打开侧边栏的 **资产**，选中要保存的条目。
2. Cloud 资产在详情面板或右键菜单里选择 **下载**。
3. 在保存对话框中选择文件夹。它会停在上次保存的位置，第一次是系统的“下载”文件夹。
4. 在 **下载** 托盘里跟进传输，点 **✕** 可以取消。

每个资产单独下载，想保留几个就重复几次。

## 下载托盘

列表按最新在前排列，条目名由模型文件夹和文件名组成。进行中的行显示已传输大小和百分比，速度与剩余时间在已知后显示。

![从 Comfy Desktop 标题栏打开的下载托盘，列出模型下载及其文件夹和进度](/images/desktop/usage/downloads_01_tray.png)

图标上的角标统计尚未完成的传输，包含已暂停的。没有下载进行时，它改为显示你之后还没查看过的结果：已完成用绿色、失败用红色；同时有进行中的下载和未查看的失败时还会出现一个红点。

把鼠标移到某一行上可以操作：

- **重试** 重新开始失败或已取消的传输。
- 文件夹按钮打开已完成文件所在的文件夹。点击已完成的行效果相同（在 Finder 中显示、在资源管理器中显示或在文件夹中显示）。
- **✕** 取消进行中的传输，或把已完成的行从列表移除。

托盘顶部的 **查看全部** 打开完整的下载视图。

## 完整下载视图

完整视图保留下载历史，并提供托盘放不下的操作：

- 按状态筛选。筛选栏提供 **全部**，以及有记录的 **活动**、**已完成** 和 **失败**；有记录的状态不足两类时整条筛选栏隐藏。已取消的下载归在 **失败** 下。
- 有主操作的行会把它显示为一个按钮：**暂停**、**继续**、**重试**，或打开文件夹。
- **✕** 取消进行中的传输或移除该行。
- 底部统计列表中活动、已完成、失败和已取消的下载数量。
- **清除已完成** 一次移除所有已结束的行。

![完整下载视图，列出两个已暂停的下载及其继续按钮，底部显示活动数量](/images/desktop/usage/downloads_02_full_view.png)

## 下载未完成时退出

模型下载可以续传。已接收的字节会保留，下次启动时该传输以已暂停状态出现：打开 **查看全部** 并选择 **继续**。取消则会删除未完成的文件。

输出和资产下载走另一条路径，退出后不会续传。

示例工作流的模型仍在下载时，退出前会先确认：

- **仍然退出**：暂停下载并退出，下次启动时它们会以已暂停状态回来。
- **继续下载**：取消退出，让 Comfy Desktop 继续运行。这是默认选项。

桌面端自己发起的退出（例如安装更新或重启）不会弹出这个提示，☰ 菜单里的 **退出桌面端** 也不会。后者会改用 **退出桌面端** 对话框，列出将被停掉的本地构建和进行中的下载；只开着 Cloud 或远程窗口不会触发它；在首页、没有打开构建窗口时则直接退出，不作询问。

## 下载保存到哪里

模型文件保存到标记为 **下载** 的共享模型文件夹。在 [桌面端设置](/zh/installation/desktop/usage/settings#存储) 中用 **用于下载** 指定是哪一个。不使用共享模型文件夹的构建会下载到自己的 `models` 文件夹，构建也可以在 **管理** 面板里添加更多模型文件夹。

Cloud 或远程构建的输出，在构建使用共享输出文件夹时保存到共享输出文件夹，否则保存到该构建的输出文件夹；该字段为空时仍保存到共享输出文件夹。远程构建可以在 **启动参数** 标签页的 **启动设置** 中关闭 **自动下载输出**。

你手动下载的资产保存到保存对话框指定的位置，可以在构建之外。
