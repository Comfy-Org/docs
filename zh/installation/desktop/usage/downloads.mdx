Comfy Desktop 会下载你的构建所需的文件，并在一处集中跟踪所有传输，无论是应用替你获取的模型，还是你自己保存的文件。当 ComfyUI 请求一个磁盘上不存在的模型并提供下载链接时，Comfy Desktop 会执行该传输，并把文件保存到对应的模型文件夹，因此你无需手动放置。

点击**标题栏**中的 **下载** 按钮，即可跟踪正在进行的传输、暂停或重试其中某一项，或打开已完成文件所在的文件夹。

## 下载列表中会出现什么

- **缺失模型**：当 ComfyUI 在缺失模型弹窗或右侧面板的 **Errors** 标签页中报告某个缺失模型且该模型带有下载链接时，下载会通过 Comfy Desktop 进行。文件会保存到对应的模型文件夹，例如 `checkpoints`、`diffusion_models`、`text_encoders`、`loras` 或 `vae`。支持的模型文件类型为 `.safetensors`、`.sft`、`.ckpt`、`.pth` 和 `.pt`。
- **应用所需的模型**：当某个[应用](/zh/installation/desktop/usage/apps)在此计算机上运行并且需要磁盘上不存在的模型时，Comfy Desktop 会下载该模型，传输过程会显示在托盘中。
- **来自 Comfy Cloud 和远程构建的输出**：当**自动下载输出**开启时，已完成的输出会自动保存到你的输出文件夹。请参阅[为远程和 Comfy Cloud 构建设置输出选项](/zh/installation/desktop/usage/instance-management#set-output-options-for-remote-and-comfy-cloud-builds)。
- **你自己下载的文件**：你从**资产**页面保存的资产。请参阅[从 Comfy Cloud 下载](/zh/installation/desktop/usage/assets#从-comfy-cloud-下载)。

## 下载托盘

点击标题栏中的 **下载** 按钮即可打开托盘。

![从 Comfy Desktop 标题栏打开的下载托盘，列出模型下载及其文件夹和进度](/images/desktop/usage/comfy-desktop-downloads.png)

该按钮上带有徽标，显示正在进行的下载数量。当没有下载正在进行时，它会改为标记那些失败的下载，或已完成但你尚未打开的下载。

下载按最新在前排列，并标注模型文件夹和文件名。进行中的条目会显示已传输的大小和百分比，当 Comfy Desktop 能够估算时，还会显示速度和剩余时间。每个条目提供以下操作：

- 进行中的条目显示 **暂停**，已暂停的条目显示 **继续**。
- **取消**（**✕**）用于停止正在进行的下载并丢弃未完成的文件。
- 失败或已取消的下载提供 **重试**。
- 已完成的条目提供 **在 Finder 中显示**（或 **在资源管理器中显示** / **在文件夹中显示**），用于打开存放该文件的文件夹。
- **从列表中移除** 用于移除已完成的条目。

托盘底部的 **查看所有下载** 会打开完整的下载视图。

## 完整的下载视图

完整视图会保留下载历史，并加入托盘放不下的那些控制项：

- 按状态过滤列表：**全部**、**活动**、**已完成** 或 **失败**。
- **暂停**进行中的下载，**继续**已暂停的下载。
- 对失败或已取消的下载**重试**。
- 打开文件所在的文件夹，或移除单个条目。
- **清除已完成**，一次移除所有已完成的条目。

页脚统计列表中的活动、已完成和失败的下载数量。

## 下载过程中退出

模型下载支持续传。如果在模型传输进行时退出 Comfy Desktop，已经接收的字节会保留，下次启动时该传输会以已暂停的条目回到 **下载** 托盘中。打开 **查看所有下载** 可以从停止的位置 **继续**，或取消它以丢弃部分文件。

来自 Comfy Cloud 和远程构建的输出下载走单独的通道，退出后不会续传。

**标题栏** **菜单** 中的 **退出桌面端** 会一次关闭所有窗口。当有运行 ComfyUI 的窗口打开时，Comfy Desktop 会先询问，确认框会列出将要关闭的构建以及任何进行中的操作。

## 下载文件保存在哪里

当构建包含共享文件夹时，模型文件会写入[桌面设置 → 文件夹](/zh/installation/desktop/usage/settings#storage)中标记为 **Downloads** 的模型文件夹；否则写入构建自己的 `models` 文件夹。若要把新下载的文件存放到另一个共享模型文件夹，请在同一标签页中点击该文件夹所在行的 **Use for downloads**。每个构建都可以在其[文件夹标签页](/zh/installation/desktop/usage/instance-management#choose-which-folders-the-build-uses)中关闭共享文件夹。

从 Comfy Cloud 或远程构建下载的输出会写入该构建的输出文件夹；当该构建使用共享输出文件夹时，则写入共享输出文件夹。远程连接可以在其 **Startup arguments** 标签页中通过 **Auto-download outputs** 关闭自动下载输出。

你自己从 **Assets** 下载的文件属于例外：它们会保存到你在保存对话框中指定的位置，因此可以完全存放在该构建之外。
