Comfy Desktop 会为你的实例下载模型，并集中跟踪所有传输。当 ComfyUI 实例需要本地还没有的模型时，Comfy Desktop 会接管下载，并把文件保存到该实例的模型目录，你不需要手动放置。

打开标题栏中的 **下载** 托盘，就可以查看正在进行的下载、重试失败的下载，或者直接打开已完成文件所在的文件夹。

## 下载列表中会出现什么

- **缺失模型**：当 ComfyUI 在缺失模型弹窗或右侧面板的 **Errors** 标签页中报告缺失模型时，下载操作会经由 Comfy Desktop 处理。每个文件都会保存到对应的模型文件夹，例如 `checkpoints`、`diffusion_models`、`text_encoders`、`loras` 或 `vae`。支持的模型文件类型为 `.safetensors`、`.sft`、`.ckpt`、`.pth` 和 `.pt`。
- **模板模型**：新手模板所需的模型会在实例创建过程中于后台下载。
- **远程实例的输出**：在远程或 Cloud 实例上运行工作流时，生成的输出会自动下载到你的本地输出目录。

## 下载托盘

点击标题栏右侧的下载按钮打开托盘。下载按最新优先排列，并标注模型文件夹和文件名；进行中的条目会显示已传输大小、百分比、速度和预计剩余时间。

有下载进行时，按钮上会显示活动下载的数量。没有下载进行时，它会改为提示失败且你尚未查看的下载，或已完成但你还没有打开的下载。

每个条目的操作：

- **点击已完成的条目**，打开文件所在的文件夹（根据系统显示为 Show in Finder、Show in Explorer 或 Show in Folder）。
- **重试**失败或已取消的下载。
- **✕** 取消进行中的下载，或从列表中移除已完成的条目。

托盘底部的 **查看所有下载** 会打开完整的下载视图。

## 完整的下载视图

完整视图保留应用的下载历史，并提供托盘放不下的控制项：

- 按 **全部**、**活动**、**已完成** 或 **失败** 筛选列表。
- **暂停**和**继续**进行中的下载。
- **重试**失败或已取消的下载。
- 打开文件所在的文件夹，或移除单个条目。
- **清除已完成**，一次移除所有已完成的条目。

页脚会统计当前列出的进行中与已完成下载数量。

## 下载文件保存在哪里

模型文件会写入该实例的主模型目录：当实例包含共享模型目录时，写入标记为**主要**的共享模型目录；否则写入实例自己的 `models` 文件夹。共享目录在[桌面设置 → 存储](/zh/installation/desktop/usage/settings#存储)中配置，每个实例也可以在管理面板的[存储标签页](/zh/installation/desktop/usage/manage#存储标签页)中选择不使用共享目录。

从远程实例下载的输出会写入共享输出文件夹（当实例使用它时），否则写入实例自己的输出文件夹。远程实例可以在存储设置中通过 **自动下载输出** 关闭自动下载输出。

## 磁盘空间检查

Comfy Desktop 在开始安装前会检查安装磁盘的可用空间，避免大型下载中途失败。

### 安装开始之前

在新建实例向导下载独立版安装包，或安装 Build 之前，Comfy Desktop 会估算这次安装需要的空间，包括下载内容、解压过程以及实例使用的 Python 环境。

当磁盘可用空间低于该估算值时，向导会弹出**磁盘空间不足**对话框，显示检测到的可用空间和这次操作预计需要的空间。选择**仍然继续**可直接安装，或取消并改用其他安装位置。

当磁盘可用空间低于 1 GB、且尺寸估算（若有）已被满足时，也会弹出只显示可用空间的同一对话框。

### 起始模板的模型文件

起始模板的模型文件会随安装一起下载。由于模型下载不完整会让实例无法使用，这项检查属于硬性拦截而非提示：当磁盘放不下该模板的模型（外加临时下载文件所需的少量余量）时，模板选择器会提示缺口，向导会以**磁盘空间不足以下载模板模型**弹窗拦截安装，在释放磁盘空间或改选更轻量的工作流之前无法安装该模板。当磁盘连最轻量的带模型模板都装不下时，向导会直接跳过模板步骤。

### 检查安装位置

向导中的安装位置字段会在路径下方显示该磁盘的可用空间，并在已知时一并显示预计需要的容量，方便你在开始安装前对比这两个数字。
