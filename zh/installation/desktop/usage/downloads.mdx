Comfy Desktop 会为你的实例下载模型，并集中跟踪所有传输。当 ComfyUI 实例需要本地还没有的模型时，Comfy Desktop 会接管下载，并把文件保存到该实例的模型目录，你不需要手动放置。

打开标题栏中的 **下载** 托盘，就可以查看正在进行的下载、重试失败的下载，或者直接打开已完成文件所在的文件夹。

## 下载列表中会出现什么

- **缺失模型**：当 ComfyUI 在缺失模型弹窗或右侧面板的 **Errors** 标签页中报告缺失模型时，下载操作会经由 Comfy Desktop 处理。每个文件都会保存到对应的模型文件夹，例如 `checkpoints`、`diffusion_models`、`text_encoders`、`loras` 或 `vae`。支持的模型文件类型为 `.safetensors`、`.sft`、`.ckpt`、`.pth` 和 `.pt`。
- **模板模型**：当你用新手模板创建实例时，该模板所需的模型会在后台下载，并和其他下载一样出现在托盘中。进度界面会保留模型下载这一步，直到下载完成。如果你想先开始使用，可以点击该界面的 **跳过并打开 ComfyUI**，立即打开 ComfyUI，下载会继续在托盘中进行。
- **远程实例的输出**：在远程或 Cloud 实例上运行工作流时，生成的输出会自动下载到你的本地输出目录。

## 下载托盘

点击标题栏右侧的下载按钮打开托盘。下载按最新优先排列，并标注模型文件夹和文件名；进行中的条目会显示已传输大小、百分比、速度和预计剩余时间。

![从 Comfy Desktop 标题栏打开的下载托盘，列出模型下载及其文件夹和进度](/images/desktop/usage/downloads_01_tray.png)

有下载进行时，按钮上会显示活动下载的数量。没有下载进行时，它会改为提示失败且你尚未查看的下载，或已完成但你还没有打开的下载。

每个条目的操作：

- **点击已完成的条目**，打开文件所在的文件夹（根据系统显示为 Show in Finder、Show in Explorer 或 Show in Folder）。
- **重试**失败或已取消的下载。
- **✕** 取消进行中的下载，或从列表中移除已完成的条目。

托盘底部的 **查看所有下载** 会打开完整的下载视图。

## 完整的下载视图

完整视图保留应用的下载历史，并提供托盘放不下的控制项：

- 按 **全部**、**活动**、**已完成** 或 **失败** 筛选列表。
- **暂停**进行中的下载，**继续**已暂停的下载。
- **重试**失败或已取消的下载。
- 打开文件所在的文件夹，或移除单个条目。
- **清除已完成**，一次移除所有已完成的条目。

页脚会统计当前列出的进行中与已完成下载数量。

![完整的下载视图，列出已暂停的下载及其继续按钮，页脚显示进行中数量](/images/desktop/usage/downloads_02_full_view.png)

## 下载过程中退出

模型下载支持续传。如果在模型下载进行时退出 Comfy Desktop，已经收到的字节会保留，下次启动时该任务会以已暂停的条目回到下载托盘。打开 **查看所有下载**，用 **继续** 从断点接着下载，或取消它以删除未完成的文件。

远程实例的输出下载走另一条通道，退出应用后不会续传。

当模板模型仍在下载时，Comfy Desktop 会在退出前请你确认，因为模板的初始化要等这些文件：

- **仍然退出**：暂停下载并退出。下次启动时这些条目仍然保留。
- **继续下载**：取消这次退出，让 Comfy Desktop 继续运行。这是默认选项。

由 Comfy Desktop 自己发起的退出不会弹出这个确认，例如安装更新或重启。标题栏菜单里的 **退出桌面端** 也不会：它会显示自己的确认框，其中列出进行中的下载。两种情况都会暂停下载，并在下次启动时以已暂停状态恢复。

## 下载文件保存在哪里

模型文件会写入该实例的模型下载目录：当实例包含共享模型目录时，写入带 **DOWNLOADS** 角标（通过 **Use for Model Downloads** 设置）的共享模型目录；否则写入实例自己的 `models` 文件夹。共享目录在[桌面设置 → 存储](/zh/installation/desktop/usage/settings#存储)中配置，每个实例也可以在管理面板的[存储标签页](/zh/installation/desktop/usage/manage#存储标签页)中选择不使用共享目录。

从远程实例下载的输出会写入共享输出文件夹（当实例使用它时），否则写入实例自己的输出文件夹。远程实例可以在存储设置中通过 **自动下载输出** 关闭自动下载输出。
