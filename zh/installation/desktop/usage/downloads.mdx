Comfy Desktop 会为你的实例下载模型，并集中跟踪所有传输，无论是它替你下载的模型，还是你自己下载的生成素材。当 ComfyUI 实例需要本地还没有的模型时，Comfy Desktop 会接管下载，并把文件保存到该实例的模型目录，你不需要手动放置。

打开标题栏中的 **下载** 托盘，就可以查看正在进行的下载、重试失败的下载，或者直接打开已完成文件所在的文件夹。

## 下载列表中会出现什么

- **缺失模型**：当 ComfyUI 在缺失模型弹窗或右侧面板的 **Errors** 标签页中报告缺失模型时，下载操作会经由 Comfy Desktop 处理。每个文件都会保存到对应的模型文件夹，例如 `checkpoints`、`diffusion_models`、`text_encoders`、`loras` 或 `vae`。支持的模型文件类型为 `.safetensors`、`.sft`、`.ckpt`、`.pth` 和 `.pt`。
- **模板模型**：当你用新手模板创建实例时，该模板所需的模型会在后台下载，并和其他下载一样出现在托盘中。进度界面会保留模型下载这一步，直到下载完成。如果你想先开始使用，可以点击该界面的 **跳过并打开 ComfyUI**，立即打开 ComfyUI，下载会继续在托盘中进行。
- **远程实例的输出**：在远程或 Cloud 实例上运行工作流时，生成的输出会自动下载到你的本地输出目录。
- **你自己下载的生成素材**：从 **资产** 面板保存的图片、视频或音频。详见[下载生成素材](#下载生成素材)。

## 下载生成素材

输出默认留在实例里。想把它存到自己选的文件夹，需要单独操作，这和上面的自动下载不是一回事。

1. 打开左侧边栏的 **资产**，选中要保存的条目。想一次存多个，先多选。
2. 点击 **下载**；多选时是 **全部下载**。素材预览和右键菜单里也有同样的操作。
3. Comfy Desktop 会弹出保存对话框，默认停在上次保存的文件夹（第一次是系统的“下载”文件夹）。确认位置后开始传输。
4. 可以在 **下载** 托盘里跟进或取消。要暂停的话，打开 **查看所有下载**，点该行上的暂停按钮。

文件夹里已有同名文件时，保存对话框会先确认是否覆盖。从 Cloud 实例一次下载多个素材时，它们会打包成一个 zip 文件。

## 下载托盘

点击标题栏尾部控件中的 **下载** 按钮即可打开托盘。下载按最新优先排列，并标注其模型文件夹和文件名；进行中的条目会显示已传输大小、百分比、速度和预计剩余时间。

![从 Comfy桌面版 标题栏打开的下载托盘，列出模型下载及其文件夹和进度](/images/desktop/usage/comfy-desktop-downloads.png)

按钮上会显示一个徽标，标出进行中的下载数量。没有下载进行时，它则改为提示你尚未查看的失败下载，或已完成但你尚未打开的下载。

每个条目有以下操作：

- **点击已完成的条目**，打开存放该文件的文件夹（根据你的系统显示为 Show in Finder、Show in Explorer 或 Show in Folder）。
- **重试**失败或已取消的下载。
- **✕** 取消进行中的下载，或从列表中移除已完成的下载。

托盘底部的 **查看所有下载** 会打开完整的下载视图。

## 完整的下载视图

完整视图会保留应用的下载历史，并提供托盘放不下的控制项：

- 按状态过滤列表。筛选栏提供 **全部**，以及每个存在条目的状态各一个标签（**活动**、**已完成**、**失败**）；当只有一种状态存在条目时，筛选栏会隐藏。
- **暂停**活动中的下载，并**继续**已暂停的下载。
- **重试**失败或已取消的下载。
- 打开文件所在的文件夹，或移除单个条目。
- **清除已完成**，一次移除所有已完成的条目。

页脚会统计列表中处于活动状态和已完成状态的下载数量，无论当前启用了哪种过滤。失败和已取消的下载不计入。

## 下载过程中退出

模型下载支持续传。如果在模型下载进行时退出 Comfy Desktop，已经收到的字节会保留，下次启动时该任务会以已暂停的条目回到下载托盘。打开 **查看所有下载**，用 **继续** 从断点接着下载，或取消它以删除未完成的文件。

远程实例的输出下载走另一条通道，退出应用后不会续传。

当模板模型仍在下载时，Comfy Desktop 会在退出前请你确认，因为模板的初始化要等这些文件：

- **仍然退出**：暂停下载并退出。下次启动时这些条目仍然保留。
- **继续下载**：取消这次退出，让 Comfy Desktop 继续运行。这是默认选项。

由 Comfy Desktop 自己发起的退出不会弹出这个确认，例如安装更新或重启。标题栏菜单里的 **退出桌面端** 也不会。它一次关闭所有窗口：只要还有本地实例窗口打开，就先弹出 **退出桌面端** 确认框，列出打开的实例和进行中的下载；如果只有仪表盘窗口，它直接退出，不再询问。两种情况都会暂停下载，并在下次启动时以已暂停状态恢复。

## 下载文件保存在哪里

模型文件会写入该实例的模型下载目录：当实例包含共享模型目录时，写入标记为 **DOWNLOADS**（通过 **Use for Model Downloads** 设置）的共享模型目录；否则写入实例自己的 `models` 文件夹。共享目录在[桌面设置](/zh/installation/desktop/usage/settings#storage)中配置，每个构建也可以在其[文件夹标签页](/zh/installation/desktop/usage/instance-management#选择构建使用哪些文件夹)中选择不使用这些共享目录。

从远程实例下载的输出，在实例使用共享输出文件夹时会写入该共享输出文件夹，否则写入为该实例设置的输出文件夹。当该字段为空时，它们会写入共享输出文件夹。远程连接可以在其 **Startup Args** 标签页的 **Launch Settings** 下通过 **Auto-Download Outputs** 关闭输出的自动下载。

你自己下载的生成资源是个例外：它们会保存到你指定的保存位置，因此可以完全位于实例之外。
