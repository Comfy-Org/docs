Comfy Desktop 中的**资产**页面会显示你的构建和 Comfy Cloud 生成的文件：图像、视频、音频和 3D 模型。它一次只显示一个位置，例如 Comfy Cloud 或某个构建的输出文件夹。要打开它，请点击**侧边栏**中的**资产**。

<Note>
  这是 Comfy Desktop 自有的页面。在运行中的 ComfyUI 里，**资产**面板是该构建的独立图库。请参阅 [ComfyUI 中的资产](/zh/interface/assets)。
</Note>

## 选择查看位置 {#choose-where-to-look}

页面左上角的菜单用于选择要查看哪个位置的文件。它包含两个分组:

- **Comfy Cloud**:来自 Comfy Cloud 的输出。你需要先登录。菜单会在其下方显示你的工作区名称。
- **本机**:包括**共享文件夹**(本地构建默认使用的共享输出文件夹),以及每个将输出保存到各自输出文件夹的本地构建。菜单会显示每个文件夹的路径。点击某个位置旁的文件夹按钮,即可在 Finder 或资源管理器中打开它。

资产列表显示的是**侧边栏**中所选工作区内的位置。远程构建不会被列出。如果某个远程构建开启了**自动下载输出**,它的输出会显示在其下载到的文件夹下。请参阅[为远程构建和 Comfy Cloud 构建设置输出选项](/zh/installation/desktop/usage/instance-management#为远程构建和-comfy-cloud-构建设置输出选项)。

## 查找文件

- **类型**：**全部**、**图像**、**视频**、**3D** 或 **音频**。
- **按名称搜索…**：查找名称中包含所输入内容的文件。
- **刷新资产**：重新加载列表。构建保存新文件后，点击此项。

在 Comfy Cloud 上，类型过滤会按当前排序顺序检查最新的 50,000 个输出，页面会在列表下方注明这一点。

## 更改视图

点击 **视图选项** 进行设置：

- **布局**：**瀑布流** 或 **网格**。
- **排序方式**：**最新** 或 **最旧**。
- **显示**：每个文件下方的**文件名**和**文件详情**。

Comfy Desktop 会记住这些选项。在页面底部，可在各页之间切换，并选择每页显示的文件数量：50、100 或 200。

## 预览文件

点击文件即可在查看器中打开它。查看器会以大图形式显示该文件，并展示其类型、**创建日期**、大小和尺寸。对于本机上的文件，查看器还会显示 **保存位置** 及所在文件夹。

- 按左右方向键可切换到上一个或下一个文件。
- 对于图像，可选择 **适应** 或某个缩放级别。
- 不超过 100 MB 的 3D模型会在 3D 视图中打开。对于更大的模型，查看器会显示 **无法显示此 3D模型。请下载后使用 3D 应用打开。**
- **标签** 会显示该文件的标签。标签需在 ComfyUI 中编辑。

## 对文件执行操作

将指针悬停在文件上可看到其主要操作；点击**更多操作**（**⋯**）或右键点击文件，可看到其余操作：

| 操作 | 位置 | 作用 |
| --- | --- | --- |
| **打开** | 本机上的图像、视频和音频 | 在默认应用中打开该文件。 |
| **在 Finder 中显示**、**在资源管理器中显示**或**在文件夹中显示** | 本机上的文件 | 打开该文件所在的文件夹。名称随你的操作系统而定。 |
| **下载** | Comfy Cloud | 将副本保存到本机。参见[从 Comfy Cloud 下载](#从-comfy-cloud-下载)。 |
| **复制** | 图像 | 将图像复制到剪贴板。 |
| **删除** | 本机上的文件 | 询问**删除 {name}？**，然后将文件移到废纸篓，在 Windows 上则移到回收站。 |

一次只能对一个文件执行操作。你无法从 Comfy Desktop 删除 Comfy Cloud 文件。

## 打开创建文件的工作流

当图像、视频或音频文件包含创建它的工作流时，查看器中会显示 **打开工作流**。

- 对于 Comfy Cloud 文件，工作流会在 Comfy Cloud 中打开。
- 对于此计算机上的文件，工作流会在包含该文件的文件夹所属的构建版本中打开。当多个构建版本共用该文件夹时，请在 **打开方式** 下选择构建版本。

如果构建版本未运行，Comfy Desktop 会启动它。如果工作流无法打开，页面会显示 **无法打开工作流**。

## 从 Comfy Cloud 下载

1. 在左上角的菜单中选择 **Comfy Cloud**。
2. 将指针悬停在文件上，然后点击 **下载**。
3. 选择一个文件夹。保存对话框会在你上次保存到的文件夹中打开，或在你“下载”文件夹中打开。

下载内容会显示在[下载](/zh/installation/desktop/usage/downloads)托盘中。

## 文件的保存位置

- **此计算机**：输出会保存到共享输出文件夹，或某个构建自有的输出文件夹。共享文件夹可在[桌面设置](/zh/installation/desktop/usage/settings)中设置，构建的文件夹则可在其[文件夹标签页](/zh/installation/desktop/usage/instance-management#选择构建使用哪些文件夹)中设置。
- **Comfy Cloud**：输出会保留在 Comfy Cloud 中，直到你将其下载。

## 故障排除

<AccordionGroup>
  <Accordion title="暂无资产">
    所选位置还没有任何文件。在一次构建中运行工作流，或运行一个[应用](/zh/installation/desktop/usage/apps)，然后点击 **Refresh assets**。
  </Accordion>
  <Accordion title="无匹配资产">
    类型筛选或搜索隐藏了所有文件。选择 **All**，或清除 **Search by name…**。
  </Accordion>
  <Accordion title="登录以查看你的资产">
    已选择 **Comfy Cloud**，但你尚未登录。点击 **Log in to Comfy Cloud**。
  </Accordion>
  <Accordion title="此工作区没有 Comfy Cloud 构建">
    在**侧边栏**中选择的工作区没有 Comfy Cloud 构建。重新启动 Comfy Desktop 以重新添加 Comfy Cloud。
  </Accordion>
  <Accordion title="无法加载资产">
    Comfy Desktop 无法读取该列表。对于 Comfy Cloud，请检查你的网络连接。然后点击 **Refresh assets**。
  </Accordion>
</AccordionGroup>
