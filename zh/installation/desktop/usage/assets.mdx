Comfy Desktop 中的 **资产** 页面会显示你的构建和 Comfy Cloud 生成的文件：图像、视频、音频以及 3D 模型。它一次只显示一个位置，例如 Comfy Cloud 或某个构建的输出文件夹。要打开它，请点击 **侧边栏** 中的 **资产**。

<Note>
  这是 Comfy Desktop 自有的页面。在运行中的 ComfyUI 内，**资产** 面板是该构建的独立图库。参见 [ComfyUI 中的资产](/zh/interface/assets)。
</Note>

## 选择查看位置

页面左上角的菜单用于选择要查看哪个位置的文件。该菜单包含两个分组：

- **Comfy Cloud**：来自 Comfy Cloud 的输出。需要登录。菜单会在其下方显示工作区名称。
- **此电脑**：**共享文件夹**，即本地构建默认使用的共享输出文件夹，以及每个保存到自己输出文件夹的本地构建。菜单会显示每个文件夹的路径。点击某个位置旁的文件夹按钮，可在 Finder 或 Explorer 中打开它。

资产会列出在**侧边栏**中选择的工作区内的位置。远程构建不会列出。当远程构建开启 **自动下载输出** 时，其输出会显示在下载到的文件夹下。请参阅[为远程构建和 Comfy Cloud 构建设置输出选项](/zh/installation/desktop/usage/instance-management#set-output-options-for-remote-and-comfy-cloud-builds)。

## 查找文件

- **Type**：**All**、**Images**、**Videos**、**3D** 或 **Audio**。
- **Search by name…**：查找名称中包含所输入内容的文件。
- **Refresh assets**：重新加载列表。在构建保存新文件后点击它。
- **刷新资产**：重新加载列表。在构建保存新文件后点击它。

在 Comfy Cloud 上，类型过滤按当前排序顺序检查你最新的 50,000 个输出，页面会在列表下方注明这一点。

## 更改视图

点击 **视图选项** 进行设置：

- **布局**：**瀑布流** 或 **网格**。
- **排序方式**：**最新** 或 **最旧**。
- **显示**：每个文件下方的 **文件名** 和 **文件详情**。

Comfy Desktop 会记住这些选项。在页面底部，可以在页面之间切换，并选择每页显示的文件数量：50、100 或 200。

## 预览文件

点击文件即可在查看器中打开它。查看器会以大尺寸显示该文件，并显示其类型、**Created** 日期、大小和尺寸。对于此计算机上的文件，查看器还会显示 **Saved in** 及所在的文件夹。

- 按左右箭头键可切换到上一个或下一个文件。
- 对于图像，可选择 **Fit** 或某个缩放级别。
- 不超过 100 MB 的 3D模型会在 3D 视图中打开。对于更大的模型，查看器会显示 **Can't show this 3D model. Download it to open it in a 3D app.**
- **Tags** 会显示该文件的标签。标签需在 ComfyUI 中编辑。

## 对文件执行操作

将指针悬停在文件上可查看其主要操作，或点击 **更多操作** (**⋯**) 或右键单击文件以查看其余操作：

| 操作 | 适用对象 | 作用 |
| --- | --- | --- |
| **打开** | 此计算机上的图像、视频和音频 | 在默认应用中打开该文件。 |
| **在访达中显示**、**在资源管理器中显示**或**在文件夹中显示** | 此计算机上的文件 | 打开文件所在的文件夹。具体名称取决于你的操作系统。 |
| **下载** | Comfy Cloud | 将副本保存到此计算机。参见[从 Comfy Cloud 下载](#从-comfy-cloud-下载)。 |
| **复制** | 图像 | 将图像复制到剪贴板。 |
| **删除** | 此计算机上的文件 | 询问 **删除 {name}？**，然后将文件移到废纸篓，Windows 上则移到回收站。 |

一次只能对一个文件执行操作。无法从 Comfy Desktop 删除 Comfy Cloud 文件。

## 打开生成文件的工作流

当图像、视频或音频文件包含生成它的工作流时，查看器会显示 **打开工作流**。

- 对于 Comfy Cloud 文件，工作流会在 Comfy Cloud 中打开。
- 对于此计算机上的文件，工作流会在文件夹包含该文件的构建中打开。当多个构建共用该文件夹时，请在 **打开方式** 下选择构建。

如果构建未运行，Comfy Desktop 会启动它。如果工作流无法打开，页面会显示 **无法打开工作流**。

## 从 Comfy Cloud 下载

1. 在左上角的菜单中选择 **Comfy Cloud**。
2. 将指针悬停在某个文件上，然后点击 **下载**。
3. 选择一个文件夹。保存对话框会打开在上次保存的文件夹中，或打开在你的“下载”文件夹中。

下载项会出现在[下载](/zh/installation/desktop/usage/downloads)托盘中。

## 文件保存位置

- **本机**：输出会保存到共享输出文件夹，或某个构建自己的输出文件夹。共享文件夹可在[桌面设置](/zh/installation/desktop/usage/settings)中设置，构建的文件夹则在其[文件夹标签页](/zh/installation/desktop/usage/instance-management#choose-which-folders-the-build-uses)中设置。
- **Comfy Cloud**：输出会保留在 Comfy Cloud 中，直到你将其下载。

## 故障排除

<AccordionGroup>
  <Accordion title="暂无资产">
    所选位置还没有任何文件。在构建中运行工作流，或运行一个[应用](/zh/installation/desktop/usage/apps)，然后点击 **刷新资产**。
  </Accordion>
  <Accordion title="没有匹配的资产">
    类型筛选或搜索会隐藏所有文件。请选择 **全部**，或清空 **按名称搜索…**。
  </Accordion>
  <Accordion title="登录以查看你的资产">
    当前已选择 **Comfy Cloud**，但你尚未登录。请点击 **登录 Comfy Cloud**。
  </Accordion>
  <Accordion title="此工作区没有 Comfy Cloud 构建">
    **侧边栏**中选择的工作区没有 Comfy Cloud 构建。请重新启动 Comfy Desktop 以重新添加 Comfy Cloud。
  </Accordion>
  <Accordion title="无法加载资产">
    Comfy Desktop 无法读取该列表。对于 Comfy Cloud，请检查你的网络连接。然后点击 **刷新资产**。
  </Accordion>
</AccordionGroup>
