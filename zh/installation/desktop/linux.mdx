**Comfy Desktop** 可以在 Linux 上运行。官方 `.deb` 包（Debian/Ubuntu）和 AppImage 通过 [Comfy Desktop 仓库](https://github.com/Comfy-Org/Comfy-Desktop) 分发，请使用[通用下载链接](https://dl.todesktop.com/241130tqe9q3y)下载（会自动识别你的平台）。大多数用户建议使用其中一种安装包。如果想从源码运行应用，请克隆仓库并按照以下步骤操作。

## 系统要求

- **操作系统：** Linux（推荐 Ubuntu 22.04 或更高版本）
- **架构：** x64
- **Node.js：** v22 LTS 或更高版本（仅源码构建需要）
- **pnpm：** v10 或更高版本，用 Corepack 启用（仅源码构建需要）
- **编译工具：** `build-essential` 和 `git`（仅源码构建需要）
- **GPU：** 推荐独立 GPU（NVIDIA / AMD），但不是必须
- **磁盘空间：** 每个 ComfyUI 安装建议至少 4.85 GB

## 安装官方安装包

通过[通用下载链接](https://dl.todesktop.com/241130tqe9q3y)下载 Linux 安装包（会自动识别你的平台），然后安装：

```bash
sudo apt install ./*.deb
```

`.deb` 安装包会把 Comfy Desktop 安装到 `/opt/Comfy Desktop`，并在安装过程中为 Comfy Desktop 的软件源添加 APT 源，之后的新版本通过系统包管理器更新。详见[更新](#更新)。

如果 AppArmor 已启用且其解析器接受随包提供的配置（Ubuntu 24.04 及更高版本，这些版本限制非特权 user namespace），安装时还会为应用安装 `/etc/apparmor.d/comfyui-desktop-2` 处的 AppArmor 配置。因此在这些系统上，Electron 沙箱无需额外参数即可正常工作。更早的发行版会跳过这个配置，因为它们的 AppArmor 无法加载它，而那里的沙箱本来就能正常运行。如果系统完全不支持非特权 user namespace，安装包会改为把自带的 `chrome-sandbox` 设为 setuid。

检查配置是否已安装：

```bash
ls /etc/apparmor.d/comfyui-desktop-2
```

安装包的安装脚本会在每次安装或升级时写入这个配置。如果你在 Ubuntu 22.04 上安装过 `.deb`，之后又把系统升级到 24.04，可以再运行一次安装脚本：

```bash
sudo apt reinstall comfyui-desktop-2
```

AppImage 的使用方式：

```bash
chmod +x ./*.AppImage
./*.AppImage
```

AppImage 不会执行安装包脚本，因此既不会安装 AppArmor 配置，也不会添加 APT 源。从应用菜单启动时已经带上 `--no-sandbox`。如果你是直接运行文件且无法启动，可能是发行版阻止了 Electron 沙箱，此时加上参数：

```bash
./*.AppImage --no-sandbox
```

该参数会关闭所有进程的 Electron 沙箱，只在沙箱启动失败时使用。

## 从源码构建并运行

这些步骤与仓库 README 的 [Development](https://github.com/Comfy-Org/Comfy-Desktop#development) 部分一致。

### 前置条件

先安装编译工具和 git。新装的 Ubuntu 默认没有这些，而 `pnpm run init` 会编译 `node-pty` 等原生模块，缺少 `build-essential` 时会报 `Error: not found: make`：

```bash
sudo apt install build-essential git
```

然后安装 Node.js 22 并启用 pnpm：

```bash
nvm install 22 && nvm use 22
corepack enable
```

如果不用 nvm，请从 [nodejs.org](https://nodejs.org/) 安装 Node.js 22。

### 克隆并安装

```bash
git clone https://github.com/Comfy-Org/Comfy-Desktop.git
cd Comfy-Desktop
pnpm run init
```

`pnpm run init` 会安装依赖并构建内置的 bootstrap Python。

### 启动应用

```bash
./linux-dev.sh
```

这会以开发模式启动 Comfy Desktop。脚本会设置 `ELECTRON_DISABLE_SANDBOX=1`，因为 Electron 沙箱在 Linux 开发环境里经常无法启动。

## 更新

Comfy Desktop 的更新方式取决于你的安装方式。

### .deb 安装

安装 `.deb` 时会同时添加 APT 源（`/etc/apt/sources.list.d/comfyui-desktop-2.sources`）和对应的 unattended-upgrades 条目，因此新版本会随系统更新一起来到：

```bash
sudo apt update
sudo apt upgrade
```

你不需要为每个版本重新下载 `.deb`。`sudo apt remove comfyui-desktop-2` 会保留 APT 源文件，`sudo apt purge comfyui-desktop-2` 会连同 unattended-upgrades 条目一起删除。

### AppImage

AppImage 会自行更新：Comfy Desktop 下载新的构建，并替换你启动的那个 `.AppImage` 文件，所以请把它放在你的账号可写的目录里。如果该文件位于只读位置，更新就无法替换它。

### 源码运行

源码检出没有应用内自动更新。拉取最新代码后再启动：

```bash
git pull
pnpm run init
./linux-dev.sh
```

## 可选：本地打包

若要自己生成 `.deb` 或 AppImage（不是 Comfy Org 的正式下载）：

```bash
pnpm run build:linux
```

产物在 `dist/`。如果 AppImage 因为 Chromium 无法创建沙箱而失败，再用 `--no-sandbox` 重试。该参数会关闭所有进程的 Electron 沙箱。

## 清理残留数据

删除应用和删除数据是两件事，先卸载应用：

- **`.deb`**：`sudo apt remove comfyui-desktop-2`。卸载时也会删除 `/etc/apparmor.d/comfyui-desktop-2` 处的 AppArmor 配置。用 `sudo apt purge comfyui-desktop-2` 可一并移除 APT 源和 unattended-upgrades 条目。
- **AppImage**：删除 `.AppImage` 文件。

这两步都不会动你的 ComfyUI 安装或应用数据。只有在需要彻底清理时才删除这些文件夹：

| 数据 | 默认位置 | 说明 |
|------|-----------------|-------------|
| 安装 | `~/ComfyUI-Installs` | 你创建的每个 ComfyUI 安装（也可在应用内删除）。自定义安装路径也不会被移除。 |
| 共享模型与输出 | `~/ComfyUI-Shared` | 共享模型库、输入/输出目录 |
| 应用配置 | `~/.config/comfyui-desktop-2` | 设置和安装记录 |
| 应用数据 | `~/.local/share/comfyui-desktop-2` | 持久化应用数据 |
| 缓存 | `~/.cache/comfyui-desktop-2` | 下载缓存和其他非必要文件 |
| 状态 | `~/.local/state/comfyui-desktop-2` | 运行时状态，例如端口锁 |
| 日志 | `~/.config/comfyui-desktop-2/logs` | 桌面应用日志（`app.log`） |

要彻底删除所有内容：

1. **删除** `Comfy-Desktop` **克隆目录**
2. **删除配置文件夹**：`~/.config/comfyui-desktop-2`
3. **删除数据、缓存和状态文件夹**：`~/.local/share/comfyui-desktop-2`、`~/.cache/comfyui-desktop-2` 和 `~/.local/state/comfyui-desktop-2`
4. **删除各个安装**：在应用内删除，或手动删除 `~/ComfyUI-Installs` 以及你配置过的自定义安装目录
5. **删除共享模型库**：`~/ComfyUI-Shared`（仅在你不再需要这些文件时）

如果你是通过 `.deb` 或 AppImage 安装的，应用还会把配置文件和日志保存在 `~/.config/Comfy Desktop`。可以运行仓库里的 [reset-linux.sh](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/scripts/reset-linux.sh) 脚本清理这些内容：它会删除所有已知的应用数据，但不会影响 `~/ComfyUI-Installs`。
