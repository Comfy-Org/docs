**Comfy Desktop** 是多安装管理器，可从一个启动器运行多个 ComfyUI 实例。Linux 构建以 `.deb`（Debian/Ubuntu）和 AppImage 形式分发。

## 系统要求

- **操作系统：** 基于 Debian 的 Linux（推荐 Ubuntu 22.04 或更高版本）
- **架构：** x64
- **GPU：** 推荐独立显卡（NVIDIA / AMD），但不是必须
- **磁盘空间：** 每个安装建议至少 4.85 GB

## 安装

### Debian / Ubuntu（`.deb`）

在下载包所在目录执行：

```bash
sudo apt install ./*.deb
```

然后从应用菜单启动 **Comfy Desktop**。

### AppImage

```bash
chmod +x ./*.AppImage
./*.AppImage --no-sandbox
```

如果 AppImage 无法启动，请安装 FUSE 2：

```bash
sudo apt install libfuse2
```

也可以从源码构建。参见 [Comfy Desktop 仓库](https://github.com/Comfy-Org/Comfy-Desktop)。

## 卸载

### 移除 Comfy Desktop

- **`.deb`：** 用系统包管理器（`apt`、`dpkg` 或桌面软件中心）移除软件包。
- **AppImage：** 删除 `.AppImage` 文件

### 卸载应用不会删除的内容

卸载 Comfy Desktop 只会移除启动器本身。以下数据**不会**被删除，如需彻底清理必须手动删除：

| 数据 | 默认位置 | 说明 |
|------|-----------------|-------------|
| 安装 | `~/ComfyUI-Installs` | 你创建的每个 ComfyUI 安装（也可在应用内删除）。自定义安装路径也不会被移除。 |
| 共享模型与输出 | `~/ComfyUI-Shared` | 共享模型库、输入/输出目录 |
| 应用配置 | `~/.config/comfyui-desktop-2` | 设置和安装记录 |
| 日志 | `~/.config/comfyui-desktop-2/logs` | 桌面应用日志（`app.log`） |

要彻底删除所有内容：

1. **删除配置文件夹**：`~/.config/comfyui-desktop-2`
2. **删除各个安装**：在应用内删除，或手动删除 `~/ComfyUI-Installs`
3. **删除共享模型库**：`~/ComfyUI-Shared`（仅在你不再需要这些文件时）
