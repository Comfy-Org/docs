**Comfy Desktop** 可以在 Linux 上运行，但目前还没有正式发布的 Linux 安装包。[下载页](https://comfy.org/download) 只提供 Windows 和 macOS。在 Linux 上，请克隆 [Comfy Desktop 仓库](https://github.com/Comfy-Org/Comfy-Desktop) 并从源码运行。

## 系统要求

- **操作系统：** Linux（推荐 Ubuntu 22.04 或更高版本）
- **架构：** x64
- **Node.js：** v22 LTS 或更高版本
- **pnpm：** v10 或更高版本（用 Corepack 启用）
- **GPU：** 推荐独立 GPU（NVIDIA / AMD），但不是必须
- **磁盘空间：** 每个 ComfyUI 安装建议至少 4.85 GB

## 从源码构建并运行

这些步骤与仓库 README 的 [Development](https://github.com/Comfy-Org/Comfy-Desktop#development) 部分一致。

### 前置条件

安装 Node.js 22，然后启用 pnpm：

```bash
nvm install 22 && nvm use 22
corepack enable
```

如果不用 nvm，请从 [nodejs.org](https://nodejs.org/) 安装 Node.js 22。

### 克隆并安装

```bash
git clone https://github.com/Comfy-Org/Comfy-Desktop.git
cd Comfy-Desktop
pnpm run init
```

`pnpm run init` 会安装依赖并构建内置的 bootstrap Python。

### 启动应用

```bash
./linux-dev.sh
```

这会以开发模式启动 Comfy Desktop。脚本会设置 `ELECTRON_DISABLE_SANDBOX=1`，因为 Electron 沙箱在 Linux 开发环境里经常无法启动。

## 更新

源码检出没有应用内自动更新。拉取最新代码后再启动：

```bash
git pull
pnpm run init
./linux-dev.sh
```

## 可选：本地打包

若要自己生成 `.deb` 或 AppImage（不是 Comfy Org 的正式下载）：

```bash
pnpm run build:linux
```

产物在 `dist/`。如果 AppImage 因为 Chromium 无法创建沙箱而失败，再用 `--no-sandbox` 重试。该参数会关闭所有进程的 Electron 沙箱。

## 清理残留数据

停止源码运行不会删除 ComfyUI 安装或应用数据。只有在需要彻底清理时才删除这些文件夹：

| 数据 | 默认位置 | 说明 |
|------|-----------------|-------------|
| 安装 | `~/ComfyUI-Installs` | 你创建的每个 ComfyUI 安装（也可在应用内删除）。自定义安装路径也不会被移除。 |
| 共享模型与输出 | `~/ComfyUI-Shared` | 共享模型库、输入/输出目录 |
| 应用配置 | `~/.config/comfyui-desktop-2` | 设置和安装记录 |
| 应用数据 | `~/.local/share/comfyui-desktop-2` | 持久化应用数据 |
| 缓存 | `~/.cache/comfyui-desktop-2` | 下载缓存和其他非必要文件 |
| 状态 | `~/.local/state/comfyui-desktop-2` | 运行时状态，例如端口锁 |
| 日志 | `~/.config/comfyui-desktop-2/logs` | 桌面应用日志（`app.log`） |

要彻底删除所有内容：

1. **删除** `Comfy-Desktop` **克隆目录**
2. **删除配置文件夹**：`~/.config/comfyui-desktop-2`
3. **删除数据、缓存和状态文件夹**：`~/.local/share/comfyui-desktop-2`、`~/.cache/comfyui-desktop-2` 和 `~/.local/state/comfyui-desktop-2`
4. **删除各个安装**：在应用内删除，或手动删除 `~/ComfyUI-Installs` 以及你配置过的自定义安装目录
5. **删除共享模型库**：`~/ComfyUI-Shared`（仅在你不再需要这些文件时）
