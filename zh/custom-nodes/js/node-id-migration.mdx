ComfyUI 前端现在会在内部边界将本地节点 ID 规范化为带品牌标记的 `NodeId` 字符串类型。序列化工作流和 API 负载仍可能包含数字 ID，但进入前端后，litegraph（旧版）中的节点 ID（例如 `node.id`、`LLink.origin_id` 和 `LLink.target_id`）应被视为字符串。连线 ID（`LLink.id`）和重新路由 ID 仍为数字。

扩展作者应避免对节点 ID 进行数值比较。特别地，子图边界哨兵值以带品牌标记的字符串 ID 的形式暴露：

- `SUBGRAPH_INPUT_ID` 从 `-10` 序列化而来
- `SUBGRAPH_OUTPUT_ID` 从 `-20` 序列化而来

请与字符串 `'-10'` 和 `'-20'` 进行比较，或者在比较传统值之前将双方都规范化为字符串。
