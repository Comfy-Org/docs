自定义节点允许你实现新功能，并与更广泛的社区分享。

自定义节点与任何 Comfy 节点一样：接收输入，对其进行处理，并产生输出。虽然有些自定义节点执行高度复杂的任务，但许多节点只做一件事。下面是一个简单节点的示例，它接收图像并将其反转。

## 客户端-服务器模型

Comfy 采用客户端-服务器模型运行。服务器端使用 Python 编写，负责所有实际工作：数据处理、模型、图像扩散等。客户端使用 JavaScript 编写，负责用户界面。

Comfy 还可以通过 API 模式使用，在此模式下，工作流由非 Comfy 客户端（例如其他 UI 或命令行脚本）发送到服务器。

自定义节点可分为以下四类：

### 仅服务器端

大多数自定义节点仅在服务器端运行，通过定义一个 Python 类来指定输入和输出类型，并提供可调用的函数来处理输入并生成输出。

### 仅客户端

少数自定义节点只对客户端 UI 进行修改，但不会增加核心功能。尽管名称如此，它们甚至可能不会向系统添加新节点。

### 独立的客户端和服务器

自定义节点可以提供额外的服务器功能，以及额外的（相关）UI 功能（例如用于处理新数据类型的新组件）。在大多数情况下，客户端与服务器之间的通信可以由 Comfy 的数据流控制来处理。

### 连接式客户端和服务器

在少数情况下，UI 功能与服务器需要直接相互交互。

<Warning>任何需要客户端-服务器通信的节点都无法兼容通过 API 使用。</Warning>
