Comfy Cloud 是 ComfyUI 的有状态、可交互、完全托管版本。你可以像在本地安装中一样，在浏览器里构建和运行工作流，而模型、GPU 以及其间的一切都由 Comfy 管理。你也可以通过 API 调用 Comfy Cloud。Comfy Cloud 提供托管端点，因此无需构建环境，也无需创建部署。

与 [Comfy API 部署](/zh/development/serverless/overview) 不同（后者提供的是你构建并发布的一个固定环境），Comfy Cloud 提供的是始终在线的、完整托管的 ComfyUI。

<Note>
  如果你是 Comfy Cloud 的新用户，请参阅 [Comfy Cloud 简介](/zh/get_started/cloud)。本节介绍如何以开发者身份使用 Comfy Cloud API。
</Note>

## 快速开始

Comfy Cloud 开箱即可配合 [Comfy SDK](/zh/development/api-development/sdks) 使用：基础 URL 默认指向 Comfy Cloud，因此你只需要一个 [API 密钥](/zh/development/api-development/getting-an-api-key) 和一个工作流。API 访问需要付费的 Comfy Cloud 订阅，免费套餐不包含此功能。

<Steps>
  <Step title="创建 API 密钥">
    登录 [platform.comfy.org](https://platform.comfy.org) 并创建一个密钥。分步说明请参阅 [获取 API 密钥](/zh/development/api-development/getting-an-api-key)。
  </Step>
  <Step title="安装 SDK">
    <CodeGroup>
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    </CodeGroup>
  </Step>
  <Step title="以 API 格式导出工作流">
    在云端编辑器中构建并测试工作流，然后通过 `File → Export Workflow (API)` 将其保存为 `workflow_api.json`。请参阅 [工作流 API 格式](/zh/development/api-development/workflow-api-format)。
  </Step>
  <Step title="运行它">
    <CodeGroup>
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")  # Comfy Cloud is the default target

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." }); // Comfy Cloud is the default target

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    </CodeGroup>

    `"9"` 是你的工作流文件中输出节点的 ID。有关输入、进度事件和错误处理的信息，请参阅 [SDK 指南](/zh/development/api-development/sdks)。
  </Step>
</Steps>

关于同一段代码如何在 Comfy Cloud、Comfy API 部署和自托管部署之间切换，请参阅 [运行工作流](/zh/development/run-workflows/overview)。

## 积分与用量

API 请求与 Comfy Cloud 网页界面共用同一份月度积分额度。不存在单独的 API 积分池。各档位包含的积分、充值选项以及每个工作流的运行时长上限，对 API 任务与 UI 任务完全同样适用。各档位的月度积分额度请参阅[定价页面](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)。如果月中积分已用完，可以从你的账户仪表盘购买充值。

## 并行执行（并发任务）

API 用户可以同时提交多个工作流，无需等待上一个任务完成。提交后，任务一经接受即返回，因此你可以同时保持多个任务在运行。调度器会并行执行这些任务，直至达到你订阅套餐的并发上限；请访问 [platform.comfy.org](https://platform.comfy.org) 查看你当前的并发数。

超出并发上限提交的任务会正常排队，并在槽位空出时自动执行。如果队列本身已满，SDK 会在有限的重试预算内自动为你重试，之后才抛出 `QueueFull`。

<Info>
  并行执行目前仅可通过 API 使用。订阅详情请查看 [定价页面](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)。
</Info>

## 现有的 v1 集成

弃用的 [v1 Cloud API](/zh/development/cloud/overview) 同样运行在 Comfy Cloud 上。请仅将其用于现有集成，或用于 [Comfy API v2](/zh/api-reference/v2/overview) 尚未开放的那些云端能力。可运行的示例位于 [Cloud API Reference](/zh/development/cloud/api-reference)（已弃用）。
