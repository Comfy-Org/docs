你可以通过 [Comfy SDKs](/zh/development/api-development/sdks)，从你自己的应用（例如后端服务或批处理脚本）中运行在 Comfy Cloud 编辑器中构建的工作流。Comfy Cloud 会在带有默认自定义节点集的标准构建上运行工作流。如果某个工作流需要标准构建中不具备的自定义节点或模型，你可以创建一个自定义构建：这是一个由你自己的自定义节点和模型组成的包，Comfy Cloud 会为你运行它。本页将展示如何通过 API 在标准构建上运行工作流，然后展示如何将同一份代码指向自定义构建。

## 开始之前

要从代码中调用 Comfy Cloud，请确保具备以下条件：

- **付费的 Comfy Cloud 订阅**
- **能在 Comfy Cloud 编辑器中运行的工作流**：在通过代码运行之前，先在编辑器中测试它。如果它需要标准构建中没有的自定义节点或模型，请先[创建自定义构建](/zh/development/deploy/cloud-custom-builds)。
- **Python 3.10 或更高版本，或 Node 22 或更高版本**：你安装的 SDK 需要其中一种。

如果你还没有使用过 Comfy Cloud，请从 [Comfy Cloud](/zh/get_started/cloud) 开始。

## 在标准构建上运行工作流

标准构建可以运行任何工作流，前提是该工作流只使用 Comfy Cloud 支持的自定义节点。要从代码中运行工作流，你需要创建 API 密钥、安装 SDK，并以 API 格式导出工作流。

<Steps>
  <Step title="创建 API 密钥">
    你的应用程序会在每次请求时发送该密钥，因此请在开发者平台上为你的应用程序创建一个密钥。

    1. 登录 [platform.comfy.org](https://platform.comfy.org)，然后点击 **API 密钥**。
    2. 点击 **新建 API 密钥**，输入名称，然后点击 **生成密钥**。
    3. 复制该密钥并妥善保存。开发者平台只会显示一次。

    该密钥以 `comfyui-` 开头。有关如何管理密钥，请参阅[获取 API 密钥](/zh/development/api-development/getting-an-api-key)。
  </Step>
  <Step title="安装 SDK">
    <CodeGroup>
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    </CodeGroup>
  </Step>
  <Step title="以 API 格式导出工作流">
    SDK 发送的是工作流的 API 格式，而不是编辑器保存的文件。

    - 在 Comfy Cloud 编辑器中，打开工作流，选择 **文件** > **导出 (API)**，然后将文件保存为 `workflow_api.json`。

    有关该文件包含的内容，请参阅[工作流 API 格式](/zh/development/api-development/workflow-api-format)。
  </Step>
  <Step title="运行工作流">
    除非你设置其他基础 URL，否则 SDK 会将请求发送到 Comfy Cloud，因此只需传入你的 API 密钥：

    <CodeGroup>
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." });

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    </CodeGroup>

    - 将 `"9"` 替换为你的 `workflow_api.json` 中输出节点的 ID。
    - `run()` 会等待任务完成，然后代码会将输出写入磁盘。

    如需设置输入、跟踪进度并处理错误，请参阅 [Comfy SDKs](/zh/development/api-development/sdks)。
  </Step>
</Steps>

## 在自定义构建上运行工作流

部署自定义构建会为你提供一个拥有独立 URL 的部署。更改基础 URL 后，上一节的代码便会在该部署上运行。

<Warning>
  部署在其 worker 运行期间会产生 GPU 时间费用，并在你删除它之前持续产生存储费用。测试完成后，请停止或删除它。请参阅[清理](/zh/development/serverless/overview#清理)。
</Warning>

<Steps>
  <Step title="创建并部署构建">
    按照[自定义构建](/zh/development/deploy/cloud-custom-builds)的说明，从你的工作流创建构建并部署它。
  </Step>
  <Step title="复制部署 URL">
    1. 在开发者平台中，打开该部署的页面。
    2. 等待部署的状态显示为 **Ready**。
    3. 在 **Run via API** 中，复制 **Deployment URL**。

    部署 URL 的格式为 `https://dep-<id>.run.comfy.app`。
  </Step>
  <Step title="设置基础 URL">
    将 `COMFY_BASE_URL` 设置为部署 URL：

    ```bash
    export COMFY_BASE_URL="https://dep-<id>.run.comfy.app"
    ```
  </Step>
  <Step title="运行工作流">
    使用你的 API 密钥运行[在标准构建上运行工作流](#在标准构建上运行工作流)中的代码。SDK 现在会将任务发送到你的部署。
  </Step>
</Steps>

<Tip>
  如需先从终端测试部署，请运行：

  ```bash
  comfy deploy run --deployment <deployment-id> --workflow workflow_api.json
  ```
</Tip>
