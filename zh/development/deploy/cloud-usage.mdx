通过 Comfy Cloud API 提交的工作流使用与其他云端工作流相同的积分和并发限制。

## 积分与用量

API 请求与 Comfy Cloud Web UI 使用相同的月度积分分配。没有单独的 API 积分池。每个套餐层级包含的积分、充值选项以及每工作流运行时长上限，均与 UI 任务一样适用于 API 任务。

有关月度积分额度和充值选项，请参阅[定价页面](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)。你可以从账户仪表盘购买充值。

## 并发限制

你可以提交多个工作流，而无需等待上一个任务完成。任务会并行运行，上限取决于你的订阅层级：

| 套餐 | 并发工作流数 |
| :--- | :--- |
| 标准版 | 1 |
| 创作者版 | 3 |
| 专业版 | 5 |

团队版套餐中每位成员可运行的并发工作流数多于专业版。请查看 [platform.comfy.org](https://platform.comfy.org)，了解你账户的并发限制。其他任务会排队，并在有可用槽位时运行。

如果队列已满，SDK 会在有限的重试预算内重试，然后抛出 `QueueFull`。

在团队版和企业版套餐中，并发数按成员计算：工作区中的每个人都有各自的并发限制，因此某个成员正在运行的任务绝不会阻塞其他成员的任务。

<Info>
  同时运行多个任务仅支持通过 API 进行。Comfy Cloud 界面每人一次只能运行一个工作流，在编辑器中排队的工作流会按顺序运行。订阅详情请参阅[定价页面](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)。
</Info>

## 运行时长与队列限制 {#runtime-and-queue-limits}

每个 Cloud 工作流都有最长运行时长。运行超时的任务会被自动取消：

| 方案 | 最长运行时长 |
| :------- | :-------------- |
| Standard | 30 分钟 |
| Creator | 30 分钟 |
| Pro | 1 小时 |

最多可同时有 100 个工作流排队。如需提高团队并发限制，请[联系支持](https://support.comfy.org/)。

## 部署计费

自定义 Build 的[部署](/zh/development/serverless/overview)会针对其 worker 计收 GPU 时间费用、针对其模型计收存储费用，均从 Comfy 积分中扣除。

### 未部署的 Build 会收取存储费用吗？

不会。Build 及其版本免费存储。存储计费从你部署时开始：

- 当你部署某个版本时，Comfy Cloud 会将该版本的模型复制到该部署的 worker 共享的网络存储中。只要该 Build 的部署存在于该区域，Comfy Cloud 就按每 GB 每月对该存储计费，包括部署处于停止状态期间。任务从你的[工作区库](/zh/development/deploy/cloud-custom-builds#添加自己的-lora-或模型)中使用的模型不会被复制到那里。worker 会为该任务下载这些模型。
  - 你[添加到部署](/zh/development/serverless/overview#向运行中的部署添加模型)的模型也会被复制到那里，并计入该存储用量。
- 每个 worker 上的本地磁盘除 GPU 费率外不产生额外费用。
- 删除部署会释放其计算资源。网络存储的计费会在你删除最后一个使用该存储的部署时结束。

有关存储和 GPU 费率，请在开发者平台打开 [**Limits**](https://platform.comfy.org/settings/limits) 并查看 **Deployment pricing**。部署对话框中的 **Estimated cost** 面板也会显示某次部署的 GPU 时间和模型存储。

### 常驻预热 worker 如何计费？

[常驻预热 worker](/zh/development/serverless/overview#缩放-worker)（comfy-cli 中的 `--min`）只要在运行，就会计收 GPU 时间费用，无论是否处理任务。

数量超出该值的 worker（最多到 **Max workers**，即 `--max`）会在任务到来时启动。它们的 GPU 时间计费从启动那一刻开始，涵盖其处理任务的整个过程，以及最后一个任务结束后到被释放之间的空闲时间。默认情况下，worker 在最后一个任务结束后会继续运行 3 分钟。在开发者平台创建部署时，你可以在 **Keep worker up after a job** 中将该时间设置为 30 秒到 20 分钟。当常驻预热 worker 数量为 `0` 时，一旦这段空闲时间结束、所有 worker 都被释放，GPU 计费就会停止。下一个任务需要等待 GPU 启动。

如果你的工作区积分已用完，其部署将会停止。

有关 GPU 费率，请在开发者平台打开 [**Limits**](https://platform.comfy.org/settings/limits) 并查看 **Deployment pricing**。费率按每个 worker 每运行一小时计算。

## 现有的 v1 集成

已弃用的 [v1 Cloud API](/zh/development/cloud/overview) 同样可以针对 Comfy Cloud 运行。如果你已有现有集成，或需要 [Comfy API v2](/zh/api-reference/v2/overview) 尚未提供的云端能力，可以使用它。可运行的示例位于已弃用的 [Cloud API Reference](/zh/development/cloud/api-reference) 中。
