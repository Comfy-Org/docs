通过 Comfy Cloud API 提交的工作流，使用与其他 Cloud 工作流相同的积分和并发限制。

## 积分与用量

API 请求与 Comfy Cloud Web UI 共用同一个月度积分额度，没有单独的 API 积分池。各套餐包含的积分、充值选项以及单个工作流的运行时长上限，对 API 任务和 UI 任务同样适用。

月度积分数量与充值选项请参阅[定价页面](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)。你可以在账户仪表盘中购买充值。

## 并发任务

你可以提交多个工作流，而无需等待上一个任务完成。任务会并行运行，直至达到你所订阅套餐的上限。请在 [platform.comfy.org](https://platform.comfy.org) 查看你当前的并发上限。超出的任务会进入队列，在有可用槽位时依次运行。

如果队列已满，SDK 会在有限的预算内重试，之后抛出 `QueueFull`。

<Info>
  通过 API 可以并行执行。订阅详情请参阅[定价页面](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)。
</Info>

## 现有的 v1 集成

已弃用的 [v1 Cloud API](/zh/development/cloud/overview) 同样运行在 Comfy Cloud 上。如果你已有集成，或需要使用 [Comfy API v2](/zh/api-reference/v2/overview) 尚未提供的云端能力，可以继续使用它。可运行的示例位于已弃用的 [Cloud API 参考](/zh/development/cloud/api-reference)中。
