  `data[].b64_json` 中字节的编码格式：`png`、`webp` 或 `jpeg`。它是 OpenAI 实际编码所用的格式：发送了请求的 `output_format` 时就是该值，未发送时则为 `png`，因此解码器可以直接依据它，而不必从请求中重新推导格式。
</ResponseField>

<ResponseField name="quality" type="string">
  本次生成实际使用的质量档位：OpenAI 报告的是 `low`、`medium`、`high`、`xhigh` 或 `max` 之一。它是已解析的档位，而不是对请求的回显，因为请求自身的 `quality` 默认为 `auto`。
</ResponseField>

<ResponseField name="size" type="string">
  本次生成实际使用的像素尺寸，格式为 `<width>x<height>`。它是已解析的尺寸：请求的 `size` 默认为 `auto` 并明确接受 `auto`，因此这里是唯一报告实际所用尺寸的地方。
</ResponseField>
