<ParamField body="mask" type="string">

抓取仅限于一组命名的主机，而不是开放的互联网，并且同一份列表会重新应用于每一个重定向跳转以及你发送的 URL，因此在任何其他主机上的 URL，或者会重定向到列表之外的主机，都会在联系任何提供商之前被拒绝。目前该列表仅包含 Comfy 自身的资产交付：Comfy 资产桶下的已签名 `storage.googleapis.com` URL，也就是 `/api/assets/{id}/content` 将你重定向到的形式。合作伙伴 CDN 或普通的 https 主机不在此列表中。
