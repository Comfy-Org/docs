它可以原样复制：`{"prompt": "give the rocketship rainbow coloring", "image": ["data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg=="], "size": "1024x1024"}`。其中的 payload 是一个完整的 1x1 PNG，而非缩写，并且该请求体已被固定为 Router 自身请求验证测试中的可接受用例。请替换为你自己图像的字节。

</ParamField>

<ParamField body="mask" type="string">
  一张图像，形式可以是 Router 代表调用方获取的 https URL，也可以是内联携带字节的 `data:image/<format>;base64,<payload>` URI。接受的图像类型为 png、webp 和 jpeg，该集合在解析时即强制执行，而不是留给提供商处理：svg、gif、avif 或 tiff 会在此处被拒绝，并指出你发送的图像，而不会变成距离原因两跳之外的合作伙伴错误。
优先使用 URL 形式。base64 payload 大约膨胀至 4/3，而整个请求体上限为 20 MiB，因此内联形式大约只能容纳接近 15 MB 的来源图像；URL 则完全绕过这一点。
URL 必须在不携带你的凭证的情况下可解析。Router 在服务器端获取它，并且不会随请求发送调用方凭证，因此预签名 URL（签名位于查询字符串中的那种）才是受支持的形式。诸如 `/api/assets/{id}/content` 这样的需要身份验证的端点会向 Router 返回 401 而不是图像；请自行请求该 URL，并传入它重定向到的已签名 URL。
获取仅限于一组具名主机，而非开放的互联网，同一列表会重新应用于你发送的 URL 以及每一次重定向跳转。因此任何其他主机上的 URL，或重定向到列表之外的主机，都会在任何提供商被联系之前被拒绝。目前该列表仅包含 Comfy 自身的资产交付：Comfy 资产存储桶下的已签名 `storage.googleapis.com` URL，这正是 `/api/assets/{id}/content` 重定向到的形式。合作伙伴 CDN 或普通的 https 主机不在该列表中。
两项放宽正在逐步推出，目前二者默认均处于关闭状态。它们通过一个切换开关发布并一同启用，因此请将以下所有内容视为即将推出，而不是现在就可依赖开发的内容；在依赖其中任何一项之前，请先询问。
第一项是 `POST /customers/storage` 为你的上传签名的存储桶。在推出到达你的环境之前，来自该端点的上传 URL 会在此处被拒绝，即使该存储桶是 Comfy 自己的、主机也相同。因此“上传到 Comfy，再传入 URL”目前还不可行，可行的形式是 `/api/assets/{id}/content` 重定向到的已签名 URL。
第二项额外允许以下第三方对象存储主机，其中的存储桶属于你，Router 不对其主张所属权：Cloudflare R2（`<account>.r2.cloudflarestorage.com`、`<id>.r2.dev`）、Amazon S3（`s3.amazonaws.com` 和 `s3.<region>.amazonaws.com`，采用路径风格或以 `<bucket>.` 为前缀的形式）、Azure Blob Storage（`<account>.blob.core.windows.net`）以及阿里云 OSS（`<bucket>.oss-<region>.aliyuncs.com`，包括 `oss-accelerate` 端点）。这些特指对象存储端点：同一提供商域名下的通用端点，例如阿里云函数计算触发器，不在列表中，会被拒绝。

每个图像上限为 25 MiB，单个请求中的图像总计上限为 64 MiB。
