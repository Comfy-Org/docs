<ParamField body="mask" type="string">
  单张图像，可以是 Router 代表调用方获取的 https URL，也可以是内联携带字节的 `data:image/<format>;base64,<payload>` URI。可接受的图像类型为 png、webp 和 jpeg，该集合在解析时即被强制执行，而不是交由提供商判断：svg、gif、avif 或 tiff 会在此处被拒绝，并指明你发送的是哪张图像，而不会在离原因两跳之外变成一个合作伙伴错误。
优先使用 URL 形式。base64 载荷会膨胀约 4/3，而整个请求体上限为 10 MiB，因此内联形式在来源图像接近 7.5 MB 时就到达上限；使用 URL 则完全避开这一限制。
该 URL 必须在不使用你的凭据的情况下即可解析。Router 会在服务器端获取它，并且不会随请求发送任何调用方凭据，因此受支持的形式是 Comfy 签名的资产 URL，即签名位于查询字符串中的那种。诸如 `/api/assets/{id}/content` 这类需要认证的端点会向 Router 返回 401 而不是图像；请自行请求该 URL，并传入它重定向到的签名 URL。该获取被限制在 Comfy 自己的资产存储桶内，而不涉及开放互联网，这一点对你发送的 URL 以及每一次重定向跳转都适用，因此第三方 URL 或会发生重定向的 URL 都会被拒绝。
