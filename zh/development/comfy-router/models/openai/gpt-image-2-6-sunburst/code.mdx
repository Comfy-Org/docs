URL 必须在不携带你的凭证的情况下可解析。Router 在服务器端抓取它，并且不会随请求发送任何调用方凭证，因此受支持的形式是预签名 URL，即签名位于查询字符串中的 URL。诸如 `/api/assets/{id}/content` 这类需要认证的 endpoint 会向 Router 返回 401 而不是图像；请自行请求该 URL，并传入它重定向到的已签名 URL。
