  `data[].b64_json` 中字节的编码格式，取值为 `png`、`webp` 或 `jpeg`。它是 OpenAI 实际编码所用的格式：若请求中发送了 `output_format`，则与之相同；若未发送，则为 `png`。因此解码器可以直接依据它，而不必再从请求中反推格式。
</ResponseField>

<ResponseField name="quality" type="string">
  本次生成实际使用的质量档位。OpenAI 会报告 `low`、`medium`、`high`、`xhigh` 或 `max` 之一。它是解析后的档位，而不是对请求的回显，因为请求自身的 `quality` 默认值为 `auto`。
</ResponseField>

<ResponseField name="size" type="string">
  本次生成实际使用的像素尺寸，格式为 `<width>x<height>`。它是解析后的尺寸：请求的 `size` 默认值为 `auto`，且明确接受 `auto`，因此这里是唯一报告实际所用尺寸的地方。
</ResponseField>
