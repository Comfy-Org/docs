<ParamField body="mask" type="string">
  单张图像，可以是 Router 代表调用方获取的 https URL，也可以是内联携带字节的 `data:image/<format>;base64,<payload>` URI。可接受的图像类型为 png、webp 和 jpeg，该集合会在解析时强制执行，而不会留给提供商处理：svg、gif、avif 或 tiff 会在此处被拒绝，并指出你发送的是哪张图像，而不是变成距离根因两步之遥的合作伙伴错误。
优先使用 URL 形式。base64 载荷大约会膨胀至 4/3，而整个请求体的上限为 10 MiB，因此内联形式的上限约为 7.5 MB 的源图像；使用 URL 则可完全避开这一限制。
该 URL 必须无需你的凭据即可解析。Router 在服务器端获取它，且不会随请求发送任何调用方凭据，因此受支持的形式是 Comfy 签名的资产 URL，即签名位于查询字符串中的 URL。诸如 `/api/assets/{id}/content` 这类需认证的端点会向 Router 返回 401 而不是图像；请自行请求该 URL，并传入它重定向到的签名 URL。无论是在你发送的 URL 上，还是在每个重定向跳转上，获取都被限制在 Comfy 自己的资产存储桶内，而非开放的互联网，因此第三方 URL 或会重定向的 URL 都会被拒绝。
