<ResponseField name="status" type="string">
  生成状态（PENDING、PROCESSING、COMPLETED、NO_OP、FAILED、REJECTED）。NO_OP 为终端状态；未进行任何唇形同步，`outputUrl` 是未更改的输入视频（加上任何已生成的语音），Sync 不对唇形同步收费，Comfy 也不向调用方计费。
</ResponseField>

<ResponseField name="synthesizedAudioUrl" type="string">
  根据文本（TTS）输入合成的音频的 URL
</ResponseField>

<ResponseField name="webhookUrl" type="string">
  指向 webhook 端点的 URL
</ResponseField>
