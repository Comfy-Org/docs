## Schema

### 输入

<ParamField body="contents" type="object[]">
  提示词和输入媒体。条目类型决定 Kling 的操作：只包含 "prompt"、"first_frame"、"middle_frame" 和 "last_frame" 条目时选择图生视频（一个提示词和最多 10 帧）；包含任何 "refer_image"、"feature_video"、"base_video"、"element" 或 "voice" 条目时选择 omni 视频；`contents` 缺失或为空时保持文生视频。Omni 视频最多接受 15 个输入加上提示词条目（共 16 个条目），其中最多 10 个图像（帧和 "refer_image"）、5 个视频（"feature_video" 和 "base_video"，最多一个 "base_video"）、7 个元素和 3 个声音；超出上述任一限制的请求都会被拒绝，并返回指明 `contents` 的 422。要使用主体，添加条目 `{"type": "element", "element_id": "<Kling element ID>", "id": "hero"}`；要使用声音，添加条目 `{"type": "voice", "voice_id": "<Kling voice ID>", "id": "narrator"}`。两者都需要 `id`，提示词条目以 @hero 和 @narrator 引用它们。元素 ID 和自定义声音 ID 属于创建它们的 Kling 账户。带 "feature_video"、"base_video" 或视频角色元素的请求按视频输入费率计费。
</ParamField>

<ParamField body="contents[].element_id" type="string">
  Kling 元素 ID，当 type 为 "element" 时使用。元素是 Kling 上已存在的主体（角色或物体）；该条目只是引用它，不会上传它。Kling 将元素 ID 限定在创建它的 Kling 账户范围内，因此在其他 Kling 账户上创建的 ID 无法解析。每个 omni 视频请求最多 7 个元素。视频角色元素按视频输入费率计费；comfy-api 无法从 `element_id` 分辨它，因此估算可能按较低费率计算。
</ParamField>

<ParamField body="contents[].id" type="string">
  此输入的引用 ID，由调用方选择，提示词以 @id 的形式使用它。必须在任务内唯一。"element" 和 "voice" 为必填。
</ParamField>

<ParamField body="contents[].text" type="string">
  文本提示词，当 type 为 "prompt" 时使用。最多 26,000 个英文字符或 11,000 个非英文字符；comfy-api 强制 1 到 26,000 个字符，而 Kling 自身会拒绝更长的非英文文本。引用其他条目时，写入 @ 后跟该条目的 `id`：例如有一个 `id` 为 "hero" 的元素条目和一个 `id` 为 "narrator" 的声音条目时，可以写 "@hero walks into the room and @narrator says hello"。
</ParamField>

<ParamField body="contents[].type" type="string" required>
  输入类型。图生视频只接受 "prompt"、"first_frame"、"middle_frame" 和 "last_frame"，并拒绝其他任何类型。Omni 视频还接受 "refer_image"、"feature_video"（参考视频）、"base_video"（要编辑的视频，最多一个）、"element"（主体，由 `element_id` 指定）和 "voice"（声音，由 `voice_id` 指定）。Comfy Router id kling/kling-4.0-flash 完全不接受 `contents`。/proxy Kling 4.0 Flash 的图生视频和 omni 视频路由接受的集合比 Kling 4.0 更窄：图生视频为 "prompt" 和 "first_frame"，omni 视频为 "prompt"、"first_frame"、"refer_image"、"feature_video"、"base_video" 和 "element"，没有 "voice"。

  可能的值：`prompt`、`first_frame`、`middle_frame`、`last_frame`、`refer_image`、`feature_video`、`base_video`、`element`、`voice`
</ParamField>

<ParamField body="contents[].url" type="string">
  图像或视频 URL，当 type 为帧、"refer_image"、"feature_video" 或 "base_video" 时使用。图像也可以使用 Base64。图像为 .jpg、.jpeg 或 .png，最大 30MB，每边至少 300px，宽高比在 2:5 到 5:2 之间。视频为 .mp4 或 .mov，最大 300MB，时长 3 到 30 秒。
</ParamField>

<ParamField body="contents[].voice_id" type="string">
  Kling 声音 ID，当 type 为 "voice" 时使用：Kling 预设声音或自定义声音。Kling 将自定义声音 ID 限定在创建它的 Kling 账户范围内。每个 omni 视频请求最多 3 个声音。/proxy Kling 4.0 Flash 路由不接受声音条目，Router id kling/kling-4.0-flash 也不接受 `contents`。
</ParamField>

<ParamField body="options" type="object">
  常规配置，例如水印选项。Kling 4.0 不支持 `options.callback_url` 和 `options.external_task_id`；Comfy Router 会拒绝在 `options` 中设置其中任一字段的请求。顶层 `callback_url` 或 `external_task_id` 不属于此 schema，会在请求到达 Kling 之前被移除。
</ParamField>

<ParamField body="options.watermark_info" type="object">
  是否同时生成带水印的结果。不支持自定义水印。显式的 null 会被视为缺失，与 /proxy Kling 4.0 的校验及 Kling 的行为一致。
</ParamField>

<ParamField body="options.watermark_info.enabled" type="boolean">
  是表示生成带水印的结果，否表示不生成。默认否。
</ParamField>

<ParamField body="prompt" type="string">
  文生视频提示词。当 `contents` 缺失或为空时必填，与不为空的 `contents` 同时出现时会被拒绝。最多 26,000 个英文字符或 11,000 个非英文字符；comfy-api 强制 1 到 26,000 个字符，而 Kling 自身会拒绝更长的非英文文本。
</ParamField>

<ParamField body="settings" type="object" required>
  输出配置，例如分辨率、宽高比和时长。
</ParamField>

<ParamField body="settings.aspect_ratio" type="string">
  已生成帧的宽高比（宽度:高度）。文生视频可选 "21:9"、"16:9"、"9:16"、"1:1"、"4:3" 或 "3:4"（默认 "16:9"）；omni 视频可选上述值或 "adaptive"（默认 "adaptive"）。图生视频跟随图像。显式的 null 会被视为缺失，与 /proxy Kling 4.0 的校验及 Kling 的行为一致。

  可能的值：`21:9`、`16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`adaptive`
</ParamField>

<ParamField body="settings.duration" type="integer">
  视频时长，单位为秒，取值范围为 3 到 30。除非 `contents` 中包含 "base_video"，此时编辑操作可以省略该字段以保留基础视频的时长，否则该字段必填。这类调用会被挂起，并按所请求分辨率下 30 秒的最大值进行估算，该值只是上限而非价格，最终会依据 Kling 为已完成任务报告的价格计费。

  范围：`3` 到 `30`
</ParamField>

<ParamField body="settings.dynamic_range" type="string">
  已生成视频的动态范围。取值为 "sdr" 或 "hdr" 之一。默认 "sdr"。"hdr" 需要 "1080p" 或 "4k" 分辨率，在 "720p" 下会被拒绝。HDR 视频的每个输出秒费用更高。显式传入 null 会被视为未提供，/proxy Kling 4.0 校验和 Kling 均如此处理。

  可选值：`sdr`、`hdr`
</ParamField>

<ParamField body="settings.resolution" type="string" required>
  已生成视频的分辨率。取值为 "720p"、"1080p" 或 "4k" 之一。必填。

  可选值：`720p`、`1080p`、`4k`
</ParamField>
