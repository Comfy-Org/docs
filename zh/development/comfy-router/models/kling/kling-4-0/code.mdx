### 输入

<ParamField body="contents" type="object[]">
  提示词与输入媒体。仅包含 "prompt"、"first_frame"、"middle_frame" 和 "last_frame" 项时选择图生视频（一个提示词和最多 10 帧）；包含任何 "refer_image"、"feature_video"、"base_video"、"element" 或 "voice" 时选择 omni video（最多 15 个输入，其中最多 10 张图像、5 个视频、7 个元素和 3 个音色）。带有 "feature_video"、"base_video" 或视频角色元素的请求按视频输入费率计费。
</ParamField>

<ParamField body="contents[].element_id" type="string">
  元素 ID，当 type 为 "element" 时使用。
</ParamField>

<ParamField body="contents[].id" type="string">
  该输入的引用 ID，在提示词中用作 @id。必须在任务内唯一。"element" 和 "voice" 必填。
</ParamField>

<ParamField body="contents[].text" type="string">
  文本提示词，当 type 为 "prompt" 时使用。最多 26,000 个英文字符或 11,000 个非英文字符；comfy-api 强制限制为 1 到 26,000 个字符，而 Kling 本身会拒绝更长的非英文文本。可使用 @id 引用其他输入。
</ParamField>

<ParamField body="contents[].type" type="string" required>
  输入类型。图生视频仅接受 "prompt"、"first_frame"、"middle_frame" 和 "last_frame"，并拒绝任何其他类型。omni video 还接受 "refer_image"、"feature_video"（参考视频）、"base_video"（要编辑的视频，最多一个）、"element" 和 "voice"。

  可能的值：`prompt`, `first_frame`, `middle_frame`, `last_frame`, `refer_image`, `feature_video`, `base_video`, `element`, `voice`
</ParamField>

<ParamField body="contents[].url" type="string">
  图像或视频 URL，当 type 为某一帧、"refer_image"、"feature_video" 或 "base_video" 时使用。图像也可以使用 Base64。图像为 .jpg、.jpeg 或 .png，最大 30MB，每边至少 300px，宽高比在 2:5 到 5:2 之间。视频为 .mp4 或 .mov，最大 300MB，时长 3 到 30 秒。
</ParamField>

<ParamField body="contents[].voice_id" type="string">
  音色 ID，当 type 为 "voice" 时使用。可以是 Kling 预设音色或自定义音色。
</ParamField>

<ParamField body="options" type="object">
  常规配置，例如水印选项。Kling 4.0 不支持 `options.callback_url` 和 `options.external_task_id`；Comfy Router 会拒绝在 `options` 内设置其中任意一项的请求。顶层的 `callback_url` 或 `external_task_id` 不属于此 schema，会在请求到达 Kling 之前被移除。
</ParamField>

<ParamField body="options.watermark_info" type="object">
  是否同时生成带水印的结果。不支持自定义水印。显式的 null 会被视为未提供，与 /proxy 的 Kling 4.0 检查和 Kling 的行为一致。
</ParamField>

<ParamField body="options.watermark_info.enabled" type="boolean">
  true 表示生成带水印的结果，false 表示不生成。默认为 false。
</ParamField>

<ParamField body="prompt" type="string">
  文生视频提示词。当 `contents` 缺失或为空时必填，与非空 `contents` 同时提供时会被拒绝。最多 26,000 个英文字符或 11,000 个非英文字符；comfy-api 强制限制为 1 到 26,000 个字符，而 Kling 本身会拒绝更长的非英文文本。
</ParamField>

<ParamField body="settings" type="object" required>
  输出配置，例如分辨率、宽高比和时长。
</ParamField>

<ParamField body="settings.aspect_ratio" type="string">
  已生成画面的宽高比（宽度:高度）。文生视频为 "21:9"、"16:9"、"9:16" 或 "1:1" 之一（默认 "16:9"）；omni video 为这些值或 "adaptive"（默认 "adaptive"）。图生视频则跟随图像。显式的 null 会被视为未提供，与 /proxy 的 Kling 4.0 检查和 Kling 的行为一致。

  可能的值：`21:9`, `16:9`, `9:16`, `1:1`, `adaptive`
</ParamField>

<ParamField body="settings.duration" type="integer">
  视频时长，单位为秒，3 到 30。除非 `contents` 包含 "base_video"（此时编辑操作可省略该字段以保留基础视频的时长），否则为必填。此类调用会被挂起，并按所请求分辨率下的 30 秒上限进行估算，这只是上限而非实际价格，最终按 Kling 为已完成任务上报的价格计费。

  范围：`3` 到 `30`
</ParamField>

<ParamField body="settings.resolution" type="string" required>
  已生成视频的分辨率。"720p" 或 "1080p" 之一。必填。

  可能的值：`720p`, `1080p`
</ParamField>
