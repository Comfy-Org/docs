</ParamField>

<ParamField body="contents[].type" type="string" required>
  输入类型。取值为 "prompt"、"refer_image" 或 "element" 之一。必须包含一个 prompt 项。参考图像和元素合计最多 10 个。

  可能的值：`prompt`、`refer_image`、`element`
</ParamField>

<ParamField body="contents[].url" type="string">
  图片网址或 Base64 数据，当 type 为 "refer_image" 时使用。图像为 .jpg、.jpeg 或 .png 格式，最大 30MB，每边至少 300px，宽高比在 2:5 到 5:2 之间。
</ParamField>

<ParamField body="options" type="object">
  常规配置，例如水印选项。Kling 4.0 不支持 `options.callback_url` 和 `options.external_task_id`；如果请求在 `options` 中设置其中任意一个，Comfy Router 会拒绝该请求。顶层的 `callback_url` 或 `external_task_id` 不属于此 schema，会在请求到达 Kling 之前被移除。
</ParamField>

<ParamField body="options.watermark_info" type="object">
  是否同时生成带水印的结果。不支持自定义水印。显式传入的 null 会被视为未提供，与 /proxy 的 Kling 4.0 检查以及 Kling 的处理方式一致。
</ParamField>

<ParamField body="options.watermark_info.enabled" type="boolean">
  true 表示生成带水印的结果，false 表示不生成。默认 false。
</ParamField>

<ParamField body="settings" type="object">
  输出配置，例如结果类型、图像数量、分辨率和宽高比。
</ParamField>

<ParamField body="settings.aspect_ratio" type="string">
  已生成图像的宽高比（宽度:高度）。默认 "auto"，即跟随输入。

  可能的值：`16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`3:2`、`2:3`、`21:9`、`auto`
</ParamField>

<ParamField body="settings.n" type="integer">
  单图模式下独立图像的数量，1 到 9。默认 1。系列模式下忽略。

  范围：`1` 到 `9`
</ParamField>

<ParamField body="settings.resolution" type="string">
  输出分辨率。取值为 "2k"、"4k" 或 "8k" 之一。默认 "2k"。

  可能的值：`2k`、`4k`、`8k`
</ParamField>

<ParamField body="settings.result_type" type="string">
  取值为 "single"（独立图像，由 `n` 计数）或 "series"（一组相关图像，由 `series_amount` 计数）之一。默认 "single"。

  可能的值：`single`、`series`
</ParamField>

<ParamField body="settings.series_amount" type="integer | `auto`">
  一组图像的数量，2 到 10，或 "auto" 表示由 Kling 根据输入在 2 到 10 之间选择。默认 4。仅在系列模式下使用。

  范围：`2` 到 `10`
