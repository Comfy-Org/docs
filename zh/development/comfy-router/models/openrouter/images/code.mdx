`openrouter/images` 的 API 参考，由 Comfy Router 从 Openrouter 提供。

**输入：** 文本、图像 · **输出：** 图像

## 请求设置

在[你的 Comfy 工作区](https://platform.comfy.org/profile/api-keys?onboarding=router)中创建一个密钥，并将其导出为 `COMFY_API_KEY`。对于 Python，运行 `pip install comfy-sdk`。对于 TypeScript，运行 `npm install @comfyorg/sdk`。cURL 使用原始 HTTP。

**模型 ID：** `openrouter/images`

**端点：** `POST https://api.comfy.org/v2/models/openrouter/images`

<Note>
此模型没有可运行的请求示例。请根据下方的输入文档构建请求体，然后将其与 [Router 快速入门](/zh/development/comfy-router/quickstart)配合使用。
</Note>
