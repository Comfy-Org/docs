相同的请求体，发送到 `POST https://api.comfy.org/v2/models/pika/pika-sfx/requests`。运行一旦被接纳，Router 就会返回 `201` 和 `request_id`；结果就绪后即可收集，无论是从当前进程还是另一个进程。[排队投递](/zh/development/comfy-router/queue)介绍了状态、取消和结果收集。

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 从环境变量中读取 COMFY_API_KEY。
# 每次 submit() 调用都会生成自己的 Idempotency-Key，并在自动重试时复用它。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "pika/pika-sfx",
            {
                "duration": 2,
                "prompt": "a wooden door creaking open",
            },
        )
        print("request_id:", handle.request_id)  # 加上模型 ID，就是另一个进程所需的全部信息

        # 轮询直到请求完成，每次都等待服务器指定的 Retry-After 时间。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 提供商自身的载荷，与 models.run() 返回的值相同。
        # 请求失败或被取消时，这里会抛出带类型的 Router 错误。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 从环境变量中读取 COMFY_API_KEY。
// 每次 submit() 调用都会生成自己的 Idempotency-Key，并在自动重试时复用它。
const handle = await comfy.models.submit("pika/pika-sfx", {
  duration: 2,
  prompt: "a wooden door creaking open",
});
console.log("requestId:", handle.requestId); // 加上模型 ID，就是另一个进程所需的全部信息

// 轮询直到请求完成，每次都等待服务器指定的 Retry-After 时间。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// 与 models.run() 返回的结果相同。请求失败或被取消时，这里会拒绝。
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 提交。Router 返回 201，以及 request_id、status_url、response_url 和 cancel_url。
curl https://api.comfy.org/v2/models/pika/pika-sfx/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"duration\": 2, \"prompt\": \"a wooden door creaking open\"}"

# 2. 轮询直到状态为 COMPLETED，每次响应指定的 Retry-After 秒数都要等待。
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/pika/pika-sfx/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 收集结果。已完成时返回 200 和模型的原始输出，仍在运行时返回 202 和状态正文。
curl https://api.comfy.org/v2/models/pika/pika-sfx/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```
