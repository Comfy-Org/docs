## Schema

### 输入

<ParamField body="aspect_ratio" type="string">
  输出宽高比。`auto` 会从提示词和媒体输入中选择一个。省略该参数可让 Pika 自行选择：当 `rewrite` 开启时为 `auto`，否则使用第一个媒体输入的比例，否则为 16:9。

  可选值：`auto`、`21:9`、`16:9`、`3:2`、`4:3`、`5:4`、`1:1`、`4:5`、`3:4`、`2:3`、`9:16`、`9:21`
</ParamField>

<ParamField body="channel_mode" type="string" default="&quot;mono&quot;">
  仅适用于音频分轨。`mono` 在分离前进行下混；`stereo` 保留两个声道。视频中的音频不会改变。

  可选值：`stereo`、`mono`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  视频时长，以整秒为单位，5 至 15。

  范围：`5` 至 `15`
</ParamField>

<ParamField body="output_mode" type="string" default="&quot;video&quot;">
  `video` 仅返回视频。`audio-stems` 还会在 `output.stems` 中返回对白、音乐和音效的 WAV 分轨，并额外收取 Pika 按秒计费的分轨分离费用。

  可选值：`video`、`audio-stems`
</ParamField>

<ParamField body="prompt" type="string" required>
  描述视频及其音频的文本提示词。
</ParamField>

<ParamField body="references" type="object[]" required>
  有序的参考媒体：最多 9 张图像、3 个视频和 3 个音频文件，共 12 个。至少需要一个图像或视频。每个文件最大 24 MiB。视频和音频片段时长为 2 至 15 秒，每种类型的总时长最多 15 秒。Pika 除了输出秒数外，还会对参考视频秒数计费。
</ParamField>

<ParamField body="references[].type" type="string" required>
  文件的媒体类型。

  可选值：`image`、`video`、`audio`
</ParamField>

<ParamField body="references[].url" type="string" required>
  参考文件的 URL。图像为 PNG、JPEG 或 WebP。
</ParamField>

<ParamField body="resolution" type="string" default="&quot;768p&quot;">
  输出分辨率。480p 和 768p 为原生分辨率。1080p、2k 和 4k 会以 768p 生成，然后再执行 upscale，同时保留音频和帧率。

  可选值：`480p`、`768p`、`1080p`、`2k`、`4k`
</ParamField>

<ParamField body="rewrite" type="boolean" default="true">
  生成前优化提示词。将其设为 false 可使用原样提示词。
</ParamField>

<ParamField body="seed" type="integer" default="0">
  视频的种子，0 或更大。

  范围：`0` 至 `…`

  格式：`int64`
</ParamField>
