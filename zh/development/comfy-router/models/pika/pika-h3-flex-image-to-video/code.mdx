### 输入

<ParamField body="aspect_ratio" type="string">
  输出宽高比。`auto` 会从提示词和媒体输入中挑选一个。省略此项则由 Pika 决定：当 `rewrite` 开启时为 `auto`，否则取第一个媒体输入的比例，再否则为 16:9。

  可选值：`auto`、`21:9`、`16:9`、`3:2`、`4:3`、`5:4`、`1:1`、`4:5`、`3:4`、`2:3`、`9:16`、`9:21`
</ParamField>

<ParamField body="channel_mode" type="string" default="&quot;mono&quot;">
  仅用于音频分轨。`mono` 会先做下混再分离；`stereo` 保留两个声道。视频中的音频不受影响。

  可选值：`stereo`、`mono`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  视频时长，以整秒为单位，取值 5 到 15。

  范围：`5` 到 `15`
</ParamField>

<ParamField body="image" type="string">
  首帧图像的 URL，需为静态 JPEG、PNG 或 WebP，最大 24 MiB、4000 万像素。
</ParamField>

<ParamField body="last_frame_image" type="string">
  尾帧图像的 URL，格式和大小限制与 `image` 相同。
</ParamField>

<ParamField body="output_mode" type="string" default="&quot;video&quot;">
  `video` 只返回视频。`audio-stems` 还会在 `output.stems` 中返回 Dialogue、Music 和 Effect 的 WAV 分轨，并额外收取 Pika 按秒计费的分轨分离费用。

  可选值：`video`、`audio-stems`
</ParamField>

<ParamField body="prompt" type="string" required>
  描述视频及其音频的文本提示词。
</ParamField>

<ParamField body="resolution" type="string" default="&quot;768p&quot;">
  输出分辨率。480p 和 768p 为原生分辨率。1080p、2k 和 4k 会先以 768p 生成再放大，同时保留音频和帧率。

  可选值：`480p`、`768p`、`1080p`、`2k`、`4k`
</ParamField>

<ParamField body="rewrite" type="boolean" default="true">
  在生成之前优化提示词。将其设为 false 即可按原样使用提示词。
</ParamField>

<ParamField body="seed" type="integer" default="0">
  视频的种子，取值 0 或更大。

  范围：`0` 到 `…`

  格式：`int64`
