相同的请求体，发送到 `POST https://api.comfy.org/v2/models/pika/pika-h3-flex-text-to-video/requests`。只要运行被接纳，Router 就会立即以 `201` 返回 `request_id`，结果就绪后即可取回，既可以从当前进程取回，也可以从另一个进程取回。[排队投递](/zh/development/comfy-router/queue) 会介绍状态、取消与结果取回。

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 从环境变量中读取 COMFY_API_KEY。
# 每次 submit() 调用都会生成自己的 Idempotency-Key，并在自动重试时复用它。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "pika/pika-h3-flex-text-to-video",
            {
                "duration": 5,
                "prompt": "A paper boat drifts down a rain-soaked street at dusk while thunder rolls in the distance",
                "resolution": "480p",
            },
        )
        print("request_id:", handle.request_id)  # 配合模型 ID，另一个进程只需这些信息

        # 轮询直到请求完成，按服务器给出的 Retry-After 时间等待。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 提供商自己的原始响应体，与 models.run() 返回的是同一个值。
        # 失败或已取消的请求会在此处抛出带类型的 Router 错误。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 从环境变量中读取 COMFY_API_KEY。
// 每次 submit() 调用都会生成自己的 Idempotency-Key，并在自动重试时复用它。
const handle = await comfy.models.submit("pika/pika-h3-flex-text-to-video", {
  duration: 5,
  prompt: "A paper boat drifts down a rain-soaked street at dusk while thunder rolls in the distance",
  resolution: "480p",
});
console.log("requestId:", handle.requestId); // 配合模型 ID，另一个进程只需这些信息

// 轮询直到请求完成，按服务器给出的 Retry-After 时间等待。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// 与 models.run() 返回的结果相同。失败或已取消的请求会在此处被拒绝。
const result = await handle.get();

console.log(result.data);
```

## Schema

### 输入

<ParamField body="aspect_ratio" type="string">
  输出宽高比。`auto` 会从提示词和媒体输入中选择一个比例。省略此项则交由 Pika 决定：当 `rewrite` 开启时为 `auto`，否则取第一个媒体输入的比例，再否则为 16:9。

  可选值：`auto`、`21:9`、`16:9`、`3:2`、`4:3`、`5:4`、`1:1`、`4:5`、`3:4`、`2:3`、`9:16`、`9:21`
</ParamField>

<ParamField body="channel_mode" type="string" default="&quot;mono&quot;">
  仅适用于音频分轨。`mono` 会在分离前先进行下混；`stereo` 则保留两个声道。视频本身的音频不会改变。

  可选值：`stereo`、`mono`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  视频时长，以整秒为单位，5 到 15。

  范围：`5` 到 `15`
</ParamField>

<ParamField body="output_mode" type="string" default="&quot;video&quot;">
  `video` 仅返回视频。`audio-stems` 还会在 `output.stems` 中返回对白、音乐和音效的 WAV 分轨，并额外收取 Pika 的每秒分轨分离费用。

  可选值：`video`、`audio-stems`
</ParamField>

<ParamField body="prompt" type="string" required>
  描述视频及其音频的文本提示词。
</ParamField>

<ParamField body="resolution" type="string" default="&quot;768p&quot;">
  输出分辨率。480p 和 768p 为原生分辨率。1080p、2k 和 4k 会先以 768p 生成，然后再放大，同时保留音频和帧率。

  可选值：`480p`、`768p`、`1080p`、`2k`、`4k`
</ParamField>

<ParamField body="rewrite" type="boolean" default="true">
  在生成之前优化提示词。将其设为 false 则按原样使用提示词。
</ParamField>

<ParamField body="seed" type="integer" default="0">
  视频的种子，0 或更大。

  范围：`0` 到 `…`

  格式：`int64`
</ParamField>
