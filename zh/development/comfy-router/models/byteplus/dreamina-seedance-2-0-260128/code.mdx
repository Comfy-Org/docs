</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  BytePlus 自有的尾帧下载 URL，与重新托管的 `last_frame_url` 并排逐字节原样返回，条件与 `upstream_video_url` 相同：仅限已选择加入的工作区、仅限 Seedance 2.x、BytePlus 清除后即缺失，并且在 `upstream_expires_at` 之前属于持有者凭据。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  BytePlus 自有的输出视频下载 URL，与重新托管的 `video_url` 并排逐字节原样返回。仅当任务是由 Comfy 在服务器端选择加入的工作区所轮询的 Seedance 2.x 任务时出现（没有请求参数）；对其他所有情况均缺失，包括无法解析到任何工作区的凭据（例如未限定到某个工作区的传统 API 密钥）；并且一旦 BytePlus 在生成后 24 小时清除其 URL，该字段也会缺失。它是预签名对象存储 URL，因此也是一种持有者凭据：任何持有它的人都可以在过期前下载视频，因此请将其视为机密。它在 `upstream_expires_at` 过期；在 Seedance 2.5 上，BytePlus 将下载次数限制为 100 次，其中一次会被 Router 自身的重新托管消耗。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  输出视频的下载 URL。Router 会将视频重新托管到 Comfy 存储并改写此字段，因此它通常是 Comfy 签名的 URL，有效期最长为 24 小时：生成时按 24 小时签名，并从 23 小时缓存记录中重放，因此稍后轮询可能拿到的 URL 只剩 1 小时有效期。无法执行重新托管时，该字段会保留 BytePlus 自有的 URL，BytePlus 会在任务结束 24 小时后清除该 URL，并在某些模型上将下载次数限制为 100 次。无论哪种情况，链接都会过期，因此请下载视频，而不是存储 URL。
</ResponseField>

<ResponseField name="created_at" type="integer">
  任务创建时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="duration" type="number">
  已生成视频的时长，单位为秒。声明为数字而不是整数，因为 BytePlus 对此并不一致：已观察到视频任务返回整秒，而 BytePlus 的其他同级接口会报告小数时长；因此客户端不得假定其为整数值。这是 BytePlus 的自有字段，在已成功的视频任务中返回并原样转发。
</ResponseField>

<ResponseField name="error" type="object">
  错误信息。任务成功时返回 null。任务失败时返回错误信息。
</ResponseField>

<ResponseField name="error.code" type="string">
  上游 ModelArk 错误码。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected 和 OutputAudioSensitiveContentDetected 表示内容策略拒绝。某个系列可能带有以点分隔的原因，例如 InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation 或 OutputImageSensitiveContentDetected.DeepFake。这是开放字符串，而非枚举：其他代码描述验证和提供商失败。Router 会在 HTTP 400 错误响应封装和 HTTP 200 失败任务响应中识别策略系列，而不会覆盖传输失败。
</ResponseField>

<ResponseField name="error.message" type="string">
  报错信息
</ResponseField>

<ResponseField name="id" type="string">The ID of the video generation task
</ResponseField>

<ResponseField name="model" type="string">
  该任务所使用的模型的名称和版本
</ResponseField>

<ResponseField name="output_format" type="string">
  已生成视频的容器格式（`mp4` 或 `mov`），在顶层作为 `content` 的同级字段返回：Seedance 视频任务查询正是在此处返回该字段。这是 BytePlus 自有字段，原样透传。
</ResponseField>

<ResponseField name="resolution" type="string">
  已生成视频的分辨率，例如 `1080p`。这是 BytePlus 自有字段，在视频任务成功时返回，并原样透传。
</ResponseField>

<ResponseField name="seed" type="integer">
  该任务实际使用的生成种子。这是 BytePlus 自有字段，在视频任务成功时返回，并原样透传。

  格式：`int64`
</ResponseField>

<ResponseField name="status" type="string">
  任务的状态

  可能的值：`queued`、`running`、`cancelled`、`succeeded`、`failed`、`expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  任务最后更新的时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="usage" type="object">
  该请求的 token 用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  模型生成的 token 数量
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  对于视频生成模型，不计算输入 token 数量，默认为 0。因此 total_tokens = completion_tokens。
</ResponseField>
