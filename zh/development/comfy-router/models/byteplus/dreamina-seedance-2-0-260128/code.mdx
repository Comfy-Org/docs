</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  BytePlus 自己的最后一帧下载 URL，与重新托管的 `last_frame_url` 并列、按与 `upstream_video_url` 相同的条件逐字节原样返回：仅限已选择加入的工作区，仅限 Seedance 2.x，BytePlus 清除后即缺失，并且在 `upstream_expires_at` 之前是 bearer 凭证。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  BytePlus 自己的输出视频下载 URL，与重新托管的 `video_url` 并列逐字节原样返回。仅当轮询 Seedance 2.x 任务的工作区已在服务器端被 Comfy 选择加入时出现（没有请求参数）；对其他所有情况均缺失，包括无法解析到任何工作区的凭证（例如未限定到某个工作区的传统 API 密钥），并且在生成 24 小时后 BytePlus 清除其 URL 后即缺失。它是预签名对象存储 URL，因此也是一种 bearer 凭证：任何持有它的人都能在过期前下载视频，所以请将其视为机密。它在 `upstream_expires_at` 过期；在 Seedance 2.5 上，BytePlus 将其限制为 100 次下载，其中一次会被 Router 自身的重新托管消耗。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  输出视频的下载 URL。Router 会将视频重新托管到 Comfy 存储并重写此字段，因此它通常是一个有效期最长 24 小时的 Comfy 签名 URL：生成时按 24 小时签名，并从 23 小时的缓存记录中重放，所以后续轮询可能返回一个剩余有效期仅一小时的 URL。当无法执行重新托管时，该字段会改为保留 BytePlus 自己的 URL；BytePlus 会在任务完成 24 小时后清除该 URL，并在某些模型上将其限制为 100 次下载。无论哪种情况，链接都会过期，因此请下载视频，而不要存储 URL。
</ResponseField>

<ResponseField name="created_at" type="integer">
  任务创建的时间。该值为以秒为单位的 UNIX 时间戳。
</ResponseField>

<ResponseField name="duration" type="number">
  已生成视频的时长，单位为秒。声明为 number 而非 integer，因为 BytePlus 在这点上并不一致：已观察到视频任务返回整秒，而 BytePlus 的其他同级接口会报告小数时长，因此客户端不得假定它是整数值。BytePlus 自己的字段，在已成功的视频任务上返回，并原样转发。
</ResponseField>

<ResponseField name="error" type="object">
  错误信息。如果任务成功，则返回 null。如果任务失败，则返回错误信息。
</ResponseField>

<ResponseField name="error.code" type="string">
  上游 ModelArk 错误码。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected 和 OutputAudioSensitiveContentDetected 表示内容策略拒绝。某个系列可能带有以点分隔的原因，例如 InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation 或 OutputImageSensitiveContentDetected.DeepFake。这是一个开放字符串，而非枚举：其他错误码描述验证和提供商失败。Router 会在 HTTP 400 错误响应封装和 HTTP 200 失败任务响应中识别策略系列，而不会覆盖传输失败。
</ResponseField>

<ResponseField name="error.message" type="string">
  报错信息
</ResponseField>

<ResponseField name="id" type="string">
  视频生成任务的 ID
</ResponseField>

<ResponseField name="model" type="string">
  任务所使用的模型名称和版本
</ResponseField>

<ResponseField name="output_format" type="string">
  生成视频的容器格式（`mp4` 或 `mov`），在顶层（TOP LEVEL）作为 `content` 的同级字段返回：Seedance 视频任务查询正是从此处返回该字段。这是 BytePlus 自有字段，原样透传。
</ResponseField>

<ResponseField name="resolution" type="string">
  生成视频的分辨率，例如 `1080p`。这是 BytePlus 自有字段，在成功的视频任务上返回并原样透传。
</ResponseField>

<ResponseField name="seed" type="integer">
  任务实际使用的生成种子。这是 BytePlus 自有字段，在成功的视频任务上返回并原样透传。

  格式：`int64`
</ResponseField>

<ResponseField name="status" type="string">
  任务状态

  可能的值：`queued`、`running`、`cancelled`、`succeeded`、`failed`、`expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  任务最后更新的时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="usage" type="object">
  请求的 token 用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  模型生成的 token 数量
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  对于视频生成模型，不计算输入 token 数量，默认为 0。因此，total_tokens = completion_tokens。
</ResponseField>
