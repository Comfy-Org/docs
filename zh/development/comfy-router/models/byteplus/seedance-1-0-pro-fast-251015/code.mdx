### 输出

<ResponseField name="content" type="object">
  视频生成任务完成后得到的输出，其中包含输出视频的下载 URL，以及在 BytePlus 返回时其最后一帧的下载 URL。`video_url` 和 `last_frame_url` 都会被重新托管到 Comfy 存储上；这里的其他字段都是 BytePlus 自己的字段。可为空：BytePlus 会在任务结束 24 小时后清除这些 URL，此后轮询一个已成功的文档时，`content` 可能缺失或为 null。
</ResponseField>

<ResponseField name="content.last_frame_url" type="string">
  生成视频最后一帧的下载 URL，仅在请求设置了 `return_last_frame` 时返回。不要从这个 URL 推断图像格式：BytePlus 在请求侧把最后一帧记录为 PNG，Router 会重新托管它实际收到的任意字节，并根据上游的 Content-Type 或内容嗅探来确定类型，而 `image/jpeg` 只是在两者都失败时的最后兜底。Router 会把最后一帧重新托管到 Comfy 存储并改写该字段，因此它通常是有效期最长 24 小时的 Comfy 签名 URL：签发时按 24 小时签名，并从 23 小时的备忘中重放，所以之后的轮询返回的 URL 可能只剩一小时有效期。无法执行重新托管时，该字段会保留 BytePlus 自己的 URL，BytePlus 会在任务结束 24 小时后清除它。无论哪种情况链接都会过期，因此请下载该帧，而不是保存 URL。
</ResponseField>

<ResponseField name="content.output_format" type="string">
  生成视频的容器格式（mp4 或 mov），当 BytePlus 将其嵌套在 `content` 内时出现。Seedance 模型更常把它作为 `content` 的顶层同级字段返回，请参见顶层 `output_format` 字段；Router 会读取两者中存在的那个。
</ResponseField>

<ResponseField name="content.upstream_expires_at" type="string (date-time)">
  上游 URL 失效的 RFC 3339 时间：即最早的签名时间加上 URL 自身携带的有效期；当 `updated_at` 存在时，绝不晚于任务的 `updated_at` 加 24 小时（BytePlus 文档记录的 URL 生存期）；否则为任务的 `updated_at` 加 24 小时。仅当 `upstream_video_url` 或 `upstream_last_frame_url` 存在时才存在，当两个来源都没有给出时间时则省略。与重新托管的 `video_url` / `last_frame_url` 的生存期无关。

  格式：`date-time`
</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  BytePlus 自己的最后一帧下载 URL，与重新托管的 `last_frame_url` 并排逐字节返回，条件与 `upstream_video_url` 相同：仅限已选择加入的工作区、仅限 Seedance 2.x、BytePlus 清除后即缺失，并且在 `upstream_expires_at` 之前都是一种持有即用的凭据。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  BytePlus 自己的输出视频下载 URL，与重新托管的 `video_url` 并排逐字节返回。仅对由 Comfy 在服务器端选择加入的工作区所轮询的 Seedance 2.x 任务存在（没有请求参数）；对其他所有人都不存在，包括无法解析到任何工作区的凭据（例如未绑定工作区的传统 API 密钥），并且在生成 24 小时后 BytePlus 清除其 URL 后也不存在。它是一个预签名对象存储 URL，因此是一种持有即用的凭据：任何持有它的人都能在过期前下载视频，所以请像对待机密一样对待它。它在 `upstream_expires_at` 过期；在 Seedance 2.5 上，BytePlus 将其限制为 100 次下载，其中一次会被 Router 自身的重新托管消耗。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  输出视频的下载 URL。Router 会把视频重新托管到 Comfy 存储并改写该字段，因此它通常是有效期最长 24 小时的 Comfy 签名 URL：签发时按 24 小时签名，并从 23 小时的备忘中重放，所以之后的轮询返回的 URL 可能只剩一小时有效期。无法执行重新托管时，该字段会保留 BytePlus 自己的 URL，BytePlus 会在任务结束 24 小时后清除它，并在某些模型上将其限制为 100 次下载。无论哪种情况链接都会过期，因此请下载视频，而不是保存 URL。
</ResponseField>

<ResponseField name="created_at" type="integer">
  任务的创建时间。该值是以秒为单位的 UNIX 时间戳。
</ResponseField>

<ResponseField name="duration" type="number">
  生成视频的时长，单位为秒。之所以声明为 number 而非 integer，是因为 BytePlus 在此并不一致：已观察到视频任务返回整秒数，而同系列的其他 BytePlus 接口会反馈带小数的时长，因此客户端不能假定它是整数值。这是 BytePlus 自己的字段，在成功的视频任务上返回并原样转发。
</ResponseField>

<ResponseField name="error" type="object">
  错误信息。如果任务成功，返回 null。如果任务失败，则返回错误信息。
</ResponseField>

<ResponseField name="error.code" type="string">
  上游 ModelArk 错误码。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected 和 OutputAudioSensitiveContentDetected 表示内容策略拒绝。同一系列可能带有以点分隔的原因，例如 InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation 或 OutputImageSensitiveContentDetected.DeepFake。这是一个开放字符串，而不是枚举：其他错误码描述验证失败和提供商故障。Router 会在 HTTP 400 错误封装和 HTTP 200 失败任务响应中识别策略系列，但不会覆盖传输故障。
</ResponseField>

<ResponseField name="error.message" type="string">
  报错信息
</ResponseField>

<ResponseField name="id" type="string">
  视频生成任务的 ID
</ResponseField>

<ResponseField name="model" type="string">
  任务所使用的模型名称和版本
</ResponseField>

<ResponseField name="output_format" type="string">
  已生成视频的容器格式（mp4 或 mov），在顶层作为 `content` 的同级字段返回，Seedance 视频任务查询正是从这里返回该字段。这是 BytePlus 自有字段，原样转发。
</ResponseField>

<ResponseField name="resolution" type="string">
  已生成视频的分辨率，例如 `1080p`。这是 BytePlus 自有字段，在成功的视频任务中返回并原样转发。
</ResponseField>

<ResponseField name="seed" type="integer">
  任务实际使用的生成种子。这是 BytePlus 自有字段，在成功的视频任务中返回并原样转发。

  格式：`int64`
</ResponseField>

<ResponseField name="status" type="string">
  任务状态

  可能的值：`queued`、`running`、`cancelled`、`succeeded`、`failed`、`expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  任务最后更新的时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="usage" type="object">
  请求的 token 用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  模型生成的 token 数量
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  对于视频生成模型，不计算输入 token 的数量，其默认值为 0。因此，total_tokens = completion_tokens。
</ResponseField>
