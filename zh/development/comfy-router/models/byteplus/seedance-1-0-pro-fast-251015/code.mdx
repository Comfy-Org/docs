</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  BytePlus 自己的最后一帧下载 URL，与重新托管的 `last_frame_url` 并排逐字节返回，其条款与 `upstream_video_url` 相同：仅限已选择加入的工作区，仅限 Seedance 2.x，BytePlus 清除后即缺失，并且在 `upstream_expires_at` 之前是 bearer 凭证。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  BytePlus 自己的输出视频下载 URL，与重新托管的 `video_url` 并排逐字节返回。仅对由 Comfy 在服务器端选择加入的工作区所轮询的 Seedance 2.x 任务出现（没有请求参数）；对其他所有情况均缺失，包括解析不到任何工作区的凭证（例如未限定到某个工作区的传统 API 密钥），并且在 BytePlus 于生成 24 小时后清除其 URL 后缺失。它是一个预签名的对象存储 URL，因此也是 bearer 凭证：任何持有它的人都可以在它过期前下载视频，因此请把它当作机密。它在 `upstream_expires_at` 过期；在 Seedance 2.5 上，BytePlus 将其限制为 100 次下载，其中一次会被 Router 自己的重新托管消耗。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  输出视频的下载 URL。Router 会将视频重新托管到 Comfy 存储并重写此字段，因此它通常是 Comfy 签名的 URL，有效期最长 24 小时：生成时签发 24 小时有效期，并从 23 小时缓存中重放，因此稍后轮询可能返回一个仅剩一小时有效期的 URL。当无法执行重新托管时，该字段会改为保留 BytePlus 自己的 URL，BytePlus 会在任务完成 24 小时后清除它，并在某些模型上将其限制为 100 次下载。无论哪种方式，链接都会过期，因此请下载视频，而不是存储 URL。
</ResponseField>

<ResponseField name="created_at" type="integer">
  任务创建时间。该值是 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="duration" type="number">
  已生成视频的时长，单位为秒。之所以声明为数字而不是整数，是因为 BytePlus 对此并不一致：已观察到视频任务返回整数秒，而同属 BytePlus 的其他接口会报告小数时长，因此客户端不得假定它是整数值。这是 BytePlus 自己的字段，在已成功的视频任务上返回并原样转发。
</ResponseField>

<ResponseField name="error" type="object">
  错误信息。如果任务成功，则返回 null。如果任务失败，则返回错误信息。
</ResponseField>

<ResponseField name="error.code" type="string">
  上游 ModelArk 错误码。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected 和 OutputAudioSensitiveContentDetected 表示内容策略拒绝。某个错误码族可能带有以点分隔的原因，例如 InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation 或 OutputImageSensitiveContentDetected.DeepFake。这是一个开放字符串，而不是枚举：其他错误码描述验证和提供商故障。Router 会在 HTTP 400 错误响应封装和 HTTP 200 失败任务响应中识别策略错误码族，且不会覆盖传输故障。
</ResponseField>

<ResponseField name="error.message" type="string">
  报错信息
</ResponseField>

<ResponseField name="id" type="string">

The ID of the video generation task
</ResponseField>

<ResponseField name="model" type="string">
  该任务使用的模型名称和版本
</ResponseField>

<ResponseField name="output_format" type="string">
  已生成视频的容器格式（mp4 或 mov），在顶层返回，与 `content` 同级。Seedance 视频任务查询会在这里返回该字段。该字段属于 BytePlus 自有字段，原样转发。
</ResponseField>

<ResponseField name="resolution" type="string">
  已生成视频的分辨率，例如 `1080p`。该字段属于 BytePlus 自有字段，在成功的视频任务中返回，并原样转发。
</ResponseField>

<ResponseField name="seed" type="integer">
  该任务实际使用的生成种子。该字段属于 BytePlus 自有字段，在成功的视频任务中返回，并原样转发。

  格式：`int64`
</ResponseField>

<ResponseField name="status" type="string">
  任务的状态

  可能的值：`queued`、`running`、`cancelled`、`succeeded`、`failed`、`expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  任务最后更新的时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="usage" type="object">
  请求的 token 用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  模型生成的 token 数量
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  对于视频生成模型，不计算输入 token 数量，默认值为 0。因此，total_tokens = completion_tokens。
</ResponseField>
