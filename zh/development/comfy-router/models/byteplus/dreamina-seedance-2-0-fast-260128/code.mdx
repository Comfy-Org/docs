<ResponseField name="content.video_url" type="string">
  输出视频的下载 URL。Router 会将视频重新托管到 Comfy 存储上并改写此字段，因此它通常是一个由 Comfy 签发的签名 URL，有效期最长 24 小时。该 URL 在签发时以 24 小时有效期签名，并从一份 23 小时的备忘中重放，因此后续轮询返回的 URL 剩余有效期可能只有一小时。当无法执行重新托管时，此字段会保留 BytePlus 自己的 URL，而 BytePlus 会在任务完成 24 小时后将其清空，并在部分模型上将其限制为 100 次下载。无论哪种情况，链接都会过期，因此请下载该视频，而不要只保存 URL。
</ResponseField>

<ResponseField name="created_at" type="integer">
  任务创建的时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="duration" type="number">
  已生成视频的时长，单位为秒。声明为数字而非整数，是因为 BytePlus 对此并不一致：视频任务曾被观察到返回整秒，而 BytePlus 的其他同类接口会报告带小数的时长，因此客户端不能假定它是整数值。这是 BytePlus 自己的字段，在成功的视频任务上返回并原样转发。
</ResponseField>

<ResponseField name="error" type="object">
  错误信息。如果任务成功，则返回 null。如果任务失败，则返回错误信息。
</ResponseField>

<ResponseField name="error.code" type="string">
  上游 ModelArk 错误码。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected 和 OutputAudioSensitiveContentDetected 表示内容策略拒绝。某一类别可能带有以点分隔的原因，例如 InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation 或 OutputImageSensitiveContentDetected.DeepFake。这是一个开放字符串而非枚举：其他错误码描述验证失败和提供商故障。Router 会在 HTTP 400 错误响应体和 HTTP 200 失败任务响应中识别策略类别，但不会覆盖传输层故障。
</ResponseField>

<ResponseField name="error.message" type="string">
  报错信息
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the video generation task
</ResponseField>

<ResponseField name="model" type="string">
  The name and version of the model used by the task
</ResponseField>

<ResponseField name="output_format" type="string">
  Container format of the generated video (mp4 or mov), returned at the TOP LEVEL as a sibling of `content` - this is where the Seedance video task query returns it. BytePlus's own field, forwarded unchanged.
</ResponseField>

<ResponseField name="resolution" type="string">
  The resolution of the generated video, for example `1080p`. BytePlus's own field, returned on succeeded video tasks and forwarded unchanged.
</ResponseField>

<ResponseField name="seed" type="integer">
  The generation seed actually used for the task. BytePlus's own field, returned on succeeded video tasks and forwarded unchanged.

  Format: `int64`
</ResponseField>

<ResponseField name="status" type="string">
  The state of the task

  Possible values: `queued`, `running`, `cancelled`, `succeeded`, `failed`, `expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  The time when the task was last updated. The value is a UNIX timestamp in seconds.
</ResponseField>

<ResponseField name="usage" type="object">
  The token usage for the request
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  The number of tokens generated by the model
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  For the video generation model, the number of input tokens is not calculated and defaults to 0. Therefore, total_tokens = completion_tokens.
</ResponseField>
