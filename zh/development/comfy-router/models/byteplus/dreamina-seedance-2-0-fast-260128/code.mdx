</ResponseField>

<ResponseField name="content.video_url" type="string">
  输出视频的下载 URL。Router 会将视频重新托管到 Comfy 存储并重写该字段，因此它通常是一个有效期最长 24 小时的 Comfy 签名 URL：签发时按 24 小时签名，并从一条 23 小时的缓存记录中重放，因此更晚的轮询可能拿到只剩一小时有效期的 URL。当无法执行重新托管时，该字段会保留 BytePlus 自己的 URL，BytePlus 会在任务完成 24 小时后清除它，并在某些模型上将其限制为 100 次下载。无论哪种方式链接都会过期，因此请下载视频，而不要存储 URL。
</ResponseField>

<ResponseField name="created_at" type="integer">
  任务创建的时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="duration" type="number">
  已生成视频的时长，单位为秒。声明为 number 而非 integer，是因为 BytePlus 在这方面并不一致：已观察到视频任务返回整数秒，而 BytePlus 的其他同级接口会报告带小数的时长，因此客户端不能假定它是整数值。这是 BytePlus 自己的字段，在成功的视频任务上返回并原样转发。
</ResponseField>

<ResponseField name="error" type="object">
  错误信息。如果任务成功，返回 null。如果任务失败，则返回错误信息。
</ResponseField>

<ResponseField name="error.code" type="string">
  上游 ModelArk 错误码。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected 和 OutputAudioSensitiveContentDetected 表示内容策略拒绝。同一个族可能带有以点分隔的原因，例如 InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation 或 OutputImageSensitiveContentDetected.DeepFake。这是一个开放的字符串，而非枚举：其他错误码描述验证失败和提供商失败。Router 会在 HTTP 400 错误封装和 HTTP 200 失败任务响应中识别策略族，但不会覆盖传输层失败。
</ResponseField>

<ResponseField name="error.message" type="string">
  报错信息
</ResponseField>

<ResponseField name="id" type="string">
  视频生成任务的 ID
</ResponseField>

<ResponseField name="model" type="string">
  任务所使用的模型名称和版本
</ResponseField>

<ResponseField name="output_format" type="string">
  已生成视频的容器格式（mp4 或 mov），在顶层作为 `content` 的同级字段返回，Seedance 视频任务查询会在此处返回该字段。BytePlus 自有字段，原样转发。
</ResponseField>

<ResponseField name="resolution" type="string">
  已生成视频的分辨率，例如 `1080p`。BytePlus 自有字段，在成功的视频任务中返回并原样转发。
</ResponseField>

<ResponseField name="seed" type="integer">
  任务实际使用的生成种子。BytePlus 自有字段，在成功的视频任务中返回并原样转发。

  格式：`int64`
</ResponseField>

<ResponseField name="status" type="string">
  任务状态

  可能的值：`queued`、`running`、`cancelled`、`succeeded`、`failed`、`expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  任务最后更新的时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="usage" type="object">
  本次请求的 token 用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  模型生成的 token 数量
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  对于视频生成模型，不计算输入 token 数量，默认值为 0。因此，total_tokens = completion_tokens。
</ResponseField>
