</ResponseField>

<ResponseField name="content.output_format" type="string">
  所生成视频的容器格式（mp4 或 mov），当 BytePlus 将其嵌套在 `content` 内时返回。Seedance 模型更常见的情况是将其作为 `content` 的顶层同级字段返回，参见顶层 `output_format` 字段；Router 会读取两者中存在的那个。
</ResponseField>

<ResponseField name="content.upstream_expires_at" type="string (date-time)">
  上游 URL 失效的 RFC 3339 时间：最早签名时间加上 URL 本身携带的有效期；当存在 `updated_at` 时，不晚于任务的 `updated_at` 加 24 小时（BytePlus 文档中说明的 URL 生命周期）；否则为任务的 `updated_at` 加 24 小时。仅当存在 `upstream_video_url` 或 `upstream_last_frame_url` 时才会出现，两个来源都无法提供时间时则省略。与重新托管的 `video_url` / `last_frame_url` 的生命周期无关。

  格式：`date-time`
</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  BytePlus 自己的最后一帧下载 URL，与重新托管的 `last_frame_url` 一并按字节原样返回，条件与 `upstream_video_url` 相同：仅限已选择加入的工作区，仅限 Seedance 2.x，BytePlus 清除后即不再出现，在 `upstream_expires_at` 之前属于持有者凭证。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  BytePlus 自己的输出视频下载 URL，与重新托管的 `video_url` 一并按字节原样返回。仅当任务由 Comfy 在服务器端选择加入的工作区轮询 Seedance 2.x 任务时才存在（没有对应的请求参数）；其他情况均不返回，包括无法解析到任何工作区的凭证（例如未绑定到工作区的传统 API 密钥），并且在 BytePlus 于生成 24 小时后清除其 URL 后也不再出现。它是一个预签名对象存储 URL，因此也是一种持有者凭证：任何持有它的人都能在过期前下载该视频，所以请将其视为机密。它在 `upstream_expires_at` 过期；在 Seedance 2.5 上，BytePlus 将其下载次数限制为 100 次，其中一次会被 Router 自身的重新托管所消耗。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  输出视频的下载 URL。Router 会将视频重新托管到 Comfy 存储并改写此字段，因此它通常是一个有效期最长 24 小时的 Comfy 签名 URL。该 URL 在生成时签名 24 小时，并从 23 小时的备忘录中重放，因此稍后轮询返回的 URL 剩余有效期可能只有一小时。当无法执行重新托管时，该字段会保留 BytePlus 自己的 URL，BytePlus 会在任务结束 24 小时后清除它，并在某些模型上将其限制为 100 次下载。无论哪种情况，链接都会过期，因此请下载该视频，而不是存储 URL。
</ResponseField>

<ResponseField name="created_at" type="integer">
  任务创建的时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="duration" type="number">
  所生成视频的时长，单位为秒。声明为 number 而非 integer，是因为 BytePlus 在这一点上并不一致：视频任务曾出现过返回整数秒的情况，而 BytePlus 其他相关接口会返回带小数的时长，因此客户端不得假定其为整数值。这是 BytePlus 自己的字段，在成功的视频任务上返回并原样转发。
</ResponseField>

<ResponseField name="error" type="object">
  错误信息。如果任务成功，则返回 null；如果任务失败，则返回错误信息。
</ResponseField>

<ResponseField name="error.code" type="string">
  上游 ModelArk 错误代码。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected 和 OutputAudioSensitiveContentDetected 表示内容策略拒绝。某个类别可能带有以点分隔的原因，例如 InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation 或 OutputImageSensitiveContentDetected.DeepFake。这是一个开放字符串，而非枚举：其他代码描述验证失败和提供商故障。Router 会在 HTTP 400 错误信封和 HTTP 200 任务失败响应中识别策略类别，但不会覆盖传输层故障。
</ResponseField>

<ResponseField name="error.message" type="string">
  报错信息
</ResponseField>

<ResponseField name="id" type="string">
  The ID of the video generation task
</ResponseField>

<ResponseField name="model" type="string">
  任务所使用的模型名称和版本
</ResponseField>

<ResponseField name="output_format" type="string">
  已生成视频的容器格式（mp4 或 mov），在顶层返回，与 `content` 同级，Seedance 视频任务查询就是在这里返回该字段的。这是 BytePlus 自己的字段，原样转发。
</ResponseField>

<ResponseField name="resolution" type="string">
  已生成视频的分辨率，例如 `1080p`。这是 BytePlus 自己的字段，在成功的视频任务中返回，原样转发。
</ResponseField>

<ResponseField name="seed" type="integer">
  该任务实际使用的生成种子。这是 BytePlus 自己的字段，在成功的视频任务中返回，原样转发。

  格式：`int64`
</ResponseField>

<ResponseField name="status" type="string">
  任务的状态

  可能的值：`queued`、`running`、`cancelled`、`succeeded`、`failed`、`expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  任务最后更新的时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="usage" type="object">
  该请求的 token 用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  模型生成的 token 数量
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  对于视频生成模型，不计算输入 token 数量，默认为 0。因此 total_tokens = completion_tokens。
</ResponseField>
