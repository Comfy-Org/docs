<ResponseField name="content.upstream_last_frame_url" type="string">
  BytePlus 自身的最后一帧下载 URL，与重新托管的 `last_frame_url` 并排原样返回，条件与 `upstream_video_url` 相同：仅限已选择加入的工作区，仅限 Seedance 2.x，BytePlus 清除后即缺失，并且在 `upstream_expires_at` 之前属于持有者凭证。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  BytePlus 自身的输出视频下载 URL，与重新托管的 `video_url` 并排原样返回。仅当任务由 Comfy 在服务器端已选择加入的工作区轮询时，才为 Seedance 2.x 任务返回（没有请求参数）；对其他所有情况均缺失，包括无法解析到任何工作区的凭证（例如未限定到某个工作区的传统 API 密钥），以及在 BytePlus 于生成 24 小时后清除其 URL 之后。它是预签名的对象存储 URL，因此属于持有者凭证：任何持有它的人都可以在过期前下载该视频，请将其视为机密。它在 `upstream_expires_at` 过期，在 Seedance 2.5 上 BytePlus 将其限制为 100 次下载，其中一次会被 Router 自身的重新托管消耗。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  输出视频的下载 URL。Router 会将视频重新托管到 Comfy 存储上并重写此字段，因此它通常是 Comfy 签名的 URL，有效期最长 24 小时：签发时按 24 小时签名，并从 23 小时的备忘录中重放，因此之后的轮询可能返回剩余有效期仅一小时的 URL。当无法执行重新托管时，该字段会保留 BytePlus 自身的 URL，BytePlus 会在任务完成 24 小时后清除它，并在某些模型上限制为 100 次下载。无论哪种情况，链接都会过期，因此请下载视频，而不是保存 URL。
</ResponseField>

<ResponseField name="created_at" type="integer">
  任务创建的时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="duration" type="number">
  已生成视频的时长，单位为秒。声明为 number 而非 integer，是因为 BytePlus 对此并不一致：已观察到视频任务返回整秒，而 BytePlus 的其他同级接口会报告小数时长，因此客户端不得假定其为整数值。这是 BytePlus 自身的字段，在已成功的视频任务上返回并原样转发。
</ResponseField>

<ResponseField name="error" type="object">
  错误信息。若任务成功，则返回 null。若任务失败，则返回错误信息。
</ResponseField>

<ResponseField name="error.code" type="string">
  上游 ModelArk 错误码。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected 和 OutputAudioSensitiveContentDetected 表示内容策略拒绝。某个系列可能带有以点分隔的原因，例如 InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation 或 OutputImageSensitiveContentDetected.DeepFake。这是一个开放字符串，而不是枚举：其他错误码描述验证和提供商故障。Router 会在 HTTP 400 错误信封和 HTTP 200 失败任务响应中识别策略系列，但不会覆盖传输故障。
</ResponseField>

<ResponseField name="error.message" type="string">
  报错信息
</ResponseField>

<ResponseField name="id" type="string">
  视频生成任务的 ID
</ResponseField>

<ResponseField name="model" type="string">
  任务所使用的模型名称和版本
</ResponseField>

<ResponseField name="output_format" type="string">
  生成视频的容器格式（mp4 或 mov），在顶层作为 `content` 的同级字段返回，Seedance 视频任务查询正是在此处返回该字段。BytePlus 自有字段，原样转发。
</ResponseField>

<ResponseField name="resolution" type="string">
  生成视频的分辨率，例如 `1080p`。BytePlus 自有字段，在成功的视频任务上返回并原样转发。
</ResponseField>

<ResponseField name="seed" type="integer">
  实际用于该任务的生成种子。BytePlus 自有字段，在成功的视频任务上返回并原样转发。

  格式：`int64`
</ResponseField>

<ResponseField name="status" type="string">
  任务的状态

  可能的值：`queued`、`running`、`cancelled`、`succeeded`、`failed`、`expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  任务最后更新的时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="usage" type="object">
  请求的 token 用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  模型生成的 token 数量
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  对于视频生成模型，不计算输入 token 数量，默认为 0。因此 total_tokens = completion_tokens。
</ResponseField>
