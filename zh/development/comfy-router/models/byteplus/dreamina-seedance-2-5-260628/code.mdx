  已生成视频最后一帧的下载 URL，仅当请求设置了 `return_last_frame` 时返回。不要根据此 URL 推断图像格式：BytePlus 在请求侧将最后一帧说明为 PNG，Router 会重新托管它实际收到的任意字节，并根据上游 Content-Type 或内容嗅探来确定其类型，`image/jpeg` 仅在两者都失败时作为最后的兜底。Router 会将最后一帧重新托管到 Comfy 存储并重写此字段，因此它通常是一个由 Comfy 签名的 URL，有效期最长 24 小时：签发时按 24 小时签名，并从 23 小时的备忘中重放，所以稍后轮询可能返回一个只剩不到一小时的 URL。当无法执行重新托管时，该字段会保留 BytePlus 自己的 URL，而 BytePlus 会在任务结束 24 小时后清除它。无论哪种情况，链接都会过期，因此请下载该帧，而不要存储 URL。
</ResponseField>

<ResponseField name="content.output_format" type="string">
  已生成视频的容器格式（mp4 或 mov），仅当 BytePlus 将其嵌套在 `content` 内时出现。Seedance 模型更常将其作为 `content` 的同级顶层字段返回，请参阅顶层 `output_format` 字段；Router 会读取两者中存在的那个。
</ResponseField>

<ResponseField name="content.upstream_expires_at" type="string (date-time)">
  上游 URL 停止可用的 RFC 3339 时间：取最早签发时间加上这些 URL 自身携带的有效期，当 `updated_at` 存在时，不得晚于任务的 `updated_at` 加 24 小时（BytePlus 文档中说明的 URL 寿命）；否则为任务的 `updated_at` 加 24 小时。仅当 `upstream_video_url` 或 `upstream_last_frame_url` 存在时才存在；两个来源都未给出时间时则省略。与重新托管的 `video_url` / `last_frame_url` 的生命周期无关。

  格式：`date-time`
</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  BytePlus 自己的最后一帧下载 URL，与重新托管的 `last_frame_url` 一并原样返回，其出现条件与 `upstream_video_url` 相同：仅限已选择加入的工作区、仅限 Seedance 2.x，一旦 BytePlus 清除即缺失，并且在 `upstream_expires_at` 之前属于持有者凭证。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  BytePlus 自己的输出视频下载 URL，与重新托管的 `video_url` 一并原样返回。仅当任务由 Comfy 在服务端选择加入的工作区轮询时，才对 Seedance 2.x 任务存在（没有对应的请求参数）；对其他所有人都不存在，包括解析不到任何工作区的凭证（例如未限定到某个工作区的传统 API 密钥）；并且在生成 24 小时后 BytePlus 清除其 URL 后也不存在。它是预签名对象存储 URL，因此属于持有者凭证：任何持有者在过期前都能下载该视频，请像对待机密一样对待它。它在 `upstream_expires_at` 过期；在 Seedance 2.5 上，BytePlus 将其限制为 100 次下载，其中一次会被 Router 自身的重新托管消耗。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  输出视频的下载 URL。Router 会将视频重新托管到 Comfy 存储并重写此字段，因此它通常是一个由 Comfy 签名的 URL，有效期最长 24 小时：签发时按 24 小时签名，并从 23 小时的备忘中重放，所以稍后轮询可能返回一个只剩不到一小时的 URL。当无法执行重新托管时，该字段会保留 BytePlus 自己的 URL，BytePlus 会在任务结束 24 小时后清除它，并在某些模型上将其限制为 100 次下载。无论哪种情况，链接都会过期，因此请下载视频，而不要存储 URL。
</ResponseField>

<ResponseField name="created_at" type="integer">
  任务的创建时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="duration" type="number">
  已生成视频的时长，单位为秒。声明为 number 而非 integer，是因为 BytePlus 在这点上并不一致：视频任务曾被观察到返回整秒，而 BytePlus 的其他同类接口会报告带小数的时长，因此客户端不得假定它是整数值。这是 BytePlus 自己的字段，在已成功的视频任务上返回，并原样转发。
</ResponseField>

<ResponseField name="error" type="object">
  错误信息。如果任务成功，返回 null。如果任务失败，则返回错误信息。
</ResponseField>

<ResponseField name="error.code" type="string">
  上游 ModelArk 错误码。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected 和 OutputAudioSensitiveContentDetected 标识内容策略拒绝。某一族错误码可能带有点分隔的原因，例如 InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation 或 OutputImageSensitiveContentDetected.DeepFake。这是一个开放字符串而非枚举：其他错误码描述验证和提供商故障。Router 会在 HTTP 400 错误信封和 HTTP 200 失败任务响应中识别策略族，但不会覆盖传输层故障。
</ResponseField>

<ResponseField name="error.message" type="string">
  报错信息
</ResponseField>

<ResponseField name="id" type="string">
  视频生成任务的 ID
</ResponseField>

<ResponseField name="model" type="string">
  任务所用模型的名称和版本
</ResponseField>

<ResponseField name="output_format" type="string">
  已生成视频的容器格式（mp4 或 mov），在顶层作为 `content` 的同级字段返回，Seedance 视频任务查询正是在此处返回该字段。这是 BytePlus 自有字段，原样转发。
</ResponseField>

<ResponseField name="resolution" type="string">
  已生成视频的分辨率，例如 `1080p`。这是 BytePlus 自有字段，在成功的视频任务上返回，并原样转发。
</ResponseField>

<ResponseField name="seed" type="integer">
  任务实际使用的生成种子。这是 BytePlus 自有字段，在成功的视频任务上返回，并原样转发。

  格式：`int64`
</ResponseField>

<ResponseField name="status" type="string">
  任务的状态

  可能的值：`queued`、`running`、`cancelled`、`succeeded`、`failed`、`expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  任务最后更新的时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="usage" type="object">
  请求的 token 用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  模型生成的 token 数量
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  对于视频生成模型，不计算输入 token 的数量，默认值为 0。因此，total_tokens = completion_tokens。
</ResponseField>
