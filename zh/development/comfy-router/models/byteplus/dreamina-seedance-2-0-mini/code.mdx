<ResponseField name="content.last_frame_url" type="string">

<ResponseField name="content.upstream_video_url" type="string">

</ResponseField>

<ResponseField name="content.video_url" type="string">
  输出视频的下载 URL。Router 会把视频重新托管到 Comfy 存储并重写此字段，因此它通常是 Comfy 签名的 URL，有效期最长为 24 小时；签发时按 24 小时签名，并从 23 小时缓存中重放，因此稍后轮询可能拿到仅剩一小时有效期的 URL。无法执行重新托管时，该字段会保留 BytePlus 自己的 URL，而 BytePlus 会在任务完成 24 小时后清除该 URL，并在某些模型上限制为 100 次下载。无论哪种情况，链接都会过期，因此请下载视频，而不要保存 URL。
</ResponseField>

<ResponseField name="created_at" type="integer">
  任务创建时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="duration" type="number">
  已生成视频的时长，单位为秒。声明为数值而不是整数，是因为 BytePlus 对此并不一致：曾观察到视频任务返回整秒数，而同属 BytePlus 的其他接口会报告带小数的时长，因此客户端不能假定它是整数值。这是 BytePlus 自己的字段，在成功的视频任务中返回并原样转发。
</ResponseField>

<ResponseField name="error" type="object">
  错误信息。如果任务成功，返回 null。如果任务失败，则返回错误信息。
</ResponseField>

<ResponseField name="error.code" type="string">
  上游 ModelArk 错误码。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected 和 OutputAudioSensitiveContentDetected 表示内容策略拒绝。一个系列可能带有以点分隔的原因，例如 InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation 或 OutputImageSensitiveContentDetected.DeepFake。这是一个开放字符串，而不是枚举：其他错误码描述验证和提供商失败。Router 会在 HTTP 400 错误响应封装和 HTTP 200 失败任务响应中识别策略系列，而不会覆盖传输失败。
</ResponseField>

<ResponseField name="error.message" type="string">
  报错信息
</ResponseField>

<ResponseField name="id" type="string">```mdx
  视频生成任务的 ID
</ResponseField>

<ResponseField name="model" type="string">
  任务所使用模型的名称和版本
</ResponseField>

<ResponseField name="output_format" type="string">
  已生成视频的容器格式（mp4 或 mov），在顶层返回，作为 `content` 的同级字段。Seedance 视频任务查询正是在此处返回该字段。该字段为 BytePlus 自有字段，原样透传。
</ResponseField>

<ResponseField name="resolution" type="string">
  已生成视频的分辨率，例如 `1080p`。该字段为 BytePlus 自有字段，在成功的视频任务中返回，并原样透传。
</ResponseField>

<ResponseField name="seed" type="integer">
  该任务实际使用的生成种子。该字段为 BytePlus 自有字段，在成功的视频任务中返回，并原样透传。

<ResponseField name="status" type="string">
