### 输出

<ResponseField name="content" type="object">
  视频生成任务完成后得到的输出，其中包含输出视频的下载 URL；当 BytePlus 返回最后一帧时，还包含最后一帧的下载 URL。`video_url` 和 `last_frame_url` 都会重新托管到 Comfy 存储；这里的其他所有字段均来自 BytePlus 本身。可为空：BytePlus 会在任务完成 24 小时后清除这些 URL，而在此之后轮询已成功的文档时，`content` 可能缺失或为 null。
</ResponseField>

<ResponseField name="content.last_frame_url" type="string">
  已生成视频最后一帧的下载 URL，当请求设置了 `return_last_frame` 时返回。不要根据此 URL 推断图像格式：BytePlus 在请求侧将最后一帧指定为 PNG，Router 会重新托管其收到的任意字节，并根据上游 Content-Type 或内容嗅探来确定其类型，只有当两者都失败时，`image/jpeg` 才作为最后的回退。Router 会将最后一帧重新托管到 Comfy 存储并重写此字段，因此它通常是 Comfy 签名的 URL，有效期最长为 24 小时：签发时按 24 小时签名，并从 23 小时缓存中重放，因此较晚的轮询可能返回仅剩一小时有效期的 URL。如果无法执行重新托管，该字段会改为保留 BytePlus 自己的 URL；BytePlus 会在任务完成 24 小时后清除该 URL。无论哪种情况，链接都会过期，因此请下载该帧，而不是保存 URL。
</ResponseField>

<ResponseField name="content.output_format" type="string">
  已生成视频的容器格式（mp4 或 mov），当 BytePlus 将其嵌套在 `content` 内时提供。Seedance 模型更常将其作为 `content` 的顶层同级字段返回（见顶层 `output_format` 字段），Router 会读取两者中存在的那个。
</ResponseField>

<ResponseField name="content.upstream_expires_at" type="string (date-time)">
  上游 URL 停止工作的时间，采用 RFC 3339 格式：URL 自身携带的最早签名时间加有效期；当 `updated_at` 存在时，绝不晚于任务的 `updated_at` 加 24 小时（BytePlus 文档给出的 URL 生命周期）；否则为任务的 `updated_at` 加 24 小时。仅当存在 `upstream_video_url` 或 `upstream_last_frame_url` 时提供，当两个来源都未给出时间时省略。与重新托管的 `video_url` / `last_frame_url` 的生命周期无关。

  格式：`date-time`
</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  BytePlus 自己的最后一帧下载 URL，与重新托管的 `last_frame_url` 一起逐字节原样返回，条件与 `upstream_video_url` 相同：仅限已选择加入的工作区，仅限 Seedance 2.x，BytePlus 清除后即不再提供，并且在 `upstream_expires_at` 之前是持有者凭证。
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  BytePlus 自己的输出视频下载 URL，与重新托管的 `video_url` 一起逐字节原样返回。仅当轮询 Seedance 2.x 任务的工作区已在服务器端由 Comfy 选择加入时才提供（没有请求参数）；对其他所有情况均不提供，包括无法解析到任何工作区的凭证（例如未限定到某个工作区的传统 API 密钥），并且一旦 BytePlus 在生成 24 小时后清除其 URL，也会不再提供。它是预签名对象存储 URL，因此也是持有者凭证：任何持有它的人都能在过期前下载视频，所以请像对待机密一样对待它。它在 `upstream_expires_at` 过期；在 Seedance 2.5 上，BytePlus 将其限制为 100 次下载，其中一次会被 Router 自己的重新托管消耗。
</ResponseField>

<ResponseField name="content.video_url" type="string">
  输出视频的下载 URL。Router 会将视频重新托管到 Comfy 存储并重写此字段，因此它通常是 Comfy 签名的 URL，有效期最长为 24 小时：签发时按 24 小时签名，并从 23 小时缓存中重放，因此较晚的轮询可能返回仅剩一小时有效期的 URL。如果无法执行重新托管，该字段会改为保留 BytePlus 自己的 URL；BytePlus 会在任务完成 24 小时后清除该 URL，并在某些模型上将其限制为 100 次下载。无论哪种情况，链接都会过期，因此请下载视频，而不是保存 URL。
</ResponseField>

<ResponseField name="created_at" type="integer">
  任务创建时间。该值是 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="duration" type="number">
  已生成视频的时长，单位为秒。声明为数字而非整数，因为 BytePlus 对此并不一致：已观察到视频任务返回整秒，而 BytePlus 的其他同级接口会反馈小数时长，因此客户端不得假定该值为整数。BytePlus 自己的字段，在已成功的视频任务上返回，并原样转发。
</ResponseField>

<ResponseField name="error" type="object">
  错误信息。如果任务成功，则返回 null。如果任务失败，则返回错误信息。
</ResponseField>

<ResponseField name="error.code" type="string">
  上游 ModelArk 错误码。SensitiveContentDetected、InputTextSensitiveContentDetected、InputImageSensitiveContentDetected、InputVideoSensitiveContentDetected、InputAudioSensitiveContentDetected、OutputTextSensitiveContentDetected、OutputImageSensitiveContentDetected、OutputVideoSensitiveContentDetected 和 OutputAudioSensitiveContentDetected 标识内容策略拒绝。某个系列可能带有以点分隔的原因，例如 InputImageSensitiveContentDetected.PrivacyInformation、OutputVideoSensitiveContentDetected.PolicyViolation 或 OutputImageSensitiveContentDetected.DeepFake。这是开放字符串，而非枚举：其他错误码用于描述验证与提供商失败。Router 能在 HTTP 400 错误封装和 HTTP 200 失败任务响应中识别策略系列，但不会覆盖传输失败。
</ResponseField>

<ResponseField name="error.message" type="string">
  报错信息
</ResponseField>

<ResponseField name="id" type="string">
  视频生成任务的 ID
</ResponseField>

<ResponseField name="model" type="string">
  该任务使用的模型名称及版本
</ResponseField>

<ResponseField name="output_format" type="string">
  已生成视频的容器格式（mp4 或 mov），在顶层作为 `content` 的兄弟字段返回，Seedance 视频任务查询即在此处返回该字段。这是 BytePlus 自有字段，原样透传。
</ResponseField>

<ResponseField name="resolution" type="string">
  已生成视频的分辨率，例如 `1080p`。这是 BytePlus 自有字段，在成功的视频任务中返回，原样透传。
</ResponseField>

<ResponseField name="seed" type="integer">
  该任务实际使用的生成种子。这是 BytePlus 自有字段，在成功的视频任务中返回，原样透传。

  格式：`int64`
</ResponseField>

<ResponseField name="status" type="string">
  任务的状态

  可能的值：`queued`, `running`, `cancelled`, `succeeded`, `failed`, `expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  任务最后更新的时间。该值为 UNIX 时间戳，单位为秒。
</ResponseField>

<ResponseField name="usage" type="object">
  本次请求的 token 用量
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  模型生成的 token 数量
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  对于视频生成模型，不计算输入 token 数量，默认为 0。因此 total_tokens = completion_tokens。
</ResponseField>
