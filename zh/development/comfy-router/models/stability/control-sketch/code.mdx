相同的请求体，发送到 `POST https://api.comfy.org/v2/models/stability/control-sketch/requests`。一旦运行被接纳，Router 就会以 `201` 返回 `request_id`；结果就绪后即可获取，可以在本进程获取，也可以在另一个进程中获取。[队列投递](/zh/development/comfy-router/queue)会逐步介绍状态、取消和结果收集。

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 从环境变量中读取 COMFY_API_KEY。
# 每次 submit() 调用都会生成自己的 Idempotency-Key，并在自动重试时复用它。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/control-sketch",
            {
                "control_strength": 0.7,
                "image": "https://storage.googleapis.com/example-bucket/sketch.png",
                "prompt": "a castle on a cliff",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # 配合模型 ID，这就是另一个进程所需的全部信息

        # 轮询直到请求完成，每次按服务器给出的 Retry-After 等待。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 提供商自己的负载，与 models.run() 返回的值相同。
        # 失败或已取消的请求会在这里抛出带类型的 Router 错误。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 从环境变量中读取 COMFY_API_KEY。
// 每次 submit() 调用都会生成自己的 Idempotency-Key，并在自动重试时复用它。
const handle = await comfy.models.submit("stability/control-sketch", {
  control_strength: 0.7,
  image: "https://storage.googleapis.com/example-bucket/sketch.png",
  prompt: "a castle on a cliff",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // 配合模型 ID，这就是另一个进程所需的全部信息

// 轮询直到请求完成，每次按服务器给出的 Retry-After 等待。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// 与 models.run() 返回的结果相同。失败或已取消的请求会在这里被拒绝。
const result = await handle.get();

console.log(result.data);
```

  -H "X-API-Key: $COMFY_API_KEY"

# 3. 获取结果。200 返回模型的原始输出，仍在运行时则返回 202 和状态响应体。

## Schema

### 输入

<ParamField body="control_strength" type="number">
  结果与来源图像的贴合程度。默认值为 0.7。

  范围：`0` 到 `1`
</ParamField>

<ParamField body="image" type="string (uri)" required>
  来源图像的 Comfy 签名资产 URL。

  格式：`uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  要从图像中排除的内容。
</ParamField>

<ParamField body="output_format" type="string">
  仅返回 `png`。

  可能的值：`png`
</ParamField>

<ParamField body="prompt" type="string" required>
  要根据来源图像生成的内容。
</ParamField>

<ParamField body="seed" type="integer">
  填 0 或省略时会随机选取一个种子。

  范围：`0` 到 `4294967294`
</ParamField>

<ParamField body="style_preset" type="string">
  会被接受，但不会应用。
</ParamField>

</ResponseField>
