同一个请求体，发送到 `POST https://api.comfy.org/v2/models/stability/sd3.5-large/requests`。运行一旦被接纳，Router 就会返回 `201` 及 `request_id`；结果就绪后即可收集，可以从当前进程获取，也可以从另一个进程获取。[队列投递](/zh/development/comfy-router/queue)介绍了状态、取消和收集的完整流程。

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 从环境变量中读取 COMFY_API_KEY。
# 每次调用 submit() 都会生成自己的 Idempotency-Key，并在自动重试时复用它。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/sd3.5-large",
            {
                "aspect_ratio": "16:9",
                "prompt": "a lighthouse on a cliff at sunset, oil painting",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # 配合模型 ID，就是另一个进程所需的全部信息

        # 轮询直到请求完成，按服务器指定的 Retry-After 等待。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 提供商自己的响应负载，与 models.run() 返回的值相同。
        # 失败或已取消的请求会在这里抛出类型化的 Router 错误。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 从环境变量中读取 COMFY_API_KEY。
// 每次调用 submit() 都会生成自己的 Idempotency-Key，并在自动重试时复用它。
const handle = await comfy.models.submit("stability/sd3.5-large", {
  aspect_ratio: "16:9",
  prompt: "a lighthouse on a cliff at sunset, oil painting",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // 配合模型 ID，就是另一个进程所需的全部信息

// 轮询直到请求完成，按服务器指定的 Retry-After 等待。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// 与 models.run() 返回的结果相同。失败或已取消的请求会在这里被拒绝。
const result = await handle.get();

console.log(result.data);
```

## Schema

### 输入

<ParamField body="aspect_ratio" type="string">
  仅文生图。输出宽高比，图像约为 100 万像素。默认 1:1。

  可选值：`1:1`、`16:9`、`9:16`、`21:9`、`9:21`、`3:2`、`2:3`、`5:4`、`4:5`
</ParamField>

<ParamField body="cfg_scale" type="number">
  图像遵循提示词的程度。

  范围：`1` 到 `10`
</ParamField>

<ParamField body="image" type="string (uri)">
  仅图生图。来源图像的 Comfy 签名资产 URL。

  格式：`uri`
</ParamField>

<ParamField body="mode" type="string">
  默认为文生图。图生图需要 `image` 和 `strength`。

  可选值：`text-to-image`、`image-to-image`
</ParamField>

<ParamField body="negative_prompt" type="string">
  希望图像中避免出现的内容。
</ParamField>

<ParamField body="output_format" type="string">
  仅返回 `png`。

  可选值：`png`
</ParamField>

<ParamField body="prompt" type="string" required>
  要生成的内容。
</ParamField>

<ParamField body="seed" type="integer">
  为 0 或省略时会随机选择种子。

  范围：`0` 到 `4294967294`
</ParamField>

<ParamField body="strength" type="number">
  仅图生图。与来源图像的偏离程度；为 1 时会忽略来源图像。

  范围：`0` 到 `1`
</ParamField>

<ParamField body="style_preset" type="string">
  Stability 风格预设，例如 `photographic`。
</ParamField>

根据 Router 在 `GET /v2/models/stability/sd3.5-large/openapi.json` 提供的 schema 生成；该文档也是请求到达提供商之前 Router 用于校验调用的同一份文档。

### 输出

<ResponseField name="finish_reason" type="string" required>
  在 200 响应中始终为 SUCCESS。
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  （第一张）PNG 图像的 Comfy 签名图片网址，有效期最长 24 小时。

  格式：`uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  仅 SDXL，在返回多张图像时使用。按输出顺序列出每个 Comfy 签名的图片网址，每个有效期最长 24 小时。
</ResponseField>

<ResponseField name="seed" type="integer" required>
  生成图像时使用的种子。
</ResponseField>
