## Schema

### 输入

<ParamField body="input" type="object" required>
  P-Video-Upscale 参数。任务按返回视频的秒数计费，秒数从返回的文件中测量并向上取整为整秒。费率由 `target` 以及输出帧率是否高于 30 fps 决定。省略 `fps` 时，输出保持 `video` 的帧率，因此由该帧率决定费率档位。`turbo` 任务在任何帧率下都按其 `target` 的 turbo 费率计费。安全过滤始终开启；请求中的 `enable_safety_filter` 值会被忽略。
</ParamField>

<ParamField body="input.fps" type="integer">
  输出帧率（16-60）。高于来源帧率的帧率会通过插值生成。省略时，输出保持来源帧率。

  范围：`16` 到 `60`
</ParamField>

<ParamField body="input.target" type="string" default="&quot;1080p&quot;">
  输出分辨率预设：720p、1080p、2k 或 4k。预设决定像素面积；不是 16:9 的视频会保持其宽高比。已经大于目标分辨率的视频不会被缩小。

  可能的值：`720p`、`1080p`、`2k`、`4k`
</ParamField>

<ParamField body="input.turbo" type="boolean" default="false">
  任务更快，画质略低，在任何帧率下都按 turbo 费率计费（约为标准费率的三分之一）。
</ParamField>

<ParamField body="input.video" type="string" required>
  输入视频 URI，最大 512 MiB。省略 `fps` 时，它必须是可公开读取的 http(s) URL，因为会在任务发送之前读取其帧率。
</ParamField>
