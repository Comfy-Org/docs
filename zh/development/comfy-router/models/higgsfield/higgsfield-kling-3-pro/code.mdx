from comfy_sdk import Comfy

## Schema

### 输入

<ParamField body="aspect_ratio" type="string" default="&quot;16:9&quot;">
  输出比例。

  可选值：`16:9`, `9:16`, `1:1`
</ParamField>

<ParamField body="cfg_scale" type="number" default="0.5">
  生成结果对提示词的遵循程度。Higgsfield 文档说明为 0-1，步长 0.01，但此处只声明 0-1 的边界：`multipleOf: 0.01` 会在二进制浮点中求值，从而会拒绝 0.3 这样的普通取值，因此更精细的值会被接受并转发，而不是被拒绝，这与 `prompt` 对其未声明的长度上限所作的说明相同。

  范围：`0` 到 `1`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  输出时长，单位为秒。支持范围：3-15。

  范围：`3` 到 `15`
</ParamField>

<ParamField body="elements" type="string[]">
  可复用的 Kling 元素 id，用于在多次生成之间保持主体一致性。
</ParamField>

<ParamField body="multi_prompt" type="object[]">
  有序的分镜定义，在 `multi_shots` 为 true 时使用。1-6 个分镜；每个分镜的时长受任务自身总时长的约束，而这一点无法在此表达。
</ParamField>

<ParamField body="multi_prompt[].duration" type="integer">
  此分镜的时长，单位为秒，1-15。所有分镜的时长之和不得超过任务的总时长，JSON Schema 无法表达这一点；由 Higgsfield 强制执行。

  范围：`1` 到 `15`
</ParamField>

<ParamField body="multi_prompt[].prompt" type="string">
  此分镜的提示词。Higgsfield 文档说明上限为 512 个字符。
</ParamField>

<ParamField body="multi_shots" type="boolean" default="false">
  启用多分镜序列。当为 true 时，由 `multi_prompt` 承载各分镜的定义。
</ParamField>

<ParamField body="prompt" type="string">
  描述期望输出的提示词。Higgsfield 文档说明 Kling 最多使用前 2,500 个字符，超出部分会被截断，因此这里不声明 maxLength：更长的正文会被接受，而不是被拒绝。
</ParamField>

<ParamField body="sound" type="string" default="&quot;on&quot;">
  启用或禁用生成的声音。

  可选值：`on`, `off`
</ParamField>
