`krea/krea-3` 的 API 参考文档，由 Comfy Router 从 Krea 提供。

## 快速开始

在[你的 Comfy 工作区](https://platform.comfy.org/profile/api-keys?onboarding=router)中创建密钥，并将其导出为 `COMFY_API_KEY`。Python 和 TypeScript 代码片段使用 Comfy SDK（`pip install comfy-sdk` 和 `npm install @comfyorg/sdk`）；cURL 代码片段是通过原始 HTTP 发出的相同调用。

**模型 ID：** `krea/krea-3`

**端点：** `POST https://api.comfy.org/v2/models/krea/krea-3`

相同的请求体，发送到 `POST https://api.comfy.org/v2/models/krea/krea-3/requests`。运行一经接纳，Router 就会返回 `201` 和一个 `request_id`，结果准备就绪后即可收集，可由当前进程或另一个进程收集。[队列投递](/zh/development/comfy-router/queue)会依次介绍状态、取消和收集。

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 从环境变量读取 COMFY_API_KEY。
# 每次 submit() 调用都会生成自己的 Idempotency-Key，并在自动重试时复用它。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "krea/krea-3",
            {
                "image_urls": ["https://example.com/reference.png"],
                "prompt": "Place the product on a clean studio background",
                "resolution": "1k",
            },
        )
        print("request_id:", handle.request_id)  # 加上模型 ID，就是另一个进程所需的全部信息

        # 轮询直到请求完成，等待服务器指定的 Retry-After。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 提供商自己的载荷，与 models.run() 返回的值相同。
        # 失败或已取消的请求会在这里抛出类型化的 Router 错误。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 从环境变量读取 COMFY_API_KEY。
// 每次 submit() 调用都会生成自己的 Idempotency-Key，并在自动重试时复用它。
const handle = await comfy.models.submit("krea/krea-3", {
  image_urls: ["https://example.com/reference.png"],
  prompt: "Place the product on a clean studio background",
  resolution: "1k",
});
console.log("requestId:", handle.requestId); // 加上模型 ID，就是另一个进程所需的全部信息

// 轮询直到请求完成，等待服务器指定的 Retry-After。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// 与 models.run() 返回的结果相同。失败或已取消的请求会在这里被拒绝。
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 提交。Router 返回 201，并带有 request_id、status_url、response_url 和 cancel_url。
curl https://api.comfy.org/v2/models/krea/krea-3/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"image_urls\": [\"https://example.com/reference.png\"], \"prompt\": \"Place the product on a clean studio background\", \"resolution\": \"1k\"}"

# 2. 轮询直到状态为 COMPLETED，并等待每个响应指定的 Retry-After 秒数。
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/krea/krea-3/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 收集。200 返回模型的原生输出，仍在运行时则返回 202 和状态响应体。
curl https://api.comfy.org/v2/models/krea/krea-3/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Schema

### 输入

<ParamField body="aspect_ratio" type="string">
  1:1、4:5、3:4、2:3、9:16、5:4、4:3、3:2、16:9 或 21:9。与分辨率配合使用；省略则自动构图。
</ParamField>

<ParamField body="image_urls" type="string[]">
  输入图像 URL，最多 8 个。使用 POST /proxy/krea/assets 返回的 image_url 值。文生图时省略。
</ParamField>

<ParamField body="model" type="string">
  berry（默认，质量）或 jam（速度）。
</ParamField>

<ParamField body="negative_prompt" type="string">
   
</ParamField>

<ParamField body="prompt" type="string" required>
  编辑指令。描述应更改什么以及应保持不变什么。
</ParamField>

<ParamField body="regional_edit" type="boolean">
  设为 true 表示执行局部编辑并保留图像其余部分。需要 model 为 berry，且 image_urls 中至少有一个图像。
</ParamField>

<ParamField body="resolution" type="string" required>
  1k 或 2k。
</ParamField>

<ParamField body="seed" type="integer">
   
</ParamField>

<ParamField body="thinking_mode" type="string">
  fast（默认）、high 或 ultra。high 和 ultra 会更详细地规划复杂编辑，耗时也更长。ultra 需要分辨率 2k。
</ParamField>

<ResponseField name="created_at" type="string (date-time)" required>
  格式：`date-time`
</ResponseField>

<ResponseField name="result" type="object" required>

</ResponseField>

</ResponseField>

<ResponseField name="status" type="string" required>
  此文档中始终为 `completed`：这是 Router 唯一报告为成功的状态，且匹配 Krea 的用词时不进行大小写折叠。

  可能的值：`completed`
</ResponseField>
