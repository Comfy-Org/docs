## Schema

### 输入

<ParamField body="base_thickness_mm" type="number">
  底板厚度（毫米），0.1 到 10。当 remove_base 为 true 时，请省略该参数或发送 0。

  范围：`0` 到 `10`
</ParamField>

<ParamField body="bend_angle" type="number" default="60">
  弯曲角度（度）。小于 1 时，浮雕保持平坦。

  范围：`0` 到 `360`
</ParamField>

<ParamField body="bend_axis" type="string">
  `xz`（默认，弯曲左右边缘）或 `yz`（弯曲上下边缘）。仅在 bend_mode 为 convex 或 concave 时适用。
</ParamField>

<ParamField body="bend_mode" type="string">
  `off`（默认）、`convex` 或 `concave`。
</ParamField>

<ParamField body="carving_depth_mm" type="number">
  雕刻深度（毫米）。variant 为 high 时默认值为 6，variant 为 low 时默认值为 3。

  范围：`0` 到 `60`
</ParamField>

<ParamField body="carving_mode" type="string">
  `emboss`（默认）或 `engrave`。
</ParamField>

<ParamField body="color_mapping" type="boolean" default="false">
  根据图像为模型上色。GLB、OBJ、FBX 和 USDZ 会携带颜色；STL 和 3MF 保持白色。费用不变。
</ParamField>

<ParamField body="image_url" type="string" required>
  jpg、jpeg、png 或 webp 图像的公开 URL 或 data URI。最大 20 MB，至少 32 x 32 像素。透明区域会填充为黑色。
</ParamField>

<ParamField body="mesh_resolution" type="integer" default="1024">
  沿较长边的点数。值越大，文件会大得多（2048 时约为 150 MB GLB 和 300 MB STL）。

  范围：`512` 到 `2048`
</ParamField>

<ParamField body="removal_threshold" type="number" default="0.01">
  背景移除阈值。仅在 remove_base 为 true 时适用。

  范围：`0.01` 到 `1`
</ParamField>

<ParamField body="remove_base" type="boolean" default="false">
  切除背景，使浮雕没有底板。
</ParamField>

<ParamField body="should_generate_model" type="boolean" default="true">
  设为 false 时仅生成深度图，不生成模型，也不生成预览。费用不变。
</ParamField>

<ParamField body="size_mm" type="number" default="60">
  较长边的长度，单位为毫米。

  范围：`20` 到 `250`
</ParamField>

<ParamField body="target_formats" type="string[]">
  要生成的模型格式。以下格式中的一个或多个：glb、obj、fbx、stl、usdz 和 3mf。默认为 glb 和 stl。
</ParamField>

<ParamField body="variant" type="string">
  `low`（默认）提供较浅的深度和更精细的细节，适用于激光或 CNC 加工。`high` 提供更深的雕塑感浮雕，适用于 3D 打印。它还会设置默认的 carving_depth_mm。
</ParamField>
