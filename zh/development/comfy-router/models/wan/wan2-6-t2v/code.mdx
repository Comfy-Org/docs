import asyncio
from comfy_sdk import AsyncComfy

# 从环境变量中读取 COMFY_API_KEY。
# 每次 submit() 调用都会生成自己的 Idempotency-Key，并在自动重试时复用它。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "wan/wan2.6-t2v",
            {
                "input": {
                    "prompt": "a single red maple leaf falling onto still water, slow motion, shallow depth of field",
                },
                "parameters": {
                    "resolution": "720P",
                    "duration": 5,
                },
            },
        )
        print("request_id:", handle.request_id)  # 配合模型 ID，就是另一个进程所需的全部信息

        # 轮询直到请求完成，每次等待服务器指定的 Retry-After 时长。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 提供商返回的原始负载，与 models.run() 返回的值相同。
        # 失败或已取消的请求会在此处抛出带类型的 Router 错误。
        result = await handle.get()

    print("video:", result["output"]["video_url"])

asyncio.run(main())

上文中各模型的计数是合作伙伴的约束，而非本 schema 的约束：media 上未声明
minItems/maxItems，因为可接受的类型及其上限因模型而异。schema 接受并不代表
提供商接受。反过来，上文每项资产“最大 20MB”的数值（即图像输入的上限，而图像
输入是唯一可以内联发送的输入）是合作伙伴对其最终收到的资产所设的上限；当资产
是一个公共 URL 时，它们按原文适用，因为这些字节从不经过 Comfy。内联的
data:\{MIME_type};base64,... URL 确实会经过 Comfy，并且也会遇到传输上限：一个
Comfy Router 的 POST 请求体总量上限为 100 MiB，超出则返回 413，而 base64 会
将载荷放大约 4/3，因此单个内联资产一旦超过约 75 MB，就会在触达这里任何合作伙伴
规则之前被拒绝。在这种大小下，单个资产即便处于合作伙伴自身的20MB 的上限可以轻松地内联容纳，因此对单个资产而言，起约束作用的是合作伙伴规则；而当涉及多个资产时，起约束作用的则是传输上限，因为 100 MiB 的 Router 上限约束的是整个请求，而不是每个元素。凡是接近这些上限的内容，请以公共 URL 的形式发送。

<ParamField body="parameters.shot_type" type="string" default="&quot;single&quot;">

</ParamField>

<ParamField body="parameters.size" type="string">
  视频分辨率，格式为 宽度*高度。支持的分辨率因模型而异：
对于 wan2.5 T2V：480P（480*832、832*480、624*624）、720P、1080P 尺寸
对于 wan2.6 T2V/R2V（无 480P）：
  720P：1280*720、720*1280、960*960、1088*832、832*1088
  1080P：1920*1080、1080*1920、1440*1440、1632*1248、1248*1632
同时发送 size 和 resolution 时，由 size 决定计费档位，而 resolution 仍必须是该代理针对该模型接受的值。对于 resolution 说明中列为无 480P 的每个模型，480P 尺寸都会返回 400。
</ParamField>

<ParamField body="parameters.watermark" type="boolean" default="false">
  是否添加水印 logo，水印位于右下角
</ParamField>
