import asyncio
from comfy_sdk import AsyncComfy

# 从环境变量中读取 COMFY_API_KEY。
# 每次 submit() 调用都会生成自己的 Idempotency-Key，并在自动重试时复用它。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "wan/wan2.6-i2v",
            {
                "input": {
                    "prompt": "the robot lowers its raised arm and steps toward the camera, the flat orange backdrop holds steady",
                    "img_url": "https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/input/pink_robot_front.png",
                },
                "parameters": {
                    "resolution": "720P",
                    "duration": 5,
                },
            },
        )
        print("request_id:", handle.request_id)  # 配合模型 ID，就是另一个进程所需的全部信息

        # 轮询直到请求完成，按服务器给出的 Retry-After 等待。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 提供商自己的响应负载，与 models.run() 返回的值相同。
        # 失败或已取消的请求会在此处抛出带类型的 Router 错误。
        result = await handle.get()

    print("video:", result["output"]["video_url"])

asyncio.run(main())

<ParamField body="input.media" type="object[]">

- happyhorse-1.0-r2v、happyhorse-1.1-r2v：仅 reference_image，1 到 9 个。这是该模型唯一的参考输入。最短边至少 400 像素，JPEG/JPG/PNG/WEBP，最大 20MB，公共 URL 或 data:\{MIME_type};base64,... URL。reference_video 不是此操作的输入类型。
- happyhorse-1.0-video-edit：video（恰好 1 个，即被编辑的片段：MP4/MOV，3-60 秒，长边最大 4096 像素，短边至少 360 像素，宽高比在 1:2.5 到 2.5:1 之间，最大 100MB，公共 HTTP/HTTPS URL；不接受内联 data: URL），外加可选的 0 到 5 个 reference_image（JPEG/JPG/PNG/WEBP，至少 300x300 像素，宽高比在 1:2.5 到 2.5:1 之间，最大 20MB，公共 URL 或 data:\{MIME_type};base64,... URL）。

该代理会拒绝既未提供 resolution 也未提供 size 的视频生成请求，因为分辨率档位决定计费费率。它会在校验前将 resolution 转为大写并转发转为大写后的值；对于该枚举之外的取值返回 400；对于上文列为不支持 480P 的 wan2.6、wan2.7 和 happyhorse-1.0 模型，遇到 480P 时返回 400（无论是以 resolution 传入，还是以 480P 的 size 传入）。

  可选值：`480P`、`720P`、`1080P`
</ParamField>

<ParamField body="parameters.seed" type="integer">

<ParamField body="parameters.shot_type" type="string" default="&quot;single&quot;">

适用于 wan2.6 和 wan2.7-r2v 模型。
- single: 单镜头视频（默认）
- multi: 多镜头视频

  可选值：`multi`、`single`
</ParamField>

<ParamField body="parameters.size" type="string">
  视频分辨率，格式为 width*height。支持的分辨率因模型而异：
wan2.5 T2V：480P（480*832、832*480、624*624）、720P、1080P 尺寸
wan2.6 T2V/R2V（不支持 480P）：
  720P：1280*720、720*1280、960*960、1088*832、832*1088
  1080P：1920*1080、1080*1920、1440*1440、1632*1248、1248*1632
当同时传入 size 和 resolution 时，size 决定计费档位，而 resolution 仍必须是该代理接受的、适用于该模型的取值。在分辨率说明中列为不支持 480P 的每个模型上，传入 480P 的 size 都会返回 400。
