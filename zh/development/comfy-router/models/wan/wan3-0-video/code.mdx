Wan 3.0 Video 的 API 参考。Wan 3.0 Video 既可以仅根据提示词生成，也可以根据由首帧和末帧、参考图像、视频和音频组成的媒体列表生成；在提示词中分别以 Image 1、Video 1 和 Audio 1 来引用。

## 快速开始

在[你的 Comfy 工作区](https://platform.comfy.org/profile/api-keys)中创建密钥，并将其导出为 `COMFY_API_KEY`。Python 和 TypeScript 代码片段使用 Comfy SDK（`pip install comfy-sdk`、`npm install @comfyorg/sdk`）；cURL 代码片段是通过原始 HTTP 发起的相同调用。

**模型 ID：** `wan/wan3.0-video`

**端点：** `POST https://api.comfy.org/v2/models/wan/wan3.0-video`

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment.
# The SDK automatically creates an idempotency key and reuses it for automatic retries.
with Comfy() as client:
    result = client.models.run(
        "wan/wan3.0-video",
        {
            "input": {
                "prompt": "the robot lowers its raised arm and steps toward the camera, the flat orange backdrop holds steady",
                "media": [
                    {
                        "type": "first_frame",

            "parameters": {
                "resolution": "720P",
                "duration": 5,
            },
        },
    )

print("video:", result["output"]["video_url"])
```

```typescript TypeScript
  },

```

</ParamField>

<ParamField body="input.media" type="object[]">
  wan2.7 和 wan3.0 模型的媒体资产列表。用于指定视频生成的参考素材（图像、音频、视频）。每个元素包含 type 和 url 字段。
支持的 type 取值因模型而异：
- wan2.7-i2v：first_frame、last_frame、driving_audio、first_clip
- wan2.7-r2v：reference_image、reference_video
- wan2.7-videoedit：video、reference_image
- wan3.0-video：first_frame（最大值 1）、last_frame（最大值 1）、reference_image（最大值 10）、
  reference_video（最大值 5 段，总时长 \<= 15s）、reference_audio（最大值 5 段，
  总时长 \<= 15s）、file（最大值 1，不能与 link 同时使用）、link（最大值 1，不能
  与 file 同时使用）。reference_*/file/link 类型与 first_frame/last_frame 类型
  在同一请求中互斥。数组顺序定义了提示词中资产的引用
  顺序（Image 1、Video 1、Audio 1、...）。
</ParamField>

<ParamField body="input.media[].type" type="string" required>
  媒体资产类型

  可选值：`first_frame`、`last_frame`、`driving_audio`、`first_clip`、`reference_image`、`reference_video`、`reference_audio`、`video`、`file`、`link`
</ParamField>

<ParamField body="input.media[].url" type="string" required>
  媒体文件的 URL（公开的 HTTP/HTTPS URL 或 OSS 临时 URL）
</ParamField>

<ParamField body="input.negative_prompt" type="string">
  反向提示词，用于描述你不希望在视频画面中看到的内容
</ParamField>

<ParamField body="input.prompt" type="string">
  文本提示词。支持中文和英文，长度不超过 800 个字符
（wan3.0-video 最多 20,000 个字符；超出限制的内容会被截断）。
对于使用多个参考视频的 wan2.6-r2v，请按参考视频的顺序使用 'character1'、'character2' 等来指代
其中的主体。示例："Character1 sings on the roadside, Character2 dances beside it"
对于 wan3.0-video 参考模式，请使用 'Image 1'、'Video 1'、'Audio 1' 等来指代
media 数组中相应顺序的媒体资产。
</ParamField>

<ParamField body="input.reference_video_urls" type="string[]">
  仅适用于 wan2.6-r2v 模型的参考视频 URL。由 1-3 个视频 URL 组成的数组。
输入限制：
- 格式：mp4、mov
- 数量：1-3 个视频
- 单个视频长度：2-30 秒
- 单个文件大小：最大值 30MB
- 不能与 audio_url 同时使用
参考时长：单个视频最大值为 5s，两个视频各最大值为 2.5s，三个视频按比例减少。
计费：基于实际使用的参考时长。
</ParamField>

<ParamField body="input.template" type="string">

</ParamField>

<ParamField body="model" type="string">

</ParamField>

<ParamField body="parameters.duration" type="integer" default="5">

- wan2.6-r2v：仅 5 或 10 秒（不支持 15s）
- wan2.7-i2v、wan2.7-t2v：[2, 15] 范围内的整数
- wan2.7-r2v、wan2.7-videoedit：[2, 10] 范围内的整数

  范围：`-1` 到 `30`

对于 wan3.0-video，adaptive（默认值）会根据输入媒体的比例和意图
自动推荐合适

  可选值：`adaptive`、`16:9`、`9:16`、`1:1`、`4:3`、`3:4`
</ParamField>

<ParamField body="parameters.resolution" type="string">

- wan2.5-i2v-preview：480P、720P、1080P
- wan2.6-i2v：仅 720P、1080P（不支持 480P）
- wan2.7 模型（i2v、t2v、r2v、videoedit）：720P、1080P（默认 1080P）
- wan3.0-video、wan3.0-video-prime：480P、720P、1080P（上游默认 1080P）
此代理会拒绝既未提供分辨率
也未提供尺寸的视频生成请求，
因为分辨率档位决定计费费率。

  可选值：`480P`、`720P`、`1080P`
