同一个请求体，发送到 `POST https://api.comfy.org/v2/models/pixverse/v3.5/requests`。运行被受理后，Router 会立即返回 `201` 和 `request_id`，结果准备就绪后即可收集，收集方可以是当前进程，也可以是另一个进程。[排队交付](/zh/development/comfy-router/queue)介绍了状态、取消和收集的完整流程。

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 从环境变量读取 COMFY_API_KEY。
# 每次 submit() 调用都会生成自己的 Idempotency-Key，并在自动重试时复用它。
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "pixverse/v3.5",
            {
                "aspect_ratio": "16:9",
                "duration": 5,
                "prompt": "a single red maple leaf falling onto still water",
                "quality": "360p",
            },
        )
        print("request_id:", handle.request_id)  # 连同模型 ID，这就是另一个进程所需的全部信息。

        # 轮询直到请求完成，并等待服务器指定的 Retry-After 时间。
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 提供商自身的 payload，与 models.run() 返回的值相同。
        # 失败或已取消的请求会在这里抛出类型化的 Router 错误。
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 从环境变量读取 COMFY_API_KEY。
// 每次 submit() 调用都会生成自己的 Idempotency-Key，并在自动重试时复用它。
const handle = await comfy.models.submit("pixverse/v3.5", {
  aspect_ratio: "16:9",
  duration: 5,
  prompt: "a single red maple leaf falling onto still water",
  quality: "360p",
});
console.log("requestId:", handle.requestId); // 连同模型 ID，这就是另一个进程所需的全部信息。

// 轮询直到请求完成，并等待服务器指定的 Retry-After 时间。
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// 与 models.run() 返回的相同结果。失败或已取消的请求会在这里被拒绝。
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 提交。Router 返回 201，以及 request_id、status_url、response_url 和 cancel_url。
curl https://api.comfy.org/v2/models/pixverse/v3.5/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"aspect_ratio\": \"16:9\", \"duration\": 5, \"prompt\": \"a single red maple leaf falling onto still water\", \"quality\": \"360p\"}"

# 2. 轮询直到 status 为 COMPLETED，并等待每个响应指定的 Retry-After 秒数。
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/pixverse/v3.5/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 收集。返回 200 和模型的原生输出；若仍在运行，则返回 202 和状态响应体。
curl https://api.comfy.org/v2/models/pixverse/v3.5/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```
