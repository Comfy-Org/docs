  当为 false（默认值）时，请求会以异步方式处理。当为
true 时，API 会保持连接打开直到处理完成。在 COMFY
ROUTER 上，第二种模式会被拒绝而不是被转发：Router
会在派发之前固定返回模式，并在调用内部轮询结果，
因此 `POST /v2/models/bria/{model}` 对该路由携带的任何
`sync` 值（只要不是 `false` 或 `null`）都会返回 422
invalid_input（routerForbiddenBodyFields）。同步调用
仍可通过此操作自身的 `/proxy/` 路由使用，本 schema
所描述的也正是这一接口。
</ParamField>
