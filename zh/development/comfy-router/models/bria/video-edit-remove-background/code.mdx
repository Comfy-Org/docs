## Schema

### 输入

<ParamField body="background_color" type="string">
  输出视频的背景颜色。如果为 Transparent，输出编解码器必须支持透明度。

  可选值：`Transparent`、`Black`、`White`、`Gray`、`Red`、`Green`、`Blue`、`Yellow`、`Cyan`、`Magenta`、`Orange`
</ParamField>

<ParamField body="output_container_and_codec" type="string">
  输出容器与编解码器预设。

  可选值：`mp4_h264`、`mp4_h265`、`webm_vp9`、`mov_h265`、`mov_proresks`、`mkv_h264`、`mkv_h265`、`mkv_vp9`、`gif`
</ParamField>

<ParamField body="preserve_audio" type="boolean">
  是否保留输入视频的音频。
</ParamField>

<ParamField body="video" type="string" required>
  输入视频的可公开访问 URL。支持的输入分辨率最高可达 16000x16000（16K）。最大时长为 60 秒。
</ParamField>
