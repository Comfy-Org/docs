from comfy_sdk import Comfy

    # 轮询直到请求完成，按照服务器指定的 Retry-After 等待。

    # 提供商自身的负载，与 models.run() 返回的值相同。

## Schema

### 输入

<ParamField body="auto_trim" type="boolean">
  当为 true 时，超过 5 秒的视频会被裁剪为前 5 秒。当为 false（默认）时，时长超过 5 秒的视频会被拒绝。
</ParamField>

<ParamField body="mask" type="string" required>
  用于定义待擦除区域的遮罩视频的可公开访问 URL。白色像素标记要移除的区域，黑色像素则会被保留。
</ParamField>

<ParamField body="output_container_and_codec" type="string">
  输出容器与编解码器预设。

  可选值：`mp4_h264`、`mp4_h265`、`webm_vp9`、`mov_h265`、`mov_proresks`、`mkv_h264`、`mkv_h265`、`mkv_vp9`、`gif`
</ParamField>

<ParamField body="preserve_audio" type="boolean">
  是否保留输入视频中的音频。
</ParamField>

<ParamField body="video" type="string" required>
  输入视频的可公开访问 URL。除非 auto_trim 为 true，否则最长时长为 5 秒。支持的输入分辨率最高为 750p；更大的输入会被缩小。
</ParamField>

本文档根据 Router 在 `GET /v2/models/bria/video-edit-erase/openapi.json` 提供的 schema 生成，这也正是请求到达提供商之前 Router 用于校验调用的同一份文档。
