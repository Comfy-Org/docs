<div className="router-quickstart-marker" />

Comfy Router 为你提供一套用于托管图像和视频模型的 API，地址为 `https://api.comfy.org`。请在[你的 Comfy 工作区](https://platform.comfy.org/profile/api-keys?onboarding=router)中创建 API 密钥，然后使用官方 [Python 和 TypeScript SDK](/zh/development/api-development/sdks) 或直接通过 HTTP 调用任意模型。计费方式为按使用量付费：每次请求都会从你的工作区余额中扣除积分，无需订阅。

<Note>
  **使用 Higgsfield？** 保存你自己的 Higgsfield 密钥后，这些生成将计入你的 Higgsfield 账户，而不是你的 Comfy 积分。端点相同，请求体也相同。请参阅[使用你自己的密钥的 Higgsfield](/zh/development/comfy-router/higgsfield-byok)。
</Note>

<Note>
  **用 LiteLLM 追踪支出？** Router 会在 LiteLLM 读取的响应头中报告同步运行的美元成本，因此你无需维护价格表。请参阅[将 Comfy Router 与 LiteLLM 搭配使用](/zh/development/comfy-router/litellm)。
</Note>

<Steps titleSize="h2">
  <Step title="创建 API 密钥">
    在[你的 Comfy 工作区](https://platform.comfy.org/profile/api-keys?onboarding=router)中创建密钥。在兼容 Bash 的终端中，设置：

    ```bash
    export COMFY_API_KEY="comfyui-..."
    ```

    请将 API 密钥保存在你的服务器上或本地环境中。这些示例面向终端或服务器，不适用于浏览器 JavaScript。

    Router 按请求扣除积分。如果你的工作区没有积分余额，首次实际调用会返回 `402`，并带有 `error_type: insufficient_credits`。该检查在请求体验证之前执行，因此未充值的工作区即使请求无效也可能返回 `402`。在调试请求体之前，请先到[工作区计费](https://platform.comfy.org)添加积分。
  </Step>

  <Step title="将请求加入队列">
    选择你的语言并运行示例。生成可能需要几分钟。

    <CodeGroup>

    ```python Python
    # 需要 Python 3.10+
    # 安装：python -m pip install "comfy-sdk>=0.3.0"
    # 保存为 quickstart.py，然后运行：python quickstart.py

    import asyncio

    from comfy_sdk import AsyncComfy

    # AsyncComfy 会从环境变量中读取 COMFY_API_KEY。
    async def main():
        async with AsyncComfy() as client:
            handle = await client.models.submit(
                "byteplus/dreamina-seedance-2-5-260628",
                {
                    "content": [
                        {
                            "text": "A red fox trotting through a snowy pine forest",
                            "type": "text",
                        },
                    ],
                    "duration": 5,
                    "ratio": "16:9",
                    "resolution": "720p",
                },
            )
            print("request_id:", handle.request_id)

            # 轮询直到请求完成，每次等待服务器指定的 Retry-After。
            async for update in handle.iter_events():
                print(update.status, update.queue_position)

            result = await handle.get()

        print("result:", result)

    asyncio.run(main())
    ```

    ```bash cURL
    # 1. 提交请求。保存 201 响应中的 request_id。
    curl https://api.comfy.org/v2/models/byteplus/dreamina-seedance-2-5-260628/requests \
      -H "X-API-Key: $COMFY_API_KEY" \
      -H "Idempotency-Key: $(uuidgen)" \
      -H "Content-Type: application/json" \
      -d '{"content": [{"text": "A red fox trotting through a snowy pine forest", "type": "text"}], "duration": 5, "ratio": "16:9", "resolution": "720p"}'

    # 2. 轮询直到状态为 COMPLETED，每次都等待 Retry-After 指定的时长。
    REQUEST_ID="paste-request-id-from-201-response"
    curl -i "https://api.comfy.org/v2/models/byteplus/dreamina-seedance-2-5-260628/requests/$REQUEST_ID/status" \
      -H "X-API-Key: $COMFY_API_KEY"

    # 3. 获取模型结果。
    curl "https://api.comfy.org/v2/models/byteplus/dreamina-seedance-2-5-260628/requests/$REQUEST_ID" \
      -H "X-API-Key: $COMFY_API_KEY"
    ```

    ```typescript TypeScript
    // 需要 Node.js 22+
    // 安装：npm install "@comfyorg/sdk@>=0.4.0" --save-dev tsx
    // 保存为 quickstart.mts，然后运行：npx tsx quickstart.mts

    import { comfy } from "@comfyorg/sdk";

    // Comfy 会从环境变量中读取 COMFY_API_KEY。
    const handle = await comfy.models.submit(
      "byteplus/dreamina-seedance-2-5-260628",
      {
        content: [
          {
            text: "A red fox trotting through a snowy pine forest",
            type: "text",
          },
        ],
        duration: 5,
        ratio: "16:9",
        resolution: "720p",
      },
    );
    console.log("requestId:", handle.requestId);

    // 轮询直到请求完成，每次等待服务器指定的 Retry-After。
    for await (const update of handle.events()) {
      console.log(update.status, update.queuePosition);
    }

    const result = await handle.get();

    console.log("result:", result.data);
    ```

    </CodeGroup>

    每次 SDK 提交调用都会创建一个幂等键，并在自动重试时复用它。cURL 示例使用 `uuidgen` 创建一个幂等键。如果该命令不可用，请改用其他 UUID 生成工具。关于状态查询、取消和结果获取的详情，请参阅[队列投递](/zh/development/comfy-router/queue)。
  </Step>
</Steps>

## Image-to-video and reference-to-video

The same Seedance request takes image, video, and audio inputs. Add items to `content` and set each one's `role`. The roles you send decide the operation Router runs. Pricing follows the media kinds in `content`, not the roles: a request with any video input bills as video-to-video, otherwise one with any image bills as image-to-video, and a text-only request bills as text-to-video. Some models charge the same rate for text-to-video and image-to-video.

| Operation | `content` items |
|---|---|
| Text-to-video | one `text` item |
| Image-to-video | a `text` item plus an `image_url` item with `role: first_frame` |
| First-and-last-frame | the above plus a second `image_url` item with `role: last_frame` |
| Reference-to-video | a `text` item plus `image_url` items with `role: reference_image`, and on Seedance 2.0 and 2.5, `video_url` items with `role: reference_video` and `audio_url` items with `role: reference_audio` |

An image `url` can be a public URL or a `data:image/<format>;base64,<content>` string. Submit, poll, and collect exactly as in the quickstart above. Only the body changes.

```bash Image-to-video
curl https://api.comfy.org/v2/models/byteplus/dreamina-seedance-2-5-260628/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "content": [
      {"type": "text", "text": "The fox turns and runs into the trees"},
      {"type": "image_url", "image_url": {"url": "https://example.com/fox.png"}, "role": "first_frame"}
    ],
    "duration": 5,
    "resolution": "720p"
  }'
```

```bash Reference-to-video
curl https://api.comfy.org/v2/models/byteplus/dreamina-seedance-2-5-260628/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "content": [
      {"type": "text", "text": "The character from the reference walks through a neon-lit market"},
      {"type": "image_url", "image_url": {"url": "https://example.com/character.png"}, "role": "reference_image"},
      {"type": "image_url", "image_url": {"url": "https://example.com/outfit.png"}, "role": "reference_image"}
    ],
    "duration": 5,
    "ratio": "16:9",
    "resolution": "720p"
  }'
```

On Seedance 2.5, first-frame and first-and-last-frame requests take the output aspect ratio from the first frame. Leave `ratio` out or send `adaptive`, because a concrete ratio is refused with a `400`. The request schema is shared across the Seedance family and can list roles a model ignores, so check the `x-comfy-router-input-modalities` field in each model's [input schema](/development/comfy-router/models) for the input kinds that model accepts. For example, `reference_video` and `reference_audio` need a model that lists `video` or `audio` there.
