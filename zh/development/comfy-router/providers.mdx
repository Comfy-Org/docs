每个模型都使用 `POST /v2/models/{provider}/{model}`。Comfy 是默认提供商。对于有备用覆盖的模型，`model_provider` 可以在不更改模型 ID 或请求体的情况下选择另一个提供商。请参阅 API 参考中的 [`model_provider`、`strict_mode` 与 `fallback_provider`](/zh/development/comfy-router/reference#post-v2modelsprovidermodel)。
