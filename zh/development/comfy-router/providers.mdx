Comfy Router 通过同一条路由为所有模型提供服务：`POST /v2/models/{provider}/{model}`。其中少数模型可以由多个提供商提供服务，`model_provider` 查询参数用于选择由哪一个执行调用。模型 ID、请求体和响应形状都不会改变。参见 API 参考中的 [`model_provider`、`strict_mode` 与 `fallback_provider`](/zh/development/comfy-router/reference#post-v2modelsprovidermodel)。

## Comfy（直连）

[模型目录](/zh/development/comfy-router/models)中的每个模型都由 Comfy Router 直接提供服务。未指定 `model_provider` 的调用走的就是这条路径，对于下方未列出的所有模型，这也是唯一的路由。

## fal

- [Dreamina Seedance 2.0 260128](/zh/development/comfy-router/models/byteplus/dreamina-seedance-2-0-260128/code)：`byteplus/dreamina-seedance-2-0-260128`，使用 `?model_provider=fal` 时以 `fal/fal-seedance-2.0` 提供服务
- [Dreamina Seedance 2.5 260628](/zh/development/comfy-router/models/byteplus/dreamina-seedance-2-5-260628/code)：`byteplus/dreamina-seedance-2-5-260628`，使用 `?model_provider=fal` 时以 `fal/fal-seedance-2.5` 提供服务

## WaveSpeed

- [Nano Banana Pro](/zh/development/comfy-router/models/google/nano-banana-pro/code)：`vertexai/gemini-3-pro-image`，使用 `?model_provider=wavespeed` 时以 `wavespeed/wavespeed-nano-banana-pro` 提供服务

`strict_mode` 默认为 false，因此按原生模型的 schema 编写的请求会被转换为替代提供商自身的 schema，响应也会被转换回来。任何无法在该提供商上表达的原生字段都会被丢弃，并在 `X-Comfy-Router-Dropped-Params` 响应头中列出。
