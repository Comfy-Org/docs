ComfyUI 是一个模块化的 GenAI 推理引擎，可以作为服务器运行、通过 API 访问、用自定义节点扩展，也能通过命令行管理。大多数 API 相关工作分为两步：先让 ComfyUI 在某处运行起来，然后从你的应用程序对它运行工作流。
