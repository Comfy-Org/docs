用于无界面运行 ComfyUI 的公开 API 历经多次演进。对于新的集成，请使用 [Comfy API v2](/zh/api-reference/v2/overview)。它已在开源版 ComfyUI（测试版期间，需通过 [API 代理](/zh/development/comfyui-server/api-proxy)）、Comfy Cloud 以及[开发者平台上的 Comfy API 部署](/zh/development/serverless/overview)中得到支持。更早的版本包括 [v1 Cloud API](/zh/development/cloud/overview)，该版本已弃用。
