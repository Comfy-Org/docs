用于以无头模式运行 ComfyUI 的公共 API 随着时间推移不断演进。对于新的集成，请使用 [Comfy API v2](/zh/api-reference/v2/overview)。它支持开源 ComfyUI（测试版期间，可通过 [API 代理](/zh/development/comfyui-server/api-proxy)）、Comfy Cloud 以及新的 [Serverless API](/zh/development/serverless/overview)。旧版本包括 [v1 Cloud API](/zh/development/cloud/overview)，该版本已弃用。
