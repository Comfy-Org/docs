# Comfy Cloud API

Comfy Cloud API 提供以编程方式访问 Comfy Cloud 的能力，可在云端基础设施上运行工作流。该 API 与本地 ComfyUI 的 API 兼容，便于迁移现有集成。

如果你使用 Python 或 TypeScript 进行开发，请使用 [Comfy SDKs](/zh/development/api-development/sdks)。它们封装了此 API，是运行工作流的最快捷方式。本页介绍 Comfy Cloud 特有的内容：你的 API 密钥、积分和并发限制。其余内容请参阅 [Cloud API 参考](/zh/development/cloud/api-reference)。

<Note>
  **需要订阅：** API 访问权限在 **Standard**、**Creator** 和 **Pro** 等级提供。Free 等级不包含 API 访问权限。详情请参阅[定价方案](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)。
</Note>

## 积分与用量

API 请求消耗的是与 Comfy Cloud 网页端相同的每月积分配额，不存在单独的 API 积分池。每个等级的包含积分、加购选项以及单次工作流运行时长上限对 API 任务和网页端任务完全相同。Standard、Creator 和 Pro 等级的每月积分数量请参阅[定价方案](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)。如果月中积分已用完，可在账户仪表盘中购买加购包。

## 基础 URL

```
https://cloud.comfy.org
```

这也是 SDK 的默认目标，因此你无需为 Comfy Cloud 进行配置。若要将相同的代码指向无服务器部署或你自己的 ComfyUI，请设置 `COMFY_BASE_URL`。请参阅[选择基础 URL](/zh/development/api-development/sdks#choosing-a-base-url)。

## 身份验证

所有 API 请求都需要 API 密钥。直接使用 HTTP 请求时，您可以在 `X-API-Key` 请求头中传递它。使用 SDK 时，您只需将其交给客户端一次，客户端便会自动为每个请求完成身份验证。

### 获取 API 密钥

请参阅[获取 API 密钥](/zh/development/api-development/getting-an-api-key)了解如何创建和管理您的 Cloud API 密钥。

### 使用 API 密钥

<CodeGroup>
```bash curl
curl -X GET "https://cloud.comfy.org/api/user" \
  -H "X-API-Key: $COMFY_CLOUD_API_KEY"
```

```python Python
import os
from comfy_sdk import Comfy

client = Comfy(api_key=os.environ["COMFY_CLOUD_API_KEY"])
```

```typescript TypeScript
import { Comfy } from "@comfyorg/sdk";

const client = new Comfy({ apiKey: process.env.COMFY_CLOUD_API_KEY! });
```
</CodeGroup>

无效或缺失的密钥会返回 `401`，SDK 会将其作为 `Unauthorized` 抛出。处于非活跃订阅状态的密钥会返回 `429`。

同一个密钥也用于[合作节点](/zh/tutorials/partner-nodes/overview)。通过 HTTP 请求时，您需要在 `extra_data.api_key_comfy_org` 中再次传递它。当您向 `submit()` 传递 `api_key` 时，SDK 会为您完成此操作。

## 运行工作流

工作流以 [API 格式](/zh/development/api-development/workflow-api-format) 提交，即 ComfyUI 前端“导出工作流 (API)”选项生成的 JSON。您提交工作流后，任务将异步执行，完成后即可下载输出。

如需从其他语言直接调用 HTTP 端点，或使用以下功能，请参阅 [云端 API 参考](/zh/development/cloud/api-reference)。它介绍了提交、轮询、WebSocket 协议以及输出下载，并附有 curl、Python 和 TypeScript 示例。

### 并行执行（并发任务）

API 用户可同时提交多个工作流，无需等待上一个任务完成。任务一经接受，提交即返回，因此您可以同时保持多个任务在运行。调度程序将并行运行这些任务，最高可达您订阅套餐的并发限制。

| 订阅套餐 | 并发任务 |
|-------------------|-----------------|
| Standard          | 1               |
| Creator           | 3               |
| Pro               | 5               |

超出并发限制提交的任务将正常排队，并在有空闲槽位时自动执行。如果队列本身已满，SDK 会在有限的预算内为您自动重试，之后才抛出 `QueueFull`。

<Info>
  并行执行目前仅可通过 API 使用。订阅详情请参阅[定价方案](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)。
</Info>

## SDK 尚未覆盖的功能

SDK 只做一件事：运行工作流并取回结果。云端的其余功能仅能通过 HTTP 访问，因此即使你使用 SDK 来执行，也需要直接调用这些端点。

| 功能 | 端点 | 参考 |
|---|---|---|
| 队列状态、运行中及待定任务 | `GET /api/queue` | [队列管理](/zh/development/cloud/api-reference#queue-management) |
| 中断当前执行 | `POST /api/interrupt` | [队列管理](/zh/development/cloud/api-reference#queue-management) |
| 节点定义和输入规格 | `GET /api/object_info` | [对象信息](/zh/development/cloud/api-reference#object-info) |
| 浏览可用模型 | 模型端点 | [云端 API 参考](/zh/development/cloud/api-reference) |
| 账户和用户信息 | `GET /api/user` | [云端 API 参考](/zh/development/cloud/api-reference) |
| 引用现有图像的遮罩上传 | `POST /api/upload/mask` | [上传输入](/zh/development/cloud/api-reference#uploading-inputs) |

取消任务可通过两种方式完成：SDK 可取消你持有句柄的任务，`POST /api/queue` 则按 ID 取消。

## 错误处理

REST 端点返回标准 HTTP 状态码：

| 状态 | 描述 |
|--------|-------------|
| `400` | 无效请求（工作流错误、字段缺失） |
| `401` | 未授权（API 密钥无效或缺失） |
| `402` | 积分不足 |
| `429` | 订阅未激活 |
| `500` | 内部服务器错误 |

SDK 则会以类型化异常的形式抛出这些错误，包括 `Unauthorized`、`InvalidWorkflow`、`InsufficientCredits`、`QueueFull` 和 `JobFailed`，它们都继承自 `ComfyError`。

执行失败与 HTTP 错误相互独立。有关执行期间返回的 `exception_type` 值，请参阅[错误处理](/zh/development/cloud/api-reference#error-handling)。
