底部面板是画布下方的停靠工作区条带。每个构建都有快捷键参考标签；自托管与 Desktop 构建有 **Logs** 流；**Terminal** 仅在 Desktop 应用中注册。Comfy Cloud 不注册终端类标签；Shortcuts 仍可用。


![底部面板的 Shortcuts 标签，显示 Essentials 列表](/images/interface/bottom-panel/bottom_panel_shortcuts.png)

![自托管安装下，Logs 标签实时显示 ComfyUI 进程的运行日志](/images/interface/bottom-panel/bottom_panel_logs.png)

## 打开面板

可通过多种方式打开底部面板：

- **Shortcuts**：点击左侧边栏底部附近的键盘图标（`Workspace.ToggleBottomPanel.Shortcuts`，默认 `Ctrl` + `Shift` + `K`）。这会专门切换快捷键面板。
- **Console / 终端面板**（非 Cloud）：点击左侧边栏底部附近的终端图标。执行 **Toggle Bottom Panel**：在已加载 Logs/Terminal 时优先打开终端面板，否则回退到 Shortcuts。
- **View** 菜单：**Bottom Panel**（`Workspace.ToggleBottomPanel`）。
- **Logs 快捷键**（非 Cloud）：默认 `Ctrl` + `` ` `` 切换 Logs 标签（`Workspace.ToggleBottomPanelTab.logs-terminal`）。

[Focus Mode](/zh/interface/canvas-controls) 开启时面板会隐藏。

## Shortcuts 标签

Shortcuts 在 **shortcuts** 面板上注册两个标签：

- **Essentials**：常用编辑与队列快捷键。
- **View Controls**：导航与视图相关快捷键。

这些面板与 Settings → Keybinding 中可自定义的同一套命令/快捷键数据对应。完整可编辑列表见 [快捷键](/zh/interface/shortcuts)。

## Logs（自托管与 Desktop）

在非 Cloud 构建上，**Logs** 标签会流式显示 ComfyUI 进程的运行时日志。调试自定义节点、服务器错误或后端消息时，无需切换到外部终端。

默认快捷键：`Ctrl` + `` ` ``。

## Terminal（仅 Desktop）

在 **Desktop** 应用中，**Terminal**（命令终端）标签注册在 Logs 旁，为 Desktop 用户提供应用内 shell。纯浏览器自托管会话与 Comfy Cloud 不注册该标签。

Cloud 构建完全跳过 Logs 与 Terminal 的注册；仅保留 Shortcuts。
