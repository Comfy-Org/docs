底部面板是画布下方的停靠工作区条带。它在所有构建上提供键盘快捷键参考标签页，在自托管与 Desktop 构建上提供 **日志** 流，并且仅在 Desktop 应用上提供 **终端**。Comfy Cloud 不注册终端标签页；快捷键功能仍可正常使用。


![底部面板在快捷键标签页中打开，显示基础列表](/images/interface/bottom-panel/bottom_panel_shortcuts.png)

![自托管安装中，日志标签页实时流式显示 ComfyUI 进程的运行时输出](/images/interface/bottom-panel/bottom_panel_logs.png)

## 打开面板

可通过多种方式打开底部面板：

- **快捷键**：点击左侧边栏底部附近的键盘图标（`Workspace.ToggleBottomPanel.Shortcuts`，默认 `Ctrl` + `Shift` + `K`）。这会专门切换快捷键面板。
- **控制台 / 终端面板**（非 Cloud）：点击左侧边栏底部附近的终端图标。这会执行 **切换底部面板**，当已加载日志/终端标签页时优先打开终端面板，否则回退到快捷键。
- **视图**菜单：**底部面板**（`Workspace.ToggleBottomPanel`）。
- **日志快捷键**（非 Cloud）：默认 `Ctrl` + `` ` `` 切换日志标签页（`Workspace.ToggleBottomPanelTab.logs-terminal`）。

开启[专注模式](/zh/interface/canvas-controls)时，面板会隐藏。

## 快捷键标签页

快捷键功能在 **shortcuts** 面板上注册两个标签页：

- **基础**：常用编辑与队列快捷键。
- **视图控制**：导航与视图相关快捷键。

这些面板与可在设置 → 按键绑定中自定义的同一套指令/按键绑定数据一致。完整可编辑列表见[快捷键](/zh/interface/shortcuts)。

## 日志（自托管与 Desktop）

在非 Cloud 构建上，**日志**标签页会流式显示 ComfyUI 进程的运行时日志输出。调试自定义节点、服务器错误或后端消息时，无需切换到外部终端即可使用。

默认快捷键：`Ctrl` + `` ` ``。

## 终端（仅 Desktop）

在 **Desktop** 应用中，**终端**（命令终端）标签页注册在日志旁，为 Desktop 用户提供应用内 shell。纯浏览器自托管会话与 Comfy Cloud 不会注册该标签页。

![Desktop 上的终端标签页，在日志旁显示应用内 shell](/images/interface/bottom-panel/bottom_panel_terminal.png)

Cloud 构建会完全跳过日志与终端的注册；仅保留快捷键。
