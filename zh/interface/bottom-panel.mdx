底部面板是画布下方的停靠工作区条带。每个构建都提供快捷键参考标签，自托管与 Desktop 构建还提供 **Logs** 日志流，而 **Terminal** 仅在 Desktop 应用中注册。Comfy Cloud 不注册终端类标签，Shortcuts 仍然可用。


![打开到底部面板 Shortcuts 标签的界面，显示 Essentials 列表](/images/interface/bottom-panel/bottom_panel_shortcuts.png)

![自托管安装下，Logs 标签实时显示 ComfyUI 进程的运行输出](/images/interface/bottom-panel/bottom_panel_logs.png)

## 打开面板

可以通过多种方式打开底部面板：

- **Shortcuts**：点击左侧边栏底部附近的键盘图标（`Workspace.ToggleBottomPanel.Shortcuts`，默认 `Ctrl` + `Shift` + `K`）。该操作专门切换快捷键面板。
- **Console / 终端面板**（非 Cloud）：点击左侧边栏底部附近的终端图标。该操作执行 **Toggle Bottom Panel** 指令：在已加载 Logs/Terminal 标签时优先打开终端面板，否则回退到 Shortcuts。
- **View** 菜单：**Bottom Panel**（`Workspace.ToggleBottomPanel`）。
- **Logs 快捷键**（非 Cloud）：默认 `Ctrl` + `` ` `` 切换 Logs 标签（`Workspace.ToggleBottomPanelTab.logs-terminal`）。

专注模式开启时，面板会隐藏，详见[画布控件](/zh/interface/canvas-controls)。

## Shortcuts 标签

Shortcuts 在 **shortcuts** 面板上注册两个标签：

- **Essentials**：常用编辑与队列快捷键。
- **View Controls**：导航与视图相关快捷键。

这些面板与设置 → 按键绑定中可自定义的是同一套指令/按键绑定数据。完整可编辑列表见[快捷键](/zh/interface/shortcuts)。

## Logs（自托管与 Desktop）

在非 Cloud 构建上，**Logs** 标签会流式显示 ComfyUI 进程的运行时日志。调试自定义节点、服务器错误或后端消息时，无需切换到外部终端。

默认快捷键：`Ctrl` + `` ` ``。

## Terminal（仅 Desktop）

在 **Desktop** 应用中，**Terminal**（指令终端）标签注册在 Logs 旁，为 Desktop 用户提供应用内 shell。纯浏览器自托管会话与 Comfy Cloud 均不注册该标签。

![Desktop 上的 Terminal 标签，在 Logs 旁显示应用内 shell](/images/interface/bottom-panel/bottom_panel_terminal.png)

Cloud 构建完全跳过 Logs 与 Terminal 的注册，仅保留 Shortcuts。
