底部面板是画布下方的停靠式工作区条带。它在所有构建上都提供快捷键参考标签，在自托管与 Desktop 构建上提供 **Logs** 流，并且仅在 Desktop 应用中提供 **Terminal**。Comfy Cloud 不注册终端标签；Shortcuts 仍然可用。


![底部面板打开在 Shortcuts 标签页，显示 Essentials 列表](/images/interface/bottom-panel/bottom_panel_shortcuts.png)

![自托管安装下，Logs 标签页实时显示 ComfyUI 进程的运行日志](/images/interface/bottom-panel/bottom_panel_logs.png)

## 打开面板

你可以通过多种方式打开底部面板：

- **Shortcuts**：点击左侧边栏底部附近的键盘图标（`Workspace.ToggleBottomPanel.Shortcuts`，默认 `Ctrl` + `Shift` + `K`）。该操作专门切换快捷键面板。
- **Console / 终端面板**（非 Cloud）：点击左侧边栏底部附近的终端图标。该操作执行 **Toggle Bottom Panel**，当已加载 Logs/Terminal 标签页时优先打开终端面板，否则回退到 Shortcuts。
- **View** 菜单：**Bottom Panel**（`Workspace.ToggleBottomPanel`）。
- **Logs 快捷键**（非 Cloud）：默认 `Ctrl` + `` ` `` 切换 Logs 标签页（`Workspace.ToggleBottomPanelTab.logs-terminal`）。

开启[专注模式](/zh/interface/canvas-controls)时，该面板会隐藏。

## Shortcuts 标签

Shortcuts 会在 **shortcuts** 面板上注册两个标签：

- **Essentials**：常用的编辑与队列快捷键。
- **View Controls**：导航与视图相关的快捷键。

这些面板反映的正是你可以在 Settings → Keybinding 下自定义的同一套指令/按键绑定数据。完整可编辑列表见[快捷键](/zh/interface/shortcuts)。

## Logs（自托管与 Desktop）

在非 Cloud 构建上，**Logs** 标签页会流式显示 ComfyUI 进程的运行时日志输出。调试自定义节点、服务器错误或后端消息时，无需切换到外部终端。

默认快捷键：`Ctrl` + `` ` ``。

## Terminal（仅 Desktop）

在 **Desktop** 应用中，**Terminal**（命令终端）标签页注册在 Logs 旁边，为 Desktop 用户提供应用内 shell。纯浏览器自托管会话和 Comfy Cloud 都不注册该标签页。

![Desktop 上的 Terminal 标签页，在 Logs 旁显示应用内 shell](/images/interface/bottom-panel/bottom_panel_terminal.png)

Cloud 构建完全跳过 Logs 与 Terminal 的注册；仅保留 Shortcuts。
