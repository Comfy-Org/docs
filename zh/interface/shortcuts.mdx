ComfyUI 自带一套默认快捷键，所有命令都可以重新绑定。打开 **设置（齿轮图标）** > **快捷键** 即可查看和修改。

![ComfyUI 快捷键设置](/images/interface/setting/keybinding.jpg)

## 查找与修改快捷键

面板会列出每个命令及其当前快捷键。顶部搜索框可以缩小范围，点击 **指令** 表头可按字母排序。**来源** 列显示提供该命令的扩展或自定义节点包，来自 ComfyUI 本身的命令这一列为空。

点击某一行的编辑图标即可录制新的按键组合。行菜单可以把该命令重置为默认，或移除它的快捷键。当一个命令有多个快捷键时，该行会展开，每个绑定各有自己的编辑和删除按钮。面板底部的 **重置所有** 会在确认后清除所有自定义。

## 快捷键预设

你的修改属于一个具名预设，面板顶部的预设选择器用于在预设之间切换。**默认预设** 保存内置快捷键；选中它会恢复这些快捷键，并丢弃当前会话中尚未保存的修改，之前保存过的预设不受影响。

- 预设存在未保存的修改时，名称后会显示 `*`。对于已保存的预设，点击 **保存更改** 即可写入。默认预设没有保存更改按钮，它的修改通过 **另存为新预设** 保存。
- 预设选择器旁边的 ...（更多）按钮里有 **另存为新预设**（默认预设没有修改时隐藏）、**重置为默认**、**删除预设**（默认预设不可用）、**导入预设** 和 **导出预设**。
- **导入预设** 读取由 ComfyUI 导出的预设文件，因此一套快捷键可以在不同安装之间迁移，或交给其他用户。**导出预设** 会把当前预设写成 JSON 文件。
- 存在未保存修改时切换预设，会先询问是否保存，或丢弃修改继续。

预设以 JSON 文件的形式存放在 ComfyUI 用户目录下的 `keybindings/` 中。
