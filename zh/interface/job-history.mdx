**Job History** 是左侧边栏标签，仅在设置 `Comfy.Queue.QPOV2` 开启时出现。前端会把它注册到侧栏顶部（`prepend`），便于查看进行中任务与历史运行，而不必另开队列弹层。

关闭该设置后标签会移除。顶栏的 Run / 队列控件仍可启动任务；本页只写侧栏历史表面。

## 后续可补充

- 进行中 / 完成 / 失败行
- 侧栏图标上的徽章计数
- 取消、清空、重新入队（若有）
- 与资产面板（某次运行的输出）的关系
- 与旧版队列按钮 UI 的差异
