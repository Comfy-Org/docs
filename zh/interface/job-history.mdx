**Job History（任务历史）** 是左侧边栏标签，在启用 **Docked job history/queue panel**（`Comfy.Queue.QPOV2`）时出现。前端将其注册在侧栏**顶部**（`prepend`），便于在不使用浮动队列浮层的情况下查看活动任务与过往运行。

关闭该设置时，标签会移除，改为使用浮动任务历史浮层（`Comfy.Queue.ToggleOverlay`）。无论哪种方式，顶部的运行 / 队列控件仍可启动任务。本页介绍的是**侧栏**任务历史界面。

![未打开 Job History 标签时，图标上显示的活跃任务数量徽章](/images/interface/job-history/job_history_badge.png)

## 开启任务历史

1. 打开 **Settings**。
2. 在 `Comfy` → `Queue` → `Layout` 下启用 **Docked job history/queue panel**（`Comfy.Queue.QPOV2`）。
3. 左侧边栏顶部会出现 **Job History** 图标。

该设置为实验性。Nightly 构建默认开启；其他构建若看不到该标签，请检查设置。

## 打开面板

点击 **Job History** 图标。当有任务正在运行或排队，且此标签**未**处于活动状态时，图标会显示活动任务数量徽章。打开该标签后，该视图不再显示徽章。

## 标签：All、Completed、Failed

面板标题区有状态标签：

- **All**：当前筛选下的全部任务。
- **Completed**：已完成的运行。
- **Failed**：仅当列表中至少有一个失败任务时出现。

标签下方有摘要行，显示正在运行与排队的任务数量（或提示没有活动任务）。**Clear queue** 控件会取消所有待处理（已排队但尚未运行）的任务。

## 搜索、筛选与排序

使用标题区工具缩小列表：

- **搜索**：按文本过滤任务。
- **筛选**：**All workflows** 或 **Current workflow**。
- **排序**：**Most recent** 或 **Total generation time**。

## 任务列表与操作

任务列表显示状态、运行中进度，以及有输出时的预览缩略图。在任务行或其右键菜单中可以：

**运行中或排队中**

- 在新标签中作为工作流打开
- 复制任务 ID
- 取消任务

**已完成**

- 检查资产（存在预览时）
- 将输出作为加载节点加入当前工作流
- 下载预览资产
- 在新标签中作为工作流打开
- 导出工作流
- 复制任务 ID

**失败**

- 在新标签中打开工作流
- 复制任务 ID
- 复制错误信息
- 报告错误
- 从历史列表中移除任务

标题栏操作菜单包含 **Clear history**，会打开确认对话框。清除历史会移除队列历史条目；请阅读对话框中关于与已存储资产关系的说明。

## 与资产、错误的关系

已完成运行的输出在启用资产系统时也会出现在 [资产](/zh/interface/assets) 中。工作流失败与缺失资源会列在 [右侧面板](/zh/interface/right-side-panel) 的 **Errors** 标签中，便于修复图。
