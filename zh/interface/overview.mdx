可视化界面是大多数人驱动 [ComfyUI Server](/zh/development/comfyui-server/comms_overview) 的方式。本页是界面地图，各区域与组件的详细说明见下方链接。

![ComfyUI Basic Interface](/images/interface/overview/comfyui_new_interface.jpg)

[ComfyUI 前端](https://github.com/Comfy-Org/ComfyUI_frontend) 是独立维护的项目。

## 本地化

ComfyUI 支持英语、中文、俄语、法语、日语和韩语。打开 **设置**，在 `Comfy` → `Locale` 选择语言。

![ComfyUI Localization Support](/images/interface/overview/locale.jpg)

## 工作区地图

![ComfyUI Workspace](/images/interface/overview/comfyui-new-interface-main.png)

| 区域 | 说明 |
| --- | --- |
| **左侧边栏** | 资产、节点库、模型库、工作流、Apps，以及（开启时）Job History |
| **画布** | 放置与连接节点的图，以及画布控制 |
| **右侧面板** | 当前选中项的参数、节点信息、设置与报错 |
| **顶栏** | 打开的工作流、Run / 队列、登录、属性面板开关 |
| **左下** | Help Center、底栏（日志 / 快捷键）、设置 |
| **右下** | 画布控制：平移、小地图、连线显示、缩放、适应视图 |

## 旧版菜单

默认启用新菜单。若要用旧菜单，在设置中将 `Comfy` → `Menu` → `Use new menu` 设为 `disabled`。

<Note>
旧版菜单仅支持英语。
</Note>
