左侧边栏的 **Nodes（节点）** 入口会打开节点库。你可以在这里查找当前 ComfyUI 实例中的全部节点：Comfy Core、Partner Nodes，以及已安装的自定义节点。面板支持搜索。

![节点库的 All nodes 标签，顶部是 BOOKMARKED 收藏区](/images/interface/overview/node_library_bookmarked.png)

![ComfyUI 节点库面板，当前为 Essentials 标签页，显示输入与输出磁贴](/images/interface/overview/node_library_essentials.png)

当 **Essentials** 标签页可用时，面板包含两个标签页：

- **Essentials（精选）**：按用途分组的常用节点网格，覆盖大多数工作流需要用到的节点。分组包括：输入与输出、生成（图像、视频、文本、音频、3D）、控制与引导（图像），以及编辑与工具（图像变换、图像工具、图像滤镜与特效、图像颜色、图像选区与遮罩、视频变换、视频合成、视频选区与遮罩、3D 变换）。将鼠标悬停在磁贴上可以预览节点，把磁贴拖到画布上即可将其加入工作流。使用筛选按钮可以只显示你需要的媒体类型，使用列表按钮可以直接跳转到指定分组。
- **All nodes（全部节点）**：完整的节点列表。可以按 Comfy 节点、合作节点、扩展、蓝图进行筛选，并在默认的分类排序和 A-Z 排序之间切换。

在 **All nodes** 中点击节点上的书签图标，即可将其加入列表顶部的 **Bookmarked（已加书签）** 分组。

![ComfyUI 节点库面板的 All nodes 标签页，显示已加书签、Comfy 节点、合作节点与扩展分组](/images/interface/overview/node_library_all_nodes.png)

**Essentials** 标签页需要 ComfyUI 后端启用后才会显示，Comfy Cloud 和 nightly 版本均已启用。自托管的稳定版仅显示 **All nodes**。如果你想回到之前的面板，可以在 `设置(Settings)` --> `Comfy` --> `Node Library` 中关闭 `全新节点库设计(New Node Library Design)`。
