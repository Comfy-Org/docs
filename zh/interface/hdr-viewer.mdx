HDR 查看器可以显示浏览器无法在节点预览中绘制的 EXR 和 HDR 文件。它以占满整个窗口的对话框形式打开，图像位于左侧，显示和检查控件位于右侧，因此你可以在把浮点图像发送到其他应用程序之前，先看清它实际包含的内容。

## 打开 HDR 查看器

运行一个会写出浮点图像的工作流，例如将 [Save Image (Advanced)](/zh/built-in-nodes/SaveImageAdvanced) 的 **format** 设置为 `exr`。`.exr` 或 `.hdr` 文件的输出预览会以一个太阳图标和 **HDR 图像**代替画面。点击预览即可在 HDR 查看器中打开该文件。对话框标题就是输出文件名，并且对话框可以最大化。

## 显示控件

这些控件改变的是文件的显示方式，而不是文件本身。

| 控件 | 作用 |
| --- | --- |
| **曝光** | 以 0.1 档为步进，将显示的亮度在 -10 到 +10 档之间偏移。较低的值可以把高于显示白色的高光重新拉回可见范围。 |
| **自动曝光** | 设置曝光，使图像中最亮的像素正好落在显示白色上。 |
| **通道** | 显示 RGB，或一次只显示一个通道：R、G、B、A 或亮度。 |
| **源色域** | sRGB 或 Rec.2020。打开文件时会从 EXR 的 chromaticities 标签中检测；当文件没有该标签或标签有误时，可手动切换。 |
| **抖动** | 默认开启。减轻平滑渐变在 8 位显示器上出现的色带。 |
| **剪切警告** | 默认关闭。用不同的图案分别为高于显示白色的像素和低于黑色的像素绘制阴影线，让你看到当前曝光所掩盖的内容。 |

## 检查图像

侧边栏还会报告文件所包含的内容，与显示设置无关：

- **像素值**：将鼠标悬停在图像上，即可在左上角读取光标处的坐标和原始 RGBA 值。
- **直方图**：已选择通道的分布。
- **统计信息**：分辨率、最小值、最大值、平均值和标准差，当文件中存在 NaN 和 Inf 时还会给出它们的计数。
- **导航**：滚动缩放，拖动平移，点击 **Fit** 使图像适配画面。
- **下载图片**会保存原始文件。
