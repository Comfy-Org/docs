**Apps（应用）** 入口注册在 Assets、Node Library、Model Library 与 Workflows 之后。它列出打包的工作流应用：文件后缀为 `.app.json` 的已保存工作流。标签标题带有 **Beta** 徽章。

此侧栏目录与 [APP 模式](/zh/interface/app-mode) 不同。APP 模式是面向工作流的线性简化运行界面；应用侧栏用于查找并打开打包应用、创建空白工作流以开始新应用，并以与普通工作流相同的方式管理这些 `.app.json` 文件。

## 打开应用面板

点击左侧边栏的 **Apps** 图标。面板布局与 [工作流](/zh/interface/workflows) 相同：搜索、可选的 **Open** 分区（当已打开工作流设为 Sidebar 时）、**Bookmarks** 与 **Browse**，但每个列表都只过滤 `.app.json` 文件。

## 空状态与创建

尚未保存任何应用时，Browse 区域显示空状态与简短说明，以及 **Create app** 按钮。Browse 有结果时，面板标题栏还会出现 **Create**。两者都执行 **New Blank Workflow**（`Comfy.NewBlankWorkflow`），打开空白图供你配置 APP 模式并保存为应用。

## 操作应用

对过滤后的列表，操作与工作流面板一致：

- 点击应用以打开。
- 与普通工作流一样可收藏、重命名、删除、复制与拖拽。
- 右键菜单中 **Duplicate** 始终可用；在非 App Mode 下提供 **Insert**。

要在简化的线性界面中运行应用，请打开它并进入 APP 模式。构建输入输出、预览布局以及在图编辑与应用视图之间切换，见 [APP 模式](/zh/interface/app-mode)。

## 与工作流、模板的关系

| 界面 | 列出内容 |
| --- | --- |
| [工作流](/zh/interface/workflows) | 普通已保存图（及打开标签），通常为 `.json` |
| **应用**（本页） | 后缀为 `.app.json` 的打包应用 |
| [模板](/zh/interface/features/template) | 来自 **Browse Templates** 的官方与社区入门图，不是本地应用库 |
