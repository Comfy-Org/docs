积分用于运行 **Partner Nodes**（调用闭源模型 API）。本地构图与开源节点仍然完全免费；只有 Partner Nodes 与 Cloud 计费相关能力会消耗积分。

在 **设置 → 用户** 登录后，打开 **设置 → 工作区 → 计划与积分**。在 Comfy Cloud 也可从个人资料菜单的 **Manage plan / 管理订阅** 进入同一面板。

部分 Cloud 工作区会把同样的套餐与积分信息放在 **Billing** 面板里，而不是「计划与积分」。它同样位于 **设置 → 工作区** 分组下，并多出自动充值设置，见 [Billing 面板与自动充值](#billing-面板与自动充值)。

![ComfyUI 计划与积分](/images/interface/setting/plan-credits-cloud-overview.jpg)

<Note>
ComfyUI 对本地用户将始终保持完全开源且免费。截图中的积分余额为示意数据。
</Note>

## 「计划与积分」里有什么

| 选项卡 | 内容 |
| --- | --- |
| **积分 / Credits** | 余额、充值与订阅概览（本地嵌入积分面板；Cloud 显示工作区订阅视图） |
| **活动 / Activity** | 积分消耗与使用历史 |
| **发票 / Invoices** | 仅 Cloud，且需具备工作区订阅管理权限：下一笔发票与 Stripe 历史 |

## 如何购买积分

<Steps>

<Step title="登录你的 ComfyUI 账号">
打开 **设置 → 用户** 并登录。
![登录界面](/images/zh/interface/setting/user.jpg)
</Step>

<Step title="打开计划与积分">
登录后，打开 **设置 → 工作区 → 计划与积分**（或云端档案 → **管理订阅**）。
![计划与积分](/images/interface/setting/plan-credits-cloud-overview.jpg)
</Step>

<Step title="设置要购买的积分数量">
![设置购买数量](/images/zh/interface/setting/buy.jpg)
在弹窗中设置购买数量，然后点击 **购买**。
</Step>

<Step title="确认并完成支付">
![确认购买](/images/zh/interface/setting/purchase-1.jpg)
核对支付金额和积分数量后，继续前往 Stripe 结账页完成支付。请使用与你的 ComfyUI 账号相同的电子邮件。
</Step>

<Step title="确认你的余额">
![购买后的计划与积分](/images/zh/interface/setting/purchase-2.jpg)
返回 **计划与积分**，确认余额已更新。如有需要，请刷新或重新启动。
</Step>

</Steps>

在显示 **Billing** 面板的工作区里，从 **设置 → 工作区 → Billing** 进入，点击 **Add credits**，在积分卡片上确认新余额。其余流程相同。

## Billing 面板与自动充值

在使用 **Billing** 面板的工作区里，**设置 → 工作区 → Billing** 把套餐、积分余额和自动充值放在同一个面板。所有者可在这里改套餐、充值积分；成员看到同样的余额，并能进入自己的用量页。

### 套餐与积分

套餐一行显示当前套餐、计费周期和下次账单日期。已排期的套餐变更会显示生效日期，可用 **Stay on** 按钮取消该变更；已取消的订阅会显示结束日期，可用 **Resume plan** 恢复续订。

积分卡片顶部是 **Available**，即工作区当前可花的积分。若运行超额，卡片会注明超出多少积分。工作区有生效中的套餐时，余额分为两部分：

- **Plan**：本计费周期内尚未用完的套餐额度
- **Top-up**：你自行添加的积分，在套餐额度用完后被消耗。正在消耗充值积分时会显示 **In use now**

**Add credits** 打开充值流程。所有者还会看到一个按钮，直达托管计费页，管理支付方式、发票与用量。

### 自动充值

自动充值会在余额低于阈值时自动补充，避免长任务因余额不足中断。它从工作区默认支付方式扣款，因此需要先绑定支付方式。扣款失败或达到月度上限时，补充会暂停，直到你处理。

开启后，卡片显示充值规则，例如补充多少金额与积分、余额低到多少时触发，并显示月度上限中自动扣款已用掉多少。只有自动扣款计入该上限，计数每个计费周期重置一次。

卡片上的按钮都会在新标签页打开计费页进行调整。工作区支持自动充值时，卡片只对所有者显示。

| 状态 | 含义 |
| --- | --- |
| **On** | 自动充值生效中。**Manage** 打开计费页，可改金额、阈值或月度上限。 |
| **Off** | 自动充值未开启。**Turn on** 打开计费页进行设置。 |
| **On hold** | 没有默认支付方式，无法扣款。**Update payment** 打开计费页添加卡。 |
| **Paused** | 自动扣款达到月度上限。卡片显示的下个周期开始时恢复；在计费页提高上限可提前恢复。 |
| **Failed** | 上次自动扣款未成功。**Update payment** 打开计费页处理，或手动充值。 |

## 常见问题

<AccordionGroup>
  <Accordion title="积分会变成负数吗？">
    积分不是授信额度。Partner Nodes 有时在执行后才上报费用，单次运行可能暂时把余额打成负数。余额为负时无法再跑 Partner Nodes，需充值恢复正余额。
  </Accordion>

  <Accordion title="未使用的积分可以退款吗？">
  目前不支持未使用积分退款。
  </Accordion>

  <Accordion title="如何查看余额与用量？">
  打开 **设置 → 工作区 → 计划与积分**。在 **积分** 选项卡看余额，在 **活动** 选项卡看使用历史。在显示 **Billing** 面板的工作区里，余额在积分卡片上，点 **View usage** 查看使用历史。
  </Accordion>

  <Accordion title="可以和其他用户共享积分吗？">
  可以在多台设备登录同一账号。不支持把积分分享给其他用户账号。Cloud Team 工作区成员共用一个工作区余额，只有工作区所有者可以充值或更改套餐。
  </Accordion>

  <Accordion title="如何知道节点大概要花多少？">
  运行前查看 API / Partner Node 上的价格徽章。实际费用会随尺寸、生成数量等参数变化。
  </Accordion>

  <Accordion title="为什么看不到微信或支付宝？">
  请选择以 Comfy Credits 支付；微信与支付宝仅在该路径下提供。
  </Accordion>

  <Accordion title="购买积分会附带 Cloud 订阅吗？">
  不会。购买积分不会开通订阅，也不会解锁 Cloud 工作流：在 Cloud 上运行工作流需要有效订阅。本地 ComfyUI 和桌面版中的合作节点无需订阅即可使用积分。
  </Accordion>

  <Accordion title="积分会过期吗？">
  会，取决于类型：
  - **月度积分**：在计费周期结束时过期
  - **充值积分**：自购买日起 1 年后过期
  </Accordion>
</AccordionGroup>
