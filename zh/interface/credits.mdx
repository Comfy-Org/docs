积分用于运行 **Partner Nodes**（调用闭源模型 API）。本地构图与开源节点仍然完全免费；只有 Partner Nodes 与 Cloud 计费相关能力会消耗积分。

在 **设置 → 用户** 登录后，打开 **设置 → 工作区 → 计划与积分**。在 Comfy Cloud 也可从个人资料菜单的 **Manage plan / 管理订阅** 进入同一面板。

![ComfyUI 计划与积分](/images/interface/setting/plan-credits-cloud-overview.jpg)

<Note>
ComfyUI 对本地用户将始终保持完全开源且免费。截图中的积分余额为示意数据。
</Note>

## 「计划与积分」里有什么

| 选项卡 | 内容 |
| --- | --- |
| **积分 / Credits** | 余额、充值与订阅概览（本地嵌入积分面板；Cloud 显示工作区订阅视图） |
| **活动 / Activity** | 积分消耗与使用历史 |
| **发票 / Invoices** | 仅 Cloud，且需具备工作区订阅管理权限 — 下一笔发票与 Stripe 历史 |

登录后在本地也会出现 **工作区 → 计划与积分**（无 Members / Invoices）：

![计划与积分（本地）](/images/interface/setting/plan-credits-local-overview.jpg)

![活动选项卡](/images/interface/setting/plan-credits-cloud-activity.jpg)

![发票选项卡（Cloud）](/images/interface/setting/plan-credits-cloud-invoices.jpg)

## 如何购买积分

<Steps>

<Step title="登录你的 ComfyUI 账号">
打开 **设置 → 用户** 并登录。
![登录界面](/images/zh/interface/setting/user.jpg)
</Step>

<Step title="打开计划与积分">
登录后，打开 **设置 → 工作区 → 计划与积分**（或云端档案 → **管理订阅**）。
![计划与积分](/images/interface/setting/plan-credits-cloud-overview.jpg)
</Step>

<Step title="设置要购买的积分数量">
![设置购买数量](/images/zh/interface/setting/buy.jpg)
在弹窗中设置购买数量，然后点击 **购买**。
</Step>

<Step title="确认并完成支付">
![确认购买](/images/zh/interface/setting/purchase-1.jpg)
核对支付金额和积分数量后，继续前往 Stripe 结账页完成支付。请使用与你的 ComfyUI 账号相同的电子邮件。
</Step>

<Step title="确认你的余额">
![购买后的计划与积分](/images/zh/interface/setting/purchase-2.jpg)
返回 **计划与积分**，确认余额已更新。如有需要，请刷新或重新启动。
</Step>

</Steps>

## 常见问题

<AccordionGroup>
  <Accordion title="积分会变成负数吗？">
    积分不是授信额度。Partner Nodes 有时在执行后才上报费用，单次运行可能暂时把余额打成负数。余额为负时无法再跑 Partner Nodes，需充值恢复正余额。
  </Accordion>

  <Accordion title="未使用的积分可以退款吗？">
  目前不支持未使用积分退款。
  </Accordion>

  <Accordion title="如何查看余额与用量？">
  打开 **设置 → 工作区 → 计划与积分**。在 **积分** 选项卡看余额，在 **活动** 选项卡看使用历史。
  </Accordion>

  <Accordion title="可以和其他用户共享积分吗？">
  可以在多台设备登录同一账号。不支持把积分分享给其他用户账号。Cloud Team 工作区成员共享工作区余额，并受所有者设置的限额约束。
  </Accordion>

  <Accordion title="如何知道节点大概要花多少？">
  运行前查看 API / Partner Node 上的价格徽章。实际费用会随尺寸、生成数量等参数变化。
  </Accordion>

  <Accordion title="为什么看不到微信或支付宝？">
  请选择以 Comfy Credits 支付；微信与支付宝仅在该路径下提供。
  </Accordion>

  <Accordion title="购买积分会附带 Cloud 订阅吗？">
  不会。购买积分不会开通订阅，也不会解锁 Cloud 工作流：在 Cloud 上运行工作流需要有效订阅。本地 ComfyUI 和桌面版中的合作节点无需订阅即可使用积分。
  </Accordion>

  <Accordion title="积分会过期吗？">
  会，取决于类型：
  - **月度积分**：在计费周期结束时过期
  - **充值积分**：自购买日起 1 年后过期
  </Accordion>
</AccordionGroup>
