**Wan2.2-Fun-Control** 是 Alibaba PAI 团队推出的新一代视频生成与控制模型，通过引入创新性的控制代码（Control Codes）机制，结合深度学习和多模态条件输入，能够生成高质量且符合预设控制条件的视频。该模型采用 **Apache 2.0 许可协议**发布，支持商业使用。

**核心功能**：
- **多模态控制**：支持多种控制条件，包括 **Canny（线稿）**、**Depth（深度）**、**OpenPose（人体姿势）**、**MLSD（几何边缘）** 等，同时支持使用 **轨迹控制**
- **高质量视频生成**：基于 Wan2.2 架构，输出影视级质量视频
- **多语言支持**：支持中英文等多语言提示词输入

## Wan2.2 Fun Control 视频生成工作流示例

<UpdateReminder/>

此工作流提供两个版本：
1. 使用来自 lightx2v 的 [Wan2.2-Lightning](https://huggingface.co/lightx2v/Wan2.2-Lightning) 4步 LoRA 的版本：可能会导致视频动态性有所损失，但速度更快
2. 无加速 LoRA 的 fp8_scaled 版本

以下是在 RTX4090D 24GB VRAM GPU 上以 640×640 分辨率、81 帧进行测试的结果

| 模型类型           | VRAM 使用 | 首次生成时间 | 第二次生成时间 |
| ---------------- | --------- | ------------ | -------------- |
| fp8_scaled       | 83%       | ≈ 524秒      | ≈ 520秒        |
| fp8_scaled + 4步 LoRA | 89%       | ≈ 138秒      | ≈ 79秒         |

由于使用 4 步 LoRA 为初次使用工作流的用户提供了更好的体验，但可能导致视频动态性有所损失，因此我们默认启用了加速 LoRA 版本。若想启用另一工作流，请选择它并按 **Ctrl+B** 激活。

### 3. 工作流指南

![Wan2.2 Fun Control工作流步骤](/images/tutorial/video/wan/wan2_2/wan_2.2_14b_fun_control.jpg)

<Note>
  该工作流使用LoRA。请确保相应的扩散模型和LoRA匹配：高噪波和低噪波模型与LoRA需要对应使用。
</Note>

1. **高噪波**模型与**LoRA**加载
   - 确保 `UNet加载器` 节点加载了 `wan2.2_fun_control_high_noise_14B_fp8_scaled.safetensors` 模型
   - 确保 `LoraLoaderModelOnly` 节点加载了 `wan2.2_i2v_lightx2v_4steps_lora_v1_high_noise.safetensors`
2. **低噪波**模型与**LoRA**加载
   - 确保 `UNet加载器` 节点加载了 `wan2.2_fun_control_low_noise_14B_fp8_scaled.safetensors` 模型
   - 确保 `LoraLoaderModelOnly` 节点加载了 `wan2.2_i2v_lightx2v_4steps_lora_v1_low_noise.safetensors`
3. 确保 `加载CLIP` 节点加载了 `umt5_xxl_fp8_e4m3fn_scaled.safetensors` 模型
4. 确保 `加载VAE` 节点加载了 `wan_2.1_vae.safetensors` 模型
5. 在 `加载图像` 节点中上传起始帧
6. 在第二个 `加载视频` 节点中加载姿态控制视频。提供的视频已预处理，可直接使用
7. 由于我们提供了预处理后的姿态视频，需要禁用对应的视频图像预处理节点。选中该节点后使用 `Ctrl + B` 将其禁用
8. 修改提示词：可使用中文或英文
9. 在 `Wan22FunControl视频` 中修改视频尺寸。默认设置为 640×640 分辨率，避免低显存用户处理时间过长
10. 点击 `运行` 按钮，或使用快捷键 `Ctrl(cmd) + Enter` 执行视频生成### 补充说明

由于 ComfyUI 内置节点仅包含 Canny 预处理器，你可以使用类似 [ComfyUI-comfyui_controlnet_aux](https://github.com/Fannovel16/comfyui_controlnet_aux) 的工具来实现其他类型的图像预处理
