**Wan2.2-Fun-Inp** 是 Alibaba pai团队推出的首尾帧控制视频生成模型，支持输入**首帧和尾帧图像**，生成中间过渡视频，为创作者带来更强的创意控制力。该模型采用 **Apache 2.0 许可协议**发布，支持商业使用。

**核心功能**：
- **首尾帧控制**：支持输入首帧和尾帧图像，生成中间过渡视频，提升视频连贯性与创意自由度
- **高质量视频生成**：基于 Wan2.2 架构，输出影视级质量视频
- **多分辨率支持**：支持生成512×512、768×768、1024×1024等分辨率的视频，适配不同场景需求

**模型版本**：
- **14B 高性能版**：模型体积达 32GB+，效果更优但需高显存支持

## Wan2.2 Fun Inp 起始-结束帧视频生成工作流示例

<UpdateReminder/>

该工作流提供两个版本：
1. 使用来自 lightx2v 的 [Wan2.2-Lightning](https://huggingface.co/lightx2v/Wan2.2-Lightning) 4步 LoRA 加速视频生成的版本
2. 不使用加速 LoRA 的 fp8_scaled 版本

以下是使用 RTX4090D 24GB VRAM GPU，在 640x640 分辨率、81 帧条件下的测试结果

| 模型类型               | VRAM 占用 | 首次生成时间 | 第二次生成时间 |
| ------------------------ | ---------- | ------------ | ------------- |
| fp8_scaled               | 83%        | ≈ 524s       | ≈ 520s        |
| fp8_scaled + 4步 LoRA    | 89%        | ≈ 138s       | ≈ 79s         |

由于使用 LoRA 加速效果显著但视频动态有所损失，默认启用加速 LoRA 版本的工作流。如需启用另一个工作流，请选中它并使用 **Ctrl+B** 激活。

### 3. 工作流指南

![工作流步骤图像](/images/tutorial/video/wan/wan2_2/wan_2.2_14b_fun_inp.jpg)

<Note>
  此工作流使用了LoRA。请确保对应的扩散模型和LoRA匹配。
</Note>

1. **高噪波**模型和**LoRA**加载
   - 确保`UNet加载器`节点加载了`wan2.2_fun_inpaint_high_noise_14B_fp8_scaled.safetensors`模型
   - 确保`LoraLoaderModelOnly`节点加载了`wan2.2_i2v_lightx2v_4steps_lora_v1_high_noise.safetensors`
2. **低噪波**模型和**LoRA**加载
   - 确保`UNet加载器`节点加载了`wan2.2_fun_inpaint_low_noise_14B_fp8_scaled.safetensors`模型
   - 确保`LoraLoaderModelOnly`节点加载了`wan2.2_i2v_lightx2v_4steps_lora_v1_low_noise.safetensors`
3. 确保`加载CLIP`节点加载了`umt5_xxl_fp8_e4m3fn_scaled.safetensors`模型
4. 确保`加载VAE`节点加载了`wan_2.1_vae.safetensors`模型
5. 上传起始帧和结束帧图像作为素材
6. 在提示词组中输入你的提示词
7. 在`WanFunInpaint视频`节点中调整尺寸和视频长度
    - 调整`宽度`和`高度`参数。默认为`640`。我们设置了一个较小的尺寸，但你可以根据需要修改。
    - 调整`长度`，即总帧数。当前工作流的fps为16。例如，如果你想要生成5秒的视频，应设置为5*16 = 80。
8. 点击`运行`按钮，或使用快捷键`Ctrl(cmd) + 回车`执行视频生成
