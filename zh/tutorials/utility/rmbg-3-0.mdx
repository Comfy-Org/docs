RMBG 3.0 是 Bria 的第三个背景移除模型，也是首个基于生成式模型而非分割网络构建的模型。它渲染的是柔和的灰度透明度遮罩，而非硬二值遮罩，因此头发、毛发、网格、薄纱和运动模糊都能保留部分透明度。

其基础模型是 Fibo 2.0，采用 8B diffusion transformer 和 Qwen3-VL-4B 提示词与图像编码器，并蒸馏至 4 个采样步数，且不使用无分类器引导。ComfyUI 支持已在 [ComfyUI #17240](https://github.com/Comfy-Org/ComfyUI/pull/17240) 中合入，该模板需要 ComfyUI 0.46.0 或更高版本。

在 ComfyUI 中，它只是被做成了子图：画布显示一个输入图像和三个输出（RGBA 抠图、背景板、原始遮罩），采样和遮罩控制项位于子图内部。

1. 将你的照片拖入 `LoadImage` 节点。
2. 开启 `auto_prompt`，模板默认是关闭的。关闭时节点会发送固定指令，`subject_note` 不会生效。
3. 可选：在 `subject_note` 中用一句简短的话描述材质，例如 `Clear glass bottle, paper label, metal cap`。
4. 运行工作流。`SaveImage` 会将两个结果都写入 `ComfyUI/output/rmbg3/`。

## 子图暴露的内容

- `auto_prompt`：开启时，视觉模型会根据图像和你的 `subject_note` 编写抠图指令。关闭时，会按原样发送模型训练时所用的固定指令，并忽略 `subject_note`。
- `cfg`：保持为 1.0。该模型在蒸馏时未使用引导，因此更高的值会用对来源的保真度换取透明度。
- `alpha_brightness`、`alpha_contrast`、`mask_threshold`、`hard_mask`：遮罩后处理。将 `hard_mask` 保持关闭，以保留柔和边缘。
- `mask_expand`、`mask_tapered_corners`：在应用之前扩大遮罩并为其添加圆角。

## 抠图结果不正确时

| 现象 | 修复方法 |
| :--- | :--- |
| 玻璃、薄纱或烟雾被抠成实心 | 开启 `auto_prompt`，在 `subject_note` 中描述该材质，然后将 `cfg` 提高到 1.5 或 2.0 |
| 背景出现灰色雾状 | 降低 `alpha_brightness`，或开启 `hard_mask` |
| 彩色玻璃仍然不透明 | 降低 `alpha_brightness`，或手动涂抹该区域 |

有两个限制来自模型本身：非常杂乱或对比度低的场景可能会把主体旁边的草、道具或水印也抠进来，而昆虫翅膀等精细结构可能会丢失像素。
