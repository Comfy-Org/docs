Runway是一家专注于生成式AI的公司，提供强大的视频生成能力。目前，ComfyUI已集成Runway API，您可以直接在ComfyUI中使用相关节点进行视频生成。

目前，ComfyUI原生集成以下Runway视频生成模型：
- Runway Gen4 turbo

<Warning>
  **生命周期终止（EOL）**：**Runway Gen3a Turbo**和**Runway首尾帧转视频**已于**2026年7月30日**结束生命周期。Runway于该日期退役了Gen-3 Alpha Turbo。相关的合作节点（`RunwayImageToVideoNodeGen3a`、`RunwayFirstLastFrameNode`）和工作流模板已弃用，不再受支持。
</Warning>

## Runway 视频生成的优势

- **图生视频生成**：`Runway Gen4 turbo` 节点可根据输入图像和描述视频内容的文本提示词生成视频
- **可调节视频长度**：修改 `duration` 参数可设置视频长度
- **可调节宽高比**：修改 `ratio` 参数可设置视频宽高比

<Warning>
  **生命周期结束（EOL）**：**Runway Gen3a Turbo** 和 **Runway 首尾帧转视频** 的生命周期已于 **2026年7月30日** 结束。Runway 于该日期退役了 Gen-3 Alpha Turbo。相关合作节点（`RunwayImageToVideoNodeGen3a`、`RunwayFirstLastFrameNode`）及工作流模板均已弃用，不再受支持。
</Warning>

### 2. 分步完成工作流执行

![ComfyUI Runway Gen4 turbo 图生视频步骤指南](/images/tutorial/api_nodes/runway/runway_gen4_turbo_image_to_video_step_guide.jpg)

您可以参照图中的数字编号，完成基本的图生视频工作流执行：

1. 在 `Load Image` 节点中，加载提供的输入图像。
2. 在 `Runway Gen4 turbo` 节点中，设置 `prompt` 描述视频内容，修改 `duration` 参数以设置视频时长，修改 `ratio` 参数以设置视频宽高比。
3. 点击 `Run` 按钮，或使用快捷键 `Ctrl(cmd) + Enter` 执行视频生成。
4. 等待 API 返回结果之后，即可在 `Save Video` 节点中查看已生成的视频（右键点击保存）。相应的视频还会保存到 `ComfyUI/output/` 目录中。
