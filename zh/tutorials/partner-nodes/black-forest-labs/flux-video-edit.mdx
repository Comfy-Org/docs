FLUX Video Edit 是 Black Forest Labs 的文本驱动视频编辑端点，在 ComfyUI 中以合作伙伴节点的形式提供。你只需提供一个源视频片段和一段通俗语言的指令，它就会按照该指令重写这段素材。

编辑改变的是镜头中发生的事，而不是镜头的拍摄方式。时长、取景、相机运动和音频轨道都来自源视频片段，因此生成结果可以直接剪回你的剪辑中，无需重新同步任何内容。这使它适用于删除、添加或替换对象、重新为素材设定风格、更改场景、重写画面中的文字，以及替换口播对白。

该节点完全通过 Comfy API 在 Black Forest Labs 的服务器上运行。无需下载模型，也不需要本地 GPU；你需要一个带有积分的 Comfy API 账户。

## FLUX Video Edit 擅长什么

- **仅靠指令**：用文字描述更改，无需遮罩、参考图像或控制输入
- **结构保留**：时长、构图、相机运动和音频均来自源片段
- **对象级编辑**：删除、添加或替换对象、角色和背景元素
- **重设风格**：改变已有素材的观感、光照或场景
- **文本与对话**：重写画面文字并替换口播台词
- **最长 15 秒**：接受 0.7 至 15 秒的源片段

## 编写编辑指令

提示词是唯一的创作控制手段，因此值得仔细撰写：

- 只描述画面上发生变化的内容。凡是未提及的部分，都应保持原样。
- 在同一句话中写明主体和结果，例如“把吉他手替换成同一姿势的大猩猩”。
- 用平实的语言撰写指令，最多 4096 个字符。关于形状、材质或动作的细节，大致对应模型改动的幅度。
- 替换台词的时长应尽量接近原始语音，因为新台词必须适应原始语音所占用的时间。无声的片段保持无声。
- 种子并不能让运行可复现。FLUX 会自行选择种子，因此同一片段上的同一条指令可能得到不同的结果。

## 节点选项参考

| 选项 | 取值 | 默认值 | 说明 |
| ------ | ------ | ------- | ----- |
| `video` | 源视频片段 | 必填 | 0.7 至 15 秒，像素尺寸至少 160x160 |
| `prompt` | 文本 | 空 | 用平实的语言描述要修改的内容，最多 4096 个字符 |
| `auto_downscale` | 开 / 关 | 开 | 上传之前将面积大于 1280x704 的来源缩小，并保持宽高比例 |
| `safety_tolerance` | 0 至 4 | 4 | 高级。内容审核阈值，`0` 最为严格 |
| `seed` | 0 至 4294967295 | 42 | FLUX 会自行选择种子，因此无论此值如何，结果都不确定 |

## 限制

- 源片段时长从 0.7 秒到 15 秒不等，且必须至少为 160x160 像素。
- 输出以 24 fps 渲染，每帧上限约为 0.9 百万像素（1280x704），因此较大的来源素材生成的结果会更小。
- 计费按片段秒数计算。请参阅[合作伙伴节点积分](/zh/tutorials/partner-nodes/pricing)。
