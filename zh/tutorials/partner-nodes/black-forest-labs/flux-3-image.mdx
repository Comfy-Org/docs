FLUX 3 是 Black Forest Labs 的多模态基础模型，于 2026 年 7 月 23 日发布，目前处于 Early Access 阶段。它在一个基于 Self-Flow 的统一架构中同时学习图像、视频和音频。Self-Flow 是他们在同一个模型中对齐多模态生成与理解的方法。FLUX 3 Image 是其中负责生成和编辑静态图像的部分。在 Early Access 推进期间，其能力和限制可能会发生变化。

FLUX 3 Image 可以把一段文本提示词变成图像，也可以编辑并组合最多 10 张参考图像。你在提示词中以 `image 1`、`image 2` 这样的方式引用这些图像，模型会先解读并扩写提示词，再开始生成。网络与图像搜索 grounding 默认开启，因此它可以查询你提到的对象。它会返回单张图像，支持十六种宽高比和五档分辨率，从 0.75K（约 0.6 百万像素）到 4K（约 16.8 百万像素）。

在 ComfyUI 中，FLUX 3 Image 通过 **Flux 3 Image** 合作伙伴节点运行，按分辨率以积分计费，每张图像一次。共有三个模板，分别覆盖文生图、多参考图编辑和边界框版式控制。

## FLUX 3 Image 擅长什么

- **文生图**：根据一段提示词生成一张图像，模型会先解读并扩写提示词
- **多参考图编辑**：编辑或组合最多 10 张参考图像，在提示词中以 `image 1` 到 `image 10` 引用
- **边界框版式控制**：用 Create Bounding Boxes 节点生成的方框，把对象和文字放到你想要的位置
- **搜索 grounding**：网络与图像搜索默认开启，模型可以在绘制前查询你提到的对象
- **灵活输出**：支持十六种宽高比和五档分辨率，从 0.75K 到 4K
- **文字排版与版式**：适合海报、标题、字幕以及以版式为核心的设计工作

### 文生图运行步骤

1. 在 **Flux 3 Image** 节点中输入提示词
2. 设置 `resolution`（0.75K 到 4K），如需自定义可把 `aspect_ratio` 设为 `auto` 以外的值
3. 保持 `grounding` 开启，让模型为你提到的对象检索网络和图像
4. 点击 **Queue** 生成图像

## FLUX 3 Image 图像编辑工作流

### 图像编辑运行步骤

1. 把你的参考图像上传到 **Load Image** 节点，通过 Autogrow 插槽继续添加，最多 10 张
2. 在 **Flux 3 Image** 节点中描述编辑内容，把每张参考图命名为 `image 1`、`image 2` 等
3. 设置输出的 `resolution` 和 `aspect_ratio`
4. 点击 **Queue** 生成编辑后的图像

## FLUX 3 Image 边界框编辑工作流

把 **Create Bounding Boxes** 节点生成的方框接入 **Flux 3 Image** 节点，即可把对象和文字放到精确位置。方框坐标相对于画布，因此输出的宽高比要与画布一致。每个方框自带描述，会一并加入提示词。

### 边界框编辑运行步骤

1. 把图像上传到 **Load Image** 节点
2. 用 **Create Bounding Boxes** 绘制方框，并给每个方框写一段描述
3. 在 **Flux 3 Image** 节点中写下整体指令
4. 把 `aspect_ratio` 设为与绘制方框时所用画布一致
5. 点击 **Queue** 生成图像
