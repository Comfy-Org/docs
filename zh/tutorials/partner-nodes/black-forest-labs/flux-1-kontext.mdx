FLUX.1 Kontext 是由 Black Forest Labs 开发的一款专业的图生图编辑模型，专注于智能理解图像上下文并执行精确编辑。
它能够在无需复杂描述的情况下执行多种编辑任务，包括对象修改、风格转换、背景替换、角色一致性编辑和文本编辑。
Kontext 的核心优势在于其出色的上下文理解能力和角色一致性保持，即使在多次迭代编辑之后，也能确保人物特征、构图布局等关键元素保持稳定。

目前，ComfyUI 已支持 Flux.1 Kontext 的两个模型：

* **Kontext Pro** 非常适合编辑、合成和重新混合。
* **Kontext Max** 在排版、提示词精确度和速度方面突破极限。

## Flux.1 Kontext 擅长什么

- **无需复杂描述的多功能编辑**：对象修改、风格迁移、背景替换、角色一致性编辑和文本编辑
- **上下文理解**：智能理解图像上下文，实现精准、有针对性的编辑
- **角色一致性**：即使经过多轮编辑，角色特征和构图布局仍保持稳定
- **多图像输入**：`Image Stitch` 节点将多张图像拼接为一张图像，以便使用 Flux.1 Kontext 进行编辑
- **两种模型层级**：Kontext Pro 适用于编辑、合成和重组；Kontext Max 适用于排版、提示词精确度和速度

## Flux.1 Kontext 多图像输入工作流

我们最近更新了多图像输入工作流的支持。使用新的 `Image Stitch` 节点，你可以将多张图像拼接成一张图像，并使用 Flux.1 Kontext 进行编辑。

下面图像的 `metadata` 中包含工作流信息。请下载并将它们拖入 ComfyUI 以加载对应的工作流。

![ComfyUI Flux.1 Kontext Pro Image 合作伙伴节点工作流](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/bfl/multiple_image_input/multiple_image_input.png)

下载以下图像作为输入，或使用你自己的图像：

![ComfyUI Flux.1 Kontext Pro Image 合作伙伴节点工作流](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/bfl/multiple_image_input/girl.jpg)
![ComfyUI Flux.1 Kontext Pro Image 合作伙伴节点工作流](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/bfl/multiple_image_input/dog.jpg)
![ComfyUI Flux.1 Kontext Pro Image 合作伙伴节点工作流](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/bfl/multiple_image_input/sofa.jpg)

### 2. 逐步完成工作流

![ComfyUI Flux.1 Kontext Pro Image 合作伙伴节点工作流步骤](/images/tutorial/api_nodes/bfl/flux_1_kontext_multiple_image_input_guide.jpg)

你可以按照图像中的编号步骤来完成工作流：

1. 在 `Load image` 节点中上传提供的图像
2. 在 `Flux.1 Kontext Pro Image` 中修改必要的参数：
    - `prompt` 输入你想要编辑的图像对应的提示词
    - `aspect_ratio` 设置原始图像的宽高比，必须在 1:4 到 4:1 之间
    - `prompt_upsampling` 设置是否使用提示词增强。如果启用，它会自动修改提示词以获得更丰富的结果，但结果不可复现
3. 点击 `Run` 按钮，或使用快捷键 `Ctrl(cmd) + Enter` 来执行图像编辑
4. 等待 API 返回结果后，你可以在 `Save Image` 节点中查看编辑后的图像，对应的图像也会被保存至 `ComfyUI/output/` 目录下

<Tip>
   后续两个工作流只在使用到的合作伙伴节点上有所不同。实际上，你只需要在多图像输入工作流的基础上进行修改，二者没有显著差异
</Tip>
