Ideogram 4.0 是 Ideogram 最新推出的文生图模型，具有出色的照片级真实感、精准的文字渲染和风格控制能力。你可以使用自然语言或 **结构化 JSON Prompts** 来实现对布局、颜色和图片内文字的精细控制。

## Ideogram 4.0 擅长什么

- **照片级真实感质量**：在已生成的图像中展现出卓越的照片级真实感
- **精准的文字渲染**：可在图像中渲染出文字，非常适合海报式构图
- **精确的风格控制**：结构化 JSON 提示词可控制风格调色板、元素位置（`bbox`）以及各元素的颜色调色板
- **灵活的提示方式**：可使用纯自然语言快速表达想法，也可使用结构化 JSON 进行精细控制
- **无需负面提示词**：使用非对称的无分类器引导，而非单独的负面提示词字符串

### Prompt 格式

Ideogram V4 节点支持两种 prompt 格式：

1. **自然语言**：简单直观，适合快速构思。
2. **结构化 JSON**：可精细控制色彩主题、元素位置（`bbox`）和图像内的文字渲染，推荐用于海报类构图。

默认工作流示例使用了结构化 JSON prompt，包含：
- `high_level_description`：整体场景描述。
- `style_description`：美学风格、光照、媒介、色彩主题。
- `compositional_deconstruction`：每个元素的边界框、描述和色彩主题。

### 工作流步骤

1. 下载并将工作流文件拖入 ComfyUI。
2. `Ideogram V4` 节点已包含默认的结构化 JSON prompt：你可以修改它，也可以直接写自然语言。
3. 点击 `Run` 或使用快捷键 `Ctrl(cmd) + Enter` 生成图像。
4. API 返回结果后，在 `Save Image` 节点查看已生成的图像。图像会保存到 `ComfyUI/output/` 目录。

### 使用 JSON Prompt Builder（可选）

工作流内置了一个 **Gemini** 节点（Gemini 3.1 Pro）帮助你构建结构化 JSON prompt：

1. 在 Gemini 节点的用户输入字段中描述你的想法。
2. 模型会生成符合 schema 的 JSON prompt。
3. 将 `STRING` 输出连接到 `Ideogram V4` 节点的 `prompt` 输入。
4. 运行工作流。

## 补充说明

- **不需要负面提示词**：Ideogram 4.0 模型使用非对称无分类器引导（asymmetric CFG），无条件路径会丢弃文本 token，而不是需要单独的负面提示词字符串。
- **模型辅助构建 prompt**：可以考虑使用 **Ideogram 4 Prompt Builder**（KJNodes）在 ComfyUI 中实现对 prompt 构建的视觉控制。
