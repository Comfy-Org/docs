Ideogram 3.0 是一款由 Ideogram 推出的强大文生图模型，以其照片级真实的画质、准确的文本渲染和一致的风格控制而闻名。

Ideogram V3 节点目前支持两种模式：
- 文生图模式
- 图像编辑模式（同时提供图像和遮罩输入时）

<ReqHint/>
<UpdateReminder/>

## Ideogram 3.0 合作节点文生图模式

当 Ideogram V3 未提供图像和遮罩输入时，节点将以文生图模式运行。

### 1. 下载工作流文件

下载以下文件并将其拖入 ComfyUI 以加载工作流：

![Ideogram 3.0 ComfyUI 工作流](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/ideogram/v3/ideogram_v3_t2i.png)

### 2. 完成工作流步骤

![Ideogram 3.0 工作流步骤](/images/tutorial/api_nodes/ideogram/ideogram_v3_t2i.jpg)

按照编号步骤完成基本工作流：
1. 在 `Ideogram V3` 节点的 `prompt` 字段中输入您的图像描述
2. 点击 `Run` 或使用快捷键 `Ctrl(cmd) + Enter` 生成图像
3. API 返回结果之后，在 `Save Image` 节点中查看已生成的图像。图像将保存到 `ComfyUI/output/` 目录中

## Ideogram 3.0 合作节点图像编辑模式

同时连接 `Ideogram V3` 节点的 `image` 和 `mask` 输入，节点会切换到图像编辑模式：根据提示词重绘蒙版区域，蒙版之外的画面保持不变。

1. 使用 `Load Image` 节点加载要编辑的图像，然后将其连接到 `Ideogram V3` 节点的 `image` 输入
2. 右键点击已加载的图像，选择 **Open in MaskEditor**，涂抹想要修改的区域
3. 将蒙版输出连接到 `Ideogram V3` 节点的 `mask` 输入。被涂上（白色）的区域会被替换，蒙版之外的区域保持不变
4. 在 `prompt` 字段中输入编辑指令，描述蒙版区域内应出现的内容
5. 点击 `Run` 或使用快捷键 `Ctrl(cmd) + Enter` 生成编辑后的图像
6. 在 `Save Image` 节点中查看结果，编辑后的图像同样会保存到 `ComfyUI/output/` 目录

<Note>
只有当 `image` 和 `mask` 同时连接时，节点才会使用编辑模式。只连接其中一个时，节点会以文生图模式运行。
</Note>
