Tripo P2 是 Tripo 的 P 系列 3D 生成模型，可输出原生四边形拓扑网格。传统的 text-to-3D 和 image-to-3D 模型返回的是三角网格，而 Tripo P2 以四边面构建几何体，关节周围拥有干净的边环，平坦表面上密度均匀。四边形在绑定下变形可预测，细分干净，是游戏、影视和产品可视化中重度重拓扑流程的标准输入。

Tripo P2 支持三种输入模式：文本生成模型、单张图像生成模型，以及多视图生成模型（前、左、后、右参考图）。网格预算最高可达 50,000 个三角面，或在四边形模式下达到 25,000 个四边形。纹理输出分级提供：标准 2K、精细 4K、极致 8K，并可与基础色一同提供 PBR 贴图（metallic、roughness、normal）。

在 ComfyUI 中，P2 节点的使用方式与其他 Tripo 合作节点相同：添加节点、提供输入，工作流会自动处理贴图、绑定、转换和导出。无需本地 GPU，也无需下载模型。

## Tripo P2 擅长什么 {#what-tripo-p2-is-good-at}

- **原生四边面拓扑**：四边面网格拥有干净的边流，无需手动重拓扑即可用于绑定和动画
- **大网格面数预算**：48 至 50,000 个三角面，或在四边面模式下为 48 至 25,000 个四边面
- **分层纹理**：标准（2K）、精细（4K）或极致（8K）基础颜色纹理，并可选 PBR 贴图
- **三种输入模式**：文本提示、单张参考图像，或最多四张多视角图像（前、左、后、右）

价格取决于所选的纹理级别。详情请参阅[定价](/zh/tutorials/partner-nodes/pricing)。

## Tripo P2：文本生成模型

根据文本描述生成 3D 模型。Tripo P2 会先根据提示词绘制概念图像（由 `image_seed` 控制），再据此生成几何结构。

### 运行步骤

1. **输入提示词**：在 **Tripo P2: Text to Model** 节点中描述该 3D 模型（最多 1024 个字符）。高级选项中提供负面提示词
2. **选择纹理级别**：`standard`（2K）、`detailed`（4K）、`extreme`（8K），或 `none` 表示无纹理网格
3. **切换四边面输出**：启用 `quad` 时网格以 FBX 格式返回；禁用时以 GLB 格式返回
4. **设置面数上限**：目标面数介于 48 到 50,000 之间（启用 quad 时为 48 到 25,000），或保留为 -1 让 Tripo 自行选择
5. **点击队列**：按 `Ctrl+Enter` 生成

生成后，该节点会按你选择的纹理级别发起请求，因此模型在生成时即已贴图，工作流会直接保存该结果（GLB 输出，启用 `quad` 时为 FBX）。模板中还包含 **TripoTextureNodeV2**、**TripoRigNode**、**TripoRetargetNode** 和 **TripoConversionNode** 节点，但它们默认处于旁路且未连接状态：如需这些额外的后处理，请连接并启用它们（选中后按 `Ctrl+B` 可切换旁路）。

### 四边面输出说明

启用 `quad` 时，将 **Save 3D** 连接到 FBX 输出槽。禁用 `quad` 时，使用 GLB 输出槽。

### 运行步骤

1. **上传参考图像**：使用 **LoadImage** 节点加载主体的正视图图像
2. **选择纹理级别**：`standard`、`detailed`、`extreme` 或 `none`
3. **切换四边形输出**：启用时输出 FBX，禁用时输出 GLB
4. **设置纹理对齐**：`original_image` 会匹配输入图像的颜色，`geometry` 则让纹理贴合已生成的形状（高级选项）
5. **点击队列**：按 `Ctrl+Enter` 即可生成

### 输入提示

- 低分辨率或低质量的图像可在建模之前通过 `enable_image_autofix` 高级选项进行增强
- `align_image` 朝向会将模型旋转至输入图像的视角（高级选项）

### 运行步骤

1. **加载参考视图**：模板自带一张正视图（`LoadImage` 节点 16）和一张后视图（`LoadImage` 节点 19）。该节点还提供 `image_left` 和 `image_right` 输入，可实现四视图重建
2. **选择纹理级别**：`standard`（2K）、`detailed`（4K）、`extreme`（8K），或 `none` 生成无纹理网格
3. **切换四边形输出**：启用 `quad` 时输出 FBX，禁用时输出 GLB
4. **设置面数上限**：目标面数可设为 48 到 50,000（四边形模式下为 48 到 25,000），或保留 -1 让 Tripo 自行决定
5. **点击 Queue**：按 `Ctrl+Enter` 开始生成

该工作流会直接保存生成的网格。模板中同时包含的贴图、骨骼绑定、预设动画和格式转换节点默认处于旁路且未连接状态。

## 节点选项参考

三个 P2 节点共用的选项：

| 选项 | 取值 | 默认值 | 说明 |
| ------ | ------ | ------- | ----- |
| `quad` | 开 / 关 | 关 | 开启时输出 FBX 格式的四边形网格，关闭时输出 GLB 格式的三角面网格 |
| `face_limit` | 48 到 50,000（启用 quad 时为 25,000） | -1 | 目标面数；实际结果可能超过该值 |
| `texture` | 标准 / 详细 / 极致 / 无 | 标准 | 2K / 4K / 8K 的基础颜色贴图；选择“无”时返回不带贴图的网格 |
| `pbr` | 开 / 关 | 开 | 金属度、粗糙度和法线贴图；texture 为“无”时忽略此项 |
| `model_seed` | 0 到 2147483647 | 42 | 几何体的种子 |

高级选项包括 `texture_seed`、`auto_size`（以米为单位的真实世界缩放）、`export_uv` 和 `compress_geometry`（Meshopt 压缩；压缩后的网格体积小得多，但无法在 ComfyUI 的 3D 视口中预览）。
