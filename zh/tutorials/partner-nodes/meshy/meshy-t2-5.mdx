**Meshy T2.5** 会直接按照你指定的三角面数构建 3D 网格。较早的流程会先生成高密度网格，再进行重新拓扑，这会丢失细节，并且资产交付前还需要清理。T2.5 会预先以目标面数预算为准，因此一个 15000 三角面的道具返回时大约就是 15000 个三角面，可直接用于引擎。

ComfyUI 通过两个合作节点提供该功能：**Meshy: Text to Model (Smart Topology)** 和 **Meshy: Image to Model (Smart Topology)**。两者都是云端 API 节点，需要拥有带积分的 Comfy 账户，并且不会在本地下载任何模型文件。每个节点都会返回一个 GLB 文件和一个 FBX 文件，模板使用 Save GLB 节点写入 GLB。

T2.5 适用于道具、环境布景和低多边形游戏资产等需要可预测三角面数的场景。如需绑定、动画和完整的资产流程，请改用 [Meshy 7](/zh/tutorials/partner-nodes/meshy/meshy-7)。

## 节点控制

| 控件 | 值 | 适用于 | 作用 |
| --- | --- | --- | --- |
| `model` | `meshy-t2.5` | 两个节点 | 智能拓扑模型版本 |
| `prompt` | 文本，最多 800 个字符 | Text to Model | 要构建对象的描述 |
| `image` | 一张图像 | Image to Model | 构建网格所依据的来源图像 |
| `target_polycount` | 100 到 30000，默认 15000 | 两个节点 | 结果的大致三角形数量 |
| `pose_mode` | 空、`A-pose`、`T-pose` | 两个节点 | 固定角色姿态。道具请留空 |
| `should_texture` | `true`、`false` | Image to Model | 是否在生成后为网格添加纹理 |
| `enable_pbr` | 默认关闭 | Image to Model，启用纹理时 | 为基础颜色添加金属度、粗糙度和法线贴图 |
| `texture_prompt` | 文本，最多 800 个字符 | Image to Model，启用纹理时 | 用于纹理的文本引导。不能与 `texture_image` 组合使用 |
| `texture_image` | 一张图像 | Image to Model，启用纹理时 | 用于纹理的图像引导。不能与 `texture_prompt` 组合使用 |
| `texture_resolution` | `2k`、`4k`、`8k` | Image to Model，启用纹理时 | 已生成纹理的分辨率 |
| `seed` | 整数 | 两个节点 | 控制节点是否重新运行。无论种子如何，Meshy 输出均具有非确定性 |

节点输出 `meshy_task_id`、`GLB` 和 `FBX`。Save GLB 会从 `GLB` 输出写入文件，而不是从任务 ID 或 FBX 输出写入。

## 提示词技巧

- **写明对象与轮廓。** `Standalone game prop, clean silhouette, no text` 可以避免模型额外添加场景、底座，或添加你之后还需要移除的文字。
- **生成之前先确定预算。** 之后修改 `target_polycount` 意味着要重新生成，所以请先决定这个资产是主角道具还是背景装饰。
- **描述材质，而不是灯光布置。** `weathered wood, iron banding, rusted lock plate` 这类表面描述词会保留到网格与纹理中。摄影棚灯光类的词只会影响预览的观感。
- **只对角色使用 `pose_mode`。** A-pose 或 T-pose 能得到便于绑定的姿势。道具最好留空。
- **形状正确之后再处理纹理。** 先在不开启纹理的情况下运行一次，检查轮廓，然后在最终一遍时打开 `should_texture`。
- **不要指望两次得到相同的网格。** 种子只决定节点是否重新运行，因此重新运行就是新的结果。
