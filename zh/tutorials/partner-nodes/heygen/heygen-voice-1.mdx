**HeyGen Voice 1.0** 可以把一段单人录音变成一个可复用的音色，然后用这个音色朗读任意文本。整个过程不需要等待训练：克隆直接由你接入的片段生成，返回的 `voice_id` 就是文本转语音节点所需的全部输入。它适用于用本人声音做旁白、角色对白以及多语言配音。

在 ComfyUI 中，该功能由两个合作伙伴节点完成：**HeyGen Voice 1.0 Instant Clone** 接收录音并返回 `voice_id`，**HeyGen Voice 1.0 Text to Speech** 用这个音色朗读文本。两者都是云端 API 节点：需要带积分的 Comfy 账号，并且不会下载本地模型。克隆免费，文本转语音按每 1K 字符计费。费率见[合作伙伴节点定价](/zh/tutorials/partner-nodes/pricing)。

模板把两个节点接在同一个工作流里，并保存两种输出：朗读出的音频，以及记录了 `voice_id` 的文本文件，方便下次直接复用同一个音色，不必重新克隆。

## HeyGen Voice 1.0 擅长什么

- **短录音即可克隆**：10 秒清晰的语音就够用，最多会用到片段的前 3 分钟
- **复用音色**：`voice_id` 输出可以接入文本转语音，也可以填入 HeyGen Avatar Video 和 HeyGen Talking Photo 的 `custom_voice_id`
- **两种速度**：`heygen-voice-1-turbo` 更快，价格是 `heygen-voice-1` 的一半
- **表现力控制**：`expressiveness_boost` 取值低时贴近原录音，取值高时情绪更丰富

### 运行步骤

1. **加载录音**：在 **LoadAudio** 节点中接入单人、至少 10 秒的清晰语音，只会使用前 3 分钟
2. **克隆音色**：在 **HeyGen Voice 1.0 Instant Clone** 上把 `language` 设为录音所用的语言，并选择 `similarity`。修改 `seed` 可以重新克隆，得到略有差异的音色
3. **写入文本**：在 **HeyGen Voice 1.0 Text to Speech** 的 `text` 中输入不超过 5000 字符的纯文本，并把克隆节点的 `voice_id` 输出接到它的 `voice_id` 输入
4. **设置表现力**：`expressiveness_boost` 取 0 到 1。`0` 最贴近原录音，`1` 情绪最丰富
5. **点击 Queue** 或按 `Ctrl+Enter` 生成
6. **保存结果**：模板用 **SaveAudioAdvanced** 保存音频、用 **SaveText** 保存音色 ID，放在 `output/HeyGen_Voice_id/` 下

## 节点控制

### HeyGen Voice 1.0 Instant Clone

| 控制项 | 取值 | 作用 |
| --- | --- | --- |
| `audio` | 一段音频 | 单人录音。建议至少 10 秒，只会使用前 3 分钟 |
| `language` | `auto` 或某种语言 | 录音中所说的语言 |
| `similarity` | `medium`、`high`、`extra_high`、`max`（默认） | 克隆音色与原录音的接近程度 |
| `remove_background_noise` | 默认开启 | 克隆前清理录音 |
| `seed` | 默认 42 | 修改后会重新克隆，每次得到略有差异的音色 |

### HeyGen Voice 1.0 Text to Speech

| 控制项 | 取值 | 作用 |
| --- | --- | --- |
| `model` | `heygen-voice-1`、`heygen-voice-1-turbo` | turbo 更快，价格只有一半 |
| `voice_id` | 已克隆的音色 ID | Instant Clone 节点的输出 |
| `text` | 1 到 5000 字符 | 要朗读的文本。超过约 12 分钟的语音会失败，超长的中文或日文请分段 |
| `language` | `auto` 或某种语言 | 塞尔维亚语、马来语等相近语言容易被自动识别混淆时请手动指定 |
| `expressiveness_boost` | 0.0 到 1.0，默认 0.5 | 取值越高表现力越强，取值越低越贴近原音色 |

## 限制

- 克隆只使用录音的前 3 分钟，实际操作中至少需要 10 秒清晰语音。
- 文本上限 5000 字符，约 12 分钟语音。只接受纯文本，其他内容会被拒绝。
- 即时克隆的音色在文本转语音中会忽略 `seed`、`speed` 和 `pitch`，表现力只能通过 `expressiveness_boost` 控制。
- `voice_id` 必须来自克隆节点，留空会报错。
- 克隆免费，文本转语音按模型费率以每 1K 字符计费。
