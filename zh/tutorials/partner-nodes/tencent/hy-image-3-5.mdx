腾讯混元图像 3.5 Preview（HY Image 3.5 Preview）是腾讯的预览版图像模型，通过合作节点在 ComfyUI 中提供。它可以根据文本生成图像，也可以按照指令编辑现有图像，重点在于多语言文字渲染、照片级真实感，以及参考图与编辑结果之间的一致性。

与之前的混元图像模型相比，HY Image 3.5 Preview 强化了三个方面：面向广告、信息图与 UI 设计的多语言文字渲染与排版；覆盖电影感、漫画、商业摄影和插画的光影真实感与风格范围；以及在更换背景、服装或风格时保持人物与产品关键特征的编辑一致性。

页面提供两个工作流：`Tencent HY Image: Text to Image` 根据提示词生成图像，`Tencent HY Image: Edit` 编辑或合并最多 5 张参考图。两者都通过 Comfy API 在腾讯的服务器上运行，无需下载模型或本地 GPU。

## HY Image 3.5 Preview 擅长什么

- **多语言文字与排版**：为海报、信息图和 UI 效果图渲染清晰可读的文字，而不只是场景图像
- **照片级真实感范围**：用简短提示词即可覆盖电影感画面、漫画、商业摄影和插画
- **编辑一致性**：更换背景、服装或风格时，保持人物与产品的关键特征稳定
- **最多 5 张参考图**：在一次编辑中组合多张图像，并在提示词中逐张引用
- **最高 4K 输出**：原生渲染最高 2K，4K 输出由 2K 渲染结果放大得到

### 运行工作流的步骤

1. 编辑 `Tencent HY Image: Text to Image` 节点中的 `prompt`
2. （可选）设置 `aspect_ratio` 控制输出形状。使用 `auto` 时由模型根据提示词选择宽高比，4K 下不支持 `auto`
3. （可选）修改 `resolution`（默认为 `2K`）。`1K` 约为 1024x1024 像素，`2K` 约为 2048x2048 像素。`4K` 输出会先以 2K 渲染，再由模型放大
4. （可选）将 `resolution` 切换为 `custom`，改用精确的 `width` 和 `height`。两者必须是 16 的倍数，总面积最大可达 4096x4096。宽高比超过约 6:1 时，模型会开始重复主体
5. 点击 `Run` 或按 `Ctrl(cmd) + Enter` 生成图像
6. 在 `Save Image` 节点中查看结果

### 运行工作流的步骤

1. 将示例图像上传到已连接到 `Tencent HY Image: Edit` 节点的 `Load Image` 节点。下载的工作流以文件名（`futuristic_brutalist_motorcycle.png`）引用该文件，因此在你上传之前该节点会显示为空。若要改为编辑自己的图像，请将 1 至 5 张图像连接到 `Tencent HY Image: Edit` 节点的 `images` 输入
2. 在 `prompt` 中编写编辑指令，按顺序用 `@Image1`、`@Image2` 等引用输入图像。批处理输入按每张图像计一次
3. （可选）设置 `aspect_ratio` 和 `resolution`。使用 `auto` 时输出会跟随第一张参考图的宽高比。`4K` 输出会先以 2K 渲染，再由模型放大
4. （可选）将 `reference_detail` 设为 `high`，让模型看到最高 2048x2048 像素的参考图，而不是 1024x1024。这样可以更好地保留小字和细节，但耗时更长
5. 点击 `Run` 或按 `Ctrl(cmd) + Enter` 生成图像
6. 在 `Save Image` 节点中查看结果

### 提示词技巧

- 分别描述要修改的部分和必须保持不变的部分，例如 `@Image1 change the background to a night market, keep the subject and jacket unchanged`
- 参考图编号按连接顺序排列，提示词中的编号必须与输入顺序一致
- `watermark` 位于节点的高级选项中，默认关闭。开启后会为输出添加 AI 生成水印

## 开始使用

1. 将 ComfyUI 更新到最新版本，或使用 [Comfy Cloud](https://cloud.comfy.org/?utm_source=docs&utm_medium=referral&utm_campaign=hy-image-3-5)
2. 打开模板库，搜索 `HY Image 3.5`
3. 打开文生图或图像编辑工作流并运行
