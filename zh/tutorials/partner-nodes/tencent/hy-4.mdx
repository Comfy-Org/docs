**Tencent HY4** 是腾讯的大语言模型，在 ComfyUI 中可通过 `Tencent HY` 合作伙伴节点使用。该节点接收一段文本提示词和最多 20 张图像并返回文本：根据参考图像撰写的美术提示词、图像描述、图表拆解，或你要求的任何其他答案。

Hy4 发布于 2026 年 11 月 4 日。它是首个具备视觉理解能力的 Hy 代际模型，腾讯表示其在指令遵循、长上下文理解和长程 agentic 任务方面相较 Hy4 预览版有所提升。该节点通过 Comfy API 调用模型，因此无需下载模型，也无需本地 GPU。

本文介绍的模板是图像转提示词示例：它读取一张照片，并写出以逗号分隔的提示词，你可以将其粘贴到图像模型中。

## Tencent HY 节点擅长什么

- **图像转提示词**：编写结构化提示词，涵盖主体、构图、相机、光照、颜色、纹理与风格
- **图像理解**：生成描述文字，拆解图表与示意图，并对照片、截图和文档进行精细细节核对
- **单次请求多张图像**：一次调用最多可传入 20 张图像，批处理中的每张图像各计一次
- **指令控制**：`system_prompt` 承载常驻角色，`prompt` 承载本次运行的任务
- **推理开关**：`reasoning` 让模型在回答前先思考，适用于需要思考的任务
- **长回答**：`max_tokens` 最高可接受 64000 个 token

### 运行工作流的步骤

这个工作流演示如何用腾讯 HY 生成回复，并把对话历史保存到 ComfyUI 中。加载参考图像并运行工作流后，可在 `Preview Any` 中查看回答；`Save Text` 会把提示词和回答写入 `output/Hy4/` 下的 `.txt` 文件。

### 提示词技巧

- 明确说明输出格式。模板中的 `Only output positive prompt, no extra explanations` 这一行正是让回答可以直接粘贴的关键
- 当你连接多张图像时，请按顺序引用它们（`the first image`、`the second image`），这样细节才能落到正确的图像上
- 把重复出现的指令放入 `system_prompt`，把 `prompt` 留给具体任务，例如 `You write photography prompts for a stock library`
- `seed` 只决定节点是否重新运行。回答在不同运行之间仍会有所变化

## 开始使用

更新 ComfyUI，在模板库中搜索 `Tencent: Hy4`，然后打开图像转提示词工作流即可。

Tencent HY4 按 API token 用量计费。Hy4 的费率请参阅[价格表](/zh/tutorials/partner-nodes/pricing)。
