Moonvalley Marey Realism v1.5 是专为影视级创作打造的 AI 视频生成模型，该模型**完全使用商业授权内容训练**，确保**版权合规，商用安全**。

## Moonvalley 的优势

- 卓越的提示词理解能力：能够准确解析复杂的提示词指令。
- 原生 1080p 高清画质：训练数据集基于 **1080P** 视频，从而生成精细且细节丰富的输出。
- 逼真的物理与动态表现：精确模拟物理运动模型和自然动态，呈现专业级的真实感。
- 复杂场景分层与高级光照效果：支持复杂场景中的前景、中景和背景分层，具备智能的空间关系理解能力。
- 生产级控制功能，例如运动与姿态迁移：自动为合成场景生成逼真的光照。

目前，ComfyUI 原生支持与 Moonvalley 相关的合作节点。您可以直接在 ComfyUI 中使用相应的文生视频、图生视频和视频转视频功能。

### 2. 按步骤运行工作流

![视频转视频工作流](/images/tutorial/api_nodes/moonvalley/api_moonvalley_video_to_video.jpg)
1. 在 `Load Video` 节点中加载参考视频（或你自己的素材）
    - 如果最终视频时长为 5s，输入视频必须大于 5s
    - 如果最终视频时长为 10s，输入视频必须大于 10s
2. 输入正向提示词（想要出现在视频中的内容）
3. 输入负面提示词（不想要出现在视频中的内容）
4. 设置 `control_type` 参数，选择视频重绘的参考类型
    - `Motion Transfer`: 根据参考视频的运动进行生成
    - `Pose Transfer`: 根据参考视频的角色姿态进行生成
5. 点击 `Run` 按钮，或使用快捷键 `Ctrl(cmd) + Enter` 开始生成视频
6. API 返回结果后，你可以在 `Save Video` 节点中查看已生成的视频。视频也会被保存至 `ComfyUI/output/` 目录下
