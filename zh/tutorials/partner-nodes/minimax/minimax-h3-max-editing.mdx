六个 MiniMax H3 Max 编辑节点以视频或静态图像为起点，并对该素材进行编辑。与其他 H3 API 节点一样，它们通过你的 Comfy API 账户运行，于 ComfyUI 0.44.0 中加入。

其中三个自带工作流模板：**Cast Swap**（`api_minimax_h3_max_recast`）、**Aspect Ratio Reframe**（`api_minimax_h3_max_reframe`）和 **Camera Control**（`api_minimax_h3_max_camera_control`）。其余三个位于节点库中的 **合作节点 > 视频 > MiniMax** 分类下，可直接拖入你的工作流。前两个模板见下文；[Camera Control 模板](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/api_minimax_h3_max_camera_control.json)会让相机围绕静态图像环绕，并为片段配上音乐。

如需使用 MiniMax H3、H3 Max 和 H3 Max Turbo 生成，请参阅 [MiniMax H3 API 视频生成](/zh/tutorials/partner-nodes/minimax/minimax-h3)。

## MiniMax H3 Max：角色替换

加载你自己的片段，并连接一到四张照片，每个新人物一张。默认情况下，照片会从左到右依次替换片段中的主要人物，因此请按你想要的顺序连接它们。提示词是可选的：用 `@Image1` 到 `@Image4` 指代照片，说明谁替换谁，以及任何必须保持不变的内容。

- **来源片段**：时长 5 至 30 秒，单个镜头不超过 15 秒，宽高比在 0.4 到 2.5 之间
- **参考照片**：至少 256 x 256 像素，最多四张
- **分辨率**：768P 或 1080P
- **增强真实感**：默认关闭。开启后可获得更自然的皮肤质感，并更好地融入场景

内置演示将一段竖直人像片段转换为 16:9 画面。加载你自己的片段，选择目标宽高比与分辨率，并用提示词描述新区域中填充的内容，例如延续主体两侧已有的背景。

- **来源片段**：0.5 至 300 秒
- **宽高比**：16:9、9:16、1:1、4:3、3:4、21:9 或 9:21
- **分辨率**：480P、768P 或 1080P

## MiniMax H3 Max 编辑节点

| 节点 | 功能 | 起始媒体 |
| :--- | :----------- | :------------- |
| **MiniMax H3 Max Recast** | 用参考照片中的人物替换视频中的人物，保留来源视频的运动、相机、剪辑和声音 | 5-30 秒视频，1-4 张照片 |
| **MiniMax H3 Max Extend Video** | 用提示词中描述的新素材延续视频 | 1.625-60 秒视频，可选 H3 Max 或 H3 Max Turbo |
| **MiniMax H3 Max Reframe Video** | 将视频适配到新的比例，并生成其周围区域，保留时间节奏和声音 | 0.5-300 秒视频 |
| **MiniMax H3 Max Insert Video** | 用新生成的场景替换两个时间戳之间的片段 | 最长 60 秒的视频，外加起始时间和恢复时间 |
| **MiniMax H3 Max Lip Sync** | 让静态图像动起来，使嘴型跟随音频轨道 | 一张图像，5-899 秒音频 |
| **MiniMax H3 Max Camera Control** | 让相机围绕静态图像中的主体环绕运动 | 一张图像，外加结束角度和距离 |

在提示词中，请以 `@Image1`、`@Video1` 或 `@Audio1` 指代已连接的参考，编号遵循连接顺序。Recast 检查 `@Image` 标签，Extend Video 检查 `@Audio` 标签，Insert Video 检查 `@Image` 和 `@Video` 标签，Reference to Video 则检查这三种标签。如果某个受检查类型的标签指向的参考超出该类型已连接的参考数量，运行将因错误而停止；其他类型的标签会原样传递。

各节点和各分辨率的费率见 [Minimax 价格表](/zh/tutorials/partner-nodes/pricing)。
