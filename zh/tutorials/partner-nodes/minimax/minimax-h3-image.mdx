MiniMax H3 Image 是 MiniMax 的图像模型，可通过 **MiniMax H3 Image** 合作伙伴节点在 ComfyUI 中使用。文生图与图像编辑使用的是同一个节点：未连接参考图像时，它会根据你的提示词生成图像；连接了参考图像时，它会对这些图像进行编辑或组合。

这些工作流通过你的 Comfy API 账户在 MiniMax 的服务器上运行，因此无需下载模型，也无需管理本地 GPU。

<UpdateReminder/>

## MiniMax H3 Image 擅长什么

- **2K 和 4K 输出**：选择尺寸档位和宽高比，或设置精确的宽度和高度
- **图像编辑**：最多可编辑或组合 16 张参考图像，在提示词中以 `@Image1` 至 `@Image16` 引用
- **提示词重写**：MiniMax 默认会将简短提示词扩展为详细的场景描述，并随图像一并返回重写后的提示词
- **海报级细节**：适合需要清晰文字和密集细节的海报、包装和编辑类图像

## 选项

| 输入 | 取值 | 说明 |
| :---- | :----- | :---- |
| `model` | `MiniMax-H3-Image`、`MiniMax-H3-Image-Highspeed` | 在模板中更改 `model` 下拉选项即可切换 |
| `size` | `2K`、`4K`、`custom` | 2K 和 4K 会根据宽高比推导出宽度和高度。`custom` 的宽度和高度各为 512 至 7680 px，总像素为 655,360 至 20,000,000 px，宽高比最大为 3:1 |
| `aspect_ratio` | `auto` 加上 15 种固定比例 | `auto` 会跟随提示词；若连接了参考图像，则跟随该图像 |
| `enhance_prompt` | 默认开启 | MiniMax 会先把提示词改写为详细的场景描述。编辑操作始终会执行增强，因此关闭它只影响文生图，此时需要选择固定比例或自定义尺寸 |
| `images` | 最多 16 张 | 用于编辑与合成的参考图像。在提示词中按连接顺序以 `@Image1`、`@Image2` 等引用它们 |

连接参考图像时，提示词最多可达 8,000 个字符。节点还会在图像旁一并返回改写后的 `revised_prompt`。

## 开始使用

1. 将 ComfyUI 更新至 0.45.1 或更高版本
2. 在模板库中搜索 `MiniMax-H3-Image`
