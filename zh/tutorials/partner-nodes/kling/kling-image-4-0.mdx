Kling Image 4.0 是 Kling AI 的图像模型，在 ComfyUI 中以合作节点形式提供。`Kling 4.0 Image` 根据提示词渲染最高 8K 的静态图像，最多可使用十张参考图，并可输出一组关联图像。`Kling 4.0 Long Image` 一次生成适合网页或商品详情的长图。

三个模板覆盖了下面的工作流。

<ReqHint/>
<UpdateReminder/>

## Kling 4.0：文生图 {#api_kling4_image_t2i}

根据提示词以 2K、4K 或 8K 分辨率生成一张图像，支持八种宽高比，或使用 `auto` 跟随参考图。最多可连接十张参考图像，并在提示词中从 `@Image1` 开始依次命名，以引导生成结果。将 `series_amount` 设为 `auto` 或 2 到 10 之间的数字，可获得一组保持相同角色和风格的关联图像。

## Kling 4.0：图像编辑 {#api_kling4_image_edit}

在图像重新设计风格的同时，保留不能改变的部分。将照片作为第一张参考图连接，然后同时描述要更改的内容和保持不变的内容：该模板保留面部、构图和背景，仅更改发型、妆容和服装。该节点与文生图相同，只是连接了一张参考图。

## Kling 4.0：长图 {#api_kling4_long_image}

一次生成一张非常高的长图。通过 `skill` 选择页面类型：

- `webpage`：可选风格图像和主体图像，分别以 `@Image1` 和 `@Image2` 引用。逐段描述页面，并说明可见文案所使用的语言。
- `ecommerce`：一到三张产品图像，从 `@Image1` 开始引用，并将 `length` 设为 `short`、`medium` 或 `long`。

两种技能均支持 1K 或 2K 渲染。

## 输入限制

- 图片：至少 300 x 300 像素，比例在 2:5 到 5:2 之间。`Kling 4.0 Image` 最多可连接十张参考图，`Kling 4.0 Long Image` 在 `ecommerce` 模式下取一到三张产品图。
- 在图像节点中，提示词里的 `@ImageN` 超出已连接输入数量时，运行会直接失败。
