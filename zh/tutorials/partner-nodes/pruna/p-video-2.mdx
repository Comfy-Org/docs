Pruna P-Video-2 是 Pruna 主打画质的视频生成模型，在 ComfyUI 中通过两个合作节点提供：**Pruna P-Video-2 文本生成视频** 和 **Pruna P-Video-2 图生视频**。它可生成 1 到 20 秒的片段，分辨率支持 720p 或 1080p，帧率为 24 或 48 fps，涵盖七种宽高比（16:9、9:16、4:3、3:4、3:2、2:3、1:1），并带有原生音频：环境音、音效，以及根据提示词生成的唇形同步对白。

图生视频节点可将首帧图像制作成动画，并可选提供尾帧；两个节点都接受可选的音频输入，由音频驱动画面运动并成为配乐。草稿模式渲染速度更快、细节更少，按标准价格的 60% 计费，因此你可以在确定进行全质量渲染之前先反复调整构图。

这些节点完全通过 Comfy API 在 Pruna 的服务器上运行。无需下载模型，也不需要本地 GPU；你只需要一个拥有积分的 Comfy API 账户。

## P-Video-2 擅长什么

- **原生音频**：生成包含环境音、音效和唇形同步对白的配乐，或跟随连接式音频轨道
- **灵活输出**：720p 或 1080p，24 或 48 fps，1 至 20 秒（或根据提示词选择 `auto` 时长），七种宽高比
- **草稿模式**：以标准费率的 60% 提供更快、细节更少的预览
- **首帧与尾帧**：图生视频在两张宽高比高度匹配的图像之间生成动画

定价取决于分辨率和草稿模式，按秒计费。详情请参阅[定价](/zh/tutorials/partner-nodes/pricing)。

### 运行步骤

1. **输入提示词**：在 **Pruna P-Video-2 Text to Video** 节点中描述场景、其动态以及声音（最多 5000 个字符）
2. **设置时长和分辨率**：选择 1 到 20 秒或 `auto`，然后选择 720p（约 0.9 兆像素）或 1080p（约 2 兆像素）
3. **选择帧率**：24 或 48 fps。在 1080p 下使用 draft 时 48 fps 不可用
4. **可选：连接音频**：音频输入将驱动动态并设定视频长度，而非使用 `duration`（1 到 20 秒；更长的音频会被截断）
5. **点击队列**：按 `Ctrl+Enter` 生成

### 提示

- `enhance_prompt`（默认开启）会为较短的提示词补充更多细节。关闭后，可使用相同的种子精确复现结果
- 关闭 `generate_audio` 可生成无声视频

### 运行步骤

1. **上传首帧**：连接一个 **LoadImage** 节点。输出会保持该图像的宽高比例
2. **可选：上传尾帧**：视频将以该图像结束。其宽高比例必须与首帧接近
3. **描述运动和声音**：在提示词中写出场景如何运动和发声（最多 5000 个字符）
4. **设置时长、分辨率和帧率**：选项与文本转视频相同
5. **点击队列**：按 `Ctrl+Enter` 生成

## 节点选项参考

| 选项 | 取值 | 默认值 | 说明 |
| ------ | ------ | ------- | ----- |
| `duration` | 1 到 20，或自动 | 5 | 连接音频时忽略；此时视频长度跟随音频长度 |
| `resolution` | 720p / 1080p | 720p | 720p 约 0.9 MP，1080p 在 16:9 下约 2 MP |
| `fps` | 24 / 48 | 24 | 在 1080p 下开启 draft 时无法使用 48 fps |
| `draft` | 开 / 关 | 关 | 渲染更快、细节更少，按标准费率的 60% 计费 |
| `generate_audio` | 开 / 关 | 开 | 连接音频时忽略 |
| `enhance_prompt` | 开 / 关 | 开 | 高级。如需精确的种子可复现性，请关闭 |
| `seed` | 0 到 2147483647 | 42 | 精确复现需要关闭 enhance_prompt |
