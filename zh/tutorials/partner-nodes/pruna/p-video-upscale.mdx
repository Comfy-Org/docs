Pruna P-Video Upscale 可将已完成片段放大至 720p、1080p、2K 或 4K。输出会保留来源视频的宽高比和音轨。帧率可保持来源帧率，或通过插帧提升至最高 60 fps，也可通过丢帧降低。

该节点为 **Pruna P-Video Upscale**，位于 `partner/video/Pruna` 类别下。它接收任意视频输出，无论来自 **加载视频** 节点，还是来自同一工作流中的生成结果，并返回放大后的片段，因此你可以将其串联在文生视频或图生视频节点之后。

它通过 Comfy API 在 Pruna 的服务器上运行。无需下载模型，也无需本地 GPU；你需要一个带有积分的 Comfy API 账户。

## 将其添加到工作流

1. **添加节点**：右键点击画布，在 `partner/video/Pruna` 下搜索 **Pruna P-Video Upscale**
2. **连接视频**：将视频输出接入 `video` 输入
3. **选择目标**：`720p`、`1080p`（默认）、`2K` 或 `4K`
4. **设置帧率**：`source` 保持输入帧率，最高 60 fps；高于来源的帧率会插帧，低于来源的帧率会丢帧
5. **保存结果**：将输出连接到 **Save Video** 节点
6. **点击队列**：按 `Ctrl+Enter` 运行

## 节点控件

| 控件 | 取值 | 作用 |
| --- | --- | --- |
| `video` | 视频 | 要放大的片段。512 MiB 上限针对节点转码后的 MP4，而不是你加载的文件 |
| `target` | `720p`, `1080p`, `2K`, `4K` | 输出像素面积约为 0.9、2.1、3.7 或 8.3 百万像素。默认 `1080p` |
| `fps` | `source`, `16`, `24`, `25`, `30`, `48`, `50`, `60` | 输出帧率。`source` 保持输入帧率，上限为 60；低于来源的数值会丢帧 |
| `turbo` | on / off | 价格相同，放大更快，但细节更柔和 |

## 限制

- 大于目标的来源会按原尺寸返回，例如 1080p 的片段选择 `720p` 后仍是 1920×1080
- 每个目标的长度上限为：`720p`、`1080p`、`2K` 或 `4K` 分别对应 2400、1200、600 或 300 帧，按最高 30 fps 计算。在 24 fps 下约为 100、50、25 或 12.5 秒
- 超过 10 百万像素的片段必须以 `2K` 或 `4K` 为目标
- 输入在上传前会重新编码为 H.264 MP4，512 MiB 上限针对这个转码后的文件，而不是原始文件。音轨会保留到结果中
- 高于 30 fps 的输出按每秒费率的两倍计费，包括 `source` 保留了 30 fps 以上的来源帧率时

## 定价

Pruna P-Video Upscale 按输出视频的秒数计费，费率取决于目标。当前费率请参阅[合作伙伴节点定价](/zh/tutorials/partner-nodes/pricing)。
