**VEED** 视频节点覆盖了那些通常需要借助另一个应用才能完成的编辑步骤：把静态图像变成会说话的人像、替换现有素材中的语音，以及把主体从背景中抠出来。

在 ComfyUI 中，该提供商通过三个合作节点实现。**VEED Fabric 1.0** 依据音频轨道让照片动起来。**VEED Lipsync 2.0** 让说话者的口型与新对白重新同步。**VEED Remove Video Background** 返回各帧和一张透明度遮罩，而不是一段已经压平的视频，因此主体可以合成进任意画面。这三个都是云端 API 节点：它们需要带有积分的 Comfy 账户，并且不会在本地下载任何模型文件。

每个节点都按你发送的视频片段的秒数或帧数计费。音频和视频的语音清理请见 [VEED Clean Audio](/zh/tutorials/partner-nodes/veed/veed-clean-audio)。

## 可用工作流

### Fabric 1.0：会说话的照片

让静态图像开口说话。照片中的人脸会与你连接的音频进行唇形同步，片段会保留图像的宽高比，因此竖版人像仍是竖版人像。它适用于照片、插画和吉祥物，因此可以为艺术作品或从未拍摄过的角色配上声音。

### 移除视频背景

从视频片段中抠出主体。该节点返回的不是已合成为单层的视频，而是帧以及标记背景区域的遮罩，因此主体可以合成到新场景上，或导出为透明序列。

## 节点控制

| 控件 | 取值 | 适用于 | 作用 |
| --- | --- | --- | --- |
| `model` | `fabric-1.0`、`lipsync-2.0`、`standard`、`fast`、`green screen` | 每个节点 | 该节点使用的 VEED 模型 |
| `image` | 图像 | Fabric 1.0 | 说话的人脸。宽高比决定输出形状 |
| `video` | 视频片段 | Lipsync 2.0、Remove Video Background | 来源素材。背景移除最长支持 60 秒 |
| `audio` | 音轨 | Fabric 1.0、Lipsync 2.0 | 用于同步的语音。决定输出时长 |
| `resolution` | `480p`、`720p` | Fabric 1.0 | 输出尺寸等级，默认 720p |
| `seed` | 整数 | Lipsync 2.0 | 仅用于重新运行控制。结果仍是非确定性的 |
| `refine_foreground_edges` | 默认开启 | Remove Video Background、standard 和 fast | 头发和毛发的边缘更干净。关闭后可降低价格 |
| `subject_is_person` | 默认开启 | Remove Video Background、standard 和 fast | 当主体是物体或动物时请将其关闭 |
| `spill_suppression_strength` | 0.0 到 1.0，默认 0.8 | Remove Video Background、green screen | 绿色偏色的移除强度。仍有绿色残留时调高，颜色发生偏移时调低 |

背景移除的输出分辨率没有可调项：standard 和 green screen 最高返回 3840x2160，fast 最高返回 1920x1080，更大的输入会被缩小。

## 提示

- **发送干净、正面的素材。** Fabric 需要一张清晰可见的人脸，Lipsync 需要一位面向相机的说话者。侧脸和拥挤的画面正是这两个节点容易丢失细节的场景。
- **让音频决定时长。** 两个说话类节点生成的视频片段长度与所连接的语音完全一致，因此应在运行前裁剪音频，而不是事后再修剪视频。
- **直接输入已生成的语音。** 将文本转语音节点连接到 `audio`，人像或配音片段会随之生成，无需导出步骤。
- **仅在需要时才为边缘优化付费。** 在背景移除中关闭 `refine_foreground_edges` 会降低每帧费率，对于边缘锐利的主体值得这样做。
- **仅在真正的绿幕素材上使用绿幕模式。** 绿幕模式会对背景进行抠像，且没有边缘优化或人物检测，因此自然背景应使用 standard 或 fast。
