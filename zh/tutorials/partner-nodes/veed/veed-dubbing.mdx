VEED Dubbing 可将片段中的语音翻译成另一种语言。每个说话人的声音都会被克隆，其口型也会与译文重新同步，因此成片看起来就像是用目标语言说出来的，而不是配了字幕。

在 ComfyUI 中，该节点为 **VEED Dubbing**，提供两个模型档位。`standard` 是更便宜的一档：单声道音频，支持 85 种目标语言，其中西班牙语为拉美西班牙语，葡萄牙语为巴西葡萄牙语。`pro` 增加了地区口音和立体声音频，支持的目标语言达到 101 种，包括 `English (UK)`、`Spanish (Mexico)` 和 `Chinese (Taiwan)` 等变体。

这是一个云端 API 节点。它需要一个有积分的 Comfy 账户，不会下载任何模型文件，并按输出时长（秒）计费。当前费率请参阅[合作伙伴节点定价](/zh/tutorials/partner-nodes/pricing)。

## 节点控制

| 控制项 | 取值 | 作用 |
| --- | --- | --- |
| `model` | `standard`、`pro` | 配音档位。`standard` 为单声道，支持 85 种目标语言；`pro` 增加了地区口音和立体声音频，支持 101 种语言 |
| `video` | clip | 要配音的素材。最长 599 秒，画面中需有清晰可见的面部，音轨中需有语音 |
| `target_language` | 语言列表 | 要配音成的目标语言。列表取决于档位，`pro` 包含口音变体 |
| `source_language` | `auto` 或某种语言 | 视频中使用的语言。`auto` 为默认值 |
| `seed` | 整数 | 仅用于控制重新运行。结果仍不确定 |

## 提示

- **提交画面中能看到说话者的素材。** 配音依赖于画面中可见的内容，因此单人正对相机是可靠的场景。后脑勺、手部、产品特写和人群场景无法进行配音。
- **确认音频中确实包含人声。** 旁白、对话和访谈都可以。音乐、音效和静音不会给模型提供任何可翻译的内容。
- **当 `auto` 识别错误时，请指定源语言。** `auto` 适用于干净的录音，但对于短视频片段或口音较重的内容，自行设置 `source_language` 可获得更准确的配音。
- **口音重要时选择 `pro`。** 标准档每种语言只提供一个变体，因此英式英语或墨西哥西班牙语的请求仅在 `pro` 上可用。
- **先裁剪到时长限制内。** 该节点最多接受 599 秒的视频，且输出时长与音轨一致，因此请在运行前裁剪，而不是运行后再处理。

## 开始使用

1. 将 ComfyUI 更新至最新版本
2. 前往模板库，搜索 `VEED Dubbing`
3. 将说话人视频片段加载到 `LoadVideo` 节点中
4. 在 `model` 中选择档位，设置 `target_language`，然后运行工作流
