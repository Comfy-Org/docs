**VEED Clean Audio** 可从录音中分离出人声。它会去除背景噪波，而且由于它专为语音设计，音乐和音效也会连同噪波一起被去除：返回的是单独的对白，干净且可直接使用。

在 ComfyUI 中，该模型通过两个合作节点运行。**VEED Clean Audio** 接收独立的录音文件并返回清理后的音频。**VEED Clean Audio (in Video)** 接收一个视频片段，只清理其中的音轨，返回的视频画面保持不变。两者都是云端 API 节点：需要拥有带积分的 Comfy 账户，且不会在本地下载任何模型文件。

两个节点的输出并不相同。**Clean Audio** 返回 48 kHz 单声道音频。**Clean Audio (in Video)** 返回视频本身，画面不变，音轨被替换为清理后的 48 kHz 单声道语音。两者的单次运行最长都支持 1799 秒，也就是略少于 30 分钟。关于对口型、说话人像和背景移除，请参阅 [VEED 视频节点](/zh/tutorials/partner-nodes/veed/veed-video)。

## 节点控件

| 控件 | 取值 | 适用节点 | 效果 |
| --- | --- | --- | --- |
| `audio` | 录音，最长 1799 秒 | Clean Audio | 待清理的语音 |
| `video` | 包含音频的视频片段，最长 1799 秒 | Clean Audio（视频内） | 其音轨会被清理的视频片段。清理步骤不会重新编码画面 |
| `strength` | 0.0 至 1.0，默认 0.874 | 两个节点 | 语音下方被去除的噪波量。数值越低，人声背后的环境底噪保留得越多 |
| `loudness` | `normalize`、`keep input level` | 两个节点 | 输出是否被归一化到目标响度 |
| `target_lufs` | -40 至 -8，默认 -19 | 两个节点，仅 `normalize` 时 | 输出的积分响度 |

无论 `strength` 设为多少，词与词之间的停顿总会被完全清理，且高于默认值的设置带来的变化很小。峰值被限制在 -1.1 dBTP，因此目标响度较高时会提前停止：典型语音最终会落在 -15 LUFS 附近。

## 提示

- **先把 `strength` 保持在默认值。** 该默认值针对语音调校过。只有当人声背后的房间底噪是你想保留的声音的一部分时，才需要把它调低。
- **当清理后的音频需要与其他片段匹配时，做响度归一化。** 使用相同的 `target_lufs`，才能让一系列录音处于同一电平。
- **不要期望能还原音乐。** 音乐和音效会与噪波一起被移除，因此此节点清理的是对白，而不是完整的混音。如果配乐必须保留，请在人声分轨上运行此节点。
- **在运行之前先切分长录音。** 上限为 1799 秒，并且按分钟计费时，更短的文件更便宜。
- **把它串联到说话类节点中。** 清理后的语音比原始录音更适合作为唇形同步和说话人像的输入。
