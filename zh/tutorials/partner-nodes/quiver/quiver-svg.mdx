Quiver SVG 通过 **Text-to-SVG** 和 **Image-to-SVG** 两种模式，在 ComfyUI 中直接生成与分辨率无关的矢量图形。借助 Arrow 1.1、Arrow 1.1 Max 和 Arrow Preview 等模型，它既能快速生成图标，也能完成复杂插画的矢量化处理。

<ReqHint/>
<UpdateReminder/>

## 核心能力

- **Text-to-SVG**：根据自然语言描述生成完全可编辑的 SVG 矢量图形，非常适合图标、标志、插画和 UI 元素。
- **Image-to-SVG**：通过描摹形状、颜色和渐变，将位图图像（PNG、JPG）转换为干净、可缩放的 SVG 矢量图形。

## 可用的工作流

### Text-to-SVG

用自然语言描述你想要的矢量图形，Quiver 便会生成干净、可编辑的 SVG。它适合用来创建图标、标志、图表、插画和 UI 组件。
