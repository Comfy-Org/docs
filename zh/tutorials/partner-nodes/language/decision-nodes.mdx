决策节点会针对你连接的内容向托管模型提出一个问题，并将答案作为工作流可以据此路由的值返回：一个布尔值、你的某个标签，或一个分数。把它放在开销高昂的生成步骤之前，该步骤就只会在通过判定的输入上运行。

有两个提供商提供了这类节点：**HeyGen Decision** 和 **Google Gemini Decision**。两者都能读取文本、图像、音频或视频，并且都提供是/否、选项和分数三种版本。它们属于 API 节点，按输入 token 在你的 Comfy 账户上计费，因此无需下载模型。

## 节点

| 节点 | 问题 | 输出 |
| :--- | :--- | :--- |
| **Decision (Yes/No)** | 一个答案为“是”或“否”的问题 | `result`（布尔值）、`answer`（`"yes"`/`"no"`）、`probability` |
| **Decision (Choice)** | 你的哪个选项合适，每行输入一个选项 | `choice`、`option_index`（从 0 开始）、`confidence` |
| **Decision (Score)** | 对已连接的内容按 1 到 10 进行评分 | `result`（达到或超过阈值的分数）、`score` |
| **Google Gemini Decision (Pick Image)** | 一批图像中哪张最好，或与文本最匹配 | `index`、`confidence` |

`result` 连接到 **If/Else Switch**（切换）节点。`choice` 连接到 **Branch** 节点，其输入包含选项名称，也可以根据 `option_index` 进行路由。对于 **Pick Image**，将 `index` 传入 **Get Image from Batch**（从批次获取图像）。

## 可以连接什么

- **文本**：最多 20,000 个字符，例如提示词、说明文字或需要检查的模型回答
- **图像**：HeyGen 上最多 4 张，Gemini 上最多 16 张。在问题中按 `image_1`、`image_2` 等方式为它们命名。**Pick Image** 是例外：它接收一批 2 到 64 张图像，并返回选中图像的索引
- **音频**：一段，命名为 `audio_1`，在 HeyGen 上最长 30 分钟
- **视频**：一段，命名为 `video_1`，在 HeyGen 上最长 60 秒
- 问题本身最多 5,000 个字符，且一次运行至少需要一个已连接的输入

## 提示

- **提问时要让“是”对应你实际采取行动的情况。** 例如“图像中有一个人吗？”在由 `result` 驱动接受分支时，它在画面中的含义与用日常英语理解时相同。
- **调整阈值，而不是改写问法。** Yes/No 返回“是”的概率，并在 `threshold` 处翻转（默认值为 0.5）。当误报代价很高时调高它。HeyGen 的明确答案会落在 0 或 1 附近；Gemini 的明确“是”大约在 0.85 到 0.92，因此设为 0.9 或更高会把很多答案拒掉。
- **把判断放在高开销节点之前。** 被拒绝的分支永远不会被生成，因此一张未通过的图像只需付出一个简短问题的代价，而不是一次完整渲染。
- **比较时每个候选只评分一次。** 在示例中，两张图像都用同一个问题进行评分，然后用 `a > b` 比较。若要留出余量，请使用 `a > b + 1`：只有当 A 领先超过 1 分时才选中 A，否则传给 B。
- **为 Choice 提供一个兜底选项。** 添加一行类似 `other` 的内容，让不匹配任何选项的输入被标记，而不是被强制归入最接近的匹配项。
