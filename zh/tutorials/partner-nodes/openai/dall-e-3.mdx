OpenAI DALL·E 3 是 ComfyUI 合作节点系列中的一员，允许用户通过 OpenAI 的 **DALL·E 3** 模型生成图像。此节点支持文生图功能。

![OpenAI DALL·E 3 节点截图](/images/built-in-nodes/api_nodes/openai/openai-dall-e-3.jpg)

DALL·E 3 是 OpenAI 最新的图像生成模型，能够根据文本提示生成细节丰富且高质量的图像。通过 ComfyUI 中的此节点，无需离开 ComfyUI 界面即可直接使用 DALL·E 3 的生成能力。

**OpenAI DALL·E 3** 节点通过 OpenAI 的图像生成 API 同步生成图像。它接收文本提示，并返回与描述匹配的图像。

## DALL·E 3 擅长什么

- **文生图**：根据文本提示词生成细节丰富且高质量的图像，支持可详细描述图像内容的多行提示词
- **质量控制**：可在 standard 和 hd 输出之间选择，hd 可生成更高质量的图像
- **风格控制**：可选择 vivid 以生成超写实且富有戏剧性的图像，或选择 natural 以生成更自然、不过度夸张的图像
- **灵活的尺寸**：可生成不同方向（横向或纵向）的正方形或长方形图像（1024x1024、1024x1792、1792x1024）

## 参数详解

### 必需参数

| 参数名  | 类型 | 描述                                                         |
|--------|----|---------------------------------------------------------------|
| prompt | 文本 | 用于生成图像的文本提示。支持多行输入，可以详细描述您想要生成的图像内容。 |

### widget 参数

| 参数名   | 类型 | 可选值                           | 默认值     | 描述                                                                       |
|---------|-----|---------------------------------|-----------|------------------------------------------------------------------------------|
| seed    | 整数 | 0-2147483647                    | 0         | 用于控制生成结果的随机种子                               |
| quality | 选项 | standard, hd                    | standard  | 图像质量设置。"hd"选项生成更高质量的图像，但可能需要更多计算资源                       |
| style   | 选项 | natural, vivid                  | natural   | 图像风格。"vivid"倾向于生成超真实和戏剧性的图像，"natural"则产生更自然、不那么夸张的图像 |
| size    | 选项 | 1024x1024, 1024x1792, 1792x1024 | 1024x1024 | 生成图像的尺寸。可以选择方形或不同方向的矩形图像                                     |

## 使用示例

你可以下载下面的图片，并拖入 ComfyUI 以加载对应的工作流
![ComfyUI openai-dall-e-3 工作流](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/openai-dall-e-3/text2image.png)

由于对应工作流非常简单，你也可以直接在 ComfyUI 中添加 **OpenAI DALL·E 3** 节点，输入你想要生成的图像描述，然后运行工作流即可

![ComfyUI openai-dall-e-3 工作流](/images/tutorial/api_nodes/openai/openai-dall-e-3/text2image.jpg)

1. 在 ComfyUI 中添加 **OpenAI DALL·E 3** 节点
2. 在提示文本框中输入你想要生成的图像描述
3. 根据需要调整可选参数（质量、风格、尺寸等）
4. 运行工作流以生成图像
