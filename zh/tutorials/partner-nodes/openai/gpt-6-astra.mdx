**GPT-6 Astra** 是 OpenAI 能力最强的模型，面向最困难的端到端任务：复杂推理、编程、计算机操作、研究和文档创作。该模型于 2026 年 9 月 3 日发布，支持 1,050,000 令牌上下文窗口、文本和图像输入，以及从 `low` 到 `max` 的推理力度等级。

在 ComfyUI 中，GPT-6 Astra 通过 `OpenAI Chat` 节点运行：在该节点的 `model` 下拉框中选择 `gpt-6-astra`。本页重点介绍该模型在 ComfyUI 工作流中的使用方法。所有模型通用的节点基础用法，请查看 [OpenAI Chat 教程](/zh/tutorials/partner-nodes/openai/chat)。

## 什么时候选 GPT-6 Astra

`OpenAI Chat` 节点提供了很多模型，从 `gpt-5-nano` 到 `gpt-6-astra`。GPT-6 Astra 最强但也最贵，适合廉价模型容易出问题的任务：

- **长上下文图像分析**：通过 `Batch Images` 输入多张图像，或输入大型提示词文件，一次性完成结构化分析
- **提示词工程**：把参考图像或粗略想法转化为详细的、逗号分隔的正向提示词，供图像或视频模型使用
- **智能体式工作流**：多步骤任务，比如先分析数据集描述，再制定生成计划，再起草提示词本身
- **复杂指令遵循**：精确的输出格式（JSON、YAML、固定章节顺序），小模型经常出错

对于简单的图片描述或简短回答，`gpt-5` 或 `gpt-5-mini` 已能有不错的结果，成本只有零头。各模型的费率请查看[定价表](/zh/tutorials/partner-nodes/pricing)。

## 在 OpenAI Chat 节点中使用该模型

`OpenAI Chat` 节点的输入：

- `prompt`：指令。用于提示词生成任务时，要明确说明从图像中提取什么内容、输出什么格式
- `images`：可选的图像上下文。连接 `LoadImage`，多张图像用 `Batch Images`；每个连接的图像都会发送给模型
- `files`：来自 `OpenAI Chat Input Files` 节点的可选文档
- `advanced_options`：来自 `OpenAI Chat Advanced Options` 节点的可选配置

输出是 `String`。下游常见用法：

- 接 `Preview Any` 节点查看回复
- 接 `Save Text` 把生成的提示词写入 `.txt` 文件
- 接 `CLIP Text Encode` 节点的正向提示词输入，搭建全自动的图像或视频生成管线，由 LLM 负责写提示词
- 接合作节点的文本输入，比如在视频生成前起草场景描述

## 推理力度

GPT-6 Astra 是推理模型。连接 `OpenAI Chat Advanced Options` 节点并设置 `reasoning_effort`，可以权衡回复质量和成本：

| 等级 | 行为 |
|------|------|
| `default` | 模型自动选择 |
| `low` | 最快最便宜，适合直截了当的分析 |
| `medium` | 提示词生成的均衡默认值 |
| `high` | 对复杂图像或指令做深入分析 |
| `xhigh` | 深度多步推理 |
| `max` | 最难任务的最大推理力度 |

同一个节点还提供 `max_output_tokens`（16 到 16384，包含推理令牌）和 `instructions` 字段，后者相当于持久的系统提示词，适合多次运行时固定输出格式。

步骤：

1. 在 `LoadImage` 节点中加载你的图像
2. 在 `OpenAI Chat` 节点中，根据需要调整分析提示词或切换 `model`。模板中的提示词让模型提取主体、构图、相机、光影、色彩、质感和风格，然后只输出逗号分隔的正向提示词
3. 点击 `Run`。生成的提示词会显示在预览中，并通过 `Save Text` 节点保存为 `.txt` 文件

想更进一步，可以把保存的提示词复制到 `CLIP Text Encode` 节点或图像、视频模型节点，直接用模型的输出生成。

GPT-6 Astra 按 API 令牌用量计费，费率高于其他 OpenAI Chat 模型。详情请查看[定价表](/zh/tutorials/partner-nodes/pricing)。
