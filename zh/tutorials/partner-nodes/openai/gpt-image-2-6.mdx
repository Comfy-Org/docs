GPT Image 2.6 是 OpenAI 的图像模型系列，在 ComfyUI 中通过 **OpenAI GPT Image 2.6** 合作伙伴节点使用。它有两个变体：

- **Flare**（`gpt-image-2.6-flare`）：几秒内返回草稿，在密集的海报和产品图上能保持版面结构稳定。适用于概念稿、情绪板和文字较多的草稿
- **Sunburst**（`gpt-image-2.6-sunburst`）：将渲染预算用于精细纹理、小号文字和材质，并在多轮生成之间保持主体和光照一致。适用于成品视觉效果，以及对细节要求较高的密集布局

两个变体都支持文本生成图像和图像编辑，最多可使用 16 张参考图像，可选遮罩用于 inpainting，质量等级从 `low` 到 `max`，还提供 `complexity` 控制项，用于设定模型在渲染前对图像的规划程度。该节点同时还提供 GPT Image 2.5、GPT Image 2 和 GPT Image 1.5。

## 入门

1. 将 ComfyUI 更新到 0.44.1 或更高版本
2. 在节点库中搜索 **OpenAI GPT Image 2.6** 并添加该节点
3. 将 `model` 设置为 `gpt-image-2.6-flare` 或 `gpt-image-2.6-sunburst`
4. 将该节点的图像输出连接到保存图像节点，或打开下方四个模板之一

## 节点设置

- **model**：`gpt-image-2.6-flare` 用于快速迭代，`gpt-image-2.6-sunburst` 用于细节优先的渲染
- **prompt**：要生成的内容；当连接了参考图像时，则是编辑指令
- **size**：`auto`、`1024x1024` 或 `3840x2160` 这类预设，或 `Custom`
- **custom_width / custom_height**：仅在 `size` 为 `Custom` 时使用，取值为 480 到 3840，步长为 16
- **background**：`auto`、`opaque` 或 `transparent`
- **quality**：`low`、`medium`、`high`、`xhigh` 或 `max`。影响成本和生成时间
- **complexity**：`low`、`medium` 或 `high`（默认）。模型在渲染前对图像进行多少规划
- **images**：可选的参考图像，用于编辑，最多 16 张
- **mask**：可选的遮罩，用于 inpainting，白色区域会被替换。需要恰好一张参考图像
- **n**：要生成多少张图像，1 到 8
- **seed**：为 API 兼容性而保留，后端尚未使用

Flare 是更省钱的方式，用来找到一个可用的 prompt。以 `low` 或 `medium` 质量运行它，直到构图稳定下来，再把胜出的 prompt 放到 Sunburst 上重新运行，得到最终图像。

## GPT Image 2.6 Flare：文生图

根据文本提示词生成海报。该模板要求渲染文字并采用密集排版，这正是 Flare 的速度优势所在：你可以反复调整措辞，而无需每次都付出最终质量的成本。
