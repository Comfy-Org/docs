[OpenRouter](https://openrouter.ai) 是一个统一的大语言模型路由平台，通过单一 API 对接多家模型服务商，便于在不同模型之间切换而无需更换集成方式。ComfyUI 通过 **OpenRouter LLM** 合作伙伴节点接入，在一个节点内提供精选的文本与多模态模型，包括 Claude、GPT、Gemini、Grok、DeepSeek、Qwen、Mistral、GLM、Kimi 以及 Perplexity Sonar。

<ReqHint/>
<UpdateReminder/>

## OpenRouter LLM 擅长什么

- **文本聊天**：提示词，以及用于角色或任务指令的可选 `system_prompt`
- **视觉**：在受支持的模型上附加参考图像（槽位数量取决于模型）
- **视频输入**：Gemini 3.5 Flash 和 Qwen 3.6 Plus/Flash 支持可选的参考视频
- **推理**：推理 / 前沿推理模型支持 `reasoning_effort`（`off`、`low`、`medium`、`high`）
- **网络搜索**：Perplexity Sonar 模型提供 `search_context_size`，用于生成有依据的答案

Token 定价详见 [合作伙伴节点定价](/zh/tutorials/partner-nodes/pricing#openrouter)。

## 随模型变化的输入项

**model** 为动态下拉：切换模型后，节点会更新显示的输入项：

- **图片槽位** — 仅视觉模型显示，数量与模型上限一致
- **视频槽位** — 仅 Gemini 3.5 Flash、Qwen 3.6 Plus/Flash 显示
- **推理强度** — 推理类 / 前沿推理类模型显示
- **搜索上下文大小** — Perplexity Sonar 系列显示

纯文本模型不显示图片与视频输入。

<Note>
在该示例中，工作流会分析参考图片，并为下游图像节点返回一个文生图提示词。你可以省略 **Load Image**、修改提示词，或完全按自己的用例重新搭建工作流。
</Note>

若以该模板为参考，一次典型运行大致如下：

1. 在 **Load Image** 中加载参考图（纯文本对话可跳过）
2. 在 **OpenRouter LLM** 中将图片连接到 `image_1`（模型支持时会出现更多槽位）
3. 填写 **prompt**，例如让模型分析图片并输出生成提示词
4. （可选）在高级选项中设置 **system_prompt** 来约束语气、格式或限制
5. 选择 **model**；如显示 **reasoning_effort** 或 **search_context_size** 可按需调整
6. 点击 **Run** 或按 `Ctrl(cmd) + Enter` 执行
7. 在 **Preview Any** 中查看回复

### 补充说明

- **seed**：设为 `0` 表示不传；多数模型仅将其视为提示
- 运行工作流时，参考图片和视频会自动上传；你只需将 ComfyUI 的图像/视频输出连接到节点
- 各模型价格见 [定价页 OpenRouter 章节](/zh/tutorials/partner-nodes/pricing#openrouter)
