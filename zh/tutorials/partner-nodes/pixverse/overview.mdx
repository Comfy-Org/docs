PixVerse 是一个 AI 视频生成平台，可根据文本和图像产出电影级的视频，现已作为 ComfyUI 的合作节点集成。它支持 **V5.6**、**V6**、**C1** 和 **R1** 模型，提供**文生视频**、**图生视频**和**模板图生视频**模式，无需单独的 API 密钥或外部配置，即可快速、可重复地创建视频。

<ReqHint/>
<UpdateReminder/>

## 核心能力

- **文生视频**：根据文本提示生成原创视频，非常适合概念可视化、分镜设计和快速创意探索。
- **图生视频**：让参考图像动起来，同时保留主体身份与场景构图，用自然的运动为静态画面注入生命力。
- **模板图生视频**：将预定义的运动模板应用到输入图像，得到可预测、可重复的动画风格，适合生产流程使用。
