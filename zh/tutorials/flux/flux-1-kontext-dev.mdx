## 关于 FLUX.1 Kontext Dev

FLUX.1 Kontext 是 Black Forest Labs 推出的突破性多模态图像编辑模型，支持同时输入文本和图像，能够智能理解图像上下文并执行精准编辑。其开发版本是一个拥有 120 亿参数的开源扩散变换器（diffusion transformer）模型，具备出色的上下文理解能力和角色一致性保持能力，确保即使经过多次迭代编辑，角色特征和构图布局等关键元素仍能保持稳定。

它与 FLUX.1 Kontext 套件具有相同的核心能力：
- 角色一致性：在多个场景和环境中保留图像中的独特元素，例如参考角色或图像中的对象。
- 编辑：对图像中的特定元素进行有针对性的修改，而不影响其他部分。
- 风格参考：根据文本提示词生成新颖场景，同时保留参考图像的独特风格。
- 交互速度：图像生成和编辑的延迟极低。

虽然之前发布的 API 版本提供最高的保真度和速度，但 FLUX.1 Kontext [Dev] 完全在本地机器上运行，为希望进行实验的开发者、研究人员和高级用户提供了无与伦比的灵活性。

### 版本信息

- **[FLUX.1 Kontext [pro]**：商业版本，专注于快速迭代编辑
- **FLUX.1 Kontext [max]**：实验版本，具有更强的提示词遵循能力
- **FLUX.1 Kontext [dev]**：开源版本（本教程使用），12B 参数，主要用于研究

目前在 ComfyUI 中，你可以使用所有这些版本，其中 [Pro 和 Max 版本](/zh/tutorials/partner-nodes/black-forest-labs/flux-1-kontext) 可以通过合作节点调用，而 Dev 开源版本请参考本指南中的说明。

### 2. 逐步完成工作流

![Workflow Step Guide](/images/tutorial/flux/flux_1_kontext_dev_basic_step_guide.jpg)
你可以参考图中的编号来完成工作流的运行：

1. 在 `Load Diffusion Model` 节点中加载 `flux1-dev-kontext_fp8_scaled.safetensors` 模型
2. 在 `DualCLIP Load` 节点中，确保加载了 `clip_l.safetensors` 和 `t5xxl_fp16.safetensors` 或 `t5xxl_fp8_e4m3fn_scaled.safetensors`
3. 在 `Load VAE` 节点中，确保加载了 `ae.safetensors` 模型
4. 在 `Load Image(from output)` 节点中，加载提供的输入图像
5. 在 `CLIP Text Encode` 节点中修改提示词，仅支持英文
6. 点击 `Queue` 按钮，或使用快捷键 `Ctrl(cmd) + Enter` 运行工作流
