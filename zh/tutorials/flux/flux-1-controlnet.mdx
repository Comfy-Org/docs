## FLUX.1 ControlNet 模型介绍

FLUX.1 Canny 和 Depth 是由 [Black Forest Labs](https://blackforestlabs.ai/) 推出的 [FLUX.1 Tools 套件](https://blackforestlabs.ai/flux-1-tools/) 中的两个强大模型。这套工具旨在为 FLUX.1 添加控制和引导能力，使用户能够修改和重新创建真实或生成的图像。

**FLUX.1-Depth-dev** 和 **FLUX.1-Canny-dev** 都是 12B 参数的 Rectified Flow Transformer 模型，能够基于文本描述生成图像，同时保持输入图像的结构特征。其中 Depth 版本通过深度图提取技术来维持源图像的空间结构，而 Canny 版本则利用边缘检测技术来保持源图像的结构特征，使得用户可以根据不同需求选择合适的控制方式。

这两个模型都具有以下特点：
- 顶级的输出质量和细节表现
- 出色的提示词遵循能力，同时保持与原始图像的一致性
- 使用引导蒸馏技术训练，提高效率
- 开放权重供研究社区使用
- 提供 API 接口（pro 版）和开源权重（dev 版）

此外，Black Forest Labs 还提供了从完整模型中提取的 **FLUX.1-Depth-dev-lora** 和 **FLUX.1-Canny-dev-lora** 适配器版本，它们可以应用于 FLUX.1 [dev] 基础模型，以较小的文件体积提供类似的功能，特别适合资源受限的环境。

本文将以完整版本的 **FLUX.1-Canny-dev** 和 **FLUX.1-Depth-dev-lora** 来完成工作流示例。

<Tip>
所有工作流图像的元数据都包含对应模型的下载信息。你可以通过以下方式加载工作流：将其直接拖入 ComfyUI，或者使用菜单 `Workflows` -> `Open（ctrl+o）`。

如果你没有使用桌面版，或者某些模型无法自动下载，请参考手动安装部分，将模型文件保存到对应的文件夹。

对于图像预处理器，你可以使用以下自定义节点来完成图像的预处理，在本示例中，我们将提供处理过的图片作为输入。
- [ComfyUI-Advanced-ControlNet](https://github.com/Kosinkadink/ComfyUI-Advanced-ControlNet)
- [ComfyUI ControlNet aux](https://github.com/Fannovel16/comfyui_controlnet_aux)
</Tip>

### 2. 手动模型安装

<Note>
如果你之前使用过 [Flux 相关工作流的完整版本](/zh/tutorials/flux/flux-1-text-to-image)，那么你只需下载 **flux1-canny-dev.safetensors** 模型文件。

</Note>

完整模型列表：
- [clip_l.safetensors](https://huggingface.co/comfyanonymous/flux_text_encoders/blob/main/clip_l.safetensors?download=true)
- [t5xxl_fp16.safetensors](https://huggingface.co/comfyanonymous/flux_text_encoders/blob/main/t5xxl_fp16.safetensors?download=true)
- [ae.safetensors](https://huggingface.co/black-forest-labs/FLUX.1-schnell/blob/main/ae.safetensors?download=true)
- [flux1-canny-dev.safetensors](https://huggingface.co/black-forest-labs/FLUX.1-Canny-dev/blob/main/flux1-canny-dev.safetensors?download=true)（请确保你已同意对应仓库的条款）

文件存储位置：
```
ComfyUI/
├── models/
│   ├── text_encoders/
│   │   ├── clip_l.safetensors
│   │   └── t5xxl_fp16.safetensors
│   ├── vae/
│   │   └── ae.safetensors
│   └── diffusion_models/
│       └── flux1-canny-dev.safetensors
```

### 3. 逐步执行工作流

![ComfyUI Flux.1 Canny Controlnet 步骤流程](/images/tutorial/flux/flow_diagram_flux_1_canny_dev.jpg)

1. 确保在 `Load VAE` 节点中加载了 `ae.safetensors`
2. 确保在 `Load Diffusion Model` 节点中加载了 `flux1-canny-dev.safetensors`
3. 确保在 `DualCLIPLoader` 节点中加载了以下模型：
   - clip_name1: t5xxl_fp16.safetensors
   - clip_name2: clip_l.safetensors
4. 在 `Load Image` 节点中上传提供的输入图像
5. 点击 `Queue` 按钮，或使用快捷键 `Ctrl(cmd) + Enter` 运行工作流

### 3. 逐步执行工作流

![ComfyUI Flux.1 Depth Controlnet 步骤流程图](/images/tutorial/flux/flow_diagram_flux_1_depth_dev_lora.jpg)

1. 确保 `Load Diffusion Model` 节点中加载了 `flux1-dev.safetensors`
2. 确保 `LoraLoaderModelOnly` 节点中加载了 `flux1-depth-dev-lora.safetensors`
3. 确保 `DualCLIPLoader` 节点中加载了以下模型：
   - clip_name1: t5xxl_fp16.safetensors
   - clip_name2: clip_l.safetensors
4. 在 `Load Image` 节点中上传提供的输入图像
5. 确保 `Load VAE` 节点中加载了 `ae.safetensors`
6. 点击 `Queue` 按钮，或使用快捷键 `Ctrl(cmd) + Enter` 运行工作流
