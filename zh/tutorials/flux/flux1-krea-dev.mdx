[Flux.1 Krea Dev](https://huggingface.co/black-forest-labs/FLUX.1-Krea-dev) 是由 Black Forest Labs (BFL) 与 Krea 合作开发的先进文生图模型。这是目前最好的开源 FLUX 模型，专为文生图而设计。

**模型特点**

- **独特美学风格**: 专注于生成具有独特美学的图像，避免常见的"AI感"外观
- **自然细节**: 不会产生过曝的高光，保持自然的细节表现
- **卓越的真实感**: 提供出色的真实感和图像质量
- **完全兼容架构**: 与 FLUX.1 [dev] 完全兼容的架构设计

**模型许可**
该模型采用 [flux-1-dev-non-commercial-license](https://huggingface.co/black-forest-labs/FLUX.1-Krea-dev/blob/main/LICENSE.md) 许可发布

#### 2. 手动安装模型

请下载以下模型文件：
**扩散模型**

- [flux1-krea-dev_fp8_scaled.safetensors](https://huggingface.co/Comfy-Org/FLUX.1-Krea-dev_ComfyUI/blob/main/split_files/diffusion_models/flux1-krea-dev_fp8_scaled.safetensors)

如果您追求更高画质并且有足够显存，可以尝试原始模型权重

- [flux1-krea-dev.safetensors](https://huggingface.co/black-forest-labs/FLUX.1-Krea-dev/blob/main/flux1-krea-dev.safetensors) 

<Note>
`flux1-dev.safetensors` 文件需要先同意 [black-forest-labs/FLUX.1-Krea-dev](https://huggingface.co/black-forest-labs/FLUX.1-Krea-dev/) 协议才能通过浏览器下载。
</Note>

如果您之前使用过 Flux 相关的工作流，以下模型是相同的，无需再次下载

**文本编码器**
- [clip_l.safetensors](https://huggingface.co/comfyanonymous/flux_text_encoders/blob/main/clip_l.safetensors?download=true)
- [t5xxl_fp16.safetensors](https://huggingface.co/comfyanonymous/flux_text_encoders/blob/main/t5xxl_fp16.safetensors?download=true) 推荐当显存大于32GB时使用。
- [t5xxl_fp8_e4m3fn.safetensors](https://huggingface.co/comfyanonymous/flux_text_encoders/blob/main/t5xxl_fp8_e4m3fn.safetensors) 适用于低显存

**VAE**
- [ae.safetensors](https://huggingface.co/black-forest-labs/FLUX.1-schnell/blob/main/ae.safetensors?download=true)

文件保存位置：
```
ComfyUI/
├── models/
│   ├── diffusion_models/
│   │   └── flux1-krea-dev_fp8_scaled.safetensors 或 flux1-krea-dev.safetensors
│   ├── text_encoders/
│   │   ├── clip_l.safetensors
│   │   └── t5xxl_fp16.safetensors 或 t5xxl_fp8_e4m3fn.safetensors
│   ├── vae/
│   │   └── ae.safetensors

```

#### 3. 逐步验证确保工作流正常运行

<Tip>
    对于低显存用户，此模型可能无法在您的设备上流畅运行，您可以等待社区提供 FP8 或 GGUF 版本。
</Tip>

请参考下图确保所有模型文件已正确加载

![ComfyUI Flux Krea Dev 工作流](/images/tutorial/flux/flux_1_krea_dev_guide.jpg)

1. 确保 `Load Diffusion Model` 节点中加载了 `flux1-krea-dev_fp8_scaled.safetensors` 或 `flux1-krea-dev.safetensors`
    - `flux1-krea-dev_fp8_scaled.safetensors` 推荐给低显存用户
    - `flux1-krea-dev.safetensors` 是原始权重，如果您有足够的显存（如24GB），可以使用它以获得更好的质量
2. 确保 `DualCLIPLoader` 节点中加载了以下模型：
   - clip_name1: t5xxl_fp16.safetensors 或 t5xxl_fp8_e4m3fn.safetensors
   - clip_name2: clip_l.safetensors
3. 确保 `Load VAE` 节点中加载了 `ae.safetensors`
4. 点击 `Queue` 按钮，或使用快捷键 `Ctrl(cmd) + Enter` 运行工作流
