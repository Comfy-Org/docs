## 关于 FLUX.3 [klein]

FLUX.3 [klein] 是 Black Forest Labs 面向本地 ComfyUI 的开源权重 FLUX.3 图像模型：同一系列内同时覆盖文生图与指令驱动的图像编辑，并包含完整版 checkpoint 与步数蒸馏变体，可实现更快的 4–16 步运行。权重以 FLUX Kommunity License 发布于 Hugging Face：下载一次，即可在自己的 GPU 上运行，无需 API 密钥，也不按图像扣除积分。

需要改用托管路径？FLUX.3 也可通过合作伙伴节点 [FLUX 3 Image](/zh/tutorials/partner-nodes/black-forest-labs/flux-3-image) 运行（按图像计费）。在自己的 GPU 上使用本地 klein 权重；想要免下载的托管模型时，则使用合作伙伴节点。

**模型亮点：**

- 文生图与图像编辑共用同一份权重；编辑接收指令提示词加参考图像
- 两个 checkpoint：完整版 Flux.3 Image Klein，以及用于 4–16 步无需引导采样的 Distilled
- 通过 `<ref_image_0>`、`<ref_image_1>` 等实现多参考图提示
- 可选的 Qwen3.5 9B 提示词上采样器，可在生成前把简短请求扩展为完整描述
- 单文件 checkpoint，提供 bf16、int8（convrot）和 nvfp4 版本，搭配 Qwen3-VL-4B 文本编码器与 Flux 2 VAE

**许可证**：[FLUX Kommunity License](https://huggingface.co/black-forest-labs/flux-3-image-klein-comfy/blob/main/LICENSE.md)

**版本要求**：Flux.3 Klein 模板需要 ComfyUI 0.41.0 或更高版本（随 0.41.1 向后移植版本发布，ComfyUI#17070）。

## Flux.3 Image Klein 工作流

### Flux.3 Image Klein：文本到图像 {#image_flux3_klein_t2i}

仅凭提示词生成图像，无需任何输入文件。该工作流是一个子图：打开它即可访问加载器、采样器和画布尺寸。

<img src="https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/templates/image_flux3_klein_t2i-1.webp" alt="Flux.3 Image Klein 文本到图像工作流预览" />

  <Card title="下载工作流" icon="download" href="https://github.com/Comfy-Org/workflow_templates/blob/main/templates/image_flux3_klein_t2i.json">
    下载 JSON，或在模板库中搜索 &quot;Flux.3 Image Klein: Text to Image&quot;
  </Card>
</CardGroup>

1. 在子图的正向提示词组件中输入你的提示词
2. 设置 `width` 和 `height`，或者从 `ResolutionSelector` 中选择一个画幅（默认为 1:1 正方形）
3. 调整 `steps`（默认 25）和 `cfg`（默认 3.5）。模板中附有一条备注，建议尝试 50 步以获得更好的质量
4. 保持 `enable_prompt_upsampler` 关闭，则根据你自己的文字生成；开启后，会先用 Qwen3.5 9B 上采样器扩展提示词
5. 点击 **Queue**。图像由 `SaveImage` 节点保存到 `ComfyUI/output/`

### Flux.3 Image Klein 蒸馏版：文生图 {#image_flux3_klein_distilled_t2i}

使用步数蒸馏版 checkpoint 根据提示词生成图像，它无需引导即可在 15 步内完成。此处默认开启提示词上采样，因此简短的提示词会在采样前被扩展为完整的描述。

## 提示词与参考图技巧

- **写出结果，而不是改动。** 图像编辑模板期望得到的是一段对最终图像的完整描述，并把编辑融入其中，这正是示例会详细描述新对象、而不是说"把这里改一下"的原因。
- **参考图会被加入两个条件中。** 按顺序把额外图像连接到 `Set Reference Multi Latent`，用 `<ref_image_0>`、`<ref_image_1>` 等来引用它们，并像参考 pipeline 那样把每一张同时加入正面和负面提示词。
- **参考图尺寸是一档成本调节。** 模板会把每张参考图调整大小到约 100 万像素，输出 Latent 也采用该尺寸。保持参考图的原始尺寸（Black Forest Labs 自家的 pipeline 最高可到约 1600 万像素）能让编辑保留更多细节，但成本也更高。
- **步数取决于 checkpoint。** 在模板中，完整 checkpoint 以 25 步、引导 3.5 运行，并附有可尝试 50 步以获得更好质量的提示。步数蒸馏版 checkpoint 以 15 或 16 步运行，引导固定为 1，想要快速跑一遍时就用它。
- **模板自带 `Create Bounding Boxes` 节点。** 它会在来源图像上绘制边界框，用于规划区域编辑，其边界框列表显示在 `Preview Any` 节点中，方便你把这些区域融入提示词。
