Ideogram 4.0 是 Ideogram 最新的文生图模型，以开源模型的形式发布，可完全在你自己的硬件上运行。它提供卓越的照片级真实感质量、准确的文本渲染和精准的风格控制。你可以使用普通的自然语言，或使用**结构化 JSON 提示词**来精细控制布局、颜色和图中文字。

<UpdateReminder/>

### 提示词格式

开源工作流支持两种提示词模式：

1. **自然语言**：快速简便，最适合简单的创意
2. **结构化 JSON**：用于精确控制布局、颜色和风格

工作流中包含一个提示词构建模板，你可以配合任意 LLM 使用它来生成匹配的 JSON 提示词。

工作流内的注释解释道：
> 该模型使用结构化 JSON 描述（场景摘要、风格块、背景，以及可选的带边界框和十六进制调色板的逐对象描述）进行训练。官方推理会针对该 schema 验证提示词。

### 工作流步骤

1. 下载模型并放入正确的目录（见上表）
2. 下载工作流文件并拖入 ComfyUI
3. 在 Ideogram4 子图节点中输入你的提示词（自然语言或结构化 JSON）
4. （可选）使用 `ResolutionSelector` 节点调整分辨率
5. 点击 `Run` 或使用快捷键 `Ctrl(cmd) + Enter` 生成图像
6. 在 `Save Image` 节点中查看结果，输出文件保存在 `ComfyUI/output/`

### 关于安全过滤器的说明

如果你看到 "Image blocked by safety filter"，这是 Ideogram 4.0 的内置安全过滤器。非 JSON（纯文本）提示词的误报率更高。使用结构化 JSON 提示词可以降低提示词被拦截的概率。

更多详情请参阅 [Ideogram 4 官方提示词指南](https://github.com/ideogram-oss/ideogram4/blob/main/docs/prompting.md#safety-filter)。
