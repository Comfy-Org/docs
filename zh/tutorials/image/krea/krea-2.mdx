**Krea 2** 是来自 [Krea AI](https://www.krea.ai) 的图像生成模型，从零开始训练，专注于创意与风格探索。

Krea 2 以两个相互配合的模型形式发布：**在 RAW 上训练 LoRA，在 Turbo 上运行推理**：
- **Krea 2 RAW**：采用全步数采样（52 步）的基础模型。未经蒸馏，多样且可塑性强，非常适合微调和 LoRA 训练。
- **Krea 2 Turbo**：用于快速、高质量生成的 8 步蒸馏 checkpoint。在 RAW 上训练的 LoRA 可以无缝应用于 Turbo。

## Krea-2 Turbo 文生图工作流

### Krea-2：文生图 (`image_krea2_turbo_t2i`)

使用 Krea 2 从文本提示词生成图像。这是一个为美学质量和创意控制而构建的基础模型，专注于渲染富有表现力、风格多样的图像。

该工作流由以下几个部分组成：

1. **Text to Image (Krea-2 Turbo) 子图**：核心生成管线，包含模型加载、提示词处理、采样和 VAE 解码
2. **ResolutionSelector**：选择你想要的输出分辨率。Krea 2 支持 1K 到 2K 的输出。将兆像素值设为 2.0 即可获得 2K 分辨率。
3. **CustomCombo (LoRA 选择器)**：为可用的风格 LoRA 预置的触发词选择器。如果你下载了额外的 LoRA，可以自定义此选择器，并将其与对应的 LoRA 文件配对。
4. **SaveImage**：保存生成的图像

### 一键生成

最简单的用法是：只需在子图中输入文本提示词，选择分辨率，然后点击 **Queue Prompt**。默认设置（8 步、启用提示词增强、无 LoRA）即可在最少配置下生成高质量图像。

### 工作流控制项

**Text to Image (Krea-2 Turbo)** 子图暴露了以下控制项：

| 控制项 | 描述 |
|---------|-------------|
| **Text String (User Prompt)** | 描述你想要生成的图像的文本提示词 |
| **prompt_enhance** | 开启/关闭 LLM 驱动的提示词扩展 |
| **LLM_max_token** | 提示词增强的最大 token 长度 |
| **Width / Height** | 输出分辨率（由 ResolutionSelector 控制） |
| **Seed** | 用于可复现性的随机种子 |
| **enable_lora?** | 启用或禁用风格 LoRA |
| **LoRA Strength** | 所应用风格 LoRA 的强度 |
| **LoRA Trigger Word** | 所选 LoRA 的触发词（自动填充） |

风格参考工作流在 Krea-2 Turbo 管线的基础上增加了参考图像条件。上传一张或多张参考图像，以影响生成输出的美学风格、氛围和视觉方向。

该工作流由以下几个部分组成：

1. **Image Style Reference (Krea-2 Turbo) 子图**：支持风格参考的核心生成管线，包含模型加载、参考图像条件、提示词处理和采样
2. **LoadImage**：上传你的风格参考图像
3. **ResolutionSelector**：选择你想要的输出分辨率。Krea 2 支持 1K 到 2K 的输出。
4. **SaveImage**：保存生成的图像

### 使用风格参考

1. **上传参考图像**：使用 **LoadImage** 节点加载一张或多张风格参考图像
2. **输入提示词**：在子图的用户提示词输入框中输入文本描述
3. **选择模型变体**：在子图的模型选择器中选择模型 checkpoint
4. **调整设置**：配置分辨率、种子，并可选择启用提示词增强
5. **点击 Queue**：按 `Ctrl+Enter` 生成

此风格参考工作流使用专用的 diffusion 模型和 LoRA。文本编码器和 VAE 与文生图工作流共用。
