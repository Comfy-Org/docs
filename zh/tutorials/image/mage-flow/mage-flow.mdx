**Mage-Flow** 是微软研究院推出的一款紧凑型 4B 规模生成式模型栈，用于高效的文生图和基于指令的图像编辑。该模型栈由两个协同设计的组件构成：[Mage-VAE](https://huggingface.co/microsoft/Mage-VAE)（一个轻量级高保真潜在编码器）以及一个通过整流流匹配（rectified flow matching）训练的原生分辨率多模态扩散 Transformer（NR-MMDiT）。结合原生分辨率打包技术，该共享模型栈驱动了两个模型实例：用于文生图的 Mage-Flow 和用于基于指令图像编辑的 Mage-Flow-Edit。每个实例都提供 Base（基础版）、RL-aligned（强化学习对齐版）和 4-step Turbo（4步 Turbo 版）三种变体。

Mage-Flow 支持每边 512 到 2048 像素的原生分辨率，适应任意宽高比，包括 4:1 等极端尺寸。

该工作流分为以下几个部分：

1. **Text to Image（Mage-Flow）子图**：核心生成管线，包含模型加载、提示词处理、原生分辨率潜在空间生成、采样和 VAE 解码
2. **SaveImageAdvanced**：保存生成的图像

### 一键生成

最简单的用法：在子图中输入文本提示词，设置所需分辨率，然后点击 **Queue Prompt**。默认设置即可在最小配置下生成高质量图像。

### 使用工作流

1. **输入提示词** — 在子图的提示词输入框中输入文本描述
2. **设置分辨率** — 调整宽度和高度以设置所需的输出尺寸。Mage-Flow 支持每边 512 到 2048 像素的原生分辨率
3. **调整设置** — 根据需要配置随机种子（seed）和负向提示词（negative prompt）
4. **点击 Queue** — 按 `Ctrl+Enter` 生成

图像编辑工作流使用 Mage-Flow-Edit，这是一个基于指令的模型，可通过自然语言描述来编辑图像。上传一张或多张参考图像，然后描述所需的编辑操作。

该工作流分为以下几个部分：

1. **LoadImage**：上传你的参考图像（最多 3 张）
2. **Image Edit（Mage-Flow-Edit）子图**：核心编辑管线，包含模型加载、参考图像条件化、提示词处理和采样
3. **ImageCompare**：并列对比原始图像和编辑后的图像
4. **SaveImage**：保存编辑后的输出

### 使用图像编辑

1. **上传参考图像** — 使用 **LoadImage** 节点加载你想要编辑的图像（最多 3 张）
2. **输入编辑指令** — 输入文本描述你想要进行的编辑操作（例如："将背景替换为海滩场景" 或 "将其转换为水彩画风格"）
3. **调整设置** — 配置分辨率、随机种子（seed）和其他参数
4. **点击 Queue** — 按 `Ctrl+Enter` 生成
