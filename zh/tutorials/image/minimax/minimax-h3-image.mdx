**MiniMax-H3-Image** 是 MiniMax 的开放权重图像模型，一个 checkpoint 同时覆盖文生图与图像编辑。其扩散 Transformer 为 33.1B 参数，采用 BF16 精度，并蒸馏为无需 CFG 的 6 步采样器。原生输出约为 16 MP，因此 4096 x 4096 的图像只需一次生成，而无需经过 upscale 链路。

- [MiniMax-H3-Image (ModelScope)](https://modelscope.cn/models/minimax/MiniMax-H3-Image)：面向中国大陆的官方镜像

- [Comfy-Org/MiniMax-H3 (Hugging Face)](https://huggingface.co/Comfy-Org/MiniMax-H3)：该模型使用的 Qwen3-VL-32B 文本编码器
- [MiniMaxAI/MiniMax-H3-Image-PE (Hugging Face)](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image-PE)：官方提示词扩展器

## 主要特性

- **在一个 checkpoint 中完成文生图与图像编辑**：无需加载单独的编辑模型或适配器
- **6 步采样**：引导固定为 1，因此没有 CFG 计算，也不需要负面提示词
- **原生约 16 MP**：4096 x 4096 至 6272 x 2688，无需额外的放大流程
- **多参考图**：最多 16 张输入图像，在提示词中从 `<Picture 1>` 起依次引用
- **可选的提示词扩展器**：将简短的请求转换为模型最容易理解的详细描述
- **开放权重**：在 ComfyUI 中完全本地可控

## 采样与画布尺寸 {#sampling-and-canvas-size}

两个模板均采用蒸馏调度方案：

| 设置 | 值 |
| --- | --- |
| 采样器 | euler |
| 调度器 | simple |
| 步数 | 6 |
| 引导（CFG） | 1 |
| 降噪 | 1 |

引导值为 1 时不存在无分类器引导（classifier-free guidance）过程，因此模板中不携带负面提示词。请把所有你想要的内容，包括需要避免的内容，都写进正向提示词中。

原生输出约为 16 MP。每条边都生成于 32 px 的倍数，任意宽度和高度均可接受。以下尺寸覆盖了常见的比例：

| 宽高比 | 尺寸（宽度 x 高度） |
| --- | --- |
| 1:1 | 4096 x 4096 |
| 4:3 | 4736 x 3552 |
| 3:4 | 3552 x 4736 |
| 3:2 | 5024 x 3360 |
| 2:3 | 3360 x 5024 |
| 16:9 | 5472 x 3072 |
| 9:16 | 3072 x 5472 |
| 21:9 | 6272 x 2688 |

更小的画布同样可行，且耗时更少。在文生图模板中，分辨率选择器分别设置宽高比和目标百万像素数，因此 4 MP 只是起点，而非上限。

### 修复文生图输出的过度处理

纯文生图的输出有时会过度处理：毛孔和痣被放大，皮肤与布料显得干硬起壳。把任意一张图接到 `MiniMax H3 Image Conditioning` 的 `images` 输入即可改善。调大画布没用，这些问题在 16 MP 下依然存在。

条件节点位于 Text to Image 子图内部。在子图里添加一个 `Load Image` 节点，连到 `images` 输入。图里画什么不影响效果，空白图片同样有效。

断开条件节点的 `vae` 输入，开销就只剩视觉 token。此时图片只经过文本编码器，`VAEDecode` 自己保留的 VAE 连接不受影响。图片小一点就够，节点会统一缩放到 1024 px 短边。

## 图像编辑中的参考图像

图像编辑模板会将来源图像作为 `<Picture 1>` 发送给模型。额外图像会按顺序标记为 `<Picture 2>`、`<Picture 3>`，最多支持 16 个参考图像，提示词会通过各自的标签来引用这些图像。第一张图像是待编辑的图像；其余图像提供身份、道具、材质或构图。简短的指令就足够了，例如将 `<Picture 1>` 中的车辆替换为 `<Picture 2>` 中的车辆。

要添加参考图像，请在工作流中再放置一个 `Load Image` 节点，并将其同时连接到提示词生成步骤和条件节点。请保持条件节点上的 VAE 输入已连接：模板已经接好，接入 VAE 时参考图还会作为图像 latent 参与条件。未接入时它们只经过文本编码器，编辑结果与来源图像的贴合度会下降。

参考图像无需任何预处理。模板会先把来源图像缩放到 4 MP，再取整为 32 px 的倍数。条件节点会自行缩放内部副本：视觉侧使用 1024 px 的短边，VAE 侧使用限制在 1024 到 2048 px 之间的短边，两者都对齐到 32 px 网格。

编辑结果约为 4 MP，与来源图像的尺寸无关，而不是模型的 16 MP。需要更大的编辑结果时，在设置为 `scale total pixels` 的 `Resize Image/Mask` 节点中提高目标值；内存不足时则在采样前降低它。模板包 0.11.104 中该节点默认处于旁路状态，目标值是 1 MP：选中后按 `Ctrl-B` 启用，再设置目标值。

## 提示词扩展器

两个模板都在采样器之前放置了一个文本生成步骤。在文生图模板中，它会把提示词改写为一段详细的英文描述，并为画布选定一个宽高比例。在图像编辑模板中，它会把简短的指令转换为一段带有参考信息的、对已完成图像的描述。

MiniMax-H3-Image 的官方扩展器是一个 Qwen3.8-27B FP4 模型，发布在 [MiniMaxAI/MiniMax-H3-Image-PE](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image-PE)。模板使用的是更轻量的 Qwen3.5 9B W4A8 版本，因此扩展器可以与 21 GB 的 diffusion 模型一起装在单张 GPU 上。

文生图模板出厂时关闭了扩展器，因此你的提示词会按原样送入模型；当你希望自动改写描述并选择宽高比例时，可以将其开启。图像编辑模板出厂时已开启扩展器。
