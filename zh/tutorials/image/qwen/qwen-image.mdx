**Qwen-Image** 是阿里巴巴 Qwen 团队发布的首个图像生成基础模型。它是一个拥有 20B 参数的 MMDiT（多模态扩散变换器）模型，基于 Apache 2.0 许可证开源。该模型在**复杂文本渲染**和**精准图像编辑**方面取得了重大进展，能够为包括英文和中文在内的多种语言实现高保真输出。

**模型亮点**：
- **出色的多语言文本渲染**：支持英文、中文、韩文、日文等多种语言的高精度文本生成，保持字体细节和排版一致性
- **多样的艺术风格**：从写实场景到印象派绘画，从动漫美学到极简设计，能够流畅适应各种创意提示词

**相关链接**：
 - [GitHub](https://github.com/QwenLM/Qwen-Image)
 - [Hugging Face](https://huggingface.co/Qwen/Qwen-Image)
 - [ModelScope](https://modelscope.cn/models/qwen/Qwen-Image)

目前 Qwen-Image 有多个 ControlNet 支持选项可用：
- [Qwen-Image-DiffSynth-ControlNets/model_patches](https://huggingface.co/Comfy-Org/Qwen-Image-DiffSynth-ControlNets/tree/main/split_files/model_patches)：包含 canny、depth 和 inpaint 模型
- [qwen_image_union_diffsynth_lora.safetensors](https://huggingface.co/Comfy-Org/Qwen-Image-DiffSynth-ControlNets/blob/main/split_files/loras/qwen_image_union_diffsynth_lora.safetensors)：支持 canny、depth、pose、lineart、softedge、normal、openpose 的图像结构控制 LoRA
- InstantX ControlNet：待更新

### 3. 工作流使用说明

![Step Guide](/images/tutorial/image/qwen/image_qwen_image-guide.jpg)

1. 确保 `Load Diffusion Model` 节点已加载 `qwen_image_fp8_e4m3fn.safetensors`
2. 确保 `Load CLIP` 节点已加载 `qwen_2.5_vl_7b_fp8_scaled.safetensors`
3. 确保 `Load VAE` 节点已加载 `qwen_image_vae.safetensors`
4. 确保 `EmptySD3LatentImage` 节点设置了正确的图像尺寸
5. 在 `CLIP Text Encoder` 节点中设置你的提示词；目前至少支持英文、中文、韩文、日文、意大利文等
6. 如果你想启用 lightx2v 的 8 步加速 LoRA，选中该节点并使用 `Ctrl + B` 启用它，并按照第 8 步的说明修改 Ksampler 设置
7. 点击 `Queue` 按钮，或使用快捷键 `Ctrl(cmd) + Enter` 运行工作流
8. 针对不同的模型版本和工作流，相应调整 KSampler 参数

<Note>
 蒸馏模型和 lightx2v 的 8 步加速 LoRA 似乎不能同时使用。你可以尝试不同的组合来验证它们能否一起使用。
</Note>

### 3. 工作流使用说明

目前 diffsynth 有三个补丁模型：Canny、Depth 和 Inpaint。

如果你是第一次使用 ControlNet 相关的工作流，需要了解：控制图像需要预处理成支持的图像格式后，才能被模型使用和识别。

![Input Type Diagram](/images/tutorial/image/qwen/controlnet_input_types.jpg)

- Canny：经过 canny 边缘处理的线稿轮廓
- Depth：经过预处理的深度图，用于表现空间关系
- Inpaint：需要使用 Mask 标记需要重绘的区域

由于该补丁模型分为三个不同的模型，输入时需要选择正确的预处理类型，以确保图像被正确预处理。

**Canny 模型 ControlNet 使用说明**

![Canny Workflow](/images/tutorial/image/qwen/image_qwen_image_controlnet_patch-canny.jpg)
1. 确保已加载 `qwen_image_canny_diffsynth_controlnet.safetensors`
2. 上传输入图像以进行后续处理
3. Canny 节点是原生预处理节点，会按照你设置的参数对输入图像进行预处理，从而控制生成
4. 如有需要，你可以修改 `QwenImageDiffsynthControlnet` 节点中的 `strength` 来控制线稿控制的强度
5. 点击 `Run` 按钮，或使用快捷键 `Ctrl(cmd) + Enter` 运行工作流

> 使用 qwen_image_depth_diffsynth_controlnet.safetensors 时，你需要将图像预处理为深度图，并替换 `image processing` 部分。关于此用法，请参考本文档中的 InstantX 处理方法。其他部分与使用 Canny 模型类似。

**Inpaint 模型 ControlNet 使用说明**
![Inpaint Workflow](/images/tutorial/image/qwen/image_qwen_image_controlnet_patch-inpaint.jpg)

对于 Inpaint 模型，需要使用[蒙版编辑器](/zh/interface/maskeditor)绘制蒙版，并将其作为输入控制条件。

1. 确保 `ModelPatchLoader` 已加载 `qwen_image_inpaint_diffsynth_controlnet.safetensors` 模型
2. 上传图像并使用[蒙版编辑器](/zh/interface/maskeditor)绘制蒙版。你需要将对应 `Load Image` 节点的 `mask` 输出连接到 `QwenImageDiffsynthControlnet` 的 `mask` 输入，以确保加载对应的蒙版
3. 使用 `Ctrl-B` 快捷键将工作流中原来的 Canny 设置为绕过模式，使对应的 Canny 节点处理失效
4. 在 `CLIP Text Encoder` 中输入你想将蒙版区域改成什么样
5. 如有需要，你可以修改 `QwenImageDiffsynthControlnet` 节点中的 `strength` 来控制对应的控制强度
6. 点击 `Run` 按钮，或使用快捷键 `Ctrl(cmd) + Enter` 运行工作流

下载下面的模型。由于这是一个 LoRA 模型，需要保存到 `ComfyUI/models/loras/` 文件夹
-  [qwen_image_union_diffsynth_lora.safetensors](https://huggingface.co/Comfy-Org/Qwen-Image-DiffSynth-ControlNets/blob/main/split_files/loras/qwen_image_union_diffsynth_lora.safetensors)：支持 canny、depth、pose、lineart、softedge、normal、openpose 的图像结构控制 LoRA

### 3. 工作流使用说明

该模型是一个统一控制 LoRA，支持 canny、depth、pose、lineart、softedge、normal、openpose 控制。由于许多图像预处理原生节点尚未完全支持，你应当使用 [comfyui_controlnet_aux](https://github.com/Fannovel16/comfyui_controlnet_aux) 之类的工具来完成其他图像预处理。

![Union Control LoRA](/images/tutorial/image/qwen/image_qwen_image_union_control_lora.jpg)

1. 确保 `LoraLoaderModelOnly` 已正确加载 `qwen_image_union_diffsynth_lora.safetensors` 模型
2. 上传输入图像
3. 如有需要，你可以调整 `Canny` 节点参数。由于不同的输入图像需要不同的参数设置才能获得更好的预处理效果，你可以尝试调整对应的参数值来获得更多/更少的细节
4. 点击 `Run` 按钮，或使用快捷键 `Ctrl(cmd) + Enter` 运行工作流

> 对于其他类型的控制，你也需要替换图像处理部分。
