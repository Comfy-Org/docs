## Overview

[Comfy Workflows](https://comfy.org/models?type=workflows) is ComfyUI's official community hub. Publishing a workflow gives it a public page on the hub, so other users can find your graph, read your description, and view the sample outputs you attach.

Publishing happens inside ComfyUI, through the **Publish** tab of the workflow share dialog. A workflow can be published again later to push an updated version, and the published page keeps the same link.

## Requirements

- A Comfy Cloud account, signed in to ComfyUI
- A saved workflow
- A creator profile. ComfyUI asks you to create one the first time you publish

## Publish a workflow

In the workflow toolbar, click **Share**, then select the **Publish** tab. If the workflow has not been saved yet, ComfyUI asks you to save it before you can continue.

<Steps>
  <Step title="Describe your workflow">
    Fill in the details that appear on the public page:

    - **Title**: a descriptive name that is easy to search
    - **Workflow description**: what the workflow does and what users should expect from it
    - **Tags**: select from the suggested tags, or type your own, for example `#nanobanana`, `#anime`, or `#faceswap`, so people can find it
  </Step>
  <Step title="Add output examples">
    Pick the thumbnail that represents the workflow, then add up to 8 sample images:

    - **Image**: a single still
    - **Video**: a clip of the result
    - **Image comparison**: a before and after pair

    Click or drag a file into the upload tile to add an example, and reorder the examples to control the order they appear in. Square (1:1) media at 1080p maximum works best.
  </Step>
  <Step title="Finish publishing">
    The last step shows the creator profile the workflow will be published under. If the workflow references private models or media files, ComfyUI lists them and requires you to confirm before publishing. Click **Publish to Comfy Workflows** to finish.
  </Step>
</Steps>

## Create your creator profile

The first time you publish, ComfyUI asks you to create a profile before it opens the publish flow. A profile has a name, a username, a description, a cover image, and a profile picture.

The username is 3 to 42 characters, lowercase letters, numbers, and hyphens only, and it must start and end with a letter or a number. It becomes the address of your public creator page at `comfy.com/p/<username>`.

After you create the profile, click **Upload my workflow** to return to the publish flow and publish your first workflow.

## Update a published workflow

To push changes to a workflow that is already on the hub:

1. Edit the workflow in ComfyUI and save it.
2. Click **Share** and open the **Publish** tab.
3. Click **Update workflow**.

The published page keeps the same link and the same stats. Only the workflow content is refreshed.

## Private models and media

<Warning>
  Publishing a workflow publishes the media files it uses, such as uploaded images, masks, and other files tied to nodes. Anyone can view them on the public page. The last step of the publish flow shows the private models and media it detected and asks you to confirm. Do not publish a workflow that contains private or sensitive content.
</Warning>
