ComfyUI is an open source, node-based application for generative AI. You build **workflows** by connecting nodes on a canvas, where each node performs one step of the process: loading a model, encoding a prompt, sampling an image, and so on. The result is a visual program that generates images, video, audio, or 3D content.

Under the hood, ComfyUI is also an **inference engine**. The same workflows you build visually can run headlessly on a server, be called from an API, or power production applications.

![ComfyUI Interface](/images/interface/overview/comfyui_new_interface.jpg)

## How it works

Everything in ComfyUI revolves around three ideas:

1. **Nodes** are individual building blocks. Each one does a single job, such as loading a checkpoint, encoding text, or decoding a latent into an image.
2. **Links** connect the output of one node to the input of another, defining how data flows through the graph.
3. **Workflows** are complete graphs of nodes and links. They are fully reproducible: a workflow saved as JSON (or embedded in a generated image) can be shared and reloaded by anyone to get the same setup.

This design gives you precise control over every step of generation, rather than a single prompt box that hides the pipeline. See [Basic Concepts](/basic-concepts/workflow) for a deeper introduction.

## Why ComfyUI

- **Open source**: The core engine is free, open source, and runs entirely on your own hardware if you want it to.
- **Reproducible**: Workflows are files. Share them, version them, and reload them with identical results.
- **Extensible**: Thousands of community [custom nodes](/custom-nodes/overview) add new models, tools, and integrations, installable through [ComfyUI-Manager](/manager/overview).
- **Production-ready**: The same graph that runs on your desktop can run on a server or in the cloud through the [developer platform](/development/overview).
