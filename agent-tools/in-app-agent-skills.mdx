## What is a personal skill?

A personal skill is a reusable set of instructions for Comfy Agent. It includes a name, a one-line description of when to use it, and the instructions themselves.

Use personal skills to repeat instructions such as “make square images,” “use a white background,” or “check node connections before running.”

Personal skills are saved to your account. The Agent loads a skill when its description matches your request or when you ask for it by name.

## Create a skill in chat

Tell the Agent what to save, what to call it, and when it should be used:

> Save this as a skill called product-shot: When I ask for a product image, use a square 1024 × 1024 canvas, a neutral gray background, and a Save Image node. Validate the workflow before running it.

The Agent saves the skill for future messages. A new or updated skill takes effect with your next message.

## Manage skills from the agent panel

The **+** menu in the message box has a **Skills** submenu that lists your skills. Pick one to attach it to your message, or choose **Manage skills** to open the Skills screen, where you can add, edit, and delete skills.

![Skills screen in the agent panel](/images/agent_tools/agent_skills_panel.png)

A skill's name can't be changed after it is saved; to rename one, delete it and add it again. Leaving the form without saving keeps what you typed as a draft on this device until you save or discard it.

## Skill fields

| Field | Purpose | Rules |
| --- | --- | --- |
| **Name** | The handle the Agent loads the skill by. | Up to 64 characters, using ASCII letters, digits, `.`, `_` and `-`. The name must be unique, and the names of the built-in skills that always load are reserved. |
| **When to use** | One line that says when to load the skill. It travels with every message, whether or not the skill is used. | A single line of up to 1,024 characters. Keep it short. |
| **Instructions** | What the Agent follows once the skill is loaded. | Required. |

## Size limits

The list shows each skill's size in bytes. Skills share a size budget for your account, and the form refuses a save that would go over it and asks you to remove a skill first.

## Use a skill

Ask for a skill by name:

> Use my product-shot skill to create a studio photo workflow for a red sneaker.

The Agent can also select a skill automatically when your request matches its description. To pick one from your list, type `/` in the message box and choose it from the **Skills** section of the menu.

## Update or delete a skill

Use the same skill name to replace its instructions:

> Update my product-shot skill to use a white background and a 1536 × 1536 canvas.

Delete a skill by name:

> Delete my product-shot skill.

## Save an existing skill file

Paste the contents of your `SKILL.md` file into chat and ask the Agent to save it as a personal skill. The Agent reads its name and description from the header at the top of the file. The saved skill is available from your next message.

## Use a public skill

Public skills are shared skills anyone can use, not just the ones you created. Ask for a public skill by name or describe what you want to do, and the Agent uses it the same way it uses one of your own:

> Use the product-shot public skill for a red sneaker on a neutral gray background.

## Built-in guidance and coding-agent skills

Comfy Agent includes guidance for building workflows and choosing models. Personal and public skills add instructions for repeated tasks on top of that guidance.

[Skills for coding agents](/agent-tools/skills) are installed separately in tools such as Claude Code. Installing one there does not add it to Comfy Agent.

Keep API keys, passwords, and access tokens out of skill instructions. For data handling, see [Data and privacy](/agent-tools/in-app-agent-data-privacy#skills-and-guidance).
