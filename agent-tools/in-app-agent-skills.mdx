## What is a skill pack?

A skill pack is a reusable set of instructions for Comfy Agent. Each pack has a name, a trigger line that says when to load it, and the instructions themselves.

Use packs for preferences you repeat, such as “make square images,” “use a white background,” or “check node connections before running.”

Packs you create are private to your account. The Agent loads a pack when its trigger line matches your request or when you ask for it by name.

## Create a skill in chat

Tell the Agent what to save, what to call it, and when it should be used:

> Save this as a skill called product-shot: When I ask for a product image, use a square 1024 × 1024 canvas, a neutral gray background, and a Save Image node. Validate the workflow before running it.

The Agent saves the skill for future messages. A new or updated skill takes effect with your next message.

## Use a skill

Ask for a skill by name:

> Use my product-shot skill to create a studio photo workflow for a red sneaker.

The Agent can also select a skill automatically when its trigger line matches your request. To pick one from your list, type `/` in the message box and choose it from the **Skills** section of the menu.

## Manage skill packs in Settings

Open **Settings** → **Skill Packs** to see every pack on your account. Each pack is listed with its name and size.

- **Add Skill Pack** opens a form for a new pack.
- **Edit** changes the trigger line or instructions of an existing pack. A pack name cannot be changed after you create it.
- **Delete** removes a pack. Deleting cannot be undone.

## Skill pack fields

| Field | Purpose | Rules |
| --- | --- | --- |
| **Name** | The handle the Agent loads the pack by. | Up to 64 characters, using letters, digits, `.`, `_` and `-`. The name must be unique, and the names of the always-on built-in packs are reserved. |
| **Trigger line** | One line that says when to load the pack. It travels with every message, whether or not the pack is used. | A single line of up to 1,024 characters. Keep it short. |
| **Instructions** | What the Agent follows once the pack is loaded. | Required. |

## Size limits

The pack list shows each pack’s total size in bytes. When you create or edit a pack, the form shows the size of the instructions as you type. Packs count toward a size budget for your account. If a new pack would go over the budget, the form refuses to save it and asks you to remove a pack first.

## Update or delete a skill

Use the same skill name to replace its instructions:

> Update my product-shot skill to use a white background and a 1536 × 1536 canvas.

Delete a skill by name:

> Delete my product-shot skill.

## Save an existing skill file

Paste the contents of your `SKILL.md` file into chat and ask the Agent to save it as a skill pack. The Agent reads its name and description from the header at the top of the file. The saved skill is available from your next message.

## Use a public skill

Public skills are shared skills anyone can use, not just the ones you created. Ask for a public skill by name or describe what you want to do, and the Agent uses it the same way it uses one of your own:

> Use the product-shot public skill for a red sneaker on a neutral gray background.

## Built-in guidance and coding-agent skills

Comfy Agent includes guidance for building workflows and choosing models. Skill packs and public skills add instructions for repeated tasks on top of that guidance.

[Skills for coding agents](/agent-tools/skills) are installed separately in tools such as Claude Code. Installing one there does not add it to Comfy Agent.

Keep API keys, passwords, and access tokens out of skill instructions. For data handling, see [Data and privacy](/agent-tools/in-app-agent-data-privacy#skills-and-guidance).
