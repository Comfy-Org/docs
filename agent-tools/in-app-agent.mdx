**Comfy In-App Agent** is the agent experience inside Comfy Cloud. Describe what you want in chat, and the agent can build or edit workflows on your graph.

## Use the agent

1. Open a workflow in Comfy Cloud.
2. Select **Ask Comfy Agent** in the workflow bar.
3. Choose the workflow the chat should work in. You can also choose **Don't work in a workflow** for questions that do not need graph access.
4. Enter a prompt. Type `@` to reference a node, select **Add nodes from graph**, or attach an image, video, audio file, 3D model, or text file to give the agent more context.
5. Review the proposed graph changes and outputs. The agent can make mistakes, so check the workflow before you run it.

The agent keeps separate chats for your workflow tabs. Use **Chat history** to return to an earlier conversation, rename it, or copy it as Markdown.

## Run permissions

The control beside the send button determines when the agent may run a workflow:

- **Ask before a workflow runs** requires your approval for each run.
- **Auto-run without approval** lets the agent run workflows without asking.
- **Auto-run with limits** asks only when a run would exceed the credit limit you set.

Run permissions affect execution, not editing. The agent can still modify the selected workflow. Review this setting before you send a prompt.

## Review a response

During a turn, the panel shows the agent's progress and the tools it uses. Responses can include formatted text, code, generated media, downloadable assets, and links that open a workflow tab.

Use the thumbs-up or thumbs-down control on a response to rate it. To report a bug or share more detail, use the feedback link below.

## Current alpha boundaries

- Access is feature-flagged and limited to selected Comfy Cloud accounts.
- Work is scoped to the workflow selected in the chat. Check the workflow selector before requesting an edit.
- Agent and human edits can update the same cloud workflow, but broad offline editing and a creator-facing conflict-resolution interface are not part of this alpha.
- If the connection is interrupted, wait for the panel to reconnect before making more edits. Confirm the graph state before running the workflow.
- A stopped or interrupted agent turn does not resume automatically. Start a new turn if needed.
