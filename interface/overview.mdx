The visual interface is how most people drive the [ComfyUI Server](/development/comfyui-server/comms_overview). Use this page as a map of the UI, then open the linked guides for each region and component.

![ComfyUI Basic Interface](/images/interface/overview/comfyui_new_interface.jpg)

The [ComfyUI frontend](https://github.com/Comfy-Org/ComfyUI_frontend) is maintained as its own project. Contributions go to that repository.

## Localization

ComfyUI supports English, Chinese, Russian, French, Japanese, and Korean. Open **Settings**, then under `Comfy` → `Locale` pick your language.

![ComfyUI Localization Support](/images/interface/overview/locale.jpg)

## Workspace map

![ComfyUI Workspace](/images/interface/overview/comfyui-new-interface-main.png)

| Area | What it is |
| --- | --- |
| **Left sidebar** | Assets, Node Library, Model Library, Workflows, Apps, and (when enabled) Job History |
| **Canvas** | The graph where you place and connect nodes, plus canvas controls |
| **Right side panel** | Parameters, node info, settings, and errors for the current selection |
| **Top bar** | Open workflows, Run / queue controls, login, and the properties panel toggle |
| **Bottom left** | Help Center, bottom panel (logs / shortcuts), and Settings |
| **Bottom right** | Canvas controls: pan, minimap, link visibility, zoom, fit |

![The left sidebar in order: Assets, Nodes, Models, Workflows, and Apps, with Job History at the top when `Comfy.Queue.QPOV2` is on](/images/interface/overview/sidebar_order.png)

## Old menu

The new menu is on by default. To use the old menu, open Settings and set `Comfy` → `Menu` → `Use new menu` to `disabled`.

<Note>
The old menu interface only supports English.
</Note>
