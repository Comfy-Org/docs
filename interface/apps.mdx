The **Apps** entry is registered in the left sidebar after Assets, Node Library, Model Library, and Workflows. It surfaces packaged workflow apps you can open without building the graph from scratch.

Running a workflow in the simplified linear UI is covered on [App Mode](/interface/app-mode). Prefer that page for queue controls, inputs, and the app-style layout; use this page for the sidebar Apps catalog itself.
