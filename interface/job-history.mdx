**Job History** is a left-sidebar tab that appears when the setting `Comfy.Queue.QPOV2` is enabled. The frontend registers it at the top of the sidebar (`prepend`) so you can watch active jobs and browse past runs without opening a separate queue popup.

When the setting is off, the tab is removed. Run / queue controls in the top header still start jobs; this page is about the sidebar history surface.
