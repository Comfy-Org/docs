The Video Edit widget is an interactive editor that ComfyUI renders inside the **Trim Video (Advanced)** and **Crop Video** nodes. It previews the video connected to the node, shows a filmstrip for choosing the segment, and draws a crop box over the frame, so you can set the trim window and the crop region visually instead of typing numbers.

## Where the widget appears

The widget is part of the node itself and occupies the node body below the video input:

| Node | Display name | Widget controls |
| --- | --- | --- |
| `VideoTrim` | Trim Video (Advanced) | Trim window only |
| `VideoCrop` | Crop Video | Crop region only |

Connect any video to the node's `video` input, for example from a Load Video node or from the output of a video generation node. Until a source is connected, the widget shows a placeholder asking you to select or connect a video to preview and edit.

Both nodes sit in the **Video** category of the node library. They are experimental, and the editor draws with the modern node design (Nodes 2.0). If the editor does not appear on the node, check that [Nodes 2.0](/interface/nodes-2) is enabled.

## Trim a video

The trim controls set the part of the clip the node keeps.

- The filmstrip below the preview shows thumbnails from the clip. Drag the left handle to move the start frame and the right handle to move the end frame. A tooltip shows the frame number while you drag.
- **Start Frame** and **End Frame** accept exact frame numbers and stay in sync with the handles.
- Drag anywhere on the filmstrip to move the playhead and scrub the preview. The trim window is highlighted on the filmstrip.
- The playback row under the preview plays or pauses the clip, seeks with the slider, shows the current timecode, opens a full screen preview, and mutes the audio.
- The rows at the bottom list the resolved dimensions, the selected and total duration, the frame rate, the number of frames, and the file size of the source video.

The widget writes the window to the node's trim input as a start time in seconds plus a duration. Dragging the end handle to the last frame sets the duration to 0, which keeps the rest of the clip.

## Crop a video

The crop controls keep a rectangular region of each frame.

- The crop box is drawn over the preview. Drag inside the box to move the region, and drag its edges or corners to resize it.
- Pick a ratio from the ratio list below the preview, then lock it to keep that aspect ratio while you resize. The region starts as the full frame.
- The bounding box fields below the preview hold the same region as numbers: `x` and `y` for the top-left corner, and `width` and `height` in pixels. A width and height of 0 keeps the full frame, and editing the numbers moves the box on the preview.

## Loading and troubleshooting

The widget reads the source video to build the preview and the filmstrip, so a long or high-resolution clip takes a moment to appear. A loading notice is shown while the preview is prepared.

- If the preview cannot be loaded, the widget shows a **Retry** button.
- If the browser cannot draw the filmstrip canvas, the panel reports that the video preview failed to render. Retry, and if it keeps failing, set the values with the numeric fields.
- The preview starts unmuted, and the mute button silences the preview. The playback controls only affect playback inside the widget and do not change the output video.

The trim window and the crop region are regular node inputs, so they are saved with the workflow and used when the workflow runs.
