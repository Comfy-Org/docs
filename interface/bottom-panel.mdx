The bottom panel opens from the workspace chrome (bottom-left controls and `Workspace.ToggleBottomPanel` in the View menu). Core tabs:

- **Shortcuts**: searchable list of keybindings (same data as [Shortcuts settings](/interface/shortcuts))
- **Logs**: runtime log stream on non-Cloud builds
- **Command Terminal**: registered on the **Desktop** app only

On **Comfy Cloud**, terminal tabs are not registered; the bottom panel still carries Shortcuts.
