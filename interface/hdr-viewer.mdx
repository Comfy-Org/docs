The HDR viewer shows EXR and HDR files that a browser cannot paint inside a node preview. It opens as a full-window dialog with the image on the left and the display and inspection controls on the right, so you can see what a float image actually contains before sending it to another application.

## Open the HDR viewer

Run a workflow that writes a float image, for example [Save Image (Advanced)](/built-in-nodes/SaveImageAdvanced) with **format** set to `exr`. The output preview of a `.exr` or `.hdr` file shows a sun icon and **HDR image** in place of the picture. Click the preview to open the file in the HDR viewer. The dialog title is the output filename, and the dialog can be maximized.

## Display controls

These controls change how the file is displayed, not the file itself.

| Control | What it does |
| --- | --- |
| **Exposure** | Shifts displayed brightness from -10 to +10 stops in 0.1 steps. Lower values bring highlights that sit above display white back into view. |
| **Auto exposure** | Sets the exposure so the brightest pixel in the image lands at display white. |
| **Channel** | Shows RGB, or one channel at a time: R, G, B, A, or luminance. |
| **Source gamut** | sRGB or Rec.2020. It is detected from the EXR chromaticities tag when the file opens; switch it by hand when a file carries no tag or the wrong one. |
| **Dither** | On by default. Smooths the banding that a smooth gradient shows on an 8-bit display. |
| **Clip warnings** | Off by default. Hatches pixels above display white and pixels below black, with a different pattern for each, so you can see what the current exposure hides. |

## Inspect the image

The sidebar also reports what the file holds, independently of the display settings:

- **Pixel values**: hover the image to read the coordinates and the raw RGBA values under the cursor in the top-left corner.
- **Histogram**: the distribution of the selected channel.
- **Statistics**: resolution, minimum, maximum, mean, and standard deviation, plus NaN and Inf counts when the file contains them.
- **Navigation**: scroll to zoom, drag to pan, and click **Fit** to frame the image.
- **Download image** saves the original file.
