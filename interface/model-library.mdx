The **Models** entry in the left sidebar opens the Model Library. After ComfyUI starts, it lists models detected under your `ComfyUI/models` tree (and any extra paths you configured).

Use it to search by name, browse by folder type (checkpoints, LoRAs, VAEs, and so on), and drag a model onto the canvas to insert the matching loader node.

If you download new files while ComfyUI is running, press `r` (or refresh node definitions from the menu) so the library picks them up.
