The **Workflows** entry in the left sidebar lists workflows saved on this machine and recent files you opened. From here you open a graph in a tab, create a blank workflow, and organize saved JSON without leaving the editor.

Templates live in a separate browse action (`Browse Templates` in the View menu / Templates entry). See [Templates](/interface/features/template).
