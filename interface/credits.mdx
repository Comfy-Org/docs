Credits power **Partner Nodes** (API calls to closed-source models). ComfyUI stays fully open-source and free for local graph execution; credits only apply when you run Partner Nodes or use Cloud billing features.

After you sign in under **Settings → User**, open **Settings → Workspace → Plan & Credits**. On Comfy Cloud you can also open the same panel from the profile menu with **Manage plan**.

Some Cloud workspaces show the same plan and credit data in a **Billing** panel instead of **Plan & Credits**. It sits under the same **Settings → Workspace** group, and it adds the automatic top-up setting. See [Billing panel and auto top-up](#billing-panel-and-auto-top-up).

## Billing panel and auto top-up

In workspaces that use the **Billing** panel, **Settings → Workspace → Billing** collects the workspace plan, the credit balance, and automatic top-up in one panel. Owners can change the plan and add credits there. Members see the same balance and a link to their usage.

### Plan and credits

The plan row shows the current plan, its billing interval, and the next invoice date. A scheduled plan change shows the date it takes effect, with a **Stay on** button to cancel that change. A canceled subscription shows its end date, with **Resume plan** to renew.

The **Available** figure at the top of the credits card is what the workspace can spend right now. When runs overspent the balance, the card notes how many credits it went over. When the workspace has an active plan, the card splits the balance two ways:

- **Plan**: the part of the plan allowance the workspace has left this billing period
- **Top-up**: credits you added, which are spent after the plan allowance runs out. It shows **In use now** when runs are already spending top-up credits.

**Add credits** opens the top-up flow. Owners also get a button to the hosted billing page for payment methods, invoices, and usage.

### Auto top-up

Auto top-up refills the balance automatically when it drops below a threshold, so long jobs can keep running without a manual top-up. It charges the workspace's default payment method, so a payment method has to be on file first. A failed charge or a reached monthly limit pauses the refill until you fix it.

While auto top-up is on, the card shows the rule, for example the amount and credits added and the balance that triggers it. It also shows how much of the monthly limit automatic charges have used. Only automatic charges count toward that limit, and the counter resets each billing cycle.

Every button on the card opens the billing page in a new tab, where you change the setting. When the workspace supports auto top-up, owners see the card and members do not.

| Status | What it means |
| --- | --- |
| **On** | Auto top-up is active. **Manage** opens the billing page to change the amount, the threshold, or the monthly limit. |
| **Off** | Auto top-up is not active. **Turn on** opens the billing page to set it up. |
| **On hold** | There is no default payment method, so the next top-up cannot be charged. **Update payment** opens the billing page to add a card. |
| **Paused** | Automatic charges reached the monthly limit. Top-up resumes at the start of the next cycle shown on the card, or sooner if you raise the limit in the billing page. |
| **Failed** | The last automatic charge did not go through. **Update payment** opens the billing page, or you can add credits manually. |

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="Can credits go negative?">
    Credits are not intended as a credit line. Partner Nodes sometimes report cost after execution, so one run can leave a temporary negative balance. While the balance is negative, Partner Nodes stay blocked until you top up.
  </Accordion>

  <Accordion title="Can I get a refund for unused credits?">
  Currently we do not support refunds for unused credits.
  </Accordion>

  <Accordion title="How do I check my current balance and usage?">
  Open **Settings → Workspace → Plan & Credits**. Use the **Credits** tab for balance and the **Activity** tab for usage history. In workspaces that show the **Billing** panel instead, the balance is on the credits card and **View usage** opens the usage history.
  </Accordion>

  <Accordion title="Can I share my credits with other users?">
  You can sign into the same account on multiple devices. Sharing credits with other user accounts is not supported. On Cloud Team workspaces, members share one workspace balance, and only the workspace owner can add credits or change the plan.
  </Accordion>

  <Accordion title="How can I know how much the node will cost?">
  Check the price badge on the API / Partner Node before running. Actual cost can vary with image size, generation count, and other parameters.
  </Accordion>

  <Accordion title="Why don't I see WeChat or Alipay payment options?">
  Choose payment in Comfy Credits. WeChat and Alipay are only available for that currency path.
  </Accordion>

  <Accordion title="Do credits come with a Cloud plan?">
  No. Buying credits does not start a subscription and does not unlock Cloud workflows: running workflows on Cloud needs a plan. Partner Nodes in local ComfyUI and Desktop can use credits without a plan.
  </Accordion>

  <Accordion title="Do credits expire?">
  Yes, expiration depends on the type:
  - **Monthly credits**: Expire at the end of your billing period
  - **Top-up credits**: Expire 1 year from the purchase date
  </Accordion>
</AccordionGroup>
