## 어떤 것을 사용해야 할까요?

| | Comfy MCP<br />클라우드 연결 | Comfy MCP<br />로컬 연결 | Comfy In-App Agent |
|---|---|---|---|
| **설명** | 자신의 에이전트로 Comfy Cloud 워크플로를 실행합니다. | 자신의 에이전트로 자신의 로컬 ComfyUI를 구동합니다. | 앱 안에서 AI와 채팅하고 AI가 워크플로를 빌드하고 실행하는 것을 지켜보세요. |
| **최적 사용 대상** | ComfyUI를 로컬에 설정하고 싶지 않은 초보자.<br />워크플로를 공유하려는 사람. | ComfyUI를 로컬에 보유한 사람.<br />비공개 커스텀 노드를 가진 사람.<br />로컬 파일 시스템과 상호작용해야 하는 사람. | 초보자부터 고급 워크플로 빌더까지 모든 사람.<br />캔버스를 보고 워크플로를 시각적으로 확인하려는 사람. |
| **요구 사항** | 자신의 에이전트.<br />유료 실행을 위한 Comfy Cloud 구독. | 자신의 에이전트.<br />로컬 ComfyUI 설정. | 설정 불필요.<br />유료 실행을 위한 Comfy Cloud 구독. |
| **GPU** | 클라우드 GPU(하드웨어 요구 사항 없음) | 로컬 GPU | 클라우드 GPU(하드웨어 요구 사항 없음) |
| **모델** | Comfy Cloud 모델.<br />나만의 모델을 가져올 수 있습니다. | 사용자 머신에 다운로드된 로컬 모델. | Comfy Cloud 모델.<br />나만의 모델을 가져올 수 있습니다. |
| **커스텀 노드** | Comfy Cloud에서 지원되는 커스텀 노드. | 모든 커스텀 노드를 설치할 수 있습니다. | Comfy Cloud에서 지원되는 커스텀 노드. |

두 MCP 열은 **동일한 제품이자 동일한 페이지**입니다. 하나를 선택하려면 [Comfy MCP](/ko/agent-tools/mcp)를 참조하세요. 두 가지를 동시에 연결할 수 있습니다.

## MCP란 무엇인가요?

**모델 컨텍스트 프로토콜(MCP)**은 AI 비서가 표준화된 인터페이스를 통해 외부 도구 및 서비스와 상호작용할 수 있도록 하는 오픈 표준입니다. AI 에이전트가 모든 서비스의 맞춤형 API 형식을 알아야 하는 대신, MCP는 도구를 노출하는 일관된 방법을 제공합니다.

MCP 서버를 Claude Desktop, Claude Code, Cursor 또는 Amp에 연결하면 AI 비서는 다음을 수행할 수 있습니다:

- 텍스트 설명으로 **이미지 생성**
- 텍스트 또는 이미지로 **비디오 생성**
- 텍스트 또는 이미지로 **3D 모델 생성**
- AI 모델을 사용해 **오디오 및 음악 생성**
- 작업에 적합한 도구를 찾기 위해 **모델 및 템플릿 검색**

...이 모든 것을 자연어 대화를 통해 수행하며, API 호출을 수동으로 작성할 필요가 없습니다.
