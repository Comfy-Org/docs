<Note>
  **Comfy Agent는 Comfy Cloud에서 정식 제공됩니다**. 로컬의 Comfy Desktop 내 Agent는 곧 출시 예정입니다. 알림을 받으려면 [웨이팅 리스트에 참여하세요](https://links.comfy.org/agentalpha).
</Note>

ComfyUI 안에서 바로 원하는 것을 설명하세요. 워크플로를 계획하고 빌드하고 실행합니다. 작업하는 동안 캔버스를 편집하며, 여러분과 나란히 함께 만들어 갑니다.

## 할 수 있는 작업

- ComfyUI 환경에서 사용 가능한 템플릿, 모델, 노드를 찾습니다.
- 템플릿에서 워크플로를 구성하고 프롬프트와 설정을 사용자 정의합니다.
- 나머지를 다시 구성하지 않고 현재 워크플로의 일부를 변경합니다.
- 노드를 추가, 연결, 구성 및 제거합니다.
- 실행하기 전에 워크플로를 검증합니다.
- 이미지를 검사하고 비디오 또는 오디오 속성을 읽습니다.
- 워크플로를 실행하고 출력을 반환합니다.
- Agent가 응답하는 동안에도 캔버스에서 계속 작업할 수 있습니다. Agent가 완료될 때까지 기다릴 필요가 없으며, 현재 열려 있는 항목을 기반으로 작업합니다.
- 일상적인 언어로 스킬을 생성하거나, 자신의 스킬만이 아니라 Comfy의 공개 스킬 중 하나를 사용하도록 Agent에게 요청할 수 있습니다. [Agent skills](/ko/agent-tools/in-app-agent-skills)를 참조하세요.
- 한 번에 여러 채팅을 열 수 있습니다. 각 채팅은 고유한 기록과 컨텍스트를 가진 독립적인 세션입니다.

## 사용할 수 있는 곳

| Comfy Agent를 사용하는 곳 | 예상되는 사항 |
| --- | --- |
| **Comfy Cloud** | 일반 제공됩니다. Agent, 워크플로, 에셋은 Comfy Cloud 계정을 사용합니다. 설치할 로컬 패키지가 없습니다. |
| **Comfy Desktop** | **곧 출시 예정.** 자체 모델과 커스텀 노드를 포함해 로컬 ComfyUI에서 Comfy Agent를 사용할 수 있게 되면 알림을 받도록 [웨이팅 리스트에 참여하기](https://links.comfy.org/agentalpha)를 이용하세요. |

어느 쪽이든 Agent 요청은 네트워크를 통해 Comfy 서비스를 사용합니다. [데이터 및 개인정보](/ko/agent-tools/in-app-agent-data-privacy)를 참조하세요.

Comfy Agent는 [Comfy MCP](/ko/agent-tools/mcp) 및 [Comfy CLI](/ko/agent-tools/cli)와 별개입니다. MCP는 외부 AI 클라이언트를 Comfy에 연결합니다. CLI는 터미널 및 스크립트 워크플로를 위한 것입니다. Comfy Agent는 ComfyUI 인터페이스에서 작동합니다.

첫 이미지를 만들려면 [Comfy Agent 시작하기](/ko/agent-tools/in-app-agent-installation#첫-이미지-만들기)를 따르세요.

## 비용 {#what-it-costs}

무료 초기 토큰이 이제 모든 사용자에게 제공되므로 누구나 Comfy Agent 채팅을 여러 번 사용해 볼 수 있습니다. 그 이후에는 Comfy Agent가 이미 생성에 사용하고 있는 동일한 Comfy 크레딧 풀에서 요금을 청구합니다. Agent를 계속 실행하려면 Comfy 크레딧 잔액이 양수여야 하지만, 반드시 구독 플랜이 있어야 하는 것은 아닙니다. 요금제 세부 정보는 [구독 및 충전 플랜](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=agent)을 참조하세요.

### 토큰당 가격

## 로컬에서 곧 출시 예정

Comfy Agent가 Comfy Desktop에 도입되면 자체 GPU, 모델, 커스텀 노드와 함께 작동하며 설정 과정도 안내해 줍니다. 또한 오늘날 클라우드에서 제공하는 것 이상으로 나아가, 설치할 필요 없이 일회성으로 쓰는 마스킹이나 합성 도구처럼 커스텀 편집 도구를 캔버스에서 직접 만들어 줍니다.

## 편집할 워크플로 선택

Agent 패널의 워크플로 선택기에서 편집할 워크플로를 선택한 다음 메시지를 보내세요. Agent가 응답하는 동안 다른 탭으로 전환해도 편집 대상이 바뀌지 않습니다.

Agent는 스스로 탭을 생성하거나 전환할 수 없습니다. 다른 곳에서 작업하려면 해당 워크플로를 열고 Agent 패널에서 선택한 뒤 새 메시지를 보내세요.

Agent는 다른 열려 있거나 저장된 워크플로를 현재 탭에 로딩하지 않고도 비교 목적으로 읽을 수 있습니다. 예를 들면 다음과 같습니다.

> 이 워크플로를 제 인물 사진 워크플로와 비교하고, 여기에 동일한 샘플러 설정을 사용해 주세요.

## 워크플로 빌드 및 편집

새 워크플로의 경우 빈 워크플로 탭을 열고 Agent 패널에서 해당 탭을 선택하세요. Agent는 개별 노드로 빌드하기 전에 일치하는 템플릿을 검색합니다. 템플릿에는 연결된 그래프와 출력 노드가 포함됩니다.

기존 워크플로를 변경할 때는 변경할 부분과 그대로 유지할 부분을 명시하세요:

- "프롬프트를 수채화 풍경으로 변경해 줘. 모델과 샘플러 설정은 유지해."
- "이미지 생성 이후에 업스케일링 단계를 추가해 줘."
- "여기에 설치된 모델을 사용해 이 워크플로를 FLUX로 전환해 줘."

Agent는 캔버스에서 실시간으로 빌드하며, 그동안에도 계속 캔버스를 편집할 수 있습니다.

## 실행 전 검증

에이전트는 실행 전에 노드 연결, 모델 이름, 필수 값, 출력 노드를 확인합니다. 워크플로 오류와 사용자만 제공할 수 있는 입력을 구분합니다.

워크플로가 유효하지만 이미지, 비디오 또는 기타 입력이 여전히 필요하다면, 파일을 첨부하고 에이전트에게 계속 진행하도록 요청하세요.

## 미디어 작업

에이전트는 정지 이미지의 보이는 내용과 크기를 확인할 수 있습니다. 비디오의 경우 재생 시간, 크기, 프레임 레이트, 형식을 읽을 수 있습니다. 오디오의 경우 재생 시간, 형식, 오디오 트랙을 읽을 수 있습니다.

메시지 상자에서 **파일 첨부**를 사용해 이미지나 파일을 추가하세요. 미디어를 대화로 끌어다 놓을 수도 있습니다.

| 대화에 추가 | 요청 | 결과 |
| --- | --- | --- |
| 이미지 | "이 이미지의 조명을 설명해 줘." | 프롬프트를 다듬는 데 사용할 수 있는 설명. |
| 비디오 | "이걸 처음 5초로 잘라 줘." | 길이가 줄어든 비디오 파일. |
| 비디오 클립 두 개 | "클립 A 뒤에 클립 B를 이어 붙여 줘." | 두 클립이 그 순서대로 포함된 하나의 비디오. |
| 비디오와 오디오 파일 | "이 오디오를 비디오에 추가해 줘." | 지정한 오디오가 포함된 비디오. |

미디어 편집을 사용하려면 설치 환경에서 미디어 도구를 사용할 수 있어야 합니다. 클라우드에서는 편집된 파일이 에셋 라이브러리에 저장됩니다. 에이전트는 대화에서 미리보기나 파일 링크를 반환합니다.

## 실행 권한

메시지 상자 옆에서 실행 권한을 선택합니다:

- **Ask**는 각 워크플로 실행 전에 승인을 요청합니다.
- **Auto**는 실행할 때마다 묻지 않고 워크플로를 실행합니다.

**Save changes**를 선택하여 선택한 설정을 적용합니다. Ask 모드에서는 승인 메시지에서 **Run**을 선택해 워크플로를 시작하거나, **Cancel**을 선택해 해당 실행을 취소합니다.

Ask와 Auto는 워크플로 실행을 제어합니다. Agent는 두 모드 중 어느 쪽에서든 선택된 워크플로를 편집할 수 있습니다.

## 에이전트가 사용할 수 있는 것

일반적으로 채팅 세션에서 에이전트는 사용자의 메시지, 선택된 워크플로, 선택된 노드, 첨부 파일, 워크플로 오류를 사용합니다. 설정을 비교하거나 재사용해 달라고 요청하면 다른 워크플로를 읽을 수도 있습니다.
또한 에이전트는 현재 워크스페이스에 저장된 워크플로, 사용 가능한 모델과 사용 가능한 노드, 그리고 공개 템플릿 워크플로와 공개/비공개 스킬에도 접근할 수 있으며, 이들은 필요할 때 모두 사용됩니다.

클라우드 및 로컬 데이터 흐름, 채팅 기록, 개인 정보 보호 제어에 대해서는 [Comfy Agent 데이터 및 개인 정보 보호](/ko/agent-tools/in-app-agent-data-privacy)를 참조하세요.

## 중지 또는 취소

메시지 상자에서 **Stop**을 선택하면 Agent의 현재 응답이 중지됩니다. 워크플로 실행에는 [실행 및 대기열 영역](/ko/interface/overview)에 별도의 컨트롤이 있으므로, 이미 제출된 워크플로를 관리할 때는 해당 컨트롤을 사용하세요.
