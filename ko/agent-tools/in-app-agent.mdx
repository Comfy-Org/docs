<Note>
  **비공개 알파.** Comfy In-App Agent는 제한된 사용자 그룹에게 순차적으로 제공됩니다. 공개 문서와 웹사이트 페이지는 아직 사용 불가하며, 액세스를 요청하려면 웨이팅 리스트에 참여하세요.
</Note>

**Comfy In-App Agent**는 Comfy Cloud 내부의 에이전트 경험입니다. 채팅에서 원하는 것을 설명하면 에이전트가 그래프에서 워크플로를 만들거나 편집할 수 있습니다.

## 에이전트 사용하기

1. Comfy Cloud에서 워크플로를 엽니다.
2. 워크플로 바에서 **Ask Comfy Agent**를 선택합니다.
3. 채팅이 작업할 워크플로를 선택합니다. 그래프 접근이 필요 없는 문의는 **Don't work in a workflow**를 선택할 수도 있습니다.
4. 프롬프트를 입력합니다. `@`를 입력해 노드를 참조하거나, **Add nodes from graph**를 선택하거나, 이미지, 비디오, 오디오 파일, 3D 모델, 텍스트 파일을 첨부해 에이전트에 더 많은 컨텍스트를 제공할 수 있습니다.
5. 제안된 그래프 변경 사항과 출력을 검토합니다. 에이전트는 실수를 할 수 있으므로 실행하기 전에 워크플로를 확인하세요.

에이전트는 워크플로 탭별로 별도의 채팅을 유지합니다. **Chat history**를 사용해 이전 대화로 돌아가거나 이름을 바꾸거나 마크다운으로 복사할 수 있습니다.

## 실행 권한

전송 버튼 옆의 컨트롤은 에이전트가 워크플로를 언제 실행할 수 있는지를 결정합니다.

- **워크플로 실행 전에 묻기**: 각 실행에 대해 사용자의 승인이 필요합니다.
- **승인 없이 자동 실행**: 에이전트가 묻지 않고 워크플로를 실행할 수 있습니다.
- **제한이 있는 자동 실행**: 실행이 사용자가 설정한 크레딧 한도를 초과하는 경우에만 묻습니다.

실행 권한은 실행에만 영향을 미치며 편집에는 영향을 미치지 않습니다. 에이전트는 선택된 워크플로를 계속 수정할 수 있습니다. 프롬프트를 보내기 전에 이 설정을 검토하십시오.

## 응답 검토하기

턴이 진행되는 동안 패널에는 에이전트의 진행 상황과 사용 중인 도구가 표시됩니다. 응답에는 서식 있는 텍스트, 코드, 생성된 미디어, 다운로드 가능한 에셋, 워크플로 탭을 여는 링크가 포함될 수 있습니다.

응답을 평가하려면 응답에 있는 엄지 올림 또는 엄지 내림 컨트롤을 사용하세요. 버그를 신고하거나 자세한 내용을 공유하려면 아래의 피드백 링크를 사용하세요.

## 현재 알파 경계

- 접근은 기능 플래그로 제어되며, 선택된 Comfy Cloud 계정으로 제한됩니다.
- 작업은 채팅에서 선택된 워크플로로 한정됩니다. 편집을 요청하기 전에 워크플로 선택기를 확인하세요.
- 에이전트와 사람의 편집은 동일한 클라우드 워크플로를 업데이트할 수 있지만, 광범위한 오프라인 편집과 크리에이터 대상 충돌 해결 인터페이스는 이 알파에 포함되지 않습니다.
- 연결이 중단되면 추가 편집을 하기 전에 패널이 다시 연결될 때까지 기다리세요. 워크플로를 실행하기 전에 그래프 상태를 확인하세요.
- 중지되거나 중단된 에이전트 턴은 자동으로 재개되지 않습니다. 필요하면 새 턴을 시작하세요.
