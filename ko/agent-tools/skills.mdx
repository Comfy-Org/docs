[**Comfy Skills**](https://github.com/Comfy-Org/comfy-skills)는 Comfy용 에이전트 스킬과 플러그인의 본거지입니다. 스킬은 에이전트가 필요 시 로드하는 패키지화된 지식입니다: 모델 가이드, 워크플로 패턴, 즉시 사용 가능한 명령어. 프롬프트를 처음부터 작성하지 않아도 모든 에이전트가 ComfyUI를 더 잘 활용할 수 있습니다.

이 저장소는 다음을 호스팅합니다:

- **Claude Code 플러그인**: 예를 들어 **comfy-cloud**는 Comfy Cloud MCP 연결과 `/comfy-cloud:*` 슬래시 명령어를 한 번의 설치로 추가합니다.
- **에이전트 스킬**: 특정 작업에 초점을 맞춘 지침입니다. 최신 모델 추천과 워크플로 구축 노하우가 포함되며, 모델이 변경됨에 따라 최신 상태로 유지됩니다.
- **커뮤니티 기여**: Comfy 커뮤니티의 스킬과 플러그인.

Claude Code에서 사용하려면:

```
/plugin marketplace add Comfy-Org/comfy-skills
/plugin install comfy-cloud@comfy-skills
```

플러그인의 슬래시 명령어와 설정 세부 정보는 [Comfy MCP](/ko/agent-tools/mcp)를 참조하세요.
