## 설정 선택

Agent 접근 권한이 있는 Comfy 계정이 필요합니다. 접근 권한이 없다면 [비공개 알파 대기자 명단에 참여](https://links.comfy.org/agentalpha)하세요.

- **Comfy Cloud:** [클라우드에 로그인](https://cloud.comfy.org)하세요. 로컬 설치가 필요하지 않습니다.
- **Comfy Desktop:** [데스크톱 설치 가이드](/ko/installation/desktop/overview)를 따른 뒤 로그인하세요. 기존 설치가 있다면 [ComfyUI 업데이트](/ko/installation/update_comfyui)를 따르세요.

## 첫 이미지 만들기

### 에이전트 열기

빈 워크플로를 연 다음, 워크플로 표시줄에서 **Ask Comfy Agent**를 선택합니다. 동의 안내가 표시되면 내용을 확인하고 동의합니다. 에이전트 패널에서 **워크플로 선택**을 사용해 빈 워크플로를 선택합니다.

### 워크플로 만들기

다음 메시지를 보내세요.

> 중립적인 회색 배경에 빨간색 스니커즈를 위한 텍스트 기반 이미지 생성 워크플로를 만들어 주세요. 사용 가능한 모델을 사용하고 이미지 저장 노드를 포함해 주세요. 워크플로에 오류가 있는지 확인하되, 아직 실행하지는 마세요.

에이전트가 캔버스에 워크플로를 만들고 프롬프트와 모델 설정을 채운 뒤, 노드 연결과 필수 입력을 확인합니다. **이미지 저장** 노드로 끝나는 연결된 워크플로가 표시되어야 합니다.

에이전트가 누락된 모델이나 파일을 보고하면, 해당 항목을 제공하거나 현재 설치 환경에서 사용할 수 있는 대안을 요청하세요. 계속하기 전에 워크플로를 다시 확인해 달라고 요청하세요.

### 이미지 생성하기

메시지 상자 옆의 **실행 권한**을 열고 **묻기**를 선택한 다음, 설정을 변경했다면 **변경 사항 저장**을 선택합니다.

“이 워크플로를 실행해 주세요.”라고 보냅니다. 에이전트가 승인을 요청하면 **실행**을 선택합니다. 해당 실행을 시작하지 않으려면 대신 **취소**를 선택합니다.

생성이 끝나면 에이전트가 대화에서 출력을 반환합니다. 이미지는 **이미지 저장** 노드에도 표시됩니다. 그곳에서 이미지를 마우스 오른쪽 버튼으로 클릭하면 컴퓨터에 저장할 수 있습니다.

### 변경 적용하기

“배경을 흰색으로 바꾸고 모델과 기타 설정은 그대로 유지해 주세요.”라고 보냅니다. 에이전트가 기존 워크플로를 업데이트합니다. 결과를 비교하려면 다시 실행해 달라고 요청하세요.

## 문제 해결

### Agent 버튼이 누락됨

Comfy 계정에 로그인하세요. Comfy Desktop에서는 [애플리케이션을 업데이트](/ko/installation/update_comfyui)하고 재시작하세요. 그래도 버튼이 누락되어 있다면 [지원팀](/ko/support/contact-support)을 통해 계정의 Agent 접근 권한을 확인하세요.

### Agent가 예상한 워크플로를 편집할 수 없음

Agent 패널에서 원하는 워크플로를 선택한 다음 메시지를 다시 보내세요. [편집할 워크플로 선택](/ko/agent-tools/in-app-agent#편집할-워크플로-선택)을 참조하세요.

### Agent가 입력을 요청함

**파일 첨부**를 선택하거나 요청된 파일을 메시지 상자로 끌어다 놓은 다음, Agent에게 계속하도록 요청하세요.

### 클라우드에서 로컬 대화를 찾을 수 없음

로컬 기록과 클라우드 기록은 별도로 관리됩니다. [데이터 및 개인정보 보호](/ko/agent-tools/in-app-agent-data-privacy#채팅-기록-및-동기화)를 참조하세요.
