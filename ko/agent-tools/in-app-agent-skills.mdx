## 개인 스킬이란 무엇인가요?

개인 스킬은 Comfy Agent를 위한 재사용 가능한 지침 세트입니다. 이름, 언제 사용할지에 대한 한 줄 설명, 그리고 지침 자체로 구성됩니다.

개인 스킬을 사용해 "정사각형 이미지 만들기", "흰색 배경 사용", "실행 전에 노드 연결 확인" 같은 지침을 반복할 수 있습니다.

개인 스킬은 계정에 저장됩니다. Agent는 스킬의 설명이 요청과 일치하거나 이름으로 요청할 때 해당 스킬을 불러옵니다.

## 채팅에서 스킬 생성하기

무엇을 저장할지, 무엇이라고 부를지, 언제 사용해야 하는지 Agent에게 알려주세요.

> Save this as a skill called product-shot: When I ask for a product image, use a square 1024 × 1024 canvas, a neutral gray background, and a Save Image node. Validate the workflow before running it.

Agent는 이후 메시지를 위해 스킬을 저장합니다. 새로 만들거나 업데이트한 스킬은 다음 메시지부터 적용됩니다.

## 스킬 사용하기

이름으로 스킬을 요청하세요.

> Use my product-shot skill to create a studio photo workflow for a red sneaker.

요청이 스킬의 설명과 일치하면 Agent가 자동으로 스킬을 선택할 수도 있습니다.

## 스킬 업데이트 또는 삭제하기

같은 스킬 이름을 사용해 지침을 교체하세요.

> Update my product-shot skill to use a white background and a 1536 × 1536 canvas.

이름으로 스킬을 삭제하세요.

> Delete my product-shot skill.

## 기존 스킬 파일 저장하기

`SKILL.md` 파일의 내용을 채팅에 붙여넣고 Agent에게 개인 스킬로 저장해 달라고 요청하세요. Agent는 파일 상단의 헤더에서 이름과 설명을 읽습니다. 저장된 스킬은 다음 메시지부터 사용할 수 있습니다.

## 내장 가이드와 코딩 에이전트 스킬

Comfy Agent에는 워크플로를 만들고 모델을 선택하기 위한 가이드가 포함되어 있습니다. 개인 스킬은 반복되는 작업을 위한 여러분만의 지침을 추가합니다.

[코딩 에이전트용 스킬](/ko/agent-tools/skills)은 Claude Code 같은 도구에 별도로 설치됩니다. 그곳에 설치해도 Comfy Agent에는 추가되지 않습니다.

스킬 지침에 API 키, 비밀번호, 액세스 토큰을 넣지 마세요. 데이터 처리에 대해서는 [데이터 및 개인정보](/ko/agent-tools/in-app-agent-data-privacy#스킬-및-가이드)를 참고하세요.
