## 스킬 팩이란 무엇인가요?

스킬 팩은 Comfy Agent를 위한 재사용 가능한 지침 세트입니다. 각 팩은 이름, 언제 불러올지 알려주는 트리거 한 줄, 그리고 지침 자체로 구성됩니다.

스킬 팩을 사용해 "정사각형 이미지 만들기", "흰색 배경 사용", "실행 전에 노드 연결 확인" 같은 반복되는 지침을 처리할 수 있습니다.

직접 만든 팩은 내 계정에만 저장됩니다. Agent는 트리거 줄이 요청과 일치하거나 이름으로 요청할 때 해당 팩을 불러옵니다.

## 채팅에서 스킬 생성하기

무엇을 저장할지, 무엇이라고 부를지, 언제 사용해야 하는지 Agent에게 알려주세요:

> product-shot이라는 스킬로 저장해 주세요: 제품 이미지를 요청하면 정사각형 1024 × 1024 캔버스, 중립적인 회색 배경, Save Image 노드를 사용하세요. 실행하기 전에 워크플로를 검증하세요.

Agent는 이후 메시지를 위해 스킬을 저장합니다. 새로 만들거나 업데이트한 스킬은 다음 메시지부터 적용됩니다.

## 스킬 사용하기

이름으로 스킬을 요청하세요:

> 내 product-shot 스킬을 사용해 빨간색 스니커즈의 스튜디오 사진 워크플로를 만들어 주세요.

트리거 줄이 요청과 일치하면 Agent가 자동으로 스킬을 선택할 수도 있습니다. 목록에서 고르려면 메시지 입력창에서 `/`를 입력하고 메뉴의 **Skills**(스킬) 섹션에서 선택하세요.

## 설정에서 스킬 팩 관리하기

**설정** → **스킬 팩**을 열면 계정의 모든 팩이 표시됩니다. 각 팩은 이름과 크기와 함께 나열됩니다.

- **스킬 팩 추가**를 누르면 새 팩을 만드는 양식이 열립니다.
- **편집**으로 기존 팩의 트리거 줄과 지침을 변경할 수 있습니다. 만든 팩의 이름은 변경할 수 없습니다.
- **삭제**로 팩을 제거합니다. 삭제는 되돌릴 수 없습니다.

## 스킬 팩 항목

| 항목 | 역할 | 규칙 |
| --- | --- | --- |
| **이름** | Agent가 팩을 불러올 때 쓰는 식별자입니다. | 최대 64자이며 영문자, 숫자, `.`, `_`, `-`만 사용할 수 있습니다. 이름은 고유해야 하고, 항상 켜져 있는 내장 팩 이름은 사용할 수 없습니다. |
| **트리거 줄** | 언제 불러올지 알려주는 한 줄입니다. 팩 사용 여부와 관계없이 모든 메시지와 함께 전송됩니다. | 한 줄에 최대 1,024자입니다. 짧게 유지하세요. |
| **지침** | 팩이 로드된 뒤 Agent가 따르는 내용입니다. | 필수입니다. |

## 크기 제한

팩 목록에는 각 팩의 전체 크기가 바이트 단위로 표시됩니다. 팩을 만들거나 편집할 때는 입력하는 지침의 크기가 양식에 표시됩니다. 팩은 계정의 크기 한도를 함께 사용합니다. 새 팩이 한도를 넘으면 양식은 저장하지 않고 먼저 팩을 삭제하라고 안내합니다.

## 스킬 업데이트 또는 삭제하기

같은 스킬 이름을 사용해 지침을 교체하세요:

> 내 product-shot 스킬을 흰색 배경과 1536 × 1536 캔버스를 사용하도록 업데이트해 주세요.

이름으로 스킬을 삭제하세요:

> 내 product-shot 스킬을 삭제해 주세요.

## 기존 스킬 파일 저장하기

`SKILL.md` 파일의 내용을 채팅에 붙여넣고 Agent에게 스킬 팩으로 저장해 달라고 요청하세요. Agent는 파일 상단의 헤더에서 이름과 설명을 읽습니다. 저장된 스킬은 다음 메시지부터 사용할 수 있습니다.

## 공개 스킬 사용하기

공개 스킬은 여러분이 만든 스킬뿐 아니라 누구나 사용할 수 있는 공유 스킬입니다. 이름으로 공개 스킬을 요청하거나 하고 싶은 일을 설명하면, Agent는 여러분의 스킬을 사용할 때와 같은 방식으로 해당 스킬을 사용합니다:

> 중립적인 회색 배경에 빨간색 스니커즈를 위해 product-shot 공개 스킬을 사용해 주세요.

## 내장 가이드와 코딩 에이전트 스킬

Comfy Agent에는 워크플로를 만들고 모델을 선택하기 위한 가이드가 포함되어 있습니다. 스킬 팩과 공개 스킬은 이 가이드 위에 반복되는 작업을 위한 지침을 추가합니다.

[코딩 에이전트용 스킬](/ko/agent-tools/skills)은 Claude Code 같은 도구에 별도로 설치됩니다. 그곳에 설치해도 Comfy Agent에는 추가되지 않습니다.

스킬 지침에 API 키, 비밀번호, 액세스 토큰을 넣지 마세요. 데이터 처리에 대해서는 [데이터 및 개인정보](/ko/agent-tools/in-app-agent-data-privacy#스킬-및-가이드)를 참고하세요.
