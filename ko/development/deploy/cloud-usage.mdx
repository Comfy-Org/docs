Comfy Cloud API를 통해 제출된 워크플로는 다른 Cloud 워크플로와 동일한 크레딧과 동시 실행 제한을 사용합니다.

## 크레딧 및 사용량

API 요청은 Comfy Cloud 웹 UI와 동일한 월간 크레딧 할당에서 차감됩니다. 별도의 API 크레딧 풀은 없습니다. 각 등급에 포함된 크레딧, 충전 옵션, 워크플로당 런타임 상한은 UI 작업과 동일한 방식으로 API 작업에 적용됩니다.

월간 크레딧 양과 충전 옵션은 [가격 페이지](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)를 참고하세요. 충전은 계정 대시보드에서 구매할 수 있습니다.

## 동시성 제한

이전 작업이 완료될 때까지 기다리지 않고 여러 워크플로를 제출할 수 있습니다. 작업은 구독 등급의 한도까지 병렬로 실행됩니다:

| 플랜     | 동시 실행 워크플로 |
| :------- | :----------------- |
| Standard | 1                  |
| Creator  | 3                  |
| Pro      | 5                  |

Team 플랜은 멤버당 동시 실행 워크플로 수가 Pro보다 많습니다. 현재 동시 실행 한도는 [platform.comfy.org](https://platform.comfy.org)에서 확인하세요. 추가 작업은 실행 대기열에 들어가 슬롯이 확보되는 대로 실행됩니다.

실행 대기열이 가득 차면 SDK는 정해진 범위 내에서 재시도한 후 `QueueFull`을 발생시킵니다.

Team 및 Enterprise 플랜에서는 동시성이 멤버별로 적용됩니다. 워크스페이스의 각 멤버에게 자체 동시 실행 한도가 주어지므로, 한 멤버가 실행 중인 작업이 다른 멤버의 작업을 차단하지 않습니다.

<Info>
  여러 작업을 동시에 실행하는 것은 API를 통해서만 지원됩니다. Comfy Cloud UI는 1인당 한 번에 하나의 워크플로만 실행하며, 에디터에서 대기열에 들어간 워크플로는 순서대로 실행됩니다. 구독 세부 정보는 [요금제](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)를 참고하세요.
</Info>

## 실행 시간 및 대기열 제한

각 Cloud 워크플로에는 최대 실행 시간이 있습니다. 제한을 넘긴 작업은 자동으로 취소됩니다:

| 플랜     | 최대 실행 시간 |
| :------- | :------------- |
| Standard | 30분           |
| Creator  | 30분           |
| Pro      | 1시간          |

대기열에는 최대 150개의 워크플로를 동시에 넣을 수 있습니다. Team 및 Enterprise 플랜에서 대기열 한도는 멤버별, 워크스페이스별로 적용됩니다. 각 멤버가 각자의 150개를 가지며, 팀 전체가 공유하는 하나의 대기열이 아닙니다. 한 멤버가 한도에 도달해도 이 한도 아래에서 다른 멤버의 제출이 막히지 않습니다. Team 동시 실행 한도를 높이려면 [지원팀](https://support.comfy.org/)에 문의하세요.

## 기존 v1 연동

지원 중단된 [v1 Cloud API](/ko/development/cloud/overview)도 Comfy Cloud에서 실행됩니다. 기존 연동이나 아직 [Comfy API v2](/ko/api-reference/v2/overview)에서 사용할 수 없는 Cloud 기능에 사용하세요. 실행 가능한 예제는 지원 중단된 [Cloud API Reference](/ko/development/cloud/api-reference)에 있습니다.
