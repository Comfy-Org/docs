Comfy Cloud API를 통해 제출된 워크플로는 다른 클라우드 워크플로와 동일한 크레딧 및 동시성 제한을 사용합니다.

## 크레딧 및 사용량

API 요청은 Comfy Cloud 웹 UI와 동일한 월간 크레딧 할당량에서 차감됩니다. 별도의 API 크레딧 풀은 없습니다. 각 티어에 포함된 크레딧, 추가 구매 옵션, 워크플로별 런타임 상한은 UI 작업과 동일한 방식으로 API 작업에 적용됩니다.

월간 크레딧 수량과 추가 구매 옵션은 [가격 페이지](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)를 참조하세요. 추가 크레딧은 계정 대시보드에서 구매할 수 있습니다.

## 동시 실행 한도

이전 작업이 완료될 때까지 기다리지 않고 여러 워크플로를 제출할 수 있습니다. 작업은 구독 등급의 한도까지 병렬로 실행됩니다:

| 플랜     | 동시 워크플로 |
| :------- | :------------------- |
| 스탠다드 | 1                    |
| 크리에이터  | 3                    |
| 프로      | 5                    |

팀 플랜은 프로보다 멤버당 더 많은 동시 워크플로를 실행합니다. 계정의 동시 실행 수는 [platform.comfy.org](https://platform.comfy.org)에서 확인하세요. 추가 작업은 실행 대기열에 들어가 빈 슬롯이 생기면 실행됩니다.

실행 대기열이 가득 차면 SDK는 정해진 재시도 한도 내에서 재시도한 뒤 `QueueFull`을 발생시킵니다.

팀 및 엔터프라이즈 플랜에서 동시 실행 수는 멤버별로 적용됩니다. 워크스페이스의 모든 멤버는 각자의 동시 실행 한도를 가지므로, 한 멤버의 실행 중인 작업이 다른 멤버의 작업을 막지 않습니다.

<Info>
  한 번에 두 개 이상의 작업을 실행하는 것은 API를 통해서만 지원됩니다. Comfy Cloud UI는 사용자당 한 번에 하나의 워크플로를 실행하며, 편집기에서 대기 중인 워크플로는 순서대로 실행됩니다. 구독 세부 정보는 [가격 페이지](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)를 참고하세요.
</Info>

## 런타임 및 실행 대기열 제한

모든 클라우드 워크플로에는 최대 런타임이 있습니다. 제한 시간을 초과하여 실행되는 작업은 자동으로 취소됩니다:

| 요금제 | 최대 런타임 |
| :------- | :-------------- |
| Standard | 30분 |
| Creator  | 30분 |
| Pro      | 1시간 |

한 번에 최대 100개의 워크플로를 실행 대기열에 추가할 수 있습니다. 팀 동시 실행 한도를 높이려면 [고객 지원에 문의하세요](https://support.comfy.org/).

## 배포 과금 {#deployment-billing}

커스텀 Build의 [배포](/ko/development/serverless/overview)는 워커의 GPU 시간과 모델의 스토리지에 대해 Comfy 크레딧으로 과금됩니다.

### 배포되지 않은 Build를 저장하는 데에도 과금되나요?

아니요. Build와 그 버전은 무료로 저장됩니다. 스토리지 과금은 배포할 때 시작됩니다.

- 버전을 배포하면 Comfy Cloud가 해당 모델을 배포의 워커들이 공유하는 네트워크 스토리지로 복사합니다. Comfy Cloud는 해당 리전에 그 Build의 배포가 존재하는 동안, 배포가 중지된 상태일 때도 포함하여, 스토리지 요금을 매월 GB당 청구합니다. 작업이 [워크스페이스 라이브러리](/ko/development/deploy/cloud-custom-builds#나만의-lora-또는-모델-추가)에서 사용하는 모델은 그곳으로 복사되지 않습니다. 워커가 해당 작업을 위해 그 모델들을 다운로드합니다.
  - [배포에 추가](/ko/development/serverless/overview#실행-중인-배포에-모델-추가)한 모델도 그곳으로 복사되며, 해당 스토리지에 포함됩니다.
- 각 워커의 로컬 디스크는 GPU 요금 외에 추가 비용이 없습니다.
- 배포를 삭제하면 해당 컴퓨팅 리소스가 해제됩니다. 네트워크 스토리지에 대한 과금은 이를 사용하는 마지막 배포를 삭제하면 종료됩니다.

스토리지 및 GPU 요금은 Developer Platform에서 [**Limits**](https://platform.comfy.org/settings/limits)를 열고 **Deployment pricing**을 확인하세요. 배포 대화상자의 **Estimated cost** 패널에서도 배포의 GPU 시간과 모델 스토리지를 확인할 수 있습니다.

### always-warm 워커는 어떻게 과금되나요?

[always-warm 워커](/ko/development/serverless/overview#워커-크기-조절)(comfy-cli의 `--min`)는 작업을 처리하든 하지 않든 실행되는 동안 GPU 시간이 과금됩니다.

그 수를 초과하는 워커는 **Max workers**(`--max`)까지 작업이 도착할 때 시작됩니다. 이 워커들은 시작되는 순간부터 작업을 처리하는 동안, 그리고 마지막 작업 이후 해제되기 전까지의 유휴 시간에 대해 GPU 시간이 과금됩니다. 기본적으로 워커는 마지막 작업 후 3분 동안 유지됩니다. Developer Platform에서 배포를 생성할 때 **Keep worker up after a job**에서 이 시간을 30초에서 20분 사이로 설정할 수 있습니다. always-warm 워커가 `0`이면, 유휴 시간이 끝나고 모든 워커가 해제되는 즉시 GPU 과금이 중단됩니다. 다음 작업은 GPU가 시작되는 동안 대기합니다.

워크스페이스의 크레딧이 소진되면 해당 배포가 중지됩니다.

GPU 요금은 Developer Platform에서 [**Limits**](https://platform.comfy.org/settings/limits)를 열고 **Deployment pricing**을 확인하세요. 요금은 워커당, 실행 1시간 기준입니다.

## 기존 v1 연동

지원 중단된 [v1 Cloud API](/ko/development/cloud/overview)도 Comfy Cloud에서 실행됩니다. 기존 연동이나 [Comfy API v2](/ko/api-reference/v2/overview)에서 아직 제공되지 않는 Cloud 기능에 사용하세요. 실행 가능한 예제는 지원 중단된 [Cloud API Reference](/ko/development/cloud/api-reference)에 있습니다.
