Comfy Cloud는 완전 관리형으로 항상 사용할 수 있는 ComfyUI 환경입니다. 브라우저에서 워크플로를 구축하거나 SDK를 통해 실행하세요. 생성해야 할 Build나 배포는 없습니다.

<Note>
  Comfy Cloud가 처음이신가요? [Comfy Cloud 소개](/ko/get_started/cloud)부터 시작하세요. 이 빠른 시작 가이드에서는 앱에서 워크플로를 실행하는 방법을 보여줍니다.
</Note>

## 빠른 시작

유료 구독, [API 키](/ko/development/api-development/getting-an-api-key), API 형식 워크플로가 필요합니다. [Comfy SDK](/ko/development/api-development/sdks)는 기본적으로 Cloud를 대상으로 합니다.

<Steps>
  <Step title="API 키 생성">
    [platform.comfy.org](https://platform.comfy.org)에서 API 키를 생성합니다. 자세한 내용은 [API 키 발급](/ko/development/api-development/getting-an-api-key)을 참고하세요.
  </Step>
  <Step title="SDK 설치">
    <CodeGroup>
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    </CodeGroup>
  </Step>
  <Step title="API 형식으로 워크플로 내보내기">
    클라우드 에디터에서 테스트한 워크플로를 `File → Export Workflow (API)`로 `workflow_api.json`으로 저장합니다. [워크플로 API 형식](/ko/development/api-development/workflow-api-format)을 참고하세요.
  </Step>
  <Step title="실행">
    <CodeGroup>
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")  # Comfy Cloud가 기본 대상입니다

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." }); // Comfy Cloud가 기본 대상입니다

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    </CodeGroup>

    `"9"`는 출력 노드 ID입니다. 입력, 진행 상황, 오류 처리에 대한 내용은 [SDK 가이드](/ko/development/api-development/sdks)를 참고하세요.
  </Step>
</Steps>

동일한 SDK 코드를 [Comfy API 배포](/ko/development/serverless/quickstart)와 [자체 호스팅 ComfyUI](/ko/development/deploy/self-hosting)에도 사용할 수 있습니다. [워크플로 실행](/ko/development/run-workflows/overview)을 참고하세요.
