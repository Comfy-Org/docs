Comfy Cloud는 상태 저장형, 대화형, 완전 관리형 버전의 ComfyUI입니다. 로컬 설치에서 하듯 브라우저에서 워크플로를 빌드하고 실행할 수 있으며, Comfy가 모델, GPU, 그 사이의 모든 것을 관리합니다. 또한 API를 통해 직접 호출할 수도 있습니다. Comfy Cloud를 서버리스 API 엔드포인트로 사용하면 구축할 환경도, 생성할 배포도 없습니다.

이는 영구적인 서버리스 배포라고 생각할 수 있습니다. [Serverless API](/ko/development/serverless/overview) 배포가 사용자가 빌드하고 릴리스하는 하나의 고정된 환경을 제공하는 반면, Comfy Cloud는 항상 켜져 있는 완전 관리형 ComfyUI를 제공합니다.

<Note>
  Comfy Cloud가 처음이라면 [Comfy Cloud 소개](/ko/get_started/cloud)를 참조하세요. 이 섹션에서는 개발자로서 Comfy Cloud API를 사용하는 방법을 다룹니다.
</Note>

## 빠른 시작

Comfy Cloud는 [Comfy SDK](/ko/development/api-development/sdks)와 별도의 설정 없이 사용할 수 있습니다. 기본 URL은 Comfy Cloud를 가리키므로 [API 키](/ko/development/api-development/getting-an-api-key)와 워크플로만 있으면 됩니다. API 액세스에는 유료 Comfy Cloud 구독이 필요하며, 무료 티어에는 포함되지 않습니다.

<Steps>
  <Step title="API 키 생성">
    [platform.comfy.org](https://platform.comfy.org)에 로그인한 다음 키를 생성하세요. 단계별 지침은 [API 키 얻기](/ko/development/api-development/getting-an-api-key)를 참조하세요.
  </Step>
  <Step title="SDK 설치">
    <CodeGroup>
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    </CodeGroup>
  </Step>
  <Step title="API 형식으로 워크플로 내보내기">
    클라우드 편집기에서 워크플로를 빌드하고 테스트한 다음 `파일 → 워크플로 내보내기 (API)`로 저장하여 `workflow_api.json` 파일을 만듭니다. [워크플로 API 형식](/ko/development/api-development/workflow-api-format)을 참조하세요.
  </Step>
  <Step title="실행하기">
    <CodeGroup>
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")  # Comfy Cloud is the default target

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." }); // Comfy Cloud is the default target

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    </CodeGroup>

    `"9"`는 워크플로 파일의 출력 노드 ID입니다. 입력, 진행 이벤트 및 오류 처리에 대한 자세한 내용은 [SDK 가이드](/ko/development/api-development/sdks)를 참조하세요.
  </Step>
</Steps>

동일한 코드가 Comfy Cloud, Serverless, 자체 호스팅 배포 간에 어떻게 이동하는지 알아보려면 [워크플로 실행](/ko/development/run-workflows/overview)을 참조하세요.

## 크레딧 및 사용량

API 요청은 Comfy Cloud 웹 UI와 동일한 월간 크레딧 할당량을 사용합니다. 별도의 API 크레딧 풀이 없습니다. 각 등급에 포함된 크레딧, 충전 옵션, 워크플로별 런타임 상한은 API 작업에도 UI 작업과 동일하게 적용됩니다. 각 등급의 월간 크레딧 금액은 [가격 페이지](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)에서 확인할 수 있습니다. 월 중간에 크레딧이 소진되면 계정 대시보드에서 충전을 구매할 수 있습니다.

## 병렬 실행(동시 작업)

API 사용자는 이전 작업이 완료될 때까지 기다리지 않고 여러 워크플로를 동시에 제출할 수 있습니다. 제출은 작업이 수락되는 즉시 반환되므로 여러 작업을 진행 중인 상태로 유지할 수 있습니다. 디스패처는 구독 등급의 한도까지 작업을 병렬로 실행합니다. 현재 동시 실행 수는 [platform.comfy.org](https://platform.comfy.org)에서 확인하세요.

동시 실행 한도를 초과하여 제출된 작업은 일반적으로 실행 대기열에 들어가며 슬롯이 비워지면 자동으로 실행됩니다. 실행 대기열 자체가 가득 찬 경우 SDK가 `QueueFull`을 발생시키기 전에 제한된 범위 내에서 자동으로 재시도합니다.

<Info>
  병렬 실행은 현재 API에서만 사용할 수 있습니다. 구독 세부 정보는 [가격 페이지](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)에서 확인하세요.
</Info>

## 기존 v1 통합

지원 중단된 [v1 Cloud API](/ko/development/cloud/overview)도 Comfy Cloud에서 실행됩니다. 기존 통합이나 [Comfy API v2](/ko/api-reference/v2/overview)에서 아직 제공하지 않는 클라우드 기능에만 사용하세요. 실행 가능한 예제는 [Cloud API Reference](/ko/development/cloud/api-reference)(지원 중단됨)에서 확인할 수 있습니다.
