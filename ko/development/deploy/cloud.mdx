[Comfy SDKs](/ko/development/api-development/sdks)를 사용하면 백엔드 서비스나 배치 스크립트 같은 자체 애플리케이션에서 Comfy Cloud 편집기로 만든 워크플로를 실행할 수 있습니다. Comfy Cloud는 기본 커스텀 노드 세트가 포함된 표준 빌드에서 워크플로를 실행합니다. 워크플로에 표준 빌드에 없는 커스텀 노드나 모델이 필요하면 커스텀 빌드를 생성합니다. 커스텀 빌드는 직접 만든 커스텀 노드와 모델을 묶은 패키지로, Comfy Cloud가 이를 대신 실행합니다. 이 페이지에서는 표준 빌드에서 API를 통해 워크플로를 실행하는 방법을 보여 준 다음, 동일한 코드가 커스텀 빌드를 사용하도록 지정하는 방법을 설명합니다.

## 시작하기 전에

코드에서 Comfy Cloud를 호출하려면 다음 항목이 필요합니다:

- **유료 Comfy Cloud 구독**
- **Comfy Cloud 편집기에서 실행되는 워크플로**: 코드에서 실행하기 전에 편집기에서 테스트하세요. 표준 빌드에 없는 커스텀 노드나 모델이 필요하다면 먼저 [커스텀 빌드 생성](/ko/development/deploy/cloud-custom-builds)하세요.
- **Python 3.10 이상 또는 Node 22 이상**: 설치하는 SDK에 이 중 하나가 필요합니다.

아직 Comfy Cloud를 사용해 본 적이 없다면 [Comfy Cloud](/ko/get_started/cloud)부터 시작하세요.

## 표준 빌드에서 워크플로 실행

표준 빌드는 Comfy Cloud가 지원하는 커스텀 노드만 사용하는 모든 워크플로를 실행합니다. 코드에서 워크플로를 실행하려면 API 키를 생성하고, SDK를 설치하고, 워크플로를 API 형식으로 내보내면 됩니다.

<Steps>
  <Step title="API 키 생성">
    애플리케이션은 각 요청과 함께 키를 전송하므로, Developer Platform에서 애플리케이션용 키를 생성하세요.

    1. [platform.comfy.org](https://platform.comfy.org)에서 로그인한 다음 **API Keys**를 클릭합니다.
    2. **New API key**를 클릭하고 이름을 입력한 다음 **Generate key**를 클릭합니다.
    3. 키를 복사하여 안전한 곳에 보관합니다. Developer Platform은 키를 한 번만 표시합니다.

    키는 `comfyui-`로 시작합니다. 키 관리 방법은 [API 키 발급](/ko/development/api-development/getting-an-api-key)을 참조하세요.
  </Step>
  <Step title="SDK 설치">
    <CodeGroup>
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    </CodeGroup>
  </Step>
  <Step title="워크플로를 API 형식으로 내보내기">
    SDK는 편집기가 저장하는 파일이 아니라 워크플로의 API 형식을 전송합니다.

    - Comfy Cloud 편집기에서 워크플로를 열고 **File** > **Export (API)**를 선택한 다음 파일을 `workflow_api.json`으로 저장합니다.

    파일에 포함된 내용은 [워크플로 API 형식](/ko/development/api-development/workflow-api-format)을 참조하세요.
  </Step>
  <Step title="워크플로 실행">
    다른 기본 URL을 설정하지 않는 한 SDK는 Comfy Cloud로 요청을 전송하므로, API 키만 전달하면 됩니다.

    <CodeGroup>
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." });

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    </CodeGroup>

    - `"9"`를 `workflow_api.json`에 있는 출력 노드의 ID로 바꾸세요.
    - `run()`은 작업이 끝날 때까지 기다린 다음, 코드가 출력을 디스크에 기록합니다.

    입력을 설정하고, 진행 상황을 추적하고, 오류를 처리하는 방법은 [Comfy SDK](/ko/development/api-development/sdks)를 참조하세요.
  </Step>
</Steps>

## 사용자 정의 Build에서 워크플로 실행

사용자 정의 Build를 배포하면 고유한 URL을 가진 배포가 생성됩니다. 기본 URL을 변경하면 이전 섹션의 코드가 배포에서 실행됩니다.

<Warning>
  배포는 워커가 실행되는 동안 GPU 시간이, 삭제할 때까지 스토리지가 과금됩니다. 테스트를 완료하면 중지하거나 삭제하세요. [정리](/ko/development/serverless/overview#정리)를 참고하세요.
</Warning>

<Steps>
  <Step title="Build 생성 및 배포">
    [사용자 정의 Build](/ko/development/deploy/cloud-custom-builds)를 따라 워크플로에서 Build를 생성하고 배포하세요.
  </Step>
  <Step title="배포 URL 복사">
    1. Developer Platform에서 배포 페이지를 엽니다.
    2. 배포 상태가 **Ready**로 표시될 때까지 기다립니다.
    3. **Run via API**에서 **Deployment URL**을 복사합니다.

    배포 URL은 `https://dep-<id>.run.comfy.app` 형식입니다.
  </Step>
  <Step title="기본 URL 설정">
    `COMFY_BASE_URL`을 배포 URL로 설정합니다:

    ```bash
    export COMFY_BASE_URL="https://dep-<id>.run.comfy.app"
    ```
  </Step>
  <Step title="워크플로 실행">
    API 키와 함께 [표준 빌드에서 워크플로 실행](#표준-빌드에서-워크플로-실행)의 코드를 실행합니다. 이제 SDK가 작업을 배포로 전송합니다.
  </Step>
</Steps>

<Tip>
  터미널에서 먼저 배포를 테스트하려면 다음을 실행하세요:

  ```bash
  comfy deploy run --deployment <deployment-id> --workflow workflow_api.json
  ```
</Tip>
