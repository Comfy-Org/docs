Comfy Cloud는 상태를 유지하는 대화형 완전 관리형 ComfyUI 버전입니다. 로컬 설치에서처럼 브라우저에서 워크플로를 구축하고 실행할 수 있으며, Comfy가 모델과 GPU, 그리고 그 사이의 모든 것을 관리합니다. API를 통해 Comfy Cloud를 호출할 수도 있습니다. Comfy Cloud는 관리형 엔드포인트를 제공하므로 구축할 환경도, 생성할 배포도 없습니다.

직접 구축하고 릴리스하는 하나의 고정된 환경을 제공하는 [Comfy API 배포](/ko/development/serverless/overview)와 달리, Comfy Cloud는 항상 켜져 있는 완전한 관리형 ComfyUI를 제공합니다.

<Note>
  처음 접하신다면 [Comfy Cloud 소개](/ko/get_started/cloud)를 참고하세요. 이 섹션에서는 개발자로서 Comfy Cloud API를 사용하는 방법을 다룹니다.
</Note>

## 빠른 시작

Comfy Cloud는 [Comfy SDK](/ko/development/api-development/sdks)와 별도 설정 없이 바로 작동합니다. 기본 URL이 Comfy Cloud로 설정되어 있으므로 [API 키](/ko/development/api-development/getting-an-api-key)와 워크플로만 있으면 됩니다. API 액세스에는 유료 Comfy Cloud 구독이 필요하며, 무료 티어에는 포함되지 않습니다.

<Steps>
  <Step title="API 키 생성">
    [platform.comfy.org](https://platform.comfy.org)에 로그인하고 키를 생성합니다. 단계별 안내는 [API 키 발급](/ko/development/api-development/getting-an-api-key)을 참고하세요.
  </Step>
  <Step title="SDK 설치">
    <CodeGroup>
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    </CodeGroup>
  </Step>
  <Step title="API 형식으로 워크플로 내보내기">
    클라우드 에디터에서 워크플로를 빌드하고 테스트한 다음, `File → Export Workflow (API)`를 사용해 `workflow_api.json`으로 저장합니다. [워크플로 API 형식](/ko/development/api-development/workflow-api-format)을 참고하세요.
  </Step>
  <Step title="실행">
    <CodeGroup>
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")  # Comfy Cloud is the default target

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." }); // Comfy Cloud is the default target

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    </CodeGroup>

    `"9"`는 워크플로 파일에 있는 출력 노드의 ID입니다. 입력, 진행 이벤트, 오류 처리에 대한 내용은 [SDK 가이드](/ko/development/api-development/sdks)를 참고하세요.
  </Step>
</Steps>

동일한 코드가 Comfy Cloud, Comfy API 배포, 자체 호스팅 배포 간에 어떻게 이동하는지 알아보려면 [워크플로 실행](/ko/development/run-workflows/overview)을 참고하세요.

## 크레딧 및 사용량

API 요청은 Comfy Cloud 웹 UI와 동일한 월간 크레딧 할당량에서 차감됩니다. 별도의 API 크레딧 풀은 없습니다. 각 티어에 포함된 크레딧, 충전 옵션, 워크플로별 런타임 상한은 UI 작업과 정확히 동일한 방식으로 API 작업에도 적용됩니다. 각 티어의 월간 크레딧 금액은 [가격 페이지](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)를 참조하세요. 월 중간에 크레딧이 소진되면 계정 대시보드에서 충전을 구매할 수 있습니다.

## 병렬 실행 (동시 작업)

API 사용자는 이전 작업이 완료될 때까지 기다리지 않고 여러 워크플로를 동시에 제출할 수 있습니다. 제출은 작업이 접수되는 즉시 반환되므로 여러 작업을 동시에 진행할 수 있습니다. 디스패처는 구독 등급의 한도까지 이들을 병렬로 실행합니다. 현재 동시 실행 수는 [platform.comfy.org](https://platform.comfy.org)에서 확인하세요.

동시 실행 한도를 초과하여 제출된 작업은 정상적으로 실행 대기열에 들어가며, 슬롯이 확보되는 대로 자동으로 실행됩니다. 대기열 자체가 가득 찬 경우 SDK가 제한된 예산 내에서 대신 재시도한 후 `QueueFull`을 발생시킵니다.

<Info>
  병렬 실행은 현재 API를 통해서만 사용할 수 있습니다. 구독 세부 정보는 [가격 페이지](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)를 참조하세요.
</Info>

## 기존 v1 통합

지원 중단된 [v1 Cloud API](/ko/development/cloud/overview)도 Comfy Cloud에서 실행됩니다. 기존 통합이나 [Comfy API v2](/ko/api-reference/v2/overview)가 아직 제공하지 않는 Cloud 기능에만 사용하세요. 실행 가능한 예제는 [Cloud API Reference](/ko/development/cloud/api-reference)(지원 중단됨)에 있습니다.
