ComfyUI를 헤드리스로 실행하기 위한 공개 API는 시간이 지남에 따라 발전해 왔습니다. 새로운 통합의 경우 [Comfy API v2](/ko/api-reference/v2/overview)를 사용하세요. 오픈소스 ComfyUI(베타 기간 동안 [API Proxy](/ko/development/comfyui-server/api-proxy)를 통해), Comfy Cloud, 그리고 새로운 [Serverless API](/ko/development/serverless/overview)에서 지원됩니다. 이전 버전에는 지원 중단된 [v1 Cloud API](/ko/development/cloud/overview)가 포함됩니다.

  </Card>
