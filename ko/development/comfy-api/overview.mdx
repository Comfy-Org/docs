ComfyUI를 헤드리스로 실행하기 위한 퍼블릭 API는 시간이 지나면서 발전해 왔습니다. 새로운 통합에는 [Comfy API v2](/ko/api-reference/v2/overview)를 사용하세요. 오픈소스 ComfyUI는 [API Proxy](/ko/development/comfyui-server/api-proxy)를 통해 이 API를 제공하며, Comfy Cloud와 [개발자 플랫폼의 Comfy API 배포](/ko/development/serverless/overview)도 이 API를 지원합니다. 이전 버전으로는 [v1 Cloud API](/ko/development/cloud/overview)가 있으며, 이는 지원 중단되었습니다.
