ComfyUI를 헤드리스로 실행하기 위한 퍼블릭 API는 시간이 지나면서 발전해 왔습니다. 새로운 통합에는 [Comfy API v2](/ko/api-reference/v2/overview)를 사용하세요. 이는 오픈소스 ComfyUI(베타 기간 동안에는 [API Proxy](/ko/development/comfyui-server/api-proxy)를 통해), Comfy Cloud, 그리고 [개발자 플랫폼의 Comfy API 배포](/ko/development/serverless/overview)에서 지원됩니다. 이전 버전으로는 [v1 Cloud API](/ko/development/cloud/overview)가 있으며, 이는 지원 중단되었습니다.
