코드에서 완전한 워크플로를 실행하고 출력을 `first-result.png`로 저장하세요. 이 샘플은 두 개의 내장 노드를 사용해 **512 × 512 단색 파란색 이미지**를 생성합니다. 모델, 입력 이미지, 커스텀 노드 없이도 인증, 워크플로 실행, 출력 다운로드를 검증합니다.

호스팅된 모델을 직접 호출해 이미지를 생성하려면 [Comfy Router 빠른 시작](/ko/development/comfy-router/quickstart)부터 시작하세요.

## 시작하기 전에

- [Comfy API 키](/ko/development/api-development/getting-an-api-key)가 필요합니다.
- [유료 Comfy Cloud 구독](/ko/development/deploy/cloud)이 필요합니다. 클라우드 워크플로 API 액세스는 무료 티어에 포함되지 않습니다.
- Python 3.10 이상, 또는 TypeScript 예제를 사용하는 경우 Node.js 22.18 이상이 필요합니다.

이 가이드에서는 SDK의 기본 대상인 Comfy Cloud를 사용합니다. 이전에 `COMFY_BASE_URL`을 설정한 경우, Comfy Cloud를 사용하려면 해당 설정을 해제하세요. 기존 Comfy API 배포 또는 자체 호스팅 인스턴스를 사용하는 경우에는 [기본 URL 선택](/ko/development/api-development/sdks#기본-url-선택)을 참조하세요.

## 1. 샘플 다운로드

예제를 위한 폴더를 생성하세요. [workflow_api.json](/files/api-first-result/workflow_api.json)과 사용하는 언어의 스크립트를 해당 폴더에 다운로드하세요:

- [Python: first_workflow.py](/files/api-first-result/first_workflow.py)
- [TypeScript: first_workflow.mts](/files/api-first-result/first_workflow.mts)

워크플로는 이미 API 형식입니다. 노드 `"1"`은 파란색 이미지를 생성하고 노드 `"2"`는 이를 저장합니다. 스크립트는 바로 그 SaveImage 노드에서 출력을 읽으므로 노드 ID를 찾거나 편집할 필요가 없습니다.

## 2. SDK 설치 및 키 설정

파일을 저장한 폴더에서 터미널을 엽니다.

<CodeGroup>
```bash Python
python -m venv .venv
source .venv/bin/activate
python -m pip install comfy-sdk
```

```bash TypeScript
npm init -y
npm install @comfyorg/sdk
```
</CodeGroup>

Windows에서는 PowerShell에서 `.venv\Scripts\Activate.ps1`로 Python 환경을 활성화합니다.

같은 터미널에서 키를 설정합니다:

<CodeGroup>
```bash macOS / Linux
export COMFY_API_KEY="comfyui-your-key"
```

```powershell Windows PowerShell
$env:COMFY_API_KEY = "comfyui-your-key"
```
</CodeGroup>

API 키는 서버 환경에 보관하세요. 브라우저 코드에 포함하거나 소스 관리 시스템에 커밋하지 마세요.

## 3. 실행하고 결과 확인하기

<CodeGroup>
```bash Python
python first_workflow.py
```

```bash TypeScript
node first_workflow.mts
```
</CodeGroup>

이 스크립트는 워크플로를 제출하고, 완료될 때까지 기다린 뒤 이미지를 다운로드합니다. `Saved`와 함께 경로가 출력되면 해당 위치에서 `first-result.png`를 열어 보세요. 단색 파란색 정사각형이 보일 것입니다. 샘플을 다시 실행하면 해당 로컬 파일이 교체됩니다.

<Note>
  이것은 워크플로 연결 확인용입니다. 생성 모델을 사용하지 않습니다. 동일한 제출, 대기, 다운로드 단계가 여러분의 자체 생성 워크플로에서도 그대로 동작합니다.
</Note>

### 요청이 실패하는 경우

- **키 누락 또는 인증 실패:** 스크립트를 실행하는 터미널에 `COMFY_API_KEY`가 설정되어 있고 유효한 키가 들어 있는지 확인하세요.
- **접근 또는 크레딧 오류:** 다시 시도하기 전에 Cloud 구독과 사용 가능한 크레딧을 확인하세요.
- **워크플로 파일을 찾을 수 없음:** 다운로드한 스크립트와 같은 위치에 `workflow_api.json`을 두세요.
- **예상치 못한 엔드포인트:** `COMFY_BASE_URL`을 확인하세요. 이 Cloud 예제에서는 설정을 해제하세요.

오류 처리와 작업 진행 상황은 [SDK 가이드](/ko/development/api-development/sdks)를 참고하세요.

## 4. 자체 생성 워크플로 실행

ComfyUI 에디터에서 워크플로를 만들거나 선택하고, 그곳에서 성공적으로 실행한 뒤 [API 형식으로 내보내기](/ko/development/api-development/workflow-api-format)하세요. `workflow_api.json`을 내보낸 파일로 교체하고, Python에서는 `get_outputs("2")`를, TypeScript에서는 `getOutputs("2")`를 워크플로의 SaveImage 노드 ID를 사용하도록 업데이트하세요. 대상 환경에 워크플로에서 사용하는 모델과 커스텀 노드가 있는지 확인하세요.

자체 모델과 커스텀 노드로 워크플로를 호스팅하려면 [Comfy API 배포](/ko/development/serverless/overview)를 생성하세요. 워크플로 입력을 변경하거나 파일을 업로드하거나 진행 상황을 확인하려면 [Comfy SDKs](/ko/development/api-development/sdks)로 계속하세요.
