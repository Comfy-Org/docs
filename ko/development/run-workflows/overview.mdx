ComfyUI가 [어딘가에 배포되면](/ko/development/deploy/overview), 애플리케이션은 해당 ComfyUI를 대상으로 워크플로를 실행합니다: 워크플로를 제출하고, 실행을 기다린 다음, 출력을 다운로드합니다. 이 페이지에서는 어떤 배포 환경에 어떤 클라이언트를 사용해야 하는지 설명합니다.

## 여기서 시작하세요: Comfy SDK

새로운 통합을 구축할 때는 공식 **Comfy SDK**(Python 및 TypeScript)와 SDK가 호출하는 [Comfy API v2](/ko/api-reference/v2/overview)를 사용하세요. 동일한 코드가 모든 배포 대상에서 실행되며, 기본 URL만 변경하면 됩니다.

<Card title="Comfy SDKs" icon="code" href="/ko/development/api-development/sdks">
  SDK를 설치하고, 워크플로를 제출하고, 출력을 다운로드하세요. 현재 베타 버전입니다.
</Card>

## 무엇이 무엇과 호환되나요

| 배포 | Comfy SDKs / API v2 | 참고 사항 |
|---|---|---|
| **Serverless API 배포** | 예 | API 키를 사용해 `COMFY_BASE_URL`을 `https://<deployment>.run.comfy.app`으로 설정하세요 |
| **Comfy Cloud** | 예 | 기본 베이스 URL입니다. API 키와 유료 구독이 필요합니다 |
| **자체 호스팅** | 예, [API 프록시](/ko/development/comfyui-server/api-proxy)를 통해 | v2 베타 기간에는 ComfyUI와 함께 실행되는 작은 서비스가 v2 API를 제공합니다 |

자체 호스팅 인스턴스는 SDK를 완전히 건너뛰고 [ComfyUI Server API](/ko/development/comfyui-server/comms_overview)(REST + WebSocket)를 직접 사용할 수도 있습니다. 이 API는 실행 대기열과 노드 정보를 포함한 로컬의 모든 기능을 노출하지만, 릴리스 간 호환성은 보장되지 않습니다.

## 어떤 API를 사용해야 하나요?

| | Comfy API v2 + SDKs | v1 Cloud API | ComfyUI Server API |
|---|---|---|---|
| **실행 위치** | 서버리스 배포, Comfy Cloud 또는 API 프록시를 통한 자체 호스팅 | Comfy Cloud 전용 | 자체 호스팅 전용 |
| **호환성** | 버전 관리됨, v2 내에서 추가 변경만 허용 | 지원 중단됨, 사전 공지 없이 변경될 수 있음 | 릴리스 간 보장 없음 |
| **인증** | 클라우드 및 서버리스에서 `Authorization: Bearer`. 자체 호스팅: 기본적으로 없음, 선택적 정적 베어러 토큰 | `X-API-Key` 헤더(Comfy Cloud 계정) | 없음(로컬) 또는 파트너 노드용 API 키 |
| **공식 클라이언트** | Python 및 TypeScript SDK | 없음, HTTP로 호출 | 없음, HTTP로 호출 |
| **프로토콜** | REST + SSE | REST + WebSocket | REST + WebSocket |
| **범위** | 워크플로 실행 및 결과 얻기 | 모델 및 계정을 포함한 Cloud의 전체 기능 | 실행 대기열 및 노드 정보를 포함한 로컬의 전체 기능 |
| **적합한 용도** | 지속적으로 작동해야 하는 새로운 통합 | 기존 통합 및 v2가 아직 다루지 않는 Cloud 기능 | 완전한 제어, 자체 인스턴스를 위한 맞춤형 도구 |

세 API 모두 동일한 워크플로 형식([API 형식](/ko/development/api-development/workflow-api-format))을 지원하므로 워크플로를 로컬에서 개발하고 테스트한 후 변경 없이 다른 배포 환경으로 이동할 수 있습니다.

## 전제 조건

- Comfy Cloud, Serverless 배포 또는 파트너 노드를 사용하는 모든 작업에는 [API 키](/ko/development/api-development/getting-an-api-key)가 필요합니다. 로컬 전용 ComfyUI에는 필요하지 않습니다.
- [API 형식](/ko/development/api-development/workflow-api-format)으로 내보낸 워크플로.
