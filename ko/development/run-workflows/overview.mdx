ComfyUI가 [어딘가에 배포](/ko/development/deploy/overview)되면, 애플리케이션은 이를 대상으로 워크플로를 실행합니다. 워크플로를 제출하고, 실행을 기다린 다음, 출력을 다운로드합니다. 이 페이지에서는 어떤 배포 환경에 어떤 클라이언트를 사용해야 하는지 정리합니다.

## 여기서 시작하기: Comfy SDKs

새로운 통합을 시작할 때는 공식 **Comfy SDKs**(Python 및 TypeScript)와 이들이 호출하는 [Comfy API v2](/ko/api-reference/v2/overview)를 사용하세요. 동일한 코드가 모든 배포 대상에서 실행되며, 베이스 URL만 변경하면 됩니다.

<Card title="Comfy SDKs" icon="code" href="/ko/development/api-development/sdks">
  SDK를 설치하고, 워크플로를 제출하고, 출력을 다운로드하세요. 현재 베타 버전입니다.
</Card>

## 어떤 배포 환경에서 무엇이 작동하는가

| 배포 환경 | Comfy SDKs / API v2 | 비고 |
|---|---|---|
| **Comfy API 배포** | 예 | `COMFY_BASE_URL`을 `https://<deployment>.run.comfy.app`로 지정하고 API 키를 함께 사용하세요 |
| **Comfy Cloud** | 예 | 기본 base URL입니다. API 키와 유료 구독이 필요합니다 |
| **셀프 호스팅** | 예, [API Proxy](/ko/development/comfyui-server/api-proxy)를 통해 가능 | v2 베타 기간에는 ComfyUI와 함께 실행되는 소규모 서비스가 v2 API를 제공합니다 |

셀프 호스팅 인스턴스는 SDK를 완전히 건너뛰고 원시 [ComfyUI Server API](/ko/development/comfyui-server/comms_overview)(REST + WebSocket)를 사용할 수도 있습니다. 이 API는 실행 대기열과 노드 정보를 포함한 전체 로컬 기능을 노출하지만, 릴리스 간 호환성은 보장되지 않습니다.

## 어떤 API를 사용해야 하나요?

| | Comfy API v2 + SDK | v1 Cloud API | ComfyUI Server API |
|---|---|---|---|
| **실행 위치** | Comfy API 배포, Comfy Cloud, 또는 API Proxy를 통한 자체 호스팅 | Comfy Cloud 전용 | 자체 호스팅 전용 |
| **호환성** | 버전이 관리되며, v2 내에서는 추가적인 변경만 발생 | 지원 중단됨, 예고 없이 변경될 수 있음 | 릴리스 간 보장 없음 |
| **인증** | Comfy Cloud 및 Comfy API 배포에서는 `Authorization: Bearer`. 자체 호스팅: 기본적으로 없음, 선택적 정적 bearer 토큰 | `X-API-Key` 헤더 (Comfy Cloud 계정) | 없음(로컬) 또는 파트너 노드용 API 키 |
| **공식 클라이언트** | Python 및 TypeScript SDK | 없음, HTTP로 직접 호출 | 없음, HTTP로 직접 호출 |
| **프로토콜** | REST + SSE | REST + WebSocket | REST + WebSocket |
| **범위** | 워크플로를 실행하고 결과 받기 | 모델과 계정을 포함한 전체 클라우드 기능 | 실행 대기열과 노드 정보를 포함한 전체 로컬 기능 |
| **적합한 용도** | 계속 작동해야 하는 새 통합 | 기존 통합 및 v2가 아직 지원하지 않는 클라우드 기능 | 완전한 제어, 자체 인스턴스에 대한 사용자 정의 도구 |

모두 동일한 워크플로 형식([API 형식](/ko/development/api-development/workflow-api-format))을 사용하므로, 로컬에서 워크플로를 개발하고 테스트한 뒤 변경 없이 다른 배포로 옮길 수 있습니다.

## 사전 요구 사항

- Comfy Cloud, Comfy API 배포 또는 파트너 노드와 관련된 모든 작업에는 [API 키](/ko/development/api-development/getting-an-api-key)가 필요합니다. 순수 로컬 ComfyUI에는 필요하지 않습니다.
- [API 형식](/ko/development/api-development/workflow-api-format)으로 내보낸 워크플로.
