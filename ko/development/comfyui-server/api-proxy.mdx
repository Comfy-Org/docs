[Comfy SDK](/ko/development/api-development/sdks)는 [Comfy API v2](/ko/api-reference/v2/overview)를 사용합니다. 베타 기간 동안 자체 호스팅 ComfyUI는 v2를 자체적으로 제공하지 않습니다. [comfy-api-proxy](https://github.com/Comfy-Org/comfy-api-proxy)는 인스턴스와 함께 실행되며 그 앞에서 v2 규약을 제공하는 작은 오픈 소스 서비스입니다.

<Note>
  이 프록시는 임시 방편입니다. v2 API가 안정화되면 ComfyUI 코어로 편입되며 프록시는 더 이상 필요하지 않습니다.
</Note>

## 설치 및 실행

```bash
pip install comfy-api-proxy
comfy-api-proxy
```

기본적으로 `127.0.0.1:8188`의 ComfyUI를 프록시하고 `127.0.0.1:8189`에서 v2 API를 제공합니다. 둘 중 하나를 변경하려면 `--comfyui`와 `--port`를 사용하세요.

설치 디렉터리에 모델 파일도 업로드하려면 `--comfyui-base-dir /path/to/ComfyUI`를 지정하여 실행하세요.

## SDK를 프록시에 연결하기

기본 URL을 설정하고 평소처럼 클라이언트를 생성합니다:

```bash
export COMFY_BASE_URL="http://127.0.0.1:8189"
```

<CodeGroup>
```python Python
from comfy_sdk import Comfy

client = Comfy()
```

```typescript TypeScript
import { Comfy } from "@comfyorg/sdk";

const client = new Comfy();
```
</CodeGroup>

[SDK 가이드](/ko/development/api-development/sdks)의 모든 내용은 Comfy Cloud에 대해서와 동일하게 프록시에 대해서도 작동합니다.

## 인증

기본적으로 인증은 필수 사항이 아닙니다. 프록시가 정적 bearer 토큰으로 구성된 경우, 해당 토큰을 SDK API 키로 전달하세요: `Comfy(api_key="...")`.

<Warning>
  프록시는 기본적으로 loopback에만 바인딩됩니다. 대여한 GPU의 ComfyUI 앞에 두는 등 loopback 너머로 노출하는 경우, bearer 토큰을 구성하거나 인증을 수행하는 리버스 프록시를 앞에 배치하세요.
</Warning>
