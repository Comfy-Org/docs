모델을 선택하고 스키마를 확인한 뒤 `POST /v2/models/{provider}/{model}`를 호출하세요. 라우트와 인증은 모든 모델에서 동일하게 유지됩니다. 각 모델은 자체 네이티브 요청 본문을 받고 자체 네이티브 결과를 반환합니다.
