동일한 본문을 `POST https://api.comfy.org/v2/models/bfl/video-upscale-v1/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`로 응답하며, 결과는 준비되는 대로 이 프로세스 또는 다른 프로세스에서 수집합니다. [대기열 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 안내합니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도를 위해 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bfl/video-upscale-v1",
            {
                "input_video": "https://your-host.example/clip.mp4",
                "upscale_factor": 2,
                "creativity": 1,
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자의 자체 페이로드이며, models.run()이 반환하는 것과 동일한 값입니다.
        # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print("video:", result["result"]["sample"])

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도를 위해 재사용합니다.
type Result = { result: { sample: string } };
const handle = await comfy.models.submit<Result>("bfl/video-upscale-v1", {
  input_video: "https://your-host.example/clip.mp4",
  upscale_factor: 2,
  creativity: 1,
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();
if (result.kind !== "json") throw new Error("expected a JSON result");

console.log("video:", result.data.result.sample);
```

```bash cURL
# 1. 제출합니다. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/bfl/video-upscale-v1/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"input_video\": \"https://your-host.example/clip.mp4\", \"upscale_factor\": 2, \"creativity\": 1}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 대기합니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/bfl/video-upscale-v1/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집합니다. 모델의 네이티브 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202를 반환합니다.
```

## 스키마

### 입력

<ParamField body="creativity" type="integer" default="1">
  0은 소스를 정확하게 보존하고 선명하게 만듭니다. 1은 창의적인 디테일 향상을 허용하며, 이 경우 얼굴이나 제품이 엄격하게 보존되지 않습니다.

  범위: `0`부터 `1`까지
</ParamField>

<ParamField body="input_video" type="string" required>
  업스케일할 비디오로, HTTP(S) URL 또는 base64로 인코딩된 MP4입니다. 소스 영상은 최대 20초, 50MB까지입니다.
</ParamField>

<ParamField body="prompt" type="string">
  클립 내용에 대한 선택적 설명으로, 향상되는 디테일을 조정합니다. 중립적인 업스케일을 원하면 비워 두세요.
</ParamField>

<ParamField body="safety_tolerance" type="integer" default="2">
  프롬프트 및 출력 프레임 검열에 대한 허용 수준이며, 0이 가장 엄격합니다.

  범위: `0`부터 `4`까지
</ParamField>

<ParamField body="upscale_factor" type="number" default="2">
  소스 해상도 대비 출력 배율입니다. 출력은 소스의 가로세로 비율을 유지하며 프레임당 약 14.4메가픽셀로 제한되므로, 소스가 매우 큰 경우에는 요청한 배율보다 작게 확대됩니다.

  범위: `1.5`부터 `3`까지

  형식: `float`
</ParamField>

<ParamField body="webhook_secret" type="string">
  웹훅 서명 검증을 위한 선택적 시크릿입니다.
</ParamField>

<ParamField body="webhook_url" type="string (uri)">
  웹훅 알림을 받을 URL입니다.

  형식: `uri`
</ParamField>

Router가 `GET /v2/models/bfl/video-upscale-v1/openapi.json`에서 제공하는 스키마에서 생성되며, 이는 요청이 공급자에게 도달하기 전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.

### 출력

<ResponseField name="cost" type="number">
  크레딧 단위로 공급자가 보고한 비용이며, 작업이 Ready 상태가 되면 채워집니다.

  형식: `float`
</ResponseField>

<ResponseField name="id" type="string" required>
  BFL 작업 식별자입니다.
</ResponseField>

<ResponseField name="progress" type="number">
  BFL이 보고하는 선택적 생성 진행률입니다.

  범위: `0`부터 `1`까지

  형식: `float`
</ResponseField>

<ResponseField name="result" type="object" required>
  완료된 생성 결과입니다. 여기서는 null을 허용하지 않습니다. 이 컴포넌트의 `required` 항목은 `200` 응답이 결과를 포함한다는 약속이며, `result`가 null을 허용하면 이는 키 존재 여부 확인으로 축소됩니다.
</ResponseField>

<ResponseField name="result.cost" type="number">
  공급자가 보고한 생성 비용입니다. 이는 BFL의 수치이며 Comfy 청구 금액이 아닙니다.

  형식: `double`
</ResponseField>

<ResponseField name="result.duration" type="number">
  공급자가 보고한 생성 재생 시간(초)입니다.

  형식: `double`
</ResponseField>

<ResponseField name="result.end_time" type="number">
  공급자가 보고한 생성 완료 시간으로, Unix 에포크 이후 초 단위입니다. `start_time`과 같은 이유로 `double`입니다.

  형식: `double`
</ResponseField>

<ResponseField name="result.prompt" type="string">
  프롬프트 업샘플링 이후 생성이 실제로 실행한 프롬프트입니다.
</ResponseField>

<ResponseField name="result.sample" type="string (uri)">
  생성된 결과물에 대한 서명된 URL입니다. Router는 결과물을 Comfy 스토리지에 다시 호스팅하고 이 필드를 다시 씁니다. 따라서 일반적으로 최대 24시간 동안 유효한 Comfy 호스팅 URL입니다. 발급 시점에 24시간으로 서명되고 23시간 메모에서 재생되므로, 나중에 폴링하면 남은 시간이 1시간밖에 되지 않는 URL을 받을 수 있습니다. 재호스팅을 수행할 수 없는 리프는 대신 BFL 자체의 수명이 짧은 전송 URL을 유지합니다(비디오는 약 2시간, 이미지는 약 10분). 어느 쪽이든 링크는 만료되므로 URL을 저장하지 말고 결과물을 다운로드하세요.

  형식: `uri`
</ResponseField>

<ResponseField name="result.seed" type="integer">
  생성에 사용된 시드로, 제공되었든 공급자가 선택했든 관계없습니다. BFL이 2^31을 초과하는 시드(예: 2784347701)를 반환하기 때문에 `int64`로 선언되었습니다. 서식이 지정되지 않은 `integer`는 많은 SDK 생성기에서 32비트 필드로 생성됩니다.

  형식: `int64`
</ResponseField>

<ResponseField name="result.start_time" type="number">
  공급자가 보고한 생성 시작 시간으로, Unix 에포크 이후 초 단위입니다. `float`이 아니라 `double`입니다. 현재 시점의 에포크 값 근처에서 float32 간격은 약 128초이므로, 생성 전체 구간이 하나의 디코딩된 값으로 뭉개집니다.

  형식: `double`
</ResponseField>

<ResponseField name="status" type="string" required>
  작업 상태: Pending, Reasoning, Generating, Ready, Request Moderated, Content Moderated, Error 또는 Task not found.
</ResponseField>

## 예시

### 입력

```json
{
  "input_video": "https://your-host.example/clip.mp4",
  "upscale_factor": 2,
  "creativity": 1
}
```

### 출력

```json
{
  "id": "0a1b2c3d-...",
  "status": "Ready",
  "result": {
    "sample": "https://.../upscaled.mp4"
  }
}
```

`result.sample`은 일반적으로 Comfy에서 호스팅하는 서명된 URL이며, 생성 시점부터 최대 24시간 동안 유효합니다. 재실행(replay)의 경우 더 오래된 URL이 반환될 수 있고, 다시 호스팅할 수 없는 자산은 수명이 더 짧은 공급자 URL을 그대로 유지합니다. 링크를 저장하기보다 MP4를 즉시 다운로드하세요.
