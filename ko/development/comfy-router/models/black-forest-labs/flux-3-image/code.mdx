동일한 본문을 `POST https://api.comfy.org/v2/models/bfl/flux-3-image/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`로 응답하며, 결과는 준비가 되면 이 프로세스 또는 다른 프로세스에서 수집합니다. [대기 중 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 설명합니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체적인 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bfl/flux-3-image",
            {
                "aspect_ratio": "16:9",
                "prompt": "A mountain landscape at sunset",
                "resolution": "1k",
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자 자체의 페이로드이며, models.run()이 반환하는 것과 같은 값입니다.
        # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체적인 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("bfl/flux-3-image", {
  aspect_ratio: "16:9",
  prompt: "A mountain landscape at sunset",
  resolution: "1k",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 같은 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/bfl/flux-3-image/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"aspect_ratio\": \"16:9\", \"prompt\": \"A mountain landscape at sunset\", \"resolution\": \"1k\"}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 대기합니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/bfl/flux-3-image/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집. 모델의 네이티브 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202.
curl https://api.comfy.org/v2/models/bfl/flux-3-image/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="aspect_ratio" type="string" default="&quot;auto&quot;">
  출력 비율: auto, 21:9, 2:1, 16:9, 3:2, 7:5, 4:3, 5:4, 1:1, 4:5, 3:4, 5:7, 2:3, 9:16, 1:2 또는 9:21. auto는 참조 이미지가 있으면 첫 번째 참조 이미지를 따릅니다.
</ParamField>

<ParamField body="grounding" type="boolean" default="true">
  모델이 생성하기 전에 웹 검색과 이미지 검색으로 프롬프트를 조사하도록 합니다. false로 설정하면 둘 다 끕니다.
</ParamField>

<ParamField body="images" type="string | string[]">
  프롬프트가 편집하거나 참조하는 1~10개의 참조 이미지로, 각각 http(s) URL 또는 base64 문자열입니다. 단일 문자열은 항목이 하나인 목록으로 처리됩니다. 각 이미지는 최소 256x256 픽셀이고 최대 16메가픽셀이어야 하며, base64 페이로드는 최대 20 MB입니다. 입력은 최대 2k까지 가장 가까운 해상도 bin으로 크기가 조정됩니다.
</ParamField>

<ParamField body="prompt" type="string" required>
  생성할 이미지 또는 참조 이미지에 적용할 편집에 대한 텍스트 설명입니다.
</ParamField>

<ParamField body="resolution" type="string" default="&quot;1k&quot;">
  출력 해상도 등급: 768sq, 1k, 1.5k, 2k 또는 4k.
</ParamField>

<ParamField body="safety_tolerance" type="integer" default="2">
  입력 및 출력 검열에 대한 허용치 수준이며, 0이 가장 엄격합니다.

  범위: `0` ~ `4`
</ParamField>

<ParamField body="version" type="string" default="&quot;latest&quot;">
  엔드포인트 버전. latest는 현재 릴리스를 제공하며, 날짜가 지정된 고정 가능 릴리스 태그는 게시되는 대로 추가됩니다.
</ParamField>

Router가 `GET /v2/models/bfl/flux-3-image/openapi.json`에서 제공하는 스키마에서 생성되었으며, 이는 요청이 공급자에 도달하기 전에 Router가 호출을 검증하는 기준이 되는 것과 동일한 문서입니다.

### 출력

<ResponseField name="cost" type="number">
  공급자가 보고한 크레딧 단위 비용으로, 작업이 Ready가 되면 채워집니다.

  형식: `float`
</ResponseField>

<ResponseField name="id" type="string" required>
  BFL 작업 식별자입니다.
</ResponseField>

<ResponseField name="progress" type="number">
  BFL이 보고하는 선택적 생성 진행률입니다.

  범위: `0` ~ `1`

  형식: `float`
</ResponseField>

<ResponseField name="result" type="object" required>
  완료된 생성 결과입니다. 여기서는 null을 허용하지 않습니다. 이 컴포넌트의 `required` 항목은 `200`이 결과를 담는다는 약속이며, `result`가 null을 허용하면 이는 키 존재 여부 검사로 축소됩니다.
</ResponseField>

<ResponseField name="result.cost" type="number">
  공급자가 보고한 생성 비용입니다. 이는 Comfy 청구가 아니라 BFL의 수치입니다.

  형식: `double`
</ResponseField>

<ResponseField name="result.duration" type="number">
  공급자가 보고한 생성 소요 시간(초)입니다.

  형식: `double`
</ResponseField>

<ResponseField name="result.end_time" type="number">
  공급자가 보고한 생성 완료 시간으로, Unix epoch 이후 경과한 초 단위입니다. `start_time`과 같은 이유로 `double`입니다.

  형식: `double`
</ResponseField>

<ResponseField name="result.prompt" type="string">
  프롬프트 업샘플링을 거친 후 생성이 실제로 실행한 프롬프트입니다.
</ResponseField>

<ResponseField name="result.sample" type="string (uri)">
  생성된 자산에 대한 서명된 URL입니다. Router는 자산을 Comfy 스토리지에 다시 호스팅하고 이 필드를 다시 작성하므로, 일반적으로 최대 24시간 동안 유효한 Comfy 호스팅 URL입니다. 발급 시 24시간 동안 서명되고 23시간 메모에서 재생되므로, 나중에 폴링하면 남은 시간이 1시간도 되지 않는 URL을 돌려받을 수 있습니다. 재호스팅을 수행할 수 없는 리프는 대신 BFL 자체의 수명이 짧은 전달 URL을 유지합니다. 비디오는 약 2시간, 이미지는 약 10분입니다. 어느 쪽이든 링크는 만료되므로 URL을 저장하지 말고 자산을 다운로드하세요.

  형식: `uri`
</ResponseField>

<ResponseField name="result.seed" type="integer">
  제공되었든 공급자가 선택했든 생성에 사용된 시드입니다. BFL이 2^31을 초과하는 시드(예: 2784347701)를 반환하기 때문에 `int64`로 선언되었습니다. 서식이 지정되지 않은 `integer`는 많은 SDK 생성기에서 이를 32비트 필드로 생성합니다.

  형식: `int64`
</ResponseField>

<ResponseField name="result.start_time" type="number">
  공급자가 보고한 생성 시작 시간으로, Unix epoch 이후 경과한 초 단위입니다. `float`이 아니라 `double`입니다. 현재 epoch 값 근처에서 float32의 간격은 약 128초이므로, 생성 전체의 범위가 단일 디코딩 값으로 붕괴됩니다.

  형식: `double`
</ResponseField>

<ResponseField name="status" type="string" required>
  작업 상태: Pending, Reasoning, Generating, Ready, Request Moderated, Content Moderated, Error 또는 Task not found.
</ResponseField>
