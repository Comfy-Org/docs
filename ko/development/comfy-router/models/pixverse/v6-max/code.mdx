동일한 본문을 `POST https://api.comfy.org/v2/models/pixverse/v6-max/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`로 응답하며, 결과는 준비되었을 때 이 프로세스에서든 다른 프로세스에서든 수집할 수 있습니다. [대기 중 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 방법을 단계별로 설명합니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 발급하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "pixverse/v6-max",
            {
                "aspect_ratio": "16:9",
                "duration": 5,
                "prompt": "a single red maple leaf falling onto still water",
                "quality": "360p",
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 서버가 지정한 Retry-After만큼 기다리며 요청이 완료될 때까지 폴링합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자의 원본 페이로드이며, models.run()이 반환하는 것과 같은 값입니다.
        # 실패하거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 발급하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("pixverse/v6-max", {
  aspect_ratio: "16:9",
  duration: 5,
  prompt: "a single red maple leaf falling onto still water",
  quality: "360p",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 서버가 지정한 Retry-After만큼 기다리며 요청이 완료될 때까지 폴링합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 같은 결과입니다. 실패하거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출합니다. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/pixverse/v6-max/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"aspect_ratio\": \"16:9\", \"duration\": 5, \"prompt\": \"a single red maple leaf falling onto still water\", \"quality\": \"360p\"}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 기다립니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/pixverse/v6-max/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집합니다. 모델의 원본 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202를 반환합니다.
curl https://api.comfy.org/v2/models/pixverse/v6-max/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```
