import { comfy } from "@comfyorg/sdk";

const handle = await comfy.models.submit("kling/kling-4.0", {

    },
    {
      type: "first_frame",

    resolution: "720p",
  },

### 입력

<ParamField body="contents" type="object[]">
  프롬프트와 입력 미디어입니다. "prompt", "first_frame", "middle_frame", "last_frame" 항목만 담으면 이미지 기반 비디오 생성을 선택하고(프롬프트 1개와 최대 10개 프레임), "refer_image", "feature_video", "base_video", "element", "voice" 중 하나라도 담으면 omni 비디오를 선택합니다(최대 15개 입력, 이미지 최대 10개, 비디오 최대 5개, 요소 최대 7개, 음성 최대 3개). "feature_video", "base_video" 또는 비디오 캐릭터 요소가 포함된 요청은 비디오 입력 요율로 청구됩니다.
</ParamField>

<ParamField body="contents[].element_id" type="string">
  요소 ID로, type이 "element"일 때 사용합니다.
</ParamField>

<ParamField body="contents[].id" type="string">
  이 입력의 참조 ID로, 프롬프트에서 @id로 사용됩니다. 작업 내에서 고유해야 합니다. "element"와 "voice"에는 필수입니다.
</ParamField>

<ParamField body="contents[].text" type="string">
  텍스트 프롬프트로, type이 "prompt"일 때 사용합니다. 영어 26,000자 또는 비영어 11,000자까지 가능합니다. comfy-api는 1~26,000자를 강제하며, Kling 자체는 더 긴 비영어 텍스트를 거부합니다. 다른 입력은 @id로 참조합니다.
</ParamField>

<ParamField body="contents[].type" type="string" required>
  입력 유형입니다. 이미지 기반 비디오 생성은 "prompt", "first_frame", "middle_frame", "last_frame"만 허용하며 다른 유형은 거부합니다. Omni 비디오는 "refer_image", "feature_video"(참조 비디오), "base_video"(편집할 비디오, 최대 1개), "element", "voice"도 허용합니다.

  가능한 값: `prompt`, `first_frame`, `middle_frame`, `last_frame`, `refer_image`, `feature_video`, `base_video`, `element`, `voice`
</ParamField>

<ParamField body="contents[].url" type="string">
  이미지 또는 비디오 URL로, type이 프레임, "refer_image", "feature_video", "base_video"일 때 사용합니다. 이미지는 Base64일 수도 있습니다. 이미지는 .jpg, .jpeg 또는 .png 형식으로 최대 30MB이며, 각 변이 300px 이상이고 종횡비는 2:5에서 5:2 사이입니다. 비디오는 .mp4 또는 .mov 형식으로 최대 300MB이고 길이는 3~30초입니다.
</ParamField>

<ParamField body="contents[].voice_id" type="string">
  음성 ID로, type이 "voice"일 때 사용합니다. Kling 프리셋 음성 또는 사용자 지정 음성입니다.
</ParamField>

<ParamField body="options" type="object">
  워터마크 옵션과 같은 일반 설정입니다. `options.callback_url`과 `options.external_task_id`는 Kling 4.0에서 지원되지 않으며, Comfy Router는 `options` 안에 이들 중 하나라도 설정한 요청을 거부합니다. 최상위 `callback_url` 또는 `external_task_id`는 이 스키마에 속하지 않으며 Kling에 요청이 도달하기 전에 제거됩니다.
</ParamField>

<ParamField body="options.watermark_info" type="object">

</ParamField>

<ParamField body="options.watermark_info.enabled" type="boolean">
  true는 워터마크가 있는 결과를 생성하고, false는 생성하지 않습니다. 기본값은 false입니다.
</ParamField>

<ParamField body="prompt" type="string">

</ParamField>

<ParamField body="settings" type="object" required>
  해상도, 종횡비, 재생 시간과 같은 출력 설정입니다.
</ParamField>

<ParamField body="settings.aspect_ratio" type="string">
  생성된 프레임의 종횡비(너비:높이)입니다. 텍스트 기반 비디오 생성에서는 "21:9", "16:9", "9:16", "1:1" 중 하나(기본값 "16:9"), omni 비디오에서는 이들 또는 "adaptive"(기본값 "adaptive")입니다. 이미지 기반 비디오 생성은 이미지를 따릅니다. 명시적 null은 /proxy Kling 4.0 검사와 Kling이 그렇게 하듯이 없는 것으로 취급됩니다.

  가능한 값: `21:9`, `16:9`, `9:16`, `1:1`, `adaptive`
</ParamField>

<ParamField body="settings.duration" type="integer">
  비디오 길이(초)로 3에서 30까지입니다. `contents`에 "base_video"가 포함된 경우가 아니면 필수이며, 이 경우 편집은 이를 생략하여 기본 비디오의 길이를 유지할 수 있습니다. 이러한 호출은 보류되고 요청된 해상도에서 30초 최대로 추정되며, 이는 가격이 아니라 상한이고, 완료된 작업에 대해 Kling이 보고하는 가격으로 청구됩니다.

  범위: `3`부터 `30`까지
</ParamField>

<ParamField body="settings.resolution" type="string" required>
  생성된 비디오의 해상도입니다. "720p" 또는 "1080p" 중 하나입니다. 필수입니다.

  가능한 값: `720p`, `1080p`
</ParamField>
