### 입력

<ParamField body="contents" type="object[]">
  프롬프트와 입력 미디어입니다. 항목 유형에 따라 Kling 작업이 결정됩니다. "prompt", "first_frame", "middle_frame", "last_frame" 항목만 담고 있으면 이미지 기반 비디오 생성을 선택하고(프롬프트와 최대 10개의 프레임), "refer_image", "feature_video", "base_video", "element", "voice" 항목을 하나라도 담고 있으면 omni 비디오를 선택합니다. `contents`가 없거나 비어 있으면 텍스트 기반 비디오 생성이 유지됩니다. Omni 비디오는 프롬프트 항목에 더해 최대 15개의 입력(총 16개 항목)을 받으며, 이미지(프레임과 "refer_image")는 최대 10개, 비디오("feature_video"와 "base_video", "base_video"는 최대 1개)는 최대 5개, element는 최대 7개, voice는 최대 3개입니다. 이 제한 중 하나라도 초과한 요청은 `contents`를 지목하는 422로 거부됩니다. 피사체를 사용하려면 `{"type": "element", "element_id": "<Kling element ID>", "id": "hero"}` 항목을 추가하고, 음성을 사용하려면 `{"type": "voice", "voice_id": "<Kling voice ID>", "id": "narrator"}` 항목을 추가합니다. 둘 다 `id`가 필요하며, 프롬프트 항목에서는 이들을 @hero, @narrator로 참조합니다. Element ID와 커스텀 voice ID는 이를 생성한 Kling 계정에 속합니다. "feature_video", "base_video" 또는 비디오 캐릭터 element가 포함된 요청은 비디오 입력 요율로 청구됩니다.
</ParamField>

<ParamField body="contents[].element_id" type="string">
  type이 "element"일 때의 Kling element ID입니다. Element는 Kling에 이미 존재하는 피사체(캐릭터 또는 객체)이며, 이 항목은 그 이름을 지정할 뿐 업로드하지는 않습니다. Kling은 element ID를 이를 생성한 Kling 계정 범위로 한정하므로, 다른 Kling 계정에서 만든 ID는 해석되지 않습니다. Omni 비디오 요청당 element는 최대 7개입니다. 비디오 캐릭터 element는 비디오 입력 요율로 청구되지만, comfy-api는 `element_id`만으로는 이를 구분할 수 없으므로 추정치가 더 낮은 요율로 계산할 수 있습니다.
</ParamField>

<ParamField body="contents[].id" type="string">
  호출자가 지정하는 이 입력의 참조 ID로, 프롬프트에서 @id로 사용됩니다. 작업 내에서 고유해야 합니다. "element"와 "voice"에서는 필수입니다.
</ParamField>

<ParamField body="contents[].text" type="string">
  type이 "prompt"일 때의 텍스트 프롬프트입니다. 영어 26,000자 또는 비영어 11,000자까지 가능하며, comfy-api는 1~26,000자를 강제하고 Kling 자체는 더 긴 비영어 텍스트를 거부합니다. 다른 항목을 참조하려면 @ 뒤에 해당 항목의 `id`를 씁니다. 예를 들어 `id`가 "hero"인 element 항목과 `id`가 "narrator"인 voice 항목이 있으면 "@hero가 방으로 걸어 들어오고 @narrator가 인사를 건넵니다"처럼 작성합니다.
</ParamField>

<ParamField body="contents[].type" type="string" required>
  입력 유형입니다. 이미지 기반 비디오 생성은 "prompt", "first_frame", "middle_frame", "last_frame"만 허용하며 다른 유형은 거부합니다. Omni 비디오는 "refer_image", "feature_video"(참조 비디오), "base_video"(편집할 비디오, 최대 1개), "element"(피사체, `element_id`로 지정) 및 "voice"(음성, `voice_id`로 지정)도 허용합니다. </ParamField>

</ParamField>

<ParamField body="contents[].voice_id" type="string">
