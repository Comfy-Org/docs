Kelly가 제공하고 Comfy Router가 서빙하는 `kelly/kelly-kling-4.0`의 API 레퍼런스입니다.

**입력:** 텍스트, 이미지, 비디오 · **출력:** 비디오

## 요청 설정

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys?onboarding=router)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python의 경우 `pip install comfy-sdk`를 실행하세요. TypeScript의 경우 `npm install @comfyorg/sdk`를 실행하세요. cURL은 원시 HTTP를 사용합니다.

**모델 ID:** `kelly/kelly-kling-4.0`

**엔드포인트:** `POST https://api.comfy.org/v2/models/kelly/kelly-kling-4.0`

<Note>
Router는 이 모델에 대해 직접 작성된 입력 스키마를 게시하지 않았으므로, 스니펫을 생성할 요청 예시가 없습니다. Router는 본문을 Kelly로 변경 없이 전달합니다: Kelly 자체 API 문서를 바탕으로 본문을 구성한 뒤 [Router 퀵스타트](/ko/development/comfy-router/quickstart)를 사용해 전송하세요.
</Note>

### 입력

<Note>
Router는 이 모델에 대해 직접 작성된 입력 스키마를 아직 게시하지 않았습니다: `GET /v2/models/kelly/kelly-kling-4.0/openapi.json`은 `x-comfy-input-schema-authored: false`가 설정된 열린 객체를 반환합니다. Router는 본문을 Kelly로 변경 없이 전달하므로 요청 필드에 대해서는 Kelly 자체 API 문서가 기준이며, Router는 모델별 입력 검증을 수행하지 않습니다. 공급자 검증은 여전히 적용됩니다.
</Note>
