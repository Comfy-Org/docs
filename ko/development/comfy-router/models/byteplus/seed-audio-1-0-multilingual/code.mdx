같은 요청 본문을 `POST https://api.comfy.org/v2/models/byteplus/seed-audio-1.0-multilingual/requests`로 전송합니다. Router는 실행이 접수되면 즉시 `201`과 `request_id`를 반환하며, 결과는 준비되는 대로 이 프로세스 또는 다른 프로세스에서 수집할 수 있습니다. 상태, 취소, 수집 과정은 [대기열 전송](/ko/development/comfy-router/queue)에서 자세히 설명합니다.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "byteplus/seed-audio-1.0-multilingual",
            {
                "audio_config": {
                    "format": "wav",
                    "sample_rate": 24000,
                },
                "text_prompt": "Hello from Comfy Router.",
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 서버가 지정한 Retry-After만큼 기다리며 요청이 완료될 때까지 폴링합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자의 자체 페이로드이며, models.run()이 반환하는 것과 동일한 값입니다.
        # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("byteplus/seed-audio-1.0-multilingual", {
  audio_config: {
    format: "wav",
    sample_rate: 24000,
  },
  text_prompt: "Hello from Comfy Router.",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 서버가 지정한 Retry-After만큼 기다리며 요청이 완료될 때까지 폴링합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

# 1. 제출합니다. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.

# 3. 수집합니다. 모델의 네이티브 출력과 함께 200, 아직 실행 중일 때는 상태 본문과 함께 202를 반환합니다.

## 스키마

### 입력

<ParamField body="audio_config" type="object">
  출력 오디오 구성입니다.
</ParamField>

<ParamField body="audio_config.enable_subtitle" type="boolean">
  자막 서비스를 활성화할지 여부입니다. 활성화하면 응답에 발화 단위 및 단어 단위 타임스탬프가 포함됩니다 (기본값: false).
</ParamField>

<ParamField body="audio_config.format" type="string">
  출력 오디오 형식: wav(기본값), mp3, pcm 또는 ogg_opus.

  가능한 값: `wav`, `mp3`, `pcm`, `ogg_opus`
</ParamField>

<ParamField body="audio_config.loudness_rate" type="integer">
  -50 ~ 100; 100은 2.0배 볼륨, -50은 0.5배 볼륨을 의미합니다 (기본값: 0).

  범위: `-50` ~ `100`
</ParamField>

<ParamField body="audio_config.pitch_rate" type="integer">
  -12 ~ 12 (기본값: 0).

  범위: `-12` ~ `12`
</ParamField>

<ParamField body="audio_config.sample_rate" type="integer">
  출력 샘플 레이트: 8000, 16000, 24000(기본값), 32000, 44100 또는 48000.

  가능한 값: `8000`, `16000`, `24000`, `32000`, `44100`, `48000`
</ParamField>

<ParamField body="audio_config.speech_rate" type="integer">
  -50 ~ 100; 100은 2.0배 속도, -50은 0.5배 속도를 의미합니다 (기본값: 0).

  범위: `-50` ~ `100`
</ParamField>

<ParamField body="model" type="string">
  모델 식별자입니다. 지원되는 모델: seed-audio-1.0 및 seed-audio-1.0-multilingual. POST /proxy/byteplus/api/v3/tts/create에 대한 직접 v1 호출은 반드시 이 값을 제공해야 합니다. 프록시는 다른 값이나 누락된 값을 400으로 거부합니다. 이 스키마의 `required` 목록에는 없는데, Comfy Router가 /v2/models/byteplus/\{model}의 `{model}` 경로 세그먼트에서 이 값을 채우므로 Router 호출자는 이를 생략하기 때문입니다.
</ParamField>

<ParamField body="references" type="object[]">
  참조 리소스입니다. 텍스트 전용 생성에서는 생략합니다. 최대 3개의 오디오 참조(각각 최대 30초, 디코딩 후 10 MB; wav, mp3, pcm 또는 ogg_opus) 또는 정확히 1개의 이미지 참조(디코딩 후 최대 10 MB; jpeg, png 또는 webp)를 사용할 수 있습니다. 이미지 참조는 오디오 참조와 혼합할 수 없습니다. 이 상한은 BytePlus의 것이며 DECODED 바이트 기준입니다. base64는 에셋을 약 4/3로 부풀리며, Comfy Router 호출은 전체 JSON 문서에 대해 100 MiB로 제한되므로, /v2/models/byteplus/\{model}로 전송되는 인라인 `audio_data`/`image_data` 참조는 전송 한도가 거부하기 전까지 디코딩 기준 약 75 MB를 담을 수 있습니다. 따라서 단일 인라인 참조에 대해서는 BytePlus 자체의 참조당 10 MB 상한이 먼저 적용되며, 이제 그 상한에 해당하는 오디오 참조 3개가 하나의 본문에 들어갑니다; 큰 에셋을 요청에서 완전히 배제하려면 `audio_url`/`image_url`을 사용하세요.
</ParamField>

<ParamField body="references[].audio_data" type="string">
  Base64로 인코딩된 참조 오디오입니다.
</ParamField>

<ParamField body="references[].audio_url" type="string">
  원격 참조 오디오 파일의 URL입니다.
</ParamField>

<ParamField body="references[].image_data" type="string">
  Base64로 인코딩된 참조 이미지입니다.
</ParamField>

<ParamField body="references[].image_url" type="string">
  원격 참조 이미지의 URL입니다.
</ParamField>

<ParamField body="references[].speaker" type="string">
  보이스 ID입니다. 지원되는 Doubao TTS 보이스 또는 음성 복제 보이스 ID일 수 있습니다.
</ParamField>

<ParamField body="text_prompt" type="string" required>
  합성할 프롬프트 또는 텍스트입니다 (1 ~ 3,000자; 빈 문자열은 거부됩니다). 오디오 참조를 제공한 경우 @Audio1, @Audio2, @Audio3을 사용해 순서대로 참조하세요.
</ParamField>

<ParamField body="watermark" type="object">
  워터마크 구성 객체입니다. 빈 객체도 허용됩니다.
</ParamField>

<ParamField body="watermark.aigc_metadata" type="object">
  암시적 워터마크입니다. 합성된 오디오 헤더에 메타데이터를 추가합니다.
</ParamField>

<ParamField body="watermark.aigc_metadata.content_producer" type="string">
  합성 서비스 공급자의 이름 또는 코드입니다.
</ParamField>

<ParamField body="watermark.aigc_metadata.content_propagator" type="string">
  콘텐츠 배포 서비스 공급자의 이름 또는 코드입니다.
</ParamField>

<ParamField body="watermark.aigc_metadata.enable" type="boolean">
  암시적 워터마크를 활성화할지 여부입니다 (기본값: false).
</ParamField>

<ParamField body="watermark.aigc_metadata.produce_id" type="string">
  콘텐츠 제작 ID입니다.
</ParamField>

<ParamField body="watermark.aigc_metadata.propagate_id" type="string">
  콘텐츠 배포 ID입니다.
</ParamField>

<ParamField body="watermark.aigc_watermark" type="boolean">
  명시적 워터마크 전환입니다. 합성된 오디오 끝에 오디오 리듬 마커를 추가합니다 (기본값: false).
</ParamField>
