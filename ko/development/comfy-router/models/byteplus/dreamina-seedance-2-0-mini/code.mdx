<ResponseField name="content" type="object">

</ResponseField>

<ResponseField name="content.last_frame_url" type="string">

BytePlus는 요청 측에서 마지막 프레임을 PNG로 문서화하고, Router는 전달받은 바이트를 그대로 재호스팅하며 업스트림 Content-Type 또는 콘텐츠 스니핑으로 형식을 지정합니다. `image/jpeg`는 둘 다 실패했을 때의 최후 수단 폴백일 뿐입니다. Router는 마지막 프레임을 Comfy 스토리지로 재호스팅하고 이 필드를 다시 작성하므로, 일반적으로 최대 24시간 동안 유효한 Comfy 서명 URL입니다. 발급 시 24시간으로 서명되고 23시간 메모에서 재생되므로, 나중 폴링에서는 남은 시간이 한 시간도 안 되는 URL이 반환될 수 있습니다. 재호스팅을 수행할 수 없었을 때는 이 필드가 대신 BytePlus 자체의 URL을 유지하며, BytePlus는 작업 후 24시간이 지나면 이를 정리합니다. 어느 경우든 링크가 만료되므로 URL을 저장하지 말고 프레임을 다운로드하세요.
</ResponseField>

<ResponseField name="content.output_format" type="string">

</ResponseField>

<ResponseField name="content.upstream_expires_at" type="string (date-time)">

  형식: `date-time`
</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">

</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  출력 비디오에 대한 BytePlus 자체의 다운로드 URL로, 재호스팅된 `video_url` 옆에 바이트 단위로 그대로 반환됩니다. Comfy가 서버 측에서 옵트인한 워크스페이스가 폴링한 Seedance 2.x 작업에만 존재하며(요청 파라미터는 없습니다), 그 외의 경우에는 존재하지 않습니다. 워크스페이스로 확인되지 않는 자격 증명(예: 특정 워크스페이스에 범위가 지정되지 않은 레거시 API 키)도 마찬가지이며, 생성 후 24시간이 지나 BytePlus가 URL을 정리하면 존재하지 않습니다. presigned 객체 스토리지 URL이므로 베어러 자격 증명입니다. 이를 보유한 누구나 만료 전까지 비디오를 다운로드할 수 있으므로 비밀 정보처럼 다루세요. `upstream_expires_at`에 만료되며, Seedance 2.5에서는 BytePlus가 다운로드 횟수를 100회로 제한하는데 그중 한 번은 Router 자체의 재호스팅이 소비합니다.
