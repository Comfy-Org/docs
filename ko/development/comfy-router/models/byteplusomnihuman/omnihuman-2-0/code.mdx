동일한 본문을 `POST https://api.comfy.org/v2/models/byteplusomnihuman/omnihuman-2.0/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`로 응답하며, 결과는 준비되는 대로 이 프로세스 또는 다른 프로세스에서 수집합니다. [대기 중 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 방법을 차례로 안내합니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "byteplusomnihuman/omnihuman-2.0",
            {
                "audio_url": "https://example.com/speech.mp3",
                "enable_watermark": False,
                "image_urls": ["https://example.com/portrait.jpg"],
                "prompt": "The person speaks calmly to the camera.",
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자의 자체 페이로드이며, models.run()이 반환하는 것과 동일한 값입니다.
        # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("byteplusomnihuman/omnihuman-2.0", {
  audio_url: "https://example.com/speech.mp3",
  enable_watermark: false,
  image_urls: ["https://example.com/portrait.jpg"],
  prompt: "The person speaks calmly to the camera.",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

## 스키마

### 입력

<ParamField body="audio_url" type="string" required>
  음성 오디오의 공개 HTTP 또는 HTTPS URL입니다. WAV 또는 MP3, 15 MB 미만, 4~300초입니다. 출력 비디오의 길이는 이 오디오와 같습니다.
</ParamField>

<ParamField body="enable_watermark" type="boolean">
  BytePlus가 비디오에 워터마크를 추가하는지 여부입니다. 이 값을 생략하면 BytePlus는 기본값을 true로 설정합니다.
</ParamField>

<ParamField body="image_urls" type="string[]" required>
  인물 이미지의 공개 HTTP 또는 HTTPS URL이 정확히 하나 필요합니다. JPEG, PNG, WEBP, BMP, TIFF, GIF, HEIC 또는 HEIF, 30 MB 미만, 가로세로 비율(너비/높이) 0.4~2.5, 각 변 300~6000 px입니다.
</ParamField>

<ParamField body="prompt" type="string">
  장면, 움직임, 카메라를 제어하는 선택적 텍스트입니다. 중국어, 영어, 일본어, 한국어, 스페인어(멕시코) 또는 인도네시아어를 지원합니다.
</ParamField>

`GET /v2/models/byteplusomnihuman/omnihuman-2.0/openapi.json`에서 Router가 제공하는 스키마에서 생성되었으며, 요청이 공급자에게 도달하기 전에 호출을 검증하는 데 사용하는 동일한 문서입니다.
