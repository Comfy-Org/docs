Luma가 제공하는 `luma/photon-flash-1`의 API 레퍼런스이며, Comfy Router를 통해 서비스됩니다.

## 빠른 시작

[내 Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python 및 TypeScript 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`)를 사용하며, cURL 스니펫은 동일한 호출을 원시 HTTP로 수행합니다.

**모델 ID:** `luma/photon-flash-1`

**엔드포인트:** `POST https://api.comfy.org/v2/models/luma/photon-flash-1`

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment.
# The SDK automatically creates an idempotency key and reuses it for automatic retries.
with Comfy() as client:
    result = client.models.run(
        "luma/photon-flash-1",
        {
            "aspect_ratio": "1:1",
            "prompt": "a red circle on a plain white background",
        },
    )

print(result)
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Reads COMFY_API_KEY from the environment.
// The SDK automatically creates an idempotency key and reuses it for automatic retries.
const { data } = await comfy.models.run("luma/photon-flash-1", {
  aspect_ratio: "1:1",
  prompt: "a red circle on a plain white background",
});

console.log(data);
```

```bash cURL
curl https://api.comfy.org/v2/models/luma/photon-flash-1 \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"aspect_ratio\": \"1:1\", \"prompt\": \"a red circle on a plain white background\"}"
```

<ResponseField name="assets" type="object">
  이미지 생성의 에셋입니다. `image`가 결과이며, `video`와 `progress_video`는 이 상태 라우트를 공유하는 Dream Machine VIDEO 작업에 속하고, Luma는 이들을 여기에 명시적 null로 보냅니다.
</ResponseField>

<ResponseField name="assets.image" type="string (uri)">
  생성된 이미지의 URL입니다. `luma/photon-*` 생성이 채우는 리프입니다. 생성이 `completed`에 도달할 때까지 null입니다.

  형식: `uri`
</ResponseField>
