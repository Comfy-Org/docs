<ParamField body="aspect_ratio" type="string">
  출력 화면 비율입니다. `auto`는 프롬프트와 미디어 입력에서 하나를 고릅니다. 생략하면 Pika가 선택합니다: `rewrite`가 켜져 있으면 `auto`, 그렇지 않으면 첫 번째 미디어 입력의 비율, 그것도 없으면 16:9입니다.

  가능한 값: `auto`, `21:9`, `16:9`, `3:2`, `4:3`, `5:4`, `1:1`, `4:5`, `3:4`, `2:3`, `9:16`, `9:21`
</ParamField>

  가능한 값: `stereo`, `mono`
</ParamField>

<ParamField body="duration" type="integer" default="5">

<ParamField body="rewrite" type="boolean" default="true">

</ParamField>

<ParamField body="seed" type="integer" default="0">
