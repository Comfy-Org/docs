## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys?onboarding=router)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python과 TypeScript 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`)를 사용하며, cURL 스니펫은 동일한 호출을 raw HTTP로 전송합니다.

**모델 ID:** `pika/pika-2.5-image-to-video`

**엔드포인트:** `POST https://api.comfy.org/v2/models/pika/pika-2.5-image-to-video`

동일한 본문을 `POST https://api.comfy.org/v2/models/pika/pika-2.5-image-to-video/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`로 응답하며, 결과는 준비되면 이 프로세스 또는 다른 프로세스에서 수집합니다. [대기열 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 안내합니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "pika/pika-2.5-image-to-video",
            {
                "duration_s": 5,
                "image": "https://example.invalid/pika/source.png",
                "prompt": "The camera slowly pushes in as the leaves begin to sway",
                "resolution": "720p",
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자 자체의 payload이며, models.run()이 반환하는 것과 동일한 값입니다.
        # 실패했거나 취소된 요청은 여기서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("pika/pika-2.5-image-to-video", {
  duration_s: 5,
  image: "https://example.invalid/pika/source.png",
  prompt: "The camera slowly pushes in as the leaves begin to sway",
  resolution: "720p",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출합니다. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/pika/pika-2.5-image-to-video/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"duration_s\": 5, \"image\": \"https://example.invalid/pika/source.png\", \"prompt\": \"The camera slowly pushes in as the leaves begin to sway\", \"resolution\": \"720p\"}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 대기합니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/pika/pika-2.5-image-to-video/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집합니다. 모델의 네이티브 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202입니다.
curl https://api.comfy.org/v2/models/pika/pika-2.5-image-to-video/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="duration_s" type="integer" default="5">
  비디오 길이(초)입니다.

  가능한 값: `5`, `10`
</ParamField>

<ParamField body="image" type="string" required>
  애니메이트할 소스 이미지의 공개 https URL입니다. 이미지가 주체를 담고 있습니다. 일반 `http://`는 거부됩니다. Pika는 Comfy의 키로 전송된 요청에서 URL을 가져옵니다.
</ParamField>

<ParamField body="negative_prompt" type="string">
  비디오에서 피해야 할 내용을 설명하는 텍스트입니다.
</ParamField>

<ParamField body="prompt" type="string">
  모션을 안내하는 텍스트 프롬프트입니다.
</ParamField>

<ParamField body="resolution" type="string" default="&quot;1080p&quot;">
  출력 해상도입니다.

  가능한 값: `720p`, `1080p`
</ParamField>

<ParamField body="seed" type="integer">
  재현 가능한 생성을 위한 시드입니다. 무작위 시드를 사용하려면 생략하거나 null을 보내세요.
</ParamField>

Router가 `GET /v2/models/pika/pika-2.5-image-to-video/openapi.json`에서 제공하는 스키마에서 생성되었으며, 요청이 공급자에 도달하기 전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.

### 출력

<ResponseField name="error" type="object">
  `failed` 작업에 설정되는 Pika의 구조화된 실패 기록입니다. Router는 실패한 작업에 자체 오류 응답으로 답하므로, Router가 반환하는 본문에는 이 필드가 포함되지 않습니다. Pika의 작업 문서에 포함되어 있기 때문에 선언되어 있습니다.
</ResponseField>

<ResponseField name="error.code" type="string" required>
  가능한 값: `invalid_input`, `content_moderation`, `provider_error`, `provider_timeout`, `provider_unavailable`, `rate_limited`, `insufficient_balance`, `membership_required`, `cycle_limit_exceeded`, `admission_suspended`, `usage_limit_exceeded`, `timed_out`, `internal`
</ResponseField>

<ResponseField name="error.message" type="string" required>
