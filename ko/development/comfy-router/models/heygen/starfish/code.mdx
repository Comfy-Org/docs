HeyGen이 Comfy Router를 통해 제공하는 `heygen/starfish`에 대한 API 레퍼런스입니다.

## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys)에서 키를 생성한 뒤 `COMFY_API_KEY`로 내보내세요. Python 및 TypeScript 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`)를 사용하며, cURL 스니펫은 동일한 호출을 raw HTTP로 수행합니다.

**모델 ID:** `heygen/starfish`

**엔드포인트:** `POST https://api.comfy.org/v2/models/heygen/starfish`

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment.
# The SDK automatically creates an idempotency key and reuses it for automatic retries.
with Comfy() as client:
    result = client.models.run(
        "heygen/starfish",
        {
            "text": "This is a billing verification test for HeyGen speech generation.",
            "voice_id": "d2f4f24783d04e22ab49ee8fdc3715e0",
        },
    )

print(result)
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Reads COMFY_API_KEY from the environment.
// The SDK automatically creates an idempotency key and reuses it for automatic retries.
const { data } = await comfy.models.run("heygen/starfish", {
  text: "This is a billing verification test for HeyGen speech generation.",
  voice_id: "d2f4f24783d04e22ab49ee8fdc3715e0",
});

console.log(data);
```

```bash cURL
curl https://api.comfy.org/v2/models/heygen/starfish \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"text\": \"This is a billing verification test for HeyGen speech generation.\", \"voice_id\": \"d2f4f24783d04e22ab49ee8fdc3715e0\"}"
```
</CodeGroup>

## 스키마

### 입력

<ParamField body="input_type" type="string">
  입력 유형: 일반 텍스트의 경우 'text', SSML 마크업의 경우 'ssml'. 기본값은 'text'
</ParamField>

<ParamField body="language" type="string">
  기본 언어 코드(예: 'en'). 생략하면 텍스트에서 자동 감지됩니다
</ParamField>

<ParamField body="locale" type="string">
  BCP-47 언어 설정 태그(예: 'en-US'). 설정되면 언어 설정에서 언어를 유추합니다
</ParamField>

<ParamField body="speed" type="number">
  속도 배율(0.5-2.0)

  범위: `0.5` ~ `2`

  형식: `double`
</ParamField>

<ParamField body="text" type="string" required>
  합성할 텍스트(1-5000자)
</ParamField>

<ParamField body="voice_id" type="string" required>
  사용할 Voice ID. 해당 음성은 starfish 엔진을 지원해야 합니다
</ParamField>

이 문서는 Router가 `GET /v2/models/heygen/starfish/openapi.json`에서 제공하는 스키마에서 생성되었으며, 이는 요청이 공급자에게 도달하기 전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.
