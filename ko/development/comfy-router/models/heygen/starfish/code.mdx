HeyGen이 Comfy Router를 통해 제공하는 `heygen/starfish`에 대한 API 레퍼런스입니다.

## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys?onboarding=router)에서 키를 생성한 뒤 `COMFY_API_KEY`로 내보내세요. Python, TypeScript, Swift 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`, 그리고 [`ComfySwiftSDK`](https://github.com/Comfy-Org/comfy-swift-sdk) Swift 패키지)를 사용하며, cURL 스니펫은 동일한 호출을 raw HTTP로 수행합니다.

**모델 ID:** `heygen/starfish`

**엔드포인트:** `POST https://api.comfy.org/v2/models/heygen/starfish`

동일한 본문을 `POST https://api.comfy.org/v2/models/heygen/starfish/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `201`과 `request_id`로 응답하며, 결과는 준비가 완료되면 이 프로세스에서든 다른 프로세스에서든 수집할 수 있습니다. [큐 전송](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 자세히 다룹니다.

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
with Comfy() as client:
    handle = client.models.submit(
        "heygen/starfish",
        {
            "text": "Hello from Comfy. This voice is generated with the HeyGen Starfish engine.",
            "voice_id": "d2f4f24783d04e22ab49ee8fdc3715e0",
        },
    )
    print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

    # 요청이 완료될 때까지 폴링하며, 서버가 알려주는 Retry-After만큼 기다립니다.
    for update in handle.iter_events():
        print(update.status, update.queue_position)

    # 공급자 자체의 페이로드이며, models.run()이 반환하는 것과 동일한 값입니다.
    # 실패하거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
    result = handle.get()

print(result)
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("heygen/starfish", {
  text: "Hello from Comfy. This voice is generated with the HeyGen Starfish engine.",
  voice_id: "d2f4f24783d04e22ab49ee8fdc3715e0",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 알려주는 Retry-After만큼 기다립니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패하거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```swift Swift
import Foundation
import ComfySwiftSDK

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
let client = ComfyCloudClient(apiKey: ProcessInfo.processInfo.environment["COMFY_API_KEY"]!)
let handle = try await client.models.submit(
    "heygen/starfish",
    input: [
        "text": "Hello from Comfy. This voice is generated with the HeyGen Starfish engine.",
        "voice_id": "d2f4f24783d04e22ab49ee8fdc3715e0",
    ]
)
print("requestId:", handle.requestId)  // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 알려주는 Retry-After만큼 기다립니다.
for try await update in handle.events() {
    print(update.state.rawValue, update.queuePosition.map(String.init) ?? "unknown")
}

// 공급자 자체의 페이로드이며, models.run()이 반환하는 것과 동일한 값입니다.
// 실패하거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 던집니다.
let result = try await handle.result()

print(result.output)
```

```bash cURL
# 1. 제출. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/heygen/starfish/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"text\": \"Hello from Comfy. This voice is generated with the HeyGen Starfish engine.\", \"voice_id\": \"d2f4f24783d04e22ab49ee8fdc3715e0\"}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 알려주는 Retry-After 초만큼 기다립니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/heygen/starfish/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집. 모델의 네이티브 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202.
curl https://api.comfy.org/v2/models/heygen/starfish/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="input_type" type="string">
  입력 타입: 일반 텍스트의 경우 'text', SSML 마크업의 경우 'ssml'. 기본값은 'text'
</ParamField>

<ParamField body="language" type="string">
  기본 언어 코드(예: 'en'). 생략하면 텍스트에서 자동 감지됩니다
</ParamField>

<ParamField body="locale" type="string">
  BCP-47 언어 설정 태그(예: 'en-US'). 설정되면 언어 설정에서 언어를 유추합니다
</ParamField>

<ParamField body="speed" type="number">
  속도 배율(0.5-2.0)

  범위: `0.5` ~ `2`

  형식: `double`
</ParamField>

<ParamField body="text" type="string" required>
  합성할 텍스트(1-5000자)
</ParamField>

<ParamField body="voice_id" type="string" required>
  사용할 Voice ID. 해당 음성은 starfish 엔진을 지원해야 합니다
</ParamField>

이 문서는 Router가 `GET /v2/models/heygen/starfish/openapi.json`에서 제공하는 스키마에서 생성되었으며, 이는 요청이 공급자에게 도달하기 전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.
