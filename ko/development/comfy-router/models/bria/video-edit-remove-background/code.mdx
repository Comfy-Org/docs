`bria/video-edit-remove-background`에 대한 API 레퍼런스로, Bria의 모델을 Comfy Router가 제공합니다.

## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python 및 TypeScript 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`)를 사용하며, cURL 스니펫은 동일한 호출을 원시 HTTP로 수행합니다.

**모델 ID:** `bria/video-edit-remove-background`

**엔드포인트:** `POST https://api.comfy.org/v2/models/bria/video-edit-remove-background`

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment.
# The SDK automatically creates an idempotency key and reuses it for automatic retries.
with Comfy() as client:
    result = client.models.run(
        "bria/video-edit-remove-background",
        {
            "background_color": "Transparent",
            "output_container_and_codec": "webm_vp9",
            "video": "https://example.com/input.mp4",
        },
    )

print(result)
```

## 스키마

### 입력

<ParamField body="background_color" type="string">
  출력 비디오의 배경색입니다. Transparent인 경우 출력 코덱이 알파를 지원해야 합니다.

  가능한 값: `Transparent`, `Black`, `White`, `Gray`, `Red`, `Green`, `Blue`, `Yellow`, `Cyan`, `Magenta`, `Orange`
</ParamField>

<ParamField body="output_container_and_codec" type="string">
  출력 컨테이너 및 코덱 프리셋입니다.

  가능한 값: `mp4_h264`, `mp4_h265`, `webm_vp9`, `mov_h265`, `mov_proresks`, `mkv_h264`, `mkv_h265`, `mkv_vp9`, `gif`
</ParamField>

<ParamField body="preserve_audio" type="boolean">
  입력 비디오의 오디오를 보존할지 여부입니다.
</ParamField>

<ParamField body="video" type="string" required>
  입력 비디오의 공개적으로 접근 가능한 URL입니다. 입력 해상도는 최대 16000x16000(16K)까지 지원합니다. 최대 재생 시간 60초입니다.
</ParamField>

Router가 `GET /v2/models/bria/video-edit-remove-background/openapi.json`에서 제공하는 스키마를 기반으로 생성되었으며, 이는 요청이 공급자에게 도달하기 전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.
