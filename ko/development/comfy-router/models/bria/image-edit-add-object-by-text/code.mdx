동일한 본문을 `POST https://api.comfy.org/v2/models/bria/image-edit-add-object-by-text/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`을 응답하며, 결과는 준비되면 이 프로세스에서든 다른 프로세스에서든 수집됩니다. [대기 중 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 자세히 설명합니다.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bria/image-edit-add-object-by-text",
            {
                "image": "https://img.freepik.com/free-psd/close-up-delicious-apple_23-2151868338.jpg",
                "instruction": "Place a red vase with flowers next to the pie",
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자 자체의 페이로드로, models.run()이 반환하는 것과 동일한 값입니다.
        # 실패하거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("bria/image-edit-add-object-by-text", {
  image: "https://img.freepik.com/free-psd/close-up-delicious-apple_23-2151868338.jpg",
  instruction: "Place a red vase with flowers next to the pie",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패하거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

# 3. 수집합니다. 모델의 네이티브 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202를 반환합니다.

<ParamField body="image" type="string" required>
  편집할 이미지입니다. 지원되는 입력 유형은 Base64로 인코딩된 문자열 또는 공개적으로 접근 가능한 이미지 파일을 가리키는 URL입니다. 허용되는 형식은 JPEG, JPG, PNG, WEBP입니다.
</ParamField>

<ParamField body="instruction" type="string" required>
  추가할 객체와 그 위치를 설명하는 텍스트 지시문입니다(예: "테이블 위에 꽃이 꽂힌 빨간색 꽃병을 놓아줘").
</ParamField>
