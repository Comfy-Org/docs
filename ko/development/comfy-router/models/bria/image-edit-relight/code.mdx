동일한 본문을 `POST https://api.comfy.org/v2/models/bria/image-edit-relight/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`로 응답하며, 결과는 준비되면 이 프로세스 또는 다른 프로세스에서 수집합니다. [대기 중 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 방법을 안내합니다.

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# 환경에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
with Comfy() as client:
    handle = client.models.submit(
        "bria/image-edit-relight",
        {
            "image": "https://img.freepik.com/free-photo/portrait-woman_395237-33.jpg?w=740&q=80",
            "light_direction": "side",
            "light_type": "midday",
        },
    )
    print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

    # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
    for update in handle.iter_events():
        print(update.status, update.queue_position)

    # 공급자 자체의 페이로드로, models.run()이 반환하는 것과 동일한 값입니다.
    # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
    result = handle.get()

print(result)
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("bria/image-edit-relight", {
  image: "https://img.freepik.com/free-photo/portrait-woman_395237-33.jpg?w=740&q=80",
  light_direction: "side",
  light_type: "midday",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```swift Swift
import Foundation
import ComfySwiftSDK

// Reads COMFY_API_KEY from the environment.
// Each submit() call mints its own Idempotency-Key and reuses it for automatic retries.
let client = ComfyCloudClient(apiKey: ProcessInfo.processInfo.environment["COMFY_API_KEY"]!)
let handle = try await client.models.submit(
    "bria/image-edit-relight",
    input: [
        "image": "https://img.freepik.com/free-photo/portrait-woman_395237-33.jpg?w=740&q=80",
        "light_direction": "side",
        "light_type": "midday",
    ]
)
print("requestId:", handle.requestId)  // with the model ID, all another process needs

// Poll until the request completes, waiting the Retry-After the server names.
for try await update in handle.events() {
    print(update.state.rawValue, update.queuePosition.map(String.init) ?? "unknown")
}

// The provider's own payload, the same value models.run() returns.
// A request that failed or was cancelled throws the typed Router error here.
let result = try await handle.result()

print(result.output)
```

```bash cURL
# 1. 제출. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/bria/image-edit-relight/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"image\": \"https://img.freepik.com/free-photo/portrait-woman_395237-33.jpg?w=740&q=80\", \"light_direction\": \"side\", \"light_type\": \"midday\"}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 대기합니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/bria/image-edit-relight/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집. 모델의 네이티브 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202를 반환합니다.
curl https://api.comfy.org/v2/models/bria/image-edit-relight/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="image" type="string" required>
  편집할 이미지입니다. 지원되는 입력 유형은 Base64로 인코딩된 문자열 또는 공개적으로 접근 가능한 이미지 파일을 가리키는 URL입니다. 허용 형식: JPEG, JPG, PNG, WEBP.
</ParamField>

<ParamField body="light_direction" type="string">
  라이트 방향으로, "front", "side", "bottom", "top-down" 중 하나입니다.
</ParamField>

<ParamField body="light_type" type="string" required>
  적용할 조명 분위기로, "midday", "blue hour light", "low-angle sunlight", "sunrise light", "spotlight on subject, keep background settings", "overcast light", "soft overcast daylight lighting", "cloud-filtered lighting", "fog-diffused lighting", "moonlight lighting", "starlight lighting nighttime", "soft bokeh lighting", "harsh studio lighting keep background setting" 중 하나입니다.
</ParamField>

Router가 `GET /v2/models/bria/image-edit-relight/openapi.json`에서 제공하는 스키마에서 생성되었으며, 이는 Router가 요청이 공급자에 도달하기 전에 호출을 검증하는 대상과 동일한 문서입니다.

### 출력

<ResponseField name="error" type="object">

</ResponseField>

<ResponseField name="error.code" type="integer">
  오류 코드.
</ResponseField>

<ResponseField name="error.details" type="string">

</ResponseField>

<ResponseField name="error.message" type="string">

</ResponseField>

<ResponseField name="request_id" type="string">

</ResponseField>

<ResponseField name="result" type="object">
  결과 객체 (status가 COMPLETED일 때만 존재합니다)
</ResponseField>

<ResponseField name="result.image_url" type="string">
  생성/편집된 이미지의 URL.
</ResponseField>

<ResponseField name="result.prompt" type="string">
  원본 프롬프트.
</ResponseField>

<ResponseField name="result.refined_prompt" type="string">
  프롬프트의 정제된 버전이며, Bria가 정제하지 않은 COMPLETED 생성에서는 null입니다. 이 키는 생략되지 않고 null을 담은 채 PRESENT이기 때문에 nullable입니다. bria/image-edit-gen-fill에서 실제로 관찰되었습니다.
</ResponseField>

<ResponseField name="result.seed" type="integer">
  생성에 사용된 시드.
</ResponseField>

<ResponseField name="result.structured_prompt" type="string">
  상세한 JSON 구조화 프롬프트.
</ResponseField>

<ResponseField name="result.video_url" type="string">
  생성된 비디오의 URL.
</ResponseField>

<ResponseField name="status" type="string">
  요청의 현재 상태.

  가능한 값: `IN_PROGRESS`, `COMPLETED`, `ERROR`, `UNKNOWN`
</ResponseField>
