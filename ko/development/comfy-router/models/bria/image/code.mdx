`bria/image`의 API 레퍼런스이며, Comfy Router가 Bria에서 제공합니다.

**입력:** 텍스트, 이미지 · **출력:** 이미지

## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys?onboarding=router)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python 및 TypeScript 스니펫은 Comfy SDK(`pip install comfy-sdk` 및 `npm install @comfyorg/sdk`)를 사용하며, cURL 스니펫은 동일한 호출을 원시 HTTP로 보냅니다.

**모델 ID:** `bria/image`

**엔드포인트:** `POST https://api.comfy.org/v2/models/bria/image`

동일한 본문을 `POST https://api.comfy.org/v2/models/bria/image/requests`로 보냅니다. Router는 실행이 접수되는 즉시 `201`과 `request_id`를 응답하며, 결과는 준비가 되면 이 프로세스 또는 다른 프로세스에서 수집합니다. [대기 중 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 절차를 단계별로 설명합니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bria/image",
            {
                "prompt": "A red vintage bicycle leaning against a brick wall in soft morning light",
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자의 자체 페이로드이며, models.run()이 반환하는 것과 같은 값입니다.
        # 실패했거나 취소된 요청은 여기서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("bria/image", {
  prompt: "A red vintage bicycle leaning against a brick wall in soft morning light",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 같은 결과입니다. 실패했거나 취소된 요청은 여기서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출. Router는 request_id, status_url, response_url, cancel_url과 함께 201을 응답합니다.
curl https://api.comfy.org/v2/models/bria/image/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"prompt\": \"A red vintage bicycle leaning against a brick wall in soft morning light\"}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 대기합니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/bria/image/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집. 모델의 네이티브 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202를 반환합니다.
curl https://api.comfy.org/v2/models/bria/image/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="aspect_ratio" type="string" default="&quot;1:1&quot;">
  출력 이미지의 가로세로 비율로, "1:1", "2:3", "3:2", "3:4", "4:3", "4:5", "5:4", "9:16", "16:9", "16:10", "10:16", "2:1", "1:2", "21:9", "9:21", "3:1", "1:3", "4:1", "1:4", "5:1" 또는 "1:5" 중 하나입니다. Bria는 "4MP"일 때, prompt와 structured_prompt를 모두 보내는 리파인먼트일 때, 그리고 prompt가 없는 이미지일 때 "16:10"부터의 비율을 거부합니다.
</ParamField>

<ParamField body="images" type="string[]">
  새 이미지에 영감을 주는 참조 이미지입니다. 공개적으로 사용 가능한 URL 또는 Base64로 인코딩됩니다. 허용 형식은 JPEG, JPG, PNG, WEBP입니다. 정확히 하나의 항목을 포함해야 합니다.
</ParamField>

<ParamField body="ip_signal" type="boolean" default="false">
  true이면 prompt에 잠재적인 IP 콘텐츠가 있는 경우 경고를 반환합니다.
</ParamField>

<ParamField body="model_version" type="string">
  사용할 모델의 버전입니다. "FIBO"만 허용되며, 생략하면 동일한 모델을 실행합니다.
</ParamField>

<ParamField body="output_type" type="string" default="&quot;png&quot;">
  출력 이미지 형식이며 "png" 또는 "jpeg"입니다.
</ParamField>

<ParamField body="prompt" type="string">
  텍스트 기반 지시입니다. 단독으로 사용하여 새 이미지를 생성하거나, images 또는 structured_prompt와 함께 사용하여 결과를 안내하거나 다듬습니다.
</ParamField>

<ParamField body="prompt_content_moderation" type="boolean" default="true">
  true이면 prompt 검열 실패 시 422를 반환합니다.
</ParamField>

<ParamField body="resolution" type="string" default="&quot;1MP&quot;">
  출력 이미지 해상도이며 "1MP" 또는 "4MP"입니다. "4MP"는 이미지 세부 정보를 개선하지만 지연 시간을 약 30초 증가시킵니다.
</ParamField>

<ParamField body="seed" type="integer">
  결정적 생성을 위한 시드입니다. 생략하면 임의의 시드가 사용됩니다.
</ParamField>

<ParamField body="structured_prompt" type="string">
  이전 생성 결과에서 가져온, JSON 형식의 structured prompt를 포함하는 문자열입니다. 동일한 시드와 함께 사용하여 해당 이미지를 다시 만들거나, 일부를 변경하여 이미지를 다듬습니다.
</ParamField>

<ParamField body="visual_input_content_moderation" type="boolean" default="true">
  true이면 이미지 검열 실패 시 422를 반환합니다.
</ParamField>

<ParamField body="visual_output_content_moderation" type="boolean" default="true">
  true이면 시각적 출력 검열 실패 시 422를 반환합니다.
</ParamField>

Router가 `GET /v2/models/bria/image/openapi.json`에서 제공하는 스키마에서 생성되었으며, 이는 요청이 공급자에 도달하기 전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.

### 출력

<ResponseField name="error" type="object">
  오류 객체입니다(status가 ERROR인 경우에만 존재합니다).
</ResponseField>

<ResponseField name="error.code" type="integer">
  오류 코드입니다.
</ResponseField>

<ResponseField name="error.details" type="string">
  추가 오류 세부 정보입니다.
</ResponseField>

<ResponseField name="error.message" type="string">
  오류 메시지입니다.
</ResponseField>

<ResponseField name="request_id" type="string">
  요청의 고유 식별자입니다.
</ResponseField>

<ResponseField name="result" type="object">
  결과 객체입니다(status가 COMPLETED인 경우에만 존재합니다).
</ResponseField>

<ResponseField name="result.image_url" type="string">
  생성되거나 편집된 이미지의 URL입니다.
</ResponseField>

<ResponseField name="result.prompt" type="string">
  원본 prompt입니다.
</ResponseField>

<ResponseField name="result.refined_prompt" type="string">
  prompt의 다듬어진 버전이며, Bria가 다듬지 않은 COMPLETED 생성에서는 null입니다. 키가 생략된 것이 아니라 null을 담은 채 PRESENT이기 때문에 nullable입니다. bria/image-edit-gen-fill에서 실제로 관찰되었습니다.
</ResponseField>

<ResponseField name="result.seed" type="integer">
  생성에 사용된 시드입니다.
</ResponseField>

<ResponseField name="result.structured_instruction" type="string">
  문자열로 직렬화된 JSON 문서인 구조화된 지시이며, `/v2/structured_instruction/generate`가 반환합니다. 해당 작업은 어느 URL도 채우지 않습니다.
</ResponseField>

<ResponseField name="result.structured_prompt" type="string">
  상세한 JSON structured prompt입니다.
</ResponseField>

<ResponseField name="result.video_url" type="string">
  생성된 비디오의 URL입니다.
</ResponseField>

<ResponseField name="status" type="string">
  요청의 현재 상태입니다.

  가능한 값: `IN_PROGRESS`, `COMPLETED`, `ERROR`, `UNKNOWN`
</ResponseField>
