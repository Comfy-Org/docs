## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys?onboarding=router)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python, TypeScript, Swift 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`, 그리고 [`ComfySwiftSDK`](https://github.com/Comfy-Org/comfy-swift-sdk) Swift 패키지)를 사용하며, cURL 스니펫은 동일한 호출을 원시 HTTP로 보낸 것입니다.

**모델 ID:** `bria/image-edit-replace-background`

**엔드포인트:** `POST https://api.comfy.org/v2/models/bria/image-edit-replace-background`

동일한 본문을 `POST https://api.comfy.org/v2/models/bria/image-edit-replace-background/requests`로 보냅니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`을 응답하고, 결과는 준비되면 이 프로세스에서든 다른 프로세스에서든 수집합니다. [큐 전송](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 안내합니다.

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
with Comfy() as client:
    handle = client.models.submit(
        "bria/image-edit-replace-background",
        {
            "image": "https://img.freepik.com/free-photo/portrait-woman_395237-33.jpg?w=740&q=80",
            "prompt": "A sunny beach with palm trees and a clear blue sky",
        },
    )
    print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

    # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
    for update in handle.iter_events():
        print(update.status, update.queue_position)

    # 공급자의 자체 페이로드이며, models.run()이 반환하는 것과 동일한 값입니다.
    # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
    result = handle.get()

print(result)
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.

  console.log(update.status, update.queuePosition);
}
```

## 스키마

### 입력

<ParamField body="enhance_ref_images" type="boolean">
  true(기본값)일 때 참조 이미지를 추가로 처리하면 결과가 향상됩니다.
</ParamField>

<ParamField body="force_background_detection" type="boolean">
  참일 때 입력 이미지에 알파 채널이 있더라도 강제로 배경을 감지하고 제거합니다.
</ParamField>

<ParamField body="image" type="string" required>
  편집할 이미지입니다. 지원되는 입력 유형은 Base64로 인코딩된 문자열 또는 공개적으로 접근 가능한 이미지 파일을 가리키는 URL입니다. 허용 형식은 JPEG, JPG, PNG, WEBP입니다.
</ParamField>

<ParamField body="mode" type="string">
  배경 생성 모드로, "base", "high_control"(기본값), "fast" 중 하나입니다. prompt가 제공된 경우에만 적용됩니다.
</ParamField>

<ParamField body="negative_prompt" type="string">
  생성된 배경에서 제외할 개념, 스타일 또는 객체를 지정하는 텍스트 프롬프트입니다.
</ParamField>

<ParamField body="original_quality" type="boolean">
  참일 때 출력은 원본 이미지 크기를 유지합니다. false(기본값)일 때 출력은 1MP로 조정됩니다.
</ParamField>

<ParamField body="prompt" type="string">
  새로운 배경에 대한 텍스트 설명입니다. prompt 또는 ref_images 중 하나만 제공하고 둘 다 제공하지 마세요. 프롬프트에 16진수 색상 코드(예: "#FF5733")를 넣으면 단색 배경이 생성됩니다.
</ParamField>

<ParamField body="prompt_content_moderation" type="boolean">
  활성화하면 프롬프트에 콘텐츠 검열을 적용합니다. 프롬프트가 검열을 통과하지 못하면 422를 반환합니다.
</ParamField>

<ParamField body="ref_images" type="object">
  배경 생성을 안내하는 하나의 참조 이미지 또는 참조 이미지 목록이며, 각 항목은 Base64로 인코딩된 문자열 또는 공개적으로 접근 가능한 이미지 파일을 가리키는 URL입니다. prompt 또는 ref_images 중 하나만 제공하고 둘 다 제공하지 마세요.
</ParamField>

<ParamField body="refine_prompt" type="boolean">
  true(기본값)일 때 최적의 생성 결과를 위해 프롬프트가 자동으로 조정됩니다.
</ParamField>

<ParamField body="seed" type="integer">
  결정적 생성을 위한 시드입니다. 생략하면 무작위 시드가 사용됩니다.
</ParamField>

<ParamField body="sync" type="boolean">
  false(기본값)일 때 요청은 비동기적으로 처리됩니다. 참일 때
API는 완료될 때까지 연결을 열린 상태로 유지합니다. ON COMFY
ROUTER에서 두 번째 모드는 전달되지 않고 거부됩니다. Router는
디스패치 전에 반환 모드를 고정하고 호출 내부에서 결과를
폴링하므로, `POST /v2/models/bria/{model}`는 이 경로가
`false` 또는 `null` 이외의 `sync`를 전달하는 경우 422
invalid_input으로 응답합니다(routerForbiddenBodyFields). 동기
호출은 이 작업 자체의 `/proxy/` 경로에서 여전히 사용할 수 있으며,
이 스키마가 설명하는 것도 바로 이 인터페이스입니다.
</ParamField>

<ParamField body="visual_output_content_moderation" type="boolean">
  활성화하면 결과 비주얼에 콘텐츠 검열을 적용합니다. 출력이 검열을 통과하지 못하면 422를 반환합니다.
</ParamField>

Router가 `GET /v2/models/bria/image-edit-replace-background/openapi.json`에서 제공하는 스키마에서 생성되었으며, 이는 요청이 공급자에 도달하기 전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.
