동일한 본문을 `POST https://api.comfy.org/v2/models/bria/image-edit-erase-foreground/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`로 응답하며, 결과는 준비되면 이 프로세스 또는 다른 프로세스에서 수집됩니다. [큐 전송](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 안내합니다.

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# 환경에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
with Comfy() as client:
    handle = client.models.submit(
        "bria/image-edit-erase-foreground",
        {
            "image": "https://img.freepik.com/free-photo/portrait-woman_395237-33.jpg?w=740&q=80",
        },
    )
    print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다.

    # 서버가 지정한 Retry-After만큼 기다리며 요청이 완료될 때까지 폴링합니다.
    for update in handle.iter_events():
        print(update.status, update.queue_position)

    # 공급자 자체의 페이로드이며, models.run()이 반환하는 값과 동일합니다.
    # 실패했거나 취소된 요청은 여기서 타입이 지정된 Router 오류를 발생시킵니다.
    result = handle.get()

print(result)
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("bria/image-edit-erase-foreground", {
  image: "https://img.freepik.com/free-photo/portrait-woman_395237-33.jpg?w=740&q=80",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다.

// 서버가 지정한 Retry-After만큼 기다리며 요청이 완료될 때까지 폴링합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```swift Swift
import Foundation
import ComfySwiftSDK

// Reads COMFY_API_KEY from the environment.
// Each submit() call mints its own Idempotency-Key and reuses it for automatic retries.
let client = ComfyCloudClient(apiKey: ProcessInfo.processInfo.environment["COMFY_API_KEY"]!)
let handle = try await client.models.submit(
    "bria/image-edit-erase-foreground",
    input: [
        "image": "https://img.freepik.com/free-photo/portrait-woman_395237-33.jpg?w=740&q=80",
    ]
)
print("requestId:", handle.requestId)  // with the model ID, all another process needs

// Poll until the request completes, waiting the Retry-After the server names.
for try await update in handle.events() {
    print(update.state.rawValue, update.queuePosition.map(String.init) ?? "unknown")
}

// The provider's own payload, the same value models.run() returns.
// A request that failed or was cancelled throws the typed Router error here.
let result = try await handle.result()

print(result.output)
```

```bash cURL

  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \

REQUEST_ID="<request_id from the 201 body>"

  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집합니다. 모델의 네이티브 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202를 반환합니다.
curl https://api.comfy.org/v2/models/bria/image-edit-erase-foreground/requests/$REQUEST_ID \
```

## 스키마

### 입력

<ParamField body="image" type="string" required>
  편집할 이미지입니다. 지원되는 입력 유형은 Base64로 인코딩된 문자열 또는 공개적으로 접근 가능한 이미지 파일을 가리키는 URL입니다. 허용되는 형식은 JPEG, JPG, PNG, WEBP입니다.
</ParamField>

<ParamField body="preserve_alpha" type="boolean">
  입력 이미지의 부분적으로 투명한 영역을 출력에 유지할지 여부를 제어합니다.
</ParamField>

<ParamField body="sync" type="boolean">
  거짓(기본값)이면 요청이 비동기적으로 처리됩니다. true이면
API가 완료될 때까지 연결을 열어 둡니다. COMFY
ROUTER에서는 두 번째 모드가 전달되지 않고 거부됩니다. Router는
디스패치 전에 반환 모드를 고정하고 호출 내부에서 결과를
폴링하므로, `POST /v2/models/bria/{model}`은 이 라우트가
`false` 또는 `null`이 아닌 `sync`를 담고 있으면 422
invalid_input으로 응답합니다(routerForbiddenBodyFields). 동기 호출은
이 작업 자체의 `/proxy/` 라우트에서 여전히 사용할 수 있으며,
이는 이 스키마가 설명하는 표면이기도 합니다.
</ParamField>

<ParamField body="visual_input_content_moderation" type="boolean">
  활성화하면 입력 시각 자료에 콘텐츠 모더레이션을 적용합니다. 이미지가 모더레이션을 통과하지 못하면 422를 반환합니다.
</ParamField>

<ParamField body="visual_output_content_moderation" type="boolean">
  활성화하면 결과 시각 자료에 콘텐츠 모더레이션을 적용합니다. 출력이 모더레이션을 통과하지 못하면 422를 반환합니다.
</ParamField>

Router가 `GET /v2/models/bria/image-edit-erase-foreground/openapi.json`에서 제공하는 스키마에서 생성되었으며, 이 문서는 요청이 공급자에게 도달하기 전에 호출을 검증할 때 사용하는 것과 동일한 문서입니다.
