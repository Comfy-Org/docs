`veed/fabric-1.0`에 대한 API 레퍼런스로, Veed에서 Comfy Router를 통해 제공됩니다.

**입력:** 이미지, 오디오 · **출력:** 비디오 + 오디오

## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys?onboarding=router)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python 및 TypeScript 스니펫은 Comfy SDK를 사용하며(`pip install comfy-sdk`, `npm install @comfyorg/sdk`), cURL 스니펫은 동일한 호출을 원시 HTTP로 보냅니다.

**모델 ID:** `veed/fabric-1.0`

**엔드포인트:** `POST https://api.comfy.org/v2/models/veed/fabric-1.0`

동일한 본문을 `POST https://api.comfy.org/v2/models/veed/fabric-1.0/requests`로 보냅니다. Router는 실행이 접수되는 즉시 `201`과 함께 `request_id`를 반환하며, 결과는 준비가 되면 이 프로세스에서든 다른 프로세스에서든 수집할 수 있습니다. [대기열 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 단계별로 살펴봅니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 발급하고 자동 재시도 시 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "veed/fabric-1.0",
            {
                "audio_url": "https://static-assets.veed.io/api-examples/fabric-input.mp3",
                "image_url": "https://static-assets.veed.io/api-examples/fabric-input.png",
                "resolution": "480p",
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자 자체의 페이로드로, models.run()이 반환하는 것과 동일한 값입니다.
        # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 발급하고 자동 재시도 시 재사용합니다.
const handle = await comfy.models.submit("veed/fabric-1.0", {
  audio_url: "https://static-assets.veed.io/api-examples/fabric-input.mp3",
  image_url: "https://static-assets.veed.io/api-examples/fabric-input.png",
  resolution: "480p",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/veed/fabric-1.0/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"audio_url\": \"https://static-assets.veed.io/api-examples/fabric-input.mp3\", \"image_url\": \"https://static-assets.veed.io/api-examples/fabric-input.png\", \"resolution\": \"480p\"}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 대기합니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/veed/fabric-1.0/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집. 모델의 원본 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202입니다.
curl https://api.comfy.org/v2/models/veed/fabric-1.0/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

### 입력

<ParamField body="audio_url" type="string" required>

</ParamField>
