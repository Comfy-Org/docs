두 가지 확장이 순차 배포 중이며 오늘 기준으로 둘 다 기본적으로 꺼져 있습니다. 이들은 하나의 전환 뒤에 함께 제공되며 함께 활성화되므로, 아래의 모든 내용은 아직 대비해 개발할 대상이 아니라 예정된 사항으로 취급하세요. 둘 중 하나에 의존하기 전에 문의하세요.

Comfy 담당자에게 계정에 대해 활성화해 달라고 요청하세요. 또한 이는 다음과 같은 서드파티 오브젝트 스토리지 호스트를 허용합니다. 여기서 버킷은 여러분의 것이며 Router는 이에 대한 소유권을 주장하지 않습니다: Cloudflare R2 (`<account>.r2.cloudflarestorage.com`, `pub-<hash>.r2.dev`), Amazon S3 (`s3.amazonaws.com` 및 `s3.<region>.amazonaws.com`, path-style 또는 `<bucket>.` 접두 형식 모두), Azure Blob Storage (`<account>.blob.core.windows.net`) 그리고 Alibaba Cloud OSS (`<bucket>.oss-<region>.aliyuncs.com`, `oss-accelerate` 엔드포인트 포함). 이들은 구체적으로 오브젝트 스토리지 엔드포인트입니다. 같은 공급자 도메인의 범용 엔드포인트, 예를 들어 Alibaba Function Compute 트리거는 목록에 없으며 거부됩니다.
