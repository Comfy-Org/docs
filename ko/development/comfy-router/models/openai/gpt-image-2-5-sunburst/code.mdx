<ResponseField name="background" type="string">
  생성된 이미지의 배경이 `opaque`인지 `transparent`인지, 그리고 OpenAI가 이번 생성에서 이를 어떻게 판정했는지를 나타냅니다. 요청 파라미터의 기본값은 `auto`이므로, 이 값을 고정하지 않은 호출자는 여기에서 어떤 배경이 생성되었는지 확인할 수 있습니다.
</ResponseField>

<ResponseField name="created" type="integer">
  생성이 완료된 시각의 Unix 타임스탬프(초)입니다. OpenAI가 이미지 생성 응답에서 REQUIRED(필수)로 선언한 유일한 멤버이므로, OpenAI가 생성 주체일 때는 항상 존재합니다. fal 또는 wavespeed가 제공하는 `openai/gpt-image-2` 응답에서는 다른 네 개의 resolved-parameter 멤버들과 마찬가지로 이 필드가 완전히 생략됩니다. 현재의 epoch 값이 2^31에 충분히 가까워서, 포맷을 지정하지 않은 `integer`는 많은 SDK 생성기에서 32비트 필드를 만들어내기 때문에 `int64`로 선언되었습니다.

  형식: `int64`
</ResponseField>

<ResponseField name="output_format" type="string">
  `data[].b64_json`에 담긴 바이트의 인코딩 방식으로, `png`, `webp` 또는 `jpeg`입니다. OpenAI가 실제로 인코딩한 형식이며, 요청에 `output_format`이 전송된 경우에는 그 값이, 전송되지 않은 경우에는 `png`이 되므로, 디코더는 요청에서 형식을 다시 도출하는 대신 이 값을 기준으로 삼을 수 있습니다.
</ResponseField>

<ResponseField name="quality" type="string">
  생성이 실제로 실행된 품질 등급으로, OpenAI는 `low`, `medium`, `high`, `xhigh` 또는 `max` 중 하나를 보고합니다. 요청을 그대로 되돌려준 값이 아니라 실제로 해석(resolve)된 등급이며, 요청의 `quality` 자체는 기본값이 `auto`입니다.
</ResponseField>

<ResponseField name="size" type="string">
  생성이 실제로 실행된 픽셀 크기로, `<width>x<height>` 형식입니다. 실제로 해석(resolve)된 크기입니다. 요청의 `size`는 기본값이 `auto`이고 `auto`를 명시적으로 허용하므로, 실제로 사용된 크기가 보고되는 곳은 여기뿐입니다.
</ResponseField>
