<ResponseField name="created" type="integer">
  생성이 완료된 시각의 Unix 타임스탬프(초)입니다. OpenAI가 이미지 생성 응답에서 필수(REQUIRED)로 선언하는 유일한 멤버이므로, OpenAI가 생성자인 경우에는 항상 존재합니다. fal이 제공하는 `openai/gpt-image-2` 응답에서는 다른 네 개의 결정된 파라미터 멤버와 마찬가지로 이 필드가 완전히 생략됩니다. `int64`로 선언된 이유는 현재의 epoch 값이 2^31에 충분히 가까워서, 포맷을 지정하지 않은 `integer`가 많은 SDK 생성기에서 32비트 필드를 만들기 때문입니다.

<ResponseField name="output_format" type="string">

</ResponseField>

<ResponseField name="quality" type="string">
  생성이 실제로 실행된 품질 등급으로, OpenAI는 `low`, `medium`, `high`, `xhigh` 또는 `max` 중 하나를 보고합니다. 이는 요청을 그대로 반영한 것이 아니라 결정된(RESOLVED) 등급이며, 요청의 `quality` 자체는 기본값이 `auto`입니다.
</ResponseField>

<ResponseField name="size" type="string">

</ResponseField>
