WaveSpeed에서 Comfy Router를 통해 제공하는 `wavespeed/seedvr2`의 API 레퍼런스입니다.

## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python과 TypeScript 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`)를 사용하며, cURL 스니펫은 동일한 호출을 raw HTTP로 수행합니다.

**모델 ID:** `wavespeed/seedvr2`

**엔드포인트:** `POST https://api.comfy.org/v2/models/wavespeed/seedvr2`

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment.
# The SDK automatically creates an idempotency key and reuses it for automatic retries.
with Comfy() as client:
    result = client.models.run(
        "wavespeed/seedvr2",
        {
            "image": "https://images.pexels.com/photos/346529/pexels-photo-346529.jpeg",
            "target_resolution": "4k",
        },
    )

print(result)
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Reads COMFY_API_KEY from the environment.
// The SDK automatically creates an idempotency key and reuses it for automatic retries.
const { data } = await comfy.models.run("wavespeed/seedvr2", {
  image: "https://images.pexels.com/photos/346529/pexels-photo-346529.jpeg",
  target_resolution: "4k",
});

console.log(data);
```

```bash cURL
curl https://api.comfy.org/v2/models/wavespeed/seedvr2 \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"image\": \"https://images.pexels.com/photos/346529/pexels-photo-346529.jpeg\", \"target_resolution\": \"4k\"}"
```
</CodeGroup>

## 스키마

### 입력

<ParamField body="enable_base64_output" type="boolean" default="false">
  활성화하면 출력이 URL 대신 BASE64 문자열로 인코딩됩니다.
</ParamField>

<ParamField body="image" type="string" required>
  업스케일할 이미지의 URL입니다.
</ParamField>

<ParamField body="output_format" type="string" default="&quot;jpeg&quot;">
  출력 이미지의 형식입니다.

  가능한 값: `jpeg`, `png`, `webp`
</ParamField>

<ParamField body="target_resolution" type="string" default="&quot;4k&quot;">
  출력 이미지의 목표 해상도입니다.

  가능한 값: `2k`, `4k`, `8k`
</ParamField>

Router가 `GET /v2/models/wavespeed/seedvr2/openapi.json`에서 제공하는 스키마에서 생성되며, 요청이 공급자에 도달하기 이전에 Router가 호출을 검증하는 기준이 되는 동일한 문서입니다.

### 출력

<ResponseField name="code" type="integer">
  WavespeedAI 자체의 envelope 상태 코드로, HTTP 상태를 반영합니다(이 스키마가 설명하는 문서에서는 200). Wavespeed는 일부 실패를 전송 상태가 아니라 여기에 보고합니다.
</ResponseField>

<ResponseField name="data" type="object" required>
   
</ResponseField>

<ResponseField name="data.created_at" type="string">
  Wavespeed가 예측을 생성한 시점의 ISO-8601 타임스탬프입니다.
</ResponseField>

<ResponseField name="data.error" type="string">
  Wavespeed의 자유 형식 실패 사유이며, 없는 경우 빈 문자열입니다. 실제로 실패한 예측은 이 문서가 아니라 Comfy Router 오류의 형태로 Router 호출자에게 전달됩니다.
</ResponseField>

<ResponseField name="data.id" type="string">
  Router가 제출하고 폴링한 예측에 대한 Wavespeed의 식별자입니다.
</ResponseField>

<ResponseField name="data.model" type="string">
  예측이 실행된 Wavespeed 모델 id입니다.
</ResponseField>

<ResponseField name="data.outputs" type="string[]" required>
  완료된 생성 결과입니다. Router가 반환하는 문서에서는 존재하며 비어 있지 않습니다. 이 목록 자체가 결과입니다. 각 요소는 생성된 콘텐츠의 URL(`wavespeed/flashvsr`의 경우 MP4, 두 업스케일러의 경우 이미지)이거나, 요청에서 `enable_base64_output`을 설정한 경우 두 이미지 id에 대해 base64로 인코딩된 바이트 자체입니다. 링크는 Wavespeed 자체의 것이며 만료됩니다.
</ResponseField>

<ResponseField name="data.status" type="string" required>
  Wavespeed가 표기한 예측의 최종 상태입니다. 여기서는 enum으로 좁히지 않습니다. Router는 값을 변경 없이 전달하고 폴링 분류기는 비교 이전에 소문자로 변환하므로, 성공은 `completed`, `succeeded`, `success` 또는 `done`으로 대소문자에 관계없이 정당하게 도착할 수 있습니다.
</ResponseField>

<ResponseField name="data.timings" type="object">
  Wavespeed 자체의 타이밍 측정값입니다.
</ResponseField>

<ResponseField name="data.timings.inference" type="integer">
  밀리초 단위의 추론 시간입니다. Comfy 청구가 아니라 Wavespeed의 수치입니다.
</ResponseField>

<ResponseField name="data.urls" type="object">
  예측에 대한 Wavespeed 자체의 링크입니다.
</ResponseField>

<ResponseField name="data.urls.get" type="string">
  Router가 폴링한 예측 결과 URL입니다.
</ResponseField>

<ResponseField name="message" type="string">
  envelope 상태 메시지입니다(예: `success`).
</ResponseField>
