Comfy Router가 WaveSpeed에서 제공하는 `wavespeed/wavespeed-nano-banana-pro`에 대한 API 레퍼런스입니다.

## 요청 설정

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python의 경우 `pip install comfy-sdk`를 실행하세요. TypeScript의 경우 `npm install @comfyorg/sdk`를 실행하세요. cURL은 원시 HTTP를 사용합니다.

**모델 ID:** `wavespeed/wavespeed-nano-banana-pro`

**엔드포인트:** `POST https://api.comfy.org/v2/models/wavespeed/wavespeed-nano-banana-pro`

<Note>
Router는 이 모델에 대해 작성된 입력 스키마를 게시하지 않았으므로, 스니펫을 생성할 요청 예시가 없습니다. Router는 본문을 WaveSpeed로 변경 없이 전달합니다. WaveSpeed 자체 API 문서를 참고해 본문을 구성한 다음, [Router 퀵스타트](/ko/development/comfy-router/quickstart)를 사용해 전송하세요.
</Note>

## 스키마

### 입력

<Note>
Router는 아직 이 모델에 대해 작성된 입력 스키마를 게시하지 않았습니다: `GET /v2/models/wavespeed/wavespeed-nano-banana-pro/openapi.json`은 `x-comfy-input-schema-authored: false`인 개방형 객체를 반환합니다. Router는 본문을 WaveSpeed로 변경 없이 전달하므로, 요청 필드에 대해서는 WaveSpeed 자체 API 문서가 기준이며, Router는 모델별 입력 검증을 수행하지 않습니다. 공급자 검증은 여전히 적용됩니다.
</Note>
