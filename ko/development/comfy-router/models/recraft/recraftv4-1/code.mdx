`recraft/recraftv4_1`에 대한 API 레퍼런스로, Recraft에서 Comfy Router를 통해 제공됩니다.

## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys?onboarding=router)에서 키를 생성한 뒤 `COMFY_API_KEY`로 내보내세요. Python, TypeScript, Swift 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`, 그리고 [`ComfySwiftSDK`](https://github.com/Comfy-Org/comfy-swift-sdk) Swift 패키지)를 사용하며, cURL 스니펫은 동일한 호출을 raw HTTP로 수행한 것입니다.

**모델 ID:** `recraft/recraftv4_1`

**엔드포인트:** `POST https://api.comfy.org/v2/models/recraft/recraftv4_1`

동일한 본문을 `POST https://api.comfy.org/v2/models/recraft/recraftv4_1/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `201`과 `request_id`를 반환하며, 결과는 준비되는 대로 이 프로세스 또는 다른 프로세스에서 수집합니다. [대기열 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 자세히 안내합니다.

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
with Comfy() as client:
    handle = client.models.submit(
        "recraft/recraftv4_1",
        {
            "n": 1,
            "prompt": "A single red maple leaf on a plain white background.",
        },
    )
    print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

    # 서버가 알려주는 Retry-After만큼 기다리며 요청이 완료될 때까지 폴링합니다.
    for update in handle.iter_events():
        print(update.status, update.queue_position)

    # 공급자 자체의 페이로드이며, models.run()이 반환하는 것과 동일한 값입니다.
    # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
    result = handle.get()

print(result)
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("recraft/recraftv4_1", {
  n: 1,
  prompt: "A single red maple leaf on a plain white background.",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 서버가 알려주는 Retry-After만큼 기다리며 요청이 완료될 때까지 폴링합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```swift Swift
import Foundation
import ComfySwiftSDK

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
let client = ComfyCloudClient(apiKey: ProcessInfo.processInfo.environment["COMFY_API_KEY"]!)
let handle = try await client.models.submit(
    "recraft/recraftv4_1",
    input: [
        "n": 1,
        "prompt": "A single red maple leaf on a plain white background.",
    ]
)
print("requestId:", handle.requestId)  // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 서버가 알려주는 Retry-After만큼 기다리며 요청이 완료될 때까지 폴링합니다.
for try await update in handle.events() {
    print(update.state.rawValue, update.queuePosition.map(String.init) ?? "unknown")
}

// 공급자 자체의 페이로드이며, models.run()이 반환하는 것과 동일한 값입니다.
// 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 던집니다.
let result = try await handle.result()

print(result.output)
```

```bash cURL
# 1. 제출합니다. Router는 request_id, status_url, response_url, cancel_url과 함께 201을 반환합니다.
curl https://api.comfy.org/v2/models/recraft/recraftv4_1/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"n\": 1, \"prompt\": \"A single red maple leaf on a plain white background.\"}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 알려주는 Retry-After 초만큼 기다립니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/recraft/recraftv4_1/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집합니다. 200은 모델의 네이티브 출력과 함께, 아직 실행 중일 때는 202와 상태 본문이 반환됩니다.
curl https://api.comfy.org/v2/models/recraft/recraftv4_1/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="controls" type="object">
  생성된 이미지에 대한 제어
</ParamField>

<ParamField body="controls.artistic_level" type="integer">
  이미지의 예술적 톤을 정의합니다. 단순한 수준에서는 인물이 정적이고 깔끔한 스타일로 카메라를 똑바로 응시합니다. 다이내믹하고 이색적인 수준은 움직임과 창의성을 도입합니다.

  범위: `0` ~ `5`
</ParamField>

<ParamField body="controls.background_color" type="object">
  RGB 색상 값
</ParamField>

<ParamField body="controls.background_color.rgb" type="integer[]" required>
   
</ParamField>

<ParamField body="controls.colors" type="object[]">
  선호하는 색상의 배열
</ParamField>

<ParamField body="controls.colors[].rgb" type="integer[]" required>
   
</ParamField>

<ParamField body="controls.no_text" type="boolean">
  텍스트 레이아웃을 삽입하지 않습니다
</ParamField>

<ParamField body="model" type="string">
  생성에 사용할 모델입니다 (예: "recraftv3"). 이 필드는 enum으로 제한되지 않습니다. 프록시는 호출자가 보낸 값을 그대로 전달합니다. Comfy가 제공하는 표기, 즉 Comfy Router가 `recraft/<model>`로 주소를 지정하는 집합은 recraftv2, recraftv3, recraftv4, recraftv4_pro, recraftv4_1, recraftv4_1_utility, recraftv4_1_pro, recraftv4_1_utility_pro, recraftv4_styles, recraftv4_styles_pro, recraftv4_1_vector, recraftv4_1_utility_vector, recraftv4_1_pro_vector, recraftv4_1_utility_pro_vector, recraftv4_styles_vector 및 recraftv4_styles_pro_vector입니다. 이를 참조로 이름을 지정하지 않고 여기에 직접 나열한 이유는, 이들을 선언하는 RecraftGenerationModel 컴포넌트가 어디에서도 `$ref`되지 않아 GET /openapi로 제공되는 명세에서 제거되므로, 이에 대한 포인터가 제공되는 문서에서 끊어진 참조가 되기 때문입니다. 네 가지 `recraftv4_styles*` 표기는 추가로 `style_id`가 필요합니다. 해당 필드를 참고하세요.
</ParamField>

<ParamField body="n" type="integer">
  생성할 이미지 수입니다. Recraft는 1-6을 허용합니다.

  범위: `1` ~ `6`
</ParamField>

<ParamField body="prompt" type="string" required>
  생성할 이미지를 설명하는 텍스트 프롬프트
</ParamField>

<ParamField body="response_format" type="string">
  가능한 값: `url`, `b64_json`
</ParamField>

<ParamField body="size" type="string">
  생성된 이미지의 크기 (예: "1024x1024")
</ParamField>

<ParamField body="style" type="string">
  생성된 이미지에 적용할 스타일 (예: "digital_illustration")
</ParamField>

<ParamField body="style_id" type="string">
  생성된 이미지에 적용할 스타일 ID (예: "123e4567-e89b-12d3-a456-426614174000"). style_id가 제공되면 style은 제공하지 않아야 합니다. 네 가지 `recraftv4_styles*` 모델에서 필수입니다. Recraft는 style_id 또는 스타일 참조가 없는 요청을 거부합니다. `POST /proxy/recraft/styles`로 스타일 ID를 발급받을 수 있으며, 이 동일한 프록시가 동일한 자격 증명으로 해당 엔드포인트를 제공합니다. 이 라우트에서 이 조합을 강제하는 것은 없습니다. 본문은 변경 없이 Recraft로 전달되므로, style_id 없이 `recraftv4_styles*`를 호출하면 파트너에 도달한 뒤 4xx로 반환됩니다.
</ParamField>

Router가 `GET /v2/models/recraft/recraftv4_1/openapi.json`에서 제공하는 스키마에서 생성되었으며, 이는 요청이 공급자에 도달하기 이전에 호출을 검증하는 데 사용하는 동일한 문서입니다.

</ResponseField>
