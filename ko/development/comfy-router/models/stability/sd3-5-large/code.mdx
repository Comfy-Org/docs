## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys?onboarding=router)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python 및 TypeScript 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`)를 사용하며, cURL 스니펫은 동일한 호출을 원시 HTTP로 수행합니다.

**모델 ID:** `stability/sd3.5-large`

**엔드포인트:** `POST https://api.comfy.org/v2/models/stability/sd3.5-large`

동일한 본문을 `POST https://api.comfy.org/v2/models/stability/sd3.5-large/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `201`과 `request_id`로 응답하며, 결과는 준비가 되면 이 프로세스에서든 다른 프로세스에서든 수집합니다. [대기 중 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 방법을 안내합니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/sd3.5-large",
            {
                "aspect_ratio": "16:9",
                "prompt": "a lighthouse on a cliff at sunset, oil painting",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자 자체의 페이로드이며, models.run()이 반환하는 것과 동일한 값입니다.
        # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("stability/sd3.5-large", {
  aspect_ratio: "16:9",
  prompt: "a lighthouse on a cliff at sunset, oil painting",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출합니다. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/stability/sd3.5-large/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"aspect_ratio\": \"16:9\", \"prompt\": \"a lighthouse on a cliff at sunset, oil painting\", \"seed\": 12345}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 대기합니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/stability/sd3.5-large/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집합니다. 200은 모델의 기본 출력과 함께, 202는 아직 실행 중일 때 상태 본문과 함께 반환됩니다.
curl https://api.comfy.org/v2/models/stability/sd3.5-large/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="aspect_ratio" type="string">
  텍스트 기반 이미지 생성 전용입니다. 약 1메가픽셀에서의 출력 이미지 비율입니다. 기본값 1:1.

  가능한 값: `1:1`, `16:9`, `9:16`, `21:9`, `9:21`, `3:2`, `2:3`, `5:4`, `4:5`
</ParamField>

<ParamField body="cfg_scale" type="number">
  이미지가 프롬프트를 얼마나 엄격하게 따르는지 나타냅니다.

  범위: `1` ~ `10`
</ParamField>

<ParamField body="image" type="string (uri)">
  이미지 기반 이미지 생성 전용입니다. 소스 이미지의 ComfyUI 서명 에셋 URL입니다.

  형식: `uri`
</ParamField>

<ParamField body="mode" type="string">
  기본값은 텍스트 기반 이미지 생성입니다. 이미지 기반 이미지 생성에는 `image`와 `strength`가 필요합니다.

  가능한 값: `text-to-image`, `image-to-image`
</ParamField>

<ParamField body="negative_prompt" type="string">
  이미지에서 제외할 내용입니다.
</ParamField>

<ParamField body="output_format" type="string">
  `png`만 반환됩니다.

  가능한 값: `png`
</ParamField>

<ParamField body="prompt" type="string" required>
  생성할 내용입니다.
</ParamField>

<ParamField body="seed" type="integer">
  0이거나 생략하면 임의의 시드를 선택합니다.

  범위: `0` ~ `4294967294`
</ParamField>

<ParamField body="strength" type="number">
  이미지 기반 이미지 생성 전용입니다. 소스 이미지에서 얼마나 벗어날지 나타내며, 1은 소스 이미지를 무시합니다.

  범위: `0` ~ `1`
</ParamField>

<ParamField body="style_preset" type="string">
  Stability 스타일 프리셋입니다. 예: `photographic`.
</ParamField>

`GET /v2/models/stability/sd3.5-large/openapi.json`에서 Router가 제공하는 스키마에서 생성되었으며, 이 문서는 요청이 공급자에 도달하기 전에 Router가 호출을 검증하는 기준 문서와 동일합니다.

### 출력

<ResponseField name="finish_reason" type="string" required>
  200 응답에서는 항상 SUCCESS입니다.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  (첫 번째) PNG 이미지의 ComfyUI 서명 URL이며 최대 24시간 동안 유효합니다.

  형식: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  SDXL 전용이며, 이미지가 둘 이상 반환된 경우에 사용됩니다. 출력 순서대로 모든 ComfyUI 서명 이미지 URL이 나열되며, 각 URL은 최대 24시간 동안 유효합니다.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  이미지를 생성하는 데 사용된 시드입니다.
</ResponseField>
