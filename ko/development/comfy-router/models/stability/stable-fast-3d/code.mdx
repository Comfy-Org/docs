동일한 본문을 `POST https://api.comfy.org/v2/models/stability/stable-fast-3d/requests`로 보냅니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`로 응답하며, 결과는 준비가 되면 이 프로세스에서든 다른 프로세스에서든 수집할 수 있습니다. [대기열 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 방법을 단계별로 설명합니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 발급하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/stable-fast-3d",
            {
                "foreground_ratio": 0.85,
                "image": "https://storage.googleapis.com/example-bucket/source.png",
                "remesh": "none",
                "texture_resolution": 1024,
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 기다립니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자 자체의 페이로드로, models.run()이 반환하는 것과 동일한 값입니다.
        # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 발급하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("stability/stable-fast-3d", {
  foreground_ratio: 0.85,
  image: "https://storage.googleapis.com/example-bucket/source.png",
  remesh: "none",
  texture_resolution: 1024,
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 기다립니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출합니다. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/stability/stable-fast-3d/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"foreground_ratio\": 0.85, \"image\": \"https://storage.googleapis.com/example-bucket/source.png\", \"remesh\": \"none\", \"texture_resolution\": 1024}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 기다립니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/stability/stable-fast-3d/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집합니다. 200과 함께 모델의 네이티브 출력을, 아직 실행 중이면 202와 함께 상태 본문을 받습니다.
curl https://api.comfy.org/v2/models/stability/stable-fast-3d/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="foreground_ratio" type="number">
  피사체가 프레임을 채우는 비율입니다. 기본값 0.85.

  범위: `0.1`부터 `1`까지
</ParamField>

<ParamField body="image" type="string (uri)" required>
  소스 이미지의 Comfy 서명 에셋 URL입니다.

  형식: `uri`
</ParamField>

<ParamField body="remesh" type="string">
  Remesh 모드입니다. 기본값 `none`.

  가능한 값: `none`, `triangle`, `quad`
</ParamField>

<ParamField body="texture_resolution" type="integer">
  텍스처 크기입니다. 기본값 1024.

  가능한 값: `512`, `1024`, `2048`
</ParamField>

<ParamField body="vertex_count" type="integer">
  대상 정점 수입니다. -1이면 그래프 자체의 개수를 사용합니다. 기본값 -1.

  범위: `-1`부터 `20000`까지
</ParamField>

Router가 `GET /v2/models/stability/stable-fast-3d/openapi.json`에서 제공하는 스키마에서 생성되었으며, 이는 요청이 공급자에 도달하기 전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.

### 출력

<ResponseField name="finish_reason" type="string" required>

<ResponseField name="model" type="string (uri)" required>

</ResponseField>
