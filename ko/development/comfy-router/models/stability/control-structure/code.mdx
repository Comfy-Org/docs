동일한 본문을 `POST https://api.comfy.org/v2/models/stability/control-structure/requests`로 전송합니다. Router는 실행이 수락되는 즉시 `201`과 `request_id`를 응답하며, 결과는 준비되면 이 프로세스 또는 다른 프로세스에서 수집합니다. [대기 중인 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 안내합니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/control-structure",
            {
                "control_strength": 0.7,
                "image": "https://storage.googleapis.com/example-bucket/sketch.png",
                "prompt": "a castle on a cliff",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면, 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 기다립니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자의 자체 페이로드이며, models.run()이 반환하는 것과 같은 값입니다.
        # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("stability/control-structure", {
  control_strength: 0.7,
  image: "https://storage.googleapis.com/example-bucket/sketch.png",
  prompt: "a castle on a cliff",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면, 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 기다립니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 같은 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출합니다. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/stability/control-structure/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"control_strength\": 0.7, \"image\": \"https://storage.googleapis.com/example-bucket/sketch.png\", \"prompt\": \"a castle on a cliff\", \"seed\": 12345}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 기다립니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/stability/control-structure/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집합니다. 모델의 기본 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202를 반환합니다.
curl https://api.comfy.org/v2/models/stability/control-structure/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="control_strength" type="number">
  결과가 소스 이미지를 얼마나 충실히 따르는지입니다. 기본값 0.7.

  범위: `0` ~ `1`
</ParamField>

<ParamField body="image" type="string (uri)" required>
  소스 이미지의 Comfy 서명 자산 URL입니다.

  형식: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  이미지에서 제외할 내용입니다.
</ParamField>

<ParamField body="output_format" type="string">
  `png`만 반환됩니다.

  가능한 값: `png`
</ParamField>

<ParamField body="prompt" type="string" required>
  소스 이미지로부터 생성할 내용입니다.
</ParamField>

<ParamField body="seed" type="integer">
  0이거나 생략하면 무작위 시드를 선택합니다.

  범위: `0` ~ `4294967294`
</ParamField>

<ParamField body="style_preset" type="string">
  허용되지만 적용되지는 않습니다.
</ParamField>

Router가 `GET /v2/models/stability/control-structure/openapi.json`에서 제공하는 스키마에서 생성되었으며, 요청이 공급자에 도달하기 이전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.

### 출력

<ResponseField name="finish_reason" type="string" required>
  200 응답에서는 항상 SUCCESS입니다.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  (첫 번째) PNG 이미지의 Comfy 서명 URL이며, 최대 24시간 동안 유효합니다.

  형식: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  SDXL 전용이며, 이미지가 두 개 이상 반환된 경우에 사용됩니다. 출력 순서대로 나열된 모든 Comfy 서명 이미지 URL이며, 각각 최대 24시간 동안 유효합니다.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  이미지 생성에 사용된 시드입니다.
</ResponseField>
