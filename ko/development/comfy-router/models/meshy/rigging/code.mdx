Meshy에서 Comfy Router를 통해 제공하는 `meshy/rigging`의 API 레퍼런스입니다.

## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python 및 TypeScript 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`)를 사용하며, cURL 스니펫은 동일한 호출을 원시 HTTP로 수행합니다.

**모델 ID:** `meshy/rigging`

**엔드포인트:** `POST https://api.comfy.org/v2/models/meshy/rigging`

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment.
# The SDK automatically creates an idempotency key and reuses it for automatic retries.
with Comfy() as client:
    result = client.models.run(
        "meshy/rigging",
        {
            "height_meters": 1.8,
            "input_task_id": "0193abcd-0000-0000-0000-000000000000",
        },
    )

print(result)
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Reads COMFY_API_KEY from the environment.
// The SDK automatically creates an idempotency key and reuses it for automatic retries.
const { data } = await comfy.models.run("meshy/rigging", {
  height_meters: 1.8,
  input_task_id: "0193abcd-0000-0000-0000-000000000000",
});

console.log(data);
```

```bash cURL
curl https://api.comfy.org/v2/models/meshy/rigging \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"height_meters\": 1.8, \"input_task_id\": \"0193abcd-0000-0000-0000-000000000000\"}"
```
</CodeGroup>

## 스키마

### 입력

<ParamField body="height_meters" type="number" default="1.7">
  캐릭터 모델의 대략적인 높이(미터)입니다. 양수여야 합니다.

  범위: `0` ~ `…`
</ParamField>

<ParamField body="input_task_id" type="string">
  리깅해야 하는 입력 작업입니다. model_url이 제공되지 않은 경우 필수입니다.
</ParamField>

<ParamField body="model_url" type="string">
  텍스처가 있는 휴머노이드 GLB 파일에 대한 공개적으로 접근 가능한 URL 또는 Data URI입니다. input_task_id가 제공되지 않은 경우 필수입니다.
</ParamField>

<ParamField body="texture_image_url" type="string">
  모델의 UV 언랩된 기본 색상 텍스처 이미지입니다. 공개적으로 접근 가능한 URL 또는 Data URI입니다. .png 형식을 지원합니다.
</ParamField>

Router가 `GET /v2/models/meshy/rigging/openapi.json`에서 제공하는 스키마에서 생성되었습니다. 이는 요청이 공급자에게 도달하기 전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.

### 출력

<ResponseField name="created_at" type="integer">
  작업이 생성된 시점의 타임스탬프(밀리초)입니다.

  형식: `int64`
</ResponseField>

<ResponseField name="expires_at" type="integer">
  작업 결과가 만료되는 시점의 타임스탬프(밀리초)입니다.

  형식: `int64`
</ResponseField>

<ResponseField name="finished_at" type="integer">
  작업이 완료된 시점의 타임스탬프(밀리초)입니다. 완료되지 않은 경우 0입니다.

  형식: `int64`
</ResponseField>

<ResponseField name="id" type="string" required>
  작업의 고유 식별자입니다.
</ResponseField>

<ResponseField name="preceding_tasks" type="integer">
  선행 작업의 수입니다. status가 PENDING인 경우에만 의미가 있습니다.
</ResponseField>

<ResponseField name="progress" type="integer">
  작업의 진행률(0-100)입니다. 시작되지 않은 경우 0, 성공한 경우 100입니다.

  범위: `0` ~ `100`
</ResponseField>

<ResponseField name="result" type="object">
  작업이 SUCCEEDED인 경우 출력 에셋 URL을 포함합니다.
</ResponseField>

<ResponseField name="result.basic_animations" type="object">
  기본 애니메이션의 URL을 포함합니다.
</ResponseField>

<ResponseField name="result.basic_animations.running_armature_glb_url" type="string">
  GLB 형식의 달리기 애니메이션 아마추어에 대한 다운로드 가능한 URL입니다.
</ResponseField>

<ResponseField name="result.basic_animations.running_fbx_url" type="string">
  FBX 형식의 달리기 애니메이션(스킨 포함)에 대한 다운로드 가능한 URL입니다.
</ResponseField>

<ResponseField name="result.basic_animations.running_glb_url" type="string">
  GLB 형식의 달리기 애니메이션(스킨 포함)에 대한 다운로드 가능한 URL입니다.
</ResponseField>

<ResponseField name="result.basic_animations.walking_armature_glb_url" type="string">
  GLB 형식의 걷기 애니메이션 아마추어에 대한 다운로드 가능한 URL입니다.
</ResponseField>

<ResponseField name="result.basic_animations.walking_fbx_url" type="string">
  FBX 형식의 걷기 애니메이션(스킨 포함)에 대한 다운로드 가능한 URL입니다.
</ResponseField>

<ResponseField name="result.basic_animations.walking_glb_url" type="string">
  GLB 형식의 걷기 애니메이션(스킨 포함)에 대한 다운로드 가능한 URL입니다.
</ResponseField>

<ResponseField name="result.rigged_character_fbx_url" type="string">
  FBX 형식의 리깅된 캐릭터에 대한 다운로드 가능한 URL입니다.
</ResponseField>

<ResponseField name="result.rigged_character_glb_url" type="string">
  GLB 형식의 리깅된 캐릭터에 대한 다운로드 가능한 URL입니다.
</ResponseField>

<ResponseField name="started_at" type="integer">
  작업이 시작된 시점의 타임스탬프(밀리초)입니다. 시작되지 않은 경우 0입니다.

  형식: `int64`
</ResponseField>

<ResponseField name="status" type="string" required>
  가능한 값: `SUCCEEDED`
</ResponseField>

<ResponseField name="task_error" type="object">
  작업이 실패한 경우 오류 메시지를 포함하는 오류 객체입니다.
</ResponseField>

<ResponseField name="task_error.message" type="string">
  자세한 오류 메시지입니다.
</ResponseField>

<ResponseField name="type" type="string">
  Rigging 작업의 유형입니다.

  가능한 값: `rig`
</ResponseField>
