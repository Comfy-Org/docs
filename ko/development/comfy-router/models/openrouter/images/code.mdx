`openrouter/images`에 대한 API 레퍼런스이며, Openrouter에서 Comfy Router를 통해 제공됩니다.

**입력:** 텍스트, 이미지 · **출력:** 이미지

## 요청 설정

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys?onboarding=router)에서 키를 생성하고 `COMFY_API_KEY`로 내보내기하세요. Python의 경우 `pip install comfy-sdk`를 실행하세요. TypeScript의 경우 `npm install @comfyorg/sdk`를 실행하세요. cURL은 원시 HTTP를 사용합니다.

**모델 ID:** `openrouter/images`

**엔드포인트:** `POST https://api.comfy.org/v2/models/openrouter/images`

<Note>
이 모델에는 실행 가능한 요청 예제가 없습니다. 아래 입력 문서를 참고하여 본문을 구성한 다음, [Router 빠른 시작](/ko/development/comfy-router/quickstart)과 함께 사용하세요.
</Note>

  응답이 1,048,576바이트보다 클 때 `b64_json` 대신 제공되는, Comfy가 호스팅하는 이미지의 서명된 URL입니다. Comfy Router는 항상 이를 요청하며, `/proxy/` 라우트는 요청이 `Comfy-Asset-Format: url`을 보낼 때만 이를 요청합니다. 제로 데이터 보존 워크스페이스는 이를 절대 받지 못하며, 해당 워크스페이스의 이미지는 `b64_json`에 남습니다. URL은 호출 후 24시간 뒤에 만료됩니다.
