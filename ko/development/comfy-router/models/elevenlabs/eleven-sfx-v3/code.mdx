## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys?onboarding=router)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python과 TypeScript 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`)를 사용하며, cURL 스니펫은 동일한 호출을 순수 HTTP로 보냅니다.

**모델 ID:** `elevenlabs/eleven_sfx_v3`

**엔드포인트:** `POST https://api.comfy.org/v2/models/elevenlabs/eleven_sfx_v3`

동일한 본문을 `POST https://api.comfy.org/v2/models/elevenlabs/eleven_sfx_v3/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`로 응답하며, 결과는 준비되면 이 프로세스 또는 다른 프로세스에서 수집합니다. [대기 중 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 안내합니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "elevenlabs/eleven_sfx_v3",
            {
                "duration_seconds": 5,
                "text": "A distant rumble of thunder rolling across a valley.",
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다.

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자 자체의 페이로드로, models.run()이 반환하는 것과 동일한 값입니다.
        # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("elevenlabs/eleven_sfx_v3", {
  duration_seconds: 5,
  text: "A distant rumble of thunder rolling across a valley.",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다.

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출합니다. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/elevenlabs/eleven_sfx_v3/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"duration_seconds\": 5, \"text\": \"A distant rumble of thunder rolling across a valley.\"}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 대기합니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/elevenlabs/eleven_sfx_v3/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집합니다. 모델의 네이티브 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202입니다.
curl https://api.comfy.org/v2/models/elevenlabs/eleven_sfx_v3/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="duration_seconds" type="number" required>
  생성될 사운드의 재생 시간(초)입니다.
최소 0.5, 최대 30이어야 합니다.
이 라우트에서는 필수입니다. 필드가 null일 때 최적의 재생 시간을 추측하는
업스트림 ElevenLabs API와 달리, 이 라우트는 이 필드를 생략한 요청을
400 "Duration is required"로 거부합니다.
이 필드가 nullable로 남아 있는 것은 명시적 null이 올바른 형식의 문서가
되도록 하기 위해서일 뿐이며, 그 경우에도 여전히 거부됩니다.
이 값은 요청이 과금되는 기준 수량입니다.

  범위: `0.5` ~ `30`

  형식: `double`
</ParamField>

<ParamField body="loop" type="boolean" default="false">
  매끄럽게 반복되는 사운드 효과를 생성할지 여부입니다.
</ParamField>

<ParamField body="model_id" type="string">
  사운드 생성에 사용할 모델 ID입니다. 이 라우트는 v1 요청의 enum에 있는
Comfy id만 허용하며, 다른 값은 요청이 ElevenLabs에 도달하기 전에
400으로 거부됩니다. 각 id는 ElevenLabs 모델에 대한 Comfy의 id입니다
('eleven_sfx_v2'는 ElevenLabs가 'eleven_text_to_sound_v2'라고 부르는
모델입니다). 프록시는 전달되는 본문을 벤더 표기로 다시 작성하며, 이는
ElevenLabs 자체 enum이 요구하는 사항입니다(ElevenLabs는 'eleven_sfx_v2'를
422로 거부합니다). 따라서 호출자가 벤더 id를 보내는 일은 없습니다. 이 필드는
이 스키마의 `required` 목록에 없습니다. Comfy Router가
/v2/models/elevenlabs/\{model}의 `{model}` 경로 세그먼트에서 이 값을 채우므로
Router 호출자는 이를 생략하기 때문입니다.
</ParamField>

<ParamField body="prompt_influence" type="number">
  프롬프트 영향력이 높을수록 생성 결과가 프롬프트를 더 가깝게 따르는 대신
생성 결과의 변동성이 줄어듭니다.
0과 1 사이의 값이어야 합니다. 기본값은 0.3입니다.

  범위: `0` ~ `1`

  형식: `double`
</ParamField>

<ParamField body="text" type="string" required>
  사운드 효과로 변환될 텍스트입니다.
</ParamField>

Router가 `GET /v2/models/elevenlabs/eleven_sfx_v3/openapi.json`에서 제공하는 스키마에서 생성되었으며, 이는 요청이 공급자에 도달하기 전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.

### 출력

<ResponseField name="*/*" type="string (binary)">
  원시 오디오 바이트입니다. Content-Type과 인코딩은 요청된 output_format을 따르며 ElevenLabs에서 그대로 전달됩니다. 예시는 바이너리 본문의 자리 표시자이며 JSON이나 base64가 아닙니다.
</ResponseField>
