동일한 본문을 `POST https://api.comfy.org/v2/models/elevenlabs/eleven_v4_turbo/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`을 응답하며, 결과는 준비되면 이 프로세스 또는 다른 프로세스에서 수집합니다. [대기 중 전달](/ko/development/comfy-router/queue)에서 상태, 취소 및 수집 과정을 안내합니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "elevenlabs/eleven_v4_turbo",
            {
                "inputs": [
                    {
                        "text": "Hello from Comfy Router.",
                        "voice_id": "21m00Tcm4TlvDq8ikWAM",
                    },
                ],
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자 자체의 페이로드이며, models.run()이 반환하는 것과 동일한 값입니다.
        # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("elevenlabs/eleven_v4_turbo", {
  inputs: [
    {
      text: "Hello from Comfy Router.",
      voice_id: "21m00Tcm4TlvDq8ikWAM",
    },
  ],
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출합니다. Router는 request_id, status_url, response_url, cancel_url과 함께 201을 응답합니다.
curl https://api.comfy.org/v2/models/elevenlabs/eleven_v4_turbo/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"inputs\": [{\"text\":\"Hello from Comfy Router.\",\"voice_id\":\"21m00Tcm4TlvDq8ikWAM\"}]}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 대기합니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/elevenlabs/eleven_v4_turbo/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집합니다. 모델의 네이티브 출력과 함께 200, 아직 실행 중인 동안에는 상태 본문과 함께 202를 반환합니다.
curl https://api.comfy.org/v2/models/elevenlabs/eleven_v4_turbo/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="apply_text_normalization" type="string" default="&quot;auto&quot;">
  세 가지 모드로 텍스트 정규화를 제어합니다:
'auto' - 시스템이 텍스트 정규화 적용 여부를 자동으로 결정합니다
'on' - 텍스트 정규화가 항상 적용됩니다
'off' - 텍스트 정규화가 건너뜀됩니다

  가능한 값: `auto`, `on`, `off`
</ParamField>

<ParamField body="inputs" type="object[]" required>
  대화 입력 목록으로, 각 항목에는 음성으로 변환될 텍스트와 voice ID가 포함됩니다.
사용할 수 있는 고유 voice ID의 최대 개수는 10개입니다.
</ParamField>

<ParamField body="inputs[].text" type="string" required>
  음성으로 변환할 텍스트입니다.
</ParamField>

<ParamField body="inputs[].voice_id" type="string" required>
  생성에 사용할 음성의 ID입니다.
</ParamField>

<ParamField body="language_code" type="string">
  모델과 텍스트 정규화에 적용할 언어를 지정하는 데 사용되는 언어 코드(ISO 639-1)입니다.
모델이 제공된 언어 코드를 지원하지 않으면 오류가 반환됩니다.
</ParamField>

<ParamField body="model_id" type="string">
  사용할 모델의 식별자입니다. 이 라우트는
'eleven_v3', 'eleven_v4', 'eleven_v4_turbo'만 허용하며 그 외에는
아무것도 허용하지 않습니다. 다른 값을 사용하면 요청이 ElevenLabs에
도달하기 전에 400으로 거부됩니다.
사용 가능한 모델 집합을 확인하려면 GET /v1/models를 조회하라는
ElevenLabs의 업스트림 권장 사항은 이 라우트를 설명하지 않습니다.
이 라우트는 이 모델들만 제공합니다.
이 항목은 이 스키마의 `required` 목록에 없습니다. Comfy Router가
/v2/models/elevenlabs/\{model}의 `{model}` 경로 세그먼트에서 이 값을
채우므로, Router 호출자는 이를 생략하기 때문입니다.
</ParamField>

<ParamField body="pronunciation_dictionary_locators" type="object[]">
  텍스트에 적용할 발음 사전 로케이터(id, version_id) 목록입니다.
지정된 순서대로 적용됩니다. 요청당 최대 3개의 로케이터를 사용할 수 있습니다.
</ParamField>

<ParamField body="pronunciation_dictionary_locators[].pronunciation_dictionary_id" type="string" required>
  발음 사전의 ID
</ParamField>

<ParamField body="pronunciation_dictionary_locators[].version_id" type="string" required>
  발음 사전의 버전 ID
</ParamField>

<ParamField body="seed" type="integer">
  지정하면 시스템이 결정적으로 샘플링하기 위해 최선을 다합니다.
같은 시드와 파라미터로 반복 요청하면 동일한 결과가 반환되어야 합니다.
0에서 4294967295 사이의 정수여야 합니다.

  범위: `0` ~ `4294967295`
</ParamField>

<ParamField body="settings" type="object">
  대화 생성을 제어하는 설정
</ParamField>

<ParamField body="settings.stability" type="number" default="0.5">
  음성이 얼마나 안정적인지, 그리고 각 생성 간의 무작위성을 결정합니다.
값이 낮을수록 음성의 감정 범위가 넓어집니다.
값이 높으면 감정이 제한된 단조로운 음성이 될 수 있습니다.

  형식: `double`
</ParamField>

Router가 `GET /v2/models/elevenlabs/eleven_v4_turbo/openapi.json`에서 제공하는 스키마에서 생성되었으며, 이는 요청이 공급자에게 도달하기 전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.

### 출력

<ResponseField name="*/*" type="string (binary)">
  원시 오디오 바이트입니다. Content-Type과 인코딩은 요청된 output_format을 따르며 ElevenLabs에서 전달됩니다. 예시는 바이너리 본문을 위한 자리 표시자이며, JSON이나 base64가 아닙니다.
</ResponseField>
