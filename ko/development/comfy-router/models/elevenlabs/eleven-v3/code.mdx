Elevenlabs에서 제공하며 Comfy Router를 통해 서비스되는 `elevenlabs/eleven_v3`의 API 레퍼런스입니다.

## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python 및 TypeScript 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`)를 사용하며, cURL 스니펫은 동일한 호출을 raw HTTP로 수행합니다.

**모델 ID:** `elevenlabs/eleven_v3`

**엔드포인트:** `POST https://api.comfy.org/v2/models/elevenlabs/eleven_v3`

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment.
# The SDK automatically creates an idempotency key and reuses it for automatic retries.
with Comfy() as client:
    result = client.models.run(
        "elevenlabs/eleven_v3",
        {
            "inputs": [
                {
                    "text": "Hello from Comfy Router.",
                    "voice_id": "21m00Tcm4TlvDq8ikWAM",
                },
            ],
        },
    )

print(result)
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Reads COMFY_API_KEY from the environment.
// The SDK automatically creates an idempotency key and reuses it for automatic retries.
const { data } = await comfy.models.run("elevenlabs/eleven_v3", {
  inputs: [
    {
      text: "Hello from Comfy Router.",
      voice_id: "21m00Tcm4TlvDq8ikWAM",
    },
  ],
});

console.log(data);
```

```bash cURL
curl https://api.comfy.org/v2/models/elevenlabs/eleven_v3 \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"inputs\": [{\"text\":\"Hello from Comfy Router.\",\"voice_id\":\"21m00Tcm4TlvDq8ikWAM\"}]}"
```
</CodeGroup>

## 스키마

### 입력

<ParamField body="apply_text_normalization" type="string" default="&quot;auto&quot;">
  세 가지 모드로 텍스트 정규화를 제어합니다:
'auto' - 시스템이 텍스트 정규화 적용 여부를 자동으로 결정합니다
'on' - 텍스트 정규화가 항상 적용됩니다
'off' - 텍스트 정규화를 건너뜁니다

  가능한 값: `auto`, `on`, `off`
</ParamField>

<ParamField body="inputs" type="object[]" required>
  각각 텍스트와 음성 ID를 포함하는 대화 입력 목록으로, 음성으로 변환됩니다.
고유 음성 ID의 최대 개수는 10개입니다.
</ParamField>

<ParamField body="inputs[].text" type="string" required>
  음성으로 변환할 텍스트입니다.
</ParamField>

<ParamField body="inputs[].voice_id" type="string" required>
  생성에 사용할 음성의 ID입니다.
</ParamField>

<ParamField body="language_code" type="string">
  모델과 텍스트 정규화에 언어를 강제 적용하는 데 사용되는 언어 코드(ISO 639-1)입니다.
모델이 제공된 언어 코드를 지원하지 않으면 오류가 반환됩니다.
</ParamField>

<ParamField body="model_id" type="string">
  사용할 모델의 식별자입니다. 이 경로는
'eleven_v3'만 허용하며, 다른 값은 요청이 ElevenLabs에
도달하기 전에 400으로 거부됩니다.
사용 가능한 모델 집합을 조회하려면 GET /v1/models를 사용하라는
ElevenLabs의 업스트림 안내는 하나의 모델만 제공하는 이 경로를
설명하지 않습니다.
Comfy Router가
/v2/models/elevenlabs/\{model}의 `{model}` 경로 세그먼트에서 이 값을
채우므로 Router 호출자는 이를 생략하기 때문에, 이 스키마의 `required` 목록에
포함되어 있지 않습니다.
</ParamField>

<ParamField body="pronunciation_dictionary_locators" type="object[]">
  텍스트에 적용할 발음 사전 로케이터(id, version_id) 목록입니다.
순서대로 적용됩니다. 요청당 최대 3개의 로케이터를 사용할 수 있습니다.
</ParamField>

<ParamField body="pronunciation_dictionary_locators[].pronunciation_dictionary_id" type="string" required>
  발음 사전의 ID
</ParamField>

<ParamField body="pronunciation_dictionary_locators[].version_id" type="string" required>
  발음 사전의 버전 ID
</ParamField>

<ParamField body="seed" type="integer">
  지정하면 시스템이 결정론적으로 샘플링하기 위해 최선을 다합니다.
동일한 시드와 파라미터로 반복된 요청은 동일한 결과를 반환해야 합니다.
0에서 4294967295 사이의 정수여야 합니다.

  범위: `0`~`4294967295`
</ParamField>

<ParamField body="settings" type="object">
  대화 생성을 제어하는 설정
</ParamField>

<ParamField body="settings.stability" type="number" default="0.5">
  음성이 얼마나 안정적인지, 그리고 각 생성 간의 무작위성을 결정합니다.
값이 낮을수록 음성의 감정 범위가 넓어집니다.
값이 높을수록 감정이 제한된 단조로운 음성이 될 수 있습니다.

  형식: `double`
</ParamField>

Router가 `GET /v2/models/elevenlabs/eleven_v3/openapi.json`에서 제공하는 스키마에서 생성되었으며, 이는 요청이 공급자에 도달하기 전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.

### 출력

Router는 이 모델에 대한 출력 스키마를 게시하지 않습니다.
