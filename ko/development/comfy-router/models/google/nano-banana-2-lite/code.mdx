## 예시

### 입력

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {
          "text": "a single red maple leaf on a plain white background, studio lighting"
        }
      ]
    }
  ],
  "generationConfig": {
    "responseModalities": [
      "IMAGE"
    ],
    "imageConfig": {
      "aspectRatio": "1:1"
    }
  }
}
```

### 출력

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [
          {
            "inlineData": {
              "mimeType": "image/png",
              "data": "PGJhc2U2ND4="
            }
          }
        ]
      },
      "finishReason": "STOP"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 12,
    "candidatesTokenCount": 1290
  }
}
```

기본적으로 생성된 이미지 part는 `inlineData.data`에 base64 바이트를, `inlineData.mimeType`에 미디어 타입을 포함합니다. 바이트를 디코딩하여 파일로 저장하세요. `uploadImagesToStorage: true`인 경우, 업로드된 이미지는 대신 `fileData.fileUri`에 서명된 URL을, `fileData.mimeType`에 미디어 타입을 사용합니다. 이 이미지들은 URL이 생성된 이후 24시간 뒤에 만료되므로 그 이전에 다운로드하세요. 업로드에 실패하면 해당 이미지는 인라인으로 남으므로, 각 part에서 `inlineData` 또는 `fileData`를 확인해야 합니다. 텍스트 part도 나타날 수 있으며, 이미지가 첫 번째 part라는 보장은 없습니다.
