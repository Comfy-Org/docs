LTX에서 제공하고 Comfy Router가 서비스하는 `ltx/ltx-2-5-pro`의 API 레퍼런스입니다.

## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys?onboarding=router)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python 및 TypeScript 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`)를 사용하며, cURL 스니펫은 동일한 호출을 원시 HTTP로 수행합니다.

**모델 ID:** `ltx/ltx-2-5-pro`

**엔드포인트:** `POST https://api.comfy.org/v2/models/ltx/ltx-2-5-pro`

동일한 본문을 `POST https://api.comfy.org/v2/models/ltx/ltx-2-5-pro/requests`로 전송합니다. Router는 실행이 승인되는 즉시 `request_id`와 함께 `201`로 응답하며, 결과는 준비가 되면 이 프로세스에서든 다른 프로세스에서든 수집합니다. [큐 전송](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 살펴봅니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 발급하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "ltx/ltx-2-5-pro",
            {
                "duration": 2,
                "fps": 24,
                "generate_audio": False,
                "prompt": "A single red maple leaf resting on a plain white background.",
                "resolution": "1280x720",
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다.

        # 서버가 지정한 Retry-After만큼 기다리며 요청이 완료될 때까지 폴링합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자 자체의 페이로드이며, models.run()이 반환하는 것과 동일한 값입니다.
        # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 발급하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("ltx/ltx-2-5-pro", {
  duration: 2,
  fps: 24,
  generate_audio: false,
  prompt: "A single red maple leaf resting on a plain white background.",
  resolution: "1280x720",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다.

// 서버가 지정한 Retry-After만큼 기다리며 요청이 완료될 때까지 폴링합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/ltx/ltx-2-5-pro/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"duration\": 2, \"fps\": 24, \"generate_audio\": false, \"prompt\": \"A single red maple leaf resting on a plain white background.\", \"resolution\": \"1280x720\"}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 기다립니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/ltx/ltx-2-5-pro/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집. 모델의 네이티브 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202.
curl https://api.comfy.org/v2/models/ltx/ltx-2-5-pro/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Schema

### 입력

<ParamField body="duration" type="integer" required>
  비디오 재생 시간(초)입니다(최대값은 해상도와 프레임 레이트에 따라 달라집니다).

  가능한 값: `2`, `3`, `4`, `5`, `6`, `8`, `10`, `12`, `14`, `16`, `18`, `20`
</ParamField>

<ParamField body="fps" type="integer" default="25">
  초당 프레임 수 단위의 프레임 레이트입니다.

  가능한 값: `24`, `25`, `48`, `50`
</ParamField>

<ParamField body="generate_audio" type="boolean" default="true">
  비디오용 오디오를 생성합니다.
</ParamField>

<ParamField body="model" type="string">
  생성에 사용할 모델입니다. Comfy Router 경로 `POST /v2/models/ltx/{model}`에서는 이 필드가 경로에서 제공되므로 생략할 수 있습니다. 이 작업에서 LTX가 제공하는 표기, 즉 Comfy Router가 `ltx/<model>`로 주소 지정하는 집합은 ltx-2-5-fast와 ltx-2-5-pro입니다. 위 주석에 제시된 이유로 여기서는 enum으로 제한하지 않고 그대로 나열합니다. 각 모델이 허용하는 해상도는 아래 `resolution` 속성의 `x-comfy-model-resolutions` 매트릭스에 있습니다.
</ParamField>

<ParamField body="prompt" type="string" required>
  원하는 비디오 콘텐츠를 설명하는 텍스트 프롬프트입니다.
</ParamField>

<ParamField body="resolution" type="string" required>
  출력 비디오 해상도입니다. enum은 모든 모델에 대한 합집합이며, 지원되는 집합은 모델별로 다릅니다. 지원되는 조합: ltx-2-5-fast: 1280x720, 720x1280, 1920x1080, 1080x1920, 2560x1440, 1440x2560, 3840x2160, 2160x3840; ltx-2-5-pro: 1280x720, 720x1280, 1920x1080, 1080x1920. 그 밖의 (모델, 해상도) 조합은 지원되지 않으며, v2 경로는 이를 400으로 거부합니다. 동일한 매트릭스가 이 속성의 x-comfy-model-resolutions 확장에 기계 판독 가능한 형태로 게시되어 있습니다.

  가능한 값: `1280x720`, `720x1280`, `1920x1080`, `1080x1920`, `2560x1440`, `1440x2560`, `3840x2160`, `2160x3840`
</ParamField>

Router가 `GET /v2/models/ltx/ltx-2-5-pro/openapi.json`에서 제공하는 스키마를 기반으로 생성되었으며, 이는 요청이 공급자에게 도달하기 이전에 호출을 검증하는 데 사용하는 동일한 문서입니다.
