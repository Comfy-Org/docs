동일한 본문을 `POST https://api.comfy.org/v2/models/higgsfield/higgsfield-genjutsu-motion-transfer-v1.0/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`을 응답하며, 결과는 준비되면 이 프로세스 또는 다른 프로세스에서 수집합니다. [대기 중 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 자세히 다룹니다.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "higgsfield/higgsfield-genjutsu-motion-transfer-v1.0",
            {
                "image_urls": ["https://cdn.example.com/character.jpg"],
                "prompt": "Keep the camera move and recast the dancer as the character in the reference image",
                "resolution": "720p",
                "video_url": "https://cdn.example.com/source.mp4",
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자 자체의 페이로드로, models.run()이 반환하는 값과 동일합니다.
        # 실패하거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("higgsfield/higgsfield-genjutsu-motion-transfer-v1.0", {
  image_urls: ["https://cdn.example.com/character.jpg"],
  prompt: "Keep the camera move and recast the dancer as the character in the reference image",
  resolution: "720p",
  video_url: "https://cdn.example.com/source.mp4",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패하거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출. Router는 request_id, status_url, response_url, cancel_url과 함께 201을 응답합니다.
curl https://api.comfy.org/v2/models/higgsfield/higgsfield-genjutsu-motion-transfer-v1.0/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"image_urls\": [\"https://cdn.example.com/character.jpg\"], \"prompt\": \"Keep the camera move and recast the dancer as the character in the reference image\", \"resolution\": \"720p\", \"video_url\": \"https://cdn.example.com/source.mp4\"}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 대기합니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/higgsfield/higgsfield-genjutsu-motion-transfer-v1.0/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집. 모델의 네이티브 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202.
curl https://api.comfy.org/v2/models/higgsfield/higgsfield-genjutsu-motion-transfer-v1.0/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="image_urls" type="string[]" required>
  캐스트, 장소 및 스타일에 사용할 1~8개의 참조 이미지 URL입니다.
</ParamField>

<ParamField body="prompt" type="string">
  리캐스트를 위한 선택적 가이드입니다.
</ParamField>

<ParamField body="resolution" type="string" default="&quot;720p&quot;">
  출력 해상도: 480p, 720p 또는 1080p.
</ParamField>

<ParamField body="video_url" type="string" required>
  모션, 카메라 및 타이밍이 유지되는 소스 비디오의 URL입니다. 최소 4초이며, 더 긴 비디오는 30초로 잘립니다.
</ParamField>

Router가 `GET /v2/models/higgsfield/higgsfield-genjutsu-motion-transfer-v1.0/openapi.json`에서 제공하는 스키마에서 생성되며, 이는 요청이 공급자에 도달하기 이전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.

### 출력

<ResponseField name="cancel_url" type="string">
  처리가 시작되기 이전에 요청을 취소하는 데 사용되는 절대 URL입니다.
</ResponseField>

<ResponseField name="error" type="string">
  `status`가 `failed`일 때 설정되는 실패 세부 정보입니다.
</ResponseField>

<ResponseField name="request_id" type="string" required>
  폴링, 취소 및 지원팀에 사용되는 안정적인 식별자입니다.
</ResponseField>

<ResponseField name="status" type="string" required>
  현재 요청 상태입니다.

  가능한 값: `queued`, `in_progress`, `nsfw`, `failed`, `completed`, `canceled`
</ResponseField>

<ResponseField name="status_url" type="string">
  요청이 터미널 상태에 도달할 때까지 폴링할 절대 URL입니다.
</ResponseField>

<ResponseField name="video" type="object">
  하나의 Higgsfield 미디어 출력입니다.
</ResponseField>

<ResponseField name="video.url" type="string" required>
  생성된 미디어의 다운로드 URL입니다.
</ResponseField>
