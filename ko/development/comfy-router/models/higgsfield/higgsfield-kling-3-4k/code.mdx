동일한 본문을 `POST https://api.comfy.org/v2/models/higgsfield/higgsfield-kling-3-4k/requests`로 전송합니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`로 응답하며, 결과는 준비되면 이 프로세스 또는 다른 프로세스에서 수집합니다. [대기열 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 자세히 설명합니다.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 발급하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "higgsfield/higgsfield-kling-3-4k",
            {
                "aspect_ratio": "16:9",
                "cfg_scale": 0.5,
                "duration": 5,
                "prompt": "A cinematic glass pavilion in a misty pine forest at sunrise",
                "sound": "on",
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 알려주는 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자의 자체 페이로드이며, models.run()이 반환하는 것과 같은 값입니다.
        # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 발급하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("higgsfield/higgsfield-kling-3-4k", {
  aspect_ratio: "16:9",
  cfg_scale: 0.5,
  duration: 5,
  prompt: "A cinematic glass pavilion in a misty pine forest at sunrise",
  sound: "on",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 알려주는 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 같은 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/higgsfield/higgsfield-kling-3-4k/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"aspect_ratio\": \"16:9\", \"cfg_scale\": 0.5, \"duration\": 5, \"prompt\": \"A cinematic glass pavilion in a misty pine forest at sunrise\", \"sound\": \"on\"}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 알려주는 Retry-After 초만큼 대기합니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/higgsfield/higgsfield-kling-3-4k/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집. 모델의 네이티브 출력과 함께 200, 아직 실행 중이면 상태 본문과 함께 202.
curl https://api.comfy.org/v2/models/higgsfield/higgsfield-kling-3-4k/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="aspect_ratio" type="string" default="&quot;16:9&quot;">
  출력 화면 비율입니다.

  가능한 값: `16:9`, `9:16`, `1:1`
</ParamField>

<ParamField body="cfg_scale" type="number" default="0.5">
  생성이 프롬프트를 얼마나 강하게 따르는지 나타냅니다. Higgsfield는 0-1을 0.01 단위로 문서화하지만, 여기서는 0-1 범위만 선언합니다. `multipleOf: 0.01`은 이진 부동소수점으로 평가되어 0.3 같은 평범한 값도 거부하게 되므로, 더 세밀한 값은 거부되지 않고 그대로 전달됩니다. 이는 `prompt`가 선언되지 않은 길이 상한을 명시한 방식과 같습니다.

  범위: `0`부터 `1`까지
</ParamField>

<ParamField body="duration" type="integer" default="5">
  출력 재생 시간(초)입니다. 지원 범위: 3-15.

  범위: `3`부터 `15`까지
</ParamField>

<ParamField body="elements" type="string[]">
  재사용 가능한 Kling 요소 id이며, 생성 전반에 걸쳐 피사체 일관성을 유지하기 위한 것입니다.
</ParamField>

<ParamField body="multi_prompt" type="object[]">
  순서가 지정된 샷 정의이며, `multi_shots`가 참일 때 사용됩니다. 샷 1-6개이며, 샷별 재생 시간은 태스크 자체의 총 재생 시간에 의해 제한되지만 이는 여기서 표현할 수 없습니다.
</ParamField>

<ParamField body="multi_prompt[].duration" type="integer">
  이 샷의 재생 시간(초)이며 1-15입니다. 샷 전체의 합은 태스크의 총 재생 시간을 초과할 수 없지만, JSON Schema로는 표현할 수 없습니다. Higgsfield가 이를 강제합니다.

  범위: `1`부터 `15`까지
</ParamField>

<ParamField body="multi_prompt[].prompt" type="string">
  이 샷에 대한 프롬프트입니다. Higgsfield는 512자 상한을 문서화합니다.
</ParamField>

<ParamField body="multi_shots" type="boolean" default="false">
  멀티 샷 시퀀스를 활성화합니다. 참이면 `multi_prompt`가 샷별 정의를 담습니다.
</ParamField>

<ParamField body="prompt" type="string">
  원하는 출력을 설명하는 프롬프트입니다. Higgsfield는 Kling이 최대 처음 2,500자까지만 사용하고 그 이후는 잘라낸다고 문서화하므로, maxLength를 선언하지 않습니다. 더 긴 본문은 거부되지 않고 허용됩니다.
</ParamField>

<ParamField body="sound" type="string" default="&quot;on&quot;">
  생성된 사운드를 활성화하거나 비활성화합니다.

  가능한 값: `on`, `off`
</ParamField>

Router가 `GET /v2/models/higgsfield/higgsfield-kling-3-4k/openapi.json`에서 제공하는 스키마에서 생성되었으며, 이는 요청이 공급자에게 도달하기 전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.

</ResponseField>
