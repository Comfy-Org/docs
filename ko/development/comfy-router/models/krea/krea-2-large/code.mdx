Krea에서 Comfy Router가 제공하는 `krea/krea-2-large`의 API 레퍼런스입니다.

## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys)에서 키를 생성하고 `COMFY_API_KEY`로 내보내기하세요. Python 및 TypeScript 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`)를 사용하며, cURL 스니펫은 동일한 호출을 순수 HTTP로 수행한 것입니다.

**모델 ID:** `krea/krea-2-large`

**엔드포인트:** `POST https://api.comfy.org/v2/models/krea/krea-2-large`

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment.
# The SDK automatically creates an idempotency key and reuses it for automatic retries.
with Comfy() as client:
    result = client.models.run(
        "krea/krea-2-large",
        {
            "aspect_ratio": "1:1",
            "prompt": "a red circle",
            "resolution": "1K",
        },
    )

print(result)
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

console.log(data);
```

```bash cURL
curl https://api.comfy.org/v2/models/krea/krea-2-large \
  -H "X-API-Key: $COMFY_API_KEY" \

  -H "Content-Type: application/json" \

```

Router가 `GET /v2/models/krea/krea-2-large/openapi.json`에서 제공하는 스키마를 바탕으로 생성되었으며, 이는 요청이 공급자에게 도달하기 이전에 호출을 검증할 때 사용하는 것과 동일한 문서입니다.

### 출력

<ResponseField name="completed_at" type="string (date-time)" required>
  형식: `date-time`
</ResponseField>

<ResponseField name="created_at" type="string (date-time)" required>
  형식: `date-time`
</ResponseField>

<ResponseField name="job_id" type="string (uuid)" required>
  형식: `uuid`
</ResponseField>

<ResponseField name="result" type="object" required>
  완료된 생성 결과. `KreaJob`과 달리 여기서는 null일 수 없습니다. `result`에 `urls`가 없는 터미널 작업은 Comfy Router 오류로 응답되므로, `200`에는 항상 이 필드가 포함됩니다.
</ResponseField>

<ResponseField name="result.style_id" type="string">
  생성이 아니라 loraTraining 작업에 의해 설정됩니다. 이 모델들에 대한 `200` 응답에는 `urls`가 포함됩니다.
</ResponseField>

<ResponseField name="result.urls" type="string (uri)[]" required>
  다운로드 가능한 링크 형태의 생성된 이미지. 최소 한 개이며, `urls`가 비어 있는 `completed` 작업은 `success_without_output`이 되어 이 문서에 도달하지 않기 때문입니다.
</ResponseField>

<ResponseField name="status" type="string" required>
  이 문서에서는 항상 `completed`입니다. 이는 `classifyKrea`가 `succeeded`로 응답하는 유일한 상태이며, Krea의 용어는 대소문자 폴딩 없이 대조됩니다.

  가능한 값: `completed`
</ResponseField>
