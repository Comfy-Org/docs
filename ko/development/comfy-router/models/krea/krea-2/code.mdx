`krea/krea-2`에 대한 API 레퍼런스이며, Krea에서 Comfy Router를 통해 제공됩니다.

## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python 및 TypeScript 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`)를 사용하며, cURL 스니펫은 동일한 호출을 원시 HTTP로 수행합니다.

**모델 ID:** `krea/krea-2`

**엔드포인트:** `POST https://api.comfy.org/v2/models/krea/krea-2`

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment.
# The SDK automatically creates an idempotency key and reuses it for automatic retries.
with Comfy() as client:
    result = client.models.run(
        "krea/krea-2",
        {
            "aspect_ratio": "1:1",
            "prompt": "a red circle",
            "resolution": "1K",
        },
    )

print(result)
```

### 출력

<ResponseField name="completed_at" type="string (date-time)" required>
  형식: `date-time`
</ResponseField>

<ResponseField name="created_at" type="string (date-time)" required>
  형식: `date-time`
</ResponseField>

<ResponseField name="job_id" type="string (uuid)" required>
  형식: `uuid`
</ResponseField>

<ResponseField name="result" type="object" required>
  완료된 생성 결과입니다. `KreaJob`과 달리 여기서는 null이 될 수 없습니다. `result`에 `urls`가 없는 터미널 작업은 Comfy Router 오류로 응답되므로, `200`에는 항상 이 필드가 포함됩니다.
</ResponseField>

<ResponseField name="result.style_id" type="string">
  생성이 아니라 loraTraining 작업에 의해 설정됩니다. 이 모델들의 `200` 응답에는 `urls`가 포함됩니다.
</ResponseField>

<ResponseField name="result.urls" type="string (uri)[]" required>
  생성된 이미지로, 다운로드 가능한 링크입니다. 최소 한 개가 보장되는데, `urls`가 비어 있는 `completed` 작업은 `success_without_output`으로 처리되어 이 문서에 도달하지 않기 때문입니다.
</ResponseField>

<ResponseField name="status" type="string" required>
  이 문서에서는 항상 `completed`입니다. `classifyKrea`가 `succeeded`로 응답하는 유일한 상태이며, Krea의 어휘는 대소문자 접기 없이 그대로 매칭됩니다.

  가능한 값: `completed`
</ResponseField>
