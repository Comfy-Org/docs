동일한 본문을 `POST https://api.comfy.org/v2/models/pruna/p-video-2-pro-avatar/requests`로 전송합니다. Router는 실행이 승인되는 즉시 `request_id`와 함께 `201`로 응답하며, 결과는 준비되면 이 프로세스에서든 다른 프로세스에서든 수집할 수 있습니다. [대기 중 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 방법을 단계별로 안내합니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "pruna/p-video-2-pro-avatar",
            {
                "input": {
                    "audio": "https://example.com/speech.mp3",
                    "image": "https://example.com/portrait.png",
                    "resolution": "768p",
                },
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자 자체의 페이로드이며, models.run()이 반환하는 값과 동일합니다.
        # 실패했거나 취소된 요청은 여기서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("pruna/p-video-2-pro-avatar", {
  input: {
    audio: "https://example.com/speech.mp3",
    image: "https://example.com/portrait.png",
    resolution: "768p",
  },
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출합니다. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/pruna/p-video-2-pro-avatar/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"input\": {\"audio\":\"https://example.com/speech.mp3\",\"image\":\"https://example.com/portrait.png\",\"resolution\":\"768p\"}}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 대기합니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/pruna/p-video-2-pro-avatar/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집합니다. 200은 모델의 네이티브 출력, 202는 아직 실행 중일 때 상태 본문을 반환합니다.
curl https://api.comfy.org/v2/models/pruna/p-video-2-pro-avatar/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="input" type="object" required>
  P-Video-2-Pro Avatar 파라미터입니다. 작업은 반환된 파일을 기준으로 측정하여 정수 초 단위로 내림한 반환 비디오의 초당 요금으로 청구되며, `resolution`에 해당하는 요율이 적용됩니다. 안전 필터는 항상 켜져 있으며, 요청에 담긴 `enable_safety_filter` 값은 무시됩니다.
</ParamField>

<ParamField body="input.audio" type="string">
  음성 오디오 URI로, 1초에서 3분까지이며 최대 64 MiB입니다. 출력 길이를 결정합니다. 설정하면 `voice_script`는 무시됩니다.
</ParamField>

<ParamField body="input.image" type="string" required>
  첫 프레임으로 사용되는 인물 사진 URI입니다. jpg, png 또는 webp, 최대 20 MiB입니다. 화면 비율을 결정합니다.
</ParamField>

<ParamField body="input.prompt" type="string" default="&quot;The person is talking.&quot;">
  비디오에 담길 내용입니다.
</ParamField>

<ParamField body="input.prompt_upsampling" type="boolean" default="true">
  인물 사진에서 장면의 움직임을 가져와 `prompt`에 추가합니다.
</ParamField>

<ParamField body="input.resolution" type="string" default="&quot;768p&quot;">
  출력 해상도: 480p, 768p, 1080p, 2k 또는 4k입니다. 1080p, 2k, 4k는 768p 비디오를 업스케일합니다.
</ParamField>

<ParamField body="input.seed" type="integer">
  재현 가능한 생성을 위한 시드입니다.
</ParamField>

<ParamField body="input.voice" type="string">
  `voice_script`에 사용할 텍스트 기반 음성 생성 음성으로, 예를 들어 `Zephyr (Female)`입니다.
</ParamField>

<ParamField body="input.voice_language" type="string">
  `voice_script`에 사용할 텍스트 기반 음성 생성 언어로, 예를 들어 `English (US)`입니다.
</ParamField>

<ParamField body="input.voice_prompt" type="string">
  `voice_script`의 전달 지침(어조, 속도, 억양)입니다. 실제로 읽히지는 않습니다.
</ParamField>

<ParamField body="input.voice_script" type="string">
  `audio`가 설정되지 않았을 때 텍스트 기반 음성 생성으로 읽을 문장입니다.
</ParamField>

Router가 `GET /v2/models/pruna/p-video-2-pro-avatar/openapi.json`에서 제공하는 스키마에서 생성되었으며, 이는 요청이 공급자에 도달하기 이전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.
