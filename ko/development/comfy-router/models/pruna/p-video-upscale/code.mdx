## 스키마

### 입력

<ParamField body="input" type="object" required>
  P-Video-Upscale 파라미터입니다. 작업은 반환된 비디오의 초당 요금으로 청구되며, 반환된 파일을 기준으로 측정하여 1초 단위로 올림합니다. 요금은 `target`과 출력 프레임 레이트가 30 fps를 초과하는지 여부에 따라 결정됩니다. `fps`를 생략하면 출력은 `video`의 프레임 레이트를 유지하므로, 해당 레이트가 등급을 결정합니다. `turbo` 작업은 프레임 레이트와 관계없이 해당 `target`의 turbo 요금으로 청구됩니다. 안전 필터는 항상 켜져 있으며, 요청의 `enable_safety_filter` 값은 무시됩니다.
</ParamField>

<ParamField body="input.fps" type="integer">
  출력 프레임 레이트(16-60)입니다. 소스 레이트보다 높은 레이트는 보간됩니다. 생략하면 출력은 소스 레이트를 유지합니다.

  범위: `16` ~ `60`
</ParamField>

<ParamField body="input.target" type="string" default="&quot;1080p&quot;">
  출력 해상도 프리셋: 720p, 1080p, 2k, 4k입니다. 프리셋은 픽셀 영역을 설정하며, 16:9가 아닌 비디오는 가로세로 비율을 유지합니다. 이미 대상보다 큰 비디오는 다운스케일되지 않습니다.

  가능한 값: `720p`, `1080p`, `2k`, `4k`
</ParamField>

<ParamField body="input.turbo" type="boolean" default="false">
  품질이 약간 낮은 더 빠른 작업으로, 프레임 레이트와 관계없이 turbo 요금(표준 요금의 약 3분의 1)으로 청구됩니다.
</ParamField>

<ParamField body="input.video" type="string" required>
  입력 비디오 URI이며, 최대 512 MiB입니다. `fps`를 생략하는 경우 공개적으로 읽을 수 있는 http(s) URL이어야 합니다. 작업을 전송하기 전에 해당 비디오의 프레임 레이트를 읽기 때문입니다.
</ParamField>
