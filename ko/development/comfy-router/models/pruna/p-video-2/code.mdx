Pruna가 Comfy Router를 통해 제공하는 `pruna/p-video-2`의 API 레퍼런스입니다.

## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python 및 TypeScript 스니펫은 Comfy SDK를 사용하며(`pip install comfy-sdk`, `npm install @comfyorg/sdk`), cURL 스니펫은 원시 HTTP를 통한 동일한 호출입니다.

**모델 ID:** `pruna/p-video-2`

**엔드포인트:** `POST https://api.comfy.org/v2/models/pruna/p-video-2`

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment.
# The SDK automatically creates an idempotency key and reuses it for automatic retries.
with Comfy() as client:
    result = client.models.run(
        "pruna/p-video-2",
        {
            "input": {
                "aspect_ratio": "16:9",
                "draft": False,
                "duration": 2,
                "fps": 24,
                "prompt": "A single red maple leaf resting on a plain white background.",
                "resolution": "720p",
            },
        },
    )

print(result)
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

console.log(data);
```

## 스키마

### 입력

<ParamField body="input" type="object" required>
  P-Video-2 생성 파라미터입니다. 생성 비용은 완료된 비디오의 초 단위로 청구되며, 반환된 파일을 기준으로 측정되고, 요율은 `resolution`과 `draft`에 따라 결정됩니다. 안전 필터는 항상 켜져 있으며, 요청에 포함된 `disable_safety_filter` 값은 무시됩니다.
</ParamField>

<ParamField body="input.aspect_ratio" type="string" default="&quot;16:9&quot;">
  화면 비율: 16:9, 9:16, 4:3, 3:4, 3:2, 2:3 또는 1:1입니다. `image`가 설정된 경우 무시됩니다.
</ParamField>

<ParamField body="input.audio" type="string">
  생성을 조건화할 입력 오디오 URI입니다(flac, mp3 또는 wav). 출력 길이는 오디오를 따릅니다.
</ParamField>

<ParamField body="input.draft" type="boolean" default="false">
  더 빠르지만 품질이 낮은 미리보기이며, draft 요율로 청구됩니다.
</ParamField>

<ParamField body="input.duration" type="integer">
  생성된 비디오의 재생 시간(초)입니다(1-20). 생략하면 모델이 프롬프트를 바탕으로 최대 20초까지 길이를 선택합니다. `audio`가 설정된 경우 무시됩니다.

  범위: `1` ~ `20`
</ParamField>

<ParamField body="input.fps" type="integer" default="24">
  프레임 레이트: 24 또는 48입니다.
</ParamField>

<ParamField body="input.image" type="string">
  이미지 기반 비디오 생성용 입력 이미지 URI입니다(jpg, jpeg, png 또는 webp).
</ParamField>

<ParamField body="input.last_frame_image" type="string">
  마지막 프레임의 참조 이미지 URI입니다.
</ParamField>

<ParamField body="input.prompt" type="string" required>
  비디오 생성을 위한 텍스트 프롬프트입니다.
</ParamField>

<ParamField body="input.prompt_upsampling" type="boolean" default="true">
  생성 이전에 프롬프트를 재작성합니다. `seed`로 결과를 재현해야 할 때는 비활성화하세요.
</ParamField>

<ParamField body="input.resolution" type="string" default="&quot;720p&quot;">
  출력 해상도: 720p 또는 1080p입니다.
</ParamField>

<ParamField body="input.save_audio" type="boolean" default="true">
  비디오에 오디오를 포함하여 저장합니다.
</ParamField>

<ParamField body="input.seed" type="integer">
  재현 가능한 생성을 위한 무작위 시드입니다. 생략하면 무작위로 설정됩니다.
</ParamField>

Router가 `GET /v2/models/pruna/p-video-2/openapi.json`에서 제공하는 스키마에서 생성되며, 이는 요청이 공급자에 도달하기 이전에 호출을 검증하는 데 사용하는 것과 동일한 문서입니다.
