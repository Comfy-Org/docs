동일한 본문을 `POST https://api.comfy.org/v2/models/tencent/hunyuan-3d-texture-edit/requests` 로 보냅니다. Router는 실행이 접수되는 즉시 `201` 과 `request_id` 를 응답하며, 결과는 준비가 되는 대로 이 프로세스나 다른 프로세스에서 수집할 수 있습니다. 상태, 취소, 수집 방법은 [큐 전송](/ko/development/comfy-router/queue) 를 참고하세요.

```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment.
# Each submit() call mints its own Idempotency-Key and reuses it for automatic retries.
with Comfy() as client:
    handle = client.models.submit(
        "tencent/hunyuan-3d-texture-edit",
        {
            "File3D": {
                "Type": "FBX",
                "Url": "https://vcg-test-1258344699.cos.ap-guangzhou.myqcloud.com/test/3d/test.fbx",
            },
            "Prompt": "a kitten",
        },
    )
    print("request_id:", handle.request_id)  # with the model ID, all another process needs

    # Poll until the request completes, waiting the Retry-After the server names.
    for update in handle.iter_events():
        print(update.status, update.queue_position)

    # The provider's own payload, the same value models.run() returns.
    # A request that failed or was cancelled raises the typed Router error here.
    result = handle.get()

print(result)
```

## 스키마

### 입력

<ParamField body="EnablePBR" type="boolean">
  PBR 텍스처 파라미터를 활성화할지 여부이며, Prompt를 사용할 때만 지원됩니다.
</ParamField>

<ParamField body="File3D" type="object" required>
  텍스처 편집을 위한 3D 파일 입력
</ParamField>

<ParamField body="File3D.Type" type="string" required>
  3D 파일 형식 유형

  가능한 값: `FBX`
</ParamField>

<ParamField body="File3D.Url" type="string (uri)" required>
  텍스처를 편집할 3D 파일의 URL

  형식: `uri`
</ParamField>

<ParamField body="Image" type="object">
  참조 이미지 - Base64 데이터 또는 이미지 URL
</ParamField>

<ParamField body="Image.Base64" type="string">
  Base64로 인코딩된 이미지입니다. 해상도는 한 변당 128-4096이며, 변환된 Base64는 10MB 미만이어야 합니다. 형식은 jpg, jpeg, png입니다.
</ParamField>

<ParamField body="Image.Url" type="string (uri)">
  이미지 URL입니다. Base64와 Url을 모두 제공하면 Url이 우선합니다.

  형식: `uri`
</ParamField>

<ParamField body="Prompt" type="string">
  텍스처 편집을 설명합니다. Image 또는 Prompt 중 하나가 필수이며, 둘은 함께 사용할 수 없습니다.
</ParamField>

`GET /v2/models/tencent/hunyuan-3d-texture-edit/openapi.json`에서 Router가 제공하는 스키마에서 생성되며, 요청이 공급자에 도달하기 전에 호출을 검증하는 데 사용하는 문서와 동일합니다.

### 출력

<ResponseField name="Response" type="object" required>
   
</ResponseField>

<ResponseField name="Response.ErrorCode" type="string">

</ResponseField>

<ResponseField name="Response.ErrorMessage" type="string">
  Tencent의 오류 메시지로, 오류가 없을 때는 빈 문자열로 문서화되어 있습니다. Router는 `Status`가 존재하면 이 값을 읽지 않습니다.
</ResponseField>

<ResponseField name="Response.RequestId" type="string">
  Tencent 자체 요청 식별자로, Tencent와 함께 문제를 해결할 때 사용합니다. 작업 ID도, 자산도 아닙니다.

</ResponseField>

<ResponseField name="Response.ResultFile3Ds[].Type" type="string">

  가능한 값: `GLB`, `OBJ`

<ResponseField name="Response.ResultFile3Ds[].Url" type="string (uri)">
  파일 URL (24시간 동안 유효)

  형식: `uri`
</ResponseField>

<ResponseField name="Response.Status" type="string" required>
