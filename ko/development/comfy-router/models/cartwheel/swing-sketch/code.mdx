동일한 본문을 `POST https://api.comfy.org/v2/models/cartwheel/swing-sketch/requests`로 전송합니다. Router는 실행이 승인되는 즉시 `request_id`와 함께 `201`로 응답하며, 결과는 준비가 되면 이 프로세스 또는 다른 프로세스에서 수집합니다. [대기 중 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 안내합니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "cartwheel/swing-sketch",
            {
                "exportSettings": {
                    "characterID": "char-upload-MHR",
                    "exportType": "glb",
                    "forward": "-Z",
                    "frameRate": 30,
                    "frameStepSize": 1,
                    "up": "Y",
                },
                "prompts": ["a person waves with the right hand"],
                "swingSketchProperties": {
                    "duration": 4,
                },
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자의 자체 페이로드이며, models.run()이 반환하는 것과 동일한 값입니다.
        # 실패했거나 취소된 요청은 여기에서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("cartwheel/swing-sketch", {
  exportSettings: {
    characterID: "char-upload-MHR",
    exportType: "glb",
    forward: "-Z",
    frameRate: 30,
    frameStepSize: 1,
    up: "Y",
  },
  prompts: ["a person waves with the right hand"],
  swingSketchProperties: {
    duration: 4,
  },
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 동일한 결과입니다. 실패했거나 취소된 요청은 여기에서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/cartwheel/swing-sketch/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"exportSettings\": {\"characterID\":\"char-upload-MHR\",\"exportType\":\"glb\",\"forward\":\"-Z\",\"frameRate\":30,\"frameStepSize\":1,\"up\":\"Y\"}, \"prompts\": [\"a person waves with the right hand\"], \"swingSketchProperties\": {\"duration\":4}}"

# 2. status가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 대기합니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/cartwheel/swing-sketch/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집. 실행 중에는 상태 본문과 함께 202, 완료되면 모델의 기본 출력과 함께 200입니다.
curl https://api.comfy.org/v2/models/cartwheel/swing-sketch/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```
