## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python 및 TypeScript 스니펫은 Comfy SDK(`pip install comfy-sdk`, `npm install @comfyorg/sdk`)를 사용하며, cURL 스니펫은 동일한 호출을 raw HTTP로 수행합니다.

**모델 ID:** `freepik/ai-image-upscaler-precision-v2`

**엔드포인트:** `POST https://api.comfy.org/v2/models/freepik/ai-image-upscaler-precision-v2`

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment.
# The SDK automatically creates an idempotency key and reuses it for automatic retries.
with Comfy() as client:
    result = client.models.run(
        "freepik/ai-image-upscaler-precision-v2",
        {
            "image": "https://img.magnific.com/free-photo/light-through-mountains_395237-33.jpg?semt=ais_hybrid&w=740&q=80",
            "scale_factor": 8,
        },
    )

print(result)
```

## 스키마

### 입력

<ParamField body="flavor" type="string">
  이미지 처리 flavor:
- sublime: 예술적이고 일러스트레이션 느낌의 이미지에 최적화
- photo: 사진 이미지에 최적화
- photo_denoiser: 노이즈 감소가 필요한 사진에 특화

  가능한 값: `sublime`, `photo`, `photo_denoiser`
</ParamField>

<ParamField body="image" type="string" required>
  업스케일할 소스 이미지. 다음 중 하나를 사용할 수 있습니다:
- 이미지를 가리키는 공개적으로 접근 가능한 HTTPS URL
- base64로 인코딩된 이미지 문자열
</ParamField>

<ParamField body="scale_factor" type="integer">
  이미지 스케일링 계수. 입력 대비 출력이 얼마나 커질지 결정합니다.

  범위: `2` ~ `16`
</ParamField>

<ParamField body="sharpen" type="integer" default="7">
  이미지 선명도 강도 제어. 값이 높을수록 윤곽이 더 뚜렷하고 선명해집니다.

  범위: `0` ~ `100`
</ParamField>

<ParamField body="smart_grain" type="integer" default="7">
  지능형 그레인/텍스처 강화. 값이 높을수록 더 미세한 텍스처가 추가됩니다.

  범위: `0` ~ `100`
</ParamField>

<ParamField body="ultra_detail" type="integer" default="30">
  초고세부 디테일 강화 수준. 값이 높을수록 더 정교한 세부 정보가 생성됩니다.

  범위: `0` ~ `100`
</ParamField>

<ParamField body="webhook_url" type="string (uri)">
  업스케일링 작업이 완료될 때 비동기 알림을 받을 선택적 콜백 URL입니다.

  형식: `uri`
</ParamField>
