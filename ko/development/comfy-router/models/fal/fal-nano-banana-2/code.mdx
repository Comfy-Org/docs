fal에서 Comfy Router가 제공하는 `fal/fal-nano-banana-2`에 대한 API 레퍼런스입니다.

## 요청 설정

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python의 경우 `pip install comfy-sdk`를 실행하세요. TypeScript의 경우 `npm install @comfyorg/sdk`를 실행하세요. cURL은 원시 HTTP를 사용합니다.

**모델 ID:** `fal/fal-nano-banana-2`

**엔드포인트:** `POST https://api.comfy.org/v2/models/fal/fal-nano-banana-2`

<Note>
Router는 이 모델에 대해 작성된 입력 스키마를 공개하지 않았으므로, 스니펫을 생성할 요청 예시가 없습니다. Router는 본문을 변경 없이 fal로 전달합니다. fal 자체 API 문서를 참고해 본문을 작성한 뒤 [Router 빠른 시작](/ko/development/comfy-router/quickstart)을 사용해 전송하세요.
</Note>
