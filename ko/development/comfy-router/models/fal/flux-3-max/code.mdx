`fal/flux-3-max`에 대한 API 레퍼런스이며, Comfy Router가 fal에서 제공합니다.

**입력:** 텍스트, 이미지 · **출력:** 비디오 + 오디오

## 빠른 시작

[Comfy 워크스페이스](https://platform.comfy.org/profile/api-keys?onboarding=router)에서 키를 생성하고 `COMFY_API_KEY`로 내보내세요. Python 및 TypeScript 스니펫은 Comfy SDK를 사용하며(`pip install comfy-sdk`, `npm install @comfyorg/sdk`), cURL 스니펫은 동일한 호출을 순수 HTTP로 보냅니다.

**모델 ID:** `fal/flux-3-max`

**엔드포인트:** `POST https://api.comfy.org/v2/models/fal/flux-3-max`

동일한 본문을 `POST https://api.comfy.org/v2/models/fal/flux-3-max/requests`로 보냅니다. Router는 실행이 접수되는 즉시 `request_id`와 함께 `201`로 응답하며, 결과는 준비가 되면 이 프로세스에서든 다른 프로세스에서든 수집할 수 있습니다. [대기열 전달](/ko/development/comfy-router/queue)에서 상태, 취소, 수집 과정을 단계별로 설명합니다.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# 환경 변수에서 COMFY_API_KEY를 읽습니다.
# 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "fal/flux-3-max",
            {
                "duration": 5,
                "prompt": "A red panda walks along a mossy log in a sunlit forest. Ambient birdsong.",
                "resolution": "720p",
            },
        )
        print("request_id:", handle.request_id)  # 모델 ID와 함께라면, 다른 프로세스에 필요한 전부입니다

        # 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # 공급자 자체의 페이로드이며, models.run()이 반환하는 것과 같은 값입니다.
        # 실패했거나 취소된 요청은 여기서 타입이 지정된 Router 오류를 발생시킵니다.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// 환경 변수에서 COMFY_API_KEY를 읽습니다.
// 각 submit() 호출은 자체 Idempotency-Key를 생성하고 자동 재시도에 재사용합니다.
const handle = await comfy.models.submit("fal/flux-3-max", {
  duration: 5,
  prompt: "A red panda walks along a mossy log in a sunlit forest. Ambient birdsong.",
  resolution: "720p",
});
console.log("requestId:", handle.requestId); // 모델 ID와 함께라면, 다른 프로세스에 필요한 전부입니다

// 요청이 완료될 때까지 폴링하며, 서버가 지정한 Retry-After만큼 대기합니다.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// models.run()이 반환하는 것과 같은 결과입니다. 실패했거나 취소된 요청은 여기서 거부됩니다.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. 제출. Router는 request_id, status_url, response_url, cancel_url과 함께 201로 응답합니다.
curl https://api.comfy.org/v2/models/fal/flux-3-max/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"duration\": 5, \"prompt\": \"A red panda walks along a mossy log in a sunlit forest. Ambient birdsong.\", \"resolution\": \"720p\"}"

# 2. 상태가 COMPLETED가 될 때까지 폴링하며, 각 응답이 지정한 Retry-After 초만큼 대기합니다.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/fal/flux-3-max/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. 수집. 200은 모델의 원본 출력과 함께, 202는 아직 실행 중일 때 상태 본문과 함께 반환됩니다.
curl https://api.comfy.org/v2/models/fal/flux-3-max/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## 스키마

### 입력

<ParamField body="aspect_ratio" type="string" default="&quot;auto&quot;">
  생성되는 비디오의 화면 비율입니다. auto는 텍스트 프롬프트인 경우 16:9이고, 그 외의 경우 첫 번째 이미지를 따릅니다.

  가능한 값: `auto`, `21:9`, `2:1`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  생성되는 비디오의 재생 시간(초)이며 5에서 20 사이입니다. fal은 이 값의 초 단위로 과금합니다.

  범위: `5` ~ `20`
</ParamField>

<ParamField body="generate_audio" type="boolean" default="true">
  동기화된 오디오를 생성합니다. 가격은 동일합니다.
</ParamField>

<ParamField body="prompt" type="string" required>
  비디오와 그 사운드를 설명하는 텍스트 프롬프트입니다.
</ParamField>

<ParamField body="reasoning_level" type="string" default="&quot;high&quot;">
  생성 이전에 모델이 프롬프트를 얼마나 추론하고 확장하는지를 나타냅니다. high는 더 느립니다. 가격은 동일합니다.

  가능한 값: `low`, `high`
</ParamField>

<ParamField body="resolution" type="string" default="&quot;720p&quot;">
  생성되는 비디오의 해상도입니다. 1080p는 720p보다 초당 비용이 더 높습니다.

  가능한 값: `720p`, `1080p`
</ParamField>

<ParamField body="seed" type="integer">
  무작위 시드입니다. 생략하면 무작위 시드가 선택됩니다.
</ParamField>

`GET /v2/models/fal/flux-3-max/openapi.json`에서 Router가 제공하는 스키마로 생성되었으며, 요청이 공급자에게 도달하기 이전에 호출을 검증하는 데에도 동일한 문서를 사용합니다.
