HappyHorse 1.0 R2V API 레퍼런스입니다. HappyHorse 1.0 레퍼런스 기반 비디오 생성은 하나 이상의 레퍼런스 이미지에 담긴 대상을 새로운 장면에서도 일관되게 유지하며, 프롬프트에서 character1, character2 등으로 지정해 참조합니다.
