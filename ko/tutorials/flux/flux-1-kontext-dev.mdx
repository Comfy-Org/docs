## FLUX.1 Kontext Dev 소개

FLUX.1 Kontext는 Black Forest Labs의 획기적인 멀티모달 이미지 편집 모델로, 텍스트와 이미지 입력을 동시에 지원하며 이미지 컨텍스트를 지능적으로 이해하고 정밀한 편집을 수행합니다. 개발 버전은 120억 개의 파라미터를 가진 오픈소스 diffusion transformer 모델로, 뛰어난 컨텍스트 이해와 캐릭터 일관성 유지 기능을 갖추고 있어 여러 번의 반복 편집 후에도 캐릭터 특징이나 구도 레이아웃과 같은 핵심 요소가 안정적으로 유지됩니다.

FLUX.1 Kontext 제품군과 동일한 핵심 기능을 공유합니다:
- 캐릭터 일관성: 참조 캐릭터나 이미지 속 객체와 같이 여러 장면과 환경에서 이미지의 고유한 요소를 보존합니다.
- 편집: 다른 부분에 영향을 주지 않고 이미지의 특정 요소를 대상으로 수정합니다.
- 스타일 참조: 텍스트 프롬프트에 따라 참조 이미지의 고유한 스타일을 유지하면서 새로운 장면을 생성합니다.
- 인터랙티브 속도: 이미지 생성 및 편집의 지연 시간이 최소화됩니다.

이전에 출시된 API 버전이 최고의 충실도와 속도를 제공하는 반면, FLUX.1 Kontext [Dev]는 완전히 로컬 머신에서 실행되어 실험을 원하는 개발자, 연구자, 고급 사용자에게 비교할 수 없는 유연성을 제공합니다.

### 버전 정보

- **[FLUX.1 Kontext [pro]** : 상용 버전, 빠른 반복 편집에 중점
- **FLUX.1 Kontext [max]** : 더 강력한 프롬프트 준수성을 갖춘 실험 버전
- **FLUX.1 Kontext [dev]** : 오픈소스 버전 (이 튜토리얼에서 사용), 12B 파라미터, 주로 연구용

현재 ComfyUI에서는 이 모든 버전을 사용할 수 있으며, [Pro 및 Max 버전](/ko/tutorials/partner-nodes/black-forest-labs/flux-1-kontext)은 파트너 노드를 통해 호출할 수 있고, Dev 오픈소스 버전은 이 가이드의 지침을 참조하세요.

## 모델 다운로드

이 가이드의 워크플로우를 성공적으로 실행하려면 먼저 다음 모델 파일을 다운로드해야 합니다. 해당 워크플로우에서 직접 모델 다운로드 링크를 얻을 수도 있으며, 워크플로우에는 이미 모델 파일 다운로드 정보가 포함되어 있습니다.

**Diffusion Model**

- [flux1-dev-kontext_fp8_scaled.safetensors](https://huggingface.co/Comfy-Org/flux1-kontext-dev_ComfyUI/blob/main/split_files/diffusion_models/flux1-dev-kontext_fp8_scaled.safetensors)

<Tip>
원본 가중치를 사용하려면 Black Forest Labs의 관련 저장소를 방문하여 원본 모델 가중치를 얻어 사용할 수 있습니다.
</Tip>

**VAE**
- [ae.safetensors](https://huggingface.co/Comfy-Org/Lumina_Image_2.0_Repackaged/blob/main/split_files/vae/ae.safetensors)

**Text Encoder**
- [clip_l.safetensors](https://huggingface.co/comfyanonymous/flux_text_encoders/blob/main/clip_l.safetensors)
- [t5xxl_fp16.safetensors](https://huggingface.co/comfyanonymous/flux_text_encoders/blob/main/t5xxl_fp16.safetensors) 또는 [t5xxl_fp8_e4m3fn_scaled.safetensors](https://huggingface.co/comfyanonymous/flux_text_encoders/blob/main/t5xxl_fp8_e4m3fn_scaled.safetensors)

│   └── 📂 text_encoders/
│       ├── clip_l.safetensors

### 2. 워크플로우 단계별 완료

![Workflow Step Guide](/images/tutorial/flux/flux_1_kontext_dev_basic_step_guide.jpg)
이미지의 번호를 참조하여 워크플로우 실행을 완료할 수 있습니다:

1. `Load Diffusion Model` 노드에서 `flux1-dev-kontext_fp8_scaled.safetensors` 모델을 로드합니다
2. `DualCLIP Load` 노드에서 `clip_l.safetensors`와 `t5xxl_fp16.safetensors` 또는 `t5xxl_fp8_e4m3fn_scaled.safetensors`가 로드되어 있는지 확인합니다
3. `Load VAE` 노드에서 `ae.safetensors` 모델이 로드되어 있는지 확인합니다
4. `Load Image(from output)` 노드에서 제공된 입력 이미지를 로드합니다
5. `CLIP Text Encode` 노드에서 프롬프트를 수정합니다. 영어만 지원됩니다
6. `Queue` 버튼을 클릭하거나 단축키 `Ctrl(cmd) + Enter`로 워크플로우를 실행합니다
