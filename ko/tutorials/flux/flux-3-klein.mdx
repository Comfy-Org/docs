## FLUX.3 [klein] 정보

FLUX.3 [klein]은 Black Forest Labs의 로컬 ComfyUI용 오픈 웨이트 FLUX.3 이미지 모델입니다. 텍스트 기반 이미지 생성과 지시 프롬프트 기반 이미지 편집을 한 패밀리에서 다루며, 전체 체크포인트와 가이드 없이 4~16스텝으로 빠르게 샘플링하는 증류판을 제공합니다. 가중치는 FLUX Kommunity License로 Hugging Face에 공개되어 한 번 받으면 자체 GPU에서 실행할 수 있고, API 키나 이미지당 크레딧이 필요하지 않습니다.

호스티드 경로가 필요하면 Partner Node인 [FLUX 3 Image](/ko/tutorials/partner-nodes/black-forest-labs/flux-3-image)(이미지당 과금)도 있습니다. 자체 GPU면 로컬 klein 가중치, 다운로드 없이 쓰려면 Partner Node를 선택하세요.

**모델 하이라이트:**

- 동일한 가중치로 텍스트 기반 이미지 생성과 이미지 편집 가능. 편집은 지시 프롬프트와 참조 이미지로 구동
- 두 가지 체크포인트: 전체 FLUX 3 Image Klein, 그리고 가이드 없이 4~16스텝인 Distilled
- 프롬프트에서 `<ref_image_0>`, `<ref_image_1>` 등으로 다중 참조 지정
- 선택적 Qwen3.5 9B 프롬프트 업샘플러로 짧은 요청을 생성 전 완전한 캡션으로 확장
- bf16, int8(convrot), nvfp4 단일 파일 체크포인트, Qwen3-VL-4B 텍스트 인코더와 FLUX.2 VAE

**라이선스**: [FLUX Kommunity License](https://huggingface.co/black-forest-labs/flux-3-image-klein-comfy/blob/main/LICENSE.md)

**버전 요구 사항**: FLUX 3 Klein 템플릿은 ComfyUI 0.41.0 이상이 필요하며, 0.41.1 백포트(ComfyUI#17070)로 제공됩니다.

## FLUX 3 Image Klein 워크플로

### FLUX 3 Image Klein: 텍스트 기반 이미지 생성 {#image_flux3_klein_t2i}

입력 파일 없이 프롬프트만으로 이미지를 생성합니다. 이 워크플로는 서브그래프입니다. 열면 로더, 샘플러, 캔버스 크기에 접근할 수 있습니다.

1. 서브그래프의 positive 프롬프트 위젯에 프롬프트를 입력합니다
2. `width`와 `height`를 설정하거나 `ResolutionSelector`에서 프레임을 선택합니다 (기본값은 1:1 정사각형)
3. `steps`(기본값 50)와 `cfg`(기본값 3.5)를 조정합니다
4. 프롬프트 업샘플링이 기본적으로 켜져 있어 짧은 프롬프트는 먼저 Qwen3.5 9B 업샘플러로 확장됩니다. 직접 작성한 문장 그대로 생성하려면 `enable_prompt_upsampler`를 끕니다
5. **실행 대기열**을 클릭합니다. 이미지는 `SaveImage` 노드에 의해 `ComfyUI/output/`에 저장됩니다

### FLUX 3 Image Klein Distilled: 텍스트 기반 이미지 생성 {#image_flux3_klein_distilled_t2i}

스텝 증류(step-distilled) checkpoint로 프롬프트에서 이미지를 생성합니다. 이 checkpoint는 16스텝으로, 가이드 없이 실행됩니다. 프롬프트 업샘플링이 기본적으로 켜져 있으므로, 짧은 프롬프트가 샘플링 전에 완전한 캡션으로 확장됩니다.

1. 프롬프트를 입력합니다. 템플릿이 먼저 업샘플링하므로 짧은 설명으로 충분합니다

3. `ResolutionSelector`에서 프레임을 선택합니다

## 프롬프트 작성 및 레퍼런스 팁

- **변경 사항이 아니라 결과를 작성하세요.** 이미지 편집 템플릿은 편집 내용이 반영된 완성 이미지에 대한 전체 캡션을 기대하므로, 예시들도 "이것을 바꿔라"라고 말하는 대신 새로운 객체를 자세히 설명합니다.
- **레퍼런스는 두 conditioning 모두에 추가됩니다.** 추가 이미지를 `Set Reference Multi Latent`에 순서대로 연결하고, `<ref_image_0>`, `<ref_image_1>` 등으로 지칭한 다음, 레퍼런스 pipeline이 하는 방식대로 각각을 positive 프롬프트와 네거티브 프롬프트 양쪽에 추가하세요.
- **레퍼런스 크기는 비용을 조절하는 다이얼입니다.** 템플릿은 각 레퍼런스의 크기를 약 1메가픽셀로 조정하며, 출력 잠재 데이터는 그 크기를 갖습니다. Black Forest Labs 자체 pipeline이 약 16메가픽셀까지 유지하는 것처럼 레퍼런스를 원본 크기로 유지하면 비용이 더 높아지는 대신 편집 결과에 더 많은 디테일이 남습니다.
- **스텝 수는 checkpoint에 따라 다릅니다.** 전체 checkpoint는 템플릿에서 50 스텝으로 실행되며, 텍스트 기반 생성에서는 가이드 3.5, 이미지 편집에서는 1입니다. 스텝 증류(step-distilled) checkpoint는 16 스텝에 가이드가 1로 고정되어 실행되며, 빠르게 처리하고 싶을 때 사용하는 것이 바로 이 checkpoint입니다.
- **박스는 `Flux3LayoutPrompt`를 거쳐 모델에 전달됩니다.** `Create Bounding Boxes`는 박스를 `elements` 출력으로 내보내고, `Flux3LayoutPrompt`는 이를 `id`, `bbox`, `desc`를 담은 JSON 레이아웃 표로 프롬프트 뒤에 덧붙입니다. 박스는 그린 순서대로 `obj_1`, `obj_2`로 번호가 붙으므로 배경 요소를 먼저 그리세요. 프롬프트에서 `<obj_1>`로 인용하면 해당 단어가 그 박스에 연결됩니다. 박스를 그리지 않으면 이 노드는 프롬프트를 그대로 반환합니다.
- **이미지 편집 템플릿은 이미 박스를 사용합니다.** `Flux3LayoutPrompt`를 프롬프트 업샘플러와 스위치를 거쳐 샘플러의 텍스트 인코드로 보내므로, 배선을 바꾸지 않아도 박스 목록이 모델에 전달됩니다. 편집 문장은 이 레이아웃 노드 자체의 프롬프트 칸에 쓰고, 박스에 해당하는 자리에 `<obj_1>`을 남겨 두세요.
- **텍스트에서 이미지 템플릿은 레이아웃 출력이 연결되어 있지 않습니다.** `Preview Any`에만 연결됩니다. `Flux3LayoutPrompt`에 프롬프트를 쓰고 그 `prompt` 출력을 서브그래프의 프롬프트 입력으로 끌어다 놓으세요. 먼저 `enable_prompt_upsampler`를 끄세요. 끄지 않으면 Qwen3.5 업샘플러가 샘플링 전에 이 텍스트를 다시 쓰면서 레이아웃 표도 함께 바뀝니다.
- **텍스트에서 이미지 생성 시 캔버스 전체를 덮는 박스 하나를 사용하세요.** 장면 설명은 그 박스의 설명에 적습니다. 그러면 모델은 레이아웃 정보가 없는 텍스트 대신 프레임 전체에 대한 배치 행을 받습니다.
- **박스 캔버스는 출력과 같은 가로세로 비율로 맞추세요.** 박스 좌표는 `Create Bounding Boxes`의 `width`와 `height`에 대한 비율로 저장되므로, 캔버스 비율이 출력 잠재 데이터와 다르면 영역이 늘어납니다. 비율만 같으면 캔버스 픽셀 크기는 상관없습니다. 이미지 편집 템플릿의 캔버스는 896 x 1152이고 잠재 데이터는 1024 x 1024이므로, 정확한 영역이 필요하면 잠재 크기를 캔버스 비율에 맞게 바꾸세요.
- **색상은 박스 설명에 적습니다.** 편집기의 팔레트는 무시되므로 색을 설명에 적으세요.
