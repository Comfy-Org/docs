## 이미지 모델로 할 수 있는 작업

- **텍스트 기반 이미지 생성**: 텍스트 프롬프트에서 이미지 생성
- **이미지 편집**: 기존 이미지의 콘텐츠 변경, 스타일 변경, 또는 참조 이미지 따르기
- **이미지 기반 이미지 생성**: 입력 이미지의 구조를 유지하면서 새 버전으로 변환
- **업스케일링 및 향상**: 해상도를 높이거나 품질을 개선
- **유틸리티 워크플로**: 배경 제거, 재조명 등

## 작업별 모델 선택

### 범용 텍스트 기반 이미지 생성

간단한 텍스트 프롬프트로 최상의 전반적인 품질을 원한다면 다음 중 하나로 시작하세요.

- **Flux.1 Kontext** (Black Forest Labs): 프롬프트 준수도가 뛰어난 최첨단 생성 모델이며, 맥락을 고려한 편집을 위해 여러 개의 입력 이미지를 지원합니다.
- **Flux 1.1 Pro Ultra** (Black Forest Labs): Flux 제품군의 고급 생성 모델입니다.
- **GPT-Image-2 / GPT-Image-1** (OpenAI): 단일 API로 강력한 텍스트 기반 이미지 생성과 이미지 편집을 제공합니다.
- **Qwen Image 3.0 Pro** (Qwen): Alibaba의 Qwen 제품군에서 제공하는 빠르고 고품질의 생성 모델입니다.

### 이미지 편집 및 inpainting

이 모델들은 기존 이미지를 수정하도록 설계되었습니다.

- **Nano Banana Pro / Nano Banana 2 / Nano Banana 2 Lite** (Google): Google의 Gemini 기반 이미지 편집 및 생성 모델로, 대화에서 후속 편집에 유용합니다.
- **Luma Uni-1** (Luma): 자연어 지시로 이미지를 생성하고 수정할 수 있습니다.
- **Muse Image 1.0** (Meta): 최대 10장의 참조 이미지를 한 번에 결합할 수 있는 지시 기반 이미지 편집.
- **Ideogram 4.0** (Ideogram): 이미지 속 텍스트 렌더링에 강하며, 이미지 입력을 통한 편집을 지원합니다.

### 배경 제거 및 유틸리티

- **Bria 배경 제거** (Bria): 이미지 배경을 깔끔하게 제거합니다.
- **Bria Fibo / Bria 이미지 편집** (Bria): 편집 및 복원 유틸리티입니다.
- **Topaz 이미지 향상 Wonder 3.5 / Bloom 2** (Topaz): 이미지 품질을 업스케일하고 복원합니다.

### 속도 및 예산

- **Nano Banana 2 Lite** (Google): Nano Banana 제품군에서 더 가볍고 빠른 변형 모델입니다.
- **Recraft V4 / Recraft 텍스트 기반 이미지 생성** (Recraft): 스타일 제어가 가능한 디자인 중심 생성 모델입니다.
- **Seedream 5.0 Pro / Lite** (ByteDance): ByteDance의 빠른 생성 모델입니다.
