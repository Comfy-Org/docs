여섯 개의 MiniMax H3 Max 편집 노드는 프롬프트만 사용하는 대신 비디오나 정지 이미지에서 시작하여 해당 소재를 편집합니다. 이 노드들은 다른 H3 API 노드와 마찬가지로 Comfy API 계정을 통해 MiniMax의 서버에서 실행되며, 편집 노드는 ComfyUI 0.44.0에서 추가되었습니다.

이 중 두 개는 워크플로 템플릿과 함께 제공됩니다: **Cast Swap** (`api_minimax_h3_max_recast`)과 **Aspect Ratio Reframe** (`api_minimax_h3_max_reframe`)입니다. 나머지 네 개는 **Partner Nodes > video > MiniMax** 아래 노드 라이브러리에 있으며, 자신의 워크플로에 바로 추가할 수 있습니다.

MiniMax H3, H3 Max, H3 Max Turbo로 생성하려면 [MiniMax H3 API 비디오 생성](/ko/tutorials/partner-nodes/minimax/minimax-h3)을 참조하세요.

## MiniMax H3 Max: Cast Swap

재촬영 없이 완성된 클립 속 인물을 교체합니다. Recast 노드는 모션, 프레이밍, 컷, 원본 오디오를 그대로 유지하고, 참조 사진으로 새로운 인물을 생성합니다.

직접 준비한 클립을 불러오고, 새 인물마다 한 장씩 1~4장의 사진을 연결합니다. 기본적으로 사진은 클립의 주요 인물을 왼쪽에서 오른쪽 순서로 교체하므로, 원하는 순서대로 연결하세요. 프롬프트는 선택 사항입니다. 사진의 이름을 `@Image1`부터 `@Image4`까지로 지정하고, 누가 누구로 바뀌는지와 함께 그대로 유지되어야 하는 요소를 설명하세요.

- **소스 클립**: 5~30초, 단일 샷은 15초를 넘지 않아야 하며 가로세로 비율이 0.4~2.5 사이여야 합니다
- **참조 사진**: 최소 256 x 256 픽셀, 최대 4장
- **해상도**: 768P 또는 1080P
- **사실감 향상**: 기본적으로 꺼짐입니다. 더 자연스러운 피부 질감과 장면에 더 잘 어우러지는 결과를 원하면 켜세요

## MiniMax H3 Max: 화면 비율 리프레임

피사체를 잘라내지 않고 클립을 다른 화면 비율에 맞춥니다. 소스는 새 캔버스에서 위치, 타이밍, 오디오를 그대로 유지하며, 모델이 주변 화면을 생성합니다.

포함된 데모는 수직 인물 클립을 16:9 프레임으로 변환합니다. 직접 준비한 클립을 불러오고, 대상 화면 비율과 해상도를 선택한 뒤, 프롬프트로 새 영역을 무엇으로 채울지 설명하세요. 예를 들어 피사체 양옆 뒤에 이미 있는 배경을 이어서 그리도록 지정할 수 있습니다.

- **소스 클립**: 0.5 ~ 300초
- **화면 비율**: 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 또는 9:21
- **해상도**: 480P, 768P 또는 1080P

## MiniMax H3 Max 편집 노드

| 노드 | 기능 | 시작 미디어 |
| :--- | :----------- | :------------- |
| **MiniMax H3 Max Recast** | 비디오 속 인물을 레퍼런스 사진의 인물로 교체하며, 소스의 움직임, 카메라, 컷, 사운드를 유지합니다 | 5-30초 비디오, 사진 1-4장 |
| **MiniMax H3 Max Extend Video** | 프롬프트에 설명된 새로운 영상으로 비디오를 이어서 생성합니다 | 1.625-60초 비디오 |
| **MiniMax H3 Max Reframe Video** | 비디오를 새로운 화면 비율에 맞추고 주변 영역을 생성하며, 타이밍과 사운드를 유지합니다 | 0.5-300초 비디오 |
| **MiniMax H3 Max Insert Video** | 두 타임스탬프 사이의 구간을 새로 생성된 장면으로 교체합니다 | 최대 60초 비디오와 시작 및 재개 시간 |
| **MiniMax H3 Max Lip Sync** | 정지 이미지를 애니메이션으로 만들어 입 모양이 오디오 트랙을 따라가게 합니다 | 이미지 1장, 5-899초 오디오 |
| **MiniMax H3 Max Camera Control** | 정지 이미지 속 피사체 주위로 카메라를 회전시킵니다 | 이미지 1장과 종료 각도 및 거리 |

Recast, Extend Video, Insert Video 프롬프트에서는 연결된 레퍼런스를 연결 순서대로 번호가 매겨진 `@Image1`, `@Audio1`, `@Video1`로 참조하세요. 레퍼런스 기반 비디오 생성 노드도 자체 레퍼런스에 동일한 축약 표기를 사용할 수 있습니다. 연결한 레퍼런스 범위를 벗어난 태그를 지정하면 실행이 오류와 함께 중단됩니다.

노드 및 해상도별 요금은 [Minimax 가격표](/ko/tutorials/partner-nodes/pricing)에 나와 있습니다.
