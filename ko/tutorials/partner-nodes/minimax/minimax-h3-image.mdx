MiniMax H3 Image는 MiniMax의 이미지 모델로, ComfyUI에서 **MiniMax H3 Image** 파트너 노드를 통해 사용할 수 있습니다. 텍스트 기반 이미지 생성과 이미지 편집은 동일한 노드를 사용합니다. 참조 이미지가 연결되지 않은 경우 프롬프트로부터 생성하고, 참조 이미지가 연결된 경우에는 이를 편집하거나 결합합니다.

워크플로는 Comfy API 계정을 통해 MiniMax의 서버에서 실행되므로 모델 다운로드가 없고 관리할 로컬 GPU도 없습니다.

## MiniMax H3 Image가 잘하는 것

- **2K 및 4K 출력**: 크기 등급과 화면 비율을 선택하거나 정확한 너비와 높이를 설정하세요
- **이미지 편집**: 최대 16개의 참조 이미지를 편집하거나 결합할 수 있으며, 프롬프트에서 `@Image1`부터 `@Image16`까지로 지정합니다
- **프롬프트 재작성**: MiniMax는 기본적으로 짧은 프롬프트를 상세한 장면 설명으로 확장하고, 재작성된 프롬프트를 이미지와 함께 반환합니다
- **포스터 수준의 디테일**: 읽기 쉬운 텍스트와 촘촘한 디테일이 필요한 포스터, 패키징, 에디토리얼 이미지에 적합합니다

## 옵션

| 입력 | 값 | 참고 |
| :---- | :----- | :---- |
| `model` | `MiniMax-H3-Image`, `MiniMax-H3-Image-Highspeed` | 템플릿에서 `model` 드롭다운을 변경하여 전환합니다 |
| `size` | `2K`, `4K`, `custom` | 2K와 4K는 가로세로 비율로부터 너비와 높이를 도출합니다. `custom`은 너비와 높이를 각각 512~7680 px로 지정하며, 총 655,360~20,000,000 px이고 가로세로 비율은 최대 3:1입니다 |
| `aspect_ratio` | `auto` 및 고정 비율 15개 | `auto`는 프롬프트를 따르며, 참조 이미지가 연결된 경우에는 해당 참조 이미지를 따릅니다 |
| `enhance_prompt` | 기본적으로 켜짐 | MiniMax는 프롬프트를 먼저 상세한 장면 설명으로 다시 작성합니다. 편집 작업에는 항상 프롬프트 향상이 적용되므로, 이 옵션을 끄면 텍스트 기반 이미지 생성에만 영향을 줍니다. 이 경우 고정 비율이나 사용자 지정 크기가 필요합니다 |
| `images` | 최대 16개 | 편집 및 결합을 위한 참조 이미지입니다. 프롬프트에서 연결된 순서대로 `@Image1`, `@Image2` 등으로 참조하세요 |

참조 이미지가 연결된 경우 프롬프트는 최대 8,000자까지 사용할 수 있습니다. 노드는 이미지와 함께 다시 작성된 `revised_prompt`도 반환합니다.
