MiniMax (Hailuo)는 뛰어난 모션 품질과 영화 같은 결과물로 잘 알려진 선도적인 AI 비디오 생성 플랫폼이며, 이제 ComfyUI 안에서 사용할 수 있습니다. **MiniMax-01**(T2V-01 텍스트 기반 비디오 생성과 Director/Live 모드를 지원하는 I2V-01 이미지 기반 비디오 생성)과 **MiniMax S2V-01**(피사체 레퍼런스 기반 비디오 생성)의 두 가지 모델 라인을 제공하며, 영화 수준의 내러티브부터 캐릭터 중심 콘텐츠까지 폭넓게 아우릅니다.

## 주요 기능

- **Director 모드를 지원하는 T2V-01**: 15가지 영화적 카메라 무브먼트 유형(팬, 틸트, 돌리, 크레인, 트래킹, 항공, 핸드헬드, 롤, 줌인, 줌아웃, 푸시인, 풀아웃, 오빗, 1인칭, 고정)으로 샷 단위의 정밀한 연출이 가능합니다
- **I2V-01-Director**: 이미지로 시작하는 비디오에 영화적 카메라 제어를 적용하여, 시작 이미지의 시각적 기반과 Director 모드의 표현력을 결합합니다
- **I2V-01-Live**: 단일 이미지에서 자연스럽고 생동감 있는 모션을 생성합니다. 유기적인 움직임 역학을 갖추고 있어 인물 사진, 풍경, 제품 이미지에 생명을 불어넣기에 이상적입니다
- **S2V-01 피사체 레퍼런스**: 단일 레퍼런스 이미지를 사용해 생성된 비디오 전반에서 캐릭터, 얼굴 또는 객체의 정체성을 유지합니다. 시리즈 콘텐츠에 안성맞춤입니다
- **높은 모션 품질**: 모든 모델 변형에서 캐릭터 움직임, 물리, 유체 역학 전반에 걸쳐 업계 최고 수준의 사실감을 제공합니다
