[MiniMax H3](https://www.minimax.io/blog/minimax-h3)은(는) MiniMax의 일반 목적 옴니모달 생성 모델로, ComfyUI에서 MiniMax H3 API 노드를 통해 사용할 수 있습니다. API 워크플로는 MiniMax 서버에서 생성 작업을 실행하므로 모델 다운로드나 로컬 GPU가 필요하지 않으며, 생성된 비디오의 각 초는 Comfy API 계정에 청구됩니다.

MiniMax H3는 **네이티브 스테레오 오디오**로 비디오를 생성합니다. 음성, 사운드 효과, 음악은 이후에 레이어링되는 대신 단일 정방향 패스에서 함께 모델링됩니다. 출력은 클립당 5~15초, 최대 2K 해상도입니다.

**MiniMax H3 Max**는 fal이 MiniMax H3를 기반으로 고속 생성에 맞춰 포스트트레이닝한 변형 모델로, ComfyUI 0.34.2에서 동일한 API 노드에 추가되었습니다. 실시간보다 빠르게 생성되며 최대 50,000자 프롬프트를 지원하고, 480P 및 768P 해상도와 함께 ComfyUI가 이미 지원하는 노드로 구성된 선택적 2단계 그래프를 제공합니다: MiniMax H3 Context IR 노드를 통한 프롬프트 개선 후 MiniMax H3 Regenerate to 2K 노드로 2K 재생성.

**MiniMax H3 Max Turbo**는 ComfyUI 0.34.4에서 텍스트 기반 비디오 생성 노드와 첫/마지막 프레임 노드에 추가된 더 빠르고 저렴한 H3 Max 옵션입니다. 480P 또는 768P로 렌더링하며, 첫/마지막 프레임 노드에서는 해상도와 비율 옵션이 제거되어 출력 비율이 입력 프레임을 따릅니다.

<Note>
이 API 워크플로는 Comfy 계정을 통해 MiniMax 서버에서 실행됩니다. 상업 작업을 위해 자체 하드웨어에서 H3를 로컬로 실행하려면 [MiniMax 상업 라이선스](https://comfy.org/minimax/license)가 필요합니다. 이 라이선스는 유일한 공식 리셀러인 Comfy를 통해 제공됩니다.
</Note>

## MiniMax H3가 뛰어난 분야

- **네이티브 스테레오 오디오**: 음성, 사운드 효과, 음악이 비디오와 함께 단일 포워드 패스로 모델링되며, 이후에 덧입혀지지 않습니다
- **고해상도 출력**: 클립당 5~15초, 최대 2K 해상도
- **텍스트 기반 비디오 생성**: 텍스트 프롬프트에서 오디오를 포함한 비디오를 생성합니다
- **첫 번째-마지막 프레임 비디오**: 첫 번째 프레임과 선택적인 마지막 프레임 이미지 사이의 모션을 생성합니다
- **참조 조건 생성**: 최대 9개의 참조 이미지, 3개의 참조 비디오, 3개의 참조 오디오 클립을 조건으로 비디오를 생성합니다
- **MiniMax H3 Max**: 480P/768P 출력, 긴 프롬프트, 선택적 2K 업스케일 단계를 갖춘 더 빠른 변형 모델입니다. H3 Max에서 Reference 노드는 최대 12개의 참조 파일을 받을 수 있습니다
- **MiniMax H3 Max Turbo**: 텍스트 기반 비디오 생성 노드와 첫/마지막 프레임 노드에서 사용할 수 있는 가장 빠른 H3 Max 옵션으로, 초당 요금은 Max의 약 절반입니다

## MiniMax H3 API 워크플로

템플릿 라이브러리에는 H3 베이스 모델용 API 예제 워크플로 3개, H3 Max용 4개, H3 Max Turbo용 2개가 포함되어 있습니다:

- **텍스트 기반 비디오 생성**: 텍스트 프롬프트에서 비디오를 생성합니다.
- **첫/마지막 프레임 기반 비디오 생성**: 첫 번째 프레임 이미지와 마지막 프레임 이미지 사이의 비디오를 생성합니다.
- **레퍼런스 기반 비디오 생성**: 레퍼런스 이미지, 비디오 및 오디오를 조건으로 비디오를 생성합니다.
- **H3 Max T2V / I2V / FLF2V / R2V**: 더 빠른 MiniMax H3 Max 모델로 동일한 모드를 실행합니다. 각 워크플로에는 선택적 프롬프트 개선 및 2K 업스케일 단계가 내장되어 있습니다.
- **H3 Max Turbo T2V / I2V**: 가장 빠른 MiniMax H3 Max Turbo 모델로 텍스트 기반 비디오 생성과 첫/마지막 프레임 비디오를 실행합니다. 이 역시 선택적 프롬프트 개선 및 2K 업스케일 단계가 내장되어 있습니다.

### MiniMax H3 Max

4개의 `api_minimax_h3_max_*` 템플릿은 동일한 API 노드를 통해 MiniMax H3 Max 모델에서 실행됩니다. Text to Video 및 First-Last-Frame 노드에는 ComfyUI 0.34.2에서, Reference to Video 노드에는 0.34.3에서 H3 Max 옵션이 추가되었습니다. 모두 실행하려면 ComfyUI를 최소 0.34.3으로 업데이트하세요.

H3 Max는 실시간보다 빠르게 생성되며 베이스 모델보다 낮은 요율로 청구됩니다: 480P는 15.09 크레딧/초, 768P는 24.14 크레딧/초입니다([Minimax 요금표](/ko/tutorials/partner-nodes/pricing) 참조). 각 Max 템플릿에는 Switch 노드 뒤에 선택적 단계 2개가 있으며, 둘 다 기본적으로 꺼져 있습니다:

1. **프롬프트 개선**: 생성 전에 MiniMax H3 Context IR 노드로 프롬프트를 다시 씁니다. `Prompt Enhance` 불리언을 켜면 활성화됩니다
2. **2K로 업스케일**: 첫 번째 패스 비디오에 MiniMax H3 Regenerate to 2K 노드를 실행합니다. `Upscale to 2K` 불리언을 켜면 활성화됩니다

Max 템플릿을 연결할 때 다음 사항에 유의하세요:

- **업스케일할 계획이라면 768P로 생성**: Regenerate to 2K 노드는 768P 소스 비디오만 받습니다
- **노드 간 재생 시간 일치**: 생성과 프롬프트 개선은 동일한 재생 시간을 사용해야 합니다. 그렇지 않으면 단계가 어긋납니다. Regenerate to 2K 노드에는 재생 시간 입력이 없으며, 제출된 768P 비디오를 원래 재생 시간으로 다시 렌더링합니다
- **추가 입력은 복제**: 3개의 노드는 추가 컨텍스트를 자동으로 공유하지 않습니다. 참조 비디오, 오디오 또는 다른 이미지를 추가했다면 동일한 연결을 Context IR 노드와 Regenerate 노드 모두에 연결하세요

#### 프롬프트 팁

1. **프롬프트**: 전체 장면과 그에 따른 오디오(대화, SFX, 음악)를 한 블록에 설명하세요.
2. **재생 시간**: 재생 시간 입력은 5~15초를 지원하며, 워크플로에는 빠른 5초 미리보기가 포함되어 있습니다.
3. **해상도 및 비율**: API는 2K로 렌더링합니다. `16:9`, `9:16`, `1:1` 등의 화면 비율 프리셋을 선택하세요.
4. **워터마크**: AIGC 워터마크는 기본적으로 꺼져 있습니다. 필요한 경우 노드의 고급 설정에서 활성화하세요.

#### 프롬프트 팁

1. **프레임**: `first_frame` 입력은 필수이고 `last_frame`은 선택 사항입니다. 모델은 두 프레임 사이의 움직임을 생성합니다.
2. **가로세로 비율**: 출력은 입력 이미지를 따르므로 두 프레임을 동일한 가로세로 비율로 유지하세요.
3. **이미지 제약 조건**: 각 프레임의 너비와 높이는 256픽셀에서 5760픽셀 사이여야 하며, 가로세로 비율은 2:5에서 5:2 사이여야 합니다.
4. **프롬프트**: 프레임 사이의 전환과 원하는 오디오(대사, 효과음, 음악)를 설명하세요.

#### 프롬프트 작성 가이드

#### 프롬프트 팁

1. **태그로 레퍼런스 지정**: 프롬프트에서 각 입력을 순서대로 참조하세요. 예: `Image 1`, `Video 1`, `Audio 1`
2. **제한 사항**: 최대 9개의 레퍼런스 이미지, 3개의 레퍼런스 비디오, 3개의 레퍼런스 오디오 클립을 사용할 수 있습니다. 각 비디오 또는 오디오 클립은 2~15초여야 하며, 레퍼런스 비디오와 오디오의 총 길이는 각각 15초로 제한됩니다.
3. **오디오에는 시각적 앵커가 필요합니다**: 레퍼런스 오디오는 최소 한 개의 레퍼런스 이미지 또는 비디오가 없으면 사용할 수 없습니다.
4. **비디오 요구 사항**: 레퍼런스 비디오는 23.976~60 FPS여야 합니다.
5. **프롬프트**: 각 레퍼런스에 작업(정체성, 스타일, 모션, 음성)을 할당하고 목표 샷을 설명하세요. 명시적인 할당이 훨씬 더 잘 작동하는 경향이 있습니다.

#### 프롬프트 작성 가이드

MiniMax는 레퍼런스 기반 생성(R2V)을 위한 공식 [전체 레퍼런스 모드 프롬프트 가이드](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md)를 게시합니다. 이 가이드는 재작성 출력 구조(피사체 정의, 레퍼런스 라벨, 보존 분석 포함)와 각 레퍼런스에 대상 샷에서의 역할을 할당하는 방법을 다룹니다.
