[MiniMax H3](https://www.minimax.io/blog/minimax-h3)은(는) MiniMax의 일반 목적 옴니모달 생성 모델로, ComfyUI에서 MiniMax H3 API 노드를 통해 사용할 수 있습니다. API 워크플로는 MiniMax 서버에서 생성 작업을 실행하므로 모델 다운로드나 로컬 GPU가 필요하지 않으며, 생성된 비디오의 각 초는 Comfy API 계정에 청구됩니다.

MiniMax H3는 **네이티브 스테레오 오디오**로 비디오를 생성합니다. 음성, 사운드 효과, 음악은 이후에 레이어링되는 대신 단일 정방향 패스에서 함께 모델링됩니다. 출력은 클립당 5~15초, 최대 2K 해상도입니다.

**MiniMax H3 Max**는 fal이 MiniMax H3를 기반으로 고속 생성에 맞춰 포스트트레이닝한 변형 모델로, ComfyUI 0.34.2에서 동일한 API 노드에 추가되었습니다. 실시간보다 빠르게 생성되며 최대 50,000자 프롬프트를 지원하고, 480P 및 768P 해상도와 함께 ComfyUI가 이미 지원하는 노드로 구성된 선택적 2단계 그래프를 제공합니다: MiniMax H3 Context IR 노드를 통한 프롬프트 개선 후 MiniMax H3 Regenerate to 2K 노드로 2K 재생성.

**MiniMax H3 Max Turbo**는 ComfyUI 0.34.4에서 텍스트 기반 비디오 생성 노드와 첫/마지막 프레임 노드에 추가된 더 빠르고 저렴한 H3 Max 옵션입니다. 480P 또는 768P로 렌더링하며, 첫/마지막 프레임 노드에서는 해상도와 비율 옵션이 제거되어 출력 비율이 입력 프레임을 따릅니다.

<Note>
이 API 워크플로는 Comfy 계정을 통해 MiniMax 서버에서 실행됩니다. 상업 작업을 위해 자체 하드웨어에서 H3를 로컬로 실행하려면 [MiniMax 상업 라이선스](https://comfy.org/minimax/license)가 필요합니다. 이 라이선스는 유일한 공식 리셀러인 Comfy를 통해 제공됩니다.
</Note>

## MiniMax H3가 뛰어난 분야

- **네이티브 스테레오 오디오**: 음성, 사운드 효과, 음악이 비디오와 함께 단일 포워드 패스로 모델링되며, 이후에 덧입혀지지 않습니다
- **고해상도 출력**: 클립당 5~15초, 최대 2K 해상도
- **텍스트 기반 비디오 생성**: 텍스트 프롬프트에서 오디오를 포함한 비디오를 생성합니다
- **첫 번째-마지막 프레임 비디오**: 첫 번째 프레임과 선택적인 마지막 프레임 이미지 사이의 모션을 생성합니다
- **참조 조건 생성**: 최대 9개의 참조 이미지, 3개의 참조 비디오, 3개의 참조 오디오 클립을 조건으로 비디오를 생성합니다
- **MiniMax H3 Max**: 480P/768P 출력, 긴 프롬프트, 선택적 2K 업스케일 단계를 갖춘 더 빠른 변형 모델입니다. H3 Max에서 Reference 노드는 최대 12개의 참조 파일을 받을 수 있습니다
- **MiniMax H3 Max Turbo**: 텍스트 기반 비디오 생성 노드와 첫/마지막 프레임 노드에서 사용할 수 있는 가장 빠른 H3 Max 옵션으로, 초당 요금은 Max의 약 절반입니다

## MiniMax H3 API 워크플로

템플릿 라이브러리에는 H3 베이스 모델용 API 예제 워크플로 3개, H3 Max용 4개, H3 Max Turbo용 2개가 포함되어 있습니다:

- **텍스트 기반 비디오 생성**: 텍스트 프롬프트에서 비디오를 생성합니다.
- **첫/마지막 프레임 기반 비디오 생성**: 첫 번째 프레임 이미지와 마지막 프레임 이미지 사이의 비디오를 생성합니다.
- **레퍼런스 기반 비디오 생성**: 레퍼런스 이미지, 비디오 및 오디오를 조건으로 비디오를 생성합니다.
- **H3 Max T2V / I2V / FLF2V / R2V**: 더 빠른 MiniMax H3 Max 모델로 동일한 모드를 실행합니다. 각 워크플로에는 선택적 프롬프트 개선 및 2K 업스케일 단계가 내장되어 있습니다.
- **H3 Max Turbo T2V / I2V**: 가장 빠른 MiniMax H3 Max Turbo 모델로 텍스트 기반 비디오 생성과 첫/마지막 프레임 비디오를 실행합니다. 이 역시 선택적 프롬프트 개선 및 2K 업스케일 단계가 내장되어 있습니다.

### MiniMax H3 Max

4개의 `api_minimax_h3_max_*` 템플릿은 동일한 API 노드를 통해 MiniMax H3 Max 모델에서 실행됩니다. Text to Video 및 First-Last-Frame 노드에는 ComfyUI 0.34.2에서, Reference to Video 노드에는 0.34.3에서 H3 Max 옵션이 추가되었습니다. 모두 실행하려면 ComfyUI를 최소 0.34.3으로 업데이트하세요.

H3 Max는 실시간보다 빠르게 생성되며 베이스 모델보다 낮은 요율로 청구됩니다: 480P는 15.09 크레딧/초, 768P는 24.14 크레딧/초입니다([Minimax 요금표](/ko/tutorials/partner-nodes/pricing) 참조). 각 Max 템플릿에는 Switch 노드 뒤에 선택적 단계 2개가 있으며, 둘 다 기본적으로 꺼져 있습니다:

1. **프롬프트 개선**: 생성 전에 MiniMax H3 Context IR 노드로 프롬프트를 다시 씁니다. `Prompt Enhance` 불리언을 켜면 활성화됩니다
2. **2K로 업스케일**: 첫 번째 패스 비디오에 MiniMax H3 Regenerate to 2K 노드를 실행합니다. `Upscale to 2K` 불리언을 켜면 활성화됩니다

Max 템플릿을 연결할 때 다음 사항에 유의하세요:

- **업스케일할 계획이라면 768P로 생성**: Regenerate to 2K 노드는 768P 소스 비디오만 받습니다
- **노드 간 재생 시간 일치**: 생성과 프롬프트 개선은 동일한 재생 시간을 사용해야 합니다. 그렇지 않으면 단계가 어긋납니다. Regenerate to 2K 노드에는 재생 시간 입력이 없으며, 제출된 768P 비디오를 원래 재생 시간으로 다시 렌더링합니다
- **추가 입력은 복제**: 3개의 노드는 추가 컨텍스트를 자동으로 공유하지 않습니다. 참조 비디오, 오디오 또는 다른 이미지를 추가했다면 동일한 연결을 Context IR 노드와 Regenerate 노드 모두에 연결하세요

#### 프롬프트 팁

1. **프롬프트**: 전체 장면과 그에 따른 오디오(대화, SFX, 음악)를 한 블록에 설명하세요.
2. **재생 시간**: 재생 시간 입력은 5~15초를 지원하며, 워크플로에는 빠른 5초 미리보기가 포함되어 있습니다.
3. **해상도 및 비율**: API는 2K로 렌더링합니다. `16:9`, `9:16`, `1:1` 등의 화면 비율 프리셋을 선택하세요.
4. **워터마크**: AIGC 워터마크는 기본적으로 꺼져 있습니다. 필요한 경우 노드의 고급 설정에서 활성화하세요.

#### 프롬프트 작성 가이드

MiniMax는 기본 생성 모드인 T2VA, I2VA, FL2VA, L2VA에 대한 공식 [비디오 프롬프트 작성 가이드](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md)를 게시합니다. 이 가이드는 카메라 움직임과 오디오(대화, SFX, 음악)가 포함된 시간별 샷으로 프롬프트를 구성하는 방법을 설명하고, 각 모드에 대한 예제를 포함합니다.

#### 프롬프트 팁

1. **프레임**: `first_frame` 입력은 필수이고 `last_frame`은 선택 사항입니다. 모델은 두 프레임 사이의 움직임을 생성합니다.
2. **가로세로 비율**: 출력은 입력 이미지를 따르므로 두 프레임을 동일한 가로세로 비율로 유지하세요.
3. **이미지 제약 조건**: 각 프레임의 너비와 높이는 256픽셀에서 5760픽셀 사이여야 하며, 가로세로 비율은 2:5에서 5:2 사이여야 합니다.
4. **프롬프트**: 프레임 사이의 전환과 원하는 오디오(대사, 효과음, 음악)를 설명하세요.

#### 프롬프트 작성 가이드

MiniMax는 기본 생성 모드인 T2VA, I2VA, FL2VA, L2VA를 위한 공식 [비디오 프롬프트 작성 가이드](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md)를 제공합니다. 이 가이드는 카메라 움직임과 오디오(대사, 효과음, 음악)가 포함된 시간대별 샷으로 프롬프트를 구성하는 방법을 설명하며, 각 모드에 대한 예시도 포함합니다.

#### 프롬프트 팁

1. **태그로 레퍼런스 지정**: 프롬프트에서 각 입력을 순서대로 참조하세요. 예: `Image 1`, `Video 1`, `Audio 1`. `@Image1`, `@Video1`, `@Audio1` 단축 표기도 허용되며 동일한 태그로 처리됩니다
2. **제한 사항**: 최대 9개의 레퍼런스 이미지, 3개의 레퍼런스 비디오, 3개의 레퍼런스 오디오 클립을 사용할 수 있습니다. 각 비디오 또는 오디오 클립은 2~15초여야 하며, 레퍼런스 비디오와 오디오의 총 길이는 각각 15초로 제한됩니다.
3. **오디오에는 시각적 앵커가 필요합니다**: 레퍼런스 오디오는 최소 한 개의 레퍼런스 이미지 또는 비디오가 없으면 사용할 수 없습니다.
4. **비디오 요구 사항**: 레퍼런스 비디오는 23.976~60 FPS여야 합니다.
5. **프롬프트**: 각 레퍼런스에 작업(정체성, 스타일, 모션, 음성)을 할당하고 목표 샷을 설명하세요. 명시적인 할당이 훨씬 더 잘 작동하는 경향이 있습니다.

## H3 Max 노드로 비디오 편집하기

H3 Max는 프롬프트만이 아니라 비디오나 정지 이미지에서 시작해 그 소재를 편집하는 파트너 노드 6개도 함께 제공합니다. Recast, Extend Video, Reframe Video, Insert Video, Lip Sync, Camera Control입니다. 이 노드들에는 템플릿이 제공되지 않습니다. **Partner Nodes > video > MiniMax** 아래의 노드 라이브러리에서 추가하고, 노드가 보이지 않으면 ComfyUI를 최신 버전으로 업데이트하세요.

| 노드 | 기능 | 시작 미디어 |
| :--- | :----------- | :------------- |
| **MiniMax H3 Max Recast** | 비디오 속 인물을 레퍼런스 사진의 인물로 교체하며, 소스의 움직임, 카메라, 컷, 사운드를 유지합니다 | 5~30초 비디오, 사진 1~4장 |
| **MiniMax H3 Max Extend Video** | 프롬프트에 설명된 새 푸티지로 비디오를 이어서 만듭니다 | 1.625~60초 비디오, 1~15초의 새 푸티지 |
| **MiniMax H3 Max Reframe Video** | 비디오를 새 화면 비율에 맞추고 그 주변 영역을 생성하며, 타이밍과 사운드를 유지합니다 | 0.5~300초 비디오 |
| **MiniMax H3 Max Insert Video** | 두 타임스탬프 사이 구간을 새로 생성된 장면으로 교체합니다 | 최대 60초 비디오, 시작 시간과 재개 시간 |
| **MiniMax H3 Max Lip Sync** | 정지 이미지를 애니메이션하여 입 모양이 오디오 트랙을 따라가게 합니다 | 이미지 1장, 5~899초 오디오 |
| **MiniMax H3 Max Camera Control** | 정지 이미지 속 피사체 주위로 카메라를 회전시킵니다 | 이미지 1장, 종료 각도와 거리 |

요금은 노드, 모델, 해상도, 재생 시간, 레퍼런스 입력에 따라 달라집니다. 가격 배지는 노드를 실행하기 전에 초당 요율, 대략적인 범위 또는 계산된 합계를 보여줍니다. 예를 들어 Extend Video는 H3 Max와 H3 Max Turbo를 모두 지원하며 선택한 재생 시간, 해상도, 모델로 합계를 계산합니다. 해상도별 요율은 [Minimax 가격표](/ko/tutorials/partner-nodes/pricing)에 있습니다.

Recast, Extend Video, Insert Video의 프롬프트에서는 연결된 레퍼런스를 `@Image1`, `@Audio1`, `@Video1`로 지칭하며, 번호는 연결 순서를 따릅니다. 노드는 요청을 보내기 전에 각 태그를 대응하는 레퍼런스로 해석합니다. 해당 유형의 레퍼런스 개수를 넘는 태그가 있으면 오류와 함께 실행이 중단되고, 노드가 지원하지 않는 유형의 태그(예: Recast의 오디오)는 그대로 전송됩니다.

### Recast

소스 비디오의 인물을 1~4장의 레퍼런스 사진 속 인물로 교체하고, 원본의 카메라, 컷, 사운드를 유지합니다. 소스 비디오는 5~30초여야 하며, 그 안의 모든 샷은 15초 이하여야 하고 화면 비율은 0.4에서 2.5 사이여야 합니다. 사진은 최소 256x256 픽셀이어야 합니다. 기본적으로 왼쪽에서 오른쪽 순서로 주요 인물을 교체하며, 프롬프트로 인물을 하나씩 지정할 수 있습니다. 예를 들어 `the man becomes @Image2`와 같이 작성합니다. 기본적으로 768P 또는 1080P로 렌더링되며, **Enhance realism**은 피부 질감을 더 자연스럽게 만들고 새 인물을 장면에 자연스럽게 어우러지게 합니다.

### Extend Video

비디오 끝에 1~15초의 새 푸티지를 추가합니다. 프롬프트는 소스 푸티지가 아니라 다음에 일어나는 일을 설명합니다. Max 및 Turbo 모델과 1.625~60초, 최대 50 MB, 화면 비율 0.4에서 2.5 사이의 소스 비디오를 받습니다. 최대 3개의 선택적 레퍼런스 오디오로 새 푸티지를 유도할 수 있으며, 각 오디오는 최소 2초이고 합계 14.5초입니다. **Output**은 선택한 해상도로 전체 비디오를 다시 렌더링한 결과(`extended`) 또는 새 푸티지만(`continuation`, 소스 끝부분을 1.6초 반복하는 것으로 시작) 반환합니다. 해상도는 480P에서 2K까지이며, 2K에서는 `extended`가 소스와 새 푸티지를 합쳐 45초로 제한됩니다.

### Reframe Video

비디오를 16:9, 9:16, 1:1, 4:3, 3:4, 21:9, 9:21 중 하나의 새 화면 비율로 다시 맞추고, 리프레임된 프레임 주변 영역을 생성합니다. 소스의 타이밍과 사운드는 유지됩니다. 소스 비디오는 0.5~300초일 수 있으며, 선택적 프롬프트가 생성되는 주변부의 내용을 안내합니다. 480P, 768P, 1080P로 렌더링됩니다.

### Insert Video

비디오에서 `start_time`과 `resume_time` 사이 구간을 5~13초의 새로 생성된 장면으로 교체합니다. 소스 비디오는 최대 60초까지 가능하며, `resume_time`은 비디오 끝에서 최소 1.375초 앞에 있어야 합니다. 프롬프트로 새 장면을 설명하거나 레퍼런스를 사용하거나 둘 다 할 수 있습니다. 최대 9장의 레퍼런스 이미지와 2~15초의 레퍼런스 비디오 3개(합계 15초)를 사용할 수 있습니다. **Color match**는 기본적으로 켜져 있으며 새 장면을 소스에 자연스럽게 어우러지게 합니다. 480P 또는 768P로 렌더링됩니다.

### Lip Sync

정지 이미지를 애니메이션하여 입 움직임이 오디오 트랙을 따라가게 하며, 비디오 길이는 오디오와 같습니다. 오디오는 5~899초일 수 있습니다. 이미지는 최소 256x256 픽셀이고 화면 비율이 0.4에서 2.5 사이여야 합니다. 480P, 768P, 1080P, 2K로 렌더링됩니다. **Transcription**은 기본적으로 꺼져 있으며, 켜면 오디오를 먼저 전사하고 그 텍스트를 사용해 동기화를 안내합니다.

### Camera Control

정지 이미지에서 카메라가 피사체 주위의 새 각도와 거리로 이동하는 비디오를 생성합니다. `azimuth`(수평 회전, 양수 값은 오른쪽으로 이동), `elevation`(양수 값은 아래를, 음수 값은 위를 바라봄), `distance`(1은 거리 유지, 1 미만은 더 가까이, 1 초과는 뒤로 물러남)로 종료 카메라를 설정합니다. **Create Camera Info** 또는 **Compose Camera Angle Prompt** 노드에서 온 카메라 정보 입력을 사용하면 대신 3D 뷰에서 각도를 설정합니다. 프롬프트를 비워 두면 장면이 고정된 채 카메라만 움직입니다. 재생 시간은 1~15초이고 480P, 768P, 1080P를 지원합니다. 방위각은 정확한 결과가 아니라 목표값입니다. 90도 요청은 흔히 30도에서 90도 사이에 도달합니다.
