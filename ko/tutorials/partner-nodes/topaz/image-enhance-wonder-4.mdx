Topaz Image Enhance Wonder 4는 Topaz 파트너 노드를 통해 ComfyUI에서 사용할 수 있는 이미지 업스케일링 모델입니다. 픽셀을 늘리는 대신 그럴듯한 세부 정보를 재구성하므로, 작고 부드러운 이미지도 원본의 최대 6배 크기까지 깨끗하게 복원됩니다. 입력 종횡비를 유지하며 1x~6x 업스케일 배율을 지원합니다.

## Topaz Image Enhance Wonder 4가 뛰어난 점

- **세부 정보 재구성**: 픽셀을 보간하는 대신 부드럽거나 압축된 이미지의 세부 정보를 재구성합니다.
- **단일 패스**: 목표 크기에서 한 번만 처리하며 조정할 강도나 그레인 설정이 없습니다.
- **작은 원본 복원**: 오래된 스캔, 스크린샷, AI 썸네일, 휴대폰 크롭 이미지에 유용합니다.
- **유연한 출력**: 입력 종횡비를 유지하고 1x~6x 업스케일 배율을 지원합니다.

### 워크플로우 개요

이 워크플로는 6개의 노드를 사용합니다.

- **LoadImage**: 소스 이미지를 제공합니다.
- **ImageScaleBy**: 목표 크기를 설정합니다. 이 워크플로에서는 `nearest-exact`로 `2`배 확대합니다.
- **GetImageSize**: 확대된 크기를 읽어 `output_width`와 `output_height`로 노드에 전달합니다.
- **TopazImageEnhanceV2**: 핵심 노드로, `Wonder 4` 모델로 구성되어 해당 목표 크기까지 업스케일합니다.
- **SaveImageAdvanced**: 업스케일된 출력을 PNG로 저장합니다.
- **ImageCompare**: 부드러운 입력과 결과를 나란히 표시하여 비교합니다.

### 컨트롤

| 컨트롤 | 기능 |
|---|---|
| `model` | `Wonder 4`로 설정합니다. `Wonder 3.5`와 `Bloom 2`는 강도 향상이나 프롬프트 같은 자체 설정을 제공합니다 |
| `scale_by` | **ImageScaleBy** 노드: 업스케일 배율입니다. Wonder 4는 1x~6x, Bloom 2는 최대 12x입니다 |
| `output_width` / `output_height` | **TopazImageEnhanceV2** 노드: 픽셀 단위 목표 크기이며, 여기서는 **GetImageSize**가 값을 채웁니다. 둘 다 0이면 출력 크기가 자동으로 결정됩니다 |
| `filename_prefix` | **SaveImageAdvanced** 노드: 출력 파일 이름 접두사입니다 |

Wonder 4는 원본 종횡비를 유지합니다. 지정한 너비와 높이가 다르면 더 큰 배율이 적용되어 출력이 요청한 크기보다 커집니다. 출력은 179메가픽셀, 한 변 32,000픽셀로 제한되며, 노드는 전송 전에 입력을 약 16메가픽셀로 축소합니다.

### 실행 단계

1. **이미지 불러오기**: **LoadImage** 노드에서 입력 이미지를 업로드하거나 선택합니다.
2. **모델 선택**: **TopazImageEnhanceV2** 노드에서 `Wonder 4`를 그대로 사용합니다.
3. **목표 크기 설정**: **ImageScaleBy** 노드의 `scale_by`를 1x~6x 범위에서 변경합니다.
4. **선택적 재정의**: 노드의 `output_width` 또는 `output_height`에 픽셀 크기를 입력합니다(둘 다 0이면 자동 크기를 유지합니다).
5. **Queue 클릭**: `Ctrl+Enter`를 눌러 생성합니다.

## 사용할 때

작거나 중간 크기의 부드럽고 노이즈가 있거나 압축된 이미지에는 Wonder 4가 적합합니다. 오래된 스캔, 스크린샷, AI 썸네일, 휴대폰 크롭 이미지 등입니다. 그래픽과 질감이 있는 이미지는 좋은 테스트 대상입니다. 찢어진 가장자리, 이음새, 평평한 색면을 보면 모델이 세부 정보를 만들어내는지 원본을 유지하는지 즉시 알 수 있습니다. 이미 선명한 고해상도 사진에는 정밀 업스케일러가 원본을 더 많이 보존합니다.
