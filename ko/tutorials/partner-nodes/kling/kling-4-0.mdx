Kling 4.0은 Kling AI의 비디오 및 이미지 생성 모델로, ComfyUI에서 파트너 노드로 제공됩니다. 비디오 생성 한 번으로 최대 30초, 720p 또는 1080p 영상을 만들고 화면과 함께 스테레오 오디오도 생성합니다. 이미지 노드는 최대 8K의 정지 이미지를 렌더링합니다.

아래 워크플로는 비디오 템플릿 네 개와 이미지 템플릿 세 개로 구성됩니다. 각 비디오 노드에는 더 빠른 `kling-4.0-flash` 모델 옵션도 있으며, 720p 및 20초로 제한됩니다.

## Kling 4.0: 롱 이미지 {#api_kling4_long_image}

한 번의 패스로 매우 세로로 긴 이미지 하나를 렌더링합니다. `skill`로 페이지 종류를 선택하세요:

- `webpage`: 선택적 스타일 및 피사체 이미지를 사용하며, `@Image1`과 `@Image2`로 참조합니다. 페이지를 밴드 단위로 설명하고, 표시되는 문구의 언어를 명시하세요.
- `ecommerce`: 1~3개의 제품 이미지를 `@Image1`부터 참조하며, `length`는 `short`, `medium`, `long` 중 하나입니다.

두 스킬 모두 1K 또는 2K로 렌더링합니다.

## 입력 제한

- 이미지: 최소 300 x 300 px, 화면비 2:5에서 5:2 사이. 이미지 노드는 최대 10장의 레퍼런스 이미지를 받으며, Long Image는 `ecommerce` 모드에서 1~3장의 제품 이미지를 받습니다.
- 비디오: 각 3~30초(`kling-4.0-flash`는 3~20초), 연결된 모든 클립 합계 30초, 최소 24 fps, 한 변 700~4553 px, 총 8,294,400 px 이하, 화면비 2:5~5:2.
- 이미지, 레퍼런스, 편집 노드에서 `@ImageN` 또는 `@VideoN`이 연결된 입력 수를 넘는 프롬프트는 실행에 실패합니다.

모든 파라미터는 노드 레퍼런스 페이지에 정리되어 있습니다: [텍스트 기반 비디오 생성](/ko/built-in-nodes/Kling4TextToVideoNode), [이미지 기반 비디오 생성](/ko/built-in-nodes/Kling4ImageToVideoNode), [레퍼런스 기반 비디오 생성](/ko/built-in-nodes/Kling4ReferenceToVideoNode), [비디오 편집](/ko/built-in-nodes/Kling4EditVideoNode).
