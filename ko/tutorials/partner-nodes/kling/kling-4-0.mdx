Kling 4.0은 Kling AI의 비디오 생성 모델로, ComfyUI에서 파트너 노드로 사용할 수 있습니다. 최대 30초 길이의 클립을 720p 또는 1080p로 렌더링하고, 영상과 동일한 패스에서 스테레오 오디오를 생성하므로 앰비언스, 효과음, 대사가 별도의 사운드 작업 없이 프레임과 함께 전달됩니다.

네 개의 노드가 워크플로를 담당합니다: **Kling 4.0 Text to Video**, **Kling 4.0 Image to Video**, **Kling 4.0 Reference to Video**, **Kling 4.0 Edit Video**. 이미지 노드는 10장의 이미지로 이루어진 키프레임 예산을 하나 사용하고, Reference to Video는 최대 5개의 레퍼런스 클립을 추가하며, Edit Video는 새로운 클립을 생성하는 대신 이미 가지고 있는 클립을 다시 작성합니다.

네 가지 모두 클라우드 API 노드입니다. 크레딧이 있는 Comfy 계정이 필요하고, 모델 파일을 다운로드하지 않으며, 비디오 1초 단위로 과금됩니다. 현재 요금은 [파트너 노드 가격](/ko/tutorials/partner-nodes/pricing)을 참고하세요.

## Kling 4.0이 강점을 보이는 작업

- **긴 단일 테이크**: 한 번의 생성으로 최대 30초까지 만들 수 있으며, 클립 전체에 걸쳐 동작과 카메라가 일관되게 유지됩니다
- **키프레임 제어**: 최대 10개의 이미지로 원하는 순간의 모습을 고정하므로, 샷을 다시 뽑는 대신 원하는 방향으로 다듬을 수 있습니다
- **참조 기반 캐스팅과 장소 설정**: 최대 10개의 이미지와 5개의 클립으로 캐릭터, 제품 또는 공간을 새로운 샷에 그대로 가져올 수 있습니다
- **나머지를 유지하는 편집**: 변경할 내용을 지정하고 반드시 유지해야 할 요소를 나열하면, 연기, 샷 수, 타이밍이 그대로 보존됩니다
- **한 번의 처리로 오디오까지**: 스테레오 오디오가 영상과 함께 생성됩니다
- **멀티 샷 연출**: 컷과 카메라 무빙을 프롬프트에 설명하면 하나의 클립 안에서 생성됩니다

## 사용 가능한 워크플로

### Kling 4.0: 텍스트 기반 비디오 생성 {#api_kling4_t2v}

프롬프트만으로 생성합니다. 한 번의 생성에 여러 샷과 여러 카메라 무브가 담길 수 있으므로, 동작을 비트 단위로 묘사하세요.

**사용 방법**

1. 샷을 순서대로 배치하고 각 샷에 카메라 무브를 지정해 프롬프트를 작성합니다.
2. `duration`(3~30초), `resolution`, `aspect_ratio`를 설정합니다.
3. `seed`는 노드가 다시 실행되는지만 결정합니다. 같은 시드에서도 실행할 때마다 결과가 달라집니다.

### Kling 4.0: 이미지 기반 비디오 생성 {#api_kling4_i2v}

스틸 이미지를 하나의 클립으로 애니메이트합니다. `first_frame`, 최대 8개의 `middle_frames`, 선택 사항인 `last_frame`을 연결하며, 이들은 모두 10개 이미지 한도 안에 들어갑니다. 중간 프레임은 재생 시간에 걸쳐 균등하게 배치되고, 클립은 첫 키프레임의 화면 비율을 따릅니다.

### Kling 4.0: 레퍼런스 기반 비디오 생성 {#api_kling4_r2v}

하나의 시작 프레임이 아니라 레퍼런스로 새로운 클립을 만듭니다. 최대 10개의 `reference_images`와 최대 5개의 `reference_videos`를 연결할 수 있으며, `first_frame`과 `last_frame`은 선택 사항이고 10개 이미지 한도에 포함됩니다. `aspect_ratio`에는 `adaptive`가 추가되어 프롬프트를 따르고, 그다음 첫 프레임이나 레퍼런스 클립을 따르며, 마지막으로 `16:9`로 대체됩니다.

### Kling 4.0: 비디오 편집 {#api_kling4_video_edit}

| 컨트롤 | 값 | 적용 대상 | 효과 |
| --- | --- | --- | --- |
| `prompt` | 텍스트, 최대 26,000자 | 네 노드 모두 | 샷 설명입니다. 참조 이미지와 비디오는 연결된 순서대로 `@Image1`, `@Video1`로 지정합니다. Reference to Video에서는 연결한 키프레임을 `@first_frame` 또는 `@last_frame`으로 지정하며, `@ImageN`은 참조 이미지만 셉니다 |
| `resolution` | `720p`, `1080p` | 네 노드 모두 | 출력 해상도 |
| `duration` | 3~30초, 기본값 5초 | 텍스트, 이미지, 레퍼런스 기반 비디오 생성 | 출력 길이입니다. 비디오 편집은 대신 `video_1`의 길이를 유지합니다 |
| `aspect_ratio` | `16:9`, `9:16`, `1:1`, `21:9`; 레퍼런스 기반 비디오 생성 및 비디오 편집에서는 `adaptive` | 네 노드 모두 | 출력 형태입니다. 이미지 기반 비디오 생성은 첫 키프레임의 비율을 사용합니다 |
| `first_frame`, `middle_frames`, `last_frame` | 총 최대 10개 이미지 | 이미지 기반 비디오 생성 | 클립이 거치는 키프레임입니다. 중간 프레임은 균등한 간격으로 배치됩니다 |
| `reference_images` | 최대 10개 이미지 | 레퍼런스 기반 비디오 생성, 비디오 편집 | 캐릭터, 제품 또는 장소 레퍼런스입니다. 각 이미지의 비율은 2:5에서 5:2 사이여야 합니다 |
| `reference_videos` | 레퍼런스 기반 비디오 생성에서는 최대 5개 클립, 비디오 편집에서는 최대 4개 | 레퍼런스 기반 비디오 생성, 비디오 편집 | 각 클립은 3~30초이며, 모든 클립을 합쳐 최대 30초입니다 |
| `video_1` | 클립 1개, 3~30초 | 비디오 편집 | 편집 중인 클립입니다 |
| `seed` | 정수, 기본값 42 | 네 노드 모두 | 재실행 제어에만 사용됩니다. 출력은 시드와 관계없이 비결정적입니다 |

## 프롬프트 팁

- **각 샷에 고유한 카메라 무브를 지정하세요.** 지정하지 않으면 여러 무브가 평균화되어 하나의 느린 드리프트가 됩니다. 모든 컷과 모든 무브를 명시하세요.
- **각 레퍼런스가 담당하는 요소를 명시하세요.** `@Image1`이 인물, `@Image2`가 방을 담당한다면 속성을 고정하세요: `keep the copper bob, the trench and the boots exactly as they are`, 그리고 장소에는 `do not change the hall`이라고 지정하세요.
- **피사체가 어디에 서 있는지 말하세요.** 레퍼런스는 정체성과 장소를 고정할 뿐, 인물의 동선은 고정하지 않습니다. 새로운 위치를 말로 작성하세요. 그렇지 않으면 모든 컷이 레퍼런스가 이미 갖고 있던 프레이밍으로 귀결됩니다.
- **편집은 `Edit @Video1:`로 시작하세요.** 변경 사항 이후의 모든 내용은 유지 목록입니다. 무엇이 살아남아야 하는지 나열하는 것이 모델이 조용히 샷을 다시 연출하는 것을 막습니다.
- **속도를 근거로 설명하세요.** 질주는 프롬프트가 무엇이 얼마나 멀리 움직이는지 말할 때 빠르게 읽힙니다. 예를 들어 3~5프레임 만에 프레임의 대부분을 가로지른 뒤 2~4프레임 동안 완전히 멈추는 식입니다.
- **샷당 하나의 아이디어를 유지하세요.** 각각 하나의 명확한 비트를 가진 적은 수의 샷이 같은 클립에 빽빽이 들어간 긴 비트 목록보다 더 잘 살아남습니다.

## 제한

- 이미지: 최소 300x300 px, 가로세로 비율 2:5 ~ 5:2, 실행당 최대 10개.
- 동영상: 각 3~30초, 연결된 클립 전체 합계 최대 30초, 최소 24 fps, 변당 700~4553 px, 총 최대 8,294,400 px(3840x2160), 가로세로 비율 2:5 ~ 5:2.
- 프롬프트 참조는 반드시 해석되어야 합니다. 일치하는 연결된 입력이 없는 `@ImageN` 또는 `@VideoN`이 있으면 실행이 실패합니다.

## 시작하기

1. ComfyUI를 최신 버전으로 업데이트하세요
2. 템플릿 라이브러리로 이동하여 `Kling 4.0`을 검색하세요
3. 워크플로를 열고 입력을 연결한 다음 실행하세요. 노드 사용료는 Comfy API 크레딧으로 청구됩니다.
