ElevenLabs는 텍스트 기반 음성 생성, 음성-텍스트 변환, 사운드 효과, 보이스 분리, 보이스 변환을 아우르는 세계적 수준의 보이스 AI를 ComfyUI에 제공합니다. **Eleven v3**와 **Multilingual v2** 모델은 29개 언어에 걸쳐 감정 표현이 풍부한 음성을 제공하며, **Scribe v2**는 화자 분리와 엔터티 감지 기능을 갖춘 빠르고 정확한 전사를 제공합니다.

## 주요 기능

- **텍스트 기반 음성 생성**: 세 가지 모델 등급(Eleven v3, Multilingual v2, Flash v2.5)으로 텍스트에서 실제와 같은 오디오를 생성합니다
- **음성 대 음성 변환**: 원본의 억양과 속도를 유지하면서 소스 오디오 클립을 다른 목소리로 변환합니다
- **음성-텍스트 변환**: Scribe v2로 오디오를 전사합니다: 90개 이상 언어, 32명 화자 분리, 엔터티 감지, 키워드 부스트
- **사운드 효과**: 텍스트 설명으로 오디오 효과를 생성합니다
- **보이스 분리**: 배경 노이즈, 음악, 주변음에서 보이스를 분리합니다
- **다중 캐릭터 대화**: 한 번의 처리로 여러 개의 서로 다른 목소리 간 대화를 생성합니다
