Runway는 생성형 AI에 특화된 기업으로, 강력한 비디오 생성 기능을 제공합니다. 현재 ComfyUI에는 Runway API가 통합되어 있어, ComfyUI에서 관련 노드를 직접 사용하여 비디오를 생성할 수 있습니다.

현재 ComfyUI는 기본적으로 다음 Runway 비디오 생성 모델을 지원합니다:
- Runway Gen4 turbo

<Warning>
  **수명 종료(EOL)**: **Runway Gen3a Turbo**와 **Runway 첫-마지막 프레임 비디오 변환**은 **2026년 7월 30일**자로 수명이 종료되었습니다. Runway는 해당 날짜에 Gen-3 Alpha Turbo를 서비스 종료했습니다. 관련 파트너 노드(`RunwayImageToVideoNodeGen3a`, `RunwayFirstLastFrameNode`)와 워크플로 템플릿은 지원이 중단되었으며 더 이상 지원되지 않습니다.
</Warning>

## Runway Video Generation의 장점

- **이미지 기반 비디오 생성**: `Runway Gen4 turbo` 노드는 입력 이미지와 비디오 콘텐츠를 설명하는 텍스트 프롬프트를 기반으로 비디오를 생성합니다.
- **조절 가능한 비디오 길이**: `duration` 매개변수를 수정하여 비디오 재생 시간을 설정합니다.
- **조절 가능한 화면 비율**: `ratio` 매개변수를 수정하여 비디오 화면 비율을 설정합니다.

<Warning>
  **지원 종료(EOL)**: **Runway Gen3a Turbo** 및 **Runway 첫-마지막 프레임 비디오 변환(First-Last-Frame to Video)**은 **2026년 7월 30일**부로 지원이 종료되었습니다. Runway는 이 날짜에 Gen-3 Alpha Turbo를 지원 중단했습니다. 관련 파트너 노드(`RunwayImageToVideoNodeGen3a`, `RunwayFirstLastFrameNode`)와 워크플로 템플릿은 지원 중단되었으며 더 이상 지원되지 않습니다.
</Warning>

### 2. 워크플로 실행 단계별 완료

![ComfyUI Runway gen4 turbo image to video Step Guide](/images/tutorial/api_nodes/runway/runway_gen4_turbo_image_to_video_step_guide.jpg)

이미지의 번호를 참고하여 기본적인 이미지 기반 비디오 생성 워크플로 실행을 완료할 수 있습니다.

1. `Load Image` 노드에서 제공된 입력 이미지를 로드합니다.
2. `Runway Gen4 turbo` 노드에서 `prompt`를 설정하여 비디오 콘텐츠를 설명하고, `duration` 파라미터를 수정하여 비디오 길이를 설정하며, `ratio` 파라미터를 수정하여 비디오 화면 비율을 설정합니다.
3. `Run` 버튼을 클릭하거나 `Ctrl(cmd) + Enter` 단축키를 사용하여 비디오 생성을 실행합니다.
4. API가 결과를 반환할 때까지 기다린 후, `Save Video` 노드에서 생성된 비디오를 확인할 수 있습니다(마우스 오른쪽 버튼으로 저장). 해당 비디오는 `ComfyUI/output/` 디렉터리에도 저장됩니다.
