Tripo P2는 네이티브 쿼드 토폴로지 메시를 출력하는 Tripo의 P 시리즈 3D 생성 모델입니다. 기존 텍스트 기반 3D 생성 및 이미지 기반 3D 생성 모델이 삼각형 메시를 반환하는 반면, Tripo P2는 관절 주변의 깔끔한 에지 루프와 평평한 표면의 균일한 밀도를 갖춘 사각형 면으로 지오메트리를 구성합니다. 쿼드는 리그 아래에서 예측 가능하게 변형되고, 깔끔하게 세분화되며, 게임, 영화, 제품 시각화 분야에서 리토폴로지 비중이 큰 파이프라인의 표준 입력입니다.

Tripo P2는 텍스트로 모델 생성, 단일 이미지로 모델 생성, 멀티뷰로 모델 생성(정면, 좌측, 후면, 우측 레퍼런스)의 세 가지 입력 모드를 지원합니다. 메시 예산은 최대 50,000개의 삼각형, 쿼드 모드에서는 25,000개의 쿼드에 이릅니다. 텍스처 출력은 단계별로 제공됩니다. 표준은 2K, 상세는 4K, 익스트림은 8K이며, 베이스 색상과 함께 PBR 맵(메탈릭, 러프니스, 노멀)을 사용할 수 있습니다.

ComfyUI에서 P2 노드는 다른 Tripo 파트너 노드와 동일하게 작동합니다. 노드를 추가하고 입력을 제공하면 워크플로가 텍스처링, 리깅, 변환, 내보내기를 자동으로 처리합니다. 로컬 GPU나 모델 다운로드가 필요하지 않습니다.

## Tripo P2의 강점

- **네이티브 쿼드 토폴로지**: 깔끔한 에지 흐름을 가진 쿼드 메시로, 수동 리토폴로지 없이 리깅과 애니메이션에 바로 사용할 수 있습니다
- **넉넉한 메시 예산**: 48~50,000개의 삼각형, 또는 쿼드 모드에서 48~25,000개의 쿼드
- **단계별 텍스처링**: 표준(2K), 상세(4K), 익스트림(8K) 베이스 색상 텍스처와 선택적 PBR 맵
- **세 가지 입력 모드**: 텍스트 프롬프트, 단일 참조 이미지, 또는 최대 4장의 멀티뷰 이미지(정면, 좌측, 후면, 우측)

가격은 선택된 텍스처 레벨에 따라 달라집니다. 자세한 내용은 [Pricing](/ko/tutorials/partner-nodes/pricing)을 참조하세요.

## Tripo P2: 텍스트로 모델 생성

텍스트 설명으로부터 3D 모델을 생성합니다. Tripo P2는 먼저 프롬프트에서 컨셉 이미지를 그린 후(`image_seed`로 제어됨), 이를 바탕으로 지오메트리를 모델링합니다.

### 실행 단계

1. **프롬프트 입력**: **Tripo P2: Text to Model** 노드에 3D 모델을 설명하세요 (최대 1024자). 네거티브 프롬프트는 고급 옵션에서 사용할 수 있습니다.
2. **텍스처 레벨 선택**: `standard` (2K), `detailed` (4K), `extreme` (8K), 또는 텍스처 없는 메시를 위한 `none`
3. **쿼드 출력 토글**: `quad`가 활성화되면 메시가 FBX로 반환되고, 비활성화되면 GLB로 반환됩니다.
4. **면 제한 설정**: 목표 면 수는 48에서 50,000 사이 (쿼드 사용 시 48에서 25,000), 또는 Tripo가 선택하도록 -1로 남겨두세요
5. **실행 대기열 클릭**: `Ctrl+Enter`를 눌러 생성하세요

생성 후, 노드는 선택한 텍스처 레벨로 요청하므로 메시는 생성 단계에서 텍스처가 입혀지고, 워크플로는 그 결과를 그대로 저장합니다(GLB 출력, `quad`가 켜져 있으면 FBX). 템플릿에는 **TripoTextureNodeV2**, **TripoRigNode**, **TripoRetargetNode**, **TripoConversionNode** 노드도 포함되어 있지만 기본적으로 바이패스되고 연결되어 있지 않습니다. 이런 추가 후처리가 필요하면 연결하고 활성화하세요(선택 후 `Ctrl+B`로 바이패스를 전환).

### 쿼드 출력 참고 사항

`quad`가 활성화되면 **Save 3D**를 FBX 출력 슬롯에 연결하세요. `quad`가 비활성화되면 GLB 출력 슬롯을 사용하세요.

### 실행 단계

1. **참조 이미지 업로드**: **LoadImage** 노드로 대상의 정면 이미지를 불러옵니다
2. **텍스처 수준 선택**: `standard`, `detailed`, `extreme` 또는 `none`
3. **쿼드 출력 전환**: 활성화하면 FBX, 비활성화하면 GLB
4. **텍스처 정렬 설정**: `original_image`는 입력 이미지의 색상과 일치시키고, `geometry`는 생성된 형태에 텍스처를 맞춥니다 (고급 옵션)
5. **실행 대기열 클릭**: `Ctrl+Enter`를 눌러 생성합니다

### 입력 팁

- 저해상도 또는 저품질 이미지는 모델링 전에 `enable_image_autofix` 고급 옵션으로 개선할 수 있습니다
- `align_image` 방향은 입력 이미지의 시점에 맞게 모델을 회전시킵니다 (고급 옵션)

## Tripo P2: 멀티뷰에서 모델로

### 실행 단계

1. **참조 뷰 불러오기**: 템플릿에는 정면 뷰(`LoadImage` 노드 16)와 후면 뷰(`LoadImage` 노드 19)가 포함되어 있습니다. 이 노드는 `image_left` 및 `image_right` 입력도 제공하므로 4뷰 재구성이 가능합니다
2. **텍스처 레벨 선택**: `standard`(2K), `detailed`(4K), `extreme`(8K), 또는 `none`으로 텍스처 없는 메시

## 노드 옵션 레퍼런스

세 가지 P2 노드에서 공통으로 사용하는 옵션입니다:

| 옵션 | 값 | 기본값 | 참고 |
| ------ | ------ | ------- | ----- |
| `quad` | on / off | off | 켜면 FBX 형식의 쿼드 메시, 끄면 GLB 형식의 삼각형 메시 |
| `face_limit` | 48 ~ 50,000 (quad 사용 시 25,000) | -1 | 목표 면 수이며, 결과가 이 값을 초과할 수 있습니다 |
| `texture` | standard / detailed / extreme / none | standard | 2K / 4K / 8K 베이스 색상, none은 텍스처가 없는 메시를 반환합니다 |
| `pbr` | on / off | on | 메탈릭, 러프니스, 노멀 맵, texture가 none이면 무시됩니다 |
| `model_seed` | 0 ~ 2147483647 | 42 | 지오메트리용 시드 |

고급 옵션에는 `texture_seed`, `auto_size`(미터 단위의 실제 크기), `export_uv`, `compress_geometry`(Meshopt 압축, 압축된 메시는 훨씬 작지만 ComfyUI의 3D 뷰포트에서 미리 볼 수 없습니다)가 있습니다.
