Wan 3.0은 Alibaba의 최신 비디오 생성 모델로, 이제 파트너 노드를 통해 ComfyUI에서 사용할 수 있습니다. 단일 패스로 최대 30초의 비디오를 생성하며, 동기화된 오디오 트랙을 포함합니다. 또한 텍스트 프롬프트를 참조 이미지, 비디오, 오디오와 결합하여 일관된 캐릭터와 장면을 생성합니다.

<UpdateReminder/>

## 주요 기능

- **최대 30초**: 한 번의 패스로 일관된 모션과 오디오가 포함된 긴 클립을 생성합니다
- **기본 오디오**: 모든 출력에는 기본적으로 동기화된 오디오 트랙이 포함됩니다
- **텍스트, 이미지 및 참조 입력**: 순수 텍스트 프롬프트, 첫 프레임 애니메이션, 또는 최대 10개의 참조 이미지, 5개의 참조 비디오, 5개의 참조 오디오 클립
- **참조 태그**: 프롬프트에서 연결된 미디어를 `@Image1`, `@Video1`, `@Audio1`으로 직접 언급할 수 있습니다
- **유연한 출력**: 적응형, 16:9, 9:16, 1:1, 4:3 또는 3:4 종횡비와 함께 480p, 720p 또는 1080p 해상도 지원
- **WAN3-Prime 모델**: `model` 옵션에서 더 높은 초당 요금으로 더 높은 품질의 출력을 생성하는 `wan3.0-video-prime`도 선택할 수 있습니다
- **이중 언어 프롬프트**: 영어 또는 중국어로 프롬프트를 입력할 수 있습니다

#### 프롬프트 팁

1. **재생 시간**: 2초에서 30초 사이로 설정하거나 `auto`로 설정하여 모델이 프롬프트에 맞는 재생 시간을 선택하도록 할 수 있습니다
2. **해상도 및 비율**: 워크플로는 기본적으로 `adaptive` 비율의 720p로 제공됩니다. 특정 형식이 필요하면 1080p 또는 `16:9`와 같은 고정 비율로 전환하세요
3. **오디오**: 오디오는 기본적으로 생성됩니다. `audio` 옵션을 비활성화하면 무음 비디오를 얻을 수 있습니다
4. **프롬프트 확장**: 프롬프트 강화는 기본적으로 활성화되어 있으며 더 나은 결과를 위해 프롬프트를 다시 작성합니다. 정확한 문구가 필요하면 고급 설정에서 끄세요

#### 프롬프트 팁

1. **첫 번째 프레임**: `first_frame` 입력은 필수입니다. `last_frame` 입력은 선택 사항이며, 모델이 두 프레임 사이의 움직임을 생성합니다.
2. **적응형 비율**: `adaptive`를 사용하면 출력 크기가 입력 이미지를 따릅니다.
3. **프롬프트**: 무엇이 어떻게 움직이는지, 그리고 원하는 오디오를 설명하세요. 모델이 주제와 구성을 변경하길 원하지 않는 경우에는 주제와 구성을 그대로 유지하세요.

#### 프롬프트 팁

1. **태그로 레퍼런스 지정**: 프롬프트에서 각 입력을 `@Image1`, `@Video1`, `@Audio1`로 참조하며, 입력 순서대로 유형별 번호를 매깁니다. 샘플 프롬프트는 신발 디자인을 `@Image1`에, 캐릭터를 `@Image2`에 할당합니다.
2. **제한 사항**: 레퍼런스 이미지는 최대 10개, 레퍼런스 비디오는 최대 5개, 레퍼런스 오디오 클립은 최대 5개까지 사용할 수 있습니다. 각 레퍼런스 비디오 또는 오디오 클립은 15초 이하여야 하며, 모든 레퍼런스 비디오의 총 재생 시간도 15초 이내여야 합니다(오디오도 동일). 레퍼런스 비디오와 출력의 총 재생 시간은 30초를 초과할 수 없습니다.
3. **작업 할당**: 각 레퍼런스가 제어하는 대상(제품 디자인, 캐릭터 정체성, 스타일, 동작, 음성)과 반드시 유지되어야 할 사항을 명시하세요. 명시적인 할당은 더 일관된 결과를 생성합니다.
4. **프롬프트 또는 레퍼런스 필수**: 프롬프트를 제공하거나 최소 한 개의 레퍼런스 입력을 제공해야 합니다. 그렇지 않으면 노드에서 오류를 반환합니다.

## 시작하기

1. ComfyUI를 최신 버전으로 업데이트하거나 최신 [Comfy Desktop](https://www.comfy.org/download)을 사용하세요.
2. Template Library로 이동하여 `Wan 3.0`을 검색하세요.
3. 세 가지 워크플로(텍스트 기반 비디오 생성, 이미지 기반 비디오 생성 또는 레퍼런스 기반 비디오 생성) 중 하나를 로드하세요.
4. Comfy 계정으로 로그인하고 [크레딧](/ko/interface/credits)이 충분한지 확인하세요.
5. 입력 자료(첫 번째 프레임 또는 레퍼런스 이미지)를 연결하고 실행하세요.
