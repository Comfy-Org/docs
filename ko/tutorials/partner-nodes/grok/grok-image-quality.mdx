Grok Imagine Image Quality는 xAI의 고품질 이미지 모델로, Grok 파트너 노드를 통해 ComfyUI에서 사용할 수 있습니다. 표준 Grok 이미지 모델에 비해 개선된 디테일, 더 나은 텍스트 렌더링, 더 강력한 창의적 제어 기능을 제공합니다.

## Grok Imagine Image Quality의 강점

- **개선된 디테일**: 표준 Grok 이미지 모델보다 고품질 출력
- **더 나은 텍스트 렌더링**: 이미지에 렌더링하려는 텍스트가 포함된 프롬프트를 처리합니다
- **더 강력한 창의적 제어**: 표준 모델에 비해 생성된 결과를 더 잘 제어합니다
- **해상도 옵션**: 1K 또는 2K 출력

## 출력 예시

`grok-imagine-image-quality` 모델로 향상된 이미지 생성:
