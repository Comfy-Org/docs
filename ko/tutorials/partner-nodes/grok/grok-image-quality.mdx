Grok Imagine Image Quality는 xAI의 고품질 이미지 모델로, Grok 파트너 노드를 통해 ComfyUI에서 사용할 수 있었습니다. 표준 Grok 이미지 모델에 비해 개선된 디테일, 더 나은 텍스트 렌더링, 더 강력한 창의적 제어 기능을 제공했습니다.

## Grok Imagine Image Quality의 강점

- **개선된 디테일**: 표준 Grok 이미지 모델보다 더 높은 품질의 출력
- **더 나은 텍스트 렌더링**: 이미지에 렌더링하려는 텍스트가 포함된 프롬프트를 처리
- **더 강력한 창의적 제어**: 표준 모델에 비해 생성 결과를 더 강력하게 제어
- **해상도 옵션**: 1K 또는 2K로 출력

### 워크플로우 개요

이 워크플로우는 두 개의 노드를 사용합니다:

- **GrokImageNode**: `grok-imagine-image-quality` 모델로 구성된 핵심 노드
- **SaveImage**: 생성된 이미지를 저장합니다

### 실행 단계

1. **프롬프트 입력**: **GrokImageNode**에 장면과 렌더링하려는 텍스트를 설명하세요
2. **가로세로 비율 선택**: 사용 가능한 비율 중에서 선택하세요
3. **해상도 설정**: `1K` 또는 `2K`
4. **실행 대기열 클릭**: `Ctrl+Enter`를 눌러 생성하세요
