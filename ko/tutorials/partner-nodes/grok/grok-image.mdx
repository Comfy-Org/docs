Grok Imagine Image는 xAI의 이미지 생성 및 편집 제품군으로, ComfyUI에서 Grok 파트너 노드를 통해 사용할 수 있습니다. 텍스트 기반 이미지 생성, 참조 이미지를 사용한 자연어 이미지 편집, 고충실도 품질 모드, 그리고 14가지 종횡비에서 1K 또는 2K 출력으로 선명한 짧은 텍스트 렌더링을 제공하는 최신 Image 2.0 생성을 포함합니다.

## Grok Imagine Image 2.0: 텍스트 기반 이미지 생성

Aurora 엔진을 사용하여 단일 텍스트 프롬프트에서 전체 포스터 스타일 이미지를 생성합니다. 이 워크플로는 선명한 짧은 텍스트 렌더링에 탁월하여 포스터, 표지, 제품 및 브랜드 비주얼, 캐릭터 중심 장면에 적합합니다. 14가지 화면 비율에 걸쳐 1K 또는 2K 이미지를 출력하며, 비용을 제어할 수 있는 낮음 또는 중간 품질 옵션을 제공합니다.

### 워크플로우 개요

이 워크플로는 두 개의 노드를 사용합니다:

- **GrokImageNode**: `grok-imagine-image-2.0` 모델로 구성된 핵심 노드
- **SaveImageAdvanced**: 생성된 이미지를 PNG로 저장

### 실행 단계

1. **프롬프트 입력**: 장면, 스타일 및 렌더링하려는 텍스트를 **GrokImageNode**에 설명합니다
2. **화면 비율 선택**: `1:1`부터 `9:20`까지 14가지 비율 중에서 선택합니다
3. **해상도 선택**: 더 빠른 결과를 원하면 `1K`, 더 많은 디테일을 원하면 `2K`를 선택합니다
4. **품질 설정**: 비용과 충실도를 제어하려면 `low` 또는 `medium`을 설정합니다
5. **시드 설정**: 결과의 재현성을 제어합니다
6. **실행 대기열 클릭**: `Ctrl+Enter`를 눌러 생성합니다
