Grok은 ComfyUI에서 Grok 파트너 노드를 통해 사용할 수 있는 xAI의 생성 모델 제품군입니다. **Grok Imagine Image**로 이미지 생성과 편집을, **Grok Imagine Video**로 비디오 생성, 편집, 확장을 지원하며, 여러 모델 버전에서 사용할 수 있습니다.

<UpdateReminder/>

## Grok Imagine Image

Grok Imagine Image는 텍스트 프롬프트에서 이미지를 생성하고 자연어 지시문으로 업로드된 이미지를 편집합니다. 사용 사례에 맞는 모델을 선택하세요:

<CardGroup cols={3}>
  <Card title="Grok Imagine Image" icon="image" href="/ko/tutorials/partner-nodes/grok/grok-image">
    텍스트 기반 이미지 생성 및 이미지 편집을 위한 표준 모델로, 13개의 종횡비와 1K 또는 2K 출력을 지원합니다.
  </Card>
  <Card title="Grok Imagine Image 2.0" icon="image" href="/ko/tutorials/partner-nodes/grok/grok-image-2-0">
    Aurora 엔진 기반의 최신 이미지 모델로, 선명한 짧은 텍스트 렌더링과 최대 3개의 참조 이미지를 지원합니다.
  </Card>
  <Card title="Grok Imagine Image Quality" icon="sparkles" href="/ko/tutorials/partner-nodes/grok/grok-image-quality">
    디테일이 개선되고 텍스트 렌더링이 향상되었으며 창의적 제어가 더 강력해진 고품질 모델입니다.
  </Card>
</CardGroup>

## Grok Imagine Video

Grok Imagine Video는 텍스트 프롬프트 또는 이미지에서 짧은 비디오를 생성하고, 자연어 지시문으로 업로드된 영상을 편집하며, 클립을 매끄럽게 확장하고, 참조 이미지를 기반으로 비디오를 생성합니다.

<CardGroup cols={2}>
  <Card title="Grok Imagine Video" icon="video" href="/ko/tutorials/partner-nodes/grok/grok-video">
    표준 비디오 모델: 생성, 편집, 확장 및 레퍼런스 기반 비디오 생성 워크플로를 지원합니다.
  </Card>
  <Card title="Grok Imagine Video 1.5" icon="video" href="/ko/tutorials/partner-nodes/grok/grok-imagine-video-1-5">
    최신 비디오 모델로, 최대 1080p의 네이티브 오디오를 포함한 이미지 기반 비디오 생성을 지원합니다.
  </Card>
</CardGroup>
