**Higgsfield Genjutsu Motion Transfer**는 새 비디오를 생성하는 대신 기존 비디오를 재구성합니다. 소스 클립은 동작, 카메라 움직임, 타이밍, 오디오를 그대로 유지하면서, 출연진, 장소, 의상, 스타일은 1~8장의 참조 이미지로부터 재구성됩니다. 무엇이 달라져야 하는지 설명하면 나머지 장면은 촬영된 그대로 유지됩니다.

Higgsfield는 Genjutsu를 Motion Transfer와 Object Swap 두 가지 모드로 제공합니다. ComfyUI는 `partner/video/Higgsfield` 카테고리의 `HiggsfieldMotionTransferNode`를 통해 Motion Transfer를 노출합니다. 이 노드는 클라우드 API 노드입니다. 크레딧이 있는 Comfy 계정이 필요하고, 모델을 다운로드하지 않으며, 결과 길이가 소스 클립을 따르므로 출력 초당 과금됩니다.

이 노드는 연기가 이미 존재하고 외형만 바꾸면 될 때 유용합니다. 휴대폰 클립을 다른 캐릭터로 다시 캐스팅하거나, 촬영을 한 번도 가능하지 않았던 장소로 옮기거나, 다른 시장을 위해 푸티지를 재스타일링하거나, 하나의 테이크를 각각 따로 촬영하지 않고 여러 변형으로 제작할 수 있습니다.

## 노드 컨트롤

| 컨트롤 | 값 | 효과 |
| --- | --- | --- |
| `model` | `genjutsu-v1.0` | Genjutsu 모델. 선택하면 아래 입력이 나타납니다 |
| `video` | 4~30초 | 동작, 카메라 움직임, 타이밍, 오디오가 유지되는 소스 클립. 더 짧은 클립은 거부되고, 더 긴 클립은 처음 30초로 잘립니다 |
| `reference_images` | 1~8개 이미지 | 사용할 캐릭터, 장소 또는 스타일. 슬롯마다 이미지 하나를 연결합니다(`image_1`, `image_2` 등). 배치 입력은 이미지마다 하나로 계산되며, 모든 슬롯을 합친 총 개수는 8을 초과할 수 없습니다 |
| `prompt` | 텍스트, 선택 사항 | 결과를 설명합니다. 예를 들어 어떤 레퍼런스가 어떤 인물을 대체하는지, 또는 새로운 배경 설정을 설명합니다 |
| `resolution` | `480p`, `720p`, `1080p` | 출력 해상도, 기본값 `720p` |
| `seed` | 정수 | 노드의 재실행 여부만 제어합니다. 동일한 시드로 실행해도 결과는 달라질 수 있습니다 |

출력 길이는 준비된 소스 클립을 따르므로, 12초 클립은 12초 비디오를 반환합니다.

## 프롬프트 작성 팁

- **각 레퍼런스가 무엇을 대체하는지 명시하세요.** 프롬프트는 선택 사항이지만, 어떤 이미지가 어느 인물이나 사물에 해당하는지 밝힐 수 있는 유일한 수단입니다. 짧은 지시문 형태로 작성하세요. 예를 들어 댄서를 첫 번째 레퍼런스 이미지의 캐릭터로 바꾸고, 두 번째 이미지는 새로운 배경에 사용하도록 지정하는 식입니다.
- **레퍼런스 세트는 좁게 유지하세요.** 보통 요소당 이미지 하나면 충분합니다: 캐릭터, 장소, 의상 변경, 또는 스타일. 이미지를 더 추가하면 모델이 블렌딩할 대상이 늘어나 결과를 예측하기 어려워집니다.
- **원하는 프레이밍에 맞추세요.** 출력은 소스 클립의 모션과 카메라를 그대로 유지하므로, 프레이밍이 결과에 이미 어울리는 소스 비디오를 선택하세요. 클로즈업 퍼포먼스는 클로즈업으로 유지됩니다.
- **전체 장면이 아니라 변경 사항을 설명하세요.** 프롬프트에 언급되지 않은 모든 것은 레퍼런스에서 다시 구성되므로, 모션과 속도감, 오디오를 다시 설명할 필요가 없습니다.
- **실행할 때마다 결과가 달라질 수 있습니다.** 시드가 결과를 고정하지 않으므로, 동일한 설정으로도 다른 결과가 나올 수 있습니다.

## 시작하기

1. ComfyUI를 버전 0.40.0 이상으로 업데이트하세요
2. **Template Library**로 이동하여 `Higgsfield Genjutsu`를 검색하세요
3. `LoadVideo` 노드에 소스 클립을, `LoadImage` 노드에 참조 이미지를 로드하세요
4. 프롬프트를 작성하고 `resolution`을 선택한 다음 워크플로를 실행하세요
