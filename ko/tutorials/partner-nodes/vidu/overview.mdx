Vidu는 Shengshu Technology가 만든 빠른 AI 비디오 생성 플랫폼으로, 이제 ComfyUI 안에서 사용할 수 있습니다. 세 가지 모델 세대인 **Q1**, **Q2**, **Q3**는 폭넓은 입력을 지원하는 기초 생성부터 카메라 제어를 갖춘 3배 빠른 추론, 그리고 최신 Vidu 엔진(2.0, 3.0, 3.5)이 만들어내는 뛰어난 애니메이션 출력까지 다양한 속도와 품질 옵션을 제공합니다.

## 주요 기능

- **세대별 진화** : 워크플로에 맞춰 Q1(기초), Q2(고속 + 다중 레퍼런스 + 카메라 제어), Q3(최신 내러티브 + 애니메/2D 중심) 중에서 선택할 수 있습니다
- **빠른 추론** : Q3는 4초 클립을 최단 10초 만에 생성하며, Q2는 Q1보다 3배 빠른 속도를 제공합니다
- **풍부한 입력 모드** : 텍스트 기반 비디오 생성, 이미지 기반 비디오 생성, 레퍼런스 기반 비디오 생성(최대 7개 이미지), 시작-끝 프레임 기반 비디오 생성, 비디오 확장, 첫 프레임-마지막 프레임 기반 비디오 생성
- **카메라 언어(Q2)** : 팬, 줌, 회전 및 기타 시네마틱 무브로 정밀한 샷을 연출합니다
- **뛰어난 애니메 & 2D 애니메이션(Q3)** : 애니메이션 제작 파이프라인을 위한 업계 최고 수준의 출력 품질
- **피사체 일관성** : 다중 레퍼런스 입력 전반에서 캐릭터와 장면의 정체성을 유지합니다
