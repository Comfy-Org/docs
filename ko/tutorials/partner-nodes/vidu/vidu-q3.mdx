Vidu Q3는 Vidu 3.5 엔진으로 구동되는 가장 최신이자 가장 뛰어난 Vidu 모델 세대입니다. 최고 수준의 시각 품질을 제공하며, 특히 애니메이션과 2D 애니메이션 스타일에 강점이 있어 애니메이션 제작 파이프라인에서 최고의 선택입니다. Q3는 대화, 사운드 효과, 배경 음악을 포함한 동기화된 오디오 생성도 지원합니다.

**Pro**(최대 2K 해상도)와 **Turbo**(속도 최적화) 등급으로 제공됩니다.

## 주요 기능

- **Vidu 3.5 엔진**: Vidu 제품군 전반에서 최고의 시각 품질을 제공하는 최신 엔진
- **뛰어난 애니메이션 품질**: 2D 애니메이션 제작을 위한 업계 최고 수준의 출력
- **동기화된 오디오**: 장면에 맞는 대화, 사운드 효과, 배경 음악 생성
- **다중 해상도 지원**: 모든 모델에서 720p, 1080p를 지원하며, 이미지 기반 비디오 생성의 경우 Pro에서 2K 추가 지원
- **유연한 재생 시간**: 1초에서 16초까지 비디오 생성
- **모션 진폭 제어**: 미세한 움직임부터 역동적인 움직임까지 강도 조절
- **세 가지 생성 모드**: 텍스트 기반 비디오 생성, 이미지 기반 비디오 생성, 시작/종료 프레임 기반 비디오 생성
