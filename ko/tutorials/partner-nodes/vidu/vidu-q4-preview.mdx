**Vidu Q4 Preview**는 Vidu의 비디오 생성 모델로, ComfyUI에서 두 개의 파트너 노드를 통해 사용할 수 있습니다. 3초에서 16초 길이의 클립을 네이티브 오디오와 함께 생성하므로, 화면과 대사, 사운드 효과가 모두 한 번의 실행으로 모델에서 나옵니다. 출력은 540p부터 4K까지 지원합니다.

ComfyUI에서 **Vidu Q4 Image-to-Video Generation**은 선택적 프롬프트와 함께 단일 첫 프레임을 애니메이션화하고, **Vidu Q4 Reference-to-Video Generation**은 최대 15개의 레퍼런스 이미지, 선택적 레퍼런스 오디오, 프롬프트로 클립을 만듭니다. 둘 다 클라우드 API 노드입니다: 크레딧이 있는 Comfy 계정이 필요하며 로컬 모델을 다운로드하지 않습니다. 초당 요금은 [파트너 노드 가격](/ko/tutorials/partner-nodes/pricing)을 참고하세요.

이미지 기반 비디오 생성은 입력 이미지의 종횡비를 유지합니다. 레퍼런스 기반 비디오 생성은 명시적인 `aspect_ratio`를 받으며, 두 노드 모두 `duration`, `resolution`, `audio` 토글을 제공합니다.

### 워크플로우 개요

두 템플릿 모두 작은 그래프를 사용합니다:

- **LoadImage**: 첫 프레임(이미지 기반 비디오 생성) 또는 레퍼런스 이미지(레퍼런스 기반 비디오 생성)를 제공합니다
- **Vidu4ImageToVideoNode** / **Vidu4ReferenceVideoNode**: 핵심 노드이며 `Vidu Q4 Preview` 모델로 구성됩니다
- **SaveVideo**: 완료된 클립을 기록합니다

### 실행 단계

1. **입력 로드**: 이미지 기반 비디오 생성에서는 첫 프레임을, 레퍼런스 기반 비디오 생성에서는 레퍼런스 이미지를 설정합니다
2. **모델 선택**: 노드에서 `Vidu Q4 Preview`를 그대로 유지합니다
3. **해상도와 재생 시간 선택**: `540p`에서 `4K`까지, 그리고 3초에서 16초까지
4. **오디오 전환**: 대사와 사운드 효과를 유지하려면 켜 두고, 무음 클립을 원하면 끕니다
5. **실행 대기열 클릭** 또는 `Ctrl+Enter`를 눌러 생성합니다

## 노드 컨트롤

| 컨트롤 | 값 | 적용 대상 | 효과 |
| --- | --- | --- | --- |
| `image` | 이미지 1장 | 이미지 기반 비디오 생성 | 클립의 첫 프레임입니다. 가로세로 비율은 1:5에서 5:1 사이여야 합니다 |
| `reference_images` | 최대 15개 | 레퍼런스 기반 비디오 생성 | 슬롯당 이미지 1장이며, 하나의 슬롯에 배치로 넣은 경우 이미지 수만큼 계산됩니다. 프롬프트에서 순서대로 `image 1`, `image 2`로 지정합니다 |
| `reference_audios` | 최대 3개, 각 3~12초 | 레퍼런스 기반 비디오 생성 | 음성 레퍼런스입니다. 발음되는 단어가 아니라 목소리만 사용됩니다. `audio`가 켜져 있어야 합니다. 프롬프트에서 음성을 지정합니다. 예: `image 1 says "Hello!" in the voice from audio 1` |
| `prompt` | 텍스트, 최대 5000자 | 두 노드 모두 | 이미지 기반 비디오 생성에서는 선택 사항이고, 레퍼런스 기반 비디오 생성에서는 필수입니다 |
| `aspect_ratio` | `16:9`, `9:16`, `1:1`, `3:4`, `4:3` | 레퍼런스 기반 비디오 생성 | 출력 가로세로 비율입니다. 이미지 기반 비디오 생성은 대신 입력 이미지를 따릅니다 |
| `resolution` | `540p`, `720p`, `1080p`, `2K`, `4K` | 두 노드 모두 | 출력 해상도이며 기본값은 `720p`입니다 |
| `duration` | 3~16초 | 두 노드 모두 | 슬라이더이며 기본값은 5입니다 |
| `audio` | 켜기(기본값), 끄기 | 두 노드 모두 | 대사와 사운드 효과를 포함한 원본 오디오를 유지합니다 |
| `seed` | 정수 | 두 노드 모두 | 동일한 시드로 실행해도 결과가 달라질 수 있습니다 |

## 프롬프트 작성 팁

- **장면과 대사, 사운드를 함께 설명하세요**. 모델이 영상과 오디오를 함께 렌더링하므로, 동작과 따옴표로 묶은 대사, 주변 음향을 같은 프롬프트에 작성하세요.
- **참조는 순서로 지정하세요**. 참조 이미지는 `image 1`, `image 2`로 지칭됩니다. 각 이미지에서 무엇을 유지할지 명시하세요. 예를 들어 `image 1`에서 캐릭터의 얼굴과 의상을 유지하도록 지정합니다.
- **음성 참조에는 대사를 작성하세요**. 참조 오디오는 단어가 아니라 음성을 담고 있으므로, 프롬프트에 대사를 작성하고 음성을 지정하세요. 예: `image 1 says "Welcome back!" in the voice from audio 1`.
- **허용 범위 안에서 화면 비율을 유지하세요**. 참조 이미지는 1:5에서 5:1 사이여야 합니다.
- **실행마다 결과가 달라질 수 있습니다**. 시드는 결과를 고정하지 않으므로, 같은 설정으로도 다른 결과가 나올 수 있습니다.
