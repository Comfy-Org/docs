**HeyGen Voice 1.0** 은 한 명의 화자가 담긴 짧은 녹음을 재사용 가능한 음성으로 만들고, 그 음성으로 어떤 대본이든 읽게 합니다. 학습 대기 시간이 없습니다. 연결한 클립에서 바로 클론이 만들어지고, 반환되는 `voice_id`가 텍스트 음성 변환 노드에 필요한 전부입니다. 내 목소리로 하는 내레이션, 캐릭터 대사, 다국어 보이스오버에 적합합니다.

ComfyUI에서는 이 기능이 두 개의 파트너 노드로 실행됩니다. **HeyGen Voice 1.0 Instant Clone** 이 녹음을 받아 `voice_id`를 반환하고, **HeyGen Voice 1.0 Text to Speech** 가 그 음성으로 텍스트를 읽습니다. 둘 다 클라우드 API 노드라서 크레딧이 있는 Comfy 계정이 필요하고 로컬 모델은 내려받지 않습니다. 클론은 무료이고 텍스트 음성 변환은 1K자당 과금됩니다. 요금은 [파트너 노드 가격](/ko/tutorials/partner-nodes/pricing)을 참고하세요.

템플릿은 두 노드를 하나의 워크플로로 연결하고 오디오와 `voice_id`를 기록한 텍스트 파일을 모두 저장합니다. 다음에 다시 클론하지 않고 같은 음성을 재사용할 수 있습니다.

## HeyGen Voice 1.0이 잘하는 것

- **짧은 녹음으로 클론**: 10초의 또렷한 음성으로 충분하며, 클립의 처음 3분까지 사용합니다
- **음성 재사용**: `voice_id` 출력을 텍스트 음성 변환에 연결하거나 HeyGen Avatar Video와 HeyGen Talking Photo의 `custom_voice_id`에 넣을 수 있습니다
- **두 가지 속도**: `heygen-voice-1-turbo`는 더 빠르고 요금은 `heygen-voice-1`의 약 4분의 1입니다
- **표현력 제어**: `expressiveness_boost`는 낮으면 녹음에 가깝고 높으면 감정이 더해집니다

### 실행 단계

1. **녹음 불러오기**: **LoadAudio** 노드에 한 명의 화자가 담긴 10초 이상의 또렷한 음성을 연결합니다. 처음 3분까지만 사용됩니다
2. **음성 클론**: **HeyGen Voice 1.0 Instant Clone** 에서 `language`를 녹음 언어로 설정하고 `similarity`를 고릅니다. `seed`를 바꾸면 다시 클론되어 조금 다른 음성이 됩니다
3. **대본 작성**: **HeyGen Voice 1.0 Text to Speech** 의 `text`에 5000자 이내의 일반 텍스트를 입력하고, 클론 노드의 `voice_id` 출력을 `voice_id` 입력에 연결합니다
4. **표현력 설정**: `expressiveness_boost`는 0에서 1입니다. `0`이 녹음에 가장 가깝고 `1`이 가장 감정적입니다
5. **Queue 클릭** 또는 `Ctrl+Enter`로 생성합니다
6. **결과 저장**: 템플릿이 **SaveAudioAdvanced**로 오디오를, **SaveText**로 음성 ID를 `output/HeyGen_Voice_id/`에 저장합니다

## 노드 제어

### HeyGen Voice 1.0 Instant Clone

| 제어 | 값 | 효과 |
| --- | --- | --- |
| `audio` | 오디오 하나 | 한 명의 화자 녹음. 10초 이상을 권장하며 처음 3분까지 사용합니다 |
| `language` | `auto` 또는 언어 | 녹음에서 말하는 언어 |
| `similarity` | `medium`, `high`, `extra_high`, `max`(기본값) | 클론한 음성이 녹음에 얼마나 가까운지 |
| `remove_background_noise` | 기본값 켜짐 | 클론 전에 녹음을 정리합니다 |
| `seed` | 기본값 42 | 바꾸면 다시 클론되며 매번 조금 다른 음성이 됩니다 |

### HeyGen Voice 1.0 Text to Speech

| 제어 | 값 | 효과 |
| --- | --- | --- |
| `model` | `heygen-voice-1`, `heygen-voice-1-turbo` | turbo는 더 빠르고 요금은 약 4분의 1입니다 |
| `voice_id` | 클론된 음성 ID | Instant Clone 노드의 출력 |
| `text` | 1 ~ 5000자 | 읽을 대본. 약 12분을 넘는 음성은 실패하므로 아주 긴 중국어나 일본어 텍스트는 나눠 주세요 |
| `language` | `auto` 또는 언어 | 세르비아어, 말레이어처럼 자동 감지가 혼동하기 쉬운 언어는 직접 지정합니다 |
| `expressiveness_boost` | 0.0 ~ 1.0, 기본값 0.5 | 값이 높을수록 표현이 풍부하고 낮을수록 원래 음성에 가깝습니다 |

## 제한 사항

- 클론에는 녹음의 처음 3분까지 사용되며, 실질적으로 10초 이상의 또렷한 음성이 필요합니다.
- 텍스트는 5000자, 약 12분 분량까지입니다. 일반 텍스트만 허용되고 그 외에는 거부됩니다.
- 인스턴트 음성은 텍스트 음성 변환에서 `seed`, `speed`, `pitch`를 무시합니다. 전달 방식은 `expressiveness_boost`로만 조정합니다.
- `voice_id`는 클론에서 가져와야 합니다. 비어 있으면 오류가 발생합니다.
- 클론은 무료이고, 텍스트 음성 변환은 모델 요율로 1K자당 과금됩니다.
