**HeyGen Voice 1.0** 은 한 명의 화자가 담긴 짧은 녹음을 재사용 가능한 음성으로 만들고, 그 음성으로 어떤 대본이든 말하게 합니다. 학습 대기 시간은 없습니다. 연결한 클립에서 곧바로 복제가 만들어지며, 반환되는 `voice_id` 만 있으면 텍스트 기반 음성 생성 노드가 동작합니다. 내 목소리로 하는 내레이션, 캐릭터 대사, 다국어 보이스오버를 위해 만들어졌습니다.

ComfyUI에서 이 기능은 세 개의 파트너 노드로 실행됩니다. **HeyGen Voice 1.0 Instant Clone Text to Speech** 는 복제와 발화를 한 단계로 처리하고, **HeyGen Voice 1.0 Instant Clone** 은 녹음을 받아 재사용할 `voice_id` 를 반환하며, **HeyGen Voice 1.0 Text to Speech** 는 저장된 음성으로 작성된 텍스트를 읽습니다. 모두 클라우드 API 노드이므로 크레딧이 있는 Comfy 계정이 필요하고 로컬 모델은 다운로드하지 않습니다. 복제는 무료이며 텍스트 기반 음성 생성은 1K자당 과금됩니다. 요금은 [파트너 노드 가격](/ko/tutorials/partner-nodes/pricing)을 참고하세요.

템플릿은 두 노드를 서로 연결하고 두 가지 출력을 모두 저장합니다. 즉, 음성 오디오와 `voice_id` 가 적힌 텍스트 파일을 저장하여, 나중에 다시 복제하지 않고도 같은 음성을 재사용할 수 있습니다.

## HeyGen Voice 1.0이 잘하는 것

- **짧은 녹음으로 클론**: 10초의 또렷한 음성으로 충분하며, 클립의 처음 3분까지 사용합니다
- **음성 재사용**: `voice_id` 출력을 텍스트 음성 변환에 연결하거나 HeyGen Avatar Video와 HeyGen Talking Photo의 `custom_voice_id`에 넣을 수 있습니다
- **두 가지 속도**: `heygen-voice-1-turbo`는 더 빠르고 요금은 `heygen-voice-1`의 약 4분의 1입니다
- **표현력 제어**: `expressiveness_boost`는 낮으면 녹음에 가깝고 높으면 감정이 더해집니다

### 실행 단계

1. **녹음 불러오기**: **LoadAudio** 노드에 한 명의 화자가 담긴 10초 이상의 또렷한 음성을 연결합니다. 처음 3분까지만 사용됩니다
2. **음성 클론**: **HeyGen Voice 1.0 Instant Clone** 에서 `language`를 녹음 언어로 설정하고 `similarity`를 고릅니다. `seed`를 바꾸면 다시 클론되어 조금 다른 음성이 됩니다
3. **대본 작성**: **HeyGen Voice 1.0 Text to Speech** 의 `text`에 5000자 이내의 일반 텍스트를 입력하고, 클론 노드의 `voice_id` 출력을 `voice_id` 입력에 연결합니다
4. **표현력 설정**: `expressiveness_boost`는 0에서 1입니다. `0`이 녹음에 가장 가깝고 `1`이 가장 감정적입니다
5. **Queue 클릭** 또는 `Ctrl+Enter`로 생성합니다
6. **결과 저장**: 템플릿이 **SaveAudioAdvanced**로 오디오를, **SaveText**로 음성 ID를 `output/HeyGen_Voice_id/`에 저장합니다

## 노드 제어

### HeyGen Voice 1.0 Instant Clone

| 제어 | 값 | 효과 |
| --- | --- | --- |
| `audio` | 오디오 클립 1개 | 한 명의 화자 녹음. 10초 이상을 권장하며 처음 3분까지만 사용합니다 |
| `language` | `auto` 또는 언어 | 녹음에서 말하는 언어 |
| `similarity` | `medium`, `high`, `extra_high`, `max`(기본값) | 복제한 음성이 녹음에 얼마나 가까운지 |
| `remove_background_noise` | 기본값 켜짐 | 복제 전에 녹음을 정리합니다 |
| `seed` | 기본값 42 | 바꾸면 다시 복제되며 매번 조금 다른 음성이 됩니다 |

### HeyGen Voice 1.0 Text to Speech

| 제어 | 값 | 효과 |
| --- | --- | --- |
| `model` | `heygen-voice-1`, `heygen-voice-1-turbo` | Turbo는 더 빠르고 요금은 약 4분의 1입니다 |
| `voice_id` | 복제된 음성 ID | Instant Clone 노드의 출력 |
| `text` | 1 ~ 5000자 | 읽을 대본. 약 12분을 넘는 음성은 실패하므로 아주 긴 중국어나 일본어 텍스트는 나눠 주세요 |
| `language` | `auto` 또는 언어 | 세르비아어, 말레이어처럼 자동 감지가 혼동하기 쉬운 언어는 직접 지정합니다 |
| `expressiveness_boost` | 0.0 ~ 1.0, 기본값 0.5 | 값이 높을수록 표현이 풍부하고 낮을수록 원래 음성에 가깝습니다 |

### HeyGen Voice 1.0 Instant Clone Text to Speech

음성 복제와 대본 낭독을 한 노드에서 처리하므로 넘겨줄 `voice_id`가 없습니다. 오디오를 바로 반환합니다.

| 제어 | 값 | 효과 |
| --- | --- | --- |
| `model` | `heygen-voice-1`, `heygen-voice-1-turbo` | Turbo는 더 빠르고 요금은 약 4분의 1입니다 |
| `audio` | 오디오 클립 1개 | 한 명의 화자 녹음. 처음 3분까지만 사용합니다 |
| `text` | 1 ~ 5000자 | 읽을 대본 |
| `recording_language` | `auto` 또는 언어 | 자동 감지가 잘못 판별할 때 지정하는, 녹음에서 말하는 언어 |
| `language` | `auto` 또는 언어 | 대본이 녹음의 언어와 다를 때 말할 언어 |
| `similarity` | `medium`, `high`, `extra_high`, `max`(기본값) | 복제한 음성이 녹음에 얼마나 가까운지 |
| `remove_background_noise` | 기본값 켜짐 | 복제 전에 녹음을 정리합니다 |
| `expressiveness_boost` | 0.0 ~ 1.0, 기본값 0.5 | 값이 높을수록 표현이 풍부하고 낮을수록 원래 음성에 가깝습니다 |
| `seed` | 기본값 42 | 바꾸면 다시 복제되며 매번 조금 다른 음성이 됩니다 |

음성을 한 번만 사용할 때는 결합 노드를 사용하세요. `voice_id`가 실행 이후에도 유지되어야 하는 경우, 예를 들어 HeyGen 아바타 비디오나 Talking Photo의 `custom_voice_id`로 써야 하는 경우에는 대신 **Instant Clone**과 **Text to Speech**를 사용하세요. 독립형 **Instant Clone** 노드는 새 워크플로에서 지원 중단됨으로 표시되어 있습니다. 여전히 복제를 수행하고 `voice_id`를 반환하며, 결합 노드가 주된 사용 사례를 대신 처리합니다.

## 제한 사항

- 클론에는 녹음의 처음 3분까지 사용되며, 실질적으로 10초 이상의 또렷한 음성이 필요합니다.
- 텍스트는 5000자, 약 12분 분량까지입니다. 일반 텍스트만 허용되고 그 외에는 거부됩니다.
- 인스턴트 음성은 텍스트 음성 변환에서 `seed`, `speed`, `pitch`를 무시합니다. 전달 방식은 `expressiveness_boost`로만 조정합니다.
- `voice_id`는 클론에서 가져와야 합니다. 비어 있으면 오류가 발생합니다.
- 클론은 무료이고, 텍스트 음성 변환은 모델 요율로 1K자당 과금됩니다.
