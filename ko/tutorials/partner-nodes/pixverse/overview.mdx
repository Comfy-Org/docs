PixVerse는 텍스트와 이미지에서 시네마틱 비디오를 생성하는 AI 비디오 생성 플랫폼이며, 이제 ComfyUI의 파트너 노드로 통합되었습니다. **V5.6**, **V6**, **C1**, **R1** 모델을 지원하므로 별도의 API 키나 외부 설정 없이 **텍스트 기반 비디오 생성**, **이미지 기반 비디오 생성**, **템플릿 이미지 기반 비디오 생성** 모드를 사용해 빠르고 반복 가능한 비디오 제작이 가능합니다.

<UpdateReminder/>

## 주요 기능

- **텍스트 기반 비디오 생성**: 텍스트 프롬프트에서 원본 비디오를 생성합니다. 콘셉트 시각화, 스토리보드 작성, 빠른 창의적 탐색에 적합합니다.
- **이미지 기반 비디오 생성**: 피사체의 정체성과 장면 구성을 유지하면서 참조 이미지를 애니메이트하여, 정적인 비주얼에 자연스러운 움직임을 더해 생동감을 줍니다.
- **템플릿 이미지 기반 비디오 생성**: 입력 이미지에 미리 정의된 모션 템플릿을 적용하여 예측 가능하고 반복 가능한 애니메이션 스타일을 구현하며, 제작 파이프라인에 적합합니다.
