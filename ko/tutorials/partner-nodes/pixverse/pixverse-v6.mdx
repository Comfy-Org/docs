**PixVerse V6**는 텍스트 프롬프트로 비디오를 생성하거나, 정지 이미지에 움직임을 주거나, 레퍼런스 피사체와 배경으로 장면을 구성합니다. **PixVerse V6 Max**는 같은 제품군에서 충실도가 더 높은 등급이며, 텍스트 기반 및 이미지 기반 비디오 생성 노드에서 모델 옵션으로 선택할 수 있습니다.

ComfyUI는 파트너 노드를 통해 이 제품군을 실행합니다: **PixVerse V6 Text to Video**, **PixVerse V6 Image to Video**, **PixVerse V6 Fusion (Reference to Video)**. 이들은 클라우드 API 노드이므로 크레딧이 있는 Comfy 계정이 필요하며, 모델 파일을 로컬로 다운로드하지 않습니다.

클립은 360p, 540p, 720p, 1080p에서 1초에서 15초 길이로 생성되며, 기본적으로 네이티브 오디오 트랙이 함께 생성됩니다. PixVerse V6는 한 번의 생성 안에서 스타일 프리셋과 멀티샷 컷 편집을 추가합니다. V6 Max는 더 높은 충실도로 렌더링하며 스타일 프리셋은 제공하지 않습니다. PixVerse는 시드를 기록하지만 시드로부터 동일한 실행을 재현하지는 않습니다.

### 레퍼런스 기반 비디오 생성 (Fusion)

자신의 피사체를 자신의 장면에 배치합니다. 이미지를 피사체 또는 배경으로 연결하고, 프롬프트에서 각 슬롯 이름으로 참조하세요. 예를 들어 `@Subject1 walks through @Background1`처럼 사용합니다. Fusion은 PixVerse V6에서만 동작합니다. 레퍼런스 비디오를 연결하면 노드가 Omni 모드로 전환됩니다. 그러면 출력 길이가 가장 긴 레퍼런스 비디오와 일치하며, 해당 비디오가 모션, 프레이밍 또는 스타일을 제공할 수도 있습니다.

## 노드 컨트롤

| 컨트롤 | 값 | 적용 대상 | 효과 |
| --- | --- | --- | --- |
| `model` | `PixVerse V6`, `PixVerse V6 Max` | 텍스트 기반 및 이미지 기반 비디오 생성(두 등급 모두), Fusion(V6만) | 모델 등급과 해당 등급에서 제공하는 설정 |
| `prompt` | 텍스트, 최대 5000자 | 모든 V6 노드 | 샷 설명: 피사체, 동작, 카메라, 라이트 |
| `negative_prompt` | 텍스트, 최대 2048자 | 모든 V6 노드 | 프레임에서 제외할 요소 |
| `quality` | `360p`, `540p`, `720p` (기본값), `1080p` | 모든 V6 노드 | 출력 해상도 등급. 프레임 크기는 화면 비율에 따라서도 달라집니다 |
| `aspect_ratio` | `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `2:3`, `3:2`, `21:9`, 그리고 Fusion에서는 `auto` | 텍스트 기반 비디오 생성, Fusion | 프레임 형태. `auto`에는 참조 비디오가 필요합니다 |
| `duration_seconds` | 1~15, 기본값 5 | 모든 V6 노드 | 클립 길이 |
| `generate_audio` | 기본값 켜짐 | 모든 V6 노드 | 비디오와 함께 네이티브 오디오 트랙을 렌더링합니다 |
| `multi_clip` | 기본값 꺼짐 | 텍스트 기반 비디오 생성(두 등급 모두), V6의 이미지 기반 비디오 생성 | 모델이 클립을 여러 샷으로 분할하도록 합니다 |
| `style` | `none`, `anime`, `3d_animation`, `clay`, `comic`, `cyberpunk`, `realistic` | V6 전용 | 클립 전체에 적용되는 룩. V6 Max에서는 사용 불가 |
| `seed` | 정수 | 모든 V6 노드 | PixVerse에 기록되지만 실행 재현에는 사용되지 않습니다 |
| `subjects` | 이미지 최대 8개 | Fusion | `@Subject1`부터 `@Subject8`로 장면에 배치되는 사람 또는 객체 |
| `backgrounds` | 이미지 최대 2개 | Fusion | 피사체가 배치되는 장면이며, `@Background1`, `@Background2`로 참조됩니다 |
| `videos` | 최대 2개, 총 15초 | Fusion | `@Video1`, `@Video2`로 읽는 참조 영상. Omni 모드도 켭니다 |

Fusion은 참조 비디오가 연결되지 않았을 때 최대 7개의 참조 이미지를, 연결된 경우 최대 10개를 허용합니다. 이미지 기반 비디오 생성은 입력 이미지의 화면 비율을 유지하므로 여기서는 `aspect_ratio`를 제공하지 않습니다.

## 프롬프트 작성 팁

- **분위기가 아니라 샷을 쓰세요.** 피사체, 동작, 카메라 무빙, 라이트를 담은 한 문단이 모델에게 렌더링할 거리를 제공합니다: `low-angle tracking shot, a courier runs past neon signs, cool blue grade`. 형용사만 나열하면 대개 흐지부지됩니다.
- **오디오를 유지할 때는 오디오를 설명하세요.** 발소리, 충격음, 앰비언스, 음악 스타일이 모두 생성된 트랙에 반영됩니다. 직접 사운드를 추가할 계획이라면 `generate_audio`를 끄세요.
- **시퀀스에는 `multi_clip`을 사용하세요.** 한 번의 생성으로 일관된 룩의 여러 샷을 얻는 방법이며, 이때 프롬프트에서 샷에 번호를 매겨야 합니다.
- **Fusion에서는 모든 레퍼런스에 레이블을 붙이세요.** 프롬프트에서 언급되지 않은 연결한 피사체나 배경은 대개 무시되므로, 동작에서 해당 위치에 `@Subject1`과 `@Background1`을 쓰세요.
- **네거티브는 짧고 구체적으로 유지하세요.** `text, watermark, logo, subtitles, oversaturated colors`가 스타일 단어를 길게 나열하는 것보다 효과적입니다.
- **시드 재현성을 쫓지 마세요.** 시드는 참고용으로만 저장되므로, 같은 시드로 다시 실행하면 새로운 생성입니다.
