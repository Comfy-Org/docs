OpenAI는 생성형 AI에 특화된 기업으로, 강력한 대화 기능을 제공합니다. 현재 ComfyUI에는 OpenAI API가 통합되어 있어, ComfyUI에서 관련 노드를 직접 사용하여 대화 기능을 수행할 수 있습니다.

**GPT-6 Astra** 는 OpenAI의 가장 강력한 모델로, 가장 어려운 엔드투엔드 작업을 위해 구축되었습니다: 복잡한 추론, 코딩, 컴퓨터 조작, 리서치, 문서 작성. 2026년 9월 3일에 출시되었으며, 1,050,000 토큰 컨텍스트 윈도우, 텍스트 및 이미지 입력, `low`부터 `max`까지의 reasoning effort 레벨을 지원합니다. ComfyUI에서는 `OpenAI Chat` 노드의 모델 목록에 표시되며, 이미지 분석 및 프롬프트 생성 작업을 위한 예제 템플릿도 함께 제공됩니다.

## OpenAI Chat의 강점

- **지능형 대화**: ComfyUI 내부에서 직접 OpenAI의 고급 언어 모델과 대화할 수 있습니다.
- **이미지 이해**: AI가 해석하고 응답할 수 있도록 이미지를 로드할 수 있습니다.
- **작업 제어**: `OpenAI Chat Advanced Options`를 조정하여 AI가 이미지 분석 및 프롬프트 생성과 같은 특정 작업을 실행하도록 할 수 있습니다.
- **모델 선택**: `OpenAI Chat` 노드에서 다양한 OpenAI 모델을 선택할 수 있습니다.
- **다중 이미지 입력**: 둘 이상의 이미지에 AI 해석이 필요한 경우 여러 이미지를 함께 배치할 수 있습니다.

## 워크플로 실행을 단계별로 완료하기

![OpenAI Chat 단계별 가이드](/images/tutorial/api_nodes/openai/openai_chat_step_guide.jpg)

<Note>
해당 템플릿에는 프롬프트 생성을 분석하는 역할 설정이 마련되어 있습니다.
</Note>

이미지에 표시된 번호를 참조하여 기본 텍스트 기반 이미지 생성 워크플로 실행을 완료할 수 있습니다:  
1. `Load Image` 노드에서 AI가 해석해야 하는 이미지를 로드합니다.
2. (선택 사항) 필요한 경우 `OpenAI Chat Advanced Options`의 설정을 수정하여 AI가 특정 작업을 실행하도록 할 수 있습니다.
3. `OpenAI Chat` 노드에서 `Prompt`를 수정하여 대화 프롬프트를 설정하거나, `model`을 수정하여 다른 모델을 선택할 수 있습니다.
4. `Run` 버튼을 클릭하거나 단축키 `Ctrl(cmd) + Enter`를 사용하여 대화를 실행합니다.
5. API가 결과를 반환할 때까지 기다린 후 `Preview Any` 노드에서 AI가 반환한 해당 콘텐츠를 확인할 수 있습니다.

## 추가 참고 사항

- 현재 파일 입력 노드인 `OpenAI Chat Input Files`는 `ComfyUI/input/` 디렉토리에 파일을 먼저 업로드해야 합니다. 이 노드는 개선 중이며, 업데이트 이후 템플릿을 수정할 예정입니다.
- 이 워크플로는 입력으로 `Batch Images`를 사용하는 예시를 제공합니다. AI 해석이 필요한 여러 이미지가 있는 경우, 단계 다이어그램을 참조하고 마우스 오른쪽 버튼을 클릭하여 해당 노드 모드를 `Always`로 설정하면 활성화할 수 있습니다.

2. `OpenAI Chat` 노드에서 필요에 따라 분석 프롬프트를 조정하거나 `model`을 전환합니다

GPT-6 Astra는 API 토큰 사용량을 기준으로 청구되며, 다른 OpenAI Chat 모델보다 요율이 높습니다. 자세한 내용은 [가격표](/ko/tutorials/partner-nodes/pricing)를 참조하세요.
