**GPT-6 Astra** 는 OpenAI의 가장 강력한 모델로, 가장 어려운 엔드투엔드 작업을 위해 구축되었습니다: 복잡한 추론, 코딩, 컴퓨터 조작, 리서치, 문서 작성. 2026년 9월 3일에 출시되었으며, 1,050,000 토큰 컨텍스트 윈도우, 텍스트 및 이미지 입력, `low`부터 `max`까지의 reasoning effort 레벨을 지원합니다.

ComfyUI에서는 GPT-6 Astra를 `OpenAI Chat` 노드를 통해 사용할 수 있습니다: 노드의 `model` 드롭다운에서 `gpt-6-astra`를 선택하세요. 노드의 기본 사용법은 [OpenAI Chat 튜토리얼](/ko/tutorials/partner-nodes/openai/chat)을 참조하세요.

## GPT-6 Astra 템플릿

별도의 템플릿은 GPT-6 Astra가 이미지를 분석하고 이를 기반으로 구조화된 AI 아트 프롬프트를 생성하는 과정을 보여줍니다. 이 워크플로는 이미지를 로드하고, `model`이 `gpt-6-astra`로 설정된 `OpenAI Chat` 노드에 분석 프롬프트를 전송한 후, `Save Text`를 통해 결과를 텍스트 파일로 저장합니다.

**입력 소재**

다음 파일을 해당 `LoadImage` 노드에 업로드하세요:

<CardGroup cols={2}>
  <Card title="blue_poppies_field.png" icon="image" href="https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/input/blue_poppies_field.png">
    `LoadImage` 노드 · `blue_poppies_field.png`
  </Card>
</CardGroup>

단계:

1. `LoadImage` 노드에서 이미지를 로드합니다
2. `OpenAI Chat` 노드에서 필요에 따라 분석 프롬프트를 조정하거나 `model`을 전환합니다
3. `Run`을 클릭합니다. 생성된 프롬프트는 미리보기에 표시되며 `Save Text` 노드를 통해 `.txt` 파일로 저장됩니다

GPT-6 Astra는 API 토큰 사용량을 기준으로 청구되며, 다른 OpenAI Chat 모델보다 요율이 높습니다. 자세한 내용은 [가격표](/ko/tutorials/partner-nodes/pricing)를 참조하세요.
