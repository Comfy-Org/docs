**GPT-6 Astra** 는 OpenAI의 가장 강력한 모델로, 가장 어려운 엔드투엔드 작업을 위해 구축되었습니다: 복잡한 추론, 코딩, 컴퓨터 조작, 리서치, 문서 작성. 2026년 9월 3일에 출시되었으며, 1,050,000 토큰 컨텍스트 윈도우, 텍스트 및 이미지 입력, `low`부터 `max`까지의 reasoning effort 레벨을 지원합니다.

ComfyUI에서는 GPT-6 Astra를 `OpenAI Chat` 노드를 통해 실행합니다: 노드의 `model` 드롭다운에서 `gpt-6-astra`를 선택하세요. 이 페이지는 ComfyUI 워크플로에서 모델을 사용하는 방법에 중점을 둡니다. 모든 모델에 공통되는 노드 기본 사용법은 [OpenAI Chat 튜토리얼](/ko/tutorials/partner-nodes/openai/chat)을 참조하세요.

## GPT-6 Astra를 선택해야 하는 경우

`OpenAI Chat` 노드에는 `gpt-5-nano`부터 `gpt-6-astra`까지 다양한 모델이 있습니다. GPT-6 Astra는 가장 강력하지만 가장 비싸므로, 저렴한 모델이 어려워하는 작업에 적합합니다:

- **긴 컨텍스트 이미지 분석**: `Batch Images`로 여러 이미지나 큰 프롬프트 파일을 입력하고 한 번에 구조화된 분석 수행
- **프롬프트 엔지니어링**: 참조 이미지나 대략적인 아이디어를 이미지·비디오 모델용 상세한 쉼표 구분 positive 프롬프트로 변환
- **에이전트형 워크플로**: 데이터셋 설명 분석, 생성 계획 수립, 프롬프트 작성 같은 다단계 작업
- **복잡한 지시 이행**: JSON, YAML, 고정 섹션 순서 등 작은 모델이 자주 깨는 정확한 출력 형식

단순한 캡션이나 짧은 답변에는 `gpt-5`나 `gpt-5-mini`도 저렴한 비용으로 좋은 결과를 냅니다. 모델별 요금은 [가격표](/ko/tutorials/partner-nodes/pricing)를 참조하세요.

## OpenAI Chat 노드에서 모델 사용하기

`OpenAI Chat` 노드의 입력:

- `prompt`: 지시문. 프롬프트 생성 작업에서는 이미지에서 무엇을 추출하고 어떤 출력 형식을 원하는지 정확히 기술합니다
- `images`: 선택적 이미지 컨텍스트. `LoadImage`를 연결하고, 여러 이미지는 `Batch Images`를 사용합니다. 연결된 모든 이미지가 모델에 전송됩니다
- `files`: `OpenAI Chat Input Files` 노드의 선택적 문서
- `advanced_options`: `OpenAI Chat Advanced Options` 노드의 선택적 설정

출력은 `String`입니다. 대표적인 다운스트림 활용:

- `Preview Any` 노드에 연결하여 응답 확인
- `Save Text`에 연결하여 생성된 프롬프트를 `.txt` 파일로 저장
- `CLIP Text Encode` 노드의 positive 프롬프트 입력에 연결하여, LLM이 프롬프트를 작성하는 완전 자동화된 이미지·비디오 생성 파이프라인 구축
- 파트너 노드의 텍스트 입력에 연결하여, 비디오 생성 전 장면 설명 초안 작성 등에 활용

## 추론 effort

GPT-6 Astra는 추론 모델입니다. `OpenAI Chat Advanced Options` 노드를 연결하고 `reasoning_effort`를 설정하여 응답 품질과 비용의 균형을 조절할 수 있습니다:

| 레벨 | 동작 |
|------|------|
| `default` | 모델이 자동 선택 |
| `low` | 가장 빠르고 저렴. 단순한 분석에 적합 |
| `medium` | 프롬프트 생성의 균형 잡힌 기본값 |
| `high` | 복잡한 이미지나 지시에 대한 철저한 분석 |
| `xhigh` | 깊은 다단계 추론 |
| `max` | 가장 어려운 작업의 최대 추론 |

같은 노드에는 `max_output_tokens`(16~16384, 추론 토큰 포함)와 `instructions` 필드도 있습니다. `instructions`는 영구 시스템 프롬프트 역할을 하며, 여러 번 실행할 때 출력 형식을 고정하는 데 유용합니다.

단계:

1. `LoadImage` 노드에서 이미지를 로드합니다
2. `OpenAI Chat` 노드에서 필요에 따라 분석 프롬프트를 조정하거나 `model`을 전환합니다. 템플릿의 프롬프트는 피사체, 구도, 카메라, 조명, 색감, 질감, 스타일을 추출하고 쉼표 구분 positive 프롬프트만 출력하도록 모델에 지시합니다
3. `Run`을 클릭합니다. 생성된 프롬프트는 미리보기에 표시되며 `Save Text` 노드를 통해 `.txt` 파일로 저장됩니다

더 나아가려면 저장한 프롬프트를 `CLIP Text Encode` 노드나 이미지·비디오 모델 노드에 복사하여, 모델의 출력으로 바로 생성할 수 있습니다.

GPT-6 Astra는 API 토큰 사용량을 기준으로 청구되며, 다른 OpenAI Chat 모델보다 요율이 높습니다. 자세한 내용은 [가격표](/ko/tutorials/partner-nodes/pricing)를 참조하세요.
