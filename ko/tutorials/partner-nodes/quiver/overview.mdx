Quiver는 텍스트 설명과 래스터 이미지로부터 고품질 SVG를 생성하는 AI 기반 벡터 그래픽 플랫폼으로, 이제 ComfyUI에서 파트너 노드로 사용할 수 있습니다. **Arrow 1.1**(빠름)부터 **Arrow 1.1 Max**(고충실도), **Arrow Preview**(실험적)까지의 모델을 갖추고 있어 수동 편집 없이 해상도에 독립적인 벡터 아트워크를 생성합니다.

## 주요 기능

- **Text-to-SVG**: 자연어 설명으로 완전히 편집 가능한 SVG 벡터 그래픽을 생성합니다. 아이콘, 로고, 일러스트레이션, UI 요소에 적합합니다.
- **Image-to-SVG**: 래스터 이미지(PNG, JPG)의 형태, 색상, 그라디언트를 추적하여 깔끔하고 확장 가능한 SVG 벡터 그래픽으로 변환합니다.
- **Arrow 1.1**: 대부분의 사용 사례에 적합한 빠르고 효율적인 SVG 생성을 제공하는 표준 모델입니다.
- **Arrow 1.1 Max**: 복잡한 일러스트레이션에서 상세하고 정확한 벡터 출력을 위한 고품질 변형입니다.
- **Arrow Preview**: 실험적 기능과 향후 모델 개선 사항을 미리 사용해 볼 수 있습니다.
