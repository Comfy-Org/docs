Quiver SVG는 **Text-to-SVG** 및 **Image-to-SVG** 모드를 통해 ComfyUI에서 바로 해상도에 독립적인 벡터 그래픽을 생성합니다. Arrow 1.1, Arrow 1.1 Max, Arrow Preview를 포함한 모델로 빠른 아이콘 생성부터 복잡한 일러스트 벡터화까지 처리합니다.

<ReqHint/>
<UpdateReminder/>

## 주요 기능

- **Text-to-SVG**: 자연어 설명으로부터 완전히 편집 가능한 SVG 벡터 그래픽을 생성합니다. 아이콘, 로고, 일러스트, UI 요소에 적합합니다.
- **Image-to-SVG**: 래스터 이미지(PNG, JPG)의 형태, 색상, 그라디언트를 추적하여 깔끔하고 확장 가능한 SVG 벡터 그래픽으로 변환합니다.

## 사용 가능한 워크플로

### Text-to-SVG

원하는 벡터 그래픽을 자연어로 설명하면 Quiver가 깔끔하고 편집 가능한 SVG를 생성합니다. 아이콘, 로고, 다이어그램, 일러스트, UI 구성 요소를 만드는 데 사용하세요.
