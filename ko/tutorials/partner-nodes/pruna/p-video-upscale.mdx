Pruna P-Video Upscale은 완료된 클립을 720p, 1080p, 2K 또는 4K로 확대합니다. 출력은 소스 비디오의 화면 비율과 오디오 트랙을 유지합니다. 프레임 레이트는 소스 레이트로 유지되거나 최대 60 fps까지 보간되며, 더 낮은 값을 지정하면 프레임이 버려집니다.

이 노드는 `partner/video/Pruna` 카테고리에 있는 **Pruna P-Video Upscale**입니다. **비디오 불러오기** 노드나 같은 워크플로의 생성 작업에서 나온 모든 비디오 출력을 받아 업스케일된 클립을 반환하므로, 텍스트 기반 비디오 생성 또는 이미지 기반 비디오 생성 노드 뒤에 연결할 수 있습니다.

Comfy API를 통해 Pruna의 서버에서 실행됩니다. 모델 다운로드나 로컬 GPU가 필요 없으며, 크레딧이 있는 Comfy API 계정만 있으면 됩니다.

## 워크플로에 추가하기

1. **노드 추가**: 캔버스를 마우스 오른쪽 버튼으로 클릭하고 `partner/video/Pruna` 아래에서 **Pruna P-Video Upscale**을 검색합니다
2. **비디오 연결**: 비디오 출력을 `video` 입력에 연결합니다
3. **대상 선택**: `720p`, `1080p`(기본값), `2K` 또는 `4K`
4. **프레임 레이트 설정**: `source`는 입력 레이트를 최대 60 fps까지 유지하며, 소스보다 높은 레이트는 보간되고 낮은 레이트는 프레임이 버려집니다
5. **결과 저장**: 출력을 **Save Video** 노드에 연결합니다
6. **실행 대기열 클릭**: `Ctrl+Enter`를 눌러 실행합니다

## 노드 컨트롤

| 컨트롤 | 값 | 효과 |
| --- | --- | --- |
| `video` | 비디오 | 업스케일할 클립. 512 MiB 제한은 노드가 만드는 MP4에 적용되며 불러온 파일 자체에는 적용되지 않습니다 |
| `target` | `720p`, `1080p`, `2K`, `4K` | 출력 픽셀 면적이 약 0.9, 2.1, 3.7 또는 8.3 메가픽셀입니다. 기본값 `1080p` |
| `fps` | `source`, `16`, `24`, `25`, `30`, `48`, `50`, `60` | 출력 프레임 레이트입니다. `source`는 입력의 레이트를 유지하며 최대 60으로 제한됩니다. 더 낮은 값을 지정하면 프레임이 버려집니다 |
| `turbo` | 켜기 / 끄기 | 동일한 가격에 더 부드러운 디테일로 더 빠르게 업스케일합니다 |

## 제한 사항

- 대상보다 큰 소스는 원래 크기로 반환되므로, 1080p 클립에 `720p`를 지정해도 1920×1080으로 나옵니다
- 길이는 `720p`, `1080p`, `2K`, `4K` 대상별로 각각 2400, 1200, 600, 300 프레임으로 제한되며, 최대 30 fps 기준으로 계산됩니다. 24 fps에서는 약 100, 50, 25, 12.5초입니다
- 10메가픽셀을 초과하는 클립은 `2K` 또는 `4K`를 대상으로 해야 합니다
- 입력은 업로드 전에 H.264 MP4로 다시 인코딩되며, 512 MiB 제한은 원본 파일이 아니라 이렇게 준비된 파일에 적용됩니다. 오디오 트랙은 결과물까지 그대로 유지됩니다
- 30 fps를 초과하는 출력은 초당 요금이 두 배로 부과되며, `source`로 30 fps를 넘는 소스 레이트를 유지할 때도 같습니다

## 가격

Pruna P-Video Upscale은 출력 비디오의 초 단위로 과금되며, 요금은 대상에 따라 달라집니다. 현재 요금은 [파트너 노드 가격](/ko/tutorials/partner-nodes/pricing)을 참고하세요.
