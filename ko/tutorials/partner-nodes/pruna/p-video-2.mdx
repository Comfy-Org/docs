Pruna P-Video-2는 품질 중심의 Pruna 비디오 생성 모델로, ComfyUI에서는 네 가지 파트너 노드로 사용할 수 있습니다: **Pruna P-Video-2 Text to Video**, **Pruna P-Video-2 Image to Video**, **Pruna P-Video-2 Pro Reference to Video**, **Pruna P-Video-2 Pro Avatar**. 텍스트 및 이미지 기반 비디오 생성 노드는 1초에서 20초 길이의 클립을 720p 또는 1080p, 24 또는 48 fps로 생성하며, 7가지 화면 비율(16:9, 9:16, 4:3, 3:4, 3:2, 2:3, 1:1)을 지원하고, 프롬프트에서 생성되는 앰비언스, 사운드 효과, 립싱크 대사 등 네이티브 오디오를 함께 제공합니다.

이미지 기반 비디오 생성 노드는 첫 프레임을 애니메이션화하며 선택적으로 마지막 프레임을 사용할 수 있습니다. 두 노드 모두 모션을 이끌고 사운드트랙이 되는 선택적 오디오 입력을 받습니다. 초안 모드는 표준 요금의 60%로 청구되는 더 빠르고 덜 상세한 미리보기를 렌더링하므로, 최종 품질의 렌더링을 확정하기 전에 구도를 반복 실험할 수 있습니다.

이 노드들은 Comfy API를 통해 전적으로 Pruna의 서버에서 실행됩니다. 모델 다운로드나 로컬 GPU가 필요하지 않으며, 크레딧이 있는 Comfy API 계정만 있으면 됩니다.

## P-Video-2의 강점

- **네이티브 오디오**: 앰비언스, 사운드 효과, 립싱크된 대사가 담긴 사운드트랙을 생성하거나, 연결된 오디오 트랙을 따릅니다
- **유연한 출력**: 24 또는 48 fps의 720p 또는 1080p, 1~20초(또는 프롬프트에서 선택되는 `auto` 재생 시간), 7가지 화면 비율
- **초안 모드**: 표준 요금의 60%로 더 빠르고 세부 정보가 적은 미리보기
- **첫 프레임과 마지막 프레임**: 이미지 기반 비디오 생성은 화면 비율이 거의 일치하는 두 이미지 사이를 애니메이션합니다
- **레퍼런스**: 이미지, 비디오, 오디오로 Pro 클립을 구성하며, 프롬프트에서 `@Image1`, `@Video1`, `@Audio1`로 지정합니다
- **토킹 포트레이트**: Avatar 노드가 초상 이미지를 스크립트나 직접 녹음한 오디오에 립싱크합니다

[요금](/ko/tutorials/partner-nodes/pricing)에는 텍스트 및 이미지 기반 비디오의 요금이 정리되어 있습니다. Pro 노드 두 개는 해상도와 모드에 따라 초 단위로 청구되며 참조 미디어 비용이 더해집니다.

### 실행 단계

1. **프롬프트 입력**: **Pruna P-Video-2 Text to Video** 노드에 장면과 움직임, 사운드를 설명합니다 (최대 5000자)
2. **재생 시간과 해상도 설정**: 1~20초 또는 `auto` 중에서 선택한 다음, 720p(약 0.9메가픽셀) 또는 1080p(약 2메가픽셀)를 선택합니다
3. **프레임 레이트 선택**: 24 또는 48 fps. 48 fps는 1080p에서 드래프트와 함께 사용할 수 없습니다
4. **선택 사항: 오디오 연결**: 오디오 입력은 움직임을 구동하고 `duration` 대신 비디오 길이를 설정합니다 (1~20초, 더 긴 오디오는 잘립니다)
5. **실행 대기열 클릭**: `Ctrl+Enter`를 눌러 생성합니다

### 팁

- `enhance_prompt`(기본적으로 켜짐)는 짧은 프롬프트를 더 자세한 내용으로 다시 작성합니다. 동일한 시드로 결과를 정확히 재현하려면 이 기능을 끄세요
- 무음 클립을 원하면 `generate_audio`를 끄면 됩니다

### 실행 단계

1. **첫 번째 프레임 업로드**: **LoadImage** 노드를 연결합니다. 출력은 이 이미지의 가로세로 비율을 유지합니다
2. **선택 사항: 마지막 프레임 업로드**: 비디오가 이 이미지로 끝납니다. 이 이미지의 가로세로 비율은 첫 번째 프레임의 비율과 가까워야 합니다
3. **모션과 사운드 설명**: 프롬프트에 장면이 어떻게 움직이고 들리는지 작성합니다 (최대 5000자)
4. **재생 시간, 해상도, 프레임 레이트 설정**: 텍스트 기반 비디오 생성과 동일한 옵션입니다
5. **실행 대기열 클릭**: `Ctrl+Enter`를 눌러 생성합니다

## P-Video-2 Pro: 레퍼런스 기반 비디오

레퍼런스 소재로 클립을 만듭니다. **Pruna P-Video-2 Pro Reference to Video** 노드를 추가하고 프롬프트에서 각 레퍼런스를 연결 순서대로 지정합니다: `@Image1`부터 `@Image9`, `@Video1`부터 `@Video3`, `@Audio1`부터 `@Audio3`.

- 이미지는 선택적인 첫 프레임과 마지막 프레임을 포함해 최대 9장입니다. 비디오는 최대 3개이며 각 2~15초, 최대 60fps이고 1080p를 넘으면 축소됩니다. 오디오는 최대 3개입니다. 레퍼런스는 모두 합쳐 12개까지입니다. 비디오는 합쳐 15초, 오디오도 합쳐 15초까지입니다.
- `duration`은 5~14초입니다. `mode`는 가격과 속도 중 무엇을 택할지 정합니다: `speed`는 더 빠르고 `cost`는 더 저렴합니다.
- `aspect_ratio`를 `adaptive`로 두면 대부분의 레퍼런스가 가진 비율을 따릅니다. `enhance_prompt`가 켜져 있으면 다시 쓴 프롬프트가 비율을 정합니다.
- `keep_audio`는 연결된 오디오 하나를 사운드트랙으로 사용합니다. 오디오가 `duration`과 1초 이내로 차이 나면 비디오 길이가 오디오에 맞춰지고, 더 긴 오디오는 `duration`에서 잘리며, 더 짧은 오디오는 생성된 사운드로 채워집니다.
- `enhance_prompt`의 기본값은 `turbo`입니다. 프롬프트에서 레퍼런스를 번호로 지정할 때는 켜 두세요. 다시 써도 라벨은 유지됩니다. `off`는 동일한 시드로 정확히 재현하기 위한 설정이며, 첫 프레임이나 마지막 프레임을 쓰면 항상 `turbo`가 됩니다.

이 노드에는 아직 템플릿이 없습니다. 노드 메뉴에서 추가하고 레퍼런스는 직접 연결하세요.

## P-Video-2 Pro: 아바타

초상 이미지를 말하는 비디오로 만듭니다. **Pruna P-Video-2 Pro Avatar** 노드를 추가하고 말하는 방식을 선택합니다:

- `script`: 선택한 `voice`와 `language`로 텍스트를 읽습니다. `voice_prompt`는 말투, 속도, 억양을 지정하며 그 자체로 읽히지는 않습니다.
- `audio`: 직접 녹음한 오디오에 립싱크합니다. 최소 1초의 음성이 필요합니다.

비디오 길이는 음성 길이를 따르며 3분에서 잘립니다. 초상 이미지는 1:2에서 4:1 사이의 종횡비를 유지하고, 그보다 극단적인 이미지는 16:9 또는 9:16으로 잘립니다.

`prompt`는 화면 내용을 설명하며 기본값은 `The person is talking.`입니다. 해상도는 480p, 768p(기본), 1080p, 2k, 4k이며 큰 세 가지는 768p 렌더를 업스케일합니다. `2k`는 최대 150초, `4k`는 최대 60초의 오디오를 받습니다.

## 텍스트 및 이미지 기반 비디오 옵션

| 옵션 | 값 | 기본값 | 비고 |
| ------ | ------ | ------- | ----- |
| `duration` | 1 ~ 20 또는 auto | 5 | 오디오가 연결됨 상태이면 무시되며, 이 경우 비디오는 오디오 길이를 따릅니다 |
| `resolution` | 720p / 1080p | 720p | 720p는 약 0.9 MP, 1080p는 16:9 기준 약 2 MP입니다 |
| `fps` | 24 / 48 | 24 | 1080p에서 draft 사용 시 48 fps는 사용할 수 없습니다 |
| `draft` | on / off | off | 더 빠르고 세부 정보가 적은 렌더링, 표준 요금의 60%로 청구 |
| `generate_audio` | on / off | on | 오디오가 연결됨 상태이면 무시됩니다 |
| `enhance_prompt` | on / off | on | 고급. 정확한 시드 재현성을 위해서는 끄세요 |
| `seed` | 0 ~ 2147483647 | 42 | 정확한 재현성을 위해서는 enhance_prompt를 꺼야 합니다 |
