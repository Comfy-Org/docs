[LTX-2.5](https://ltx.io/model/ltx-2.5)는 Lightricks의 오픈 가중치 비디오 및 월드 모델로, ComfyUI에서 LTX-2.5 API 노드를 통해 사용할 수 있습니다. API 워크플로는 Lightricks 서버에서 생성 작업을 실행하므로 모델 다운로드나 로컬 GPU가 필요하지 않으며, 생성된 비디오 1초마다 Comfy API 계정으로 청구됩니다.

LTX-2.5 API는 두 가지 모델 등급을 제공합니다. 최고 품질을 위한 **LTX-2.5 (Pro)**, 그리고 증류 모델을 사용한 더 빠른 생성을 위한 **LTX-2.5 (Fast)**입니다. 두 등급 모두 동기화된 오디오 및 비디오 생성과 기본 멀티샷 장면을 지원하며, Fast 등급에서는 최대 4K 해상도로 출력합니다.

## LTX-2.5의 강점

- **오디오와 비디오 동기화**: 두 등급 모두 오디오와 비디오를 함께 생성하며, 기본 제공되는 멀티샷 장면을 지원합니다
- **두 가지 모델 등급**: 최대 품질을 위한 LTX-2.5(Pro), 증류 모델로 더 빠르게 생성하는 LTX-2.5(Fast)
- **최대 4K 출력**: Fast 등급은 최대 4K 해상도로 출력합니다
- **로컬 GPU 불필요**: 생성은 Lightricks 서버에서 실행되며, 모델 다운로드가 필요 없습니다
- **다양한 생성 모드**: 텍스트 기반 비디오 생성, 이미지 기반 비디오 생성, 첫-마지막 프레임 기반 비디오 생성

## LTX-2.5 API 워크플로

템플릿 라이브러리에는 세 가지 API 예시 워크플로가 포함되어 있습니다:

- **텍스트 기반 비디오 생성**: 텍스트 프롬프트에서 비디오 생성
- **이미지 기반 비디오 생성**: 단일 시작 이미지에서 비디오 생성
- **FLF2V**: 첫 번째 프레임과 마지막 프레임 이미지 사이의 비디오 생성

#### 프롬프트 팁

1. **모델**: 최고 품질을 위해 `LTX-2.5 (Pro)`를 선택하거나, 더 빠른 생성을 위해 `LTX-2.5 (Fast)`를 선택하세요
2. **재생 시간**: Pro는 2-10초를, Fast는 2-20초를 지원합니다. 10초가 넘는 재생 시간은 720p 또는 1080p 해상도와 24/25 FPS가 필요합니다
3. **해상도 및 비율**: `1280x720`(가로) 또는 `720x1280`(세로)과 같은 해상도 프리셋을 선택하세요. Fast에는 `2560x1440` 및 `3840x2160` 옵션이 추가됩니다
4. **FPS**: Fast에서는 24, 25, 48 또는 50 FPS 중에서, Pro에서는 24, 25 또는 50 FPS 중에서 선택하세요
5. **오디오**: 오디오 생성은 기본적으로 활성화되어 있습니다. 무성 비디오만 필요한 경우 노드의 고급 설정에서 비활성화하세요
6. **프롬프트**: 장면 전체를 하나의 자연스러운 문단으로 설명하세요. 촬영 구도, 동작, 캐릭터, 카메라 움직임, 원하는 오디오를 포함하세요

2. **단일 이미지만**: 이미지 입력에는 정확히 하나의 시작 이미지만 허용됩니다
3. **프롬프트**: 다음에 일어날 일을 설명하세요. 시작 이미지에서 이어지는 움직임, 카메라 움직임, 소리를 설명합니다. "제공된 시작 이미지를 첫 번째 프레임으로 사용하세요"와 같은 표현은 생성 결과를 안정화하는 데 도움이 됩니다
4. **재생 시간 및 해상도**: Fast 티어는 최대 20초와 4K 해상도를 지원합니다. 10초가 넘는 재생 시간에는 24/25 FPS의 720p/1080p가 필요합니다

1. **프레임**: 워크플로는 첫 번째 이미지를 `image` 입력에, 두 번째 이미지를 `last_frame` 입력에 연결합니다. 모델은 두 프레임 사이의 움직임을 생성합니다

4. **프롬프트**: 프레임 사이의 전환과 원하는 오디오(대화, 효과음, 음악)를 설명하세요
