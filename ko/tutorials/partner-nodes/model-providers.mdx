이 페이지는 Comfy의 파트너 노드 뒤에 있는 모델 공급자를 하나의 표로 정리합니다: 검증 상태, 클라우드 및 로컬 사용을 위한 상업적 라이선스, 데이터 상주 위치를 다룹니다. 이는 현재 채워 나가고 있는 구조이며, 완성된 참조 자료가 아닙니다. 일부 열은 오늘날 확인된 사실을 반영하고, 다른 열은 각 공급자와 세부 정보를 검증할 때까지 임시 항목입니다.

공급자별 가격은 [파트너 노드 가격](/ko/tutorials/partner-nodes/pricing)을 참고하세요.

이 페이지는 파트너 노드 뒤의 공급자를 다룹니다. Comfy가 파트너 노드 입력과 출력을 얼마나 오래 보관하는지는 [데이터 보존](/ko/tutorials/partner-nodes/data-retention)을 참고하세요. 각 Comfy Router 모델을 제공하는 공급자는 [제공 공급자](/ko/development/comfy-router/providers)를 참고하세요.

## 각 열의 의미

- **검증됨**: "예"는 Comfy가 해당 공급자와 직접적인 상업 및 API 파트너십을 체결하고 관련 계약 조건을 검토했음을 의미합니다. "아니요"는 아직 이 상태에 도달하지 않았음을 뜻합니다. "대기 중"은 파트너 계약 요약표에서 해당 공급자의 검증 상태가 아직 확인되지 않았음을 의미합니다.
- **상업적 라이선스(클라우드)**: 해당 공급자의 모델에 대해 Comfy Cloud를 통한 상업적 사용이 확인되었는지 여부입니다.
- **상업적 라이선스(로컬)**: 해당 공급자의 모델에 대해 로컬, 자체 호스팅 사용에 대한 상업적 사용이 확인되었는지 여부입니다. "요청"은 상업적 사용이 자동으로 포함되는 것이 아니라 별도의 요청이나 라이선스가 필요함을 의미합니다.
- **데이터 상주 위치**: 오늘날 공급자가 기본적으로 데이터를 처리하는 위치입니다. "대기 중"은 아직 해당 공급자와 위치를 확인하지 못했음을 의미합니다.

라이선스 열의 "대기 중"은 아직 해당 라이선스를 확인하지 못했음을 의미합니다. 각 파트너십이 확인되는 대로 이는 체크 표시, 대시 또는 "요청"으로 바뀝니다.
