Anthropic Claude는 강력한 추론, 안전성, 긴 컨텍스트 처리 능력으로 잘 알려진 AI 모델 제품군입니다. ComfyUI는 파트너 노드를 통해 Anthropic Claude API를 통합하여, 대화 및 이미지 분석 작업을 위해 워크플로에서 Claude를 직접 사용할 수 있게 해줍니다.

## Anthropic Claude의 강점

- **강력한 추론**: 강력한 추론, 안전성, 긴 컨텍스트 처리 능력으로 잘 알려진 모델 제품군
- **대화 및 이미지 분석 작업**: 파트너 노드를 통해 ComfyUI 워크플로 내부에서 Claude를 직접 사용하세요
- **멀티모달 입력**: 지원되는 모든 모델은 텍스트 전용 및 텍스트 + 이미지 입력을 허용하며, 요청당 최대 20개의 이미지까지 처리할 수 있습니다
- **모든 워크로드에 적합한 모델**: 플래그십 Opus 라인부터 높은 처리량이 필요한 사용 사례에 적합한 빠르고 비용 효율적인 Haiku까지

## 지원 모델

| 모델 | 특징 |
|-------|-----------|
| **Opus 5** | Anthropic의 최신 플래그십 모델로, 2026년 7월 24일에 출시되었습니다. Claude Fable 5.1 요금의 절반으로, 코딩 및 지식 작업에서 비슷한 성능을 제공합니다. |
| **Fable 5.1** | Anthropic의 고급 추론 모델로, 2026년 9월 1일에 출시되었습니다. Fable 5의 업데이트 버전으로, 에이전트형 작업 비용이 낮아지고 오탐이 줄었습니다. thinking이 항상 활성화되며 `temperature`는 사용할 수 없습니다. |
| **Sonnet 5** | Anthropic의 미드티어 모델로, 2026년 6월 30일에 출시되었습니다. Opus 계열보다 낮은 가격으로 자율적인 에이전트형 작업을 위해 설계되었습니다. `temperature`는 사용할 수 없습니다. |
| **Opus 4.8** | 강력한 전반적인 성능을 갖춘 이전 세대 플래그십 모델입니다. |
| **Opus 4.7** | Anthropic의 가장 강력한 모델입니다. 에이전틱 코딩, 복잡한 추론, 정교한 분석에서 획기적인 개선을 제공합니다. 1M 컨텍스트 창. 지식 기준일: 2026년 1월. |
| **Opus 4.6** | 강력한 전반적인 성능을 갖춘 이전 세대 플래그십 모델입니다. 1M 컨텍스트 창. |
| **Sonnet 4.6** | 대부분의 워크로드에서 속도와 지능의 최상의 균형을 제공합니다. 1M 컨텍스트 창. 빠른 지연 시간. |
| **Sonnet 4.5** | 빠르고 성능이 뛰어나며 일상적인 작업에 적합합니다. 200k 컨텍스트 창. |
| **Haiku 4.5** | 단순한 쿼리와 높은 처리량이 필요한 사용 사례에 가장 빠르고 비용 효율적인 옵션입니다. 200k 컨텍스트 창. |

모든 모델은 텍스트 전용 및 멀티모달(텍스트 + 이미지) 입력을 모두 지원하며, 요청당 최대 20개의 이미지를 처리할 수 있습니다.

워크플로 이미지의 번호가 표시된 단계를 참조하여 기본 워크플로 실행을 완료합니다:
1. `Load Image` 노드에서 AI가 해석해야 할 이미지를 로드합니다 (선택 사항: 텍스트 전용 쿼리는 건너뛰기)
2. `Anthropic Claude` 노드에서 `prompt`를 수정하여 대화 프롬프트를 설정하거나, `model`을 변경하여 다른 Claude 모델을 선택합니다
3. (선택 사항) `system_prompt`을 설정하여 모델의 동작 지침을 정의합니다
4. `Run`을 클릭하거나 `Ctrl(cmd) + Enter`를 눌러 대화를 실행합니다
5. API가 결과를 반환한 이후, `Preview Any` 노드에서 AI 응답을 확인합니다

### 추가 참고 사항

- 노드의 고급 옵션에서 `max_tokens`(최대 32768) 및 `temperature`(0.0~1.0)를 조정합니다. thinking이 활성화되거나 `Opus 4.7`을 선택한 경우 `temperature`는 사용할 수 없습니다
- `seed` 매개변수는 노드의 재실행 여부를 제어합니다. 시드 값과 관계없이 결과는 비결정적입니다.
