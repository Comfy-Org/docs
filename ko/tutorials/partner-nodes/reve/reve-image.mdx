Reve는 파트너 노드를 통해 ComfyUI에서 사용할 수 있는 이미지 생성 모델입니다. 세 가지 전용 노드를 통해 최대 **4K 해상도**의 텍스트 기반 이미지 생성, 이미지 편집, 이미지 리믹스를 지원합니다.

## Reve Image가 뛰어난 분야

- **최대 4K 해상도**: 고해상도에서 선명하고 디테일한 이미지를 생성합니다
- **내장된 미적 학습**: 패션 에디토리얼, 시네마틱, 자연 조명 스타일에 적합한 결과물을 생성합니다
- **이미지 편집**: 기존 이미지의 조명 조건과 색상 그레이딩을 수정하고 모션 효과를 추가합니다
- **이미지 리믹싱**: 일관성을 유지하면서 참조 이미지의 요소를 대상 이미지에 결합합니다

## 시작하기

1. **ComfyUI를 최신 버전으로 업데이트**하거나 [Comfy Cloud](https://cloud.comfy.org/?utm_source=docs)를 방문하세요.
2. **왼쪽 사이드바의 노드 라이브러리 또는 템플릿에서** Reve 이미지 생성, Reve 이미지 리믹스, Reve 이미지 편집 노드를 찾으세요.
3. **캔버스에 노드를 드롭**하여 시작하세요.

## 사용 가능한 노드

| 노드 | 유형 | 설명 |
|------|------|-------------|
| **Reve 이미지 생성** | 텍스트 기반 이미지 생성 | 텍스트 프롬프트에서 최대 4K 해상도로 이미지를 생성합니다 |
| **Reve 이미지 편집** | 이미지 편집 | 기존 이미지의 조명, 색상 그레이딩, 모션을 수정합니다 |
| **Reve 이미지 리믹스** | 이미지 리믹스 | 참조 이미지의 시각적 속성을 대상 이미지로 전달합니다 |
