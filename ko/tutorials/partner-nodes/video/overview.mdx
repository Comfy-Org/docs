## 비디오 모델로 할 수 있는 작업

- **텍스트 기반 비디오 생성**: 텍스트 프롬프트에서 비디오를 생성합니다.
- **이미지 기반 비디오 생성**: 정지 이미지를 애니메이트하여 사진이나 아트워크에 생명을 불어넣습니다.
- **비디오 향상**: 업스케일, 프레임 보간 또는 비디오 품질 개선을 지원합니다.
- **모션 제어**: 생성된 비디오에서 카메라 움직임, 피사체의 움직임 또는 캐릭터의 움직임을 제어합니다.

## 작업별 모델 선택

### 일반용 텍스트 기반 비디오 생성

- **Seedance 2.5 / 2.0** (ByteDance): 모든 면에서 뛰어난 텍스트 기반 비디오 생성 성능을 제공합니다.
- **FLUX 3 Video** (Black Forest Labs): FLUX 제품군을 기반으로 구축된 Black Forest Labs의 비디오 모델입니다.
- **Wan 3.0 / Wan 2.7** (Wan): 모션 품질이 우수한 오픈 모델 기반 비디오 생성 기능을 제공합니다.
- **Grok Imagine Video 1.5** (Grok): xAI가 제공하는 빠른 텍스트 기반 비디오 생성 모델입니다.

### 이미지 기반 비디오 생성

- **Luma Image-to-Video** (Luma): 단일 이미지를 짧은 애니메이션 클립으로 변환합니다.
- **Kling 3.0** (Kling): 강력한 모션을 갖춘 이미지 기반 비디오 생성 및 텍스트 기반 비디오 생성 기능을 제공합니다.
- **Runway Video Generation** (Runway): 영화적 품질의 이미지 기반 비디오 생성 및 텍스트 기반 비디오 생성 기능을 제공합니다.
- **HappyHorse 1.1 / 1.0** (HappyHorse): 이미지 기반 애니메이션을 생성합니다.

### 비디오 향상 및 업스케일링

- **FLUX Video Upscale** (Black Forest Labs): 생성된 비디오를 업스케일링하고 품질을 개선합니다.
- **Topaz Video Enhance Starlight Precise 2.5** (Topaz): 업스케일링 및 화질 개선 기능을 제공합니다.
- **Topaz Astra / Video Enhance Astra** (Topaz): 화질 복원 도구입니다.

### 모션 제어 및 캐릭터 애니메이션

- **Kling 모션 컨트롤** (Kling): 카메라와 피사체의 움직임을 제어합니다.
- **Seedance 2.0 Real Human** (ByteDance): 사람의 움직임 및 캐릭터 애니메이션을 생성합니다.
