VEED Dubbing은 클립의 음성을 다른 언어로 번역합니다. 각 화자의 음성이 복제되고 립싱크가 번역에 맞춰 재조정되므로, 결과물은 자막이 아니라 목표 언어로 실제 말하는 것처럼 보입니다.

ComfyUI에서 노드는 **VEED Dubbing**이며, 두 가지 모델 티어가 있습니다. `standard`는 더 저렴한 티어로, 모노 오디오와 85개 목표 언어를 지원하며 스페인어는 라틴 아메리카 스페인어, 포르투갈어는 브라질 포르투갈어로 처리됩니다. `pro`는 지역 억양과 스테레오 오디오를 추가하고 101개 목표 언어에 도달하며, `English (UK)`, `Spanish (Mexico)`, `Chinese (Taiwan)` 같은 변형도 포함합니다.

클라우드 API 노드입니다. 크레딧이 있는 Comfy 계정이 필요하고, 모델 파일을 다운로드하지 않으며, 출력 초 단위로 과금됩니다. 현재 요금은 [파트너 노드 가격](/ko/tutorials/partner-nodes/pricing)을 참조하세요.

## 노드 제어

| 제어 | 값 | 효과 |
| --- | --- | --- |
| `model` | `standard`, `pro` | 더빙 등급입니다. `standard`는 85개 대상 언어를 지원하는 모노이며, `pro`는 지역 억양과 스테레오 오디오를 추가하여 101개 대상 언어를 지원합니다 |
| `video` | 클립 | 더빙할 영상입니다. 최대 599초이며, 오디오 트랙에 음성이 있고 얼굴이 보여야 합니다 |
| `target_language` | 언어 목록 | 더빙할 대상 언어입니다. 목록은 등급에 따라 달라지며, `pro`에는 억양 변형이 포함됩니다 |
| `source_language` | `auto` 또는 언어 | 비디오에서 사용되는 언어입니다. 기본값은 `auto`입니다 |
| `seed` | 정수 | 다시 실행 제어 전용입니다. 결과는 여전히 비결정적입니다 |

## 팁

- **화자가 보이는 영상을 보내세요.** 더빙은 화면에 보이는 것을 기준으로 작동하므로, 카메라를 정면으로 바라보는 한 사람이 안정적인 경우입니다. 뒷머리, 손, 제품 촬영, 군중 장면은 더빙되지 않습니다.
- **오디오에 실제로 말소리가 있는지 확인하세요.** 내레이션, 대사, 인터뷰는 모두 작동합니다. 음악, 사운드 효과, 무음은 모델이 번역할 내용을 제공하지 않습니다.
- **자동 인식이 잘못 들을 때는 소스 언어를 지정하세요.** `auto`는 깨끗한 녹음은 처리하지만, 짧은 클립이나 강한 억양은 `source_language`를 직접 설정할 때 더 정확하게 더빙됩니다.
- **억양이 중요할 때는 `pro`를 선택하세요.** 표준 등급은 언어당 하나의 변형만 제공하므로, 영국식 영어나 멕시코식 스페인어 요청은 `pro`에만 존재합니다.
- **먼저 길이 제한에 맞게 잘라내세요.** 이 노드는 최대 599초의 비디오를 허용하며, 출력은 오디오 트랙과 같은 길이이므로 실행 후가 아니라 실행 전에 잘라내세요.

## 시작하기

1. ComfyUI를 최신 버전으로 업데이트합니다
2. Template Library로 이동해 `VEED Dubbing`을 검색합니다
3. `LoadVideo` 노드에 토킹 헤드 클립을 불러옵니다
4. `model`에서 tier를 선택하고 `target_language`를 설정한 뒤 워크플로를 실행합니다
