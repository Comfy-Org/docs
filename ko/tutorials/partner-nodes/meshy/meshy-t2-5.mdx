**Meshy T2.5**는 요청한 삼각형 수에 맞춰 3D 메시를 직접 생성합니다. 이전 파이프라인은 고밀도 메시를 만든 뒤 리토폴로지하는 방식이라 디테일이 손실되고, 에셋을 출시하기 전에 정리 작업이 필요합니다. T2.5는 예산을 처음부터 목표로 삼기 때문에, 15000 삼각형짜리 소품은 대략 15000 삼각형으로 돌아오며 바로 엔진에 넣을 수 있습니다.

ComfyUI는 이를 두 개의 파트너 노드로 제공합니다: **Meshy: Text to Model (Smart Topology)** 와 **Meshy: Image to Model (Smart Topology)**. 둘 다 크레딧이 있는 Comfy 계정이 필요한 클라우드 API 노드이며, 모델 파일을 로컬로 다운로드하지 않습니다. 각각 GLB 파일과 FBX 파일을 반환하고, 템플릿은 Save GLB 노드로 GLB를 저장합니다.

T2.5는 예측 가능한 삼각형 수가 중요한 소품, 환경 장식, 로우폴리 게임 에셋을 위한 모드입니다. 리깅, 애니메이션, 전체 에셋 파이프라인에는 대신 [Meshy 7](/ko/tutorials/partner-nodes/meshy/meshy-7)을 사용하세요.

## 노드 컨트롤

| 컨트롤 | 값 | 적용 대상 | 효과 |
| --- | --- | --- | --- |
| `model` | `meshy-t2.5` | 두 노드 모두 | Smart Topology 모델 릴리스 |
| `prompt` | 텍스트, 최대 800자 | Text to Model | 빌드할 객체에 대한 설명 |
| `image` | 이미지 1개 | Image to Model | 메시를 생성하는 데 사용하는 소스 이미지 |
| `target_polycount` | 100~30000, 기본값 15000 | 두 노드 모두 | 결과의 대략적인 삼각형 수 |
| `pose_mode` | 비어 있음, `A-pose`, `T-pose` | 두 노드 모두 | 캐릭터 자세를 고정합니다. 소품의 경우 비워 두세요 |
| `should_texture` | `true`, `false` | Image to Model | 생성 후 메시에 텍스처를 적용할지 여부 |
| `enable_pbr` | 기본적으로 꺼짐 | Image to Model, 텍스처링 켜짐 | 기본 색상에 메탈릭, 러프니스, 노멀 맵을 추가합니다 |
| `texture_prompt` | 텍스트, 최대 800자 | Image to Model, 텍스처링 켜짐 | 텍스처에 대한 텍스트 가이드입니다. `texture_image`와 함께 사용할 수 없습니다 |
| `texture_image` | 이미지 1개 | Image to Model, 텍스처링 켜짐 | 텍스처에 대한 이미지 가이드입니다. `texture_prompt`와 함께 사용할 수 없습니다 |
| `texture_resolution` | `2k`, `4k`, `8k` | Image to Model, 텍스처링 켜짐 | 생성된 텍스처의 해상도 |
| `seed` | 정수 | 두 노드 모두 | 노드를 다시 실행할지 여부를 제어합니다. Meshy 출력은 시드와 관계없이 비결정적입니다 |

노드는 `meshy_task_id`, `GLB`, `FBX`를 출력합니다. Save GLB는 작업 ID나 FBX 출력이 아닌 `GLB` 출력에서 파일을 기록합니다.

## 프롬프트 작성 팁

- **오브젝트와 실루엣을 명시하세요.** `Standalone game prop, clean silhouette, no text`를 사용하면 모델이 장면이나 받침대, 나중에 제거해야 할 글자를 덧붙이지 않습니다.
- **생성 이전에 폴리곤 예산을 정하세요.** 이후에 `target_polycount`를 변경하면 새로운 생성이 이루어지므로, 해당 에셋이 핵심 소품인지 배경 장식인지 먼저 결정하세요.
- **조명 장비가 아니라 재질을 설명하세요.** `weathered wood, iron banding, rusted lock plate` 같은 표면 표현은 메시와 텍스처에 그대로 반영됩니다. 스튜디오 조명 용어는 미리보기가 어떻게 보이는지에만 영향을 줍니다.
- **`pose_mode`는 캐릭터에만 사용하세요.** A-pose 또는 T-pose는 리깅에 적합한 자세를 만들어 줍니다. 소품은 비워 두는 편이 좋습니다.
- **형태가 맞은 뒤에 텍스처를 입히세요.** 텍스처 없이 한 번 실행해 실루엣을 확인한 다음, 최종 단계에서 `should_texture`를 켜세요.
- **같은 메시가 두 번 나오리라 기대하지 마세요.** 시드는 노드가 다시 실행되는지만 결정하므로, 재실행은 새로운 결과입니다.
