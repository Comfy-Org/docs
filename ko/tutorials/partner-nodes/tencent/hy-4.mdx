**Tencent HY4**는 Tencent의 대규모 언어 모델로, ComfyUI에서 `Tencent HY` 파트너 노드를 통해 사용할 수 있습니다. 이 노드는 텍스트 프롬프트와 최대 20개의 이미지를 입력받아 텍스트를 반환합니다. 참조 이미지를 바탕으로 작성된 아트 프롬프트, 캡션, 차트 분석, 또는 요청하는 그 밖의 어떤 답변이든 가능합니다.

Hy4는 2026년 11월 4일에 출시되었습니다. 시각적 이해를 갖춘 최초의 Hy 세대이며, Tencent는 Hy4 preview에 비해 지시 따르기, 긴 문맥 이해, 장기 과제 에이전트 작업에서 개선되었다고 보고합니다. 이 노드는 Comfy API를 통해 모델을 호출하므로 모델 다운로드도, 로컬 GPU도 필요하지 않습니다.

여기에서 다루는 템플릿은 이미지에서 프롬프트를 생성하는 예제입니다. 사진을 읽고 이미지 모델에 붙여넣을 수 있는 쉼표로 구분된 프롬프트를 작성합니다.

## Tencent HY 노드의 강점

- **이미지 → 프롬프트**: 피사체, 구도, 카메라, 조명, 색상, 질감, 스타일을 아우르는 구조화된 프롬프트를 작성합니다
- **이미지 이해**: 사진, 스크린샷, 문서에 대한 캡션, 차트 및 다이어그램 분석, 세부 사항 확인
- **요청당 여러 이미지**: 한 번의 호출로 최대 20개의 이미지를 처리하며, 배치의 각 이미지는 한 번씩 집계됩니다
- **지시 제어**: `system_prompt`는 상시 역할을 담당하고, `prompt`는 이번 실행의 작업을 전달합니다
- **추론 토글**: `reasoning`은 모델이 답변하기 전에 사고하도록 하며, 사고가 필요한 작업에 사용합니다
- **긴 답변**: `max_tokens`는 최대 64000 토큰을 허용합니다

### 워크플로 실행 단계

1. `LoadImage` 노드에 이미지를 불러오세요. 다운로드한 워크플로는 `blue_poppies_field.png`를 이름으로 참조하므로, 해당 파일을 업로드하기 전까지는 노드가 비어 있습니다
2. `Text (User Prompt)` 노드를 편집하세요. 그 텍스트가 `prompt`로 모델에 전달되며, 템플릿은 이미 쉼표로 구분된 긍정 프롬프트만 요청합니다. 다른 출력이 필요하면 다시 작성하세요. 예: `Describe this chart and list the trends it shows`
3. (선택 사항) 단계별 사고가 필요한 작업이라면 `reasoning`을 켜세요. 답변이 더 오래 걸리고 더 많은 토큰을 사용합니다
4. (선택 사항) 긴 답변이 필요하면 `max_tokens`를 기본값 `32000`에서 (최대 `64000`까지) 높이거나, 다양성을 조절하려면 `temperature`를 `1.0`에서 (범위 0 ~ 1.4) 변경하세요
5. `Run`을 클릭하거나 `Ctrl(cmd) + Enter`를 누르세요
6. `Preview Any`에서 답변을 확인하세요. `Save Text`가 프롬프트와 답변을 `output/Hy4/` 아래 `.txt` 파일로 기록합니다

### 프롬프트 작성 팁

- 출력 형식을 명시하세요. 템플릿의 `Only output positive prompt, no extra explanations` 문구가 답변을 바로 붙여넣을 수 있는 형태로 유지해 줍니다
- 여러 이미지를 연결할 때는 순서대로 언급하세요 (`the first image`, `the second image`). 그래야 세부 내용이 올바른 이미지에 적용됩니다
- 반복되는 지시는 `system_prompt`에 넣고 `prompt`는 작업용으로 남겨 두세요. 예: `You write photography prompts for a stock library`
- `seed`는 노드의 재실행 여부만 결정합니다. 답변은 실행할 때마다 여전히 달라집니다

## 시작하기

1. ComfyUI를 최신 버전으로 업데이트합니다
2. Template Library로 이동하여 `Tencent: Hy4`를 검색합니다
3. 이미지를 프롬프트로 변환하는 워크플로를 열고 실행합니다

Tencent HY4는 API 토큰 사용량을 기준으로 과금됩니다. Hy4 요금은 [가격 표](/ko/tutorials/partner-nodes/pricing)를 참조하세요.
