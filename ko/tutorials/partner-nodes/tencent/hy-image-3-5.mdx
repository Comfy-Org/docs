Tencent Hunyuan Image 3.5 Preview(HY Image 3.5 Preview)는 ComfyUI 파트너 노드에서 사용할 수 있는 Tencent의 프리뷰 이미지 모델입니다. 텍스트로 이미지를 생성하고 지시에 따라 기존 이미지를 편집하며, 다국어 텍스트 렌더링, 사실적인 표현, 참조 이미지와 편집 결과 사이의 일관성에 중점을 둡니다.

이전 Hunyuan 이미지 모델과 비교해 HY Image 3.5 Preview는 세 가지 영역을 강화했습니다. 광고, 인포그래픽, UI 디자인을 위한 다국어 텍스트 렌더링과 조판. 시네마틱, 만화, 상업 사진, 일러스트레이션을 아우르는 사실적 표현과 스타일 범위. 그리고 배경, 의상, 스타일을 바꿔도 인물과 제품의 핵심 특징을 유지하는 편집 일관성입니다.

워크플로는 두 가지입니다. `Tencent HY Image: Text to Image`는 프롬프트로 이미지를 생성하고, `Tencent HY Image: Edit`은 최대 5장의 참조 이미지를 편집하거나 합성합니다. 둘 다 Comfy API를 통해 Tencent 서버에서 실행되므로 모델 다운로드나 로컬 GPU가 필요하지 않습니다.

## HY Image 3.5 Preview의 강점

- **다국어 텍스트와 조판**: 단순한 장면 이미지가 아니라 포스터, 인포그래픽, UI 목업에 읽기 쉬운 텍스트를 렌더링합니다
- **사실적 표현의 폭**: 짧은 프롬프트로 시네마틱 컷, 만화풍, 상업 사진, 일러스트레이션을 모두 다룹니다
- **편집 일관성**: 배경, 의상, 스타일을 바꿔도 인물과 제품의 특징을 유지합니다
- **최대 5장의 참조 이미지**: 한 번의 편집에서 여러 이미지를 조합하고 프롬프트에서 각각을 참조할 수 있습니다
- **최대 4K 출력**: 최대 2K를 기본으로 렌더링하고 4K 출력은 2K 렌더링 결과에서 업스케일합니다

### 워크플로 실행 단계

1. `Tencent HY Image: Text to Image` 노드의 `prompt`를 편집합니다.
2. (선택 사항) `aspect_ratio`를 설정해 출력 형태를 제어합니다. `auto`에서는 모델이 프롬프트로 종횡비를 선택하며, 4K에서는 `auto`를 사용할 수 없습니다.
3. (선택 사항) `resolution`을 기본값 `2K`에서 변경합니다. `1K`는 약 1024x1024, `2K`는 약 2048x2048 픽셀입니다. `4K` 출력은 2K로 렌더링한 뒤 모델이 업스케일합니다.
4. (선택 사항) `resolution`을 `custom`으로 전환해 정확한 `width`와 `height`를 지정합니다. 둘 다 16의 배수여야 하며 전체 픽셀 수는 최대 4096x4096입니다. 종횡비가 약 6:1을 넘으면 모델이 피사체를 반복하기 시작합니다.
5. `Run`을 클릭하거나 `Ctrl(cmd) + Enter`를 눌러 이미지를 생성합니다.
6. `Save Image` 노드에서 결과를 확인합니다.

### 워크플로 실행 단계

1. `Tencent HY Image: Edit` 노드의 `images` 입력에 1~5장의 이미지를 연결합니다.
2. `prompt`에 편집 지시를 작성합니다. 연결한 순서대로 `@Image1`, `@Image2`처럼 참조합니다. 배치 입력은 이미지 한 장당 한 번으로 계산합니다.
3. (선택 사항) `aspect_ratio`와 `resolution`을 설정합니다. `auto`에서는 출력이 첫 참조 이미지의 종횡비를 따릅니다. `4K` 출력은 2K로 렌더링한 뒤 모델이 업스케일합니다.
4. (선택 사항) `reference_detail`을 `high`로 설정하면 모델이 참조 이미지를 1024x1024 대신 최대 2048x2048 픽셀로 봅니다. 작은 텍스트와 세부 묘사를 더 잘 유지하지만 시간이 더 걸립니다.
5. `Run`을 클릭하거나 `Ctrl(cmd) + Enter`를 눌러 이미지를 생성합니다.
6. `Save Image` 노드에서 결과를 확인합니다.

### 프롬프트 팁

- 변경할 부분과 그대로 유지할 부분을 나눠서 설명합니다. 예: `@Image1 change the background to a night market, keep the subject and jacket unchanged`
- 참조 이미지 번호는 연결한 순서대로 지정되며, 프롬프트의 번호는 입력 순서와 일치해야 합니다
- `watermark`는 노드의 고급 옵션에 있으며 기본값은 꺼짐입니다. 켜면 출력에 AI 생성 워터마크가 추가됩니다
