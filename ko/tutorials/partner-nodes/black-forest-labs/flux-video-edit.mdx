FLUX Video Edit는 Black Forest Labs의 텍스트 기반 비디오 편집 엔드포인트로, ComfyUI에서 파트너 노드로 사용할 수 있습니다. 소스 클립과 평이한 언어로 작성된 지시를 입력하면, 해당 지시에 맞게 영상을 다시 작성합니다.

이 편집은 장면에서 벌어지는 일을 바꾸는 것이지, 촬영 방식을 바꾸는 것이 아닙니다. 길이, 프레이밍, 카메라 움직임, 오디오 트랙은 모두 소스 클립에서 그대로 가져오므로, 아무것도 다시 동기화할 필요 없이 결과물을 편집본에 다시 잘라 넣을 수 있습니다. 그래서 객체를 제거하거나 추가 또는 교체하기, 영상 스타일 바꾸기, 배경 변경하기, 화면 텍스트 다시 쓰기, 대사 교체에 유용합니다.

이 노드는 전적으로 Comfy API를 통해 Black Forest Labs의 서버에서 실행됩니다. 모델 다운로드나 로컬 GPU가 필요하지 않으며, 크레딧이 있는 Comfy API 계정이 필요합니다.

## FLUX Video Edit이 잘하는 것

- **지시문만으로**: 마스크, 참조 이미지, 제어 입력 없이 변경 사항을 말로 설명합니다
- **구조 유지**: 길이, 프레이밍, 카메라 움직임, 오디오는 소스 클립에서 가져옵니다
- **객체 수준 편집**: 객체, 캐릭터, 배경 요소를 제거, 추가 또는 교체합니다
- **스타일 변경**: 이미 보유한 영상의 룩, 조명 또는 배경을 변경합니다
- **텍스트 및 대사**: 화면 텍스트를 다시 작성하고 음성 대사를 교체합니다
- **최대 15초**: 0.7초에서 15초 사이의 소스 클립을 지원합니다

## 편집 지시문 작성하기

프롬프트는 유일한 창작 제어 수단이므로, 신중하게 작성할 가치가 있습니다.

- 화면에서 바뀌는 것만 설명하세요. 언급하지 않은 부분은 모두 원래대로 유지됩니다.
- 대상과 결과를 하나의 문장에 함께 명시하세요. 예를 들어 "기타 연주자를 같은 포즈의 고릴라로 교체"처럼 작성합니다.
- 지시문은 최대 4096자까지 평이한 언어로 작성하세요. 형태, 재질, 동작에 관한 세부 정보는 모델이 얼마나 크게 바뀌는지와 대략적으로 대응합니다.
- 대체 대사는 원본 발화의 길이에 가깝게 유지하세요. 새 대사가 원본 발화가 차지하는 시간에 맞춰져야 하기 때문입니다. 무음 클립은 무음으로 유지됩니다.
- 시드는 실행을 재현 가능하게 만들어 주지 않습니다. FLUX는 자체적으로 시드를 선택하므로, 같은 클립에 동일한 지시문을 사용해도 결과가 다르게 나올 수 있습니다.

## 노드 옵션 레퍼런스

| 옵션 | 값 | 기본값 | 비고 |
| ------ | ------ | ------- | ----- |
| `video` | 소스 클립 | 필수 | 0.7~15초, 최소 160x160 픽셀 |
| `prompt` | 텍스트 | 비어 있음 | 무엇을 변경할지 평이한 언어로 작성, 최대 4096자 |
| `auto_downscale` | 켜기 / 끄기 | 켜기 | 업로드 이전에 면적이 1280x704보다 큰 소스를 다운스케일하며, 가로세로 비율을 유지합니다 |
| `safety_tolerance` | 0~4 | 4 | 고급. 검열 허용치이며, `0`이 가장 엄격합니다 |
| `seed` | 0~4294967295 | 42 | FLUX가 자체적으로 시드를 선택하므로, 이 값과 관계없이 결과는 비결정적입니다 |

## 제한 사항

- 소스 클립은 0.7초에서 15초 사이이며 최소 160x160 픽셀이어야 합니다.
- 출력은 24 fps로 렌더링되며 프레임당 약 0.9 메가픽셀(1280x704)로 제한되므로, 더 큰 소스는 더 작게 반환됩니다.
- 청구는 클립 초 단위로 이루어집니다. [파트너 노드 크레딧](/ko/tutorials/partner-nodes/pricing)을 참조하세요.
