FLUX.1 Kontext는 Black Forest Labs가 개발한 전문적인 이미지 기반 이미지 편집 모델로, 이미지 맥락에 대한 지능적인 이해와 정밀한 편집에 중점을 둡니다.
객체 수정, 스타일 전송, 배경 교체, 캐릭터 일관성 편집, 텍스트 편집 등 복잡한 설명 없이 다양한 편집 작업을 수행할 수 있습니다.
Kontext의 핵심 장점은 뛰어난 맥락 이해 능력과 캐릭터 일관성 유지에 있으며, 여러 차례 반복 편집 후에도 캐릭터 특징과 구도 레이아웃 같은 핵심 요소가 안정적으로 유지되도록 합니다.

현재 ComfyUI는 FLUX.1 Kontext의 두 가지 모델을 지원합니다:

* **Kontext Pro**는 편집, 구성, 리믹스에 이상적입니다.
* **Kontext Max**는 타이포그래피, 프롬프트 정밀도, 속도의 한계를 끌어올립니다.

## FLUX.1 Kontext가 뛰어난 점

- **복잡한 설명 없이 다재다능한 편집**: 객체 수정, 스타일 변환, 배경 교체, 캐릭터 일관성 편집, 텍스트 편집
- **맥락 이해**: 이미지의 맥락을 지능적으로 이해하여 정밀하고 목표 지향적인 편집이 가능합니다
- **캐릭터 일관성**: 여러 차례 편집을 반복한 이후에도 캐릭터의 특징과 구성 레이아웃이 안정적으로 유지됩니다
- **다중 이미지 입력**: `Image Stitch` 노드는 여러 이미지를 하나의 이미지로 이어 붙여 FLUX.1 Kontext로 편집할 수 있게 합니다
- **두 가지 모델 등급**: Kontext Pro는 편집, 구성, 리믹스에 적합하고, Kontext Max는 타이포그래피, 프롬프트 정밀도, 속도에 적합합니다

## Flux.1 Kontext 다중 이미지 입력 워크플로

최근 다중 이미지 입력 워크플로를 지원하도록 업데이트되었습니다. 새로운 `Image Stitch` 노드를 사용하면 여러 이미지를 하나의 이미지로 이어 붙이고, 이를 Flux.1 Kontext로 편집할 수 있습니다.

### 1. 워크플로 파일 다운로드

아래 이미지의 `metadata`에는 워크플로 정보가 포함되어 있습니다. 다운로드하여 ComfyUI로 드래그하면 해당 워크플로를 로드할 수 있습니다.

![ComfyUI Flux.1 Kontext Pro Image 파트너 노드 워크플로](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/bfl/multiple_image_input/multiple_image_input.png)

입력용으로 다음 이미지를 다운로드하거나 직접 준비한 이미지를 사용하세요:

![ComfyUI Flux.1 Kontext Pro Image 파트너 노드 워크플로](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/bfl/multiple_image_input/girl.jpg)
![ComfyUI Flux.1 Kontext Pro Image 파트너 노드 워크플로](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/bfl/multiple_image_input/dog.jpg)
![ComfyUI Flux.1 Kontext Pro Image 파트너 노드 워크플로](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/bfl/multiple_image_input/sofa.jpg)

### 2. 워크플로 단계별 완료하기

![ComfyUI Flux.1 Kontext Pro Image 파트너 노드 워크플로 단계](/images/tutorial/api_nodes/bfl/flux_1_kontext_multiple_image_input_guide.jpg)

이미지의 번호가 매겨진 단계를 따라 워크플로를 완료할 수 있습니다:

1. `Load image` 노드에서 제공된 이미지를 업로드하세요
2. `Flux.1 Kontext Pro Image`에서 필요한 파라미터를 수정하세요:
    - `prompt` 편집하려는 이미지에 대한 프롬프트를 입력하세요
    - `aspect_ratio` 원본 이미지의 비율을 설정하세요. 1:4에서 4:1 사이여야 합니다
    - `prompt_upsampling` 프롬프트 업샘플링 사용 여부를 설정하세요. 활성화하면 프롬프트가 자동으로 수정되어 더 풍부한 결과를 얻을 수 있지만, 결과를 재현할 수 없습니다
3. `Run` 버튼을 클릭하거나 단축키 `Ctrl(cmd) + Enter`를 사용해 이미지 편집을 실행하세요
4. API가 결과를 반환할 때까지 기다린 후, `Save Image` 노드에서 편집된 이미지를 확인할 수 있으며, 해당 이미지는 `ComfyUI/output/` 디렉토리에도 저장됩니다

<Tip>
   이후 두 워크플로는 사용하는 파트너 노드만 다릅니다. 실제로 다중 이미지 입력 워크플로를 기반으로 수정하기만 하면 되며, 큰 차이는 없습니다
</Tip>
