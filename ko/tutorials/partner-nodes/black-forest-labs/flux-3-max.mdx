**FLUX 3 Max**는 FLUX 3 기반의 Black Forest Labs 비디오 모델로, fal을 통해 제공되며 ComfyUI에서 파트너 노드로 사용할 수 있습니다. 텍스트 프롬프트로 클립을 생성하거나, 여러 장의 정지 이미지를 하나의 연속된 샷으로 애니메이션화합니다.

표준 FLUX 3 비디오 노드와의 차이는 타임라인을 제어할 수 있다는 점입니다. 이미지 기반 비디오 생성은 1개에서 10개의 키프레임 이미지를 입력받습니다. 이미지 하나는 클립의 시작을 열고, 두 개는 첫 프레임과 마지막 프레임이 되며, 그보다 많으면 클립 전체에 균등하게 분산되거나 사용자가 지정한 초 지점에 고정됩니다. 모든 실행은 앰비언스, 음성, 사운드 효과를 포함한 동기화된 오디오도 함께 생성합니다.

두 노드 모두 클라우드 API 노드입니다. 크레딧이 있는 Comfy 계정이 필요하고, 모델을 다운로드하지 않으며, 출력 1초당 과금됩니다. 요금은 [파트너 노드 가격](/ko/tutorials/partner-nodes/pricing)을 참고하세요.

## FLUX 3 Max가 잘하는 것

- **키프레임 제어**: 타임라인에 최대 10개의 이미지를 배치하면 모델이 그 사이의 움직임을 채워 넣습니다
- **네이티브 오디오**: 모든 클립에는 동기화된 앰비언스, 음성, 효과음이 함께 제공되며, 오디오 트랙을 끌 수도 있습니다
- **5초에서 20초까지의 클립**: 한 번의 생성으로 이어 붙인 구간이 아닌 완전한 한 장면을 만듭니다
- **프롬프트 확장**: `reasoning_level`이 생성 전에 모델이 프롬프트를 얼마나 재작성하고 계획할지 결정하며, 어느 쪽이든 가격은 동일합니다
- **유연한 프레이밍**: 24 fps에서 720p 또는 1080p, 21:9부터 9:16까지, 또는 입력 이미지를 따르려면 `auto`

**사용 방법**

1. **프롬프트 작성**: 장면을 설명한 다음 사운드를 설명하세요. 앰비언스, 음악, 음성을 구분해 오디오 레이어가 서로 겹치지 않게 하세요.
2. **클립 설정**: `duration`은 5초에서 20초 사이이며, `resolution`은 `720p` 또는 `1080p`이고, `aspect_ratio`의 기본값은 `auto`입니다.
3. **컷이나 여러 피사체가 있는 복잡한 프롬프트에서는 `reasoning_level`을 `high`로 두세요.** 시간이 더 오래 걸리지만 비용은 `low`와 동일합니다.
4. **실행**하고 `SaveVideo`로 결과를 저장하세요.

## FLUX 3 Max 이미지 기반 비디오 생성 워크플로

**사용 방법**

1. **이미지 추가**: 재생 순서대로 1~10개의 이미지를 `keyframes` 입력에 연결합니다.
2. **배치 방식 선택**: `spread across the clip`은 첫 이미지를 시작에, 마지막 이미지를 끝에 두고 나머지는 그 사이에 균등하게 배치합니다. `at times`는 각 이미지를 직접 입력한 초 단위 시점에 고정할 수 있으며, 쉼표로 구분하고 값이 커지는 순서여야 합니다(예: `0, 2.5, 5`).
3. **동작과 사운드 설명**: 프롬프트는 장면이 어떻게 움직여야 하고 어떤 소리가 나야 하는지를 모델에 알려줍니다. 컷은 `SHOT ONE`, `HARD CUT`, `SHOT TWO`처럼 명시적으로 작성합니다.
4. **클립 설정**: `duration`, `resolution`, `aspect_ratio`는 텍스트 기반 비디오 생성 노드와 동일하게 동작합니다.
5. **실행**하고 결과를 `SaveVideo`로 저장합니다.

## 노드 제어

두 노드 모두 다음 입력을 공유합니다:

| 제어 | 값 | 효과 |
| --- | --- | --- |
| `prompt` | 최대 50,000자 | 샷, 카메라 동작, 오디오 |
| `aspect_ratio` | `auto`, `21:9`, `2:1`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16` | `auto`는 텍스트 프롬프트에서는 16:9이고, 그 외의 경우에는 첫 번째 이미지를 따릅니다 |
| `duration` | 5~20초 | 클립 길이 |
| `resolution` | `720p`, `1080p` | 24 fps 기준 출력 해상도 |
| `reasoning_level` | `low`, `high` | 생성 전에 모델이 프롬프트를 얼마나 확장하는지; 가격은 변하지 않습니다 |
| `generate_audio` | 기본적으로 켜짐 | 무음 비디오를 원하면 끕니다 |
| `seed` | 기본값 42 | 값을 변경하면 노드가 다시 실행됩니다; 시드와 관계없이 결과는 비결정적입니다 |

이미지 기반 비디오 생성에는 `keyframes`(이미지 1~10장)와 `placement`(`spread across the clip` 또는 `at times`)가 추가됩니다.

## 제한 사항

- 클립은 24 fps에서 5~20초입니다. 이 노드에는 이어 생성 입력이 없으므로, 더 긴 영상은 별도의 생성 결과물입니다.
- 키프레임 이미지는 최대 10개이며, 최소 한 개가 필요합니다.
- `at times`를 사용할 때는 이미지마다 정확히 하나의 시간을 오름차순으로 지정하고, 마지막 시간은 클립 안에 있어야 합니다.
- 오디오는 비디오와 함께 생성되며, 결과가 반환되기 이전에는 따로 편집할 수 없습니다.
- 시드는 실행을 재현 가능하게 만들지 않습니다. 같은 그래프를 다시 실행하면 다른 결과가 나옵니다.

## 시작하기

2. Template Library로 이동하여 `FLUX 3 Max`를 검색한 후, 두 템플릿 중 하나를 엽니다.
