FLUX 3는 Black Forest Labs의 멀티모달 파운데이션 모델로, 2026년 7월 23일에 발표되어 현재 얼리 액세스 단계입니다. 이미지, 비디오, 오디오를 Self-Flow를 기반으로 한 단일 아키텍처 안에서 함께 학습합니다. Self-Flow는 동일한 모델에서 멀티모달 생성과 이해를 정렬하기 위한 Black Forest Labs의 접근 방식입니다. FLUX 3 Image는 그중 정지 이미지 생성과 편집을 담당하는 부분입니다. 얼리 액세스 롤아웃 기간 동안 기능과 한계는 변경될 수 있습니다.

FLUX 3 Image는 텍스트 프롬프트로 이미지를 생성하거나, 최대 10장의 참조 이미지를 편집하고 합성합니다. 참조 이미지는 프롬프트에서 `image 1`, `image 2`처럼 지정하며, 모델은 프롬프트를 해석하고 확장한 뒤 생성합니다. 웹 및 이미지 검색 그라운딩은 기본적으로 켜져 있어, 지정한 대상을 검색할 수 있습니다. 출력은 단일 이미지이며, 16가지 종횡비와 0.75K(약 0.6메가픽셀)부터 4K(약 16.8메가픽셀)까지 5단계 해상도를 지원합니다.

ComfyUI에서 FLUX 3 Image는 **Flux 3 Image** 파트너 노드를 통해 실행되며, 생성한 이미지 한 장마다 해상도에 따라 크레딧으로 과금됩니다. 텍스트-이미지, 다중 참조 이미지 편집, 바운딩 박스 레이아웃 제어를 위한 세 가지 템플릿이 있습니다.

## FLUX 3 Image의 강점

- **텍스트-이미지**: 프롬프트로 이미지 한 장을 생성하며, 모델이 먼저 프롬프트를 해석하고 확장합니다
- **다중 참조 이미지 편집**: 최대 10장의 참조 이미지를 편집하거나 합성하며, 프롬프트에서 `image 1`부터 `image 10`까지로 지정합니다
- **바운딩 박스 레이아웃 제어**: Create Bounding Boxes 노드가 만든 박스로 객체와 텍스트를 원하는 위치에 배치합니다
- **검색 그라운딩**: 웹 및 이미지 검색이 기본으로 켜져 있어, 그리기 전에 지정한 대상을 조사할 수 있습니다
- **유연한 출력**: 16가지 종횡비와 0.75K부터 4K까지 5단계 해상도
- **타이포그래피와 레이아웃**: 포스터, 헤드라인, 캡션, 레이아웃 중심 디자인 작업에 적합합니다

### 텍스트-이미지 단계

1. **Flux 3 Image** 노드에 프롬프트를 입력합니다
2. `resolution`(0.75K부터 4K)을 설정하고, 필요하면 `aspect_ratio`를 `auto` 이외의 값으로 설정합니다
3. `grounding`을 켜 둔 상태로 두어, 지정한 대상을 웹과 이미지에서 검색하게 합니다
4. **Queue**를 클릭해 이미지를 생성합니다

### 이미지 편집 단계

1. 참조 이미지를 **Load Image** 노드에 업로드하고, Autogrow 슬롯으로 최대 10장까지 추가합니다
2. **Flux 3 Image** 노드에 편집 내용을 설명하고, 각 참조 이미지를 `image 1`, `image 2` 등으로 지정합니다
3. 출력의 `resolution`과 `aspect_ratio`를 설정합니다
4. **Queue**를 클릭해 편집된 이미지를 생성합니다

### 바운딩 박스 편집 단계

1. 이미지를 **Load Image** 노드에 업로드합니다
2. **Create Bounding Boxes**로 박스를 그리고, 각 박스에 설명을 넣습니다
3. **Flux 3 Image** 노드에 전체 지시를 작성합니다
4. 박스를 그린 캔버스에 맞게 `aspect_ratio`를 설정합니다
5. **Queue**를 클릭해 이미지를 생성합니다

## 시작하기

1. ComfyUI를 최신 버전(0.38.2 이상)으로 업데이트합니다
2. 템플릿 라이브러리를 열고 `Flux 3 Image`를 검색합니다
