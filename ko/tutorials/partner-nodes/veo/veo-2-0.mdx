<Warning>
  **Veo 2.0은 지원이 종료되었습니다.** ComfyUI는 #15883에서 Veo 2.0 노드를 제거했고 예제 워크플로는 이제 `archived/`에 있으므로, 최신 ComfyUI에서는 더 이상 실행되지 않습니다. 대신 [Veo 3.1](/ko/tutorials/partner-nodes/veo/veo-3-1)을 사용하세요: **Google Veo 3 Video Generation** 노드는 선택적 참조 이미지를 입력받아 네이티브 오디오와 함께 720p에서 4K까지의 비디오를 생성합니다.
</Warning>

Veo 2.0은 텍스트 프롬프트로 짧은 클립을 생성했고, 선택적으로 이미지를 넣어 첫 프레임을 고정할 수 있었습니다. 아래 보관된 예시는 이미지 기반 비디오 생성 버전으로, 한 장의 정지 이미지를 구도를 유지한 채 애니메이션으로 만듭니다.

## 보관된 워크플로

Veo 2.0 이미지 기반 비디오 생성 워크플로는 참고용으로 워크플로 템플릿 아카이브에 보관되어 있습니다. 대상으로 삼는 노드가 더 이상 존재하지 않기 때문에 최신 ComfyUI에서는 사용할 수 없습니다.

<CardGroup cols={1}>
  <Card title="보관된 워크플로" icon="download" href="https://github.com/Comfy-Org/workflow_templates/blob/main/archived/api_veo2_i2v.json">
    워크플로 템플릿 아카이브에서 `api_veo2_i2v.json`을 다운로드하세요.
  </Card>
</CardGroup>

실제로 작동하는 이미지 기반 비디오 생성 경로는 [Veo 3.1](/ko/tutorials/partner-nodes/veo/veo-3-1)을 사용하세요.
