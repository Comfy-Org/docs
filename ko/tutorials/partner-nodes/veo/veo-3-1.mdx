Veo 3.1은 Google DeepMind의 텍스트 기반 비디오 생성 모델입니다. 동기화된 오디오가 포함된 비디오를 생성하며, ComfyUI에서는 파트너 노드로 실행됩니다. 생성은 Google 서버에서 이루어지므로 Comfy 크레딧으로 결제하고 모델 다운로드나 로컬 GPU가 필요하지 않습니다.

## 노드

Veo 3.1은 두 개의 파트너 노드로 제공됩니다. 노드 라이브러리에서 원하는 노드를 추가하세요:

- **Google Veo 3 Video Generation**: 텍스트 기반 비디오 생성이며, 선택적인 참조 이미지 입력이 있습니다.
- **Google Veo 3 First-Last-Frame to Video**: 첫 프레임에서 마지막 프레임으로 애니메이션합니다.

두 노드 모두 동일한 세 가지 모델 옵션을 제공합니다:

| 등급 | `model` 옵션 | 해상도 |
| :--- | :--- | :--- |
| Standard | `veo-3.1-generate` | 720p, 1080p, 4K |
| Fast | `veo-3.1-fast-generate` | 720p, 1080p, 4K |
| Lite | `veo-3.1-lite` | 720p, 1080p |

클립은 16:9 또는 9:16 화면 비율로 4초에서 8초까지 재생됩니다. `generate_audio`는 출력에 동기화된 오디오를 유지하는 설정이며, 첫/마지막 프레임 노드에서는 기본적으로 켜져 있습니다.

## Veo 3.1 실행

Veo 3.1용 예시 워크플로는 아직 제공되지 않으므로 노드를 중심으로 그래프를 구성하세요. 프롬프트를 불러오고 `model` 위젯에서 등급을 설정한 다음 프롬프트를 실행 대기열에 추가하면 됩니다. 크레딧은 생성된 비디오 1초당 과금되며 등급, 해상도, 오디오 생성 여부에 따라 달라집니다. 현재 요금은 [파트너 노드 가격](/ko/tutorials/partner-nodes/pricing)을 참고하세요.

## 지원 종료된 모델

Veo 2.0은 더 이상 제공되지 않습니다. 해당 노드는 ComfyUI에서 제거되었고 워크플로 템플릿은 보관되었으며, [Veo 2.0 페이지](/ko/tutorials/partner-nodes/veo/veo-2-0)는 참고용으로만 유지됩니다.
