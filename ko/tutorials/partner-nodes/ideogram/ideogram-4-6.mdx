**Ideogram 4.6**은 네이티브 4K 출력을 지원하는 Ideogram의 이미지 생성 및 편집 모델입니다. 한 번의 패스로 최대 4096x4096까지 렌더링하므로 포스터, 패키징, 제품 사진에 별도의 업스케일이 필요하지 않습니다. Precise Edit는 변경을 요청하지 않은 픽셀의 색상과 디테일을 그대로 유지합니다.

이 모델은 세 가지 ComfyUI 파트너 노드인 **Ideogram Text to Image**, **Ideogram Edit**, **Ideogram Precise Edit**에서 모델 옵션으로 실행됩니다. 어느 노드에서든 `model`을 `ideogram-4.6`으로 설정하고, 이전 모델을 사용하려면 같은 목록에서 `ideogram-4.5`를 선택하세요. 이전 모델에는 [자체 페이지](/ko/tutorials/partner-nodes/ideogram/ideogram-4-5)가 있습니다.

## 텍스트 기반 이미지 생성

1K, 2K 또는 4K 캔버스에서 텍스트 프롬프트로 이미지를 생성합니다.

</Card>

![Ideogram 4.6 텍스트 기반 이미지 생성 예시 출력](https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/output/api_ideogram_v4_6_t2i.png)

**Ideogram Text to Image** 노드는 다음을 입력으로 받습니다:

| 입력 | 값 | 효과 |
| --- | --- | --- |
| `prompt` | 최대 10000자 | 이미지 설명입니다. 구조화된 JSON 캡션도 사용할 수 있으며, 예를 들어 이전 실행에서 얻은 `final_prompt`를 사용할 수 있습니다 |
| `size` | `auto`, 1K/2K/4K 프리셋 또는 `custom` | `auto`는 프롬프트에 어울리는 캔버스를 선택합니다. 프리셋은 세로 `1:3` 및 `9:23`부터 가로 `3:1` 및 `23:9`까지 1K, 2K, 4K 캔버스를 포함하며, 예를 들면 `(2K) 2048x2048 (1:1)`, `(4K) 5120x2880 (16:9)`입니다 |
| `width`, `height` | 256 ~ 8192, 간격 32 | `size`가 `custom`일 때만 사용됩니다. 두 치수는 16777216 픽셀(4096x4096) 이내이면서 종횡비 6:1 이내여야 합니다 |
| `quality` | `very_low`, `low`, `medium`(기본값), `high` | 등급이 높을수록 비용이 더 들고 시간이 더 오래 걸립니다. `very_low`는 4194304 픽셀(2048x2048)로 제한됩니다 |
| `background` | `auto`(기본값), `opaque`, `transparent` | `transparent`는 알파 채널이 있는 이미지를 반환하고, `opaque`는 단색 배경을 강제하며, `auto`는 프롬프트를 따릅니다 |
| `magic_prompt` | `auto`(기본값), `on`, `off` | 생성 전에 프롬프트를 상세한 구조화 캡션으로 재작성합니다. `off`는 입력한 문구를 최대한 그대로 유지합니다 |
| `seed` | 정수 | 텍스트 기반 이미지 생성은 매 실행마다 프롬프트가 재작성되므로 시드만으로는 재현할 수 없습니다 |

이 노드는 이미지를 생성하는 데 사용된 구조화 캡션인 `final_prompt`도 출력합니다. 이미지를 재현하려면 `magic_prompt`를 `off`로 설정하고 동일한 시드와 함께 해당 캡션을 다시 입력하세요.

## 이미지 편집

하나의 지시로 최대 5개의 이미지를 편집하거나 결합할 수 있습니다. `image_1`은 편집 대상 이미지이며, 이미지 2~5는 디자인, 재질 또는 색상 참조를 제공합니다. 프롬프트에서는 `@Image1`, `@Image2` 등으로 이들을 지정하세요.

**입력 소재**

<Card title="retro_crt_room.png" icon="image" href="https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/input/retro_crt_room.png">
  Ideogram Edit 노드의 `image_1` 슬롯에 로드하세요

이 템플릿은 **Build JSON Prompt** 노드로 지시를 작성하므로, 이미지의 영역을 표시하고 캡션을 달 수 있습니다. 편집기가 나타나지 않으면 [Nodes 2.0](/ko/interface/nodes-2)을 켜세요.

`ideogram-4.6`을 사용하는 **Ideogram Edit** 노드는 다음을 추가합니다:

| 입력 | 값 | 효과 |
| --- | --- | --- |
| `size` | `auto` (기본값), `source`, 프리셋 또는 `custom` | `auto`는 이미지와 프롬프트를 바탕으로 약 2K 크기의 캔버스를 선택합니다. `source`는 `image_1`의 크기를 유지합니다. 가로세로 비율이 다른 프리셋은 장면을 재구성합니다. `custom`은 아래의 `width`와 `height`를 사용합니다 |
| `width`, `height` | 256~8192, 32 단위 | `size`가 `custom`일 때만 사용됩니다. 두 치수는 16777216픽셀(4096x4096) 이내이면서 가로세로 비율 6:1 이내여야 합니다 |
| `quality` | `very_low`, `low`, `medium` (기본값), `high` | 높은 등급일수록 비용이 더 들고 시간이 더 오래 걸립니다 |
| `background` | `auto` (기본값), `opaque`, `transparent` | `transparent`는 알파 채널이 있는 이미지를 반환합니다 |
| `seed` | 정수 | 동일한 이미지, 프롬프트, 설정 및 시드는 동일한 결과를 제공합니다 |

16.7 MP를 초과하거나 한 변이 8192픽셀을 초과하는 입력은 업로드되기 전에 축소되며, 각 이미지의 가로세로 비율은 1:6에서 6:1 사이여야 합니다.

편집은 전체 이미지를 다시 렌더링하므로, 편집과 함께 프레이밍과 건드리지 않은 영역이 달라질 수 있습니다. 나머지 그림이 정확히 그대로 유지되어야 할 때는 Precise Edit를 사용하세요.

## 정밀 편집

프롬프트가 요청한 부분만 변경합니다. 건드리지 않은 픽셀은 그대로 유지되며, 출력은 `image_1`의 크기를 유지합니다. 영역을 지정하지 않고 소스가 16.7 MP 또는 한 변 8192픽셀을 초과하면 먼저 축소됩니다. 편집 중인 이미지 외에 참조 이미지를 최대 4개까지 받으며, 마스크가 있는 경우 최대 3개까지 받습니다.

Precise Edit는 참조 슬롯, `@Image1` 주소 지정, `quality`, `seed` 제어를 Edit와 공유합니다. 크기 제어는 없습니다. 영역을 사용하면 출력은 `image_1`의 크기를 유지하고, 영역을 사용하지 않으면 16.7 MP를 초과하거나 한 변이 8192픽셀을 초과하는 소스가 먼저 축소됩니다.

### 한 영역만 편집하기

`context_window`를 설정하면 단일 영역을 원래 해상도로 편집할 수 있습니다:

| `context_window` | 추가 입력 | 편집되는 영역 |
| --- | --- | --- |
| `none` | none | 전체 이미지, 16.7 MP 초과 시 축소됨 |
| `auto` (기본값) | `mask` | 마스크가 표시하는 영역, 또는 마스크가 연결되지 않은 경우 전체 이미지 |
| `custom` | `context_window_bboxes` | 연결된 모든 박스를 감싸는 하나의 사각형(분리된 박스 사이의 공간도 포함되며 편집될 수 있음), 예: **바운딩 박스 생성** 노드에서 생성된 것 |

영역은 한 변당 최대 8192픽셀, 약 16.7 MP이며 최대 6:1 비율입니다. 영역을 사용하는 경우 `image_1` 자체는 모든 화면 비율에서 최대 8192x8192픽셀일 수 있으며, 영역 밖의 픽셀은 변경 없이 그대로 복사됩니다.

제품 색상 변경, 재질 교체, 그리고 사진 나머지 부분의 조명, 배경, 구도를 그대로 유지해야 하는 보정 작업에 사용하세요.

## 시작하기

1. ComfyUI를 최신 버전으로 업데이트합니다.
2. **워크플로** > **템플릿 탐색**을 열고 "Ideogram 4.6"을 검색하거나, 위의 워크플로를 다운로드하여 캔버스에 끌어다 놓습니다.
3. Ideogram 4.5 워크플로에서 시작한 경우 노드에서 `model`을 `ideogram-4.6`으로 설정합니다.
