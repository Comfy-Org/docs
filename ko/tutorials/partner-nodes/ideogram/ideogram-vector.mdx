**Ideogram Vector 1**은 픽셀 대신 벡터 그래픽을 반환합니다. 출력은 Illustrator, Figma, Inkscape 또는 브라우저에서 열어 어떤 크기에서도 경로 단위로 편집할 수 있는 SVG 파일입니다.

ComfyUI는 이를 두 개의 파트너 노드로 제공합니다. **Ideogram Vector Generate SVG**는 최대 다섯 개의 참조 이미지로 안내를 받으며 텍스트 프롬프트로부터 그림을 생성합니다. **Ideogram Vector Image to SVG**는 기존 비트맵을 경로로 추적합니다. 두 노드 모두 클라우드 API 노드입니다. 크레딧이 있는 Comfy 계정이 필요하고, 모델 파일을 다운로드하지 않으며, 워크플로 마지막의 Save SVG 노드를 통해 결과를 기록합니다.

두 노드 모두 로고, 포스터, 플랫 일러스트, 패턴, 라인 아트를 다룹니다. Text to SVG는 프롬프트의 문자를 렌더링하고, Image to SVG는 투명 영역을 투명하게 유지하므로 누끼 처리한 PNG는 그대로 누끼 상태로 남습니다.

**예제 프롬프트**

- `Flat vector badge of a mountain range inside a circle, three colors, heavy outlines, no gradients`
- `Vintage travel poster of a coastal town at golden hour, layered flat shapes with fine hatching, warm cream and terracotta palette, condensed serif lettering 'COSTIERA AMALFITANA' across the bottom`
- `Minimal line art icon of a coffee cup with steam, single weight stroke, transparent background`

최대 다섯 개의 이미지를 `ref_image_1`부터 `ref_image_5`까지로 연결하고, 프롬프트에서 `@Image1`, `@Image2` 등으로 호출하세요. 이미지 1이 기본 소스이고, 나머지는 추가 참조입니다.

### 이미지를 SVG로

비트맵을 패스로 변환합니다. 노드는 그레인, 그라디언트, 배경의 잡동사니까지 그림에 담긴 것을 그대로 읽으므로, 큰 평면 영역이 있는 깔끔한 소스가 가장 잘 변환됩니다. 사진도 사용할 수 있지만, 손으로 편집하기 어려운 수천 개의 작은 패스로 변환됩니다.

`mode`는 디테일이 얼마나 유지되는지를 결정합니다. `simple`은 더 적고 더 큰 색상 블록을 변환하여 더 가볍고 평평한 SVG를 만듭니다. `default`는 더 세밀한 디테일과 더 많은 색상 블록을 유지하므로 결과가 소스에 더 가깝게 남습니다. 이미지를 배치로 넣으면 이미지마다 SVG 하나가 생성됩니다.

## 노드 컨트롤

| 컨트롤 | 값 | 적용 대상 | 효과 |
| --- | --- | --- | --- |
| `model` | `ideogram-vector-1` | 두 노드 | Ideogram Vector 모델 릴리스 |
| `prompt` | 텍스트, 최대 9500자 | Text to SVG | 그림에 대한 설명. `@Image1` 형식 참조를 지원합니다 |
| `images` | 최대 5개 이미지 (`ref_image_1` ~ `ref_image_5`) | Text to SVG | 참조 이미지. 이미지 1이 기본 소스이며, 나머지는 추가 참조입니다 |
| `aspect_ratio` | `auto`, `1:3`, `1:2`, `9:16`, `10:16`, `2:3`, `3:4`, `4:5`, `1:1`, `5:4`, `4:3`, `3:2`, `16:10`, `16:9`, `2:1`, `3:1` | Text to SVG | 캔버스 형태. `auto`는 이미지 1을 따르며, 이미지가 연결되지 않은 경우 프롬프트를 따릅니다 |
| `quality` | `low`, `medium` (기본값), `high` | Text to SVG | 디테일 등급. 등급이 높을수록 시간이 더 오래 걸리고 비용이 더 많이 듭니다 |
| `seed` | 정수, 기본적으로 고정 | Text to SVG | 동일한 프롬프트, 이미지, 설정, 시드는 동일한 SVG를 생성합니다. 변형을 탐색하려면 무작위로 설정하세요 |
| `image` | 하나 이상의 이미지 | Image to SVG | 추적할 비트맵 |
| `mode` | `default` (기본값), `simple` | Image to SVG | `simple`은 더 적고 큰 형태를 유지하며, `default`는 더 세밀한 디테일을 유지합니다 |

## 프롬프트 작성 팁

- **사진이 아니라 그림을 설명하세요.** 형태, 팔레트, 구성이 결과를 좌우합니다: `flat badge, three colors, heavy outlines`. 카메라와 렌즈 관련 표현은 이미지 모델의 영역이며 여기서는 노이즈만 더할 뿐입니다.
- **문자는 따옴표로 감싸세요.** `'COSTIERA AMALFITANA'`는 아트워크 위의 텍스트로 렌더링되지만, 따옴표가 없는 단어는 보통 피사체 설명의 일부로 읽힙니다.
- **원하는 레이어를 지정하세요.** `layered flat shapes with fine hatching` 또는 `single weight stroke`를 요청하면 모델이 어떤 벡터 스타일로 그릴지 알게 됩니다.
- **브랜드 스타일에는 레퍼런스를 사용하세요.** 로고나 목업을 `ref_image_1`로 지정하면 팔레트와 선 두께를 설명하는 것보다 더 잘 반영됩니다. 참조 입력은 이미지를 받으므로 이전 SVG를 재사용하려면 먼저 PNG로 내보내세요.
- **트레이싱할 때는 깨끗한 소스에서 시작하세요.** 평면적인 색상, 날카로운 가장자리, 배경 잡음이 없는 상태가 편집 가능한 파일을 만듭니다. 그레인과 그라디언트는 경로 노이즈로 변합니다.
- **시드로 좋은 결과를 그대로 재현하세요.** Text to SVG는 동일한 프롬프트, 이미지, 설정, 시드로 동일한 SVG를 재현합니다.

## 시작하기

2. 템플릿 라이브러리로 이동해 `Ideogram Vector`를 검색합니다
