## Ideogram P-Image 텍스트 기반 이미지 생성 워크플로

Ideogram의 빠른 P-Image 모델을 사용하여 텍스트 설명으로 이미지를 생성합니다. 텍스트 프롬프트 하나를 입력하면 이미지 하나가 출력됩니다.
