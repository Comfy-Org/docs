**Ideogram 4.5**는 같은 제품군의 최신 모델이자 Ideogram에서 편집 정밀도가 가장 높은 모델입니다. 프롬프트가 요청한 내용만 변경하므로 반복해서 편집해도 색상, 질감, 세부 묘사가 그대로 유지됩니다. ComfyUI에서는 세 개의 파트너 노드로 제공되며, 다른 파트너 노드와 마찬가지로 같은 Comfy 계정에서 이미지 단위로 과금됩니다. Ideogram 4.0은 전용 페이지에서 확인할 수 있습니다: [ComfyUI의 Ideogram 4.0](/ko/tutorials/partner-nodes/ideogram/ideogram-v4).

**Ideogram 4.5 Text to Image** 노드의 입력은 다음과 같습니다.

| 입력 | 값 | 효과 |
| --- | --- | --- |
| `prompt` | 최대 10000자 | 이미지 설명. 이전 실행에서 얻은 `final_prompt`처럼 구조화된 JSON 캡션도 사용할 수 있습니다 |
| `size` | `auto` 또는 1K, 2K 프리셋 | `auto`는 프롬프트에 맞는 캔버스를 모델이 선택합니다. 프리셋은 1K와 2K를 모두 지원하며 `1:1`부터 `23:9`까지 있습니다. 예: `(2K) 2048x2048 (1:1)`, `(1K) 1280x720 (16:9)` |
| `quality` | `low`, `medium`(기본값), `high` | 등급이 높을수록 비용과 시간이 더 듭니다 |
| `magic_prompt` | `auto`(기본값), `on`, `off` | 생성 전에 프롬프트를 상세한 구조화 캡션으로 다시 씁니다. `off`는 입력한 문구를 최대한 그대로 사용합니다 |
| `seed` | 정수 | 실행할 때마다 프롬프트가 다시 작성되므로 seed만으로는 텍스트 기반 이미지 생성 결과를 재현할 수 없습니다 |

이 노드는 `final_prompt`도 출력합니다. 실제 생성에 사용된 구조화 캡션입니다. 이미지를 재현하려면 그 캡션을 프롬프트로 입력하고 `magic_prompt`를 `off`, seed를 같은 값으로 설정하세요.

## 이미지 편집

하나의 지시로 최대 다섯 장의 이미지를 편집하거나 결합합니다. `image_1`은 편집 대상 이미지이고, 2번째부터 5번째 이미지는 디자인, 소재, 색상 참조입니다. 프롬프트에서는 `@Image1`, `@Image2`와 같이 참조합니다.

**입력 자료**

<Card title="interior_orange_sofa.png" icon="image" href="https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/input/interior_orange_sofa.png">

템플릿은 **Build JSON Prompt** 노드로 지시를 구성하므로, 이미지에서 영역을 지정하고 "remove it" 같은 캡션을 달 수 있습니다. 편집기가 보이지 않으면 [Nodes 2.0](/ko/interface/nodes-2)을 켜세요.

**Ideogram 4.5 Edit** 노드의 추가 입력은 다음과 같습니다.

| 입력 | 값 | 효과 |
| --- | --- | --- |
| `size` | `auto`(기본값), `source`, 프리셋, `custom` | `auto`는 이미지와 프롬프트로 약 2K 캔버스를 선택합니다. `source`는 `image_1`의 크기를 유지합니다. 다른 비율의 프리셋은 구도를 다시 구성합니다. `custom`은 아래 `width`와 `height`를 사용합니다 |
| `width`, `height` | 256~4608, 간격 32 | `size`가 `custom`일 때만 사용합니다. 두 값을 합쳐 4194304픽셀(2048x2048) 이내, 비율 6:1 이내여야 합니다 |
| `quality` | `very_low`, `low`, `medium`(기본값), `high` | 등급이 높을수록 비용과 시간이 더 듭니다 |
| `seed` | 정수 | 같은 이미지, 프롬프트, 설정, seed라면 같은 결과가 나옵니다 |

이미지는 모두 합쳐 최대 다섯 장까지 연결할 수 있습니다. 약 4 MP를 넘는 입력은 업로드 전에 축소되며, 각 이미지의 비율은 1:6에서 6:1 사이여야 합니다.

편집은 이미지 전체를 다시 렌더링하므로 편집한 부분 외에 구도와 건드리지 않은 영역도 달라질 수 있습니다. 나머지를 그대로 유지해야 한다면 Precise Edit를 사용하세요.

## 정밀 편집

프롬프트가 요청한 내용만 변경합니다. 변경하지 않은 픽셀은 완전히 그대로 유지되고, 출력은 `image_1`의 크기를 유지합니다. 편집 대상 이미지 외에 최대 네 장의 참조 이미지를 받습니다.

Precise Edit는 참조 슬롯, `@Image1` 참조 방식, `quality`, `seed` 제어를 Edit와 공유합니다. 출력이 항상 `image_1`의 크기와 일치하므로 크기 제어는 없습니다. 이 템플릿도 **Build JSON Prompt** 노드로 지시를 구성합니다.

제품 색상 변경, 소재 교체, 그리고 사진의 나머지 부분에 대한 조명과 배경, 구도를 그대로 유지해야 하는 부분 보정에 적합합니다.
