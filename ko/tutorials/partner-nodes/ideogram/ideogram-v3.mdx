Ideogram 3.0은 Ideogram이 만든 강력한 텍스트 기반 이미지 생성 모델로, 사실적인 품질, 정확한 텍스트 렌더링, 일관된 스타일 제어로 잘 알려져 있습니다.

Ideogram V3 노드는 현재 다음 두 가지 모드를 지원합니다:
- 텍스트 기반 이미지 생성 모드
- 이미지 편집 모드(이미지와 마스크 입력이 모두 제공된 경우)

## Ideogram 3.0 파트너 노드 텍스트 기반 이미지 생성 모드

Ideogram V3를 이미지 및 마스크 입력 없이 사용하면 노드는 텍스트 기반 이미지 생성 모드로 작동합니다.

### 1. 워크플로 파일 다운로드

다음 파일을 다운로드하여 ComfyUI로 드래그하면 워크플로를 불러올 수 있습니다:

![Ideogram 3.0 ComfyUI Workflow](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/ideogram/v3/ideogram_v3_t2i.png)

### 2. 워크플로 단계 완료하기

![Ideogram 3.0 Workflow Steps](/images/tutorial/api_nodes/ideogram/ideogram_v3_t2i.jpg)

번호가 매겨진 단계에 따라 기본 워크플로를 완료하세요:
1. `Ideogram V3` 노드의 `prompt` 필드에 이미지 설명을 입력하세요.
2. `Run`을 클릭하거나 단축키 `Ctrl(cmd) + Enter`를 사용하여 이미지를 생성하세요.
3. API가 결과를 반환한 후 `Save Image` 노드에서 생성된 이미지를 확인하세요. 이미지는 `ComfyUI/output/` 디렉토리에 저장됩니다.

## Ideogram 3.0 파트너 노드 이미지 편집 모드

`Ideogram V3` 노드의 `image`와 `mask` 입력을 모두 연결하면 이미지 편집 모드로 전환됩니다. 프롬프트에 따라 마스크 영역을 다시 생성하고, 마스크 밖의 영역은 그대로 유지합니다.

1. 편집할 이미지를 `Load Image` 노드로 불러온 뒤 `Ideogram V3` 노드의 `image` 입력에 연결합니다
2. 불러온 이미지를 마우스 오른쪽 버튼으로 클릭하고 **Open in MaskEditor**를 선택해 변경할 영역을 칠합니다
3. 마스크 출력을 `Ideogram V3` 노드의 `mask` 입력에 연결합니다. 칠한(흰색) 영역이 교체되고 마스크 밖의 영역은 유지됩니다
4. `prompt` 필드에 편집 지시문을 입력해 마스크 영역에 무엇이 나타나야 하는지 설명합니다
5. `Run`을 클릭하거나 단축키 `Ctrl(cmd) + Enter`로 편집된 이미지를 생성합니다
6. `Save Image` 노드에서 결과를 확인합니다. 편집된 이미지는 `ComfyUI/output/` 디렉터리에도 저장됩니다

<Note>
편집 모드는 `image`와 `mask`가 모두 연결된 경우에만 사용됩니다. 둘 중 하나만 연결하면 텍스트 기반 이미지 생성 모드로 실행됩니다.
</Note>
