Pika H3 Flex는 [MiniMax H3](/ko/tutorials/video/minimax/minimax-h3)를 Pika가 후속 학습(post-training)한 버전으로, Pika 파트너 API를 통해 제공됩니다. **Pika H3 Flex Video** 노드는 텍스트 프롬프트, 첫 프레임 또는 마지막 프레임으로 오디오가 동기화된 클립을 생성하고, **Pika H3 Flex Reference to Video** 노드는 여기에 참조 이미지, 비디오, 오디오 클립을 더할 수 있습니다. 두 노드 모두 다운로드할 가중치가 없습니다.

이 페이지는 API 버전을 다룹니다. H3 베이스에서 두 개의 LoRA 어댑터를 로컬로 실행하는 오픈 가중치 버전은 [Pika H3 Flex](/ko/tutorials/video/pika/pika-h3-flex)를 참고하세요.

## 시작하기

1. ComfyUI를 0.44.1 이상으로 업데이트하세요
2. Template Library로 이동하여 `Pika H3 Flex`를 검색하세요
3. 프롬프트를 작성한 후 워크플로를 실행하세요

## Pika H3 Flex: 텍스트 기반 비디오 생성 (API) {#api_pika_h3_flex_t2v}

- **해상도**: `480p`, `768p`, `1080p`, `2k` 또는 `4k`, 기본값 `768p`. `1080p` 이상은 768p로 렌더링한 뒤 한 번 upscale합니다
- **재생 시간**: 5~15초. 출력은 프레임 그리드를 따르며, 5초는 124프레임으로 약 5.17초입니다
- **화면 비율**: `auto`는 첫 번째로 연결된 프레임을 따르며, 연결된 프레임이 없으면 프롬프트를 따릅니다
- **프롬프트 재작성**: 기본적으로 꺼져 있으며, 프롬프트와 시드를 재현 가능하게 유지합니다

## 이미지 기반 비디오 생성 및 첫/마지막 프레임

동일한 노드가 두 가지를 모두 처리합니다. 시작 이미지를 애니메이트하려면 `first_frame`만 연결하거나, 두 개의 고정된 프레임 사이의 움직임을 생성하려면 `first_frame`과 `last_frame`을 함께 연결하세요.

## 레퍼런스 기반 비디오 생성

**Pika H3 Flex Reference to Video** 노드는 레퍼런스 자료를 바탕으로 클립을 생성하거나 편집합니다. 최대 이미지 9개, 비디오 3개, 오디오 클립 3개, 총 12개의 레퍼런스를 사용할 수 있습니다. 비디오와 오디오 클립은 각각 2~15초이며, 비디오와 오디오는 각각 최대 15초까지 합산됩니다.

프롬프트에서 레퍼런스는 연결 순서에 따라 `@Image1`, `@Video1`, `@Audio1`로 참조하세요. 연결된 비디오의 사운드 대신 새로운 앰비언스나 새 음악을 원할 때는 `reference_video_audio`를 끄세요.

## Pika 오디오 노드

세 가지 오디오 노드는 동일한 Pika API에서 실행되며, 생성된 오디오에 대해 초당 과금됩니다:

- **Pika Soundtrack**: 최대 10분 길이의 비디오 오디오를 동기화된 사운드트랙으로 대체합니다. 지시문은 사운드 효과, 앰비언스 또는 음악을 설명하며, 오디오를 화면에서 도출하려면 비워 두세요
- **Pika SFX**: 텍스트 설명을 바탕으로 1~20초 길이의 사운드 효과를 생성합니다
- **Pika Music**: 텍스트 프롬프트와 선택적 가사로 10~360초 길이의 노래를 생성하거나, 원곡 길이 그대로 커버하며 5~360초로 제한됩니다

텍스트로 구동되는 이 두 오디오 노드의 컨트롤과 프롬프트 작성법, 제한은 [Pika Music 및 Pika SFX](/ko/tutorials/partner-nodes/pika/pika-audio)를 참고하세요.

## 프롬프트 형식

Pika H3 Flex 프롬프트는 MiniMax H3 텍스트 모드 구조를 따르며, 여기서 하나의 설명이 화면과 사운드를 모두 담습니다:

```text
integrated_multimodal_description: [Shot 1] Live-action, cinematic, ... The camera tracks low alongside the board ...

overall_soundscape: Wind rushes past the microphone, the board slaps across shallow water ...

non_diegetic_music: A bright electronic pulse at a fast tempo ...
```

설명된 모든 이벤트가 설정한 재생 시간 안에 있도록 하세요. 대화 태그와 샷 목록을 포함한 전체 프롬프트 구조는 [MiniMax H3 프롬프트 작성 가이드](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md)를 참조하세요.

## 비용

비디오 노드는 출력 1초당 과금되며, 해상도가 높아질수록 요금이 올라갑니다. 현재 크레딧은 [파트너 노드 요금](/ko/tutorials/partner-nodes/pricing)에서 확인하세요.
