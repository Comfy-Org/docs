FIBO Edit는 Bria AI의 JSON 네이티브 이미지 편집 모델로, 이제 ComfyUI에서 파트너 노드를 통해 사용할 수 있습니다. 구조화된 JSON 프롬프트와 이미지를 결합하여 정확하고 정밀한 편집이 가능합니다. 프롬프트를 추측할 필요 없이, 이미지의 다른 부분에 원치 않는 변경이 생기지 않습니다.

## FIBO 편집 정보

**주요 기능:**
- **정밀 편집**: 특정 속성(조명, 색상, 텍스처, 재질)을 변경하되 장면의 나머지 부분은 그대로 유지
- **배경 교체 및 객체 수정**: 대상 영역에 대한 정밀한 제어
- **재현 가능하고 감사 가능한 편집**: 일관된 결과를 위한 구조화된 JSON 입력
- **100% 라이선스 데이터**: 상업적 사용에 대한 완전한 거버넌스 및 법적 명확성
- **강력한 프롬프트 준수**: PRISM 스타일 평가에서 검증됨

## 예제 출력

FIBO Edit은 다양한 편집 작업에 뛰어납니다:

- **시간 변경**: 장면의 조명을 다시 설정하거나 시간을 변경합니다
- **재질 및 텍스처 교체**: 다양한 색상, 재질, 직물, 의류를 시도해 보세요
- **객체 재질 교체**: 특정 객체의 재질을 교체합니다
- **마스크 영역 편집**: 특정 영역을 마스크하여 정밀하게 편집합니다
- **텍스트 조정**: 이미지의 텍스트를 조정합니다
- **아트 스타일 변환**: 이미지를 다른 아트 스타일로 재구성합니다
