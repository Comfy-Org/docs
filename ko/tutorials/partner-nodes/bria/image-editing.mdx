Bria의 이미지 편집 도구는 ComfyUI에서 파트너 노드로 제공됩니다. 이 페이지에서는 마스크 기반 편집 워크플로 세 가지를 다룹니다: **Bria Eraser** (객체 제거), **Bria Expand Image** (테두리 바깥으로 outpainting), **Bria Generative Fill** (마스크 영역 안에 콘텐츠 생성). 세 도구 모두 편집 영역 밖의 모든 부분은 픽셀 단위로 완벽하게 그대로 유지됩니다.

## Bria Image Editing이 뛰어난 점

- **객체 제거**: Bria Eraser는 마스크된 객체나 영역을 지우고 주변 맥락에 맞게 채웁니다. 프롬프트가 필요하지 않습니다.
- **이미지 확장**: Bria Expand Image는 원본 경계 너머로 아웃페인팅하여 해당 이미지의 조명, 원근법, 텍스처와 일치하는 주변을 생성합니다.
- **생성형 채우기**: Bria Generative Fill은 프롬프트를 기반으로 마스크된 영역을 재생성하여 장면에 새로운 콘텐츠를 연출합니다.
- **픽셀 단위 완벽 보존**: 세 워크플로 모두 편집 영역 밖의 모든 것을 변경 없이 그대로 유지합니다.

## 출력 예시

Bria Eraser로 객체를 제거하고, 지워진 영역 뒤쪽 배경을 inpainting합니다:

![Bria: Eraser 출력 예시](https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/output/Bria_Eraser.png)

Bria Expand Image로 이미지를 확장하여 장면을 원래 경계 너머로 연장합니다:

![Bria: Expand Image 출력 예시](https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/output/Bria_Expand_Image.png)

프롬프트를 기반으로 마스크 영역을 재생성하는 생성형 채우기:

![Bria: Generative Fill 출력 예시](https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/output/Bria_GenFill.png)

각 워크플로는 단일 입력 이미지와 마스크를 사용합니다. 템플릿의 **Painter** 노드는 마스크를 그리기 위한 브러시 캔버스를 제공하며, **ImageCompare** 노드가 전후 결과를 나란히 보여줍니다. Painter 노드는 Nodes 2.0에서만 사용할 수 있습니다. "Painter: Node 2.0 only"만 표시된다면 **Menu -> Nodes2.0**을 통해 Nodes 2.0을 활성화하거나, 대신 [Mask Editor](https://docs.comfy.org/interface/maskeditor)를 사용하여 마스크를 만드세요.

**사용 방법**

1. **이미지 로드**: `LoadImage`에 이미지를 업로드하세요. Painter 캔버스와 비교 보기가 자동으로 업데이트됩니다.
2. **마스크 그리기**: 제거하려는 객체나 영역 위에 브러시로 칠하세요. 모델이 깔끔하게 블렌딩할 공간을 확보할 수 있도록 객체 가장자리(머리카락, 유리, 천, 접점)를 약간 넘어 칠하는 것이 좋습니다.
3. **`BriaEraser` 실행**: 프롬프트가 필요하지 않습니다. 노드가 마스크 영역을 지우고 배경을 inpainting합니다. `api_key`가 아직 설정되지 않았다면 입력하세요.
4. **비교 및 저장**: `ImageCompare`로 전후를 확인하고, `SaveImageAdvanced`로 결과를 내보냅니다.

<Note>
마스크 영역은 주변에서 완전히 재생성되므로 결과가 자연스럽게 블렌딩됩니다. 마스크는 이진값입니다. 흰색(255)은 지울 영역을, 검은색(0)은 그 외의 영역을 나타내며, 이미지의 가로세로 비율과 일치해야 합니다. 더 정밀한 결과가 필요하다면 사용 가능한 경우 자동 분할 마스크(SAM 스타일)를 사용하세요. API의 `mask_type`은 `manual`(브러시로 그림)과 `automatic`(알고리즘 생성) 마스크를 구분합니다.
</Note>

**사용 방법**

1. **이미지 로드**: `LoadImage`에 이미지를 업로드하고 `BriaExpandImage`에 연결하세요.
2. `expand_mode` 드롭다운에서 **확장 모드 선택**:
   - **사전 설정 가로세로 비율**: `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9` 중 하나를 선택하세요. 이미지가 중앙에 배치되고 가장자리가 해당 비율에 맞게 확장됩니다.
   - **사용자 지정 비율**: `custom_ratio`를 선택하고 `ratio_width`/`ratio_height`를 설정하세요(예: 21:9의 경우 21과 9). Bria는 0.5~3.0 사이의 가로-세로 비율을 허용하므로 1:2보다 세로로 긴 비율은 수동 모드가 필요합니다.
   - **수동**: `manual`을 선택하고 `canvas_width`/`canvas_height`(최대 5,000 x 5,000), `image_width`/`image_height`, `image_x`/`image_y`(이미지의 왼쪽 위 모서리; 음수면 크롭)로 캔버스에 원본 이미지를 배치하세요.
3. **프롬프트(선택)**: 비워 두면 Bria가 입력 이미지에서 프롬프트를 자동 생성하고 장면과 스타일에 맞게 확장합니다. 직접 작성하여 확장 방향을 명시적으로 안내할 수도 있습니다. 예: "오른쪽으로 이어지는 거리", "가로등 추가", "다른 차량 없음". 영어만 지원되며 특수 문자는 지원되지 않습니다.
4. **선택 사항**: 원치 않는 콘텐츠를 피하려면 `negative_prompt`, 결과를 재현하려면 `seed`, 콘텐츠 검열을 활성화하려면 `moderation`을 사용하세요.
5. **저장**: 이미지 출력을 `SaveImage`에 연결하세요.

<Note>
노드의 `prompt` 출력에는 실제로 사용된 프롬프트가 표시됩니다. 즉, 직접 입력한 값 또는 필드가 비어 있을 때 Bria가 자동 생성한 프롬프트입니다. 대상 가로세로 비율이 이미지의 현재 비율과 같다면(예: 1:1 이미지를 `1:1`로 설정) 변경 없이 원본 이미지가 반환됩니다. 캔버스 영역은 5,000 x 5,000픽셀로 제한됩니다. 최상의 결과를 위해 주요 피사체를 전체 캔버스 면적의 15% 이상으로 유지하세요.
</Note>

**사용 방법**

1. **이미지 로드**: `LoadImage`에 이미지를 업로드하세요. Painter 캔버스와 비교 보기가 자동으로 업데이트됩니다.
2. **마스크 그리기**: 재생성하려는 영역 위에 브러시로 칠하세요. 덩어리 모양의 브러시 마스크가 가장 효과적입니다. 모델이 블렌딩할 공간을 확보할 수 있도록 객체 가장자리(머리카락, 유리, 천, 접점)를 약간 넘어 칠하세요.
3. **프롬프트 작성**: `BriaGenFill`에서 마스크 영역 안에 무엇을 생성할지 설명하세요. 마치 잘린 미니 장면을 연출하듯이 객체의 이름, 재질, 크기, 표면과의 상호작용을 말하고 접촉 그림자를 요청하세요. 약 90~110단어가 가장 효과적입니다. `refine_prompt`를 켠 상태로 유지하세요.
4. **선택 사항**: 원치 않는 세부 사항을 피하려면 `negative_prompt`를 사용하세요. 고정된 `seed`로 마스크나 문구를 반복 조정한 다음, 결과가 만족스러우면 시드를 무작위화하세요.
5. **비교 및 저장**: `ImageCompare`로 전후를 확인하고, `SaveImageAdvanced`로 결과를 내보냅니다.

<Note>
마스크는 픽셀 보정이 아닌 생성적 대체를 트리거합니다. 마스크 영역은 "이 영역 재생성"을 의미하지, "이 영역 보정"을 의미하지 않습니다.
</Note>

## 시작하기

1. ComfyUI를 최신 버전으로 업데이트하세요.
2. Template Library로 이동하여 `Bria Eraser`, `Bria Expand Image` 또는 `Bria Generative Fill`을 검색하세요.
