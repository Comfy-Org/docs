Krea 3은 [Krea](https://www.krea.ai)의 호스팅 이미지 모델입니다. 지시 기반 편집을 위해 만들어졌습니다. 무엇을 바꿀지, 무엇을 그대로 유지할지 설명하면 모델이 편집된 이미지를 반환합니다. 이미지를 연결하지 않으면 대신 텍스트로부터 생성합니다.

Krea 3은 ComfyUI에서 파트너 노드로 실행되므로 다운로드할 가중치가 없고 자체 GPU에서 실행되는 것도 없습니다. 이 노드는 프롬프트와 참조 이미지를 Krea 서버로 전송하고 완료된 이미지를 워크플로로 반환합니다.

## Krea 3의 강점

- **지시 기반 편집**: 일상적인 언어로 변경 사항을 작성하면("초록색 차를 주황색 차로 교체") Krea 3가 전체 이미지를 반환하며, 변경을 요청하지 않은 부분은 그대로 유지합니다
- **동일한 노드에서 텍스트 기반 이미지 생성**: 이미지 입력을 비워 두면 노드가 프롬프트만으로 생성합니다
- **최대 8개의 참조 이미지**: 원하는 순서대로 연결한 다음 프롬프트에서 `@Image1`, `@Image2` 등으로 언급합니다
- **두 가지 사고 모드**: `fast`가 기본값이자 권장 설정이며, `high`는 복잡한 편집을 더 자세히 계획하고 시간이 더 오래 걸립니다
- **정밀 편집**: `precise_edit`를 켜면 편집된 영역 외부의 모든 것을 변경하지 않고 유지합니다
- **해상도 제어**: 1K 또는 2K 출력, `auto` 비율은 첫 번째 참조 이미지를 따릅니다

## Krea 3 텍스트 기반 이미지 생성 워크플로 {#api_krea3_t2i}

프롬프트만으로 이미지를 생성합니다. Krea 3 Image 노드에는 연결된 이미지가 없으므로 프롬프트와 종횡비 설정을 사용합니다.

1. **Krea 3 Image** 노드에 프롬프트를 작성합니다. 기본 제공되는 예시는 피사체, 조명, 구도를 설명하는 하나의 상세한 문장입니다
2. `aspect_ratio`를 설정합니다. 프롬프트를 따르려면 `auto`로 두고, 또는 지원되는 열 가지 비율 중 하나를 선택하세요
3. `resolution`을 선택합니다. 템플릿은 `1K`로 제공되며, `2K`는 더 높은 비용으로 더 큰 캔버스를 제공합니다
4. `thinking_mode`를 `fast`로 두고, 프롬프트가 복잡한 장면을 설명하는 경우에는 `high`로 전환하세요
5. **Queue**를 클릭합니다. 이미지는 `SaveImageAdvanced` 노드에 의해 `ComfyUI/output/`에 저장됩니다

**입력 자료**

<img src="https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/input/wide_format_digital_render.png" alt="wide_format_digital_render.png" style={{width: '100%', height: 'auto'}} />

1. 편집할 이미지를 `LoadImage` 노드에 불러와 **Krea 3 Image** 노드에 연결합니다
2. 편집 내용을 지시문으로 작성합니다. 기본 제공 예시는 장면 속 초록색 자동차를 주황색 자동차로 바꾸고, 그대로 유지해야 할 항목(구도, 배경, 건물, 먼지, 조명, 원근법)을 나열합니다
3. 편집 영역 바깥의 모든 요소를 그대로 유지해야 한다면 `precise_edit`를 켭니다. 최소 한 개의 참조 이미지가 필요합니다
4. 출력 캔버스에 맞게 `aspect_ratio`와 `resolution`을 조정합니다
5. **Queue**를 클릭하고 입력과 결과를 비교합니다

**참조 이미지 더 추가하기**

이 노드는 최대 8개의 이미지를 받을 수 있습니다. 참조하려는 순서대로 이미지를 추가한 다음, 프롬프트에서 각 이미지를 `@Image1`, `@Image2` 등으로 언급하세요.

## Krea 3 노드 파라미터

**Krea 3 Image** 노드(`Krea3ImageNode`)는 다음 설정을 제공합니다:

- `image_1` ... `image_8`: 최대 8개의 참조 이미지이며, 연결 순서대로 번호가 지정됩니다. 텍스트 기반 이미지 생성 시에는 비워 두세요
- `prompt`: 지시 사항 또는 장면 설명. 참조는 `@Image1`, `@Image2` 등으로 지칭합니다
- `aspect_ratio`: `auto` 또는 `1:1`, `4:5`, `3:4`, `2:3`, `9:16`, `5:4`, `4:3`, `3:2`, `16:9`, `21:9` 중 하나. `auto`는 첫 번째 참조 이미지를 따르며, 이미지가 연결되지 않은 경우에는 프롬프트를 따릅니다
- `resolution`: `1K` 또는 `2K` 출력
- `thinking_mode`: `fast`를 권장합니다. `high`는 복잡한 편집을 더 자세히 계획하며 시간이 더 오래 걸립니다
- `precise_edit`: 편집 영역 밖의 모든 항목을 변경하지 않고 유지합니다. 최소 한 개의 참조 이미지가 필요합니다
- `seed`: 요청에 사용할 시드. Krea는 생성 전에 프롬프트를 재작성하므로 동일한 시드로도 동일한 이미지가 재현되지 않습니다

## 참고 사항 및 제한

- **프롬프트 재작성**: Krea는 생성 이전에 프롬프트를 재작성하므로, 동일한 시드를 반복해도 이미지가 반복되지 않습니다
- **레퍼런스 크기**: 각 레퍼런스는 업로드 이전에 출력 픽셀 예산에 맞춰 조정되므로, 2K 설정이 1K보다 더 많은 레퍼런스 디테일을 유지합니다
- **과금**: Krea 3는 파트너 노드이므로 모든 실행이 귀하의 Comfy 계정으로 청구됩니다. 요금은 [파트너 노드 크레딧](/ko/tutorials/partner-nodes/pricing)을 참조하고, 동시에 진행할 수 있는 요청 수는 [동시성 제한](/ko/tutorials/partner-nodes/concurrency-limits)을 참조하세요
- **버전**: Krea 3 Image 노드는 ComfyUI [PR #17067](https://github.com/comfyanonymous/ComfyUI/pull/17067)과 함께 제공되며, 두 템플릿은 `workflow_templates` 0.11.84부터 템플릿 라이브러리에 포함됩니다
