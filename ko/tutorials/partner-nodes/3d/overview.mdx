## 3D 모델로 할 수 있는 작업

- **텍스트 기반 3D 생성**: 텍스트 설명에서 3D 에셋 생성
- **이미지 기반 3D 생성**: 하나 이상의 참조 이미지에서 텍스처가 입혀진 3D 모델 재구성
- **내보내기**: 게임 엔진, DCC 도구, 3D 프린팅 파이프라인용 메시 다운로드

## 작업별 모델 선택

### 일반적인 3D 생성

- **Tripo P1 / Tripo 3.1** (Tripo): 깔끔한 토폴로지의 빠른 텍스트 기반 3D 생성 및 이미지 기반 3D 생성
- **Meshy 7 / Meshy 6** (Meshy): 스타일화 및 PBR 텍스처 출력을 지원하는 텍스트 기반 3D 생성 및 이미지 기반 3D 생성
- **Hunyuan 3D 3.0** (Hunyuan 3D): Tencent의 3D 생성 모델

### 이미지 기반 3D 재구성

- **Rodin Model Generation** (Rodin): 이미지에서 인물 및 캐릭터 에셋을 포함한 상세한 3D 모델 재구성
- **Meshy 7** (Meshy): 높은 텍스처 충실도의 이미지 기반 3D 생성
