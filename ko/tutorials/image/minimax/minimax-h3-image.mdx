**MiniMax-H3-Image**는 MiniMax의 오픈 웨이트 이미지 모델로, 체크포인트 하나로 텍스트 기반 이미지 생성과 이미지 편집을 모두 처리합니다. diffusion transformer는 BF16 기준 33.1B 파라미터이며, CFG 없이 6-step 샘플러로 증류되었습니다. 출력은 약 16 MP의 네이티브 해상도이므로 4096 x 4096 이미지를 업스케일 체인 없이 한 번에 생성할 수 있습니다.

**관련 링크**

- [MiniMaxAI/MiniMax-H3-Image (Hugging Face)](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image): 공식 모델 카드와 가중치
- [MiniMax-H3-Image (ModelScope)](https://modelscope.cn/models/minimax/MiniMax-H3-Image): 중국 본토용 공식 미러
- [MiniMax-AI/MiniMax-H3-Image (GitHub)](https://github.com/MiniMax-AI/MiniMax-H3-Image): 공식 예제와 skill
- [Comfy-Org/MiniMax-H3-Image (Hugging Face)](https://huggingface.co/Comfy-Org/MiniMax-H3-Image): diffusion 모델 및 이미지 VAE
- [Comfy-Org/MiniMax-H3 (Hugging Face)](https://huggingface.co/Comfy-Org/MiniMax-H3): 이 모델에서 사용하는 Qwen3-VL-32B 텍스트 인코더
- [MiniMaxAI/MiniMax-H3-Image-PE (Hugging Face)](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image-PE): 공식 프롬프트 확장기

## 주요 기능

- **하나의 checkpoint로 텍스트 기반 이미지 생성과 편집**: 별도의 편집 모델이나 어댑터를 로드할 필요가 없습니다
- **6단계 샘플링**: 가이드가 1로 고정되어 CFG 패스와 네거티브 프롬프트가 없습니다
- **기본 약 16 MP**: 업스케일 패스 없이 4096 x 4096에서 최대 6272 x 2688
- **다중 레퍼런스**: 최대 16개의 입력 이미지를 사용하며, 프롬프트에서 `<Picture 1>`부터 지정합니다
- **선택적 프롬프트 확장기**: 짧은 요청을 모델이 가장 잘 읽는 상세 캡션으로 변환합니다
- **오픈 가중치**: ComfyUI에서 완전한 로컬 제어

## 샘플링 및 캔버스 크기

두 템플릿 모두 증류된 스케줄을 제공합니다:

| 설정 | 값 |
| --- | --- |
| 샘플러 | euler |
| 스케줄러 | simple |
| 스텝 | 6 |
| 가이드(CFG) | 1 |
| Denoise | 1 |

가이드가 1이면 classifier-free guidance 패스가 없으므로 템플릿에는 네거티브 프롬프트가 포함되지 않습니다. 피하고 싶은 요소를 포함해 원하는 모든 내용을 포지티브 프롬프트에 작성하세요.

기본 출력은 약 16 MP입니다. 모든 변은 32 px의 배수로 생성되며, 너비와 높이는 임의의 값을 사용할 수 있습니다. 다음 크기는 일반적인 비율을 커버합니다:

| 화면 비율 | 크기(너비 x 높이) |
| --- | --- |
| 1:1 | 4096 x 4096 |
| 4:3 | 4736 x 3552 |
| 3:4 | 3552 x 4736 |
| 3:2 | 5024 x 3360 |
| 2:3 | 3360 x 5024 |
| 16:9 | 5472 x 3072 |
| 9:16 | 3072 x 5472 |
| 21:9 | 6272 x 2688 |

더 작은 캔버스도 사용할 수 있으며 시간이 덜 걸립니다. 텍스트 기반 이미지 생성 템플릿에서 해상도 선택기는 화면 비율과 목표 메가픽셀 수를 별도로 설정하므로, 4 MP는 제한이 아니라 시작점입니다.

## 이미지 편집에서의 참조 이미지

이미지 편집 템플릿은 소스 이미지를 `<Picture 1>`로 모델에 전송합니다. 추가 이미지는 순서대로 `<Picture 2>`, `<Picture 3>`으로 최대 16개의 참조까지 레이블이 지정되며, 프롬프트는 각 이미지를 해당 레이블로 지칭합니다. 첫 번째 이미지는 편집 대상이고, 나머지는 피사체의 동일성, 소품, 재질 또는 구도를 제공합니다. 짧은 지시문으로 충분합니다. 예를 들어 `<Picture 1>`의 차량을 `<Picture 2>`의 차량으로 교체하는 것입니다.

참조를 추가하려면 워크플로에 `Load Image` 노드를 하나 더 배치하고 프롬프트 생성 단계와 조건화 노드 모두에 연결합니다. 조건화 노드의 VAE 입력은 연결한 상태로 두세요. 템플릿은 이미 연결되어 있으며, VAE가 있으면 참조 이미지가 이미지 latent로도 조건에 포함되지만, 없으면 텍스트 인코더만 거치므로 편집 결과가 소스를 덜 따라갑니다.

참조 이미지는 별도의 준비가 필요하지 않습니다. 템플릿이 소스를 4 MP로 조정한 뒤 32 px의 배수로 반올림하고, 조건화 노드가 내부 복사본의 크기를 자체적으로 조정합니다. 비전 측에는 1024 px의 짧은 변을, VAE 측에는 1024~2048 px 사이로 제한된 짧은 변을 사용하며, 둘 다 32 px 그리드를 따릅니다.

편집 결과는 소스 크기와 무관하게 약 4 MP로 반환되며 모델의 16 MP가 아닙니다. 더 큰 편집 결과가 필요하면 `scale total pixels`로 설정된 `Resize Image/Mask` 노드에서 목표값을 높이고, 메모리가 부족하면 샘플링 전에 낮추세요.

## 프롬프트 확장기 {#prompt-expander}

두 템플릿 모두 샘플러 앞에 텍스트 생성 단계를 두고 있습니다. 텍스트 기반 이미지 생성 템플릿에서는 프롬프트를 상세한 영어 캡션으로 다시 쓰고 캔버스의 종횡비를 선택합니다. 이미지 편집 템플릿에서는 짧은 지시를 완성된 이미지에 대한 레퍼런스 인식 설명으로 바꿉니다.

MiniMax-H3-Image의 공식 확장기는 Qwen3.8-27B FP4 모델이며, [MiniMaxAI/MiniMax-H3-Image-PE](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image-PE)로 공개되어 있습니다. 템플릿은 대신 더 가벼운 Qwen3.5 9B W4A8 빌드를 사용하므로, 확장기가 21 GB diffusion 모델과 함께 하나의 GPU에 들어갑니다.

텍스트 기반 이미지 생성 템플릿은 확장기가 꺼진 상태로 제공되므로, 프롬프트가 입력한 그대로 모델에 전달됩니다. 캡션을 다시 쓰고 종횡비를 자동으로 선택하게 하려면 확장기를 켜면 됩니다. 이미지 편집 템플릿은 확장기가 켜진 상태로 제공됩니다.
