Ideogram 4.0은 Ideogram의 최신 텍스트 기반 이미지 생성 모델로, 사용자의 하드웨어에서 완전히 실행되는 오픈소스 모델로 출시되었습니다. 뛰어난 사실적 품질, 정확한 텍스트 렌더링, 정밀한 스타일 제어를 제공합니다. 일반 자연어 또는 **구조화된 JSON 프롬프트**를 사용하여 레이아웃, 색상, 이미지 내 텍스트를 세밀하게 제어할 수 있습니다.

### 프롬프트 형식

오픈소스 워크플로는 두 가지 프롬프트 모드를 지원합니다:

1. **자연어**: 빠르고 쉬우며 간단한 아이디어에 가장 적합
2. **구조화된 JSON**: 레이아웃, 색상, 스타일을 정밀하게 제어

워크플로에는 어떤 LLM과도 함께 사용하여 맞춤 JSON 프롬프트를 생성할 수 있는 프롬프트 구성 템플릿이 포함되어 있습니다.

워크플로 내부의 노트에 다음과 같이 설명되어 있습니다:
> 이 모델은 구조화된 JSON 캡션(장면 요약, 스타일 블록, 배경, 그리고 바운딩 박스와 16진수 색상 팔레트를 포함한 선택적 객체별 설명)으로 학습되었습니다. 공식 추론은 해당 스키마에 대해 프롬프트를 검증합니다.

### 워크플로 단계

1. 모델을 다운로드하여 올바른 디렉터리에 배치합니다 (위 표 참조)
2. 워크플로 파일을 다운로드하여 ComfyUI로 드래그합니다
3. Ideogram4 서브그래프 노드에 프롬프트(자연어 또는 구조화된 JSON)를 입력합니다
4. (선택 사항) `ResolutionSelector` 노드를 사용하여 해상도를 조정합니다
5. `Run`을 클릭하거나 단축키 `Ctrl(cmd) + Enter`로 이미지를 생성합니다
6. `Save Image` 노드에서 결과를 확인합니다. 출력 파일은 `ComfyUI/output/`에 저장됩니다

### 안전 필터에 대한 참고 사항

"Image blocked by safety filter"가 표시되면 이는 Ideogram 4.0의 내장 안전 필터입니다. JSON이 아닌(일반 텍스트) 프롬프트는 오탐지율이 더 높습니다. 구조화된 JSON 프롬프트를 사용하면 프롬프트가 차단될 가능성이 줄어듭니다.

자세한 내용은 [Ideogram 4 공식 프롬프팅 가이드](https://github.com/ideogram-oss/ideogram4/blob/main/docs/prompting.md#safety-filter)를 참조하세요.
