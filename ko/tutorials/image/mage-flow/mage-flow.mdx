**Mage-Flow**는 Microsoft Research에서 개발한 컴팩트한 4B 규모의 생성 스택으로, 효율적인 텍스트-이미지 생성과 명령 기반 이미지 편집을 지원합니다. 이 스택은 두 가지 공동 설계 구성 요소, 즉 경량 고충실도 잠재 토크나이저인 [Mage-VAE](https://huggingface.co/microsoft/Mage-VAE)와 rectified flow matching으로 학습된 Native-Resolution Multimodal Diffusion Transformer (NR-MMDiT)로 구성됩니다. 네이티브 해상도 패킹과 함께, 이 공유 스택은 두 가지 모델 인스턴스를 구동합니다: 텍스트-이미지 생성을 위한 Mage-Flow와 명령 기반 이미지 편집을 위한 Mage-Flow-Edit입니다. 각각 Base, RL 정렬, 4-step Turbo 변형으로 제공됩니다.

Mage-Flow는 512에서 2048 픽셀까지의 네이티브 해상도를 모든 종횡비(4:1과 같은 극단적인 비율 포함)에서 지원합니다.

### 원클릭 생성

가장 간단하게는, 서브그래프에 텍스트 프롬프트를 입력하고 원하는 해상도를 설정한 후 **Queue Prompt**를 클릭하세요. 기본 설정으로 최소한의 구성만으로도 고품질 이미지를 생성할 수 있습니다.

### 워크플로우 사용법

1. **프롬프트 입력** — 서브그래프의 프롬프트 입력란에 텍스트 설명을 입력합니다
2. **해상도 설정** — 원하는 출력 크기에 맞게 너비와 높이를 조정합니다. Mage-Flow는 512에서 2048 픽셀까지의 네이티브 해상도를 지원합니다.
3. **설정 조정** — 필요에 따라 시드(seed)와 네거티브 프롬프트를 구성합니다
4. **Queue 클릭** — `Ctrl+Enter`를 눌러 생성합니다

이미지 편집 워크플로우는 자연어 설명을 사용하여 이미지를 편집하는 명령 기반 모델인 Mage-Flow-Edit을 사용합니다. 하나 이상의 참조 이미지를 업로드하고 원하는 편집 내용을 설명하세요.

워크플로우는 몇 가지 부분으로 구성되어 있습니다:

1. **LoadImage**: 참조 이미지 업로드 (최대 3개)
2. **Image Edit (Mage-Flow-Edit) 서브그래프**: 모델 로딩, 참조 이미지 컨디셔닝, 프롬프트 처리, 샘플링을 포함하는 핵심 편집 파이프라인
3. **ImageCompare**: 원본과 편집된 이미지를 나란히 비교합니다
4. **SaveImage**: 편집된 결과를 저장합니다

### 이미지 편집 사용법

1. **참조 이미지 업로드** — **LoadImage** 노드를 사용하여 편집할 이미지를 불러옵니다 (최대 3개)
2. **편집 명령 입력** — 적용하려는 편집 내용을 텍스트로 입력합니다 (예: "배경을 해변 장면으로 바꿔줘" 또는 "이걸 수채화 그림으로 만들어줘")
3. **설정 조정** — 해상도, 시드(seed) 및 기타 매개변수를 구성합니다
4. **Queue 클릭** — `Ctrl+Enter`를 눌러 생성합니다
