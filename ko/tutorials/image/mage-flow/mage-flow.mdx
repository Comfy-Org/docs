**Mage-Flow**는 Microsoft Research의 소형 4B 규모 생성형 스택으로, 효율적인 텍스트 기반 이미지 생성과 명령 기반 이미지 편집을 위해 설계되었습니다. 이 스택은 공동 설계된 두 가지 구성 요소로 구축됩니다: 경량 고충실도 잠재 데이터 토크나이저인 [Mage-VAE](https://huggingface.co/microsoft/Mage-VAE)와 정류 플로우 매칭으로 학습된 네이티브 해상도 멀티모달 Diffusion Transformer(NR-MMDiT)입니다. 네이티브 해상도 패킹과 함께, 이 공유 스택은 두 가지 모델 구현체를 지원합니다: 텍스트 기반 이미지 생성을 위한 Mage-Flow와 명령 기반 이미지 편집을 위한 Mage-Flow-Edit입니다. 각각 Base, RL 정렬, 4-step Turbo 변형으로 제공됩니다.

Mage-Flow는 4:1과 같은 극단적인 치수를 포함한 모든 종횡비에서 한 변당 512~2048픽셀의 네이티브 해상도를 지원합니다.

### 원클릭 생성

가장 간단한 사용법은 서브그래프에 텍스트 프롬프트를 입력하고 원하는 해상도를 설정한 다음 **실행 대기열에 프롬프트 추가**를 클릭하는 것입니다. 기본 설정은 최소한의 구성으로 고품질 이미지를 생성합니다.

### 워크플로 사용하기

1. **프롬프트 입력**: 서브그래프의 프롬프트 입력란에 텍스트 설명을 입력합니다
2. **해상도 설정**: 원하는 출력 크기에 맞게 너비와 높이를 조정합니다. Mage-Flow는 한 변당 512~2048픽셀의 기본 해상도를 지원합니다.
3. **설정 조정**: 필요에 따라 시드와 네거티브 프롬프트를 구성합니다
4. **실행 대기열 클릭**: `Ctrl+Enter`를 눌러 생성합니다

이미지 편집 워크플로는 자연어 설명을 사용하여 이미지를 편집하는 지시 기반 모델인 Mage-Flow-Edit를 사용합니다. 참조 이미지를 하나 이상 업로드하고 원하는 편집 내용을 설명하세요.

워크플로는 몇 가지 부분으로 구성됩니다.

1. **LoadImage**: 참조 이미지 업로드(최대 3개)
2. **Image Edit(Mage-Flow-Edit) 서브그래프**: 모델 로딩, 참조 이미지 조건화, 프롬프트 처리, 샘플링을 포함하는 핵심 편집 파이프라인
3. **ImageCompare**: 원본과 편집된 이미지를 나란히 비교
4. **SaveImage**: 편집된 출력 저장

### 이미지 편집 사용하기

1. **참조 이미지 업로드**: 편집하려는 이미지를 **LoadImage** 노드로 로드합니다(최대 3개).
2. **편집 지시 입력**: 적용하려는 편집 내용을 텍스트 설명으로 입력합니다(예: "배경을 해변 장면으로 바꾸기" 또는 "이것을 수채화 그림으로 변환").
3. **설정 조정**: 해상도, 시드 및 기타 파라미터를 구성합니다.
4. **Queue 클릭**: `Ctrl+Enter`를 눌러 생성합니다.
