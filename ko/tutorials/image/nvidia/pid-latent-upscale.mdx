**PiD(Pixel Diffusion Decoder)**는 증류된 4단계 픽셀 공간 처리로 확산 모델의 **latent**를 **4배 초해상도 이미지**로 변환합니다. 별도의 VAE 디코딩이 필요 없습니다. 이 워크플로는 PiD로 Z-Image-Turbo latent를 **1024px에서 4096px**로 업스케일하는 방법을 보여줍니다.

## PiD 작동 방식

PiD는 확산 모델 이름만이 아니라 상위 모델의 **VAE / latent 공간**(인코더 측)을 기준으로 체크포인트를 맞춥니다. 초기 생성에 사용한 모델의 latent 공간에 해당하는 PiD 체크포인트를 선택해야 합니다.

이 워크플로는 Flux.1과 같은 16채널 VAE를 공유하는 **Z-Image-Turbo**(1024px latent에서 4096px 출력)를 사용합니다.

### 서브그래프 설정

**Latent Upscale Decode (PiD)** 서브그래프에서 다음 항목을 설정합니다.

| 설정 | 값 | 설명 |
|---|---|---|
| `latent_format` | `flux` | Flux.1/Flux.2/Z-Image는 `flux`, SD3는 `sd3`(Flux.2는 128채널로 자동 감지) |
| `degrade_sigma` | `0.0` | 입력 latent가 얼마나 "완성"되었는지. 완전히 디노이즈된 경우 `0.0`(기본값), 부분적이면 `0.1–0.8`, 순수 노이즈면 `1.0` |

### 실행 단계

1. **latent 생성**. T2I 워크플로(예: Z-Image-Turbo)로 latent 이미지를 생성합니다.
2. **PiD에 연결**. latent를 **Latent Upscale Decode (PiD)** 서브그래프 노드에 연결합니다.
3. **체크포인트 선택**. 상위 모델의 VAE latent 공간과 맞는 PiD 체크포인트를 선택합니다.
4. **출력 크기 설정**. PiD 출력 크기를 입력 latent 해상도의 **4배**로 설정합니다.
5. **실행**. 서브그래프가 한 번의 4단계 처리로 디코딩과 업스케일을 수행합니다.
