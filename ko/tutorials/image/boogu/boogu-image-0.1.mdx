**Boogu-Image-0.1**은 Apache-2.0 오픈소스 통합 이미지 생성 및 편집 모델 제품군입니다. 이해와 생성을 통합한 시스템을 사용해 사진, 텍스트 렌더링, 스타일화, 이미지 편집 작업에서 경쟁력 있는 성능을 제공합니다.

**모델 변형**:
- **Boogu-Image-0.1-Turbo** – 고품질 생성과 포토리얼리즘에 초점을 맞춘 4스텝 증류 텍스트-이미지 변형으로, LoRA rank-128 모듈을 탑재했습니다. 3-4회의 샘플링 스텝만 필요합니다. 대부분의 텍스트-이미지 생성 사용 사례에서 기본값으로 권장됩니다.
- **Boogu-Image-0.1-Base** – 뛰어난 다양성과 제어성을 갖춘 기반 모델로, 파인튜닝 및 2K 해상도의 초고밀도 텍스트 렌더링에 적합합니다.
- **Boogu-Image-0.1-Edit** – 지시 기반 제어로 이미지 편집 및 변환 작업을 위해 파인튜닝된 변형입니다.

**모델 하이라이트**:
- **10B 파라미터**로 소비자용 GPU에서 효율적인 추론
- **Apache-2.0 라이선스**로 자유로운 사용 및 다운스트림 개발 가능
- **이중 언어 텍스트 렌더링**(중국어 및 영어)과 신뢰할 수 있는 타이포그래피
- **다재다능한 기능**: 사실적인 사진, 스타일화, 포스터 디자인, 정확한 텍스트 렌더링

**관련 링크**:
- [프로젝트 페이지](https://boogu.org/)
- [GitHub](https://github.com/boogu-project/Boogu-Image)
- [Hugging Face (ComfyUI)](https://huggingface.co/Comfy-Org/Boogu-Image)
- [Hugging Face (Turbo)](https://huggingface.co/Boogu/Boogu-Image-0.1-Turbo-fp8)
- [Hugging Face (Edit)](https://huggingface.co/Boogu/Boogu-Image-0.1-Edit-fp8)

### Boogu Turbo: Text to Image (`image_boogu_image_0_1_turbo_t2i`)

Boogu Turbo 모델을 사용해 텍스트 프롬프트로 고품질 이미지를 생성합니다. 이는 단 4스텝으로 포토리얼리스틱한 출력을 생성하는 증류된 10B 파라미터 텍스트-이미지 파이프라인입니다.
