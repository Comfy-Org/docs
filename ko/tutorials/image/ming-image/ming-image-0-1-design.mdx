**Ming Image 0.1 Design**은 inclusionAI(Ant Group)에서 MIT 라이선스로 공개한 6B 오픈 웨이트 텍스트 기반 이미지 생성 모델입니다. 사진 같은 사실감보다는 디자인 작업을 겨냥합니다. UI 화면, 인포그래픽, 포스터처럼 텍스트가 많이 들어가는 레이아웃이 대상입니다. 출력은 실제 알파 채널을 포함한 RGBA이므로, 투명한 결과물을 디자인 파일에 바로 넣을 수 있습니다.

이 워크플로는 샘플러 앞에 프롬프트 재작성 단계를 둡니다. Qwen3.8-27B가 샘플링 전에 짧은 아이디어를 구조화된 레이아웃 캡션으로 확장하며, 입력한 텍스트를 그대로 전송하고 싶을 때는 인핸서를 끌 수 있습니다.

## Ming Image 0.1 Design의 장점

- **길고 구조화된 레이아웃**: 여러 섹션이 있는 페이지, 포스터, 인포그래픽을 섹션별로 구성
- **텍스트 렌더링**: 프롬프트에 인용된 문자열을 충실히 따르므로 라벨, 가격, 제목을 읽기 쉽게 유지
- **투명 출력**: 분리된 요소를 합성하기 위한 실제 알파 채널이 있는 RGBA 이미지
- **프롬프트 재작성**: 명령을 따르는 비전 언어 모델이 짧은 개요를 상세한 레이아웃 캡션으로 확장
- **오픈 가중치**: MIT 라이선스이므로 체크포인트를 자유롭게 사용하고 미세 조정할 수 있음

### 워크플로 실행 단계

1. 해당 노드 하단의 **Enter subgraph** 버튼으로 **Text to Image (Ming Image 0.1 Design)** 서브그래프에 들어갑니다
2. `prompt` 필드에 프롬프트를 작성합니다. 레이아웃을 섹션별로 설명하고, 렌더링하려는 문구는 따옴표 안에 넣습니다
3. `ResolutionSelector` 노드로 캔버스를 선택합니다. 2048 x 2048이 품질이 가장 좋고, 1024 x 1024는 더 빠릅니다
4. 프롬프트 인핸서를 켜 두면 Qwen3.8-27B가 프롬프트를 확장하고, `enable_PE`를 끄면 입력한 텍스트가 그대로 전달됩니다
5. 프롬프트를 실행 대기열에 넣습니다. 디코딩된 이미지가 `PreviewImage` 노드에 표시됩니다
6. 투명 배경을 원하면 프롬프트 맨 앞에 RGBA 문구를 추가합니다. 예: `RGBA, 4-channel, transparent background`

1. ComfyUI를 최신 버전으로 업데이트하세요. Ming Image 0.1 지원은 최신 ComfyUI 빌드에 포함되어 있습니다.
2. 템플릿 라이브러리로 이동하여 `Ming Image 0.1 Design`을 검색하세요.

Comfy Desktop과 Comfy Cloud는 안정 릴리스를 따르므로, 최신 ComfyUI 빌드에서만 지원되는 모델은 아직 해당 환경에서 사용하지 못할 수 있습니다.
