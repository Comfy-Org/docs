**Qwen-Image**는 Alibaba의 Qwen 팀이 공개한 첫 번째 이미지 생성 파운데이션 모델입니다. Apache 2.0 라이선스로 오픈소스화된 20B 파라미터 MMDiT(멀티모달 디퓨전 트랜스포머) 모델입니다. 이 모델은 **복잡한 텍스트 렌더링**과 **정밀한 이미지 편집**에서 큰 진전을 이루었으며, 영어와 중국어를 포함한 여러 언어에서 고충실도 출력을 제공합니다.

**모델 특징**:
- **뛰어난 다국어 텍스트 렌더링**: 영어, 중국어, 한국어, 일본어 등 여러 언어의 고정밀 텍스트 생성을 지원하며, 폰트 디테일과 레이아웃 일관성을 유지합니다
- **다양한 아트 스타일**: 사실적인 장면부터 인상주의 회화, 애니메이션 미학에서 미니멀리스트 디자인까지 다양한 크리에이티브 프롬프트에 유연하게 대응합니다

**관련 링크**:
 - [GitHub](https://github.com/QwenLM/Qwen-Image)
 - [Hugging Face](https://huggingface.co/Qwen/Qwen-Image)
 - [ModelScope](https://modelscope.cn/models/qwen/Qwen-Image)

현재 Qwen-Image에는 여러 ControlNet 지원 옵션이 있습니다:
- [Qwen-Image-DiffSynth-ControlNets/model_patches](https://huggingface.co/Comfy-Org/Qwen-Image-DiffSynth-ControlNets/tree/main/split_files/model_patches): canny, depth, inpaint 모델 포함
- [qwen_image_union_diffsynth_lora.safetensors](https://huggingface.co/Comfy-Org/Qwen-Image-DiffSynth-ControlNets/blob/main/split_files/loras/qwen_image_union_diffsynth_lora.safetensors): canny, depth, pose, lineart, softedge, normal, openpose를 지원하는 이미지 구조 제어 LoRA
- InstantX ControlNet: 업데이트 예정

### 3. 워크플로우 사용 방법

![Step Guide](/images/tutorial/image/qwen/image_qwen_image-guide.jpg)

1. `Load Diffusion Model` 노드에 `qwen_image_fp8_e4m3fn.safetensors`가 로드되어 있는지 확인합니다
2. `Load CLIP` 노드에 `qwen_2.5_vl_7b_fp8_scaled.safetensors`가 로드되어 있는지 확인합니다
3. `Load VAE` 노드에 `qwen_image_vae.safetensors`가 로드되어 있는지 확인합니다
4. `EmptySD3LatentImage` 노드에 올바른 이미지 크기가 설정되어 있는지 확인합니다
5. `CLIP Text Encoder` 노드에 프롬프트를 설정합니다. 현재 영어, 중국어, 한국어, 일본어, 이탈리아어 등을 지원합니다
6. lightx2v의 8스텝 가속 LoRA를 활성화하려면 노드를 선택하고 `Ctrl + B`로 활성화한 다음, 8번 단계의 설명에 따라 Ksampler 설정을 수정합니다
7. `Queue` 버튼을 클릭하거나 단축키 `Ctrl(cmd) + Enter`로 워크플로우를 실행합니다
8. 모델 버전과 워크플로우에 따라 KSampler 파라미터를 조정합니다

<Note>
 증류 모델과 lightx2v의 8스텝 가속 LoRA는 동시에 사용할 수 없는 것으로 보입니다. 다양한 조합을 실험하여 함께 사용할 수 있는지 확인해 보세요.
</Note>

### 3. 워크플로우 사용 방법

현재 diffsynth에는 Canny, Depth, Inpaint 세 가지 패치 모델이 있습니다.

ControlNet 관련 워크플로우를 처음 사용하는 경우, 제어 이미지는 모델이 사용하고 인식할 수 있도록 지원되는 이미지 형식으로 전처리해야 한다는 점을 이해해야 합니다.

![Input Type Diagram](/images/tutorial/image/qwen/controlnet_input_types.jpg)

- Canny: canny 엣지 처리된 선화 윤곽
- Depth: 공간 관계를 보여주는 전처리된 깊이 맵
- Inpaint: 다시 그려야 할 영역을 Mask로 표시해야 합니다

이 패치 모델은 세 가지 다른 모델로 나뉘어 있으므로, 입력 시 올바른 전처리 유형을 선택하여 적절한 이미지 전처리가 이루어지도록 해야 합니다.

**Canny 모델 ControlNet 사용 방법**

![Canny Workflow](/images/tutorial/image/qwen/image_qwen_image_controlnet_patch-canny.jpg)
1. `qwen_image_canny_diffsynth_controlnet.safetensors`가 로드되어 있는지 확인합니다
2. 후속 처리를 위해 입력 이미지를 업로드합니다
3. Canny 노드는 네이티브 전처리 노드로, 설정한 파라미터에 따라 입력 이미지를 전처리하여 생성을 제어합니다
4. 필요한 경우 `QwenImageDiffsynthControlnet` 노드의 `strength`를 수정하여 선화 제어 강도를 조절할 수 있습니다
5. `Run` 버튼을 클릭하거나 단축키 `Ctrl(cmd) + Enter`로 워크플로우를 실행합니다

> qwen_image_depth_diffsynth_controlnet.safetensors를 사용하려면 이미지를 깊이 맵으로 전처리하고 `image processing` 부분을 교체해야 합니다. 이 사용법은 이 문서의 InstantX 처리 방법을 참조하세요. 나머지 부분은 Canny 모델 사용법과 유사합니다.

**Inpaint 모델 ControlNet 사용 방법**
![Inpaint Workflow](/images/tutorial/image/qwen/image_qwen_image_controlnet_patch-inpaint.jpg)

Inpaint 모델의 경우 [마스크 에디터](/ko/interface/maskeditor)를 사용하여 마스크를 그리고 이를 입력 제어 조건으로 사용해야 합니다.

1. `ModelPatchLoader`에 `qwen_image_inpaint_diffsynth_controlnet.safetensors` 모델이 로드되어 있는지 확인합니다
2. 이미지를 업로드하고 [마스크 에디터](/ko/interface/maskeditor)를 사용하여 마스크를 그립니다. 해당 `Load Image` 노드의 `mask` 출력을 `QwenImageDiffsynthControlnet`의 `mask` 입력에 연결하여 해당 마스크가 로드되도록 해야 합니다
3. `Ctrl-B` 단축키로 워크플로우의 기존 Canny를 바이패스 모드로 설정하여 해당 Canny 노드 처리가 적용되지 않도록 합니다
4. `CLIP Text Encoder`에 마스크 영역을 어떻게 변경할지 입력합니다
5. 필요한 경우 `QwenImageDiffsynthControlnet` 노드의 `strength`를 수정하여 해당 제어 강도를 조절할 수 있습니다
6. `Run` 버튼을 클릭하거나 단축키 `Ctrl(cmd) + Enter`로 워크플로우를 실행합니다

-  [qwen_image_union_diffsynth_lora.safetensors](https://huggingface.co/Comfy-Org/Qwen-Image-DiffSynth-ControlNets/blob/main/split_files/loras/qwen_image_union_diffsynth_lora.safetensors): canny, depth, pose, lineart, softedge, normal, openpose를 지원하는 이미지 구조 제어 LoRA

### 3. 워크플로우 사용 방법

이 모델은 canny, depth, pose, lineart, softedge, normal, openpose 제어를 지원하는 통합 제어 LoRA입니다. 많은 이미지 전처리 네이티브 노드가 완전히 지원되지 않으므로, [comfyui_controlnet_aux](https://github.com/Fannovel16/comfyui_controlnet_aux)와 같은 도구를 사용하여 다른 이미지 전처리를 완료해야 합니다.

![Union Control LoRA](/images/tutorial/image/qwen/image_qwen_image_union_control_lora.jpg)

1. `LoraLoaderModelOnly`에 `qwen_image_union_diffsynth_lora.safetensors` 모델이 올바르게 로드되어 있는지 확인합니다
2. 입력 이미지를 업로드합니다
3. 필요한 경우 `Canny` 노드 파라미터를 조정할 수 있습니다. 입력 이미지에 따라 더 나은 이미지 전처리 결과를 얻으려면 다른 파라미터 설정이 필요하므로, 해당 파라미터 값을 조정하여 디테일을 늘리거나 줄여 보세요
4. `Run` 버튼을 클릭하거나 단축키 `Ctrl(cmd) + Enter`로 워크플로우를 실행합니다

> 다른 유형의 제어의 경우에도 이미지 처리 부분을 교체해야 합니다.
