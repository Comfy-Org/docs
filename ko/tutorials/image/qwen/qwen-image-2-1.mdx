**Qwen-Image-2.1**은 Alibaba Qwen 팀의 Qwen-Image 시리즈에서 최신 오픈 웨이트 릴리스입니다. 단일 모델이 텍스트 기반 이미지 생성과 지시 기반 이미지 편집을 모두 처리하며, 네이티브 2K 출력, 전문적인 타이포그래피, 투명 배경을 위한 알파 채널을 갖추고 있습니다.

**주요 기능**:
- **하나의 모델에서 생성과 편집**: 동일한 가중치가 텍스트 기반 이미지 생성 프롬프트와 편집 지시를 모두 처리하므로, 워크플로에서 체크포인트를 교체할 필요가 없습니다
- **네이티브 2K 출력**: 더 작은 결과를 업스케일링하는 대신 최대 2048x2048로 직접 생성합니다
- **전문적인 타이포그래피**: 인포그래픽, 슬라이드, UI 목업, 포스터, 패키징 디자인에서 촘촘한 작은 텍스트와 복잡한 레이아웃이 유지됩니다
- **알파 채널 지원**: VAE가 4개 채널을 가지므로 투명 배경 이미지를 나중에 잘라내는 대신 직접 생성하고 편집할 수 있습니다
- **다중 이미지 편집**: 참조 이미지는 슬롯 순서대로 텍스트 인코더에 이어 붙습니다. 노드는 `image_1`부터 `image_16`까지의 슬롯을 노출하며, 프롬프트는 인덱스로 이를 지정합니다. 예를 들어 `image_1`은 `<image1>`로 작성합니다
- **국소 편집**: 변경할 객체나 영역을 설명하면 이미지의 나머지 부분은 그대로 유지됩니다

## 워크플로 설정

### 샘플러 설정

두 템플릿 모두 `steps` 25, `cfg` 1, `euler` 샘플러, `simple` scheduler로 샘플링합니다. 텍스트 기반 이미지 생성 워크플로는 시드를 고정하고, 이미지 편집 워크플로는 시드를 무작위로 설정합니다.

### 해상도

**텍스트 기반 이미지 생성**: **해상도 선택기** 노드가 화면 비율(1:1, 16:9, 9:16, 3:2, 2:3, 4:3, 3:4, 21:9)과 메가픽셀 목표값을 설정하며, 여기서 1.0 MP는 약 1024x1024입니다. 템플릿은 기본적으로 1 MP의 1:1로 설정됩니다. Qwen-Image-2.1은 2K로 네이티브 생성하므로, 2048x2048 정사각형 출력에는 목표값을 약 4.0 MP로 설정하세요.

**이미지 편집**: 템플릿 기본값인 `custom_size` 끄기 상태에서는 출력이 `image_1`의 화면 비율을 따르며, 약 `resolution` x `resolution` 픽셀(기본 1024, 32의 배수로 반올림)로 조정됩니다. 이는 `image_1`의 원본 픽셀 크기가 아닙니다. 각 참조 이미지를 32의 배수로 반올림한 자체 크기로 유지하려면 `resolution`을 0으로 설정하세요. 대신 **해상도 선택기** 캔버스를 사용하려면 `custom_size`를 켜고, 크기를 조정된 `image_1` 크기에 가깝게 유지하세요. 그렇지 않으면 편집 결과가 어긋날 수 있습니다.

### 이미지 편집 프롬프트 작성

참조 이미지는 슬롯 순서대로 텍스트 인코더에 삽입되며, 프롬프트는 각 이미지를 인덱스로 지칭합니다. 템플릿 프롬프트가 이 패턴의 좋은 예입니다:

```
Keep the character and pose in <image1> unchanged, put this light blue denim shirt from <image2> on the character, preserve the original facial features, hair, body shape and pose
```

### KV 캐시

이미지 편집 워크플로에는 **Qwen Image 2.1 Cache** 노드가 포함되어 있으며, 이 노드는 캐시된 텍스트와 참조 프리픽스가 저장되는 위치를 설정합니다:

| 설정 | 값 | 효과 |
| --- | --- | --- |
| `device` | `auto`(기본값), `gpu`, `cpu`, `off` | `auto`는 남는 VRAM을 사용한 뒤 RAM을 사용합니다. `cpu`는 연산 뒤에서 프리페치되며 속도 손실이 거의 없습니다. `off`는 매 스텝마다 프리픽스를 다시 계산하므로 더 느리지만, 디버깅할 때 캐시를 배제할 수 있습니다 |
| `dtype` | `default`(기본값), `int8`, `int4` | 저장 정밀도입니다. `default`는 무손실이고, `int8`은 bf16 정도의 정확도로 캐시를 절반으로 줄이며, `int4`는 4분의 1로 줄이지만 스텝당 오류가 대략 두 배가 됩니다 |
