**Krea 2**는 [Krea AI](https://www.krea.ai)의 이미지 생성 모델로, 처음부터 새로 학습되었으며 창의적이고 스타일리시한 탐구에 중점을 두고 있습니다.

Krea 2는 함께 작동하도록 설계된 두 가지 모델로 제공됩니다: **RAW에서 LoRA를 학습하고, Turbo에서 추론을 실행**하세요:
- **Krea 2 RAW**: 전체 스텝 샘플링(52스텝)을 사용하는 베이스 모델입니다. 증류되지 않아 다양하고 유연성이 높으며, 파인튜닝과 LoRA 학습에 이상적입니다.
- **Krea 2 Turbo**: 빠르고 고품질의 생성을 위한 8스텝 증류 checkpoint입니다. RAW에서 학습된 LoRA는 Turbo에 원활하게 적용됩니다.

Krea 2는 두 가지 변형으로 제공됩니다:

## Krea-2 Turbo 텍스트 기반 이미지 생성 워크플로

### Krea-2: 텍스트 기반 이미지 생성 (`image_krea2_turbo_t2i`)

미적 품질과 창의적 제어를 위해 구축된 파운데이션 모델인 Krea 2를 사용하여 텍스트 프롬프트로 이미지를 생성합니다. 표현력이 풍부하고 스타일이 다양한 이미지 렌더링에 중점을 둡니다.

워크플로는 몇 가지 부분으로 구성됩니다:

1. **Text to Image (Krea-2 Turbo) 서브그래프**: 모델 로딩, 프롬프트 처리, 샘플링, VAE 디코딩을 포함하는 핵심 생성 파이프라인
2. **ResolutionSelector**: 원하는 출력 해상도를 선택합니다. Krea 2는 1K부터 2K까지의 출력을 지원합니다. 메가픽셀 값을 2.0으로 설정하면 2K 해상도를 얻을 수 있습니다.
3. **CustomCombo (LoRA 선택기)**: 사용 가능한 스타일 LoRA를 위한 사전 구축된 트리거 워드 선택기입니다. 추가 LoRA를 다운로드하면 이 선택기를 사용자 정의하고 해당 LoRA 파일과 페어링할 수 있습니다.
4. **SaveImage**: 생성된 이미지를 저장합니다

### 원클릭 생성

가장 간단한 방법은 서브그래프에 텍스트 프롬프트를 입력하고, 해상도를 선택한 후 **Queue Prompt**를 클릭하는 것입니다. 기본값(8스텝, 프롬프트 향상 활성화, LoRA 없음)으로 최소한의 설정만으로 고품질 이미지를 생성할 수 있습니다.

### 워크플로 컨트롤

**Text to Image (Krea-2 Turbo)** 서브그래프는 다음 컨트롤을 제공합니다:

| 컨트롤 | 설명 |
|---------|-------------|
| **Text String (User Prompt)** | 생성하려는 이미지를 설명하는 텍스트 프롬프트 |
| **prompt_enhance** | LLM 기반 프롬프트 확장 켜기/끄기 |
| **LLM_max_token** | 프롬프트 향상의 최대 토큰 길이 |
| **Width / Height** | 출력 해상도 (ResolutionSelector로 제어) |
| **Seed** | 재현성을 위한 랜덤 시드 |
| **enable_lora?** | 스타일 LoRA 활성화 또는 비활성화 |
| **LoRA Strength** | 적용된 스타일 LoRA의 강도 |
| **LoRA Trigger Word** | 선택한 LoRA의 트리거 워드 (자동 입력) |

스타일 참조 워크플로는 Krea-2 Turbo 파이프라인에 참조 이미지 컨디셔닝을 추가하여 구축되었습니다. 하나 이상의 참조 이미지를 업로드하여 생성되는 출력의 미적 스타일, 분위기, 시각적 방향에 영향을 줄 수 있습니다.

워크플로는 몇 가지 부분으로 구성됩니다:

1. **Image Style Reference (Krea-2 Turbo) 서브그래프**: 스타일 참조를 지원하는 핵심 생성 파이프라인으로, 모델 로딩, 참조 이미지 컨디셔닝, 프롬프트 처리, 샘플링을 포함합니다
2. **LoadImage**: 스타일 참조 이미지를 업로드합니다
3. **ResolutionSelector**: 원하는 출력 해상도를 선택합니다. Krea 2는 1K부터 2K까지의 출력을 지원합니다.
4. **SaveImage**: 생성된 이미지를 저장합니다

### 스타일 참조 사용하기

1. **참조 이미지 업로드**: **LoadImage** 노드를 사용하여 하나 이상의 스타일 참조 이미지를 로드합니다
2. **프롬프트 입력**: 서브그래프의 사용자 프롬프트 입력란에 텍스트 설명을 입력합니다
3. **모델 변형 선택**: 서브그래프의 모델 선택기에서 모델 checkpoint를 선택합니다
4. **설정 조정**: 해상도, 시드를 구성하고 선택적으로 프롬프트 향상을 활성화합니다
5. **Queue 클릭**: `Ctrl+Enter`를 눌러 생성합니다

이 스타일 참조 워크플로는 전용 diffusion 모델과 LoRA를 사용합니다. 텍스트 인코더와 VAE는 텍스트 기반 이미지 생성 워크플로와 공유됩니다.
