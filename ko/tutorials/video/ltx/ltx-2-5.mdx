[LTX-2.5](https://huggingface.co/Lightricks/LTX-2.5)는 Lightricks의 오픈 가중치 비디오 및 월드 모델로, 이제 ComfyUI에서 기본 지원됩니다. 이 모델은 LTX-2.3을 기반으로 장면 복잡도에 따라 렌더링 컴퓨팅을 할당하는 Diffusion Fidelity Rendering 파이프라인을 도입했습니다. LTX-2.3의 동기화된 오디오 및 비디오 생성을 유지하면서 네이티브 멀티샷을 추가했습니다. 한 번의 생성으로 여러 개의 연결된 샷을 만들어 컷 전반에 걸쳐 캐릭터, 환경, 조명, 음성을 유지합니다.

LTX-2.5는 복잡한 프롬프트에서 여러 주제, 작업, 조명, 카메라 방향을 유지하는 맞춤형 Gemma 4 12B 텍스트 인코더와, 짧은 프롬프트를 상세한 지시문으로 확장하는 선택적 프롬프트 강화기를 제공합니다. 자동 재생 시간은 디퓨전 시작 이전에 설명된 작업에서 클립 길이를 예측합니다. 증류 모델은 더 빠른 생성을 제공하며, 출력은 네이티브 4K HDR, 최대 50 FPS, 전문가용 후반 작업 파이프라인을 위한 RAW 워크플로를 지원합니다.

ComfyUI는 LTX-2.5용 기본 워크플로 4개를 제공합니다:

- **텍스트 기반 비디오 생성** (T2V): 텍스트 프롬프트에서 비디오 생성
- **이미지 기반 비디오 생성** (I2V): 입력 이미지에서 비디오 생성
- **FLF2V**: 첫 번째 프레임과 마지막 프레임 이미지 사이를 보간
- **DFR**: Diffusion Fidelity Rendering 파이프라인으로 이미지 또는 텍스트에서 오디오가 포함된 비디오를 생성

<UpdateReminder/>

## 주요 기능

- **Diffusion 충실도 렌더링**: 키프레임 우선 생성 방식으로 모든 장면을 고충실도 키프레임의 그리드 위에 구성하여 픽셀 단위 품질을 구현합니다.
- **Diffusion 비디오 디코더**: 빠른 모션에서도 더 선명한 얼굴, 읽기 쉬운 텍스트, 더 적은 번짐을 제공합니다.
- **네이티브 멀티샷**: 한 번의 생성으로 여러 개의 연결된 샷을 만들어내며, 컷 사이에서도 캐릭터, 환경, 조명, 음성, 스타일을 유지합니다.
- **Gemma 4 12B 텍스트 인코더**: 복잡한 프롬프트에서도 여러 대상, 작업, 조명, 디테일, 카메라 방향을 유지합니다.
- **프롬프트 강화기**(선택): 짧은 프롬프트를 풍부한 시네마틱 지시문으로 확장하는 경량 모델입니다.
- **자동 재생 시간**: diffusion이 시작되기 이전에 설명된 작업으로부터 적절한 클립 길이를 예측합니다.
- **네이티브 4K HDR**: 전문 후반 작업용으로 제작된 고해상도 HDR 출력으로, 최대 50 FPS에서 동기화된 오디오-비디오를 지원합니다.

## 시작하기

LTX-2.5는 ComfyUI에서 기본적으로 지원됩니다. 시작하려면:

1. ComfyUI를 최신 버전으로 업데이트하세요
2. **템플릿 라이브러리** > **비디오** > 원하는 LTX-2.5 워크플로를 선택하세요
3. Hugging Face에서 모델 저장소에 대한 액세스를 요청한 다음(아래 참조), 팝업에 따라 모델을 다운로드하고 워크플로를 실행하세요

<Callout type="warning">
  LTX-2.5 모델 파일은 Hugging Face의 액세스 제한(gated) 저장소인 [Lightricks/LTX-2.5](https://huggingface.co/Lightricks/LTX-2.5)와 [Lightricks/LTX-2.5-22b-IC-LoRA-Pixel-Spatial-Upscaler](https://huggingface.co/Lightricks/LTX-2.5-22b-IC-LoRA-Pixel-Spatial-Upscaler)에 호스팅되어 있습니다. 저장소 페이지를 열고 모델 라이선스에 동의한 후 액세스 요청이 승인될 때까지 기다렸다가 모델을 다운로드하세요. 액세스 권한이 없으면 모델 다운로드가 실패합니다.
</Callout>

#### 프롬프트 작성 팁

1. **전체 장면 설명**: 샷 유형, 장면, 동작, 캐릭터, 카메라 움직임을 하나의 자연스러운 문단에 포함하세요.
2. **오디오**: 장면에 필요한 소리와 대사를 설명하세요. 모델이 비디오와 동기화된 오디오를 함께 생성합니다.
3. **프롬프트 강화기 사용(선택)**: 워크플로는 기본적으로 꺼져 있습니다. LTX-2.5 노드에서 `prompt_enhance`를 활성화하면 짧은 프롬프트를 상세한 시네마틱 지침으로 확장합니다. 전용 강화기 모델(약 5GB)이 필요하며 생성 시간이 약 1~2분 늘어납니다

1. **다음에 일어날 일을 설명하세요**: 입력 이미지 이후의 움직임, 카메라 이동, 소리를 작성하세요. 이미 보이는 내용을 다시 설명하지 마세요.

### LTX-2.5 DFR: 이미지 기반 비디오 생성

LTX-2.5의 Diffusion Fidelity Rendering 경로로 이미지 한 장에서 동기화된 오디오가 포함된 비디오를 생성합니다. DFR은 제작 품질을 위한 레시피입니다. 증류 transformer와 디테일링 IC-LoRA를 조합하고, 클립 내부에서 생성한 키프레임을 이후 단계가 가이드로 재사용합니다. `Switch to T2V`를 켜면 동일한 파이프라인을 텍스트만으로 실행할 수 있습니다.

#### 세 단계

| 단계 | 실행 해상도 | 스텝 수 | 하는 일 |
| :---- | :------ | :---- | :----------- |
| 1. 생성 | 출력 크기의 절반 | 8 | 비디오, 초당 하나의 디테일링 키프레임, 오디오를 한 번의 패스로 함께 디노이즈 |
| 2. 공간 x2 | 출력 크기 | 3 | 1단계 latent를 업샘플링하고 픽셀 공간 디테일링 IC-LoRA로 다시 샘플링합니다. 절반 해상도 latent를 참조로 사용 |
| 3. 시간 x2 | 241 프레임, 48 fps | 4 | 같은 재생 시간에서 프레임 레이트를 두 배로 늘리고, 2단계 키프레임을 가이드로 고정 |

모든 단계는 `euler` 샘플러, `cfg` 1.0, 고정된 `ManualSigmas` 스케줄로 샘플링합니다. 체크포인트가 증류 모델이므로 스텝 수와 스케줄 자체가 레시피의 일부입니다. 값을 바꾸면 결과의 느낌이 달라집니다.

세 번째 단계는 선택 사항입니다. `Run 3rd stage - Temporal Upscale`를 끄면 이 단계를 건너뛰고 2단계 프레임 레이트의 클립을 얻습니다. 오디오는 1단계에서 파이프라인 전체로 이어지므로 시간 업스케일을 해도 소리는 바뀌지 않습니다.

#### 워크플로 제어 항목

- `Start image (I2V)`: 첫 프레임입니다. `Switch to T2V`가 켜져 있으면 무시됩니다
- `Output size (aspect / megapixels)`: 목표 화면 비율과 픽셀 예산이며 32의 배수로 반올림됩니다. 1단계는 이 크기의 절반에서 실행됩니다
- `Switch to T2V`: 시작 이미지 없이 텍스트만으로 파이프라인을 실행합니다
- `Float (fps)`와 `Float (Duration)`: 기본값은 24 fps, 5초로 121 프레임입니다
- `Enable Prompt Enhancer`: 샘플링 전에 작은 Gemma 4 인코더로 프롬프트를 다시 쓰고 확장합니다
- `Enable Tiled Decode`: VAE를 타일 단위로 디코딩해 VRAM 사용량을 낮춥니다. 세부 묘사가 약간 부드러워집니다

#### 프롬프트 팁

1. **하나의 연속된 샷으로 작성하세요**: DFR은 생성된 키프레임을 축으로 클립을 구성하므로, 컷을 이어 붙이기보다 한 번에 이어지는 장면을 설명하세요
2. **오디오도 같은 패스에서**: 대사는 따옴표로 묶고 주변음과 효과음도 설명하세요. 모델이 비디오와 함께 오디오를 생성합니다
3. **카메라 움직임은 완만하게**: 노이즈가 많은 텍스처와 매끄러운 그라데이션 위에서 빠르게 움직일 때 파이프라인이 끓어 보이거나 밴딩이 나타나기 가장 쉽습니다
