**Stable Audio 1.0**는 Stability AI의 첫 번째 오픈소스 오디오 생성 모델입니다. 텍스트 프롬프트를 받아 오디오 클립을 생성합니다. ComfyUI에서는 표준 텍스트 기반 오디오 생성 파이프라인처럼 작동합니다. CLIP이 프롬프트를 인코딩하고, KSampler가 잠재 데이터를 디노이징하며, VAE가 이를 오디오로 디코딩합니다.

**관련 링크**:
- [GitHub: Stability-AI/stable-audio-open-1.0](https://github.com/Stability-AI/stable-audio-open-1.0)

워크플로는 **표준 ComfyUI 노드**를 사용합니다. 커스텀 노드가 필요하지 않습니다. Stable Audio 1.0 체크포인트를 로드하고, CLIP 텍스트 인코더(t5-base)를 통해 프롬프트를 인코딩하며, KSampler로 잠재 오디오를 디노이즈하고, 모델의 VAE를 통해 오디오로 디코딩합니다.

**사용 방법**:
1. **체크포인트 로드**: `CheckpointLoaderSimple` 노드가 `stable-audio-open-1.0.safetensors`를 사용합니다
2. **프롬프트 작성**: `CLIPTextEncode` 노드에 설명을 입력합니다 (예: "heaven church electronic dance music")
3. **재생 시간 설정**: `EmptyLatentAudio` 노드의 길이 값을 조정합니다 (기본값 47.6초)
4. **실행** (`Ctrl/Cmd + Enter`)을 클릭하여 생성합니다. 오디오는 `ComfyUI/output/audio/`에 저장됩니다.

## 모델 다운로드

워크플로를 로딩 중일 때 ComfyUI에서 누락된 모델에 대한 다운로드 링크를 안내합니다. 수동으로 설정하려면 아래 파일을 다운로드하여 올바른 폴더에 넣으세요.

### 체크포인트

<Card title="stable-audio-open-1.0.safetensors" icon="download" href="https://huggingface.co/StabilityAI/stable-audio-open-1.0/blob/main/stable-audio-open-1.0.safetensors">
    2.3GB. models/checkpoints/ 폴더에 넣으세요.
  </Card>

체크포인트를 다음 위치에 넣으세요:

```
📂 ComfyUI/
├── 📂 models/
│   └── 📂 checkpoints/
│       └── stable-audio-open-1.0.safetensors
```

### 텍스트 인코더

<Card title="t5-base.safetensors" icon="download" href="https://huggingface.co/Comfy-Org/t5-base/blob/main/t5-base.safetensors">
    프롬프트 조건화를 위한 텍스트 인코더입니다. models/text_encoders/ 폴더에 넣으세요.
  </Card>

텍스트 인코더를 다음 위치에 넣으세요:

```
📂 ComfyUI/
├── 📂 models/
│   └── 📂 text_encoders/
│       └── t5-base.safetensors
```

파일을 넣은 후 ComfyUI에서 **R**을 눌러 노드를 새로 고침하고 최신 모델을 로드하세요.
