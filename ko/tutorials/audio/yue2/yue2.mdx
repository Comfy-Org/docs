YuE2는 Multimodal Art Projection(m-a-p)의 오픈 소스 음악 생성 모델로, 스타일 프롬프트와 가사를 입력하면 보컬과 반주가 포함된 완성된 곡을 만들어냅니다. 3B 파라미터 모델인 YuE2는 인트로, 벌스, 코러스, 브리지, 아웃트로와 같은 섹션으로 구성된 완전한 곡 구조를 생성하며, 영어, 중국어, 일본어를 비롯한 여러 언어의 노래를 지원합니다.

YuE2가 대부분의 텍스트-투-뮤직 시스템과 다른 점은 편집 가능한 작곡 단계입니다. 오디오를 생성하기 전에 YuE2는 먼저 ABC 표기법으로 기호 음악 계획을 작성할 수 있습니다. 이는 멜로디이며 선택적으로 코드를 포함할 수 있고, 직접 확인하고 편집할 수 있습니다. 그런 다음 이 계획을 바탕으로 최종 곡이 렌더링됩니다. 이 방식은 한 번에 생성하는 오디오 생성보다 결과를 조정하기 쉽게 만들어 주며, 아래의 커버 워크플로에서도 핵심 역할을 합니다. 이 워크플로에서는 참조 곡을 동일한 표기법으로 채보한 뒤 새로운 스타일과 가사로 다시 노래하게 합니다.

YuE2는 ComfyUI에서 기본적으로 지원됩니다. 시작하기 전에 [ComfyUI](https://github.com/comfyanonymous/ComfyUI)를 최신 버전으로 업데이트하세요. ComfyUI v0.35.0 이상이 필수이며, AMD GPU에서는 v0.35.1 이상이 권장됩니다.

## 텍스트로 음악 생성 {#audio_yue2_text2music}

음악 스타일 설명과 직접 작성한 가사로 완성된 곡을 생성합니다. ABC 플래닝을 활성화하면 YuE2가 먼저 편집 가능한 기호 음악 계획(멜로디와 선택적으로 코드)을 만들고, 그 계획을 바탕으로 최종 오디오를 생성합니다.

### 1. 실행 단계

1. **Style**에 원하는 음악에 대한 설명을 작성합니다
2. `[Verse]`, `[Chorus]` 같은 섹션 태그를 사용해 **Lyrics**에 곡의 가사를 입력합니다
3. 플래닝 **Mode**를 선택합니다. `full`은 멜로디와 코드를 생성하고, `melody`는 멜로디만 생성합니다
4. 곡의 **Max Duration**을 설정합니다
5. 워크플로를 실행 대기열에 넣어 곡을 생성합니다

### 3. 스타일 작성하기

주요 음악적 특징을 설명합니다. 유용한 요소는 다음과 같습니다:

- **장르**: 팝, 재즈, 록, 일렉트로닉, 포크
- **보컬**: 따뜻한 여성 보컬, 표현력 있는 남성 보컬, 부드러운 보컬
- **언어**: 영어, 중국어, 일본어 등
- **템포**: 90 BPM, 느림, 경쾌함
- **악기**: 피아노, 일렉트릭 기타, 베이스, 드럼, 신스

예시:

> English, warm female vocal, contemporary pop, 96 BPM, piano, rounded electric bass, restrained drums, clear diction

음악적 지시는 가사가 아니라 **Style**에 넣으세요.

### 4. 가사 작성하기

섹션 태그로 곡의 구조를 설명합니다:

```
[Verse]
Morning light across the window
City waking down below

[Chorus]
Run with me into the sunlight
Leave the shadows far behind
```

`[Verse]`, `[Chorus]`, `[Bridge]`, `[Outro]` 같은 섹션으로 곡을 구성할 수 있습니다. 가사 필드에는 노래할 단어만 넣으세요.

### 5. ABC 플래닝

**Mode** 옵션은 기호 계획 단계를 제어합니다:

- **full**: 곡을 생성하기 전에 멜로디와 코드가 포함된 계획을 만듭니다. 일반적인 텍스트 투 뮤직 생성에 권장됩니다.
- **melody**: 멜로디만 있는 계획을 만들고 반주는 더 자유롭게 생성되도록 합니다.

**abc** 입력을 비워 두면 플래닝이 비활성화되고 Style과 Lyrics에서 직접 음악을 생성합니다.

### 6. Max Duration

**Max Duration**은 생성된 곡의 최대 길이를 초 단위로 설정합니다. 최대 900입니다. 생성된 음악 구조와 가사에 따라 곡이 더 일찍 끝날 수 있습니다. 프롬프트가 길면 ComfyUI가 토큰 예산을 자동으로 줄여 생성이 모델의 컨텍스트 안에 들어가도록 합니다.

### 1. 실행 단계

1. **Audio**에서 참조 곡을 로드합니다
2. **Style**에서 새로운 음악적 방향을 설명합니다
3. **Lyrics**에 노래할 가사를 입력합니다
4. 워크플로를 실행 대기열에 넣어 새로운 커버 버전을 생성합니다

참조 오디오는 멜로디를 제공하고, YuE2는 입력한 Style과 Lyrics를 바탕으로 새로운 연주와 편곡을 생성합니다.

### 3. 커버의 동작 방식

이 워크플로는 참조 오디오를 YuE2에 직접 입력하지 않습니다. 대신:

```
Reference Audio
    ↓
SheetSage2 (transcription)
    ↓
Melody ABC score
    ↓
YuE2 (generation with new Style and Lyrics)
```

원본 곡과의 연결 고리가 멜로디이기 때문에, 커버는 새로운 가사가 원본의 구절 구성과 음절 수에 어느 정도 가깝게 유지될 때 가장 잘 작동합니다.

### 4. Style과 Lyrics 작성하기

목표로 하는 음악 스타일을 명확하게 설명하세요. 장르, 보컬 유형, 언어, 템포, 악기, 분위기 등의 요소가 유용합니다:

> 영어, 소울이 넘치는 재즈 팝, 표현력이 풍부한 남성 보컬, 편안한 88 BPM, 로즈 피아노, 업라이트 베이스, 브러시 드럼, 따뜻한 색소폰, 친밀한 심야 분위기

텍스트-투-뮤직 워크플로와 동일한 `[Verse]` / `[Chorus]` / `[Bridge]` / `[Outro]` 섹션 태그를 사용하세요. 멜로디 매칭을 향상하려면 새 가사의 길이를 원본 가사의 각 줄과 비슷하게 유지하세요.
