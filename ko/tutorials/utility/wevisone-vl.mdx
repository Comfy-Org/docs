WeVisOne-VL은 산문 대신 형태로 답하는 소형 비전-언어 모델입니다. 이미지와 짧은 텍스트 쿼리를 주면 한 번의 패스로 박스, 포인트 또는 인스턴스별 알파 매트를 반환합니다. 어노테이션도, 객체별 프롬프트도 필요 없습니다.

ComfyUI에서는 **WeVisOne-VL Detect** 노드로 실행됩니다. 아래 템플릿은 이를 서브그래프로 감싸고 매트, 소스 이미지 위에 그려진 박스, 전경 및 배경 컷아웃을 미리 보여 주므로, 매트를 배경 제거, 마스킹 또는 합성 체인에 바로 투입할 수 있습니다.

가중치는 Apache-2.0 라이선스의 Tencent 릴리스로, ComfyUI용으로 [Comfy-Org/WeVisOne-VL](https://huggingface.co/Comfy-Org/WeVisOne-VL)에서 재패키징되었습니다. 지원은 [ComfyUI #17632](https://github.com/Comfy-Org/ComfyUI/pull/17632)에 추가되었으며, 템플릿에는 ComfyUI 0.45.0 이상이 필요합니다.

## 작업

`task` 위젯은 쿼리를 checkpoint가 학습한 지시문으로 다시 작성합니다. 각 작업은 쿼리를 조금씩 다른 형태로 받습니다:

| `task` | 쿼리 형태 | 반환값 |
| :--- | :--- | :--- |
| `segmentation` | `human`과 같은 짧은 명사구 하나 | 알파 매트와 상자(`individual_masks`가 꺼져 있으면 통합 매트 하나) |
| `detection` | 한 줄에 레이블 하나 | 상자만 |
| `referring` | `the cup on the left`와 같은 설명 구 | 상자 |
| `point` | 한 줄에 레이블 하나 | 중심점을 JSON으로 |
| `count_box` | 개수를 셀 대상 | 개수와 각 인스턴스의 상자 |
| `count_point` | 개수를 셀 대상 | 개수와 각 인스턴스의 점 |
| `ocr` | 없음 | 이미지의 모든 단어에 상자 |
| `ocr_grounding` | 찾을 정확한 문자열 | 해당 문자열을 둘러싼 상자 |
| `visual_prompt` | 없음, `bboxes` 입력 사용 | 참조 상자와 유사한 객체의 상자 |
| `freeform` | 무엇이든 | 쿼리를 전체 프롬프트로 사용한 원시 응답 |

쿼리는 짧게 유지하세요. 완전한 문장을 쓰면 `segmentation`이 장황해지며, 대상에 대한 설명보다 대상을 지칭하는 구가 더 잘 작동합니다.

## 노드에 대한 추가 제어

- **`individual_masks`**: on이면 상자마다 마스크 하나, off이면 프레임마다 하나의 통합 마스크
- **`max_length`**: 답변 길이 상한으로, 기본 4096 tokens이며 최대 32768까지 가능
- **출력**: `masks`, `bboxes`, `points`(x, y, label, frame을 담은 JSON), `text`(원시 답변)
