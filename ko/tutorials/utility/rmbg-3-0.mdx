RMBG 3.0은 Bria의 세 번째 배경 제거 모델이며, 분할 네트워크 대신 생성 모델을 기반으로 구축된 첫 모델입니다. 단단한 이진 마스크가 아니라 부드러운 회색조 알파 매트를 렌더링하므로 머리카락, 털, 메시, 베일, 모션 블러가 부분 투명도를 유지합니다.

기반은 8B diffusion transformer와 Qwen3-VL-4B 프롬프트 및 이미지 인코더를 갖춘 Fibo 2.0이며, classifier-free 가이드 없이 4 샘플링 스텝으로 증류되었습니다. ComfyUI 지원은 [ComfyUI #17240](https://github.com/Comfy-Org/ComfyUI/pull/17240)에서 추가되었고, 템플릿에는 ComfyUI 0.46.0 이상이 필요합니다.

워크플로는 이미지 한 장을 입력받아 RGBA 컷아웃, 배경 플레이트, 처리된 매트 세 가지를 출력합니다.

1. 사진을 `LoadImage` 노드에 끌어다 놓습니다.
2. `auto_prompt`를 켭니다. 템플릿의 기본값은 꺼짐입니다. 끈 상태에서는 고정 지시문이 전송되어 `subject_note`가 사용되지 않습니다.
3. 선택 사항: `subject_note`에 재질에 대한 짧은 문장을 하나 작성합니다. 예: `Clear glass bottle, paper label, metal cap`.
4. 워크플로를 실행합니다. `SaveImage`가 두 결과를 모두 `ComfyUI/output/rmbg3/`에 기록합니다.

## 워크플로 컨트롤

- `auto_prompt`: 켜면 비전 모델이 이미지와 `subject_note`를 바탕으로 매팅 지시문을 작성합니다. 끄면 모델이 학습한 고정 지시문이 그대로 전송되고 `subject_note`는 무시됩니다.
- `cfg`: 1.0으로 유지하세요. 이 모델은 가이드 없이 증류되었으므로, 값을 높이면 소스에 대한 충실도를 희생하는 대신 투명도를 얻습니다.
- `alpha_brightness`, `alpha_contrast`, `mask_threshold`, `hard_mask`: 매트 후처리입니다. `hard_mask`는 꺼 두어 부드러운 가장자리를 유지하세요.
- `mask_expand`, `mask_tapered_corners`: 적용 이전에 매트를 확장하고 둥글게 만듭니다.

## 컷아웃이 잘못되었을 때

| 증상 | 해결 방법 |
| :--- | :--- |
| 유리, 베일, 연기가 불투명하게 나옴 | `auto_prompt`를 켜고 `subject_note`에 재질을 설명한 다음 `cfg`를 1.5 또는 2.0으로 올리세요 |
| 배경 전체에 회색 안개가 낌 | `alpha_brightness`를 낮추거나 `hard_mask`를 켜세요 |
| 유색 유리가 불투명하게 남음 | `alpha_brightness`를 낮추거나 해당 영역을 손으로 칠하세요 |

두 가지 한계는 모델 자체에서 비롯됩니다. 매우 복잡하거나 대비가 낮은 장면에서는 피사체 옆의 풀, 소품, 워터마크가 함께 딸려 들어올 수 있고, 곤충 날개처럼 미세한 구조는 픽셀이 유실될 수 있습니다.
