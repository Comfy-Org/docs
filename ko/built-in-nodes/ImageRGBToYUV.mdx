# 이미지 RGB to YUV

ImageRGBToYUV 노드는 RGB에서 YUV 색 공간으로의 색 공간 변환을 수행합니다. RGB 이미지를 입력으로 받아 YUV 채널을 나타내는 세 개의 별도의 이미지를 출력합니다: Y (명도), U (파란색 차이), V (빨간색 차이).

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 변환할 RGB 이미지입니다. 이는 3 채널 이미지여야 합니다. | 이미지 | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `Y`         | 이미지의 명도(밝기)를 나타냅니다. | 이미지 |
| `U`         | 파란색 차이 색상 성분을 나타냅니다. | 이미지 |
| `V`         | 빨간색 차이 색상 성분을 나타냅니다. | 이미지 |

출력 이미지는 입력 이미지와 같은 크기를 가집니다.
