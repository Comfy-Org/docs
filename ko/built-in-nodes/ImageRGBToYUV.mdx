ImageRGBToYUV 노드는 RGB-to-YCbCr 색상 변환을 사용하여 RGB 이미지를 YUV 스타일 색상 구성 요소로 변환합니다. 결과를 Y(휘도 또는 밝기), U(청색 차분 크로마), V(적색 차분 크로마)의 세 가지 개별 이미지로 분리하며, 각 구성 요소를 입력과 동일한 너비와 높이로 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | Y, U, V 구성 요소로 변환할 입력 RGB 이미지입니다. 이미지에 알파 채널이 포함된 경우 처음 세 개(RGB) 채널만 사용합니다. | IMAGE | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `Y` | YUV 색 공간의 휘도(밝기) 구성 요소이며, 3채널 이미지로 반환됩니다. | IMAGE |
| `U` | YUV 색 공간의 청색 차분 크로마 구성 요소이며, 3채널 이미지로 반환됩니다. | IMAGE |
| `V` | YUV 색 공간의 적색 차분 크로마 구성 요소이며, 3채널 이미지로 반환됩니다. | IMAGE |

각 출력은 입력 이미지와 동일한 너비와 높이를 가집니다. 해당 Y, U 또는 V 구성 요소가 세 채널 모두에 반복되어 모든 출력이 표준 3채널 이미지로 반환됩니다.
