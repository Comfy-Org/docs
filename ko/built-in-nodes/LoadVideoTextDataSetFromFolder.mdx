이 노드는 ComfyUI 입력 디렉토리 내의 선택한 하위 폴더에서 비디오 파일과 관련 텍스트 캡션을 로드하여 비디오와 캡션의 두 목록으로 반환합니다. 비디오 항목은 지연 참조이므로 프레임은 다운스트림 노드가 필요로 할 때만 디코딩됩니다. 지원되는 형식은 MP4, AVI, MOV, WEBM, MKV 및 FLV입니다. 반복 횟수 접두사가 있는 중첩 폴더(예: `5_classname/`, kohya-ss/sd-scripts와 같은 도구에서 사용)도 지원됩니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `폴더` | 비디오 파일과 .txt 캡션이 포함된 폴더입니다. | STRING | 예 | 콤보: ComfyUI 입력 디렉토리 내 모든 하위 폴더의 동적 목록 |

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
선택한 폴더에 지원되는 비디오 확장자의 파일이 없으면 노드에서 오류가 발생합니다. 이름이 숫자와 밑줄로 시작하는 중첩 폴더(예: `5_classname`)의 경우, 해당 폴더의 각 비디오는 해당 접두사가 지정한 횟수만큼 데이터셋에 포함됩니다.
|-------------|-------------|-----------|
| `비디오` | 지연 비디오 참조. 프레임은 다운스트림에서 필요할 때만 디코딩됩니다. 폴더에서 찾은 각 비디오 파일에 대해 하나의 항목이 있습니다. | VIDEO (list) |
| `텍스트` | 텍스트 캡션 목록입니다. 비디오당 하나의 캡션. 비디오에 해당하는 `.txt` 파일이 없는 경우 캡션은 빈 문자열입니다. | STRING (list) |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/LoadVideoTextDataSetFromFolder/ko.md)
