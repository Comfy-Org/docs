이 노드는 ComfyUI 입력 디렉터리 내부의 폴더에서 비디오 파일과 이에 대응하는 텍스트 캡션을 로드하고, 이를 두 개의 목록, 즉 비디오와 캡션으로 반환합니다. 비디오 항목은 지연 참조이므로 프레임은 다운스트림 노드가 필요로 할 때만 디코딩됩니다. 지원되는 형식은 MP4, AVI, MOV, WEBM, MKV, FLV이며, 반복 횟수 접두사가 있는 중첩 폴더(예: `5_classname/`, kohya-ss/sd-scripts 같은 도구에서 사용)도 지원됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `폴더` | 비디오 파일과 .txt 캡션을 포함하는 폴더입니다. | COMBO | 예 | ComfyUI 입력 디렉터리 내부의 모든 하위 폴더를 동적으로 나열합니다. |

선택한 폴더는 ComfyUI 입력 디렉터리의 하위 폴더여야 합니다. 해당 디렉터리 외부로 해석되는 폴더 이름은 오류를 발생시킵니다. 선택한 폴더에 지원되는 비디오 확장자(MP4, AVI, MOV, WEBM, MKV, FLV)를 가진 파일이 없으면 노드에서 오류를 발생시킵니다. 이름이 숫자 뒤에 밑줄이 오는 형태로 시작하는 중첩 폴더(예: `5_classname`)의 경우, 해당 폴더 내 각 비디오는 그 접두사에 지정된 횟수만큼 데이터셋에 포함됩니다. 각 비디오의 캡션은 같은 기본 이름을 가진 `.txt` 파일에서 읽습니다. 일치하는 `.txt` 파일이 없으면 캡션은 빈 문자열입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `videos` | 지연 비디오 참조입니다. 프레임은 다운스트림에서 필요할 때만 디코딩됩니다. 폴더에서 발견된 각 비디오 파일마다 하나의 항목이 포함됩니다. | VIDEO (list) |
| `texts` | 텍스트 캡션 목록입니다. 비디오당 하나의 캡션이 있으며, 비디오에 일치하는 `.txt` 파일이 없으면 해당 캡션은 빈 문자열입니다. | STRING (list) |
