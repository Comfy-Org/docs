이 노드는 ComfyUI 입력 디렉터리에서 선택한 하위 폴더에 있는 비디오 파일과 해당 텍스트 캡션을 불러와서 비디오 목록과 캡션 목록, 두 개의 목록으로 반환합니다. 비디오 항목은 지연(lazy) 참조이므로 다운스트림 노드에서 프레임이 필요할 때에만 디코딩됩니다. 지원되는 형식은 MP4, AVI, MOV, WEBM, MKV, FLV입니다. 반복 횟수 접두사가 있는 중첩 폴더(예: kohya-ss/sd-scripts 같은 도구에서 사용되는 `5_classname/`)도 지원됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `폴더` | 비디오 파일과 .txt 캡션을 포함하는 폴더입니다. | COMBO | 예 | 선택 가능한 여러 옵션: ComfyUI 입력 디렉터리 안의 모든 하위 폴더를 동적으로 나열합니다 |

선택한 폴더는 ComfyUI 입력 디렉터리의 하위 폴더여야 합니다. 해당 디렉터리 밖으로 연결되는 폴더 이름을 지정하면 오류가 발생합니다. 선택한 폴더에 지원되는 비디오 확장자(MP4, AVI, MOV, WEBM, MKV, FLV)를 가진 파일이 하나도 없으면 노드에서 오류가 발생합니다. 이름이 숫자와 밑줄로 시작하는 중첩 폴더(예: `5_classname`)의 경우, 해당 폴더 안의 각 비디오는 접두사에 지정된 횟수만큼 데이터셋에 포함됩니다. 각 비디오의 캡션은 동일한 기본 이름을 가진 `.txt` 파일에서 읽어옵니다. 일치하는 `.txt` 파일이 없으면 캡션은 빈 문자열이 됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `비디오` | 지연 비디오 참조입니다. 프레임은 다운스트림에서 필요할 때만 디코딩됩니다. 폴더에서 찾은 비디오 파일마다 항목이 하나씩 생성됩니다. | VIDEO (list) |
| `텍스트` | 텍스트 캡션 목록입니다. 비디오마다 캡션이 하나씩 있으며, 일치하는 `.txt` 파일이 없는 비디오의 캡션은 빈 문자열입니다. | STRING (list) |
