이 노드는 ComfyUI 입력 디렉토리에서 선택한 하위 폴더의 비디오 파일과 관련 텍스트 캡션을 로드하여 비디오와 캡션의 두 목록으로 반환합니다. 비디오 항목은 지연 참조(lazy reference)이므로 다운스트림 노드가 필요로 할 때만 프레임이 디코딩됩니다. 지원되는 형식은 MP4, AVI, MOV, WEBM, MKV 및 FLV이며, 반복 횟수 접두사가 있는 중첩 폴더(예: `5_classname/`, kohya-ss/sd-scripts와 같은 도구에서 사용됨)도 지원됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `폴더` | 비디오 파일과 .txt 캡션이 포함된 폴더입니다. | STRING | 예 | Combo: ComfyUI 입력 디렉토리 내 모든 하위 폴더의 동적 목록 |

선택한 폴더에 지원되는 비디오 확장자를 가진 파일이 없으면 노드에서 오류가 발생합니다. 폴더 이름은 ComfyUI 입력 디렉토리 내부의 위치로 확인되어야 하며, 디렉토리를 벗어나려는 폴더 이름(예: `..` 또는 절대 경로 사용)도 오류를 발생시킵니다. 이름이 숫자와 밑줄로 시작하는 중첩 폴더(예: `5_classname`)의 경우, 해당 폴더의 각 비디오는 접두사에 지정된 횟수만큼 데이터셋에 포함됩니다. 선택한 폴더에 직접 배치된 비디오는 한 번 포함됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `비디오` | 지연 비디오 참조이며, 프레임은 다운스트림에서 필요할 때만 디코딩됩니다. 폴더에서 찾은 각 비디오 파일당 하나의 항목입니다. | VIDEO (list) |
| `텍스트` | 텍스트 캡션 목록입니다. 비디오당 캡션 하나씩이며, 일치하는 `.txt` 파일이 없는 비디오의 캡션은 빈 문자열입니다. | STRING (list) |
