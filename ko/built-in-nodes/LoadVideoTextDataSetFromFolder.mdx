이 노드는 ComfyUI 입력 디렉토리 내의 지정된 하위 폴더에서 비디오 파일과 해당 텍스트 캡션 데이터셋을 로드합니다. 두 개의 리스트를 반환합니다: 레이지 비디오 참조(다운스트림에서 필요할 때만 프레임이 디코딩됨)와 관련 캡션입니다. 이 노드는 MP4, AVI, MOV, WEBM, MKV, FLV와 같은 일반적인 비디오 형식을 지원하며, kohya‑ss/sd‑scripts 같은 도구에서 사용하는 반복 횟수 접두사(예: `5_classname/`)가 있는 중첩 폴더 구조도 처리할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `폴더` | 비디오 파일과 `.txt` 캡션 파일이 포함된 하위 폴더입니다. ComfyUI 입력 디렉토리에서 사용 가능한 하위 폴더 중에서 선택합니다. | STRING | 예 | 콤보: ComfyUI 입력 폴더 내 모든 하위 디렉토리의 동적 목록 |

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `비디오` | 로드된 비디오 파일에 대한 레이지 참조입니다. 프레임은 이를 처리하는 다운스트림 노드에 연결된 경우에만 디코딩됩니다. 각 요소는 입력 폴더의 비디오에 해당합니다. | VIDEO (list) |
| `텍스트` | 텍스트 캡션 리스트로, 비디오당 하나씩 있습니다. 비디오에 해당하는 `.txt` 파일이 없는 경우 캡션은 빈 문자열입니다. | STRING (list) |
