Grok Video Extend 노드는 텍스트 프롬프트를 기반으로 기존 비디오를 끊김 없이 이어지는 장면으로 확장합니다. 짧은 소스 비디오를 제공하고 다음에 어떤 일이 일어나야 하는지 설명하면, 노드는 원본에서 이어지는 새 비디오 클립을 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 비디오 확장에 사용할 모델입니다. `"grok-imagine-video"` 옵션을 선택하면 모델별 설정이 표시됩니다. | DYNAMIC_COMBO | 예 | `"grok-imagine-video"` |
| `프롬프트` | 비디오에서 다음에 어떤 일이 일어나야 하는지에 대한 텍스트 설명입니다. | STRING | 예 | N/A |
| `비디오` | 확장할 소스 비디오입니다. MP4 형식, 2-15초입니다. | VIDEO | 예 | MP4, 2-15 seconds, maximum 50MB |
| `시드` | 노드를 다시 실행할지 결정하는 시드입니다. 실제 결과는 시드와 관계없이 비결정적입니다(기본값: 0). | INT | 예 | 0  ~  2147483647 |

### grok-imagine-video 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `duration` | 확장 길이(초)입니다(기본값: 8). | INT | 예 | 2  ~  10 |

**매개변수 제약 조건:**
* `video` 입력은 길이가 2~15초인 MP4 파일이어야 하며 파일 크기가 50MB를 초과할 수 없습니다.
* `prompt`는 공백을 제거한 후 최소 한 문자를 포함해야 합니다.
* `model` 매개변수는 동적 콤보입니다. `"grok-imagine-video"` 옵션을 선택하면 중첩된 `duration` 매개변수가 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 새로 생성된 비디오 확장입니다. | VIDEO |
