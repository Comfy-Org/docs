LTXV Add Generated Keyframes 노드는 비디오 latent에 디테일링 키프레임을 추가합니다. 각 키프레임은 단일 픽셀 프레임 위에 배치된 토큰의 latent 프레임 하나이며, 비디오와 함께 디노이즈되고 디코딩된 출력에는 포함되지 않습니다. 배치는 `interval_frames` 픽셀마다 슬롯 하나이며, I2V 프레임, 기존 가이드, 그리고 컨디셔닝에 이미 있는 생성된 키프레임을 건너뜁니다. 생성된 키프레임은 LTXV Separate Generated Keyframes로 다시 꺼내세요. 생성된 키프레임용으로 학습된 체크포인트(`keyframes_abs_pos_embedding`을 보유한 체크포인트)가 필요합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 키프레임이 연결되는 긍정 컨디셔닝입니다. | CONDITIONING | 예 | N/A |
| `negative` | 키프레임이 연결되는 부정 컨디셔닝입니다. | CONDITIONING | 예 | N/A |
| `vae` | latent 스케일 팩터를 읽는 데만 사용됩니다. | VAE | 예 | N/A |
| `latent` | 키프레임을 함께 생성할 일반 5D 비디오 latent입니다. Concat AV Latent 전에 추가하세요. | LATENT | 예 | N/A |
| `interval_frames` | 자동 배치를 위한 픽셀 프레임 간격입니다. 기본값 24는 24 fps에서 약 초당 키프레임 하나에 해당합니다. 점유된 픽셀은 건너뜁니다. `frame_indices`가 설정되면 무시됩니다. (기본값: 24) | INT | 아니요 | 1-1024 |
| `keyframes` | 새 키프레임을 초기화할 선택적 콘텐츠입니다. 이전 Separate의 키프레임(동일한 공간 크기)을 연결하거나, 일반 비디오 latent를 연결하여 각 새 슬롯에서 가장 가까운 프레임을 복사할 수 있습니다(예: 시간적 업스케일 후). 이들은 여전히 디노이즈되며 가이드로 고정되지 않습니다. `frame_indices`가 설정되지 않은 경우 키프레임 latent에 기록된 인덱스는 무시됩니다. 샘플링이 시그마 1 미만에서 시작될 때만 효과가 있습니다. | LATENT | 아니요 | N/A |
| `frame_indices` | 선택적 픽셀 프레임 인덱스입니다. 비워 두면 현재 캔버스에서 `interval_frames`에 따라 배치됩니다. 설정하면 이 목록이 배치가 됩니다(연결된 키프레임은 순서대로 매칭됩니다). 마지막 프레임은 허용되지만 프레임 0은 허용되지 않습니다(이미 독립형 토큰입니다). (기본값: 빈 문자열) | STRING | 아니요 | Comma-separated integers; 1 to the last pixel frame (frame 0 excluded) |

**참고:** `latent`는 Concat AV Latent 전에 생성된 키프레임이 추가된 일반 5D 비디오 latent여야 합니다. `frame_indices`가 설정된 경우, 나열된 각 픽셀 프레임은 고유해야 하며 이미 이미지 키프레임, 가이드 또는 생성된 키프레임을 보유하고 있어서는 안 됩니다. `frame_indices`가 비어 있으면 점유된 픽셀은 자동으로 건너뜁니다. 사용 가능한 디테일링 슬롯이 없으면 노드에서 오류를 발생시킵니다. 기존 생성된 키프레임에 추가할 때, latent는 여전히 프레임당 동일한 토큰을 가져야 하며 기존 블록은 마지막 latent 프레임에서 끝나야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 생성된 키프레임 어텐션이 연결된 긍정 컨디셔닝입니다. | CONDITIONING |
| `negative` | 생성된 키프레임 어텐션이 연결된 부정 컨디셔닝입니다. | CONDITIONING |
| `latent` | T 축에 생성된 키프레임이 추가된 비디오 latent입니다. | LATENT |

## 참고

- `interval_frames` 매개변수는 자동 배치된 키프레임의 간격을 설정합니다. 값이 높을수록 키프레임 수가 적어지고 간격이 넓어지며, 값이 낮을수록 키프레임 수가 많아집니다.
- `keyframes` 입력을 사용하면 기존 키프레임 또는 비디오 latent로 새 키프레임을 초기화할 수 있습니다. 더 긴 일반 비디오 latent가 제공되면 각 새 슬롯에서 가장 가까운 비디오 프레임이 복사됩니다. 이 키프레임들은 여전히 디노이즈되며 가이드로 고정되지 않습니다.
- `frame_indices` 매개변수를 사용하면 키프레임을 배치할 정확한 픽셀 프레임 인덱스를 지정할 수 있습니다. 제공된 경우 `interval_frames`는 무시됩니다. 목록은 유효한 픽셀 범위 내의 고유한 정수를 포함해야 하며, 프레임 0은 허용되지 않습니다.
- `positive` 및 `negative` 출력에는 생성된 키프레임 어텐션이 연결된 컨디셔닝이 포함됩니다.
- `latent` 출력에는 T 축에 생성된 키프레임이 추가된 비디오 latent가 포함됩니다.
- 생성된 키프레임용으로 학습된 체크포인트(`keyframes_abs_pos_embedding`을 보유한 체크포인트)가 필요합니다.
- 생성된 키프레임은 LTXV Separate Generated Keyframes로 다시 꺼내세요.
