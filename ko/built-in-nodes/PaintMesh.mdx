PaintMesh는 3D 메시와 복셀 색상 필드를 입력받습니다. 이 노드는 필드에서 가장 가까운 복셀의 색상을 각 정점에 할당하고, 해당 정점 색상이 적용된 메시를 반환합니다. 복셀 필드가 비어 있으면 메시는 기본값인 0(검은색) 정점 색상으로 칠해집니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `메시` | 칠할 메시입니다. | MESH | 예 | N/A |
| `voxel_colors` | 칠하기에 사용되는 색상 데이터를 포함하는 복셀 필드입니다. 필드에서는 기본 색상 RGB 채널만 사용됩니다. | VOXEL | 예 | N/A |

참고: 복셀 필드 좌표에 배치 인덱스 채널이 포함되어 있고 입력 메시에 여러 메시 항목이 들어 있는 경우, 이 노드는 배치의 각 메시 항목에 색상을 개별적으로 적용합니다. 특정 메시 항목에 일치하는 복셀이 없으면 해당 항목은 기본값인 0(검은색) 정점 색상을 받습니다. 복셀 필드가 전체 PBR 데이터를 포함할 수 있지만 정점 색상에는 기본 색상 RGB만 사용되므로, 샘플링된 색상은 출력 메시를 위해 sRGB에서 선형 RGB로 변환됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `mesh` | 정점 색상이 적용된 칠해진 메시입니다. | MESH |
