Bria FIBO Image Edit 노드는 텍스트 명령을 사용하여 기존 이미지를 편집합니다. 이 노드는 이미지와 프롬프트를 Bria API로 전송하며, FIBO 모델이 편집된 버전을 생성합니다. 선택적으로 마스크를 사용하여 변경 사항을 특정 영역으로 제한할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 이미지 편집에 사용할 모델 버전입니다. | COMBO | 예 | `"FIBO"` |
| `image` | 편집하려는 입력 이미지입니다. | IMAGE | 예 | - |
| `프롬프트` | 이미지를 편집하기 위한 지시문입니다(기본값: 비어 있음). | STRING | 예 | - |
| `네거티브 프롬프트` | 편집된 이미지에 나타나지 않아야 하는 내용을 설명하는 텍스트입니다(기본값: 비어 있음). | STRING | 예 | - |
| `구조화된 프롬프트` | JSON 형식의 구조화된 편집 프롬프트가 포함된 문자열입니다. 정밀하고 프로그래밍 방식의 제어를 위해 일반 프롬프트 대신 사용합니다(기본값: 비어 있음). | STRING | 예 | - |
| `시드` | 무작위 생성을 초기화하는 데 사용되는 숫자로, 재현 가능한 결과를 보장합니다(기본값: 1). | INT | 예 | 1 ~ 2147483647 |
| `가이던스 스케일` | 값이 높을수록 이미지가 프롬프트를 더 밀접하게 따릅니다(기본값: 3). | FLOAT | 예 | 3.0 ~ 5.0 |
| `스텝` | 모델이 수행하는 노이즈 제거 단계 수입니다(기본값: 50). | INT | 예 | 20 ~ 50 |
| `모더레이션` | 검열 설정입니다. `"true"`를 선택하면 추가 검열 옵션이 표시됩니다. | DYNAMIC_COMBO | 예 | `"false"`<br />`"true"` |
| `마스크` | 생략하면 편집이 전체 이미지에 적용됩니다. | MASK | 아니오 | - |

### 검열 입력

`moderation`이 `"true"`로 설정되면 다음 추가 입력을 사용할 수 있습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | 부적절한 콘텐츠가 있는지 프롬프트 텍스트를 검열할지 여부입니다(기본값: false). | BOOLEAN | 아니오 | `true`<br />`false` |
| `visual_input_moderation` | 부적절한 콘텐츠가 있는지 입력 이미지를 검열할지 여부입니다(기본값: false). | BOOLEAN | 아니오 | `true`<br />`false` |
| `visual_output_moderation` | 부적절한 콘텐츠가 있는지 편집된 출력 이미지를 검열할지 여부입니다(기본값: true). | BOOLEAN | 아니오 | `true`<br />`false` |

**중요 제약 사항:**

- `prompt` 또는 `structured_prompt` 중 하나 이상은 비어 있지 않아야 합니다. 둘 다 비어 있으면 노드에서 오류가 발생합니다.
- `moderation`이 `"true"`로 설정되면 위의 세 가지 검열 입력이 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | Bria API가 반환한 편집된 이미지입니다. | IMAGE |
| `구조화된 프롬프트` | 편집 프로세스 중 사용되거나 생성된 구조화된 프롬프트입니다. | STRING |
