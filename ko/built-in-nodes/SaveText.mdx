Save Text 노드는 텍스트 콘텐츠를 출력 디렉터리의 파일에 저장합니다. .txt, .csv, .md 또는 .json 형식으로 저장하는 것을 지원하며, 유효한 JSON이 제공되면 JSON pretty-printing을 자동으로 처리합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `text` | 파일에 저장할 텍스트 콘텐츠입니다. 이 입력은 다른 노드에서 연결해야 합니다. | STRING | 예 | - |
| `filename_prefix` | 출력 파일 이름의 접두사입니다. 기존 파일을 덮어쓰지 않도록 5자리 카운터가 추가됩니다(기본값: "ComfyUI"). | STRING | 아니요 | - |
| `format` | 텍스트를 저장할 파일 형식입니다(기본값: "txt"). "json"을 선택하면 유효한 JSON 텍스트가 2칸 들여쓰기로 pretty-print됩니다. 그렇지 않으면 텍스트가 있는 그대로 저장됩니다. | COMBO | 아니요 | `"txt"`<br />`"csv"`<br />`"md"`<br />`"json"` |

### 참고 사항

- `text`는 강제 입력이며 다른 노드에 연결해야 합니다. 직접 입력할 수 없습니다.
- 저장된 파일 이름은 `<filename_prefix>_<5-digit counter>.<extension>`이며, ComfyUI 출력 디렉터리(접두사에서 파생된 하위 폴더)에 기록됩니다.
- `"json"` 형식을 선택하면 텍스트를 JSON으로 파싱하려고 시도합니다. 파싱에 성공하면 콘텐츠가 2칸 들여쓰기로 pretty-print되어 기록됩니다. 파싱에 실패하면 원본 텍스트가 변경 없이 기록됩니다.
- 노드는 저장된 파일을 인터페이스에 다시 보고하여 다른 생성된 출력 파일들과 함께 표시되도록 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `text` | 파일에 저장된 원본 텍스트 콘텐츠입니다. | STRING |
