MiniMax H3 Image를 사용하여 텍스트에서 이미지를 생성하거나, 최대 16개의 참조 이미지를 편집 및 결합합니다. 프롬프트에서는 연결 순서에 따라 `@Image1`, `@Image2` 등으로 참조 이미지를 지정합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | `MiniMax-H3-Image` 또는 더 빠른 실행을 위한 `MiniMax-H3-Image-Highspeed`입니다. 기본값: `"MiniMax-H3-Image"`. | COMBO | 예 | `"MiniMax-H3-Image"`<br />`"MiniMax-H3-Image-Highspeed"` |
| `prompt` | 생성할 내용 또는 참조 이미지를 편집할 방법입니다. 참조 이미지가 연결된 경우 최대 8,000자까지 입력할 수 있습니다. 기본값: 비어 있음. | STRING | 예 | 1~8000자 |
| `size` | `2K` 및 `4K`는 화면 비율에서 크기를 도출하고, `custom`은 정확한 너비와 높이를 설정합니다. 기본값: `"2K"`. | DYNAMIC_COMBO | 예 | `"2K"`<br />`"4K"`<br />`"custom"` |
| `enhance_prompt` | MiniMax는 생성 전에 프롬프트를 상세한 장면 설명으로 다시 작성합니다. 이미지 편집 시에는 항상 프롬프트가 향상됩니다. 이 옵션을 끄면 고정 화면 비율 또는 사용자 지정 크기를 선택합니다. 기본값: true. | BOOLEAN | 아니요 | true<br />false |
| `seed` | 노드의 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 아니요 | 0~2147483647 |
| `images` | 편집하거나 결합할 참조 이미지입니다. 프롬프트에서는 연결 순서에 따라 `@Image1`부터 `@Image16`까지로 지정합니다. | AUTOGROW | 아니요 | 최대 16개 이미지 |

### 크기 "2K" 및 "4K" 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | `auto`인 경우 MiniMax가 프롬프트에서 비율을 선택하거나, 참조 이미지가 연결되어 있으면 해당 이미지의 비율을 따릅니다. `enhance_prompt`가 꺼진 텍스트-이미지 생성에는 고정 비율이 필요합니다. 기본값: `"auto"`. | COMBO | 예 | 여러 옵션 사용 가능 |

### 크기 "custom" 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `width` | 출력 너비(픽셀)입니다. 기본값: 2048. | INT | 예 | 512~7680 (단계: 16) |
| `height` | 출력 높이(픽셀)입니다. 기본값: 2048. | INT | 예 | 512~7680 (단계: 16) |

참고: 사용자 지정 크기의 경우 너비 × 높이가 655,360~20,000,000픽셀이어야 하며, 화면 비율은 최대 3:1이어야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `image` | 생성되거나 편집된 이미지이며 PNG 형식입니다. | IMAGE |
| `revised_prompt` | 프롬프트 향상이 켜져 있었을 때 MiniMax가 사용한 다시 작성된 프롬프트입니다. | STRING |
