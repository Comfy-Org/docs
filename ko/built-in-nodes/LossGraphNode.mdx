LossGraphNode는 학습 단계에 따른 학습 손실 값의 꺾은선 그래프를 생성하고 이를 미리보기 이미지로 표시합니다. 학습 노드에서 손실 값을 읽고, 레이블이 지정된 축과 최소/최대 손실 값을 갖는 그래프에 표시하며, UI에서 이미지 미리보기로 그래프를 반환합니다. 이 노드는 실험적 기능으로 표시되어 있으며 출력 노드입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `손실` | 학습 노드의 손실 맵입니다. 숫자 손실 값 목록이 있는 `loss` 키를 포함해야 합니다. | LOSS_MAP | 예 | - |
| `파일명 접두사` | 저장된 손실 그래프 이미지의 접두사입니다. (기본값: "loss_graph") | STRING | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `ui.images` | 미리보기로 표시되는 생성된 손실 그래프 이미지입니다. | IMAGE |
