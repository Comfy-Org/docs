일반 텍스트로 설명된 다른 객체로 이미지 내 객체를 대체하며, Bria의 텍스트 안내 이미지 편집을 사용합니다. Bria는 약 1메가픽셀 해상도로 전체 프레임을 다시 렌더링하므로 결과는 입력과 픽셀 단위로 정렬되지 않습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 대체할 객체가 포함된 이미지입니다. 이미지가 업로드되기 전에 알파 채널은 제거됩니다. | IMAGE | 예 | - |
| `지시문` | 무엇을 무엇으로 대체할지 지정합니다. 예: "빨간 사과를 초록색 배로 교체". 최소 1자 이상이어야 합니다. | STRING | 예 | 여러 줄 텍스트; 기본값: "" (비어 있음) |
| `시드` | Bria는 여기서 `seed`를 사용하지 않고 호출할 때마다 편집을 새로 구상하므로, 반복 실행 시 결과가 달라질 수 있습니다. 이 값은 전송되지 않습니다. 이 값은 이 노드의 캐시 키만 변경하므로, 그 외에는 동일한 그래프가 캐시된 결과를 반환하는 대신 편집을 다시 실행하게 합니다. | INT | 예 | 0 ~ 2147483647, 단계 1; 기본값: 42; 생성 후 제어 활성화됨 |

### 검열 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모더레이션` | 검열 설정입니다. "true"를 선택하면 아래의 검열 하위 옵션이 표시되며, 그렇지 않으면 표시되지 않습니다. | DYNAMIC_COMBO | 예 | `"false"`<br />`"true"` |
| `visual_input_moderation` | 입력 이미지의 검열을 활성화합니다. `moderation`이 "true"로 설정된 경우에만 사용할 수 있습니다. | BOOLEAN | 아니요 | `true` / `false`; 기본값: false |
| `visual_output_moderation` | 생성된 출력 이미지의 검열을 활성화합니다. `moderation`이 "true"로 설정된 경우에만 사용할 수 있습니다. | BOOLEAN | 아니요 | `true` / `false`; 기본값: false |

참고: `instruction`은 요청이 전송되기 전에 검증되며 최소 1자 이상을 포함해야 합니다. `seed` 값은 Bria로 전송되지 않습니다. 이 값은 노드가 편집을 다시 실행할지 아니면 캐시된 결과를 반환할지에만 영향을 줍니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 설명된 객체 대체가 적용된 편집 이미지입니다. | IMAGE |
| `structured_prompt` | 편집된 이미지의 구조화된 설명으로, Bria FIBO Image Edit을 사용한 후속 편집에 사용됩니다. | STRING |
