이 노드는 ComfyUI 출력 디렉터리 내의 지정된 폴더에 이미지 목록을 저장합니다. 구성 가능한 파일 이름 접두사를 사용하여 각 이미지를 PNG 파일로 디스크에 씁니다. 이 노드는 더 이상 사용되지 않으며 기존 Save Image 노드로 대체되었습니다. 기존 노드에서는 파일 이름 접두사에 대상 폴더를 지정할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 저장할 이미지 목록입니다. | IMAGE | 예 | N/A |
| `folder_name` | 이미지를 저장할 폴더의 이름입니다(출력 디렉터리 내부). 기본값: "dataset". | STRING | 아니요 | N/A |
| `filename_prefix` | 저장된 이미지 파일 이름의 접두사입니다. 기본값: "image". 고급 매개변수입니다. | STRING | 아니요 | N/A |
| `mode` | 기존 파일을 덮어쓸지, 덮어쓰지 않도록 파일 이름을 증가시킬지 여부입니다. 기본값: "overwrite". | COMBO | 아니요 | "overwrite"<br />"increment" |

**참고:**

- `images` 입력은 목록이므로 한 번의 실행으로 여러 이미지를 저장할 수 있습니다.
- `folder_name`, `filename_prefix`, `mode` 매개변수는 스칼라 값입니다. 목록이 연결된 경우 해당 목록의 첫 번째 값만 사용됩니다.
- `folder_name`은 ComfyUI 출력 디렉터리 내부 위치로 확인되어야 합니다. 출력 디렉터리를 벗어나는 값(예: `..`가 포함된 경로, 절대 경로, 드라이브 문자 또는 심볼릭 링크 이탈)은 오류와 함께 거부됩니다.
- "overwrite" 모드에서는 파일이 `{prefix}_00000.png`, `{prefix}_00001.png` 등으로 저장되며 기존 파일을 대체합니다. "increment" 모드에서는 파일 이름에 카운터가 삽입되어 기존 파일을 덮어쓰지 않습니다.
- PNG 출력만 지원됩니다.

## 출력

이 노드는 출력이 없습니다. 파일 시스템에 저장 작업을 수행하는 출력 노드입니다.
