이 노드는 Bria를 사용하여 일반 텍스트로 설명된 객체를 이미지에 삽입합니다. Bria는 약 1메가픽셀 수준으로 전체 프레임을 다시 렌더링하므로, 결과는 입력과 픽셀 단위로 정렬되지 않습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 설명된 객체가 추가될 이미지입니다. 이미지가 업로드되기 전에 알파 채널이 제거됩니다. | IMAGE | 예 | - |
| `지시문` | 무엇을 어디에 추가할지 지정합니다. 예: 'Place a red vase with flowers on the table'. 비어 있으면 안 됩니다. 기본값: ""(빈 문자열). | STRING | 예 | - |
| `시드` | Bria는 여기서 시드를 받지 않고 호출할 때마다 편집을 다시 생성하므로, 반복 실행 시 결과가 달라질 수 있습니다. 이 값은 전송되지 않습니다. 이 값은 이 노드의 캐시 키만 변경하므로, 그 외에는 동일한 그래프가 캐시된 결과를 반환하는 대신 편집을 다시 실행하게 합니다. 기본값: 42. | INT | 예 | 0  ~  2147483647 |
| `검토` | 모데레이션 설정입니다. 아래의 모데레이션 플래그를 표시하려면 "true"를 선택합니다. | DYNAMIC_COMBO | 예 | "false"<br />"true" |

### 모데레이션 활성화 시 입력

`moderation`이 "true"로 설정된 경우 사용할 수 있습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | 입력 이미지에 대한 콘텐츠 모데레이션을 활성화합니다. 기본값: False. | BOOLEAN | 아니요 | True / False |
| `visual_output_moderation` | 생성된 출력 이미지에 대한 콘텐츠 모데레이션을 활성화합니다. 기본값: False. | BOOLEAN | 아니요 | True / False |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 설명된 객체가 추가된 편집된 이미지입니다. | IMAGE |
| `structured_prompt` | 편집된 이미지의 구조화된 설명으로, Bria FIBO Image Edit를 사용한 후속 편집에 사용됩니다. | STRING |
