MOSS-Image 색상/깊이 제어 어댑터의 색상 영역 맵과 깊이 맵을 컨디셔닝에 추가합니다. `positive` 및 `negative` 컨디셔닝, VAE, 그리고 하나 또는 두 맵을 모두 연결합니다. 맵은 잠재 벡터로 인코딩되고, 색상/깊이 제어 신호로 결합되며, 선택한 샘플링 구간에 대해 컨디셔닝에 연결됩니다. LoRA 로더를 통해 로드한 MOSS-Image 제어 어댑터와 함께 사용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 제어 신호를 연결할 positive 컨디셔닝입니다. | CONDITIONING | 예 | N/A |
| `negative` | 제어 신호를 연결할 negative 컨디셔닝입니다. | CONDITIONING | 예 | N/A |
| `vae` | 맵을 잠재 벡터로 인코딩하는 데 사용할 VAE입니다. | VAE | 예 | N/A |
| `color_map` | 출력 크기에 맞춘 영역별 단일 평면 색상입니다. 색상은 영역 ID로만 사용됩니다. | IMAGE | 아니요 | N/A |
| `depth_map` | 출력 크기에 맞춘 깊이 맵이며, 가까운 영역은 흰색입니다. | IMAGE | 아니요 | N/A |
| `strength` | 이미지 토큰에 대한 맵의 기여도를 조정합니다. 0.0은 맵이 없는 것과 같고, 1.0은 학습된 강도입니다(기본값: 1.0). | FLOAT | 예 | 0.0  ~  10.0 (단계: 0.01) |
| `start_percent` | 제어가 시작되는 샘플링 비율입니다(기본값: 0.0). | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.001) |
| `end_percent` | 제어가 종료되는 샘플링 비율입니다. 일찍 종료하면 레이아웃과 깊이를 유지하면서 나머지 단계에서 형태를 느슨하게 만듭니다(기본값: 1.0). | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.001) |

**참고:** `color_map`과 `depth_map` 중 최소 하나를 연결하십시오. 둘 다 없으면 노드는 컨디셔닝을 변경 없이 반환합니다. 누락된 맵은 0으로 대체되므로 색상만 사용하거나 깊이만 사용하는 구성도 모두 작동합니다. 두 맵의 크기가 다르면 작은 맵이 다른 맵의 크기에 맞게 확대됩니다. 이 노드는 ComfyUI에서 실험적(experimental)으로 표시됩니다.
