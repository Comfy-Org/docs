Quiver AI를 사용하여 텍스트 프롬프트로 확장 가능한 벡터 그래픽(SVG)을 생성합니다. 선택적 참조 이미지와 스타일 지침을 통해 생성을 유도할 수 있습니다.

`model`을 선택하면 아래에 나열된 모델별 매개변수가 표시됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | SVG 생성에 사용할 모델입니다. | DYNAMIC_COMBO | 예 | `"arrow-2"`<br />`"arrow-2-telos"` |
| `prompt` | 원하는 SVG 출력에 대한 텍스트 설명입니다. 최소 한 글자 이상을 포함해야 합니다(기본값: 비어 있음). | STRING | 예 | 모든 텍스트 |
| `instructions` | 추가 스타일 또는 서식 지침입니다. 선택적 고급 매개변수입니다(기본값: 비어 있음). | STRING | 아니요 | 모든 텍스트 |
| `reference_images` | 확장 가능한 슬롯: 생성을 유도하는 하나 이상의 선택적 참조 이미지(`ref_1`, `ref_2`, ...)를 연결합니다. 최대 이미지 수는 14개입니다. | IMAGE | 아니요 | 최대 14 |
| `width` | 출력 SVG 캔버스(viewBox)의 너비이며 사용자 단위입니다. 출력 크기와 종횡비를 제어하려면 `width`와 `height`를 모두 설정하세요. 둘 중 하나를 0으로 두면 모델이 선택하게 하며, 일반적으로 정사각형 캔버스가 됩니다. 고급 매개변수입니다(기본값: 0). | INT | 예 | 0~8192 |
| `height` | 출력 SVG 캔버스(viewBox)의 높이이며 사용자 단위입니다. 출력 크기와 종횡비를 제어하려면 `width`와 `height`를 모두 설정하세요. 둘 중 하나를 0으로 두면 모델이 선택하게 하며, 일반적으로 정사각형 캔버스가 됩니다. 고급 매개변수입니다(기본값: 0). | INT | 예 | 0~8192 |
| `seed` | 노드를 다시 실행할지 결정하는 시드입니다. 실제 결과는 시드 값과 관계없이 비결정적입니다. 이 매개변수는 "생성 후 제어" 기능을 가집니다(기본값: 42). | INT | 예 | 0~2147483647 |

### 모델별 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | 모델이 그리기 전에 사용하는 추론량입니다. 높은 수준은 세부 묘사를 향상시키고 더 많은 토큰을 소비합니다. `"arrow-2"` 및 `"arrow-2-telos"` 모델에서만 사용됩니다(기본값: `"high"`). | COMBO | 예 | `"low"`<br />`"medium"`<br />`"high"`<br />`"xhigh"` |
| `temperature` | 무작위성 제어입니다. 값이 높을수록 무작위성이 증가합니다. `"arrow-2-telos"` 모델에서는 사용되지 않습니다. 고급 매개변수입니다(기본값: 1.0). | FLOAT | 예 | 0.0~2.0 (0.1 단위) |
| `top_p` | 뉴클리어스 샘플링 매개변수입니다. `"arrow-2-telos"` 모델에서는 사용되지 않습니다. 고급 매개변수입니다(기본값: 1.0). | FLOAT | 예 | 0.05~1.0 (0.05 단위) |
| `presence_penalty` | 토큰 존재 패널티입니다. `"arrow-2-telos"` 모델에서는 사용되지 않습니다. 고급 매개변수입니다(기본값: 0.0). | FLOAT | 예 | -2.0~2.0 (0.1 단위) |

**참고:** `reference_images`의 최대 개수는 14개입니다. `width` 또는 `height`를 0으로 두면 모델이 캔버스 크기를 선택하게 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `SVG` | 생성된 SVG 출력입니다. | SVG |
