이 노드는 선택한 폴더에서 이미지-텍스트 캡션 쌍 데이터셋을 로드하여 리스트로 반환합니다. PNG, JPG, JPEG, WEBP 이미지를 지원하며, 각 이미지에 대해 동일한 기본 이름을 가진 `.txt` 파일에서 캡션을 찾습니다. 또한 kohya-ss/sd-scripts 폴더 구조를 지원하며, 숫자로 시작하는 하위 폴더 이름(예: `10_cats`)은 해당 하위 폴더의 이미지를 출력에서 그 횟수만큼 반복합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `폴더` | 이미지와 텍스트 캡션을 로드할 폴더. | COMBO | 예 | ComfyUI 입력 디렉터리 내의 하위 폴더 (동적으로 로드됨) |

**참고:** 선택한 폴더는 ComfyUI의 입력 디렉터리 하위 폴더여야 합니다. 이 노드는 이미지당 하나의 `.txt` 캡션 파일을 기대합니다. 각 이미지 파일(`.png`, `.jpg`, `.jpeg`, `.webp`)에 대해 동일한 위치에서 같은 기본 이름을 가진 `.txt` 파일을 찾아 앞뒤 공백을 제거한 내용을 캡션으로 사용합니다. 캡션 파일이 없으면 빈 문자열을 사용합니다. 또한 kohya-ss/sd-scripts 폴더 구조를 지원합니다. 숫자와 밑줄로 시작하는 하위 폴더 이름(예: `5_cats`)은 해당 하위 폴더의 이미지를 최종 출력 목록에 그 횟수만큼 반복합니다. 선택한 폴더에 유효한 이미지가 없으면 노드는 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `이미지` | 로드된 이미지 목록. 이미지는 RGB로 변환되고 0–1 부동 소수점 범위로 정규화됩니다. | IMAGE |
| `텍스트` | 각 로드된 이미지에 대한 텍스트 캡션 목록. 캡션은 해당 `.txt` 파일의 앞뒤 공백이 제거된 내용이며, 캡션 파일이 없으면 빈 문자열입니다. | STRING |
