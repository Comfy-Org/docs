이 노드는 LTX 2.4 지속 시간 헤드를 사용하여 프롬프트에 대한 샷의 자연스러운 지속 시간을 예측합니다. 예측된 지속 시간을 공급된 프레임 레이트와 최소/최대 지속 시간 제한을 사용하여 VAE의 프레임 그리드에 맞는 프레임 수로 변환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 텍스트 임베딩을 전처리하고 지속 시간 헤드를 실행하는 데 사용되는 모델입니다. | MODEL | 예 | N/A |
| `positive` | 지속 시간 예측을 위한 프롬프트의 텍스트 임베딩과 메타데이터를 제공하는 컨디셔닝입니다. | CONDITIONING | 예 | N/A |
| `duration_head` | ModelPatchLoader로 로드된 LTX 2.4 지속 시간 헤드입니다. LTX 지속 시간 헤드여야 합니다. | MODEL_PATCH | 예 | N/A |
| `frame_rate` | 초를 프레임으로 변환하는 데 사용되는 초당 프레임 수입니다 (기본값: 24.0). | FLOAT | 예 | 1.0 ~ 120.0 |
| `min_seconds` | 예측을 프레임 수로 변환할 때 사용되는 최소 지속 시간(초)입니다 (기본값: 1.0). | FLOAT | 예 | 0.5 ~ 120.0 |
| `max_seconds` | 예측을 프레임 수로 변환할 때 사용되는 최대 지속 시간(초)입니다 (기본값: 20.0). | FLOAT | 예 | 0.5 ~ 120.0 |

참고: `duration_head` 입력은 ModelPatchLoader로 로드된 LTX 2.4 지속 시간 헤드여야 합니다. 연결된 모델 패치가 LTX 지속 시간 헤드가 아닌 경우 노드는 ValueError를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `num_frames` | 예측된 지속 시간을 프레임 수로 변환하고 VAE의 8k+1 프레임 그리드에 맞춘 값입니다. | INT |
| `seconds` | 원시(클램프되지 않은) 예측 지속 시간입니다. 프레임 그리드에 맞추기 전의 값입니다. | FLOAT |
