이 노드는 ComfyUI 출력 디렉터리에 파일을 저장하지 않고 UI에 3D 모델 미리보기를 표시합니다. 모델을 임시 파일로 저장하고, 이후 후속 처리를 위해 모델 데이터, 모델 정보, 카메라 정보 및 미리보기 크기를 전달합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 이전 3D 노드에서 전달된 3D 모델 파일입니다. | FILE3D | 예 | GLB, GLTF, FBX, OBJ, STL, USDZ 또는 지원되는 기타 3D 형식 |
| `model_3d_info` | 선택적 모델 정보 메타데이터입니다. 고급 옵션입니다. | LOAD3DMODELINFO | 아니요 | - |
| `viewport_state` | 카메라 및 모델 정보를 포함하는 현재 뷰포트 상태입니다. | LOAD3D | 예 | - |
| `camera_info` | 3D 뷰를 위한 선택적 카메라 구성입니다. 고급 옵션입니다. | LOAD3DCAMERA | 아니요 | - |
| `width` | 미리보기의 픽셀 너비입니다. 기본값: 1024. | INT | 예 | 1 ~ 4096 |
| `height` | 미리보기의 픽셀 높이입니다. 기본값: 1024. | INT | 예 | 1 ~ 4096 |

참고: `camera_info` 또는 `model_3d_info`가 연결되지 않은 경우, 사용 가능하면 해당 값은 `viewport_state`에서 가져옵니다. `viewport_state`에 카메라 정보가 없으면 `camera_info`는 None입니다. `viewport_state`에 모델 정보가 없으면 `model_3d_info`는 빈 목록으로 기본 설정됩니다. `viewport_state`가 딕셔너리 유형이 아니면 빈 값으로 처리됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `model_file` | 입력에서 그대로 전달된 3D 모델 파일입니다. | FILE3D |
| `camera_info` | 입력 또는 뷰포트 상태에서 가져온 모델 정보 메타데이터입니다. | LOAD3DMODELINFO |
| `model_3d_info` | 입력 또는 뷰포트 상태에서 가져온 카메라 구성입니다. | LOAD3DCAMERA |
| `width` | 미리보기의 픽셀 너비입니다. | INT |
| `height` | 미리보기의 픽셀 높이입니다. | INT |
