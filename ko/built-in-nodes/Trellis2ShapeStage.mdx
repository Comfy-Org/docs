이 노드는 Trellis2 파이프라인의 첫 번째 형상 생성 샘플링 패스를 설정합니다. VaeDecodeStructureTrellis2가 생성한 밀집 구조 복셀을 입력으로 받아 채워진 복셀의 희소 좌표를 추출하고, 빈 희소 잠재 변수를 만든 다음, 샘플링 메타데이터를 컨디셔닝에 첨부하여 모델이 샘플링 중에 이를 읽을 수 있게 합니다. 업샘플링 후의 두 번째 형상 패스에서는 캐스케이드와 두 번째 패스 단계 설정을 결합한 Trellis2UpsampleStage를 대신 사용하세요.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 형상 단계를 준비하기 위한 긍정 컨디셔닝입니다. 표준 Trellis2 컨디셔닝 또는 투영 특징 팩을 제공하는 Pixal3D 컨디셔닝일 수 있습니다. 투영 특징이 있는 경우 선택된 단계에 대해 계산되어 출력 컨디셔닝에 첨부됩니다. | CONDITIONING | 예 | 모든 Trellis2 또는 Pixal3D 컨디셔닝 |
| `negative` | 형상 단계를 준비하기 위한 부정 컨디셔닝입니다. 긍정 컨디셔닝과 동일한 형상 단계 메타데이터가 여기에도 첨부됩니다. | CONDITIONING | 예 | 모든 Trellis2 또는 Pixal3D 컨디셔닝 |
| `voxel` | VaeDecodeStructureTrellis2에서 생성된 밀집 구조 복셀입니다. | VOXEL | 예 | 모든 복셀 그리드; 그리드 해상도(축당 복셀 수)가 파이프라인 단계를 선택합니다 |

### 참고 사항

- 복셀 그리드 해상도가 파이프라인 단계를 선택합니다. 해상도가 32 이하인 경우 `shape_generation_512` 모드와 `shape_512` 단계를 사용하고, 해상도가 32보다 크면 `shape_generation` 모드와 `shape_1024` 단계를 사용합니다.
- 복셀에는 채워진 복셀이 하나 이상 포함되어야 합니다. 빈 복셀은 오류를 발생시킵니다. 복셀에서 파생된 배치 인덱스는 음수가 아니어야 하며 연속적이어야 합니다.
- `positive` 컨디셔닝에 `proj_feat_pack`(Pixal3D 컨디셔닝에서 제공)이 포함된 경우, 선택된 단계에 대해 투영 특징이 계산되고 출력 잠재 변수의 모델 프레임이 `y_up`으로 설정됩니다. 그렇지 않으면 투영 특징이 첨부되지 않으며 모델 프레임이 `z_up`으로 설정됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 형상 단계 메타데이터가 첨부된 긍정 컨디셔닝입니다. 소스 컨디셔닝이 제공하는 경우 생성 모드, 희소 좌표, 배치별 좌표 개수, 투영 특징이 포함됩니다. | CONDITIONING |
| `negative` | 동일한 형상 단계 메타데이터가 첨부된 부정 컨디셔닝입니다. | CONDITIONING |
| `latent` | 추출된 희소 좌표, 배치별 좌표 개수, 좌표 해상도, `trellis2` 유형 표시자 및 모델 프레임 방향과 함께 제공되는 빈 희소 잠재 텐서입니다(형태: 배치 크기, 32, 토큰 개수, 1). | LATENT |
