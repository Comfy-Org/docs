이 노드는 MiniMax H3 768P 비디오 출력을 2K 해상도로 다시 렌더링합니다. 소스 비디오와 이를 생성하는 데 사용된 정확한 프롬프트를 업로드하고, MiniMax H3 재생성 작업을 시작한 후, 다시 렌더링된 2K 비디오를 반환합니다. 원래 생성에서 첫 번째 또는 마지막 프레임이나 참조 미디어를 사용한 경우, 동일한 입력을 첨부하세요.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 재생성에 사용할 모델입니다. 이 모델을 선택하면 아래에 문서화된 프롬프트, 해상도 및 참조 미디어 설정이 표시됩니다. | COMBO | 예 | "MiniMax H3" |
| `prompt` | 소스 비디오를 생성하는 데 사용된 정확한 프롬프트입니다. 비어 있으면 안 됩니다. | STRING | 예 | Text |
| `resolution` | 소스 비디오를 다시 렌더링할 해상도입니다. | COMBO | 예 | "2K" |
| `reference_images` | 원래 생성에서 참조 이미지로, 동일한 순서로 지정합니다. 최대 9개 이미지. | IMAGE | 아니요 | 0-9 images |
| `reference_videos` | 원래 생성에서 참조 비디오로, 동일한 순서로 지정합니다. 최대 3개 비디오, 각각 2-15초, 총 15초입니다. | VIDEO | 아니요 | 0-3 videos |
| `reference_audios` | 원래 생성에서 오디오 참조로, 동일한 순서로 지정합니다. 최대 3개 클립, 각각 2-15초, 총 15초입니다. 참조 이미지나 비디오 없이는 사용할 수 없습니다. | AUDIO | 아니요 | 0-3 clips |
| `video` | 다시 렌더링할 MiniMax H3 768P 출력 비디오입니다. MiniMax H3 비디오 노드의 수정되지 않은 출력(24 FPS, 4-15초)을 연결하세요. 2K 출력은 사용할 수 없습니다. | VIDEO | 예 | 24 FPS, 4-15 seconds |
| `first_frame` | 원래 생성에서 사용된 첫 번째 프레임 이미지입니다(사용된 경우). | IMAGE | 아니요 | Image |
| `last_frame` | 원래 생성에서 사용된 마지막 프레임 이미지입니다(사용된 경우). | IMAGE | 아니요 | Image |
| `watermark` | 비디오에 AIGC 워터마크를 추가할지 여부입니다. 기본값은 false입니다. | BOOLEAN | 예 | false / true |

### 제약 사항

- 소스 `video`는 수정되지 않은 MiniMax H3 768P 출력이어야 합니다: 너비와 높이가 32로 나누어 떨어지고, 총 픽셀이 최대 1,032,192개, 24 FPS, 그리고 107~362프레임(17 단위)이어야 합니다(24 FPS에서 4~15초). 2K 출력은 소스로 사용할 수 없습니다.
- `first_frame` / `last_frame`와 참조 미디어(`reference_images`, `reference_videos`, `reference_audios`)는 상호 배타적입니다. 프레임은 이미지-투-비디오 프롬프트에 사용하고, 참조 미디어는 참조-투-비디오 프롬프트에 사용하세요.
- `reference_audios`는 최소 하나의 `reference_images` 또는 `reference_videos` 입력이 필요합니다.
- `reference_images`: 각 이미지는 종횡비가 0.4에서 2.5 사이여야 하며 최소 256x256 픽셀이어야 합니다.
- `reference_videos`: 각 비디오는 23.976~60 FPS, 길이는 2~15초여야 하며, 총 재생 시간은 15초를 초과할 수 없습니다.
- `reference_audios`: 각 클립은 2~15초 길이여야 하며, 총 재생 시간은 15초를 초과할 수 없습니다.
