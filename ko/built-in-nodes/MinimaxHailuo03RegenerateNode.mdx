이 노드는 MiniMax H3 768P 비디오 출력을 2K 해상도로 다시 렌더링합니다. 수정되지 않은 768P 비디오와 이를 생성하는 데 사용된 정확한 프롬프트를 업로드하고, MiniMax H3 재생성 작업을 시작한 뒤, 다시 렌더링된 2K 비디오를 반환합니다. 원래 생성에서 첫 프레임 또는 마지막 프레임이나 참조 미디어를 사용했다면 동일한 입력을 연결하십시오.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 재생성에 사용할 모델입니다. "MiniMax H3"를 선택하면 프롬프트, 해상도, 참조 미디어 설정이 표시됩니다. | DYNAMIC_COMBO | 예 | "MiniMax H3" |
| `video` | 다시 렌더링할 MiniMax H3 768P 출력 비디오입니다. MiniMax H3 비디오 노드의 수정되지 않은 출력을 연결하십시오(24 FPS, 4-15초). 2K 출력은 사용할 수 없습니다. | VIDEO | 예 | 24 FPS, 4-15초 |
| `first_frame` | 원래 생성에서 첫 프레임 이미지가 사용된 경우 해당 이미지입니다. | IMAGE | 아니요 | IMAGE |
| `last_frame` | 원래 생성에서 마지막 프레임 이미지가 사용된 경우 해당 이미지입니다. | IMAGE | 아니요 | IMAGE |
| `watermark` | 비디오에 AIGC 워터마크를 추가할지 여부입니다. 기본값은 false입니다. | BOOLEAN | 예 | false / true |

### MiniMax H3 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 소스 비디오를 생성하는 데 사용된 정확한 프롬프트입니다. 비워 둘 수 없습니다. | STRING | 예 | 텍스트(여러 줄) |
| `resolution` | 소스 비디오를 다시 렌더링할 해상도입니다. | COMBO | 예 | "2K" |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 확장 가능한 슬롯: `image_1`부터 `image_9`까지 연결합니다(최대 9개 이미지). 원래 생성에서 사용한 참조 이미지를 동일한 순서로 지정합니다. | IMAGE | 아니요 | 0-9개 이미지 |
| `reference_videos` | 확장 가능한 슬롯: `video_1`부터 `video_3`까지 연결합니다(최대 3개 비디오). 원래 생성에서 사용한 참조 비디오를 동일한 순서로 지정합니다. | VIDEO | 아니요 | 0-3개 비디오 |
| `reference_audios` | 확장 가능한 슬롯: `audio_1`부터 `audio_3`까지 연결합니다(최대 3개 클립). 원래 생성에서 사용한 오디오 참조를 동일한 순서로 지정합니다. 참조 이미지나 비디오 없이 사용할 수 없습니다. | AUDIO | 아니요 | 0-3개 클립 |

### 제약 사항

- `prompt`는 비워 둘 수 없습니다.
- 소스 `video`는 수정되지 않은 MiniMax H3 768P 출력이어야 합니다: 24 FPS, 너비와 높이가 32로 나누어져야 하며, 총 픽셀 수는 최대 1,032,192개이고, 107~362프레임(17프레임 단위, 24 FPS에서 4~15초)이어야 합니다. 2K 출력은 소스로 사용할 수 없습니다.
- `first_frame`과 `last_frame`은 참조 미디어(`reference_images`, `reference_videos`, `reference_audios`)와 함께 사용할 수 없습니다. 이미지-투-비디오 프롬프트에는 프레임을 사용하고, 참조-투-비디오 프롬프트에는 참조 미디어를 사용하십시오.
- `reference_audios`를 사용하려면 최소 하나의 `reference_images` 또는 `reference_videos` 입력이 필요합니다.
- `first_frame`, `last_frame`, 각 `reference_image`의 가로세로 비율은 0.4에서 2.5 사이여야 하며, 최소 256x256픽셀이어야 합니다.
- `reference_videos`: 각 비디오는 23.976~60 FPS이고 2~15초 길이여야 하며, 총 길이는 15초를 초과할 수 없습니다.
- `reference_audios`: 각 클립은 2~15초 길이여야 하며, 총 길이는 15초를 초과할 수 없습니다.
