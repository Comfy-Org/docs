이 노드는 MiniMax H3 768P 비디오 출력을 2K 해상도로 다시 렌더링합니다. 수정되지 않은 768P 비디오와 해당 비디오를 생성할 때 사용된 정확한 프롬프트를 업로드하고 MiniMax H3 재생성 작업을 시작한 후, 다시 렌더링된 2K 비디오를 반환합니다. 원래 생성에서 첫 번째 또는 마지막 프레임이나 참조 미디어를 사용한 경우, 동일한 입력을 첨부하세요.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 재생성에 사용할 모델입니다. "MiniMax H3"을 선택하면 프롬프트, 해상도, 참조 미디어 설정이 표시됩니다. | DYNAMIC_COMBO | 예 | "MiniMax H3" |
| `video` | 다시 렌더링할 MiniMax H3 768P 출력 비디오입니다. MiniMax H3 비디오 노드의 수정되지 않은 출력(24 FPS, 4~15초)을 연결하세요. 2K 출력은 사용할 수 없습니다. | VIDEO | 예 | 24 FPS, 4-15 seconds |
| `first_frame` | 원래 생성에서 사용된 경우, 첫 번째 프레임 이미지입니다. | IMAGE | 아니요 | Image |
| `last_frame` | 원래 생성에서 사용된 경우, 마지막 프레임 이미지입니다. | IMAGE | 아니요 | Image |
| `watermark` | 비디오에 AIGC 워터마크를 추가할지 여부입니다. 기본값은 false입니다. | BOOLEAN | 예 | false / true |

### MiniMax H3 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 소스 비디오를 생성하는 데 사용된 정확한 프롬프트입니다. 비어 있으면 안 됩니다. | STRING | 예 | Text (multiline) |
| `resolution` | 소스 비디오를 다시 렌더링할 해상도입니다. | COMBO | 예 | "2K" |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 확장 가능한 슬롯: `image_1`부터 `image_9`까지(최대 9개 이미지) 연결합니다. 원래 생성에서 사용된 참조 이미지를 동일한 순서로 연결합니다. | IMAGE | 아니요 | 0-9 images |
| `reference_videos` | 확장 가능한 슬롯: `video_1`부터 `video_3`까지(최대 3개 비디오) 연결합니다. 원래 생성에서 사용된 참조 비디오를 동일한 순서로 연결합니다. | VIDEO | 아니요 | 0-3 videos |
| `reference_audios` | 확장 가능한 슬롯: `audio_1`부터 `audio_3`까지(최대 3개 클립) 연결합니다. 원래 생성에서 사용된 오디오 참조를 동일한 순서로 연결합니다. 참조 이미지 또는 비디오 없이는 사용할 수 없습니다. | AUDIO | 아니요 | 0-3 clips |

### 제약 사항

- `prompt`는 비어 있으면 안 됩니다.
- 소스 `video`는 수정되지 않은 MiniMax H3 768P 출력이어야 합니다: 24 FPS, 너비와 높이가 32로 나누어 떨어지고, 총 픽셀 수가 1,032,192 이하이며, 17 단위로 107~362 프레임(24 FPS에서 4~15초)이어야 합니다. 2K 출력은 소스로 사용할 수 없습니다.
- `first_frame` 및 `last_frame`은 참조 미디어(`reference_images`, `reference_videos`, `reference_audios`)와 함께 사용할 수 없습니다. 이미지-비디오 프롬프트에는 프레임을 사용하고, 참조-비디오 프롬프트에는 참조 미디어를 사용하십시오.
- `reference_audios`를 사용하려면 `reference_images` 또는 `reference_videos` 입력이 최소 하나 이상 필요합니다.
- `first_frame`, `last_frame` 및 각 `reference_image`의 종횡비는 0.4~2.5 사이여야 하며 최소 256x256 픽셀이어야 합니다.
- `reference_videos`: 각 비디오는 23.976~60 FPS, 길이 2~15초여야 하며, 총 재생 시간은 15초를 초과할 수 없습니다.
- `reference_audios`: 각 클립은 길이 2~15초여야 하며, 총 재생 시간은 15초를 초과할 수 없습니다.
