PerturbedAttentionGuidance 노드는 확산 모델에 섭동 어텐션 가이던스를 적용하여 생성 품질을 향상시킵니다. 이 노드는 샘플링 중 모델의 노이즈 제거 과정을 조정합니다. 정상적인 조건부 예측을 값 프로젝션만 사용하는 단순화된 어텐션 메커니즘으로 만든 예측과 비교한 다음, 스케일된 차이를 결과에 다시 더합니다. `scale`이 0으로 설정된 경우, 이 노드는 아무런 효과가 없습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 섭동 어텐션 가이던스를 적용할 확산 모델입니다. | MODEL | 예 | - |
| `스케일` | 섭동 어텐션 가이던스 효과의 강도입니다 (기본값: 3.0). 0으로 설정하면 노드가 효과를 가지지 않으며 원래의 디노이징 결과를 반환합니다. | FLOAT | 예 | 0.0 - 100.0 (step: 0.01) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model` | 섭동 어텐션 가이던스가 적용된 수정된 모델입니다. | MODEL |
