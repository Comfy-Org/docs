PerturbedAttentionGuidance 노드는 생성 품질을 향상시키기 위해 확산 모델에 교란 어텐션 가이던스를 적용합니다. 샘플링 중에는 중간 블록의 셀프 어텐션이 값 투영을 그대로 통과시키는 단순화된 버전으로 대체되는 추가 예측을 수행한 다음, 일반 조건부 예측과 이 교란된 예측 간의 차이에 `scale`을 곱한 값을 노이즈 제거 결과에 더합니다. `scale`을 0으로 설정하면 효과가 완전히 비활성화됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 교란 어텐션 가이던스를 적용할 확산 모델 | MODEL | 예 | - |
| `스케일` | 교란 어텐션 가이던스 효과의 강도입니다(기본값: 3.0). 0으로 설정하면 노드가 아무 효과도 없으며 원래의 노이즈 제거 결과를 변경 없이 반환합니다. | FLOAT | 예 | 0.0 - 100.0 (단계: 0.01) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model` | 샘플링 프로세스에 교란 어텐션 가이던스 패치가 연결된 수정된 모델 | MODEL |
