## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `da3_geometry` | 깊이 맵, 선택적 신뢰도 맵, 선택적 스카이 맵 및 원본 이미지를 포함하는 DA3_GEOMETRY 패킷입니다. | DA3_GEOMETRY | 예 | - |
| `batch_index` | 변환할 배치의 이미지를 지정합니다. 이미지별 정점 수가 다르므로 배치를 스택할 수 없습니다(기본값: 0). 입력 지오메트리의 배치 크기보다 작아야 하며, 그렇지 않으면 오류가 발생합니다. | INT | 예 | 0  ~  4096 |
| `decimation` | 정점 스트라이드입니다. 1 = 전체 해상도, 2 = 절반 등(기본값: 1) | INT | 예 | 1  ~  8 |
| `discontinuity_threshold` | 3x3 깊이 범위가 이 비율을 초과하는 삼각형을 제거합니다. 0 = 끄기(기본값: 0.04) | FLOAT | 예 | 0.0  ~  1.0 |
| `confidence_threshold` | 이미지별로 정규화된 신뢰도가 이 값 미만인 픽셀을 제외합니다. 0 = 모두 유지, 1 = 가장 신뢰도가 높은 단일 픽셀만 유지. 지오메트리에 신뢰도 맵이 있을 때 사용됩니다(Small/Base 모델)(기본값: 0.1) | FLOAT | 예 | 0.0  ~  1.0 |
| `use_sky_mask` | 메시에서 하늘 확률 픽셀(하늘 >= 0.5)을 제외합니다. 지오메트리에 스카이 맵이 있을 때 사용됩니다(Mono/Metric 모델)(기본값: True) | BOOLEAN | 예 | True or False |
| `texture` | 원본 이미지를 기본 색상 텍스처로 사용합니다(기본값: True) | BOOLEAN | 예 | True or False |

유한하지 않거나 0 또는 음수인 깊이 값을 가진 픽셀은 항상 메시에서 제외됩니다. 결과 메시가 비어 있으면 오류가 발생하며, 오류 메시지는 `discontinuity_threshold`를 높이거나 `confidence_threshold`를 낮추거나 `use_sky_mask`를 비활성화하도록 제안합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `MESH` | 정점, 면, UV 좌표 및 선택적 텍스처를 포함하는 삼각분할된 3D 메시 | MESH |
