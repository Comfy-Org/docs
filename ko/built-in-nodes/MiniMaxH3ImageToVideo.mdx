## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 프롬프트를 토큰화하고 키프레임 이미지를 컨디셔닝으로 인코딩하는 데 사용되는 CLIP 모델입니다. | CLIP | 예 |  |
| `vae` | 키프레임 이미지가 제공될 때 해당 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 |  |
| `prompt` | 생성할 비디오를 설명하는 텍스트 프롬프트입니다. 여러 줄 및 동적 프롬프트를 지원합니다. | STRING | 예 |  |
| `width` | 비디오의 너비(픽셀)입니다(기본값: 1344). | INT | 예 | 32 ~ MAX_RESOLUTION (단계 32) |
| `height` | 비디오의 높이(픽셀)입니다(기본값: 768). | INT | 예 | 32 ~ MAX_RESOLUTION (단계 32) |
| `length` | 24 fps 기준 프레임 수이며, 모델의 17k+5 그리드에 맞춰 올림됩니다(124 = 약 5초, 학습 범위는 약 124-362이며 더 긴 값은 테스트되지 않음)(기본값: 124). | INT | 예 | 5 ~ 3600 (단계 17) |
| `first_frame` | 비디오의 첫 프레임으로 사용할 선택적 이미지입니다. 전체 캔버스 크기에 맞게 늘어나므로 종횡비가 유지되지 않습니다. 입력 배치의 첫 번째 이미지만 사용됩니다. | IMAGE | 아니요 |  |
| `last_frame` | 비디오의 마지막 프레임으로 사용할 선택적 이미지입니다. 종횡비를 유지하면서 캔버스를 채우도록 잘립니다. 입력 배치의 첫 번째 이미지만 사용됩니다. | IMAGE | 아니요 |  |

`first_frame` 및/또는 `last_frame`이 제공되면, 키프레임 이미지가 VAE로 인코딩되어 각각 프레임 0과 마지막 프레임의 컨디셔닝에 첨부됩니다. 둘 다 제공되지 않으면 노드는 프롬프트만으로 작동합니다. 요청된 `length`는 가장 가까운 유효 프레임 수(17k + 5)로 올림되므로, 실제 프레임 수는 요청한 값보다 약간 더 클 수 있습니다.

오디오-비디오 latent는 요청된 `width`, `height` 및 올림된 프레임 수에 맞는 빈 쌍으로 생성됩니다. 오디오 부분은 동일한 프레임 수를 기준으로 초당 40 오디오 프레임으로 크기가 정해집니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 인코딩된 프롬프트와, 키프레임 이미지가 제공된 경우 MiniMax H3 모델용으로 인코딩된 키프레임 및 프레임 수를 포함하는 컨디셔닝입니다. | CONDITIONING |
| `latent` | 생성할 콘텐츠를 나타내는 빈 오디오-비디오 latent로, 요청된 너비, 높이 및 프레임 수를 가집니다. | LATENT |
