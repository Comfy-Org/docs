이 노드는 Meshy T2.5를 사용하여 목표 면 수에 맞는 게임용 삼각형 메시를 생성합니다. 요청된 폴리곤 수에 맞춰 토폴로지가 구축되며, 이후에 데시메이션되지 않으므로 별도의 리토폴로지 과정 없이 게임 엔진에서 바로 사용할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 생성에 사용할 Meshy 모델 버전입니다. | COMBO | 예 | `"meshy-t2.5"` |
| `prompt` | 생성할 3D 모델에 대한 텍스트 설명입니다. | STRING | 예 | 1~800자 |
| `target_polycount` | 생성된 메시의 대략적인 삼각형 수입니다. 기본값: 15000. | INT | 예 | 100~30000 |
| `pose_mode` | 생성된 캐릭터의 포즈입니다. 빈 문자열은 특정 포즈를 요청하지 않습니다. 이 설정은 고급 설정입니다. 기본값: `""` (빈 문자열). | COMBO | 예 | `""`<br />`"A-pose"`<br />`"T-pose"` |
| `seed` | 시드는 노드의 재실행 여부를 제어합니다. 시드에 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |

**제약 사항:**

* 프롬프트는 1자에서 800자 사이여야 합니다.
* `target_polycount`는 메시가 구축되는 삼각형 수이며, 생성 후에 적용되는 제한이 아닙니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `meshy_task_id` | Meshy API 작업의 고유 식별자입니다. | MESHY_TASK_ID |
| `GLB` | GLB 형식으로 생성된 3D 모델입니다. | FILE3DGLB |
| `FBX` | FBX 형식으로 생성된 3D 모델입니다. | FILE3DFBX |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/MeshyTextToModelSmartTopologyNode/ko.md)
