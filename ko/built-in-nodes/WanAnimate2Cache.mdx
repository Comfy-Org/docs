포즈 비디오의 블록별 활성화를 한 번 캐시하여 매 샘플링 단계마다 재계산할 필요가 없게 하므로 생성 시간이 약 절반으로 줄어듭니다. 대신 추가 메모리가 사용됩니다. bf16에서 81프레임, 480x832 해상도일 때 시스템 RAM 약 12.5GB가 필요하며, 해상도와 비디오 길이에 따라 증가합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 캐시를 연결할 Wan Animate2 모델입니다. | MODEL | 예 | |
| `device` | 캐시를 유지할 위치입니다. cpu(RAM)가 안전한 선택입니다. 일반적인 크기에서는 캐시가 모델과 함께 VRAM에 맞지 않습니다. gpu(VRAM)는 맞는다면 더 빠를 수 있습니다. (기본값: "cpu") | STRING | 예 | "cpu"<br />"gpu" |
| `dtype` | 저장 정밀도입니다. default는 모델의 계산 dtype으로 활성화를 저장합니다. int8은 캐시를 절반으로 줄이고, int4는 4분의 1로 줄이며, convrot은 정확도를 유지하는 데 사용됩니다. (기본값: "default") | STRING | 예 | "default"<br />"int8"<br />"int4" |

참고: 컨텍스트 창을 사용하는 경우 각 창이 별도로 캐시되므로 메모리 사용량은 창 수에 따라 증가합니다. static_standard 스케줄을 사용해야 합니다. uniform 스케줄은 매 단계마다 창을 이동시키므로 캐시가 재사용되지 않기 때문입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model` | 포즈 비디오 활성화 캐시가 연결된 복제된 모델입니다. 캐시는 생성이 완료되면 자동으로 해제됩니다. | MODEL |
