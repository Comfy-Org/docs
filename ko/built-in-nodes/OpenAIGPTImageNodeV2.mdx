이 노드는 OpenAI의 GPT Image API를 사용하여 이미지를 생성합니다. 여러 모델(`gpt-image-2`, `gpt-image-1.5`, `gpt-image-1`)을 지원하며, 편집을 위한 참조 이미지를 제공할 수 있고, 마스크를 사용하여 이미지에서 수정할 부분을 지정할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 사용할 OpenAI GPT Image 모델입니다. 모델을 선택하면 해당 모델에 특화된 추가 매개변수가 표시됩니다. | DYNAMIC_COMBO | 예 | `"gpt-image-2"`<br />`"gpt-image-1.5"`<br />`"gpt-image-1"` |
| `프롬프트` | GPT Image용 텍스트 프롬프트(기본값: `""`). | STRING | 예 | N/A |
| `개수` | 생성할 이미지 수(기본값: `1`). | INT | 예 | 1 ~ 8 |
| `시드` | 재현성을 위한 시드(기본값: `0`). 아직 백엔드에서 구현되지 않았습니다. | INT | 예 | 0 ~ 2147483647 |

### gpt-image-2 입력

이 입력은 `model`이 `gpt-image-2`로 설정된 경우에 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `사이즈` | 이미지 크기. 사용자 지정 너비와 높이를 사용하려면 "Custom"을 선택합니다(기본값: `"auto"`). | COMBO | 예 | `"auto"`<br />`"1024x1024"`<br />`"1024x1536"`<br />`"1536x1024"`<br />`"2048x2048"`<br />`"2048x1152"`<br />`"1152x2048"`<br />`"3840x2160"`<br />`"2160x3840"`<br />`"Custom"` |
| `사용자 지정 너비` | `model.size`가 "Custom"인 경우에만 사용됩니다. 16의 배수여야 합니다(기본값: `1024`). | INT | 아니요 | 1024 ~ 3840 |
| `사용자 지정 높이` | `model.size`가 "Custom"인 경우에만 사용됩니다. 16의 배수여야 합니다(기본값: `1024`). | INT | 아니요 | 1024 ~ 3840 |
| `배경` | 배경이 있거나 없는 이미지를 반환합니다(기본값: `"auto"`). | COMBO | 예 | `"auto"`<br />`"opaque"` |
| `품질` | 이미지 품질. 비용과 생성 시간에 영향을 줍니다(기본값: `"low"`). | COMBO | 예 | `"low"`<br />`"medium"`<br />`"high"` |
| `model.images` | 이미지 편집을 위한 선택적 참조 이미지. 최대 16개 이미지. 자세한 내용은 참조 입력을 참조하세요. | IMAGE | 아니요 | 0 ~ 16 |
| `model.mask` | 인페인팅을 위한 선택적 마스크(흰색 영역은 대체됩니다). 참조 이미지가 정확히 하나 있어야 합니다. | MASK | 아니요 | N/A |

### gpt-image-1.5 및 gpt-image-1 입력

이 입력은 `model`이 `gpt-image-1.5` 또는 `gpt-image-1`로 설정된 경우 나타납니다. 두 모델은 동일한 매개변수 집합을 공유합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `사이즈` | 이미지 크기(기본값: `"auto"`). | COMBO | 예 | `"auto"`<br />`"1024x1024"`<br />`"1024x1536"`<br />`"1536x1024"` |
| `배경` | 배경이 있거나 없는 이미지를 반환합니다(기본값: `"auto"`). | COMBO | 예 | `"auto"`<br />`"opaque"`<br />`"transparent"` |
| `품질` | 이미지 품질. 비용과 생성 시간에 영향을 줍니다(기본값: `"low"`). | COMBO | 예 | `"low"`<br />`"medium"`<br />`"high"` |
| `model.images` | 이미지 편집을 위한 선택적 참조 이미지. 최대 16개 이미지. 자세한 내용은 참조 입력을 참조하세요. | IMAGE | 아니요 | 0 ~ 16 |
| `model.mask` | 인페인팅을 위한 선택적 마스크(흰색 영역은 대체됩니다). 참조 이미지가 정확히 하나 있어야 합니다. | MASK | 아니요 | N/A |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `model.images` | 확장 가능한 슬롯: 1..N개 항목(예: `image_1`...`image_16`)을 연결합니다. 모든 모델에서 최대 16개의 참조 이미지를 지원합니다. | IMAGE | 아니요 | 1 ~ 16 |
| `model.mask` | 인페인팅을 위한 선택적 마스크(흰색 영역은 대체됩니다). 참조 이미지가 정확히 하나 있어야 합니다. | MASK | 아니요 | N/A |

**매개변수 제약 조건 및 제한 사항:**

- `model.size`가 "Custom"일 때(gpt-image-2 전용), `model.custom_width` 및 `model.custom_height`는 모두 16의 배수여야 하며, 가장 긴 변은 3840을 초과할 수 없고, 종횡비는 3:1을 초과할 수 없으며, 총 픽셀 수는 655,360 이상 8,294,400 이하여야 합니다.
- `model.mask`는 `model.images`에 참조 이미지가 정확히 하나 있어야 합니다. 참조 이미지 없이는 사용할 수 없고, 두 개 이상의 이미지와 함께 사용할 수도 없습니다.
- `model.mask`를 사용하는 경우 해당 크기는 참조 이미지의 크기와 일치해야 합니다.
- `model.images`가 제공되면 노드는 이미지 편집 모드로 실행됩니다. `model.images`가 없으면 프롬프트만으로 이미지를 생성합니다.
- 참조 이미지는 API로 전송되기 전에 축소됩니다.
- `seed`는 현재 백엔드에 구현되어 있지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `image` | 생성된 이미지(들). 반환된 모든 이미지는 하나의 배치로 쌓이며, 크기가 다를 경우 첫 번째 이미지에 맞춰 크기가 조정됩니다. | IMAGE |
