프롬프트를 MiniMax H3 Image용 컨디셔닝과 빈 레이턴트로 변환합니다. 이미지를 연결하지 않으면 텍스트 투 이미지이고, 이미지를 연결하면 편집이 되며 프롬프트에서는 `<Picture 1>`, `<Picture 2>`처럼 이미지를 참조합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | 참조 이미지가 있으면 프롬프트를 해당 이미지와 함께 토큰화하고 컨디셔닝을 인코딩하는 MiniMax H3 Image CLIP 모델입니다. | CLIP | 예 | - |
| `vae` | MiniMax H3 Image VAE입니다. 이를 사용하면 이미지가 참조 레이턴트로도 고정되고, 사용하지 않으면 이미지는 텍스트 인코더에만 조건을 제공합니다. | VAE | 아니요 | - |
| `prompt` | 생성할 내용 또는 참조 이미지를 편집하는 방법입니다. | STRING | 예 | 여러 줄 텍스트 |
| `width` | 출력 너비(픽셀)입니다. 0이면 참조 스케일링 후 `image_1`의 너비를 사용하며, 이미지가 없으면 2048을 사용합니다. 기본값: 0. | INT | 예 | 0 ~ MAX_RESOLUTION (단계: 32) |
| `height` | 출력 높이(픽셀)입니다. 0이면 참조 스케일링 후 `image_1`의 높이를 사용하며, 이미지가 없으면 2048을 사용합니다. 기본값: 0. | INT | 예 | 0 ~ MAX_RESOLUTION (단계: 32) |
| `images` | `image_1`부터 시작하는 확장 가능한 참조 이미지 그룹입니다. `image_1`은 편집할 이미지입니다. 프롬프트에서는 이를 `<Picture n>`으로 참조합니다. | AUTOGROW | 아니요 | 0~100개 이미지 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `positive` | MiniMax H3 Image 샘플러용 컨디셔닝이며, 이미지가 연결되면 참조 레이턴트가 함께 첨부됩니다. | CONDITIONING |
| `latent` | 출력 크기의 1/16 크기이며 24개 채널을 가진 단일 이미지용 빈 레이턴트입니다. | LATENT |

참고: 이 모델은 2048x2048픽셀 면적에 맞게 조정되어 있으므로, 다른 캔버스가 필요하지 않는 한 `width`와 `height`를 0으로 두십시오.
