WanSoundImageToVideoExtend 노드는 오디오, 참조 이미지 및 제어 비디오에 의해 선택적으로 안내되는 추가 프레임을 생성하여 기존 비디오 잠재 변수를 확장합니다. 시작 비디오 잠재 변수를 입력받아 제공된 컨디셔닝과 오디오 신호를 사용하여 새 콘텐츠에 영향을 주면서 더 긴 비디오 시퀀스를 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `긍정 프롬프트` | 비디오에 포함되어야 하는 내용을 안내하는 긍정 컨디셔닝 프롬프트입니다. | CONDITIONING | 예 | - |
| `부정 프롬프트` | 비디오에서 제외되어야 하는 내용을 지정하는 부정 컨디셔닝 프롬프트입니다. | CONDITIONING | 예 | - |
| `VAE` | 참조 이미지와 제어 비디오를 잠재 공간으로 인코딩하는 데 사용되는 변분 오토인코더입니다. | VAE | 예 | - |
| `길이` | 비디오 시퀀스에 생성할 총 프레임 수입니다. (기본값: 77, 간격: 4) | INT | 예 | 1 to MAX_RESOLUTION |
| `비디오 잠재 공간` | 확장의 시작점 역할을 하는 초기 비디오 잠재 변수입니다. 출력 너비, 높이, 배치 크기 및 프레임 오프셋은 이 잠재 변수에서 파생됩니다. 이 잠재 변수의 마지막 19개 프레임은 참조 모션 컨디셔닝으로 사용됩니다. | LATENT | 예 | - |
| `오디오 인코더 출력` | 사운드 특성에 따라 비디오 생성에 영향을 줄 수 있는 선택적 오디오 임베딩입니다. 제공되면 오디오가 보간되고 오디오 임베딩 버킷으로 변환되어 컨디셔닝에 추가됩니다. | AUDIOENCODEROUTPUT | 아니요 | - |
| `참조 이미지` | 비디오 생성에 시각적 안내를 제공하는 선택적 참조 이미지입니다. 이미지는 대상 크기에 맞게 업스케일된 후 잠재 변수로 인코딩되며, 이 잠재 변수는 긍정 및 부정 컨디셔닝에 모두 추가됩니다. 배치의 첫 번째 이미지만 사용됩니다. | IMAGE | 아니요 | - |
| `제어 비디오` | 생성된 비디오의 움직임과 구조를 안내하는 선택적 제어 비디오입니다. 비디오는 업스케일 및 인코딩된 후 긍정 및 부정 컨디셔닝에 모두 추가됩니다. 제어 비디오는 지정된 `length`로 잘립니다. | IMAGE | 아니요 | - |

참고: 출력 잠재 변수는 대상 크기의 0으로 초기화됩니다. 입력 `video_latent`는 이 출력에 복사되지 않으며, 대신 마지막 19개 프레임이 참조 모션으로 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `긍정 프롬프트` | 비디오 컨텍스트가 적용된 처리된 긍정 컨디셔닝입니다. 제공된 경우 오디오 임베딩, 참조 잠재 변수, 참조 모션 및 제어 비디오가 포함됩니다. | CONDITIONING |
| `부정 프롬프트` | 비디오 컨텍스트가 적용된 처리된 부정 컨디셔닝입니다. 제공된 경우 오디오 임베딩(0으로 설정됨), 참조 잠재 변수, 참조 모션 및 제어 비디오가 포함됩니다. | CONDITIONING |
| `잠재 공간` | 확장된 시퀀스의 비디오 잠재 변수 표현입니다. 입력 `video_latent`와 대상 `length`에서 파생된 크기로 0으로 초기화됩니다. | LATENT |
