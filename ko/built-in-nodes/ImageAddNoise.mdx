ImageAddNoise 노드는 입력 이미지에 무작위 노이즈를 추가합니다. 지정된 무작위 시드를 사용하여 일관된 노이즈 패턴을 생성하며, 노이즈 효과의 강도를 제어할 수 있습니다. 결과 이미지는 입력과 동일한 크기를 유지하지만 시각적 텍스처가 추가됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `이미지` | 노이즈가 추가될 입력 이미지입니다. | IMAGE | 예 | - |
| `시드` | 노이즈 생성에 사용되는 무작위 시드입니다(기본값: 0). 이 매개변수는 "생성 후 제어" 기능을 지원합니다. | INT | 예 | 0 ~ 18446744073709551615 |
| `강도` | 노이즈 효과의 강도를 제어합니다(기본값: 0.5, 단계: 0.01). | FLOAT | 예 | 0.0 ~ 1.0 |

**참고:** 노이즈 값은 이미지에 더해지며, 결과는 0.0~1.0 범위로 클리핑됩니다. 입력 이미지에 알파 채널(4채널)이 있는 경우 원본 알파 채널은 변경되지 않고 유지되며, 노이즈는 색상 채널에만 적용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `image` | 노이즈가 추가된 출력 이미지입니다. | IMAGE |
