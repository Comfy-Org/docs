기존 텍스처 이미지에서 basecolor, normal, roughness, metalness 및 height로 구성된 PBR 머티리얼 맵 세트를 도출합니다. 활성화하는 각 맵은 비용을 증가시키므로 필요한 맵만 활성화하십시오. 아직 머티리얼 맵이 없는 텍스처를 완성하거나 손상된 단일 맵을 다시 생성하는 데 사용하십시오.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | PBR 맵을 도출할 사진 또는 렌더입니다. | IMAGE | 예 | - |
| `basecolor` | basecolor(알베도) 맵을 생성합니다. 기본값: True. | BOOLEAN | 예 | true<br />false |
| `normal` | 노멀 맵을 생성합니다. 기본값: True. | BOOLEAN | 예 | true<br />false |
| `roughness` | 러프니스 맵을 생성합니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `metalness` | 메탈니스 맵을 생성합니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `height` | 하이트(변위) 맵을 생성합니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `seed` | 재현 가능한 디노이징을 위한 시드입니다. 기본값: 42. | INT | 예 | 0 ~ 2147483646 |
| `safety_checker` | 요청에 대해 제공업체의 콘텐츠 안전 검사를 실행합니다. 고급 설정입니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `auto_downscale` | 가장 긴 변이 모델 입력 한도인 2048픽셀을 초과하는 입력 이미지를 가로세로 비율을 유지하면서 자동으로 다운스케일합니다. 더 작은 이미지는 그대로 둡니다. 비활성화하면 크기가 초과된 이미지에서 대신 오류가 발생합니다. 고급 설정입니다. 기본값: True. | BOOLEAN | 아니요 | true<br />false |

**제약 사항 및 동작:**

* 맵을 하나 이상 활성화해야 하며, 그렇지 않으면 실행이 실패합니다.
* 입력 이미지는 가장 긴 변이 2048픽셀로 제한됩니다. `auto_downscale`로 축소하도록 하거나, 그렇지 않으면 크기가 초과된 이미지에서는 실행이 실패합니다.
* 비활성화된 각 맵도 출력을 반환하지만 1x1 자리 표시자 이미지로 반환되므로, 실제로 생성한 출력만 연결하십시오.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `basecolor` | 생성된 basecolor(알베도) 맵이며, 해당 맵이 비활성화된 경우 1x1 자리 표시자입니다. | IMAGE |
| `normal` | 생성된 노멀 맵이며, 해당 맵이 비활성화된 경우 1x1 자리 표시자입니다. | IMAGE |
| `roughness` | 생성된 러프니스 맵이며, 해당 맵이 비활성화된 경우 1x1 자리 표시자입니다. | IMAGE |
| `metalness` | 생성된 메탈니스 맵이며, 해당 맵이 비활성화된 경우 1x1 자리 표시자입니다. | IMAGE |
| `height` | 생성된 하이트(변위) 맵이며, 해당 맵이 비활성화된 경우 1x1 자리 표시자입니다. | IMAGE |
