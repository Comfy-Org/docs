Wan22ImageToVideoLatent 노드는 이미지에서 비디오 잠재 표현을 생성합니다. 지정된 너비, 높이, 프레임 길이 및 배치 크기로 빈 비디오 잠재 공간을 생성하며, 선택적으로 시작 이미지 시퀀스를 비디오의 시작 프레임에 인코딩할 수 있습니다. 시작 이미지가 제공되면 이 노드는 해당 이미지를 잠재 공간으로 인코딩하고, 생성 중 노이즈 제거가 필요한 영역을 표시하는 노이즈 마스크를 함께 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `VAE` | 시작 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 | - |
| `너비` | 출력 비디오의 픽셀 너비입니다. (기본값: 1280, 단계: 32) | INT | 예 | 32 to MAX_RESOLUTION |
| `높이` | 출력 비디오의 픽셀 높이입니다. (기본값: 704, 단계: 32) | INT | 예 | 32 to MAX_RESOLUTION |
| `길이` | 비디오 시퀀스의 프레임 수입니다. (기본값: 49, 단계: 4) | INT | 예 | 1 to MAX_RESOLUTION |
| `배치 크기` | 생성할 비디오 잠재 수입니다. (기본값: 1) | INT | 예 | 1 ~ 4096 |
| `시작 이미지` | 비디오 잠재의 시작 프레임에 인코딩할 선택적 시작 이미지 시퀀스입니다. (첫 `length` 프레임 사용) | IMAGE | 아니오 | - |

**참고:** `start_image`가 제공되면 이미지 시퀀스는 목표 `width` 및 `height`로 업스케일되고, VAE를 통해 인코딩된 후 잠재의 첫 번째 프레임에 배치됩니다. 해당 프레임의 노이즈 마스크는 0(보존됨)으로 설정되고, 나머지 프레임의 마스크 값은 1(노이즈 제거 대상)입니다. 잠재는 항상 48개의 채널과 `height / 16` × `width / 16`의 공간 차원, 그리고 `((length - 1) // 4) + 1`의 시간적 차원을 가집니다. `width`와 `height`는 16으로 나누어떨어져야 하며(32 단계로 강제됨), `length`는 시간적 차원을 4 단계로 증가시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `samples` | 생성된 비디오 잠재 표현으로, 배치의 각 항목에 대해 반복됩니다. | LATENT |
| `noise_mask` | 노이즈 제거 대상 영역(값 1)과 인코딩된 시작 이미지를 유지할 영역(값 0)을 나타내는 노이즈 마스크입니다. | LATENT |

두 필드는 단일 LATENT 출력 안에 함께 반환됩니다.
