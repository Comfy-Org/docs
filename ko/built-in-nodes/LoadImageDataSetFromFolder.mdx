이 노드는 ComfyUI의 기본 입력 디렉터리 내에서 선택한 하위 폴더로부터 여러 이미지를 불러와 목록으로 반환합니다. 선택한 폴더에서 PNG, JPG, JPEG, WEBP 형식의 이미지 파일을 검사하므로 일괄 처리나 이미지 데이터셋 준비에 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `폴더` | 이미지를 불러올 폴더입니다. 옵션은 ComfyUI 기본 입력 디렉터리에 존재하는 하위 폴더입니다. | COMBO | 예 | 여러 옵션 사용 가능 |

참고: 선택한 폴더는 ComfyUI 기본 입력 디렉터리의 하위 폴더여야 하며, 해당 디렉터리 밖으로 해석되는 값(예: `..`, 절대 경로, 드라이브 문자 또는 심볼릭 링크 사용)은 거부됩니다. 확장자가 .png, .jpg, .jpeg 또는 .webp인 파일만 불러오며, 확장자 검사는 대소문자를 구분하지 않습니다. 불러온 이미지는 RGB로 변환되고 0-1 범위로 조정됩니다. 선택한 폴더에 유효한 이미지 파일이 없으면 노드에서 오류를 발생시킵니다. 이 노드는 실험적으로 표시되어 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `images` | 불러온 이미지의 목록입니다. 노드는 선택한 폴더에서 발견된 모든 유효한 이미지 파일(PNG, JPG, JPEG, WEBP)을 불러옵니다. | IMAGE |
