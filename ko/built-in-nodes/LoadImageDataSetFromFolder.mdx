이 노드는 ComfyUI의 기본 입력 디렉터리 내에서 선택한 하위 폴더에서 여러 이미지를 로드하여 목록으로 반환합니다. 선택한 폴더에서 PNG, JPG, JPEG 또는 WEBP 형식의 이미지 파일을 검색하므로 일괄 처리 또는 이미지 데이터 세트를 준비할 때 유용합니다.

## 입력

| 파라미터 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `폴더` | 이미지를 로드할 폴더입니다. 옵션은 ComfyUI의 기본 입력 디렉터리에 있는 하위 폴더입니다. | COMBO | 예 | 여러 옵션 사용 가능 |

참고: 선택한 폴더는 ComfyUI의 기본 입력 디렉터리의 하위 폴더여야 합니다. 디렉터리 외부로 확인되는 값은 거부됩니다. .png, .jpg, .jpeg 또는 .webp 확장자를 가진 파일만 로드되며, 확장자 확인은 대소문자를 구분하지 않습니다. 선택한 폴더에 유효한 이미지 파일이 없으면 노드에서 오류가 발생합니다. 이 노드는 실험적 기능으로 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `이미지` | 로드된 이미지 목록입니다. 노드는 선택한 폴더에서 찾은 모든 유효한 이미지 파일(PNG, JPG, JPEG, WEBP)을 로드합니다. | IMAGE |
