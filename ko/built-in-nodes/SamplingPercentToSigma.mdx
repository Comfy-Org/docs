선택한 모델의 샘플링 설정을 사용하여 샘플링 백분율을 이에 대응하는 sigma 값으로 변환합니다. 0.0과 1.0 사이의 백분율을 모델의 노이즈 스케줄에 매핑하며, 선택적으로 두 끝점에서 모델의 실제 최대 또는 최소 sigma를 반환할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 변환에 사용되는 샘플링 매개변수를 포함하는 모델 | MODEL | 예 | - |
| `샘플링 백분율` | sigma 값으로 변환할 샘플링 백분율 (기본값: 0.0) | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.0001) |
| `실제 시그마 값 반환` | 구간 검사에 사용되는 값 대신 실제 sigma 값을 반환합니다. 이는 0.0 및 1.0에서의 결과에만 영향을 미칩니다. (기본값: False) | BOOLEAN | 예 | - |

`return_actual_sigma`가 활성화된 경우, `sampling_percent`가 0.0이면 모델의 최대 sigma 값(sigma_max)을 반환하고, `sampling_percent`가 1.0이면 최소 sigma 값(sigma_min)을 반환합니다. 다른 모든 백분율에서는 이 옵션의 활성화 여부와 관계없이 결과가 동일합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `sigma_value` | 입력 샘플링 백분율에 대응하는 sigma 값 | FLOAT |
