CheckpointLoader 노드는 사전 학습된 모델 체크포인트와 해당 구성 파일을 함께 로드합니다. 구성 파일과 체크포인트 파일을 입력으로 받아 로드된 모델 구성 요소(메인 모델, CLIP 모델, VAE 모델)를 반환하여 워크플로우에서 사용할 수 있게 합니다. 이 노드는 더 이상 사용되지 않습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `설정 이름` | 모델 아키텍처와 설정을 정의하는 구성 파일 | COMBO | 예 | 사용 가능한 구성 파일 |
| `체크포인트 파일명` | 학습된 모델 가중치와 매개변수를 포함하는 체크포인트 파일 | COMBO | 예 | 사용 가능한 체크포인트 파일 |

**참고:** 이 노드를 사용하려면 구성 파일과 체크포인트 파일을 모두 선택해야 합니다. 구성 파일은 로드되는 체크포인트 파일의 아키텍처와 일치해야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `MODEL` | 추론에 사용할 수 있도록 로드된 메인 모델 구성 요소 | MODEL |
| `CLIP` | 텍스트 인코딩을 위해 로드된 CLIP 모델 구성 요소 | CLIP |
| `VAE` | 이미지 인코딩 및 디코딩을 위해 로드된 VAE 모델 구성 요소 | VAE |

**중요 참고:** 이 노드는 더 이상 사용되지 않는 것으로 표시되었으며 향후 버전에서 제거될 수 있습니다. 새 워크플로우에서는 대체 로딩 노드를 사용하는 것을 고려하십시오.
