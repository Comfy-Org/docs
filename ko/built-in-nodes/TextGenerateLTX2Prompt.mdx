TextGenerateLTX2Prompt 노드는 짧은 사용자 프롬프트를 LTX-2 시리즈 비디오 모델로 비디오를 생성하기에 적합한 상세한 시청각 설명으로 확장합니다. 이 노드는 작업별 시스템 지침을 자동으로 추가하고, 형식화된 프롬프트를 언어 모델에 전송한 후 향상된 텍스트를 반환합니다. 선택적 참조 이미지가 제공되면 노드는 이미지-투-비디오 모드로 전환하여 해당 이미지의 내용을 기반으로 프롬프트를 확장합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | 텍스트 인코딩에 사용되는 CLIP 모델입니다. 노드는 모델의 토크나이저 이름을 확인하여 일치하는 지침을 선택합니다. Gemma 4 기반 모델은 LTX-2.4 형식을 사용하고, 다른 모델은 LTX-2(Gemma 3) 형식을 사용합니다. | CLIP | 예 |  |
| `프롬프트` | 상세한 비디오 생성 프롬프트로 확장될 장면이나 개념을 설명하는 원시 텍스트 입력입니다. | STRING | 예 |  |
| `최대 길이` | 언어 모델이 생성하도록 허용된 최대 토큰 수입니다. | INT | 예 |  |
| `샘플링 모드` | 텍스트 생성 중 다음 토큰을 선택하는 데 사용되는 샘플링 전략입니다. | COMBO | 예 | `"greedy"`<br />`"top_k"`<br />`"top_p"`<br />`"temperature"` |
| `이미지` | 비디오의 첫 프레임으로 사용되는 선택적 입력 이미지입니다. 제공되면 노드는 이미지-투-비디오 모드로 전환하여 이미지 내용을 기반으로 사용자 프롬프트를 확장하는 시스템 프롬프트를 사용합니다. | IMAGE | 아니요 |  |
| `생각 중` | 활성화하면 모델이 답변 전에 추론하도록 지시됩니다. 추론 블록은 반환된 출력에서 제거됩니다(기본값: False). | BOOLEAN | 아니요 |  |
| `use_default_template` | 활성화하면 노드는 기본 채팅 템플릿을 사용하여 형식화합니다(기본값: True). | BOOLEAN | 아니요 |  |
| `비디오` | 생성에 추가 컨텍스트로 사용할 수 있는 선택적 비디오 입력입니다. | VIDEO | 아니요 |  |
| `오디오` | 생성에 추가 컨텍스트로 사용할 수 있는 선택적 오디오 입력입니다. | AUDIO | 아니요 |  |

**참고:** 노드의 동작은 입력에 따라 달라집니다.

- `image`가 제공되면 생성된 프롬프트는 이미지 내용을 기반으로 프롬프트를 확장하는 방법을 설명하는 시스템 프롬프트를 사용하여 이미지-투-비디오 작업용으로 형식화됩니다. 이미지가 제공되지 않으면 텍스트-투-비디오 작업용으로 형식화되며, 상세한 비디오 생성 설명으로 프롬프트를 확장하는 시스템 프롬프트가 사용됩니다.
- CLIP 토크나이저 이름에 "gemma4"가 포함된 경우, 노드는 LTX-2.4 시스템 프롬프트와 Gemma 4 채팅 형식을 사용합니다. 그 외에는 LTX-2(Gemma 3) 시스템 프롬프트와 채팅 형식을 사용합니다.
- 언어 모델이 추론 블록 제거 후 사용 가능한 텍스트를 생성하지 못하면, 노드는 대신 원래 `prompt`를 반환합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `생성된 텍스트` | 언어 모델이 생성한 향상된 비디오 생성 프롬프트로, 추론 블록이 제거된 결과입니다. 결과가 비어 있으면 원래 사용자 프롬프트가 반환됩니다. | STRING |
