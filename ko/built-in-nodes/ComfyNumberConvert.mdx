Number Convert 노드는 다양한 입력 데이터 타입을 숫자 값으로 변환합니다. 이 노드는 정수, 부동 소수점, 문자열 또는 부울 중 하나의 단일 입력을 받아 부동 소수점 숫자와 정수라는 두 가지 출력을 생성합니다. 이는 워크플로우에서 다른 수학 또는 처리 노드가 사용할 수 있는 형식으로 텍스트나 논리 값을 변환하는 데 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `값` | 숫자 출력으로 변환할 값입니다. 정수, 부동 소수점 숫자, 텍스트 문자열 또는 true/false 부울을 허용합니다. | INT, FLOAT, STRING, BOOLEAN | 예 | 해당 없음 |

**참고:** 입력이 문자열인 경우 비어 있지 않아야 하며 유효한 숫자 표현(예: `"123"`, `"3.14"`)을 포함해야 합니다. 노드는 빈 문자열, 숫자로 구문 분석할 수 없는 텍스트, 또는 (`"inf"`나 `"nan"`과 같은) 유한하지 않은 값에 대해 오류를 발생시킵니다. 부울 입력의 경우 `true`는 1.0(FLOAT)과 1(INT)로 변환되고, `false`는 0.0(FLOAT)과 0(INT)으로 변환됩니다. 부동 소수점 입력 및 소수점 숫자를 포함하는 문자열의 경우 정수 출력은 소수 부분을 잘라내어 얻습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `FLOAT` | 입력 값을 부동 소수점 숫자로 변환한 결과입니다. | FLOAT |
| `INT` | 입력 값을 정수로 변환한 결과입니다. 부동 소수점 입력의 경우 소수 부분을 잘라냅니다. | INT |
