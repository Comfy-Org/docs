이 노드는 ByteDance Seedance 모델을 사용하여 필수 첫 번째 프레임 이미지와 선택적 마지막 프레임 이미지에서 비디오를 생성합니다. 텍스트 프롬프트로 비디오를 설명합니다. 첫 번째 프레임은 비디오의 시작을 안내하고 마지막 프레임은 끝을 안내합니다. Seedance 2.5 및 Seedance 2.0 제품군(Seedance 2.0, Seedance 2.0 Fast 및 Seedance 2.0 Mini)을 지원합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | Seedance 2.5는 최신 모델로 최대 30초 동영상과 mp4/mov 출력을 지원합니다. Seedance 2.0은 최고 품질과 4k를 지원합니다. Fast는 속도 최적화를 위한 모델이고, Mini는 가장 빠르고 저렴한 생성 모델입니다. 모델을 선택하면 아래에 모델별 입력이 표시됩니다. | DYNAMIC_COMBO | 예 | `"Seedance 2.5"`<br />`"Seedance 2.0"`<br />`"Seedance 2.0 Fast"`<br />`"Seedance 2.0 Mini"` |
| `first_frame` | 비디오의 첫 번째 프레임 이미지입니다. | IMAGE | 아니요 | - |
| `last_frame` | 비디오의 마지막 프레임 이미지입니다. | IMAGE | 아니요 | - |
| `first_frame_asset_id` | 첫 번째 프레임으로 사용할 Seedance asset_id입니다. `first_frame` 이미지 입력과 상호 배타적입니다. 기본값은 빈 문자열입니다. | STRING | 아니요 | - |
| `last_frame_asset_id` | 마지막 프레임으로 사용할 Seedance asset_id입니다. `last_frame` 이미지 입력과 상호 배타적입니다. 기본값은 빈 문자열입니다. | STRING | 아니요 | - |
| `seed` | Seed는 노드 재실행 여부를 제어합니다. 시드 값과 관계없이 결과는 비결정적입니다. 기본값은 0입니다. | INT | 예 | 0 ~ 2147483647 |
| `watermark` | 비디오에 워터마크를 추가할지 여부입니다. 기본값은 False입니다. | BOOLEAN | 예 | False<br />True |

### Seedance 2.5 입력

이 입력은 `Seedance 2.5`를 선택할 때 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 말하는 대사를 큰따옴표로 묶어 생성될 대화를 유도하십시오. | STRING | 예 | - |
| `resolution` | 출력 비디오의 해상도입니다. 기본값은 720p입니다. | COMBO | 예 | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `duration` | 출력 비디오의 길이(초, 4-30)입니다. 기본값은 5입니다. | INT | 예 | 4 ~ 30 |
| `generate_audio` | 출력 비디오에 오디오 생성을 활성화합니다. 기본값은 True입니다. | BOOLEAN | 예 | False<br />True |
| `output_format` | 출력 비디오의 컨테이너 형식입니다. 기본값은 mp4입니다. | COMBO | 예 | `"mp4"` |

### Seedance 2.0 입력

이 입력은 `Seedance 2.0`을 선택할 때 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. | STRING | 예 | - |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"480p"`<br />`"720p"`<br />`"1080p"`<br />`"4k"` |
| `ratio` | 출력 비디오의 화면 비율입니다. 기본값은 `adaptive`이며, 입력 프레임의 화면 비율에서 가장 가까운 지원 비율을 사용합니다. | COMBO | 예 | `"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"`<br />`"adaptive"` |
| `duration` | 출력 비디오의 길이(초, 4-15)입니다. 기본값은 7입니다. | INT | 예 | 4 ~ 15 |
| `generate_audio` | 출력 비디오에 오디오 생성을 활성화합니다. 기본값은 True입니다. | BOOLEAN | 예 | False<br />True |

### Seedance 2.0 Fast 및 Seedance 2.0 Mini 입력

`Seedance 2.0 Fast` 및 `Seedance 2.0 Mini`에서 공유됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. | STRING | 예 | - |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"480p"`<br />`"720p"` |
| `ratio` | 출력 비디오의 화면 비율입니다. 기본값은 `adaptive`이며, 입력 프레임의 화면 비율에서 가장 가까운 지원 비율을 사용합니다. | COMBO | 예 | `"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"`<br />`"adaptive"` |
| `duration` | 출력 비디오의 길이(초, 4-15)입니다. 기본값은 7입니다. | INT | 예 | 4 ~ 15 |
| `generate_audio` | 출력 비디오에 오디오 생성을 활성화합니다. 기본값은 True입니다. | BOOLEAN | 예 | False<br />True |

**매개변수 제약 조건**

- 첫 번째 프레임은 `first_frame` 이미지 또는 `first_frame_asset_id` 중 하나로 제공해야 합니다. 둘 다 제공하면 오류가 발생하며, 둘 다 제공하지 않아도 오류가 발생합니다.
- `last_frame` 및 `last_frame_asset_id` 입력은 선택 사항이지만, 동일한 프레임에 대해 둘 다 제공할 수는 없습니다.
- Asset ID는 기존의 활성 Seedance Image 자산을 참조해야 합니다.
- `prompt` 입력은 필수이며 비어 있을 수 없습니다.
- `Seedance 2.5` 사용 시 출력 화면 비율은 항상 적응형이며 첫 번째 프레임의 고유 화면 비율을 따르므로 `ratio` 입력이 표시되지 않습니다.
- Seedance 2.0 제품군 모델과 로컬 프레임 이미지를 사용하는 경우, 생성 전에 이미지가 중앙 크롭된 후 대상 출력 해상도와 비율로 크기가 조정됩니다. `ratio`가 `adaptive`인 경우 입력 이미지에 가장 가까운 지원 비율이 사용됩니다.
- 로컬 프레임 이미지는 지원되는 화면 비율과 크기에 대해 검증되며, 지나치게 큰 이미지는 축소됩니다.
