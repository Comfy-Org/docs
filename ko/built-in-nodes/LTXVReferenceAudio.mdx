LTXV Reference Audio는 참조 오디오 클립에서 화자의 음성 정체성을 생성된 오디오로 전이합니다. 참조 오디오를 컨디셔닝에 인코딩하고, 선택적으로 아이덴티티 가이던스로 모델을 패치합니다. 이는 각 단계마다 참조 없이 추가 순방향 패스를 실행하여 화자 정체성 효과를 증폭합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 아이덴티티 가이던스로 패치될 모델입니다. | MODEL | 예 | - |
| `positive` | 긍정 컨디셔닝 입력입니다. | CONDITIONING | 예 | - |
| `negative` | 부정 컨디셔닝 입력입니다. | CONDITIONING | 예 | - |
| `reference_audio` | 화자 정체성을 전이할 참조 오디오 클립입니다. ~5초를 권장합니다(학습 길이). 더 짧거나 긴 클립은 음성 정체성 전이 품질을 저하시킬 수 있습니다. | AUDIO | 예 | - |
| `audio_vae` | 인코딩용 LTXV Audio VAE입니다. | VAE | 예 | - |
| `identity_guidance_scale` | 아이덴티티 가이던스의 강도입니다. 각 단계마다 참조 없이 추가 순방향 패스를 실행하여 화자 정체성을 증폭합니다. 비활성화하려면 0으로 설정합니다(추가 패스 없음). (기본값: 3.0) | FLOAT | 예 | 0.0 - 100.0 |
| `start_percent` | 아이덴티티 가이던스가 활성화되는 시그마 범위의 시작입니다. (기본값: 0.0) | FLOAT | 예 | 0.0 - 1.0 |
| `end_percent` | 아이덴티티 가이던스가 활성화되는 시그마 범위의 끝입니다. (기본값: 1.0) | FLOAT | 예 | 0.0 - 1.0 |

참고: 아이덴티티 가이던스는 `identity_guidance_scale`이 0보다 크고 현재 샘플링 단계가 `start_percent`와 `end_percent`로 정의된 범위 내에 있을 때만 적용됩니다. 두 값이 다르면 참조 오디오는 오디오 VAE의 샘플 레이트로 리샘플링됩니다.

참고: `start_percent`와 `end_percent`는 고급 매개변수이며, 인터페이스에서 고급 옵션이 활성화된 경우에만 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | 아이덴티티 가이던스 기능으로 패치된 모델입니다. | MODEL |
| `positive` | 이제 인코딩된 참조 오디오 데이터를 포함하는 긍정 컨디셔닝입니다. | CONDITIONING |
| `negative` | 이제 인코딩된 참조 오디오 데이터를 포함하는 부정 컨디셔닝입니다. | CONDITIONING |
