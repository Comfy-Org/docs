Generates videos from text prompts using Google's Veo 3 API. This node supports multiple Veo 3 models, including fast and lite variants, and allows you to specify video resolution, duration, and audio generation.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 비디오에 대한 텍스트 설명 (기본값: "") | STRING | 예 | - |
| `화면비` | 출력 비디오의 화면 비율 (기본값: "16:9") | COMBO | 예 | "16:9"<br />"9:16" |
| `해상도` | 출력 비디오 해상도. veo-3.1-lite 모델에서는 4K를 사용할 수 없습니다. (기본값: "720p") | COMBO | 아니요 | "720p"<br />"1080p"<br />"4k" |
| `네거티브 프롬프트` | 비디오에서 피해야 할 내용을 안내하는 네거티브 텍스트 프롬프트 (기본값: "") | STRING | 아니요 | - |
| `지속시간_초` | 출력 비디오의 길이(초) (기본값: 8) | INT | 아니요 | 4 - 8 (step 2) |
| `프롬프트 향상` | 이 매개변수는 더 이상 사용되지 않으며 무시됩니다. (기본값: True) | BOOLEAN | 아니요 | - |
| `사람 생성` | 비디오에 사람 생성을 허용할지 여부 (기본값: "ALLOW") | COMBO | 아니요 | "ALLOW"<br />"BLOCK" |
| `시드` | 비디오 생성을 위한 시드 (0은 무작위) (기본값: 0) | INT | 아니요 | 0 - 4294967295 |
| `이미지` | 비디오 생성을 안내하는 선택적 참조 이미지 | IMAGE | 아니요 | - |
| `모델` | 비디오 생성에 사용할 Veo 3 모델 (기본값: "veo-3.1-generate") | COMBO | 아니요 | "veo-3.1-generate"<br />"veo-3.1-fast-generate"<br />"veo-3.1-lite" |
| `오디오 생성` | 비디오용 오디오를 생성합니다. 모든 Veo 3 모델에서 지원됩니다. (기본값: False) | BOOLEAN | 아니요 | - |

**참고:** `enhance_prompt` 매개변수는 더 이상 사용되지 않으며 해당 값은 무시됩니다. 노드는 항상 프롬프트를 내부적으로 향상시킵니다. veo-3.1-lite 모델에서 "4k" 해상도를 선택하면 노드에서 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오 파일 | VIDEO |
