이 노드는 HappyHorse 모델을 사용하여 참조 이미지의 인물이나 객체가 등장하는 비디오를 생성합니다. 단일 캐릭터 연기와 다중 캐릭터 상호 작용을 지원합니다. 참조 이미지는 업로드되어 생성된 비디오에서 캐릭터를 표현하는 데 사용됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 생성에 사용할 HappyHorse 참조-비디오(reference-to-video) 모델입니다. | DYNAMIC_COMBO | 예 | `"happyhorse-1.1-r2v"`<br />`"happyhorse-1.0-r2v"` |
| `seed` | 생성에 사용할 시드입니다(기본값: 0). 생성 후 자동으로 변경되도록 설정할 수 있습니다. | INT | 예 | 0 ~ 2147483647 |
| `watermark` | 결과물에 AI 생성 워터마크를 추가할지 여부입니다(기본값: False). | BOOLEAN | 예 | True 또는 False |

### HappyHorse 1.1 입력 (happyhorse-1.1-r2v)

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오를 설명하는 프롬프트입니다. 'character1', 'character2'와 같은 식별자를 사용하여 참조 캐릭터를 지정할 수 있습니다. | STRING | 예 | N/A |
| `resolution` | 생성된 비디오의 해상도입니다. | COMBO | 예 | `"720P"`<br />`"1080P"` |
| `ratio` | 생성된 비디오의 화면 비율입니다. | COMBO | 예 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"`<br />`"21:9"`<br />`"9:21"`<br />`"5:4"`<br />`"4:5"` |
| `duration` | 생성된 비디오의 길이(초)입니다(기본값: 5). | INT | 예 | 3 ~ 15 |

### HappyHorse 1.0 입력 (happyhorse-1.0-r2v)

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오를 설명하는 프롬프트입니다. 'character1', 'character2'와 같은 식별자를 사용하여 참조 캐릭터를 지정할 수 있습니다. | STRING | 예 | N/A |
| `resolution` | 생성된 비디오의 해상도입니다. | COMBO | 예 | `"720P"`<br />`"1080P"` |
| `ratio` | 생성된 비디오의 화면 비율입니다. | COMBO | 예 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 생성된 비디오의 길이(초)입니다(기본값: 5). | INT | 예 | 3 ~ 15 |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 확장 가능한 슬롯: 비디오에 등장시킬 인물이나 객체의 참조 이미지 1~9장을 연결합니다. 참조 이미지를 최소 1장 이상 제공해야 합니다. | IMAGE | 예 | 1 ~ 9(모델당) |

참고: 참조 이미지를 최소 1장 이상 제공해야 하며, 그렇지 않으면 노드에서 오류가 발생합니다. 각 참조 이미지는 최소 400 x 400 픽셀이어야 하며 화면 비율이 1:2.5 ~ 2.5:1 사이여야 합니다. 프롬프트는 비어 있으면 안 됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 생성된 비디오 파일입니다. | VIDEO |
