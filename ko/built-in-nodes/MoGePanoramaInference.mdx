## 개요

이 노드는 등장방형 파노라마 이미지에 대해 깊이 추정을 수행합니다. 파노라마를 12개의 원근 뷰로 분할하고, 각 뷰에 대해 MoGe 깊이 추정 모델을 실행한 후, 뷰별 결과를 병합하여 전체 파노라마를 포괄하는 단일 깊이 맵을 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `moge_model` | 추론에 사용할 MoGe 모델입니다. | MOGE_MODEL | 예 |  |
| `image` | 등장방형 파노라마(모든 종횡비). 이 노드는 단일 이미지만 허용하며, 이미지 배치를 전달하면 오류가 발생합니다. 처음 3개의 색상 채널(RGB)만 사용됩니다. | IMAGE | 예 |  |
| `resolution_level` | 뷰별 디테일 수준 (0 = 가장 빠름, 9 = 가장 상세함) (기본값: 9). | INT | 예 | 0 ~ 9 |
| `split_resolution` | 각 원근 분할의 해상도 (기본값: 512). | INT | 예 | 256 ~ 1024 |
| `merge_resolution` | 병합된 등장방형 거리 맵의 긴 변 해상도 (기본값: 1920). | INT | 예 | 256 ~ 8192 |
| `batch_size` | 추론 배치당 뷰 수 (총 12개 분할) (기본값: 4). | INT | 예 | 1 ~ 12 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `moge_geometry` | 추정된 지오메트리를 포함하는 사전: `points`(3D 포인트 클라우드), `depth`(깊이 맵), `mask`(유효 영역 마스크), `image`(입력 이미지). | MOGE_GEOMETRY |
