Tripo: Image to Model 노드는 Tripo의 image-to-model 서비스를 사용하여 단일 참조 이미지를 3D 모델로 변환합니다. 이미지를 업로드하고, 생성 작업을 제출하고, 작업이 완료될 때까지 기다린 후, 결과 3D 파일을 작업 ID와 함께 반환합니다. 이 노드는 API 노드이므로 유효한 Comfy API 키가 필요합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 3D 모델을 생성하는 데 사용되는 참조 이미지입니다. | IMAGE | 예 | — |
| `model_version` | 생성에 사용할 모델 버전입니다. 설정하지 않으면 노드는 Tripo의 v3.1 (20260211) 버전으로 대체합니다. | COMBO | 아니요 | Tripo 모델 버전 목록 |
| `texture` | 텍스처 맵을 생성합니다. 끄면 텍스처 없는 지오메트리를 반환하고 `pbr`을 무시합니다 (기본값: true). | BOOLEAN | 아니요 | true<br />false |
| `pbr` | PBR 머티리얼 맵(베이스 컬러, 메탈릭, 러프니스, 노멀)입니다. `texture`가 필요합니다 (기본값: true). | BOOLEAN | 아니요 | true<br />false |
| `model_seed` | 지오메트리 생성 단계에 사용되는 시드입니다 (기본값: 42). | INT | 아니요 | 0 ~ 2147483647 |
| `orientation` | 생성된 모델에 적용되는 방향 설정입니다 (기본값: DEFAULT). | COMBO | 아니요 | Tripo 방향 옵션, 기본값 `DEFAULT` |
| `texture_seed` | 텍스처 생성 단계에 사용되는 시드입니다 (기본값: 42). | INT | 아니요 | 0 ~ 2147483647 |
| `texture_quality` | detailed = HD 텍스처, extreme = 8K 울트라 텍스처 (기본값: "standard"). | COMBO | 아니요 | "standard"<br />"detailed"<br />"extreme" |
| `texture_alignment` | 생성된 지오메트리에서 텍스처가 정렬되는 방식입니다 (기본값: "original_image"). | COMBO | 아니요 | "original_image"<br />"geometry" |
| `face_limit` | 최대 면 수입니다. -1은 Tripo가 적응형으로 선택하도록 합니다(v3.x standard에서 약 140만 면, detailed에서 200만 면). Tripo는 별도 알림 없이 제한합니다: v2.5는 500,000, 쿼드 메시는 150,000입니다 (기본값: -1). | INT | 아니요 | -1 ~ 2000000 |
| `quad` | 쿼드 메시 출력입니다. Tripo는 쿼드 메시를 FBX로 전달하므로 결과는 FBX 출력으로 나오고 GLB 출력은 비어 있게 됩니다 (기본값: false). | BOOLEAN | 아니요 | true<br />false |
| `geometry_quality` | 생성된 지오메트리의 품질 수준입니다 (기본값: "standard"). | COMBO | 아니요 | "standard"<br />"detailed" |
| `smart_low_poly` | 깔끔한 수작업 스타일 토폴로지를 가진 로우 폴리 메시입니다(500-20,000면, 쿼드 500-10,000). 단순한 대상에 가장 적합하며, 복잡한 대상은 실패할 수 있습니다 (기본값: false). | BOOLEAN | 아니요 | true<br />false |
| `auto_size` | 텍스처가 있는 모델을 실제 크기(미터)로 조정합니다. Tripo는 크기를 모델의 장면 변환으로 저장하고 모델이 변환, 리깅 또는 리타게팅될 때 이를 베이킹합니다. 텍스처가 없으면 무시됩니다 (기본값: true). | BOOLEAN | 아니요 | true<br />false |

**참고:**

- `image`는 필수입니다. 이미지가 제공되지 않으면 노드에서 오류가 발생합니다.
- `smart_low_poly`가 활성화되고 `face_limit`이 -1이 아닌 값으로 설정된 경우, 제한은 삼각형 메시의 경우 500에서 20,000 사이여야 하며, `quad`가 활성화된 경우 500에서 10,000 사이여야 합니다. 다른 값은 오류를 발생시킵니다.
- `texture`가 비활성화되면 `pbr`은 설정에 관계없이 강제로 꺼지고, `auto_size`는 효과가 없습니다.
- `face_limit`이 -1이면 Tripo에 "no limit"으로 전송되어 서비스가 적응형으로 선택할 수 있습니다.
- 노드가 반환할 수 없는 새로운 3D 파일 형식(GLB 또는 FBX 이외의 형식)은 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model task_id` | 생성 작업의 Tripo 작업 ID입니다. | MODEL_TASK_ID |
| `GLB` | GLB 파일로 생성된 모델입니다. `quad`가 활성화되면 비어 있습니다. | FILE3DGLB |
| `FBX` | FBX 파일로 생성된 모델입니다. `quad`가 활성화된 경우에만 채워집니다. | FILE3DFBX |
