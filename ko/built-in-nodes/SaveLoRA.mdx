SaveLoRA 노드는 LoRA(Low-Rank Adaptation) 모델을 파일로 저장합니다. LoRA 모델을 입력으로 받아 출력 디렉터리에 `.safetensors` 파일로 기록합니다. 최종 파일 이름에 포함할 파일 이름 접두사와 선택적 스텝 수를 지정할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `lora` | 저장할 LoRA 모델입니다. LoRA 레이어가 적용된 모델은 사용하지 마십시오. | LORA_MODEL | 예 | 해당 없음 |
| `prefix` | 저장할 LoRA 파일에 사용할 접두사입니다 (기본값: "loras/ComfyUI_trained_lora"). | STRING | 예 | 해당 없음 |
| `steps` | 선택 사항: LoRA가 학습된 스텝 수로, 저장된 파일 이름을 지정하는 데 사용됩니다. | INT | 아니요 | 해당 없음 |

**참고:** `lora` 입력은 순수 LoRA 모델이어야 합니다. LoRA 레이어가 적용된 기본 모델을 제공하지 마십시오.

**참고:** 파일은 ComfyUI 출력 디렉터리에 `.safetensors` 확장자로 저장됩니다. 파일 이름은 `prefix`와 5자리 숫자(앞자리 0으로 채움) 카운터로 구성되어 기존 파일을 덮어쓰지 않도록 합니다. `steps`가 제공되면 스텝 수가 파일 이름에 포함됩니다(예: 1000스텝의 경우 `1000_steps`).

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| *None* | 이 노드는 워크플로우에 데이터를 출력하지 않습니다. 파일을 디스크에 저장하는 출력 노드입니다. | 해당 없음 |
