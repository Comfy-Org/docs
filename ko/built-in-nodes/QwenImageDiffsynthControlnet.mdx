QwenImageDiffsynthControlnet은 기본 모델에 디퓨전 합성 컨트롤 네트워크 패치를 적용합니다. 입력 이미지와 선택적 마스크를 사용하여 조정 가능한 강도로 모델의 생성 과정을 안내하며, 보다 제어된 이미지 합성을 위해 컨트롤 네트워크의 영향을 반영한 패치 적용 모델을 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 컨트롤 네트워크로 패치할 기본 모델 | MODEL | 예 | - |
| `모델 패치` | 기본 모델에 적용할 컨트롤 네트워크 패치 모델 | MODEL_PATCH | 예 | - |
| `VAE` | 디퓨전 과정에서 사용되는 VAE(변분 오토인코더) | VAE | 예 | - |
| `이미지` | 컨트롤 네트워크를 안내하는 데 사용되는 입력 이미지입니다. 처음 세 개의 색상 채널(RGB)만 사용되며 추가 채널은 모두 버려집니다 | IMAGE | 예 | - |
| `강도` | 컨트롤 네트워크 영향의 강도입니다(기본값: 1.0) | FLOAT | 예 | -10.0 ~ 10.0 (단계 0.01) |
| `마스크` | 컨트롤 네트워크를 적용해야 하는 영역을 정의하는 선택적 마스크입니다. DiffSynth 및 Z-Image 패치의 경우 마스크는 사용 전에 내부적으로 반전됩니다 | MASK | 아니요 | - |
| `start_percent` | 전체 샘플링 단계에 대한 비율로서, 컨트롤 네트워크가 효과를 발휘하기 시작하는 노이즈 제거 과정의 지점입니다(기본값: 0.0) | FLOAT | 아니요 | 0.0 ~ 1.0 (단계 0.001) |
| `end_percent` | 컨트롤 네트워크가 효과 발휘를 중단하는 노이즈 제거 과정의 지점입니다(기본값: 1.0) | FLOAT | 아니요 | 0.0 ~ 1.0 (단계 0.001) |

**참고:** `start_percent` 및 `end_percent` 값은 컨트롤 네트워크를 노이즈 제거 과정의 특정 구간으로 제한합니다. 해당 구간 밖에서는 패치 없이 모델을 샘플링합니다. `strength`가 0으로 설정되면 노드는 변경되지 않은 기본 모델을 반환합니다. 마스크가 제공되면 Z-Image Control 및 표준 DiffSynth 경로에서는 마스크가 반전(1.0 - mask)되고 형상이 재구성되며, Qwen Image 2.1 Fun ControlNet 패치는 마스크를 주어진 그대로 사용합니다. 노드는 로드된 모델 패치에서 내부 패치 구현을 선택하므로, 동일한 입력이라도 Z-Image Control, Qwen Image 2.1 Fun ControlNet 및 표준 DiffSynth 체크포인트에 대해 동작이 약간 다를 수 있습니다. 이 노드는 실험적 기능으로 표시되어 있습니다.
