이 노드는 이전에 디스크에 저장된 인코딩된 학습 데이터셋(latents 및 conditioning)을 불러옵니다. 선택한 datasets 디렉터리의 데이터셋 폴더에서 모든 `shard_*.pkl` 데이터 샤드 파일을 읽고, 학습 워크플로에서 사용할 수 있도록 결합된 잠재 벡터와 conditioning 데이터를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `folder_name` | datasets 디렉터리에서 불러올 저장된 데이터셋입니다. | COMBO | 예 | datasets 디렉터리에서 발견된 각 데이터셋 폴더당 하나의 옵션 |

참고: `folder_name` 옵션은 datasets 디렉터리를 검사하여 자동으로 생성됩니다. 하위 폴더가 `metadata.json` 파일 또는 하나 이상의 `.safetensors` 파일을 포함하면 해당 하위 폴더가 데이터셋으로 나열됩니다(검사는 일치하는 폴더 내부로 내려가지 않습니다). 선택한 데이터셋 폴더는 구성된 모든 데이터셋 루트 디렉터리에서 검색되며, 폴더 이름은 해당 루트 중 하나 내부의 하위 폴더로 확인되어야 합니다. 이 노드는 선택한 폴더에서 `shard_*.pkl` 이름의 모든 파일을 정렬된 순서로 읽으며, 샤드 파일을 찾을 수 없거나 폴더를 찾을 수 없으면 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `latents` | latent 딕셔너리 목록(출력 목록)이며, 각 딕셔너리는 텐서가 포함된 `"samples"` 키를 가집니다. | LATENT |
| `conditioning` | conditioning 목록의 목록(출력 목록)이며, 각 내부 목록은 해당 샘플에 대한 conditioning 데이터를 포함합니다. | CONDITIONING |
