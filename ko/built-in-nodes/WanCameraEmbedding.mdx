이 노드는 선택한 카메라 경로에 대해 Plücker 임베딩을 사용하여 카메라 궤적 임베딩을 생성합니다. 패닝, 줌, 회전과 같은 움직임을 시뮬레이션하는 일련의 카메라 포즈를 구성하고, 이를 비디오 생성 파이프라인에서 사용할 수 있는 임베딩 텐서로 변환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `카메라 포즈` | 시뮬레이션할 카메라 이동 유형 (기본값: "Static") | COMBO | 예 | "Static"<br />"Pan Up"<br />"Pan Down"<br />"Pan Left"<br />"Pan Right"<br />"Zoom In"<br />"Zoom Out"<br />"Anti Clockwise (ACW)"<br />"ClockWise (CW)" |
| `너비` | 출력의 너비(픽셀 단위) (기본값: 832, 단계: 16) | INT | 예 | 16 to MAX_RESOLUTION |
| `높이` | 출력의 높이(픽셀 단위) (기본값: 480, 단계: 16) | INT | 예 | 16 to MAX_RESOLUTION |
| `길이` | 카메라 궤적 시퀀스의 길이 (기본값: 81, 단계: 4) | INT | 예 | 1 to MAX_RESOLUTION |
| `속도` | 카메라 이동 속도 (기본값: 1.0, 단계: 0.1) | FLOAT | 아니요 | 0.0  ~  10.0 |
| `fx` | 초점 거리 x 매개변수 (기본값: 0.5, 단계: 0.000000001) | FLOAT | 아니요 | 0.0  ~  1.0 |
| `fy` | 초점 거리 y 매개변수 (기본값: 0.5, 단계: 0.000000001) | FLOAT | 아니요 | 0.0  ~  1.0 |
| `cx` | 주점 x 좌표 (기본값: 0.5, 단계: 0.01) | FLOAT | 아니요 | 0.0  ~  1.0 |
| `cy` | 주점 y 좌표 (기본값: 0.5, 단계: 0.01) | FLOAT | 아니요 | 0.0  ~  1.0 |

참고: `fx`, `fy`, `cx`, `cy`는 고급 카메라 내부 매개변수입니다. `speed` 매개변수는 선택한 카메라 모션의 회전 각도와 이동 거리에 배율을 적용합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `camera_embedding` | 궤적 시퀀스를 포함하는 생성된 카메라 임베딩 텐서 | TENSOR |
| `width` | 처리에 사용된 너비 값 | INT |
| `height` | 처리에 사용된 높이 값 | INT |
| `length` | 처리에 사용된 길이 값 | INT |
