ModelMergeQwenImage는 두 AI 모델을 병합하고 구성 요소의 가중치를 조정할 수 있게 해줍니다. Qwen 이미지 모델의 특정 부분(트랜스포머 블록, 위치 임베딩, 텍스트 처리 구성 요소)을 혼합할 수 있으며, 각 모델이 병합 결과의 서로 다른 섹션에 얼마나 영향을 미치는지 제어할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델1` | 병합할 첫 번째 모델 | MODEL | 예 | - |
| `모델2` | 병합할 두 번째 모델 | MODEL | 예 | - |
| `pos_embeds.` | 위치 임베딩 혼합 가중치 (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (step: 0.01) |
| `img_in.` | 이미지 입력 처리 혼합 가중치 (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (step: 0.01) |
| `txt_norm.` | 텍스트 정규화 혼합 가중치 (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (step: 0.01) |
| `txt_in.` | 텍스트 입력 처리 혼합 가중치 (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (step: 0.01) |
| `time_text_embed.` | 시간 및 텍스트 임베딩 혼합 가중치 (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (step: 0.01) |
| `transformer_blocks.0.` ~ `transformer_blocks.59.` | 각 트랜스포머 블록의 혼합 가중치 (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (step: 0.01) |
| `proj_out.` | 출력 투영 혼합 가중치 (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (step: 0.01) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | 두 입력 모델의 구성 요소를 지정된 가중치로 결합한 병합 모델 | MODEL |
