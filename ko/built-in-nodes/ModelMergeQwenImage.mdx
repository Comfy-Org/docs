이 노드는 두 Qwen 이미지 모델을 개별 구성 요소를 조정 가능한 가중치로 블렌딩하여 병합합니다. 각 가중치는 두 번째 모델의 해당 부분이 병합 결과에 얼마나 기여하는지를 제어하므로, 위치 임베딩, 텍스트 처리 레이어, 이미지 입력 레이어, 60개 트랜스포머 블록 전체, 출력 프로젝션을 각각 따로 혼합할 수 있습니다. 최종 결과는 일반 모델이 기대되는 곳 어디에서나 사용할 수 있는 단일 MODEL입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델1` | 병합할 첫 번째 모델입니다 | MODEL | 예 | - |
| `모델2` | 병합할 두 번째 모델입니다 | MODEL | 예 | - |
| `pos_embeds.` | 위치 임베딩 블렌딩에 대한 가중치입니다(기본값: 1.0) | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.01) |
| `img_in.` | 이미지 입력 처리 블렌딩에 대한 가중치입니다(기본값: 1.0) | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.01) |
| `txt_norm.` | 텍스트 정규화 블렌딩에 대한 가중치입니다(기본값: 1.0) | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.01) |
| `txt_in.` | 텍스트 입력 처리 블렌딩에 대한 가중치입니다(기본값: 1.0) | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.01) |
| `time_text_embed.` | 시간 및 텍스트 임베딩 블렌딩에 대한 가중치입니다(기본값: 1.0) | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.01) |
| `transformer_blocks.0.` to `transformer_blocks.59.` | 각 트랜스포머 블록 블렌딩에 대한 가중치입니다(기본값: 1.0). 이 노드는 60개 트랜스포머 블록 각각에 대해 하나의 가중치를 노출합니다. | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.01) |
| `proj_out.` | 출력 프로젝션 블렌딩에 대한 가중치입니다(기본값: 1.0) | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.01) |

참고: 모든 가중치 입력은 필수이며 동일한 제한을 공유합니다. 즉, 기본값 1.0에 유효 범위는 0.0에서 1.0까지이며 0.01 단위로 조정할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | 지정된 가중치로 두 입력 모델의 구성 요소를 결합한 병합 모델입니다 | MODEL |
