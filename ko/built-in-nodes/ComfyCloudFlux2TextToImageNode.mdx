Comfy Cloud GPU에서 Flux 2 dev 텍스트-투-이미지 모델을 실행하고 생성된 이미지를 반환합니다. `turbo` 옵션은 약간의 충실도를 희생하는 대신 훨씬 빠르게 실행하기 위해 짧은 스케줄로 Turbo LoRA를 적용합니다. 이 옵션을 끄면 LoRA 없이 전체 길이의 dev 패스를 수행합니다. 이 노드 세트는 베타이며, 실행 시간에 따라 크레딧으로 청구됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성할 이미지를 설명하는 텍스트 프롬프트입니다. 제출 전에 앞뒤 공백이 제거됩니다. | STRING | 예 | 1~4096자 |
| `seed` | 생성 결과를 재현할 수 있도록 제어하는 랜덤 시드입니다(기본값: 42). | INT | 예 | 0~18446744073709551615 |
| `aspect_ratio` | 출력 이미지의 가로세로 비율입니다(기본값: "1:1"). | COMBO | 예 | "1:1"<br />"3:4"<br />"2:3"<br />"3:2"<br />"4:3"<br />"16:9"<br />"9:16"<br />"21:9" |
| `megapixels` | 총 픽셀 예산입니다. 1.0은 정사각형 비율에서 약 1024x1024에 해당합니다(기본값: 1.0). | FLOAT | 예 | 0.1~16.0 (단계 0.1) |
| `turbo` | 짧은 스케줄로 Turbo LoRA를 실행하여 약간의 충실도를 희생하는 대신 훨씬 빠르게 실행합니다. 끄면 LoRA 없이 전체 길이의 dev 패스를 실행합니다(기본값: True). | BOOLEAN | 예 | True / False |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 텍스트 프롬프트에서 생성된 이미지로, 다른 노드로 전달할 수 있는 ComfyUI 이미지 텐서로 반환됩니다. | IMAGE |
