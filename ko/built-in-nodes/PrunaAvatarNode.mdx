인물 사진을 Pruna P-Video-2 Pro Avatar로 말하는 비디오로 변환합니다. 텍스트 음성 변환을 통해 스크립트를 말하게 하거나, 사용자의 오디오를 연결하면 인물이 해당 오디오에 립싱크합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `image` | 비디오가 시작되는 인물 사진입니다. 1:2부터 4:1까지의 종횡비는 유지되며, 1:5와 같이 더 극단적인 이미지는 9:16 또는 16:9로 잘립니다. | IMAGE | 예 | - |
| `speech` | 텍스트 음성 변환 스크립트 또는 사용자 오디오로 비디오를 구동합니다. 옵션을 선택하면 아래에 해당 입력이 표시됩니다. | DYNAMIC_COMBO | 예 | `"script"`<br />`"audio"` |
| `prompt` | 비디오에 표시되는 내용을 설명합니다(기본값: "The person is talking."). 최대 5000자입니다. | STRING | 예 | 최대 5000자 |
| `resolution` | 출력 해상도입니다(기본값: `"768p"`). 1080p, 2k, 4k는 생성된 768p 비디오를 업스케일합니다. | COMBO | 예 | `"480p"`<br />`"768p"`<br />`"1080p"`<br />`"2k"`<br />`"4k"` |
| `enhance_prompt` | 인물 사진에서 보이는 움직임(예: 배경, 조명, 신체 움직임)을 프롬프트에 추가합니다(기본값: True). 고급 설정입니다. | BOOLEAN | 예 | `True`<br />`False` |
| `seed` | 생성용 시드입니다(기본값: 42). 동일한 시드는 `enhance_prompt`가 꺼져 있을 때만 결과를 정확히 재현합니다. | INT | 예 | 0 ~ 2147483647<br />단계: 1 |

### `"script"` 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `speech.script` | 인물이 말할 단어입니다. 비디오 길이는 음성 길이에 맞춰지며, 3분을 초과하는 음성은 3분에서 잘립니다. | STRING | 예 | 임의 텍스트 |
| `speech.voice` | 음성에 사용할 목소리입니다(기본값: `"Zephyr (Female)"`). | COMBO | 예 | 30개 프리셋 음성 |
| `speech.language` | 스크립트를 말할 언어입니다(기본값: `"English (US)"`). | COMBO | 예 | `"English (US)"`<br />`"English (UK)"`<br />`"Spanish"`<br />`"French"`<br />`"German"`<br />`"Italian"`<br />`"Portuguese (Brazil)"`<br />`"Japanese"`<br />`"Korean"`<br />`"Hindi"` |
| `speech.voice_prompt` | 스크립트를 말하는 방식입니다: 어조, 속도, 억양, 감정(기본값: "Say the following."). 이 문구 자체는 음성으로 읽히지 않습니다. | STRING | 예 | 임의 텍스트 |

### `"audio"` 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `speech.audio` | 인물이 립싱크할 음성입니다. 비디오 길이는 해당 음성 길이에 맞춰집니다. | AUDIO | 예 | 최소 1초 |

**참고:**

- 출력 해상도가 높을수록 오디오 길이 제한이 더 엄격해집니다: 2k는 최대 150초, 4k는 최대 60초의 오디오를 허용합니다. 해당 해상도에서 더 긴 오디오를 사용하면 노드가 오류와 함께 중지되므로, 더 낮은 해상도나 더 짧은 클립을 사용하세요.
- 인물 사진의 종횡비가 출력 형태를 고정합니다. 매우 세로로 길거나 매우 가로로 넓은 인물 사진은 여백을 추가하는 대신 잘리므로, 피사체가 가장자리에 걸치지 않게 하세요.
- `enhance_prompt`가 꺼져 있으면 프롬프트가 작성된 그대로 사용되며, 이로 인해 동일한 시드로 결과를 정확히 재현할 수 있습니다.
