이 노드는 동일한 객체의 참조 뷰 1~4개를 사용하여 이전에 생성된 3D 모델에 텍스처를 입힙니다. 원본 모델의 작업 ID와 참조 이미지를 제공하면 노드가 이를 Meshy 서비스로 전송하고 작업이 완료될 때까지 대기한 후 텍스처가 적용된 모델을 GLB 및 FBX 파일로 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 텍스처 작업에 사용되는 AI 모델입니다. 현재는 "meshy-7"만 사용할 수 있습니다. | COMBO | 예 | `"meshy-7"` |
| `meshy_task_id` | 텍스처를 입힐 이전에 생성된 3D 모델의 작업 ID입니다. | MESHY_TASK_ID | 예 | — |
| `multiview_images` | 동일한 객체의 참조 뷰입니다. 첫 번째 이미지가 기본(전면) 뷰이며, 나머지 뷰의 순서는 중요하지 않습니다. 확장 가능한 슬롯: 1~4개의 이미지(`image_1` ~ `image_4`)를 연결할 수 있습니다. | IMAGE | 예 | 이미지 1~4개 |
| `enable_original_uv` | 새 UV를 생성하는 대신 모델의 원본 UV를 사용합니다. 활성화하면 Meshy가 업로드된 모델의 기존 텍스처를 보존합니다. 모델에 원본 UV가 없는 경우 출력 품질이 좋지 않을 수 있습니다. (기본값: True) | BOOLEAN | 아니요 | True / False |
| `pbr` | PBR(물리 기반 렌더링) 텍스처 생성을 활성화합니다. (기본값: False) | BOOLEAN | 아니요 | True / False |
| `texture_resolution` | 기본 색상 텍스처 해상도입니다. 해상도가 높을수록 더 많은 표면 디테일을 포착합니다. | COMBO | 예 | `"2k"`<br />`"4k"`<br />`"8k"` |

**참고:** `multiview_images`에는 1~4개의 이미지가 포함되어야 합니다. 노드는 런타임에 이 값을 검증하며, 개수가 이 범위를 벗어나면 오류를 발생시킵니다. 연결된 이미지에 여러 이미지가 포함된 배치가 있는 경우 배치의 각 이미지가 한도에 포함됩니다. 첫 번째 이미지는 기본(전면) 뷰로 사용되며 나머지 이미지의 순서는 중요하지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model_file` | 모델 파일 이름입니다. 이 출력은 이전 버전과의 호환성을 위해서만 유지됩니다. | STRING |
| `meshy_task_id` | 텍스처 작업의 작업 ID입니다. | MESHY_TASK_ID |
| `GLB` | GLB 형식으로 다운로드된 텍스처가 적용된 3D 모델입니다. | GLB |
| `FBX` | FBX 형식으로 다운로드된 텍스처가 적용된 3D 모델입니다. | FBX |
