TomePatchModel은 추론 중 계산 비용을 줄이기 위해 확산 모델에 Token Merging(ToMe)을 적용합니다. 이는 모델의 어텐션 메커니즘 내부에서 유사한 토큰을 병합하는 방식으로 동작하므로, 모델은 출력 품질을 대부분 유지하면서 더 적은 토큰을 처리합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 토큰 병합을 적용할 확산 모델 | MODEL | 예 | - |
| `비율` | 병합할 토큰의 비율(기본값: 0.3). 값이 높을수록 더 많은 토큰을 병합하므로 더 큰 속도 향상을 얻을 수 있지만 품질이 낮아질 가능성이 있습니다. | FLOAT | 예 | 0.0 - 1.0 |

참고: 어텐션 블록의 토큰 수가 충분히 적어 다운샘플링이 필요하지 않은 경우, 병합 함수는 no-op으로 대체되며 해당 블록에서는 모델이 변경 없이 실행됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | 토큰 병합이 적용된 수정된 모델 | MODEL |
