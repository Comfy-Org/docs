Pruna P-Video-2 Pro Reference to Video를 사용하여 참조 이미지, 비디오 및 오디오의 안내를 받아 프롬프트로부터 비디오를 생성합니다. 프롬프트에서 각 참조를 번호로 언급하면 모델이 해당 피사체, 스타일 또는 동작을 결과에 반영합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 사용할 Pruna 비디오 모델입니다. 모델을 선택하면 아래에 해당 입력이 표시됩니다. | DYNAMIC_COMBO | 예 | `"p-video-2-pro-reference"` |

### P-Video-2 Pro Reference 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model.images` | 참조 이미지용 확장 가능한 슬롯(`image_1`, `image_2`, ...)입니다. 프롬프트에서는 연결 순서에 따라 `@Image1`부터 `@Image9`로 참조합니다. 첫 번째 및 마지막 프레임을 포함하여 최대 9개 이미지입니다. | AUTOGROW | 아니요 | 0~9개 이미지 |
| `model.videos` | 참조 비디오용 확장 가능한 슬롯(`video_1`, `video_2`, ...)입니다. `@Video1`부터 `@Video3`로 참조합니다. 각 비디오는 최대 60fps로 2~15초이며, 총 15초입니다. 1080p를 초과하는 비디오는 다운스케일됩니다. | AUTOGROW | 아니요 | 0~3개 비디오 |
| `model.audios` | 참조 오디오용 확장 가능한 슬롯(`audio_1`, `audio_2`, ...)입니다. `@Audio1`부터 `@Audio3`로 참조합니다. 총 최대 15초입니다. | AUTOGROW | 아니요 | 0~3개 오디오 클립 |
| `model.prompt` | 비디오를 설명합니다. 참조는 `@Image1`, `@Video1` 또는 `@Audio1`로 언급합니다(기본값: 비어 있음). 최대 5000자입니다. | STRING | 예 | 1~5000자 |
| `model.first_frame` | 비디오가 시작되는 이미지입니다. 9개 이미지 제한에 포함됩니다. | IMAGE | 아니요 | - |
| `model.last_frame` | 비디오가 끝나는 이미지입니다. 9개 이미지 제한에 포함됩니다. | IMAGE | 아니요 | - |
| `model.keep_audio` | 연결된 오디오를 사운드트랙으로 사용하고 이에 맞춰 비디오를 생성합니다(기본값: False). 정확히 하나의 오디오가 필요합니다. 오디오가 더 짧으면 생성된 사운드가 뒤따르고, 더 길면 비디오 길이에 맞게 잘립니다. | BOOLEAN | 예 | `True`<br />`False` |
| `model.duration` | 비디오 길이(초)입니다(기본값: `"5"`). | COMBO | 예 | `"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"`<br />`"11"`<br />`"12"`<br />`"13"`<br />`"14"` |
| `model.resolution` | 출력 해상도입니다(기본값: `"768p"`). 1080p, 2k, 4k는 생성된 768p 비디오를 업스케일합니다. | COMBO | 예 | `"480p"`<br />`"768p"`<br />`"1080p"`<br />`"2k"`<br />`"4k"` |
| `model.mode` | `"cost"`는 더 저렴하고, `"speed"`는 더 빠르게 렌더링합니다(기본값: `"speed"`). | COMBO | 예 | `"cost"`<br />`"speed"` |
| `model.aspect_ratio` | 출력 비디오의 화면 비율입니다(기본값: `"16:9"`). `"adaptive"`는 참조들 중 가장 일반적인 비율을 사용하며, `enhance_prompt`가 켜져 있으면 재작성된 프롬프트가 대신 비율을 선택합니다. | COMBO | 예 | `"adaptive"`<br />`"16:9"`<br />`"9:16"`<br />`"4:3"`<br />`"3:4"`<br />`"3:2"`<br />`"2:3"`<br />`"1:1"` |
| `model.enhance_prompt` | 생성 전에 프롬프트를 더 자세하게 재작성합니다. `"max"`는 더 느립니다(기본값: `"turbo"`). 프롬프트에서 참조를 번호로 언급할 때는 켜 두세요. 첫 번째 또는 마지막 프레임이 있으면 항상 `"turbo"`가 사용됩니다. 고급 설정입니다. | COMBO | 예 | `"off"`<br />`"turbo"`<br />`"max"` |
| `model.seed` | 생성용 시드입니다(기본값: 42). 동일한 시드는 `model.enhance_prompt`가 꺼져 있을 때만 결과를 정확히 재현합니다. | INT | 예 | 0~2147483647<br />단계: 1 |

**참고:**

- 최소 하나의 참조 이미지, 비디오, 첫 번째 프레임 또는 마지막 프레임을 연결해야 합니다. 그렇지 않으면 노드가 오류와 함께 중지됩니다.
- 첫 번째 및 마지막 프레임을 포함하여 이미지 9개가 허용되며, 이미지, 프레임, 비디오 및 오디오를 통틀어 총 12개의 참조가 허용됩니다.
- 참조 비디오와 참조 오디오는 각각 총 15초로 제한되며, 각 참조 비디오는 최대 60fps로 2~15초 길이여야 합니다.

| 출력 이름 | 설명 | 데이터 타입 |

| `video` | 생성된 비디오입니다. | VIDEO |
