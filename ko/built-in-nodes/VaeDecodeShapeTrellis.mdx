이 노드는 Trellis2 셰이프 잠재 표현을 3D 메시로 디코딩합니다. VAE를 사용하여 희소 셰이프 잠재 데이터를 메시 지오메트리로 변환하고, 디코딩 과정에서 생성된 셰이프 세분화(subdivision) 데이터도 출력합니다. 이 노드는 단일 및 배치(batch) 잠재 입력을 모두 지원하며, 메시 방향을 예상 좌표 프레임에 맞게 자동으로 조정합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `samples` | 디코딩할 잠재 샘플입니다. 샘플 텐서와 희소 좌표 데이터를 포함합니다. 잠재 딕셔너리에는 선택적 필드로 `coord_counts`(배치 셰이프 처리용), `coord_resolution`(메시 해상도 제어용), `model_frame`(좌표 방향 지정용)이 포함될 수 있습니다. | LATENT | 예 | None |
| `vae` | 셰이프 잠재를 메시로 디코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 | None |

### `samples`에 대한 참고 사항

- `samples` 입력은 잠재 딕셔너리이며, `samples` 텐서와 `coords`(희소 좌표)를 반드시 포함해야 합니다.
- `coord_counts`가 제공되는 경우, 값은 음이 아닌 정수의 1D 텐서여야 하며 모든 값의 합은 좌표 행의 총 개수와 같아야 합니다. 각 값은 배치에서 하나의 셰이프를 나타냅니다.
- `coord_resolution`이 제공되면 메시 해상도는 `coord_resolution * 16`으로 계산됩니다. 제공되지 않으면 VAE에 내장된 해상도 버퍼가 사용됩니다(기본값: 1024).
- `model_frame`이 `"z_up"`으로 설정되면 디코딩된 메시 정점은 Z-up 좌표계에서 glTF에서 사용하는 Y-up 규칙으로 회전됩니다. 기본값은 `"y_up"`입니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `mesh` | 디코딩된 3D 메시로, 정점 위치와 면 인덱스를 포함합니다. 여러 셰이프를 디코딩할 때 모든 메시가 동일한 형태(shape)를 공유하면 단일 스택 텐서로 반환되고, 그렇지 않으면 패킹된 가변 크기 배치로 반환됩니다. | MESH |
| `형상 세분화` | 디코딩 과정의 각 단계에서 생성된 셰이프 세분화 데이터입니다. | SHAPE_SUBDIVIDES |
