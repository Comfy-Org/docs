이 노드는 지정된 평균과 표준 편차를 기준으로 픽셀 값을 조정하여 입력 이미지의 색상을 정규화합니다. 각 픽셀에서 평균을 뺀 다음 표준 편차로 나누며, 이는 다른 처리 전에 이미지 데이터를 표준화하기 위해 흔히 사용되는 단계입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 정규화할 입력 이미지입니다. | IMAGE | 예 | - |
| `평균값` | 정규화를 위한 평균값입니다(기본값: 0.5). | FLOAT | 아니요 | 0.0 - 1.0 |
| `표준편차` | 정규화를 위한 표준 편차입니다(기본값: 0.5). | FLOAT | 아니요 | 0.001 - 1.0 |

`mean` 및 `std` 매개변수는 입력 이미지에 적용되는 정규화를 제어합니다. 두 매개변수의 기본값은 0.5입니다.

참고: 입력 이미지에 알파(투명도) 채널이 있는 경우 해당 채널은 정규화되지 않습니다. 알파는 색상이 아니라 투명도를 저장하므로 변경되지 않은 상태로 출력에 복사됩니다.

참고: 이 노드는 모든 배치 크기에서 작동하므로 여러 이미지를 한 번에 처리할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 정규화 프로세스가 적용된 후의 결과 이미지입니다. 픽셀 값은 지정된 평균과 표준 편차를 사용하여 조정되며, 알파 채널(있는 경우)은 보존됩니다. | IMAGE |
