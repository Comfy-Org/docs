Avatar 6를 사용하는 HeyGen 아바타의 말하는 영상을 생성합니다. Avatar 6를 지원하는 내장 룩 중 하나를 선택하거나 자신의 HeyGen 아바타 ID를 붙여넣은 다음, 텍스트 스크립트 또는 자신의 오디오로 구동합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 모델 선택기입니다. `"heygen-avatar-6-turbo"`는 더 저렴하고 빠른 등급이며, 두 모델 모두 동일한 입력과 해상도를 받습니다. | COMBO | 예 | `"heygen-avatar-6"`<br />`"heygen-avatar-6-turbo"` |
| `avatar` | 표시할 아바타 룩입니다. Avatar 6를 지원하는 19개의 내장 룩이 바로 나열되며, `custom avatar`를 선택하면 HeyGen에서 만든 룩에 사용할 `custom_avatar_id`가 표시됩니다. | DYNAMIC_COMBO | 예 | 19개 내장 룩<br />`custom avatar` |
| `speech` | 텍스트 스크립트(HeyGen 텍스트 음성 변환) 또는 자신의 오디오로 아바타를 구동합니다. 표시 이름: 음성 소스. | DYNAMIC_COMBO | 예 | `"script"`<br />`"audio"` |
| `resolution` | 출력 영상의 해상도입니다. 기본값: `"1080p"`. | COMBO | 예 | `"1080p"`<br />`"2k"` |
| `aspect_ratio` | 출력 영상의 화면 비율입니다. `"auto"`는 아바타 룩의 원본 영상 비율을 따릅니다. 기본값: `"auto"`. | COMBO | 예 | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:5"`<br />`"5:4"` |
| `motion_prompt` | 제스처, 표정, 자세 및 카메라 움직임에 대한 선택적 지시입니다. 기본값: 빈 문자열. | STRING | 예 | 여러 줄 텍스트 |
| `motion_expressiveness` | `"less"`는 더 적고 더 작은 제스처를 생성합니다. 두 설정이 겹치는 부분에서는 모션 프롬프트가 우선합니다. 기본값: `"default"`. | COMBO | 예 | `"less"`<br />`"default"` |
| `seed` | 시드는 노드의 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0 ~ 2147483647 |

### `custom avatar` 입력

이 입력은 `avatar`가 `custom avatar`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `custom_avatar_id` | Avatar 6를 지원하는 HeyGen 아바타 룩 ID입니다(예: HeyGen Create Avatar로 만든 ID). 기본값: 빈 문자열. | STRING | 예 | - |

### `script` 음성 입력

이 입력은 `speech`가 `"script"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `text` | 아바타가 말할 텍스트입니다. 기본값: 빈 문자열. | STRING | 예 | 최대 5000자 |
| `voice` | 스크립트에 사용할 음성입니다. 기본 옵션은 HeyGen이 아바타에 할당한 음성을 사용합니다. HeyGen Create Avatar로 만든 아바타에는 할당된 음성이 없으므로 해당 아바타에는 음성을 선택해야 합니다. | COMBO | 예 | `"(avatar's default voice)"` 및 HeyGen 일반 음성 목록 |
| `custom_voice_id` | 선택적 HeyGen 음성 ID입니다. 설정하면 위에서 선택한 음성을 재정의합니다. 기본값: 빈 문자열. | STRING | 아니요 | - |
| `voice_speed` | 음성 속도 배율입니다. 기본값: 1.0. | FLOAT | 아니요 | 0.5 ~ 1.5 (단계: 0.05) |

### `audio` 음성 입력

이 입력은 `speech`가 `"audio"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 아바타가 말할 음성입니다. 영상 길이는 오디오 길이를 따릅니다. | AUDIO | 예 | 0.5초 ~ 10분 |

**제약 사항 및 동작:**

* `custom avatar`에는 비어 있지 않은 아바타 ID가 필요하며, 그렇지 않으면 노드에서 오류가 발생합니다.
* 스크립트는 5000자로 제한되며, 오디오는 10분으로 제한됩니다.
* 가격은 출력 영상 1초당 과금되며 모델과 해상도에 따라 달라집니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 렌더링이 완료되면 HeyGen에서 다운로드되는 생성된 말하는 영상입니다. | VIDEO |
