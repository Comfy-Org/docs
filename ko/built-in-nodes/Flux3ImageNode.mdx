Flux 3 Image는 프롬프트로 FLUX 3 이미지를 생성하거나 참조 이미지를 편집 및 결합합니다. 원하는 내용을 지침으로 작성한 다음 최대 10개의 참조 이미지를 연결하고, 프롬프트에서 image 1, image 2 등으로 참조하세요. 프롬프트는 생성 전에 해석 및 확장되며, 결과는 선택한 가로세로 비율과 해상도로 렌더링됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성할 내용 또는 수행할 편집입니다. 프롬프트는 생성 전에 해석 및 확장됩니다. 연결된 참조 이미지는 image 1, image 2 등으로 참조하세요. (기본값: "") | STRING | 예 | 1 ~ 15000자 |
| `images` | 참조 이미지용 확장 가능한 슬롯이며, 총 최대 10개까지 연결할 수 있습니다. 각 이미지는 최소 256x256픽셀이어야 하며, 가로세로 비율은 64:1보다 더 극단적일 수 없습니다. | IMAGE | 아니요 | 0 ~ 10개 이미지 |
| `bounding_boxes` | 출력에 개체나 텍스트를 배치하는 Create Bounding Boxes 노드의 선택적 박스입니다. 위치는 캔버스를 기준으로 하므로, 노드에 출력의 가로세로 비율을 제공하세요. | ARRAY | 아니요 | - |
| `aspect_ratio` | 생성된 이미지의 가로세로 비율입니다. "auto"는 첫 번째 참조 이미지를 따르거나 프롬프트에서 비율을 선택합니다. (기본값: "auto") | COMBO | 예 | `"auto"`<br />`"21:9"`<br />`"2:1"`<br />`"16:9"`<br />`"3:2"`<br />`"7:5"`<br />`"4:3"`<br />`"5:4"`<br />`"1:1"`<br />`"4:5"`<br />`"3:4"`<br />`"5:7"`<br />`"2:3"`<br />`"9:16"`<br />`"1:2"`<br />`"9:21"` |
| `resolution` | 선택한 가로세로 비율에서의 출력 크기입니다. 0.75K는 약 0.6메가픽셀, 1K는 1MP, 1.5K는 2.4MP, 2K는 4.2MP, 4K는 16.8MP입니다. (기본값: "2K") | COMBO | 예 | `"0.75K"`<br />`"1K"`<br />`"1.5K"`<br />`"2K"`<br />`"4K"` |
| `grounding` | 생성 전에 모델이 웹 및 이미지 검색으로 프롬프트를 조사하도록 합니다. (기본값: True) | BOOLEAN | 예 | True<br />False |
| `safety_tolerance` | 모더레이션 허용치이며, 0이 가장 엄격합니다. (기본값: 4) | INT | 예 | 0 ~ 4 |
| `seed` | 노드를 다시 실행할지 결정하는 시드입니다. FLUX 3는 자체 시드를 선택하므로 이 값과 관계없이 실제 결과는 비결정적입니다. (기본값: 42) | INT | 예 | 0 ~ 4294967295 |

`safety_tolerance`는 고급 입력이며, `seed`에는 UI의 Control After Generate 컨트롤이 포함됩니다.

참조 이미지는 요청이 전송되기 전에 업로드됩니다. 하나의 슬롯은 배치를 담을 수 있으며, 모든 배치의 모든 프레임이 10개 이미지 제한에 포함됩니다.

`bounding_boxes` 행은 프롬프트에 추가되므로, 프롬프트와 박스 설명을 합쳐 15000자 이하여야 합니다.

표시되는 가격은 `resolution`에 따라 달라집니다: 0.75K에서 $0.05863, 1K에서 $0.06864, 1.5K에서 $0.1001, 2K에서 $0.143, 4K에서 $0.86801입니다.

|-------------|-------------|-----------|
