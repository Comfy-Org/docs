LTXV Generated Keyframes to Guides 노드는 이전 단계에서 생성된 키프레임을 이후 캔버스에 고정된 이미지 가이드로 고정합니다. 키프레임을 독립 실행형 프레임으로 디코딩하고, 필요하면 크기를 조정하며, 다시 노이즈 제거되지 않도록 노이즈 마스크 0으로 기록합니다. 시간적 업스케일 후에는 기록된 인덱스가 생성된 캔버스에서 이 캔버스로 스케일 조정됩니다. 위치를 명시적으로 설정하려면 `override_frame_indices`를 사용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 키프레임 가이드를 추가할 긍정 컨디셔닝입니다. | CONDITIONING | 예 | |
| `negative` | 키프레임 가이드를 추가할 부정 컨디셔닝입니다. | CONDITIONING | 예 | |
| `vae` | 크기 조정이 필요할 때 키프레임을 디코딩하는 데 사용되는 VAE입니다. | VAE | 예 | |
| `latent` | 가이드를 추가할 대상 비디오 레이턴트입니다(예: 시간적으로 업스케일된 레이턴트). | LATENT | 예 | |
| `keyframes` | LTXV Separate Generated Keyframes의 keyframes 출력으로, 각 키프레임이 생성된 픽셀 프레임 인덱스를 포함합니다. | LATENT | 예 | |
| `강도` | 가이드 강도입니다. 1.0은 강한 고정이며, 값이 낮을수록 고정이 완화됩니다. (기본값: 1.0) | FLOAT | 예 | 0.0 - 10.0 (단계: 0.01) |
| `override_frame_indices` | 선택 사항 — 기록된(또는 자동 스케일된) 위치 대신 이 픽셀 프레임에 고정합니다. 키프레임마다 인덱스 하나를 제공합니다. 비워 두면 기록된 위치를 재사용하거나, 대상 캔버스 길이가 다를 때(예: temporal x2 이후) 위치를 스케일 조정합니다. (기본값: "") | STRING | 아니요 | |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 키프레임이 이미지 가이드로 고정된 긍정 컨디셔닝입니다. | CONDITIONING |
| `negative` | 키프레임이 이미지 가이드로 고정된 부정 컨디셔닝입니다. | CONDITIONING |
| `latent` | 키프레임이 고정된 가이드로 추가된 대상 비디오 레이턴트입니다. | LATENT |

## 참고 사항

- `keyframes` 입력은 LTXV Separate Generated Keyframes의 keyframes 출력에 연결해야 합니다. 레이턴트가 생성된 키프레임 위치를 포함하지 않으면 노드에서 오류를 발생시킵니다.
- `positive` 및 `negative` 컨디셔닝 입력은 LTXV Separate Generated Keyframes의 positive 및 negative 출력에서 가져와야 합니다. 긍정 컨디셔닝이 여전히 생성된 키프레임을 포함하면 노드에서 오류를 발생시킵니다.
- `latent` 입력은 일반 비디오 레이턴트(5D 텐서)여야 합니다. 가이드는 Concat AV Latent로 비디오 및 오디오 레이턴트를 병합하기 전에 추가해야 합니다.
- 배치 크기 1만 지원됩니다. 각 가이드는 하나의 이미지에서 인코딩되므로 배치 요소마다 달라질 수 없습니다.
- `keyframes` 레이턴트의 키프레임 수는 기록된 위치 수와 일치해야 하며, 그렇지 않으면 오류가 발생합니다.
- `override_frame_indices`를 비워 두면 기록된 위치가 사용됩니다. 대상 캔버스의 프레임 수가 키프레임이 생성된 캔버스와 다르면 기록된 인덱스가 자동으로 스케일 조정됩니다.
- `override_frame_indices`를 제공하는 경우, 키프레임당 하나의 정수 인덱스를 쉼표 또는 공백으로 구분하여 포함해야 합니다. 인덱스는 고유해야 하며 1과 (대상 레이턴트의 픽셀 프레임 수 - 1) 사이에 있어야 합니다. 그렇지 않으면 오류가 발생합니다.
- 최종 키프레임 인덱스가 대상 레이턴트의 픽셀 프레임 수보다 크거나 같으면 노드에서 오류를 발생시킵니다. 이는 키프레임이 생성된 후 대상이 시간적으로 크기 조정된 경우 발생할 수 있습니다.
- `strength` 매개변수의 최솟값은 0.0이고 최댓값은 10.0입니다.
