Ideogram 4.5 정밀 편집을 사용하여 텍스트 프롬프트의 안내에 따라 이미지를 편집합니다. 프롬프트가 요청한 내용만 변경되고, 건드리지 않은 픽셀은 동일하게 유지되며, 출력은 이미지 1의 크기를 유지합니다. 이미지 1은 편집할 이미지이고 최대 4개의 추가 이미지를 참조로 연결할 수 있습니다. 이미지 1의 단일 영역을 마스크 또는 바운딩 박스로 선택하여 해당 영역만 편집할 수도 있으며, 이 경우 전체 크기의 이미지가 반환됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 사용할 모델입니다. (기본값: `"ideogram-4.5"`) | DYNAMIC_COMBO | 예 | `"ideogram-4.5"` |
| `images` | 확장 가능한 슬롯: 이미지 1은 편집할 이미지이고 이미지 2~5는 선택적 참조입니다(`image_1` ... `image_5`). 프롬프트에서 @Image1, @Image2, ...로 참조하십시오. 일괄 입력은 이미지당 한 번으로 계산됩니다. 각 이미지의 종횡비는 1:6에서 6:1 사이여야 하지만, 컨텍스트 창이 사용 중일 때는 이미지 1의 종횡비를 검사하지 않습니다. | IMAGE | 예 | 이미지 1~5개 |
| `prompt` | 편집 지침입니다. 연결된 이미지에 대한 @Image1 형식 참조를 지원합니다. (기본값: 빈 문자열) | STRING | 예 | 1~10000자 |
| `quality` | 품질 등급입니다. 더 높은 등급은 비용과 시간이 더 많이 듭니다. (기본값: `"medium"`) | COMBO | 예 | `"very_low"`<br />`"low"`<br />`"medium"`<br />`"high"` |
| `seed` | 생성용 시드입니다. 동일한 이미지, 프롬프트, 설정 및 시드는 동일한 결과를 제공합니다. (기본값: 42) | INT | 예 | 0~2147483647 |
| `context_window` | 이미지 1에서 편집할 영역입니다. `"none"`은 전체 이미지를 편집합니다. `"auto"`는 `context_window_mask` 주변 영역을 편집하고 `"custom"`은 `context_window_bboxes`의 영역을 편집합니다. 두 경우 모두 이미지 1을 전체 크기로 유지하고 이미지의 나머지 부분은 변경하지 않습니다. (기본값: `"none"`) | COMBO | 아니요 | `"none"`<br />`"auto"`<br />`"custom"` |
| `context_window_bboxes` | 이미지 1에서 편집할 영역입니다. 예를 들어 Create Bounding Boxes의 출력입니다. `context_window`가 `"custom"`일 때 필요하며, 그렇지 않으면 사용되지 않습니다. 여러 상자는 하나의 영역으로 병합되며, 이 영역은 각 변이 최소 256픽셀이고 종횡비 6:1이 되도록 확장됩니다. 영역은 각 변이 최대 4608픽셀이고 약 4MP(예: 2048x2048)일 수 있습니다. | BOUNDING_BOX | 아니요 | - |
| `context_window_mask` | 흰색은 편집할 부분을 표시하며, 편집 영역은 그 주변에 배치됩니다. `context_window`가 `"auto"`일 때 필요하며, 그렇지 않으면 사용되지 않습니다. 마스크에는 흰색(편집) 영역과 검은색(유지) 영역이 모두 포함되어야 합니다. | MASK | 아니요 | - |

### 매개변수 제약

- **이미지 개수:** 이미지는 최소 1개, 최대 5개입니다. 일괄 입력은 이미지당 한 번으로 계산됩니다. 이미지 1은 편집할 이미지이고 이미지 2~5는 참조입니다. `context_window_mask`를 사용할 때는 최대 4개 이미지, 즉 이미지 1과 참조 3개까지 허용됩니다.
- **출력 크기:** 결과는 이미지 1의 크기를 유지하므로 이 노드에는 크기, 너비 또는 높이 입력이 없습니다. 영역을 편집할 때도 마찬가지이며, 영역만 변경된 전체 이미지가 반환됩니다.
- **이미지 종횡비:** 모든 이미지는 너비가 높이의 6배를 넘지 않고 높이가 너비의 6배를 넘지 않아야 합니다(1:6에서 6:1 사이). `context_window`가 `"auto"` 또는 `"custom"`일 때는 선택된 영역만 전송되므로 이미지 1은 예외입니다.
- **영역 소스 크기:** 컨텍스트 창을 사용할 때 이미지 1은 최대 8192x8192픽셀(약 67MP)일 수 있으며, 더 큰 소스는 오류를 발생시킵니다. 컨텍스트 창을 사용하지 않을 때는 약 4MP 또는 긴 변 4608픽셀을 초과하는 이미지가 전송 전에 축소됩니다.
- **영역 제한:** `context_window_bboxes`의 영역은 각 변이 최대 4608픽셀이고 약 4MP일 수 있습니다. 이미지 1의 바깥에 완전히 있는 상자는 오류를 발생시킵니다.
- **프롬프트 태그:** `@ImageN`은 대소문자를 구분하지 않고 일치하며, 연결된 이미지 수를 초과해서는 안 됩니다. 프롬프트는 공백이 아니어야 하며 최대 10000자여야 합니다.
- **업로드 제한:** 이미지 1, 마스크 및 참조의 총 크기는 Ideogram의 50MB 업로드 제한 이내여야 합니다. 필요할 경우 이미지 1은 JPEG로 다시 인코딩되며, 그래도 맞지 않으면 노드가 오류를 발생시킵니다.
- **콘텐츠 안전:** Ideogram의 콘텐츠 안전 필터가 결과를 차단하면 노드는 이미지를 반환하는 대신 오류를 발생시킵니다.
