프롬프트로 안내된 편집을 사용하여 Ideogram 4.6 또는 4.5 정밀 편집으로 이미지를 편집합니다. 프롬프트가 요청한 부분만 변경되고, 건드리지 않은 픽셀은 동일하게 유지되며, 출력은 이미지 1의 크기를 유지합니다. 이미지 1은 편집할 이미지이며, 최대 4개의 추가 이미지를 참조로 연결할 수 있습니다. 이미지 1의 단일 영역만 마스크 또는 경계 상자로 선택하여 편집할 수도 있으며, 이 경우 이미지는 전체 크기로 반환됩니다.

## 입력

`model`을 선택하면 표시되는 입력이 결정됩니다. 두 모델 모두 `context_window`를 통해 영역을 편집하지만, 4.6은 `mask`에서 마스크를 받고 4.5는 `context_window_mask`에서 받으며, 4.6의 기본값은 `"none"`이 아니라 `"auto"`입니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 사용할 모델입니다. `"ideogram-4.6"`은 더 큰 소스와 더 넓은 영역을 처리하며, `"ideogram-4.5"`는 이전 모델입니다(기본값: `"ideogram-4.6"`). | DYNAMIC_COMBO | 예 | `"ideogram-4.6"`<br />`"ideogram-4.5"` |
| `images` | 확장 가능한 슬롯입니다. 이미지 1은 편집할 이미지이고 이미지 2~5는 선택적 참조입니다(`image_1` ... `image_5`). 프롬프트에서 @Image1, @Image2, ...로 참조하십시오. 배치 입력은 이미지당 한 번으로 계산됩니다. 각 이미지는 1:6에서 6:1 사이의 종횡비를 가져야 하며, 단 컨텍스트 윈도우를 사용하는 동안 이미지 1은 종횡비를 검사하지 않습니다. | IMAGE | 예 | 1~5개 이미지 |
| `prompt` | 편집 지침입니다. 연결된 이미지에 대한 @Image1 형식의 참조를 지원합니다(기본값: 빈 문자열). | STRING | 예 | 1~10000자 |
| `quality` | 품질 등급입니다. 높은 등급일수록 비용과 시간이 더 많이 듭니다(기본값: `"medium"`). | COMBO | 예 | `"very_low"`<br />`"low"`<br />`"medium"`<br />`"high"` |
| `seed` | 생성용 시드입니다. 동일한 이미지, 프롬프트, 설정 및 시드를 사용하면 동일한 결과가 나옵니다(기본값: 42). | INT | 예 | 0~2147483647 |

### Ideogram 4.6 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `context_window` | 편집할 이미지 1의 영역입니다. `"auto"`는 `mask` 주변을 편집하고 이미지 1을 전체 크기로 유지하며, 마스크가 연결되지 않은 경우 전체 이미지를 편집합니다. `"none"`은 마스크가 있어도 전체 이미지를 편집합니다. `"custom"`은 `context_window_bboxes`의 영역을 편집하고 이미지 1을 전체 크기로 유지합니다. 전체 이미지 편집 시 16.7 MP 또는 한 변 8192픽셀을 초과하는 이미지는 먼저 축소됩니다(기본값: `"auto"`). | COMBO | 아니요 | `"none"`<br />`"auto"`<br />`"custom"` |
| `context_window_bboxes` | 편집할 이미지 1의 영역입니다. 예를 들어 Create Bounding Boxes의 출력입니다. `context_window`가 `"custom"`일 때 필요하며, 그 외에는 사용되지 않습니다. 여러 상자는 하나의 영역으로 병합되며, 이 영역은 한 변이 최소 256픽셀이고 종횡비가 6:1이 되도록 확장됩니다. 영역은 한 변 최대 8192픽셀이고 약 16.7 MP(예: 4096x4096)까지 가능합니다. | BOUNDING_BOX | 아니요 | - |
| `mask` | 흰색은 편집할 부분을 표시하며, 편집 영역은 그 주변에 배치됩니다. 마스크에는 흰색(편집) 영역과 검은색(유지) 영역이 모두 포함되어야 합니다. `context_window`가 `"auto"`일 때만 사용됩니다. | MASK | 아니요 | - |

### Ideogram 4.5 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `context_window` | 편집할 이미지 1의 영역입니다. `"none"`은 전체 이미지를 편집합니다. `"auto"`는 `context_window_mask` 주변 영역을 편집하고 `"custom"`은 `context_window_bboxes`의 영역을 편집합니다. 두 옵션 모두 이미지 1을 전체 크기로 유지하고 나머지 이미지는 변경하지 않습니다(기본값: `"none"`). | COMBO | 아니요 | `"none"`<br />`"auto"`<br />`"custom"` |
| `context_window_bboxes` | 편집할 이미지 1의 영역입니다. 예를 들어 Create Bounding Boxes의 출력입니다. `context_window`가 `"custom"`일 때 필요하며, 그 외에는 사용되지 않습니다. 영역은 한 변 최대 4608픽셀이고 약 4 MP(예: 2048x2048)까지 가능합니다. | BOUNDING_BOX | 아니요 | - |
| `context_window_mask` | 흰색은 편집할 부분을 표시하며, 편집 영역은 그 주변에 배치됩니다. `context_window`가 `"auto"`일 때 필요하며, 그 외에는 사용되지 않습니다. 마스크에는 흰색(편집) 영역과 검은색(유지) 영역이 모두 포함되어야 합니다. | MASK | 아니요 | - |

### 매개변수 제약 조건

- **이미지 수:** 최소 1개, 최대 5개 이미지입니다. 배치 입력은 이미지당 한 번으로 계산됩니다. 마스크가 있으면 최대 4개 이미지, 즉 이미지 1과 참조 3개까지 허용됩니다.
- **출력 크기:** 결과는 이미지 1의 크기를 유지하므로, 이 노드에는 size, width 또는 height 입력이 없습니다. 4.6에서는 16.7 MP 또는 한 변 8192픽셀을 초과하는 이미지가 먼저 축소되며, 4.5에서는 약 4 MP 또는 한 변 4608픽셀을 초과할 때 동일하게 처리됩니다.
- **영역 소스 크기:** 컨텍스트 윈도우를 사용하는 경우 이미지 1은 최대 8192x8192픽셀(약 67 MP)까지 가능하며, 더 큰 소스는 오류를 발생시킵니다.
- **영역 제한:** `context_window_bboxes`의 영역은 4.6에서 한 변 최대 8192픽셀 및 약 16.7 MP, 4.5에서 한 변 최대 4608픽셀 및 약 4 MP까지 가능합니다. 이미지 1의 완전히 바깥에 있는 상자는 오류를 발생시킵니다.
- **프롬프트 태그:** `@ImageN`은 대소문자를 구분하지 않고 일치하며, 연결된 이미지 수를 초과해서는 안 됩니다. 프롬프트는 공백이 아니어야 하며 최대 10000자여야 합니다.
- **업로드 제한:** 이미지 1, 마스크 및 참조를 합쳐 Ideogram의 50 MB 업로드 제한 내에 있어야 합니다. 필요 시 이미지 1은 JPEG로 다시 인코딩되며, 그래도 제한 내에 들지 않으면 노드가 오류를 발생시킵니다.
- **콘텐츠 안전:** Ideogram의 콘텐츠 안전 필터가 결과를 차단하면 노드는 이미지를 반환하는 대신 오류를 발생시킵니다.
