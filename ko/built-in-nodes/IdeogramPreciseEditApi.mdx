Ideogram 4.5 정밀 편집을 사용하여 텍스트 프롬프트에 따라 이미지를 편집합니다. 프롬프트가 요청한 부분만 변경되고, 건드리지 않은 픽셀은 동일하게 유지되며, 출력은 이미지 1의 크기를 유지합니다. 이미지 1은 편집할 이미지이며, 최대 4개의 추가 이미지를 참조로 연결할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 사용할 모델입니다. (기본값: `"ideogram-4.5"`) | DYNAMIC_COMBO | 예 | `"ideogram-4.5"` |
| `images` | 확장 가능한 슬롯: 이미지 1은 편집할 이미지이고 이미지 2~5는 선택적 참조입니다(`image_1` ... `image_5`). 프롬프트에서 @Image1, @Image2, ...로 참조하세요. 배치 입력은 이미지당 한 번으로 계산됩니다. 각 이미지의 가로세로 비율은 1:6에서 6:1 사이여야 합니다. | IMAGE | 예 | 이미지 1~5개 |
| `prompt` | 편집 지침입니다. 연결된 이미지에 대한 @Image1 스타일 참조를 지원합니다. (기본값: 빈 문자열) | STRING | 예 | 1~10000자 |
| `quality` | 품질 등급입니다. 등급이 높을수록 비용이 더 들고 시간이 더 오래 걸립니다. (기본값: `"medium"`) | COMBO | 예 | `"very_low"`<br />`"low"`<br />`"medium"`<br />`"high"` |
| `seed` | 생성용 시드입니다. 동일한 이미지, 프롬프트, 설정 및 시드는 동일한 결과를 제공합니다. (기본값: 42) | INT | 예 | 0~2147483647 |

### 매개변수 제약 조건

- **이미지 수:** 이미지는 최소 1개, 최대 5개입니다. 배치 입력은 이미지당 한 번으로 계산됩니다. 이미지 1은 편집할 이미지이고 이미지 2~5는 참조입니다.
- **출력 크기:** 결과는 이미지 1의 크기를 유지하므로, 이 노드에는 크기, 너비 또는 높이 입력이 없습니다.
- **이미지 가로세로 비율:** 모든 이미지는 높이의 6배보다 넓지 않아야 하고, 너비의 6배보다 높지 않아야 합니다(1:6에서 6:1 사이).
- **프롬프트 태그:** `@ImageN`은 대소문자를 구분하지 않고 일치하며, 연결된 이미지 수를 초과해서는 안 됩니다. 프롬프트는 공백이 아니어야 하며 최대 10000자여야 합니다.
- **업로드 크기 조정:** 약 4 MP보다 크거나 긴 변이 4608 px보다 큰 이미지는 전송되기 전에 축소됩니다.
- **콘텐츠 안전:** Ideogram의 콘텐츠 안전 필터가 결과를 차단하면, 노드는 이미지를 반환하는 대신 오류를 발생시킵니다.

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 편집된 이미지를 배치로, 이미지 1의 크기로 제공합니다. | IMAGE |
