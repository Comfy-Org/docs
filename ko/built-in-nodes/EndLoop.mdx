End Loop는 루프 블록의 끝을 표시합니다. 루프 본문의 마지막 노드에서 생성된 값을 수집하고, `accumulate` 설정에 따라 최종 반복만 반환하거나 모든 반복을 반환하며, 동시에 다음 반복이 시작될 수 있도록 Start Loop로 값을 다시 전달합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `출력 값` | End Loop에서 반환되는 값입니다. accumulate에 따라 최종 반복 또는 모든 반복을 반환합니다. | ANY | 아니요 | 모든 값 타입 |
| `다음 반복 값` | 다음 반복을 위해 End Loop에서 Start Loop로 다시 전달되는 값입니다. | ANY | 아니요 | 모든 값 타입 |
| `누적` | 활성화하면 모든 반복에서 output_value를 반환하고, 그렇지 않으면 최종 반복만 반환합니다. | BOOLEAN | 아니요 | `true`<br />`false` (기본값: `false`) |
| `종료 항목` | 모든 반복에서 실행되어야 하는 출력을 연결합니다. 해당 값은 반환되지 않습니다. `termination_1`, `termination_2` 등으로 이름이 지정되는 확장 가능한 슬롯입니다. | ANY | 아니요 | 0~50 슬롯 |

참고: `terminations`는 최소 0개, 최대 50개 연결을 지원하는 확장 가능한 슬롯 목록입니다. 여기에 연결된 값은 모든 반복에서 실행되도록 강제하지만 반환 결과에는 포함되지 않습니다.

참고: 이 노드는 입력 목록 노드이므로, 해당 입력은 모든 루프 반복에서 수집된 값을 받습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `outputs` | 최종 반복의 output_value 또는 accumulate가 활성화된 경우 반복 전반에 걸쳐 누적된 값들입니다. | ANY (list) |
