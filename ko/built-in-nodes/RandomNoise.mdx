RandomNoise 노드는 샘플링 과정에서 사용할 시드 값을 기반으로 노이즈 생성기를 생성합니다. 동일한 시드는 항상 동일한 노이즈 패턴을 생성하므로 여러 실행에서 일관되고 재현 가능한 결과를 얻을 수 있습니다. 샘플러는 잠재 이미지를 처리할 때 생성된 노이즈를 사용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `노이즈 시드` | 랜덤 노이즈 패턴을 생성하는 데 사용되는 시드 값입니다(기본값: 0). 동일한 시드는 항상 동일한 노이즈 출력을 생성합니다. 이 입력에는 각 생성 후 시드를 자동으로 업데이트하는 생성 후 제어(control-after-generate) 옵션이 포함됩니다. | INT | 예 | 0 ~ 18446744073709551615 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `noise` | 제공된 시드 값을 기반으로 잠재 샘플용 랜덤 노이즈를 생성하는 노이즈 객체입니다. 샘플링 과정에서 샘플러에 의해 사용됩니다. | NOISE |
