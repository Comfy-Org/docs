Tripo API를 사용하여 단일 입력 이미지로부터 대상의 정면, 좌측, 후면 및 우측 뷰를 생성합니다. 이미지가 업로드되고, 멀티뷰 생성 작업이 시작되며 완료될 때까지 폴링되고, 작업 ID와 함께 네 개의 결과 뷰가 반환됩니다. 이는 약 0.10 USD로 과금되는 유료 작업입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | Tripo가 정면, 좌측, 후면 및 우측 뷰를 생성하는 데 사용하는 대상의 원본 이미지입니다. 배치가 제공되더라도 요청에는 하나의 이미지만 사용됩니다. | IMAGE | 예 | 단일 이미지 |

참고: 이 노드는 Tripo의 클라우드 API를 호출하고 생성 작업이 끝날 때까지 기다립니다. 일반적인 작업은 약 25초 정도 걸립니다. 인증은 노드의 숨겨진 입력을 통해 자동으로 처리되므로 워크플로에서 Tripo API 키를 제공할 필요가 없습니다. 이 노드는 Tripo 응답의 네 가지 뷰 URL(`front_view_url`, `left_view_url`, `back_view_url`, `right_view_url`)을 모두 필요로 합니다. 뷰가 하나라도 누락되면 실행이 오류와 함께 실패합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `multiview task_id` | 멀티뷰 이미지 생성 요청에 대해 Tripo가 반환한 작업 식별자입니다. 완료된 작업을 참조하는 데 사용할 수 있습니다. 예를 들어 Tripo: Edit Multiview로 뷰를 개선할 때 사용할 수 있습니다. | MULTIVIEW_TASK_ID |
| `front` | 생성된 대상의 정면 뷰입니다. | IMAGE |
| `left` | 생성된 대상의 좌측 뷰입니다. | IMAGE |
| `back` | 생성된 대상의 후면 뷰입니다. | IMAGE |
| `right` | 생성된 대상의 우측 뷰입니다. | IMAGE |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/TripoImageToMultiviewNode/ko.md)
