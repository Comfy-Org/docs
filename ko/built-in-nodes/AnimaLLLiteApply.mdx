AnimaLLLiteApply는 확산 모델에 경량 애니메이션 패치를 적용하여 강도와 시점을 조절할 수 있는 이미지-투-이미지 생성을 가능하게 합니다. 사전 구성된 모델 패치를 입력 이미지 및 선택적 마스크와 통합하여 모델의 어텐션(attention) 및 MLP 레이어를 수정함으로써 생성 과정에 영향을 줍니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 패치를 적용할 기본 확산 모델 | MODEL | 예 | |
| `model_patch` | 적용할 사전 구성된 애니메이션 패치 | MODEL_PATCH | 예 | |
| `image` | 생성 과정을 안내할 참조 이미지. 처음 3개 색상 채널(RGB)만 사용됩니다 | IMAGE | 예 | |
| `강도` | 패치 효과의 강도 (기본값: 1.0) | FLOAT | 예 | -10.0 ~ 10.0 |
| `시작 비율` | 패치가 효과를 나타내기 시작하는 노이즈 제거 과정의 백분율 (기본값: 0.0) | FLOAT | 예 | 0.0 ~ 1.0 |
| `종료 비율` | 패치가 효과를 멈추는 노이즈 제거 과정의 백분율 (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 |
| `mask` | 패치 효과를 이미지의 특정 영역으로 제한하는 선택적 마스크 | MASK | 아니요 | |

**매개변수 제약 사항 참고:** `model_patch`에 4개의 입력 채널이 있고 `mask`가 제공되지 않으면 이미지 크기에 맞는 0 마스크가 자동으로 생성됩니다. `model_patch`에 4개의 입력 채널이 없으면 `mask` 매개변수는 무시되고 `None`으로 설정됩니다. 이 노드는 ComfyUI에서 실험적(experimental)으로 표시되어 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `MODEL` | 애니메이션 패치가 적용된 확산 모델 | MODEL |
