입력 오디오를 ComfyUI 출력 디렉토리에 저장합니다. 이 노드는 구성 가능한 품질 설정과 함께 FLAC, MP3, Opus를 포함한 다양한 형식으로 오디오를 내보낼 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 저장할 오디오입니다. | AUDIO | 예 | - |
| `filename_prefix` | 저장할 파일의 접두사입니다. %date:yyyy-MM-dd%와 같은 형식 토큰을 포함할 수 있습니다. (기본값: "audio/ComfyUI") | STRING | 예 | - |
| `format` | 오디오를 저장할 파일 형식입니다. | DYNAMIC_COMBO | 예 | "flac"<br />"mp3"<br />"opus" |

### MP3 입력

형식으로 "mp3"를 선택하면 다음 설정을 사용할 수 있습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `quality` | 출력 MP3 파일의 인코딩 품질입니다. (기본값: "V0") | COMBO | 아니오 | "V0"<br />"128k"<br />"320k" |

### Opus 입력

형식으로 "opus"를 선택하면 다음 설정을 사용할 수 있습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `quality` | 출력 Opus 파일의 인코딩 품질입니다. (기본값: "128k") | COMBO | 아니오 | "64k"<br />"96k"<br />"128k"<br />"192k"<br />"320k" |

참고: `quality` 설정은 해당 형식이 선택된 경우에만 사용할 수 있습니다. "flac"을 선택하면 추가 품질 설정을 사용할 수 없습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `audio` | 입력 오디오로, 저장 후 변경 없이 그대로 반환됩니다. | AUDIO |

또한 이 노드는 저장된 오디오 파일 정보가 포함된 UI 정보를 반환합니다.
