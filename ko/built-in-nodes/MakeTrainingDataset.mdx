이 노드는 이미지와 텍스트를 인코딩하여 학습용 데이터를 준비합니다. 이미지 목록과 이에 대응하는 텍스트 캡션 목록을 입력받은 다음, VAE 모델을 사용해 이미지를 latent 표현으로 변환하고 CLIP 모델을 사용해 텍스트를 컨디셔닝 데이터로 변환합니다. 생성된 짝을 이룬 latent와 conditioning은 목록으로 출력되어 학습 워크플로에서 사용할 준비가 됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `이미지` | 인코딩할 이미지 목록입니다. | IMAGE | 예 | N/A |
| `vae` | 이미지를 latent로 인코딩하기 위한 VAE 모델입니다. | VAE | 예 | N/A |
| `clip` | 텍스트를 conditioning으로 인코딩하기 위한 CLIP 모델입니다. | CLIP | 예 | N/A |
| `텍스트` | 텍스트 캡션 목록입니다. 길이는 n(이미지와 일치), 1(모든 이미지에 반복), 또는 생략(빈 문자열 사용)일 수 있습니다. | STRING | 아니요 | 0, 1 또는 n개 항목(n = 이미지 개수) |

**매개변수 제약 사항:**

* 이 노드는 목록 입력을 사용합니다: `images`와 `texts`는 목록으로 처리되는 반면, `vae`와 `clip`은 각각 단일 모델을 받습니다(제공된 목록의 첫 번째 항목이 사용됩니다).
* `texts` 목록의 항목 수는 0, 1이거나 `images` 목록의 항목 수와 정확히 일치해야 합니다. 0이거나 생략된 경우 모든 이미지에 빈 문자열이 사용됩니다. 1인 경우 해당 단일 텍스트가 모든 이미지에 반복됩니다. 그 외의 길이는 오류를 발생시킵니다.
* 출력 `latents` 및 `conditioning` 목록은 항상 `images` 목록과 동일한 수의 항목을 포함하므로, 각 latent는 해당 캡션에 대한 conditioning과 짝을 이룹니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `latents` | latent 딕셔너리 목록입니다. | LATENT |
| `conditioning` | 컨디셔닝 목록의 목록입니다. | CONDITIONING |
