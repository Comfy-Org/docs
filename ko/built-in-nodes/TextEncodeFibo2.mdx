Fibo 2.0 프롬프트를 컨디셔닝과 그에 맞는 빈 잠재로 인코딩합니다. 프롬프트는 일반 텍스트이거나 구조화된 JSON 캡션입니다. 이미지가 연결되면 프롬프트는 편집 지침이 되거나, `edit_instruction` 키가 있는 결과의 JSON 캡션이 됩니다. VAE가 연결되어 있으면 이미지는 두 출력 모두에 대한 참조 잠재로 작동합니다. `latent` 출력을 샘플링하세요. 이 출력의 크기는 이미지가 크롭되는 크기입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | 프롬프트를 토큰화하고 인코딩하는 데 사용되는 Fibo 2.0 텍스트 인코더입니다. | CLIP | 예 | - |
| `prompt` | 생성의 기준이 되는 캡션 또는 이미지가 연결된 경우 편집 지침입니다. 이미지는 `<image_1>`, `<image_2>` 등으로 지칭합니다. 예상 결과의 JSON 캡션도 사용할 수 있으며, 변경 사항은 해당 캡션의 `edit_instruction` 키에 설명합니다. | STRING | 예 | - |
| `negative_prompt` | 멀어지도록 유도할 캡션으로, 네거티브 컨디셔닝으로 인코딩됩니다. 비어 있지 않은 값은 캡션처럼 정리되지 않고 그대로 Fibo 2.0의 채팅 템플릿에 넣어 전송됩니다. 비워 두면 편집 워크플로에서 classifier-free guidance를 위해 Fibo 2.0이 학습한 null 캡션이 됩니다(기본값: 비어 있음). | STRING | 예 | - |
| `vae` | 이미지를 참조 잠재로 인코딩하는 데 사용되는 VAE입니다. 이것이 없으면 이미지는 텍스트 인코딩에만 조건을 부여합니다. | VAE | 아니요 | - |
| `images` | 편집할 이미지로, 최대 16개입니다. 이미지가 하나이면 편집이 픽셀 단위로 정렬되므로 해당 이미지를 결과 크기에 맞게 크기 조정하고 중앙 크롭합니다. 이미지가 여러 개이면 각 이미지를 자체 학습 크기로 조정합니다. | IMAGE | 아니요 | 0 ~ 16개 이미지 |
| `width` | 결과의 너비로, 16의 배수로 내림합니다. 0이면 첫 번째 이미지의 종횡비에 대해 Fibo 2.0이 학습된 크기(약 1메가픽셀)를 사용하거나, 이미지가 없으면 1024를 사용합니다(기본값: 0). | INT | 예 | 0  ~  16384 (단계: 16) |
| `height` | 결과의 높이로, 16의 배수로 내림합니다. 0이면 첫 번째 이미지의 종횡비에 대해 Fibo 2.0이 학습된 크기(약 1메가픽셀)를 사용하거나, 이미지가 없으면 1024를 사용합니다(기본값: 0). | INT | 예 | 0  ~  16384 (단계: 16) |
| `batch_size` | 배치에서 생성할 잠재의 수입니다(기본값: 1). | INT | 예 | 1  ~  4096 |

참조 잠재는 두 출력 모두에 연결되므로, 이미지는 positive 브랜치에만이 아니라 컨디셔닝과 함께 전달됩니다. VAE가 연결되지 않은 경우 이미지는 텍스트 인코더에만 보이며 참조 잠재는 추가되지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `positive` | 프롬프트의 컨디셔닝으로, VAE와 이미지가 연결된 경우 참조 잠재를 포함합니다. | CONDITIONING |
| `negative` | `negative_prompt`의 컨디셔닝으로, 텍스트만 포함하며 동일한 참조 잠재를 함께 가집니다. | CONDITIONING |
| `latent` | 요청한 크기의 빈 잠재로, 샘플링할 준비가 되어 있습니다. | LATENT |
