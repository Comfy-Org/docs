호환되는 두 MiniMax H3 모델을 구성 요소별로 병합하며, 아키텍처의 각 부분에 대해 별도의 비율을 사용합니다. 각 비율은 `model1`의 비중이므로, 한 모델의 패치 프로젝션과 리파인먼트 블록은 유지하면서 트랜스포머 블록은 다른 모델의 것으로 교체할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model1` | 첫 번째 MiniMax H3 모델입니다. 모든 구성 요소는 이 모델에서 시작되며, 각 비율은 해당 구성 요소를 대신 `model2`에서 얼마나 가져올지 결정합니다. | MODEL | 예 | - |
| `model2` | 블렌딩에 사용할 구성 요소를 제공하는 두 번째 MiniMax H3 모델입니다. | MODEL | 예 | - |
| `video_patch_proj.` | 비디오 패치 프로젝션에 대한 `model1`의 비율입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `audio_patch_proj.` | 오디오 패치 프로젝션에 대한 `model1`의 비율입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `condition_proj.` | 컨디셔닝 프로젝션에 대한 `model1`의 비율입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `time_embedder.` | 시간 임베더에 대한 `model1`의 비율입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `token_refiner.blocks.0.` | 첫 번째 토큰 리파이너 블록에 대한 `model1`의 비율입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `token_refiner.blocks.1.` | 두 번째 토큰 리파이너 블록에 대한 `model1`의 비율입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `token_refiner.final_norm.` | 토큰 리파이너 최종 정규화에 대한 `model1`의 비율입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `blocks.0.` ~ `blocks.49.` | 50개 트랜스포머 블록 각각에 대한 `model1`의 비율이며, 블록마다 위젯이 하나씩 있습니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `final_layer.norm.` | 최종 레이어 정규화에 대한 `model1`의 비율입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `final_layer.adaln_proj.` | 최종 적응형 정규화 프로젝션에 대한 `model1`의 비율입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `final_layer.video_out.` | 비디오 출력 레이어에 대한 `model1`의 비율입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `final_layer.audio_out.` | 오디오 출력 레이어에 대한 `model1`의 비율입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |

비율 1.0(기본값)은 해당 구성 요소를 전적으로 `model1`에서 유지하고, 0.0은 전적으로 `model2`에서 가져옵니다. 그 중간 값은 두 모델을 블렌딩합니다. 정규화 통계처럼 비율이 적용되지 않는 텐서는 항상 `model1`에서 가져옵니다. 두 입력 모두 동일한 아키텍처의 MiniMax H3 모델이어야 하며, 그렇지 않으면 병합 결과가 실행되지 않는 모델이 됩니다.

|-------------|-------------|-----------|
| `MODEL` | 병합된 MiniMax H3 모델입니다. | MODEL |
