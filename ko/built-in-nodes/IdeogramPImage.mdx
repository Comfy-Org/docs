Ideogram 및 Pruna P-Image는 Ideogram의 빠른 텍스트-이미지 모델을 사용하여 텍스트 프롬프트에서 이미지를 생성합니다. 이 모델은 뛰어난 타이포그래피와 사실적 이미지 생성으로 잘 알려져 있습니다. 또한 Ideogram 4.0 구조화 JSON 캡션을 지원하여 텍스트 문자열, 색상, 레이아웃을 정확하게 제어할 수 있습니다. 이 노드는 생성된 이미지와 함께 이미지가 실제로 생성된 최종 프롬프트를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 텍스트 프롬프트. Ideogram 4.0 구조화 JSON 캡션(#RRGGBB 형식의 정확한 색상, 정확한 텍스트 문자열, 경계 상자 레이아웃)도 허용합니다. 이 캡션을 그대로 사용하려면 `prompt_upsampling`을 OFF로 설정하세요. 비어 있어서는 안 됩니다. (기본값: "") | STRING | 예 | 비어 있지 않은 모든 텍스트 |
| `품질` | 속도/가격/품질 등급입니다. MEDIUM은 일상적인 기본값이며, HIGH는 복잡한 프롬프트, 미세한 디테일, 어려운 텍스트에 적합합니다. VERY_LOW/LOW는 대규모 초안용입니다. MEDIUM 미만에서는 어려운 텍스트의 품질이 낮게 렌더링됩니다. (기본값: "MEDIUM") | COMBO | 예 | "VERY_LOW"<br />"LOW"<br />"MEDIUM"<br />"HIGH" |
| `해상도` | 출력 크기 등급입니다(정확한 픽셀 수는 종횡비에 따라 결정됩니다. 예: 16:9에서 1K는 1280x720, 2K는 2560x1440). 선명한 타이포그래피를 원한다면 HIGH + 2K를 권장합니다. (기본값: "1K") | COMBO | 예 | "1K"<br />"2K" |
| `종횡비` | 이미지 생성에 사용할 종횡비입니다. (기본값: "1:1") | COMBO | 예 | "1:3"<br />"3:1"<br />"1:2"<br />"2:1"<br />"9:16"<br />"16:9"<br />"10:16"<br />"16:10"<br />"2:3"<br />"3:2"<br />"3:4"<br />"4:3"<br />"4:5"<br />"5:4"<br />"1:1" |
| `프롬프트 업샘플링` | 생성 전에 짧은 프롬프트를 상세한 구조화 캡션으로 확장합니다(재작성된 프롬프트는 `final_prompt`로 반환됩니다). 자체 JSON 캡션이나 정확한 문구를 제공하는 경우 OFF로 설정하세요. (기본값: "AUTO") | COMBO | 예 | "AUTO"<br />"ON"<br />"OFF" |
| `시드` | 재현 가능한 생성을 위한 시드입니다. `prompt_upsampling`이 OFF면 동일한 시드와 설정으로 동일한 이미지가 반환됩니다. ON/AUTO에서는 프롬프트 재작성이 실행마다 달라지므로, 결과를 재현하려면 해당 `final_prompt` 출력을 재사용하면서 `prompt_upsampling`을 OFF로 설정하고 동일한 시드를 사용하세요. (기본값: 42) | INT | 아니요 | 0 ~ 2147483647 |

**제약 조건 참고:** 프롬프트에는 공백이 아닌 문자가 하나 이상 포함되어야 하며, 그렇지 않으면 노드가 실패합니다. 자체 구조화 JSON 캡션이나 정확한 문구를 제공하는 경우 `prompt_upsampling`을 OFF로 설정하세요. `prompt_upsampling`이 ON 또는 AUTO인 경우 생성 전에 프롬프트가 다시 작성되므로 동일한 시드를 사용해도 동일한 이미지가 재현되지 않을 수 있습니다. 이미지를 재현하려면 해당 `final_prompt` 출력을 `prompt_upsampling` OFF 및 동일한 시드와 함께 재사용하세요.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 생성된 이미지(들)를 이미지 배치로 반환합니다. Ideogram의 콘텐츠 안전 필터가 생성을 차단하면 대신 오류가 발생합니다. | IMAGE |
| `final_prompt` | 이미지가 실제로 생성된 프롬프트입니다(`prompt_upsampling`이 실행된 경우 재작성된 구조화 캡션이고, 그렇지 않은 경우 사용자의 프롬프트입니다). 이 값을 `prompt_upsampling` OFF 및 동일한 시드와 함께 다시 입력하면 동일한 이미지를 재현할 수 있습니다. | STRING |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/IdeogramPImage/ko.md)
