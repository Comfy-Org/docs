Ideogram & Pruna P-Image는 뛰어난 타이포그래피와 사실적인 사진 표현으로 알려진 Ideogram의 빠른 텍스트-이미지 모델을 사용하여 텍스트 프롬프트로부터 이미지를 생성합니다. 또한 텍스트 문자열, 색상, 레이아웃을 정확하게 제어할 수 있도록 Ideogram 4.0 구조화된 JSON 캡션을 지원합니다. 이 노드는 생성된 이미지와 함께 이미지가 실제로 생성된 최종 프롬프트를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 텍스트 프롬프트입니다. 또한 Ideogram 4.0 구조화된 JSON 캡션(#RRGGBB 16진수 형식의 정확한 색상, 정확한 텍스트 문자열, 바운딩 박스 레이아웃)을 받을 수 있습니다 — 이를 그대로 사용하려면 prompt_upsampling을 OFF로 설정하세요. 비어 있으면 안 됩니다. (기본값: "") | STRING | 예 | 비어 있지 않은 임의의 텍스트 |
| `품질` | 속도/가격/품질 등급입니다. MEDIUM은 일상적인 기본값이고, HIGH는 복잡한 프롬프트, 미세한 디테일, 어려운 텍스트에 사용합니다. VERY_LOW/LOW는 대량 초안용입니다. 어려운 텍스트는 MEDIUM 미만에서 잘 렌더링되지 않습니다. (기본값: "MEDIUM") | COMBO | 예 | "VERY_LOW"<br />"LOW"<br />"MEDIUM"<br />"HIGH" |
| `해상도` | 출력 크기 등급입니다(정확한 픽셀은 종횡비를 따릅니다. 예를 들어 16:9는 1K에서 1280x720, 2K에서 2560x1440을 제공합니다). 선명한 타이포그래피를 위해서는 HIGH + 2K를 권장합니다. (기본값: "1K") | COMBO | 예 | "1K"<br />"2K" |
| `종횡비` | 이미지 생성에 사용할 종횡비입니다. (기본값: "1:1") | COMBO | 예 | "1:3"<br />"3:1"<br />"1:2"<br />"2:1"<br />"9:16"<br />"16:9"<br />"10:16"<br />"16:10"<br />"2:3"<br />"3:2"<br />"3:4"<br />"4:3"<br />"4:5"<br />"5:4"<br />"1:1" |
| `프롬프트 업샘플링` | 생성 전에 짧은 프롬프트를 상세한 구조화된 캡션으로 확장합니다(재작성된 프롬프트는 final_prompt로 반환됩니다). 직접 JSON 캡션 또는 정확한 문구를 제공할 때는 OFF로 설정하세요. (기본값: "AUTO") | COMBO | 예 | "AUTO"<br />"ON"<br />"OFF" |
| `시드` | 재현 가능한 생성을 위한 시드입니다. prompt_upsampling이 OFF이면 동일한 시드와 설정으로 동일한 이미지가 반환됩니다. ON/AUTO이면 프롬프트 재작성이 실행마다 달라집니다 — 결과를 재현하려면 해당 final_prompt 출력을 prompt_upsampling OFF 및 동일한 시드와 함께 다시 사용하세요. (기본값: 42) | INT | 아니요 | 0 ~ 2147483647 |

**제약 사항:** 프롬프트에는 공백이 아닌 문자가 하나 이상 포함되어야 하며, 그렇지 않으면 노드가 실패합니다. 직접 구조화된 JSON 캡션 또는 정확한 문구를 제공할 때는 `prompt_upsampling`을 OFF로 설정하세요. `prompt_upsampling`이 ON 또는 AUTO이면 생성 전에 프롬프트가 재작성되므로 동일한 시드로 동일한 이미지가 재현되지 않을 수 있습니다. 이미지를 재현하려면 해당 `final_prompt` 출력을 `prompt_upsampling` OFF 및 동일한 시드와 함께 다시 사용하세요.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 생성된 이미지가 이미지 배치로 반환됩니다. Ideogram의 콘텐츠 안전 필터가 생성을 차단하면 대신 오류가 발생합니다. | IMAGE |
| `final_prompt` | 이미지가 실제로 생성된 프롬프트입니다(prompt_upsampling이 실행된 경우 재작성된 구조화된 캡션, 그렇지 않으면 사용자의 프롬프트). 이 이미지를 재현하려면 prompt_upsampling OFF 및 동일한 시드와 함께 이 출력을 다시 입력하세요. | STRING |
