Bria Increase Resolution은 Bria의 이미지 업스케일링 서비스를 사용하여 입력 이미지를 2배 또는 4배로 업스케일하며, 원본 콘텐츠를 보존합니다. 이미지를 업로드하여 Bria 서비스에서 처리한 후, 업스케일된 결과를 이미지로 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 업스케일할 입력 이미지입니다. | IMAGE | 예 | Single image |
| `desired_increase` | 해상도 배율입니다. 출력 이미지의 각 변은 8192픽셀 이내여야 합니다. | COMBO | 예 | "2"<br />"4" |
| `auto_downscale` | 출력 이미지가 제한을 초과할 경우 배율을 자동으로 낮추고, 그래도 부족하면 입력 이미지를 다운스케일합니다. (기본값: False) | BOOLEAN | 예 | True<br />False |
| `콘텐츠 검토` | 모더레이션 설정입니다. "true"로 설정하면 `visual_input_moderation` 및 `visual_output_moderation` 하위 옵션이 활성화되며, 두 옵션 모두 기본값은 False입니다. | DYNAMIC_COMBO | 예 | "false"<br />"true" |

참고:
- `moderation`을 "true"로 설정하면 하위 옵션인 `visual_input_moderation`과 `visual_output_moderation`을 사용할 수 있으며, 두 옵션 모두 기본값은 False입니다. 이 옵션들은 입력 이미지와 출력 이미지 콘텐츠의 모더레이션을 제어합니다.
- 이 노드는 출력 이미지의 최대 변 길이를 8192픽셀로 제한합니다. 선택한 배율이 이 제한을 초과하고 `auto_downscale`이 비활성화된 경우 오류가 발생합니다. `auto_downscale`을 활성화하면 노드가 더 낮은 배율을 자동으로 사용하거나 입력 이미지를 대신 다운스케일합니다.
- Bria는 업스케일링 전에 입력 이미지의 짧은 변을 먼저 최소 224픽셀로 확대합니다. 너무 길쭉한 이미지의 경우 더 정사각형에 가까운 형태로 잘라 달라는 오류가 발생할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | Bria API가 반환한 업스케일된 이미지입니다. | IMAGE |
