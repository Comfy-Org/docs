Reve Image Edit 노드는 자연어 텍스트 지시에 따라 기존 이미지를 수정합니다. 입력 이미지와 지시 사항을 Reve API로 전송하며, API는 요청된 편집이 적용된 새 이미지를 반환합니다.

## 입력

`model` 선택기는 표시할 모델별 입력을 결정합니다. `upscale` 선택기는 업스케일 배율 입력 사용 가능 여부를 제어합니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 편집할 이미지입니다. | IMAGE | 예 | - |
| `편집 지시` | 이미지를 편집하는 방법에 대한 텍스트 설명입니다. 최대 2560자입니다. | STRING | 예 | - |
| `모델` | 편집에 사용할 모델 버전입니다. | DYNAMIC_COMBO | 예 | `"reve-edit@20250915"`<br />`"reve-edit-fast@20251030"` |
| `업스케일` | 생성된 이미지를 업스케일합니다. 추가 비용이 발생할 수 있습니다. (기본값: "disabled") | DYNAMIC_COMBO | 아니요 | `"disabled"`<br />`"enabled"` |
| `배경 제거` | 생성된 이미지에서 배경을 제거합니다. 추가 비용이 발생할 수 있습니다. (기본값: False) | BOOLEAN | 아니요 | `true`<br />`false` |
| `시드` | 시드는 노드 재실행 여부를 제어합니다. 결과는 시드 값과 관계없이 비결정적입니다. (기본값: 0) | INT | 아니요 | 0 ~ 2147483647 |

### 모델 입력 (`reve-edit@20250915` 및 `reve-edit-fast@20251030` 공통)

두 모델 버전 모두 동일한 모델별 입력을 제공합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `종횡비` | 출력 이미지의 가로세로 비율입니다. "auto"로 설정하면 가로세로 비율이 자동으로 결정됩니다. | COMBO | 아니요 | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"3:2"`<br />`"2:3"`<br />`"4:3"`<br />`"3:4"`<br />`"1:1"` |
| `테스트 타임 스케일링` | 고급 옵션입니다. 값이 높을수록 더 나은 이미지를 생성하지만 더 많은 크레딧을 소비합니다. (기본값: 1) | INT | 아니요 | 1 ~ 5 |

### 업스케일 입력 (`upscale`이 "enabled"로 설정된 경우)

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `upscale.upscale_factor` | 업스케일 배율(2x, 3x 또는 4x)입니다. (기본값: 2) | INT | 아니요 | 2 ~ 4 |

**참고:**

- `upscale.upscale_factor`는 `upscale`이 "enabled"로 설정된 경우에만 적용됩니다. 업스케일과 배경 제거는 함께 또는 개별적으로 활성화할 수 있습니다.
- `edit_instruction`은 비어 있으면 안 되며 2560자를 초과할 수 없습니다.
- `model.aspect_ratio`가 "auto"로 설정되면 API에 고정 가로세로 비율이 전송되지 않으며 가로세로 비율이 자동으로 선택됩니다.
- `model.test_time_scaling`은 값이 1보다 큰 경우에만 API로 전송됩니다. 기본값 1은 API의 기본 동작을 유지합니다.
- 시드 값과 관계없이 결과는 비결정적입니다. 시드는 노드 재실행 여부만 제어합니다.
- 이 노드는 더 이상 사용되지 않는(deprecated) 것으로 표시됩니다.
- 대략적인 비용(노드의 가격 배지 기준, USD): `$0.01001` (`reve-edit-fast@20251030`); `$0.0572` (`reve-edit@20250915`, 업스케일 없음); `$0.0686` (2배 업스케일), `$0.0819` (3배 업스케일), `$0.0991` (4배 업스케일).
