Kling Text to Video 노드는 Kling 비디오 생성 API를 사용하여 텍스트 설명으로부터 비디오를 생성합니다. 이 노드는 프롬프트와 설정(종횡비, 생성 모드, CFG 스케일)을 API로 전송하고, 생성 작업이 완료될 때까지 기다린 후 결과 비디오를 해당 ID 및 길이와 함께 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 긍정 텍스트 프롬프트 | STRING | 예 | 최대 2500자 |
| `부정 프롬프트` | 부정 텍스트 프롬프트 | STRING | 아니요 | 최대 2500자 |
| `cfg 스케일` | 비디오가 프롬프트를 얼마나 밀접하게 따르는지 제어하는 구성 스케일 값입니다. (기본값: 1.0) | FLOAT | 아니요 | 0.0 ~ 1.0 |
| `종횡비` | 비디오 종횡비 설정입니다. (기본값: "16:9") | COMBO | 아니요 | "16:9"<br />"9:16"<br />"1:1" |
| `모드` | 다음 형식에 따라 비디오 생성에 사용할 구성입니다: mode / duration / model_name (기본값: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | 아니요 | "pro mode / 5s duration / kling-v2-5-turbo"<br />"pro mode / 10s duration / kling-v2-5-turbo" |

참고: `prompt` 매개변수는 필수이며 비어 있어서는 안 됩니다. `prompt`와 `negative_prompt`는 모두 최대 2500자로 제한됩니다. 10초 `mode` 옵션은 5초 옵션보다 비용이 더 많이 듭니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오 출력 | VIDEO |
| `video_id` | 생성된 비디오의 고유 식별자 | STRING |
| `duration` | 생성된 비디오의 길이 정보 | STRING |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/KlingTextToVideoNode/ko.md)
