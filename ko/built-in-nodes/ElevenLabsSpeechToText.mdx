ElevenLabs Speech to Text 노드는 ElevenLabs API를 사용하여 오디오를 텍스트로 전사합니다. 자동 언어 감지, 화자 분리(다른 화자 식별), 오디오 이벤트 태깅(대본에서 웃음이나 음악과 같은 소리 주석 달기)을 지원합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 전사에 사용할 모델입니다. 이 모델을 선택하면 추가 매개변수가 표시됩니다. | DYNAMIC_COMBO | 예 | `"scribe_v2"` |
| `audio` | 전사할 오디오입니다. | AUDIO | 예 | - |
| `language_code` | ISO-639-1 또는 ISO-639-3 언어 코드(예: 'en', 'es', 'fra')입니다. 자동 감지를 위해 비워 두십시오. (기본값: "") | STRING | 아니요 | - |
| `num_speakers` | 예측할 최대 화자 수입니다. 자동 감지를 위해 0으로 설정하십시오. (기본값: 0) | INT | 아니요 | 0 - 32 |
| `seed` | 재현성을 위한 시드입니다(결정성은 보장되지 않습니다). (기본값: 1) | INT | 아니요 | 0 - 2147483647 |

### Scribe v2 입력

이 매개변수는 `"scribe_v2"` 모델을 선택할 때 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `tag_audio_events` | 대본에서 (웃음), (음악) 등과 같은 소리에 주석을 답니다. (기본값: False) | BOOLEAN | 아니요 | - |
| `diarize` | 어떤 화자가 말하고 있는지 주석을 답니다. (기본값: False) | BOOLEAN | 아니요 | - |
| `diarization_threshold` | 화자 분리 민감도입니다. 값이 낮을수록 화자 변경에 더 민감합니다. `diarize`가 활성화된 경우에만 사용됩니다. (기본값: 0.22) | FLOAT | 아니요 | 0.1 - 0.4 |
| `temperature` | 무작위성 제어입니다. 0.0은 모델 기본값을 사용합니다. 값이 높을수록 무작위성이 증가합니다. (기본값: 0.0) | FLOAT | 아니요 | 0.0 - 2.0 |
| `timestamps_granularity` | 대본 단어의 시간 정밀도입니다. (기본값: "word") | COMBO | 아니요 | `"word"`<br />`"character"`<br />`"none"` |

**참고:** `diarize`가 활성화된 경우 `num_speakers`를 0보다 큰 값으로 설정할 수 없습니다. `diarize`를 비활성화하거나 `num_speakers`를 0으로 설정해야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `text` | 오디오에서 전사된 텍스트입니다. | STRING |
| `language_code` | 오디오에서 감지된 언어 코드입니다. | STRING |
| `words_json` | 타임스탬프와 활성화된 경우 화자 레이블을 포함한 상세한 단어 수준 정보가 포함된 JSON 형식 문자열입니다. | STRING |
