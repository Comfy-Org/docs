LoopResult는 루프 블록의 종료 지점을 표시하는 개발자 전용 출력 노드입니다. 전달된 값을 순서대로 수집하며(이름은 `output0`, `output1` 등) close ID로 식별되는 외부 실행 블록을 해제합니다. 입력 핑거프린팅이 항상 NaN을 반환하므로, 이 노드는 항상 변경된 것으로 간주되어 실행할 때마다 다시 실행됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `종료 ID` | 닫을 루프 블록의 식별자입니다. 목록의 첫 번째 값만 사용됩니다. | STRING | 예 | - |
| `output0`, `output1`, ... | 루프 블록에서 수집된 값입니다. 이 노드는 추가 입력을 모두 허용하며 `output0`부터 시작하여 순차적으로 수집하고, 처음 누락된 인덱스에서 중지합니다. | 모든 타입 | 아니요 | - |

참고: 이 노드는 모든 입력을 허용합니다(`accept_all_inputs`). `close_id` 이외의 모든 입력은 수집된 루프 값으로 처리되며, 결과에 포함되려면 `output0`, `output1`, `output2` 등과 같이 빈틈없이 이름이 지정되어야 합니다.

## 출력

이 노드는 출력을 반환하지 않습니다. `close_id`와 연결된 외부 실행 블록만 해제합니다.
