Pixal3D Multi-View Conditioning 노드는 고정 궤도 카메라 리그로부터 컨디셔닝 데이터를 구성합니다. 즉, 전면, 왼쪽, 후면, 오른쪽 뷰가 90도 간격으로 배치되며, 프레이밍된 그대로 사용됩니다. 객체의 정사각형 뷰를 하나 이상 연결하면 Pixal3D 모델에 맞는 positive 및 negative 컨디셔닝을 준비합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip_vision_model` | 번들로 제공되는 NAF 가중치가 포함된 DINOv3 ViT-L/16 ClipVision입니다. | CLIP_VISION | 예 | N/A |
| `fov` | 프레이밍된 뷰의 수평 FOV(도)입니다. 리그 렌더 및 대부분의 다시점 생성기에는 20을 사용하고, 사진의 경우 뷰 중 하나에 MoGeGeometryToFOV를 적용한 값을 사용합니다. 기본값: 20.0. | FLOAT | 예 | 1.0 - 170.0 |
| `전면` | 객체의 전면을 담은 정사각형 뷰입니다. 알파 채널이 있거나 검은 배경 위에 있어야 하며, 리그처럼 프레이밍되어야 합니다. 객체는 가장 넓은 부분이 프레임의 약 1/1.1을 차지하고, 모든 뷰에서 동일한 스케일이어야 합니다. 처음 연결된 뷰(전면, 왼쪽, 후면, 오른쪽 순서)가 메시의 포즈가 맞춰지는 전면입니다. | IMAGE | 아니요 | N/A |
| `왼쪽` | 객체의 왼쪽을 담은 정사각형 뷰입니다. 알파 채널이 있거나 검은 배경 위에 있어야 하며, 리그처럼 프레이밍되어야 합니다. 객체는 가장 넓은 부분이 프레임의 약 1/1.1을 차지하고, 모든 뷰에서 동일한 스케일이어야 합니다. 처음 연결된 뷰(전면, 왼쪽, 후면, 오른쪽 순서)가 메시의 포즈가 맞춰지는 전면입니다. | IMAGE | 아니요 | N/A |
| `후면` | 객체의 후면을 담은 정사각형 뷰입니다. 알파 채널이 있거나 검은 배경 위에 있어야 하며, 리그처럼 프레이밍되어야 합니다. 객체는 가장 넓은 부분이 프레임의 약 1/1.1을 차지하고, 모든 뷰에서 동일한 스케일이어야 합니다. 처음 연결된 뷰(전면, 왼쪽, 후면, 오른쪽 순서)가 메시의 포즈가 맞춰지는 전면입니다. | IMAGE | 아니요 | N/A |
| `오른쪽` | 객체의 오른쪽을 담은 정사각형 뷰입니다. 알파 채널이 있거나 검은 배경 위에 있어야 하며, 리그처럼 프레이밍되어야 합니다. 객체는 가장 넓은 부분이 프레임의 약 1/1.1을 차지하고, 모든 뷰에서 동일한 스케일이어야 합니다. 처음 연결된 뷰(전면, 왼쪽, 후면, 오른쪽 순서)가 메시의 포즈가 맞춰지는 전면입니다. | IMAGE | 아니요 | N/A |

### 참고 사항

- 뷰를 하나 이상 연결해야 합니다. 네 개의 뷰 입력이 모두 비어 있으면 노드에서 오류가 발생합니다.
- 전면, 왼쪽, 후면, 오른쪽 순서에서 처음 연결된 뷰가 전면으로 처리되며, 메시는 해당 뷰를 기준으로 포즈가 설정됩니다. 처음 연결된 뷰가 `front`가 아니면 해당 뷰를 전면으로 하여 메시 포즈가 설정된다는 경고가 기록됩니다.
- 뷰는 전면, 왼쪽, 후면, 오른쪽 순서로 읽히며, 처음 연결된 뷰를 기준으로 고정된 방위각에 궤도 상에 배치됩니다.
- 알파 채널이 있는 입력 뷰는 알파가 검은색 위에 적용됩니다. 1024 x 1024가 아닌 뷰는 1024 x 1024로 크기가 조정됩니다.
- 배치 크기는 처음 연결된 뷰에서 가져옵니다. 연결된 뷰의 배치 크기가 다르면 더 작은 뷰가 일치하도록 순환됩니다.
