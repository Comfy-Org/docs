The ModelSamplingFlux 노드는 이미지 크기에 기반한 시프트 매개변수를 계산하여 주어진 모델에 Flux 모델 샘플링을 적용합니다. 지정된 너비, 높이 및 시프트 매개변수에 따라 모델의 동작을 조정하는 특수 샘플링 구성을 생성한 다음, 새 샘플링 설정이 적용된 수정된 모델을 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | Flux 샘플링을 적용할 모델입니다. | MODEL | 예 | - |
| `최대 시프트` | 샘플링 계산을 위한 최대 시프트 값입니다 (기본값: 1.15). | FLOAT | 예 | 0.0 - 100.0 (step 0.01) |
| `기본 시프트` | 샘플링 계산을 위한 기본 시프트 값입니다 (기본값: 0.5). | FLOAT | 예 | 0.0 - 100.0 (step 0.01) |
| `너비` | 대상 이미지의 너비(픽셀)입니다 (기본값: 1024). | INT | 예 | 16 - MAX_RESOLUTION (step 8) |
| `높이` | 대상 이미지의 높이(픽셀)입니다 (기본값: 1024). | INT | 예 | 16 - MAX_RESOLUTION (step 8) |

`max_shift`와 `base_shift`는 고급 매개변수입니다. 샘플링 구성에 적용되는 시프트는 이미지 크기에서 계산됩니다. 잠재 해상도는 `width × height / 256`로 계산되며, 시프트 값은 잠재 해상도 256에서의 `base_shift`와 잠재 해상도 4096에서의 `max_shift` 사이에서 보간됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | Flux 샘플링 구성이 적용된 수정된 모델입니다. | MODEL |
