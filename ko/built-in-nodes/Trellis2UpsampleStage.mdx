이 노드는 512 해상도의 shape latent를 고해상도 희소 좌표로 업스케일하고, 대상 해상도에서 두 번째 shape-stage 샘플링 패스를 준비합니다. 생성 중 모델이 사용할 수 있도록 컨디셔닝에 스테이지별 메타데이터를 첨부합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 업샘플링 스테이지 shape 메타데이터가 첨부되는 positive 컨디셔닝입니다. | CONDITIONING | 예 | |
| `negative` | 업샘플링 스테이지 shape 메타데이터가 첨부되는 negative 컨디셔닝입니다. | CONDITIONING | 예 | |
| `shape_latent` | 첫 번째 shape-stage KSampler에서 출력된 512 해상도의 shape latent입니다. | LATENT | 예 | |
| `vae` | shape latent를 고해상도 희소 좌표로 디코딩하는 데 사용되는 Trellis2 VAE입니다. | VAE | 예 | |
| `target_resolution` | 업샘플링된 shape의 복셀 해상도입니다. 높을수록 더 많은 디테일과 더 많은 VRAM을 사용합니다. 기본값: 1024. | INT | 예 | 1024 - 2048 (단계: 128) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 업샘플링 스테이지 shape 메타데이터가 첨부된 positive 컨디셔닝입니다. | CONDITIONING |
| `negative` | 업샘플링 스테이지 shape 메타데이터가 첨부된 negative 컨디셔닝입니다. | CONDITIONING |
| `latent` | 대상 해상도에서 두 번째 shape-stage 샘플링 패스를 위해 준비된 0으로 채워진 latent로, 업샘플링된 좌표, 샘플별 좌표 수, 좌표 해상도 메타데이터를 포함합니다. | LATENT |
