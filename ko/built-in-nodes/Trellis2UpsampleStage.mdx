이 노드는 첫 번째 셰이프 단계 샘플링 패스에서 생성된 512 해상도 셰이프 잠상을 가져와 더 높은 대상 해상도로 업스케일하고, 두 번째 셰이프 단계 샘플링 패스에 필요한 컨디셔닝과 잠상을 준비합니다. 또한 단계별 메타데이터를 컨디셔닝에 첨부하여 모델이 생성 중에 이를 사용할 수 있도록 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 업스케일링 단계 셰이프 메타데이터가 첨부되는 포지티브 컨디셔닝입니다. | CONDITIONING | 예 | |
| `negative` | 업스케일링 단계 셰이프 메타데이터가 첨부되는 네거티브 컨디셔닝입니다. | CONDITIONING | 예 | |
| `shape_latent` | 첫 번째 셰이프 단계 KSampler에서 출력된 512 해상도 셰이프 잠상입니다. | LATENT | 예 | |
| `vae` | 셰이프 잠상을 고해상도 희소 좌표로 디코딩하는 데 사용되는 Trellis2 VAE입니다. | VAE | 예 | |
| `target_resolution` | 업스케일된 셰이프의 복셀 해상도입니다. 값이 높을수록 더 많은 디테일과 더 많은 VRAM을 사용합니다. 기본값: 1024. | INT | 예 | 1024 - 2048 (단계 128) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 업스케일링 단계 셰이프 메타데이터가 첨부된 포지티브 컨디셔닝입니다. | CONDITIONING |
| `negative` | 업스케일링 단계 셰이프 메타데이터가 첨부된 네거티브 컨디셔닝입니다. | CONDITIONING |
| `latent` | 대상 해상도에서 두 번째 셰이프 단계 샘플링 패스를 위해 준비된 0으로 채워진 잠상으로, 업스케일된 좌표와 해상도 메타데이터를 포함합니다. | LATENT |
