WanCameraImageToVideo 노드는 이미지에서 비디오를 생성하기 위한 conditioning 및 latent 데이터를 준비합니다. 이 노드는 positive 및 negative conditioning 프롬프트와 선택적 시작 이미지, 선택적 카메라 컨트롤을 입력받아 수정된 conditioning과 비디오 모델이 채울 수 있는 빈 latent 텐서를 출력합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `긍정 프롬프트` | 비디오 생성을 위한 긍정적 컨디셔닝 프롬프트입니다. | CONDITIONING | 예 | - |
| `부정 프롬프트` | 비디오 생성 시 피해야 할 부정적 컨디셔닝 프롬프트입니다. | CONDITIONING | 예 | - |
| `VAE` | 이미지를 잠재 공간으로 인코딩하는 VAE 모델입니다. | VAE | 예 | - |
| `너비` | 출력 비디오의 가로 해상도(픽셀)입니다 (기본값: 832, 증가 단위: 16). | INT | 예 | 16 to MAX_RESOLUTION |
| `높이` | 출력 비디오의 세로 해상도(픽셀)입니다 (기본값: 480, 증가 단위: 16). | INT | 예 | 16 to MAX_RESOLUTION |
| `길이` | 비디오 시퀀스의 프레임 수입니다 (기본값: 81, 증가 단위: 4). | INT | 예 | 1 to MAX_RESOLUTION |
| `배치 크기` | 동시에 생성할 비디오 수입니다 (기본값: 1). | INT | 예 | 1 ~ 4096 |
| `CLIP 비전 출력` | 추가 컨디셔닝을 위한 선택적 CLIP vision 출력입니다. | CLIP_VISION_OUTPUT | 아니요 | - |
| `시작 이미지` | 비디오 시퀀스를 초기화하는 선택적 시작 이미지입니다. 제공되면 비디오의 첫 프레임들이 이 이미지를 기반으로 하며, 시작 프레임과 생성된 콘텐츠를 혼합하기 위한 마스크가 적용됩니다. 이미지는 지정된 width 및 height에 맞게 크기가 조정됩니다. | IMAGE | 아니요 | - |
| `카메라 조건` | 비디오 생성을 위한 선택적 카메라 임베딩 조건입니다. 제공되면 이 조건은 positive 및 negative conditioning 모두에 적용됩니다. | WAN_CAMERA_EMBEDDING | 아니요 | - |

**참고:** `start_image`가 제공되면 입력 이미지의 처음 `length` 프레임만 비디오 시퀀스 초기화에 사용되며, 노드는 이 시작 프레임들을 생성된 콘텐츠와 혼합하기 위한 마스크를 적용합니다. `camera_conditions` 및 `clip_vision_output` 매개변수는 선택 사항이지만, 제공되면 positive 및 negative 프롬프트 모두에 대한 컨디셔닝을 수정합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `긍정 프롬프트` | 카메라 조건, clip vision 출력 및/또는 시작 이미지 데이터가 적용된 수정된 positive conditioning입니다. | CONDITIONING |
| `부정 프롬프트` | 카메라 조건, clip vision 출력 및/또는 시작 이미지 데이터가 적용된 수정된 negative conditioning입니다. | CONDITIONING |
| `잠재 공간` | 비디오 모델과 함께 사용하기 위해 생성된 빈 비디오 latent 표현입니다. latent 텐서의 차원은 [batch_size, 16, frames, height/8, width/8]이며, 여기서 frames는 ((length - 1) // 4) + 1로 계산됩니다. | LATENT |
