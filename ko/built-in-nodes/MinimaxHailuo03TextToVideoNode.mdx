이 노드는 MiniMax H3 모델 제품군(MiniMax H3, MiniMax H3 Max, MiniMax H3 Max Turbo)을 사용하여 텍스트 프롬프트에서 비디오를 생성합니다. 모델을 선택하고 텍스트 프롬프트를 입력한 다음 해상도, 화면 비율, 재생 시간 등의 설정을 조정합니다. 노드는 MiniMax API로 요청을 전송하고, 생성 작업이 완료될 때까지 대기한 후 결과 비디오를 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용할 모델입니다(기본값: "MiniMax H3"). 모델을 선택하면 아래 섹션에 설명된 모델별 설정도 표시됩니다. | DYNAMIC_COMBO | 예 | "MiniMax H3"<br />"MiniMax H3 Max"<br />"MiniMax H3 Max Turbo" |
| `seed` | 난수 시드입니다. 동일한 시드를 사용한 동일한 요청은 유사한 결과를 제공하지만 완전히 동일한 결과는 보장되지 않습니다(기본값: 42). | INT | 예 | 0~4294967295 |
| `watermark` | 비디오에 AIGC 워터마크를 추가할지 여부입니다(기본값: false). 활성화하면 "MiniMax H3" 모델만 지원됩니다. | BOOLEAN | 아니요 | true<br />false |

### MiniMax H3 입력

이 설정은 "MiniMax H3" 모델을 선택할 때 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 공백이 아닌 문자를 하나 이상 포함해야 합니다. | STRING | 예 | 모든 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | "768P"<br />"2K" |
| `ratio` | 출력 비디오의 화면 비율입니다(기본값: "16:9"). | COMBO | 예 | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 출력 비디오의 재생 시간(초)입니다(4~15초, 기본값: 5). | INT | 예 | 4~15 |

### MiniMax H3 Max and MiniMax H3 Max Turbo 입력

이 설정은 "MiniMax H3 Max" 및 "MiniMax H3 Max Turbo" 모델에서 공유되며, 두 모델 중 하나를 선택하면 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 공백이 아닌 문자를 하나 이상 포함해야 하며 최대 50,000자까지 입력할 수 있습니다. | STRING | 예 | 최대 50,000자 |
| `resolution` | 출력 비디오의 해상도입니다(기본값: "768P"). | COMBO | 예 | "480P"<br />"768P" |
| `ratio` | 출력 비디오의 화면 비율입니다(기본값: "16:9"). | COMBO | 예 | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 출력 비디오의 재생 시간(초)입니다(5~15초, 기본값: 5). | INT | 예 | 5~15 |
| `prompt_expansion_mode` | 생성 전 프롬프트 재작성에 투입되는 노력의 정도입니다(기본값: "balanced"). | COMBO | 예 | "balanced"<br />"quality" |

### 참고 사항

- 모든 모델에서 프롬프트에는 공백이 아닌 문자가 하나 이상 포함되어야 합니다.
- `watermark` 설정은 "MiniMax H3"에서만 지원됩니다. "MiniMax H3 Max" 또는 "MiniMax H3 Max Turbo"와 함께 활성화하면 오류가 발생합니다.
- "MiniMax H3 Max" 및 "MiniMax H3 Max Turbo" 모델은 프롬프트를 50,000자로 제한합니다.
- 해상도 및 재생 시간 제한은 선택한 모델에 따라 다릅니다. "MiniMax H3"는 "768P" 및 "2K" 해상도와 4~15초 비디오를 지원하는 반면, "MiniMax H3 Max" 및 "MiniMax H3 Max Turbo"는 "480P" 및 "768P" 해상도와 5~15초 비디오를 지원합니다.
- 이 노드에 표시되는 예상 가격은 선택한 모델, 해상도 및 재생 시간을 기반으로 계산됩니다.
