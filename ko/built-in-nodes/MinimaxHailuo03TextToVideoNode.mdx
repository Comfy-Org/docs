이 노드는 MiniMax H3 모델군(MiniMax H3, MiniMax H3 Max, MiniMax H3 Max Turbo)을 사용하여 텍스트 프롬프트로부터 비디오를 생성합니다. 모델을 선택하고 텍스트 프롬프트를 입력한 뒤 해상도, 화면 비율, 길이 등의 설정을 조정합니다. 노드는 MiniMax API로 요청을 전송하고, 생성 작업이 완료될 때까지 기다린 후 결과 비디오를 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용할 모델입니다(기본값: "MiniMax H3"). 모델을 선택하면 아래 섹션에 설명된 모델별 설정도 표시됩니다. | DYNAMIC_COMBO | 예 | "MiniMax H3"<br />"MiniMax H3 Max"<br />"MiniMax H3 Max Turbo" |
| `seed` | 무작위 시드입니다. 동일한 요청과 동일한 시드는 유사하지만 반드시 동일하다고 보장되지는 않는 결과를 제공합니다(기본값: 42). | INT | 예 | 0  ~  4294967295 |
| `watermark` | 비디오에 AIGC 워터마크를 추가할지 여부입니다(기본값: false). 활성화하면 "MiniMax H3" 모델만 지원됩니다. | BOOLEAN | 아니요 | true<br />false |

### MiniMax H3 입력

이러한 설정은 "MiniMax H3" 모델을 선택했을 때 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 공백이 아닌 문자를 최소 하나 이상 포함해야 합니다. | STRING | 예 | 모든 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | "768P"<br />"2K" |
| `ratio` | 출력 비디오의 화면 비율입니다(기본값: "16:9"). | COMBO | 예 | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 출력 비디오의 길이(초)입니다(4-15)(기본값: 5). | INT | 예 | 4  ~  15 |

### MiniMax H3 Max 및 MiniMax H3 Max Turbo 입력

이러한 설정은 "MiniMax H3 Max" 및 "MiniMax H3 Max Turbo" 모델에서 공유되며, 둘 중 하나의 모델을 선택했을 때 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 공백이 아닌 문자를 최소 하나 이상 포함해야 하며 최대 50,000자까지 입력할 수 있습니다. | STRING | 예 | 최대 50000자 |
| `resolution` | 출력 비디오의 해상도입니다(기본값: "768P"). | COMBO | 예 | "480P"<br />"768P" |
| `ratio` | 출력 비디오의 화면 비율입니다(기본값: "16:9"). | COMBO | 예 | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 출력 비디오의 길이(초)입니다(5-15)(기본값: 5). | INT | 예 | 5  ~  15 |
| `prompt_expansion_mode` | 생성 전에 프롬프트를 다시 작성하는 데 얼마나 많은 노력을 기울이는지 설정합니다(기본값: "balanced"). | COMBO | 예 | "balanced"<br />"quality" |

### 참고 사항

- 모든 모델에서 프롬프트는 공백이 아닌 문자를 최소 하나 이상 포함해야 합니다.
- `watermark` 설정은 "MiniMax H3"에서만 지원됩니다. "MiniMax H3 Max" 또는 "MiniMax H3 Max Turbo"에서 이를 활성화하면 오류가 발생합니다.
- "MiniMax H3 Max" 및 "MiniMax H3 Max Turbo" 모델은 프롬프트를 50,000자로 제한합니다.
- 해상도 및 길이 제한은 선택한 모델에 따라 달라집니다. "MiniMax H3"는 "768P" 및 "2K" 해상도와 4-15초 비디오를 지원하고, "MiniMax H3 Max" 및 "MiniMax H3 Max Turbo"는 "480P" 및 "768P" 해상도와 5-15초 비디오를 지원합니다.
- 이 노드에 표시되는 예상 가격은 선택한 모델, 해상도 및 길이를 기준으로 계산됩니다.
