이 노드는 SAM3 추적 데이터를 WanSCAILToVideo 노드에서 사용하는 컬러 마스크로 렌더링합니다. 드라이빙 포즈 비디오와 선택적으로 참조 이미지의 추적 데이터를 처리하여, 두 출력 모두에서 추적된 각 사람에게 일관된 색상을 할당합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `driving_track_data` | 드라이빙 포즈 비디오의 SAM3 트랙입니다. pose_video_mask 출력으로 렌더링됩니다. | SAM3_TRACK_DATA | 예 | - |
| `ref_track_data` | 참조 이미지의 SAM3 트랙(객체당 하나의 아이덴티티, 배치 순서대로 색상 지정) 또는 참조 대상의 일반 MASK(단일 아이덴티티로 렌더링)입니다. | SAM3_TRACK_DATA 또는 MASK | 아니요 | - |
| `object_indices` | 포함할 사람 인덱스의 쉼표로 구분된 목록입니다(예: '0,2,3'). 참조 및 포즈 비디오 마스크 모두에 적용됩니다. 비어 있으면 전체를 의미합니다. (기본값: "") | STRING | 예 | - |
| `sort_by` | 팔레트 색상이 추적된 객체에 할당되는 순서입니다(참조 및 포즈 비디오 모두에 적용되어 각 아이덴티티가 동일한 색상을 유지합니다). 더 이른 프레임에 나타나는 객체가 항상 먼저 옵니다. 한 프레임 내에서는 left_to_right = 가장 왼쪽 객체(첫 등장 시 중심점 기준)가 첫 번째 색상을 받고, area = 가장 큰 객체(첫 등장 시 마스크 면적 기준)가 첫 번째 색상을 받습니다. none = SAM3의 순서를 유지합니다. (기본값: "left_to_right") | COMBO | 예 | `"none"`<br />`"left_to_right"`<br />`"area"` |
| `replacement_mode` | False = 애니메이션 모드(pose_video_mask는 검은색 배경, reference_image_mask는 흰색 배경). True = 교체 모드(pose_video_mask는 흰색 배경, reference_image_mask는 검은색 배경). (기본값: False) | BOOLEAN | 예 | False<br />True |

참고: `object_indices`는 쉼표로 구분된 숫자만 허용하며, 숫자가 아닌 항목과 범위를 벗어난 인덱스는 무시됩니다. `ref_track_data`가 제공되지 않으면 `reference_image_mask` 출력은 참조 배경색(애니메이션 모드에서는 흰색, 교체 모드에서는 검은색)으로 단색 채우기됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `pose_video_mask` | 드라이빙 포즈 비디오 추적 데이터에서 렌더링된 컬러 마스크입니다. 배경색은 replacement_mode 설정을 따릅니다. | IMAGE |
| `reference_image_mask` | 참조 이미지 추적 데이터에서 렌더링된 컬러 마스크입니다. 배경은 교체 모드에서는 검은색, 애니메이션 모드에서는 흰색입니다. 참조 데이터가 제공되지 않으면 참조 배경색과 일치하는 단색 채우기를 반환합니다. | IMAGE |
