이 노드는 기존 Tripo 3D 모델을 가져와 리깅된 버전을 생성합니다. 즉, 모델에 애니메이션을 적용할 수 있도록 스켈레톤이 추가됩니다. 리깅할 모델의 task ID를 제공하고, rig 버전, 스켈레톤 유형, 본 이름 지정 스타일, 출력 파일 형식을 선택하면, 노드가 작업을 Tripo로 전송하고 완료될 때까지 기다린 후 다운로드한 결과를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `원본 모델 작업 ID` | 리깅할 원본 3D 모델의 task ID입니다. 일반적으로 이전 Tripo 모델 생성 노드에서 생성된 ID입니다. | MODEL_TASK_ID | 예 | - |
| `model_version` | 사용할 rig 모델 버전입니다. v1.0: 인간형(biped) 캐릭터만 지원하며, 90개 이상의 애니메이션 프리셋을 제공합니다. v2.5: 비인간형 생물(quadruped, hexapod, octopod, avian, serpentine, aquatic)을 지원합니다. 기본값: `v1.0-20240301`. | COMBO | 아니요 | "v1.0-20240301"<br />"v2.5-20260210" |
| `rig_type` | 스켈레톤 유형입니다. "auto"는 Tripo의 무료 리깅 검사를 먼저 실행하고 권장 유형을 사용합니다. 기본값: "auto". | COMBO | 아니요 | "auto"<br />"biped"<br />"quadruped"<br />"hexapod"<br />"octopod"<br />"avian"<br />"serpentine"<br />"aquatic" |
| `spec` | 본 이름 지정: Tripo 네이티브 또는 Mixamo 호환입니다. Tripo는 자사 애니메이션 프리셋을 mixamo spec으로 만든 v1.0 rig에 리타게팅할 수 없습니다. Tripo: Retarget rigged model에는 tripo를 사용하세요. 기본값: "tripo". | COMBO | 아니요 | "tripo"<br />"mixamo" |
| `out_format` | 출력 파일 형식입니다. 결과는 일치하는 출력으로 전달됩니다. 기본값: "glb". | COMBO | 아니요 | "glb"<br />"fbx" |

**참고:** v1.0 모델 버전(`v1.0-20240301`)은 biped 스켈레톤만 지원합니다. 이 버전에서 non-biped `rig_type`을 사용하면 노드가 오류를 발생시키고 대신 `v2.5-20260210`을 사용하도록 안내합니다.

**참고:** `rig_type`이 "auto"이면 Tripo가 먼저 모델을 리깅할 수 있는지 확인하고 권장 스켈레톤 유형을 선택합니다. Tripo가 모델을 리깅할 수 없다고 보고하면 노드가 오류와 함께 실패합니다.

**참고:** 이 노드는 Tripo가 GLB 또는 FBX 파일을 반환할 것으로 예상합니다. Tripo가 다른 파일 형식을 반환하면 노드가 오류를 발생시킵니다.

**참고:** `out_format`과 일치하는 출력만 채워집니다. `out_format`이 "glb"이면 `GLB`, "fbx"이면 `FBX`입니다. 다른 3D 출력은 비어 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model_file` | 생성된 리깅된 모델 파일 이름입니다(task ID와 형식 확장자). 하위 호환성을 위해서만 유지됩니다. | STRING |
| `rig task_id` | rig 생성 과정을 추적하기 위한 task ID입니다. | RIG_TASK_ID |
| `GLB` | 리깅된 모델을 GLB 3D 파일로 나타낸 것입니다. `out_format`이 "glb"일 때 채워집니다. | FILE3DGLB |
| `FBX` | 리깅된 모델을 FBX 3D 파일로 나타낸 것입니다. `out_format`이 "fbx"일 때 채워집니다. | FILE3DFBX |
