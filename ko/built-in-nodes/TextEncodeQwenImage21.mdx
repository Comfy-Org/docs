The TextEncodeQwenImage21 노드는 Qwen-Image 2.1 모델용 프롬프트와 부정 프롬프트를 인코딩하며, 선택적으로 참조 이미지를 첨부합니다. 참조 이미지는 텍스트 인코더에 의해 인식되며, VAE가 연결된 경우 latent로 인코딩되어 시퀀스에 이어 붙여집니다. 따라서 컨디셔닝은 텍스트 지시와 시각적 참조를 모두 전달합니다. 이 노드는 첫 번째 참조 이미지 크기에 맞춰진 빈 latent와 함께 긍정 및 부정 컨디셔닝을 반환하며, 바로 샘플링할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | 프롬프트를 토큰화하고 인코딩하는 데 사용되는 Qwen-Image 2.1 텍스트 인코더입니다. | CLIP | 예 | - |
| `prompt` | 생성할 이미지 또는 적용할 편집을 설명하는 텍스트 프롬프트입니다. 여러 줄 입력과 동적 프롬프트를 지원합니다. | STRING | 예 | 모든 텍스트 |
| `negative_prompt` | 결과가 피해야 할 내용을 설명하는 텍스트 프롬프트입니다. 여러 줄 입력과 동적 프롬프트를 지원합니다. | STRING | 예 | 모든 텍스트 |
| `vae` | 참조 이미지를 참조 latent로 인코딩하는 데 사용되는 VAE입니다. 생략하면 참조 이미지는 텍스트 인코더를 통해서만 결과에 컨디셔닝을 적용합니다. | VAE | 아니요 | - |
| `resolution` | 참조 이미지는 약 `resolution` x `resolution` 픽셀 크기로, 32의 배수로 조정되며 종횡비를 유지합니다. 0은 각 참조 이미지를 자체 크기로 유지하되 32의 배수로 반올림합니다(기본값: 1024). | INT | 예 | 0 ~ 4096 (단계 32) |
| `images` | 텍스트 인코더에 의해 인식되고 VAE latent로 시퀀스에 이어 붙여지는 참조 이미지입니다. 확장 가능한 슬롯: 최대 16개의 이미지(`image_1` ... `image_16`)를 연결할 수 있습니다. | IMAGE | 아니요 | 0 ~ 16개 이미지 |

빈 latent 출력은 연결된 첫 번째 참조 이미지 크기에 맞춰지며, 참조 이미지가 연결되지 않은 경우에는 `resolution` 크기에 맞춰집니다. 이 노드가 반환하는 latent에서 샘플링하세요. 다른 크기를 사용하면 편집 결과가 달라집니다. VAE가 연결되면 동일한 참조 latent가 긍정 및 부정 컨디셔닝 모두에 첨부되므로, 단일 샘플러 단계에서 둘 모두를 디노이즈할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `positive` | 프롬프트에 대해 인코딩된 컨디셔닝이며, VAE가 연결된 경우 참조 latent를 전달합니다. | CONDITIONING |
| `negative` | 부정 프롬프트에 대해 인코딩된 컨디셔닝이며, 동일한 참조 latent를 포함합니다. | CONDITIONING |
| `latent` | 첫 번째 참조 이미지 크기의 빈 latent이며, 참조 이미지가 연결되지 않은 경우에는 1024 x 1024입니다. | LATENT |
