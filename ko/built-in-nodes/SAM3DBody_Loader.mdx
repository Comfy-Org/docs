detection 폴더에 저장된 체크포인트 파일에서 SAM3D Body 모델을 로드하고 3D 신체 감지에 사용할 수 있도록 준비합니다. 이 노드는 모델 가중치를 로드하고, 양자화 설정이 있는 경우 이를 감지하여 적용하며, 자동 메모리 관리를 위해 모델을 래핑합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_file` | 로드할 SAM3D Body 체크포인트 파일입니다. 파일은 detection 폴더에 있어야 합니다. | COMBO | 예 | detection 폴더에서 사용 가능한 모든 모델 파일 |

참고: 모델 파일은 detection 폴더에 위치해야 합니다. 체크포인트의 state_dict 키가 SAM3D Body 모델 구조와 일치하지 않으면 오류와 함께 로딩이 실패합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `sam3d_body_model` | GPU와 CPU 간 자동 메모리 관리를 위해 래핑된 로드된 SAM3D Body 모델입니다. 손 감지 가중치는 제거되어 신체 감지 전용으로 특화된 모델입니다. | SAM3D_BODY_MODEL |
