'crisp upscale' 도구를 사용하여 입력 이미지를 동기식으로 업스케일하여 해상도를 높이고 더 선명하고 깨끗하게 만듭니다. 입력 배치의 각 이미지는 독립적으로 처리되며, 업스케일된 결과는 배치로 반환됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 업스케일할 입력 이미지입니다. 이미지 배치를 허용합니다. | IMAGE | 예 | — |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 향상된 해상도와 선명도를 가진 업스케일된 이미지입니다. 입력으로 배치가 제공된 경우 이미지 배치를 반환합니다. | IMAGE |
