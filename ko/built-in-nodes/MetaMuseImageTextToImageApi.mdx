Meta Muse Image Text to Image는 Meta의 Muse Image 모델을 사용하여 텍스트 프롬프트로부터 이미지를 생성합니다. 모델은 렌더링 전에 프롬프트를 추론하며, 이미지를 계획하는 동안 웹 검색, 이미지 검색 및 코드 실행을 사용할 수 있습니다. 이 노드는 Muse Image API를 호출하고 결과 이미지 또는 이미지들을 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 사용할 모델입니다. | DYNAMIC_COMBO | 예 | `"muse-image-1.0"` |

목록에서 모델을 선택하면 해당 모델이 지원하는 설정이 표시됩니다. 사용 가능한 모델은 `muse-image-1.0`뿐이며, 해당 설정은 아래에 나열되어 있습니다.

### muse-image-1.0 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 이미지를 설명하는 프롬프트입니다. 모델은 렌더링 전에 프롬프트를 추론하며, 내장된 웹 및 이미지 검색을 사용할 수 있습니다. | STRING | 예 | 여러 줄 텍스트, 최소 1자 |
| `aspect_ratio` | 출력의 가로세로 비율입니다. 이미지는 약 2.5메가픽셀(1:1은 1600x1600, 16:9는 2048x1152)로 렌더링됩니다. `"auto"`를 사용하면 모델이 프롬프트를 바탕으로 선택합니다. | COMBO | 예 | `"auto"`<br />`"1:1"`<br />`"3:2"`<br />`"2:3"`<br />`"4:3"`<br />`"3:4"`<br />`"5:4"`<br />`"4:5"`<br />`"16:9"`<br />`"9:16"`<br />`"21:9"`<br />`"9:21"`<br />`"2:1"`<br />`"1:2"` |
| `reasoning_strength` | 렌더링 전에 모델이 얼마나 생각하고, 계획하고, 스스로 개선하는지입니다. | COMBO | 예 | `"high"`<br />`"low"` |
| `enable_web_search` | 이미지를 계획하는 동안 모델이 사실과 실시간 정보를 웹에서 검색할 수 있도록 합니다. | BOOLEAN | 아니요 | True<br />False (기본값: True) |
| `enable_image_search` | 이미지를 계획하는 동안 모델이 참조 이미지를 검색할 수 있도록 합니다. | BOOLEAN | 아니요 | True<br />False (기본값: True) |
| `enable_shell` | 계획 중에 모델이 코드를 실행할 수 있도록 하여 정밀한 레이아웃, 차트 및 다이어그램을 만들 수 있습니다. 끄면 수량과 정렬이 근사치로 처리됩니다. | BOOLEAN | 아니요 | True<br />False (기본값: True) |
| `seed` | 노드를 다시 실행할지 결정하는 시드입니다. API에는 시드가 없으므로 이 값과 관계없이 실제 결과는 비결정적입니다. | INT | 예 | 0 – 2147483647 (기본값: 42) |

참고: 프롬프트는 최소 한 글자 이상이어야 합니다. `aspect_ratio`가 `"auto"`로 설정된 경우 API에 명시적 크기가 전송되지 않으며 모델이 프롬프트로부터 출력 크기를 결정합니다. `seed` 매개변수는 노드가 다시 실행되는 시점만 제어합니다. API로 전송되지 않으므로 생성 결과는 비결정적입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | API에서 반환된 생성 이미지로, 디코딩되어 배치 이미지로 제공됩니다. API 응답에 여러 이미지가 포함된 경우 하나의 배치로 결합됩니다. | IMAGE |
