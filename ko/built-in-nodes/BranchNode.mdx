Branch는 이름을 기준으로 연결된 여러 입력 중 하나를 선택하여 출력으로 전달합니다. 지연 스위치처럼 동작하므로 선택된 분기만 평가되며, 다른 분기는 연결되지 않은 상태로 두거나 계산하지 않으려는 출력을 보유할 수 있습니다. 새 연결이 추가될 때마다 분기 입력이 하나씩 추가되고, 입력은 두 번 클릭하여 이름을 바꿀 수 있으며, 활성 분기는 `branch` 선택기에서 선택합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `autogrow` | 연결된 분기입니다. 각 연결은 최대 32개까지 새 분기 입력을 추가하며, 모든 분기는 동일한 데이터 타입을 사용해야 하고, 이 데이터 타입이 출력 타입이 됩니다. | AUTOGROW | 예 | 1~32개 분기 |
| `branch` | 출력으로 전달할 분기의 이름입니다. 옵션은 연결된 분기 입력의 이름이며, 입력은 두 번 클릭하여 이름을 바꿀 수 있습니다. | STRING | 예 | Names of the connected branches |
| `branch_names` | 연결된 분기 이름의 내부 목록으로, 프런트엔드에서 동기화 상태를 유지합니다. 선택한 이름을 해당 분기에 매핑하며, 직접 편집하기 위한 용도가 아닙니다. | ARRAY | 예 | - |

**참고:** 선택된 분기만 요청되므로 다른 분기는 평가되지 않습니다. 선택한 이름이 연결되어 있지 않으면 노드에서 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `output` | 선택된 분기의 값으로, 변경 없이 전달됩니다. | MATCH_TYPE |
