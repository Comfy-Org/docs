StableZero123_Conditioning_Batched 노드는 단일 입력 이미지에서 3D 모델을 생성하기 위한 컨디셔닝 데이터를 준비합니다. CLIP 비전 모델과 VAE로 이미지를 인코딩하고, 고도 및 방위각으로부터 생성된 카메라 임베딩과 시각적 특징을 결합하여 샘플 배치에 대한 포지티브 및 네거티브 컨디셔닝과 잠재 텐서를 생성합니다. `batch_size`가 1보다 크면 배치의 각 항목에 대해 고도와 방위각이 해당 배치 증분 값만큼 증가합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip_vision` | 입력 이미지 인코딩에 사용되는 CLIP 비전 모델 | CLIP_VISION | 예 | - |
| `초기 이미지` | 처리 및 인코딩할 초기 입력 이미지 | IMAGE | 예 | - |
| `vae` | 이미지 픽셀을 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델 | VAE | 예 | - |
| `너비` | 처리된 이미지의 출력 너비 (기본값: 256) | INT | 예 | 16 ~ MAX_RESOLUTION (8씩 증가) |
| `높이` | 처리된 이미지의 출력 높이 (기본값: 256) | INT | 예 | 16 ~ MAX_RESOLUTION (8씩 증가) |
| `배치 크기` | 배치에서 생성할 컨디셔닝 샘플 수 (기본값: 1) | INT | 예 | 1 ~ 4096 |
| `고도` | 초기 카메라 고도 각도 (도 단위, 기본값: 0.0) | FLOAT | 예 | -180.0 ~ 180.0 |
| `방위각` | 초기 카메라 방위각 (도 단위, 기본값: 0.0) | FLOAT | 예 | -180.0 ~ 180.0 |
| `고도 배치 증가` | 배치 항목마다 고도를 증가시킬 값 (기본값: 0.0) | FLOAT | 예 | -180.0 ~ 180.0 |
| `방위각 배치 증가` | 배치 항목마다 방위각을 증가시킬 값 (기본값: 0.0) | FLOAT | 예 | -180.0 ~ 180.0 |

**참고:** `width` 및 `height` 값은 8의 배수여야 합니다. 노드가 잠재 텐서를 구성할 때 내부적으로 이 두 값을 8로 나누기 때문입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `긍정 조건` | 각 배치 항목에 대한 이미지 임베딩 및 카메라 임베딩을 포함하는 포지티브 컨디셔닝 데이터 | CONDITIONING |
| `부정 조건` | 0으로 초기화된 임베딩을 포함하는 네거티브 컨디셔닝 데이터 | CONDITIONING |
| `잠재 데이터` | batch_size x 4 x height/8 x width/8 차원의 0으로 초기화된 잠재 텐서와 배치 인덱싱 정보 | LATENT |
