이 노드는 참조 이미지, 비디오, 오디오를 조건으로 사용하여 MiniMax H3 모델로 비디오를 생성합니다. 참조는 프롬프트에서 연결 순서에 따라 "Image 1", "Image 2", "Video 1", "Audio 1" 등으로 참조됩니다. 두 가지 모델을 사용할 수 있습니다: "MiniMax H3" 및 "MiniMax H3 Max".

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용할 모델입니다(기본값: "MiniMax H3"). "MiniMax H3"를 선택하면 아래의 MiniMax H3 생성 및 참조 입력이 제공됩니다. "MiniMax H3 Max"를 선택하면 아래의 MiniMax H3 Max 생성 및 참조 입력이 제공됩니다. | DYNAMIC_COMBO | 예 | "MiniMax H3"<br />"MiniMax H3 Max" |
| `seed` | 무작위 시드입니다. 동일한 시드로 동일한 요청을 하면 유사하지만 반드시 동일하지는 않은 결과가 생성됩니다(기본값: 42). | INT | 예 | 0~4294967295 |
| `watermark` | 비디오에 AIGC 워터마크를 추가할지 여부입니다(기본값: false). MiniMax H3 모델에서만 지원됩니다. | BOOLEAN | 아니요 | true<br />false |

### MiniMax H3 입력

이 입력은 모델로 "MiniMax H3"를 선택한 경우 사용할 수 있습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 참조 미디어는 순서에 따라 참조할 수 있습니다. 예: "Image 1", "Image 2", "Video 1" 또는 "Audio 1". | STRING | 예 | 최소 1자 |
| `resolution` | 출력 비디오의 해상도입니다(기본값: "768P"). | COMBO | 예 | "768P"<br />"2K" |
| `ratio` | 출력 비디오의 가로세로 비율입니다(기본값: "adaptive"). | COMBO | 예 | "adaptive"<br />"16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 출력 비디오의 길이(초)입니다(기본값: 5). | INT | 예 | 4~15 |

### MiniMax H3 Max 입력

이 입력은 모델로 "MiniMax H3 Max"를 선택한 경우 사용할 수 있습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 참조 미디어는 순서에 따라 참조할 수 있습니다. 예: "Image 1", "Image 2", "Video 1" 또는 "Audio 1". | STRING | 예 | 1~50000자 |
| `resolution` | 출력 비디오의 해상도입니다(기본값: "768P"). | COMBO | 예 | "480P"<br />"768P" |
| `ratio` | 출력 비디오의 가로세로 비율입니다(기본값: "adaptive"). | COMBO | 예 | "adaptive"<br />"16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 출력 비디오의 길이(초)입니다(기본값: 5). | INT | 예 | 5~15 |
| `prompt_expansion_mode` | 생성 전에 프롬프트를 다시 작성하는 데 사용하는 노력의 정도입니다(기본값: "balanced"). | COMBO | 예 | "balanced"<br />"quality" |
| `reference_detail` | 참조 이미지를 전송하는 세부 수준입니다. "high"는 모델이 사용하는 최대 크기(짧은 변 최대 2048픽셀)로 전송하고, "standard"는 참조 비용을 줄이기 위해 최대 2048x1024로 축소합니다(기본값: "standard"). | COMBO | 예 | "high"<br />"standard" |

### 참조 입력

이 참조 입력은 두 모델에서 공유됩니다. 각각은 확장 가능한 슬롯입니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 확장 가능한 슬롯: 최대 9개 항목(`image_1`...`image_9`)을 연결합니다. 피사체 또는 스타일 참조 이미지이며, 프롬프트에서 연결 순서에 따라 "Image 1".."Image 9"로 참조됩니다. 최대 9개 이미지. | IMAGE | 아니요 | 0~9개 이미지 |
| `reference_videos` | 확장 가능한 슬롯: 최대 3개 항목(`video_1`...`video_3`)을 연결합니다. 모션 또는 장면 참조 비디오이며, 프롬프트에서 연결 순서에 따라 "Video 1".."Video 3"으로 참조됩니다. 각 2~15초, 총 15초까지 최대 3개 비디오. | VIDEO | 아니요 | 0~3개 비디오 |
| `reference_audios` | 확장 가능한 슬롯: 최대 3개 항목(`audio_1`...`audio_3`)을 연결합니다. 오디오 참조이며, 프롬프트에서 연결 순서에 따라 "Audio 1".."Audio 3"으로 참조됩니다. 각 2~15초, 총 15초까지 최대 3개 클립. 참조 이미지 또는 비디오 없이 사용할 수 없습니다. | AUDIO | 아니요 | 0~3개 클립 |

### 매개변수 제약

- 참조 이미지 또는 참조 비디오가 최소 하나 필요합니다. 참조 오디오만으로는 허용되지 않습니다.
- 각 참조 이미지는 가로세로 비율이 약 0.4~2.5(2:5~5:2)여야 하며, 최소 너비와 높이가 256픽셀이어야 합니다.
- 각 참조 비디오는 길이가 2~15초이고 프레임 레이트가 23.976~60 FPS여야 합니다. 모든 참조 비디오의 총 길이는 15초를 초과할 수 없습니다.
- 각 참조 오디오 클립은 길이가 2~15초여야 합니다. 모든 참조 오디오 클립의 총 길이는 15초를 초과할 수 없습니다.
- "MiniMax H3 Max"를 선택한 경우 `watermark` 설정은 비활성화해야 합니다.
- "MiniMax H3 Max"를 선택한 경우 총 참조 파일 수(이미지, 비디오, 오디오 합계)는 12개를 초과할 수 없습니다.
