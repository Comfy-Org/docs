이 노드는 MiniMax H3 모델을 사용하여 비디오를 생성하며, 참조 이미지, 비디오 및 오디오를 사용하여 결과를 조건화합니다. 참조 항목은 프롬프트에서 연결 순서에 따라 "Image 1", "Image 2", "Video 1", "Audio 1" 등으로 참조됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용할 모델(기본값: "MiniMax H3"). "MiniMax H3"을 선택하면 아래의 `prompt`, `resolution`, `ratio`, `duration`, `reference_images`, `reference_videos` 및 `reference_audios` 설정이 제공됩니다. | DYNAMIC_COMBO | 예 | "MiniMax H3" |
| `seed` | 난수 시드. 동일한 시드를 사용한 동일한 요청은 유사한 결과를 제공하지만, 동일한 결과가 보장되지는 않습니다(기본값: 42). | INT | 예 | 0~4294967295 |
| `watermark` | 비디오에 AIGC 워터마크를 추가할지 여부(기본값: false). | BOOLEAN | 아니요 | true<br />false |

### MiniMax H3 입력

이 입력은 모델로 "MiniMax H3"을 선택한 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성용 텍스트 프롬프트. 참조 미디어는 순서에 따라 "Image 1", "Image 2", "Video 1" 또는 "Audio 1"과 같이 참조할 수 있습니다. | STRING | 예 | 최소 길이: 1자 |
| `resolution` | 출력 비디오의 해상도(기본값: "768P"). | STRING | 예 | "768P"<br />"2K" |
| `ratio` | 출력 비디오의 화면 비율(기본값: "adaptive"). | STRING | 예 | "adaptive"<br />"16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9" |
| `duration` | 출력 비디오의 길이(초)(기본값: 5). | INT | 예 | 4~15 |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 확장 가능 슬롯: 1~9개 항목(`image_1`...`image_9`)을 연결합니다. 피사체 또는 스타일 참조 이미지로, 프롬프트에서 연결 순서에 따라 "Image 1"~"Image 9"로 참조됩니다. 최대 9개 이미지. | IMAGE | 아니요 | 0~9개 이미지 |
| `reference_videos` | 확장 가능 슬롯: 1~3개 항목(`video_1`...`video_3`)을 연결합니다. 모션 또는 장면 참조 비디오로, 프롬프트에서 연결 순서에 따라 "Video 1"~"Video 3"로 참조됩니다. 최대 3개 비디오, 각 2~15초, 총 15초. | VIDEO | 아니요 | 0~3개 비디오 |
| `reference_audios` | 확장 가능 슬롯: 1~3개 항목(`audio_1`...`audio_3`)을 연결합니다. 오디오 참조로, 프롬프트에서 연결 순서에 따라 "Audio 1"~"Audio 3"로 참조됩니다. 최대 3개 클립, 각 2~15초, 총 15초. 참조 이미지 또는 비디오 없이는 사용할 수 없습니다. | AUDIO | 아니요 | 0~3개 클립 |

### 매개변수 제약 조건

- 참조 이미지 또는 참조 비디오가 하나 이상 필요합니다. 참조 오디오만으로는 사용할 수 없습니다.
- 각 참조 이미지의 화면 비율은 약 0.4~2.5(2:5~5:2) 범위여야 하며, 최소 너비와 높이는 256픽셀이어야 합니다.
- 각 참조 비디오는 2~15초 길이여야 하며, 프레임 속도는 23.976~60 FPS여야 합니다. 모든 참조 비디오의 총 길이는 15초를 초과할 수 없습니다.
- 각 참조 오디오 클립은 2~15초 길이여야 합니다. 모든 참조 오디오 클립의 총 길이는 15초를 초과할 수 없습니다.
