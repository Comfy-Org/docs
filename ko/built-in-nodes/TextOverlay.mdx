이 노드는 이미지 또는 이미지 배치 위에 텍스트를 그립니다. 구성 가능한 글꼴 크기, 색상, 수직 위치, 수평 정렬 및 선택적 검은색 외곽선을 사용하여 텍스트 오버레이를 만든 다음, 오버레이를 원본 이미지 픽셀과 결합합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 텍스트를 그릴 입력 이미지 또는 이미지 배치입니다 | IMAGE | 예 | |
| `text` | 이미지 위에 오버레이할 텍스트입니다(기본값: ""). 여러 줄을 지원합니다: `\n` 및 `\t` 이스케이프 시퀀스는 줄바꿈과 탭으로 변환되며, 긴 줄은 이미지 너비에 맞게 자동으로 줄바꿈됩니다. | STRING | 예 | |
| `font_size` | 이미지 높이에 대한 백분율로 표시한 글꼴 크기입니다(기본값: 5.0) | FLOAT | 예 | 0.5  ~  50.0 (단계: 0.5) |
| `color` | 텍스트 색상입니다(기본값: "#ffffff") | COLOR | 예 | |
| `position` | 이미지에서 텍스트의 수직 위치입니다(기본값: "top") | COMBO | 예 | "top"<br />"bottom" |
| `align` | 텍스트의 수평 정렬입니다(기본값: "left") | COMBO | 예 | "left"<br />"center"<br />"right" |
| `outline` | 텍스트 주위에 검은색 외곽선을 그립니다(기본값: True) | BOOLEAN | 예 | |

참고: `text`가 비어 있거나 공백만 포함하는 경우, 노드는 입력 이미지를 변경 없이 반환합니다. 텍스트 오버레이는 한 번 렌더링되어 배치의 모든 이미지에 적용됩니다. 렌더링된 텍스트 블록이 사용 가능한 이미지 영역보다 높으면, 맞을 때까지 또는 최소 크기에 도달할 때까지 글꼴 크기가 자동으로 줄어듭니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `images` | 텍스트 오버레이가 위에 합성된 입력 이미지입니다 | IMAGE |
