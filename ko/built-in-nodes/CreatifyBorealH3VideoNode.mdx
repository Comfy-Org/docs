Creatify Boreal-H3 Video는 비디오 광고용으로 포스트 트레이닝된 Creatify의 H3 모델을 사용하여 텍스트 프롬프트를 사운드가 포함된 비디오로 변환합니다. 첫 프레임을 연결해 정지 이미지를 애니메이션화하고, 선택적으로 마지막 프레임을 연결해 샷이 선택한 이미지에서 끝나도록 할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오를 설명하는 텍스트 프롬프트입니다. 공백이 아닌 문자를 하나 이상 포함해야 합니다. | STRING | 예 | 비어 있지 않은 임의 텍스트 |
| `first_frame` | 비디오가 시작되는 이미지입니다. 이 항목을 연결한 경우 비디오가 이미지를 따르도록 `aspect_ratio`를 `"auto"`로 유지하세요. | IMAGE | 아니요 | - |
| `last_frame` | 비디오가 끝나는 이미지입니다. 연결된 `first_frame`이 필요합니다. | IMAGE | 아니요 | - |
| `resolution` | 출력 비디오의 해상도입니다(기본값: `"768p"`). | COMBO | 예 | `"768p"`<br />`"1088p"`<br />`"2k"` |
| `aspect_ratio` | 출력 비디오의 종횡비입니다. 첫 프레임이 연결된 경우 `"auto"`는 첫 프레임을 따릅니다. 이 경우 `"auto"`로 두세요(기본값: `"auto"`). | COMBO | 예 | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 비디오 길이(초)입니다(기본값: 5). `"2k"`에서는 최대 14초입니다. | INT | 예 | 1 ~ 15 (단계: 1) |
| `prompt_enhancement` | 렌더링 전에 Creatify가 프롬프트를 재작성하는 방식입니다. `"auto"` 및 `"ads"`는 이를 비디오 광고 프롬프트로 바꾸고 음성 대사를 추가할 수 있으며, `"general"`은 다른 모든 비디오에 맞게 재작성하고, `"none"`은 작성된 그대로 렌더링합니다(기본값: `"auto"`). | COMBO | 예 | `"auto"`<br />`"ads"`<br />`"general"`<br />`"none"` |
| `seed` | 시드는 노드의 재실행 여부를 제어합니다. Creatify는 자체적인 무작위성을 선택하므로, 동일한 입력으로 동일한 비디오를 얻으려면 `prompt_enhancement`가 `"none"`으로 설정된 경우에만 가능합니다(기본값: 42). | INT | 예 | 0 ~ 2147483647 |

**제약 사항:** `first_frame`이 있으면 종횡비는 항상 이미지에서 가져오므로, 다른 `aspect_ratio` 값을 지정하면 오류가 발생합니다. `first_frame` 없이 `last_frame`을 지정하면 거부되며, `"2k"`에서는 14초를 초과하는 `duration`이 거부됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 사운드가 포함된 생성된 비디오입니다. | VIDEO |
