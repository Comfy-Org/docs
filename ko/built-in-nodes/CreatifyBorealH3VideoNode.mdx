Creatify Boreal-H3 Video는 텍스트 프롬프트를 소리가 포함된 비디오로 변환하며, 비디오 광고용으로 후속 학습된 Creatify의 H3 모델을 사용합니다. 첫 프레임을 연결하여 정지 이미지를 애니메이션화하고, 선택적으로 마지막 프레임을 연결하여 선택한 이미지에서 샷이 끝나도록 할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오를 설명하는 텍스트 프롬프트입니다. 공백이 아닌 문자를 하나 이상 포함해야 합니다. | STRING | 예 | 비어 있지 않은 임의 텍스트 |
| `first_frame` | 비디오가 시작되는 이미지입니다. 연결된 경우 비디오가 이미지를 따르도록 `aspect_ratio`를 `"auto"`로 유지하세요. | IMAGE | 아니오 | - |
| `last_frame` | 비디오가 끝나는 이미지입니다. 연결된 `first_frame`이 필요합니다. | IMAGE | 아니오 | - |
| `resolution` | 출력 비디오의 해상도입니다(기본값: `"768p"`). | COMBO | 예 | `"768p"`<br />`"1088p"`<br />`"2k"` |
| `aspect_ratio` | 출력 비디오의 화면 비율입니다. `"auto"`는 첫 프레임이 연결된 경우 해당 프레임을 따릅니다. 이 경우 `"auto"`로 두세요(기본값: `"auto"`). | COMBO | 예 | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 비디오 길이(초)입니다(기본값: 5). `"2k"`에서는 최대 14초입니다. | INT | 예 | 1 ~ 15 (단계: 1) |
| `prompt_enhancement` | 렌더링 전에 Creatify가 프롬프트를 다시 작성하는 방식입니다. `"auto"`와 `"ads"`는 이를 비디오 광고 프롬프트로 바꾸고 음성 대사를 추가할 수 있으며, `"general"`은 그 밖의 다른 비디오용으로 다시 작성하고, `"none"`은 작성된 그대로 렌더링합니다(기본값: `"auto"`). | COMBO | 예 | `"auto"`<br />`"ads"`<br />`"general"`<br />`"none"` |
| `seed` | 시드는 노드가 다시 실행되는지 여부를 제어합니다. Boreal-H3에는 시드가 전송되지 않으므로 동일한 입력으로 다시 실행하면 다른 비디오가 생성될 수 있습니다(기본값: 42). | INT | 예 | 0 ~ 2147483647 |

**제약 사항:** `first_frame`이 있으면 화면 비율은 항상 이미지에서 가져오므로 다른 `aspect_ratio` 값은 오류를 발생시킵니다. `first_frame` 없이 `last_frame`을 지정하면 거부되며, `"2k"`에서는 `duration`이 14초를 초과하면 거부됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 소리가 포함된 생성된 비디오입니다. | VIDEO |
