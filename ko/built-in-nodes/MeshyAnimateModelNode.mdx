이 노드는 Meshy 서비스를 사용하여 이전에 리깅된 3D 캐릭터에 특정 애니메이션 액션을 적용합니다. 이전 리깅 작업의 작업 ID와 라이브러리에서 원하는 애니메이션을 선택하기 위한 액션 ID를 입력으로 받은 다음, 애니메이션이 적용된 모델을 GLB 및 FBX 파일 형식으로 모두 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `rig_task_id` | 이전에 완료된 Meshy 캐릭터 리깅 작업의 고유 작업 ID입니다. | MESHY_RIGGED_TASK_ID | 예 | N/A |
| `action_id` | 적용할 애니메이션 액션의 ID 번호입니다. 사용 가능한 값 목록은 https://docs.meshy.ai/en/api/animation-library 를 참조하십시오. (기본값: 0) | INT | 예 | 0  ~  696 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model_file` | 애니메이션이 적용된 모델의 문자열 식별자입니다. 이 출력은 하위 호환성을 위해서만 제공됩니다. | STRING |
| `GLB` | GLB 형식의 애니메이션이 적용된 3D 모델 파일입니다. | FILE3DGLB |
| `FBX` | FBX 형식의 애니메이션이 적용된 3D 모델 파일입니다. | FILE3DFBX |
