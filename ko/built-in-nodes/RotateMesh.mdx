월드 축을 기준으로 3D 메시를 회전합니다. 회전에는 오일러 XYZ 각도(단위: 도) 또는 쿼터니언을 사용할 수 있습니다. 회전은 메시의 정점에 적용되며, 법선과 탄젠트도 함께 회전하므로 조명과 음영이 올바르게 유지됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모드` | 사용할 회전 모드입니다. `"euler_xyz"`는 월드 축을 기준으로 X, Y, Z 각도 순서대로 회전을 적용합니다(단위: 도). `"quaternion"`은 자동으로 정규화되는 (w, x, y, z) 쿼터니언을 사용합니다. | DYNAMIC_COMBO | 예 | `"euler_xyz"`<br />`"quaternion"` |
| `메시` | 회전할 3D 메시입니다. | MESH | 예 | — |

### euler_xyz 입력

이 입력들은 `mode`가 `"euler_xyz"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `angle_x` | X축을 기준으로 한 회전 각도(단위: 도)입니다. (기본값: 0.0) | FLOAT | 아니요 | -360.0 ~ 360.0 (step: 0.1) |
| `angle_y` | Y축을 기준으로 한 회전 각도(단위: 도)입니다. (기본값: 0.0) | FLOAT | 아니요 | -360.0 ~ 360.0 (step: 0.1) |
| `angle_z` | Z축을 기준으로 한 회전 각도(단위: 도)입니다. (기본값: 0.0) | FLOAT | 아니요 | -360.0 ~ 360.0 (step: 0.1) |

### quaternion 입력

이 입력들은 `mode`가 `"quaternion"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `qw` | 쿼터니언(w, x, y, z)의 W 성분입니다. (기본값: 1.0) | FLOAT | 아니요 | -1.0 ~ 1.0 (step: 0.001) |
| `qx` | 쿼터니언(w, x, y, z)의 X 성분입니다. (기본값: 0.0) | FLOAT | 아니요 | -1.0 ~ 1.0 (step: 0.001) |
| `qy` | 쿼터니언(w, x, y, z)의 Y 성분입니다. (기본값: 0.0) | FLOAT | 아니요 | -1.0 ~ 1.0 (step: 0.001) |
| `qz` | 쿼터니언(w, x, y, z)의 Z 성분입니다. (기본값: 0.0) | FLOAT | 아니요 | -1.0 ~ 1.0 (step: 0.001) |

**참고:** `mode`가 `"euler_xyz"`이고 세 각도가 모두 0.0이거나, `mode`가 `"quaternion"`이고 쿼터니언이 항등 쿼터니언(1, 0, 0, 0)이면 메시가 변경 없이 반환됩니다. 쿼터니언은 사용 전에 자동으로 정규화됩니다. 쿼터니언의 크기가 0에 너무 가까우면 노드에서 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `mesh` | 회전된 메시입니다. 정점이 회전되고 법선은 방향 벡터로 회전됩니다. 탄젠트의 X, Y, Z 성분은 회전되고, W(손방향) 성분은 변경되지 않은 채 유지됩니다. | MESH |
