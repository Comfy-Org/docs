이 노드는 Stable Diffusion 3 컨디셔닝에 ControlNet 가이던스를 적용합니다. 긍정(positive) 및 부정(negative) 컨디셔닝 입력과 ControlNet 모델 및 이미지를 받아 강도와 타이밍 매개변수를 조절하여 제어 가이던스를 적용함으로써 생성 과정에 영향을 줍니다.

**참고:** 이 노드는 더 이상 사용되지 않는(deprecated) 것으로 표시되었으며 향후 버전에서 제거될 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `긍정 조건` | ControlNet 가이던스를 적용할 긍정 컨디셔닝 | CONDITIONING | 예 | - |
| `부정 조건` | ControlNet 가이던스를 적용할 부정 컨디셔닝 | CONDITIONING | 예 | - |
| `컨트롤넷` | 가이던스에 사용할 ControlNet 모델 | CONTROL_NET | 예 | - |
| `vae` | 프로세스에 사용되는 VAE 모델 | VAE | 예 | - |
| `이미지` | ControlNet이 가이던스로 사용할 입력 이미지 | IMAGE | 예 | - |
| `강도` | ControlNet 효과의 강도(기본값: 1.0). 0.0으로 설정하면 노드가 ControlNet 적용을 건너뛰고 컨디셔닝을 변경 없이 반환합니다. | FLOAT | 예 | 0.0 - 10.0 |
| `시작 퍼센트` | 생성 과정에서 ControlNet이 적용되기 시작하는 지점(기본값: 0.0) | FLOAT | 예 | 0.0 - 1.0 |
| `종료 퍼센트` | 생성 과정에서 ControlNet 적용이 중지되는 지점(기본값: 1.0) | FLOAT | 예 | 0.0 - 1.0 |

**참고:** `strength`를 0.0으로 설정하면 ControlNet 가이던스가 적용되지 않으며 입력 컨디셔닝이 변경 없이 두 출력 모두에 그대로 전달됩니다.

**참고:** 동일한 컨디셔닝이 다른 곳에서 재사용되어 이미 제어 정보를 포함하고 있는 경우, 새 ControlNet은 이전 ControlNet 뒤에 연결되므로 여러 ControlNet을 순차적으로 적용할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |

| `긍정 조건` | ControlNet 가이던스가 적용된 수정된 긍정 컨디셔닝 | CONDITIONING |
| `부정 조건` | ControlNet 가이던스가 적용된 수정된 부정 컨디셔닝 | CONDITIONING |
