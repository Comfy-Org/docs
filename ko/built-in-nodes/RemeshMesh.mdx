Remesh Mesh는 원본 표면 주변의 협대역 거리 필드를 샘플링하고 Dual Contouring으로 추출하여 깨끗하고 균일한 테셀레이션으로 메시를 리메시합니다. 이는 지저분하거나 논매니폴드이거나 자기 교차하는 토폴로지를 정규화하며, 정확한 면 수에 도달하기 위해 Decimate Mesh 전에 실행하는 것을 목적으로 합니다. 처리는 활성 컴퓨팅 장치에서 실행되며 출력 메시는 웰드된 상태로 유지됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `메시` | 리메시할 입력 메시입니다. | MESH | 예 | — |
| `해상도` | 복셀 그리드 해상도(출력 밀도)입니다. 256은 약 10만 면, 512는 약 100만 면입니다. 정확한 면 수를 원하면 Decimate Mesh를 이어서 실행하십시오. (기본값: 512) | INT | 예 | 32 - 2048 |
| `sign_mode` | 표면 추출 모드입니다. "udf"는 지저분하거나 논매니폴드 입력에 강건하며, "sdf"는 QEF(Quadratic Error Function) 샤프 특징 복구를 통해 깨끗한 단일 표면을 생성하지만 일관된 와인딩이 필요합니다. 모드를 선택하면 해당 모드의 특정 하위 옵션이 나타납니다. (기본값: "udf") | DYNAMIC_COMBO | 예 | "udf"<br />"sdf" |
| `band` | 복셀 단위의 협대역 폭입니다. UDF 모드에서는 표면도 오프셋합니다. (고급, 기본값: 1.0) | FLOAT | 예 | 0.5 - 4.0 |
| `project_back` | 정점을 원본 표면 방향으로 선형 보간합니다(0 = 순수 DC, 1 = 스냅됨). (고급, 기본값: 0.0) | FLOAT | 예 | 0.0 - 1.0 |
| `fix_poles` | 밸런스(valence) 3 정점 쌍을 축소합니다(DC T-정션 아티팩트). (고급, 기본값: false) | BOOLEAN | 예 | true / false |
| `smooth_iters` | Taubin 스무딩 반복 횟수입니다(0 = 끔). 2-3은 DC 계단형 아티팩트를 정리하고, 더 높은 값은 QEF 에지를 과도하게 스무딩합니다. (기본값: 0) | INT | 예 | 0 - 20 |
| `drop_small_components` | 가장 큰 구성 요소의 면 수에 대한 이 비율 미만인 구성 요소를 제거합니다. 0은 비활성화합니다. (고급, 기본값: 0.01) | FLOAT | 예 | 0.0 - 0.5 |
| `precluster_max_verts` | 필드 쿼리 전에 입력 정점 수를 제한합니다. 이 값보다 큰 입력은 먼저 이 값으로 클러스터 데시메이트됩니다. 거대한 메시에서 OOM을 방지합니다. (고급, 기본값: 20,000,000) | INT | 예 | 0 - 100,000,000 |

### "udf" 모드 입력

이 매개변수들은 `sign_mode`가 `"udf"`로 설정되었을 때 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `qef` | 더 날카로운 에지를 위한 QEF(Quadratic Error Function) 듀얼 정점 배치입니다. (고급, 기본값: false) | BOOLEAN | 아니요 | true / false |
| `drop_inverted_components` | 내향 법선(음수 부피) 닫힌 구성 요소, 즉 UDF 내부 셸을 제거합니다. (고급, 기본값: false) | BOOLEAN | 아니요 | true / false |
| `drop_enclosed_components` | 가장 큰 구성 요소의 bbox 내부에 있으면서 메시 내부 점 판정(point-in-mesh) 레이캐스트에 실패하는 구성 요소를 제거합니다. 정당한 중첩 부품에는 비활성화하십시오. (고급, 기본값: false) | BOOLEAN | 아니요 | true / false |

### "sdf" 모드 입력

이 매개변수들은 `sign_mode`가 `"sdf"`로 설정되었을 때 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `qef` | QEF(Quadratic Error Function) 듀얼 정점 배치(샤프 특징 복구)와 에지 교차 중심점 중 선택합니다. (기본값: true) | BOOLEAN | 아니요 | true / false |
| `manifold` | Manifold Dual Contouring: 다중 시트 케이스에서 복셀당 1-4개의 듀얼 정점을 사용합니다. 더 느립니다. (기본값: false) | BOOLEAN | 아니요 | true / false |

참고: `qef` 옵션의 기본값은 선택한 모드에 따라 다릅니다. "udf" 모드에서는 false이고, "sdf" 모드에서는 true입니다. `precluster_max_verts`가 0보다 크고 입력 메시의 정점 수가 이 값보다 많으면, 메시는 필드 쿼리 전에 해당 목표값까지 클러스터 데시메이트됩니다. 처리 후 노드는 입력에서 출력으로의 면 수 변화를 노드에 표시합니다(예: "faces: 1.23M → 200K (-84%)").

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-----------|-----------|
