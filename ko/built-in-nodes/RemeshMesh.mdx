Remesh Mesh는 원본 표면 주변의 좁은 대역 거리 필드를 샘플링하고 Dual Contouring으로 추출하여 깨끗하고 균일한 테셀레이션으로 메시를 재구축합니다. 이는 지저분하거나 비매니폴드이거나 자기 자신과 교차하는 토폴로지를 정규화하며, 정확한 면 수를 얻기 위해 Decimate Mesh 전에 실행하도록 설계되었습니다. 처리는 활성 컴퓨트 디바이스에서 실행되며 출력 메시는 용접된(welded) 상태로 유지됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `메시` | 리메시할 입력 메시입니다. | MESH | 예 | — |
| `해상도` | 복셀 그리드 해상도(출력 밀도)입니다. 256은 약 10만 개의 면, 512는 약 100만 개의 면을 생성합니다. 정확한 면 수가 필요하면 Decimate Mesh를 이어서 실행하세요. (기본값: 512) | INT | 예 | 32 - 2048 |
| `sign_mode` | 표면 추출에 사용되는 부호 거리(signed-distance) 모드입니다. "udf"는 지저분하거나 비매니폴드인 입력에 강건하며, "sdf"는 QEF(Quadratic Error Function) 날카로운 특징 복원을 통해 깨끗한 단일 표면을 생성하지만 일관된 와인딩(winding)이 필요합니다. 모드를 선택하면 해당 모드의 세부 하위 옵션이 표시됩니다. (기본값: "udf") | DYNAMIC_COMBO | 예 | "udf"<br />"sdf" |
| `band` | 복셀 단위의 좁은 대역 폭입니다. UDF 모드에서는 표면도 오프셋합니다. (고급, 기본값: 1.0) | FLOAT | 예 | 0.5 - 4.0 |
| `project_back` | 원래 표면 방향으로 정점을 선형 보간합니다(0 = 순수 DC, 1 = 스냅됨). (고급, 기본값: 0.0) | FLOAT | 예 | 0.0 - 1.0 |
| `fix_poles` | valence-3(차수 3) 정점 쌍을 축소합니다(DC T-접합 아티팩트). (고급, 기본값: false) | BOOLEAN | 예 | true / false |
| `smooth_iters` | Taubin 스무딩 반복 횟수입니다(0 = 꺼짐). 2~3회는 DC 계단형 아티팩트를 정리하며, 그 이상은 QEF 모서리를 과도하게 스무딩합니다. (기본값: 0) | INT | 예 | 0 - 20 |
| `drop_small_components` | 가장 큰 컴포넌트의 면 수 대비 이 비율 미만인 컴포넌트를 제거합니다. 0이면 비활성화됩니다. (고급, 기본값: 0.01) | FLOAT | 예 | 0.0 - 0.5 |
| `precluster_max_verts` | 필드 쿼리 전에 입력 정점 수를 제한합니다. 이 값보다 큰 입력은 먼저 클러스터 디시메이션으로 이 값까지 줄입니다. 거대한 메시에서 OOM(메모리 부족)을 방지합니다. (고급, 기본값: 20,000,000) | INT | 예 | 0 - 100,000,000 |

### "udf" 모드 입력

이 매개변수들은 `sign_mode`가 `"udf"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `qef` | QEF(Quadratic Error Function) 이중 정점 배치로 더 날카로운 모서리를 생성합니다. (기본값: false) | BOOLEAN | 아니요 | true / false |
| `drop_inverted_components` | 안쪽을 향한 법선(음의 부피)을 가진 닫힌 컴포넌트를 제거합니다 — UDF 내부 셸(shell)입니다. (기본값: false) | BOOLEAN | 아니요 | true / false |
| `drop_enclosed_components` | 가장 큰 컴포넌트의 경계 상자(bbox) 내부에 있으면서 메시 내부 점(point-in-mesh) 레이캐스트에 실패하는 컴포넌트를 제거합니다. 정당한 중첩 부품이 있는 경우 비활성화하세요. (기본값: false) | BOOLEAN | 아니요 | true / false |

### "sdf" 모드 입력

이 매개변수들은 `sign_mode`가 `"sdf"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `qef` | QEF(Quadratic Error Function) 이중 정점 배치(날카로운 특징 복원)와 모서리 교차 중심점(edge-crossing centroid) 중 선택합니다. (기본값: true) | BOOLEAN | 아니요 | true / false |
| `manifold` | 매니폴드 Dual Contouring: 다중 시트(multi-sheet) 경우에 복셀당 이중 정점 1~4개를 생성합니다. 더 느립니다. (기본값: false) | BOOLEAN | 아니요 | true / false |

참고: `qef` 옵션의 기본값은 선택한 모드에 따라 다릅니다. "udf" 모드에서는 false이고 "sdf" 모드에서는 true입니다. `precluster_max_verts`가 0보다 크고 입력 메시의 정점 수가 이 값보다 많으면, 메시는 필드 쿼리 전에 해당 목표치까지 클러스터 디시메이션됩니다. 처리 후 노드는 입력 대비 출력 면 수의 변화를 노드에 표시합니다(예: "faces: 1.23M → 200K (-84%)").
