이 노드는 완료된 Tripo 3D 모델 작업의 ID를 Tripo API로 전송하고 해당 모델을 리깅할 수 있는지 확인합니다. 검사가 완료될 때까지 기다린 다음, 예/아니요 결과와 Tripo가 해당 모델에 권장하는 스켈레톤 유형을 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | 분석할 모델의 Tripo 작업 ID입니다. 이전에 생성되었거나 가져왔거나 그 밖의 방식으로 Tripo 작업을 통해 만들어진 모델을 식별합니다. | MODEL_TASK_ID | 예 | N/A |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `riggable` | 모델을 리깅할 수 있는지 여부입니다. | BOOLEAN |
| `rig_type` | 권장 스켈레톤: biped, quadruped, hexapod, octopod, avian, serpentine 또는 aquatic; 모델을 리깅할 수 없을 때는 'others'입니다. | STRING |
