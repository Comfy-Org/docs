PixVerse API를 사용하여 두 입력 이미지 간의 전환 비디오를 생성합니다. 시작 이미지와 종료 이미지를 제공하면 노드는 텍스트 프롬프트와 선택한 설정에 따라 한 이미지에서 다른 이미지로 전환되는 부드러운 비디오를 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `시작 프레임` | 비디오 전환의 시작 이미지입니다. | IMAGE | 예 | - |
| `끝 프레임` | 비디오 전환의 종료 이미지입니다. | IMAGE | 예 | - |
| `프롬프트` | 비디오 생성용 프롬프트입니다. (기본값: 빈 문자열) | STRING | 예 | - |
| `품질` | 비디오 품질 설정입니다. (기본값: `"540p"`) | COMBO | 예 | `"360p"`<br />`"540p"`<br />`"720p"`<br />`"1080p"` |
| `길이(초)` | 비디오 길이(초)입니다. | COMBO | 예 | `5`<br />`8` |
| `모션 모드` | 전환의 모션 스타일입니다. (기본값: `"normal"`) | COMBO | 예 | `"normal"`<br />`"fast"` |
| `시드` | 비디오 생성용 시드입니다. (기본값: 0) | INT | 예 | 0 ~ 2147483647 |
| `부정 프롬프트` | 이미지에서 원치 않는 요소에 대한 선택적 텍스트 설명입니다. (기본값: 빈 문자열) | STRING | 아니요 | - |

**매개변수 제약 사항 참고:** 1080p 품질을 사용하는 경우 모션 모드가 자동으로 `"normal"`로 설정되고 비디오 길이는 5초로 제한됩니다. 5초가 아닌 비디오 길이의 경우에도 모션 모드가 자동으로 `"normal"`로 설정됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `output` | 생성된 전환 비디오입니다. | VIDEO |
