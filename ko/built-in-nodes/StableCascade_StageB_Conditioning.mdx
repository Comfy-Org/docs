StableCascade_StageB_Conditioning 노드는 기존 컨디셔닝 정보를 Stage C에서 생성된 prior 잠재 표현과 결합하여 Stable Cascade Stage B 생성을 위한 컨디셔닝 데이터를 준비합니다. 각 컨디셔닝 항목을 복사하고 Stage C 잠재 샘플을 저장하여, 이후 생성 단계에서 이 prior 정보를 사용해 더 일관된 결과를 얻을 수 있도록 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `조건` | Stage C prior 정보로 수정할 컨디셔닝 데이터입니다. 목록의 각 항목은 복사되어 Stage C 샘플이 할당됩니다. | CONDITIONING | 예 | - |
| `StageC 잠재 이미지` | Stage C의 잠재 표현입니다. 해당 `samples` 값은 컨디셔닝에 추가되는 prior 정보로 사용됩니다. | LATENT | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `CONDITIONING` | Stage C prior 정보가 통합된 수정된 컨디셔닝 데이터입니다. | CONDITIONING |
