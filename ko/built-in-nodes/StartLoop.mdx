Start Loop 노드는 워크플로 내부에서 반복 구조를 시작합니다. 연결된 루프 본문을 반복마다 한 번씩 실행하며, 세 가지 방식으로 반복 횟수를 계산할 수 있습니다: 고정된 반복 횟수(simple), 숫자 인덱스 범위(For), 목록의 항목당 한 번(List). 각 반복 실행은 현재 인덱스, 처음/마지막 플래그, 그리고 한 반복에서 다음 반복으로 전달할 수 있는 선택적 전달 값을 노출합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모드` | 루프 반복 모드입니다(기본값: "simple"). 선택한 모드에 따라 표시되는 추가 매개변수가 결정됩니다. | DYNAMIC_COMBO | 예 | `"simple"`<br />`"For"`<br />`"List"` |
| `cache_iterations` | 이전 실행에서 변경되지 않은 반복 결과를 재사용합니다. 비활성화하면 모든 반복을 다시 실행합니다. 기본값: false. | BOOLEAN | 예 | true<br />false |
| `parent_iteration` | 이 루프를 중첩하려면 외부 Start Loop의 iteration_index를 연결합니다. 이 입력은 강제 입력(force-input) 전용이며 링크가 필요합니다. | INT | 아니요 | 임의의 정수 |
| `initial_iteration_value` | 첫 번째 반복에서 current_iteration_value로 노출되는 값입니다. | ANY (type-matched) | 아니요 | 모든 값 |

### Simple 모드 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `num_iterations` | 루프 본문을 실행할 횟수입니다. 기본값: 4. | INT | 예 | 최소 0 |

### For 모드 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `start_iteration_index` | For 루프 모드를 사용할 때 첫 번째 반복의 인덱스입니다. 기본값: 0. | INT | 예 | 임의의 정수 |
| `max_iteration` | For 모드에서 iteration_index의 종료 값(해당 값은 포함하지 않음)입니다. 기본값: 4. | INT | 예 | 최대 0xffffffffffffffff |
| `step` | For 루프 모드를 사용할 때 각 반복 사이의 인덱스 증가 폭입니다. 기본값: 1. | INT | 예 | 최소 1 |

### List 모드 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `list` | 루프가 반복 처리할 항목의 목록입니다. 루프 본문은 항목마다 한 번씩 실행됩니다. | ANY (type-matched list item) | 예 | 모든 목록 |

참고:

- 현재 선택된 `mode`에 속하는 매개변수만 표시되고 사용됩니다.
- Simple 모드에서 반복 인덱스는 0부터 `num_iterations` - 1까지 실행됩니다. For 모드에서 인덱스는 `start_iteration_index`부터 `max_iteration` 전까지(해당 값은 포함하지 않음) `step`씩 증가하며 실행됩니다. List 모드에서는 `list`의 항목마다 한 번의 반복이 실행됩니다.
- `step`은 0이어서는 안 되며, 0이면 오류가 발생합니다. 1 미만의 값은 허용되지 않습니다.
- 계산된 반복 횟수가 0이면 `is_last` 출력이 true로 보고되고 루프 본문은 실행되지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `iteration_index` | 현재 루프 반복의 인덱스입니다. | INT |
| `is_first` | 루프의 첫 번째 반복 동안 true입니다. | BOOLEAN |
| `is_last` | 루프의 마지막 반복 동안 true입니다. | BOOLEAN |
| `list_item` | List 모드를 사용할 때 목록의 현재 항목입니다. Simple 및 For 모드에서는 None입니다. | ANY (type-matched) |
| `current_iteration_value` | 현재 반복에 대한 루프 전달 값입니다: 첫 번째 반복에서는 initial_iteration_value이고, 이후 각 반복에서는 End Loop의 next_iteration_value입니다. | ANY (type-matched) |
