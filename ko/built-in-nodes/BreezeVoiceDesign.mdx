작성된 설명으로부터 새로운 Breeze 음성을 생성합니다. 음성에 대한 설명과 음성이 말할 문장을 제공하세요. 음성은 해당 미리보기를 기반으로 만들어지며 계정에 저장됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `description` | 3~500자로 음성을 설명합니다: 나이, 성별, 억양, 어조, 속도. 기본값: 비어 있음. | STRING | 예 | 3~500자 |
| `preview_text` | 미리보기에서 새 음성이 말할 문장이며 최대 500자입니다. 음성이 이 미리보기를 기반으로 만들어지므로 선택한 언어로 작성하세요. 기본값: 비어 있음. | STRING | 예 | 1~500자 |
| `language` | 미리보기 텍스트의 언어입니다. English와 Chinese는 두 모델 중 하나를 사용할 수 있으며, 다른 언어는 Breeze TTS 2 Multilingual을 사용합니다. | DYNAMIC_COMBO | 예 | 여러 옵션 사용 가능 |
| `strength` | 음성이 설명을 얼마나 밀접하게 따르는지 설정합니다. 기본값: 4.0. | FLOAT | 아니요 | 1.0 ~ 10.0 (단계: 0.1) |
| `seed` | 노드의 재실행 여부를 제어합니다. 시드 값과 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 아니요 | 0 ~ 2147483647 |

### 언어 "English" 및 "Chinese" 입력

이 항목은 `language`가 English 또는 Chinese일 때만 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | `Breeze TTS 2` 또는 `Breeze TTS 2 Multilingual`. 기본값: `"Breeze TTS 2"`. | COMBO | 예 | `"Breeze TTS 2"`<br />`"Breeze TTS 2 Multilingual"` |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `voice` | 설명을 바탕으로 이름이 지정된 새로운 Breeze 음성입니다. | BREEZE_VOICE |
| `preview` | 설계된 음성의 오디오 미리보기입니다. | AUDIO |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/BreezeVoiceDesign/ko.md)
