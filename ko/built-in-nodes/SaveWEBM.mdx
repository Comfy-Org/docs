SaveWEBM 노드는 이미지 시퀀스를 WEBM 비디오 파일로 저장합니다. 여러 입력 이미지를 받아 구성 가능한 품질 설정과 프레임 레이트를 사용하여 VP9 또는 AV1 코덱으로 비디오로 인코딩합니다. 결과 비디오 파일은 프롬프트 정보를 포함한 메타데이터와 함께 출력 디렉터리에 저장됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | RGBA 이미지는 알파 채널을 투명도로 사용하여 저장됩니다(vp9 코덱 전용). | IMAGE | 예 | - |
| `파일명_접두사` | 출력 파일 이름의 접두사입니다(기본값: "ComfyUI"). | STRING | 아니요 | - |
| `코덱` | 인코딩에 사용할 비디오 코덱입니다. | COMBO | 예 | "vp9"<br />"av1" |
| `fps` | 출력 비디오의 프레임 레이트입니다(기본값: 24.0). | FLOAT | 아니요 | 0.01-1000.0 |
| `crf` | crf가 높을수록 품질은 낮아지고 파일 크기는 작아지며, crf가 낮을수록 품질은 높아지고 파일 크기는 커집니다(기본값: 32.0). | FLOAT | 아니요 | 0-63.0 |

**알파 채널 관련 참고:** RGBA 이미지의 알파 채널은 VP9 코덱을 사용할 때만 보존됩니다. AV1 코덱을 사용할 경우 알파 채널은 무시되고 RGB 데이터만 인코딩됩니다.

**파일 이름 지정 관련 참고:** 비디오는 출력 디렉터리에 `{filename_prefix}_{counter:05}_.webm` 형식으로 저장되며, 여기서 counter는 기존 파일을 덮어쓰지 않도록 자동으로 증가합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `images` | 비디오가 저장된 후 변경 없이 전달되는 입력 이미지입니다. | IMAGE |
| UI preview | 저장된 WEBM 파일을 보여주는 비디오 미리보기입니다. | PREVIEW |
