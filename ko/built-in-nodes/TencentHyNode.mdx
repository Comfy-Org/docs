이 노드는 Tencent의 Hy4 모델로 텍스트 응답을 생성합니다. 텍스트 프롬프트와 선택적으로 하나 이상의 이미지를 컨텍스트로 전송하고, 모델의 답변을 텍스트로 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 답변을 생성하는 데 사용되는 모델입니다. 선택하면 아래에 해당 입력이 표시됩니다. 기본값: `"Hy4"`. | DYNAMIC_COMBO | 예 | `"Hy4"` |

### Hy4 입력

이 입력은 `model`이 `"Hy4"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 모델에 보낼 메시지입니다. 비어 있으면 안 됩니다. 기본값: ""(빈 문자열). | STRING | 예 | 최소 1자 |
| `images` | 최대 20개 이미지입니다. 배치의 각 이미지가 개수에 포함됩니다. 기본값: 이미지 없음. | AUTOGROW | 아니요 | 0~20개 이미지 |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. 기본값: 42. | INT | 예 | 0 ~ 2147483647 |
| `system_prompt` | 모델의 동작을 규정하는 기본 지침입니다. 기본값: ""(빈 문자열). | STRING | 아니요 | - |
| `reasoning` | 모델이 답변 전에 사고합니다. 답변이 더 오래 걸리고 더 많은 토큰을 사용하며, 매우 어려운 작업은 시간 초과될 수 있습니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `temperature` | 무작위성을 제어합니다. 0에서도 결과는 여전히 달라집니다. 기본값: 1.0. | FLOAT | 예 | 0.0 ~ 1.4 (단계: 0.01) |
| `max_tokens` | 생성할 최대 토큰 수입니다. `reasoning`이 켜져 있으면 사고 토큰도 포함됩니다. 매우 긴 답변은 시간 초과될 수 있습니다. 기본값: 32000. | INT | 예 | 1 ~ 64000 |

**제약 조건:**

* 요청당 최대 20개 이미지가 허용되며, 배치의 각 이미지를 개별적으로 계산합니다.
* Tencent의 콘텐츠 필터가 요청을 차단할 수 있으며, 이 경우 오류가 발생합니다.
* 답변이 완료되기 전에 `max_tokens`가 소진되면 노드에서 오류가 발생합니다. `max_tokens`를 늘리거나 `reasoning`을 끄세요.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `STRING` | Hy4 모델의 텍스트 답변입니다. | STRING |
