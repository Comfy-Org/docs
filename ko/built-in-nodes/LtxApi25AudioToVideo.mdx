이 노드는 LTX 2.5 모델을 사용하여 오디오 트랙에 맞춰지는 비디오를 생성합니다. 오디오는 비디오 길이(2~20초)를 결정하며, 선택적으로 첫 프레임으로 사용할 이미지를 제공할 수 있습니다. 비디오는 LTX 2.5 API 서비스를 통해 생성됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `오디오` | 비디오를 구동하는 오디오 트랙입니다. 길이(2-20초)가 비디오 길이를 설정합니다. | AUDIO | 예 | 2-20 seconds |
| `모델` | 사용할 LTX 2.5 모델 버전입니다. 모델을 선택하면 해당 모델의 `resolution` 하위 옵션도 표시됩니다. | COMBO | 예 | "LTX-2.5 (Fast)"<br />"LTX-2.5 (Pro)" |
| `resolution` | 생성된 비디오의 출력 해상도입니다. 이 하위 옵션은 선택한 `model` 아래에 표시됩니다(기본값: "1920x1080"). 두 모델 모두 동일한 해상도 옵션을 제공합니다. | COMBO | 예 | "1920x1080"<br />"1080x1920" |
| `프롬프트` | 생성된 비디오의 내용을 안내하는 텍스트 설명입니다(기본값: ""). 최소 1자 이상, 최대 10000자 이하여야 합니다. | STRING | 예 | 1-10000 characters |
| `시드` | 생성의 무작위성을 제어하는 숫자입니다. 동일한 seed는 동일한 결과를 생성합니다(기본값: 42). | INT | 예 | Any integer |
| `이미지` | 비디오에 사용할 선택적 첫 프레임입니다. 이미지는 하나만 지원됩니다. | IMAGE | 아니요 | Single image |

제약 사항:
- 오디오 길이는 2~20초 사이여야 하며, 이 범위를 벗어나면 노드에서 오류가 발생합니다.
- `prompt`는 필수이며 비워 둘 수 없고, 1~10000자 사이여야 합니다.
- `image`를 제공하는 경우 입력 이미지는 하나만 허용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 제공된 오디오 트랙에 따라 생성된 비디오입니다. | VIDEO |
