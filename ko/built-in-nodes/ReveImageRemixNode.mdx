Reve Image Remix 노드는 Reve API를 사용하여 새 이미지를 생성합니다. 하나 이상의 참조 이미지와 텍스트 프롬프트를 결합하여 제공된 설명에 기반한 새로운 리믹스 이미지를 만듭니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 리믹싱에 사용할 모델 버전입니다. | DYNAMIC_COMBO | 예 | `"reve-remix@20250915"`<br />`"reve-remix-fast@20251030"` |
| `프롬프트` | 원하는 이미지에 대한 텍스트 설명입니다. 특정 이미지를 인덱스로 참조하기 위해 XML img 태그를 포함할 수 있습니다(예: `<img>0</img>`, `<img>1</img>` 등). (기본값: 비어 있음) | STRING | 예 | 1~2560자 |
| `업스케일` | 생성된 이미지를 업스케일합니다. 추가 비용이 발생할 수 있습니다. (기본값: "disabled") | DYNAMIC_COMBO | 아니요 | `"disabled"`<br />`"enabled"` |
| `배경 제거` | 생성된 이미지에서 배경을 제거합니다. 추가 비용이 발생할 수 있습니다. (기본값: false) | BOOLEAN | 아니요 | `true`<br />`false` |
| `시드` | 시드는 노드가 다시 실행되어야 하는지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. (기본값: 0) | INT | 아니요 | 0~2147483647 |

### 모델 입력 (reve-remix@20250915 및 reve-remix-fast@20251030 공통)

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | 출력 이미지의 가로세로 비율입니다. (기본값: "auto") | COMBO | 예 | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"3:2"`<br />`"2:3"`<br />`"4:3"`<br />`"3:4"`<br />`"1:1"` |
| `test_time_scaling` | 값이 높을수록 더 나은 이미지를 생성하지만 더 많은 크레딧을 소비합니다. (기본값: 1) | INT | 아니요 | 1~5 |

### 업스케일 입력 (`upscale`이 "enabled"로 설정된 경우 표시됨)

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `upscale_factor` | 업스케일 배율(2x, 3x 또는 4x)입니다. (기본값: 2) | INT | 아니요 | 2~4 |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `참고 이미지` | 확장 가능한 슬롯: 리믹스의 시각적 기반으로 사용할 1~6개의 이미지(`image_1`~`image_6`)를 연결합니다. 참조 이미지는 최소 1개 이상 필요합니다. | IMAGE | 예 | 1~6개 이미지 |

**참고:** 프롬프트는 1~2560자 사이여야 합니다. `aspect_ratio`가 "auto"로 설정된 경우 서비스가 출력 이미지의 가로세로 비율을 결정합니다. `test_time_scaling` 값이 1이면 표준 처리가 적용되며, 값이 높을수록 이미지 품질이 향상되지만 더 많은 크레딧을 소비합니다. `upscale_factor` 위젯은 `upscale`이 "enabled"로 설정된 경우에만 표시됩니다. 리믹스 결과는 시드 값과 관계없이 비결정적입니다. 이 노드는 더 이상 사용되지 않습니다(deprecated).

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | Reve 리믹스 프로세스로 생성된 새 이미지입니다. | IMAGE |
