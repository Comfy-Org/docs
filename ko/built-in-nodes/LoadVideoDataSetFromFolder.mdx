ComfyUI 입력 디렉토리 내의 선택한 폴더에서 지원되는 모든 비디오 파일을 로드하여 비디오 참조 목록으로 반환합니다. 이 노드는 지연 비디오 참조를 반환하므로 다른 노드가 실제로 필요할 때만 프레임이 디코딩됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `폴더` | 비디오 파일이 포함된 폴더입니다. ComfyUI 입력 디렉토리 내의 사용 가능한 하위 폴더에서 선택하세요. | STRING | 예 | ComfyUI 입력 디렉토리에서 사용 가능한 모든 하위 폴더 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
**참고:** 선택한 폴더에는 지원되는 비디오 파일이 하나 이상 포함되어야 합니다. 지원되는 확장자는 MP4, AVI, MOV, WEBM, MKV 및 FLV입니다. 지원되는 비디오 파일이 없으면 노드에서 오류가 발생합니다.
|-------------|-------------|-----------|
| `비디오` | 지연 비디오 참조 목록으로, 선택한 폴더의 각 비디오 파일에 대해 하나씩입니다. 출력이 다른 노드에서 사용될 때만 비디오 프레임이 디코딩됩니다. | VIDEO (list) |
