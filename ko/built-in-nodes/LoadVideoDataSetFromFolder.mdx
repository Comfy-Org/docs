ComfyUI 입력 디렉토리 내의 지정된 폴더에서 비디오 데이터셋을 로드합니다. 이 노드는 폴더를 스캔하여 지원되는 비디오 파일을 찾고 지연 참조(lazy references)를 반환합니다. 실제 프레임은 다운스트림에서 필요할 때만 디코딩됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `폴더` | 비디오 파일이 포함된 폴더입니다. ComfyUI 입력 디렉토리 내의 사용 가능한 하위 폴더에서 선택하세요. | STRING | 예 | *(입력 하위 폴더에서 채워집니다)* |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `비디오` | 지연 비디오 참조 목록입니다(파일당 하나). 출력이 다른 노드에서 사용될 때만 비디오 프레임이 디코딩됩니다. | VIDEO |
