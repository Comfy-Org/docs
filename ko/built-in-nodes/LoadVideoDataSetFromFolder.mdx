ComfyUI 입력 디렉터리 내에서 선택한 폴더로부터 비디오 데이터셋을 불러와 지연 비디오 참조 목록으로 반환합니다. 이 노드는 비디오 데이터셋을 불러옵니다: 프레임은 다른 노드가 실제로 필요로 할 때만 디코딩됩니다. 지원되는 형식은 MP4, AVI, MOV, WEBM, MKV, FLV입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `폴더` | 비디오 파일이 들어 있는 폴더입니다. | COMBO | 예 | ComfyUI 입력 디렉터리에서 사용 가능한 모든 하위 폴더(동적으로 채워짐) |

**참고:** 선택한 폴더는 ComfyUI 입력 디렉터리의 하위 폴더여야 하며, 지원되는 비디오 파일이 하나 이상 포함되어야 합니다. 지원되는 확장자는 MP4, AVI, MOV, WEBM, MKV, FLV입니다. 지원되는 비디오 파일을 찾지 못하거나 폴더 경로가 입력 디렉터리 외부에 있는 것으로 확인되면, 노드에서 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `videos` | 선택한 폴더에 있는 지원되는 비디오 파일마다 하나씩, 파일 이름 기준 알파벳순으로 정렬된 지연 비디오 참조 목록입니다. 비디오 프레임은 출력이 다른 노드에 의해 소비될 때만 디코딩됩니다. | VIDEO (list) |
