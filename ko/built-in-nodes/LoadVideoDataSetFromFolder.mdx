ComfyUI 입력 디렉터리 내의 선택한 폴더에서 지원되는 모든 비디오 파일(MP4, AVI, MOV, WEBM, MKV, FLV)을 로드하고, 이를 지연(lazy) 비디오 참조 목록으로 반환합니다. 프레임은 다운스트림의 다른 노드가 필요로 할 때만 디코딩됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `폴더` | 비디오 파일이 포함된 폴더입니다. ComfyUI 입력 디렉터리 내의 사용 가능한 하위 폴더에서 선택하십시오. | STRING | 예 | ComfyUI 입력 디렉터리에서 사용 가능한 모든 하위 폴더 |

**참고:** 선택한 폴더에는 지원되는 비디오 파일이 하나 이상 포함되어 있어야 합니다. 지원되는 확장자는 MP4, AVI, MOV, WEBM, MKV 및 FLV입니다. 지원되는 비디오 파일이 없으면 노드가 오류를 발생시킵니다. 폴더는 ComfyUI 입력 디렉터리 내의 위치로 확인되어야 합니다. 입력 디렉터리를 벗어나는 경로(예: ".." 사용)는 거부됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `비디오` | 선택한 폴더의 각 지원 비디오 파일에 대한 지연(lazy) 비디오 참조 목록입니다. 비디오 프레임은 출력이 다른 노드에서 소비될 때만 디코딩됩니다. | VIDEO (list) |
