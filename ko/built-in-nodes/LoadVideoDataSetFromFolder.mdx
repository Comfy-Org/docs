ComfyUI 입력 디렉토리 내의 선택된 폴더에서 비디오 데이터셋을 로드하고 해당 비디오들을 지연 비디오 참조 목록으로 반환합니다. 이 노드는 비디오 데이터셋을 로드합니다. 프레임은 다른 노드가 실제로 필요로 할 때만 디코딩됩니다. 지원되는 형식은 MP4, AVI, MOV, WEBM, MKV 및 FLV입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `폴더` | 비디오 파일이 포함된 폴더입니다. | COMBO | 예 | ComfyUI 입력 디렉토리에서 사용 가능한 모든 하위 폴더 (동적으로 채워짐) |

**참고:** 선택한 폴더는 ComfyUI 입력 디렉토리의 하위 폴더여야 하며 지원되는 비디오 파일을 하나 이상 포함해야 합니다. 지원되는 확장자는 MP4, AVI, MOV, WEBM, MKV 및 FLV입니다. 지원되는 비디오 파일이 없거나 폴더 경로가 입력 디렉토리 외부로 확인되면 노드에서 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `비디오` | 선택한 폴더에 있는 각 지원 비디오 파일에 대한 지연 비디오 참조 목록으로, 파일 이름을 기준으로 알파벳순으로 정렬됩니다. 비디오 프레임은 출력이 다른 노드에서 소비될 때만 디코딩됩니다. | VIDEO (list) |
