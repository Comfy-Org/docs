MiniMax Music3 Text Encode는 MiniMax Music3 CLIP 모델을 사용하여 텍스트 설명과 가사를 음악 생성용 음향 조건 시퀀스로 변환합니다. 이 노드는 변환된 CONDITIONING 데이터와 입력된 길이에 따라 계산된 실제 오디오 시간(초)을 반환합니다.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `clip` | MiniMax Music3 CLIP 모델로, 텍스트 인코딩과 조건 시퀀스 생성에 사용됩니다. | CLIP | 예 | - |
| `caption` | 생성할 음악을 설명하는 텍스트 내용입니다. 여러 줄 텍스트와 동적 프롬프트를 지원합니다. | STRING | 예 | - |
| `lyrics` | 음악 생성에 사용할 가사 텍스트입니다. 여러 줄 텍스트와 동적 프롬프트를 지원합니다. | STRING | 예 | - |
| `seed` | 생성 과정에 사용되는 재현 가능한 난수 시드입니다. 기본값: 0. | INT | 예 | 0 ~ 18446744073709551615（0xffffffffffffffff） |
| `max_duration` | 생성 음악의 최대 길이(초)로, 모델이 노래를 일찍 끝낼 수 있습니다. 기본값: 120.0. | FLOAT | 예 | 0.04 ~ 모델 최대 오디오 길이（MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND）, 스텝 0.04 |
| `cfg_scale` | 분류기 자유 안내(Classifier-Free Guidance) 스케일 계수입니다. 기본값: 모델 상수 CFG_SCALE. 고급 매개변수입니다. | FLOAT | 예 | 0.0 ~ 100.0, 스텝 0.1（소수점 2자리 유지） |
| `top_k` | 음향 토큰 선택에 사용되는 top-k 샘플링 값입니다. 기본값: 모델 상수 CFG_TOP_K. 고급 매개변수입니다. | INT | 예 | 1 ~ 모델 어휘 크기（C0_VOCAB_SIZE） |

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `conditioning` | 생성된 음향 조건 시퀀스로, 후속 음악 생성을 안내하는 데 사용됩니다. | CONDITIONING |
| `seconds` | 조건 시퀀스에 해당하는 실제 길이(초)입니다. | FLOAT |
