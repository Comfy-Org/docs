MiniMax Music3 Text Encode는 MiniMax Music3 CLIP 모델을 사용하여 텍스트 캡션과 가사를 음악 생성을 위한 음향 컨디셔닝 시퀀스로 변환합니다. 이 노드는 입력된 최대 지속 시간을 기반으로 계산된 실제 오디오 지속 시간(초)과 함께 결과 CONDITIONING 데이터를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 텍스트 인코딩 및 컨디셔닝 시퀀스 생성에 사용되는 MiniMax Music3 CLIP 모델입니다. | CLIP | 예 | - |
| `caption` | 생성할 음악을 설명하는 텍스트입니다. 여러 줄 텍스트와 동적 프롬프트를 지원합니다. | STRING | 예 | - |
| `가사` | 음악 생성에 사용될 가사 텍스트입니다. 여러 줄 텍스트와 동적 프롬프트를 지원합니다. | STRING | 예 | - |
| `시드` | 생성 과정에 사용되는 재현 가능한 무작위 시드입니다. 기본값: 0. | INT | 예 | 0 ~ 18446744073709551615 (0xffffffffffffffff) |
| `max_duration` | 최대 지속 시간(초)입니다. 모델이 노래를 더 일찍 종료할 수 있습니다. 기본값: 120.0. | FLOAT | 예 | 0.04 ~ 모델의 최대 오디오 지속 시간(MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND), 간격 0.04 |
| `cfg_scale` | Classifier-free guidance 스케일입니다. 기본값: 모델 상수 CFG_SCALE. 고급 매개변수입니다. | FLOAT | 예 | 0.0 ~ 100.0, 간격 0.1 (소수점 둘째 자리까지 유지) |
| `top_k` | 음향 토큰 선택에 사용되는 Top-k 샘플링 값입니다. 기본값: 모델 상수 CFG_TOP_K. 고급 매개변수입니다. | INT | 예 | 1 ~ 모델의 어휘 크기(C0_VOCAB_SIZE) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `conditioning` | 생성된 음향 컨디셔닝 시퀀스로, 후속 음악 생성을 안내하는 데 사용됩니다. | CONDITIONING |
| `초` | 컨디셔닝 시퀀스의 실제 지속 시간(초)입니다. | FLOAT |
