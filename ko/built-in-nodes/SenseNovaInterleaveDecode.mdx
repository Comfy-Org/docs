SenseNova Conditioning이 남긴 인터리브 기록을 사용 가능한 텍스트, 이미지, 사고(thinking)로 변환합니다. 루프 끝에서 End Loop accumulate를 비활성화한 상태로 실행하여 모델이 한 번의 패스에서 생성한 모든 것을 수집합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 생성된 토큰을 디코딩하는 데 사용되는 SenseNova CLIP 모델입니다. | CLIP | 예 | - |
| `conditioning` | SenseNova Conditioning의 인터리브 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `samples` | 마지막 KSampler 픽셀 latent로, 루프가 이미지 요청에서 끝난 경우 필요합니다. | LATENT | 아니요 | - |

**제약 사항 및 동작:**

* `conditioning`은 `interleave` 또는 `self-correction` 작업의 SenseNova Conditioning에서 와야 하며, 그 외의 경우 오류가 발생합니다.
* 모델이 이미지를 기다리는 경우 샘플러의 LATENT 출력을 `samples`에 연결합니다.
* 실행 시작 시 연결된 참조 이미지는 출력에서 제외되며, 생성된 이미지가 없으면 이미지 소비자는 건너뜁니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `text` | 인터리브 기록에서 디코딩된 텍스트로, 이미지 마커는 빈 줄로 대체됩니다. | STRING |
| `images` | 모델이 실행 중 생성한 이미지입니다. | IMAGE |
| `thinking` | 모델이 생성한 경우의 추론 텍스트입니다. | STRING |
