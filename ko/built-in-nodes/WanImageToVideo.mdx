WanImageToVideo 노드는 비디오 생성 작업을 위한 컨디셔닝 및 잠재 표현을 준비합니다. 빈 잠재 공간을 생성하며, 선택적으로 시작 이미지와 CLIP 비전 출력을 통합하여 비디오 생성 과정을 안내할 수 있습니다. 이 노드는 제공된 이미지와 비전 데이터를 기반으로 긍정 및 부정 컨디셔닝 입력을 모두 수정합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `긍정 조건` | 생성을 안내하기 위한 긍정 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `부정 조건` | 생성을 안내하기 위한 부정 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `vae` | 이미지를 잠재 공간으로 인코딩하기 위한 VAE 모델 | VAE | 예 | - |
| `너비` | 출력 비디오의 너비 (기본값: 832, 단계: 16) | INT | 예 | 16 to MAX_RESOLUTION |
| `높이` | 출력 비디오의 높이 (기본값: 480, 단계: 16) | INT | 예 | 16 to MAX_RESOLUTION |
| `길이` | 비디오의 프레임 수 (기본값: 81, 단계: 4) | INT | 예 | 1 to MAX_RESOLUTION |
| `배치 크기` | 배치로 생성할 비디오 수 (기본값: 1) | INT | 예 | 1 ~ 4096 |
| `clip_vision 출력` | 추가 컨디셔닝을 위한 선택적 CLIP 비전 출력 | CLIP_VISION_OUTPUT | 아니요 | - |
| `시작 이미지` | 선택적 시작 이미지로, 비디오 생성을 초기화합니다. 제공된 경우 이미지는 지정된 너비와 높이에 맞게 크기가 조정되며, 비디오의 첫 번째 프레임이 이 이미지로 초기화됩니다. 나머지 프레임은 중성 회색(0.5) 값으로 채워집니다. `length`를 초과하는 프레임은 무시됩니다. | IMAGE | 아니요 | - |

**참고:** `start_image`가 제공되면 노드는 VAE를 사용하여 이미지 시퀀스를 인코딩하고 컨디셔닝 입력에 마스크를 적용합니다. 마스크는 시작 이미지로 초기화된 프레임을 제외한 모든 프레임을 덮어, 생성이 제공된 이미지를 기반으로 진행될 수 있도록 합니다. 인코딩 시 이미지의 처음 세 개의 색상 채널(RGB)만 사용됩니다. `clip_vision_output` 매개변수가 제공되면 긍정 및 부정 입력 모두에 비전 기반 컨디셔닝을 추가합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `긍정 조건` | 이미지 및 비전 데이터가 통합된 수정된 긍정 컨디셔닝 | CONDITIONING |
| `부정 조건` | 이미지 및 비전 데이터가 통합된 수정된 부정 컨디셔닝 | CONDITIONING |
| `잠재 비디오` | 비디오 생성에 적합한 빈 잠재 공간 텐서, 형태: [batch_size, 16, ((length-1)//4)+1, height//8, width//8] | LATENT |
