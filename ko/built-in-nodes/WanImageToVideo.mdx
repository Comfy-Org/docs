WanImageToVideo 노드는 비디오 생성을 위한 컨디셔닝 및 잠재 표현을 준비합니다. 비디오를 위한 빈 잠재 공간을 생성하고, 선택적으로 시작 이미지와 CLIP 비전 출력을 포함하여 생성을 유도할 수 있습니다. 제공된 이미지와 비전 데이터로 `positive` 및 `negative` 컨디셔닝 입력이 모두 업데이트됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `긍정 조건` | 생성을 유도하는 데 사용되는 positive 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `부정 조건` | 생성을 유도하는 데 사용되는 negative 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `vae` | 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델 | VAE | 예 | - |
| `너비` | 생성되는 비디오의 너비 (기본값: 832, 단계: 16) | INT | 예 | 16 to MAX_RESOLUTION |
| `높이` | 생성되는 비디오의 높이 (기본값: 480, 단계: 16) | INT | 예 | 16 to MAX_RESOLUTION |
| `길이` | 비디오의 프레임 수 (기본값: 81, 단계: 4) | INT | 예 | 1 to MAX_RESOLUTION |
| `배치 크기` | 한 배치에서 생성할 비디오 수 (기본값: 1) | INT | 예 | 1  ~  4096 |
| `clip_vision 출력` | `positive`와 `negative` 입력 모두에 추가 컨디셔닝으로 추가되는 선택적 CLIP 비전 출력 | CLIP_VISION_OUTPUT | 아니요 | - |
| `시작 이미지` | 비디오를 초기화하는 데 사용되는 선택적 시작 이미지입니다. 제공되면 지정된 `width`와 `height`로 크기가 조정되고 프레임 시퀀스의 시작 부분에 배치됩니다. `length`를 초과하는 프레임은 무시됩니다. 나머지 프레임은 중립 회색(0.5) 값으로 채워집니다. | IMAGE | 아니요 | - |

**참고:** `start_image`가 제공되면 프레임 시퀀스가 VAE로 인코딩되고 컨디셔닝에 마스크가 적용됩니다. 마스크는 시작 이미지가 차지하는 프레임에는 0으로, 나머지 프레임에는 1로 설정되어 제공된 이미지부터 생성이 이어집니다. 인코딩 중에는 이미지의 처음 세 색상 채널(RGB)만 사용됩니다. `positive` 및 `negative` 컨디셔닝은 모두 동일한 연결된 잠재 이미지, 마스크, 그리고 (제공된 경우) CLIP 비전 출력을 받습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `positive` | 이미지와 비전 데이터로 업데이트된 positive 컨디셔닝 | CONDITIONING |
| `negative` | 이미지와 비전 데이터로 업데이트된 negative 컨디셔닝 | CONDITIONING |
| `latent` | 비디오 생성을 위해 준비된 빈 잠재 텐서이며, 형태는 [batch_size, 16, ((length-1)//4)+1, height//8, width//8]입니다 | LATENT |
