Adjust Contrast 노드는 색상 범위의 중간점을 기준으로 밝은 영역과 어두운 영역 간의 차이를 스케일링하여 입력 이미지의 대비를 조정합니다. factor 값이 1.0이면 이미지가 변경되지 않으며, 1.0 미만이면 대비가 감소하고, 1.0 초과이면 대비가 증가합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `image` | 대비를 조정할 입력 이미지입니다. | IMAGE | 예 | - |
| `factor` | 대비 계수입니다. 1.0 = 변경 없음, &lt;1.0 = 대비 감소, >1.0 = 대비 증가. (기본값: 1.0) | FLOAT | 아니요 | 0.0 - 2.0 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `images` | 대비가 조정된 결과 이미지입니다. 픽셀 값은 0.0~1.0 범위로 제한됩니다. 입력 이미지에 알파 채널이 있는 경우 해당 채널은 변경되지 않고 그대로 유지됩니다. | IMAGE |
