텍스트 지침을 사용하여 기존 오디오 샘플의 일부를 변환합니다. 이 노드는 설명형 프롬프트를 제공하여 오디오의 특정 구간을 수정할 수 있게 하며, 나머지 오디오는 유지하면서 선택한 부분을 효과적으로 "인페인팅"하거나 재생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 오디오 인페인팅에 사용할 AI 모델입니다. | STRING | 예 | `"stable-audio-2.5"` |
| `prompt` | 오디오가 어떻게 변환되어야 하는지 안내하는 텍스트 설명입니다(기본값: 비어 있음). 최대 길이는 10,000자입니다. | STRING | 예 |  |
| `audio` | 변환할 입력 오디오 파일입니다. 오디오 길이는 6초에서 190초 사이여야 합니다. | AUDIO | 예 |  |
| `duration` | 생성되는 오디오의 길이(초)를 제어합니다(기본값: 190). | INT | 아니요 | 1~190 |
| `seed` | 생성에 사용되는 무작위 시드입니다(기본값: 0). | INT | 아니요 | 0~4294967294 |
| `steps` | 샘플링 단계 수를 제어합니다(기본값: 8). | INT | 아니요 | 4~8 |
| `mask_start` | 변환할 오디오 구간의 시작 위치(초)입니다(기본값: 30). | INT | 아니요 | 0~190 |
| `mask_end` | 변환할 오디오 구간의 끝 위치(초)입니다(기본값: 190). | INT | 아니요 | 0~190 |

**참고:** `mask_end` 값은 `mask_start` 값보다 커야 합니다. 입력 오디오의 길이는 6초에서 190초 사이여야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `audio` | 프롬프트에 따라 지정된 구간이 수정된 변환 오디오 출력입니다. | AUDIO |
