**Higgsfield Genjutsu Motion Transfer** 노드는 원본 클립의 모션, 카메라 움직임, 타이밍 및 오디오를 유지하면서 참조 이미지에서 가져온 새로운 캐릭터, 장소 또는 스타일로 비디오를 재구성합니다. 스타일을 변경할 클립과 새로운 모습을 설명하는 하나 이상의 참조 이미지를 연결한 다음, 프롬프트에 결과를 설명합니다. 요청은 Higgsfield API로 전송되며, 생성된 비디오가 반환됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 사용할 모델입니다. 모델을 선택하면 해당 모델에 특화된 매개변수인 `video`, `reference_images`, `prompt`, `resolution`, `seed`가 표시됩니다. | DYNAMIC_COMBO | 예 | `"genjutsu-v1.0"` |
| `video` | 모션, 카메라 움직임, 타이밍 및 오디오가 유지되는 소스 비디오입니다. 최소 4초 이상이어야 하며, 처음 30초만 사용됩니다. | VIDEO | 예 | 4~30초 |
| `reference_images` | 확장 가능한 슬롯: 사용할 캐릭터, 장소 또는 스타일의 이미지(`image_1`, `image_2`, ...)를 1~8개 연결합니다. 배치로 입력된 경우에도 이미지마다 하나씩 계산됩니다. | IMAGE | 예 | 이미지 1~8개 |
| `prompt` | 선택 사항입니다. 결과를 설명합니다. 예를 들어 어떤 참조가 어떤 인물을 대체하는지, 또는 새로운 설정을 설명할 수 있습니다. (기본값: 비어 있음) | STRING | 예 | 임의 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. (기본값: `"720p"`) | COMBO | 예 | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `seed` | `seed`는 노드를 다시 실행할지 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. 이 매개변수는 "control after generate" 기능을 가집니다. (기본값: 42) | INT | 예 | 0~2147483647 |

소스 비디오는 요청이 전송되기 전에 검증됩니다. 4초보다 짧은 클립은 거부되고, 30초보다 긴 클립은 처음 30초로 잘립니다. 클립의 오디오는 결과에 그대로 전달됩니다. 참조 이미지가 먼저 업로드되며, 노드가 8개의 슬롯을 노출하더라도 연결된 모든 슬롯의 총 이미지 수는 8개를 초과할 수 없습니다. Higgsfield의 콘텐츠 모더레이션은 입력 또는 결과를 거부할 수 있으며, 이 경우 비디오를 반환하는 대신 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 스타일이 변경된 비디오 파일입니다. | VIDEO |
