연결한 텍스트, 이미지, 오디오 또는 비디오를 1점에서 10점까지 평가하고, 점수와 함께 설정한 임계값에서 값이 바뀌는 불리언을 받습니다. 이를 사용하여 출력을 필터링하거나 정렬할 수 있습니다. 예를 들어 점수가 7점 이상인 이미지만 유지하고, `result`를 If/Else Switch 노드에 연결하여 그 결과에 따라 동작하게 할 수 있습니다. 한 번의 실행은 연결한 대상을 전체로 평가하므로, 개별 이미지를 필터링하려면 이미지를 하나씩 평가해야 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 사용할 모델입니다 (기본값: `"gemini-decision-1"`). | COMBO | 예 | `"gemini-decision-1"` |
| `question` | 평가할 내용과 1점과 10점의 의미를 설명합니다 (기본값: "Rate the technical quality of the image from 1 (worst) to 10 (best)."). | STRING | 예 | 1~5000자 |
| `threshold` | 점수가 이 값 이상일 때 `result`가 true가 됩니다. 깨끗하고 선명한 이미지는 약 7~8점, 심하게 손상된 이미지는 약 3~5점을 받습니다 (기본값: 6.0). | FLOAT | 예 | 1.0 ~ 10.0 (단계: 0.1) |
| `images` | 평가할 이미지로, 확장 가능한 슬롯(`image_1` ... `image_16`)을 통해 최대 16개까지 지정할 수 있습니다. 배치된 이미지는 이미지마다 한 번씩 집계됩니다. | IMAGE | 아니요 | 최대 16개 이미지 |
| `audio` | 평가할 오디오 클립입니다. | AUDIO | 아니요 | - |
| `video` | 평가할 비디오 클립입니다. | VIDEO | 아니요 | - |
| `text` | 질문의 대상이 되는 텍스트입니다. 예를 들어 프롬프트나 LLM 응답일 수 있으며, 최대 20000자까지 가능합니다. | STRING | 아니요 | 최대 20000자 |

`text`, `images`, `audio` 또는 `video` 중 하나 이상을 연결해야 합니다. 평가할 대상이 없으면 노드가 오류를 발생시킵니다. 이미지가 여러 개인 경우 질문 안에서 `image_1`, `image_2` 등으로 이름을 지정하세요.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `result` | 점수가 `threshold` 이상이면 true이고, 그렇지 않으면 false입니다. | BOOLEAN |
| `score` | 1부터 10까지의 평가 점수입니다. | FLOAT |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/GeminiDecisionScore/ko.md)
