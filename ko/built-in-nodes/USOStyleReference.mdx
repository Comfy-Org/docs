USOStyleReference 노드는 CLIP 비전 특징과 모델 패치를 결합하여 모델에 스타일 참조를 적용하고, 입력 모델의 패치된 복사본을 반환합니다. 시각적 스타일 정보는 생성에 영향을 줄 수 있도록 모델의 텍스트 컨디셔닝과 결합됩니다. 이 노드는 Flux 모델용이며 실험적으로 표시되어 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 스타일 참조 패치가 적용되는 기본 모델입니다. | MODEL | 예 | - |
| `모델 패치` | 참조 이미지 특징을 인코딩하는 데 사용되는 투영 모델을 포함하는 모델 패치입니다. | MODEL_PATCH | 예 | - |
| `CLIP 비전 출력` | 참조 이미지의 CLIP 비전 처리에서 추출된 인코딩된 시각적 특징입니다. | CLIP_VISION_OUTPUT | 예 | - |

참고: `clip_vision_output`은 전체 히든 상태와 끝에서 두 번째 히든 상태를 제공하는 CLIP 비전 모델에서 가져와야 합니다. 이 노드는 끝에서 20번째, 끝에서 11번째, 끝에서 두 번째 히든 상태를 결합하여 스타일 임베딩을 만듭니다. `model_patch`는 이러한 이미지 특징을 스타일 임베딩으로 변환하는 투영 모델을 해당 `model` 속성을 통해 노출해야 합니다. 샘플링 중에 스타일 임베딩은 생성에 영향을 줄 수 있도록 텍스트 컨디셔닝 앞에 추가되며, 일치하는 0 위치 텍스트 ID가 텍스트 ID 앞에 추가되어 식별자 시퀀스가 확장된 컨디셔닝과 정렬된 상태로 유지됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | 스타일 참조 패치가 적용된 수정된 모델입니다. | MODEL |
