HappyHorse 모델을 사용하여 텍스트 프롬프트를 기반으로 비디오를 생성합니다. 이 노드는 프롬프트와 설정을 HappyHorse API로 전송하고, 비디오가 생성될 때까지 대기한 후 결과를 다운로드합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 생성에 사용되는 HappyHorse 모델 및 해당 하위 매개변수입니다. 모델을 선택하면 사용 가능한 하위 매개변수가 결정됩니다(아래 모델 섹션 참조). | DYNAMIC_COMBO | 예 | "happyhorse-1.1-t2v"<br />"happyhorse-1.0-t2v" |
| `seed` | 생성에 사용할 시드입니다. 동일한 입력에 동일한 시드를 사용하면 동일한 결과가 생성됩니다. (기본값: 0). | INT | 예 | 0 ~ 2147483647 |
| `watermark` | 결과물에 AI 생성 워터마크를 추가할지 여부입니다. (기본값: False). | BOOLEAN | 예 | True / False |

### happyhorse-1.1-t2v 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 요소와 시각적 특징을 설명하는 프롬프트입니다. 영어와 중국어를 지원합니다. (기본값: ""). | STRING | 예 | - |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | "720P"<br />"1080P" |
| `ratio` | 출력 비디오의 화면 비율입니다. | COMBO | 예 | "16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4"<br />"21:9"<br />"9:21"<br />"5:4"<br />"4:5" |
| `duration` | 비디오 길이(초)입니다. (기본값: 5, 최소: 3, 최대: 15, 증가 단위: 1). | INT | 예 | 3 ~ 15 |

### happyhorse-1.0-t2v 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 요소와 시각적 특징을 설명하는 프롬프트입니다. 영어와 중국어를 지원합니다. (기본값: ""). | STRING | 예 | - |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | "720P"<br />"1080P" |
| `ratio` | 출력 비디오의 화면 비율입니다. | COMBO | 예 | "16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4" |
| `duration` | 비디오 길이(초)입니다. (기본값: 5, 최소: 3, 최대: 15, 증가 단위: 1). | INT | 예 | 3 ~ 15 |

참고: 프롬프트는 비어 있으면 안 됩니다. 프롬프트가 제공되지 않으면 오류가 발생합니다. 두 모델 모두 3~15초의 비디오 길이를 지원합니다. `happyhorse-1.1-t2v` 모델은 `happyhorse-1.0-t2v`에서 사용할 수 없는 추가 화면 비율(`21:9`, `9:21`, `5:4`, `4:5`)을 제공합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 생성된 비디오 파일입니다. | VIDEO |
