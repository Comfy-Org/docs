`CLIP Set Last Layer`는 CLIP 모델의 처리 깊이를 제어하기 위한 ComfyUI의 핵심 노드입니다. 사용자는 CLIP 텍스트 인코더가 처리를 중단하는 위치를 정밀하게 제어할 수 있으며, 이는 텍스트 이해의 깊이와 생성된 이미지의 스타일 모두에 영향을 줍니다. 원본 CLIP 모델은 변경되지 않습니다. 노드는 복사본에서 작동하고 수정된 복사본을 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | 수정할 CLIP 모델 | CLIP | 예 | - |
| `CLIP 레이어 중단점` | 어느 레이어에서 중지할지 지정합니다. 값이 -1이면 모든 레이어를 사용하고, -24이면 첫 번째 레이어만 사용합니다(기본값: -1). 이는 고급 매개변수입니다. | INT | 예 | -24 to -1 (단계: 1) |

값은 음수이며 모델의 끝에서부터 거꾸로 세어집니다. -1은 마지막(가장 깊은) 레이어를 가리키고, -24는 첫 번째(가장 얕은) 레이어를 가리킵니다. 따라서 허용 범위는 -24부터 -1까지만 포함합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `clip` | 지정된 레이어가 마지막 레이어로 설정된 수정된 CLIP 모델(입력의 복제본이며 원본 CLIP 모델은 변경되지 않음) | CLIP |

## 마지막 레이어를 설정하는 이유

- **성능 최적화**: 간단한 문장을 이해하는 데 박사 학위가 필요하지 않은 것처럼, 때로는 얕은 이해로 충분하며 더 빠릅니다
- **스타일 제어**: 이해 수준이 다르면 서로 다른 예술적 스타일이 생성됩니다
- **호환성**: 일부 모델은 특정 레이어에서 더 잘 수행할 수 있습니다

CLIP 모델을 24개 레이어로 구성된 지능형 뇌라고 상상해 보세요:

- 얕은 레이어(1-8): 기본 글자와 단어를 인식합니다
- 중간 레이어(9-16): 문법과 문장 구조를 이해합니다
- 깊은 레이어(17-24): 추상적 개념과 복잡한 의미를 파악합니다

`CLIP Set Last Layer`는 **"사고 깊이 컨트롤러"**처럼 작동합니다:

- -1: 24개 레이어를 모두 사용합니다(완전한 이해)
- -2: 레이어 23에서 중지합니다(약간 단순화됨)
- -12: 레이어 13에서 중지합니다(중간 수준 이해)
- -24: 레이어 1만 사용합니다(기본 이해)
