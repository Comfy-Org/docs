HeyGen Avatar 6로 연결한 오디오를 사용해 인물이 말하는 비디오를 생성하며, 사진이나 동영상을 참조 자료로 사용합니다. Avatar 6는 해당 참조 자료로부터 얼굴과 장면을 재구성하므로, 동일한 오디오로 정지 사진, 기존 클립 또는 두 가지 모두를 구동할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 모델 선택기로, 모델을 선택하면 아래에 해당 모델의 입력 항목이 표시됩니다. `"heygen-avatar-6-turbo"`는 더 저렴하고 빠른 등급입니다. | DYNAMIC_COMBO | 예 | `"heygen-avatar-6"`<br />`"heygen-avatar-6-turbo"` |

### `heygen-avatar-6` 입력

`"heygen-avatar-6-turbo"`는 동일한 제한을 가진 동일한 입력 항목을 제공합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 애니메이션할 사람 또는 캐릭터의 선택적 사진입니다. 외형과 장면을 설정하며 첫 프레임으로는 사용되지 않습니다. | IMAGE | 아니오 | 단일 이미지 |
| `video` | 애니메이션화되었거나 양식화된 캐릭터가 말하고 움직이는 방식을 보여주는 선택적 동영상입니다. 더 긴 동영상은 처음 30초로 잘립니다. | VIDEO | 아니오 | 2~30초 |
| `audio` | 아바타의 음성입니다. 동영상 길이는 오디오를 따릅니다. | AUDIO | 예 | 1.5초 ~ 10분 |
| `resolution` | 출력 동영상의 해상도입니다. 기본값: `"1080p"`. | COMBO | 예 | `"1080p"`<br />`"2k"` |
| `aspect_ratio` | 출력 동영상의 화면 비율입니다. `"auto"`는 이미지의 형태를 유지하며, 이미지가 연결되지 않은 경우에는 동영상의 형태를 유지합니다. 다른 값을 지정하면 장면을 다시 프레이밍합니다. 기본값: `"auto"`. | COMBO | 예 | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:5"`<br />`"5:4"` |
| `motion_prompt` | 제스처, 표정, 자세 및 카메라 움직임에 대한 선택적 지시 사항입니다. 기본값: 빈 문자열. | STRING | 예 | 여러 줄 텍스트, 최대 1200자 |
| `motion_expressiveness` | `"less"`는 더 적고 작은 동작을 생성합니다. 두 항목이 겹치는 부분에서는 motion prompt가 우선합니다. 기본값: `"default"`. | COMBO | 예 | `"less"`<br />`"default"` |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어하며, 시드와 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0 ~ 2147483647 |

**제약 사항 및 동작 방식:**

* 이미지, 동영상 또는 둘 다를 연결하십시오. 둘 다 연결하지 않으면 노드에서 오류가 발생합니다.
* 이미지 입력에는 배치가 아닌 정확히 하나의 이미지만 있어야 합니다.
* 실사 인물의 참조 동영상은 거부됩니다. 애니메이션화되었거나 양식화된 캐릭터의 동영상을 사용하거나, 대신 해당 인물의 사진을 연결하십시오.
* 참조 동영상은 2초 이상이어야 하며 50MB를 초과할 수 없습니다.
* 가격은 출력 동영상 1초당 책정되며 모델과 해상도에 따라 달라집니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 렌더링이 완료되면 HeyGen에서 다운로드되는 생성된 말하는 동영상입니다. | VIDEO |
