이미지를 마스크의 경계 상자(bounding box)로 크롭하여 단색 배경 위에 중앙 정렬된 피사체를 생성합니다. 이 노드는 마스크된 이미지를 선택한 배경 위에 합성하고 결과물을 지정된 출력 크기로 리사이즈하므로, 고정 해상도에서 중앙 정렬되고 배경이 없는 피사체를 필요로 하는 3D 파이프라인에 적합합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 크롭할 입력 이미지 또는 이미지 배치입니다. | IMAGE | 예 | — |
| `마스크` | 피사체 영역을 정의하는 마스크 또는 마스크 배치입니다. 단일 마스크는 모든 이미지에 적용되며, 그렇지 않은 경우 마스크 배치 크기가 이미지 배치 크기와 일치해야 합니다. 마스크 해상도가 이미지 해상도와 다른 경우 마스크는 자동으로 크기가 조정되어 일치합니다. | MASK | 예 | — |
| `너비` | 출력 너비(픽셀)입니다. (기본값: 1024) | INT | 예 | 64 ~ 4096 (step 8) |
| `높이` | 출력 높이(픽셀)입니다. (기본값: 1024) | INT | 예 | 64 ~ 4096 (step 8) |
| `pad_factor` | 마스크 경계 상자 주변의 추가 여백 배율입니다. (기본값: 1.0) | FLOAT | 예 | 1.0 ~ 2.0 (step 0.01) |
| `grow_mask` | 크롭 전에 마스크를 이 픽셀 수만큼 확장하거나 축소합니다. 양수 값은 마스크를 확장하고 음수 값은 축소합니다. (기본값: 0) | INT | 예 | -32 ~ 32 (step 1) |
| `배경` | 마스크된 피사체 뒤의 배경 색상입니다. (기본값: #000000) | COLOR | 예 | — |

참고: 크롭 영역은 마스크의 경계 상자에 중앙 정렬되며 종횡비는 `width` / `height`와 일치합니다. 이 노드는 반전된 마스크(경계를 따라 전경 픽셀이 있고 중앙이 배경인 경우)를 자동으로 감지하고 수정합니다. 마스크에 전경 픽셀이 없는 경우 노드는 반전된 마스크를 시도하며, 그 마스크도 비어 있으면 경고를 기록하고 전체 이미지를 크롭합니다. 마스크 배치 크기가 이미지 배치 크기와 일치하지 않고 단일 마스크도 아닌 경우 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `이미지` | 선택한 배경 색상 위에 마스크된 피사체가 있는 크롭된 합성 이미지로, `width` x `height`로 리사이즈됩니다. 배치 크기는 입력 이미지 배치와 일치합니다. | IMAGE |
