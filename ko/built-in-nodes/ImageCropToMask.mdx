## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 자르려는 입력 이미지 또는 이미지 배치입니다. | IMAGE | 예 | — |
| `마스크` | 피사체 영역을 정의하는 마스크 또는 마스크 배치입니다. 단일 마스크는 모든 이미지에 적용되며, 그렇지 않으면 마스크 배치 크기가 이미지 배치 크기와 일치해야 합니다. 마스크 해상도가 이미지 해상도와 다르면 마스크가 자동으로 일치하도록 크기 조정됩니다. | MASK | 예 | — |
| `너비` | 출력 너비(픽셀)입니다. (기본값: 1024) | INT | 예 | 64  ~  4096 (단계: 8) |
| `높이` | 출력 높이(픽셀)입니다. (기본값: 1024) | INT | 예 | 64  ~  4096 (단계: 8) |
| `pad_factor` | 마스크 경계 상자 주변에 추가되는 여백을 배수로 지정합니다. (기본값: 1.0) | FLOAT | 예 | 1.0  ~  2.0 (단계: 0.01) |
| `grow_mask` | 자르기 전에 마스크를 이 픽셀 수만큼 확장하거나 축소합니다. 양수 값은 마스크를 확장하고, 음수 값은 축소합니다. (기본값: 0) | INT | 예 | -32  ~  32 (단계: 1) |
| `배경` | 마스크된 피사체 뒤의 배경색입니다. (기본값: #000000) | COLOR | 예 | — |

참고: 자르기 영역은 마스크의 경계 상자를 중심으로 하며 가로세로 비율은 `width` / `height`와 일치합니다. 노드는 반전된 마스크(테두리를 따라 전경 픽셀이 있고 중앙에 배경이 있는 경우)를 자동으로 감지하고 보정합니다. 마스크에 전경 픽셀이 없으면 노드는 반전된 마스크를 시도합니다. 그것도 비어 있으면 경고를 기록하고 전체 이미지를 자릅니다. 마스크 배치 크기가 이미지 배치 크기와 일치하지 않고 단일 마스크도 아닌 경우 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `images` | 자른 합성 이미지(선택한 배경색 위에 마스크된 피사체)이며 `width` x `height`로 크기가 조정됩니다. 배치 크기는 입력 이미지 배치와 일치합니다. | IMAGE |
