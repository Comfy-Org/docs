BFL API를 통해 Flux.1 Kontext [pro]로 프롬프트와 종횡비를 기반으로 이미지를 생성하거나 편집합니다. `input_image`가 연결된 경우 프롬프트는 편집 내용을 설명합니다. 연결되지 않은 경우 노드는 프롬프트만으로 새 이미지를 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 이미지 생성을 위한 프롬프트입니다. 입력 이미지가 있는 경우 무엇을 어떻게 편집할지 지정합니다. | STRING | 예 | - |
| `aspect_ratio` | 이미지의 종횡비입니다. 1:4에서 4:1 사이여야 합니다(기본값: `"16:9"`). | STRING | 예 | - |
| `guidance` | 이미지 생성 과정의 가이던스 강도입니다(기본값: 3.0). | FLOAT | 예 | 0.1  ~  99.0 (단계: 0.1) |
| `steps` | 이미지 생성 과정의 단계 수입니다(기본값: 50). | INT | 예 | 1  ~  150 |
| `seed` | 노이즈 생성에 사용되는 무작위 시드입니다(기본값: 1234). | INT | 예 | 0  ~  18446744073709551615 |
| `prompt_upsampling` | 프롬프트에 업샘플링을 수행할지 여부입니다. 활성화하면 더 창의적인 생성을 위해 프롬프트가 자동으로 수정되지만, 결과가 비결정적이므로 동일한 시드로 정확히 같은 결과가 생성되지 않습니다(기본값: `False`). 고급 설정입니다. | BOOLEAN | 예 | True / False |
| `input_image` | 편집할 선택적 이미지입니다. 생략하면 프롬프트가 비어 있지 않은지 검증합니다. | IMAGE | 아니요 | - |

**참고:** 노드는 BFL에 요청을 보내고 이미지가 준비될 때까지 폴링합니다. BFL의 콘텐츠 검열에서 거부된 요청은 이미지를 반환하지 않고 실패합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 생성되거나 편집된 이미지입니다. | IMAGE |
