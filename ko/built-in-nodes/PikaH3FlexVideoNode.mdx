이 노드는 텍스트 프롬프트로부터 동기화된 오디오가 포함된 비디오를 생성하며, 선택적으로 첫 프레임, 마지막 프레임 또는 둘 모두를 기준으로 삼을 수 있습니다. Pika H3 Flex는 Pika가 추가 학습시킨 MiniMax H3 모델로, 한 번의 패스로 영상과 해당 사운드를 렌더링하며 해상도, 화면 비율, 길이를 설정할 수 있습니다. 프레임을 연결하지 않으면 텍스트-비디오로 실행되고, 프레임을 연결하면 이미지-비디오로 전환됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오에서 발생하는 일과 원하는 사운드를 포함합니다. 비어 있을 수 없습니다. 기본값: ""(빈 문자열). | STRING | 예 | 1~8000자 |
| `first_frame` | 오프닝 프레임으로 사용할 선택적 이미지입니다. 연결하면 텍스트-비디오 대신 이미지-비디오로 실행됩니다. | IMAGE | 아니요 | - |
| `last_frame` | 클로징 프레임으로 사용할 선택적 이미지입니다. `first_frame`과 함께 사용하거나 단독으로 사용할 수 있습니다. | IMAGE | 아니요 | - |
| `resolution` | 출력 해상도입니다. `"1080p"` 이상은 768p로 렌더링한 후 한 번 업스케일합니다. 480p에서 동일한 시드는 다른 비디오를 생성합니다. 기본값: `"768p"`. | COMBO | 예 | `"480p"`<br />`"768p"`<br />`"1080p"`<br />`"2k"`<br />`"4k"` |
| `aspect_ratio` | 출력 화면 비율입니다. `"auto"`는 연결된 첫 프레임을 따르고, 그렇지 않으면 프롬프트를 따릅니다. 기본값: `"auto"`. | COMBO | 예 | `"auto"`<br />`"21:9"`<br />`"16:9"`<br />`"3:2"`<br />`"4:3"`<br />`"5:4"`<br />`"1:1"`<br />`"4:5"`<br />`"3:4"`<br />`"2:3"`<br />`"9:16"`<br />`"9:21"` |
| `duration` | 초 단위 클립 길이입니다. 출력 길이는 프레임 그리드를 따릅니다. 5초는 124프레임으로, 약 5.17초입니다. 기본값: 5. | INT | 예 | 5~15초 |
| `rewrite_prompt` | Pika가 프롬프트를 먼저 확장하도록 합니다. 그러면 동일한 시드라도 실행할 때마다 다른 비디오가 생성됩니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `seed` | 샘플링용 시드입니다. `rewrite_prompt`가 꺼져 있으면 동일한 시드는 비디오를 정확히 반복하지만, 동일한 시드로 로컬 실행하면 다른 결과가 생성됩니다. 기본값: 42. | INT | 예 | 0~2147483647 |

**제약 사항:**

* 프롬프트는 1~8000자 사이여야 합니다.
* 과금은 선택한 해상도와 클립 길이를 따르며, 출력 초당 기준으로 계산됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 동기화된 오디오가 포함된 생성된 클립입니다. | VIDEO |
