이 노드는 샘플링 과정의 후반부에 여러 개의 이동된 패치 그리드 위치에 걸쳐 모델 출력을 평균화하여 HiDream-O1 모델이 생성한 이미지에서 보이는 이음새(seam)를 줄입니다. 약간 다른 이미지 정렬로 모델을 여러 번 실행한 다음 결과를 혼합하여 패치 경계에서 나타날 수 있는 격자 모양의 아티팩트를 상쇄합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 이음새 평활화를 적용할 HiDream-O1 모델입니다. | MODEL | 예 | - |
| `start_percent` | 평활화 효과가 켜지는 샘플링 진행률(0=시작, 1=끝)입니다 (기본값: 0.8). | FLOAT | 예 | 0.0 ~ 1.0 (단위: 0.01) |
| `end_percent` | 평활화 효과가 꺼지는 샘플링 진행률입니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 (단위: 0.01) |
| `pattern` | 이동된 그리드 위치의 배치입니다. `single_shift`: 자연 패치 그리드에서 한 번 통과하고 나머지는 오프셋을 적용합니다. `symmetric`: 모든 통과가 그리드 밖에서 이루어지며 원점을 기준으로 이동이 분할됩니다 (기본값: `"single_shift"`). | COMBO | 예 | `"single_shift"`<br />`"symmetric"` |
| `passes` | 게이트된 단계당 패스(모델 실행) 횟수입니다. `2` 또는 `4`는 고정된 횟수입니다. `ramp_2_4`와 `ramp_2_4_8`은 샘플링이 끝날수록 패스 횟수를 늘려 이음새가 가장 잘 보이는 곳에서 평활화를 강화합니다 (기본값: `"2"`). | COMBO | 예 | `"2"`<br />`"4"`<br />`"ramp_2_4"`<br />`"ramp_2_4_8"` |
| `blend` | 각 패스의 결과를 결합하는 방법입니다. `average`: 모든 패스의 동일 가중 평균입니다. `window`: 해닝(Hann) 창을 사용하여 각 패스의 중심에 더 높은 가중치를 부여하여 경계 아티팩트를 줄입니다. `median`: 픽셀별 중앙값을 사용하며, 랩어라운드로 인해 발생하는 이상치 패스를 배제할 수 있습니다 (기본값: `"average"`). | COMBO | 예 | `"average"`<br />`"window"`<br />`"median"` |
| `strength` | 원본 모델 출력(0.0)과 완전히 평활화된 결과(1.0) 사이의 보간을 제어합니다 (기본값: 1.0). | FLOAT | 예 | 0.0 ~ 1.0 (단위: 0.01) |

**매개변수 제약 참고 사항:**
- `strength`가 0.0 이하이거나 `end_percent`가 `start_percent`보다 작거나 같으면 평활화 효과가 적용되지 않습니다. 이 경우 노드는 모델을 변경하지 않은 채 반환합니다.
- `passes` 매개변수의 램프 옵션(`ramp_2_4`, `ramp_2_4_8`)은 `start_percent`와 `end_percent`가 범위를 정의할 때만 의미가 있습니다. 해당 범위를 진행하면서 샘플링이 진행됨에 따라 패스 횟수가 증가하기 때문입니다.
