연결한 텍스트, 이미지, 오디오 또는 비디오에 대해 예/아니요 질문을 하고, 라우팅에 사용할 불리언 값을 얻습니다. `result`를 If/Else Switch 노드에 연결하여 실행을 두 경로 중 하나로 보내고, 모델이 그렇게 답한 이유를 확인하고 싶을 때는 `answer`와 `probability`를 읽습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 사용할 모델입니다(기본값: `"gemini-decision-1"`). | COMBO | 예 | `"gemini-decision-1"` |
| `question` | 연결된 대상에 대해 묻는 예/아니요 질문이며, 최대 5000자입니다. 「예」에 해당하는 경우에 수행할 작업이 되도록 질문하세요(기본값: "Is there a person in the image?"). | STRING | 예 | 1~5000자 |
| `threshold` | `result`가 true가 되는 "yes"의 확률 임계값입니다. 명확한 yes 답변은 약 0.85~0.92의 점수를 받으므로, 0.9 이상으로 설정하면 그러한 답변을 많이 거부합니다(기본값: 0.5). | FLOAT | 예 | 0.01 ~ 0.99 (단계: 0.01) |
| `images` | 질문할 이미지로, 확장 가능한 슬롯(`image_1` ... `image_16`)에 걸쳐 최대 16개까지 지정할 수 있습니다. 배치된 이미지는 이미지마다 한 번씩 집계됩니다. | IMAGE | 아니요 | 최대 16개 이미지 |
| `audio` | 질문할 오디오 클립입니다. | AUDIO | 아니요 | - |
| `video` | 질문할 비디오 클립입니다. | VIDEO | 아니요 | - |
| `text` | 질문의 대상이 되는 텍스트로, 프롬프트나 LLM 응답 등이며 최대 20000자입니다. | STRING | 아니요 | 최대 20000자 |

`text`, `images`, `audio` 또는 `video` 중 하나 이상을 연결해야 합니다. 살펴볼 대상이 없으면 노드에서 오류가 발생합니다. 이미지가 여러 개인 경우 질문 안에서 이들을 `image_1`, `image_2` 등으로 지칭하세요. 배치는 프레임 단위로 확장되므로, 번호는 연결 순서에 따라 슬롯 전체의 개별 프레임을 셉니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `result` | "yes"일 확률이 `threshold`에 도달하면 true이고, 그렇지 않으면 false입니다. | BOOLEAN |
| `answer` | `result`와 동일한 `threshold`를 따르는 판정 결과이며, 문자열 `"yes"` 또는 `"no"`입니다. | STRING |
| `probability` | "yes"일 확률로, 0에서 1 사이의 값입니다. | FLOAT |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/GeminiDecisionYesNo/ko.md)
