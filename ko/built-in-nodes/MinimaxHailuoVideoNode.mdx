MiniMax Hailuo-02 모델을 사용하여 텍스트 프롬프트에서 비디오를 생성합니다. 첫 번째 프레임으로 시작 이미지를 선택적으로 제공하여 해당 이미지에서 이어지는 비디오를 만들 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `텍스트 프롬프트` | 비디오 생성을 안내하는 텍스트 프롬프트입니다. | STRING | 예 | - |
| `시드` | 노이즈 생성에 사용되는 무작위 시드입니다 (기본값: 0). | INT | 아니요 | 0 ~ 18446744073709551615 |
| `첫 번째 프레임 이미지` | 비디오 생성의 첫 번째 프레임으로 사용할 선택적 이미지입니다. | IMAGE | 아니요 | - |
| `프롬프트 최적화` | 필요 시 프롬프트를 최적화하여 생성 품질을 향상시킵니다 (기본값: True). | BOOLEAN | 아니요 | True<br />False |
| `지속 시간` | 출력 비디오의 길이(초)입니다 (기본값: 6). | COMBO | 아니요 | 6<br />10 |
| `해상도` | 비디오 디스플레이의 해상도입니다. 1080p는 1920x1080, 768p는 1366x768입니다 (기본값: "768P"). | COMBO | 아니요 | "768P"<br />"1080P" |

**참고:** `resolution`을 "1080P"로 설정하면 `duration`이 6초로 제한됩니다. `first_frame_image`가 제공되지 않으면 `prompt_text`는 비어 있지 않아야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오 파일입니다. | VIDEO |
