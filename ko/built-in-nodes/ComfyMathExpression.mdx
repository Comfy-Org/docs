ComfyMathExpression 노드는 텍스트로 작성한 수학 공식을 평가합니다. 공식에서는 `a`, `b`, `c`와 같은 문자 이름을 사용하여 노드의 입력값을 참조할 수 있으며, 확장 가능한 `values` 그룹을 통해 필요한 만큼 입력값을 추가할 수 있습니다. 계산 결과는 부동소수점 숫자, 정수, 불리언 값으로 동시에 반환됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `수식` | 평가할 수학 공식으로, 텍스트로 작성합니다(예: `a + b`). 입력값의 문자 이름을 변수로 사용합니다. 여러 줄 입력입니다. (기본값: "a + b") | STRING | 예 | N/A |
| `값` | `expression`에 사용할 변수를 제공하는 확장 가능한 입력값 그룹입니다. 그룹에 값을 추가할 때마다 `a`부터 시작하는 다음 소문자 이름(`a`, `b`, `c`, ...)이 자동으로 지정되며, 이 이름을 `expression` 안에서 사용할 수 있습니다. 각 항목은 숫자(INT 또는 FLOAT) 또는 불리언(TRUE/FALSE)을 받습니다. | FLOAT, INT, BOOLEAN | 예 | 1~26개 값, `a`부터 `z`까지 이름 지정 |

### 참고 및 제약 사항

- `expression`은 비어 있거나 공백만 포함할 수 없습니다.
- 표현식은 숫자 결과(INT 또는 FLOAT) 또는 불리언 결과(TRUE/FALSE)로 평가되어야 합니다. 불리언 결과는 TRUE일 때 1, FALSE일 때 0으로 처리됩니다. 결과가 텍스트와 같은 다른 타입이면 노드는 오류를 발생시킵니다.
- 숫자 결과는 유한해야 하며 float로 변환할 수 있어야 합니다. 결과가 너무 크거나 유한하지 않으면 오류가 발생합니다.
- 전체 입력값 집합은 표현식 안에서 변수 이름 `values`(리스트)로도 사용할 수 있으므로 `sum(values)`와 같은 표현식을 작성할 수 있습니다.
- 표현식 안에서 다음 수학 함수를 사용할 수 있습니다: `sum`, `min`, `max`, `abs`, `round`, `pow`, `sqrt`, `ceil`, `floor`, `log`, `log2`, `log10`, `sin`, `cos`, `tan`, `int`, `float`.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `FLOAT` | 표현식의 결과를 부동소수점 숫자로 나타낸 값입니다. | FLOAT |
| `INT` | 표현식의 결과를 소수 부분을 버리고 정수로 변환한 값입니다. | INT |
| `BOOL` | 결과를 불리언 값으로 변환한 값입니다. 숫자 결과가 0이 아니면 TRUE, 0이면 FALSE입니다. | BOOLEAN |
