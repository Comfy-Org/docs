ComfyMathExpression 노드는 텍스트로 작성한 수학 공식을 평가합니다. 공식은 `a`, `b`, `c` 같은 문자 이름을 사용하여 노드의 입력 값을 참조할 수 있으며, 확장 가능한 `values` 그룹을 통해 필요한 만큼 입력 값을 추가할 수 있습니다. 계산 결과는 부동 소수점 숫자, 정수, 부울 값으로 동시에 반환됩니다.

## 입력

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `수식` | 평가할 수학 공식으로, 텍스트로 작성합니다(예: `a + b`). 입력 값의 문자 이름을 변수로 사용합니다. 여러 줄 입력 가능. (기본값: "a + b") | STRING | 예 | N/A |
| `값` | 수식의 변수를 제공하는 확장 가능한 입력 값 그룹입니다. 그룹에 추가된 각 값은 자동으로 `a`부터 시작하는 다음 소문자 이름(`a`, `b`, `c`, ...)을 받으며, 해당 이름을 `expression` 내부에서 사용할 수 있습니다. 각 항목은 숫자(INT 또는 FLOAT) 또는 부울(TRUE/FALSE)을 허용합니다. | FLOAT, INT, BOOLEAN | 예 | 1~26개 값, `a`~`z`로 명명됨 |

### 참고 사항 및 제약 조건

- `expression`은(는) 비어 있거나 공백만 포함할 수 없습니다.
- 수식은 숫자 결과(INT 또는 FLOAT)로 평가되어야 합니다. 결과가 텍스트와 같은 다른 유형이면 노드에서 오류가 발생합니다.
- 숫자 결과는 유한해야 하며 float으로 변환 가능해야 합니다. 너무 크거나 유한하지 않은 결과는 오류를 발생시킵니다.
- 전체 입력 값 집합은 수식 내에서 `values`라는 변수 이름(리스트 형태)으로도 사용할 수 있으므로 `sum(values)` 같은 표현식이 가능합니다.
- 수식 내에서 사용할 수 있는 수학 함수는 다음과 같습니다: `sum`, `min`, `max`, `abs`, `round`, `pow`, `sqrt`, `ceil`, `floor`, `log`, `log2`, `log10`, `sin`, `cos`, `tan`, `int`, `float`.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `FLOAT` | 수식의 결과를 부동 소수점 숫자로 반환합니다. | FLOAT |
| `INT` | 결과를 소수 부분을 버리고 정수로 변환하여 반환합니다. | INT |
| `BOOL` | 결과를 부울 값으로 변환하여 반환합니다. 숫자 결과가 0이 아니면 TRUE, 0이면 FALSE입니다. | BOOLEAN |
