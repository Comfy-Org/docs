SplitSigmasDenoise 노드는 디노이징 강도 매개변수를 기반으로 시그마 값 시퀀스를 두 부분으로 나눕니다. 입력 시그마를 높은 시그마와 낮은 시그마 시퀀스로 분할하며, 분할 지점은 전체 단계 수(시그마 값 개수보다 1 작은 값)에 `denoise` 계수를 곱하여 결정됩니다. 이를 통해 노이즈 스케줄을 서로 다른 강도 범위로 분리하여 특수한 처리에 활용할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `시그마 배열` | 노이즈 스케줄을 나타내는 입력 시그마 값 시퀀스입니다. | SIGMAS | 예 | - |
| `노이즈 제거양` | 시그마 시퀀스를 분할할 위치를 결정하는 디노이징 강도 계수입니다(기본값: 1.0). | FLOAT | 예 | 0.0 - 1.0 (단계: 0.01) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `high_sigmas` | 분할 지점까지의 더 높은 시그마 값을 포함하는 시그마 시퀀스의 첫 번째 부분입니다. | SIGMAS |
| `low_sigmas` | 분할 지점 이후의 더 낮은 시그마 값을 포함하는 시그마 시퀀스의 두 번째 부분입니다. | SIGMAS |
