WanVaceToVideo 노드는 비디오 생성 모델을 위한 비디오 컨디셔닝 데이터를 준비합니다. 이 노드는 positive 및 negative 컨디셔닝 입력과 선택적 컨트롤 비디오, 마스크, 참조 이미지를 받아 비디오 생성을 안내하는 잠재 표현으로 인코딩합니다. 또한 업스케일링, 패딩, 마스킹 및 VAE 인코딩을 처리하여 비디오 모델에 적합한 컨디셔닝 구조를 구축합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `긍정 조건` | 생성을 안내하는 positive 컨디셔닝 입력입니다. | CONDITIONING | 예 | - |
| `부정 조건` | 생성을 안내하는 negative 컨디셔닝 입력입니다. | CONDITIONING | 예 | - |
| `vae` | 이미지와 비디오 프레임 인코딩에 사용되는 VAE 모델입니다. | VAE | 예 | - |
| `너비` | 출력 비디오의 너비(픽셀)입니다. (기본값: 832, 단계: 16) | INT | 예 | 16 to MAX_RESOLUTION |
| `높이` | 출력 비디오의 높이(픽셀)입니다. (기본값: 480, 단계: 16) | INT | 예 | 16 to MAX_RESOLUTION |
| `길이` | 비디오의 프레임 수입니다. (기본값: 81, 단계: 4) | INT | 예 | 1 to MAX_RESOLUTION |
| `배치 크기` | 동시에 생성할 비디오 수입니다. (기본값: 1) | INT | 예 | 1 ~ 4096 |
| `강도` | VACE 제어의 컨디셔닝 강도입니다. (기본값: 1.0, 단계: 0.01). 이 값은 LoRA 강도가 아닙니다. LoRA 가중치는 별도의 LoRA 노드를 통해 적용됩니다. | FLOAT | 예 | 0.0 ~ 1000.0 |
| `제어 비디오` | 컨트롤 컨디셔닝에 사용되는 선택적 입력 비디오입니다. 제공되지 않으면 중성 회색 비디오가 자동으로 생성됩니다. | IMAGE | 아니오 | - |
| `제어 마스크` | 컨트롤 비디오의 어느 부분이 활성화되는지 결정하는 선택적 마스크입니다. 제공되지 않으면 전체 흰색 마스크가 사용됩니다. | MASK | 아니오 | - |
| `참조 이미지` | 추가 컨디셔닝을 위한 선택적 참조 이미지입니다. 제공되면 인코딩되어 잠재 시퀀스 앞에 추가됩니다. | IMAGE | 아니오 | - |

**참고:** `control_video`가 제공되면 `length` 프레임 수에 맞게 잘리고 지정된 `width` 및 `height`로 업스케일링됩니다. `length`보다 프레임 수가 적으면 누락된 프레임은 중성 회색(값 0.5)으로 패딩됩니다. 제공되지 않으면 `length` 프레임의 중성 회색 비디오가 자동으로 생성됩니다. `control_masks`는 지정된 `width` 및 `height`로 업스케일링되고, `length` 프레임 수로 잘리며, 더 짧은 경우 값 1.0으로 패딩됩니다. 마스크는 컨트롤 비디오를 비활성 부분과 반응 부분으로 나누며, 각 부분은 VAE 인코딩된 후 채널 차원을 따라 연결됩니다. 마스크는 또한 잠재 해상도로 다운샘플링됩니다. `reference_image`가 제공되면 VAE 인코딩되어 잠재 시퀀스 앞에 추가됩니다. 잠재 프레임 수는 `((length - 1) // 4) + 1`로 계산되고, 잠재 공간 차원은 `height / 8` 및 `width / 8`입니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `긍정 조건` | 비디오 컨트롤 데이터(vace_frames, vace_mask, vace_strength)가 적용된 positive 컨디셔닝입니다. | CONDITIONING |
| `부정 조건` | 비디오 컨트롤 데이터(vace_frames, vace_mask, vace_strength)가 적용된 negative 컨디셔닝입니다. | CONDITIONING |
| `잠재 비디오` | 비디오 생성을 위한 빈 잠재 텐서로, 형태는 [batch_size, 16, latent_length, height/8, width/8]입니다. | LATENT |
| `잘린 잠재 비디오` | 참조 이미지가 사용될 때 잘라낼 잠재 프레임 수입니다. 참조 이미지가 제공되지 않으면 0입니다. | INT |
