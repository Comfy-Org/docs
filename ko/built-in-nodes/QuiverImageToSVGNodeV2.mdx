래스터 이미지를 Quiver AI로 확장 가능한 벡터 그래픽(SVG)으로 벡터화합니다. 이미지는 Quiver AI의 API로 전송되며, API는 벡터화된 결과를 반환합니다.

`model`을 선택하면 아래에 나열된 모델별 매개변수가 표시됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | SVG 벡터화에 사용할 모델입니다. | DYNAMIC_COMBO | 예 | `"arrow-2"`<br />`"arrow-2-telos"` |
| `image` | 벡터화할 입력 이미지입니다. | IMAGE | 예 | N/A |
| `auto_crop` | 주요 피사체에 맞게 자동으로 자릅니다. 고급 매개변수(기본값: False). | BOOLEAN | 예 | `True`<br />`False` |
| `target_size` | 벡터화 전에 입력 이미지에 적용되는 정사각형 크기 조정(픽셀 단위)입니다. 0은 원본 크기를 유지하며, 강제로 크기를 조정하는 것보다 더 깔끔하게 벡터화됩니다. 128 미만의 다른 값은 128로 제한됩니다. 이는 출력 캔버스를 설정하지 않습니다. 이를 위해서는 `width`와 `height`를 사용하세요. 고급 매개변수(기본값: 0). | INT | 예 | 0 ~ 4096 |
| `width` | 출력 SVG 캔버스(viewBox)의 너비(사용자 단위)입니다. `width`와 `height`를 모두 설정하여 출력 크기와 종횡비를 제어하세요. 둘 중 하나를 0으로 두면 모델이 선택하게 되며, 일반적으로 정사각형 캔버스가 됩니다. 고급 매개변수(기본값: 0). | INT | 예 | 0 ~ 8192 |
| `height` | 출력 SVG 캔버스(viewBox)의 높이(사용자 단위)입니다. `width`와 `height`를 모두 설정하여 출력 크기와 종횡비를 제어하세요. 둘 중 하나를 0으로 두면 모델이 선택하게 되며, 일반적으로 정사각형 캔버스가 됩니다. 고급 매개변수(기본값: 0). | INT | 예 | 0 ~ 8192 |
| `seed` | 노드의 재실행 여부를 결정하는 시드입니다. 실제 결과는 시드 값에 관계없이 비결정적입니다. 이 매개변수에는 '생성 후 제어' 기능이 있습니다(기본값: 42). | INT | 예 | 0 ~ 2147483647 |

### 모델별 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reasoning_effort` | 모델이 그리기 전에 사용하는 추론량입니다. 수준이 높을수록 세부 묘사가 향상되고 더 많은 토큰을 소모합니다. `"arrow-2"` 및 `"arrow-2-telos"` 모델에서만 사용됩니다(기본값: `"high"`). | COMBO | 예 | `"low"`<br />`"medium"`<br />`"high"`<br />`"xhigh"` |
| `temperature` | 무작위성 제어입니다. 값이 높을수록 무작위성이 증가합니다. `"arrow-2-telos"` 모델에서는 사용되지 않습니다. 고급 매개변수(기본값: 1.0). | FLOAT | 예 | 0.0 ~ 2.0 (단계: 0.1) |
| `top_p` | Nucleus 샘플링 매개변수입니다. `"arrow-2-telos"` 모델에서는 사용되지 않습니다. 고급 매개변수(기본값: 1.0). | FLOAT | 예 | 0.05 ~ 1.0 (단계: 0.05) |
| `presence_penalty` | 토큰 존재 페널티입니다. `"arrow-2-telos"` 모델에서는 사용되지 않습니다. 고급 매개변수(기본값: 0.0). | FLOAT | 예 | -2.0 ~ 2.0 (단계: 0.1) |

**참고:** `target_size`는 벡터화 전에 적용되며 출력 캔버스를 변경하지 않습니다. `width` 또는 `height`를 0으로 두면 모델이 캔버스 크기를 선택합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `SVG` | 벡터화된 SVG 출력입니다. | SVG |
