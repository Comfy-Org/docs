이 노드는 생성된 이미지를 원본 리사이즈 이미지와 정렬하고 선택적으로 색상 보정을 적용합니다. SeedVR2 업스케일링 프로세스의 출력을 가져와 원본 참조 이미지의 색상 및 크기와 일치하도록 조정합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 처리할 생성 이미지입니다. | IMAGE | 예 | - |
| `original_resized_images` | 전처리 전의 원본 리사이즈 이미지로, 참조용으로 사용됩니다. | IMAGE | 예 | - |
| `color_correction_method` | 생성된 이미지의 색상을 원본 이미지에 맞추는 방법입니다. lab: CIELAB 공간에서 색상을 전송하여 디테일을 보존합니다(가장 원본에 충실함). wavelet: 저주파 색상을 전송하고 업스케일된 고주파 디테일을 유지합니다. adain: 채널별 평균/표준편차를 일치시킵니다(가장 빠르며 전역 색조를 적용). none: 색상 전송을 건너뜁니다(기하학적 정렬만 수행). (기본값: "lab") | COMBO | 예 | `"lab"`<br />`"wavelet"`<br />`"adain"`<br />`"none"` |

**참고:** 두 입력 모두 4차원(배치, 높이, 너비, 채널) 또는 5차원(배치, 프레임, 높이, 너비, 채널) 텐서일 수 있습니다. 노드는 두 입력을 가장 작은 배치, 프레임 수, 높이, 너비에 맞춰 자르므로 정확히 일치할 필요가 없습니다. 출력 높이와 너비는 짝수로 내림 처리됩니다. 참조 이미지에 알파 채널(4채널)이 있는 경우 해당 알파 채널이 보존되어 출력에 적용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `images` | 정렬되고 색상 보정된 이미지입니다. | IMAGE |
