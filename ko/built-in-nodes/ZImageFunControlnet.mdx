ZImageFunControlnet은 기본 모델에 컨트롤 네트워크 패치를 적용하여 이미지 생성 또는 편집 과정을 안내할 수 있게 합니다. 이 노드는 모델, 모델 패치, VAE를 결합하며, 컨트롤 효과가 결과에 미치는 영향의 강도를 제어할 수 있습니다. 선택적인 `image`, `inpaint_image`, `mask` 입력을 사용하면 보다 정밀한 편집이 가능합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 생성 과정에 사용되는 기본 모델입니다. | MODEL | 예 | - |
| `모델 패치` | 컨트롤 네트워크의 안내를 적용하는 특수 패치 모델입니다. | MODEL_PATCH | 예 | - |
| `vae` | 이미지 인코딩 및 디코딩에 사용되는 변분 오토인코더입니다. | VAE | 예 | - |
| `강도` | 컨트롤 네트워크 영향의 강도입니다. 양수 값은 효과를 적용하고, 음수 값은 효과를 반전시킬 수 있습니다(기본값: 1.0). | FLOAT | 예 | -10.0  ~  10.0 (단계: 0.01) |
| `이미지` | 생성 과정을 안내하는 선택적 기본 이미지입니다. | IMAGE | 아니요 | - |
| `인페인트 이미지` | 마스크로 정의된 영역을 인페인팅하는 데 특별히 사용되는 선택적 이미지입니다. | IMAGE | 아니요 | - |
| `mask` | 이미지에서 편집하거나 인페인팅해야 할 영역을 정의하는 선택적 마스크입니다. | MASK | 아니요 | - |

**참고:** `inpaint_image` 매개변수는 일반적으로 `mask`와 함께 사용되어 인페인팅할 내용을 지정합니다. 노드의 동작은 어떤 선택적 입력이 제공되는지에 따라 달라질 수 있습니다(예: `image`를 사용해 안내하거나, `image`, `mask`, `inpaint_image`를 사용해 인페인팅).

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | 컨트롤 네트워크 패치가 적용된 모델로, 샘플링 파이프라인에서 사용할 준비가 되어 있습니다. | MODEL |
| `positive` | 컨트롤 네트워크 입력에 의해 수정될 수 있는 긍정 컨디셔닝입니다. | CONDITIONING |
| `negative` | 컨트롤 네트워크 입력에 의해 수정될 수 있는 부정 컨디셔닝입니다. | CONDITIONING |
