ZImageFunControlnet은 기본 모델에 제어 네트워크 패치를 적용하여 이미지 생성 또는 편집 과정을 안내할 수 있게 합니다. 이 노드는 모델, 모델 패치, VAE를 결합하며, 제어 효과가 결과에 얼마나 강하게 영향을 미치는지 제어할 수 있습니다. 선택적 이미지, 인페인팅 이미지, 마스크 입력을 통해 더욱 표적화된 편집이 가능합니다. 이 노드는 Z-Image ControlNet 패치와 Load Model Patch 노드를 통해 로드된 Qwen Image 2.1 Fun ControlNet 패치와 함께 작동합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 생성 과정에 사용되는 기본 모델입니다. | MODEL | 예 | - |
| `모델 패치` | 제어 네트워크의 가이드를 적용하는 특수화된 패치 모델입니다. | MODEL_PATCH | 예 | - |
| `vae` | 이미지 인코딩 및 디코딩에 사용되는 변분 오토인코더입니다. | VAE | 예 | - |
| `강도` | 제어 네트워크 영향의 강도입니다. 양수 값은 효과를 적용하고, 음수 값은 효과를 반전할 수 있습니다(기본값: 1.0). | FLOAT | 예 | -10.0 ~ 10.0 (단계 0.01) |
| `이미지` | 생성 과정을 안내하는 선택적 기본 이미지입니다. | IMAGE | 아니요 | - |
| `인페인트 이미지` | 마스크로 정의된 영역을 인페인팅하는 데 특별히 사용되는 선택적 이미지입니다. | IMAGE | 아니요 | - |
| `mask` | 이미지에서 편집하거나 인페인팅해야 할 영역을 정의하는 선택적 마스크입니다. | MASK | 아니요 | - |
| `start_percent` | 제어 네트워크가 효과를 발휘하기 시작하는 디노이징 과정의 지점으로, 전체 샘플링 단계에 대한 비율입니다(기본값: 0.0). | FLOAT | 아니요 | 0.0 ~ 1.0 (단계 0.001) |
| `end_percent` | 제어 네트워크가 효과를 멈추는 디노이징 과정의 지점입니다(기본값: 1.0). | FLOAT | 아니요 | 0.0 ~ 1.0 (단계 0.001) |

**참고:** `inpaint_image` 매개변수는 일반적으로 `mask`와 함께 사용되어 인페인팅할 내용을 지정합니다. 노드의 동작은 어떤 선택적 입력이 제공되는지에 따라 달라질 수 있습니다(예: `image`를 안내에 사용하거나 `image`, `mask`, `inpaint_image`를 인페인팅에 사용). `start_percent` 및 `end_percent` 값은 제어 네트워크를 디노이징 과정의 특정 구간으로 제한하며, 그 구간 밖에서는 패치 없이 모델을 샘플링합니다. `strength`가 0이거나 `image`, `inpaint_image`, `mask` 중 어느 것도 연결되지 않은 경우, 노드는 기본 모델을 변경하지 않고 반환합니다. Z-Image Control 패치의 경우 제공된 마스크는 사용 전에 반전되며(1.0 - mask), Qwen Image 2.1 Fun ControlNet 패치는 마스크를 주어진 대로 사용합니다. 이 노드는 실험적(experimental)으로 표시되어 있습니다.
