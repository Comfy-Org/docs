SaveAudioOpus 노드는 오디오 데이터를 Opus 형식의 파일로 저장합니다. 오디오 입력을 받아 품질 설정을 구성할 수 있는 압축된 Opus 파일로 내보냅니다. 이 노드는 더 이상 사용되지 않으며 향후 버전에서 제거될 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `오디오` | Opus 파일로 저장할 오디오 데이터입니다. 이 값이 None이면(예: 원본 비디오에 오디오 트랙이 없는 경우) ValueError가 발생합니다. | AUDIO | 예 | - |
| `파일명 접두사` | 출력 파일 이름의 접두사입니다 (기본값: "audio/ComfyUI") | STRING | 아니요 | - |
| `품질` | Opus 파일을 인코딩하는 데 사용되는 비트레이트입니다. 값이 높을수록 품질은 좋아지지만 파일 크기는 커집니다 (기본값: "128k") | COMBO | 아니요 | "64k"<br />"96k"<br />"128k"<br />"192k"<br />"320k" |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `audio` | Opus 파일에 저장된 오디오 데이터입니다 | AUDIO |
