이 노드는 저해상도 이미지를 초해상도로 업스케일링하면서 아티팩트와 노이즈를 제거하여 이미지를 향상시킵니다. 이미지를 처리를 위해 외부 API로 전송하며, 허용된 출력 제한을 벗어나지 않도록 입력 크기를 자동으로 조정할 수 있습니다. 허용되는 최대 출력 크기는 32메가픽셀입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 사용할 향상 모델입니다. `generative_portrait` 모델은 인물 사진에 최적화되어 있으며, `generative`는 범용 모델입니다. | COMBO | 예 | `"generative_portrait"`<br />`"generative"` |
| `이미지` | 향상할 입력 이미지입니다. | IMAGE | 예 | - |
| `업스케일 배수` | 이미지 크기를 업스케일할 배율입니다. 배율 1은 업스케일하지 않음을 의미하고, 2는 크기를 2배로, 4는 크기를 4배로 만듭니다. | COMBO | 예 | `1`<br />`2`<br />`4` |
| `자동 다운스케일` | 출력이 제한을 초과할 경우 입력 이미지를 자동으로 다운스케일합니다. (기본값: `False`) | BOOLEAN | 아니요 | - |

**참고:** 계산된 출력 크기(입력 너비 × `upscale_factor` × 입력 높이 × `upscale_factor`)가 32,000,000픽셀(32MP)을 초과하고 `auto_downscale`이 비활성화된 경우 노드는 오류를 발생시킵니다. `auto_downscale`이 활성화된 경우, 노드는 출력이 32MP 제한 내에 맞도록 입력 이미지 크기나 업스케일 배율(또는 둘 다)을 자동으로 줄입니다. 선택한 `model`과 `upscale_factor`는 서비스로 전송되는 모델 이름으로 결합됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 향상되고 업스케일된 출력 이미지입니다. | IMAGE |
