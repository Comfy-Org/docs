CFGNorm은 확산 모델의 classifier-free guidance (CFG) 과정에 정규화 기법을 적용합니다. 조건부 출력과 무조건부 출력의 노름을 비교하여 노이즈 제거 예측의 스케일을 조정한 다음, 강도 배율을 적용하여 효과를 제어합니다. 기본적으로 정규화는 가이던스 출력만 감쇠시키지만, `pre_cfg`를 활성화하면 샘플러의 CFG 결합 전에 결합된 노이즈를 클램핑 없이 재조정하며, 이 경우 증폭될 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | CFG 정규화를 적용할 확산 모델 | MODEL | 예 | - |
| `strength` | CFG 스케일링에 적용되는 정규화 효과의 강도를 제어합니다 (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 100.0 |
| `pre_cfg` | true로 설정하면 샘플러의 CFG 결합 전에 결합된 노이즈를 클램핑 없이 재조정합니다 (증폭될 수 있음). Lens와 같은 모델에서 사용하는 노름-스케일 CFG와 일치합니다. 기본값인 false는 원래의 포스트-CFG x0 공간 감쇠 전용 동작을 유지합니다. (기본값: False) | BOOLEAN | 아니요 | true / false |

참고: 이 노드는 실험용으로 표시되어 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `patched_model` | CFG 정규화가 샘플링 과정에 적용된 수정된 모델을 반환합니다 | MODEL |
