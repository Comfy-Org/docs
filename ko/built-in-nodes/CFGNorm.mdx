CFGNorm은 조건부 예측의 크기(노름)를 가이드된 예측과 비교하고 결과를 재조정하여 디퓨전 모델에서 classifier-free guidance(CFG)가 적용되는 방식을 조정합니다. `strength` 값은 조정이 얼마나 적용되는지를 제어합니다. 기본적으로 스케일링은 가이던스 출력을 감쇠만 시키지만, `pre_cfg`를 활성화하면 샘플러의 CFG 결합 전에 결합된 노이즈를 클램핑 없이 재조정하므로 결과가 증폭될 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | CFG 정규화를 적용할 디퓨전 모델 | MODEL | 예 | - |
| `strength` | CFG 스케일링에 적용되는 정규화 효과의 강도를 제어합니다 (기본값: 1.0) | FLOAT | 예 | 0.0  ~  100.0 (단계: 0.01) |
| `pre_cfg` | true이면 샘플러의 CFG 결합 전에 결합된 노이즈를 클램핑 없이 재조정합니다(증폭될 수 있음). Lens와 같은 모델에서 사용하는 노름으로 스케일링된 CFG와 일치합니다. 기본값 false는 원래의 CFG 이후 x0 공간 감쇠 전용 동작을 유지합니다. (기본값: False) | BOOLEAN | 아니요 | true / false |

참고: 이 노드는 실험적으로 표시되어 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `patched_model` | 샘플링 프로세스에 CFG 정규화가 적용된 수정된 모델을 반환합니다 | MODEL |
