이 노드는 외부 3D 모델을 Tripo로 가져와 Texture, Rig, Convert와 같은 Tripo 후처리 노드에서 사용할 수 있게 합니다. 이 노드는 파일을 Tripo에 업로드하고, 해당 노드에서 사용할 수 있도록 가져온 모델을 식별하는 작업 ID를 반환합니다. GLB를 권장합니다. 텍스처는 파일에 내장된 경우에만 보존되며, 가져온 모델에 텍스처를 입히려면 텍스처 프롬프트가 필요하기 때문입니다. 이 노드는 무료로 사용할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 가져올 3D 모델(GLB / FBX / OBJ / STL, 최대 150MB). OBJ 및 STL 파일에는 내장 텍스처가 없습니다. | FILE3D | 예 | GLB<br />FBX<br />OBJ<br />STL<br />Any 3D format |

**참고:** GLB, FBX, OBJ, STL 형식만 지원합니다. GLTF(.gltf)는 외부 파일을 참조하므로 가져올 수 없습니다. 대신 단일 파일 GLB로 내보내십시오. 모델 파일은 150MB 이하여야 합니다. GLB를 권장합니다. 텍스처는 파일에 내장된 경우에만 가져오기 후에도 유지되기 때문입니다. OBJ 및 STL 파일에는 내장 텍스처가 없습니다. 가져온 모델에 텍스처를 입히려면 텍스처 프롬프트가 필요합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model task_id` | 가져온 모델을 식별하는 작업 ID로, Tripo 후처리 노드에서 사용합니다 | MODEL_TASK_ID |
