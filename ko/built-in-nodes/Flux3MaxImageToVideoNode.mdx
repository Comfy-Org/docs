FLUX 3 Max Image to Video는 FLUX 3 Max를 사용하여 1~10개의 이미지를 애니메이션으로 만듭니다. 각 이미지는 클립의 프레임이 됩니다. 이미지가 하나이면 클립의 시작 프레임이 되고, 두 개이면 첫 프레임과 마지막 프레임이 되며, 더 많으면 클립 전체에 분산되거나 사용자가 선택한 시간에 고정됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 장면이 어떻게 움직이고 들려야 하는지 지정합니다(기본값: 비어 있음). | STRING | 예 | 여러 줄 텍스트 |
| `keyframes` | 확장 가능한 슬롯: 재생 순서대로 1~10개의 키프레임 이미지를 연결합니다. 예: `image_1`, `image_2` 등. 각 이미지는 클립의 프레임이 됩니다. | IMAGE | 예 | 이미지 1~10개 |
| `placement` | `"spread across the clip"`은 첫 이미지를 시작에, 마지막 이미지를 끝에 두고 나머지를 그 사이에 균등하게 배치합니다. `"at times"`는 모든 이미지를 사용자가 선택한 초에 고정합니다(기본값: `"spread across the clip"`). | DYNAMIC_COMBO | 예 | `"spread across the clip"`<br />`"at times"` |
| `aspect_ratio` | 출력 가로세로 비율입니다. `"auto"`는 첫 번째 키프레임 이미지를 따릅니다(기본값: `"auto"`). | COMBO | 예 | `"auto"`<br />`"21:9"`<br />`"2:1"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"` |
| `duration` | 클립 길이(초)입니다(기본값: `"5"`). | COMBO | 예 | `"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"`<br />`"11"`<br />`"12"`<br />`"13"`<br />`"14"`<br />`"15"`<br />`"16"`<br />`"17"`<br />`"18"`<br />`"19"`<br />`"20"` |
| `resolution` | 출력 해상도입니다(기본값: `"720p"`). | COMBO | 예 | `"720p"`<br />`"1080p"` |
| `reasoning_level` | 생성 전에 모델이 프롬프트를 얼마나 추론하고 확장하는지를 설정합니다. `"high"`는 더 오래 걸리지만 가격은 동일합니다(기본값: `"high"`). | COMBO | 예 | `"low"`<br />`"high"` |
| `generate_audio` | 동기화된 오디오를 생성합니다. 끄면 오디오 트랙이 없는 비디오를 생성합니다(기본값: true). | BOOLEAN | 예 | `true`<br />`false` |
| `seed` | 노드가 다시 실행되는지 여부를 제어하는 시드입니다. 이 값과 관계없이 결과는 비결정적입니다(기본값: 42). | INT | 예 | 0  ~  2147483646 |

### at times 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `times` | 이미지당 초 단위 시간을 하나씩, 쉼표로 구분하고 증가하는 순서로 지정합니다. 예: "0, 2.5, 5". `placement`가 `"at times"`일 때만 표시됩니다. | STRING | 아니요 | 쉼표로 구분된 초 |

참고: `prompt`는 최소 한 글자 이상이어야 합니다. `keyframes`는 최소 한 개의 이미지를 포함해야 하며 10개를 초과할 수 없습니다. 배치 입력은 이미지마다 한 번씩 계산됩니다.

`placement`가 `"spread across the clip"`으로 설정된 경우, 이미지가 하나 또는 두 개이면 시작 이미지와 선택적 끝 이미지로 전송되고, 세 개 이상이면 24fps로 클립 전체에 균등하게 분산된 키프레임에 배치됩니다.

`placement`가 `"at times"`로 설정된 경우, `times`는 이미지마다 하나의 값을 제공해야 하며 해당 값은 증가해야 하고 음수일 수 없으며 마지막 시간은 클립 끝을 넘을 수 없습니다.

표시되는 가격은 `resolution`과 `duration`을 기준으로 합니다. 720p는 2026년 11월 7일까지 초당 $0.060775, 1080p는 초당 $0.103675가 청구되며, 해당 날짜 이후에는 각각 초당 $0.2431 및 $0.4147가 청구됩니다. 클립의 총 예상 비용은 UI에 표시됩니다.

| 출력 이름 | 설명 | 데이터 타입 |
