이 노드는 이미지 배치와 해당 바운딩 박스를 레이어 스택으로 변환하여 프레임당 하나의 레이어를 생성하고 각 레이어를 일치하는 박스에 따라 배치합니다. 노드가 레이어를 배치(batch)로 출력할 때 사용하십시오. 배치(batch)는 모든 프레임에 대해 단일 위치만 전달하므로, 그렇지 않으면 개별 위치가 손실됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 이미지 배치입니다. 각 프레임이 하나의 레이어가 됩니다. | IMAGE | 예 | — |
| `bboxes` | 배치 상자로, 이미지 배치와 인덱스가 정렬됩니다. 바운딩 박스(x, y, width, height), 정규화된 요소("bbox" 포함 — 픽셀로 변환하려면 canvas_width/canvas_height가 필요함) 또는 둘 중 하나의 JSON 문자열을 허용합니다. 일치하는 박스가 없는 프레임은 원점에 배치됩니다. 박스의 너비/높이는 레이어를 해당 크기에 맞게 조정합니다. metadata.name(또는 desc) 및 metadata.z_index는 있는 경우 사용되며, metadata.content_rect(프레임 기준)는 프레임을 실제 콘텐츠로 크롭합니다. | BOUNDING_BOX, ARRAY, or STRING | 예 | — |
| `mask` | 프레임별 투명도로, 이미지 배치와 인덱스가 정렬됩니다(1 = 투명, LoadImage 규칙). | MASK | 아니요 | — |
| `layers` | 추가할 레이어 스택입니다. 연결하지 않으면 새 스택이 시작됩니다. | LAYERS | 아니요 | — |
| `crop_to_content` | 각 프레임을 metadata.content_rect가 있는 경우 해당 영역으로 크롭하고, 콘텐츠를 박스 위치에 사각형 오프셋을 더해 배치합니다. 프레임이 패딩된 배치에서는 이 옵션을 켜 두십시오. 실제 콘텐츠만 원래 위치에 유지됩니다. (기본값: true) | BOOLEAN | 아니요 | true<br />false |
| `canvas_width` | 문서 캔버스 너비입니다. 0이면 배치된 레이어에서 파생됩니다. (기본값: 0) | INT | 아니요 | 0 ~ MAX_RESOLUTION |
| `canvas_height` | 문서 캔버스 높이입니다. 0이면 배치된 레이어에서 파생됩니다. (기본값: 0) | INT | 아니요 | 0 ~ MAX_RESOLUTION |

참고:

- `bboxes`와 `mask`는 `image`와 인덱스가 정렬되어야 합니다. n번째 박스와 n번째 마스크 프레임은 n번째 이미지 프레임에 대응됩니다. 일치하는 박스가 없는 프레임은 원점에 배치됩니다.
- `bboxes`에 정규화된 요소("bbox" 포함)가 포함된 경우, 정규화된 위치를 픽셀로 변환하려면 `canvas_width`와 `canvas_height`를 제공해야 합니다.
- `canvas_width`와 `canvas_height`가 모두 0보다 커야 문서 캔버스를 명시적으로 설정할 수 있습니다. 둘 중 하나라도 0이면 캔버스는 배치된 레이어에서 파생되거나 연결된 `layers` 스택에서 상속됩니다.
- `layers`가 연결되면 새 레이어가 해당 스택에 추가되고, 스택에 이미 있는 가장 높은 z-index 값보다 높은 z-index 값을 받습니다.
- `crop_to_content`가 활성화되고 프레임에 metadata.content_rect가 있으면 프레임이 해당 사각형으로 크롭되고 박스의 너비/높이 배율은 적용되지 않습니다. 대신 사각형의 오프셋이 박스 위치에 더해집니다.
