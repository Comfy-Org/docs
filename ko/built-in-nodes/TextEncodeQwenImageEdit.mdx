TextEncodeQwenImageEdit 노드는 텍스트 프롬프트와 선택적 이미지를 이미지 생성 또는 편집을 위한 컨디셔닝 데이터로 변환합니다. CLIP 모델을 사용하여 입력을 토큰화하며, VAE를 사용하여 참조 이미지를 인코딩해 참조 잠재 변수를 생성할 수 있습니다. 이미지가 제공되면 일관된 처리 크기를 유지하기 위해 자동으로 크기가 조정됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | 텍스트 및 이미지 토큰화에 사용되는 CLIP 모델 | CLIP | 예 | - |
| `프롬프트` | 컨디셔닝 생성을 위한 텍스트 프롬프트로, 여러 줄 입력과 동적 프롬프트를 지원합니다. | STRING | 예 | - |
| `vae` | 참조 이미지를 잠재 변수로 인코딩하기 위한 선택적 VAE 모델 | VAE | 아니요 | - |
| `이미지` | 참조 또는 편집 목적의 선택적 입력 이미지 | IMAGE | 아니요 | - |

**참고:** 이미지가 제공되면 총 픽셀 수가 1,048,576(1024 × 1024)에 가깝게 유지되도록 크기가 조정되며, RGB 채널만 사용됩니다. 크기가 조정된 이미지는 프롬프트와 함께 CLIP 토크나이저에 전달됩니다. `image`와 `vae`가 모두 제공되면 노드는 이미지를 참조 잠재 변수로 인코딩하여 컨디셔닝 출력에 첨부합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `CONDITIONING` | 텍스트 토큰과 이미지 생성을 위한 선택적 참조 잠재 변수를 포함하는 컨디셔닝 데이터 | CONDITIONING |
