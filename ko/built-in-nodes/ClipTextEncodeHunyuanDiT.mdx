`CLIPTextEncodeHunyuanDiT` 노드는 텍스트 설명을 HunyuanDiT 모델이 이해할 수 있는 형식으로 변환합니다. HunyuanDiT의 이중 텍스트 인코더 구조를 위해 설계된 고급 컨디셔닝 노드로, 두 개의 개별 텍스트 입력을 서로 다른 토크나이저로 처리하고 그 결과를 단일 컨디셔닝 출력으로 결합합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | 텍스트 토큰화 및 인코딩에 사용되는 CLIP 모델 인스턴스로, 조건 생성의 핵심입니다. | CLIP | 예 | - |
| `bert 프롬프트` | BERT 토크나이저를 통해 인코딩할 텍스트 입력입니다. 구문과 키워드를 선호합니다. 여러 줄 및 동적 프롬프트를 지원합니다. | STRING | 예 | - |
| `mt5xl 프롬프트` | mT5-XL 토크나이저를 통해 인코딩할 텍스트 입력입니다. 여러 줄 및 동적 프롬프트(다국어)를 지원합니다. 완전한 문장과 복잡한 설명을 사용할 수 있습니다. | STRING | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `CONDITIONING` | BERT와 mT5-XL 토크나이저로 처리된 텍스트를 결합한 인코딩된 컨디셔닝 출력으로, 생성 작업의 추가 처리에 사용됩니다. | CONDITIONING |
