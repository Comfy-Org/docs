SaveGLB 노드는 3D 메시 데이터 또는 3D 파일 입력을 출력 디렉토리에 저장합니다. 메시 데이터와 일반적인 3D 파일 형식(GLB, GLTF, OBJ, FBX, STL, USDZ, PLY, SPLAT, SPZ, KSPLAT)을 입력받아 지정된 파일 이름 접두사를 사용하여 내보냅니다. 메시 입력은 배치 항목당 하나씩 GLB 파일로 작성되며, 3D 파일 입력은 원래 형식으로 저장됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `메시` | 저장할 메시 또는 3D 파일 | MESH 또는 FILE3D | 예 | 메시 데이터<br />GLB<br />GLTF<br />OBJ<br />FBX<br />STL<br />USDZ<br />PLY<br />SPLAT<br />SPZ<br />KSPLAT<br />모든 스플랫 형식<br />모든 포인트 클라우드 형식<br />모든 3D 파일 형식 |
| `파일명 접두사` | 출력 파일 이름의 접두사(기본값: "3d/ComfyUI"). 접두사에는 하위 폴더 경로가 포함될 수 있으므로, 기본적으로 파일은 출력 디렉토리의 "3d" 하위 폴더에 저장됩니다 | STRING | 아니오 | - |

참고: `mesh` 입력이 3D 파일인 경우, 노드는 원래 형식 확장자를 사용하여 저장합니다(파일에 형식이 없는 경우 GLB가 사용됨). 메시 데이터인 경우 배치의 각 항목은 별도의 `.glb` 파일로 저장되며, 정점이나 면이 없는 빈 항목은 경고와 함께 건너뜁니다. 출력 파일 이름은 `{filename_prefix}_{counter:05}_.{ext}` 패턴을 따르며 카운터가 증가합니다. 메타데이터가 활성화된 경우 작업 흐름 메타데이터(프롬프트 및 추가 PNG 정보)가 저장된 파일에 포함됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `ui` | 저장된 3D 파일을 파일 이름, 하위 폴더, 형식 정보와 함께 사용자 인터페이스에 표시합니다 | UI |
