이 노드는 ByteDance의 Seedream 모델(버전 4.0, 4.5, 5.0 Lite 및 5.0 Pro)을 사용하여 이미지를 생성하거나 편집합니다. 최대 4K 해상도에서 통합된 텍스트-이미지 생성과 정밀한 단일 문장 이미지 편집을 제공합니다. 이는 Seedream 노드의 레거시(V2) 버전입니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 생성에 사용할 Seedream 모델 버전입니다. 각 모델은 서로 다른 기능과 가격을 가지고 있습니다. | DYNAMIC_COMBO | 예 | `"seedream 5.0 pro"`<br />`"seedream 5.0 lite"`<br />`"seedream-4-5-251128"`<br />`"seedream-4-0-250828"` |
| `프롬프트` | 이미지를 생성하거나 편집하기 위한 텍스트 프롬프트입니다 (기본값: 빈 문자열). | STRING | 예 | N/A |
| `시드` | 생성에 사용할 시드입니다 (기본값: 0). | INT | 예 | 0 ~ 2147483647 |
| `워터마크` | 이미지에 "AI 생성" 워터마크를 추가할지 여부입니다 (기본값: False). | BOOLEAN | 예 | True / False |
| `thinking` | 모델의 프롬프트 최적화 추론('thinking')을 활성화하여 명령 준수도를 높입니다. 생성 시간이 크게 늘어날 수 있으며, 특히 Seedream 5.0 Pro에서 두드러집니다. 텍스트-이미지 생성에서만 비활성화할 수 있습니다 (참조 이미지가 제공되는 경우에는 불가). (기본값: True). | BOOLEAN | 아니오 | True / False |

### `seedream 5.0 pro` 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `size_preset` | 권장 크기를 선택합니다. 아래의 `width`와 `height`를 사용하려면 Custom을 선택하세요. | COMBO | 예 | 모델별 여러 프리셋 제공, `Custom` 포함 |
| `width` | 사용자 지정 이미지 너비입니다. `size_preset`이 `Custom`으로 설정된 경우에만 값이 적용됩니다 (기본값: 2048). | INT | 예 | 1024 ~ 3136 (step 2) |
| `height` | 사용자 지정 이미지 높이입니다. `size_preset`이 `Custom`으로 설정된 경우에만 값이 적용됩니다 (기본값: 2048). | INT | 예 | 1024 ~ 2496 (step 2) |

### `seedream 5.0 lite` 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `size_preset` | 권장 크기를 선택합니다. 아래의 `width`와 `height`를 사용하려면 Custom을 선택하세요. | COMBO | 예 | 모델별 여러 프리셋 제공, `Custom` 포함 |
| `width` | 사용자 지정 이미지 너비입니다. `size_preset`이 `Custom`으로 설정된 경우에만 값이 적용됩니다 (기본값: 2048). | INT | 예 | 1024 ~ 6240 (step 2) |
| `height` | 사용자 지정 이미지 높이입니다. `size_preset`이 `Custom`으로 설정된 경우에만 값이 적용됩니다 (기본값: 2048). | INT | 예 | 1024 ~ 4992 (step 2) |
| `max_images` | 생성할 최대 이미지 수입니다. 1이면 정확히 하나의 이미지를 생성합니다. 1보다 크면 모델은 1에서 max_images 사이의 관련 이미지를 생성합니다 (예: 스토리 장면, 캐릭터 변형). 총 이미지 수(입력 + 생성)는 15개를 초과할 수 없습니다. (기본값: 1) | INT | 예 | 1 ~ 14 |
| `fail_on_partial` | 활성화하면 요청된 이미지가 누락되거나 오류가 반환되는 경우 실행을 중단합니다. (기본값: False) | BOOLEAN | 예 | True / False |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 확장 가능한 슬롯: 1..N개 항목을 연결합니다 (예: `image_1`, `image_2`, ...). 개수 제한은 선택한 모델에 따라 다릅니다 (모델 섹션 참조). 이미지-이미지 또는 다중 참조 생성을 위한 선택적 참조 이미지입니다. 참조 이미지가 없으면 노드는 텍스트-이미지 모드로 작동합니다. | IMAGE | 아니오 | 0~10개 이미지 (`seedream 5.0 pro`, `seedream-4-5-251128`, `seedream-4-0-250828`)<br />0~14개 이미지 (`seedream 5.0 lite`) |

### 제약 사항 참고

- `width` 및 `height`는 `size_preset`이 `Custom`으로 설정된 경우에만 적용됩니다.
- 참조 이미지와 생성 이미지의 총 개수는 15개를 초과할 수 없습니다.
- `thinking`은 텍스트-이미지 생성에서만 비활성화할 수 있으며, 참조 이미지가 제공되는 경우에는 비활성화할 수 없습니다.
- Seedream 5.0 Pro는 배치 생성을 지원하지 않습니다. 항상 단일 이미지를 생성하므로 `max_images` 및 `fail_on_partial`은 이 모델에서 사용할 수 없습니다.
