이 노드는 오디오 데이터를 FLAC 형식의 파일로 저장합니다. 오디오 입력을 받아 지정된 파일 이름 접두사를 사용하여 출력 디렉터리에 기록하며, 오디오를 출력으로도 그대로 전달합니다. 이 노드는 더 이상 사용되지 않으며, 현재 Save Audio 노드로 대체해야 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `오디오` | 저장할 오디오 데이터입니다 | AUDIO | 예 | - |
| `파일명 접두사` | 출력 파일 이름의 접두사입니다(기본값: "audio/ComfyUI") | STRING | 아니요 | - |

*참고: `prompt` 및 `extra_pnginfo` 매개변수는 숨겨져 있으며 시스템에서 자동으로 처리됩니다.*

`audio` 입력이 데이터를 받지 못하는 경우(예: 원본 비디오에 오디오 트랙이 없는 경우), 노드에서 오류가 발생하고 파일이 저장되지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `audio` | 파일이 저장된 후 입력으로 제공된 오디오 데이터를 그대로 전달합니다 | AUDIO |
