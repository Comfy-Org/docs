이 노드는 Bria를 사용하여 이미지를 다른 계절로 이동시킵니다. 전체 장면이 다시 렌더링되므로 계절 자체 외에도 풍경이 바뀔 수 있습니다. Bria는 전체 프레임을 약 1메가픽셀 해상도로 다시 렌더링하므로 결과는 입력과 픽셀 단위로 정렬되지 않습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 다른 계절로 이동할 이미지입니다. 이미지가 전송되기 전에 모든 알파 채널이 제거됩니다. | IMAGE | 예 | - |
| `계절` | 적용할 계절입니다. | COMBO | 예 | `"spring"`<br />`"summer"`<br />`"autumn"`<br />`"winter"` |
| `모더레이션` | 검열 설정입니다. 이 요청에 대해 콘텐츠 검열 옵션을 구성할지 여부를 선택합니다. | DYNAMIC_COMBO | 예 | `"false"`<br />`"true"` |

### 검열 입력

이 옵션은 `moderation`이 `"true"`로 설정된 경우 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | 입력 이미지에 대한 콘텐츠 검열을 활성화합니다(기본값: false). | BOOLEAN | 아니요 | true<br />false |
| `visual_output_moderation` | 생성된 출력 이미지에 대한 콘텐츠 검열을 활성화합니다(기본값: false). | BOOLEAN | 아니요 | true<br />false |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 선택한 계절로 다시 렌더링된 이미지입니다. | IMAGE |
| `structured_prompt` | Bria FIBO Image Edit로 후속 편집을 하기 위한 편집된 이미지의 구조화된 설명입니다. | STRING |
