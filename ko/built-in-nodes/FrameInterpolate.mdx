Frame Interpolate 노드는 일련의 이미지에서 기존 프레임 사이에 새 프레임을 생성하여 프레임 속도를 효과적으로 높입니다. AI 모델을 사용하여 중간 프레임이 어떻게 보일지 예측하며, 부드러운 슬로우모션 효과를 만들거나 비디오의 부드러움을 향상시키는 데 사용할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `interp_model` | 중간 프레임을 생성하는 데 사용할 프레임 보간 모델입니다. | INTERP_MODEL | 예 | - |
| `이미지` | 보간할 연속된 이미지(프레임) 배치입니다. 최소 2개 이상의 이미지가 필요합니다. 2개 미만의 프레임이 제공되면 입력 이미지를 변경하지 않고 그대로 반환합니다. | IMAGE | 예 | - |
| `배수` | 프레임 수를 곱할 횟수입니다. 예를 들어, multiplier 값이 2이면 프레임 수가 두 배가 됩니다. (기본값: 2) | INT | 예 | 2 ~ 16 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `IMAGE` | 보간된 프레임이 원본 프레임 사이에 삽입된 새 이미지 배치로, 더 부드러운 시퀀스를 생성합니다. 총 출력 프레임 수는 `(number of input frames - 1) * multiplier + 1`입니다. | IMAGE |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/FrameInterpolate/ko.md)
