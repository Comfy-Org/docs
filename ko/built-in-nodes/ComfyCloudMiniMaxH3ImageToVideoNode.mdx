Comfy Cloud GPU에서 MiniMax H3 이미지-투-비디오 워크플로우를 실행하고, 이에 어울리는 사운드트랙이 포함된 비디오를 반환합니다. 정지 이미지는 첫 프레임이 됩니다. 클립의 마지막 프레임을 다시 입력하면 시퀀스가 이어지므로, 여러 번 실행을 연쇄하면 더 긴 장면을 만들 수 있습니다. 이 노드는 베타 버전이며 GPU 초 단위로 과금됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 비디오가 시작되는 이미지입니다. 워크플로우가 실행되기 전에 최대 2048x2048 픽셀로 업로드됩니다. | IMAGE | 예 | - |
| `프롬프트` | 샷이 담아야 할 움직임과 사운드에 대한 텍스트 설명입니다. 제출 전에 앞뒤 공백이 제거됩니다. | STRING | 예 | 1 ~ 4096 자 |
| `시드` | 생성 결과를 제어하는 무작위 시드입니다(기본값: 42). | INT | 예 | 0 ~ 18446744073709551615 |
| `aspect_ratio` | 생성되는 비디오의 화면 비율입니다(기본값: `"1:1"`). | COMBO | 예 | `"1:1"`<br />`"3:4"`<br />`"2:3"`<br />`"3:2"`<br />`"4:3"`<br />`"16:9"`<br />`"9:16"`<br />`"21:9"` |
| `해상도` | 프레임 크기 예산입니다(기본값: `"480p"`). 720p는 480p에 비해 약 두 배의 GPU 초가 소요됩니다. | COMBO | 예 | `"480p"`<br />`"720p"` |
| `duration_seconds` | 길이(초)입니다(기본값: 5). 파이프라인이 24 fps에서 17프레임 단위로 양자화하므로, 클립은 이 값에서 약 3분의 2초 이내로 맞춰집니다. | INT | 예 | 5 ~ 15 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 사운드트랙이 포함된 생성 비디오입니다. | VIDEO |
