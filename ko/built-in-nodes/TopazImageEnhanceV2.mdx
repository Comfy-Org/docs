Topaz Image Enhance는 Topaz 모델을 사용하여 단일 입력 이미지에 업계 표준 업스케일링 및 이미지 향상을 적용합니다. 이미지를 Topaz API로 전송하고 선택한 모델로 처리한 후 향상된 결과를 반환합니다. Reimagine, Bloom 2, Wonder 3.5의 세 가지 모델 중에서 선택할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 향상할 입력 이미지입니다. 단일 입력 이미지만 지원됩니다. | IMAGE | 예 | 단일 이미지 |
| `model` | 사용할 Topaz 향상 모델입니다. 선택한 모델에 따라 모델별 설정이 표시됩니다. | STRING | 예 | `"Reimagine"`<br />`"Bloom 2"`<br />`"Wonder 3.5"` |
| `output_width` | 0 값은 자동으로 계산됨을 의미합니다(일반적으로 원본 크기이거나 `output_height`가 지정된 경우 비례적으로 조정됩니다). Wonder 3.5는 1x에서 6x까지의 업스케일 배수만 지원합니다. Bloom 2와 Wonder 3.5는 입력 비율을 유지하며 요청된 크기를 목표로 처리합니다. (기본값: 0) | INT | 아니요 | 0 to 32000 |
| `output_height` | 0 값은 원본과 동일한 높이로 출력하거나 `output_width`가 지정된 경우 비례적으로 조정됨을 의미합니다. Wonder 3.5는 1x에서 6x까지의 업스케일 배수만 지원합니다. Bloom 2와 Wonder 3.5는 입력 비율을 유지하며 요청된 크기를 목표로 처리합니다. (기본값: 0) | INT | 아니요 | 0 to 32000 |

### Reimagine 설정

다음 설정은 `model`이 `"Reimagine"`으로 설정된 경우 적용됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 창의적인 업스케일링 안내를 위한 선택적 텍스트 프롬프트입니다. (기본값: "") | STRING | 예 | 모든 텍스트 |
| `creativity` | 향상 작업의 창의성 수준입니다. (기본값: 3) | INT | 예 | 1 to 9 |
| `subject_detection` | 피사체 감지 모드입니다. | STRING | 예 | `"All"`<br />`"Foreground"`<br />`"Background"` |
| `face_enhancement` | 처리 중 얼굴(있는 경우)을 향상시킵니다. (기본값: True) | BOOLEAN | 예 | true<br />false |
| `face_enhancement_creativity` | 얼굴 향상을 위한 창의성 수준을 설정합니다. (기본값: 0.0) | FLOAT | 예 | 0.0 to 1.0 |
| `face_enhancement_strength` | 향상된 얼굴이 배경에 비해 얼마나 선명한지 제어합니다. (기본값: 1.0) | FLOAT | 예 | 0.0 to 1.0 |
| `face_preservation` | 피사체의 얼굴 정체성을 보존합니다. (기본값: True) | BOOLEAN | 예 | true<br />false |
| `color_preservation` | 원본 색상을 보존합니다. (기본값: True) | BOOLEAN | 예 | true<br />false |
| `crop_to_fill` | 기본적으로 출력 비율이 다른 경우 이미지에 레터박스가 적용됩니다. 활성화하면 출력 크기를 채우도록 이미지를 잘라냅니다. (기본값: False) | BOOLEAN | 예 | true<br />false |

### Bloom 2 설정

다음 설정은 `model`이 `"Bloom 2"`로 설정된 경우 적용됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성을 위한 선택적 텍스트 프롬프트입니다. 비워 두면 입력 이미지에서 프롬프트가 자동 생성됩니다. (기본값: "") | STRING | 예 | 모든 텍스트 |
| `creativity` | 1은 절제된 향상이고, 9는 새로 생성된 디테일이 포함된 뚜렷한 재해석입니다. (기본값: 3) | INT | 예 | 1 to 9 |
| `seed` | 재현 가능한 생성을 위한 시드입니다. (기본값: 2) | INT | 예 | 1 to 2000 |
| `color_preservation` | 원본 색상을 보존합니다. (기본값: True) | BOOLEAN | 예 | true<br />false |
| `grain` | 출력 이미지에 그레인을 추가합니다. (기본값: False) | BOOLEAN | 예 | true<br />false |
| `grain_model` | 사용할 그레인 모델입니다. 그레인이 비활성화된 경우 무시됩니다. | STRING | 예 | `"silver"`<br />`"gaussian"`<br />`"grey"` |
| `grain_strength` | 그레인 효과의 강도입니다. 그레인이 비활성화된 경우 무시됩니다. (기본값: 0.5) | FLOAT | 예 | 0.0 to 1.0 |
| `grain_size` | 그레인 입자의 크기입니다. 그레인이 비활성화된 경우 무시됩니다. (기본값: 1.0) | FLOAT | 예 | 1.0 to 5.0 |
| `grain_density` | 그레인 효과의 세기입니다. 그레인이 비활성화된 경우 무시됩니다. (기본값: 0.5) | FLOAT | 예 | 0.0 to 1.0 |
