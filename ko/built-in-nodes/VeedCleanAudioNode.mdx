VEED를 사용하여 음성에서 배경 노이즈를 제거합니다. 이 노드는 모든 언어의 음성을 위해 설계되었습니다. 음성 아래에 깔린 노이즈는 정리되고, 일시 정지 구간은 완전히 정리되며, 음악과 음향 효과는 보존되지 않고 제거됩니다. 출력은 48 kHz 모노 오디오입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `audio` | 30분 미만의 음성 녹음입니다. | AUDIO | 예 | 최대 1799초 |
| `strength` | 음성 아래에서 제거되는 노이즈의 양입니다. 값을 낮추면 음성 뒤의 룸 톤이 더 많이 유지됩니다. 단어 사이의 일시 정지는 항상 완전히 정리되며, 기본값보다 높은 값은 거의 변화를 주지 않습니다. (기본값: 0.874) | FLOAT | 예 | 0.0~1.0 (단계 0.001) |
| `loudness` | 출력 라우드니스를 정규화할지 여부입니다. `"normalize"`는 출력을 `target_lufs`로 설정하고, `"keep input level"`은 레벨을 그대로 유지합니다. 옵션을 선택하면 해당 매개변수가 표시됩니다. (기본값: `"normalize"`) | DYNAMIC_COMBO | 예 | `"normalize"`<br />`"keep input level"` |
| `target_lufs` | LUFS 단위의 출력 통합 라우드니스입니다. 피크는 -1.1 dBTP로 제한되므로, 목표 라우드니스가 큰 경우 조기에 상한에 도달합니다(일반 음성 기준 약 -15 LUFS). `loudness`가 `"normalize"`일 때 사용할 수 있습니다(기본값: -19.0). | FLOAT | 예 | -40.0~-8.0 (단계 0.1) |

녹음 길이가 1799초를 초과하면 노드가 오류와 함께 중지됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `AUDIO` | 정리된 음성이며 48 kHz 모노 오디오입니다. | AUDIO |
