이 노드는 FLUX 3를 사용해 기존 비디오 클립을 이어갑니다. 새 클립은 제공한 비디오의 마지막 프레임부터 이어집니다. 소스 클립을 업로드하고, 프롬프트와 설정을 생성 서비스로 전송한 뒤, 준비가 완료되면 생성된 이어짐 비디오를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video` | 이어갈 클립입니다. | VIDEO | 예 | 단일 비디오 클립 |
| `prompt` | 이어짐 영상에 무엇이 표시되어야 하는지입니다. 프롬프트는 생성 전에 해석 및 확장됩니다. (기본값: "") | STRING | 예 | 비어 있지 않은 텍스트 (최소 1자) |
| `aspect_ratio` | 출력 화면 비율입니다. 'auto'는 프롬프트와 입력에서 하나를 선택합니다. (기본값: "auto") | COMBO | 예 | "auto" (기본값)<br />여러 사전 정의된 옵션 |
| `duration` | 클립 길이(초)입니다. 'auto'는 길이를 콘텐츠에 맞춥니다. (기본값: "auto") | COMBO | 예 | "auto" (기본값)<br />초 단위 숫자 값 |
| `resolution` | 출력 해상도입니다. (기본값: "720p") | COMBO | 예 | "720p" (기본값)<br />"1080p"<br />기타 사전 정의된 옵션 |
| `generate_audio` | 동기화된 오디오(주변음, 음성, 효과음)를 생성합니다. 끄면 오디오 트랙이 없는 비디오가 생성됩니다. (기본값: true) | BOOLEAN | 예 | true<br />false |
| `safety_tolerance` | 검열 허용 범위이며, 0이 가장 엄격합니다. 이미지나 비디오를 전송하는 요청은 여기에서 설정한 값과 관계없이 2로 제한됩니다. (고급 매개변수, 기본값: 2) | INT | 예 | 0 - 4 (비디오 요청의 경우 실효 최대값: 2) |
| `seed` | 노드를 다시 실행할지 결정하는 시드입니다. FLUX 3는 자체 시드를 선택하므로, 이 값과 관계없이 실제 결과는 비결정적입니다. (기본값: 42) | INT | 예 | 0 - 4294967295 (0xFFFFFFFF) |

### 참고 사항

- `prompt`는 최소 한 글자 이상 포함해야 하며, 그렇지 않으면 생성이 실패합니다. 이 필드는 기본적으로 빈 문자열이지만, 노드를 실행하려면 비어 있지 않은 프롬프트가 필요합니다.
- `safety_tolerance`는 0부터 4까지의 모든 값을 허용하지만, 이 노드는 비디오를 API로 전송하므로 선택한 값과 관계없이 실효 허용 범위가 2로 제한됩니다.
- `duration`이 숫자로 설정되면 정수 초로 변환됩니다. 특수 값 "auto"는 서비스가 길이를 콘텐츠에 맞추도록 합니다.
- `aspect_ratio`, `duration`, `resolution`의 정확한 옵션 목록은 노드 내부에서 정의됩니다. 해상도 옵션에는 최소한 "720p"(기본값)와 "1080p"가 포함됩니다. 가격은 선택한 `resolution`과 `duration`을 기준으로 계산됩니다. "1080p"는 초당 $0.7579로 청구되며, 다른 해상도는 초당 $0.5863로 청구됩니다.
- `seed`는 노드의 재실행 여부만 제어하며, 생성 서비스로 전송되지 않습니다.
- 인증 및 노드 식별 필드(`auth_token_comfy_org`, `api_key_comfy_org`, `unique_id`)는 숨겨져 있으며 플랫폼에서 자동으로 처리됩니다.
