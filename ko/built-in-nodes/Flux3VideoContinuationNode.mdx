이 노드는 FLUX 3로 기존 비디오 클립을 이어서 생성합니다. 새 클립은 제공한 비디오의 마지막 프레임에서 이어집니다. 소스 클립을 업로드하고 프롬프트와 설정을 생성 서비스로 전송한 후, 결과 연속 비디오가 준비되면 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video` | 이어서 생성할 클립입니다. | VIDEO | 예 | 단일 비디오 클립 |
| `prompt` | 연속 생성 결과에 표시할 내용입니다. 프롬프트는 생성 전에 해석되고 확장됩니다. (기본값: "") | STRING | 예 | 비어 있지 않은 텍스트 (최소 1자) |
| `aspect_ratio` | 출력 화면 비율입니다. 'auto'는 프롬프트와 입력에서 비율을 선택합니다. (기본값: "auto") | COMBO | 예 | "auto" (기본값)<br />사전 정의된 여러 옵션 |
| `duration` | 클립 길이(초)입니다. 'auto'는 콘텐츠에 맞게 길이를 조정합니다. (기본값: "auto") | COMBO | 예 | "auto" (기본값)<br />초 단위의 숫자 값 |
| `resolution` | 출력 해상도입니다. (기본값: "720p") | COMBO | 예 | "720p" (기본값)<br />"1080p"<br />기타 사전 정의된 옵션 |
| `generate_audio` | 동기화된 오디오(주변음, 음성, 효과음)를 생성합니다. 끄면 오디오 트랙이 없는 비디오가 생성됩니다. (기본값: true) | BOOLEAN | 예 | true<br />false |
| `safety_tolerance` | 검열 허용 수준입니다. 0이 가장 엄격합니다. 이미지나 비디오를 전송하는 요청은 여기서 설정한 값과 관계없이 2로 제한됩니다. (고급 매개변수, 기본값: 2) | INT | 예 | 0 - 4 (비디오 요청 시 유효 최대값: 2) |
| `seed` | 노드 재실행 여부를 결정하는 시드입니다. FLUX 3는 자체 시드를 선택하므로 이 값과 관계없이 실제 결과는 비결정적입니다. (고급 매개변수, 기본값: 42) | INT | 예 | 0 - 4294967295 (0xFFFFFFFF) |

### 참고

- `prompt`는 최소한 한 자 이상이어야 하며, 그렇지 않으면 생성이 실패합니다. 필드의 기본값은 빈 문자열이지만, 노드를 실행하려면 비어 있지 않은 프롬프트가 필요합니다.
- `safety_tolerance`는 0에서 4 사이의 모든 값을 허용하지만, 이 노드는 API로 비디오를 전송하므로 선택한 값과 관계없이 실제 허용 수준은 2로 제한됩니다.
- `duration`을 숫자로 설정하면 초 단위의 정수로 변환됩니다. 특수 값 "auto"는 서비스가 콘텐츠에 맞게 길이를 조정하도록 합니다.
- `aspect_ratio`, `duration`, `resolution`의 정확한 옵션 목록은 노드 내부적으로 정의됩니다. 해상도 옵션에는 최소한 "720p"(기본값)와 "1080p"가 포함됩니다. 요금은 선택한 `resolution`과 `duration`을 기준으로 계산됩니다. "1080p"는 초당 $0.7579로 청구되고, 다른 해상도는 초당 $0.5863로 청구됩니다.
- 인증 및 노드 식별 필드(`auth_token_comfy_org`, `api_key_comfy_org`, `unique_id`)는 숨겨져 있으며 플랫폼에서 자동으로 처리됩니다.
