이 노드는 FLUX 3를 사용하여 기존 비디오 클립을 이어서 생성하므로, 새 클립은 제공한 비디오의 마지막 프레임부터 이어집니다. 소스 클립을 업로드하고 프롬프트와 설정을 생성 서비스로 전송한 후, 준비가 완료되면 결과 연속 비디오를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video` | 이어서 생성할 클립입니다. | VIDEO | 예 | 단일 비디오 클립 |
| `prompt` | 연속 생성에서 보여줄 내용입니다. 프롬프트는 생성 전에 해석 및 확장됩니다. (기본값: "") | STRING | 예 | 비어 있지 않은 텍스트 (최소 1자) |
| `aspect_ratio` | 출력 화면 비율입니다. 'auto'는 프롬프트와 입력에서 하나를 자동으로 선택합니다. (기본값: "auto") | STRING | 예 | 사전 정의된 여러 옵션 (기본값: "auto") |
| `duration` | 클립 길이(초)입니다. 'auto'는 콘텐츠에 맞게 길이를 조정합니다. (기본값: "auto") | STRING | 예 | "auto" (기본값)<br />초 단위 숫자 값 |
| `resolution` | 출력 해상도입니다. (기본값: "720p") | STRING | 예 | 사전 정의된 여러 옵션 (기본값: "720p") |
| `generate_audio` | 동기화된 오디오(주변음, 음성, 효과음)를 생성합니다. Off를 선택하면 오디오 트랙이 없는 비디오가 생성됩니다. (기본값: true) | BOOLEAN | 예 | true<br />false |
| `safety_tolerance` | 검열 허용 수준입니다. 0이 가장 엄격합니다. 이미지나 비디오를 전송하는 요청은 여기에 설정한 값과 관계없이 2로 제한됩니다. (고급 매개변수, 기본값: 2) | INT | 예 | 0 - 4 (비디오 요청의 유효 최대값: 2) |
| `seed` | 노드 재실행 여부를 결정하는 시드입니다. FLUX 3는 자체 시드를 선택하므로 실제 결과는 이 값과 관계없이 비결정적입니다. (고급 매개변수, 기본값: 42) | INT | 예 | 0 - 4294967295 (0xFFFFFFFF) |

### 참고 사항

- `prompt`는 최소 하나의 문자를 포함해야 하며, 그렇지 않으면 생성이 실패합니다. 필드가 기본적으로 빈 문자열로 설정되어 있지만, 노드를 실행하려면 비어 있지 않은 프롬프트가 필요합니다.
- `safety_tolerance`는 0부터 4까지의 모든 값을 허용하지만, 이 노드는 API에 비디오를 전송하므로 선택한 값과 관계없이 유효 허용 수준은 2로 제한됩니다.
- `duration`이 숫자로 설정되면 정수 초로 변환됩니다. 특수 값 "auto"를 사용하면 서비스가 콘텐츠에 맞게 길이를 조정합니다.
- `aspect_ratio`, `duration`, `resolution`의 정확한 옵션 목록은 노드 내부에서 정의됩니다. 해상도 옵션에는 최소한 기본값인 "720p"와 다른 요금 체계가 적용되는 "1080p"가 포함됩니다.
- 인증 및 노드 식별 필드(`auth_token_comfy_org`, `api_key_comfy_org`, `unique_id`)는 숨겨져 있으며 플랫폼에서 자동으로 처리됩니다.
