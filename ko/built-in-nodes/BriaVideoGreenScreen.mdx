이 노드는 Bria API를 사용하여 비디오의 배경을 단색 크로마키 화면으로 교체합니다. 입력 비디오를 처리하고, 원래 배경이 제거된 후 균일한 녹색 또는 파란색 화면 색상으로 대체된 새 비디오를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video` | 처리할 입력 비디오 | VIDEO | 예 | 비디오 파일 |
| `green_shade` | 전경 뒤에 적용되는 단색 크로마키 색상: broadcast_green(#00B140), chroma_green(#00FF00) 또는 blue_screen(#0000FF) | COMBO | 예 | `"broadcast_green"`<br />`"chroma_green"`<br />`"blue_screen"` |
| `seed` | 시드는 노드의 재실행 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다(기본값: 0) | INT | 예 | 0 ~ 2147483647 |

**참고:** 입력 비디오의 길이는 60초를 초과할 수 없습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 원래 배경이 선택한 크로마키 색상으로 대체된 처리된 비디오(MP4, H.264) | VIDEO |
