이 노드는 하나 이상의 참조 이미지를 인코딩하고, 해당 잠재값을 편집 모델이 사용하는 컨디셔닝에 추가합니다. 이는 Set Reference Latent의 다중 이미지 대응 버전입니다. VAE와 참조 이미지 세트를 연결하면, 노드가 인코딩된 모든 잠재값을 positive 컨디셔닝에 연결하고, negative 컨디셔닝이 연결된 경우에는 negative 컨디셔닝에도 연결합니다. 모델이 단일 잠재값 대신 여러 참조 이미지를 한 번에 기대할 때 사용합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `positive` | 참조 잠재값으로 수정할 positive 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `negative` | 동일한 참조 잠재값을 받는 선택적 negative 컨디셔닝입니다. 연결하지 않으면 `negative` 출력에서 수정된 positive 컨디셔닝을 재사용합니다. | CONDITIONING | 아니요 | - |
| `vae` | 연결된 참조 이미지를 인코딩하는 데 사용되는 VAE입니다. VAE가 연결되지 않으면 참조 이미지는 무시됩니다. | VAE | 아니요 | - |
| `resolution` | 인코딩 전에 각 참조 이미지를 준비하는 방식입니다. `"keep resolution"`은 들어온 크기 그대로 인코딩하고, `"resize"`는 종횡비를 유지하면서 목표 메가픽셀 수로 조정하며, 이 경우 `megapixels`가 표시됩니다. (기본값: "keep resolution") | DYNAMIC_COMBO | 예 | `"keep resolution"`<br />`"resize"` |
| `images` | 확장 가능한 슬롯: 하나 이상의 참조 이미지(`image_1`, `image_2`, ...)를 연결하여 참조로 사용합니다. 이미지는 슬롯 순서대로 인코딩되어 그 순서대로 컨디셔닝에 추가됩니다. | IMAGE | 아니요 | 1 ~ 100 |

### 리사이즈 입력

이 옵션은 `resolution`이 `"resize"`로 설정된 경우 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `megapixels` | 종횡비를 유지한 각 참조 이미지의 목표 크기입니다. 1.0은 약 1024 x 1024 픽셀입니다. (기본값: 1.0) | FLOAT | 예 | 0.01 ~ 16.0 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `positive` | 인코딩된 참조 잠재값이 추가된 positive 컨디셔닝입니다. | CONDITIONING |
| `negative` | 동일한 참조 잠재값이 추가된 negative 컨디셔닝입니다. negative 컨디셔닝이 연결되지 않은 경우 positive 출력을 반환합니다. | CONDITIONING |
| `empty_latent` | 첫 번째 참조 잠재값에 0.0을 곱한 값으로, 샘플러를 시드할 준비가 되어 있습니다. 참조 잠재값이 생성되지 않으면 선택한 해상도의 정사각형 빈 잠재값이 대신 반환됩니다. | LATENT |

## 참고

- 잠재값은 대체되지 않고 추가되므로, 여러 Set Reference Multi Latent 노드를 연결하면 참조가 누적됩니다.
- 연결된 각 이미지는 개별적으로 인코딩되므로 참조 이미지들이 같은 크기를 공유할 필요가 없습니다.
- VAE가 연결되지 않았거나 이미지가 연결되지 않은 경우, `positive`와 `negative`는 변경되지 않은 상태로 반환되고 `empty_latent`는 정사각형 빈 잠재값입니다. 1024 x 1024이며, `resolution`이 `"resize"`이면 `megapixels`에서 계산된 크기입니다.
