Kling Image Generation 노드는 텍스트 프롬프트로부터 이미지를 생성하며, 안내를 위해 참조 이미지를 사용하는 옵션을 제공합니다. 텍스트 설명과 참조 설정에 따라 하나 이상의 이미지를 생성한 다음, 생성된 이미지를 출력으로 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 긍정 텍스트 프롬프트입니다. 필수이며, 1자 이상 500자 이하여야 합니다. | STRING | 예 | 최대 500자 |
| `부정 프롬프트` | 부정 텍스트 프롬프트입니다. | STRING | 예 | 최대 500자 |
| `이미지 종류` | 이미지 참조 유형 선택(고급)입니다. 참조 이미지가 제공될 때 필수입니다. | COMBO | 예 | `"subject_reference"`<br />`"style_reference"` |
| `이미지 충실도` | 사용자 업로드 이미지에 대한 참조 강도입니다(기본값: 0.5, 고급). | FLOAT | 예 | 0.0 - 1.0 |
| `사람 충실도` | 피사체 참조 유사도입니다(기본값: 0.45, 고급). | FLOAT | 예 | 0.0 - 1.0 |
| `모델 명` | 이미지 생성용 모델 선택입니다(기본값: "kling-v3"). | COMBO | 예 | `"kling-v3"` |
| `종횡비` | 생성된 이미지의 종횡비입니다(기본값: "16:9"). | COMBO | 예 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"`<br />`"21:9"`<br />`"9:21"` |
| `개수` | 생성되는 이미지 수입니다(기본값: 1). | INT | 예 | 1 - 9 |
| `이미지` | 선택적 참조 이미지입니다. | IMAGE | 아니요 | - |
| `시드` | 시드는 노드의 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다(기본값: 0). | INT | 아니요 | 0 - 2147483647 |

**매개변수 제약 사항:**

- `image` 매개변수는 선택 사항입니다. 참조 이미지가 제공되면 `image_type` 매개변수가 해당 참조를 피사체 참조로 사용할지 스타일 참조로 사용할지 결정합니다.
- 참조 이미지가 제공되지 않으면 참조 관련 설정(`image_type`, `image_fidelity`, `human_fidelity`)은 결과에 영향을 주지 않습니다.
- `prompt` 및 `negative_prompt`의 최대 길이는 500자입니다.
- `seed` 매개변수는 선택 사항이며 결정적 결과를 보장하지 않습니다.
- `n` 매개변수는 생성되는 이미지 수를 제어하며 요청 가격도 결정합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 입력 매개변수를 기반으로 생성된 이미지입니다. `n`이 1보다 크면 여러 이미지가 배치로 반환됩니다. | IMAGE |
