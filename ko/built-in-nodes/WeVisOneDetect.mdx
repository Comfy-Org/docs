WeVisOne-VL Detect는 텍스트 프롬프트를 사용해 이미지에서 객체를 찾고, 선택한 작업에 따라 박스, 알파 매트, 포인트 또는 모델 자체의 답변을 반환합니다. 개방형 어휘 검출 및 분할, 지시 표현, 포인팅, 계수 및 OCR 그라운딩을 지원하며, 배치의 이미지당 하나의 프롬프트를 실행합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | 체크포인트를 로드하는 WeVisOne-VL 텍스트 인코더입니다. | CLIP | 예 | - |
| `image` | 검색할 이미지 또는 이미지 배치입니다. | IMAGE | 예 | - |
| `task` | 노드가 반환해야 하는 항목입니다. segmentation은 박스와 알파 매트를 반환하고, detection, referring, ocr 및 ocr_grounding은 박스를 반환합니다. point 및 count_point는 포인트를 반환하고, count_box는 박스와 함께 개수를 세며, visual_prompt는 `bboxes`의 참조 박스와 유사한 객체를 찾고, freeform은 쿼리를 변경하지 않고 전송하며 텍스트만 반환합니다(기본값: "segmentation"). | COMBO | 예 | `"segmentation"`<br />`"detection"`<br />`"referring"`<br />`"point"`<br />`"count_box"`<br />`"count_point"`<br />`"ocr"`<br />`"ocr_grounding"`<br />`"visual_prompt"`<br />`"freeform"` |
| `query` | 찾을 대상을 일상적인 언어로 입력합니다(예: "빨간 머그잔"). `detection` 및 `point`는 한 줄에 하나의 레이블을 읽고, `count_box` 및 `count_point`는 지정한 대상을 세며, `ocr_grounding`은 이 정확한 텍스트를 찾고, `visual_prompt`는 대신 `bboxes`를 사용하며, `freeform`은 이를 전체 프롬프트로 전송합니다. `ocr`은 이를 무시합니다. | STRING | 예 | - |
| `bboxes` | `visual_prompt`가 찾을 객체의 예시로 사용하는 참조 박스입니다. | BOUNDING_BOX | 아니요 | - |
| `individual_masks` | 프레임당 하나의 결합된 매트 대신 `bboxes` 순서와 프레임별로 박스마다 하나의 매트를 반환합니다(기본값: false). | BOOLEAN | 아니요 | true<br />false |
| `max_length` | 모델이 답변으로 생성할 수 있는 최대 토큰 수입니다(기본값: 4096). | INT | 예 | 1~32768 |

**참고:** 매트는 모델이 객체 참조로 답할 때만 채워지며, 이는 segmentation 및 visual prompt 작업에서 요구하는 방식입니다. 다른 작업은 빈 매트와 함께 박스, 포인트 또는 텍스트를 반환합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `masks` | 일치한 객체의 알파 매트로, 기본적으로 프레임당 하나 또는 `individual_masks` 사용 시 박스당 하나입니다. | MASK |
| `bboxes` | 각 이미지에서 찾은 박스로, `x`, `y`, `width`, `height` 및 `label`로 저장됩니다. | BOUNDING_BOX |
| `points` | 픽셀 단위의 JSON 포인트로, `[{"x", "y", "label", "frame"}]` 형태이며 `point` 및 `count_point` 작업에서 채워집니다. | STRING |
| `text` | 모델의 원시 답변으로, 이미지당 한 줄입니다. | STRING |
