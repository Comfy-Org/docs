Convert String to Combo 노드는 텍스트 문자열을 입력으로 받아 Combo 데이터 타입으로 변환합니다. 이를 통해 텍스트 값을 Combo 입력이 필요한 다른 노드의 선택 항목으로 사용할 수 있습니다. 문자열 값을 변경하지 않고 그대로 전달하지만 데이터 타입만 변경합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `string` | Combo 타입으로 변환할 텍스트 문자열입니다. | STRING | 예 | 해당 없음 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `output` | Combo 데이터 타입으로 형식화된 입력 문자열입니다. | COMBO |
