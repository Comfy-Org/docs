Bria Expand Image는 Bria로 새 콘텐츠를 생성하여 이미지를 원래 경계 너머로 확장합니다. 대상 종횡비, 사용자 지정 비율 또는 원본 이미지를 수동으로 배치한 캔버스를 선택할 수 있습니다. 확장은 텍스트 프롬프트로 안내할 수 있으며, 프롬프트를 비워 두면 Bria가 자동으로 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 확장할 입력 이미지입니다. | IMAGE | 예 | — |
| `expand_mode` | 확장된 이미지의 대상 모양입니다. 사전 설정된 종횡비, 사용자 지정 비율 또는 캔버스에 원본 이미지를 수동으로 배치하는 방식입니다. `manual` 모드는 1:2보다 세로로 긴 캔버스에 도달할 수 있는 유일한 모드입니다. `custom_ratio`를 선택하면 `ratio_width`와 `ratio_height`가 표시됩니다. `manual`을 선택하면 캔버스 및 이미지 배치 매개변수가 표시됩니다. | DYNAMIC_COMBO | 예 | `"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"`<br />`"custom_ratio"`<br />`"manual"` |
| `ratio_width` | 대상 비율의 가로 변입니다. 21과 9를 입력하면 21:9가 됩니다. 기본값: 21. | INT | 조건부 | 1–100 |
| `ratio_height` | 대상 비율의 세로 변입니다. 21과 9를 입력하면 21:9가 됩니다. Bria는 가로/세로 비율이 0.5에서 3.0 사이인 경우만 허용하므로, 1:2보다 세로로 긴 비율은 manual 모드가 필요합니다. 기본값: 9. | INT | 조건부 | 1–100 |
| `canvas_width` | 출력 캔버스의 픽셀 너비입니다. 기본값: 1000. | INT | 조건부 | 64–5000 |
| `canvas_height` | 출력 캔버스의 픽셀 높이입니다. 기본값: 1000. | INT | 조건부 | 64–5000 |
| `image_width` | 캔버스 내 원본 이미지의 너비입니다. 기본값: 500. | INT | 조건부 | 1–5000 |
| `image_height` | 캔버스 내 원본 이미지의 높이입니다. 기본값: 500. | INT | 조건부 | 1–5000 |
| `image_x` | 캔버스 내 이미지 왼쪽 위 모서리의 X 위치입니다. 캔버스 밖에 위치할 수 있으며, 이 경우 이미지가 잘립니다. 기본값: 250. | INT | 조건부 | -5000–5000 |
| `image_y` | 캔버스 내 이미지 왼쪽 위 모서리의 Y 위치입니다. 캔버스 밖에 위치할 수 있으며, 이 경우 이미지가 잘립니다. 기본값: 250. | INT | 조건부 | -5000–5000 |
| `prompt` | 확장된 장면에 대한 선택적 설명입니다. 비어 있으면 Bria가 이미지에서 자동으로 생성합니다. 기본값: 빈 문자열. | STRING | 아니요 | 모든 문자열 |
| `negative_prompt` | 확장을 위한 선택적 네거티브 프롬프트입니다. 기본값: 빈 문자열. | STRING | 아니요 | 모든 문자열 |
| `seed` | 무작위 생성 프로세스의 시드입니다. 기본값: 42. | INT | 아니요 | 1–2147483647 |
| `moderation` | 모더레이션 설정입니다. `true`로 설정하면 추가 모더레이션 옵션이 표시됩니다. | DYNAMIC_COMBO | 아니요 | `"false"`<br />`"true"` |
| `prompt_content_moderation` | 활성화하면 프롬프트 콘텐츠를 모더레이션합니다. 기본값: false. `moderation`이 `true`일 때만 사용할 수 있습니다. | BOOLEAN | 조건부 | true/false |
| `visual_input_moderation` | 활성화하면 시각적 입력을 모더레이션합니다. 기본값: false. `moderation`이 `true`일 때만 사용할 수 있습니다. | BOOLEAN | 조건부 | true/false |
| `visual_output_moderation` | 활성화하면 시각적 출력을 모더레이션합니다. 기본값: false. `moderation`이 `true`일 때만 사용할 수 있습니다. | BOOLEAN | 조건부 | true/false |

`expand_mode`가 `custom_ratio`인 경우, `ratio_width`와 `ratio_height`가 대상 종횡비를 정의합니다. Bria는 가로-세로 비율이 0.5에서 3.0 사이인 경우만 허용합니다. 비율이 이 범위를 벗어나면 오류가 발생하며, 대신 `manual` 모드를 사용해야 합니다.

`expand_mode`가 `manual`인 경우, 원본 이미지가 지정된 크기와 위치로 캔버스에 배치됩니다. 이미지가 캔버스 밖으로 확장될 수 있으며, 이 경우 캔버스 밖의 부분은 잘립니다.

`moderation`이 `true`이면 세 가지 모더레이션 불리언 값이 Bria로 전송됩니다. `moderation`이 `false`이면 해당 값들은 무시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | Bria가 생성한 확장된 이미지입니다. | IMAGE |
| `prompt` | 확장에 사용된 프롬프트입니다. 프롬프트 입력이 비어 있으면 Bria가 자동으로 생성합니다. | STRING |
