Bria Expand Image는 Bria를 사용하여 새로운 콘텐츠를 생성함으로써 이미지를 원본 경계 너머로 확장합니다. 대상 가로세로 비율, 사용자 지정 비율을 선택하거나 원본 이미지를 수동으로 배치하여 캔버스를 정의할 수 있습니다. 확장은 텍스트 프롬프트로 안내할 수 있으며, 프롬프트를 비워 두면 Bria가 자동으로 하나를 생성합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 확장할 입력 이미지입니다. | IMAGE | 예 | — |
| `expand_mode` | 확장된 이미지의 대상 형태입니다. 사전 설정된 가로세로 비율, 사용자 지정 비율 또는 캔버스에 원본 이미지를 수동으로 배치하는 방식 중 하나입니다. 수동 모드는 1:2보다 세로로 긴 캔버스에 도달할 수 있는 유일한 모드입니다. `custom_ratio`를 선택하면 `ratio_width`와 `ratio_height`가 표시됩니다. `manual`을 선택하면 캔버스 및 이미지 배치 매개변수가 표시됩니다. | DYNAMIC_COMBO | 예 | `"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"`<br />`"custom_ratio"`<br />`"manual"` |
| `prompt` | 확장된 장면에 대한 선택적 설명입니다. 비워 두면 Bria가 이미지에서 하나를 생성합니다. 기본값: 빈 문자열. | STRING | 예 | 임의의 문자열 |
| `negative_prompt` | 확장을 위한 선택적 부정 프롬프트입니다. 기본값: 빈 문자열. | STRING | 예 | 임의의 문자열 |
| `seed` | 무작위 생성 프로세스의 시드입니다. 기본값: 42. | INT | 예 | 1–2147483647 |
| `moderation` | 검열 설정입니다. `true`로 설정하면 추가 검열 옵션이 표시됩니다. | DYNAMIC_COMBO | 예 | `"false"`<br />`"true"` |

### 사용자 지정 비율 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `ratio_width` | 대상 비율의 너비 측입니다. 21과 9는 21:9가 됩니다. 기본값: 21. | INT | 예 | 1–100 |
| `ratio_height` | 대상 비율의 높이 측입니다. 21과 9는 21:9가 됩니다. Bria는 너비/높이가 0.5에서 3.0 사이인 값만 허용하므로, 1:2보다 세로로 긴 비율에는 수동 모드가 필요합니다. 기본값: 9. | INT | 예 | 1–100 |

### 수동 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `canvas_width` | 출력 캔버스의 너비(픽셀)입니다. 기본값: 1000. | INT | 예 | 64–5000 |
| `canvas_height` | 출력 캔버스의 높이(픽셀)입니다. 기본값: 1000. | INT | 예 | 64–5000 |
| `image_width` | 캔버스 내 원본 이미지의 너비입니다. 기본값: 500. | INT | 예 | 1–5000 |
| `image_height` | 캔버스 내 원본 이미지의 높이입니다. 기본값: 500. | INT | 예 | 1–5000 |
| `image_x` | 캔버스 내 이미지 왼쪽 위 모서리의 X 위치입니다. 캔버스 밖에 놓일 수 있으며, 이 경우 이미지가 잘립니다. 기본값: 250. | INT | 예 | -5000–5000 |
| `image_y` | 캔버스 내 이미지 왼쪽 위 모서리의 Y 위치입니다. 캔버스 밖에 놓일 수 있으며, 이 경우 이미지가 잘립니다. 기본값: 250. | INT | 예 | -5000–5000 |

### 검열 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | 사용하도록 설정하면 프롬프트 콘텐츠를 검열합니다. 기본값: false. `moderation`이 `true`일 때만 사용할 수 있습니다. | BOOLEAN | 예 | true/false |
| `visual_input_moderation` | 사용하도록 설정하면 시각적 입력을 검열합니다. 기본값: false. `moderation`이 `true`일 때만 사용할 수 있습니다. | BOOLEAN | 예 | true/false |
| `visual_output_moderation` | 사용하도록 설정하면 시각적 출력을 검열합니다. 기본값: false. `moderation`이 `true`일 때만 사용할 수 있습니다. | BOOLEAN | 예 | true/false |

사전 설정된 가로세로 비율 옵션(`1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`)에는 추가 입력이 없습니다.

`expand_mode`가 `custom_ratio`일 때 `ratio_width`와 `ratio_height`가 대상 가로세로 비율을 정의합니다. Bria는 너비 대 높이 비율이 0.5에서 3.0 사이인 값만 허용합니다. 비율이 이 범위를 벗어나면 오류가 발생하며 대신 `manual` 모드를 사용해야 합니다.

`expand_mode`가 `manual`일 때 원본 이미지는 지정된 크기와 위치로 캔버스에 배치됩니다. 이미지가 캔버스 밖으로 확장될 수 있으며, 이 경우 바깥 부분은 잘립니다.

`moderation`이 `true`이면 세 가지 검열 불리언이 Bria로 전송됩니다. `moderation`이 `false`이면 무시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | Bria가 생성한 확장된 이미지입니다. | IMAGE |
| `prompt` | 확장에 사용된 프롬프트입니다. 프롬프트 입력이 비어 있으면 Bria가 자동 생성합니다. | STRING |
