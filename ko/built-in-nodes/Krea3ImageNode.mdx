Krea 3 Image는 Krea 3로 이미지를 편집하거나, 이미지가 연결되지 않은 경우 텍스트 프롬프트로 새 이미지를 생성합니다. 최대 8개의 이미지를 연결하고 변경할 항목과 유지할 항목을 설명하세요. 프롬프트에서는 이를 @Image1, @Image2 등으로 참조합니다. 가로세로 비율과 해상도는 출력 크기를 설정하며, thinking 모드는 속도를 희생하여 더 자세한 계획을 세웁니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 사용할 Krea 3 모델입니다. 모델을 선택하면 해당 모델이 허용하는 매개변수가 표시됩니다. | DYNAMIC_COMBO | 예 | `"Krea 3"` |

### Krea 3 입력

이 입력들은 `model`이 `Krea 3`로 설정된 경우 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model.images` | 편집할 이미지이며 연결 순서대로 번호가 지정됩니다. 연결된 각 이미지는 8개 제한에 포함됩니다. 텍스트만으로 생성하려면 비워 두세요. | IMAGE | 아니요 | 0~8개 이미지 |
| `model.prompt` | 변경할 내용과 유지할 내용입니다. 프롬프트에서 이미지를 `@Image1`, `@Image2` 등으로 또는 image 1, image 2, ...로 참조하세요. 프롬프트는 비워 둘 수 없습니다. | STRING | 예 | - |
| `model.aspect_ratio` | 결과의 가로세로 비율입니다. `"auto"`는 첫 번째 이미지를 따르며, 이미지가 연결되지 않은 경우 프롬프트를 따릅니다. (기본값: `"auto"`) | COMBO | 예 | `"auto"`<br />`"1:1"`<br />`"4:5"`<br />`"3:4"`<br />`"2:3"`<br />`"9:16"`<br />`"5:4"`<br />`"4:3"`<br />`"3:2"`<br />`"16:9"`<br />`"21:9"` |
| `model.resolution` | 출력 해상도입니다. `"2K"`는 `"1K"`보다 시간이 더 오래 걸리고 더 큰 이미지를 생성합니다. (기본값: `"2K"`) | COMBO | 예 | `"1K"`<br />`"2K"` |
| `model.thinking_mode` | Krea 3가 편집 계획에 얼마나 많은 작업을 투입할지 결정합니다. `"fast"`를 권장하며, `"high"`는 복잡한 편집을 더 자세히 계획하고 더 오래 걸립니다. `"ultra"`는 여러 후보를 생성해 가장 좋은 결과를 반환합니다. 이미지가 최소 1장 필요하고, 항상 2K로 출력하며, `precise_edit`을 지원하지 않습니다. (기본값: `"fast"`) | COMBO | 예 | `"fast"`<br />`"high"`<br />`"ultra"` |
| `model.precise_edit` | 편집된 영역 밖의 모든 것을 변경하지 않고 유지합니다. 연결된 이미지가 최소 하나 필요합니다. (기본값: False) | BOOLEAN | 예 | false<br />true |
| `model.seed` | 요청의 시드입니다(기본값: 42). Krea는 생성 전에 프롬프트를 다시 작성하므로 동일한 시드로도 같은 이미지가 반복되지 않습니다. | INT | 예 | 0 ~ 2147483647 |

`@Image3`과 같은 참조는 이미지가 최소 세 개 연결된 경우에만 허용되며, 그렇지 않으면 노드에서 오류가 발생합니다. 참조 이미지는 요청을 보내기 전에 업로드됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `image` | 생성되거나 편집된 이미지입니다. | IMAGE |
