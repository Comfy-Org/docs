여러 비디오 세그먼트를 하나의 비디오로 연결하며, 연결된 순서를 유지합니다. 호환되는 인코딩된 입력은 디코딩하지 않고 결합되며, 원본 오디오를 대체할 선택적 별도 오디오 트랙을 제공할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `videos` | 입력 순서대로 연결할 비디오 세그먼트입니다. 1~100개의 비디오를 연결할 수 있으며, 각 비디오는 `video_1`, `video_2` 등으로 레이블이 지정된 별도의 입력 슬롯으로 나타납니다. | VIDEO | 예 | 1~100개 세그먼트 |
| `codec` | 비디오 텐서를 인코딩하는 데 사용되는 코덱입니다. "auto"는 H.264를 사용하며, 호환되는 인코딩된 입력은 변경되지 않습니다. 기본값: "auto" | COMBO | 예 | `"auto"`<br />다른 옵션은 사용 가능한 비디오 코덱 유형에 따라 정의됩니다. |
| `complete_audio` | 연결된 비디오를 위한 선택적 전체 사운드트랙입니다. 입력 비디오에 포함된 오디오를 덮어씁니다. | AUDIO | 아니요 | 해당 없음 |

**참고:** `videos` 입력은 1~100개의 비디오 세그먼트를 허용합니다. `complete_audio`가 제공되면 모든 입력 비디오의 오디오를 대체합니다. `codec`이 "auto"로 설정된 경우, 호환되는 인코딩된 입력은 디코딩 없이 연결됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 연결된 비디오입니다. | VIDEO |
