OpenAI의 GPT Image 엔드포인트를 통해 이미지를 동기적으로 생성합니다. 이 노드는 텍스트 프롬프트에서 새 이미지를 생성하거나, 입력 이미지와 선택적 마스크가 제공되면 기존 이미지를 편집할 수 있습니다. gpt-image-1, gpt-image-1.5 및 gpt-image-2 모델을 지원하며 더 이상 사용되지 않음(deprecated)으로 표시되어 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | GPT Image용 텍스트 프롬프트 (기본값: "") | STRING | 예 | - |
| `시드` | 생성을 위한 무작위 시드 (기본값: 0) - 아직 백엔드에서 구현되지 않음 | INT | 아니요 | 0 ~ 2147483647 |
| `품질` | 이미지 품질, 비용과 생성 시간에 영향을 줍니다 (기본값: "low") | COMBO | 아니요 | "low"<br />"medium"<br />"high" |
| `배경` | 배경 유무에 따라 이미지를 반환합니다 (기본값: "auto") | COMBO | 아니요 | "auto"<br />"opaque"<br />"transparent" |
| `크기` | 이미지 크기. 사용자 지정 너비와 높이를 사용하려면 "Custom"을 선택하세요 (GPT Image 2 전용) (기본값: "auto") | COMBO | 아니요 | "auto"<br />"1024x1024"<br />"1024x1536"<br />"1536x1024"<br />"2048x2048"<br />"2048x1152"<br />"1152x2048"<br />"3840x2160"<br />"2160x3840"<br />"Custom" |
| `개수` | 생성할 이미지 수 (기본값: 1) | INT | 아니요 | 1 ~ 8 |
| `참조 이미지` | 이미지 편집을 위한 선택적 참조 이미지 | IMAGE | 아니요 | - |
| `마스크` | 인페인팅을 위한 선택적 마스크 (흰색 영역이 대체됩니다) | MASK | 아니요 | - |
| `model` | 사용할 GPT Image 모델 (기본값: "gpt-image-2") | COMBO | 아니요 | "gpt-image-1"<br />"gpt-image-1.5"<br />"gpt-image-2" |
| `custom_width` | `size`가 "Custom"일 때만 사용됩니다. 16의 배수여야 합니다 (GPT Image 2 전용) (기본값: 1024) | INT | 아니요 | 1024 ~ 3840, step 16 |
| `custom_height` | `size`가 "Custom"일 때만 사용됩니다. 16의 배수여야 합니다 (GPT Image 2 전용) (기본값: 1024) | INT | 아니요 | 1024 ~ 3840, step 16 |

**매개변수 제약 사항:**

- `image`가 제공되면 노드는 이미지 편집 모드로 전환됩니다.
- `mask`는 `image`가 제공될 때만 사용할 수 있습니다.
- `mask`를 사용할 때는 단일 이미지만 지원됩니다 (배치 크기는 1이어야 합니다).
- `mask`와 `image`는 크기가 같아야 합니다.
- 사용자 지정 해상도(`size` = "Custom")는 gpt-image-2 모델에서만 지원됩니다.
- 사용자 지정 너비와 높이는 16의 배수여야 합니다.
- 사용자 지정 해상도의 종횡비는 3:1을 초과할 수 없습니다.
- 사용자 지정 해상도의 총 픽셀 수는 655,360 이상 8,294,400 이하이어야 합니다.
- 투명 배경은 gpt-image-2 모델에서 지원되지 않습니다.
- 1536x1024보다 큰 크기(예: 2048x2048, 3840x2160)는 gpt-image-2 모델에서만 지원됩니다.
- `gpt-image-1` 및 `gpt-image-1.5` 모델은 `auto`, `1024x1024`, `1024x1536`, `1536x1024` 크기만 지원합니다.

|-------------|-------------|-----------|
| `IMAGE` | 생성 또는 편집된 이미지(들) | IMAGE |
