이 노드는 Bria API를 통해 오래되었거나 손상된 사진을 복원합니다. 그레인, 긁힘, 흐림을 제거하고, 노화로 인한 색 편향을 중화하며, 카드 마운트와 스튜디오 테두리를 잘라낼 수 있고, 얼굴을 다시 그립니다. 결과는 약 1메가픽셀 정도로 다시 렌더링되므로 입력과 픽셀 정렬되지 않습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 복원할 사진입니다. 업로드 전에 알파 채널이 제거됩니다. | IMAGE | 예 | - |
| `모더레이션` | 요청에 대한 검열 설정입니다. `"true"`를 선택하면 두 개의 추가 부울 토글이 나타나고, `"false"`를 선택하면 검열 플래그를 전송하지 않습니다. 기본값: `"false"`. | DYNAMIC_COMBO | 예 | `"false"`<br />`"true"` |

### 검열 입력

이 입력은 `moderation`이 `"true"`로 설정된 경우에만 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | 입력 이미지에 대한 시각 콘텐츠 검열을 활성화합니다. 기본값: false. | BOOLEAN | 아니요 | true<br />false |
| `visual_output_moderation` | 출력 이미지에 대한 시각 콘텐츠 검열을 활성화합니다. 기본값: false. | BOOLEAN | 아니요 | true<br />false |

**참고:** 이 노드는 전체 프레임을 약 1메가픽셀 정도로 다시 렌더링하므로 결과는 입력과 픽셀 정렬되지 않습니다. 이미지를 확대하려면 이 노드 대신 Bria Increase Resolution 노드를 사용하십시오.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | Bria에서 반환된 복원된 사진입니다. | IMAGE |
| `structured_prompt` | Bria FIBO Image Edit로 후속 편집을 하기 위한 편집된 이미지의 구조화된 설명입니다. | STRING |
