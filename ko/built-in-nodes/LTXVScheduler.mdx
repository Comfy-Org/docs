LTXVScheduler 노드는 사용자 정의 샘플링 프로세스를 위한 시그마 값을 생성합니다. 제공된 latent의 토큰 수로부터 노이즈 스케줄을 계산하거나, latent가 연결되지 않은 경우 기본값인 4096개의 토큰을 사용하며, 선택적으로 시그마 값을 늘려 최종 값이 지정된 `terminal` 값과 일치하도록 할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `스텝 수` | 샘플링 단계 수 (기본값: 20) | INT | 예 | 1-10000 |
| `최대 시프트` | 시그마 계산에 사용되는 최대 시프트 값 (기본값: 2.05) | FLOAT | 예 | 0.0-100.0 (단계: 0.01) |
| `기반 시프트` | 시그마 계산에 사용되는 기본 시프트 값 (기본값: 0.95) | FLOAT | 예 | 0.0-100.0 (단계: 0.01) |
| `늘이기` | 시그마를 [terminal, 1] 범위에 있도록 늘립니다 (기본값: True) | BOOLEAN | 예 | True/False |
| `종료값` | 늘리기 후 시그마의 최종 값 (기본값: 0.1). `stretch`가 활성화된 경우에만 사용됩니다. | FLOAT | 예 | 0.0-0.99 (단계: 0.01) |
| `잠재 비디오` | 시그마 조정을 위한 토큰 수를 계산하는 데 사용되는 선택적 latent 입력입니다. 제공되지 않은 경우 기본 토큰 수인 4096이 사용됩니다. | LATENT | 아니요 | - |

**참고:** `stretch`가 활성화되면 마지막 0이 아닌 시그마가 `terminal` 값과 같아지도록 0이 아닌 시그마 값이 재조정됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `sigmas` | 샘플링 프로세스를 위해 생성된 시그마 값 | SIGMAS |
