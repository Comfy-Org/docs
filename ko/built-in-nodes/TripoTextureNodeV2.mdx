이 노드는 이전 생성 단계의 작업 ID로 식별되는 Tripo 워크플로의 기존 3D 모델에 텍스처를 추가합니다. PBR 재질 맵 또는 단색 텍스처를 생성할 수 있으며, 결과는 텍스트 프롬프트, 스타일 이미지 또는 참조 이미지로 안내할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델 task_id` | 이전 Tripo 노드(모델 생성 또는 모델 분할)에서 생성된 소스 모델의 작업 ID입니다. | MODEL_TASK_ID / SEGMENT_TASK_ID | 예 | - |
| `pbr` | PBR 재질 맵(베이스 컬러, 메탈릭, 러프니스, 노멀)입니다. 끄면 단색 텍스처를 생성합니다. (기본값: true) | BOOLEAN | 아니요 | true<br />false |
| `텍스처 시드` | 텍스처 생성에 사용되는 시드입니다. (기본값: 42) 고급 입력입니다. | INT | 아니요 | 0 ~ 2147483647 |
| `texture_quality` | 생성된 텍스처의 품질입니다. `detailed` = HD 텍스처, `extreme` = 8K Ultra 텍스처입니다. (기본값: "standard") 고급 입력입니다. | COMBO | 아니요 | "standard"<br />"detailed"<br />"extreme" |
| `texture_alignment` | 텍스처가 모델에 정렬되는 방식입니다. (기본값: "original_image") 고급 입력입니다. | COMBO | 아니요 | "original_image"<br />"geometry" |
| `texture_prompt` | 텍스처링을 위한 선택적 텍스트 안내입니다. 색상을 추론할 소스 이미지가 없는 가져온 모델(Tripo: Import Model)에는 실제로 필요합니다. 참조 이미지와 함께 사용할 수 없습니다. (기본값: 비어 있음) | STRING | 아니요 | - |
| `model_version` | 텍스처 모델: v3.x로 생성된 메시에는 v3.0, v2.5로 생성된 메시에는 v2.5를 사용합니다. (기본값: v3_0_20250812) | COMBO | 아니요 | Tripo 텍스처 모델 버전, 기본값 "v3_0_20250812" |
| `style_image` | 텍스처의 예술적 스타일을 위한 참조 이미지입니다. `texture_prompt`와 함께 사용할 때만 적용됩니다. | IMAGE | 아니요 | - |
| `reference` | 텍스처를 안내하는 참조 이미지입니다. `texture_prompt` 또는 `style_image`와 함께 사용할 수 없습니다. (기본값: "none") | DYNAMIC_COMBO | 아니요 | "none"<br />"image"<br />"multiview" |
| `part_names` | 텍스처링할 Tripo: Segment Model의 부품 이름을 쉼표로 구분한 목록입니다. 비워 두면 모든 부품에 텍스처를 적용합니다. (기본값: 비어 있음) 고급 입력입니다. | STRING | 아니요 | - |

### 이미지 참조 입력

`reference`가 "image"로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | 텍스처가 따라야 할 단일 참조 이미지입니다. | IMAGE | 예 | - |

### 멀티뷰 참조 입력

`reference`가 "multiview"로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image_front` | 정면 뷰(0°)입니다. | IMAGE | 예 | - |
| `image_left` | 왼쪽 뷰(90°)입니다. | IMAGE | 예 | - |
| `image_back` | 뒷면 뷰(180°)입니다. | IMAGE | 예 | - |
| `image_right` | 오른쪽 뷰(270°)입니다. | IMAGE | 예 | - |

**매개변수 제약 사항:**

- 참조 이미지(참조 모드 "image" 또는 "multiview")는 `texture_prompt` 또는 `style_image`와 함께 사용할 수 없습니다.
- `style_image`를 사용하려면 `texture_prompt`를 제공해야 합니다.
- `texture_prompt`가 제공되지 않은 경우, 소스 모델은 text-to-model, image-to-model, multiview-to-model 또는 texture-model 작업에서 생성된 것이어야 합니다. 소스 이미지가 없는 모델(가져온 모델, 분할된 모델, 완료된 모델 또는 리토폴로지된 모델)에는 `texture_prompt`가 필요합니다. Tripo는 자체 생성한 모델에 대해서만 참조 이미지를 허용하기 때문입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model task_id` | 텍스처 작업의 작업 ID로, 다른 Tripo 노드에 전달할 수 있습니다. | MODEL_TASK_ID |
| `GLB` | GLB 형식의 텍스처가 적용된 모델입니다. 소스가 쿼드 메시 또는 FBX 가져오기인 경우 비어 있습니다. | FILE_3D_GLB |
| `FBX` | FBX 형식의 텍스처가 적용된 모델입니다. Tripo는 쿼드 메시와 FBX 가져오기에 대해 FBX를 반환하며, 그 외의 경우에는 비어 있습니다. | FILE_3D_FBX |
