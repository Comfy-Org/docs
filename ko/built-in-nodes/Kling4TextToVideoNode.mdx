Kling 4.0 모델을 사용하여 텍스트 프롬프트로 오디오가 포함된 비디오를 생성합니다. 이 노드는 프롬프트와 생성 설정을 Kling API로 전송하고, 작업이 완료될 때까지 기다린 뒤 완성된 비디오를 반환합니다. 참조 미디어 없이 설명만으로 클립을 만들어야 할 때 사용합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 모델 선택기입니다. `"kling-4.0"`은 최대 1080p 및 30초를 지원하며, `"kling-4.0-flash"`는 720p 및 20초로 제한됩니다. 모델을 선택하면 아래에 해당 입력이 표시됩니다. | DYNAMIC_COMBO | 예 | `"kling-4.0"`<br />`"kling-4.0-flash"` |

### kling-4.0 입력

`model`이 `"kling-4.0"`으로 설정되면 아래 입력이 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성할 비디오의 텍스트 설명입니다. 1~26000자 사이여야 합니다. | STRING | 예 | 1~26000자 |
| `resolution` | 출력 비디오의 해상도입니다. 기본값: `"720p"`. | COMBO | 예 | `"720p"`<br />`"1080p"` |
| `aspect_ratio` | 출력 비디오의 화면 비율입니다. 기본값: `"16:9"`. | COMBO | 예 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `duration` | 생성된 비디오의 길이(초)입니다. 기본값: 5. | INT | 예 | 3~30 |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |

### kling-4.0-flash 입력

`model`이 `"kling-4.0-flash"`으로 설정되면 아래 입력이 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성할 비디오의 텍스트 설명입니다. 1~26000자 사이여야 합니다. | STRING | 예 | 1~26000자 |
| `resolution` | 출력 비디오의 해상도입니다. Flash는 720p만 렌더링합니다. 기본값: `"720p"`. | COMBO | 예 | `"720p"` |
| `aspect_ratio` | 출력 비디오의 화면 비율입니다. 기본값: `"16:9"`. | COMBO | 예 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `duration` | 생성된 비디오의 길이(초)입니다. 기본값: 5. | INT | 예 | 3~20 |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 작업이 완료되면 제공자로부터 다운로드되는 생성된 비디오입니다. | VIDEO |
