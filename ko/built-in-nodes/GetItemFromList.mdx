이 노드는 목록에서 위치에 따라 선택된 단일 항목을 반환합니다. 목록과 원하는 항목의 인덱스 번호를 제공하면 노드가 해당 항목을 출력합니다. 따라서 배치에서 특정 이미지와 같이 값 그룹 중 하나의 특정 요소를 선택할 때 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `목록` | 선택할 값의 목록입니다. 이 노드는 목록 입력을 받는 것으로 표시되어 있으므로, 연결된 값은 항목 그룹으로 처리됩니다. | Any Type | 예 | 모든 값 목록 |
| `인덱스` | 반환할 항목의 위치입니다. 값은 0부터 시작하므로 `0`은 첫 번째 항목을, `1`은 두 번째 항목을 반환하는 식입니다(기본값: 0). | INT | 예 | 모든 정수 인덱스 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `OUTPUT` | 제공된 `list` 내에서 주어진 `index`에 위치한 단일 항목입니다. | Any Type |
