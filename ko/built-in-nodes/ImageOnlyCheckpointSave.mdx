ImageOnlyCheckpointSave 노드는 모델, CLIP 비전 인코더 및 VAE를 포함하는 체크포인트 파일을 저장합니다. 지정된 파일 이름 접두사를 사용하여 safetensors 파일을 생성하며, 생성된 파일을 출력 디렉터리에 저장합니다. 이 노드는 이미지 관련 모델 구성 요소를 단일 체크포인트 파일로 함께 저장하기 위해 특별히 설계되었습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 체크포인트에 저장할 모델 | MODEL | 예 | - |
| `clip_vision` | 체크포인트에 저장할 CLIP 비전 인코더 | CLIP_VISION | 예 | - |
| `vae` | 체크포인트에 저장할 VAE(변분 오토인코더) | VAE | 예 | - |
| `파일명 접두사` | 출력 파일 이름의 접두사(기본값: "checkpoints/ComfyUI") | STRING | 예 | - |
| `prompt` | 워크플로우 프롬프트 데이터를 위한 숨겨진 매개변수 | PROMPT | 아니요 | - |
| `extra_pnginfo` | 추가 PNG 메타데이터 | EXTRA_PNGINFO | 아니요 | - |
