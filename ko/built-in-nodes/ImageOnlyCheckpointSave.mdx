이 노드는 모델을 CLIP 비전 인코더 및 VAE와 함께 묶은 체크포인트 파일을 저장합니다. 파일은 safetensors 형식으로 출력 디렉터리에 지정된 파일 이름 접두사를 사용하여 기록되므로, 모델의 이미지 관련 구성 요소를 단일 체크포인트로 저장할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 체크포인트에 저장할 모델입니다 | MODEL | 예 | - |
| `clip_vision` | 체크포인트에 저장할 CLIP 비전 인코더입니다 | CLIP_VISION | 예 | - |
| `vae` | 체크포인트에 저장할 VAE(변분 오토인코더)입니다 | VAE | 예 | - |
| `파일명 접두사` | 출력 파일 이름의 접두사입니다(기본값: "checkpoints/ComfyUI") | STRING | 예 | - |
| `prompt` | 워크플로 프롬프트 데이터를 받는 숨겨진 매개변수입니다 | PROMPT | 아니요 | - |
| `extra_pnginfo` | 추가 PNG 메타데이터를 받는 숨겨진 매개변수입니다 | EXTRA_PNGINFO | 아니요 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| - | 이 노드는 출력을 반환하지 않습니다 | - |
