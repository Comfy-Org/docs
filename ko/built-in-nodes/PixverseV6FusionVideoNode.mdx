## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 모델 및 생성 설정입니다. 모델을 선택하고 아래에 해당 생성 설정을 표시합니다. 사용 가능한 옵션은 "PixVerse V6"뿐입니다. | DYNAMIC_COMBO | 예 | "PixVerse V6" |

### PixVerse V6 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 프롬프트입니다. 연결된 참조 항목을 @Subject1, @Background1, @Video1로 지칭하세요. 기본값: 비어 있음. | STRING | 예 | 1~5000자 |
| `aspect_ratio` | 출력 화면 비율입니다. "auto" 옵션은 참조 비디오가 하나 이상 연결된 경우에만 허용됩니다. | COMBO | 예 | "auto"<br />및 PixVerse V6 사전 정의 화면 비율 |
| `quality` | 출력 해상도입니다. 긴 변을 기준으로 합니다: 360p는 640px, 540p는 1024px, 720p는 1280px, 1080p는 1920px입니다. 기본값: "720p". | COMBO | 예 | "360p"<br />"540p"<br />"720p"<br />"1080p" |
| `duration_seconds` | 생성된 비디오의 길이(초)입니다. 참조 비디오가 연결된 경우 출력 길이는 가장 긴 참조 비디오를 따르며 이 설정은 무시됩니다. 기본값: 5. | INT | 예 | 1~15 |
| `generate_audio` | 비디오와 함께 기본 오디오 트랙을 생성합니다. 기본값: True. | BOOLEAN | 예 | True<br />False |
| `seed` | 비디오 생성용 시드입니다. PixVerse는 이를 기록하지만 해당 시드로 실행을 재현하지는 않습니다. 기본값: 42. | INT | 예 | 0~2147483647 |
| `negative_prompt` | 비디오에서 원하지 않는 요소에 대한 선택적 텍스트 설명입니다. 기본값: 비어 있음. | STRING | 아니오 | 최대 2048자 |
| `style` | 전체 비디오에 적용되는 선택적 시각적 스타일입니다. 기본값: "none". | COMBO | 아니오 | "none"<br />및 PixVerse V6 사전 정의 스타일 |

### 참조 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `피사체` | 증가형 슬롯: 장면에 배치할 주제의 참조 이미지를 연결합니다. 슬롯 이름은 subject1~subject8이며 프롬프트에서 @Subject1, @Subject2 등으로 참조합니다. | IMAGE | 아니오 | 0~8개 이미지 |
| `배경` | 증가형 슬롯: 주제가 배치되는 장면의 참조 이미지를 연결합니다. 슬롯 이름은 background1~background2이며 프롬프트에서 @Background1, @Background2로 참조합니다. | IMAGE | 아니오 | 0~2개 이미지 |
| `비디오` | 증가형 슬롯: 주제, 모션, 프레이밍 또는 스타일을 차용할 참조 비디오를 연결합니다. 슬롯 이름은 video1~video2이며 프롬프트에서 @Video1, @Video2로 참조합니다. 각 비디오는 최대 15초여야 하며 총 길이는 15초를 초과할 수 없습니다. 비디오를 하나 이상 연결하면 노드가 Omni 모드로 전환됩니다. | VIDEO | 아니오 | 0~2개 비디오<br />각 최대 15초<br />총 15초 |

참고: 주제, 배경 또는 참조 비디오를 하나 이상 연결하세요. 프롬프트의 참조 태그(예: @Subject1, @Background1, @Video1)는 연결된 슬롯과 일치해야 합니다. 그렇지 않으면 요청이 거부됩니다. 참조 비디오가 하나 이상 연결된 경우(Omni 모드) 출력 길이는 가장 긴 참조 비디오를 따르며, `duration_seconds`는 무시되고, `aspect_ratio`는 "auto"로 설정할 수 있으며, 최대 10개의 참조 이미지가 허용됩니다. 참조 비디오가 없는 경우 최대 7개의 참조 이미지(주제와 배경 합산)만 허용되며 "auto" 화면 비율은 허용되지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `video` | PixVerse에서 다운로드한 생성된 퓨전 비디오입니다. | VIDEO |
