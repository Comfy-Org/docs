SDPoseDrawKeypoints 노드는 포즈 추정 데이터(키포인트)를 가져와 빈 캔버스에 시각적 골격으로 그립니다. 이 노드를 사용하면 신체, 머리, 손, 얼굴, 발과 같은 포즈의 여러 부분을 사용자 지정 가능한 선 너비와 점 크기로 선택적으로 그릴 수 있습니다. 결과 이미지는 시각화 용도로 사용하거나 포즈 이미지가 필요한 다른 노드의 입력으로 사용할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `keypoints` | 그릴 포즈 키포인트 데이터입니다. 이 데이터는 일반적으로 포즈 감지 노드에서 제공되며 하나 이상의 프레임을 포함할 수 있습니다. | POSE_KEYPOINT | 예 | - |
| `draw_body` | 주요 신체 골격을 그릴지 여부를 제어합니다(기본값: True). | BOOLEAN | 아니요 | - |
| `draw_hands` | 손 키포인트를 그릴지 여부를 제어합니다(기본값: True). | BOOLEAN | 아니요 | - |
| `draw_face` | 얼굴 키포인트를 그릴지 여부를 제어합니다(기본값: True). | BOOLEAN | 아니요 | - |
| `draw_feet` | 발 키포인트를 그릴지 여부를 제어합니다(기본값: False). | BOOLEAN | 아니요 | - |
| `stick_width` | 신체 및 머리 골격을 그리는 데 사용되는 선의 너비입니다(기본값: 4). | INT | 아니요 | 1 ~ 10 |
| `face_point_size` | 얼굴 키포인트를 그리는 데 사용되는 점의 크기입니다(기본값: 3). | INT | 아니요 | 1 ~ 10 |
| `score_threshold` | 키포인트가 그려지기 위해 가져야 하는 최소 신뢰도 점수입니다. 이 값보다 낮은 점수의 키포인트는 무시됩니다(기본값: 0.3). | FLOAT | 아니요 | 0.0 ~ 1.0 |
| `머리 그리기` | 머리 키포인트(코, 눈, 귀)를 그릴지 여부를 제어합니다(기본값: True). | BOOLEAN | 아니요 | - |

**참고:** `keypoints` 입력이 비어 있거나 `None`이면 노드는 빈 64x64 이미지를 출력합니다.

**참고:** `draw_body`와 `draw_head`는 독립적으로 작동합니다. `draw_head`가 비활성화되면 `draw_body`가 활성화된 경우에도 머리 키포인트는 그려지지 않습니다. `draw_body`가 비활성화되고 `draw_head`가 활성화된 경우 머리 키포인트와 목(neck) 점만 그려집니다. 둘 다 비활성화된 경우 신체 또는 머리 키포인트는 그려지지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `output` | 그려진 포즈 키포인트가 포함된 이미지입니다. 이미지 크기는 입력 키포인트 데이터에 지정된 `canvas_height` 및 `canvas_width`와 일치합니다. 입력에 여러 프레임이 포함된 경우 이미지 배치(batch)가 반환됩니다. | IMAGE |
