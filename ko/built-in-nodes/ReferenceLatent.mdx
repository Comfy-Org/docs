이 노드는 편집 모델의 가이드 latent를 설정합니다. conditioning 데이터와 선택적 latent 입력을 받은 다음, conditioning을 수정하여 참조 latent 정보를 포함시킵니다. 모델이 이를 지원하는 경우, 여러 Set Reference Latent 노드를 연결하여 여러 참조 이미지를 설정할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `조건화` | 참조 latent 정보로 수정할 conditioning 데이터 | CONDITIONING | 예 | - |
| `잠재` | 편집 모델의 참조로 사용할 선택적 latent 데이터입니다. 제공되지 않으면 conditioning이 변경 없이 반환됩니다 | LATENT | 아니요 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `output` | 참조 latent 정보를 포함하는 수정된 conditioning 데이터 | CONDITIONING |

## 참고 사항

- 참조 latent는 샘플 텐서 목록으로 저장되므로, 여러 Set Reference Latent 노드를 순차적으로 연결하면 이전 참조를 대체하지 않고 추가 참조를 덧붙입니다.
- `latent`가 연결되지 않은 경우, 이 노드는 들어오는 `conditioning`을 변경 없이 그대로 전달합니다.
