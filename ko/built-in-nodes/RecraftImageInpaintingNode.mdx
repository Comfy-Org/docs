이 노드는 텍스트 프롬프트와 마스크를 기반으로 이미지의 특정 영역을 수정합니다. Recraft API를 사용하여 마스크된 영역만 지능적으로 편집하고 나머지 이미지는 변경하지 않습니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 수정할 입력 이미지 | IMAGE | 예 | - |
| `마스크` | 이미지에서 수정할 영역을 정의하는 마스크 | MASK | 예 | - |
| `프롬프트` | 이미지 생성을 위한 프롬프트 (기본값: 빈 문자열, 최대 길이: 1000자) | STRING | 예 | - |
| `n` | 생성할 이미지 수 (기본값: 1, 최소: 1, 최대: 6) | INT | 예 | 1-6 |
| `시드` | 노드 재실행 여부를 결정하는 시드입니다. 실제 결과는 시드와 관계없이 비결정적입니다 (기본값: 0) | INT | 예 | 0-18446744073709551615 |
| `recraft 스타일` | Recraft API용 선택적 스타일 매개변수입니다. 제공하지 않으면 "realistic_image" 스타일로 기본 설정됩니다 | STYLEV3 | 아니요 | - |
| `부정 프롬프트` | 이미지에서 원치 않는 요소에 대한 선택적 텍스트 설명 (기본값: 빈 문자열) | STRING | 아니요 | - |

*참고: 인페인팅 작업이 작동하려면 `image`와 `mask`를 함께 제공해야 합니다. 마스크는 이미지 크기에 맞게 자동으로 조정됩니다. `prompt`는 검증되며 최대 길이는 1000자입니다. Infinite Style Library의 `style_id`를 사용하는 경우, Vector 아트 스타일이 아닌지 확인하세요. Vector 아트 스타일을 사용하면 API가 이미지 대신 SVG 데이터를 반환할 수 있습니다.*

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `image` | 프롬프트와 마스크를 기반으로 생성된 수정된 이미지입니다. 입력 이미지마다 `n` 매개변수 값에 해당하는 수만큼 이미지를 반환합니다 | IMAGE |
