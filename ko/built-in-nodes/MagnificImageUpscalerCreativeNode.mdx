이 노드는 Magnific AI 서비스를 사용하여 이미지를 업스케일하고 창의적으로 향상시킵니다. 텍스트 프롬프트로 향상 과정을 안내하고, 최적화할 특정 스타일을 선택하며, 디테일, 원본 유사성, 스타일화 강도 등 창의적 과정의 다양한 측면을 제어할 수 있습니다. 노드는 선택한 배율(2x, 4x, 8x 또는 16x)로 업스케일된 이미지를 출력하며, 최대 출력 크기는 25.3 메가픽셀입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 업스케일 및 향상에 사용할 입력 이미지입니다. | IMAGE | 예 | - |
| `prompt` | 이미지의 창의적 향상을 안내하는 텍스트 설명입니다. 선택 사항입니다(기본값: 비어 있음). | STRING | 아니요 | - |
| `scale_factor` | 이미지의 크기를 업스케일할 배율입니다. | COMBO | 예 | `"2x"`<br />`"4x"`<br />`"8x"`<br />`"16x"` |
| `optimized_for` | 향상 과정을 최적화할 스타일 또는 콘텐츠 유형입니다. | COMBO | 예 | `"standard"`<br />`"soft_portraits"`<br />`"hard_portraits"`<br />`"art_n_illustration"`<br />`"videogame_assets"`<br />`"nature_n_landscapes"`<br />`"films_n_photography"`<br />`"3d_renders"`<br />`"science_fiction_n_horror"` |
| `creativity` | 이미지에 적용되는 창의적 해석 수준을 제어합니다(기본값: 0). | INT | 아니요 | -10 ~ 10 |
| `hdr` | 선명도와 디테일 수준입니다(기본값: 0). | INT | 아니요 | -10 ~ 10 |
| `resemblance` | 원본 이미지와의 유사성 수준입니다(기본값: 0). | INT | 아니요 | -10 ~ 10 |
| `fractality` | 프롬프트의 강도와 제곱 픽셀당 정교함입니다(기본값: 0). | INT | 아니요 | -10 ~ 10 |
| `engine` | 처리에 사용할 특정 AI 엔진입니다. 고급 매개변수입니다. | COMBO | 예 | `"automatic"`<br />`"magnific_illusio"`<br />`"magnific_sharpy"`<br />`"magnific_sparkle"` |
| `auto_downscale` | 출력이 최대 픽셀 제한을 초과할 경우 입력 이미지를 자동으로 다운스케일합니다(기본값: False). 고급 매개변수입니다. | BOOLEAN | 아니요 | - |

**제약 사항:**

* 입력 `image`는 정확히 한 장의 이미지여야 합니다.
* 입력 이미지의 최소 높이와 너비는 160픽셀이어야 합니다.
* 입력 이미지의 가로세로 비율은 1:3에서 3:1 사이여야 합니다.
* 최종 출력 크기(입력 크기에 `scale_factor`를 곱한 값)는 25,300,000픽셀을 초과할 수 없습니다. 이 제한을 초과하는 경우:
  - `auto_downscale`이 활성화된 경우, 노드는 출력이 제한 내에 유지되도록 입력 이미지 크기를 자동으로 줄이거나(최대 2배까지) 더 낮은 `scale_factor`를 사용합니다.
  - `auto_downscale`이 비활성화된 경우, 노드는 오류를 발생시킵니다.
