SV3D_Conditioning은 SV3D 모델을 사용하여 3D 비디오 생성을 위한 컨디셔닝 데이터를 준비합니다. 초기 이미지를 입력받아 CLIP 비전 및 VAE 인코더를 통해 처리하여 긍정 및 부정 컨디셔닝과 잠재 표현을 생성합니다. 이 노드는 지정된 비디오 프레임 수에 따라 다중 프레임 비디오 생성을 위한 카메라 고도 및 방위각 시퀀스를 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip_vision` | 입력 이미지를 인코딩하는 데 사용되는 CLIP 비전 모델 | CLIP_VISION | 예 | - |
| `초기 이미지` | 3D 비디오 생성을 위한 시작점 역할을 하는 초기 이미지 | IMAGE | 예 | - |
| `vae` | 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델 | VAE | 예 | - |
| `너비` | 생성된 비디오 프레임의 출력 너비입니다(기본값: 576, 스텝: 8) | INT | 예 | 16 to MAX_RESOLUTION |
| `높이` | 생성된 비디오 프레임의 출력 높이입니다(기본값: 576, 스텝: 8) | INT | 예 | 16 to MAX_RESOLUTION |
| `비디오 프레임` | 비디오 시퀀스용으로 생성할 프레임 수입니다(기본값: 21) | INT | 예 | 1  ~  4096 |
| `고도` | 3D 보기의 카메라 고도 각도(도)입니다(기본값: 0.0, 스텝: 0.1) | FLOAT | 예 | -90.0  ~  90.0 |

참고: 카메라 방위각은 0도에서 시작하여 각 프레임마다 일정량씩 증가하므로, 생성된 프레임 전체에 걸쳐 카메라가 객체 주위를 360도 완전히 한 바퀴 회전합니다. 프레임당 증가량은 360을 (`video_frames` - 1)로 나눈 값으로 계산되며, 프레임을 하나만 요청한 경우 최소 제수 2를 사용합니다. `elevation` 값은 모든 프레임에서 일정하게 유지됩니다.

`init_image`는 VAE 인코딩 전에 지정된 `width`와 `height`로 조정되며, 반환되는 latent는 `video_frames` x 4 x (`height` // 8) x (`width` // 8) 차원을 사용합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `positive` | 생성용 이미지 임베딩과 카메라 매개변수를 포함하는 긍정 컨디셔닝 데이터 | CONDITIONING |
| `negative` | 대조적 생성을 위해 임베딩과 latent를 0으로 설정한 부정 컨디셔닝 데이터 | CONDITIONING |
| `latent` | 지정된 비디오 프레임 수 및 해상도와 일치하는 차원의 빈 잠재 텐서 | LATENT |
