SV3D_Conditioning은 SV3D 모델을 사용하여 3D 비디오 생성을 위한 컨디셔닝 데이터를 준비합니다. 초기 이미지를 받아 CLIP 비전 및 VAE 인코더를 통해 처리하여 포지티브 및 네거티브 컨디셔닝과 함께 잠재 표현을 생성합니다. 이 노드는 지정된 비디오 프레임 수에 따라 다중 프레임 비디오 생성을 위한 카메라 고도 및 방위각 시퀀스를 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip_vision` | 입력 이미지를 인코딩하는 데 사용되는 CLIP 비전 모델 | CLIP_VISION | 예 | - |
| `초기 이미지` | 3D 비디오 생성을 위한 시작점 역할을 하는 초기 이미지 | IMAGE | 예 | - |
| `vae` | 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델 | VAE | 예 | - |
| `너비` | 생성된 비디오 프레임의 출력 너비 (기본값: 576, 8로 나누어 떨어져야 함) | INT | 예 | 16 ~ MAX_RESOLUTION |
| `높이` | 생성된 비디오 프레임의 출력 높이 (기본값: 576, 8로 나누어 떨어져야 함) | INT | 예 | 16 ~ MAX_RESOLUTION |
| `비디오 프레임` | 비디오 시퀀스로 생성할 프레임 수 (기본값: 21) | INT | 예 | 1 ~ 4096 |
| `고도` | 3D 뷰의 카메라 고도 각도 (도 단위, 기본값: 0.0) | FLOAT | 예 | -90.0 ~ 90.0 |

참고: 카메라 방위각은 0도에서 시작하여 각 프레임마다 일정한 양만큼 증가하므로 생성된 프레임 전체에 걸쳐 카메라가 객체 주위를 360도 회전합니다. `elevation` 값은 모든 프레임에서 일정하게 유지됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `긍정 조건` | 생성에 사용되는 이미지 임베딩과 카메라 매개변수를 포함하는 포지티브 컨디셔닝 데이터 | CONDITIONING |
| `부정 조건` | 대비 생성을 위해 임베딩과 잠재 변수가 0으로 설정된 네거티브 컨디셔닝 데이터 | CONDITIONING |
| `잠재 데이터` | 지정된 비디오 프레임 수와 해상도에 맞는 차원을 가진 빈 잠재 텐서 | LATENT |
