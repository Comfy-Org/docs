SUPIRApply 노드는 확산 모델에 SUPIR 모델 패치를 적용합니다. 이 패치는 모델의 동작을 수정하여 샘플링 과정에서 입력 이미지로부터의 가이던스를 반영할 수 있도록 합니다. 또한 이 노드는 이 가이던스의 강도를 시간에 따라 조정하기 위한 제어 기능을 제공하며, 원본 입력에 대한 충실도를 유지하는 데 도움이 되는 선택적 기능도 포함합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | SUPIR 패치가 적용될 기본 확산 모델입니다. | MODEL | 예 | - |
| `model_patch` | 모델을 수정하기 위한 가중치와 구성을 포함하는 SUPIR 모델 패치입니다. | MODEL_PATCH | 예 | - |
| `vae` | 입력 이미지를 잠재 표현으로 인코딩하는 데 사용되는 VAE(변분 오토인코더)입니다. | VAE | 예 | - |
| `image` | 생성 과정을 안내하는 데 사용되는 입력 이미지입니다. 처음 세 개의 색상 채널(RGB)만 사용됩니다. | IMAGE | 예 | - |
| `strength_start` | 샘플링 시작 시점(높은 시그마)의 제어 강도입니다. 이미지 가이던스의 영향은 이 값에서 시작됩니다. (기본값: 1.0) | FLOAT | 예 | 0.0 - 10.0 |
| `strength_end` | 샘플링 종료 시점(낮은 시그마)의 제어 강도입니다. 시작 값에서부터 선형 보간됩니다. 이미지 가이던스의 영향은 이 값에서 끝납니다. (기본값: 1.0) | FLOAT | 예 | 0.0 - 10.0 |
| `restore_cfg` | 노이즈 제거된 출력을 입력 잠재 표현 쪽으로 끌어당깁니다. 값이 높을수록 입력에 대한 충실도가 강해집니다. 0이면 비활성화됩니다. (기본값: 4.0, 고급 설정) | FLOAT | 예 | 0.0 - 20.0 |
| `restore_cfg_s_tmin` | `restore_cfg`가 비활성화되는 시그마 임계값입니다. (기본값: 0.05, 고급 설정) | FLOAT | 예 | 0.0 - 1.0 |

*참고:* `image` 입력은 RGB 채널만 추출하도록 처리됩니다. 알파 채널이 있는 이미지가 제공되면 알파 채널은 무시됩니다.

*참고:* SUPIR 모델 패치가 디노이즈 인코더 가중치를 제공하는 경우, 입력 이미지는 일반 VAE 인코더 대신 해당 가중치로 인코딩됩니다.

*참고:* `restore_cfg`는 0보다 큰 값으로 설정된 경우에만 효과가 있습니다. 0으로 설정하면 복원 후처리가 완전히 비활성화됩니다. 활성화된 경우 현재 시그마 값이 `restore_cfg_s_tmin`보다 높을 때만 보정이 적용됩니다.

*참고:* 이 노드는 ComfyUI에서 실험적(experimental)으로 표시되어 있습니다.
