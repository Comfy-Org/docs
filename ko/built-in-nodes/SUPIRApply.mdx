SUPIRApply 노드는 확산 모델에 SUPIR 모델 패치를 적용합니다. 이 패치를 사용하여 모델의 동작을 수정하며, 샘플링 과정에서 입력 이미지의 안내를 통합할 수 있습니다. 또한 이 노드는 시간에 따른 안내 강도를 조절하는 컨트롤을 제공하며, 원본 입력에 대한 충실도를 유지하는 데 도움이 되는 선택적 기능을 포함합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | SUPIR 패치가 적용될 기본 확산 모델입니다. | MODEL | 예 | - |
| `model_patch` | 모델을 수정하기 위한 가중치와 구성을 포함하는 SUPIR 모델 패치입니다. | MODELPATCH | 예 | - |
| `vae` | 입력 이미지를 잠재 표현으로 인코딩하는 데 사용되는 VAE(변형 오토인코더)입니다. | VAE | 예 | - |
| `image` | 생성 과정을 안내하는 데 사용되는 입력 이미지입니다. 처음 세 개의 색상 채널(RGB)만 사용됩니다. | IMAGE | 예 | - |
| `strength_start` | 샘플링 시작 시(높은 sigma)의 제어 강도입니다. 이미지 안내의 영향이 이 값에서 시작됩니다. (기본값: 1.0) | FLOAT | 예 | 0.0 - 10.0 |
| `strength_end` | 샘플링 종료 시(낮은 sigma)의 제어 강도입니다. 시작 값에서 선형적으로 보간됩니다. 이미지 안내의 영향이 이 값에서 종료됩니다. (기본값: 1.0) | FLOAT | 예 | 0.0 - 10.0 |
| `restore_cfg` | 노이즈 제거된 출력을 입력 잠재 표현 쪽으로 끌어당깁니다. 값이 높을수록 입력에 대한 충실도가 강해집니다. 0으로 설정하면 비활성화됩니다. (기본값: 4.0) | FLOAT | 예 | 0.0 - 20.0 |
| `restore_cfg_s_tmin` | `restore_cfg`가 비활성화되는 sigma 임계값입니다. (기본값: 0.05) | FLOAT | 예 | 0.0 - 1.0 |

*참고:* `image` 입력은 RGB 채널만 추출하도록 처리됩니다. 알파 채널이 있는 이미지가 제공되면 알파 채널은 무시됩니다.

*참고:* `restore_cfg`는 0보다 큰 값으로 설정된 경우에만 적용됩니다. 0으로 설정하면 복원 후처리가 완전히 비활성화됩니다. 활성화되면 현재 sigma 값이 `restore_cfg_s_tmin`보다 높은 동안에만 보정이 적용됩니다.

*참고:* 이 노드는 ComfyUI에서 실험적(experimental)으로 표시되어 있습니다.
