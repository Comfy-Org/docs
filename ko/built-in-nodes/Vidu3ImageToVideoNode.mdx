Vidu Q3 Image-to-Video 생성 노드는 입력 이미지에서 시작하는 비디오 시퀀스를 생성합니다. 이 노드는 Vidu Q3 모델을 사용하여 이미지에 애니메이션을 적용하며, 선택적으로 텍스트 프롬프트의 안내를 받아 비디오 파일을 출력합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용할 모델입니다. | DYNAMIC_COMBO | 예 | `"viduq3-pro"`<br />`"viduq3-turbo"` |
| `image` | 생성된 비디오의 시작 프레임으로 사용할 이미지입니다. | IMAGE | 예 | - |
| `prompt` | 비디오 생성을 위한 선택적 텍스트 프롬프트입니다 (최대 2000자) (기본값: 비어 있음). | STRING | 예 | - |
| `seed` | 생성의 무작위성을 제어하는 시드 값입니다 (기본값: 1). 생성 후 제어(control-after-generate)를 지원합니다. | INT | 예 | 0 ~ 2147483647 |

### viduq3-pro 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"720p"`<br />`"1080p"`<br />`"2K"` |
| `duration` | 출력 비디오의 지속 시간(초)입니다 (기본값: 5). | INT | 예 | 1 ~ 16 |
| `audio` | 활성화하면 소리(대화 및 음향 효과 포함)와 함께 비디오를 출력합니다 (기본값: False). | BOOLEAN | 예 | `True`<br />`False` |

### viduq3-turbo 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"720p"`<br />`"1080p"` |
| `duration` | 출력 비디오의 지속 시간(초)입니다 (기본값: 5). | INT | 예 | 1 ~ 16 |
| `audio` | 활성화하면 소리(대화 및 음향 효과 포함)와 함께 비디오를 출력합니다 (기본값: False). | BOOLEAN | 예 | `True`<br />`False` |

**참고:** `image`의 종횡비는 1:4에서 4:1 사이(세로~가로)여야 합니다. `prompt`는 선택 사항이지만 2000자를 초과할 수 없습니다. 해상도 옵션은 선택한 모델에 따라 달라집니다. `"viduq3-pro"`는 `"720p"`, `"1080p"`, `"2K"`를 지원하며, `"viduq3-turbo"`는 `"720p"`와 `"1080p"`를 지원합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오 파일입니다. | VIDEO |
