이 노드는 메시의 베이크된 텍스처를 추출하여 기본 색상, 메탈릭, 러프니스, 오클루전 및 노멀 맵의 개별 이미지로 반환합니다. 베이크되지 않은 텍스처 채널은 중립 기본값으로 반환됩니다 — 오클루전은 흰색, 노멀 맵은 평평한 파란색입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 베이크된 텍스처가 추출되는 메시입니다. 메시에는 기본 색상 텍스처가 있어야 합니다. 정점 색상만 있는 메시(예: PaintMesh 노드 이후)에는 텍스처가 포함되어 있지 않으므로 오류가 발생합니다. | MESH | 예 | — |

참고: 메시에는 베이크된 기본 색상 텍스처가 있어야 합니다. 텍스처가 없으면 노드는 오류를 발생시키고 먼저 BakeTextureFromVoxel을 실행할 것을 권장합니다. 메탈릭-러프니스 텍스처가 없으면 `metallic` 및 `roughness` 출력은 검은색(0)입니다. `occlusion` 출력은 메시에 베이크된 앰비언트 오클루전이 포함되어 있지 않으면 흰색입니다. 노멀 맵이 베이크되지 않은 경우 `normal_map` 출력은 평평한 중립 파란색입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `base_color` | 메시의 기본 색상 텍스처를 이미지로 반환합니다. | IMAGE |
| `metallic` | 메시의 오클루전-러프니스-메탈릭 텍스처에서 메탈릭 채널을 회색조 이미지로 반환합니다. 검은색(0)은 비금속, 흰색(1)은 완전 금속을 의미합니다. 텍스처가 없으면 검은색입니다. | IMAGE |
| `roughness` | 메시의 오클루전-러프니스-메탈릭 텍스처에서 러프니스 채널을 회색조 이미지로 반환합니다. 텍스처가 없으면 검은색입니다. | IMAGE |
| `occlusion` | 메시의 오클루전-러프니스-메탈릭 텍스처에서 앰비언트 오클루전 채널을 회색조 이미지로 반환합니다. 앰비언트 오클루전이 베이크되지 않은 경우 흰색(오클루전 없음)입니다. | IMAGE |
| `normal_map` | 메시의 노멀 맵 텍스처입니다. 노멀 맵이 베이크되지 않은 경우 평평한 중립 노멀 맵(0.5, 0.5, 1.0, 평평한 파란색으로 표시)입니다. | IMAGE |
