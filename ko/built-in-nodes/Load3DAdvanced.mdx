Load 3D (Advanced) 노드는 ComfyUI의 `input/3d` 디렉터리에서 3D 모델 파일을 불러오고, 모델 데이터와 함께 3D 뷰어의 뷰포트 상태에 캡처된 모델 배치 및 카메라 정보를 제공합니다. 일반적인 3D 파일 형식을 지원하며 뷰포트의 렌더 너비와 높이를 픽셀 단위로 설정할 수 있습니다. 이 노드는 실험적입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_file` | 불러올 3D 모델 파일입니다. 모델 파일 불러오기를 건너뛰려면 "none"을 선택하십시오. 위젯을 통해 파일을 업로드할 수도 있습니다. | COMBO | 예 | `"none"`<br />`input/3d` 디렉터리에 있는 사용 가능한 3D 모델 파일 |
| `viewport_state` | 3D 뷰어의 카메라 및 모델 정보를 포함하는 현재 뷰포트 상태입니다. | LOAD3D | 예 | - |
| `width` | 뷰포트의 렌더 너비(픽셀)입니다(기본값: 1024). | INT | 예 | 최소: 1<br />최대: 4096<br />기본값: 1024<br />단계: 1 |
| `height` | 뷰포트의 렌더 높이(픽셀)입니다(기본값: 1024). | INT | 예 | 최소: 1<br />최대: 4096<br />기본값: 1024<br />단계: 1 |

**매개변수 참고 사항:**
- `model_file` 매개변수는 다음 확장자를 가진 파일만 나열합니다: .gltf, .glb, .obj, .fbx, .stl
- 파일은 ComfyUI 설치의 `input/3d` 디렉터리에 있어야 합니다. 하위 폴더도 검색되며, 파일 경로는 입력 디렉터리를 기준으로 상대적으로 표시됩니다.
- `model_file`이 "none"이면 모델 데이터가 로드되지 않으며 `model_3d` 출력은 비어 있습니다.
- `model_file`이 존재하지 않는 파일로 설정된 경우 노드는 유효성 검사 오류를 반환합니다: "Invalid 3D model file: &#123;model_file&#125;"
- `viewport_state`가 유효한 뷰포트 상태 객체가 아니면 빈 상태로 처리되므로 `model_3d_info`는 빈 목록이 되고 `camera_info`는 비어 있는 상태로 반환됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model_3d` | 불러온 3D 모델 파일(glb/obj/stl 등)입니다. 모델 파일을 선택하지 않은 경우 비어 있습니다. | FILE3DANY |
| `model_3d_info` | 장면에 있는 각 모델의 배치: 위치, 회전 및 스케일(Y-up 월드 공간)입니다. | LOAD3DMODELINFO |
| `camera_info` | 뷰포트 카메라 정보: 위치, 바라보는 대상, 줌 및 유형입니다. | LOAD3DCAMERA |
| `width` | 뷰포트의 렌더 너비(픽셀)입니다. | INT |
| `height` | 뷰포트의 렌더 높이(픽셀)입니다. | INT |
