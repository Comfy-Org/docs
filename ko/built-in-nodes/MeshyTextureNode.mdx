Meshy: Texture 노드는 AI 생성 텍스처를 3D 모델에 적용합니다. 이전 Meshy 3D 생성 또는 변환 노드에서 작업 ID(task ID)를 가져와 텍스트 설명 또는 참조 이미지를 사용하여 모델의 새 텍스처를 만듭니다. 이 노드는 텍스처가 적용된 모델을 GLB 및 FBX 파일 형식으로 출력합니다.

## 입력

| 매개변수 | 설명 | 데이터 형식 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 텍스처링에 사용할 AI 모델 버전입니다. | COMBO | 예 | `"meshy-7"`<br />`"meshy-6"`<br />`"latest"` |
| `meshy_task_id` | 이전 Meshy 3D 생성 또는 변환 작업의 고유 식별자(작업 ID)입니다. 텍스처를 입힐 기본 3D 모델을 제공합니다. | MESHY_TASK_ID | 예 | - |
| `원본 UV 사용` | 새 UV를 생성하는 대신 모델의 원본 UV를 사용합니다. 활성화하면(기본값: `True`) Meshy가 업로드된 모델의 기존 텍스처를 보존합니다. 모델에 원본 UV가 없는 경우 출력 품질이 좋지 않을 수 있습니다. 고급 옵션입니다. | BOOLEAN | 아니요 | true / false |
| `pbr` | 텍스처가 적용된 모델에 물리 기반 렌더링(PBR) 재질 출력을 활성화합니다(기본값: `False`). 고급 옵션입니다. | BOOLEAN | 아니요 | true / false |
| `텍스트 스타일 프롬프트` | 원하는 객체의 텍스처 스타일을 텍스트로 설명하세요. 최대 600자입니다. `image_style`와 동시에 사용할 수 없습니다. | STRING | 아니요 | - |
| `이미지 스타일` | 텍스처링 과정을 안내하는 2D 이미지입니다. `text_style_prompt`와 동시에 사용할 수 없습니다. | IMAGE | 아니요 | - |
| `texture_resolution` | 기본 색상 텍스처 해상도입니다. 해상도가 높을수록 더 많은 표면 디테일을 포착합니다. | COMBO | 예 | `"2k"`<br />`"4k"`<br />`"8k"` |

**매개변수 제약 조건:**

* `text_style_prompt` 또는 `image_style` 중 하나를 제공해야 하며, 둘을 동시에 제공할 수는 없습니다.
* `text_style_prompt`는 최대 600자로 제한됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 형식 |
| --- | --- | --- |
| `모델 파일` | 생성된 GLB 모델의 파일 이름입니다. 이 출력은 이전 버전과의 호환성을 위해서만 제공됩니다. | STRING |
| `meshy_task_id` | 이 텍스처링 작업의 고유 작업 식별자로, 결과를 참조하는 데 사용할 수 있습니다. | MESHY_TASK_ID |
| `GLB` | GLB 파일 형식으로 저장된 텍스처 적용 3D 모델입니다. | FILE3DGLB |
| `FBX` | FBX 파일 형식으로 저장된 텍스처 적용 3D 모델입니다. | FILE3DFBX |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/MeshyTextureNode/ko.md)
