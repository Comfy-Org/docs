MOSS-Image가 읽는 레이아웃 프롬프트를 생성합니다. Create Bounding Boxes 노드에서 그린 요소를 받아 각 상자마다 항목이 하나씩 있는 JSON 레이아웃을 출력합니다: 레이블, 캡션, 대상 캔버스의 픽셀 공간에서의 사각형입니다. `width`와 `height`를 생성하려는 이미지의 크기로 설정한 다음 출력을 텍스트 인코더의 프롬프트 입력에 연결하세요. 연결된 요소가 없으면 프롬프트 텍스트가 변경되지 않고 반환됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `prompt` | 전체 이미지에 대한 설명입니다. 레이아웃의 캡션으로 사용됩니다. | STRING | 예 | - |
| `element` | 배치할 요소로, Create Bounding Boxes 노드에서 가져옵니다. 각 상자는 자신의 캡션을 제공하며, 텍스트 상자는 자신의 텍스트도 제공하고, 색상 팔레트를 가진 상자는 팔레트를 유지합니다. | ARRAY | 예 | - |
| `width` | 생성된 이미지의 너비(픽셀)입니다. 상자는 이 픽셀 그리드로 변환되므로, 생성하려는 이미지의 크기를 사용하세요(기본값: 1024). | INT | 예 | 16 ~ 16384 (단계: 16) |
| `height` | 생성된 이미지의 높이(픽셀)입니다. 상자는 이 픽셀 그리드로 변환되므로, 생성하려는 이미지의 크기를 사용하세요(기본값: 1024). | INT | 예 | 16 ~ 16384 (단계: 16) |
| `character_boxes` | 객체 대신 캐릭터로 레이블을 지정할 상자 번호입니다. Create Bounding Boxes 미리보기에서 태그된 대로 입력하며, 예를 들어 "1, 3"과 같습니다. 문자열에 있는 모든 숫자를 읽으므로 구분 기호는 무엇이든 작동합니다(기본값: 비어 있음). | STRING | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `prompt` | 레이아웃 프롬프트: 캡션, 각 상자별 항목, 상자 좌표 형식을 담은 JSON 객체입니다. 연결된 요소가 없으면 입력 텍스트가 그대로 전달됩니다. | STRING |

## 참고

상자 사각형은 Create Bounding Boxes에서 0에서 1000 사이의 정규화된 좌표로 전달되며, 캔버스 중앙을 기준으로 한 픽셀 단위로 `yxyx` 순서에 따라 레이아웃에 기록됩니다. 따라서 `width`와 `height` 값은 생성하는 이미지와 일치해야 하며, 그렇지 않으면 상자가 잘못된 위치에 놓입니다.

텍스트를 포함하는 상자는 항상 텍스트로 레이블이 지정되고, 번호가 `character_boxes`에 나열된 상자는 캐릭터로 레이블이 지정되며, 그 외의 모든 상자는 객체로 레이블이 지정됩니다.
