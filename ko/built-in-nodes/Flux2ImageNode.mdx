Flux.2 Image

텍스트 프롬프트와 선택적 참조 이미지를 사용하여 Flux.2 [pro] 또는 Flux.2 [max] 모델로 이미지를 생성합니다. 이 노드는 요청을 BFL API로 전송하고, 결과를 폴링하며, 생성된 이미지를 텐서로 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 사용할 Flux.2 모델 버전입니다. 모델을 선택하면 너비, 높이 및 선택적 참조 이미지에 대한 추가 매개변수가 활성화됩니다. | DYNAMIC_COMBO | 예 | "Flux.2 [pro]"<br />"Flux.2 [max]" |
| `프롬프트` | 이미지 생성 또는 편집을 위한 프롬프트입니다 (기본값: 빈 문자열). | STRING | 예 | N/A |
| `시드` | 노이즈 생성에 사용되는 난수 시드입니다. 각 생성 후 무작위화하도록 설정할 수 있습니다 (기본값: 0). | INT | 예 | 0 ~ 18446744073709551615 |

### Flux.2 [pro] 및 Flux.2 [max] 입력

두 모델이 공유합니다 — 매개변수 세트는 동일합니다.

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `너비` | 생성된 이미지의 너비(픽셀)입니다 (기본값: 1024). | INT | 예 | 256 ~ 2048 (32 단계) |
| `높이` | 생성된 이미지의 높이(픽셀)입니다 (기본값: 768). | INT | 예 | 256 ~ 2048 (32 단계) |

### 참조 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model.images` | 이미지 간(image-to-image) 생성을 위한 선택적 참조 이미지입니다. 최대 8개 이미지. 확장 가능한 슬롯: 1~8개 항목(`image_1`...`image_8`)을 연결할 수 있습니다. | IMAGE | 아니요 | 0 ~ 8개 이미지 |

**참고:**
- 참조 이미지의 최대 개수는 8개입니다. 8개를 초과하는 이미지가 제공되면 오류가 발생합니다.
- `model.width` 및 `model.height` 값은 생성 비용에 영향을 미칩니다. 비용은 선택한 모델과 참조 이미지 제공 여부에 따라서도 달라집니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `image` | BFL API 결과에서 다운로드된 생성 이미지 텐서입니다. | IMAGE |
