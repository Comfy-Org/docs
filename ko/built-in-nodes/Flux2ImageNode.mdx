Flux.2 [pro] 또는 Flux.2 [max] 모델을 사용하여 텍스트 프롬프트와 선택적 참조 이미지로부터 이미지를 생성합니다. 이 노드는 BFL API로 요청을 전송하고, 결과가 준비될 때까지 폴링한 뒤 생성된 이미지를 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 사용할 Flux.2 모델 버전입니다. 모델을 선택하면 너비, 높이 및 선택적 참조 이미지에 대한 추가 매개변수가 활성화됩니다. | DYNAMIC_COMBO | 예 | "Flux.2 [pro]"<br />"Flux.2 [max]" |
| `프롬프트` | 이미지 생성 또는 편집을 위한 프롬프트입니다(기본값: 빈 문자열). | STRING | 예 | N/A |
| `시드` | 노이즈 생성에 사용되는 무작위 시드입니다(기본값: 0). 각 실행 후 값을 무작위화하는 control-after-generate 옵션을 지원합니다. | INT | 예 | 0  ~  18446744073709551615 |

### Flux.2 [pro] 및 Flux.2 [max] 입력

두 모델에서 공유되며, 매개변수 구성은 동일합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `너비` | 생성되는 이미지의 너비(픽셀)입니다(기본값: 1024). | INT | 예 | 256  ~  2048 (단계: 32) |
| `높이` | 생성되는 이미지의 높이(픽셀)입니다(기본값: 768). | INT | 예 | 256  ~  2048 (단계: 32) |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model.images` | 이미지-투-이미지 생성을 위한 선택적 참조 이미지입니다. 최대 8개 이미지입니다. 확장 가능한 슬롯: 1..8개 항목을 연결합니다(`image_1`...`image_8`). | IMAGE | 아니요 | 0  ~  8 images |

**참고:**
- 참조 이미지의 최대 개수는 8개입니다. 8개를 초과하여 제공하면 오류가 발생합니다. 배치 이미지는 이 제한에 포함되는데, 배치의 각 이미지가 개별적으로 계산되기 때문입니다.
- 참조 이미지는 API로 전송되기 전에 총 픽셀 수가 2048 x 2048을 초과하지 않도록 크기가 조정됩니다.
- `model.width` 및 `model.height` 값은 생성 비용에 영향을 줍니다. 비용은 선택한 모델과 참조 이미지 제공 여부에 따라서도 달라집니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | BFL API 결과에서 다운로드된, 텐서 형태의 생성 이미지입니다. | IMAGE |
