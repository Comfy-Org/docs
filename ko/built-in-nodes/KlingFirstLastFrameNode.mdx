이 노드는 Kling 3.0 모델을 사용하여 비디오를 생성합니다. 텍스트 프롬프트, 지정된 길이 및 두 개의 제공된 이미지(시작 프레임과 종료 프레임)를 기반으로 비디오를 만듭니다. 이 노드는 비디오에 맞는 오디오도 생성할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 모델 및 생성 설정입니다. 이 옵션을 선택하면 중첩된 `resolution` 매개변수가 표시됩니다. | DYNAMIC_COMBO | 아니요 | `"kling-v3"` |
| `프롬프트` | 비디오 생성을 안내하는 텍스트 설명입니다. 길이는 1자에서 2500자 사이여야 합니다. | STRING | 예 | N/A |
| `지속 시간` | 비디오 길이(초)입니다 (기본값: 5). | INT | 아니요 | 3 ~ 15 |
| `첫 프레임` | 비디오의 시작 이미지입니다. 최소 300x300 픽셀이어야 하며 종횡비가 1:2.5에서 2.5:1 사이여야 합니다. | IMAGE | 예 | N/A |
| `마지막 프레임` | 비디오의 종료 이미지입니다. 최소 300x300 픽셀이어야 하며 종횡비가 1:2.5에서 2.5:1 사이여야 합니다. | IMAGE | 예 | N/A |
| `오디오 생성` | 비디오에 오디오를 생성할지 여부를 제어합니다 (기본값: True). | BOOLEAN | 아니요 | N/A |
| `시드` | 시드는 노드가 다시 실행되어야 하는지 제어합니다. 시드와 관계없이 결과는 비결정적입니다 (기본값: 0). | INT | 아니요 | 0 ~ 2147483647 |

### Kling V3 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 생성된 비디오의 해상도입니다 (기본값: `"1080p"`). | COMBO | 아니요 | `"4k"`<br />`"1080p"`<br />`"720p"` |

**참고:** `first_frame` 및 `end_frame` 이미지는 노드가 올바르게 작동하려면 최소 300x300 픽셀이고 종횡비가 1:2.5에서 2.5:1 사이여야 합니다. `prompt`는 1자에서 2500자 사이여야 합니다. `resolution` 옵션은 Kling 생성 모드인 `"4k"`, `"1080p"`(프로), `"720p"`(표준)에 매핑됩니다.
