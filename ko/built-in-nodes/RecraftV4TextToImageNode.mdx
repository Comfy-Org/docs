Recraft V4 텍스트-이미지 변환

이 노드는 Recraft V4 및 V4.1 AI 모델을 사용하여 텍스트 설명에서 이미지를 생성합니다. 프롬프트를 외부 API로 전송하고 생성된 이미지를 반환합니다. 모델, 이미지 크기, 이미지 수, 선택적 스타일(저장된 스타일 ID 또는 참조 이미지)을 지정하여 출력을 제어할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 생성에 사용할 모델입니다. recraftv4_styles 모델은 스타일 일관성 생성을 위해 설계되었으며 항상 style_id 또는 style_references가 필요합니다. | DYNAMIC_COMBO | 예 | "recraftv4_1"<br />"recraftv4_1_utility"<br />"recraftv4_1_pro"<br />"recraftv4_1_utility_pro"<br />"recraftv4"<br />"recraftv4_pro"<br />"recraftv4_styles"<br />"recraftv4_styles_pro" |
| `prompt` | 이미지 생성을 위한 프롬프트입니다. 최대 10,000자입니다. | STRING | 예 | 1~10000자 |
| `negative_prompt` | 이 입력은 무시됩니다. Recraft V4 및 V4.1 모델은 네거티브 프롬프트를 지원하지 않습니다. | STRING | 예 | 해당 없음 |
| `n` | 생성할 이미지 수입니다(기본값: 1). | INT | 예 | 1~6 |
| `seed` | 노드 재실행 여부를 결정하는 시드입니다. 시드와 관계없이 실제 결과는 비결정적입니다(기본값: 0). | INT | 예 | 0~18446744073709551615 |
| `recraft_controls` | Recraft Controls 노드를 통해 생성 과정에 적용하는 선택적 추가 제어입니다. | CUSTOM | 아니요 | 해당 없음 |
| `style_id` | 적용할 Recraft V4 스타일의 UUID입니다(예: Recraft V4 Create Style 노드 또는 이전 실행의 style_id 출력에서 가져온 값). style_references와 함께 사용할 수 없습니다(기본값: 비어 있음). | STRING | 아니요 | 유효한 UUID 문자열 |
| `style_match` | 스타일을 얼마나 밀접하게 따를지 결정합니다. precise는 세부적으로 재현하고, flexible는 전반적인 느낌을 일치시킵니다. 스타일이 제공된 경우에만 사용됩니다(기본값: "precise"). | COMBO | 아니요 | "precise"<br />"flexible" |

### recraftv4_1, recraftv4_1_utility, recraftv4, recraftv4_styles 입력

이 모델들은 동일한 `size` 매개변수를 공유합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `size` | 생성되는 이미지의 크기입니다(기본값: "1024x1024"). | COMBO | 예 | 여러 옵션 사용 가능(표준 Recraft V4 크기, "1024x1024" 포함) |

### recraftv4_1_pro, recraftv4_1_utility_pro, recraftv4_pro, recraftv4_styles_pro 입력

이 모델들은 동일한 `size` 매개변수를 공유합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `size` | 생성되는 이미지의 크기입니다(기본값: "2048x2048"). | COMBO | 예 | 여러 옵션 사용 가능(프로 Recraft V4 크기, "2048x2048" 포함) |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `style_references` | 즉석에서 스타일을 만들기 위한 참조 이미지로, 생성 비용에 추가로 청구됩니다. 만들어진 스타일은 재사용을 위해 style_id로 반환됩니다. style_id와 함께 사용할 수 없습니다. 확장 가능한 슬롯: 1~N개의 이미지를 연결합니다(style_reference_1, style_reference_2, ...). | IMAGE | 아니요 | 0~Recraft API가 허용하는 최대 참조 이미지 수, 총 인코딩된 크기는 10MB를 초과할 수 없음 |

**참고:** `size` 매개변수는 선택한 `model`에 따라 사용 가능한 옵션이 달라지는 동적 입력입니다. `recraftv4_styles` 및 `recraftv4_styles_pro` 모델은 항상 스타일이 필요하므로 스타일 참조 이미지를 연결하거나 `style_id`를 제공해야 합니다. `style_id`와 `style_references` 입력은 상호 배타적이므로 둘 중 하나만 제공하십시오. `style_id`는 유효한 UUID여야 합니다. `style_match` 입력은 스타일이 제공된 경우에만 사용됩니다. 스타일 참조 이미지는 생성 비용에 추가로 청구되며 총 인코딩된 크기가 10MB를 초과할 수 없습니다. `seed` 값은 재현 가능한 이미지 출력을 보장하지 않습니다. Infinite Style Library의 스타일 ID를 사용하는 경우 벡터 아트 스타일이 아닌지 확인하십시오. 벡터 아트 스타일은 이미지 대신 SVG 데이터를 반환할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 이미지 또는 이미지 배치입니다. | IMAGE |
| `style_id` | 이 생성에서 사용되었거나 생성된 스타일 ID입니다. 스타일 참조 이미지가 제공된 경우 생성된 스타일이 재사용을 위해 여기에 반환되며, 스타일을 사용하지 않으면 빈 문자열입니다. | STRING |
