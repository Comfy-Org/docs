Recraft V4 및 V4.1 모델을 사용하여 텍스트 프롬프트로부터 이미지를 생성합니다. 프롬프트와 선택한 설정을 Recraft API로 전송하고 생성된 이미지 또는 이미지들을 반환합니다. 스타일 참조 이미지를 사용하는 경우 생성된 스타일 ID도 함께 반환됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 생성에 사용할 모델입니다. recraftv4_styles 모델은 스타일 일관성 있는 생성을 위해 만들어졌으며 항상 style_id 또는 style_references가 필요합니다. `recraftv4_1_flash`는 가장 빠르고 저렴한 모델이며 스타일을 전혀 지원하지 않습니다. | DYNAMIC_COMBO | 예 | "recraftv4_1"<br />"recraftv4_1_flash"<br />"recraftv4_1_utility"<br />"recraftv4_1_pro"<br />"recraftv4_1_utility_pro"<br />"recraftv4"<br />"recraftv4_pro"<br />"recraftv4_styles"<br />"recraftv4_styles_pro" |
| `prompt` | 이미지 생성을 위한 프롬프트입니다. 최대 10,000자입니다. | STRING | 예 | 1~10000자 |
| `negative_prompt` | 이 입력은 무시됩니다. 부정 프롬프트는 Recraft V4 및 V4.1 모델에서 지원되지 않습니다. | STRING | 예 | N/A |
| `n` | 생성할 이미지 수입니다(기본값: 1). | INT | 예 | 1~6 |
| `seed` | 노드를 다시 실행할지 결정하는 시드입니다. 실제 결과는 시드와 관계없이 비결정적입니다(기본값: 0). | INT | 예 | 0~18446744073709551615 |
| `recraft_controls` | Recraft Controls 노드를 통해 생성에 대한 선택적 추가 제어를 제공합니다. | CUSTOM | 아니요 | N/A |
| `style_id` | 적용할 Recraft V4 스타일의 UUID입니다. 예: Recraft V4 Create Style 노드 또는 이전 실행의 style_id 출력에서 가져올 수 있습니다. style_references와 함께 사용할 수 없습니다(기본값: 비어 있음). | STRING | 아니요 | 유효한 UUID 문자열 |
| `style_match` | 스타일을 얼마나 밀접하게 따를지 지정합니다. precise는 스타일을 세부적으로 재현하고, flexible은 전반적인 모양을 맞춥니다. 스타일이 제공된 경우에만 사용됩니다(기본값: "precise"). | COMBO | 아니요 | "precise"<br />"flexible" |

### recraftv4_1, recraftv4_1_flash, recraftv4_1_utility, recraftv4 및 recraftv4_styles 입력

이 모델들은 동일한 `size` 매개변수를 공유합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `size` | 생성된 이미지의 크기입니다(기본값: "1024x1024"). | COMBO | 예 | 여러 옵션 사용 가능(표준 Recraft V4 크기, "1024x1024" 포함) |

### recraftv4_1_pro, recraftv4_1_utility_pro, recraftv4_pro 및 recraftv4_styles_pro 입력

이 모델들은 동일한 `size` 매개변수를 공유합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `size` | 생성된 이미지의 크기입니다(기본값: "2048x2048"). | COMBO | 예 | 여러 옵션 사용 가능(pro Recraft V4 크기, "2048x2048" 포함) |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `style_references` | 즉석에서 스타일을 만들기 위한 참조 이미지이며, 생성 비용에 추가로 청구됩니다. 생성된 스타일은 재사용을 위해 style_id로 반환됩니다. style_id와 함께 사용할 수 없습니다. 확장 가능한 슬롯: 1..N개의 이미지를 연결합니다(style_reference_1, style_reference_2, ...). | IMAGE | 아니요 | 0~Recraft API에서 허용하는 최대 참조 이미지 수; 총 인코딩 크기는 10MB를 초과할 수 없습니다 |

**참고:** `size` 매개변수는 선택한 `model`에 따라 사용 가능한 옵션이 달라지는 동적 입력입니다. `recraftv4_styles` 및 `recraftv4_styles_pro` 모델은 항상 스타일이 필요합니다. 스타일 참조 이미지를 연결하거나 `style_id`를 제공하세요. `style_id` 및 `style_references` 입력은 상호 배타적이므로 둘 중 하나만 제공하세요. `style_id`는 유효한 UUID여야 합니다. `style_match` 입력은 스타일이 제공된 경우에만 사용됩니다. 스타일 참조 이미지는 생성 비용에 추가로 청구되며 총 인코딩 크기는 10MB를 초과할 수 없습니다. `seed` 값은 재현 가능한 이미지 출력을 보장하지 않습니다. Infinite Style Library의 스타일 ID를 사용하는 경우 벡터 아트 스타일이 아닌지 확인하세요. 그렇지 않으면 이미지 대신 SVG 데이터가 반환될 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 이미지 또는 이미지 배치입니다. | IMAGE |
| `style_id` | 이 생성에서 사용되거나 만들어진 스타일 ID입니다. 스타일 참조 이미지가 제공된 경우 생성된 스타일이 재사용을 위해 여기에 반환됩니다. 스타일이 사용되지 않으면 빈 문자열입니다. | STRING |
