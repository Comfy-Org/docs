이 노드는 ByteDance의 Seedance 2.5 또는 2.0 모델을 사용하여 텍스트 프롬프트로부터 비디오를 생성합니다. 선택한 모델에 프롬프트를 전송하고, 비디오 처리가 완료될 때까지 기다린 뒤 결과 비디오 파일을 반환합니다. `Seedance 2.5 Draft` 모델을 선택하면 대신 빠른 480p 미리보기를 렌더링합니다. 결과로 나온 `draft_task_id`를 ByteDance Seedance 2.5 Draft to Final Video 노드에 연결하여 1080p 최종본을 렌더링하십시오.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용할 Seedance 모델입니다. Seedance 2.5는 최신 모델이며 최대 30초 길이의 비디오와 mp4 출력을 지원합니다. Seedance 2.5 Draft는 빠른 480p 미리보기를 렌더링하며, 그 `draft_task_id` 출력은 ByteDance Seedance 2.5 Draft to Final Video 노드에서 1080p 최종본을 렌더링합니다. Seedance 2.0은 최고 품질 및 4k용입니다. Seedance 2.0 Fast는 속도 최적화용입니다. Seedance 2.0 Mini는 가장 빠르고 비용이 가장 낮은 생성을 위한 모델입니다. 모델을 선택하면 프롬프트, 해상도, 화면 비율, 길이, 오디오 생성에 대한 추가 입력이 표시됩니다. | DYNAMIC_COMBO | 예 | `"Seedance 2.5"`<br />`"Seedance 2.5 Draft"`<br />`"Seedance 2.0"`<br />`"Seedance 2.0 Fast"`<br />`"Seedance 2.0 Mini"` |
| `seed` | 노드를 다시 실행할지 여부를 제어합니다. seed 값과 관계없이 결과는 비결정적입니다. (기본값: 0) | INT | 아니요 | 0 ~ 2147483647 |
| `watermark` | 비디오에 워터마크를 추가할지 여부입니다. (기본값: False) 고급 설정입니다. | BOOLEAN | 아니요 | True / False |

### Seedance 2.5 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성용 텍스트 프롬프트입니다. 생성되는 대사를 유도하려면 말할 대사를 큰따옴표로 묶습니다. | STRING | 예 | — |
| `resolution` | 출력 비디오의 해상도입니다. (기본값: `"720p"`) | COMBO | 예 | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `ratio` | 출력 비디오의 화면 비율입니다. (기본값: `"16:9"`) | COMBO | 예 | `"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"`<br />`"adaptive"` |
| `duration` | 출력 비디오의 길이(초)입니다. (기본값: 5) | INT | 예 | 4 ~ 30 |
| `generate_audio` | 출력 비디오의 오디오 생성을 활성화합니다. (기본값: True) | BOOLEAN | 예 | True / False |
| `output_format` | 출력 비디오의 컨테이너 형식입니다. (기본값: `"mp4"`) | COMBO | 예 | `"mp4"` |

### Seedance 2.5 Draft 입력

이 입력들은 `Seedance 2.5 Draft`를 선택했을 때 표시됩니다. 매개변수 구성은 위의 Seedance 2.5와 동일하지만, `resolution`은 `"480p"`만 제공합니다(기본값 `"480p"`).

### Seedance 2.0 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성용 텍스트 프롬프트입니다. | STRING | 예 | — |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"480p"`<br />`"720p"`<br />`"1080p"`<br />`"4k"` |
| `ratio` | 출력 비디오의 화면 비율입니다. (기본값: `"16:9"`) | COMBO | 예 | `"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"`<br />`"adaptive"` |
| `duration` | 출력 비디오의 길이(초)입니다. (기본값: 7) | INT | 예 | 4 ~ 15 |
| `generate_audio` | 출력 비디오의 오디오 생성을 활성화합니다. (기본값: True) | BOOLEAN | 예 | True / False |

### Seedance 2.0 Fast 및 Seedance 2.0 Mini 입력

Seedance 2.0 Fast와 Seedance 2.0 Mini에서 공유됩니다. 두 모델 모두 동일한 매개변수를 제공합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성용 텍스트 프롬프트입니다. | STRING | 예 | — |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"480p"`<br />`"720p"` |
| `ratio` | 출력 비디오의 화면 비율입니다. (기본값: `"16:9"`) | COMBO | 예 | `"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"`<br />`"adaptive"` |
| `duration` | 출력 비디오의 길이(초)입니다. (기본값: 7) | INT | 예 | 4 ~ 15 |
| `generate_audio` | 출력 비디오의 오디오 생성을 활성화합니다. (기본값: True) | BOOLEAN | 예 | True / False |

**참고:** `model` 선택자는 동적입니다. 각 모델 섹션 아래에 표시된 입력은 해당 모델을 선택했을 때 나타납니다. 프롬프트는 공백을 제거한 후 최소 1자 이상이어야 합니다. 해상도와 길이 제한은 선택한 모델에 따라 달라집니다. Seedance 2.5는 480p/720p/1080p와 4~30초를 지원하고, Seedance 2.0은 480p/720p/1080p/4k와 4~15초를 지원하며, Seedance 2.0 Fast와 Seedance 2.0 Mini는 480p/720p와 4~15초만 지원합니다. Seedance 2.5 Draft는 480p만 지원하고 4~30초를 지원합니다. 모든 실행은 작업 ID를 `draft_task_id`로 반환하지만, `Seedance 2.5 Draft` 실행의 ID만 ByteDance Seedance 2.5 Draft to Final Video 노드에서 렌더링할 수 있습니다. 따라서 다른 모델을 사용하는 경우 출력을 연결하지 않은 상태로 두어야 하며, 그렇지 않으면 실행이 실패합니다. `seed` 값은 노드를 다시 실행할지 여부만 제어하며, 결과를 결정적으로 만들지는 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 생성된 비디오 파일입니다. | VIDEO |
| `draft_task_id` | 실행에서 반환된 작업 ID입니다. `Seedance 2.5 Draft` 실행만 ByteDance Seedance 2.5 Draft to Final Video 노드에서 렌더링할 수 있는 초안을 생성합니다. 다른 모델을 사용하는 경우 출력을 연결하지 않은 상태로 두어야 하며, 그렇지 않으면 실행이 실패합니다. | STRING |
