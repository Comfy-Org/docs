이 노드는 LTXV-AV 모델에 크로스 모달(오디오-비디오) 가이던스를 적용합니다. 샘플링 중에 오디오-비디오 및 비디오-오디오 크로스 어텐션 연결을 비활성화한 상태로 단계마다 추가 순방향 패스를 한 번 실행하고, 그 결과를 결합된 예측 쪽으로 끌어당깁니다. 이는 립싱크와 같은 오디오-비주얼 동기화를 강화합니다. `modality_scale`의 참조 기본값은 3.0이며, 1.0으로 설정하면 추가 패스가 비활성화됩니다.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | 모달리티 가이던스가 적용될 기본 모델입니다. 내부적으로 복제되어 원본 모델은 변경되지 않습니다. | MODEL | 예 | - |
| `modality_scale` | 오디오-비디오 결합 가이던스의 강도입니다. 기본값은 3.0입니다. 1.0으로 설정하면 추가 순방향 패스가 비활성화됩니다. | FLOAT | 예 | 1.0 ~ 100.0 (default: 3.0) |
| `start_percent` | 모달리티 가이던스가 시작되는 샘플링 과정의 지점을 0.0에서 1.0 사이의 백분율로 나타냅니다. 기본값은 0.0입니다. | FLOAT | 예 | 0.0 ~ 1.0 (default: 0.0) |
| `end_percent` | 모달리티 가이던스가 종료되는 샘플링 과정의 지점을 0.0에서 1.0 사이의 백분율로 나타냅니다. 기본값은 1.0입니다. | FLOAT | 예 | 0.0 ~ 1.0 (default: 1.0) |

가이던스는 sigma 값이 `start_percent`와 `end_percent`로 정의된 범위 내에 있는 샘플링 단계에만 적용됩니다. 이 범위를 벗어나면 노드는 노이즈 제거 결과를 변경하지 않고 반환합니다. `modality_scale`이 1.0이면 추가 순방향 패스도 완전히 비활성화됩니다.

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `model` | 복제된 모델에 포스트-CFG 가이던스 함수가 연결되어 있습니다. 이 수정된 모델은 샘플링 중에 모달리티 가이던스를 적용합니다. | MODEL |
