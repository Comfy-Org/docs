VSR Decode는 RelayVSR Conditioning의 키프레임 잠재값을 RelayVSR Flash 디코더를 사용해 전체 비디오로 되돌립니다. 디코더는 전달한 저품질 프레임의 바이큐빅 업스케일 결과 위에 디코더의 x2 또는 x4 배율로 세부 정보를 추가합니다. 프레임 수는 동일하게 유지됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `vae` | RelayVSR Flash 디코더로, Load VAE로 로드합니다: `relayvsr_flash_vae_x2_fp32.safetensors` 또는 `relayvsr_flash_vae_x4_fp32.safetensors`. 파일의 메타데이터가 업스케일 배율을 설정하므로 모델과 일치해야 합니다. | VAE | 예 | 해당 없음 |
| `samples` | 샘플러에서 반환된 잠재값으로, 키프레임마다 하나의 프레임을 담고 있습니다. | LATENT | 예 | 해당 없음 |
| `images` | RelayVSR Conditioning에 전달한 것과 동일한 저품질 비디오입니다. | IMAGE | 예 | 해당 없음 |
| `detail` | 바이큐빅 업스케일 위에 디코더의 세부 정보를 얼마나 유지할지 지정합니다. 1은 전체 모델 출력이고, 0은 순수 업스케일입니다. (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `images` | 모든 프레임이 복원된 업스케일 비디오입니다. | IMAGE |

## 참고

- 두 노드에 동일한 저품질 비디오를 전달하세요. 디코더는 이를 프레임 단위로 읽으므로 길이나 해상도가 일치하지 않으면 잘못되거나 깨진 결과가 나옵니다.
- `detail` 값을 낮추면 복원된 세부 정보가 부드러워지고 출력이 순수 바이큐빅 업스케일에 더 가까워지며, 이는 노이즈가 매우 많은 소스에서 도움이 될 수 있습니다.
