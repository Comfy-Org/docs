프롬프트와 명시적인 출력 크기를 사용하여 BFL API를 통해 Flux.2 [pro]로 이미지를 생성하며, 선택적으로 참조 이미지의 안내를 받을 수 있습니다.

**참고:** 이 노드는 소스 코드에서 사용 중단(deprecated)으로 표시되어 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 이미지 생성 또는 편집을 위한 프롬프트입니다. | STRING | 예 | - |
| `너비` | 생성된 이미지의 너비(픽셀)입니다(기본값: 1024). | INT | 예 | 256 ~ 2048 (단계: 32) |
| `높이` | 생성된 이미지의 높이(픽셀)입니다(기본값: 768). | INT | 예 | 256 ~ 2048 (단계: 32) |
| `시드` | 노이즈 생성에 사용되는 무작위 시드입니다(기본값: 0). | INT | 예 | 0 ~ 18446744073709551615 |
| `프롬프트 업샘플링` | 프롬프트에 업샘플링을 수행할지 여부입니다. 활성화하면 더 창의적인 생성을 위해 프롬프트가 자동으로 수정됩니다(기본값: `True`). 이는 고급 설정입니다. | BOOLEAN | 예 | True / False |
| `이미지` | 이미지 대 이미지 생성을 위한 선택적 참조 이미지입니다. 각 이미지는 업로드 전에 최대 2048x2048픽셀로 축소됩니다. | IMAGE | 아니요 | 0 ~ 9 개 이미지 |

**제약 사항:**

* 9개를 초과하는 참조 이미지를 연결하면 오류가 발생합니다.
* 출력 크기는 메가픽셀 단위로 과금되므로 `width`와 `height` 값이 클수록 비용이 더 많이 듭니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 생성된 이미지입니다. | IMAGE |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/Flux2ProImageNode/ko.md)
