이 노드는 LTX 2.5 모델을 사용하여 시작 이미지로부터 전문가 수준의 비디오를 생성합니다. 텍스트 프롬프트로 비디오 콘텐츠를 설명하고, 모델 변형을 선택하며, 지속 시간, 해상도, 프레임 레이트 및 오디오 생성을 조정합니다. 선택적으로 마지막 프레임을 제공하여 비디오의 끝을 정의할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 비디오에 사용할 첫 번째 프레임입니다. | IMAGE | 예 | 정확히 하나의 이미지 |
| `모델` | 모델 설정 그룹입니다. 사용할 LTX 2.5 모델 변형을 선택합니다. | COMBO | 예 | "LTX-2.5 (Fast)"<br />"LTX-2.5 (Pro)" |
| `지속 시간` | 생성된 비디오의 길이(초)입니다. | INT | 예 | 정수 |
| `해상도` | 생성된 비디오의 해상도입니다. 사용 가능한 옵션은 선택한 모델에 따라 달라질 수 있습니다. | COMBO | 예 | "1280x720"<br />"720x1280"<br />"1920x1080"<br />"1080x1920"<br />"2560x1440"<br />"1440x2560"<br />"3840x2160"<br />"2160x3840" |
| `FPS` | 생성된 비디오의 프레임 레이트입니다. | INT | 예 | 정수 (기본값: 25) |
| `오디오 생성` | 비디오에 오디오를 생성할지 여부입니다. | BOOLEAN | 예 | True<br />False (기본값: True) |
| `프롬프트` | 생성할 비디오 콘텐츠에 대한 텍스트 설명입니다. 1자에서 10000자 사이여야 합니다. | STRING | 예 | 1자에서 10000자 |
| `시드` | 재현 가능한 생성을 위한 시드 값입니다. 동일한 설정과 동일한 시드를 사용하면 동일한 결과가 생성됩니다. | INT | 예 | 정수 (기본값: 42) |
| `마지막 프레임` | 비디오에 사용할 마지막 프레임입니다. | IMAGE | 아니요 | 정확히 하나의 이미지 |

**참고:** `image`에는 하나의 이미지만 지원됩니다. `last_frame`을 제공하는 경우에도 정확히 하나의 이미지를 포함해야 합니다. 사용 가능한 `model.resolution` 옵션은 선택한 `model` 변형에 따라 달라질 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `video` | 제공된 시작 이미지와 생성 설정을 기반으로 생성된 비디오입니다. | VIDEO |
