ControlNetInpaintingAliMamaApply 노드는 포지티브 컨디셔닝과 네거티브 컨디셔닝을 제어 이미지 및 마스크와 결합하여 인페인팅 작업을 위한 ControlNet 컨디셔닝을 적용합니다. 입력 이미지와 마스크를 처리하여 생성 과정을 안내하는 수정된 컨디셔닝을 생성하며, 이미지에서 인페인팅할 영역을 정밀하게 제어할 수 있습니다. 이 노드는 강도 조정 및 타이밍 제어를 지원하여 생성 과정의 여러 단계에서 ControlNet의 영향을 미세하게 조정할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `긍정 조건` | 원하는 콘텐츠를 향해 생성 과정을 안내하는 포지티브 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `부정 조건` | 원하지 않는 콘텐츠에서 생성 과정을 멀어지게 하는 네거티브 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `컨트롤넷` | 생성 과정에 추가 제어를 제공하는 ControlNet 모델입니다. | CONTROL_NET | 예 | - |
| `vae` | 이미지 인코딩 및 디코딩에 사용되는 VAE(변분 오토인코더)입니다. | VAE | 예 | - |
| `이미지` | ControlNet에 제어 안내를 제공하는 입력 이미지입니다. | IMAGE | 예 | - |
| `마스크` | 이미지에서 인페인팅할 영역을 정의하는 마스크입니다. | MASK | 예 | - |
| `강도` | ControlNet 효과의 강도입니다 (기본값: 1.0, 단계: 0.01). | FLOAT | 예 | 0.0 ~ 10.0 |
| `시작 퍼센트` | 고급 매개변수. 생성 중 ControlNet 영향이 시작되는 시점(백분율)입니다 (기본값: 0.0, 단계: 0.001). | FLOAT | 예 | 0.0 ~ 1.0 |
| `종료 퍼센트` | 고급 매개변수. 생성 중 ControlNet 영향이 중지되는 시점(백분율)입니다 (기본값: 1.0, 단계: 0.001). | FLOAT | 예 | 0.0 ~ 1.0 |

**참고:** ControlNet에서 `concat_mask`가 활성화된 경우, 마스크가 반전되어 처리 전에 이미지에 적용되며, 반전된 마스크는 ControlNet으로 전송되는 추가 연결(concatenation) 데이터에 포함됩니다.

## 출력

| `부정 조건` | 인페인팅을 위해 ControlNet이 적용된 수정된 네거티브 컨디셔닝입니다. | CONDITIONING |
