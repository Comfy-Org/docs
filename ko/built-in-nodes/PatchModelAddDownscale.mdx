PatchModelAddDownscale (Kohya Deep Shrink)는 선택한 블록에서 중간 특징을 축소한 다음 원래 크기로 다시 확대하는 방식으로 모델에 Kohya Deep Shrink 기법을 적용합니다. 축소는 디노이징 과정 중 선택된 구간에서만 발생하므로 처리 비용을 줄이면서 최종 결과를 원본에 가깝게 유지할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 다운스케일 패치를 적용할 모델 | MODEL | 예 | - |
| `블록 번호` | 다운스케일링이 적용될 특정 블록 번호 (기본값: 3) | INT | 예 | 1-32 |
| `다운스케일 배율` | 특징을 다운스케일링할 배율 (기본값: 2.0) | FLOAT | 예 | 0.1-9.0 |
| `시작 퍼센트` | 다운스케일링이 시작되는 디노이징 과정의 시작 지점 (기본값: 0.0) | FLOAT | 예 | 0.0-1.0 |
| `종료 퍼센트` | 다운스케일링이 중지되는 디노이징 과정의 종료 지점 (기본값: 0.35) | FLOAT | 예 | 0.0-1.0 |
| `스킵 후 다운스케일` | 스킵 연결 이후에 다운스케일링을 적용할지 여부 (기본값: True) | BOOLEAN | 예 | - |
| `다운스케일 방법` | 다운스케일링 작업에 사용되는 보간 방법 (기본값: "bicubic") | COMBO | 예 | "bicubic"<br />"nearest-exact"<br />"bilinear"<br />"area"<br />"bislerp" |
| `업스케일 방법` | 업스케일링 작업에 사용되는 보간 방법 (기본값: "bicubic") | COMBO | 예 | "bicubic"<br />"nearest-exact"<br />"bilinear"<br />"area"<br />"bislerp" |

다운스케일 패치는 현재 디노이징 단계가 `start_percent`와 `end_percent`로 정의된 범위에 속하고, `block_number`로 선택된 블록일 때만 적용됩니다. `downscale_after_skip`이 활성화되면 패치는 스킵 연결 이후에 적용되고, 비활성화되면 스킵 연결 이전에 적용됩니다. 이후 특징은 원래 크기로 다시 업스케일되지만, 현재 특징 크기가 다운스케일링 전에 기록된 크기와 더 이상 일치하지 않을 때만 그렇게 됩니다.

`block_number`, `start_percent`, `end_percent`, `downscale_after_skip` 매개변수는 노드 인터페이스에서 고급 옵션으로 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | 다운스케일 패치가 적용된 수정된 모델 | MODEL |
