Grok Image Edit 노드는 텍스트 프롬프트를 기반으로 기존 이미지를 수정합니다. Grok API를 사용하여 사용자의 설명에 따라 입력 이미지의 변형인 하나 이상의 새 이미지를 생성합니다. 이 노드는 더 이상 사용되지 않음(Deprecated)으로 표시되어 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 이미지 편집에 사용할 특정 AI 모델입니다. | COMBO | 예 | `"grok-imagine-image-quality"`<br />`"grok-imagine-image-pro"`<br />`"grok-imagine-image"` |
| `image` | 편집할 입력 이미지입니다. | IMAGE | 예 |  |
| `프롬프트` | 이미지를 생성하는 데 사용되는 텍스트 프롬프트입니다. 여러 줄 텍스트이며, 공백이 아닌 문자가 하나 이상 포함되어야 합니다. | STRING | 예 |  |
| `해상도` | 출력 이미지의 해상도입니다. | COMBO | 예 | `"1K"`<br />`"2K"` |
| `이미지 개수` | 생성할 편집 이미지 수입니다 (기본값: 1). | INT | 예 | 1 ~ 10 |
| `시드` | 노드 재실행 여부를 결정하는 시드입니다. 실제 결과는 시드와 관계없이 비결정적입니다 (기본값: 0). | INT | 예 | 0 ~ 2147483647 |
| `종횡비` | 출력 이미지의 종횡비입니다. 여러 이미지가 `image` 입력에 연결된 경우에만 허용됩니다 (기본값: "auto"). | COMBO | 아니요 | `"auto"`<br />`"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"9:16"`<br />`"16:9"`<br />`"9:19.5"`<br />`"19.5:9"`<br />`"9:20"`<br />`"20:9"`<br />`"1:2"`<br />`"2:1"` |

**중요한 제약 사항:**
- `image` 입력은 최대 3개의 이미지를 지원합니다. 단, `grok-imagine-image-pro` 모델을 사용하는 경우에는 입력 이미지를 1개만 지원합니다.
- `aspect_ratio` 매개변수는 여러 이미지가 `image` 입력에 연결된 경우에만 사용자 지정 값("auto" 아님)으로 설정할 수 있습니다. 단일 입력 이미지로 사용자 지정 종횡비를 설정하면 오류가 발생합니다.
- `prompt`에는 공백이 아닌 문자가 하나 이상 포함되어야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 노드에서 생성된 편집 이미지입니다. 이미지가 두 개 이상 생성된 경우, 이미지들은 단일 배치로 연결됩니다. | IMAGE |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/GrokImageEditNode/ko.md)
