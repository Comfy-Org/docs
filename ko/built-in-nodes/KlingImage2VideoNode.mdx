Kling Image to Video 노드는 시작 이미지를 첫 번째 프레임으로 사용하여 짧은 비디오를 생성합니다. 이 노드는 이미지와 텍스트 프롬프트 및 생성 설정을 결합한 후, 결과 비디오와 해당 ID 및 길이를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `start_frame` | 비디오 생성에 사용되는 참조 이미지입니다. 이미지는 최소 300x300 픽셀이어야 하며 화면비가 1:2.5에서 2.5:1 사이여야 합니다. | IMAGE | 예 | - |
| `프롬프트` | 긍정 텍스트 프롬프트입니다. 비어 있으면 안 되며 최대 500자입니다. | STRING | 예 | - |
| `부정 프롬프트` | 부정 텍스트 프롬프트입니다. 최대 500자이며, 사용하지 않는 경우 비워 둡니다. | STRING | 예 | - |
| `모델명` | 비디오 생성에 사용되는 모델입니다(기본값: `"kling-v2-5-turbo"`). | COMBO | 예 | `"kling-v2-5-turbo"` |
| `cfg 스케일` | 비디오가 프롬프트를 얼마나 밀접하게 따르는지 제어합니다. 값이 높을수록 프롬프트를 더 강하게 따릅니다(기본값: 0.8). | FLOAT | 예 | 0.0 ~ 1.0 |
| `모드` | 생성 모드입니다(기본값: `"pro"`). | COMBO | 예 | `"pro"` |
| `종횡비` | 생성된 비디오의 화면비입니다(기본값: `"16:9"`). | COMBO | 예 | `"16:9"`<br />`"9:16"`<br />`"1:1"` |
| `길이` | 생성된 비디오의 길이(초)입니다(기본값: `"5"`). | COMBO | 예 | `"5"`<br />`"10"` |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오 출력입니다. | VIDEO |
| `비디오 ID` | 생성된 비디오의 고유 식별자입니다. | STRING |
| `길이` | 생성된 비디오의 길이 정보입니다. | STRING |
