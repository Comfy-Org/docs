이 노드는 Z-Image Turbo 모델을 사용하여 텍스트 프롬프트로부터 이미지를 생성하며, 단 8단계로 완료됩니다. 생성은 Comfy Cloud GPU에서 원격으로 실행되며 실행 시간에 따라 과금되므로, 이미지 아이디어를 반복 실험할 때 여기에서 가장 빠르고 저렴한 옵션 중 하나입니다. 생성이 완료되면 노드는 완성된 이미지를 다운로드하여 워크플로우에서 사용할 수 있게 합니다. 이 노드는 BETA로 표시된 Comfy Cloud 노드 세트의 일부입니다: 옵션이 추가되거나 제거될 수 있으며, 워크플로우가 폐기될 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 생성할 이미지를 설명하는 텍스트 프롬프트입니다. 여러 줄 입력을 허용하며 제출 전에 공백이 제거됩니다. 공백 제거 후 비어 있으면 안 됩니다. 기본값: "" (비어 있음). | STRING | 예 | 1 - 4096자 |
| `시드` | 생성을 재현 가능하게 제어하는 데 사용되는 무작위 시드입니다. 값을 변경하면 다른 변형이 생성됩니다. 생성 후 제어 옵션을 포함합니다. 기본값: 42. | INT | 아니요 | 0 - 18446744073709551615 |
| `aspect_ratio` | 생성된 이미지의 종횡비입니다. 기본값: "1:1". | COMBO | 아니요 | "1:1"<br />"3:4"<br />"2:3"<br />"3:2"<br />"4:3"<br />"16:9"<br />"9:16"<br />"21:9" |
| `메가픽셀` | 총 픽셀 예산입니다. 1.0은 정사각형 비율에서 약 1024x1024에 해당합니다. 기본값: 1.0. | FLOAT | 아니요 | 0.1 - 16.0<br />(0.1 단위) |

참고: 입력 값은 생성이 제출되기 전에 검증됩니다. `prompt`는 공백이 제거된 후 1자 이상 4,096자 이하여야 하며, `aspect_ratio`는 나열된 옵션 중 하나여야 하고, `megapixels`는 0.1 단위로 입력해야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 생성된 이미지는 이미지 텐서로 반환되며, 추가 이미지 처리나 저장 노드에 사용할 준비가 되어 있습니다. | IMAGE |
