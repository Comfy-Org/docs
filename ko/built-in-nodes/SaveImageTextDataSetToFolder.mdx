Save Image-Text (to Folder)는 이미지 목록과 해당하는 텍스트 캡션을 ComfyUI 출력 디렉터리 내의 지정된 폴더에 저장합니다. 각 이미지가 PNG 파일로 저장될 때, 동일한 기본 이름을 가진 TXT 파일이 생성되어 해당 캡션을 저장합니다. 이를 통해 생성된 이미지와 설명을 짝지은 체계적인 데이터셋을 만드는 데 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 저장할 이미지 목록입니다. | IMAGE | 예 | - |
| `texts` | 저장할 텍스트 캡션 목록입니다. 이 입력은 선택 사항입니다. | STRING | 아니요 | - |
| `folder_name` | 이미지를 저장할 폴더 이름입니다(출력 디렉터리 내). (기본값: "dataset") | STRING | 예 | - |
| `filename_prefix` | 저장된 이미지 파일 이름의 접두사입니다. (기본값: "image") | STRING | 예 | - |
| `mode` | 기존 파일을 덮어쓸지, 아니면 덮어쓰기를 방지하기 위해 파일 이름에 일련번호를 추가할지 여부입니다. (기본값: "overwrite") | COMBO | 예 | "overwrite"<br />"increment" |

**참고:** `images` 입력은 목록입니다. `texts` 입력은 선택 사항이며, 제공되는 경우 텍스트 캡션 목록이어야 하고 `images`와 동일한 항목 수를 포함해야 합니다. 각 캡션은 해당 이미지와 짝을 이루는 `.txt` 파일로 저장됩니다. `overwrite` 모드에서는 파일 이름이 `{filename_prefix}_{index}.png`로 지정되며, 동일한 이름의 기존 파일을 대체합니다. `increment` 모드에서는 고유한 카운터가 파일 이름에 추가되어 기존 파일을 덮어쓰지 않습니다. `folder_name`은 출력 디렉터리 내부의 경로로 확인되어야 하며, 예를 들어 `..`를 사용하여 이를 벗어나려는 폴더 이름은 거부됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| - | 이 노드는 데이터를 반환하지 않습니다. 파일을 파일 시스템에 직접 저장합니다. | - |
