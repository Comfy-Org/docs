EmptyHunyuanImageLatent 노드는 Hunyuan 이미지 생성 모델용 빈(all-zero) 잠재 공간을 생성합니다. 지정된 `width`, `height`, `batch_size`를 사용하여 비어 있는 시작 잠재를 만들며, 이는 워크플로의 다운스트림 노드로 전달할 수 있습니다. 잠재 텐서는 64개 채널을 포함하고, 각 공간 차원은 해당 픽셀 차원을 32로 나눈 값과 같습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `너비` | 생성할 잠재 이미지의 너비(픽셀 단위)입니다. (기본값: 2048, 단계: 32) | INT | 예 | 64 to MAX_RESOLUTION |
| `높이` | 생성할 잠재 이미지의 높이(픽셀 단위)입니다. (기본값: 2048, 단계: 32) | INT | 예 | 64 to MAX_RESOLUTION |
| `배치 크기` | 한 배치에서 생성할 잠재 샘플 수입니다. (기본값: 1) | INT | 예 | 1  ~  4096 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `LATENT` | 64개 채널과 높이 ÷ 32 × 너비 ÷ 32 크기를 가진 빈 잠재 텐서로, Hunyuan 이미지 처리에 사용할 준비가 되어 있습니다. | LATENT |
