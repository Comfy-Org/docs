Luma Ray 3.2 Extend Video는 이전 Luma Ray 3.2 비디오 생성을 이어받아 원본 클립 이후(앞으로) 또는 이전(뒤로)에 새로운 5초 세그먼트를 만듭니다. 이전 Luma Ray 3.2 노드의 `generation_id` 출력을 연결하여 해당 클립을 확장의 시작 프레임(앞으로) 또는 종료 프레임(뒤로)으로 사용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `source_generation_id` | 확장할 이전 Ray 3.2 비디오의 생성 ID입니다. 다른 Luma Ray 3.2 노드의 `generation_id` 출력을 연결하세요. 이 값은 필수이며 비어 있으면 안 됩니다. | STRING | 예 | - |
| `direction` | 앞으로는 이전 클립 이후에 계속되고, 뒤로는 이전 클립 앞에 추가됩니다. "Forward (continue after)"를 선택하면 `loop` 옵션도 추가됩니다. | COMBO | 예 | "순방향(뒤에 이어서)"<br />"역방향(앞에 추가)" |
| `loop` | 확장된 비디오를 매끄럽게 반복합니다(앞으로 확장만). `direction`이 "Forward (continue after)"인 경우에만 사용할 수 있습니다. 기본값: False. | BOOLEAN | 아니요 | True<br />False |
| `prompt` | 새 콘텐츠에 대한 텍스트 프롬프트입니다. 1~6000자 사이여야 합니다. | STRING | 예 | - |
| `resolution` | 확장된 비디오 세그먼트의 출력 해상도입니다. 기본값: "720p". | COMBO | 예 | "540p"<br />"720p"<br />"1080p" |
| `seed` | 재현 가능한 생성 결과를 위한 무작위 시드입니다. | INT | 예 | - |

**참고:** `loop` 매개변수는 `direction`이 "순방향(뒤에 이어서)"으로 설정된 경우에만 사용할 수 있습니다. "역방향(앞에 추가)"을 사용하는 경우 루프 옵션을 사용할 수 없습니다. `prompt`는 1자에서 6000자 사이여야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `generation_id` | 생성된 5초 길이의 확장 비디오 세그먼트입니다. | VIDEO |
| `generation_id` | 이 생성 결과의 고유 식별자로, 다른 Luma Ray 3.2 비디오 확장 노드에 연결하여 추가 확장에 사용할 수 있습니다. | STRING |
