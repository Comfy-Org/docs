Luma Ray 3.2 Extend Video는 이전 Luma Ray 3.2 비디오 생성 결과를 이어서, 원본 클립 이후(전방) 또는 이전(후방)에 새로운 5초 세그먼트를 생성합니다. 이전 Luma Ray 3.2 노드의 `generation_id` 출력을 연결하여 해당 클립을 확장의 시작 프레임(전방) 또는 끝 프레임(후방)으로 사용할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `direction` | 전방은 이전 클립 이후에 이어지며, 후방은 이전 클립 앞에 추가됩니다. 전방은 원본 클립을 시작 프레임으로 사용하고, 후방은 끝 프레임으로 사용합니다. "Forward (continue after)"를 선택하면 `loop` 옵션이 추가됩니다. | DYNAMIC_COMBO | 예 | "Forward (continue after)"<br />"Backward (lead-in before)" |
| `source_generation_id` | 확장할 이전 Ray 3.2 비디오의 생성 ID입니다. 다른 Luma Ray 3.2 노드의 `generation_id` 출력을 연결하세요. 이 값은 필수이며 비어 있으면 안 됩니다. | STRING | 예 | – |
| `prompt` | 새 콘텐츠에 대한 텍스트 프롬프트입니다. 1자 이상 6000자 이하여야 합니다. | STRING | 예 | 1~6000자 |
| `resolution` | 확장된 비디오 세그먼트의 출력 해상도입니다. 기본값: "720p". | COMBO | 예 | "540p"<br />"720p"<br />"1080p" |
| `seed` | 노드 재실행 여부를 결정하는 시드입니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 0. | INT | 예 | 0~0xFFFFFFFFFFFFFFFF |

### Forward (continue after) 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `loop` | 확장된 비디오를 끊김 없이 반복 재생합니다(전방 확장 전용). 기본값: False. | BOOLEAN | 아니오 | True<br />False |

### Backward (lead-in before) 입력

이 방향은 추가 매개변수가 없습니다.

**참고:** 확장 세그먼트는 항상 5초입니다. `loop` 매개변수는 `direction`이 "Forward (continue after)"일 때만 사용할 수 있으며, "Backward (lead-in before)"를 사용할 때는 `loop` 옵션을 사용할 수 없습니다. `prompt`는 1자 이상 6000자 이하여야 합니다. `source_generation_id`는 필수이며 이전 Luma Ray 3.2 노드의 `generation_id` 출력에서 연결해야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 생성된 5초 확장 비디오 세그먼트입니다. | VIDEO |
| `generation_id` | 이 생성에 대한 고유 식별자로, 추가 확장을 위해 다른 Luma Ray 3.2 Extend Video 노드에 연결할 수 있습니다. | STRING |
