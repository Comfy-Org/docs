OpenRouter LLM 노드는 텍스트 프롬프트를 OpenRouter 서비스를 통해 제공되는 선별된 인기 언어 모델 세트로 전송하고 생성된 텍스트 응답을 반환합니다. Anthropic(Claude), OpenAI(GPT), Google(Gemini), xAI(Grok), DeepSeek, Qwen, Mistral, Z.AI(GLM), Moonshot(Kimi), Perplexity Sonar 모델을 지원하며, 요청에 이미지나 비디오를 참조 입력으로 선택적으로 포함할 수 있습니다.

## 입력

`model` 선택기에서 모델을 선택하면 노드는 선택한 모델의 기능에 따라 공통 입력 위에 모델별 위젯(추론 노력, 웹 검색 크기, 및/또는 참조 미디어 슬롯)을 표시합니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 모델에 전달할 텍스트 입력입니다. | STRING | 예 | N/A |
| `model` | 응답 생성에 사용되는 OpenRouter 모델입니다. | DYNAMIC_COMBO | 예 | 사용 가능한 여러 옵션 (아래 모델 섹션 참조) |
| `seed` | 샘플링을 위한 시드입니다. 0으로 설정하면 생략됩니다. 대부분의 모델은 이를 힌트로만 취급합니다. (기본값: 0) | INT | 예 | 0 ~ 2147483647 |
| `system_prompt` | 모델의 동작을 결정하는 기본 지침입니다. (기본값: "") | STRING | 아니요 | N/A |

**참고:**

- **사용 가능한 모델:** 사용 가능한 모델 옵션은 동적으로 구성되며 서로 다른 기능을 가진 모델을 포함합니다. 총 34개 모델의 전체 목록은 다음과 같습니다:
  - Anthropic: `anthropic/claude-opus-5`, `anthropic/claude-opus-4.8`, `anthropic/claude-opus-4.7`, `anthropic/claude-fable-5`, `anthropic/claude-sonnet-5`, `anthropic/claude-haiku-4.5`
  - OpenAI: `openai/gpt-5.6-sol-pro`, `openai/gpt-5.6-sol`, `openai/gpt-5.6-terra-pro`, `openai/gpt-5.6-terra`, `openai/gpt-5.6-luna-pro`, `openai/gpt-5.6-luna`, `openai/gpt-5.5-pro`, `openai/gpt-5.5`
  - Google: `google/gemini-3.5-flash`
  - xAI: `x-ai/grok-4.5`, `x-ai/grok-4.20`, `x-ai/grok-4.3`
  - DeepSeek: `deepseek/deepseek-v4-pro`, `deepseek/deepseek-v4-flash`, `deepseek/deepseek-v3.2`
  - Qwen: `qwen/qwen3.6-max-preview`, `qwen/qwen3.6-plus`, `qwen/qwen3.6-flash`
  - Mistral: `mistralai/mistral-large-2512`, `mistralai/mistral-medium-3-5`
  - Z.AI: `z-ai/glm-4.6`, `z-ai/glm-5`
  - Moonshot: `moonshotai/kimi-k3`, `moonshotai/kimi-k2.6`, `moonshotai/kimi-k2-thinking`
  - Perplexity: `perplexity/sonar-pro`, `perplexity/sonar-reasoning-pro`, `perplexity/sonar-deep-research`

- **이미지 및 비디오 제약:** 참조 이미지와 비디오의 최대 개수는 선택한 모델에 따라 다릅니다. 제공된 이미지 또는 비디오의 총 수가 모델 제한을 초과하면 노드가 오류를 발생시킵니다. 이미지 또는 비디오를 지원하지 않는 모델은 해당 참조 슬롯을 표시하지 않습니다.

- **추론 동작:** `reasoning_effort`가 "off" 외의 값으로 설정되면 요청은 공급자에게 추론 추적을 반환하지 않고 내부적으로 추론하도록 요청합니다.

- **시드 동작:** `seed` 매개변수는 "control_after_generate" 동작을 가집니다. 즉, 사용자의 위젯 설정에 따라 각 노드 실행 후 자동으로 변경(예: 무작위화, 증가 또는 고정)되도록 설정할 수 있습니다.

- **시스템 프롬프트:** `system_prompt` 매개변수는 선택 사항이며 사용자 인터페이스에서 고급 매개변수로 표시됩니다.

- **오류 사례:** 노드는 프롬프트가 공백을 제거한 후 비어 있는 경우, OpenRouter가 오류를 반환하는 경우, 선택한 모델이 응답을 거부하는 경우, 또는 응답에 선택지나 메시지가 없는 경우 오류를 발생시킵니다. 노드의 가격 배지는 선택한 모델 기준 1K 토큰당 대략적인 비용 추정치를 표시합니다.
