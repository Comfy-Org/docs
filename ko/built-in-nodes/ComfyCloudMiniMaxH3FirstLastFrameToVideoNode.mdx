Comfy Cloud GPU에서 MiniMax H3 첫-마지막 프레임 워크플로우를 실행하고, 두 키프레임 사이의 움직임을 일치하는 사운드트랙과 함께 반환합니다. 시작 프레임과 종료 프레임을 제공하면 모델이 그 사이의 장면을 채워 넣습니다. 마지막 프레임은 선택 사항입니다. 마지막 프레임을 생략하면 첫 프레임으로부터 움직임이 이어집니다. 이 노드는 베타 버전이며 GPU 초 단위로 과금됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 비디오가 시작되는 이미지입니다. 워크플로우가 실행되기 전에 최대 2048x2048 픽셀로 업로드됩니다. | IMAGE | 예 | - |
| `last_frame` | 선택적 종료 프레임입니다. 연결되면 생성된 움직임이 이 이미지에서 끝납니다. 연결하지 않으면 `first_frame`으로부터 움직임이 이어집니다. | IMAGE | 아니오 | - |
| `prompt` | 움직임과 장면에 포함될 사운드에 대한 텍스트 설명입니다. 제출 전에 앞뒤 공백이 제거됩니다. | STRING | 예 | 1 ~ 4096자 |
| `seed` | 생성 결과를 제어하는 무작위 시드입니다(기본값: 42). | INT | 예 | 0 ~ 18446744073709551615 |
| `aspect_ratio` | 생성된 비디오의 가로세로 비율입니다(기본값: `"1:1"`). | COMBO | 예 | `"1:1"`<br />`"3:4"`<br />`"2:3"`<br />`"3:2"`<br />`"4:3"`<br />`"16:9"`<br />`"9:16"`<br />`"21:9"` |
| `resolution` | 프레임 크기 예산입니다(기본값: `"480p"`). 720p는 480p에 비해 GPU 초가 대략 두 배 소모됩니다. | COMBO | 예 | `"480p"`<br />`"720p"` |
| `duration_seconds` | 길이(초)입니다(기본값: 5). 파이프라인은 24fps에서 17프레임 단위로 양자화하므로, 클립 길이는 이 값에서 약 2/3초 이내로 맞춰집니다. | INT | 예 | 5 ~ 15 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 사운드트랙이 포함된 생성 비디오입니다. | VIDEO |
