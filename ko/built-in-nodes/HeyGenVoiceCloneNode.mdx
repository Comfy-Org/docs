HeyGen의 Voice 1.0 엔진으로 한 명의 화자가 녹음된 파일에서 음성을 복제합니다. 이 노드는 녹음 파일을 업로드하고, 즉시 음성 복제를 생성하며, HeyGen이 처리를 완료할 때까지 기다린 후 `voice_id`를 반환합니다. 해당 `voice_id`를 HeyGen Voice 1.0 Text to Speech 또는 HeyGen Avatar Video 및 HeyGen Talking Photo의 `custom_voice_id`에 연결하세요. 복제 생성은 무료이며, 해당 음성으로 생성한 발화에 대해서만 비용이 청구됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 한 명의 화자를 녹음한 파일입니다. 최소 10초 이상의 명확한 발화를 사용하십시오. 처음 3분만 사용됩니다. | AUDIO | 예 | N/A |
| `language` | 녹음에서 사용된 언어입니다(기본값: "auto"). | COMBO | 예 | `"auto"`<br />여러 언어 프리셋 |
| `similarity` | 음성이 녹음을 얼마나 밀접하게 따르는지입니다(기본값: "max"). | COMBO | 예 | `"medium"`<br />`"high"`<br />`"extra_high"`<br />`"max"` |
| `remove_background_noise` | 복제하기 전에 녹음의 배경 소음을 정리합니다(기본값: True). | BOOLEAN | 예 | True<br />False |
| `seed` | 녹음을 다시 복제하려면 시드를 변경하십시오. 각 복제본은 약간씩 다른 음성입니다(기본값: 42). | INT | 예 | 0 ~ 2147483647 |

**참고:** 음성은 HeyGen 계정에 "ComfyUI Voice"로 생성되며, 노드는 UI에 `voice_id`를 출력하므로 재사용을 위해 복사할 수 있습니다. 화자가 밀접하게 관련된 언어와 혼동되기 쉬운 언어를 말하는 경우가 아니라면 `language`를 "auto"로 두십시오. `seed` 입력에는 UI에 고정된 Control After Generate 컨트롤이 포함되어 있으므로 다른 복제본을 원할 때 수동으로 변경하십시오.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `voice_id` | 복제된 음성의 ID로, HeyGen Voice 1.0 Text to Speech 노드에서 재사용하거나 `custom_voice_id`로 사용할 수 있습니다. | STRING |
