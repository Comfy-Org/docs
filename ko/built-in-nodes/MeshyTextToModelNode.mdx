The Meshy: Text to Model 노드는 Meshy API를 사용하여 텍스트 설명으로부터 3D 모델을 생성합니다. 프롬프트와 설정을 담아 API에 요청을 보낸 뒤, 생성이 완료될 때까지 기다리고 결과 모델 파일을 다운로드합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 생성에 사용할 AI 모델 버전을 지정합니다. | COMBO | 예 | `"meshy-7.1"`<br />`"meshy-7"`<br />`"meshy-6"`<br />`"latest"` |
| `prompt` | 생성하려는 3D 모델의 텍스트 설명입니다. 길이는 1자 이상 600자 이하여야 합니다. 기본값은 빈 문자열입니다. | STRING | 예 | 1 - 600 characters |
| `style` | 생성된 3D 모델의 예술적 스타일입니다. | COMBO | 예 | `"realistic"` |
| `should_remesh` | false로 설정하면 처리되지 않은 삼각형 메시를 반환합니다. "true"를 선택하면 `topology` 및 `target_polycount`에 대한 추가 매개변수가 표시됩니다. | DYNAMIC_COMBO | 예 | `"true"`<br />`"false"` |
| `topology` | 리메시된 모델의 대상 폴리곤 유형입니다. 이 매개변수는 `should_remesh`가 "true"로 설정된 경우에만 사용할 수 있습니다. | COMBO | 아니요* | `"triangle"`<br />`"quad"` |
| `target_polycount` | 리메시된 모델의 목표 폴리곤 수입니다. 기본값은 300000입니다. 이 매개변수는 `should_remesh`가 "true"로 설정된 경우에만 사용할 수 있습니다. | INT | 아니요* | 100 - 300000 |
| `symmetry_mode` | 생성된 모델의 대칭을 제어합니다. 고급 매개변수입니다. 옵션은 `"auto"`, `"on"`, `"off"`입니다. | COMBO | 예 | `"auto"`<br />`"on"`<br />`"off"` |
| `pose_mode` | 생성된 모델의 포즈 모드를 지정합니다. 빈 문자열은 특정 포즈를 요청하지 않음을 의미합니다. 고급 매개변수입니다. | COMBO | 예 | `""`<br />`"A-pose"`<br />`"T-pose"` |
| `seed` | 시드는 노드의 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값은 0입니다. | INT | 예 | 0 - 2147483647 |
| `ultra_mode` | 더 높은 충실도의 지오메트리와 더 세밀한 표면 디테일을 위해 추가 정제 패스를 실행합니다. 기본값은 false입니다. | BOOLEAN | 예 | true<br />false |
| `ultra_resolution` | 울트라 패스의 해상도: `"2k"`는 2048³, `"4k"`는 4096³에서 실행되어 가장 세밀한 표면 디테일을 제공합니다. `"4k"`에는 `"meshy-7.1"` 또는 `"latest"` 모델이 필요합니다. `ultra_mode`가 활성화된 경우에만 사용됩니다(기본값: `"2k"`). | COMBO | 아니요 | `"2k"`<br />`"4k"` |

*참고: `topology` 및 `target_polycount` 매개변수는 조건부로 사용할 수 있습니다. 이 매개변수들은 `should_remesh` 매개변수가 "true"로 설정된 경우에만 표시됩니다.

`ultra_mode`가 활성화된 경우 `model` 매개변수를 `"meshy-7.1"`, `"meshy-7"`, `"latest"` 중 하나로 설정해야 합니다. 다른 모델을 선택하면 오류가 발생합니다. `"meshy-7"`에서는 울트라 패스가 항상 2048³으로 실행되며, `"4k"` 해상도에는 `"meshy-7.1"` 또는 `"latest"`가 필요합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model_file` | 생성된 GLB 모델의 파일 이름입니다. 이 출력은 이전 버전과의 호환성을 위해 제공됩니다. | STRING |
| `meshy_task_id` | Meshy API 작업의 고유 식별자입니다. | MESHY_TASK_ID |
| `GLB` | GLB 형식으로 생성된 3D 모델 파일입니다. | FILE3DGLB |
| `FBX` | FBX 형식으로 생성된 3D 모델 파일입니다. | FILE3DFBX |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/MeshyTextToModelNode/ko.md)
