이 노드는 여러 이미지 레이어를 하나의 합성 이미지로 결합합니다. Add Layer 노드로 빌드한 레이어 스택을 입력으로 사용하며, 선택적으로 컴포지터 편집기에서 저장된 합성 설정을 적용합니다. 그런 다음 레이어의 배치, 크기, 회전, 불투명도 및 혼합 모드에 따라 레이어를 혼합합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `layers` | 합성할 레이어 스택입니다. Add Layer 노드로 빌드합니다. 항목은 z_index에 따라 쌓이며, 항목 내부의 배치 프레임은 연속적인 레이어로 확장됩니다. 항목의 배치, 불투명도 및 혼합 모드가 초기 합성 상태를 결정합니다. 명시적인 문서 캔버스가 없으면 크기는 배치된 레이어들의 최대 범위로 최선의 방식으로 결정됩니다. 현재 입력과 일치하는 저장된 합성 설정이 우선합니다. | LAYERS | 예 | Maximum 50 layers |
| `compositor` | 컴포지터 편집기에서 저장한 레이어 합성 설정입니다. | COMPOSITOR | 아니요 | None |

**제약 사항 참고:**

- 레이어 스택은 최대 50개 레이어(확장된 프레임 기준)를 지원하며, 이를 초과하면 오류가 발생합니다.
- 현재는 래스터 레이어만 지원됩니다. 다른 유형의 레이어 항목은 오류를 발생시킵니다.
- `layers` 문서 버전은 1이어야 하며, 다른 버전이면 오류가 발생합니다.
- 저장된 `compositor` 상태는 기록된 입력 지문이 현재 레이어 스택과 일치할 때만 재생됩니다. 일치하지 않으면 노드는 레이어 속성을 기준으로 합성하고 저장된 상태를 오래된(stale) 것으로 표시합니다.
- 레이어 불투명도는 0.0~1.0 범위로 제한됩니다.
- 레이어의 가로/세로 배치(`x`, `y`)는 최대 해상도 한도를 넘지 않도록 제한됩니다.
- 레이어 너비와 높이는 0 이하로 설정되면 원본 이미지 크기로 대체되며, 최대 해상도 한도를 초과할 수 없습니다.
- 합성 캔버스 크기는 최대 해상도 한도를 초과해서는 안 됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-----------|-------------|-----------|
| `IMAGE` | 합성된 이미지입니다. 합성 결과에 투명한 영역(예: 숨겨진 배경)이 있으면 알파 채널을 포함하고, 그렇지 않으면 일반 RGB입니다. | IMAGE |
| `MASK` | 합성 결과의 투명도입니다(1 = 완전히 투명). 합성 결과가 불투명하면 모든 값이 0입니다. | MASK |
