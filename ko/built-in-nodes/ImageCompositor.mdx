이 노드는 여러 이미지 레이어를 단일 합성 이미지로 결합합니다. Add Layer 노드로 빌드한 레이어 스택과, 선택적으로 컴포지터 편집기에서 저장한 컴포지션을 입력받아 배치, 크기, 회전, 불투명도, 블렌드 모드 설정에 따라 레이어를 혼합합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `layers` | 합성할 레이어 스택입니다. Add Layer 노드로 빌드합니다. 항목은 z_index별로 쌓이며, 항목 내부의 배치 프레임은 연속된 레이어로 확장됩니다. 항목의 배치, 불투명도, 블렌드 모드가 초기 합성을 정의합니다. 명시적인 문서 캔버스가 없으면 크기는 배치된 레이어의 최대 범위를 기준으로 최선의 값을 사용합니다. 현재 입력과 일치하는 저장된 컴포지션이 있으면 그 컴포지션이 우선합니다. | LAYERS | 예 | 50개 레이어 이하 |
| `compositor` | 컴포지터 편집기에서 저장한 레이어 컴포지션입니다. | COMPOSITOR | 아니요 | 없음 |

**제약 사항 참고:**

- 레이어 스택은 최대 50개 레이어(확장된 프레임 기준)를 지원합니다. 이를 초과하면 오류가 발생합니다.
- 현재는 래스터 레이어만 지원됩니다. 다른 유형의 레이어 항목은 오류를 발생시킵니다.
- `layers` 문서 버전은 1이어야 합니다. 다른 버전은 오류를 발생시킵니다.
- 저장된 `compositor` 상태는 기록된 입력 지문이 현재 레이어 스택과 일치할 때만 재생됩니다. 일치하지 않으면 노드는 레이어 속성에서 합성을 다시 수행하고 저장된 상태를 오래된 것으로 표시합니다.
- 레이어 불투명도는 0.0 ~ 1.0 범위로 제한됩니다.
- 레이어 가로/세로 배치(`x`, `y`)는 최대 해상도 한도로 제한됩니다.
- 레이어 너비와 높이는 0 이하로 설정된 경우 자연 이미지 크기로 대체되며, 최대 해상도 한도로 제한됩니다.
- 합성 캔버스 크기는 최대 해상도 한도를 초과할 수 없습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 합성된 이미지입니다. 합성 결과에 투명 영역이 있으면(예: 숨겨진 배경) 알파 채널을 포함하고, 그렇지 않으면 일반 RGB입니다. | IMAGE |
| `MASK` | 합성 결과의 투명도입니다(1 = 완전히 투명). 합성 결과가 불투명하면 모든 값이 0입니다. | MASK |
