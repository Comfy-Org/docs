이 노드는 각 입력 이미지를 검은색 배경의 중앙 정사각형으로 크롭하고 지정된 출력 크기에 도달하도록 패딩을 추가합니다. 이 노드는 TripoSplat 3D 모델용 이미지를 준비하도록 설계되었으며, 일관된 정사각형 프레임을 보장하고 선택적 알파 매트 침식을 통해 테두리 아티팩트를 방지합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 전처리할 입력 이미지입니다. | IMAGE | 예 | - |
| `mask` | 크롭 영역을 결정하는 데 사용되는 이미지의 알파 마스크입니다. | MASK | 예 | - |
| `erode_radius` | 크롭 전에 알파 매트를 이 픽셀 반경만큼 침식합니다(테두리 번짐 방지). 기본값: 1. 침식을 비활성화하려면 0으로 설정합니다. | INT | 예 | 0 ~ 16 |
| `size` | 정사각형 이미지 크기입니다. 모델은 1024 크기로 학습되었으며, 다른 크기로도 실행되지만 학습 분포에서 벗어납니다. 기본값: 1024. | INT | 예 | 256 ~ 4096 (step of 16) |

**참고:** `mask` 입력은 필수이며 제공되어야 합니다. 마스크의 배치 크기가 이미지와 다른 경우, 마스크는 자동으로 반복되어 일치됩니다. 마스크의 차원이 이미지 차원과 다른 경우, 마스크는 양선형 보간법을 사용하여 이미지와 일치하도록 크기가 조정됩니다. 출력 크기는 DINOv3 패치 및 Flux2 VAE 스트라이드 요구 사항과의 호환성을 보장하기 위해 자동으로 16의 가장 가까운 배수(최소 16)로 내림됩니다. 마스크에 전경 픽셀이 없는 경우(빈 마스크) 노드는 오류를 발생시킵니다. `erode_radius`가 0이면 침식이 적용되지 않습니다. 정사각형 크롭은 마스크의 알파 경계 상자 중앙에 맞춰지며, 더 큰 경계 상자 차원의 1.2배 크기로 조정됩니다. 이미지 경계 밖의 모든 영역은 검은색으로 채워집니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 요청된 `size` 해상도에서 검은색 배경의 중앙 정사각형으로 크롭되고 패딩이 추가된 전처리된 이미지입니다. | IMAGE |
