AlignYourStepsScheduler 노드는 다양한 모델 유형에 따라 디노이징 과정에 사용할 시그마 값(노이즈 레벨)을 생성합니다. 각 샘플링 단계에 적절한 노이즈 레벨을 계산하고 `denoise` 매개변수에 따라 총 단계 수를 조정하여, 샘플링 단계를 여러 디퓨전 모델의 특정 요구 사항에 맞추도록 돕습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델 유형` | 시그마 계산에 사용할 모델 유형을 지정합니다(기본값: "SD1") | COMBO | 예 | `"SD1"`<br />`"SDXL"`<br />`"SVD"` |
| `스텝 수` | 생성할 총 샘플링 단계 수입니다(기본값: 10) | INT | 예 | 1  ~  10000 |
| `노이즈 제거양` | 이미지를 얼마나 디노이징할지 제어하며, 1.0은 모든 단계를 사용하고 더 낮은 값은 더 적은 단계를 사용합니다(기본값: 1.0) | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.01) |

참고: 각 모델 유형에는 11개의 시그마 값(10단계 기준)을 포함하는 내장 노이즈 레벨 스케줄이 있습니다. `denoise`가 0.0이면 노드는 빈 시그마 텐서를 반환합니다. `denoise`가 0.0과 1.0 사이이면 유효 단계 수는 `round(steps × denoise)`로 계산되며, 시그마 스케줄의 마지막 해당 부분만 사용됩니다. 요청된 `steps` 값이 내장 스케줄 길이와 일치하지 않으면 노이즈 레벨은 요청된 단계 수에 맞게 로그 선형 보간됩니다. 최종 시그마 값은 항상 0으로 설정됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `sigmas` | 디노이징 과정을 위해 계산된 시그마 값을 반환합니다 | SIGMAS |
