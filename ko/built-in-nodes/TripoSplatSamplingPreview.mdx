이 노드는 TripoSplat 모델을 패치하여 표준 KSampler 노드와 함께 사용할 때 각 샘플링 단계에서 디코딩된 가우시안 스플랫의 실시간 미리보기가 표시되도록 합니다. 이는 샘플러의 콜백을 래핑하여 매 단계 후 모델 출력을 미리보기 이미지로 디코딩하는 방식으로 작동합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 라이브 미리보기를 위해 패치할 TripoSplat 모델 | MODEL | 예 | |
| `vae` | TripoSplat VAE 디코더 | VAE | 예 | |
| `octree_level` | 미리보기 디코딩을 위한 옥트리 깊이 (낮을수록 계산 비용이 낮고 더 거칠어짐). 기본값: 5 | INT | 아니요 | 2 ~ 8 |
| `num_gaussians` | 미리보기에 생성할 가우시안 수 (32의 배수로 반올림됨). 기본값: 16384 | INT | 아니요 | 1024 ~ 262144 (step: 32) |
| `yaw` | 미리보기 카메라의 요(yaw) 각도(도). 기본값: 90.0 | FLOAT | 아니요 | -360.0 ~ 360.0 (step: 1.0) |
| `pitch` | 미리보기 카메라의 피치(pitch) 각도(도). 기본값: 15.0 | FLOAT | 아니요 | -89.0 ~ 89.0 (step: 1.0) |
| `point_size` | 스플랫의 최대 반경(픽셀). 각 가우시안은 자신의 스케일에서 크기가 결정되며 여기서 상한이 적용됩니다. 낮을수록 더 미세하고 점 형태에 가까우며, 높을수록 더 덩어리집니다. 기본값: 3 | INT | 아니요 | 1 ~ 16 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `MODEL` | 라이브 미리보기 기능이 추가된 패치된 TripoSplat 모델 | MODEL |
