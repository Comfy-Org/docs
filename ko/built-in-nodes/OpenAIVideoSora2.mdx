OpenAIVideoSora2 노드는 OpenAI의 Sora 모델을 사용하여 비디오를 생성합니다. 텍스트 프롬프트와 선택적 입력 참조 이미지를 기반으로 비디오 콘텐츠를 만들고, 생성된 비디오를 출력으로 제공합니다. 이 노드는 선택한 모델에 따라 다양한 비디오 길이와 해상도를 지원합니다.

**지원 중단 공지:** OpenAI는 2026년 9월에 Sora v2 API 제공을 중단합니다. 이 노드는 해당 시점에 ComfyUI에서 제거됩니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 비디오 생성에 사용할 OpenAI Sora 모델입니다 (기본값: "sora-2") | COMBO | 예 | "sora-2"<br />"sora-2-pro" |
| `프롬프트` | 생성을 안내하는 텍스트입니다. 입력 이미지가 있으면 비워 둘 수 있습니다 (기본값: 비어 있음) | STRING | 예 | - |
| `크기` | 생성된 비디오의 해상도입니다 (기본값: "1280x720") | COMBO | 예 | "720x1280"<br />"1280x720"<br />"1024x1792"<br />"1792x1024" |
| `지속 시간` | 생성된 비디오의 길이(초)입니다 (기본값: 8) | COMBO | 예 | 4<br />8<br />12 |
| `이미지` | 비디오 생성에 사용되는 선택적 입력 참조 이미지입니다 (피팅, 캐릭터, 장면 참조 등). 단일 이미지만 지원됩니다 | IMAGE | 아니요 | - |
| `시드` | 노드가 다시 실행될지 여부를 결정하는 시드입니다. 시드와 무관하게 실제 결과는 비결정적입니다 (기본값: 0) | INT | 아니요 | 0~2147483647 |

**제약 사항 및 한계:**

- `"sora-2"` 모델은 `"720x1280"` 및 `"1280x720"` 해상도만 지원합니다. `"1024x1792"` 및 `"1792x1024"` 옵션은 `"sora-2-pro"` 모델에서만 유효합니다.
- 이미지를 연결하는 경우 정확히 하나의 이미지가 포함되어야 합니다. 두 개 이상의 이미지를 연결하면 오류가 발생합니다.
- 시드 값과 관계없이 결과는 비결정적입니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `output` | OpenAI Sora에서 생성된 비디오 파일입니다 | VIDEO |
