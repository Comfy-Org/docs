OpenAIVideoSora2 노드는 OpenAI의 Sora 모델로 비디오를 생성합니다. 텍스트 프롬프트와 선택적 단일 참조 이미지를 입력으로 받아 OpenAI에 요청을 보내고, 생성이 완료될 때까지 기다린 뒤 결과 비디오를 반환합니다. 지원되는 길이와 해상도는 선택한 모델에 따라 달라집니다.

**지원 중단 공지:** OpenAI는 2026년 9월에 Sora v2 API 제공을 중단할 예정입니다. 이 노드는 그 시점에 ComfyUI에서 제거될 예정입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 비디오 생성에 사용할 OpenAI Sora 모델입니다(기본값: "sora-2"). | COMBO | 예 | "sora-2"<br />"sora-2-pro" |
| `프롬프트` | 안내 텍스트입니다. 입력 이미지가 있는 경우 비어 있을 수 있습니다(기본값: 빈 문자열). | STRING | 예 | - |
| `크기` | 생성된 비디오의 해상도입니다(기본값: "1280x720"). | COMBO | 예 | "720x1280"<br />"1280x720"<br />"1024x1792"<br />"1792x1024" |
| `지속 시간` | 생성된 비디오의 길이(초 단위)입니다(기본값: 8). | COMBO | 예 | 4<br />8<br />12 |
| `이미지` | 비디오 생성에 사용되는 선택적 입력 참조 이미지입니다. 단일 이미지만 지원합니다. | IMAGE | 아니요 | - |
| `시드` | 노드의 재실행 여부를 결정하는 시드입니다. 실제 결과는 시드와 관계없이 비결정적입니다(기본값: 0). | INT | 아니요 | 0 ~ 2147483647 |

**제약 사항 및 제한:**

- "sora-2" 모델은 "720x1280" 및 "1280x720" 크기만 지원합니다. "sora-2"에서 "1024x1792" 또는 "1792x1024"를 선택하면 오류가 발생합니다. 더 큰 크기는 "sora-2-pro"에서만 사용할 수 있습니다.
- 이미지가 연결된 경우 정확히 하나의 이미지만 포함해야 합니다. 둘 이상의 이미지를 연결하면 오류가 발생합니다.
- 결과는 시드 값과 관계없이 비결정적입니다.
- 표시되는 가격 추정치는 선택한 `model`, `size`, `duration`에 따라 달라집니다.
