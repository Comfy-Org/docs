Comfy Cloud GPU에서 MiniMax Music 3 워크플로를 실행하고 생성된 노래를 반환합니다. `prompt`에는 스타일, 악기 구성 및 분위기를 담습니다. `lyrics`는 설명이 아니라 실제로 노래로 불리며, 가사를 비워 두면 트랙이 연주곡이 됩니다. 이 노드는 베타 노드이며 GPU 초 단위로 과금됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 노래에 대한 설명으로, 스타일, 악기 구성 및 분위기를 담습니다. 제출 전에 앞뒤 공백이 제거됩니다. | STRING | 예 | 1 ~ 4096자 |
| `가사` | 노래로 부를 가사입니다. 연주곡으로 만들려면 비워 두십시오. | STRING | 아니요 | 0 ~ 4096자 |
| `시드` | 생성 결과를 제어하는 무작위 시드입니다(기본값: 42). | INT | 예 | 0 ~ 9223372036854775807 |
| `max_duration` | 트랙이 실행될 수 있는 최대 길이(초)입니다(기본값: 120.0). 모델이 노래를 더 일찍 끝낼 수 있습니다. | FLOAT | 예 | 0.04 ~ 360.0 (0.04 단위) |
| `audio_quality` | 출력 비트레이트입니다. `"V0"`는 가변 비트레이트이며 세 옵션 중 품질이 가장 높습니다(기본값: `"V0"`). | COMBO | 예 | `"V0"`<br />`"128k"`<br />`"320k"` |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `AUDIO` | 생성된 노래입니다. | AUDIO |
