이 노드는 "ace step 1.5" 프로세스에서 사용할 참조 오디오 음색을 설정합니다. conditioning 입력과 선택적으로 오디오의 잠재 표현을 받아, 해당 잠재 데이터를 conditioning에 첨부하여 워크플로우의 후속 노드에서 사용할 수 있도록 합니다. 이 노드는 현재 실험적 상태로 표시되어 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `컨디셔닝` | 참조 오디오 정보가 첨부될 conditioning 데이터입니다. | CONDITIONING | 예 |  |
| `latent` | 참조 오디오의 선택적 잠재 표현입니다. 제공된 경우 해당 샘플이 conditioning에 추가(첨부)되어 참조 오디오 음색 잠재 표현으로 사용될 수 있습니다. | LATENT | 아니요 |  |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `conditioning` | 선택적 `latent` 입력이 제공된 경우 참조 오디오 음색 잠재 표현을 포함하게 된 수정된 conditioning 데이터입니다. | CONDITIONING |
