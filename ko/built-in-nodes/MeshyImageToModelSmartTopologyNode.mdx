이 노드는 Meshy T2.5를 사용하여 참조 이미지로부터 목표 면 수에 맞는 게임용 삼각형 메시를 생성합니다. 요청된 폴리곤 수에 맞춰 토폴로지를 구축하며, 생성 후에 감면(decimation)을 적용하는 방식이 아니므로 별도의 리토폴로지 과정 없이 게임 엔진에서 바로 사용할 수 있는 결과를 제공합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 생성에 사용할 Meshy 모델 버전입니다. | COMBO | 예 | `"meshy-t2.5"` |
| `image` | 모델 생성에 사용할 참조 이미지입니다. | IMAGE | 예 | - |
| `target_polycount` | 생성된 메시의 대략적인 삼각형 수입니다. 기본값: 15000. | INT | 예 | 100~30000 |
| `should_texture` | 텍스처 생성 여부를 결정합니다. `"false"`로 설정하면 텍스처 단계를 건너뛰고 텍스처가 없는 메시를 반환합니다. | DYNAMIC_COMBO | 예 | `"true"`<br />`"false"` |
| `enable_pbr` | 기본 색상에 더해 PBR 맵(메탈릭, 러프니스, 노멀)을 생성합니다. 이 입력은 `should_texture`가 `"true"`로 설정된 경우에만 사용할 수 있습니다. 기본값: `False`. | BOOLEAN | 아니요 | - |
| `texture_prompt` | 텍스처링 과정을 안내하는 텍스트 프롬프트입니다. 최대 800자까지 입력할 수 있습니다. `texture_image`와 동시에 사용할 수 없습니다. 이 입력은 `should_texture`가 `"true"`로 설정된 경우에만 사용할 수 있습니다. 기본값: `""`(빈 문자열). | STRING | 아니요 | 1~800자 |
| `texture_image` | 텍스처링 과정에 사용할 참조 이미지입니다. `texture_image` 또는 `texture_prompt` 중 하나만 동시에 사용할 수 있습니다. 이 입력은 `should_texture`가 `"true"`로 설정된 경우에만 사용할 수 있습니다. | IMAGE | 아니요 | - |
| `texture_resolution` | 텍스처 해상도입니다. 해상도가 높을수록 더 많은 표면 디테일을 표현할 수 있습니다. 이 입력은 `should_texture`가 `"true"`로 설정된 경우에만 사용할 수 있습니다. | COMBO | 아니요 | `"2k"`<br />`"4k"`<br />`"8k"` |
| `pose_mode` | 생성된 캐릭터의 포즈입니다. 빈 문자열은 특정 포즈를 요청하지 않음을 의미합니다. 고급 설정입니다. 기본값: `""`(빈 문자열). | COMBO | 예 | `""`<br />`"A-pose"`<br />`"T-pose"` |
| `seed` | 시드는 노드의 재실행 여부를 제어합니다. 시드 값과 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |

**참고:** `enable_pbr`, `texture_prompt`, `texture_image` 및 `texture_resolution` 입력은 `should_texture`가 `"true"`로 설정된 경우에만 사용할 수 있습니다.

**제약 사항:**

* `target_polycount`는 메시를 구성하는 삼각형 수이며, 생성 후에 적용되는 제한값이 아닙니다.
* `should_texture`가 `"true"`로 설정된 경우 `texture_prompt`와 `texture_image`를 동시에 사용할 수 없습니다. 둘 다 제공되면 노드에서 오류가 발생합니다.
* `texture_prompt`의 최대 길이는 800자입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `meshy_task_id` | Meshy API 작업의 고유 식별자입니다. | MESHY_TASK_ID |
| `GLB` | GLB 형식으로 생성된 3D 모델입니다. | FILE3DGLB |
| `FBX` | FBX 형식으로 생성된 3D 모델입니다. | FILE3DFBX |
