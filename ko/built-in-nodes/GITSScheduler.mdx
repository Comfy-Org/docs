GITSScheduler 노드는 GITS(Generative Iterative Time Steps) 샘플링 방식에 사용할 노이즈 스케줄 sigma를 생성합니다. 계수 매개변수와 단계 수를 기반으로 sigma 값을 계산하며, 사용되는 총 단계 수를 줄일 수 있는 디노이징 계수를 사용합니다. 이 노드는 미리 정의된 노이즈 레벨과 보간을 사용하여 최종 sigma 스케줄을 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `계수` | 고급 매개변수입니다. 노이즈 스케줄 곡선을 제어하는 계수 값입니다(기본값: 1.20). 이 값은 소수점 두 자리로 반올림되며, 어떤 미리 정의된 노이즈 레벨 테이블을 사용할지 선택합니다. | FLOAT | 예 | 0.80 - 1.50 (단계: 0.05) |
| `스텝 수` | sigma를 생성할 총 샘플링 단계 수입니다(기본값: 10). | INT | 예 | 2 - 1000 |
| `노이즈 제거양` | 사용되는 단계 수를 줄이는 디노이징 계수입니다(기본값: 1.0). | FLOAT | 예 | 0.0 - 1.0 (단계: 0.01) |

**참고:** `denoise`가 0.0 이하이면 노드는 빈 텐서를 반환합니다. `denoise`가 1.0보다 작으면 실제 사용되는 단계 수는 `round(steps * denoise)`로 계산되며, 스케줄의 마지막 해당 부분만 유지됩니다. 단계 수가 2에서 20 사이이면 노드는 일치하는 미리 정의된 노이즈 스케줄을 선택합니다. 단계 수가 20보다 크면 노드는 로그-선형 보간을 사용하여 미리 정의된 노이즈 레벨을 원하는 단계 수까지 확장합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `sigmas` | 노이즈 스케줄에 대해 생성된 sigma 값입니다. N개의 샘플링 단계에 대해 N+1개의 sigma 값이 반환되며, 마지막 sigma는 0으로 설정됩니다. | SIGMAS |
