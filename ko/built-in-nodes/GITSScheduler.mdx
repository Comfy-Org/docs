GITSScheduler 노드는 GITS(Generative Iterative Time Steps) 샘플링 방법에 대한 노이즈 스케줄 시그마를 생성합니다. 계수 매개변수와 단계 수를 기반으로 시그마 값을 계산하며, 사용되는 총 단계를 줄일 수 있는 선택적 디노이징(denoising) 인자를 제공합니다. 이 노드는 사전 정의된 노이즈 레벨과 보간법을 사용하여 최종 시그마 스케줄을 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `계수` | 노이즈 스케줄 곡선을 제어하는 계수 값입니다 (기본값: 1.20). 이 값은 소수점 두 자리로 반올림되며, 사용할 사전 정의된 노이즈 레벨 테이블을 선택합니다. | FLOAT | 예 | 0.80 - 1.50 (간격 0.05) |
| `스텝 수` | 시그마를 생성할 총 샘플링 단계 수입니다 (기본값: 10) | INT | 예 | 2 - 1000 |
| `노이즈 제거양` | 사용되는 단계 수를 줄이는 디노이징 인자입니다 (기본값: 1.0) | FLOAT | 예 | 0.0 - 1.0 |

**참고:** `denoise`가 0.0 이하이면 노드는 빈 텐서를 반환합니다. `denoise`가 1.0 미만이면 실제 사용되는 단계 수는 `round(steps * denoise)`로 계산되며, 스케줄의 마지막 해당 부분만 유지됩니다. 단계 수가 2에서 20 사이인 경우 노드는 일치하는 사전 정의된 노이즈 스케줄을 선택합니다. 단계 수가 20보다 큰 경우 노드는 로그-선형 보간법을 사용하여 사전 정의된 노이즈 레벨을 원하는 단계 수로 확장합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `sigmas` | 노이즈 스케줄에 대한 생성된 시그마 값입니다. N 단계의 경우 N+1개의 시그마 값이 반환되며, 마지막 시그마는 0으로 설정됩니다. | SIGMAS |
