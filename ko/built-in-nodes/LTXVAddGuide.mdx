## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `긍정 조건` | 키프레임 가이던스로 수정할 긍정 컨디셔닝 입력입니다. | CONDITIONING | 예 | - |
| `부정 조건` | 키프레임 가이던스로 수정할 부정 컨디셔닝 입력입니다. | CONDITIONING | 예 | - |
| `vae` | 입력 이미지/비디오 프레임을 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 | - |
| `잠재 비디오` | 컨디셔닝 프레임을 받을 입력 잠재 시퀀스입니다. | LATENT | 예 | - |
| `이미지` | 잠재 비디오를 컨디셔닝할 이미지 또는 비디오입니다. 8*n + 1개 프레임이어야 합니다. 비디오가 8*n + 1개 프레임이 아니면 가장 가까운 8*n + 1개 프레임으로 잘립니다. | IMAGE | 예 | - |
| `프레임 번호` | 컨디셔닝을 시작할 프레임 인덱스입니다. 단일 프레임 이미지 또는 1~8개 프레임의 비디오에서는 모든 `frame_idx` 값을 사용할 수 있습니다. 9개 이상 프레임의 비디오에서는 `frame_idx`가 8로 나누어떨어져야 하며, 그렇지 않으면 가장 가까운 8의 배수로 내림됩니다. 음수 값은 비디오 끝에서부터 계산됩니다. 기본값: 0. | INT | 예 | -9999 ~ 9999 |
| `강도` | 컨디셔닝 영향의 강도로, 1.0은 전체 컨디셔닝을 적용하고 0.0은 컨디셔닝을 적용하지 않습니다. 기본값: 1.0. | FLOAT | 예 | 0.0 ~ 10.0 |
| `attention_mask` | 선택적 픽셀 공간 마스크입니다. 셀프 어텐션을 통해 영역별 컨디셔닝 영향을 제어하며, `strength`가 곱해집니다. | MASK | 아니요 | - |
| `iclora_parameters` | Get IC-LoRA Parameters 노드에서 가져온 선택적 IC-LoRA 매개변수입니다. 특정 IC-LoRA(예: `reference_downscale_factor` > 1인 경우)에서 요구하는 대로 가이드 처리를 조정하는 데 사용됩니다. 체인으로 연결된 경우 각 LTXVAddGuide는 자신에게 연결된 매개변수만 사용합니다. | IC_LORA_PARAMETERS | 아니요 | - |

**참고:** 입력 이미지/비디오는 8*n + 1 패턴(예: 1, 9, 17, 25개 프레임)을 따르는 프레임 수를 가져야 합니다. 입력이 이 패턴을 초과하면 가장 가까운 유효한 프레임 수로 자동으로 잘립니다.

**`iclora_parameters` 관련 참고:** `reference_downscale_factor`가 1보다 큰 IC-LoRA 매개변수를 사용할 때, 잠재 공간 차원(너비와 높이)은 해당 계수로 나누어떨어져야 합니다. 이 조건이 충족되지 않으면 노드에서 오류가 발생합니다.

**참고:** 인코딩된 가이드 프레임은 선택한 프레임 위치에서 잠재 시퀀스 내에 들어맞아야 합니다. 컨디셔닝된 프레임이 잠재 시퀀스 길이를 초과하면 노드에서 오류가 발생합니다.

**참고:** 오디오 및 비디오 채널을 결합한 잠재에 가이드를 추가하는 것은 지원되지 않으며 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 키프레임 가이던스 정보로 업데이트된 긍정 컨디셔닝입니다. | CONDITIONING |
| `negative` | 키프레임 가이던스 정보로 업데이트된 부정 컨디셔닝입니다. | CONDITIONING |
| `latent` | 컨디셔닝 프레임이 포함되고 노이즈 마스크가 업데이트된 잠재 시퀀스입니다. | LATENT |
