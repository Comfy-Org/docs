## 개요

이 노드는 렌더링된 가이던스 비디오(예: 왜곡된 포인트 클라우드 렌더)를 사용하여 Wan 비디오 확산 모델에 Uni3C ControlNet을 적용하며, 모델의 출력에 영향을 줍니다. 특정 블록 레이어에 제어 신호를 주입하여 비디오 생성 중 카메라 궤적 기반 가이던스를 가능하게 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|----------|------|-------------|------|------|
| `모델` | 패치할 Wan 확산 모델입니다. | MODEL | 예 | – |
| `모델 패치` | Uni3C ControlNet 패치입니다(`comfy.ldm.wan.uni3c.WanUni3CControlnet` 인스턴스여야 합니다). | MODEL_PATCH | 예 | – |
| `vae` | 가이던스 비디오를 잠재 변수로 인코딩하는 데 사용되는 VAE입니다. | VAE | 예 | – |
| `렌더 비디오` | 카메라 궤적에서 렌더링된 가이던스 비디오로, 일반적으로 입력 이미지의 왜곡된 포인트 클라우드 렌더입니다. | IMAGE | 예 | – |
| `강도` | 적용되는 제어 신호의 강도입니다. | FLOAT | 예 | -10.0 ~ 10.0 (기본값: 1.0) |
| `시작 비율` | 제어가 시작되는 노이즈 제거 과정의 백분율입니다. | FLOAT | 예 | 0.0 ~ 1.0 (기본값: 0.0) |
| `종료 비율` | 제어가 종료되는 노이즈 제거 과정의 백분율입니다. | FLOAT | 예 | 0.0 ~ 1.0 (기본값: 1.0) |

**참고:**
- `model_patch`는 반드시 Uni3C ControlNet이어야 하며, 그렇지 않으면 노드에서 오류가 발생합니다.
- ControlNet의 내부 차원은 Wan 모델의 차원과 일치해야 하며, 다를 경우 오류가 발생합니다.
- `render_video` 입력 이미지는 RGB 형식이어야 합니다(처음 3개 채널만 사용됩니다).

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-----------|------|-------------|
| `MODEL` | Uni3C ControlNet이 적용된 패치된 Wan 모델입니다. | MODEL |
