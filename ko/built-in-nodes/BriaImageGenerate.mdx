Bria FIBO 2.0을 사용하여 텍스트 프롬프트, 구조화된 JSON 프롬프트 또는 단일 참조 이미지로부터 새로운 이미지를 생성합니다. 이 노드는 Bria API로 요청을 보내고, 생성이 완료될 때까지 기다린 후, 나중에 실행에서 이미지를 재현하거나 개선할 수 있는 구조화된 프롬프트와 함께 이미지를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성할 이미지에 대한 자연어 설명입니다(기본값: 비어 있음). | STRING | 예 | 여러 줄 텍스트 |
| `structured_prompt` | 이전 Bria FIBO 결과에서 가져온 JSON 구조화 프롬프트입니다. 동일한 seed를 사용하면 해당 이미지를 재현하며, JSON을 변경하거나 프롬프트를 추가하여 개선할 수 있습니다(기본값: 비어 있음). | STRING | 예 | 여러 줄 텍스트 |
| `aspect_ratio` | 출력 종횡비입니다(기본값: `"1:1"`). `"16:10"` 이후의 비율은 아래에 나열된 추가 요구 사항이 있는 FIBO 2.0 크기입니다. | COMBO | 예 | `"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"`<br />`"16:10"`<br />`"10:16"`<br />`"2:1"`<br />`"1:2"`<br />`"21:9"`<br />`"9:21"`<br />`"3:1"`<br />`"1:3"`<br />`"4:1"`<br />`"1:4"`<br />`"5:1"`<br />`"1:5"` |
| `resolution` | 메가픽셀 단위의 출력 해상도입니다(기본값: `"1MP"`). | COMBO | 예 | `"1MP"`<br />`"4MP"` |
| `seed` | 생성을 초기화하는 시드입니다(기본값: 42). | INT | 예 | 1  ~  2147483647 |
| `moderation` | 검열 설정입니다. `"true"`를 선택하면 아래에 나열된 검열 입력이 나타납니다. | DYNAMIC_COMBO | 예 | `"false"`<br />`"true"` |
| `image` | 바탕으로 삼을 선택적 참조 이미지입니다. 결과는 선택된 종횡비의 새로운 이미지이며, 이 이미지를 편집한 것이 아닙니다. | IMAGE | 아니오 | - |

### 검열 입력

`moderation`이 `"true"`로 설정되면 다음 추가 입력을 사용할 수 있습니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | 프롬프트 텍스트를 검열할지 여부입니다. 검열에서 거부되면 요청이 실패합니다(기본값: false). | BOOLEAN | 아니오 | `true`<br />`false` |
| `visual_input_moderation` | 참조 이미지를 검열할지 여부입니다. 검열에서 거부되면 요청이 실패합니다(기본값: false). | BOOLEAN | 아니오 | `true`<br />`false` |
| `visual_output_moderation` | 생성된 이미지를 검열할지 여부입니다. 검열에서 거부되면 요청이 실패합니다(기본값: false). | BOOLEAN | 아니오 | `true`<br />`false` |

**중요 제약 사항:**

- `prompt`, `structured_prompt` 또는 참조 `image` 중 하나 이상을 제공해야 합니다. 세 가지가 모두 비어 있으면 노드에서 오류가 발생합니다.
- 참조 이미지는 `structured_prompt`와 함께 사용할 수 없습니다. 둘 중 하나만 사용하십시오.
- FIBO 2.0 비율(`"16:10"`, `"10:16"`, `"2:1"`, `"1:2"`, `"21:9"`, `"9:21"`, `"3:1"`, `"1:3"`, `"4:1"`, `"1:4"`, `"5:1"`, `"1:5"`)을 사용하려면 `resolution`을 `"1MP"`로 설정하고 `prompt` 또는 `structured_prompt` 중 정확히 하나를 제공해야 합니다.
- 이 노드는 유료 API 노드이며, ComfyUI가 실행할 때마다 약 0.0572 USD를 청구합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | Bria API에서 반환된 생성 이미지입니다. | IMAGE |
| `structured_prompt` | 생성된 이미지에 대한 구조화된 설명으로, 이 노드를 사용하여 이미지를 재현하거나 개선하는 데 사용됩니다. | STRING |
