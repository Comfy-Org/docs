ElevenLabs Text to Dialogue 노드는 텍스트로부터 다중 화자 오디오 대화를 생성합니다. 각 참가자에 대해 서로 다른 텍스트 줄과 개별 음성을 지정하여 대화를 만들 수 있습니다. 이 노드는 대화 요청을 ElevenLabs API로 보내고 생성된 오디오를 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `stability` | 음성 안정성입니다. 값이 낮을수록 더 넓은 감정 범위를 제공하고, 값이 높을수록 더 일관되지만 잠재적으로 단조로운 음성을 생성합니다. (기본값: 0.5) | FLOAT | 예 | 0.0 - 1.0 |
| `apply_text_normalization` | 텍스트 정규화 모드입니다. 'auto'는 시스템이 결정하게 하고, 'on'은 항상 정규화를 적용하며, 'off'는 정규화를 건너뜁니다. | COMBO | 예 | `"auto"`<br />`"on"`<br />`"off"` |
| `model` | 대화 생성에 사용할 모델입니다. | COMBO | 예 | `"eleven_v3"` |
| `inputs` | 대화 항목 수입니다. 숫자를 선택하면 해당 수만큼 텍스트와 음성 입력 쌍이 생성됩니다. | DYNAMIC_COMBO | 예 | `"1"`<br />`"2"`<br />`"3"`<br />`"4"`<br />`"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"` |
| `language_code` | ISO-639-1 또는 ISO-639-3 언어 코드입니다 (예: 'en', 'es', 'fra'). 자동 감지를 원하면 비워 두세요. (기본값: 비어 있음) | STRING | 예 | - |
| `seed` | 재현성을 위한 시드입니다. (기본값: 1) | INT | 예 | 0 - 4294967295 |
| `output_format` | 오디오 출력 형식입니다. | COMBO | 예 | `"mp3_44100_192"`<br />`"opus_48000_192"` |

### 대화 항목 입력

모든 `inputs` 옵션에서 공유됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `text1` ... `text10` | 해당 대화 항목의 텍스트 내용입니다. 노드는 선택된 각 대화 항목마다 하나의 `text` 필드를 생성합니다. 각 텍스트 값은 최소 한 문자를 포함해야 합니다. | STRING | 예 | - |
| `voice1` ... `voice10` | 해당 대화 항목의 음성입니다. Voice Selector 또는 Instant Voice Clone 노드에서 연결하세요. 노드는 선택된 각 대화 항목마다 하나의 `voice` 필드를 생성합니다. | ELEVENLABS_VOICE | 예 | - |

**참고:** `inputs` 선택기는 최대 10개의 대화 항목을 생성할 수 있습니다. 각 항목에는 `text` 필드와 `voice` 필드가 모두 필요합니다. `text` 값은 비워 둘 수 없습니다. `voice` 입력은 호환되는 ElevenLabs 음성 노드에서 제공하는 음성 ID를 요구합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `audio` | 선택한 출력 형식으로 생성된 다중 화자 대화 오디오입니다. | AUDIO |
