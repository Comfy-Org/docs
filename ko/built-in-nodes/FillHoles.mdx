이 노드는 열린 경계 엣지를 감지하고 이를 닫기 위한 새 면을 생성하여 3D 메시의 구멍을 채웁니다. GPU에서 실행되며 기존 지오메트리와 UV를 보존하고, 단일 메시, 메시 목록 또는 메시 배치를 처리할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 처리할 3D 메시입니다. 단일 메시, 메시 목록 또는 배치된 메시를 받습니다. | MESH | 예 | - |
| `max_perimeter` | 채울 최대 구멍 둘레입니다. 0이면 비활성화됩니다. (기본값: 0.03) | FLOAT | 예 | 0.0 to no upper limit (단계: 0.0001) |
| `weld_epsilon_rel` | 사전 용접 허용 오차(경계 상자 대각선의 비율)입니다. 경계 감지에는 용접된 정점이 필요합니다. 0이면 건너뜁니다. (기본값: 1e-5) | FLOAT | 예 | 0.0 to no upper limit (step 1e-6) |
| `max_vertices` | 사이클당 경계 정점 수를 제한합니다. 중심 팬은 작고 거의 평면인 구멍에만 작동합니다. 16 이하로 유지하십시오. (기본값: 16) | INT | 예 | 3  ~  1024 |
| `fill_chains` | 열린 체인도 채웁니다(사이클만이 아님). 노이즈가 많습니다. OFF는 cumesh와 일치합니다. (기본값: False) | BOOLEAN | 예 | True or False |

참고: `max_perimeter`가 0보다 크면 노드가 구멍을 채웁니다. 0이면 구멍 채우기가 완전히 건너뛰어집니다. `weld_epsilon_rel`이 0보다 크면 노드가 구멍을 감지하기 전에 중복 정점을 사전 용접합니다. 용접 허용 오차는 경계 상자 대각선의 지정된 비율에서 시작하여 메시가 용접된 것으로 간주되거나 허용 오차가 1e-2의 상한에 도달할 때까지 두 배로 자동 증가합니다. 경계 정점이 8개보다 많은 구멍은 중심 팬 채우기(새 중심 정점 삽입)를 사용하고, 더 작은 구멍은 기존 경계 정점을 재사용하는 정점 팬 채우기를 사용합니다. 기본적으로 닫힌 경계 사이클만 채워집니다. 열린 체인도 닫으려면 `fill_chains`를 True로 설정하십시오.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `mesh` | 구멍이 채워진 메시이며, 입력 배치 형식과 일치합니다. | MESH |
