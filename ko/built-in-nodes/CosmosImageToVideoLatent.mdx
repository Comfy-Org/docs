CosmosImageToVideoLatent 노드는 입력 이미지에서 비디오 잠재 표현을 생성합니다. 요청된 너비, 높이 및 프레임 수로 빈 비디오 잠재를 만든 다음 선택적으로 시작 이미지를 시작 프레임에 인코딩하거나 종료 이미지를 종료 프레임에 인코딩합니다. 이미지가 제공되면 인코딩된 프레임이 생성 중에 고정되도록 노이즈 마스크도 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `vae` | 이미지를 비디오 잠재 공간에 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 필수 | - |
| `너비` | 출력 비디오의 픽셀 단위 너비입니다 (기본값: 1280). | INT | 필수 | 16 to MAX_RESOLUTION (step: 16) |
| `높이` | 출력 비디오의 픽셀 단위 높이입니다 (기본값: 704). | INT | 필수 | 16 to MAX_RESOLUTION (step: 16) |
| `길이` | 비디오의 총 프레임 수입니다 (기본값: 121). | INT | 필수 | 1 to MAX_RESOLUTION (step: 8) |
| `배치 크기` | 생성할 비디오 잠재의 수입니다 (기본값: 1). | INT | 필수 | 1 ~ 4096 |
| `시작 이미지` | 비디오의 시작 부분에 인코딩할 선택적 이미지 또는 이미지 시퀀스입니다. | IMAGE | 선택 | - |
| `끝 이미지` | 비디오의 끝 부분에 인코딩할 선택적 이미지 또는 이미지 시퀀스입니다. | IMAGE | 선택 | - |

**참고:**
- `start_image`와 `end_image`가 모두 제공되지 않으면 노드는 노이즈 마스크 없이 빈 잠재를 반환합니다.
- `start_image`가 제공되면 잠재의 처음 프레임들에 인코딩되며 해당 프레임은 노이즈 마스크 값 0(보존)으로 표시됩니다. `end_image`가 제공되면 마지막 프레임들에 인코딩되며 해당 프레임은 노이즈 마스크 값 0으로 표시됩니다. 나머지 프레임은 마스크 값 1을 유지합니다.
- 잠재는 16개 채널을 가지며 공간 차원은 `height / 8` x `width / 8`입니다. 잠재 프레임 수는 `((length - 1) // 8) + 1`입니다.
- `batch_size`는 잠재와, 존재하는 경우 노이즈 마스크를 반복합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `latent` | 생성된 비디오 잠재로, 선택적으로 인코딩된 시작 및/또는 종료 이미지를 포함하며, 이미지가 제공된 경우 보존된 프레임에 값 0이 있는 일치하는 노이즈 마스크를 포함합니다. | LATENT |
