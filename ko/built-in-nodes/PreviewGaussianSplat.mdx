PreviewGaussianSplat 노드는 3D 가우시안 스플랫 파일을 ComfyUI 출력 디렉터리에 저장하지 않고 프리뷰 창에 표시합니다. 다양한 가우시안 스플랫 형식의 3D 모델 파일을 입력받아 프리뷰용 임시 복사본을 저장한 뒤, 워크플로에서 추가 처리할 수 있도록 모델 데이터를 그대로 전달합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 3D 가우시안 스플랫 파일입니다. | FILE3D | 예 | splat<br />ply<br />spz<br />ksplat |
| `model_3d_info` | 3D 모델에 대한 선택적 메타데이터 정보입니다. 연결되지 않은 경우 노드는 `viewport_state`의 모델 정보를 사용합니다. | LOAD3DMODELINFO | 아니요 | - |
| `viewport_state` | 카메라 및 모델 정보를 포함한 3D 뷰포트의 현재 상태입니다. | LOAD3D | 예 | - |
| `camera_info` | 프리뷰에 사용할 선택적 카메라 정보입니다. 연결되지 않은 경우 노드는 `viewport_state`의 카메라 정보를 사용합니다. | LOAD3DCAMERA | 아니요 | - |
| `width` | 프리뷰 렌더링의 픽셀 너비입니다(기본값: 1024). | INT | 예 | 1 ~ 4096 |
| `height` | 프리뷰 렌더링의 픽셀 높이입니다(기본값: 1024). | INT | 예 | 1 ~ 4096 |

참고: `camera_info` 또는 `model_3d_info`가 제공되지 않으면 노드는 `viewport_state`에 저장된 카메라 및 모델 정보를 대신 사용합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model_3d` | 변경 없이 그대로 통과된 입력 3D 가우시안 스플랫 파일입니다. | FILE3D |
| `model_3d_info` | 입력에서 제공되거나 뷰포트 상태에서 파생된 3D 모델의 메타데이터 정보입니다. | LOAD3DMODELINFO |
| `camera_info` | 입력에서 제공되거나 뷰포트 상태에서 파생된 프리뷰용 카메라 정보입니다. | LOAD3DCAMERA |
| `width` | 프리뷰 렌더링의 너비입니다. | INT |
| `height` | 프리뷰 렌더링의 높이입니다. | INT |
