VAEEncodeTiled는 이미지를 더 작은 타일로 나누고 Variational Autoencoder를 사용하여 인코딩합니다. 이 타일 방식은 메모리 한계를 초과할 수 있는 큰 이미지를 처리할 수 있게 해줍니다. 이 노드는 이미지 및 비디오 VAE를 모두 지원하며, 공간 및 시간 차원에 대해 별도의 타일링 제어 기능을 제공합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `픽셀` | 인코딩할 입력 이미지 데이터 | IMAGE | 예 | - |
| `vae` | 인코딩에 사용되는 Variational Autoencoder 모델 | VAE | 예 | - |
| `타일 크기` | 공간 처리를 위한 각 타일의 크기 (기본값: 512) | INT | 예 | 64-4096 (단계: 64) |
| `겹침` | 인접한 타일 간의 겹침 정도 (기본값: 64) | INT | 예 | 0-4096 (단계: 32) |
| `시간적 크기` | 비디오 VAE에만 사용됨: 한 번에 인코딩할 프레임 수 (기본값: 64) | INT | 예 | 8-4096 (단계: 4) |
| `시간적 겹침` | 비디오 VAE에만 사용됨: 겹칠 프레임 수 (기본값: 8) | INT | 예 | 4-4096 (단계: 4) |

**참고:** `temporal_size` 및 `temporal_overlap` 매개변수는 비디오 VAE를 사용하는 경우에만 관련이 있으며, 표준 이미지 VAE에는 영향을 미치지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `LATENT` | 입력 이미지의 인코딩된 잠재 표현 | LATENT |
