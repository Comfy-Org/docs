Tripo 서비스를 사용하여 텍스트 설명으로부터 3D 모델을 생성합니다. 이 노드는 프롬프트와 설정을 Tripo로 전송하고, 생성 작업이 완료될 때까지 기다린 후, 완성된 3D 파일을 작업 식별자와 함께 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 생성할 모델에 대한 텍스트 설명입니다. 비워 둘 수 없습니다. | STRING | 예 | 여러 줄 텍스트 |
| `네거티브 프롬프트` | 생성된 모델에 나타나지 않아야 할 내용을 설명하는 텍스트입니다. 최대 255자입니다. | STRING | 아니요 | 여러 줄 텍스트, 최대 255자 |
| `모델 버전` | 생성에 사용되는 Tripo 모델 버전입니다(기본값: `v3.1_20260211`). | COMBO | 아니요 | 지원되는 Tripo 모델 버전 목록 |
| `텍스처` | 텍스처 맵을 생성합니다. 끄면 순수 지오메트리를 반환하고 `pbr`을 무시합니다(기본값: True). | BOOLEAN | 아니요 | True<br />False |
| `pbr` | PBR 재질 맵(베이스 컬러, 메탈릭, 러프니스, 노멀)입니다. `texture`가 필요합니다(기본값: True). | BOOLEAN | 아니요 | True<br />False |
| `이미지 시드` | 이미지 생성용 시드 값입니다(기본값: 42). | INT | 아니요 | 0 ~ 2147483647 |
| `모델 시드` | 모델 생성용 시드 값입니다(기본값: 42). | INT | 아니요 | 0 ~ 2147483647 |
| `텍스처 시드` | 텍스처 생성용 시드 값입니다(기본값: 42). | INT | 아니요 | 0 ~ 2147483647 |
| `텍스처 품질` | 텍스처 세부 수준입니다(기본값: "standard"). "detailed" = HD 텍스처, "extreme" = 8K 울트라 텍스처. | COMBO | 아니요 | `"standard"`<br />`"detailed"`<br />`"extreme"` |
| `면 제한` | 최대 면 수입니다. -1은 Tripo가 적응적으로 선택하도록 합니다(v3.x standard에서 약 140만 면, detailed에서 200만 면). Tripo는 별도 알림 없이 제한합니다: v2.5는 500,000, 쿼드 메시는 150,000입니다(기본값: -1). | INT | 아니요 | -1 ~ 2000000 |
| `쿼드` | 쿼드 메시 출력입니다. Tripo는 쿼드 메시를 FBX로 제공하므로 결과가 FBX 출력으로 전달되고 GLB 출력은 비어 있게 됩니다(기본값: False). | BOOLEAN | 아니요 | True<br />False |
| `지오메트리 품질` | 지오메트리 세부 수준입니다(기본값: "standard"). | COMBO | 아니요 | `"standard"`<br />`"detailed"` |
| `스마트 로우 폴리` | 깔끔하고 수작업 스타일의 토폴로지를 가진 로우 폴리 메시입니다(500-20,000면, 쿼드 500-10,000). 단순한 피사체에 가장 적합하며, 복잡한 피사체는 실패할 수 있습니다(기본값: False). | BOOLEAN | 아니요 | True<br />False |
| `자동 크기` | 텍스처가 있는 모델을 실제 크기(미터)로 조정합니다. Tripo는 크기를 모델의 장면 변환으로 저장하고, 모델이 변환, 리깅 또는 리타게팅될 때 이를 반영합니다. 텍스처가 없으면 무시됩니다(기본값: True). | BOOLEAN | 아니요 | True<br />False |

### 참고 사항

- `prompt`는 필수이며 비어 있거나 공백만으로 이루어질 수 없습니다.
- `texture`가 False로 설정되면 `pbr`는 강제로 꺼지고, `auto_size`는 효과가 없습니다.
- `smart_low_poly`가 활성화되고 `face_limit`가 -1이 아니면, `face_limit`는 삼각형 메시의 경우 500에서 20,000 사이여야 하며, `quad`가 활성화된 경우 500에서 10,000 사이여야 합니다.
- `quad`가 활성화되면 Tripo는 FBX 파일을 반환하므로, `GLB` 출력은 비어 있고 `FBX` 출력이 채워집니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model task_id` | 모델을 생성한 Tripo 생성 작업의 식별자입니다. | MODEL_TASK_ID |
| `GLB` | GLB 형식으로 생성된 모델입니다. `quad`가 활성화되면 비어 있습니다. | FILE3D_GLB |
| `FBX` | FBX 형식으로 생성된 모델입니다. `quad`가 활성화된 경우에만 채워집니다. | FILE3D_FBX |
