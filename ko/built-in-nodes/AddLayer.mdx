Add Layer 노드는 입력 이미지를 레이어로 변환하여 캔버스에 배치합니다. 새 레이어 스택을 시작하거나 기존 레이어 스택에 추가할 수 있습니다. 레이어의 이름, 위치, 크기, 회전, 불투명도, 블렌드 모드, 스택 순서, 가로 또는 세로 뒤집기를 설정할 수 있습니다. 이 노드는 실험 단계로 표시됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `layers` | 추가할 레이어 스택입니다. 연결하지 않으면 새 스택이 시작됩니다. | LAYERS | 아니요 | — |
| `image` | 기본 크기의 레이어 콘텐츠입니다. 배치는 연속된 레이어로 확장됩니다. | IMAGE | 예 | — |
| `mask` | 이 레이어의 투명도 마스크입니다. 마스크된 영역(값 1)은 투명해지며, 이미지에 이미 포함된 알파 채널과 곱해집니다. | MASK | 아니요 | — |
| `name` | 합성 편집기에 표시되는 레이어 이름입니다. (기본값: "") | STRING | 아니요 | — |
| `x` | 캔버스에서 초기 가로 위치입니다. (기본값: 0) | INT | 아니요 | -MAX_RESOLUTION ~ MAX_RESOLUTION |
| `y` | 캔버스에서 초기 세로 위치입니다. (기본값: 0) | INT | 아니요 | -MAX_RESOLUTION ~ MAX_RESOLUTION |
| `opacity` | 초기 레이어 불투명도입니다. (기본값: 1.0) | FLOAT | 아니요 | 0.0 ~ 1.0 (단계 0.01) |
| `blend_mode` | 아래 레이어에 적용되는 초기 블렌드 모드입니다. 기본 투명 배경 위의 최하단 레이어에서는 normal이 아닌 모드가 투명도를 생성합니다. (기본값: "normal") | COMBO | 아니요 | 여러 옵션 사용 가능 |
| `rotation` | 시계 방향의 초기 회전 각도(도)입니다. (기본값: 0.0) | FLOAT | 아니요 | -360.0 ~ 360.0 (단계 1.0) |
| `width` | 초기 표시 너비입니다. 0이면 이미지의 기본 너비를 유지합니다. (기본값: 0) | INT | 아니요 | 0 ~ MAX_RESOLUTION |
| `height` | 초기 표시 높이입니다. 0이면 이미지의 기본 높이를 유지합니다. (기본값: 0) | INT | 아니요 | 0 ~ MAX_RESOLUTION |
| `z_index` | 스택 순서 재정의입니다. 레이어는 z_index 기준으로 안정 정렬되며, 동일한 값은 목록 순서를 유지합니다. (기본값: 0) | INT | 아니요 | -1000 ~ 1000 |
| `flip_h` | 레이어를 가로로 뒤집습니다. (기본값: False) | BOOLEAN | 아니요 | false / true |
| `flip_v` | 레이어를 세로로 뒤집습니다. (기본값: False) | BOOLEAN | 아니요 | false / true |

참고:
- `image`만 필수이며, 다른 모든 입력은 선택 사항입니다.
- `layers`를 연결하지 않으면 새 레이어 스택이 생성됩니다. 레이어 스택을 연결하면 새 레이어가 해당 스택에 추가됩니다.
- `image` 입력의 이미지 배치는 여러 개의 연속된 레이어를 생성합니다.
- `width`와 `height`는 기본값이 0이며, 이 경우 이미지의 기본 크기를 유지합니다. 0보다 큰 값은 표시 크기를 재정의합니다.
- `opacity`, `blend_mode`, `rotation`, `width`, `height`는 기본값과 다를 때만 적용됩니다.
- 연결된 레이어 스택의 캔버스 크기는 출력에서 유지됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `layers` | 이 레이어가 추가된 레이어 스택입니다. | LAYERS |
