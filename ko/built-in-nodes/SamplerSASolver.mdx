SamplerSASolver 노드는 확산 모델을 위한 사용자 정의 샘플링 알고리즘을 구현합니다. 이 노드는 예측-수정(predictor-corrector) 접근 방식과 구성 가능한 차수 설정 및 확률 미분 방정식(SDE) 매개변수를 사용하여 입력 모델에서 샘플을 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 샘플링에 사용할 확산 모델 | MODEL | 예 | - |
| `ETA` | 스텝 크기 스케일링 계수를 제어합니다 (기본값: 1.0) | FLOAT | 아니요 | 0.0 - 10.0 |
| `SDE 시작 백분율` | SDE 샘플링의 시작 백분율 (기본값: 0.2) | FLOAT | 아니요 | 0.0 - 1.0 |
| `SDE 종료 백분율` | SDE 샘플링의 종료 백분율 (기본값: 0.8) | FLOAT | 아니요 | 0.0 - 1.0 |
| `S 노이즈` | 샘플링 중 추가되는 노이즈의 양을 제어합니다 (기본값: 1.0) | FLOAT | 아니요 | 0.0 - 100.0 |
| `예측기 차수` | 솔버에서 예측자 구성 요소의 차수 (기본값: 3) | INT | 아니요 | 1 - 6 |
| `수정기 차수` | 솔버에서 수정자 구성 요소의 차수 (기본값: 4) | INT | 아니요 | 0 - 6 |
| `PECE 사용` | PECE(Predict-Evaluate-Correct-Evaluate) 방식을 활성화 또는 비활성화합니다 | BOOLEAN | 아니요 | - |
| `단순 2차` | 단순화된 2차 계산을 활성화 또는 비활성화합니다 | BOOLEAN | 아니요 | - |

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `sampler` | 확산 모델과 함께 사용할 수 있는 구성된 샘플러 객체 | SAMPLER |
