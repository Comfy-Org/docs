SamplerSASolver 노드는 diffusion 모델용 사용자 정의 샘플러를 생성하고 구성합니다. 구성 가능한 predictor-corrector 방식과 확률 미분 방정식(SDE) 설정과 함께 `"sa_solver"` 샘플링 알고리즘을 사용하며, 샘플링 노드에 연결할 수 있는 sampler 객체를 반환합니다. `sde_start_percent` 및 `sde_end_percent` 값은 연결된 모델의 샘플링 스케줄을 사용하여 sigma 값으로 변환되어, 확률적 구성 요소가 적용되는 구간을 정의합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 샘플러를 구성하는 데 그 샘플링 스케줄이 사용되는 diffusion 모델 | MODEL | 예 | - |
| `ETA` | SDE 솔버의 스텝 크기 스케일링 계수를 제어합니다 (기본값: 1.0) | FLOAT | 아니요 | 0.0 - 10.0 |
| `SDE 시작 백분율` | 확률적(SDE) 구성 요소가 시작되는 샘플링 과정의 시작 백분율입니다. 모델의 스케줄을 사용하여 sigma 값으로 변환됩니다 (기본값: 0.2) | FLOAT | 아니요 | 0.0 - 1.0 |
| `SDE 종료 백분율` | 확률적(SDE) 구성 요소가 중지되는 샘플링 과정의 종료 백분율입니다. 모델의 스케줄을 사용하여 sigma 값으로 변환됩니다 (기본값: 0.8) | FLOAT | 아니요 | 0.0 - 1.0 |
| `S 노이즈` | 샘플링 중 추가되는 노이즈의 양을 제어합니다 (기본값: 1.0) | FLOAT | 아니요 | 0.0 - 100.0 |
| `예측기 차수` | 솔버에서 predictor 구성 요소의 차수입니다 (기본값: 3) | INT | 아니요 | 1 - 6 |
| `수정기 차수` | 솔버에서 corrector 구성 요소의 차수입니다 (기본값: 4) | INT | 아니요 | 0 - 6 |
| `PECE 사용` | PECE(Predict-Evaluate-Correct-Evaluate) 방법을 활성화합니다 (기본값: 비활성화) | BOOLEAN | 아니요 | - |
| `단순 2차` | 단순화된 2차 계산을 활성화합니다 (기본값: 비활성화) | BOOLEAN | 아니요 | - |

모든 선택적 입력은 인터페이스에서 고급 항목으로 표시됩니다.

## 출력

| --- | --- | --- |
| `sampler` | 샘플링 노드에서 사용할 수 있는 구성된 샘플러 객체입니다 (`sa_solver` 알고리즘 사용) | SAMPLER |
