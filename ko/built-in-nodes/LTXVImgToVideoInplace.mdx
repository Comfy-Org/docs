LTXVImgToVideoInplace는 입력 이미지를 잠재 공간으로 인코딩하고, 인코딩된 프레임을 기존 잠재 비디오의 시작 부분에 배치합니다. `strength` 값은 인코딩된 이미지가 초기 프레임에 얼마나 강하게 조건을 부여하는지 제어하며, `bypass`가 활성화되면 입력 잠재 변수가 변경 없이 반환됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `vae` | 입력 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 | - |
| `이미지` | 인코딩되어 비디오 잠재 변수에 조건을 부여하는 데 사용되는 입력 이미지입니다. | IMAGE | 예 | - |
| `latent` | 수정할 대상 잠재 비디오 표현입니다. | LATENT | 예 | - |
| `강도` | 인코딩된 이미지가 잠재 변수의 초기 프레임에 얼마나 강하게 조건을 부여하는지 제어합니다. 값이 1.0이면 인코딩된 이미지로 초기 프레임에 완전히 조건을 부여하고, 값이 낮을수록 조건 부여 강도가 약해집니다. 초기 프레임의 노이즈 마스크는 `1.0 - strength`로 설정됩니다. (기본값: 1.0) | FLOAT | 아니요 | 0.0 - 1.0 |
| `우회` | 조건 부여를 우회합니다. 활성화되면 노드가 입력 잠재 변수를 변경 없이 반환합니다. (기본값: False) | BOOLEAN | 아니요 | True or False |

**참고:** `image`는 `latent` 입력의 너비와 높이를 기준으로 `vae` 인코딩에 필요한 공간 차원에 맞게 자동으로 크기가 조정됩니다. `image`의 RGB 채널만 인코딩에 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `latent` | 결과 잠재 비디오 표현입니다. bypass가 비활성화되면 업데이트된 `samples`와 초기 프레임에 조건 부여 강도를 적용하는 `noise_mask`를 포함합니다. bypass가 활성화되면 입력 잠재 변수가 변경 없이 반환됩니다. | LATENT |
