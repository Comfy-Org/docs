Grok Video 노드는 텍스트 설명을 기반으로 짧은 비디오를 생성합니다. 프롬프트를 사용하여 처음부터 비디오를 만들거나, 단일 입력 이미지에서 비디오를 생성할 수 있습니다. 이 노드는 외부 API로 요청을 보내고 생성된 비디오를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용할 모델입니다(기본값: `"grok-imagine-video-1.5-lite"`). | COMBO | 예 | `"grok-imagine-video"`<br />`"grok-imagine-video-1.5"`<br />`"grok-imagine-video-1.5-lite"` |
| `프롬프트` | 원하는 비디오에 대한 텍스트 설명입니다. 입력 이미지가 제공된 경우 `grok-imagine-video-1.5` 모델에서는 선택 사항입니다. | STRING | 예 | - |
| `해상도` | 출력 비디오의 해상도입니다. `1080p`는 `grok-imagine-video`에서 사용할 수 없습니다. | COMBO | 예 | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `종횡비` | 출력 비디오의 종횡비입니다. 입력 이미지가 제공되면 무시되며, 비디오는 이미지의 종횡비를 따릅니다. | COMBO | 예 | `"auto"`<br />`"16:9"`<br />`"4:3"`<br />`"3:2"`<br />`"1:1"`<br />`"2:3"`<br />`"3:4"`<br />`"9:16"` |
| `길이` | 출력 비디오의 길이(초)입니다(기본값: 6). | INT | 예 | 1~15 |
| `시드` | 노드를 다시 실행할지 결정하는 시드입니다. 실제 결과는 시드와 관계없이 비결정적입니다(기본값: 0). | INT | 예 | 0~2147483647 |
| `image` | 선택적 시작 이미지입니다. 생략하면 텍스트 프롬프트만으로 비디오가 생성됩니다. | IMAGE | 아니요 | - |

**참고:** `image`가 제공되면 입력 이미지는 하나만 지원하며, 여러 이미지를 제공하면 오류가 발생합니다. 이미지가 제공되지 않은 경우, 또는 이미지가 있더라도 `grok-imagine-video`를 사용하는 경우에는 `prompt`가 공백을 제거한 뒤 비어 있지 않아야 합니다. `grok-imagine-video-1.5` 모델에서는 입력 이미지가 제공된 경우에만 `prompt`가 선택 사항입니다. `1080p` 해상도는 `grok-imagine-video`에서 사용할 수 없습니다. `aspect_ratio`가 `"auto"`로 설정되면 서비스에서 종횡비를 자동으로 선택합니다. 입력 이미지가 제공되면 `aspect_ratio`는 무시되고 비디오는 이미지의 종횡비를 따릅니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오입니다. | VIDEO |
