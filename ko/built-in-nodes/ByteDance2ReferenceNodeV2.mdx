ByteDance Seedance 2.5 Reference to Video는 텍스트 프롬프트와 선택적 참조 이미지, 비디오, 오디오 또는 이전에 업로드한 라이브러리 자산의 안내를 받아 ByteDance Seedance 모델(Seedance 2.5, 2.0, 2.0 Fast, 2.0 Mini)을 사용하여 비디오를 생성, 편집 또는 연장합니다. 참조 자료를 업로드하고, 생성 작업을 제출한 뒤 완료될 때까지 기다리고, 완성된 비디오 파일을 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 모델 선택기입니다. Seedance 2.5는 최신 모델로 최대 30초 비디오와 mp4/mov 출력을 지원하고, Seedance 2.0은 최대 품질과 4k를 지원하며, Fast는 속도 최적화, Mini는 가장 빠르고 비용이 가장 낮은 생성에 사용됩니다. 모델을 선택하면 아래에 표시되는 입력 위젯이 변경됩니다. | DYNAMIC_COMBO | 예 | "Seedance 2.5"<br />"Seedance 2.0"<br />"Seedance 2.0 Fast"<br />"Seedance 2.0 Mini" |
| `시드` | `seed`는 노드의 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 0. | INT | 예 | 0  ~  2147483647 |
| `워터마크` | 비디오에 워터마크를 추가할지 여부입니다. 기본값: False. 고급 설정. | BOOLEAN | 예 | true<br />false |

### Seedance 2.5 입력

이 입력은 `model`이 "Seedance 2.5"로 설정된 경우 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 생성되는 대사를 유도하려면 말하는 대사를 큰따옴표로 묶으세요. 기본값: 빈 문자열. | STRING | 예 | 여러 줄 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. 기본값: 720p. | COMBO | 예 | "480p"<br />"720p"<br />"1080p" |
| `ratio` | 출력 비디오의 화면 비율입니다. 기본값: 16:9. | COMBO | 예 | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9"<br />"adaptive" |
| `duration` | 출력 비디오의 길이(초)입니다(4-30). 기본값: 5. | INT | 예 | 4  ~  30 |
| `generate_audio` | 출력 비디오의 오디오 생성을 활성화합니다. 기본값: True. | BOOLEAN | 예 | true<br />false |
| `task_type` | 참조 미디어로 무엇을 할지 지정합니다. auto를 제외한 모든 값은 작업 제출 시 검증되므로, 설정이 맞지 않으면 생성이 시작되기 전에 실패합니다.<br />auto: 모델이 프롬프트와 입력을 바탕으로 작업을 추론하며, 모델의 해석과 충돌하는 설정은 생성이 시작된 후에만 실패합니다.<br />reference: 참조 이미지, 비디오, 오디오를 안내로 삼아 새 비디오를 생성합니다.<br />edit: 연결된 참조 비디오를 변경합니다(추가, 제거, 교체). 출력은 원본 클립의 길이와 화면 비율을 유지하며, `duration` 및 `ratio` 위젯은 무시됩니다.<br />extend: 연결된 참조 비디오를 앞 또는 뒤로 연장합니다. 프롬프트에 "extend forward", "extend backward" 또는 "continue"라고 적어야 하며, 화면 비율은 원본 클립을 따르고, 출력에는 설정한 길이의 새로 생성된 부분만 포함되고 원본 클립은 포함되지 않습니다. 기본값: auto. | COMBO | 예 | "auto"<br />"reference"<br />"edit"<br />"extend" |
| `output_format` | 출력 비디오의 컨테이너 형식입니다. 기본값: mp4. | COMBO | 예 | "mp4" |

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |

| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | "480p"<br />"720p"<br />"1080p"<br />"4k" |
| `ratio` | 출력 비디오의 화면 비율입니다. 기본값: adaptive. | COMBO | 예 | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9"<br />"adaptive" |

### Seedance 2.0 Fast 및 Seedance 2.0 Mini 입력

이 입력은 `model`이 "Seedance 2.0 Fast" 또는 "Seedance 2.0 Mini"로 설정된 경우 나타납니다. 두 모델은 동일한 입력 세트를 공유합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 기본값: 빈 문자열. | STRING | 예 | 여러 줄 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | "480p"<br />"720p" |
| `ratio` | 출력 비디오의 화면 비율입니다. 기본값: adaptive. | COMBO | 예 | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9"<br />"adaptive" |
| `duration` | 출력 비디오의 길이(초)입니다(4-15). 기본값: 7. | INT | 예 | 4  ~  15 |
| `generate_audio` | 출력 비디오의 오디오 생성을 활성화합니다. 기본값: True. | BOOLEAN | 예 | true<br />false |

### 참조 입력

이러한 확장 가능한 참조 슬롯은 모든 모델에서 사용할 수 있습니다. 최대 슬롯 수는 모델마다 다릅니다. Seedance 2.5는 최대 30개의 이미지, 10개의 비디오, 10개의 오디오, 30개의 자산을 지원하고, Seedance 2.0, 2.0 Fast, 2.0 Mini는 최대 9개의 이미지, 3개의 비디오, 3개의 오디오, 9개의 자산을 지원합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 확장 가능한 슬롯: 출력을 안내하는 1..N개의 참조 이미지를 연결합니다. 개수 제한은 모델마다 다릅니다(모델 섹션 참조). 이미지는 화면 비율(0.4~2.5)이 검증되며 최대 변 길이 6000픽셀로 자동 축소됩니다. | IMAGE | 아니오 | 1..9개 슬롯(Seedance 2.0 계열)<br />1..30개 슬롯(Seedance 2.5) |
| `reference_videos` | 확장 가능한 슬롯: 1..N개의 참조 비디오를 연결합니다. 개수 제한은 모델마다 다릅니다(모델 섹션 참조). 각 비디오는 최소 1.8초 이상이어야 하며 선택한 모델과 해상도의 픽셀 제한에 맞아야 합니다. | VIDEO | 아니오 | 1..3개 슬롯(Seedance 2.0 계열)<br />1..10개 슬롯(Seedance 2.5) |
| `reference_audios` | 확장 가능한 슬롯: 1..N개의 참조 오디오 트랙을 연결합니다. 개수 제한은 모델마다 다릅니다(모델 섹션 참조). 각 오디오는 최소 1.8초 이상이어야 합니다. | AUDIO | 아니오 | 1..3개 슬롯(Seedance 2.0 계열)<br />1..10개 슬롯(Seedance 2.5) |
| `reference_assets` | 확장 가능한 슬롯: Seedance 가상 라이브러리에 이미 업로드된 미디어의 자산 ID 문자열을 1..N개 연결합니다. 각 자산은 Active 상태여야 합니다. 프롬프트에서 `asset1` 또는 `asset 1`과 같은 토큰으로 자산을 참조할 수 있으며, 노드는 이를 해당 자산의 위치 레이블(예: "Image 2" 또는 "Video 1")로 바꿉니다. | STRING | 아니오 | 1..9개 슬롯(Seedance 2.0 계열)<br />1..30개 슬롯(Seedance 2.5) |
| `auto_downscale` | 선택한 해상도에 대한 모델의 픽셀 예산을 초과하는 참조 비디오를 자동으로 축소합니다. 화면 비율은 유지되며, 이미 제한 범위 내에 있는 비디오는 그대로 둡니다. 기본값: True. | BOOLEAN | 아니오 | true<br />false |
| `auto_upscale` | 선택한 해상도에 대한 모델의 최소 픽셀 수보다 낮은 참조 비디오를 자동으로 업스케일합니다. 화면 비율은 유지되며, 이미 최소 기준을 충족하는 비디오는 그대로 둡니다. 참고: 저해상도 소스를 업스케일해도 실제 디테일이 추가되지는 않으며 품질이 낮은 생성 결과가 나올 수 있습니다. 기본값: False. 고급 설정. | BOOLEAN | 아니오 | true<br />false |

**참고:** 노드를 실행하려면 최소 하나의 참조 이미지, 비디오 또는 자산이 필요합니다(Seedance 2.5는 오디오만 있는 참조도 허용합니다). 참조 비디오와 오디오는 각각 최소 1.8초 이상이어야 하며, 모든 참조 비디오의 총 길이(그리고 별도로 모든 참조 오디오의 총 길이)는 선택한 모델의 최대 총 초 수를 초과해서는 안 됩니다. 참조 이미지는 화면 비율이 대략 2:5에서 5:2 사이(0.4~2.5)여야 하고, 최소 300x300픽셀이어야 하며, 최대 변 길이 6000픽셀로 자동 축소됩니다. `task_type`의 "edit" 및 "extend" 옵션은 Seedance 2.5에서만 사용할 수 있으며 둘 다 최소 하나의 참조 비디오가 필요합니다. "edit"를 사용하면 출력은 원본 클립의 길이와 화면 비율을 유지하고 `duration` 및 `ratio` 위젯은 무시됩니다. "extend"를 사용하면 출력에는 설정한 길이의 새로 생성된 부분만 포함됩니다. 참조된 자산은 Active 상태여야 하며, 그렇지 않으면 작업이 실패합니다.
