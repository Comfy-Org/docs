## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 모델 선택기. Seedance 2.5는 최신 모델로 최대 30초 비디오와 mp4/mov 출력을 지원합니다. Seedance 2.0은 최고 품질과 4K를 지원합니다. Fast는 속도 최적화를 위한 모델입니다. Mini는 가장 빠르고 저렴한 생성 모델입니다. 모델을 선택하면 아래에 표시되는 입력 위젯이 변경됩니다. | DYNAMIC_COMBO | 예 | "Seedance 2.5"<br />"Seedance 2.0"<br />"Seedance 2.0 Fast"<br />"Seedance 2.0 Mini" |
| `시드` | 시드는 노드가 재실행되어야 하는지 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. 기본값: 0. | INT | 예 | 0 ~ 2147483647 |
| `워터마크` | 비디오에 워터마크를 추가할지 여부입니다. 기본값: False. 고급 설정입니다. | BOOLEAN | 예 | true<br />false |

### Seedance 2.5 입력

이 입력은 `model`이 "Seedance 2.5"로 설정된 경우 나타납니다.

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 생성되는 대화를 유도하려면 대사를 큰따옴표로 묶으세요. 기본값: 빈 문자열. | STRING | 예 | 여러 줄 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. 기본값: 720p. | COMBO | 예 | "480p"<br />"720p"<br />"1080p" |
| `ratio` | 출력 비디오의 종횡비입니다. 기본값: 16:9. | COMBO | 예 | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9"<br />"adaptive" |
| `duration` | 출력 비디오의 길이(초)입니다 (4~30). 기본값: 5. | INT | 예 | 4 ~ 30 |
| `generate_audio` | 출력 비디오에 오디오 생성을 활성화합니다. 기본값: True. | BOOLEAN | 예 | true<br />false |
| `task_type` | 참조 미디어로 무엇을 할지 결정합니다. auto를 제외한 모든 값은 작업 제출 시 검증되므로, 불일치하는 설정은 생성이 시작되기 전에 실패합니다.<br />auto: 모델이 프롬프트와 입력에서 작업을 추론하며, 해당 해석과 충돌하는 설정은 생성이 시작된 후에만 실패합니다.<br />reference: 참조 이미지, 비디오, 오디오를 기반으로 새 비디오를 생성합니다.<br />edit: 연결된 참조 비디오를 변경합니다(추가, 제거, 교체). 출력은 소스 클립의 원래 길이와 종횡비를 유지하며, `duration` 및 `ratio` 위젯은 무시됩니다.<br />extend: 연결된 참조 비디오를 앞뒤로 연장합니다. 프롬프트에 "extend forward", "extend backward" 또는 "continue"라고 입력해야 하며, 종횡비는 소스 클립을 따릅니다. 출력에는 설정한 길이만큼 새로 생성된 구간만 포함되며 소스 클립은 포함되지 않습니다. 기본값: auto. | COMBO | 예 | "auto"<br />"reference"<br />"edit"<br />"extend" |
| `output_format` | 출력 비디오의 컨테이너 형식입니다. 기본값: mp4. | COMBO | 예 | "mp4" |

### Seedance 2.0 Fast 및 Seedance 2.0 Mini 입력

이 입력은 `model`이 "Seedance 2.0 Fast" 또는 "Seedance 2.0 Mini"로 설정된 경우 나타납니다. 두 모델은 동일한 입력 세트를 공유합니다.

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 기본값: 빈 문자열. | STRING | 예 | 여러 줄 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | "480p"<br />"720p" |
| `ratio` | 출력 비디오의 종횡비입니다. 기본값: adaptive. | COMBO | 예 | "16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16"<br />"21:9"<br />"adaptive" |
| `duration` | 출력 비디오의 길이(초)입니다 (4~15). 기본값: 7. | INT | 예 | 4 ~ 15 |
| `generate_audio` | 출력 비디오에 오디오 생성을 활성화합니다. 기본값: True. | BOOLEAN | 예 | true<br />false |

### 참조 입력

이 확장 가능한 참조 슬롯은 모든 모델에서 사용할 수 있습니다. 최대 슬롯 수는 모델마다 다릅니다. Seedance 2.5는 최대 30개의 이미지, 10개의 비디오, 10개의 오디오, 30개의 에셋을 지원하며, Seedance 2.0, 2.0 Fast, 2.0 Mini는 최대 9개의 이미지, 3개의 비디오, 3개의 오디오, 9개의 에셋을 지원합니다.

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 확장 가능한 슬롯: 출력을 안내하는 참조 이미지 1..N개를 연결합니다. 개수 제한은 모델별로 적용됩니다(모델 섹션 참조). 이미지는 종횡비(0.4~2.5)가 검증되며, 최대 변의 길이가 6000픽셀 이하로 자동 다운스케일됩니다. | IMAGE | 아니요 | 1..9 슬롯 (Seedance 2.0 계열)<br />1..30 슬롯 (Seedance 2.5) |
| `reference_videos` | 확장 가능한 슬롯: 참조 비디오 1..N개를 연결합니다. 개수 제한은 모델별로 적용됩니다(모델 섹션 참조). 각 비디오는 최소 1.8초 이상이어야 하며 선택한 모델과 해상도에 맞는 픽셀 한도를 충족해야 합니다. | VIDEO | 아니요 | 1..3 슬롯 (Seedance 2.0 계열)<br />1..10 슬롯 (Seedance 2.5) |
| `reference_audios` | 확장 가능한 슬롯: 참조 오디오 트랙 1..N개를 연결합니다. 개수 제한은 모델별로 적용됩니다(모델 섹션 참조). 각 오디오는 최소 1.8초 이상이어야 합니다. | AUDIO | 아니요 | 1..3 슬롯 (Seedance 2.0 계열)<br />1..10 슬롯 (Seedance 2.5) |
| `reference_assets` | 확장 가능한 슬롯: Seedance 가상 라이브러리에 이미 업로드된 미디어의 에셋 ID 문자열 1..N개를 연결합니다. 각 에셋은 Active 상태여야 합니다. 프롬프트에서 `asset1` 또는 `asset 1` 같은 토큰으로 에셋을 참조할 수 있습니다. 노드는 이를 에셋의 위치 레이블(예: "Image 2" 또는 "Video 1")로 대체합니다. | STRING | 아니요 | 1..9 슬롯 (Seedance 2.0 계열)<br />1..30 슬롯 (Seedance 2.5) |
| `auto_downscale` | 선택한 해상도에 대해 모델의 픽셀 한도를 초과하는 참조 비디오를 자동으로 다운스케일합니다. 종횡비는 유지되며, 이미 한도 내에 있는 비디오는 변경되지 않습니다. 기본값: True. | BOOLEAN | 아니요 | true<br />false |
| `auto_upscale` | 선택한 해상도에 대해 모델의 최소 픽셀 수보다 낮은 참조 비디오를 자동으로 업스케일합니다. 종횡비는 유지되며, 이미 최소 기준을 충족하는 비디오는 변경되지 않습니다. 참고: 저해상도 소스를 업스케일해도 실제 디테일이 추가되지는 않으며, 더 낮은 품질의 생성 결과가 나올 수 있습니다. 기본값: False. 고급 설정입니다. | BOOLEAN | 아니요 | true<br />false |

**참고:** 노드를 실행하려면 참조 이미지, 비디오 또는 에셋이 하나 이상 필요합니다(Seedance 2.5는 오디오 전용 참조도 허용합니다). 참조 비디오와 오디오는 각각 최소 1.8초 이상이어야 하며, 모든 참조 비디오의 총 길이(및 별도로 모든 참조 오디오의 총 길이)는 선택한 모델의 최대 총 시간을 초과할 수 없습니다. 참조 이미지의 종횡비는 대략 2:5 ~ 5:2(0.4~2.5) 사이여야 하고, 최소 300x300픽셀 이상이어야 하며, 최대 변의 길이가 6000픽셀 이하로 자동 다운스케일됩니다. `task_type`의 "edit" 및 "extend" 옵션은 Seedance 2.5에서만 사용할 수 있으며, 두 옵션 모두 참조 비디오가 하나 이상 필요합니다. "edit"를 사용하면 출력이 소스 클립의 원래 길이와 종횡비를 유지하고 `duration` 및 `ratio` 위젯은 무시됩니다. "extend"를 사용하면 출력에는 설정한 길이만큼 새로 생성된 구간만 포함됩니다. 참조된 에셋은 Active 상태여야 하며, 그렇지 않으면 작업이 실패합니다.
