배경 제거 모델을 파일에서 불러옵니다. 이 노드는 이미지에서 배경을 제거하는 작업에 사용할 수 있도록 모델을 준비합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `bg_removal_name` | 이미지에서 배경을 제거하는 데 사용되는 모델입니다. 사용 가능한 배경 제거 모델 파일 목록에서 선택하십시오. | COMBO | 예 | 사용 가능한 모델 파일 목록(알파벳순 정렬) |

참고: 선택한 파일에 유효한 배경 제거 모델이 포함되어 있지 않으면 노드가 RuntimeError를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `bg_model` | 로드된 배경 제거 모델로, 다른 노드가 이미지를 처리하는 데 사용할 준비가 된 상태입니다. | BACKGROUND_REMOVAL |
