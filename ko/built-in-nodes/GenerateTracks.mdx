`GenerateTracks` 노드는 비디오 생성을 위한 여러 개의 평행 이동 경로(트랙)를 생성합니다. 시작 위치에서 끝 위치까지의 기본 경로를 정의한 다음, 이 경로와 평행하게 일정한 간격으로 배치된 트랙 집합을 생성합니다. 경로의 형태(직선 또는 베지어 곡선), 이동 속도, 트랙이 표시되는 프레임을 제어할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `width` | 비디오 프레임의 픽셀 단위 너비입니다. 기본값은 832입니다. | INT | 예 | 16 - 4096 |
| `height` | 비디오 프레임의 픽셀 단위 높이입니다. 기본값은 480입니다. | INT | 예 | 16 - 4096 |
| `start_x` | 시작 위치의 정규화된 X 좌표(0-1)입니다. 기본값은 0.0입니다. | FLOAT | 예 | 0.0 - 1.0 |
| `start_y` | 시작 위치의 정규화된 Y 좌표(0-1)입니다. 기본값은 0.0입니다. | FLOAT | 예 | 0.0 - 1.0 |
| `end_x` | 끝 위치의 정규화된 X 좌표(0-1)입니다. 기본값은 1.0입니다. | FLOAT | 예 | 0.0 - 1.0 |
| `end_y` | 끝 위치의 정규화된 Y 좌표(0-1)입니다. 기본값은 1.0입니다. | FLOAT | 예 | 0.0 - 1.0 |
| `num_frames` | 트랙 위치를 생성할 총 프레임 수입니다. 기본값은 81입니다. | INT | 예 | 1 - 1024 |
| `num_tracks` | 생성할 평행 트랙의 수입니다. 기본값은 5입니다. | INT | 예 | 1 - 100 |
| `track_spread` | 트랙 사이의 정규화된 거리입니다. 트랙은 이동 방향에 수직으로 퍼집니다. 기본값은 0.025입니다. | FLOAT | 예 | 0.0 - 1.0 |
| `bezier` | 중간 지점을 제어점으로 사용하는 베지어 곡선 경로를 활성화합니다. 기본값은 False입니다. | BOOLEAN | 예 | True / False |
| `mid_x` | 베지어 곡선의 정규화된 X 제어점입니다. `bezier`가 활성화된 경우에만 사용됩니다. 기본값은 0.5입니다. | FLOAT | 예 | 0.0 - 1.0 |
| `mid_y` | 베지어 곡선의 정규화된 Y 제어점입니다. `bezier`가 활성화된 경우에만 사용됩니다. 기본값은 0.5입니다. | FLOAT | 예 | 0.0 - 1.0 |
| `interpolation` | 경로를 따른 이동의 타이밍/속도를 제어합니다 (기본값: "linear"):<br />"linear" - 일정한 속도<br />"ease_in" - 느리게 시작하고 빨라짐<br />"ease_out" - 빠르게 시작하고 느려짐<br />"ease_in_out" - 부드러운 가속과 감속<br />"constant" - 모든 위치를 시작 지점에 유지 | COMBO | 예 | `"linear"`<br />`"ease_in"`<br />`"ease_out"`<br />`"ease_in_out"`<br />`"constant"` |
| `track_mask` | 표시 가능한 프레임을 나타내는 선택적 마스크입니다. 제공된 경우 마스크에 0이 아닌 픽셀이 있는 프레임은 모든 트랙에 대해 표시 가능한 것으로 표시됩니다. | MASK | 아니오 | - |

**참고:** `mid_x` 및 `mid_y` 매개변수는 `bezier` 매개변수가 `True`로 설정된 경우에만 사용됩니다. `bezier`가 `False`이면 경로는 시작점에서 끝점까지의 직선입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `TRACKS` | 생성된 경로 좌표와 모든 트랙의 모든 프레임에 대한 가시성 정보를 포함하는 트랙 객체입니다. | TRACKS |
| `track_length` | 트랙이 생성된 프레임 수로, 입력 `num_frames`와 일치합니다. | INT |
