텍스트 설명으로부터 완전하고 이음새 없이 타일링되는 PBR 머티리얼을 생성합니다. 기본 텍스처와 최대 5개의 머티리얼 맵을 만들며, 선택적으로 맵에 SeedVR 업스케일링을 적용할 수 있습니다. 입력 이미지를 사용하면 결과를 image-to-image 패스로 이끌 수 있고, 마스크가 있는 입력 이미지는 inpaint 패스로 전환합니다. 실제 머티리얼을 스캔하지 않고도 게임용 또는 3D용 표면을 제작할 때 사용하세요.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성할 머티리얼 또는 텍스처에 대한 설명입니다. | STRING | 예 | Multiline text |
| `image_size` | 출력 텍스처 크기입니다. `"custom"`을 선택하면 `width` 및 `height` 입력이 나타납니다. 기본값: `"1:1 (1024x1024)"`. | DYNAMIC_COMBO | 예 | `"1:1 (1024x1024)"`<br />`"1:1 (512x512)"`<br />`"4:3 (1024x768)"`<br />`"3:4 (768x1024)"`<br />`"16:9 (1024x576)"`<br />`"9:16 (576x1024)"`<br />`"custom"` |
| `basecolor` | basecolor(albedo) 맵을 생성합니다. 기본값: True. | BOOLEAN | 예 | true<br />false |
| `normal` | normal 맵을 생성합니다. 기본값: True. | BOOLEAN | 예 | true<br />false |
| `roughness` | roughness 맵을 생성합니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `metalness` | metalness 맵을 생성합니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `height` | height(displacement) 맵을 생성합니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `upscale_factor` | PBR 맵에 이음새 없는 SeedVR 업스케일링을 적용합니다. 기본 텍스처는 업스케일되지 않으며, 4x는 2048픽셀 맵을 8K로 만듭니다. 기본값: 0(꺼짐). | INT | 예 | 0  ~  4 (단계: 2) |
| `seed` | 재현 가능한 생성을 위한 시드입니다. 기본값: 42. | INT | 예 | 0  ~  2147483646 |
| `tiling_mode` | 타일링 방향: 전방향, 수평 또는 수직입니다. 고급 설정입니다. 기본값: `"both"`. | COMBO | 예 | `"both"`<br />`"horizontal"`<br />`"vertical"` |
| `num_inference_steps` | 텍스처 생성을 위한 디노이징 단계 수입니다. 고급 설정입니다. 기본값: 8. | INT | 예 | 1  ~  8 |
| `tile_size` | 잠재 공간에서의 타일 크기이며, 64는 512픽셀, 128은 1024픽셀을 의미합니다. 고급 설정입니다. 기본값: 128. | INT | 예 | 32  ~  256 (단계: 2) |
| `tile_stride` | 잠재 공간에서의 타일 스트라이드입니다. 고급 설정입니다. 기본값: 64. | INT | 예 | 16  ~  128 (단계: 2) |
| `image` | 선택적 소스 이미지입니다. 단독으로 사용하면 image-to-image를 실행하고, 마스크와 함께 사용하면 inpaint 패스를 실행합니다. | IMAGE | 아니요 | - |
| `mask` | 선택적 inpaint 마스크이며, 입력 이미지가 필요합니다. 흰색 영역은 재생성되고 검은색 영역은 유지됩니다. | MASK | 아니요 | - |
| `strength` | 입력 이미지를 얼마나 변형할지 지정합니다. 이미지가 연결된 경우에만 사용됩니다. 고급 설정입니다. 기본값: 0.6. | FLOAT | 예 | 0.01  ~  1.0 (단계: 0.01) |
| `prompt_expansion` | 더 풍부한 텍스처 디테일을 위해 언어 모델로 프롬프트를 확장합니다. 확장은 프롬프트를 사진으로 재구성하고 metalness 맵을 흐릿하게 만드는 경향이 있으므로 기본적으로 꺼져 있습니다. 고급 설정입니다. | BOOLEAN | 예 | true<br />false |
| `safety_checker` | 요청에 대해 제공자의 콘텐츠 안전 검사를 실행합니다. 고급 설정입니다. 기본값: False. | BOOLEAN | 예 | true<br />false |

### 사용자 지정 이미지 크기 입력

이 입력은 `image_size`가 `"custom"`으로 설정된 경우 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | 픽셀 단위의 텍스처 너비입니다. 기본값: 1024. | INT | 예 | 512  ~  2048 (단계: 16) |
| `image_size.height` | 픽셀 단위의 텍스처 높이입니다. 기본값: 1024. | INT | 예 | 512  ~  2048 (단계: 16) |

**제약 사항 및 동작:**

* 머티리얼 맵을 하나도 활성화하지 않는 것이 허용됩니다. 이 경우 노드는 기본 텍스처만 반환하며, 모든 맵 출력은 1x1 플레이스홀더로 유지됩니다.
* 마스크에는 입력 이미지가 필요합니다. 마스크만 단독으로 제공하면 오류가 발생합니다.
* 8K 결과는 단일 8K 생성이 아니라 2048픽셀 렌더의 맵을 4배 업스케일링하여 얻습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `texture` | 맵이 적용되지 않은 머티리얼의 기본 텍스처입니다. | IMAGE |
| `basecolor` | basecolor(albedo) 맵이며, 해당 맵이 비활성화된 경우 1x1 플레이스홀더입니다. | IMAGE |
| `normal` | normal 맵이며, 해당 맵이 비활성화된 경우 1x1 플레이스홀더입니다. | IMAGE |
| `roughness` | roughness 맵이며, 해당 맵이 비활성화된 경우 1x1 플레이스홀더입니다. | IMAGE |
| `metalness` | metalness 맵이며, 해당 맵이 비활성화된 경우 1x1 플레이스홀더입니다. | IMAGE |
| `height` | height(displacement) 맵이며, 해당 맵이 비활성화된 경우 1x1 플레이스홀더입니다. | IMAGE |
| `expanded_prompt` | 제공자가 실제로 사용한 프롬프트입니다. `prompt_expansion`이 활성화된 경우에만 입력과 달라집니다. | STRING |
