텍스트 설명으로부터 완전하고 이음새 없이 타일링되는 PBR 머티리얼을 생성합니다. 여기에는 기본 텍스처와 최대 5개의 머티리얼 맵이 포함되며, 선택적으로 해당 맵을 SeedVR로 업스케일링할 수 있습니다. 입력 이미지는 이미지 투 이미지 패스로 결과를 이끌 수 있으며, 마스크가 있는 입력 이미지는 인페인트 패스로 전환합니다. 실제 머티리얼을 스캔하지 않고도 게임용 또는 3D용 표면을 제작할 때 사용하십시오.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성할 머티리얼 또는 텍스처에 대한 설명입니다. | STRING | 예 | 여러 줄 텍스트 |
| `image_size` | 출력 텍스처 크기입니다. `"custom"`을 선택하면 `width` 및 `height` 입력이 표시됩니다. 기본값: `"1:1 (1024x1024)"`. | DYNAMIC_COMBO | 예 | `"1:1 (1024x1024)"`<br />`"1:1 (512x512)"`<br />`"4:3 (1024x768)"`<br />`"3:4 (768x1024)"`<br />`"16:9 (1024x576)"`<br />`"9:16 (576x1024)"`<br />`"custom"` |
| `basecolor` | 베이스컬러(알베도) 맵을 생성합니다. 기본값: True. | BOOLEAN | 예 | true<br />false |
| `normal` | 노멀 맵을 생성합니다. 기본값: True. | BOOLEAN | 예 | true<br />false |
| `roughness` | 러프니스 맵을 생성합니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `metalness` | 메탈니스 맵을 생성합니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `height` | 높이(변위) 맵을 생성합니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `upscale_factor` | PBR 맵의 이음새 없는 SeedVR 업스케일링입니다. 기본 텍스처는 업스케일되지 않으며, 4배 설정 시 2048픽셀 맵을 8K 맵으로 만듭니다. 기본값: 0(꺼짐). | INT | 예 | 0 ~ 4 (단계: 2) |
| `seed` | 재현 가능한 생성을 위한 시드입니다. 기본값: 42. | INT | 예 | 0 ~ 2147483646 |
| `tiling_mode` | 타일링 방향: 전방향, 수평 또는 수직입니다. 고급 설정입니다. 기본값: `"both"`. | COMBO | 예 | `"both"`<br />`"horizontal"`<br />`"vertical"` |
| `num_inference_steps` | 텍스처 생성을 위한 디노이징 단계 수입니다. 고급 설정입니다. 기본값: 8. | INT | 예 | 1 ~ 8 |
| `tile_size` | 잠재 공간에서의 타일 크기이며, 64는 512픽셀, 128은 1024픽셀을 의미합니다. 고급 설정입니다. 기본값: 128. | INT | 예 | 32 ~ 256 (단계: 2) |
| `tile_stride` | 잠재 공간에서의 타일 스트라이드입니다. 고급 설정입니다. 기본값: 64. | INT | 예 | 16 ~ 128 (단계: 2) |
| `image` | 선택적 소스 이미지입니다. 단독으로 사용하면 이미지 투 이미지로 실행되며, 마스크와 함께 사용하면 인페인트 패스로 실행됩니다. | IMAGE | 아니요 | - |
| `mask` | 선택적 인페인트 마스크이며, 입력 이미지가 필요합니다. 흰색 영역은 다시 생성되고 검은색 영역은 유지됩니다. | MASK | 아니요 | - |
| `strength` | 입력 이미지를 얼마나 변환할지 지정합니다. 이미지가 연결된 경우에만 사용됩니다. 고급 설정입니다. 기본값: 0.6. | FLOAT | 예 | 0.01 ~ 1.0 (단계: 0.01) |
| `prompt_expansion` | 더 풍부한 텍스처 디테일을 위해 언어 모델로 프롬프트를 확장합니다. 확장은 프롬프트를 사진으로 재구성하여 메탈니스 맵을 흐리게 만드는 경향이 있으므로 기본값은 꺼져 있습니다. 고급 설정입니다. | BOOLEAN | 예 | true<br />false |
| `safety_checker` | 요청에 대해 공급자의 콘텐츠 안전 검사를 실행합니다. 고급 설정입니다. 기본값: False. | BOOLEAN | 예 | true<br />false |

### custom 이미지 크기 입력

이 입력은 `image_size`가 `"custom"`으로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | 텍스처 너비(픽셀)입니다. 기본값: 1024. | INT | 예 | 512 ~ 2048 (단계: 16) |
| `image_size.height` | 텍스처 높이(픽셀)입니다. 기본값: 1024. | INT | 예 | 512 ~ 2048 (단계: 16) |

**제약 사항 및 동작:**

* 최소 하나의 머티리얼 맵이 활성화되어야 하며, 그렇지 않으면 실행이 실패합니다.
* 마스크를 사용하려면 입력 이미지가 필요하며, 마스크만 단독으로 제공하면 오류가 발생합니다.
* 8K 결과는 단일 8K 생성이 아니라 2048픽셀 렌더의 맵을 4배 업스케일링하여 만들어집니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `texture` | 머티리얼의 기본 텍스처로, 어떤 맵도 적용되지 않은 상태입니다. | IMAGE |
| `basecolor` | 베이스컬러(알베도) 맵이며, 해당 맵이 비활성화된 경우 1x1 플레이스홀더입니다. | IMAGE |
| `normal` | 노멀 맵이며, 해당 맵이 비활성화된 경우 1x1 플레이스홀더입니다. | IMAGE |
| `roughness` | 러프니스 맵이며, 해당 맵이 비활성화된 경우 1x1 플레이스홀더입니다. | IMAGE |
| `metalness` | 메탈니스 맵이며, 해당 맵이 비활성화된 경우 1x1 플레이스홀더입니다. | IMAGE |
| `height` | 높이(변위) 맵이며, 해당 맵이 비활성화된 경우 1x1 플레이스홀더입니다. | IMAGE |
| `expanded_prompt` | 공급자가 실제로 사용한 프롬프트이며, `prompt_expansion`이 활성화된 경우에만 입력과 달라집니다. | STRING |
