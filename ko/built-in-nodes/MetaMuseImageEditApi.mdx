텍스트 프롬프트와 Meta의 Muse Image 모델을 사용하여 최대 10개의 참조 이미지를 편집하거나 결합합니다. 프롬프트에 원하는 편집 내용을 설명하고, 필요할 때 참조 이미지를 `@Image1`, `@Image2` 등으로 참조합니다. 이 노드는 참조 이미지를 업로드하고, Meta Muse Image API를 호출하며, 편집된 결과를 이미지로 반환합니다.

## 입력

이 노드는 `model` 선택기로 제어됩니다. 아래에 설명된 모델별 입력은 모델을 선택할 때 나타나며, 연결한 참조 이미지는 필요에 따라 늘리거나 줄일 수 있습니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 사용할 모델입니다. | DYNAMIC_COMBO | 예 | "muse-image-1.0" |

### muse-image-1.0 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 편집 지침입니다. 입력 이미지에 대해 `@Image1` 형식의 참조를 지원합니다. 기본값: 빈 문자열. 프롬프트는 최소 한 글자 이상이어야 합니다. | STRING | 예 | 최소 길이 1자인 임의의 텍스트 |
| `aspect_ratio` | 출력의 가로세로 비율입니다. 이미지는 약 2.5메가픽셀로 렌더링됩니다(1:1은 1600x1600, 16:9는 2048x1152). "auto"는 입력의 가로세로 비율을 유지합니다. | COMBO | 예 | "auto"<br />"1:1"<br />"3:2"<br />"2:3"<br />"4:3"<br />"3:4"<br />"5:4"<br />"4:5"<br />"16:9"<br />"9:16"<br />"21:9"<br />"9:21"<br />"2:1"<br />"1:2" |
| `reasoning_strength` | 렌더링 전에 모델이 얼마나 생각하고 계획하며 스스로 개선하는지를 나타냅니다. | COMBO | 예 | "high"<br />"low" |
| `enable_web_search` | 이미지를 계획하는 동안 모델이 사실과 실시간 정보를 웹에서 검색할 수 있게 합니다. 기본값: true. | BOOLEAN | 예 | true 또는 false (기본값: true) |
| `enable_image_search` | 이미지를 계획하는 동안 모델이 참조 이미지를 검색할 수 있게 합니다. 기본값: true. | BOOLEAN | 예 | true 또는 false (기본값: true) |
| `enable_shell` | 계획 중 정밀한 레이아웃, 차트 및 다이어그램을 위해 모델이 코드를 실행할 수 있게 합니다. 꺼져 있으면 수량과 정렬이 근사치로 처리됩니다. 기본값: true. | BOOLEAN | 예 | true 또는 false (기본값: true) |
| `seed` | 노드를 다시 실행할지 결정하기 위한 시드입니다. API에는 시드가 없으므로 이 값에 관계없이 실제 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0 ~ 2147483647 (단계 1) |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 확장 가능한 슬롯: 편집하거나 결합할 1~10개의 참조 이미지(`image_1`부터 `image_10`까지)를 연결합니다. 프롬프트에서 `@Image1`, `@Image2`, ...로 참조하며, 입력 순서대로 번호가 지정됩니다. 배치 입력은 이미지마다 한 번씩 계산됩니다. | IMAGE | 예 | 1~10개의 참조 이미지 |

참고: 프롬프트는 비어 있을 수 없으며, 프롬프트에 포함된 각 `@ImageN` 참조는 입력 순서상 연결된 이미지 중 하나와 일치해야 합니다(예를 들어 `@Image1`은 첫 번째로 연결된 참조 이미지입니다). 프롬프트가 연결되지 않은 이미지 번호를 참조하거나 10개를 초과하는 참조 이미지가 연결되면 노드에서 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | Muse Image 모델이 반환한 편집 또는 결합된 이미지입니다. API가 여러 이미지를 반환하면 배치로 반환됩니다. | IMAGE |
