`OptimalStepsScheduler` 노드는 디퓨전 샘플링 중 사용할 노이즈 스케줄(시그마 값의 시퀀스)을 생성합니다. 선택한 모델 유형에서 기본 노이즈 레벨을 선택하고, 디노이징이 부분적으로만 적용될 때 스케줄을 조정하며, 반환되는 시그마가 요청된 스텝 수와 일치하도록 레벨을 보간합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델 종류` | 노이즈 레벨 계산에 사용할 디퓨전 모델 유형입니다. 각 옵션은 자체적으로 미리 정의된 노이즈 레벨 테이블을 사용합니다. | COMBO | 예 | "FLUX"<br />"Wan"<br />"Chroma" |
| `스텝` | 계산할 총 샘플링 스텝 수입니다(기본값: 20). | INT | 예 | 3  ~  1000 |
| `디노이즈` | 디노이징 강도를 제어하며, 이는 유효 스텝 수를 조정합니다(기본값: 1.0). | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.01) |

**참고:** 선택한 `model_type`의 기본 노이즈 레벨 테이블은 길이가 `steps + 1`과 같지 않을 때마다 로그-선형 보간으로 리샘플링되므로, 출력은 항상 요청된 스텝 수와 일치합니다.

**참고:** `denoise`가 1.0보다 작으면, 노드는 `round(steps * denoise)`를 총 유효 스텝 수로 사용하고 스케줄에서 이에 해당하는 뒷부분만 유지합니다. `denoise`가 0.0 이하이면, 노드는 빈 텐서를 반환합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `sigmas` | 디퓨전 샘플링을 위한 노이즈 스케줄을 나타내는 시그마 값의 시퀀스입니다. 시퀀스의 마지막 값은 항상 0으로 설정됩니다. | SIGMAS |
