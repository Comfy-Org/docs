WanAnimateToVideo는 참조 이미지, 포즈, 얼굴, 배경 및 이전 청크의 선택적 모션과 같은 입력을 사용하여 Wan으로 애니메이션 비디오를 생성하기 위한 컨디셔닝 데이터와 초기 잠재 변수를 준비합니다. 또한 `video_frame_offset` 값을 읽고 업데이트하여 더 긴 비디오를 청크 단위로 생성하는 것을 지원합니다. 이 노드는 실험적(experimental)으로 표시되어 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `긍정 프롬프트` | 생성 과정을 원하는 콘텐츠로 안내하기 위한 긍정적 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `부정 프롬프트` | 원치 않는 콘텐츠에서 생성 과정을 멀어지게 하기 위한 부정적 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `VAE` | 이미지와 비디오 입력을 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 | - |
| `너비` | 생성되는 비디오의 가로 크기(픽셀)입니다 (기본값: 832, 증가 단위: 16). | INT | 예 | 16 to MAX_RESOLUTION |
| `높이` | 생성되는 비디오의 세로 크기(픽셀)입니다 (기본값: 480, 증가 단위: 16). | INT | 예 | 16 to MAX_RESOLUTION |
| `길이` | 생성할 프레임 수입니다 (기본값: 77, 증가 단위: 4). | INT | 예 | 1 to MAX_RESOLUTION |
| `배치 크기` | 한 번에 생성할 비디오 수입니다 (기본값: 1). | INT | 예 | 1 ~ 4096 |
| `클립 비전 출력` | 양성 및 음성 컨디셔닝에 모두 추가되는 선택적 CLIP 비전 출력입니다. | CLIP_VISION_OUTPUT | 아니요 | - |
| `참조 이미지` | 생성되는 비디오의 외형 시작점으로 사용되는 참조 이미지입니다. 제공되지 않으면 검은색 이미지가 사용됩니다. | IMAGE | 아니요 | - |
| `얼굴 비디오` | 표정 가이드를 제공하는 비디오 입력입니다. 내부적으로 512x512로 크기가 조정되고 -1.0~1.0 범위로 스케일링됩니다. | IMAGE | 아니요 | - |
| `포즈 비디오` | 포즈 및 동작 가이드를 제공하는 비디오 입력입니다. | IMAGE | 아니요 | - |
| `연속 모션 최대 프레임 수` | 이전 모션 시퀀스에서 이월되는 최대 프레임 수입니다 (기본값: 5, 증가 단위: 4). | INT | 예 | 1 to MAX_RESOLUTION |
| `배경 비디오` | 프레임에서 캐릭터가 아닌 부분을 채우는 데 사용되는 배경 비디오입니다. | IMAGE | 아니요 | - |
| `캐릭터 마스크` | 캐릭터 영역을 정의하여 캐릭터를 배경과 분리하는 데 사용되는 마스크입니다. | MASK | 아니요 | - |
| `연속 모션` | 이전에 생성된 청크와 시간적 일관성을 유지하면서 이어질 이전 모션 프레임입니다. | IMAGE | 아니요 | - |
| `비디오 프레임 오프셋` | 모든 입력 비디오에서 건너뛸 프레임 수입니다. 청크 단위로 더 긴 비디오를 생성하는 데 사용됩니다. 비디오를 확장하려면 이전 노드의 video_frame_offset 출력에 연결하세요. (기본값: 0, 증가 단위: 1) | INT | 예 | 0 to MAX_RESOLUTION |

**매개변수 제약 조건:**

- `continue_motion`이 제공되면 해당 입력의 마지막 `continue_motion_max_frames` 프레임만 사용됩니다.
- 입력 비디오(`face_video`, `pose_video`, `background_video`, `character_mask`)는 사용 전에 `video_frame_offset`만큼 오프셋됩니다. 오프셋이 입력의 프레임 수 이상이면 해당 입력은 무시됩니다. 단, 단일 프레임 `character_mask`는 예외입니다.
- `character_mask`가 한 프레임만 있으면 해당 프레임이 출력의 모든 프레임에 반복됩니다.
- `pose_video`가 `length`보다 짧은 경우, 마지막 프레임이 반복되어 나머지 프레임을 채웁니다. 출력 길이는 변경되지 않습니다.
- `clip_vision_output`이 제공되면 양성 및 음성 컨디셔닝에 모두 추가됩니다.
- `reference_image`가 제공되지 않으면 검은색 이미지(모두 0 값)가 기본 참조로 사용됩니다.
- `continue_motion`이 제공되지 않으면 초기 모션 프레임은 일정한 회색(강도 0.5) 프레임으로 채워집니다.
- `continue_motion`을 사용하면 다음 청크 오프셋을 계산하기 전에 `video_frame_offset`이 이월된 프레임 수만큼 줄어들어 겹치는 프레임이 두 번 처리되지 않습니다.
- `background_video`는 참조 모션 부분 이후의 모션 프레임을 채웁니다. 참조 이미지나 이월된 `continue_motion` 프레임을 대체하지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `긍정 프롬프트` | CLIP 비전 출력, 포즈 비디오 잠재 변수, 얼굴 비디오 픽셀, 연결된 잠재 이미지 및 연결된 마스크를 포함하는 추가 비디오 컨텍스트가 포함된 수정된 양성 컨디셔닝입니다. | CONDITIONING |
| `부정 프롬프트` | CLIP 비전 출력, 포즈 비디오 잠재 변수, 빈 얼굴 픽셀, 연결된 잠재 이미지 및 연결된 마스크를 포함하는 추가 비디오 컨텍스트가 포함된 수정된 음성 컨디셔닝입니다. | CONDITIONING |
| `잠재 공간` | 생성되는 비디오의 초기 잠재 텐서(모두 0인 샘플)이며 형태는 `[batch_size, 16, latent_length + trim_latent, latent_height, latent_width]`입니다. | LATENT |
| `잠재 공간 트리밍` | 참조 이미지 프레임에 해당하는, 잠재 변수의 시작 부분에서 잘라낼 잠재 프레임 수입니다. | INT |
| `이미지 트리밍` | 참조 모션 프레임에 해당하는, 시작 부분에서 잘라낼 이미지 프레임 수입니다. | INT |
| `비디오 프레임 오프셋` | 입력 오프셋과 처리된 프레임 수를 기반으로 다음 청크에 사용할 업데이트된 프레임 오프셋입니다. | INT |
