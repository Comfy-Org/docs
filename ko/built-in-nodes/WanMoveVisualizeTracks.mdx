WanMoveVisualizeTracks 노드는 모션 추적 데이터를 이미지 또는 비디오 프레임 시퀀스 위에 오버레이합니다. 추적된 포인트의 이동 경로와 현재 위치를 포함한 시각적 표현을 그려, 모션 데이터를 눈에 띄게 하고 더 쉽게 분석할 수 있도록 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 트랙을 시각화할 입력 이미지 또는 비디오 프레임 시퀀스입니다. | IMAGE | 예 | - |
| `트랙` | 포인트 경로와 가시성 정보를 포함하는 모션 추적 데이터입니다. 제공되지 않으면 입력 이미지가 변경 없이 그대로 전달됩니다. | TRACKS | 아니요 | - |
| `선 해상도` | 각 트랙의 궤적 경로 선을 그릴 때 사용할 이전 프레임 수입니다(기본값: 24). | INT | 예 | 1 - 1024 |
| `원 크기` | 각 트랙의 현재 위치에 그려지는 원의 크기입니다(기본값: 12). 고급 매개변수로 표시됩니다. | INT | 예 | 1 - 128 |
| `불투명도` | 그려진 트랙 오버레이의 불투명도입니다(기본값: 0.75). | FLOAT | 예 | 0.0 - 1.0 |
| `선 두께` | 트랙 경로를 그리는 데 사용되는 선의 너비입니다(기본값: 16). 고급 매개변수로 표시됩니다. | INT | 예 | 1 - 128 |

**참고:** 입력 이미지 수가 제공된 `tracks` 데이터의 프레임 수와 일치하지 않으면, 이미지 시퀀스가 트랙 길이에 맞게 반복됩니다.

**참고:** 트랙 포인트는 제한된 반복 색상 세트로 그려지며, 특정 프레임에서 가시성 플래그가 0이면 해당 프레임에서 포인트를 건너뜁니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 모션 추적 데이터가 오버레이로 시각화된 이미지 시퀀스입니다. `tracks`가 제공되지 않은 경우 원본 입력 이미지가 반환됩니다. | IMAGE |
