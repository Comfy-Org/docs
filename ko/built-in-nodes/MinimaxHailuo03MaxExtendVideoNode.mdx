이 노드는 프롬프트와 선택적 오디오 참조의 안내를 받아 새 영상으로 비디오를 연장합니다. 원본 비디오를 업로드하면 연속 장면이 생성되고, 결과는 전체 비디오를 다시 렌더링한 형태 또는 새 영상만의 형태로 반환됩니다. 사용 가능한 모델은 "MiniMax H3 Max"와 "MiniMax H3 Max Turbo" 두 가지이며, 후자는 단위당 비용이 더 저렴합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 비디오 연속 생성을 위해 사용할 모델입니다. 두 모델 모두 아래와 동일한 입력을 제공합니다. | DYNAMIC_COMBO | 예 | "MiniMax H3 Max"<br />"MiniMax H3 Max Turbo" |

### 모델 입력

이 입력들은 두 모델 모두에 적용됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `video` | 확장할 비디오로, 길이는 1.625~60초, 최대 50 MB입니다. 화면 비율은 0.4에서 2.5 사이여야 합니다. | VIDEO | 예 | 1.625~60초 |
| `prompt` | 다음에 발생할 내용입니다. 소스가 아니라 연속 장면을 설명하십시오. 참조 오디오는 `@Audio1`..`@Audio3`로 참조하십시오. 예: "@Audio1 for the voice". | STRING | 예 | 1~50000자 |
| `reference_audios` | 확장 가능한 슬롯: 새 영상에 사용할 오디오 클립(`audio_1`...`audio_3`)을 최대 3개까지 연결할 수 있으며, 각각 최소 2초, 전체 최대 14.5초입니다. | AUDIO | 아니요 | 0~3개 클립 |
| `duration` | 추가할 새 영상의 길이(초)입니다(기본값: 5). | INT | 예 | 1~15 |
| `resolution` | 출력 비디오의 해상도입니다(기본값: "768P"). | COMBO | 예 | "480P"<br />"768P"<br />"1080P"<br />"2K" |
| `aspect_ratio` | 출력의 화면 비율입니다. "auto"는 원본 비디오를 따르며, 다른 값은 비디오를 선택한 비율로 자릅니다(기본값: "auto"). | COMBO | 예 | "auto"<br />"21:9"<br />"16:9"<br />"4:3"<br />"1:1"<br />"3:4"<br />"9:16" |
| `output` | "extended"는 새 영상이 포함된 전체 비디오를 선택한 해상도로 다시 렌더링하여 반환합니다. "continuation"은 원본의 마지막 부분을 1.6초 반복하는 것으로 시작하여 새 영상만 반환합니다(기본값: "extended"). | COMBO | 예 | "extended"<br />"continuation" |
| `prompt_expansion` | 소스 비디오를 사용하여 프롬프트를 재작성해 연속 장면의 일관성을 유지합니다. 동일한 시드에 대해 재현 가능한 결과를 얻으려면 이 기능을 끄십시오(기본값: true). | BOOLEAN | 아니요 | true<br />false |
| `seed` | 난수 시드입니다. 동일한 시드로 동일한 요청을 하면 유사하지만 동일하다고 보장되지는 않는 결과가 나옵니다(기본값: 42). | INT | 예 | 0~4294967295 |

### 매개변수 제약 사항

- 2K 해상도에서 "extended" 출력은 원본 비디오와 새 영상을 합쳐 총 45초로 제한됩니다. 더 긴 클립에는 "continuation" 또는 더 낮은 해상도를 사용하십시오.
- 각 참조 오디오 클립은 최소 2초 이상이어야 하며, 모두 합쳐 14.5초를 초과할 수 없습니다.
