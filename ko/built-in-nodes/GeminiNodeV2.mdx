Google의 Gemini 모델로 텍스트 응답을 생성합니다. 텍스트 프롬프트와 선택적으로 하나 이상의 이미지, 오디오 클립, 비디오 또는 파일을 멀티모달 컨텍스트로 제공하세요. 이 노드는 프롬프트와 첨부된 미디어를 선택한 모델로 전송하고 모델의 텍스트 답변을 반환합니다.

**참고:** 이 노드는 소스 코드에서 사용 중단(deprecated)으로 표시되어 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 응답을 생성하는 데 사용되는 Gemini 모델입니다. 모델을 선택하면 아래에 해당 모델의 입력 세트가 표시됩니다. | DYNAMIC_COMBO | 예 | `"Gemini 3.8 Flash"`<br />`"Gemini 3.7 Flash"`<br />`"Gemini 3.5 Flash"`<br />`"Gemini 3.1 Pro"`<br />`"Gemini 3.1 Flash-Lite"` |
| `prompt` | 모델에 대한 텍스트 입력입니다. 자세한 지침, 질문 또는 컨텍스트를 포함하세요. (기본값: "") | STRING | 예 | 공백이 아닌 문자를 하나 이상 포함해야 합니다 |
| `seed` | 샘플링용 시드입니다. 무작위 시드를 사용하려면 0으로 설정하세요. 결정론적 출력은 보장되지 않습니다. (기본값: 42) | INT | 예 | 0 ~ 2147483647 |
| `system_prompt` | 모델의 동작을 결정하는 기본 지침입니다. (기본값: "") | STRING | 아니요 |  |

### Gemini 3.8 Flash 입력

이 입력은 `model`이 `"Gemini 3.8 Flash"`로 설정되었을 때 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `thinking_level` | 모델이 답변하기 전에 내부적으로 추론하는 정도입니다. HIGH는 어려운 작업에서 품질을 향상시키지만 더 많은 (사고) 토큰을 소비하고 느립니다. (기본값: "MEDIUM") | COMBO | 예 | `"LOW"`<br />`"MEDIUM"`<br />`"HIGH"` |
| `max_output_tokens` | 생성할 최대 토큰 수로, 모델의 내부 사고를 포함합니다. thinking_level이 HIGH일 때 값이 낮으면 답변을 위한 여유가 없을 수 있습니다. 응답이 비어 있거나 잘려서 반환되면 이 값을 높이세요. 모델은 완료되면 조기에 중지하므로, 짧은 답변에서는 상한을 높여도 추가 비용이 들지 않습니다. (기본값: 32768) | INT | 예 | 16 ~ 65536 |

**참고:** 이 모델은 `temperature` 또는 `top_p` 샘플링 제어를 노출하지 않습니다.

### 미디어 및 파일 입력

다음 입력은 모든 모델에서 공유되며 모델별 입력과 함께 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 확장 가능한 슬롯: 1~16개의 이미지를 연결합니다(`image_1` ... `image_16`). 모델의 컨텍스트로 사용할 선택적 이미지입니다. 최대 16개의 이미지. | IMAGE | 아니요 | 0 ~ 16개 이미지 |
| `audio` | 확장 가능한 슬롯: 하나의 오디오 클립을 연결합니다(`audio_1`). 모델의 컨텍스트로 사용할 선택적 오디오 클립입니다. | AUDIO | 아니요 | 0 ~ 1개 클립 |
| `video` | 확장 가능한 슬롯: 하나의 비디오 클립을 연결합니다(`video_1`). 모델의 컨텍스트로 사용할 선택적 비디오 클립입니다. | VIDEO | 아니요 | 0 ~ 1개 클립 |
| `files` | 모델의 컨텍스트로 사용할 선택적 파일입니다. Gemini Input Files 노드의 입력을 받습니다. | GEMINI_INPUT_FILES | 아니요 |  |

**참고:** 미디어(이미지, 오디오 또는 비디오)가 첨부되면 노드는 처음 10개의 미디어 항목을 ComfyAPI 스토리지에 업로드하고 URL로 전달합니다. 이 URL 예산은 모든 미디어 유형에 걸쳐 공유되며 순서대로 소비됩니다(비디오 먼저, 그다음 오디오, 그다음 이미지). 남은 미디어는 인라인으로 base64 데이터로 인코딩되며, 최대 결합 인라인 페이로드는 18 MB입니다. 인라인 페이로드가 18 MB를 초과하면 노드에서 오류를 발생시킵니다. `prompt` 매개변수는 공백이 아닌 문자를 하나 이상 포함해야 합니다. `seed`를 0으로 설정하면 무작위 시드를 요청합니다.
