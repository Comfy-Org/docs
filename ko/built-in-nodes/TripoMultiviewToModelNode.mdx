이 노드는 Tripo API를 사용하여 객체의 서로 다른 뷰(전면, 왼쪽, 후면, 오른쪽)를 보여주는 최대 4개의 이미지를 처리하여 3D 모델을 동기적으로 생성합니다. 3D 모델을 만들려면 전면 이미지와 최소 하나의 추가 뷰(왼쪽, 후면 또는 오른쪽)가 필요합니다. 텍스처, PBR 머티리얼, 지오메트리 품질 및 출력 형식은 노드에서 제어할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 객체의 전면 뷰 이미지입니다. | IMAGE | 예 | - |
| `왼쪽 이미지` | 객체의 왼쪽 뷰 이미지입니다. | IMAGE | 아니요 | - |
| `뒷면 이미지` | 객체의 후면 뷰 이미지입니다. | IMAGE | 아니요 | - |
| `오른쪽 이미지` | 객체의 오른쪽 뷰 이미지입니다. | IMAGE | 아니요 | - |
| `모델 버전` | 생성에 사용할 모델 버전입니다. | COMBO | 아니요 | 여러 옵션 사용 가능 |
| `방향` | 3D 모델의 방향 설정입니다(기본값: `"default"`). | COMBO | 아니요 | 여러 옵션 사용 가능 |
| `텍스처` | 텍스처 맵을 생성합니다. 끄면 베어 지오메트리를 반환하고 pbr을 무시합니다. (기본값: True) | BOOLEAN | 아니요 | - |
| `PBR` | PBR 머티리얼 맵(베이스 컬러, 메탈릭, 러프니스, 노멀)입니다. 텍스처가 필요합니다. (기본값: True) | BOOLEAN | 아니요 | - |
| `모델 시드` | 모델 생성을 위한 무작위 시드입니다(기본값: 42). | INT | 아니요 | 0 ~ 2,147,483,647 |
| `텍스처 시드` | 텍스처 생성을 위한 무작위 시드입니다(기본값: 42). | INT | 아니요 | 0 ~ 2,147,483,647 |
| `텍스처 품질` | 텍스처 생성 품질 수준입니다(기본값: `"standard"`). `"detailed"` = HD 텍스처, `"extreme"` = 8K Ultra 텍스처. | COMBO | 아니요 | `"standard"`<br />`"detailed"`<br />`"extreme"` |
| `텍스처 정렬` | 텍스처를 모델에 정렬하는 데 사용되는 방법입니다(기본값: `"original_image"`). | COMBO | 아니요 | `"original_image"`<br />`"geometry"` |
| `얼굴 제한` | 최대 면 수입니다. -1은 Tripo가 적응형으로 선택하게 합니다(v3.x standard에서 약 140만 면, detailed에서 200만 면). Tripo는 별도 알림 없이 값을 제한합니다: v2.5는 500,000, 쿼드 메시는 150,000. (기본값: -1) | INT | 아니요 | -1 ~ 2,000,000 |
| `쿼드` | 쿼드 메시 출력입니다. Tripo는 쿼드 메시를 FBX로 제공하므로 결과는 FBX 출력으로 도착하고 GLB 출력은 비어 있습니다. (기본값: False) | BOOLEAN | 아니요 | - |
| `geometry_quality` | 지오메트리 생성 품질 수준입니다(기본값: `"standard"`). | COMBO | 아니요 | `"standard"`<br />`"detailed"` |
| `smart_low_poly` | 깔끔하고 수작업 스타일의 토폴로지를 가진 로우폴리 메시입니다(500-20,000면, 쿼드 500-10,000). 단순한 대상에 가장 적합하며, 복잡한 대상은 실패할 수 있습니다. (기본값: False) | BOOLEAN | 아니요 | - |
| `auto_size` | 텍스처가 있는 모델을 실제 크기(미터)로 조정합니다. Tripo는 크기를 모델의 장면 변환으로 저장하고, 모델이 변환, 리깅 또는 리타게팅될 때 이를 베이킹합니다. 텍스처가 없으면 무시됩니다. (기본값: False) | BOOLEAN | 아니요 | - |

**참고:** 전면 이미지(`image`)는 항상 필요하며, `image_left`, `image_back`, `image_right` 중 최소 하나도 제공해야 합니다. `texture`를 끄면 `pbr`도 자동으로 꺼집니다. `pbr`에는 텍스처가 필요하기 때문입니다. `smart_low_poly`가 활성화되어 있고 `face_limit`이 -1로 남아 있지 않은 경우, `face_limit`은 삼각형 메시의 경우 500에서 20,000 사이, 쿼드 메시의 경우 500에서 10,000 사이여야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `모델 파일` | 생성된 3D 모델의 파일 경로 또는 식별자입니다(하위 호환성 전용). | STRING |
| `모델 task_id` | 모델 생성 프로세스를 추적하기 위한 작업 식별자입니다. | MODEL_TASK_ID |
| `GLB` | GLB 형식으로 생성된 3D 모델 파일입니다. `quad`가 활성화되면 비어 있습니다. | FILE3DGLB |
| `FBX` | FBX 형식으로 생성된 3D 모델 파일입니다. `quad`가 활성화된 경우에만 채워집니다. | FILE3DFBX |
