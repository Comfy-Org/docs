Save Video 노드는 입력 비디오를 ComfyUI 출력 디렉터리에 저장합니다. 파일 이름 접두사, 컨테이너 형식, 비디오 코덱, 품질과 같은 인코딩 옵션을 선택할 수 있습니다. 이 노드는 카운터를 사용하여 고유한 파일 이름을 자동으로 생성하며, 저장된 파일에 워크플로 메타데이터를 포함할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `비디오` | 저장할 비디오입니다. | VIDEO | 예 | - |
| `파일명 접두사` | 저장할 파일의 접두사입니다. 노드의 값을 포함하기 위해 `%date:yyyy-MM-dd%` 또는 `%Empty Latent Image.width%`와 같은 형식 정보를 포함할 수 있습니다 (기본값: `video/ComfyUI`). | STRING | 예 | - |
| `포맷` | 출력 컨테이너입니다. 자동은 Auto/H.264에 MP4를 사용하고 AV1에 WebM을 사용합니다. MP4, MKV, WebM은 특정 컨테이너를 선택합니다. 형식을 선택하면 사용 가능한 코덱 옵션도 결정됩니다 (기본값: `auto`). | DYNAMIC_COMBO | 예 | `"auto"`<br />`"mp4"`<br />`"mkv"`<br />`"webm"` |
| `코덱` | 출력 비디오 코덱입니다. 자동은 호환되는 소스 스트림을 보존합니다. H.264 및 AV1 재인코딩은 SDR, HDR(HLG), HDR PQ를 지원합니다. 이 선택기는 선택한 형식 아래에 중첩됩니다 (기본값: `auto`). | DYNAMIC_COMBO | 아니오 | `"auto"`<br />`"h264"`<br />`"av1"` (`webm` 형식에서는 사용할 수 없음) |

### H.264 입력

이 입력은 `codec`이 `"h264"`일 때 나타나며 `auto`, `mp4`, `mkv` 형식에서 사용할 수 있습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `encoding` | 자동은 호환되는 H.264 스트림을 보존합니다. 재인코딩은 사용자 지정 인코딩 옵션을 적용합니다. | DYNAMIC_COMBO | 아니오 | `"auto"`<br />`"re-encode"` |
| `crf` | 값이 낮을수록 품질이 높아지고 파일 크기가 커집니다. `encoding`이 `"re-encode"`일 때 나타납니다 (기본값: 23.0). | FLOAT | 아니오 | 0.0 ~ 51.0 |

### AV1 입력

이 입력은 `codec`이 `"av1"`일 때 나타나며 `auto`, `mp4`, `mkv`, `webm` 형식에서 사용할 수 있습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `encoding` | 자동은 호환되는 AV1 스트림을 보존합니다. 재인코딩은 사용자 지정 인코딩 옵션을 적용합니다. | DYNAMIC_COMBO | 아니오 | `"auto"`<br />`"re-encode"` |
| `crf` | 값이 낮을수록 품질이 높아지고 파일 크기가 커집니다. `encoding`이 `"re-encode"`일 때 나타납니다 (기본값: 30.0). | FLOAT | 아니오 | 0.0 ~ 63.0 |

참고: `format`이 `"auto"`이면 저장되는 컨테이너가 자동으로 선택됩니다. `av1`은 WebM을 생성하고, `auto`와 `h264`는 MP4를 생성합니다. `webm` 형식은 `auto` 및 `av1` 코덱만 허용합니다. `codec`이 `"auto"`이면 소스 비디오 스트림이 재인코딩되지 않고 보존됩니다. 저장된 파일은 기존 파일을 덮어쓰지 않도록 카운터 접미사를 사용합니다. 파일 확장자는 결정된 컨테이너에 따라 정해집니다. 시작 시 메타데이터 저장이 비활성화되지 않는 한 워크플로 메타데이터(프롬프트 및 추가 노드 정보)가 저장된 파일에 포함됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `video` | 변경되지 않은 입력 비디오입니다. | VIDEO |
| `ui` | UI에 표시하기 위해 파일 경로와 하위 폴더 정보를 포함하는 저장된 비디오 파일의 미리보기입니다. | PREVIEW_VIDEO |
