WanMoveTrackToVideo 노드는 선택적 모션 트래킹 정보를 통합하여 비디오 생성을 위한 컨디셔닝 및 잠재 공간 데이터를 준비합니다. 시작 이미지 시퀀스를 잠재 표현으로 인코딩하고 객체 트랙의 위치 데이터를 혼합하여 생성된 비디오의 모션을 안내할 수 있습니다. 이 노드는 수정된 positive 및 negative 컨디셔닝과 비디오 모델에 사용할 준비가 된 빈 잠재 텐서를 출력합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `positive` | 수정할 positive 컨디셔닝 입력입니다. | CONDITIONING | 예 | - |
| `negative` | 수정할 negative 컨디셔닝 입력입니다. | CONDITIONING | 예 | - |
| `vae` | 시작 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 | - |
| `트랙` | 객체 경로를 포함하는 선택적 모션 트래킹 데이터입니다. | TRACKS | 아니오 | - |
| `강도` | 트랙 컨디셔닝의 강도입니다. (기본값: 1.0) | FLOAT | 예 | 0.0 - 100.0 |
| `너비` | 출력 비디오의 너비입니다. 16으로 나누어 떨어져야 합니다. (기본값: 832) | INT | 예 | 16 - MAX_RESOLUTION |
| `높이` | 출력 비디오의 높이입니다. 16으로 나누어 떨어져야 합니다. (기본값: 480) | INT | 예 | 16 - MAX_RESOLUTION |
| `길이` | 비디오 시퀀스의 프레임 수이며, 4 단위로 증가합니다. (기본값: 81) | INT | 예 | 1 - MAX_RESOLUTION |
| `배치 크기` | 잠재 출력의 배치 크기입니다. (기본값: 1) | INT | 예 | 1 - 4096 |
| `시작 이미지` | 인코딩할 시작 이미지 또는 이미지 시퀀스입니다. | IMAGE | 예 | - |
| `clip 비전 출력` | 컨디셔닝에 추가할 선택적 CLIP 비전 모델 출력입니다. | CLIP_VISION_OUTPUT | 아니오 | - |

**참고:** `strength` 매개변수는 `tracks`가 제공되고 `strength`가 0.0보다 클 때만 효과가 있습니다. 트랙 컨디셔닝은 `start_image`도 함께 제공된 경우에만 적용됩니다. `tracks`가 제공되지 않거나 `strength`가 0.0이면 트랙 혼합이 생략됩니다. 트랙 혼합이 활성화되면 positive 컨디셔닝은 트랙이 혼합된 잠재 이미지를 받고, negative 컨디셔닝은 수정되지 않은 잠재 이미지를 받습니다. `start_image`가 제공되지 않으면 잠재 이미지 및 마스크 컨디셔닝이 생성되지 않습니다. positive 및 negative 컨디셔닝은 변경 없이 통과하며(`clip_vision_output`이 제공된 경우 여전히 추가됨), 노드는 빈 잠재 텐서를 출력합니다.

**참고:** `start_image`가 제공되면 이미지 시퀀스는 대상 `width` 및 `height`로 크기가 조정되고 처음 `length` 프레임으로 잘립니다. 시퀀스가 `length`보다 짧으면 VAE 인코딩 전에 나머지 프레임이 중립 회색 프레임(값 0.5)으로 채워집니다. 결과 컨디셔닝에는 시작 이미지 프레임에 해당하는 시간적 위치에서 값이 0이고 그 외 위치에서는 1인 `concat_mask`가 포함됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `positive` | 수정된 positive 컨디셔닝으로, `concat_latent_image`, `concat_mask`, `clip_vision_output`을 포함할 수 있습니다. | CONDITIONING |
| `negative` | 수정된 negative 컨디셔닝으로, `concat_latent_image`, `concat_mask`, `clip_vision_output`을 포함할 수 있습니다. | CONDITIONING |
| `latent` | `batch_size`, `length`, `height`, `width` 입력에 따라 결정되는 형태 `[batch_size, 16, ((length - 1) // 4) + 1, height // 8, width // 8]`의 빈 잠재 텐서입니다. | LATENT |
