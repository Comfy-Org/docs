Qwen Image 3 Text to Image는 Qwen-Image 3.0 모델을 사용하여 텍스트 프롬프트에서 하나 이상의 이미지를 생성합니다. 모델을 선택하고 프롬프트를 제공하면 노드는 생성된 이미지를 배치로 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 사용할 모델(기본값: "qwen-image-3.0-pro"). 이 복합 선택기는 프롬프트, 이미지 너비, 이미지 높이 및 선택적 네거티브 프롬프트도 제공합니다. | MODEL | 예 | "qwen-image-3.0-pro"<br />"qwen-image-3.0" |
| `n` | 생성할 이미지 수로, 배치로 반환됩니다(기본값: 1). | INT | 아니요 | 1 ~ 6 |
| `seed` | 생성에 사용할 시드(기본값: 42). 각 생성 후 자동으로 업데이트되도록 설정할 수 있습니다. | INT | 아니요 | 0 ~ 2147483647 |
| `prompt_extend` | AI 지원으로 프롬프트를 향상시킬지 여부(기본값: true). 고급 옵션입니다. | BOOLEAN | 아니요 | true<br />false |
| `watermark` | 결과에 AI 생성 워터마크를 추가할지 여부(기본값: false). 고급 옵션입니다. | BOOLEAN | 아니요 | true<br />false |

참고: `model` 입력은 다음 하위 필드를 포함하는 복합 선택기입니다: `model`(모델 ID), `prompt`(텍스트 프롬프트, 1자 이상이어야 함), `width` 및 `height`(이미지 크기, 노드에서 검증됨), 그리고 `negative_prompt`(선택적 네거티브 프롬프트).

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 생성된 이미지 또는 이미지들로, 배치로 반환됩니다. | IMAGE |
