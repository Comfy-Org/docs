Qwen Image 3 Text to Image는 Qwen-Image 3.0 모델을 사용하여 텍스트 프롬프트로부터 하나 이상의 이미지를 생성합니다. 모델을 선택하고 프롬프트를 제공하면, 노드는 생성된 이미지를 배치로 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 사용할 모델입니다(기본값: "qwen-image-3.0-pro"). 이 복합 선택기는 프롬프트, 부정 프롬프트, 이미지 너비 및 이미지 높이도 제공합니다. | DYNAMIC_COMBO | 예 | "qwen-image-3.0-pro"<br />"qwen-image-3.0" |
| `n` | 생성할 이미지 수이며, 배치로 반환됩니다(기본값: 1). | INT | 아니요 | 1~6 |
| `seed` | 생성에 사용할 시드입니다(기본값: 42). 각 생성 후 자동으로 업데이트되도록 설정할 수 있습니다. | INT | 아니요 | 0~2147483647 |
| `prompt_extend` | AI 지원으로 프롬프트를 향상할지 여부입니다(기본값: true). 고급 옵션입니다. | BOOLEAN | 아니요 | true<br />false |
| `watermark` | 결과에 AI 생성 워터마크를 추가할지 여부입니다(기본값: false). 고급 옵션입니다. | BOOLEAN | 아니요 | true<br />false |

### qwen-image-3.0-pro 및 qwen-image-3.0 입력

qwen-image-3.0-pro와 qwen-image-3.0에서 공유됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 이미지를 설명하는 프롬프트입니다. 영어와 중국어를 지원합니다. 최소 1자 이상이어야 합니다. | STRING | 예 | 자유 텍스트 |
| `negative_prompt` | 피해야 할 내용을 설명하는 부정 프롬프트입니다(기본값: ""). | STRING | 아니요 | 자유 텍스트 |
| `width` | 총 픽셀 면적이 512x512에서 2560x2560 사이여야 하며, 해당 면적 내의 모든 가로세로 비율을 사용할 수 있습니다. (기본값: 1024) | INT | 아니요 | 256~2560 (간격 16) |
| `height` | 총 픽셀 면적이 512x512에서 2560x2560 사이여야 하며, 해당 면적 내의 모든 가로세로 비율을 사용할 수 있습니다. (기본값: 1024) | INT | 아니요 | 256~2560 (간격 16) |

참고: `model` 입력은 `model`(모델 ID), `prompt`(필수, 최소 1자 이상), `negative_prompt`(선택 사항), `width`, `height` 하위 필드를 가진 복합 선택기입니다. `width`와 `height`의 결합 픽셀 면적은 262,144픽셀(512x512)에서 6,553,600픽셀(2560x2560) 사이여야 하며, 가로세로 비율은 1:8에서 8:1 사이를 유지해야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 생성된 이미지 또는 이미지들을 배치로 반환합니다. | IMAGE |
