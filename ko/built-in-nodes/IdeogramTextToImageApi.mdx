Ideogram 4.6 또는 4.5를 사용하여 텍스트 프롬프트로 이미지를 생성합니다. 이 프롬프트는 Ideogram 구조화 JSON 캡션(예: 이전 실행에서 반환된 `final_prompt`)도 받을 수 있으며, 이를 통해 텍스트 문자열, 색상, 레이아웃을 정확하게 제어할 수 있습니다. 이 노드는 이미지와 함께 실제로 이미지 생성에 사용된 캡션을 반환합니다.

## 입력

`model`을 선택하면 표시되는 입력이 결정됩니다. Ideogram 4.6은 `background`, `very_low` 품질 등급, `(4K)` 크기 및 사용자 지정 너비와 높이를 추가하며, 4.5는 `(1K)` 및 `(2K)` 프리셋을 유지합니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 사용할 모델입니다. `"ideogram-4.6"`은 선택적 투명 배경과 함께 최대 4K로 렌더링하며, `"ideogram-4.5"`는 이전 모델입니다(기본값: `"ideogram-4.6"`). | DYNAMIC_COMBO | 예 | `"ideogram-4.6"`<br />`"ideogram-4.5"` |
| `prompt` | 텍스트 프롬프트 또는 이전 `final_prompt`와 같은 Ideogram 구조화 JSON 캡션입니다(기본값: 빈 문자열). | STRING | 예 | 1 ~ 10000자 |
| `magic_prompt` | 생성 전에 프롬프트를 상세한 구조화 캡션으로 다시 작성합니다. `"off"`는 사용자의 표현을 최대한 문자 그대로 유지합니다. 캡션은 `final_prompt`로 반환됩니다(기본값: `"auto"`). 이 설정은 고급 설정입니다. | COMBO | 예 | `"auto"`<br />`"on"`<br />`"off"` |

### 매개변수 제약 사항

- **Prompt:** 공백이 아닌 문자를 최소 1개 포함해야 하며 최대 10000자입니다. 직접 작성한 JSON 캡션을 제공할 때는 `magic_prompt`를 `"off"`로 설정하세요.
- **사용자 지정 크기(4.6):** 너비 × 높이는 16.7 MP(4096x4096)를 초과할 수 없고, 각 변은 256에서 8192 사이여야 하며 32의 배수로 맞춰져야 하고, 긴 변은 짧은 변의 6배를 초과할 수 없습니다.
- **`very_low` 품질(4.6):** 4 MP(2048x2048)로 제한되며, 더 큰 크기는 오류를 발생시킵니다.
- **재현성:** `magic_prompt`가 `"auto"` 또는 `"on"`이면 매 실행마다 프롬프트가 다시 작성되므로 동일한 시드라도 다른 이미지가 생성될 수 있습니다.
- **콘텐츠 안전:** Ideogram의 콘텐츠 안전 필터가 생성을 차단하면 노드는 이미지를 반환하는 대신 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 생성된 이미지를 배치로 반환합니다. | IMAGE |
| `final_prompt` | 이미지 생성에 사용된 구조화 캡션입니다. 이를 `magic_prompt`를 `"off"`로 설정하고 동일한 시드와 함께 다시 입력하면 이미지를 재현할 수 있습니다. | STRING |
