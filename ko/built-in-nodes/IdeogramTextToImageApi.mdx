Ideogram 4.5로 텍스트 프롬프트에서 이미지를 생성합니다. 이 프롬프트는 Ideogram 구조화 JSON 캡션도 받을 수 있습니다. 예를 들어 이전 실행에서 반환된 `final_prompt`를 사용하면 텍스트 문자열, 색상 및 레이아웃을 정확하게 제어할 수 있습니다. 이 노드는 생성된 이미지와 이미지가 실제로 생성된 기준이 된 캡션을 함께 반환합니다.

|-----------|-------------|-----------|----------|-------|
| `모델` | 사용할 모델입니다. (기본값: `"ideogram-4.5"`) | DYNAMIC_COMBO | 예 | `"ideogram-4.5"` |
| `prompt` | 텍스트 프롬프트 또는 이전 `final_prompt`와 같은 Ideogram 구조화 JSON 캡션입니다. (기본값: 빈 문자열) | STRING | 예 | 1  ~  10000자 |

### 매개변수 제약

- **프롬프트 필수:** 프롬프트에는 공백이 아닌 문자가 최소 1개, 최대 10000자가 포함되어야 합니다. 직접 JSON 캡션 또는 정확한 문구를 제공할 때는 `magic_prompt`를 `"off"`로 설정하십시오.
- **크기:** `"auto"`는 모델이 선택하도록 합니다. `(2K)` 프리셋은 약 300만~400만 화소, `(1K)` 프리셋은 약 100만 화소입니다. 등급 라벨은 고정된 긴 변이 아니라 화소 예산을 나타냅니다. 프리셋의 화면 비율이 유지됩니다. API에는 프리셋의 픽셀 크기 부분만 전송됩니다.
- **재현성:** `magic_prompt`가 `"auto"` 또는 `"on"`으로 설정된 경우 매 실행마다 프롬프트가 다시 작성되므로 동일한 시드로도 다른 이미지가 생성될 수 있습니다. 이미지를 재현하려면 해당 `final_prompt`를 `magic_prompt`가 `"off"`로 설정된 상태에서 동일한 시드와 함께 다시 입력하십시오.
- **콘텐츠 안전:** Ideogram의 콘텐츠 안전 필터가 생성을 차단하면 노드는 이미지를 반환하는 대신 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 생성된 이미지(들)을 배치로 나타냅니다. | IMAGE |
| `final_prompt` | 이미지가 생성된 기준이 된 구조화 캡션입니다. 이미지를 재현하려면 이를 `magic_prompt`가 `"off"`로 설정된 상태에서 동일한 시드와 함께 다시 입력하십시오. | STRING |
