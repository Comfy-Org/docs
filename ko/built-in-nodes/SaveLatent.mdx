SaveLatent는 잠재 텐서를 `.latent` 파일로 디스크에 저장하여 나중에 재사용하거나 공유할 수 있도록 합니다. 잠재 샘플을 입력받아 자동으로 생성된 이름으로 출력 폴더에 저장하며, 저장된 파일 내부에 프롬프트와 같은 워크플로우 메타데이터를 포함시킬 수 있습니다. 동일한 잠재 샘플은 추가 처리를 위해 변경 없이 그대로 전달됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `잠재 데이터` | 디스크에 저장할 잠재 샘플입니다. | LATENT | 예 | - |
| `파일명 접두사` | 출력 파일 이름을 만드는 데 사용되는 접두사입니다. 하위 폴더를 포함할 수 있습니다(예: "latents/ComfyUI" (기본값: "latents/ComfyUI")). | STRING | 예 | - |
| `prompt` | 워크플로우 프롬프트로, JSON으로 직렬화되어 저장된 파일 메타데이터에 포함됩니다(숨김 매개변수, 자동으로 제공됨). | PROMPT | 아니요 | - |
| `extra_pnginfo` | 추가 워크플로우 정보로, JSON으로 직렬화되어 저장된 파일 메타데이터에 포함됩니다(숨김 매개변수, 자동으로 제공됨). | EXTRA_PNGINFO | 아니요 | - |

참고: 저장된 각 파일은 접두사와 5자리 카운터를 사용하여 이름이 지정됩니다(예: `ComfyUI_00001_.latent`). 출력 디렉터리에 배치됩니다. 파일에는 잠재 텐서와 잠재 형식 버전 마커가 포함됩니다. 메타데이터는 메타데이터 지원이 활성화된 경우에만 저장된 파일에 포함됩니다. 즉, ComfyUI가 `--disable-metadata` 옵션으로 시작되지 않은 경우입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `samples` | 입력으로 제공된 잠재 샘플로, 변경 없이 그대로 전달됩니다. | LATENT |
| `ui` | 저장된 파일을 설명하는 인터페이스 표시 데이터: 파일 이름, 하위 폴더 및 출력 유형("output"). | UI |
