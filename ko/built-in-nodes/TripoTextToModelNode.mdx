Tripo의 API를 사용하여 텍스트 설명에서 완성된 3D 모델을 생성합니다. 이 노드는 생성이 완료될 때까지 대기한 다음, 선택적으로 텍스처와 PBR 재질이 포함된 모델 파일을 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 생성할 3D 모델에 대한 텍스트 설명입니다(여러 줄). 필수 매개변수이며 비어 있을 수 없습니다. | STRING | 예 | - |
| `네거티브 프롬프트` | 생성된 모델에서 피해야 할 내용에 대한 텍스트 설명입니다(여러 줄). 최대 255자입니다. 비어 있지 않은 경우에만 API로 전송됩니다. | STRING | 아니요 | 최대 255자 |
| `모델 버전` | 생성에 사용할 Tripo 모델의 버전입니다(기본값: v3.1-20260211). | COMBO | 아니요 | 여러 옵션 사용 가능 |
| `스타일` | 생성된 모델에 적용되는 스타일입니다(기본값: None). Tripo에서 더 이상 지원되지 않으며 무시됩니다. 이전 워크플로와의 호환성을 위해 유지됩니다. | COMBO | 아니요 | 여러 옵션 사용 가능 |
| `텍스처` | 텍스처 맵 생성 여부입니다. 끄면 텍스처가 없는 지오메트리를 반환하고 `pbr`은 무시됩니다(기본값: True). | BOOLEAN | 아니요 | true / false |
| `PBR` | PBR 재질 맵(베이스 컬러, 메탈릭, 러프니스, 노멀) 생성 여부입니다. `texture`가 활성화되어 있어야 하며, `texture`가 꺼져 있으면 이 값도 강제로 꺼집니다(기본값: True). | BOOLEAN | 아니요 | true / false |
| `이미지 시드` | 이미지 생성 단계에서 사용되는 시드입니다(기본값: 42). | INT | 아니요 | 0 ~ 2147483647 |
| `모델 시드` | 모델 생성 단계에서 사용되는 시드입니다(기본값: 42). | INT | 아니요 | 0 ~ 2147483647 |
| `텍스처 시드` | 텍스처 생성 단계에서 사용되는 시드입니다(기본값: 42). | INT | 아니요 | 0 ~ 2147483647 |
| `텍스처 품질` | 생성되는 텍스처의 품질입니다. detailed는 HD 텍스처, extreme은 8K Ultra 텍스처입니다(기본값: standard). | COMBO | 아니요 | "standard"<br />"detailed"<br />"extreme" |
| `얼굴 제한` | 최대 면 수입니다. -1로 설정하면 Tripo가 적응형으로 선택합니다(v3.x standard의 경우 약 140만 개, detailed의 경우 약 200만 개). Tripo는 상한값을 자동으로 적용합니다. v2.5는 500,000개, 쿼드 메시는 150,000개로 제한됩니다. (기본값: -1) | INT | 아니요 | -1 ~ 2000000 |
| `쿼드` | 쿼드 메시 출력 여부입니다. Tripo는 쿼드 메시를 FBX로 제공하므로 결과물은 FBX 출력으로 전달되고 GLB 출력은 비어 있게 됩니다(기본값: False). | BOOLEAN | 아니요 | true / false |
| `geometry_quality` | 생성되는 지오메트리의 품질입니다(기본값: standard). | COMBO | 아니요 | "standard"<br />"detailed" |
| `smart_low_poly` | 깔끔하고 수작업으로 제작한 듯한 토폴로지를 가진 저폴리 메시입니다(면 500~20,000개, 쿼드 500~10,000개). 단순한 대상에 가장 적합하며, 복잡한 대상은 생성에 실패할 수 있습니다(기본값: False). | BOOLEAN | 아니요 | true / false |
| `auto_size` | 텍스처가 포함된 모델을 실제 세계 크기(미터 단위)로 조정합니다. Tripo는 크기를 모델의 씬 트랜스폼에 저장하며, 모델을 변환, 리깅 또는 리타깃할 때 이 크기를 적용합니다. `texture`가 없으면 무시됩니다(기본값: True). | BOOLEAN | 아니요 | true / false |

**참고:**

- `prompt` 매개변수는 필수입니다. 프롬프트가 비어 있으면 노드에서 오류가 발생합니다.
- `pbr`은 `texture`가 필요합니다. `texture`가 꺼져 있으면 노드는 `pbr`을 강제로 끄고 해당 값을 무시합니다. `auto_size`도 `texture`가 없으면 효과가 없습니다.
- `smart_low_poly`가 활성화되고 `face_limit`이 -1이 아닌 값으로 설정된 경우, 면 수 제한은 삼각형 출력에서는 500~20,000개 사이여야 하며, `quad`가 활성화된 경우에는 500~10,000개 사이여야 합니다. 그렇지 않으면 노드에서 오류가 발생합니다.
- `quad`가 활성화되면 생성된 쿼드 메시가 FBX로 제공되므로 FBX 출력이 채워지고 GLB 출력은 비어 있게 됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `모델 파일` | 생성된 3D 모델 파일입니다. 하위 호환성을 위해서만 유지됩니다. | STRING |
| `모델 task_id` | 모델 생성 프로세스의 고유 작업 식별자입니다. | MODEL_TASK_ID |
| `GLB` | GLB 형식으로 생성된 3D 모델입니다. `quad`가 활성화되면 비어 있게 됩니다. | FILE3DGLB |
| `FBX` | FBX 형식으로 생성된 3D 모델입니다. `quad`가 활성화된 경우에만 채워집니다. | FILE3DFBX |
