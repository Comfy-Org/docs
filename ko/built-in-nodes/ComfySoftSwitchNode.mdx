Soft Switch 노드는 불리언 조건에 따라 두 가지 가능한 입력 값 중 하나를 선택합니다. `switch`가 true일 때 `on_true` 입력의 값을 출력하고, `switch`가 false일 때 `on_false` 입력의 값을 출력합니다. 이 노드는 지연 평가(lazy) 방식으로 설계되어, 스위치 상태에 따라 실제로 필요한 입력만 평가합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `switch` | 어떤 입력을 통과시킬지 결정하는 불리언 조건입니다. true이면 `on_true` 입력이 선택됩니다. false이면 `on_false` 입력이 선택됩니다. | BOOLEAN | 예 | True or False |
| `on_false` | `switch` 조건이 false일 때 출력할 값입니다. 이 입력은 선택 사항이지만, `on_false` 또는 `on_true` 중 적어도 하나는 연결되어야 합니다. | MATCH_TYPE | 아니요 | `on_true`와 동일한 데이터 타입 |
| `on_true` | `switch` 조건이 true일 때 출력할 값입니다. 이 입력은 선택 사항이지만, `on_false` 또는 `on_true` 중 적어도 하나는 연결되어야 합니다. | MATCH_TYPE | 아니요 | `on_false`와 동일한 데이터 타입 |

**참고:** `on_false` 및 `on_true` 입력은 노드의 내부 템플릿에 정의된 대로 동일한 데이터 타입이어야 합니다. 이 두 입력 중 적어도 하나는 연결되어야 하며, 그렇지 않으면 노드는 "At least one of on_false or on_true must be connected to Switch node"라는 유효성 검사 메시지를 반환합니다. 이 노드는 지연 평가 방식이므로 입력이 하나만 연결된 경우 `switch` 상태와 관계없이 항상 해당 입력의 값을 출력합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `output` | 선택된 값입니다. 연결된 `on_false` 또는 `on_true` 입력의 데이터 타입과 일치합니다. 두 입력이 모두 연결된 경우, `switch`가 true이면 `on_true`를 출력하고 `switch`가 false이면 `on_false`를 출력합니다. | MATCH_TYPE |
