ModelComputeDtype 노드는 처리 중 모델이 사용하는 계산 데이터 타입(정밀도)을 변경합니다. 입력 모델의 복사본을 생성하고 선택한 정밀도 설정을 적용하며, 이를 통해 하드웨어에 따라 메모리 사용량과 성능을 최적화할 수 있습니다. 다양한 정밀도 구성을 디버깅하고 테스트하는 데 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 새로운 계산 데이터 타입으로 수정할 입력 모델 | MODEL | 예 | - |
| `dtype` | 모델에 적용할 계산 데이터 타입(기본값: "default"). 이 매개변수는 고급 옵션으로 표시됩니다. | COMBO | 예 | "default"<br />"fp32"<br />"fp16"<br />"bf16" |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | 새로운 계산 데이터 타입이 적용된 수정된 모델 | MODEL |
