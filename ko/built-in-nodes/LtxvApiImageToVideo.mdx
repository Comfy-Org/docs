LTXV Image To Video 노드는 단일 시작 이미지에서 전문가 수준의 비디오를 생성합니다. 외부 API를 사용하여 텍스트 프롬프트를 기반으로 비디오 시퀀스를 만들며, 길이, 해상도, 프레임 속도를 사용자 지정할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `image` | 비디오에 사용할 첫 프레임입니다. | IMAGE | 예 | - |
| `model` | 비디오 생성에 사용할 AI 모델입니다. "Pro" 모델은 품질에 최적화되어 있고, "Fast" 모델은 속도에 최적화되어 있습니다. | COMBO | 예 | `"LTX-2 (Pro)"`<br />`"LTX-2 (Fast)"` |
| `prompt` | 생성된 비디오의 내용과 움직임을 안내하는 텍스트 설명입니다(기본값: 비어 있음). | STRING | 예 | - |
| `duration` | 비디오 길이(초)입니다(기본값: 8). | COMBO | 예 | `6`<br />`8`<br />`10`<br />`12`<br />`14`<br />`16`<br />`18`<br />`20` |
| `resolution` | 생성된 비디오의 출력 해상도입니다. | COMBO | 예 | `"1920x1080"`<br />`"2560x1440"`<br />`"3840x2160"` |
| `fps` | 비디오의 초당 프레임 수입니다(기본값: 25). | COMBO | 예 | `25`<br />`50` |
| `generate_audio` | true인 경우 생성된 비디오에 장면과 일치하는 AI 생성 오디오가 포함됩니다(기본값: False). | BOOLEAN | 아니요 | - |

**중요 제약 사항:**

* `image` 입력에는 정확히 하나의 이미지만 포함되어야 합니다.
* `prompt`는 1자에서 10,000자 사이여야 합니다.
* `duration`을 10초보다 길게 선택하면 **"LTX-2 (Fast)"** 모델, **"1920x1080"** 해상도, **25** FPS를 사용해야 합니다. 이 조합은 더 긴 비디오에 필요합니다.

**참고:** 이 노드는 더 이상 사용되지 않음(deprecated)으로 표시되어 있습니다. 노드에 표시되는 예상 비용은 선택한 `model`, `duration`, `resolution`에 따라 달라집니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `video` | 생성된 비디오 파일입니다. | VIDEO |
