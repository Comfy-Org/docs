MaskPreview 노드는 출력 디렉토리에 저장하지 않고 ComfyUI 인터페이스에서 마스크 데이터의 시각적 미리보기를 직접 표시합니다. 이를 통해 워크플로우의 어느 지점에서든 정확한 마스크 값을 검사할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `마스크` | 미리보기할 마스크 데이터 | MASK | 예 | - |
| `filename_prefix` | 미리보기 파일 이름의 접두사 (기본값: "ComfyUI") | STRING | 아니요 | - |
| `prompt` | 메타데이터용 프롬프트 정보 (자동 제공됨) | PROMPT | 아니요 | - |
| `extra_pnginfo` | 메타데이터용 추가 PNG 정보 (자동 제공됨) | EXTRA_PNGINFO | 아니요 | - |

`prompt` 및 `extra_pnginfo` 입력은 숨겨져 있으며 ComfyUI 시스템에서 자동으로 제공되므로 수동으로 연결할 필요가 없습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `mask` | 미리보기된 마스크 데이터로, 워크플로우에서 추가로 사용할 수 있도록 변경 없이 반환됩니다. | MASK |
