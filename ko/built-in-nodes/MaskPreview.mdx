MaskPreview 노드는 마스크 데이터의 시각적 미리 보기를 ComfyUI 인터페이스에 직접 표시하며, 출력 디렉터리에 저장하지 않습니다. 따라서 워크플로우의 어느 지점에서든 마스크를 검사할 수 있으며, 마스크는 노드를 변경 없이 통과하므로 이후 단계에서 계속 사용할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `마스크` | 미리 보기할 마스크 데이터 | MASK | 예 | - |
| `filename_prefix` | 미리 보기에 사용되는 파일 이름 접두사 (기본값: "ComfyUI") | STRING | 아니요 | - |
| `prompt` | 메타데이터용 프롬프트 정보 (자동으로 제공됨) | PROMPT | 아니요 | - |
| `extra_pnginfo` | 메타데이터용 추가 PNG 정보 (자동으로 제공됨) | EXTRA_PNGINFO | 아니요 | - |

`mask`만 연결해야 하는 표시 입력입니다. `filename_prefix`, `prompt`, `extra_pnginfo` 매개변수는 시스템에서 제공됩니다. `filename_prefix`는 기본값으로 대체되고, `prompt`와 `extra_pnginfo`는 숨겨진 매개변수로 ComfyUI 런타임이 자동으로 제공합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `mask` | 미리 보기된 동일한 마스크 데이터가 변경 없이 반환되어 워크플로우의 다른 곳에서 사용할 수 있습니다 | MASK |
