텍스트 프롬프트를 기반으로 하나 이상의 기존 이미지를 수정합니다. 이 노드는 선택한 모델을 사용하여 연결된 참조 이미지와 프롬프트를 Grok 이미지 편집 API로 전송한 다음, 편집된 이미지를 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 사용할 Grok 이미지 모델입니다. 아래에 표시된 하위 매개변수는 선택한 모델에 따라 달라집니다. | DYNAMIC_COMBO | 예 | "grok-imagine-image-2.0"<br />"grok-imagine-image-quality"<br />"grok-imagine-image-pro"<br />"grok-imagine-image" |
| `프롬프트` | 이미지를 생성하는 데 사용되는 텍스트 프롬프트입니다. (기본값: "") | STRING | 예 | N/A |
| `시드` | 노드를 다시 실행할지 결정하는 시드입니다. 실제 결과는 시드와 관계없이 비결정적입니다. (기본값: 0) | INT | 예 | 0~2147483647 |

### grok-imagine-image-2.0 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 편집된 이미지의 출력 해상도입니다. | COMBO | 예 | "1K"<br />"2K" |
| `number_of_images` | 생성할 편집 이미지 수입니다. (기본값: 1) | INT | 예 | 1~10 |
| `quality` | 생성된 이미지의 품질 수준입니다. | COMBO | 예 | "medium"<br />"low" |
| `aspect_ratio` | 편집된 이미지의 종횡비입니다. (기본값: "auto") | COMBO | 예 | "auto"<br />"1:1"<br />"2:3"<br />"3:2"<br />"3:4"<br />"4:3"<br />"9:16"<br />"16:9"<br />"9:19.5"<br />"19.5:9"<br />"9:20"<br />"20:9"<br />"1:2"<br />"2:1" |

### grok-imagine-image-quality 및 grok-imagine-image 입력

grok-imagine-image-quality 및 grok-imagine-image에서 공유됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 편집된 이미지의 출력 해상도입니다. | COMBO | 예 | "1K"<br />"2K" |
| `number_of_images` | 생성할 편집 이미지 수입니다. (기본값: 1) | INT | 예 | 1~10 |
| `aspect_ratio` | 여러 이미지가 연결된 경우에만 허용됩니다. (기본값: "auto") | COMBO | 예 | "auto"<br />"1:1"<br />"2:3"<br />"3:2"<br />"3:4"<br />"4:3"<br />"9:16"<br />"16:9"<br />"9:19.5"<br />"19.5:9"<br />"9:20"<br />"20:9"<br />"1:2"<br />"2:1" |

### grok-imagine-image-pro 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 편집된 이미지의 출력 해상도입니다. | COMBO | 예 | "1K"<br />"2K" |
| `number_of_images` | 생성할 편집 이미지 수입니다. (기본값: 1) | INT | 예 | 1~10 |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 확장 가능한 슬롯: 편집할 참조 이미지를 1개에서 N개까지 연결합니다. 슬롯은 템플릿 이름 `image_1`, `image_2`, `image_3`을 사용하며, 최대 슬롯 수는 선택한 모델에 따라 달라집니다. | IMAGE | 예 | `grok-imagine-image-pro`의 경우 1개 이미지<br />`grok-imagine-image-2.0`, `grok-imagine-image-quality`, `grok-imagine-image`의 경우 1~3개 이미지 |

**제약 사항:**
- `prompt`에는 공백이 아닌 문자가 1개 이상 포함되어야 합니다.
- 편집에는 참조 이미지가 1개 이상 필요하며, 이미지가 연결되지 않은 경우 노드에서 오류가 발생합니다.
- 최대 입력 이미지 수는 `grok-imagine-image-pro`의 경우 1개이고, `grok-imagine-image-2.0`, `grok-imagine-image-quality`, `grok-imagine-image`의 경우 3개입니다. 모델이 지원하는 수보다 많은 이미지를 연결하면 오류가 발생합니다.
- 이미지 제한은 연결된 입력의 모든 이미지를 계산하므로, 여러 이미지가 포함된 배치는 제한에 여러 이미지로 계산됩니다.
- `grok-imagine-image-quality` 및 `grok-imagine-image`의 경우, 사용자 지정 `aspect_ratio`("auto" 이외의 값)는 여러 이미지가 연결된 경우에만 허용됩니다. 단일 이미지인 경우 `aspect_ratio`는 "auto"여야 합니다.
- `grok-imagine-image-2.0`의 경우, 단일 이미지에서도 `aspect_ratio`를 자유롭게 설정할 수 있습니다.
- `quality` 하위 매개변수는 `grok-imagine-image-2.0`에서만 사용할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | Grok API에서 반환된 편집된 이미지입니다. 단일 이미지가 생성되면 직접 반환됩니다. 여러 이미지가 생성되면 하나의 배치 텐서로 연결됩니다. | IMAGE |
