렌더링된 이미지를 메시의 UV 레이아웃에 다시 투영합니다. Render Mesh로 메시를 렌더링하고, 이미지를 편집하거나 다시 생성한 다음, 동일한 메시와 카메라로 베이크합니다. 어떤 뷰도 덮지 않는 텍셀은 메시 자체의 텍스처 또는 버텍스 색상을 유지합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `mesh` | 렌더링된 UV 언랩 메시입니다. | MESH | 예 | - |
| `images` | 카메라 순서대로 카메라당 이미지 하나입니다(Batch Images). 렌더링의 종횡비와 일치하는 임의 해상도이며, 해상도가 높을수록 더 선명하게 베이크합니다. | IMAGE | 예 | - |
| `camera_info` | 이미지가 렌더링된 카메라이며, Render Mesh에 연결된 것과 같습니다. 리그는 Batch Cameras로 결합합니다. 없음: Render Mesh의 자동 프레이밍된 정면 뷰입니다. | LOAD3D_CAMERA | 아니요 | - |
| `resolution` | 정사각형 텍스처 해상도입니다. 0은 메시의 현재 텍스처 크기를 유지하며, 텍스처가 없으면 2048을 사용합니다. 그 외의 값이면 현재 텍스처가 해당 값으로 리샘플링됩니다. 기본값: 0. | INT | 아니요 | 0 ~ 8192 (단계: 64) |
| `blend_exponent` | 뷰는 cos(뷰 각도)^지수로 가중됩니다. 값이 높을수록 가장 정면에 가까운 뷰를 선호하며(더 선명하고 이음새가 더 뚜렷함), 값이 낮을수록 더 많은 뷰를 평균화합니다(더 부드러움). 기본값: 4.0. | FLOAT | 아니요 | 0.0 ~ 32.0 (단계: 0.5) |
| `fill_unseen` | 어떤 뷰도 보지 못하는 텍셀은 메시 자체의 텍스처나 버텍스 색상 대신, 보이는 표면에서 확장된 색상을 사용합니다. 뷰가 전체 텍스처를 대체할 때 사용하십시오. 기본값: false. | BOOLEAN | 아니요 | true<br />false |
| `mask` | 뷰별 편집 영역입니다. 마스크된 픽셀만 투영됩니다. 단일 마스크는 모든 뷰에 적용됩니다. | MASK | 아니요 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `base_color` | Apply Texture to Mesh에 사용할 베이크된 텍스처입니다. | IMAGE |
| `confidence` | 텍셀별로 가장 좋은 뷰가 얼마나 정면에서 보았는지를 나타냅니다. 0은 보이지 않았음을 의미합니다. | MASK |

참고: 뷰어 모델 변환으로 만든 렌더는 베이크와 정렬되지 않으며, 배치의 첫 번째 메시만 사용됩니다.
