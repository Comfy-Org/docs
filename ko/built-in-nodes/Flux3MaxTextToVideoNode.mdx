FLUX 3 Max Text to Video는 텍스트 프롬프트로부터 동기화된 오디오가 포함된 비디오를 생성합니다. 프롬프트는 렌더링 전에 FLUX 3 Max에 의해 해석되고 확장되며, 노드는 렌더링이 완료될 때까지 기다린 후 완성된 클립을 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 클립이 무엇을 보여주어야 하는지 평이한 언어로 설명합니다. 계층화된 오디오를 위해서는 주변음, 음악, 음성을 각각 따로 설명합니다(기본값: 비어 있음). | STRING | 예 | 여러 줄 텍스트 |
| `aspect_ratio` | 출력 화면 비율입니다. 텍스트 프롬프트의 경우 `"auto"`는 16:9입니다(기본값: `"auto"`). | COMBO | 예 | `"auto"`<br />`"21:9"`<br />`"2:1"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"` |
| `duration` | 클립 길이(초)입니다(기본값: `"5"`). | COMBO | 예 | `"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"`<br />`"11"`<br />`"12"`<br />`"13"`<br />`"14"`<br />`"15"`<br />`"16"`<br />`"17"`<br />`"18"`<br />`"19"`<br />`"20"` |
| `resolution` | 출력 해상도입니다(기본값: `"720p"`). | COMBO | 예 | `"720p"`<br />`"1080p"` |
| `reasoning_level` | 생성 전에 모델이 프롬프트를 얼마나 추론하고 확장할지 설정합니다. `"high"`는 시간이 더 오래 걸리지만 가격은 동일합니다(기본값: `"high"`). | COMBO | 예 | `"low"`<br />`"high"` |
| `generate_audio` | 동기화된 오디오를 생성합니다. 끄면 오디오 트랙이 없는 비디오가 생성됩니다(기본값: true). | BOOLEAN | 예 | `true`<br />`false` |
| `seed` | 노드의 재실행 여부를 제어하는 시드입니다. 이 값과 무관하게 결과는 비결정적입니다(기본값: 42). | INT | 예 | 0  ~  2147483646 |

참고: `prompt`는 최소 한 글자 이상 포함해야 합니다. 표시되는 가격은 `resolution`과 `duration`을 기준으로 하며, 2026년 11월 7일까지는 720p가 초당 $0.060775, 1080p가 초당 $0.103675이고, 그 이후에는 초당 $0.2431 및 $0.4147입니다. 클립의 총 예상 비용은 UI에 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 생성된 비디오 클립입니다. `generate_audio`가 활성화된 경우 동기화된 오디오가 포함됩니다. | VIDEO |
