이미지 생성 또는 텍스트와 이미지가 교차하는 출력을 위해 SenseNova 컨디셔닝을 준비합니다. `task` 선택자는 프롬프트 템플릿과 중지 동작을 설정하며, 노드는 모델이 이미지를 요청하는지 여부를 보고하므로 루프에서 샘플러를 실행할 시점을 알 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip` | SenseNova CLIP 모델입니다. CLIP Text Encode에도 연결하는 CLIP 로더를 연결하고, 인코더 출력은 `conditioning`으로 보냅니다. 들어오는 컨디셔닝이 이미 완료된 경우를 제외하고 모든 작업에 필요합니다. | CLIP | 아니요 | - |
| `conditioning` | CLIP Text Encode에서 가져온 SenseNova 텍스트 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `negative` | 선택적 네거티브 컨디셔닝입니다. `interleave` 및 `self-correction` 작업에서 업데이트되어 반환됩니다. | CONDITIONING | 아니요 | - |
| `task` | 실행할 작업입니다. `"image"`는 표준 샘플러용 프롬프트를 인코딩하고, `"image thinking"`은 모델이 답변하기 전에 사고하도록 하며, `"interleave"`는 텍스트와 이미지를 한 번에 생성하고, `"self-correction"`은 모델이 자신의 이전 출력을 수정하도록 합니다. | DYNAMIC_COMBO | 예 | `"image"`<br />`"image thinking"`<br />`"interleave"`<br />`"self-correction"` |
| `max_tokens` | 이 호출에서 생성되는 최대 토큰 수입니다. 기본값: 1024. | INT | 예 | 1 ~ 8192 |

### `interleave` 입력

이 입력들은 `task`가 `"interleave"`로 설정된 경우 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `thinking` | 모델이 답변하기 전에 사고하도록 합니다. 기본값: True. | BOOLEAN | 예 | True<br />False |
| `samples` | 이전 샘플러 출력으로, 이미지 요청 후 계속할 때 연결합니다. | LATENT | 아니요 | - |

### `self-correction` 입력

이 입력들은 `task`가 `"self-correction"`로 설정된 경우 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `samples` | 이전 샘플러 출력으로, 이미지 요청 후 계속할 때 연결합니다. | LATENT | 아니요 | - |

**제약 사항 및 동작:**

* `clip` 입력은 CLIP Text Encode의 출력(`CONDITIONING`)이 아니라 SenseNova CLIP 모델 자체를 받습니다. `clip`이 없거나 SenseNova CLIP이 아니면 오류가 발생합니다.
* `"image thinking"`에는 정확히 하나의 포지티브 컨디셔닝 항목이 필요합니다. `"interleave"`와 `"self-correction"`에는 포지티브 항목 하나와 네거티브 항목 하나가 필요합니다.
* 모델이 이미지를 기다리고 있을 때는 앞선 샘플러의 LATENT 출력을 `samples`에 연결하십시오. 이미지가 요청되기 전에 샘플을 전달하면 오류가 발생합니다.
* 들어오는 컨디셔닝이 이미 완료된 경우, 노드는 빈 `generated_text`와 False로 설정된 `image_requested`와 함께 이를 변경 없이 반환합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `conditioning` | 이 호출에서 생성된 텍스트로 확장된, 샘플러용 컨디셔닝입니다. | CONDITIONING |
| `generated_text` | 이 호출에서 생성된 텍스트입니다. 완전한 결과를 얻으려면 SenseNova Interleave Decode를 사용하십시오. | STRING |
| `negative` | `interleave` 및 `self-correction` 작업에 대해 업데이트된 네거티브 컨디셔닝입니다. | CONDITIONING |
| `image_requested` | 모델이 이미지를 요청한 경우 True입니다. 샘플러를 실행한 다음 루프를 이 노드로 다시 피드백하십시오. | BOOLEAN |
