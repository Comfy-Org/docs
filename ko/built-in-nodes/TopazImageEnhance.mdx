Topaz Image Enhance 노드는 업계 표준 업스케일링 및 이미지 향상 기능을 제공합니다. 클라우드 기반 AI 모델을 사용하여 단일 입력 이미지를 처리해 품질, 디테일, 해상도를 개선합니다. 이 노드는 창의적 가이드, 피사체 집중, 얼굴 보존을 위한 옵션을 포함하여 향상 과정을 세밀하게 제어할 수 있습니다.

이 노드는 레거시 버전이며 인터페이스에서 사용 중단(deprecated)으로 표시됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 이미지 향상에 사용할 AI 모델입니다. | COMBO | 예 | `"Reimagine"` |
| `image` | 향상할 입력 이미지입니다. 이미지는 한 개만 지원합니다. | IMAGE | 예 | - |
| `prompt` | 창의적 업스케일링 가이드를 위한 선택적 텍스트 프롬프트입니다(기본값: 비어 있음). | STRING | 아니요 | - |
| `subject_detection` | 이미지에서 향상이 집중할 부분을 제어합니다(기본값: "All"). | COMBO | 아니요 | `"All"`<br />`"Foreground"`<br />`"Background"` |
| `face_enhancement` | 처리 중 얼굴이 있는 경우 얼굴을 향상합니다(기본값: True). | BOOLEAN | 아니요 | - |
| `face_enhancement_creativity` | 얼굴 향상의 창의성 수준을 설정합니다(기본값: 0.0). | FLOAT | 아니요 | 0.0 - 1.0 |
| `face_enhancement_strength` | 향상된 얼굴이 배경 대비 얼마나 선명한지 제어합니다(기본값: 1.0). | FLOAT | 아니요 | 0.0 - 1.0 |
| `crop_to_fill` | 기본적으로 출력 종횡비가 다를 때 이미지에 레터박스가 적용됩니다. 출력 크기를 채우도록 이미지를 자르려면 활성화합니다(기본값: False). | BOOLEAN | 아니요 | - |
| `output_width` | 0 값은 자동으로 계산함을 의미합니다(일반적으로 원본 크기 또는 지정된 경우 output_height가 됩니다)(기본값: 0). | INT | 아니요 | 0 - 32000 |
| `output_height` | 0 값은 원본과 같은 높이 또는 output width로 출력함을 의미합니다(기본값: 0). | INT | 아니요 | 0 - 32000 |
| `creativity` | 향상의 전반적인 창의성 수준을 제어합니다(기본값: 3). | INT | 아니요 | 1 - 9 |
| `face_preservation` | 피사체의 얼굴 정체성을 보존합니다(기본값: True). | BOOLEAN | 아니요 | - |
| `color_preservation` | 원본 색상을 보존합니다(기본값: True). | BOOLEAN | 아니요 | - |

**참고:** 이 노드는 입력 이미지를 한 개만 처리할 수 있습니다. 여러 이미지의 배치를 제공하면 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 향상된 출력 이미지입니다. | IMAGE |
