하이폴리 메시에서 앰비언트 오클루전 맵을 베이크하여 로우폴리 메시의 UV 레이아웃에 적용합니다. 출력은 그레이스케일 이미지로, 흰색 텍셀은 열린 영역이고 어두운 텍셀은 틈새입니다. 이 이미지는 Apply Texture To Mesh 노드의 오클루전 입력을 위한 것입니다. UV가 펼쳐진 로우폴리 메시와 그것이 디시메이션된 하이폴리 메시를 연결하십시오.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | UV가 펼쳐진 로우폴리 메시로, 이 메시에 베이크합니다. UV가 있어야 하며, 없으면 노드에서 오류가 발생합니다. | MESH | 예 | - |
| `high_poly` | 로우폴리가 디시메이션된 하이폴리 메시로, 오클루전의 소스 지오메트리로 사용됩니다. | MESH | 예 | - |
| `resolution` | 픽셀 단위의 텍스처 해상도입니다. 각 텍셀은 오클루전 값을 받습니다. 기본값: 1024. | INT | 예 | 64 ~ 8192 (step 64) |
| `samples` | 텍셀당 광선 수입니다. 많을수록 더 부드러워지지만 느려집니다. 입자가 거칠면 값을 늘리십시오. 기본값: 64. | INT | 예 | 4 ~ 1024 (step 4) |
| `max_distance` | 광선 길이로, 경계 상자 대각선의 비율입니다. 작을수록 더 타이트하고 국소적인 오클루전을 생성합니다. 기본값: 0.5. | FLOAT | 예 | 0.01 ~ 2.0 (step 0.01) |
| `strength` | 오클루전을 스케일링합니다. 1보다 크면 어두워지고, 1보다 작으면 밝아집니다. 기본값: 1.0. | FLOAT | 예 | 0.0 ~ 2.0 (step 0.05) |
| `bias` | 표면에서 광선 시작점을 들어 올리는 거리로, 경계 상자 대각선의 비율입니다. 평평한 표면에 어두운 얼룩이나 구멍이 보이면 값을 늘리십시오. 기본값: 0.01. | FLOAT | 예 | 0.0001 ~ 0.2 (step 0.0005) |

참고: `low_poly`에는 UV 좌표가 있어야 합니다. 이 노드는 메시를 언랩하지 않습니다. `high_poly`에 배치 항목이 하나만 포함된 경우 `low_poly`의 모든 배치 항목에 대해 재사용됩니다. 면이 없는 `low_poly`의 배치 항목은 건너뛰고 경고를 로그한 후 모두 흰색 이미지로 대체됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `occlusion` | [0,1] 범위의 값을 가진 그레이스케일 앰비언트 오클루전 이미지입니다(흰색 = 열림, 어두움 = 틈새). `low_poly`의 배치 항목당 하나의 이미지입니다. Apply Texture To Mesh 노드의 오클루전 입력(ORM 맵 / occlusionTexture에 패킹됨)을 위한 것입니다. | IMAGE |
