하이폴리 메시에서 앰비언트 오클루전 맵을 베이크하여 로우폴리 메시의 UV 레이아웃에 기록합니다. 출력은 회색조 이미지로, 흰색 텍셀은 열린 영역을, 어두운 텍셀은 틈새를 나타냅니다. 이는 Apply Texture To Mesh 노드의 occlusion 입력용으로 사용됩니다. UV가 전개된 로우폴리 메시와 그 로우폴리가 디시메이트되기 전의 하이폴리 메시를 연결하세요.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | 베이크 대상이 되는 UV가 전개된 로우폴리 메시입니다. UV가 반드시 있어야 하며, 없을 경우 노드에서 오류를 발생시킵니다. | MESH | 예 | - |
| `high_poly` | 로우폴리가 디시메이트되기 전의 하이폴리 메시로, 오클루전을 계산할 소스 지오메트리로 사용됩니다. | MESH | 예 | - |
| `resolution` | 텍스처 해상도(픽셀)입니다. 각 텍셀에 오클루전 값이 할당됩니다. 기본값: 1024. | INT | 예 | 64 ~ 8192 (64 단위) |
| `samples` | 텍셀당 광선 수입니다. 값이 클수록 더 부드럽지만 느려집니다. 노이즈(그레인)가 보이면 값을 높이세요. 기본값: 64. | INT | 예 | 4 ~ 1024 (4 단위) |
| `max_distance` | 광선 길이로, 바운딩 박스 대각선에 대한 비율입니다. 값이 작을수록 더 좁고 국소적인 오클루전이 됩니다. 기본값: 0.5. | FLOAT | 예 | 0.01 ~ 2.0 (0.01 단위) |
| `strength` | 오클루전을 배율 조정합니다. 1보다 크면 어두워지고, 1보다 작으면 밝아집니다. 기본값: 1.0. | FLOAT | 예 | 0.0 ~ 2.0 (0.05 단위) |
| `bias` | 광선 시작점을 표면에서 띄우는 거리로, 바운딩 박스 대각선에 대한 비율입니다. 평평한 표면에도 어두운 얼룩이나 구멍이 나타나면 값을 높이세요. 기본값: 0.01. | FLOAT | 예 | 0.0001 ~ 0.2 (0.0005 단위) |

참고: `low_poly`에는 UV 좌표가 반드시 있어야 합니다. 이 노드는 메시의 UV를 전개하지 않습니다. `high_poly`에 배치 항목이 하나만 포함된 경우, `low_poly`의 모든 배치 항목에 대해 재사용됩니다. 면이 없는 `low_poly`의 배치 항목은 건너뛰고 전체가 흰색인 이미지로 대체하며, 경고가 로그에 기록됩니다. `low_poly`의 UV가 0~1 범위를 벗어나는 경우 균일하게 범위 안으로 다시 맞추며, 타일/UDIM 방식 레이아웃이 감지되면 경고가 로그에 기록됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `occlusion` | 값이 [0,1] 범위인 회색조 앰비언트 오클루전 이미지입니다(흰색 = 열린 영역, 어두운 색 = 틈새). `low_poly`의 배치 항목마다 이미지 하나가 생성됩니다. Apply Texture To Mesh 노드의 occlusion 입력용입니다(ORM 맵 / occlusionTexture에 패킹됨). | IMAGE |
