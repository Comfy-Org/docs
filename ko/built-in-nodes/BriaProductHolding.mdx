이 노드는 Bria를 사용하여 사람이 제품을 들고 있는 이미지를 생성합니다. 사람의 정체성, 포즈, 배경은 유지하면서 장면을 약 1메가픽셀로 다시 렌더링하므로, 결과 이미지는 입력 사진과 픽셀 단위로 정렬되지 않습니다. 모든 제품 이미지는 동일한 제품을 서로 다른 각도나 단계에서 보여 주는 이미지입니다.

## 입력

`moderation` 선택기를 `"true"`로 설정하면 추가 검열 옵션이 표시됩니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `person_image` | 제품을 들고 있는 사람의 사진입니다. 이미지가 업로드되기 전에 알파 채널이 제거됩니다. | IMAGE | 예 | - |
| `product_images` | 한 제품에 대한 1~3개의 이미지입니다: 제품 자체, 포장, 다른 각도 또는 함께 제공되는 구성품입니다. 배치 입력은 이미지마다 하나씩 계산되며, 투명 영역은 흰색으로 처리됩니다. | AUTOGROW | 예 | 이미지 1~3개 |
| `instruction` | Bria의 기본 제공 지시문에 추가되는 선택적 추가 지시사항입니다. 예를 들어 어느 손을 사용할지 또는 라벨이 어느 방향을 향할지 등을 지정할 수 있습니다. 기본값: `""` (빈 문자열). | STRING | 예 | - |
| `aspect_ratio` | `"auto"`는 사람 사진의 구도를 약 1메가픽셀로 유지합니다. 고정 비율은 0.6~1메가픽셀의 결과를 반환하며, 예를 들어 `"3:4"`의 경우 768x1024입니다. 기본값: `"auto"`. | COMBO | 예 | `"auto"`<br />`"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"` |
| `seed` | 요청과 함께 Bria로 전송되는 시드입니다. 기본값: 42. | INT | 예 | 1~2147483647 |
| `moderation` | 검열 설정입니다. `"true"`로 설정하면 아래의 검열 플래그를 사용할 수 있습니다. | DYNAMIC_COMBO | 예 | `"false"`<br />`"true"` |

### 검열 "true" 입력

이 매개변수는 `moderation`이 `"true"`로 설정된 경우에만 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `visual_output_moderation` | 생성된 이미지에 콘텐츠 검열을 활성화합니다. 기본값: `False`. | BOOLEAN | 아니요 | True / False |

**제약 사항:**

* `product_images`는 최대 3개의 이미지를 허용하며, 입력이 배치인 경우 이미지마다 하나씩 계산됩니다.
* 제품 이미지의 투명 픽셀은 업로드 전에 흰색 위에 합성됩니다.
* `person_image`의 알파 채널은 업로드 전에 제거됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 제품이 사람의 손에 배치된 편집된 사진입니다. | IMAGE |
