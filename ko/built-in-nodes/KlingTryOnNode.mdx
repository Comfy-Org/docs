Kling의 가상 피팅으로 사람에게 의류 아이템을 입힙니다. 사람 사진과 의류 사진을 연결하면, 노드는 해당 사람이 그 아이템을 착용한 새 이미지를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `person_image` | 한 사람의 사진으로, 정면 또는 3/4 측면 뷰가 이상적입니다. 최소 300x300픽셀이어야 하며, 한 변이 2048픽셀을 초과하는 이미지는 먼저 축소됩니다. | IMAGE | 예 | N/A |
| `garment_image` | 입힐 의류: 제품 사진, 평면 배치(flat lay), 마네킹, 또는 모델 착용 사진입니다. 모델 착용 사진은 해당 착장의 나머지 부분도 함께 반영할 수 있습니다. 최소 300x300픽셀이어야 합니다. 의류만 지원되며, 신발, 가방, 액세서리는 지원되지 않습니다. | IMAGE | 예 | N/A |
| `keep_pose` | 더 나은 의상 표현을 위해 포즈가 변경되도록 허용하려면 끄십시오. 고급 매개변수(기본값: True)입니다. | BOOLEAN | 예 | `True`<br />`False` |
| `seed` | 시드는 노드의 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 이 매개변수에는 "생성 후 제어" 기능이 있습니다(기본값: 42). | INT | 예 | 0 ~ 2147483647 |

**참고:** 결과는 `person_image`와 동일한 크기이며, 가장 긴 변이 2048픽셀로 제한됩니다. 두 입력 모두 Kling의 API로 업로드되므로 잠시 시간이 걸릴 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 의류 아이템을 착용한 사람입니다. | IMAGE |
