Quiver Text to SVG 노드는 Quiver AI의 모델을 사용하여 텍스트 설명으로부터 확장 가능한 벡터 그래픽(SVG) 이미지를 생성합니다. 생성 과정을 안내하기 위해 참조 이미지와 스타일 지침을 선택적으로 제공할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 원하는 SVG 출력에 대한 텍스트 설명입니다. 생성할 내용에 대한 주요 지침입니다. | STRING | 예 | N/A |
| `instructions` | 추가 스타일 또는 서식 지침입니다. 선택적이고 고급 매개변수입니다. | STRING | 아니요 | N/A |
| `reference_images` | 생성을 안내하기 위한 최대 4개의 참조 이미지입니다. 선택적 입력입니다. | IMAGE | 아니요 | 0  ~  4 images |
| `model` | SVG 생성에 사용할 모델입니다. 모델을 선택하면 해당 모델에 특화된 추가 매개변수인 `temperature`, `top_p`, `presence_penalty`가 표시됩니다. | DYNAMIC_COMBO | 예 | `"arrow-2"`<br />`"arrow-2-telos"`<br />`"arrow-1.1"`<br />`"arrow-1.1-max"`<br />`"arrow-preview"` |
| `seed` | 노드의 재실행 여부를 결정하는 시드입니다. 실제 결과는 시드와 관계없이 비결정적입니다. 기본값: 0. | INT | 예 | 0  ~  2147483647 |
| `reasoning_effort` | 모델이 그리기 전에 사용하는 추론량입니다. 수준이 높을수록 세부 묘사가 향상되고 더 많은 토큰이 소모됩니다. Arrow 2 모델에서만 사용됩니다(기본값: "high"). | COMBO | 아니요 | `"low"`<br />`"medium"`<br />`"high"`<br />`"xhigh"` |

**참고:** `reference_images` 입력은 최대 4개의 이미지를 허용합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `SVG` | 생성된 확장 가능한 벡터 그래픽(SVG) 이미지입니다. | SVG |
