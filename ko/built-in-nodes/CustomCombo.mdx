Custom Combo 노드를 사용하면 고정된 값 중에서 선택하는 대신 드롭다운 메뉴에 사용할 텍스트 옵션 목록을 직접 정의할 수 있습니다. 이 노드는 프런트엔드 중심 노드이면서 백엔드 표현도 가지고 있어, 이 노드를 포함하는 워크플로가 호환성을 유지합니다. 옵션을 선택하면 노드는 선택한 텍스트와 해당 인덱스 위치를 출력합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `선택` | 사용자 지정 드롭다운에서 선택한 텍스트 옵션입니다. 사용 가능한 옵션 목록은 노드의 프런트엔드 인터페이스에서 사용자가 정의합니다. | COMBO | 예 | 사용자 정의 |
| `index` | 인덱스를 지정하는 데 사용할 수 있는 정수 값입니다. 기본값: 0. | INT | 아니요 | 모든 정수(기본값: 0) |

**참고:** 이 노드의 입력에 대한 유효성 검사는 의도적으로 비활성화되어 있습니다. 이를 통해 백엔드에서 선택한 항목이 미리 정의된 목록과 일치하는지 확인하지 않고도 프런트엔드에서 임의의 사용자 지정 텍스트 옵션을 작성할 수 있습니다. 콤보 드롭다운 이외의 위젯은 프런트엔드에서 완전히 정의됩니다. 이 노드는 실험용으로 표시되어 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `STRING` | 사용자 지정 콤보 상자에서 선택한 옵션의 텍스트 문자열입니다. | STRING |
| `INDEX` | 드롭다운 목록에서 선택한 옵션의 인덱스 위치입니다. | INT |
