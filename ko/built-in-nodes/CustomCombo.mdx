Custom Combo 노드를 사용하면 직접 정의한 텍스트 옵션 목록이 있는 사용자 지정 드롭다운 메뉴를 만들 수 있습니다. 이 노드는 프런트엔드 중심 노드로, 워크플로우 호환성을 유지하기 위해 백엔드 표현을 포함합니다. 드롭다운에서 옵션을 선택하면 노드는 해당 텍스트를 문자열과 해당 인덱스 위치로 출력합니다.

## 입력

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `선택` | 사용자 지정 드롭다운에서 선택한 텍스트 옵션입니다. 사용 가능한 옵션 목록은 사용자가 노드의 프런트엔드 인터페이스에서 정의합니다. | COMBO | 예 | User-defined |
| `index` | 인덱스를 지정하는 데 사용할 수 있는 정수 값입니다. 기본값: 0. | INT | 아니요 | Any integer (default: 0) |

**참고:** 이 노드의 입력에 대한 검증은 의도적으로 비활성화되어 있습니다. 이를 통해 백엔드에서 선택 항목이 사전 정의된 목록과 일치하는지 확인하지 않고 프런트엔드에서 임의의 사용자 지정 텍스트 옵션을 작성할 수 있습니다. 콤보 드롭다운 외의 위젯은 프런트엔드에서 완전히 정의됩니다. 이 노드는 실험적인 것으로 표시되어 있습니다.

## 출력

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `STRING` | 사용자 지정 콤보 상자에서 선택한 옵션의 텍스트 문자열입니다. | STRING |
| `INDEX` | 드롭다운 목록에서 선택한 옵션의 인덱스 위치입니다. | INT |
