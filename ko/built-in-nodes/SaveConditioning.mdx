이 노드는 단일 컨디셔닝을 safetensors 파일로 출력 폴더에 저장합니다. 저장된 파일은 models/embeddings 폴더로 이동할 수 있으며, 나중에 Load Conditioning으로 불러올 수 있습니다. 예를 들어 텍스트 인코더를 건너뛰는 데 사용할 수 있습니다. 이 노드는 컨디셔닝을 변경하지 않고 그대로 전달하므로 워크플로에서 계속 사용할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `conditioning` | 저장할 컨디셔닝입니다. 단일 컨디셔닝 항목만 지원합니다. | CONDITIONING | 예 | - |
| `filename_prefix` | 출력 파일 이름을 구성하는 데 사용되는 접두사입니다. 파일은 숫자 카운터가 뒤에 추가된 상태로 출력 폴더에 기록됩니다. 기본값: `conditioning/ComfyUI` | STRING | 예 | - |

**참고:**

- `conditioning` 입력에 둘 이상의 항목이 포함된 경우(예: 여러 컨디셔닝을 결합한 후), 노드는 "Save Conditioning supports a single conditioning entry, save it before combining." 오류를 발생시킵니다.
- 텐서, 텐서의 리스트/튜플, 불리언, 정수, 부동 소수점 또는 문자열인 컨디셔닝 옵션은 컨디셔닝과 함께 저장됩니다. `None`인 옵션은 건너뜁니다. 다른 옵션 유형은 해당 옵션을 저장할 수 없다는 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `conditioning` | 전달된 것과 동일한 컨디셔닝이며 변경되지 않았습니다. | CONDITIONING |
