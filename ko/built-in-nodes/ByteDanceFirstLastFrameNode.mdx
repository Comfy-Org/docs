이 노드는 텍스트 프롬프트와 첫 번째 및 마지막 프레임 이미지를 사용하여 비디오를 생성합니다. 설명과 두 개의 키 프레임을 입력으로 받아 두 프레임 사이를 전환하는 완전한 비디오 시퀀스를 만듭니다. 이 노드는 비디오의 해상도, 종횡비, 지속 시간 및 기타 생성 매개변수를 제어할 수 있는 다양한 옵션을 제공합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 비디오 생성에 사용되는 모델입니다(기본값: `"seedance-1-5-pro-251215"`). | COMBO | 예 | `"seedance-1-5-pro-251215"`<br />`"seedance-1-0-pro-250528"` |
| `prompt` | 비디오 생성에 사용되는 텍스트 프롬프트입니다. 비어 있어서는 안 되며 예약된 매개변수 키워드(`resolution`, `ratio`, `duration`, `seed`, `camerafixed`, `watermark`)를 포함해서는 안 됩니다. | STRING | 예 | - |
| `first_frame` | 비디오에 사용할 첫 번째 프레임입니다. 300x300픽셀과 6000x6000픽셀 사이여야 하며 종횡비는 0.4와 2.5 사이여야 합니다. | IMAGE | 예 | - |
| `last_frame` | 비디오에 사용할 마지막 프레임입니다. 300x300픽셀과 6000x6000픽셀 사이여야 하며 종횡비는 0.4와 2.5 사이여야 합니다. | IMAGE | 예 | - |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `aspect_ratio` | 출력 비디오의 종횡비입니다. | COMBO | 예 | `"adaptive"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"` |
| `duration` | 출력 비디오의 지속 시간(초)입니다. `seedance-1-5-pro-251215`를 사용할 때 최소 지속 시간은 4초입니다. (기본값: 5) | INT | 예 | 3 - 12 |
| `seed` | 생성에 사용할 시드입니다. (기본값: 0) | INT | 아니요 | 0 - 2147483647 |
| `camera_fixed` | 카메라를 고정할지 여부를 지정합니다. 플랫폼은 프롬프트에 카메라 고정 지침을 추가하지만 실제 효과를 보장하지는 않습니다. (기본값: False) | BOOLEAN | 아니요 | - |
| `watermark` | 비디오에 "AI generated" 워터마크를 추가할지 여부입니다. (기본값: False) | BOOLEAN | 아니요 | - |
| `generate_audio` | 이 매개변수는 `seedance-1-5-pro-251215`를 제외한 모든 모델에서 무시됩니다. (기본값: False) | BOOLEAN | 아니요 | - |

**참고:** `seedance-1-5-pro-251215` 모델의 경우 `duration`은 4초 이상이어야 합니다. `first_frame`과 `last_frame`은 모두 300x300~6000x6000픽셀 사이여야 하며 종횡비가 0.4~2.5 사이여야 합니다. `prompt`는 예약된 매개변수 키워드가 포함되어 있는지 확인되며, 포함된 경우 거부됩니다.
