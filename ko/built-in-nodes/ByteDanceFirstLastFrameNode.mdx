# ByteDance 첫 번째-마지막 프레임을 비디오로 변환

이 노드는 텍스트 프롬프트와 이미지의 첫 번째 및 마지막 프레임을 사용하여 비디오를 생성합니다. 두 프레임 간의 원활한 전환을 통해 완전한 비디오 시퀀스를 생성합니다. 이 노드는 비디오의 해상도, 비율, 지속 시간 및 추가 생성 매개변수를 사용자 정의할 수 있는 다양한 옵션을 제공합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성을 위해 사용할 모델. 사용 가능한 옵션 중 선택하세요 (기본: `"seedance-1-5-pro-251215"`). | COMBO | 예 | `"seedance-1-5-pro-251215"`<br />`"seedance-1-0-pro-250528"` |
| `prompt` | 비디오 생성을 위해 사용할 텍스트 프롬프트. 이 프롬프트는 해상도, 비율, 지속 시간, 시드, 카메라 고정, 워터마크와 같은 특정 매개변수를 포함하지 않아야 합니다. | STRING | 예 | - |
| `first_frame` | 비디오에 사용할 첫 번째 프레임. 이미지는 300x300에서 6000x6000 픽셀 사이이며, 비율은 0.4에서 2.5 사이여야 합니다. | IMAGE | 예 | - |
| `last_frame` | 비디오에 사용할 마지막 프레임. 이미지는 300x300에서 6000x6000 픽셀 사이이며, 비율은 0.4에서 2.5 사이여야 합니다. | IMAGE | 예 | - |
| `resolution` | 출력 비디오의 해상도. 사용 가능한 옵션 중 선택하세요 (기본: `"480p"`). | COMBO | 예 | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `aspect_ratio` | 출력 비디오의 비율. 사용 가능한 옵션 중 선택하세요 (기본: `"adaptive"`). | COMBO | 예 | `"adaptive"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"` |
| `duration` | 출력 비디오의 지속 시간(초)(기본: 5). `seedance-1-5-pro-251215` 모델의 경우 최소 지원 지속 시간은 4초입니다. | INT | 예 | 3 - 12 |
| `seed` | 생성에 사용할 시드(기본: 0). 이 매개변수는 선택 사항입니다. | INT | 아님 | 0 - 2147483647 |
| `camera_fixed` | 비디오에서 카메라를 고정할지 여부를 지정합니다. 플랫폼은 프롬프트에 카메라 고정 명령을 추가하지만, 실제 효과는 보장되지 않습니다(기본: False). | BOOLEAN | 아님 | - |
| `watermark` | 비디오에 "AI 생성" 워터마크를 추가할지 여부를 결정합니다(기본: False). | BOOLEAN | 아님 | - |
| `generate_audio` | 이 매개변수는 모든 모델에서 `seedance-1-5-pro-251215` 모델을 제외하고 무시됩니다(기본: False). | BOOLEAN | 아님 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오 파일. | VIDEO |

## 주의사항

- `model` 매개변수는 비디오 생성 과정의 기능과 제한을 결정합니다.
- `prompt`은 창의적이고 명확해야 하며, 비디오 생성을 안내합니다.
- `first_frame` 및 `last_frame` 이미지는 원하는 비디오 내용을 대표해야 합니다.
- `resolution` 및 `aspect_ratio` 매개변수는 최종 출력 비디오의 품질과 크기를 영향을 미칩니다.
- `duration` 매개변수는 비디오의 길이를 설정하며, 최소 3초에서 최대 12초입니다.
- `seed` 매개변수는 선택 사항이며, 비디오 생성 과정의 재현성을 위해 사용할 수 있습니다.
- `camera_fixed` 매개변수는 고급 옵션으로, 항상 예상한 효과를 얻을 수는 없습니다.
- `watermark` 매개변수는 비디오에 워터마크를 추가하여 AI에 의해 생성된 것을 표시할 수 있습니다.
- `generate_audio` 매개변수는 현재 모든 모델에서 `seedance-1-5-pro-251215` 모델을 제외하고 무시됩니다.
