이 노드는 OpenAI 모델에서 텍스트 응답을 생성합니다. 텍스트 프롬프트와 선택적으로 이미지나 파일을 본문으로 사용하여 이 정보를 OpenAI 모델에 전달하여 텍스트 응답을 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 모델에 입력되는 텍스트, 응답을 생성하는 데 사용됩니다. 이는 모델이 응답하려는 텍스트입니다. | STRING | 예 | - |
| `컨텍스트 유지` | 이 매개변수는 폐지되었으며 영향을 미치지 않습니다. 후속 호환성을 위해 포함되었지만 노드의 동작에 영향을 미치지 않습니다. | BOOLEAN | 아님 | - |
| `모델` | 응답을 생성하는 데 사용되는 모델. 사용 가능한 OpenAI 모델 중 하나를 선택합니다. | COMBO | 예 | gpt-6-astra<br />gpt-5.6-sol<br />gpt-5.6-terra<br />gpt-5.6-luna<br />gpt-5.5-pro<br />gpt-5.5<br />gpt-5<br />gpt-5-mini<br />gpt-5-nano<br />gpt-4.1<br />gpt-4.1-mini<br />gpt-4.1-nano<br />o4-mini<br />o3<br />o1-pro<br />o1 |
| `이미지` | 모델에 본문으로 사용할 선택적 이미지. 여러 이미지를 포함하려면 Batch Images 노드를 사용할 수 있습니다. | IMAGE | 아님 | - |
| `파일` | 모델에 본문으로 사용할 선택적 파일. OpenAI Chat Input Files 노드에서 입력을 받습니다. | OPENAI_INPUT_FILES | 아님 | - |
| `고급 옵션` | 모델에 대한 선택적 구성. OpenAI Chat Advanced Options 노드에서 입력을 받습니다. | OPENAI_CHAT_CONFIG | 아님 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output_text` | OpenAI 모델에서 생성된 텍스트 응답. 이는 입력 프롬프트와 본문에 기반한 생성된 텍스트입니다. | STRING |

## 주의사항

- `persist_context` 매개변수는 폐지되었으며 영향을 미치지 않습니다. 후속 호환성을 위해 포함되었지만 사용하지 말아야 합니다.
- `images` 입력은 모델에 추가적인 본문을 제공할 수 있습니다. 여러 이미지를 제공하려면 Batch Images 노드를 사용해야 합니다.
- `files` 입력은 파일 형태로 추가적인 본문을 제공할 수 있습니다. 이 파일들은 OpenAI Chat Input Files 노드에서 연결되어야 합니다.
- `advanced_options` 입력은 모델의 동작을 더 상세히 구성할 수 있습니다. 이는 OpenAI Chat Advanced Options 노드에서 연결되어야 합니다.
- 이 노드를 사용하는 비용은 선택된 모델에 따라 다릅니다. 비용은 모델이 사용하는 토큰 수에 따라 계산됩니다. 정확한 비용은 노드의 UI에서 표시됩니다.
```
