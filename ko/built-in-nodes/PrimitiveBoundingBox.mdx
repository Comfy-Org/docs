PrimitiveBoundingBox 노드는 위치와 크기로 정의된 단순한 사각형 영역을 생성합니다. 왼쪽 상단 모서리의 X 및 Y 좌표와 너비 및 높이 값을 입력받아, 워크플로우의 다른 노드에서 사용할 수 있는 경계 상자 데이터 구조를 출력합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `x` | 경계 상자의 왼쪽 상단 모서리에 대한 X 좌표입니다 (기본값: 0). | INT | 예 | 0 ~ 16384 |
| `y` | 경계 상자의 왼쪽 상단 모서리에 대한 Y 좌표입니다 (기본값: 0). | INT | 예 | 0 ~ 16384 |
| `너비` | 경계 상자의 너비입니다 (기본값: 512). | INT | 예 | 1 ~ 16384 |
| `높이` | 경계 상자의 높이입니다 (기본값: 512). | INT | 예 | 1 ~ 16384 |

참고: 모든 최대값은 ComfyUI의 MAX_RESOLUTION 상수를 따르며, 이 상수는 노드가 허용하는 최대 이미지 크기를 정의합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `bounding_box` | 정의된 사각형의 `x`, `y`, `width`, `height` 속성을 포함하는 데이터 구조입니다. | BOUNDING_BOX |
