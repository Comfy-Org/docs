이 노드는 Boogu를 사용한 이미지 편집을 위한 컨디셔닝을 준비합니다. 참조 이미지를 처리하여 긍정 및 부정 컨디셔닝 출력을 모두 생성합니다. 참조 이미지는 두 번 사용됩니다. 이미지의 비전 토큰은 편집 명령을 증폭하기 위해 긍정 컨디셔닝에만 추가되는 반면, VAE 참조 잠재 변수는 긍정 및 부정 컨디셔닝 모두에 추가되어 CFG 하에서 상쇄되어 원본 이미지의 정체성을 보존합니다. 토크나이저는 이미지 존재 여부와 빈 부정 프롬프트에 따라 적절한 시스템 프롬프트를 자동으로 선택합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 텍스트 인코딩에 사용되는 CLIP 모델 | CLIP | 예 | |
| `프롬프트` | 원하는 편집을 설명하는 텍스트 프롬프트. 여러 줄 텍스트와 동적 프롬프트를 지원합니다. | STRING | 예 | |
| `네거티브 프롬프트` | 편집에서 피해야 할 내용을 설명하는 텍스트 프롬프트. 비워 두면 부정 컨디셔닝을 제외할 수 있습니다. 고급 매개변수. | STRING | 예 | |
| `vae` | 참조 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델. 컨디셔닝 출력에 참조 잠재 변수를 추가하는 데 필요합니다. | VAE | 아니요 | |
| `이미지` | 편집할 참조 이미지입니다. Boogu는 샘플당 하나의 참조 이미지에 초점을 맞춥니다. 더 많은 이미지도 허용됩니다. | IMAGE | 아니요 | 최대 16개 이미지 |
참조 잠재 변수는 `vae`가 참조 `image` 하나 이상과 함께 제공된 경우에만 두 컨디셔닝 출력 모두에 추가됩니다. `vae`가 생략되면 긍정 출력은 참조 이미지의 비전 토큰을 계속 받지만, 두 출력 모두 참조 잠재 변수를 포함하지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 비전 토큰이 포함된 텍스트 프롬프트와 참조 잠재값을 모두 포함하는 컨디셔닝 | CONDITIONING |
| `negative` | 부정 텍스트 프롬프트와 참조 잠재값을 포함하는 컨디셔닝 | CONDITIONING |
