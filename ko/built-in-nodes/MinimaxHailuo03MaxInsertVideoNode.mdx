이 노드는 비디오의 시작 시간과 재개 시간 사이 구간을 프롬프트와 선택적 참조 이미지 및 비디오를 바탕으로 새로 생성된 장면으로 교체합니다. 원본 비디오는 `start_time`에서 잘리고 `resume_time`에서 재개되며, 제거된 구간이 다시 생성되어 이어 붙여집니다. 특정 샷을 수정하거나 동작을 교체하거나, 클립의 두 부분을 연결할 때 사용합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 비디오 생성에 사용할 모델입니다. | DYNAMIC_COMBO | 예 | "MiniMax H3 Max" |

### MiniMax H3 Max 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `video` | 원본 비디오이며 최대 60초 길이입니다. 가로세로 비율은 0.4에서 2.5 사이여야 합니다. | VIDEO | 예 | 0~60초 |
| `reference_images` | 확장 가능한 슬롯: 새 장면을 위한 선택적 참조 이미지를 최대 9개(`image_1`...`image_9`)까지 연결할 수 있으며, 각 이미지는 최소 256x256 픽셀이어야 합니다. 프롬프트에서는 연결 순서에 따라 `@Image1`..`@Image9`로 참조됩니다. | IMAGE | 아니요 | 0~9개 이미지 |
| `reference_videos` | 확장 가능한 슬롯: 새 장면을 위한 선택적 참조 비디오를 최대 3개(`video_1`...`video_3`)까지 연결할 수 있으며, 각각 2~15초, 전체 합계 15초 이하여야 합니다. 프롬프트에서는 연결 순서에 따라 `@Video1`..`@Video3`로 참조됩니다. | VIDEO | 아니요 | 0~3개 비디오 |
| `prompt` | 새 장면에 대한 설명입니다. 프롬프트 또는 최소 하나의 참조가 필요하며, 프롬프트 없이 참조만 사용하는 경우 무시되는 경우가 많습니다. | STRING | 예 | 0~50000자 |
| `start_time` | 원본 비디오가 멈추고 새 장면이 시작되는 초 단위 지점입니다(기본값: 2.0). | FLOAT | 예 | 1.625~60.0 |
| `resume_time` | 새 장면 이후 원본 비디오가 재개되는 초 단위 지점입니다(기본값: 3.0). `start_time` 이후여야 하며 비디오 끝에서 최소 1.375초 전이어야 합니다. `start_time`과 `resume_time` 사이의 원본 구간은 제거됩니다. | FLOAT | 예 | 1.625~60.0 |
| `duration` | 새 장면의 길이(초)입니다(기본값: 5). | INT | 예 | 5~13 |
| `resolution` | 출력 비디오의 해상도입니다(기본값: "768P"). | COMBO | 예 | "480P"<br />"768P" |
| `color_match` | 새 장면의 색상을 원본 비디오에 맞춥니다(기본값: true). | BOOLEAN | 아니요 | true<br />false |
| `prompt_expansion` | 원본 비디오를 사용하여 프롬프트를 재작성합니다. 동일한 시드에 대해 재현 가능한 결과를 얻으려면 끄십시오(기본값: true). | BOOLEAN | 아니요 | true<br />false |
| `seed` | 무작위 시드입니다. 동일한 시드로 동일한 요청을 보내면 유사하지만 반드시 동일하지는 않은 결과가 생성됩니다(기본값: 42). | INT | 예 | 0~2147483647 |

### 매개변수 제약

- `resume_time`은 `start_time`보다 커야 하며 비디오 끝에서 최소 1.375초 전이어야 합니다. 그렇지 않으면 요청이 거부됩니다.
- 각 참조 비디오는 2~15초 길이여야 하며, 모든 참조 비디오의 합계는 15초를 초과할 수 없습니다.
