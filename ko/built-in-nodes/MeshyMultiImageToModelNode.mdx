이 노드는 Meshy API를 사용하여 여러 입력 이미지에서 3D 모델을 생성합니다. 제공된 이미지를 업로드하고 처리 작업을 제출한 후, 참조를 위해 결과 3D 모델 파일(GLB 및 FBX)을 작업 ID와 함께 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 사용할 AI 모델 버전을 지정합니다. | COMBO | 예 | `"meshy-7"`<br />`"meshy-6"`<br />`"latest"` |
| `should_remesh` | 생성된 메시가 처리되는지 여부를 결정합니다. `"false"`로 설정하면 노드가 처리되지 않은 삼각형 메시를 반환합니다. `"true"`로 설정하면 아래의 리메시 설정이 표시됩니다. | DYNAMIC_COMBO | 예 | `"true"`<br />`"false"` |
| `symmetry_mode` | 생성된 모델에 대칭 적용 여부를 제어합니다. | COMBO | 예 | `"auto"`<br />`"on"`<br />`"off"` |
| `should_texture` | 텍스처 생성 여부를 결정합니다. `"false"`로 설정하면 텍스처 단계를 건너뛰고 텍스처가 없는 메시를 반환합니다. `"true"`로 설정하면 아래의 텍스처 설정이 표시됩니다. | DYNAMIC_COMBO | 예 | `"true"`<br />`"false"` |
| `pose_mode` | 생성된 모델의 포즈 모드를 지정합니다. | COMBO | 예 | `""` (빈 값)<br />`"A-pose"`<br />`"T-pose"` |
| `seed` | 시드는 노드가 다시 실행될지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. (기본값: 0) | INT | 예 | 0 ~ 2147483647 |

### 리메시 설정 (`should_remesh`가 `"true"`일 때 표시됨)

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `topology` | 리메시 출력의 목표 폴리곤 유형입니다. | COMBO | 아니요 | `"triangle"`<br />`"quad"` |
| `target_polycount` | 리메시 모델의 목표 폴리곤 수입니다 (기본값: 300000). | INT | 아니요 | 100 ~ 300000 |

### 텍스처 설정 (`should_texture`가 `"true"`일 때 표시됨)

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `enable_pbr` | 기본 색상 외에 PBR 맵(금속성, 거칠기, 법선)을 생성합니다. (기본값: False) | BOOLEAN | 아니요 | True / False |
| `texture_prompt` | 텍스처링 과정을 안내하는 텍스트 프롬프트를 제공합니다. 최대 600자입니다. `texture_image`와 동시에 사용할 수 없습니다. (기본값: 빈 값) | STRING | 아니요 | 최대 600자 |
| `texture_image` | `texture_image` 또는 `texture_prompt` 중 하나만 동시에 사용할 수 있습니다. | IMAGE | 아니요 | - |
| `texture_resolution` | 기본 색상 텍스처 해상도입니다. 해상도가 높을수록 더 많은 표면 디테일을 포착합니다. | COMBO | 아니요 | `"2k"`<br />`"4k"`<br />`"8k"` |

### 이미지 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `images` | 확장 가능 슬롯: 2~4개의 입력 이미지(`image_1`, `image_2`, `image_3`, `image_4`)를 연결합니다. 이 이미지들은 3D 모델 생성에 사용됩니다. | IMAGE | 예 | 2~4개 이미지 |

**참고 사항**

* `images` 입력에는 2~4개의 이미지를 반드시 제공해야 합니다.
* `topology` 및 `target_polycount` 매개변수는 `should_remesh`가 `"true"`로 설정된 경우에만 활성화됩니다.
* `enable_pbr`, `texture_prompt`, `texture_image`, `texture_resolution` 매개변수는 `should_texture`가 `"true"`로 설정된 경우에만 활성화됩니다.
* `texture_prompt`와 `texture_image`는 상호 배타적이므로 동시에 사용할 수 없습니다. `texture_prompt`는 600자로 제한됩니다.
* `seed` 값은 결과를 결정적으로 만들지 않습니다. 값을 변경하면 단순히 노드가 생성 작업을 다시 실행하게 됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `model_file` | 생성된 GLB 모델의 파일 이름입니다. 이 출력은 이전 버전과의 호환성을 위해서만 제공됩니다. | STRING |
| `meshy_task_id` | Meshy API 작업의 고유 식별자입니다. | MESHY_TASK_ID |
| `GLB` | GLB 형식으로 생성된 3D 모델입니다. | FILE3DGLB |
| `FBX` | FBX 형식으로 생성된 3D 모델입니다. | FILE3DFBX |
