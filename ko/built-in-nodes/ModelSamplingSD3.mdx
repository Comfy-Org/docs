ModelSamplingSD3 노드는 Stable Diffusion 3 샘플링 매개변수를 모델에 적용합니다. `shift` 매개변수를 조정하여 모델의 샘플링 동작을 수정하며, 이는 샘플링 분포 특성을 제어합니다. 이 노드는 지정된 샘플링 구성이 적용된 입력 모델의 수정된 복사본을 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | SD3 샘플링 매개변수를 적용할 입력 모델 | MODEL | 예 | - |
| `시프트` | 샘플링 이동 매개변수를 제어합니다 (기본값: 3.0) | FLOAT | 예 | 0.0 - 100.0 (단계: 0.01) |

참고: 이 노드는 `shift` 값을 고정 내부 승수 1000으로 적용합니다. 원본 모델에 노이즈 스케일 설정이 있는 경우 수정된 모델에서도 유지됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | SD3 샘플링 매개변수가 적용된 수정된 모델 | MODEL |
