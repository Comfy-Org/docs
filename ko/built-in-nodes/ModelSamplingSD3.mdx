이 노드는 모델에 Stable Diffusion 3 스타일 샘플링 설정을 적용합니다. 모델의 복사본을 만들어 해당 샘플링 방식을 지정된 `shift` 값을 사용하는 흐름 기반(flow-based) 샘플링 구성으로 대체하며, 이 값은 샘플링 분포의 형태를 제어합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | SD3 샘플링 매개변수를 적용할 입력 모델 | MODEL | 예 | - |
| `시프트` | 샘플링 시프트 매개변수를 제어합니다 (기본값: 3.0) | FLOAT | 예 | 0.0 - 100.0 (단계: 0.01) |

참고: `shift` 값은 고정된 내부 배수 1000과 함께 적용됩니다. 원본 모델에 노이즈 스케일 설정이 있는 경우 해당 값은 수정된 모델로 이어집니다. 원본 모델은 변경되지 않으며, 복제 및 패치된 복사본이 반환됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | SD3 샘플링 매개변수가 적용된 수정된 모델 | MODEL |
