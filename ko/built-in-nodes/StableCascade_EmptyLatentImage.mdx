StableCascade_EmptyLatentImage 노드는 Stable Cascade 모델용 빈 잠재 텐서를 생성합니다. 이 노드는 입력 해상도와 압축 설정으로부터 계산된 차원으로 두 개의 별도 잠재 표현을 생성합니다. 하나는 스테이지 C용이고 다른 하나는 스테이지 B용입니다. 이 노드는 Stable Cascade 생성 파이프라인의 시작점을 제공합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `너비` | 출력 이미지의 너비(픽셀)입니다(기본값: 1024, 단계: 8). | INT | 예 | 256 ~ MAX_RESOLUTION |
| `높이` | 출력 이미지의 높이(픽셀)입니다(기본값: 1024, 단계: 8). | INT | 예 | 256 ~ MAX_RESOLUTION |
| `압축` | 스테이지 C의 잠재 차원을 결정하는 압축 계수입니다(기본값: 42, 단계: 1). 이는 고급 매개변수입니다. | INT | 예 | 4 ~ 128 |
| `배치 크기` | 배치에서 생성할 잠재 샘플 수입니다(기본값: 1). | INT | 예 | 1 ~ 4096 |

참고: `compression` 값은 스테이지 C 잠재 크기를 제어합니다. 높이와 너비는 입력 `height`와 `width`를 `compression`으로 나눈 값입니다. 스테이지 B 잠재는 항상 고정 압축 4를 사용합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `stage_c` | 차원이 [batch_size, 16, height//compression, width//compression]인 스테이지 C 잠재 텐서입니다. | LATENT |
| `stage_b` | 차원이 [batch_size, 4, height//4, width//4]인 스테이지 B 잠재 텐서입니다. | LATENT |
