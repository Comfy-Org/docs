StableCascade_EmptyLatentImage 노드는 Stable Cascade 모델용 빈 잠재 텐서를 생성합니다. 입력 해상도와 압축 설정에 따라 적절한 차원을 가진 두 개의 개별 잠재 표현(하나는 stage C용, 다른 하나는 stage B용)을 생성합니다. 이 노드는 Stable Cascade 생성 파이프라인의 시작점을 제공합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `너비` | 출력 이미지의 너비(픽셀 단위) (기본값: 1024, 증가 단위: 8) | INT | 예 | 256 to MAX_RESOLUTION |
| `높이` | 출력 이미지의 높이(픽셀 단위) (기본값: 1024, 증가 단위: 8) | INT | 예 | 256 to MAX_RESOLUTION |
| `압축` | stage C의 잠재 차원을 결정하는 압축 계수 (기본값: 42, 증가 단위: 1). 고급 매개변수입니다. | INT | 예 | 4 ~ 128 |
| `배치 크기` | 배치에서 생성할 잠재 샘플 수 (기본값: 1) | INT | 아니요 | 1 ~ 4096 |

참고: `compression` 값은 stage C 잠재 표현의 크기를 제어합니다. stage C의 높이와 너비는 입력 `height` 및 `width`를 `compression`으로 나눈 값입니다. stage B 잠재 표현은 항상 고정 압축 계수 4를 사용합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `StageC 잠재 이미지` | 형태가 [batch_size, 16, height//compression, width//compression]인 stage C 잠재 텐서 | LATENT |
| `StageB 잠재 이미지` | 형태가 [batch_size, 4, height//4, width//4]인 stage B 잠재 텐서 | LATENT |
