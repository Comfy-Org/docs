입력 이미지의 영역에서 추출할 대상(벽, 바닥, 직물 등)을 지정하는 프롬프트를 사용하여 이음새 없이 타일링되는 PBR 재질을 추출합니다. 추출된 기본 텍스처와 최대 5개의 재질 맵을 반환하며, 선택적으로 SeedVR을 사용해 맵을 업스케일링합니다. 실제 표면 사진을 재사용 가능한 타일링 재질로 변환하는 데 사용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 텍스처를 추출할 이미지입니다. | IMAGE | 예 | - |
| `prompt` | 이미지에서 추출할 텍스처에 대한 설명입니다. 예: `"the wall"`. | STRING | 예 | 여러 줄 텍스트 |
| `image_size` | 출력 텍스처 크기입니다. `"custom"` 선택 시 `width` 및 `height` 입력이 표시됩니다. 기본값: `"1:1 (1024x1024)"`. | DYNAMIC_COMBO | 예 | `"1:1 (1024x1024)"`<br />`"1:1 (512x512)"`<br />`"4:3 (1024x768)"`<br />`"3:4 (768x1024)"`<br />`"16:9 (1024x576)"`<br />`"9:16 (576x1024)"`<br />`"custom"` |
| `basecolor` | basecolor(알베도) 맵을 생성합니다. 기본값: True. | BOOLEAN | 예 | true<br />false |
| `normal` | 노멀 맵을 생성합니다. 기본값: True. | BOOLEAN | 예 | true<br />false |
| `roughness` | 러프니스 맵을 생성합니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `metalness` | 메탈니스 맵을 생성합니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `height` | 높이(디스플레이스먼트) 맵을 생성합니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `upscale_factor` | PBR 맵의 이음새 없는 SeedVR 업스케일링입니다. 기본 텍스처는 업스케일링되지 않으며, 4x는 2048픽셀 맵을 8K 맵으로 변환합니다. 기본값: 0(꺼짐). | INT | 예 | 0  ~  4 (단계: 2) |
| `seed` | 재현 가능한 생성을 위한 시드입니다. 기본값: 42. | INT | 예 | 0  ~  2147483646 |
| `strength` | 입력 이미지를 얼마나 변형할지 지정합니다. 고급 설정입니다. 기본값: 0.6. | FLOAT | 예 | 0.01  ~  1.0 (단계: 0.01) |
| `tiling_mode` | 타일링 방향: 전방향, 수평 또는 수직입니다. 고급 설정입니다. 기본값: `"both"`. | COMBO | 예 | `"both"`<br />`"horizontal"`<br />`"vertical"` |
| `num_inference_steps` | 텍스처 생성을 위한 디노이징 단계입니다. 고급 설정입니다. 기본값: 8. | INT | 예 | 1  ~  8 |
| `tile_size` | 잠재 공간에서의 타일 크기입니다. 64는 512픽셀, 128은 1024픽셀을 의미합니다. 고급 설정입니다. 기본값: 128. | INT | 예 | 32  ~  256 (단계: 2) |
| `tile_stride` | 잠재 공간에서의 타일 스트라이드입니다. 고급 설정입니다. 기본값: 64. | INT | 예 | 16  ~  128 (단계: 2) |
| `prompt_expansion` | 더 풍부한 텍스처 디테일을 위해 언어 모델로 프롬프트를 확장합니다. 기본적으로 꺼져 있습니다. 확장은 프롬프트를 사진으로 재구성하는 경향이 있어 메탈니스 맵을 흐릿하게 만들 수 있기 때문입니다. 고급 설정입니다. | BOOLEAN | 예 | true<br />false |
| `safety_checker` | 요청에 대해 제공자의 콘텐츠 안전 검사를 실행합니다. 고급 설정입니다. 기본값: False. | BOOLEAN | 예 | true<br />false |

### 사용자 지정 이미지 크기 입력

이 입력들은 `image_size`가 `"custom"`으로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | 텍스처 너비(픽셀)입니다. 기본값: 1024. | INT | 예 | 512  ~  2048 (단계: 16) |
| `image_size.height` | 텍스처 높이(픽셀)입니다. 기본값: 1024. | INT | 예 | 512  ~  2048 (단계: 16) |

**제약 사항 및 동작:**

* 재질 맵을 하나도 활성화하지 않는 것이 허용됩니다. 이 경우 노드는 기본 텍스처만 반환하며, 모든 맵 출력은 1x1 자리 표시자로 유지됩니다.
* 프롬프트는 필수이며 비어 있으면 안 됩니다. 추출할 영역을 가능한 한 정확하게 지정해야 합니다.
* 8K 결과는 단일 8K 생성이 아니라 2048픽셀 렌더의 맵을 4x 업스케일링한 결과입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `texture` | 추출된 기본 텍스처로, 어떤 맵도 적용되지 않은 상태입니다. | IMAGE |
| `basecolor` | basecolor(알베도) 맵이며, 해당 맵이 비활성화된 경우 1x1 자리 표시자입니다. | IMAGE |
| `normal` | 노멀 맵이며, 해당 맵이 비활성화된 경우 1x1 자리 표시자입니다. | IMAGE |
| `roughness` | 러프니스 맵이며, 해당 맵이 비활성화된 경우 1x1 자리 표시자입니다. | IMAGE |
| `metalness` | 메탈니스 맵이며, 해당 맵이 비활성화된 경우 1x1 자리 표시자입니다. | IMAGE |
| `height` | 높이(디스플레이스먼트) 맵이며, 해당 맵이 비활성화된 경우 1x1 자리 표시자입니다. | IMAGE |
| `expanded_prompt` | 제공자가 실제로 사용한 프롬프트로, `prompt_expansion`이 활성화된 경우에만 입력과 다릅니다. | STRING |
