Cosmos Predict2 이미지-투-비디오 워크플로를 위한 비디오 latent를 생성합니다. 이 노드는 지정된 크기와 길이의 빈 비디오 latent를 생성하거나, 인코딩된 시작 및/또는 종료 이미지를 시퀀스에 삽입하여 생성 중 해당 프레임이 유지되도록 할 수 있습니다. 제공된 이미지는 요청된 `width`와 `height`로 크기가 조정되고, 제공된 VAE로 인코딩된 후 latent 시퀀스의 시작 및/또는 끝에 배치됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `vae` | 시작 및 종료 이미지를 latent 공간으로 인코딩하는 데 사용되는 VAE 모델 | VAE | 예 | - |
| `width` | 출력 비디오의 너비(픽셀)입니다. (기본값: 848, 16의 배수여야 합니다) | INT | 예 | 16 ~ MAX_RESOLUTION |
| `height` | 출력 비디오의 높이(픽셀)입니다. (기본값: 480, 16의 배수여야 합니다) | INT | 예 | 16 ~ MAX_RESOLUTION |
| `length` | 비디오 시퀀스의 프레임 수입니다. (기본값: 93) | INT | 예 | 1 ~ MAX_RESOLUTION |
| `batch_size` | 생성할 비디오 시퀀스 수입니다. (기본값: 1) | INT | 예 | 1 ~ 4096 |
| `start_image` | 비디오 시퀀스의 선택적 시작 이미지입니다. | IMAGE | 아니요 | - |
| `end_image` | 비디오 시퀀스의 선택적 종료 이미지입니다. | IMAGE | 아니요 | - |

**참고:** `start_image`와 `end_image`가 모두 제공되지 않으면, 이 노드는 요청된 크기와 길이의 빈 latent를 반환합니다. 하나 또는 두 이미지가 제공되면 `width`와 `height`로 크기가 조정되고, `vae`로 인코딩되며, latent 시퀀스의 시작 및/또는 끝에 배치됩니다. 해당 영역은 생성 중 보존되도록 노이즈 마스크에 표시됩니다. 인코딩된 latent는 Wan 2.1 latent 형식으로 변환되며, 결과 latent와 마스크는 `batch_size`번 반복됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `LATENT` | 생성된 비디오 latent로, `samples`(비디오 latent 시퀀스)를 포함하며, `start_image` 또는 `end_image` 중 하나 이상이 제공된 경우 생성 중 보존해야 할 프레임을 표시하는 `noise_mask`도 포함합니다 | LATENT |
