## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 이미지를 생성하거나 편집하기 위한 텍스트 프롬프트입니다. 공백을 제거한 뒤 비어 있으면 안 됩니다. | STRING | 예 | 여러 줄 텍스트 |
| `모델` | 사용할 Seedream 모델을 선택합니다. 각 모델은 아래에 설명된 자체 하위 매개변수와 제한을 제공합니다. | DYNAMIC_COMBO | 예 | "seedream 5.0 pro"<br />"seedream 5.0 lite"<br />"seedream-4-5-251128"<br />"seedream-4-0-250828" |

### Seedream 5.0 Pro 입력 (seedream 5.0 pro)

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `size_preset` | 권장 크기를 선택합니다. 아래 `width`와 `height`를 사용하려면 Custom을 선택하세요. 기본값: 이 모델의 첫 번째 권장 프리셋. | COMBO | 아니요 | 모델별 권장 크기 프리셋<br />"Custom" |
| `width` | 이미지의 사용자 지정 너비입니다. `size_preset`이 `Custom`으로 설정된 경우에만 값이 적용됩니다. 기본값: 2048. | INT | 아니요 | 1024  ~  3136 (단계: 2) |
| `height` | 이미지의 사용자 지정 높이입니다. `size_preset`이 `Custom`으로 설정된 경우에만 값이 적용됩니다. 기본값: 2048. | INT | 아니요 | 1024  ~  2496 (단계: 2) |
| `prompt_optimization` | 참조 이미지가 제공될 때의 프롬프트 최적화 모드입니다. 'standard'는 더 높은 품질을, 'fast'는 더 짧은 생성 시간을 제공합니다. 기본값: "standard". | COMBO | 아니요 | "standard"<br />"fast" |
| `seed` | 생성에 사용할 시드입니다. 기본값: 42. | INT | 아니요 | 0  ~  2147483647 |
| `watermark` | 이미지에 "AI generated" 워터마크를 추가할지 여부입니다. 기본값: false. | BOOLEAN | 아니요 | true / false |
| `thinking` | 더 나은 준수를 위해 모델의 프롬프트 최적화 추론('thinking')을 활성화합니다. 생성 시간이 상당히 늘어날 수 있으며, 특히 Seedream 5.0 Pro에서 그렇습니다. 텍스트-투-이미지에서만 비활성화할 수 있습니다(참조 이미지가 제공된 경우에는 불가). 기본값: true. | BOOLEAN | 아니요 | true / false |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 확장 가능한 슬롯: 이미지-투-이미지 또는 다중 참조 생성을 위한 선택적 참조 이미지입니다. 1..N개의 이미지(예: `image_1`, `image_2`, ...)를 연결하세요. 개수 제한은 모델별로 다릅니다(아래 참고 사항 참조). 연결된 이미지에 이미지 배치가 포함된 경우, 배치의 모든 이미지가 제한 개수에 포함됩니다. | IMAGE | 아니요 | 0  ~  10 (Seedream 5.0 Pro, Seedream 4.5, Seedream 4.0)<br />0  ~  14 (Seedream 5.0 Lite) |

**참고 사항:**

- `prompt`는 공백을 제거한 뒤 비어 있으면 안 됩니다.
- 최대 참조 이미지 수: Seedream 5.0 Pro, Seedream 4.5, Seedream 4.0의 경우 10개, Seedream 5.0 Lite의 경우 14개입니다.
- 각 참조 이미지는 1:3에서 3:1 사이의 종횡비를 가져야 합니다.
- `max_images`가 1보다 큰 경우(Seedream 5.0 Pro에서는 사용할 수 없음), 참조 이미지와 생성된 이미지의 총 개수는 15를 초과할 수 없습니다.
- `thinking`은 텍스트-투-이미지 생성에서만 비활성화할 수 있습니다. 참조 이미지가 제공되면 `thinking`은 활성화되어야 합니다.
- `width`와 `height`는 `size_preset`이 "Custom"으로 설정된 경우에만 사용됩니다.
- `prompt_optimization`은 Seedream 5.0 Pro에서만 사용할 수 있습니다.
- `max_images`와 `fail_on_partial`은 Seedream 5.0 Lite, Seedream 4.5, Seedream 4.0에서만 사용할 수 있습니다. Seedream 5.0 Pro는 항상 단일 이미지만 요청합니다.
- 해상도 요구 사항(너비 x 높이):
  - Seedream 5.0 Pro: 0.92MP(921,600픽셀)에서 4.19MP(4,194,304픽셀) 사이입니다.
  - Seedream 5.0 Lite 및 Seedream 4.5: 최소 3.68MP(3,686,400픽셀)입니다.
  - Seedream 4.0: 최소 0.92MP(921,600픽셀)입니다.
  - 모든 비 Pro 모델: 최대 16.78MP(16,777,216픽셀)입니다.
