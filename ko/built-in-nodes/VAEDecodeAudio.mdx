이 노드는 변분 오토인코더(VAE)를 사용하여 오디오 잠재 표현을 재생 가능한 오디오 파형으로 다시 변환합니다. 인코딩된 샘플을 가져와 선택한 VAE를 통해 디코딩한 다음, 결과 파형을 정규화하여 전체 볼륨 레벨이 일관되게 유지되도록 합니다. 출력 오디오는 VAE의 오디오 샘플 레이트(기본값 44100 Hz)를 사용하며, 입력 `samples`에 샘플 레이트가 저장되어 있는 경우에는 해당 값을 사용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `잠재 오디오` | 오디오 파형으로 다시 디코딩될 잠재 공간의 인코딩된 오디오 샘플입니다. `samples`에 자체 샘플 레이트가 포함되어 있으면 해당 값이 출력에 사용됩니다. | LATENT | 예 | - |
| `vae` | 잠재 샘플을 오디오로 디코딩하는 데 사용되는 변분 오토인코더 모델입니다. 입력 `samples`가 샘플 레이트를 지정하지 않은 경우, 이 모델의 오디오 출력 샘플 레이트(기본값 44100 Hz)가 결과 파형의 샘플 레이트를 결정합니다. | VAE | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `AUDIO` | 볼륨이 정규화된 디코딩된 오디오 파형으로, 해당 샘플 레이트와 함께 반환됩니다(입력 `samples`의 샘플 레이트가 있으면 그 값, 그렇지 않으면 VAE의 오디오 샘플 레이트, 기본값 44100 Hz). | AUDIO |
