DCTestNode는 사용자가 동적 콤보 상자에서 선택한 내용에 따라 다양한 유형의 데이터를 반환하는 로직 노드입니다. 선택된 옵션이 어떤 입력 필드를 활성화하고 노드가 어떤 유형의 값을 출력할지 결정하는 조건부 라우터 역할을 합니다.

## 입력

이 노드는 동적 콤보 선택기를 사용합니다. `combo` 매개변수는 항상 표시되며, 다른 입력 필드는 해당 옵션이 선택된 경우에만 나타납니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `combo` | 활성화할 입력 필드와 노드가 출력할 내용을 결정하는 기본 선택 항목입니다. | DYNAMIC_COMBO | 예 | `"option1"`<br />`"option2"`<br />`"option3"`<br />`"option4"` |

### option1 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `string` | 텍스트 입력 필드입니다. 이 필드는 `combo`가 `"option1"`로 설정된 경우에만 활성화되며 필수로 지정됩니다. | STRING | 예 | - |

### option2 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `integer` | 정수 입력 필드입니다. 이 필드는 `combo`가 `"option2"`로 설정된 경우에만 활성화되며 필수로 지정됩니다. | INT | 예 | - |

### option3 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `image` | 이미지 입력 필드입니다. 이 필드는 `combo`가 `"option3"`로 설정된 경우에만 활성화되며 필수로 지정됩니다. | IMAGE | 예 | - |

### option4 입력

`combo`가 `"option4"`로 설정되면 노드는 중첩된 입력 필드 집합을 제어하는 두 번째 동적 콤보 선택기(`subcombo`)를 표시합니다.

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `subcombo` | `combo`가 `"option4"`로 설정된 경우 나타나는 보조 동적 콤보 선택 항목입니다. 활성화할 중첩 입력 필드를 결정합니다. | DYNAMIC_COMBO | 예 | `"opt1"`<br />`"opt2"` |
| `float_x` | 실수 입력 필드입니다. 이 필드는 `combo`가 `"option4"`로 설정되고 `subcombo`가 `"opt1"`로 설정된 경우에만 활성화되며 필수로 지정됩니다. | FLOAT | 예 | - |
| `float_y` | 실수 입력 필드입니다. 이 필드는 `combo`가 `"option4"`로 설정되고 `subcombo`가 `"opt1"`로 설정된 경우에만 활성화되며 필수로 지정됩니다. | FLOAT | 예 | - |
| `mask1` | 마스크 입력 필드입니다. 이 필드는 `combo`가 `"option4"`로 설정되고 `subcombo`가 `"opt2"`로 설정된 경우에만 활성화됩니다. 선택 사항입니다. | MASK | 아니요 | - |

**매개변수 제약 조건:**

* `combo` 매개변수는 다른 모든 입력 필드의 표시 여부와 필수 여부를 제어합니다. 선택된 `combo` 옵션과 연결된 입력만 표시되며 필수로 지정됩니다(`mask1`은 선택 사항으로 예외입니다).
* `combo`가 `"option4"`로 설정되면 `subcombo` 매개변수가 필수로 지정되며 두 번째 중첩 입력 집합(`float_x`/`float_y` 또는 `mask1`)을 제어합니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `output` | 출력은 선택된 `combo` 옵션에 따라 달라집니다. STRING(`"option1"`), INT(`"option2"`), IMAGE(`"option3"`) 또는 `subcombo` 딕셔너리의 문자열 표현(`"option4"`)이 될 수 있습니다. | ANYTYPE |
