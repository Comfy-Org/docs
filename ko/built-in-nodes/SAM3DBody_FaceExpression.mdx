이 노드는 MediaPipe Face Landmarker로 이미지에서 얼굴을 감지하고, 감지된 각 얼굴을 추적 중인 인물에 매칭하며, 52개의 ARKit 블렌드셰이프를 MHR의 72축 표정 파라미터에 매핑하여 SAM3D 바디에 표정을 추가합니다. 그런 다음 바디 모델을 다시 실행하여 출력 메시 정점과 키포인트가 새 표정과 일치하도록 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `sam3d_body_model` | 얼굴을 감지하고 바디 메시를 재생성하는 데 사용되는 얼굴 랜드마크 감지기를 포함하는 SAM3D 바디 모델입니다. | SAM3D_BODY_MODEL | 예 | - |
| `mhr_pose_data` | 경계 상자, 키포인트 및 표정 파라미터가 포함된 프레임별 추적 인물 데이터입니다. 이 노드는 감지된 각 얼굴을 인물에 매칭하고 업데이트된 표정 파라미터를 이 데이터에 기록합니다. | MHR_POSE_DATA | 예 | - |
| `image` | 얼굴 감지에 사용되는 이미지 프레임입니다. 이미지 배치의 프레임 수가 포즈 데이터보다 적으면 나머지 프레임에는 마지막 프레임이 재사용됩니다. | IMAGE | 예 | - |
| `strength` | 모든 블렌드셰이프에 적용되는 전역 배율입니다. 1보다 크면 표정이 과장됩니다. 기본값: 1.0. | FLOAT | 아니오 | 0.0 ~ 4.0 (step 0.05, default 1.0) |
| `mouth_strength` | 입/턱 셰이프에 적용되는 배율입니다. MediaPipe의 jawOpen은 1.0 근처에서 포화됩니다. 기본값: 1.0. | FLOAT | 아니오 | 0.0 ~ 4.0 (step 0.05, default 1.0) |
| `eye_strength` | 눈 셰이프에 적용되는 배율입니다. MediaPipe는 0.5를 거의 초과하지 않으므로 2~3배가 자주 필요합니다. 기본값: 2.0. | FLOAT | 아니오 | 0.0 ~ 4.0 (step 0.05, default 2.0) |
| `brow_strength` | 눈썹/볼/비웃음 셰이프에 적용되는 배율입니다. MediaPipe는 약 0.1~0.3을 출력하므로 2~3배가 필요합니다. 기본값: 2.0. | FLOAT | 아니오 | 0.0 ~ 4.0 (step 0.05, default 2.0) |
| `input_threshold` | MediaPipe 원시 출력에 적용되는 데드존입니다(미만이면 0, 초과면 선형 재매핑). 기본값: 0.02. | FLOAT | 아니오 | 0.0 ~ 0.5 (step 0.01, default 0.02) |
| `blendshape_smooth_window` | MHR 매핑 전 MediaPipe의 프레임별 신호에 적용되는 가우시안 창입니다. MediaPipe의 원시 출력은 정지된 얼굴에서도 프레임 간 30~70% 변동합니다. 1 = 비활성화. 홀수 값을 사용하십시오. 기본값: 7. | INT | 아니오 | 1 ~ 31 (step 2, default 7) |

참고: 클립의 최소 30프레임에 감지된 인물이 포함된 경우에만 클립별 기준선 차감이 적용됩니다. 인물당 최대 12프레임의 감지 공백은 보간으로 채워집니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `mhr_pose_data` | 업데이트된 포즈 데이터입니다. 각 추적 인물의 표정 파라미터는 매핑된 얼굴 표정으로 대체되며, 이에 맞게 메시 정점과 키포인트가 재생성됩니다. | MHR_POSE_DATA |
