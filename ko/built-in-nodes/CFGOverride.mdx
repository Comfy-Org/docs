CFG Override 노드는 샘플링 과정의 백분율(sigma) 범위에 걸쳐 CFG(Classifier-Free Guidance) 스케일을 고정 값으로 재정의합니다. 여러 CFG Override 노드를 사용하는 경우, 범위가 겹치면 샘플러에 가장 가까운 재정의가 우선합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | CFG 재정의를 적용할 모델입니다. | MODEL | 예 | |
| `cfg` | 재정의 범위 동안 사용할 고정 CFG 스케일 값입니다. 기본값: 1.0. | FLOAT | 예 | 0.0  ~  100.0 (단계: 0.1) |
| `시작 퍼센트` | 샘플링 과정의 백분율로 나타낸 재정의 범위의 시작점입니다. 기본값: 0.0. | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.001) |
| `종료 퍼센트` | 샘플링 과정의 백분율로 나타낸 재정의 범위의 끝점입니다. 기본값: 1.0. | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.001) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `MODEL` | CFG 재정의 래퍼가 적용된 모델입니다. | MODEL |
