Bria를 사용하여 동영상에서 프레임별 마스크가 덮는 영역을 지우고 빈 공간을 채웁니다. 마스크는 지워야 할 대상이 흰색, 그 외 영역은 검은색이어야 합니다. Bria는 최대 5.1초 길이, 초당 20~30프레임, 짝수 픽셀 크기의 클립을 지원합니다. 오디오는 기본적으로 유지됩니다. 반환되는 클립은 입력보다 몇 프레임 짧을 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video` | 지울 대상이 포함된 클립입니다. | VIDEO | 예 | - |
| `mask` | 동영상의 각 프레임마다 하나씩 대응하는 마스크로, 지울 객체가 있는 위치가 흰색입니다. 마스크 또는 마스크 동영상 중 하나만 제공해야 하며, 둘 다 제공하면 안 됩니다. | MASK | 아니요 | - |
| `mask_video` | 동영상과 동일한 크기와 프레임 수를 가진, 이미 인코딩된 마스크 동영상입니다. 마스크 또는 마스크 동영상 중 하나만 제공해야 하며, 둘 다 제공하면 안 됩니다. | VIDEO | 아니요 | - |
| `preserve_audio` | 입력의 오디오 트랙을 유지합니다. 기본값: true. | BOOLEAN | 아니요 | `true`<br />`false` |

**제약 사항:**

- `mask` 또는 `mask_video` 중 정확히 하나만 연결해야 합니다. 둘 다 제공되지 않거나 둘 다 제공되면 오류가 발생합니다.
- 동영상은 최대 5.1초 길이여야 하며 초당 20~30프레임으로 재생되어야 합니다. 필요한 경우 Get Video Components와 Create Video를 사용하여 클립의 시간을 다시 맞추십시오.
- 동영상의 픽셀 크기는 짝수여야 합니다(너비와 높이가 2로 나누어떨어져야 함). 그렇지 않은 경우 먼저 자르거나 크기를 조정하십시오.
- `mask`를 사용할 때는 동영상 프레임마다 하나의 마스크 프레임이 포함되어야 하며, 가로세로 비율이 동영상과 일치해야 합니다. 마스크는 50%를 기준으로 이진화됩니다. 불투명도가 절반 미만으로 칠해진 영역은 무시되며, 빈 마스크는 오류를 발생시킵니다. 마스크 해상도가 동영상과 다르면 동영상 크기에 맞게 조정됩니다.
- `mask_video`를 사용할 때는 동영상과 동일한 크기와 동일한 프레임 수를 가져야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 마스크된 영역이 지워지고 빈 공간이 채워진 편집된 클립입니다. 입력 클립보다 몇 프레임 짧을 수 있습니다. | VIDEO |
