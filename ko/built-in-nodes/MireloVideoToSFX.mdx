Mirelo SFX로 영상을 따라가는 음향 효과를 생성합니다. 클립을 업로드하면 모델이 화면의 동작을 따라가며 음향 효과 믹스와, 사운드트랙에서 대사를 분리한 별도의 음성 스템을 반환합니다. 무음 또는 부분 무음 클립에 폴리(foley), 앰비언스, 임팩트를 추가할 때 사용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 사용할 모델입니다. 모델을 선택하면 해당 모델에 특화된 매개변수인 `video`, `audio`, `prompt`, `negative_prompt`, `preserve_speech`, `seed`가 표시됩니다. | DYNAMIC_COMBO | 예 | `"sfx-2.0"` |
| `video` | 음향을 생성할 영상입니다. 음향은 클립 전체(1~600초)에 대해 생성됩니다. | VIDEO | 예 | 1~600초 |
| `audio` | `preserve_speech`와 `speech` 출력에 사용할 대사 트랙으로, 영상 자체의 사운드트랙 대신 사용합니다. 연결하지 않으면 영상에 포함된 사운드를 사용합니다. | AUDIO | 아니요 | - |
| `prompt` | 음향이 어떤 느낌이어야 하는지 나타냅니다. 모델이 영상 자체를 설명하며 항상 프롬프트를 따르지는 않으므로 비워 둘 수 있습니다(기본값: 비어 있음). 최대 2000자입니다. | STRING | 예 | 최대 2000자 |
| `negative_prompt` | 피하고 싶은 소리를 짧은 쉼표 구분 목록으로 지정합니다. 비워 둘 수 있습니다(기본값: 비어 있음). 최대 1000자입니다. | STRING | 예 | 최대 1000자 |
| `preserve_speech` | 생성된 음향 아래에 대사를 섞어 유지합니다. 끄면 음향 효과만 반환합니다. (기본값: True) | BOOLEAN | 예 | false<br />true |
| `seed` | 요청에 사용할 시드입니다. 결과는 비결정적이므로 동일한 시드로도 같은 클립이 반복되지 않습니다. (기본값: 42) | INT | 예 | 0  ~  4294967295 |

노드는 클립이 1초 미만이거나 600초를 초과하면 오류와 함께 중지됩니다. `audio` 트랙을 연결하면 `preserve_speech`가 유지할 대사와 `speech` 출력이 분리할 대사를 설정합니다. 연결하지 않으면 대사는 영상 자체의 사운드트랙에서 가져옵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `audio` | 클립의 음향 효과 믹스입니다. `preserve_speech`가 켜져 있으면 대사가 그 아래에 섞여 있습니다. | AUDIO |
| `speech` | 사운드트랙에서 분리된 대사입니다. 음성이 발견되지 않거나 음성 분리 결과가 없으면 `audio`와 동일한 샘플 레이트의 무음이 됩니다. | AUDIO |
