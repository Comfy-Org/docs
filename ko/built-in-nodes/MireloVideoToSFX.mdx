Mirelo SFX로 비디오에 맞는 음향 효과를 생성합니다. 클립을 업로드하면 모델이 화면의 동작을 따라가며 음향 효과 믹스를 반환하고, 사운드트랙에서 분리한 대사를 별도의 음성 스템으로 함께 반환합니다. 무음 또는 부분적으로 무음인 클립에 폴리, 앰비언스, 임팩트를 추가할 때 사용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 사용할 모델입니다. 모델을 선택하면 해당 모델에 특화된 매개변수인 `video`, `audio`, `prompt`, `negative_prompt`, `preserve_speech`, `seed`, `auto_downscale`가 표시됩니다. | DYNAMIC_COMBO | 예 | `"sfx-2.0"` |
| `video` | 소리를 생성할 비디오입니다. 전체 클립(1~600초)에 대해 소리가 생성됩니다. | VIDEO | 예 | 1~600초 |
| `audio` | `preserve_speech` 및 `speech` 출력에 사용할 대사 트랙으로, 비디오 자체의 사운드트랙 대신 사용합니다. 연결하지 않으면 비디오에 포함된 사운드를 사용합니다. | AUDIO | 아니요 | - |
| `prompt` | 소리가 어떤 느낌이어야 하는지 지정합니다. 모델이 비디오 자체를 설명하며 항상 프롬프트를 따르지는 않으므로 비워 둘 수 있습니다(기본값: 비어 있음). 최대 2000자입니다. | STRING | 예 | 최대 2000자 |
| `negative_prompt` | 피해야 할 소리를 짧은 쉼표 구분 목록으로 지정합니다. 비워 둘 수 있습니다(기본값: 비어 있음). 최대 1000자입니다. | STRING | 예 | 최대 1000자 |
| `preserve_speech` | 생성된 사운드 아래에 대사를 섞어 유지합니다. 끄면 음향 효과만 반환합니다. (기본값: True) | BOOLEAN | 예 | false<br />true |
| `seed` | 요청에 사용할 시드입니다. 결과는 비결정적이므로 동일한 시드를 사용해도 같은 클립이 반복되지 않습니다. (기본값: 42) | INT | 예 | 0~4294967295 |
| `auto_downscale` | 업로드 전에 짧은 변이 2160픽셀을 초과하는 클립을 가로세로 비율을 유지한 채 축소합니다. 더 작은 클립은 그대로 둡니다(기본값: True). | BOOLEAN | 아니요 | `True`<br />`False` |

클립이 1초 미만이거나 600초를 초과하면 노드가 오류와 함께 중지됩니다. 연결된 `audio` 트랙은 `preserve_speech`가 유지하고 `speech` 출력이 분리하는 대사를 설정합니다. 연결된 트랙이 없으면 대사는 비디오 자체의 사운드트랙에서 가져옵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `audio` | 클립의 음향 효과 믹스입니다. `preserve_speech`가 켜져 있으면 그 아래에 대사가 섞입니다. | AUDIO |
| `speech` | 사운드트랙에서 분리된 대사입니다. 음성이 발견되지 않거나 음성 분리 결과가 없으면 `audio`와 동일한 샘플 레이트의 무음입니다. | AUDIO |
