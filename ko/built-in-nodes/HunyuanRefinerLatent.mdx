HunyuanRefinerLatent 노드는 Hunyuan 비디오 정제 프로세스를 위한 conditioning 및 latent 데이터를 준비합니다. 입력 latent 이미지 데이터를 positive 및 negative conditioning에 모두 첨부하고, 노이즈 증강 값을 적용하며, 추가 처리를 위해 32개 채널을 가진 새로운 0으로 채워진 latent를 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `긍정적` | 처리할 positive conditioning 입력 | CONDITIONING | 예 | - |
| `부정적` | 처리할 negative conditioning 입력 | CONDITIONING | 예 | - |
| `잠재` | conditioning의 latent 이미지 데이터로 사용되고 출력 latent의 차원을 정의하는 데 사용되는 latent 표현 입력 | LATENT | 예 | - |
| `노이즈 증강` | 적용할 노이즈 증강 양(기본값: 0.10). 이 매개변수는 노드의 고급 섹션에 표시됩니다. | FLOAT | 예 | 0.0 - 1.0 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `긍정적` | latent 이미지 데이터가 첨부되고 노이즈 증강이 적용된 처리된 positive conditioning | CONDITIONING |
| `부정적` | latent 이미지 데이터가 첨부되고 노이즈 증강이 적용된 처리된 negative conditioning | CONDITIONING |
| `잠재` | 입력 latent와 동일한 배치 크기와 동일한 마지막 3개 차원을 가지며 32개 채널을 가진 0으로 채워진 새로운 latent | LATENT |
