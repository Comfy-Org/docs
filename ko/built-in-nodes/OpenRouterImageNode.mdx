이 노드는 Microsoft의 MAI-Image-2.6 모델을 사용하여 OpenRouter를 통해 이미지를 생성하거나 편집합니다. 텍스트-이미지 생성과 최대 5개의 참조 이미지를 사용하는 이미지 기반 편집을 지원하며, 1K 또는 1.5K 해상도에서 7가지 종횡비를 제공합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 이미지를 생성하는 데 사용되는 OpenRouter 이미지 모델입니다. 모델을 선택하면 아래에 나열된 모델별 옵션이 표시됩니다. | DYNAMIC_COMBO | 예 | `microsoft/mai-image-2.6`<br />`microsoft/mai-image-2.6-flash` |

### Mai Image 2.6 및 Mai Image 2.6 Flash 입력

두 모델 옵션(`microsoft/mai-image-2.6` 및 `microsoft/mai-image-2.6-flash`)에서 공유되며, 동일한 매개변수 집합을 제공합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성할 이미지 또는 참조 이미지에 적용할 편집 내용을 설명합니다. 최대 20000자입니다. 기본값: `""`(비어 있음). 앞뒤 공백을 제거한 후 최소 1자가 필요합니다. | STRING | 예 | 1~20000자 |
| `aspect_ratio` | 생성된 이미지의 종횡비이며, 참조 이미지가 연결된 경우에도 적용됩니다. 기본값: `"1:1"`. `"auto"`는 텍스트-이미지 생성 시 모델이 비율을 선택하도록 하며(1.5K 크기로 렌더링됨), 편집 시에는 첫 번째 참조 이미지의 종횡비를 유지합니다. | COMBO | 예 | `"1:1"`<br />`"16:9"`<br />`"9:16"`<br />`"3:2"`<br />`"2:3"`<br />`"4:3"`<br />`"3:4"`<br />`"auto"` |
| `resolution` | 출력 크기 등급입니다. 1K는 약 1메가픽셀(1:1은 1024x1024, 16:9는 1360x768)이고, 1.5K는 약 2.3메가픽셀(1:1은 1536x1536, 16:9는 2048x1152)입니다. 기본값: `"1K"`. `aspect_ratio`가 `"auto"`일 때는 무시됩니다. | COMBO | 예 | `"1K"`<br />`"1.5K"` |
| `seed` | 노드를 다시 실행할지 결정하는 시드입니다. API에는 시드가 없으므로 이 값과 관계없이 실제 결과는 비결정적입니다. 기본값: `42`. | INT | 예 | 0~2147483647 |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image_1` ... `image_5` | 확장 가능한 슬롯: 이미지 기반 편집을 위해 1~5개의 참조 이미지를 연결합니다. 배치 입력은 이미지당 한 번으로 계산됩니다. 슬롯은 선택 사항이며 비워 둘 수 있습니다(최소 0개 연결). | IMAGE | 아니요 | 0~5개 이미지 |

**참고:**

- 연결된 모든 슬롯을 통틀어 최대 5개의 참조 이미지가 지원됩니다. 배치 입력은 이미지당 한 번으로 계산됩니다.
- `prompt`는 앞뒤 공백을 제거한 후 최소 1자를 포함해야 하며, 20000자를 초과할 수 없습니다.
- 참조 이미지는 PNG 데이터로 전송되며 총 2048 x 2048 픽셀로 제한됩니다.
- `aspect_ratio` 설정은 참조 이미지가 연결된 경우에도 출력에 적용됩니다.
- `aspect_ratio`가 `"auto"`이면 `resolution` 설정은 무시됩니다. 참조 이미지가 없으면 모델이 텍스트-이미지 생성 비율을 선택하고 1.5K 크기로 렌더링합니다. 참조 이미지가 연결되어 있으면 첫 번째 참조 이미지의 종횡비가 유지됩니다.
- 시드 값은 API 결과에 영향을 주지 않으며, 노드를 다시 실행할지 여부만 결정합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 생성되거나 편집된 이미지입니다. 서비스가 여러 이미지를 반환하면 단일 배치 IMAGE 출력으로 결합됩니다. 이미지가 반환되지 않거나 반환된 이미지를 디코딩할 수 없으면 오류가 발생합니다. | IMAGE |
