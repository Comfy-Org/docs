ModelPatchLoader 노드는 model_patches 폴더에서 특수 모델 패치 파일을 로드합니다. 이 노드는 파일 내용에서 패치 유형을 자동으로 감지하여 해당 모델 아키텍처를 로드한 다음, 워크플로우에서 사용할 수 있도록 ModelPatcher로 감쌉니다. 이 노드는 ControlNet 블록, 특징 임베더 모델 및 기타 특수 아키텍처를 포함한 다양한 패치 유형을 지원합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `이름` | model_patches 디렉토리에서 로드할 모델 패치의 파일 이름 | STRING | 예 | model_patches 폴더의 모든 사용 가능한 모델 패치 파일 |

참고: 이 노드는 실험적으로 표시되어 있습니다. 패치 유형은 파일 내용에서 자동으로 감지되므로 수동 유형 선택이 필요하지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `MODEL_PATCH` | 워크플로우에서 사용할 수 있도록 ModelPatcher로 감싼 로드된 모델 패치 | MODEL_PATCH |
