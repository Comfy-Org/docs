이 노드는 제공한 시작 이미지와 종료 이미지 사이를 전환하는 비디오 시퀀스를 생성합니다. 첫 번째 프레임부터 마지막 프레임까지 모든 중간 프레임을 생성하여 부드러운 변환을 만들어 냅니다. 이 노드는 이미지-투-비디오 API를 호출하지만 `image_tail` 요청 필드와 호환되는 입력 옵션만 지원합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `시작 프레임` | 참조 이미지 - URL 또는 Base64 인코딩 문자열, 10MB를 초과할 수 없으며, 해상도는 300*300px 이상이어야 합니다. 종횡비는 1:2.5 ~ 2.5:1 사이여야 합니다. Base64에는 data:image 접두어가 포함되지 않아야 합니다. | IMAGE | 예 | - |
| `끝 프레임` | 참조 이미지 - 종료 프레임 제어. URL 또는 Base64 인코딩 문자열, 10MB를 초과할 수 없으며, 해상도는 300*300px 이상이어야 합니다. Base64에는 data:image 접두어가 포함되지 않아야 합니다. | IMAGE | 예 | - |
| `프롬프트` | 긍정 텍스트 프롬프트. 비어 있으면 안 되며 500자를 초과할 수 없습니다. | STRING | 예 | - |
| `부정 프롬프트` | 부정 텍스트 프롬프트. 500자를 초과할 수 없습니다. 비워 두면 요청에서 생략됩니다. | STRING | 예 | - |
| `cfg 스케일` | 프롬프트 안내 강도를 제어합니다 (기본값: 0.5) | FLOAT | 예 | 0.0-1.0 |
| `종횡비` | 생성된 비디오의 종횡비 (기본값: "16:9") | COMBO | 예 | "16:9"<br />"9:16"<br />"1:1" |
| `모드` | 다음 형식에 따라 비디오 생성에 사용할 구성: mode / duration / model_name. (기본값: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | 예 | "pro mode / 5s duration / kling-v2-5-turbo"<br />"pro mode / 10s duration / kling-v2-5-turbo" |

**이미지 제약 조건:**

- `start_frame`와 `end_frame`은 모두 필수이며 파일 크기가 10MB를 초과할 수 없습니다.
- 두 이미지 모두 최소 해상도는 300×300픽셀입니다.
- `start_frame`의 종횡비는 1:2.5에서 2.5:1 사이여야 합니다.
- Base64 인코딩 이미지에는 "data:image" 접두어가 포함되지 않아야 합니다.

**프롬프트 제약 조건:**

- `prompt`는 비어 있으면 안 되며 500자를 초과할 수 없습니다.
- `negative_prompt`는 500자를 초과할 수 없으며, 비어 있으면 요청에 포함되지 않습니다.

**모드 참고 사항:**

- 두 모드 옵션 모두 pro mode와 kling-v2-5-turbo 모델을 사용하며, 지속 시간(5초 또는 10초)만 다릅니다.
- 노드의 가격 배지에 표시된 대로 생성당 요금은 5초 모드가 미화 $0.35, 10초 모드가 미화 $0.70입니다.

| `길이` | 생성된 비디오의 길이 | STRING |
