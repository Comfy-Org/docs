이 노드는 제공한 시작 이미지와 종료 이미지 사이를 전환하는 비디오 시퀀스를 생성합니다. 첫 프레임에서 마지막 프레임까지 부드러운 변환을 만들기 위해 그 사이의 모든 프레임을 생성합니다. 이 노드는 이미지-투-비디오 API를 호출하지만 `image_tail` 요청 필드와 함께 작동하는 입력 옵션만 지원합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `시작 프레임` | 참조 이미지 - URL 또는 Base64로 인코딩된 문자열이며, 10MB를 초과할 수 없고, 해상도는 300*300px 이상이어야 하며, 가로세로 비율은 1:2.5 ~ 2.5:1 사이여야 합니다. Base64에는 data:image 접두사가 포함되어서는 안 됩니다. | IMAGE | 예 | - |
| `끝 프레임` | 참조 이미지 - 종료 프레임 제어입니다. URL 또는 Base64로 인코딩된 문자열이며, 10MB를 초과할 수 없고, 해상도는 300*300px 이상이어야 합니다. Base64에는 data:image 접두사가 포함되어서는 안 됩니다. | IMAGE | 예 | - |
| `프롬프트` | 긍정 텍스트 프롬프트입니다. 비어 있을 수 없으며 500자를 초과할 수 없습니다. | STRING | 예 | - |
| `부정 프롬프트` | 부정 텍스트 프롬프트입니다. 500자를 초과할 수 없습니다. 비워 두면 요청에서 생략됩니다. | STRING | 예 | - |
| `cfg 스케일` | 프롬프트 가이던스의 강도를 제어합니다(기본값: 0.5). | FLOAT | 예 | 0.0-1.0 |
| `종횡비` | 생성된 비디오의 가로세로 비율입니다(기본값: "16:9"). | COMBO | 예 | "16:9"<br />"9:16"<br />"1:1" |
| `모드` | 비디오 생성에 사용할 구성으로, 형식은 mode / duration / model_name입니다. (기본값: "pro mode / 5s duration / kling-v2-5-turbo") | COMBO | 예 | "pro mode / 5s duration / kling-v2-5-turbo"<br />"pro mode / 10s duration / kling-v2-5-turbo" |

**이미지 제약 사항:**

- `start_frame`과 `end_frame`은 모두 필수이며 파일 크기가 10MB를 초과할 수 없습니다.
- 최소 해상도: 두 이미지 모두 300×300픽셀입니다.
- `start_frame`의 가로세로 비율은 1:2.5에서 2.5:1 사이여야 합니다.
- Base64로 인코딩된 이미지에는 "data:image" 접두사가 포함되어서는 안 됩니다.

**프롬프트 제약 사항:**

- `prompt`는 비어 있을 수 없으며 500자를 초과할 수 없습니다.
- `negative_prompt`는 500자를 초과할 수 없으며, 비어 있으면 요청과 함께 전송되지 않습니다.

**모드 참고 사항:**

- 두 모드 옵션 모두 kling-v2-5-turbo 모델과 함께 pro 모드를 사용하며, 지속 시간(5초 또는 10초)만 다릅니다.
- 생성당 가격은 노드의 가격 배지에 표시된 대로, 5초 모드는 $0.35 USD, 10초 모드는 $0.70 USD입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오 시퀀스입니다. | VIDEO |
| `video_id` | 생성된 비디오의 고유 식별자입니다. | STRING |
| `duration` | 생성된 비디오의 지속 시간입니다. | STRING |
