이 노드는 Bria를 사용하여 이미지의 전경을 제거하고 그 자리에 새로운 배경을 생성합니다. Bria가 전경으로 식별한 모든 항목이 제거되며, 사람만 제거되는 것이 아니고, 손대지 않은 픽셀은 보존됩니다. 결과는 약 1메가픽셀에 가까운 표준 크기로 다시 렌더링됩니다.

이것은 Bria의 서비스에서 실행되는 유료 API 노드이므로, 각 실행마다 Comfy API 자격 증명이 사용됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 전경이 제거되고 생성된 배경으로 대체될 이미지입니다. 색상 채널만 전송되며, 알파 채널은 업로드 전에 삭제됩니다. | IMAGE | 예 | - |
| `검토` | 검열 설정입니다. 이미지를 검열 플래그 없이 전송하려면 `"false"`를 선택하고, 아래의 콘텐츠 검열 토글을 표시하려면 `"true"`를 선택합니다. 기본값: `"false"`. | DYNAMIC_COMBO | 예 | `"false"`<br />`"true"` |

### `"false"` 입력

추가 입력이 없습니다. 요청은 콘텐츠 검열 플래그 없이 전송됩니다.

### `"true"` 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | 입력 이미지에 콘텐츠 검열을 활성화합니다. 기본값: false. | BOOLEAN | 예 | true<br />false |
| `visual_output_moderation` | 생성된 출력 이미지에 콘텐츠 검열을 활성화합니다. 기본값: false. | BOOLEAN | 예 | true<br />false |

### 참고 사항

- 출력은 약 1메가픽셀에 가까운 표준 크기로 다시 렌더링되므로, 반환된 이미지는 입력 이미지와 크기가 다를 수 있습니다.
- 이 노드는 유료 API 노드이며, 각 실행 비용은 약 0.0572 USD입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 입력 이미지에서 전경이 지워지고 그 자리에 새로 생성된 배경이 배치된 이미지입니다. | IMAGE |
