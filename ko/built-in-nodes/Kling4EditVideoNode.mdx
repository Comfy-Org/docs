기존 동영상을 Kling 4.0 모델과 텍스트 프롬프트로 편집하며, 선택적으로 참조 동영상과 참조 이미지를 활용할 수 있습니다. 결과물은 입력 동영상의 길이를 유지합니다. 클립에서 발생하는 내용을 바꾸거나, 스타일을 변경하거나, 원래 타이밍을 유지한 채 요소를 교체하는 데 사용하세요.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 모델 선택기입니다. `"kling-4.0"`은 최대 4K HDR 및 30초 편집을 지원하고, `"kling-4.0-flash"`는 720p 및 20초로 제한됩니다. 모델을 선택하면 아래에 해당 모델의 입력이 표시됩니다. | DYNAMIC_COMBO | 예 | `"kling-4.0"`<br />`"kling-4.0-flash"` |

### kling-4.0 입력

`model`이 `"kling-4.0"`으로 설정되면 다음 입력이 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video_1` | 편집할 동영상이며 길이는 3~30초입니다. 출력은 입력 동영상의 길이를 유지합니다. | VIDEO | 예 | 3~30초 |
| `reference_videos` | 참조 동영상용 확장 가능한 슬롯이며 최대 4개입니다. 프롬프트에서 `@Video2` 등으로 참조하세요. 각 동영상 및 모든 동영상을 합친 길이는 3~30초여야 합니다. | AUTOGROW | 아니오 | 0~4개 동영상 |
| `reference_images` | 참조 이미지용 확장 가능한 슬롯이며 최대 10개입니다. 프롬프트에서 `@Image1`, `@Image2` 등으로 참조하세요. | AUTOGROW | 아니오 | 0~10개 이미지 |
| `prompt` | 변경할 내용과 유지할 내용에 대한 설명입니다. 편집 중인 동영상은 `@Video1`, 참조 동영상은 `@Video2` 등으로, 이미지는 `@Image1` 등으로 참조하세요. | STRING | 예 | 1~26000자 |
| `resolution` | 출력 동영상의 해상도입니다. 이름에 `HDR`이 포함된 옵션은 HDR 동영상을 반환합니다. 기본값: `"720p"`. | COMBO | 예 | `"720p"`<br />`"1080p"`<br />`"4k"`<br />`"1080p HDR"`<br />`"4k HDR"` |
| `aspect_ratio` | 출력 동영상의 화면 비율입니다. `"adaptive"`는 입력 동영상의 화면 비율을 유지합니다. 기본값: `"adaptive"`. | COMBO | 예 | `"adaptive"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"`<br />`"4:3"`<br />`"3:4"` |
| `seed` | 시드는 노드의 재실행 여부를 제어합니다. 시드에 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |
| `audio` | `"native"`는 편집된 동영상에 새 오디오를 생성하고, `"original"`은 입력 동영상의 오디오를 유지합니다. 기본값: `"native"`. | COMBO | 아니오 | `"native"`<br />`"original"` |

### kling-4.0-flash 입력

`model`이 `"kling-4.0-flash"`로 설정되면 다음 입력이 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video_1` | 편집할 동영상이며 길이는 3~20초입니다. 출력은 입력 동영상의 길이를 유지합니다. | VIDEO | 예 | 3~20초 |
| `reference_videos` | 참조 동영상용 확장 가능한 슬롯이며 최대 4개입니다. 프롬프트에서 `@Video2` 등으로 참조하세요. 각 동영상 및 모든 동영상을 합친 길이는 3~20초여야 합니다. | AUTOGROW | 아니오 | 0~4개 동영상 |
| `reference_images` | 참조 이미지용 확장 가능한 슬롯이며 최대 10개입니다. 프롬프트에서 `@Image1`, `@Image2` 등으로 참조하세요. | AUTOGROW | 아니오 | 0~10개 이미지 |
| `prompt` | 변경할 내용과 유지할 내용에 대한 설명입니다. 편집 중인 동영상은 `@Video1`, 참조 동영상은 `@Video2` 등으로, 이미지는 `@Image1` 등으로 참조하세요. | STRING | 예 | 1~26000자 |
| `resolution` | 출력 동영상의 해상도입니다. Flash는 720p로만 렌더링합니다. 기본값: `"720p"`. | COMBO | 예 | `"720p"` |
| `aspect_ratio` | 출력 동영상의 화면 비율입니다. `"adaptive"`는 입력 동영상의 화면 비율을 유지합니다. 기본값: `"adaptive"`. | COMBO | 예 | `"adaptive"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"`<br />`"4:3"`<br />`"3:4"` |
| `seed` | 시드는 노드의 재실행 여부를 제어합니다. 시드에 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |
| `audio` | `"native"`는 편집된 동영상에 새 오디오를 생성하고, `"original"`은 입력 동영상의 오디오를 유지합니다. 기본값: `"native"`. | COMBO | 아니오 | `"native"`<br />`"original"` |

**제약 사항 및 동작:**

* 입력 동영상과 각 참조 동영상은 길이가 3~30초(`kling-4.0-flash`의 경우 3~20초)여야 하고, 최소 700x700, 최대 4553x4553픽셀이어야 하며, 총 픽셀 수는 8,294,400을 넘지 않아야 합니다. 화면 비율은 2:5에서 5:2 사이여야 하고 프레임 속도는 최소 24fps여야 합니다. 모든 동영상을 합친 경우에도 동일한 제한을 초과해서는 안 됩니다.
* 각 참조 이미지는 최소 300x300픽셀이어야 하고 화면 비율은 2:5에서 5:2 사이여야 하며, 최대 10개까지 연결할 수 있습니다.
* `@VideoN` 또는 `@ImageN`을 언급하는 프롬프트에서 해당 종류의 입력이 N개 미만으로 연결되어 있으면 오류가 발생합니다.
