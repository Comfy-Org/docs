Kling 4.0 모델을 사용하여 텍스트 프롬프트로 기존 비디오를 편집하며, 선택적으로 참조 비디오와 참조 이미지의 안내를 받을 수 있습니다. 결과물은 입력 비디오의 길이를 유지합니다. 클립에서 발생하는 내용을 변경하거나, 스타일을 바꾸거나, 원래 타이밍을 유지한 채 요소를 교체할 때 사용합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 모델 선택기입니다. `"kling-4.0"`만 사용할 수 있으며, 이를 선택하면 아래 입력이 표시됩니다. | DYNAMIC_COMBO | 예 | `"kling-4.0"` |

### kling-4.0 입력

`model`이 `"kling-4.0"`으로 설정되면 다음 입력이 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video_1` | 편집할 비디오로, 길이는 3~30초입니다. 출력은 해당 길이를 유지합니다. | VIDEO | 예 | 3 ~ 30 seconds |
| `reference_videos` | 참조 비디오용으로 확장 가능한 슬롯이며 최대 4개입니다. 프롬프트에서 `@Video2` 등으로 참조합니다. 각 비디오 및 모든 비디오의 합계 길이는 3~30초여야 합니다. | AUTOGROW | 아니요 | 0 ~ 4 개 동영상 |
| `reference_images` | 참조 이미지용으로 확장 가능한 슬롯이며 최대 10개입니다. 프롬프트에서 `@Image1`, `@Image2` 등으로 참조합니다. | AUTOGROW | 아니요 | 0 ~ 10 개 이미지 |
| `prompt` | 변경할 내용과 유지할 내용에 대한 설명입니다. 편집 중인 비디오는 `@Video1`, 참조 비디오는 `@Video2` 등으로, 이미지는 `@Image1` 등으로 참조합니다. | STRING | 예 | 1 ~ 26000 자 |
| `resolution` | 출력 비디오의 해상도입니다. 기본값: `"720p"`. | COMBO | 예 | `"720p"`<br />`"1080p"` |
| `aspect_ratio` | 출력 비디오의 화면 비율입니다. `"adaptive"`는 입력 비디오의 화면 비율을 유지합니다. 기본값: `"adaptive"`. | COMBO | 예 | `"adaptive"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0 ~ 2147483647 |

**제약 사항 및 동작:**

* 입력 비디오와 모든 참조 비디오는 길이가 3~30초여야 하며, 최소 700x700, 최대 4553x4553 픽셀이어야 하고, 총 픽셀 수는 8,294,400을 초과할 수 없으며, 화면 비율은 2:5에서 5:2 사이이고 프레임 속도는 최소 24 fps여야 합니다. 모든 비디오의 합계 길이는 30초를 초과할 수 없습니다.
* 모든 참조 이미지는 최소 300x300 픽셀이어야 하며 화면 비율은 2:5에서 5:2 사이여야 하고, 최대 10개의 이미지를 연결할 수 있습니다.
* 프롬프트에서 `@VideoN` 또는 `@ImageN`을 언급했지만 해당 종류의 입력이 N개 미만으로 연결된 경우 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 편집된 비디오로, 작업이 완료되면 제공자로부터 다운로드됩니다. 입력 비디오와 동일한 길이를 가집니다. | VIDEO |
