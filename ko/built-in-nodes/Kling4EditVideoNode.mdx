Kling 4.0 모델을 사용하여 텍스트 프롬프트로 기존 비디오를 편집하며, 선택적으로 참조 비디오와 참조 이미지의 안내를 받을 수 있습니다. 결과물은 입력 비디오의 길이를 유지합니다. 클립에서 발생하는 일을 변경하거나, 스타일을 바꾸거나, 원래 타이밍을 그대로 유지하면서 요소를 교체할 때 사용합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 모델 선택기입니다. `"kling-4.0"`은 최대 30초까지 1080p 편집을 지원하고, `"kling-4.0-flash"`는 720p 및 20초로 제한됩니다. 모델을 선택하면 아래에 해당 모델의 입력이 표시됩니다. | DYNAMIC_COMBO | 예 | `"kling-4.0"`<br />`"kling-4.0-flash"` |

### kling-4.0 입력

`model`이 `"kling-4.0"`으로 설정되면 다음 입력이 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video_1` | 편집할 비디오로, 길이는 3~30초입니다. 출력은 해당 길이를 유지합니다. | VIDEO | 예 | 3~30초 |
| `reference_videos` | 참조 비디오용 확장 가능한 슬롯이며 최대 4개입니다. 프롬프트에서 `@Video2` 등으로 참조합니다. 각 비디오와 모든 비디오의 합계는 3~30초여야 합니다. | AUTOGROW | 아니요 | 0~4개 비디오 |
| `reference_images` | 참조 이미지용 확장 가능한 슬롯이며 최대 10개입니다. 프롬프트에서 `@Image1`, `@Image2` 등으로 참조합니다. | AUTOGROW | 아니요 | 0~10개 이미지 |
| `prompt` | 변경할 내용과 유지할 내용에 대한 설명입니다. 편집 중인 비디오는 `@Video1`, 참조 비디오는 `@Video2` 등으로, 이미지는 `@Image1` 등으로 참조합니다. | STRING | 예 | 1~26000자 |
| `resolution` | 출력 비디오의 해상도입니다. 기본값: `"720p"`. | COMBO | 예 | `"720p"`<br />`"1080p"` |
| `aspect_ratio` | 출력 비디오의 화면 비율입니다. `"adaptive"`는 입력 비디오의 화면 비율을 유지합니다. 기본값: `"adaptive"`. | COMBO | 예 | `"adaptive"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `seed` | 시드는 노드의 재실행 여부를 제어하며, 결과는 시드와 관계없이 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |
| `audio` | `"native"`는 편집된 비디오에 새 오디오를 생성하고, `"original"`은 입력 비디오의 오디오를 유지합니다. 기본값: `"native"`. | COMBO | 아니요 | `"native"`<br />`"original"` |

### kling-4.0-flash 입력

`model`이 `"kling-4.0-flash"`으로 설정되면 다음 입력이 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video_1` | 편집할 비디오로, 길이는 3~20초입니다. 출력은 해당 길이를 유지합니다. | VIDEO | 예 | 3~20초 |
| `reference_videos` | 참조 비디오용 확장 가능한 슬롯이며 최대 4개입니다. 프롬프트에서 `@Video2` 등으로 참조합니다. 각 비디오와 모든 비디오의 합계는 3~20초여야 합니다. | AUTOGROW | 아니요 | 0~4개 비디오 |
| `reference_images` | 참조 이미지용 확장 가능한 슬롯이며 최대 10개입니다. 프롬프트에서 `@Image1`, `@Image2` 등으로 참조합니다. | AUTOGROW | 아니요 | 0~10개 이미지 |
| `prompt` | 변경할 내용과 유지할 내용에 대한 설명입니다. 편집 중인 비디오는 `@Video1`, 참조 비디오는 `@Video2` 등으로, 이미지는 `@Image1` 등으로 참조합니다. | STRING | 예 | 1~26000자 |
| `resolution` | 출력 비디오의 해상도입니다. Flash는 720p만 렌더링합니다. 기본값: `"720p"`. | COMBO | 예 | `"720p"` |
| `aspect_ratio` | 출력 비디오의 화면 비율입니다. `"adaptive"`는 입력 비디오의 화면 비율을 유지합니다. 기본값: `"adaptive"`. | COMBO | 예 | `"adaptive"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `seed` | 시드는 노드의 재실행 여부를 제어하며, 결과는 시드와 관계없이 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |
| `audio` | `"native"`는 편집된 비디오에 새 오디오를 생성하고, `"original"`은 입력 비디오의 오디오를 유지합니다. 기본값: `"native"`. | COMBO | 아니요 | `"native"`<br />`"original"` |

**제약 사항 및 동작:**

* 입력 비디오와 모든 참조 비디오는 3~30초(`kling-4.0-flash` 사용 시 3~20초)여야 하며, 최소 700x700, 최대 4553x4553픽셀이고, 총 8,294,400픽셀을 초과하지 않아야 합니다. 화면 비율은 2:5에서 5:2 사이여야 하고 프레임 레이트는 최소 24fps여야 합니다. 모든 비디오를 합친 경우에도 동일한 제한을 초과해서는 안 됩니다.
* 모든 참조 이미지는 최소 300x300픽셀이어야 하며, 화면 비율은 2:5에서 5:2 사이여야 합니다. 연결할 수 있는 이미지는 최대 10개입니다.
* `@VideoN` 또는 `@ImageN`을 언급하는 프롬프트는 해당 종류의 입력이 N개 미만으로 연결된 경우 오류를 발생시킵니다.
