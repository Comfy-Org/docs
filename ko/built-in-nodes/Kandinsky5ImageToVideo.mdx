Kandinsky5ImageToVideo 노드는 Kandinsky 모델을 사용하여 비디오 생성을 위한 컨디셔닝 및 잠재 공간 데이터를 준비합니다. 빈 비디오 잠재 텐서를 생성하고, 선택적으로 시작 이미지를 인코딩하여 생성된 비디오의 초기 프레임을 안내할 수 있으며, 이에 따라 긍정적 및 부정적 컨디셔닝을 수정합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `positive` | 비디오 생성을 안내하는 긍정적 컨디셔닝 프롬프트입니다. | CONDITIONING | 예 | N/A |
| `negative` | 특정 개념에서 비디오 생성을 멀어지게 하는 부정적 컨디셔닝 프롬프트입니다. | CONDITIONING | 예 | N/A |
| `vae` | 선택적 시작 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 | N/A |
| `너비` | 출력 비디오의 픽셀 단위 너비입니다(기본값: 768). | INT | 예 | 16 ~ 16384 (step 16) |
| `높이` | 출력 비디오의 픽셀 단위 높이입니다(기본값: 512). | INT | 예 | 16 ~ 16384 (step 16) |
| `길이` | 비디오의 프레임 수입니다(기본값: 121). | INT | 예 | 1 ~ 16384 (step 4) |
| `배치 크기` | 동시에 생성할 비디오 시퀀스 수입니다(기본값: 1). | INT | 예 | 1 ~ 4096 |
| `시작 이미지` | 선택적 시작 이미지 또는 프레임 배치입니다. 제공된 경우 인코딩되어 모델 출력 잠재의 노이즈 시작 부분을 대체하는 데 사용됩니다. | IMAGE | 아니요 | N/A |

**참고:** `start_image`가 제공되면 이중 선형 보간법을 사용하여 지정된 `width` 및 `height`에 맞게 자동으로 크기가 조정됩니다. 이미지 배치의 첫 `length` 프레임만 인코딩에 사용되며, 추가 프레임은 무시됩니다. 이미지 배치에 `length` 프레임보다 적은 프레임이 있는 경우 해당 프레임만 사용됩니다. 이미지의 RGB 채널만 인코딩됩니다. 인코딩된 잠재는 비디오의 초기 모양을 안내하기 위해 `positive` 및 `negative` 컨디셔닝 모두에 주입되며, 노이즈가 없는 인코딩된 프레임은 모델 출력 잠재의 노이즈 시작 부분을 대체합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `positive` | 인코딩된 시작 이미지 데이터로 업데이트될 수 있는 수정된 긍정적 컨디셔닝입니다. | CONDITIONING |
| `negative` | 인코딩된 시작 이미지 데이터로 업데이트될 수 있는 수정된 부정적 컨디셔닝입니다. | CONDITIONING |
| `latent` | 빈 비디오 잠재입니다. 지정된 차원으로 형태가 지정된 0으로 채워진 잠재 텐서입니다. | LATENT |
| `cond_latent` | 모델 출력 잠재의 노이즈 시작 부분을 대체하는 데 사용되는 노이즈가 없는 인코딩된 시작 이미지입니다. `start_image`가 제공되지 않으면 비어 있습니다. | LATENT |
