Kandinsky5ImageToVideo 노드는 Kandinsky 모델을 사용한 비디오 생성에 필요한 conditioning 및 latent 데이터를 준비합니다. 요청된 `width`, `height`, `length`, `batch_size`에 맞는 빈 비디오 latent를 생성하며, 선택적으로 시작 이미지를 인코딩하여 `positive` 및 `negative` conditioning을 업데이트함으로써 생성되는 비디오의 초기 프레임을 안내할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `positive` | 비디오 생성을 안내하는 긍정 컨디셔닝 프롬프트입니다. | CONDITIONING | 예 | N/A |
| `negative` | 특정 개념에서 벗어나도록 비디오 생성을 유도하는 부정 컨디셔닝 프롬프트입니다. | CONDITIONING | 예 | N/A |
| `vae` | 선택적 시작 이미지를 latent 공간으로 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 | N/A |
| `너비` | 출력 비디오의 너비(픽셀)입니다(기본값: 768). | INT | 예 | 16  ~  16384 (단계: 16) |
| `높이` | 출력 비디오의 높이(픽셀)입니다(기본값: 512). | INT | 예 | 16  ~  16384 (단계: 16) |
| `길이` | 비디오의 프레임 수입니다(기본값: 121). | INT | 예 | 1  ~  16384 (단계: 4) |
| `배치 크기` | 동시에 생성할 비디오 시퀀스 수입니다(기본값: 1). | INT | 예 | 1  ~  4096 |
| `시작 이미지` | 선택적 시작 이미지 또는 프레임 배치입니다. 제공된 경우 인코딩되어 모델 출력 latent의 노이즈가 있는 시작 부분을 대체하는 데 사용됩니다. | IMAGE | 아니요 | N/A |

**참고:** `start_image`가 제공되면 지정된 `width` 및 `height`에 맞게 이중선형 보간을 사용하여 자동으로 크기가 조정됩니다. 이미지 배치의 처음 `length` 프레임만 인코딩에 사용되며, 추가 프레임은 무시됩니다. 이미지 배치의 프레임 수가 `length`보다 적으면 해당 프레임만 사용됩니다. 이미지의 RGB 채널만 인코딩됩니다. 그런 다음 인코딩된 latent가 `positive` 및 `negative` 컨디셔닝 모두에 주입되어 비디오의 초기 모습을 안내하고, 노이즈가 없는 인코딩된 프레임이 모델 출력 latent의 노이즈가 있는 시작 부분을 대체합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `positive` | 수정된 긍정 컨디셔닝으로, `start_image`가 제공된 경우 인코딩된 시작 이미지 데이터로 업데이트됩니다. | CONDITIONING |
| `negative` | 수정된 부정 컨디셔닝으로, `start_image`가 제공된 경우 인코딩된 시작 이미지 데이터로 업데이트됩니다. | CONDITIONING |
| `latent` | 빈 비디오 latent입니다. 지정된 차원에 맞게 형태가 지정된 0으로 채워진 latent 텐서입니다. | LATENT |
| `cond_latent` | 노이즈가 없는 인코딩된 시작 이미지로, 모델 출력 latent의 노이즈가 있는 시작 부분을 대체하는 데 사용됩니다. `start_image`가 제공되지 않은 경우 비어 있습니다. | LATENT |
