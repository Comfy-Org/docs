이 노드는 최신 Kling AI 모델을 사용하여 텍스트 설명에서 비디오를 생성합니다. 프롬프트를 원격 API로 전송하고 생성된 비디오를 반환합니다. 이 노드를 통해 비디오의 길이, 화면 비율, 품질을 제어할 수 있으며 멀티샷 스토리보드도 생성할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | 비디오 생성에 사용할 특정 Kling 모델입니다(기본값: `"kling-v3-omni"`). | COMBO | 예 | `"kling-v3-omni"`<br />`"kling-video-o1"` |
| `프롬프트` | 비디오 내용을 설명하는 텍스트 프롬프트입니다. 긍정적 설명과 부정적 설명을 모두 포함할 수 있습니다. 스토리보드가 활성화되면 무시됩니다. | STRING | 예 | 0~2500자 |
| `화면 비율` | 생성할 비디오의 화면 비율(모양 또는 크기)입니다. | COMBO | 예 | `"16:9"`<br />`"9:16"`<br />`"1:1"` |
| `지속 시간` | 비디오의 길이(초)입니다(기본값: 5). | INT | 예 | 3~15초 |
| `해상도` | 비디오의 품질 또는 픽셀 해상도입니다(기본값: `"1080p"`). 내부적으로 표준, 프로 또는 4K 품질에 매핑됩니다. | COMBO | 아니요 | `"4k"`<br />`"1080p"`<br />`"720p"` |
| `스토리보드` | 개별 프롬프트와 길이를 가진 일련의 비디오 세그먼트를 생성합니다. o1 모델에서는 무시됩니다. | DYNAMIC_COMBO | 아니요 | `"disabled"`<br />`"1 storyboard"`<br />`"2 storyboards"`<br />`"3 storyboards"`<br />`"4 storyboards"`<br />`"5 storyboards"`<br />`"6 storyboards"` |
| `오디오 생성` | 비디오에 오디오를 생성할지 여부입니다(기본값: False). | BOOLEAN | 아니요 | True / False |
| `시드` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다(기본값: 0). | INT | 아니요 | 0~2147483647 |

### 스토리보드 하위 입력

`storyboards`가 `"disabled"` 외의 값으로 설정되면 각 스토리보드 세그먼트에 대해 다음 입력이 나타납니다. 아래 매개변수 이름에서 `{i}`는 선택한 스토리보드 개수까지의 세그먼트 번호(1부터 시작)입니다.

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_{i}_prompt` | 스토리보드 세그먼트 &#123;i&#125;에 대한 프롬프트입니다. 최대 512자입니다. | STRING | 예 | 1~512자 |
| `storyboard_{i}_duration` | 스토리보드 세그먼트 &#123;i&#125;의 길이(초)입니다(기본값: 4). | INT | 예 | 1~15초 |

### 매개변수 제약 및 제한사항

- **모델별 제한사항:**
  - `kling-video-o1` 모델은 **5초 또는 10초** 길이만 지원합니다.
  - `kling-video-o1` 모델은 오디오 생성을 **지원하지 않습니다**.
  - `kling-video-o1` 모델은 4K 해상도를 **지원하지 않습니다**.
  - `kling-video-o1` 모델은 스토리보드를 **지원하지 않습니다**.
- **스토리보드 제약사항:**
  - 스토리보드가 활성화되면 `prompt` 필드는 무시됩니다.
  - 각 스토리보드에는 자체 프롬프트(1~512자)와 길이가 필요합니다.
  - 모든 스토리보드의 총 길이는 전역 `duration` 매개변수와 정확히 일치해야 합니다.
- **프롬프트 요구사항:**
  - 스토리보드가 **비활성화**된 경우 `prompt` 필드는 필수입니다(최소 1자).
  - 스토리보드가 **활성화**된 경우 `prompt` 필드는 비어 있을 수 있습니다(0자).
