ConditioningSetAreaPercentageVideo 노드는 비디오 생성을 위한 특정 영역과 시간적 구간을 정의하여 조건부 입력(conditioning) 데이터를 수정합니다. 전체 크기 대비 백분율 값을 사용하여 조건부 입력이 적용되는 영역의 위치, 크기 및 지속 시간을 설정합니다. 이는 비디오 시퀀스의 특정 부분에 생성을 집중하는 데 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `조건` | 수정할 조건부 입력(conditioning) 데이터입니다. | CONDITIONING | 예 | - |
| `너비` | 전체 너비 대비 영역 너비의 백분율입니다. (기본값: 1.0) | FLOAT | 예 | 0.0 - 1.0 (step 0.01) |
| `높이` | 전체 높이 대비 영역 높이의 백분율입니다. (기본값: 1.0) | FLOAT | 예 | 0.0 - 1.0 (step 0.01) |
| `시간` | 전체 비디오 길이 대비 영역의 시간적 지속 시간의 백분율입니다. (기본값: 1.0) | FLOAT | 예 | 0.0 - 1.0 (step 0.01) |
| `x` | 영역의 가로 시작 위치를 백분율로 지정합니다. (기본값: 0.0) | FLOAT | 예 | 0.0 - 1.0 (step 0.01) |
| `y` | 영역의 세로 시작 위치를 백분율로 지정합니다. (기본값: 0.0) | FLOAT | 예 | 0.0 - 1.0 (step 0.01) |
| `z` | 비디오 타임라인 대비 영역의 시간적 시작 위치를 백분율로 지정합니다. (기본값: 0.0) | FLOAT | 예 | 0.0 - 1.0 (step 0.01) |
| `강도` | 정의된 영역 내에서 조건부 입력에 적용되는 강도 배율입니다. (기본값: 1.0) | FLOAT | 예 | 0.0 - 10.0 (step 0.01) |

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `conditioning` | 지정된 영역 및 강도 설정이 적용된 수정된 조건부 입력 데이터입니다. | CONDITIONING |
