메시의 UV 레이아웃을 이미지로 렌더링합니다. 각각 연결된 UV 영역(차트)은 서로 다른 색으로 채워지며, 차트 경계 엣지는 어두운 회색 배경 위에 검은색 윤곽선으로 그려집니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `메시` | UV 레이아웃을 렌더링할 3D 메시입니다. 메시에는 UV 좌표가 있어야 합니다. 그렇지 않으면 노드가 "mesh has no UVs to render. Run UnwrapMesh first." 오류를 발생시킵니다. | MESH | 예 | - |
| `해상도` | 렌더링된 정사각형 이미지의 너비와 높이(픽셀)입니다(기본값: 1024). | INT | 예 | 64  ~  4096 (단계: 64) |

참고: 메시에 배치 차원(3D UV 또는 면 배열)이 포함된 경우 배치의 첫 번째 항목만 렌더링됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 렌더링된 UV 아틀라스 이미지이며, 단일 이미지 배치로 반환됩니다. 각 UV 차트는 색이 지정되고, 차트 경계 엣지는 검은색으로 윤곽이 그려집니다. | IMAGE |
