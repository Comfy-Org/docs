메시의 UV 레이아웃을 이미지로 렌더링합니다. 연결된 각 UV 영역(차트)은 고유한 색상으로 채워지며, 차트 경계는 어두운 회색 배경 위에 검은색 윤곽선으로 표시됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `메시` | UV 레이아웃을 렌더링할 3D 메시입니다. 메시에는 UV 좌표가 있어야 하며, 그렇지 않으면 오류가 발생합니다. | MESH | 예 | - |
| `해상도` | 렌더링된 이미지의 너비와 높이(픽셀 단위)입니다(기본값: 1024). | INT | 예 | 64 ~ 4096 (step 64) |

참고: 메시에 UV 좌표가 없으면 노드는 "mesh has no UVs to render. Run UnwrapMesh first." 오류를 발생시킵니다. 메시에 배치 차원(3D UV 또는 면 배열)이 포함된 경우 배치의 첫 번째 항목만 렌더링됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `이미지` | 각 차트가 색상으로 채워지고 차트 경계 가장자리가 검은색 윤곽선으로 표시된 렌더링된 UV 아틀라스 이미지입니다. | IMAGE |
