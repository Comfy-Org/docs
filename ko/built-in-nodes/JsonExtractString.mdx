JsonExtractString 노드는 텍스트 문자열에서 첫 번째 유효한 JSON 객체를 검색하고, 특정 키와 연결된 값을 추출하여 문자열로 변환합니다. JSON 객체 앞뒤의 텍스트는 무시되므로, 이 노드는 Markdown 코드 블록과 JSON을 추가 설명으로 감싼 모델 응답에서도 작동합니다. 유효한 JSON 객체를 찾지 못하거나, 키를 찾지 못하거나, 값이 null인 경우 노드는 빈 문자열을 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `json_string` | JSON 객체를 검색할 텍스트입니다. 이 필드는 여러 줄 입력을 지원하며 주변에 설명 텍스트나 Markdown 코드 펜스가 포함될 수 있습니다. | STRING | 예 | N/A |
| `key` | JSON 객체에서 값을 추출할 특정 키입니다. 이 필드는 한 줄 입력만 지원합니다. | STRING | 예 | N/A |

**참고:** 노드는 JSON 객체(딕셔너리)에서만 값을 추출합니다. 입력의 각 `{`를 순서대로 시도하고, 유효한 JSON 객체를 생성하는 첫 번째 위치부터 디코딩하므로 앞뒤의 텍스트는 건너뜁니다. JSON 객체를 디코딩할 수 없거나 지정한 키가 그 안에 존재하지 않으면 출력은 빈 문자열입니다. 키와 연결된 값이 `null`이면 노드도 빈 문자열을 반환합니다. 문자열이 아닌 값은 해당 값의 문자열 표현으로 반환됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `output` | 지정한 키에 대해 JSON에서 추출된 문자열 값이며, 추출에 실패하면 빈 문자열입니다. | STRING |
