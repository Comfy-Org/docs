HeyGen Voice 1.0 Instant Clone으로 복제한 음성으로 텍스트를 말합니다. 이 노드는 텍스트와 음성 ID를 HeyGen에 보내고 생성된 음성을 오디오로 반환합니다. 두 가지 모델을 사용할 수 있습니다: `heygen-voice-1`과 비용이 더 낮고 더 빠른 `heygen-voice-1-turbo`입니다.

`model`을 선택하면 해당 모델에 특화된 매개변수가 표시됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 사용할 모델입니다. `heygen-voice-1-turbo`는 더 빠르고 비용이 더 낮습니다. 모델을 선택하면 해당 모델에 특화된 매개변수인 `voice_id`, `text`, `language`, `expressiveness_boost`가 표시됩니다. | DYNAMIC_COMBO | 예 | `"heygen-voice-1"`<br />`"heygen-voice-1-turbo"` |
| `voice_id` | HeyGen Voice 1.0 Instant Clone의 음성입니다(기본값: 비어 있음). | STRING | 예 | N/A |
| `text` | 말할 텍스트입니다. 최대 5,000자이며, 약 12분이 넘는 음성은 실패하므로 매우 긴 중국어 또는 일본어 텍스트는 나누어야 합니다(기본값: 비어 있음). | STRING | 예 | 1~5000자 |
| `language` | 텍스트의 언어입니다. 세르비아어나 말레이어처럼 자동 감지가 혼동할 수 있는 유사 언어의 경우 설정하십시오(기본값: `"auto"`). | COMBO | 예 | `"auto"`<br />여러 언어 프리셋 |
| `expressiveness_boost` | 값이 높을수록 더 표현력이 풍부해지고, 낮을수록 원래 음성에 더 가깝게 유지됩니다(기본값: 0.5). | FLOAT | 예 | 0.0~1.0 (간격 0.05) |

**참고:** `voice_id`는 HeyGen Voice 1.0 Instant Clone으로 생성한 음성이어야 하며, 비어 있으면 노드가 오류와 함께 중지됩니다. `text`는 최소 1자 이상이어야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `AUDIO` | 텍스트에서 생성된 음성이며, 복제된 목소리로 말해집니다. | AUDIO |
