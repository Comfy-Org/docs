이 노드는 Qwen-Image 3.0 모델을 사용하여 텍스트 프롬프트에 따라 최대 3개의 참조 이미지를 편집하거나 결합합니다. 모델을 선택하고 프롬프트와 참조 이미지를 제공하면 노드는 하나 이상의 생성된 이미지를 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 사용할 모델입니다. 이 선택 항목에는 텍스트 프롬프트, 최대 3개의 참조 이미지 입력, 선택적 네거티브 프롬프트도 포함됩니다. | DYNAMIC_COMBO | 예 | "qwen-image-3.0-pro"<br />"qwen-image-3.0" |
| `size` | 출력 해상도입니다. "match input"은 첫 번째 참조 이미지의 크기를 재사용하고, "auto"는 모델이 동일한 종횡비의 크기를 선택하게 하며, "custom"은 명시적인 너비와 높이를 설정합니다. | DYNAMIC_COMBO | 예 | "match input"<br />"auto"<br />"custom" |
| `n` | 생성할 이미지 수이며 배치로 반환됩니다. (기본값: 1) | INT | 아니요 | 1 ~ 6 |
| `seed` | 생성에 사용할 시드입니다. (기본값: 42) | INT | 아니요 | 0 ~ 2147483647 |
| `prompt_extend` | AI 지원으로 프롬프트를 향상시킬지 여부입니다. (기본값: True) | BOOLEAN | 아니요 | True<br />False |
| `watermark` | 결과에 AI 생성 워터마크를 추가할지 여부입니다. (기본값: False) | BOOLEAN | 아니요 | True<br />False |

### qwen-image-3.0-pro 및 qwen-image-3.0 입력

두 모델은 동일한 하위 매개변수를 공유합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 편집 지침입니다. 영어와 중국어를 지원하며 입력 이미지에 대한 @Image1 스타일 참조를 지원합니다. (기본값: "") | STRING | 예 | - |
| `negative_prompt` | 피해야 할 내용을 설명하는 네거티브 프롬프트입니다. (기본값: "") | STRING | 아니요 | - |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 확장 가능한 슬롯: 1~3개의 참조 이미지(`image_1`, `image_2`, `image_3`)를 연결합니다. 프롬프트에서 입력 순서대로 번호가 매겨진 @Image1, @Image2, @Image3으로 참조합니다. 배치 입력은 이미지당 한 번으로 계산됩니다. | IMAGE | 예 | 1 ~ 3 |

### 사용자 지정 크기 입력

`size`가 "custom"으로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `width` | 출력 너비입니다. 총 픽셀 면적은 512x512 이상 2560x2560 이하여야 하며 종횡비는 1:8 이상 8:1 이하여야 합니다. (기본값: 1024) | INT | 예 (`size`가 "custom"인 경우) | 256 ~ 2560, step 16 |
| `height` | 출력 높이입니다. 총 픽셀 면적은 512x512 이상 2560x2560 이하여야 하며 종횡비는 1:8 이상 8:1 이하여야 합니다. (기본값: 1024) | INT | 예 (`size`가 "custom"인 경우) | 256 ~ 2560, step 16 |

### 제약 조건

- 텍스트 프롬프트는 필수이며 최소 한 자 이상 포함해야 합니다.
- 최대 3개의 참조 이미지를 지원합니다. 더 많이 제공하면 오류가 발생합니다(배치 입력은 이미지당 한 번으로 계산됩니다).
- `size`가 "custom"으로 설정된 경우 명시적인 너비와 높이 값을 제공해야 하며 다음 조건이 검증됩니다: 총 픽셀 면적은 262,144 (512x512) 이상 6,553,600 (2560x2560) 이하여야 하고 종횡비는 1:8 이상 8:1 이하여야 합니다.
- `size`가 "match input"으로 설정된 경우 첫 번째 참조 이미지의 크기가 사용되므로 최소 하나의 참조 이미지가 필요합니다. 크기는 지원되는 면적 및 종횡비 범위에 맞게 조정됩니다.
- `size`가 "auto"로 설정된 경우 모델은 입력 종횡비를 유지하면서 출력 크기(1.9~4.2 메가픽셀)를 선택합니다.
- 프롬프트 참조는 입력 순서대로 번호가 매겨진 @Image1, @Image2, @Image3을 사용합니다. 연결된 이미지 수보다 높은 인덱스를 참조하면 오류가 발생합니다. 태그는 단어 경계에서만 인식되므로 user@image1.com과 같은 주소는 그대로 유지됩니다.
- 입력 참조 이미지는 API로 전송되기 전에 최대 2048x2048 픽셀로 축소됩니다. PNG 인코딩이 API 크기 제한을 초과하면 JPEG 인코딩이 대신 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 생성된 이미지를 배치로 반환합니다. 최대 `n`개의 이미지가 반환됩니다. | IMAGE |
