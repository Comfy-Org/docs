이 노드는 Qwen-Image 3.0 모델을 사용하여 텍스트 프롬프트를 기반으로 최대 3개의 참조 이미지를 편집하거나 결합합니다. 텍스트 프롬프트와 참조 이미지를 제공하면 노드는 생성된 결과를 하나 이상의 이미지로 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 사용할 모델입니다. 이 선택 항목에는 텍스트 프롬프트, 최대 3개의 참조 이미지 입력, 선택적 네거티브 프롬프트도 포함됩니다. | COMBO | 예 | "qwen-image-3.0-pro"<br />"qwen-image-3.0" |
| `size` | 출력 해상도입니다. "match input"은 첫 번째 참조 이미지의 크기를 재사용하고, "auto"는 모델이 동일한 종횡비의 크기를 선택하며, "custom"은 명시적인 너비와 높이를 설정합니다. | COMBO | 예 | "match input"<br />"auto"<br />"custom" |
| `n` | 생성할 이미지 수이며 배치로 반환됩니다. (기본값: 1) | INT | 아니요 | 1 ~ 6 |
| `seed` | 생성에 사용할 시드입니다. (기본값: 42) | INT | 아니요 | 0 ~ 2147483647 |
| `prompt_extend` | AI 지원으로 프롬프트를 향상시킬지 여부입니다. (기본값: True) | BOOLEAN | 아니요 | True<br />False |
| `watermark` | 결과에 AI 생성 워터마크를 추가할지 여부입니다. (기본값: False) | BOOLEAN | 아니요 | True<br />False |

### 제약 조건

- 텍스트 프롬프트는 필수이며 최소 하나의 문자를 포함해야 합니다.
- 최대 3개의 참조 이미지가 지원되며, 그 이상 제공하면 오류가 발생합니다(배치 입력은 이미지당 한 번으로 계산됩니다).
- `size`가 "custom"으로 설정된 경우 명시적인 너비와 높이 값을 제공해야 하며 유효성 검사가 수행됩니다.
- `size`가 "match input"으로 설정된 경우 첫 번째 참조 이미지의 크기가 사용되므로 최소 하나의 참조 이미지가 필요합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| IMAGE | 생성된 이미지 또는 이미지 배치로 반환됩니다. 최대 `n`개의 이미지가 반환됩니다. | IMAGE |
