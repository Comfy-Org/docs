3D 모델을 의미적으로 유의미한 부분으로 분할하고 각 부분에 이름을 지정합니다. 기존 모델(작업 ID를 통해 제공됨)을 분할하거나, 먼저 이미지에서 모델을 생성한 다음 분할할 수 있습니다. 결과로 생성되는 `segment task_id`는 Tripo: Segment Model 결과와 동일한 방식으로 Complete Mesh Parts, Retopology, Texture model, Convert model 등 다른 Tripo 노드에서 사용할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `source` | 기존 모델을 분할하거나, 이미지에서 모델을 생성한 후 분할합니다. 선택한 옵션에 따라 표시되는 추가 입력이 결정됩니다. | DYNAMIC_COMBO | 예 | `"model"`<br />`"image"` |

### 모델 입력

`source`가 `"model"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | GLB 결과입니다. Quad (FBX) 메시는 먼저 Tripo: Convert model (GLTF)를 거쳐야 합니다. | MODEL_TASK_ID | 예 | - |
| `granularity` | 모델이 부분으로 분할되는 세분화 정도입니다(기본값: "medium"). | COMBO | 아니요 | `"coarse"`<br />`"medium"`<br />`"fine"` |
| `hint` | 찾을 부분의 이름을 지정하는 선택적 텍스트입니다. 예: '검과 갑옷을 든 게임 캐릭터'(기본값: 비어 있음). | STRING | 아니요 | - |

### 이미지 입력

`source`가 `"image"`로 설정된 경우 표시됩니다. Tripo는 먼저 이미지에서 모델을 생성한 다음 분할합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 분할할 모델을 생성하는 데 사용되는 이미지입니다. | IMAGE | 예 | - |
| `granularity` | 모델이 부분으로 분할되는 세분화 정도입니다(기본값: "medium"). | COMBO | 아니요 | `"coarse"`<br />`"medium"`<br />`"fine"` |
| `hint` | 찾을 부분의 이름을 지정하는 선택적 텍스트입니다. 예: '검과 갑옷을 든 게임 캐릭터'(기본값: 비어 있음). | STRING | 아니요 | - |

**참고:**

- `granularity`와 `hint`는 두 `source` 옵션에서 공통으로 사용되며 선택 사항입니다. `hint`를 비워 두면 서비스로 힌트가 전송되지 않습니다.
- `source`가 `"model"`인 경우 GLB 모델만 허용됩니다. Quad (FBX) 메시와 같은 다른 형식은 먼저 Tripo: Convert model (GLTF)로 변환해야 합니다.
- 작업은 종료 상태에 도달할 때까지 폴링되며, 예상 소요 시간은 약 180초입니다. Tripo가 불완전한 분할 결과를 반환하면 노드는 오류를 보고합니다.
- 가격 배지: `source`가 `"image"`일 때 약 0.85 USD, `source`가 `"model"`일 때 약 0.55 USD입니다(값은 대략적으로 표시됨).

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `segment task_id` | 분할 작업의 작업 ID로, 다른 Tripo 노드의 입력으로 사용할 수 있습니다. | SEGMENT_TASK_ID |
| `model task_id` | 분할된 모델입니다(이미지에서 생성되었거나 가져온 모델). | MODEL_TASK_ID |
| `GLB` | 분할된 3D 모델 파일입니다. | FILE3DGLB |
| `part_names` | 쉼표로 구분된 부분 이름입니다. | STRING |
| `parts` | Tripo가 찾은 부분에 대한 설명입니다. | STRING |
| `mask` | 분할로 생성된 마스크 이미지입니다. | IMAGE |
