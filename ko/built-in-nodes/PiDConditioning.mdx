latent와 `degrade_sigma` 값을 CONDITIONING에 첨부하여 PiD 디코딩 또는 업스케일링에 사용할 수 있게 합니다. 이를 통해 latent가 처리되기 전에 얼마나 열화될지 제어할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `포지티브` | latent와 `degrade_sigma`를 첨부할 컨디셔닝 데이터입니다. | CONDITIONING | 예 | - |
| `latent` | 컨디셔닝에 첨부할 latent입니다(VAEEncode 또는 KSampler에서 가져옴). | LATENT | 예 | - |
| `latent_format` | latent의 형식입니다. Flux1(16-ch) 및 Flux2(128-ch) latent는 `"flux"` 선택 시 채널 차원에서 자동 감지됩니다. SD3(16-ch), SDXL(4-ch) 또는 QwenImage(16-ch)의 경우 수동으로 선택합니다(기본값: `"flux"`). | COMBO | 예 | `"flux"`<br />`"sd3"`<br />`"sdxl"`<br />`"qwenimage"` |
| `degrade_sigma` | 적용할 열화 정도입니다. 0은 깨끗한 latent를 의미합니다. 손상된 latent 출력의 노이즈를 제거하려면 이 값을 높입니다(기본값: 0.0). | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.01) |

참고: `latent_format`이 `"flux"`로 설정되면 노드는 채널 차원에서 latent 유형을 자동 감지합니다. 128개 채널은 Flux2 latent로 처리되고, 16개 채널은 Flux1 latent로 처리됩니다.

참고: 지원되지 않는 `latent_format` 값은 오류를 발생시키지만, 사용 가능한 모든 옵션은 노드에서 처리됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-----------|-----------|
| `CONDITIONING` | 원본 컨디셔닝 데이터에 latent와 `degrade_sigma` 값이 첨부된 데이터입니다. | CONDITIONING |
