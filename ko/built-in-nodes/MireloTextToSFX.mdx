Mirelo SFX를 사용하여 텍스트 설명으로부터 음향 효과를 생성합니다. 해당 소리가 속한 그림이 아니라 소리 자체를 설명하면, 노드가 요청한 길이의 단일 오디오 트랙을 반환합니다. 영상을 촬영하거나 업로드하지 않고도 폴리(Foley), 앰비언스, 임팩트 및 짧은 음악적 텍스처에 사용할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 사용할 모델입니다. 모델을 선택하면 해당 모델에 특화된 매개변수인 `prompt`, `negative_prompt`, `duration`, `seed`가 표시됩니다. | DYNAMIC_COMBO | 예 | `"sfx-2.0"` |
| `prompt` | 그림이 아니라 소리를 설명합니다. 1~2000자입니다. | STRING | 예 | 1 ~ 2000자 |
| `negative_prompt` | 피해야 할 소리를 짧은 쉼표 구분 목록으로 지정합니다. 비워 둘 수 있습니다(기본값: 비어 있음). 최대 1000자입니다. | STRING | 예 | 최대 1000자 |
| `duration` | 소리의 길이(초)입니다. (기본값: 5.0) | FLOAT | 예 | 0.1  ~  600.0 (단계: 0.1) |
| `seed` | 요청에 사용할 시드입니다. 결과는 비결정적이므로 동일한 시드로도 같은 소리가 반복되지 않습니다. (기본값: 42) | INT | 예 | 0  ~  4294967295 |

`prompt`가 비어 있거나 2000자를 초과하는 경우, 그리고 `negative_prompt`가 1000자를 초과하는 경우 노드는 오류와 함께 중지됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `AUDIO` | 생성된 음향 효과로, `duration` 길이만큼입니다. | AUDIO |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/MireloTextToSFX/ko.md)
