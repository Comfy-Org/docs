Tencent HY Image: Edit 노드는 Tencent의 Hunyuan Image 모델을 사용하여 텍스트 지시로 참조 이미지를 편집하거나 결합합니다. 1~5개의 이미지를 연결하고, 프롬프트에서 변경 사항을 설명하며 이미지를 `@Image1`, `@Image2` 등으로 참조하세요. 이 노드는 참조 이미지를 업로드하고 API로 요청을 보낸 뒤 편집된 결과를 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 편집에 사용되는 모델입니다. 선택한 모델에 따라 표시되는 추가 입력이 결정됩니다. | DYNAMIC_COMBO | 예 | `"hy-image-3.5-preview"` |

### hy-image-3.5-preview 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 편집 지침입니다. 연결된 이미지에 대해 `@Image1` 형식 참조를 지원합니다. 비어 있으면 안 됩니다(기본값: 비어 있음). | STRING | 예 | 임의 텍스트 |
| `aspect_ratio` | 출력의 가로세로 비율입니다. `"auto"`는 첫 번째 참조 이미지의 가로세로 비율을 따르며 4K에서는 사용할 수 없습니다. `resolution`이 `"custom"`이면 무시됩니다. | COMBO | 예 | `"auto"`<br />`"1:1"`<br />`"3:2"`<br />`"2:3"`<br />`"4:3"`<br />`"3:4"`<br />`"16:9"`<br />`"9:16"`<br />`"21:9"`<br />`"9:21"` (기본값: `"auto"`) |
| `resolution` | 출력의 픽셀 면적입니다. 1K는 약 1024x1024, 2K는 약 2048x2048, 4K는 약 4096x4096입니다. 2K를 초과하는 해상도는 2K로 렌더링된 후 모델에 의해 업스케일됩니다. `"custom"`으로 설정하면 사전 설정 영역 대신 `width`와 `height`를 사용합니다. | COMBO | 예 | `"1K"`<br />`"2K"`<br />`"4K"`<br />`"custom"` (기본값: `"2K"`) |
| `width` | 출력의 너비(픽셀)입니다. `resolution`이 `"custom"`일 때만 사용됩니다. | INT | 예 | 256-8192, 16 단위 (기본값: 2048) |
| `height` | 출력의 높이(픽셀)입니다. `resolution`이 `"custom"`일 때만 사용됩니다. | INT | 예 | 256-8192, 16 단위 (기본값: 2048) |
| `seed` | 생성에 사용되는 시드입니다. 동일한 시드로도 실행할 때마다 결과가 달라질 수 있습니다. | INT | 예 | 0-2147483647 (기본값: 42) |
| `reference_detail` | 모델이 참조 이미지의 세부 정보를 얼마나 자세히 보는지 결정합니다. `"standard"`는 이미지당 최대 1024x1024 픽셀을 허용하고, `"high"`는 최대 2048x2048을 허용하며 작은 텍스트와 미세한 세부 정보를 더 잘 보존하지만 시간이 더 오래 걸립니다. 이는 고급 매개변수입니다. | COMBO | 아니요 | `"standard"`<br />`"high"` (기본값: `"standard"`) |
| `watermark` | 결과에 AI 생성 워터마크를 추가할지 여부입니다. 이는 고급 매개변수입니다. | BOOLEAN | 아니요 | true<br />false (기본값: false) |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 편집하거나 결합할 참조 이미지입니다. 확장 가능한 슬롯입니다. 1~5개의 이미지를 연결하세요(`image_1`부터 `image_5`까지). 프롬프트에서 입력 순서대로 번호가 매겨진 `@Image1` ... `@Image5`로 참조하세요. 배치 입력은 이미지마다 각각 하나로 계산됩니다. | IMAGE | 예 | 1-5개 이미지 |

`prompt`는 비어 있으면 안 되며, 이미지가 1개 또는 2개만 연결된 경우 `@Image3`과 같은 프롬프트 참조는 오류를 발생시킵니다. 총 최대 5개의 참조 이미지를 사용할 수 있으며, 배치의 각 이미지는 개별적으로 계산됩니다. `"custom"` 해상도에서는 `width`와 `height`가 모두 16의 배수여야 하며, 두 값의 곱은 4096 x 4096 픽셀 면적 제한(약 16.7메가픽셀)을 초과해서는 안 됩니다. 어떤 가로세로 비율이든 작동하지만, 대략 6:1을 넘으면 모델이 피사체를 반복하기 시작합니다. `"auto"` 가로세로 비율은 2K 면적 제한 내에서만 작동하므로 4K에서는 명시적인 가로세로 비율을 선택하거나 `"custom"`을 사용하세요.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 참조 이미지와 프롬프트로 생성된 편집된 이미지입니다. | IMAGE |
