WanFunInpaintToVideo 노드는 인페인팅 스타일 비디오 생성을 위해 컨디셔닝 및 잠재(latent) 데이터를 준비하며, 선택적인 시작 이미지와 끝 이미지를 사용하여 결과를 안내합니다. 이 노드는 제공된 컨디셔닝, VAE 및 이미지 프레임을 첫 프레임 및 마지막 프레임 비디오 생성에 사용되는 것과 동일한 로직으로 전달하며, 업데이트된 컨디셔닝과 샘플링용 빈 잠재(latent)를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `긍정 조건` | 비디오 생성을 위한 긍정 컨디셔닝 프롬프트 | CONDITIONING | 예 | - |
| `부정 조건` | 비디오 생성 시 피해야 할 부정 컨디셔닝 프롬프트 | CONDITIONING | 예 | - |
| `vae` | 비디오 프레임 인코딩 및 디코딩에 사용되는 VAE 모델 | VAE | 예 | - |
| `너비` | 출력 비디오 너비(픽셀) (기본값: 832, 단계: 16) | INT | 예 | 16 to MAX_RESOLUTION |
| `높이` | 출력 비디오 높이(픽셀) (기본값: 480, 단계: 16) | INT | 예 | 16 to MAX_RESOLUTION |
| `길이` | 비디오 시퀀스의 프레임 수 (기본값: 81, 단계: 4) | INT | 예 | 1 to MAX_RESOLUTION |
| `배치 크기` | 한 배치에서 생성할 비디오 수 (기본값: 1) | INT | 예 | 1  ~  4096 |
| `clip_vision 출력` | 시작 이미지에 대한 컨디셔닝으로 사용되는 선택적 CLIP 비전 출력 | CLIP_VISION_OUTPUT | 아니요 | - |
| `시작 이미지` | 비디오 생성을 위한 선택적 시작 프레임 이미지 | IMAGE | 아니요 | - |
| `종료 이미지` | 비디오 생성을 위한 선택적 끝 프레임 이미지 | IMAGE | 아니요 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `positive` | 처리된 긍정 컨디셔닝 출력 | CONDITIONING |
| `negative` | 처리된 부정 컨디셔닝 출력 | CONDITIONING |
| `latent` | 생성된 비디오 잠재 표현 | LATENT |
