ByteDance의 Seed 2.0 모델을 사용하여 텍스트 응답을 생성합니다. 텍스트 프롬프트를 제공하고 선택적으로 이미지나 비디오를 포함하여 멀티모달 컨텍스트를 제공할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 응답을 생성하는 데 사용되는 Seed 모델입니다. | DYNAMIC_COMBO | 예 | `"Seed 2.0 Pro"`<br />`"Seed 2.0 Lite"`<br />`"Seed 2.0 Mini"` |
| `프롬프트` | 모델에 대한 텍스트 입력입니다. (기본값: "") | STRING | 예 | N/A |
| `시드` | 시드는 노드가 다시 실행되어야 하는지 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. (기본값: 0) | INT | 예 | 0 ~ 2147483647 |
| `시스템 프롬프트` | 모델의 동작을 규정하는 기본 지침입니다. (기본값: "") | STRING | 아니요 | N/A |

### 모델 입력 (Seed 2.0 Pro, Seed 2.0 Lite 및 Seed 2.0 Mini 공통)

세 가지 Seed 모델 모두 선택 시 동일한 하위 매개변수를 노출합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `temperature` | 무작위성을 제어합니다. 0.0은 결정적이며, 값이 높을수록 더 무작위적입니다. (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 2.0 (step: 0.01) |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 모델의 컨텍스트로 사용할 선택적 이미지입니다. 최대 20개의 이미지. 확장 가능한 슬롯: 1~20개 항목을 연결하세요 (예: `image_1`부터 `image_20`까지). | IMAGE | 아니요 | 0 ~ 20 images |
| `videos` | 모델의 컨텍스트로 사용할 선택적 비디오입니다. 최대 4개의 비디오. 확장 가능한 슬롯: 1~4개 항목을 연결하세요 (예: `video_1`부터 `video_4`까지). | VIDEO | 아니요 | 0 ~ 4 videos |

**참고:** `model` 매개변수는 모델을 선택하면 참조 및 temperature 하위 매개변수를 노출하는 동적 콤보입니다. 이미지 및 비디오 입력을 이 매개변수에 연결하여 멀티모달 컨텍스트를 제공할 수 있습니다. 요청당 최대 20개의 이미지와 4개의 비디오가 지원되며, `prompt`는 필수이며 공백이 아닌 문자를 하나 이상 포함해야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | Seed 모델에서 생성된 텍스트 응답입니다. | STRING |
