ByteDance의 Seed 2.0 모델로 텍스트 응답을 생성합니다. 텍스트 프롬프트를 제공하고 선택적으로 이미지나 비디오를 연결하여 모델에 추가 컨텍스트를 제공할 수 있습니다. 사용 가능한 Seed 2.0 변형 중에서 모델을 선택하며, 노드는 모델의 텍스트 답변을 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 모델에 입력할 텍스트입니다. (기본값: "") | STRING | 예 | N/A |
| `모델` | 응답을 생성하는 데 사용할 Seed 모델입니다. 이 선택기에서는 모델의 하위 매개변수도 노출됩니다. | DYNAMIC_COMBO | 예 | `"Seed 2.0 Pro"`<br />`"Seed 2.0 Lite"`<br />`"Seed 2.0 Mini"` |
| `시드` | 시드는 노드의 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. (기본값: 0) | INT | 예 | 0 ~ 2147483647 |
| `시스템 프롬프트` | 모델의 동작을 규정하는 기본 지침입니다. (기본값: "") | STRING | 아니요 | N/A |

### 모델 입력 (Seed 2.0 Pro, Seed 2.0 Lite 및 Seed 2.0 Mini에서 공유)

세 Seed 모델 모두 선택 시 동일한 하위 매개변수를 노출합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `temperature` | 무작위성을 제어합니다. 0.0은 결정적이며, 값이 높을수록 더 무작위적입니다. (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 2.0 (단계: 0.01) |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 모델의 컨텍스트로 사용할 선택적 이미지입니다. 최대 20개 이미지. 확장 가능한 슬롯: 1..20개 항목을 연결합니다(예: `image_1`부터 `image_20`까지). | IMAGE | 아니요 | 이미지 0~20개 |
| `videos` | 모델의 컨텍스트로 사용할 선택적 비디오입니다. 최대 4개 비디오. 확장 가능한 슬롯: 1..4개 항목을 연결합니다(예: `video_1`부터 `video_4`까지). | VIDEO | 아니요 | 비디오 0~4개 |

**참고:** `model` 매개변수는 동적 콤보이며, 모델을 선택하면 참조 및 temperature 하위 매개변수가 나타납니다. `images` 및 `videos` 슬롯은 확장 가능하므로 멀티모달 컨텍스트를 위해 여러 입력을 연결할 수 있습니다.

- `prompt`는 필수이며 공백이 아닌 문자를 하나 이상 포함해야 합니다. 그렇지 않으면 오류가 발생합니다.
- 요청당 최대 20개 이미지가 지원됩니다. 이 제한은 연결된 배치 전체의 모든 이미지를 계산합니다.
- 요청당 최대 4개 비디오가 지원됩니다.
- 모델이 빈 응답을 반환하거나 응답을 거부하면 오류가 발생합니다(거부 텍스트가 보고됩니다).

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | Seed 모델에서 생성된 텍스트 응답입니다. | STRING |
