이 노드는 Bria를 사용하여 인물에게 의상이나 액세서리를 착용시킵니다. 인물의 정체성, 포즈, 배경은 유지되지만 장면이 약 1메가픽셀 해상도로 다시 렌더링되므로 결과는 입력 사진과 픽셀 단위로 정렬되지 않습니다. 각 의상 이미지는 인물이 이미 착용하고 있는 해당 품목을 대체합니다.

## 입력

`moderation` 선택기를 `"true"`로 설정하면 추가 검열 옵션이 나타납니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `person_image` | 의상을 착용해 볼 인물의 사진입니다. 이미지가 업로드되기 전에 알파 채널이 제거됩니다. | IMAGE | 예 | - |
| `garment_images` | 함께 착용할 1~3개의 의상 또는 액세서리로, 각각 인물이 착용 중인 해당 품목을 대체합니다. 배치 입력은 이미지당 한 번으로 계산되며 투명 영역은 흰색으로 처리됩니다. | AUTOGROW | 예 | 1~3개 이미지 |
| `instruction` | Bria의 내장 지시문에 추가되는 선택적 지시 사항으로, 예를 들어 어느 의상을 맨 위에 겹쳐 입을지 지정할 수 있습니다. 기본값: `""`(빈 문자열). | STRING | 예 | - |
| `aspect_ratio` | `"auto"`는 인물 사진의 구도를 약 1메가픽셀 수준으로 유지합니다. 고정 비율은 0.6~1메가픽셀의 결과를 반환하며, 예를 들어 `"3:4"`의 경우 768x1024입니다. 기본값: `"auto"`. | COMBO | 예 | `"auto"`<br />`"1:1"`<br />`"2:3"`<br />`"3:2"`<br />`"3:4"`<br />`"4:3"`<br />`"4:5"`<br />`"5:4"`<br />`"9:16"`<br />`"16:9"` |
| `seed` | 요청과 함께 Bria로 전송되는 시드입니다. 기본값: 42. | INT | 예 | 1~2147483647 |
| `moderation` | 검열 설정입니다. `"true"`로 설정하면 아래의 검열 플래그를 사용할 수 있습니다. | DYNAMIC_COMBO | 예 | `"false"`<br />`"true"` |

### Moderation "true" 입력

이 매개변수는 `moderation`이 `"true"`로 설정된 경우에만 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `visual_output_moderation` | 생성된 이미지에 콘텐츠 검열을 활성화합니다. 기본값: `False`. | BOOLEAN | 아니요 | True / False |

**제약 사항:**

* `garment_images`는 최대 3개의 이미지를 허용하며, 입력이 배치인 경우 이미지당 하나로 계산됩니다.
* 의상 이미지의 투명 픽셀은 업로드 전에 흰색 위에 합성됩니다.
* `person_image`의 알파 채널은 업로드 전에 제거됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 인물이 제공된 의상을 착용하고 있는 편집된 사진입니다. | IMAGE |
