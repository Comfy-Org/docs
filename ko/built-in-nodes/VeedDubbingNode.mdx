VEED Dubbing은 VEED를 통해 영상 속 음성을 다른 언어로 번역하며, 각 화자의 목소리를 복제하고 입 모양을 번역에 맞춰 동기화합니다. 클립이 업로드되고 VEED 작업이 폴링되며, 더빙된 영상은 새 오디오 트랙과 같은 길이로 25 fps로 반환됩니다. 완성된 클립을 다시 촬영하거나 음성을 다시 녹음하지 않고 현지화할 때 사용하세요.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 더빙 모델입니다. `"standard"`는 더 저렴하고 모노 오디오를 반환하며 라틴 아메리카 스페인어와 브라질 포르투갈어를 지원합니다. `"pro"`는 지역 억양과 스테레오 오디오를 추가합니다. 모델을 선택하면 `video`, `target_language`, `source_language` 및 `seed`가 표시됩니다. | DYNAMIC_COMBO | 예 | `"standard"`<br />`"pro"` |

### standard 입력

`model`이 `"standard"`로 설정된 경우 표시되는 입력입니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video` | 얼굴이 보이고 음성이 포함된 영상으로, 최대 599초까지 가능합니다. 출력은 오디오 트랙과 같은 길이이며 25 fps로 재생됩니다. | VIDEO | 예 | 최대 599초 |
| `target_language` | 더빙할 대상 언어로, 85개 언어 중 하나입니다. (기본값: `"English"`) | COMBO | 예 | 85개 언어 |
| `source_language` | 영상에서 사용되는 언어이거나, 자동 감지를 위한 `"auto"`입니다. (기본값: `"auto"`) | COMBO | 예 | `"auto"`<br />85개 언어 |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. (기본값: 42) | INT | 예 | 0 ~ 2147483647 |

### pro 입력

`model`이 `"pro"`로 설정된 경우 표시되는 입력입니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video` | 얼굴이 보이고 음성이 포함된 영상으로, 최대 599초까지 가능합니다. 출력은 오디오 트랙과 같은 길이이며 25 fps로 재생됩니다. | VIDEO | 예 | 최대 599초 |
| `target_language` | 더빙할 대상 언어 또는 지역 억양입니다: 87개 언어와 `"English (UK)"`, `"Spanish (Mexico)"`, `"Portuguese (Brazil)"` 같은 14개 억양이 포함됩니다. (기본값: `"English (US)"`) | COMBO | 예 | 101개 옵션 |
| `source_language` | 영상에서 사용되는 언어이거나, 자동 감지를 위한 `"auto"`입니다. (기본값: `"auto"`) | COMBO | 예 | `"auto"`<br />91개 언어 |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. (기본값: 42) | INT | 예 | 0 ~ 2147483647 |

영상에 오디오 트랙이 없거나, 클립이 599초보다 길거나, VEED 작업이 실패하면 노드가 오류와 함께 중지됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 더빙된 영상입니다. 번역된 음성과 이에 맞춰진 입 모양이 적용된 원본 영상입니다. | VIDEO |
