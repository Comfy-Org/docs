작성된 지시문을 사용하여 기존 비디오 클립을 편집합니다. 객체를 제거, 추가 또는 교체하거나, 배경/장면을 변경하거나, 영상 스타일을 변경하거나, 화면 텍스트를 변경하거나, 음성 대사를 교체할 수 있습니다. 길이, 프레이밍, 카메라 움직임 및 오디오는 원본 클립에서 가져오므로, `prompt`에 언급하지 않은 내용은 원래대로 유지됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video` | 0.7~15초, 최소 160x160픽셀의 원본 클립입니다. 출력은 24fps로 렌더링되고 프레임당 약 0.9메가픽셀로 제한되므로, 더 큰 원본은 더 작게 반환됩니다. | VIDEO | 예 | 0.7~15초; 최소 160x160픽셀 |
| `prompt` | 변경할 내용을 일상적인 언어로 작성하며, 최대 4096자까지 가능합니다. 언급하지 않은 내용은 원래대로 유지됩니다. 교체 대사는 원래 음성이 차지하는 시간에 맞아야 하며, 무음 클립은 무음으로 유지됩니다. 기본값: 빈 문자열. | STRING | 예 | 1~4096자 |
| `auto_downscale` | 업로드 전에 영역이 1280x704픽셀보다 큰 원본을 자동으로 다운스케일합니다. 종횡비는 유지되며, 더 작은 비디오는 변경되지 않습니다. 기본값: true. | BOOLEAN | 아니요 | true<br />false |
| `safety_tolerance` | 검열 허용 범위이며, 0이 가장 엄격합니다. 기본값: 4. | INT | 아니요 | 0~4 |
| `seed` | 노드의 재실행 여부를 결정하는 시드입니다. FLUX는 자체 시드를 선택하므로, 이 값과 관계없이 실제 결과는 비결정적입니다. 기본값: 42. | INT | 아니요 | 0~4294967295 |

**참고:** `prompt`는 최소 1자 이상, 최대 4096자 이하여야 합니다. 원본 `video`는 길이가 0.7~15초여야 하고 최소 160x160픽셀이어야 합니다. 이러한 제한을 벗어난 업로드는 요청이 전송되기 전에 거부됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | FLUX 서비스에서 반환된 편집된 비디오 클립입니다. | VIDEO |
