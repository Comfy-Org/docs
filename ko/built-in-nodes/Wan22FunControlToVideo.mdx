The Wan22FunControlToVideo 노드는 Wan 비디오 모델을 사용한 비디오 생성을 위해 컨디셔닝 데이터와 빈 잠재 텐서를 준비합니다. 선택적 참조 이미지와 제어 비디오를 잠재 공간으로 인코딩하여 긍정 및 부정 컨디셔닝에 첨부하고, 요청된 비디오에 맞는 정확한 공간 및 시간 차원을 가진 0으로 채워진 잠재 텐서를 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `긍정 프롬프트` | 비디오 생성을 안내하는 긍정 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `부정 프롬프트` | 비디오 생성을 안내하는 부정 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `VAE` | 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델 | VAE | 예 | - |
| `너비` | 출력 비디오의 픽셀 너비 (기본값: 832, 간격: 16) | INT | 예 | 16 to MAX_RESOLUTION |
| `높이` | 출력 비디오의 픽셀 높이 (기본값: 480, 간격: 16) | INT | 예 | 16 to MAX_RESOLUTION |
| `길이` | 비디오 시퀀스의 프레임 수 (기본값: 81, 간격: 4) | INT | 예 | 1 to MAX_RESOLUTION |
| `배치 크기` | 생성할 비디오 시퀀스 수 (기본값: 1) | INT | 예 | 1 ~ 4096 |
| `참조 이미지` | 생성에 시각적 안내를 제공하는 선택적 참조 이미지 | IMAGE | 아니요 | - |
| `제어 비디오` | 생성 과정을 안내하는 선택적 제어 비디오 | IMAGE | 아니요 | - |

**참고:** `length` 매개변수는 4프레임 단위로 처리되며, 노드는 잠재 공간을 구성할 때 시간적 스케일링을 자동으로 적용합니다. `ref_image`가 제공되면 첫 번째 프레임만 인코딩되어 참조 잠재값으로 컨디셔닝에 첨부됩니다. `control_video`가 제공되면 `length` 프레임으로 잘린 후 인코딩되어 컨디셔닝에서 사용하는 concat 잠재값에 배치됩니다. `start_image` 매개변수는 실행 로직에서 참조되지만 노드의 입력 스키마에는 노출되지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `긍정 프롬프트` | concat 잠재값, 마스크 및 선택적 참조 잠재값을 포함하여 비디오별 잠재 데이터가 추가된 긍정 컨디셔닝 | CONDITIONING |
| `부정 프롬프트` | concat 잠재값, 마스크 및 선택적 참조 잠재값을 포함하여 비디오별 잠재 데이터가 추가된 부정 컨디셔닝 | CONDITIONING |
| `잠재 공간` | 배치 크기, 잠재 채널, 길이, 높이 및 너비에 따라 크기가 지정된 비디오 생성용 빈 잠재 텐서 | LATENT |
