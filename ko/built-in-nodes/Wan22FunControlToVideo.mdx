Wan22FunControlToVideo 노드는 Wan 비디오 모델을 사용한 비디오 생성을 위해 컨디셔닝 데이터와 빈 잠재 텐서를 준비합니다. 선택적 참조 이미지와 제어 비디오를 잠재 공간으로 인코딩하고, 이를 긍정 및 부정 컨디셔닝에 연결하며, 요청된 비디오에 맞는 올바른 공간 및 시간 차원을 가진 0으로 채워진 잠재 텐서를 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `긍정 프롬프트` | 비디오 생성을 유도하기 위한 긍정 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `부정 프롬프트` | 비디오 생성을 유도하기 위한 부정 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `VAE` | 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델 | VAE | 예 | - |
| `너비` | 출력 비디오의 너비(픽셀) (기본값: 832, 단계: 16) | INT | 예 | 16 ~ MAX_RESOLUTION |
| `높이` | 출력 비디오의 높이(픽셀) (기본값: 480, 단계: 16) | INT | 예 | 16 ~ MAX_RESOLUTION |
| `길이` | 비디오 시퀀스의 프레임 수 (기본값: 81, 단계: 4) | INT | 예 | 1 ~ MAX_RESOLUTION |
| `배치 크기` | 생성할 비디오 시퀀스 수 (기본값: 1) | INT | 예 | 1 ~ 4096 |
| `참조 이미지` | 생성에 시각적 지침을 제공하는 선택적 참조 이미지 | IMAGE | 아니요 | - |
| `제어 비디오` | 생성 과정을 안내하는 선택적 제어 비디오 | IMAGE | 아니요 | - |

**참고:** `length` 매개변수는 4프레임 단위로 처리되며, 노드는 잠재 공간을 구성할 때 시간 스케일링을 자동으로 적용합니다. `ref_image`가 제공되면 첫 번째 프레임만 인코딩되어(`width` x `height`로 크기 조정) 참조 잠재로 컨디셔닝에 연결됩니다. `control_video`가 제공되면 `length` 프레임으로 잘라내고, 크기를 조정하고, 인코딩한 뒤 컨디셔닝에서 사용하는 concat 잠재에 배치합니다. 연결된 잠재는 채널 차원을 따라 복제되며, 채널 레이아웃은 VAE의 잠재 채널 수에 따라 달라집니다(48채널은 Wan 2.2 형식을 사용하고, 그렇지 않으면 Wan 2.1 형식을 사용합니다). `start_image` 매개변수는 실행 로직에서 참조되지만 노드의 입력 스키마에 노출되지 않으므로 노드 인터페이스에서 설정할 수 없습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `positive` | 비디오별 잠재 데이터가 추가된 긍정 컨디셔닝으로, concat 잠재, 마스크 및 선택적 참조 잠재를 포함합니다 | CONDITIONING |
| `negative` | 비디오별 잠재 데이터가 추가된 부정 컨디셔닝으로, concat 잠재, 마스크 및 선택적 참조 잠재를 포함합니다 | CONDITIONING |
| `latent` | 비디오 생성을 위해 준비된 빈 잠재 텐서로, 배치 크기, 잠재 채널, 길이, 높이 및 너비에 따라 크기가 지정됩니다 | LATENT |
