ByteDance 텍스트로 비디오 노드는 텍스트 프롬프트를 기반으로 ByteDance 모델을 통해 API를 통해 비디오를 생성합니다. 텍스트 설명과 다양한 비디오 설정을 입력으로 받아, 제공된 사양에 맞는 비디오를 생성합니다. 노드는 API 통신을 처리하고 생성된 비디오를 출력으로 반환합니다.

## 개요

ByteDance 텍스트로 비디오 노드는 ByteDance의 AI 기능을 사용하여 텍스트 프롬프트를 비디오로 변환하는 데 설계되었습니다. 사용자는 모델, 해상도, 비율, 지속 시간 등 다양한 매개변수를 지정하여 비디오 생성 과정을 제어할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 생성에 사용할 ByteDance 모델입니다. | STRING | 예 | 
  - "seedance-1-5-pro-251215"
  - "seedance-1-0-pro-250528"
  - "seedance-1-0-pro-fast-251015" |
| `prompt` | 비디오를 생성하는 데 사용할 텍스트 프롬프트입니다. | STRING | 예 | 다중 줄 텍스트 입력 |
| `resolution` | 출력 비디오의 해상도입니다. | STRING | 예 | 
  - "480p"
  - "720p"
  - "1080p" |
| `aspect_ratio` | 출력 비디오의 비율입니다. | STRING | 예 | 
  - "16:9"
  - "4:3"
  - "1:1"
  - "3:4"
  - "9:16"
  - "21:9" |
| `duration` | 출력 비디오의 지속 시간(초)입니다. | INT | 예 | 3초에서 12초 사이 |
| `seed` | 생성에 사용할 시드입니다. | INT | 아님 | 0에서 2,147,483,647 사이 |
| `camera_fixed` | 카메라를 고정할지 여부를 지정합니다. | BOOLEAN | 아님 | - |
| `watermark` | 비디오에 "AI 생성" 워터마크를 추가할지 여부를 지정합니다. | BOOLEAN | 아님 | - |
| `generate_audio` | 이 매개변수는 `seedance-1-5-pro-251215` 모델을 제외한 모든 모델에서 무시됩니다. | BOOLEAN | 아님 | - |

**매개변수 제약 조건:**

- `prompt`은 공백 제거 후 최소 1자리 이상이어야 합니다.
- `prompt`은 다음 텍스트 매개변수를 포함할 수 없습니다: "resolution", "ratio", "duration", "seed", "camerafixed", "watermark".
- `duration`은 3초에서 12초 사이의 값을 가지도록 제한됩니다.
- `seedance-1-5-pro-251215` 모델에서는 최소 지원 지속 시간이 4초입니다.
- `seed`은 0에서 2,147,483,647 사이의 값을 받아들입니다.
- `generate_audio` 매개변수는 `model`이 `seedance-1-5-pro-251215`으로 설정되었을 때만 효과가 있으며, 다른 모델에서는 무시됩니다.

|-------------|-------------|-----------|
| `output` | 생성된 비디오 파일입니다. | 비디오 |
