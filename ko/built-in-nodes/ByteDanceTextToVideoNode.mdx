ByteDance Text to Video 노드는 텍스트 프롬프트를 기반으로 API를 통해 ByteDance 모델을 사용하여 비디오를 생성합니다. 사용자는 프롬프트를 제공하고 모델, 해상도, 종횡비, 지속 시간 등의 설정을 선택합니다. 그러면 노드가 생성 요청을 제출하고 생성된 비디오를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용되는 ByteDance 모델(기본값: `"seedance-1-0-pro-fast-251015"`). | COMBO | 예 | `"seedance-1-5-pro-251215"`<br />`"seedance-1-0-pro-250528"`<br />`"seedance-1-0-pro-fast-251015"` |
| `prompt` | 비디오 생성에 사용되는 텍스트 프롬프트. | STRING | 예 | - |
| `resolution` | 출력 비디오의 해상도. | COMBO | 예 | `"480p"`<br />`"720p"`<br />`"1080p"` |
| `aspect_ratio` | 출력 비디오의 종횡비. | COMBO | 예 | `"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"` |
| `duration` | 출력 비디오의 지속 시간(초) (기본값: 5). | INT | 예 | 3~12 |
| `seed` | 생성에 사용되는 시드(기본값: 0). | INT | 아니요 | 0~2,147,483,647 |
| `camera_fixed` | 카메라 고정 여부를 지정합니다. 플랫폼은 카메라를 고정하라는 지시문을 프롬프트에 추가하지만 실제 효과를 보장하지는 않습니다(기본값: False). | BOOLEAN | 아니요 | - |
| `watermark` | 비디오에 "AI 생성" 워터마크를 추가할지 여부(기본값: False). | BOOLEAN | 아니요 | - |
| `generate_audio` | 이 매개변수는 `seedance-1-5-pro-251215` 모델을 제외한 모든 모델에서 무시됩니다(기본값: False). | BOOLEAN | 아니요 | - |

**매개변수 제약 조건:**

- `prompt` 매개변수는 공백 제거 후 최소 1자를 포함해야 합니다.
- `prompt` 매개변수에는 다음 텍스트 매개변수를 포함할 수 없습니다: "resolution", "ratio", "duration", "seed", "camerafixed", "watermark".
- 노드는 선택한 `resolution`, `aspect_ratio`, `duration`, `seed`, `camera_fixed`, `watermark` 설정을 프롬프트 텍스트에 추가하여 최종 프롬프트를 구성합니다.
- `duration` 매개변수는 3초에서 12초 사이의 값으로 제한됩니다. `seedance-1-5-pro-251215` 모델의 경우 지원되는 최소 지속 시간은 4초입니다.
- `seed` 매개변수는 0부터 2,147,483,647까지의 값을 허용합니다.
- `generate_audio` 매개변수는 `model`이 `seedance-1-5-pro-251215`로 설정된 경우에만 적용되며, 다른 모든 모델에서는 무시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오 파일 | VIDEO |
