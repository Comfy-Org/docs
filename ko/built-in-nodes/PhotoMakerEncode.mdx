PhotoMakerEncode 노드는 참조 이미지와 텍스트 프롬프트를 결합하여 이미지 생성을 위한 컨디셔닝 데이터를 생성합니다. 텍스트에 "photomaker"라는 단어가 포함된 경우, 노드는 PhotoMaker 모델을 사용하여 프롬프트의 해당 위치에 참조 이미지의 시각적 정체성을 컨디셔닝에 삽입합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `포토메이커 모델` | 참조 이미지를 처리하고 이미지 기반 임베딩을 생성하는 데 사용되는 PhotoMaker 모델 | PHOTOMAKER | 예 | - |
| `이미지` | 컨디셔닝에 시각적 특성을 제공하는 참조 이미지 | IMAGE | 예 | - |
| `clip` | 텍스트 토큰화 및 텍스트 인코딩에 사용되는 CLIP 모델 | CLIP | 예 | - |
| `텍스트` | 컨디셔닝 생성을 위한 텍스트 프롬프트. 여러 줄 텍스트와 동적 프롬프트를 지원합니다(기본값: "photograph of photomaker") | STRING | 예 | 모든 문자열 |

**참고:** 텍스트에 "photomaker"가 독립 단어로 포함된 경우, 노드는 인코딩된 프롬프트에서 해당 단어를 제거하고 PhotoMaker 모델을 사용하여 해당 위치에 참조 이미지의 정체성을 적용합니다. 텍스트에 "photomaker"가 없으면 노드는 이미지 영향 없이 표준 텍스트 컨디셔닝을 반환합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `CONDITIONING` | 이미지 생성을 안내하는 텍스트 및 이미지 임베딩과 CLIP 텍스트 인코더의 풀링된 출력을 포함하는 컨디셔닝 데이터 | CONDITIONING |
