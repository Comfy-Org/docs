Create List 노드는 여러 입력을 하나의 순차적인 리스트로 결합합니다. 동일한 데이터 타입을 공유하는 원하는 수의 입력 슬롯을 받아들이며, 슬롯이 연결된 순서대로 해당 항목을 연결합니다. 결과는 연결된 모든 항목을 포함하는 하나의 리스트입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `입력값` | `input`, `input_2`, `input_3` 등으로 이름이 지정되는 가변 개수의 입력 슬롯입니다. 각 슬롯은 동일한 데이터 타입의 항목 리스트(예: 모두 IMAGE 또는 모두 STRING)를 받습니다. 필요에 따라 새 슬롯이 자동으로 생성됩니다. 노드는 슬롯 순서대로 리스트를 연결합니다. | Any | 예 | 슬롯 수 제한 없음; 각 슬롯은 항목 수 제한 없이 받을 수 있음 |

**참고:** 연결된 모든 입력은 동일한 데이터 타입을 공유해야 합니다. 각 연결된 슬롯은 항목 리스트를 제공하며, 노드는 슬롯 순서(`input`, 그다음 `input_2`, 그다음 `input_3`, ...)대로 리스트를 결합합니다. 이 노드는 "Image Iterator", "Text Iterator", "Iterator" 별칭으로도 검색할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `list` | 연결된 입력의 모든 항목을 포함하는 하나의 리스트로, 슬롯이 제공된 순서대로 연결됩니다. 출력 데이터 타입은 입력 데이터 타입과 일치합니다. | Any |
