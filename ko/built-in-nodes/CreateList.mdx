Create List 노드는 여러 입력을 하나의 순차 목록으로 결합합니다. 동일한 데이터 타입의 입력을 원하는 개수만큼 받아 연결된 순서대로 이어 붙입니다. 이 노드는 워크플로우의 다른 노드에서 처리할 이미지나 텍스트와 같은 데이터 배치를 준비하는 데 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `입력값` | `input`, `input_2`, `input_3` 등으로 이름이 지정된 가변 개수의 입력 슬롯입니다. 각 슬롯은 동일한 데이터 타입의 항목 목록을 허용합니다. 더하기(+) 아이콘을 클릭하여 슬롯을 더 추가할 수 있습니다. 모든 슬롯은 동일한 데이터 타입(예: 모두 IMAGE 또는 모두 STRING)을 사용해야 합니다. | 가변 | 예 | 슬롯 개수 무제한, 각 슬롯은 항목을 원하는 개수만큼 허용 |

**참고:** 노드는 항목을 연결할 때 자동으로 새 입력 슬롯을 생성합니다. 노드가 올바르게 작동하려면 연결된 모든 입력이 동일한 데이터 타입을 공유해야 합니다. 각 연결된 슬롯은 항목 목록을 제공하며, 노드는 슬롯 순서(`input`, 그다음 `input_2`, 그다음 `input_3`, ...)대로 목록을 결합합니다. 또한 이 노드는 "Image Iterator", "Text Iterator", "Iterator" 별칭으로도 검색할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `목록` | 연결된 입력의 모든 항목을 제공된 순서대로 이어 붙인 단일 목록입니다. 출력 데이터 타입은 입력 데이터 타입과 일치합니다. | 가변 |
