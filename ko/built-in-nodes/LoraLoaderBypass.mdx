LoraLoaderBypass 노드는 특수한 "바이패스" 모드로 확산 모델과 CLIP 모델에 LoRA(저차원 적응)를 적용합니다. 표준 LoRA 로더와 달리 이 방식은 기본 모델의 가중치를 영구적으로 수정하지 않습니다. 대신 LoRA의 효과를 모델의 일반적인 순방향 패스에 더하여 출력을 계산하며, 이는 학습이나 가중치가 오프로드된 모델로 작업할 때 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | LoRA가 적용될 확산 모델입니다. | MODEL | 예 | - |
| `clip` | LoRA가 적용될 CLIP 모델입니다. | CLIP | 예 | - |
| `lora_name` | LoRA의 이름입니다. 사용 가능한 LoRA 파일은 `loras` 폴더에서 불러옵니다. | COMBO | 예 | 사용 가능한 LoRA 파일 목록 |
| `strength_model` | 확산 모델을 수정하는 강도입니다. 이 값은 음수일 수 있습니다(기본값: 1.0). | FLOAT | 예 | -100.0 ~ 100.0 (step: 0.01) |
| `strength_clip` | CLIP 모델을 수정하는 강도입니다. 이 값은 음수일 수 있습니다(기본값: 1.0). | FLOAT | 예 | -100.0 ~ 100.0 (step: 0.01) |

**참고:** `strength_model`과 `strength_clip`이 모두 0으로 설정된 경우, 이 노드는 처리 없이 원본의 수정되지 않은 `model` 및 `clip` 입력을 반환합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `MODEL` | 수정된 확산 모델입니다. | MODEL |
| `CLIP` | 수정된 CLIP 모델입니다. | CLIP |

**참고:** 이 노드는 실험적인 것으로 표시되어 있습니다.
