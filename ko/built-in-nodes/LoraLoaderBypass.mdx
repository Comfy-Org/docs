LoraLoaderBypass 노드는 특별한 "바이패스" 모드로 디퓨전 모델과 CLIP 모델에 LoRA(Low-Rank Adaptation)를 적용합니다. 표준 LoRA 로더와 달리, 이 방식은 기본 모델의 가중치를 영구적으로 수정하지 않습니다. 대신 모델의 정상 순전파에 LoRA의 기여도를 더하여 결과를 계산합니다. 이는 학습 시 또는 가중치가 오프로드된 모델로 작업할 때 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | LoRA가 적용될 디퓨전 모델입니다. | MODEL | 예 | - |
| `clip` | LoRA가 적용될 CLIP 모델입니다. | CLIP | 예 | - |
| `lora_name` | LoRA의 이름입니다. 사용 가능한 LoRA 파일은 `loras` 폴더에서 불러옵니다. | COMBO | 예 | 사용 가능한 LoRA 파일 목록 |
| `strength_model` | 디퓨전 모델을 얼마나 강하게 수정할지 지정합니다. 이 값은 음수일 수 있습니다(기본값: 1.0). | FLOAT | 예 | -100.0  ~  100.0 (단계: 0.01) |
| `strength_clip` | CLIP 모델을 얼마나 강하게 수정할지 지정합니다. 이 값은 음수일 수 있습니다(기본값: 1.0). | FLOAT | 예 | -100.0  ~  100.0 (단계: 0.01) |

**참고:** `strength_model`과 `strength_clip`이 모두 0으로 설정되면, 노드는 처리 없이 원본의 수정되지 않은 `model` 및 `clip` 입력을 반환합니다.

**참고:** 선택한 LoRA 파일은 처음 로드된 후 캐시됩니다. 다른 `lora_name`을 선택한 경우에만 디스크에서 다시 읽습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `MODEL` | 수정된 디퓨전 모델입니다. | MODEL |
| `CLIP` | 수정된 CLIP 모델입니다. | CLIP |

**참고:** 이 노드는 실험적으로 표시되어 있습니다.
