Anthropic의 Claude 모델에서 텍스트 응답을 생성합니다. 텍스트 프롬프트와 필요에 따라 하나 이상의 이미지를 멀티모달 컨텍스트로 제공하면, 노드는 모델이 생성한 텍스트 응답을 반환합니다.

## 입력

입력은 공통 설정, 모델 선택 시 표시되는 모델별 설정, 그리고 선택적 참조 이미지로 그룹화됩니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 응답 생성에 사용되는 Claude 모델입니다. 모델을 선택하면 아래에 모델별 설정이 표시됩니다. | DYNAMIC_COMBO | 예 | `"Opus 5"`<br />`"Opus 4.8"`<br />`"Fable 5"`<br />`"Sonnet 5"`<br />`"Opus 4.7"`<br />`"Opus 4.6"`<br />`"Sonnet 4.6"`<br />`"Sonnet 4.5"`<br />`"Haiku 4.5"` |
| `프롬프트` | 모델에 전달하는 텍스트 입력입니다. (기본값: 빈 문자열) | STRING | 예 | N/A |
| `시드` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. (기본값: 0) | INT | 예 | 0 ~ 2147483647 |
| `시스템 프롬프트` | 모델의 동작을 결정하는 기본 지침입니다. (기본값: 빈 문자열) | STRING | 아니요 | N/A |

### Opus 5 및 Fable 5 입력

이 두 모델은 동일한 설정을 공유합니다. 온도(temperature) 설정을 노출하지 않으며, 추론(reasoning)은 항상 활성화됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | 생성할 최대 토큰 수입니다. (활성화된 경우 추론 토큰 포함). (기본값: 32768) | INT | 예 | 4096 ~ 64000 |
| `reasoning_effort` | 확장 사고 노력입니다. 이 모델에서는 추론이 항상 활성화됩니다. (기본값: "high") | COMBO | 예 | `"low"`<br />`"medium"`<br />`"high"` |

### Opus 4.8 및 Sonnet 5 입력

이 두 모델은 동일한 설정을 공유합니다. 온도(temperature) 설정을 노출하지 않습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | 생성할 최대 토큰 수입니다. (활성화된 경우 추론 토큰 포함). (기본값: 32768) | INT | 예 | 4096 ~ 64000 |
| `reasoning_effort` | 확장 사고 노력입니다. `"off"`는 추론을 비활성화합니다. (기본값: "off") | COMBO | 예 | `"off"`<br />`"low"`<br />`"medium"`<br />`"high"` |

### Opus 4.7, Opus 4.6, Sonnet 4.6 및 Sonnet 4.5 입력

이 네 모델은 동일한 설정을 공유합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | 생성할 최대 토큰 수입니다. (활성화된 경우 추론 토큰 포함). (기본값: 32768) | INT | 예 | 4096 ~ 64000 |
| `temperature` | 무작위성을 제어합니다. 0.0은 결정적이며, 1.0은 가장 무작위적입니다. Opus 4.7 및 `reasoning_effort`가 설정된 모든 모델에서는 무시됩니다. (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (step: 0.01) |
| `reasoning_effort` | 확장 사고 노력입니다. `"off"`는 추론을 비활성화합니다. (기본값: "off") | COMBO | 예 | `"off"`<br />`"low"`<br />`"medium"`<br />`"high"` |

### Haiku 4.5 입력

이 모델은 `reasoning_effort` 설정을 노출하지 않습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `max_tokens` | 생성할 최대 토큰 수입니다. (활성화된 경우 추론 토큰 포함). (기본값: 32768) | INT | 예 | 4096 ~ 64000 |
| `temperature` | 무작위성을 제어합니다. 0.0은 결정적이며, 1.0은 가장 무작위적입니다. Opus 4.7 및 `reasoning_effort`가 설정된 모든 모델에서는 무시됩니다. (기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (step: 0.01) |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 모델에 맥락으로 사용할 선택적 이미지입니다. 최대 20개까지 제공할 수 있습니다. 확장 가능한 슬롯: 1~20개 항목(`image_1` ... `image_20`)을 연결할 수 있습니다. | IMAGE | 아니요 | 0 ~ 20 images |

### 매개변수 제약 조건

- **이미지 제한:** 요청당 최대 20개의 이미지를 제공할 수 있습니다. 20개를 초과하여 연결하면 오류가 발생합니다.
- **프롬프트 필수:** 프롬프트에는 공백이 아닌 문자가 하나 이상 포함되어야 합니다. 빈 프롬프트는 검증 오류를 발생시킵니다.
- **temperature 처리:** 추론(thinking)이 활성화되면 Anthropic API는 temperature가 설정되지 않아야 합니다(기본값은 1.0입니다). Opus 5, Opus 4.8, Fable 5 및 Sonnet 5는 temperature 설정을 노출하지 않습니다. Opus 4.7은 `temperature`를 무시하며, `reasoning_effort`가 `"low"`, `"medium"` 또는 `"high"`로 설정된 모든 모델도 이를 무시합니다.
- **추론/사고 동작:** `reasoning_effort` 설정은 thinking(추론) 활성화 여부를 제어합니다. Opus 5와 Fable 5는 항상 추론이 활성화되어 있습니다. Haiku 4.5는 추론을 지원하지 않습니다. thinking이 활성화되면 노드는 선택한 모델에 적합한 thinking 모드를 사용합니다(적응형(adaptive) 또는 예산 기반(budget-based)). 예산 기반 모드에서는 실제 응답을 위해 최소 1024토큰을 남기도록 추론 토큰 예산이 제한됩니다.
- **안전 거부:** Claude가 안전상의 이유로 요청에 응답하지 않으면, 노드는 프롬프트를 바꾸거나 다른 모델을 시도하라는 오류를 발생시킵니다.
- **출력 텍스트:** thinking 및 reasoning 블록은 출력에 포함되지 않으며, 생성된 텍스트만 반환됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | Claude 모델에서 생성된 텍스트 응답입니다. thinking/reasoning 블록은 포함되지 않습니다. 생성된 텍스트가 없으면 "Empty response from Claude model."을 반환합니다. | STRING |
