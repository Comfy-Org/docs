연결한 텍스트, 이미지, 오디오 또는 비디오에 대해 직접 지정한 옵션 중 하나를 선택하고, 선택된 옵션과 그 위치, 신뢰도를 반환합니다. `choice`를 동일한 옵션 이름을 가진 입력이 있는 Branch 노드에 연결하거나 `option_index`를 기준으로 분기하세요. Branch 노드는 최대 32개의 입력만 허용하므로, 더 많은 옵션 집합은 `option_index`로 분기하세요.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 사용할 모델입니다(기본값: `"gemini-decision-1"`). | COMBO | 예 | `"gemini-decision-1"` |
| `question` | 옵션이 답하는 질문이며 최대 5000자입니다(기본값: "What style is the image?"). | STRING | 예 | 1~5000자 |
| `options` | 한 줄에 하나의 옵션이며 입력한 그대로 사용되고, 각 옵션은 최대 128자입니다. 입력이 어떤 옵션에도 해당하지 않는 경우를 위해 `other`와 같은 옵션을 추가하세요(기본값: `photo`, `illustration`, `3d render`, `anime`, `sketch`, `other`). | STRING | 예 | 2~255개 옵션 |
| `images` | 분류할 이미지로, 확장 가능한 슬롯(`image_1` ... `image_16`)을 통해 최대 16개까지 지원합니다. 배치 이미지는 이미지 한 장당 한 번으로 계산됩니다. | IMAGE | 아니요 | 최대 16개 이미지 |
| `audio` | 분류할 오디오 클립입니다. | AUDIO | 아니요 | - |
| `video` | 분류할 비디오 클립입니다. | VIDEO | 아니요 | - |
| `text` | 질문의 대상이 되는 텍스트로, 프롬프트나 LLM 응답 등이 있으며 최대 20000자입니다. | STRING | 아니요 | 최대 20000자 |

옵션은 최소 2개, 최대 255개까지 지정하고 어떤 옵션도 두 번 나열하지 마세요. 그렇지 않으면 노드에서 오류가 발생합니다. `text`, `images`, `audio` 또는 `video` 중 최소 하나를 연결하고, 여러 이미지를 사용하는 경우 질문 안에서 이미지 이름을 `image_1`, `image_2` 등으로 지정하세요.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `choice` | `options`에 작성된 그대로 선택된 옵션입니다. | STRING |
| `option_index` | `options`에서 선택된 옵션의 위치이며 0부터 시작합니다. | INT |
| `confidence` | 선택에 대한 신뢰도로, 0에서 1 사이입니다. | FLOAT |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/GeminiDecisionChoice/ko.md)
