이 노드는 입력 이미지를 DINOv3 이미지 인코더와 Flux2 VAE로 인코딩하여 TripoSplat 모델용 긍정 및 부정 컨디셔닝 데이터를 생성합니다. 또한 KSampler의 시작점 역할을 하는 고정 크기 노이즈 타깃(latent와 카메라 데이터)을 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip_vision` | DINOv3 ViT-H/16+ 이미지 인코더 | CLIP_VISION | 예 | - |
| `vae` | Flux2 VAE | VAE | 예 | - |
| `이미지` | 인코딩할 입력 이미지 | IMAGE | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | DINOv3 특징 시퀀스와 참조 latent로 전달되는 Flux2 VAE latent를 포함하는 긍정 컨디셔닝 데이터 | CONDITIONING |
| `negative` | 0으로 채워진 DINOv3 특징과 0으로 채워진 Flux2 VAE 참조 latent를 포함하는 부정 컨디셔닝 데이터 | CONDITIONING |
| `latent` | KSampler용 고정 크기 노이즈 타깃(latent + 카메라)입니다. latent는 단일 카메라 토큰(1 x 5)과 쌍을 이루는 고정 형상의 shape-code 시퀀스(8192 x 16)입니다 | LATENT |
