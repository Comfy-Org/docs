Bria Eraser는 Bria API를 사용하여 이미지에서 객체나 영역을 제거합니다. 제거할 영역을 나타내는 이미지와 마스크를 제공하면, 노드가 둘 다 Bria에 업로드하고, 지우기 작업을 실행하며, 완료될 때까지 대기한 후, 마스크된 영역이 지워진 편집된 이미지를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 제거할 객체나 영역이 포함된 입력 이미지입니다. | IMAGE | 예 | - |
| `mask` | 흰색 영역은 지워지고, 검은색 영역은 보존됩니다. 마스크는 전송 전에 이진화되므로, 부분적으로 칠해진 영역도 흰색으로 간주됩니다. 이미지와 동일한 종횡비를 가져야 합니다. | MASK | 예 | - |
| `mask_type` | 마스크가 생성된 방식을 선택합니다. "manual"은 손으로 그리거나 브러시로 만든 마스크용이고, "automatic"은 SAM과 같은 분할 모델이 생성한 마스크용입니다. | COMBO | 예 | "manual"<br />"automatic" |
| `moderation` | 검열 설정입니다. "true"로 설정하면 입력 및/또는 출력 이미지에 대한 시각적 콘텐츠 검열이 활성화됩니다. | DYNAMIC_COMBO | 예 | "false"<br />"true" |

참고: `moderation`을 "true"로 설정하면 두 가지 추가 불리언 설정을 사용할 수 있습니다.

- `visual_input_moderation` — 입력 이미지에 시각적 콘텐츠 검열을 적용합니다 (기본값: false)
- `visual_output_moderation` — 출력 이미지에 시각적 콘텐츠 검열을 적용합니다 (기본값: false)

마스크는 이미지의 종횡비와 일치해야 하며, 그렇지 않으면 요청이 실패합니다. 마스크는 API로 전송되기 전에 이진(흑백) 마스크로 변환됩니다. 불투명도가 절반 미만으로 칠해진 영역은 무시되고, 부분적으로 칠해진 영역은 흰색으로 간주되어 지워집니다. 마스크에는 최소한 일부 흰색 영역이 있어야 합니다. 빈 마스크는 지울 내용이 없으므로 요청이 실패합니다.
