Bria Eraser는 Bria API를 사용하여 이미지에서 객체나 영역을 제거합니다. 이미지와 제거할 영역을 표시하는 마스크를 제공하면, 노드가 두 항목을 Bria에 업로드하고, erase 작업을 실행한 뒤 완료될 때까지 기다린 후, 마스크된 영역이 지워진 편집된 이미지를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 제거할 객체나 영역이 포함된 입력 이미지입니다. | IMAGE | 예 | - |
| `mask` | 흰색 영역은 지워지고 검은색 영역은 보존됩니다. 마스크는 전송 전에 이진화되므로 부분적으로 칠한 영역은 흰색으로 간주됩니다. 이미지와 동일한 가로세로 비율이어야 합니다. | MASK | 예 | - |
| `mask_type` | 마스크 소스 유형입니다. "manual"은 손으로 그린 마스크나 브러시 마스크용이고, "automatic"은 SAM과 같은 분할 모델에서 생성된 마스크용입니다. | COMBO | 예 | "manual"<br />"automatic" |
| `moderation` | 모더레이션 설정입니다. "true"로 설정하면 입력 및/또는 출력 이미지에 시각적 콘텐츠 모더레이션을 활성화합니다. | DYNAMIC_COMBO | 예 | "false"<br />"true" |

`moderation`이 "true"로 설정되면 두 가지 추가 불리언 설정을 사용할 수 있습니다.

- `visual_input_moderation` — 입력 이미지에 시각적 콘텐츠 모더레이션을 적용합니다(기본값: false)
- `visual_output_moderation` — 출력 이미지에 시각적 콘텐츠 모더레이션을 적용합니다(기본값: false)

참고: 마스크는 이미지의 가로세로 비율과 일치해야 하며, 그렇지 않으면 요청이 실패합니다. 마스크는 API로 전송되기 전에 이진(흑백) 마스크로 변환됩니다. 불투명도가 절반 미만으로 칠해진 영역은 무시되고, 부분적으로 칠한 영역은 흰색으로 처리되어 지워집니다. 마스크에는 최소한 일부 흰색 영역이 있어야 합니다. 빈 마스크는 지울 내용이 없기 때문에 요청이 실패합니다.

| 출력 이름 | 설명 | 데이터 타입 |
