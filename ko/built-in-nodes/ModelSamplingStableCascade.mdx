ModelSamplingStableCascade 노드는 shift 값을 사용하여 샘플링 매개변수를 조정함으로써 모델에 Stable Cascade 샘플링을 적용합니다. 원본 모델은 변경하지 않고, 사용자 정의 Stable Cascade 샘플링 구성이 적용된 패치된 복사본을 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | Stable Cascade 샘플링을 적용할 입력 모델 | MODEL | 예 | - |
| `시프트` | 샘플링 매개변수에 적용할 shift 값 (기본값: 2.0) | FLOAT | 예 | 0.0 - 100.0 (step 0.01) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | Stable Cascade 샘플링이 적용된 수정된 모델 | MODEL |
