PixVerse V6 Text to Video는 PixVerse의 V6 모델을 사용하여 텍스트 프롬프트에서 비디오를 생성합니다. 이 노드는 선택한 해상도, 지속 시간, 화면 비율 및 기타 설정과 함께 프롬프트를 PixVerse로 전송하고, 생성이 완료될 때까지 기다린 다음 결과 비디오를 반환합니다. 오디오 생성이 활성화된 경우 네이티브 오디오 트랙도 포함됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 모델 및 생성 설정입니다. 모델을 선택하고 생성 옵션을 구성합니다. | DYNAMIC_COMBO | 예 | "PixVerse V6" |

### PixVerse V6 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 프롬프트입니다. (기본값: "") | STRING | 예 | 1–5000자 |
| `aspect_ratio` | 출력 화면 비율입니다. PixVerse V6에서 지원하는 화면 비율 중 하나를 선택합니다. | COMBO | 예 | 여러 옵션 사용 가능 |
| `quality` | 출력 해상도입니다. 긴 변을 기준으로 설정합니다: 360p는 640px, 540p는 1024px, 720p는 1280px, 1080p는 1920px입니다. (기본값: "720p") | COMBO | 예 | "360p"<br />"540p"<br />"720p"<br />"1080p" |
| `duration_seconds` | 생성된 비디오의 길이(초)입니다. (기본값: 5) | INT | 예 | 1–15 |
| `generate_audio` | 비디오와 함께 네이티브 오디오 트랙을 생성합니다. (기본값: True) | BOOLEAN | 예 | True<br />False |
| `multi_clip` | 모델이 하나의 연속 테이크 대신 비디오를 여러 컷으로 분할하도록 합니다. (기본값: False) | BOOLEAN | 예 | True<br />False |
| `seed` | 비디오 생성을 위한 시드입니다. PixVerse가 이를 기록하지만 해당 시드로 실행을 재현하지는 않습니다. 생성 후 무작위화를 지원합니다. (기본값: 42) | INT | 예 | 0–2147483647 |
| `negative_prompt` | 비디오에서 원하지 않는 요소에 대한 선택적 텍스트 설명입니다. (기본값: "") | STRING | 아니요 | 0–2048자 |
| `style` | 전체 비디오에 적용되는 선택적 시각적 스타일입니다. (기본값: "none") | COMBO | 아니요 | 여러 옵션 사용 가능 |

**참고:** `prompt`는 필수이며, 공백을 제거한 후 비어 있지 않아야 합니다. 최대 길이는 5000자입니다. `negative_prompt`는 2048자로 제한됩니다. `style`을 "none"(기본값)으로 설정하면 시각적 스타일이 적용되지 않습니다. `seed`는 PixVerse에 기록되지만 동일한 실행을 재현하는 데 사용할 수는 없습니다. 노드는 PixVerse가 비디오 생성을 완료할 때까지 기다린 후 이를 다운로드합니다. 요청이 실패하는 경우(예: PixVerse가 이미 최대 동시 생성 수에 도달했거나, 공급자 계정의 크레딧이 소진되었거나, 콘텐츠 검토가 프롬프트를 거부하는 경우) 노드는 오류를 반환합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 생성된 비디오입니다. `generate_audio`가 활성화된 경우 비디오에는 네이티브 오디오 트랙이 포함됩니다. | VIDEO |
