이 노드는 시작 시간과 지속 시간을 설정하여 비디오를 선택한 시간 구간으로 자릅니다. 또한 요청한 지속 시간을 맞출 수 없을 때 오류를 발생시키는 엄격 모드를 제공합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video` | 자를 비디오입니다. | VIDEO | 예 | — |
| `trim` | 시작/종료 프레임을 사용하여 자를 구간을 지정합니다. 이 구간은 시작 시간(비디오 시작부터의 초 단위)과 지속 시간(초 단위)으로 변환됩니다. 시작 시간과 지속 시간이 모두 0이면 비디오는 자르지 않고 반환됩니다. | VIDEO_EDIT | 예 | start_time: >= 0, 기본값 0<br />duration: >= 0, 기본값 0 |
| `strict_duration` | True이면 지정한 지속 시간을 맞출 수 없을 때 오류가 발생합니다. (기본값: False) | BOOLEAN | 아니요 | true<br />false |

참고: 자르기 지속 시간은 0 이상이어야 하며, 음수 값은 오류를 발생시킵니다. 요청한 자르기 구간은 원본 비디오 안에 들어와야 합니다. 자르기를 적용할 수 없으면 원본 지속 시간, 시작 시간, 대상 지속 시간을 보고하는 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 잘린 비디오입니다. 자르기 구간이 비어 있으면(시작 시간과 지속 시간이 모두 0), 원본 비디오가 변경되지 않고 반환됩니다. | VIDEO |
