ByteDance Seedream 5.0 Pro 레이어 분리(Layer Separation)는 이미지를 배경판과 최대 16개의 투명 레이어로 분해하며, 각 레이어는 고유한 적층 순서, 경계 상자(bounding box), 이름, 설명을 갖습니다. 이 노드는 배경, 레이어별 이미지와 마스크, 배치 상자, 즉시 편집 가능한 레이어 스택을 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 분리할 이미지입니다. 정확히 하나의 이미지여야 하며, 최소 512x512 픽셀이고 가로세로 비율이 1:16에서 16:1 사이여야 합니다. 약 4MP보다 큰 입력은 업로드 전에 축소됩니다. | IMAGE | 예 | 단일 이미지 |
| `prompt` | 이미지를 분리하는 방법입니다. 비워 두면 모든 주요 요소를 자동으로 감지하여 분리합니다. 자연어로 요소를 설명하여 분리를 제어하거나, `<bbox>left top right bottom&lt;/bbox>` 태그(0-1000 천분율 좌표)로 정확한 영역을 지정할 수 있습니다. 기본값: 빈 문자열. | STRING | 예 | 여러 줄 텍스트 |
| `size` | 출력 해상도 레벨입니다. "auto"는 입력 이미지 크기를 따릅니다(1K-2K 범위로 제한됨). 기본값: "auto". | STRING | 예 | "auto"<br />"1K"<br />"1.5K"<br />"2K" |
| `seed` | 생성에 사용할 시드입니다. 기본값: 0. | INT | 예 | 0 ~ 2147483647 |
| `prompt_optimization` | 프롬프트 최적화 모드입니다. "standard"는 더 높은 품질을 제공하고, "fast"는 생성 시간을 단축합니다. 기본값: "standard". | STRING | 아니요 | "standard"<br />"fast" |
| `watermark` | 이미지에 "AI 생성" 워터마크를 추가할지 여부입니다. 기본값: false. | BOOLEAN | 아니요 | false<br />true |
| `crop_layers` | 레이어/마스크 배치 출력의 지오메트리입니다(layer_stack은 영향을 받지 않으며 항상 타이트하게 유지됩니다). 전체 캔버스(Full canvas) 모드: 각 레이어가 기본 크기 캔버스의 경계 상자 위치에 배치됩니다. ImageCompositeMasked로 직접 재합성할 수 있습니다. 최소 크기(Minimal size) 모드: 각 레이어가 경계 상자로 크롭됩니다(배치를 위해 가장 큰 레이어 크기로 패딩됨). 텐서가 훨씬 작아집니다. bboxes 출력과 함께 Layers From Bounding Boxes를 사용하여 배치를 재구성할 수 있습니다. 기본값: false(전체 캔버스). | BOOLEAN | 아니요 | false (전체 캔버스)<br />true (최소 크기) |

참고: 입력 이미지는 단일 이미지여야 하며 배치는 지원되지 않습니다. 이미지는 최소 512x512 픽셀이고 가로세로 비율이 1:16에서 16:1 사이여야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `base_image` | 레이어가 적층되는 기본 이미지(배경판)입니다. | IMAGE |
| `base_mask` | 기본 이미지의 투명도입니다(1 = 투명, LoadImage 규약). 현재는 항상 완전히 불투명합니다. | MASK |
| `layers` | 아래에서 위로 정렬된 투명 레이어입니다. 전체 캔버스(Full canvas) 모드: 기본 크기의 검은색 캔버스에서 경계 상자 위치에 배치됩니다. 최소 크기(Minimal size) 모드: 경계 상자로 크롭되고 왼쪽 위를 기준으로 정렬되며, 가장 큰 레이어 크기로 패딩됩니다. | IMAGE |
| `masks` | 레이어별 투명도로, 레이어 배치와 인덱스가 정렬됩니다(1 = 투명, LoadImage 규약). ImageCompositeMasked 스타일 합성의 경우 먼저 InvertMask를 추가해야 합니다. | MASK |
| `bboxes` | 레이어당 하나의 배치 상자로, 레이어 배치와 인덱스가 정렬됩니다(bboxes와 layers를 모두, 그리고 masks를 Layers From Bounding Boxes에 전달하여 레이어별 배치를 재구성할 수 있습니다): `{x, y, width, height, metadata: {name, desc, z_index, native_size, content_rect, flags}}`. `content_rect = [left, top, width, height]`는 레이어 자체 프레임 내의 콘텐츠 영역입니다. 이 영역은 박스 위치에 해당 오프셋을 더한 캔버스 좌표에 배치됩니다. | BOUNDING_BOX |
| `layer_stack` | Create Layered Image를 위한 즉시 편집 가능한 레이어 문서입니다. 배경판과 각 요소가 고유한 이름을 가진 타이트하게 크롭된 레이어로, 실제 위치와 적층 순서에 따라 포함됩니다. 직접 연결하거나 Add Layer로 확장할 수 있습니다. | LAYERS |
