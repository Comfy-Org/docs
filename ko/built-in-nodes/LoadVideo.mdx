Load Video 노드는 입력 디렉터리에서 비디오 파일을 로드하고 워크플로에서 처리할 수 있도록 합니다. 지정된 입력 폴더에서 비디오 파일을 읽고 다른 비디오 처리 노드에 연결할 수 있는 비디오 데이터로 출력합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `파일` | 입력 디렉터리에서 로드할 비디오 파일입니다. 드롭다운 목록은 ComfyUI 입력 폴더에서 발견된 모든 비디오 파일로 동적으로 채워지며, 파일 선택기를 통해 새 비디오 파일을 직접 업로드할 수 있습니다. | COMBO | 예 | 여러 옵션 사용 가능(입력 디렉터리에 있는 모든 비디오 파일) |

**참고:** `file` 매개변수에 사용할 수 있는 옵션은 입력 디렉터리에 있는 비디오 파일에서 동적으로 채워집니다. 지원되는 비디오 콘텐츠 유형과 일치하는 파일만 표시되며, 목록은 알파벳순으로 정렬됩니다. 노드의 파일 선택기 인터페이스를 통해 새 비디오 파일을 직접 업로드할 수도 있습니다. 이전에 선택한 비디오 파일을 더 이상 찾을 수 없으면 노드에서 유효하지 않은 파일 오류를 보고합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `video` | 다른 비디오 처리 노드에 전달하여 추가 조작이나 분석을 수행할 수 있는 로드된 비디오 데이터입니다. | VIDEO |

**참고:** 이 노드는 로드된 비디오의 미리보기도 생성하며, 이는 노드에 직접 표시됩니다.
