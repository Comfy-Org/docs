이 Comfy Cloud 노드는 Mage-Flow Turbo 워크플로(`mage-flow-turbo/text-to-image`)를 사용하여 텍스트 프롬프트로부터 이미지를 생성합니다. 이 노드는 Mage-Flow 모델의 증류된 버전을 실행하여 cfg 값 1에서 4단계로 이미지를 생성하며, 전체 Mage-Flow 패스의 약 1/7에 해당하는 GPU 시간이 걸리므로 빠른 반복 작업에 적합한 변형입니다.

## 입력

노드 클래스 자체는 사용 가능한 소스에서 입력 위젯을 선언하지 않습니다. 해당 입력 스키마는 공유 기본 클래스 `_ComfyCloudMageFlowNode`에서 상속되며, 이 클래스의 정의는 소스 스냅샷에 포함되어 있지 않습니다. 노드 요약과 text-to-image 워크플로 이름을 기준으로 볼 때, 이 노드는 생성할 이미지를 설명하는 텍스트 프롬프트를 받습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성할 이미지를 설명하는 텍스트 프롬프트입니다. 정확한 매개변수 이름은 상속된 `_ComfyCloudMageFlowNode` 기본 스키마에 의해 설정되며, 이 레이블과 다를 수 있습니다. | STRING | 예 | 자유 텍스트 |

참고: 상속된 기본 노드 정의에는 추가 입력 매개변수가 존재할 수 있으며, 해당 정의는 제공된 소스에서 사용할 수 없습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 텍스트 프롬프트로부터 생성된 이미지입니다. | IMAGE |
