이미지 또는 비디오 레이턴트를 읽고 해당 레이턴트의 너비, 높이, 프레임 수, 배치 크기를 반환하므로, 레이턴트를 디코딩하지 않고도 지오메트리를 재사용할 수 있습니다. 노이즈 마스크의 크기를 정하거나, 해상도를 정렬하거나, 샘플러를 타일링할 때 겹치는 영역을 계산하는 데 사용할 수 있습니다. 측정된 값은 노드 자체에도 표시됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `latent` | 검사할 이미지 또는 비디오 레이턴트입니다. `latent`가 여러 스트림을 보유하는 경우 첫 번째 스트림을 측정합니다. | LATENT | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `width` | 레이턴트의 너비로, 픽셀이 아닌 레이턴트 셀 단위입니다. | INT |
| `height` | 레이턴트의 높이로, 픽셀이 아닌 레이턴트 셀 단위입니다. | INT |
| `frames` | 레이턴트의 프레임 수입니다. 이미지 레이턴트는 단일 프레임을 가집니다. | INT |
| `batch_size` | 배치에 포함된 레이턴트의 수입니다. | INT |
