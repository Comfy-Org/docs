이 노드는 Quiver AI의 벡터화 모델을 사용하여 래스터 이미지를 확장 가능한 벡터 그래픽(SVG)으로 변환합니다. 이미지를 외부 API로 전송하면 API가 이미지를 처리하고 벡터화된 결과를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 벡터화할 입력 이미지입니다. | IMAGE | 예 | N/A |
| `auto_crop` | 주요 피사체를 기준으로 자동으로 자릅니다(기본값: False). | BOOLEAN | 예 | True<br />False |
| `model` | SVG 벡터화에 사용할 모델입니다. 모델을 선택하면 해당 모델에 특화된 추가 매개변수가 표시됩니다: `target_size`(픽셀 단위의 정사각형 크기 조정 대상이며, 0이면 원본 이미지 크기를 유지하고, 그렇지 않으면 128에서 4096 사이), `temperature`, `top_p`, `presence_penalty`. | DYNAMIC_COMBO | 예 | `"arrow-2"`<br />`"arrow-2-telos"`<br />`"arrow-1.1"`<br />`"arrow-1.1-max"`<br />`"arrow-preview"` |
| `seed` | 노드를 다시 실행할지 결정하는 시드입니다. 시드 값과 관계없이 실제 결과는 비결정적입니다. 이 매개변수에는 "control after generate" 기능이 있습니다(기본값: 0). | INT | 예 | 0  ~  2147483647 |
| `reasoning_effort` | 모델이 그리기 전에 사용하는 추론량입니다. 수준이 높을수록 세부 묘사가 향상되며 더 많은 토큰이 소모됩니다. Arrow 2 모델에서만 사용됩니다(기본값: "high"). | COMBO | 아니요 | `"low"`<br />`"medium"`<br />`"high"`<br />`"xhigh"` |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `SVG` | 벡터화된 SVG 출력입니다. | SVG |
