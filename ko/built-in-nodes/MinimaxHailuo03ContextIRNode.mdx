## 개요

이 노드는 MiniMax H3 Context IR을 사용하여 텍스트 설명과 첨부된 미디어를 분석한 다음, 더 강력하고 구조화된 비디오 프롬프트를 생성합니다. 반환된 프롬프트는 MiniMax H3 비디오 노드의 프롬프트 입력에 연결하도록 설계되었습니다. 해당 위치에 미디어를 첨부하는 경우, 향상된 프롬프트가 위치로 미디어를 참조하므로 동일한 미디어를 동일한 순서로 첨부하세요.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 프롬프트 향상에 사용할 모델입니다. | DYNAMIC_COMBO | 예 | `"MiniMax H3"` |
| `first_frame` | 생성하려는 비디오의 첫 프레임입니다. 참조 미디어와 함께 사용할 수 없습니다. | IMAGE | 아니요 | 단일 이미지 |
| `last_frame` | 생성하려는 비디오의 마지막 프레임입니다. 참조 미디어와 함께 사용할 수 없습니다. | IMAGE | 아니요 | 단일 이미지 |

### MiniMax H3 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성하려는 비디오에 대한 설명입니다. 비워 둘 수 없습니다. (기본값: `""`) | STRING | 예 | 모든 텍스트(비워 둘 수 없음) |
| `duration` | 생성하려는 비디오의 길이(초)입니다(4-15). (기본값: 5) | INT | 예 | 4~15 |
| `ratio` | 생성하려는 비디오의 화면 비율입니다. `"adaptive"`는 최소 하나의 이미지, 비디오 또는 오디오 입력이 필요합니다. (기본값: `"adaptive"`) | COMBO | 예 | `"adaptive"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"` |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 프롬프트에서 연결 순서에 따라 "Image 1".."Image 9"로 참조되는 피사체 또는 스타일 참조 이미지입니다. 최대 9개 이미지입니다. 확장 가능한 슬롯: `image_1`...`image_9`를 연결합니다. | IMAGE | 아니요 | 0~9개 이미지 |
| `reference_videos` | 프롬프트에서 연결 순서에 따라 "Video 1".."Video 3"으로 참조되는 모션 또는 장면 참조 비디오입니다. 최대 3개 비디오, 각각 2-15초, 총 15초입니다. 확장 가능한 슬롯: `video_1`...`video_3`을 연결합니다. | VIDEO | 아니요 | 0~3개 비디오 |
| `reference_audios` | 프롬프트에서 연결 순서에 따라 "Audio 1".."Audio 3"으로 참조되는 오디오 참조입니다. 최대 3개 클립, 각각 2-15초, 총 15초입니다. 참조 이미지 또는 비디오 없이 사용할 수 없습니다. 확장 가능한 슬롯: `audio_1`...`audio_3`을 연결합니다. | AUDIO | 아니요 | 0~3개 클립 |

### 매개변수 제약 조건

- `prompt`, `duration`, `ratio`, `reference_images`, `reference_videos`, `reference_audios` 입력은 `model` 옵션 그룹의 일부이며 "MiniMax H3"를 선택하면 나타납니다.
- `first_frame`과 `last_frame`은 어떤 참조 미디어와도 함께 사용할 수 없습니다.
- `reference_audios`는 적어도 하나의 `reference_image` 또는 `reference_video`도 연결되어 있지 않으면 사용할 수 없습니다.
- 프레임이 없고 참조 미디어도 연결되지 않은 경우 `ratio`를 `"adaptive"`로 설정할 수 없습니다.
- 참조 비디오는 각각 약 2-15초여야 하며, 총 길이는 15초를 초과할 수 없습니다. 프레임 레이트는 23.9~60.5 FPS 사이여야 합니다.
- 참조 오디오는 각각 약 2-15초여야 하며, 총 길이는 15초를 초과할 수 없습니다.
- `first_frame`, `last_frame` 및 모든 참조 이미지는 최소 256x256픽셀이어야 하며, 화면 비율은 0.4~2.5 사이여야 합니다.
