이 노드는 비디오 latent의 처음 몇 프레임을 조정하여 이후 프레임처럼 보이게 만듭니다. 비디오 후반부의 참조 프레임 집합에서 평균과 변동을 계산하고, 해당 특성을 시작 프레임에 동일하게 적용합니다. 이를 통해 비디오 시작 부분에서 더 부드럽고 일관된 시각적 전환이 만들어집니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `latent` | 처리할 비디오 latent 표현입니다. | LATENT | 예 | - |
| `start_frame_count` | 시작부터 계산하여 정규화할 latent 프레임 수입니다 (기본값: 4). | INT | 예 | 1~16384 (최대 해상도) |
| `reference_frame_count` | 시작 프레임 이후에 참조로 사용할 latent 프레임 수입니다 (기본값: 5). | INT | 예 | 1~16384 (최대 해상도) |

**참고:** `reference_frame_count`는 시작 프레임 이후에 사용 가능한 프레임 수로 자동 제한됩니다. 비디오 latent가 1프레임뿐인 경우 정규화가 수행되지 않으며 원본 latent가 변경 없이 그대로 반환됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `latent` | 시작 프레임이 정규화된 처리된 비디오 latent입니다. | LATENT |
