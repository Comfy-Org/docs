샘플링을 겹치는 컨텍스트 윈도우로 분할하여 MiniMax H3 비디오가 모델의 단일 패스 윈도우보다 길어질 수 있도록 합니다. 윈도우는 모델의 17프레임 청크에 배치되므로, 생성된 비디오와 오디오가 윈도우 경계를 넘어 정렬된 상태로 유지됩니다. 반환된 모델을 원래 모델 대신 샘플러에 연결합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 샘플링 중에 컨텍스트 윈도우를 적용할 모델입니다. | MODEL | 예 | - |
| `context_length` | 실제 프레임 기준 컨텍스트 윈도우의 길이입니다. 17*n + 5여야 합니다(기본값: 124). | INT | 예 | 22 ~ 16384 (MAX_RESOLUTION), 단계 17 |
| `context_overlap` | 실제 프레임 기준 컨텍스트 윈도우의 겹침입니다. 17*n + 5여야 합니다(기본값: 39). | INT | 예 | 5 이상, 단계 17 |
| `fuse_method` | 컨텍스트 윈도우를 융합하는 데 사용되는 방법입니다(기본값: `"pyramid"`). | COMBO | 예 | `"pyramid"`<br />`"relative"`<br />`"flat"`<br />`"overlap-linear"` |
| `freenoise` | FreeNoise 노이즈 셔플링을 적용할지 여부입니다. 이는 윈도우 블렌딩을 향상시킵니다(기본값: True, 고급 매개변수). | BOOLEAN | 예 | true<br />false |
| `split_conds_to_windows` | 여러 컨디셔닝(ConditionCombine으로 생성됨)을 영역 인덱스에 따라 각 윈도우로 분할할지 여부입니다(기본값: False, 고급 매개변수). | BOOLEAN | 예 | true<br />false |

두 길이 모두 실제 프레임 단위로 지정되며 샘플링 전에 잠재(latent)로 변환됩니다. `context_length`는 5프레임 이하일 때 2개의 잠재가 되고, 그 외에는 `((frames - 5) / 17) * 5 + 2`가 됩니다. `context_overlap`도 같은 방식으로 변환된 다음 `context_length`에서 5를 뺀 값으로 제한되므로, 겹침은 항상 진행할 전체 청크를 남깁니다. 이 노드는 항상 스트라이드 1의 정적 스케줄을 사용하고, 잠재 시간 차원에 윈도우를 적용하며, 모든 윈도우가 청크 경계에서 시작하기 때문에 causal fix 프레임을 추가하지 않습니다. `split_conds_to_windows`는 ConditionCombine 노드로 생성된 여러 컨디셔닝을 기대합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | 컨텍스트 윈도우 구성이 적용된 모델입니다. | MODEL |
