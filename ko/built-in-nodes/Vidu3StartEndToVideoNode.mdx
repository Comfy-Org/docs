이 노드는 제공된 시작 프레임과 끝 프레임 사이를 텍스트 프롬프트에 따라 보간하여 비디오를 생성합니다. Vidu Q3 모델을 사용하여 두 이미지 간의 자연스러운 전환을 만들고, 지정된 지속 시간과 해상도의 비디오를 생성합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 비디오 생성에 사용할 모델입니다. 옵션을 선택하면 `resolution`, `duration` 및 `audio`에 대한 추가 구성 매개변수가 표시됩니다. | DYNAMIC_COMBO | 예 | `"viduq3-pro"`<br />`"viduq3-turbo"` |
| `시작 프레임` | 비디오 시퀀스의 시작 이미지입니다. | IMAGE | 예 | - |
| `종료 프레임` | 비디오 시퀀스의 끝 이미지입니다. | IMAGE | 예 | - |
| `프롬프트` | 프롬프트 설명(최대 2000자)입니다. | STRING | 예 | - |
| `시드` | 생성의 무작위성을 제어하기 위한 시드 값입니다(기본값: 1). | INT | 예 | 0 ~ 2147483647 |

### viduq3-pro 및 viduq3-turbo 입력

다음 매개변수는 두 모델 옵션(`viduq3-pro` 및 `viduq3-turbo`)에서 공통으로 사용됩니다. 모델을 선택한 후에 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 출력 비디오의 해상도입니다. 이 매개변수는 `model`을 선택한 후 표시됩니다. | COMBO | 예 | `"720p"`<br />`"1080p"` |
| `duration` | 출력 비디오의 지속 시간(초)입니다(기본값: 5). 이 매개변수는 `model`을 선택한 후 표시됩니다. | INT | 예 | 1 ~ 16 |
| `audio` | 활성화하면 소리(대화 및 음향 효과 포함)가 포함된 비디오를 출력합니다(기본값: False). 이 매개변수는 `model`을 선택한 후 표시됩니다. | BOOLEAN | 예 | `True`<br />`False` |

**참고:** `first_frame` 및 `end_frame` 이미지는 종횡비가 서로 유사해야 합니다. 두 이미지의 종횡비는 서로의 80%~125% 이내여야 합니다(상대적 근접도 0.8~1.25).

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 생성된 비디오 파일입니다. | VIDEO |
