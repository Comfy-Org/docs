이 노드는 시작 프레임과 종료 프레임 사이의 전환을 생성하여 텍스트 프롬프트의 안내를 받아 비디오를 생성합니다. Vidu Q3 모델을 사용하여 두 이미지 사이를 보간하고 선택한 지속 시간과 해상도로 비디오를 생성합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 비디오 생성에 사용할 모델입니다. 옵션을 선택하면 `resolution`, `duration`, `audio`에 대한 추가 구성 매개변수가 표시됩니다. | DYNAMIC_COMBO | 예 | `"viduq3-pro"`<br />`"viduq3-turbo"` |
| `시작 프레임` | 비디오 시퀀스의 시작 이미지입니다. | IMAGE | 예 | - |
| `종료 프레임` | 비디오 시퀀스의 종료 이미지입니다. | IMAGE | 예 | - |
| `프롬프트` | 프롬프트 설명(최대 2000자). | STRING | 예 | 최대 2000자 |
| `시드` | 생성의 무작위성을 제어하는 데 사용되는 시드 값입니다. 생성 후 제어 옵션을 제공합니다(기본값: 1). | INT | 예 | 0~2147483647 |

### viduq3-pro 및 viduq3-turbo 입력

다음 매개변수는 두 모델 옵션(`viduq3-pro` 및 `viduq3-turbo`)에서 공통으로 사용됩니다. 모델을 선택한 후에 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"720p"`<br />`"1080p"` |
| `duration` | 출력 비디오의 지속 시간(초)입니다(기본값: 5). | INT | 예 | 1~16 |
| `audio` | 활성화하면 사운드(대사 및 음향 효과 포함)가 있는 비디오를 출력합니다(기본값: False). | BOOLEAN | 예 | `True`<br />`False` |

**참고:** `first_frame` 및 `end_frame` 이미지는 유사한 종횡비를 가져야 합니다. 두 이미지의 종횡비는 서로의 80%~125% 이내여야 합니다(상대적 근접도 0.8~1.25).

**참고:** `viduq3-turbo`의 경우 가격은 720p에서 초당 0.06 USD, 1080p에서 초당 0.08 USD입니다. `viduq3-pro`의 경우 가격은 720p에서 초당 0.15 USD, 1080p에서 초당 0.16 USD입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 생성된 비디오 파일입니다. | VIDEO |
