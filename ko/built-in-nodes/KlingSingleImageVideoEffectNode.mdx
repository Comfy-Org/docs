Kling 단일 이미지 비디오 효과 노드는 단일 참조 이미지를 기반으로 다양한 특수 효과가 적용된 비디오를 생성합니다. 정적 이미지에 여러 시각 효과와 장면을 적용하여 동적인 비디오 콘텐츠로 변환합니다. 이 노드는 원하는 시각적 결과를 얻기 위해 다양한 효과 장면, 모델 옵션 및 비디오 길이를 지원합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 참조 이미지. URL 또는 Base64 인코딩 문자열(data:image 접두사 제외). 파일 크기는 10MB를 초과할 수 없으며, 해상도는 300x300px 이상이어야 하고, 가로세로 비율은 1:2.5에서 2.5:1 사이여야 합니다 | IMAGE | 예 | - |
| `effect_scene` | 비디오 생성에 적용할 특수 효과 장면의 유형입니다. 일부 효과는 가격이 다를 수 있습니다. | COMBO | 예 | `"dizzydizzy"`<br />`"bloombloom"`<br />`"neon"`<br />`"cartoon"`<br />`"sketch"`<br />`"oil"`<br />`"watercolor"`<br />`"3d"` |
| `model_name` | 비디오 효과 생성에 사용할 특정 모델 버전입니다. | COMBO | 예 | `"kling-v1-5"`<br />`"kling-v1-6"` |
| `duration` | 생성된 비디오의 길이(초)입니다. | COMBO | 예 | `"5"`<br />`"10"` |

**참고:** `effect_scene` 매개변수는 노드의 가격에 영향을 줍니다. `dizzydizzy` 및 `bloombloom` 효과는 생성당 0.49달러이며, 다른 모든 효과는 생성당 0.28달러입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 효과가 적용되어 생성된 비디오 | VIDEO |
| `video_id` | 생성된 비디오의 고유 식별자 | STRING |
| `duration` | 생성된 비디오의 길이 | STRING |
