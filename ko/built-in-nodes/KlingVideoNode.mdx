이 노드는 Kling V3 모델로 비디오를 생성합니다. 텍스트 설명으로 비디오를 만드는 텍스트-투-비디오와 기존 이미지를 애니메이션화하는 이미지-투-비디오를 지원합니다. 또한 스토리보드 프롬프트를 사용해 여러 세그먼트로 구성된 비디오를 만들 수 있으며, 선택적으로 오디오를 생성할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `멀티 샷` | 개별 프롬프트와 지속 시간으로 일련의 비디오 세그먼트를 생성합니다. 스토리보드 옵션으로 설정하면 각 스토리보드의 프롬프트와 지속 시간에 대한 추가 입력이 나타납니다. | DYNAMIC_COMBO | 예 | `"disabled"`<br />`"1 storyboard"`<br />`"2 storyboards"`<br />`"3 storyboards"`<br />`"4 storyboards"`<br />`"5 storyboards"`<br />`"6 storyboards"` |
| `오디오 생성` | 활성화하면 노드가 비디오에 대한 오디오를 생성합니다. 참고: `"kling-3.0-turbo"`는 항상 네이티브 오디오를 생성하므로 해당 모델에서는 오디오 토글이 무시됩니다. 기본값은 True입니다. | BOOLEAN | 예 | True<br />False |
| `모델` | 모델 및 생성 설정입니다. 모델을 선택하면 해당 해상도 및 종횡비 하위 매개변수가 나타납니다. | DYNAMIC_COMBO | 예 | `"kling-v3"`<br />`"kling-3.0-turbo"` |
| `시드` | `seed`는 노드를 다시 실행할지 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. 기본값은 0입니다. | INT | 예 | 0  ~  2147483647 |
| `시작 프레임` | 선택적 시작 프레임 이미지입니다. 연결하면 이미지-투-비디오 모드로 전환됩니다. | IMAGE | 아니요 | - |

### kling-v3 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `해상도` | 생성된 비디오의 해상도입니다. 기본값은 `"1080p"`입니다. | COMBO | 예 | `"4k"`<br />`"1080p"`<br />`"720p"` |
| `종횡비` | 생성된 비디오의 종횡비입니다. 이미지-투-비디오 모드에서는 무시됩니다. | COMBO | 예 | `"16:9"`<br />`"9:16"`<br />`"1:1"` |

### kling-3.0-turbo 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `해상도` | 생성된 비디오의 해상도입니다. 기본값은 `"720p"`입니다. | COMBO | 예 | `"1080p"`<br />`"720p"` |
| `종횡비` | 생성된 비디오의 종횡비입니다. 이미지-투-비디오 모드에서는 무시됩니다. | COMBO | 예 | `"16:9"`<br />`"9:16"`<br />`"1:1"` |

### 멀티샷 입력

**`multi_shot`이 `"disabled"`로 설정된 경우:**

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오의 주요 텍스트 설명입니다. 1자 이상 2500자 이하여야 합니다. | STRING | 예 | 1  ~  2500 characters |
| `negative_prompt` | 비디오에 나타나지 않아야 할 내용을 설명하는 텍스트입니다. 비워 둘 수 있습니다. | STRING | 아니요 | - |
| `duration` | 비디오 길이(초)입니다. 기본값은 5입니다. | INT | 예 | 3  ~  15 |

**`multi_shot`이 스토리보드 옵션(예: `"3 storyboards"`)으로 설정된 경우:**

선택한 스토리보드 수까지의 각 스토리보드 세그먼트 N(1부터 선택한 스토리보드 수까지)에 대해 다음 입력이 나타납니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `storyboard_N_prompt` | 스토리보드 세그먼트 N에 대한 프롬프트입니다. 최대 512자입니다. | STRING | 예 | 1  ~  512 characters |
| `storyboard_N_duration` | 스토리보드 세그먼트 N의 지속 시간(초)입니다. 기본값은 4입니다. | INT | 예 | 1  ~  15 |

**제약 사항 및 동작:**

- `start_frame`이 연결되지 않은 경우 텍스트-투-비디오 모드가 사용되고, `start_frame`이 연결된 경우 이미지-투-비디오 모드가 사용됩니다. 이미지-투-비디오 모드에서는 `model.aspect_ratio`가 무시되며, 입력 이미지는 최소 300x300픽셀이어야 하고 종횡비는 1:2.5에서 2.5:1 사이여야 합니다.
- 스토리보드 모드에서는 기본 `prompt`와 `negative_prompt`가 사용되지 않습니다. 모든 스토리보드 지속 시간의 총합은 3초에서 15초 사이여야 합니다.
- `negative_prompt`는 `kling-v3`에서만 사용되며, `kling-3.0-turbo`를 선택한 경우 무시됩니다.
- `kling-v3`의 경우 각 스토리보드가 별도의 세그먼트로 API에 전송됩니다. `kling-3.0-turbo`의 경우 스토리보드 프롬프트와 지속 시간이 하나의 멀티샷 프롬프트로 결합됩니다.
- `kling-3.0-turbo`의 경우 이 모델이 항상 네이티브 오디오를 생성하므로 `generate_audio`가 무시됩니다.
