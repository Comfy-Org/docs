MergeMeshes는 여러 메쉬 입력을 단일 메쉬로 결합합니다. 정점, 면, UV 좌표, 정점 색상을 쌓고 면 인덱스를 오프셋하여 모든 부분이 하나의 연속된 메쉬로 올바르게 결합되도록 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `메시` | 확장 가능한 슬롯: 2~50개의 메쉬 객체를 연결합니다(`mesh_1`, `mesh_2`, ..., `mesh_50`). 연결된 모든 메쉬는 하나의 출력 메쉬로 병합됩니다. | MESH | 예 | 2  ~  50 meshes |

**참고:** 최소 하나의 메쉬가 제공되어야 하며, 그렇지 않으면 노드에서 오류를 발생시킵니다. 각 입력 메쉬의 배치에서 첫 번째 메쉬 항목만 사용됩니다. 입력 메쉬는 병합 전에 CPU로 이동됩니다. 입력 메쉬 중 하나라도 UV 데이터를 가지면 출력에 UV가 포함되며, UV가 없는 메쉬는 0으로 채워진 UV 값을 받습니다. 입력 메쉬 중 하나라도 정점 색상을 가지면 출력에 정점 색상이 포함됩니다. 색상이 없는 메쉬는 흰색(값 1) 색상을 받으며, 색상 채널은 입력들 사이에서 발견된 가장 큰 채널 수에 맞게 패딩됩니다. 텍스처를 제공하는 첫 번째 입력의 텍스처만 유지되며, 추가 텍스처는 삭제됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `mesh` | 모든 입력 정점, 면, UV 및 색상을 하나의 메쉬로 결합한 병합된 메쉬입니다. | MESH |
