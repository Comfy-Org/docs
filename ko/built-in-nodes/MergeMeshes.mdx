MergeMeshes는 여러 메시 입력을 하나의 메시로 결합합니다. 정점, 면, UV 좌표, 정점 색상을 쌓고 면 인덱스를 조정하여 단일 연속 메시를 만듭니다.

## 입력

| 파라미터 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `메시` | 확장 가능한 슬롯: 메시 객체 2~50개를 연결합니다(`mesh_1`, `mesh_2`, ..., `mesh_50` 이름 사용). 연결된 모든 메시는 하나의 출력 메시로 병합됩니다. | MESH | 예 | 2 ~ 50 meshes |

**참고:** 각 입력 메시의 배치에서 첫 번째 메시 항목만 사용됩니다. 입력 메시 중 하나라도 UV 데이터가 있으면 출력에 UV가 포함되며, UV가 없는 메시에는 0으로 채워진 UV 값이 할당됩니다. 입력 메시 중 하나라도 정점 색상이 있으면 출력에 정점 색상이 포함됩니다. 색상이 없는 메시에는 흰색(값 1) 색상이 할당되며, 색상 채널은 입력 중 가장 큰 채널 수에 맞춰 패딩됩니다. 텍스처를 제공하는 첫 번째 입력의 텍스처만 유지되며, 나머지 텍스처는 삭제됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `메시` | 모든 입력 정점, 면, UV 및 색상이 하나의 메시로 결합된 병합 메시입니다. | MESH |
