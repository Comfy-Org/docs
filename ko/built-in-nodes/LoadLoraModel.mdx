diffusion 모델에 LoRA 스택을 단일 노드에서 적용합니다. `loras`의 각 행은 LoRA 파일, 해당 강도 및 켜기/끄기 스위치를 가지며, 행은 위에서 아래로 적용되므로 각 행은 바로 위 행의 결과를 패치합니다. 워크플로가 동일한 모델에 긴 LoRA 목록을 적용할 때 여러 단일 LoRA 로더를 연쇄하는 대신 이 노드를 사용하십시오.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | LoRA가 적용될 diffusion 모델입니다. | MODEL | 예 | - |
| `loras` | 행 순서(`loras.0`, `loras.1` 등)대로 모델에 적용되는 확장 가능한 LoRA 그룹입니다. LoRA마다 한 행을 추가합니다. 각 행은 파일, 강도 및 켜기/끄기 스위치를 가집니다. | DYNAMIC_GROUP | 예 | 1~20개 행 |

### `loras` 행 필드

모든 행은 다음 필드를 반복하며, 제출된 행 내에서 각 필드는 필수입니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `lora_name` | 적용할 LoRA 파일의 이름입니다. | COMBO | 예 | 여러 옵션 사용 가능 |
| `strength` | 이 LoRA를 얼마나 강하게 적용할지 지정합니다. `0`이면 끄고, 음수 값은 효과를 반전시킵니다. (기본값: 1.0) | FLOAT | 예 | -100~100 (0.01 단위) |
| `enabled` | 끄면 파일이나 강도를 변경하지 않고 이 LoRA를 건너뜁니다. (기본값: true) | BOOLEAN | 예 | false / true |

### 매개변수 제약 사항

- **행 수:** 최소 한 개의 행을 제출해야 하며 최대 20개 행까지 허용되므로, 가장 높은 행 인덱스는 19입니다.
- **건너뛴 행:** 파일이 비어 있거나 `enabled`가 꺼져 있거나 `strength`가 `0`일 때 해당 행을 건너뜁니다. 음수 강도는 건너뛰지 않고 그대로 전달됩니다.
- **행 순서:** 행은 나타나는 순서대로 적용되며, 각 행은 이전 행에서 반환된 모델에서 시작합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `MODEL` | 건너뛰지 않은 LoRA 행이 적용된 확산 모델입니다. | MODEL |
