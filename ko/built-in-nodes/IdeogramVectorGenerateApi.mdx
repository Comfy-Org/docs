이 노드는 Ideogram Vector를 사용하여 텍스트 프롬프트로 편집 가능한 SVG를 생성하며, 선택적으로 최대 5개의 참조 이미지를 활용할 수 있습니다. 결과는 래스터 이미지가 아닌 벡터 마크업이므로, 도형을 벡터 편집기에서 계속 편집할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 사용할 모델입니다. 기본값: `"ideogram-vector-1"`. | DYNAMIC_COMBO | 예 | `"ideogram-vector-1"` |
| `images` | 선택적 참조 이미지입니다. 이미지 1은 기본 소스이고 이미지 2~5는 추가 참조입니다. 프롬프트에서 `@Image1`, `@Image2` 등으로 언급할 수 있습니다. 배치 입력의 경우 이미지마다 한 개로 계산됩니다. | AUTOGROW | 아니요 | 0 ~ 5 개 이미지 |
| `prompt` | SVG에 대한 설명입니다. 입력 이미지에 대한 `@Image1` 형식 참조를 지원합니다. | STRING | 예 | 1 ~ 9500 자 |
| `aspect_ratio` | `"auto"`는 이미지 1의 비율을 따르며, 이미지가 연결되지 않은 경우에는 프롬프트를 따릅니다. 기본값: `"auto"`. | COMBO | 예 | `"auto"`<br />`"1:3"`<br />`"1:2"`<br />`"9:16"`<br />`"10:16"`<br />`"2:3"`<br />`"3:4"`<br />`"4:5"`<br />`"1:1"`<br />`"5:4"`<br />`"4:3"`<br />`"3:2"`<br />`"16:10"`<br />`"16:9"`<br />`"2:1"`<br />`"3:1"` |
| `quality` | 품질 등급입니다. 등급이 높을수록 비용이 더 들고 시간이 더 오래 걸립니다. 기본값: `"medium"`. | COMBO | 예 | `"low"`<br />`"medium"`<br />`"high"` |
| `seed` | 생성용 시드입니다. 동일한 프롬프트, 이미지, 설정 및 시드는 동일한 SVG를 생성합니다. 기본값: 42. | INT | 예 | 0 ~ 2147483647 |

**제약 사항:**

* 프롬프트는 1자 이상 9,500자 이하여야 합니다.
* `images`는 최대 5개의 이미지를 허용하며, 입력이 배치인 경우 이미지마다 하나로 계산됩니다. 각 이미지의 가로세로 비율은 1:6에서 6:1 사이여야 합니다.
* 가장 긴 변이 2048픽셀을 초과하는 이미지는 업로드 전에 축소됩니다.
* 연결되지 않은 이미지를 참조하면 오류가 발생합니다. 예를 들어 이미지가 두 개만 제공된 상태에서 `@Image4`를 참조하는 경우입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `SVG` | 생성된 SVG로, 편집 가능한 벡터 마크업입니다. | SVG |
