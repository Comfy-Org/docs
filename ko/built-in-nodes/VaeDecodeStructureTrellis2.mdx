이 노드는 VAE의 구조 디코더를 사용하여 Trellis 구조 잠재 샘플을 3D 복셀 그리드로 변환합니다. 잠재 변수의 처음 8개 채널만 읽어 복셀 점유를 재구성하고 요청된 대로 출력 해상도를 32 또는 64로 조정합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `샘플` | 디코딩할 구조의 잠재 표현입니다. 디코딩에는 잠재 변수의 처음 8개 채널만 사용됩니다. | LATENT | 예 | - |
| `vae` | 구조 디코더가 잠재 변수를 복셀 그리드로 변환하는 VAE입니다. 디코딩은 배치 단위로 수행됩니다. | VAE | 예 | - |
| `해상도` | 출력 복셀 그리드의 대상 공간 해상도입니다(기본값: "32"). 디코딩된 그리드의 해상도가 다른 경우 일치하도록 다운샘플링됩니다. | COMBO | 예 | "32"<br />"64" |

참고: 디코딩된 복셀 그리드의 해상도가 선택한 `resolution`과 다른 경우, 그리드는 3D 최대 풀링을 사용하여 요청된 크기로 다운샘플링됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `복셀` | 형태가 [배치, 깊이, 높이, 너비]인 float 텐서의 이진 복셀 점유 그리드입니다. 값은 점유된 복셀의 경우 1.0이고 빈 복셀의 경우 0.0입니다. | VOXEL |
