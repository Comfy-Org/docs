StableCascade_SuperResolutionControlnet 노드는 Stable Cascade 초고해상도 처리를 위한 입력을 준비합니다. 입력 이미지를 받아 VAE를 사용하여 인코딩하여 controlnet 입력을 생성하며, 동시에 Stable Cascade 파이프라인의 stage C 및 stage B를 위한 자리 표시자 잠재 표현도 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `이미지` | 초고해상도 처리를 위한 입력 이미지입니다. 인코딩에는 이미지의 처음 3개 색상 채널(RGB)만 사용됩니다. | IMAGE | 예 | - |
| `vae` | 입력 이미지를 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `컨트롤넷 입력` | controlnet 입력에 적합한 VAE 인코딩 이미지 표현입니다. | IMAGE |
| `StageC 잠재 이미지` | Stable Cascade 처리의 stage C를 위한 자리 표시자(0으로 채워진) 잠재 표현으로, 16개 채널과 입력 이미지 크기를 16으로 나눈 치수를 갖습니다. | LATENT |
| `StageB 잠재 이미지` | Stable Cascade 처리의 stage B를 위한 자리 표시자(0으로 채워진) 잠재 표현으로, 4개 채널과 입력 이미지 크기를 2로 나눈 치수를 갖습니다. | LATENT |
