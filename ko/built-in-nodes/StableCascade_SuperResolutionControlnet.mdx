이 노드는 실험적인 Stable Cascade 그룹의 일부입니다. VAE로 입력 이미지를 인코딩하여 ControlNet 입력을 생성하고, Stable Cascade 파이프라인의 stage C와 stage B에 대한 비어 있는(0으로 채워진) 잠재 플레이스홀더를 생성함으로써 Stable Cascade 초해상도 처리를 위한 입력을 준비합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `이미지` | 초해상도 처리 대상 입력 이미지입니다. 이미지의 처음 3개 색상 채널(RGB)만 인코딩에 사용됩니다. | IMAGE | 예 | - |
| `vae` | 입력 이미지를 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `controlnet_input` | ControlNet 입력에 적합한 VAE 인코딩 이미지 표현입니다. | IMAGE |
| `stage_c` | Stable Cascade 처리의 stage C를 위한 플레이스홀더(0으로 채워진) 잠재 표현으로, 16개 채널을 가지며 차원은 입력 이미지 크기를 16으로 나눈 값을 기반으로 합니다. | LATENT |
| `stage_b` | Stable Cascade 처리의 stage B를 위한 플레이스홀더(0으로 채워진) 잠재 표현으로, 4개 채널을 가지며 차원은 입력 이미지 크기를 2로 나눈 값을 기반으로 합니다. | LATENT |
