MiniMax H3 Reference to Video는 텍스트 컨디셔닝과 MiniMax H3 참조-투-비디오(reference-to-video) 생성에 필요한 빈 오디오-비디오 잠재 변수(latent)를 생성합니다. 프롬프트와 선택적 참조 이미지, 비디오, 오디오 클립을 제공하면 노드는 이러한 참조를 모델이 생성 중에 사용할 수 있는 컨디셔닝으로 인코딩합니다. 프롬프트는 `<Picture i>`, `<Video k>`, `<Audio j>` 태그를 사용하여 참조를 나타냅니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 프롬프트를 토큰화하고 참조 미디어를 컨디셔닝 토큰으로 인코딩하는 데 사용되는 CLIP 모델입니다. | CLIP | 예 | |
| `vae` | 참조 이미지와 참조 비디오 프레임을 인코딩하는 데 사용되는 비디오 VAE입니다. 이 값이 없으면 참조 이미지/비디오는 텍스트 인코더에만 컨디셔닝을 제공합니다. | VAE | 아니요 | |
| `audio_vae` | 참조 오디오를 인코딩하는 데 사용되는 오디오 VAE입니다. 오디오는 오디오 VAE 샘플 레이트(기본값 32kHz)로 리샘플링됩니다. 이 값이 없으면 참조 오디오는 텍스트 인코더에만 컨디셔닝을 제공합니다. | VAE | 아니요 | |
| `prompt` | 비디오용 텍스트 프롬프트입니다. 참조 미디어는 `<Picture i>`, `<Video k>`, `<Audio j>` 태그(유형별 1부터 시작)로 지정할 수 있습니다. 여러 줄 및 동적 프롬프트를 지원합니다. | STRING | 예 | |
| `width` | 생성되는 비디오의 너비(픽셀)입니다(기본값: 1344). | INT | 예 | 32 ~ 16384 (단계 32) |
| `height` | 생성되는 비디오의 높이(픽셀)입니다(기본값: 768). | INT | 예 | 32 ~ 16384 (단계 32) |
| `length` | 24fps에서의 프레임 수입니다. 124 = 약 5초, 학습 범위는 약 124~362입니다(기본값: 124). | INT | 예 | 5 ~ 3600 (단계 17) |
| `ref_image_size` | 참조 이미지 크기 조정 방식입니다. `match`는 각 참조 이미지를 종횡비를 유지한 채 생성 영역의 픽셀 면적으로 축소만 합니다. `max`는 최상의 동일성 보존 충실도를 위해 참조 파이프라인의 2048px 짧은 변을 사용합니다. 참조 토큰은 모든 샘플링 단계에서 전달되므로 `max`는 몇 배 더 느릴 수 있습니다(기본값: `match`). | COMBO | 예 | `"match"`<br />`"max"` |
| `ref_images` | 확장 슬롯: 참조 이미지를 최대 9개까지 연결할 수 있습니다(`ref_image_1` ... `ref_image_9`). 참조 이미지는 더 클 경우 2048px 짧은 변으로 다운스케일되며 절대 업스케일되지 않습니다. | IMAGE | 아니요 | 0 ~ 9 |
| `ref_videos` | 확장 슬롯: 참조 비디오를 최대 3개까지 연결할 수 있습니다(`ref_video_1` ... `ref_video_3`). 참조 비디오 프레임은 24fps(2~15초)입니다. | IMAGE | 아니요 | 0 ~ 3 |
| `ref_video_audios` | 확장 슬롯: 사운드트랙을 최대 3개까지 연결할 수 있습니다(`ref_video_audio_1` ... `ref_video_audio_3`). 동일한 번호의 참조 비디오에 대한 사운드트랙입니다. | AUDIO | 아니요 | 0 ~ 3 |
| `ref_audios` | 확장 슬롯: 독립형 참조 오디오 클립을 최대 3개까지 연결할 수 있습니다(`ref_audio_1` ... `ref_audio_3`). | AUDIO | 아니요 | 0 ~ 3 |

참고:

- 프롬프트는 참조 미디어를 유형별 1부터 시작하는 태그로 지정합니다. `<Picture i>`는 이미지, `<Video k>`는 비디오, `<Audio j>`는 오디오를 나타냅니다. 참조는 고정된 순서로 모델에 제공됩니다. 즉 이미지, 그다음 비디오(각 사운드트랙의 `<Audio j>` 라벨은 해당 `<Video k>` 바로 앞에 배치됨), 그다음 독립형 오디오 순서입니다.
- `ref_video_audio_N`에 연결된 사운드트랙은 `ref_video_N`에 연결된 참조 비디오와 함께 사용됩니다.
- 참조 비디오는 최소 5프레임(24fps에서 약 0.2초) 이상을 포함해야 하며, 그렇지 않으면 노드가 오류를 발생시킵니다. 요청된 `length`를 초과하는 프레임은 잘려나가고, 남은 프레임 수는 모델이 지원하는 값으로 조정됩니다.
- 요청된 `length`는 latent가 생성되기 전에 지원되는 프레임 수로 조정됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 인코딩된 프롬프트를 포함하는 컨디셔닝입니다. 참조 미디어와 해당 VAE가 제공되면 MiniMax H3 모델이 사용하는 인코딩된 참조 이미지, 비디오 및 오디오 콘텐츠도 포함합니다. | CONDITIONING |
| `latent` | 요청된 `width`, `height`, `length`(프레임 수)에 해당하는 빈 오디오-비디오 latent입니다. | LATENT |
