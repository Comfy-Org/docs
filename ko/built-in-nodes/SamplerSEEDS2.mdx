이 노드는 이미지 생성을 위한 설정 가능한 샘플러를 제공합니다. 이 노드는 확률적 미분 방정식(SDE) 솔버인 SEEDS-2 알고리즘을 구현합니다. 매개변수를 조정하여 `seeds_2`, `exp_heun_2_x0`, `exp_heun_2_x0_sde`를 포함한 여러 특정 샘플러처럼 동작하도록 구성할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `solver_type` | 샘플러의 기본 솔버 알고리즘을 선택합니다. | COMBO | 예 | "phi_1"<br />"phi_2" |
| `eta` | 확률적 강도 (기본값: 1.0). | FLOAT | 아니요 | 0.0 - 100.0 |
| `s_noise` | SDE 노이즈 배율 (기본값: 1.0). | FLOAT | 아니요 | 0.0 - 100.0 |
| `r` | 중간 단계(c2 노드)의 상대적 단계 크기 (기본값: 0.5). | FLOAT | 아니요 | 0.01 - 1.0 |

**참고:** 노드 설명은 다음과 같은 샘플러 프리셋을 정의합니다:
- `seeds_2`: 기본 설정
- `exp_heun_2_x0`: `solver_type` = "phi_2", `r` = 1.0, `eta` = 0.0
- `exp_heun_2_x0_sde`: `solver_type` = "phi_2", `r` = 1.0, `eta` = 1.0, `s_noise` = 1.0

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `sampler` | 다른 샘플링 노드에 전달할 수 있는 구성된 샘플러 객체입니다. | SAMPLER |
