이 노드는 3D 모델을 개별 부품으로 분할합니다. 모델을 Tripo 세그멘테이션 서비스로 전송하고, 작업이 완료될 때까지 기다린 뒤, 분할된 모델을 GLB 형식과 쉼표로 구분된 부품 이름 목록과 함께 반환합니다. 이러한 부품 이름은 Tripo: Complete Mesh Parts, Tripo: Retopology, Tripo: Convert model 같은 후속 단계로 전달됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | 부품으로 분할할 3D 모델의 작업 ID입니다. | MODEL_TASK_ID | 예 | N/A |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model_file` | 분할된 GLB 모델의 출력 파일 이름이며 `<task_id>.glb` 형식입니다. 하위 호환성을 위해서만 유지됩니다. | STRING |
| `segment task_id` | 결과를 생성한 세그멘테이션 작업의 작업 ID입니다. | SEGMENT_TASK_ID |
| `GLB` | 분할된 3D 모델로, GLB 파일입니다. | GLB |
| `part_names` | 쉼표로 구분된 부품 이름입니다. | STRING |
