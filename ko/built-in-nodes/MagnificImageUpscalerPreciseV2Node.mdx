Magnific Image Upscale (Precise V2) 노드는 선명도, 그레인 및 디테일 향상을 세밀하게 제어하면서 고충실도 이미지 업스케일링을 수행합니다. 이 노드는 외부 API를 통해 이미지를 처리하며 최대 출력 해상도 10060×10060 픽셀을 지원합니다. 노드는 다양한 처리 스타일을 제공하며 요청된 출력이 최대 허용 크기를 초과할 경우 입력 이미지를 자동으로 다운스케일할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 업스케일링할 입력 이미지입니다. 정확히 하나의 이미지가 필요합니다. 최소 크기는 160x160 픽셀입니다. 종횡비는 1:3에서 3:1 사이여야 합니다. | IMAGE | 예 | - |
| `scale_factor` | 원하는 업스케일링 배율입니다. | COMBO | 예 | `"2x"`<br />`"4x"`<br />`"8x"`<br />`"16x"` |
| `flavor` | 처리 스타일: 일반용은 sublime, 사진용은 photo, 노이즈가 많은 사진용은 photo_denoiser입니다. | COMBO | 예 | `"sublime"`<br />`"photo"`<br />`"photo_denoiser"` |
| `sharpen` | 이미지 선명도 강도입니다. 값이 높을수록 가장자리 정의와 선명도가 높아집니다. 기본값: 7. | INT | 아니요 | 0 ~ 100 |
| `smart_grain` | 이미지가 너무 매끄럽거나 인공적으로 보이는 것을 방지하기 위한 지능형 그레인/텍스처 향상입니다. 기본값: 7. | INT | 아니요 | 0 ~ 100 |
| `ultra_detail` | 업스케일링 중 추가되는 미세 디테일, 텍스처 및 미세한 세부 요소를 제어합니다. 기본값: 30. | INT | 아니요 | 0 ~ 100 |
| `auto_downscale` | 출력이 최대 해상도를 초과할 경우 입력 이미지를 자동으로 다운스케일합니다. 기본값: False. | BOOLEAN | 아니요 | - |

**참고:** `auto_downscale`이 비활성화된 상태에서 요청된 출력 크기(입력 크기 × `scale_factor`)가 10060x10060 픽셀을 초과하면 노드가 오류를 발생시킵니다. `auto_downscale`이 활성화되면 노드는 품질 손실을 최소화하는 최적의 배율을 찾으려고 시도합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 업스케일링된 결과 이미지입니다. | IMAGE |
