**ColorToRGBInt** 노드는 16진수 형식(예: `#FF5733`)으로 제공된 색상을 단일 RGB 정수 값으로 변환합니다. 색상 문자열에서 빨간색, 녹색, 파란색 구성 요소를 추출하여 하나의 정수로 결합하고, 원래의 16진수 표현과 알파(불투명도) 값도 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `색상` | `#RRGGBB` 또는 `#RRGGBBAA` 형식의 색상 값입니다. 7자 또는 9자 길이여야 하며 `#`로 시작해야 합니다. | COLOR | 예 | `#RRGGBB`<br />`#RRGGBBAA` |

**참고:** 입력 `color` 문자열은 `#RRGGBB` 또는 `#RRGGBBAA` 형식을 따라야 합니다. 길이가 7자 또는 9자가 아니거나, `#`로 시작하지 않거나, 유효하지 않은 16진수 문자가 포함된 경우 노드에서 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `rgb_정수` | 계산된 RGB 정수 값으로, `(Red * 65536) + (Green * 256) + Blue` 공식에서 파생됩니다. | INT |
| `hex` | `#RRGGBB` 형식의 16진수 색상 문자열입니다. 입력에 알파 채널이 포함된 경우 이 출력에서는 제거됩니다. | COLOR |
| `alpha` | 0.0과 1.0 사이의 알파(불투명도) 값입니다. 입력이 `#RRGGBB`인 경우 1.0과 같고, 입력이 `#RRGGBBAA`인 경우 알파 채널 값을 255로 나눈 값입니다. | FLOAT |
