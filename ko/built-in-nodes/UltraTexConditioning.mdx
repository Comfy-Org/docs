UltraTex LoRA와 함께 FLUX.2 Klein 9B를 조건화하여 참조 이미지의 모습을 메시에 입히며, 뷰당 하나의 이미지로 생성합니다. `world normal` 모드의 Render Mesh로 뷰를 렌더링하고, Create Camera Orbit의 4개 뷰에 상단과 하단을 더해 사용하며, Bake Texture From Views로 결과를 베이크합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `conditioning` | 텍스트 조건화입니다. UltraTex는 빈 프롬프트로 학습되었습니다. | CONDITIONING | 예 | - |
| `vae` | 법선, 뷰 및 참조를 인코딩하는 데 사용되는 VAE입니다. | VAE | 예 | - |
| `normals` | Render Mesh `world normal` 이미지입니다. 6개의 표준 뷰 또는 4개의 측면 뷰입니다. | IMAGE | 예 | - |
| `masks` | 동일한 뷰의 Render Mesh 마스크이며, 뷰당 하나입니다. | MASK | 예 | - |
| `reference` | 정면 카메라 쪽에서 본, 객체가 보여야 하는 모습입니다. | IMAGE | 예 | - |
| `reference_mask` | 참조의 객체 마스크이며, 객체는 흰색입니다. 기본값: 완전 흰색. | MASK | 아니요 | - |
| `extra_views` | 추가 참조입니다. 다른 뷰에서 본 객체이며, 각 항목은 참조가 정면에 연결되는 방식과 동일하게 해당 뷰에 연결됩니다. 기본값: `"off"`. | DYNAMIC_COMBO | 예 | `"off"`<br />`"on"` |

### 추가 뷰 "on" 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `right` | 오른쪽 뷰에서 본 객체입니다. | IMAGE | 아니요 | - |
| `back` | 뒤쪽 뷰에서 본 객체입니다. | IMAGE | 아니요 | - |
| `left` | 왼쪽 뷰에서 본 객체입니다. | IMAGE | 아니요 | - |
| `top` | 위쪽 뷰에서 본 객체입니다. | IMAGE | 아니요 | - |
| `bottom` | 아래쪽 뷰에서 본 객체입니다. | IMAGE | 아니요 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `conditioning` | 뷰 그리드, 참조 잠재값 및 UltraTex에 필요한 토큰 마스크를 담고 있는 조건화입니다. | CONDITIONING |

참고: `normals`는 6개의 표준 뷰(Create Camera Orbit에서 `count` 4 및 상단과 하단 `poles`) 또는 4개의 측면 뷰 중 하나를 포함해야 하며, `masks`는 해당 뷰 수와 일치해야 합니다.
