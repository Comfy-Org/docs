이 노드는 Seedance 2.5 Draft의 1080p 최종 비디오를 렌더링합니다. 드래프트는 빠른 480p 미리보기입니다. Seedance 2.5 비디오 노드(텍스트-투-비디오, 첫/마지막 프레임-투-비디오, 참조-투-비디오)에서 `model`을 `Seedance 2.5 Draft`로 설정하고 실행한 다음, 해당 노드의 `draft_task_id` 출력을 이 노드에 연결하세요. 최종 결과는 드래프트의 장면과 모션을 유지하며, 드래프트를 생성한 프롬프트, 참조, 길이, 화면 비율, 오디오 설정을 재사용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `draft_task_id` | Seedance 2.5 Draft 모델로 실행한 Seedance 2.5 노드의 `draft_task_id` 출력, 또는 붙여넣은 드래프트 작업 ID입니다. 생성 노드를 다시 실행할 때는 시드 제어를 fixed로 설정하세요. 그렇지 않으면 다음 실행에서 검토한 드래프트를 재사용하지 않고 새 드래프트를 생성합니다. | STRING | 예 | - |
| `watermark` | 비디오에 워터마크를 추가할지 여부입니다. 기본값은 False입니다. 고급 설정입니다. | BOOLEAN | 아니요 | True / False |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `video` | 렌더링된 1080p 최종 비디오입니다. 렌더 작업이 완료되면 제공자로부터 다운로드됩니다. | VIDEO |

**참고:** 드래프트는 생성된 후 7일 동안 렌더링할 수 있습니다. 드래프트 작업 ID만으로 드래프트를 식별할 수 있으므로 프롬프트, 참조, 길이, 화면 비율, 오디오 설정을 다시 전달할 필요가 없습니다.
