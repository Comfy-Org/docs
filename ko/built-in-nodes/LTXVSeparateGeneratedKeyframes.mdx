## 개요

LTXV Separate Generated Keyframes 노드는 LTXV Add Generated Keyframes에 의해 추가된 생성된 키프레임을 샘플링된 latent에서 다시 분리하고 컨디셔닝에서 제거합니다. 비디오 latent를 공간적으로 업스케일링하기 전에 사용하십시오. 먼저 LTXV Crop Guides를 실행하지 마십시오. 이 노드는 생성된 키프레임을 일회용 가이드로 취급하여 제거합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 생성된 키프레임 메타데이터를 보유한 positive 컨디셔닝입니다. 출력 시 이 컨디셔닝에서 메타데이터가 제거됩니다. | CONDITIONING | 예 | N/A |
| `negative` | 생성된 키프레임 메타데이터를 보유한 negative 컨디셔닝입니다. 출력 시 이 컨디셔닝에서 메타데이터가 제거됩니다. | CONDITIONING | 예 | N/A |
| `latent` | 생성된 키프레임을 포함하는 비디오 latent입니다. 출력 시 이 latent에서 키프레임이 제거됩니다. | LATENT | 예 | N/A |
| `keyframes_to_batch` | 키프레임을 단일 프레임 latent의 배치로 반환합니다. 비활성화하면 하나의 다중 프레임 latent로 반환되며, 이는 latent 업샘플러와 이후 Add Generated Keyframes가 기대하는 형식입니다. | BOOLEAN | 아니요 | 기본값: False |

### 입력 관련 참고 사항

- `positive`에는 생성된 키프레임 메타데이터가 포함되어 있어야 하며, 그렇지 않으면 노드에서 먼저 LTXV Add Generated Keyframes로 키프레임을 추가하라는 오류를 발생시킵니다.
- `latent`는 일반 비디오 latent(5D 텐서)여야 합니다. 비디오와 오디오 latent가 아직 결합되어 있다면 먼저 Separate AV Latent로 분리해야 합니다.
- 키프레임이 추가될 때 기록된 latent 프레임당 토큰 수는 제공된 `latent`의 프레임당 토큰 수와 일치해야 합니다. 키프레임이 추가된 후 latent의 크기가 조정되었다면 더 이상 정렬되지 않으며 노드에서 오류를 발생시킵니다. latent를 업스케일링하기 전에 키프레임을 분리해야 합니다.
- 기록된 키프레임 프레임 범위는 제공된 `latent` 내에 맞아야 하며, 그렇지 않으면 키프레임이 다른 latent를 기준으로 기록되었다는 오류를 노드에서 발생시킵니다.
- 기록된 가이드 어텐션 항목 인덱스가 컨디셔닝에 여전히 존재해야 합니다. 키프레임이 추가된 후 컨디셔닝이 다시 작성되었다면 노드에서 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 생성된 키프레임 메타데이터가 제거된 positive 컨디셔닝입니다. | CONDITIONING |
| `negative` | 생성된 키프레임 메타데이터가 제거된 negative 컨디셔닝입니다. | CONDITIONING |
| `latent` | 생성된 키프레임이 제거된 비디오 latent입니다. | LATENT |
| `keyframes` | 분리된 키프레임으로, generated_keyframe_indices 및 generated_keyframe_num_frames로 레이블이 지정됩니다. 이후 Add Generated Keyframes에 전달하여 새 슬롯을 초기화하거나, Generated Keyframes To Guides에 전달하여 고정된 이미지 가이드로 고정할 수 있습니다(캔버스 길이가 변경된 경우 인덱스가 다시 매핑됩니다). | LATENT |

## 참고 사항

- `keyframes_to_batch` 매개변수는 키프레임이 단일 프레임 latent의 배치로 반환되는지, 하나의 다중 프레임 latent로 반환되는지를 결정합니다.
- 이 노드는 추가 처리를 수행하기 전에 생성된 키프레임이 컨디셔닝과 latent에서 제거되도록 보장합니다.
- `keyframes` 출력은 생성된 키프레임을 위한 새 슬롯을 초기화하거나, 고정된 이미지 가이드로 고정하는 데 사용할 수 있습니다.
- latent에 생성된 키프레임이 없거나 키프레임이 예상 형식과 일치하지 않으면 노드에서 `ValueError`를 발생시킵니다.
- 이 노드는 생성된 키프레임이 LTXV Add Generated Keyframes 노드를 사용하여 추가되었으며 현재 latent와 호환된다고 가정합니다.
