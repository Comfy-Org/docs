이 노드는 Bria RMBG 2.0 서비스를 사용하여 이미지에서 배경을 제거합니다. 이미지를 외부 API로 전송하여 처리하고, 배경이 제거된 결과를 반환합니다.

## 입력

`moderation` 선택자는 `"true"`로 설정하면 추가 중재 옵션을 표시합니다.

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `moderation` | 중재 설정입니다. `"true"`로 설정하면 추가 중재 옵션을 사용할 수 있습니다. | DYNAMIC_COMBO | 예 | `"false"`<br />`"true"` |
| `image` | 배경이 제거될 입력 이미지입니다. | IMAGE | 예 | - |
| `seed` | 시드는 노드 재실행 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. 기본값: `0`. | INT | 예 | 0 ~ 2147483647 |

### Moderation "true" 입력

이 매개변수들은 `moderation`이 `"true"`로 설정된 경우에만 나타납니다. `"false"` 옵션은 추가 입력을 추가하지 않습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | 입력 이미지에 대한 시각적 콘텐츠 중재를 활성화합니다. 기본값: `False`. | BOOLEAN | 아니요 | - |
| `visual_output_moderation` | 출력 이미지에 대한 시각적 콘텐츠 중재를 활성화합니다. 기본값: `True`. | BOOLEAN | 아니요 | - |

**참고:** `visual_input_moderation` 및 `visual_output_moderation` 매개변수는 `moderation` 매개변수에 종속됩니다. 이들은 `moderation`이 `"true"`로 설정된 경우에만 활성화됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 배경이 제거된 처리된 이미지입니다. | IMAGE |
