Adjust Brightness 노드는 이미지의 밝기를 조정합니다. 이미지의 색상 값에 `factor`를 곱하고 결과가 유효한 0.0~1.0 범위 내에 유지되도록 합니다. factor가 1.0이면 이미지가 변경되지 않고, 1.0보다 낮으면 더 어두워지며, 1.0보다 높으면 더 밝아집니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `image` | 조정할 입력 이미지입니다. 단일 이미지 또는 이미지 배치(batch)를 허용합니다. | IMAGE | 예 | - |
| `factor` | 밝기 배율입니다. 1.0 = 변경 없음, &lt;1.0 = 더 어두움, >1.0 = 더 밝음. (기본값: 1.0) | FLOAT | 아니요 | 0.0 - 2.0 |

참고: 입력 이미지에 알파 채널(RGBA)이 있는 경우 색상 채널만 조정됩니다. 알파 채널은 색상이 아닌 투명도를 저장하므로 입력에서 변경 없이 그대로 복사됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `images` | 밝기가 조정된 출력 이미지입니다. 입력에 알파 채널이 있는 경우 알파 값은 변경되지 않습니다. | IMAGE |
