이 노드는 MiniMax H3 모델을 사용하여 첫 번째 프레임 이미지와 선택적으로 마지막 프레임 이미지로부터 비디오를 생성합니다. `model` 선택기에 따라 적용되는 생성 설정과 제약 조건이 변경되며, 생성된 비디오의 종횡비는 제공된 이미지의 종횡비를 따릅니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 비디오 생성에 사용할 모델입니다. 모델을 선택하면 아래에 해당 모델별 설정이 표시됩니다. | DYNAMIC_COMBO | 예 | "MiniMax H3"<br />"MiniMax H3 Max"<br />"MiniMax H3 Max Turbo" |
| `첫 프레임` | 비디오의 첫 번째 프레임 이미지입니다. 생성된 비디오는 이 이미지의 종횡비를 따릅니다. | IMAGE | 예 | - |
| `마지막 프레임` | 비디오의 마지막 프레임 이미지입니다. 선택 사항이며, 제공된 경우 첫 번째 프레임에서 이 마지막 프레임을 향해 비디오가 생성됩니다. | IMAGE | 아니요 | - |
| `시드` | 난수 시드입니다. 동일한 시드로 동일한 요청을 보내면 유사한 결과가 생성되지만 완전히 동일한 결과는 보장되지 않습니다. '생성 후 제어(control after generate)' 옵션이 포함됩니다. 기본값: 42. | INT | 예 | 0 ~ 4294967295 |
| `워터마크` | 비디오에 AIGC 워터마크를 추가할지 여부입니다. 고급 매개변수입니다. `MiniMax H3` 모델에서만 지원됩니다. 기본값: False. | BOOLEAN | 예 | True<br />False |

### MiniMax H3 입력

다음 설정은 `model` 선택기에서 `MiniMax H3`를 선택한 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성용 텍스트 프롬프트입니다. 공백 문자가 아닌 문자가 하나 이상 포함되어야 합니다. | STRING | 예 | 여러 줄 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | "768P"<br />"2K" |
| `duration` | 출력 비디오의 길이(초)입니다. 기본값: 5. | INT | 예 | 4 ~ 15 |

### MiniMax H3 Max 및 MiniMax H3 Max Turbo 입력

다음 설정은 `model` 선택기에서 `MiniMax H3 Max` 또는 `MiniMax H3 Max Turbo` 중 하나를 선택한 경우 표시됩니다. 두 모델 모두 동일한 설정을 제공합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성용 텍스트 프롬프트입니다. 비어 있거나 공백만 있어서는 안 되며, 50,000자로 제한됩니다. | STRING | 예 | 여러 줄 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. 기본값: 768P. | COMBO | 예 | "480P"<br />"768P" |
| `duration` | 출력 비디오의 길이(초)입니다. 기본값: 5. | INT | 예 | 5 ~ 15 |
| `prompt_expansion_mode` | 생성 전에 프롬프트를 다시 작성하는 데 어느 정도 노력을 들일지 결정합니다. 기본값: balanced. | COMBO | 예 | "balanced"<br />"quality" |

**제약 조건 관련 참고 사항:**

- 프롬프트에는 텍스트가 포함되어야 합니다. 빈 프롬프트나 공백만 있는 프롬프트는 거부됩니다.
- 제공되는 모든 프레임 이미지는 너비 256픽셀 이상, 높이 256픽셀 이상이어야 하며, 너비 대 높이 종횡비가 0.4에서 2.5 사이(약 2:5 ~ 5:2)여야 합니다. 이 요구 사항은 `first_frame`에 적용되며, `last_frame`도 제공하는 경우 해당 이미지에도 적용됩니다.
- `last_frame`을 생략하면 첫 번째 프레임만으로 비디오가 생성됩니다.
- 출력 비디오는 제공된 이미지의 종횡비를 따릅니다.
- `watermark`는 `MiniMax H3`에서만 지원됩니다. `MiniMax H3 Max` 또는 `MiniMax H3 Max Turbo`에서 이를 활성화하면 오류가 발생합니다.
- 비디오 길이는 `MiniMax H3`의 경우 4초에서 15초, `MiniMax H3 Max` 및 `MiniMax H3 Max Turbo`의 경우 5초에서 15초입니다.
