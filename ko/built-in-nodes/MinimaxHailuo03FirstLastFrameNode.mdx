이 노드는 MiniMax H3 모델을 사용하여 첫 번째 프레임 이미지와 선택적인 마지막 프레임 이미지로부터 비디오를 생성합니다. 생성된 비디오는 입력 이미지의 종횡비를 따르며, 마지막 프레임이 제공되면 첫 번째 프레임에서 마지막 프레임 방향으로 애니메이션됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 비디오 생성에 사용할 모델입니다. 이 콤보에는 모델 선택("MiniMax H3"), 생성할 비디오를 설명하는 텍스트 프롬프트, 출력 해상도 및 비디오 길이가 포함됩니다. 프롬프트에는 공백이 아닌 문자가 하나 이상 포함되어야 합니다. | COMBO | 예 | "MiniMax H3" |
| `첫 프레임` | 비디오의 첫 번째 프레임 이미지입니다. 생성된 비디오의 종횡비는 이 이미지를 따릅니다. 최소 256x256 픽셀이어야 하며, 너비 대 높이 비율이 0.4에서 2.5 사이여야 합니다. | IMAGE | 예 | - |
| `마지막 프레임` | 비디오의 선택적 마지막 프레임 이미지입니다. 제공되면 비디오는 첫 번째 프레임에서 시작하여 이 이미지에서 끝납니다. `첫 프레임`과 동일한 크기 및 종횡비 요구 사항을 충족해야 합니다. | IMAGE | 아니요 | - |
| `시드` | 무작위 시드입니다. 동일한 시드를 사용한 동일한 요청은 유사하지만 동일하다고 보장되지는 않는 결과를 생성합니다. 각 생성 후 무작위화하는 "생성 후 제어" 옵션을 포함합니다. 기본값: 42. | INT | 예 | 0 ~ 4294967295 |
| `워터마크` | 비디오에 AIGC 워터마크를 추가할지 여부입니다. 고급 매개변수입니다. 기본값: False. | BOOLEAN | 예 | True<br />False |

**제약 조건 참고:**
- `model` 콤보 내부의 텍스트 프롬프트는 비어 있을 수 없으며, 공백만 있는 프롬프트는 거부됩니다.
- 제공되는 모든 프레임 이미지(`first_frame` 및 사용되는 경우 `last_frame`)는 최소 256픽셀 너비와 256픽셀 높이여야 하며, 너비 대 높이 비율이 0.4에서 2.5(약 2:5 ~ 5:2) 사이여야 합니다.
- `last_frame`은 선택 사항입니다. 생략하면 첫 번째 프레임만으로 비디오가 생성됩니다.
- 출력 비디오의 종횡비는 별도의 비율 설정이 아닌 제공된 이미지에 의해 결정됩니다.
