이 노드는 MiniMax H3 모델을 사용하여 첫 프레임 이미지와 선택적으로 마지막 프레임 이미지로부터 비디오를 생성합니다. `model` 선택기는 적용되는 생성 설정과 제약 조건을 변경하며, 생성된 비디오의 종횡비는 제공된 이미지를 따릅니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 비디오 생성에 사용할 모델입니다. 모델을 선택하면 아래에 해당 모델의 전용 설정이 표시됩니다. | DYNAMIC_COMBO | 예 | "MiniMax H3"<br />"MiniMax H3 Max"<br />"MiniMax H3 Max Turbo" |
| `첫 프레임` | 비디오의 첫 프레임 이미지입니다. 생성된 비디오는 이 이미지의 종횡비를 따릅니다. | IMAGE | 예 | - |
| `마지막 프레임` | 비디오의 선택적 마지막 프레임 이미지입니다. 제공되면 비디오는 첫 프레임에서 이 마지막 프레임 방향으로 생성됩니다. | IMAGE | 아니요 | - |
| `시드` | 무작위 시드입니다. 동일한 시드로 동일한 요청을 하면 유사하지만 반드시 동일하다고 보장되지는 않는 결과가 나옵니다. "생성 후 제어" 옵션을 포함합니다. 기본값: 42. | INT | 예 | 0~4294967295 |
| `워터마크` | 비디오에 AIGC 워터마크를 추가할지 여부입니다. 고급 매개변수입니다. `MiniMax H3` 모델에서만 지원됩니다. 기본값: False. | BOOLEAN | 예 | True<br />False |

### MiniMax H3 입력

이 설정은 `model` 선택기에서 `MiniMax H3`를 선택하면 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 하나 이상의 공백이 아닌 문자를 포함해야 합니다. | STRING | 예 | 여러 줄 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | "768P"<br />"2K" |
| `duration` | 출력 비디오의 길이(초)입니다. 기본값: 5. | INT | 예 | 4~15 |

### MiniMax H3 Max 및 MiniMax H3 Max Turbo 입력

이 설정은 `MiniMax H3 Max`와 `MiniMax H3 Max Turbo`가 공유합니다. 어느 모델을 선택하든 동일한 설정이 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 텍스트 프롬프트입니다. 비어 있거나 공백만으로 구성될 수 없으며, 50,000자로 제한됩니다. | STRING | 예 | 여러 줄 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. 기본값: 768P. | COMBO | 예 | "480P"<br />"768P" |
| `duration` | 출력 비디오의 길이(초)입니다. 기본값: 5. | INT | 예 | 5~15 |
| `prompt_expansion_mode` | 생성 전에 프롬프트를 재작성하는 데 사용하는 노력 수준입니다. 기본값: balanced. | COMBO | 예 | "balanced"<br />"quality" |

**제약 사항:**

- 프롬프트에는 텍스트가 포함되어야 합니다. 비어 있거나 공백만 있는 프롬프트는 거부됩니다.
- 제공된 모든 프레임 이미지는 너비가 최소 256픽셀, 높이가 최소 256픽셀이어야 하며, 너비 대 높이 종횡비가 0.4에서 2.5 사이(대략 2:5~5:2)여야 합니다. 이 요구 사항은 `first_frame`과, 제공된 경우 `last_frame`에 적용됩니다.
- `last_frame`을 생략하면 비디오는 첫 프레임만으로 생성됩니다.
- 출력 비디오는 제공된 이미지의 종횡비를 따릅니다.
- `watermark`는 `MiniMax H3`에서만 지원됩니다. `MiniMax H3 Max` 또는 `MiniMax H3 Max Turbo`에서 이를 활성화하면 오류가 발생합니다.
- 길이는 `MiniMax H3`의 경우 4~15초, `MiniMax H3 Max` 및 `MiniMax H3 Max Turbo`의 경우 5~15초입니다.
