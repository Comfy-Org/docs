이 노드는 정지 이미지에서 시작하여 피사체 주변의 새로운 각도와 거리로 카메라를 이동시키는 비디오를 생성합니다. 방위각, 고도 및 거리는 카메라가 최종적으로 위치하는 곳을 설명하며, 첫 프레임은 제공된 상태 그대로 유지됩니다. 프롬프트가 제공되지 않으면 장면은 정지된 상태로 유지되고 카메라만 이동합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 비디오 생성에 사용할 모델입니다. | DYNAMIC_COMBO | 예 | "MiniMax H3 Max" |

### MiniMax H3 Max 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `image` | 비디오의 첫 프레임이며 최소 256x256 픽셀입니다. 가로세로 비율은 0.4에서 2.5 사이여야 합니다. | IMAGE | 예 | 단일 이미지 |
| `camera_info` | 선택적 종료 카메라입니다. 예를 들어 Create Camera Info 또는 Compose Camera Angle Prompt에서 생성할 수 있으며, 이미지를 정면 뷰로 사용합니다. 연결되면 `azimuth`와 `elevation`을 설정합니다. | LOAD3D_CAMERA | 아니요 | 카메라 정보 |
| `prompt` | 선택 사항입니다. 비어 있으면 장면은 정지된 상태로 유지되고 카메라만 이동합니다. | STRING | 예 | 0~50000자 |
| `azimuth` | 비디오 종료 시점에 피사체 주위를 도는 수평 궤도이며, 이미지 기준 각도입니다(기본값: 90). 양수 값은 카메라를 오른쪽으로 이동시키므로 피사체는 프레임의 왼쪽을 향해 회전합니다. 이는 목표값입니다. 90도 궤도는 종종 30도에서 90도 사이의 결과로 나타납니다. `camera_info`가 연결된 경우 무시됩니다. | INT | 예 | -360~360 |
| `elevation` | 비디오 종료 시점의 수직 카메라 각도입니다(기본값: 0). 양수 값은 위에서 아래를 내려다보고, 음수 값은 아래에서 위를 올려다봅니다. `camera_info`가 연결된 경우 무시됩니다. | INT | 예 | -90~90 |
| `distance` | 비디오 종료 시점의 이미지 기준 카메라 거리입니다. 1은 유지, 1 미만은 더 가까이, 1초과는 뒤로 물러납니다(기본값: 1.0). | FLOAT | 예 | 0.1~10.0 |
| `duration` | 출력 비디오의 길이(초)입니다(기본값: 5). | INT | 예 | 1~15 |
| `resolution` | 출력 비디오의 해상도입니다(기본값: "768P"). | COMBO | 예 | "480P"<br />"768P"<br />"1080P" |
| `prompt_expansion_mode` | 생성 전에 프롬프트를 다시 작성하는 데 얼마나 많은 노력을 들이는지 설정합니다(기본값: "balanced"). | COMBO | 예 | "disabled"<br />"balanced"<br />"quality" |
| `seed` | 무작위 시드입니다. 동일한 요청과 동일한 시드를 사용하면 유사한 결과가 나오지만, 동일한 결과가 보장되지는 않습니다(기본값: 42). | INT | 예 | 0~4294967295 |
