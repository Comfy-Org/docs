Dual CFG Guider 노드는 두 개의 컨디셔닝 입력과 하나의 네거티브 컨디셔닝 입력을 함께 사용하는 샘플링용 가이던스 시스템을 생성합니다. 생성 결과에 각 컨디셔닝이 얼마나 강하게 영향을 미치는지 제어하기 위해 두 개의 개별 가이던스 스케일을 적용하며, 이러한 스케일을 결합하는 두 가지 방식인 "regular"와 "nested"를 지원합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 가이던스에 사용할 모델 | MODEL | 예 | - |
| `조건1` | 첫 번째 포지티브 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `조건2` | 첫 번째 포지티브 컨디셔닝과 네거티브 컨디셔닝 사이의 참조로 사용되는 두 번째 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `부정 조건` | 네거티브 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `전체 조건 cfg` | 첫 번째 포지티브 컨디셔닝에 적용되는 가이던스 스케일 (기본값: 8.0) | FLOAT | 예 | 0.0 - 100.0 |
| `(조건2 - 부정 조건) cfg` | 두 번째 컨디셔닝과 네거티브 컨디셔닝 사이에 적용되는 가이던스 스케일 (기본값: 8.0) | FLOAT | 예 | 0.0 - 100.0 |
| `style` | 적용할 가이던스 스타일 (기본값: "regular"). "nested"로 설정하면 가이던스가 중첩 방식으로 적용됩니다 | COMBO | 예 | "regular"<br />"nested" |

참고: `regular` 스타일에서는 `cfg_cond2_negative`가 `cond2`와 `negative` 사이에 적용되고, `cfg_conds`는 `cond1`과 `cond2` 사이에 적용됩니다. `nested` 스타일에서는 `cfg_conds`가 먼저 `cond1`과 `cond2` 사이에 적용되며, 그 결과 예측값은 `cfg_cond2_negative`를 사용하여 `negative`로부터 멀어지도록 가이드됩니다.

참고: `regular` 스타일에서 `cfg_cond2_negative`가 1.0이면 네거티브 컨디셔닝은 건너뛰고, `cfg_conds`도 1.0이면 두 번째 컨디셔닝 역시 건너뜁니다. 이렇게 하면 수행되는 모델 평가 횟수가 줄어듭니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `GUIDER` | 샘플링에 사용할 준비가 된 구성된 가이던스 시스템 | GUIDER |
