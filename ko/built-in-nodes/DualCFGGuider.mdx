DualCFGGuider 노드는 이중 분류기 없는 안내(Classifier-Free Guidance) 샘플링을 위한 안내 시스템을 생성합니다. 이 노드는 두 개의 조건 입력을 하나의 부정 조건 입력과 결합하고, 두 개의 개별 안내 스케일을 적용하여 각 조건이 생성 출력에 영향을 미치는 강도를 제어합니다. 이러한 안내 스케일을 결합하는 두 가지 스타일("regular" 및 "nested")을 지원합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 안내에 사용할 모델 | MODEL | 예 | - |
| `조건1` | 첫 번째 긍정 조건 입력 | CONDITIONING | 예 | - |
| `조건2` | 첫 번째 긍정 조건과 부정 조건 사이의 기준으로 사용되는 두 번째 조건 입력 | CONDITIONING | 예 | - |
| `부정 조건` | 부정 조건 입력 | CONDITIONING | 예 | - |
| `전체 조건 cfg` | 첫 번째 긍정 조건에 적용되는 안내 스케일(기본값: 8.0) | FLOAT | 예 | 0.0 - 100.0 |
| `(조건2 - 부정 조건) cfg` | 두 번째 조건과 부정 조건 사이에 적용되는 안내 스케일(기본값: 8.0) | FLOAT | 예 | 0.0 - 100.0 |
| `style` | 적용할 안내 스타일(기본값: "regular"). "nested"로 설정하면 안내가 중첩 방식으로 적용됩니다 | COMBO | 예 | "regular"<br />"nested" |

참고: `regular` 스타일에서는 `cfg_cond2_negative`가 `cond2`와 `negative` 사이에 적용되고, `cfg_conds`는 `cond1`과 `cond2` 사이에 적용됩니다. `nested` 스타일에서는 `cfg_conds`가 먼저 `cond1`과 `cond2` 사이에 적용된 후, 결과 예측이 `cfg_cond2_negative`를 사용하여 `negative`로부터 멀어지도록 안내됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `GUIDER` | 샘플링에 사용할 준비가 된 구성된 안내 시스템 | GUIDER |
