Reve Image Create 노드는 Reve AI 모델을 사용하여 텍스트 설명에서 이미지를 생성합니다. 텍스트 프롬프트를 Reve API에 전송하고 생성된 이미지를 반환하며, 종횡비 제어 및 업스케일링, 배경 제거와 같은 선택적 후처리 기능을 제공합니다. 이 노드는 더 이상 사용되지 않습니다(deprecated).

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 생성에 사용할 모델 버전입니다. | DYNAMIC_COMBO | 예 | `"reve-create@20250915"` |
| `프롬프트` | 원하는 이미지의 텍스트 설명입니다. 최대 2560자입니다. | STRING | 예 | 1 ~ 2560 characters |
| `업스케일` | 생성된 이미지를 업스케일합니다. 추가 비용이 발생할 수 있습니다. 기본값: "disabled". | DYNAMIC_COMBO | 아니요 | `"disabled"`<br />`"enabled"` |
| `배경 제거` | 생성된 이미지에서 배경을 제거합니다. 추가 비용이 발생할 수 있습니다. 기본값: False. | BOOLEAN | 아니요 | N/A |
| `시드` | 시드는 노드의 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 0. | INT | 아니요 | 0 ~ 2147483647 |

### reve-create@20250915 입력

`model`이 `"reve-create@20250915"`로 설정된 경우 사용할 수 있는 옵션입니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | 출력 이미지의 종횡비입니다. | COMBO | 예 | `"3:2"`<br />`"16:9"`<br />`"9:16"`<br />`"2:3"`<br />`"4:3"`<br />`"3:4"`<br />`"1:1"` |
| `test_time_scaling` | 값이 높을수록 더 나은 이미지를 생성하지만 더 많은 크레딧을 소비합니다. 기본값: 1. 고급 옵션입니다. | INT | 아니요 | 1 ~ 5 |

### 업스케일 입력

`upscale`이 `"enabled"`로 설정된 경우 사용할 수 있는 옵션입니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `upscale_factor` | 업스케일 배율(2x, 3x 또는 4x)입니다. 기본값: 2. | INT | 아니요 | 2 ~ 4 |

**참고:** `seed` 매개변수는 결정적 출력을 보장하지 않습니다. `upscale` 매개변수는 업스케일링이 후처리 단계로 적용되는지 여부를 제어하며, 추가 비용이 발생할 수 있습니다. `prompt`는 1자에서 2560자 사이여야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `image` | Reve 모델이 입력 프롬프트를 기반으로 생성한 이미지입니다. | IMAGE |
