SaveImage 노드는 입력 이미지를 ComfyUI 출력 디렉터리에 PNG 파일로 저장합니다. 저장된 각 파일에 프롬프트와 같은 워크플로 메타데이터를 포함할 수 있으며, 이미지를 변경하지 않고 반환하므로 다른 노드에서 계속 사용할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `이미지` | 저장할 이미지입니다. | IMAGE | 예 | - |
| `파일명 접두사` | 저장할 파일의 접두사입니다. 노드의 값을 포함하기 위해 `%date:yyyy-MM-dd%` 또는 `%Empty Latent Image.width%`와 같은 형식 정보를 포함할 수 있습니다 (기본값: "ComfyUI"). | STRING | 예 | - |

이 노드는 또한 두 개의 숨겨진 입력 `prompt`와 `extra_pnginfo`를 받으며, 이러한 입력은 ComfyUI에 의해 워크플로 프롬프트와 추가 PNG 정보로 자동 채워집니다. 메타데이터가 활성화된 경우, 이 정보는 저장된 각 PNG 파일에 텍스트 메타데이터로 포함됩니다.

저장된 각 이미지의 파일 이름은 `filename_prefix`, 배치 내 이미지 위치로 대체되는 선택적 `%batch_num%` 자리 표시자, 그리고 다섯 자리 카운터로 구성됩니다. 예: `ComfyUI_00001_.png`. 이미지는 PNG 압축 수준 4로 기록됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `images` | 원본 입력 이미지이며, 디스크에 저장된 후 변경되지 않고 반환됩니다. | IMAGE |
| `ui` | 프런트엔드에 표시하기 위해 저장된 이미지 파일 목록(파일 이름, 하위 폴더, 유형)을 포함하는 UI 전용 결과입니다. | UI_RESULT |
