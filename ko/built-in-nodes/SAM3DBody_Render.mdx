선택 가능한 스타일을 사용하여 3D 신체 포즈 데이터를 이미지로 렌더링합니다. 이 노드는 SAM3D 신체 추적기(MHR) 또는 Kimodo와 같은 외부 Y-up 리그로부터 포즈 데이터를 받아들이며, 결과를 선택적 배경 이미지 위에 합성할 수 있습니다(제공되지 않은 경우 검은 캔버스 위에 합성합니다). 사용 가능한 렌더 스타일에는 셰이딩된 3D 메시, 이진 실루엣, 2D 및 3D OpenPose 스타일 골격, SCAIL 스타일 신체 캡슐이 포함됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `render_style` | 렌더 모드입니다. 'mesh' = 카메라를 통해 래스터화된 3D MHR 메시입니다. 'silhouette' = 메시의 이진 마스크입니다. 'openpose_2d' = 평면 2D 골격입니다. 'openpose_3d' = 플랫 셰이딩된 3D 모델로 표현한 OpenPose 골격입니다. 'scail' = SCAIL 3D 캡슐입니다. (기본값: "mesh") | DYNAMIC_COMBO | 예 | "mesh"<br />"silhouette"<br />"openpose_2d"<br />"openpose_3d"<br />"scail" |
| `pose_data` | MHR 포즈 데이터 또는 외부 Y-up 리그 포즈 데이터(KimodoSample)입니다. 모든 렌더 스타일은 `_skeleton_override`에 OpenPose 관절 맵을 포함하는 외부 리그에서 작동합니다(KimodoSample이 그렇습니다). | MHR_POSE_DATA or KIMODO_POSE_DATA | 예 | — |
| `배경` | 프레임별 배경입니다. 생략하면 검은 캔버스입니다. | IMAGE | 아니오 | — |
| `너비` | 출력 너비(픽셀)입니다. 0 = 포즈 데이터의 기본 image_size를 사용합니다. width/height 중 하나만 설정된 경우 다른 하나는 원본 종횡비를 유지하며 파생됩니다. (기본값: 0) | INT | 아니오 | 0~16384, 간격 8 |
| `높이` | 출력 높이(픽셀)입니다. 0 = 포즈 데이터의 기본 image_size를 사용합니다. width/height 중 하나만 설정된 경우 다른 하나는 원본 종횡비를 유지하며 파생됩니다. (기본값: 0) | INT | 아니오 | 0~16384, 간격 8 |
| `camera_info` | 자유 6DOF 카메라 오버라이드입니다. 연결되면 예측된 카메라 대신 이 카메라(position/target/zoom/rotation/FoV)를 통해 포즈가 다시 투영됩니다. | LOAD_3D_CAMERA | 아니오 | — |

### 메시 입력

이 매개변수들은 `render_style`이 "mesh"일 때 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `shader` | 프리셋 셰이더입니다. 'normals' = 카메라 공간에서의 현재 표면 노멀입니다(OpenGL Y+ 노멀 맵 규칙: +X→R, +Y→G, +Z→B). 'rainbow' = RealisDance 스타일 body-Y jet입니다. 'rainbow_face_*' 변형은 얼굴 버텍스를 노멀/영역별 색상으로 덮어씁니다. 'depth' = 선형 회색입니다. (기본값: "default") | DYNAMIC_COMBO | 아니오 | "default"<br />"normals"<br />"rainbow"<br />"rainbow_face_normal"<br />"rainbow_face_semantic"<br />"depth" |
| `rainbow_tilt_z` | 무지개 jet 축을 Z(앞쪽)를 중심으로 회전합니다. 좌/우를 구분합니다. `shader`가 "rainbow", "rainbow_face_normal" 또는 "rainbow_face_semantic"일 때만 사용할 수 있습니다. (기본값: -35.0) | FLOAT | 아니오 | -90.0~90.0, 간격 0.5 |
| `rainbow_tilt_x` | 무지개 jet 축을 X(오른쪽)를 중심으로 회전합니다. 앞/뒤를 구분합니다. `shader`가 "rainbow", "rainbow_face_normal" 또는 "rainbow_face_semantic"일 때만 사용할 수 있습니다. (기본값: 0.0) | FLOAT | 아니오 | -90.0~90.0, 간격 0.5 |
| `opacity` | 배경 이미지 위 또는 연결된 배경이 없을 때 검은색 위에 적용되는 메시 알파입니다. (기본값: 1.0) | FLOAT | 아니오 | 0.0~1.0, 간격 0.01 |
| `person_palette_falloff` | 사람별 흰색 방향 채도 감소입니다. 트랙 k는 (1 - falloff^k) 파스텔 혼합을 받습니다(SCAIL 'softer second person'). 1.0 = 끔. (기본값: 0.6) | FLOAT | 아니오 | 0.1~1.0, 간격 0.05 |
| `region` | 'hands_only'는 미리 계산된 `hand_vert_mask`(표준 손 KP에 대한 LBS 가중치)를 통해 면을 필터링하여 디버깅을 위해 손 메시를 분리합니다. 마스크가 없으면 전체 메시로 대체됩니다. (기본값: "full_body") | COMBO | 아니오 | "full_body"<br />"hands_only" |

### 실루엣 입력

`render_style`이 "silhouette"일 때 이 노드는 3D 메시의 이진 마스크를 렌더링합니다. 이 모드에는 추가 매개변수가 없습니다.

### OpenPose 2D 입력

이 매개변수들은 `render_style`이 "openpose_2d"일 때 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `marker_radius_px` | 신체 키포인트 점 반지름(px)입니다. (기본값: 4) | INT | 아니오 | 1~32, 간격 1 |
| `stick_width_px` | 신체 사지 타원의 절반 너비(px)입니다. DWPose 기본값 = 4. (기본값: 4) | INT | 아니오 | 1~32, 간격 1 |
| `limb_alpha` | 사지별 알파입니다. DWPose 기본값 = 0.6. (기본값: 0.6) | FLOAT | 아니오 | 0.0~1.0, 간격 0.05 |
| `face_style` | 'full' = 모든 얼굴 랜드마크입니다(있으면 sapiens-238, 그렇지 않으면 리그 폴백 약 30개). 'eyes_mouth' = 리그 폴백 하위 집합입니다(약 12개 점: 눈 + 바깥 입술만). 'disabled' = 얼굴 점 없음. (기본값: "disabled") | COMBO | 아니오 | "disabled"<br />"full"<br />"eyes_mouth" |
| `hand_style` | 21+21 손 키포인트 + 스틱을 그립니다. 'disabled' = 손 없음. 'dwpose' = 단색 파란색 점, 'openpose' = 무지개 점. (기본값: "disabled") | COMBO | 아니오 | "disabled"<br />"dwpose"<br />"openpose" |
| `person_palette_falloff` | 사람별 채도 감소입니다. 트랙 k는 1 - falloff^k만큼 흰색으로 혼합됩니다. 트랙 0은 선명하게 유지되며, 1.0은 감소를 비활성화합니다. (기본값: 0.6) | FLOAT | 아니오 | 0.1~1.0, 간격 0.05 |

### OpenPose 3D 입력

이 매개변수들은 `render_style`이 "openpose_3d"일 때 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |

| `person_palette_falloff` | 사람별 채도 감소입니다. 트랙 k는 1 - falloff^k만큼 흰색으로 혼합됩니다. 트랙 0은 선명하게 유지되며, 1.0은 감소를 비활성화합니다. (기본값: 0.6) | FLOAT | 아니오 | 0.1~1.0, 간격 0.05 |

이 매개변수들은 `render_style`이 "scail"일 때 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|

| `face_style` | 'full' = 모든 얼굴 랜드마크입니다(있으면 sapiens-238, 그렇지 않으면 리그 폴백 약 30개). 'eyes_mouth' = 리그 폴백 하위 집합입니다(약 12개 점: 눈 + 바깥 입술만). 'disabled' = 얼굴 점 없음. (기본값: "disabled") | COMBO | 아니오 | "disabled"<br />"full"<br />"eyes_mouth" |
| `person_palette_falloff` | 사람별 채도 감소입니다. 트랙 k는 1 - falloff^k만큼 흰색으로 혼합됩니다. 트랙 0은 선명하게 유지되며, 1.0은 감소를 비활성화합니다. (기본값: 0.6) | FLOAT | 아니오 | 0.1~1.0, 간격 0.05 |

### 참고 사항

- `width`와 `height`가 모두 0이면 출력은 포즈 데이터의 기본 이미지 크기를 사용합니다. 둘 중 하나만 설정된 경우 다른 하나는 원본 종횡비를 유지하며 파생됩니다. 연결된 `background`는 렌더 해상도에 맞게 크기가 조정됩니다.
- `camera_info`가 연결되면 예측된 카메라 대신 해당 카메라를 통해 포즈가 다시 투영됩니다.
- 메시 모드에서 `rainbow_tilt_z`와 `rainbow_tilt_x`는 `shader`가 "rainbow", "rainbow_face_normal" 또는 "rainbow_face_semantic"으로 설정된 경우에만 사용할 수 있습니다.
- 메시 모드에서 `region`이 "hands_only"일 때 손 영역 필터는 포즈 데이터에 손 버텍스 마스크가 포함되어 있어야 합니다. 마스크가 없으면 대신 전체 메시가 렌더링됩니다.
- scail 모드에서 손은 3D 캡슐이 아니라 3D 캡슐 신체 위에 2D OpenPose 오버레이로 그려집니다. `hand_style`을 "disabled"로 설정하면 손이 완전히 제거됩니다.
- 출력 해상도가 포즈 데이터의 기본 해상도와 다르면 openpose_2d 마커 및 스틱 크기가 비례하여 조정됩니다.
- 배경의 프레임 수가 포즈 데이터보다 적으면 마지막 배경 프레임이 나머지 프레임에 재사용됩니다.
- 출력에는 입력 포즈 프레임마다 한 프레임이 포함됩니다. 포즈 데이터에 프레임이 없으면 단일 검은색 이미지가 반환됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 렌더링된 프레임입니다. 선택한 렌더 스타일로 그린 포즈 데이터이며, 배경이 연결된 경우 배경 위에, 그렇지 않으면 검은색 위에 합성됩니다. 입력 포즈 프레임마다 한 프레임이며, 단일 배치 이미지로 반환됩니다. | IMAGE |
