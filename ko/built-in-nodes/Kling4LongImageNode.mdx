Kling 4.0으로 세로로 긴 이미지 한 장을 생성합니다. 전체 웹페이지 디자인 또는 이커머스 제품 상세 페이지를 만들 수 있습니다. 원하는 레이아웃에 맞는 `skill`을 선택하면 노드가 해당 레이아웃의 입력을 표시합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `skill` | 생성할 레이아웃입니다. `"webpage"`는 선택적 스타일 이미지와 피사체를 중심으로 전체 페이지를 디자인하고, `"ecommerce"`는 제품 사진으로 제품 상세 페이지를 구성합니다. | DYNAMIC_COMBO | 예 | `"webpage"`<br />`"ecommerce"` |

### `webpage` 입력

`skill`이 `"webpage"`로 설정된 경우 이 입력들이 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `style_image` | 시각적 스타일과 레이아웃을 위한 선택적 참조입니다. 프롬프트에서 `@Image1`로 참조하세요. | IMAGE | 아니요 | 단일 이미지 |
| `subject_image` | 유지하고 페이지 디자인의 중심으로 삼을 선택적 피사체입니다. 프롬프트에서 `@Image2`로 참조하세요. | IMAGE | 아니요 | 단일 이미지 |
| `prompt` | 페이지에 대한 선택적 설명입니다. 스타일 이미지는 `@Image1`, 피사체 이미지는 `@Image2`로 참조하고, 페이지 텍스트의 언어를 명시하세요. 예: "All visible text must be in English only." 기본값: 빈 문자열. | STRING | 예 | 여러 줄 텍스트 |
| `resolution` | 출력 이미지의 해상도입니다. 기본값: `"1K"`. | COMBO | 예 | `"1K"`<br />`"2K"` |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |

### `ecommerce` 입력

`skill`이 `"ecommerce"`로 설정된 경우 이 입력들이 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `product_images` | 제품 사진을 위한 확장 가능한 슬롯입니다(`image_1` ... `image_3`). 프롬프트에서 `@Image1`, `@Image2`, `@Image3`로 참조하세요. | AUTOGROW | 예 | 1~3개 이미지 |
| `prompt` | 페이지에 대한 선택적 설명입니다. 제품 이미지는 `@Image1`, `@Image2`, `@Image3`로 참조하세요. 기본값: 빈 문자열. | STRING | 예 | 여러 줄 텍스트 |
| `length` | 생성되는 페이지의 길이입니다. 기본값: `"medium"`. | COMBO | 예 | `"short"`<br />`"medium"`<br />`"long"` |
| `resolution` | 출력 이미지의 해상도입니다. 기본값: `"1K"`. | COMBO | 예 | `"1K"`<br />`"2K"` |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |

**제약 사항 및 동작:**

* `ecommerce`에서는 최대 3개의 제품 이미지를 연결할 수 있습니다.
* 모든 이미지는 최소 300x300픽셀이어야 하며, 종횡비는 2:5에서 5:2 사이여야 합니다.
* `webpage`의 경우, 프롬프트에서 `@Image1` 또는 `@Image2`를 언급했는데 해당 이미지가 연결되어 있지 않으면 오류가 발생합니다.
* 호출 가격은 `skill`, 해상도, 그리고 `ecommerce`의 경우 페이지 길이에 따라 달라집니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 작업이 완료되면 Kling에서 다운로드되는 생성된 세로로 긴 이미지입니다. | IMAGE |
