`CLIPMergeSimple`는 두 개의 CLIP 텍스트 인코더 모델을 지정된 비율에 따라 결합하는 모델 병합 노드입니다. 첫 번째 CLIP 모델을 복제한 후, position ID와 logit scale 구성 요소를 제외한 두 번째 CLIP 모델의 가중치 패치를 적용하여 두 소스의 특징을 혼합한 하이브리드 모델을 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `CLIP1` | 병합할 첫 번째 CLIP 모델입니다. 병합 과정에서 기본 모델 역할을 합니다. | CLIP | 예 | - |
| `CLIP2` | 병합할 두 번째 CLIP 모델입니다. position ID와 logit scale을 제외한 핵심 패치가 지정된 비율에 따라 첫 번째 모델에 적용됩니다. | CLIP | 예 | - |
| `비율` | 두 번째 모델의 특징을 첫 번째 모델에 혼합할 비율을 결정합니다. 비율이 1.0이면 두 번째 모델의 특징을 완전히 채택하고, 0.0이면 첫 번째 모델의 특징만 유지합니다. 기본값: 1.0. | FLOAT | 예 | 0.0 - 1.0 (step: 0.01) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `clip` | 지정된 비율에 따라 두 입력 모델의 특징을 통합한 결과 병합 CLIP 모델입니다. | CLIP |

## 병합 메커니즘 설명

### 병합 알고리즘

이 노드는 가중 평균 방식으로 두 모델을 병합합니다.

1. **기본 모델 복제**: 먼저 `clip1`을 기본 모델로 복제합니다.
2. **패치 획득**: `clip2`에서 모든 키 패치를 가져옵니다.
3. **특수 키 필터링**: `.position_ids` 및 `.logit_scale`로 끝나는 키를 건너뜁니다.
4. **가중 평균 병합 적용**: `(1.0 - ratio) * clip1 + ratio * clip2` 공식을 사용합니다.

### 비율 매개변수 설명

- **ratio = 0.0**: `clip1`만 완전히 사용하고 `clip2`는 무시합니다.
- **ratio = 0.5**: 각 모델에서 50%씩 기여합니다.
- **ratio = 1.0**: `clip2`만 완전히 사용하고 `clip1`은 무시합니다.

## 사용 사례

1. **모델 스타일 융합**: 서로 다른 데이터로 학습된 CLIP 모델의 특성을 결합합니다.
2. **성능 최적화**: 여러 모델의 장단점을 균형 있게 조정합니다.
3. **실험 연구**: 다양한 CLIP 인코더의 조합을 탐색합니다.
