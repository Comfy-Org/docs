이 노드는 여러 키프레임 간 전환을 생성하여 비디오를 만듭니다. 초기 이미지에서 시작하여 사용자가 정의한 일련의 종료 이미지와 프롬프트를 통해 애니메이션을 생성하고, 최종적으로 하나의 비디오 파일을 출력합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용할 Vidu 모델입니다. | COMBO | 예 | "viduq2-pro"<br />"viduq2-turbo" |
| `start_image` | 시작 프레임 이미지입니다. 종횡비는 1:4에서 4:1 사이여야 합니다. | IMAGE | 예 | 종횡비 1:4 ~ 4:1 |
| `seed` | 재현 가능한 결과를 보장하기 위한 난수 생성 시드 값입니다 (기본값: 1). | INT | 예 | 0 ~ 2147483647 |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | "720p"<br />"1080p" |
| `frames` | 키프레임 전환 수입니다 (2-9). 값을 선택하면 해당 프레임에 필요한 입력이 동적으로 표시됩니다. | DYNAMIC_COMBO | 예 | "2"<br />"3"<br />"4"<br />"5"<br />"6"<br />"7"<br />"8"<br />"9" |

### 프레임 입력 (모든 프레임 수 옵션에 공통)

`frames`에 숫자를 설정하면 1부터 해당 숫자까지 각 프레임 `i`에 대해 다음 세 가지 입력이 표시됩니다. 예를 들어, "3"을 선택하면 `prompt1` / `end_image1` / `duration1`, `prompt2` / `end_image2` / `duration2`, `prompt3` / `end_image3` / `duration3`이 추가됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt{i}` | 프레임 &#123;i&#125; 전환을 위한 텍스트 프롬프트입니다. 여러 줄 텍스트 필드입니다. 최대 2000자입니다. | STRING | 예 | 최대 2000자 |
| `end_image{i}` | 세그먼트 &#123;i&#125;의 끝 프레임 이미지입니다. 종횡비는 1:4에서 4:1 사이여야 합니다. | IMAGE | 예 | 종횡비 1:4 ~ 4:1 |
| `duration{i}` | 세그먼트 &#123;i&#125;의 지속 시간(초)입니다 (기본값: 4). | INT | 예 | 2 ~ 7 |

**참고:**

- 모든 입력은 필수입니다. `seed`에는 기본값이 있지만 여전히 필수 입력입니다.
- `start_image`와 모든 `end_image{i}`의 종횡비는 1:4에서 4:1 사이여야 합니다.
- 모든 `prompt{i}`의 최대 길이는 2000자입니다.
- 모든 `duration{i}`는 2초에서 7초 사이여야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오 파일로, 모든 애니메이션 전환이 포함됩니다. | VIDEO |
