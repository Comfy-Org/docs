Google Gemini Omni (Video)는 Google의 Gemini Omni Flash 모델을 사용하여 텍스트 프롬프트에서 오디오가 포함된 비디오를 생성합니다. 선택적으로 참조 이미지 및/또는 비디오를 첨부하여 결과를 안내하거나 기존 푸티지를 편집할 수 있습니다. 원하는 길이(3-10초)를 프롬프트에 직접 명시하세요.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용되는 Gemini 비디오 모델입니다. | DYNAMIC_COMBO | 예 | "Omni Flash 1.1"<br />"Omni Flash" |

### Omni Flash 1.1 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성할 비디오 또는 첨부된 비디오에 적용할 편집을 설명합니다. 길이는 프롬프트에 직접 지정합니다(예: "6초 클립" 또는 'extend' 작업의 경우 "5초 연장"). 생성 길이는 3~10초일 수 있으며 기본값은 10초입니다. 출력에는 오디오가 포함됩니다. (기본값: "") | STRING | 예 | - |
| `resolution` | 출력 해상도입니다. (기본값: "720p") | COMBO | 예 | "360p"<br />"720p"<br />"1080p"<br />"4k" |
| `aspect_ratio` | 출력 화면 비율입니다: 16:9(가로) 또는 9:16(세로). 'edit' 및 'extend' 작업은 대신 입력 비디오의 화면 비율을 유지합니다. (기본값: "16:9") | COMBO | 예 | "16:9"<br />"9:16" |
| `task_type` | 프롬프트와 첨부된 미디어로 수행할 작업입니다. 'auto'를 사용하면 모델이 결정합니다. 'text_to_video'는 프롬프트만으로 생성하며 첨부된 미디어를 거부합니다. 'image_to_video'는 이미지 하나를 애니메이션화하거나, 이미지가 두 개 첨부된 경우 시작 프레임에서 끝 프레임으로 보간합니다. 'reference_to_video'는 첨부된 미디어를 피사체 참조로 취급합니다. 'edit'는 정확히 하나의 첨부된 비디오를 다시 쓰고, 'extend'는 그 비디오에 새 푸티지를 추가하므로 출력은 입력 비디오로 시작됩니다. (기본값: "auto") | COMBO | 예 | "auto"<br />"text_to_video"<br />"image_to_video"<br />"reference_to_video"<br />"edit"<br />"extend" |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. (기본값: 42) | INT | 예 | 0~2147483647 |

### Omni Flash 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성할 비디오 또는 첨부된 비디오에 적용할 편집을 설명합니다. 길이는 프롬프트에 직접 지정합니다(예: "6초 클립"). 길이는 3~10초일 수 있습니다. 출력은 720p, 24FPS, 오디오 포함입니다. (기본값: "") | STRING | 예 | - |
| `aspect_ratio` | 출력 화면 비율입니다: 16:9(가로) 또는 9:16(세로). 'edit' 작업은 대신 입력 비디오의 화면 비율을 유지합니다. (기본값: "16:9") | COMBO | 예 | "16:9"<br />"9:16" |
| `task_type` | 프롬프트와 첨부된 미디어로 수행할 작업입니다. 'auto'를 사용하면 모델이 결정합니다. 'text_to_video'는 프롬프트만으로 생성하며 첨부된 미디어를 거부합니다. 'image_to_video'는 이미지 하나를 애니메이션화하거나, 이미지가 두 개 첨부된 경우 시작 프레임에서 끝 프레임으로 보간합니다. 'reference_to_video'는 첨부된 미디어를 피사체 참조로 취급합니다. 'edit'는 정확히 하나의 첨부된 비디오를 다시 씁니다. (기본값: "auto") | COMBO | 예 | "auto"<br />"text_to_video"<br />"image_to_video"<br />"reference_to_video"<br />"edit" |
| `temperature` | 무작위성을 제어합니다. 값이 낮을수록 더 집중적이고 결정적이며, 높을수록 더 다양해집니다. (기본값: 1.0) | FLOAT | 예 | 0.0~2.0 (단계 0.01) |
| `top_p` | 핵 샘플링: 누적 확률이 top_p에 도달하는 가장 작은 토큰 집합에서 샘플링합니다. (기본값: 0.95) | FLOAT | 예 | 0.0~1.0 (단계 0.01) |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. (기본값: 42) | INT | 예 | 0~2147483647 |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 확장 가능한 슬롯: 최대 14개의 이미지(`image_1`...`image_14`)를 연결할 수 있습니다. 비디오를 안내하거나 애니메이션화하는 선택적 참조 이미지입니다. 'image_to_video' 작업에서는 첫 번째 이미지가 시작 프레임이고, 선택적으로 두 번째 이미지가 끝 프레임입니다. | IMAGE | 아니요 | 이미지 0~14개 |
| `videos` | 확장 가능한 슬롯: 최대 3개의 비디오(`video_1`...`video_3`)를 연결할 수 있습니다. 안내하거나 편집할 선택적 참조 비디오입니다. 각 비디오는 최대 10초 길이입니다. | VIDEO | 아니요 | 비디오 0~3개 |

**참고 사항:**
- `prompt`는 비어 있으면 안 됩니다. 비어 있으면 노드에서 오류가 발생합니다.
- `text_to_video` 작업은 프롬프트만으로 생성하며, 이미지나 비디오를 첨부하면 오류가 발생합니다.
- `image_to_video` 작업은 이미지만 허용하며(비디오 없음) 정확히 1개 또는 2개의 이미지가 필요합니다. 첫 번째 이미지는 시작 프레임이고 선택적으로 두 번째 이미지는 끝 프레임입니다.
- `edit` 작업(두 모델 모두)과 `extend` 작업(Omni Flash 1.1 전용)은 정확히 하나의 입력 비디오가 필요하며 해당 입력 비디오의 화면 비율을 유지하여 `aspect_ratio`를 재정의합니다.
- 최대 14개의 이미지와 3개의 비디오를 첨부할 수 있으며, 첨부된 각 비디오는 10초 이하여야 합니다.
- Omni Flash는 항상 오디오가 포함된 720p 24FPS 비디오를 출력합니다. 해상도 선택은 Omni Flash 1.1에서만 사용할 수 있습니다.
- `temperature` 및 `top_p` 컨트롤은 Omni Flash 모델에서만 사용할 수 있습니다. Omni Flash 1.1은 고정된 생성 설정을 사용합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` (첫 번째 출력) | 오디오가 포함된 생성된 비디오입니다. Omni Flash: 720p, 24FPS. Omni Flash 1.1: `resolution` 입력에서 선택한 해상도입니다. | VIDEO |
| `text` (두 번째 출력) | 모델이 비디오와 함께 생성한 텍스트 콘텐츠입니다(비어 있을 수 있음). | STRING |
