이 노드는 샘플링 중 LTXV 유사 모델의 컨텍스트 윈도우를 설정합니다. 생성을 중첩 윈도우로 분할하여 메모리 사용량을 관리하고 시간적 일관성을 향상하는 데 도움을 줍니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 샘플링 중 컨텍스트 윈도우를 적용할 모델입니다. | MODEL | 예 | - |
| `context_length` | 실제 프레임 단위의 컨텍스트 윈도우 길이입니다. 8*n + 1 형식이어야 합니다. (기본값: 145) | INT | 예 | 최소: 1<br />최대: nodes.MAX_RESOLUTION<br />단계: 8 |
| `context_overlap` | 실제 프레임 단위의 컨텍스트 윈도우 겹침입니다. (기본값: 40) | INT | 예 | 최소: 0<br />단계: 8 |
| `context_schedule` | 컨텍스트 윈도우에 대한 단계 의존적 스케줄링 알고리즘입니다. (기본값: "UNIFORM_STANDARD") | COMBO | 예 | `"STATIC_STANDARD"`<br />`"UNIFORM_STANDARD"`<br />`"UNIFORM_LOOPED"`<br />`"BATCHED"` |
| `context_stride` | 컨텍스트 윈도우의 스트라이드입니다. 균일 스케줄에만 적용됩니다. (기본값: 1) | INT | 예 | 최소: 1 |
| `closed_loop` | 컨텍스트 윈도우 루프를 닫을지 여부입니다. 루프 스케줄에만 적용됩니다. (기본값: False) | BOOLEAN | 예 | True<br />False |
| `fuse_method` | 컨텍스트 윈도우를 융합하는 데 사용할 방법입니다. 사용 가능한 옵션은 `ContextFuseMethods.LIST_STATIC`에 정의되어 있습니다. (기본값: "PYRAMID") | COMBO | 예 | `ContextFuseMethods.LIST_STATIC`에 정의됨 |
| `freenoise` | FreeNoise 노이즈 셔플링을 적용할지 여부입니다. 윈도우 블렌딩을 향상합니다. (기본값: True) | BOOLEAN | 예 | True<br />False |
| `retain_first_frame` | 모든 컨텍스트 윈도우에서 첫 번째 잠재 프레임을 유지합니다. (초기 참조를 유지하는 데 도움이 될 수 있습니다.) (기본값: False) | BOOLEAN | 예 | True<br />False |
| `split_conds_to_windows` | 여러 컨디셔닝(ConditionCombine으로 생성됨)을 영역 인덱스에 따라 각 윈도우로 분할할지 여부입니다. (기본값: False) | BOOLEAN | 예 | True<br />False |

**참고:** `context_length` 값은 실제 프레임 단위로 제공되며 내부적으로 `((context_length - 1) // 8) + 1` 공식을 사용하여 잠재 프레임으로 변환되며, 최솟값은 1입니다. `context_overlap` 값도 실제 프레임 단위로 제공되며 8로 정수 나눗셈하여 잠재 프레임으로 변환되며, 최솟값은 0입니다. `context_length`의 툴팁은 8*n + 1 패턴을 따라야 함을 나타냅니다.
