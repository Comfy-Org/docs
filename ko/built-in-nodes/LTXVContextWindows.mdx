이 노드는 샘플링 중 LTXV 계열 모델에 컨텍스트 창을 설정합니다. 비디오 생성 과정을 겹치는 창으로 분할하여 메모리 사용량을 관리하고 시간적 일관성을 향상시킵니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 샘플링 중 컨텍스트 창을 적용할 모델입니다. | MODEL | 예 | - |
| `context_length` | 실제 프레임 기준 컨텍스트 창의 길이입니다. 반드시 8*n + 1 형식이어야 합니다. (기본값: 145) | INT | 예 | 최소: 1<br />최대: nodes.MAX_RESOLUTION<br />단계: 8 |
| `context_overlap` | 실제 프레임 기준 컨텍스트 창의 겹침 영역입니다. (기본값: 40) | INT | 예 | 최소: 0<br />단계: 8 |
| `context_schedule` | 컨텍스트 창에 대한 단계 종속 스케줄링 알고리즘입니다. (기본값: UNIFORM_STANDARD) | COMBO | 예 | `STATIC_STANDARD`<br />`UNIFORM_STANDARD`<br />`UNIFORM_LOOPED`<br />`BATCHED` |
| `context_stride` | 컨텍스트 창의 보폭(stride)입니다. 균등(uniform) 스케줄에만 적용됩니다. (기본값: 1) | INT | 아니요 | 최소: 1 |
| `closed_loop` | 컨텍스트 창 루프를 닫을지 여부입니다. 루프(looped) 스케줄에만 적용됩니다. (기본값: False) | BOOLEAN | 아니요 | True<br />False |
| `fuse_method` | 컨텍스트 창을 융합하는 방법입니다. (기본값: PYRAMID) | COMBO | 예 | comfy.context_windows.ContextFuseMethods.LIST_STATIC의 옵션 |
| `freenoise` | FreeNoise 노이즈 셔플링 적용 여부입니다. 창 혼합 품질을 개선합니다. (기본값: True) | BOOLEAN | 아니요 | True<br />False |
| `retain_first_frame` | 모든 컨텍스트 창에서 첫 번째 잠재 프레임을 유지할지 여부입니다. 초기 참조를 유지하는 데 도움이 될 수 있습니다. (기본값: False) | BOOLEAN | 아니요 | True<br />False |
| `split_conds_to_windows` | ConditionCombine으로 생성된 여러 컨디셔닝을 지역 인덱스에 따라 각 창으로 분할할지 여부입니다. (기본값: False) | BOOLEAN | 아니요 | True<br />False |

**참고:** `context_length` 매개변수는 반드시 8*n + 1 공식을 따라야 하며, 여기서 n은 양의 정수입니다. 이 노드는 실제 프레임을 잠재 프레임으로 변환하여 이 요구 사항을 충족하도록 값을 자동으로 조정합니다. `context_overlap` 역시 실제 프레임에서 잠재 프레임으로 변환됩니다(8로 나눔).

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `MODEL` | 샘플링을 위해 컨텍스트 창이 적용된 모델입니다. | MODEL |
