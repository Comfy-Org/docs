SVG 파일을 디스크에 저장합니다. 이 노드는 SVG 데이터를 입력으로 받아 ComfyUI 출력 디렉터리에 기록하며, 카운터 접미사를 사용한 파일 이름 지정을 자동으로 처리합니다. 워크플로 프롬프트 정보를 사용할 수 있는 경우, 해당 정보는 SVG 파일에 메타데이터 요소로 직접 포함됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `SVG` | 디스크에 저장할 SVG 데이터 | SVG | 예 | - |
| `파일명 접두사` | 저장할 파일의 접두사입니다. 이는 %date:yyyy-MM-dd% 또는 %Empty Latent Image.width%와 같은 형식 정보를 포함하여 노드의 값을 파일 이름에 포함할 수 있습니다. (기본값: "svg/ComfyUI") | STRING | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `svg` | 저장 후 전달되는 원본 SVG 데이터 | SVG |
| `ui` | ComfyUI 인터페이스에 표시하기 위한 파일 이름, 하위 폴더 및 유형을 포함한 저장된 파일 정보 | DICT |

**참고:** 이 노드는 사용 가능한 경우 워크플로 메타데이터(프롬프트 및 추가 PNG 정보)를 SVG 파일에 자동으로 포함합니다. 메타데이터는 SVG의 metadata 요소 내 CDATA 섹션으로 삽입됩니다. 파일은 `filename_prefix_00001_.svg` 패턴을 사용하여 저장됩니다. 배치를 처리할 때 접두사의 `%batch_num%`는 현재 배치 항목의 인덱스로 대체됩니다. 이 노드는 출력 노드이므로 파일 자체가 이미지 미리보기로 표시되지는 않지만 출력 폴더에 저장된 결과를 생성합니다.
