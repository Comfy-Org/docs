PixVerse V6 첫 번째 프레임-마지막 프레임 비디오 생성(First-Last-Frame to Video)은 PixVerse를 사용하여 첫 번째 프레임에서 마지막 프레임으로 전환되는 비디오를 생성하며, 선택적으로 네이티브 오디오를 포함합니다. 제공된 두 이미지는 PixVerse API로 전송되어 전환 비디오를 생성하고 비디오 파일로 반환합니다. 출력 비디오는 첫 번째 프레임의 종횡비를 유지합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 비디오의 시작 이미지입니다. | IMAGE | 예 | — |
| `last_frame` | 비디오의 끝 이미지입니다. | IMAGE | 예 | — |
| `model` | 모델 및 생성 설정입니다. PixVerse 모델을 선택하고 해당 모델의 생성 매개변수를 표시합니다. | DYNAMIC_COMBO | 예 | "PixVerse V6" |

### PixVerse V6 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 전환을 설명하는 프롬프트입니다. | STRING | 예 | 최대 5000자 |
| `quality` | 출력 해상도입니다. 긴 변을 설정합니다: 360p는 640px, 540p는 1024px, 720p는 1280px, 1080p는 1920px입니다. (기본값: 720p) | COMBO | 예 | "360p"<br />"540p"<br />"720p"<br />"1080p" |
| `duration_seconds` | 생성된 비디오의 길이(초)입니다. (기본값: 5) | INT | 예 | 1~15 |
| `generate_audio` | 비디오와 함께 네이티브 오디오 트랙을 생성할지 여부입니다. (기본값: true) | BOOLEAN | 예 | true<br />false |
| `seed` | 비디오 생성에 사용되는 시드입니다. PixVerse는 이를 기록하지만 해당 시드로 실행을 재현하지는 않습니다. (기본값: 42) | INT | 예 | 0~2147483647 |
| `negative_prompt` | 비디오에서 원치 않는 요소에 대한 선택적 텍스트 설명입니다. | STRING | 아니오 | 최대 2048자 |
| `style` | 전체 비디오에 적용되는 선택적 비주얼 스타일입니다. (기본값: none) | COMBO | 아니오 | 여러 옵션 사용 가능 (기본값: "none") |

참고: 프롬프트는 공백을 제거한 후 비어 있지 않아야 하며, 5000자로 제한됩니다. 네거티브 프롬프트가 제공될 경우 2048자로 제한됩니다. 지속 시간은 1초에서 15초 사이여야 합니다. 출력 비디오는 첫 번째 프레임의 종횡비를 유지합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 첫 번째 프레임에서 마지막 프레임으로 전환되는 생성된 비디오입니다. `generate_audio`가 활성화된 경우 오디오 트랙도 포함됩니다. | VIDEO |
