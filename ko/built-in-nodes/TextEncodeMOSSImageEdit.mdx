편집 지시와 참조 이미지를 함께 인코딩하여 MOSS-Image 편집 LoRA용 conditioning으로 만듭니다. 출력을 긍정 conditioning으로 연결하고, 같은 참조로 부정용 인스턴스를 한 번 더 실행하세요. 참조는 들어온 크기 그대로 사용되므로 연결 전에 스케일하세요. VAE가 없으면 이미지는 텍스트 인코더로만 갑니다. 이 노드는 ComfyUI에서 실험적으로 표시됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | 지시를 토큰화하고 인코딩하는 CLIP 모델입니다. | CLIP | 예 | - |
| `prompt` | 편집을 설명하는 지시입니다. 여러 줄 텍스트와 동적 프롬프트를 지원합니다. | STRING | 예 | 임의 텍스트 |
| `vae` | 이미지를 편집 LoRA용 참조 latent로 인코딩합니다. 선택: 없으면 이미지는 텍스트 인코더로만 갑니다. | VAE | 아니오 | - |
| `edit_format` | 편집 LoRA가 학습된 레이아웃입니다. 참조 latent 메서드와 텍스트 인코더가 참조도 보는지 여부를 선택합니다. | COMBO | 예 | `"ai-toolkit"`<br />`"ai-toolkit (kv_cache off)"`<br />`"Moss-Image-Edit"` |
| `images` | 확장 가능한 슬롯: 하나 이상의 참조 이미지(`image_1`, `image_2`, ...)를 연결합니다. 각 이미지는 입력된 크기로 사용됩니다. VAE가 연결되면 알파가 제거되고 참조 latent로 인코딩되며, VAE가 없으면 텍스트 인코더로만 갑니다. | IMAGE | 예 | 이미지 1개 이상 |
| `image_strength` | 텍스트 인코더가 보는 이미지에 대한 모델 주의도를 조절합니다(ai-toolkit 형식 또는 VAE 없음): 0은 무시, 1은 그대로, 1 초과는 강조. 고급. 기본값: 1.0. | FLOAT | 예 | 0.0~100.0(단계 0.05) |

**참고:** `"ai-toolkit"`와 `"ai-toolkit (kv_cache off)"`이거나 VAE가 없고 `image_strength`가 0보다 크면 텍스트 인코더도 각 참조를 봅니다(최대 384x384로 축소, 프롬프트에 `Picture N:` 마커). `"Moss-Image-Edit"`에 VAE가 있으면 참조는 참조 latent로만 모델에 들어가고 텍스트 인코더는 지시만 봅니다. `"ai-toolkit (kv_cache off)"`은 참조가 생성 중인 이미지에도 계속 주의를 기울여 매 스텝 재계산됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `conditioning` | 참조 latent와 일치하는 참조 latent 메서드가 붙은 인코딩된 지시입니다. | CONDITIONING |
