SamplerCustomAdvanced 노드는 사용자 지정 노이즈, 가이던스 및 샘플링 구성을 사용하여 고급 잠재 공간 샘플링을 수행합니다. 사용자 지정 가능한 노이즈 생성기와 시그마 스케줄을 사용한 가이드 샘플링 프로세스를 통해 잠재 이미지를 처리하며, 사용 가능한 경우 최종 샘플링된 출력과 노이즈 제거된 버전을 모두 생성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `노이즈` | 샘플링 프로세스의 초기 노이즈 패턴과 시드를 제공하는 노이즈 생성기입니다 | NOISE | 예 | - |
| `가이더` | 샘플링 프로세스를 원하는 출력으로 유도하는 가이던스 모델입니다 | GUIDER | 예 | - |
| `샘플러` | 생성 중 잠재 공간을 탐색하는 방법을 정의하는 샘플링 알고리즘입니다 | SAMPLER | 예 | - |
| `시그마 배열` | 샘플링 단계 전반에 걸쳐 노이즈 수준을 제어하는 시그마 스케줄입니다 | SIGMAS | 예 | - |
| `잠재 데이터` | 샘플링의 시작점 역할을 하는 초기 잠재 표현입니다. 선택적 노이즈 제거를 위한 `noise_mask` 키와 고급 잠재 처리를 위한 선택적 `downscale_ratio_spacial` 및 `downscale_ratio_temporal` 키를 지원합니다 | LATENT | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `output` | 샘플링 프로세스 완료 후 최종 샘플링된 잠재 표현입니다. 입력 잠재의 모든 `downscale_ratio_spacial` 또는 `downscale_ratio_temporal` 키는 이 출력에서 제거됩니다 | LATENT |
| `denoised_output` | 샘플링 프로세스가 중간 클린 예측(x0)을 생성할 때 출력의 노이즈 제거된 버전이며, 그렇지 않으면 `output`과 동일한 값을 반환합니다. 사용 가능한 경우 이는 모델의 클린 잠재에 대한 최선의 추정치를 나타냅니다 | LATENT |
