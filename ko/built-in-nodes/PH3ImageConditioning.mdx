이 노드는 p-h3-image를 사용하여 프롬프트를 조건화(conditioning)와 단일 정지 이미지용 빈 레이턴트로 변환합니다. 이미지를 연결하지 않으면 텍스트 투 이미지로 동작하고, 이미지를 연결하면 `image_1`이 편집 대상 이미지가 되며 나머지 슬롯은 참조 이미지로 사용됩니다. 프롬프트에서는 이 참조 이미지들을 `<Picture 1>`, `<Picture 2>` 등으로 지칭합니다. 샘플러에는 MiniMax H3 sigma shift 노드로 패치된 모델이 필요하며, 두 shift 값은 모두 1.0으로 설정해야 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | 프롬프트(참조 이미지 포함)를 토큰화하고 조건화를 인코딩하는 데 사용되는 p-h3-image CLIP 모델입니다. | CLIP | 예 | - |
| `prompt` | 생성할 내용 또는 `image_1`을 편집하는 방법입니다. 이미지가 연결된 경우 짧은 지시문 앞에는 `Edit <Picture 1>. `가 추가됩니다. 이미 `Edit <Picture`로 시작하는 지시문이나 프롬프트 업샘플러가 생성한 편집 브리프는 작성된 그대로 사용됩니다. | STRING | 예 | - |
| `width` | 픽셀 단위의 출력 너비입니다. 0이면 크기 조정 후의 `image_1` 너비를 사용하고, 이미지가 연결되지 않은 경우 2912를 사용합니다(기본값: 0). | INT | 예 | 0 ~ MAX_RESOLUTION |
| `height` | 픽셀 단위의 출력 높이입니다. 0이면 크기 조정 후의 `image_1` 높이를 사용하고, 이미지가 연결되지 않은 경우 2912를 사용합니다(기본값: 0). | INT | 예 | 0 ~ MAX_RESOLUTION |
| `vae` | p-h3-image VAE입니다. 참조 레이턴트가 이 VAE로 인코딩되므로 이미지 슬롯이 연결되면 즉시 필요합니다. | VAE | 아니요 | - |
| `images` | 최대 9개 이미지(`image_1`부터 `image_9`까지)로 구성된 확장 가능한 그룹입니다. `image_1`은 편집 대상 이미지이고 나머지 슬롯은 참조 이미지입니다. | AUTOGROW | 아니요 | 0~9개 이미지 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `positive` | p-h3-image 샘플러용 조건화입니다. 이미지가 연결된 경우 패킹된 참조 레이턴트도 함께 전달합니다. | CONDITIONING |
| `latent` | 모델이 기대하는 두 개의 오디오 레이턴트를 포함한, 단일 정지 프레임용 빈 레이턴트입니다. | LATENT |

**참고:** 이미지를 사용하려면 `vae` 입력이 필요합니다. VAE 없이 이미지를 연결하여 노드를 실행하면 오류가 발생합니다.

**참고:** 이 조건화는 단일 프레임만 처리합니다. 비디오나 오디오에는 MiniMax H3 비디오 노드를 사용하세요.
