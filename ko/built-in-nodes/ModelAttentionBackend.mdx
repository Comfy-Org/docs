이 노드는 모델이 어텐션 계산에 사용할 어텐션 백엔드를 선택할 수 있게 해줍니다. 선택한 어텐션 함수로 교체한 모델 사본을 생성하며, 이는 성능이나 동작에 영향을 줄 수 있습니다. 선택한 백엔드를 사용할 수 없는 경우 자동으로 PyTorch 어텐션으로 대체하고 경고를 기록합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 선택한 어텐션 백엔드가 적용될 모델입니다. | MODEL | 예 |  |
| `attention` | 사용할 어텐션 백엔드입니다 (기본값: "pytorch attention"). 선택한 백엔드를 사용할 수 없으면 PyTorch 어텐션이 대체로 사용됩니다. | STRING | 예 | "pytorch attention"<br />"comfy kitchen attention" |

참고: "comfy kitchen attention" 옵션은 현재 환경에 comfy kitchen int8 어텐션 모듈이 있는 경우에만 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `MODEL` | 선택한 어텐션 백엔드가 적용된 입력 모델의 복제본입니다. | MODEL |
