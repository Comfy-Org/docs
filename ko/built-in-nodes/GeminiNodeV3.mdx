## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 응답 생성에 사용할 Gemini 모델입니다. 선택한 모델에 따라 표시되는 추가 입력이 결정됩니다. | DYNAMIC_COMBO | 예 | `"Gemini 3.8 Flash"`<br />`"Gemini 3.7 Flash"`<br />`"Gemini 3.5 Flash"`<br />`"Gemini 3.1 Pro"`<br />`"Gemini 3.1 Flash-Lite"` |

### 미디어 입력

이 확장 가능한 미디어 입력은 모든 모델 옵션에서 사용할 수 있습니다.

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 모델의 컨텍스트로 사용할 선택적 이미지입니다. 최대 16개 이미지. 확장 가능한 슬롯: `image_1`부터 `image_16`까지 이미지를 연결합니다. | IMAGE | 아니요 | 최대 16개 이미지 |
| `audio` | 모델의 컨텍스트로 사용할 선택적 오디오 클립입니다. 확장 가능한 슬롯: `audio_1`. | AUDIO | 아니요 | 오디오 클립 1개 |
| `video` | 모델의 컨텍스트로 사용할 선택적 비디오 클립입니다. 확장 가능한 슬롯: `video_1`. | VIDEO | 아니요 | 비디오 클립 1개 |

### Gemini 3.8 Flash 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 모델에 대한 텍스트 입력입니다. 자세한 지침, 질문 또는 컨텍스트를 포함하세요. 비어 있으면 안 됩니다. | STRING | 예 | 여러 줄 텍스트(공백이 아닌 문자를 하나 이상 포함해야 함) |
| `video_processing` | 모델이 첨부된 비디오를 읽는 방식입니다. `static`은 고정된 비율로 프레임을 샘플링하여 모든 프레임을 컨텍스트로 전송합니다. `agentic`은 모델이 타임라인을 스스로 탐색하고 필요한 프레임, 오디오 또는 대본만 로드하게 하므로, 긴 비디오에서 입력 토큰을 훨씬 적게 소비합니다. | COMBO | 예 | `"static"`<br />`"agentic"` (기본값: `"static"`) |
| `files` | 모델의 컨텍스트로 사용할 선택적 파일입니다. Gemini Input Files 노드의 입력을 받습니다. | GEMINI_INPUT_FILES | 아니요 | N/A |
| `thinking_level` | 모델이 답변하기 전에 내부적으로 얼마나 깊이 추론할지 결정합니다. HIGH는 어려운 작업에서 품질을 향상하지만 더 많은 (사고) 토큰을 소비하고 느려집니다. | COMBO | 예 | `"LOW"`<br />`"MEDIUM"`<br />`"HIGH"` (기본값: `"MEDIUM"`) |
| `max_output_tokens` | 모델의 내부 사고를 포함하여 생성할 최대 토큰 수입니다. `thinking_level`이 HIGH일 때 값이 낮으면 답변을 위한 공간이 남지 않을 수 있습니다. 응답이 비어 있거나 잘려서 반환되면 이 값을 높이세요. 모델은 완료되면 일찍 중지하므로, 짧은 답변에서는 상한을 높여도 추가 비용이 발생하지 않습니다. | INT | 예 | 16-65536 (기본값: 32768) |
| `seed` | 샘플링용 시드입니다. 무작위 시드를 사용하려면 0으로 설정합니다. 결정론적 출력은 보장되지 않습니다. | INT | 예 | 0-2147483647 (기본값: 42) |
| `system_prompt` | 모델의 동작을 규정하는 기본 지침입니다. | STRING | 예 | 여러 줄 텍스트 (기본값: 비어 있음) |

참고: Gemini 3.8 Flash에서는 `temperature`와 `top_p`를 사용할 수 없으며, `video_processing`은 이 모델 옵션에서만 사용할 수 있습니다. `thinking_level` 옵션과 기본값은 위에 나열된 모델별로 다릅니다.

참고: `prompt` 입력은 비어 있으면 안 됩니다. 노드는 공백이 아닌 문자를 하나 이상 포함하는지 검증합니다.

참고: 노드는 최대 처음 10개의 미디어 항목을 URL로 업로드하며, 비디오, 오디오, 이미지 순으로 우선순위를 둡니다. 나머지 미디어는 base64로 인라인 전송됩니다. 인라인 미디어의 총 용량은 18MB로 제한되며, 이를 초과하면 노드에서 첨부된 미디어의 수나 크기를 줄이라고 요청하는 오류를 발생시킵니다.
