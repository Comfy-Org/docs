LazyCache는 샘플링 중 캐싱을 추가하여 계산량을 줄이는 EasyCache의 실험적인 자체 제작 버전입니다. ComfyUI의 모델과 범용적으로 호환되도록 설계되었지만, 일반적으로 EasyCache보다 성능이 떨어지며 드문 경우에만 더 나은 결과를 낼 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | LazyCache를 추가할 모델입니다. | MODEL | 예 | - |
| `재사용 임계값` | 캐시된 단계를 재사용하기 위한 임계값입니다. 기본값: 0.2. | FLOAT | 예 | 0.0 - 3.0 (단계: 0.01) |
| `시작 백분율` | LazyCache 사용을 시작할 상대적 샘플링 단계입니다. 기본값: 0.15. | FLOAT | 예 | 0.0 - 1.0 (단계: 0.01) |
| `종료 백분율` | LazyCache 사용을 종료할 상대적 샘플링 단계입니다. 기본값: 0.95. | FLOAT | 예 | 0.0 - 1.0 (단계: 0.01) |
| `상세 정보` | 자세한 정보를 로그로 기록할지 여부입니다. 기본값: False. | BOOLEAN | 예 | - |

참고: `reuse_threshold`, `start_percent`, `end_percent`, `verbose`는 고급 입력으로 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | LazyCache 기능이 추가된 모델입니다. | MODEL |
