제공된 프롬프트를 기반으로 이미지의 배경을 교체합니다. 이 노드는 Recraft API를 사용하여 텍스트 설명에 따라 이미지의 새 배경을 생성하며, 주요 피사체를 그대로 유지하면서 배경을 완전히 변환할 수 있습니다. 입력 배치의 각 이미지는 개별적으로 처리되고, 결과는 단일 출력 배치로 결합됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 처리할 입력 이미지 | IMAGE | 예 | - |
| `프롬프트` | 이미지 생성용 프롬프트 (기본값: 비어 있음) | STRING | 예 | - |
| `개수` | 생성할 이미지 수 (기본값: 1) | INT | 예 | 1-6 |
| `시드` | 노드 재실행 여부를 결정하는 시드입니다. 시드와 관계없이 실제 결과는 비결정적입니다. (기본값: 0) | INT | 예 | 0-18446744073709551615 |
| `recraft 스타일` | 생성된 배경에 대한 선택적 스타일 선택입니다. 제공되지 않으면 "realistic_image" 스타일이 기본값입니다. | STYLEV3 | 아니요 | - |
| `부정 프롬프트` | 이미지에서 원하지 않는 요소에 대한 선택적 텍스트 설명입니다. (기본값: 비어 있음) | STRING | 아니요 | - |

**참고:**
- `seed` 매개변수는 노드가 언제 다시 실행되는지를 제어하지만, 외부 API의 특성상 결정적 결과를 보장하지 않습니다.
- `recraft_style`이 연결되지 않았거나 비어 있으면 노드는 `realistic_image` 스타일로 대체합니다.
- `negative_prompt`가 비어 있으면 요청과 함께 전송되지 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 배경이 교체된 생성 이미지입니다. 각 입력 이미지에 대해 생성되는 결과 수는 `n`에 의해 결정됩니다. | IMAGE |
