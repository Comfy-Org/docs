제공된 프롬프트를 기반으로 이미지의 배경을 교체합니다. 이 노드는 Recraft API를 사용하여 텍스트 설명에 따라 이미지의 새 배경을 생성하므로, 주요 피사체를 유지하면서 배경을 완전히 변환할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 처리할 입력 이미지입니다. | IMAGE | 예 | - |
| `프롬프트` | 이미지 생성을 위한 프롬프트입니다 (기본값: 비어 있음). | STRING | 예 | - |
| `개수` | 생성할 이미지의 수입니다 (기본값: 1). | INT | 예 | 1-6 |
| `시드` | 노드 재실행 여부를 결정하는 시드입니다. 실제 결과는 시드와 무관하게 비결정적입니다 (기본값: 0). | INT | 예 | 0-18446744073709551615 |
| `recraft 스타일` | 생성된 배경에 대한 선택적 스타일 선택입니다. 제공하지 않으면 기본적으로 "realistic_image" 스타일이 사용됩니다. | STYLEV3 | 아니요 | - |
| `부정 프롬프트` | 이미지에서 원하지 않는 요소에 대한 선택적 텍스트 설명입니다 (기본값: 비어 있음). | STRING | 아니요 | - |

**참고:** `seed` 매개변수는 노드가 재실행되는 시점을 제어하지만, 외부 API의 특성상 결정적인 결과를 보장하지는 않습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| IMAGE | 배경이 교체된 생성 이미지입니다. 각 입력 이미지에 대해 생성 결과 수는 `n`에 의해 결정됩니다. | IMAGE |
