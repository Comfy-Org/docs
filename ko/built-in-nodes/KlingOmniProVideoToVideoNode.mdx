이 노드는 Kling AI 모델을 사용하여 입력 비디오와 선택적 참조 이미지를 기반으로 새 비디오를 생성합니다. 원하는 내용을 설명하는 텍스트 프롬프트를 제공하면 노드가 참조 비디오를 그에 맞게 변환합니다. 또한 최대 4개의 추가 참조 이미지를 포함하여 출력의 스타일과 내용을 안내할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_name` | 비디오 생성에 사용할 특정 Kling 모델입니다(기본값: "kling-v3-omni"). | COMBO | 예 | `"kling-v3-omni"`<br />`"kling-video-o1"` |
| `프롬프트` | 비디오 콘텐츠를 설명하는 텍스트 프롬프트입니다. 긍정적 설명과 부정적 설명을 모두 포함할 수 있습니다. | STRING | 예 | N/A |
| `종횡비` | 생성된 비디오의 원하는 종횡비입니다. | COMBO | 예 | `"16:9"`<br />`"9:16"`<br />`"1:1"` |
| `길이` | 생성된 비디오의 길이(초)입니다(기본값: 3). | INT | 예 | 3~10 |
| `참조 비디오` | 참조로 사용할 비디오입니다. | VIDEO | 예 | N/A |
| `원본 사운드 유지` | 참조 비디오의 오디오를 출력에 유지할지 결정합니다(기본값: True). | BOOLEAN | 예 | N/A |
| `참조 이미지` | 최대 4개의 추가 참조 이미지입니다. | IMAGE | 아니요 | N/A |
| `해상도` | 생성된 비디오의 해상도입니다(기본값: "1080p"). | COMBO | 아니요 | `"1080p"`<br />`"720p"` |
| `시드` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다(기본값: 0). | INT | 아니요 | 0~2147483647 |

**매개변수 제약 조건:**

* `prompt`는 1자에서 2500자 사이여야 합니다.
* `reference_video`의 길이는 3.0초에서 10.05초 사이여야 합니다.
* `reference_video`의 크기는 720x720픽셀에서 2160x2160픽셀 사이여야 합니다.
* 최대 4개의 `reference_images`를 제공할 수 있습니다. 각 이미지는 최소 300x300픽셀이어야 하며, 종횡비는 1:2.5에서 2.5:1 사이여야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 새로 생성된 비디오입니다. | VIDEO |
