Hunyuan Video 15 Latent Upscale With Model 노드는 잠재 이미지 표현의 해상도를 높입니다. 먼저 선택한 보간 방법을 사용하여 잠재 샘플을 지정된 크기로 업스케일한 다음, 특화된 Hunyuan Video 1.5 업스케일 모델을 사용하여 업스케일된 결과를 정제해 품질을 향상합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 업스케일된 샘플을 정제하는 데 사용되는 Hunyuan Video 1.5 잠재 업스케일 모델입니다. | LATENT_UPSCALE_MODEL | 예 | N/A |
| `samples` | 업스케일할 잠재 이미지 표현입니다. | LATENT | 예 | N/A |
| `upscale_method` | 초기 업스케일 단계에 사용되는 보간 알고리즘입니다(기본값: `"bilinear"`). | COMBO | 예 | `"nearest-exact"`<br />`"bilinear"`<br />`"area"`<br />`"bicubic"`<br />`"bislerp"` |
| `width` | 업스케일된 잠재의 대상 너비(픽셀 단위)입니다. 값이 0이면 대상 높이와 원본 종횡비를 기준으로 너비를 자동 계산합니다. 최종 출력 너비는 16의 배수가 됩니다(기본값: 1280). | INT | 예 | 0  ~  16384 (단계: 8) |
| `height` | 업스케일된 잠재의 대상 높이(픽셀 단위)입니다. 값이 0이면 대상 너비와 원본 종횡비를 기준으로 높이를 자동 계산합니다. 최종 출력 높이는 16의 배수가 됩니다(기본값: 720). | INT | 예 | 0  ~  16384 (단계: 8) |
| `crop` | 업스케일된 잠재를 대상 치수에 맞게 자르는 방법을 결정합니다. | COMBO | 예 | `"disabled"`<br />`"center"` |

**치수 관련 참고 사항:** `width`와 `height`가 모두 0으로 설정되면 노드는 입력 `samples`를 변경하지 않고 반환합니다. 한쪽 치수만 0으로 설정되면 원본 종횡비를 유지하도록 다른 치수가 계산됩니다. 두 값 모두 최소 64로 제한되며, 보간 단계에 전달되는 업스케일 대상은 `width // 16` × `height // 16`이므로 요청된 치수는 사실상 16의 배수로 내림됩니다.
