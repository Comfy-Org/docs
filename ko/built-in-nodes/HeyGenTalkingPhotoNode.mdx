HeyGen의 Avatar IV 기술을 사용하여 사람의 정지 이미지를 립싱크가 적용된 말하는 동영상으로 애니메이션합니다. HeyGen이 음성으로 변환하는 텍스트 스크립트로 애니메이션을 구동하거나, 아바타가 립싱크할 자체 오디오를 제공할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 애니메이션할 사람의 이미지입니다. 2K보다 크면 자동으로 다운스케일됩니다. | IMAGE | 예 | - |
| `speech` | 텍스트 스크립트(HeyGen 텍스트 음성 변환) 또는 자체 오디오로 아바타를 구동합니다. | DYNAMIC_COMBO | 예 | `"script"`<br />`"audio"` |
| `resolution` | 출력 비디오 해상도(기본값: `"1080p"`). | COMBO | 아니요 | `"720p"`<br />`"1080p"` |
| `aspect_ratio` | 출력 화면 비율입니다. `"auto"`는 입력 이미지를 따릅니다(기본값: `"auto"`). | COMBO | 아니요 | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:5"`<br />`"5:4"` |
| `expressiveness` | 애니메이션된 얼굴과 제스처의 표현력 수준입니다(기본값: `"low"`). | COMBO | 아니요 | `"low"`<br />`"medium"`<br />`"high"` |
| `seed` | HeyGen으로 전송되지 않습니다. 변경하면 강제로 재실행됩니다(기본값: 42). | INT | 아니요 | 0 ~ 2147483647 |

### 스크립트 입력

`speech`가 `"script"`일 때 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `text` | 아바타가 말할 텍스트입니다(최대 5000자). 생성된 음성은 1초 이상이어야 합니다. (기본값: 비어 있음) | STRING | 예 | 1 ~ 5000자 |
| `voice` | 스크립트용 음성입니다(HeyGen의 가장 인기 있는 음성). | COMBO | 예 | 사용 가능한 여러 옵션 |
| `custom_voice_id` | 선택적 HeyGen 음성 ID입니다. 설정하면 위에서 선택한 음성을 재정의합니다. HeyGen 라이브러리(2000개 이상)의 모든 음성을 사용할 수 있습니다. (기본값: 비어 있음) | STRING | 아니요 | - |
| `voice_speed` | 음성 속도 배율입니다(기본값: 1.0). | FLOAT | 아니요 | 0.5 ~ 1.5 (단계: 0.05) |

### 오디오 입력

`speech`가 `"audio"`일 때 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 아바타가 립싱크할 오디오로, 최대 10분입니다. | AUDIO | 예 | 최대 10분 |

참고: `speech`가 `"script"`인 경우 `text`를 지정해야 하며, `voice` 선택기(아바타의 기본 음성이 아닌 다른 음성 선택) 또는 `custom_voice_id`를 통해 음성을 지정해야 합니다. `speech`가 `"audio"`인 경우 `audio`가 대신 필요합니다.
