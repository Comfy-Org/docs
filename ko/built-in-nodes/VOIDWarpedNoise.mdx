VOID 비디오 정제 과정의 두 번째 패스에 사용할 시간적 상관관계가 있는 노이즈를 생성합니다. Pass 1 출력 비디오를 입력으로 받아 광학 흐름 벡터를 따라 가우시안 노이즈를 워핑하므로, 노이즈가 비디오 콘텐츠와 일관되게 움직입니다. 생성된 워핑된 노이즈는 Pass 2의 시작 잠재값으로 사용되어 최종 출력의 시간적 일관성을 향상시킵니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `optical_flow` | OpticalFlowLoader(RAFT-large)의 광학 흐름 모델입니다. | OPTICAL_FLOW | 예 | - |
| `video` | Pass 1 출력 비디오 프레임 [T, H, W, 3]입니다. | IMAGE | 예 | - |
| `width` | 목표 너비(픽셀)입니다(기본값: 672). 노이즈를 생성하기 전에 입력 비디오를 이 너비로 조정하며, 잠재 너비는 width ÷ 8로 계산됩니다. | INT | 예 | 16 to MAX_RESOLUTION (단계: 8) |
| `height` | 목표 높이(픽셀)입니다(기본값: 384). 노이즈를 생성하기 전에 입력 비디오를 이 높이로 조정하며, 잠재 높이는 height ÷ 8로 계산됩니다. | INT | 예 | 16 to MAX_RESOLUTION (단계: 8) |
| `length` | 픽셀 프레임 수입니다. latent_t가 짝수가 되도록 내림 처리됩니다(patch_size_t=2 요구 사항). 예: 49는 45가 됩니다(기본값: 45). | INT | 예 | 1 to MAX_RESOLUTION (단계: 1) |
| `batch_size` | 생성할 동일한 워핑된 노이즈 시퀀스 수입니다(기본값: 1). 생성된 노이즈는 배치 차원을 따라 이 횟수만큼 반복됩니다. | INT | 예 | 1  ~  64 |

**`length` 매개변수에 대한 참고:** `length` 값은 CogVideoX-Fun-V1.5 모델의 `patch_size_t=2` 제약 조건에 따라 짝수 `latent_t` 차원을 생성하는 가장 가까운 값으로 자동 내림 처리됩니다(예: 49는 45가 됩니다). 이 내림 처리가 발생하면 노드가 경고를 기록합니다. 조정된 `length`를 초과하는 프레임은 무시되며, 노이즈는 결과 잠재 프레임 수에 맞게 다시 샘플링됩니다.

**`width` 및 `height`에 대한 참고:** 이 값은 들어오는 비디오 프레임의 크기를 조정하는 데(양선형, 중앙 크롭) 사용되고, 최종 잠재 해상도(8로 나눔)를 결정하는 데도 사용됩니다. 생성된 노이즈가 요청한 잠재 크기와 일치하지 않으면 크기에 맞게 조정됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `warped_noise` | VOID Pass 2에서 초기 잠재값으로 사용할 수 있는, 광학 흐름으로 워핑된 가우시안 노이즈를 포함하는 5D 텐서(B, C, T, H, W)입니다. | LATENT |
