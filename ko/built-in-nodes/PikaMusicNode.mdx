이 노드는 Pika를 사용하여 텍스트 설명과 선택적 가사로 음악을 생성하거나, 제공한 곡을 커버합니다. 설정한 길이로 새 곡을 작성하려면 `"text to music"`을 선택하고, 곡을 다시 녹음하여 길이를 유지하려면 `"cover"`를 선택합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `mode` | 노드가 수행할 작업입니다. `"text to music"`은 새 곡을 작성하고, `"cover"`는 제공된 곡을 다시 녹음합니다. 각 모드는 아래에 해당 모드의 입력을 표시합니다. 기본값: `"text to music"`. | DYNAMIC_COMBO | 예 | `"text to music"`<br />`"cover"` |

### 텍스트로 음악 입력

이 입력은 `mode`가 `"text to music"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 음악이 어떤 느낌으로 들려야 하는지 설명합니다. 비어 있으면 안 됩니다. 기본값: "" (빈 문자열). | STRING | 예 | 1~4000자 |
| `lyrics` | 선택적 가사입니다. `[Verse]` 및 `[Chorus]`와 같은 섹션 태그를 사용할 수 있습니다. 기본값: "" (빈 문자열). | STRING | 예 | 0~8000자 |
| `duration` | 곡의 길이(초)입니다. 기본값: 30.0. | FLOAT | 예 | 10.0 ~ 360.0 (단계: 0.1) |
| `rewrite_prompt` | 생성 전에 모델을 사용하여 짧거나 모호한 프롬프트를 확장합니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `seed` | 샘플링용 시드입니다. 기본값: 42. | INT | 예 | 0 ~ 2147483647 |

### 커버 입력

이 입력은 `mode`가 `"cover"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `source_audio` | 커버할 곡입니다. 결과는 동일한 길이를 가지며, 5~360초로 제한됩니다. | AUDIO | 예 | - |
| `prompt` | 커버가 어떤 느낌으로 들려야 하는지 설명합니다. 비어 있으면 안 됩니다. 기본값: "" (빈 문자열). | STRING | 예 | 1~4000자 |
| `lyrics` | 선택적 가사입니다. `[Verse]` 및 `[Chorus]`와 같은 섹션 태그를 사용할 수 있습니다. 기본값: "" (빈 문자열). | STRING | 예 | 0~8000자 |
| `rewrite_prompt` | 생성 전에 모델을 사용하여 짧거나 모호한 프롬프트를 확장합니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `seed` | 샘플링용 시드입니다. 기본값: 42. | INT | 예 | 0 ~ 2147483647 |

**제약 사항:**

* 프롬프트는 1~4000자 사이여야 하며, 가사는 8000자 이하여야 합니다.
* 커버 모드는 `duration`을 무시합니다. 출력은 `source_audio`의 길이와 일치하며, 5~360초로 제한됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `AUDIO` | 생성된 곡 또는 제공된 트랙의 커버입니다. | AUDIO |
