ModelMergeMOSSImage 노드는 두 MOSS 이미지 모델을 일치하는 가중치를 블록별로 혼합하여 병합하므로, 결과의 일부는 기본 모델에서, 나머지는 파인튜닝 모델 또는 두 번째 모델에서 가져올 수 있습니다. 아키텍처의 모든 주요 구성 요소에는 고유한 비율이 있습니다: 비디오 임베더, 텍스트 임베더, 시간 임베딩, 공유 블록 모듈레이션, 42개 트랜스포머 레이어 전체, 출력 헤드입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model1` | 병합할 첫 번째 모델입니다. 두 번째 모델이 기여하지 않는 모든 항목은 이 모델에서 유지됩니다 | MODEL | 예 | - |
| `model2` | 병합할 두 번째 모델입니다. 이 모델의 가중치는 아래 비율에 따라 혼합됩니다 | MODEL | 예 | - |
| `video_embedder.` | 비디오 임베더 블록의 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `text_embedder.proj.` | 텍스트 임베더의 프로젝션 레이어에 대한 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `text_embedder.blocks.0.` 및 `text_embedder.blocks.1.` | 두 텍스트 임베더 블록 각각의 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `time_embedding.` | 시간 임베딩 블록의 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `shared_block_modulation.` | 트랜스포머 블록에서 사용하는 공유 모듈레이션 레이어의 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `layers.0.`부터 `layers.41.`까지 | 42개 트랜스포머 레이어 각각의 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `final_norm_video.` | 비디오 스트림의 최종 정규화에 대한 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `final_linear_video.` | 비디오 스트림의 최종 선형 레이어에 대한 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `video_head_modulation.` | 비디오 출력 헤드의 모듈레이션 레이어에 대한 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |

비율이 0.0이면 해당 구성 요소를 `model1`에 있는 그대로 유지하고, 1.0이면 전적으로 `model2`에서 가져오며, 그 사이의 값은 가중 혼합을 생성합니다. 두 입력은 동일한 아키텍처를 가진 MOSS 이미지 모델이어야 합니다. 위의 접두사 중 어느 것과도 일치하지 않는 가중치는 `video_embedder.`의 비율로 대체됩니다.
