이 노드는 HappyHorse 모델을 사용하여 하나의 시작 이미지에서 짧은 비디오를 생성합니다. 첫 프레임 이미지와 원하는 움직임 및 장면을 설명하는 텍스트 프롬프트를 제공하면, 노드는 해당 이미지에서 이어지는 비디오를 생성합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용할 HappyHorse 모델입니다. | DYNAMIC_COMBO | 예 | `"happyhorse-1.1-i2v"`<br />`"happyhorse-1.0-i2v"` |
| `first_frame` | 첫 번째 프레임 이미지입니다. 출력 종횡비는 이 이미지에서 도출됩니다. | IMAGE | 예 | 300×300 px min; 1:2.5 ~ 2.5:1 |
| `seed` | 생성에 사용할 시드입니다. (기본값: 0) | INT | 예 | 0 ~ 2147483647 |
| `watermark` | 결과에 AI 생성 워터마크를 추가할지 여부입니다. (고급 옵션, 기본값: False) | BOOLEAN | 예 | True / False |

### happyhorse-1.1-i2v 및 happyhorse-1.0-i2v 입력

두 모델 버전은 동일한 매개변수 세트를 공유합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 요소와 시각적 특징을 설명하는 프롬프트입니다. 영어와 중국어를 지원합니다. (기본값: "") | STRING | 아니요 | N/A |
| `resolution` | 출력 비디오 해상도입니다. (기본값: `"720P"`) | COMBO | 예 | `"720P"`<br />`"1080P"` |
| `duration` | 생성된 비디오의 길이(초)입니다. (기본값: 5) | INT | 예 | 3 ~ 15 |

참고: `first_frame` 이미지는 최소 300x300픽셀이어야 하며, 종횡비는 1:2.5에서 2.5:1 사이여야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 생성된 비디오 파일입니다. | VIDEO |
