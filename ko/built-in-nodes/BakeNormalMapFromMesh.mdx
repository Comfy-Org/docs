이 노드는 하이폴리 메시에서 로우폴리 메시의 UV 레이아웃으로 탄젠트 공간 노멀 맵을 베이크하여, 데시메이션 중 손실된 표면 디테일을 캡처합니다. UV 언랩된 로우폴리 메시와 그것이 유래한 하이폴리 메시를 연결하면, 이 노드는 Apply Texture To Mesh의 `normal_map` 입력에 사용할 수 있는 이미지를 출력합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | 베이크된 디테일을 받는 UV 언랩된 로우폴리 메시입니다. 기존 UV가 반드시 있어야 하며, 이 노드는 절대 언랩하지 않습니다. | MESH | 예 | — |
| `high_poly` | 표면 디테일이 로우폴리의 UV 레이아웃에 베이크되는 하이폴리 메시입니다. | MESH | 예 | — |
| `resolution` | 정사각형 출력 노멀 맵의 픽셀 단위 변 길이입니다(기본값: 1024). | INT | 예 | 64  ~  8192 (단계: 64) |
| `cage_distance` | 표면 검색 밴드로, 바운딩 박스 대각선에 대한 비율입니다. 심한 데시메이션에서 잘못되거나 누락된 패치가 나타나면 값을 높이고, 간극을 넘어 잡으면 값을 낮추십시오. 기본값: 0.05. | FLOAT | 예 | 0.001  ~  0.5 (단계: 0.001) |
| `ignore_backfaces` | 텍셀 반대쪽을 향하는 하이폴리 표면을 건너뛰어, 틈새/밀폐 공간이 반대편 벽을 잡지 않도록 합니다. 하이폴리의 와인딩이 일관되지 않은 경우에만 비활성화하십시오. 기본값: true. | BOOLEAN | 예 | true / false |

참고: `low_poly`에는 UV 좌표가 있어야 합니다. UV가 없으면 이 노드는 기존 UV 레이아웃에 베이크하며 메시를 언랩하지 않기 때문에 오류를 발생시킵니다. `low_poly`가 배치인 경우 각 항목이 순서대로 베이크됩니다. `high_poly`에 항목이 하나만 있으면 해당 항목이 모든 배치 항목에 재사용됩니다. 배치에서 빈 메시는 경고와 함께 건너뛰며, 평평한 중간 회색(0.5) 노멀 맵을 생성합니다. 로우폴리 UV가 [0,1] 범위를 벗어나면 [0,1]로 균일하게 맞춰집니다(레이아웃이 타일/UDIM처럼 보이면 경고가 표시됨). 따라서 베이크와 Apply Texture To Mesh가 동일한 UV를 사용합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `normal_map` | 베이크된 탄젠트 공간 노멀 맵(glTF/OpenGL +Y 규약)으로, [0,1] 범위의 값을 갖는 정사각형 resolution × resolution RGB 이미지입니다. Apply Texture To Mesh의 `normal_map` 입력에 연결하십시오. | IMAGE |
