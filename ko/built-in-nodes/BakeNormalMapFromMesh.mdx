이 노드는 하이폴리 메시의 표면 디테일을 저폴리 메시의 UV 레이아웃에 탄젠트 공간 노멀 맵으로 구워 넣어, 디시메이션 과정에서 손실된 표면 디테일을 캡처합니다. UV가 펼쳐진 저폴리 메시와 해당 메시에서 파생된 하이폴리 메시를 연결하면, 노드는 Apply Texture To Mesh의 `normal_map` 입력에 사용할 수 있는 이미지를 출력합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `low_poly` | 베이크된 디테일을 받는 UV 펼침 저폴리 메시입니다. 기존 UV가 있어야 하며, 노드는 절대 UV를 펼치지 않습니다. | MESH | 예 | — |
| `high_poly` | 표면 디테일이 저폴리의 UV 레이아웃에 베이크되는 하이폴리 메시입니다. | MESH | 예 | — |
| `resolution` | 정사각형 출력 노멀 맵의 픽셀 단위 모서리 길이 (기본값: 1024). | INT | 예 | 64 ~ 8192 (step 64) |
| `cage_distance` | 경계 상자 대각선의 비율로 나타낸 표면 검색 대역입니다. 심한 디시메이션으로 잘못되거나 누락된 패치가 있을 때는 값을 높이고, 간격을 가로질러 잡아낼 때는 값을 낮추세요. 기본값: 0.05. | FLOAT | 예 | 0.001 ~ 0.5 (step 0.001) |
| `ignore_backfaces` | 텍셀에서 반대 방향을 향한 하이폴리 표면을 건너뜁니다. 따라서 틈새나 밀폐된 공간에서 반대편 벽을 잡아내지 않습니다. 하이폴리 메시의 감김(winding) 방향이 일관되지 않은 경우에만 비활성화하세요. 기본값: true. | BOOLEAN | 예 | true / false |

참고: `low_poly`에는 UV 좌표가 있어야 합니다. UV가 없으면 노드는 오류를 발생시킵니다. 기존 UV 레이아웃에 베이크하며 메시를 펼치지 않기 때문입니다. `low_poly`가 배치(batch)인 경우 각 항목이 순서대로 베이크됩니다. `high_poly`에 항목이 하나만 있으면 해당 항목이 모든 배치 항목에 재사용됩니다. 배치의 빈 메시는 경고와 함께 건너뛰며 완전한 중간 회색(0.5) 노멀 맵을 생성합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `normal_map` | 베이크된 탄젠트 공간 노멀 맵(glTF/OpenGL +Y 규약)으로, 값이 [0,1]인 정사각형 resolution × resolution RGB 이미지입니다. Apply Texture To Mesh의 `normal_map` 입력에 연결하세요. | IMAGE |
