FLUX 3 Image가 프롬프트에서 읽는 레이아웃 테이블을 생성합니다. Create Bounding Boxes 노드에서 그린 요소를 가져와 각각 id, 좌표, 설명이 포함된 박스 목록으로 프롬프트에 추가합니다. 프롬프트에서 박스를 `<obj_N>`로 인용하여 단어를 해당 영역에 연결한 다음, 출력을 FLUX 3 Image 노드의 프롬프트 입력에 연결하세요. 연결된 요소가 없으면 프롬프트가 변경되지 않고 반환됩니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `prompt` | 프롬프트 텍스트입니다. 박스 N을 `<obj_N>`로 인용하여 단어를 해당 박스에 연결합니다. | STRING | 예 | - |
| `element` | 레이아웃에 배치할 요소로, Create Bounding Boxes 노드에서 가져옵니다. 색상 팔레트는 사용되지 않으므로 대신 설명에 색상을 기술하세요. | ARRAY | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `prompt` | 박스 레이아웃 테이블이 추가된 프롬프트로, FLUX 3 Image 노드에 입력할 준비가 되어 있습니다. | STRING |
