Context Windows (Manual) 노드를 사용하면 샘플링 중에 모델의 컨텍스트 윈도우를 수동으로 구성할 수 있습니다. 지정된 길이, 중첩, 스케줄링 패턴으로 겹치는 컨텍스트 세그먼트를 생성하여 데이터를 관리 가능한 청크 단위로 처리하면서도 세그먼트 간 연속성을 유지합니다. 이 노드는 컨텍스트 윈도우 적용 방식을 제어하는 고급 옵션을 제공하며, 노이즈 셔플링, 컨디셔닝 유지, 인과적 윈도우 수정 기능을 포함합니다. 이 노드는 실험적입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 샘플링 중 컨텍스트 윈도우를 적용할 모델입니다. | MODEL | 예 | - |
| `context_length` | 컨텍스트 윈도우의 길이입니다(기본값: 16). | INT | 예 | 1+ |
| `context_overlap` | 컨텍스트 윈도우의 중첩입니다(기본값: 4). | INT | 예 | 0+ |
| `context_schedule` | 컨텍스트 윈도우에 대한 스텝 종속 스케줄링 알고리즘입니다(기본값: STATIC_STANDARD). | COMBO | 예 | `STATIC_STANDARD`<br />`UNIFORM_STANDARD`<br />`UNIFORM_LOOPED`<br />`BATCHED` |
| `context_stride` | 컨텍스트 윈도우의 스트라이드입니다. 균일 스케줄에만 적용됩니다(기본값: 1). | INT | 예 | 1+ |
| `closed_loop` | 컨텍스트 윈도우 루프를 닫을지 여부입니다. 루프형 스케줄에만 적용됩니다(기본값: False). | BOOLEAN | 예 | - |
| `fuse_method` | 컨텍스트 윈도우를 융합하는 데 사용하는 방법입니다(기본값: PYRAMID). | COMBO | 예 | 정적 융합 방법(`ContextFuseMethods.LIST_STATIC` 참조) |
| `dim` | 컨텍스트 윈도우를 적용할 차원입니다(기본값: 0). | INT | 예 | 0-5 |
| `프리노이즈` | FreeNoise 노이즈 셔플링을 적용할지 여부입니다. 이 기능은 윈도우 블렌딩을 개선합니다(기본값: False). | BOOLEAN | 예 | - |
| `cond_retain_index_list` | 각 윈도우에 대해 컨디셔닝 텐서에 유지할 잠재 인덱스 목록입니다. concat 방식 I2V 모델(예: Wan I2V, HunyuanVideo I2V, Cosmos I2V, SVD)의 경우 인코딩된 시작 이미지가 c_concat 컨디셔닝 채널에 있습니다. 이 값을 '0'으로 설정하면 모든 윈도우의 sub-pos 0에 해당 시작 이미지 콘텐츠가 유지됩니다(기본값: ""). | STRING | 아니요 | - |
| `split_conds_to_windows` | 여러 컨디셔닝(ConditionCombine으로 생성됨)을 영역 인덱스에 따라 각 윈도우로 분할할지 여부입니다(기본값: False). | BOOLEAN | 아니요 | - |
| `latent_retain_index_list` | 각 윈도우에 대해 노이즈 잠재 자체에 유지할 잠재 인덱스 목록입니다. 참조 콘텐츠(예: 시작 이미지)가 별도의 컨디셔닝 채널이 아닌 노이즈 잠재에 직접 있는 워크플로우에 사용합니다(예: LTXV, AnimateDiff와 같은 inplace 방식 I2V). `cond_retain_index_list`와 독립적입니다(기본값: ""). | STRING | 아니요 | - |
| `causal_window_fix` | 0이 아닌 인덱스를 가진 컨텍스트 윈도우에 인과적 수정 프레임을 추가할지 여부입니다(기본값: True). | BOOLEAN | 아니요 | - |

**매개변수 제약 조건:**

- `context_stride`는 균일 스케줄(`UNIFORM_STANDARD` 또는 `UNIFORM_LOOPED`)이 선택된 경우에만 사용됩니다.
- `closed_loop`는 루프형 스케줄(`UNIFORM_LOOPED`)에만 적용됩니다.
- `dim`은 0 이상 5 이하의 값이어야 합니다.
- `cond_retain_index_list`와 `latent_retain_index_list`는 문자열 형식의 쉼표로 구분된 정수 인덱스 목록을 입력받습니다(예: "0,1,2").
- `latent_retain_index_list`는 `cond_retain_index_list`와 독립적입니다.
