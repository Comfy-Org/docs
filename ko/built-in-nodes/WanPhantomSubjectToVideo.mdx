WanPhantomSubjectToVideo 노드는 Wan 비디오 생성을 위한 컨디셔닝 데이터와 latent를 준비합니다. 요청된 `width`, `height`, `length`, `batch_size`로부터 빈 latent 비디오를 생성하며, 참조 이미지가 제공되면 VAE로 인코딩하고 시간 차원 시각적 가이던스로 컨디셔닝에 추가합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `포지티브` | 비디오 생성을 유도하기 위한 긍정 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `네거티브` | 특정 특성을 피하기 위한 부정 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `VAE` | 참조 이미지가 제공될 때 이를 인코딩하는 데 사용되는 VAE 모델 | VAE | 예 | - |
| `너비` | 출력 비디오의 너비(픽셀) (기본값: 832) | INT | 예 | 16 ~ MAX_RESOLUTION (단계 16) |
| `높이` | 출력 비디오의 높이(픽셀) (기본값: 480) | INT | 예 | 16 ~ MAX_RESOLUTION (단계 16) |
| `길이` | 생성된 비디오의 프레임 수 (기본값: 81) | INT | 예 | 1 ~ MAX_RESOLUTION (단계 4) |
| `배치 크기` | 동시에 생성할 비디오 수 (기본값: 1) | INT | 예 | 1 ~ 4096 |
| `이미지` | 시간 차원 시각적 가이던스로 사용되는 선택적 참조 이미지 | IMAGE | 아니요 | - |

**참고:** `images`가 제공되면 지정된 `width`와 `height`에 맞게 자동으로 업스케일되며, 처음 `length`개의 이미지만 처리에 사용됩니다. 각 이미지는 `vae`로 인코딩되어 시간 차원을 따라 연결되며, 각 이미지의 RGB 채널만 사용됩니다. `images`가 제공되지 않으면 세 가지 컨디셔닝 출력 모두 입력 컨디셔닝에서 변경 없이 반환됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `positive` | 이미지가 제공되면 인코딩된 참조 이미지의 시간 차원 연결이 포함된 긍정 컨디셔닝이고, 그렇지 않으면 입력 `positive`가 변경 없이 반환됩니다 | CONDITIONING |
| `negative_text` | 이미지가 제공되면 인코딩된 참조 이미지의 시간 차원 연결이 포함된 부정 컨디셔닝이고, 그렇지 않으면 입력 `negative`가 변경 없이 반환됩니다 | CONDITIONING |
| `negative_img_text` | 이미지가 제공되면 0으로 설정된 시간 차원 연결이 포함된 부정 컨디셔닝이고, 그렇지 않으면 입력 `negative`가 변경 없이 반환됩니다 | CONDITIONING |
| `latent` | 16개 채널을 가진 0으로 채워진 latent 비디오 텐서입니다. 프레임 수는 `length`에서 파생되고, 공간 차원은 `height`와 `width`에서 파생됩니다 | LATENT |
