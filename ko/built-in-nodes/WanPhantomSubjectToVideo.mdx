WanPhantomSubjectToVideo 노드는 Wan 비디오 생성을 위한 컨디셔닝 데이터와 잠재(latent)를 준비합니다. 요청된 너비, 높이, 길이 및 배치 크기로 빈 잠재 비디오를 생성하며, 참조 이미지가 제공되면 VAE로 인코딩하여 시간 차원의 시각적 가이던스로 컨디셔닝에 추가합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `포지티브` | 비디오 생성을 안내하는 긍정 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `네거티브` | 특정 특성을 피하기 위한 부정 컨디셔닝 입력 | CONDITIONING | 예 | - |
| `VAE` | 참조 이미지가 제공될 때 이를 인코딩하는 데 사용되는 VAE 모델 | VAE | 예 | - |
| `너비` | 출력 비디오의 너비(픽셀 단위) (기본값: 832, 16의 배수여야 함) | INT | 예 | 16 to MAX_RESOLUTION |
| `높이` | 출력 비디오의 높이(픽셀 단위) (기본값: 480, 16의 배수여야 함) | INT | 예 | 16 to MAX_RESOLUTION |
| `길이` | 생성된 비디오의 프레임 수 (기본값: 81, 4의 배수여야 함) | INT | 예 | 1 to MAX_RESOLUTION |
| `배치 크기` | 동시에 생성할 비디오 수 (기본값: 1) | INT | 예 | 1 ~ 4096 |
| `이미지` | 시간 차원의 시각적 가이던스로 사용되는 선택적 참조 이미지 | IMAGE | 아니요 | - |

**참고:** `images`가 제공되면 지정된 `width` 및 `height`에 맞게 자동으로 업스케일되며, 처음 `length`개의 이미지만 처리에 사용됩니다. 각 이미지는 `vae`로 인코딩되어 시간 차원을 따라 연결되며, 각 이미지의 RGB 채널만 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `포지티브` | 이미지가 제공된 경우 인코딩된 참조 이미지의 시간 차원 연결을 포함한 긍정 컨디셔닝이고, 그렇지 않으면 입력 `positive`가 그대로 반환됩니다. | CONDITIONING |
| `네거티브 텍스트` | 이미지가 제공된 경우 인코딩된 참조 이미지의 시간 차원 연결을 포함한 부정 컨디셔닝이고, 그렇지 않으면 입력 `negative`가 그대로 반환됩니다. | CONDITIONING |
| `네거티브 이미지 텍스트` | 이미지가 제공된 경우 0으로 채워진 시간 차원 연결을 포함한 부정 컨디셔닝이고, 그렇지 않으면 입력 `negative`가 그대로 반환됩니다. | CONDITIONING |
| `잠재` | 16개 채널을 가진 0으로 채워진 잠재 비디오 텐서입니다. 프레임 수는 `length`에서, 공간 차원은 `height`와 `width`에서 파생됩니다. | LATENT |
