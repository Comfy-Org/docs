ModelSamplingLTXV 노드는 토큰 수를 기준으로 모델에 고급 샘플링 매개변수를 적용합니다. `base_shift`와 `max_shift` 사이를 토큰 범위에 걸쳐 선형 보간하여 시프트 값을 계산한 다음, 특수 샘플링 구성으로 입력 모델을 패치합니다. `latent`가 제공되면 해당 차원이 토큰 수를 결정하며, 그렇지 않으면 4096개의 토큰이 사용됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 샘플링 매개변수를 적용할 입력 모델입니다. | MODEL | 예 | - |
| `최대 시프트` | 선형 보간 계산에 사용되는 최대 시프트 값입니다(기본값: 2.05). | FLOAT | 예 | 0.0  ~  100.0 (단계: 0.01) |
| `기반 시프트` | 선형 보간 계산에 사용되는 기준 시프트 값입니다(기본값: 0.95). | FLOAT | 예 | 0.0  ~  100.0 (단계: 0.01) |
| `잠재 비디오` | 시프트 계산의 토큰 수를 결정하는 데 사용되는 선택적 레이턴트 입력입니다. 제공되지 않으면 기본 토큰 수 4096이 사용됩니다. | LATENT | 아니요 | - |

시프트 값은 1024개 토큰에서의 `base_shift`와 4096개 토큰에서의 `max_shift` 사이를 보간하여 계산됩니다. `latent`가 제공되면 토큰 수는 레이턴트 샘플에서 처음 두 차원 이후의 모든 차원(공간/시간 차원)의 곱입니다. `latent`가 제공되지 않으면 토큰 수는 기본적으로 4096입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `model` | 적용된 샘플링 매개변수로 수정된 모델입니다. | MODEL |
