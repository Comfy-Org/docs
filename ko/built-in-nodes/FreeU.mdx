FreeU 노드는 모델의 출력 블록에 주파수 영역 수정을 적용하여 이미지 생성 품질을 향상합니다. 서로 다른 채널 그룹을 스케일링하고 특정 특징 맵에 푸리에 필터링을 적용하여 작동하며, 생성 과정에서 모델 동작을 세밀하게 제어할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | FreeU 수정을 적용할 모델 | MODEL | 예 | - |
| `b1` | model_channels × 4 채널의 특징 맵에 적용되는 백본 스케일링 계수(기본값: 1.1)입니다. 고급 설정으로 표시됩니다. | FLOAT | 예 | 0.0 - 10.0 |
| `b2` | model_channels × 2 채널의 특징 맵에 적용되는 백본 스케일링 계수(기본값: 1.2)입니다. 고급 설정으로 표시됩니다. | FLOAT | 예 | 0.0 - 10.0 |
| `s1` | model_channels × 4 채널의 특징 맵에 적용되는 스킵 연결 스케일링 계수(기본값: 0.9)입니다. 고급 설정으로 표시됩니다. | FLOAT | 예 | 0.0 - 10.0 |
| `s2` | model_channels × 2 채널의 특징 맵에 적용되는 스킵 연결 스케일링 계수(기본값: 0.2)입니다. 고급 설정으로 표시됩니다. | FLOAT | 예 | 0.0 - 10.0 |

참고: FreeU 조정은 채널 수가 model_channels × 4(`b1`과 `s1` 사용) 또는 model_channels × 2(`b2`와 `s2` 사용)와 같은 특징 맵에만 적용됩니다. 푸리에 필터는 스킵 연결 특징 맵의 중앙 저주파 영역(임계값 1)만 스케일링하며, 다른 모든 주파수 성분은 변경되지 않습니다. 네 가지 스케일링 매개변수 모두 0.0에서 10.0 사이의 값을 0.01 단위로 받습니다.
