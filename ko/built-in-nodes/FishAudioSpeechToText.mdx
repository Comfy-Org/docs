이 노드는 Fish Audio 음성-텍스트 변환 서비스를 사용하여 오디오를 텍스트로 전사합니다. 오디오의 언어를 자동으로 감지하며, 선택적으로 단어 수준 타임스탬프가 포함된 세그먼트를 JSON으로 반환할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 전사할 오디오입니다. | AUDIO | 예 | — |
| `language` | ISO 639-1 언어 힌트(예: 'en', 'zh')입니다. 언어는 힌트와 관계없이 자동 감지됩니다. 기본값: ""(빈 문자열). | STRING | 아니요 | 모든 ISO 639-1 언어 코드(예: `en`, `zh`) 또는 자동 감지용 빈 문자열 |
| `precise_timestamps` | 단어 수준 타임스탬프가 포함된 세그먼트를 반환합니다. 기본값: false. | BOOLEAN | 아니요 | true 또는 false |

참고: `language` 매개변수는 힌트일 뿐이며, 언어는 항상 오디오에서 자동 감지됩니다. `precise_timestamps`가 false(기본값)이면 단어 수준 타임스탬프가 반환되지 않으며, true이면 출력 세그먼트에 단어 수준 타임스탬프가 포함됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `text` | 전사된 텍스트입니다. | STRING |
| `language_code` | 오디오에서 감지된 ISO 639-1 언어 코드입니다. | STRING |
| `segments_json` | 전사 세그먼트가 포함된 JSON 문자열입니다. `precise_timestamps`를 활성화하면 단어 수준 타임스탬프를 포함합니다. | STRING |
