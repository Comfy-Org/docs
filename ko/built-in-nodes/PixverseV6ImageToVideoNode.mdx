이 노드는 PixVerse V6 모델로 입력 이미지를 애니메이션화하고, 선택적으로 네이티브 오디오 트랙과 함께 비디오를 반환합니다. 출력 비디오는 입력 이미지의 가로세로 비율을 유지합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 애니메이션화할 입력 이미지입니다. | IMAGE | 예 | 단일 이미지 |
| `모델` | 모델 및 생성 설정입니다. | DYNAMIC_COMBO | 예 | "PixVerse V6" |

### PixVerse V6 입력

이 설정들은 "PixVerse V6" 모델을 선택할 때 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오 생성을 위한 프롬프트입니다(기본값: 비어 있음). | STRING | 예 | 1~5000자 |
| `quality` | 출력 해상도입니다. 긴 변을 설정합니다: 360p는 640px, 540p는 1024px, 720p는 1280px, 1080p는 1920px입니다(기본값: "720p"). | COMBO | 예 | "360p"<br />"540p"<br />"720p"<br />"1080p" |
| `duration_seconds` | 생성된 비디오의 길이(초)입니다(기본값: 5). | INT | 예 | 1~15 |
| `generate_audio` | 비디오와 함께 네이티브 오디오 트랙을 생성합니다(기본값: true). | BOOLEAN | 예 | true 또는 false |
| `multi_clip` | 모델이 비디오를 하나의 연속 테이크 대신 여러 샷으로 분할하도록 합니다(기본값: false). | BOOLEAN | 예 | true 또는 false |
| `seed` | 비디오 생성을 위한 시드입니다. PixVerse는 이를 기록하지만, 이를 사용해 실행을 재현하지는 않습니다(기본값: 42, 생성 후 제어 활성화됨). | INT | 예 | 0~2147483647 |
| `negative_prompt` | 비디오에서 원하지 않는 요소에 대한 선택적 텍스트 설명입니다(기본값: 비어 있음). | STRING | 아니요 | 최대 2048자 |
| `style` | 전체 비디오에 적용되는 선택적 시각 스타일입니다(기본값: 없음). | COMBO | 아니요 | 여러 옵션 사용 가능(PixVerse V6 스타일 프리셋) |

참고: 프롬프트에는 공백이 아닌 문자가 최소 하나 이상 포함되어야 하며, 최대 5000자까지 가능합니다. 부정 프롬프트를 제공하는 경우 최대 2048자여야 합니다. 출력 비디오는 항상 입력 이미지의 가로세로 비율과 일치하므로 가로세로 비율 설정이 필요하지 않습니다. 입력 이미지는 한 장만 허용됩니다. 콘텐츠 검열이 실패하거나, 제공자 계정의 크레딧이 소진되었거나, 동시 생성 최대 개수가 이미 실행 중인 경우 PixVerse는 요청을 거부할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 생성된 비디오로, `generate_audio`가 활성화된 경우 네이티브 오디오 트랙을 포함합니다. 가로세로 비율은 입력 이미지와 일치합니다. | VIDEO |
