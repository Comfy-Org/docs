이 노드는 Trellis2 생성의 텍스처 단계 샘플링 패스를 설정합니다. 입력으로 받은 셰이프 잠재에서 좌표 레이아웃과 복셀별 셰이프 잠재를 읽어, 동일한 좌표 레이아웃에 32개 채널을 가진 빈 희소 잠재를 생성하고, 필요한 텍스처 단계 메타데이터를 컨디셔닝에 첨부합니다.

## 입력

| 파라미터 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 텍스처 생성 패스에 사용되는 포지티브 컨디셔닝입니다. 텍스처 단계 메타데이터가 여기에 첨부됩니다. | CONDITIONING | 예 | - |
| `negative` | 텍스처 생성 패스에 사용되는 네거티브 컨디셔닝입니다. 텍스처 단계 메타데이터가 여기에 첨부됩니다. | CONDITIONING | 예 | - |
| `shape_latent` | Trellis2ShapeStage 또는 Trellis2UpsampleStage에서 생성된 잠재 딕셔너리입니다. `coords`(좌표 레이아웃, 형태 [N, 4])와 `samples`(복셀별 셰이프 잠재)를 반드시 포함해야 하며, `coord_resolution`과 `model_frame`은 선택 사항입니다. | LATENT | 예 | - |

참고 사항:
- `shape_latent`는 Trellis2ShapeStage 또는 Trellis2UpsampleStage의 출력이어야 합니다. 텍스처 패스에서 사용되는 좌표 레이아웃과 복셀별 셰이프 잠재를 제공합니다.
- 좌표 레이아웃이 검증됩니다. `coords`의 첫 번째 열에 있는 배치 ID는 음수가 아니어야 하며 연속적이어야 하고, 총 행 수는 좌표 개수와 일치해야 합니다.
- `positive`에 프로젝션 피처 팩(Pixal3D 컨디셔닝)이 포함되어 있고 `shape_latent`에 `coord_resolution`이 포함된 경우, 1024 텍스처 해상도의 프로젝션 피처가 계산되어 컨디셔닝에 첨부됩니다.
- 모델 프레임은 `shape_latent`에서 읽습니다. 해당 값이 없으면 프로젝션 피처가 있는 경우 `"y_up"`으로, 그렇지 않은 경우 `"z_up"`으로 기본 설정됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 텍스처 단계 메타데이터(생성 모드, 좌표, 좌표 개수, 셰이프 잠재, 모델 프레임, 그리고 해당되는 경우 프로젝션 피처)가 첨부된 포지티브 컨디셔닝입니다. | CONDITIONING |
| `negative` | 동일한 텍스처 단계 메타데이터가 첨부된 네거티브 컨디셔닝입니다. | CONDITIONING |
| `latent` | 입력으로 받은 셰이프 잠재와 동일한 좌표 레이아웃에 32개 채널을 가진 새로운 빈 희소 잠재입니다. 해당 딕셔너리에는 `samples`, `type`("trellis2"), `coords`, `coord_counts`, `model_frame`이 포함되며, 사용 가능한 경우 `coord_resolution`도 포함됩니다. | LATENT |
