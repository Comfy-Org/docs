이 노드는 Trellis2 생성의 텍스처 단계 샘플링 패스를 설정합니다. 입력 shape latent에서 좌표 레이아웃과 복셀별 shape latent를 읽고, 동일한 좌표 레이아웃에서 32개 채널을 가진 빈 희소 latent를 생성하며, 필요한 텍스처 단계 메타데이터를 컨디셔닝에 첨부합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 텍스처 생성 패스에 사용되는 긍정 컨디셔닝입니다. 텍스처 단계 메타데이터가 여기에 첨부됩니다. | CONDITIONING | 예 | - |
| `negative` | 텍스처 생성 패스에 사용되는 부정 컨디셔닝입니다. 텍스처 단계 메타데이터가 여기에 첨부됩니다. | CONDITIONING | 예 | - |
| `shape_latent` | Trellis2ShapeStage 또는 Trellis2UpsampleStage에서 생성된 latent 딕셔너리입니다. `coords`(좌표 레이아웃, shape [N, 4])와 `samples`(복셀별 shape latent)를 포함해야 하며, `coord_resolution`과 `model_frame`은 선택 사항입니다. | LATENT | 예 | - |

참고:
- `shape_latent`는 Trellis2ShapeStage 또는 Trellis2UpsampleStage의 출력이어야 합니다. 이는 텍스처 패스에서 사용하는 좌표 레이아웃과 복셀별 shape latent를 제공합니다.
- 좌표 레이아웃은 검증됩니다: `coords`의 첫 번째 열에 있는 배치 ID는 음수가 아니고 연속적이어야 하며, 전체 행 수는 좌표 수와 일치해야 합니다.
- shape latent는 4D 희소 텐서(해당 좌표와 함께 평탄화됨) 또는 이미 평탄화된 형태로 허용됩니다.
- `positive`가 프로젝션 특징 팩(Pixal3D 컨디셔닝)을 전달하고 `shape_latent`에 `coord_resolution`이 포함된 경우, 1024 텍스처 해상도의 프로젝션 특징이 계산되어 컨디셔닝에 첨부됩니다.
- 모델 프레임은 `shape_latent`에서 읽습니다. 없는 경우 프로젝션 특징이 있으면 `"y_up"`으로, 그렇지 않으면 `"z_up"`으로 기본 설정됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 텍스처 단계 메타데이터(생성 모드, 좌표, 좌표 수, shape latent, 모델 프레임, 해당되는 경우 프로젝션 특징)가 첨부된 긍정 컨디셔닝입니다. | CONDITIONING |
| `negative` | 동일한 텍스처 단계 메타데이터가 첨부된 부정 컨디셔닝입니다. | CONDITIONING |
| `latent` | 수신 shape latent와 동일한 좌표 레이아웃에서 32개 채널을 가진 새로운 빈 희소 latent입니다. 해당 딕셔너리에는 `samples`, `type` ("trellis2"), `coords`, `coord_counts`, `model_frame`이 포함되며, 사용 가능한 경우 `coord_resolution`이 포함됩니다. | LATENT |
