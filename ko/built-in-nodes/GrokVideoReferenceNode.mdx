Grok Reference-to-Video 노드는 텍스트 프롬프트에서 비디오를 생성하며, 최대 7개의 참조 이미지를 사용하여 출력의 스타일과 내용을 안내합니다. `grok-imagine-video-1.5` 모델을 사용하면 최대 3개의 사전 설정 음성 참조를 첨부하고 `@ImageN` 및 `@AudioN` 태그를 사용하여 프롬프트에서 이미지와 음성을 직접 참조할 수 있습니다. 이 노드는 외부 API에 요청을 전송하고, 생성이 완료될 때까지 대기한 후 결과 비디오를 다운로드합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 비디오 생성에 사용할 모델입니다. | DYNAMIC_COMBO | 예 | `"grok-imagine-video-1.5"`<br />`"grok-imagine-video"` |
| `프롬프트` | 원하는 비디오에 대한 텍스트 설명입니다. 비어 있지 않은 문자열이어야 합니다. | STRING | 예 | N/A |
| `시드` | 노드 재실행 여부를 결정하는 시드입니다. 시드와 관계없이 실제 결과는 비결정적입니다(기본값: 0). | INT | 예 | 0 ~ 2147483647 |

### Grok Imagine Video 1.5 입력

`model`이 `grok-imagine-video-1.5`로 설정된 경우 사용할 수 있습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `voice_1` | 선택적 사전 설정 음성 참조입니다. 프롬프트에서 @Audio1로 참조하세요. API는 사용자 지정 오디오가 아닌 사전 설정 음성만 지원합니다(기본값: none). | COMBO | 아니요 | 사전 설정 음성 옵션, `"none"` 포함 |
| `voice_2` | 선택적 두 번째 음성 참조입니다. 프롬프트에서 @Audio2로 참조합니다(기본값: none). | COMBO | 아니요 | 사전 설정 음성 옵션, `"none"` 포함 |
| `voice_3` | 선택적 세 번째 음성 참조입니다. 프롬프트에서 @Audio3로 참조합니다(기본값: none). | COMBO | 아니요 | 사전 설정 음성 옵션, `"none"` 포함 |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"480p"`<br />`"720p"` |
| `aspect_ratio` | 출력 비디오의 화면 비율입니다. | COMBO | 예 | `"16:9"`<br />`"4:3"`<br />`"3:2"`<br />`"1:1"`<br />`"2:3"`<br />`"3:4"`<br />`"9:16"` |
| `duration` | 출력 비디오의 길이(초)입니다(기본값: 6). | INT | 예 | 1 ~ 15 |

### Grok Imagine Video 입력

`model`이 `grok-imagine-video`로 설정된 경우 사용할 수 있습니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"480p"`<br />`"720p"` |
| `aspect_ratio` | 출력 비디오의 화면 비율입니다. | COMBO | 예 | `"16:9"`<br />`"4:3"`<br />`"3:2"`<br />`"1:1"`<br />`"2:3"`<br />`"3:4"`<br />`"9:16"` |
| `duration` | 출력 비디오의 길이(초)입니다(기본값: 6). | INT | 예 | 2 ~ 10 |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 확장 가능한 슬롯: 비디오 생성을 안내하기 위해 1~7개의 참조 이미지를 연결합니다. `grok-imagine-video-1.5`에서는 입력 순서대로 번호가 매겨진 @Image1 ... @Image7로 프롬프트에서 참조할 수 있습니다. 배치 입력은 이미지당 한 번으로 계산됩니다. | IMAGE | 예 | 1~7개 이미지 |

**참고:** 표시되는 하위 매개변수는 선택한 `model`에 따라 달라집니다. `grok-imagine-video-1.5`는 `voice_1`, `voice_2`, `voice_3` 입력을 추가합니다. 최소 1개의 참조 이미지가 필요하며 총 개수는 7개로 제한됩니다(배치 입력은 이미지당 한 번으로 계산됩니다). `grok-imagine-video-1.5`에서 프롬프트는 연결된 이미지를 `@Image1` ... `@Image7`로, 음성 슬롯을 `@Audio1`, `@Audio2`, `@Audio3`로 참조할 수 있습니다. 번호가 없는 `@image` 또는 `@audio`는 첫 번째 항목을 참조합니다. `@AudioN`은 활성화된 음성의 순서가 아닌 `voice_N` 위젯을 참조합니다. 연결되지 않은 이미지 또는 `none`으로 설정된 음성 슬롯을 참조하면 오류가 발생합니다. API는 사용자 지정 오디오가 아닌 사전 설정 음성만 지원합니다.
