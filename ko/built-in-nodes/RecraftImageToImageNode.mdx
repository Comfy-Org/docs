이 노드는 텍스트 프롬프트와 강도 설정을 기반으로 기존 이미지를 수정합니다. 이미지를 Recraft V3 API로 전송하고, 강도 값에 따라 원본과 어느 정도 유사성을 유지하면서 프롬프트를 따르는 새 이미지를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 수정할 입력 이미지입니다. 이미지 배치가 제공되면 각 이미지가 개별적으로 처리됩니다. | IMAGE | 예 | - |
| `프롬프트` | 이미지 생성용 프롬프트입니다. 기본값: 빈 문자열. 최대 길이: 1000자. | STRING | 예 | - |
| `개수` | 생성할 이미지 수입니다. 기본값: 1. | INT | 예 | 1-6 |
| `강도` | 원본 이미지와의 차이를 정의합니다. [0, 1] 범위에 있어야 하며, 0은 거의 동일함, 1은 유사성이 거의 없음을 의미합니다. 기본값: 0.5. | FLOAT | 예 | 0.0-1.0 (단계: 0.01) |
| `시드` | 노드 재실행 여부를 결정하는 시드입니다. 실제 결과는 시드에 관계없이 비결정적입니다. 기본값: 0. | INT | 예 | 0-18446744073709551615 |
| `recraft 스타일` | 이미지 생성을 위한 선택적 스타일 선택입니다. 제공되지 않으면 기본값은 `realistic_image`입니다. | STYLEV3 | 아니요 | - |
| `부정 프롬프트` | 이미지에서 원하지 않는 요소에 대한 선택적 텍스트 설명입니다. 기본값: 빈 문자열. 입력 소켓으로 제공됩니다. | STRING | 아니요 | - |
| `recraft 제어` | Recraft Controls 노드를 통해 생성에 대한 선택적 추가 제어입니다. | CONTROLS | 아니요 | - |

**참고:** `seed` 매개변수는 노드의 재실행만 트리거하며 결정론적 결과를 보장하지 않습니다. `strength` 매개변수는 내부적으로 소수점 둘째 자리로 반올림됩니다. `prompt`는 검증되며 1000자를 초과해서는 안 됩니다. 빈 `negative_prompt`는 네거티브 프롬프트가 없는 것으로 처리됩니다. `recraft_style`이 제공되지 않으면 노드는 기본적으로 `realistic_image` 스타일을 사용합니다. Infinite Style Library에서 `style_id`를 사용하는 경우 Vector art 스타일이 아닌지 확인하세요. 그렇지 않으면 노드가 이미지 대신 SVG 데이터를 수신하여 오류가 발생할 수 있습니다. 입력 `image`가 배치인 경우, 배치의 각 이미지가 개별적으로 처리되고 모든 결과가 함께 반환됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 입력 이미지, 프롬프트 및 강도를 기반으로 생성된 이미지입니다. | IMAGE |
