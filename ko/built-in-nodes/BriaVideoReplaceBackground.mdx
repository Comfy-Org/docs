이 노드는 Bria의 API를 사용하여 비디오의 배경을 제공된 이미지 또는 비디오로 교체합니다. 출력은 전경 비디오의 해상도와 프레임 속도를 유지합니다. 종횡비가 다른 배경은 맞춰지도록 늘어나므로, 종횡비를 일치시키면 왜곡 없는 결과가 생성됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video` | 배경이 교체되는 전경 비디오입니다. | VIDEO | 예 | - |
| `background_image` | 전경 뒤에 합성할 배경 이미지입니다. 배경 이미지 또는 배경 비디오 중 하나만 제공하세요. 둘 다 제공하지 마세요. | IMAGE | 아니요 | - |
| `background_video` | 전경 뒤에 합성할 배경 비디오입니다. 배경 이미지 또는 배경 비디오 중 하나만 제공하세요. 둘 다 제공하지 마세요. | VIDEO | 아니요 | - |
| `seed` | 시드는 노드가 다시 실행되어야 하는지 제어합니다. 시드와 관계없이 결과는 비결정적입니다. (기본값: 0) | INT | 예 | 0 ~ 2147483647 |

**참고:** `background_image` 또는 `background_video` 중 정확히 하나를 제공해야 합니다. 둘 다 제공하거나 둘 다 제공하지 않으면 안 됩니다. 전경 비디오와 배경 비디오(사용하는 경우)는 각각 60초 이하여야 합니다. `background_image`를 사용하는 경우 처리 전에 알파 채널이 제거됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 배경이 교체된 결과 비디오로, MP4(H.264)로 인코딩됩니다. | VIDEO |
