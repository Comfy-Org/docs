3D 모델을 ComfyUI 출력 디렉터리의 파일로 저장하고 저장된 장면의 미리보기를 생성합니다. 또한 3D 모델, 장면 내 배치, 카메라 정보 및 뷰포트 크기를 다운스트림 노드로 전달합니다. 모델 배치 또는 카메라 정보가 연결되지 않은 경우, 노드는 뷰포트 상태에 저장된 값을 사용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 업스트림 3D 노드에서 가져온 3D 모델 파일입니다. | FILE3D | 예 | GLB<br />GLTF<br />FBX<br />OBJ<br />STL<br />USDZ<br />Any |
| `filename_prefix` | 저장되는 파일 이름에 사용되는 접두사입니다(기본값: "3d/ComfyUI"). | STRING | 예 | Free text |
| `viewport_state` | 카메라 및 모델 배치 정보를 포함하는 뷰포트 상태이며, 일반적으로 Load 3D 노드에서 가져옵니다. | LOAD3D | 예 | - |
| `model_3d_info` | 장면에서 각 모델의 배치: 위치, 회전 및 스케일(Y-up 월드 공간)입니다. 연결된 경우 `viewport_state`에 저장된 모델 배치를 재정의합니다. | LOAD3DMODELINFO | 아니요 | - |
| `camera_info` | 뷰포트 카메라 정보: 위치, 바라보는 대상, 줌 및 유형입니다. 연결된 경우 `viewport_state`에 저장된 카메라 정보를 재정의합니다. | LOAD3DCAMERA | 아니요 | - |
| `width` | 뷰포트의 렌더 너비(픽셀)입니다(기본값: 1024). | INT | 예 | 1  ~  4096 |
| `height` | 뷰포트의 렌더 높이(픽셀)입니다(기본값: 1024). | INT | 예 | 1  ~  4096 |

참고: `model_3d_info`와 `camera_info`는 선택 사항입니다. 둘 중 하나의 입력이 연결되지 않은 경우, 노드는 `viewport_state`에 저장된 해당 값으로 대체합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model_3d` | 입력에서 전달된 3D 모델 파일입니다. | FILE3D |
| `model_3d_info` | 장면에서 각 모델의 배치: 위치, 회전 및 스케일(Y-up 월드 공간)입니다. | LOAD3DMODELINFO |
| `camera_info` | 뷰포트 카메라 정보: 위치, 바라보는 대상, 줌 및 유형입니다. | LOAD3DCAMERA |
| `width` | 입력에서 전달된 렌더 너비 값입니다. | INT |
| `height` | 입력에서 전달된 렌더 높이 값입니다. | INT |
