Smooth SAM3D Body Pose Data는 시간에 따라 모션을 평균화하여 일련의 3D 신체 포즈에서 프레임 간 지터를 줄입니다. 카메라 및 외형 데이터는 완전히 스무딩되며, 피사체가 빠르게 회전할 때 메시 지오메트리는 덜 스무딩되어 빠른 회전이 평탄화되지 않습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `mhr_pose_data` | 스무딩할 MHR 포즈 데이터 시퀀스로, 모델 매개변수, 형상 매개변수, 표정 매개변수, MHR70 키포인트 레이아웃 및 관련 메시 데이터를 포함합니다. | MHR_POSE_DATA | 예 | — |
| `강도` | 스무딩 강도입니다. 0 = 원본, 1 = 스무딩됨. (기본값: 1.0) | FLOAT | 예 | 0.0  ~  1.0 (단계: 0.05) |
| `방법` | gaussian: 대칭 가중 평균으로, 범용 스무더로 가장 적합합니다.<br />savgol: 슬라이딩 다항식 피팅으로, 날카로운 피크를 보존합니다. (기본값: "savgol") | COMBO | 예 | "gaussian"<br />"savgol" |
| `윈도우` | 프레임 단위의 시간적 윈도우입니다(홀수 값). (기본값: 7) | INT | 예 | 1  ~  51 (odd values, step 2) |
| `rotation_threshold_degrees` | 이 루트 회전 속도(도/프레임)에 대해 스무딩을 비활성화하여 빠른 회전을 보존합니다. 30°는 대부분의 콘텐츠에 적합하며, 낮은 값은 일반적인 지터에서 스무딩을 비활성화할 수 있고 품질에 조용히 영향을 미칩니다. 0 = 비활성화. (기본값: 30.0) | FLOAT | 예 | 0.0  ~  90.0 (단계: 1.0) |

참고: `strength`가 0.0 이하이거나 `window`가 1 이하이면 노드는 입력 데이터를 변경하지 않고 반환합니다. 입력에는 최소 2개의 프레임과 키포인트 데이터가 포함되어야 하며, 그렇지 않으면 노드는 입력 데이터를 변경하지 않고 반환합니다. `rotation_threshold_degrees`가 0.0이면 회전 기반 스무딩 백오프가 비활성화됩니다.
