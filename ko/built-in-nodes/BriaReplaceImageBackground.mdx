이 노드는 이미지의 배경을 Bria에서 생성한 새 배경으로 교체합니다. 새 배경은 텍스트 프롬프트로 설명하거나 참조 이미지로 안내할 수 있습니다. 피사체의 픽셀은 보존되며, 그 주변에 배경이 생성됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 배경을 교체할 입력 이미지입니다. | IMAGE | 예 | |
| `배경` | 프롬프트로 새 배경을 설명하거나 참조 이미지로 안내합니다. | DYNAMIC_COMBO | 예 | `"prompt"`<br />`"reference images"` |
| `original_quality` | 결과를 약 1메가픽셀로 조정하는 대신 입력의 정확한 픽셀 크기를 반환합니다. 따라서 큰 입력은 큰 이미지를 반환합니다. (기본값: false) | BOOLEAN | 아니요 | `true`<br />`false` |
| `시드` | 동일한 시드는 일반적으로 동일한 배경을 반환하지만, 자동 프롬프트 개선으로 인해 결과가 달라질 수 있습니다. (기본값: 42) | INT | 아니요 | 0  ~  2147483647 |
| `모더레이션` | 검열 설정. (기본값: "false") | DYNAMIC_COMBO | 아니요 | `"false"`<br />`"true"` |

### 프롬프트 입력

`background`가 `"prompt"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 새 배경에 대한 설명입니다. #FF5733과 같은 헥스 색상 코드는 단색 배경을 생성합니다. 최소 1자 이상이어야 합니다. | STRING | 예 | |
| `mode` | `high_control`은 프롬프트를 가장 밀접하게 따르고, `base`는 균형 잡힌 기본값이며 `fast`는 세부 묘사 대신 속도를 우선합니다. | COMBO | 예 | `"high_control"`<br />`"base"`<br />`"fast"` |
| `refine_prompt` | 더 나은 결과를 위해 프롬프트를 다시 작성하며, 영어가 아닌 프롬프트도 번역합니다. 프롬프트를 작성한 그대로 보내려면 끄세요. (기본값: true) | BOOLEAN | 아니요 | `true`<br />`false` |

### 참조 이미지 입력

`background`가 `"reference images"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `ref_images` | 확장 가능한 슬롯: 새 배경을 안내하는 이미지를 1~10개 연결합니다. 크기가 같을 필요는 없습니다. 모든 참조가 결과를 바꾸므로 일관된 소수 참조가 서로 충돌하는 많은 참조보다 낫습니다. 배치 입력은 이미지당 한 번으로 계산됩니다. | IMAGE | 예 | 1  ~  10 images |
| `enhance_ref_images` | 더 나은 결과를 위해 참조 이미지를 추가 처리합니다. (기본값: true) | BOOLEAN | 아니요 | `true`<br />`false` |

### 검열 입력

`moderation`이 `"true"`로 설정된 경우 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | 프롬프트 콘텐츠에 대한 검열을 활성화합니다. (기본값: false) | BOOLEAN | 아니요 | `true`<br />`false` |
| `visual_input_moderation` | 시각적 입력에 대한 검열을 활성화합니다. (기본값: false) | BOOLEAN | 아니요 | `true`<br />`false` |
| `visual_output_moderation` | 시각적 출력에 대한 검열을 활성화합니다. (기본값: false) | BOOLEAN | 아니요 | `true`<br />`false` |

**참고:** `ref_images` 입력은 최대 10개의 이미지를 허용하며, 10개를 초과하여 제공하면 오류가 반환됩니다. `prompt` 필드는 최소 1자 이상이어야 합니다. `original_quality`가 false이면 입력 이미지는 처리 전에 약 1메가픽셀로 축소됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 새 배경이 적용된 이미지입니다. | IMAGE |
| `refined_prompt` | Bria가 생성한 프롬프트이며, 참조 이미지 경로에서는 비어 있습니다. | STRING |
