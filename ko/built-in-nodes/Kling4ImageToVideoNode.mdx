Kling 4.0 모델을 사용하여 키프레임 세트로부터 오디오를 포함한 비디오를 생성합니다. 첫 번째 프레임, 최대 8개의 중간 프레임, 마지막 프레임이 순서대로 전송되며, 중간 프레임은 클립 전체에 균등한 간격으로 배치되고, 출력은 첫 번째 키프레임의 화면 비율을 따릅니다. 하나의 이미지를 애니메이션화하거나 일련의 주요 순간을 통해 샷을 유도하는 데 사용합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 모델 선택기입니다. `"kling-4.0"`은 최대 1080p 해상도와 30초 길이를 지원합니다. `"kling-4.0-flash"`는 720p, 20초, 단일 첫 프레임으로 제한됩니다. 모델을 선택하면 해당 모델의 입력이 아래에 표시됩니다. | DYNAMIC_COMBO | 예 | `"kling-4.0"`<br />`"kling-4.0-flash"` |

### kling-4.0 입력

`model`이 `"kling-4.0"`로 설정된 경우 이 입력들이 표시됩니다. 프레임 입력 중 최소 하나 이상이 연결되어 있어야 합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 비디오가 시작되는 선택적 프레임입니다. | IMAGE | 아니요 | - |
| `middle_frames` | 첫 번째와 마지막 프레임 사이의 프레임을 위한 선택적 확장 가능 슬롯이며, 최대 8개입니다. 클립 전체에 균등하게 배치됩니다. | AUTOGROW | 아니요 | 0~8개 이미지 |
| `last_frame` | 비디오가 끝나는 선택적 프레임입니다. | IMAGE | 아니요 | - |
| `prompt` | 움직임에 대한 선택적 설명입니다. 연결된 프레임은 첫 번째 프레임, 중간 프레임, 마지막 프레임 순서대로 `@Image1`, `@Image2` 등으로 참조하십시오. 기본값: 빈 문자열. | STRING | 예 | 여러 줄 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. 기본값: `"720p"`. | COMBO | 예 | `"720p"`<br />`"1080p"` |
| `duration` | 생성된 비디오의 길이(초)입니다. 기본값: 5. | INT | 예 | 3~30 |
| `seed` | 시드는 노드의 재실행 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |

### kling-4.0-flash 입력

`model`이 `"kling-4.0-flash"`로 설정된 경우 이 입력들이 표시됩니다. Flash는 단일 첫 프레임을 애니메이션화합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 비디오가 시작되는 프레임입니다. | IMAGE | 예 | - |
| `prompt` | 움직임에 대한 선택적 설명입니다. 첫 번째 프레임을 `@Image1`로 참조하십시오. 기본값: 빈 문자열. | STRING | 예 | 여러 줄 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. Flash는 720p만 렌더링합니다. 기본값: `"720p"`. | COMBO | 예 | `"720p"` |
| `duration` | 생성된 비디오의 길이(초)입니다. 기본값: 5. | INT | 예 | 3~20 |
| `seed` | 시드는 노드의 재실행 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |

**제약 사항 및 동작:**

* 첫 번째 프레임, 모든 중간 프레임, 마지막 프레임을 포함하여 총 최대 10개의 프레임을 연결할 수 있습니다.
* 비디오는 첫 번째 키프레임의 화면 비율을 따르므로 화면 비율 입력이 필요하지 않습니다.
* 모든 프레임은 최소 300x300픽셀이어야 하며 화면 비율은 2:5에서 5:2 사이여야 합니다.
* `@ImageN`을 언급하는 프롬프트는 연결된 프레임 수가 N개 미만이면 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 생성된 비디오로, 작업이 완료되면 제공자로부터 다운로드됩니다. | VIDEO |
