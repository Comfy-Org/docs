Kling 4.0 모델을 사용하여 키프레임 집합으로부터 오디오를 포함한 비디오를 생성합니다. 첫 번째 프레임, 최대 8개의 중간 프레임, 마지막 프레임이 순서대로 전송되며, 중간 프레임은 클립 전체에 균등하게 배치되고 출력은 첫 번째 키프레임의 가로세로 비율을 사용합니다. 한 이미지를 애니메이션화하거나 일련의 핵심 순간들을 따라 샷을 이끄는 데 사용할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 모델 선택기입니다. `"kling-4.0"`만 사용할 수 있으며, 이를 선택하면 아래 입력이 표시됩니다. | DYNAMIC_COMBO | 예 | `"kling-4.0"` |

### kling-4.0 입력

이 입력은 `model`이 `"kling-4.0"`으로 설정된 경우 표시됩니다. 프레임 입력 중 최소 하나는 연결해야 합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | 비디오가 시작되는 선택적 프레임입니다. | IMAGE | 아니요 | - |
| `middle_frames` | 첫 프레임과 마지막 프레임 사이의 프레임을 위한 선택적 확장 가능 슬롯으로, 최대 8개입니다. 이 프레임들은 클립 전체에 균등하게 배치됩니다. | AUTOGROW | 아니요 | 이미지 0~8개 |
| `last_frame` | 비디오가 끝나는 선택적 프레임입니다. | IMAGE | 아니요 | - |
| `prompt` | 동작에 대한 선택적 설명입니다. 연결된 프레임은 첫 프레임, 중간 프레임, 마지막 프레임 순서로 `@Image1`, `@Image2` 등으로 참조합니다. 기본값: 빈 문자열. | STRING | 예 | 여러 줄 텍스트 |
| `resolution` | 출력 비디오의 해상도입니다. 기본값: `"720p"`. | COMBO | 예 | `"720p"`<br />`"1080p"` |
| `duration` | 생성된 비디오의 길이(초)입니다. 기본값: 5. | INT | 예 | 3~30 |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |

**제약 사항 및 동작:**

* 첫 프레임, 모든 중간 프레임, 마지막 프레임을 포함하여 총 최대 10개의 프레임을 연결할 수 있습니다.
* 비디오는 첫 번째 키프레임의 가로세로 비율을 사용하므로 가로세로 비율 입력이 필요하지 않습니다.
* 모든 프레임은 최소 300x300픽셀이어야 하며 가로세로 비율은 2:5에서 5:2 사이여야 합니다.
* `@ImageN`을 언급하는 프롬프트는 연결된 프레임 수가 N개 미만일 때 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 생성된 비디오이며, 작업이 완료되면 제공자로부터 다운로드됩니다. | VIDEO |
