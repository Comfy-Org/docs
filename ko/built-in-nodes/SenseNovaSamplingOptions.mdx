SenseNova Sampling Options는 모델에 SenseNova flow shift를 설정합니다. 입력 모델을 복제하고, 선택한 flow shift 값을 사용하는 SenseNova 모델 샘플링 구성을 추가한 뒤, 샘플링 중 사용할 수 있도록 패치된 모델을 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | SenseNova flow shift 샘플링 구성이 적용되는 모델입니다. | MODEL | 예 | - |
| `shift` | SenseNova 모델 샘플링에 설정할 flow shift 값입니다(기본값: 3.0, UI 단계: 0.01). | FLOAT | 예 | 최솟값 또는 최댓값이 정의되지 않음 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `MODEL` | SenseNova flow shift가 샘플링 구성에 적용된 입력 모델의 복제본입니다. | MODEL |
