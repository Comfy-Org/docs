Text Encode Ming Image Edit는 텍스트 프롬프트를 Ming 이미지 편집용 컨디셔닝으로 인코딩하며, 선택적으로 참조 이미지를 혼합합니다. 프롬프트와 참조 이미지는 CLIP 모델에 의해 토큰화되며, VAE가 연결된 경우 참조 이미지는 컨디셔닝에 추가되는 잠재 프레임으로도 인코딩됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 프롬프트와 참조 이미지를 토큰화하는 데 사용되는 CLIP 모델입니다. | CLIP | 예 | - |
| `vae` | 참조 이미지를 컨디셔닝에 추가되는 잠재 프레임으로 인코딩하는 선택적 VAE입니다. VAE가 없으면 이미지는 비전 타워를 통해 텍스트 인코더만 조건화합니다. | VAE | 아니요 | - |
| `prompt` | 인코딩할 텍스트 프롬프트입니다. 여러 줄 입력과 동적 프롬프트를 지원합니다. | STRING | 예 | 여러 줄 텍스트 |
| `images` | 확장 가능한 슬롯: 텍스트 인코더가 보는 선택적 참조 이미지이며, 클린 프레임으로 잠재 시퀀스에 추가됩니다. 1..8개의 이미지(`image_1`, `image_2`, ...)를 연결하세요. 이후 이미지는 첫 번째 이미지 크기로 조정되며, 샘플링된 잠재는 그 크기와 일치해야 합니다. RGB 채널만 사용됩니다. | IMAGE | 아니요 | 0  ~  8 |

**참고:** 참조 이미지는 슬롯 이름의 숫자 순서대로 읽히며, 빈 슬롯은 무시됩니다. 참조 잠재는 `vae`와 최소 하나의 이미지가 모두 제공된 경우에만 생성됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `CONDITIONING` | 인코딩된 프롬프트를 포함하는 컨디셔닝이며, VAE와 참조 이미지가 제공된 경우 참조 잠재도 포함합니다. | CONDITIONING |
