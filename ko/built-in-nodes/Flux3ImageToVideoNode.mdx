Flux 3 Image to Video는 FLUX 3를 사용하여 1~10개의 이미지를 애니메이션으로 만듭니다. 각 이미지는 클립의 프레임이 됩니다. 이미지 하나는 클립을 시작하고, 두 개는 첫 번째에서 두 번째로 모핑되며, 더 많은 이미지는 클립 전체에 분산되거나 선택한 시간에 고정됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 씬이 어떻게 움직이고 소리를 낼지에 대한 설명입니다. 생성 전에 프롬프트가 해석되고 확장됩니다. 최소 한 자 이상이어야 합니다. | STRING | 예 | 여러 줄 텍스트 (기본값: 비어 있음) |
| `keyframes` | 재생 순서대로 된 1~10개의 이미지입니다. 각각 최소 256x256 픽셀이어야 합니다. 확장 가능한 입력: `image_1`, `image_2` 등으로 이미지를 연결합니다. | IMAGE | 예 | 이미지 1~10개 |
| `placement` | "spread across the clip"은 FLUX 3가 이미지를 배치하도록 합니다(이미지 하나는 클립을 시작하고, 두 개는 시작과 끝이 됩니다). "at times"는 모든 이미지를 선택한 시간(초)에 고정합니다. | DYNAMIC_COMBO | 예 | `"spread across the clip"` (기본값)<br />`"at times"` |
| `times` | 이미지당 하나의 시간(초)으로, 쉼표로 구분되고 증가해야 합니다(예: "0, 2.5, 5"). `placement`가 "at times"일 때만 표시되며, 각 키프레임 이미지에 대해 하나의 시간이 필요합니다. | STRING | 아니요 | 쉼표로 구분된 초 (기본값: "0") |
| `aspect_ratio` | 출력 종횡비입니다. "auto"는 프롬프트와 입력에서 하나를 선택합니다. | COMBO | 예 | `"auto"` (기본값)<br />기타 사용 가능한 종횡비 |
| `duration` | 클립 길이(초)입니다. "auto"는 콘텐츠에 맞게 길이를 조정합니다. | COMBO | 예 | `"auto"` (기본값)<br />기타 사용 가능한 지속 시간 |
| `resolution` | 출력 해상도입니다. | COMBO | 예 | `"720p"` (기본값)<br />`"1080p"` |
| `generate_audio` | 동기화된 오디오(주변음, 음성, 효과음)를 생성합니다. 해제하면 오디오 트랙이 없는 비디오가 생성됩니다. | BOOLEAN | 예 | true / false (기본값: true) |
| `safety_tolerance` | 검열 허용 오차로, 0이 가장 엄격합니다. 이미지나 비디오를 전송하는 요청은 여기에 설정한 값과 관계없이 2로 제한됩니다. | INT | 예 | 0~4 (기본값: 2, 고급 설정) |
| `seed` | 노드를 다시 실행할지 결정하는 시드입니다. FLUX 3는 자체 시드를 선택하므로 실제 결과는 이 값과 관계없이 비결정적입니다. | INT | 예 | 0~4294967295 (기본값: 42, 생성 후 제어) |

참고: `keyframes`에는 최소 하나의 이미지가 포함되어야 하며, 연결된 이미지가 없으면 노드에서 오류가 발생합니다. 각 키프레임 이미지는 최소 256x256 픽셀이어야 하며 종횡비는 64:1보다 극단적일 수 없습니다.

`placement`가 "spread across the clip"이고 키프레임이 3개 이상 연결된 경우, `duration`은 "auto"가 아닌 명시적 값으로 설정해야 합니다. 그렇지 않으면 노드에서 오류가 발생합니다.

`placement`가 "at times"인 경우, `times`는 이미지당 하나의 시간(초)을 제공해야 합니다. 시간은 증가해야 하고 음수일 수 없으며, 마지막 시간은 클립 끝을 지날 수 없습니다(`duration`이 "auto"일 때 최대 20초).

이 노드는 이미지를 전송하므로 `safety_tolerance`는 설정한 값과 관계없이 2로 제한됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 키프레임 이미지에서 선택한 종횡비, 지속 시간, 해상도 및 오디오 설정으로 생성된 비디오 클립입니다. | VIDEO |
