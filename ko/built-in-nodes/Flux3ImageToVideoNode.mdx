Flux 3 Image to Video는 FLUX 3를 사용하여 1~10개의 이미지를 애니메이션화합니다. 각 이미지는 클립의 프레임이 됩니다. 이미지가 하나면 클립을 시작하고, 둘이면 첫 번째 이미지에서 두 번째 이미지로 모핑되며, 더 많으면 클립 전체에 분산되거나 사용자가 선택한 시간에 고정됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `placement` | "spread across the clip"은 FLUX 3가 이미지를 배치하도록 합니다(하나는 클립을 열고, 둘은 시작과 끝이 됩니다). "at times"는 모든 이미지를 사용자가 선택한 초에 고정합니다. | DYNAMIC_COMBO | 예 | `"spread across the clip"` (기본값)<br />`"at times"` |
| `prompt` | 장면이 어떻게 움직이고 소리를 내야 하는지입니다. 프롬프트는 생성 전에 해석되고 확장됩니다. 최소 한 문자를 포함해야 합니다. | STRING | 예 | 여러 줄 텍스트 (기본값: 비어 있음) |
| `aspect_ratio` | 출력 종횡비입니다. "auto"는 프롬프트와 입력에서 하나를 선택합니다. | COMBO | 예 | `"auto"` (기본값)<br />기타 사용 가능한 종횡비 |
| `duration` | 클립 길이(초)입니다. "auto"는 콘텐츠에 맞게 길이를 맞춥니다. | COMBO | 예 | `"auto"` (기본값)<br />기타 사용 가능한 길이 |
| `resolution` | 출력 해상도입니다. | COMBO | 예 | `"720p"` (기본값)<br />`"1080p"` |
| `generate_audio` | 동기화된 오디오(주변음, 음성, 효과)를 생성합니다. 끄면 오디오 트랙이 없는 비디오를 생성합니다. | BOOLEAN | 예 | true / false (기본값: true) |
| `safety_tolerance` | 검열 허용 범위이며 0이 가장 엄격합니다. 이미지나 비디오를 전송하는 요청은 여기서 설정한 값과 관계없이 2로 제한됩니다. | INT | 예 | 0~4 (기본값: 2, 고급 설정) |
| `seed` | 노드를 다시 실행할지 결정하는 시드입니다. FLUX 3는 자체 시드를 선택하므로 이 값과 관계없이 실제 결과는 비결정적입니다. | INT | 예 | 0~4294967295 (기본값: 42, 생성 후 제어) |

### spread across the clip 입력

이 배치 옵션에는 추가 매개변수가 없습니다.

### at times 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `times` | 이미지당 하나의 시간(초)이며, 쉼표로 구분되고 증가해야 합니다. 예: "0, 2.5, 5". `placement`가 "at times"일 때만 나타납니다. 각 키프레임 이미지마다 하나의 시간이 필요합니다. | STRING | 아니요 | 쉼표로 구분된 초 (기본값: "0") |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `keyframes` | 확장 가능한 슬롯: 재생 순서대로 1~10개의 키프레임 이미지를 연결합니다. 예: `image_1`, `image_2` 등. 각 이미지는 클립의 프레임이 됩니다. 각 이미지는 최소 256x256픽셀이어야 하며, 종횡비는 64:1보다 더 극단적일 수 없습니다. | IMAGE | 예 | 이미지 1~10개 |

참고: `keyframes`에는 최소 하나의 이미지가 포함되어야 합니다. 아무것도 연결되지 않으면 노드에서 오류가 발생합니다. 각 키프레임 이미지는 최소 256x256픽셀이어야 하며, 종횡비는 64:1보다 더 극단적일 수 없습니다.

`placement`가 "spread across the clip"이고 키프레임이 3개 이상 연결된 경우, `duration`을 "auto"가 아닌 명시적인 값으로 설정해야 합니다. 그렇지 않으면 노드에서 오류가 발생합니다.

`placement`가 "at times"인 경우, `times`는 이미지마다 시간(초)을 하나씩 제공해야 합니다. 시간은 증가해야 하고 음수가 될 수 없으며, 마지막 시간은 클립의 끝을 넘을 수 없습니다(`duration`이 "auto"일 때 최대 20초).

이 노드는 이미지를 전송하므로, `safety_tolerance`는 설정한 값과 관계없이 2로 제한됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 선택한 종횡비, 길이, 해상도 및 오디오 설정에 따라 키프레임 이미지로 구성된 생성된 비디오 클립입니다. | VIDEO |
