Flux 3 Image to Video는 FLUX 3로 1~10개의 이미지를 애니메이션으로 변환합니다. 각 이미지는 클립의 프레임이 됩니다. 이미지 하나는 클립을 시작하고, 두 개는 첫 번째에서 두 번째로 모핑되며, 더 많은 이미지는 클립 전체에 분산되거나 선택한 시간에 고정됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 장면이 어떻게 움직이고 어떤 소리가 나야 하는지 설명합니다. 프롬프트는 생성 전에 해석되고 확장됩니다. 최소 한 자 이상의 문자가 필요합니다. | STRING | 예 | 여러 줄 텍스트 (기본값: 비어 있음) |
| `keyframes` | 재생 순서대로 정렬된 1~10개의 이미지입니다. 각 이미지는 최소 256x256 픽셀이어야 합니다. 각 키프레임은 클립의 한 지점이 됩니다. | IMAGE | 예 | 1~10개의 이미지 |
| `placement` | 'spread across the clip'은 FLUX 3가 이미지를 배치하도록 합니다(이미지 하나는 클립을 시작하고, 두 개는 클립의 시작과 끝이 됩니다). 'at times'는 모든 이미지를 선택한 시간(초)에 고정합니다. | STRING | 예 | `"spread across the clip"` (기본값)<br />`"at times"` |
| `times` | 이미지당 하나의 시간(초)을 쉼표로 구분하여 증가하는 순서로 지정합니다(예: '0, 2.5, 5'). `placement`가 `"at times"`인 경우 필수입니다. | STRING | 아니요 | 쉼표로 구분된 초 (기본값: "0") |
| `aspect_ratio` | 출력 화면 비율입니다. 'auto'는 프롬프트와 입력에서 화면 비율을 선택합니다. | STRING | 예 | `"auto"` (기본값)<br />그 외 사용 가능한 옵션 |
| `duration` | 클립 길이(초)입니다. 'auto'는 콘텐츠에 맞게 길이를 조정합니다. | STRING | 예 | `"auto"` (기본값)<br />그 외 사용 가능한 옵션 |
| `resolution` | 출력 해상도입니다. | STRING | 예 | `"720p"` (기본값)<br />`"1080p"` |
| `generate_audio` | 동기화된 오디오(주변음, 음성, 효과음)를 생성합니다. 끄면 오디오 트랙이 없는 비디오가 생성됩니다. | BOOLEAN | 예 | true / false (기본값: true) |
| `safety_tolerance` | 안전 허용 수준입니다. 0이 가장 엄격합니다. 이미지나 비디오를 보내는 요청은 여기에서 설정한 값과 관계없이 2로 제한됩니다. | INT | 예 | 0~4 (기본값: 2, 고급 설정) |
| `seed` | 노드 재실행 여부를 결정하는 시드입니다. FLUX 3는 자체 시드를 선택하므로 이 값과 관계없이 실제 결과는 비결정적입니다. | INT | 예 | 0~4294967295 (기본값: 42, 생성 후 제어 기능 포함) |

참고: `keyframes`는 필수입니다. 키프레임 이미지가 연결되지 않으면 노드가 오류를 발생시킵니다. `placement`가 `"spread across the clip"`이고 3개 이상의 이미지가 제공되는 경우 `duration`을 명시적 값(`"auto"`가 아님)으로 설정해야 합니다. 그렇지 않으면 노드가 오류를 발생시킵니다. `placement`가 `"at times"`인 경우 `times`는 이미지당 하나의 시간(초)을 증가하는 순서로 제공해야 합니다. 이미지를 보내는 요청은 설정된 값과 관계없이 안전 허용 수준이 2로 제한됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 선택한 화면 비율, 길이, 해상도 및 오디오 설정으로 키프레임 이미지에서 생성된 비디오 클립입니다. | VIDEO |
