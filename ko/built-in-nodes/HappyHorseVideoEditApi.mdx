HappyHorse 모델을 사용하여 텍스트 지침이나 참조 이미지로 비디오를 편집합니다. 출력 길이는 3~15초이며 입력 비디오와 일치하고, 15초를 초과하는 입력은 잘립니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 사용할 HappyHorse 비디오 편집 모델입니다. 이 선택에 따라 사용 가능한 프롬프트, 해상도, 비율 및 참조 이미지 옵션이 결정됩니다. | DYNAMIC_COMBO | 예 | "happyhorse-1.0-video-edit" |
| `video` | 편집할 비디오입니다. | VIDEO | 예 | 3~60초 |
| `seed` | 생성에 사용할 시드입니다(기본값: 0). | INT | 예 | 0~2147483647 |
| `watermark` | 결과물에 AI 생성 워터마크를 추가할지 여부입니다(기본값: False). 고급 매개변수입니다. | BOOLEAN | 예 | True<br />False |

### happyhorse-1.0-video-edit 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 편집 지침 또는 스타일 변환 요구 사항입니다. 최소 1자 이상이어야 합니다. | STRING | 예 | - |
| `resolution` | 출력 해상도입니다. | COMBO | 예 | "720P"<br />"1080P" |
| `ratio` | 화면 비율입니다. 변경하지 않으면 입력 비디오의 비율에 근사합니다. | COMBO | 예 | "16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4" |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | Growable 슬롯: 편집을 안내하기 위해 참조 이미지(`image1`...`image5`)를 0~5장 연결합니다. | IMAGE | 아니요 | 0~5장 |

**참고:** 입력 비디오는 3~60초 길이여야 합니다. 출력 길이는 3~15초이며 입력 비디오와 일치하고, 15초를 초과하는 입력 비디오는 잘립니다. `prompt`는 최소 1자 이상이어야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 편집된 비디오 출력입니다. | VIDEO |
