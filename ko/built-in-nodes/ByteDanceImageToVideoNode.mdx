ByteDance 이미지에서 비디오로 변환 노드는 ByteDance의 API를 사용하여 입력 이미지와 텍스트 프롬프트로 비디오를 생성합니다. 제공된 설명을 시각적으로 표현하는 비디오 시퀀스를 생성하며, 출력의 해상도, 비율, 지속 시간 및 다른 매개변수를 사용자 정의할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 비디오 생성에 사용할 ByteDance 모델입니다. 사용 가능한 옵션은 다음과 같습니다:<br />`"seedance-1-5-pro-251215"`<br />`"seedance-1-0-pro-250528"`<br />`"seedance-1-0-pro-fast-251015"` | STRING | 예 | 위에 나열된 것과 같습니다 |
| `프롬프트` | 비디오 생성에 사용할 텍스트 프롬프트입니다. 공백을 제거한 후 최소 1자리 이상이어야 합니다. | STRING | 예 | - |
| `이미지` | 비디오에 사용될 첫 번째 프레임입니다. 이미지는 300x300에서 6000x6000 픽셀 사이이며, 비율은 0.4에서 2.5 사이여야 합니다. | IMAGE | 예 | - |
| `해상도` | 출력 비디오의 해상도입니다. 사용 가능한 옵션은 다음과 같습니다:<br />`"480p"`<br />`"720p"`<br />`"1080p"` | STRING | 예 | 위에 나열된 것과 같습니다 |
| `화면비율` | 출력 비디오의 비율입니다. 사용 가능한 옵션은 다음과 같습니다:<br />`"adaptive"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"`<br />`"21:9"` | STRING | 예 | 위에 나열된 것과 같습니다 |
| `지속 시간` | 출력 비디오의 지속 시간(초)입니다. `seedance-1-5-pro-251215` 모델의 경우 최소 지원 시간은 4초입니다. | INT | 예 | 3 - 12 |
| `시드` | 생성에 사용할 시드입니다. 기본 값은 0입니다. | INT | 아님 | 0 - 2147483647 |
| `카메라 고정` | 카메라를 고정할지 여부를 지정합니다. 플랫폼은 프롬프트에 카메라 고정 명령을 추가하지만, 실제 효과를 보장하지 않습니다. 기본 값은 False입니다. | BOOLEAN | 아님 | - |
| `워터마크` | 비디오에 "AI generated" 워터마크를 추가할지 여부입니다. 기본 값은 False입니다. | BOOLEAN | 아님 | - |
| `generate_audio` | 이 매개변수는 `seedance-1-5-pro-251215` 모델 외의 모델에서 무시됩니다. 기본 값은 False입니다. | BOOLEAN | 아님 | - |

**주의:** 프롬프트에는 다음 단어(대소문자 구분 없이)가 포함되지 않아야 합니다: `resolution`, `ratio`, `duration`, `seed`, `camerafixed`, `watermark`. 이 매개변수는 그 전용 입력을 통해 설정됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
