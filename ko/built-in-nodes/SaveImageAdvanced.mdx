**Save Image (Advanced)** 노드는 입력 이미지를 ComfyUI 출력 디렉터리에 저장하며, 파일 형식, 비트 깊이, 색 공간을 고급 수준에서 제어할 수 있습니다. PNG, EXR 또는 AVIF 파일(애니메이션 AVIF 포함)로 저장할 수 있고, 저장된 파일에 워크플로 메타데이터를 포함할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `images` | 저장할 이미지입니다. | IMAGE | 예 | - |
| `filename_prefix` | 저장할 파일의 접두사입니다. `%date:yyyy-MM-dd%` 또는 `%Empty Latent Image.width%` 같은 형식 토큰을 포함할 수 있습니다. (기본값: "ComfyUI") | STRING | 예 | - |
| `format` | 이미지를 저장할 파일 형식입니다. 형식을 선택하면 해당 형식의 추가 옵션이 표시됩니다. | DYNAMIC_COMBO | 예 | `"png"`<br />`"exr"`<br />`"avif"` |

### PNG 입력

이 옵션은 `format`이 `"png"`로 설정된 경우 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `bit_depth` | 저장된 PNG 파일의 비트 깊이입니다. (기본값: "8-bit") | COMBO | 예 (조건부) | `"8-bit"`<br />`"16-bit"` |
| `input_color_space` | 입력 텐서의 색 공간입니다. PNG 형식에서는 sRGB만 사용할 수 있습니다. (기본값: "sRGB") | COMBO | 예 (조건부) | `"sRGB"` |

### EXR 입력

이 옵션은 `format`이 `"exr"`로 설정된 경우 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `bit_depth` | 저장된 EXR 파일의 비트 깊이입니다. (기본값: "32-bit float") | COMBO | 예 (조건부) | `"32-bit float"` |
| `input_color_space` | 입력 텐서의 색 공간입니다. EXR은 항상 일치하는 색역의 scene-linear로 기록됩니다.<br />`"sRGB"` — 입력은 sRGB로 인코딩된 Rec.709이며, 역 sRGB EOTF가 적용됩니다.<br />`"HDR"` — 입력은 HLG로 인코딩된 Rec.2020(BT.2100)이며, 장면 선형 광을 얻기 위해 역 HLG OETF가 적용됩니다.<br />`"linear"` — 입력은 이미 scene-linear(Rec.709 원색)이며, 변경 없이 그대로 기록됩니다. 렌더러/컴포지터 출력에 사용하십시오. (기본값: "sRGB") | COMBO | 예 (조건부) | `"sRGB"`<br />`"HDR"`<br />`"linear"` |

### AVIF 입력

이 옵션은 `format`이 `"avif"`로 설정된 경우 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `bit_depth` | 저장된 AVIF 파일의 비트 깊이입니다. Auto는 sRGB에 8-bit YUV420을, HDR에 10-bit YUV420을 사용합니다. (기본값: "auto") | COMBO | 예 (조건부) | `"auto"`<br />`"8-bit YUV420"`<br />`"10-bit YUV420"` |
| `input_color_space` | 입력 이미지의 색 공간입니다. HDR은 BT.2020/HLG를 선택하고 HDR PQ는 BT.2020/PQ를 선택합니다. (기본값: "sRGB") | COMBO | 예 (조건부) | `"sRGB"`<br />`"HDR"`<br />`"HDR PQ"` |
| `crf` | 값이 낮을수록 품질이 높아지고 파일 크기가 커집니다. (기본값: 18) | INT | 예 (조건부) | 1  ~  63 |
| `save_mode` | AVIF 파일의 저장 모드입니다. `"still images"`는 배치의 각 이미지를 별도의 스틸 파일로 저장합니다. `"animated"`는 전체 배치를 하나의 애니메이션 AVIF 파일로 저장하고 `fps` 및 `loop_count`를 표시합니다. (기본값: "still images") | DYNAMIC_COMBO | 예 (조건부) | `"still images"`<br />`"animated"` |

### AVIF 애니메이션 옵션

이 옵션은 `save_mode`가 `"animated"`로 설정된 경우 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `fps` | 애니메이션의 프레임 속도입니다. (기본값: 6.0) | FLOAT | 예 (조건부) | 0.01  ~  1000.0 |
| `loop_count` | 애니메이션을 반복할 횟수입니다. 0은 무한 반복입니다. (기본값: 0) | INT | 예 (조건부) | 0  ~  1000 |

**매개변수 종속성 참고:**
- 형식별 매개변수(`bit_depth`, `input_color_space`, AVIF의 경우 `crf` 및 `save_mode`도 해당)는 특정 `format`이 선택된 경우에만 사용할 수 있습니다.
- PNG 형식에서는 "8-bit" 및 "16-bit" 비트 깊이만 사용할 수 있으며, "sRGB" 색 공간만 지원합니다.
- EXR 형식에서는 "32-bit float" 비트 깊이만 사용할 수 있으며, "sRGB", "HDR" 또는 "linear" 색 공간을 지원합니다.
- AVIF 형식에서는 `save_mode`가 `"animated"`로 설정된 경우에만 `fps` 및 `loop_count`를 사용할 수 있습니다.
- PNG 및 EXR 이미지는 1(그레이스케일), 3(RGB) 또는 4(RGBA) 채널이어야 합니다. 다른 채널 수는 지원되지 않으며 오류가 발생합니다.
- AVIF는 1채널 그레이스케일 및 3채널 RGB 이미지만 지원합니다. RGBA(알파) 이미지는 지원되지 않으며 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `images` | 입력 이미지이며 변경 없이 그대로 전달됩니다. 노드의 UI 출력은 저장된 이미지 결과 목록을 제공하며, 각 결과에는 파일 이름, 하위 폴더, 타입("output")이 포함됩니다. 이미지가 두 개 이상인 애니메이션 AVIF의 경우 UI 출력에 `animated` 플래그도 포함됩니다. | IMAGE |
