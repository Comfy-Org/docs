```markdown
# LTXV Empty Latent Audio

LTXV Empty Latent Audio 노드는 비어 있는(0으로 채워진) 잠재 오디오 텐서 배치를 생성합니다. 제공된 Audio VAE 모델의 구성을 사용하여 채널 수와 주파수 빈과 같은 잠재 공간의 올바른 차원을 결정하고, 프레임 수와 프레임 속도에서 오디오 잠재의 수를 계산합니다. 이 빈 잠재 텐서는 ComfyUI 내 오디오 생성 또는 조작 워크플로의 시작점으로 사용됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `frames_number` | 프레임 수입니다. 기본값은 97입니다. | INT | 예 | 1 ~ 1000 |
| `frame_rate` | 초당 프레임 수입니다. 기본값은 25.0입니다. FLOAT 또는 INT 값을 허용합니다. | FLOAT | 예 | 1.0 ~ 1000.0 |
| `batch_size` | 배치 내 잠재 오디오 샘플 수입니다. 기본값은 1입니다. | INT | 예 | 1 ~ 4096 |
| `audio_vae` | 구성을 가져올 Audio VAE 모델입니다. 이 매개변수는 필수입니다. | VAE | 예 | N/A |

**참고:** `audio_vae` 입력은 필수입니다. 제공되지 않으면 노드에서 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `Latent` | 입력 Audio VAE와 일치하도록 구성된 (batch_size, z_channels, num_audio_latents, audio_freq) 구조의 빈 잠재 오디오 텐서입니다. 출력에는 "audio"로 설정된 `type` 필드도 포함됩니다. | LATENT |
```
