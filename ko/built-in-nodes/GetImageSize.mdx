GetImageSize는 입력 이미지를 읽고 해당 이미지의 너비, 높이 및 배치 크기를 반환합니다. 또한 이 노드는 측정된 값을 노드 인터페이스에 직접 표시합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 너비, 높이 및 배치 크기가 추출되는 입력 이미지입니다. | IMAGE | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `width` | 입력 이미지의 너비(픽셀 단위)입니다. | INT |
| `height` | 입력 이미지의 높이(픽셀 단위)입니다. | INT |
| `batch_size` | 입력 배치에 포함된 이미지의 개수입니다. | INT |
