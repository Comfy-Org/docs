## 개요

Block Sparse Attention 노드는 ComfyUI 모델에 블록-스파스 어텐션 메커니즘을 적용하여, 각 쿼리 블록이 선택된 키 블록 집합에만 어텐션을 주도록 하여 어텐션 계산을 줄입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 블록-스파스 어텐션을 적용할 ComfyUI 모델. | MODEL | 예 | N/A |
| `selection` | 어텐션할 키 블록을 선택하는 선택 방법. | DYNAMIC_COMBO | 예 | 옵션: Sol-Attn (적응형 tau), top-k (SLA), VSA (FastVideo) |
| `tau` | Sol-Attn (적응형 tau) 선택에 사용할 스코어 분포 시그마의 임계값. | FLOAT | 아님 | 기본: 1.3, 최소: 0.0, 최대: 4.0, 단위: 0.05 |
| `keep_percent` | top-k (SLA) 선택에서 각 쿼리 블록이 정확히 유지할 키 블록의 비율. | FLOAT | 아님 | 기본: 10.0, 최소: 0.5, 최대: 95.0, 단위: 0.5 |
| `start_percent` | 모델이 밀집형 어텐션을 사용할 스케줄의 시작 비율. | FLOAT | 아님 | 기본: 0.2, 최소: 0.0, 최대: 1.0, 단위: 0.01 |
| `end_percent` | 모델이 밀집형 어텐션을 사용할 스케줄의 종료 비율. | FLOAT | 아님 | 기본: 1.0, 최소: 0.0, 최대: 1.0, 단위: 0.01 |
| `dense_blocks` | 항상 밀집형 어텐션을 실행하는 트랜스포머 블록을 나타내는 문자열. | STRING | 아님 | 기본: "" |
| `min_tokens` | 모델이 밀집형 어텐션을 사용할 시퀀스의 토큰 수의 최소값. | INT | 아님 | 기본: 12288, 최소: 0, 최대: 1 &lt;&lt; 20, 단위: 512 |
| `extra_tokens` | 각 쿼리 블록이 선택된 블록 이상으로 어텐션할 최고 점수 토큰의 수. | INT | 아님 | 기본: 256, 최소: 0, 최대: 256, 단위: 64 |
| `sink_conditioning` | sink conditioning에 사용할 MiniMax-H3 조건 행. | COMBO | 아님 | 옵션: exact_kv, exact_kv_and_rows, off |
| `verbose` | 상세 로깅을 활성화할지 여부. | BOOLEAN | 아님 | 기본: False |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model` | 블록-스파스 어텐션을 적용한 ComfyUI 모델. | MODEL |

### 주의사항

- `selection` 매개변수는 키 블록 선택 방법을 결정합니다. 옵션은 다음과 같습니다:
  - Sol-Attn (적응형 tau): 각 쿼리 블록이 적응형 임계값에 기반하여 선택된 키 블록 집합에 어텐션을 합니다.
  - top-k (SLA): 각 쿼리 블록이 정확히 유지할 키 블록의 비율을 고정합니다.
  - VSA (FastVideo): 각 쿼리 블록이 FastH3-VSA의 쿼드 블록 타일링과 코arse branch를 사용하여 정확히 유지할 비디오 쿼드 블록의 비율을 고정합니다.
- `dense_blocks` 매개변수는 항상 밀집형 어텐션을 실행하는 트랜스포머 블록을 지정할 수 있습니다.
- `min_tokens` 매개변수는 모델이 밀집형 어텐션을 사용할 시퀀스의 토큰 수의 최소값을 설정합니다.
- `extra_tokens` 매개변수는 각 쿼리 블록이 선택된 블록 이상으로 어텐션할 최고 점수 토큰의 수를 지정할 수 있습니다.
- `sink_conditioning` 매개변수는 sink conditioning에 사용할 MiniMax-H3 조건 행을 결정합니다.
- `verbose` 매개변수는 상세 로깅을 활성화합니다.
