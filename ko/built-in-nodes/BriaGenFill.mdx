이 노드는 Bria를 사용하여 이미지의 마스크된 영역 안에 객체나 장면을 생성합니다. 이미지와 마스크를 업로드하고, 프롬프트를 Bria 생성형 채우기 서비스로 전송한 뒤 작업이 완료될 때까지 기다리고, 편집된 이미지를 반환합니다. 이는 유료 API 작업입니다(요청당 US$0.0429).

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 편집할 입력 이미지입니다. | IMAGE | 예 | - |
| `mask` | 흰색 영역은 생성된 콘텐츠로 채워지고, 검은색 영역은 보존됩니다. 마스크는 전송 전에 이진화되므로 부분적으로 칠해진 영역도 흰색으로 간주됩니다. 이미지와 동일한 가로세로 비율을 가져야 합니다. | MASK | 예 | - |
| `prompt` | 마스크된 영역 안에 생성할 내용에 대한 설명입니다. 최소 1자 이상이어야 합니다. (기본값: "") | STRING | 예 | - |
| `negative_prompt` | 생성 결과에서 피할 내용을 설명하는 프롬프트입니다. 비워 두면 API로 전송되지 않습니다. (기본값: "") | STRING | 예 | - |
| `refine_prompt` | 더 나은 결과를 위해 프롬프트를 자동으로 조정합니다. 비활성화하면 작성한 프롬프트를 그대로 사용합니다. (기본값: true) | BOOLEAN | 예 | true<br />false |
| `seed` | 생성 프로세스용 시드입니다. (기본값: 42) | INT | 예 | 1  ~  2147483647 |
| `콘텐츠 검토` | 검열 설정입니다. "true"로 설정하면 아래 검열 옵션이 적용됩니다. (기본값: "false") | DYNAMIC_COMBO | 예 | "false"<br />"true" |

### 검열 입력 (`moderation` = "true"일 때)

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt_content_moderation` | 프롬프트에 콘텐츠 검열을 적용합니다. (기본값: false) | BOOLEAN | 아니오 | true<br />false |
| `visual_input_moderation` | 입력 이미지에 콘텐츠 검열을 적용합니다. (기본값: false) | BOOLEAN | 아니오 | true<br />false |
| `visual_output_moderation` | 출력 이미지에 콘텐츠 검열을 적용합니다. (기본값: false) | BOOLEAN | 아니오 | true<br />false |

**참고:** `prompt`는 비어 있으면 안 됩니다. `mask`는 `image`와 동일한 가로세로 비율을 가져야 합니다. 마스크는 50% 불투명도를 기준으로 이진화되므로 불투명도가 절반 미만으로 칠해진 영역은 무시됩니다. 이진화 후 마스크에 흰색 영역이 없으면 노드에서 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 생성된 콘텐츠로 마스크된 영역이 채워진 결과 이미지입니다. | IMAGE |
