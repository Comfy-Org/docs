Wan2VideoEditApi 노드는 Wan 2.7 모델을 사용하여 텍스트 지침, 참조 이미지 또는 스타일 변환을 기반으로 비디오를 편집합니다. 입력 비디오를 처리하고 해상도, 지속 시간 및 화면 비율과 같은 지정된 매개변수에 따라 새 비디오를 생성합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 편집에 사용할 모델입니다. | DYNAMIC_COMBO | 예 | `"wan2.7-videoedit"` |
| `video` | 편집할 비디오입니다. | VIDEO | 예 | - |
| `seed` | 생성에 사용할 시드입니다. (기본값: 0) | INT | 예 | 0 ~ 2147483647 |
| `audio_setting` | 'auto': 모델이 프롬프트를 기반으로 오디오를 다시 생성할지 여부를 결정합니다. 'origin': 입력 비디오의 원본 오디오를 유지합니다. (기본값: "auto") | COMBO | 예 | `"auto"`<br />`"origin"` |
| `watermark` | 결과물에 AI 생성 워터마크를 추가할지 여부입니다. (기본값: False) | BOOLEAN | 예 | - |

### wan2.7-videoedit 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 편집 지침 또는 스타일 변환 요구 사항입니다. (기본값: 빈 문자열) | STRING | 예 | - |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"720P"`<br />`"1080P"` |
| `ratio` | 화면 비율입니다. 변경하지 않으면 입력 비디오의 비율에 근사합니다. | COMBO | 예 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 출력 지속 시간(초)입니다. 'auto'는 입력 비디오의 지속 시간과 일치합니다. 특정 값을 지정하면 비디오 시작 부분부터 잘라냅니다. (기본값: "auto") | COMBO | 예 | `"auto"`<br />`"2"`<br />`"3"`<br />`"4"`<br />`"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"` |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 확장 가능한 슬롯: 편집을 안내하기 위해 0~4개의 이미지(`image1`...`image4`)를 연결합니다. wan2.7-videoedit 모델의 최대 개수는 4개입니다. | IMAGE | 아니요 | 0~4개 항목 |

**제약 사항:**
*   `prompt`는 최소 1자 이상 포함해야 합니다.
*   입력 `video`는 지속 시간이 2초에서 10초 사이여야 합니다.
*   `reference_images` 확장 가능한 슬롯은 최대 4개의 이미지를 허용합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 모델이 생성한 편집된 비디오입니다. | VIDEO |
