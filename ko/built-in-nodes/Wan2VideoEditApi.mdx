Wan 2.7 Video Edit 노드는 텍스트 지침, 참조 이미지 또는 스타일 변환을 사용하여 비디오를 편집합니다. 입력 비디오(및 참조 이미지)를 Wan 2.7 비디오 편집 서비스로 전송하고, 선택한 해상도, 가로세로 비율, 길이 설정에 따라 새로 생성된 비디오를 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 편집에 사용할 모델입니다. 각 옵션은 자체 하위 매개변수 세트를 제공합니다. | DYNAMIC_COMBO | 예 | `"wan2.7-videoedit"` |
| `video` | 편집할 비디오입니다. | VIDEO | 예 | - |
| `seed` | 생성에 사용할 시드입니다. (기본값: 0) | INT | 예 | 0 ~ 2147483647 |
| `audio_setting` | 'auto': 모델이 프롬프트에 따라 오디오를 재생성할지 결정합니다. 'origin': 입력 비디오의 원본 오디오를 보존합니다. (기본값: "auto") | COMBO | 예 | `"auto"`<br />`"origin"` |
| `watermark` | 결과에 AI 생성 워터마크를 추가할지 여부입니다. (기본값: False) | BOOLEAN | 예 | - |

### wan2.7-videoedit 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 편집 지침 또는 스타일 변환 요구 사항입니다. (기본값: 빈 문자열) | STRING | 예 | - |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"720P"`<br />`"1080P"` |
| `ratio` | 가로세로 비율입니다. 변경하지 않으면 입력 비디오 비율에 가깝게 설정됩니다. | COMBO | 예 | `"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:3"`<br />`"3:4"` |
| `duration` | 출력 길이(초)입니다. 'auto'는 입력 비디오 길이와 일치합니다. 특정 값을 지정하면 비디오 시작부터 잘라냅니다. (기본값: "auto") | COMBO | 예 | `"auto"`<br />`"2"`<br />`"3"`<br />`"4"`<br />`"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"` |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 확장 가능한 슬롯: 편집을 안내하기 위해 0~4개의 이미지(`image1`...`image4`)를 연결합니다. 이미지 개수 제한은 wan2.7-videoedit 모델의 경우 4개입니다. | IMAGE | 아니오 | 0 ~ 4개 항목 |

**제약 사항:**
*   `audio_setting` 및 `watermark`는 고급 옵션입니다.
*   `prompt`는 최소 1자 이상이어야 합니다.
*   입력 `video`의 길이는 2초에서 10초 사이여야 합니다.
*   `reference_images` 확장 가능한 슬롯은 최대 4개의 이미지를 허용합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 모델이 생성한 편집된 비디오입니다. | VIDEO |
