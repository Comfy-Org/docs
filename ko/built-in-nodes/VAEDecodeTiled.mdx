VAEDecodeTiled 노드는 큰 이미지를 효율적으로 처리하기 위해 타일 방식으로 잠재 표현을 이미지로 디코딩합니다. 메모리 사용량을 관리하면서 이미지 품질을 유지하기 위해 입력을 더 작은 타일로 처리합니다. 또한 이 노드는 부드러운 전환을 위해 시간적 프레임을 오버랩이 있는 청크로 처리하여 비디오 VAE를 지원합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `잠재 데이터` | 이미지로 디코딩할 잠재 표현입니다 | LATENT | 예 | - |
| `vae` | 잠재 샘플을 디코딩하는 데 사용되는 VAE 모델입니다 | VAE | 예 | - |
| `타일 크기` | 처리할 각 타일의 크기입니다(기본값: 512) | INT | 예 | 64-4096 (단계: 32) |
| `겹침` | 인접한 타일 간의 오버랩 양입니다(기본값: 64) | INT | 예 | 0-4096 (단계: 32) |
| `시간 크기` | 비디오 VAE에만 사용됩니다: 한 번에 디코딩할 프레임 수입니다(기본값: 64) | INT | 예 | 8-4096 (단계: 4) |
| `시간 겹침` | 비디오 VAE에만 사용됩니다: 오버랩할 프레임 수입니다(기본값: 8) | INT | 예 | 4-4096 (단계: 4) |

**참고:** `tile_size`, `overlap`, `temporal_size`, `temporal_overlap` 입력은 고급 설정으로 표시됩니다.

**참고:** 노드는 오버랩 값이 실제 한계를 초과하면 자동으로 조정합니다. `tile_size`가 `overlap`의 4배보다 작으면 오버랩은 타일 크기의 1/4로 줄어듭니다. 마찬가지로 `temporal_size`가 `temporal_overlap`의 2배보다 작으면 시간적 오버랩은 절반으로 줄어듭니다. 또한 이 노드는 공간 및 시간 차원 모두에 대해 타일 및 오버랩 크기를 계산할 때 VAE의 내부 압축 비율을 고려합니다. 입력 잠재 표현이 중첩된 잠재 표현 배치인 경우, 배치의 첫 번째 항목만 디코딩됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `IMAGE` | 잠재 표현에서 생성된 디코딩된 이미지입니다. 비디오 잠재 표현을 디코딩할 때 출력은 이미지 프레임 시퀀스입니다. | IMAGE |
