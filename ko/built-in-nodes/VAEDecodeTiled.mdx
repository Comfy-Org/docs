VAEDecodeTiled 노드는 타일 방식으로 잠재 표현을 이미지로 디코딩하여 대형 이미지를 효율적으로 처리합니다. 메모리 사용을 관리하면서 이미지 품질을 유지하기 위해 입력을 더 작은 타일로 나누어 처리합니다. 또한 이 노드는 시간적 프레임을 겹침(overlap)과 함께 청크 단위로 처리하여 비디오 VAE를 지원하며, 부드러운 전환을 구현합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `잠재 데이터` | 이미지로 디코딩될 잠재 표현 | LATENT | 예 | - |
| `vae` | 잠재 샘플 디코딩에 사용되는 VAE 모델 | VAE | 예 | - |
| `타일 크기` | 처리에 사용되는 각 타일의 크기 (기본값: 512) | INT | 예 | 64-4096 (step: 32) |
| `겹침` | 인접한 타일 간의 겹침 크기 (기본값: 64) | INT | 예 | 0-4096 (step: 32) |
| `시간 크기` | 비디오 VAE 전용: 한 번에 디코딩할 프레임 수 (기본값: 64) | INT | 예 | 8-4096 (step: 4) |
| `시간 겹침` | 비디오 VAE 전용: 겹칠 프레임 수 (기본값: 8) | INT | 예 | 4-4096 (step: 4) |

**참고:** 노드는 겹침 값이 실질적인 한도를 초과하는 경우 이를 자동으로 조정합니다. `tile_size`가 `overlap`의 4배 미만이면 겹침은 타일 크기의 4분의 1로 줄어듭니다. 마찬가지로 `temporal_size`가 `temporal_overlap`의 2배 미만이면 시간적 겹침은 절반으로 줄어듭니다. 또한 노드는 공간 및 시간 차원 모두에 대해 타일과 겹침 크기를 계산할 때 VAE의 내부 압축 비율을 고려합니다. 입력 잠재 표현이 중첩 배치인 경우 배치의 첫 번째 항목만 디코딩됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `IMAGE` | 잠재 표현에서 생성된 디코딩된 이미지 또는 이미지들. 비디오 잠재 표현을 디코딩할 때 출력은 일련의 이미지 프레임입니다. | IMAGE |
