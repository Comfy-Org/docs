Preview Audio 노드는 오디오를 출력 디렉토리에 저장하지 않고 ComfyUI 인터페이스에서 직접 들을 수 있게 해주는 노드입니다. 이 노드는 오디오 데이터를 입력으로 받아 해당 데이터가 존재하는지 확인한 후, 임시 오디오 플레이어를 표시하여 결과를 들을 수 있도록 데이터를 그대로 전달합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `오디오` | 미리 볼 오디오 데이터입니다. 입력이 None인 경우 노드가 ValueError를 발생시킵니다. 이는 소스 비디오에 오디오 트랙이 없을 때 발생할 수 있습니다. | AUDIO | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `audio` | 입력에서 변경 없이 그대로 전달된 오디오 데이터입니다. | AUDIO |
| `ui` | 오디오 미리 보기를 위해 인터페이스에 표시되는 오디오 플레이어 위젯입니다. | UI |
