Kling Lip Sync Text to Video 노드는 비디오 파일의 입 모양 움직임을 텍스트 프롬프트와 일치하도록 동기화합니다. 입력 비디오를 받아 캐릭터의 입 움직임이 제공된 텍스트에 맞춰 정렬된 새 비디오를 생성합니다. 이 노드는 음성 합성을 사용하여 자연스러운 발화 동기화를 만듭니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `비디오` | 립 동기화를 위한 입력 비디오 파일입니다. 비디오는 높이/너비가 720px에서 1920px 사이여야 하고, 길이가 2초에서 10초 사이여야 하며, 100MB 이하여야 합니다. | VIDEO | 예 | - |
| `텍스트` | 립싱크 비디오 생성을 위한 텍스트 콘텐츠입니다. mode가 text2video일 때 필수입니다. 최대 길이는 120자입니다. | STRING | 예 | - |
| `음성` | 립싱크 오디오용 음성 선택(기본값: "Melody")입니다. 영어 및 중국어 음성 옵션을 포함합니다. | COMBO | 아니요 | "Melody"<br />"Sunny"<br />"Sage"<br />"Ace"<br />"Blossom"<br />"Peppy"<br />"Dove"<br />"Shine"<br />"Anchor"<br />"Lyric"<br />"Tender"<br />"Siren"<br />"Zippy"<br />"Bud"<br />"Sprite"<br />"Candy"<br />"Beacon"<br />"Rock"<br />"Titan"<br />"Grace"<br />"Helen"<br />"Lore"<br />"Crag"<br />"Prattle"<br />"Hearth"<br />"The Reader"<br />"Commercial Lady"<br />"阳光少年"<br />"懂事小弟"<br />"运动少年"<br />"青春少女"<br />"温柔小妹"<br />"元气少女"<br />"阳光男生"<br />"幽默小哥"<br />"文艺小哥"<br />"甜美邻家"<br />"温柔姐姐"<br />"职场女青"<br />"活泼男童"<br />"俏皮女童"<br />"稳重老爸"<br />"温柔妈妈"<br />"严肃上司"<br />"优雅贵妇"<br />"慈祥爷爷"<br />"唠叨爷爷"<br />"唠叨奶奶"<br />"和蔼奶奶"<br />"东北老铁"<br />"重庆小伙"<br />"四川妹子"<br />"潮汕大叔"<br />"台湾男生"<br />"西安掌柜"<br />"天津姐姐"<br />"新闻播报男"<br />"译制片男"<br />"撒娇女友"<br />"刀片烟嗓"<br />"乖巧正太" |
| `음성 속도` | 말하기 속도입니다. 유효 범위: 0.8~2.0이며 소수점 첫째 자리까지 정확합니다. (기본값: 1) | FLOAT | 아니요 | 0.8-2.0 |

**비디오 요구 사항:**

- 비디오 파일은 100MB보다 크지 않아야 합니다.
- 높이/너비는 720px에서 1920px 사이여야 합니다.
- 길이는 2초에서 10초 사이여야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 립싱크된 오디오가 포함된 생성 비디오 | VIDEO |
| `video_id` | 생성된 비디오의 고유 식별자 | STRING |
| `duration` | 생성된 비디오의 길이 정보 | STRING |
