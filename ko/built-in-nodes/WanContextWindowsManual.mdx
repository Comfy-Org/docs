WAN Context Windows (Manual) 노드를 사용하면 Wan 스타일 비디오 모델용 컨텍스트 창을 수동으로 구성할 수 있습니다. 이 노드는 샘플링 중에 이러한 설정을 적용하여 모델이 비디오를 처리하는 동안 창 길이, 겹침, 스케줄링 및 융합 방법을 제어할 수 있게 합니다. 컨텍스트 길이와 겹침은 실제 프레임 단위로 지정되며, 모델의 2D 처리를 위해 내부적으로 변환됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델` | 샘플링 중에 컨텍스트 창을 적용할 모델입니다. | MODEL | 예 | - |
| `컨텍스트 길이` | 실제 프레임 단위의 컨텍스트 창 길이입니다. 4*n + 1 형식이어야 합니다(기본값: 81). | INT | 예 | 1 ~ 16384 (MAX_RESOLUTION), step 4 |
| `컨텍스트 오버랩` | 실제 프레임 단위의 컨텍스트 창 겹침입니다(기본값: 30). | INT | 예 | 0 or higher |
| `컨텍스트 스케줄` | 컨텍스트 창에 대한 단계 종속 스케줄링 알고리즘입니다(기본값: "uniform_standard"). | COMBO | 예 | `"static_standard"`<br />`"uniform_standard"`<br />`"uniform_looped"`<br />`"batched"` |
| `컨텍스트 스트라이드` | 컨텍스트 창의 스트라이드입니다. uniform 스케줄에만 적용됩니다(기본값: 1). | INT | 예 | 1 or higher |
| `폐쇄 루프` | 컨텍스트 창 루프를 닫을지 여부입니다. looped 스케줄에만 적용됩니다(기본값: False). | BOOLEAN | 예 | - |
| `퓨즈 방법` | 컨텍스트 창을 융합하는 데 사용할 방법입니다(기본값: "pyramid"). | COMBO | 예 | `"pyramid"`<br />`"gaussian"`<br />`"average"`<br />`"overlap"` |
| `freenoise` | FreeNoise 노이즈 셔플링을 적용할지 여부입니다. 창 혼합을 개선합니다(기본값: True). | BOOLEAN | 예 | - |
| `retain_first_frame` | 모든 컨텍스트 창에서 첫 번째 I2V 프레임을 유지합니다(초기 참조를 유지하는 데 도움이 될 수 있음)(기본값: False). | BOOLEAN | 예 | - |
| `split_conds_to_windows` | 여러 컨디셔닝(ConditionCombine으로 생성된)을 지역 인덱스를 기준으로 각 창에 분할할지 여부입니다(기본값: False). | BOOLEAN | 예 | - |

**참고:** `context_stride`는 uniform 스케줄에만 영향을 주며, `closed_loop`는 looped 스케줄에만 적용됩니다. 컨텍스트 길이와 겹침은 실제 프레임 단위로 지정되며, 처리 중에 자동으로 변환되고 최소 유효 값으로 제한됩니다(`context_length`는 ((length - 1) / 4) + 1이 되고, `context_overlap`은 overlap / 4가 됩니다). `context_length`는 4*n + 1 형식을 따라야 합니다. `retain_first_frame`은 이미지-투-비디오(image-to-video) 용도로 사용됩니다. `split_conds_to_windows`는 ConditionCombine 노드로 생성된 여러 컨디셔닝을 필요로 합니다. `fuse_method` 매개변수는 "pyramid" 외에도 여러 옵션을 포함합니다.
