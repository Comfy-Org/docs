이 노드는 MoGe 포인트 맵을 3D 메시로 변환합니다. MoGe 깊이 추정 노드에서 생성된 지오메트리 데이터를 가져와 UV 좌표와 선택적 텍스처를 포함하는 메시로 삼각분할합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `moge_geometry` | 포인트 맵, 깊이, 선택적으로 원본 이미지를 포함하는 MoGe 지오메트리 데이터입니다. | MOGE_GEOMETRY | 예 | N/A |
| `batch_index` | 배치된 MoGe 지오메트리 중 메시로 변환할 이미지를 지정합니다. 이미지별 정점 수가 다르기 때문에 배치를 단일 MESH로 쌓을 수 없습니다(기본값: 0). | INT | 예 | 0  ~  4096 |
| `decimation` | 정점 스트라이드입니다. 1 = 전체 해상도(기본값: 1)입니다. | INT | 예 | 1  ~  8 |
| `discontinuity_threshold` | 3x3 깊이 범위가 이 비율을 초과하는 픽셀을 제거합니다. 0 = 끔(기본값: 0.04)입니다. | FLOAT | 예 | 0.0  ~  1.0 |
| `texture` | 원본 이미지를 baseColor 텍스처로 전달합니다(기본값: True). | BOOLEAN | 예 | True/False |

참고: `batch_index`는 입력 `moge_geometry`의 배치 크기보다 작아야 하며, 범위를 벗어난 인덱스를 선택하면 오류가 발생합니다. 입력에는 points 출력이 포함되어야 하며, 그렇지 않으면 노드에서 오류가 발생합니다. 삼각분할이 빈 메시를 생성하면 노드에서 오류가 발생합니다 — `discontinuity_threshold`를 0으로 설정하면 깊이 불연속성 필터가 비활성화됩니다. 출력 메시는 glTF 좌표로 변환됩니다. 원근 MoGe 데이터(X 오른쪽, Y 아래, Z 앞)는 glTF에 맞게 뒤집히고(Y 위, Z 뒤), 파노라마 데이터(내재 매개변수가 없는 지오메트리)는 이에 따라 회전하며 와인딩이 보정됩니다. `texture`가 활성화되면 `moge_geometry`의 원본 이미지가 baseColor 텍스처로 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `MESH` | 정점, 면, UV 좌표, 그리고 원본 이미지의 선택적 baseColor 텍스처를 포함하는 3D 메시입니다. | MESH |
