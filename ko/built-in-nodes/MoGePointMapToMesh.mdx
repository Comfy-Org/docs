이 노드는 MoGe 포인트 맵을 3D 메시로 변환합니다. MoGe 깊이 추정 노드에서 생성된 지오메트리 데이터를 가져와 UV 좌표와 선택적 텍스처가 포함된 메시로 삼각분할합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `moge_geometry` | 포인트 맵, 깊이, 그리고 선택적으로 소스 이미지를 포함하는 MoGe 지오메트리 데이터입니다. | MOGE_GEOMETRY | 예 | N/A |
| `batch_index` | 배치된 MoGe 지오메트리에서 메시로 변환할 이미지를 지정합니다. 이미지마다 정점 수가 다르므로 배치를 단일 MESH로 쌓을 수 없습니다 (기본값: 0). | INT | 예 | 0 ~ 4096 |
| `decimation` | 정점 스트라이드입니다. 1이면 전체 해상도입니다 (기본값: 1). | INT | 예 | 1 ~ 8 |
| `discontinuity_threshold` | 3x3 깊이 범위가 이 비율을 초과하는 픽셀을 제거합니다. 0은 비활성화를 의미합니다 (기본값: 0.04). | FLOAT | 예 | 0.0 ~ 1.0 |
| `texture` | 소스 이미지를 baseColor 텍스처로 전달합니다 (기본값: True). | BOOLEAN | 예 | True/False |

참고: `batch_index`는 입력 `moge_geometry`의 배치 크기보다 작아야 합니다. 범위를 벗어난 인덱스를 선택하면 오류가 발생합니다. 삼각분할 결과 메시가 비어 있으면 노드가 오류를 발생시킵니다. `discontinuity_threshold`를 0으로 설정하면 깊이 불연속성 필터가 비활성화됩니다. 출력 메시는 glTF 좌표계로 변환됩니다. 원근 MoGe 데이터(X 오른쪽, Y 아래, Z 앞)는 glTF 좌표계(Y 위, Z 뒤)에 맞게 반전되고, 파노라마 데이터는 그에 따라 회전됩니다. `texture`가 활성화되면 `moge_geometry`의 소스 이미지가 baseColor 텍스처로 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `MESH` | 소스 이미지에서 가져온 정점, 면, UV 좌표, 그리고 선택적 baseColor 텍스처를 포함하는 3D 메시입니다. | MESH |
