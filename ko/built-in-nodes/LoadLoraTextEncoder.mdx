단일 노드에서 CLIP 텍스트 인코더에 LoRA 스택을 적용합니다. `loras`의 각 행은 LoRA 파일, 강도, 켜기/끄기 스위치를 가지며, 행은 위에서 아래로 적용되므로 각 행은 위 행의 결과를 패치합니다. 텍스트 인코더를 변경하는 LoRA 파일은 일반적으로 모델에도 적용되므로, 이 노드는 보통 동일한 행을 사용하는 Load LoRA (Model)와 함께 사용됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | LoRA가 적용될 CLIP 텍스트 인코더입니다. | CLIP | 예 | - |
| `loras` | 텍스트 인코더에 행 순서(`loras.0`, `loras.1` 등)로 적용되는 확장 가능한 LoRA 그룹입니다. LoRA당 한 행을 추가하세요. 각 행은 파일, 강도, 켜기/끄기 스위치를 가집니다. | DYNAMIC_GROUP | 예 | 1~20행 |

### `loras` 행 필드

모든 행은 다음 필드를 반복하며, 제출된 각 행에서 각 필드는 필수입니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `lora_name` | 적용할 LoRA 파일의 이름입니다. | COMBO | 예 | 여러 옵션 사용 가능 |
| `strength` | 이 LoRA를 텍스트 인코더에 얼마나 강하게 적용할지 지정합니다. `0`은 끄고, 음수 값은 효과를 반전시킵니다. (기본값: 1.0) | FLOAT | 예 | -100~100 (단계 0.01) |
| `enabled` | 파일이나 강도를 변경하지 않고 이 LoRA를 건너뛰려면 끕니다. (기본값: true) | BOOLEAN | 예 | false / true |

### 매개변수 제약

- **행 수:** 최소 하나의 행을 제출해야 하며 최대 20개 행까지 허용되므로, 가장 높은 행 인덱스는 19입니다.
- **건너뛴 행:** 파일이 비어 있거나, `enabled`가 꺼져 있거나, `strength`가 `0`일 때 해당 행은 건너뜁니다. 음수 strength는 건너뛰지 않고 그대로 전달됩니다.
- **행 순서:** 행은 나타나는 순서대로 적용되며, 각 행은 이전 행에서 반환된 텍스트 인코더에서 시작합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `CLIP` | 건너뛰지 않은 LoRA 행이 적용된 CLIP 텍스트 인코더입니다. | CLIP |
