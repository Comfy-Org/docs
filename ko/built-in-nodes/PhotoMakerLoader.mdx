PhotoMakerLoader 노드는 사용 가능한 모델 파일에서 PhotoMaker 모델을 로드합니다. 선택한 파일을 읽고 ID 인코더 가중치를 로드하며, 신원 기반 이미지 생성 작업에 사용할 수 있도록 PhotoMaker ID 인코더를 준비합니다. 이 노드는 실험적(experimental)으로 표시되어 있으며 테스트 목적으로 사용됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `포토메이커 파일명` | 로드할 PhotoMaker 모델 파일의 이름입니다. 사용 가능한 옵션은 `photomaker` 폴더에 있는 모델 파일에 따라 결정됩니다. | COMBO | 예 | 여러 옵션 사용 가능 (`photomaker` 폴더에서 동적으로 채워짐) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `photomaker_model` | ID 인코더를 포함하여 로드된 PhotoMaker 모델로, 신원 인코딩 작업에 사용할 준비가 되어 있습니다. | PHOTOMAKER |
