Tripo: Retopology는 이전 Tripo 노드에서 생성된 고폴리곤 3D 모델을 가져와 깨끗한 토폴로지를 가진 저폴리곤 버전으로 재구성합니다. 이 노드는 모델을 Tripo 리토폴로지 서비스에 제출하고 작업이 끝날 때까지 기다린 다음, 완성된 모델을 다운로드하고 다른 Tripo 노드에서 사용할 수 있도록 작업 ID를 노출합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | 원본 고폴리곤 모델의 작업 ID입니다. Tripo 생성 노드의 모델 작업 ID 또는 Tripo: Segment Model의 세그먼트 작업 ID를 받습니다. | STRING | 예 | Tripo 작업 ID |
| `face_limit` | 목표 면 수: 500-20,000개의 삼각형 또는 500-10,000개의 사각형입니다. -1은 Tripo가 선택하도록 합니다. (기본값: -1) | INT | 예 | -1 (자동)<br />500~20,000 (삼각형)<br />500~10,000 (사각형) |
| `quad` | 사각형 메시 출력입니다. Tripo는 사각형 메시를 FBX로 제공하므로 결과는 FBX 출력으로 나오고 GLB 출력은 비어 있게 됩니다. (기본값: False) | BOOLEAN | 예 | True<br />False (기본값) |
| `bake` | 소스 텍스처를 저폴리곤 메시에 베이크합니다. (기본값: True) | BOOLEAN | 아니요 | True (기본값)<br />False |
| `part_names` | Tripo: Segment Model에서 가져온 쉼표로 구분된 파트 이름입니다. 비어 있으면 전체 모델을 처리합니다. (기본값: "") | STRING | 아니요 | 모델 파트 이름 또는 비어 있음 |

참고: `face_limit`이 -1로 설정되면 Tripo가 면 수를 자동으로 결정합니다. `quad`가 활성화되면 최대 면 제한은 20,000개의 삼각형 대신 10,000개의 사각형이며, 결과는 FBX로 제공됩니다(GLB 출력은 비어 있게 됩니다). `part_names`가 비어 있으면 전체 모델이 처리됩니다. `face_limit`이 -1이 아니면서 허용 범위를 벗어나면 노드가 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model_file` | 완료된 모델 파일을 식별하는 하위 호환 출력입니다. 최신 워크플로에서는 대신 GLB 또는 FBX 출력을 사용해야 합니다. | STRING |
| `model task_id` | 완료된 리토폴로지 결과의 작업 ID입니다. 다른 Tripo 노드에 전달하여 이 모델을 참조할 수 있습니다. | STRING |
| `GLB` | GLB 형식의 리토폴로지된 저폴리곤 모델입니다. `quad`가 활성화되면 비어 있습니다. | GLB FILE |
| `FBX` | FBX 형식의 리토폴로지된 저폴리곤 모델입니다. `quad`가 활성화된 경우에만 채워집니다. | FBX FILE |
