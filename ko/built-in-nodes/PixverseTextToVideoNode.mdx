PixVerse API를 사용하여 텍스트 프롬프트로부터 비디오를 생성합니다. 이 노드를 사용하면 비디오의 형태, 품질, 길이, 모션 스타일을 제어할 수 있으며, 선택적으로 저장된 스타일 템플릿을 적용할 수 있습니다. 요청을 제출하고 생성이 완료될 때까지 기다린 뒤 완성된 비디오를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `프롬프트` | 비디오 생성을 위한 프롬프트 (기본값: "") | STRING | 예 | 최소 1자 이상 포함해야 합니다 |
| `화면 비율` | 생성된 비디오의 화면 비율 | COMBO | 예 | `"16:9"`<br />`"9:16"`<br />`"1:1"` |
| `품질` | 비디오 품질 설정 (기본값: "540p") | COMBO | 예 | `"540p"`<br />`"1080p"` |
| `길이(초)` | 생성된 비디오의 길이(초) | COMBO | 예 | `"5"`<br />`"10"` |
| `모션 모드` | 비디오 생성을 위한 모션 스타일 | COMBO | 예 | `"normal"`<br />`"fast"` |
| `시드` | 비디오 생성용 시드 (기본값: 0) | INT | 예 | 0 ~ 2147483647 |
| `부정 프롬프트` | 이미지에서 원하지 않는 요소에 대한 선택적 텍스트 설명 (기본값: "") | STRING | 아니요 | - |
| `PixVerse 템플릿` | 생성 스타일에 영향을 주기 위한 선택적 템플릿으로, PixVerse Template 노드에서 생성됩니다 | CUSTOM | 아니요 | - |

**참고:** `prompt`는 최소 1자 이상 포함해야 합니다. 1080p 품질을 선택하면 모션 모드는 자동으로 `normal`로 설정되고 길이는 5초로 제한됩니다. 5초 이외의 길이에서는 모션 모드도 자동으로 `normal`로 설정됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오 파일 | VIDEO |
