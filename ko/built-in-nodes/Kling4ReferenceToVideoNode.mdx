Kling 4.0 모델로 참조 이미지와 참조 동영상으로부터 오디오를 포함한 동영상을 생성합니다. 참조 요소는 피사체, 스타일, 움직임을 결정하며, 선택적인 첫 프레임과 마지막 프레임은 클립의 시작과 끝을 고정합니다. 샷 전체에서 캐릭터나 장면의 일관성을 유지하면서 프롬프트에 동작을 설명할 때 사용하세요.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 모델 선택기입니다. `"kling-4.0"`은 최대 1080p, 30초 클립 및 마지막 프레임을 지원합니다. `"kling-4.0-flash"`는 720p 및 20초로 제한되며 `last_frame` 입력이 없습니다. 모델을 선택하면 아래에 해당 입력이 표시됩니다. | DYNAMIC_COMBO | 예 | `"kling-4.0"`<br />`"kling-4.0-flash"` |

### kling-4.0 입력

`model`이 `"kling-4.0"`로 설정된 경우 이러한 입력이 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 참조 이미지용 확장 가능한 슬롯으로, 최대 10개입니다. 프롬프트에서 연결 순서대로 `@Image1`, `@Image2` 등으로 참조하세요. | AUTOGROW | 아니요 | 0~10개 이미지 |
| `reference_videos` | 참조 동영상용 확장 가능한 슬롯으로, 최대 5개입니다. 프롬프트에서 `@Video1`, `@Video2` 등으로 참조하세요. 각 동영상 및 모든 동영상을 합친 길이는 3~30초여야 합니다. | AUTOGROW | 아니요 | 0~5개 동영상 |
| `first_frame` | 동영상이 시작되는 선택적 프레임입니다. 참조 이미지와 함께 10개 이미지 제한에 포함됩니다. | IMAGE | 아니요 | - |
| `last_frame` | 동영상이 끝나는 선택적 프레임입니다. 참조 이미지와 함께 10개 이미지 제한에 포함됩니다. | IMAGE | 아니요 | - |
| `prompt` | 생성할 동영상에 대한 설명입니다. 입력은 `@Image1`, `@Image2` 등과 `@Video1`, `@Video2` 등으로 참조하세요. | STRING | 예 | 1~26000자 |
| `resolution` | 출력 동영상의 해상도입니다. 기본값: `"720p"`. | COMBO | 예 | `"720p"`<br />`"1080p"` |
| `aspect_ratio` | 출력 동영상의 화면 비율입니다. `"adaptive"`는 프롬프트를 따르고, 그다음 첫 프레임 또는 참조 동영상을 따르며, 그 외의 경우에는 16:9로 대체됩니다. 기본값: `"adaptive"`. | COMBO | 예 | `"adaptive"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `duration` | 생성되는 동영상의 길이(초)입니다. 기본값: 5. | INT | 예 | 3~30 |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |

### kling-4.0-flash 입력

`model`이 `"kling-4.0-flash"`로 설정된 경우 이러한 입력이 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 참조 이미지용 확장 가능한 슬롯으로, 최대 10개입니다. 프롬프트에서 연결 순서대로 `@Image1`, `@Image2` 등으로 참조하세요. | AUTOGROW | 아니요 | 0~10개 이미지 |
| `reference_videos` | 참조 동영상용 확장 가능한 슬롯으로, 최대 5개입니다. 프롬프트에서 `@Video1`, `@Video2` 등으로 참조하세요. 각 동영상 및 모든 동영상을 합친 길이는 3~20초여야 합니다. | AUTOGROW | 아니요 | 0~5개 동영상 |
| `first_frame` | 동영상이 시작되는 선택적 프레임입니다. 참조 이미지와 함께 10개 이미지 제한에 포함됩니다. | IMAGE | 아니요 | - |
| `prompt` | 생성할 동영상에 대한 설명입니다. 입력은 `@Image1`, `@Image2` 등과 `@Video1`, `@Video2` 등으로 참조하세요. | STRING | 예 | 1~26000자 |
| `resolution` | 출력 동영상의 해상도입니다. Flash는 720p만 렌더링합니다. 기본값: `"720p"`. | COMBO | 예 | `"720p"` |
| `aspect_ratio` | 출력 동영상의 화면 비율입니다. `"adaptive"`는 프롬프트를 따르고, 그다음 첫 프레임 또는 참조 동영상을 따르며, 그 외의 경우에는 16:9로 대체됩니다. 기본값: `"adaptive"`. | COMBO | 예 | `"adaptive"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `duration` | 생성되는 동영상의 길이(초)입니다. 기본값: 5. | INT | 예 | 3~20 |
| `seed` | 시드는 노드를 다시 실행할지 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0~2147483647 |

**제약 사항 및 동작:**

* 이미지는 참조 이미지, 첫 프레임, 마지막 프레임을 포함하여 총 10개로 제한됩니다.
* 모든 이미지는 최소 300x300픽셀이어야 하며, 화면 비율은 2:5에서 5:2 사이여야 합니다.
* 각 참조 동영상은 3~30초(`kling-4.0-flash`의 경우 3~20초)여야 하며, 최소 700x700, 최대 4553x4553픽셀이고, 총 8,294,400픽셀 이하여야 하며, 화면 비율은 2:5에서 5:2 사이이고 프레임 속도는 최소 24fps여야 합니다. 모든 참조 동영상을 합친 길이도 동일한 제한을 초과해서는 안 됩니다.
* 프롬프트에서 `@ImageN` 또는 `@VideoN`을 언급했는데 해당 종류의 입력이 N개 미만으로 연결되어 있으면 오류가 발생합니다.
* 첫 프레임 또는 마지막 프레임이 연결되면 노드는 동영상이 해당 프레임에서 정확히 시작하거나 끝나도록 하는 지시문을 추가합니다.
