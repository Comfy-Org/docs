Kling 4.0 모델을 사용하여 참조 이미지와 참조 비디오로부터 오디오를 포함한 비디오를 생성합니다. 참조는 피사체, 스타일 및 모션을 제어하며, 선택적인 첫 프레임과 마지막 프레임은 클립의 시작과 끝을 고정합니다. 프롬프트에서 동작을 설명하면서 한 샷 전체에서 캐릭터나 장면의 일관성을 유지하는 데 사용할 수 있습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 모델 선택기입니다. `"kling-4.0"`만 사용할 수 있으며, 이를 선택하면 아래 입력이 표시됩니다. | DYNAMIC_COMBO | 예 | `"kling-4.0"` |

### kling-4.0 입력

`model`이 `"kling-4.0"`으로 설정되면 다음 입력이 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 참조 이미지용 확장 가능한 슬롯이며 최대 10개입니다. 연결 순서에 따라 프롬프트에서 `@Image1`, `@Image2` 등으로 참조합니다. | AUTOGROW | 아니요 | 0 ~ 10 개 이미지 |
| `reference_videos` | 참조 비디오용 확장 가능한 슬롯이며 최대 5개입니다. 프롬프트에서 `@Video1`, `@Video2` 등으로 참조합니다. 각 비디오와 모든 비디오의 합계는 3~30초여야 합니다. | AUTOGROW | 아니요 | 0 ~ 5 개 동영상 |
| `first_frame` | 비디오가 시작되는 선택적 프레임입니다. 참조 이미지와 함께 10개 이미지 제한에 포함됩니다. | IMAGE | 아니요 | - |
| `last_frame` | 비디오가 끝나는 선택적 프레임입니다. 참조 이미지와 함께 10개 이미지 제한에 포함됩니다. | IMAGE | 아니요 | - |
| `prompt` | 생성할 비디오에 대한 설명입니다. 입력은 `@Image1`, `@Image2` 등과 `@Video1`, `@Video2` 등으로 참조합니다. | STRING | 예 | 1 ~ 26000 자 |
| `resolution` | 출력 비디오의 해상도입니다. 기본값: `"720p"`. | COMBO | 예 | `"720p"`<br />`"1080p"` |
| `aspect_ratio` | 출력 비디오의 화면 비율입니다. `"adaptive"`는 프롬프트를 따르고, 그다음 첫 프레임 또는 참조 비디오를 따르며, 그 외의 경우에는 16:9로 대체됩니다. 기본값: `"adaptive"`. | COMBO | 예 | `"adaptive"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"21:9"` |
| `duration` | 생성된 비디오의 길이(초)입니다. 기본값: 5. | INT | 예 | 3 ~ 30 |
| `seed` | 시드는 노드의 재실행 여부를 제어합니다. 시드와 관계없이 결과는 비결정적입니다. 기본값: 42. | INT | 예 | 0 ~ 2147483647 |

**제약 사항 및 동작:**

* 이미지는 참조 이미지, 첫 프레임, 마지막 프레임을 합산하여 총 10개로 제한됩니다.
* 모든 이미지는 최소 300x300픽셀이어야 하며, 화면 비율은 2:5에서 5:2 사이여야 합니다.
* 모든 참조 비디오는 3~30초 길이여야 하고, 최소 700x700픽셀, 최대 4553x4553픽셀이어야 하며, 총 8,294,400픽셀을 초과할 수 없습니다. 화면 비율은 2:5에서 5:2 사이여야 하고 프레임 속도는 최소 24fps여야 합니다. 모든 참조 비디오의 합계 길이는 30초를 초과할 수 없습니다.
* 프롬프트에서 `@ImageN` 또는 `@VideoN`을 언급했지만 해당 종류의 입력이 N개 미만으로 연결된 경우 오류가 발생합니다.
* 첫 프레임 또는 마지막 프레임이 연결되면 노드는 비디오가 정확히 해당 프레임에서 시작하거나 끝나도록 지시문을 추가합니다.
