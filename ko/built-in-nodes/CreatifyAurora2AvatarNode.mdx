Creatify Aurora 2.0 Avatar는 사진 한 장과 음성 또는 노래 클립을 말하기 또는 노래하는 비디오로 변환합니다. 비디오는 연결된 오디오와 길이가 같고 해당 오디오를 그대로 유지합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 애니메이션할 인물의 사진입니다. 각 변이 최소 256픽셀이고 가로세로 비율이 1:4에서 4:1 사이여야 하며, 비디오는 사진의 가로세로 비율을 유지합니다. | IMAGE | 예 | - |
| `audio` | 입 모양과 비디오 길이를 구동하는 음성 또는 노래입니다. 최대 60초이며, `"2k"`에서는 14초입니다. 시작된 1초 단위로 과금됩니다. | AUDIO | 예 | 최대 60초 |
| `resolution` | 출력 비디오의 해상도입니다(기본값: `"720p"`). | COMBO | 예 | `"480p"`<br />`"720p"`<br />`"1080p"`<br />`"2k"` |
| `text_prompt` | 샷의 장면, 카메라, 조명, 표정 또는 움직임입니다. 비워 두면 사진을 그대로 유지합니다(기본값: 빈 문자열). | STRING | 예 | 임의 텍스트 |
| `seed` | `seed`는 노드의 재실행 여부를 제어합니다. 결과는 `seed`와 관계없이 비결정적입니다(기본값: 42). | INT | 예 | 0 ~ 2147483647 |

**제약 사항:** 한 변이 256픽셀보다 작거나 가로세로 비율이 1:4에서 4:1을 벗어난 사진은 오류를 발생시킵니다. 선택한 해상도의 제한보다 긴 오디오는 거부됩니다. 일반적으로 60초이며, `"2k"`에서는 14초입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 연결된 오디오가 포함된 말하기 또는 노래 비디오입니다. | VIDEO |
