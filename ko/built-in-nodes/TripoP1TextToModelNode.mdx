Tripo P1 텍스트-투-3D. 이 노드는 Tripo P1 API를 사용하여 텍스트 설명으로부터 3D 모델을 생성합니다. 안정적인 토폴로지를 갖춘 로우폴리, 게임용 메시 생성에 최적화되어 있어 실시간 애플리케이션에 적합합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `출력 모드` | 생성된 모델에 형상만 포함할지, 색상/PBR 텍스처도 포함할지 제어합니다. "Geometry only"는 텍스처가 없는 메시를 반환합니다. "Textured"는 색상/PBR 맵을 추가하고 아래의 텍스처 옵션을 표시합니다. | DYNAMIC_COMBO | 예 | `"Geometry only"`<br />`"Textured"` |
| `프롬프트` | 생성하려는 3D 모델에 대한 텍스트 설명입니다. 최대 1024자입니다. 필수이며 비워 둘 수 없습니다. | STRING | 예 | 최대 1024자 |
| `네거티브 프롬프트` | 생성된 모델에 포함되지 않기를 원하는 항목에 대한 텍스트 설명입니다. 최대 255자입니다. 기본값: 설정되지 않음. | STRING | 아니오 | 최대 255자 |
| `이미지 시드` | 무작위성을 제어하는 데 사용되는 시드 값입니다. 기본값: 42. | INT | 아니오 | 0~2147483647 |
| `페이스 제한` | 목표 면 수, 48-20000. -1은 Tripo가 적응적으로 선택하도록 합니다. 기본값: -1. | INT | 아니오 | -1~20000 |
| `모델 시드` | 무작위성을 제어하는 데 사용되는 시드 값입니다. 기본값: 42. | INT | 아니오 | 0~2147483647 |
| `자동 크기 조정` | 출력을 실제 미터 단위에 가깝게 조정합니다. 기본값: False. | BOOLEAN | 아니오 | True / False |
| `UV 내보내기` | 생성 중 UV 펼치기를 수행합니다. 형상 전용 실행 속도를 높이려면 끄십시오. 기본값: True. | BOOLEAN | 아니오 | True / False |
| `지오메트리 압축` | meshopt 형상 압축(EXT_meshopt_compression)을 적용합니다. 파일은 더 작아지지만 ComfyUI의 3D 미리보기에서는 표시할 수 없으므로 편집 전에 압축을 해제하십시오. 기본값: False. | BOOLEAN | 아니오 | True / False |

### Geometry only 입력

`output_mode`가 `"Geometry only"`로 설정된 경우 추가 입력을 사용할 수 없습니다. 이 모드에서는 텍스처 관련 매개변수가 Tripo로 전송되지 않습니다.

### Textured 입력

이 입력은 `output_mode`가 `"Textured"`로 설정된 경우에만 나타납니다.

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `pbr` | PBR 맵을 포함합니다. 켜면 기본 텍스처도 강제로 켜집니다. 기본값: True. | BOOLEAN | 예 | True / False |
| `texture_quality` | 텍스처 품질 사전 설정입니다. detailed = HD 텍스처, extreme = 8K Ultra 텍스처. 기본값: `"standard"`. | COMBO | 예 | `"standard"`<br />`"detailed"`<br />`"extreme"` |
| `texture_seed` | 텍스처 생성을 위한 시드 값으로, 무작위성을 제어하는 데 사용됩니다. 기본값: 42. | INT | 예 | 0~2147483647 |

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `model_file` | 생성된 모델 파일 이름으로, 하위 호환성을 위해서만 유지됩니다. | STRING |
| `model task_id` | 모델 생성 요청의 고유 작업 ID입니다. | MODEL_TASK_ID |
| `GLB` | 생성된 3D 모델(GLB 형식)입니다. | FILE3DGLB |
