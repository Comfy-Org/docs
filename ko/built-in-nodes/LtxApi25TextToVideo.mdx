LTX 2.5 Text To Video는 LTX 2.5 모델을 사용하여 텍스트 설명에서 전문가 수준의 비디오를 생성하는 API 노드입니다. 프롬프트를 제공하고 모델 등급, 지속 시간, 해상도, 프레임 속도 및 오디오 포함 여부와 같은 생성 설정을 선택하면 노드가 작업을 LTX API에 제출하고 결과 비디오를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 비디오 생성에 사용할 LTX 2.5 모델 등급입니다. | STRING | 예 | "LTX-2.5 (Fast)"<br />"LTX-2.5 (Pro)" |
| `model.duration` | 생성된 비디오의 길이입니다. | INT | 예 | 정수 |
| `model.resolution` | 비디오의 출력 해상도입니다. 사용 가능한 옵션은 선택한 `model`에 따라 달라집니다. | STRING | 예 | "LTX-2.5 (Fast)" 선택 시:<br />"1280x720"<br />"720x1280"<br />"1920x1080"<br />"1080x1920"<br />"2560x1440"<br />"1440x2560"<br />"3840x2160"<br />"2160x3840"<br />"LTX-2.5 (Pro)" 선택 시:<br />"1280x720"<br />"720x1280"<br />"1920x1080"<br />"1080x1920" |
| `model.fps` | 생성된 비디오의 프레임 속도입니다 (기본값: 25). | INT | 아니요 | 정수 |
| `model.generate_audio` | 비디오와 함께 오디오를 생성할지 여부입니다 (기본값: True). | BOOLEAN | 아니요 | True<br />False |
| `prompt` | 생성할 비디오에 대한 텍스트 설명입니다. 최대 10,000자의 비어 있지 않은 프롬프트가 필요합니다 (기본값: ""). | STRING | 예 | 1~10000자 |
| `seed` | 재현 가능한 생성을 위해 사용되는 시드 값입니다 (기본값: 42). | INT | 아니요 | 정수 |

참고: 사용 가능한 `model.resolution` 옵션은 선택한 `model`에 따라 달라집니다. "LTX-2.5 (Fast)"는 최대 2160x3840 해상도를 지원하며, "LTX-2.5 (Pro)"는 최대 1920x1080 해상도를 지원합니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-----------|-------------|-----------|
| `video` | LTX API가 반환한 생성된 비디오로, 워크플로우에서 추가로 사용할 준비가 되어 있습니다. 오디오 생성이 활성화된 경우 비디오에는 동기화된 오디오가 포함됩니다. | VIDEO |
