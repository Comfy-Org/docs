이 노드는 메시의 기존 UV 레이아웃을 사용하여 3D 메시에 PBR 텍스처를 베이크합니다. 각 텍셀에서 스파스 복셀 볼륨의 색상 및 재질 속성을 샘플링하여 베이스 컬러 이미지와 메탈릭, 러프니스 맵을 출력합니다. 메시를 언랩하지 않으므로 UV 언랩 노드가 업스트림에 연결되어 있어야 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 텍스처를 베이크할 3D 메시입니다. 이미 UV 레이아웃이 있어야 하며, UV 언랩 노드가 업스트림에 연결되어 있어야 합니다. | MESH | 예 | |
| `voxel_colors` | 복셀별 색상과 선택적 PBR 속성(메탈릭 및 러프니스 채널)을 포함하는 스파스 복셀 볼륨입니다. | VOXEL | 예 | |
| `texture_size` | 정사각형 UV 아틀라스 해상도입니다(표시 이름: "resolution", 기본값: 2048). | INT | 예 | 64 ~ 8192 |
| `reference_mesh` | 선택적 정밀 밀집 사전 축소 메시입니다. 각 텍셀을 실제 표면으로 역투영한 후 샘플링하여 거친 메시의 면상 베이킹(faceted baking)을 제거합니다. | MESH | 아니요 | |

참고:

- 입력 메시에는 UV가 있어야 합니다. UV가 없으면 노드가 오류를 발생시킵니다. UV는 정점과 1:1 대응해야 합니다(정점당 UV 하나).
- 메시와 복셀 좌표에 배치 차원이 포함된 경우 각 배치 항목은 개별적으로 베이크됩니다. 배치 항목에 복셀이나 면이 없으면 건너뛰고 해당 항목에 대해 검은색 텍스처를 출력합니다.
- 배치에 `reference_mesh`가 제공되면 배치 인덱스로 일치시킵니다. 단, 참조 메시가 단일 메시만 포함하는 경우 해당 메시가 모든 항목에 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `base_color` | RGB 베이스 컬러 텍스처 맵입니다. 값은 0~1 범위의 float입니다. | IMAGE |
| `metallic` | 회색조 메탈릭 맵(float, 0~1)입니다. 복셀 색상에 메탈릭 채널이 없으면 검은색입니다. | IMAGE |
| `roughness` | 회색조 러프니스 맵(float, 0~1)입니다. 복셀 색상에 러프니스 채널이 없으면 검은색입니다. | IMAGE |
