이 노드는 메시의 기존 UV 레이아웃을 사용하여 PBR 텍스처를 3D 메시에 베이크합니다. 각 텍셀에서 스파스 복셀 볼륨(sparse voxel volume)의 색상 및 재질 속성을 샘플링하고 기본 색상(base color) 이미지와 금속성(metallic) 및 거칠기(roughness) 맵을 출력합니다. 메시를 언랩하지 않으므로 UV 언랩 노드가 업스트림에 연결되어 있어야 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 텍스처를 베이크할 3D 메시입니다. 이미 UV 레이아웃이 있어야 하며, UV 언랩 노드가 업스트림에 연결되어 있어야 합니다. | MESH | 예 | |
| `voxel_colors` | 복셀별 색상과 선택적 PBR 속성(금속성 및 거칠기 채널)을 포함하는 스파스 복셀 볼륨입니다. | VOXEL | 예 | |
| `texture_size` | 정사각형 UV 아틀라스 해상도입니다(표시 이름: "resolution", 기본값: 2048). | INT | 예 | 64 ~ 8192 |
| `reference_mesh` | 선택적인 디시메이션(decimation) 전 고밀도 메시입니다. 샘플링 전에 각 텍셀을 실제 표면으로 역투영하여 거친 메시에서 패싯(faceted) 베이크가 발생하지 않도록 합니다. | MESH | 아니요 | |

참고:

- 입력 메시에는 UV가 있어야 합니다. UV가 없으면 노드가 오류를 발생시킵니다. UV는 정점과 1:1로 일치해야 합니다(정점당 UV 1개).
- 메시와 복셀 좌표에 배치(batch) 차원이 포함된 경우 각 배치 항목은 개별적으로 베이크됩니다. 배치 항목에 복셀이나 면이 없으면 해당 항목은 건너뛰고 검은색 텍스처가 출력됩니다.
- 배치에 `reference_mesh`를 제공하면 해당 메시는 배치 인덱스로 일치됩니다. 단, 메시가 하나만 포함된 경우에는 모든 항목에 해당 메시가 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `base_color` | RGB 기본 색상 텍스처 맵입니다. 값은 0–1 범위의 float입니다. | IMAGE |
| `metallic` | 회색조 금속성 맵(float, 0–1)입니다. 복셀 색상에 금속성 채널이 없으면 검은색입니다. | IMAGE |
| `roughness` | 회색조 거칠기 맵(float, 0–1)입니다. 복셀 색상에 거칠기 채널이 없으면 검은색입니다. | IMAGE |
