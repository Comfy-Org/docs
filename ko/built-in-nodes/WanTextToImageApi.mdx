Wan Text to Image 노드는 텍스트 설명을 기반으로 이미지를 생성합니다. AI 모델을 사용하여 작성된 프롬프트로부터 시각적 콘텐츠를 만들며, 영어와 중국어 텍스트 입력을 모두 지원합니다. 이 노드는 출력 이미지 크기, 품질 및 스타일 기본 설정을 조정할 수 있는 다양한 제어 기능을 제공합니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 사용할 모델 (기본값: "wan2.5-t2i-preview") | STRING | 예 | "wan2.5-t2i-preview" |
| `프롬프트` | 요소와 시각적 특징을 설명하는 프롬프트입니다. 영어와 중국어를 지원합니다 (기본값: 비어 있음) | STRING | 예 | - |
| `부정 프롬프트` | 피해야 할 내용을 설명하는 부정 프롬프트입니다 (기본값: 비어 있음) | STRING | 아니요 | - |
| `너비` | 이미지 너비(픽셀) (기본값: 1024, 단계: 32) | INT | 아니요 | 768-1440 |
| `높이` | 이미지 높이(픽셀) (기본값: 1024, 단계: 32) | INT | 아니요 | 768-1440 |
| `시드` | 생성에 사용할 시드 (기본값: 0) | INT | 아니요 | 0-2147483647 |
| `프롬프트 확장` | AI 지원으로 프롬프트를 향상할지 여부 (기본값: True) | BOOLEAN | 아니요 | - |
| `워터마크` | 결과에 AI 생성 워터마크를 추가할지 여부 (기본값: False) | BOOLEAN | 아니요 | - |

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
|-------------|-------------|-----------|
| `output` | 텍스트 프롬프트를 기반으로 생성된 이미지 | IMAGE |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/WanTextToImageApi/ko.md)
