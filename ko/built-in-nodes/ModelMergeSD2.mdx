ModelMergeSD2 노드는 일치하는 구성 요소를 혼합하여 두 Stable Diffusion 2.x 모델을 병합하며, 시간 임베딩, 레이블 임베딩, 그리고 모든 입력, 중간 및 출력 블록에 대해 별도의 가중치를 둡니다. 블록 레이아웃은 ModelMergeSD1과 동일하므로 두 노드는 동일한 비율 집합을 노출합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `모델1` | 병합할 첫 번째 모델입니다. 두 번째 모델이 기여하지 않는 모든 부분은 이 모델에서 유지됩니다 | MODEL | 예 | - |
| `모델2` | 병합할 두 번째 모델입니다. 해당 가중치는 아래 비율에 따라 혼합되어 반영됩니다 | MODEL | 예 | - |
| `time_embed.` | 시간 임베딩 레이어의 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `label_emb.` | 레이블 임베딩 레이어의 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `input_blocks.0.`부터 `input_blocks.11.`까지 | 12개 입력 블록 각각의 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `middle_block.0.`부터 `middle_block.2.`까지 | 3개 중간 블록 각각의 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `output_blocks.0.`부터 `output_blocks.11.`까지 | 12개 출력 블록 각각의 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |
| `out.` | 출력 레이어의 혼합 비율입니다(기본값: 1.0) | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |

비율 0.0은 해당 구성 요소를 `model1`에 있는 그대로 유지하고, 비율 1.0은 이를 전적으로 `model2`에서 가져오며, 그 사이 값은 가중치가 적용된 혼합을 생성합니다. 두 입력 모두 동일한 블록 구조를 가진 Stable Diffusion 2.x 모델이어야 합니다.
