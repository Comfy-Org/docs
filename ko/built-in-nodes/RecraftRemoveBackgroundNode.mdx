이 노드는 Recraft API 서비스를 사용하여 이미지에서 배경을 제거합니다. 입력 배치의 각 이미지를 개별적으로 처리하며, 투명한 배경을 가진 처리된 이미지와 제거된 배경 영역을 나타내는 해당 알파 마스크를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | 배경 제거를 처리할 입력 이미지입니다. 배치의 각 이미지가 개별적으로 처리됩니다. | IMAGE | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `image` | 투명한 배경을 가진 처리된 이미지(RGBA 형식) | IMAGE |
| `mask` | 제거된 배경 영역을 나타내는 알파 채널 마스크(B,H,W 형식) | MASK |
