이 노드는 목록에 있는 비디오-텍스트 쌍의 순서를 무작위로 셔플하며, 각 비디오가 해당 텍스트와 쌍을 유지하도록 합니다. 길이가 같은 두 목록을 입력받아 동일한 무작위 순열을 두 목록 모두에 적용하므로, 셔플 후에도 원래의 쌍이 보존됩니다. 시드 값이 셔플 순서를 제어하므로 결과를 재현할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `비디오` | 셔플할 비디오 목록입니다. | VIDEO | 예 | 비디오 항목 목록 |
| `텍스트` | 셔플할 텍스트 목록입니다(비디오와 쌍을 이루는 캡션). | STRING | 예 | 텍스트 문자열 목록 |
| `시드` | 셔플 순서를 결정하는 난수 시드입니다(기본값: 0). | INT | 예 | 0 ~ 18446744073709551615 |

참고: `videos`와 `texts`의 길이는 동일해야 합니다. 노드가 각 비디오를 같은 위치의 텍스트와 쌍으로 묶고, 셔플 시에도 이 쌍을 유지하기 때문입니다. 내부적으로 `seed` 값은 무작위 순서가 생성되기 전에 모듈로 4294967295(2^32 - 1) 연산을 통해 축소되므로, 매우 큰 시드 값은 더 작은 값과 동일한 셔플 결과를 생성할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `비디오` | 새로운 무작위 순서로 셔플된 비디오입니다. | VIDEO |
| `텍스트` | 비디오와 동일한 새 순서로 셔플된 텍스트입니다. | STRING |
