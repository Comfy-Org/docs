이 노드는 비디오-텍스트 쌍의 순서를 무작위로 섞으며, 각 비디오가 해당 텍스트와 쌍을 이루도록 유지합니다. 길이가 같은 두 개의 리스트를 입력받아 동일한 무작위 순열을 적용하여, 섞은 후에도 원래 쌍이 유지되도록 보장합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `비디오` | 섞을 비디오 목록입니다. | VIDEO | 예 | 비디오 항목 목록 |
| `텍스트` | 섞을 텍스트 목록입니다. | STRING | 예 | 텍스트 문자열 목록 |
| `시드` | 섞기 순서를 제어하는 무작위 시드입니다(기본값: 0). | INT | 예 | 0 ~ 18446744073709551615 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `비디오` | 새로운 무작위 순서로 섞인 비디오입니다. | VIDEO |
| `텍스트` | 비디오와 동일한 새로운 순서로 섞인 텍스트입니다. | STRING |
