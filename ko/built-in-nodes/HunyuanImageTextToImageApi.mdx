Tencent HY Image: Text to Image 노드는 Tencent의 Hunyuan Image 모델을 사용하여 텍스트 설명으로부터 이미지를 생성합니다. 프롬프트는 API로 전송되며, API는 렌더링 전에 이를 다시 작성하고 확장한 뒤, 완성된 이미지를 이미지 배치로 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 생성에 사용되는 모델입니다. 선택한 모델에 따라 표시되는 추가 입력이 결정됩니다. | DYNAMIC_COMBO | 예 | `"hy-image-3.5-preview"` |

### hy-image-3.5-preview 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성할 이미지를 설명합니다. 모델은 렌더링 전에 이 설명을 다시 작성하고 확장합니다. 비어 있어서는 안 됩니다(기본값: 비어 있음). | STRING | 예 | 모든 텍스트 |
| `aspect_ratio` | 출력의 가로세로 비율입니다. `"auto"`는 모델이 프롬프트에서 비율을 선택하도록 하며 4K에서는 사용할 수 없습니다. `resolution`이 `"custom"`일 때는 무시됩니다. | COMBO | 예 | `"auto"`<br />`"1:1"`<br />`"3:2"`<br />`"2:3"`<br />`"4:3"`<br />`"3:4"`<br />`"16:9"`<br />`"9:16"`<br />`"21:9"`<br />`"9:21"` (기본값: `"auto"`) |
| `resolution` | 이미지의 픽셀 면적입니다: 1K는 약 1024x1024, 2K는 약 2048x2048, 4K는 약 4096x4096입니다. 2K를 초과하는 값은 2K로 렌더링되고 모델에 의해 업스케일됩니다. `"custom"`으로 설정하면 사전 설정 면적 대신 `width`와 `height`를 사용합니다. | COMBO | 예 | `"1K"`<br />`"2K"`<br />`"4K"`<br />`"custom"` (기본값: `"2K"`) |
| `width` | 이미지의 너비(픽셀)입니다. `resolution`이 `"custom"`일 때만 사용됩니다. | INT | 예 | 256-8192, 16 단위 (기본값: 2048) |
| `height` | 이미지의 높이(픽셀)입니다. `resolution`이 `"custom"`일 때만 사용됩니다. | INT | 예 | 256-8192, 16 단위 (기본값: 2048) |
| `seed` | 생성에 사용되는 시드입니다. 동일한 시드로도 실행마다 결과가 달라집니다. | INT | 예 | 0-2147483647 (기본값: 42) |
| `watermark` | 결과에 AI 생성 워터마크를 추가할지 여부입니다. 이 매개변수는 고급 매개변수입니다. | BOOLEAN | 아니오 | true<br />false (기본값: false) |

`prompt`는 비어 있어서는 안 됩니다. `"custom"` 해상도에서는 `width`와 `height`가 모두 16의 배수여야 하며, 두 값의 곱이 4096 x 4096 픽셀 면적 제한(약 16.7메가픽셀)을 초과해서는 안 됩니다. 어떤 가로세로 비율이든 사용할 수 있지만, 대략 6:1을 넘으면 모델이 피사체를 반복하기 시작합니다. `"auto"` 가로세로 비율은 모델이 크기를 선택해야 하므로 2K 면적 제한 내에서만 작동합니다: 4K에서는 명시적인 가로세로 비율을 선택하거나 `"custom"`을 사용하십시오.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 생성된 이미지입니다. | IMAGE |
