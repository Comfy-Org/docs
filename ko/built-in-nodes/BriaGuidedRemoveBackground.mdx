이 노드는 Bria를 사용하여 이미지에서 배경을 제거하고, 프롬프트에 설명된 부분을 유지합니다. 원본 픽셀은 다시 렌더링되지 않고 새로운 알파 채널과 함께 원래 해상도로 반환되므로, 세밀한 디테일과 경계가 그대로 유지됩니다. 아무것과도 일치하지 않는 프롬프트는 완전히 투명한 이미지를 반환합니다. 별도의 안내 없이 단순한 누끼 추출만 필요한 경우에는 Bria Remove Image Background가 더 저렴합니다.

## 입력

`moderation` 선택자를 `"true"`로 설정하면 추가 검열 옵션이 나타납니다.

### 공통 입력

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `image` | 잘라낼 이미지입니다. | IMAGE | 예 | - |
| `prompt` | 유지할 대상과, 선택적으로 제거하거나 범위를 좁힐 대상을 지정합니다. 예: 'the person with the mat and the plant', 'the woman at her desk without the lamp', 'only the chair'. 비어 있을 수 없습니다. 프롬프트와 일치하는 항목이 없으면 결과는 완전히 투명합니다. 기본값: `""`(빈 문자열). | STRING | 예 | 1 character or more |
| `moderation` | 검열 설정입니다. `"true"`로 설정하면 아래의 시각 검열 플래그를 사용할 수 있습니다. | DYNAMIC_COMBO | 예 | `"false"`<br />`"true"` |

### Moderation "true" 입력

이 매개변수들은 `moderation`이 `"true"`로 설정된 경우에만 나타납니다. `"false"` 옵션은 추가 입력을 제공하지 않습니다.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `visual_input_moderation` | 입력 이미지에 대한 콘텐츠 검열을 활성화합니다. 기본값: `False`. | BOOLEAN | 아니요 | True / False |
| `visual_output_moderation` | 생성된 이미지에 대한 콘텐츠 검열을 활성화합니다. 기본값: `False`. | BOOLEAN | 아니요 | True / False |

## 출력

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `image` | 잘라낸 이미지입니다. 새로운 알파 채널이 적용된 원본 픽셀입니다. | IMAGE |
