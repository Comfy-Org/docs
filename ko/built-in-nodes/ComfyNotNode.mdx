Not 노드는 모든 입력 값에 대해 논리적 NOT 연산을 수행합니다. 입력 값이 거짓으로 간주되는 경우(예: 0, 빈 문자열, None, False) True를 반환하고, 입력 값이 참인 경우 False를 반환합니다. Python의 표준 진리값 판정 규칙을 사용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `value` | 반전할 입력 값입니다. 모든 데이터 타입이 허용되며 Python의 진리값 규칙을 사용하여 평가됩니다. | ANY | 예 | 모든 값 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `output` | 입력 값의 논리적 역입니다. 입력이 거짓이면 True를 반환하고, 입력이 참이면 False를 반환합니다. | BOOLEAN |
