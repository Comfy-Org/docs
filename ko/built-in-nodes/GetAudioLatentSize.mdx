오디오 잠재를 읽고 해당 길이, 오디오 채널 수, 배치 크기를 반환하므로 오디오를 디코딩하지 않고도 이 값을 재사용할 수 있습니다. 샘플링 전에 노이즈 마스크 크기를 지정하거나 오디오와 비디오 길이를 맞추는 데 사용합니다. 측정된 값은 노드 자체에도 표시됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `latent` | 검사할 오디오 또는 오디오/비디오 잠재입니다. 잠재에 여러 스트림이 포함된 경우 오디오 스트림을 측정합니다. | LATENT | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `length` | 오디오 잠재의 길이이며, 오디오 샘플이 아닌 잠재 셀 단위입니다. | INT |
| `audio_channels` | 오디오 채널 수입니다. 오디오 채널 차원이 없는 잠재는 하나의 채널로 보고합니다. | INT |
| `batch_size` | 배치에 있는 잠재의 수입니다. | INT |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/GetAudioLatentSize/ko.md)
