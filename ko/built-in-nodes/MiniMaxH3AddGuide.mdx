이 노드는 MiniMax H3 비디오의 선택한 프레임에 이미지, 짧은 클립, 오디오 또는 사운드트랙이 포함된 클립을 고정합니다. 지정된 프레임 인덱스에서 컨디셔닝에 가이드 키프레임을 추가하며, 여러 노드를 연결하여 동일한 비디오의 여러 프레임을 고정할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 가이드 키프레임이 첨부되는 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `latent` | 대상 비디오를 정의하는 MiniMax H3 오디오-비디오 잠재 변수입니다. MiniMax H3 AV 잠재 변수(중첩되어 있으며 각각 24채널의 5D 텐서 두 개)여야 합니다. | LATENT | 예 | - |
| `frame_idx` | 이미지 또는 클립의 첫 번째 프레임을 고정할 프레임 인덱스입니다. 음수 값은 비디오의 끝에서부터 계산됩니다. (기본값: 0) | INT | 예 | -9999 ~ 9999 |
| `vae` | 비디오 VAE로, 이미지가 연결된 경우 필요합니다. | VAE | 아니오 | - |
| `audio_vae` | 오디오 VAE로, 오디오가 연결된 경우 필요합니다. | VAE | 아니오 | - |
| `image` | 고정할 이미지 또는 비디오 프레임입니다. 다중 프레임 배치는 클립으로 고정되며 모델의 유효한 클립 길이(5, 22, 39... (17k + 5) 프레임)로 잘립니다. 5프레임 미만의 배치는 첫 번째 이미지만 사용합니다. | IMAGE | 아니오 | - |
| `audio` | 같은 프레임 인덱스에서 시작하도록 고정할 사운드트랙으로, 비디오의 남은 재생 시간에 맞게 잘립니다. | AUDIO | 아니오 | - |

**제약 사항:**
- `image` 또는 `audio` 중 하나 이상이 제공되어야 하며, 그렇지 않으면 노드가 오류를 발생시킵니다.
- `image`가 연결된 경우 `vae`가 필요합니다.
- `audio`가 연결된 경우 `audio_vae`가 필요합니다.
- 5프레임 미만의 `image` 배치는 첫 번째 이미지만 사용하며, 5프레임 이상의 배치는 유효한 클립 길이(5, 22, 39 등)로 잘립니다.
- `frame_idx`는 가이드를 비디오의 프레임 범위 내에 배치해야 하며, 다중 프레임 클립은 비디오에 완전히 맞아야 합니다. 그렇지 않으면 노드가 오류를 발생시킵니다.
- 오디오가 연결된 경우 프레임 인덱스는 비디오의 오디오 트랙 끝을 초과할 수 없습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 가이드 키프레임이 추가된 컨디셔닝으로, 확정된 프레임 인덱스와 제공된 경우 인코딩된 이미지 또는 오디오 잠재 변수를 포함합니다. | CONDITIONING |
