이 노드는 이미지, 짧은 클립, 오디오 또는 사운드트랙이 포함된 클립을 MiniMax H3 비디오의 임의 프레임에 앵커링합니다. 선택한 프레임 인덱스의 컨디셔닝에 가이드 키프레임을 추가하며, 이 노드를 여러 개 연결하여 동일한 비디오의 여러 프레임을 앵커링할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 가이드 키프레임이 연결되는 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `vae` | 비디오 VAE로, 이미지가 연결된 경우 필요합니다. | VAE | 아니요 | - |
| `audio_vae` | 오디오 VAE로, 오디오가 연결된 경우 필요합니다. | VAE | 아니요 | - |
| `latent` | 대상 비디오를 정의하는 MiniMax H3 오디오-비디오 latent입니다. 반드시 MiniMax H3 AV latent여야 합니다(중첩 구조이며, 두 개의 5D 텐서로 구성되고, 비디오 텐서는 24개 채널을 가집니다). | LATENT | 예 | - |
| `image` | 앵커링할 이미지 또는 비디오 프레임입니다. 다중 프레임 배치는 클립으로 앵커링되며 모델의 유효 클립 길이인 5, 22, 39... (17k + 5) 프레임으로 잘립니다. 5프레임 미만의 배치는 첫 번째 이미지만 사용합니다. | IMAGE | 아니요 | - |
| `audio` | 동일한 프레임 인덱스에서 앵커링을 시작할 사운드트랙이며, 비디오의 남은 길이에 맞게 잘립니다. | AUDIO | 아니요 | - |
| `frame_idx` | 이미지 또는 클립의 첫 프레임을 앵커링할 프레임 인덱스입니다. 음수 값은 비디오 끝에서부터 계산됩니다. (기본값: 0) | INT | 예 | -9999 ~ 9999 |

**제약 사항:**
- `image` 또는 `audio` 중 하나 이상을 제공해야 하며, 그렇지 않으면 노드가 오류를 발생시킵니다.
- `image`가 연결된 경우 `vae`가 필요합니다.
- `audio`가 연결된 경우 `audio_vae`가 필요합니다.
- 5프레임 미만의 `image` 배치는 첫 번째 이미지만 사용하며, 5프레임 이상의 배치는 유효한 클립 길이(5, 22, 39 등)로 잘립니다.
- `frame_idx`는 가이드를 비디오의 프레임 범위 안에 배치해야 하며, 다중 프레임 클립은 비디오 안에 완전히 들어맞아야 합니다. 그렇지 않으면 노드가 오류를 발생시킵니다.
- 오디오가 연결된 경우, 프레임 인덱스는 비디오의 오디오 트랙 끝을 넘어가면 안 됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 가이드 키프레임이 추가된 컨디셔닝으로, 계산된 프레임 인덱스와 제공된 경우 인코딩된 이미지 또는 오디오 latent를 포함합니다. | CONDITIONING |
