Preview Point Cloud 노드는 3D 포인트 클라우드 파일을 ComfyUI 출력 디렉토리에 저장하지 않고 ComfyUI 인터페이스에서 직접 볼 수 있게 해줍니다. 포인트 클라우드를 임시 위치에 저장하고 3D 미리보기 창에 표시하면서, 모델 데이터, 카메라 정보 및 뷰포트 상태를 후속 처리를 위해 전달합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 포인트 클라우드 파일(.ply) | FILE3D | 예 | - |
| `model_3d_info` | 3D 모델에 대한 정보 | LOAD3DMODELINFO | 아니오 | - |
| `viewport_state` | 현재 뷰포트 상태 | LOAD3D | 예 | - |
| `camera_info` | 3D 뷰를 위한 카메라 정보 | LOAD3DCAMERA | 아니오 | - |
| `width` | 미리보기 창의 너비(기본값: 1024) | INT | 예 | 1 ~ 4096 |
| `height` | 미리보기 창의 높이(기본값: 1024) | INT | 예 | 1 ~ 4096 |

참고: `camera_info` 또는 `model_3d_info`가 연결되지 않은 경우, 노드는 `viewport_state`에 저장된 해당 값으로 대체됩니다. 포인트 클라우드 파일은 ComfyUI의 임시 디렉토리에 저장되며 출력 디렉토리에는 기록되지 않습니다. 이 노드는 출력 노드이므로 주로 인터페이스에서 미리보기 결과를 표시하는 데 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model_3d` | 포인트 클라우드 모델 데이터 | FILE3D |
| `model_3d_info` | 3D 모델에 대한 정보 | LOAD3DMODELINFO |
| `camera_info` | 3D 뷰를 위한 카메라 정보 | LOAD3DCAMERA |
| `width` | 미리보기 창의 너비 | INT |
| `height` | 미리보기 창의 높이 | INT |
