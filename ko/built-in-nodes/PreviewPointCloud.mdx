Preview Point Cloud 노드는 3D 포인트 클라우드 파일을 ComfyUI 출력 디렉터리에 저장하지 않고도 ComfyUI 인터페이스에서 볼 수 있게 해줍니다. 포인트 클라우드를 임시 위치에 저장하고 3D 미리보기 창에 표시하며, 모델 데이터, 모델 정보, 카메라 정보 및 미리보기 크기를 후속 처리를 위해 전달합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 포인트 클라우드 파일(.ply) | FILE3D | 예 | - |
| `model_3d_info` | 3D 모델에 대한 정보 | LOAD3DMODELINFO | 아니요 | - |
| `viewport_state` | 3D 뷰포트의 현재 상태 | LOAD3D | 예 | - |
| `camera_info` | 3D 뷰의 카메라 정보 | LOAD3DCAMERA | 아니요 | - |
| `width` | 미리보기 창의 너비(기본값: 1024) | INT | 예 | 1 ~ 4096 |
| `height` | 미리보기 창의 높이(기본값: 1024) | INT | 예 | 1 ~ 4096 |

참고: `model_3d_info`와 `camera_info`는 선택적인 고급 입력입니다. 연결되지 않은 경우 노드는 `viewport_state`에 저장된 해당 값으로 대체합니다. 포인트 클라우드 파일은 출력 디렉터리가 아닌 ComfyUI의 임시 디렉터리에 기록됩니다. 이 노드는 출력(터미널) 노드이므로 주로 인터페이스에서 미리보기를 표시하는 데 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model_3d` | 포인트 클라우드 모델 데이터 | FILE3D |
| `model_3d_info` | 3D 모델에 대한 정보 | LOAD3DMODELINFO |
| `camera_info` | 3D 뷰의 카메라 정보 | LOAD3DCAMERA |
| `width` | 미리보기 창의 너비 | INT |
| `height` | 미리보기 창의 높이 | INT |

> 이 문서는 AI에 의해 생성되었습니다. 오류를 발견하거나 개선 제안이 있으시면 기여해 주세요! [GitHub에서 편집](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/PreviewPointCloud/ko.md)
