이 노드는 Wan 3.0 모델을 사용하여 텍스트 프롬프트와 선택적 참조 이미지, 동영상, 오디오로부터 비디오를 생성합니다. 참조 미디어는 자유롭게 조합할 수 있으며 프롬프트에서 @Image1, @Video1, @Audio1로 언급할 수 있습니다. 이 노드는 생성 요청을 Wan API에 제출하고 완성된 비디오를 반환합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 생성에 사용될 Wan 3.0 모델 변형을 선택합니다. | DYNAMIC_COMBO | 예 | `wan3.0-video`<br />`wan3.0-video-prime` |
| `시드` | 생성에 사용할 시드입니다. 기본값: 42. | INT | 예 | 0~2147483647 |
| `워터마크` | 결과물에 AI 생성 워터마크를 추가할지 여부입니다. 기본값: false. | BOOLEAN | 예 | true<br />false |

### wan3.0-video 및 wan3.0-video-prime 입력

두 모델 옵션은 동일한 매개변수 집합을 공유합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 요소와 시각적 특징을 설명하는 프롬프트입니다. 영어와 중국어를 지원합니다. 연결된 참조 미디어를 @Image1, @Video1, @Audio1로 참조하며, 입력 순서대로 유형별로 번호가 매겨집니다. 기본값: 비어 있음. | STRING | 예 | 최대 20,000자 |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | "1080P"<br />"720P"<br />"480P" |
| `ratio` | 출력 비디오의 화면 비율입니다. "adaptive"를 선택하면 입력 미디어에서 출력 크기가 파생됩니다. | COMBO | 예 | "adaptive"<br />"16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4" |
| `duration` | 출력 길이(초)입니다. "auto"를 선택하면 모델이 프롬프트와 참조 미디어에 맞는 길이를 선택합니다. 참조 동영상과 출력의 총 길이는 30초를 초과할 수 없습니다. | COMBO | 예 | "auto"<br />"2"~"30" (정수 초) |
| `audio` | 출력 비디오에 오디오 트랙이 포함되는지 여부입니다. 기본값: true. | BOOLEAN | 예 | true<br />false |
| `prompt_extend` | AI 지원으로 프롬프트를 향상시킬지 여부입니다. 기본값: true. | BOOLEAN | 예 | true<br />false |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 확장 가능한 슬롯: 참조 이미지 1~10개를 연결합니다. 참조는 입력 순서대로 image1~image10으로 번호가 매겨집니다. | IMAGE | 아니요 | 0~10개 이미지 |
| `reference_videos` | 확장 가능한 슬롯: 참조 동영상 1~5개를 연결합니다. 참조는 입력 순서대로 video1~video5로 번호가 매겨집니다. | VIDEO | 아니요 | 0~5개 동영상 |
| `reference_audios` | 확장 가능한 슬롯: 참조 오디오 클립 1~5개를 연결합니다. 참조는 입력 순서대로 audio1~audio5로 번호가 매겨집니다. | AUDIO | 아니요 | 0~5개 오디오 클립 |

**제약 사항:**

- 프롬프트에는 비어 있지 않은 문자가 하나 이상 포함되어야 하거나, 참조 이미지, 동영상 또는 오디오 입력이 하나 이상 연결되어야 합니다.
- 프롬프트의 참조 태그는 연결된 입력과 일치해야 합니다. 예를 들어 @Image1은 첫 번째 연결된 참조 이미지를, @Video2는 두 번째 연결된 참조 동영상을, @Audio1은 첫 번째 연결된 참조 오디오를 나타냅니다. 태그는 입력 순서대로 유형별로 별도로 번호가 매겨집니다.
- 연결된 각 참조 이미지에는 배치(batch)가 아닌 정확히 하나의 이미지만 포함되어야 합니다.
- 각 참조 동영상은 15초 이하여야 합니다. 모든 참조 동영상의 총 길이는 15초를 초과할 수 없습니다.
- 각 참조 오디오는 15초 이하여야 합니다. 모든 참조 오디오의 총 길이는 15초를 초과할 수 없습니다.
- `duration`이 "auto"가 아닌 경우, 모든 참조 동영상의 총 길이와 선택한 출력 길이의 합은 30초를 초과할 수 없습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 생성된 비디오 파일입니다. `audio` 매개변수가 활성화된 경우 오디오 트랙이 포함됩니다. | VIDEO |
