EmptyARVideoLatent 노드는 비디오 생성을 위한 빈 잠재 표현을 생성합니다. 요청된 너비, 높이, 프레임 수, 배치 크기를 사용하여 0으로 채워진 텐서를 만들며, 이는 이후 비디오 생성 프로세스를 초기화하는 데 사용할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `width` | 비디오 프레임의 너비(픽셀 단위)입니다. (기본값: 832) | INT | 예 | 16  ~  8192 (단계: 16) |
| `height` | 비디오 프레임의 높이(픽셀 단위)입니다. (기본값: 480) | INT | 예 | 16  ~  8192 (단계: 16) |
| `length` | 비디오의 프레임 수입니다. (기본값: 81) | INT | 예 | 1  ~  1024 (단계: 4) |
| `batch_size` | 단일 배치에서 생성할 비디오 수입니다. (기본값: 1) | INT | 예 | 1  ~  64 |

참고: 내부 잠재 크기는 이러한 입력에서 파생됩니다. `width`와 `height`는 8로 나뉘며, 잠재 시간 스텝 수는 `((length - 1) // 4) + 1`로 계산됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `LATENT` | 0으로 채워진 잠재 텐서로, 지정된 차원, 길이, 배치 크기를 가진 빈 비디오 잠재 공간을 나타냅니다. 텐서 형상은 [batch_size, 16, lat_t, height/8, width/8]이며, 여기서 lat_t = ((length - 1) // 4) + 1은 요청된 `length`에서 파생된 잠재 시간 스텝 수입니다. | LATENT |
