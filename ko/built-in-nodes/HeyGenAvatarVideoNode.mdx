HeyGen 아바타로 말하는 발표자 영상을 생성합니다. 이 노드는 HeyGen의 렌더링 엔진을 사용하여 AI 아바타가 제공한 텍스트를 말하거나 사용자의 오디오에 립싱크하는 영상을 만듭니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `엔진` | 렌더링 엔진입니다. 각 선택지는 이를 지원하는 아바타만 나열합니다. `"auto"`는 모든 아바타를 제공하고 최적의 엔진을 선택합니다(Avatar IV 우선). Avatar V는 가장 높은 충실도를, Avatar III는 가장 저렴한 비용을 제공합니다. | DYNAMIC_COMBO | 예 | `"auto"`<br />`"avatar_iv"`<br />`"avatar_iii"`<br />`"avatar_v"` |
| `커스텀 아바타 ID` | 선택적 HeyGen 아바타 룩 ID입니다. 설정하면 위에서 선택한 아바타를 재정의합니다. HeyGen의 3000개 이상 공개 룩(또는 사용자의 비공개 아바타) 중 무엇이든 사용할 수 있습니다. 기본값: `""`. | STRING | 아니오 |  |
| `음성` | 텍스트 스크립트(HeyGen 텍스트 음성 변환) 또는 사용자의 오디오로 아바타를 구동합니다. 표시 이름: "speech source". | DYNAMIC_COMBO | 예 | `"script"`<br />`"audio"` |
| `해상도` | 출력 영상 해상도입니다. 기본값: `"1080p"`. | COMBO | 아니오 | `"720p"`<br />`"1080p"` |
| `화면 비율` | 출력 화면 비율입니다. `"auto"`는 아바타의 원본 영상을 따릅니다. 기본값: `"auto"`. | COMBO | 아니오 | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:5"`<br />`"5:4"` |
| `배경 색상` | 선택적 단색 배경 색상(16진수 코드, 예: `"#00ff00"`)입니다. 비워 두면 아바타 자체 배경을 사용합니다. 값을 제공하는 경우 `#`로 시작해야 합니다. 기본값: `""`. | STRING | 아니오 |  |
| `시드` | HeyGen으로 전송되지 않습니다. 다시 실행하려면 값을 변경하세요. 기본값: `42`. | INT | 아니오 | 최소: 0<br />최대: 2147483647 |

### `auto` 입력

`engine`이 `"auto"`일 때 다음 하위 매개변수를 사용할 수 있습니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `avatar` | 영상을 진행할 아바타 룩입니다(HeyGen 공개 라이브러리에서 엄선됨). 해당 룩이 지원하는 최적의 엔진이 자동으로 선택됩니다. | COMBO | 예 | 여러 옵션 사용 가능 |

### `avatar_iv` 입력

`engine`이 `"avatar_iv"`일 때 다음 하위 매개변수를 사용할 수 있습니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Avatar IV 엔진을 지원하는 아바타 룩입니다. | COMBO | 예 | 여러 옵션 사용 가능 |

### `avatar_iii` 입력

`engine`이 `"avatar_iii"`일 때 다음 하위 매개변수를 사용할 수 있습니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Avatar III 엔진을 지원하는 아바타 룩입니다. | COMBO | 예 | 여러 옵션 사용 가능 |

### `avatar_v` 입력

`engine`이 `"avatar_v"`일 때 다음 하위 매개변수를 사용할 수 있습니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `avatar` | Avatar V 엔진을 지원하는 아바타 룩입니다. | COMBO | 예 | 여러 옵션 사용 가능 |

### `script` 입력

`speech`가 `"script"`일 때 다음 하위 매개변수를 사용할 수 있습니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `text` | 아바타가 말할 텍스트입니다(최대 5000자). 생성된 음성은 최소 1초 이상이어야 합니다. 기본값: `""`. | STRING | 예 | 최소: 1자<br />최대: 5000자 |
| `voice` | 스크립트에 사용할 음성입니다. 기본 옵션은 HeyGen이 아바타에 할당한 음성을 사용합니다. `custom_voice_id`가 설정된 경우 무시됩니다. | COMBO | 예 | `"(avatar's default voice)"`<br />여러 일반 음성 옵션 사용 가능 |
| `custom_voice_id` | 선택적 HeyGen 음성 ID입니다. 설정하면 위에서 선택한 음성을 재정의합니다. HeyGen 라이브러리의 2000개 이상 음성 중 무엇이든 사용할 수 있습니다. 기본값: `""`. | STRING | 아니오 |  |
| `voice_speed` | 음성 속도 배율입니다. 기본값: `1.0`. | FLOAT | 아니오 | 최소: 0.5<br />최대: 1.5<br />단계: 0.05 |

### `audio` 입력

`speech`가 `"audio"`일 때 다음 하위 매개변수를 사용할 수 있습니다:

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `audio` | 아바타가 립싱크할 오디오입니다(최대 10분). | AUDIO | 예 |  |

참고: `engine`과 `speech`는 선택한 값에 따라 서로 다른 하위 매개변수를 표시하는 선택자입니다. `speech` 선택자에는 상호 배타적인 두 가지 모드가 있습니다. `"script"` 모드에서는 `text`가 필수입니다. `custom_voice_id`를 제공하면 `voice`를 재정의합니다. `"audio"` 모드에서는 아바타가 제공된 오디오 클립에 립싱크합니다. `background_color`를 제공하는 경우 `#`로 시작하는 16진수 색상 코드여야 합니다. `custom_avatar_id`를 설정하면 `avatar` 선택을 재정의하며, 선택한 `engine`은 해당 아바타 룩에서 지원되어야 합니다. 그렇지 않으면 `engine`이 `"auto"`가 아닌 한 오류가 발생합니다.
