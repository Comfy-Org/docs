이 노드는 모델 샘플링 중에 사용되는 노이즈 스케일을 조정합니다. 입력 모델의 복사본을 만들고, 지정된 노이즈 스케일을 해당 샘플링 구성에 적용한 뒤 수정된 모델을 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 노이즈 스케일 조정을 적용할 모델입니다. | MODEL | 예 | - |
| `noise_scale` | 절대 학습 노이즈 스케일입니다. 예를 들어 HiDream-O1 base: 8.0, dev: 7.5입니다. (기본값: 1.0) | FLOAT | 예 | 0.0  ~  64.0 (단계: 0.01) |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `MODEL` | 새 노이즈 스케일이 적용된 수정된 모델입니다. | MODEL |
