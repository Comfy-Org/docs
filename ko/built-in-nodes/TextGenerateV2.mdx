Generate Text 노드는 CLIP 모델을 사용하여 프롬프트로부터 텍스트를 생성합니다. 이전의 단일 첨부 노드와 달리 이미지, 비디오, 오디오 파일의 확장 가능한 스택을 추가 컨텍스트로 받아들이므로, 하나의 노드에 전체 참조 세트를 입력할 수 있습니다. 출력 길이, 샘플링 사용 여부, 모델 자체의 채팅 템플릿과 사고 모드 적용 여부를 제어할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `clip` | 프롬프트를 토큰화하고 텍스트를 생성하는 데 사용되는 CLIP 모델입니다. | CLIP | 예 | - |
| `prompt` | 생성을 안내하는 프롬프트입니다. 여러 줄과 동적 프롬프트를 지원합니다 (기본값: 빈 문자열). | STRING | 예 | - |
| `images` | 최대 50개 이미지(`image1`부터 `image50`까지)로 구성된 확장 가능한 그룹으로, 모델의 시각적 컨텍스트로 사용됩니다. | AUTOGROW | 아니요 | 0~50개 이미지 |
| `videos` | 최대 100개 비디오 입력(`video1`부터 `video100`까지)으로 구성된 확장 가능한 그룹입니다. 각 비디오는 24 FPS로 가정되는 프레임 배치이며 내부적으로 1 FPS로 서브샘플링됩니다. | AUTOGROW | 아니요 | 0~100개 동영상 |
| `audios` | 최대 100개 오디오 입력(`audio1`부터 `audio100`까지)으로 구성된 확장 가능한 그룹으로, 모델의 오디오 컨텍스트로 사용됩니다. | AUTOGROW | 아니요 | 0~100개 오디오 파일 |
| `max_length` | 생성할 최대 토큰 수입니다 (기본값: 512). | INT | 예 | 1 ~ 32768 |
| `sampling_mode` | `"on"`은 출력을 샘플링하고 아래 샘플링 매개변수를 표시합니다. `"off"`는 무작위 샘플링 없이 그리디하게 생성합니다. | DYNAMIC_COMBO | 예 | `"on"`<br />`"off"` |
| `thinking` | 모델이 지원하는 경우 사고 모드로 동작합니다 (기본값: False). | BOOLEAN | 아니요 | True 또는 False |
| `use_default_template` | 모델에 내장된 시스템 프롬프트 또는 채팅 템플릿이 있으면 사용합니다 (기본값: True). 고급 매개변수입니다. | BOOLEAN | 아니요 | True 또는 False |
| `mtp` | 체크포인트의 다중 토큰 예측 헤드를 사용한 추측 디코딩입니다. MTP 가중치가 없으면 아무런 효과가 없습니다. `"auto"`는 관찰된 토큰 일치와 실행 비용에 맞춰 드래프트 깊이와 폭을 조정하고, `"2"`부터 `"5"`는 일정한 드래프트 깊이를 고정하며, `tree` 모드는 폭과 깊이를 모두 고정합니다. 샘플링된 출력은 분포가 올바르게 유지되지만 동일한 시드에 대해서는 비-MTP 출력과 다릅니다 (기본값: `"auto"`). | COMBO | 아니요 | `"auto"`<br />`"off"`<br />`"2"`<br />`"3"`<br />`"4"`<br />`"5"`<br />`"tree2s1"`<br />`"tree2s2"`<br />`"tree3s1"`<br />`"tree4s1m8"` |
| `system_prompt` | 모델의 채팅 템플릿에서 시스템 프롬프트를 대체합니다. 기본 템플릿을 사용하지 않으면 무시됩니다. 노드에 직접 입력하는 대신 STRING 입력을 연결하세요 (기본값: 비어 있음). | STRING | 아니요 | - |

### 샘플링 매개변수 (`sampling_mode`가 `"on"`일 때)

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `temperature` | 출력의 무작위성을 제어합니다. 값이 낮을수록 출력이 더 예측 가능해지고, 높을수록 더 창의적이 됩니다 (기본값: 0.7). | FLOAT | 예 | 0.01 ~ 2.0 |
| `top_k` | 샘플링 풀을 다음 토큰으로 가장 가능성이 높은 K개로 제한합니다. 값이 0이면 필터가 비활성화됩니다 (기본값: 64). | INT | 예 | 0 ~ 1000 |
| `top_p` | 뉴클리어스 샘플링: 누적 확률이 이 값에 도달하는 가장 가능성이 높은 토큰의 최소 집합을 유지합니다 (기본값: 0.95). | FLOAT | 예 | 0.0 ~ 1.0 |
| `min_p` | 토큰이 풀에 남기 위해 도달해야 하는 최소 확률입니다 (기본값: 0.05). | FLOAT | 예 | 0.0 ~ 1.0 |
| `repetition_penalty` | 이미 생성된 토큰에 페널티를 적용하여 반복을 줄입니다. 값이 1.0이면 페널티가 적용되지 않습니다 (기본값: 1.05). | FLOAT | 예 | 0.0 ~ 5.0 |
| `presence_penalty` | 지금까지 텍스트에 등장했는지 여부에 따라 새 토큰에 페널티를 적용하여 모델이 새로운 주제로 이동하도록 유도합니다 (기본값: 0.0). | FLOAT | 예 | 0.0 ~ 5.0 |
| `seed` | 재현 가능한 결과를 위해 난수 생성기를 초기화하는 데 사용되는 숫자입니다 (기본값: 0). | INT | 예 | 0 ~ 18446744073709551615 |

**참고:** 위 샘플링 매개변수는 `sampling_mode`가 `"on"`일 때만 존재합니다. `"off"`이면 노드는 무작위 샘플링 없이 텍스트를 생성하며 매개변수는 숨겨집니다.

**참고:** 모델의 출력이 `<think>`로 추론 블록을 열면 노드가 이를 분리합니다. `generated_text`에는 답변이 담기고 `thinking`에는 여는 태그가 제거된 추론이 담깁니다. 그렇지 않으면 `generated_text`에는 모델이 생성한 모든 내용이 담기고 `thinking`은 비어 있습니다. `max_length`로 인해 잘린 추론은 `generated_text`에 남습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `generated_text` | 모델이 생성한 텍스트이며, 추론 블록이 있으면 `thinking` 출력으로 분리됩니다. | STRING |
| `thinking` | 모델이 생성한 추론 블록으로, 여는 `<think>` 태그가 제거된 상태입니다. 모델이 추론 블록을 생성하지 않으면 비어 있습니다. | STRING |
