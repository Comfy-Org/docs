Runway Image to Video (Gen3a Turbo) 노드는 Runway의 Gen3a Turbo 모델을 사용하여 단일 시작 프레임에서 비디오를 생성합니다. 텍스트 프롬프트와 초기 이미지 프레임을 입력받은 다음, 지정된 지속 시간과 종횡비를 기반으로 비디오 시퀀스를 생성합니다. 생성은 Runway의 API를 통해 원격으로 처리됩니다. 이 노드는 사용 중단됨(deprecated)으로 표시되어 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 생성을 위한 텍스트 프롬프트 (기본값: "") | STRING | 예 | N/A |
| `start_frame` | 비디오에 사용할 시작 프레임 | IMAGE | 예 | N/A |
| `duration` | 생성된 비디오의 지속 시간(초) (기본값: "5") | COMBO | 예 | `"5"`<br />`"10"` |
| `ratio` | 생성된 비디오의 종횡비 (기본값: "768:1280") | COMBO | 예 | `"768:1280"`<br />`"1280:768"` |
| `seed` | 생성을 위한 무작위 시드 (기본값: 0) | INT | 예 | 0  ~  4294967295 |

**매개변수 제약:**

- `prompt`에는 최소 한 개의 문자가 포함되어야 합니다(비어 있을 수 없습니다).
- `start_frame`은 단일 이미지를 허용합니다(최대 1개).
- `start_frame`은 크기가 7999 x 7999픽셀을 초과해서는 안 됩니다.
- `start_frame`의 종횡비는 1:2에서 2:1 사이여야 합니다(0.5에서 2.0).

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 비디오 시퀀스 | VIDEO |
