Empty Flux 2 Latent 노드는 비어 있는 빈 잠재 표현을 생성합니다. 0으로 채워진 텐서를 생성하며, 이는 Flux 모델의 디노이징 과정의 시작점으로 사용됩니다. 잠재 표현의 크기는 입력 너비와 높이에 의해 결정되며, 16분의 1로 축소됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `너비` | 생성할 최종 이미지의 너비입니다. 잠재 표현의 너비는 이 값을 16으로 나눈 값입니다. 기본값은 1024입니다. | INT | 예 | 16 ~ 8192 |
| `높이` | 생성할 최종 이미지의 높이입니다. 잠재 표현의 높이는 이 값을 16으로 나눈 값입니다. 기본값은 1024입니다. | INT | 예 | 16 ~ 8192 |
| `배치 크기` | 단일 배치에서 생성할 잠재 샘플의 수입니다. 기본값은 1입니다. | INT | 아니오 | 1 ~ 4096 |

**참고:** `width` 및 `height` 입력 값은 16으로 나누어 떨어져야 합니다. 노드가 내부적으로 이 값을 16으로 나누어 잠재 표현의 크기를 생성하기 때문입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `samples` | 0으로 채워진 잠재 텐서입니다. 형태는 `[batch_size, 128, height // 16, width // 16]`입니다. | LATENT |
