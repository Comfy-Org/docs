이 노드는 Pika를 사용하여 비디오에 동기화된 사운드트랙을 생성합니다. 화면과 길이는 유지되며 오디오만 교체됩니다. 원하는 소리를 설명하거나, 지시를 비워 두면 화면을 기반으로 유도합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video` | 사운드트랙을 작성할 클립입니다. 최대 10분입니다. | VIDEO | 예 | - |
| `instruction` | 오디오가 어떤 내용이어야 하는지: 음향 효과, 앰비언스, 음악 또는 스타일입니다. 비워 두면 화면을 기반으로 유도합니다. 기본값: ""(빈 문자열). | STRING | 예 | 0 ~ 10000자 |
| `seed` | 샘플링용 시드입니다. 기본값: 42. | INT | 예 | 0 ~ 2147483647 |

**제약 사항:**

* 입력 비디오는 10분 이하여야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `VIDEO` | 원본 오디오 대신 생성된 사운드트랙이 적용된 입력 클립입니다. | VIDEO |
