FLUX 3를 사용하여 텍스트 프롬프트에서 오디오가 동기화된 비디오를 생성합니다. 이 노드는 프롬프트를 FLUX 3 서비스로 전송하고, 생성이 완료될 때까지 대기한 후 완성된 비디오 클립을 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 원하는 내용을 평이한 언어로 작성합니다. 프롬프트는 생성 전에 해석되고 확장됩니다. 레이어드 오디오를 위해 배경음, 음악, 음성을 각각 구분하여 설명하시기 바랍니다. (기본값: "") | STRING | 예 | 여러 줄 텍스트 |
| `aspect_ratio` | 출력 화면 비율입니다. 'auto'는 프롬프트와 입력에서 비율을 자동으로 선택합니다. (기본값: "auto") | COMBO | 예 | `"auto"`를 포함한 여러 옵션 사용 가능 |
| `duration` | 클립 길이(초)입니다. 'auto'는 콘텐츠에 맞게 길이를 자동으로 조정합니다. (기본값: "auto") | COMBO | 예 | `"auto"`를 포함한 여러 옵션 사용 가능 |
| `resolution` | 출력 해상도입니다. (기본값: "720p") | COMBO | 예 | `"720p"`<br />`"1080p"` |
| `generate_audio` | 동기화된 오디오(배경음, 음성, 효과음)를 생성합니다. 끄면 오디오 트랙이 없는 비디오가 생성됩니다. (기본값: True) | BOOLEAN | 예 | True<br />False |
| `safety_tolerance` | 모더레이션 허용 수준으로, 0이 가장 엄격합니다. 이미지나 비디오를 전송하는 요청은 설정 값과 관계없이 2로 제한됩니다. (기본값: 2) | INT | 예 | 0~4 |
| `seed` | 노드 재실행 여부를 결정하는 시드입니다. FLUX 3는 자체 시드를 선택하므로 이 값과 관계없이 실제 결과는 비결정적입니다. (기본값: 42) | INT | 예 | 0~4294967295 |

참고: `seed` 입력에는 UI의 Control After Generate 컨트롤이 포함됩니다. 표시되는 가격은 `resolution` 및 `duration`을 기준으로 산정됩니다. HD(720p)는 초당 $0.2431, FHD(1080p)는 초당 $0.4147이 청구됩니다. 고정 길이를 선택하면 클립의 총 예상 비용이 표시되고, `duration`이 "auto"인 경우에는 초당 요금이 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 생성된 비디오 클립입니다. `generate_audio`가 활성화된 경우 동기화된 오디오가 포함됩니다. | VIDEO |
