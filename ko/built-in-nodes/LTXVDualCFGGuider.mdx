이 노드는 LTXV-AV 모델을 위한 가이드 샘플링 객체(CFG 가이더)를 생성합니다. 패킹된 잠재 표현의 비디오 부분과 오디오 부분에 별도의 가이던스 스케일을 적용하여, 각 모달리티에 미치는 컨디셔닝의 영향을 독립적으로 제어할 수 있습니다. 두 스케일이 같거나 잠재 표현에 별도의 비디오 및 오디오 구성 요소가 포함되지 않은 경우 단일 전체 스케일이 사용됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 샘플링 시 사용할 모델입니다. | MODEL | 예 | - |
| `positive` | 생성 방향을 안내하는 긍정 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `negative` | 생성을 원치 않는 방향에서 멀어지게 하는 부정 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `video_cfg` | 잠재 표현의 비디오 모달리티에 적용되는 가이던스 강도입니다(기본값: 3.0). | FLOAT | 예 | 0.0 ~ 100.0 |
| `audio_cfg` | 잠재 표현의 오디오 모달리티에 적용되는 가이던스 강도입니다(기본값: 7.0). | FLOAT | 예 | 0.0 ~ 100.0 |

참고: `video_cfg`와 `audio_cfg`의 값이 같으면 가이더는 해당 값을 전체 잠재 표현에 대한 단일 CFG 스케일로 사용합니다. 잠재 표현이 패킹된 LTXV-AV 잠재 표현이 아닌 경우 `video_cfg` 값만 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `guider` | 샘플러 노드에 전달할 설정된 CFG 가이더입니다. | GUIDER |
