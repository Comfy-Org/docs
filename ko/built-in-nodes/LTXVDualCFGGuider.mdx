이 노드는 LTXV-AV 모델용 가이드 샘플링 객체(CFG 가이더)를 생성합니다. 패킹된 LTXV-AV 잠재의 비디오 부분과 오디오 부분에 각각 별도의 가이던스 스케일을 적용하여, 각 모달리티에 대한 컨디셔닝의 영향을 독립적으로 제어할 수 있게 합니다. 두 스케일이 같거나, 잠재에 별도의 비디오 및 오디오 구성 요소가 없는 경우에는 대신 하나의 전체 스케일이 사용됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 샘플링할 때 사용할 모델입니다. | MODEL | 예 | - |
| `positive` | 생성을 유도할 긍정 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `negative` | 생성이 벗어나도록 유도할 부정 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `video_cfg` | 잠재의 비디오 모달리티에 적용되는 가이던스 강도입니다(기본값: 3.0). | FLOAT | 예 | 0.0  ~  100.0 |
| `audio_cfg` | 잠재의 오디오 모달리티에 적용되는 가이던스 강도입니다(기본값: 7.0). | FLOAT | 예 | 0.0  ~  100.0 |

참고: `video_cfg`와 `audio_cfg`가 같거나(또는 값이 매우 가까우면) 가이더는 해당 값을 전체 잠재에 대한 단일 CFG 스케일로 사용합니다. 잠재가 패킹된 LTXV-AV 잠재가 아니면 `video_cfg` 값만 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `guider` | 샘플러 노드에 전달할 구성된 CFG 가이더입니다. | GUIDER |
