이 노드는 LTXV-AV 모델용 유도 샘플링 객체(CFG guider)를 생성합니다. 패킹된 잠재 변수의 비디오 부분과 오디오 부분에 각각 별도의 안내 스케일을 적용하여, 각 양식에 대한 컨디셔닝의 영향을 개별적으로 제어할 수 있게 합니다. 두 스케일이 같거나 잠재 변수에 비디오와 오디오 구성 요소가 분리되어 있지 않은 경우에는 단일 전체 스케일이 사용됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 샘플링 시 사용할 모델입니다. | MODEL | 예 | - |
| `positive` | 생성을 유도하기 위한 긍정 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `negative` | 생성을 회피하도록 유도하는 부정 컨디셔닝입니다. | CONDITIONING | 예 | - |
| `video_cfg` | 잠재 변수의 비디오 모달리티에 적용되는 안내 강도(기본값: 3.0)입니다. | FLOAT | 예 | 0.0 ~ 100.0 |
| `audio_cfg` | 잠재 변수의 오디오 모달리티에 적용되는 안내 강도(기본값: 7.0)입니다. | FLOAT | 예 | 0.0 ~ 100.0 |

참고: `video_cfg`와 `audio_cfg` 값이 같거나 매우 가까운 경우, guider는 해당 값을 전체 잠재 변수에 대한 단일 CFG 스케일로 사용합니다. 잠재 변수가 패킹된 LTXV-AV 잠재 변수가 아닌 경우 `video_cfg` 값만 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `guider` | 샘플러 노드에 전달할 구성된 CFG guider입니다. | GUIDER |
