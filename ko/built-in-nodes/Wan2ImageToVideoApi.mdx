Wan 2.7 Image to Video 노드는 첫 번째 프레임 이미지에서 시작하는 비디오를 생성합니다. 선택적으로 마지막 프레임 이미지를 제공하여 두 이미지 간의 전환을 만들거나, 오디오 파일을 제공하여 비디오의 움직임과 타이밍을 안내할 수 있습니다. 이 노드는 AI 모델을 사용하여 텍스트 설명에 따라 장면을 애니메이션화합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `model` | 비디오 생성에 사용할 AI 모델입니다. | DYNAMIC_COMBO | 예 | `"wan2.7-i2v"` |
| `first_frame` | 첫 번째 프레임 이미지입니다. 출력 비디오의 화면 비율은 이 이미지에서 파생됩니다. | IMAGE | 예 | - |
| `last_frame` | 마지막 프레임 이미지입니다. 모델이 첫 번째 프레임에서 마지막 프레임으로 전환되는 비디오를 생성합니다. | IMAGE | 아니요 | - |
| `audio` | 비디오 생성을 안내하는 오디오입니다(예: 립싱크, 비트 맞춤 동작). 지속 시간: 2초~30초. 제공하지 않으면 모델이 자동으로 어울리는 배경 음악이나 효과음을 생성합니다. | AUDIO | 아니요 | - |
| `seed` | 생성에 사용할 시드 값입니다(기본값: 0). | INT | 예 | 0 ~ 2147483647 |
| `prompt_extend` | AI 지원으로 프롬프트를 향상시킬지 여부입니다(기본값: True). 고급 설정입니다. | BOOLEAN | 예 | True<br />False |
| `watermark` | 결과물에 AI 생성 워터마크를 추가할지 여부입니다(기본값: False). 고급 설정입니다. | BOOLEAN | 예 | True<br />False |

### wan2.7-i2v 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `prompt` | 요소와 시각적 특징을 설명하는 프롬프트입니다. 영어와 중국어를 지원합니다. (기본값: 비어 있음) | STRING | 예 | - |
| `negative_prompt` | 피해야 할 내용을 설명하는 네거티브 프롬프트입니다. (기본값: 비어 있음) | STRING | 예 | - |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | `"720P"`<br />`"1080P"` |
| `duration` | 생성된 비디오의 길이(초)입니다(기본값: 5). | INT | 예 | 2 ~ 15 |

**참고:** `audio` 입력에는 지속 시간 제한이 있습니다. 제공하는 경우 오디오 파일은 2초에서 30초 사이여야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `output` | 생성된 비디오 파일입니다. | VIDEO |
