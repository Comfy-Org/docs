HeyGen Voice 1.0을 사용하여 한 화자의 녹음에서 음성을 복제하고, 그 음성으로 텍스트를 말합니다. 이 노드는 녹음을 업로드하고 음성을 합성한 뒤 오디오로 반환하므로, 단일 노드로 음성 샘플에서 완성된 음성까지 처리할 수 있습니다.

`model`을 선택하면 해당 모델에 특화된 매개변수가 표시됩니다: `audio`, `text`, `language`, `expressiveness_boost`, `recording_language`, `similarity`, `remove_background_noise`, `seed`.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 사용할 모델입니다. `heygen-voice-1-turbo`는 더 빠르고 비용이 적게 듭니다(기본값: `"heygen-voice-1"`). | DYNAMIC_COMBO | 예 | `"heygen-voice-1"`<br />`"heygen-voice-1-turbo"` |
| `audio` | 복제할 한 화자의 녹음입니다. 최소 10초 이상의 명확한 음성을 사용하세요. 처음 3분만 사용됩니다. | AUDIO | 예 | - |
| `text` | 말할 텍스트이며 최대 5000자입니다. 약 12분을 초과하는 음성은 실패하므로 매우 긴 중국어 또는 일본어 텍스트는 분할하세요(기본값: 비어 있음). | STRING | 예 | 1 ~ 5000자 |
| `language` | 텍스트의 언어입니다. 자동 감지가 혼동할 수 있는 세르비아어 또는 말레이어처럼 서로 가까운 언어의 경우 설정하세요(기본값: `"auto"`). | COMBO | 예 | `"auto"`<br />여러 언어 프리셋 |
| `expressiveness_boost` | 값이 높을수록 더 표현력이 풍부하고, 낮을수록 원래 음성에 더 가깝습니다(기본값: 0.5). | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.05) |
| `recording_language` | 녹음에서 사용된 언어이며, 복제 음성을 해당 언어로 좁힙니다(기본값: `"auto"`). | COMBO | 예 | `"auto"`<br />여러 언어 프리셋 |
| `similarity` | 음성이 녹음을 얼마나 밀접하게 따르는지입니다(기본값: `"max"`). | COMBO | 예 | `"medium"`<br />`"high"`<br />`"extra_high"`<br />`"max"` |
| `remove_background_noise` | 복제 전에 녹음의 배경 소음을 정리합니다(기본값: True). | BOOLEAN | 예 | `True`<br />`False` |
| `seed` | 시드는 노드의 재실행 여부를 제어합니다. 결과는 시드와 관계없이 비결정적입니다(기본값: 42). | INT | 예 | 0 ~ 2147483647 |

`text`에는 최소 한 글자가 포함되어야 하며 `audio`는 필수입니다. 여러 화자의 녹음이거나 복제하기에 너무 잡음이 많은 녹음은 품질이 낮은 음성을 생성합니다. 샘플의 언어가 명확하지 않을 때는 `recording_language`를 설정하세요.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `AUDIO` | 복제된 음성으로 말한 텍스트입니다. | AUDIO |
