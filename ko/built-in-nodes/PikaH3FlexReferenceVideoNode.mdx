이 노드는 참조 이미지, 비디오 및 오디오 클립을 기반으로 동기화된 오디오가 포함된 비디오를 생성하거나 편집합니다. Pika H3 Flex는 Pika가 추가 학습시킨 MiniMax H3 모델입니다. 참조를 연결하고 프롬프트에서 연결 순서에 따라 `@Image1`, `@Video1` 또는 `@Audio1`로 지정하세요. 참조 이미지 또는 비디오가 최소 하나 필요하며, 총 최대 12개의 참조를 연결할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | 최대 9개 이미지이며, 프롬프트에서 연결 순서에 따라 `@Image1`부터 `@Image9`로 지정합니다. 이미지 또는 비디오가 최소 하나 필요합니다. | AUTOGROW | 아니요 | 0~9개 이미지 |
| `reference_videos` | 최대 3개 클립이며, 프롬프트에서 연결 순서에 따라 `@Video1`부터 `@Video3`로 지정합니다. 각 클립은 2~15초여야 하며, 클립 총 길이는 15초 이하여야 합니다. 초 단위로 과금됩니다. | AUTOGROW | 아니요 | 0~3개 비디오 |
| `reference_audios` | 최대 3개 클립이며, 프롬프트에서 `@Audio1`부터 `@Audio3`로 지정합니다. 각 클립은 2~15초여야 하며, 클립 총 길이는 15초 이하여야 합니다. 출력으로 복사되면 클립은 연결된 비디오의 사운드보다 앞서 연결 순서대로 재생됩니다. | AUTOGROW | 아니요 | 0~3개 오디오 클립 |
| `prompt` | 생성할 내용 또는 수행할 편집입니다. 참조는 `@Image1`, `@Video1`, `@Audio1` 또는 `<Picture 1>`, `<Video 1>`, `<Audio 1>`로 지정합니다. 비어 있으면 안 됩니다. 기본값: "" (빈 문자열). | STRING | 예 | 1~8000자 |
| `reference_video_audio` | 연결된 비디오의 사운드를 출력에 복사합니다. 새로운 앰비언스가 필요하거나 새 음악으로 모션 트랜스퍼를 하려면 끄세요. 그러면 프롬프트에 대사가 없는 토킹 헤드에는 새로 생성된 음성이 적용됩니다. 기본값: True. | BOOLEAN | 예 | true<br />false |
| `resolution` | 출력 해상도입니다. `"1080p"` 이상은 768p로 렌더링한 뒤 한 번 업스케일합니다. 480p에서는 동일한 시드라도 다른 비디오가 생성됩니다. 기본값: `"768p"`. | COMBO | 예 | `"480p"`<br />`"768p"`<br />`"1080p"`<br />`"2k"`<br />`"4k"` |
| `aspect_ratio` | 출력 화면 비율입니다. `"auto"`는 참조 비디오를 따르고, 그렇지 않으면 프롬프트를 따릅니다. 참조 이미지는 영향을 주지 않습니다. 기본값: `"auto"`. | COMBO | 예 | `"auto"`<br />`"21:9"`<br />`"16:9"`<br />`"3:2"`<br />`"4:3"`<br />`"5:4"`<br />`"1:1"`<br />`"4:5"`<br />`"3:4"`<br />`"2:3"`<br />`"9:16"`<br />`"9:21"` |
| `duration` | 클립 길이(초)입니다. 출력 길이는 프레임 그리드를 따르며, 5초는 124프레임으로 약 5.17초입니다. 기본값: 5. | INT | 예 | 5~15초 |
| `rewrite_prompt` | Pika가 프롬프트를 먼저 확장하도록 합니다. 그러면 동일한 시드라도 실행할 때마다 다른 비디오가 생성됩니다. 기본값: False. | BOOLEAN | 예 | true<br />false |
| `seed` | 샘플링용 시드입니다. `rewrite_prompt`가 꺼져 있으면 동일한 시드는 비디오를 정확히 반복하지만, 동일한 시드로 로컬에서 실행하면 다른 결과가 나옵니다. 기본값: 42. | INT | 예 | 0~2147483647 |

**제약 사항:**

* 참조 이미지 또는 비디오가 최소 하나 필요합니다.
* 이미지, 비디오, 오디오 클립을 모두 합쳐 총 최대 12개의 참조를 연결할 수 있습니다.
* 각 참조 비디오와 오디오 클립은 2~15초여야 하며, 비디오 총 길이는 15초 이하, 오디오 클립 총 길이는 15초 이하여야 합니다.
* 프롬프트는 1~8000자 사이여야 합니다.
* 연결되지 않은 슬롯을 참조하면(예: 이미지 두 개를 제공한 상태에서 `@Image3` 참조) 오류가 발생합니다.
