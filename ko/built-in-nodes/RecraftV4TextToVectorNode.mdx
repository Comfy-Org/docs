Recraft V4 Text to Vector 노드는 Recraft V4 및 V4.1 모델을 사용하여 텍스트 설명에서 확장 가능한 벡터 그래픽(SVG) 일러스트레이션을 생성합니다. Recraft API에 연결되어 프롬프트를 기반으로 하나 이상의 SVG 파일을 생성하며, 기존 벡터 스타일을 적용하거나 참조 이미지에서 새 스타일을 만들 수 있습니다. 참조 이미지를 사용하면 생성된 스타일이 재사용할 수 있도록 `style_id`로 반환됩니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 생성에 사용할 모델입니다. recraftv4_styles 모델은 일관된 스타일 생성을 위해 설계되었으며 항상 style_id 또는 style_references가 필요합니다. 모델을 선택하면 사용 가능한 `size` 옵션이 변경됩니다. | DYNAMIC_COMBO | 예 | `"recraftv4_1_vector"`<br />`"recraftv4_1_utility_vector"`<br />`"recraftv4_1_pro_vector"`<br />`"recraftv4_1_utility_pro_vector"`<br />`"recraftv4"`<br />`"recraftv4_pro"`<br />`"recraftv4_styles_vector"`<br />`"recraftv4_styles_pro_vector"` |
| `prompt` | 이미지 생성용 프롬프트입니다. 최대 10,000자입니다. | STRING | 예 | N/A |
| `negative_prompt` | 이 입력은 무시됩니다. Recraft V4 및 V4.1 모델은 네거티브 프롬프트를 지원하지 않습니다. | STRING | 예 | N/A |
| `n` | 생성할 이미지 수입니다(기본값: 1). | INT | 예 | 1 ~ 6 |
| `seed` | 노드 재실행 여부를 결정하는 시드입니다. 실제 결과는 시드와 관계없이 비결정적입니다(기본값: 0). | INT | 예 | 0 ~ 18446744073709551615 |
| `recraft_controls` | Recraft Controls 노드를 통해 생성 과정을 추가로 제어할 수 있는 선택적 옵션입니다. | CUSTOM | 아니요 | N/A |
| `style_id` | 적용할 Recraft V4 벡터 스타일의 UUID입니다(예: Recraft V4 Create Style 노드 또는 이전 실행의 style_id 출력). style_references와 함께 사용할 수 없습니다. | STRING | 아니요 | N/A |
| `style_match` | 스타일을 얼마나 밀접하게 따를지 결정합니다. precise는 세부 사항까지 정확하게 재현하고, flexible는 전반적인 느낌을 맞춥니다. 스타일이 제공된 경우에만 사용됩니다(기본값: "precise"). | COMBO | 아니요 | `"precise"`<br />`"flexible"` |

### recraftv4_1_vector, recraftv4_1_utility_vector, recraftv4 및 recraftv4_styles_vector 입력

이 모델들은 동일한 `size` 옵션을 공유합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `size` | 생성된 이미지의 크기입니다. 기본값은 `"1024x1024"`입니다. | COMBO | 예 | `"1024x1024"`<br />`"1152x896"`<br />`"896x1152"`<br />`"1216x832"`<br />`"832x1216"`<br />`"1344x768"`<br />`"768x1344"`<br />`"1536x640"`<br />`"640x1536"` |

### recraftv4_1_pro_vector, recraftv4_1_utility_pro_vector, recraftv4_pro 및 recraftv4_styles_pro_vector 입력

이 모델들은 동일한 `size` 옵션을 공유합니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `size` | 생성된 이미지의 크기입니다. 기본값은 `"2048x2048"`입니다. | COMBO | 예 | `"2048x2048"`<br />`"2304x1792"`<br />`"1792x2304"`<br />`"2432x1664"`<br />`"1664x2432"`<br />`"2688x1536"`<br />`"1536x2688"`<br />`"3072x1280"`<br />`"1280x3072"` |

### 참조 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `style_references` | 즉시 벡터 스타일을 생성하기 위한 참조 이미지이며, 생성 비용에 추가로 청구됩니다. 생성된 스타일은 재사용을 위해 style_id로 반환됩니다. style_id와 함께 사용할 수 없습니다. | IMAGE | 아니요 | 확장 가능한 슬롯: 참조 이미지 1..N개 연결 가능(노드의 최대 한도까지) |

**참고:** `size` 매개변수는 선택한 `model`에 따라 사용 가능한 옵션이 변경되는 동적 입력입니다. `seed` 값은 외부 API에서 재현 가능한 결과를 보장하지 않습니다. `recraftv4_styles_vector` 및 `recraftv4_styles_pro_vector` 모델은 항상 스타일이 필요합니다. `style_id`를 제공하거나 `style_references` 이미지를 하나 이상 연결하세요. `style_id`와 `style_references`는 함께 사용할 수 없습니다. 둘 다 제공하면 오류가 발생하며, `style_id`는 유효한 UUID여야 합니다. 참조 이미지는 개수가 제한되며 총 인코딩 크기가 10MB를 초과해서는 안 됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `output` | 생성된 확장 가능한 벡터 그래픽(SVG) 이미지입니다. | SVG |
| `style_id` | Recraft API가 반환하는 스타일 UUID입니다. 참조 이미지가 제공되면 생성된 스타일이 재사용을 위해 여기에 반환되며, 그렇지 않으면 빈 문자열입니다. | STRING |
