이 노드는 디코딩된 Marigold V2 예측을 표시 가능한 이미지로 변환합니다. 원시 예측 텐서를 받아 예측 유형에 따라 형식을 지정합니다: 정규화된 깊이(가까운 객체가 밝게 표시됨), 단위 길이 표면 법선 또는 sRGB albedo.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 표시 가능한 이미지로 변환할 디코딩된 Marigold V2 예측입니다. | IMAGE | 예 | - |
| `prediction` | 입력에 포함된 예측 유형으로, 데이터 변환 방식을 결정합니다. `"depth"`는 깊이 값을 정규화하여 가까운 표면은 밝게, 먼 표면은 어둡게 만든 다음 결과를 세 색상 채널 모두에 복사합니다. `"normals"`는 값을 -1..1 범위로 재조정하고, 단위 표면 법선으로 정규화한 뒤 0..1로 다시 매핑합니다. `"albedo"`는 값에 선형에서 sRGB로의 변환을 적용합니다. | COMBO | 예 | `"depth"`<br />`"normals"`<br />`"albedo"` |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `IMAGE` | 선택된 표현으로 처리된 이미지: 정규화된 깊이(세 채널에 반복된 그레이스케일), 단위 표면 법선 또는 sRGB albedo입니다. | IMAGE |
