이 노드는 Wan 3.0 모델을 사용하여 첫 프레임 이미지로부터 비디오를 생성합니다. 마지막 프레임 이미지를 선택적으로 제공하여 비디오의 종료 방식을 제어할 수 있습니다. 그러면 모델이 첫 프레임에서 마지막 프레임으로 전환되는 비디오를 생성합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `모델` | 사용할 Wan 3.0 모델 변형을 선택하고 아래에 표시되는 모델별 설정을 결정합니다. | DYNAMIC_COMBO | 예 | "wan3.0-video"<br />"wan3.0-video-prime" |
| `첫 프레임` | 첫 프레임 이미지입니다. 정확히 하나의 이미지가 필요합니다. | IMAGE | 예 | 단일 이미지 |
| `마지막 프레임` | 마지막 프레임 이미지입니다. 모델은 첫 프레임에서 마지막 프레임으로 전환되는 비디오를 생성합니다. 선택 사항이며, 제공하는 경우 정확히 하나의 이미지가 필요합니다. | IMAGE | 아니요 | 단일 이미지 |
| `시드` | 생성에 사용할 시드입니다(기본값: 42). | INT | 예 | 0 - 2147483647 |
| `워터마크` | 결과에 AI 생성 워터마크를 추가할지 여부입니다(기본값: false). | BOOLEAN | 예 | true<br />false |

### wan3.0-video 및 wan3.0-video-prime 입력

이러한 모델별 설정은 두 모델 옵션에서 공통으로 사용되며, 모델을 선택하면 표시됩니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 요소와 시각적 특징을 설명하는 프롬프트입니다. 영어와 중국어를 지원합니다. 비워 둘 수 있습니다(기본값: 비어 있음). | STRING | 예 | 최대 20,000자 |
| `resolution` | 출력 비디오의 해상도입니다. | COMBO | 예 | "1080P"<br />"720P"<br />"480P" |
| `ratio` | 출력 비디오의 화면 비율입니다. "adaptive"인 경우 출력 크기는 첫 프레임에서 파생됩니다. | COMBO | 예 | "adaptive"<br />"16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4" |
| `duration` | 출력 지속 시간(초)입니다. "auto"인 경우 모델이 프롬프트에 맞는 지속 시간을 선택합니다. | COMBO | 예 | "auto"<br />"2" - "30" |
| `audio` | 출력 비디오에 오디오 트랙이 포함되는지 여부입니다(기본값: true). | BOOLEAN | 예 | true<br />false |
| `prompt_extend` | AI 지원으로 프롬프트를 향상할지 여부입니다(기본값: true). | BOOLEAN | 예 | true<br />false |

참고: 노드는 정확히 하나의 `first_frame` 이미지와 선택적으로 하나의 `last_frame` 이미지를 허용합니다. 두 입력 중 하나에 둘 이상의 이미지가 연결되면 오류가 발생합니다. `last_frame`이 제공되면 생성된 비디오는 첫 프레임에서 마지막 프레임으로 전환됩니다. `prompt`는 20,000자로 제한됩니다. 실행 비용은 선택한 `model`, `resolution`, `duration`에 따라 달라집니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 생성된 비디오입니다. `audio` 옵션이 활성화되면 오디오 트랙이 포함됩니다. | VIDEO |
