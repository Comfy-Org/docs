LTXVImgToVideo는 입력 이미지를 비디오 생성 모델용 비디오 잠재 표현으로 변환합니다. 이미지를 요청된 너비와 높이로 크기를 조정하고, VAE로 인코딩한 후, 인코딩된 프레임을 0으로 채워진 비디오 크기 잠재 공간의 시작 부분에 배치합니다. 강도(strength) 제어는 비디오 생성 중 원본 이미지 콘텐츠가 보존되는 정도와 수정되는 정도를 결정합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `긍정 조건` | 비디오 생성을 안내하기 위한 긍정 조건 프롬프트 | CONDITIONING | 예 | - |
| `부정 조건` | 비디오에서 특정 요소를 피하기 위한 부정 조건 프롬프트 | CONDITIONING | 예 | - |
| `vae` | 입력 이미지를 잠재 공간으로 인코딩하는 데 사용되는 VAE 모델 | VAE | 예 | - |
| `이미지` | 비디오 프레임으로 변환할 입력 이미지 | IMAGE | 예 | - |
| `너비` | 출력 비디오 너비(픽셀 단위, 기본값: 768, 증가 단위: 32) | INT | 아니요 | 64 to MAX_RESOLUTION |
| `높이` | 출력 비디오 높이(픽셀 단위, 기본값: 512, 증가 단위: 32) | INT | 아니요 | 64 to MAX_RESOLUTION |
| `길이` | 생성된 비디오의 프레임 수(기본값: 97, 증가 단위: 8) | INT | 아니요 | 9 to MAX_RESOLUTION |
| `배치 크기` | 동시에 생성할 비디오 수(기본값: 1) | INT | 아니요 | 1 ~ 4096 |
| `강도` | 생성된 비디오의 첫 프레임에서 원본 이미지 콘텐츠가 얼마나 보존되는지 제어합니다. 1.0 값은 원본 이미지를 완전히 보존하고, 0.0은 최대 수정을 허용합니다(기본값: 1.0) | FLOAT | 아니요 | 0.0 ~ 1.0 |

참고: `width`와 `height`는 32픽셀 단위로 변경되고, `length`는 8프레임 단위로 변경되며, 이는 비디오 잠재 압축(공간 차원에서 32배, 시간 차원에서 8배)과 일치합니다. 비디오 잠재 공간에는 ((length - 1) // 8) + 1개의 프레임이 포함됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `긍정 조건` | 생성된 잠재 공간과 함께 사용하기 위해 변경 없이 통과된 긍정 조건 | CONDITIONING |
| `부정 조건` | 생성된 잠재 공간과 함께 사용하기 위해 변경 없이 통과된 부정 조건 | CONDITIONING |
| `잠재 데이터` | 인코딩된 이미지 프레임과 비디오 생성 중 조건이 적용되는 강도를 제어하는 노이즈 마스크를 포함하는 비디오 잠재 표현 | LATENT |
