이 노드는 베이크된 텍스처 이미지를 메시의 UV 레이아웃에 부착하여 SaveGLB 노드에서 메시와 함께 내보낼 수 있도록 합니다. 텍스처를 베이크한 대상과 동일한 UV 펼침 메시와 베이크된 이미지 맵을 입력으로 제공하세요. 선택적인 metallic, roughness, occlusion 맵은 단일 ORM 텍스처로 패킹되며, normal map을 제공하면 올바른 셰이딩에 필요한 스무스 정점 노멀과 탄젠트 기저도 저장됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 베이크된 텍스처를 부착할 UV가 펼쳐진 메시입니다. 베이킹 중 사용한 것과 동일한 메시여야 하며, 메시에 UV가 없으면 오류가 발생합니다. | MESH | 예 | — |
| `base_color` | 베이크된 베이스 컬러 이미지입니다. 메시의 텍스처로 저장되며 0-1 범위로 클램프됩니다. | IMAGE | 예 | — |
| `metallic` | 베이크된 메탈릭 맵입니다. 결합된 ORM 텍스처의 파란색 채널로 사용되며, 제공되지 않으면 기본값은 0입니다. | IMAGE | 아니요 | — |
| `roughness` | 베이크된 러프니스 맵입니다. 결합된 ORM 텍스처의 초록색 채널로 사용되며, 제공되지 않으면 기본값은 1입니다. | IMAGE | 아니요 | — |
| `occlusion` | 베이크된 앰비언트 오클루전 맵입니다. 결합된 ORM 텍스처의 빨간색 채널로 사용되며, 제공되지 않으면 기본값은 1입니다. 제공되면 ORM 텍스처가 SaveGLB의 오클루전 텍스처로도 지정됩니다. | IMAGE | 아니요 | — |
| `normal_map` | 베이크된 탄젠트 공간 노멀 맵입니다. 제공되면 노드가 정점별 탄젠트를 다시 계산하고 스무스 정점 노멀을 내보내어 노멀 맵이 올바르게 셰이딩되도록 합니다. | IMAGE | 아니요 | — |

참고: `mesh` 입력에는 UV 좌표가 있어야 합니다. 그렇지 않으면 노드가 베이킹에 사용한 것과 동일한 UV 펼침 메시를 연결하라는 오류를 발생시킵니다.

참고: `metallic`, `roughness`, `occlusion` 중 하나라도 연결되면 세 맵 모두 채널 R = occlusion, G = roughness, B = metallic인 단일 glTF ORM 텍스처로 패킹됩니다. 누락된 맵은 기본값(occlusion 1, roughness 1, metallic 0)으로 채워지며, 해상도가 다른 맵은 제공된 맵 중 가장 큰 너비와 높이로 크기 조정됩니다.

참고: `normal_map`이 연결되면 메시에 저장된 노멀이 계산된 스무스 정점 노멀로 대체되고 정점별 탄젠트 기저가 추가됩니다. [0,1] 범위를 벗어나는 UV 좌표는 종횡비를 유지하면서 [0,1] 범위로 균일하게 스케일됩니다. UV 범위가 타일형/UDIM 레이아웃처럼 보이면 경고가 기록됩니다. 배치 메시의 경우 UV 정규화는 베이킹 단계와 동일한 로직을 사용하여 배치의 각 항목에 개별적으로 적용되므로 두 단계가 정렬된 상태로 유지됩니다.
