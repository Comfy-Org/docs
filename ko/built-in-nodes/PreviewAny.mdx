PreviewAny는 모든 입력 값을 읽을 수 있는 텍스트로 변환하여 검사할 수 있게 합니다. 문자열은 변경 없이 그대로 전달되고, 숫자와 불리언은 일반 텍스트가 되며, 그 밖의 데이터 유형은 가능한 경우 JSON으로 직렬화됩니다(직렬화에 실패하면 일반 문자열 형식으로 대체됩니다). 결과 텍스트는 사용자 인터페이스에 표시되며, 추가 처리를 위해 문자열 출력으로도 반환됩니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `소스` | 미리보기 표시를 위해 모든 입력 데이터 유형을 받습니다. 값이 제공되지 않으면 미리보기에 'None'이 표시됩니다. | ANY | 예 | 모든 데이터 유형 |

**변환 동작**

- STRING 유형의 값은 제공된 그대로 표시됩니다.
- INT, FLOAT, BOOLEAN 유형의 값은 일반 텍스트로 변환됩니다.
- 그 밖의 비어 있지 않은 값은 4칸 들여쓰기로 JSON 텍스트로 변환됩니다. 해당 변환이 실패하면 노드는 값의 일반 텍스트 형식으로 대체합니다. 그것마저 실패하면 미리보기에 'source exists, but could not be serialized.'라는 메시지가 표시됩니다.
- 값이 연결되지 않았거나 값이 비어 있으면 미리보기에 'None'이 표시됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `result` | 텍스트 형식으로 변환된 입력 값입니다. 동일한 텍스트가 사용자 인터페이스에도 표시됩니다. | STRING |
