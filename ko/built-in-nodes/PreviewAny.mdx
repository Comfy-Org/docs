PreviewAny는 모든 입력 값을 읽을 수 있는 텍스트로 변환하여 검사할 수 있게 합니다. 문자열은 변경 없이 그대로 전달되며, 숫자와 부울 값은 일반 텍스트가 됩니다. 그 외 데이터 유형은 가능한 경우 JSON으로 직렬화되며, 직렬화에 실패하면 일반 문자열 형태로 대체됩니다. 결과 텍스트는 사용자 인터페이스에 표시되고, 추가 처리를 위해 문자열 출력으로도 반환됩니다.

## 입력

| 매개변수 | 설명 | 데이터 유형 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `소스` | 미리보기 표시를 위해 모든 입력 데이터 유형을 허용합니다. 값이 제공되지 않으면 미리보기에 'None'으로 표시됩니다. | ANY | 예 | 모든 데이터 유형 |

## 출력

| 출력 이름 | 설명 | 데이터 유형 |
| --- | --- | --- |
| `result` | 입력 값을 텍스트 형식으로 변환한 결과입니다. 동일한 텍스트가 사용자 인터페이스에도 표시됩니다. | STRING |
