## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `소스` | 미리보기 표시를 위해 모든 입력 데이터 타입을 허용합니다. 값이 제공되지 않으면 미리보기에 'None'이 표시됩니다. | ANY | 예 | 모든 데이터 타입 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `result` | 입력 값을 텍스트 형식으로 변환한 것입니다. 동일한 텍스트가 사용자 인터페이스에도 표시됩니다. | STRING |
