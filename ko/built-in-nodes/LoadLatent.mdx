LoadLatent 노드는 입력 디렉토리의 .latent 파일에서 이전에 저장된 잠재 표현을 로드합니다. 선택한 파일에서 잠재 텐서 데이터를 읽고 필요한 스케일링 조정을 적용한 후, 다른 노드에서 사용할 수 있도록 잠재 데이터를 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `잠재 데이터` | 입력 디렉토리의 사용 가능한 파일 중에서 로드할 .latent 파일을 선택합니다. | COMBO | 예 | 입력 디렉토리의 모든 .latent 파일 (동적 목록, 알파벳순 정렬) |

참고: 사용 가능한 파일 목록은 동적으로 생성되며 입력 디렉토리에 존재하는 .latent 확장자 파일만 포함됩니다. 선택한 파일이 더 이상 존재하지 않으면 노드는 이를 유효하지 않은 latent 파일로 보고합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `LATENT` | 선택한 파일에서 로드된 잠재 표현 데이터를 float 텐서로 반환합니다. 파일에 `latent_format_version_0` 마커가 포함되어 있지 않으면 텐서는 반환되기 전에 1/0.18215로 스케일링되며, 마커가 포함된 파일은 저장된 스케일 그대로 반환됩니다. | LATENT |
