이 노드는 PixVerse V6 모델을 사용하여 기존 비디오를 이어서 생성하며, 선택적으로 연속 생성 영상과 함께 기본 오디오 트랙을 생성합니다. 소스 비디오는 40초 미만이어야 하며 가로와 세로 모두 1920픽셀을 초과할 수 없습니다. 출력은 소스 비디오의 해상도를 유지하므로 품질 설정은 프레임 크기가 아닌 연속 영상의 렌더링 품질을 제어합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `video` | 이어서 생성할 비디오입니다. | VIDEO | 예 | 40초 미만, 가로 및 세로 최대 1920픽셀 |
| `model` | 모델 및 생성 설정입니다. | DYNAMIC_COMBO | 예 | "PixVerse V6" |

### PixVerse V6 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 비디오가 어떻게 이어져야 하는지 설명하는 프롬프트입니다. (기본값: 비어 있음) | STRING | 예 | 1–5000자 |
| `quality` | 생성된 연속 영상의 렌더링 품질입니다. 1080p는 540p나 360p보다 눈에 띄게 좋습니다. 크기를 조정하지 않으며 출력은 소스 비디오의 해상도를 유지합니다. (기본값: "720p") | COMBO | 예 | "360p"<br />"540p"<br />"720p"<br />"1080p" |
| `duration_seconds` | 생성된 비디오의 길이(초)입니다. (기본값: 5) | INT | 예 | 1–15 |
| `generate_audio` | 비디오와 함께 기본 오디오 트랙을 생성합니다. (기본값: true) | BOOLEAN | 예 | true / false |
| `seed` | 비디오 생성용 시드입니다. PixVerse는 이를 기록하지만 이를 통해 실행을 재현하지는 않습니다. (기본값: 42) | INT | 예 | 0–2147483647 |
| `negative_prompt` | 비디오에서 원치 않는 요소에 대한 선택적 텍스트 설명입니다. (기본값: 비어 있음) | STRING | 아니요 | 최대 2048자 |
| `style` | 전체 비디오에 적용되는 선택적 시각적 스타일입니다. (기본값: "none") | COMBO | 아니요 | 여러 옵션 사용 가능, 기본값은 "none"입니다 |

**참고:** 소스 `video`는 40초 미만이어야 하며 가로와 세로 모두 최대 1920픽셀이어야 합니다. 더 길거나 더 큰 비디오는 거부됩니다. 생성된 출력은 소스 비디오의 해상도를 유지하므로 `quality`는 출력 프레임 크기가 아닌 렌더링 품질을 변경합니다. `prompt`는 필수이며 공백을 제거한 후 1자에서 5000자 사이여야 합니다. `negative_prompt`는 제공하는 경우 2048자로 제한됩니다. `seed`는 PixVerse에 기록되지만 동일한 실행을 재현하는 데 사용할 수 없습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `video` | 소스 비디오와 동일한 해상도로 생성된 연속 비디오입니다. | VIDEO |
