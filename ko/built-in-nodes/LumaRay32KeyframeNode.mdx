이 노드는 가이드 이미지를 Luma Ray 3.2 출력 비디오 타임라인의 특정 위치에 고정합니다. 이 노드를 Luma Ray 3.2 Keyframes to Video 노드의 `keyframes` 입력에 연결하고, 선택적 `keyframes` 입력을 연결하여 여러 키프레임을 함께 체인으로 묶습니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 출력 비디오의 선택한 시점에 배치할 가이드 이미지입니다. | IMAGE | 예 | - |
| `position` | 출력 비디오 타임라인에 이 이미지를 배치하는 방식입니다. | DYNAMIC_COMBO | 예 | "Fraction of duration (0.0-1.0)"<br />"Absolute time (seconds)" |
| `keyframes` | 이 키프레임과 연결할 선택적 이전 키프레임입니다. | LUMA_RAY32_KEYFRAME | 아니요 | - |

### Fraction of duration (0.0-1.0) 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `fraction` | 이 이미지가 출력 비디오의 어디에 적용되는지 나타냅니다(0.0 = 시작, 1.0 = 끝). 기본값: 0.0. | FLOAT | 예 | 0.0 ~ 1.0 (단계: 0.01) |

### Absolute time (seconds) 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `seconds` | 출력 비디오 시작부터 이 이미지가 적용되는 시간(초)입니다. 기본값: 0.0. | FLOAT | 예 | 0.0 ~ 10.0 (단계: 0.1) |

`position` 매개변수는 타임라인에 이미지를 배치할 때 어떤 값을 사용할지 결정합니다. 선택한 옵션에 속하는 하위 매개변수만 표시되고 사용됩니다: "Fraction of duration (0.0-1.0)"의 경우 `fraction`, "Absolute time (seconds)"의 경우 `seconds`입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-----------|-----------|
| `keyframes` | 새 키프레임과 선택적 이전 키프레임들을 결합한 키프레임 체인입니다. | LUMA_RAY32_KEYFRAME |
