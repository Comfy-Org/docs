이 노드는 Luma Ray 3.2 출력 비디오 타임라인의 특정 위치에 가이드 이미지를 고정합니다. 이 노드를 Luma Ray 3.2 Keyframes to Video 노드의 "keyframes" 입력에 연결하고, 선택적 "keyframes" 입력을 연결하여 여러 키프레임을 함께 연결할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image` | 출력 비디오의 선택한 시점에 배치할 가이드 이미지입니다. | IMAGE | 예 | - |
| `position` | 이 이미지를 출력 비디오 타임라인에 배치하는 방법입니다. | DYNAMIC_COMBO | 예 | "Fraction of duration (0.0-1.0)"<br />"Absolute time (seconds)" |
| `keyframes` | 이 키프레임과 연결할 선택적 이전 키프레임입니다. | LUMA_RAY32_KEYFRAME | 아니요 | - |

`position` 매개변수는 이미지를 타임라인에 배치하는 데 사용할 값을 결정합니다.

`position` 매개변수에 "Fraction of duration (0.0-1.0)"을 선택하면 `fraction` 값을 지정할 수 있습니다(기본값: 0.0, 범위: 0.0~1.0, 단계: 0.01). 이 값은 출력 비디오에서 이 이미지가 적용되는 위치를 결정합니다(0.0 = 시작, 1.0 = 끝).

`position` 매개변수에 "Absolute time (seconds)"을 선택하면 `seconds` 값을 지정할 수 있습니다(기본값: 0.0, 범위: 0.0~10.0, 단계: 0.1). 이 값은 출력 비디오 시작부터 이 이미지가 적용되는 시간(초)을 결정합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `keyframes` | 새 키프레임과 선택적 이전 키프레임을 결합한 키프레임 체인입니다. | LUMA_RAY32_KEYFRAME |
