WanAnimate2ToVideo는 별도의 포즈 비디오에서 표정, 신체 동작, 손 제스처를 전이하여 참조 이미지의 캐릭터를 애니메이션화합니다. 비디오 생성 샘플러가 애니메이션을 만드는 데 사용하는 컨디셔닝 데이터와 시작 잠재 변수를 구축합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 비디오 생성을 위한 긍정 컨디셔닝입니다. | CONDITIONING | 예 | N/A |
| `negative` | 비디오 생성을 위한 부정 컨디셔닝입니다. | CONDITIONING | 예 | N/A |
| `vae` | 참조 이미지와 비디오 프레임을 잠재 공간으로 인코딩하는 데 사용되는 VAE입니다. | VAE | 예 | N/A |
| `width` | 출력 비디오의 너비(픽셀)입니다. (기본값: 832) | INT | 예 | 16 ~ MAX_RESOLUTION (단계 16) |
| `height` | 출력 비디오의 높이(픽셀)입니다. (기본값: 480) | INT | 예 | 16 ~ MAX_RESOLUTION (단계 16) |
| `length` | 생성할 프레임 수입니다. (기본값: 81) | INT | 예 | 1 ~ MAX_RESOLUTION (단계 4) |
| `batch_size` | 동시에 생성할 비디오 수입니다. (기본값: 1) | INT | 예 | 1 ~ 4096 |
| `reference_image` | 애니메이션화할 캐릭터입니다. 생략하면 검은색 이미지가 사용됩니다. | IMAGE | 아니요 | N/A |
| `pose_video` | 모션이 참조 캐릭터로 전이되는 비디오입니다. 프레임 수가 `length`보다 적으면 마지막 프레임이 반복되어 부족한 프레임을 채웁니다. | IMAGE | 아니요 | N/A |
| `clip_vision_output` | 참조 이미지의 CLIP 비전입니다. | CLIP_VISION_OUTPUT | 아니요 | N/A |
| `positive_pose` | 포즈 비디오 분기용 프롬프트로, 캐릭터보다는 모션을 설명합니다. 기본값은 `positive`입니다. cond 패스와 uncond 패스 모두에 사용됩니다. | CONDITIONING | 아니요 | N/A |
| `clip_vision_output_pose` | 포즈 비디오 첫 번째 프레임의 CLIP 비전입니다. 기본값은 `clip_vision_output`입니다. | CLIP_VISION_OUTPUT | 아니요 | N/A |
| `continue_motion` | 시간적 일관성을 위해 이어서 사용할 이전 모션 시퀀스입니다. 이 시퀀스의 마지막 프레임만 시작 모션 프레임으로 사용됩니다. | IMAGE | 아니요 | N/A |
| `video_frame_offset` | 포즈 비디오에서 탐색할 프레임 수입니다. 확장 시에는 이전 노드의 `video_frame_offset` 출력에 연결해야 합니다. (기본값: 0) | INT | 예 | 0 ~ MAX_RESOLUTION |
| `pose_strength` | 포즈 비디오가 모션에 미치는 영향을 조정합니다. 1.0은 학습된 동작이며, 그 이하에서는 준수 강도가 약해지고 그 이상에서는 증폭됩니다. 0.0으로 설정하면 영향이 0이 되지만 완전히 제거되지는 않습니다. (기본값: 1.0) | FLOAT | 예 | 0.00 ~ 10.00 (단계 0.01) |
| `pose_start_percent` | 포즈 영향이 시작되는 샘플링 비율입니다. 이 구간 밖에서는 포즈 분기가 완전히 건너뛰어지므로 해당 단계도 빨라집니다. (기본값: 0.0) | FLOAT | 예 | 0.00 ~ 1.00 (단계 0.01) |
| `pose_end_percent` | 포즈 영향이 종료되는 샘플링 비율입니다. 모션은 대부분 초반에 확립되므로, 예를 들어 0.7은 안무를 유지하면서 미세한 디테일을 완화할 수 있습니다. (기본값: 1.0) | FLOAT | 예 | 0.00 ~ 1.00 (단계 0.01) |
| `reference_image_strength` | 생성 프레임이 참조 이미지의 잠재 프레임에 주의를 기울이는 강도를 조정합니다. 1.0 미만으로 설정하면 정체성/외관 준수가 완화되고(예: 프롬프트가 스타일을 변경할 수 있음), 1.0 초과로 설정하면 드리프트에 대해 더 강하게 고정됩니다. (기본값: 1.0) | FLOAT | 예 | 0.00 ~ 10.00 (단계 0.01) |

**검증 참고 사항:**

- `pose_start_percent`는 `pose_end_percent`보다 클 수 없습니다. 그렇지 않으면 노드에서 ValueError가 발생합니다.
- `pose_video`가 제공되는 경우 해당 프레임 수는 `video_frame_offset`보다 커야 합니다. 그렇지 않으면 노드에서 ValueError가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 참조 이미지, 마스크 및 선택적 포즈 데이터가 첨부된 샘플링용 긍정 컨디셔닝입니다. | CONDITIONING |
| `negative` | 동일한 참조 이미지, 마스크 및 선택적 포즈 데이터가 첨부된 샘플링용 부정 컨디셔닝입니다. | CONDITIONING |
| `latent` | 비디오 샘플러용 0으로 채워진 시작 잠재 변수입니다. 디코딩 전에 처음 `trim_latent` 프레임을 제거해야 합니다. | LATENT |
| `trim_latent` | 디코딩 전에 제거해야 하는 잠재 프레임 수입니다. | INT |
| `trim_image` | 비디오 확장 시 겹치는 이미지 프레임 수입니다. | INT |
| `video_frame_offset` | 포즈 비디오에서 탐색할 프레임 수이며, 조정된 입력 오프셋에 생성된 프레임 수를 더한 값입니다. | INT |
