이 노드는 Mage-Flow-Edit 모델을 위해 하나 이상의 참조 이미지와 함께 편집 명령(프롬프트)을 인코딩합니다. 모든 참조 이미지를 대상 출력 해상도로 크기를 조정하고, VAE가 제공된 경우 이를 잠재 공간으로 인코딩한 후 참조 잠재 텐서를 조건화 출력에 첨부합니다. 또한 샘플링에 적합한 차원의 빈 잠재 텐서를 생성하여 크기가 항상 출력 너비 및 높이와 일치하도록 보장합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip` | 텍스트 프롬프트를 토큰화하고 인코딩하는 데 사용되는 CLIP 모델입니다. | CLIP | 예 | |
| `prompt` | 적용할 편집 명령(포지티브 프롬프트)입니다. | STRING | 예 | multiline, dynamic prompts enabled |
| `negative_prompt` | 회피할 네거티브 프롬프트입니다. 기본값: 빈 문자열(비어 있을 경우 내부적으로 공백 사용). | STRING | 아니요 | multiline, dynamic prompts enabled |
| `vae` | 참조 이미지를 잠재 공간으로 인코딩하는 VAE 모델입니다. 제공되지 않으면 조건화에 참조 잠재 텐서가 추가되지 않습니다. | VAE | 아니요 | |
| `images` | 편집할 하나 이상의 참조 이미지입니다. 인코딩 전에 모든 이미지가 출력 해상도로 크기 조정됩니다. | IMAGE (autogrow) | 아니요 | Up to 16 images (named `image_1`…`image_16`), at least 0 |
| `width` | 출력 너비(픽셀 단위)입니다. 0으로 설정하면 첫 번째 참조 이미지의 너비가 사용됩니다. 항상 16의 배수로 내림 처리됩니다. 기본값: 0. | INT | 예 | 0 to 8192 (step 16) |
| `height` | 출력 높이(픽셀 단위)입니다. 너비와 동일한 대체 동작을 따릅니다. 기본값: 0. | INT | 예 | 0 to 8192 (step 16) |
| `batch_size` | 생성할 잠재 샘플 수입니다. 기본값: 1. | INT | 예 | 1 to 4096 |

**매개변수 종속성 참고 사항:**
- `width` 및/또는 `height`가 0이고 참조 이미지가 제공되지 않은 경우 각각 1024로 대체됩니다.
- `vae` 매개변수는 선택 사항입니다. VAE가 연결된 경우에만 참조 잠재 텐서가 생성되어 조건화에 첨부됩니다.
- `negative_prompt` 필드는 선택 사항입니다. 비워 두면 내부적으로 공백 하나가 네거티브 텍스트로 사용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 포지티브 프롬프트 토큰과 (VAE가 제공된 경우) 인코딩된 참조 잠재 텐서를 포함하는 조건화 출력입니다. | CONDITIONING |
| `negative` | 네거티브 프롬프트 토큰과 (VAE가 제공된 경우) 동일한 참조 잠재 텐서를 포함하는 조건화 출력입니다. | CONDITIONING |
| `latent` | 샘플링 중 초기 노이즈로 사용되는 형태 `[batch_size, 128, height÷16, width÷16]`의 빈 잠재 텐서입니다. | LATENT |
