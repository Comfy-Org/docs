ImageYUVToRGB 노드는 YUV 색 공간 이미지를 RGB 색 공간으로 변환합니다. 이 노드는 Y(휘도), U(청색 투영), V(적색 투영) 성분을 나타내는 세 개의 개별 입력 이미지를 받아 하나의 RGB 이미지로 결합합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `Y` | Y(휘도) 성분 입력 이미지입니다. 이미지에 3개를 초과하는 채널이 있는 경우 처음 3개 채널만 사용되며 단일 채널로 평균화됩니다. | IMAGE | 예 | - |
| `U` | U(청색 투영) 성분 입력 이미지입니다. 이미지에 3개를 초과하는 채널이 있는 경우 처음 3개 채널만 사용되며 단일 채널로 평균화됩니다. | IMAGE | 예 | - |
| `V` | V(적색 투영) 성분 입력 이미지입니다. 이미지에 3개를 초과하는 채널이 있는 경우 처음 3개 채널만 사용되며 단일 채널로 평균화됩니다. | IMAGE | 예 | - |

**참고:** 세 입력 이미지(Y, U, V)는 모두 함께 제공되어야 하며, 변환이 성공하려면 호환되는 크기(높이, 너비 및 배치 크기 일치)를 가져야 합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `output` | 변환된 RGB 이미지 | IMAGE |
