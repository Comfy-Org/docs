입력 비디오에서 연속적인 프레임 범위를 무작위로 자릅니다. 자르기 길이는 `length` 매개변수로 제어되며, 시작 위치는 난수 시드를 사용하여 선택됩니다. 이 노드는 느긋하게(lazy) 작동하므로, 출력이 다운스트림에서 사용될 때까지 전체 비디오를 처리하지 않습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `비디오` | 입력 비디오입니다. | VIDEO | 예 | – |
| `길이` | 유지할 프레임 수입니다. (기본값: 16) | INT | 예 | 최소: 1, 최대: 99999 |
| `시드` | 난수 시드입니다. (기본값: 0) | INT | 예 | 최소: 0, 최대: 0xFFFFFFFFFFFFFFFF |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `비디오` | 느긋하게(lazy) 자른 비디오입니다. | VIDEO |
