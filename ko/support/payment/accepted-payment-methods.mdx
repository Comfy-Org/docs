결제 시 보이는 결제 수단이 위치와 통화에서 사용할 수 있는 옵션입니다. Comfy Organization Inc는 Stripe로 결제를 처리합니다.

## 신용카드 및 직불카드

다음과 같은 주요 신용카드 및 직불카드를 수락합니다.

- Visa
- Mastercard
- American Express

## 디지털 지갑

다음 디지털 지갑으로도 결제할 수 있습니다.

- Google Pay
- Link

## 기타 결제 수단

다음 수단은 **USD**로 결제할 때만 사용할 수 있습니다.

- **Alipay**: 로컬 API 크레딧과 Comfy Cloud 구독
- **WeChat Pay**: 로컬 API 크레딧만

<Note>
WeChat Pay와 Alipay는 특정 지역에서만 제공됩니다. 국가별 이용 가능 여부는 Stripe 문서의 `Business locations`를 확인하세요.
- [Stripe WeChat Pay 문서](https://docs.stripe.com/payments/wechat-pay#get-started)
- [Stripe Alipay 문서](https://docs.stripe.com/payments/alipay)
</Note>

Alipay 또는 WeChat Pay를 쓰려면 결제 시 통화로 **USD**를 선택하세요. 해당 지역에서 사용 가능하면 결제 수단 목록에 나타납니다.

## 요구사항

결제를 성공적으로 처리하려면:

- 카드에 충분한 잔액 또는 이용 가능한 한도가 있어야 합니다.
- 청구서 주소가 카드 발급사에 등록된 주소와 일치해야 합니다.
- 해외 카드도 수락되지만, 은행에서 환율 변환 수수료가 부과될 수 있습니다.

## 보안

Stripe는 결제 업계에서 가장 엄격한 인증 수준인 PCI 서비스 제공업체 레벨 1입니다. 모든 결제 정보는 업계 표준 암호화를 사용해 안전하게 처리됩니다. Comfy Organization Inc는 전체 카드 정보를 서버에 저장하지 않습니다.

## 결제 처리

결제는 구독 또는 갱신 시 즉시 처리됩니다. 결제가 성공적으로 처리되면 확인 이메일을 받습니다.

결제 처리에 문제가 있으면 [지원팀](https://support.comfy.org/)에 문의하세요.
