## 워크플로란 무엇인가요?

워크플로는 ComfyUI가 무언가를 생성하는 방법을 알려주는 일련의 단계입니다.

워크플로를 요리 레시피처럼 생각할 수 있습니다:

- 레시피가 워크플로입니다.
- 레시피의 각 지시사항이 노드입니다.
- 재료에는 프롬프트, 이미지, 모델이 포함됩니다.
- 결과물은 생성된 이미지, 비디오, 오디오 또는 기타 출력입니다.

예를 들어, 간단한 이미지 워크플로는 다음과 같을 수 있습니다:

1. 모델을 로드합니다.
2. 텍스트 프롬프트를 읽습니다.
3. 이미지를 생성합니다.
4. 이미지를 저장합니다.

ComfyUI는 이러한 단계를 캔버스의 상자로 표시합니다.

![간단한 ComfyUI 워크플로](/images/simple_workflow.jpg)

## 노드는 단계입니다

노드는 하나의 특정 작업을 수행합니다. 일부 노드는 파일을 로드하고, 일부 노드는 데이터를 변경하며, 다른 노드는 결과를 생성하거나 저장합니다.

예를 들어:

- **체크포인트 로드** 노드는 AI 모델을 로드합니다.
- **CLIP 텍스트 인코딩** 노드는 프롬프트를 모델을 위한 지침으로 변환합니다.
- **KSampler** 노드는 모델과 해당 지침으로 이미지를 생성합니다.
- **이미지 저장** 노드는 결과를 컴퓨터에 저장합니다.

노드를 다양한 방식으로 결합하여 다양한 워크플로를 생성할 수 있습니다. 노드를 사용하기 위해 코드를 작성할 필요가 없습니다.

[노드](/ko/basic-concepts/nodes)에서 노드에 대해 더 알아보세요.

## 링크는 노드 간에 데이터를 전달합니다

노드는 한 노드에서 다른 노드로 데이터를 전달하며 함께 작동합니다. 링크는 한 노드의 출력을 다른 노드의 입력에 연결합니다.

예를 들어, **체크포인트 로드** 노드로 로드된 모델을 **KSampler** 노드에 전달할 수 있습니다. 텍스트 인코딩 노드가 생성한 텍스트 지침도 샘플러에 전달할 수 있습니다.

호환되는 데이터 유형만 연결할 수 있습니다. 예를 들어, 이미지 출력은 숫자를 기대하는 입력에 직접 연결할 수 없습니다.

링크에 대한 자세한 정보는 [링크](/ko/basic-concepts/links)에서 더 알아보세요.

## 속성이 각 단계를 제어합니다

노드에는 속성이 포함됩니다. 속성은 노드가 작동하는 방식을 제어하는 설정입니다.

예를 들어, 샘플러 노드에는 다음에 대한 속성이 있을 수 있습니다:

- 단계 수
- 가이드 스케일
- 샘플링 방법
- 이미지 크기

일반적으로 노드에서 속성을 직접 설정할 수 있습니다. 일부 속성은 다른 노드에서 값을 받을 수도 있습니다.

속성에 대해 더 알아보려면 [속성](/ko/basic-concepts/properties)을 참조하세요.

## 워크플로 실행

워크플로를 실행하면 ComfyUI가 필수 노드를 실행하고 링크를 통해 데이터를 전달합니다. 워크플로는 최종 출력을 생성할 때까지 계속됩니다.

노드가 누락되었거나, 오류가 있거나, 필요한 데이터를 받지 못하면 ComfyUI는 워크플로를 완료할 수 없습니다. 문제를 찾아 해결할 수 있도록 해당 노드가 표시됩니다.

## 템플릿으로 시작하기

시작하려면 **워크플로** → **워크플로 템플릿 찾아보기**에서 기본 제공되는 워크플로 템플릿을 여세요. 템플릿은 실행하고 편집할 수 있는 완전한 예제를 제공합니다.

템플릿은 ComfyUI에 포함된 코어 노드를 사용합니다. 또한 필수 모델을 다운로드하라는 메시지를 표시합니다.

커뮤니티는 더 많은 기능을 추가하는 다양한 커스텀 노드를 만들었습니다. [커스텀 노드](/ko/basic-concepts/custom-nodes)에서 더 알아보세요.

## 워크플로 저장 및 공유

워크플로를 JSON 파일로 저장하고 생성된 미디어와 별도로 공유할 수 있습니다.

기본 제공 저장 노드로 출력을 저장하면 ComfyUI가 워크플로를 출력 파일 안에 함께 저장할 수도 있습니다. 그런 다음 파일을 캔버스로 다시 끌어다 놓으면 워크플로를 복구할 수 있습니다.

임베디드 데이터, 지원되는 파일 형식, 프로그래밍 방식 액세스에 대한 세부 정보는 [워크플로 메타데이터](/ko/development/api-development/workflow-metadata)를 참조하세요.

## 약간의 배경 지식

기술적으로 워크플로는 노드 그래프입니다. 노드는 그래프의 지점이며, 링크는 데이터가 노드 사이에서 어떻게 이동하는지 보여줍니다.

이는 코드를 작성하는 대신 시각적 블록을 배열하고 연결하여 프로그램을 생성하기 때문에 시각적 프로그래밍이라고도 합니다.
