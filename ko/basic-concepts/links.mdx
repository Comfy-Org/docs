## 링크는 노드를 연결합니다

ComfyUI에서 노드 사이에 그려지는 선이나 곡선을 **_링크_**라고 합니다(**_연결_** 또는 와이어라고도 함). 링크는 한 노드의 출력에서 다른 노드의 입력으로 데이터를 전달하며, 워크플로의 흐름을 정의합니다.

아래의 모든 작업은 동일한 대상, 즉 노드 가장자리에 있는 색상 원을 다룹니다. 출력은 오른쪽 가장자리에, 입력은 왼쪽 가장자리에 있습니다.

### 두 노드 연결하기

출력 포트에서 같은 색상의 입력 포트로 드래그합니다. 드래그하는 동안 호환되는 포트가 강조되며, 놓으면 링크가 스냅됩니다.

<video
  controls

></video>

색상이 데이터 타입을 나타내므로 같은 색상의 포트만 연결됩니다. [색상 코드](#색상-구분)를 참고하세요.

### 빈 캔버스에 링크 놓기

빈 캔버스 위에서 링크를 놓으면 현재 전달 중인 데이터 타입으로 이미 필터링된 노드 추가 검색이 열립니다. 노드를 선택하면 연결된 상태로 생성됩니다.

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/release-on-empty-search.mp4"
></video>

![전달 중인 데이터 타입으로 필터링된 노드 추가 검색](/images/basic-concepts/links/add-node-search.png)

놓을 때 `Shift`를 누르고 있으면 대신 컨텍스트 메뉴가 표시됩니다: **노드 추가**, **경유점 추가**, **검색**, 그리고 해당 데이터를 받는 노드 타입.

<video

  className="w-full aspect-video"

></video>

![Shift를 누른 채 링크를 놓았을 때의 컨텍스트 메뉴](/images/basic-concepts/links/release-context-menu.png)

두 해제 동작 모두 **설정 → LiteGraph → 링크 해제**에서 구성할 수 있으며, 일반 해제용 항목과 `Shift`용 항목이 하나씩 있습니다.

### 링크 숨기기 또는 삭제하기

링크를 마우스 오른쪽 버튼으로 클릭하면 메뉴가 열립니다:

- **링크 숨기기**는 연결을 유지하고 와이어만 숨기므로 데이터는 계속 흐릅니다
- **삭제**는 연결을 제거합니다
- **경유점 추가**는 와이어에 경유점을 배치합니다
- **노드 추가**는 링크에 노드를 삽입합니다

### 모든 링크 숨기기

캔버스 툴바의 링크 표시 토글은 워크플로를 변경하지 않고 모든 와이어를 한 번에 숨깁니다. 이는 **링크 렌더 모드**를 **숨김**으로 설정하는 것과 같으며, 다시 켜면 이전 스타일이 복원됩니다.

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/hide-links.mp4"
></video>

<Tip>
링크를 표시하는 것은 워크플로를 학습하거나, 공유하거나, 디버깅할 때 특히 유용합니다. 데이터 흐름을 한눈에 볼 수 있게 해줍니다. 편집할 의도가 없는 완료된 워크플로의 경우 링크를 숨기면 시각적 혼잡을 줄일 수 있습니다.
</Tip>

### 링크에 경유점 추가하기

워크플로가 복잡해지면 와이어가 겹치거나 노드 뒤로 지나가게 됩니다. 링크 메뉴의 **경유점 추가**는 와이어에 네이티브 경유점을 배치합니다. 그 지점을 원하는 곳으로 드래그하여 다른 노드를 피해 와이어를 배치할 수 있습니다.

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/link-menu-reroute.mp4"
></video>

ComfyUI에는 **Reroute** 노드도 함께 제공되는데, 그룹에 넣거나 실행 건너뛰기, 재사용이 가능한 명시적 노드로 같은 역할을 합니다. 새 워크플로에서는 네이티브 경유점으로 충분합니다.

![ComfyUI Reroute 노드](/images/interface/link/reroute.jpg)

## 링크 렌더 모드

링크는 곡선, 직각, 직선으로 그리거나 완전히 숨길 수 있습니다.

![링크 스타일](/images/interface/link/link_styles.jpg)

**설정 → LiteGraph → 그래프 → 링크 렌더 모드**에서 스타일을 변경하거나, 캔버스 툴바에서 링크 가시성을 전환할 수 있습니다.

![렌더 모드 설정](/images/interface/link/render_mode.jpg)

## 색상 구분

ComfyUI의 모든 데이터 타입은 고유한 색상을 가집니다. 노드의 입력 및 출력 포트와 이들을 연결하는 링크 와이어도 모두 이 색상 체계를 따릅니다. **같은 색상의 포트끼리만 연결할 수 있습니다**. 이를 통해 워크플로 전체에서 타입 안전성이 보장됩니다.

![ComfyUI Node Data Types](/images/concepts/node/data_type.jpg)

| 데이터 타입            | 색상         |
|---------------------------|-------------|
| Diffusion 모델            | 라벤더      |
| CLIP 모델                 | 노란색      |
| VAE 모델                  | 로즈        |
| 조건화                    | 주황색      |
| 잠재 이미지               | 분홍색      |
| 픽셀 이미지               | 파란색      |
| 마스크                    | 초록색      |
| 숫자 (정수 또는 실수)     | 회색        |
| 메시                      | 밝은 초록색 |
