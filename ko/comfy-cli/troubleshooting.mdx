Comfy CLI의 대부분의 문제는 필수 요구 사항이 빠졌거나 설정 단계를 건너뛰어서 발생합니다. 문제를 보고하기 전에 아래 항목을 순서대로 확인하세요.

## 사전 요구사항

Comfy CLI를 사용하려면 시스템에 [git](https://git-scm.com/downloads)이 설치되어 있어야 합니다. 먼저 git을 설치해야 `comfy install`과 `comfy update`가 ComfyUI와 커스텀 노드를 복제할 수 있습니다.

## 가상 환경에 ComfyUI 설치

`comfy install`은 현재 활성화된 Python 환경에 ComfyUI를 설치하며, Python 3.10 이상이 필요합니다. 먼저 가상 환경을 만들고 활성화하세요:

```bash
python3 -m venv comfy-env
source comfy-env/bin/activate
comfy install
```

## GPU에 맞는 PyTorch 빌드 설치

`comfy install`은 사용할 GPU를 물어보고 그에 맞는 PyTorch 빌드를 설치합니다. 프롬프트에 답하거나 플래그로 GPU를 지정해 무인 실행할 수 있습니다:

| 플랫폼 | `comfy install`이 설치하는 것 | 별도로 필요한 것 |
| --- | --- | --- |
| NVIDIA | CUDA runtime 포함 PyTorch(pip 휠) | 최신 GPU 드라이버(전체 CUDA Toolkit 불필요) |
| AMD Linux | ROCm PyTorch 휠 | 해당 휠에 맞는 ROCm 지원 AMD 드라이버/스택 |
| AMD Windows | `torch-directml` | 호환 AMD GPU(DirectML, ROCm 아님) |
| Apple silicon | PyTorch nightly 휠(CPU 인덱스, Metal/MPS) | Apple silicon macOS |
| Intel Arc | PyTorch XPU 휠 | 호환 Intel Arc GPU / XPU 스택 |
| CPU | CPU용 PyTorch 휠 | 독립 GPU 불필요 |

```bash
comfy install --nvidia
```

PyTorch를 직접 설치한다면 `--skip-torch-or-directml`을 지정하세요. `comfy env`는 ComfyUI가 사용하는 Python 환경과 워크스페이스를 출력합니다.

## 브라우저 없이 Comfy Cloud 설정

`comfy setup`은 브라우저로 로그인하므로 CI, devcontainer, 헤드리스 서버에서는 완료할 수 없습니다. 대신 API 키를 전달하고 비대화형 모드로 실행하세요:

```bash
comfy setup --where cloud --api-key comfyui-... --non-interactive
```
