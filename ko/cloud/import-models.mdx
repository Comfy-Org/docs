## 개요

Comfy Cloud를 사용하면 Civitai와 Hugging Face에서 직접 모델을 가져올 수 있습니다. 이 기능은 **Creator** 이상 구독자에게 제공됩니다.

## 요구사항

- **구독**: Creator 이상 등급
- **지원되는 소스**: Civitai 및 Hugging Face

## 모델 가져오기 방법

### 1. 가져오기 기능에 액세스하기
![가져오기](/images/cloud/import_model/import_model.png)
1. 왼쪽 사이드바의 **모델** 버튼을 클릭해 모델 라이브러리를 엽니다.
2. 모델 라이브러리 모달에서 **가져오기** 버튼을 클릭하세요.

### 2. 링크 붙여넣기
1. Hugging Face 또는 Civitai에서 얻은 모델 링크를 붙여넣으세요.
![가져오기 모달](/images/cloud/import_model/import_model_modal-1.png)

2. 링크가 유효하면 확인 표시가 나타나고, `계속` 버튼을 클릭해 진행할 수 있습니다.
![가져오기 모달](/images/cloud/import_model/import_model_modal-2.png)

3. 모델 유형과 대상 폴더를 선택하세요.
![가져오기 모달](/images/cloud/import_model/import_model_modal-3.png)

4. 모델 다운로드가 완료될 때까지 기다리세요.
![가져오기 모달](/images/cloud/import_model/import_model_modal-4.png)

5. 다운로드가 완료되면, 모델 라이브러리에서 해당 모델을 확인할 수 있습니다.

## 가져온 모델 보기 방법

모델 라이브러리에서 드롭다운 필터에서 "내 모델"을 선택해 가져온 모델만 필터링하세요.

![가져온 모델](/images/cloud/import_model/imported_model.png)

## 모델 가져오기 링크 얻는 방법

### 1. Civitai에서 링크 얻기

1. [Civitai](https://civitai.com/)로 이동해 가져오려는 모델을 찾으세요.
2. 다운로드 버튼을 오른쪽 클릭하고 "링크 주소 복사"를 선택해 모델 다운로드 링크를 얻으세요.

![Civitai 링크 복사](/images/cloud/import_model/copy_civitai_link.png)

### 2. Hugging Face에서 링크 얻기

1. [Hugging Face](https://huggingface.co/)로 이동해 가져오려는 모델 저장소를 찾으세요.
2. 모델 파일 페이지로 이동하세요. 지원되는 형식은 ".safetensors"입니다. 특정 모델 이름을 클릭해 상세 페이지로 들어가세요.

![Huggingface 모델 링크 복사](/images/cloud/import_model/copy_huggingface_link-1.png)

3. 상세 페이지에서 `Copy Download Link` 버튼을 클릭해 모델 다운로드 링크를 얻으세요.

![Huggingface 모델 링크 복사](/images/cloud/import_model/copy_huggingface_link-2.png)

## 비공개 모델 가져오기

Hugging Face나 Civitai의 비공개 모델을 가져오려면 먼저 API 키를 설정해야 합니다.

### 1. API 키 생성하기

먼저 각 플랫폼에서 API 키를 생성해야 합니다:

<Tabs>
  <Tab title="Civitai">
    1. Civitai에 로그인해 [https://civitai.com/user/account](https://civitai.com/user/account)에 방문하세요.
    2. 계정 설정에서 API 키를 생성하세요.

    ![Civitai API 키](/images/cloud/import_model/civitai_key-1.png)
  </Tab>
  <Tab title="Hugging Face">
    1. [https://huggingface.co/settings/tokens](https://huggingface.co/settings/tokens)에 방문하세요.
    2. API 토큰을 생성하세요.

    ![Hugging Face API 키](/images/cloud/import_model/huggingface_key-1.png)

    3. 가져오려는 비공개 모델이 포함된 리포지토리에 대한 읽기 권한이 있는지 확인하세요.

    ![Hugging Face 토큰 권한](/images/cloud/import_model/huggingface_key-2.png)
  </Tab>
</Tabs>

### 2. API 키 저장하기

1. [Comfy Cloud 설정](https://cloud.comfy.org)에 접속해 **Secrets** 섹션으로 이동하세요.

![설정 Secrets](/images/cloud/import_model/setting_secerts-1.png)

2. **Add Secret**을 클릭하고 키가 속한 **Provider**(예: Hugging Face 또는 Civitai)를 선택한 뒤 이름을 지정하고 키를 **Secret Value**에 붙여넣으세요. Provider는 필수입니다. Comfy Cloud는 이 정보를 사용해 해당 플랫폼에서 모델을 가져올 때 올바른 토큰을 선택합니다.

![Secrets 추가](/images/cloud/import_model/setting_secerts-2.png)

3. API 키가 가져오려는 비공개 모델에 대한 접근 권한을 가지고 있는지 확인하세요.

<Note>
시크릿은 암호화되어 저장되며 저장 후에는 다시 볼 수 없으므로 키를 따로 보관하세요. Provider당 하나의 시크릿을 저장할 수 있으며, 교체하려면 해당 시크릿을 열어 새 값을 입력하세요. 패널 전체 설명은 [API Keys & Secrets](/ko/cloud/api-keys-and-secrets)를 참고하세요.
</Note>

### 3. 비공개 모델 가져오기

API 키가 설정되면, 공개 모델과 동일한 과정으로 비공개 모델을 가져올 수 있습니다:

1. Hugging Face 또는 Civitai에서 모델 링크를 얻으세요.
2. 가져오기 모달에 링크를 붙여넣으세요.
3. 시스템은 자동으로 저장된 API 키를 사용해 비공개 모델에 접근합니다.

<Note>
필요한 비공개 모델에 접근할 수 있는 권한이 있는지 확인하세요.
</Note>

## FAQ

<AccordionGroup>
  <Accordion title="업로드할 수 있는 모델에 제한이 있나요?">
    네. **safetensors** 파일만 지원됩니다. 파일 크기 제한은 사실상 없습니다(최대 100GB).
  </Accordion>

  <Accordion title="업로드한 모델은 비공개인가요, 아니면 모두에게 공유되나요?">
    가져온 모델은 **귀하만의 비공개 모델**입니다. 귀하만이 라이브러리에서 해당 모델을 볼 수 있습니다.
  </Accordion>

  <Accordion title="로컬 하드디스크에서 직접 만든 사용자 지정 모델을 업로드할 수 있나요?">
    현재는 모델을 먼저 **공개 Hugging Face 또는 Civitai 저장소**에 업로드한 다음, 해당 플랫폼에서 가져와야 합니다.
  </Accordion>

  <Accordion title="분할된 모델 파일을 업로드할 수 있나요?">
    아니요. 가져오기 전에 분할된 모델 파일을 하나의 파일로 결합해야 합니다.
  </Accordion>

  <Accordion title="현재 클라우드 구독에 이 기능이 포함되어 있나요?">
    이 기능은 **Creator** 및 **Pro** 플랜에서만 사용할 수 있습니다.
  </Accordion>

  <Accordion title="데스크톱 또는 포터블 버전의 Comfy에서도 이 기능을 사용할 수 있나요?">
    아니요. 이 기능은 **클라우드 전용** 기능입니다.
  </Accordion>

  <Accordion title="업로드한 모델을 삭제할 수 있나요?">
    네. 가져온 모델은 삭제할 수 있습니다. 단, Comfy 내부 팀이 업로드한 모델은 삭제할 수 없습니다.
  </Accordion>

  <Accordion title="어떤 모델 유형을 가져올 수 있나요(BYOM)?">
    아래 예시에만 국한되지 않습니다. BYOM은 가져오기 과정에서 **가져오기 유형 선택기**에 Comfy Cloud가 표시하는 모든 모델 폴더를 지원합니다. 이 목록은 Comfy Cloud가 지원하는 ComfyUI 모델 폴더에서 비롯되며, 기준이 되는 정보입니다.

    실제로 ComfyUI가 파일을 모델 가중치(checkpoint, LoRA, VAE, ControlNet, embedding, upscaler, IP-Adapter, SAM, audio encoder 등)로 취급하고 해당 폴더가 그 선택기에 표시된다면, 가져올 수 있습니다.

    일반적인 예:

    - **Checkpoint 및 UNet**: `checkpoints`, `diffusion_models`
    - **LoRA 및 어댑터**: `loras`, `animatediff_motion_lora`, `cogvideox_loras` 및 이와 유사한 어댑터 폴더
    - **VAE**: `vae`, `vae_approx`
    - **ControlNet**: `controlnet`
    - **CLIP 및 text encoder**: `clip_vision`, `text_encoders`
    - **Embedding / textual inversion**: `embeddings` (`CLIPTextEncode` 프롬프트에서 `embedding:my-embedding-name`으로 참조)
    - **Upscaler**: `upscale_models`, `latent_upscale_models`
    - **비전 / 분할 / 제거**: `ipadapter`, `gligen`, `sams`, `sam3`, `rmbg`, `ultralytics_bbox`, `ultralytics_segm`
    - **선택기의 기타 폴더**: `audio_encoders`, `model_patches`, `style_models`, `photomaker`, `LLM`, `CogVideo` 등

    가져오기를 실제로 제한하는 것은 모델 카테고리가 아니라 다음 규칙입니다:

    - **파일 형식**: `.safetensors`만 지원(ComfyUI 로컬에서 해당 폴더에 `.ckpt`, `.pth`, `.onnx`를 지원하더라도 동일)
    - **소스**: Civitai 또는 Hugging Face 다운로드 링크만 가능(로컬 직접 업로드 불가)
    - **차단된 폴더**: `nlf` 모델은 가져올 수 없음
  </Accordion>
</AccordionGroup>
