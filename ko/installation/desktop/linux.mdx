**Comfy Desktop**은 단일 실행기에서 여러 ComfyUI 인스턴스를 실행할 수 있는 다중 설치 매니저입니다. Linux 빌드는 `.deb`(Debian/Ubuntu) 및 AppImage로 배포됩니다.

## 시스템 요구 사항

- **OS:** Debian 기반 Linux(Ubuntu 22.04 이상 권장)
- **아키텍처:** x64
- **GPU:** 전용 GPU(NVIDIA / AMD) 권장, 필수는 아님
- **디스크 공간:** 설치당 최소 4.85 GB 권장

    최신 Linux 빌드를 다운로드하세요. 페이지에서 플랫폼을 자동으로 감지합니다.
</Card>

## 설치

### Debian / Ubuntu (`.deb`)

패키지를 다운로드한 디렉토리에서:

```bash
sudo apt install ./*.deb
```

그런 다음 애플리케이션 메뉴에서 **Comfy Desktop**을 실행하세요.

### AppImage

```bash
chmod +x ./*.AppImage
./*.AppImage
```

Chromium이 샌드박스를 만들지 못해 AppImage가 시작되지 않으면 `--no-sandbox`로 다시 시도하세요:

```bash
./*.AppImage --no-sandbox
```

<Warning>`--no-sandbox`는 모든 프로세스의 Electron 샌드박스를 끕니다. 이 플래그 없이는 시작되지 않을 때만 사용하세요. 흔한 AppImage 패키징 제한이며, 권장 실행 방식이 아닙니다.</Warning>

AppImage가 시작되지 않으면 FUSE 2를 설치하세요:

```bash
sudo apt install libfuse2
```

소스에서 직접 빌드할 수도 있습니다. [Comfy Desktop 저장소](https://github.com/Comfy-Org/Comfy-Desktop)를 참조하세요.

## Comfy Desktop 업데이트

`.deb` 설치는 시스템 패키지 매니저(`apt`)를 통해서도 업데이트를 받을 수 있습니다.

## 제거

### Comfy Desktop 제거

- **`.deb`:** 시스템 패키지 매니저(`apt`, `dpkg` 또는 데스크톱의 소프트웨어 센터)로 패키지를 제거하세요.
- **AppImage:** `.AppImage` 파일을 삭제하세요.

### 앱 제거 시 제거되지 않는 항목

Comfy Desktop을 제거하면 실행기 앱 자체만 제거됩니다. 완전한 정리를 원한다면 다음 데이터는 **제거되지 않으며**, 수동으로 삭제해야 합니다:

| 데이터 | 기본 위치 | 설명 |
|------|-----------------|-------------|
| 설치 | `~/ComfyUI-Installs` | 생성한 각 ComfyUI 설치(앱 내에서도 삭제 가능). 사용자 지정 설치 경로도 제거되지 않습니다. |
| 공유 모델 및 출력 | `~/ComfyUI-Shared` | 공유 모델 라이브러리, 입력/출력 디렉토리 |
| 앱 설정 | `~/.config/comfyui-desktop-2` | 설정 및 설치 기록 |
| 앱 데이터 | `~/.local/share/comfyui-desktop-2` | 지속 앱 데이터 |
| 캐시 | `~/.cache/comfyui-desktop-2` | 다운로드 캐시 및 기타 비필수 파일 |
| 상태 | `~/.local/state/comfyui-desktop-2` | 포트 잠금 같은 런타임 상태 |
| 로그 | `~/.config/comfyui-desktop-2/logs` | 데스크톱 앱 로그(`app.log`) |

모든 항목을 완전히 제거하려면:

1. **설정 폴더 삭제**: `~/.config/comfyui-desktop-2`
2. **데이터, 캐시, 상태 폴더 삭제**: `~/.local/share/comfyui-desktop-2`, `~/.cache/comfyui-desktop-2`, `~/.local/state/comfyui-desktop-2`
3. **개별 설치 삭제**: 앱 내에서 삭제하거나 `~/ComfyUI-Installs`와 직접 설정한 사용자 지정 설치 디렉토리를 수동으로 삭제하세요.
4. **공유 모델 라이브러리 삭제**: `~/ComfyUI-Shared`를 삭제하세요(해당 파일이 더 이상 필요하지 않은 경우).
