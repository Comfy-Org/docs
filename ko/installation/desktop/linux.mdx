**Comfy Desktop**은 Linux에서 실행할 수 있습니다. 공식 `.deb` 패키지(Debian/Ubuntu)와 AppImage는 [Comfy Desktop 저장소](https://github.com/Comfy-Org/Comfy-Desktop)를 통해 배포됩니다. [범용 다운로드 링크](https://dl.todesktop.com/241130tqe9q3y)에서 다운로드하세요(플랫폼을 자동으로 감지합니다). 대부분의 사용자는 이 패키지 중 하나를 사용하는 것을 권장합니다. 소스에서 앱을 실행하려면 저장소를 클론하고 아래 단계를 따르세요.

## 시스템 요구 사항

- **OS:** Linux (Ubuntu 22.04 이상 권장)
- **아키텍처:** x64
- **Node.js:** v22 LTS 이상 (소스 빌드만)
- **pnpm:** v10 이상, Corepack으로 활성화 (소스 빌드만)
- **빌드 도구:** `build-essential` 및 `git` (소스 빌드만)
- **GPU:** 전용 GPU(NVIDIA / AMD)를 권장하지만 필수는 아닙니다
- **디스크 공간:** ComfyUI 설치마다 최소 4.85 GB 권장

## 공식 패키지 설치

[범용 다운로드 링크](https://dl.todesktop.com/241130tqe9q3y)로 Linux 패키지를 다운로드한 뒤 설치하세요(플랫폼을 자동으로 감지합니다):

```bash
sudo apt install ./*.deb
```

`.deb` 패키지는 Comfy Desktop을 `/opt/Comfy Desktop`에 설치하며, 설치 과정에서 Comfy Desktop 패키지 저장소용 APT 소스도 추가하므로 이후 릴리스는 시스템 패키지 관리자로 받습니다. 자세한 내용은 [업데이트](#업데이트)를 참고하세요.

AppArmor가 활성화되어 있고 파서가 함께 제공되는 프로필을 받아들이는 경우(Ubuntu 24.04 이상, 이 버전에서는 비특권 user namespace가 제한됩니다), 설치 시 `/etc/apparmor.d/comfyui-desktop-2`에 앱용 AppArmor 프로필도 함께 등록되어 이런 시스템에서는 추가 플래그 없이 Electron 샌드박스가 동작합니다. 그보다 오래된 배포판은 AppArmor가 이 프로필을 읽지 못하고 원래 샌드박스가 정상 동작하므로 건너뜁니다. 비특권 user namespace를 전혀 쓸 수 없는 환경에서는 대신 함께 제공되는 `chrome-sandbox`가 setuid로 설정됩니다.

프로필이 등록되었는지 확인하려면:

```bash
ls /etc/apparmor.d/comfyui-desktop-2
```

이 프로필은 패키지 설치 스크립트가 설치할 때와 업그레이드할 때 기록합니다. Ubuntu 22.04에서 `.deb`를 설치한 뒤 시스템을 24.04로 업그레이드했다면, 설치 스크립트를 다시 실행하세요:

```bash
sudo apt reinstall comfyui-desktop-2
```

AppImage 사용 방법:

```bash
chmod +x ./*.AppImage
./*.AppImage
```

AppImage는 패키지 설치 스크립트를 실행하지 않으므로 AppArmor 프로필도 APT 소스도 추가하지 않습니다. 앱 메뉴에서 실행하면 이미 `--no-sandbox`가 붙습니다. 파일을 직접 실행했는데 시작되지 않으면 배포판이 Electron 샌드박스를 차단하고 있을 수 있으므로 플래그를 붙여 실행하세요:

```bash
./*.AppImage --no-sandbox
```

이 플래그는 모든 프로세스의 Electron 샌드박스를 끄므로 샌드박스 실행이 실패할 때만 사용하세요.

## 소스에서 빌드하고 실행

이 단계는 저장소 README의 [Development](https://github.com/Comfy-Org/Comfy-Desktop#development) 섹션과 같습니다.

### 사전 요구 사항

먼저 빌드 도구와 git을 설치하세요. 새로 설치한 Ubuntu에는 기본으로 포함되어 있지 않으며, `pnpm run init`은 `node-pty` 같은 네이티브 모듈을 컴파일하므로 `build-essential`이 없으면 `Error: not found: make`로 실패합니다:

```bash
sudo apt install build-essential git
```

그다음 Node.js 22를 설치하고 pnpm을 활성화하세요:

```bash
nvm install 22 && nvm use 22
corepack enable
```

nvm을 쓰지 않는다면 [nodejs.org](https://nodejs.org/)에서 Node.js 22를 설치하세요.

### 클론 및 설치

```bash
git clone https://github.com/Comfy-Org/Comfy-Desktop.git
cd Comfy-Desktop
pnpm run init
```

`pnpm run init`은 의존성을 설치하고 번들된 bootstrap Python을 빌드합니다.

### 앱 시작

```bash
./linux-dev.sh
```

개발 모드로 Comfy Desktop을 시작합니다. 스크립트는 `ELECTRON_DISABLE_SANDBOX=1`을 설정합니다. Linux 개발 환경에서는 Electron 샌드박스가 자주 실패하기 때문입니다.

## 업데이트

Comfy Desktop 업데이트 방식은 설치 방법에 따라 다릅니다.

### .deb 설치

`.deb`를 설치하면 APT 소스(`/etc/apt/sources.list.d/comfyui-desktop-2.sources`)와 해당 unattended-upgrades 항목도 추가되므로, 새 릴리스는 평소의 시스템 업데이트로 받습니다:

```bash
sudo apt update
sudo apt upgrade
```

릴리스마다 `.deb`를 다시 받을 필요가 없습니다. `sudo apt remove comfyui-desktop-2`는 APT 소스를 남기고, `sudo apt purge comfyui-desktop-2`는 unattended-upgrades 항목과 함께 삭제합니다.

### AppImage

AppImage는 스스로 업데이트됩니다. Comfy Desktop은 새 빌드를 내려받아 실행한 `.AppImage` 파일을 교체하므로, 사용자 계정으로 쓸 수 있는 폴더에 두세요. 읽기 전용 위치에 있으면 업데이트가 파일을 교체할 수 없습니다.

### 소스 실행

소스 체크아웃에는 앱 내 자동 업데이트가 없습니다. 최신 코드를 pull한 뒤 다시 시작하세요:

```bash
git pull
pnpm run init
./linux-dev.sh
```

## 선택 사항: 로컬 패키지

직접 `.deb` 또는 AppImage를 만들려면 (Comfy Org 공식 다운로드가 아님):

```bash
pnpm run build:linux
```

산출물은 `dist/`에 생성됩니다. Chromium이 샌드박스를 만들지 못해 AppImage가 실패하면 `--no-sandbox`로 다시 시도하세요. 이 플래그는 모든 프로세스의 Electron 샌드박스를 끕니다.

## 남은 데이터 삭제

앱 삭제와 데이터 삭제는 별개입니다. 먼저 앱을 제거하세요:

- **`.deb`**: `sudo apt remove comfyui-desktop-2`. 제거할 때 `/etc/apparmor.d/comfyui-desktop-2`의 AppArmor 프로필도 함께 삭제됩니다. `sudo apt purge comfyui-desktop-2`를 쓰면 APT 소스와 unattended-upgrades 항목까지 제거됩니다.
- **AppImage**: `.AppImage` 파일을 삭제하세요.

둘 다 ComfyUI 설치와 앱 데이터는 건드리지 않습니다. 완전히 정리하려면 다음 폴더만 삭제하세요:

| 데이터 | 기본 위치 | 설명 |
|------|-----------------|-------------|
| 설치 | `~/ComfyUI-Installs` | 생성한 각 ComfyUI 설치(앱 내에서도 삭제 가능). 사용자 지정 설치 경로도 제거되지 않습니다. |
| 공유 모델 및 출력 | `~/ComfyUI-Shared` | 공유 모델 라이브러리, 입력/출력 디렉토리 |
| 앱 설정 | `~/.config/comfyui-desktop-2` | 설정 및 설치 기록 |
| 앱 데이터 | `~/.local/share/comfyui-desktop-2` | 지속 앱 데이터 |
| 캐시 | `~/.cache/comfyui-desktop-2` | 다운로드 캐시 및 기타 비필수 파일 |
| 상태 | `~/.local/state/comfyui-desktop-2` | 포트 잠금 같은 런타임 상태 |
| 로그 | `~/.config/comfyui-desktop-2/logs` | 데스크톱 앱 로그(`app.log`) |

모든 항목을 완전히 제거하려면:

1. **`Comfy-Desktop` 클론 삭제**
2. **설정 폴더 삭제**: `~/.config/comfyui-desktop-2`
3. **데이터, 캐시, 상태 폴더 삭제**: `~/.local/share/comfyui-desktop-2`, `~/.cache/comfyui-desktop-2`, `~/.local/state/comfyui-desktop-2`
4. **개별 설치 삭제**: 앱 내에서 삭제하거나 `~/ComfyUI-Installs`와 직접 설정한 사용자 지정 설치 디렉토리를 수동으로 삭제하세요.
5. **공유 모델 라이브러리 삭제**: `~/ComfyUI-Shared`를 삭제하세요(해당 파일이 더 이상 필요하지 않은 경우).

`.deb` 또는 AppImage로 설치한 경우, 앱 프로필과 로그는 `~/.config/Comfy Desktop`에도 저장됩니다. 저장소의 [reset-linux.sh](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/scripts/reset-linux.sh) 스크립트를 실행하면 알려진 모든 앱 데이터를 정리하며, `~/ComfyUI-Installs`는 그대로 유지됩니다.
