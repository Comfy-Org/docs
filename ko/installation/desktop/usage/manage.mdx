## 관리 패널

관리 패널의 콘텐츠는 인스턴스 유형에 따라 다릅니다. 이 페이지의 스크린샷은 **로컬 독립 실행형 설치**를 보여줍니다. 클라우드 및 원격 인스턴스는 탭과 설정이 더 적습니다.

관리 패널을 열려면 **Chooser** 뷰(인스턴스를 나열하는 홈 화면)에서 인스턴스 카드의 ⋮ 아이콘을 클릭한 뒤 **관리**를 선택하세요.

![로컬 인스턴스의 관리 패널: 업데이트, 시작 인수, 스냅샷, 저장소, 터미널, 정보](/images/desktop/usage/instance_settings_00.png)

패널에는 **업데이트**, **시작 인자**, **스냅샷**, **저장소**, **터미널**, **정보**의 여섯 개 탭이 있습니다.

### 업데이트 탭

![관리 패널의 업데이트 탭: 설치된 버전과 최신 버전을 보여주는 ComfyUI 업데이트 카드와 그 아래의 PyTorch 패키지 카드](/images/desktop/usage/instance_settings_01_update.png)

이 탭에는 ComfyUI용 카드와 PyTorch용 카드가 하나씩 있습니다. 두 카드의 구성은 같습니다. 제목에 현재 버전이 표시되고, 드롭다운에서 채널이나 torch 스택을 고르면 카드 아래 버튼이 선택한 항목에 대해 동작합니다.

#### ComfyUI

제목에는 ComfyUI 버전이 표시되며, 선택한 채널에 더 새로운 릴리스가 없는 동안 **Up to date** 배지가 붙습니다. 더 새로운 릴리스가 있으면 제목이 해당 버전으로 바뀌고 **Update available** 배지가 붙으며, 카드에 **Installed Version** 과 **Latest Version** 행이 추가됩니다. **Last checked** 는 Comfy Desktop이 마지막으로 확인한 뒤 얼마나 지났는지를 보여주며, 마우스를 올리면 정확한 시각이 표시됩니다.

- **Update Channel**: **Stable**(테스트를 거친 릴리스, 기본값) 또는 **Latest on GitHub**(master 브랜치의 최신 커밋). 드롭다운에서 인스턴스가 현재 사용하는 채널에 **Current** 가 표시됩니다.
- **Check for updates**: 선택한 채널에 더 새로운 릴리스가 없을 때 표시되며, 즉시 다시 확인합니다. 이 확인은 Comfy Desktop이 자체적으로도 수행합니다. [FAQ](/ko/installation/desktop/faq#일반-질문)를 참고하세요.
- **Update Now**: 선택한 채널에 더 새로운 릴리스가 있을 때만 표시됩니다. 확인 대화상자에 전환할 이전 버전과 새 버전(또는 전환할 채널), 해당 채널이 공개한 릴리스 노트가 표시되고 스냅샷 탭을 안내합니다. Comfy Desktop은 업데이트 전에 스냅샷을 저장하므로, 새 버전에서 사용자 정의 노드가 깨지면 그곳에서 이전 상태로 되돌릴 수 있습니다.
- **Copy & Update**: 인스턴스를 복사하고 복사본만 업데이트하며 원본은 그대로 둡니다. 기존 노드 구성을 유지한 채 새 버전을 시험할 때 사용합니다.
- **Switch Channel**: 선택한 채널에 설치할 업데이트가 없을 때 표시되며, 업데이트 없이 인스턴스를 해당 채널로 전환합니다.

안정 버전보다 앞선 커밋으로 실행 중인 인스턴스에서 **Stable** 을 선택하면 롤백이 됩니다. 확인 대화상자에도 그 사실이 표시되며, 더 새로운 커밋은 제거됩니다.

#### PyTorch

카드에는 설치된 torch 빌드가 표시되고, 이 인스턴스에 설치할 수 있는 공식 스택 목록이 나옵니다. 스택이 여러 백엔드에 걸쳐 있으면 다른 드롭다운에서 백엔드를 먼저 고릅니다(**CUDA 13.0**, **CUDA 12.8** 등과 **ROCm**, **Intel XPU**, **CPU**). 각 옵션에는 torchvision과 torchaudio 버전이 표시되며, 번들로 배포되는 스택은 다운로드 크기도 표시됩니다. torchaudio가 없는 스택에는 경고가 붙습니다. 전환하면 torchaudio가 제거되어 이를 필요로 하는 사용자 정의 노드가 동작하지 않기 때문입니다.

- **Change PyTorch**: 이 인스턴스를 선택한 스택으로 전환합니다. 확인 대화상자에 다운로드 내용이 표시되고, 전환하는 동안 현재 환경이 백업되며 실패하면 자동으로 복원됩니다.
- **Copy & Change PyTorch**: 인스턴스의 새 복사본에서 같은 전환을 수행하고 원본은 그대로 둡니다.

나이틀리 빌드는 불안정으로 표시됩니다. 선택기에는 게시일 이후 약 45일 동안만 표시되며, PyTorch가 해당 나이틀리를 인덱스에서 제거하는 약 60일보다 먼저 목록에서 빠집니다.

### 시작 인자 탭

![인스턴스 실행 인자 및 베타 인자를 설정하는 Manage Startup Args 탭](/images/desktop/usage/instance_settings_02_startup_args.png)

시작 CLI 인자, 매니저 정책, 실행 모드, 브라우저 캐시 공유, 포트 충돌 동작, 환경 변수를 설정합니다.

- **시작 인자**: ComfyUI용 사용자 지정 CLI 인자입니다(예: `--listen`). 톱니바퀴 아이콘을 클릭하면 카테고리별 플래그를 볼 수 있습니다. 베타 기능이 활성화된 경우 필드 옆의 **+N beta** 표시에 현재 실행 중인 세션을 위해 Comfy Desktop이 추가한 베타 인자 또는 다음 실행 시 적용 가능한 인자가 나열됩니다.
- **매니저 보안 수준**: 이 인스턴스에서 ComfyUI-Manager가 설치할 수 있는 노드 팩을 제어합니다. 다음 실행 시 적용됩니다.
  - **엄격**: 모든 노드 팩 설치, 업데이트, 제거를 차단합니다. 매니저는 읽기 전용입니다.
  - **표준(권장)**: 등록된 노드 팩을 허용합니다. 등록되지 않은 소스(예: 임의의 git URL)에서의 설치를 차단합니다.
  - **완화**: 표준과 같지만, ComfyUI에 이 머신에서만 접근할 수 있는 경우 등록되지 않은 소스에서의 설치도 허용합니다. `--listen`을 사용하면 다시 차단됩니다.
  - **허용**: 모든 위험 등급을 허용합니다. ComfyUI가 `--listen`으로 노출된 경우에도 설치는 **개인 클라우드** 네트워크 모드를 요구합니다.
- **매니저 네트워크 모드**: 매니저가 노드 레지스트리와 통신하는 방식입니다.
  - **공개(기본값)**: 공개 레지스트리를 사용합니다. `--listen`을 사용하면 모든 보안 수준에서 노드 팩 설치가 차단됩니다.
  - **비공개**: 직접 구성한 비공개 노드 데이터베이스를 사용합니다.
  - **오프라인**: 외부 네트워크를 사용하지 않습니다. 다운로드를 사용할 수 없습니다.
  - **개인 클라우드**: 이 머신을 신뢰할 수 있는 원격 머신으로 취급하고 `--listen` 설치 차단을 해제합니다. 선택한 보안 수준은 그대로 적용됩니다. 직접 관리하는 머신에서만 사용하세요.
- **실행 모드**: **앱 창**(임베디드) 또는 **콘솔 전용**(앱 창 없음, ComfyUI가 콘솔 프로세스로 실행됨)입니다.
- **브라우저 캐시**: **이 인스턴스 전용** 또는 **공유**입니다.
- **포트가 사용 중인 경우**: **수행할 작업 묻기** 또는 **사용 가능한 다음 포트 사용(--port가 설정된 경우 묻기)**입니다.
- **환경 변수**: **+ 변수 추가** 버튼으로 사용자 지정 환경 변수를 추가합니다. 키 이름이 자격 증명처럼 보이는 값(예: `HF_TOKEN`, `AWS_SECRET_ACCESS_KEY`)은 표시할 때까지 가려지고, 중복된 키는 필드 아래에 경고가 표시됩니다. Comfy Desktop은 이 값을 암호화하지 않고 디스크에 저장하므로 실제 시크릿은 이 목록에 넣지 마세요.

#### 피커로 시작 인자 구성하기

**시작 인자** 옆의 톱니바퀴 아이콘을 클릭하면 인자 편집기가 열립니다. 이 인스턴스에 설치된 ComfyUI 버전에서 플래그 목록을 읽어 오므로, 해당 버전이 지원하는 인자만 표시됩니다.

![시작 인자 편집기: 원시 인자 필드, 검색 상자, Active 섹션, Network 카테고리](/images/desktop/usage/instance_settings_02-2_startup_args_builder.png)

- **Raw arguments**: Comfy Desktop이 ComfyUI에 전달하는 인자 문자열을 유지합니다. 직접 편집할 수 있고, 페이지의 모든 스위치가 이 텍스트를 따릅니다. 입력하는 동안 플래그를 검사해 알 수 없는 플래그는 **Unsupported**, 값이 필요한데 아직 값이 없는 플래그는 **Missing value for**로 표시되며, 값을 받는 플래그는 입력할 때까지 값이 필요하다는 안내가 표시됩니다. 입력 중에는 플래그 이름 자동 완성도 동작합니다.
- **Search arguments**: 플래그 이름과 각 플래그의 설명 텍스트로 목록을 필터링하고, 각 카테고리 안에서 일치도가 높은 순서로 정렬합니다. 검색 상자를 비우면 모든 플래그와 Active 섹션이 다시 표시됩니다.
- **Active**: 이 인스턴스에 이미 설정된 플래그를 모아 보여 주므로 카테고리를 찾아다니지 않고 수정할 수 있습니다.
- 나머지 영역은 플래그를 주제별로 묶습니다: Network, Launch, GPU & VRAM, Precision, Performance, Cache, Preview, Manager, Frontend, Features, Paths, Logging, Advanced, Other. 스위치를 켜면 플래그가 추가되고, 값을 받는 플래그는 설명 텍스트 아래에 입력 필드가 나타납니다.
- 함께 사용할 수 없는 플래그는 한 줄의 **Choose one**으로 합쳐집니다. 드롭다운에서 하나를 고르거나 **None (default)**를 선택해 그룹을 해제합니다. 한 멤버를 켜면 다른 멤버는 해제됩니다.

편집기가 인식하지 못하는 플래그는 필드에 남아 스위치 편집을 거쳐도 사라지지 않지만, Comfy Desktop이 인스턴스를 시작할 때 ComfyUI로 전달하지는 않습니다.

변경 사항은 다음에 인스턴스를 시작할 때 적용됩니다. 인스턴스가 실행 중일 때 인자를 편집하면 편집기에 **Restart to apply**가 표시됩니다. 설치된 ComfyUI에서 플래그 목록을 읽을 수 없으면 페이지에 카테고리 대신 해당 오류가 표시되고, Raw arguments 필드는 계속 사용할 수 있습니다.

### 스냅샷 탭

![인스턴스의 복원 지점을 나열하는 관리 스냅샷 탭](/images/desktop/usage/instance_settings_03_snapshots.png)

스냅샷을 보고, 가져오고, 내보내고, 생성할 수 있습니다. 각 항목에는 버전 변경과 패키지 통계가 표시됩니다.

- **타임라인**: 모든 스냅샷을 시간순으로 나열하며 버전 변경과 통계를 보여줍니다.
- **최신**: 가장 최근 스냅샷이 생성된 시점을 표시합니다.
- **가져오기**: 파일에서 스냅샷을 가져옵니다.
- **모두 내보내기**: 모든 스냅샷을 백업으로 내보냅니다.
- **스냅샷 생성**: 언제든지 수동으로 새 스냅샷을 만들 수 있습니다.
- 각 스냅샷 항목에는 다음이 표시됩니다:
  - 버전 변경(예: `v0.20.1 → v0.24.1`)
  - 패키지 변경
  - 노드 및 패키지 수
  - **내보내기** 및 **삭제** 버튼

### 저장소 탭

![인스턴스별 모델 및 입출력 경로를 위한 관리 스토리지 탭](/images/desktop/usage/instance_settings_04_storage.png)

이 인스턴스가 전역 공유 폴더를 사용할지 여부를 설정하고, 이 인스턴스에만 적용되는 추가 모델 디렉토리를 추가합니다.

- **공유 디렉토리 포함**: 이 인스턴스가 [데스크탑 설정 → 스토리지](/ko/installation/desktop/usage/settings#저장소)의 전역 공유 모델 디렉토리를 스캔할지 여부를 전환합니다.
- **공유 입력 폴더 사용**: 활성화하면 이 인스턴스가 전역 공유 입력 폴더에서 입력 파일을 읽습니다. 비활성화하면 이 인스턴스 자체의 입력 폴더를 사용합니다.
- **공유 출력 폴더 사용**: 활성화하면 이 인스턴스가 생성된 출력을 전역 공유 출력 폴더에 기록합니다. 비활성화하면 이 인스턴스 자체의 출력 폴더를 사용합니다.
- **모델 디렉토리**: 이 인스턴스에만 적용되는 추가 모델 디렉토리로, 공유 모델 디렉토리에 더해 검색됩니다.
- **입력 디렉토리** / **출력 디렉토리**: 위의 공유 토글이 꺼져 있을 때 사용되는 이 인스턴스 자체의 폴더입니다.

### 터미널 탭

![인스턴스 콘솔을 보여주는 관리 터미널 탭](/images/desktop/usage/instance_settings_05_console.png)

이 인스턴스 폴더에서 실행되는 대화형 셸입니다. ComfyUI가 실행 중이든 중지되어 있든 작동합니다.

- 시작 로그, 오류 및 Python 출력을 확인하는 데 사용하세요.
- 복사, 붙여넣기, 전체 선택은 OS 단축키를 따릅니다. 동일한 작업을 하려면 터미널을 마우스 오른쪽 버튼으로 클릭하세요.

### 정보 탭

![관리 패널의 정보 탭: 편집할 수 있는 인스턴스 이름, 인스턴스 정보, 설치 경로](/images/desktop/usage/instance_settings_05_about.png)

정보 탭에는 Comfy Desktop이 해당 인스턴스에 대해 알고 있는 정보가 모여 있습니다. 경로를 클릭하면 파일 관리자에서 열리고, 옆의 복사 버튼으로 경로를 복사할 수 있습니다.

정보는 그룹으로 나뉘며, 내용이 있는 그룹만 표시됩니다.

- **Instance details**: ComfyUI 버전, 하드웨어, Python 및 PyTorch 버전. 원격 연결의 경우 이 그룹에 연결 URL과 추가 날짜가 표시됩니다.
- **Running details**: ComfyUI가 수신 대기 중인 포트. 인스턴스가 실행 중일 때만 표시됩니다.
- **Location & storage**: 디스크의 전체 설치 경로와 설치가 사용하는 공간. 파일이 이 컴퓨터에 있는 것은 로컬 설치뿐이므로 Cloud와 원격 연결에는 이 그룹이 없습니다.
- **Lineage**: 이 인스턴스를 복사한 원본 인스턴스와 시점. **Duplicate Instance**, 버전이나 PyTorch를 바꾼 복사, 레거시 데스크톱에서의 마이그레이션, 또는 그 자리에서의 인수를 통해 만든 인스턴스에 표시됩니다.

#### 인스턴스 이름 변경

![정보 탭에서 인스턴스 이름과, 마우스를 올리면 나타나는 연필 버튼이 강조된 화면](/images/desktop/usage/instance_settings_06_rename.png)

정보 탭 상단의 인스턴스 이름을 클릭한 뒤 새 이름을 입력하고 Enter를 누르거나 다른 곳을 클릭합니다. 이름 위에 마우스를 올리면 연필 버튼이 나타나며, 클릭하면 같은 필드에 커서가 들어갑니다. Esc를 누르면 편집이 취소되고 이전 이름이 유지되며, 이름이 비어 있거나 현재 이름과 같으면 아무것도 변경되지 않습니다.

관리 패널의 **More** 메뉴에 있는 **Rename**도 같은 작업이며, **Name** 필드가 있는 **Rename Instance** 대화상자가 열립니다.

다른 인스턴스가 사용 중인 이름은 거부되며 다른 이름을 선택하라는 안내가 표시됩니다. Comfy Cloud 항목은 이름을 유지하며 연필 버튼도 없습니다. 로컬, 원격, 추적 인스턴스만 이름을 변경할 수 있습니다.

#### 원격 연결 URL 변경

![원격 연결의 정보 탭에서 연결 URL과 연필 버튼이 강조된 화면](/images/desktop/usage/instance_settings_07_remote_url.png)

원격 연결의 주소는 정보 탭의 **URL** 행입니다. URL이나 옆의 연필 버튼을 클릭한 뒤 새 주소를 입력하고 Enter를 누르거나 다른 곳을 클릭합니다. 스킴이 없는 주소는 `http://`로 해석되며, 저장할 때 끝의 슬래시는 제거됩니다.

인스턴스가 연결된 상태에서 수정한 URL은 다음 실행부터 적용됩니다. 다시 시작할 때까지 해당 행에 **Restart to apply**가 표시되며, 실행 중인 세션은 이전 주소를 계속 사용합니다. Comfy Desktop이 해석할 수 없는 주소는 저장되지 않고, 행은 이전 값으로 돌아갑니다.

## 설치 작업

설치 카드를 마우스 오른쪽 버튼으로 클릭(또는 ⋮ 아이콘 클릭)하여 작업에 액세스합니다. 전체 작업 목록은 [인스턴스 관리](/ko/installation/desktop/usage/instance-management) 페이지를 참조하세요.
