## 관리 패널

관리 패널의 콘텐츠는 인스턴스 유형에 따라 다릅니다. 이 페이지의 스크린샷은 **로컬 독립 실행형 설치**를 보여줍니다. 클라우드 및 원격 인스턴스는 탭과 설정이 더 적습니다.

설정 패널을 열려면 인스턴스에서 **관리**를 선택하세요.

![로컬 인스턴스의 관리 패널: 업데이트, 시작 인수, 스냅샷, 저장소, 터미널, 정보](/images/desktop/usage/instance_settings_00.png)

- **Chooser** 뷰(모든 인스턴스를 보여주는 홈 화면)를 엽니다
- 인스턴스 카드의 ⋮ 아이콘을 클릭합니다
- 컨텍스트 메뉴에서 **관리**를 선택합니다

패널에는 여섯 개의 탭이 있습니다:

### 업데이트 탭

![관리 패널의 업데이트 탭: ComfyUI 버전, 업데이트 채널, PyTorch 패키지](/images/desktop/usage/instance_settings_01_update.png)

이 탭은 현재 버전을 보여주고, 업데이트를 확인하며, 업데이트 채널을 구성할 수 있게 해줍니다.

- **버전**: 현재 설치된 버전과 최신 상태 여부를 표시합니다.
- **마지막 확인**: 업데이트를 마지막으로 확인한 시점을 표시합니다.
- **업데이트 확인**: 새 버전을 수동으로 확인합니다.
- **업데이트 채널**: 드롭다운에서 업데이트 채널을 선택합니다:
  - **Stable**: 테스트를 거친 릴리스로, 대부분의 사용자에게 권장됩니다. 기본 옵션입니다.
  - **Latest on GitHub**: master 브랜치의 최신 커밋입니다.

### 시작 인자 탭

![인스턴스 실행 인자 및 베타 인자를 설정하는 Manage Startup Args 탭](/images/desktop/usage/instance_settings_02_startup_args.png)

시작 CLI 인자, 매니저 정책, 실행 모드, 브라우저 캐시 공유, 포트 충돌 동작, 환경 변수를 설정합니다.

- **시작 인자**: ComfyUI용 사용자 지정 CLI 인자입니다(예: `--listen`). 톱니바퀴 아이콘을 클릭하면 카테고리별 플래그를 볼 수 있습니다. 베타 기능이 활성화된 경우 필드 옆의 **+N beta** 표시에 현재 실행 중인 세션을 위해 Comfy Desktop이 추가한 베타 인자 또는 다음 실행 시 적용 가능한 인자가 나열됩니다.
- **매니저 보안 수준**: 이 인스턴스에서 ComfyUI-Manager가 설치할 수 있는 노드 팩을 제어합니다. 다음 실행 시 적용됩니다.
  - **엄격**: 모든 노드 팩 설치, 업데이트, 제거를 차단합니다. 매니저는 읽기 전용입니다.
  - **표준(권장)**: 등록된 노드 팩을 허용합니다. 등록되지 않은 소스(예: 임의의 git URL)에서의 설치를 차단합니다.
  - **완화**: 표준과 같지만, ComfyUI에 이 머신에서만 접근할 수 있는 경우 등록되지 않은 소스에서의 설치도 허용합니다. `--listen`을 사용하면 다시 차단됩니다.
  - **허용**: 모든 위험 등급을 허용합니다. ComfyUI가 `--listen`으로 노출된 경우에도 설치는 **개인 클라우드** 네트워크 모드를 요구합니다.
- **매니저 네트워크 모드**: 매니저가 노드 레지스트리와 통신하는 방식입니다.
  - **공개(기본값)**: 공개 레지스트리를 사용합니다. `--listen`을 사용하면 모든 보안 수준에서 노드 팩 설치가 차단됩니다.
  - **비공개**: 직접 구성한 비공개 노드 데이터베이스를 사용합니다.
  - **오프라인**: 외부 네트워크를 사용하지 않습니다. 다운로드를 사용할 수 없습니다.
  - **개인 클라우드**: 이 머신을 신뢰할 수 있는 원격 머신으로 취급하고 `--listen` 설치 차단을 해제합니다. 선택한 보안 수준은 그대로 적용됩니다. 직접 관리하는 머신에서만 사용하세요.
- **실행 모드**: **앱 창**(임베디드) 또는 **콘솔 전용**(앱 창 없음, ComfyUI가 콘솔 프로세스로 실행됨)입니다.
- **브라우저 캐시**: **이 인스턴스 전용** 또는 **공유**입니다.
- **포트가 사용 중인 경우**: **수행할 작업 묻기** 또는 **사용 가능한 다음 포트 사용(--port가 설정된 경우 묻기)**입니다.
- **환경 변수**: **+ 변수 추가** 버튼으로 사용자 지정 환경 변수를 추가합니다.

### 스냅샷 탭

![인스턴스의 복원 지점을 나열하는 관리 스냅샷 탭](/images/desktop/usage/instance_settings_03_snapshots.png)

스냅샷을 보고, 가져오고, 내보내고, 생성할 수 있습니다. 각 항목에는 버전 변경과 패키지 통계가 표시됩니다.

- **타임라인**: 모든 스냅샷을 시간순으로 나열하며 버전 변경과 통계를 보여줍니다.
- **최신**: 가장 최근 스냅샷이 생성된 시점을 표시합니다.
- **가져오기**: 파일에서 스냅샷을 가져옵니다.
- **모두 내보내기**: 모든 스냅샷을 백업으로 내보냅니다.
- **스냅샷 생성**: 언제든지 수동으로 새 스냅샷을 만들 수 있습니다.
- 각 스냅샷 항목에는 다음이 표시됩니다:
  - 버전 변경(예: `v0.20.1 → v0.24.1`)
  - 패키지 변경
  - 노드 및 패키지 수
  - **내보내기** 및 **삭제** 버튼

### 저장소 탭

![인스턴스별 모델 및 입출력 경로를 위한 관리 스토리지 탭](/images/desktop/usage/instance_settings_04_storage.png)

이 인스턴스가 전역 공유 폴더를 사용할지 여부를 설정하고, 이 인스턴스에만 적용되는 추가 모델 디렉토리를 추가합니다.

- **공유 디렉토리 포함**: 이 인스턴스가 [데스크탑 설정 → 스토리지](/ko/installation/desktop/usage/settings#저장소)의 전역 공유 모델 디렉토리를 스캔할지 여부를 전환합니다.
- **공유 입력 폴더 사용**: 활성화하면 이 인스턴스가 전역 공유 입력 폴더에서 입력 파일을 읽습니다. 비활성화하면 이 인스턴스 자체의 입력 폴더를 사용합니다.
- **공유 출력 폴더 사용**: 활성화하면 이 인스턴스가 생성된 출력을 전역 공유 출력 폴더에 기록합니다. 비활성화하면 이 인스턴스 자체의 출력 폴더를 사용합니다.
- **모델 디렉토리**: 이 인스턴스에만 적용되는 추가 모델 디렉토리로, 공유 모델 디렉토리에 더해 검색됩니다.
- **입력 디렉토리** / **출력 디렉토리**: 위의 공유 토글이 꺼져 있을 때 사용되는 이 인스턴스 자체의 폴더입니다.

### 터미널 탭

![인스턴스 콘솔을 보여주는 관리 터미널 탭](/images/desktop/usage/instance_settings_05_console.png)

이 인스턴스 폴더에서 실행되는 대화형 셸입니다. ComfyUI가 실행 중이든 중지되어 있든 작동합니다.

- 시작 로그, 오류 및 Python 출력을 확인하는 데 사용하세요.
- 복사, 붙여넣기, 전체 선택은 OS 단축키를 따릅니다. 동일한 작업을 하려면 터미널을 마우스 오른쪽 버튼으로 클릭하세요.

### 정보 탭

![인스턴스 경로와 버전 세부 정보가 있는 관리 정보 탭](/images/desktop/usage/instance_settings_05_about.png)

설치 세부 정보를 확인하세요: ComfyUI 버전, 하드웨어, Python 및 PyTorch 버전, 디스크 경로, 사용량.

- **현재 버전**: 설치된 ComfyUI 버전.
- **하드웨어**: 감지된 하드웨어(예: `Apple Silicon (MPS)`).
- **Python**: 번들된 Python 버전.
- **PyTorch**: 설치된 PyTorch 빌드. **PyTorch 변경**은 이 설치 유형(CUDA, ROCm, Intel XPU, CPU 또는 Apple MPS)으로 테스트된 공식 스택으로 전환합니다. 나머지 환경은 유지됩니다. 최신 테스트 버전(nightly) 빌드는 불안정으로 표시됩니다.
- **위치**: 디스크의 전체 설치 경로입니다. 복사 버튼을 클릭하여 복사하세요.
- **디스크 사용량**: 설치가 사용하는 디스크 공간입니다.

## 설치 작업

설치 카드를 마우스 오른쪽 버튼으로 클릭(또는 ⋮ 아이콘 클릭)하여 작업에 액세스합니다. 전체 작업 목록은 [인스턴스 관리](/ko/installation/desktop/usage/instance-management) 페이지를 참조하세요.
