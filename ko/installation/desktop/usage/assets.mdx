**에셋** 페이지는 Comfy Desktop에서 빌드와 Comfy Cloud가 생성한 파일을 보여줍니다. 이미지, 비디오, 오디오, 3D 모델 등이 포함됩니다. 한 번에 한 위치, 예를 들어 Comfy Cloud 또는 특정 빌드의 출력 폴더만 표시합니다. 열려면 **사이드바**에서 **에셋**을 클릭하세요.

<Note>
  이것은 Comfy Desktop 자체의 페이지입니다. 실행 중인 ComfyUI 내부에서 **에셋** 패널은 해당 빌드를 위한 별도의 갤러리입니다. 자세한 내용은 [ComfyUI의 에셋](/ko/interface/assets)을 참조하세요.
</Note>

## 볼 위치 선택

페이지 왼쪽 상단의 메뉴에서 어떤 위치의 파일을 표시할지 선택합니다. 이 메뉴에는 두 개의 그룹이 있습니다:

- **Comfy Cloud**: Comfy Cloud의 출력입니다. 로그인되어 있어야 합니다. 메뉴에는 그 아래에 워크스페이스 이름이 표시됩니다.
- **This computer**: 로컬 빌드가 기본적으로 사용하는 공유 출력 폴더인 **Shared folder**와, 자체 출력 폴더에 저장하는 각 로컬 빌드입니다. 메뉴에는 각 폴더의 경로가 표시됩니다. 위치 옆의 폴더 버튼을 클릭하면 Finder 또는 Explorer에서 해당 위치가 열립니다.

에셋은 **사이드바**에서 선택한 워크스페이스의 위치를 나열합니다. 원격 빌드는 나열되지 않습니다. 원격 빌드에서 **Auto-download outputs**가 켜져 있으면 해당 출력은 다운로드되는 폴더 아래에 표시됩니다. [원격 및 Comfy Cloud 빌드의 출력 옵션 설정](/ko/installation/desktop/usage/instance-management#원격-및-comfy-cloud-빌드의-출력-옵션-설정)을 참조하세요.

## 파일 찾기

- **유형**: **전체**, **이미지**, **동영상**, **3D**, **오디오**.
- **이름으로 검색…**: 입력한 내용이 이름에 포함된 파일을 찾습니다.
- **에셋 새로 고침**: 목록을 다시 불러옵니다. 빌드에서 새 파일을 저장한 후 클릭하세요.

Comfy Cloud에서는 유형 필터가 현재 정렬 순서로 최신 출력 50,000개를 확인하며, 페이지의 목록 아래에 이 내용이 나와 있습니다.

## 보기 변경

**보기 옵션**을 클릭하여 다음을 설정합니다.

- **레이아웃**: **메이슨리** 또는 **그리드**.
- **정렬 기준**: **최신순** 또는 **오래된순**.
- **표시**: 각 파일 아래에 **파일 이름** 및 **파일 세부 정보**.

Comfy Desktop은 이러한 옵션을 기억합니다. 페이지 하단에서 페이지 간을 이동하고 페이지에 표시할 파일 수(50, 100, 200)를 선택합니다.

## 파일 미리보기

파일을 클릭하면 뷰어에서 열립니다. 뷰어는 파일을 크게 표시하며 유형, **생성 날짜**, 크기, 치수를 함께 보여 줍니다. 이 컴퓨터에 있는 파일의 경우 **저장 위치**와 폴더도 표시합니다.

- 왼쪽 및 오른쪽 화살표 키를 눌러 이전 또는 다음 파일로 이동합니다.
- 이미지의 경우 **맞춤** 또는 확대/축소 수준을 선택합니다.
- 최대 100 MB의 3D 모델은 3D 보기에서 열립니다. 더 큰 모델의 경우 뷰어에 **이 3D 모델을 표시할 수 없습니다. 다운로드하여 3D 앱에서 여세요.**가 표시됩니다.
- **태그**는 파일의 태그를 보여 줍니다. 태그는 ComfyUI에서 편집합니다.

## 파일 작업

파일 위로 포인터를 가져가면 주요 작업이 표시됩니다. 나머지 작업은 **추가 작업** (**⋯**)을 클릭하거나 파일을 마우스 오른쪽 버튼으로 클릭하면 볼 수 있습니다:

| 작업 | 위치 | 수행하는 작업 |
| --- | --- | --- |
| **열기** | 이 컴퓨터의 이미지, 비디오 및 오디오 | 파일을 기본 앱으로 엽니다. |
| **Finder에서 보기**, **Explorer에서 보기** 또는 **폴더에서 보기** | 이 컴퓨터의 파일 | 파일이 있는 폴더를 엽니다. 표시 이름은 운영 체제에 따라 달라집니다. |
| **다운로드** | Comfy Cloud | 이 컴퓨터에 사본을 저장합니다. [Comfy Cloud에서 다운로드](#comfy-cloud에서-다운로드)를 참조하세요. |
| **복사** | 이미지 | 이미지를 클립보드에 복사합니다. |
| **삭제** | 이 컴퓨터의 파일 | **{name}을(를) 삭제하시겠습니까?**라고 확인한 다음, 파일을 휴지통으로 이동합니다(Windows에서는 Recycle Bin). |

파일은 한 번에 하나씩만 작업할 수 있습니다. Comfy Desktop에서는 Comfy Cloud 파일을 삭제할 수 없습니다.

## 파일을 만든 워크플로 열기

이미지, 비디오 또는 오디오 파일에 해당 파일을 만든 워크플로가 포함되어 있으면 뷰어에 **워크플로우 열기**가 표시됩니다.

- Comfy Cloud 파일의 경우 워크플로가 Comfy Cloud에서 열립니다.
- 이 컴퓨터에 있는 파일의 경우 파일이 들어 있는 폴더를 가진 빌드에서 워크플로가 열립니다. 여러 빌드가 같은 폴더를 공유하는 경우 **다음에서 열기**에서 빌드를 선택하세요.

Comfy Desktop은 빌드가 실행 중이 아니면 빌드를 시작합니다. 워크플로가 열리지 않으면 페이지에 **워크플로를 열 수 없습니다**가 표시됩니다.

## Comfy Cloud에서 다운로드

1. 왼쪽 상단의 메뉴에서 **Comfy Cloud**를 선택합니다.
2. 파일 위로 포인터를 이동한 다음 **다운로드**를 클릭합니다.
3. 폴더를 선택합니다. 저장 대화 상자는 마지막으로 저장한 폴더 또는 Downloads 폴더에서 열립니다.

다운로드는 [다운로드](/ko/installation/desktop/usage/downloads) 트레이에 표시됩니다.

## 파일이 저장되는 위치

- **이 컴퓨터**: 출력은 공유 출력 폴더 또는 빌드 자체의 출력 폴더에 저장됩니다. 공유 폴더는 [데스크탑 설정](/ko/installation/desktop/usage/settings)에서 설정하고, 빌드의 폴더는 [폴더 탭](/ko/installation/desktop/usage/instance-management#빌드가-사용할-폴더-선택)에서 설정합니다.
- **Comfy Cloud**: 출력은 다운로드할 때까지 Comfy Cloud에 남아 있습니다.

## 문제 해결 {#troubleshoot}

<AccordionGroup>
  <Accordion title="아직 에셋이 없음">
    선택한 위치에 아직 파일이 없습니다. 빌드에서 워크플로를 실행하거나 [앱](/ko/installation/desktop/usage/apps)을 실행한 다음 **에셋 새로 고침**을 클릭하세요.
  </Accordion>
  <Accordion title="일치하는 에셋이 없음">
    유형 또는 검색으로 인해 모든 파일이 숨겨져 있습니다. **전체**를 선택하거나 **이름으로 검색…**을 지우세요.
  </Accordion>
  <Accordion title="에셋을 보려면 로그인하세요">
    **Comfy Cloud**가 선택되어 있지만 로그인되어 있지 않습니다. **Log in to Comfy Cloud**를 클릭하세요.
  </Accordion>
  <Accordion title="이 워크스페이스에는 Comfy Cloud 빌드가 없음">
    **사이드바**에서 선택한 워크스페이스에 Comfy Cloud 빌드가 없습니다. Comfy Cloud를 다시 추가하려면 Comfy Desktop을 재시작하세요.
  </Accordion>
  <Accordion title="에셋을 불러올 수 없음">
    Comfy Desktop이 목록을 읽지 못했습니다. Comfy Cloud의 경우 인터넷 연결을 확인하세요. 그런 다음 **에셋 새로 고침**을 클릭하세요.
  </Accordion>
</AccordionGroup>
