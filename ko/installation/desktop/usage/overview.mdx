Comfy Desktop은 ComfyUI **빌드**를 관리합니다. 빌드는 자체 버전, 사용자 정의 노드, 모델을 가진 하나의 ComfyUI 환경입니다. 여러 빌드를 나란히 두고 한 창에서 어느 것이든 시작할 수 있습니다.

ComfyUI를 직접 설치할 필요는 없습니다. Comfy Desktop이 Python 환경을 만들고 ComfyUI 소스를 복사하며 각 빌드를 최신 상태로 유지합니다.

버전 1.2는 각 환경을 **빌드**라고 부릅니다. 이 섹션의 일부 페이지는 여전히 **인스턴스**라고 쓰는데, 같은 것을 가리킵니다.

### 주요 기능

- **[여러 빌드](/ko/installation/desktop/usage/instance-management)**: 각 빌드는 자체 ComfyUI 버전, 사용자 정의 노드, 설정을 가집니다.
- **[스냅샷](/ko/installation/desktop/usage/manage#스냅샷-탭)**: ComfyUI 버전, 사용자 정의 노드, Python 패키지를 포함한 빌드 상태를 저장하고 복원합니다.
- **[공유 모델](/ko/installation/desktop/usage/settings#저장소)**: 모델 폴더는 기본으로 공유되므로 모델 한 벌을 모든 빌드에서 씁니다.
- **업데이트**: 제목 표시줄은 Comfy Desktop 자체를 업데이트합니다. 각 빌드는 해당 [업데이트 탭](/ko/installation/desktop/usage/manage#업데이트-탭)에서 업데이트합니다.
- **Comfy Cloud**: 로컬 빌드 없이 같은 워크플로우를 클라우드 하드웨어에서 실행합니다.
- **[기존 설치](/ko/installation/desktop/usage/instance-management)**: 이미 가지고 있는 포터블 또는 git 클론 ComfyUI 폴더를 추가합니다.

## 창

![왼쪽에 사이드바, 오른쪽에 빌드 세 개가 나열된 빌드 페이지를 보여 주는 Comfy Desktop](/images/desktop/interface/interface_desktop_dashboard.png)

창은 두 부분으로 나뉩니다. 왼쪽 사이드바와 그것이 여는 오른쪽 페이지입니다. 위쪽 제목 표시줄에 창 컨트롤이 있습니다.

### 사이드바

- **Home**: 시작 페이지입니다. 빌드를 열고, 어떤 빌드가 준비되었는지 보고, 예제 워크플로우를 둘러봅니다.
- **Apps**: 공개된 Comfy 앱입니다. 앱이 켜져 있을 때만 이 행이 나타납니다.
- **Assets**: 빌드가 만든 이미지, 비디오, 워크플로우를 한 라이브러리에 모은 것입니다.
- **Builds**: 빌드 전체 목록입니다. 제목 옆의 **+** 로 새로 만들고, 각 빌드는 행으로 표시되고, 실행 중이거나 실패했을 때 상태 점이 붙습니다.
- 아래쪽에 **Desktop settings** 와 Comfy 계정이 있습니다. 로그아웃 상태에서는 **Log in to Comfy** 로 표시됩니다.

### Home

Home은 Comfy Desktop을 열 때 처음 보이는 페이지입니다. 인사말 아래에 각 빌드가 상태와 함께 카드로 나오고, 카드를 클릭하면 시작됩니다. **All builds** 는 빌드 페이지로 이동하고, 오른쪽 위의 **Open ComfyUI** 는 최근에 쓴 빌드를 엽니다. 다른 빌드는 그 메뉴에서 고를 수 있습니다. 카드 위의 캐러셀에는 예제 워크플로우가, 앱이 켜져 있으면 앱이 표시됩니다.

### 빌드

빌드 페이지는 모든 빌드를 카드로 나열하고 이름, 유형, 상태를 보여 줍니다.

- **New build** 는 이 컴퓨터에 ComfyUI를 설치합니다. 옆의 화살표를 누르면 **More build options** 가 열리고 **Add existing build** 와 **Load snapshot** 이 있습니다.
- **Where it runs** 는 목록을 All, This computer, Cloud, Remote로 걸러 줍니다. Cloud와 Remote는 해당 빌드가 있을 때만 나타납니다.
- **Sort** 는 **Last used** 또는 **Name** 순으로 정렬하고, 검색 상자는 이름으로 찾습니다.
- 카드를 클릭하면 그 빌드가 시작됩니다. 카드의 **More actions** 버튼이나 마우스 오른쪽 클릭으로 빌드 메뉴를 엽니다. 중지된 빌드는 **Start** 로 시작하고, 실행 중이면 **View logs**, **Restart**, **Stop** 이 먼저 나옵니다. 그 아래에 **Auto start**, **Manage**, **Update**, **Migrate to Standalone**, **Duplicate**, **Show in Finder**(Windows는 **Show in Explorer**, Linux는 **Show in folder**), **Export snapshot**, **Restore snapshot**, **Upload build**, **Uninstall** 이 이어집니다. 해당 빌드에 적용되지 않는 항목은 숨겨집니다.

### 앱 메뉴

제목 표시줄 오른쪽 끝의 **☰** 버튼이 앱 메뉴를 엽니다. 항목은 창에 따라 달라집니다.

- **Home 또는 빌드 페이지**: Performance tests 와 Benchmarks.
- **빌드 창**: Performance tests, Benchmarks, Desktop settings, 확대된 상태의 Reset zoom (N%), Close window, Quit Desktop.
- **최초 설정 중**: Skip onboarding 만 표시됩니다.

빌드 창을 닫아도 그 빌드는 계속 실행됩니다. 마지막 창을 닫으면 Comfy Desktop이 종료되지만, macOS에서는 로컬 빌드가 실행 중인 동안 앱이 열린 채로 남습니다. **Quit Desktop** 은 실행 중인 빌드를 중지합니다.

macOS에서는 앱, Edit, Window로 구성된 표준 시스템 메뉴 막대도 유지됩니다. Windows와 Linux 빌드에는 시스템 메뉴 막대가 없습니다.

### 제목 표시줄

- **Home** 은 빌드 창에서 Home으로 돌아갑니다.
- **Reset zoom (N%)** 은 빌드 보기가 100%가 아닐 때 나타나며, 누르면 초기화됩니다.
- **Refresh** 는 ComfyUI 보기를 다시 불러옵니다.
- **What's new** 는 짧은 메뉴를 열며, **Take the tour** 로 소개 투어를 다시 볼 수 있습니다.
- **Downloads** 는 다운로드 트레이를 엽니다. 배지는 진행 중인 개수를 보여 주고 실패했거나 확인하지 않은 다운로드를 표시합니다. 자세한 내용은 [다운로드](/ko/installation/desktop/usage/downloads)를 참고하세요.
