이 페이지에서는 첫 실행 이후 Comfy Desktop에서 사용하는 화면들을 보여 줍니다: **홈**, 가이드 투어, **사이드바**, **제목 표시줄**, 워크스페이스, **크레딧**. Comfy Desktop 설치와 첫 빌드 방법은 [Comfy Desktop](/ko/installation/desktop/overview)을 참고하세요.

## 홈에서 시작하기

**홈**은 Comfy Desktop을 시작하면 열리는 페이지입니다. **홈**에서 클릭 한 번으로 ComfyUI를 열 수 있습니다. **홈**에는 위에서 아래로 다음이 표시됩니다:

- **ComfyUI 열기**: 오른쪽 위 모서리에 있는 버튼입니다. 툴팁에 표시된 빌드에서 ComfyUI를 엽니다. 빌드가 둘 이상 있으면 옆의 화살표를 클릭해 열 빌드를 선택하세요.
- **[앱](/ko/installation/desktop/usage/apps)**: **앱**이 켜져 있을 때 표시되는 바로 사용할 수 있는 도구 행입니다. **모든 앱 보기**를 클릭하면 **앱** 페이지가 열립니다.
- **예제 워크플로**: **앱**이 켜져 있지 않으면 해당 행에 대신 예제 워크플로가 표시됩니다. 가운데 카드를 클릭하면 브라우저에서 comfy.org의 해당 페이지가 열립니다.
- **[빌드](/ko/installation/desktop/usage/instance-management)**: 최대 3개의 빌드가 각각 카드로 표시됩니다. 카드를 클릭해 빌드를 시작하거나, 실행 중인 빌드를 열 수 있습니다. **모든 빌드**를 클릭하면 모든 빌드를 볼 수 있습니다. 아직 로컬 빌드가 없으면 해당 행 끝에 **새 빌드** 타일이 표시됩니다. 클릭하면 새 빌드를 시작합니다.

Comfy Cloud 카드에는 [로그인](/ko/installation/desktop/overview#로그인하고-comfy-cloud-열기)하기 전까지 **사용하려면 로그인**이 표시됩니다.

![Comfy Desktop Home, 번호 표시: 1 오른쪽 위 Open ComfyUI 버튼, 2 앱 행, 3 See all apps, 4 BUILDS 행, 5 ComfyUI 빌드 카드, 6 사이드바 아래쪽 Desktop settings](/images/desktop/installation/comfy-desktop-landing-page.png)

1. **Open ComfyUI**: 실행 중인 빌드를 엽니다. 옆 화살표로 다른 빌드를 고릅니다.
2. **Apps**: 워크플로 없이 결과를 만드는 앱 행입니다.
3. **See all apps**: Apps 페이지를 엽니다.
4. **BUILDS**: 빌드 카드입니다. 카드를 클릭하면 시작하거나 엽니다.
5. **ComfyUI**: 이 컴퓨터에 설치된 로컬 빌드입니다.
6. **Desktop settings**: 앱 전체에 적용되는 설정입니다.

페이지 제목이 **Welcome. Let's create!**로 표시되면 **홈** 화면에 있는 것입니다.

## 가이드 투어 시작하기

**홈**이 처음 열리면 짧은 투어가 페이지의 여러 부분과 **사이드바**를 가리킵니다. 투어에서는 빌드가 무엇인지, Comfy Cloud 및 로컬 빌드 카드, 모든 빌드를 확인하고 새 빌드를 시작하는 위치, 그리고 **에셋**을 설명합니다. 이전에 Comfy Desktop을 사용한 적이 있다면 투어가 **인스턴스는 이제 빌드입니다**로 시작합니다.

- **다음**을 클릭하여 다음 단계로 이동하고, **뒤로**를 클릭하여 이전 단계로 이동하거나, **건너뛰기**를 클릭하여 투어를 닫습니다. `Esc`를 눌러도 건너뛸 수 있습니다.

투어는 예를 들어 **1 of 6**처럼 현재 위치를 표시하고, 화면에 없는 부분은 건너뜁니다. 마지막 단계에는 **뒤로**와 **완료**만 있습니다. **완료**를 클릭하여 투어를 닫습니다.

![Comfy Desktop 홈 위에 표시된 가이드 투어, 번호 표시: 1 단계 제목 Instances are now builds, 2 단계 설명 텍스트, 3 현재 위치 1 of 5, 4 Skip과 Next 버튼](/images/desktop/installation/comfy-desktop-guided-tour.png)

1. **단계 제목**: 이 단계가 가리키는 부분을 알려 줍니다. Comfy Desktop을 써 본 적이 있으면 투어가 **Instances are now builds**로 시작합니다.
2. **단계 설명**: 그 부분을 한두 문장으로 설명합니다.
3. **현재 위치**: 지금 어디쯤인지 **1 of 5**처럼 보여 줍니다. 화면에 없는 부분은 건너뛰므로 전체 개수는 달라집니다.
4. **Skip**과 **Next**: 투어를 닫거나 다음 단계로 넘어갑니다.

### 투어 다시 보기

투어를 다시 보려면:

1. **제목 표시줄**에서 벨 아이콘(**새로운 기능**)을 클릭합니다.
2. **투어 시작하기**를 선택합니다.

**홈**이 열리고 투어가 다시 시작됩니다.

## 사이드바 살펴보기

**홈** 창 왼쪽의 **사이드바**는 페이지 사이를 이동하는 수단입니다.

![홈, 앱, 에셋 항목과 초록색 점으로 표시된 ComfyUI 빌드가 있는 빌드 목록, 그리고 Comfy Cloud가 보이는 Comfy Desktop 사이드바 상단](/images/desktop/installation/comfy-desktop-builds-sidebar.png)

각 항목을 클릭하면 페이지가 열립니다:

| 항목 | 열리는 페이지 |
| --- | --- |
| **홈** | **홈**. **사이드바**가 펼쳐져 있을 때는 맨 위의 Comfy 로고를 클릭해도 열립니다. |
| **앱** | [**앱**](/ko/installation/desktop/usage/apps) 페이지로, **앱 검색**으로 앱을 검색하고 열 수 있습니다. 이 항목은 **앱**이 켜져 있을 때만 표시됩니다. |
| **에셋** | [**에셋**](/ko/installation/desktop/usage/assets) 페이지로, 빌드와 Comfy Cloud가 생성한 결과물을 찾아볼 수 있습니다. |
| **빌드** | 모든 빌드. |

**빌드** 아래에 **사이드바**가 각 빌드를 나열합니다:

- 빌드를 클릭하면 해당 빌드 페이지가 열립니다.
- 빌드를 마우스 오른쪽 버튼으로 클릭하면 작업 메뉴가 나타납니다.
- 새 빌드를 시작하려면 **빌드** 위에 포인터를 두고 더하기(**+**) 버튼(**새 빌드**)을 클릭하세요.

빌드에 초록색 점이 있으면 실행 중이라는 뜻입니다. 빨간색 점은 충돌했거나 시작하지 못했다는 뜻입니다. 빌드 위에 마우스를 올리면 이유를 확인할 수 있습니다.

**사이드바** 하단에는 다음이 있습니다:

![로그인한 상태의 Comfy Desktop 사이드바 하단: 데스크탑 설정, 크레딧 잔액, 그리고 메뉴 버튼이 있는 개인 워크스페이스](/images/desktop/installation/comfy-desktop-signed-in-sidebar.png)

- **데스크탑 업데이트**: Comfy Desktop 업데이트가 있을 때 표시됩니다. 클릭한 다음 **다운로드**를 클릭하세요. **데스크탑 업데이트 준비됨**으로 표시되면 클릭한 다음 **재시작 및 업데이트**를 클릭하세요.
- **데스크탑 설정**: Comfy Desktop의 설정을 엽니다. [Comfy Desktop 설정](/ko/installation/desktop/usage/settings)을 참고하세요.
- **크레딧**: 로그인하면 표시되는 잔액입니다. [크레딧 확인하기](#크레딧-확인)를 참고하세요.
- **Comfy 로그인**: 로그인에 사용하는 카드입니다. 로그인하면 이 자리를 워크스페이스가 대신합니다. [로그인 및 Comfy Cloud 열기](/ko/installation/desktop/overview#로그인하고-comfy-cloud-열기)를 참고하세요.

공간을 확보하려면 사이드바 상단의 **사이드바 접기**를 클릭하세요. 항목들은 아이콘만 남게 되고, **Comfy 로그인** 카드는 **로그인** 아이콘이 됩니다. 페이지를 별도의 창에서 열려면 해당 항목을 마우스 오른쪽 버튼으로 클릭하고 **새 창에서 열기**를 선택하세요.

## 타이틀 바 사용하기

**타이틀 바**는 모든 Comfy Desktop 창의 상단에 있습니다.

![Comfy Desktop 타이틀 바의 오른쪽 끝: 새 소식 종 아이콘, 다운로드, 메뉴](/images/desktop/usage/comfy-desktop-title-bar.png)

오른쪽에 있는 버튼은 스크린샷에 표시된 번호 순서대로 다음과 같습니다.

- **1** **새 소식**(종 아이콘): **투어 시작**이 포함된 메뉴를 엽니다. [투어 다시 보기](#투어-다시-보기)를 참고하세요.
- **2** **다운로드**: 다운로드 트레이를 엽니다. 배지에는 진행 중인 다운로드, 실패한 다운로드, 아직 확인하지 않은 완료된 다운로드 수가 표시됩니다.
- **3** **메뉴**: 타이틀 바 메뉴를 엽니다.

**홈**에서 **메뉴**에는 **성능 테스트**와 **벤치마크**가 있습니다. ComfyUI를 실행하는 창에서는 **메뉴**에 다음 항목도 있습니다.

- **데스크탑 설정**: Comfy Desktop의 설정을 엽니다.
- **확대/축소 초기화(N%)**: ComfyUI를 확대하거나 축소하면 표시됩니다. 선택하면 100%로 돌아갑니다.
- **창 닫기**: 이 창을 닫습니다.
- **Desktop 종료**: Comfy Desktop을 종료합니다.

ComfyUI를 실행하는 창에는 **타이틀 바** 왼쪽에 **홈** 버튼도 있습니다. 클릭하면 **홈**으로 돌아갑니다.

최초 실행 시 설정 과정에서는 **메뉴**에 **온보딩 건너뛰기**만 있습니다.

## 워크스페이스 메뉴 사용하기

로그인하면 Comfy Cloud를 사용할 수 있고 크레딧이 표시됩니다. 로그인하려면 [로그인 및 Comfy Cloud 열기](/ko/installation/desktop/overview#로그인하고-comfy-cloud-열기)를 따르세요.

로그인하고 나면 **사이드바** 하단의 **Log in to Comfy** 카드가 워크스페이스로 바뀝니다. 이를 클릭하면 메뉴가 열립니다:

- 상단의 워크스페이스 이름을 클릭하면 다른 워크스페이스로 전환할 수 있습니다. 그러면 **Home**과 **사이드바**에 해당 워크스페이스의 빌드가 표시됩니다.
- **워크스페이스 설정**과 **플랜 및 크레딧 관리**는 브라우저에서 열립니다.
- 메뉴에는 이메일과 **로그아웃**도 표시됩니다.

## 크레딧 확인

**사이드바** 하단, 워크스페이스 위에 있는 **크레딧**에서 잔액을 확인할 수 있습니다. **크레딧** 위로 포인터를 올리면 잔액이 새로 고침됩니다.

- 크레딧을 추가하거나 플랜을 변경하려면 **크레딧**을 클릭하세요. 브라우저에서 해당 워크스페이스의 **플랜 및 크레딧 관리** 페이지가 열립니다.

## 문제 해결

**홈** 또는 **사이드바**의 일부가 로드되지 않을 때 다음 항목을 사용하세요.

<AccordionGroup>
  <Accordion title="예제 워크플로가 로드되지 않음">
    **홈**에 **예제 워크플로를 불러올 수 없습니다. 연결을 확인하고 다시 시도하세요.**라는 메시지가 표시됩니다. 인터넷 연결을 확인한 다음 **다시 시도하기**를 클릭하세요.
  </Accordion>
  <Accordion title="앱이 로드되지 않음">
    **홈**에 **앱을 불러올 수 없습니다. 연결을 확인하고 다시 시도하세요.**라는 메시지가 표시됩니다. 인터넷 연결을 확인한 다음 **다시 시도하기**를 클릭하세요.
  </Accordion>
  <Accordion title="크레딧에 잔액을 불러올 수 없음이 표시됨">
    Comfy Desktop에서 잔액을 읽을 수 없습니다. **크레딧** 위에 포인터를 올려 다시 불러오세요.
  </Accordion>
</AccordionGroup>

Comfy Desktop 관련 문제는 [GitHub](https://github.com/Comfy-Org/Comfy-Desktop/issues)에서 신고하세요. 이 문서 관련 문제는 [문서 저장소](https://github.com/Comfy-Org/docs/issues)에서 신고하세요.
