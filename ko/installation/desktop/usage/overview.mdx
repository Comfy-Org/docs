Comfy Desktop은 **ComfyUI**의 공식 데스크톱 애플리케이션입니다. ComfyUI 설치, 최신 상태 유지, 여러 독립적인 설정을 나란히 실행할 수 있도록 모든 것을 관리해 줍니다.

둘의 관계를 이해하자면: **Comfy Desktop**은 **ComfyUI** 인스턴스를 관리하고 실행하는 앱입니다. ComfyUI를 따로 설치할 필요 없이 Comfy Desktop이 각 인스턴스의 설치, Python 환경, 종속성을 자동으로 처리합니다.

### 주요 기능

- **[멀티 인스턴스 관리](/ko/installation/desktop/usage/instance-management):** 여러 개의 ComfyUI 인스턴스를 나란히 실행하며 각 인스턴스마다 서로 다른 버전, 커스텀 노드, 설정을 적용할 수 있습니다
- **[스냅샷](/ko/installation/desktop/usage/manage#스냅샷-탭):** 인스턴스의 전체 상태(ComfyUI 버전, 커스텀 노드, Python 패키지)를 저장하고 복원하여 쉽게 롤백하거나 환경을 재현할 수 있습니다
- **[공유 저장소](/ko/installation/desktop/usage/settings#저장소):** 모델은 기본적으로 모든 인스턴스가 공유하므로 디스크 공간을 절약합니다. 외부 모델 폴더도 추가할 수 있습니다
- **자동 업데이트:** 제목 표시줄의 **Desktop Update** 컨트롤이 Comfy Desktop을 업데이트합니다. 관리 패널의 [업데이트 탭](/ko/installation/desktop/usage/manage#업데이트-탭)으로 선택한 ComfyUI 인스턴스를 업데이트합니다.
- **클라우드 통합:** Chooser 보기에서 직접 Comfy Cloud 인스턴스를 실행하거나 연결할 수 있습니다
- **[기존 설치 추적](/ko/installation/desktop/usage/instance-management#기존-설치-추적하기):** 기존에 포터블 방식이나 git 클론으로 설치한 ComfyUI를 Comfy Desktop에 추가하여 통합 관리할 수 있습니다

이 가이드에서는 이러한 기능들을 사용하는 방법을 다룹니다.

Comfy Desktop 창은 몇 가지 주요 영역으로 나뉩니다. 아래 이미지는 대시보드의 주요 부분을 표시합니다:

![Comfy Desktop 대시보드](/images/desktop/interface/interface_desktop_dashboard.png)

### 앱 메뉴

![제목 표시줄에서 연 앱 메뉴(Performance Tests, Benchmarks, Desktop Settings 포함)](/images/desktop/usage/comfy_desktop_app_menu.png)

좌측 상단의 햄버거 메뉴(☰)를 클릭하면 앱 메뉴가 열리며, 앱 수준의 모든 작업이 이곳에 있습니다:

- **Open Dashboard**: Dashboard를 새 창에서 엽니다. 실행 중인 인스턴스는 계속 실행됩니다.
- **New Instance** 및 **Add Existing Instance**: 새 인스턴스를 만들거나 이미 있는 ComfyUI 설치를 등록합니다.
- **Load Snapshot**: 다른 사용자가 공유한 스냅샷 파일로 인스턴스를 만듭니다.
- **Log in**: Comfy 계정에 로그인합니다. 이 항목은 로그아웃 상태일 때만 표시됩니다.
- **Performance Tests**: 인스턴스에 대해 시간을 측정하는 워크플로를 실행합니다. 자세한 내용은 [성능 테스트 및 벤치마크](/ko/installation/desktop/usage/performance-tests)를 참고하세요.
- **Benchmarks**: 저장된 성능 테스트 결과를 하드웨어, 워크플로, 인스턴스별로 비교합니다.
- **Desktop Settings**: 자동 업데이트, 프록시/미러, 공유 저장소, 데이터 위치에 대한 전역 설정입니다.
- **Send Feedback**: 피드백 패널을 엽니다.
- **Close Window** 및 **Quit Desktop**: 현재 창을 닫거나 앱을 종료합니다. 인스턴스 창을 닫으면 해당 창이 실행하는 ComfyUI 인스턴스가 중지되고, 마지막 창을 닫으면 Comfy Desktop이 종료됩니다.

상황에 따라 두 항목만 추가로 표시됩니다: ComfyUI 뷰가 확대 또는 축소된 경우 **Reset Zoom (N%)**, 최초 실행 설정 중에는 **Skip Onboarding**입니다. 최초 실행 설정이 화면에 있는 동안에는 **Skip Onboarding**이 메뉴의 유일한 항목입니다.

macOS에서는 앱, 편집, 윈도우 메뉴를 포함한 시스템 메뉴 막대가 유지됩니다. Windows와 Linux 빌드에는 시스템 메뉴 막대가 없습니다.

### 인스턴스 전환기

중앙의 알약 버튼에는 해당 창에서 실행 중인 ComfyUI 인스턴스 이름이 표시됩니다. Dashboard에서는 대신 앱 이름이 표시됩니다. 버튼을 클릭하면 **인스턴스 선택기**가 열립니다. 해당 인스턴스에 새 ComfyUI 버전이 있으면 알약 버튼에 **Update** 칩도 표시됩니다. 칩을 클릭하면 해당 인스턴스의 Update 탭에서 선택기가 열리고 업데이트를 확인할 수 있는 상태가 됩니다.

![인스턴스 선택기: (1) 소스 필터, (2) 인스턴스 목록, (3) 선택한 인스턴스의 설정, (4) New Instance, (5) 선택한 인스턴스의 기본 동작](/images/desktop/usage/instance_picker_overview.png)

선택기는 세 영역으로 구성됩니다.

- **상단의 검색과 필터**. 검색 상자는 인스턴스 이름과 일치하는 항목을 찾습니다. 필터 칩은 소스별로 목록을 좁힙니다. **All**은 항상 표시되고, **Local**, **Cloud**, **Remote**는 해당 종류의 인스턴스가 하나 이상 있을 때 나타납니다.
- **왼쪽의 인스턴스 목록**은 마지막 실행 순으로 정렬되며 최근 항목이 먼저 옵니다. 한 번도 실행하지 않은 인스턴스는 맨 뒤에 옵니다. 각 행에는 종류 아이콘, 이름, 마지막 실행 시점이 표시되며, 이 창에서 실행 중인 인스턴스에는 **Current**가 붙습니다. 아이콘의 점이 상태를 알려줍니다. 녹색은 실행 중, 주황색은 업데이트 있음, 회전 표시는 업데이트나 스냅샷 복원 같은 백그라운드 작업이 진행 중이라는 뜻입니다. 하단의 **New Instance**를 누르면 [New Instance 마법사](/ko/installation/desktop/usage/instance-management)가 열립니다.
- **오른쪽에는 선택한 인스턴스의 설정**이 [Manage 패널](/ko/installation/desktop/usage/manage)과 같은 탭으로 표시됩니다. 행을 선택해도 아무것도 실행되지 않습니다. 해당 인스턴스의 설정이 패널에 표시될 뿐이므로, 현재 창을 떠나지 않고 다른 인스턴스의 시작 인수, 스토리지, 스냅샷을 변경할 수 있습니다.

패널 하단의 기본 버튼은 선택한 인스턴스에 적용되며, 버튼 이름이 어떤 동작인지 알려줍니다.

- **Start**: 선택한 로컬 인스턴스를 이 창에서 엽니다. Dashboard에서 보이는 레이블이며, 이때 인스턴스가 해당 창을 대신합니다.
- **Restart**: 이 창에서 실행 중인 인스턴스를 다시 시작합니다.
- **Switch**: 이 창의 인스턴스를 선택한 인스턴스로 교체합니다. 선택한 인스턴스가 이미 다른 창에서 실행 중이면 **Switch**는 그 창을 앞으로 가져옵니다.
- **Open in new window**: 현재 인스턴스를 계속 실행한 채 선택한 인스턴스를 별도 창에서 엽니다. 기본 버튼 옆의 캐럿에, 두 번째 창을 열 수 있는 선택인 경우 표시됩니다.
- **Open Cloud**(원격 연결의 경우 **Open Remote**): 선택한 Cloud 또는 Remote 인스턴스를 엽니다. Dashboard에서는 해당 창을 대신하고, 인스턴스 창에서 열면 로컬 인스턴스를 계속 실행한 채 새 창에서 엽니다.

실행 중인 로컬 인스턴스를 다시 시작하거나 그 창에서 다른 인스턴스로 전환하면 해당 인스턴스가 중지되므로 먼저 확인을 받습니다. **Restart**는 워크플로의 저장하지 않은 변경 사항이 사라진다고 알려 줍니다. 인스턴스 창에서 전환할 때는 세 가지 선택지가 나옵니다. **Switch**는 현재 인스턴스를 중지하고 선택한 인스턴스를 이 창에 로드하며, **Open in new window**는 현재 인스턴스를 계속 실행하고, 취소하면 아무것도 바뀌지 않습니다. Cloud 또는 Remote 인스턴스를 표시하는 창에서는 로컬 프로세스가 중지되지 않으므로 확인이 나오지 않습니다. 이미 다른 창에서 실행 중인 인스턴스를 앞으로 가져오는 경우에도 중지되는 것이 없으므로 확인이 나오지 않습니다.

선택기에서 시작한 작업(업데이트, 복제, 스냅샷 복원 등)이 실행되는 동안 패널에 진행률이 표시됩니다. 중단할 수 있는 작업에는 **Cancel**도 표시됩니다. 실패하면 **Try Again**으로 다시 시도하고 **Dismiss**로 오류를 닫습니다.

인스턴스 창에서는 선택기의 필터 칩 옆에 **Open Dashboard**도 표시됩니다. Dashboard를 새 창에서 열고 실행 중인 인스턴스는 계속 실행됩니다.

### 우측 버튼 그룹

![제목 표시줄 오른쪽 버튼: 새 소식(종), 피드백, 다운로드](/images/desktop/usage/title_bar_trailing.png)

제목 표시줄 오른쪽의 컨트롤은 다음 기능에 빠르게 접근할 수 있게 해줍니다:

- **Desktop Update**：Comfy Desktop의 새 버전이 있을 때 여기에 알약 모양 버튼이 나타납니다. 클릭하면 업데이트를 다운로드하고 적용합니다.
- **Reset Zoom**：ComfyUI 뷰의 확대/축소가 100%가 아닐 때 현재 배율을 보여주는 알약 버튼이 표시됩니다. 클릭하면 100%로 돌아갑니다.
- **What's new**：공지 패널을 엽니다. 공지에서는 ComfyUI의 새 기능과 Comfy 제품 출시를 짧은 영상, 주요 내용, 자세히 보기 링크와 함께 소개합니다. 확인하지 않은 공지가 있으면 종 모양 아이콘에 점이 표시되고, 패널을 열면 점이 사라집니다.
- **Feedback**：Comfy Desktop 팀에 피드백을 보냅니다.
- **Downloads**：다운로드 트레이를 엽니다. 배지는 진행 중인 다운로드 수를 표시하고 실패했거나 확인하지 않은 다운로드를 강조합니다. 트레이에서는 실패한 다운로드를 재시도하거나 진행 중인 다운로드를 취소할 수 있습니다. **View All Downloads**로 전체 목록을 열면 일시정지와 재개도 할 수 있습니다.

### 검색

검색 상자를 이용하면 설치된 인스턴스를 이름으로 필터링하여, 여러 개의 설정이 있을 때 특정 설정을 쉽게 찾을 수 있습니다.

### 선택기 (인스턴스 목록)

대시보드의 주요 영역인 **선택기**는 모든 ComfyUI 인스턴스를 카드 형태로 표시합니다. **아무 인스턴스 카드를 클릭하면 해당 인스턴스를 실행하거나 전환할 수 있습니다.**

여기서 할 수 있는 작업:

- **＋ 새 인스턴스**：독립적인 새 ComfyUI 인스턴스를 만듭니다.
- **Comfy Cloud**：클라우드 인스턴스에 연결하거나 실행합니다. 무료 클라우드 실행이 가능한 경우 카드에 **TRY FREE** 알약이 표시될 수 있습니다.
- **계정 칩**（오른쪽 위）：Comfy 계정으로 로그인합니다. 로그인하면 칩에 아바타와 이메일이 표시되고, 그리드 위에 작업 공간 전환기가 나타납니다.
- **작업 공간 Build**：로그인하면 선택한 작업 공간에 게시된 ComfyUI Build를 새 인스턴스 흐름에서 설치할 수 있습니다. 자세한 내용은 [작업 공간과 ComfyUI Build](/ko/installation/desktop/usage/workspaces-and-builds)를 참고하세요.
- **기존 인스턴스 카드**：각 카드에는 인스턴스 이름, 상태, 유형이 표시됩니다. 마우스 오른쪽 버튼을 클릭하거나 (⋮ 아이콘을 클릭)하여 인스턴스를 관리, 업데이트, 스냅샷, 삭제할 수 있습니다.
