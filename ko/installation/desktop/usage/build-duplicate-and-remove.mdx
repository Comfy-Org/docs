이 페이지에서는 빌드 복제, 목록에서 제거, 제거 방법을 설명합니다. 빌드 설치, 추가, 연결 방법은 [빌드](/ko/installation/desktop/usage/instance-management)를 참고하세요.

## 빌드 복제

복제본은 원본을 건드리지 않고 변경할 수 있는 빌드의 복사본입니다. 팀의 워크스페이스에서 **Standalone** 빌드 또는 Developer Platform Build를 복제할 수 있습니다.

1. [빠른 작업 메뉴](/ko/installation/desktop/usage/instance-management#빌드-목록의-빠른-작업) 또는 **더 보기** 메뉴에서 **복제**를 선택합니다.
2. **빌드 복제**에서 복사본의 이름을 입력합니다.
3. **복제**를 클릭합니다.

Comfy Desktop은 원본 옆에 복사본을 만듭니다. 복사본이 준비되면 Comfy Desktop은 복사본의 빌드 페이지를 엽니다. 빌드를 복사하고 한 단계로 변경하려면 [ComfyUI 업데이트](/ko/installation/desktop/usage/build-management#comfyui-업데이트)에서 **복사 및 업데이트**를 사용하거나 [PyTorch 변경](/ko/installation/desktop/usage/build-management#pytorch-변경)에서 **PyTorch 복사 및 변경**을 사용합니다.

## 빌드 제거

빌드를 제거하는 작업은 두 가지입니다. **잊기**는 디스크의 파일을 그대로 유지합니다. **제거**는 파일을 삭제합니다.

**잊기**는 Comfy Desktop에서 빌드를 제거합니다. 폴더는 컴퓨터에 그대로 남으며, [**기존 빌드 추가**](/ko/installation/desktop/usage/instance-management#이미-보유한-comfyui-추가)로 다시 추가할 수 있습니다.

1. [빌드 페이지](/ko/installation/desktop/usage/instance-management#빌드-관리)를 연 다음 **더 보기**를 클릭합니다.
2. **잊기**를 선택한 다음 **빌드 잊기**에서 확인합니다.

원격 빌드의 경우 **잊기**는 연결을 제거합니다. 서버는 변경되지 않습니다. Comfy Desktop이 레거시 데스크톱에서 만든 **독립 실행형** 빌드에는 **잊기**가 없습니다.

**제거**는 이 컴퓨터에서 빌드를 제거합니다. 원격 빌드의 경우 Comfy Desktop에서 빌드를 제거하며 서버는 변경하지 않습니다.

<Warning>
  **제거**는 빌드와 모든 파일을 영구적으로 삭제하며 실행 취소할 수 없습니다. 다른 빌드는 영향을 받지 않습니다. 제거를 취소하더라도 Comfy Desktop이 이미 삭제한 파일은 복원할 수 없습니다.
</Warning>

1. 빌드가 실행 중이면 중지합니다.
2. [빠른 작업 메뉴](/ko/installation/desktop/usage/instance-management#빌드-목록의-빠른-작업) 또는 **더 보기** 메뉴에서 **제거**를 선택합니다.
3. 대화 상자에 표시된 폴더를 확인한 다음 **제거**를 클릭합니다.

빌드에 **제거 중**과 퍼센트가 표시됩니다. 완료되면 빌드가 **사이드바**와 **빌드** 페이지에서 사라집니다.

제거를 중지하려면:

1. 빠른 작업 메뉴에서 **취소**를 선택합니다.
2. **제거 중지**를 클릭합니다.

빌드는 빌드 목록에 그대로 남습니다. Comfy Desktop이 이미 삭제한 파일은 복원할 수 없으므로, 마무리하려면 빌드를 다시 제거해야 합니다. 제거가 실패하면 [실패한 빌드 해결](/ko/installation/desktop/usage/build-troubleshooting#빌드-실패-해결)을 참고하세요.
