Comfy Desktop은 팀이 Comfy Developer Platform에서 공유하는 ComfyUI 설정을 설치할 수 있습니다. 예를 들어 선택한 모델과 커스텀 노드로 구성된, 승인된 Build 하나를 설치할 수 있습니다. Developer Platform에서 이 설정은 워크스페이스가 번호가 매겨진 버전으로 게시하는 Developer Platform Build이며, Comfy Desktop은 그중 한 버전을 팀 빌드로 컴퓨터에 설치합니다. 워크스페이스를 선택하고, 해당 워크스페이스의 빌드를 설치하고, 팀이 더 새로운 버전을 게시하면 업데이트하며, 자신의 빌드를 Developer Platform에 업로드합니다.

Developer Platform에서 Build를 생성하고 그 버전을 게시하는 방법은 [Comfy Cloud에 커스텀 빌드 추가하기](/ko/development/deploy/cloud-custom-builds)를 참고하세요.

## 빌드를 확인할 워크스페이스 선택

각 워크스페이스에는 자체 Developer Platform 빌드가 있으며, Comfy Desktop은 한 번에 하나의 워크스페이스만 표시합니다. 팀의 빌드를 보려면 먼저 로그인하세요. [Comfy Cloud 로그인 및 열기](/ko/installation/desktop/overview#로그인하고-comfy-cloud-열기)를 따르세요.

**사이드바** 하단에서 선택된 워크스페이스가 표시되는 내용을 결정합니다:

- **홈**, **사이드바**, **빌드** 페이지 및 각 빌드 페이지에는 해당 워크스페이스의 빌드만 표시됩니다.
- **새 빌드**는 **팀 빌드** 아래에 해당 워크스페이스의 Developer Platform 빌드를 제공합니다. **개인** 워크스페이스에는 자체 빌드가 있습니다.

워크스페이스를 전환하려면 [워크스페이스 메뉴 사용](/ko/installation/desktop/usage/overview#워크스페이스-메뉴-사용하기)을 참조하세요. Comfy Desktop은 선택한 워크스페이스를 기억하고 다음에 열 때 해당 워크스페이스로 시작합니다.

<Tip>
  Comfy Desktop이 열려 있는 동안 팀에서 빌드를 게시하면 **빌드** 페이지에서 **워크스페이스 새로 고침**을 클릭하세요. 그러면 워크스페이스와 해당 Developer Platform 빌드가 다시 로드됩니다.
</Tip>

## 팀에서 빌드 설치

Developer Platform 빌드는 사용 중인 컴퓨터의 운영 체제와 GPU용 빌드가 포함된 버전이 게시되어야 Comfy Desktop에 표시됩니다. 이를 설치하면 이 컴퓨터에 팀 빌드가 추가됩니다. **Name**과 **Location**처럼 모든 빌드에 공통으로 적용되는 **New build** 대화 상자의 항목은 [새 빌드 설치](/ko/installation/desktop/usage/instance-management#새-빌드-설치)를 참조하세요.

<Steps>
  <Step title="New build 대화 상자 열기">
    **Builds** 페이지에서 **New build**를 클릭합니다.

    로그인한 상태라면 대화 상자가 워크스페이스의 빌드 목록으로 열리고 첫 번째 빌드가 선택됩니다. 워크스페이스에 설치할 빌드가 없으면 대신 **Official release**로 열립니다.
  </Step>
  <Step title="빌드와 하드웨어 확인">
    요약에는 설치될 항목이 표시됩니다.

    - **Release**: 빌드의 이름과 설명, **Release v{version}**, **By {creator}**입니다.
    - **Hardware**: 이 컴퓨터의 운영 체제와 GPU에 맞는 빌드 대상(예: CUDA 12.8이 포함된 NVIDIA)과 해당 릴리스 버전입니다.

    **Name** 상자에는 빌드의 이름이 제안됩니다.
  </Step>
  <Step title="다른 빌드 선택(선택 사항)">
    **Change**를 클릭하면 **Change setup**이 열립니다.

    - **Source**: **Your team's builds**를 선택합니다. 로그인하지 않은 상태라면 로그인할 수 있도록 브라우저가 열리고, 대화 상자에 **Continue in your browser**가 표시됩니다.
    - **Release**: 빌드를 선택합니다. 목록에는 이 컴퓨터에 설치할 수 있는 빌드만 표시됩니다. **View builds online**을 클릭하면 브라우저에서 Developer Platform의 워크스페이스 빌드가 열리고, **Refresh builds**를 클릭하면 목록을 다시 불러옵니다.
    - **Hardware**: 빌드 대상을 선택합니다. 이 컴퓨터에 권장되는 대상이 미리 선택되어 있습니다.

    Comfy Desktop이 워크스페이스로 전환하는 동안 대화 상자에는 **Waiting for workspace authorization… Complete authorization in your browser if prompted.**가 표시됩니다.

    **Save changes**를 클릭하면 요약으로 돌아갑니다.
  </Step>
  <Step title="빌드 설치">
    **Install**을 클릭합니다. 설치 진행 상황을 확인하려면 [새 빌드 설치](/ko/installation/desktop/usage/instance-management#새-빌드-설치)를 참조하세요.
  </Step>
</Steps>

설치가 완료되면 **Builds** 페이지의 빌드 타일에는 설치한 버전인 **Build v{version}**이 표시됩니다. 빌드가 목록에 없으면 [문제 해결](#문제-해결)을 참조하세요.

## 팀 빌드 업데이트

팀 빌드는 해당 Developer Platform Build의 버전 간에만 이동합니다. 팀에서 더 새로운 버전을 게시하면 빌드를 업데이트하여 가져올 수 있습니다. 빌드 페이지의 **개요** 탭에는 **빌드 버전** 섹션이 표시됩니다.

1. **사이드바**에서 팀 빌드를 클릭하여 빌드 페이지를 엽니다. 업데이트가 있으면 **개요** 탭에 점이 표시되고, 빌드 타일에는 **업데이트 가능**이 표시됩니다.
2. **개요**에서 **빌드 버전** 섹션을 확인합니다: **설치됨**, **최신 게시**, **마지막 확인**, 그리고 **업데이트 가능** 또는 **최신 상태**. 다시 확인하려면 **업데이트 확인**을 클릭합니다.
3. **v{version}(으)로 업데이트**를 클릭합니다. [빠른 작업 메뉴](/ko/installation/desktop/usage/instance-management#빌드-목록의-빠른-작업)에서 **업데이트**를 선택할 수도 있습니다.
4. **빌드 업데이트** 대화상자에서 이동할 버전을 확인한 다음 **지금 업데이트**를 클릭합니다.

업데이트는 빌드의 환경을 새 버전으로 교체하고, 워크플로와 이미 스테이징된 모델은 그대로 유지합니다. 업데이트가 실행되는 동안 진행 상태에는 **v{version}(으)로 업데이트 중**이 표시됩니다. 완료되면 **설치됨**에 새 버전이 표시됩니다.

## Developer Platform에 빌드 업로드

**빌드 업로드**는 이 컴퓨터에 있는 빌드로부터 Developer Platform 빌드를 시작하므로, 워크스페이스에서 이를 게시하고 팀에서 설치할 수 있습니다. 로그인한 상태여야 하며, 빌드가 이 컴퓨터에 설치되어 있어야 합니다. Comfy Cloud와 원격 빌드는 업로드할 수 없습니다.

1. **사이드바**에서 빌드를 마우스 오른쪽 버튼으로 클릭하거나, **빌드** 페이지의 타일 또는 **홈**의 카드를 마우스 오른쪽 버튼으로 클릭합니다.
2. **빌드 업로드**를 선택합니다. 힌트에는 **이 빌드를 Comfy Developer Platform에 업로드합니다.**라고 표시됩니다.

실행되는 동안 해당 항목에는 **생성 중…**이 표시됩니다. 그러면 Comfy Desktop이 다음을 수행합니다.

1. 빌드의 수동 스냅샷을 저장합니다. 이 스냅샷은 빌드의 **스냅샷** 탭에 나타납니다. [스냅샷 저장 및 복원](/ko/installation/desktop/usage/instance-management#스냅샷-저장-및-복원)을 참조하세요.
2. 스냅샷을 초안으로서 빌드가 속한 워크스페이스의 Developer Platform에 전송합니다. **개인** 워크스페이스에 있는 빌드는 **개인** 워크스페이스로 이동합니다.
3. 브라우저에서 초안을 엽니다. 빌드 페이지에는 **초안**과 **데스크톱 스냅샷 수신됨**이 표시됩니다.

초안은 해당 버전이 게시되고 Developer Platform에서 빌드가 완료될 때까지 **팀의 빌드** 아래에 나타나지 않습니다. 게시하려면 [빌드 게시](/ko/development/deploy/cloud-custom-builds#빌드-게시)를 참조하세요.

빌드에서 다른 작업이 실행 중이면 **빌드 업로드**가 회색으로 표시됩니다. 포인터를 그 위에 두면 **이 빌드의 현재 작업이 완료될 때까지 기다리세요.**라는 내용이 표시됩니다.

## 문제 해결

<AccordionGroup>
  <Accordion title="릴리스에 '설치할 수 있는 호환 빌드가 없습니다.'가 표시됩니다.">
    Comfy Desktop는 최신 게시 버전의 빌드가 완료되어 이 컴퓨터의 운영 체제 및 GPU용 빌드가 있는 경우에만 Developer Platform 빌드를 표시합니다. **사이드바**에서 선택된 워크스페이스가 팀에서 게시하는 워크스페이스인지 확인하세요. **온라인에서 빌드 보기**를 클릭하여 Developer Platform에서 빌드를 확인한 다음 **빌드 새로 고침**을 클릭하세요.
  </Accordion>
  <Accordion title="대화 상자에 '빌드를 불러올 수 없습니다. 재시도'가 표시됩니다">
    Comfy Desktop가 워크스페이스의 빌드를 불러오지 못했습니다. **빌드를 불러올 수 없습니다. 재시도**를 클릭하여 다시 불러오세요.
  </Accordion>
  <Accordion title="빌드를 업로드할 수 없습니다">
    **빌드를 업로드할 수 없습니다** 알림에 **Comfy Developer Platform에서 초안을 생성할 수 없습니다.**와 같은 이유가 표시됩니다. **빌드 업로드**를 다시 선택하세요.
  </Accordion>
</AccordionGroup>
