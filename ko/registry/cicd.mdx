## 소개

커스텀 노드를 변경할 때 Comfy나 다른 커스텀 노드에서 문제가 발생하는 경우가 드물지 않습니다. 모든 운영체제와 다양한 PyTorch 구성에서 테스트를 수행하는 것은 종종 현실적이지 않습니다.

### GitHub Actions를 사용한 Comfy 워크플로우 실행

[Comfy-Action](https://github.com/Comfy-Org/comfy-action)을 사용하면 GitHub Actions에서 Comfy workflow.json 파일을 실행할 수 있습니다. 모델 다운로드, 커스텀 노드 지원 및 Linux/Mac/Windows에서 실행됩니다.

### 결과

출력 파일은 [CI/CD 대시보드](https://ci.comfy.org/)에 업로드되며, 새로운 변경사항을 커밋하거나 커스텀 노드의 새 버전을 출시하기 전 마지막 단계에서 확인할 수 있습니다.

![ComfyCI](/images/comfyci.png)

### GitHub Actions로 버전 게시

[Publish Node Action](https://github.com/Comfy-Org/node-publish-action)은 `pyproject.toml`의 버전을 Registry에 게시하므로 버전만 올리면 릴리스됩니다. 먼저 **Settings** > **Secrets and variables** > **Actions**에서 `REGISTRY_ACCESS_TOKEN`이라는 이름의 리포지토리 시크릿(Registry 액세스 토큰)을 추가한 뒤 다음 워크플로우를 추가하세요.

```yaml
name: Publish to Comfy registry
on:
  workflow_dispatch:
  push:
    branches:
      - main
    paths:
      - "pyproject.toml"

jobs:
  publish-node:
    name: Publish Custom Node to registry
    runs-on: ubuntu-latest
    steps:
      - name: Check out code
        uses: actions/checkout@v4
      - name: Publish Custom Node
        uses: Comfy-Org/publish-node-action@main
        with:
          personal_access_token: ${{ secrets.REGISTRY_ACCESS_TOKEN }}
```

<Note>
게시되는 버전은 `pyproject.toml`의 `version` 필드입니다. 워크플로우를 실행하기 전에 업데이트하세요.
</Note>
