HDR 뷰어는 브라우저가 노드 미리보기 안에 표시할 수 없는 EXR 및 HDR 파일을 보여 줍니다. 이미지는 왼쪽에, 디스플레이 및 검사 컨트롤은 오른쪽에 배치된 창 전체를 채우는 대화상자로 열리므로, 다른 애플리케이션으로 보내기 전에 실수 이미지에 실제로 무엇이 들어 있는지 확인할 수 있습니다.

## HDR 뷰어 열기

실수 이미지를 기록하는 워크플로를 실행하세요. 예를 들어 [이미지 저장 (고급)](/ko/built-in-nodes/SaveImageAdvanced)에서 **format**을 `exr`로 설정한 워크플로를 실행합니다. `.exr` 또는 `.hdr` 파일의 출력 미리보기에서는 이미지 대신 태양 아이콘과 **HDR 이미지**가 표시됩니다. 미리보기를 클릭하면 HDR 뷰어에서 파일이 열립니다. 대화상자 제목은 출력 파일 이름이며, 대화상자는 최대화할 수 있습니다.

## 디스플레이 컨트롤

이 컨트롤은 파일 자체가 아니라 파일이 표시되는 방식을 변경합니다.

| 컨트롤 | 기능 |
| --- | --- |
| **노출** | 표시 밝기를 -10~+10 스톱 범위에서 0.1 단위로 조정합니다. 값을 낮추면 디스플레이 흰색보다 밝은 하이라이트를 다시 볼 수 있습니다. |
| **자동 노출** | 이미지에서 가장 밝은 픽셀이 디스플레이 흰색에 오도록 노출을 설정합니다. |
| **채널** | RGB 또는 한 번에 한 채널(R, G, B, A 또는 휘도)을 표시합니다. |
| **소스 색 영역** | sRGB 또는 Rec.2020. 파일을 열 때 EXR chromaticities 태그에서 감지됩니다. 파일에 태그가 없거나 잘못된 태그가 있으면 수동으로 전환하세요. |
| **디더** | 기본적으로 켜져 있습니다. 8비트 디스플레이에서 부드러운 그라디언트에 나타나는 밴딩을 완화합니다. |
| **클리핑 경고** | 기본적으로 꺼져 있습니다. 디스플레이 흰색보다 밝은 픽셀과 검정색보다 어두운 픽셀에 각각 다른 패턴으로 빗금을 표시하여 현재 노출 설정에서 가려지는 부분을 확인할 수 있습니다. |

## 이미지 검사

사이드바에서는 표시 설정과 관계없이 파일에 포함된 내용도 보여 줍니다.

- **픽셀 값**: 이미지 위로 마우스를 이동하면 왼쪽 위 모서리에 커서 아래의 좌표와 원시 RGBA 값이 표시됩니다.
- **히스토그램**: 선택한 채널의 분포입니다.
- **통계**: 해상도, 최솟값, 최댓값, 평균, 표준 편차와 함께 파일에 NaN 및 Inf가 포함된 경우 해당 개수도 표시합니다.
- **탐색**: 스크롤하여 확대/축소하고, 드래그하여 이동하며, **Fit**을 클릭하여 이미지를 맞춥니다.
- **이미지 다운로드**는 원본 파일을 저장합니다.
