**Job History**는 설정 **Docked job history/queue panel**(`Comfy.Queue.QPOV2`)이 켜져 있을 때 나타나는 왼쪽 사이드바 탭입니다. 프론트엔드는 사이드바 **맨 위**(`prepend`)에 등록해, 떠 있는 큐 오버레이 없이 활성 작업과 과거 실행을 볼 수 있게 합니다.

설정이 꺼지면 탭이 제거되고 떠 있는 작업 기록 오버레이(`Comfy.Queue.ToggleOverlay`)를 대신 사용합니다. 어느 쪽이든 상단 Run / 큐 컨트롤로 작업은 시작할 수 있습니다. 이 페이지는 **사이드바** Job History를 다룹니다.

## Job History 켜기

1. **Settings**를 엽니다.
2. `Comfy` → `Queue` → `Layout`에서 **Docked job history/queue panel**(`Comfy.Queue.QPOV2`)을 켭니다.
3. 왼쪽 사이드바 맨 위에 **Job History** 아이콘이 나타납니다.

실험적 설정입니다. nightly에서는 기본으로 켜져 있습니다. 다른 빌드에서 탭이 안 보이면 설정을 확인하세요.

## 패널 열기

**Job History** 아이콘을 클릭합니다. 실행 중이거나 대기 중인 작업이 있고 이 탭이 **비활성**이면 아이콘에 활성 작업 수 숫자 배지가 붙습니다. 탭을 열면 그 표시는 사라집니다.

## 탭: All, Completed, Failed

헤더 상태 탭:

- **All**: 현재 필터의 모든 작업.
- **Completed**: 완료된 실행.
- **Failed**: 목록에 실패한 작업이 하나 이상 있을 때만 표시.

탭 아래 요약 줄은 실행 중·대기 중 수(또는 활성 작업 없음)를 보여 줍니다. **Clear queue**는 대기 중(큐에 있으나 아직 실행되지 않음) 작업을 모두 취소합니다.

## 검색, 필터, 정렬

헤더 도구로 목록을 좁힙니다.

- **검색**: 텍스트로 작업 필터.
- **필터**: **All workflows** 또는 **Current workflow**.
- **정렬**: **Most recent** 또는 **Total generation time**.

## 작업 목록과 동작

상태, 실행 중 진행률, 출력이 있으면 미리보기 썸네일이 나열됩니다. 행 또는 컨텍스트 메뉴에서:

**실행 중 또는 대기 중**

- 새 탭에서 워크플로로 열기
- 작업 ID 복사
- 작업 취소

**완료**

- 에셋 검사(미리보기가 있을 때)
- 출력을 현재 워크플로에 로더 노드로 추가
- 미리보기 에셋 다운로드
- 새 탭에서 워크플로로 열기
- 워크플로 내보내기
- 작업 ID 복사

**실패**

- 새 탭에서 워크플로 열기
- 작업 ID 복사
- 오류 메시지 복사
- 오류 보고
- 기록 목록에서 작업 제거

헤더 동작 메뉴에는 **Clear history**가 있으며 확인 대화상자가 열립니다. 기록 지우기는 큐 기록 항목을 제거합니다. 저장된 에셋과의 관계는 대화상자 안내를 읽으세요.

## 에셋·오류와의 관계

완료된 실행의 출력은 에셋 시스템이 켜져 있으면 [에셋](/ko/interface/assets)에도 나타납니다. 워크플로 실패와 누락 리소스는 그래프를 고칠 때 [오른쪽 패널](/ko/interface/right-side-panel) **Errors** 탭에 나열됩니다.
