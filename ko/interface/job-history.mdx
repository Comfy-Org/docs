**Job History**는 설정 `Comfy.Queue.QPOV2`가 켜져 있을 때만 왼쪽 사이드바에 나타나는 탭입니다. 앞에 등록(`prepend`)되어 별도 큐 UI 없이 진행 중 작업과 기록을 볼 수 있습니다.

끄면 탭이 제거됩니다. 상단 Run / 큐 컨트롤은 그대로 작업을 시작합니다. 이 페이지는 사이드바 기록 화면용입니다.

## 다음에 적을 내용

- 진행 중 / 완료 / 실패 행
- 아이콘 배지 수
- 취소, 지우기, 다시 큐
- Assets(실행 출력)과의 관계
- 구 큐 버튼 UI와의 차이
