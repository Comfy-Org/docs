크레딧은 **Partner Nodes**(폐쇄형 모델 API 호출)를 실행하는 데 사용됩니다. 로컬 그래프 실행과 오픈소스 노드는 계속 완전 무료입니다. Partner Nodes나 Cloud 결제 기능을 쓸 때만 크레딧이 필요합니다.

**설정 → 사용자**에서 로그인한 뒤 **설정 → 워크스페이스 → 플랜 및 크레딧**을 엽니다. Comfy Cloud에서는 프로필 메뉴의 **Manage plan / 플랜 관리**로도 같은 패널을 열 수 있습니다.

![플랜 및 크레딧(Cloud)](/images/interface/setting/plan-credits-cloud-overview.jpg)

<Note>
ComfyUI는 로컬 사용자에게 항상 완전 오픈소스이며 무료입니다. 스크린샷의 잔액은 설명용 예시 데이터입니다.
</Note>

## 플랜 및 크레딧에 있는 것

**설정 → 워크스페이스 → 플랜 및 크레딧**을 엽니다. 로컬 설치에서는 로그인 후 사이드바 Workspace 아래에 플랜 및 크레딧이 표시됩니다(Members / Invoices 없음):

![플랜 및 크레딧(로컬)](/images/interface/setting/plan-credits-local-overview.jpg)

| 탭 | 내용 |
| --- | --- |
| **Credits(크레딧)** | 잔액, 충전, 플랜 요약(로컬은 크레딧 패널 임베드, Cloud는 워크스페이스 구독 뷰) |
| **Activity(활동)** | 크레딧 사용 내역 |
| **Invoices(인보이스)** | Cloud 전용. 워크스페이스 구독 관리 권한이 있는 사용자용 — 다음 인보이스와 Stripe 기록 |

![Activity 탭](/images/interface/setting/plan-credits-cloud-activity.jpg)

![Invoices 탭(Cloud)](/images/interface/setting/plan-credits-cloud-invoices.jpg)

## 크레딧 구매 방법

<Steps>

<Step title="ComfyUI 계정에 로그인">
**설정 → 사용자**를 열고 로그인합니다.
![로그인 인터페이스](/images/interface/setting/user.jpg)
</Step>

<Step title="플랜 및 크레딧 열기">
로그인 후 **설정 → 워크스페이스 → 플랜 및 크레딧**(또는 클라우드 프로필 → **플랜 관리**)을 엽니다.
![플랜 및 크레딧](/images/interface/setting/plan-credits-cloud-overview.jpg)
</Step>

<Step title="구매할 크레딧 수량 설정">
![구매 수량 설정](/images/interface/setting/buy.jpg)
팝업에서 구매 수량을 설정한 뒤 **구매**를 클릭합니다.
</Step>

<Step title="확인하고 결제 완료">
![구매 확인](/images/interface/setting/purchase-1.jpg)
결제 금액과 크레딧 수량을 확인한 뒤 Stripe 결제로 계속 진행하여 결제를 완료합니다. ComfyUI 계정과 같은 이메일을 사용하세요.
</Step>

<Step title="잔액 확인">
![구매 후 플랜 및 크레딧](/images/interface/setting/purchase-2.jpg)
**플랜 및 크레딧**으로 돌아가 잔액이 업데이트됐는지 확인합니다. 필요하면 새로 고침하거나 재시작하세요.
</Step>

</Steps>

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="크레딧이 마이너스가 될 수 있나요?">
    크레딧은 신용 한도로 쓰도록 설계되지 않았습니다. Partner Nodes가 실행 후에 비용을 보고하는 경우가 있어, 한 번 실행으로 일시적으로 마이너스 잔액이 될 수 있습니다. 잔액이 마이너스인 동안에는 충전으로 양수 잔액을 복구할 때까지 Partner Nodes를 실행할 수 없습니다.
  </Accordion>

  <Accordion title="미사용 크레딧을 환불받을 수 있나요?">
  현재 미사용 크레딧 환불은 지원하지 않습니다.
  </Accordion>

  <Accordion title="현재 잔액과 사용량을 어떻게 확인하나요?">
  **설정 → 워크스페이스 → 플랜 및 크레딧**을 엽니다. 잔액은 **Credits** 탭, 사용 내역은 **Activity** 탭입니다.
  </Accordion>

  <Accordion title="크레딧을 다른 사용자와 공유할 수 있나요?">
  여러 기기에서 같은 계정으로 로그인할 수는 있습니다. 다른 사용자 계정과 크레딧을 공유하는 것은 지원되지 않습니다. Cloud Team 워크스페이스에서는 멤버가 소유자가 설정한 한도 안에서 워크스페이스 잔액을 공유합니다.
  </Accordion>

  <Accordion title="노드 비용을 미리 알 수 있나요?">
  실행 전에 API / Partner Node의 가격 배지를 확인하세요. 실제 비용은 이미지 크기, 생성 수, 기타 파라미터에 따라 달라질 수 있습니다.
  </Accordion>

  <Accordion title="WeChat이나 Alipay 결제 옵션이 보이지 않는 이유는?">
  Comfy Credits로 결제하도록 선택하세요. WeChat과 Alipay는 그 통화 경로에서만 제공됩니다.
  </Accordion>

  <Accordion title="크레딧을 구매하면 Cloud 요금제가 포함되나요?">
  아니요. 크레딧 구매는 구독을 시작하지 않고 Cloud 워크플로를 사용할 수 있게 하지도 않습니다. Cloud에서 워크플로를 실행하려면 요금제가 필요합니다. 로컬 ComfyUI와 데스크톱의 파트너 노드는 요금제 없이 크레딧을 사용할 수 있습니다.
  </Accordion>

  <Accordion title="크레딧은 만료되나요?">
  예. 유형에 따라 다릅니다:
  - **월간 크레딧**: 청구 기간이 끝날 때 만료
  - **충전 크레딧**: 구매일로부터 1년 후 만료
  </Accordion>
</AccordionGroup>
