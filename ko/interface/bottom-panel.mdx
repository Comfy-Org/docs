하단 패널은 캔버스 아래에 도킹되는 워크스페이스 띠입니다. 모든 빌드에서 키보드 단축키 참고 탭을 제공하며, 셀프 호스트 및 Desktop 빌드에서는 **로그** 스트림을, Desktop 앱에서만 **터미널**을 제공합니다. Comfy Cloud는 터미널 탭을 등록하지 않지만, Shortcuts는 여전히 동작합니다.


![Shortcuts 탭이 열린 하단 패널. 필수 목록이 표시됩니다](/images/interface/bottom-panel/bottom_panel_shortcuts.png)

![자체 호스팅 설치에서 ComfyUI 프로세스의 런타임 출력을 스트리밍하는 로그 탭](/images/interface/bottom-panel/bottom_panel_logs.png)

## 패널 열기

하단 패널을 여는 방법은 여러 가지입니다.

- **Shortcuts**: 왼쪽 사이드바 하단 근처의 키보드 아이콘을 클릭합니다(`Workspace.ToggleBottomPanel.Shortcuts`, 기본 `Ctrl` + `Shift` + `K`). 이 아이콘은 단축키 패널만 전환합니다.
- **콘솔 / 터미널 패널**(비 Cloud): 왼쪽 사이드바 하단 근처의 터미널 아이콘을 클릭합니다. 그러면 **하단 패널 전환** 명령이 실행되며, 로그/터미널 탭이 로드되어 있으면 터미널 패널을 우선하고, 그렇지 않으면 Shortcuts로 대체됩니다.
- **보기** 메뉴: **하단 패널**(`Workspace.ToggleBottomPanel`).
- **로그 단축키**(비 Cloud): 기본 `Ctrl` + `` ` ``는 로그 탭(`Workspace.ToggleBottomPanelTab.logs-terminal`)을 전환합니다.

패널은 [집중 모드](/ko/interface/canvas-controls)가 켜져 있는 동안에는 숨겨집니다.

## 단축키 탭

Shortcuts는 **shortcuts** 패널에 두 개의 탭을 등록합니다:

- **필수**: 일반적인 편집 및 실행 대기열 단축키.
- **보기 컨트롤**: 탐색 및 보기 관련 단축키.

이 패널들은 설정 → 키 바인딩에서 사용자 정의할 수 있는 것과 동일한 명령/키 바인딩 데이터를 반영합니다. 편집 가능한 전체 목록은 [단축키](/ko/interface/shortcuts)를 참고하세요.

## 로그(셀프 호스트 및 Desktop)

비 Cloud 빌드에서는 **로그** 탭이 ComfyUI 프로세스의 런타임 로그 출력을 스트리밍합니다. 커스텀 노드, 서버 오류 또는 백엔드 메시지를 디버깅할 때 외부 터미널로 전환하지 않고 사용합니다.

기본 단축키: `Ctrl` + `` ` ``.

## 터미널(Desktop 전용)

**Desktop** 앱에서는 **터미널**(명령 터미널) 탭이 로그 옆에 등록됩니다. Desktop 사용자에게 앱 내 셸을 제공합니다. 순수 브라우저 셀프 호스트 세션이나 Comfy Cloud에는 등록되지 않습니다.

![Desktop의 터미널 탭. 로그 옆에 앱 내 셸이 표시됩니다](/images/interface/bottom-panel/bottom_panel_terminal.png)

클라우드 빌드는 로그와 터미널 등록을 모두 완전히 건너뛰고 Shortcuts만 남깁니다.
