왼쪽 사이드바의 **Models** 항목은 Model Library를 엽니다. ComfyUI가 시작되면 `ComfyUI/models` 트리(및 추가로 구성한 모델 경로)에서 감지된 모델 폴더와 파일을 나열합니다. 이름으로 검색하고, 폴더 유형별로 탐색하며, 메타데이터를 미리 보고, 모델을 캔버스로 드래그해 맞는 로더 노드를 삽입할 수 있습니다.

버전별 가용성:

- **셀프 호스트 / Desktop**: 사이드바에 로컬 모델 폴더 트리가 표시됩니다. Desktop에서는 진행 중인 다운로드가 패널 상단에 나타나고, 사이드바 아이콘에 다운로드 수 배지가 붙을 수 있습니다.
- **Comfy Cloud**: 에셋 시스템을 사용할 수 있고 **Use the asset browser for the model library**가 켜져 있으면(Cloud 기본값) **Models**를 클릭할 때 사이드바 트리 대신 모델용 에셋 브라우저가 열립니다. 자체 가중치 업로드·가져오기는 [모델 가져오기](/ko/cloud/import-models)를 참고하세요.

미디어 파일(이미지, 비디오, 오디오, 3D)은 여기에 없습니다. [에셋](/ko/interface/assets)에 있습니다.

## Model Library 열기

왼쪽 사이드바의 **Models** 아이콘을 클릭합니다. 패널 제목은 **Model Library**입니다.

## 폴더로 탐색

검색어가 없으면 루트 모델 폴더(서버가 반환하는 `checkpoints`, `loras`, `vae`, `controlnet`, `diffusion_models`, `upscale_models`, `text_encoders` 등)가 나열됩니다. 폴더를 펼치면 내용이 로드됩니다.

기본적으로 루트 폴더는 펼칠 때 로드됩니다. 설정에서 바꿀 수 있습니다.

- **Automatically load all model folders**(`Comfy.ModelLibrary.AutoLoadAll`): 켜면 라이브러리를 열자마자 모든 폴더를 로드합니다(큰 라이브러리에서는 느릴 수 있음). 끄면(셀프 호스트 기본값) 펼칠 때만 로드합니다. Comfy Cloud에서는 숨겨집니다.
- **What name to display in the model library tree view**(`Comfy.ModelLibrary.NameFormat`): `title`(기본)은 메타데이터 제목을, `filename`은 디렉터리와 `.safetensors`를 뺀 단순 파일명을 표시합니다.

에셋 기능 플래그가 꺼져 있으면 헤더의 새로고침 옆에 **Load all folders**가 나타납니다.

## 검색

상단 검색창은 이름 등 검색 가능 필드로 모델을 필터합니다. 검색 시 모든 폴더를 로드해 결과가 완전해지고, 결과 트리는 자동으로 펼쳐집니다. 일치 항목이 500개를 넘으면 잘림 안내가 나옵니다. 쿼리를 좁혀 나머지를 찾으세요.

## 미리보기와 새로고침

모델 리프에 마우스를 올리면 메타데이터가 있을 때 미리보기 카드가 열립니다(제목, 파일명, 아키텍처, 작성자, 미리보기 이미지, 사용 힌트, 트리거 문구, 설명 등).

ComfyUI 실행 중 모델 파일을 추가·삭제했다면 패널 헤더의 새로고침 버튼 또는 `r`(`Comfy.RefreshNodeDefinitions`)를 사용하세요. 노드 콤보 목록도 다시 로드되어 로더 위젯이 새 파일을 인식합니다.

## 캔버스로 드래그

모델 리프는 드래그할 수 있습니다. 캔버스에 놓으면 해당 폴더에 매핑된 로더 노드가 만들어집니다(예: `checkpoints` → `CheckpointLoaderSimple`, `loras` → `LoraLoader`, `vae` → `VAELoader`, `diffusion_models` → `UNETLoader`, `text_encoders` → `CLIPLoader` 및 프론트엔드에 등록된 기타 매핑). 해당 위젯에 모델 파일명이 채워집니다.

등록된 로더 매핑이 없는 폴더 유형은 노드가 만들어지지 않을 수 있습니다. 워크플로가 기대하는 누락 모델은 [오른쪽 패널](/ko/interface/right-side-panel) **Errors** 탭에 나타나며, 가능하면 다운로드·가져오기 동작이 제공됩니다.

## 관련 설정

| 설정 | 위치 | 역할 |
| --- | --- | --- |
| Automatically load all model folders | `Comfy` → Model Library | 열 때 전부 로드 / 펼칠 때 로드 |
| Name format | `Comfy` → Model Library | 트리에 `title` 또는 `filename` |
| Use the asset browser for the model library | 실험적 / Cloud 지향 | 에셋 사용 시 사이드바 트리 대신 에셋 브라우저 |
