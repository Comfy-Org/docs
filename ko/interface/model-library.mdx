왼쪽 사이드바 **Models**가 Model Library를 엽니다. 시작 후 `ComfyUI/models`(및 추가 경로)에서 감지된 모델이 나열됩니다.

이름 검색, 폴더 유형(checkpoints, LoRA, VAE 등) 탐색, 캔버스로 드래그해 해당 로더 노드를 넣을 수 있습니다.

실행 중 새 파일을 받으면 `r`(또는 메뉴에서 노드 정의 새로고침)로 반영합니다.
