ComfyUI에는 기본 단축키 세트가 포함되어 있으며 모든 명령의 키를 다시 지정할 수 있습니다. **설정(톱니바퀴 아이콘)** > **키 바인딩**을 열어 확인하고 변경하세요.

![ComfyUI 단축키 설정](/images/interface/setting/keybinding.jpg)

## 단축키 찾기 및 편집

패널에는 각 명령과 현재 단축키가 나열됩니다. 상단 검색창으로 목록을 좁힐 수 있고, **명령** 열 머리글을 클릭하면 알파벳순으로 정렬됩니다. **소스** 열에는 해당 명령을 제공하는 확장 기능이나 사용자 정의 노드 팩 이름이 표시되며, ComfyUI 자체 명령은 비어 있습니다.

행의 편집 아이콘을 선택하면 새 키 조합을 기록할 수 있습니다. 행 메뉴에서는 해당 명령을 기본값으로 되돌리거나 단축키를 제거할 수 있습니다. 한 명령에 단축키가 여러 개 있으면 행이 펼쳐지고 바인딩마다 편집 및 삭제 버튼이 따로 표시됩니다. 패널 아래의 **모두 초기화**는 확인 후 모든 사용자 지정을 지웁니다.

## 키 바인딩 프리셋

변경 사항은 이름이 있는 프리셋에 속하며, 패널 상단의 프리셋 선택기로 프리셋을 전환합니다. **기본 프리셋**은 내장 단축키를 담고 있으며, 선택하면 해당 단축키가 복원되고 현재 세션에서 저장하지 않은 변경은 버려집니다. 이전에 저장한 프리셋은 그대로 남습니다.

- 저장하지 않은 변경이 있으면 프리셋 이름 뒤에 `*`가 표시됩니다. 저장된 프리셋에서는 **변경 사항 저장**을 선택하면 기록됩니다. 기본 프리셋에는 변경 사항 저장 버튼이 없으므로 그 변경은 **새 프리셋으로 저장**으로 저장합니다.
- 프리셋 선택기 옆의 ...(더보기) 버튼에는 **새 프리셋으로 저장**(기본 프리셋에 변경이 없으면 숨김), **기본값으로 재설정**, **프리셋 삭제**(기본 프리셋은 사용할 수 없음), **프리셋 가져오기**, **프리셋 내보내기**가 있습니다.
- **프리셋 가져오기**는 ComfyUI에서 내보낸 프리셋 파일을 읽으므로 단축키 세트를 다른 설치로 옮기거나 다른 사용자에게 전달할 수 있습니다. **프리셋 내보내기**는 현재 프리셋을 JSON 파일로 저장합니다.
- 저장하지 않은 변경이 있는 상태에서 프리셋을 전환하면 먼저 저장할지, 버리고 계속할지 묻습니다.

프리셋은 ComfyUI 사용자 디렉터리의 `keybindings/` 아래에 JSON 파일로 저장됩니다.
