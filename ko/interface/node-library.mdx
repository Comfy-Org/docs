왼쪽 사이드바의 **Nodes** 항목이 Node Library를 엽니다. Comfy Core, Partner Nodes, 설치한 커스텀 노드 등 이 인스턴스에서 쓸 수 있는 모든 노드를 검색할 수 있습니다.

> **Screenshot TODO:** **All nodes**에서 노드를 북마크하고 목록 상단 **Bookmarked** 섹션을 촬영(아래 Essentials / All nodes 이미지가 유효하면 재사용).

![ComfyUI 노드 라이브러리 패널. Essentials 탭에서 입력과 출력 타일 표시](/images/interface/overview/node_library_essentials.png)

**Essentials** 탭을 사용할 수 있으면 패널에는 두 개의 탭이 있습니다:

- **Essentials(에센셜)**: 대부분의 워크플로에 필요한 노드를 용도별로 모아 놓은 그리드입니다. 섹션은 입력과 출력, 생성(이미지, 비디오, 텍스트, 오디오, 3D), 제어와 가이드(이미지), 편집과 유틸리티(이미지 변환, 이미지 유틸리티, 이미지 필터와 효과, 이미지 색상, 이미지 선택과 마스킹, 비디오 변환, 비디오 합성, 비디오 선택과 마스킹, 3D 변환)입니다. 타일에 마우스를 올리면 노드를 미리 볼 수 있고, 타일을 캔버스로 끌면 워크플로에 추가됩니다. 필터 버튼으로 사용하는 미디어 유형만 표시하고, 목록 버튼으로 원하는 섹션으로 바로 이동할 수 있습니다.
- **All nodes(모든 노드)**: 전체 노드 목록입니다. Comfy Nodes, 파트너 노드, 확장 기능, 블루프린트로 필터링하고, 정렬을 기본 카테고리 순서와 A-Z 사이에서 전환할 수 있습니다.

**All nodes** 에서 노드의 북마크 아이콘을 클릭하면 목록 상단의 **Bookmarked(북마크됨)** 섹션에 추가됩니다.

![ComfyUI 노드 라이브러리 패널의 All nodes 탭. 북마크됨, Comfy 노드, 파트너 노드, 확장 그룹 표시](/images/interface/overview/node_library_all_nodes.png)

**Essentials** 탭은 ComfyUI 백엔드에서 활성화한 경우에 표시되며, Comfy Cloud와 nightly 빌드에서 활성화되어 있습니다. 자체 호스팅 안정 버전에서는 **All nodes**만 표시됩니다. 이전 패널로 돌아가려면 `Settings` --> `Comfy` --> `Node Library`에서 `New Node Library Design`을 비활성화하세요.
