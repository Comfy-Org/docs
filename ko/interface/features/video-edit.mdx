Video Edit 위젯은 ComfyUI가 **비디오 트리밍 (고급)** 과 **비디오 자르기** 노드 안에 렌더링하는 대화형 편집기입니다. 노드에 연결된 비디오를 미리 보여주고, 구간을 고르는 필름스트립을 표시하며, 프레임 위에 자르기 상자를 그립니다. 따라서 숫자를 입력하는 대신 트리밍 구간과 자르기 영역을 시각적으로 설정할 수 있습니다.

## 위젯이 표시되는 위치

위젯은 노드 자체의 일부이며 비디오 입력 아래의 노드 본문을 차지합니다.

| 노드 | 표시 이름 | 위젯 컨트롤 |
| --- | --- | --- |
| `VideoTrim` | 비디오 트리밍 (고급) | 트리밍 구간만 |
| `VideoCrop` | 비디오 자르기 | 자르기 영역만 |

노드의 `video` 입력에 아무 비디오나 연결하세요. 예를 들어 비디오 불러오기 노드에서, 또는 비디오 생성 노드의 출력에서 연결할 수 있습니다. 소스가 연결되기 전까지 위젯에는 미리보기와 편집을 위해 비디오를 선택하거나 연결하라는 안내가 표시됩니다.

두 노드 모두 노드 라이브러리의 **비디오** 카테고리에 있습니다. 둘 다 실험적인 노드이고, 편집기는 최신 노드 디자인(Nodes 2.0)으로 그려집니다. 노드에 편집기가 보이지 않으면 [Nodes 2.0](/ko/interface/nodes-2) 이 켜져 있는지 확인하세요.

## 비디오 트리밍

트리밍 컨트롤은 노드가 유지할 클립의 구간을 정합니다.

- 미리보기 아래의 필름스트립에는 클립의 썸네일이 표시됩니다. 왼쪽 핸들을 드래그해 시작 프레임을, 오른쪽 핸들을 드래그해 종료 프레임을 옮깁니다. 드래그하는 동안 툴팁에 프레임 번호가 표시됩니다.
- **시작 프레임**과 **종료 프레임**에는 정확한 프레임 번호를 입력할 수 있고 핸들과 동기화됩니다.
- 필름스트립 위 아무 곳이나 드래그하면 재생 헤드가 움직이며 미리보기를 스크러빙합니다. 트리밍 구간은 필름스트립에 강조 표시됩니다.
- 미리보기 아래의 재생 행에서는 클립 재생과 일시 정지, 슬라이더로 탐색, 현재 타임코드 표시, 전체 화면 미리보기 열기, 오디오 음소거를 할 수 있습니다.
- 아래쪽 행에는 확정된 해상도, 선택한 재생 시간과 전체 재생 시간, 프레임 레이트, 프레임 수, 소스 비디오의 파일 크기가 표시됩니다.

위젯은 구간을 시작 시간(초)과 재생 시간으로 노드의 `trim` 입력에 기록합니다. 종료 핸들을 마지막 프레임까지 드래그하면 재생 시간이 0이 되고 클립의 나머지가 그대로 유지됩니다.

## 비디오 자르기

자르기 컨트롤은 각 프레임의 직사각형 영역을 유지합니다.

- 자르기 상자는 미리보기 위에 그려집니다. 상자 안을 드래그해 영역을 옮기고, 가장자리나 모서리를 드래그해 크기를 조절합니다.
- 미리보기 아래의 비율 목록에서 비율을 고른 뒤 잠그면 크기를 조절하는 동안 그 가로세로 비율이 유지됩니다. 영역은 처음에 전체 프레임입니다.
- 미리보기 아래의 바운딩 박스 필드에는 같은 영역이 숫자로 들어 있습니다. `x` 와 `y` 는 왼쪽 위 모서리이고 `width` 와 `height` 는 픽셀 단위입니다. 너비와 높이가 0이면 전체 프레임이 유지되고, 숫자를 편집하면 미리보기에서 상자가 움직입니다.

## 로딩과 문제 해결

위젯은 미리보기와 필름스트립을 만들기 위해 소스 비디오를 읽으므로, 길거나 고해상도인 클립은 나타나기까지 잠시 걸립니다. 미리보기를 준비하는 동안에는 로딩 안내가 표시됩니다.

- 미리보기를 불러올 수 없으면 위젯에 **다시 시도** 버튼이 표시됩니다.
- 브라우저가 필름스트립 캔버스를 그릴 수 없으면 패널에 비디오 미리보기 렌더링에 실패했다는 메시지가 표시됩니다. 다시 시도하고, 계속 실패하면 숫자 필드로 값을 설정하세요.
- 미리보기는 처음부터 음소거되어 있지 않고, 음소거 버튼으로 미리보기 소리를 끌 수 있습니다. 재생 컨트롤은 위젯 안의 재생에만 영향을 주며 출력 비디오는 바뀌지 않습니다.

트리밍 구간과 자르기 영역은 일반적인 노드 입력이므로 워크플로와 함께 저장되고 워크플로가 실행될 때 사용됩니다.
