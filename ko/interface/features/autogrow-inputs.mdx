ComfyUI에는 **자동 확장 입력**(autogrow inputs, 동적 입력)을 가진 노드가 있습니다. 이런 노드는 입력 슬롯을 고정으로 보여주지 않습니다. 마지막 빈 입력을 연결하면 다음 입력이 자동으로 추가됩니다. 그래서 노드 하나로 이미지 두 장이든 스무 장이든 묶어서 처리할 수 있습니다.

## 자동 확장 입력의 동작 방식

1. **마지막 빈 입력을 연결합니다.** 이 페이지의 예시에서는 **Batch Images** 노드의 `image0`에 이미지를 연결했고, `image1`은 비어 있습니다.
2. **노드가 늘어납니다.** 마지막 빈 입력을 채우면 그 아래에 새 빈 입력이 추가됩니다. 아래 그림에서는 `image1`을 연결한 뒤 `image2`가 나타났습니다.
3. **필요한 만큼 반복합니다.** 마지막 입력을 채울 때마다 노드가 다시 늘어나며, 해당 노드가 허용하는 최대 입력 수까지 증가합니다.

![입력 두 개를 연결하고 새로 추가된 빈 입력이 강조된 Batch Images 노드](/images/interface/features/autogrow/autogrow-2.png)

알아두면 좋은 두 가지가 있습니다.

- **순서가 중요합니다.** 입력은 화면에 보이는 순서대로 노드에 전달되므로 `image0`이 `image1`보다 먼저 옵니다. 순서가 결과에 영향을 주는 경우(예: 이미지를 한꺼번에 동영상 모델로 보낼 때)에는 특히 주의하세요.
- **빈 입력은 자리 표시자입니다.** 무언가 연결해야 노드 데이터의 일부가 됩니다. 입력 0개를 허용하는 노드는 모든 슬롯이 비어 있어도 실행됩니다.

## 자동 확장 입력을 사용하는 노드

| 노드 | 늘어나는 입력 | 최대 입력 수 |
|---|---|---|
| **Batch Images** | `image` | 50 |
| **Batch Masks** | `mask` | 50 |
| **Batch Latents** | `latent` | 50 |
| **And** / **Or** | `value` | 10 |
| **Nano Banana 2** 등 참조 이미지를 받는 파트너 노드 | `image_1`, `image_2` 등 | 최대 14장 |

상한은 노드마다 다릅니다. 몇 개까지 받는지 확실하지 않다면 ComfyUI에서 입력 위에 마우스를 올려 툴팁을 확인하세요.

<Tip>
자동 확장은 ComfyUI V3 노드 스키마의 일부입니다. 커스텀 노드를 만든다면 [동적 입력](/ko/custom-nodes/v3_migration#동적-입력)의 `Autogrow` 템플릿 API를 참고하세요.
</Tip>
