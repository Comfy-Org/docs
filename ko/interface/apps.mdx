**Apps**는 왼쪽 사이드바에서 Assets, Node Library, Model Library, Workflows 다음에 등록됩니다. 그래프를 처음부터 짜지 않고 열 수 있는 패키지 워크플로 앱을 보여 줍니다.

단순 선형 UI로 실행하는 방법은 [App Mode](/ko/interface/app-mode)에 있습니다. 큐·입력·레이아웃은 그 페이지를, 이 페이지는 사이드바 Apps 목록을 다룹니다.

## 다음에 적을 내용

- 목록에 나타나는 조건(로컬 vs Cloud)
- 열기 / 설치 / 제거
- Templates·Workflows와의 관계
- 앱이 없을 때 빈 상태
