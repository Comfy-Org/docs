**Apps** 항목은 Assets, Node Library, Model Library, Workflows 다음에 왼쪽 사이드바에 등록됩니다. 파일 접미사가 `.app.json`인 저장된 워크플로, 즉 패키지된 워크플로 앱을 나열합니다. 탭 제목에는 **Beta** 배지가 붙습니다.

이 사이드바 카탈로그는 [앱 모드](/ko/interface/app-mode)와 다릅니다. 앱 모드는 워크플로를 위한 선형의 단순화된 실행 UI입니다. Apps 사이드바는 패키지된 앱을 찾아 열고, 새 앱을 만들기 위해 빈 워크플로를 생성하고, 일반 워크플로를 관리하는 것과 같은 방식으로 그 `.app.json` 파일을 관리하는 곳입니다. 또한 Comfy에서 제공하는 기성 도구를 나열하는 Comfy Desktop의 **Apps** 페이지와도 다릅니다. [Comfy Desktop 앱](/ko/installation/desktop/usage/apps)을 참고하세요.

![Beta 배지와 Create 버튼, Browse 아래에 저장된 앱이 표시된 Apps 패널](/images/desktop/usage/comfy-desktop-apps-page.png)

## Apps 패널 열기

왼쪽 사이드바에서 **Apps** 아이콘을 클릭합니다. 패널은 [워크플로](/ko/interface/workflows)와 동일한 레이아웃을 재사용합니다. 검색, 선택적 **Open** 섹션(열린 워크플로가 Sidebar로 설정된 경우), **Bookmarks**, **Browse**가 있으며, 모든 목록은 `.app.json` 파일로만 필터링됩니다.

## 빈 상태와 Create

아직 저장된 앱이 없으면 Browse 영역에 짧은 메시지와 **Create app** 버튼이 있는 빈 상태가 표시됩니다. Browse 목록에 결과가 있으면 패널 헤더에도 **Create** 버튼이 나타납니다. 두 동작 모두 **New Blank Workflow**(`Comfy.NewBlankWorkflow`)를 실행하며, 앱 모드용으로 구성한 뒤 앱으로 저장할 수 있는 빈 그래프를 엽니다.

## 앱 다루기

필터링된 목록에서의 작업은 Workflows 패널과 동일합니다.

- 앱을 클릭하면 열립니다.
- 북마크, 이름 바꾸기, 삭제, 복제, 드래그는 일반 워크플로와 같은 방식으로 동작합니다.
- 컨텍스트 메뉴에서 **Duplicate**는 항상 사용할 수 있습니다. **Insert**는 앱 모드 밖에서 사용할 수 있습니다.

단순화된 선형 UI에서 앱을 실제로 실행하려면 앱을 연 뒤 앱 모드로 진입하세요. 입력과 출력 구성, 레이아웃 미리보기, 그래프 편집과 앱 스타일 보기 간 전환은 [앱 모드](/ko/interface/app-mode)를 참고하세요.

## Apps와 Workflows, Templates의 관계

| 화면 | 나열 내용 |
| --- | --- |
| [워크플로](/ko/interface/workflows) | 저장된 일반 그래프(및 열린 탭)이며 보통 `.json` |
| **Apps**(이 페이지) | `.app.json`으로 끝나는 패키지된 앱 |
| [템플릿](/ko/interface/features/template) | **Browse Templates**에서 제공하는 공식 및 커뮤니티 스타터 그래프이며, 로컬 앱 라이브러리가 아닙니다 |
