**Apps** 항목은 Assets, Node Library, Model Library, Workflows 다음에 왼쪽 사이드바에 등록됩니다. 패키지된 워크플로 앱(파일 접미사가 `.app.json`인 저장된 워크플로)을 나열합니다. 탭 제목에는 **Beta** 배지가 붙습니다.

이 사이드바 목록은 [APP 모드](/ko/interface/app-mode)와 다릅니다. APP 모드는 워크플로용 선형·단순 실행 UI입니다. Apps 사이드바는 패키지 앱을 찾고 열고, 새 앱을 위해 빈 워크플로를 만들며, 일반 워크플로와 같은 방식으로 그 `.app.json` 파일을 관리하는 곳입니다.


![앱 패널. Beta 배지와 Create 버튼, Browse 아래에 저장된 앱이 표시됩니다](/images/interface/apps/apps_panel.png)

## Apps 패널 열기

왼쪽 사이드바의 **Apps** 아이콘을 클릭합니다. 레이아웃은 [워크플로](/ko/interface/workflows)와 같습니다(검색, 선택적 **Open**, **Bookmarks**, **Browse**). 다만 각 목록은 `.app.json`만 필터합니다.

## 빈 상태와 Create

아직 앱이 없으면 Browse에 빈 상태 메시지와 **Create app** 버튼이 나옵니다. Browse에 결과가 있으면 헤더에도 **Create**가 나타납니다. 둘 다 **New Blank Workflow**(`Comfy.NewBlankWorkflow`)를 실행해 APP 모드용으로 구성한 뒤 앱으로 저장할 수 있는 빈 그래프를 엽니다.

## 앱 다루기

필터된 목록에서의 동작은 Workflows와 같습니다.

- 클릭해 열기.
- 북마크, 이름 바꾸기, 삭제, 복제, 드래그.
- 컨텍스트 메뉴에서 **Duplicate**는 항상 가능. **Insert**는 App Mode 밖에서 가능.

단순 선형 UI로 실행하려면 연 뒤 APP 모드로 들어가세요. 입출력 구성, 레이아웃 미리보기, 그래프 편집과 앱 뷰 전환은 [APP 모드](/ko/interface/app-mode)를 참고하세요.

## Workflows / Templates와의 관계

| 화면 | 나열 내용 |
| --- | --- |
| [워크플로](/ko/interface/workflows) | 일반 저장 그래프(및 열린 탭). 보통 `.json` |
| **앱**(이 페이지) | `.app.json`으로 끝나는 패키지 앱 |
| [템플릿](/ko/interface/features/template) | **Browse Templates**의 공식·커뮤니티 스타터. 로컬 앱 라이브러리 아님 |
