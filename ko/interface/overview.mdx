시각적 UI는 대부분 사용자가 [ComfyUI Server](/ko/development/comfyui-server/comms_overview)를 다루는 방식입니다. 이 페이지는 UI 지도이며, 각 영역과 구성 요소 안내는 아래 링크를 보세요.

![ComfyUI Basic Interface](/images/interface/overview/comfyui_new_interface.jpg)

[ComfyUI 프론트엔드](https://github.com/Comfy-Org/ComfyUI_frontend)는 별도 프로젝트로 유지됩니다.

## 지역화

영어, 중국어, 러시아어, 프랑스어, 일본어, 한국어를 지원합니다. **설정**을 연 뒤 `Comfy` → `Locale`에서 언어를 고릅니다.

![ComfyUI Localization Support](/images/interface/overview/locale.jpg)

## 워크스페이스 지도

![ComfyUI Workspace](/images/interface/overview/comfyui-new-interface-main.png)

| 영역 | 설명 |
| --- | --- |
| **왼쪽 사이드바** | Assets, Node Library, Model Library, Workflows, Apps, (켜진 경우) Job History |
| **캔버스** | 노드를 놓고 연결하는 그래프와 캔버스 컨트롤 |
| **오른쪽 패널** | 선택 항목의 파라미터, 노드 정보, 설정, 오류 |
| **상단 바** | 열린 워크플로, Run / 큐, 로그인, 속성 패널 토글 |
| **왼쪽 아래** | Help Center, 하단 패널, 설정 |
| **오른쪽 아래** | 캔버스 컨트롤: 팬, 미니맵, 링크, 줌, 맞춤 |

![왼쪽 사이드바 순서: 에셋, 노드, 모델, 워크플로, 앱. `Comfy.Queue.QPOV2`를 켜면 Job History가 맨 위에 표시됩니다](/images/interface/overview/sidebar_order.png)

## 구 메뉴

새 메뉴가 기본입니다. 구 메뉴를 쓰려면 설정에서 `Comfy` → `Menu` → `Use new menu`를 `disabled`로 둡니다.

<Note>
구 메뉴는 영어만 지원합니다.
</Note>
