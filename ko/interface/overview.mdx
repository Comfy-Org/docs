시각적 UI는 대부분 사용자가 [ComfyUI Server](/ko/development/comfyui-server/comms_overview)를 다루는 방식입니다. 이 페이지는 UI 지도이며, 각 영역과 구성 요소 안내는 아래 링크를 보세요.

![ComfyUI Basic Interface](/images/interface/overview/comfyui_new_interface.jpg)

[ComfyUI 프론트엔드](https://github.com/Comfy-Org/ComfyUI_frontend)는 별도 프로젝트로 유지됩니다.

## 지역화

영어, 중국어, 러시아어, 프랑스어, 일본어, 한국어를 지원합니다. **설정**을 연 뒤 `Comfy` → `Locale`에서 언어를 고릅니다.

![ComfyUI Localization Support](/images/interface/overview/locale.jpg)

## 워크스페이스 지도

![번호 1–6가 표시된 ComfyUI 워크스페이스](/images/interface/overview/comfyui-new-interface-main.png)

스크린샷의 번호는 아래 표의 영역과 일치합니다:

| # | 영역 | 설명 |
| --- | --- | --- |
| **1** | **왼쪽 사이드바** | Assets, Node Library, Model Library, Workflows, Apps, (켜진 경우) Job History |
| **2** | **캔버스** | 노드를 놓고 연결하는 그래프와 캔버스 컨트롤 |
| **3** | **오른쪽 패널** | 선택 항목의 파라미터, 노드 정보, 설정, 오류 (상단 바 속성 패널 토글로 열림) |
| **4** | **상단 바** | 열린 워크플로, Run / 큐, 로그인, 속성 패널 토글 |
| **5** | **왼쪽 아래** | Help Center, 하단 패널, 설정 |
| **6** | **오른쪽 아래** | 캔버스 컨트롤: 팬, 미니맵, 링크, 줌, 맞춤 |

### Run 바

캔버스 상단에 떠 있는 Run 바에 실행에 필요한 조작이 모여 있습니다: 배치 횟수, Run, 큐 모드, 취소, 실행 중 작업 수.

![Run 바: 1 드래그 핸들, 2 배치 횟수, 3 Run, 4 큐 모드, 5 취소, 6 실행 중 작업](/images/interface/overview/run_bar.png)

| # | 컨트롤 | 동작 |
| --- | --- | --- |
| **1** | **드래그 핸들** | 바를 캔버스 어디로든 옮깁니다. 드래그하는 동안 **Dock to top** 영역이 나타나며, 여기에 놓으면 상단에 다시 고정됩니다. |
| **2** | **배치 횟수** | 한 번 실행할 때 워크플로를 큐에 넣는 횟수입니다(기본값 `1`). 숫자를 입력하거나 위아래 화살표로 조정합니다. |
| **3** | **Run** | 워크플로를 큐에 추가합니다. `Shift`를 누른 채 클릭하면 맨 뒤가 아니라 맨 앞에 추가됩니다. |
| **4** | **큐 모드 메뉴** | 자동 큐 방식 선택: **Run**(직접 클릭할 때만), **Run (On Change)**(워크플로가 바뀔 때마다 다시 큐에 추가), **Run (Instant)**(현재 실행이 끝나면 즉시 다시 큐에 추가). |
| **5** | **취소** | 현재 실행 중인 작업을 중지합니다. 큐가 비어 있으면 비활성화됩니다. |
| **6** | **실행 중 작업** | 대기 중이거나 실행 중인 작업 수입니다. 클릭하면 큐가 열리고, 마우스 오른쪽 버튼을 누르면 큐가 비워집니다. |

Comfy Cloud 에서는 드래그 핸들과 **Run** 사이에 컨트롤이 하나 더 있습니다. 배포 전환기로 편집기가 어느 워크스페이스 배포에서 동작할지 고릅니다. 자세한 내용은 [Comfy Cloud 편집기에서 배포 실행하기](/ko/development/deploy/overview#comfy-cloud-편집기에서-배포-실행하기) 를 참고하세요.
