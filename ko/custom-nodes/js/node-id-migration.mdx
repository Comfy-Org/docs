ComfyUI 프론트엔드는 이제 내부 경계에서 로컬 노드 ID를 브랜드 지정 `NodeId` 문자열
유형으로 정규화합니다. 직렬화된 워크플로와 API 페이로드에는 여전히 숫자 ID가
포함될 수 있지만, litegraph의 노드 ID(예: `node.id`,
`LLink.origin_id`, `LLink.target_id`)는 프론트엔드에 입력된 이후
문자열로 취급해야 합니다. 링크 ID(`LLink.id`)와 경유점 ID는 계속 숫자입니다.

확장 프로그램 작성자는 노드 ID에 대한 숫자 비교를 피해야 합니다. 특히 서브그래프
경계 센티널은 브랜드 지정 문자열 ID로 노출됩니다:

- `SUBGRAPH_INPUT_ID`는 `-10`에서 직렬화됩니다
- `SUBGRAPH_OUTPUT_ID`는 `-20`에서 직렬화됩니다

문자열 `'-10'` 및 `'-20'`과 비교하거나, 레거시 값을 비교하기 전에 양쪽을
문자열로 정규화하세요.
