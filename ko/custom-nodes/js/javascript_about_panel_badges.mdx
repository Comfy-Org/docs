About Panel Badges API를 사용하면 확장 프로그램에서 ComfyUI의 정보 페이지에 맞춤형 배지를 추가할 수 있습니다. 이러한 배지는 확장 프로그램에 대한 정보를 표시하고, 문서, 소스 코드 또는 기타 리소스로 연결되는 링크를 포함할 수 있습니다.

## 기본 사용법

```javascript
app.registerExtension({
  name: "MyExtension",
  aboutPageBadges: [
    {
      label: "문서",
      url: "https://example.com/docs",
      icon: "icon-[lucide--file]"
    },
    {
      label: "GitHub",
      url: "https://github.com/username/repo",
      icon: "icon-[lucide--github]"
    }
  ]
});
```

## 배지 구성

각 배지에는 다음 속성이 모두 필요합니다:

```javascript
{
  label: string,           // 배지에 표시할 텍스트
  url: string,             // 배지를 클릭했을 때 열리는 URL
  icon: string             // 아이콘 클래스 (예: "icon-[lucide--github]")
}
```

## 아이콘 옵션

배지 아이콘은 `icon-[lucide--<icon-name>]` 형식의 [Lucide](https://lucide.dev/icons/) 아이콘 클래스를 사용합니다. 다음은 자주 사용되는 아이콘들입니다:

- 문서: `icon-[lucide--file]` 또는 `icon-[lucide--book-open]`
- GitHub: `icon-[lucide--github]`
- 외부 링크: `icon-[lucide--external-link]`
- 정보: `icon-[lucide--info]`
- 다운로드: `icon-[lucide--download]`
- 웹사이트: `icon-[lucide--globe]`

이 클래스는 프론트엔드 빌드 시 생성되므로 프론트엔드 자체에서 사용하는 Lucide 아이콘만 사용할 수 있습니다. 아이콘이 표시되지 않으면 다른 아이콘을 선택하거나, 확장에서 로드하는 스타일시트에 직접 아이콘 클래스를 정의하세요.

`pi pi-file` 같은 PrimeIcons 클래스는 당분간 계속 표시되지만 단계적으로 제거되고 있습니다. 새 코드에서는 사용하지 마세요. [PrimeVue 제거 마이그레이션](/custom-nodes/js/primevue-removal-migration)을 참조하세요.

## 예제

```javascript
app.registerExtension({
  name: "BadgeExample",
  aboutPageBadges: [
    {
      label: "웹사이트",
      url: "https://example.com",
      icon: "icon-[lucide--globe]"
    },
    {
      label: "기부하기",
      url: "https://example.com/donate",
      icon: "icon-[lucide--heart]"
    },
    {
      label: "문서",
      url: "https://example.com/docs",
      icon: "icon-[lucide--book-open]"
    }
  ]
});
```

배지는 ComfyUI 인터페이스의 오른쪽 상단 모서리에 있는 톱니바퀴 아이콘을 통해 접근할 수 있는 설정 대화상자의 정보 패널에 나타납니다.
