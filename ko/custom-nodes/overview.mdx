커스텀 노드를 사용하면 새로운 기능을 구현하고 더 넓은 커뮤니티와 공유할 수 있습니다.

커스텀 노드는 다른 Comfy 노드와 같습니다: 입력을 받아 무언가를 수행한 다음 출력을 생성합니다. 일부 커스텀 노드는 매우 복잡한 작업을 수행하지만, 많은 노드는 단 하나의 작업만 수행합니다. 다음은 이미지를 받아 반전시키는 간단한 노드의 예입니다.

![고유 이미지 노드](/images/invert_image_node.png)

커스텀 노드 예시:
- [cookiecutter-comfy-extension](https://github.com/Comfy-Org/cookiecutter-comfy-extension)
- [ComfyUI-React-Extension-Template](https://github.com/Comfy-Org/ComfyUI-React-Extension-Template)
- [ComfyUI_frontend_vue_basic](https://github.com/jtydhr88/ComfyUI_frontend_vue_basic)

개발에 Claude Code를 사용한다면, [ComfyUI Custom Node Skills](https://github.com/jtydhr88/comfyui-custom-node-skills)는 Claude에게 ComfyUI 노드 시스템에 대한 포괄적인 지식을 제공하며, V3 및 V1 API를 모두 다룹니다. Claude Code 마켓플레이스에서 설치하거나 저장소 URL을 추가하면 노드 기본, 입력, 출력, 데이터 유형, 고급 패턴, 프론트엔드 확장, 패키징을 다루는 9가지 스킬을 얻을 수 있습니다.

## 클라이언트-서버 모델

Comfy는 클라이언트-서버 모델로 작동합니다. Python으로 작성된 서버는 데이터 처리, 모델, 이미지 디퓨전 등 모든 실제 작업을 처리합니다. Javascript로 작성된 클라이언트는 사용자 인터페이스를 담당합니다.

Comfy는 API 모드로도 사용할 수 있습니다. 이 모드에서는 비-Comfy 클라이언트(다른 UI 또는 명령줄 스크립트 등)가 서버로 워크플로를 전송합니다.

커스텀 노드는 다음 네 가지 카테고리 중 하나로 분류할 수 있습니다:

### 서버 전용

대부분의 커스텀 노드는 Python 클래스를 정의하여 순수하게 서버 측에서 실행됩니다. 이 클래스는 입력 및 출력 유형을 지정하고, 입력을 처리하여 출력을 생성하기 위해 호출할 수 있는 함수를 제공합니다.

### 클라이언트 전용

일부 커스텀 노드는 클라이언트 UI를 수정하지만 핵심 기능을 추가하지는 않습니다. 이름과 달리 시스템에 새 노드를 추가하지 않을 수도 있습니다.

### 독립적인 클라이언트와 서버

커스텀 노드는 추가 서버 기능과 추가(관련) UI 기능(예: 새 데이터 유형을 처리하기 위한 새 위젯)을 제공할 수 있습니다. 대부분의 경우 클라이언트와 서버 간의 통신은 Comfy 데이터 흐름 제어로 처리할 수 있습니다.

### 연결된 클라이언트와 서버

소수의 경우 UI 기능과 서버가 서로 직접 상호 작용해야 합니다.

<Warning>클라이언트-서버 통신이 필요한 모든 노드는 API를 통한 사용과 호환되지 않습니다.</Warning>
