    Para los distintos errores de mirror, puedes consultar el contenido siguiente para intentar encontrar manualmente otros mirrors y reemplazarlos.

    Los casos siguientes se aplican principalmente a usuarios de China.

    #### Mirror de instalación de Python

    Si el mirror predeterminado no está disponible, prueba el mirror de abajo.

    ```
    https://python-standalone.org/mirror/astral-sh/python-build-standalone
    ```

    Si necesitas encontrar otras direcciones de mirror alternativas de GitHub, busca y construye una dirección de mirror que apunte a las releases del repositorio `python-build-standalone`.

    ```
    https://github.com/astral-sh/python-build-standalone/releases/download
    ```
    Construye un enlace con el siguiente patrón

    ```
    https://xxx/astral-sh/python-build-standalone/releases/download
    ```

    <info>Como la mayoría de los servicios de mirror de Github los ofrecen terceros, presta atención a la seguridad durante su uso.</info>
