## Importante: No modifiques la carpeta resource/ComfyUI

<Warning>
No agregues ni modifiques ningún contenido en la carpeta `/resource/ComfyUI`. Todo el contenido de esta carpeta se reiniciará cuando Comfy Desktop se actualice.

A diferencia de otras Versiones de ComfyUI, la Versión Desktop administra esta Carpeta automáticamente. Durante la instalación, elegiste una ubicación Personalizada para tus Modelos, Nodos Personalizados y otros archivos de Usuario: usa esa ubicación en su lugar.
</Warning>
