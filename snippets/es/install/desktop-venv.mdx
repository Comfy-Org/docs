## Entorno de Python de escritorio

La instalación de escritorio creará un entorno virtual de Python en el directorio de instalación que elijas, normalmente una carpeta oculta `.venv`.

Si necesitas gestionar dependencias para los plugins de ComfyUI, tendrás que hacerlo dentro de este entorno. Usar la línea de comandos del sistema directamente conlleva el riesgo de instalar dependencias en el entorno del sistema, así que sigue las instrucciones a continuación para activar el entorno correspondiente.

### ¿Cómo usar el entorno de Python de escritorio?

<Tabs>
  <Tab title="Escritorio (RECOMENDADO)">
    Puedes usar la terminal integrada en la aplicación de escritorio para acceder al entorno de Python.
    ![Terminal de Comfy Desktop](/images/desktop/desktop_terminal.png)
    1. Haz clic en el icono de la barra de menú para abrir el panel inferior
    2. Haz clic en `Terminal` para abrir la terminal
    3. Si quieres comprobar la ubicación de instalación de Python para el entorno correspondiente, puedes usar el siguiente comando
    <Tabs>
      <Tab title="Windows">
      ```
        python -c "import sys; print(sys.executable)"
      ```
      </Tab>
      <Tab title="macOS">
        ```
        which python
        ```
      </Tab>
    </Tabs>

    <Warning>
      A menos que entiendas el significado de tus operaciones actuales, tus acciones podrían causar problemas de dependencias en el entorno correspondiente. Usa este método con precaución.
    </Warning>
  </Tab>
  <Tab title="Terminal">
    También puedes usar tu terminal preferida para acceder al entorno de Python, pero primero tendrás que activar el entorno virtual.

    <Warning>
    Al usar otras terminales, si no estás familiarizado con las operaciones, podrías instalar dependencias accidentalmente en el entorno del sistema. Usa este método con precaución.
    </Warning>

    ![Usar el sistema para activar el entorno](/images/desktop/terminal.jpg)

    <Warning>
    En la captura de pantalla se muestra una terminal de macOS. Si usas Windows, consulta los siguientes pasos para activar el entorno virtual en tu sistema.    
    </Warning>
    <Steps>
        <Step title="Abrir la terminal">
            Abre tu terminal preferida y usa el comando `cd` para navegar a tu directorio de instalación de ComfyUI, por ejemplo:
            ```
            cd <your comfyui install directory>/ComfyUI
            ```
        </Step>
        <Step title="Activar el entorno virtual">
            Escribe el siguiente comando en la terminal para activar el entorno virtual

            <Tabs>
              <Tab title="Windows">
                ```
                .venv/Scripts/activate
                ```
              </Tab>
              <Tab title="macOS">
                ```
                source .venv/bin/activate
                ```
              </Tab>
            </Tabs>
           
            Después de la activación, deberías ver un prompt como `(ComfyUI)` en la terminal, lo que indica que has activado el entorno virtual.
        </Step>
        <Step title="Confirmar el entorno de Python actual">
            Usa `which python` para comprobar la ubicación de instalación actual de Python y confirmar que no es el entorno del sistema.

            Después de completar estos pasos, habrás activado el entorno de Python correspondiente y podrás continuar realizando operaciones de instalación de dependencias en este entorno.
        </Step>
    </Steps>
  </Tab>
</Tabs>
