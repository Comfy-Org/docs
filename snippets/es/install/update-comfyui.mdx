## Cómo actualizar Comfy Desktop

Actualmente, Comfy Desktop usa actualizaciones con detección automática. Asegúrate de que las Actualizaciones Automáticas estén habilitadas en las Configuraciones.

![Configuraciones de Comfy Desktop](/images/desktop/comfyui-desktop-update-setting.jpg)

También puedes buscar actualizaciones manualmente desde el `Menu` --> `Help` --> `Check for Updates`.

![Comfy Desktop: Buscar actualizaciones](/images/desktop/desktop_check_for_updates.jpg)
