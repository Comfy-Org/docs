<Tabs>
  <Tab title="Portable">
    **Método recomendado**: Usa el script de lote `ComfyUI_windows_portable\update\update_comfyui.bat`, que actualizará tanto el código de ComfyUI como todas las dependencias de Python.

    **Actualización manual de dependencias**:
    Si necesitas actualizar las dependencias manualmente, usa el siguiente comando:
    ```bash
    # Abre la línea de comandos en el directorio de la versión portable
    .\python_embeded\python.exe -m pip install -r ComfyUI\requirements.txt
    ```
  </Tab>
  <Tab title="Instalación manual">

    <Steps>
      <Step title="Activa el entorno de Python">
      Si usas Conda para administrar entornos de Python, activa tu entorno primero:
      ```bash
      conda activate comfyui  # o el nombre de otro entorno
      ```
      </Step>
      <Step title="Actualiza el código">
      Navega al directorio raíz de ComfyUI y actualiza el código con Git:
      ```
      cd <ComfyUI_ROOT_PATH>
      git pull
      ```
      </Step>
      <Step title="Actualiza las dependencias">
      Actualiza las dependencias de ComfyUI. Este paso es crucial, especialmente para el `comfyui-frontend-package`:
      ```
      pip install -r requirements.txt
      ```
      </Step>
    </Steps>

  </Tab>
  <Tab title="Desktop">
    - **Instancia de ComfyUI + dependencias de Python:** usa [Administrar → Actualizar](/es/installation/desktop/usage/manage#pestaña-actualizar) (**Stable** o **Latest on GitHub**). Las actualizaciones de dependencias suelen aplicarse dentro de ese flujo.
    - **La app Desktop en sí:** usa el menú de la app **Buscar actualizaciones** (es independiente del canal de actualización de ComfyUI).
    - Reinstala Desktop solo como último recurso.
  </Tab>
</Tabs>
