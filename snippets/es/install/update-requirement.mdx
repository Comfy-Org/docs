<Tabs>
  <Tab title="Portátil">
    **Método recomendado**: usa el script por lotes `ComfyUI_windows_portable\update\update_comfyui.bat`, que actualiza tanto el código de ComfyUI como todas las dependencias de Python.

    **Actualización manual de dependencias**:
    Si necesitas actualizar las dependencias a mano, usa el siguiente comando:
    ```bash
    # Abre la línea de comandos en el directorio de la versión portátil
    .\python_embeded\python.exe -m pip install -r ComfyUI\requirements.txt
    ```
  </Tab>
  <Tab title="Instalación manual">

    <Steps>
      <Step title="Activar el entorno de Python">
      Si usas Conda para gestionar entornos de Python, activa tu entorno primero:
      ```bash
      conda activate comfyui  # o el nombre de otro entorno
      ```
      </Step>
      <Step title="Actualizar el código">
      Ve al directorio raíz de ComfyUI y actualiza el código con Git:
      ```
      cd <ComfyUI_ROOT_PATH>
      git pull
      ```
      </Step>
      <Step title="Actualizar las dependencias">
      Actualiza las dependencias de ComfyUI: este paso es importante, sobre todo para `comfyui-frontend-package`:
      ```
      pip install -r requirements.txt
      ```
      </Step>
    </Steps>

  </Tab>
  <Tab title="Desktop">
    - **Instancia de ComfyUI y dependencias de Python:** usa [Gestionar → Actualizar](/es/installation/desktop/usage/manage#pestaña-actualizar) (**Stable** o **Latest on GitHub**). Las actualizaciones de dependencias se aplican normalmente como parte de ese flujo.
    - **La propia aplicación Desktop:** usa el menú de la aplicación **Check for Updates** (es independiente del canal de actualización de ComfyUI).
    - Reinstala Desktop solo como último recurso.
  </Tab>
</Tabs>
