## Agregar rutas de modelos externos

Si tienes modelos almacenados en otras ubicaciones de tu computadora fuera del directorio de instalación de ComfyUI, agrégalos en Comfy Desktop en lugar de editar archivos de configuración a mano:

- **Todas las instancias:** [Configuraciones de Escritorio → Almacenamiento](/es/installation/desktop/usage/settings#almacenamiento) → **Modelos compartidos** → **+ Agregar directorio compartido**
- **Solo una instancia:** [Administrar → Almacenamiento](/es/installation/desktop/usage/manage#pestaña-almacenamiento) → **Directorios de modelos**

También puedes colocar un `extra_model_paths.yaml` en la carpeta ComfyUI de esa instancia (`<install>/ComfyUI/extra_model_paths.yaml`). ComfyUI carga este archivo al iniciar.

El Comfy Desktop clásico usaba un archivo diferente en los datos de la aplicación (`extra_models_config.yaml` dentro de la antigua carpeta de soporte de la aplicación `ComfyUI`). Prefiere la interfaz de Almacenamiento en el Comfy Desktop actual.

Para instrucciones detalladas, consulta la [documentación de Modelos](/es/basic-concepts/models)
