Hay muchas razones por las que podrías tener problemas al instalar ComfyUI. Puede que haya fallado una conexión de red al instalar pytorch (15 GB), o que no tengas git instalado. La página de mantenimiento se abre automáticamente cuando detecta un problema y te ofrece una forma de resolverlo.

Puedes usarla para resolver la mayoría de los problemas:

- Crear un entorno virtual de Python
- Reinstalar las dependencias principales que falten en tu entorno virtual de Python administrado por Desktop
- Instalar git, VC redis
- Elegir una nueva ubicación de instalación

La página de mantenimiento predeterminada muestra el contenido actual del error

![Página de mantenimiento de ComfyUI](/images/desktop/maintenance-1.jpg)

Al hacer clic en `All` puedes ver todo el contenido sobre el que se puede operar en este momento
