[Instala Miniconda](https://docs.anaconda.com/free/miniconda/index.html#latest-miniconda-installer-links). Esto te ayuda a instalar las versiones correctas de Python y de las demás bibliotecas que necesita ComfyUI.

Crea un entorno con Conda.

```
conda create -n comfyenv
conda activate comfyenv
```
