Las GPU Intel Arc (Arc serie A, Arc serie B y procesadores Core Ultra con Arc Graphics) son compatibles a través del backend XPU nativo de PyTorch. Las GPU Intel usan XPU, no CUDA.

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/xpu
```

Asegúrate de que tu [controlador de GPU Intel](https://www.intel.com/content/www/us/en/developer/articles/tool/pytorch-prerequisites-for-intel-gpu.html) esté instalado y actualizado. No instales los wheels de CUDA. Si ComfyUI sigue sin detectar la GPU, consulta [solución de problemas de GPU Intel](/es/troubleshooting/overview#intel-gpu-issues).
