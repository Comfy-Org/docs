## Requisitos previos para usar los Nodos asociados

Para usar los Nodos asociados, se deben cumplir los siguientes requisitos:


### 1. Requisitos de versión de ComfyUI

Actualiza tu ComfyUI a la última versión, ya que es posible que agreguemos más compatibilidad con API en el futuro y los nodos correspondientes se actualicen, así que mantén tu ComfyUI actualizado.

<Tip>
Ten en cuenta la diferencia entre las versiones nocturna y de lanzamiento. Recomendamos usar la versión `nightly` (que es la confirmación de código más reciente), ya que es posible que la versión de lanzamiento no se actualice de manera oportuna.
Esto se refiere a la versión de desarrollo y a la versión estable, y como todavía estamos iterando rápidamente, es posible que este documento no se actualice con prontitud, así que presta atención a las diferencias entre versiones.
</Tip>

### 2. Requisitos de cuenta y créditos

Debes haber iniciado sesión en tu ComfyUI con una [cuenta de Comfy](/es/interface/user) y tener un saldo de [créditos](/es/interface/credits) mayor que 0.

Inicia sesión mediante `Settings` -> `User`:

![ComfyUI User Interface](/images/interface/setting/user.jpg)

Ve a `Settings` -> `Credits` para comprar créditos
![Credits Interface](/images/interface/setting/purchase-1.jpg)

Consulta la documentación correspondiente sobre la cuenta y los créditos para asegurar este requisito:
- [Cuenta de Comfy](/es/interface/user): busca la sección `User` en el menú de configuraciones para iniciar sesión.
- [Créditos](/es/interface/credits): después de iniciar sesión, la interfaz de configuraciones mostrará un menú de créditos donde puedes comprar créditos. Usamos un sistema de prepago, así que no habrá cargos inesperados.


### 3. Requisitos del entorno de red

El acceso a la API requiere que tus solicitudes actuales se realicen en un entorno de red seguro. Los requisitos actuales para el acceso a la API son los siguientes:

 - La red local solo permite el acceso desde `127.0.0.1` o `localhost`, y puedes usar directamente la función de inicio de sesión.
- Si accedes desde una red de área local o un sitio web que no esté en la lista de permitidos, inicia sesión con una Clave API. Consulta [Iniciar sesión con una Clave API](/es/account/login#iniciar-sesión-con-una-clave-api).
- Deberías poder acceder normalmente a nuestro servicio de API (en algunas regiones, es posible que necesites usar un servicio de proxy).
- El acceso debe realizarse en un entorno `https` para garantizar la seguridad de las solicitudes.

<Note>
Acceder en un contexto no seguro conlleva riesgos importantes, lo que puede provocar las siguientes consecuencias:
1. La autenticación puede ser robada, lo que ocasiona la filtración de la información de tu cuenta.
2. Tu cuenta puede ser utilizada de forma maliciosa, lo que resulta en pérdidas financieras.

Incluso si en el futuro abrimos esta restricción, recomendamos encarecidamente no acceder a los servicios de API mediante solicitudes de red no seguras debido a los altos riesgos que implica.
</Note>


### 4. Usar los nodos correspondientes

**Agregar al flujo de trabajo**: agrega el Nodo asociado a tu flujo de trabajo tal como lo harías con otros nodos.
**Ejecutar**: configura los parámetros y luego ejecuta el flujo de trabajo.
