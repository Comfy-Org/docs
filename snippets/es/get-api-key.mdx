<Steps>
  <Step title="Visita la Comfy Platform e inicia sesión">
    Visita la [página de inicio de sesión de Comfy Platform](https://platform.comfy.org/login) e inicia sesión con la cuenta correspondiente
    ![Visita la página de inicio de sesión de Platform](/images/interface/setting/user/user-login-api-key-1.jpg)
  </Step>
  <Step title="Haz clic en `+ New` en API Keys para crear una clave API">
    Haz clic en `+ New` en API Keys para crear una clave API
    ![Crear clave API](/images/interface/setting/user/user-login-api-key-2.jpg)
  </Step>
  <Step title="Ingresa el nombre de la clave API">

    ![Ingresa el nombre de la clave API](/images/interface/setting/user/user-login-api-key-3.jpg)
    1. (Requerido) Ingresa el nombre de la clave API,
    2. Haz clic en `Generate` para crearla
  </Step>
  <Step title="Guarda la clave API obtenida">
    ![Obtener clave API](/images/interface/setting/user/user-login-api-key-4.jpg)
    <Warning>
      Dado que la clave API solo es visible en el momento de su primera creación, guárdala inmediatamente después de crearla. No se podrá ver más adelante, así que consérvala en un lugar seguro.
      Ten en cuenta que no debes compartir tu clave API con otras personas. Si se filtra, puedes eliminarla y crear una nueva.
    </Warning>
  </Step>
</Steps>
