## Adding External Model Paths

If you have models stored in other locations on your computer outside the ComfyUI installation directory, add them in Comfy Desktop instead of editing config files by hand:

- **All instances:** [Desktop Settings → Storage](/installation/desktop/usage/settings#storage) → **Shared Models** → **+ Add directory**
- **One instance only:** [Manage → Storage](/installation/desktop/usage/manage#storage-tab) → **Model Directories**

You can also place an `extra_model_paths.yaml` in that instance's ComfyUI folder (`<install>/ComfyUI/extra_model_paths.yaml`). ComfyUI loads this file at startup.

Legacy Desktop used a different file in app data (`extra_models_config.yaml` under the old `ComfyUI` application-support folder). Prefer the Storage UI on current Comfy Desktop.

For detailed instructions, see [Models documentation](/basic-concepts/models)
