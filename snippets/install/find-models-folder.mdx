By default, models are stored in `<your ComfyUI installation>/ComfyUI/models/` with subfolders like `checkpoints`, `embeddings`, `vae`, `lora`, `upscale_model`, etc. ComfyUI detects models in these folders and paths configured in `extra_model_paths.yaml` at startup.

<Tabs>
  <Tab title="Comfy Desktop (Find models folder)">
  Click the capsule menu at the top of the desktop app, then open the **Storage** tab to check your model directories. The capsule only exists in the desktop app, not when ComfyUI runs in a browser. Click the folder icon next to a directory to open it in your file manager.

  ![Comfy Desktop capsule menu: Storage tab showing model directory settings](/images/concepts/models_desktop_storage_tab.png)
  </Tab>
  <Tab title="ComfyUI Portable (Find models folder)">
  For the portable version, the models folder is usually located at:

  `ComfyUI_windows_portable/ComfyUI/models/`
  </Tab>
</Tabs>
