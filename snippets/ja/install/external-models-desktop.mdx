## 外部モデルパスの追加

ComfyUI のインストールディレクトリ以外の場所にモデルを保存している場合は、設定ファイルを手動で編集するのではなく、Comfy Desktop から追加してください。

- **すべてのインスタンス:** [デスクトップ設定 → ストレージ](/ja/installation/desktop/usage/settings#storage) → **Shared Models** → **+ Add Shared Directory**
- **1 つのインスタンスのみ:** [管理 → ストレージ](/ja/installation/desktop/usage/settings#storage) → **Model Directories**

そのインスタンスの ComfyUI フォルダー（`<install>/ComfyUI/extra_model_paths.yaml`）に `extra_model_paths.yaml` を配置することもできます。ComfyUI は起動時にこのファイルを読み込みます。

レガシーの Desktop では、アプリデータ内の別のファイル（旧 `ComfyUI` Application Support フォルダー内の `extra_models_config.yaml`）を使用していました。現行の Comfy Desktop では Storage UI の使用を推奨します。

詳細な手順については、[モデルのドキュメント](/ja/basic-concepts/models)を参照してください。
