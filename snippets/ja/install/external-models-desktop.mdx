## 外部モデルパスの追加

モデルが ComfyUI のインストールディレクトリ以外にある場合は、設定ファイルを手編集せず、Comfy Desktop から追加してください。

- **すべてのインスタンス:** [Desktop Settings → Storage](/ja/installation/desktop/usage/settings#ストレージ) → **Shared Models** → **+ Add Shared Directory**
- **特定のインスタンスのみ:** [Manage → Storage](/ja/installation/desktop/usage/manage#ストレージタブ) → **Model Directories**

そのインスタンスの ComfyUI フォルダーに `extra_model_paths.yaml` を置くこともできます（`<install>/ComfyUI/extra_model_paths.yaml`）。ComfyUI は起動時にこのファイルを読み込みます。

旧 Desktop ではアプリデータの `extra_models_config.yaml`（旧 `ComfyUI` の Application Support フォルダー）を使っていました。現行の Comfy Desktop では Storage UI を使ってください。

詳細は [モデルのドキュメント](/ja/basic-concepts/models) を参照してください。
