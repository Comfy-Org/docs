すべてのモデルは `<あなたのComfyUIインストール先>/ComfyUI/models/` ディレクトリ内に保存され、`checkpoints`、`embeddings`、`vae`、`lora`、`upscale_model` などのサブディレクトリに分類されます。ComfyUIは起動時にこれらのディレクトリおよび `extra_model_paths.yaml` で設定されたパス内のモデルを検出します。

<Tabs>
  <Tab title="Comfyデスクトップ版（モデルフォルダーの探し方）">
  デスクトップアプリ上部のカプセルメニューをクリックし、**Storage** タブを開いてモデルディレクトリを確認します。カプセルメニューはデスクトップアプリにのみ存在し、ブラウザーで実行している ComfyUI にはありません。ディレクトリ横のフォルダーアイコンをクリックすると、ファイルマネージャーで開けます。

  ![Comfy Desktop カプセルメニュー: モデルディレクトリ設定を表示する Storage タブ](/images/concepts/models_desktop_storage_tab.png)
  </Tab>
  <Tab title="ComfyUIポータブル版（モデルフォルダーの探し方）">
  ポータブル版の場合、モデルフォルダーは通常次の場所にあります：

  `ComfyUI_windows_portable/ComfyUI/models/`
  </Tab>
</Tabs>
