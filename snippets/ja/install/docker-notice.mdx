<Note>
**Docker：** ComfyUI は公式の Docker イメージを提供していません。コンテナで ComfyUI を実行したい場合は、[Docker Hub](https://hub.docker.com/search?q=comfyui) にあるコミュニティがメンテナンスするイメージを利用できます。`comfyui` や `comfy-ui` などの語句で検索すると、利用可能なイメージが見つかります。

コミュニティイメージを使う際の一般的な設定手順：
1. Web インターフェースにアクセスするためにポート `8188` をマッピングする
2. ホストからのポートマッピングが機能するよう、コンテナ内の ComfyUI が `0.0.0.0` でリッスンしていることを確認する（ほとんどのコミュニティイメージではデフォルトで対応済み）
3. モデルディレクトリ用のボリュームをマウントする
4. 出力ディレクトリ用のボリュームをマウントする

例：
```bash
docker run -d \
  --name comfyui \
  --gpus all \
  -p 8188:8188 \
  -v /path/to/models:/ComfyUI/models \
  -v /path/to/output:/ComfyUI/output \
  <community-image-name>
```

GPU を使う場合は `--gpus all` が必要です（[NVIDIA Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html) が必要）。`/ComfyUI/models` などのコンテナ内パスはイメージによって異なる場合があります。正確なパスは選んだイメージのドキュメントを参照してください。

なお、**これらのイメージはいずれも ComfyUI 公式イメージではなく**、ComfyUI チームによるサポートもありません。自己責任でご利用ください。
</Note>
