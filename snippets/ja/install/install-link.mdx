  <Accordion title="Comfy デスクトップ版">
    Comfy デスクトップは **Windows**、**macOS（Apple Silicon）**、**Linux**（AppImage と `.deb`）でのスタンドアロンインストールに対応しています。
    - ソースは [GitHub](https://github.com/Comfy-Org/Comfy-Desktop) にあります
    <Tip>
    デスクトップ版のインストールは、デフォルトで ComfyUI の **安定版** リリースを追跡します。最新のコミットをすべて使いたい場合は、ポータブル版か手動の git インストールを使用するか、ビルドの更新チャンネルを **Latest on GitHub** に切り替えてください。
    </Tip>
    <Card title="Comfy デスクトップ インストールガイド" icon="link" href="/ja/installation/desktop/overview#お使いの-os-に-comfyデスクトップをインストール">
      Windows 10 以降、Apple Silicon 搭載の macOS、または Linux に対応しています。ガイドにはシステムごとのタブがあります。
    </Card>
  </Accordion>

  <Accordion title="ComfyUI ポータブル版（Windows）">
    ポータブル版は、独立した組み込みPython環境を統合したComfyUIバージョンです。ポータブル版を使用することで最新の機能を体験できます。現在は **Windows** システムのみをサポートしています。
    <Card title="ComfyUI ポータブル版（Windows）インストールガイド" icon="link" href="/ja/installation/comfyui_portable_windows">
      **NVIDIA GPU** または **CPU のみ** で動作する **Windows** 向けのComfyUIバージョンに対応しています。常に最新のコミットを使用でき、完全にポータブルです。
    </Card>
  </Accordion>
