<Tabs>
  <Tab title="ポータブル版">
    **推奨方法**：`ComfyUI_windows_portable\update\update_comfyui.bat` バッチスクリプトを使用します。このスクリプトは ComfyUI のコードとすべての Python 依存関係を更新します。

    **依存関係の手動更新**：
    依存関係を手動で更新する必要がある場合は、次のコマンドを使用してください：
    ```bash
    # ポータブル版のディレクトリでコマンドラインを開く
    .\python_embeded\python.exe -m pip install -r ComfyUI\requirements.txt
    ```
  </Tab>
  <Tab title="手動インストール">

    <Steps>
      <Step title="Python 環境の有効化">
      Conda で Python 環境を管理している場合は、まず環境を有効化してください：
      ```bash
      conda activate comfyui  # または他の環境名
      ```
      </Step>
      <Step title="コードの更新">
      ComfyUI のルートディレクトリに移動し、Git を使ってコードを更新します：
      ```
      cd <ComfyUI_ROOT_PATH>
      git pull
      ```
      </Step>
      <Step title="依存関係の更新">
      ComfyUI の依存関係を更新します。この手順は、特に `comfyui-frontend-package` にとって重要です：
      ```
      pip install -r requirements.txt
      ```
      </Step>
    </Steps>

  </Tab>
  <Tab title="デスクトップ版">
    - **ComfyUI インスタンス + Python 依存関係：** [管理 → 更新](/ja/installation/desktop/usage/manage#更新タブ)（**安定版** または **GitHub 最新版**）を使用します。依存関係の更新は通常、この流れの中で適用されます。
    - **デスクトップアプリ自体：** アプリメニューの **アップデートを確認** を使用します（ComfyUI の更新チャンネルとは別です）。
    - デスクトップ版の再インストールは最後の手段としてのみ行ってください。
  </Tab>
</Tabs>
