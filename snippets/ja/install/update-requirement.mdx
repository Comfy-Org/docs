<Tabs>
  <Tab title="ポータブル版">
    **推奨方法**：`ComfyUI_windows_portable\update\update_comfyui.bat` バッチスクリプトを使用します。このスクリプトは、ComfyUI のコードとすべての Python 依存パッケージを同時に更新します。

    **手動での依存パッケージ更新**：  
    依存パッケージを手動で更新する必要がある場合は、以下のコマンドを使用してください：
    ```bash
    # ポータブル版のディレクトリ内でコマンドラインを開く
    .\python_embeded\python.exe -m pip install -r ComfyUI\requirements.txt
    ```
  </Tab>
  <Tab title="手動インストール">
    **標準的な更新手順**：

    <Steps>
      <Step title="Python 環境の有効化">
      Conda を使用して Python 環境を管理している場合、まず対象の環境を有効化してください：
      ```bash
      conda activate comfyui  # または他の環境名
      ```
      </Step>
      <Step title="コードの更新">
      ComfyUI のルートディレクトリに移動し、Git を用いてコードを更新します：
      ```
      cd <ComfyUI_ROOT_PATH>
      git pull
      ```
      </Step>
      <Step title="依存パッケージの更新">
      ComfyUI の依存パッケージを更新します。このステップは特に `comfyui-frontend-package` の更新において非常に重要です：
      ```
      pip install -r requirements.txt
      ```
      </Step>
    </Steps>

  </Tab>
  <Tab title="デスクトップ版">
    - **ComfyUI インスタンス + Python 依存関係：** [管理 → アップデート](/ja/installation/desktop/usage/manage#更新タブ)（**安定版** または **GitHub 最新版**）を使用します。依存関係の更新は通常その流れで適用されます。
    - **デスクトップアプリ自体：** アプリメニューの **更新の確認** を使用します（ComfyUI の更新チャンネルとは別です）。
    - デスクトップ版の再インストールは最終手段としてのみ行ってください。
  </Tab>
</Tabs>
