Intel Arc GPU（Arc A シリーズ、Arc B シリーズ、Arc グラフィックス搭載 Core Ultra プロセッサ）は、PyTorch のネイティブ XPU バックエンドでサポートされています。Intel GPU では CUDA ではなく XPU を使用します。

```
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/xpu
```

Intel GPU ドライバーがインストールされ、最新の状態であることを確認してください。CUDA wheel はインストールしないでください。それでも ComfyUI が GPU を検出しない場合は、[Intel GPU のトラブルシューティング](/troubleshooting/overview#intel-gpu-issues)を参照してください。
