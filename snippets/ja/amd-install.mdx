Linux では、ROCm 7.2 版の PyTorch をインストールします:

```
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm7.2
```

または、PyTorch の Nightly バージョン（ROCm 7.2）をインストールすることもできます。

<Accordion title="Nightly をインストール">
<Warning>Nightly バージョンのインストール（リスクが高い可能性があります）</Warning>
```
pip3 install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/rocm7.2
```
</Accordion>

Windows では、AMD の[マルチアーキテクチャ PyTorch パッケージ](https://rocm.docs.amd.com/projects/ai-ecosystem/en/latest/frameworks/pytorch/install.html)を ROCm 10.0 で使用します。`device-*` エクストラは GPU のカーネルと対応する ROCm ランタイムを自動的にインストールするため、別途 HIP SDK をインストールする必要はありません。Windows 11、最新の [AMD グラフィックドライバー](https://www.amd.com/en/support/download/drivers.html)、64 ビットの Python 3.13 を使用してください。

以下のコマンドは、サポートされているすべての GPU のカーネルをインストールする `device-all` を使用します。ダウンロードサイズとディスク使用量を減らすには、`device-all` の **両方の** 出現箇所を対象 GPU のターゲットに置き換えてください:

| GPU | デバイスエクストラ |
| --- | --- |
| RX 9070 / XT、Radeon AI PRO R9700 | `device-gfx1201` |
| RX 9060 / XT | `device-gfx1200` |
| RX 7900 XT / XTX | `device-gfx1100` |
| RX 7700 XT / 7800 XT | `device-gfx1101` |
| RX 7600 / XT | `device-gfx1102` |
| Ryzen AI Max / Max+（Strix Halo） | `device-gfx1151` |

<Note>
この表は一例です。表にない GPU でもサポートされている場合があります。サポートされるアーキテクチャは RDNA 2、RDNA 3、RDNA 3.5、RDNA 4 です。サポートされるすべてのターゲットのカーネルをインストールするには `device-all` のままにしてください。その他のモデルについては、AMD の [GPU ターゲットテーブル](https://github.com/ROCm/TheRock/blob/main/RELEASES.md#gfx-target-lookup-table)と [ROCm 互換性マトリクス](https://rocm.docs.amd.com/en/docs-10.0.0/compatibility/compatibility-matrix.html)を参照してください。
</Note>

```
pip install --index-url https://stable.repo.amd.com/rocm/whl-next/ "torch[device-all]==2.13.0+rocm10.0.0" "torchvision[device-all]==0.28.0+rocm10.0.0" "torchaudio==2.11.0.2+rocm10.0.0"
```
