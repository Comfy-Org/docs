<Tip>
**すでに Legacy Desktop をお使いですか？** Comfy Desktop は既存のインストールを自動検出して移行できます。カスタムノード、ワークフロー、モデル、設定はすべて引き継がれ、Comfy Desktop が開始前にレガシー状態をバックアップします。移行では既存のデータフォルダと Python 環境をその場で再利用するため、完全なコピーが必要な場合は事前にご自身でバックアップしてください。

詳細は[レガシーからの移行](/ja/installation/desktop/usage/migrate)ガイドをご覧ください。
</Tip>
