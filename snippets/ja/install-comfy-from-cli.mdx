Python 3.10 以上のバージョンで仮想環境を作成します。

<CodeGroup>

```bash conda
conda create -n comfy-env python=3.11
conda activate comfy-env
```

```bash venv
python3 -m venv comfy-env
source comfy-env/bin/activate
```

</CodeGroup>

ComfyUI のインストール

```bash
comfy install
```

<Note>`comfy install` は選択した GPU に合った PyTorch ビルドをインストールします。NVIDIA ホイールには CUDA runtime が含まれます（GPU ドライバのみで十分で、フルの CUDA Toolkit は不要）。AMD Windows では ROCm ではなく `torch-directml` を使います。GPU ドライバは最新の状態に保ってください。</Note>
