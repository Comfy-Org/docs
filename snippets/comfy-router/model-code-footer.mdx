## Before you ship

The snippets above are the shortest working call. Four things change between a first call and production code, and all four are covered in the [Comfy Router quickstart](/api-reference/comfy-router/quickstart):

- **Fields come from the model's own schema.** Append `/openapi.json` to the model's invocation path to read the exact input schema the server validates against. It is the same document Router enforces, so it cannot drift from what is documented here.
- **Send an `Idempotency-Key` on every paid call.** Router replays the original response for 24 hours instead of dispatching (and billing) the provider a second time. Reuse the same key when retrying one logical call.
- **Set a client timeout above Router's 10 minute server deadline.** Router holds the connection for the whole generation and answers `504` / `deadline_exceeded` at its own bound. A client that gives up first loses the typed error and the request id.
- **Keep `X-Comfy-Request-Id` from every response.** It is on success and error responses alike and is the id to quote in a support request. On failure, `X-Comfy-Error-Type` names one of fifteen buckets; a `422` means your body failed the model's schema and was never billed.
