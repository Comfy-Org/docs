Linux 上安装 ROCm 7.2 版本的 PyTorch：

```
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm7.2
```

或者，您可以安装 PyTorch 的 nightly 版本（ROCm 7.2）。

<Accordion title="安装 Nightly 版本">
<Warning>安装 Nightly 版本（可能存在一定风险）</Warning>
```
pip3 install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/rocm7.2
```
</Accordion>

Windows 上请使用 AMD 的[多架构 PyTorch 软件包](https://rocm.docs.amd.com/projects/ai-ecosystem/en/latest/frameworks/pytorch/install.html)（ROCm 10.0）。`device-*` 附加项会自动安装对应 GPU 的内核和匹配的 ROCm 运行时，无需单独安装 HIP SDK。请使用 Windows 11、最新的 [AMD 显卡驱动](https://www.amd.com/en/support/download/drivers.html)和 64 位 Python 3.13。

下面的安装命令使用 `device-all` 安装所有受支持 GPU 的内核。如需减少下载体积和磁盘占用，可以选择将 **两处** `device-all` 替换为您 GPU 对应的目标：

| GPU | 设备附加项 |
| --- | --- |
| RX 9070 / XT、Radeon AI PRO R9700 | `device-gfx1201` |
| RX 9060 / XT | `device-gfx1200` |
| RX 7900 XT / XTX | `device-gfx1100` |
| RX 7700 XT / 7800 XT | `device-gfx1101` |
| RX 7600 / XT | `device-gfx1102` |
| Ryzen AI Max / Max+（Strix Halo） | `device-gfx1151` |

<Note>
此表仅列出部分示例。表中未列出的 GPU 仍可能受支持：支持的架构包括 RDNA 2、RDNA 3、RDNA 3.5 和 RDNA 4。保留 `device-all` 可安装所有受支持目标的内核。其他型号请参阅 AMD 的 [GPU 目标表](https://github.com/ROCm/TheRock/blob/main/RELEASES.md#gfx-target-lookup-table)和 [ROCm 兼容性矩阵](https://rocm.docs.amd.com/en/docs-10.0.0/compatibility/compatibility-matrix.html)。
</Note>

```
pip install --index-url https://stable.repo.amd.com/rocm/whl-next/ "torch[device-all]==2.13.0+rocm10.0.0" "torchvision[device-all]==0.28.0+rocm10.0.0" "torchaudio==2.11.0.2+rocm10.0.0"
```
