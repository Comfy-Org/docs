使用 Python 3.10 或更高版本创建虚拟环境。

<CodeGroup>

```bash conda
conda create -n comfy-env python=3.11
conda activate comfy-env
```

```bash venv
python3 -m venv comfy-env
source comfy-env/bin/activate
```

</CodeGroup>

安装 ComfyUI

```bash
comfy install
```

<Note>`comfy install` 会安装与你所选 GPU 匹配的 PyTorch 构建。NVIDIA wheel 已包含 CUDA runtime（只需 GPU 驱动，不必安装完整 CUDA Toolkit）。AMD Windows 使用 `torch-directml`，而不是 ROCm。请保持 GPU 驱动为最新版本。</Note>
