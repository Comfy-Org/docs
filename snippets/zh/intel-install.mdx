Intel Arc GPU（Arc A 系列、Arc B 系列以及配备 Arc 显卡的 Core Ultra 处理器）可通过 PyTorch 原生 XPU 后端使用。Intel GPU 使用 XPU，而不是 CUDA。

```
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/xpu
```

请确保已安装并更新 Intel GPU 驱动程序。不要安装 CUDA wheel。如果 ComfyUI 仍无法检测到 GPU，请参阅 [Intel GPU 故障排除](/zh/troubleshooting/overview#intel-gpu-问题)。
