<Tabs>
  <Tab title="便携版">
    **推荐方法**：使用 `ComfyUI_windows_portable\update\update_comfyui.bat` 这个批处理脚本，它会同时更新 ComfyUI 代码和所有 Python 依赖。

    **手动更新依赖**：
    如果你需要手动更新依赖，可以使用以下命令：
    ```bash
    # 在便携版目录下打开命令行
    .\python_embeded\python.exe -m pip install -r ComfyUI\requirements.txt
    ```
  </Tab>
  <Tab title="手动安装">

    <Steps>
      <Step title="激活 Python 环境">
      如果你使用 Conda 管理 Python 环境，请先激活你的环境：
      ```bash
      conda activate comfyui  # 或其他环境名
      ```
      </Step>
      <Step title="更新代码">
      进入 ComfyUI 根目录，并使用 Git 更新代码：
      ```
      cd <ComfyUI_ROOT_PATH>
      git pull
      ```
      </Step>
      <Step title="更新依赖">
      更新 ComfyUI 依赖，这一步非常关键，尤其是 `comfyui-frontend-package`：
      ```
      pip install -r requirements.txt
      ```
      </Step>
    </Steps>

  </Tab>
  <Tab title="桌面版">
    - **ComfyUI 实例 + Python 依赖：** 使用 [管理 → 更新](/zh/installation/desktop/usage/instance-management#更新-comfyui)（**稳定版** 或 **GitHub 最新版**）。依赖更新通常会在该流程中一并完成。
    - **桌面应用本身：** 使用应用菜单中的 **检查更新**（与 ComfyUI 更新通道相互独立）。
    - 仅在万不得已时才重装桌面版。
  </Tab>
</Tabs>
