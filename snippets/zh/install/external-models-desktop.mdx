## 添加外部模型路径

如果你的模型存储在计算机上 ComfyUI 安装目录以外的其他位置，请在 Comfy Desktop 中添加它们，而不要手动编辑配置文件：

- **所有实例：** [桌面设置 → 存储](/zh/installation/desktop/usage/settings#storage) → **共享模型** → **+ 添加共享目录**
- **仅单个实例：** [管理 → 存储](/zh/installation/desktop/usage/instance-management#选择构建使用哪些文件夹) → **模型目录**

也可以把 `extra_model_paths.yaml` 放在该实例的 ComfyUI 文件夹中（`<install>/ComfyUI/extra_model_paths.yaml`）。ComfyUI 启动时会加载这个文件。

旧版 Desktop 在应用数据中使用了另一个文件（旧 `ComfyUI` Application Support 文件夹下的 `extra_models_config.yaml`）。当前 Comfy Desktop 请优先使用存储界面。

详细说明请参见[模型文档](/zh/basic-concepts/models)
