<Note>
**Docker：** ComfyUI 不提供官方 Docker 镜像。若需在容器中运行 ComfyUI，可以使用 [Docker Hub](https://hub.docker.com/search?q=comfyui) 上社区维护的镜像。搜索 `comfyui` 或 `comfy-ui` 等关键词即可找到可用镜像。

使用社区镜像时的常见设置步骤：
1. 映射端口 `8188` 以访问网页界面
2. 确保容器内的 ComfyUI 监听 `0.0.0.0`，这样主机端的端口映射才能生效（大多数社区镜像默认已处理）
3. 为模型目录挂载卷
4. 为输出目录挂载卷

示例：
```bash
docker run -d \
  --name comfyui \
  --gpus all \
  -p 8188:8188 \
  -v /path/to/models:/ComfyUI/models \
  -v /path/to/output:/ComfyUI/output \
  <community-image-name>
```

GPU 用户需要添加 `--gpus all`（需要安装 [NVIDIA Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html)）。注意，`/ComfyUI/models` 等容器内路径可能因镜像而异，具体路径请参考所选镜像的文档。

请注意，**这些镜像均非 ComfyUI 官方镜像**，也不受 ComfyUI 团队支持，请自行评估风险后使用。
</Note>
