默认情况下，模型会存储在 `<你的 ComfyUI 安装位置>/ComfyUI/models/` 文件夹下，并按用途划分为 `checkpoints`、`embeddings`、`vae`、`lora`、`upscale_model` 等子文件夹。ComfyUI 会在启动时检测这些文件夹，以及 `extra_model_paths.yaml` 中配置的路径。

<Tabs>
  <Tab title="Comfy 桌面版（如何找到模型文件夹）">
  点击桌面应用顶部的胶囊菜单，打开 **存储（Storage）** 标签页查看模型目录。胶囊菜单仅桌面应用内存在，浏览器访问的 Web 版没有此项。点击文件夹图标可在文件管理器中打开对应目录。

  ![Comfy Desktop 胶囊菜单：显示模型目录设置的存储（Storage）标签页](/images/concepts/models_desktop_storage_tab.png)
  </Tab>
  <Tab title="ComfyUI 便携版（如何找到模型文件夹）">
  便携版的模型文件夹一般在：

  `ComfyUI_windows_portable/ComfyUI/models/`
  </Tab>
</Tabs>
