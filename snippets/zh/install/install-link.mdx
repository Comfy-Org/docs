<AccordionGroup>
  <Accordion title="Comfy 桌面版">
    Comfy Desktop 支持在 **Windows**、**macOS（Apple Silicon）** 和 **Linux**（AppImage 和 `.deb`）上进行独立安装。
    - 源码在 [GitHub](https://github.com/Comfy-Org/Comfy-Desktop)
    <Tip>
    Desktop 安装默认跟踪 ComfyUI 的 **稳定版** 发布。如果想使用每一个最新提交，请使用便携版或手动 git 安装，或把某个构建的更新通道切换为 **Latest on GitHub**。
    </Tip>
    <Card title="Comfy Desktop 安装指南" icon="link" href="/zh/installation/desktop/overview#为你的操作系统安装-comfy-桌面版">
      Windows 10 或更高版本、Apple 芯片上的 macOS，或 Linux。指南为每种系统提供了一个标签页。
    </Card>
  </Accordion>

  <Accordion title="ComfyUI 便携版（Windows）">
    便携版是集成了独立嵌入式 Python 环境的 ComfyUI 版本，使用便携版可以体验最新功能，目前仅支持 **Windows** 系统
    <Card title="ComfyUI 便携版（Windows）安装指南" icon="link" href="/zh/installation/comfyui_portable_windows">
    支持在 **Nvidia GPU** 或 **仅 CPU** 上运行的 **Windows** ComfyUI 版本，始终使用最新提交，完全便携。
    </Card>
  </Accordion>

  <Accordion title="手动安装">
    <Card title="ComfyUI 手动安装指南" icon="link" href="/zh/installation/manual_install">
    支持所有系统类型和 GPU 类型（Nvidia、AMD、Intel、Apple Silicon、Ascend NPU、Cambricon MLU）
    </Card>
  </Accordion>
</AccordionGroup>
