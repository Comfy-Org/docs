Installieren Sie die mitgelieferten Comfy-Agent-Skills in Claude Code, Cursor und jedes Tool, das AGENTS.md unterstützt, damit Ihr Coding-Agent die CLI direkt steuern kann:

```bash
comfy skills install
comfy skills list      # comfy, comfy-fragments, comfy-debug, comfy-relay, comfy-director
comfy skills status    # was wo installiert ist
```

<Note>
  Dabei handelt es sich um **mitgelieferte CLI-Skills**, die durch `comfy skills install` installiert werden. Sie sind getrennt vom [Comfy Skills](https://github.com/Comfy-Org/comfy-skills/)-Repository, das das **comfy-cloud**-Plugin für Claude Code für [Comfy Cloud MCP](/agent-tools/mcp) beherbergt.
</Note>
