<Note>
  **Zwei Oberflächen, eine CLI.** Jeder Befehl erkennt automatisch, wo er ausgeführt werden soll. Wenn Sie bei Comfy Cloud angemeldet sind, werden Befehle an die **Cloud** geleitet; andernfalls werden sie auf Ihrem **lokalen** Server ausgeführt. Sie können dies pro Aufruf mit `--where local|cloud`, der Umgebungsvariable `COMFY_WHERE` überschreiben oder mit `comfy set-default --where cloud` dauerhaft festlegen.
</Note>
