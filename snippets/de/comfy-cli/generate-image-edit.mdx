Übergeben Sie lokale Dateipfade. Die CLI lädt über Comfys Storage-Endpunkt hoch oder kodiert die Datei bei Bedarf als Base64:

```bash
comfy generate nano-banana \
    --prompt "add a top hat" \
    --image ./cat.png \
    --download edited.png

comfy generate flux-kontext \
    --prompt "add a top hat and a monocle" \
    --input_image ./photo.jpg \
    --download out.png

comfy generate ideogram-edit \
    --image cat.png --mask mask.png \
    --prompt "add sunglasses" \
    --rendering_speed TURBO \
    --download edited.png
```

Einmal hochladen und über mehrere Aufrufe hinweg wiederverwenden:

```bash
comfy generate upload ./photo.jpg     # gibt eine signierte URL aus
```
