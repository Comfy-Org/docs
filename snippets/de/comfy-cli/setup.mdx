Neu in den letzten Versionen: ein einziger interaktiver Assistent, der Routing, Authentifizierung und Agent Skills in einem Schritt übernimmt.

```bash
comfy setup
```

Er führt Sie durch die Auswahl eines Routing-Ziels (lokal oder Cloud), **die Anmeldung über Ihren Browser (OAuth)**, die Wahl eines Projektverzeichnisses und optional die Installation der Agent Skills. Dies ist der empfohlene Weg. Er öffnet die Browser-Anmeldung für Sie, ganz ohne Schlüssel zum Kopieren.

```bash
comfy setup --where cloud
```

<Note>
  **Nicht interaktiv (nur CI).** Browser-OAuth benötigt eine interaktive Sitzung. Für CI, Devcontainer und skriptgesteuerte Installationen, bei denen kein Browser verfügbar ist, übergeben Sie stattdessen einen API-Schlüssel:

  ```bash
  comfy setup --where cloud --api-key comfyui-... --non-interactive
  ```
</Note>

| Flag | Zweck |
| --- | --- |
| `--where local\|cloud` | Routing-Ziel; überspringt die Abfrage |
| `--project-dir` | Verzeichnis für Workflows, Eingänge und Ausgänge |
| `--api-key` | *(Optional)* Comfy Cloud API-Schlüssel für Headless/CI; impliziert `--where cloud` |
| `-y, --non-interactive` | Keine Abfragen. Alles über Flags steuern |
| `--skip-skills` | Agent Skills nicht installieren |
| `--skip-verify` | Überspringt die Konnektivitätsprüfung |
