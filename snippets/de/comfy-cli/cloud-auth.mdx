Führen Sie Workflows und Partner-Nodes auf Comfys gehosteten GPUs aus. Keine lokale Installation erforderlich.

```bash
comfy cloud login          # Browser-OAuth + PKCE
comfy cloud whoami         # Anmeldestatus, Authentifizierungsmethode, Basis-URL anzeigen
comfy cloud logout         # lokale Sitzung leeren
```

Nach der Anmeldung werden Befehle automatisch an die Cloud weitergeleitet. **Browser-OAuth ist der empfohlene Weg.** Keine Schlüssel zu verwalten, und die CLI übernimmt die Token-Aktualisierung für Sie. Um vor der Anmeldung auf eine benutzerdefinierte Umgebung (zum Beispiel eine PR-Vorschau) zu verweisen:

```bash
comfy cloud set-base-url https://my-preview.comfy.org
```

<Note>
  **Der API-Schlüssel ist optional.** Sie benötigen einen API-Schlüssel nur für Headless- oder CI-Nutzung, bei der eine Browser-Anmeldung nicht möglich ist. Er ist ein Fallback, nicht der Standard:

  ```bash
  export COMFY_API_KEY=comfyui-...   # oder pro Aufruf --api-key übergeben
  ```
</Note>

<Note>
  **Lebensdauer der Sitzung.** Cloud-Sitzungstoken sind kurzlebig (~1h). Die CLI aktualisiert sie bei Bedarf automatisch. Wenn ein Befehl `cloud_unauthorized` meldet, führen Sie `comfy cloud login` erneut aus.
</Note>
