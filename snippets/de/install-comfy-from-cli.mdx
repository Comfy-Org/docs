Erstellen Sie eine virtuelle Umgebung mit Python 3.10 oder neuer.

<CodeGroup>

```bash conda
conda create -n comfy-env python=3.11
conda activate comfy-env
```

```bash venv
python3 -m venv comfy-env
source comfy-env/bin/activate
```

</CodeGroup>

ComfyUI installieren

```bash
comfy install
```

`comfy install` fragt, welche GPU Sie haben, und installiert den passenden PyTorch-Build. Beantworten Sie den Prompt, oder übergeben Sie für unbeaufsichtigte Installationen ein GPU-Flag:

| Plattform | Was `comfy install` installiert | Was Sie noch benötigen |
| --- | --- | --- |
| NVIDIA | PyTorch mit CUDA-Runtime (pip-Wheel) | Aktueller GPU-Treiber (nicht das vollständige CUDA Toolkit) |
| AMD Linux | ROCm-PyTorch-Wheels | ROCm-fähiger AMD-GPU-Treiber/Stack für diese Wheels |
| AMD Windows | `torch-directml` | ComfyUI unterstützt DirectML nicht mehr. Installieren Sie stattdessen den ROCm-PyTorch-Build; er erfordert eine AMD GPU der RDNA-2-Generation oder neuer (siehe [Systemanforderungen](/de/installation/system_requirements)) |
| Apple Silicon | PyTorch-Nightly-Wheels (CPU-Index; Metal/MPS) | macOS auf Apple Silicon |
| Intel Arc | PyTorch-XPU-Wheels | Kompatible Intel Arc GPU / XPU-Stack |
| CPU | CPU-PyTorch-Wheels | Keine diskrete GPU erforderlich |
