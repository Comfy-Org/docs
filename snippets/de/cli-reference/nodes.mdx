**Nutzung**:

```console
$ comfy node [OPTIONS] COMMAND [ARGS]...
```

**Optionen**:

* `--install-completion`: Installiert die Vervollständigung für die aktuelle Shell.
* `--show-completion`: Zeigt die Vervollständigung für die aktuelle Shell an, damit Sie sie kopieren oder die Installation anpassen können.
* `--help`: Zeigt diese Meldung und beendet den Vorgang.
