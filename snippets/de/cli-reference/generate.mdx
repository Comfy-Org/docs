**Nutzung**:

```console
$ comfy generate [OPTIONS] <MODEL_OR_ACTION> [--<param> value]...
```

`<MODEL_OR_ACTION>` ist entweder:

* Ein **Modell-Alias** (z. B. `flux-pro`, `ideogram-edit`, `kling`, `dalle`): ruft dieses Partnermodell direkt auf.
* Eine **reservierte Aktion**: `list`, `schema`, `refresh`, `upload`, `resume`.

Alles, was nicht zu den reservierten Aktionen gehört, wird als Modell-Alias behandelt, und die Anfrage wird an den entsprechenden Partner-Endpunkt gesendet.

**Authentifizierung**:

Legen Sie die Umgebungsvariable `COMFY_API_KEY` fest, oder übergeben Sie bei jedem Aufruf `--api-key <KEY>`. Einen Schlüssel erhalten Sie unter [platform.comfy.org](https://platform.comfy.org).

**Flags auf Ausführungsebene** (funktionieren mit jedem Modell):

* `--download PATH`: Speichert das Ergebnisbild bzw. -video unter `PATH`.
* `--async`: Sendet den Job ab und gibt sofort eine Job-ID zurück, statt bis zum Abschluss zu pollen. Später fortsetzen mit `comfy generate resume <model> <job_id>`.
* `--json`: Gibt die rohe API-Antwort als JSON aus (nützlich für Skripte).
* `--timeout SECONDS`: Überschreibt das standardmäßige Polling-Timeout von 300s.
* `--api-key KEY`: Inline-API-Schlüssel (überschreibt `COMFY_API_KEY`).

**Beispiele**:

```bash
comfy generate flux-pro --prompt "a cat on the moon" --width 1024 --height 1024 --download cat.png
comfy generate ideogram-edit --image cat.png --mask m.png --prompt "add sunglasses" --rendering_speed TURBO
comfy generate kling --prompt "a paper boat drifting at dusk" --duration 5 --download boat.mp4
```

### `list`

Listet die verfügbaren Partnermodelle mit ihren kurzen Aliasen auf.

**Nutzung**:

```console
$ comfy generate list [OPTIONS]
```

**Optionen**:

* `--partner TEXT` / `-p TEXT`: Nach Partner filtern (z. B. `bfl`, `kling`, `ideogram`, `openai`).
* `--category TEXT` / `--style TEXT` / `-c TEXT`: Nach Kategorie filtern (z. B. `text-to-image`, `image-edit`, `inpaint`, `upscale`, `text-to-video`, `image-to-video`).
* `--query TEXT` / `-q TEXT`: Teilzeichenfolgen-Übereinstimmung mit Modell-ID/Zusammenfassung.

### `schema`

Zeigt die Parameter für ein bestimmtes Modell an, einschließlich erforderlicher bzw. optionaler Flags, Typen, Standardwerte und eines Beispielaufrufs.

**Nutzung**:

```console
$ comfy generate schema <MODEL>
```

**Beispiel**:

```bash
comfy generate schema flux-pro
comfy generate schema kling-i2v
```

### `refresh`

Aktualisiert den lokal zwischengespeicherten Modellkatalog aus der Cloud-OpenAPI-Spezifikation. Nützlich, wenn neue Partnermodelle hinzugefügt werden.

**Nutzung**:

```console
$ comfy generate refresh
```

### `upload`

Lädt eine lokale Datei hoch (oder hostet eine entfernte URL erneut) in den Speicher von Comfy und gibt die signierte URL aus. Die meisten Modelle akzeptieren lokale Dateipfade direkt. Dies ist für Fälle gedacht, in denen Sie die URL ausdrücklich benötigen (z. B. um dasselbe Asset über mehrere Aufrufe hinweg wiederzuverwenden).

**Nutzung**:

```console
$ comfy generate upload <FILE_OR_URL> [--json]
```

**Beispiel**:

```bash
comfy generate upload ./photo.jpg
comfy generate upload ./photo.jpg --json
```

<Note>
**Referenz-Assets werden nach 24 Stunden automatisch gelöscht.** Hochgeladene Dateien (ob über `comfy generate upload` oder implizit, wenn Sie einen lokalen Dateipfad an ein Modell übergeben) werden in einem von Comfy verwalteten GCS-Bucket (`api-nodes-prod`) gespeichert und sind nur über eine signierte URL erreichbar. Objekte werden durch eine Lifecycle-Regel des Buckets automatisch **1 Tag nach dem Upload** gelöscht. Wenn ein Asset über lang laufende asynchrone Jobs hinweg erhalten bleiben soll, laden Sie es vor jedem Job erneut hoch, oder hosten Sie es selbst und übergeben Sie die URL direkt.
</Note>

### `resume`

Setzt einen zuvor abgesendeten asynchronen Job fort (typischerweise einen Video-Job, der mit `--async` abgesendet wurde). Pollt, bis das Ergebnis bereit ist, und lädt es optional herunter.

**Nutzung**:

```console
$ comfy generate resume <MODEL> <JOB_ID> [--download PATH] [--json]
```

**Beispiel**:

```bash
comfy generate resume luma 7c3f9e2a --download out.mp4
```
