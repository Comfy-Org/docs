**Nutzung**:

```console
$ comfy model [OPTIONS] COMMAND [ARGS]...
```

**Optionen**:

* `--install-completion`: Installiert die Vervollständigung für die aktuelle Shell.
* `--show-completion`: Zeigt die Vervollständigung für die aktuelle Shell an, um sie zu kopieren oder die Installation anzupassen.
* `--help`: Zeigt diese Meldung an und beendet das Programm.

**Befehle**:

* `download`: Lädt ein Modell in einen angegebenen relativen...
* `list`: Zeigt eine Liste aller derzeit heruntergeladenen Modelle...
* `remove`: Entfernt ein oder mehrere heruntergeladene Modelle,...

### `download`

Lädt ein Modell in einen angegebenen relativen Pfad herunter, sofern es nicht bereits heruntergeladen wurde.

**Nutzung**:

```console
$ download [OPTIONS]
```

**Optionen**:

* `--url TEXT`: Die URL, von der das Modell heruntergeladen wird  [erforderlich]
* `--relative-path TEXT`: Der relative Pfad vom aktuellen Workspace, in dem das Modell installiert wird.  [Standard: models/checkpoints]
* `--help`: Zeigt diese Meldung an und beendet das Programm.

### `list`

Zeigt eine Liste aller derzeit heruntergeladenen Modelle in Tabellenform an.

**Nutzung**:

```console
$ list [OPTIONS]
```

**Optionen**:

* `--relative-path TEXT`: Der relative Pfad vom aktuellen Workspace, in dem die Modelle gespeichert sind.  [Standard: models/checkpoints]
* `--help`: Zeigt diese Meldung an und beendet das Programm.

### `remove`

Entfernt ein oder mehrere heruntergeladene Modelle, entweder durch direkte Angabe oder über eine interaktive Auswahl.

**Nutzung**:

```console
$ remove [OPTIONS]
```

**Optionen**:

* `--relative-path TEXT`: Der relative Pfad vom aktuellen Workspace, in dem die Modelle gespeichert sind.  [Standard: models/checkpoints]
* `--model-names TEXT`: Liste der zu löschenden Modell-Dateinamen, durch Leerzeichen getrennt
* `--help`: Zeigt diese Meldung an und beendet das Programm.
