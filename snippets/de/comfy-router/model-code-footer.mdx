## Bevor Sie live gehen

Die SDKs erstellen einen `Idempotency-Key` und verwenden ihn bei automatischen Wiederholungsversuchen erneut. Bei manuellen Wiederholungsversuchen sollten Sie den ursprünglichen Schlüssel wiederverwenden. Router kann die Verbindung bis zu 10 Minuten lang offen halten.

Wenn eine Anfrage fehlschlägt, sendet Router einen Response-Header `X-Comfy-Error-Type`, der den Grund erklärt. Ein `422` bedeutet, dass Router die Eingabe abgelehnt hat, bevor der Anbieter aufgerufen wurde, und ein `413` bedeutet, dass der Request-Body größer war, als Router akzeptiert. Laden Sie generierte Assets zeitnah herunter, da [Ergebnis-URLs ablaufen können](/development/comfy-router/reference#result-assets).

Jede oben in einer Feldbeschreibung genannte Größenbeschränkung ist die eigene Obergrenze des Anbieters für dieses Feld, zitiert aus der Spezifikation des Anbieters. Router wendet eine separate Obergrenze auf den gesamten Request-Body an, gegen die auch base64-kodierte Medien zählen: siehe [Größe des Request-Bodys](/development/comfy-router/limitations#request-bodies-are-capped).

Diese Seite dokumentiert ein Partner-Modell, das über Comfy Router aufgerufen wird. Dasselbe Paket `comfy-sdk` / `@comfyorg/sdk` enthält außerdem einen zweiten Client, mit dem Sie einen kompletten ComfyUI-Workflow-Graph auf Comfy Cloud ausführen: `Comfy(api_key=...)` / `new Comfy({ apiKey })`, mit `client.workflows`, `client.assets` und `client.jobs`. Siehe [Comfy SDKs](/de/development/api-development/sdks).
