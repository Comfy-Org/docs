Intel Arc GPUs (Arc A-Serie, Arc B-Serie und Core Ultra Prozessoren mit Arc Graphics) werden über PyTorchs natives XPU-Backend unterstützt. Intel GPUs verwenden XPU, nicht CUDA.

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/xpu
```

Stellen Sie sicher, dass Ihr [Intel GPU-Treiber](https://www.intel.com/content/www/us/en/developer/articles/tool/pytorch-prerequisites-for-intel-gpu.html) installiert und auf dem neuesten Stand ist. Installieren Sie keine CUDA-Wheels. Wenn ComfyUI die GPU weiterhin nicht erkennt, lesen Sie [Intel GPU-Fehlerbehebung](/de/troubleshooting/overview#probleme-mit-intel-gpus).
