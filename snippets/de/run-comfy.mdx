## Anwendung starten

```
cd ComfyUI
python main.py
```

Führen Sie `python main.py --help` aus, um die integrierte Hilfe aufzurufen, oder sehen Sie in der [Startup Flags-Referenz](/development/comfyui-server/startup-flags) nach, um eine vollständige Liste der Befehlszeilenoptionen zu erhalten.
