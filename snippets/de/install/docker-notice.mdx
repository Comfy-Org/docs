<Note>
**Docker:** ComfyUI stellt kein offizielles Docker-Image bereit. Wenn Sie ComfyUI in einem Container ausführen möchten, können Sie von der Community gepflegte Images von [Docker Hub](https://hub.docker.com/search?q=comfyui) verwenden. Diese Images werden **nicht offiziell von Comfy-Org gepflegt** und vom ComfyUI-Team nicht unterstützt. Die Verwendung erfolgt auf eigenes Risiko.
</Note>
