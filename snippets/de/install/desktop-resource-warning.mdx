## Wichtig: Ändern Sie den Ordner `/resource/ComfyUI` nicht

<Warning>
Fügen Sie keine Inhalte in den Ordner `/resource/ComfyUI` ein und ändern Sie dort nichts. Alle Inhalte in diesem Ordner werden zurückgesetzt, wenn Comfy Desktop aktualisiert wird.

Im Gegensatz zu anderen ComfyUI-Versionen verwaltet die Desktop-Version diesen Ordner automatisch. Während der Installation haben Sie einen benutzerdefinierten Speicherort für Ihre Modelle, Custom Nodes und andere Benutzerdateien gewählt. Bitte verwenden Sie stattdessen diesen Speicherort.
</Warning>
