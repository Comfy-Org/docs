## Externe Modellpfade hinzufügen

Wenn Sie Modelle an anderen Orten auf Ihrem Computer außerhalb des ComfyUI-Installationsverzeichnisses gespeichert haben, fügen Sie diese in Comfy Desktop hinzu, anstatt Konfigurationsdateien manuell zu bearbeiten:

- **Alle Instanzen:** [Desktop-Einstellungen → Speicher](/de/installation/desktop/usage/settings#storage) → **Gemeinsame Modelle** → **+ Gemeinsames Verzeichnis hinzufügen**
- **Nur eine Instanz:** [Verwalten → Speicher](/de/installation/desktop/usage/instance-management#choose-which-folders-the-build-uses) → **Modellverzeichnisse**

Sie können auch eine `extra_model_paths.yaml` im ComfyUI-Ordner dieser Instanz ablegen (`<install>/ComfyUI/extra_model_paths.yaml`). ComfyUI lädt diese Datei beim Start.

Ältere Desktop-Versionen verwendeten eine andere Datei in den App-Daten (`extra_models_config.yaml` im alten `ComfyUI`-Ordner für Anwendungs-Support). Verwenden Sie im aktuellen Comfy Desktop bevorzugt die Speicher-Oberfläche.

Ausführliche Anweisungen finden Sie in der [Dokumentation zu Modellen](/de/basic-concepts/models)
