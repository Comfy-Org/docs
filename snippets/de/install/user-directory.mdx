Das Benutzerverzeichnis von ComfyUI ist der Ort, an dem Ihre persönlichen Einstellungen, Workflows und Anpassungen gespeichert werden. Der Speicherort hängt von Ihrer Installationsart ab:

<Tabs>
<Tab title="Desktop - Windows">
```
C:\Users\<your username>\AppData\Roaming\ComfyUI\user
```
</Tab>
<Tab title="Desktop - macOS">
```
~/<ComfyUI installation path>/ComfyUI/user
```
</Tab>
<Tab title="Desktop - Linux">
```
~/.config/ComfyUI/user
```
</Tab>
<Tab title="Manuelle Installation">
Das Benutzerverzeichnis befindet sich in Ihrem ComfyUI-Installationsordner:
```
<ComfyUI installation path>/user
```

Wenn Sie ComfyUI beispielsweise nach `C:\ComfyUI` geklont haben, wäre Ihr Benutzerverzeichnis `C:\ComfyUI\user\default` (oder `C:\ComfyUI\user\john`, wenn Sie einen benutzerdefinierten Benutzernamen eingerichtet haben).

<Note>
ComfyUI unterstützt mehrere Benutzer pro Installation. Wenn Sie keinen benutzerdefinierten Benutzernamen konfiguriert haben, wird standardmäßig „default“ verwendet. Jeder Benutzer erhält ein eigenes Unterverzeichnis innerhalb des Ordners `user`.
</Note>
</Tab>
<Tab title="Portable">
Das Benutzerverzeichnis befindet sich in Ihrem portablen ComfyUI-Ordner:
```
<ComfyUI_windows_portable>/ComfyUI/user
```

Zum Beispiel: `ComfyUI_windows_portable/ComfyUI/user/default`

<Note>
ComfyUI unterstützt mehrere Benutzer pro Installation. Wenn Sie keinen benutzerdefinierten Benutzernamen konfiguriert haben, wird standardmäßig „default“ verwendet. Jeder Benutzer erhält ein eigenes Unterverzeichnis innerhalb des Ordners `user`.
</Note>
</Tab>
</Tabs>

Dieser Speicherort enthält Ihre Workflows, Einstellungen und weitere benutzerspezifische Dateien.
