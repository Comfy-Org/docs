<Tabs>
  <Tab title="Portable">
    **Empfohlene Methode**: Verwenden Sie das Batchskript `ComfyUI_windows_portable\update\update_comfyui.bat`, das sowohl den ComfyUI-Code als auch alle Python-Abhängigkeiten aktualisiert.

    **Manuelles Aktualisieren der Abhängigkeiten**:
    Wenn Sie die Abhängigkeiten manuell aktualisieren müssen, verwenden Sie den folgenden Befehl:
    ```bash
    # Eingabeaufforderung im Verzeichnis der portablen Version öffnen
    .\python_embeded\python.exe -m pip install -r ComfyUI\requirements.txt
    ```
  </Tab>
  <Tab title="Manuelle Installation">

    <Steps>
      <Step title="Python-Umgebung aktivieren">
      Wenn Sie Conda zum Verwalten von Python-Umgebungen verwenden, aktivieren Sie zuerst Ihre Umgebung:
      ```bash
      conda activate comfyui  # oder anderer Umgebungsname
      ```
      </Step>
      <Step title="Code aktualisieren">
      Navigieren Sie zum Stammverzeichnis von ComfyUI und aktualisieren Sie den Code mit Git:
      ```
      cd <ComfyUI_ROOT_PATH>
      git pull
      ```
      </Step>
      <Step title="Abhängigkeiten aktualisieren">
      Aktualisieren Sie die ComfyUI-Abhängigkeiten. Dieser Schritt ist entscheidend, insbesondere für das `comfyui-frontend-package`:
      ```
      pip install -r requirements.txt
      ```
      </Step>
    </Steps>

  </Tab>
  <Tab title="Desktop">
    - **ComfyUI-Instanz + Python-Abhängigkeiten:** Verwenden Sie [Verwalten → Aktualisieren](/de/installation/desktop/usage/instance-management#update-comfyui) (**Stable** oder **Latest on GitHub**). Aktualisierungen der Abhängigkeiten werden normalerweise im Rahmen dieses Ablaufs angewendet.
    - **Die Desktop-App selbst:** Verwenden Sie im App-Menü **Nach Updates suchen** (getrennt vom Aktualisierungskanal von ComfyUI).
    - Installieren Sie Desktop nur als letztes Mittel neu.
  </Tab>
</Tabs>
