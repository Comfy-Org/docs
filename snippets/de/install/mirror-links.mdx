Bei verschiedenen Mirror-Fehlern können Sie sich an den folgenden Inhalten orientieren, um manuell andere Mirrors zu finden und diese zu ersetzen.

    Die folgenden Fälle betreffen hauptsächlich Nutzer in China.

    #### Mirror für die Python-Installation

    Wenn der Standard-Mirror nicht verfügbar ist, versuchen Sie bitte den unten stehenden Mirror.

    ```
    https://python-standalone.org/mirror/astral-sh/python-build-standalone
    ```

    Wenn Sie andere alternative GitHub-Mirror-Adressen finden müssen, suchen Sie bitte eine Mirror-Adresse, die auf die Releases des Repositorys `python-build-standalone` verweist, und bauen Sie diese entsprechend auf.

    ```
    https://github.com/astral-sh/python-build-standalone/releases/download
    ```
    Erstellen Sie eine Adresse nach folgendem Muster

    ```
    https://xxx/astral-sh/python-build-standalone/releases/download
    ```

    <info>Da die meisten GitHub-Mirror-Dienste von Dritten bereitgestellt werden, achten Sie bitte während der Nutzung auf die Sicherheit.</info>
