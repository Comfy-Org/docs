<AccordionGroup>
  <Accordion title="Comfy Desktop">
    Comfy Desktop unterstützt die eigenständige Installation unter **Windows**, **macOS (Apple Silicon)** und **Linux** (AppImage und `.deb`).
    - Die Quelle liegt auf [GitHub](https://github.com/Comfy-Org/Comfy-Desktop)
    <Tip>
    Desktop-Installationen verwenden standardmäßig die **stable** ComfyUI-Version. Wenn Sie jeden neuesten Commit mitnehmen möchten, verwenden Sie die portable Version oder eine manuelle Git-Installation, oder stellen Sie den Update-Kanal einer Instanz auf **Latest on GitHub** um.
    </Tip>
    <Card title="Anleitung zur Installation von Comfy Desktop" icon="link" href="/de/installation/desktop/overview#install-comfy-desktop-for-your-os">
      Windows 10 oder neuer, macOS auf Apple Silicon oder Linux. Die Anleitung enthält für jedes System einen eigenen Tab.
    </Card>
  </Accordion>

  <Accordion title="ComfyUI Portable (Windows)">
    Die portable Version ist eine ComfyUI-Version mit einer eigenständigen, eingebetteten Python-Umgebung. Mit der portablen Version können Sie die neuesten Funktionen ausprobieren; derzeit wird nur **Windows** unterstützt.
    <Card title="Anleitung zur Installation von ComfyUI Portable (Windows)" icon="link" href="/de/installation/comfyui_portable_windows">
    Unterstützt ComfyUI unter **Windows** auf **Nvidia GPUs** oder **CPU-only**, verwendet immer die neuesten Commits und ist vollständig portabel.
    </Card>
  </Accordion>

  <Accordion title="Manuelle Installation">
    <Card title="Anleitung zur manuellen Installation von ComfyUI" icon="link" href="/de/installation/manual_install">
    Unterstützt alle Systemtypen und GPU-Typen (Nvidia, AMD, Intel, Apple Silicon, Ascend NPU, Cambricon MLU)
    </Card>
  </Accordion>
