  <Accordion title="Comfy Desktop">
    Comfy Desktop unterstützt die eigenständige Installation unter **Windows**, **macOS (Apple Silicon)** und **Linux** (AppImage und `.deb`).
    - Die Quelle liegt auf [GitHub](https://github.com/Comfy-Org/Comfy-Desktop)
    <Tip>
    Desktop-Installationen verwenden standardmäßig die **stable** ComfyUI-Version. Wenn Sie jeden neuesten Commit mitnehmen möchten, verwenden Sie die portable Version oder eine manuelle Git-Installation, oder stellen Sie den Update-Kanal der Instanz auf **Latest on GitHub** um.
    </Tip>
    Wählen Sie unten die passende Installation für Ihr System und Ihre Hardware aus

  <Accordion title="ComfyUI Portable (Windows)">
    Die portable Version ist eine ComfyUI-Version mit einer eigenständigen, eingebetteten Python-Umgebung. Mit der portablen Version können Sie die neuesten Funktionen ausprobieren; derzeit wird nur **Windows** unterstützt.
    <Card title="ComfyUI Portable (Windows) installieren" icon="link" href="/de/installation/comfyui_portable_windows">
    Unterstützt ComfyUI unter **Windows** auf **Nvidia GPUs** oder **CPU-only**, verwendet immer die neuesten Commits und ist vollständig portabel.
    </Card>
