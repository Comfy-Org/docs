[Installieren Sie Miniconda](https://docs.anaconda.com/free/miniconda/index.html#latest-miniconda-installer-links). Damit installieren Sie die richtigen Versionen von Python und der weiteren Bibliotheken, die ComfyUI benötigt.

Erstellen Sie eine Umgebung mit Conda.

```
conda create -n comfyenv
conda activate comfyenv
```
