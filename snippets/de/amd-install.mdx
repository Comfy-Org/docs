Installieren Sie unter Linux die PyTorch-Version für ROCm 7.2:

```
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm7.2
```

Alternativ können Sie die Nightly-Version von PyTorch (ROCm 7.2) installieren.

<Accordion title="Nightly installieren">
<Warning>
  Nightly-Version installieren (kann riskanter sein)
</Warning>
```
pip3 install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/rocm7.2
```
</Accordion>

Verwenden Sie unter Windows AMDs [PyTorch-Pakete für mehrere Architekturen](https://rocm.docs.amd.com/projects/ai-ecosystem/en/latest/frameworks/pytorch/install.html) mit ROCm 10.0. Die Extras `device-*` installieren die Kernel Ihrer GPU und die passende ROCm-Laufzeit automatisch; eine separate Installation des HIP SDK ist nicht nötig. Verwenden Sie Windows 11, einen aktuellen [AMD-Grafiktreiber](https://www.amd.com/en/support/download/drivers.html) und 64-Bit-Python 3.13.

Der folgende Installationsbefehl verwendet `device-all`, um die Kernel für alle unterstützten GPUs zu installieren. Um Downloadgröße und Speicherbedarf zu reduzieren, können Sie **beide** Vorkommen von `device-all` optional durch das Ziel für Ihre GPU ersetzen:

| GPU | Device-Extra |
| --- | --- |
| RX 9070 / XT, Radeon AI PRO R9700 | `device-gfx1201` |
| RX 9060 / XT | `device-gfx1200` |
| RX 7900 XT / XTX | `device-gfx1100` |
| RX 7700 XT / 7800 XT | `device-gfx1101` |
| RX 7600 / XT | `device-gfx1102` |
| Ryzen AI Max / Max+ (Strix Halo) | `device-gfx1151` |

<Note>
Diese Tabelle enthält nur Beispiele. Eine hier fehlende GPU kann trotzdem unterstützt werden: Unterstützte Architekturen sind RDNA 2, RDNA 3, RDNA 3.5 und RDNA 4. Behalten Sie `device-all` bei, um die Kernel für alle unterstützten Ziele zu installieren. Für andere Modelle sehen Sie in AMDs [GPU-Zieltabelle](https://github.com/ROCm/TheRock/blob/main/RELEASES.md#gfx-target-lookup-table) und in die [ROCm-Kompatibilitätsmatrix](https://rocm.docs.amd.com/en/docs-10.0.0/compatibility/compatibility-matrix.html).
</Note>

```
pip install --index-url https://stable.repo.amd.com/rocm/whl-next/ "torch[device-all]==2.13.0+rocm10.0.0" "torchvision[device-all]==0.28.0+rocm10.0.0" "torchaudio==2.11.0.2+rocm10.0.0"
```
