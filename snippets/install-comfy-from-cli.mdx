Create a virtual environment with Python 3.10 or newer.

<CodeGroup>

```bash conda
conda create -n comfy-env python=3.11
conda activate comfy-env
```

```bash venv
python3 -m venv comfy-env
source comfy-env/bin/activate
```

</CodeGroup>

Install ComfyUI

```bash
comfy install
```

<Note>`comfy install` installs the PyTorch build for the GPU you select. Keep your GPU driver up to date.</Note>
