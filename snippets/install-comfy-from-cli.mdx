Create a virtual environment with Python 3.10 or newer.

<CodeGroup>

```bash conda
conda create -n comfy-env python=3.11
conda activate comfy-env
```

```bash venv
python3 -m venv comfy-env
source comfy-env/bin/activate
```

</CodeGroup>

Install ComfyUI

```bash
comfy install
```

<Note>`comfy install` installs the matching PyTorch build for your GPU. NVIDIA wheels include the CUDA runtime (GPU driver only—not the full CUDA Toolkit). AMD Windows uses `torch-directml`, not ROCm. Keep your GPU driver up to date.</Note>
