<Note>
  **Current release: 0.4.0.** [`comfy-sdk`](https://pypi.org/project/comfy-sdk/) on PyPI and [`@comfyorg/sdk`](https://www.npmjs.com/package/@comfyorg/sdk) on npm are released together and share a version number. Install the latest (`pip install comfy-sdk`, `npm install @comfyorg/sdk`) or state a range rather than an exact pin. The two ecosystems spell that differently: `comfy-sdk>=0.4` is a floor and accepts later minors, while `@comfyorg/sdk@^0.4` is npm's compatible range for `0.4.x` and stops short of `0.5.0`, so a caret range needs raising when a new minor ships. Use `@comfyorg/sdk@>=0.4.0` if you want the npm side to track later minors too. The registry pages are authoritative if this note is behind.
</Note>
