<Tip>
**Already using Legacy Desktop?** Comfy Desktop can automatically detect and migrate your existing installation. Your custom nodes, workflows, models, and settings are carried over, and Comfy Desktop backs up your legacy state before it starts. The migration reuses your existing data folder and Python environment in place, so back them up yourself if you need a pristine copy.

Learn more in the [Migrate from Legacy](/installation/desktop/usage/migrate) guide.
</Tip>
