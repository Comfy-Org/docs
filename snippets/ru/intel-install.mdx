Графические процессоры Intel Arc (Arc A-Series, Arc B-Series и процессоры Core Ultra с графикой Arc) поддерживаются через нативный XPU-бэкенд PyTorch. В графических процессорах Intel используется XPU, а не CUDA.

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/xpu
```

Убедитесь, что ваш [драйвер Intel GPU](https://www.intel.com/content/www/us/en/developer/articles/tool/pytorch-prerequisites-for-intel-gpu.html) установлен и обновлён. Не устанавливайте wheel-пакеты для CUDA. Если ComfyUI по-прежнему не обнаруживает GPU, см. [Устранение проблем с Intel GPU](/troubleshooting/overview#intel-gpu-issues).
