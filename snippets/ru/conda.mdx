[Установите Miniconda](https://docs.anaconda.com/free/miniconda/index.html#latest-miniconda-installer-links). Это поможет установить правильные версии Python и других библиотек, необходимых ComfyUI.

Создайте окружение с помощью Conda.

```
conda create -n comfyenv
conda activate comfyenv
```
