**Использование**:

```console
$ comfy model [OPTIONS] COMMAND [ARGS]...
```

**Опции**:

* `--install-completion`: Установить автодополнение для текущей оболочки.
* `--show-completion`: Показать автодополнение для текущей оболочки, чтобы скопировать его или настроить установку.
* `--help`: Показать это сообщение и выйти.

**Команды**:

* `download`: Скачать модель в указанный относительный...
* `list`: Показать список всех моделей, которые сейчас...
* `remove`: Удалить одну или несколько скачанных моделей,...

### `download`

Скачать модель в указанный относительный путь, если она ещё не скачана.

**Использование**:

```console
$ download [OPTIONS]
```

**Опции**:

* `--url TEXT`: URL, с которого нужно скачать модель  [обязательно]
* `--relative-path TEXT`: Относительный путь от текущего рабочего пространства, по которому установить модель.  [default: models/checkpoints]
* `--help`: Показать это сообщение и выйти.

### `list`

Показать список всех моделей, которые сейчас скачаны, в виде таблицы.

**Использование**:

```console
$ list [OPTIONS]
```

**Опции**:

* `--relative-path TEXT`: Относительный путь от текущего рабочего пространства, где хранятся модели.  [default: models/checkpoints]
* `--help`: Показать это сообщение и выйти.

### `remove`

Удалить одну или несколько скачанных моделей: либо указав их напрямую, либо выбрав в интерактивном режиме.

**Использование**:

```console
$ remove [OPTIONS]
```

**Опции**:

* `--relative-path TEXT`: Относительный путь от текущего рабочего пространства, где хранятся модели.  [default: models/checkpoints]
* `--model-names TEXT`: Список имён файлов моделей для удаления, разделённых пробелами
* `--help`: Показать это сообщение и выйти.
