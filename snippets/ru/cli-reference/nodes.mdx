**Использование**:

```console
$ comfy node [OPTIONS] COMMAND [ARGS]...
```

**Опции**:

* `--install-completion`: Установить автодополнение для текущей оболочки.
* `--show-completion`: Показать автодополнение для текущей оболочки, чтобы скопировать его или настроить установку.
* `--help`: Показать это сообщение и выйти.

**Команды**:

* `deps-in-workflow`
* `disable`
* `enable`
* `fix`
* `install`
* `install-deps`
* `reinstall`
* `restore-dependencies`
* `restore-snapshot`
* `save-snapshot`: Сохранить снимок текущего окружения ComfyUI...
* `show`

* `uninstall`
* `update`

### `deps-in-workflow`

**Использование**:

```console
$ deps-in-workflow [OPTIONS]
```

**Опции**:

* `--workflow TEXT`: Файл рабочего процесса (.json/.png)  [обязательно]
* `--output TEXT`: Файл рабочего процесса (.json/.png)  [обязательно]
* `--channel TEXT`: Указать режим работы
* `--mode TEXT`: [remote|local|cache]
* `--help`: Показать это сообщение и выйти.
