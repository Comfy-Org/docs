**Использование**:

```console
$ comfy generate [OPTIONS] <MODEL_OR_ACTION> [--<param> value]...
```

`<MODEL_OR_ACTION>` может быть одним из следующих:

* **Псевдоним модели** (например, `flux-pro`, `ideogram-edit`, `kling`, `dalle`): прямой вызов этой модели партнёра.
* **Зарезервированное действие**: `list`, `schema`, `refresh`, `upload`, `resume`.

Всё, что не входит в зарезервированный набор, трактуется как псевдоним модели, и запрос отправляется на соответствующий эндпоинт партнёра.

**Аутентификация**:

Задайте переменную окружения `COMFY_API_KEY` или передавайте `--api-key <KEY>` при каждом вызове. Ключ можно получить на [platform.comfy.org](https://platform.comfy.org).

**Флаги уровня запуска** (работают с любой моделью):

* `--download PATH`: сохранить изображение или видео результата в `PATH`.
* `--async`: отправить задачу и сразу вернуть ID задачи, не дожидаясь завершения. Позже можно возобновить её с помощью `comfy generate resume <model> <job_id>`.
* `--json`: вывести необработанный ответ API в формате JSON (удобно для скриптов).
* `--timeout SECONDS`: переопределить тайм-аут опроса по умолчанию (300 с).
* `--api-key KEY`: API-ключ прямо в вызове (переопределяет `COMFY_API_KEY`).

**Примеры**:

```bash
comfy generate flux-pro --prompt "a cat on the moon" --width 1024 --height 1024 --download cat.png
comfy generate ideogram-edit --image cat.png --mask m.png --prompt "add sunglasses" --rendering_speed TURBO
comfy generate kling --prompt "a paper boat drifting at dusk" --duration 5 --download boat.mp4
```

### `list`

Перечислить доступные модели партнёров и их короткие псевдонимы.

**Использование**:

```console
$ comfy generate list [OPTIONS]
```

**Параметры**:

* `--partner TEXT` / `-p TEXT`: фильтровать по партнёру (например, `bfl`, `kling`, `ideogram`, `openai`).
* `--category TEXT` / `--style TEXT` / `-c TEXT`: фильтровать по категории (например, `text-to-image`, `image-edit`, `inpaint`, `upscale`, `text-to-video`, `image-to-video`).
* `--query TEXT` / `-q TEXT`: совпадение подстроки с id или описанием модели.

### `schema`

Показать параметры конкретной модели: обязательные и необязательные флаги, типы, значения по умолчанию и пример вызова.

**Использование**:

```console
$ comfy generate schema <MODEL>
```

**Пример**:

```bash
comfy generate schema flux-pro
comfy generate schema kling-i2v
```

### `refresh`

Обновить локальный кешированный каталог моделей из облачной спецификации OpenAPI. Полезно, когда добавляются новые модели партнёров.

**Использование**:

```console
$ comfy generate refresh
```

### `upload`

Загрузить локальный файл (или переразместить удалённый URL) в хранилище Comfy и вывести подписанный URL. Большинство моделей принимают локальные пути к файлам напрямую; этот вариант нужен, когда вы хотите явно получить URL (например, чтобы использовать один и тот же ассет в нескольких вызовах).

**Использование**:

```console
$ comfy generate upload <FILE_OR_URL> [--json]
```

**Пример**:

```bash
comfy generate upload ./photo.jpg
comfy generate upload ./photo.jpg --json
```

<Note>
**Референсные ассеты автоматически удаляются через 24 часа.** Загруженные файлы (как через `comfy generate upload`, так и неявно, когда вы передаёте модели локальный путь) хранятся в управляемом Comfy бакете GCS (`api-nodes-prod`) и доступны только по подписанному URL. Объекты автоматически удаляются **через 1 день после загрузки** согласно правилу жизненного цикла бакета. Если ассет должен сохраняться между длительными асинхронными задачами, загружайте его заново перед каждой задачей или разместите его самостоятельно и передавайте URL напрямую.
</Note>

### `resume`

Возобновить ранее отправленную асинхронную задачу (обычно видеозадачу, отправленную с `--async`). Опрос продолжается до готовности результата, после чего его можно скачать.

**Использование**:

```console
$ comfy generate resume <MODEL> <JOB_ID> [--download PATH] [--json]
```

**Пример**:

```bash
comfy generate resume luma 7c3f9e2a --download out.mp4
```
