## Перед публикацией

SDK создают `Idempotency-Key` и переиспользуют его для автоматических повторов. При ручных повторах используйте исходный ключ. Router может удерживать соединение до 10 минут.

Когда запрос завершается ошибкой, Router отправляет заголовок ответа `X-Comfy-Error-Type` с объяснением причины. Код `422` означает, что Router отклонил вход до вызова провайдера, а `413` означает, что тело запроса оказалось больше, чем Router принимает. Скачивайте сгенерированные ассеты своевременно, поскольку [URL результатов могут истекать](/development/comfy-router/reference#result-assets).

Любое ограничение размера, указанное в описании поля выше, это собственный предел провайдера для этого поля, приведённый из спецификации провайдера. Router применяет отдельное ограничение ко всему телу запроса, в которое засчитываются медиа в base64: см. [размер тела запроса](/development/comfy-router/limitations#request-bodies-are-capped).

Эта страница описывает одну партнёрскую модель, вызываемую через Comfy Router. Тот же пакет `comfy-sdk` / `@comfyorg/sdk` также поставляется со вторым клиентом для запуска целого графа рабочего процесса ComfyUI на Comfy Cloud: `Comfy(api_key=...)` / `new Comfy({ apiKey })`, с `client.workflows`, `client.assets` и `client.jobs`. См. [Comfy SDKs](/development/api-development/sdks).
