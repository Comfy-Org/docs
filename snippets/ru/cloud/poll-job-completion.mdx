**Значения статуса задачи:**

API возвращает одно из следующих значений статуса:

| Статус | Описание |
|--------|-------------|
| `success` | Задача успешно завершена. Терминальное состояние |
| `error` | Задача не выполнена. Терминальное состояние |
| `non_retryable_error` | Задача не выполнена, повторные попытки не помогут. Терминальное состояние |
| `lost` | Задача исчезла до завершения. Терминальное состояние |
| `cancelled` | Задача была отменена. Терминальное состояние |

Эти пять значений являются терминальными состояниями. Все остальные означают, что задача ещё выполняется, в том числе `submitted`, `queued_waiting`, `preparing`, `executing` и переходные состояния, такие как `cancel_requested`. Опрашивайте статус, пока не получите терминальное значение, вместо того чтобы ориентироваться на названия промежуточных состояний.

```bash curl
# Опрос завершения задачи
curl -X GET "$BASE_URL/api/job/{prompt_id}/status" \
  -H "X-API-Key: $COMFY_CLOUD_API_KEY"

# Примеры ответов:
# {"status": "queued_waiting"}       - Задача в очереди
# {"status": "executing"}            - Задача выполняется прямо сейчас
# {"status": "success"}              - Задача успешно завершена
# {"status": "error"}                - Задача завершилась с ошибкой
# {"status": "non_retryable_error"}  - Задача не выполнена, повторные попытки не помогут
# {"status": "lost"}                 - Задача исчезла до завершения
# {"status": "cancelled"}            - Задача была отменена
```

```typescript TypeScript
interface JobStatus {
  status: string;
}

async function getJobStatus(promptId: string): Promise<JobStatus> {
  const response = await fetch(`${BASE_URL}/api/job/${promptId}/status`, {
    headers: getHeaders(),
  });
  if (!response.ok) throw new Error(`HTTP ${response.status}`);
  return response.json();
}

async function pollForCompletion(
  promptId: string,
  timeout: number = 300,
  pollInterval: number = 2000
): Promise<void> {
  const startTime = Date.now();

  while (Date.now() - startTime < timeout * 1000) {
    const { status } = await getJobStatus(promptId);

    if (status === "success") {
      return;
    } else if (
      ["error", "non_retryable_error", "lost", "cancelled"].includes(status)
    ) {
      throw new Error(`Job failed with status: ${status}`);
    }

    await new Promise((resolve) => setTimeout(resolve, pollInterval));
  }

  throw new Error(`Job ${promptId} did not complete within ${timeout}s`);
}

await pollForCompletion(promptId);
console.log("Job completed!");
```

```python Python
def get_job_status(prompt_id: str) -> str:
    """Получить текущий статус задачи."""
    response = requests.get(
        f"{BASE_URL}/api/job/{prompt_id}/status",
        headers=get_headers()
    )
    response.raise_for_status()
    return response.json()["status"]

def poll_for_completion(prompt_id: str, timeout: int = 300, poll_interval: float = 2.0) -> None:
    """Опрашивать статус, пока задача не завершится или не истечёт таймаут."""
    start_time = time.time()

    while time.time() - start_time < timeout:
        status = get_job_status(prompt_id)

        if status == "success":
            return
        elif status in ("error", "non_retryable_error", "lost", "cancelled"):
            raise RuntimeError(f"Job failed with status: {status}")

        time.sleep(poll_interval)

    raise TimeoutError(f"Job {prompt_id} did not complete within {timeout}s")

poll_for_completion(prompt_id)
print("Job completed!")
```
