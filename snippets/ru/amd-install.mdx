Для Linux установите версию PyTorch для ROCm 7.2:

```
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm7.2
```

Кроме того, можно установить ночную версию PyTorch (ROCm 7.2).

<Accordion title="Установить ночную версию">
<Warning>Установка ночной версии (может быть рискованнее)</Warning>
```
pip3 install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/rocm7.2
```
</Accordion>

Для Windows используйте [пакеты PyTorch для нескольких архитектур](https://rocm.docs.amd.com/projects/ai-ecosystem/en/latest/frameworks/pytorch/install.html) от AMD с ROCm 10.0. Дополнительные компоненты `device-*` автоматически устанавливают ядра вашей GPU и соответствующую среду выполнения ROCm; отдельная установка HIP SDK не требуется. Используйте Windows 11, актуальный [драйвер AMD](https://www.amd.com/en/support/download/drivers.html) и 64-битный Python 3.13.

В команде установки ниже используется `device-all`, чтобы установить ядра для всех поддерживаемых GPU. Чтобы уменьшить размер загрузки и занимаемое место, можно заменить **оба** вхождения `device-all` на компонент для вашей GPU:

| GPU | Дополнительный компонент |
| --- | --- |
| RX 9070 / XT, Radeon AI PRO R9700 | `device-gfx1201` |
| RX 9060 / XT | `device-gfx1200` |
| RX 7900 XT / XTX | `device-gfx1100` |
| RX 7700 XT / 7800 XT | `device-gfx1101` |
| RX 7600 / XT | `device-gfx1102` |
| Ryzen AI Max / Max+ (Strix Halo) | `device-gfx1151` |

<Note>
В таблице приведены только примеры. GPU, которой нет в таблице, всё равно может поддерживаться: поддерживаются архитектуры RDNA 2, RDNA 3, RDNA 3.5 и RDNA 4. Оставьте `device-all`, чтобы установить ядра для всех поддерживаемых целей. Для других моделей см. [таблицу целей GPU](https://github.com/ROCm/TheRock/blob/main/RELEASES.md#gfx-target-lookup-table) и [матрицу совместимости ROCm](https://rocm.docs.amd.com/en/docs-10.0.0/compatibility/compatibility-matrix.html).
</Note>

```
pip install --index-url https://stable.repo.amd.com/rocm/whl-next/ "torch[device-all]==2.13.0+rocm10.0.0" "torchvision[device-all]==0.28.0+rocm10.0.0" "torchaudio==2.11.0.2+rocm10.0.0"
```
