Запускайте рабочие процессы и партнёрские узлы на хостинговых GPU Comfy. Локальная установка не требуется.

```bash
comfy cloud login          # вход через браузер (OAuth + PKCE)
comfy cloud whoami         # показать статус входа, метод аутентификации, базовый URL
comfy cloud logout         # очистить локальную сессию
```

После входа команды автоматически направляются в облако. **РЕКОМЕНДУЕТСЯ вход через браузер (OAuth).** Ключами управлять не нужно, а CLI сам обновляет токены за вас. Чтобы указать пользовательское окружение (например, предпросмотр PR) до входа:

```bash
comfy cloud set-base-url https://my-preview.comfy.org
```

<Note>
  **API-ключ необязателен.** API-ключ нужен только для headless- или CI-использования, где вход через браузер невозможен. Это запасной вариант, а не вариант по умолчанию:

  ```bash
  export COMFY_API_KEY=comfyui-...   # или передайте --api-key при каждом вызове
  ```
</Note>

<Note>
  **Время жизни сессии.** Токены облачной сессии недолговечны (~1 ч). CLI обновляет их по требованию автоматически. Если команда сообщает `cloud_unauthorized`, выполните `comfy cloud login` снова.
</Note>
