**Nano Banana (Google Gemini): текст в изображение и редактирование:**

```bash
comfy generate nano-banana \
    --prompt "a watercolor of a sleeping fox" \
    --download fox.png

# Редактирование изображения:
comfy generate nano-banana \
    --prompt "add a top hat" \
    --image ./cat.png \
    --download edited.png

# Указать вариант модели:
comfy generate nano-banana \
    --prompt "neon city skyline" \
    --model gemini-3-pro-image-preview \
    --download city.png
```

**FLUX 1.1 Pro Ultra: изображение высокого разрешения по тексту:**

comfy generate flux-ultra \

**Seedance (ByteDance): текст в видео и изображение в видео, до 1080p / 12 с:**

```bash
# Текст в видео:
comfy generate seedance \
    --prompt "a hummingbird hovering over a flower" \
    --resolution 1080p --duration 5 \
    --download hummingbird.mp4

# Изображение в видео (анимация локального изображения, загружается автоматически):
comfy generate seedance \
    --model seedance-1-0-pro-250528 \
    --image ./painting.png \
    --ratio 3:4 --resolution 1080p --duration 5 \
    --prompt "the painting gently comes alive, a soft breeze stirs the trees" \
    --download animated.mp4
```
