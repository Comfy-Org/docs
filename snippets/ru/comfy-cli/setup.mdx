Новое в последних версиях: единый интерактивный мастер, который за один шаг настраивает маршрутизацию, авторизацию и навыки агента.

```bash
comfy setup
```

Он проведёт вас через выбор цели маршрутизации (локальной или облачной), **вход через браузер (OAuth)**, выбор каталога проекта и, при желании, установку навыков агента. Это рекомендуемый способ. Вход в браузере открывается автоматически, копировать ключи не нужно.

```bash
comfy setup --where cloud
```

<Note>
  **Неинтерактивный режим (только для CI).** Для OAuth через браузер требуется интерактивная сессия. Для CI, devcontainer-ов и установки скриптами, где браузер недоступен, передайте вместо этого API-ключ:

  ```bash
  comfy setup --where cloud --api-key comfyui-... --non-interactive
  ```
</Note>

| Флаг | Назначение |
| --- | --- |
| `--where local\|cloud` | Цель маршрутизации; пропускает запрос |
| `--project-dir` | Каталог для рабочих процессов, входов и выходов |
| `--api-key` | *(Необязательно)* API-ключ Comfy Cloud для headless/CI; подразумевает `--where cloud` |
| `-y, --non-interactive` | Без запросов. Всё задаётся флагами |
| `--skip-skills` | Не устанавливать навыки агента |
| `--skip-verify` | Пропустить проверку подключения |
