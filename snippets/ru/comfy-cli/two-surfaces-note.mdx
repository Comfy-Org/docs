<Note>
  **Две среды, один CLI.** Каждая команда автоматически определяет, где выполняться. Если вход в Comfy Cloud выполнен, команды направляются в **облако**; в противном случае они выполняются на вашем **локальном** сервере. Переопределить для отдельного вызова можно с помощью `--where local|cloud`, переменной окружения `COMFY_WHERE` или закрепить выбор с помощью `comfy set-default --where cloud`.
</Note>
