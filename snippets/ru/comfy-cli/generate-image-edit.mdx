Передайте пути к локальным файлам. CLI загружает их через хранилище Comfy или при необходимости кодирует в base64:

```bash
comfy generate nano-banana \
    --prompt "add a top hat" \
    --image ./cat.png \
    --download edited.png

comfy generate flux-kontext \
    --prompt "add a top hat and a monocle" \
    --input_image ./photo.jpg \
    --download out.png

comfy generate ideogram-edit \
    --image cat.png --mask mask.png \
    --prompt "add sunglasses" \
    --rendering_speed TURBO \
    --download edited.png
```

Чтобы загрузить файл один раз и использовать его в нескольких вызовах:

```bash
comfy generate upload ./photo.jpg     # выводит подписанный URL
```
