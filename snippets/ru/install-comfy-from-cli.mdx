Создайте виртуальную среду с Python 3.10 или новее.

<CodeGroup>

```bash conda
conda create -n comfy-env python=3.11
conda activate comfy-env
```

```bash venv
python3 -m venv comfy-env
source comfy-env/bin/activate
```

</CodeGroup>

Установить ComfyUI

```bash
comfy install
```

`comfy install` спрашивает, какой у вас GPU, и устанавливает подходящую сборку PyTorch. Ответьте на запрос или передайте флаг GPU для установки без участия пользователя:

| Платформа | Что устанавливает `comfy install` | Что ещё потребуется |
| --- | --- | --- |
| NVIDIA | PyTorch со средой выполнения CUDA (pip-пакет) | Актуальный драйвер GPU (не полный CUDA Toolkit) |
| AMD Linux | PyTorch-пакеты ROCm | Драйвер или стек AMD GPU с поддержкой ROCm для этих пакетов |
| AMD Windows | `torch-directml` | ComfyUI больше не поддерживает DirectML. Установите вместо этого сборку PyTorch с ROCm; для неё нужен AMD GPU RDNA 2 или новее (см. [системные требования](/ru/installation/system_requirements)) |
| Apple silicon | Ночные сборки PyTorch (индекс CPU; Metal/MPS) | macOS на Apple silicon |
| Intel Arc | PyTorch-пакеты XPU | Совместимый Intel Arc GPU или стек XPU |
| CPU | PyTorch-пакеты для CPU | Дискретная видеокарта не требуется |
