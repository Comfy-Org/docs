## Важно: не изменяйте папку resource/ComfyUI

<Warning>
Не добавляйте и не изменяйте содержимое папки `/resource/ComfyUI`. Всё содержимое этой папки будет сброшено при обновлении Comfy Desktop.

В отличие от других версий ComfyUI, версия Desktop управляет этой папкой автоматически. При установке вы выбрали пользовательское расположение для моделей, пользовательских узлов и других пользовательских файлов. Используйте это расположение вместо указанной папки.
</Warning>
