<Tabs>
  <Tab title="Портативная версия">
    **Рекомендуемый метод**: используйте пакетный скрипт `ComfyUI_windows_portable\update\update_comfyui.bat`, который обновит и код ComfyUI, и все зависимости Python.

    **Ручное обновление зависимостей**:
    Если вам нужно обновить зависимости вручную, используйте следующую команду:
    ```bash
    # Откройте командную строку в каталоге портативной версии
    .\python_embeded\python.exe -m pip install -r ComfyUI\requirements.txt
    ```
  </Tab>
  <Tab title="Ручная установка">

    <Steps>
      <Step title="Активировать окружение Python">
      Если вы используете Conda для управления окружениями Python, сначала активируйте своё окружение:
      ```bash
      conda activate comfyui  # или другое имя окружения
      ```
      </Step>
      <Step title="Обновить код">
      Перейдите в корневой каталог ComfyUI и обновите код с помощью Git:
      ```
      cd <ComfyUI_ROOT_PATH>
      git pull
      ```
      </Step>
      <Step title="Обновить зависимости">
      Обновите зависимости ComfyUI: этот шаг критически важен, особенно для `comfyui-frontend-package`:
      ```
      pip install -r requirements.txt
      ```
      </Step>
    </Steps>

  </Tab>
  <Tab title="Desktop">
    - **Экземпляр ComfyUI + зависимости Python:** используйте [Управлять → Обновить](/ru/installation/desktop/usage/manage#update-tab) (**Stable** или **Latest on GitHub**). Обновления зависимостей обычно применяются в рамках этого процесса.
    - **Само приложение Desktop:** используйте пункт меню приложения **Проверить обновления** (он не связан с каналом обновлений ComfyUI).
    - Переустанавливайте Desktop только в крайнем случае.
  </Tab>
</Tabs>
