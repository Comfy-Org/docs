## Добавить внешние пути к моделям

Если модели хранятся в других местах на вашем компьютере вне каталога установки ComfyUI, добавьте их в Comfy Desktop вместо ручного редактирования файлов конфигурации:

- **Все экземпляры:** [Настройки рабочего стола → Хранилище](/ru/installation/desktop/usage/settings#storage) → **Shared Models** → **+ Add Shared Directory**
- **Только один экземпляр:** [Управлять → Хранилище](/ru/installation/desktop/usage/instance-management#выбрать-папки-которые-использует-сборка) → **Model Directories**

Вы также можете поместить `extra_model_paths.yaml` в папку ComfyUI этого экземпляра (`<install>/ComfyUI/extra_model_paths.yaml`). ComfyUI загружает этот файл при запуске.

Классический Desktop использовал другой файл в данных приложения (`extra_models_config.yaml` в старой папке поддержки приложения `ComfyUI`). В текущем Comfy Desktop предпочитайте интерфейс хранилища.

Подробные инструкции см. в [документации по моделям](/basic-concepts/models).
