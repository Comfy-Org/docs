По умолчанию модели хранятся в `<your ComfyUI installation>/ComfyUI/models/` с подпапками вроде `checkpoints`, `embeddings`, `vae`, `lora`, `upscale_model` и т. д. При запуске ComfyUI обнаруживает модели в этих папках и в путях, заданных в `extra_model_paths.yaml`.

<Tabs>
  <Tab title="Comfy Desktop (найти папку моделей)">
  Нажмите меню-капсулу в верхней части приложения, затем откройте вкладку **Storage**, чтобы проверить каталоги моделей. Капсула есть только в десктопном приложении, но не при запуске ComfyUI в браузере. Нажмите иконку папки рядом с каталогом, чтобы открыть его в вашем файловом менеджере.

  ![Меню-капсула Comfy Desktop: вкладка Storage с настройками каталогов моделей](/images/concepts/models_desktop_storage_tab.png)
  </Tab>
  <Tab title="ComfyUI Portable (найти папку моделей)">
  В портативной версии папка моделей обычно находится по пути:

  `ComfyUI_windows_portable/ComfyUI/models/`
  </Tab>
</Tabs>
