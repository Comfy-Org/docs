Каталог пользователя ComfyUI: здесь хранятся ваши личные настройки, рабочие процессы и пользовательские изменения. Расположение зависит от типа установки:

<Tabs>
<Tab title="Desktop - Windows">
```
C:\Users\<your username>\AppData\Roaming\ComfyUI\user
```
</Tab>
<Tab title="Desktop - macOS">
```
~/<ComfyUI installation path>/ComfyUI/user
```
</Tab>
<Tab title="Desktop - Linux">
```
~/.config/ComfyUI/user
```
</Tab>
<Tab title="Установка вручную">
Каталог пользователя находится в папке установки ComfyUI:
```
<ComfyUI installation path>/user
```

Например, если вы склонировали ComfyUI в `C:\ComfyUI`, ваш каталог пользователя будет `C:\ComfyUI\user\default` (или `C:\ComfyUI\user\john`, если вы задали собственное имя пользователя).

<Note>
ComfyUI поддерживает несколько пользователей в одной установке. Если вы не настроили собственное имя пользователя, используется «default». Каждый пользователь получает собственный подкаталог в папке `user`.
</Note>
</Tab>
<Tab title="Портативная версия">
Каталог пользователя находится в портативной папке ComfyUI:
```
<ComfyUI_windows_portable>/ComfyUI/user
```

Например: `ComfyUI_windows_portable/ComfyUI/user/default`

<Note>
ComfyUI поддерживает несколько пользователей в одной установке. Если вы не настроили собственное имя пользователя, используется «default». Каждый пользователь получает собственный подкаталог в папке `user`.
</Note>
</Tab>
</Tabs>

В этом каталоге хранятся ваши рабочие процессы, настройки и другие файлы пользователя.
