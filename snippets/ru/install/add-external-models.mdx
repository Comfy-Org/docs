## Добавление дополнительных путей к моделям

Если вы хотите хранить файлы моделей вне `ComfyUI/models`, причины могут быть следующими:

- У вас несколько экземпляров ComfyUI, и вы хотите, чтобы они использовали общие файлы моделей и экономили место на диске
- Вы используете разные GUI-программы (например, WebUI) и хотите, чтобы они работали с одними и теми же файлами моделей
- Файлы моделей не распознаются или не находятся

Мы предоставляем способ добавлять дополнительные пути поиска моделей через файл конфигурации `extra_model_paths.yaml`.

### Открыть файл конфигурации

<Tabs>
  <Tab title="Portable/Ручная установка">
  Для версии ComfyUI, установленной как [portable](/ru/installation/comfyui_portable_windows) или [вручную](/ru/installation/manual_install), в корневом каталоге ComfyUI есть пример файла `extra_model_paths.yaml.example`:
  ```
  ComfyUI/extra_model_paths.yaml.example
  ```

  Скопируйте его и переименуйте в `extra_model_paths.yaml`. Оставьте файл в корневом каталоге ComfyUI: `ComfyUI/extra_model_paths.yaml`.
  Пример конфигурации также доступен [здесь](https://github.com/Comfy-Org/ComfyUI/blob/master/extra_model_paths.yaml.example)
  
  </Tab>
  <Tab title="Comfy Desktop">
  Если вы используете приложение [Comfy Desktop](/ru/installation/desktop/windows), нажмите меню-капсулу в верхней части приложения, откройте вкладку **Storage** и добавьте там каталоги моделей. Меню-капсула есть только в настольном приложении, а не при работе ComfyUI в браузере.

  ![Меню-капсула Comfy Desktop: вкладка «Storage» с настройками каталогов моделей](/images/concepts/models_desktop_storage_tab.png)

  Или откройте файл напрямую:

  <Tabs>
    <Tab title="Windows">
      ```
      C:\Users\YourUsername\AppData\Roaming\ComfyUI\extra_models_config.yaml
      ```
    </Tab>
    <Tab title="macOS">
      ```
      ~/Library/Application Support/ComfyUI/extra_models_config.yaml
      ```
    </Tab>
  </Tabs>

  Файл должен оставаться в том же каталоге; не переносите его в другое место.
  </Tab>
</Tabs>

Если файла нет, создайте его в любом текстовом редакторе.

### Пример структуры

Предположим, вы хотите добавить в ComfyUI следующие пути к моделям:

```
📁 YOUR_PATH/
  ├── 📁models/
  |   ├── 📁 loras/
  |   │   └── xxxxx.safetensors
  |   ├── 📁 checkpoints/
  |   │   └── xxxxx.safetensors
  |   ├── 📁 vae/
  |   │   └── xxxxx.safetensors
  |   └── 📁 controlnet/
  |       └── xxxxx.safetensors
```

Тогда файл `extra_model_paths.yaml` можно настроить так, чтобы ComfyUI распознавал пути к моделям на вашем устройстве:

```
my_custom_config:
    base_path: YOUR_PATH
    loras: models/loras/
    checkpoints: models/checkpoints/
    vae: models/vae/
    controlnet: models/controlnet/
```
или

```
my_custom_config:
    base_path: YOUR_PATH/models/
    loras: loras
    checkpoints: checkpoints
    vae: vae
    controlnet: controlnet
```

<Warning>
  В настольной версии добавляйте конфигурацию к существующему пути, не перезаписывая конфигурацию путей, созданную при установке. Перед изменением сделайте резервную копию файла, чтобы восстановить его в случае ошибки.
</Warning>

Другие параметры конфигурации см. в стандартном файле [extra_model_paths.yaml.example](https://github.com/Comfy-Org/ComfyUI/blob/master/extra_model_paths.yaml.example). После сохранения **перезапустите ComfyUI**, чтобы изменения вступили в силу.

Ниже приведён исходный пример конфигурации:

```yaml
#Переименуйте этот файл в extra_model_paths.yaml, и ComfyUI загрузит его


#конфигурация для a1111 ui
#достаточно изменить base_path на путь, по которому установлен ваш интерфейс
a111:
    base_path: path/to/stable-diffusion-webui/

    checkpoints: models/Stable-diffusion
    configs: models/Stable-diffusion
    vae: models/VAE
    loras: |
         models/Lora
         models/LyCORIS
    upscale_models: |
                  models/ESRGAN
                  models/RealESRGAN
                  models/SwinIR
    embeddings: embeddings
    hypernetworks: models/hypernetworks
    controlnet: models/ControlNet

#конфигурация для comfyui
#base_path должен указывать либо на существующую установку Comfy, либо на общий каталог, где хранятся все ваши модели, LoRA и т. д.

#comfyui:
#     base_path: path/to/comfyui/
#     # is_default помечает эти каталоги как первые в списке и используемые по умолчанию, например для загрузок
#     #is_default: true
#     checkpoints: models/checkpoints/
#     clip: models/clip/
#     clip_vision: models/clip_vision/
#     configs: models/configs/
#     controlnet: models/controlnet/
#     diffusion_models: |
#                  models/diffusion_models
#                  models/unet
#     embeddings: models/embeddings/
#     loras: models/loras/
#     upscale_models: models/upscale_models/
#     vae: models/vae/

#other_ui:
#    base_path: path/to/ui
#    checkpoints: models/checkpoints
#    gligen: models/gligen
#    custom_nodes: path/custom_nodes

```

Например, если ваш WebUI находится в `D:\stable-diffusion-webui\`, измените конфигурацию так:
```yaml
a111:
    base_path: D:\stable-diffusion-webui\
    checkpoints: models/Stable-diffusion
    configs: models/Stable-diffusion
    vae: models/VAE
    loras: |
         models/Lora
         models/LyCORIS
    upscale_models: |
                  models/ESRGAN
                  models/RealESRGAN
                  models/SwinIR
    embeddings: embeddings
    hypernetworks: models/hypernetworks
    controlnet: models/ControlNet
```

### Добавление дополнительного пути к пользовательским узлам

Помимо внешних моделей, можно добавить пути к пользовательским узлам, которые находятся вне стандартного каталога ComfyUI.

<Tip>
  Учтите, что это не меняет стандартный путь установки пользовательских узлов, а добавляет дополнительный путь поиска при запуске ComfyUI. Зависимости пользовательских узлов всё равно нужно установить в соответствующем окружении, чтобы среда выполнения была полной.
</Tip>

Ниже приведён простой пример конфигурации (macOS). Измените его под вашу ситуацию, добавьте в соответствующий файл конфигурации, сохраните и перезапустите ComfyUI, чтобы изменения вступили в силу:

```yaml
my_custom_nodes:
  custom_nodes: /Users/your_username/Documents/extra_custom_nodes
```
