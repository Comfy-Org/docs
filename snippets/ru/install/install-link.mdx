  <Accordion title="Comfy Desktop">
    Comfy Desktop поддерживает автономную установку на **Windows**, **macOS (Apple Silicon)** и **Linux** (AppImage и `.deb`).
    - Исходный код находится на [GitHub](https://github.com/Comfy-Org/Comfy-Desktop)
    <Tip>
    При установке десктопной версии по умолчанию используется **stable**-релиз ComfyUI. Если вам нужны все последние коммиты, используйте портативную версию, ручную установку через git или переключите канал обновления экземпляра на **Latest on GitHub**.
    </Tip>
    Ниже можно выбрать подходящий вариант установки для вашей системы и оборудования.
    <Tabs>
      <Tab title="Windows">
        <Card title="Руководство по установке Comfy Desktop (Windows)" icon="link" href="/ru/installation/desktop/windows">
        Подходит для **Windows** 10 и новее. Рекомендуется GPU NVIDIA или AMD.
        </Card>
      </Tab>
      <Tab title="macOS (Apple Silicon)">
        <Card title="Руководство по установке Comfy Desktop (macOS)" icon="link" href="/ru/installation/desktop/macos">
          Подходит для macOS с **Apple Silicon**
        </Card>
      </Tab>
      <Tab title="Linux">
        <Card title="Руководство по установке Comfy Desktop (Linux)" icon="link" href="/ru/installation/desktop/linux">
          Установите AppImage или `.deb`, либо соберите и запустите из исходного кода.
        </Card>
      </Tab>
    </Tabs>
  </Accordion>

  <Accordion title="ComfyUI Portable (Windows)">
    Портативная версия представляет собой вариант ComfyUI со встроенным независимым окружением Python. С её помощью можно опробовать новейшие функции; сейчас поддерживается только система **Windows**.
    <Card title="Руководство по установке ComfyUI Portable (Windows)" icon="link" href="/ru/installation/comfyui_portable_windows">
    Поддерживает версию ComfyUI для **Windows**, работающую на **Nvidia GPU** или **только на CPU**, всегда использует последние коммиты и полностью портативна.
    </Card>
  </Accordion>
