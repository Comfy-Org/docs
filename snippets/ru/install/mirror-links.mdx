При различных ошибках зеркал можно обратиться к приведённому ниже материалу, чтобы попробовать вручную найти другие зеркала и заменить их.

    Следующие случаи в основном относятся к пользователям из Китая.

    #### Зеркало для установки Python
    
    Если зеркало по умолчанию недоступно, попробуйте использовать зеркало ниже.

    ```
    https://python-standalone.org/mirror/astral-sh/python-build-standalone
    ```

    Если нужно найти другие альтернативные адреса зеркал GitHub, найдите и составьте адрес зеркала, указывающий на релизы репозитория `python-build-standalone`.

    ```
    https://github.com/astral-sh/python-build-standalone/releases/download
    ```
    Составьте ссылку по следующему шаблону

    ```
    https://xxx/astral-sh/python-build-standalone/releases/download
    ```

    <info>Поскольку большинство сервисов зеркал GitHub предоставляются третьими сторонами, обратите внимание на безопасность при использовании.</info>

    #### Зеркало PyPI

    - Alibaba Cloud: https://mirrors.aliyun.com/pypi/simple/
    - Tencent Cloud: https://mirrors.cloud.tencent.com/pypi/simple/
    - University of Science and Technology of China: https://pypi.mirrors.ustc.edu.cn/simple/
    - Shanghai Jiao Tong University: https://pypi.sjtu.edu.cn/simple/

    #### Зеркало Torch
    
    - Aliyun: https://mirrors.aliyun.com/pytorch-wheels/cu130/
