Запустить приложение

```
cd ComfyUI
python main.py
```

Выполните `python main.py --help`, чтобы получить встроенную справку, или обратитесь к [ссылке по флагам запуска](/development/comfyui-server/startup-flags), где приведён полный список параметров командной строки.
