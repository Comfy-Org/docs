기본적으로 모델은 `<ComfyUI 설치 위치>/ComfyUI/models/` 아래에 저장되며, `checkpoints`, `embeddings`, `vae`, `lora`, `upscale_model` 등 하위 폴더로 구분됩니다. ComfyUI는 시작할 때 이러한 폴더들과 `extra_model_paths.yaml`에 설정된 경로에서 모델을 감지합니다.

<Tabs>
  <Tab title="Comfy 데스크톱 (모델 폴더 찾기)">
  데스크톱 앱 상단의 캡슐 메뉴를 클릭하고 **Storage** 탭을 열어 모델 디렉터리를 확인하세요. 캡슐 메뉴는 데스크톱 앱에만 있으며 브라우저에서 실행하는 ComfyUI에는 없습니다. 디렉터리 옆의 폴더 아이콘을 클릭하면 파일 관리자에서 열 수 있습니다.

  </Tab>
