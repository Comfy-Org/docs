## 외부 모델 경로 추가

컴퓨터의 ComfyUI 설치 디렉터리 외부 다른 위치에 모델이 저장되어 있다면, 설정 파일을 직접 편집하는 대신 Comfy Desktop에서 추가하세요:

- **모든 인스턴스:** [데스크탑 설정 → 저장소](/ko/installation/desktop/usage/settings#storage) → **공유 모델** → **+ 공유 디렉터리 추가**
- **한 인스턴스에서만:** [관리 → 저장소](/ko/installation/desktop/usage/instance-management#빌드가-사용할-폴더-선택) → **모델 디렉터리**

해당 인스턴스의 ComfyUI 폴더(`<install>/ComfyUI/extra_model_paths.yaml`)에 `extra_model_paths.yaml`을 둘 수도 있습니다. ComfyUI는 시작할 때 이 파일을 로드합니다.

레거시 Desktop은 앱 데이터에 있는 다른 파일(이전 `ComfyUI` 애플리케이션 지원 폴더 아래의 `extra_models_config.yaml`)을 사용했습니다. 현재 Comfy Desktop에서는 저장소 UI를 사용하는 것이 좋습니다.

자세한 안내는 [모델 문서](/ko/basic-concepts/models)를 참조하세요.
