## 외부 모델 경로 추가

모델이 ComfyUI 설치 디렉터리 밖에 있다면 설정 파일을 직접 고치지 말고 Comfy Desktop에서 추가하세요.

- **모든 인스턴스:** [Desktop Settings → Storage](/ko/installation/desktop/usage/settings#저장소) → **Shared Models** → **+ Add Shared Directory**
- **특정 인스턴스만:** [Manage → Storage](/ko/installation/desktop/usage/manage#저장소-탭) → **Model Directories**

해당 인스턴스의 ComfyUI 폴더에 `extra_model_paths.yaml`을 둘 수도 있습니다(`<install>/ComfyUI/extra_model_paths.yaml`). ComfyUI는 시작 시 이 파일을 로드합니다.

레거시 Desktop은 앱 데이터의 `extra_models_config.yaml`(이전 `ComfyUI` Application Support 폴더)을 사용했습니다. 현재 Comfy Desktop에서는 Storage UI를 사용하세요.

자세한 내용은 [모델 문서](/ko/basic-concepts/models)를 참조하세요.
