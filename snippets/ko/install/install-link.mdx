  <Accordion title="Comfy 데스크톱">
    Comfy Desktop은 **Windows**, **macOS(Apple Silicon)**, **Linux**(AppImage 및 `.deb`)에서 독립형 설치를 지원합니다.
    - 소스는 [GitHub](https://github.com/Comfy-Org/Comfy-Desktop)에 있습니다
    <Tip>
    Desktop 설치는 기본적으로 ComfyUI **안정** 릴리스를 따릅니다. 모든 최신 커밋을 사용하려면 휴대용 버전이나 수동 git 설치를 사용하거나, 빌드의 업데이트 채널을 **Latest on GitHub**로 전환하세요.
    </Tip>
    <Card title="Comfy Desktop 설치 가이드" icon="link" href="/ko/installation/desktop/overview#사용-중인-os에-맞게-comfy-desktop-설치">
      Windows 10 이상, Apple Silicon 기반 macOS 또는 Linux를 지원합니다. 가이드에는 시스템별 탭이 있습니다.
    </Card>
  </Accordion>

  <Accordion title="ComfyUI 휴대용 (Windows)">
    휴대용 버전은 독립적인 임베디드 Python 환경을 통합한 ComfyUI 버전으로, 휴대용 버전을 사용하면 최신 기능을 경험할 수 있습니다. 현재 **Windows** 시스템만 지원합니다.
    <Card title="ComfyUI 휴대용 (Windows) 설치 가이드" icon="link" href="/ko/installation/comfyui_portable_windows">
    **Windows**에서 **Nvidia GPU** 또는 **CPU 전용**으로 실행되는 ComfyUI 버전을 지원하며, 항상 최신 커밋을 사용하고 완전히 휴대 가능합니다.
    </Card>
  </Accordion>

  <Accordion title="수동 설치">
    <Card title="ComfyUI 수동 설치 가이드" icon="link" href="/ko/installation/manual_install">
