<Note>
**Docker:** ComfyUI는 공식 Docker 이미지를 제공하지 않습니다. 컨테이너에서 ComfyUI를 실행하려면 [Docker Hub](https://hub.docker.com/search?q=comfyui)의 커뮤니티 유지보수 이미지를 사용할 수 있습니다. `comfyui` 또는 `comfy-ui` 같은 검색어로 사용 가능한 이미지를 찾으세요.

커뮤니티 이미지를 사용할 때 일반적인 설정 단계:
1. 웹 인터페이스에 접속하기 위해 포트 `8188`을 매핑합니다
2. 호스트에서 포트 매핑이 동작하도록 컨테이너 안의 ComfyUI가 `0.0.0.0`에서 수신 대기하는지 확인합니다(대부분의 커뮤니티 이미지는 기본으로 처리합니다)
3. 모델 디렉터리용 볼륨을 마운트합니다
4. 출력 디렉터리용 볼륨을 마운트합니다

예시:
```bash
docker run -d \
  --name comfyui \
  --gpus all \
  -p 8188:8188 \
  -v /path/to/models:/ComfyUI/models \
  -v /path/to/output:/ComfyUI/output \
  <community-image-name>
```

GPU 사용자는 `--gpus all`이 필요합니다([NVIDIA Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html) 필요). `/ComfyUI/models` 같은 컨테이너 내부 경로는 이미지마다 다를 수 있습니다. 정확한 경로는 선택한 이미지의 문서를 참고하세요.

**이 이미지들은 모두 ComfyUI 공식 이미지가 아니며**, ComfyUI 팀의 지원도 받지 않습니다. 사용에 따른 책임은 사용자에게 있습니다.
</Note>
