  <Tab title="휴대용">
    **권장 방법**: `ComfyUI_windows_portable\update\update_comfyui.bat` 배치 스크립트를 사용하세요. 이 스크립트는 ComfyUI 코드와 모든 Python 의존성을 함께 업데이트합니다.

    **수동 의존성 업데이트**:
    의존성을 수동으로 업데이트해야 하는 경우 다음 명령을 사용하세요:
    ```bash
    # 휴대용 버전 디렉터리에서 명령줄 열기
    .\python_embeded\python.exe -m pip install -r ComfyUI\requirements.txt
    ```
  </Tab>
  <Tab title="수동 설치">

    <Steps>
      <Step title="Python 환경 활성화">
      Conda로 Python 환경을 관리한다면 먼저 환경을 활성화하세요:
      ```bash
      conda activate comfyui  # 또는 다른 환경 이름
      ```
      </Step>
      <Step title="코드 업데이트">
      ComfyUI 루트 디렉터리로 이동한 뒤 Git으로 코드를 업데이트하세요:
      ```
      cd <ComfyUI_ROOT_PATH>
      git pull
      ```
      </Step>
      <Step title="의존성 업데이트">
      ComfyUI 의존성을 업데이트하세요. 특히 `comfyui-frontend-package`의 경우 이 단계가 매우 중요합니다:
      ```
      pip install -r requirements.txt
      ```
      </Step>
    </Steps>

  </Tab>
  <Tab title="데스크톱">
    - **ComfyUI 인스턴스 + Python 의존성:** [관리 → 업데이트](/ko/installation/desktop/usage/instance-management#comfyui-업데이트)(**안정판** 또는 **GitHub 최신판**)를 사용하세요. 의존성 업데이트는 보통 이 과정에서 함께 적용됩니다.
    - **데스크톱 앱 자체:** 앱 메뉴의 **업데이트 확인**을 사용하세요(ComfyUI 업데이트 채널과는 별개).
    - 데스크톱 재설치는 최후의 수단으로만 하세요.
  </Tab>
