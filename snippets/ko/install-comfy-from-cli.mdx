Python 3.10 이상 버전으로 가상 환경을 생성하세요.

<CodeGroup>

```bash conda
conda create -n comfy-env python=3.11
conda activate comfy-env
```

```bash venv
python3 -m venv comfy-env
source comfy-env/bin/activate
```

</CodeGroup>

ComfyUI 설치하기

```bash
comfy install
```

<Note>`comfy install`은 선택한 GPU에 맞는 PyTorch 빌드를 설치합니다. GPU 드라이버를 최신 상태로 유지하세요.</Note>
