Linux에서는 ROCm 7.2 버전의 PyTorch를 설치합니다:

```
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm7.2
```

또는 PyTorch의 Nightly 버전(ROCm 7.2)을 설치할 수도 있습니다.

<Accordion title="Nightly 설치">
<Warning>Nightly 버전 설치 (더 위험할 수 있음)</Warning>
```
pip3 install --pre torch torchvision torchaudio --index-url https://download.pytorch.org/whl/nightly/rocm7.2
```
</Accordion>

Windows에서는 AMD의 [멀티 아키텍처 PyTorch 패키지](https://rocm.docs.amd.com/projects/ai-ecosystem/en/latest/frameworks/pytorch/install.html)를 ROCm 10.0과 함께 사용하세요. `device-*` 엑스트라가 GPU 커널과 일치하는 ROCm 런타임을 자동으로 설치하므로 별도의 HIP SDK 설치가 필요하지 않습니다. Windows 11, 최신 [AMD 그래픽 드라이버](https://www.amd.com/en/support/download/drivers.html), 64비트 Python 3.13을 사용하세요.

아래 설치 명령어는 지원되는 모든 GPU의 커널을 설치하는 `device-all`을 사용합니다. 다운로드 크기와 디스크 사용량을 줄이려면 `device-all` **두 군데**를 모두 해당 GPU의 타겟으로 바꿀 수 있습니다:

| GPU | 디바이스 엑스트라 |
| --- | --- |
| RX 9070 / XT, Radeon AI PRO R9700 | `device-gfx1201` |
| RX 9060 / XT | `device-gfx1200` |
| RX 7900 XT / XTX | `device-gfx1100` |
| RX 7700 XT / 7800 XT | `device-gfx1101` |
| RX 7600 / XT | `device-gfx1102` |
| Ryzen AI Max / Max+ (Strix Halo) | `device-gfx1151` |

<Note>
이 표는 예시일 뿐입니다. 표에 없는 GPU도 지원될 수 있습니다: 지원되는 아키텍처는 RDNA 2, RDNA 3, RDNA 3.5, RDNA 4입니다. 지원되는 모든 타겟의 커널을 설치하려면 `device-all`을 유지하세요. 다른 모델은 AMD의 [GPU 타겟 테이블](https://github.com/ROCm/TheRock/blob/main/RELEASES.md#gfx-target-lookup-table)과 [ROCm 호환성 매트릭스](https://rocm.docs.amd.com/en/docs-10.0.0/compatibility/compatibility-matrix.html)를 참조하세요.
</Note>

```
pip install --index-url https://stable.repo.amd.com/rocm/whl-next/ "torch[device-all]==2.13.0+rocm10.0.0" "torchvision[device-all]==0.28.0+rocm10.0.0" "torchaudio==2.11.0.2+rocm10.0.0"
```
