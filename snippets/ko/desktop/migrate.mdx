**이미 Legacy Desktop을 사용 중이신가요?** Comfy Desktop은 기존 설치를 자동으로 감지하고 마이그레이션할 수 있습니다. 커스텀 노드, 워크플로, 모델, 설정이 모두 이전되며, Comfy Desktop이 시작 전에 레거시 상태를 백업합니다. 마이그레이션은 기존 데이터 폴더와 Python 환경을 그대로 재사용하므로, 온전한 사본이 필요하다면 미리 직접 백업하세요.

자세한 내용은 [레거시에서 마이그레이션](/ko/installation/desktop/usage/migrate) 가이드를 참고하세요.
