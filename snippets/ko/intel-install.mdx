Intel Arc GPU(Arc A 시리즈, Arc B 시리즈 및 Arc 그래픽이 탑재된 Core Ultra 프로세서)는 PyTorch의 기본 XPU 백엔드를 통해 지원됩니다. Intel GPU는 CUDA가 아닌 XPU를 사용합니다.

```
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/xpu
```

Intel GPU 드라이버가 설치되어 있고 최신 상태인지 확인하세요. CUDA 휠은 설치하지 마세요. 그래도 ComfyUI가 GPU를 감지하지 못하면 [Intel GPU 문제 해결](/troubleshooting/overview#intel-gpu-issues)을 참조하세요.
