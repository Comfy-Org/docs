FIBO 2.0 is Bria's 8B image model that generates and edits with one set of weights. The open-weight release runs locally in ComfyUI with no credits, works in the FLUX.2 VAE latent space, and encodes prompts with Qwen3-VL-4B.

Two templates ship with it. **Fibo 2.0 Turbo: Image Edit** is the distilled version for quick direction tests, and **Fibo 2.0 Dev: Image Edit** runs the non-distilled base for the cleanest edit. Both take a reference image and a one-line instruction.

## Model downloads

Both templates load the int8_convrot files, the bf16 4B text encoder, and the 8B encoder the prompt enhancer reads the reference image with. The bf16 diffusion files are the same weights in full precision, about twice the size.
