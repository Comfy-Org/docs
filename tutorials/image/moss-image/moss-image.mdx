## About MOSS-Image

MOSS-Image is OpenMOSS's open-weights text-to-image model: a 5B single-stream DiT that turns a full scene caption into one finished image. It is strongest where text and placement matter, because it renders English and Chinese typography, accepts prompts of up to about 4K tokens, and can read a JSON layout that says where each object and each line of text belongs. Weights ship under Apache 2.0, so you download once and run on your own GPU with no API key and no per-image credits.

The family has two checkpoints. The instruction-tuned **SFT** checkpoint is the one the templates load: it groups text and lays out scenes more cleanly. The **Base** checkpoint has no post-training or CFG distillation, which makes it the starting point for community LoRAs. Both run in the same graph, so switching checkpoints is a single loader change.

In ComfyUI the model runs from single-file checkpoints in int8 and bf16, with a Qwen3.5 9B text encoder loaded as type `moss_image` and the FLUX.2 small VAE. The text to image templates also ship a prompt upsampler that rewrites a short request into a full caption before sampling, using the same text encoder the model already needs.

**Model highlights:**

- 5B single-stream DiT with bilingual English and Chinese text rendering
- Native layout guidance: draw boxes, give each box a caption, and text boxes render their own text
- Prompt upsampler built into the text to image templates, so a one-line idea is enough
- Two checkpoints: SFT for cleaner layouts, Base for fine-tuning and LoRA work
- Long prompts of roughly 4K tokens, and any aspect ratio in multiples of 16

### MOSS-Image: Layout-Guided Text to Image {#image_moss_image_t2i_bboxes}

## Prompting tips

- **Describe the finished image, not the request.** The model was trained on captions, so write what the picture looks like rather than an instruction like "make me a poster". The upsampler follows the same rule, which is why a short prompt still works.
- **Turn the upsampler off to control the wording.** Set `enable_prompt_upsampler` to `false` on the subgraph node and your prompt goes to the model unchanged. Both settings show the result in `Preview Any`, so you can compare.
- **Control line breaks yourself.** Automatic breaks may not land where you want them. Put real newlines or `\n` in the text you want rendered when the position of a break matters.
- **Use the layout workflow when placement matters.** Boxes give the model an explicit position for each element and each block of text, which is more reliable than describing positions in prose.
- **Keep the canvas in the recommended range.** `ResolutionSelector` picks the aspect ratio and the megapixel count (1 MP by default). MOSS-Image is trained for 1 MP to 2 MP and extrapolates from about 0.25 MP to 4 MP; width and height must be multiples of 16.
- **Start from the template settings, then go slower for the official look.** The templates run 25 steps at CFG 2.5 with the `er_sde` sampler for speed. The official settings are 50 steps at CFG 3, so try those if a result is undercooked.
- **Keep the negative prompt short.** The templates ship `nsfw, worst quality, bad anatomy, watermark, jpeg artifact`.
- **Skip layer guidance is on at layer 22.** The subgraph node carries an `SLG` toggle, and the guidance runs at the official layer 22. Turning it off can look more realistic but may collapse detail; other layers are only reachable inside the subgraph.
- **Base is for fine-tuning.** When you train a LoRA on MOSS-Image, freeze the text encoder.
