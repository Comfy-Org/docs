**MiniMax-H3-Image** is MiniMax's open-weights image model, and one checkpoint covers both text to image and image editing. The diffusion transformer is 33.1B parameters in BF16, distilled to a 6-step sampler with no CFG. Output is native at about 16 MP, so a 4096 x 4096 image is a single pass rather than an upscale chain.

## Key features

- **Text to image and editing in one checkpoint**: no separate edit model or adapter to load
- **6-step sampling**: guidance is fixed at 1, so there is no CFG pass and no negative prompt
- **About 16 MP natively**: 4096 x 4096 up to 6272 x 2688 without an upscale pass
- **Multiple references**: up to 16 input images, addressed as `<Picture 1>` upwards in the prompt
- **Optional prompt expander**: turns a short request into the detailed caption the model reads best
- **Open weights**: full local control in ComfyUI

## Sampling and canvas size

Both templates ship the distilled schedule:

| Setting | Value |
| --- | --- |
| Sampler | euler |
| Scheduler | simple |
| Steps | 6 |
| Guidance (CFG) | 1 |
| Denoise | 1 |

With guidance at 1 there is no classifier-free guidance pass, so the templates carry no negative prompt. Write everything you want, including things to avoid, into the positive prompt.

Native output is about 16 MP. Every edge is generated on a multiple of 32 px, and any width and height are accepted. These sizes cover the common ratios:

| Aspect ratio | Size (width x height) |
| --- | --- |
| 1:1 | 4096 x 4096 |
| 4:3 | 4736 x 3552 |
| 3:4 | 3552 x 4736 |
| 3:2 | 5024 x 3360 |
| 2:3 | 3360 x 5024 |
| 16:9 | 5472 x 3072 |
| 9:16 | 3072 x 5472 |
| 21:9 | 6272 x 2688 |

Smaller canvases work too and cost less time. In the text-to-image template the resolution selector sets the aspect ratio and the target megapixels separately, so any target from about 4 MP up to the selector's 16 MP ceiling is one setting away.

## Reference images in image editing

The image editing template sends the source image to the model as `<Picture 1>`. Additional images are labelled in order, `<Picture 2>`, `<Picture 3>`, up to 16 references, and the prompt addresses each one by its label. The first picture is the one being edited and the rest supply identity, props, materials, or composition, so a short instruction is enough: replacing the vehicle in `<Picture 1>` with the one in `<Picture 2>`.

To add a reference, place another `Load Image` node in the workflow and connect it to both the prompt generation step and the conditioning node. Keep the VAE input on the conditioning node connected: the template already wires it, and with the VAE the reference pictures are also anchored as image latents, so the edit follows the source more closely. Give every reference a short edge of at least 1024 px, and 2048 px when identity matters: the node resizes them for you, upscales anything below 1024 px (those pixels are interpolation), and discards detail beyond 2048 px.

Without the resize node, an edit comes back at the source's size. Enable it to generate at a set target instead: 16 MP in the current template pack, and bypassed at 1 MP on pack 0.11.104, where you select it, press `Ctrl-B`, then set the target. Lower the target before sampling if the edit runs out of memory.

The model reads the picture it edits at a short edge of 2048 px at most, which is roughly 4 MP at 1:1 and 7 MP at 16:9. A target above that adds generated detail rather than source detail, so put the target at that size when detail matters and upscale the result afterwards.

### Writing an edit prompt

Leave the expander on and a short instruction is enough: it rewrites your text into the shape the model reads best. Turn it off to write the prompt yourself, and use that same shape.

1. **Name what you refer to, element first.** `The woman in a red coat in <Picture 1> is <Subject 1>`, with enough visible detail to single her out. Every definition names its `<Picture N>`.
2. **Describe the target image, then give each subject its outcome.** `<Subject 1> is fully preserved`, or `<Subject 1> is partially preserved; her face and coat remain, while her pose changes to a lean toward <Subject 2>`.
3. **Describe only what changed or is new.** The surface a removed object leaves behind goes here, and so does any text the edit adds.

Content with no source in a reference takes no subject number. Name a removed element once with its `<Picture N>` in the target description, then describe the area it leaves.

`<Subject N>` is wording the text encoder reads, not a binding the sampler enforces, so the description is what holds an edit together. State what changes and what stays instead of assuming the reference carries it. The official editing example shows the full structure: [revised_prompt.edit.txt](https://github.com/MiniMax-AI/MiniMax-H3-Image/blob/main/examples/revised_prompt.edit.txt).

### Enlarging and restoring a picture

The edit workflow can also do the second pass itself, with no separate upscaler model. Set the target in the `Resize Image/Mask` node that holds `scale total pixels` (16 MP in the shipped template) and clear the toggle in the `Boolean (Enable PE?)` node. If the node is bypassed on your pack, select it and press `Ctrl-B` first.

```text
Re-render and sharpen as if the photo were taken with a 50 mm lens. Remove noise and compression artifacts. Improve skin, hair, eye and fabric detail while keeping pose, identity, and colors.
```

Match the lens to the source. With the expander off the instruction reaches the model as written, while the expander writes a description of a new image and adds content you did not ask for.

The frame is re-rendered rather than patched, so this is an enlargement with new detail, not a faithful copy. Pose, identity, and colors hold when the target stays near the size the model reads the source at, about 4 MP at 1:1, since everything above the 2048 px short edge is generated. Anything the prompt leaves out can change, and at large targets skin texture can turn glossy and older-looking.

## Prompt expander

Both templates hold a text generation step in front of the sampler. In the text-to-image template it rewrites the prompt into a detailed English caption. In the image editing template it turns a short instruction into a reference-aware description of the finished image.

The official expander for MiniMax-H3-Image is a Qwen3.8-27B FP4 model, published as [MiniMaxAI/MiniMax-H3-Image-PE](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image-PE). The templates use a lighter Qwen3.5 9B W4A8 build instead, so the expander fits beside the 21 GB diffusion model on one GPU.

Both templates ship with the expander switched on, so your prompt is rewritten before sampling. Switch it off to send your prompt to the model exactly as typed.
