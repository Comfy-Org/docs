**MiniMax-H3-Image** is MiniMax's open-weights image model, and one checkpoint covers both text to image and image editing. The diffusion transformer is 33.1B parameters in BF16, distilled to a 6-step sampler with no CFG. Output is native at about 16 MP, so a 4096 x 4096 image is a single pass rather than an upscale chain.

**Related links**

- [MiniMaxAI/MiniMax-H3-Image (Hugging Face)](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image): official model card and weights
- [MiniMax-H3-Image (ModelScope)](https://modelscope.cn/models/minimax/MiniMax-H3-Image): official mirror for mainland China
- [MiniMax-AI/MiniMax-H3-Image (GitHub)](https://github.com/MiniMax-AI/MiniMax-H3-Image): official examples and skills

- [Comfy-Org/MiniMax-H3 (Hugging Face)](https://huggingface.co/Comfy-Org/MiniMax-H3): Qwen3-VL-32B text encoder used by this model
- [MiniMaxAI/MiniMax-H3-Image-PE (Hugging Face)](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image-PE): official prompt expander

## Key features

- **Text to image and editing in one checkpoint**: no separate edit model or adapter to load
- **6-step sampling**: guidance is fixed at 1, so there is no CFG pass and no negative prompt
- **About 16 MP natively**: 4096 x 4096 up to 6272 x 2688 without an upscale pass
- **Multiple references**: up to 16 input images, addressed as `<Picture 1>` upwards in the prompt
- **Optional prompt expander**: turns a short request into the detailed caption the model reads best
- **Open weights**: full local control in ComfyUI

## Sampling and canvas size

Both templates ship the distilled schedule:

| Setting | Value |
| --- | --- |
| Sampler | euler |
| Scheduler | simple |
| Steps | 6 |
| Guidance (CFG) | 1 |
| Denoise | 1 |

With guidance at 1 there is no classifier-free guidance pass, so the templates carry no negative prompt. Write everything you want, including things to avoid, into the positive prompt.

Native output is about 16 MP. Every edge is generated on a multiple of 32 px, and any width and height are accepted. These sizes cover the common ratios:

| Aspect ratio | Size (width x height) |
| --- | --- |
| 1:1 | 4096 x 4096 |
| 4:3 | 4736 x 3552 |
| 3:4 | 3552 x 4736 |
| 3:2 | 5024 x 3360 |
| 2:3 | 3360 x 5024 |
| 16:9 | 5472 x 3072 |
| 9:16 | 3072 x 5472 |
| 21:9 | 6272 x 2688 |

Smaller canvases work too and cost less time. In the text-to-image template the resolution selector sets the aspect ratio and the target megapixels separately, so 4 MP is a starting point rather than a limit.

### Fixing over-processed text to image output

Connect any picture to the `images` input of `MiniMax H3 Image Conditioning` when text-only output comes out over-processed: pores and moles exaggerated, skin and fabric reading as crusty. A larger canvas does not help, since the artifacts persist at 16 MP.

The conditioning node sits inside the Text to Image subgraph. Add a `Load Image` node there and wire it to `images`. What the picture shows does not matter, so a blank image works.

Disconnect `vae` on the conditioning node to keep the cost at the vision tokens alone. The picture then reaches only the text encoder, and `VAEDecode` keeps its own VAE connection. Any small picture is enough, since the node rescales it to a 1024 px short edge.

## Reference images in image editing

The image editing template sends the source image to the model as `<Picture 1>`. Additional images are labelled in order, `<Picture 2>`, `<Picture 3>`, up to 16 references, and the prompt addresses each one by its label. The first picture is the one being edited and the rest supply identity, props, materials, or composition, so a short instruction is enough: replacing the vehicle in `<Picture 1>` with the one in `<Picture 2>`.

To add a reference, place another `Load Image` node in the workflow and connect it to both the prompt generation step and the conditioning node. Keep the VAE input on the conditioning node connected: the template already wires it, and with the VAE the reference pictures are also anchored as image latents, so the edit follows the source more closely. Give every reference a short edge of at least 1024 px, and 2048 px when identity matters: the node resizes them for you, upscales anything below 1024 px (those pixels are interpolation), and discards detail beyond 2048 px.

Without the resize node, an edit comes back at the source's size. Enable it to generate at a set target instead: 4 MP on template packs where it ships active, and bypassed at 1 MP on pack 0.11.104, where you select it, press `Ctrl-B`, then set the target. Lower the target before sampling if the edit runs out of memory.

## Prompt expander

Both templates hold a text generation step in front of the sampler. In the text-to-image template it rewrites the prompt into a detailed English caption and picks an aspect ratio for the canvas. In the image editing template it turns a short instruction into a reference-aware description of the finished image.

The official expander for MiniMax-H3-Image is a Qwen3.8-27B FP4 model, published as [MiniMaxAI/MiniMax-H3-Image-PE](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image-PE). The templates use a lighter Qwen3.5 9B W4A8 build instead, so the expander fits beside the 21 GB diffusion model on one GPU.

The text-to-image template ships with the expander switched off, so your prompt reaches the model exactly as typed; switch it on when you want the caption rewritten and the aspect ratio chosen for you. The image editing template ships with it on.
