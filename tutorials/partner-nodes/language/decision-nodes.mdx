Decision nodes ask a hosted model one question about whatever you connect, and return the answer as a value your graph can route on: a boolean, one of your labels, or a score. Put one in front of an expensive generation step and that step only runs on inputs that pass.

Two providers ship them: **HeyGen Decision** and **Google Gemini Decision**. Both read text, images, audio, or video, and both come in a yes/no, a choice, and a score version. They are API nodes, billed per input token on your Comfy account, so there is no model to download.

## The nodes

| Node | Question | Outputs |
| :--- | :--- | :--- |
| **Decision (Yes/No)** | A question with a yes or no answer | `result` (BOOLEAN), `answer` (`"yes"`/`"no"`), `probability` |
| **Decision (Choice)** | Which of your options fits, entered one per line | `choice`, `option_index` (0-based), `confidence` |
| **Decision (Score)** | Rate whatever is connected from 1 to 10 | `result` (score at or above the threshold), `score` |
| **Google Gemini Decision (Pick Image)** | Which image in a batch is best, or best matches the text | `index`, `confidence` |

`result` connects to an **If/Else Switch** node. `choice` connects to a **Branch** node whose inputs carry the option names, or you can route on `option_index`. For **Pick Image**, feed `index` into **Get Image from Batch**.

## What you can connect

- **Text** up to 20,000 characters, such as a prompt, a caption, or a model answer to check
- **Images**: up to 4 on HeyGen, up to 16 on Gemini. Name them in the question as `image_1`, `image_2`, and so on. **Pick Image** is the exception: it takes one batch of 2 to 64 images and returns the index of the chosen one
- **Audio**: one clip as `audio_1`, up to 30 minutes on HeyGen
- **Video**: one clip as `video_1`, up to 60 seconds on HeyGen
- The question itself is up to 5,000 characters, and one run needs at least one connected input

## Tips

- **Phrase the question so "yes" is the case you act on.** "Is there a person in the image?" with `result` driving the accept branch reads the same in the graph as in plain English.
- **Tune the threshold rather than rewording.** Yes/No returns the probability of yes and flips at `threshold` (default 0.5). Raise it when a false positive is expensive. HeyGen's clear answers sit near 0 or 1; Gemini's clear yes answers score about 0.85 to 0.92, so 0.9 or higher rejects many of them.
- **Put the decision before the expensive node.** The rejected branch is never generated, so a failing image costs one short question instead of a full render.
- **Score once per candidate when comparing.** In the example both images are scored by the same question, then compared with `a > b`. For a margin, use `a > b + 1`: A wins only when it leads by more than one point, and B passes otherwise.
- **Give Choice an escape option.** Add a line such as `other` so inputs that fit nothing are labelled instead of forced into the closest match.
