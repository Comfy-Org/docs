<Warning>
  **Veo 2.0 is retired.** ComfyUI removed the Veo 2.0 node in #15883 and the example workflow now lives in `archived/`, so it no longer runs on current ComfyUI. Use [Veo 3.1](/tutorials/partner-nodes/veo/veo-3-1) instead: the **Google Veo 3 Video Generation** node takes an optional reference image and generates 720p to 4K video with native audio.
</Warning>

Veo 2.0 generated short clips from a text prompt and accepted an optional image to anchor the first frame. The archived example below is the image-to-video variant, which animated a single still while keeping its composition.
