This page shows how to call Ideogram 4.0 from your own code. For what the model is and what it does best, see the [Ideogram 4.0 overview](/tutorials/partner-nodes/ideogram/ideogram-v4). To run it interactively in ComfyUI instead, see the [workflows](/tutorials/partner-nodes/ideogram/ideogram-v4/workflow).

<RouterPreviewNotice />

Comfy Router runs Ideogram 4.0 behind one host, one credential and one route. The request body is Ideogram's own native JSON input. The response is their native JSON output, unwrapped. A call written against the Ideogram API becomes a Router call by changing the host.

Create a key at [platform.comfy.org/profile/api-keys](https://platform.comfy.org/profile/api-keys) and export it as `COMFY_API_KEY`. Every snippet below reads it from the environment.

The Python and TypeScript snippets use the Comfy SDKs (`pip install comfy-sdk`, `npm install @comfyorg/sdk`). The SDKs send an `Idempotency-Key` on every call, wait up to Router's 10 minute deadline, and surface `X-Comfy-Request-Id` on results and errors. The cURL snippet is the same call over raw HTTP.

## Quick start

**Model ID:** `ideogram/ideogram-v4`

**Endpoint:** `POST https://api.comfy.org/v2/models/ideogram/ideogram-v4`

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment. Each call sends a fresh
# Idempotency-Key and waits up to 10 minutes for the finished result.
with Comfy() as client:
    result = client.models.run(
        "ideogram/ideogram-v4",
        {
            "text_prompt": "a single red maple leaf on a plain white background, studio lighting",
            "resolution": "1024x1024",
            "rendering_speed": "DEFAULT",
        },
    )

print("image:", result["data"][0]["url"])
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Reads COMFY_API_KEY from the environment. Each call sends a fresh
// Idempotency-Key and waits up to 10 minutes for the finished result.
type Result = { data: { url: string }[] };
const { data } = await comfy.models.run<Result>("ideogram/ideogram-v4", {
  text_prompt: "a single red maple leaf on a plain white background, studio lighting",
  resolution: "1024x1024",
  rendering_speed: "DEFAULT",
});

console.log("image:", data.data[0].url);
```

```bash cURL
curl https://api.comfy.org/v2/models/ideogram/ideogram-v4 \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"text_prompt\": \"a single red maple leaf on a plain white background, studio lighting\", \"resolution\": \"1024x1024\", \"rendering_speed\": \"DEFAULT\"}"
```

## Schema

### Input

_Fields follow Ideogram's published API specification and are checked against it in CI. Router's own schema for this model is not published yet, so requests are forwarded to the provider unvalidated._

<ParamField body="text_prompt" type="string">
  Text description of the image. Provide this or `json_prompt`.
</ParamField>

<ParamField body="json_prompt" type="object">
  Structured prompt, as an alternative to `text_prompt`.
</ParamField>

<ParamField body="resolution" type="string">
  Output size as `WIDTHxHEIGHT`, for example `1024x1024` or `1536x1024`.
</ParamField>

<ParamField body="rendering_speed" type="string" default="&quot;DEFAULT&quot;">
  Speed / quality trade-off.

  Possible values: `TURBO`, `BALANCED`, `DEFAULT`, `QUALITY`
</ParamField>

<ParamField body="enable_copyright_detection" type="boolean">
  Reject outputs that match known copyrighted material.
</ParamField>

### Output

Router returns Ideogram's native response unchanged. The image is at `data[0].url`.

<ResponseField name="response_type" type="string">
  How the images are delivered.

  Possible values: `url`
</ResponseField>

<ResponseField name="created" type="string (date-time)" required>
  Timestamp of the generation.

  Format: `date-time`
</ResponseField>

<ResponseField name="data" type="object[]" required>
  Generated images.
</ResponseField>

<ResponseField name="data[].url" type="string (uri)">
  Temporary URL of the image. Download it promptly.

  Format: `uri`
</ResponseField>

<ResponseField name="data[].prompt" type="string" required>
  The prompt that was run.
</ResponseField>

<ResponseField name="data[].resolution" type="string" required>
  Output size as `WIDTHxHEIGHT`.
</ResponseField>

<ResponseField name="data[].seed" type="integer" required>
  Seed used for this image.
</ResponseField>

<ResponseField name="data[].is_image_safe" type="boolean" required>
  Whether the image passed Ideogram's safety filter.
</ResponseField>
