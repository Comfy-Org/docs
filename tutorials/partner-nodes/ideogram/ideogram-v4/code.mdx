This page shows how to call Ideogram 4.0 from your own code. For what the model is and what it does best, see the [Ideogram 4.0 overview](/tutorials/partner-nodes/ideogram/ideogram-v4). To run it interactively in ComfyUI instead, see the [workflows](/tutorials/partner-nodes/ideogram/ideogram-v4/workflow).

<RouterPreviewNotice />

Comfy Router runs Ideogram 4.0 behind one host, one credential and one route. The request body is Ideogram's own native JSON input and the response is their native JSON output, unwrapped, so a call written against the Ideogram API becomes a Router call by changing the host. Create a key at [platform.comfy.org/profile/api-keys](https://platform.comfy.org/profile/api-keys) and export it as `COMFY_API_KEY` before running any snippet.

## Quick start

**Endpoint:** `POST https://api.comfy.org/v2/models/ideogram/ideogram-v4`  **Model ID:** `ideogram/ideogram-v4`

<CodeGroup>
```python Python
import os
import uuid

import httpx

response = httpx.post(
    "https://api.comfy.org/v2/models/ideogram/ideogram-v4",
    headers={
        "X-API-Key": os.environ["COMFY_API_KEY"],
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={
        "text_prompt": "a single red maple leaf on a plain white background, studio lighting",
        "resolution": "1024x1024",
        "rendering_speed": "DEFAULT",
    },
    timeout=httpx.Timeout(660.0, connect=10.0),
)
response.raise_for_status()
result = response.json()
print("image:", result["data"][0]["url"])
```

```typescript TypeScript
const response = await fetch("https://api.comfy.org/v2/models/ideogram/ideogram-v4", {
  method: "POST",
  headers: {
    "X-API-Key": process.env.COMFY_API_KEY!,
    "Idempotency-Key": crypto.randomUUID(),
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    text_prompt: "a single red maple leaf on a plain white background, studio lighting",
    resolution: "1024x1024",
    rendering_speed: "DEFAULT",
  }),
  signal: AbortSignal.timeout(660_000),
});
if (!response.ok) throw new Error(`HTTP ${response.status}`);

const result = (await response.json()) as { data: { url: string }[] };
console.log("image:", result.data[0].url);
```

## Request fields

Provide either `text_prompt` or a structured `json_prompt`. `resolution` is a `WIDTHxHEIGHT` string such as `1024x1024` or `1536x1024`; `rendering_speed` is `TURBO`, `DEFAULT` or `QUALITY`. `enable_copyright_detection` rejects outputs that match known copyrighted material. This list is a convenience: the authoritative schema is served live, and it is the same document Router validates your call against.

```bash
curl -H "X-API-Key: $COMFY_API_KEY" \
  https://api.comfy.org/v2/models/ideogram/ideogram-v4/openapi.json
```

## Read the result

Router holds the connection until the generation is finished and returns Ideogram's native result. The image is at `data[0].url`:

```json
{
  "created": "2026-08-27T21:00:00Z",
  "data": [
    {
      "url": "https://.../image.png",
      "prompt": "a single red maple leaf on a plain white background, studio lighting",
      "resolution": "1024x1024",
      "seed": 1234567890,
      "is_image_safe": true,
      "style_type": "AUTO"
    }
  ]
}
```

The URL is temporary. Download the image promptly if you need to keep it.
