Ideogram 3.0 is a powerful text-to-image model by Ideogram, known for its photorealistic quality, accurate text rendering, and consistent style control.

The Ideogram V3 node currently supports two modes:
- Text-to-Image mode
- Image Editing mode (when both image and mask inputs are provided)

<ReqHint/>
<UpdateReminder/>

## Ideogram 3.0 Partner Nodes Text-to-Image Mode

When using Ideogram V3 without image and mask inputs, the node operates in Text-to-Image mode.

### 1. Download Workflow File

Download and drag the following file into ComfyUI to load the workflow:

![Ideogram 3.0 ComfyUI Workflow](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/api_nodes/ideogram/v3/ideogram_v3_t2i.png)

### 2. Complete the Workflow Steps

![Ideogram 3.0 Workflow Steps](/images/tutorial/api_nodes/ideogram/ideogram_v3_t2i.jpg)

Follow the numbered steps to complete the basic workflow:
1. Enter your image description in the `prompt` field of the `Ideogram V3` node
2. Click `Run` or use shortcut `Ctrl(cmd) + Enter` to generate the image
3. After the API returns results, view the generated image in the `Save Image` node. Images are saved to the `ComfyUI/output/` directory

## Ideogram 3.0 Partner Nodes Image Editing Mode

Connect both the `image` and `mask` inputs on the `Ideogram V3` node to switch it into image editing mode. The node regenerates the masked area from your prompt and keeps the rest of the image unchanged.

1. Load the image you want to edit with a `Load Image` node, then connect it to the `image` input of the `Ideogram V3` node
2. Right-click the loaded image, choose **Open in MaskEditor**, and paint the area you want to change
3. Connect the mask output to the `mask` input of the `Ideogram V3` node. Painted (white) areas are replaced, and everything outside the mask is kept
4. Enter the edit instruction in the `prompt` field, describing what should appear inside the masked area
5. Click `Run` or use the shortcut `Ctrl(cmd) + Enter` to generate the edited image
6. View the result in the `Save Image` node. The edited image is also saved to the `ComfyUI/output/` directory

<Note>
The node only uses editing mode when both `image` and `mask` are connected. If you connect just one of them, the node runs in text-to-image mode.
</Note>
