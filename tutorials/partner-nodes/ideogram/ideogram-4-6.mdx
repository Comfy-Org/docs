**Ideogram 4.6** is Ideogram's image generation and editing model with native 4K output. It renders up to 4096x4096 in one pass, so posters, packaging, and product shots do not need a separate upscale. Precise Edit keeps the colors and detail of the pixels you did not ask to change.

It runs as a model option in three ComfyUI partner nodes: **Ideogram Text to Image**, **Ideogram Edit**, and **Ideogram Precise Edit**. Set `model` to `ideogram-4.6` in any of them, and pick `ideogram-4.5` in the same list to use the older model, which has [its own page](/tutorials/partner-nodes/ideogram/ideogram-4-5).

## Text to Image

Generate an image from a text prompt at a 1K, 2K, or 4K canvas.

![Ideogram 4.6 text to image example output](https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/output/api_ideogram_v4_6_t2i.png)

The **Ideogram Text to Image** node takes:

| Input | Values | Effect |
| --- | --- | --- |
| `prompt` | up to 10000 characters | The image description. A structured JSON caption works too, for example a `final_prompt` from an earlier run |
| `size` | `auto`, a 1K, 2K, or 4K preset, or `custom` | `auto` picks a canvas that suits the prompt. Presets cover 1K, 2K, and 4K canvases from portrait `1:3` and `9:23` up to landscape `3:1` and `23:9`, for example `(2K) 2048x2048 (1:1)` and `(4K) 5120x2880 (16:9)` |
| `width`, `height` | 256 to 8192, step 32 | Used only when `size` is `custom`. The two dimensions must stay within 16777216 pixels (4096x4096) and within an aspect ratio of 6:1 |
| `quality` | `very_low`, `low`, `medium` (default), `high` | Higher tiers cost more and take longer. `very_low` is limited to 4194304 pixels (2048x2048) |
| `background` | `auto` (default), `opaque`, `transparent` | `transparent` returns the image with an alpha channel, `opaque` forces a solid background, `auto` follows the prompt |
| `magic_prompt` | `auto` (default), `on`, `off` | Rewrites the prompt into a detailed structured caption before generating. `off` keeps your wording as literal as possible |
| `seed` | integer | Text to image is not reproducible from the seed alone, because the prompt is rewritten on every run |

The node also outputs `final_prompt`, the structured caption the image was generated from. To reproduce an image, feed that caption back with `magic_prompt` set to `off` and the same seed.

## Image Edit

Edit or combine up to five images with one instruction. `image_1` is the image being edited; images 2 to 5 supply design, material, or color references. Address them in the prompt as `@Image1`, `@Image2`, and so on.

The template builds its instruction with a **Build JSON Prompt** node, so you can mark a region of the image and caption it. Turn on [Nodes 2.0](/interface/nodes-2) if the editor does not appear.

The **Ideogram Edit** node with `ideogram-4.6` adds:

| Input | Values | Effect |
| --- | --- | --- |
| `size` | `auto` (default), `source`, a preset, or `custom` | `auto` picks a canvas of about 2K from the images and the prompt. `source` keeps the size of `image_1`. A preset with a different aspect ratio recomposes the scene. `custom` uses the `width` and `height` below |
| `width`, `height` | 256 to 8192, step 32 | Used only when `size` is `custom`. The two dimensions must stay within 16777216 pixels (4096x4096) and within an aspect ratio of 6:1 |
| `quality` | `very_low`, `low`, `medium` (default), `high` | Higher tiers cost more and take longer |
| `background` | `auto` (default), `opaque`, `transparent` | `transparent` returns the image with an alpha channel |
| `seed` | integer | The same images, prompt, settings, and seed give the same result |

Inputs above 16.7 MP or 8192 pixels per side are scaled down before they are uploaded, and each image must sit between 1:6 and 6:1.

Edit re-renders the whole image, so it can shift the framing and the untouched areas along with the edit. Use Precise Edit when the rest of the picture has to stay exactly as it is.

## Precise Edit

Change only what the prompt asks for. Untouched pixels stay identical, and the output keeps the size of `image_1` unless the source is above 16.7 MP or 8192 pixels per side and no region is set. Accepts up to four reference images beyond the image being edited, or three with a mask.

Precise Edit shares the reference slots, `@Image1` addressing, `quality`, and `seed` controls with Edit. It has no size control: with a region the output keeps the size of `image_1`, and without one a source above 16.7 MP or 8192 pixels per side is scaled down first.

### Edit a single region

Set `context_window` to edit one region at native resolution:

| `context_window` | Extra input | Region that is edited |
| --- | --- | --- |
| `none` | none | The whole image, scaled down above 16.7 MP |
| `auto` (default) | `mask` | The area the mask marks, or the whole image when no mask is connected |
| `custom` | `context_window_bboxes` | One enclosing rectangle around all connected boxes (space between separated boxes is included and may be edited), for example from the **Create Bounding Boxes** node |

A region can be up to 8192 pixels per side and about 16.7 MP, and at most 6:1. With a region, `image_1` itself can be up to 8192x8192 pixels at any aspect ratio, and pixels outside the region are copied through unchanged.

Use it for product recolors, material swaps, and touch-ups that must leave the lighting, background, and framing of the rest of the photo alone.

## Get started

1. Update ComfyUI to the latest version.
2. Open **Workflow** > **Browse Templates** and search for "Ideogram 4.6", or download a workflow above and drag it onto the canvas.
3. Set `model` to `ideogram-4.6` in the node if you started from an Ideogram 4.5 workflow.
