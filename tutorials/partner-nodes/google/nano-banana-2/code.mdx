Comfy Router runs Nano Banana 2 behind one host, one credential and one route. The request body is Google's own native JSON input and the response is their native JSON output, unwrapped, so a call written against the Google API becomes a Router call by changing the host. Create a key at [platform.comfy.org/profile/api-keys](https://platform.comfy.org/profile/api-keys) and export it as `COMFY_API_KEY` before running any snippet.

```python
import os
import uuid

import httpx

response = httpx.post(
    "https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image",
    headers={
        "X-API-Key": os.environ["COMFY_API_KEY"],
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={
        "contents": [
            {
                "role": "user",
                "parts": [
                    {
                        "text": "a single red maple leaf on a plain white background, studio lighting",
                    },
                ],
            },
        ],
        "generationConfig": {
            "responseModalities": ["IMAGE"],
            "imageConfig": {
                "aspectRatio": "1:1",
            },
        },
    },
    timeout=httpx.Timeout(660.0, connect=10.0),
)
response.raise_for_status()
result = response.json()
print("image (base64):", result["candidates"][0]["content"]["parts"][0]["inlineData"]["data"])
```

## Request fields

This is the Gemini `generateContent` body. `contents` is required: a list of turns, each with a `role` and `parts` (text, or `inlineData` with a base64 image and `mimeType` for image editing). Ask for an image with `generationConfig.responseModalities: ["IMAGE"]` and set the shape with `imageConfig.aspectRatio`. `seed` and `safetySettings` are also accepted. This list is a convenience: the authoritative schema is served live, and it is the same document Router validates your call against.

```bash
curl -H "X-API-Key: $COMFY_API_KEY" \
  https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image/openapi.json
```

## Read the result

Router holds the connection until the generation is finished and returns Google's native result. The image (base64) is at `candidates[0].content.parts[0].inlineData.data`:

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [
          {
            "inlineData": {
              "mimeType": "image/png",
              "data": "iVBORw0KGgoAAAANSUhEUgAA..."
            }
          }
        ]
      },
      "finishReason": "STOP"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 12,
    "candidatesTokenCount": 1290
  }
}
```

The image comes back inline as base64 in `inlineData.data`, with its `mimeType` beside it. Decode it and write it to a file; there is no URL to download.
