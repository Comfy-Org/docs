This page shows how to call Google Gemini from your own code. For what the model is and what it does best, see the [Google Gemini overview](/tutorials/partner-nodes/google/gemini). To run it interactively in ComfyUI instead, see the [workflows](/tutorials/partner-nodes/google/gemini/workflow).

<RouterPreviewNotice />

Comfy Router runs both Google Gemini models behind one host, one credential and one route. The request body is Google's own native JSON input and the response is their native JSON output, unwrapped, so a call written against the Google API becomes a Router call by changing the host. Create a key at [platform.comfy.org/profile/api-keys](https://platform.comfy.org/profile/api-keys) and export it as `COMFY_API_KEY` before running any snippet.

## Quick start

The only difference between the variants is the model ID in the path. Pick the tab for the model you want to call.

<Tabs>
  <Tab title="Gemini 3.1 Pro">
**Endpoint:** `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-pro-preview`  **Model ID:** `vertexai/gemini-3.1-pro-preview`

<CodeGroup>
```python
import os
import uuid

import httpx

response = httpx.post(
    "https://api.comfy.org/v2/models/vertexai/gemini-3.1-pro-preview",
    headers={
        "X-API-Key": os.environ["COMFY_API_KEY"],
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={
        "contents": [
            {
                "role": "user",
                "parts": [
                    {
                        "text": "Describe a single red maple leaf on a white background in one sentence.",
                    },
                ],
            },
        ],
        "generationConfig": {
            "temperature": 0.7,
            "maxOutputTokens": 256,
        },
    },
    timeout=httpx.Timeout(660.0, connect=10.0),
)
response.raise_for_status()
result = response.json()
print("text:", result["candidates"][0]["content"]["parts"][0]["text"])
```

```typescript
const response = await fetch("https://api.comfy.org/v2/models/vertexai/gemini-3.1-pro-preview", {
  method: "POST",
  headers: {
    "X-API-Key": process.env.COMFY_API_KEY!,
    "Idempotency-Key": crypto.randomUUID(),
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    contents: [
      {
        role: "user",
        parts: [
          {
            text: "Describe a single red maple leaf on a white background in one sentence.",
          },
        ],
      },
    ],
    generationConfig: {
      temperature: 0.7,
      maxOutputTokens: 256,
    },
  }),
  signal: AbortSignal.timeout(660_000),
});
if (!response.ok) throw new Error(`HTTP ${response.status}`);

const result = (await response.json()) as { candidates: { content: { parts: { text: string }[] } }[] };
console.log("text:", result.candidates[0].content.parts[0].text);
```

```bash
curl https://api.comfy.org/v2/models/vertexai/gemini-3.1-pro-preview \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"contents\": [{\"role\":\"user\",\"parts\":[{\"text\":\"Describe a single red maple leaf on a white background in one sentence.\"}]}], \"generationConfig\": {\"temperature\":0.7,\"maxOutputTokens\":256}}"
```

## Request fields

This is the Gemini `generateContent` body. `contents` is required: a list of turns, each with a `role` (`user` or `model`) and `parts`. A part is `text`, or `inlineData` with base64 content and a `mimeType` to send an image, audio or video alongside the prompt. `systemInstruction` sets the system prompt; `generationConfig` carries `temperature`, `topP`, `topK`, `maxOutputTokens`, `seed`, `stopSequences` and `thinkingConfig`; `tools` declares functions the model may call. This list is a convenience: the authoritative schema is served live, and it is the same document Router validates your call against.

```bash
curl -H "X-API-Key: $COMFY_API_KEY" \
  https://api.comfy.org/v2/models/vertexai/gemini-3.1-pro-preview/openapi.json
```

## Read the result

Router holds the connection until the response is finished and returns Google's native result. The text is at `candidates[0].content.parts[0].text`:

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [
          {
            "text": "A single red maple leaf rests on a plain white background, its edges sharp and its color deep."
          }
        ]
      },
      "finishReason": "STOP"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 18,
    "candidatesTokenCount": 24
  }
}
```
