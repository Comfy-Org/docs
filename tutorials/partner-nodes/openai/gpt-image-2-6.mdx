GPT Image 2.6 is OpenAI's image model family, available in ComfyUI on the **OpenAI GPT Image 2.6** partner node. It comes in two variants:

- **Flare** (`gpt-image-2.6-flare`): returns a draft in seconds and holds the layout together on dense posters and product shots. Use it for concept passes, mood boards and typography-heavy drafts
- **Sunburst** (`gpt-image-2.6-sunburst`): spends its render budget on fine texture, small type and materials, and keeps subjects and lighting consistent across passes. Use it for finished visuals and dense layouts where detail has to hold up

Both variants do text to image and image edit, with up to 16 reference images, an optional annotation layer for local edits, quality levels from `low` to `max`, and a `complexity` control that sets how much the model plans the image before rendering. This node also offers the GPT Image 2.5 variants. GPT Image 2 and GPT Image 1.5 live on the **OpenAI GPT Image** node.

## Getting started

1. Update ComfyUI to 0.44.1 or later
2. In the Node Library, search for **OpenAI GPT Image 2.6** and add the node
3. Set `model` to `gpt-image-2.6-flare` or `gpt-image-2.6-sunburst`
4. Connect the node's image output to a Save Image node, or open one of the four templates below

## Node settings

- **model**: `gpt-image-2.6-flare` for fast iteration, `gpt-image-2.6-sunburst` for detail-first renders
- **prompt**: what to generate, or the edit instruction when reference images are connected
- **size**: `auto`, a preset such as `1024x1024` or `3840x2160`, or `Custom`
- **custom_width / custom_height**: used only when `size` is `Custom`, from 480 to 3840 in steps of 16
- **background**: `auto`, `opaque`, or `transparent`
- **quality**: `low`, `medium`, `high`, `xhigh`, or `max`. Affects cost and generation time
- **complexity**: `low`, `medium`, or `high` (default). How much the model plans the image before rendering
- **images**: optional reference images for editing, up to 16
- **markup / markup_alpha**: optional annotation layer for local edits. Connect a picture drawn over the first reference image to `markup`, and a mask to `markup_alpha` where white marks the areas to change. Connect both or neither, and both must match the reference image's size. The Painter node's mask output fits `markup_alpha` directly
- **seed**: kept for API compatibility, the backend does not use it yet

Flare is the cheaper way to find a prompt that works. Run it at `low` or `medium` quality until the composition holds, then re-run the winning prompt on Sunburst for the final image.

## GPT Image 2.6 GIF: Animated output

The **OpenAI GPT Image 2.6 GIF** node animates a short prompt and returns the frames plus the frame rate. It needs a ComfyUI build newer than 0.44.2. Connect `frames` and `fps` to **Save Animated WEBP**, **Save Animated PNG**, or **Save WEBM** to write the file.

- **model**: `gpt-image-2.6-flare` or `gpt-image-2.6-sunburst`
- **size**: frame size, from `384x384` up to `1280x720` or `720x1280`. Larger frames only fit fewer frames
- **frame_count**: 2 to 16 frames, 9 by default
- **frame_duration_ms**: how long each frame stays on screen, 20 to 2000 ms, 200 by default
- **background**: `opaque` or `transparent`. Transparency survives the animated save nodes and WEBM with vp9
- **quality** and **complexity**: quality of each frame, and how much the model plans the animation

## GPT Image 2.6 SVG: Vector output

The **OpenAI GPT Image 2.6 SVG** node renders a picture, then traces it into scalable vector paths. It needs a ComfyUI build newer than 0.44.2. Connect the SVG output to **Save SVG** to write an editable `.svg` file.

- **model**: `gpt-image-2.6-flare` or `gpt-image-2.6-sunburst`
- **size**: `1024x1024`, `1024x1536`, or `1536x1024`
- **background**: `auto`, `opaque`, or `transparent`
- **quality** and **complexity**: quality of the reference image the SVG is drawn from, and how much the model plans it
