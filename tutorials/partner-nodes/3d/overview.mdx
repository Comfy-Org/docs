## What you can do with 3D models

- **Text-to-3D**: Generate a 3D asset from a text description
- **Image-to-3D**: Reconstruct a textured 3D model from one or more reference images
- **Export**: Download meshes for game engines, DCC tools, and 3D printing pipelines

## Choosing a model by task

### General-purpose 3D generation

- **Tripo P1 / Tripo 3.1** (Tripo) — fast text-to-3D and image-to-3D generation with clean topology
- **Meshy 7 / Meshy 6** (Meshy) — text-to-3D and image-to-3D with stylized and PBR-textured output
- **Hunyuan 3D 3.0** (Hunyuan 3D) — Tencent's 3D generation model

### Image-to-3D reconstruction

- **Rodin Model Generation** (Rodin) — reconstruct detailed 3D models from images, including human and character assets
- **Meshy 7** (Meshy) — image-to-3D with high texture fidelity
