This page shows how to call Flux.1 Kontext from your own code. For what the model is and what it does best, see the [Flux.1 Kontext overview](/tutorials/partner-nodes/black-forest-labs/flux-1-kontext). To run it interactively in ComfyUI instead, see the [workflows](/tutorials/partner-nodes/black-forest-labs/flux-1-kontext/workflow).

<RouterPreviewNotice />

Comfy Router runs both Kontext models behind one host, one credential and one route. The request body is Black Forest Labs' own native JSON input and the response is their native JSON output, unwrapped, so a call written against the BFL API becomes a Router call by changing the host. Create a key at [platform.comfy.org/profile/api-keys](https://platform.comfy.org/profile/api-keys) and export it as `COMFY_API_KEY` before running any snippet.

## Quick start

The only difference between the two variants is the model ID in the path. Pick the tab for the model you want to call.

<Tabs>
  <Tab title="Kontext Pro">
**Endpoint:** `POST https://api.comfy.org/v1/models/bfl/flux-kontext-pro`  **Model ID:** `bfl/flux-kontext-pro`

<CodeGroup>
```python
import base64
import os
import uuid

import httpx

with open("input.jpg", "rb") as f:
    input_image = base64.b64encode(f.read()).decode()

response = httpx.post(
    "https://api.comfy.org/v1/models/bfl/flux-kontext-pro",
    headers={
        "X-API-Key": os.environ["COMFY_API_KEY"],
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={
        "prompt": "replace the background with a sunlit beach, keep the subject unchanged",
        "input_image": input_image,
        "aspect_ratio": "1:1",
    },
    timeout=httpx.Timeout(660.0, connect=10.0),
)
response.raise_for_status()
result = response.json()
print("image:", result["result"]["sample"])
```

```typescript
import { readFile } from "node:fs/promises";

const inputImage = (await readFile("input.jpg")).toString("base64");

const response = await fetch("https://api.comfy.org/v1/models/bfl/flux-kontext-pro", {
  method: "POST",
  headers: {
    "X-API-Key": process.env.COMFY_API_KEY!,
    "Idempotency-Key": crypto.randomUUID(),
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    prompt: "replace the background with a sunlit beach, keep the subject unchanged",
    input_image: inputImage,
    aspect_ratio: "1:1",
  }),
  signal: AbortSignal.timeout(660_000),
});
if (!response.ok) throw new Error(`HTTP ${response.status}`);

const result = (await response.json()) as { result: { sample: string } };
console.log("image:", result.result.sample);
```

```bash
IMG=$(base64 < input.jpg | tr -d '\n')

curl https://api.comfy.org/v1/models/bfl/flux-kontext-pro \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"prompt\": \"replace the background with a sunlit beach, keep the subject unchanged\", \"input_image\": \"$IMG\", \"aspect_ratio\": \"1:1\"}"
```

## Request fields

`prompt` and `input_image` are required. `input_image` is the image to edit, base64 encoded. `aspect_ratio` sets the output ratio between `3:7` and `7:3`; `seed`, `prompt_upsampling`, `safety_tolerance` and `output_format` are the fields you will reach for next. This list is a convenience: the authoritative schema is served live, and it is the same document Router validates your call against.

```bash
curl -H "X-API-Key: $COMFY_API_KEY" \
  https://api.comfy.org/v1/models/bfl/flux-kontext-pro/openapi.json
```

## Read the result

Router holds the connection until the edit is finished and returns BFL's native result. The image URL is at `result.sample`:

```json
{
  "id": "0a1b2c3d-...",
  "status": "Ready",
  "result": {
    "sample": "https://.../out.jpeg",
    "prompt": "replace the background with a sunlit beach, keep the subject unchanged",
    "seed": 1234567890
  }
}
```

The URL is temporary. Download the image promptly if you need to keep it.
