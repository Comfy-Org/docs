<RouterPreviewNotice />

Comfy Router runs FLUX 3 Video behind one host, one credential and one route. The request body is Black Forest Labs' own native JSON input and the response is their native JSON output, unwrapped, so a call written against the Black Forest Labs API becomes a Router call by changing the host. Create a key at [platform.comfy.org/profile/api-keys](https://platform.comfy.org/profile/api-keys) and export it as `COMFY_API_KEY` before running any snippet.

```python Python
import os
import uuid

import httpx

response = httpx.post(
    "https://api.comfy.org/v2/models/bfl/flux-3-video",
    headers={
        "X-API-Key": os.environ["COMFY_API_KEY"],
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={
        "mode": "t2v",
        "prompt": "a single red maple leaf falling onto still water, slow motion",
        "duration": 5,
        "aspect_ratio": "16:9",
        "generate_audio": True,
    },
    timeout=httpx.Timeout(660.0, connect=10.0),
)
response.raise_for_status()
result = response.json()
print("video:", result["result"]["sample"])
```

## Request fields

`mode` is required: `t2v` for text-to-video, `i2v` to continue from one or more images passed in `keyframes` (URLs or base64), or `v2v` to continue a video passed in `start_video`. `prompt` is required in every mode except `draft_enhance`. `duration` is any whole second from 5 to 20 or `auto`; `aspect_ratio` accepts `auto`, `21:9`, `2:1`, `16:9`, `4:3`, `1:1`, `3:4` or `9:16`; `resolution` is `hd` or `fhd`. Router holds the connection for the whole render, so a 20 second clip takes minutes, not seconds. This list is a convenience: the authoritative schema is served live, and it is the same document Router validates your call against.

```bash
curl -H "X-API-Key: $COMFY_API_KEY" \
  https://api.comfy.org/v2/models/bfl/flux-3-video/openapi.json
```

## Read the result

Router holds the connection until the video generation is finished and returns Black Forest Labs' native result. The video is at `result.sample`:

```json
{
  "id": "0a1b2c3d-...",
  "status": "Ready",
  "result": {
    "sample": "https://.../out.mp4"
  }
}
```

`result.sample` is a signed URL that expires roughly two hours after the result is ready. Download the MP4 promptly.
