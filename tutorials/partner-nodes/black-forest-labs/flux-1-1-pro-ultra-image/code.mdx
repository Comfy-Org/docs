API Reference for Flux 1.1 Pro Ultra Image. FLUX 1.1 [pro] is Black Forest Labs' flagship text-to-image model, and its Ultra mode generates images at up to 4MP resolution without slowing down.

## Quick start

Create a key at [platform.comfy.org/profile/api-keys](https://platform.comfy.org/profile/api-keys) and export it as `COMFY_API_KEY`. The Python and TypeScript snippets use the Comfy SDKs (`pip install comfy-sdk`, `npm install @comfyorg/sdk`); the cURL snippet is the same call over raw HTTP.

Pick the model you want to call. Everything below, from the snippets to the schema and examples, follows your choice.

  <Tab title="FLUX 1.1 [pro] Ultra">
**Model ID:** `bfl/flux-pro-1.1-ultra`

**Endpoint:** `POST https://api.comfy.org/v2/models/bfl/flux-pro-1.1-ultra`

<CodeGroup>
```python Python
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment. Each call sends a fresh
# Idempotency-Key and waits up to 10 minutes for the finished result.
with Comfy() as client:
    result = client.models.run(
        "bfl/flux-pro-1.1-ultra",
        {
            "prompt": "a single red maple leaf on a plain white background, studio lighting",
            "aspect_ratio": "16:9",
            "raw": False,
        },
    )

print("image:", result["result"]["sample"])
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Reads COMFY_API_KEY from the environment. Each call sends a fresh
// Idempotency-Key and waits up to 10 minutes for the finished result.
type Result = { result: { sample: string } };
const { data } = await comfy.models.run<Result>("bfl/flux-pro-1.1-ultra", {
  prompt: "a single red maple leaf on a plain white background, studio lighting",
  aspect_ratio: "16:9",
  raw: false,
});

console.log("image:", data.result.sample);
```

```bash cURL
curl https://api.comfy.org/v2/models/bfl/flux-pro-1.1-ultra \

  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"prompt\": \"a single red maple leaf on a plain white background, studio lighting\", \"aspect_ratio\": \"16:9\", \"raw\": false}"
```

<h2>Schema</h2>

<h3>Input</h3>

_Fields follow Black Forest Labs' published API specification and are checked against it in CI. Router's own schema for this model is not published yet, so requests are forwarded to the provider unvalidated._

<ParamField body="prompt" type="string">
  Text description of the image to generate. Optional in the schema (defaults to an empty prompt), required in practice.
</ParamField>

<ParamField body="aspect_ratio" type="string" default="&quot;16:9&quot;">
  Output aspect ratio, from `21:9` to `9:21`.
</ParamField>

<ParamField body="raw" type="boolean" default="false">
  Generate with the less processed, more natural aesthetic.
</ParamField>

<ParamField body="image_prompt" type="string">
  Optional base64 image to blend with the prompt.
</ParamField>

<ParamField body="image_prompt_strength" type="number" default="0.1">
  How strongly `image_prompt` steers the result.

  Range: `0` to `1`
</ParamField>

<ParamField body="seed" type="integer">
  Seed for reproducible results. Omit for random.
</ParamField>

<ParamField body="safety_tolerance" type="integer" default="2">
  Moderation tolerance for inputs and outputs. 0 is strictest.

  Range: `0` to `6`
</ParamField>

<ParamField body="output_format" type="string" default="&quot;jpeg&quot;">
  Format of the returned image.

  Possible values: `jpeg`, `png`, `webp`
</ParamField>

<ParamField body="prompt_upsampling" type="boolean" default="false">
  Rewrite the prompt for richer results. Results are not reproducible when enabled.
</ParamField>
