This page shows how to call Flux 1.1 Pro Ultra Image from your own code. For what the model is and what it does best, see the [Flux 1.1 Pro Ultra Image overview](/tutorials/partner-nodes/black-forest-labs/flux-1-1-pro-ultra-image). To run it interactively in ComfyUI instead, see the [workflows](/tutorials/partner-nodes/black-forest-labs/flux-1-1-pro-ultra-image/workflow).

<RouterPreviewNotice />

Comfy Router runs both Flux 1.1 Pro Ultra Image models behind one host, one credential and one route. The request body is Black Forest Labs' own native JSON input and the response is their native JSON output, unwrapped, so a call written against the Black Forest Labs API becomes a Router call by changing the host. Create a key at [platform.comfy.org/profile/api-keys](https://platform.comfy.org/profile/api-keys) and export it as `COMFY_API_KEY` before running any snippet.

## Quick start

```python Python
import os
import uuid

import httpx

response = httpx.post(
    "https://api.comfy.org/v2/models/bfl/flux-pro-1.1-ultra",
    headers={
        "X-API-Key": os.environ["COMFY_API_KEY"],
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={
        "prompt": "a single red maple leaf on a plain white background, studio lighting",
        "aspect_ratio": "16:9",
        "raw": False,
    },
    timeout=httpx.Timeout(660.0, connect=10.0),
)
response.raise_for_status()
result = response.json()
print("image:", result["result"]["sample"])
```

## Request fields

`prompt` is required for both. Ultra takes `aspect_ratio` (from `21:9` to `9:21`) and `raw` (true for the less processed, more natural look); the standard model takes `width` and `height` in multiples of 32 up to 1440. Both accept `seed`, `safety_tolerance`, `output_format` and an `image_prompt` for image-to-image. This list is a convenience: the authoritative schema is served live, and it is the same document Router validates your call against.

```bash
curl -H "X-API-Key: $COMFY_API_KEY" \
  https://api.comfy.org/v2/models/bfl/flux-pro-1.1-ultra/openapi.json
```

## Read the result

Router holds the connection until the generation is finished and returns Black Forest Labs' native result. The image is at `result.sample`:

```json
{
  "id": "0a1b2c3d-...",
  "status": "Ready",
  "result": {
    "sample": "https://.../out.jpeg",
    "prompt": "a single red maple leaf on a plain white background, studio lighting",
    "seed": 1234567890
  }
}
```

The URL is temporary. Download the image promptly if you need to keep it.
