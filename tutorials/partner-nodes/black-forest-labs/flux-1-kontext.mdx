FLUX.1 Kontext is a professional image-to-image editing model developed by Black Forest Labs, focusing on intelligent understanding of image context and precise editing.
It can perform various editing tasks without complex descriptions, including object modification, style transfer, background replacement, character consistency editing, and text editing.
The core advantage of Kontext lies in its excellent context understanding ability and character consistency maintenance, ensuring that key elements such as character features and composition layout remain stable even after multiple iterations of editing.

Currently, ComfyUI has supported two models of Flux.1 Kontext:

* **Kontext Pro** is ideal for editing, composing, and remixing.
* **Kontext Max** pushes the limits on typography, prompt precision, and speed.

In this guide, we will briefly introduce how to use the Flux.1 Kontext Partner nodes to perform image editing through corresponding workflows.

### Two ways to use it

- **Workflows**: load a ready-made ComfyUI workflow that uses the Flux.1 Kontext Pro or Max Partner node, in ComfyUI or on Comfy Cloud. Best when you want to edit interactively or combine Kontext with other nodes. See the **Workflows** tab.
- **Code**: call the same models over HTTP through Comfy Router with one API key, from Python, TypeScript or cURL. Best when you are integrating Kontext into your own product or pipeline. See the **Code** tab.

Both paths run on the same Comfy account and are billed in the same credits. See [Partner Nodes pricing](/tutorials/partner-nodes/pricing) for per-model rates and [Concurrency limits](/tutorials/partner-nodes/concurrency-limits) for how many requests you can have in flight.

### 2. Complete the Workflow Step by Step

![ComfyUI Flux.1 Kontext Pro Image Partner Nodes Workflow Steps](/images/tutorial/api_nodes/bfl/flux_1_kontext_multiple_image_input_guide.jpg)

You can follow the numbered steps in the image to complete the workflow:

1. Upload the provided images in the `Load image` node
2. Modify the necessary parameters in `Flux.1 Kontext Pro Image`:
    - `prompt` Enter the prompt for the image you want to edit
    - `aspect_ratio` Set the aspect ratio of the original image, which must be between 1:4 and 4:1
    - `prompt_upsampling` Set whether to use prompt upsampling. If enabled, it will automatically modify the prompt to get richer results, but the results are not reproducible
3. Click the `Run` button or use the shortcut `Ctrl(cmd) + Enter` to execute the image editing
4. After waiting for the API to return results, you can view the edited image in the `Save Image` node, and the corresponding image will also be saved to the `ComfyUI/output/` directory

<Tip>
   The subsequent two workflows only differ in the Partner nodes used. In fact, you only need to modify based on the multiple image input workflow, with no significant differences

<RouterPreviewNotice />

Comfy Router runs both Kontext models behind one host, one credential and one route. The request body is Black Forest Labs' own native JSON input and the response is their native JSON output, unwrapped, so a call written against the BFL API becomes a Router call by changing the host. Create a key at [platform.comfy.org/profile/api-keys](https://platform.comfy.org/profile/api-keys) and export it as `COMFY_API_KEY` before running any snippet.

The only difference between the two variants is the model ID in the path. Pick the tab for the model you want to call.

<Tabs>
  <Tab title="Kontext Pro">
**Endpoint:** `POST https://api.comfy.org/v1/models/bfl/flux-kontext-pro`  **Model ID:** `bfl/flux-kontext-pro`

<CodeGroup>
```python
import base64
import os
import uuid

import httpx

with open("input.jpg", "rb") as f:
    input_image = base64.b64encode(f.read()).decode()

response = httpx.post(
    "https://api.comfy.org/v1/models/bfl/flux-kontext-pro",
    headers={
        "X-API-Key": os.environ["COMFY_API_KEY"],
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={
        "prompt": "replace the background with a sunlit beach, keep the subject unchanged",
        "input_image": input_image,
        "aspect_ratio": "1:1",
    },
    timeout=httpx.Timeout(660.0, connect=10.0),
)
response.raise_for_status()
result = response.json()
print("image:", result["result"]["sample"])
```

```typescript
import { readFile } from "node:fs/promises";

const inputImage = (await readFile("input.jpg")).toString("base64");

const response = await fetch("https://api.comfy.org/v1/models/bfl/flux-kontext-pro", {
  method: "POST",
  headers: {
    "X-API-Key": process.env.COMFY_API_KEY!,
    "Idempotency-Key": crypto.randomUUID(),
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    prompt: "replace the background with a sunlit beach, keep the subject unchanged",
    input_image: inputImage,
    aspect_ratio: "1:1",
  }),
  signal: AbortSignal.timeout(660_000),
});
if (!response.ok) throw new Error(`HTTP ${response.status}`);

const result = (await response.json()) as { result: { sample: string } };
console.log("image:", result.result.sample);
```

```bash
IMG=$(base64 < input.jpg | tr -d '\n')

curl https://api.comfy.org/v1/models/bfl/flux-kontext-pro \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"prompt\": \"replace the background with a sunlit beach, keep the subject unchanged\", \"input_image\": \"$IMG\", \"aspect_ratio\": \"1:1\"}"
```

### Request fields

`prompt` and `input_image` are required. `input_image` is the image to edit, base64 encoded. `aspect_ratio` sets the output ratio between `3:7` and `7:3`; `seed`, `prompt_upsampling`, `safety_tolerance` and `output_format` are the fields you will reach for next. This list is a convenience: the authoritative schema is served live, and it is the same document Router validates your call against.

```bash
curl -H "X-API-Key: $COMFY_API_KEY" \
  https://api.comfy.org/v1/models/bfl/flux-kontext-pro/openapi.json
```

### Read the result

Router holds the connection until the edit is finished and returns BFL's native result. The image URL is at `result.sample`:

```json
{
  "id": "0a1b2c3d-...",
  "status": "Ready",
  "result": {
    "sample": "https://.../out.jpeg",
    "prompt": "replace the background with a sunlit beach, keep the subject unchanged",
    "seed": 1234567890
  }
}
```

The URL is temporary. Download the image promptly if you need to keep it.
