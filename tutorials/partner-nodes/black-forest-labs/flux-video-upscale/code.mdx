<RouterPreviewNotice />

Comfy Router runs FLUX Video Upscale behind one host, one credential and one route. The request body is Black Forest Labs' own native JSON input and the response is their native JSON output, unwrapped, so a call written against the Black Forest Labs API becomes a Router call by changing the host. Create a key at [platform.comfy.org/profile/api-keys](https://platform.comfy.org/profile/api-keys) and export it as `COMFY_API_KEY` before running any snippet.

```python Python
import os
import uuid

import httpx

response = httpx.post(
    "https://api.comfy.org/v2/models/bfl/video-upscale-v1",
    headers={
        "X-API-Key": os.environ["COMFY_API_KEY"],
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={
        "input_video": "https://your-host.example/clip.mp4",
        "upscale_factor": 2,
        "creativity": 1,
    },
    timeout=httpx.Timeout(660.0, connect=10.0),
)
response.raise_for_status()
result = response.json()
print("video:", result["result"]["sample"])
```

## Request fields

`input_video` is required: an HTTP(S) URL or a base64-encoded MP4 of at most 20 seconds and 50MB. `upscale_factor` multiplies the resolution (default 2). `creativity` from 0 to 10 sets how much new detail the model is allowed to invent; keep it low to preserve faces and products, raise it for generated footage. An optional `prompt` steers that added detail. This list is a convenience: the authoritative schema is served live, and it is the same document Router validates your call against.

```bash
curl -H "X-API-Key: $COMFY_API_KEY" \
  https://api.comfy.org/v2/models/bfl/video-upscale-v1/openapi.json
```

## Read the result

Router holds the connection until the upscale is finished and returns Black Forest Labs' native result. The video is at `result.sample`:

```json
{
  "id": "0a1b2c3d-...",
  "status": "Ready",
  "result": {
    "sample": "https://.../upscaled.mp4"
  }
}
```

`result.sample` is a signed URL that expires roughly two hours after the result is ready. Download the MP4 promptly.
