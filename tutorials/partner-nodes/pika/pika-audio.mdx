Pika's audio nodes turn a text description into finished audio without a local GPU. **Pika Music** writes a song from a style prompt and optional lyrics, in a length you choose from 10 to 360 seconds, and it can also cover an uploaded song at that song's own length. **Pika SFX** returns a single sound effect of 1 to 20 seconds, which fits foley, UI blips and trailer hits.

Neither node downloads weights. Both run on your Comfy account and are billed in credits like the other partner nodes.

## Pika Music: Text to Music {#api_pika_music}

Write the arrangement, mood and instrumentation into the prompt. Add section-tagged lyrics with tags such as `[Verse]` and `[Chorus]` for a vocal track, or leave the lyrics field empty for an instrumental.

1. Pick `text to music` in the `Pika Music` node and describe the track: genre, tempo, instruments and mood.
2. Set `duration` between 10 and 360 seconds. Turn on `rewrite_prompt` if you only have a short idea and want the model to expand it first.
3. Run the workflow. `Save Audio (Advanced)` writes an MP3 to `ComfyUI/output/audio/`.

Switch the same node's mode to `cover` to restyle an existing song instead. Connect an audio file to `source_audio`, describe the new style, and the result keeps the source length, clamped to 5 to 360 seconds.

## Pika SFX: Text to Sound Effects {#api_pika_sfx}

Name the material, the action, the space and the intensity in one line. A close, dry description reads better than a list of adjectives.

1. Write the sound in the `Pika SFX` prompt, for example an old timber door creaking open on rusty hinges, then a heavy latch clicking shut.
2. Set `duration` between 1 and 20 seconds, then run the workflow. The MP3 lands in `ComfyUI/output/audio/`.

Each run produces one mono sound effect. For a sequence of sounds, run the node once per sound and place them on the timeline yourself.
