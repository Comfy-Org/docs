Chatterbox is an open-source text-to-speech family from [Resemble AI](https://github.com/resemble-ai/chatterbox). It clones a voice from a few seconds of reference audio, then speaks whatever text you write in that voice. The multilingual model does the same in 23 languages, and a separate node re-speaks an existing recording in another voice while keeping its timing.

ComfyUI ships four Chatterbox templates: **Chatter Box: Voice Cloning with TTS**, **Chatter Box: Multilingual Text-to-Speech with Voice Cloning**, **Chatter Box: Voice Cloning Audio Conversion**, and **Chatter Box: Multi-Speaker Conversation with Cloned Voices**. Each one runs on the [FL ChatterBox](https://github.com/filliptm/ComfyUI_Fill-ChatterBox) custom node pack, which downloads the model weights on first run into `ComfyUI/models/chatterbox/`.

<UpdateReminder/>

<Note>
Install the FL ChatterBox pack before running these templates: open **ComfyUI Manager**, search for **FL ChatterBox**, and install it, or follow [Install custom nodes](/installation/install_custom_node). The templates need ComfyUI 0.25.0 or later. Chatterbox runs on CUDA, Apple MPS, and CPU.
</Note>

The output is saved as FLAC.

## Notes

- Reference clips of 5 to 10 seconds of clean single-speaker speech give the most reliable clone. Background noise degrades the clone.
- Each generation is limited to roughly 40 seconds of audio. Split longer scripts into several runs.
- The first run downloads the model weights into `ComfyUI/models/chatterbox/`, so it takes longer than later runs.
