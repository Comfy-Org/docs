Большинство сбоев Comfy CLI связаны с отсутствующим требованием или пропущенным шагом настройки. Перед тем как сообщить о проблеме, проверьте пункты ниже.

## Требования

Comfy CLI требует установленного в системе [git](https://git-scm.com/downloads). Установите его заранее, чтобы `comfy install` и `comfy update` могли клонировать ComfyUI и его пользовательские узлы.

## Установить ComfyUI в виртуальное окружение

`comfy install` устанавливает ComfyUI в активное окружение Python, которое должно быть Python 3.10 или новее. Создайте и активируйте виртуальное окружение перед запуском:

```bash
python3 -m venv comfy-env
source comfy-env/bin/activate
comfy install
```

## Установить сборку PyTorch, подходящую для вашей GPU

`comfy install` спрашивает, какая у вас GPU, и устанавливает подходящую сборку PyTorch. Ответьте на запрос или передайте флаг GPU, чтобы команда выполнилась без участия пользователя:

| Платформа | Что устанавливает `comfy install` | Что ещё нужно |
| --- | --- | --- |
| NVIDIA | PyTorch со средой выполнения CUDA (pip wheel) | Актуальный драйвер GPU (не полный CUDA Toolkit) |
| AMD Linux | PyTorch wheels с ROCm | Драйвер и стек AMD с поддержкой ROCm для этих wheels |
| AMD Windows | `torch-directml` | ComfyUI больше не поддерживает DirectML. Установите вместо этого сборку PyTorch с ROCm; для неё нужна AMD GPU RDNA 2 или новее (см. [системные требования](/ru/installation/system_requirements)) |
| Apple silicon | Ночные wheels PyTorch (индекс CPU; Metal/MPS) | macOS на Apple silicon |
| Intel Arc | PyTorch wheels с XPU | Совместимая Intel Arc GPU / стек XPU |
| CPU | PyTorch wheels для CPU | Дискретная GPU не требуется |

```bash
comfy install --nvidia
```

Передайте `--skip-torch-or-directml`, если вы устанавливаете PyTorch самостоятельно. `comfy env` выводит окружение Python и рабочее пространство, которое использует ComfyUI.

## Настроить Comfy Cloud без браузера

`comfy setup` выполняет вход через браузер, поэтому не может завершиться в CI, devcontainer или на сервере без графического интерфейса. Передайте API-ключ и запустите в неинтерактивном режиме:

```bash
comfy setup --where cloud --api-key comfyui-... --non-interactive
```
