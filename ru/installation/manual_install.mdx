Установка ComfyUI в основном состоит из нескольких шагов:
1. Создать виртуальное окружение (чтобы не загрязнять системное окружение Python)
2. Клонировать репозиторий с кодом ComfyUI
3. Установить зависимости
4. Запустить ComfyUI

Также можно обратиться к [ComfyUI CLI](/ru/comfy-cli/getting-started), чтобы установить ComfyUI. Это инструмент командной строки, который позволяет легко установить ComfyUI и управлять его зависимостями.

## Создать виртуальное окружение

<Tip>
    Независимые виртуальные окружения необходимы, поскольку зависимости ComfyUI могут конфликтовать с другими зависимостями в системе, а также это позволяет не засорять системное окружение Python.
</Tip>

## Клонирование репозитория с кодом ComfyUI

Убедитесь, что в вашей системе установлен [Git](https://git-scm.com/downloads). Сначала откройте терминал (командную строку), затем склонируйте репозиторий с кодом.
<Tabs>
<Tab title="Windows">
<Warning>Если вы не установили Microsoft Visual C++ Redistributable, установите его [здесь.](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)</Warning>
</Tab>
<Tab title="Linux">
Откройте приложение Terminal.
</Tab>
<Tab title="MacOS">
Откройте [приложение Terminal](https://support.apple.com/guide/terminal/open-or-quit-terminal-apd5265185d-f365-44cb-8b09-71a064a42125/mac).
</Tab>
</Tabs>

```bash
git clone https://github.com/Comfy-Org/ComfyUI.git
```

## Как обновить ComfyUI

<Steps>
    <Step title="Получить последнюю версию кода">
    С помощью командной строки перейдите в каталог установки ComfyUI, затем получите последнюю версию кода.
    ```bash
    cd <installation path>/ComfyUI
    git pull
    ```
    </Step>
    <Step title="Установить зависимости">
    С помощью командной строки перейдите в каталог установки ComfyUI, затем установите зависимости.
    <Warning>
    Необходимо убедиться, что текущая среда Python является виртуальной средой ComfyUI, иначе зависимости будут установлены в системную среду Python, что приведёт к её загрязнению.
    </Warning>
    ```bash
        pip install -r requirements.txt
    ```
    </Step>
</Steps>

### Как остановить ComfyUI или выйти из него

Нажмите **Ctrl+C** в окне терминала, где запущен ComfyUI, или просто закройте окно терминала.
