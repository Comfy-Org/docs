Мы уже рассказывали об обновлении ComfyUI для разных способов установки в отдельных разделах, а это подробное руководство объединяет все процедуры обновления, чтобы вы могли чётко понять, как обновить ComfyUI.

## Как обновить ComfyUI?

<Tabs>
<Tab title="Portable">
 ComfyUI Portable предоставляет удобные пакетные скрипты для простого обновления.

 ### Расположение скриптов обновления
 В папке `update` в каталоге вашей portable-установки вы найдёте следующие скрипты обновления:

 ```
 ComfyUI_windows_portable
 └─ 📂update
    ├── update.py
    ├── update_comfyui.bat                           // Обновление до последней версии для разработки
    ├── update_comfyui_stable.bat                    // Обновление до последней стабильной версии
    └── update_comfyui_and_python_dependencies.bat   // ⚠️ ОПАСНО: Переустанавливает зависимости, может вызвать конфликты
```
<Warning>Во время обновления обеспечьте стабильное интернет-соединение.</Warning>

<Warning>
**⚠️ ОПАСНО: используйте `update_comfyui_and_python_dependencies.bat` с крайней осторожностью!**

Этот скрипт работает тщательнее обычного обновления и выполнит следующее:
- ✅ Обновит сам код ComfyUI
- ✅ Обновит PyTorch для **стандартного Nvidia portable** (сейчас **CUDA 13.0 / cu130**, Python 3.13)
- ✅ Переустановит ВСЕ зависимости Python

**Классический Nvidia portable (CUDA 12.6 / cu126):** если вы установили отдельный portable-пакет для видеокарт Nvidia **10-й серии и старше**, эта сборка использует **CUDA 12.6** и Python 3.12. Не считайте cu130 правильной целью для этого пакета: переустановите или обновите PyTorch с индексом колёс cu126, соответствующим этому portable, либо заново скачайте пакет cu126 из [руководства по portable-установке](/ru/installation/comfyui_portable_windows).

**Риски:**
- Может вызвать конфликты зависимостей с вашей текущей конфигурацией
- Может сломать пользовательские узлы, которые зависят от определённых версий пакетов
- Может перезаписать пакеты, настроенные вручную
- На portable с cu126 (или другой сборке, отличной от cu130) принудительная установка колеса cu130 может нарушить запуск GPU

**⚠️ Используйте этот скрипт только когда:**
- Вам нужно исправить проблемы с зависимостями
- Вы выполняете обновление до мажорной версии
- Для повседневных обновлений используйте `update_comfyui.bat`

**Перед запуском этого скрипта:**
1. **Сделайте резервную копию всей установки ComfyUI**
2. Запишите версии пользовательских пакетов, которые вы установили
3. Подтвердите, какой portable-пакет у вас установлен (стандартный cu130 или классический cu126). См. [ComfyUI Portable для Windows](/ru/installation/comfyui_portable_windows)
4. Будьте готовы при необходимости переустановить пользовательские узлы
</Warning>
</Tab>
<Tab title="Desktop">
Чтобы обновить ComfyUI, откройте [панель управления](/ru/installation/desktop/usage/instance-management#update-comfyui) и используйте вкладку Update. Вы можете выбрать канал обновлений **Stable** (по умолчанию) или **Latest on GitHub**.

Само приложение Desktop обновляется автоматически и отдельно от обновлений экземпляра ComfyUI.
</Tab>
<Tab title="Ручная установка">
Для ComfyUI, установленного вручную, для выполнения обновлений требуются команды Git.

### Требования перед обновлением
Убедитесь, что в вашей системе установлен [Git](https://git-scm.com/downloads), а ComfyUI был установлен через клонирование Git.

### Шаги обновления
<Steps>
<Step title="Активировать виртуальное окружение">
Сначала активируйте виртуальное окружение Python для ComfyUI (если вы его используете):
```bash
# Для окружения conda
conda activate comfyui

# Для окружения venv
# Windows
venv\Scripts\activate
# macOS/Linux  
source venv/bin/activate
```
</Step>
<Step title="Получить последний код">
Перейдите в каталог установки ComfyUI и получите последний код:
```bash
cd <ComfyUI-installation-path>
git pull
```
</Step>
<Step title="Обновить зависимости">
Установите или обновите пакеты зависимостей ComfyUI:
```bash
pip install -r requirements.txt
```
<Warning>
Убедитесь, что вы находитесь в виртуальном окружении ComfyUI, чтобы не загрязнять системное окружение Python
</Warning>
</Step>
<Step title="Перезапустить ComfyUI">
После обновления перезапустите ComfyUI:
```bash
python main.py
```
</Step>
</Steps>

### Переключение версий (необязательно)
Чтобы переключиться на определённую версию, используйте следующие команды:
```bash
# Просмотреть историю коммитов
git log --oneline

# Переключиться на определённый коммит
git checkout <commit-hash>

# Вернуться к последней версии
git checkout master
```
<Tip>Для получения последних функций и исправлений безопасности рекомендуется регулярно обновляться, а для стабильности системы лучше подходят стабильные версии</Tip>
</Tab>
</Tabs>

## Что нужно обновлять при обновлении ComfyUI?

Обновление ComfyUI состоит в основном из двух компонентов:
1. Обновление основного кода ComfyUI
2. Обновление основных зависимостей ComfyUI, включая необходимые зависимости Python и функциональные пакеты зависимостей ComfyUI

**Основной код**: новые узлы, поддержка новых моделей, новые функции и т. д.
**Основные зависимости**: в основном включают функциональность фронтенда ComfyUI, шаблоны рабочих процессов, документацию по узлам и т. д.

```
comfyui-frontend-package   # функциональность фронтенда ComfyUI
comfyui-workflow-templates # шаблоны рабочих процессов ComfyUI
comfyui-embedded-docs      # документация по узлам ComfyUI
comfy-kitchen              # основные утилиты ComfyUI
comfy-aimdo                # основные утилиты ComfyUI
```

Эти основные зависимости поддерживаются в отдельных репозиториях:
- [ComfyUI_frontend](https://github.com/Comfy-Org/ComfyUI_frontend/) - интерфейс фронтенда и интерактивные функции
- [workflow_templates](https://github.com/Comfy-Org/workflow_templates) - готовые шаблоны рабочих процессов
- [comfyui-embedded-docs](https://github.com/Comfy-Org/embedded-docs) - документация по узлам
- [comfy-kitchen](https://github.com/Comfy-Org/comfy-kitchen) - библиотека быстрых ядер для вывода Diffusion с поддержкой нескольких вычислительных бэкендов
- [comfy-aimdo](https://github.com/Comfy-Org/comfy-aimdo) - AI Model Demand Offloading Allocator

Важно понимать разницу между версиями для разработки (nightly) и стабильными (release):
- **Версия для разработки (nightly)**: код последнего коммита, даёт доступ к новейшим функциям, но может содержать потенциальные проблемы
- **Стабильная версия (release)**: собрана на основе стабильных релизов, обычно отстаёт от версий для разработки, но обеспечивает более высокую стабильность. Мы поддерживаем стабильные версии после того, как функции протестированы и стабилизированы

Многие пользователи при обновлении обнаруживают, что находятся на release-версиях или на канале **Stable** по умолчанию в Desktop, а нужные функции доступны только в сборках для разработки / nightly. В **Desktop** переключитесь на **Latest on GitHub** в разделе [Manage → Update](/ru/installation/desktop/usage/instance-management#update-comfyui). Для портативных или ручных установок проверьте, соответствует ли ваш локальный `ComfyUI/requirements.txt` [зависимостям nightly-версии](https://github.com/Comfy-Org/ComfyUI/blob/master/requirements.txt), чтобы определить, поддерживают ли все зависимости последние функции.

## Типичные проблемы при обновлении

### Отсутствует или устарел фронтенд, шаблоны рабочих процессов, узлы после обновлений


<Tabs><Tab title="Зависимости не обновлены должным образом">
    Пользователи часто используют только команду `git pull` для обновления кода ComfyUI, но **пренебрегают обновлением ключевых зависимостей**, что приводит к следующим проблемам:

  - Отсутствующие или некорректно работающие функции интерфейса
  - Не удаётся найти недавно добавленные шаблоны рабочих процессов
  - Устаревшая или отсутствующая документация по узлам
  - Новые функции не имеют соответствующей поддержки в интерфейсе

  После использования команды `git pull` примените соответствующее окружение ComfyUI и выполните `pip install -r requirements.txt`, чтобы обновить зависимости.
  </Tab><Tab title="Сбои при обновлении зависимостей">
    Если обновление зависимостей завершается неудачно, обычно это связано с проблемами сети или разрешений компьютера. Когда во время обновления возникают сбои основных зависимостей, система откатывается к более старым версиям. При запуске вы обычно увидите в логах примерно следующее:
    ```
    Falling back to the default frontend.
    ComfyUI frontend version: xxx
    ```

    Выполните следующие шаги по устранению неполадок:
    1. Используйте `pip list` в соответствующем окружении, чтобы просмотреть установленные пакеты зависимостей. Если вы обнаружите несоответствия версий, выполните `pip install -r requirements.txt` в окружении ComfyUI, чтобы повторить попытку обновления зависимостей.
    2. Если после обновления проблемы сохраняются, проверьте сетевое подключение. Пользователям в материковом Китае может потребоваться настроить прокси для надёжного доступа к репозиториям GitHub.
    3. Если проблемы не исчезли, проверьте разрешения компьютера. Если требуются права администратора, запустите командную строку с правами администратора.
  </Tab>
</Tabs>

### Как правильно обновить основные зависимости

<UpdateRequirement/>

### Устранение неполадок при обновлении основных зависимостей {#core-dependency-update-troubleshooting}

Если обновление основных зависимостей завершается неудачно, выполните следующие шаги:

<Steps>
  <Step title="Проверить подключение к сети">
    Если вы находитесь в материковом Китае, убедитесь, что у вас есть доступ к PyPI, или настройте местное зеркало:
    ```bash
    # Использование зеркала Университета Цинхуа
    pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
    ```
  </Step>
  <Step title="Установить основные пакеты по отдельности">
    Если пакетная установка завершается неудачно, попробуйте устанавливать пакеты по одному. **Сначала проверьте требования к версиям в `ComfyUI/requirements.txt`**:

    **Затем установите в соответствии с указанными версиями (используйте номера версий из вашего requirements.txt):**
    ```bash
    pip install comfyui-frontend-package==<version> 
    pip install comfyui-workflow-templates==<version>
    pip install comfyui-embedded-docs==<version>
    pip install comfy-kitchen==<version>
    pip install comfy-aimdo==<version>
    ```
    <Warning>
    Рекомендуется использовать точные номера версий, указанные в `ComfyUI/requirements.txt`. Не обновляйте до последних версий самостоятельно, так как это может вызвать проблемы совместимости.
    </Warning>
  </Step>
</Steps>

### Почему после обновления не удаётся найти новые функции?

Это одна из самых частых проблем:
- Если вы используете **Desktop** на канале обновлений **Stable**, функции могут отставать от новых коммитов на GitHub. Переключите канал на **Latest on GitHub** на вкладке [Manage → Update](/ru/installation/desktop/usage/instance-management#update-comfyui), когда вам нужны новые функции (Latest может быть менее стабильным).
- Для Portable или ручной установки, когда вам нужны самые новые коммиты, убедитесь, что вы используете **версию разработки (nightly)**, а не **стабильную версию (release)**.

Кроме того, убедитесь, что в процессе обновления соответствующие зависимости были успешно обновлены. Если после обновления проблемы сохраняются, обратитесь к разделу [Устранение неполадок при обновлении зависимостей](#типичные-проблемы-при-обновлении), чтобы диагностировать проблемы.

### Как переключиться между версией разработки (Nightly) и стабильной версией (Release)?

Различия между версиями:

<Tabs>
  <Tab title="Версия разработки (Nightly)">
    - **Характеристики**: содержит код последнего коммита
    - **Преимущества**: позволяет первыми оценить новые функции и улучшения
    - **Риски**: могут присутствовать невыявленные ошибки или нестабильные факторы
    - **Подходит для**: разработчиков, тестировщиков, пользователей, желающих опробовать новые функции
  </Tab>
  <Tab title="Стабильная версия (Release)">
    - **Характеристики**: проверенный и подтверждённый стабильный код
    - **Преимущества**: высокая стабильность, подходит для production-сред
    - **Недостатки**: обновления функций задерживаются, могут отставать от версий разработки на недели или месяцы
    - **Подходит для**: пользователей, которым нужна стабильность, и пользователей production-сред
  </Tab>
</Tabs>

<Tabs>
  <Tab title="Portable">
    Используйте `update_comfyui.bat` вместо `update_comfyui_stable.bat`:
    ```
    # Версия разработки (новейшие функции)
    double-click: update_comfyui.bat
    
    # Стабильная версия
    double-click: update_comfyui_stable.bat
    ```
  </Tab>
  <Tab title="Ручная установка">
    ```bash
    # Переключиться на версию разработки
    git checkout master
    git pull
    
    # Переключиться на последнюю стабильную версию
    git fetch --tags
    git checkout $(git describe --tags `git rev-list --tags --max-count=1`)
    ```
  </Tab>
  <Tab title="Desktop">
    Откройте [панель Manage](/ru/installation/desktop/usage/instance-management#update-comfyui) и переключите канал на вкладке Update:
    - **Stable** (по умолчанию): проверенные релизы, могут отставать от новых коммитов на GitHub
    - **Latest on GitHub**: отслеживает новые коммиты на GitHub; может быть менее стабильным

    Используйте **Switch Channel**, **Update Now** или **Copy & Update** в зависимости от того, есть ли для выбранного канала более новая сборка. Подробности на странице [вкладки Update панели Manage](/ru/installation/desktop/usage/instance-management#update-comfyui).
  </Tab>
</Tabs>

### Что делать, если после обновления возникают ошибки?

1. **Проверьте зависимости**: выполните `pip install -r requirements.txt`, чтобы убедиться, что все зависимости обновлены
2. **Проверьте пользовательские узлы**: некоторые пользовательские узлы могут быть несовместимы с новыми версиями
3. **Откатите версию**: если проблемы серьёзны, можно откатиться к предыдущей стабильной версии

Если возникли проблемы, обратитесь к странице устранения неполадок, чтобы найти решения.
