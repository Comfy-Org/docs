**Comfy Desktop** представляет собой менеджер с поддержкой нескольких установок, который позволяет запускать несколько экземпляров ComfyUI из одного лаунчера. В этом руководстве описано, как установить и удалить Comfy Desktop в Windows.

## Системные требования

- **ОС:** Windows 10 или более поздняя версия
- **Архитектура:** x64 или ARM64
- **Видеокарта:** для хорошей производительности рекомендуется дискретная видеокарта (NVIDIA / AMD), но она не обязательна
- **Место на диске:** рекомендуется не менее 4.85 ГБ на одну установку

## Установка

Запустите скачанный установщик `.exe` (установщик NSIS) и следуйте подсказкам. После установки запустите Comfy Desktop из меню «Пуск» или с ярлыка на рабочем столе.

![Установка Windows](/images/desktop/installation/windows_1_install.png)
При первом открытии приложения мастер первого запуска спросит, как вы хотите запускать Comfy: в Comfy Cloud или локально на этом компьютере. Доступные варианты описаны в разделе [Подтвердить экран настройки](/ru/installation/desktop/overview#подтвердить-экран-настройки).

## Удаление

### Удалить приложение Comfy Desktop

1. Перейдите в **Параметры → Приложения → Установленные приложения**
2. Найдите **Comfy Desktop** и нажмите **Удалить**

![Удаление Comfy Desktop в Windows](/images/desktop/installation/windows_2_uninstall.png)

### Что не удаляется вместе с приложением

При удалении Comfy Desktop удаляется только само приложение-лаунчер. Следующие данные **не** удаляются, и их нужно удалить вручную, если вы хотите полностью очистить систему:

| Данные | Расположение по умолчанию | Описание |
|------|-----------------|-------------|
| Установки | `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Installs` | Каждая созданная вами установка ComfyUI (их также можно удалить из самого приложения). Пользовательские пути установки тоже не удаляются. Старые установки могут по-прежнему находиться в `%USERPROFILE%\ComfyUI-Installs`. |
| Общие модели и выходы | `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared` | Общая библиотека моделей, каталоги входов и выходов. Старые установки могут по-прежнему использовать `%USERPROFILE%\ComfyUI-Shared`. |
| Настройки приложения и реестр | `%APPDATA%\Comfy Desktop` | Настройки и записи об установках |
| Логи | `%APPDATA%\Comfy Desktop\logs` | Логи десктопного приложения (`app.log`) |

<Warning>Перечисленные выше каталоги содержат ваши **личные данные ComfyUI** (модели, выходы, настройки и установки). Это **не** файлы приложения Comfy Desktop. Их удаление безвозвратно удалит ваши данные.</Warning>

Чтобы удалить всё полностью:

1. **Удалите папку данных приложения**: `%APPDATA%\Comfy Desktop`
2. **Удалите отдельные установки** из самого приложения или вручную удалите `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Installs` (или `%USERPROFILE%\ComfyUI-Installs`, если установки были созданы там). Также удалите все настроенные вами пользовательские каталоги установки
3. **Удалите общую библиотеку моделей** в `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared` (или `%USERPROFILE%\ComfyUI-Shared`), только если эти файлы вам больше не нужны
