**Comfy Desktop** может работать на Linux. Официальные пакеты `.deb` (Debian/Ubuntu) и AppImage распространяются через [репозиторий Comfy Desktop](https://github.com/Comfy-Org/Comfy-Desktop). Скачать их можно по [универсальной ссылке для скачивания](https://dl.todesktop.com/241130tqe9q3y), которая автоматически определяет вашу платформу. Большинству пользователей стоит использовать один из этих пакетов. Если вы хотите запустить приложение из исходников, клонируйте репозиторий и выполните шаги ниже.

## Системные требования

- **ОС:** Linux (рекомендуется Ubuntu 22.04 или более поздняя версия)
- **Архитектура:** x64
- **Node.js:** v24 LTS или более поздняя версия (только при сборке из исходников)
- **pnpm:** v10 или более поздняя версия, включённый через Corepack (только при сборке из исходников)
- **Инструменты сборки:** `build-essential` и `git` (только при сборке из исходников)
- **GPU:** рекомендуется выделенный GPU (NVIDIA / AMD), но это не обязательно
- **Место на диске:** рекомендуется не менее 4.85 GB на каждую установку ComfyUI

## Установить официальный пакет

Скачайте пакет для Linux по [универсальной ссылке для скачивания](https://dl.todesktop.com/241130tqe9q3y) (она автоматически определяет вашу платформу), затем установите его:

```bash
sudo apt install ./*.deb
```

Пакет `.deb` устанавливает Comfy Desktop в `/opt/Comfy Desktop` и во время установки добавляет источник APT для репозитория пакетов Comfy Desktop, поэтому последующие выпуски приходят через менеджер пакетов вашей системы. См. [Обновление](#updating).

Если AppArmor включён и его парсер принимает встроенный профиль (Ubuntu 24.04 и новее, где непривилегированные пространства имён пользователей ограничены), пакет также устанавливает профиль AppArmor для приложения в `/etc/apparmor.d/comfyui-desktop-2`. Поэтому песочница Electron работает на таких системах без дополнительных флагов. Более старые дистрибутивы пропускают профиль, так как их AppArmor не может его загрузить, и песочница работает там и без него. Там, где непривилегированные пространства имён пользователей вообще не работают, пакет вместо этого устанавливает бит setuid для своего помощника `chrome-sandbox`.

Чтобы проверить, был ли установлен профиль:

```bash
ls /etc/apparmor.d/comfyui-desktop-2
```

Скрипты установки пакета записывают профиль при каждой установке или обновлении пакета. Если вы установили `.deb` на Ubuntu 22.04, а затем обновили систему до 24.04, запустите скрипты установки снова:

```bash
sudo apt reinstall comfyui-desktop-2
```

Для AppImage сначала установите FUSE 2. AppImage загружает `libfuse.so.2`, который Ubuntu не устанавливает по умолчанию:

- Ubuntu 24.04 и новее: `sudo apt install libfuse2t64`
- Ubuntu 22.04: `sudo apt install libfuse2`

Затем сделайте его исполняемым и запустите:

```bash
chmod +x ./*.AppImage
./*.AppImage
```

AppImage не запускает скрипты установки пакетов, поэтому он не добавляет ни профиль AppArmor, ни источник APT. При запуске из меню приложения уже передаётся `--no-sandbox`. Если вы запускаете файл напрямую и он не запускается, возможно, ваш дистрибутив блокирует песочницу Electron, поэтому добавьте флаг:

```bash
./*.AppImage --no-sandbox
```

Этот флаг отключает песочницу Electron для всех процессов, поэтому используйте его, только если запуск с песочницей не удаётся.

## Собрать и запустить из исходников

Эти шаги соответствуют разделу [Development](https://github.com/Comfy-Org/Comfy-Desktop#development) в README репозитория.

### Предварительные требования

Сначала установите инструменты сборки и git. В свежей установке Ubuntu их нет, а `pnpm run init` компилирует нативные модули, такие как `node-pty`, и завершается с ошибкой `Error: not found: make`, если `build-essential` отсутствует:

```bash
sudo apt install build-essential git
```

Затем установите Node.js 24 и включите pnpm:

```bash
nvm install 24 && nvm use 24
corepack enable
```

Файл `.nvmrc` в репозитории фиксирует точную версию. Если вы не используете nvm, установите Node.js 24 с [nodejs.org](https://nodejs.org/).

### Клонировать и установить

```bash
git clone https://github.com/Comfy-Org/Comfy-Desktop.git
cd Comfy-Desktop
pnpm run init
```

`pnpm run init` устанавливает зависимости и собирает встроенный bootstrap Python.

### Запустить приложение

```bash
./linux-dev.sh
```

Эта команда запускает Comfy Desktop в режиме разработки. Скрипт задаёт `ELECTRON_DISABLE_SANDBOX=1`, поскольку песочница Electron часто не работает в средах разработки Linux.

## Обновление

Обновление Comfy Desktop зависит от того, как вы его установили.

### Установка из .deb

Установка `.deb` также добавляет APT-источник (`/etc/apt/sources.list.d/comfyui-desktop-2.sources`) и запись unattended-upgrades для него, поэтому новые релизы приходят вместе с вашими обычными обновлениями системы:

```bash
sudo apt update
sudo apt upgrade
```

Вам не нужно скачивать `.deb` заново для каждого выпуска. `sudo apt remove comfyui-desktop-2` оставляет источник APT на диске; `sudo apt purge comfyui-desktop-2` удаляет его вместе с записью unattended-upgrades.

### AppImage

AppImage обновляется самостоятельно: Comfy Desktop загружает новую сборку и заменяет файл `.AppImage`, который вы запустили, поэтому храните его в папке, доступной для записи вашей учётной записи. Если файл находится в месте, доступном только для чтения, обновление не сможет его заменить.

### Получение исходного кода

В приложении нет автообновления, если оно установлено из исходного кода. Получите последнюю версию кода и снова запустите приложение:

```bash
git pull
pnpm run init
./linux-dev.sh
```

## Необязательно: локальный пакет

Чтобы самостоятельно собрать локальный `.deb` или AppImage (а не официальную загрузку Comfy Org):

```bash
pnpm run build:linux
```

Артефакты сборки попадут в `dist/`. Если AppImage не запускается, потому что Chromium не может создать песочницу, повторите попытку с `--no-sandbox`. Этот флаг отключает песочницу Electron для всех процессов.

## Удалить оставшиеся данные

Удаление приложения и удаление ваших данных: это отдельные шаги. Сначала удалите приложение:

- **`.deb`**: `sudo apt remove comfyui-desktop-2`. При удалении также стирается профиль AppArmor по пути `/etc/apparmor.d/comfyui-desktop-2`. Используйте `sudo apt purge comfyui-desktop-2`, чтобы удалить также источник APT и запись unattended-upgrades.
- **AppImage**: удалите файл `.AppImage`.

Ни то, ни другое не затрагивает ваши установки ComfyUI или данные приложения. Удаляйте эти папки, только если хотите полностью всё очистить:

| Данные | Расположение по умолчанию | Описание |
|------|-----------------|-------------|
| Установки | `~/ComfyUI-Installs` | Каждая созданная вами установка ComfyUI (их также можно удалить из приложения). Пользовательские пути установки тоже не удаляются. |
| Общие модели и выходы | `~/ComfyUI-Shared` | Общая библиотека моделей, каталоги входов и выходов |
| Конфигурация приложения | `~/.config/comfyui-desktop-2` | Настройки (`settings.json`) |
| Данные приложения | `~/.local/share/comfyui-desktop-2` | Постоянные данные приложения, включая список установок (`installations.json`) |
| Кэш | `~/.cache/comfyui-desktop-2` | Кэш загрузок и другие неосновные файлы |
| Состояние | `~/.local/state/comfyui-desktop-2` | Состояние выполнения, например блокировки портов |
| Логи | `~/.config/Comfy Desktop/logs` (`~/.config/comfyui-desktop-2/logs` при клонировании исходников) | Логи десктопного приложения (`app.log`) |

Чтобы полностью всё удалить:

1. **Удалите клон** `Comfy-Desktop`
2. **Удалите папку конфигурации**: `~/.config/comfyui-desktop-2`
3. **Удалите папки данных, кэша и состояния**: `~/.local/share/comfyui-desktop-2`, `~/.cache/comfyui-desktop-2` и `~/.local/state/comfyui-desktop-2`
4. **Удалите отдельные установки** из приложения или вручную удалите `~/ComfyUI-Installs` вместе с любыми настроенными пользовательскими каталогами установки
5. **Удалите общую библиотеку моделей** в `~/ComfyUI-Shared` (только если эти файлы больше не нужны)

Пакетные установки (`.deb` или AppImage) также хранят профиль приложения и логи в `~/.config/Comfy Desktop`. Чтобы очистить всё это, запустите скрипт [reset-linux.sh](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/scripts/reset-linux.sh) из репозитория. Он удаляет папки конфигурации, кэша, данных и состояния приложения для текущей сборки и для ранее использовавшихся названий приложения, а `~/ComfyUI-Installs` и `~/ComfyUI-Shared` оставляет нетронутыми. Список установок удаляется вместе с ними, поэтому вам, возможно, придётся заново добавить свои установки с помощью **Add Existing Instance**.
