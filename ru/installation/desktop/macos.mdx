**Comfy Desktop** — это менеджер нескольких установок, который позволяет запускать несколько экземпляров ComfyUI из одного лаунчера. В этом руководстве описано, как установить и удалить Comfy Desktop на macOS.

## Системные требования

- **ОС:** macOS 13 (Ventura) или новее
- **Оборудование:** Apple Silicon (M1 или новее)
- **Место на диске:** рекомендуется не менее 4.85 GB на одну установку

## Установка

1. Откройте скачанный файл `.dmg`
2. Перетащите **Comfy Desktop** в папку **Applications**
3. Запустите его из Launchpad или Spotlight

![Comfy Desktop для macOS](/images/desktop/installation/mac_1_install.png)
При первом запуске macOS может показать предупреждение о безопасности. Перейдите в **System Settings → Privacy & Security** и нажмите **Open Anyway**, чтобы разрешить запуск.

## Удаление

### Удалить Comfy Desktop

1. Откройте папку **Applications** в Finder
2. Нажмите правой кнопкой мыши на **Comfy Desktop** и выберите **Move to Trash**

![Удаление Comfy Desktop на macOS](/images/desktop/installation/mac_2_uninstall.png)

### Что удаление приложения НЕ удаляет

Удаление Comfy Desktop удаляет только само приложение-лаунчер. Следующие данные **не** удаляются, и их нужно удалить вручную, если вы хотите полностью очистить систему:

| Данные | Расположение по умолчанию | Описание |
|------|-----------------|-------------|
| Установки | `~/ComfyUI-Installs` | Каждая установка ComfyUI, которую вы создали (их также можно удалить из приложения). Пользовательские пути установки тоже не удаляются. |
| Общие модели и выходы | `~/ComfyUI-Shared` | Общая библиотека моделей, каталоги входа и выхода |
| Настройки приложения и реестр | `~/Library/Application Support/Comfy Desktop` | Настройки и записи об установках |
| Логи | `~/Library/Logs/Comfy Desktop` | Логи приложения ( `app.log` ) |

<Warning>Перечисленные выше каталоги содержат ваши **личные данные ComfyUI** (модели, выходы, настройки и установки). Это **не** файлы приложения Comfy Desktop. Их удаление безвозвратно удалит ваши данные.</Warning>

Чтобы полностью удалить всё:

1. **Удалите папку данных приложения**: `~/Library/Application Support/Comfy Desktop`
2. **Удалите папку логов**: `~/Library/Logs/Comfy Desktop`
3. **Удалите отдельные установки** из приложения или вручную удалите `~/ComfyUI-Installs` и все настроенные вами пользовательские каталоги установки
4. **Удалите общую библиотеку моделей** в `~/ComfyUI-Shared` (только если эти файлы вам больше не нужны)

## Если Comfy Desktop запускается с ошибками

Обновление вручную может привести к тому, что Comfy Desktop будет запускаться без стилей, с отсутствующими переводами или с кнопками и выпадающими списками, которые ничего не делают. Обычная причина: профиль Chromium или кэшированное ожидающее обновление, оставшееся от предыдущей версии.

Сначала выйдите из Comfy Desktop, затем запустите скрипт сброса из [репозитория Comfy-Desktop](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/scripts/reset-mac.sh):

```bash
curl -fsSLO https://raw.githubusercontent.com/Comfy-Org/Comfy-Desktop/main/scripts/reset-mac.sh && bash reset-mac.sh
```

Скрипт перечисляет все пути, которые собирается удалить, и спрашивает подтверждение перед удалением. Он очищает настройки приложения, кэши и профиль Chromium для текущей версии и для прежних названий приложения, поэтому профиль, оставшийся от более старой сборки, не может вернуться. Скрипт отказывается запускаться, пока Comfy Desktop открыт. Поскольку папка логов входит в число удаляемых путей, сначала скопируйте лог, если вам может понадобиться сообщить о проблеме, см. [Где находится лог приложения](#where-the-app-log-is).

Ваши установки ComfyUI в `~/ComfyUI-Installs` и общие модели в `~/ComfyUI-Shared` остаются на диске, но файл со списком установок удаляется вместе с остальными данными приложения, поэтому при следующем запуске вам, возможно, придётся добавить их заново с помощью **Add Existing Instance**. Скрипт также сообщает о любых дополнительных копиях приложения, найденных на Mac, не удаляя их, поскольку вторая копия в Dock часто становится причиной того, что сброс как будто ничего не меняет.

### Где находится лог приложения {#where-the-app-log-is}

Если сброс не устранил проблему и вы хотите сообщить о ней в [трекере проблем Comfy-Desktop](https://github.com/Comfy-Org/Comfy-Desktop/issues), прикрепите файл `app.log` из `~/Library/Logs/Comfy Desktop`. Эта папка входит в число путей, удаляемых при сбросе, поэтому скопируйте её в другое место до запуска скрипта. Comfy Desktop создаёт новый `app.log` при каждом запуске и хранит рядом 50 самых новых предыдущих файлов под именами `app.log_<timestamp>.log`, поэтому выбирайте файл из той сессии, в которой произошла ошибка. Каждый файл ротируется при достижении 5 MB, поэтому длинная сессия может занимать несколько файлов.
