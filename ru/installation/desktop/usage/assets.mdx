Страница **Ассеты** в Comfy Desktop показывает файлы, сгенерированные вашими сборками и Comfy Cloud: изображения, видео, аудио и 3D-модели. Она отображает одно расположение за раз, например, Comfy Cloud или папку вывода одной сборки. Чтобы открыть её, нажмите **Ассеты** на **боковой панели**.

<Note>
  Это собственная страница Comfy Desktop. В запущенном ComfyUI панель **Ассеты** служит отдельной галереей для этой сборки. См. [Ассеты в ComfyUI](/ru/interface/assets).
</Note>

## Выберите, где искать

Меню в левом верхнем углу страницы позволяет выбрать место, файлы которого вы видите. В нём две группы:

- **Comfy Cloud**: ваши выходы из Comfy Cloud. Для этого нужно войти в систему. Под этим пунктом меню показано название вашего рабочего пространства.
- **This computer**: **Shared folder**, общая папка выходов, которую локальные сборки используют по умолчанию, а также каждая локальная сборка, сохраняющая данные в собственную папку выходов. Меню показывает путь каждой папки. Нажмите кнопку папки рядом с местом, чтобы открыть её в Finder или Explorer.

Ассеты перечисляют места в рабочем пространстве, выбранном в **боковой панели**. Удалённые сборки в списке не отображаются. Если для удалённой сборки включена опция **Auto-download outputs**, её выходы появляются в папке, в которую они скачиваются. См. [Настроить параметры выходов для удалённых сборок и сборок Comfy Cloud](/ru/installation/desktop/usage/instance-management#set-output-options-for-remote-and-comfy-cloud-builds).

## Найти файл

- **Type**: **All**, **Images**, **Videos**, **3D** или **Audio**.
- **Search by name…**: находит файлы, имя которых содержит введённый текст.
- **Refresh assets**: загружает список заново. Нажмите её после того, как сборка сохранит новые файлы.

В Comfy Cloud фильтр по типу проверяет ваши новейшие 50 000 выходов в текущем порядке сортировки, и страница сообщает об этом под списком.

## Изменить вид

Нажмите **Параметры просмотра**, чтобы настроить:

- **Макет**: **Мозаика** или **Сетка**.
- **Сортировать по**: **Сначала новые** или **Сначала старые**.
- **Показывать**: **Имя файла** и **Детали файла** под каждым файлом.

Comfy Desktop запоминает эти параметры. Внизу страницы можно переключаться между страницами и выбирать, сколько файлов показывать на одной странице: 50, 100 или 200.

## Предпросмотр файла

Нажмите на файл, чтобы открыть его в средстве просмотра. Средство просмотра показывает файл крупно, а также его тип, дату **Created**, размер и размеры. Для файла на этом компьютере оно также показывает **Saved in** с папкой.

- Используйте клавиши со стрелками влево и вправо, чтобы перейти к предыдущему или следующему файлу.
- Для изображения выберите **Fit** или уровень масштаба.
- 3D-модель размером до 100 MB открывается в 3D-представлении. Для модели большего размера средство просмотра показывает: «Can't show this 3D model. Download it to open it in a 3D app.»
- **Tags** показывают теги файла. Теги редактируются в ComfyUI.

## Действия с файлом

Наведите указатель на файл, чтобы увидеть основное действие, либо нажмите **More actions** (**⋯**) или щёлкните файл правой кнопкой мыши, чтобы увидеть остальные:

| Действие | Где | Что делает |
| --- | --- | --- |
| **Открыть** | Изображения, видео и аудио на этом компьютере | Открывает файл в приложении по умолчанию. |
| **Show in Finder**, **Show in Explorer** или **Show in folder** | Файлы на этом компьютере | Открывает папку с файлом. Название зависит от вашей операционной системы. |
| **Скачать** | Comfy Cloud | Сохраняет копию на этот компьютер. См. раздел [Скачивание из Comfy Cloud](#скачать-из-comfy-cloud). |
| **Копировать** | Изображения | Копирует изображение в буфер обмена. |
| **Удалить** | Файлы на этом компьютере | Запрашивает **Удалить {name}?**, затем перемещает файл в Корзину, а в Windows в Recycle Bin. |

За один раз можно выполнить действие только с одним файлом. Удалить файлы Comfy Cloud из Comfy Desktop невозможно.

## Открыть рабочий процесс, создавший файл

Когда изображение, видео или аудиофайл содержит рабочий процесс, создавший его, в просмотрщике отображается **Открыть рабочий процесс**.

- Для файла Comfy Cloud рабочий процесс открывается в Comfy Cloud.
- Для файла на этом компьютере рабочий процесс открывается в сборке, в папке которой находится файл. Если одну папку используют несколько сборок, выберите сборку в разделе **Open in**.

Comfy Desktop запускает сборку, если она ещё не запущена. Если рабочий процесс не открывается, на странице отображается «Couldn't open workflow».

## Скачать из Comfy Cloud

1. Выберите **Comfy Cloud** в меню в левом верхнем углу.
2. Наведите указатель на файл, затем нажмите **Download**.
3. Выберите папку. Диалог сохранения открывается в папке, в которую вы сохраняли в последний раз, или в папке «Загрузки».

Загрузка появится в панели [Загрузки](/ru/installation/desktop/usage/downloads).

## Где сохраняются файлы

- **Этот компьютер**: выходные файлы попадают в общую папку выходных файлов или в собственную папку выходных файлов сборки. Общую папку можно задать в разделе [Настройки рабочего стола](/ru/installation/desktop/usage/settings), а папку сборки на её вкладке [Folders](/ru/installation/desktop/usage/instance-management#choose-which-folders-the-build-uses).
- **Comfy Cloud**: выходные файлы остаются в Comfy Cloud, пока вы их не скачаете.

  <Accordion title="Ассетов пока нет">
    В выбранном месте ещё нет файлов. Запустите рабочий процесс в сборке или [приложение](/ru/installation/desktop/usage/apps), а затем нажмите **Refresh assets**.
  </Accordion>
  <Accordion title="Нет подходящих ассетов">

  </Accordion>
  <Accordion title="Войдите, чтобы увидеть свои ассеты">
    Выбран **Comfy Cloud**, но вы не вошли в аккаунт. Нажмите **Log in to Comfy Cloud**.
  </Accordion>
  <Accordion title="В этом рабочем пространстве нет сборки Comfy Cloud">
    В рабочем пространстве, выбранном в **боковой панели**, нет сборки Comfy Cloud. Перезапустите Comfy Desktop, чтобы вернуть Comfy Cloud.
  </Accordion>
  <Accordion title="Не удалось загрузить ассеты">
    Comfy Desktop не удалось прочитать список. Для Comfy Cloud проверьте подключение к интернету. Затем нажмите **Refresh assets**.
  </Accordion>
</AccordionGroup>
