Comfy Desktop может установить конфигурацию ComfyUI, которую ваша команда совместно использует на Comfy Developer Platform, например одну утверждённую сборку с выбранными моделями и пользовательскими узлами. На Developer Platform такая конфигурация представляет собой Developer Platform Build, которую ваше рабочее пространство публикует в виде пронумерованных версий, а Comfy Desktop устанавливает одну из версий на ваш компьютер как командную сборку. Вы выбираете рабочее пространство, устанавливаете его сборку, обновляете её, когда команда публикует более новую версию, и загружаете собственные сборки на Developer Platform.

Чтобы создать сборку на Developer Platform и опубликовать её версии, см. раздел [Добавление пользовательских сборок в Comfy Cloud](/ru/development/deploy/cloud-custom-builds).

## Выберите рабочее пространство, сборки которого вы видите

У каждого рабочего пространства есть собственные сборки Developer Platform, а Comfy Desktop показывает только одно рабочее пространство за раз. Чтобы увидеть сборки вашей команды, сначала войдите в систему. Следуйте инструкции [Войти и открыть Comfy Cloud](/ru/installation/desktop/overview#войти-и-открыть-comfy-cloud).

Рабочее пространство, выбранное в нижней части **боковой панели**, определяет, что вы видите:

- **Home**, **боковая панель**, страница **Builds** и страницы сборок показывают только сборки в этом рабочем пространстве.
- **New build** предлагает сборки Developer Platform этого рабочего пространства в разделе **Your team's builds**. У вашего рабочего пространства **Personal** есть собственные сборки.

Чтобы переключить рабочие пространства, см. раздел [Использовать меню рабочего пространства](/ru/installation/desktop/usage/overview#использовать-меню-рабочего-пространства). Comfy Desktop запоминает выбранное рабочее пространство и при следующем запуске открывает его.

<Tip>
  Когда ваша команда публикует сборку, пока Comfy Desktop открыт, нажмите **Refresh workspaces** на странице **Builds**. Это перезагрузит ваши рабочие пространства и их сборки Developer Platform.
</Tip>

## Установить сборку вашей команды

Сборка Developer Platform появляется в Comfy Desktop, когда у неё есть опубликованная версия со сборкой для операционной системы и GPU вашего компьютера. Её установка добавляет командную сборку на этот компьютер. Об общих для всех сборок элементах диалога **New build**, таких как **Name** и **Location**, см. в разделе [Установить новую сборку](/ru/installation/desktop/usage/instance-management#install-a-new-build).

<Steps>
  <Step title="Откройте диалог New build">
    На странице **Builds** нажмите **New build**.

    Если вы вошли в систему, диалог открывается на сборках вашего рабочего пространства, причём первая сборка уже выбрана. Если в рабочем пространстве нет сборки для установки, вместо этого он открывается на **Official release**.
  </Step>
  <Step title="Проверьте сборку и оборудование">
    В сводке показано, что будет установлено:

    - **Release**: название сборки с её описанием, **Release v{version}** и **By {creator}**.
    - **Hardware**: цель сборки для операционной системы и GPU этого компьютера, например NVIDIA с CUDA 12.8, и её версия релиза.

    В поле **Name** подставляется название сборки.
  </Step>
  <Step title="Выберите другую сборку (необязательно)">
    Нажмите **Change**, чтобы открыть **Change setup**.

    - **Source**: выберите **Your team's builds**. Если вы не вошли в систему, откроется браузер для входа, а в диалоге появится **Continue in your browser**.
    - **Release**: выберите сборку. В списке отображаются только сборки, которые можно установить на этот компьютер. Нажмите **View builds online**, чтобы открыть сборки вашего рабочего пространства на Developer Platform в браузере, или нажмите **Refresh builds**, чтобы перезагрузить список.
    - **Hardware**: выберите цель сборки. Рекомендуемая цель для этого компьютера выбирается автоматически.

    Пока Comfy Desktop переключается на рабочее пространство, в диалоге отображается **Waiting for workspace authorization… Complete authorization in your browser if prompted.**

    Нажмите **Save changes**, чтобы вернуться к сводке.
  </Step>
  <Step title="Установите сборку">
    Нажмите **Install**. Чтобы следить за установкой, см. в разделе [Установить новую сборку](/ru/installation/desktop/usage/instance-management#install-a-new-build).
  </Step>
</Steps>

Когда установка завершится, плитка сборки на странице **Builds** покажет **Build v{version}**, то есть установленную вами версию. Если сборки нет в списке, см. раздел [Устранение неполадок](#устранение-неполадок).

## Обновить сборку команды

Сборка команды переходит только между версиями своей Developer Platform Build. Когда ваша команда публикует более новую версию, обновите сборку, чтобы её получить. На странице сборки на вкладке **Обзор** есть раздел **Версия сборки**.

1. В **боковой панели** нажмите на сборку команды, чтобы открыть её страницу. Когда доступно обновление, на вкладке **Обзор** появляется точка, а на плитке сборки отображается **Доступно обновление**.
2. На вкладке **Обзор** проверьте раздел **Версия сборки**: **Установлено**, **Последняя опубликованная** и **Последняя проверка**, а также статус **Доступно обновление** или **Актуально**. Чтобы проверить снова, нажмите **Проверить обновления**.
3. Нажмите **Обновить до v{version}**. Также можно выбрать **Обновить** в [меню быстрых действий](/ru/installation/desktop/usage/instance-management#quick-actions-from-the-build-list).
4. В диалоговом окне **Обновить сборку** проверьте версии, между которыми выполняется переход, и нажмите **Обновить сейчас**.

Обновление заменяет окружение сборки новой версией и сохраняет ваши рабочие процессы и уже подготовленные модели. Пока оно выполняется, в статусе отображается **Обновление до v{version}**. Когда оно завершится, в поле **Установлено** будет указана новая версия.

## Загрузить сборку в Developer Platform

**Upload build** создаёт сборку в Developer Platform на основе сборки на этом компьютере, чтобы ваше рабочее пространство могло её опубликовать, а команда могла её установить. Нужно войти в аккаунт, а сборка должна быть установлена на этом компьютере. Сборки Comfy Cloud и удалённые сборки загрузить нельзя.

1. Нажмите правой кнопкой мыши на сборку в **боковой панели**, либо на её плитку на странице **Builds**, либо на её карточку на **Home**.
2. Выберите **Upload build**. Подсказка для него: **Upload this build to Comfy Developer Platform.**

Пока задача выполняется, элемент отображает **Creating…**. Затем Comfy Desktop:

1. Сохраняет ручной снимок сборки. Он появляется на вкладке **Snapshots** этой сборки. См. [Сохранить и восстановить снимки](/ru/installation/desktop/usage/instance-management#save-and-restore-snapshots).
2. Отправляет снимок в Developer Platform как черновик, в рабочее пространство, к которому относится сборка. Сборка из вашего рабочего пространства **Personal** попадает в ваше рабочее пространство **Personal**.
3. Открывает черновик в браузере, где на странице сборки отображаются **Draft** и **Desktop snapshot received**.

Черновик не появляется в разделе **Your team's builds**, пока какая-либо его версия не будет опубликована и не завершит сборку в Developer Platform. Чтобы опубликовать его, см. [Опубликовать сборку](/ru/development/deploy/cloud-custom-builds#опубликовать-сборку).

Если на сборке выполняется другая задача, **Upload build** становится неактивной. Наведите на неё указатель, чтобы увидеть **Wait for the current task on this build to finish.**

## Устранение неполадок

<AccordionGroup>
  <Accordion title="В Release отображается «No compatible Builds are available to install.»">
    Comfy Desktop показывает сборку Developer Platform, только когда сборка последней опубликованной версии завершена и для неё есть сборка под операционную систему и GPU этого компьютера. Убедитесь, что в **боковой панели** выбрано рабочее пространство, в которое публикует ваша команда. Нажмите **View builds online**, чтобы проверить сборку на Developer Platform, затем нажмите **Refresh builds**.
  </Accordion>
  <Accordion title="В диалоговом окне отображается «Couldn't load builds. Retry»">
    Comfy Desktop не удалось загрузить сборки вашего рабочего пространства. Нажмите **Couldn't load builds. Retry**, чтобы загрузить их снова.
  </Accordion>
  <Accordion title="Не удалось загрузить сборку">
    Предупреждение **Could not upload build** указывает причину, например **Could not create a draft in Comfy Developer Platform.** Снова нажмите **Upload build**.
  </Accordion>
</AccordionGroup>
