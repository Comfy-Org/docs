## Общие вопросы

<Accordion title="В чём разница между Comfy Desktop и Классическим Desktop?">
Comfy Desktop представляет собой полностью переписанное приложение, которое работает как **менеджер нескольких установок**. В отличие от Классического Desktop, который был приложением с единственной установкой, Comfy Desktop позволяет устанавливать, управлять и запускать несколько версий ComfyUI одновременно. Кроме того, в нём появились снимки и управление загрузкой моделей.

Если вы пользовались Классическим Desktop, обратитесь к [руководству по миграции](/ru/installation/desktop/usage/migrate), чтобы перенести текущую установку.
</Accordion>
<Accordion title="Открыт ли исходный код Comfy Desktop?">
Да. Исходный код опубликован на [GitHub](https://github.com/Comfy-Org/Comfy-Desktop). Comfy Desktop распространяется по двойной лицензии: [AGPL-3.0-or-later](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/LICENSE) или коммерческая лицензия от Comfy Org (`licensing@comfy.org`).
</Accordion>
<Accordion title="Заменяет ли Comfy Desktop портативную или ручную установку?">
Comfy Desktop входит в число нескольких вариантов установки. Вы по-прежнему можете использовать установку **Portable (Windows)**, **Manual Install** или **Comfy Cloud** в зависимости от ваших потребностей. Desktop рекомендуется большинству пользователей благодаря простоте использования и таким возможностям, как обновление в один клик и управление снимками.
</Accordion>
<Accordion title="Можно ли отключить проверку обновлений?">
Нет. Comfy Desktop проверяет наличие новой версии вскоре после запуска, а затем каждые 10 минут, и эту проверку нельзя отключить. Единственная настройка обновлений находится в **Desktop Settings → Updates** и называется **Automatically install Desktop updates**; по умолчанию она включена.

- **On**: новая версия скачивается в фоне и устанавливается без запроса. Пока идёт загрузка, в строке заголовка отображается **Downloading update…**, а когда обновление готово к применению, там появляется **Desktop Update Ready**.
- **Off**: в строке заголовка отображается **Desktop Update**, а карточка обновлений показывает **Update … available**. Обновление всё равно скачивается в фоне, но само по себе ничего не устанавливается: оно не применяется ни при выходе из приложения, ни при следующем запуске. Когда обновление готово, нажмите плашку **Desktop Update Ready** и выберите **Restart & Update**.

Версия ComfyUI внутри экземпляра обновляется отдельно. Откройте вкладку **Update** нужного экземпляра и выберите там канал **Stable** или **Latest on GitHub**.

В Linux встроенное средство обновления не применяется к установкам из `.deb`. Скачайте новый пакет по [универсальной ссылке для загрузки](https://dl.todesktop.com/241130tqe9q3y) и установите его командой `sudo apt install ./*.deb`.
</Accordion>

## Установка и настройка

<Accordion title="Какие системные требования?">
Полные детали см. в разделе [системные требования](/ru/installation/system_requirements).

- **Windows:** Windows 10+, x64 или ARM64. Дискретная видеокарта (NVIDIA / AMD) рекомендуется, но не обязательна.
- **macOS:** macOS 13+ (Ventura), Apple Silicon (M1+)
- **Linux:** Официальные пакеты `.deb` и AppImage распространяются через [репозиторий Comfy Desktop](https://github.com/Comfy-Org/Comfy-Desktop). Дискретная видеокарта рекомендуется.
- **Диск:** не менее 4.85 GB на каждую отдельную установку
- **ОЗУ:** минимум 8 GB, рекомендуется 16 GB
</Accordion>
<Accordion title="Можно ли установить Десктопный Comfy без прав администратора?">
В **Windows** автономная установка не требует прав администратора. В **macOS** права администратора понадобятся для первоначальной общесистемной установки. В **Linux** для установки пакета `.deb` требуется `sudo`; AppImage работает в пользовательском пространстве без прав администратора.
</Accordion>
<Accordion title="Как скачать Десктопный Comfy?">
Скачайте последнюю сборку для Windows или macOS с официальной [страницы загрузки ComfyUI](https://comfy.org/download). В Linux скачайте `.deb` или AppImage по [универсальной ссылке](https://dl.todesktop.com/241130tqe9q3y) из [репозитория Comfy Desktop](https://github.com/Comfy-Org/Comfy-Desktop). Чтобы запустить из исходников, см. [руководство по установке в Linux](/ru/installation/desktop/linux).
</Accordion>
<Accordion title="Можно ли установить одновременно Классический Desktop и Десктопный Comfy?">
Да, они могут сосуществовать. Однако мы рекомендуем перенести ваши установки в новый Десктопный Comfy и в конечном итоге удалить Классический Desktop. См. [руководство по миграции](/ru/installation/desktop/usage/migrate).
</Accordion>

## Использование

<Accordion title="Как добавить новую установку ComfyUI?">
На Панели управления нажмите **New Instance**, чтобы создать отдельный экземпляр, или откройте **New Instance** и выберите **Add Existing Instance**, чтобы отслеживать git clone или портативную установку Windows. Используйте карточку **Comfy Cloud**, чтобы подключиться к Cloud.

- **Standalone**: чистая установка со встроенным Python
- **Add Existing Instance**: отслеживать git clone или портативную установку
- **Cloud**: подключиться к Comfy Cloud
</Accordion>
<Accordion title="Можно ли запускать несколько версий ComfyUI одновременно?">
Да! Comfy Desktop создан именно для этого. Каждая установка работает в собственной изолированной среде со своим Python и зависимостями. Их можно запускать одновременно в отдельных окнах.
</Accordion>
<Accordion title="Где хранятся мои модели, пользовательские узлы и настройки?">
По умолчанию модели общие для всех экземпляров. Настроить общие папки можно в разделе [Настройки рабочего стола → Storage](/ru/installation/desktop/usage/settings#хранилище).

- **Standalone:** сама установка находится в своей папке установки. Пользовательские узлы и среда Python относятся к конкретной установке. Модели обычно берутся из общих каталогов моделей.
- **Git clone / portable (отслеживаемые):** данные остаются в этой существующей папке (`models/`, `custom_nodes/`, `user/`). При этом можно включить использование общих моделей, входов и выходов.
</Accordion>
<Accordion title="Как работают снимки?">
Comfy Desktop создаёт снимки автоматически при ключевых событиях: при каждом запуске и перезапуске, до и после обновления, а также после восстановления. Снимок фиксирует версию ComfyUI экземпляра, пользовательские узлы с их версиями и все пакеты pip в среде. Файлы моделей, входы и выходы в снимок не входят.

Просматривать, восстанавливать, экспортировать и передавать снимки можно на вкладке **Snapshots** экземпляра. См. [Снимки](/ru/installation/desktop/usage/snapshots).
</Accordion>
### Как остановить Comfy Desktop и выйти из него

Чтобы остановить запущенный экземпляр ComfyUI (остановить бэкенд Python, оставив приложение открытым):

1. Нажмите **⋮ (меню из трёх точек)** на карточке экземпляра
2. Выберите **Stop**
3. Подтвердите действие в диалоговом окне

Процесс Python ComfyUI останавливается, но окно приложения остаётся открытым, поэтому вы можете запустить его снова в любой момент. Чтобы полностью выйти из приложения, откройте **меню ☰** в левом верхнем углу и выберите **Quit Desktop** (или используйте аналогичную команду выхода в ОС). Закрытие последнего окна возвращает на Панель управления, если только вы не вышли из приложения.

## Устранение неполадок

<Accordion title="Приложение не запускается после установки">
1. **Windows:** попробуйте один раз запустить приложение от имени администратора
2. **macOS:** если появляется предупреждение системы безопасности, откройте **System Settings → Privacy & Security** и нажмите **Open Anyway**
3. **Linux:** установите FUSE 2: `libfuse2t64` на Ubuntu 24.04 и новее, `libfuse2` на 22.04
4. Проверьте [страницу загрузки](https://comfy.org/download), возможно, там уже есть последняя версия
</Accordion>
<Accordion title="Comfy Desktop закрывается сам после обновления (Windows)">
В Windows Comfy Desktop 1.0.46 и более ранние версии могут зависнуть, если загрузка обновления не завершилась. Приложение ненадолго показывает экран обновления, а затем закрывается без сообщения об ошибке. Это повторяется при каждом запуске: приложение закрывается раньше, чем успевает скачать исправление. Версии 1.0.47 и новее устраняют эту проблему.

Чтобы восстановить работу, установите последнюю версию вручную:

1. Скачайте [последний установщик для Windows](https://dl.todesktop.com/241130tqe9q3y/windows) или загрузите его со [страницы загрузки](https://comfy.org/download).
2. Запустите установщик. Удалять старую версию предварительно не нужно.
3. Запустите Comfy Desktop.

Ваши установки, модели и настройки сохраняются.
</Accordion>
<Accordion title="GPU не обнаружен">
- Убедитесь, что драйверы NVIDIA обновлены
- В Linux проверьте, установлен ли CUDA toolkit
- Убедитесь, что выбранный тип установки поддерживает GPU (Standalone и Git Clone поддерживают, а подключения к облаку используют удалённый GPU)
</Accordion>
<Accordion title="Установка не обновляется">
- Проверьте подключение к интернету
- Перед повторной попыткой создайте ручной снимок на вкладке **Snapshots** экземпляра
- Если проблема сохраняется, восстановитесь из предыдущего снимка и повторите попытку
</Accordion>

<Accordion title="При установке или обновлении появляется Operation failed">
Экран прогресса остаётся открытым с сообщением **Operation failed**, текстом ошибки и (если доступно) автоматически открытой панелью **View logs**.

- **Reboot** повторяет ту же операцию (**Restart ComfyUI**, если не удался запуск).
- **Back** возвращает на панель управления без каких-либо запросов и оставляет неудачную установку на диске.
- Уход со страницы, пока шаги ещё выполняются, отменяет операцию: **Return to Dashboard** спрашивает **Cancel current operation?**. При отмене установки приложение пытается удалить недостроенную папку (файлы могут остаться, если удаление не удалось).

Если ошибки повторяются, проверьте сеть, затем соберите `app.log` (и любые `app.log_*.log`) через **Настройки рабочего стола → Логи → Диагностика → Открыть папку журналов**. При первой установке в меню может быть доступен только **Skip Onboarding**: сначала выберите **Back**, а затем откройте Настройки на панели управления. См. также [Как проверить журналы запуска Comfy Desktop?](#как-проверить-журналы-запуска-comfy-desktop).
</Accordion>
<Accordion title="Появляется Low Disk Space или Not Enough Space for Template Models">
Во время **New Instance** Comfy Desktop проверяет свободное место на диске установки. **Low Disk Space** это предупреждение: выберите **Continue Anyway**, чтобы продолжить, или укажите другой путь. **Not Enough Space for Template Models** блокирует этот шаблон: выберите более лёгкий рабочий процесс или освободите место. На очень маленьких дисках шаг с шаблоном может быть пропущен. См. [Создание нового экземпляра](/ru/installation/desktop/usage/instance-management#создать-новый-экземпляр).
</Accordion>
<Accordion title="Как проверить журналы запуска Comfy Desktop?">
Приложение Comfy Desktop ведёт файл `app.log` с ротацией. Быстрее всего найти его через **Настройки рабочего стола → Логи → Диагностика → Открыть папку журналов** (меню ☰ в левом верхнем углу).

Папки журналов по умолчанию:

- **Windows:** `%APPDATA%\Comfy Desktop\logs`
- **macOS:** `~/Library/Logs/Comfy Desktop`
- **Linux:** `~/.config/Comfy Desktop/logs`

Ищите файл `app.log`. Журналы предыдущих сессий ротируются в файлы `app.log_*.log` с отметкой времени.

Чтобы посмотреть вывод процесса ComfyUI (а не самого приложения Comfy Desktop), откройте панель **Manage** экземпляра и вкладку **Terminal**. См. [Управление](/ru/installation/desktop/usage/manage).
</Accordion>
<Accordion title="Можно ли использовать Ollama с ComfyUI?">
ComfyUI не имеет встроенной интеграции с [Ollama](https://ollama.ai) в качестве бэкенда для моделей diffusion. Однако вы можете использовать LLM, обслуживаемые Ollama, для генерации промптов и обработки текста через **пользовательские узлы** из реестра ComfyUI Manager.

О том, как подключить ComfyUI к сервисам LLM, см. [Установка пользовательских узлов](/ru/installation/install_custom_node).
</Accordion>
<Accordion title="Как удалить Comfy Desktop?">
Comfy Desktop и его установки хранятся на диске отдельно друг от друга. Чтобы удалить приложение и его установки:

1. **Удалите установки** из приложения (правый клик → Remove) или удалите папки установок вручную
2. **Удалите приложение** стандартным способом вашей системы (Add/Remove Programs в Windows, перетаскивание в Корзину в macOS, менеджер пакетов в Linux)

При этом не удаляются настройки приложения, журналы, общие модели и выходные файлы. Об оставшихся папках и полной очистке см. разделы [Windows](/ru/installation/desktop/windows#что-не-удаляется-вместе-с-приложением), [macOS](/ru/installation/desktop/macos#что-удаление-приложения-не-удаляет) и [Linux](/ru/installation/desktop/linux#удалить-оставшиеся-данные).
</Accordion>
<Accordion title="Можно ли запускать Comfy Desktop в headless-режиме или режиме сервера?">
Нет. Comfy Desktop представляет собой локальное приложение с графическим интерфейсом и не поддерживает headless-режим, режим только сервера или удалённую работу. Для запуска и управления экземплярами ComfyUI требуется графическая среда рабочего стола.

Для headless-развёртываний или развёртываний на сервере используйте **ручную установку ComfyUI** или сборку **Windows Portable**.
</Accordion>
