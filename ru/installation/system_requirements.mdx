В этом руководстве мы расскажем о системных требованиях для установки ComfyUI. Так как ComfyUI обновляется часто, этот документ может обновляться с задержкой. Актуальные инструкции смотрите в репозитории [ComfyUI](https://github.com/Comfy-Org/ComfyUI).

Независимо от того, какую версию ComfyUI вы используете, она работает в отдельном окружении Python.

### Поддерживаемые операционные системы

Сейчас поддерживаются следующие операционные системы:
- Windows
- Linux
- macOS (поддерживается Apple Silicon, например серия M)

### Версия Python

- **Python 3.13** полностью поддерживается и рекомендуется
- Python 3.14 работает, но с некоторыми пользовательскими узлами могут возникнуть проблемы. Вариант free threaded работает, однако часть зависимостей включает GIL, поэтому полной поддержки нет
- Если у вас возникли проблемы с зависимостями некоторых пользовательских узлов на 3.13, хорошим запасным вариантом станет Python 3.12

### Требования к браузеру

Для наилучшего результата используйте **Google Chrome версии 143 или новее**. В более ранних версиях Chrome (142 и ниже) есть известные проблемы, которые могут вызывать визуальные артефакты и снижение производительности в ComfyUI.

### Поддерживаемое оборудование

- **NVIDIA GPU**: установите стабильный pytorch с CUDA 13.0: `pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu130`
- **AMD GPU (Linux)**: ROCm 7.2, стабильная или ночная сборка
- **AMD GPU (Windows)**: ROCm 10.0 через многoархитектурные пакеты PyTorch от AMD. Поддерживаются RDNA 2, RDNA 3, RDNA 3.5 и RDNA 4; отдельная установка HIP SDK не требуется
- **Intel GPU**: серия Arc с нативной поддержкой torch.xpu в PyTorch
- **Apple Silicon**: серии M1/M2/M3/M4 с ускорением Metal
- **Ascend NPU**: через расширение torch_npu
- **Cambricon MLU**: через расширение torch_mlu
- **Iluvatar Corex**: через Iluvatar Extension for PyTorch
- **CPU**: используйте параметр `--cpu` (медленнее)

Подробные шаги установки смотрите в разделе [ручной установки ComfyUI для Windows и Linux](https://github.com/Comfy-Org/ComfyUI?tab=readme-ov-file#manual-install-windows-linux).

<Note>
Поддерживается PyTorch 2.7 и выше, но настоятельно рекомендуется использовать более новую версию. На видеокартах Nvidia 20-й серии и новее требуется версия PyTorch с cu130 или выше. Некоторые функции и оптимизации могут работать только на более новых версиях. Обычно мы рекомендуем последнюю мажорную версию PyTorch с последней версией CUDA, но не используйте версии, выпущенные меньше 2 недель назад.

Портативная сборка для Windows сейчас поставляется с Python 3.13 и PyTorch CUDA 13.0. Если она не запускается, обновите драйверы Nvidia.
</Note>

### Зависимости

- Установите PyTorch (версию, подходящую для вашего оборудования)
- Установите все зависимости из requirements.txt ComfyUI: `pip install -r requirements.txt`

## Частые вопросы

<Accordion title="Поддерживает ли ComfyUI MLX (фреймворк машинного обучения от Apple)?">
ComfyUI не использует MLX напрямую. На Mac с Apple Silicon (M1/M2/M3/M4) ComfyUI использует PyTorch с бэкендом **MPS (Metal Performance Shaders)**, который задействует графический фреймворк Metal от Apple для ускорения на GPU.

MLX это отдельный фреймворк массивов для машинного обучения, созданный для Apple Silicon. Архитектура ComfyUI на основе PyTorch использует вместо него MPS.

Чтобы проверить, что MPS работает на вашем Mac:
```bash
python -c "import torch; print(torch.backends.mps.is_available())"
```
</Accordion>
