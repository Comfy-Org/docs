# Спецификации

Файл `pyproject.toml` содержит два основных раздела для пользовательских узлов ComfyUI: `[project]` и `[tool.comfy]`. Ниже приведены спецификации для каждого из разделов.

## Раздел [project]

### name (обязательно)
Идентификатор узла однозначно определяет пользовательский узел и используется в URL реестра. Пользователи могут установить узел, указав это имя:

```bash
comfy node install <node-id>
```

**Требования:**
- Не длиннее 100 символов
- Только буквы латиницы и цифры, дефисы, подчёркивания и точки
- Специальные символы не могут идти подряд
- Не может начинаться с цифры или специального символа
- Сравнение выполняется без учёта регистра

**Рекомендации:**
- Используйте короткое и понятное имя
- Не включайте в имя «ComfyUI»
- Сделайте имя запоминающимся и простым для ввода

**Примеры:**
```toml
name = "image-processor"      # ✅ Хорошо: просто и понятно
name = "super-resolution"     # ✅ Хорошо: описывает функциональность
name = "ComfyUI-enhancer"    # ❌ Плохо: содержит ComfyUI
name = "123-tool"            # ❌ Плохо: начинается с цифры
```

Подробнее см. официальную [документацию Python](https://packaging.python.org/en/latest/guides/writing-pyproject-toml/#name).

### version (обязательно)
Используется [семантическое версионирование](https://semver.org/) с трёхзначным номером версии X.Y.Z:

- X (**MAJOR**): несовместимые изменения
- Y (**MINOR**): новые возможности ( обратно совместимые)
- Z (**PATCH**): исправления ошибок

**Примеры:**
```toml
version = "1.0.0"    # Первый релиз
version = "1.1.0"    # Добавлены новые возможности
version = "1.1.1"    # Исправление ошибки
version = "2.0.0"    # Несовместимые изменения
```

### license (необязательно)
Указывает лицензию пользовательского узла. Возможны два способа:

1. **Ссылка на файл:**
```toml
license = { file = "LICENSE" }     # ✅ Указывает на файл LICENSE
license = { file = "LICENSE.txt" } # ✅ Указывает на файл LICENSE.txt
license = "LICENSE"                # ❌ Неверный формат
```

2. **Название лицензии:**
```toml
license = { text = "MIT License" }  # ✅ Верный формат
license = { text = "Apache-2.0" }   # ✅ Верный формат
license = "MIT LICENSE"             # ❌ Неверный формат
```

Распространённые лицензии: [MIT](https://opensource.org/license/mit), [GPL](https://www.gnu.org/licenses/gpl-3.0.en.html), [Apache](https://www.apache.org/licenses/LICENSE-2.0)

### description (рекомендуется)
Краткое описание того, что делает ваш пользовательский узел.

```toml
description = "A super resolution node for enhancing image quality"
```

### repository (обязательно)
Ссылки на связанные ресурсы:

```toml
[project.urls]
Repository = "https://github.com/username/repository"
```

### urls (рекомендуется)
Ссылки на связанные ресурсы:

```toml
[project.urls]
Documentation = "https://github.com/username/repository/wiki"
"Bug Tracker" = "https://github.com/username/repository/issues"
```

### requires-python (рекомендуется)
Указывает версии Python, которые поддерживает ваш узел:

```toml
requires-python = ">=3.8"        # Python 3.8 или новее
requires-python = ">=3.8,<3.11"  # Python 3.8 до 3.11 (не включая 3.11)
```

### Совместимость версий фронтенда (необязательно)
Если у вашего узла есть требования к версиям фронтенда ComfyUI, укажите их через зависимость `comfyui-frontend-package`. Этот пакет публикуется на [PyPI](https://pypi.org/project/comfyui-frontend-package/).

Например, это поле нужно, когда:
- ваш пользовательский узел использует API фронтенда, появившиеся в определённой версии
- вы обнаружили несовместимость своего узла с отдельными версиями фронтенда
- вашему узлу нужны возможности интерфейса, доступные только в новых версиях фронтенда

```toml
[project]
dependencies = [
    "comfyui-frontend-package>=1.20.0"       # Требуется фронтенд 1.20.0 или новее
    "comfyui-frontend-package<=1.21.6"       # Ограничивает версии фронтенда до 1.21.6
    "comfyui-frontend-package>=1.19,<1.22"   # Работает с фронтендом 1.19 до 1.21.x
    "comfyui-frontend-package~=1.20.0"       # Совместимо с 1.20.x, но не с 1.21.0
    "comfyui-frontend-package!=1.21.3"       # Работает с любой версией, кроме 1.21.3
]
```

### classifiers (рекомендуется)
Классификаторы указывают совместимость с операционными системами и поддержку GPU-ускорителей. Эта информация помогает пользователям подобрать подходящий узел для своей системы.

```toml
[project]
classifiers = [
    # Для узлов, не зависящих от ОС (работают во всех операционных системах)
    "Operating System :: OS Independent",

    # ИЛИ для узлов, зависящих от ОС, укажите поддерживаемые системы:
    "Operating System :: Microsoft :: Windows",  # Только Windows
    "Operating System :: POSIX :: Linux",  # Только Linux
    "Operating System :: MacOS",  # Только macOS
    
    # Поддержка GPU-ускорителей
    "Environment :: GPU :: NVIDIA CUDA",    # Поддержка NVIDIA CUDA
    "Environment :: GPU :: AMD ROCm",       # Поддержка AMD ROCm
    "Environment :: GPU :: Intel Arc",      # Поддержка Intel Arc
    "Environment :: NPU :: Huawei Ascend",  # Поддержка Huawei Ascend
    "Environment :: GPU :: Apple Metal",    # Поддержка Apple Metal
]
```
## Раздел [tool.comfy]

### PublisherId (обязательно)
Ваш уникальный идентификатор издателя, обычно совпадающий с именем пользователя GitHub.

**Примеры:**
```toml
PublisherId = "john-doe"        # ✅ Совпадает с именем пользователя GitHub
PublisherId = "image-wizard"    # ✅ Уникальный идентификатор
```

### DisplayName (необязательно)
Удобное для пользователя имя вашего пользовательского узла.

```toml
DisplayName = "Super Resolution Node"
```

### Icon (необязательно)
URL иконки вашего пользовательского узла, которая будет отображаться в ComfyUI Registry и ComfyUI-Manager.

**Требования:**
- Типы файлов: SVG, PNG, JPG или GIF
- Максимальное разрешение: 400px × 400px
- Соотношение сторон должно быть квадратным

```toml
Icon = "https://raw.githubusercontent.com/username/repo/main/icon.png"
```

### Banner (необязательно)
URL более крупного изображения баннера, которое будет отображаться в ComfyUI Registry и ComfyUI-Manager.

**Требования:**
- Типы файлов: SVG, PNG, JPG или GIF
- Соотношение сторон: 21:9

```toml
Banner = "https://raw.githubusercontent.com/username/repo/main/banner.png"
```

### requires-comfyui (необязательно)
Указывает, с какой версией ComfyUI совместим ваш узел. Это помогает пользователям убедиться, что у них установлена правильная версия ComfyUI.

**Поддерживаемые операторы:** `<`, `>`, `<=`, `>=`, `~=`, `<>`, `!=` и диапазоны

```toml
requires-comfyui = ">=1.0.0"        # ComfyUI 1.0.0 или новее
requires-comfyui = ">=1.0.0,<2.0.0"  # ComfyUI от 1.0.0 до 2.0.0 (не включая 2.0.0)
requires-comfyui = "~=1.0.0"         # Совместимый релиз: версия 1.0.0 или новее, но не версия 2.0.0
requires-comfyui = "!=1.2.3"         # Любая версия, кроме 1.2.3
requires-comfyui = ">0.1.3,<1.0.0"   # Больше 0.1.3 и меньше 1.0.0
```

### includes (необязательно)
Указывает, следует ли принудительно включать определённые папки. В некоторых ситуациях, например для пользовательских узлов во фронтенд-проектах, итоговая папка с выходными данными может быть указана в .gitignore. В таких случаях её нужно принудительно включить для использования в реестре.

```toml
includes = ['dist']
```

<Tip>Чтобы исключить файлы из опубликованного архива (обратное действие для `includes`), см. [`.comfyignore`](/ru/registry/publishing#исключить-файлы-с-помощью-comfyignore) на странице публикации.</Tip>

## Complete Example
```toml
[project]
name = "super-resolution-node"
version = "1.0.0"
description = "Enhance image quality using advanced super resolution techniques"
license = { file = "LICENSE" }
requires-python = ">=3.8"
dependencies = [
    "comfyui-frontend-package<=1.21.6"  # Frontend version compatibility
]
classifiers = [
    "Operating System :: OS Independent"  # Works on all operating systems
]
dynamic = ["dependencies"]

[tool.setuptools.dynamic]
dependencies = {file = ["requirements.txt"]}

[project.urls]
Repository = "https://github.com/username/super-resolution-node"
Documentation = "https://github.com/username/super-resolution-node/wiki"
"Bug Tracker" = "https://github.com/username/super-resolution-node/issues"

[tool.comfy]
PublisherId = "image-wizard"
DisplayName = "Super Resolution Node"
Icon = "https://raw.githubusercontent.com/username/super-resolution-node/main/icon.png"
Banner = "https://raw.githubusercontent.com/username/super-resolution-node/main/banner.png"
requires-comfyui = ">=1.0.0"  # ComfyUI version compatibility
```
