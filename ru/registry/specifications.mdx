# Спецификации

Файл `pyproject.toml` содержит два основных раздела для пользовательских узлов ComfyUI: `[project]` и `[tool.comfy]`. Ниже приведены спецификации для каждого раздела.

## [project] Раздел

### name (обязательно)
Идентификатор узла однозначно определяет пользовательский узел и используется в URL-адресах реестра. Пользователи могут установить узел, указав это имя:

```bash
comfy node install <node-id>
```

**Требования:**
- Должно быть меньше 100 символов
- Может содержать только буквенно-цифровые символы, дефисы, символы подчёркивания и точки
- Не может содержать идущие подряд специальные символы
- Не может начинаться с цифры или специального символа
- Сравнение без учёта регистра

**Рекомендации:**
- Используйте короткое описательное имя
- Не включайте «ComfyUI» в имя
- Сделайте его запоминающимся и простым для ввода

**Examples:**
```toml
name = "image-processor"      # ✅ Good: Simple and clear
name = "super-resolution"     # ✅ Good: Describes functionality
name = "ComfyUI-enhancer"    # ❌ Bad: Includes ComfyUI
name = "123-tool"            # ❌ Bad: Starts with number
```

Подробнее см. в официальной [документации Python](https://packaging.python.org/en/latest/guides/writing-pyproject-toml/#name).

### version (обязательно)
Используется [семантическое версионирование](https://semver.org/) с трёхзначным номером версии X.Y.Z:

- X (**MAJOR**): Breaking changes
Y (**MINOR**): Новые функции (обратно совместимые)
- Z (**PATCH**): Bug fixes

**Examples:**
```toml
version = "1.0.0"    # Initial release
version = "1.1.0"    # Added new features
version = "1.1.1"    # Bug fix
version = "2.0.0"    # Breaking changes
```

### license (необязательно)
Указывает лицензию для вашего пользовательского узла. Можно указать двумя способами:

1. **File Reference:**
```toml
license = { file = "LICENSE" }     # ✅ Points to LICENSE file
license = { file = "LICENSE.txt" } # ✅ Points to LICENSE.txt
license = "LICENSE"                # ❌ Incorrect format
```

2. **License Name:**
```toml
license = { text = "MIT License" }  # ✅ Correct format
license = { text = "Apache-2.0" }   # ✅ Correct format
license = "MIT LICENSE"             # ❌ Incorrect format
```

Распространённые лицензии: [MIT](https://opensource.org/license/mit), [GPL](https://www.gnu.org/licenses/gpl-3.0.en.html), [Apache](https://www.apache.org/licenses/LICENSE-2.0)

### description (рекомендуется)
Краткое описание того, что делает ваш пользовательский узел.

```toml
description = "A super resolution node for enhancing image quality"
```

### репозиторий (обязательно)
Ссылки на связанные ресурсы:

```toml
[project.urls]
Repository = "https://github.com/username/repository"
```

### urls (рекомендуется)
Ссылки на связанные ресурсы:

```toml
[project.urls]
Documentation = "https://github.com/username/repository/wiki"
"Bug Tracker" = "https://github.com/username/repository/issues"
```

### requires-python (рекомендуется)
Указывает версии Python, которые поддерживает ваш узел:

```toml
requires-python = ">=3.8"        # Python 3.8 or higher
requires-python = ">=3.8,<3.11"  # Python 3.8 up to (but not including) 3.11
```

### Совместимость версий фронтенда (необязательно)
Если у вашего узла есть особые требования к поддерживаемым версиям фронтенда ComfyUI, вы можете указать их с помощью зависимости `comfyui-frontend-package`. Этот пакет опубликован на [PyPI](https://pypi.org/project/comfyui-frontend-package/).

Например, используйте это поле, если:
- Ваш пользовательский узел использует API фронтенда, которые были представлены в определённой версии
- Вы обнаружили несовместимости между вашим узлом и определёнными версиями фронтенда
- Вашему узлу требуются определённые функции UI, доступные только в более новых версиях фронтенда

```toml
[project]
dependencies = [
    "comfyui-frontend-package>=1.20.0"       # Requires frontend 1.20.0 or newer
    "comfyui-frontend-package<=1.21.6"       # Restricts to frontend versions up to 1.21.6
    "comfyui-frontend-package>=1.19,<1.22"   # Works with frontend 1.19 to 1.21.x
    "comfyui-frontend-package~=1.20.0"       # Compatible with 1.20.x but not 1.21.0
    "comfyui-frontend-package!=1.21.3"       # Works with any version except 1.21.3
]
```

### Классификаторы (рекомендуется)
Используйте классификаторы, чтобы указать совместимость с операционной системой и GPU-ускорители. Эта информация помогает пользователям найти подходящий узел для своей системы.

```toml
[project]
classifiers = [
    # For OS-independent nodes (works on all operating systems)
    "Operating System :: OS Independent",

    # OR for OS-specific nodes, specify the supported systems:
    "Operating System :: Microsoft :: Windows",  # Windows specific
    "Operating System :: POSIX :: Linux",  # Linux specific
    "Operating System :: MacOS",  # macOS specific
    
    # GPU Accelerator support
    "Environment :: GPU :: NVIDIA CUDA",    # NVIDIA CUDA support
    "Environment :: GPU :: AMD ROCm",       # AMD ROCm support
    "Environment :: GPU :: Intel Arc",      # Intel Arc support
    "Environment :: NPU :: Huawei Ascend",  # Huawei Ascend support
    "Environment :: GPU :: Apple Metal",    # Apple Metal support
]
```

## Раздел [tool.comfy]

### PublisherId (обязательно)
Ваш уникальный идентификатор издателя, обычно совпадающий с именем пользователя GitHub.

**Примеры:**
```toml
PublisherId = "john-doe"        # ✅ Совпадает с именем пользователя GitHub
PublisherId = "image-wizard"    # ✅ Уникальный идентификатор
```

### DisplayName (необязательно)
Удобное для пользователя имя вашего пользовательского узла.

```toml
DisplayName = "Super Resolution Node"
```

### Icon (необязательно)
URL-адрес иконки вашего пользовательского узла, которая будет отображаться в ComfyUI Registry и ComfyUI-Manager.

**Требования:**
- Типы файлов: SVG, PNG, JPG или GIF
- Максимальное разрешение: 400px × 400px
- Соотношение сторон должно быть квадратным

```toml
Icon = "https://raw.githubusercontent.com/username/repo/main/icon.png"
```

### Banner (необязательно)
URL-адрес более крупного баннера, который будет отображаться в ComfyUI Registry и ComfyUI-Manager.

**Требования:**
- Типы файлов: SVG, PNG, JPG или GIF
- Соотношение сторон: 21:9

```toml
Banner = "https://raw.githubusercontent.com/username/repo/main/banner.png"
```

### requires-comfyui (необязательно)
Указывает, с какой версией ComfyUI совместим ваш узел. Это помогает пользователям убедиться, что у них установлена правильная версия ComfyUI.

**Поддерживаемые операторы:** `<`, `>`, `<=`, `>=`, `~=`, `<>`, `!=` и диапазоны

```toml
requires-comfyui = ">=1.0.0"        # ComfyUI 1.0.0 или выше
requires-comfyui = ">=1.0.0,<2.0.0"  # ComfyUI от 1.0.0 до 2.0.0 (не включая 2.0.0)
requires-comfyui = "~=1.0.0"         # Совместимый выпуск: версия 1.0.0 или новее, но не 2.0.0
requires-comfyui = "!=1.2.3"         # Любая версия, кроме 1.2.3
requires-comfyui = ">0.1.3,<1.0.0"   # Больше 0.1.3 и меньше 1.0.0
```

### includes (необязательно)
Указывает, нужно ли принудительно включать определённые папки. В некоторых ситуациях, например для пользовательских узлов в frontend-проектах, итоговая выходная папка пакета может быть добавлена в .gitignore. В таких случаях её нужно принудительно включить для использования в реестре.

```toml
includes = ['dist']
```

<Tip>Чтобы исключить файлы из публикуемого архива (обратное действию `includes`), см. [`.comfyignore`](/ru/registry/publishing#исключить-файлы-с-помощью-comfyignore) на странице публикации.</Tip>

## Полный пример
```toml
[project]
name = "super-resolution-node"
version = "1.0.0"
description = "Enhance image quality using advanced super resolution techniques"
license = { file = "LICENSE" }
requires-python = ">=3.8"
dependencies = [
    "comfyui-frontend-package<=1.21.6"  # Frontend version compatibility
]
classifiers = [
    "Operating System :: OS Independent"  # Works on all operating systems
]
dynamic = ["dependencies"]

[tool.setuptools.dynamic]
dependencies = {file = ["requirements.txt"]}

[project.urls]
Repository = "https://github.com/username/super-resolution-node"
Documentation = "https://github.com/username/super-resolution-node/wiki"
"Bug Tracker" = "https://github.com/username/super-resolution-node/issues"

[tool.comfy]
PublisherId = "image-wizard"
DisplayName = "Super Resolution Node"
Icon = "https://raw.githubusercontent.com/username/super-resolution-node/main/icon.png"
Banner = "https://raw.githubusercontent.com/username/super-resolution-node/main/banner.png"
requires-comfyui = ">=1.0.0"  # ComfyUI version compatibility
```
