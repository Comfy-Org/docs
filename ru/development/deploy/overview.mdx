Вы можете запускать свои рабочие процессы ComfyUI в Comfy Cloud, в собственном развёртывании Comfy API или на сервере, которым управляете сами. Comfy Cloud и Comfy API работают на GPU Comfy, поэтому GPU на вашем компьютере не требуется. Выберите вариант, подходящий вашему рабочему процессу, и начните с его карточки.

Чтобы вызвать любой из этих вариантов из своего кода, отправьте рабочий процесс в [формате API](/ru/development/api-development/workflow-api-format).

## Развернуть из приложения ComfyUI

В ComfyUI на вашем компьютере или в Десктопном Comfy карточка **Deploy to Comfy API** запускает сборку из открытого рабочего процесса.

<Warning>
  Публикация версии бесплатна. Когда её сборка завершится, в строке **Serverless build** появится кнопка **Deploy**. При развёртывании оплачивается хранилище с момента развёртывания, а также время GPU, пока работает воркер. В диалоге развёртывания отображается ориентировочная стоимость до подтверждения.
</Warning>

<Steps>
  <Step title="Открыть меню Workflow actions">
    В **Top bar** щёлкните правой кнопкой мыши по вкладке рабочего процесса. Также можно нажать кнопку **Workflow actions** в левом верхнем углу **Canvas**.

    ![Меню Workflow actions, открытое из вкладки рабочего процесса, с пунктом Deploy to Comfy API и его значком NEW под Export (API)](/images/development/deploy/deploy-to-comfy-api.png)
  </Step>
  <Step title="Выбрать Deploy to Comfy API">
    Выберите **Deploy to Comfy API**. Пункт отмечен как **NEW**. Открывается карточка **Deploy to Comfy API** с подсчётом пакетов узлов, моделей и классов узлов, которые использует рабочий процесс.

    ![Карточка Deploy to Comfy API с видео о продукте, счётчиками пакетов узлов, моделей и классов узлов, а также кнопкой Deploy on Platform](/images/development/deploy/deploy-api-ui.png)
  </Step>
  <Step title="Продолжить на платформе разработчиков">
    Нажмите **Deploy on Platform**. Платформа разработчиков по адресу [platform.comfy.org](https://platform.comfy.org) откроется в новой вкладке.
  </Step>
</Steps>

На платформе разработчиков вы создаёте сборку из рабочего процесса, публикуете версию и развёртываете её. В разделе [Запуск сборки](/ru/development/serverless/overview#начать-сборку-из-comfy-desktop-файла-рабочего-процесса-или-comfyui) описано, как запустить сборку из файла рабочего процесса, а раздел [Развернуть в Comfy Cloud](/ru/development/deploy/cloud#запустить-рабочий-процесс-на-пользовательской-сборке) описывает, как вызвать развёртывание из вашего кода.

## Запустить развёртывание из редактора Comfy Cloud

Чтобы создать развёртывание из редактора Comfy Cloud, запустить в нём рабочие процессы, а затем остановить или удалить его, см. раздел [Добавление пользовательских сборок в Comfy Cloud](/ru/development/deploy/cloud-custom-builds).

## Запустить рабочие процессы из приложения

Когда развертывание находится в состоянии **Готов**, см. раздел [Запуск рабочих процессов](/ru/development/run-workflows/overview), чтобы вызывать его из вашего приложения. [Comfy SDKs](/ru/development/api-development/sdks) работают с Comfy Cloud и вашими развертываниями. Самостоятельно размещённому ComfyUI требуется [API Proxy](/ru/development/comfyui-server/api-proxy), чтобы предоставлять Comfy API v2.
