Вы можете запустить рабочий процесс, созданный вами в редакторе Comfy Cloud, из собственного приложения, например из серверной службы или пакетного скрипта, с помощью [Comfy SDKs](/ru/development/api-development/sdks). Comfy Cloud запускает рабочие процессы в стандартной сборке с набором пользовательских узлов по умолчанию. Если рабочему процессу нужны пользовательские узлы или модели, которых нет в стандартной сборке, вы создаёте пользовательскую сборку: пакет ваших собственных пользовательских узлов и моделей, который Comfy Cloud запускает для вас. На этой странице показано, как запустить рабочий процесс через API в стандартной сборке, а затем как переключить тот же код на пользовательскую сборку.

## Перед началом

Чтобы вызывать Comfy Cloud из своего кода, убедитесь, что у вас есть следующее:

- **Платная подписка Comfy Cloud**
- **Рабочий процесс, который запускается в редакторе Comfy Cloud**: проверьте его в редакторе, прежде чем запускать из кода. Если ему нужны пользовательские узлы или модели, которых нет в стандартной сборке, сначала [создайте пользовательскую сборку](/ru/development/deploy/cloud-custom-builds).
- **Python 3.10 или новее, или Node 22 или новее**: для устанавливаемого SDK нужен один из них.

Если вы ещё не пользовались Comfy Cloud, начните с [Comfy Cloud](/ru/get_started/cloud).

## Запустить рабочий процесс в стандартной сборке

Стандартная сборка запускает любой рабочий процесс, который использует только те пользовательские узлы, что поддерживает Comfy Cloud. Чтобы запустить его из своего кода, создайте API-ключ, установите SDK и экспортируйте рабочий процесс в формате API.

<Steps>
  <Step title="Создать API-ключ">
    Ваше приложение отправляет ключ с каждым запросом, поэтому создайте ключ для своего приложения на Developer Platform.

    1. Войдите на [platform.comfy.org](https://platform.comfy.org), а затем нажмите **API Keys**.
    2. Нажмите **New API key**, введите имя, а затем нажмите **Generate key**.
    3. Скопируйте ключ и сохраните его в надёжном месте. Developer Platform показывает его только один раз.

    Ключ начинается с `comfyui-`. О том, как управлять ключами, см. в разделе [Getting an API Key](/ru/development/api-development/getting-an-api-key).
  </Step>
  <Step title="Установить SDK">
    <CodeGroup>
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    </CodeGroup>
  </Step>
  <Step title="Экспортировать рабочий процесс в формате API">
    SDK отправляет рабочий процесс в формате API, а не файл, который сохраняет редактор.

    - В редакторе Comfy Cloud откройте рабочий процесс, выберите **File** > **Export (API)** и сохраните файл как `workflow_api.json`.

    О том, что содержится в файле, см. в разделе [Workflow API Format](/ru/development/api-development/workflow-api-format).
  </Step>
  <Step title="Запустить рабочий процесс">
    SDK отправляет запросы в Comfy Cloud, если вы не задали другой базовый URL, поэтому передавайте только свой API-ключ:

    <CodeGroup>
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." });

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    </CodeGroup>

    - Замените `"9"` на идентификатор узла вывода в вашем `workflow_api.json`.
    - `run()` ждёт завершения задачи, после чего код записывает выходы на диск.

    О том, как задавать входы, отслеживать прогресс и обрабатывать ошибки, см. в разделе [Comfy SDKs](/ru/development/api-development/sdks).
  </Step>
</Steps>

## Запустить рабочий процесс на пользовательской сборке

Развёртывание пользовательской сборки даёт вам развёртывание с собственным URL. Ваш код из предыдущего раздела будет выполняться на этом развёртывании, как только вы измените базовый URL.

<Warning>
  Развёртывание расходует GPU-время, пока работают его воркеры, и хранилище, пока вы его не удалите. Когда закончите тестирование, остановите или удалите его. См. [Очистка](/ru/development/serverless/overview#очистить).
</Warning>

<Steps>
  <Step title="Создать и развернуть сборку">
    Следуйте инструкции [Пользовательские сборки](/ru/development/deploy/cloud-custom-builds), чтобы создать сборку из вашего рабочего процесса и развернуть её.
  </Step>
  <Step title="Скопировать URL развёртывания">
    1. На платформе разработчика откройте страницу развёртывания.
    2. Дождитесь, когда статус развёртывания станет **Ready**.
    3. В разделе **Run via API** скопируйте **Deployment URL**.

    URL развёртывания имеет вид `https://dep-<id>.run.comfy.app`.
  </Step>
  <Step title="Задать базовый URL">
    Установите `COMFY_BASE_URL` в значение URL развёртывания:

    ```bash
    export COMFY_BASE_URL="https://dep-<id>.run.comfy.app"
    ```
  </Step>
  <Step title="Запустить рабочий процесс">
    Запустите код из раздела [Запустить рабочий процесс в стандартной сборке](#запустить-рабочий-процесс-в-стандартной-сборке) с вашим API-ключом. Теперь SDK отправляет задачу в ваше развёртывание.
  </Step>
</Steps>

<Tip>
  Чтобы сначала протестировать развёртывание из терминала, выполните:

  ```bash
  comfy deploy run --deployment <deployment-id> --workflow workflow_api.json
  ```
</Tip>
