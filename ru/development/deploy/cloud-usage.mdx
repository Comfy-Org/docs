Рабочие процессы, отправленные через API Comfy Cloud, используют те же кредиты и ограничения параллелизма, что и другие рабочие процессы Cloud.

## Кредиты и использование

Запросы к API расходуют тот же ежемесячный объём кредитов, что и веб-интерфейс Comfy Cloud. Отдельного пула кредитов для API не существует. Включённые в тариф кредиты, варианты пополнения и ограничения времени выполнения для каждого рабочего процесса действуют для заданий API так же, как и для заданий из интерфейса.

Ежемесячные объёмы кредитов и варианты пополнения смотрите на [странице тарифов](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api). Пополнить баланс можно в панели управления аккаунтом.

## Ограничения параллельных запусков

Вы можете отправлять несколько рабочих процессов, не дожидаясь завершения предыдущих задач. Задачи выполняются параллельно в пределах лимита вашего тарифа:

| Тариф    | Одновременных рабочих процессов |
| :------- | :------------------------------ |
| Standard | 1                               |
| Creator  | 3                               |
| Pro      | 5                               |

Тарифы уровня «Команда» допускают больше одновременных рабочих процессов на участника, чем Pro. Проверьте [platform.comfy.org](https://platform.comfy.org), чтобы узнать ограничение для своей учётной записи. Дополнительные задачи встают в очередь и запускаются по мере освобождения слотов.

Если очередь заполнена, SDK повторяют попытки в пределах ограниченного бюджета, прежде чем выдать `QueueFull`.

На тарифах «Команда» и «Корпоративный» лимит действует для каждого участника: у всех в рабочем пространстве свой предел параллельности, поэтому запущенные задачи одного участника никогда не блокируют задачи другого.

<Info>
  Одновременный запуск более одной задачи поддерживается только через API. Интерфейс Comfy Cloud выполняет один рабочий процесс за раз на человека, а рабочие процессы, поставленные в очередь в редакторе, выполняются по порядку. Детали подписки смотрите в разделе [тарифные планы](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api).
</Info>

## Ограничения времени выполнения и очереди

Для каждого рабочего процесса в Comfy Cloud действует максимальное время выполнения. Задача, превысившая этот лимит, отменяется автоматически:

| Тариф     | Максимальное время выполнения |
| :------- | :-------------- |
| Standard | 30 минут      |
| Creator  | 30 минут      |
| Pro      | 1 час      |

В очереди одновременно может находиться до 100 рабочих процессов. Чтобы увеличить лимит параллельных задач для команды, [свяжитесь с поддержкой](https://support.comfy.org/).

## Выставление счетов за развёртывание

[Развёртывание](/ru/development/serverless/overview) пользовательской сборки тарифицирует время GPU для её воркеров и хранилище для её моделей за счёт кредитов Comfy.

### Взимается ли плата за хранение сборок, которые не развёрнуты?

Нет. Сборки и их версии хранятся бесплатно. Плата за хранилище начинает взиматься при развёртывании:

- При развёртывании версии Comfy Cloud копирует её модели в сетевое хранилище, которое совместно используют воркеры развёртывания. Comfy Cloud тарифицирует хранилище за ГБ в месяц, пока в этом регионе существует развёртывание сборки, в том числе пока развёртывание остановлено. Модели, которые задача использует из вашей [библиотеки рабочего пространства](/ru/development/deploy/cloud-custom-builds#добавить-свою-lora-или-модель), туда не копируются. Воркер загружает их для задачи.
  - Модели, которые вы [добавляете в развёртывание](/ru/development/serverless/overview#добавить-модель-в-работающее-развёртывание), также копируются туда и учитываются в этом хранилище.
- Локальный диск на каждом воркере не добавляет платы сверх тарифа за GPU.
- Удаление развёртывания освобождает его вычислительные ресурсы. Плата за сетевое хранилище прекращается, когда вы удаляете последнее развёртывание, которое его использует.

Чтобы узнать тарифы на хранилище и GPU, откройте [**Limits**](https://platform.comfy.org/settings/limits) на Developer Platform и проверьте **Deployment pricing**. Панель **Estimated cost** в диалоге развёртывания также показывает время GPU и хранилище моделей для развёртывания.

### Как оплачиваются постоянно активные воркеры?

[Постоянно активные воркеры](/ru/development/serverless/overview#масштабировать-воркеры) (`--min` в comfy-cli) тарифицируют время GPU всё время, пока они работают, независимо от того, обрабатывают ли они задания.

Воркеры сверх этого числа, вплоть до **Max workers** (`--max`), запускаются при поступлении заданий. Они тарифицируют время GPU с момента запуска, на протяжении своих заданий и за время простоя после последнего задания до их освобождения. По умолчанию воркер остаётся запущенным 3 минуты после последнего задания. Это время можно задать, от 30 секунд до 20 минут, в поле **Keep worker up after a job** при создании развёртывания на Developer Platform. При `0` постоянно активных воркеров оплата GPU прекращается, как только это время простоя заканчивается и все воркеры освобождаются. Следующее задание ждёт, пока запустится GPU.

Если в вашем рабочем пространстве закончились кредиты, его развёртывания останавливаются.

Чтобы узнать тарифы на GPU, откройте [**Limits**](https://platform.comfy.org/settings/limits) на Developer Platform и проверьте **Deployment pricing**. Тарифы указаны за воркер за каждый час его работы.

## Существующие интеграции v1

Устаревший [Cloud API v1](/ru/development/cloud/overview) также работает с Comfy Cloud. Используйте его для существующих интеграций или возможностей Comfy Cloud, которые ещё недоступны в [Comfy API v2](/ru/api-reference/v2/overview). Примеры для запуска находятся в устаревшем [справочнике по Cloud API](/ru/development/cloud/api-reference).
