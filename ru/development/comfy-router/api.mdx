Выберите модель, изучите её схему и вызовите `POST /v2/models/{provider}/{model}`. Маршрут и аутентификация одинаковы для всех моделей. Каждая модель принимает собственное нативное тело запроса и возвращает собственный нативный результат.

  <Card title="Поиск моделей" icon="magnifying-glass" href="/ru/development/comfy-router/discover-models">
