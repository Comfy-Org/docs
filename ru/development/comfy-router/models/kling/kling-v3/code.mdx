```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "kling/kling-v3",
            {
                "aspect_ratio": "16:9",
                "duration": "5",
                "mode": "std",
                "prompt": "A red fox trotting through falling snow, cinematic lighting.",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственная полезная нагрузка провайдера, то же значение, которое возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, возбуждает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

## Провайдеры, обслуживающие модель

Эта модель обслуживается напрямую через Comfy Router, если в запросе не указан другой провайдер. Провайдеры ниже также её обслуживают: на том же эндпоинте и с тем же ID модели, который выбирается параметром запроса `model_provider`.

- **Comfy** (по умолчанию): `POST https://api.comfy.org/v2/models/kling/kling-v3`
- **Higgsfield**, как `higgsfield/higgsfield-kling-3-std`: `POST https://api.comfy.org/v2/models/kling/kling-v3?model_provider=higgsfield`
  - Отклоняются с `invalid_input`: `image`, `image_tail`, `mode`, отличный от `std` (например, `"pro"`)
  - Резервный вариант: если Higgsfield завершается ошибкой, запрос один раз повторяется на Kling (провайдер по умолчанию). Отправьте `fallback_provider=false`, чтобы отказаться от этого. Отклонённые входы и запросы BYOK не переключаются на резервный провайдер.
- **Tencent**: `POST https://api.comfy.org/v2/models/kling/kling-v3?model_provider=tencent`
  - Ограничения: 720P, без звука; 3–15 секунд (по умолчанию 5); соотношение сторон 16:9, 9:16 или 1:1
  - Отклоняются с `invalid_input`: `image`, `image_tail`, `sound: "on"`, `mode`, отличный от `std` (например, `"pro"`), `multi_shot`, `multi_prompt`, `shot_type`
  - Резервный вариант: если Tencent завершается ошибкой, запрос один раз повторяется на Kling (провайдер по умолчанию). Отправьте `fallback_provider=false`, чтобы отказаться от этого. Отклонённые входы и запросы BYOK не переключаются на резервный провайдер.

Значение `strict_mode` по умолчанию равно false, поэтому Router переводит нативное тело запроса, описанное на этой странице, в собственную схему провайдера и переводит ответ обратно. См. [`model_provider`, `strict_mode` и `fallback_provider`](/ru/development/comfy-router/reference#post-v2modelsprovidermodel) в справочнике по API, а также [Провайдеры, обслуживающие модель](/ru/development/comfy-router/providers), где перечислены все модели, маршрутизируемые таким образом.
