Ссылка на API для `kling/videos-lip-sync`, предоставляемого Comfy Router от Kling.

**Вход:** Видео, Аудио · **Выход:** Видео

## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL делает тот же вызов по чистому HTTP.

**ID модели:** `kling/videos-lip-sync`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/kling/videos-lip-sync`

То же тело, отправленное на `POST https://api.comfy.org/v2/models/kling/videos-lip-sync/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "kling/videos-lip-sync",
            {
                "input": {
                    "mode": "text2video",
                    "text": "Welcome to Comfy Cloud.",
                    "video_id": "kling-video-6f5e4d3c2b1a",
                    "voice_id": "genshin_vindi2",
                    "voice_language": "en",
                    "voice_speed": 1,
                },
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указывает сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, здесь вызывает типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("kling/videos-lip-sync", {
  input: {
    mode: "text2video",
    text: "Welcome to Comfy Cloud.",
    video_id: "kling-video-6f5e4d3c2b1a",
    voice_id: "genshin_vindi2",
    voice_language: "en",
    voice_speed: 1,
  },
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указывает сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/kling/videos-lip-sync/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"input\": {\"mode\":\"text2video\",\"text\":\"Welcome to Comfy Cloud.\",\"video_id\":\"kling-video-6f5e4d3c2b1a\",\"voice_id\":\"genshin_vindi2\",\"voice_language\":\"en\",\"voice_speed\":1}}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/kling/videos-lip-sync/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/kling/videos-lip-sync/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

<ParamField body="input" type="object" required>
   
</ParamField>

<ParamField body="input.audio_file" type="string">
  Локальный путь к аудиофайлу. Поддерживаемые форматы: .mp3/.wav/.m4a/.aac, максимальный размер файла 5 МБ. Код в Base64.
</ParamField>

<ParamField body="input.audio_type" type="string">
  Метод передачи аудиофайлов для lip-sync. Обязательно, если mode имеет значение audio2video.

  Возможные значения: `file`, `url`
</ParamField>

<ParamField body="input.audio_url" type="string">
  URL для скачивания аудиофайла. Поддерживаемые форматы: .mp3/.wav/.m4a/.aac, максимальный размер файла 5 МБ.
</ParamField>

<ParamField body="input.mode" type="string" required>
  Режим генерации видео. text2video: режим генерации видео из текста; audio2video: режим генерации видео из аудио

  Возможные значения: `text2video`, `audio2video`
</ParamField>

<ParamField body="input.text" type="string">
  Текстовое содержимое для генерации видео с lip-sync. Обязательно, если mode имеет значение text2video. Максимальная длина: 120 символов.
</ParamField>

<ParamField body="input.video_id" type="string">
  ID видео, сгенерированного Kling AI. Поддерживаются только видео длительностью 5 и 10 секунд, сгенерированные за последние 30 дней.
</ParamField>

<ParamField body="input.video_url" type="string">
  Ссылка на загруженное видео. Поддерживаются видеофайлы .mp4/.mov, размер файла не превышает 100 МБ, длительность видео от 2 до 10 с.
</ParamField>

<ParamField body="input.voice_id" type="string">
  ID голоса. Обязательно, если mode имеет значение text2video. Система предлагает на выбор множество вариантов голоса.
</ParamField>

<ParamField body="input.voice_language" type="string" default="&quot;en&quot;">
  Язык голоса соответствует Voice ID.

  Возможные значения: `zh`, `en`
</ParamField>

<ParamField body="input.voice_speed" type="number" default="1">
  Скорость речи. Допустимый диапазон: 0.8~2.0, с точностью до одного знака после запятой.

  Диапазон: от `0.8` до `2`
</ParamField>
