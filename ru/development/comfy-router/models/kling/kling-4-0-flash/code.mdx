```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "kling/kling-4.0-flash",
            {
                "prompt": "A neon-lit alley in the rain, slow dolly forward.",
                "settings": {
                    "aspect_ratio": "16:9",
                    "duration": 5,
                    "resolution": "720p",
                },
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивает до завершения запроса, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("kling/kling-4.0-flash", {
  prompt: "A neon-lit alley in the rain, slow dolly forward.",
  settings: {
    aspect_ratio: "16:9",
    duration: 5,
    resolution: "720p",
  },
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивает до завершения запроса, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

<ParamField body="options" type="object">
  Общие настройки, например параметры водяного знака. `options.callback_url` и `options.external_task_id` не поддерживаются в Kling 4.0; Comfy Router отклоняет запрос, в котором любой из них задан внутри `options`. </ParamField>

<ParamField body="options.watermark_info" type="object">
  Генерировать ли одновременно результаты с водяным знаком. Пользовательские водяные знаки не поддерживаются. Явный null трактуется как отсутствие значения, так же как это делают проверка Kling 4.0 в /proxy и сам Kling.
</ParamField>

<ParamField body="options.watermark_info.enabled" type="boolean">
  true означает сгенерировать результат с водяным знаком, false означает не генерировать. По умолчанию false.
</ParamField>

<ParamField body="prompt" type="string" required>
  Промпт, который может содержать позитивные и негативные описания. До 26,000 английских символов или 11,000 неанглийских символов; comfy-api допускает от 1 до 26,000 символов, а сам Kling отклоняет более длинный неанглийский текст.
</ParamField>

<ParamField body="settings" type="object" required>
  Настройки вывода, такие как разрешение, соотношение сторон и длительность.
</ParamField>

<ParamField body="settings.aspect_ratio" type="string">
  Соотношение сторон (ширина:высота) сгенерированных кадров. Одно из "21:9", "16:9", "9:16", "1:1", "4:3" или "3:4". По умолчанию "16:9".

  Возможные значения: `21:9`, `16:9`, `9:16`, `1:1`, `4:3`, `3:4`
</ParamField>

<ParamField body="settings.duration" type="integer" required>
  Длительность видео в секундах, от 3 до 20. Обязательно.

  Диапазон: от `3` до `20`
</ParamField>

<ParamField body="settings.resolution" type="string" required>
  Разрешение сгенерированного видео. Kling 4.0 Flash выдаёт только "720p". Обязательно.

  Возможные значения: `720p`
</ParamField>
