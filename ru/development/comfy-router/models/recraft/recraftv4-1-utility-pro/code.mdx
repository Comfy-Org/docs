То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/recraft/recraftv4_1_utility_pro/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из любого другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "recraft/recraftv4_1_utility_pro",
            {
                "n": 1,
                "prompt": "A single red maple leaf on a plain white background.",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указывает сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, которое возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("recraft/recraftv4_1_utility_pro", {
  n: 1,
  prompt: "A single red maple leaf on a plain white background.",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указывает сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/recraft/recraftv4_1_utility_pro/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"n\": 1, \"prompt\": \"A single red maple leaf on a plain white background.\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/recraft/recraftv4_1_utility_pro/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с собственным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/recraft/recraftv4_1_utility_pro/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

Написания, которые поставляет Comfy (набор, который Comfy Router адресует как `recraft/<model>`), таковы: recraftv2, recraftv3, recraftv4, recraftv4_pro, recraftv4_1, recraftv4_1_flash_v2, recraftv4_1_utility, recraftv4_1_pro, recraftv4_1_utility_pro, recraftv4_styles, recraftv4_styles_pro, recraftv4_1_vector, recraftv4_1_utility_vector, recraftv4_1_pro_vector, recraftv4_1_utility_pro_vector, recraftv4_styles_vector и recraftv4_styles_pro_vector. Они перечислены здесь явно, а не указаны по ссылке, потому что компонент RecraftGenerationModel, который их объявляет, нигде не подключается через `$ref` и поэтому удаляется из спецификации, отдаваемой по GET /openapi, так что указатель на него остался бы висячим в отдаваемом документе. Четыре написания `recraftv4_styles*` дополнительно требуют `style_id`: см. это поле.
</ParamField>

<ParamField body="style" type="string">

<ParamField body="style_id" type="string">
  Идентификатор стиля, применяемого к сгенерированному изображению (например, «123e4567-e89b-12d3-a456-426614174000»). Если указан style_id, style указывать не следует. ОБЯЗАТЕЛЕН для четырёх моделей `recraftv4_styles*`: Recraft отклоняет их без style_id или ссылки на стиль. Создайте его с помощью `POST /proxy/recraft/styles`: этот же прокси обслуживает этот эндпоинт с теми же учётными данными. Ничто на этом маршруте не проверяет эту связку: тело пересылается в Recraft без изменений, поэтому вызов `recraftv4_styles*` без него доходит до партнёра и возвращается с 4xx.
</ParamField>
