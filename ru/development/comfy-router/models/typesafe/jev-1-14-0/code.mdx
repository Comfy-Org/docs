То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/typesafe/jev-1.14.0/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирают, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "typesafe/jev-1.14.0",
            {
                "questions": {
                    "department": {
                        "criteria": {
                            "billing": "Payments, invoicing, refunds",
                            "technical": "Bugs, outages, integrations",
                        },
                        "instructions": "Which team should handle this?",
                        "type": "choice",
                    },
                    "is_urgent": {
                        "instructions": "Does this convey urgency?",
                        "type": "noul",
                    },
                },
                "state": "Help! My payouts have been failing for 3 days.",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, возбуждает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("typesafe/jev-1.14.0", {
  questions: {
    department: {
      criteria: {
        billing: "Payments, invoicing, refunds",
        technical: "Bugs, outages, integrations",
      },
      instructions: "Which team should handle this?",
      type: "choice",
    },
    is_urgent: {
      instructions: "Does this convey urgency?",
      type: "noul",
    },
  },
  state: "Help! My payouts have been failing for 3 days.",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// То же значение, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

## Схема

### Входы

<ParamField body="assets" type="object">
  Изображения в запросе, с ключами по строке-ссылке. Каждая ссылка должна встречаться где-то в `state`, `instructions` или `criteria`. Каждое изображение — неподвижный PNG или JPEG размером от 280 до 1568 пикселей по каждой стороне и не более 16 MiB после декодирования; TypeSafe отклоняет вызов, превышающий 32 MiB в сумме.
</ParamField>

<ParamField body="model" type="string">
  Закреплённая версия Jev. Необязательно: Router заполняет её из идентификатора модели в пути. Псевдонимы `jev-latest` и `jev-preview` не принимаются.
</ParamField>

<ParamField body="questions" type="object" required>
  Вопросы, на которые нужно ответить, с ключами по выбранному вами id. Ответ на каждый возвращается под тем же id.
</ParamField>

<ParamField body="state" type="object" required>
  Содержимое для оценки: строка или структурированные данные (объект или массив) глубиной до 64 уровней. Любая ссылка на ассет в нём заменяется этим изображением.
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по `GET /v2/models/typesafe/jev-1.14.0/openapi.json`: это тот же документ, по которому он проверяет вызов, прежде чем запрос дойдёт до провайдера.

### Выходы

<ResponseField name="answers" type="object" required>
  Один ответ на каждый вопрос, с ключами по отправленным вами id вопросов.
</ResponseField>

<ResponseField name="model" type="string" required>
  Версия Jev, которая ответила, например `jev-1.14.0`.
</ResponseField>

<ResponseField name="usage" type="object">
  Использование токенов для запроса.
</ResponseField>

<ResponseField name="usage.input_tokens" type="integer">
  Входные токены, включая каждое изображение в запросе.
</ResponseField>

<ResponseField name="usage.output_tokens" type="integer">

</ResponseField>
