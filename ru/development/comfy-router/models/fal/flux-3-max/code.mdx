То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/fal/flux-3-max/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "fal/flux-3-max",
            {
                "duration": 5,
                "prompt": "A red panda walks along a mossy log in a sunlit forest. Ambient birdsong.",
                "resolution": "720p",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивать до завершения запроса, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("fal/flux-3-max", {
  duration: 5,
  prompt: "A red panda walks along a mossy log in a sunlit forest. Ambient birdsong.",
  resolution: "720p",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивать до завершения запроса, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
  -H "X-API-Key: $COMFY_API_KEY"
```

### Входы

<ParamField body="aspect_ratio" type="string" default="&quot;auto&quot;">
  Соотношение сторон сгенерированного видео. Значение `auto` задаёт 16:9 для текстового промпта, а в остальных случаях следует за первым изображением.

  Возможные значения: `auto`, `21:9`, `2:1`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  Длительность сгенерированного видео в секундах, от 5 до 20. fal взимает плату за каждую секунду этого значения.

  Диапазон: от `5` до `20`
</ParamField>

<ParamField body="generate_audio" type="boolean" default="true">
  Генерировать синхронизированное аудио. Стоимость не меняется.
</ParamField>

<ParamField body="prompt" type="string" required>
  Текстовый промпт, который описывает видео и его звук.
</ParamField>

<ParamField body="reasoning_level" type="string" default="&quot;high&quot;">
  Насколько глубоко модель анализирует и расширяет промпт перед генерацией. Значение `high` работает медленнее. Стоимость не меняется.

  Возможные значения: `low`, `high`
</ParamField>

<ParamField body="resolution" type="string" default="&quot;720p&quot;">
  Разрешение сгенерированного видео. 1080p стоит дороже за секунду, чем 720p.

  Возможные значения: `720p`, `1080p`
</ParamField>

<ParamField body="seed" type="integer">
  Случайный сид. Если параметр не указан, выбирается случайный сид.
</ParamField>
