Справочник по API для `fal/h3-max-turbo`, предоставляемый Comfy Router от fal.

**Вход:** текст, изображение, видео, аудио · **Выход:** видео + аудио

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. В сниппетах Python и TypeScript используются Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); сниппет cURL делает тот же вызов напрямую через HTTP.

**ID модели:** `fal/h3-max-turbo`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/fal/h3-max-turbo`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/fal/h3-max-turbo/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "fal/h3-max-turbo",
            {
                "duration": 5,
                "prompt": "a red fox running through a snowy forest",
                "prompt_expansion_mode": "balanced",
                "resolution": "480P",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте статус, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("fal/h3-max-turbo", {
  duration: 5,
  prompt: "a red fox running through a snowy forest",
  prompt_expansion_mode: "balanced",
  resolution: "480P",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте статус, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/fal/h3-max-turbo/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"duration\": 5, \"prompt\": \"a red fox running through a snowy forest\", \"prompt_expansion_mode\": \"balanced\", \"resolution\": \"480P\"}"

# 2. Опрос, пока статус не станет COMPLETED, с ожиданием Retry-After секунд, указанных в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/fal/h3-max-turbo/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/fal/h3-max-turbo/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

<ParamField body="seed" type="integer">

</ParamField>

<ParamField body="sync_mode" type="boolean">
  Вернуть сгенерированное видео в виде base64 вместо URL из CDN.
</ParamField>
