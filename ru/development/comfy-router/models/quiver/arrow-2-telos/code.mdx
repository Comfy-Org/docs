## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты на Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL: тот же вызов напрямую по HTTP.

**ID модели:** `quiver/arrow-2-telos`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/quiver/arrow-2-telos`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/quiver/arrow-2-telos/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирают, когда он готов, из этого процесса или из любого другого. В разделе [Доставка через очередь](/ru/development/comfy-router/queue) описаны статус, отмена и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "quiver/arrow-2-telos",
            {
                "n": 1,
                "prompt": "A single red maple leaf on a plain white background.",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивать до завершения запроса, выдерживая паузу Retry-After, указанную сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственные данные провайдера: то же значение, что возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, здесь вызывает типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("quiver/arrow-2-telos", {
  n: 1,
  prompt: "A single red maple leaf on a plain white background.",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивать до завершения запроса, выдерживая паузу Retry-After, указанную сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, здесь отклоняется.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/quiver/arrow-2-telos/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"n\": 1, \"prompt\": \"A single red maple leaf on a plain white background.\"}"

# 2. Опрос до статуса COMPLETED с ожиданием Retry-After секунд, указанных в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/quiver/arrow-2-telos/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с собственным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/quiver/arrow-2-telos/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```
