Справочник по API для Ideogram 4.0. Ideogram 4.0 это модель текст в изображение от Ideogram, которая отрисовывает разборчивый текст внутри сгенерированных изображений.

**Вход:** текст · **Выход:** изображение

## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты на Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL делает тот же вызов по обычному HTTP.

**ID модели:** `ideogram/ideogram-v4`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/ideogram/ideogram-v4`

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# SDK автоматически создаёт ключ идемпотентности и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        result = await client.models.run(
            "ideogram/ideogram-v4",
            {
                "text_prompt": "a single red maple leaf on a plain white background, studio lighting",
                "resolution": "1024x1024",
                "rendering_speed": "DEFAULT",
            },
        )

    print("image:", result["data"][0]["url"])

asyncio.run(main())
```

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/ideogram/ideogram-v4/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или из другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "ideogram/ideogram-v4",
            {
                "text_prompt": "a single red maple leaf on a plain white background, studio lighting",
                "resolution": "1024x1024",
                "rendering_speed": "DEFAULT",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, который указал сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print("image:", result["data"][0]["url"])

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
type Result = { data: { url: string }[] };
const handle = await comfy.models.submit<Result>("ideogram/ideogram-v4", {
  text_prompt: "a single red maple leaf on a plain white background, studio lighting",
  resolution: "1024x1024",
  rendering_speed: "DEFAULT",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, который указал сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();
if (result.kind !== "json") throw new Error("expected a JSON result");

console.log("image:", result.data.data[0].url);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/ideogram/ideogram-v4/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"text_prompt\": \"a single red maple leaf on a plain white background, studio lighting\", \"resolution\": \"1024x1024\", \"rendering_speed\": \"DEFAULT\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выжидая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/ideogram/ideogram-v4/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/ideogram/ideogram-v4/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="enable_copyright_detection" type="boolean">
  Включить детекцию авторских прав после генерации (проверки сходства и логотипов Hive).
</ParamField>

<ParamField body="json_prompt" type="object">
  Структурированный промпт V4. Отключает Magic Prompt и используется напрямую. Укажите ровно одно из полей: text_prompt или json_prompt.
</ParamField>

<ParamField body="rendering_speed" type="string" default="&quot;DEFAULT&quot;">
  Настройка скорости рендеринга, которая определяет баланс между скоростью генерации и качеством

  Возможные значения: `DEFAULT`, `TURBO`, `QUALITY`
</ParamField>

<ParamField body="resolution" type="string">
  Разрешение результата в формате ШИРИНАxВЫСОТА. Не указывайте, чтобы модель сама выбрала соотношение сторон. Поддерживаемые значения 2K: 2048x2048, 1440x2880, 2880x1440, 1664x2496, 2496x1664, 1792x2240, 2240x1792, 1440x2560, 2560x1440, 1600x2560, 2560x1600, 1728x2304, 2304x1728, 1296x3168, 3168x1296, 1152x2944, 2944x1152, 1248x3328, 3328x1248, 1280x3072, 3072x1280.
</ParamField>

<ParamField body="text_prompt" type="string">
  Промпт на естественном языке. Автоматически включает Magic Prompt. Укажите ровно одно из полей: text_prompt или json_prompt.
</ParamField>

Сгенерировано из схемы, которую Router предоставляет по адресу `GET /v2/models/ideogram/ideogram-v4/openapi.json`. Это тот же документ, по которому он проверяет вызов, прежде чем запрос дойдёт до провайдера.
