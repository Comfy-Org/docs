Справочник по API для `ideogram/p-image-ideogram`, предоставляемой через Comfy Router от Ideogram.

**Вход:** Текст · **Выход:** Изображение

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL делает тот же вызов по обычному HTTP.

**ID модели:** `ideogram/p-image-ideogram`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/ideogram/p-image-ideogram`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/ideogram/p-image-ideogram/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и повторно использует его для автоматических повторов.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "ideogram/p-image-ideogram",
            {
                "prompt": "A beautiful mountain landscape",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственные данные провайдера, то же значение, которое возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и повторно использует его для автоматических повторов.
const handle = await comfy.models.submit("ideogram/p-image-ideogram", {
  prompt: "A beautiful mountain landscape",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/ideogram/p-image-ideogram/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"prompt\": \"A beautiful mountain landscape\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/ideogram/p-image-ideogram/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/ideogram/p-image-ideogram/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="aspect_ratio" type="string">
  Соотношение сторон в формате WxH. Поддерживаемые значения: 1x3, 3x1, 1x2, 2x1, 9x16, 16x9, 10x16, 16x10, 2x3, 3x2, 3x4, 4x3, 4x5, 5x4, 1x1. По умолчанию: 1x1.
</ParamField>

<ParamField body="enable_copyright_detection" type="boolean">
  Включить детекцию авторских прав после генерации (проверки сходства и логотипов Hive).
</ParamField>

<ParamField body="prompt" type="string" required>
  Промпт для генерации изображения: либо естественный язык, либо структурированный JSON-промпт Ideogram 4.0.
</ParamField>

<ParamField body="prompt_upsampling" type="string">
  Режим апсемплинга промпта. Поддерживаемые значения: AUTO, ON и OFF. По умолчанию: AUTO.
</ParamField>

<ParamField body="quality" type="string">
  Уровень качества генерации. Поддерживаемые значения: VERY_LOW, LOW, MEDIUM и HIGH. По умолчанию: MEDIUM.
</ParamField>

<ParamField body="resolution" type="string">
  Разрешение выходного изображения. Поддерживаемые значения: 1K и 2K. По умолчанию: 1K.
</ParamField>

<ParamField body="seed" type="integer">
  Значение seed для воспроизводимой генерации
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/ideogram/p-image-ideogram/openapi.json`, тому же документу, по которому он проверяет вызов до того, как запрос дойдёт до провайдера.

### Выходы

<ResponseField name="created" type="string (date-time)">
  Временная метка создания генерации.

  Формат: `date-time`
</ResponseField>

<ResponseField name="data" type="object[]">
  Массив с информацией о сгенерированных изображениях.
</ResponseField>

<ResponseField name="data[].is_image_safe" type="boolean">
  Указывает, считается ли изображение безопасным.
</ResponseField>

<ResponseField name="data[].prompt" type="string">
  Промпт, использованный для генерации этого изображения.
</ResponseField>

<ResponseField name="data[].resolution" type="string">
  Разрешение сгенерированного изображения (например, '1024x1024').
</ResponseField>

<ResponseField name="data[].seed" type="integer">
  Значение seed, использованное для этой генерации.
</ResponseField>

<ResponseField name="data[].style_type" type="string">
  Тип стиля, использованный для генерации (например, 'REALISTIC', 'ANIME').
</ResponseField>

<ResponseField name="data[].url" type="string">
  URL сгенерированного изображения.
</ResponseField>
