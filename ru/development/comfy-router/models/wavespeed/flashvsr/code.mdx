Справочник по API для `wavespeed/flashvsr`, предоставляемый Comfy Router от WaveSpeed.

**Вход:** Видео · **Выход:** Видео

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL это тот же вызов напрямую по HTTP.

**ID модели:** `wavespeed/flashvsr`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/wavespeed/flashvsr`

```python Python
from comfy_sdk import Comfy

# Читает COMFY_API_KEY из переменных окружения.
# SDK автоматически создаёт ключ идемпотентности и переиспользует его для автоматических повторов.
```

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/wavespeed/flashvsr/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его для автоматических повторов.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "wavespeed/flashvsr",
            {
                "duration": 4,
                "target_resolution": "1080p",
                "video": "https://samplelib.com/mp4/sample-30s.mp4",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его для автоматических повторов.
const handle = await comfy.models.submit("wavespeed/flashvsr", {
  duration: 4,
  target_resolution: "1080p",
  video: "https://samplelib.com/mp4/sample-30s.mp4",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/wavespeed/flashvsr/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"duration\": 4, \"target_resolution\": \"1080p\", \"video\": \"https://samplelib.com/mp4/sample-30s.mp4\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая указанное в каждом ответе число секунд Retry-After.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/wavespeed/flashvsr/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока он ещё выполняется.
curl https://api.comfy.org/v2/models/wavespeed/flashvsr/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="duration" type="number" required>
  Длительность видео в секундах
</ParamField>

<ParamField body="target_resolution" type="string" default="&quot;1080p&quot;">
  Целевое разрешение, до которого выполняется upscale.

  Возможные значения: `720p`, `1080p`, `2k`, `4k`
</ParamField>

<ParamField body="video" type="string" required>
  Видео для upscale. Это может быть URL на видеофайл или видео в кодировке base64.
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/wavespeed/flashvsr/openapi.json`, того же документа, с которым он сверяет вызов, прежде чем запрос дойдёт до провайдера.

### Выходы

<ResponseField name="code" type="integer">
  Собственный код статуса конверта WavespeedAI, повторяющий HTTP-статус (200 в документе, который описывает эта схема). Некоторые ошибки Wavespeed сообщает здесь, а не в транспортном статусе.
</ResponseField>

<ResponseField name="data" type="object" required>
   
</ResponseField>

<ResponseField name="data.created_at" type="string">
  Отметка времени в формате ISO-8601, когда Wavespeed создал предсказание.
</ResponseField>

<ResponseField name="data.error" type="string">
  Причина ошибки в свободной форме от Wavespeed; пустая строка, если ошибки нет. Предсказание, которое действительно завершилось ошибкой, приходит вызывающему Router как ошибка Comfy Router, а не как этот документ.
</ResponseField>

<ResponseField name="data.id" type="string">
  Идентификатор предсказания в Wavespeed, которое Router отправил и опрашивал.
</ResponseField>

<ResponseField name="data.model" type="string">
  Идентификатор модели Wavespeed, на которой выполнялось предсказание.
</ResponseField>

<ResponseField name="data.outputs" type="string[]" required>
  Завершённая генерация. В документе, который возвращает Router, присутствует и не пуст; этот список И ЕСТЬ результат. Каждый элемент: URL на сгенерированное содержимое (MP4 для `wavespeed/flashvsr`, изображение для двух upscale-моделей) или, для двух идентификаторов изображений, когда в запросе задан `enable_base64_output`, сами байты в кодировке base64. Ссылки принадлежат Wavespeed и истекают.
</ResponseField>

<ResponseField name="data.status" type="string" required>
  Терминальное состояние предсказания в том виде, как его записал Wavespeed. Здесь оно не сужено до перечисления: Router передаёт значение без изменений, а классификатор опроса приводит его к нижнему регистру перед сравнением, поэтому успех может законно прийти как `completed`, `succeeded`, `success` или `done` в любом регистре.
</ResponseField>

<ResponseField name="data.timings" type="object">
  Собственные измерения времени Wavespeed.
</ResponseField>

<ResponseField name="data.timings.inference" type="integer">
  Время вывода в миллисекундах. Это число Wavespeed, а не списанная сумма Comfy.
</ResponseField>

<ResponseField name="data.urls" type="object">
  Собственные ссылки Wavespeed для предсказания.
</ResponseField>

<ResponseField name="data.urls.get" type="string">
  URL результата предсказания, который опрашивал Router.
</ResponseField>

<ResponseField name="message" type="string">
  Сообщение статуса конверта, например `success`.
</ResponseField>
