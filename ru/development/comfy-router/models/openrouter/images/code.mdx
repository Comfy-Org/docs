Ссылка на API для `openrouter/images`, предоставляемая Comfy Router от Openrouter.

**Вход:** текст, изображение · **Выход:** изображение

## Настройка запроса

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Для Python выполните `pip install comfy-sdk`. Для TypeScript выполните `npm install @comfyorg/sdk`. cURL использует обычный HTTP.

**ID модели:** `openrouter/images`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/openrouter/images`

<Note>
У этой модели нет примера запроса, который можно запустить. Соберите тело запроса по документации по входам ниже, затем используйте его вместе с [кратким руководством Router](/ru/development/comfy-router/quickstart).
</Note>

### Выходы

<ResponseField name="created" type="integer">
  Временная метка Unix создания
</ResponseField>

<ResponseField name="data" type="object[]">
  Сгенерированные изображения
</ResponseField>

<ResponseField name="data[].b64_json" type="string">
  Данные изображения в кодировке Base64. Когда ответ больше 1,048,576 байт, Comfy Router возвращает вместо него `url`. Изображение остаётся здесь, если ответ не больше этого размера или если его загрузка в хранилище Comfy не удалась.
</ResponseField>

<ResponseField name="data[].media_type" type="string">
  MIME-тип изображения
</ResponseField>

<ResponseField name="data[].url" type="string">
  Подписанный URL изображения, размещённого в Comfy, возвращается вместо `b64_json`, когда ответ больше 1,048,576 байт. Comfy Router запрашивает его всегда; маршрут `/proxy/` запрашивает его только когда запрос отправляет `Comfy-Asset-Format: url`. Рабочее пространство с нулевым хранением данных никогда его не получает: его изображения остаются в `b64_json`. URL истекает через 24 часа после вызова.
</ResponseField>

<ResponseField name="usage" type="object">
  Использование при генерации изображений
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  Сгенерированные токены
</ResponseField>

<ResponseField name="usage.cost" type="number">
  Полная стоимость запроса в USD

  Формат: `double`
</ResponseField>

<ResponseField name="usage.prompt_tokens" type="integer">
  Токены, использованные для входа
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  Всего токенов для запроса
</ResponseField>
