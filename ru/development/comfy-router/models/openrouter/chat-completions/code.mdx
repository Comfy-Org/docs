Ссылка на API для `openrouter/chat-completions`, который предоставляет Comfy Router от Openrouter.

**Вход:** Text, Image · **Выход:** Text

## Настройка запроса

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Для Python выполните `pip install comfy-sdk`. Для TypeScript выполните `npm install @comfyorg/sdk`. В cURL используется обычный HTTP.

**ID модели:** `openrouter/chat-completions`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/openrouter/chat-completions`

<Note>
Для этой модели нет готового примера запроса. Соберите тело запроса по документации входов ниже, а затем используйте его вместе с [кратким руководством по Router](/ru/development/comfy-router/quickstart).
</Note>
