Справочник по API для `beeble/switchx`, предоставляемого Comfy Router от Beeble.

**Вход:** изображение, видео, текст · **Выход:** изображение + видео

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. В сниппетах Python и TypeScript используются Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); сниппет cURL выполняет тот же вызов напрямую по HTTP.

**ID модели:** `beeble/switchx`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/beeble/switchx`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/beeble/switchx/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "beeble/switchx",
            {
                "alpha_mode": "auto",
                "generation_type": "image",
                "max_resolution": 720,
                "prompt": "A cinematic product photo of a glass lamp on a marble table",
                "source_uri": "https://img.freepik.com/free-photo/portrait-woman_395237-33.jpg?w=740&q=80",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, ожидая Retry-After, который называет сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, возбуждает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("beeble/switchx", {
  alpha_mode: "auto",
  generation_type: "image",
  max_resolution: 720,
  prompt: "A cinematic product photo of a glass lamp on a marble table",
  source_uri: "https://img.freepik.com/free-photo/portrait-woman_395237-33.jpg?w=740&q=80",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, ожидая Retry-After, который называет сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправьте запрос. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/beeble/switchx/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"alpha_mode\": \"auto\", \"generation_type\": \"image\", \"max_resolution\": 720, \"prompt\": \"A cinematic product photo of a glass lamp on a marble table\", \"source_uri\": \"https://img.freepik.com/free-photo/portrait-woman_395237-33.jpg?w=740&q=80\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, ожидая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/beeble/switchx/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Заберите результат. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/beeble/switchx/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="alpha_mode" type="string" required>
  Режим альфа-канала: auto, fill, custom или select

  Возможные значения: `auto`, `fill`, `custom`, `select`
</ParamField>

<ParamField body="alpha_uri" type="string">
  URI пользовательской альфа-маски. Обязательно, если alpha_mode равен custom или select. Игнорируется для auto или fill.
</ParamField>

<ParamField body="callback_url" type="string">
  HTTPS-URL для уведомления через вебхук о завершении или ошибке.
</ParamField>

<ParamField body="generation_type" type="string" required>
  Тип выходных данных: изображение или видео

  Возможные значения: `image`, `video`
</ParamField>

<ParamField body="idempotency_key" type="string">
  Ключ идемпотентности для безопасных повторных попыток. Если задача с тем же ключом уже существует для вашей учётной записи, API возвращает статус существующей задачи вместо создания дубликата.
</ParamField>

<ParamField body="max_resolution" type="integer" default="1080">
  Максимальное разрешение выходных данных: 720 или 1080 (по умолчанию: 1080).
</ParamField>

<ParamField body="prompt" type="string">
  Текстовое описание желаемого результата (максимум 2,000 символов). Требуется хотя бы одно из полей prompt или reference_image_uri.
</ParamField>

<ParamField body="reference_image_uri" type="string">
  URI референсного изображения для переноса стиля. Принимает те же типы URI, что и source_uri.
</ParamField>

<ParamField body="source_uri" type="string" required>
  URI исходного изображения или видео. Принимает beeble://uploads/\{id}/\{filename}, URL-адреса https или URI data:\{mime};base64 (максимум 50 MB).
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/beeble/switchx/openapi.json`: это тот же документ, по которому он проверяет вызов до того, как запрос доходит до провайдера.
