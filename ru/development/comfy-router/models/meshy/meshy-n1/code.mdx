То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/meshy/meshy-n1/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создает собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "meshy/meshy-n1",
            {
                "image_style_url": "https://example.invalid/meshy/n1/front.png",
                "model_url": "https://cdn.meshy.ai/model/example_model_2.glb",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создает собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("meshy/meshy-n1", {
  image_style_url: "https://example.invalid/meshy/n1/front.png",
  model_url: "https://cdn.meshy.ai/model/example_model_2.glb",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/meshy/meshy-n1/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"

## Схема

### Входы

<ParamField body="ai_model" type="string">
  Модель Meshy для запуска. На маршруте Comfy Router она передаётся через путь (`/v2/models/meshy/{model}`) и может быть опущена или отправлена как null; после валидации Router записывает сюда модель из пути.
</ParamField>

<ParamField body="enable_original_uv" type="boolean">
  Использовать оригинальные UV модели вместо генерации новых UV.
</ParamField>

<ParamField body="enable_pbr" type="boolean" default="false">
  meshy-n1 не генерирует PBR-карты, поэтому принимается только false.

  Возможные значения: `false`
</ParamField>

<ParamField body="image_style_url" type="string">
  Одно референсное изображение, используемое как вид спереди. Поддерживаются jpg, jpeg, png и webp, а также base64 data URI. Не отправляйте вместе с multiview_image_urls.
</ParamField>

<ParamField body="input_task_id" type="string">
  ID завершённой задачи Meshy, чья сетка будет текстурирована. Обязательно, если model_url не указан.
</ParamField>

<ParamField body="model_url" type="string">
  Публично доступный URL или data URI на 3D-модель. Поддерживаемые форматы: glb, gltf, obj, fbx, stl. Обязательно, если input_task_id не указан. Не более 7,999,999 треугольных граней.
</ParamField>

<ParamField body="multiview_image_urls" type="string[]">
  От одного до четырёх референсных изображений одного и того же объекта. Первое изображение является видом спереди. Не отправляйте вместе с image_style_url.
</ParamField>

<ParamField body="target_formats" type="string[]">
  Форматы модели для генерации. Один или несколько из glb, obj, fbx, stl, usdz и 3mf.
</ParamField>

<ParamField body="texture_resolution" type="string" default="&quot;2k&quot;">
  Разрешение текстуры карты базового цвета. meshy-n1 поддерживает только 2k.

  Возможные значения: `2k`
</ParamField>
