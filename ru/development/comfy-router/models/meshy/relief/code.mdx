Ссылка на API для `meshy/relief`, предоставляемого Comfy Router от Meshy.

**Вход:** Image · **Выход:** Image + 3D

## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов по «сырому» HTTP.

**ID модели:** `meshy/relief`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/meshy/relief`

from comfy_sdk import Comfy

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/meshy/relief/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из любого другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "meshy/relief",
            {
                "image_url": "https://example.invalid/meshy/relief/logo.png",
                "variant": "low",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указал сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственные данные провайдера: то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("meshy/relief", {
  image_url: "https://example.invalid/meshy/relief/logo.png",
  variant: "low",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указал сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/meshy/relief/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"image_url\": \"https://example.invalid/meshy/relief/logo.png\", \"variant\": \"low\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/meshy/relief/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/meshy/relief/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="base_thickness_mm" type="number">
  Толщина базовой пластины в миллиметрах, от 0.1 до 10. Если remove_base равен true, не указывайте её или отправьте 0.

  Диапазон: от `0` до `10`
</ParamField>

<ParamField body="bend_angle" type="number" default="60">
  Угол изгиба в градусах. При значении меньше 1 рельеф остаётся плоским.

  Диапазон: от `0` до `360`
</ParamField>

<ParamField body="bend_axis" type="string">
  `xz` (по умолчанию, изгибает левое и правое ребра) или `yz` (изгибает верхнее и нижнее ребра). Применяется только когда bend_mode равен convex или concave.
</ParamField>

<ParamField body="bend_mode" type="string">
  `off` (по умолчанию), `convex` или `concave`.
</ParamField>

<ParamField body="carving_depth_mm" type="number">
  Глубина гравировки в миллиметрах. По умолчанию 6 для variant high и 3 для variant low.

  Диапазон: от `0` до `60`
</ParamField>

<ParamField body="carving_mode" type="string">
  `emboss` (по умолчанию) или `engrave`.
</ParamField>

<ParamField body="color_mapping" type="boolean" default="false">
  Раскрасить модель по изображению. GLB, OBJ, FBX и USDZ передают цвет, STL и 3MF остаются белыми. Стоимость не меняется.
</ParamField>

<ParamField body="image_url" type="string" required>
  Публичный URL или data URI изображения jpg, jpeg, png или webp. Не более 20 MB и не менее 32 x 32 пикселей. Прозрачные области заполняются чёрным цветом.
</ParamField>

<ParamField body="mesh_resolution" type="integer" default="1024">
  Количество точек по длинной стороне. Большие значения дают значительно более крупные файлы (около 150 MB GLB и 300 MB STL при 2048).

  Диапазон: от `512` до `2048`
</ParamField>

<ParamField body="removal_threshold" type="number" default="0.01">
  Порог удаления фона. Применяется только когда remove_base равен true.

  Диапазон: от `0.01` до `1`
</ParamField>

<ParamField body="remove_base" type="boolean" default="false">
  Срезать фон, чтобы у рельефа не было базовой пластины.
</ParamField>

<ParamField body="should_generate_model" type="boolean" default="true">
  Установите false, чтобы получить только карту глубины, без модели и без предпросмотра. Стоимость не меняется.
</ParamField>

<ParamField body="size_mm" type="number" default="60">
  Длина длинной стороны в миллиметрах.

  Диапазон: от `20` до `250`
</ParamField>

<ParamField body="target_formats" type="string[]">
  Форматы модели для генерации. Один или несколько из glb, obj, fbx, stl, usdz и 3mf. По умолчанию glb и stl.
</ParamField>

<ParamField body="variant" type="string">
  `low` (по умолчанию) даёт небольшую глубину и более мелкие детали, для лазерной обработки или работ на CNC. `high` даёт более глубокий, скульптурный рельеф, для 3D-печати. Он также задаёт значение carving_depth_mm по умолчанию.
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по `GET /v2/models/meshy/relief/openapi.json`, того же документа, по которому он проверяет вызов до того, как запрос дойдёт до провайдера.

### Выходы

<ResponseField name="consumed_credits" type="integer">
  Кредиты Meshy, использованные задачей. 0 для задачи с ошибкой.
</ResponseField>

<ResponseField name="created_at" type="integer">
  Метка времени создания задачи в миллисекундах.

  Формат: `int64`
</ResponseField>

<ResponseField name="depth_map_url" type="string">
  URL для скачивания PNG-файла карты глубины 2k, 16-бит, в градациях серого. Значения относительные, не в миллиметрах.
</ResponseField>

<ResponseField name="expires_at" type="integer">
  Метка времени истечения срока действия результата задачи в миллисекундах. 0, если задача не завершена.

  Формат: `int64`
</ResponseField>

<ResponseField name="finished_at" type="integer">
  Метка времени завершения задачи в миллисекундах. 0, если задача не завершена.

  Формат: `int64`
</ResponseField>

<ResponseField name="id" type="string" required>
  Уникальный идентификатор задачи.
</ResponseField>

<ResponseField name="model_urls" type="object">
  URL для скачивания файлов модели рельефа, по одному на каждый запрошенный формат. Пусто для задачи только с картой глубины.
</ResponseField>

<ResponseField name="model_urls.3mf" type="string">
  URL для скачивания файла 3MF.
</ResponseField>

<ResponseField name="model_urls.fbx" type="string">
  URL для скачивания файла FBX.
</ResponseField>

<ResponseField name="model_urls.glb" type="string">
  URL для скачивания файла GLB, в метрах.
</ResponseField>

<ResponseField name="model_urls.mtl" type="string">
  URL для скачивания файла материала MTL для файла OBJ.
</ResponseField>

<ResponseField name="model_urls.obj" type="string">
  URL для скачивания файла OBJ.
</ResponseField>

<ResponseField name="model_urls.stl" type="string">
  URL для скачивания бинарного файла STL, в миллиметрах.
</ResponseField>

<ResponseField name="model_urls.usdz" type="string">
  URL для скачивания файла USDZ.
</ResponseField>

<ResponseField name="preceding_tasks" type="integer">
  Количество предшествующих задач. Имеет смысл только когда статус имеет значение PENDING.
</ResponseField>

<ResponseField name="progress" type="integer">
  Прогресс задачи. 0, если задача не начата, 100 при успешном завершении.

  Диапазон: `0` до `100`
</ResponseField>

<ResponseField name="started_at" type="integer">
  Метка времени начала задачи в миллисекундах. 0, если задача не начата.

  Формат: `int64`
</ResponseField>

<ResponseField name="status" type="string" required>
  Возможные значения: `SUCCEEDED`
</ResponseField>

<ResponseField name="task_error" type="object">
  Объект ошибки, содержащий сообщение об ошибке, если задача завершилась с ошибкой.
</ResponseField>

<ResponseField name="task_error.message" type="string">
  Подробное сообщение об ошибке.
</ResponseField>

<ResponseField name="texture_urls" type="object[]">
  URL текстур. Присутствует только при color_mapping true.
</ResponseField>

<ResponseField name="texture_urls[].base_color" type="string">
  URL для скачивания изображения карты базового цвета.
</ResponseField>

<ResponseField name="texture_urls[].metallic" type="string">
  URL для скачивания изображения карты металличности.
</ResponseField>

<ResponseField name="texture_urls[].normal" type="string">
  URL для скачивания изображения карты нормалей.
</ResponseField>

<ResponseField name="texture_urls[].roughness" type="string">
  URL для скачивания изображения карты шероховатости.
</ResponseField>

<ResponseField name="thumbnail_url" type="string">
  URL для скачивания изображения предварительного просмотра. Пусто для задачи только с картой глубины.
</ResponseField>

<ResponseField name="type" type="string">
  Тип задачи. Всегда relief.
</ResponseField>
