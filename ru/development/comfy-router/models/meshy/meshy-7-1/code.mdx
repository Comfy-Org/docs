То же тело запроса, отправленное в `POST https://api.comfy.org/v2/models/meshy/meshy-7.1/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат можно получить, когда он будет готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает работу со статусом, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создает собственный Idempotency-Key и повторно использует его для автоматических повторных попыток.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "meshy/meshy-7.1",
            {
                "art_style": "realistic",
                "mode": "preview",
                "prompt": "a red cube",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это все, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создает собственный Idempotency-Key и повторно использует его для автоматических повторных попыток.
const handle = await comfy.models.submit("meshy/meshy-7.1", {
  art_style: "realistic",
  mode: "preview",
  prompt: "a red cube",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это все, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```
