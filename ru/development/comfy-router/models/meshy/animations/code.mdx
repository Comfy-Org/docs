Справочник по API для `meshy/animations`, доступного через Comfy Router от Meshy.

**Вход:** 3D · **Выход:** 3D

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты на Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов по обычному HTTP.

**Model ID:** `meshy/animations`

**Endpoint:** `POST https://api.comfy.org/v2/models/meshy/animations`

from comfy_sdk import Comfy

# Читает COMFY_API_KEY из переменных окружения.

То же тело, отправленное на `POST https://api.comfy.org/v2/models/meshy/animations/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или из другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "meshy/animations",
            {
                "action_id": 92,
                "post_process": {
                    "fps": 60,
                    "operation_type": "change_fps",
                },
                "rig_task_id": "0193abcd-0000-0000-0000-000000000000",
            },
        )
        print("request_id:", handle.request_id)  # вместе с model ID это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("meshy/animations", {
  action_id: 92,
  post_process: {
    fps: 60,
    operation_type: "change_fps",
  },
  rig_task_id: "0193abcd-0000-0000-0000-000000000000",
});
console.log("requestId:", handle.requestId); // вместе с model ID это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/meshy/animations/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"action_id\": 92, \"post_process\": {\"fps\":60,\"operation_type\":\"change_fps\"}, \"rig_task_id\": \"0193abcd-0000-0000-0000-000000000000\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/meshy/animations/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/meshy/animations/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="action_id" type="integer" required>
  Идентификатор действия анимации, которое нужно применить.
</ParamField>

<ParamField body="post_process" type="object">
  Параметры постобработки файлов анимации.
</ParamField>

<ParamField body="post_process.fps" type="integer" default="30">
  Целевая частота кадров. По умолчанию 30. Применимо, только если operation_type имеет значение change_fps.

  Возможные значения: `24`, `25`, `30`, `60`
</ParamField>

<ParamField body="post_process.operation_type" type="string" required>
  Тип выполняемой операции.

  Возможные значения: `change_fps`, `fbx2usdz`, `extract_armature`
</ParamField>

<ParamField body="rig_task_id" type="string" required>
  Идентификатор успешно завершённой задачи риггинга (из POST /openapi/v1/rigging). Персонаж из этой задачи будет анимирован.
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/meshy/animations/openapi.json` — того же документа, по которому он проверяет вызов перед тем, как запрос попадёт к провайдеру.

### Выходы

<ResponseField name="created_at" type="integer">
  Отметка времени создания задачи в миллисекундах.

  Формат: `int64`
</ResponseField>

<ResponseField name="expires_at" type="integer">
  Отметка времени истечения срока действия результата задачи в миллисекундах.

  Формат: `int64`
</ResponseField>

<ResponseField name="finished_at" type="integer">
  Отметка времени завершения задачи в миллисекундах. 0, если задача не завершена.

  Формат: `int64`
</ResponseField>

<ResponseField name="id" type="string" required>
  Уникальный идентификатор задачи.
</ResponseField>

<ResponseField name="preceding_tasks" type="integer">
  Количество задач, стоящих перед этой. Имеет смысл, только если статус PENDING.
</ResponseField>

<ResponseField name="progress" type="integer">
  Прогресс задачи (0-100).

  Диапазон: от `0` до `100`
</ResponseField>

<ResponseField name="result" type="object">
  Содержит URL-адреса выходной анимации, если задача завершилась со статусом SUCCEEDED.
</ResponseField>

<ResponseField name="result.animation_fbx_url" type="string">
  URL-адрес для скачивания анимации в формате FBX.
</ResponseField>

<ResponseField name="result.animation_glb_url" type="string">
  URL-адрес для скачивания анимации в формате GLB.
</ResponseField>

<ResponseField name="result.processed_animation_fps_fbx_url" type="string">
  URL-адрес для скачивания анимации с изменённой частотой кадров в формате FBX.
</ResponseField>

<ResponseField name="result.processed_armature_fbx_url" type="string">
  URL-адрес для скачивания обработанного арматурного скелета в формате FBX.
</ResponseField>

<ResponseField name="result.processed_usdz_url" type="string">
  URL-адрес для скачивания обработанной анимации в формате USDZ.
</ResponseField>

<ResponseField name="started_at" type="integer">
  Отметка времени запуска задачи в миллисекундах. 0, если задача не запущена.

  Формат: `int64`
</ResponseField>

<ResponseField name="status" type="string" required>
  Возможные значения: `SUCCEEDED`
</ResponseField>

<ResponseField name="task_error" type="object">
  Объект ошибки, содержащий сообщение об ошибке, если задача завершилась неудачно.
</ResponseField>

<ResponseField name="task_error.message" type="string">
  Подробное сообщение об ошибке.
</ResponseField>

<ResponseField name="type" type="string">
  Тип задачи Animation.

  Возможные значения: `animate`
</ResponseField>
