Справочник по API для `meshy/meshy-7`, предоставляемый Comfy Router от Meshy.

**Вход:** текст · **Выход:** 3D

## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL это тот же вызов по «сырому» HTTP.

**ID модели:** `meshy/meshy-7`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/meshy/meshy-7`

```python Python
from comfy_sdk import Comfy

# Читает COMFY_API_KEY из переменных окружения.
# SDK автоматически создаёт ключ идемпотентности и переиспользует его при автоматических повторных попытках.
with Comfy() as client:
    result = client.models.run(
        "meshy/meshy-7",
        {
            "art_style": "realistic",
            "mode": "preview",
            "prompt": "a red cube",
        },
    )

print(result)
```

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/meshy/meshy-7/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторных попытках.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "meshy/meshy-7",
            {
                "art_style": "realistic",
                "mode": "preview",
                "prompt": "a red cube",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указывает сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся с ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторных попытках.
const handle = await comfy.models.submit("meshy/meshy-7", {
  art_style: "realistic",
  mode: "preview",
  prompt: "a red cube",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указывает сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся с ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/meshy/meshy-7/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"art_style\": \"realistic\", \"mode\": \"preview\", \"prompt\": \"a red cube\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/meshy/meshy-7/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с собственным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/meshy/meshy-7/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

#### Вариант `preview`

<ParamField body="ai_model" type="string">
  Модель Meshy для запуска. На маршруте Comfy Router она задаётся путём (`/v2/models/meshy/{model}`) и может быть опущена или отправлена как null; после валидации Router записывает сюда модель из пути. На маршруте v1 /proxy см. MeshyTextTo3DPreviewRequest, где она ограничена MeshyAiModel.
</ParamField>

<ParamField body="art_style" type="string" default="&quot;realistic&quot;">
  Опишите желаемый художественный стиль объекта.

  Возможные значения: `realistic`, `sculpture`
</ParamField>

<ParamField body="geometry_resolution" type="string" default="&quot;standard&quot;">
  Разрешение геометрии сгенерированной сетки. 2k и 4k запускают проход Ultra для более тонкой детализации поверхности. 2k и 4k требуют ai_model meshy-7.1 или latest.

  Возможные значения: `standard`, `2k`, `4k`
</ParamField>

<ParamField body="is_a_t_pose" type="boolean" default="false">
  Устаревший параметр. Используйте вместо него pose_mode. Определяет, генерировать ли модель в A/T-позе.
</ParamField>

<ParamField body="mode" type="string" required>
  При создании задачи предпросмотра это поле должно быть установлено в "preview".

  Возможные значения: `preview`
</ParamField>

<ParamField body="moderation" type="boolean" default="false">
  Если true, входное содержимое будет проверено на наличие потенциально вредоносного содержимого.
</ParamField>

<ParamField body="pose_mode" type="string">
  Укажите режим позы для сгенерированной модели.

  Возможные значения: `a-pose`, `t-pose`, ``
</ParamField>

<ParamField body="prompt" type="string" required>
  Опишите, что представляет собой объект 3D-модели. Максимум 800 символов.
</ParamField>

<ParamField body="should_remesh" type="boolean" default="false">
  Управляет включением фазы remesh. При false возвращается треугольная сетка наивысшей точности. По умолчанию true для Meshy 5 и false для Meshy 6 и 7.
</ParamField>

<ParamField body="symmetry_mode" type="string" default="&quot;auto&quot;">
  Управляет поведением симметрии при генерации модели.

  Возможные значения: `off`, `auto`, `on`
</ParamField>

<ParamField body="target_polycount" type="integer" default="30000">
  Укажите целевое количество полигонов в сгенерированной модели. Допустимый диапазон: от 100 до 300,000.

  Диапазон: от `100` до `300000`
</ParamField>

<ParamField body="topology" type="string" default="&quot;triangle&quot;">
  Укажите топологию сгенерированной модели.

  Возможные значения: `quad`, `triangle`
</ParamField>

<ParamField body="ultra_mode" type="boolean" default="false">
  Устаревший параметр. Используйте вместо него geometry_resolution; true эквивалентно geometry_resolution 2k. Поддерживается только когда ai_model равен meshy-7, meshy-7.1 или latest. Исключение составляет meshy-7: geometry_resolution 2k требует meshy-7.1 или latest, поэтому на meshy-7 запросить проход Ultra позволяет только ultra_mode true.
</ParamField>

#### Вариант `refine`

<ParamField body="ai_model" type="string">
  Модель Meshy для запуска. На маршруте Comfy Router она задаётся путём (`/v2/models/meshy/{model}`) и может быть опущена или отправлена как null; после валидации Router записывает сюда модель из пути. На маршруте v1 /proxy см. MeshyTextTo3DRefineRequest, где она ограничена MeshyAiModel.
</ParamField>

<ParamField body="enable_pbr" type="boolean" default="false">
  Генерировать PBR-карты (metallic, roughness, normal) в дополнение к базовому цвету. Обратите внимание: при использовании стиля Sculpture для enable_pbr следует задать false.
</ParamField>

<ParamField body="mode" type="string" required>
  При создании задачи refine это поле должно быть установлено в "refine".

  Возможные значения: `refine`
</ParamField>

<ParamField body="moderation" type="boolean" default="false">
  Если true, входное содержимое будет проверено на наличие потенциально вредоносного содержимого.
</ParamField>

<ParamField body="preview_task_id" type="string" required>
  Идентификатор соответствующей задачи предпросмотра. Статус указанной задачи предпросмотра должен быть SUCCEEDED.
</ParamField>

<ParamField body="texture_image_url" type="string">
  Предоставьте 2D-изображение для управления процессом текстурирования. Поддерживаются форматы .jpg, .jpeg, .png или base64-encoded data URI.
</ParamField>

<ParamField body="texture_prompt" type="string">
  Предоставьте дополнительный текстовый промпт для управления процессом текстурирования. Максимум 800 символов.
</ParamField>

<ParamField body="texture_resolution" type="string" default="&quot;2k&quot;">
  Разрешение сгенерированных текстур. Одно из 2k, 4k или 8k. 4k и 8k требуют ai_model meshy-6, meshy-7, meshy-7.1 или latest.

  Возможные значения: `2k`, `4k`, `8k`
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/meshy/meshy-7/openapi.json`, того же документа, по которому он валидирует вызов до того, как запрос достигнет провайдера.
