Справочник по API для `meshy/rigging`, предоставляется Comfy Router от Meshy.

**Вход:** 3D · **Выход:** 3D

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов по обычному HTTP.

**ID модели:** `meshy/rigging`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/meshy/rigging`

from comfy_sdk import Comfy

# Читает COMFY_API_KEY из переменной окружения.
# SDK автоматически создаёт ключ идемпотентности и переиспользует его при автоматических повторах.

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/meshy/rigging/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "meshy/rigging",
            {
                "height_meters": 1.8,
                "input_task_id": "0193abcd-0000-0000-0000-000000000000",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели, это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, ожидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственные данные провайдера, то же значение, что возвращает models.run().
        # Запрос, завершившийся с ошибкой или отменённый, вызовет здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("meshy/rigging", {
  height_meters: 1.8,
  input_task_id: "0193abcd-0000-0000-0000-000000000000",
});
console.log("requestId:", handle.requestId); // вместе с ID модели, это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, ожидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся с ошибкой или отменённый, будет отклонён здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/meshy/rigging/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"height_meters\": 1.8, \"input_task_id\": \"0193abcd-0000-0000-0000-000000000000\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, ожидая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/meshy/rigging/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с собственным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/meshy/rigging/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="height_meters" type="number" default="1.7">
  Приблизительный рост модели персонажа в метрах. Должен быть положительным числом.

  Диапазон: от `0` до `…`
</ParamField>

<ParamField body="include_fingers" type="boolean" default="false">
  Добавлять ли кости пальцев к кистям персонажа. Только для biped-скелета; при указании texture_image_url, quadruped-скелета или input_task_id с quad-топологией Meshy отклоняет запрос с кодом 400, а модель, которую можно риггинговать только без пальцев, с кодом 422 (средства не списываются). Кости пальцев не влияют на стоимость в кредитах. По умолчанию false.
</ParamField>

<ParamField body="input_task_id" type="string">
  Задача, результат которой нужно привязать к скелету. Обязательна, если не указан model_url.
</ParamField>

<ParamField body="model_url" type="string">
  Публично доступный URL или Data URI на текстурированный GLB-файл гуманоида. Обязателен, если не указан input_task_id.
</ParamField>

<ParamField body="skeleton_template" type="string" default="&quot;meshyrig&quot;">
  Скелет для персонажа, задающий имена костей и иерархию. Только для biped-скелета. При значении, отличном от meshyrig (или при include_fingers true), выходные файлы будут в метрах и используют кости этого скелета вместо стандартных файлов meshyrig с 24 костями в сантиметрах; задача анимации, созданная из этого рига, использует тот же скелет. Любое другое значение отклоняется. По умолчанию meshyrig.

  Возможные значения: `meshyrig`, `mixamo`, `ue5_mannequin`, `max_biped`, `unity_humanoid`, `maya_human_ik`, `blender_rigify_basic_human`, `cc5_hd_neutral_base`, `daz_genesis9`
</ParamField>

<ParamField body="texture_image_url" type="string">
  Изображение базового цвета текстуры с UV-развёрткой модели. Публично доступный URL или Data URI. Поддерживается формат .png.
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/meshy/rigging/openapi.json`, того же документа, по которому он проверяет вызов до того, как запрос дойдёт до провайдера.

<ResponseField name="finished_at" type="integer">

<ResponseField name="preceding_tasks" type="integer">
