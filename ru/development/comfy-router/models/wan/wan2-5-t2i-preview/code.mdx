Ссылка на API для модели `wan/wan2.5-t2i-preview`, предоставляемой Comfy Router от Wan.

**Вход:** текст · **Выход:** изображение

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты на Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`), а фрагмент cURL выполняет тот же вызов напрямую по HTTP.

**Model ID:** `wan/wan2.5-t2i-preview`

**Endpoint:** `POST https://api.comfy.org/v2/models/wan/wan2.5-t2i-preview`

from comfy_sdk import Comfy

# Читает COMFY_API_KEY из переменной окружения.
# SDK автоматически создаёт ключ идемпотентности и переиспользует его при автоматических повторах.

    )

То же тело, отправленное на `POST https://api.comfy.org/v2/models/wan/wan2.5-t2i-preview/requests`. Router отвечает `201` с `request_id` сразу после того, как запуск принят, а результат собирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и сбор результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "wan/wan2.5-t2i-preview",
            {
                "input": {
                    "prompt": "A single red maple leaf on a plain white background.",
                },
                "parameters": {
                    "n": 1,
                    "size": "1280*1280",
                },
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, здесь вызывает типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("wan/wan2.5-t2i-preview", {
  input: {
    prompt: "A single red maple leaf on a plain white background.",
  },
  parameters: {
    n: 1,
    size: "1280*1280",
  },
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, здесь отклоняется.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/wan/wan2.5-t2i-preview/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"input\": {\"prompt\":\"A single red maple leaf on a plain white background.\"}, \"parameters\": {\"n\":1,\"size\":\"1280*1280\"}}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выжидая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/wan/wan2.5-t2i-preview/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Сбор результата. 200 с нативным выводом модели, 202 с телом статуса, пока он ещё выполняется.
curl https://api.comfy.org/v2/models/wan/wan2.5-t2i-preview/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="input" type="object" required>
  Введите базовую информацию: промпты и т. п.
</ParamField>

<ParamField body="input.negative_prompt" type="string">
  Негативный промпт: описывает содержимое, которое вы не хотите видеть на изображении. После 500 символов модель усекает его, а не отклоняет запрос. Он учитывается в том же бюджете ввода, что и промпт.
</ParamField>

<ParamField body="input.prompt" type="string" required>
  Позитивный промпт: описывает ожидаемые элементы изображения и визуальные особенности. Поддерживает китайский и английский языки. После 2,000 символов модель усекает промпт, а не отклоняет запрос. Провайдер отклоняет запрос, если промпт и negative_prompt вместе длиннее примерно 60,850 байт текста UTF-8 (около 20,000 китайских символов), возвращая InvalidParameter `Range of input length should be [1, 61440]`.
</ParamField>

<ParamField body="model" type="string">
  ID модели, которую нужно вызвать для генерации изображения из текста. НЕ ограничен в этом компоненте: Comfy Router заполняет его из сегмента пути `{model}` запроса `POST /v2/models/wan/{model}`. Прямой вызов v1 `POST /proxy/wan/api/v1/services/aigc/text2image/image-synthesis` ДОЛЖЕН передавать его, а перечисление допустимых написаний находится в собственном компоненте этой операции, `WanImageGenerationRequest`.
</ParamField>

<ParamField body="parameters" type="object">
  Параметры обработки изображения
</ParamField>

<ParamField body="parameters.n" type="integer" default="4">
  Количество сгенерированных изображений. Диапазон 1-4, по умолчанию 4

  Диапазон: от `1` до `4`
</ParamField>

<ParamField body="parameters.prompt_extend" type="boolean" default="true">
  Включить интеллектуальное переписывание промпта. По умолчанию true
</ParamField>

<ParamField body="parameters.seed" type="integer">
  Сид случайных чисел для управления случайностью. Диапазон [0, 2147483647]

  Диапазон: от `0` до `2147483647`
</ParamField>

<ParamField body="parameters.size" type="string" default="&quot;1280*1280&quot;">
  Разрешение выходного изображения в формате ширина*высота. По умолчанию 1280*1280. API принимает площадь в пикселях от 1638400 (1280*1280) до 2073600 (1440*1440) при соотношении сторон от 1:4 до 4:1, поэтому 768*2700 допустимо
</ParamField>

<ParamField body="parameters.watermark" type="boolean" default="false">
  Добавлять ли логотип-водяной знак в правом нижнем углу
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/wan/wan2.5-t2i-preview/openapi.json`, того же документа, по которому он проверяет вызов до того, как запрос дойдёт до провайдера.
