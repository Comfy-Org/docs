Справочник по API для модели `wan/wan2.5-i2i-preview` от Wan, предоставляемой Comfy Router.

**Вход:** изображение, текст · **Выход:** изображение

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL это тот же вызов по «сырому» HTTP.

**ID модели:** `wan/wan2.5-i2i-preview`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/wan/wan2.5-i2i-preview`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/wan/wan2.5-i2i-preview/requests`. Router отвечает `201` с `request_id` сразу после того, как запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его для автоматических повторов.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "wan/wan2.5-i2i-preview",
            {
                "input": {
                    "images": ["https://example.invalid/red-maple-leaf.png"],
                    "prompt": "Make the leaf golden.",
                },
                "parameters": {
                    "n": 1,
                    "size": "768*768",
                },
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указывает сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, здесь вызывает типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его для автоматических повторов.
const handle = await comfy.models.submit("wan/wan2.5-i2i-preview", {
  input: {
    images: ["https://example.invalid/red-maple-leaf.png"],
    prompt: "Make the leaf golden.",
  },
  parameters: {
    n: 1,
    size: "768*768",
  },
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указывает сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, здесь отклоняется.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/wan/wan2.5-i2i-preview/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"input\": {\"images\":[\"https://example.invalid/red-maple-leaf.png\"],\"prompt\":\"Make the leaf golden.\"}, \"parameters\": {\"n\":1,\"size\":\"768*768\"}}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/wan/wan2.5-i2i-preview/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/wan/wan2.5-i2i-preview/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="input" type="object" required>
  Введите базовую информацию: промпты, изображения и т. д.
</ParamField>

<ParamField body="input.images" type="string[]" required>
  Массив от 1 до 3 URL изображений для генерации изображение в изображение
</ParamField>

<ParamField body="input.negative_prompt" type="string">
  Негативный промпт, описывающий содержимое, которое вы не хотите видеть на изображении. Он расходует тот же бюджет ввода, что и prompt.
</ParamField>

<ParamField body="input.prompt" type="string" required>
  Позитивный промпт, описывающий ожидаемые элементы изображения и визуальные особенности. Поддерживает китайский и английский языки. Промпт длиннее, чем считывает модель, обрезается, а не отклоняется. Провайдер отклоняет запрос, если prompt и negative_prompt вместе длиннее примерно 60 850 байт текста в UTF-8 (около 20 000 китайских символов), возвращая InvalidParameter `Range of input length should be [1, 61440]`.
</ParamField>

<ParamField body="model" type="string">
  ID модели, вызываемой для генерации изображение в изображение. На этом компоненте НЕ ограничен: Comfy Router заполняет его из сегмента пути `{model}` запроса `POST /v2/models/wan/{model}`. Прямой вызов v1 `POST /proxy/wan/api/v1/services/aigc/image2image/image-synthesis` ОБЯЗАН его передавать, а перечень допустимых написаний находится на компоненте самой этой операции, `WanImage2ImageGenerationRequest`.
</ParamField>

<ParamField body="parameters" type="object">
  Параметры обработки изображения
</ParamField>

<ParamField body="parameters.n" type="integer" default="1">
  Количество сгенерированных изображений. Диапазон 1-4. Если тело запроса его не содержит, Comfy отправляет провайдеру 1 и выставляет счёт за 1 изображение

  Диапазон: от `1` до `4`
</ParamField>

<ParamField body="parameters.seed" type="integer">
  Начальное значение генератора случайных чисел для управления случайностью. Диапазон [0, 2147483647]

  Диапазон: от `0` до `2147483647`
</ParamField>

<ParamField body="parameters.size" type="string" default="&quot;1280*1280&quot;">
  Разрешение выходного изображения в формате ширина*высота. По умолчанию 1280*1280. API принимает площадь в пикселях от 589824 (768*768) до 1638400 (1280*1280) при соотношении сторон от 1:4 до 4:1.
</ParamField>

<ParamField body="parameters.watermark" type="boolean" default="false">
  Добавлять ли логотип-водяной знак в правом нижнем углу
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/wan/wan2.5-i2i-preview/openapi.json`, того же документа, по которому он проверяет вызов до того, как запрос доходит до провайдера.
