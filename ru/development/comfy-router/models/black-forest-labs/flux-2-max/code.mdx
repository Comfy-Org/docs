То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/bfl/flux-2-max/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из любого другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bfl/flux-2-max",
            {
                "prompt": "A single red maple leaf on a plain white background.",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("bfl/flux-2-max", {
  prompt: "A single red maple leaf on a plain white background.",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

  Подписанный URL сгенерированного ресурса. Router переносит ресурс в хранилище Comfy и перезаписывает это поле, поэтому обычно это URL на хостинге Comfy, действительный до 24 часов: при создании он подписывается на 24 часа и воспроизводится из кэша на 23 часа, поэтому при более позднем опросе может вернуться ссылка, которой осталось всего около часа. Если перенос выполнить не удалось, ресурс сохраняет собственный короткоживущий URL BFL: примерно два часа для видео и примерно десять минут для изображений.
