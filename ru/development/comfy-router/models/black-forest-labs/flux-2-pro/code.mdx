## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL делает тот же вызов напрямую через HTTP.

**Model ID:** `bfl/flux-2-pro`

**Endpoint:** `POST https://api.comfy.org/v2/models/bfl/flux-2-pro`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/bfl/flux-2-pro/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из любого другого. [Доставка через очередь](/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и повторно использует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bfl/flux-2-pro",
            {
                "prompt": "A single red maple leaf on a plain white background.",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивать, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся с ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и повторно использует его при автоматических повторах.
const handle = await comfy.models.submit("bfl/flux-2-pro", {
  prompt: "A single red maple leaf on a plain white background.",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивать, пока запрос не завершится, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся с ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/bfl/flux-2-pro/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"prompt\": \"A single red maple leaf on a plain white background.\"}"

# 2. Опрашивать, пока статус не станет COMPLETED, выжидая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/bfl/flux-2-pro/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/bfl/flux-2-pro/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

### Выходы

<ResponseField name="cost" type="number">
  Стоимость в кредитах, сообщённая провайдером; заполняется, когда задача переходит в состояние Ready.

  Формат: `float`
</ResponseField>

<ResponseField name="id" type="string" required>
  Идентификатор задачи BFL.
</ResponseField>

<ResponseField name="progress" type="number">
  Необязательный прогресс генерации, сообщаемый BFL.

  Диапазон: от `0` до `1`

  Формат: `float`
</ResponseField>

<ResponseField name="result" type="object" required>
  Завершённая генерация. Здесь значение не может быть null: запись `required` этого компонента это обещание, что ответ `200` несёт результат, а nullable `result` свёл бы её к проверке наличия ключа.
</ResponseField>

<ResponseField name="result.cost" type="number">
  Стоимость генерации, сообщённая провайдером. Это число BFL, а не списание Comfy.

  Формат: `double`
</ResponseField>

<ResponseField name="result.duration" type="number">
  Длительность генерации в секундах, сообщённая провайдером.

  Формат: `double`
</ResponseField>

<ResponseField name="result.end_time" type="number">
  Время завершения генерации, сообщённое провайдером, в секундах с начала эпохи Unix. `double` по той же причине, что и `start_time`.

  Формат: `double`
</ResponseField>

<ResponseField name="result.prompt" type="string">
  Промпт, с которым генерация фактически выполнялась, после любого апсэмплинга промпта.
</ResponseField>

<ResponseField name="result.sample" type="string (uri)">
  Подписанный URL сгенерированного ресурса. Router переносит ресурс в хранилище Comfy и перезаписывает это поле, поэтому обычно это URL на хосте Comfy, действительный до 24 часов: он подписан на 24 часа при создании и воспроизводится из 23-часового мемо, так что более поздний запрос статуса может вернуть URL, которому остался всего час; лист, для которого перенос выполнить не удалось, сохраняет собственный короткоживущий URL доставки BFL: примерно два часа для видео и примерно десять минут для изображений. В любом случае ссылка истекает, поэтому скачайте ресурс, а не сохраняйте URL.

  Формат: `uri`
</ResponseField>

<ResponseField name="result.seed" type="integer">
  Сид, который использовала генерация, переданный или выбранный провайдером. Объявлен как `int64`, потому что BFL возвращает сиды выше 2^31 (например, 2784347701), которые неформатированный `integer` во многих генераторах SDK создаёт как 32-битное поле.

  Формат: `int64`
</ResponseField>

<ResponseField name="result.start_time" type="number">
  Время начала генерации, сообщённое провайдером, в секундах с начала эпохи Unix. `double`, а не `float`: шаг float32 вблизи значения текущей эпохи составляет ~128 секунд, что схлопывает весь интервал генерации в одно декодированное значение.

  Формат: `double`
</ResponseField>

<ResponseField name="status" type="string" required>
  Статус задачи: Pending, Reasoning, Generating, Ready, Request Moderated, Content Moderated, Error или Task not found.
</ResponseField>
