## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов напрямую по HTTP.

**Model ID:** `bfl/video-upscale-v1`

**Endpoint:** `POST https://api.comfy.org/v2/models/bfl/video-upscale-v1`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/bfl/video-upscale-v1/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или из другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bfl/video-upscale-v1",
            {
                "input_video": "https://your-host.example/clip.mp4",
                "upscale_factor": 2,
                "creativity": 1,
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print("video:", result["result"]["sample"])

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
type Result = { result: { sample: string } };
const handle = await comfy.models.submit<Result>("bfl/video-upscale-v1", {
  input_video: "https://your-host.example/clip.mp4",
  upscale_factor: 2,
  creativity: 1,
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();
if (result.kind !== "json") throw new Error("expected a JSON result");

console.log("video:", result.data.result.sample);
```

## Схема

### Входы

<ParamField body="creativity" type="integer" default="1">
  0 точно сохраняет источник и повышает его резкость; 1 включает творческое улучшение деталей, которое не гарантирует строгого сохранения лиц или товаров.

  Диапазон: от `0` до `1`
</ParamField>

<ParamField body="input_video" type="string" required>
  Видео для апскейла: HTTP(S)-URL или MP4 в кодировке base64. Не более 20 секунд исходного материала, 50MB и 2560x1440 (3.7 мегапикселя) на кадр; уменьшайте масштаб более крупного источника перед отправкой.
</ParamField>

<ParamField body="prompt" type="string">
  Необязательное описание содержимого клипа, направляющее улучшение деталей. Оставьте пустым для нейтрального апскейла.
</ParamField>

<ParamField body="safety_tolerance" type="integer" default="2">
  Уровень допуска при модерации промпта и кадров результата; значение 0 соответствует самой строгой проверке.

  Диапазон: от `0` до `4`
</ParamField>

<ParamField body="upscale_factor" type="number" default="2">
  Масштабирование выхода относительно разрешения источника. Выход сохраняет соотношение сторон источника, а его разрешение ограничено примерно 14.4 мегапикселя на кадр, поэтому очень крупные источники масштабируются меньше запрошенного коэффициента. Опции разрешения нет; чтобы получить 2K (2560x1440) или 4K (3840x2160), разделите целевую высоту на высоту источника. Источник 720p достигает 2K при коэффициенте 2, а 4K при 3; источник 1080p достигает 4K при 2, но не может достичь 2K, для которого нужен 1.33.

  Диапазон: от `1.5` до `3`

  Формат: `float`
</ParamField>

<ParamField body="webhook_secret" type="string">
  Необязательный секрет для проверки подписи вебхука.
</ParamField>

<ParamField body="webhook_url" type="string (uri)">
  URL для получения уведомлений вебхука.

  Формат: `uri`
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по `GET /v2/models/bfl/video-upscale-v1/openapi.json`, того же документа, по которому он проверяет вызов, прежде чем запрос дойдёт до провайдера.

### Выходы

<ResponseField name="cost" type="number">
  Стоимость в кредитах, которую сообщает провайдер; заполняется, когда задача переходит в статус Ready.

  Формат: `float`
</ResponseField>

<ResponseField name="id" type="string" required>
  Идентификатор задачи BFL.
</ResponseField>

<ResponseField name="progress" type="number">
  Необязательный прогресс генерации, который сообщает BFL.

  Диапазон: от `0` до `1`

  Формат: `float`
</ResponseField>

<ResponseField name="result" type="object" required>
  Завершённая генерация. Здесь значение не может быть null: запись `required` этого компонента гарантирует, что ответ `200` несёт результат, а nullable-поле `result` свело бы проверку к наличию ключа.
</ResponseField>

<ResponseField name="result.cost" type="number">
  Стоимость генерации, которую сообщает провайдер. Это значение BFL, а не списание Comfy.

  Формат: `double`
</ResponseField>

<ResponseField name="result.duration" type="number">
  Длительность генерации в секундах, которую сообщает провайдер.

  Формат: `double`
</ResponseField>

<ResponseField name="result.end_time" type="number">
  Время завершения генерации, которое сообщает провайдер, в секундах с начала эпохи Unix. Тип `double` по той же причине, что и у `start_time`.

  Формат: `double`
</ResponseField>

<ResponseField name="result.prompt" type="string">
  Промпт, с которым генерация фактически выполнялась, после любого апсемплинга промпта.
</ResponseField>

<ResponseField name="result.sample" type="string (uri)">
  Подписанный URL сгенерированного ресурса. Router переносит ресурс в хранилище Comfy и перезаписывает это поле, поэтому обычно это URL на хостинге Comfy, действительный до 24 часов: он подписывается на 24 часа при создании и воспроизводится из 23-часового кэша, так что при более позднем опросе может вернуться ссылка, которой осталось всего час; если перенос выполнить не удалось, вместо неё сохраняется собственный короткоживущий URL доставки BFL: примерно два часа для видео и примерно десять минут для изображений. В любом случае ссылка истекает, поэтому скачивайте ресурс, а не сохраняйте URL.

  Формат: `uri`
</ResponseField>

<ResponseField name="result.seed" type="integer">
  Seed, который использовала генерация, переданный или выбранный провайдером. Объявлен как `int64`, потому что BFL возвращает seed больше 2^31 (например, 2784347701), а неформатированный `integer` во многих генераторах SDK создаёт 32-битное поле.

  Формат: `int64`
</ResponseField>

<ResponseField name="result.start_time" type="number">
  Время начала генерации, которое сообщает провайдер, в секундах с начала эпохи Unix. `double`, а не `float`: шаг float32 вблизи текущего значения эпохи составляет около 128 секунд, из-за чего весь интервал генерации схлопывается в одно декодированное значение.

  Формат: `double`
</ResponseField>

<ResponseField name="status" type="string" required>
  Статус задачи: Pending, Reasoning, Generating, Ready, Request Moderated, Content Moderated, Error или Task not found.
</ResponseField>

## Примеры

### Входы

```json
{
  "input_video": "https://your-host.example/clip.mp4",
  "upscale_factor": 2,
  "creativity": 1
}
```

### Выходы

```json
{
  "id": "0a1b2c3d-...",
  "status": "Ready",
  "result": {
    "sample": "https://.../upscaled.mp4"
  }
}
```

`result.sample` обычно представляет собой подписанный URL, размещённый на Comfy, действительный до 24 часов с момента создания. При повторном запросе может вернуться более старый URL, а ресурс, который не удалось разместить повторно, сохраняет свой короткоживущий URL провайдера. Скачайте MP4 сразу, а не сохраняйте ссылку.
