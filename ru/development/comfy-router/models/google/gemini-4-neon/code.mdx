```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "vertexai/gemini-4-neon",
            {
                "contents": [
                    {
                        "parts": [
                            {
                                "text": "Describe a robot learning to paint, in two sentences.",
                            },
                        ],
                        "role": "user",
                    },
                ],
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивает статус, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("vertexai/gemini-4-neon", {
  contents: [
    {
      parts: [
        {
          text: "Describe a robot learning to paint, in two sentences.",
        },
      ],
      role: "user",
    },
  ],
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивает статус, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

<ParamField body="generationConfig.topP" type="number" default="0.95">
  Если указано, используется ядерная выборка.
Top-P изменяет то, как модель выбирает токены для вывода. Токены выбираются от наиболее (см. top-K) до наименее вероятных, пока сумма их вероятностей не сравняется со значением top-P. Например, если токены A, B и C имеют вероятности 0.3, 0.2 и 0.1, а значение top-P равно 0.5, модель выберет A или B в качестве следующего токена с помощью температуры, а C исключит из кандидатов.
Укажите меньшее значение для менее случайных ответов и большее для более случайных ответов.

  Диапазон: от `0` до `1`

  Формат: `float`
