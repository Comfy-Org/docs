То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-pro-preview/requests`. Router отвечает `201` с `request_id` сразу после приёма запуска, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "vertexai/gemini-3.1-pro-preview",
            {
                "contents": [
                    {
                        "role": "user",
                        "parts": [
                            {
                                "text": "Describe a single red maple leaf on a white background in one sentence.",
                            },
                        ],
                    },
                ],
                "generationConfig": {
                    "temperature": 0.7,
                    "maxOutputTokens": 256,
                },
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print("text:", result["candidates"][0]["content"]["parts"][0]["text"])

asyncio.run(main())
```

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
type Result = { candidates: { content: { parts: { text: string }[] } }[] };
const handle = await comfy.models.submit<Result>("vertexai/gemini-3.1-pro-preview", {
  contents: [
    {
      role: "user",
      parts: [
        {
          text: "Describe a single red maple leaf on a white background in one sentence.",
        },
      ],
    },
  ],
  generationConfig: {
    temperature: 0.7,
    maxOutputTokens: 256,
  },
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();
if (result.kind !== "json") throw new Error("expected a JSON result");

  -H "X-API-Key: $COMFY_API_KEY" \

# 2. Опрашивайте, пока status не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.

curl -i https://api.comfy.org/v2/models/vertexai/gemini-3.1-pro-preview/requests/$REQUEST_ID/status \

# 3. Получение. 200 с собственным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.

Низкие температуры подходят для промптов, требующих менее открытого или творческого ответа, а высокие температуры могут давать более разнообразные или творческие результаты. <ParamField body="generationConfig.topP" type="number" default="0.95">
  Если указано, используется ядерная выборка (nucleus sampling).
Top-P определяет, как модель выбирает токены для вывода. Токены выбираются от наиболее вероятных (см. top-K) к наименее вероятным, пока сумма их вероятностей не достигнет значения top-P. Например, если токены A, B и C имеют вероятности 0.3, 0.2 и 0.1, а значение top-P равно 0.5, то модель выберет в качестве следующего токена либо A, либо B с помощью температуры, а C исключит из числа кандидатов.
Укажите меньшее значение для менее случайных ответов и большее значение для более случайных ответов.

  Диапазон: от `0` до `1`

  Формат: `float`
</ParamField>

async def main():
    async with AsyncComfy() as client:

            "vertexai/gemini-3.5-flash",
