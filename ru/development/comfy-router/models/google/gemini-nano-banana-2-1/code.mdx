## Провайдеры, обслуживающие модель

Эту модель напрямую обслуживает Comfy Router, если в запросе не указан другой провайдер. Перечисленные ниже провайдеры также обслуживают её через ту же конечную точку и с тем же ID модели. Провайдер выбирается с помощью параметра запроса `model_provider`.

- **Comfy** (по умолчанию): `POST https://api.comfy.org/v2/models/vertexai/gemini-nano-banana-2.1`
- **MiniMax**, как `minimax/minimax-nano-banana-2.1`: `POST https://api.comfy.org/v2/models/vertexai/gemini-nano-banana-2.1?model_provider=minimax`

`strict_mode` по умолчанию имеет значение false, поэтому Router преобразует нативное тело запроса, описанное на этой странице, в собственную схему провайдера и преобразует ответ обратно. См. [`model_provider`, `strict_mode` и `fallback_provider`](/ru/development/comfy-router/reference#post-v2modelsprovidermodel) в справочнике API, а также [Провайдеры, обслуживающие модель](/ru/development/comfy-router/providers) для всех моделей, которые маршрутизируются этим способом.

<ParamField body="generationConfig.topP" type="number" default="0.95">
