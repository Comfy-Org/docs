Справочник по API для Nano Banana 2. Nano Banana 2 (Gemini 3.1 Flash Image) генерирует изображения по тексту и редактирует входное изображение, если оно предоставлено.

**Вход:** текст, изображение, видео · **Выход:** изображение + текст

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты кода на Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент на cURL, это тот же вызов через raw HTTP.

**Model ID:** `vertexai/gemini-3.1-flash-image`

**Endpoint:** `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image`

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# SDK автоматически создаёт ключ идемпотентности и повторно использует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        result = await client.models.run(
            "vertexai/gemini-3.1-flash-image",
            {
                "contents": [
                    {
                        "role": "user",
                        "parts": [
                            {
                                "text": "a single red maple leaf on a plain white background, studio lighting",
                            },
                        ],
                    },
                ],
                "generationConfig": {
                    "responseModalities": ["IMAGE"],
                    "imageConfig": {
                        "aspectRatio": "1:1",
                    },
                },
            },
        )

    print("image (base64):", result["candidates"][0]["content"]["parts"][0]["inlineData"]["data"])

asyncio.run(main())
```

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image/requests`. Router отвечает `201` с `request_id` сразу после того, как запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "vertexai/gemini-3.1-flash-image",
            {
                "contents": [
                    {
                        "role": "user",
                        "parts": [
                            {
                                "text": "a single red maple leaf on a plain white background, studio lighting",
                            },
                        ],
                    },
                ],
                "generationConfig": {
                    "responseModalities": ["IMAGE"],
                    "imageConfig": {
                        "aspectRatio": "1:1",
                    },
                },
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, возбуждает здесь типизированную ошибку Router.
        result = await handle.get()

    print("image (base64):", result["candidates"][0]["content"]["parts"][0]["inlineData"]["data"])

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
type Result = { candidates: { content: { parts: { inlineData: { data: string } }[] } }[] };
const handle = await comfy.models.submit<Result>("vertexai/gemini-3.1-flash-image", {
  contents: [
    {
      role: "user",
      parts: [
        {
          text: "a single red maple leaf on a plain white background, studio lighting",
        },
      ],
    },
  ],
  generationConfig: {
    responseModalities: ["IMAGE"],
    imageConfig: {
      aspectRatio: "1:1",
    },
  },
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();
if (result.kind !== "json") throw new Error("expected a JSON result");

console.log("image (base64):", result.data.candidates[0].content.parts[0].inlineData.data);
```

## Провайдеры, обслуживающие модель

Эта модель обслуживается напрямую через Comfy Router, если в запросе не указан другой провайдер. Перечисленные ниже провайдеры также обслуживают её, на том же эндпоинте и с тем же ID модели, выбор выполняется с помощью параметра запроса `model_provider`.

- **Comfy** (по умолчанию): `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image`
- **fal**, как `fal/fal-nano-banana-2`: `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image?model_provider=fal`
- **MiniMax**, как `minimax/minimax-nano-banana-2`: `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image?model_provider=minimax`
- **Pika**, как `pika/pika-nano-banana-2`: `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image?model_provider=pika`
- **Runware**, как `runware/runware-nano-banana-2`: `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image?model_provider=runware`
- **WaveSpeed**, как `wavespeed/wavespeed-nano-banana-2`: `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image?model_provider=wavespeed`

По умолчанию `strict_mode` имеет значение false, поэтому Router переводит нативное тело запроса, описанное на этой странице, в собственную схему провайдера и переводит ответ обратно. См. [`model_provider`, `strict_mode` и `fallback_provider`](/ru/development/comfy-router/reference#post-v2modelsprovidermodel) в справочнике API и [Провайдеры, обслуживающие модель](/ru/development/comfy-router/providers) для всех моделей, маршрутизируемых таким образом.

<ParamField body="generationConfig.temperature" type="number" default="1">
  Температура используется для выборки при генерации ответа, которая происходит после применения topP и topK. Температура управляет степенью случайности при выборе токенов. Низкие температуры подходят для промптов, требующих менее открытого или творческого ответа, а высокие температуры могут давать более разнообразные или творческие результаты. <ParamField body="generationConfig.topK" type="integer" default="40">
  Top-K меняет то, как модель выбирает токены для вывода. Top-K равный 1 означает, что следующий выбранный токен будет наиболее вероятным среди всех токенов словаря модели. Top-K равный 3 означает, что следующий токен выбирается из 3 наиболее вероятных токенов с помощью температуры.

  Диапазон: от `1` до `…`
</ParamField>

<ParamField body="generationConfig.topP" type="number" default="0.95">
  Если указано, используется ядерная выборка.
Top-P меняет то, как модель выбирает токены для вывода. Токены выбираются от наиболее вероятных (см. top-K) к наименее вероятным, пока сумма их вероятностей не достигнет значения top-P. Например, если у токенов A, B и C вероятности 0.3, 0.2 и 0.1, а значение top-P равно 0.5, модель выберет следующий токен A или B с помощью температуры, а C исключит из кандидатов.
Укажите меньшее значение для менее случайных ответов и большее для более случайных ответов.

  Диапазон: от `0` до `1`

  Формат: `float`

## Примеры

### Вход

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {
          "text": "a single red maple leaf on a plain white background, studio lighting"
        }
      ]
    }
  ],
  "generationConfig": {
    "responseModalities": [
      "IMAGE"
    ],
    "imageConfig": {
      "aspectRatio": "1:1"
    }
  }
}
```

### Выход

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [
          {
            "inlineData": {
              "mimeType": "image/png",
              "data": "PGJhc2U2ND4="
            }
          }
        ]
      },
      "finishReason": "STOP"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 12,
    "candidatesTokenCount": 1290
  }
}
```

По умолчанию сгенерированные части изображения содержат байты base64 в `inlineData.data` и тип медиа в `inlineData.mimeType`. Декодируйте байты и сохраните их в файл. При `uploadImagesToStorage: true` загруженные изображения вместо этого используют `fileData.fileUri` для подписанного URL и `fileData.mimeType` для типа медиа. Скачайте эти изображения до истечения срока действия URL, то есть в течение 24 часов после их создания. Сбой загрузки оставляет это изображение встроенным, поэтому проверяйте каждую часть на наличие `inlineData` или `fileData`; текстовые части также могут присутствовать, и изображение не гарантированно оказывается первой частью. Путь `candidates[0].content.parts[0].inlineData.data` в примерах быстрого старта выше считывает единственную встроенную часть примера ответа на этой странице; при работе с реальным ответом вместо обращения по позиции 0 просматривайте `parts` в поисках нужного ключа.
