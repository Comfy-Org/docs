## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. **ID модели:** `veo/veo-3.1-fast-generate-001`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/veo/veo-3.1-fast-generate-001`

import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("veo/veo-3.1-fast-generate-001", {

    {
      prompt: "a single red maple leaf falling onto still water, slow motion",
    },
  ],
  parameters: {
    durationSeconds: 4,
    generateAudio: false,
    sampleCount: 1,
  },
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.

console.log(result.data);

Вне bring-your-own-key этот маршрут работает под собственными учётными данными Comfy в Google Cloud, а не под вашими, поэтому адрес назначения внутри бакета, принадлежащего Comfy, означал бы запись, выполняемую сервисной учётной записью Comfy в общую структуру и оплачиваемую из проекта Comfy. Запрос, указывающий такой адрес, отклоняется с кодом 400, и ничего не генерируется, за одним исключением: при синхронном вызове Comfy Router (`POST /v2/models/{provider}/{model}`) с включённым платформенным хранилищем значение, указывающее на собственный бакет ресурсов Veo или Gemini в Router, заменяется адресом назначения, который Router создаёт под вашим собственным префиксом платформы для этого вызова (см. маршрут Veo в Router), и пропускается только этот точный адрес, созданный Router. Постановка запроса в очередь через Router (`POST /v2/models/{provider}/{model}/requests`) не выполняет такой замены, поэтому она отклоняет это значение с кодом 400, как и любой другой бакет, принадлежащий Comfy. Любой другой адрес назначения передаётся в Vertex без изменений, и доступ к нему предоставляете вы. Вызов bring-your-own-key выполняется в вашем собственном проекте и передаётся как есть.
