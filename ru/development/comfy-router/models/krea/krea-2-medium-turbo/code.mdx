То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/krea/krea-2-medium-turbo/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. Раздел [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторных попытках.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "krea/krea-2-medium-turbo",
            {
                "aspect_ratio": "1:1",
                "prompt": "a red circle",
                "resolution": "1K",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, ожидая указанный сервером Retry-After.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторных попытках.
const handle = await comfy.models.submit("krea/krea-2-medium-turbo", {
  aspect_ratio: "1:1",
  prompt: "a red circle",
  resolution: "1K",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, ожидая указанный сервером Retry-After.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/krea/krea-2-medium-turbo/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"aspect_ratio\": \"1:1\", \"prompt\": \"a red circle\", \"resolution\": \"1K\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, ожидая указанное в каждом ответе число секунд Retry-After.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/krea/krea-2-medium-turbo/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с собственным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/krea/krea-2-medium-turbo/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

</ResponseField>

<ResponseField name="result.style_id" type="string">

</ResponseField>

<ResponseField name="status" type="string" required>
  В этом документе всегда `completed`: это единственный статус, который Router сообщает как успех, а словарь Krea сопоставляется без приведения регистра.

  Возможные значения: `completed`
</ResponseField>
