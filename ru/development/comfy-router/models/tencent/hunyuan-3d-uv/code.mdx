## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты на Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`), а фрагмент на cURL делает тот же вызов по «сырому» HTTP.

**Model ID:** `tencent/hunyuan-3d-uv`

**Endpoint:** `POST https://api.comfy.org/v2/models/tencent/hunyuan-3d-uv`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/tencent/hunyuan-3d-uv/requests`. Router отвечает `201` с `request_id` сразу после того, как запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его для автоматических повторов.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "tencent/hunyuan-3d-uv",
            {
                "File": {
                    "Type": "GLB",
                    "Url": "https://vcg-test-1258344699.cos.ap-guangzhou.myqcloud.com/test/3d/test.glb",
                },
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте статус, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его для автоматических повторов.
const handle = await comfy.models.submit("tencent/hunyuan-3d-uv", {
  File: {
    Type: "GLB",
    Url: "https://vcg-test-1258344699.cos.ap-guangzhou.myqcloud.com/test/3d/test.glb",
  },
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте статус, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

## Схема

### Входы

<ParamField body="File" type="object">
  Входной 3D-файл для UV-развёртки
</ParamField>

<ParamField body="File.Type" type="string" required>
  Тип формата 3D-файла

  Возможные значения: `FBX`, `OBJ`, `GLB`
</ParamField>

<ParamField body="File.Url" type="string (uri)" required>
  URL 3D-файла, для которого нужна UV-развёртка

  Формат: `uri`
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/tencent/hunyuan-3d-uv/openapi.json`, того же документа, по которому он проверяет вызов, прежде чем запрос дойдёт до провайдера.

### Выходы

<ResponseField name="Response" type="object" required>
   
</ResponseField>

<ResponseField name="Response.ErrorCode" type="string">
  Код ошибки Tencent; по документации принимает значение пустой строки, если ошибки нет. Router не читает его, когда присутствует `Status`.
</ResponseField>

<ResponseField name="Response.ErrorMessage" type="string">
  Сообщение об ошибке Tencent; по документации принимает значение пустой строки, если ошибки нет. Router не читает его, когда присутствует `Status`.
</ResponseField>

<ResponseField name="Response.RequestId" type="string">
  Собственный идентификатор запроса Tencent для диагностики совместно с Tencent. Это не ID задачи и не ассет.
</ResponseField>

<ResponseField name="Response.ResultFile3Ds" type="object[]" required>
  Сгенерированные 3D-файлы завершённой задачи. Присутствуют и непусты в документе, который возвращает Router; хотя бы одна запись содержит `Url`, по которому можно получить файл. Ссылки принадлежат Tencent и по документации действительны в течение 24 часов.
</ResponseField>

<ResponseField name="Response.ResultFile3Ds[].PreviewImageUrl" type="string (uri)">
  URL изображения предварительного просмотра

  Формат: `uri`
</ResponseField>

<ResponseField name="Response.ResultFile3Ds[].Type" type="string">
  Формат файла. Завершённая задача может вернуть несколько записей в произвольном порядке, и не каждая запись является сеткой: операции UV и smart-topology, как наблюдалось, возвращают сетки OBJ, GLB и FBX рядом с IMAGE (текстурой PNG). Выбирайте запись по `Type`, а не по положению. Намеренно не является enum: перечисленные выше значения только из числа наблюдавшихся, этот компонент общий для операций, вывод которых никогда не наблюдался (part, texture-edit), а схема вывода носит описательный характер, поэтому значение, которого нет в списке и которое возвращает Tencent, не должно превращать корректный результат в нарушение схемы.
</ResponseField>

<ResponseField name="Response.ResultFile3Ds[].Url" type="string (uri)">
  URL файла (действителен 24 часа)

  Формат: `uri`
</ResponseField>

<ResponseField name="Response.Status" type="string" required>
  Возможные значения: `DONE`
</ResponseField>
