## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов напрямую по HTTP.

**ID модели:** `tencent/hunyuan-3d-smart-topology`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/tencent/hunyuan-3d-smart-topology`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/tencent/hunyuan-3d-smart-topology/requests`. Router отвечает `201` с `request_id` сразу после приёма запуска, а результат забирается, когда он готов, из этого или из другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "tencent/hunyuan-3d-smart-topology",
            {
                "File3D": {
                    "Type": "GLB",
                    "Url": "https://vcg-test-1258344699.cos.ap-guangzhou.myqcloud.com/test/3d/test.glb",
                },
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте до завершения запроса, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("tencent/hunyuan-3d-smart-topology", {
  File3D: {
    Type: "GLB",
    Url: "https://vcg-test-1258344699.cos.ap-guangzhou.myqcloud.com/test/3d/test.glb",
  },
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

curl https://api.comfy.org/v2/models/tencent/hunyuan-3d-smart-topology/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.

curl -i https://api.comfy.org/v2/models/tencent/hunyuan-3d-smart-topology/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение результата. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/tencent/hunyuan-3d-smart-topology/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"

## Схема

### Входы

<ParamField body="FaceLevel" type="string">
  Уровень сокращения полигонов.

  Возможные значения: `high`, `medium`, `low`
</ParamField>

<ParamField body="File3D" type="object" required>
  Входной 3D-файл для smart topology
</ParamField>

<ParamField body="File3D.Type" type="string" required>
  Тип формата 3D-файла

  Возможные значения: `OBJ`, `GLB`
</ParamField>

<ParamField body="File3D.Url" type="string (uri)" required>
  URL 3D-файла для ретопологии

  Формат: `uri`
</ParamField>

<ParamField body="PolygonType" type="string">
  Тип полигонов выходной сетки. По умолчанию: triangle.

  Возможные значения: `triangle`, `quadrilateral`
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/tencent/hunyuan-3d-smart-topology/openapi.json`, того же документа, по которому он проверяет вызов, прежде чем запрос дойдёт до провайдера.

### Выходы

<ResponseField name="Response" type="object" required>
   
</ResponseField>

<ResponseField name="Response.ErrorCode" type="string">
  Код ошибки Tencent; по документации пустая строка, когда ошибки нет. Router не читает его, как только присутствует `Status`.
</ResponseField>

<ResponseField name="Response.ErrorMessage" type="string">
  Сообщение об ошибке Tencent; по документации пустая строка, когда ошибки нет. Router не читает его, как только присутствует `Status`.
</ResponseField>

<ResponseField name="Response.RequestId" type="string">
  Собственный идентификатор запроса Tencent для разбора проблем вместе с Tencent. Это не ID задачи и не ассет.
</ResponseField>

<ResponseField name="Response.ResultFile3Ds" type="object[]" required>
  Сгенерированные 3D-файлы завершённой задачи. Присутствуют и непусты в документе, который возвращает Router; хотя бы один элемент содержит загружаемый `Url`. Ссылки принадлежат Tencent и по документации действительны 24 часа.
</ResponseField>

<ResponseField name="Response.ResultFile3Ds[].PreviewImageUrl" type="string (uri)">
  URL изображения предварительного просмотра

  Формат: `uri`
</ResponseField>

<ResponseField name="Response.ResultFile3Ds[].Type" type="string">
  Формат файла. Завершённая задача может вернуть несколько элементов в
произвольном порядке, и не каждый элемент является сеткой: замечено,
что операции UV и smart topology возвращают сетки OBJ, GLB и FBX
рядом с IMAGE (текстурой PNG). Выбирайте элемент по `Type`, а не по
положению. Намеренно не enum: перечисленные значения это только
наблюдённые, компонент используется совместно с операциями, чей вывод
никогда не наблюдался (part, texture-edit), а схема вывода описательная,
поэтому не перечисленное значение, которое вернёт Tencent, не должно
превращать корректный результат в нарушение схемы.
</ResponseField>

<ResponseField name="Response.ResultFile3Ds[].Url" type="string (uri)">
  URL файла (действителен 24 часа)

  Формат: `uri`
</ResponseField>

<ResponseField name="Response.Status" type="string" required>
  Возможные значения: `DONE`
</ResponseField>
