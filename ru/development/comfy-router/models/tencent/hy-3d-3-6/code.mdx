Справочник по API для модели `tencent/hy-3d-3.6`, предоставляемой Comfy Router от Tencent.

**Вход:** текст, изображение · **Выход:** 3D

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов напрямую по HTTP.

**ID модели:** `tencent/hy-3d-3.6`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/tencent/hy-3d-3.6`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/tencent/hy-3d-3.6/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "tencent/hy-3d-3.6",
            {
                "generate_type": "Geometry",
                "image_url": "https://example.invalid/tencent/hy-3d-3.6/input.png",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, ожидая указанный сервером Retry-After.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("tencent/hy-3d-3.6", {
  generate_type: "Geometry",
  image_url: "https://example.invalid/tencent/hy-3d-3.6/input.png",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, ожидая указанный сервером Retry-After.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправьте запрос. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/tencent/hy-3d-3.6/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"generate_type\": \"Geometry\", \"image_url\": \"https://example.invalid/tencent/hy-3d-3.6/input.png\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, ожидая указанное в каждом ответе число секунд Retry-After.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/tencent/hy-3d-3.6/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Заберите результат. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/tencent/hy-3d-3.6/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="ao_strength" type="number">
  Сила ambient occlusion, от 0 до 1. Только для multi-view входа. По умолчанию 0.

  Диапазон: от `0` до `1`
</ParamField>

<ParamField body="bake_lighting" type="boolean">
  Истина сохраняет освещение и тени изображения. Ложь удаляет их. Только для Normal. По умолчанию ложь.
</ParamField>

<ParamField body="enable_pbr" type="boolean">
  Возвращать результаты PBR-текстур. Только для Normal. По умолчанию ложь.
</ParamField>

<ParamField body="face_count" type="integer">
  Целевое количество граней. По умолчанию 2000000.

  Диапазон: от `1000` до `2000000`
</ParamField>

<ParamField body="face_strict_mode" type="boolean">
  Истина задаёт точное целевое количество граней. Иначе количество корректируется по геометрической ошибке.
</ParamField>

<ParamField body="generate_type" type="string">
  Normal (модель с текстурами, по умолчанию) или Geometry (только геометрия). С учётом регистра.

  Возможные значения: `Normal`, `Geometry`
</ParamField>

<ParamField body="image_base64" type="string">
  Входное изображение в кодировке Base64. Те же форматы и размеры, что у image_url, до 6 МБ.
</ParamField>

<ParamField body="image_url" type="string">
  URL входного изображения. JPG, PNG, JPEG или WebP, от 128 до 5000 px по каждой стороне, до 10 МБ. Обязателен как вид спереди вместе с multi_view_images.
</ParamField>

<ParamField body="model" type="string">
  Модель для запуска. На маршруте Comfy Router она задаётся путём (`/v2/models/tencent/{model}`) и может быть опущена или отправлена как null; после валидации Router записывает сюда модель из пути.
</ParamField>

<ParamField body="multi_view_images" type="object[]">
  Дополнительные виды объекта, по одному изображению на каждый вид. Требует вид спереди в image_url.
</ParamField>

<ParamField body="multi_view_images[].view_image_url" type="string" required>
  URL изображения для этого вида. JPG или PNG
</ParamField>

<ParamField body="multi_view_images[].view_type" type="string" required>
  Вид. Одно из значений: back, left, right, top, bottom, left_front, right_front. Каждый вид не более одного раза
</ParamField>

<ParamField body="prompt" type="string">
  Промпт для text-to-3D, до 1024 символов UTF-8. Не отправляйте вместе с изображением.
</ParamField>

<ParamField body="seam_less" type="boolean">
  Истина даёт меньше швов. Ложь сохраняет больше деталей. Только для Normal. По умолчанию ложь.
</ParamField>

<ParamField body="style" type="string">
  Только для текстового ввода. По умолчанию нет.

  Возможные значения: `qinghuaci`, `china_style`, `sculpture`, `cartoon`, `cyberpunk`
</ParamField>

<ParamField body="tex_fmt" type="string">
  Формат текстур. Только для Normal. По умолчанию jpeg.

  Возможные значения: `png`, `jpeg`, `jpg`, `webp`
</ParamField>

<ParamField body="tex_res" type="string">
  Разрешение текстур. Только для Normal. По умолчанию 4k.

  Возможные значения: `2k`, `4k`, `8k`
</ParamField>
