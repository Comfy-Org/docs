Ссылка на API для `elevenlabs/eleven_multilingual_v2`, предоставляемого Comfy Router от Elevenlabs.

**Вход:** Текст · **Выход:** Аудио

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты на Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов по чистому HTTP.

**ID модели:** `elevenlabs/eleven_multilingual_v2`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/elevenlabs/eleven_multilingual_v2`

То же тело запроса, отправленное в `POST https://api.comfy.org/v2/models/elevenlabs/eleven_multilingual_v2/requests`. Router отвечает `201` с `request_id` сразу после того, как запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "elevenlabs/eleven_multilingual_v2",
            {
                "text": "Hello from Comfy Router.",
                "voice_id": "21m00Tcm4TlvDq8ikWAM",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указывает сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("elevenlabs/eleven_multilingual_v2", {
  text: "Hello from Comfy Router.",
  voice_id: "21m00Tcm4TlvDq8ikWAM",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указывает сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/elevenlabs/eleven_multilingual_v2/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"text\": \"Hello from Comfy Router.\", \"voice_id\": \"21m00Tcm4TlvDq8ikWAM\"}"

# 2. Опрашивайте, пока status не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/elevenlabs/eleven_multilingual_v2/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/elevenlabs/eleven_multilingual_v2/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="apply_language_text_normalization" type="boolean" default="false">
  Управляет нормализацией текста для конкретного языка. Может сильно увеличить задержку. Сейчас поддерживается только для японского.
</ParamField>

<ParamField body="apply_text_normalization" type="string" default="&quot;auto&quot;">
  Управляет нормализацией текста. 'auto' позволяет системе решить самостоятельно, 'on' всегда применяет нормализацию,
'off' пропускает нормализацию.

  Возможные значения: `auto`, `on`, `off`
</ParamField>

<ParamField body="language_code" type="string">
  Код языка (ISO 639-1), который нужно принудительно задать для модели. Если он не поддерживается, возвращается ошибка.
</ParamField>

<ParamField body="model_id" type="string" default="&quot;eleven_multilingual_v2&quot;">
  Идентификатор используемой модели. Чтобы получить список доступных моделей, выполните запрос /v1/models.
</ParamField>

<ParamField body="next_request_ids" type="string[]">
  ID запросов следующих генераций для обеспечения непрерывности. Максимум 3.
</ParamField>

<ParamField body="next_text" type="string">
  Текст, который идёт после этого запроса; используется для улучшения непрерывности речи.
</ParamField>

<ParamField body="previous_request_ids" type="string[]">
  ID запросов предыдущих генераций для обеспечения непрерывности. Максимум 3.
</ParamField>

<ParamField body="previous_text" type="string">
  Текст, который шёл до этого запроса; используется для улучшения непрерывности речи.
</ParamField>

<ParamField body="pronunciation_dictionary_locators" type="object[]">
  Список локаторов словарей произношения (id, version_id). Максимум 3 на запрос.
</ParamField>

<ParamField body="pronunciation_dictionary_locators[].pronunciation_dictionary_id" type="string" required>
  ID словаря произношения
</ParamField>

<ParamField body="pronunciation_dictionary_locators[].version_id" type="string" required>
  ID версии словаря произношения
</ParamField>

<ParamField body="seed" type="integer">
  Начальное значение для детерминированной генерации. Должно быть от 0 до 4294967295.

  Диапазон: `0` до `4294967295`
</ParamField>

<ParamField body="text" type="string" required>
  Текст, который будет преобразован в речь.
</ParamField>

<ParamField body="use_pvc_as_ivc" type="boolean" default="false">
  Устаревший параметр. Если истина, используется IVC-версия голоса вместо PVC.
</ParamField>

<ParamField body="voice_settings" type="object">
  Настройки голоса
</ParamField>

<ParamField body="voice_settings.similarity_boost" type="number" default="0.75">
  Насколько точно ИИ придерживается оригинального голоса при его воспроизведении.

  Диапазон: `0` до `1`

  Формат: `double`
</ParamField>

<ParamField body="voice_settings.speed" type="number" default="1">
  Настройка скорости. 1.0 — значение по умолчанию, меньшие значения замедляют, большие ускоряют.

  Диапазон: `0.7` до `1.2`

  Формат: `double`
</ParamField>

<ParamField body="voice_settings.stability" type="number" default="0.5">
  Стабильность голоса. Меньшие значения дают более широкий эмоциональный диапазон.

  Диапазон: `0` до `1`

  Формат: `double`
</ParamField>

<ParamField body="voice_settings.style" type="number" default="0">
  Усиление стиля. Подчёркивает стиль оригинального диктора.

  Диапазон: `0` до `1`

  Формат: `double`
</ParamField>

<ParamField body="voice_settings.use_speaker_boost" type="boolean" default="true">
  Повышает сходство с оригинальным диктором. Требует больших вычислительных затрат.
</ParamField>

<ParamField body="voice_id" type="string" required>
  ID используемого голоса, только буквы и цифры. Router подставляет его в путь запроса к ElevenLabs.
</ParamField>

{
  "text": "Hello from Comfy Router.",

### Выход

Двоичное тело: необработанные байты, а не документ JSON, возвращается как `*/*`, поэтому JSON-примера для показа нет. `Content-Type` и кодировка ответа соответствуют запросу, как описано в схеме выходных данных выше.
