from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызовет здесь типизированную ошибку Router.

## Схема

### Входы

<ParamField body="duration_seconds" type="number" required>
  Длительность генерируемого звука в секундах.
Должна быть не меньше 0.5 и не больше 30.
Обязательно на этом маршруте: в отличие от API ElevenLabs, который
подбирает оптимальную длительность, когда поле равно null, этот маршрут
отклоняет запрос без него с ошибкой 400 «Duration is required».
Поле остаётся nullable только для того, чтобы явный null считался корректным
документом; такой запрос всё равно отклоняется.
Именно по этому значению тарифицируется запрос.

  Диапазон: от `0.5` до `30`

  Формат: `double`
</ParamField>

<ParamField body="loop" type="boolean" default="false">
  Создавать ли звуковой эффект, который плавно зацикливается.
</ParamField>

<ParamField body="model_id" type="string">
  ID модели, используемый для генерации звука. Этот маршрут принимает
только идентификаторы Comfy из перечисления в запросе v1; любое другое
значение отклоняется с ошибкой 400 ещё до того, как запрос достигнет ElevenLabs.
Каждый из них это id Comfy для модели ElevenLabs ('eleven_sfx_v2' это модель,
которую ElevenLabs называет 'eleven_text_to_sound_v2'). Прокси переписывает
передаваемое тело в написание вендора, которого требует собственное
перечисление ElevenLabs (оно отклоняет 'eleven_sfx_v2' с ошибкой 422),
поэтому вызывающая сторона никогда не отправляет id вендора. Его НЕТ в
списке `required` этой схемы, потому что Comfy Router заполняет его из
сегмента пути `{model}` в /v2/models/elevenlabs/\{model}, поэтому
вызывающая сторона Router его опускает.
</ParamField>

<ParamField body="prompt_influence" type="number">
  Более высокое влияние промпта заставляет генерацию точнее следовать
промпту и при этом делает результаты менее вариативными.
Должно быть значением от 0 до 1. По умолчанию 0.3.

  Диапазон: от `0` до `1`

  Формат: `double`
</ParamField>

<ParamField body="text" type="string" required>
  Текст, который будет преобразован в звуковой эффект.
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/elevenlabs/eleven_sfx_v2/openapi.json`, того же документа, по которому он проверяет вызов до того, как запрос достигнет провайдера.
