Справочник по API для `luma_2/ray-3.2`, который предоставляет Comfy Router от Luma 2.

**Вход:** текст, изображение, видео · **Выход:** видео

## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Во фрагментах для Python и TypeScript используются SDK Comfy (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов напрямую по HTTP.

**ID модели:** `luma_2/ray-3.2`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/luma_2/ray-3.2`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/luma_2/ray-3.2/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или любого другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "luma_2/ray-3.2",
            {
                "prompt": "a paper boat drifting across a plain white background",
                "type": "video",
                "video": {
                    "duration": "5s",
                    "resolution": "360p",
                },
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, который указывает сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("luma_2/ray-3.2", {
  prompt: "a paper boat drifting across a plain white background",
  type: "video",
  video: {
    duration: "5s",
    resolution: "360p",
  },
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, который указывает сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/luma_2/ray-3.2/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"prompt\": \"a paper boat drifting across a plain white background\", \"type\": \"video\", \"video\": {\"duration\":\"5s\",\"resolution\":\"360p\"}}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выжидая количество секунд Retry-After, указанное в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/luma_2/ray-3.2/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/luma_2/ray-3.2/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

  Возможные значения: `3:1`, `2:1`, `21:9`, `16:9`, `3:2`, `4:3`, `1:1`, `3:4`, `2:3`, `9:16`, `1:2`, `1:3`
</ParamField>

<ParamField body="image_ref" type="object[]">

<ParamField body="image_ref[].data" type="string">

</ParamField>

<ParamField body="image_ref[].generation_id" type="string">

</ParamField>

<ParamField body="image_ref[].media_type" type="string">

</ParamField>

<ParamField body="image_ref[].url" type="string">
  Публично доступный URL изображения или видео
</ParamField>

<ParamField body="model" type="string">

<ParamField body="output_format" type="string">
