Ссылка на API для `tripo/v3.0-20250812-text-to-model`, который предоставляется через Comfy Router от Tripo.

**Вход:** Text · **Выход:** 3D

## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов по «сырому» HTTP.

**ID модели:** `tripo/v3.0-20250812-text-to-model`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/tripo/v3.0-20250812-text-to-model`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/tripo/v3.0-20250812-text-to-model/requests`. Router отвечает `201` с `request_id` сразу после приёма запуска, а результат получают, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторных попытках.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "tripo/v3.0-20250812-text-to-model",
            {
                "prompt": "a red chair",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторных попытках.
const handle = await comfy.models.submit("tripo/v3.0-20250812-text-to-model", {
  prompt: "a red chair",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/tripo/v3.0-20250812-text-to-model/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"prompt\": \"a red chair\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд из каждого ответа.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/tripo/v3.0-20250812-text-to-model/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/tripo/v3.0-20250812-text-to-model/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```
