То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/tripo/p1-20260311-multiview-to-model/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он будет готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "tripo/p1-20260311-multiview-to-model",
            {
                "inputs": ["https://example.invalid/tripo/front.png", "", "https://example.invalid/tripo/back.png", ""],
            },
        )
        print("request_id:", handle.request_id)  # вместе с model ID этого достаточно любому другому процессу

        # Опрашивает до завершения запроса, выдерживая Retry-After, который указывает сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("tripo/p1-20260311-multiview-to-model", {
  inputs: ["https://example.invalid/tripo/front.png", "", "https://example.invalid/tripo/back.png", ""],
});
console.log("requestId:", handle.requestId); // вместе с model ID этого достаточно любому другому процессу

// Опрашивает до завершения запроса, выдерживая Retry-After, который указывает сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

  -H "Idempotency-Key: $(uuidgen)" \

  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока она ещё выполняется.
curl https://api.comfy.org/v2/models/tripo/p1-20260311-multiview-to-model/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
