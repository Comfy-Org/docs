То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/tripo/v3.1-20260211-multiview-to-model/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его для автоматических повторов.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "tripo/v3.1-20260211-multiview-to-model",
            {
                "inputs": ["https://example.invalid/tripo/front.png", "", "https://example.invalid/tripo/back.png", ""],
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, который завершился с ошибкой или был отменён, здесь выбрасывает типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его для автоматических повторов.
const handle = await comfy.models.submit("tripo/v3.1-20260211-multiview-to-model", {
  inputs: ["https://example.invalid/tripo/front.png", "", "https://example.invalid/tripo/back.png", ""],
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился с ошибкой или был отменён, здесь отклоняется.
const result = await handle.get();

console.log(result.data);
```
