  Результат после завершения задачи генерации видео: содержит URL для скачивания выходного видео и, если BytePlus его возвращает, URL для скачивания последнего кадра. И `video_url`, и `last_frame_url` ПЕРЕЗАЛИТЫ в хранилище Comfy; все остальные поля здесь принадлежат BytePlus. Может быть null: BytePlus очищает URL через 24 часа после задачи, и документ об успешной задаче, запрошенный после этого, может содержать `content` отсутствующим или равным null.
</ResponseField>

<ResponseField name="content.last_frame_url" type="string">
  URL для скачивания последнего кадра сгенерированного видео; возвращается, когда в запросе задан `return_last_frame`. Не выводите формат изображения из этого URL: BytePlus на стороне запроса документирует последний кадр как PNG, Router перезаливает те байты, которые ему отдали, и определяет их тип по Content-Type от апстрима или по содержимому, а `image/jpeg` - лишь крайний fallback, когда не сработало ни то, ни другое. Router перезаливает последний кадр в хранилище Comfy и переписывает это поле, поэтому обычно это подписанный Comfy URL, действительный до 24 часов: он подписывается на 24 часа при создании и воспроизводится из 23-часового мемо, так что более поздний запрос может вернуть URL, которому остался всего час. Если перезалив выполнить не удалось, поле сохраняет собственный URL BytePlus, который BytePlus очищает через 24 часа после задачи. В любом случае ссылка истекает, поэтому скачайте кадр, а не сохраняйте URL.
</ResponseField>

<ResponseField name="content.output_format" type="string">
  Формат контейнера сгенерированного видео (mp4 или mov), когда BytePlus вкладывает его внутрь `content`. Модели Seedance чаще возвращают его как поле верхнего уровня, соседнее с `content`, см. поле `output_format` верхнего уровня; Router читает то из двух, которое присутствует.
</ResponseField>

<ResponseField name="content.upstream_expires_at" type="string (date-time)">
  Время в RFC 3339, когда апстрим-URL перестают работать: самое раннее время подписи плюс срок действия, указанный в самих URL, но не позже `updated_at` задачи плюс 24 часа (задокументированный BytePlus срок жизни URL), когда `updated_at` присутствует; иначе `updated_at` задачи плюс 24 часа. Присутствует только когда присутствует `upstream_video_url` или `upstream_last_frame_url`, и опускается, когда ни один источник не даёт времени. Не связано со сроком жизни перезалитых `video_url` / `last_frame_url`.

  Формат: `date-time`
</ResponseField>

<ResponseField name="content.upstream_last_frame_url" type="string">
  Собственный URL BytePlus для скачивания последнего кадра, возвращаемый байт в байт рядом с перезалитым `last_frame_url` на тех же условиях, что и `upstream_video_url`: только для рабочих пространств с включённой опцией, только для Seedance 2.x, отсутствует, как только BytePlus его очищает, и является bearer-учётными данными до `upstream_expires_at`.
</ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  Собственный URL BytePlus для скачивания выходного видео, возвращаемый байт в байт рядом с перезалитым `video_url`. Присутствует ТОЛЬКО для задач Seedance 2.x, запрошенных рабочим пространством, которое Comfy включил на стороне сервера (параметра запроса нет); отсутствует для всех остальных, включая учётные данные, не соответствующие ни одному рабочему пространству (например, классический API-ключ, не привязанный к рабочему пространству), и отсутствует, как только BytePlus очищает свои URL через 24 часа после генерации. Это presigned URL объектного хранилища, а значит bearer-учётные данные: любой, у кого он есть, может скачать видео до истечения срока, поэтому обращайтесь с ним как с секретом. Он истекает в `upstream_expires_at`, а в Seedance 2.5 BytePlus ограничивает его 100 загрузками, одну из которых расходует собственный перезалив Router.
</ResponseField>

<ResponseField name="content.video_url" type="string">
  URL для скачивания выходного видео. Router перезаливает видео в хранилище Comfy и переписывает это поле, поэтому обычно это подписанный Comfy URL, действительный до 24 часов: он подписывается на 24 часа при создании и воспроизводится из 23-часового мемо, так что более поздний запрос может вернуть URL, которому остался всего час. Если перезалив выполнить не удалось, поле сохраняет собственный URL BytePlus, который BytePlus очищает через 24 часа после задачи и ограничивает 100 загрузками на некоторых моделях. В любом случае ссылка истекает, поэтому скачайте видео, а не сохраняйте URL.
</ResponseField>

<ResponseField name="created_at" type="integer">
  Время создания задачи. Значение - UNIX-временная метка в секундах.
</ResponseField>

<ResponseField name="duration" type="number">
  Длительность сгенерированного видео в секундах. Объявлена как число, а не целое, потому что BytePlus непостоянен в этом: задачи с видео возвращали целые секунды, а другие интерфейсы BytePlus сообщают дробные длительности, поэтому клиент не должен предполагать целое значение. Собственное поле BytePlus, возвращается для успешных задач с видео и передаётся без изменений.
</ResponseField>

<ResponseField name="error" type="object">
  Информация об ошибке. Если задача завершилась успешно, возвращается null. Если задача завершилась с ошибкой, возвращается информация об ошибке.
</ResponseField>

<ResponseField name="error.code" type="string">
  Код ошибки апстрима ModelArk. SensitiveContentDetected, InputTextSensitiveContentDetected, InputImageSensitiveContentDetected, InputVideoSensitiveContentDetected, InputAudioSensitiveContentDetected, OutputTextSensitiveContentDetected, OutputImageSensitiveContentDetected, OutputVideoSensitiveContentDetected и OutputAudioSensitiveContentDetected обозначают отказы по политике содержимого. У семейства может быть причина, отделённая точкой, например InputImageSensitiveContentDetected.PrivacyInformation, OutputVideoSensitiveContentDetected.PolicyViolation или OutputImageSensitiveContentDetected.DeepFake. Это открытая строка, а не enum: другие коды описывают ошибки валидации и сбои провайдера. Router распознаёт семейства политик в конвертах ошибок HTTP 400 и в ответах HTTP 200 с неуспешной задачей, не переопределяя транспортные сбои.
</ResponseField>

<ResponseField name="error.message" type="string">
  Сообщение об ошибке
</ResponseField>

<ResponseField name="id" type="string">Идентификатор задачи генерации видео
</ResponseField>

<ResponseField name="model" type="string">
  Название и версия модели, использованной в задаче
</ResponseField>

<ResponseField name="output_format" type="string">
  Формат контейнера сгенерированного видео (mp4 или mov). Возвращается на ВЕРХНЕМ УРОВНЕ, как соседнее поле `content`: именно там его возвращает запрос задачи видео Seedance. Собственное поле BytePlus, передаётся без изменений.
</ResponseField>

<ResponseField name="resolution" type="string">
  Разрешение сгенерированного видео, например `1080p`. Собственное поле BytePlus: возвращается для успешно выполненных задач видео и передаётся без изменений.
</ResponseField>

<ResponseField name="seed" type="integer">
  Фактически использованное в задаче зерно генерации. Собственное поле BytePlus: возвращается для успешно выполненных задач видео и передаётся без изменений.

  Формат: `int64`
</ResponseField>

<ResponseField name="status" type="string">
  Состояние задачи

  Возможные значения: `queued`, `running`, `cancelled`, `succeeded`, `failed`, `expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  Время последнего обновления задачи. Значение представляет собой метку времени UNIX в секундах.
</ResponseField>

<ResponseField name="usage" type="object">
  Использование токенов для запроса
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  Количество токенов, сгенерированных моделью
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  Для модели генерации видео количество входных токенов не вычисляется и по умолчанию равно 0. Поэтому total_tokens = completion_tokens.
</ResponseField>
