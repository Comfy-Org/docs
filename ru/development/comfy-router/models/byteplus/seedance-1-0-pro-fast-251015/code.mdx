<ResponseField name="content.last_frame_url" type="string">

Не определяйте формат изображения по этому URL: BytePlus на стороне запроса описывает последний кадр как PNG, Router переразмещает те байты, которые ему отдали, и определяет их тип по Content-Type вышестоящего сервиса или по анализу содержимого, а `image/jpeg` является лишь крайним запасным вариантом, когда не сработали оба способа. </ResponseField>

<ResponseField name="content.upstream_video_url" type="string">
  Собственный URL BytePlus для скачивания выходного видео, возвращается байт в байт рядом с переразмещённым `video_url`. Присутствует ТОЛЬКО для задач Seedance 2.x, статус которых запрашивает рабочее пространство, включённое на стороне сервера Comfy (параметра запроса для этого нет); отсутствует для всех остальных, включая учётные данные, не привязанные ни к какому рабочему пространству (например, классический API-ключ без привязки к пространству), и отсутствует после того, как BytePlus очистит свои URL через 24 часа после генерации.
