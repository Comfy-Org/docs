То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/byteplus/seed-audio-1.0/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "byteplus/seed-audio-1.0",
            {
                "audio_config": {
                    "format": "wav",
                    "sample_rate": 24000,
                },
                "text_prompt": "Hello from Comfy Router.",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственная полезная нагрузка провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("byteplus/seed-audio-1.0", {
  audio_config: {
    format: "wav",
    sample_rate: 24000,
  },
  text_prompt: "Hello from Comfy Router.",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

## Схема

### Входы

<ParamField body="audio_config" type="object">
  Конфигурация выходного аудио.
</ParamField>

<ParamField body="audio_config.enable_subtitle" type="boolean">
  Включать ли службу субтитров. При включении в ответ добавляются временные метки на уровне высказываний и слов (по умолчанию: false).
</ParamField>

<ParamField body="audio_config.format" type="string">
  Формат выходного аудио: wav (по умолчанию), mp3, pcm или ogg_opus.

  Возможные значения: `wav`, `mp3`, `pcm`, `ogg_opus`
</ParamField>

<ParamField body="audio_config.loudness_rate" type="integer">
  От -50 до 100; 100 означает громкость 2.0x, -50 означает громкость 0.5x (по умолчанию: 0).

  Диапазон: от `-50` до `100`
</ParamField>

<ParamField body="audio_config.pitch_rate" type="integer">
  От -12 до 12 (по умолчанию: 0).

  Диапазон: от `-12` до `12`
</ParamField>

<ParamField body="audio_config.sample_rate" type="integer">
  Частота дискретизации выходного аудио: 8000, 16000, 24000 (по умолчанию), 32000, 44100 или 48000.

  Возможные значения: `8000`, `16000`, `24000`, `32000`, `44100`, `48000`
</ParamField>

<ParamField body="audio_config.speech_rate" type="integer">
  От -50 до 100; 100 означает скорость 2.0x, -50 означает скорость 0.5x (по умолчанию: 0).

  Диапазон: от `-50` до `100`
</ParamField>

<ParamField body="model" type="string">
  Идентификатор модели. Поддерживаемые модели: seed-audio-1.0 и seed-audio-1.0-multilingual. Прямой вызов v1 к POST /proxy/byteplus/api/v3/tts/create ОБЯЗАН его передавать: прокси отклоняет любое другое значение, а также его отсутствие, с кодом 400. Его НЕТ в списке `required` этой схемы, потому что Comfy Router подставляет его из сегмента пути `{model}` в /v2/models/byteplus/\{model}, поэтому вызывающая сторона Router его опускает.
</ParamField>

<ParamField body="references" type="object[]">
  Референсные ресурсы. Опустите для генерации только по тексту. До 3 аудиореференсов (каждый до 30 секунд и 10 МБ после декодирования; wav, mp3, pcm или ogg_opus) или ровно 1 референс-изображение (до 10 МБ после декодирования; jpeg, png или webp). Референсы изображений нельзя смешивать с аудиореференсами. Эти пределы заданы BytePlus и указаны в ДЕКОДИРОВАННЫХ байтах: base64 увеличивает объём ассета примерно в 4/3 раза, а вызов Comfy Router ограничен 100 MiB на весь JSON-документ, поэтому встроенный референс `audio_data`/`image_data`, отправленный на /v2/models/byteplus/\{model}, может содержать примерно 75 МБ в декодированном виде, прежде чем транспортный лимит отклонит его. Поэтому для любого отдельного встроенного референса первым срабатывает собственный предел BytePlus в 10 МБ на референс, и три аудиореференса на этом пределе теперь помещаются в одно тело; используйте `audio_url`/`image_url`, чтобы вообще не включать крупные ассеты в запрос.
</ParamField>
