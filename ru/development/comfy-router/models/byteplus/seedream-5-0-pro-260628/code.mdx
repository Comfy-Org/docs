## Схема

### Входы

<ParamField body="background" type="string">
  Управляет тем, будет ли у сгенерированного изображения прозрачный фон (альфа-канал). Поддерживается seedream-5.0-pro, 5.0-flash и более новыми моделями Seedream, в схеме которых он описан.
auto: модель решает на основе промпта и output_format. При output_format jpeg результат всегда непрозрачный.
transparent: вывод изображения RGBA с прозрачным фоном. При output_format jpeg возвращается ошибка.
opaque: вывод изображения RGB с непрозрачным фоном. Значение по умолчанию для seedream-5.0-pro.
seedream-5.0-pro поддерживает прозрачный вывод только для изображение в изображение, с одним входным изображением png, имеющим альфа-канал.
Не поддерживается в сценарии разделения на слои: передача его вместе с включённым layer_decomposition возвращает ошибку.

  Возможные значения: `auto`, `transparent`, `opaque`
</ParamField>

<ParamField body="guidance_scale" type="number">
  Управляет тем, насколько точно выходное изображение соответствует входному промпту. Диапазон [1, 10]. Более высокие значения дают более сильное следование промпту. Не поддерживается seedream-5.0-pro, 5.0-lite, 4.5 и 4.0.

  Диапазон: от `1` до `10`

  Формат: `float`
</ParamField>

<ParamField body="image" type="string | string[]">
  Изображение или изображения для редактирования: доступный URL или полезная нагрузка Base64 с префиксом data-URI. Идентично общему полю Seedream, кроме ограничения числа референсных изображений: на этой модели оно равно 10, а не 14.
</ParamField>

<ParamField body="layer_decomposition" type="boolean" default="false">
  Управляет включением разделения на слои. Этот параметр поддерживают только seedream-5.0-pro, 5.0-flash и 5.5.
true: режим разделения на слои. Модель раскладывает единственное входное изображение на одно базовое изображение и несколько слоёв (до 16; до 99 на seedream-5.5) и возвращает информацию о положении и содержимом каждого полученного слоя, включая порядок наложения (z_index), границы (bounding_box), имя (name) и описание (description).
false: стандартный режим генерации изображения; разделение на слои не выполняется.
Примечания к режиму разделения на слои: поддерживается только одно входное изображение (передача нескольких изображений возвращает ошибку); если хотя бы один слой не удалось сгенерировать, весь запрос завершается неудачей, частичный успех не поддерживается; возвращается не более 17 изображений (1 базовое изображение + 16 слоёв). seedream-5.5 возвращает не более layer_decomposition_options.max_images изображений (1 базовое изображение + до 99 слоёв). При передаче sequential_image_generation, sequential_image_generation_options, tools и stream возвращается ошибка.
</ParamField>

<ParamField body="layer_decomposition_options" type="object">
  Параметры режима разделения на слои. Этот параметр поддерживается только в seedream-5.5 и действует, только когда layer_decomposition равен true.
</ParamField>

<ParamField body="layer_decomposition_options.max_images" type="integer" default="30">
  Максимальное общее число изображений, возвращаемых этим запросом, включая базовое изображение и слои. Диапазон: [2, 100]. Если в промпте не указано, как разбить изображение, модель планирует слои исходя из max_images и сложности входного изображения; большее значение обычно даёт более мелкие слои.

  Диапазон: от `2` до `100`
</ParamField>

<ParamField body="model" type="string">
  Идентификатор модели. Поддерживаемые модели: seedream-4-0-250828, seedream-4-5-251128, seedream-5-0-260128, seedream-5-0-pro-260628, seedream-5-0-flash-260915 и seedream-5-5-261028. При прямом вызове v1 POST /proxy/byteplus/api/v3/images/generations его ОБЯЗАТЕЛЬНО нужно передавать: прокси отклоняет любое другое значение, а также его отсутствие, с ошибкой 400. Его НЕТ в списке `required` этой схемы, потому что Comfy Router подставляет его из сегмента пути `{model}` в /v2/models/byteplus/\{model}, поэтому вызывающий через Router его опускает.
</ParamField>

<ParamField body="optimize_prompt_options" type="object">

</ParamField>

<ParamField body="optimize_prompt_options.mode" type="string" default="&quot;standard&quot;">

  Возможные значения: `standard`, `fast`
</ParamField>

<ParamField body="output_format" type="string" default="&quot;jpeg&quot;">
  Задаёт формат выходного изображения. Этот параметр поддерживают только seedream-5.0-pro, 5.0-flash, 5.0-lite и 5.5. В seedream-5.5 по умолчанию используется png. В сценарии разделения на слои output_format управляет только форматом базового изображения; каждый слой всегда выводится в png.

  Возможные значения: `png`, `jpeg`
</ParamField>

<ParamField body="prompt" type="string">
  Текстовое описание для генерации или преобразования изображения.
Необязателен в сценарии разделения на слои (seedream-5.0-pro, 5.0-flash или 5.5 с включённым layer_decomposition): если промпт передан, модель распознаёт и разделяет указанные вами элементы в соответствии с замыслом промпта; если промпт не передан, модель автоматически определяет все основные элементы изображения и разделяет их на независимые слои.

Значение b64_json отклоняется вместе с layer_decomposition на этом маршруте (400 на v1, 422 для response_format в Comfy Router), потому что встроенные в ответ base64-слои могут превысить лимит размера результата Comfy Router и привести к сбою после того, как изображение уже отрисовано и оплачено; для запросов разделения на слои используйте url (значение по умолчанию).

  Возможные значения: `url`, `b64_json`
</ParamField>

<ParamField body="seed" type="integer" default="-1">

<ParamField body="sequential_image_generation_options" type="object">

  Тип фона, который фактически имеет изображение: transparent или opaque. В сценарии разделения на слои базовое изображение всегда opaque, а каждый слой - transparent. Это поле возвращает только seedream-5.5.

<ResponseField name="data[].bounding_box" type="object">
  Информация о границах (Bounding Box) области, которую текущий слой занимает внутри базового изображения. Это поле возвращают только слои; базовое изображение покрывает весь холст и не возвращает bounding_box. Возвращается только при layer_decomposition = true.
</ResponseField>

<ResponseField name="data[].bounding_box.absolute" type="integer[]">
  Абсолютные координаты границ слоя в пикселях в системе координат выходного базового изображения с началом в левом верхнем углу (0, 0). Формат координат: [left, top, right, bottom].
</ResponseField>

<ResponseField name="data[].bounding_box.normalized" type="integer[]">
  Нормализованные координаты границ слоя, квантованные в промилле и пропорционально отображённые на дискретный целочисленный диапазон [0, 1000] относительно размера базового изображения, с усечением до 1000. Формат координат: [left, top, right, bottom].
</ResponseField>

<ResponseField name="data[].description" type="string">
  Подробное описание текущего выделенного элемента, которое даёт более богатые характеристики слоя (такие как цвет, состояние, материал), чем name. Это поле возвращают только слои, базовое изображение - нет. Возвращается только при layer_decomposition = true.
</ResponseField>

<ResponseField name="data[].name" type="string">
  Имя/метка текущего выделенного элемента, автоматически создаваемые моделью по характеристикам выделенного объекта. Это поле возвращают только слои, базовое изображение - нет. Возвращается только при layer_decomposition = true.
</ResponseField>

<ResponseField name="data[].output_format" type="string">
  Формат файла выходного изображения. Это поле поддерживают только seedream-5.0-pro и 5.5.
</ResponseField>

<ResponseField name="data[].size" type="string">
  Ширина и высота изображения в пикселях в формате \<width>x\<height>. Этот параметр поддерживают только seedream-5.0-pro, 5.0-lite, 5.5, 4.5 и 4.0.
</ResponseField>

<ResponseField name="data[].url" type="string (uri)">
  URL для скачивания изображения (если response_format имеет значение "url")

  Формат: `uri`
</ResponseField>

<ResponseField name="data[].z_index" type="integer">
  Порядок наложения слоёв, возрастающий снизу вверх: 0 - самый нижний слой (базовое изображение), большие значения располагаются выше. Используйте его, чтобы собрать слои в полное изображение в правильном порядке наложения. Возвращается только при layer_decomposition = true.
</ResponseField>
