Справочник по API для `heygen/starfish`, который предоставляет Comfy Router от HeyGen.

**Вход:** Текст · **Выход:** Аудио

## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты на Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов напрямую по HTTP.

**ID модели:** `heygen/starfish`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/heygen/starfish`

from comfy_sdk import Comfy

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/heygen/starfish/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из любого другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "heygen/starfish",
            {
                "text": "Hello from Comfy. This voice is generated with the HeyGen Starfish engine.",
                "voice_id": "d2f4f24783d04e22ab49ee8fdc3715e0",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился с ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("heygen/starfish", {
  text: "Hello from Comfy. This voice is generated with the HeyGen Starfish engine.",
  voice_id: "d2f4f24783d04e22ab49ee8fdc3715e0",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился с ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/heygen/starfish/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"text\": \"Hello from Comfy. This voice is generated with the HeyGen Starfish engine.\", \"voice_id\": \"d2f4f24783d04e22ab49ee8fdc3715e0\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/heygen/starfish/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/heygen/starfish/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="input_type" type="string">
  Тип входа: 'text' для обычного текста, 'ssml' для разметки SSML. По умолчанию используется 'text'
</ParamField>

<ParamField body="language" type="string">
  Базовый код языка (например, 'en'). Если не указан, определяется автоматически из текста
</ParamField>

<ParamField body="locale" type="string">
  Тег локализации BCP-47 (например, 'en-US'). Если задан, язык выводится из локализации
</ParamField>

<ParamField body="speed" type="number">
  Множитель скорости (0.5-2.0)

  Диапазон: от `0.5` до `2`

  Формат: `double`
</ParamField>

<ParamField body="text" type="string" required>
  Текст для синтеза (1-5000 символов)
</ParamField>

<ParamField body="voice_id" type="string" required>
  ID голоса, который нужно использовать. Голос должен поддерживать движок starfish
</ParamField>
