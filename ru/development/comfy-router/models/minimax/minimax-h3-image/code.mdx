То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/minimax/minimax-h3-image/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "minimax/minimax-h3-image",
            {
                "area": "1K",
                "prompt": "A single red maple leaf resting on a plain white background.",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивать, пока запрос не завершится, выдерживая паузу Retry-After, которую указывает сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("minimax/minimax-h3-image", {
  area: "1K",
  prompt: "A single red maple leaf resting on a plain white background.",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивать, пока запрос не завершится, выдерживая паузу Retry-After, которую указывает сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

### Входы

<ParamField body="area" type="string">
  Уровень области вывода, когда `size` пропущен или равен `auto`. Одно из значений `1K`, `2K`, `4K` (по умолчанию).
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Соотношение сторон вывода, когда `size` пропущен или равен `auto`. `auto` (по умолчанию) или `X:Y` от 1:3 до 3:1, например `16:9`.
</ParamField>

<ParamField body="disable_prompt_enhanced" type="boolean" default="false">
  Отключает улучшение промпта от MiniMax. Требует фиксированного `size` или соотношения `aspect_ratio` в виде `X:Y`.
</ParamField>

<ParamField body="images" type="object[]">
  Необязательные референсные изображения. Если они указаны, запрос выполняется как редактирование изображения, точно так же, как на маршруте edits.
</ParamField>

<ParamField body="images[].image_url" type="string" required>
  Публичный URL http(s) или URI `data:image/<format>;base64,`. JPEG, PNG, WEBP, HEIC или HEIF, каждая сторона от 128 до 8192 px, длинная сторона не более чем в 4 раза больше короткой.
</ParamField>

<ParamField body="model" type="string">
  Имя модели. `MiniMax-H3-Image` или `MiniMax-H3-Image-Highspeed`. Вызывающие через Router могут опустить это поле или отправить null; Router подставляет модель, выбранную маршрутом запроса.
</ParamField>

<ParamField body="n" type="integer" default="1">
  Количество изображений. Входные токены списываются один раз за изображение.

  Диапазон: от `1` до `10`
</ParamField>

<ParamField body="output_compression" type="integer">
  Качество сжатия для `jpeg` и `webp`, по умолчанию 95.

  Диапазон: от `0` до `100`
</ParamField>

<ParamField body="output_format" type="string">
  Формат выходного изображения. Одно из значений `png`, `jpeg`, `jpg` (по умолчанию), `webp`.
</ParamField>

<ParamField body="prompt" type="string" required>
  Текстовое описание изображения. Вместе с `images` это описание правки; референсными изображениями считаются изображение 1, изображение 2 и так далее в порядке массива.
</ParamField>

<ParamField body="size" type="string">
  Размер вывода: `auto` (по умолчанию) или `WIDTHxHEIGHT`, например `2720x1536`. Фиксированный размер должен иметь площадь от 655,360 до 20,000,000 пикселей и соотношение сторон от 1:3 до 3:1, и его нельзя комбинировать с `aspect_ratio` или `area`.
</ParamField>
