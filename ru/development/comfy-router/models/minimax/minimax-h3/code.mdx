Справочник по API для MiniMax H3. MiniMax H3 (Hailuo 03) — омнимодальная видеомодель. Она генерирует изображение и звуковую дорожку за один проход, поэтому готовый клип уже содержит диалоги, звуковые эффекты и музыку.

**Вход:** текст, изображение · **Выход:** видео + аудио

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты на Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL это тот же вызов по чистому HTTP.

**ID модели:** `minimax/minimax-h3`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/minimax/minimax-h3`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/minimax/minimax-h3/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "minimax/minimax-h3",
            {
                "content": [
                    {
                        "text": "A single red maple leaf resting on a plain white background.",
                        "type": "text",
                    },
                ],
                "duration": 5,
                "ratio": "16:9",
                "resolution": "768P",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственные данные провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, возбуждает здесь типизированную ошибку Router.
        result = await handle.get()

    print("video:", result["task"]["content"]["url"])

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
type Result = { task: { content: { url: string } } };
const handle = await comfy.models.submit<Result>("minimax/minimax-h3", {
  content: [
    {
      text: "A single red maple leaf resting on a plain white background.",
      type: "text",
    },
  ],
  duration: 5,
  ratio: "16:9",
  resolution: "768P",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();
if (result.kind !== "json") throw new Error("expected a JSON result");

console.log("video:", result.data.task.content.url);
```

## Примеры

### Входы

```json
{
  "content": [
    {
      "text": "A single red maple leaf resting on a plain white background.",
      "type": "text"
    }
  ],
  "duration": 5,
  "ratio": "16:9",
  "resolution": "768P"
}
```

### Выходы

```json
{
  "task": {
    "content": {
      "url": "https://example.invalid/minimax/minimax-h3/generated.mp4"
    },
    "duration": 6,
    "id": "3f7a1b28-5c0d-4e91-8a6f-1b2c3d4e5f60",
    "model": "MiniMax-H3",
    "ratio": "16:9",
    "resolution": "768P",
    "status": "succeeded",
    "usage": {
      "output_seconds": 6,
      "total_seconds": 6
    }
  }
}
```

**MP4 содержит сгенерированную звуковую дорожку.** H3 является омнимодальной моделью: голос, звуковые эффекты и музыка синтезируются вместе с картинкой за один прямой проход, а не накладываются после, и результат представляет собой один MP4 с нативным стереозвуком. Ничто в теле запроса выше не отключает это: документированные поля это содержимое промпта, `duration`, `ratio`, `resolution`, `seed`, `aigc_watermark` и `callback_url`, и ни одно из них не выбирает рендер без звука. Поэтому конвейер, который собирается наложить собственную озвучку на клип, должен сначала выключить звук или удалить возвращённую дорожку, иначе он смикширует поверх клипа, который уже говорит. Именно промпт управляет аудио: описывайте диалоги, звуковые эффекты и музыку в том же блоке промпта, что и кадр. О том, как его составить, см. в [руководстве по промптам MiniMax H3](/ru/tutorials/video/minimax/minimax-h3-prompt-guide), а о том, что модель делает в ComfyUI, см. в [обзоре MiniMax H3](/ru/tutorials/video/minimax/minimax-h3).

URL видео истекает. Router переразмещает MP4 и возвращает подписанный Comfy URL, действительный 12 часов, а если переразмещение не удаётся, отдаёт собственную ссылку MiniMax с более коротким сроком действия. Описание `task.content.url` в схеме ответа выше говорит запросить повторно, чтобы получить обновлённый URL: это формулировка самого MiniMax для их API, перенесённая без изменений, и Router не предоставляет маршрут MiniMax для запроса задачи. Повторное чтение маршрута результата запроса, находящегося в очереди, возвращает сохранённый документ результата, пока запрос [хранится в течение 24 часов после завершения](/ru/development/comfy-router/queue#идемпотентность-и-выставление-счетов), но ничто не указывает, что такое чтение создаёт заново подписанный URL. Скачивайте MP4 сразу, а не сохраняйте ссылку.
