## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов по обычному HTTP.

**ID модели:** `cartwheel/swing-choreo`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/cartwheel/swing-choreo`

Тот же текст запроса, отправленный на `POST https://api.comfy.org/v2/models/cartwheel/swing-choreo/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. В разделе [Доставка через очередь](/ru/development/comfy-router/queue) описаны статус, отмена и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "cartwheel/swing-choreo",
            {
                "exportSettings": {
                    "characterID": "char-upload-MHR",
                    "exportType": "glb",
                    "forward": "-Z",
                    "frameRate": 30,
                    "frameStepSize": 1,
                    "up": "Y",
                },
                "prompts": ["two dancers spin and bow"],
                "swingChoreoProperties": {
                    "duration": 8,
                },
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственная полезная нагрузка провайдера, то же значение, что возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("cartwheel/swing-choreo", {
  exportSettings: {
    characterID: "char-upload-MHR",
    exportType: "glb",
    forward: "-Z",
    frameRate: 30,
    frameStepSize: 1,
    up: "Y",
  },
  prompts: ["two dancers spin and bow"],
  swingChoreoProperties: {
    duration: 8,
  },
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/cartwheel/swing-choreo/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"exportSettings\": {\"characterID\":\"char-upload-MHR\",\"exportType\":\"glb\",\"forward\":\"-Z\",\"frameRate\":30,\"frameStepSize\":1,\"up\":\"Y\"}, \"prompts\": [\"two dancers spin and bow\"], \"swingChoreoProperties\": {\"duration\":8}}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанный в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/cartwheel/swing-choreo/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с собственным выводом модели, 202 с телом статуса, пока она ещё выполняется.
curl https://api.comfy.org/v2/models/cartwheel/swing-choreo/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="exportSettings" type="object" required>
  Формат экспорта сгенерированного движения.
</ParamField>

<ParamField body="exportSettings.characterID" type="string" required>
  Персонаж, на которого экспортируется движение, например `char-upload-MHR`.
</ParamField>

<ParamField body="exportSettings.exportType" type="string" required>
  Формат экспорта, например `glb` или `fbx-blender`.
</ParamField>

<ParamField body="exportSettings.forward" type="string" required>
  Направление вперед, например `-Z`.
</ParamField>

<ParamField body="exportSettings.frameRate" type="number" required>
  Частота кадров при экспорте, например 24, 30, 60 или 120.
</ParamField>

<ParamField body="exportSettings.frameStepSize" type="number" required>
  Размер шага кадров, обычно 1.
</ParamField>

<ParamField body="exportSettings.includeMesh" type="boolean">
  Включает сетку персонажа в экспорт.
</ParamField>

<ParamField body="exportSettings.keyframeCleaning" type="string">
  `none`, `reduce` или `simplify`.
</ParamField>

<ParamField body="exportSettings.moveInPlace" type="boolean">
  Удерживает персонажа на месте.
</ParamField>

<ParamField body="exportSettings.restPose" type="boolean">
  Добавляет позу покоя как кадр 0. По умолчанию истина.
</ParamField>

<ParamField body="exportSettings.up" type="string" required>
  Направление вверх, например `Y`.
</ParamField>

<ParamField body="prompts" type="string[]" required>
  Ровно один промпт, содержащий хотя бы один непробельный символ.
</ParamField>

<ParamField body="requestedModel" type="string">
  Пропустите его или отправьте null при использовании Comfy Router; идентификатор модели выбирает `swing_choreo`.
</ParamField>

<ParamField body="swingChoreoProperties" type="object" required>
  Настройки Swing Choreo.
</ParamField>

<ParamField body="swingChoreoProperties.duration" type="integer" required>
  Длительность сцены в целых секундах, от 5 до 15.

  Диапазон: `5` до `15`
</ParamField>

Сгенерировано из схемы, которую Router отдает по адресу `GET /v2/models/cartwheel/swing-choreo/openapi.json`, того же документа, по которому он проверяет вызов, прежде чем запрос дойдет до провайдера.
