Справочник по API для `stability/generate-ultra`, предоставляемого Comfy Router от Stability.

**Вход:** Текст, изображение · **Выход:** Изображение

## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL делает тот же вызов напрямую по HTTP.

**Model ID:** `stability/generate-ultra`

**Endpoint:** `POST https://api.comfy.org/v2/models/stability/generate-ultra`

```python Python
from comfy_sdk import Comfy

# Читает COMFY_API_KEY из переменных окружения.
# SDK автоматически создаёт ключ идемпотентности и переиспользует его для автоматических повторов.
with Comfy() as client:
    result = client.models.run(
        "stability/generate-ultra",
        {
            "aspect_ratio": "16:9",
            "prompt": "a lighthouse on a cliff at sunset, oil painting",
            "seed": 12345,
        },
    )
```

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/stability/generate-ultra/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его для автоматических повторов.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/generate-ultra",
            {
                "aspect_ratio": "16:9",
                "prompt": "a lighthouse on a cliff at sunset, oil painting",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его для автоматических повторов.
const handle = await comfy.models.submit("stability/generate-ultra", {
  aspect_ratio: "16:9",
  prompt: "a lighthouse on a cliff at sunset, oil painting",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/stability/generate-ultra/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"aspect_ratio\": \"16:9\", \"prompt\": \"a lighthouse on a cliff at sunset, oil painting\", \"seed\": 12345}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/stability/generate-ultra/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/stability/generate-ultra/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="aspect_ratio" type="string">
  Только для текст в изображение. Соотношение сторон результата. По умолчанию 1:1.

  Возможные значения: `1:1`, `16:9`, `9:16`, `21:9`, `9:21`, `3:2`, `2:3`, `5:4`, `4:5`
</ParamField>

<ParamField body="image" type="string (uri)">
  Только для `stability/generate-ultra`. Подписанный Comfy URL ресурса исходного изображения; его передача переключает на изображение в изображение и требует `strength`. Отклоняется с кодом 400 на `stability/generate-core`.

  Формат: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Что нужно исключить из изображения.
</ParamField>

<ParamField body="output_format" type="string">
  Если не указано, используется `png`. `jpeg` и `webp` выдаются только пока в развёртывании включён переключатель форматов вывода stability; иначе они отклоняются с кодом 400 до запуска любой задачи. Формат никогда не влияет на цену.

  Возможные значения: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="prompt" type="string" required>
  Что нужно сгенерировать.
</ParamField>

<ParamField body="seed" type="integer">
  Значение 0 или отсутствие параметра выбирает случайное значение seed.

  Диапазон: от `0` до `4294967294`
</ParamField>

<ParamField body="strength" type="number">
  Только для изображение в изображение в `stability/generate-ultra`. Насколько сильно отойти от исходного изображения; значение 1 игнорирует его. Отклоняется с кодом 400 на `stability/generate-core`.

  Диапазон: от `0` до `1`
</ParamField>

<ParamField body="style_preset" type="string">
  Пресет стиля Stability, например `photographic`.
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/stability/generate-ultra/openapi.json`, того же документа, по которому он проверяет вызов до того, как запрос достигнет провайдера.

### Выходы

<ResponseField name="finish_reason" type="string" required>
  Всегда SUCCESS при ответе 200.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  Подписанный Comfy URL (первого) изображения PNG, действителен до 24 часов.

  Формат: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  Только для SDXL, когда возвращено более одного изображения. Каждый подписанный Comfy URL изображения в порядке вывода, каждый действителен до 24 часов.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  Значение seed, с которым было сгенерировано изображение.
</ResponseField>
