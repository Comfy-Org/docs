То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/stability/control-style/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/control-style",
            {
                "aspect_ratio": "16:9",
                "fidelity": 0.5,
                "image": "https://storage.googleapis.com/example-bucket/style.png",
                "prompt": "a castle on a cliff",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("stability/control-style", {
  aspect_ratio: "16:9",
  fidelity: 0.5,
  image: "https://storage.googleapis.com/example-bucket/style.png",
  prompt: "a castle on a cliff",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

## Схема

### Входы

<ParamField body="aspect_ratio" type="string">
  Соотношение сторон результата примерно при одном мегапикселе. По умолчанию 1:1.

  Возможные значения: `1:1`, `16:9`, `9:16`, `21:9`, `9:21`, `3:2`, `2:3`, `5:4`, `4:5`
</ParamField>

<ParamField body="fidelity" type="number">
  Насколько точно результат следует исходному стилю. По умолчанию 0.5.

  Диапазон: от `0` до `1`
</ParamField>

<ParamField body="image" type="string (uri)" required>
  Подписанный Comfy URL ресурса источника стиля.

  Формат: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Что нужно исключить из изображения.
</ParamField>

<ParamField body="output_format" type="string">
  Если параметр не указан, используется `png`. `jpeg` и `webp` выдаются только тогда, когда в развёртывании включён переключатель форматов вывода stability; иначе они отклоняются с кодом 400 ещё до запуска задачи. Формат никогда не влияет на цену.

  Возможные значения: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="prompt" type="string" required>
  Что сгенерировать в стиле исходного изображения.
</ParamField>

<ParamField body="seed" type="integer">
  `0` или отсутствие значения выбирает случайный seed.

  Диапазон: от `0` до `4294967294`
</ParamField>

<ParamField body="style_preset" type="string">
  Принимается, но не применяется.
</ParamField>

</ResponseField>
