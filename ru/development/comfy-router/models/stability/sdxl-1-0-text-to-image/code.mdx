Справочник по API для `stability/sdxl-1.0-text-to-image`, который предоставляет Comfy Router от Stability.

**Вход:** Текст · **Выход:** Изображение

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты на Python и TypeScript используют SDK Comfy (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL делает тот же вызов напрямую по HTTP.

**ID модели:** `stability/sdxl-1.0-text-to-image`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/stability/sdxl-1.0-text-to-image`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/stability/sdxl-1.0-text-to-image/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторных попытках.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/sdxl-1.0-text-to-image",
            {
                "samples": 1,
                "seed": 12345,
                "steps": 30,
                "text_prompts": [
                    {
                        "text": "a lighthouse on a cliff at sunset, oil painting",
                    },
                ],
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, который сообщает сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственные данные провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторных попытках.
const handle = await comfy.models.submit("stability/sdxl-1.0-text-to-image", {
  samples: 1,
  seed: 12345,
  steps: 30,
  text_prompts: [
    {
      text: "a lighthouse on a cliff at sunset, oil painting",
    },
  ],
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, который сообщает сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/stability/sdxl-1.0-text-to-image/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"samples\": 1, \"seed\": 12345, \"steps\": 30, \"text_prompts\": [{\"text\":\"a lighthouse on a cliff at sunset, oil painting\"}]}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выжидая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/stability/sdxl-1.0-text-to-image/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с родным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/stability/sdxl-1.0-text-to-image/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="cfg_scale" type="number">
  Насколько строго изображение следует промпту. По умолчанию 7.

  Диапазон: от `0` до `35`
</ParamField>

<ParamField body="clip_guidance_preset" type="string">
  Пресет CLIP guidance от Stability, например `NONE`.
</ParamField>

<ParamField body="extras" type="object">
  Принимается для совместимости и игнорируется.
</ParamField>

<ParamField body="height" type="integer">
  Только для режима текст в изображение. Высота результата; вместе с `width` должна образовывать один из поддерживаемых размеров SDXL 1.0. По умолчанию 1024.
</ParamField>

<ParamField body="image_strength" type="number">
  Только для режима изображение в изображение. Какая доля исходного изображения сохраняется.

  Диапазон: от `0` до `1`
</ParamField>

<ParamField body="init_image" type="string (uri)">
  Только для режима изображение в изображение, там обязательно. URL исходного изображения с подписью Comfy.

  Формат: `uri`
</ParamField>

<ParamField body="init_image_mode" type="string">
  Только для режима изображение в изображение. Что управляет тем, какая доля исходного изображения сохраняется: `image_strength` или расписание шагов. По умолчанию IMAGE_STRENGTH.

  Возможные значения: `IMAGE_STRENGTH`, `STEP_SCHEDULE`
</ParamField>

<ParamField body="sampler" type="string">
  Название сэмплера Stability, например `K_DPMPP_2M`.
</ParamField>

<ParamField body="samples" type="integer">
  Количество генерируемых изображений. По умолчанию 1. Каждое возвращённое изображение оплачивается.

  Диапазон: от `1` до `10`
</ParamField>

<ParamField body="seed" type="integer">
  Сид для всего пакета. Значение 0 или отсутствие значения выбирает случайный сид.

  Диапазон: от `0` до `…`
</ParamField>

<ParamField body="step_schedule_end" type="number">
  Только для режима изображение в изображение, при `init_image_mode` STEP_SCHEDULE.

  Диапазон: от `0` до `1`
</ParamField>

<ParamField body="step_schedule_start" type="number">
  Только для режима изображение в изображение, при `init_image_mode` STEP_SCHEDULE.

  Диапазон: от `0` до `1`
</ParamField>

<ParamField body="steps" type="integer">
  Шаги диффузии. По умолчанию 30.

  Диапазон: от `10` до `30`
</ParamField>

<ParamField body="style_preset" type="string">
  Пресет стиля Stability, например `photographic`.
</ParamField>

<ParamField body="text_prompts" type="object[]" required>
  Промпты, каждый с необязательным весом. Отрицательный вес делает его негативным промптом.
</ParamField>

<ParamField body="text_prompts[].text" type="string" required>
   
</ParamField>

<ParamField body="text_prompts[].weight" type="number">
   
</ParamField>

<ParamField body="width" type="integer">
  Только для режима текст в изображение. Ширина результата; вместе с `height` должна образовывать один из поддерживаемых размеров SDXL 1.0. По умолчанию 1024.
</ParamField>

Документ сгенерирован из схемы, которую Router отдаёт по адресу `GET /v2/models/stability/sdxl-1.0-text-to-image/openapi.json`, того же документа, по которому он проверяет вызов, прежде чем запрос попадёт к провайдеру.

### Выходы

<ResponseField name="finish_reason" type="string" required>
  Всегда SUCCESS при ответе 200.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  URL (первого) PNG-изображения с подписью Comfy, действителен до 24 часов.

  Формат: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  Только SDXL, когда возвращено более одного изображения. Все URL изображений с подписью Comfy, в порядке вывода, каждый действителен до 24 часов.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  Сид, с которым было сгенерировано изображение.
</ResponseField>
