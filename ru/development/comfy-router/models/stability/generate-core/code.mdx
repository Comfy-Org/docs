То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/stability/generate-core/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/generate-core",
            {
                "aspect_ratio": "16:9",
                "prompt": "a lighthouse on a cliff at sunset, oil painting",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

import { comfy } from "@comfyorg/sdk";

// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.

for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

## Схема

### Входы

<ParamField body="aspect_ratio" type="string">
  Только для текст в изображение. Соотношение сторон результата. По умолчанию 1:1.

  Возможные значения: `1:1`, `16:9`, `9:16`, `21:9`, `9:21`, `3:2`, `2:3`, `5:4`, `4:5`
</ParamField>

<ParamField body="image" type="string (uri)">
  Только для `stability/generate-ultra`. URL исходного изображения, подписанный Comfy; его отправка переключает на изображение в изображение и требует `strength`. На `stability/generate-core` отклоняется с кодом 400.

  Формат: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Что нужно оставить за пределами изображения.
</ParamField>

<ParamField body="output_format" type="string">
  Если не указан, используется `png`. `jpeg` и `webp` доступны, только пока в развёртывании включён переключатель форматов вывода stability; иначе они отклоняются с кодом 400 до запуска любой задачи. Формат никогда не влияет на цену.

  Возможные значения: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="prompt" type="string" required>
  Что генерировать.
</ParamField>

<ParamField body="seed" type="integer">
  0 или отсутствие значения выбирает случайный seed.

  Диапазон: `0` до `4294967294`
</ParamField>

<ParamField body="strength" type="number">
  Только для изображение в изображение в `stability/generate-ultra`. Насколько сильно отойти от исходного изображения; значение 1 игнорирует его. На `stability/generate-core` отклоняется с кодом 400.

  Диапазон: `0` до `1`
</ParamField>

<ParamField body="style_preset" type="string">
  Пресет стиля Stability, например `photographic`.
</ParamField>

Создано из схемы, которую Router отдаёт по адресу `GET /v2/models/stability/generate-core/openapi.json`, тот же документ используется для проверки вызова перед тем, как запрос дойдёт до провайдера.

### Выходы

<ResponseField name="finish_reason" type="string" required>
  Всегда SUCCESS при ответе 200.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  Подписанный Comfy URL (первого) PNG-изображения, действителен до 24 часов.

  Формат: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">

</ResponseField>

<ResponseField name="seed" type="integer" required>
  Seed, с которым было сгенерировано изображение.
</ResponseField>
