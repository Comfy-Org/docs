То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/stability/edit-search-and-recolor/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его для автоматических повторов.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/edit-search-and-recolor",
            {
                "image": "https://storage.googleapis.com/example-bucket/source.png",
                "prompt": "bright red",
                "seed": 12345,
                "select_prompt": "the cat",
            },
        )
        print("request_id:", handle.request_id)  # вместе с model ID это всё, что нужно другому процессу

        # Опрашивает до завершения запроса, выжидая Retry-After, который называет сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его для автоматических повторов.
const handle = await comfy.models.submit("stability/edit-search-and-recolor", {
  image: "https://storage.googleapis.com/example-bucket/source.png",
  prompt: "bright red",
  seed: 12345,
  select_prompt: "the cat",
});
console.log("requestId:", handle.requestId); // вместе с model ID это всё, что нужно другому процессу

// Опрашивает до завершения запроса, выжидая Retry-After, который называет сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/stability/edit-search-and-recolor/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"image\": \"https://storage.googleapis.com/example-bucket/source.png\", \"prompt\": \"bright red\", \"seed\": 12345, \"select_prompt\": \"the cat\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выжидая Retry-After секунд, которые называет каждый ответ.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/stability/edit-search-and-recolor/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/stability/edit-search-and-recolor/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="grow_mask" type="integer">
  Насколько, в пикселях, расширить найденную область. По умолчанию 3.

  Диапазон: `0` до `20`
</ParamField>

<ParamField body="image" type="string (uri)" required>
  Подписанный Comfy URL ресурса исходного изображения.

  Формат: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Что нужно исключить из перекрашивания.
</ParamField>

<ParamField body="output_format" type="string">
  Если не указан, используется `png`. `jpeg` и `webp` отдаются только пока в развёртывании включён переключатель формата вывода stability; в противном случае они отклоняются с кодом 400 до запуска любой задачи. Формат никогда не влияет на цену.

  Возможные значения: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="prompt" type="string" required>
  Новый цвет или внешний вид.
</ParamField>

<ParamField body="seed" type="integer">
  0 или отсутствие значения означает случайный seed.

  Диапазон: `0` до `4294967294`
</ParamField>

<ParamField body="select_prompt" type="string" required>
  Что нужно перекрасить.
</ParamField>

<ResponseField name="seed" type="integer" required>

</ResponseField>
