То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/stability/sdxl-1.0-masking/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/sdxl-1.0-masking",
            {
                "init_image": "https://storage.googleapis.com/example-bucket/source.png",

                    {
                        "text": "a lighthouse on a cliff at sunset, oil painting",
                    },
                ],
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивать до завершения запроса, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, здесь вызывает типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())

import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("stability/sdxl-1.0-masking", {
  init_image: "https://storage.googleapis.com/example-bucket/source.png",
  mask_image: "https://storage.googleapis.com/example-bucket/mask.png",
  mask_source: "MASK_IMAGE_WHITE",
  seed: 12345,
  text_prompts: [
    {
      text: "a lighthouse on a cliff at sunset, oil painting",
    },
  ],
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивать до завершения запроса, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// То же значение, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, здесь отклоняется.
const result = await handle.get();

console.log(result.data);

## Схема

### Входы

<ParamField body="cfg_scale" type="number">
  Насколько строго изображение следует промпту. По умолчанию 7.

  Диапазон: `0` до `35`
</ParamField>

<ParamField body="clip_guidance_preset" type="string">
  Предустановка CLIP guidance от Stability, например `NONE`.
</ParamField>

<ParamField body="extras" type="object">
  Принимается для совместимости и игнорируется.
</ParamField>

<ParamField body="init_image" type="string (uri)" required>
  URL ресурса исходного изображения, подписанный Comfy.

  Формат: `uri`
</ParamField>

<ParamField body="mask_image" type="string (uri)">
  URL ресурса маски, подписанный Comfy. Обязателен с MASK_IMAGE_WHITE и MASK_IMAGE_BLACK, отклоняется с INIT_IMAGE_ALPHA.

  Формат: `uri`
</ParamField>

<ParamField body="mask_source" type="string" required>
  Откуда берется маска. MASK_IMAGE_WHITE и MASK_IMAGE_BLACK читают `mask_image`, перекрашивая его белые или черные пиксели; INIT_IMAGE_ALPHA читает альфа-канал `init_image`.

  Возможные значения: `MASK_IMAGE_WHITE`, `MASK_IMAGE_BLACK`, `INIT_IMAGE_ALPHA`
</ParamField>

<ParamField body="sampler" type="string">
  Имя сэмплера Stability, например `K_DPMPP_2M`.
</ParamField>

<ParamField body="samples" type="integer">
  Количество изображений для генерации. По умолчанию 1. За каждое возвращенное изображение взимается плата.

  Диапазон: `1` до `10`
</ParamField>

<ParamField body="seed" type="integer">
  Seed для всего пакета. 0 или отсутствие значения выбирает случайный seed.

  Диапазон: `0` до `…`
</ParamField>

<ParamField body="steps" type="integer">
  Шаги diffusion. По умолчанию 30.

  Диапазон: `10` до `30`
</ParamField>

<ParamField body="style_preset" type="string">
  Стилевой пресет Stability, например `photographic`.
</ParamField>

<ParamField body="text_prompts" type="object[]" required>
  Промпты, каждый с необязательным весом. Отрицательный вес делает его негативным промптом.
</ParamField>
