Справочник по API для `stability/edit-search-and-replace`, предоставляемый через Comfy Router от Stability.

**Вход:** текст, изображение · **Выход:** изображение

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты кода на Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент на cURL делает тот же вызов через обычный HTTP.

**ID модели:** `stability/edit-search-and-replace`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/stability/edit-search-and-replace`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/stability/edit-search-and-replace/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. Страница [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/edit-search-and-replace",
            {
                "image": "https://storage.googleapis.com/example-bucket/source.png",
                "prompt": "a dog",
                "search_prompt": "the cat",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивает до завершения запроса, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("stability/edit-search-and-replace", {
  image: "https://storage.googleapis.com/example-bucket/source.png",
  prompt: "a dog",
  search_prompt: "the cat",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивает до завершения запроса, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/stability/edit-search-and-replace/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"image\": \"https://storage.googleapis.com/example-bucket/source.png\", \"prompt\": \"a dog\", \"search_prompt\": \"the cat\", \"seed\": 12345}"

# 2. Опрос до статуса COMPLETED, выжидая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/stability/edit-search-and-replace/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/stability/edit-search-and-replace/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="grow_mask" type="integer">
  Насколько, в пикселях, расширить найденную область. По умолчанию 3.

  Диапазон: `0` до `20`
</ParamField>

<ParamField body="image" type="string (uri)" required>
  Подписанный Comfy URL ресурса исходного изображения.

  Format: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Что нужно исключить из замены.
</ParamField>

<ParamField body="output_format" type="string">
  Если не указано, используется `png`. `jpeg` и `webp` доступны только пока в развёртывании включён переключатель форматов вывода stability; иначе они отклоняются с кодом 400 до запуска любой задачи. Формат никогда не влияет на цену.

  Возможные значения: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="prompt" type="string" required>
  Что разместить вместо найденного объекта.
</ParamField>

<ParamField body="search_prompt" type="string" required>
  Что искать на изображении.
</ParamField>

<ParamField body="seed" type="integer">
  0 или отсутствие значения выбирает случайный seed.

  Диапазон: `0` до `4294967294`
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/stability/edit-search-and-replace/openapi.json`, того же документа, по которому проверяется вызов, прежде чем запрос доходит до провайдера.

### Выходы

<ResponseField name="finish_reason" type="string" required>
  Всегда SUCCESS при ответе 200.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  Подписанный Comfy URL (первого) PNG-изображения, действителен до 24 часов.

  Format: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  Только для SDXL, когда возвращено более одного изображения. Все подписанные Comfy URL изображений в порядке вывода, каждый действителен до 24 часов.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  Seed, с которым было сгенерировано изображение.
</ResponseField>
