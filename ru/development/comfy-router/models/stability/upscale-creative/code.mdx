То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/stability/upscale-creative/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из любого другого. Раздел [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/upscale-creative",
            {
                "creativity": 0.3,
                "image": "https://storage.googleapis.com/example-bucket/source.png",
                "prompt": "a detailed photo of a cat",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственные данные провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("stability/upscale-creative", {
  creativity: 0.3,
  image: "https://storage.googleapis.com/example-bucket/source.png",
  prompt: "a detailed photo of a cat",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

## Схема

### Входы

<ParamField body="creativity" type="number">
  Сколько деталей добавлять. По умолчанию 0.3.

  Диапазон: от `0.1` до `0.5`
</ParamField>

<ParamField body="image" type="string (uri)" required>
  URL ресурса исходного изображения с подписью Comfy.

  Формат: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Что исключить из изображения после upscale.
</ParamField>

<ParamField body="output_format" type="string">
  Если не указан, используется `png`. `jpeg` и `webp` отдаются, только пока у развёртывания включён переключатель формата вывода stability; иначе они отклоняются с кодом 400 до запуска любой задачи. Формат никогда не влияет на цену.

  Возможные значения: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="prompt" type="string" required>
  Что должно быть на изображении после upscale.
</ParamField>

<ParamField body="seed" type="integer">
  0 или отсутствие значения выбирает случайный seed.

  Диапазон: от `0` до `4294967294`
</ParamField>

<ParamField body="style_preset" type="string">
  Стиль, который применяется к `prompt` и `negative_prompt`.

  Возможные значения: `3d-model`, `analog-film`, `anime`, `cinematic`, `comic-book`, `digital-art`, `enhance`, `fantasy-art`, `isometric`, `line-art`, `low-poly`, `modeling-compound`, `neon-punk`, `origami`, `photographic`, `pixel-art`, `tile-texture`
</ParamField>

Создано на основе схемы, которую Router отдаёт по адресу `GET /v2/models/stability/upscale-creative/openapi.json`; это тот же документ, по которому он проверяет вызов, прежде чем запрос достигнет провайдера.

### Выходы

<ResponseField name="finish_reason" type="string" required>
  Всегда SUCCESS при ответе 200.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  URL (первого) PNG-изображения с подписью Comfy, действителен до 24 часов.

  Формат: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  Только для SDXL, если возвращено более одного изображения. Все URL изображений с подписью Comfy в порядке вывода, каждый действителен до 24 часов.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  Seed, с которым было сгенерировано изображение.
</ResponseField>
