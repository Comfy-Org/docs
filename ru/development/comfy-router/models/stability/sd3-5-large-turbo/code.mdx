Router отвечает `201` с `request_id` сразу после того, как запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/sd3.5-large-turbo",
            {
                "aspect_ratio": "16:9",
                "prompt": "a lighthouse on a cliff at sunset, oil painting",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())

import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("stability/sd3.5-large-turbo", {
  aspect_ratio: "16:9",
  prompt: "a lighthouse on a cliff at sunset, oil painting",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);

## Схема

### Входы

<ParamField body="aspect_ratio" type="string">
  Только для режима текст в изображение. Соотношение сторон результата при размере около одного мегапикселя. По умолчанию 1:1.

  Возможные значения: `1:1`, `16:9`, `9:16`, `21:9`, `9:21`, `3:2`, `2:3`, `5:4`, `4:5`
</ParamField>

<ParamField body="cfg_scale" type="number">
  Насколько строго изображение следует промпту.

  Диапазон: `1` до `10`
</ParamField>

<ParamField body="image" type="string (uri)">
  Только для режима изображение в изображение. Подписанный Comfy URL ресурса с исходным изображением.

  Формат: `uri`
</ParamField>

<ParamField body="mode" type="string">
  По умолчанию текст в изображение. Для режима изображение в изображение требуются `image` и `strength`.

  Возможные значения: `text-to-image`, `image-to-image`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Что нужно оставить за пределами изображения.
</ParamField>

<ParamField body="output_format" type="string">
  Если не указан, используется `png`. `jpeg` и `webp` доступны, только пока в развёртывании включено переключение форматов вывода Stability; иначе они отклоняются с кодом 400 до запуска любой задачи. Формат никогда не влияет на цену.

  Возможные значения: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="prompt" type="string" required>
  Что генерировать.
</ParamField>

<ParamField body="seed" type="integer">
  0 или отсутствие значения выбирает случайный seed.

  Диапазон: `0` до `4294967294`
</ParamField>

<ParamField body="strength" type="number">
  Только для режима изображение в изображение. Насколько сильно отойти от исходного изображения; значение 1 игнорирует его.

  Диапазон: `0` до `1`
</ParamField>

<ParamField body="style_preset" type="string">
  Пресет стиля Stability, например `photographic`.
</ParamField>
