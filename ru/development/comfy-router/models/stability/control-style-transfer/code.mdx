**Вход:** текст, изображение · **Выход:** изображение

## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты на Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов напрямую по HTTP.

**ID модели:** `stability/control-style-transfer`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/stability/control-style-transfer`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/stability/control-style-transfer/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/control-style-transfer",
            {
                "init_image": "https://storage.googleapis.com/example-bucket/photo.png",
                "seed": 12345,
                "style_image": "https://storage.googleapis.com/example-bucket/style.png",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивать, пока запрос не завершится, выжидая Retry-After, который указывает сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("stability/control-style-transfer", {
  init_image: "https://storage.googleapis.com/example-bucket/photo.png",
  seed: 12345,
  style_image: "https://storage.googleapis.com/example-bucket/style.png",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивать, пока запрос не завершится, выжидая Retry-After, который указывает сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/stability/control-style-transfer/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"init_image\": \"https://storage.googleapis.com/example-bucket/photo.png\", \"seed\": 12345, \"style_image\": \"https://storage.googleapis.com/example-bucket/style.png\"}"

# 2. Опрашивать, пока статус не станет COMPLETED, выжидая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/stability/control-style-transfer/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с собственным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/stability/control-style-transfer/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="change_strength" type="number">
  Насколько сильно результат может отличаться от `init_image`. По умолчанию 0.9.

  Диапазон: от `0.1` до `1`
</ParamField>

<ParamField body="composition_fidelity" type="number">
  Насколько точно сохраняется композиция `init_image`. По умолчанию 0.9.

  Диапазон: от `0` до `1`
</ParamField>

<ParamField body="init_image" type="string (uri)" required>
  URL изображения с подписью Comfy, которое нужно перестроить в новом стиле.

  Формат: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Что нужно исключить из изображения.
</ParamField>

<ParamField body="output_format" type="string">
  Если не указан, используется `png`. `jpeg` и `webp` отдаются только пока в развёртывании включён переключатель форматов вывода stability; иначе они отклоняются с кодом 400 до запуска любой задачи. Формат никогда не влияет на цену.

  Возможные значения: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="prompt" type="string">
  Необязательная подсказка для результата.
</ParamField>

<ParamField body="seed" type="integer">
  0 или отсутствие значения: выбирается случайный seed.

  Диапазон: от `0` до `4294967294`
</ParamField>

<ParamField body="style_image" type="string (uri)" required>
  URL изображения с подписью Comfy для источника стиля.

  Формат: `uri`
</ParamField>

<ParamField body="style_preset" type="string">
  Принимается, но не применяется.
</ParamField>

<ParamField body="style_strength" type="number">
  Насколько сильно применяется стиль. По умолчанию 1.

  Диапазон: от `0` до `1`
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/stability/control-style-transfer/openapi.json`. Это тот же документ, по которому он проверяет вызов, прежде чем запрос достигает провайдера.

### Выходы

<ResponseField name="finish_reason" type="string" required>
  Всегда SUCCESS при ответе 200.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  URL изображения (первого) PNG с подписью Comfy, действителен до 24 часов.

  Формат: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  Только SDXL, когда возвращено более одного изображения. Все URL изображений с подписью Comfy, в порядке вывода, каждый действителен до 24 часов.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  Seed, с которым было сгенерировано изображение.
</ResponseField>
