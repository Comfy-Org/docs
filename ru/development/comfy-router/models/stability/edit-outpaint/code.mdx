**Вход:** текст, изображение · **Выход:** изображение

## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты на Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов по чистому HTTP.

**ID модели:** `stability/edit-outpaint`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/stability/edit-outpaint`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/stability/edit-outpaint/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/edit-outpaint",
            {
                "image": "https://storage.googleapis.com/example-bucket/source.png",
                "left": 64,
                "prompt": "a cliff beyond the frame",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивать, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызовет здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("stability/edit-outpaint", {
  image: "https://storage.googleapis.com/example-bucket/source.png",
  left: 64,
  prompt: "a cliff beyond the frame",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивать, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, здесь отклоняется.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/stability/edit-outpaint/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"image\": \"https://storage.googleapis.com/example-bucket/source.png\", \"left\": 64, \"prompt\": \"a cliff beyond the frame\", \"seed\": 12345}"

# 2. Опрашивать, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/stability/edit-outpaint/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Забрать результат. 200 с собственным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/stability/edit-outpaint/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="creativity" type="number">
  Насколько свободно дорисовывать расширяемую область. По умолчанию 0.5.

  Диапазон: `0` до `1`
</ParamField>

<ParamField body="down" type="integer">
  Сколько пикселей добавить снизу. По умолчанию 0.

  Диапазон: `0` до `2000`
</ParamField>

<ParamField body="image" type="string (uri)" required>
  Подписанный Comfy URL изображения-источника.

  Формат: `uri`
</ParamField>

<ParamField body="left" type="integer">
  Сколько пикселей добавить слева. По умолчанию 0. Хотя бы один из параметров left, right, up или down должен быть больше 0.

  Диапазон: `0` до `2000`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Принимается, но не применяется. В графе outpainting нет негативного промпта.
</ParamField>

<ParamField body="output_format" type="string">
  Если не указан, используется `png`. `jpeg` и `webp` доступны, только пока в развёртывании включён переключатель форматов вывода stability; иначе они отклоняются с кодом 400 ещё до запуска любой задачи. Формат никогда не влияет на цену.

  Возможные значения: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="prompt" type="string">
  Что нарисовать в расширяемой области.
</ParamField>

<ParamField body="right" type="integer">
  Сколько пикселей добавить справа. По умолчанию 0.

  Диапазон: `0` до `2000`
</ParamField>

<ParamField body="seed" type="integer">
  Значение 0 или пропущенный параметр означает случайный seed.

  Диапазон: `0` до `4294967294`
</ParamField>

<ParamField body="up" type="integer">
  Сколько пикселей добавить сверху. По умолчанию 0.

  Диапазон: `0` до `2000`
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/stability/edit-outpaint/openapi.json`: это тот же документ, по которому он проверяет вызов, прежде чем запрос доходит до провайдера.

### Выходы

<ResponseField name="finish_reason" type="string" required>
  Всегда SUCCESS при коде 200.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  Подписанный Comfy URL (первого) PNG-изображения, действительный до 24 часов.

  Формат: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  Только для SDXL, когда вернулось больше одного изображения. Все подписанные Comfy URL изображений в порядке вывода, каждый действителен до 24 часов.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  Seed, с которым было сгенерировано изображение.
</ResponseField>
