Справочник по API для `stability/upscale-fast`, предоставляемый через Comfy Router от Stability.

**Вход:** Изображение · **Выход:** Изображение

## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. В сниппетах Python и TypeScript используются SDK Comfy (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); сниппет cURL — тот же вызов по «сырому» HTTP.

**Идентификатор модели:** `stability/upscale-fast`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/stability/upscale-fast`

```python Python
from comfy_sdk import Comfy

# Читает COMFY_API_KEY из переменных окружения.
# SDK автоматически создаёт ключ идемпотентности и переиспользует его при автоматических повторных попытках.
with Comfy() as client:
    result = client.models.run(
        "stability/upscale-fast",
        {
            "image": "https://storage.googleapis.com/example-bucket/source.png",
        },
    )

print(result)
```

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/stability/upscale-fast/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он будет готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторных попытках.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/upscale-fast",
            {
                "image": "https://storage.googleapis.com/example-bucket/source.png",
            },
        )
        print("request_id:", handle.request_id)  # вместе с идентификатором модели это всё, что нужно другому процессу

        # Опрашивает до завершения запроса, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторных попытках.
const handle = await comfy.models.submit("stability/upscale-fast", {
  image: "https://storage.googleapis.com/example-bucket/source.png",
});
console.log("requestId:", handle.requestId); // вместе с идентификатором модели это всё, что нужно другому процессу

// Опрашивает до завершения запроса, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/stability/upscale-fast/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"image\": \"https://storage.googleapis.com/example-bucket/source.png\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выжидая указанное в каждом ответе число секунд Retry-After.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/stability/upscale-fast/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/stability/upscale-fast/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="image" type="string (uri)" required>
  Подписанный Comfy URL ресурса исходного изображения.

  Формат: `uri`
</ParamField>

<ParamField body="output_format" type="string">
  Если параметр опущен, используется `png`. `jpeg` и `webp` отдаются, только пока в развёртывании включён переключатель форматов вывода stability; иначе они отклоняются с кодом 400 до запуска любой задачи. Формат никогда не влияет на цену.

  Возможные значения: `png`, `jpeg`, `webp`
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/stability/upscale-fast/openapi.json`, того же документа, по которому он проверяет вызов до того, как запрос дойдёт до провайдера.

### Выходы

<ResponseField name="finish_reason" type="string" required>
  Всегда SUCCESS при ответе 200.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  Подписанный Comfy URL (первого) PNG-изображения, действительный до 24 часов.

  Формат: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  Только для SDXL, когда возвращено больше одного изображения. Все подписанные Comfy URL изображений в порядке вывода, каждый действителен до 24 часов.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  Сид, с которым было сгенерировано изображение.
</ResponseField>
