Справочник API для `stability/sd3.5-flash`, предоставляемого Comfy Router от Stability.

**Вход:** текст, изображение · **Выход:** изображение

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL делает тот же вызов напрямую по HTTP.

**ID модели:** `stability/sd3.5-flash`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/stability/sd3.5-flash`

```python Python
from comfy_sdk import Comfy

# Читает COMFY_API_KEY из переменной окружения.
# SDK автоматически создаёт ключ идемпотентности и переиспользует его при автоматических повторах.
with Comfy() as client:
    result = client.models.run(
        "stability/sd3.5-flash",
        {
            "aspect_ratio": "16:9",
            "prompt": "a lighthouse on a cliff at sunset, oil painting",
            "seed": 12345,
        },
    )

print(result)
```

То же тело, отправленное на `POST https://api.comfy.org/v2/models/stability/sd3.5-flash/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из любого другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/sd3.5-flash",
            {
                "aspect_ratio": "16:9",
                "prompt": "a lighthouse on a cliff at sunset, oil painting",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивать до завершения запроса, выжидая Retry-After, который указывает сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, здесь вызывает типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("stability/sd3.5-flash", {
  aspect_ratio: "16:9",
  prompt: "a lighthouse on a cliff at sunset, oil painting",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивать до завершения запроса, выжидая Retry-After, который указывает сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, здесь отклоняется.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/stability/sd3.5-flash/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"aspect_ratio\": \"16:9\", \"prompt\": \"a lighthouse on a cliff at sunset, oil painting\", \"seed\": 12345}"

# 2. Опрашивать, пока статус не станет COMPLETED, выжидая указанное в каждом ответе число секунд Retry-After.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/stability/sd3.5-flash/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/stability/sd3.5-flash/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="aspect_ratio" type="string">
  Только для текст в изображение. Соотношение сторон результата примерно на один мегапиксель. По умолчанию 1:1.

  Возможные значения: `1:1`, `16:9`, `9:16`, `21:9`, `9:21`, `3:2`, `2:3`, `5:4`, `4:5`
</ParamField>

<ParamField body="cfg_scale" type="number">
  Насколько строго изображение следует промпту.

  Диапазон: от `1` до `10`
</ParamField>

<ParamField body="image" type="string (uri)">
  Только для изображение в изображение. Подписанный Comfy URL ресурса исходного изображения.

  Формат: `uri`
</ParamField>

<ParamField body="mode" type="string">
  По умолчанию текст в изображение. Для изображение в изображение требуются `image` и `strength`.

  Возможные значения: `text-to-image`, `image-to-image`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Что не должно попасть в изображение.
</ParamField>

<ParamField body="output_format" type="string">
  Если не указано, используется `png`. `jpeg` и `webp` выдаются, только пока в развёртывании включён переключатель формата вывода stability; иначе они отклоняются с ошибкой 400 ещё до запуска задачи. Формат никогда не влияет на цену.

  Возможные значения: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="prompt" type="string" required>
  Что генерировать.
</ParamField>

<ParamField body="seed" type="integer">
  0 или отсутствие значения означает случайный seed.

  Диапазон: от `0` до `4294967294`
</ParamField>

<ParamField body="strength" type="number">
  Только для изображение в изображение. Насколько сильно отойти от исходного изображения; при значении 1 оно игнорируется.

  Диапазон: от `0` до `1`
</ParamField>

<ParamField body="style_preset" type="string">
  Предустановленный стиль Stability, например `photographic`.
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/stability/sd3.5-flash/openapi.json`, того же документа, с которым он сверяет вызов, прежде чем запрос доходит до провайдера.

### Выходы

<ResponseField name="finish_reason" type="string" required>
  Всегда SUCCESS при ответе 200.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  Подписанный Comfy URL (первого) PNG-изображения, действительный до 24 часов.

  Формат: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  Только для SDXL, когда вернулось больше одного изображения. Все подписанные Comfy URL изображений в порядке вывода, каждый действителен до 24 часов.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  Seed, с которым было сгенерировано изображение.
</ResponseField>
