<ParamField body="foreground_prompt" type="string">

</ParamField>

<ParamField body="keep_original_background" type="string">

  Возможные значения: `true`, `false`
</ParamField>

<ParamField body="light_reference" type="string (uri)">
  URL ресурса, подписанный Comfy, на изображение, за которым следует освещение.

  Формат: `uri`
</ParamField>

<ParamField body="light_source_direction" type="string">
  Откуда идёт свет. `left` не предлагается.

  Возможные значения: `right`, `below`, `above`
</ParamField>

<ParamField body="light_source_strength" type="number">
  Насколько силён свет. Требуется `light_reference` или `light_source_direction`.

  Диапазон: `0` до `1`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Что нужно исключить из изображения.
</ParamField>

<ParamField body="original_background_depth" type="number">
  Насколько точно новый фон соответствует глубине субъекта. По умолчанию 0.5.

  Диапазон: `0` до `1`
</ParamField>

<ParamField body="output_format" type="string">
  Если не указан, используется `png`. `jpeg` и `webp` отдаются, только пока в развёртывании включён переключатель форматов вывода stability; иначе они отклоняются с кодом 400 до запуска любой задачи. Формат никогда не влияет на цену.

  Возможные значения: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="preserve_original_subject" type="number">
  Насколько точно сохранять исходного субъекта. По умолчанию 0.6.

  Диапазон: `0` до `1`
</ParamField>

<ParamField body="seed" type="integer">
  0 или отсутствие значения выбирает случайный seed.

  Диапазон: `0` до `4294967294`
</ParamField>

<ParamField body="subject_image" type="string (uri)" required>
  URL ресурса, подписанный Comfy, на изображение, субъект которого сохраняется.
