## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. **Конечная точка:** `POST https://api.comfy.org/v2/models/stability/stable-point-aware-3d`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/stability/stable-point-aware-3d/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/stable-point-aware-3d",
            {
                "foreground_ratio": 1.3,
                "image": "https://storage.googleapis.com/example-bucket/source.png",
                "seed": 12345,
                "texture_resolution": 1024,
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("stability/stable-point-aware-3d", {
  foreground_ratio: 1.3,
  image: "https://storage.googleapis.com/example-bucket/source.png",
  seed: 12345,
  texture_resolution: 1024,
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправьте. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/stability/stable-point-aware-3d/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"foreground_ratio\": 1.3, \"image\": \"https://storage.googleapis.com/example-bucket/source.png\", \"seed\": 12345, \"texture_resolution\": 1024}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/stability/stable-point-aware-3d/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Заберите результат. 200 с родным выводом модели, 202 с телом статуса, пока он ещё выполняется.
curl https://api.comfy.org/v2/models/stability/stable-point-aware-3d/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="foreground_ratio" type="number">
  Какую часть кадра занимает объект. По умолчанию 1.3.

  Диапазон: `1` до `2`
</ParamField>

<ParamField body="guidance_scale" type="number">
  Насколько точно результат следует исходному изображению. По умолчанию 3.

  Диапазон: `1` до `10`
</ParamField>

<ParamField body="image" type="string (uri)" required>
  URL-адрес исходного изображения, подписанный Comfy.

  Формат: `uri`
</ParamField>

<ParamField body="remesh" type="string">
  Режим ремеша. По умолчанию `none`.

  Возможные значения: `none`, `triangle`, `quad`
</ParamField>

<ParamField body="seed" type="integer">
  `0` или отсутствие значения выбирает случайный seed.

  Диапазон: `0` до `4294967294`
</ParamField>

<ParamField body="target_count" type="integer">
  Целевое количество вершин или граней. По умолчанию 1000.

  Диапазон: `100` до `20000`
</ParamField>

<ParamField body="target_type" type="string">
  Что считает `target_count`. По умолчанию `none`.

  Возможные значения: `none`, `vertex`, `face`
</ParamField>

<ParamField body="texture_resolution" type="integer">
  Размер текстуры. По умолчанию 1024.

  Возможные значения: `512`, `1024`, `2048`
</ParamField>

<ResponseField name="finish_reason" type="string" required>

</ResponseField>

<ResponseField name="model" type="string (uri)" required>

  Формат: `uri`
</ResponseField>

<ResponseField name="seed" type="integer" required>
  Seed, с которым была сгенерирована модель.
</ResponseField>
