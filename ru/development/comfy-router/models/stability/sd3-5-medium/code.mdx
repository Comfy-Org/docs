Справочник по API для `stability/sd3.5-medium`, предоставляемый Comfy Router от Stability.

**Вход:** текст, изображение · **Выход:** изображение

## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты на Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL делает тот же вызов напрямую по HTTP.

**ID модели:** `stability/sd3.5-medium`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/stability/sd3.5-medium`

from comfy_sdk import Comfy

# Читает COMFY_API_KEY из переменных окружения.
# SDK автоматически создаёт ключ идемпотентности и переиспользует его при автоматических повторах.

            "prompt": "a lighthouse on a cliff at sunset, oil painting",

        },

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/stability/sd3.5-medium/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/sd3.5-medium",
            {
                "aspect_ratio": "16:9",
                "prompt": "a lighthouse on a cliff at sunset, oil painting",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("stability/sd3.5-medium", {
  aspect_ratio: "16:9",
  prompt: "a lighthouse on a cliff at sunset, oil painting",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/stability/sd3.5-medium/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"aspect_ratio\": \"16:9\", \"prompt\": \"a lighthouse on a cliff at sunset, oil painting\", \"seed\": 12345}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выжидая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/stability/sd3.5-medium/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с собственным выводом модели, 202 с телом статуса, пока она ещё выполняется.
curl https://api.comfy.org/v2/models/stability/sd3.5-medium/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="aspect_ratio" type="string">
  Только для текст в изображение. Соотношение сторон результата при размере около одного мегапикселя. По умолчанию 1:1.

  Возможные значения: `1:1`, `16:9`, `9:16`, `21:9`, `9:21`, `3:2`, `2:3`, `5:4`, `4:5`
</ParamField>

<ParamField body="cfg_scale" type="number">
  Насколько строго изображение следует промпту.

  Диапазон: от `1` до `10`
</ParamField>

<ParamField body="image" type="string (uri)">
  Только для изображение в изображение. Подписанный Comfy URL исходного изображения.

  Формат: `uri`
</ParamField>

<ParamField body="mode" type="string">
  По умолчанию текст в изображение. Для изображение в изображение требуются `image` и `strength`.

  Возможные значения: `text-to-image`, `image-to-image`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Что нужно оставить за пределами изображения.
</ParamField>

<ParamField body="output_format" type="string">
  Если не указан, используется `png`. `jpeg` и `webp` отдаются только пока в развёртывании включён переключатель форматов вывода Stability; иначе они отклоняются с кодом 400 ещё до запуска любой задачи. Формат никогда не влияет на цену.

  Возможные значения: `png`, `jpeg`, `webp`
</ParamField>

<ParamField body="prompt" type="string" required>
  Что генерировать.
</ParamField>

<ParamField body="seed" type="integer">
  0 или отсутствие значения выбирает случайный seed.

  Диапазон: от `0` до `4294967294`
</ParamField>

<ParamField body="strength" type="number">
  Только для изображение в изображение. Насколько сильно отойти от исходного изображения; значение 1 игнорирует его.

  Диапазон: от `0` до `1`
</ParamField>

<ParamField body="style_preset" type="string">
  Пресет стиля Stability, например `photographic`.
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/stability/sd3.5-medium/openapi.json`, того же документа, по которому он проверяет вызов до того, как запрос попадёт к провайдеру.

### Выходы

<ResponseField name="finish_reason" type="string" required>
  Всегда SUCCESS при ответе 200.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  Подписанный Comfy URL (первого) PNG-изображения, действителен до 24 часов.

  Формат: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  Только для SDXL, когда возвращено больше одного изображения. Все подписанные Comfy URL изображений в порядке вывода, каждый действителен до 24 часов.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  Seed, с которым было сгенерировано изображение.
</ResponseField>
