То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/viggle/jst-2-scene-view/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "viggle/jst-2-scene-view",
            {
                "projection": "perspective",
                "referenceBatchIds": ["3f0a6c1e-8d2b-4b7a-9e5c-1a2b3c4d5e6f"],
                "sessionId": "replace-with-a-new-random-id",
                "targetPosition": {
                    "pitch": 0,
                    "position": [0.3, 0, 0],
                    "yaw": 30,
                },
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте статус, пока запрос не завершится, выдерживая паузу Retry-After, указанную сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызовет здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("viggle/jst-2-scene-view", {
  projection: "perspective",
  referenceBatchIds: ["3f0a6c1e-8d2b-4b7a-9e5c-1a2b3c4d5e6f"],
  sessionId: "replace-with-a-new-random-id",
  targetPosition: {
    pitch: 0,
    position: [0.3, 0, 0],
    yaw: 30,
  },
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте статус, пока запрос не завершится, выдерживая паузу Retry-After, указанную сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/viggle/jst-2-scene-view/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"projection\": \"perspective\", \"referenceBatchIds\": [\"3f0a6c1e-8d2b-4b7a-9e5c-1a2b3c4d5e6f\"], \"sessionId\": \"replace-with-a-new-random-id\", \"targetPosition\": {\"pitch\":0,\"position\":[0.3,0,0],\"yaw\":30}}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая указанное в каждом ответе число секунд Retry-After.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/viggle/jst-2-scene-view/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение результата. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/viggle/jst-2-scene-view/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```
