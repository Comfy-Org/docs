То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/viggle/jst-2-scene/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или любого другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "viggle/jst-2-scene",
            {
                "prompt": "a sunlit atrium with tall plants and a stone floor",
                "quality": "low",
                "sessionId": "replace-with-a-new-random-id",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели этого достаточно любому другому процессу

        # Опрашивайте, пока запрос не завершится, ожидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("viggle/jst-2-scene", {
  prompt: "a sunlit atrium with tall plants and a stone floor",
  quality: "low",
  sessionId: "replace-with-a-new-random-id",
});
console.log("requestId:", handle.requestId); // вместе с ID модели этого достаточно любому другому процессу

// Опрашивайте, пока запрос не завершится, ожидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \

# 2. Опрашивайте, пока статус не станет COMPLETED, ожидая Retry-After секунд, указанные в каждом ответе.

  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/viggle/jst-2-scene/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
