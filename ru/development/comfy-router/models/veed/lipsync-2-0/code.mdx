**Вход:** Видео, Аудио · **Выход:** Видео + Аудио

## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. В примерах на Python и TypeScript используются Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); пример на cURL выполняет тот же вызов по обычному HTTP.

**Model ID:** `veed/lipsync-2.0`

**Endpoint:** `POST https://api.comfy.org/v2/models/veed/lipsync-2.0`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/veed/lipsync-2.0/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "veed/lipsync-2.0",
            {
                "audio_url": "https://static-assets.veed.io/api-examples/lipsyncv2-input.mp3",
                "video_url": "https://static-assets.veed.io/api-examples/lipsyncv2-input.mp4",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивает до завершения запроса, выдерживая Retry-After, который указывает сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("veed/lipsync-2.0", {
  audio_url: "https://static-assets.veed.io/api-examples/lipsyncv2-input.mp3",
  video_url: "https://static-assets.veed.io/api-examples/lipsyncv2-input.mp4",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивает до завершения запроса, выдерживая Retry-After, который указывает сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/veed/lipsync-2.0/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"audio_url\": \"https://static-assets.veed.io/api-examples/lipsyncv2-input.mp3\", \"video_url\": \"https://static-assets.veed.io/api-examples/lipsyncv2-input.mp4\"}"

# 2. Опрос до статуса COMPLETED с ожиданием Retry-After секунд, указанных в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/veed/lipsync-2.0/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/veed/lipsync-2.0/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="audio_url" type="string" required>
  Публичный http(s)-URL новой аудиодорожки, под которую нужно синхронизировать видео. Запрос отклоняется с кодом 400, если аудио длиннее предельного размера входных данных для одного вызова.
</ParamField>

<ParamField body="video_url" type="string" required>
  Публичный http(s)-URL исходного видео с одним говорящим.
</ParamField>
