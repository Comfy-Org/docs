## Быстрый старт

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/veed/fabric-1.0/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторных попытках.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "veed/fabric-1.0",
            {
                "audio_url": "https://static-assets.veed.io/api-examples/fabric-input.mp3",
                "image_url": "https://static-assets.veed.io/api-examples/fabric-input.png",
                "resolution": "480p",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивать статус до завершения запроса, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторных попытках.
const handle = await comfy.models.submit("veed/fabric-1.0", {
  audio_url: "https://static-assets.veed.io/api-examples/fabric-input.mp3",
  image_url: "https://static-assets.veed.io/api-examples/fabric-input.png",
  resolution: "480p",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивать статус до завершения запроса, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/veed/fabric-1.0/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"audio_url\": \"https://static-assets.veed.io/api-examples/fabric-input.mp3\", \"image_url\": \"https://static-assets.veed.io/api-examples/fabric-input.png\", \"resolution\": \"480p\"}"

# 2. Опрашивать статус, пока он не станет COMPLETED, выдерживая Retry-After секунд из каждого ответа.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/veed/fabric-1.0/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Забрать результат. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/veed/fabric-1.0/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```
