То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/sandbase/magi-2-reference-to-video/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "sandbase/magi-2-reference-to-video",
            {
                "aspect_ratio": "16:9",
                "duration": 5,
                "generate_audio": True,
                "images": ["https://cdn.example.com/jazz-bar.jpg", "https://cdn.example.com/player.webp"],
                "prompt": "The basketball player from image 2 walks into the jazz bar from image 1 and dances in front of the band.",
                "resolution": "1080p",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, который называет сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("sandbase/magi-2-reference-to-video", {
  aspect_ratio: "16:9",
  duration: 5,
  generate_audio: true,
  images: ["https://cdn.example.com/jazz-bar.jpg", "https://cdn.example.com/player.webp"],
  prompt: "The basketball player from image 2 walks into the jazz bar from image 1 and dances in front of the band.",
  resolution: "1080p",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, который называет сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// То же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

### Входы

<ParamField body="aspect_ratio" type="string" default="&quot;16:9&quot;">

</ParamField>

<ParamField body="audios" type="string[]">
  До 5 общедоступных HTTPS-URL референсных аудиоклипов в формате WAV или MP3, длительностью от 2 до 30 секунд каждый и 30 секунд в сумме.
</ParamField>

<ParamField body="duration" type="integer" default="5">
  Длительность видео в секундах, от 4 до 30. Средства списываются за каждую секунду.

  Диапазон: от `4` до `30`
</ParamField>

<ParamField body="generate_audio" type="boolean" default="true">
  Генерировать аудио вместе с видео. Цена одинакова с аудио и без него.
</ParamField>

<ParamField body="images" type="string[]">
  До 10 общедоступных HTTPS-URL референсных изображений, каждое размером менее 30 МБ.
</ParamField>

<ParamField body="prompt" type="string" required>
  Опишите, как использовать референсы, сцену, движение и звук.
</ParamField>

<ParamField body="resolution" type="string" default="&quot;1080p&quot;">
  Разрешение выходного видео. Доступно только 1080p.

  Возможные значения: `1080p`
</ParamField>

<ParamField body="seed" type="integer">
  Необязательный seed для воспроизводимости. Если не указать его, будет использован случайный seed.

  Диапазон: от `0` до `4294967295`

  Формат: `int64`
</ParamField>

<ParamField body="videos" type="string[]">
  До 5 общедоступных HTTPS-URL референсных видео в формате MP4 или MOV, длительностью от 2 до 30 секунд каждое и 30 секунд в сумме.
</ParamField>
