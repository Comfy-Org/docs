То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/freepik/ai-image-upscaler-precision-v2/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "freepik/ai-image-upscaler-precision-v2",
            {
                "image": "https://img.magnific.com/free-photo/light-through-mountains_395237-33.jpg?semt=ais_hybrid&w=740&q=80",
                "scale_factor": 8,
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указывает сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственные данные провайдера, то же значение, что возвращает models.run().
        # Запрос, завершившийся с ошибкой или отменённый, вызовет здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("freepik/ai-image-upscaler-precision-v2", {
  image: "https://img.magnific.com/free-photo/light-through-mountains_395237-33.jpg?semt=ais_hybrid&w=740&q=80",
  scale_factor: 8,
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указывает сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся с ошибкой или отменённый, вызовет здесь отклонение промиса.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/freepik/ai-image-upscaler-precision-v2/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"image\": \"https://img.magnific.com/free-photo/light-through-mountains_395237-33.jpg?semt=ais_hybrid&w=740&q=80\", \"scale_factor\": 8}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/freepik/ai-image-upscaler-precision-v2/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с собственным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/freepik/ai-image-upscaler-precision-v2/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="flavor" type="string">
  Режим обработки изображения:
- sublime: оптимизирован для художественных и иллюстрированных изображений
- photo: оптимизирован для фотографических изображений
- photo_denoiser: предназначен для фотографий со снижением шума

  Возможные значения: `sublime`, `photo`, `photo_denoiser`
</ParamField>

<ParamField body="image" type="string" required>
  Исходное изображение для увеличения разрешения. Принимает одно из двух:
- публично доступный HTTPS-URL, указывающий на изображение
- строку с изображением в кодировке base64
</ParamField>

<ParamField body="scale_factor" type="integer">
  Коэффициент масштабирования изображения. Определяет, насколько больше будет выход по сравнению со входом.

  Диапазон: от `2` до `16`
</ParamField>

<ParamField body="sharpen" type="integer" default="7">
  Управление интенсивностью резкости изображения. Большие значения повышают чёткость границ и ясность.

  Диапазон: от `0` до `100`
</ParamField>

<ParamField body="smart_grain" type="integer" default="7">
  Интеллектуальное усиление зерна и текстуры. Большие значения добавляют более мелкую текстуру.

  Диапазон: от `0` до `100`
</ParamField>

<ParamField body="ultra_detail" type="integer" default="30">
  Уровень усиления сверхдетализации. Большие значения создают более сложные детали.

  Диапазон: от `0` до `100`
</ParamField>

<ParamField body="webhook_url" type="string (uri)">
  Необязательный URL обратного вызова, на который будут приходить асинхронные уведомления о завершении задачи увеличения разрешения.

  Формат: `uri`
</ParamField>
