**Endpoint:** `POST https://api.comfy.org/v2/models/bria/video-edit-erase`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/bria/video-edit-erase/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bria/video-edit-erase",
            {
                "auto_trim": True,
                "mask": "https://bria-test-images.s3.us-east-1.amazonaws.com/videos/eraser/video1_mask.mp4",
                "video": "https://bria-test-images.s3.us-east-1.amazonaws.com/videos/eraser/video1_video.mp4",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, ожидая Retry-After, который укажет сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("bria/video-edit-erase", {
  auto_trim: true,
  mask: "https://bria-test-images.s3.us-east-1.amazonaws.com/videos/eraser/video1_mask.mp4",
  video: "https://bria-test-images.s3.us-east-1.amazonaws.com/videos/eraser/video1_video.mp4",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, ожидая Retry-After, который укажет сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с собственным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.

## Схема

### Входы

<ParamField body="auto_trim" type="boolean">
  Когда указано true, видео длительностью более 5 секунд обрезаются до первых 5 секунд. Когда указано false (по умолчанию), более длинные видео отклоняются.
</ParamField>

<ParamField body="mask" type="string" required>
  Публично доступный URL видео-маски, задающей область для удаления. Белые пиксели отмечают область, которую нужно удалить, чёрные пиксели сохраняются.
</ParamField>

<ParamField body="output_container_and_codec" type="string">
  Пресет контейнера и кодека для выходного файла.

  Возможные значения: `mp4_h264`, `mp4_h265`, `webm_vp9`, `mov_h265`, `mov_proresks`, `mkv_h264`, `mkv_h265`, `mkv_vp9`, `gif`
</ParamField>

<ParamField body="preserve_audio" type="boolean">
  Сохранять ли аудио из входного видео.
</ParamField>

<ParamField body="video" type="string" required>
  Публично доступный URL входного видео. Максимальная длительность 5 секунд, если для auto_trim не задано true. Поддерживается входное разрешение до 750p; более крупные входы уменьшаются.
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/bria/video-edit-erase/openapi.json`, того же документа, с которым он сверяет вызов до того, как запрос достигнет провайдера.
