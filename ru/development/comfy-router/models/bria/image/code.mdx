То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/bria/image/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого же или из другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bria/image",
            {
                "prompt": "A red vintage bicycle leaning against a brick wall in soft morning light",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указал сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственная полезная нагрузка провайдера, то же значение, которое возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("bria/image", {
  prompt: "A red vintage bicycle leaning against a brick wall in soft morning light",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указал сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/bria/image/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"prompt\": \"A red vintage bicycle leaning against a brick wall in soft morning light\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/bria/image/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с собственным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/bria/image/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

### Входы

<ParamField body="aspect_ratio" type="string" default="&quot;1:1&quot;">
  Соотношение сторон выходного изображения, одно из "1:1", "2:3", "3:2", "3:4", "4:3", "4:5", "5:4", "9:16", "16:9", "16:10", "10:16", "2:1", "1:2", "21:9", "9:21", "3:1", "1:3", "4:1", "1:4", "5:1" или "1:5". Bria отклоняет соотношения начиная с "16:10" при "4MP", при уточнении, которое отправляет и prompt, и structured_prompt, и при изображениях без промпта.
</ParamField>

<ParamField body="images" type="string[]">
  Изображение-референс, которое вдохновляет новое изображение. Общедоступный URL или строка в кодировке Base64. Принимаемые форматы: JPEG, JPG, PNG, WEBP. Массив должен содержать ровно один элемент.
</ParamField>

<ParamField body="ip_signal" type="boolean" default="false">

<ParamField body="model_version" type="string">

<ParamField body="output_type" type="string" default="&quot;png&quot;">

</ParamField>

<ParamField body="prompt" type="string">
  Текстовая инструкция. Используйте её отдельно, чтобы сгенерировать новое изображение, или вместе с images или structured_prompt, чтобы направить или уточнить результат.

<ParamField body="resolution" type="string" default="&quot;1MP&quot;">
  Разрешение выходного изображения: "1MP" или "4MP". "4MP" улучшает детали изображения, но увеличивает задержку примерно на 30 секунд.
</ParamField>

<ParamField body="seed" type="integer">

<ParamField body="structured_prompt" type="string">

</ParamField>

<ParamField body="sync" type="boolean">

Синхронный режим Bria (истина) отклоняется, а не передаётся дальше, и в Comfy Router, и на собственном маршруте `/proxy/` этой операции: Comfy Router фиксирует режим возврата до отправки и опрашивает результат внутри вызова, а маршрут `/proxy/` возвращает request_id и status_url для опроса.
</ParamField>

<ParamField body="visual_input_content_moderation" type="boolean" default="true">
  Если истина, возвращает 422 при неудачной модерации изображений.

<ParamField body="visual_output_content_moderation" type="boolean" default="true">
