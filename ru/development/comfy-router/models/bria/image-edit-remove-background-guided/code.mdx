То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/bria/image-edit-remove-background-guided/requests`. Router отвечает `201` с `request_id` сразу после того, как запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bria/image-edit-remove-background-guided",
            {
                "image": "https://labs-assets.bria.ai/api-examples/guided-remove-background/yoga_studio_input.jpg",
                "prompt": "the person with the mat and the plant",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивать, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("bria/image-edit-remove-background-guided", {
  image: "https://labs-assets.bria.ai/api-examples/guided-remove-background/yoga_studio_input.jpg",
  prompt: "the person with the mat and the plant",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивать, пока запрос не завершится, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

  -H "X-API-Key: $COMFY_API_KEY" \

  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/bria/image-edit-remove-background-guided/requests/$REQUEST_ID \

## Схема

### Входы

<ParamField body="image" type="string" required>
  Изображение, из которого нужно удалить фон. Поддерживаемые типы входных данных: строка в кодировке Base64 или URL, указывающий на общедоступный файл изображения. Допустимые форматы: JPEG, JPG, PNG, WEBP.
</ParamField>

<ParamField body="preserve_alpha" type="boolean">
  Управляет тем, сохраняются ли частично прозрачные области входного изображения в выходном после удаления фона.
</ParamField>

<ParamField body="prompt" type="string">
  Необязательные слова на простом языке, которые меняют то, что сохраняет обрезка по умолчанию, например «the person with the mat and the plant», «the woman at her desk without the lamp» или «only the chair». Если промпт отсутствует или пуст, возвращается стандартный вырез Remove Background.
</ParamField>

<ParamField body="sync" type="boolean">
  Должно быть false или не указано. Синхронный режим Bria (true) отклоняется, а не перенаправляется, как в Comfy Router, так и в собственном маршруте `/proxy/` этой операции: Comfy Router фиксирует режим возврата до отправки и опрашивает результат внутри вызова, а маршрут `/proxy/` возвращает request_id и status_url для опроса.
</ParamField>

<ParamField body="visual_input_content_moderation" type="boolean">
  Если включено, применяет модерацию содержимого к входному визуальному материалу. Возвращает 422, если изображение не проходит модерацию.
</ParamField>

<ParamField body="visual_output_content_moderation" type="boolean">
  Если включено, применяет модерацию содержимого к визуальному результату. Возвращает 422, если выходные данные не проходят модерацию.
</ParamField>

Сгенерировано из схемы, которую Router предоставляет по адресу `GET /v2/models/bria/image-edit-remove-background-guided/openapi.json`, того же документа, по которому он проверяет вызов, прежде чем запрос дойдёт до провайдера.
