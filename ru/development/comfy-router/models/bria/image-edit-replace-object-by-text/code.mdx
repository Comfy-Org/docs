То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/bria/image-edit-replace-object-by-text/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bria/image-edit-replace-object-by-text",
            {
                "image": "https://img.freepik.com/free-psd/close-up-delicious-apple_23-2151868338.jpg",
                "instruction": "Replace the pie with a chocolate cake",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указал сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился с ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("bria/image-edit-replace-object-by-text", {
  image: "https://img.freepik.com/free-psd/close-up-delicious-apple_23-2151868338.jpg",
  instruction: "Replace the pie with a chocolate cake",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, который указал сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился с ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

## Схема

### Входы

<ParamField body="image" type="string" required>
  Изображение для редактирования. Поддерживаемые типы входа: строка в кодировке Base64 или URL, указывающий на общедоступный файл изображения. Допустимые форматы: JPEG, JPG, PNG, WEBP.
</ParamField>

<ParamField body="instruction" type="string" required>
  Текстовая инструкция, описывающая замену (например, «Replace the red apple with a green pear»).
</ParamField>
