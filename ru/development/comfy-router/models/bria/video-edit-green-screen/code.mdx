То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/bria/video-edit-green-screen/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "bria/video-edit-green-screen",
            {
                "green_shade": "broadcast_green",
                "video": "https://example.com/input.mp4",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("bria/video-edit-green-screen", {
  green_shade: "broadcast_green",
  video: "https://example.com/input.mp4",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/bria/video-edit-green-screen/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"green_shade\": \"broadcast_green\", \"video\": \"https://example.com/input.mp4\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/bria/video-edit-green-screen/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/bria/video-edit-green-screen/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="green_shade" type="string">
  Сплошной оттенок фона, применяемый позади переднего плана для хромакея. По умолчанию: broadcast_green.

  Возможные значения: `broadcast_green`, `chroma_green`, `blue_screen`
</ParamField>

<ParamField body="output_container_and_codec" type="string">
  Пресет контейнера и кодека для вывода.

  Возможные значения: `mp4_h264`, `mp4_h265`, `webm_vp9`, `mov_h265`, `mov_proresks`, `mkv_h264`, `mkv_h265`, `mkv_vp9`, `gif`
</ParamField>

<ParamField body="preserve_audio" type="boolean">
  Сохранять ли аудио из входного видео.
</ParamField>

<ParamField body="video" type="string" required>
  Публично доступный URL входного видео. Поддерживается входное разрешение до 16000x16000 (16K). Макс. длительность: 60 секунд.
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/bria/video-edit-green-screen/openapi.json`, того же документа, по которому он проверяет вызов перед тем, как запрос достигает провайдера.
