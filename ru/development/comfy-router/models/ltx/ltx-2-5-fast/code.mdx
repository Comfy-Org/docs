То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/ltx/ltx-2-5-fast/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его для автоматических повторов.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "ltx/ltx-2-5-fast",
            {
                "duration": 2,
                "fps": 24,
                "generate_audio": False,
                "prompt": "A single red maple leaf resting on a plain white background.",
                "resolution": "1280x720",
            },
        )
        print("request_id:", handle.request_id)  # вместе с model ID это всё, что нужно другому процессу

        # Опрашивать до завершения запроса, выжидая Retry-After, который называет сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, которое возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, здесь вызывает типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его для автоматических повторов.
const handle = await comfy.models.submit("ltx/ltx-2-5-fast", {
  duration: 2,
  fps: 24,
  generate_audio: false,
  prompt: "A single red maple leaf resting on a plain white background.",
  resolution: "1280x720",
});
console.log("requestId:", handle.requestId); // вместе с model ID это всё, что нужно другому процессу

// Опрашивать до завершения запроса, выжидая Retry-After, который называет сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

Написания, которые LTX обслуживает в этой операции (набор, который Comfy Router адресует как `ltx/<model>`), это ltx-2-5-fast и ltx-2-5-pro; они выписаны здесь, а не ограничены перечислением, по причине, указанной в комментарии выше. <ParamField body="resolution" type="string" required>
  Разрешение выходного видео. Перечисление представляет собой объединение по всем моделям; поддерживаемый набор зависит от модели. Поддерживаемые пары: ltx-2-5-fast: 1280x720, 720x1280, 1920x1080, 1080x1920, 2560x1440, 1440x2560, 3840x2160, 2160x3840; ltx-2-5-pro: 1280x720, 720x1280, 1920x1080, 1080x1920. Другие пары (модель, разрешение) не поддерживаются; маршруты v2 отклоняют их с кодом 400. Та же матрица публикуется в машиночитаемом виде в расширении x-comfy-model-resolutions этого свойства.

  Возможные значения: `1280x720`, `720x1280`, `1920x1080`, `1080x1920`, `2560x1440`, `1440x2560`, `3840x2160`, `2160x3840`
</ParamField>
