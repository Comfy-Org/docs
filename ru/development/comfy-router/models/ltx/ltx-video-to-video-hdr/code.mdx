То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/ltx/ltx-video-to-video-hdr/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "ltx/ltx-video-to-video-hdr",
            {
                "output_colorspace": "acescg",
                "video_uri": "https://test-videos.co.uk/vids/sintel/mp4/h264/720/Sintel_720_10s_1MB.mp4",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивает состояние до завершения запроса, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственные данные провайдера — то же значение, что возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())

import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("ltx/ltx-video-to-video-hdr", {
  output_colorspace: "acescg",
  video_uri: "https://test-videos.co.uk/vids/sintel/mp4/h264/720/Sintel_720_10s_1MB.mp4",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивает состояние до завершения запроса, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);

## Схема

### Входы

<ParamField body="output_colorspace" type="string" default="&quot;acescg&quot;">
  Цветовое пространство последовательности кадров OpenEXR по адресу `result.exr_frames_url`. На `result.video_url` оно не влияет.

  Возможные значения: `acescg`, `acescct`, `srgb_linear`, `aces2065-1`
</ParamField>

<ParamField body="video_uri" type="string" required>
  Входное видео в виде общедоступного HTTPS-URL или data URI в base64. H.264 или HEVC в MP4, MOV или MKV, до 200 МБ по URL. Ширина и высота должны укладываться в 3840x2160 при любой ориентации.
</ParamField>

Схема сгенерирована из документа, который Router отдаёт по адресу `GET /v2/models/ltx/ltx-video-to-video-hdr/openapi.json`. По этому же документу проверяется вызов, прежде чем запрос уходит провайдеру.
