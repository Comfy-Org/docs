Справочник по API для `ltx/ltx-video-alpha-gen`, предоставляемого Comfy Router от LTX.

**Вход:** Видео · **Выход:** Видео

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов напрямую через HTTP.

**ID модели:** `ltx/ltx-video-alpha-gen`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/ltx/ltx-video-alpha-gen`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/ltx/ltx-video-alpha-gen/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "ltx/ltx-video-alpha-gen",
            {
                "video_uri": "https://test-videos.co.uk/vids/sintel/mp4/h264/720/Sintel_720_10s_1MB.mp4",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели этого достаточно другому процессу

        # Опрашивает, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, здесь вызывает типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("ltx/ltx-video-alpha-gen", {
  video_uri: "https://test-videos.co.uk/vids/sintel/mp4/h264/720/Sintel_720_10s_1MB.mp4",
});
console.log("requestId:", handle.requestId); // вместе с ID модели этого достаточно другому процессу

// Опрашивает, пока запрос не завершится, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, который завершился ошибкой или был отменён, здесь отклоняется.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/ltx/ltx-video-alpha-gen/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"video_uri\": \"https://test-videos.co.uk/vids/sintel/mp4/h264/720/Sintel_720_10s_1MB.mp4\"}"

# 2. Опрос, пока статус не станет COMPLETED, с ожиданием Retry-After в секундах, указанного в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/ltx/ltx-video-alpha-gen/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/ltx/ltx-video-alpha-gen/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="video_uri" type="string" required>
  Входное видео в виде общедоступного HTTPS-URL или data URI в base64. H.264 или HEVC в MP4, MOV или MKV, до 200 МБ при передаче по URL. Не более 3840 пикселей по длинной стороне и 2160 по короткой.
</ParamField>

Создано на основе схемы, которую Router отдаёт по адресу `GET /v2/models/ltx/ltx-video-alpha-gen/openapi.json`, того же документа, по которому он проверяет вызов, прежде чем запрос достигает провайдера.

### Выходы

<ResponseField name="completed_at" type="string">
  Отметка времени завершения задачи (ISO 8601)
</ResponseField>

<ResponseField name="created_at" type="string">
  Отметка времени создания задачи (ISO 8601)
</ResponseField>

<ResponseField name="error" type="object">
  Присутствует при статусе failed
</ResponseField>

<ResponseField name="error.message" type="string">
   
</ResponseField>

<ResponseField name="error.type" type="string">
   
</ResponseField>

<ResponseField name="id" type="string">
  Уникальный идентификатор задачи
</ResponseField>

<ResponseField name="result" type="object">
  Присутствует при статусе completed; URL результатов истекают через 24 часа после завершения
</ResponseField>

<ResponseField name="result.cutout_video_url" type="string">
  URL входного видео с маской в качестве альфа-канала, ProRes 4444 MOV
</ResponseField>

<ResponseField name="result.matte_video_url" type="string">
  URL полутоновой альфа-маски, MP4-файла, в котором белый цвет означает передний план
</ResponseField>

<ResponseField name="status" type="string">
  Статус задачи (pending, processing, completed, failed)
</ResponseField>
