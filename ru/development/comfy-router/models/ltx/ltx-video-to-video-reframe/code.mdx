Справочник по API для `ltx/ltx-video-to-video-reframe`, предоставляемый Comfy Router от LTX.

**Вход:** Видео · **Выход:** Видео

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL делает тот же вызов напрямую по HTTP.

**ID модели:** `ltx/ltx-video-to-video-reframe`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/ltx/ltx-video-to-video-reframe`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/ltx/ltx-video-to-video-reframe/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его для автоматических повторов.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "ltx/ltx-video-to-video-reframe",
            {
                "resolution": "720x1280",
                "video_uri": "https://test-videos.co.uk/vids/sintel/mp4/h264/720/Sintel_720_10s_1MB.mp4",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его для автоматических повторов.
const handle = await comfy.models.submit("ltx/ltx-video-to-video-reframe", {
  resolution: "720x1280",
  video_uri: "https://test-videos.co.uk/vids/sintel/mp4/h264/720/Sintel_720_10s_1MB.mp4",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/ltx/ltx-video-to-video-reframe/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"resolution\": \"720x1280\", \"video_uri\": \"https://test-videos.co.uk/vids/sintel/mp4/h264/720/Sintel_720_10s_1MB.mp4\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выжидая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/ltx/ltx-video-to-video-reframe/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/ltx/ltx-video-to-video-reframe/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="placement" type="object">
  Где исходное видео располагается в выходном кадре. Отправьте либо `anchor`, либо `x` и `y` вместе с `width`, `height` или обоими сразу. Опустите `placement`, чтобы центрировать видео в наибольшем размере, который помещается в кадр.
</ParamField>

<ParamField body="placement.anchor" type="string">
  Край или угол выходного кадра, к которому прижимается видео.

  Возможные значения: `center`, `top`, `bottom`, `left`, `right`, `top_left`, `top_right`, `bottom_left`, `bottom_right`
</ParamField>

<ParamField body="placement.height" type="number">
  Высота размещаемого видео как доля высоты выхода.

  Формат: `double`
</ParamField>

<ParamField body="placement.width" type="number">
  Ширина размещаемого видео как доля ширины выхода.

  Формат: `double`
</ParamField>

<ParamField body="placement.x" type="number">
  Левый край размещаемого видео как доля ширины выхода.

  Формат: `double`
</ParamField>

<ParamField body="placement.y" type="number">
  Верхний край размещаемого видео как доля высоты выхода.

  Формат: `double`
</ParamField>

<ParamField body="resolution" type="string" required>
  Целевое разрешение выхода. Исходное видео расширяется, чтобы заполнить этот кадр.

  Возможные значения: `720x720`, `1080x1080`, `720x900`, `1080x1350`, `900x720`, `1350x1080`, `720x1280`, `1080x1920`, `1280x720`, `1920x1080`
</ParamField>

<ParamField body="video_uri" type="string" required>
  Входное видео в виде общедоступного HTTPS-URL или data URI в base64. H.264 или HEVC в MP4, MOV или MKV, до 200 МБ при передаче по URL. Не более 60 секунд и 1800 кадров, ширина и высота от 64 до 4096 пикселей.
</ParamField>
