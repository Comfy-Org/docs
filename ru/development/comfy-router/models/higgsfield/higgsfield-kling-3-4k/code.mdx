```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "higgsfield/higgsfield-kling-3-4k",
            {
                "aspect_ratio": "16:9",
                "cfg_scale": 0.5,
                "duration": 5,
                "prompt": "A cinematic glass pavilion in a misty pine forest at sunrise",
                "sound": "on",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("higgsfield/higgsfield-kling-3-4k", {
  aspect_ratio: "16:9",
  cfg_scale: 0.5,
  duration: 5,
  prompt: "A cinematic glass pavilion in a misty pine forest at sunrise",
  sound: "on",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

## Схема

### Входы

<ParamField body="aspect_ratio" type="string" default="&quot;16:9&quot;">
  Соотношение сторон выходного видео.

  Возможные значения: `16:9`, `9:16`, `1:1`
</ParamField>

<ParamField body="cfg_scale" type="number" default="0.5">
  Насколько строго генерация следует промпту. Higgsfield документирует диапазон 0-1 с шагом 0.01, но здесь объявлена только граница 0-1: `multipleOf: 0.01` вычислялся бы в двоичной плавающей точке и отвергал бы обычные значения, например 0.3, поэтому более точное значение ПРИНИМАЕТСЯ и передаётся дальше, а не отвергается, точно так же, как `prompt` оговаривает свой необъявленный потолок длины.

  Диапазон: от `0` до `1`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  Длительность выходного видео в секундах. Поддерживаемый диапазон: 3-15.

  Диапазон: от `3` до `15`
</ParamField>

<ParamField body="elements" type="string[]">
  Повторно используемые id элементов Kling для согласованности объекта между генерациями.
</ParamField>

<ParamField body="multi_prompt" type="object[]">
  Упорядоченные определения кадров, используются, когда `multi_shots` имеет значение true. От 1 до 6 кадров; длительность каждого кадра ограничена общей длительностью задачи, которую здесь выразить нельзя.
</ParamField>

<ParamField body="multi_prompt[].duration" type="integer">
  Длительность этого кадра в секундах, 1-15. Сумма по всем кадрам не должна превышать общую длительность задачи, что JSON Schema выразить не может; Higgsfield проверяет это.

  Диапазон: от `1` до `15`
</ParamField>

<ParamField body="multi_prompt[].prompt" type="string">
  Промпт для этого кадра. Higgsfield документирует потолок в 512 символов.
</ParamField>

<ParamField body="multi_shots" type="boolean" default="false">
  Включить последовательность из нескольких кадров. Если true, `multi_prompt` содержит определения для каждого кадра.
</ParamField>

<ParamField body="prompt" type="string">
  Промпт, описывающий желаемый результат. Higgsfield документирует, что Kling использует первые 2 500 символов и обрезает всё, что дальше, поэтому maxLength не объявлен: более длинное тело запроса принимается, а не отвергается.
</ParamField>

<ParamField body="sound" type="string" default="&quot;on&quot;">
  Включить или отключить сгенерированный звук.

  Возможные значения: `on`, `off`
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/higgsfield/higgsfield-kling-3-4k/openapi.json`, того же документа, по которому он проверяет вызов, прежде чем запрос достигнет провайдера.
