## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Примеры для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); пример cURL выполняет тот же вызов через обычный HTTP.

**ID модели:** `higgsfield/higgsfield-kling-3-pro`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/higgsfield/higgsfield-kling-3-pro`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/higgsfield/higgsfield-kling-3-pro/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, как только он будет готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его для автоматических повторов.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "higgsfield/higgsfield-kling-3-pro",
            {
                "aspect_ratio": "16:9",
                "cfg_scale": 0.5,
                "duration": 5,
                "prompt": "A cinematic glass pavilion in a misty pine forest at sunrise",
                "sound": "on",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивать, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его для автоматических повторов.
const handle = await comfy.models.submit("higgsfield/higgsfield-kling-3-pro", {
  aspect_ratio: "16:9",
  cfg_scale: 0.5,
  duration: 5,
  prompt: "A cinematic glass pavilion in a misty pine forest at sunrise",
  sound: "on",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивать, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправить. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/higgsfield/higgsfield-kling-3-pro/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"aspect_ratio\": \"16:9\", \"cfg_scale\": 0.5, \"duration\": 5, \"prompt\": \"A cinematic glass pavilion in a misty pine forest at sunrise\", \"sound\": \"on\"}"

# 2. Опрашивать, пока статус не станет COMPLETED, выдерживая количество секунд Retry-After, указанное в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/higgsfield/higgsfield-kling-3-pro/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Забрать. 200 с исходным выводом модели, 202 с телом статуса, пока он ещё выполняется.
curl https://api.comfy.org/v2/models/higgsfield/higgsfield-kling-3-pro/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="aspect_ratio" type="string" default="&quot;16:9&quot;">
  Соотношение сторон выходного видео.

  Возможные значения: `16:9`, `9:16`, `1:1`
</ParamField>

<ParamField body="cfg_scale" type="number" default="0.5">
  Насколько строго генерация следует промпту. Higgsfield документирует диапазон 0-1 с шагом 0.01, но здесь объявлена только граница 0-1: `multipleOf: 0.01` вычислялся бы в двоичной плавающей точке и отклонял бы обычные значения, например 0.3, поэтому более мелкое значение ПРИНИМАЕТСЯ и передаётся дальше, а не отклоняется, так же как `prompt` оговаривает свой необъявленный потолок длины.

  Диапазон: от `0` до `1`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  Длительность выходного видео в секундах. Поддерживаемый диапазон: 3-15.

  Диапазон: от `3` до `15`
</ParamField>

<ParamField body="elements" type="string[]">
  Переиспользуемые идентификаторы элементов Kling для согласованности субъекта между генерациями.
</ParamField>

<ParamField body="multi_prompt" type="object[]">
  Упорядоченные определения кадров, используются, когда `multi_shots` имеет значение true. От 1 до 6 кадров; длительности отдельных кадров ограничены общей длительностью самой задачи, что здесь выразить нельзя.
</ParamField>

<ParamField body="multi_prompt[].duration" type="integer">
  Длительность этого кадра в секундах, 1-15. Сумма по всем кадрам не должна превышать общую длительность задачи, что JSON Schema выразить не может; это проверяет Higgsfield.

  Диапазон: от `1` до `15`
</ParamField>

<ParamField body="multi_prompt[].prompt" type="string">
  Промпт для этого кадра. Higgsfield документирует потолок в 512 символов.
</ParamField>

<ParamField body="multi_shots" type="boolean" default="false">
  Включить последовательность из нескольких кадров. Если true, `multi_prompt` содержит определения отдельных кадров.
</ParamField>

<ParamField body="prompt" type="string">
  Промпт, описывающий желаемый результат. Higgsfield документирует, что Kling использует только первые 2,500 символов и обрезает всё сверх этого, поэтому maxLength не объявлен: более длинное тело запроса принимается, а не отклоняется.
</ParamField>

<ParamField body="sound" type="string" default="&quot;on&quot;">
  Включить или отключить сгенерированный звук.

  Возможные значения: `on`, `off`
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/higgsfield/higgsfield-kling-3-pro/openapi.json`, того же документа, по которому он проверяет вызов, прежде чем запрос достигнет провайдера.

### Выходы

<ResponseField name="cancel_url" type="string">
  Абсолютный URL для отмены запроса до начала обработки.
</ResponseField>

<ResponseField name="error" type="string">
  Детали сбоя, заполняется, когда `status` имеет значение `failed`.
</ResponseField>

<ResponseField name="request_id" type="string" required>
  Стабильный идентификатор для опроса, отмены и обращения в поддержку.
</ResponseField>

<ResponseField name="status" type="string" required>
  Текущее состояние запроса.

  Возможные значения: `queued`, `in_progress`, `nsfw`, `failed`, `completed`, `canceled`
</ResponseField>

<ResponseField name="status_url" type="string">
  Абсолютный URL для опроса, пока запрос не достигнет терминального состояния.
</ResponseField>

<ResponseField name="video" type="object">
  Один медиа-выход Higgsfield.
</ResponseField>

<ResponseField name="video.url" type="string" required>
  URL для скачивания сгенерированного медиа.
</ResponseField>
