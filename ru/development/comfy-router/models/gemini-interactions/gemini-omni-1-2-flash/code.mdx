## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. **Эндпоинт:** `POST https://api.comfy.org/v2/models/gemini-interactions/gemini-omni-1.2-flash`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/gemini-interactions/gemini-omni-1.2-flash/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его для автоматических повторов.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "gemini-interactions/gemini-omni-1.2-flash",
            {
                "input": "Reply with the single word: ok",
                "stream": False,
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, который называет сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его для автоматических повторов.
const handle = await comfy.models.submit("gemini-interactions/gemini-omni-1.2-flash", {
  input: "Reply with the single word: ok",
  stream: false,
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, который называет сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/gemini-interactions/gemini-omni-1.2-flash/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"input\": \"Reply with the single word: ok\", \"stream\": false}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выжидая Retry-After секунд, указанные в каждом ответе.

curl -i https://api.comfy.org/v2/models/gemini-interactions/gemini-omni-1.2-flash/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/gemini-interactions/gemini-omni-1.2-flash/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="input" type="object" required>
  Либо строка промпта, либо массив типизированных частей содержимого (text, image, audio, video, document).
</ParamField>

<ParamField body="model" type="string">
  Идентификатор модели Gemini: `gemini-omni-1.2-flash` или `gemini-omni-1.1-flash` (общедоступные), либо устаревший `gemini-omni-flash-preview`. На маршруте Comfy Router `POST /v2/models/gemini-interactions/{model}` он передаётся из пути и может быть опущен. Именно эти три написания, набор, который Comfy Router адресует как `gemini-interactions/<model>`, обслуживает данная операция (supportedGeminiInteractionModels); они выписаны здесь, а не ограничены перечислением, потому что прокси сам валидирует модель и возвращает собственный 400 на написание, которое он не обслуживает.
</ParamField>

<ParamField body="previous_interaction_id" type="string">
  ID ранее сохранённого взаимодействия, включающий многоходовое редактирование видео с сохранением состояния.
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по `GET /v2/models/gemini-interactions/gemini-omni-1.2-flash/openapi.json`, того же документа, по которому он валидирует вызов, прежде чем запрос дойдёт до провайдера.
