**Вход:** текст, изображение, видео · **Выход:** видео

## Настройка запроса

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Для Python выполните `pip install comfy-sdk`. Для TypeScript выполните `npm install @comfyorg/sdk`. В cURL используется обычный HTTP.

**ID модели:** `kelly/kelly-kling-4.0`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/kelly/kelly-kling-4.0`

<Note>
Router не опубликовал готовую схему входных данных для этой модели, поэтому примера запроса, из которого можно сгенерировать сниппет, нет. Router передаёт тело запроса в Kelly без изменений: составьте его по собственной документации API Kelly, а затем отправьте с помощью [краткого руководства по Router](/ru/development/comfy-router/quickstart).
</Note>
