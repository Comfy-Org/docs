Справочник по API для `runway/gen4_image`, предоставляемого Comfy Router от Runway.

**Вход:** текст, изображение · **Выход:** изображение

## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты на Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL делает тот же вызов напрямую по HTTP.

**ID модели:** `runway/gen4_image`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/runway/gen4_image`

```python Python
from comfy_sdk import Comfy

# Читает COMFY_API_KEY из переменных окружения.
# SDK автоматически создаёт ключ идемпотентности и переиспользует его при автоматических повторах.
with Comfy() as client:
    result = client.models.run(
        "runway/gen4_image",

            "promptText": "a red circle",
            "ratio": "1024:1024",
        },
    )

print(result)
```

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/runway/gen4_image/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает работу со статусом, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменных окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "runway/gen4_image",
            {
                "promptText": "a red circle",
                "ratio": "1024:1024",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменных окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("runway/gen4_image", {
  promptText: "a red circle",
  ratio: "1024:1024",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выдерживая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/runway/gen4_image/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"promptText\": \"a red circle\", \"ratio\": \"1024:1024\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выдерживая Retry-After секунд, указанный в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/runway/gen4_image/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/runway/gen4_image/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="model" type="string">
  Модель для генерации. На маршруте Comfy Router `POST /v2/models/runway/{model}` это поле подставляется из пути, и отправлять его НЕЛЬЗЯ; на маршруте v1 `POST /proxy/runway/text_to_image` оно обязательно и ограничено значением `gen4_image`.
</ParamField>

<ParamField body="promptText" type="string" required>
  Текстовый промпт для генерации изображения, не более 1000 кодовых единиц UTF-16 (символ вне Basic Multilingual Plane, например большинство эмодзи, считается за две)
</ParamField>

<ParamField body="ratio" type="string" required>
  Возможные значения: `1920:1080`, `1080:1920`, `1024:1024`, `1360:768`, `1080:1080`, `1168:880`, `1440:1080`, `1080:1440`, `1808:768`, `2112:912`, `1280:720`, `720:1280`, `720:720`, `960:720`, `720:960`, `1680:720`
</ParamField>

<ParamField body="referenceImages" type="object[]">
  Массив референсных изображений, направляющих генерацию
</ParamField>

<ParamField body="referenceImages[].uri" type="string" required>
  URL по протоколу HTTPS, URI загрузки Runway (runway://) или data URI, содержащий закодированное изображение
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/runway/gen4_image/openapi.json`. Это тот же документ, по которому Router проверяет вызов, прежде чем запрос дойдёт до провайдера.

### Выходы

<ResponseField name="createdAt" type="string (date-time)" required>
  Временная метка создания задачи

  Формат: `date-time`
</ResponseField>

<ResponseField name="id" type="string" required>
  ID задачи
</ResponseField>

<ResponseField name="output" type="string[]">
  URL-адреса ресурсов завершённой генерации: для `runway/gen4_image` каждый элемент это URL изображения. Присутствует после успешного завершения задачи; этот список И ЕСТЬ результат.
</ResponseField>

<ResponseField name="progress" type="number">
  Значение с плавающей точкой от 0 до 1, отражающее прогресс задачи. Доступно, только если статус RUNNING.

  Диапазон: `0` до `1`

  Формат: `float`
</ResponseField>

<ResponseField name="status" type="string" required>
  Возможные статусы задачи Runway.

  Возможные значения: `SUCCEEDED`, `RUNNING`, `FAILED`, `PENDING`, `CANCELLED`, `THROTTLED`
</ResponseField>
