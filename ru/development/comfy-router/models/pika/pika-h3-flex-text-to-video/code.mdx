То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/pika/pika-h3-flex-text-to-video/requests`. Router отвечает `201` с `request_id` сразу после того, как запуск принят, а результат забирается, когда он готов, из этого или другого процесса. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "pika/pika-h3-flex-text-to-video",
            {
                "duration": 5,
                "prompt": "A paper boat drifts down a rain-soaked street at dusk while thunder rolls in the distance",
                "resolution": "480p",
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивайте, пока запрос не завершится, выжидая Retry-After, который укажет сервер.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный ответ провайдера, то же значение, что возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())

import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт свой Idempotency-Key и переиспользует его при автоматических повторах.
const handle = await comfy.models.submit("pika/pika-h3-flex-text-to-video", {
  duration: 5,
  prompt: "A paper boat drifts down a rain-soaked street at dusk while thunder rolls in the distance",
  resolution: "480p",
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивайте, пока запрос не завершится, выжидая Retry-After, который укажет сервер.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, что возвращает models.run(). Запрос, который завершился ошибкой или был отменён, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

## Схема

### Входы

<ParamField body="aspect_ratio" type="string">
  Соотношение сторон результата. `auto` выбирает его на основе промпта и медиавходов. Не указывайте параметр, чтобы Pika выбрала сама: `auto`, если включён `rewrite`, иначе соотношение первого медиавхода, иначе 16:9.

  Возможные значения: `auto`, `21:9`, `16:9`, `3:2`, `4:3`, `5:4`, `1:1`, `4:5`, `3:4`, `2:3`, `9:16`, `9:21`
</ParamField>

<ParamField body="channel_mode" type="string" default="&quot;mono&quot;">
  Только для аудиостемов. `mono` выполняет даунмикс перед разделением; `stereo` сохраняет оба канала. Аудио видео при этом не меняется.

  Возможные значения: `stereo`, `mono`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  Длительность видео в целых секундах, от 5 до 15.

  Диапазон: от `5` до `15`
</ParamField>

<ParamField body="output_mode" type="string" default="&quot;video&quot;">
  `video` возвращает только видео. `audio-stems` дополнительно возвращает WAV-стемы Dialogue, Music и Effect в `output.stems` и добавляет посекундное списание средств Pika за разделение на стемы.

  Возможные значения: `video`, `audio-stems`
</ParamField>

<ParamField body="prompt" type="string" required>
  Текстовый промпт, описывающий видео и его аудио.
</ParamField>

<ParamField body="resolution" type="string" default="&quot;768p&quot;">
  Разрешение результата. 480p и 768p нативные. 1080p, 2k и 4k генерируются в 768p, а затем масштабируются с сохранением аудио и частоты кадров.

  Возможные значения: `480p`, `768p`, `1080p`, `2k`, `4k`
</ParamField>

<ParamField body="rewrite" type="boolean" default="true">
  Улучшает промпт перед генерацией. Установите значение false, чтобы использовать промпт как есть.
</ParamField>

<ParamField body="seed" type="integer" default="0">
  Seed для видео, 0 или больше.

  Диапазон: от `0` до `…`

  Формат: `int64`
</ParamField>
