Справочник по API для `pika/pika-2.5-image-to-video`, предоставляемый Comfy Router от Pika.

**Вход:** текст, изображение · **Выход:** видео

## Быстрый старт

Создайте ключ в [вашем рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL выполняет тот же вызов напрямую по HTTP.

**ID модели:** `pika/pika-2.5-image-to-video`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/pika/pika-2.5-image-to-video`

from comfy_sdk import Comfy

# Читает COMFY_API_KEY из переменной окружения.
# SDK автоматически создаёт ключ идемпотентности и использует его повторно при автоматических повторах.

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/pika/pika-2.5-image-to-video/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из текущего процесса или другого. [Доставка через очередь](/ru/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и использует его повторно при автоматических повторах.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "pika/pika-2.5-image-to-video",
            {
                "duration_s": 5,
                "image": "https://example.invalid/pika/source.png",
                "prompt": "The camera slowly pushes in as the leaves begin to sway",
                "resolution": "720p",
            },
        )
        print("request_id:", handle.request_id)  # с ID модели другому процессу больше ничего не нужно

        # Опрашивайте, пока запрос не завершится, выжидая указанный сервером Retry-After.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственная полезная нагрузка провайдера, то же значение, которое возвращает models.run().
        # Запрос, который завершился ошибкой или был отменён, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и использует его повторно при автоматических повторах.
const handle = await comfy.models.submit("pika/pika-2.5-image-to-video", {
  duration_s: 5,
  image: "https://example.invalid/pika/source.png",
  prompt: "The camera slowly pushes in as the leaves begin to sway",
  resolution: "720p",
});
console.log("requestId:", handle.requestId); // с ID модели другому процессу больше ничего не нужно

// Опрашивайте, пока запрос не завершится, выжидая указанный сервером Retry-After.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, который завершился ошибкой или был отменён, будет отклонён здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправить. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/pika/pika-2.5-image-to-video/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"duration_s\": 5, \"image\": \"https://example.invalid/pika/source.png\", \"prompt\": \"The camera slowly pushes in as the leaves begin to sway\", \"resolution\": \"720p\"}"

# 2. Опрашивайте, пока статус не станет COMPLETED, выжидая указанное в каждом ответе количество секунд Retry-After.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/pika/pika-2.5-image-to-video/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Забрать. 200 с собственным выводом модели, 202 с телом статуса, пока он всё ещё выполняется.
curl https://api.comfy.org/v2/models/pika/pika-2.5-image-to-video/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="duration_s" type="integer" default="5">
  Длительность видео в секундах.

  Возможные значения: `5`, `10`
</ParamField>

<ParamField body="image" type="string" required>
  Публичный https-URL исходного изображения, которое нужно анимировать. Субъект задаётся изображением. Простой `http://` отклоняется: Pika загружает URL по запросу, отправленному под ключом Comfy.
</ParamField>

<ParamField body="negative_prompt" type="string">
  Текст, описывающий, чего следует избегать в видео.
</ParamField>

<ParamField body="prompt" type="string">
  Текстовый промпт, задающий движение.
</ParamField>

<ParamField body="resolution" type="string" default="&quot;1080p&quot;">
  Разрешение выходного видео.

  Возможные значения: `720p`, `1080p`
</ParamField>

<ParamField body="seed" type="integer">
  Сид для воспроизводимой генерации. Пропустите его (или отправьте null), чтобы получить случайный сид.
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/pika/pika-2.5-image-to-video/openapi.json`, того же документа, по которому он проверяет вызов до того, как запрос дойдёт до провайдера.

### Выходы

<ResponseField name="error" type="object">
  Структурированная запись об ошибке от Pika, устанавливается для задачи со статусом `failed`. Router отвечает на задачу со статусом `failed` собственным ответом об ошибке, поэтому тело, которое возвращает Router, её не содержит; поле объявлено, так как является частью документа задачи Pika.
</ResponseField>

<ResponseField name="error.code" type="string" required>
  Возможные значения: `invalid_input`, `content_moderation`, `provider_error`, `provider_timeout`, `provider_unavailable`, `rate_limited`, `insufficient_balance`, `membership_required`, `cycle_limit_exceeded`, `admission_suspended`, `usage_limit_exceeded`, `timed_out`, `internal`
</ResponseField>

<ResponseField name="error.message" type="string" required>
   
</ResponseField>

<ResponseField name="id" type="string" required>
  ID задачи в Pika.
</ResponseField>

</ResponseField>

<ResponseField name="usage" type="object">
  Единицы использования, сообщаемые провайдером для задачи. Ключи разрежены: присутствуют только те единицы, которые сообщает задача.
</ResponseField>
