## Быстрый старт

Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) и экспортируйте его как `COMFY_API_KEY`. Фрагменты для Python и TypeScript используют Comfy SDK (`pip install comfy-sdk` и `npm install @comfyorg/sdk`); фрагмент cURL делает тот же вызов по чистому HTTP.

**ID модели:** `anthropic/claude-fable-5`

**Эндпоинт:** `POST https://api.comfy.org/v2/models/anthropic/claude-fable-5`

То же тело запроса, отправленное на `POST https://api.comfy.org/v2/models/anthropic/claude-fable-5/requests`. Router отвечает `201` с `request_id`, как только запуск принят, а результат забирается, когда он готов, из этого процесса или из другого. [Доставка через очередь](/development/comfy-router/queue) описывает статус, отмену и получение результата.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Читает COMFY_API_KEY из переменной окружения.
# Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его для автоматических повторов.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "anthropic/claude-fable-5",
            {
                "max_tokens": 16,
                "messages": [
                    {
                        "content": "Reply with the single word: ok",
                        "role": "user",
                    },
                ],
            },
        )
        print("request_id:", handle.request_id)  # вместе с ID модели это всё, что нужно другому процессу

        # Опрашивать, пока запрос не завершится, выжидая Retry-After, указанный сервером.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # Собственный payload провайдера, то же значение, которое возвращает models.run().
        # Запрос, завершившийся ошибкой или отменённый, вызывает здесь типизированную ошибку Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Читает COMFY_API_KEY из переменной окружения.
// Каждый вызов submit() создаёт собственный Idempotency-Key и переиспользует его для автоматических повторов.
const handle = await comfy.models.submit("anthropic/claude-fable-5", {
  max_tokens: 16,
  messages: [
    {
      content: "Reply with the single word: ok",
      role: "user",
    },
  ],
});
console.log("requestId:", handle.requestId); // вместе с ID модели это всё, что нужно другому процессу

// Опрашивать, пока запрос не завершится, выжидая Retry-After, указанный сервером.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Тот же результат, который возвращает models.run(). Запрос, завершившийся ошибкой или отменённый, отклоняется здесь.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Отправка. Router отвечает 201 с request_id, status_url, response_url и cancel_url.
curl https://api.comfy.org/v2/models/anthropic/claude-fable-5/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"max_tokens\": 16, \"messages\": [{\"content\":\"Reply with the single word: ok\",\"role\":\"user\"}]}"

# 2. Опрашивать, пока статус не станет COMPLETED, выжидая Retry-After секунд, указанные в каждом ответе.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/anthropic/claude-fable-5/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Получение. 200 с нативным выводом модели, 202 с телом статуса, пока запрос ещё выполняется.
curl https://api.comfy.org/v2/models/anthropic/claude-fable-5/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```

## Схема

### Входы

<ParamField body="max_tokens" type="integer" required>
  Максимальное количество токенов, которое нужно сгенерировать до остановки.
</ParamField>

<ParamField body="messages" type="object[]" required>
  Реплики диалога. Полную таксономию блоков содержимого см. в документации Anthropic Messages API.
</ParamField>

<ParamField body="messages[].content" type="object" required>
  Либо сокращённая форма в виде строки, либо массив блоков содержимого (text, image, document, tool_use, tool_result, ...).
</ParamField>

<ParamField body="messages[].role" type="string" required>
  Возможные значения: `user`, `assistant`
</ParamField>

<ParamField body="model" type="string">
  Идентификатор модели Anthropic (например, `claude-sonnet-4-5`, `claude-opus-4-7`).
</ParamField>

<ParamField body="stream" type="boolean">
  На маршруте Comfy Router `POST /v2/models/anthropic/{model}` параметр `stream` НЕ ДЕЙСТВУЕТ: Router принудительно устанавливает его в `false` перед отправкой и всегда возвращает завершённое сообщение одним JSON-документом. На маршруте v1 `POST /proxy/anthropic/v1/messages` значение `true` превращает ответ в `text/event-stream` событий сообщений Anthropic вместо одного JSON-тела. На Router передавайте `stream` со значением `false` или не указывайте его вовсе; у ветки `text/event-stream` ответа 200 операции `/proxy/` нет аналога в Router.
</ParamField>

<ParamField body="system" type="object">
  Системный промпт верхнего уровня. Либо строка, либо массив блоков содержимого; и то и другое доходит до Anthropic без изменений.
</ParamField>

Сгенерировано из схемы, которую Router отдаёт по адресу `GET /v2/models/anthropic/claude-fable-5/openapi.json`, того же документа, по которому он проверяет вызов, прежде чем запрос дойдёт до провайдера.
