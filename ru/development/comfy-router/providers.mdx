Каждая модель использует `POST /v2/models/{provider}/{model}`. Comfy является провайдером по умолчанию. Для моделей с альтернативным покрытием `model_provider` выбирает другого провайдера без изменения ID модели или тела запроса. См. [`model_provider`, `strict_mode` и `fallback_provider`](/ru/development/comfy-router/reference#post-v2modelsprovidermodel) в справочнике по API.
