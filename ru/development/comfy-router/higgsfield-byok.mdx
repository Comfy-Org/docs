Higgsfield [проводит акцию кешбэка за расходы на API](https://higgsfield.ai). Мы не собираемся отговаривать вас от участия.

Используйте свой ключ Higgsfield в Comfy Router, и ваши генерации будут выполняться в **вашем** аккаунте Higgsfield, поэтому они будут учитываться как ваши расходы в Higgsfield, а выгода, которую эта акция вам даёт, останется у вас. При этом вы по-прежнему получаете один эндпоинт, один клиент и ту же форму запроса, что и для любой другой модели в Router.

<Note>
  Higgsfield является организатором акции и устанавливает её условия. Проверьте актуальное предложение на их сайте, прежде чем на него рассчитывать.
</Note>

## Что меняется, если использовать свой ключ

| | Ваш ключ Comfy | Ваш ключ Higgsfield |
| --- | --- | --- |
| Оплачивается | Ваши кредиты Comfy | Ваш аккаунт Higgsfield |
| Списание кредитов Comfy | Да | **Нет** |
| Эндпоинт, тело запроса, ответ | Без изменений | Без изменений |

Всё остальное в вызове не меняется. Чтобы переключиться, не нужно менять код: вы сохраняете ключ, и Router использует его.

<Steps>
  <Step title="Получить API-ключ Higgsfield">
    Создайте ключ в [своём аккаунте Higgsfield](https://higgsfield.ai). Higgsfield выдаёт его как **пару id и secret**, а Comfy хранит его как одну строку `id:secret`: двоеточие нужно сохранить, не разделяйте значение на два поля.
  </Step>

  <Step title="Сохранить его в Comfy">
    Откройте [**Provider keys**](https://platform.comfy.org/profile/provider-keys) в своём профиле Comfy, выберите **Higgsfield** и вставьте значение `id:secret`.

    Ваш ключ шифруется при хранении и после сохранения никогда не возвращается через API. Router читает его только для подписи ваших собственных вызовов.
  </Step>

  <Step title="Создать Comfy API-ключ">
    Это ключ, который аутентифицирует вас в Comfy; он не связан с ключом Higgsfield. Создайте его в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys), затем задайте:

    ```bash
    export COMFY_API_KEY="comfyui-..."
    ```

    Храните API-ключи на своём сервере или в локальном окружении. Эти примеры предназначены для терминала или сервера, а не для JavaScript в браузере.
  </Step>

  <Step title="Запустить модель">
    Скопируйте и вставьте фрагмент кода ниже для выбранной модели.
  </Step>
</Steps>

## Модели

<Tabs>
  <Tab title="Kling 3.0 std">
    Сбалансированное качество и скорость. `duration` принимает значения от 3 до 15 секунд.

    <CodeGroup>

    ```bash cURL
    curl --max-time 660 \
      https://api.comfy.org/v2/models/higgsfield/higgsfield-kling-3-std \
      -H "X-API-Key: $COMFY_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "prompt": "A cinematic glass pavilion in a misty pine forest at sunrise",
        "duration": 5,
        "aspect_ratio": "16:9",
        "cfg_scale": 0.5,
        "sound": "on"
      }'
    ```

    ```python Python
    # Python 3.10+
    # Install: python -m pip install "comfy-sdk>=0.3.0"

    from comfy_sdk import Comfy

    # Comfy reads COMFY_API_KEY from the environment.
    with Comfy() as client:
        result = client.models.run(
            "higgsfield/higgsfield-kling-3-std",
            {
                "prompt": "A cinematic glass pavilion in a misty pine forest at sunrise",
                "duration": 5,
                "aspect_ratio": "16:9",
                "cfg_scale": 0.5,
                "sound": "on",
            },
            timeout=660.0,
        )

    print("video:", result["video"]["url"])
    ```

    ```typescript TypeScript
    // Node.js 22+
    // Install: npm install "@comfyorg/sdk@>=0.4.0" --save-dev tsx

    import { comfy } from "@comfyorg/sdk";

    type HiggsfieldResult = { video: { url: string } };

    const { data } = await comfy.models.run<HiggsfieldResult>(
      "higgsfield/higgsfield-kling-3-std",
      {
        prompt: "A cinematic glass pavilion in a misty pine forest at sunrise",
        duration: 5,
        aspect_ratio: "16:9",
        cfg_scale: 0.5,
        sound: "on",
      },
      { timeoutMs: 660_000 },
    );

    console.log("video:", data.video.url);
    ```

## Чтение результата

`run` возвращает собственный итоговый документ Higgsfield. URL для скачивания находится в `video.url`:

```json
{
  "status": "completed",
  "request_id": "0c4a9e17-5b82-4d66-9a3f-7c1e08b45d29",
  "video": { "url": "https://example.com/generated.mp4" }
}
```

Сохраните его сразу же:

```bash
curl --fail --location "PASTE_VIDEO_URL_HERE" --output out.mp4
```

Router сам опрашивает Higgsfield, поэтому состояния `queued` и `in_progress` до вас не доходят: вы получаете завершённый документ или ошибку. `nsfw`, `failed` и `canceled` являются терминальными ошибками; `failed` содержит подробности в `error`.

## Примечания

- **Валидация выполняется до вызова Higgsfield.** Если тело запроса выходит за опубликованные границы, возвращается `422` с указанием проблемного поля, и ничего не отправляется во внешний сервис, поэтому ошибочный запрос ничего вам не стоит.
- **Ваш ключ используется только для тех моделей, для которых он у вас есть.** Сохранение ключа Higgsfield никак не влияет на то, как оплачивается любой другой провайдер в Router.
- Полные схемы запросов и ответов для каждой модели приведены в [справочнике Comfy Router](/ru/development/comfy-router/reference).
