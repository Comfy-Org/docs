Каждая модель Router адресуется по ID вида `{provider}/{model}`. Используйте каталог, чтобы найти этот ID, а затем вызовите `POST /v2/models/{provider}/{model}`.

## Просмотреть каталог

Перечислите модели с тем же API-ключом, который используется для генерации:

```bash
curl -H "X-API-Key: $COMFY_API_KEY" \
  "https://api.comfy.org/v2/models?limit=50"
```

Сокращённый ответ каталога:

```json
{
  "data": [
    {
      "id": "bfl/flux-2-pro",
      "provider": "bfl",
      "model": "flux-2-pro",
      "billing": { "charges_on_policy_rejection": "no" }
    }
  ],
  "has_more": true,
  "next_cursor": "example-cursor",
  "limit": 50
}
```

Используйте `id` в пути вызова. Объект `billing` содержит факты о выставлении счетов, а не цену. Прочитайте [выставление счетов при отказе по политике](/ru/development/comfy-router/billing#сведения-о-списании-средств-за-модели), прежде чем полагаться на него.

### Пагинация

- Когда `has_more` равно `true`, передайте полученный `next_cursor` как `cursor`. Остановитесь, когда `has_more` равно `false`, даже если ранее полученная страница была короче запрошенной.
- Считайте курсоры непрозрачными. Кодируйте значение для URL, например в cURL `--get --data-urlencode "cursor=$NEXT_CURSOR"`; не вычисляйте смещения и не изменяйте курсор.
- `limit` по умолчанию равен 20 и ограничен сверху значением 100. Значения выше предела обрезаются; ноль и отрицательные значения выбирают значение по умолчанию. В ответе указывается фактически использованный лимит.
- Недействительный курсор возвращает `400` / `invalid_input`. Список при этом не перезапускается незаметно.
- Курсор может оставаться действительным при обновлениях каталога, но обход не является снимком состояния: модель, добавленная до вашей текущей позиции, может не появиться в этом обходе.

`503` / `service_unavailable` является временной ошибкой. Повторите попытку с задержкой; не считайте это пустым каталогом. Методы запуска SDK вызывают выбранную модель напрямую.

## Прочитать модель

Получите запись каталога напрямую, если знаете ID модели:

```bash
curl -H "X-API-Key: $COMFY_API_KEY" \
  https://api.comfy.org/v2/models/bfl/flux-2-pro
```

Эндпоинт сведений о модели позволяет не обходить весь каталог. Полный набор полей записи описан в [справочнике API](/development/comfy-router/reference).
