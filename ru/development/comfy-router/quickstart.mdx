<div className="router-quickstart-marker" />

Comfy Router предоставляет единый API для размещённых моделей изображений и видео по адресу `https://api.comfy.org`. Создайте API-ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router), затем вызывайте любую модель с помощью официальных [SDK для Python и TypeScript](/ru/development/api-development/sdks) или по обычному HTTP. Оплата производится по факту использования: по умолчанию каждый запрос списывает кредиты с баланса рабочего пространства, без подписки. Тарифы и другие варианты оплаты см. в разделе [Цены Router](/development/comfy-router/pricing).

<Note>
  **Отслеживаете расходы с помощью LiteLLM?** Router передаёт стоимость синхронного запуска в долларах США в заголовке, который читает LiteLLM, поэтому вам не нужно вести таблицу цен. См. [Использование Comfy Router с LiteLLM](/ru/development/comfy-router/litellm).
</Note>

<Steps titleSize="h2">
  <Step title="Добавить кредиты в рабочее пространство (необязательно)">
    Пропустите этот шаг, если ваше рабочее пространство уже пополнено или использует корпоративный план.

    Router списывает кредиты за каждый запрос, а рабочее пространство без баланса кредитов получает `402` с `error_type: insufficient_credits`. Пополните счёт в разделе [выставления счетов рабочего пространства](https://platform.comfy.org/settings/billing). О том, как отображаются списания, см. в разделе [Оплата Router](/ru/development/comfy-router/billing).
  </Step>

  <Step title="Создать API-ключ">
    Создайте ключ в [своём рабочем пространстве Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router). В терминале, совместимом с Bash, задайте:

    ```bash
    export COMFY_API_KEY="comfyui-..."
    ```

    Храните API-ключи на сервере или в локальной среде. Эти примеры предназначены для терминала или сервера, а не для JavaScript в браузере.

    Рабочее пространство без средств возвращает `402` `insufficient_credits` даже при недопустимом теле запроса, поскольку проверка кредитов выполняется до валидации тела. Сначала добавьте кредиты (шаг 1), а затем отлаживайте запрос.
  </Step>

  <Step title="Отправить запрос в очередь">
    Выберите язык и запустите пример. Генерация может занять несколько минут.

    <CodeGroup>

    ```python Python
    # Python 3.10+
    # Установка: python -m pip install "comfy-sdk>=0.3.0"
    # Сохраните как quickstart.py, затем запустите: python quickstart.py

    import asyncio

    from comfy_sdk import AsyncComfy

    # AsyncComfy читает COMFY_API_KEY из переменных среды.
    async def main():
        async with AsyncComfy() as client:
            handle = await client.models.submit(
                "byteplus/dreamina-seedance-2-5-260628",
                {
                    "content": [
                        {
                            "text": "A red fox trotting through a snowy pine forest",
                            "type": "text",
                        },
                    ],
                    "duration": 5,
                    "ratio": "16:9",
                    "resolution": "720p",
                },
            )
            print("request_id:", handle.request_id)

            # Опрашивайте до завершения запроса, выжидая Retry-After, указанный сервером.
            async for update in handle.iter_events():
                print(update.status, update.queue_position)

            result = await handle.get()

        print("result:", result)

    asyncio.run(main())
    ```

    ```bash cURL
    # 1. Отправьте запрос. Сохраните request_id из ответа 201.
    curl https://api.comfy.org/v2/models/byteplus/dreamina-seedance-2-5-260628/requests \
      -H "X-API-Key: $COMFY_API_KEY" \
      -H "Idempotency-Key: $(uuidgen)" \
      -H "Content-Type: application/json" \
      -d '{"content": [{"text": "A red fox trotting through a snowy pine forest", "type": "text"}], "duration": 5, "ratio": "16:9", "resolution": "720p"}'

    # 2. Опрашивайте, пока статус не станет COMPLETED, каждый раз выжидая значение Retry-After.
    REQUEST_ID="paste-request-id-from-201-response"
    curl -i "https://api.comfy.org/v2/models/byteplus/dreamina-seedance-2-5-260628/requests/$REQUEST_ID/status" \
      -H "X-API-Key: $COMFY_API_KEY"

    # 3. Получите результат модели.
    curl "https://api.comfy.org/v2/models/byteplus/dreamina-seedance-2-5-260628/requests/$REQUEST_ID" \
      -H "X-API-Key: $COMFY_API_KEY"
    ```

    ```typescript TypeScript
    // Node.js 22+
    // Установка: npm install "@comfyorg/sdk@>=0.4.0" --save-dev tsx
    // Сохраните как quickstart.mts, затем запустите: npx tsx quickstart.mts

    import { comfy } from "@comfyorg/sdk";

    // Comfy читает COMFY_API_KEY из переменных среды.
    const handle = await comfy.models.submit(
      "byteplus/dreamina-seedance-2-5-260628",
      {
        content: [
          {
            text: "A red fox trotting through a snowy pine forest",
            type: "text",
          },
        ],
        duration: 5,
        ratio: "16:9",
        resolution: "720p",
      },
    );
    console.log("requestId:", handle.requestId);

    // Опрашивайте до завершения запроса, выжидая Retry-After, указанный сервером.
    for await (const update of handle.events()) {
      console.log(update.status, update.queuePosition);
    }

    const result = await handle.get();

    console.log("result:", result.data);
    ```

    </CodeGroup>

    Каждый вызов отправки через SDK создаёт ключ идемпотентности и повторно использует его при автоматических повторных попытках.
    Пример cURL создаёт его с помощью `uuidgen`. Если эта утилита недоступна, используйте другой генератор UUID.
    Подробнее о статусе, отмене и получении результатов см. в разделе [Доставка через очередь](/ru/development/comfy-router/queue).
  </Step>
</Steps>

## Изображение в видео и видео по референсу

Один и тот же запрос Seedance принимает на вход изображения, видео и аудио. Добавьте элементы в `content` и задайте каждому `role`. Отправленные роли определяют, какую операцию выполнит Router. Тарификация зависит от типов медиа в `content`, а не от ролей: запрос с любым видео на входе тарифицируется как видео в видео, иначе запрос с любым изображением тарифицируется как изображение в видео, а запрос только с текстом тарифицируется как текст в видео. Некоторые модели берут одинаковую ставку за текст в видео и изображение в видео.

| Операция | Элементы `content` |
|---|---|
| Текст в видео | один элемент `text` |
| Изображение в видео | элемент `text` плюс элемент `image_url` с `role: first_frame` |
| Первый и последний кадр | то же самое плюс второй элемент `image_url` с `role: last_frame` |
| Видео по референсу | элемент `text` плюс элементы `image_url` с `role: reference_image`, а на Seedance 2.0 и 2.5 также элементы `video_url` с `role: reference_video` и элементы `audio_url` с `role: reference_audio` |

`url` изображения может быть публичным URL или строкой `data:image/<format>;base64,<content>`. Отправляйте запрос, опрашивайте статус и забирайте результат точно так же, как в быстром старте выше. Меняется только тело запроса.

```bash Image-to-video
curl https://api.comfy.org/v2/models/byteplus/dreamina-seedance-2-5-260628/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "content": [
      {"type": "text", "text": "The fox turns and runs into the trees"},
      {"type": "image_url", "image_url": {"url": "https://example.com/fox.png"}, "role": "first_frame"}
    ],
    "duration": 5,
    "resolution": "720p"
  }'
```

```bash Reference-to-video
curl https://api.comfy.org/v2/models/byteplus/dreamina-seedance-2-5-260628/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "content": [
      {"type": "text", "text": "The character from the reference walks through a neon-lit market"},
      {"type": "image_url", "image_url": {"url": "https://example.com/character.png"}, "role": "reference_image"},
      {"type": "image_url", "image_url": {"url": "https://example.com/outfit.png"}, "role": "reference_image"}
    ],
    "omni_reference_task_type": "reference",
    "duration": 5,
    "ratio": "16:9",
    "resolution": "720p"
  }'
```

На Seedance 2.5 запросы с первым кадром и с первым и последним кадром берут соотношение сторон результата из первого кадра. Не передавайте `ratio` или отправьте `adaptive`, поскольку конкретное соотношение отклоняется с ошибкой `400`. Схема запроса общая для всего семейства Seedance и может перечислять роли, которые модель игнорирует, поэтому проверяйте поле `x-comfy-router-input-modalities` в [схеме входов](/ru/development/comfy-router/models) каждой модели, чтобы узнать, какие типы входов она принимает. Например, для `reference_video` и `reference_audio` нужна модель, в которой там указаны `video` или `audio`.

### Изменить или продлить видео по референсу

На Seedance 2.5 поле `omni_reference_task_type` сообщает модели, что делать с референсными медиа: `reference` создаёт новое видео по ним, `edit` изменяет клип `reference_video`, а `extend` продолжает его. Без этого поля модель выбирает задачу по промпту, а при редактировании сохраняются собственные длительность и соотношение сторон клипа, а `duration` и `ratio` игнорируются. На нативном плече BytePlus явное значение, не подходящее к запросу, отклоняется до начала генерации, поэтому средства не списываются. У альтернативного плеча провайдера, которое используется при отказе или выбирается через `model_provider`, нет поля типа задачи: оно отбрасывает значение и позволяет этому провайдеру определить задачу так, как если бы поле не передавалось. Об отбрасывании сообщается в `X-Comfy-Router-Dropped-Params`: в ответе маршрута синхронного запуска и в ответе `201` на отправку в очередь. У маршрута с очередью нет резервного варианта, поэтому он попадает на альтернативное плечо только через `model_provider`.

```bash Edit a reference video
curl https://api.comfy.org/v2/models/byteplus/dreamina-seedance-2-5-260628/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "content": [
      {"type": "text", "text": "Make the fox bright red"},
      {"type": "video_url", "video_url": {"url": "https://example.com/fox.mp4"}, "role": "reference_video"}
    ],
    "omni_reference_task_type": "edit",
    "duration": -1,
    "resolution": "720p"
  }'
```

При редактировании сохраняется длительность исходного клипа, поэтому отправьте `"duration": -1` и не передавайте `ratio`. Запрос `extend` возвращает только новый сгенерированный фрагмент, длительностью из отправленного `duration`.
