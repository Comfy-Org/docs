ComfyUI представляет собой модульный движок вывода GenAI, который можно запустить как сервер, использовать через API, расширять пользовательскими узлами и управлять из командной строки. Большинство задач с API состоит из двух шагов: запустить ComfyUI где-либо, а затем выполнять рабочие процессы на нём из вашего приложения.
