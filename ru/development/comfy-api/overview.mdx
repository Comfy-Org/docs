Публичный API для запуска ComfyUI без интерфейса развивался со временем. Для новых интеграций используйте [Comfy API v2](/api-reference/v2/overview). Он поддерживается в ComfyUI с открытым исходным кодом через [API Proxy](/ru/development/comfyui-server/api-proxy), в Comfy Cloud и в [развёртываниях Comfy API на платформе Developer Platform](/ru/development/serverless/overview). К более старым версиям относится [облачный API v1](/ru/development/cloud/overview), который устарел.
