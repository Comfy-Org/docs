## Использование спецификации

Спецификацию OpenAPI можно использовать для:

- **Генерации клиентских библиотек** на любом языке с помощью инструментов вроде [OpenAPI Generator](https://openapi-generator.tech/)
- **Импорта в API-инструменты** такие как Postman, Insomnia или Paw
- **Генерации документации** с помощью инструментов вроде Redoc или Swagger UI
- **Проверки запросов** в вашем приложении

## Аутентификация

Все запросы к API требуют API-ключ, передаваемый в заголовке `X-API-Key`.

### Получение API-ключа

Пошаговые инструкции со скриншотами приведены в разделе [Получение API-ключа](/ru/development/api-development/getting-an-api-key).

### Использование API-ключа

```yaml
X-API-Key: your-api-key
```

## WebSocket-соединение

Для обновлений в реальном времени подключайтесь к конечной точке WebSocket:

```
wss://cloud.comfy.org/ws?clientId={uuid}&token={api_key}
```

Типы сообщений и их обработка описаны в [справочнике по Cloud API](/ru/development/cloud/api-reference#websocket-для-прогресса-в-реальном-времени).
