## Обзор

Когда ComfyUI сохраняет выходной файл, он может сохранить рабочий процесс, создавший этот файл, внутри самого файла.

Это можно представить как сохранение сгенерированного изображения вместе с рецептом его создания. Изображение является результатом, а встроенный рабочий процесс описывает шаги, использованные для его создания.

Встроенные метаданные рабочего процесса позволяют вам:

- Снова открыть сгенерированный файл в ComfyUI и восстановить его рабочий процесс.
- Поделиться сгенерированным файлом вместе с рабочим процессом, использованным для его создания.
- Просмотреть настройки генерации в автоматизированном рабочем процессе.
- Создавать инструменты, которые читают метаданные рабочего процесса ComfyUI из выходных файлов.

Метаданные хранятся внутри формата файла. Они не изменяют видимое содержимое изображения или видео.

## Встроенные поля

ComfyUI обычно хранит два поля JSON:

| Поле | Описание |
| --- | --- |
| `workflow` | Полный граф рабочего процесса, включая узлы, связи и сведения о расположении. |
| `prompt` | Промпт API, используемый для выполнения рабочего процесса. Он содержит узлы и входы, необходимые для выполнения. |

Упрощённый пример выглядит так:

```json
{
  "workflow": {
    "nodes": [],
    "links": []
  },
  "prompt": {
    "3": {
      "class_type": "KSampler",
      "inputs": {}
    }
  }
}
```

Фактическое содержимое зависит от рабочего процесса и версии ComfyUI. Пользовательские узлы также могут добавлять поля через `extra_pnginfo`.

Эти два поля служат разным целям. `workflow` предназначено для восстановления рабочего процесса в интерфейсе. `prompt` представляет собой ориентированное на выполнение представление, используемое при отправке рабочего процесса на сервер ComfyUI. Файл может содержать одно поле без другого.

## Поддерживаемые форматы

Встроенные узлы сохранения встраивают метаданные в следующие выходные форматы:

| Выходной формат | Расположение метаданных |
| --- | --- |
| PNG | Чанки `tEXt` PNG |
| Анимированный PNG | Текстовые метаданные PNG |
| Анимированный WebP | Теги EXIF |
| MP4 | Теги метаданных контейнера |
| WebM | Теги метаданных контейнера |
| `.latent` | Метаданные Safetensors |
| `.safetensors` | Метаданные Safetensors, если файл записан узлом, который включает метаданные рабочего процесса |

Точная поддержка метаданных зависит от узла сохранения и пути записи файла. Файл, который был перекодирован другим приложением, может уже не содержать метаданных.

Файлы анимированного WebP хранят значения в тегах EXIF. Теги содержат строки, например `workflow:{JSON}` и `prompt:{JSON}`. Это отличается от MP4 и WebM, которые хранят значения как теги метаданных контейнера.

## Как ComfyUI записывает метаданные

Встроенные узлы вывода получают промпт API и дополнительную информацию о рабочем процессе, когда ComfyUI выполняет рабочий процесс. Если сохранение метаданных не отключено, узел сохранения сериализует эти значения как JSON и записывает их в выходной файл.

Для вывода PNG значения записываются как текстовые записи. Стандартные имена полей: `prompt` и `workflow`.

Метаданные не являются отдельным sidecar-файлом. Они записываются в выходной файл во время операции сохранения. Это означает, что копирование файла также копирует встроенный рабочий процесс, но любая операция, перезаписывающая файл, может удалить или заменить метаданные.

Чтобы отключить метаданные при запуске ComfyUI, используйте:

```bash
python main.py --disable-metadata
```

В ComfyUI Desktop откройте **Настройки** > **Настройки сервера** и включите **Disable saving prompt metadata in files.**

Файлы, созданные при включённой этой опции, нельзя использовать для восстановления рабочего процесса из встроенных метаданных.

## Как ComfyUI читает метаданные

Чтобы восстановить рабочий процесс в интерфейсе ComfyUI, перетащите сгенерированный файл на холст. Также можно открыть файл через **File** > **Open**.

Если файл содержит и `workflow`, и `prompt`, ComfyUI использует встроенный `workflow` для пересборки холста. Если файл не содержит рабочего процесса, ComfyUI обрабатывает поддерживаемые медиафайлы как обычные входные медиаданные.

При создании интеграции проверяйте наличие поля, прежде чем его разбирать. Метаданные могут отсутствовать, если файл был создан с `--disable-metadata`, если узел сохранения не получил информацию о рабочем процессе или если другое приложение перекодировало файл.

О том, как просматривать и редактировать встроенные рабочие процессы в браузере, см. [ComfyUI Embedded Workflow Editor](https://comfyui-embedded-workflow-editor.vercel.app/).

## Ограничения

- Встроенные метаданные не являются цифровой подписью. Они не доказывают, кто создал или изменил файл.
- Рабочий процесс не включает файлы моделей, входные ресурсы или пакеты пользовательских узлов, от которых он зависит.
- Перемещение или переименование модели, входного ресурса или пользовательского узла может помешать восстановленному рабочему процессу запуститься.
- Редакторы изображений и видео могут удалить метаданные при повторном кодировании файла.
- Файлы, созданные с `--disable-metadata`, не содержат стандартных метаданных рабочего процесса ComfyUI.
- Считайте встроенные метаданные необязательными и недоверенными входными данными. Проверьте, что значение является допустимым JSON, перед его использованием, и не предполагайте, что рабочий процесс содержит все модели или пользовательские узлы, необходимые для его запуска.
