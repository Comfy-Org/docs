Запустите полный рабочий процесс из кода и сохраните его результат в файл `first-result.png`. Этот пример создаёт **сплошное синее изображение 512 × 512** с помощью двух встроенных узлов. Он проверяет аутентификацию, выполнение рабочего процесса и скачивание результата, не требуя модели, входного изображения или пользовательских узлов.

Чтобы сгенерировать изображение, обратившись к размещённой модели напрямую, начните с [краткого руководства Comfy Router](/ru/development/comfy-router/quickstart).

Этот пример выполняется в Comfy Cloud. О других вариантах размещения, включая развёртывания Comfy API и самостоятельный хостинг, см. [Развёртывание ComfyUI](/ru/development/deploy/overview).

## Перед началом работы

- [Comfy API-ключ](/ru/development/api-development/getting-an-api-key).
- [Платная подписка Comfy Cloud](/ru/development/deploy/cloud). Доступ к API рабочих процессов Cloud не включён в бесплатный тариф.
- Python 3.10 или новее, либо Node.js 22.18 или новее для примера на TypeScript.

В этом руководстве используется Comfy Cloud: цель по умолчанию для SDK. Если вы ранее задавали `COMFY_BASE_URL`, сбросьте его, чтобы использовать Cloud. Для существующего развёртывания Comfy API или самостоятельно размещённого экземпляра см. [Выбор базового URL](/ru/development/api-development/sdks#choosing-a-base-url).

## 1. Скачать пример

Создайте папку для примера. Скачайте в неё [workflow_api.json](/ru/files/api-first-result/workflow_api.json) и скрипт для вашего языка:

- [Python: first_workflow.py](/ru/files/api-first-result/first_workflow.py)
- [TypeScript: first_workflow.mts](/ru/files/api-first-result/first_workflow.mts)

Рабочий процесс уже представлен в формате API. Узел `"1"` создаёт синее изображение, а узел `"2"` сохраняет его. Скрипты считывают выходы именно из этого узла SaveImage, поэтому искать или изменять ID узла не требуется.

## 2. Установить SDK и задать ключ

Откройте терминал в папке, куда вы сохранили файлы.

<CodeGroup>
```bash Python
python -m venv .venv
source .venv/bin/activate
python -m pip install comfy-sdk
```

```bash TypeScript
npm init -y
npm install @comfyorg/sdk
```
</CodeGroup>

В Windows активируйте окружение Python командой `.venv\Scripts\Activate.ps1` в PowerShell.

Задайте ключ в том же терминале:

<CodeGroup>
```bash macOS / Linux
export COMFY_API_KEY="comfyui-your-key"
```

```powershell Windows PowerShell
$env:COMFY_API_KEY = "comfyui-your-key"
```
</CodeGroup>

Храните API-ключ в окружении сервера. Не вставляйте его в код, выполняемый в браузере, и не добавляйте в систему контроля версий.

## 3. Запустить и просмотреть результат

<CodeGroup>
```bash Python
python first_workflow.py
```

```bash TypeScript
node first_workflow.mts
```
</CodeGroup>

Скрипт отправляет рабочий процесс, ждёт его завершения и скачивает изображение. Когда он выведет `Saved` и путь к файлу, откройте `first-result.png` по этому пути. Вы должны увидеть сплошной синий квадрат. Повторный запуск примера заменит этот локальный файл.

<Note>
  Это проверка соединения рабочего процесса. Здесь не используется генеративная модель. Те же шаги отправки, ожидания и скачивания работают и с вашими собственными рабочими процессами генерации.
</Note>

### Если запрос завершился ошибкой

- **Отсутствует ключ или нет авторизации:** проверьте, что `COMFY_API_KEY` задан в терминале, где запускается скрипт, и содержит действующий ключ.
- **Ошибка доступа или кредитов:** проверьте подписку Cloud и доступные кредиты, прежде чем повторить попытку.
- **Файл рабочего процесса не найден:** оставьте `workflow_api.json` рядом со скачанным скриптом.
- **Неожиданная конечная точка:** проверьте `COMFY_BASE_URL`. Для этого примера Cloud её нужно сбросить.
- **Задача завершается ошибкой на развёртывании Comfy API:** её ошибка может содержать категорию с указанием причины. См. [Категории ошибок](/ru/development/api-development/sdks#failure-categories).

Об обработке ошибок и о ходе выполнения задачи см. в [руководстве по SDK](/ru/development/api-development/sdks).

## 4. Запустить собственный рабочий процесс генерации

Создайте или выберите рабочий процесс в редакторе ComfyUI, успешно запустите его там и [экспортируйте в формате API](/ru/development/api-development/workflow-api-format). Замените `workflow_api.json` на свой экспорт и обновите `get_outputs("2")` в Python или `getOutputs("2")` в TypeScript, указав ID узла SaveImage вашего рабочего процесса. Проверьте, что в целевой среде есть модели и пользовательские узлы, которые использует ваш рабочий процесс.

Чтобы разместить рабочие процессы со своими моделями и пользовательскими узлами, следуйте [краткому руководству по Comfy API](/ru/development/serverless/quickstart). Чтобы изменить входы рабочего процесса, загрузить файлы или отслеживать ход выполнения, перейдите к разделу [Comfy SDK](/ru/development/api-development/sdks).
