API-ключ: это ваши учётные данные для доступа к сервисам Comfy Platform, в том числе:

- [Cloud API](/ru/development/cloud/overview): программный вызов эндпоинтов Comfy Cloud
- [Partner Node API Integration](/ru/development/comfyui-server/api-key-integration): использование платных партнёрских узлов в локальных рабочих процессах
- [Agent Tools / MCP](/ru/agent-tools): подключение к Comfy через MCP
- [Login to ComfyUI locally](/interface/user#logging-in-with-an-api-key): вход с помощью API-ключа вместо электронной почты

## Управление API-ключами

Просматривать все свои API-ключи и управлять ими можно на [platform.comfy.org](https://platform.comfy.org) после входа.

- **Просмотр существующих ключей**: отображаются имя и дата создания каждого ключа
- **Удаление ключа**: если ключ скомпрометирован или больше не нужен, удалите его немедленно
- **Создание дополнительных ключей**: у вас может быть несколько API-ключей для разных приложений

<Warning>
  API-ключ отображается только один раз при создании. Сразу сохраните его в надёжном месте. Если вы потеряли ключ, удалите его и создайте новый.
</Warning>

## Использование API-ключа

Получив API-ключ, вы можете:

1. **Войти в локальный ComfyUI**: перейдите в **Настройки → Пользователь** и выберите вход «Comfy API-ключ»
2. **Вызывать API партнёрских узлов**: указывайте ключ в `extra_data.api_key_comfy_org` при отправке рабочих процессов
3. **Использовать Cloud API**: указывайте ключ в заголовках запросов к эндпоинтам Cloud API

В целях безопасности никогда не передавайте свой API-ключ другим и не добавляйте его в систему контроля версий.
