Начиная с [PR #8041](https://github.com/Comfy-Org/ComfyUI/pull/8041), ComfyUI поддерживает прямое использование встроенных платных Партнёрских узлов через API-ключ вашей учётной записи ComfyUI, без необходимости в конкретном интерфейсе фронтенда (можно даже работать без фронтенда).

Это значит, что вы можете создавать рабочие процессы, объединяющие:
- локальные open-source модели
- инструменты от сообщества пользовательских узлов
- популярные платные модели

Затем можно запустить всё вместе, просто отправив промпт в API веб-сервера Comfy: он возьмёт на себя всю оркестрацию.

Это полезно пользователям, которые хотят использовать Comfy как бэкенд-сервис, через командную строку, с собственным фронтендом и т. д.

## Предварительные требования

Для вызова платных Партнёрских узлов с помощью API-ключа аккаунта ComfyUI требуется:
- [API-ключ аккаунта ComfyUI](/ru/development/api-development/getting-an-api-key)
- Достаточно кредитов на аккаунте

<Note>
  **Важно:** Эта страница описывает **API-ключ аккаунта ComfyUI**, который используется для доступа к платным Партнёрским узлам в рабочих процессах. Если вместо этого вы хотите опубликовать пользовательские узлы в реестре, см. [Публикация узлов](/ru/registry/publishing).
</Note>

Чтобы использовать API-ключ аккаунта ComfyUI для вызова платных Партнёрских узлов, сначала зарегистрируйте аккаунт на [ComfyUI Platform](https://platform.comfy.org/login) и [создайте API-ключ](/ru/development/api-development/getting-an-api-key).



Убедитесь, что на вашем аккаунте ComfyUI достаточно кредитов для тестирования соответствующих функций.

<Card title="Кредиты" icon="link" href="/ru/interface/credits">
О том, как купить кредиты для аккаунта, см. в разделе «Кредиты».
</Card>

## Пример на Python

Ниже приведён пример отправки рабочего процесса, содержащего партнёрские узлы, в API ComfyUI с помощью кода на Python:

```python
"""Использование партнёрских узлов при запуске ComfyUI без графического интерфейса или с альтернативным фронтендом

Вы можете выполнить рабочий процесс ComfyUI, содержащий партнёрские узлы, добавив API-ключ в промпт.
API-ключ следует добавить в поле `extra_data` полезной нагрузки.
Ниже показан пример того, как это сделать.

Подробнее:

- Обзор партнёрских узлов: https://docs.comfy.org/tutorials/partner-nodes/overview
- Чтобы сгенерировать API-ключ, войдите здесь: https://platform.comfy.org/login
"""

import json
from urllib import request

SERVER_URL = "http://127.0.0.1:8188"

# У нас есть промпт/задача (рабочий процесс в формате "API"), содержащий партнёрские узлы.
workflow_with_api_nodes = """{
  "11": {
    "inputs": {
      "prompt": "A dreamy, surreal half-body portrait of a young woman meditating. She has a short, straight bob haircut dyed in pastel pink, with soft bangs covering her forehead. Her eyes are gently closed, and her hands are raised in a calm, open-palmed meditative pose, fingers slightly curved, as if levitating or in deep concentration. She wears a colorful dress made of patchwork-like pastel tiles, featuring clouds, stars, and rainbows. Around her float translucent, iridescent soap bubbles reflecting the rainbow hues. The background is a fantastical sky filled with cotton-candy clouds and vivid rainbow waves, giving the entire scene a magical, dreamlike atmosphere. Emphasis on youthful serenity, whimsical ambiance, and vibrant soft lighting.",
      "prompt_upsampling": false,
      "seed": 589991183902375,
      "aspect_ratio": "1:1",
      "raw": false,
      "image_prompt_strength": 0.4000000000000001,
      "image_prompt": [
        "14",
        0
      ]
    },
    "class_type": "FluxProUltraImageNode",
    "_meta": {
      "title": "Flux 1.1 [pro] Ultra Image"
    }
  },
  "12": {
    "inputs": {
      "filename_prefix": "ComfyUI",
      "images": [
        "11",
        0
      ]
    },
    "class_type": "SaveImage",
    "_meta": {
      "title": "Save Image"
    }
  },
  "14": {
    "inputs": {
      "image": "example.png"
    },
    "class_type": "LoadImage",
    "_meta": {
      "title": "Load Image"
    }
  }
}"""


prompt = json.loads(workflow_with_api_nodes)
payload = {
    "prompt": prompt,
    # Добавьте `api_key_comfy_org` в полезную нагрузку.
    # Если вы обслуживаете несколько клиентов, сначала можно получить ключ у связанного пользователя.
    "extra_data": {
        "api_key_comfy_org": "comfyui-87d01e28d*******************************************************"  # замените на фактический ключ
    },
}
data = json.dumps(payload).encode("utf-8")
req = request.Request(f"{SERVER_URL}/prompt", data=data)
request.urlopen(req)

```
