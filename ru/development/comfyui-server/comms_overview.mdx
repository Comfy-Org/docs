По умолчанию ComfyUI работает на вашей машине как HTTP-сервер. К нему можно обращаться программно, чтобы отправлять рабочие процессы, загружать файлы, скачивать выходы и отслеживать прогресс, не открывая браузер.

## Запустить сервер

При запуске ComfyUI автоматически запускается HTTP-сервер по адресу `http://127.0.0.1:8188`.

Чтобы запустить ComfyUI как сервер без графического интерфейса (без браузера):

<CodeGroup>
```bash
# Запуск без открытия браузера
python main.py --disable-auto-launch
```

```bash
# Указать пользовательский порт
python main.py --port 8288
```

```bash
# Прослушивать все сетевые интерфейсы (для удалённого доступа)
python main.py --listen 0.0.0.0
```
</CodeGroup>

<Tip>
  Полный список флагов запуска можно получить, выполнив `python main.py --help`, или см. [Справочник по флагам запуска](/ru/development/comfyui-server/startup-flags).
</Tip>

## Использовать партнёрские узлы

Если ваш рабочий процесс содержит платные партнёрские узлы, вы можете указать свой API-ключ в payload. Подробности приведены в руководстве [Partner Node API Integration](/ru/development/comfyui-server/api-key-integration).

## Как работает сервер

Сервер Comfy работает на основе [фреймворка aiohttp](https://docs.aiohttp.org/), который, в свою очередь, использует [asyncio](https://pypi.org/project/asyncio/).

Сообщения от сервера клиенту отправляются через сообщения сокета с помощью метода `send_sync` сервера, который является экземпляром `PromptServer` (определён в `server.py`). Они обрабатываются обработчиком событий сокета, зарегистрированным в `api.js`. См. [сообщения](/ru/development/comfyui-server/comms_messages).

Сообщения от клиента серверу отправляются методом `api.fetchApi()`, определённым в `api.js`, и обрабатываются HTTP-маршрутами, определёнными сервером. См. [маршруты](/ru/development/comfyui-server/comms_routes).

<Tip>
  Клиент отправляет весь рабочий процесс (вместе со значениями виджетов и всем остальным), когда вы ставите запрос в очередь.
  Сервер не получает никаких изменений, которые вы вносите после отправки запроса в очередь.
  Если вы хотите изменить поведение сервера во время выполнения, вам понадобятся маршруты.
</Tip>
