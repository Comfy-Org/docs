ComfyUI принимает аргументы командной строки при запуске с `python main.py`. На этой странице описаны все флаги, определённые в [`comfy/cli_args.py`](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy/cli_args.py).

<Note>
  Пользователи **Windows Portable** могут добавлять флаги в `.bat`-файлы запуска (например, `run_nvidia_gpu.bat`). Подробности см. в [руководстве по Windows Portable](/ru/installation/comfyui_portable_windows).
</Note>

Выполните `python main.py --help` в каталоге ComfyUI, чтобы получить встроенный текст справки. При необходимости объедините несколько флагов:

```bash
python main.py --listen 0.0.0.0 --port 8288 --disable-auto-launch --lowvram
```

## Сеть и сервер

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--listen` `[IP]` | `127.0.0.1` | IP-адрес для прослушивания. Поддерживается список через запятую (например, `127.2.2.2,127.3.3.3`). Если указан без значения, по умолчанию используются `0.0.0.0,::` (все интерфейсы IPv4 и IPv6). |
| `--port` | `8188` | Порт для прослушивания. |
| `--tls-keyfile` `PATH` | нет | Путь к файлу ключа TLS (SSL). Включает HTTPS. Требует `--tls-certfile`. |
| `--tls-certfile` `PATH` | нет | Путь к файлу сертификата TLS (SSL). Включает HTTPS. Требует `--tls-keyfile`. |
| `--enable-cors-header` `[ORIGIN]` | disabled | Включить CORS. Необязательный источник или `*` для всех источников, если значение не указано. |
| `--max-upload-size` | `100` | Максимальный размер загружаемого файла в МБ. |
| `--enable-compress-response-body` | disabled | Включить сжатие тела HTTP-ответа. |

<CodeGroup>
```bash
# Прослушивать все интерфейсы (доступ по локальной сети)
python main.py --listen

# Прослушивать конкретный IP
python main.py --listen 0.0.0.0

# Пользовательский порт с HTTPS
python main.py --port 8443 --tls-keyfile key.pem --tls-certfile cert.pem
```
</CodeGroup>

|------|---------|-------------|

| `--models-directory` `PATH` | `ComfyUI root/models` | Каталог моделей. Переопределяет папку `models` в `--base-directory`. |
| `--extra-model-paths-config` `PATH` | — | Загрузить один или несколько файлов `extra_model_paths.yaml`. Можно указать несколько раз. |
| `--output-directory` `PATH` | — | Выходной каталог. Переопределяет `--base-directory`. |
| `--temp-directory` `PATH` | — | Временный каталог. Переопределяет `--base-directory`. |
| `--input-directory` `PATH` | — | Входной каталог. Переопределяет `--base-directory`. |
| `--previews-directory` `PATH` | — | Каталог для превью сгенерированных ресурсов. Переопределяет `--base-directory`. |
| `--user-directory` `PATH` | — | Каталог пользователя (абсолютный путь). Переопределяет `--base-directory`. Путь должен существовать и быть доступным для чтения. |

## Запуск и браузер

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--auto-launch` | отключено | Автоматически открывать ComfyUI в браузере по умолчанию при запуске. |
| `--disable-auto-launch` | отключено | Отключить автоматический запуск браузера. |
| `--windows-standalone-build` | отключено | Режим удобства для портативной сборки Windows. Включает автозапуск при старте (эквивалентно `--auto-launch`) и активирует систему ассетов. |

<Note>
  `--windows-standalone-build` устанавливает для `auto_launch` значение `true` и включает систему ассетов. `--disable-auto-launch` переопределяет запуск браузера, а `--disable-assets` переопределяет систему ассетов. Чтобы запустить сервер без открытия браузера, используйте `--disable-auto-launch`.
</Note>

```bash
# Запустить сервер без открытия браузера
python main.py --disable-auto-launch
```

## Устройства и CUDA

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--cuda-device` `DEVICE_ID` | — | Идентификаторы устройств CUDA для использования через запятую (например, `0` или `0,1`) или `all`, чтобы оставить все видимые в данный момент устройства. Остальные устройства скрываются. |
| `--default-device` `ID` | — | Идентификатор устройства по умолчанию. Все остальные устройства остаются видимыми. |
| `--cuda-malloc` | Авто (torch 2.0+) | Включает cudaMallocAsync. Несовместим с `--disable-cuda-malloc`. |
| `--disable-cuda-malloc` | — | Отключает cudaMallocAsync. Несовместим с `--cuda-malloc`. |
| `--oneapi-device-selector` `STRING` | — | Строка селектора устройств oneAPI для устройств Intel. |

<Note>
  В Windows ComfyUI по умолчанию использует только GPU 0. Чтобы восстановить все GPU, передайте `--cuda-device all`.
</Note>

## Точность и вывод

<Note>
  Флаги в группах **Global**, **UNET**, **VAE** и **Text Encoder** ниже являются взаимоисключающими внутри каждой группы. Одновременно можно использовать только один флаг из группы.
</Note>

### Глобальный формат с плавающей запятой

| Флаг | Описание |
|------|-------------|
| `--force-fp32` | Принудительно использовать fp32 глобально. Сообщите, если это улучшает производительность GPU. |
| `--force-fp16` | Принудительно использовать fp16 глобально. Также задаёт `--fp16-unet`. |

### Точность UNET

| Флаг | Описание |
|------|-------------|
| `--fp32-unet` | Запускать диффузионную модель в fp32. |
| `--fp64-unet` | Запускать диффузионную модель в fp64. |
| `--bf16-unet` | Запускать диффузионную модель в bf16. |
| `--fp16-unet` | Запускать диффузионную модель в fp16. |
| `--fp8_e4m3fn-unet` | Хранить веса UNet в fp8 (e4m3fn). |
| `--fp8_e5m2-unet` | Хранить веса UNet в fp8 (e5m2). |
| `--fp8_e8m0fnu-unet` | Хранить веса UNet в fp8 (e8m0fnu). |

Каждый суффикс флага FP8 обозначает раскладку 8-битного числа с плавающей запятой из отраслевой спецификации FP8 (ONNX / OCP):
- **e4m3fn**: 4 бита экспоненты, 3 бита мантиссы. Хороший баланс точности и диапазона для весов моделей на GPU NVIDIA Ada Lovelace и новее.
- **e5m2**: 5 бит экспоненты, 2 бита мантиссы. Шире динамический диапазон, но точность ниже, чем у e4m3fn. Полезен, когда величины весов сильно различаются.
- **e8m0fnu**: 8 бит экспоненты, 0 бит мантиссы. Максимальный динамический диапазон без дробной точности. Обычно используется как блочный масштабирующий коэффициент (только степени двойки).

### Точность VAE

| Флаг | Описание |
|------|-------------|
| `--fp16-vae` | Запускать VAE в fp16. Может приводить к чёрным изображениям. |
| `--fp32-vae` | Запускать VAE в полной точности fp32. |
| `--bf16-vae` | Запускать VAE в bf16. |
| `--cpu-vae` | Запускать VAE на CPU (не является взаимоисключающим с флагами точности VAE). |

### Точность текстового кодировщика

| Флаг | Описание |
|------|-------------|
| `--fp8_e4m3fn-text-enc` | Хранить веса текстового кодировщика в fp8 (e4m3fn). |
| `--fp8_e5m2-text-enc` | Хранить веса текстового кодировщика в fp8 (e5m2). |
| `--fp16-text-enc` | Хранить веса текстового кодировщика в fp16. |
| `--fp32-text-enc` | Хранить веса текстового кодировщика в fp32. |
| `--bf16-text-enc` | Хранить веса текстового кодировщика в bf16. |

Описание каждого суффикса формата FP8 см. в разделе [Точность UNET](#точность-unet).

### Прочие параметры вывода

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--fp16-intermediates` | disabled | Экспериментально: использовать fp16 для промежуточных тензоров между узлами вместо fp32. |
| `--force-channels-last` | disabled | Принудительно использовать формат памяти channels-last при выводе. |
| `--supports-fp8-compute` | disabled | Вести себя так, будто устройство поддерживает вычисления fp8. |
| `--enable-triton-backend` | disabled | Включить бэкенд Triton в comfy-kitchen. По умолчанию при запуске отключён. |
| `--disable-triton-backend` | disabled | Принудительно отключить бэкенд Triton в comfy-kitchen, переопределяя `--enable-triton-backend`. |

## Кэш

<Note>
  Флаги режима кэширования взаимоисключающие. Следует использовать только один из `--cache-ram`, `--cache-classic`, `--high-ram`, `--cache-lru` или `--cache-none`.
</Note>

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--cache-ram` `[GB] [GB]` | включён (режим по умолчанию) | Кэширование с учётом давления на RAM. Первое значение: порог активного кэша в GB. Необязательное второе значение: порог неактивного кэша/закрепления в GB. Если значения не указаны: активный = 10% системной RAM (мин. 2 GB, макс. 10 GB); неактивный = 100% системной RAM (макс. 128 GB). Принимает не более двух значений. |
| `--cache-classic` | не задано | Использовать старый агрессивный стиль кэширования. |
| `--high-ram` | отключён | Может немного повысить производительность в системах с большим объёмом RAM или там, где предпочтительнее использовать файл подкачки, а не перезагружать модели. Также включает классическое кэширование. |
| `--cache-lru` `N` | `0` (отключён) | LRU-кэширование с максимумом N кэшируемых результатов узлов. Жёсткого верхнего предела нет; ограничено доступной RAM/VRAM. Может использовать больше RAM/VRAM. |
| `--cache-none` | не задано | Снижает использование RAM/VRAM; повторно выполняет каждый узел при каждом запуске. |
| `--force-output-rerun` | отключён | Повторно выполняет выходные узлы при каждом запуске, даже при попадании в кэш, чтобы они снова записывали свои файлы. Их входы повторно используются из кэша, пока кэшированные результаты всё ещё доступны, поэтому модели и латенты не пересчитываются. API-узлы исключены, поскольку повторный запуск приводит к повторному платному внешнему вызову, а выходные узлы, созданные кэшированным раскрывающим узлом, не запускаются повторно. Для многопользовательских серверов, которые удаляют выходные файлы после каждой задачи. |

<Note>
  ComfyUI повторно использует кэшированные результаты узлов между запусками в рамках одной сессии, что и ускоряет повторные запуски. Используйте `--cache-none`, если хотите, чтобы каждый запуск начинался с чистого кэша, например при отладке рабочего процесса или исключении повторного использования кэша между запусками. Каждый узел выполняется повторно, поэтому генерация занимает больше времени. Это флаг запуска, поэтому для его применения перезапустите ComfyUI.
</Note>

## Внимание

<Note>
  Флаги методов cross-attention взаимоисключающие. Split- и quad-attention игнорируются при использовании xformers.
</Note>

| Флаг | Описание |
|------|-------------|
| `--use-split-cross-attention` | Использовать оптимизацию split cross attention. |
| `--use-quad-cross-attention` | Использовать субквадратичную оптимизацию cross attention. |
| `--use-pytorch-cross-attention` | Использовать cross attention из PyTorch 2.0. |
| `--use-sage-attention` | Использовать Sage attention. |
| `--use-flash-attention` | Использовать FlashAttention. |
| `--use-ck-attention` | Использовать Comfy Kitchen attention. Требуется аппаратная поддержка его ядер INT8. |

| `--force-upcast-attention` | Принудительно включить upcasting для attention. Сообщите, если это исправляет чёрные изображения. Взаимоисключающий с `--dont-upcast-attention`. |
| `--dont-upcast-attention` | Отключить весь upcasting для attention. Только для отладки. |

## VRAM и память

Асинхронное выгружение весов включено по умолчанию на GPU Nvidia и AMD, а динамическая VRAM включается автоматически там, где она поддерживается. Флаги ниже переопределяют эти значения по умолчанию.

<Note>
  Флаги режима VRAM (`--gpu-only`, `--highvram`, `--lowvram`, `--novram`, `--cpu`) взаимоисключающие.
</Note>

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--gpu-only` | — | Хранить и выполнять всё на GPU (текстовые энкодеры, CLIP и т. д.). |
| `--highvram` | — | Держать модели в памяти GPU, а не выгружать их в CPU после использования. |
| `--lowvram` | — | Не действует, когда включена динамическая VRAM. В остальных случаях выполняет текстовые энкодеры на CPU. |
| `--novram` | — | Минимальное использование VRAM, когда `--lowvram` недостаточно. |
| `--cpu` | — | Использовать CPU для всего (медленно). |
| `--reserve-vram` `GB` | Зависит от ОС | Объём VRAM в ГБ, резервируемый для ОС и другого программного обеспечения. |
| `--vram-headroom` `GB` | `0` | Дополнительный запас VRAM в ГБ, который динамическая VRAM держит свободным сверх запаса по умолчанию. ComfyUI старается держать этот объём VRAM полностью свободным и неиспользуемым, учитывая в том числе VRAM, занятую другими приложениями. |
| `--disable-nvml-pressure` | отключён | Использовать CUDA вместо NVML для сообщения о давлении на память динамической VRAM. |
| `--async-offload` `[NUM_STREAMS]` | включён на Nvidia и AMD | Асинхронное выгружение весов. Необязательное число потоков (по умолчанию: 2). |
| `--disable-async-offload` | — | Отключить асинхронное выгружение весов. |
| `--disable-dynamic-vram` | — | Отключить динамическую VRAM; использовать загрузку моделей на основе оценки. |
| `--enable-dynamic-vram` | авто на Nvidia, ROCm 7.14+ | Включить динамическую VRAM в системах, где она не включена по умолчанию. |
| `--fast-disk` | ложь | Принудительно использовать динамическую загрузку и выгружение с диска вместо незакреплённой RAM. Полезно с быстрым NVMe. Если не задан ни этот флаг, ни `--disable-fast-disk`, загрузка и выгружение с диска включаются автоматически, если все файлы моделей находятся на хранилище, определённом как быстрое. |
| `--disable-fast-disk` | отключён | Отключить динамическую загрузку и выгружение с диска, чтобы вместо них использовалась незакреплённая RAM. Переопределяет `--fast-disk` и автоматическую детекцию. |
| `--disable-cuda-graphs` | отключён | Отключить графы CUDA. |
| `--disable-comfy-compiler` | отключён | Отключить компилятор моделей Comfy, включая его подфункцию графов CUDA. |
| `--assert-graph-breaks` | отключён | Завершаться с ошибкой при разрывах графа компилятора моделей Comfy. |
| `--force-non-blocking` | отключён | Принудительно использовать неблокирующие операции с тензорами. Может помочь в системах без Nvidia; может нарушить работу некоторых рабочих процессов. |
| `--disable-smart-memory` | отключён | Агрессивно выгружать в RAM вместо хранения моделей в VRAM. |
| `--disable-pinned-memory` | отключён | Отключить использование закреплённой памяти. |
| `--mmap-torch-files` | отключён | Использовать mmap при загрузке файлов ckpt/pt. |
| `--disable-mmap` | отключён | Не использовать mmap при загрузке safetensors. |

## Производительность и отладка

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--fast` `[OPT...]` | отключено | Включить экспериментальные оптимизации, которые могут повлиять на качество или стабильность. Один `--fast` включает все. Конкретные параметры: `fp16_accumulation`, `fp8_matrix_mult`, `cublas_ops`, `autotune`. |
| `--deterministic` | отключено | Использовать более медленные детерминированные алгоритмы PyTorch, где это возможно. Не гарантирует одинаковых изображений во всех случаях. |
| `--default-hashing-function` | `sha256` | Хеш-функция для сравнения дубликатов по имени файла или содержимому. Варианты: `md5`, `sha1`, `sha256`, `sha512`. |
| `--debug-hang` | отключено | Включить вывод стеков вызовов при нажатии Ctrl-C для отладки зависаний. |

```bash
# Включить все быстрые оптимизации (экспериментальные)
python main.py --fast

# Включить только определённые оптимизации
python main.py --fast fp16_accumulation cublas_ops
```

## ComfyUI Manager

Инструкции по установке см. в разделе [Установка ComfyUI-Manager](/ru/manager/install).

| Флаг | Описание |
|------|-------------|
| `--enable-manager` | Включить ComfyUI-Manager. |
| `--enable-agent` | Включить функцию агента ComfyUI. |
| `--disable-manager-ui` | Отключить только UI и эндпоинты Manager. Фоновые задачи (запланированные установки и т. п.) продолжают выполняться. Требует `--enable-manager`. |
| `--enable-manager-legacy-ui` | Использовать классический UI Manager. Подразумевает `--enable-manager`. Взаимоисключающий с `--disable-manager-ui`. |

## Пользовательские узлы и API-узлы

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--disable-all-custom-nodes` | отключено | Отключает загрузку всех пользовательских узлов. |
| `--whitelist-custom-nodes` `FOLDER...` | — | Папки пользовательских узлов, которые нужно загружать, даже если задан `--disable-all-custom-nodes`. |
| `--disabled-nodes-config` `PATH` | — | Путь к YAML-файлу со списком ID узлов, которые нужно отключить. Файл должен содержать список `disabled_nodes` из строк с ID узлов. |
| `--disable-partner-nodes` | отключено | Отключает загрузку Партнёрских узлов (платных API-узлов). Доступ фронтенда к интернету сохраняется. |
| `--offline` | отключено | Запрещает фронтенду обращаться к интернету, добавляя строгую Content-Security-Policy. Также отключает Партнёрские узлы. |
| `--disable-api-nodes` | отключено | Устаревший синоним `--offline`. Используйте `--offline` или `--disable-partner-nodes`, чтобы отключить только Партнёрские узлы. |
| `--disable-metadata` | отключено | Отключает сохранение метаданных промпта в выходных файлах. |

<Note>
  `--offline` также меняет то, что разрешено загружать браузеру. Флаг добавляет Content-Security-Policy, который удерживает страницу на ресурсах, отдаваемых самим ComfyUI, поэтому изображения, шрифты, медиа, фреймы и сетевые запросы с других источников блокируются, а Партнёрские узлы (API-узлы) вообще не регистрируются. Если после перезапуска пропал предпросмотр или миниатюра, которая обычно загружается, проверьте аргументы запуска на наличие этого флага, прежде чем искать проблему в узле. `--disable-partner-nodes` только останавливает загрузку Партнёрских узлов и оставляет остальной доступ фронтенда к интернету без изменений.
</Note>

```bash
# Устранение неполадок с пользовательскими узлами
python main.py --disable-all-custom-nodes

# Разрешить только определённые пользовательские узлы
python main.py --disable-all-custom-nodes --whitelist-custom-nodes ComfyUI-Manager
```

## Фронтенд и API

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--front-end-version` | `comfyanonymous/ComfyUI@latest` | Версия фронтенда в формате `[owner]/[repo]@[version]`. Для скачивания с релизов GitHub требуется интернет. Версия может быть `latest` или semver (например, `1.0.0`). |
| `--front-end-root` `PATH` | Не задано | Локальный путь в файловой системе к каталогу фронтенда. Переопределяет `--front-end-version`. |
| `--comfy-api-base` | `https://api.comfy.org` | Базовый URL для API ComfyUI. |
| `--database-url` | `sqlite:///<ComfyUI>/user/comfyui.db` | URL базы данных. Используйте `sqlite:///:memory:` для базы данных в памяти. |
| `--enable-assets` | отключено | Включает систему ассетов (маршруты API, синхронизацию базы данных, фоновое сканирование). |
| `--disable-assets` | отключено | Отключает систему ассетов, даже если включены `--enable-assets` или `--windows-standalone-build`. |
| `--enable-asset-hashing` | отключено | Вычисляет хеши содержимого blake3 при сканировании ассетов. Включает будущие функции переносимости ассетов, такие как дедупликация и разрешение моделей между машинами, ценой увеличения времени запуска и хеширования каждого выходного файла в больших каталогах моделей. По умолчанию отключено; требует системы ассетов (`--enable-assets` или `--windows-standalone-build`). |
| `--feature-flag` `KEY[=VALUE]` | Не задано | Устанавливает серверный флаг функции. Указание только `KEY` устанавливает значение true. Можно повторять. Логические значения и числа преобразуются автоматически. |
| `--list-feature-flags` | Не задано | Выводит известные флаги функций, задаваемые через CLI, в формате JSON и завершает работу. |

```bash
# Список доступных флагов функций
python main.py --list-feature-flags

# Установка флагов функций
python main.py --feature-flag show_signin_button=true
```

Чтобы также записывать этот уровень в файл, добавьте уровень и путь к файлу; флаг можно повторять, чтобы настроить вывод в консоль и файл одновременно. |

| `--multi-user` | отключено | Включить отдельное хранилище для каждого пользователя. |
| `--quick-test-for-ci` | отключено | Быстрый тест запуска для CI. Завершается сразу после инициализации. |
