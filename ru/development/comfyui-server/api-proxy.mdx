[Comfy SDK](/ru/development/api-development/sdks) работают с [Comfy API v2](/api-reference/v2/overview). Собственный экземпляр ComfyUI предоставляет v2 через [comfy-api-proxy](https://github.com/Comfy-Org/comfy-api-proxy), небольшой сервис с открытым исходным кодом, который работает рядом с вашим экземпляром.

## Установить и запустить

```bash
pip install comfy-api-proxy
comfy-api-proxy
```

По умолчанию он проксирует ComfyUI на `127.0.0.1:8188` и обслуживает API v2 на `127.0.0.1:8189`. Используйте `--comfyui` и `--port`, чтобы изменить любой из этих параметров.

Запустите его с `--comfyui-base-dir /path/to/ComfyUI`, если вы также хотите загружать файлы моделей в свою установку.

## Направить SDK на прокси

Задайте базовый URL и создайте клиент как обычно:

```bash
export COMFY_BASE_URL="http://127.0.0.1:8189"
```

<CodeGroup>
```python Python
from comfy_sdk import Comfy

client = Comfy()
```

```typescript TypeScript
import { Comfy } from "@comfyorg/sdk";

const client = new Comfy();
```
</CodeGroup>

Всё из [руководства по SDK](/ru/development/api-development/sdks) работает с прокси так же, как с Comfy Cloud.

## Аутентификация

По умолчанию аутентификация не требуется. Если прокси настроен со статическим bearer-токеном, передайте этот токен как API-ключ SDK: `Comfy(api_key="...")`.

<Warning>
  По умолчанию прокси привязан только к loopback. Если вы открываете его за пределы loopback, например перед ComfyUI на арендованном GPU, настройте bearer-токен или поставьте перед ним reverse proxy с аутентификацией.
</Warning>
