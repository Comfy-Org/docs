## Как Comfy загружает пользовательские узлы

При запуске Comfy сканирует каталог `custom_nodes` в поисках модулей Python и пытается их загрузить. 
Если модуль экспортирует `NODE_CLASS_MAPPINGS`, он будет рассматриваться как пользовательский узел.
<Tip>Модуль Python представляет собой каталог, содержащий файл `__init__.py`. 
Модуль экспортирует всё, что перечислено в атрибуте `__all__`, определённом в `__init__.py`.</Tip>

### __init__.py

`__init__.py` выполняется, когда Comfy пытается импортировать модуль. Чтобы модуль был распознан как содержащий
определения пользовательских узлов, он должен экспортировать `NODE_CLASS_MAPPINGS`. Если это так (и если при импорте ничего не пошло не так),
узлы, определённые в модуле, будут доступны в Comfy. Если в вашем коде есть ошибка,
Comfy продолжит работу, но сообщит, что модуль не удалось загрузить. Так что проверяйте консоль Python!

Очень простой файл `__init__.py` может выглядеть так:
```python
from .python_file import MyCustomNode
NODE_CLASS_MAPPINGS = { "My Custom Node" : MyCustomNode }
__all__ = ["NODE_CLASS_MAPPINGS"]
```

#### NODE_CLASS_MAPPINGS

`NODE_CLASS_MAPPINGS` должен быть `dict`, сопоставляющим имена пользовательских узлов (уникальные в пределах установки Comfy)
соответствующим классам узлов.

#### NODE_DISPLAY_NAME_MAPPINGS

`__init__.py` также может экспортировать `NODE_DISPLAY_NAME_MAPPINGS`, который сопоставляет то же уникальное имя отображаемому имени узла.
Если `NODE_DISPLAY_NAME_MAPPINGS` не указан, Comfy использует уникальное имя как отображаемое имя.

#### WEB_DIRECTORY

Если вы развёртываете клиентский код, вам также потребуется экспортировать путь относительно модуля, в котором
находятся файлы JavaScript. Принято размещать их в подкаталоге пользовательского узла с именем `js`.
<Tip>Будут обслуживаться *только* файлы `.js`; развернуть `.css` или другие типы таким способом нельзя</Tip>

<Warning>В предыдущих версиях Comfy требовалось, чтобы `__init__.py` копировал файлы JavaScript в основной веб-подкаталог Comfy.
Вы всё ещё встретите код, который это делает. Не делайте так.</Warning>
