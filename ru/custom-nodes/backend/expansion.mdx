## Расширение узлов

Обычно, когда узел выполняется, функция выполнения сразу возвращает результаты выходов этого узла. «Расширение узлов» - это сравнительно продвинутая техника, которая позволяет узлам возвращать новый подграф узлов, который должен занять их место в графе. Именно эта техника позволяет пользовательским узлам реализовывать циклы.

### Простой пример

Сначала вот простой пример того, как выглядит расширение узлов:

<Tip>Мы настоятельно рекомендуем использовать класс `GraphBuilder` при создании подграфов. Это не обязательно, но позволяет избежать множества простых ошибок.</Tip>
```python
def load_and_merge_checkpoints(self, checkpoint_path1, checkpoint_path2, ratio):
    from comfy_execution.graph_utils import GraphBuilder # Обычно в начале файла
    graph = GraphBuilder()
    checkpoint_node1 = graph.node("CheckpointLoaderSimple", checkpoint_path=checkpoint_path1)
    checkpoint_node2 = graph.node("CheckpointLoaderSimple", checkpoint_path=checkpoint_path2)
    merge_model_node = graph.node("ModelMergeSimple", model1=checkpoint_node1.out(0), model2=checkpoint_node2.out(0), ratio=ratio)
    merge_clip_node = graph.node("ClipMergeSimple", clip1=checkpoint_node1.out(1), clip2=checkpoint_node2.out(1), ratio=ratio)
    return {
        # Возврат выходов (MODEL, CLIP, VAE)
        "result": (merge_model_node.out(0), merge_clip_node.out(0), checkpoint_node1.out(2)),
        "expand": graph.finalize(),
    }
```

Хотя этот же узел можно было реализовать и раньше, вручную обращаясь к внутренностям ComfyUI, использование расширения означает, что каждый подузел будет кэшироваться отдельно (так что если вы измените `model2`, вам не придётся перезагружать `model1`).

### Требования

Чтобы выполнить расширение узлов, узел должен вернуть словарь со следующими ключами:
1. `result`: кортеж выходов узла. Он может сочетать финализированные значения (как при возврате из обычного узла) и выходы узлов.
2. `expand`: финализированный граф, к которому нужно применить расширение. См. ниже, если вы не используете `GraphBuilder`.

#### Дополнительные требования, если вы не используете GraphBuilder

Формат, ожидаемый в ключе `expand`, совпадает с форматом API ComfyUI. Следующие требования обрабатываются `GraphBuilder`, но их нужно выполнять вручную, если вы решите отказаться от него:

1. Идентификаторы узлов должны быть уникальными во всём графе. (Это включает случаи нескольких выполнений одного и того же узла из-за использования списков.)
2. Идентификаторы узлов должны быть детерминированными и согласованными между несколькими выполнениями графа (включая частичные выполнения из-за кэширования).

Даже если вы не хотите использовать `GraphBuilder` для непосредственного построения графа (например, потому что загружаете необработанный json графа из файла), можно применить функцию `GraphBuilder.alloc_prefix()` для генерации префикса и `comfy.graph_utils.add_graph_prefix`, чтобы привести существующие графы в соответствие с этими требованиями.

### Эффективное кэширование подграфов

Хотя вы можете передавать в узлы внутри подграфа нелитеральные входы (например, тензоры torch), это может препятствовать кэшированию *внутри* подграфа. Когда это возможно, передавайте связи с объектами подграфа, а не сам узел. (Чтобы сделать это проще, можно объявить вход как `rawLink` в разделе [Дополнительные параметры](./datatypes#дополнительные-параметры) этого входа.)
