## pytorch, тензоры и torch.Tensor

Все основные вычисления в Comfy выполняет [pytorch](https://pytorch.org/). Если ваши пользовательские узлы должны будут разбираться во внутренностях Stable Diffusion, вам потребуется освоить эту библиотеку, что выходит далеко за рамки этого введения.

Однако многим пользовательским узлам потребуется обрабатывать изображения, латенты и маски, каждый из которых внутри представлен как `torch.Tensor`, поэтому стоит добавить в закладки [документацию по torch.Tensor](https://pytorch.org/docs/stable/tensors.html).

### Что такое тензор?

`torch.Tensor` представляет тензор, то есть математическое обобщение вектора или матрицы на любое число размерностей. _Ранг_ тензора это число его размерностей (у вектора _ранг_ 1, у матрицы _ранг_ 2); его _форма_ описывает размер каждой размерности.

Так, RGB-изображение (высотой H и шириной W) можно представить как три массива (по одному на каждый цветовой канал), каждый размером H x W, что можно выразить тензором с _формой_ `[H,W,3]`. В Comfy изображения почти всегда идут в пакете (даже если пакет содержит всего одно изображение). `torch` всегда ставит размерность пакета первой, поэтому изображения Comfy имеют _форму_ `[B,H,W,3]`, обычно записываемую как `[B,H,W,C]`, где C означает каналы (Channels).

### squeeze, unsqueeze и reshape

Если у тензора есть размерность размером 1 (так называемая свёрнутая размерность), он эквивалентен тому же тензору с удалённой этой размерностью (пакет из 1 изображения это просто изображение). Удаление такой свёрнутой размерности называют squeeze (сжатие), а вставку новой: unsqueeze.

<Warning>Некоторые фрагменты кода на torch и некоторые авторы пользовательских узлов возвращают сжатый тензор, когда размерность свёрнута, например когда в пакете только один элемент. Это частая причина ошибок!</Warning>

Представление тех же данных в другой форме называется reshape. Это часто требует знания внутренней структуры данных, поэтому обращайтесь с ним осторожно!

### Важная нотация

`torch.Tensor` поддерживает большинство операций срезов Python, итерацию и другие обычные операции, характерные для списков. У тензора также есть атрибут `.shape`, который возвращает его размер как `torch.Size` (это подкласс `tuple`, с которым можно обращаться как с кортежем).

Есть и другие важные элементы нотации, которые вы часто встретите (некоторые из них относятся к менее распространённой стандартной нотации Python и гораздо чаще встречаются именно при работе с тензорами).

- `torch.Tensor` поддерживает использование `None` в срезах, чтобы указать вставку размерности размером 1.

- `:` часто используется при срезе тензора и означает «оставить размерность целиком». Это как `a[start:end]` в Python, но без указания начальной и конечной точки.

- `...` означает «все размерности в неопределённом количестве». Так, `a[0, ...]` извлечёт первый элемент из пакета независимо от числа размерностей.

- в методах, куда нужно передать форму, она часто передаётся как `tuple` размерностей, при этом одной размерности можно задать размер `-1`, что означает, что размер этой размерности должен быть вычислен исходя из общего размера данных.

```python
>>> a = torch.Tensor((1,2))
>>> a.shape
torch.Size([2])
>>> a[:,None].shape 
torch.Size([2, 1])
>>> a.reshape((1,-1)).shape
torch.Size([1, 2])
```

### Поэлементные операции

Многие бинарные операции над `torch.Tensor` (включая '+', '-', '*', '/' и '==') применяются поэлементно (независимо к каждому элементу). Операнды должны быть _либо_ двумя тензорами одинаковой формы, _либо_ тензором и скаляром. Например:

```python
>>> import torch
>>> a = torch.Tensor((1,2))
>>> b = torch.Tensor((3,2))
>>> a*b
tensor([3., 4.])
>>> a/b
tensor([0.3333, 1.0000])
>>> a==b
tensor([False,  True])
>>> a==1
tensor([ True, False])
>>> c = torch.Tensor((3,2,1)) 
>>> a==c
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
RuntimeError: The size of tensor a (2) must match the size of tensor b (3) at non-singleton dimension 0
```

### Истинность тензоров

<Warning>Значение «истинности» тензора не совпадает с таковым для списков Python.</Warning>

Возможно, вы знакомы с тем, что значение истинности списка Python равно `True` для любого непустого списка и `False` для `None` или `[]`. Напротив, у `torch.Tensor` (с более чем одним элементом) нет определённого значения истинности. Вместо этого нужно использовать `.all()` или `.any()`, чтобы объединить поэлементную истинность:

```python
>>> a = torch.Tensor((1,2))
>>> print("yes" if a else "no")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
RuntimeError: Boolean value of Tensor with more than one value is ambiguous
>>> a.all()
tensor(False)
>>> a.any()
tensor(True)
```

Это также означает, что для проверки, задана ли переменная-тензор, нужно использовать `if a is not None:`, а не `if a:`.
