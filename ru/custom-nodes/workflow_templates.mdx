Если у ваших пользовательских узлов есть примеры файлов рабочих процессов, ComfyUI может показать их пользователю в браузере шаблонов (меню `Workflow`/`Browse Templates`). Шаблоны рабочих процессов: отличный способ помочь пользователям освоиться с вашими узлами.

Как разработчику узла, вам достаточно создать папку `example_workflows` и поместить в неё файлы `json`. При желании можно положить файлы `jpg` с тем же именем, которые будут отображаться как миниатюра шаблона.

Внутри ComfyUI статически отдаёт эти файлы вместе с эндпоинтом (`/api/workflow_templates`), который возвращает коллекцию шаблонов рабочих процессов.

<Note>

Следующие имена папок также принимаются, но мы по-прежнему рекомендуем использовать `example_workflows`:
- workflow
- workflows
- example
- examples
</Note>

## Пример

В папке `ComfyUI-MyCustomNodeModule/example_workflows/`:
 - `My_example_workflow_1.json`
 - `My_example_workflow_1.jpg`
 - `My_example_workflow_2.json`

В этом примере браузер шаблонов ComfyUI показывает категорию `ComfyUI-MyCustomNodeModule` с двумя элементами, у одного из которых есть миниатюра.

Реальный пример см. в [папке example_workflows проекта ComfyUI-Impact-Pack](https://github.com/ltdrdata/ComfyUI-Impact-Pack/tree/Main/example_workflows).
