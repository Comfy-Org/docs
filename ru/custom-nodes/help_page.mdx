## Документация узла в Markdown

Пользовательские узлы могут содержать подробную документацию в Markdown, которая отображается в интерфейсе вместо общего описания узла. Это даёт пользователям сведения о возможностях узла, его параметрах и примерах использования.

Если вы уже добавили подсказки для каждого параметра в описании узла, эту базовую информацию можно посмотреть прямо на панели документации узла.
Дополнительную документацию добавлять не нужно; пример реализации смотрите в [ContextWindowsManualNode](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy_extras/nodes_context_windows.py#L7).

## Настройка

Чтобы добавить документацию для пользовательских узлов или документацию с поддержкой нескольких языков:

1. Создайте папку `docs` внутри каталога `WEB_DIRECTORY`.
2. Добавьте файлы Markdown с именами ваших узлов (имена узлов — это ключи словаря в `NODE_CLASS_MAPPINGS`, который используется для регистрации узлов):
   - `WEB_DIRECTORY/docs/NodeName.md` — документация по умолчанию
   - `WEB_DIRECTORY/docs/NodeName/en.md` — документация на английском
   - `WEB_DIRECTORY/docs/NodeName/zh.md` — документация на китайском
   - При необходимости добавьте другие языки (например, `fr.md`, `de.md` и т. д.)

Система сама загрузит подходящую документацию с учётом языка пользователя, а если локализованной версии нет, вернётся к `NodeName.md`.

## Поддерживаемые возможности Markdown

- Стандартный синтаксис Markdown (заголовки, списки, блоки кода и т. д.)
- Изображения в синтаксисе Markdown: `![alt text](image.png)`
- HTML-медиаэлементы с определёнными атрибутами:
  - теги `<video>` и `<source>`
  - допустимые атрибуты: `controls`, `autoplay`, `loop`, `muted`, `preload`, `poster`

## Пример структуры

```
my-custom-node/
├── __init__.py
├── web/              # WEB_DIRECTORY
│   ├── js/
│   │   └── my-node.js
│   └── docs/
│       ├── MyNode.md           # Fallback documentation
│       └── MyNode/
│           ├── en.md           # English version
│           └── zh.md           # Chinese version
```

## Пример файла Markdown

```markdown
# My Custom Node

This node processes images using advanced algorithms.

## Parameters

- **image**: Input image to process
- **strength**: Processing strength (0.0 - 1.0)

## Usage

![example usage](example.png)

<video controls loop muted>
  <source src="demo.mp4" type="video/mp4">
</video>
```
