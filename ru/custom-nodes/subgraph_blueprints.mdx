Если у вас есть переиспользуемые компоненты подграфов, связанные с вашими пользовательскими узлами, ComfyUI может сделать их доступными для пользователей как глобальные чертежи подграфов. Чертежи подграфов позволяют пользователям быстро добавлять готовые группы узлов из меню подграфов.

Как разработчику узлов, вам достаточно создать папку `subgraphs` в каталоге вашего пользовательского узла и поместить туда файлы `.json`.

Внутри ComfyUI сканирует все каталоги пользовательских узлов на наличие файлов подграфов и отдаёт их через эндпоинт API `/global_subgraphs`.

## Пример

В каталоге `ComfyUI-MyCustomNodeModule/subgraphs/`:
 - `My_upscale_subgraph.json`
 - `My_effects_subgraph.json`

В этом примере браузер подграфов ComfyUI показывает чертежи из `ComfyUI-MyCustomNodeModule`, которые пользователи могут добавить в свои рабочие процессы.

## Создание JSON-файла подграфа

JSON-файлы подграфов используют тот же формат, что и JSON-файлы рабочих процессов. Самый простой способ создать такой файл:

1. Соберите подграф в ComfyUI
2. Выберите узлы, которые нужно включить
3. Преобразуйте их в подграф
4. Экспортируйте подграф в формате JSON
5. Поместите JSON-файл в папку `subgraphs/`
