API значков панели «О программе» позволяет расширениям добавлять пользовательские значки на страницу «О программе» ComfyUI. Такие значки могут отображать сведения о вашем расширении и содержать ссылки на документацию, исходный код или другие ресурсы.

## Использование

```javascript
app.registerExtension({
  name: "MyExtension",
  aboutPageBadges: [
    {
      label: "Documentation",
      url: "https://example.com/docs",
      icon: "icon-[lucide--file]"
    },
    {
      label: "GitHub",
      url: "https://github.com/username/repo",
      icon: "icon-[lucide--github]"
    }
  ]
});
```

## Настройка значков

Каждому значку требуются все перечисленные свойства:

```javascript
{
  label: string,           // Текст, отображаемый на значке
  url: string,             // URL, открываемый при нажатии на значок
  icon: string             // Класс иконки (например, "icon-[lucide--github]")
}
```

## Параметры иконок

Иконки значков используют классы иконок [Lucide](https://lucide.dev/icons/) в формате
`icon-[lucide--<icon-name>]`. Вот некоторые часто используемые иконки:

- Документация: `icon-[lucide--file]` или `icon-[lucide--book-open]`
- GitHub: `icon-[lucide--github]`
- Внешняя ссылка: `icon-[lucide--external-link]`
- Информация: `icon-[lucide--info]`
- Скачать: `icon-[lucide--download]`
- Веб-сайт: `icon-[lucide--globe]`

Фронтенд генерирует эти классы при сборке, поэтому доступны только те иконки Lucide,
которые использует сам фронтенд. Если иконка не отображается, выберите другую
иконку или определите собственный класс иконки в таблице стилей, которую загружает ваше расширение.

Классы PrimeIcons, например `pi pi-file`, пока ещё отображаются, но постепенно
выводятся из использования. Не используйте их в новом коде. См. [Миграция с PrimeVue](/ru/custom-nodes/js/primevue-removal-migration).

## Пример

```javascript
app.registerExtension({
  name: "BadgeExample",
  aboutPageBadges: [
    {
      label: "Website",
      url: "https://example.com",
      icon: "icon-[lucide--globe]"
    },
    {
      label: "Donate",
      url: "https://example.com/donate",
      icon: "icon-[lucide--heart]"
    },
    {
      label: "Documentation",
      url: "https://example.com/docs",
      icon: "icon-[lucide--book-open]"
    }
  ]
});
```

Значки отображаются на панели «О программе» в диалоге настроек, который открывается по иконке шестерёнки в правом верхнем углу интерфейса ComfyUI.
