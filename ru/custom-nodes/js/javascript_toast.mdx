Toast API предоставляет способ отображения неблокирующих уведомлений пользователям. Они полезны для обратной связи без прерывания рабочего процесса.
## Базовое использование

### Простое всплывающее уведомление

```javascript
// Показать простое информационное всплывающее уведомление
app.extensionManager.toast.add({
  severity: "info",
  summary: "Information",
  detail: "Operation completed successfully",
  life: 3000
});
```

### Типы всплывающих уведомлений

```javascript
// Уведомление об успехе
app.extensionManager.toast.add({
  severity: "success",
  summary: "Success",
  detail: "Data saved successfully",
  life: 3000
});

// Уведомление-предупреждение
app.extensionManager.toast.add({
  severity: "warn",
  summary: "Warning",
  detail: "This action may cause problems",
  life: 5000
});

// Уведомление об ошибке
app.extensionManager.toast.add({
  severity: "error",
  summary: "Error",
  detail: "Failed to process request",
  life: 5000
});
```

### Вспомогательный метод для Alert

```javascript
// Краткий способ создать alert-уведомление
app.extensionManager.toast.addAlert("This is an important message");
```
## Справочник по API

### Сообщение Toast

```javascript
app.extensionManager.toast.add({
  severity?: "success" | "info" | "warn" | "error" | "secondary" | "contrast", // Уровень важности сообщения (по умолчанию: "info")
  summary?: string,         // Короткий заголовок для всплывающего сообщения
  detail?: any,             // Подробное содержимое сообщения
  closable?: boolean,       // Может ли пользователь закрыть всплывающее сообщение (по умолчанию: true)
  life?: number,            // Длительность в миллисекундах до автоматического закрытия
  group?: string,           // Идентификатор группы для управления связанными всплывающими сообщениями
  styleClass?: any,         // Класс стиля сообщения
  contentStyleClass?: any   // Класс стиля содержимого
});
```

### Вспомогательный метод Alert

```javascript
app.extensionManager.toast.addAlert(message: string);
```

### Дополнительные методы

```javascript
// Удалить конкретное всплывающее сообщение
app.extensionManager.toast.remove(toastMessage);

// Удалить все всплывающие сообщения
app.extensionManager.toast.removeAll();
```
