Холст направляет ввод указателя через `CanvasPointer`. Он определяет, станет ли нажатие щелчком, двойным щелчком или перетаскиванием, и запускает обратные вызовы, которые вы назначили для этого нажатия. Виджеты, отрисованные на холсте, используют его через `onPointerDown`.

## Поведение по умолчанию

- Чтобы перетащить несколько выбранных элементов, больше не нужно удерживать Shift. Щелчок по одному элементу, когда выбран несколько, по-прежнему снимает выделение с остальных.
- Щелчок по прикреплённому соединению на входе больше не отключает и не подключает его заново.
- Небольшое смещение между нажатием и отпусканием указателя по-прежнему считается щелчком. Как только указатель выходит за предел смещения при щелчке, нажатие становится перетаскиванием. Время на это решение не влияет.
- Для двойного щелчка нужны два нажатия в пределах времени двойного щелчка и на расстоянии не более трёхкратного смещения при щелчке. Завершить двойной щелчок может только нажатие, которому назначен `onDoubleClick`.

Смещение при щелчке и время двойного щелчка пользователи задают в настройках (`Comfy.Pointer.ClickDrift` и `Comfy.Pointer.DoubleClickTime`).

### Выбор нескольких элементов

- `Ctrl` + перетаскивание: начать множественный выбор
- `Ctrl` + `Shift` + перетаскивание: добавить к выбору
- `Ctrl` + перетаскивание, затем `Shift`: добавить к выбору
- `Ctrl` + перетаскивание, затем `Alt`: удалить из выбора

## Обработка ввода указателя на виджете

Назначьте `onPointerDown` для виджета. Он срабатывает при нажатии указателя и получает
указатель, узел и холст. Назначьте необходимые обратные вызовы для указателя;
холст запускает нужные из них, когда нажатие разрешается:

```js
widget.onPointerDown = function (pointer, node, canvas) {
  const e = pointer.eDown
  const offsetFromNode = [e.canvasX - node.pos[0], e.canvasY - node.pos[1]]

  pointer.onClick = (upEvent) => {
    console.log(pointer.eDown, pointer.eMove, pointer.eUp)
  }
  pointer.onDoubleClick = (upEvent) => this.customFunction(upEvent)

  pointer.onDragStart = () => {}
  pointer.onDrag = (moveEvent) => {}
  pointer.onDragEnd = (upEvent) => {}
  pointer.onDragCancel = () => {}

  pointer.finally = () => {}

  return true
}
```

- `onClick` и `onDoubleClick` никогда не выполняются в том же нажатии, что и `onDragStart`,
  `onDragEnd` or `onDragCancel`. `onDrag` can run in a press that ends as a
  click, because it also receives movement inside the click drift limit.
- `onDragStart` запускается один раз за перетаскивание, когда указатель впервые смещается дальше порога клика
  drift limit. If the pointer is released past the limit before any movement
  event is reported, `onDragStart` runs on release, `onDragEnd` runs right
  after it, and `onDrag` does not run.
- Когда нажатие назначает одновременно и `onClick`, и `onDoubleClick`, отпускание первого
  press of a double-click runs `onClick`. The second press runs
  `onDoubleClick` instead of `onClick`, so make `onClick` safe to run first.
  The first click can also land on a nearby item instead of your widget, so
  `onDoubleClick` can run without your `onClick` having run.
- `onDragEnd` получает событие pointer up при перетаскивании. `onDragCancel` выполняется
  instead when the drag is interrupted, for example when pointer capture is
  lost.
- `finally` срабатывает один раз, когда нажатие заканчивается. Присваивание `pointer.finally` запускает
  callback it replaces immediately. If `onPointerDown` does not return `true`,
  the canvas assigns its own `finally`, so yours runs during pointer down.
  Return `true` when you rely on `finally` for cleanup.
- `pointer.eDown`, `pointer.eMove` и `pointer.eUp` дают каждому колбэку доступ
  to the whole sequence of events.
Верните `true`, чтобы холст не обрабатывал нажатие самостоятельно.
- Удалите любой устаревший обработчик `widget.mouse`, когда добавляете `onPointerDown`. Если
  `onPointerDown` returns `true`, the canvas keeps tracking the widget after
  release and keeps calling `widget.mouse` on every pointer move.

Холст сам распознаёт двойные щелчки и перетаскивания, поэтому виджету больше не нужно
отмерять время или расстояние между отдельными событиями указателя. Он также учитывает
пользовательские настройки допуска смещения при щелчке и двойном щелчке.

## Управлять курсором холста

`canvas.state.hoveringOver` содержит битовые флаги типов элементов под указателем, например узла, группы, перенаправления или соединения. Установите для `canvas.state.shouldSetCursor` значение `false`, чтобы холст перестал задавать стиль курсора, а затем задайте его сами:

```js
canvas.state.shouldSetCursor = false
canvas.canvas.style.cursor = 'pointer'
```

Запуск изменения размера узла по-прежнему устанавливает курсор изменения размера, пока `shouldSetCursor` равен `false`. Снова задайте курсор после завершения изменения размера.
