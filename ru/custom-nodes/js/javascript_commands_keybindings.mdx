API команд и горячих клавиш позволяет расширениям регистрировать пользовательские команды и связывать их с горячими клавишами. Это позволяет пользователям быстро запускать действия без использования мыши.

## Базовое использование

```javascript
app.registerExtension({
  name: "MyExtension",
  // Register commands
  commands: [
    {
      id: "myCommand",
      label: "My Command",
      function: () => {
        console.log("Command executed!");
      }
    }
  ],
  // Associate keybindings with commands
  keybindings: [
    {
      combo: { key: "k", ctrl: true },
      commandId: "myCommand"
    }
  ]
});
```

## Конфигурация команд

Каждая команда требует `id`, `label` и `function`:

```javascript
{
  id: string,              // Unique identifier for the command
  label: string,           // Display name for the command
  function: () => void     // Function to execute when command is triggered
}
```

## Настройка привязок клавиш

Каждая привязка клавиш требует `combo` и `commandId`:

```javascript
{
  combo: {                 // Комбинация клавиш
    key: string,           // Основная клавиша (один символ или специальная клавиша)
    ctrl?: boolean,        // Требовать клавишу Ctrl (необязательно)
    shift?: boolean,       // Требовать клавишу Shift (необязательно)
    alt?: boolean,         // Требовать клавишу Alt (необязательно)
    meta?: boolean         // Требовать клавишу Meta/Command (необязательно)
  },
  commandId: string        // ID команды для запуска
}
```

### Специальные клавиши

Для несимвольных клавиш используйте одно из следующих значений:
- Стрелки: `"ArrowUp"`, `"ArrowDown"`, `"ArrowLeft"`, `"ArrowRight"`
- Функциональные клавиши: `"F1"` ... `"F12"`
- Другие специальные клавиши: `"Escape"`, `"Tab"`, `"Enter"`, `"Backspace"`, `"Delete"`, `"Home"`, `"End"`, `"PageUp"`, `"PageDown"`

## Примеры команд

```javascript
app.registerExtension({
  name: "CommandExamples",
  commands: [
    {
      id: "runWorkflow",
      label: "Run Workflow",
      function: () => {
        app.queuePrompt();
      }
    },
    {
      id: "clearWorkflow",
      label: "Clear Workflow",
      function: () => {
        if (confirm("Clear the workflow?")) {
          app.graph.clear();
        }
      }
    },
    {
      id: "saveWorkflow",
      label: "Save Workflow",
      function: () => {
        app.graphToPrompt().then(workflow => {
          const blob = new Blob([JSON.stringify(workflow)], {type: "application/json"});
          const url = URL.createObjectURL(blob);
          const a = document.createElement("a");
          a.href = url;
          a.download = "workflow.json";
          a.click();
          URL.revokeObjectURL(url);
        });
      }
    }
  ]
});
```

## Примеры привязок клавиш

```javascript
app.registerExtension({
  name: "KeybindingExamples",
  commands: [
    /* Commands defined above */
  ],
  keybindings: [
    // Ctrl+R to run workflow
    {
      combo: { key: "r", ctrl: true },
      commandId: "runWorkflow"
    },
    // Ctrl+Shift+C to clear workflow
    {
      combo: { key: "c", ctrl: true, shift: true },
      commandId: "clearWorkflow"
    },
    // Ctrl+S to save workflow
    {
      combo: { key: "s", ctrl: true },
      commandId: "saveWorkflow"
    },
    // F5 to run workflow (alternative)
    {
      combo: { key: "F5" },
      commandId: "runWorkflow"
    }
  ]
});
```

## Примечания и ограничения

- Расширения не могут переопределять горячие клавиши, заданные в ядре ComfyUI. Проверьте основные горячие клавиши в этих исходных файлах:
  - [Основные команды](https://github.com/Comfy-Org/ComfyUI_frontend/blob/e76e9ec61a068fd2d89797762f08ee551e6d84a0/src/composables/useCoreCommands.ts)
  - [Основные команды меню](https://github.com/Comfy-Org/ComfyUI_frontend/blob/e76e9ec61a068fd2d89797762f08ee551e6d84a0/src/constants/coreMenuCommands.ts)
  - [Основные горячие клавиши](https://github.com/Comfy-Org/ComfyUI_frontend/blob/e76e9ec61a068fd2d89797762f08ee551e6d84a0/src/constants/coreKeybindings.ts)
  - [Зарезервированные сочетания клавиш](https://github.com/Comfy-Org/ComfyUI_frontend/blob/e76e9ec61a068fd2d89797762f08ee551e6d84a0/src/constants/reservedKeyCombos.ts)

- Некоторые сочетания клавиш зарезервированы браузером (например, Ctrl+F для поиска) и не могут быть переопределены.
- Если несколько расширений регистрируют одну и ту же привязку клавиш, поведение не определено.
