Dialog API предоставляет стандартизированные диалоги, единообразно работающие в настольной и веб-средах. Авторам расширений наиболее полезны методы `prompt` и `confirm`.

## Базовое использование

### Диалог промпта

```javascript
// Показать диалог промпта
app.extensionManager.dialog.prompt({
  title: "User Input",
  message: "Please enter your name:",
  defaultValue: "User"
}).then(result => {
  if (result !== null) {
    console.log(`Input: ${result}`);
  }
});
```

### Диалог подтверждения

```javascript
// Показать диалог подтверждения
app.extensionManager.dialog.confirm({
  title: "Confirm Action",
  message: "Are you sure you want to continue?",
  type: "default"
}).then(result => {
  console.log(result ? "User confirmed" : "User cancelled");
});
```

## Справочник по API

### Промпт

```javascript
app.extensionManager.dialog.prompt({
  title: string,             // Заголовок диалога
  message: string,           // Сообщение или вопрос для отображения
  defaultValue?: string      // Начальное значение в поле ввода (необязательно)
}).then((result: string | null) => {
  // result: введённый текст или null при отмене
});
```

### Подтверждение

```javascript
app.extensionManager.dialog.confirm({
  title: string,             // Заголовок диалога
  message: string,           // Сообщение для отображения
  type?: "default" | "overwrite" | "delete" | "dirtyClose" | "reinstall", // Тип диалога (необязательно)
  itemList?: string[],       // Список элементов для отображения (необязательно)
  hint?: string              // Текст подсказки для отображения (необязательно)
}).then((result: boolean | null) => {
  // result: true при подтверждении, false при отказе, null при отмене
});
```

С другими специализированными диалогами, доступными в ComfyUI, авторы расширений могут ознакомиться в файле `dialogService.ts` в исходном коде.
