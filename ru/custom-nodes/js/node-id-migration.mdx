Фронтенд ComfyUI теперь нормализует локальные идентификаторы узлов к брендированному строковому типу `NodeId` на внутренних границах. Сериализованные рабочие процессы и payload'ы API по-прежнему могут содержать числовые ID, но идентификаторы узлов в litegraph, такие как `node.id`, `LLink.origin_id` и `LLink.target_id`, после попадания во фронтенд следует рассматривать как строки. ID соединений (`LLink.id`) и ID перенаправлений остаются числами.

Авторам расширений следует избегать числовых сравнений с идентификаторами узлов. В частности, пограничные маркеры подграфов представлены как брендированные строковые ID:

- `SUBGRAPH_INPUT_ID` сериализуется из `-10`
- `SUBGRAPH_OUTPUT_ID` сериализуется из `-20`

Сравнивайте со строками `'-10'` и `'-20'` или приведите обе стороны к строкам перед сравнением классических значений.
