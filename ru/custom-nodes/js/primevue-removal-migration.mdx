Фронтенд ComfyUI больше не устанавливает PrimeVue. Хост-приложение не вызывает
`app.use(PrimeVue)`, поэтому расширения лишаются трёх вещей, на которые они могли полагаться:

- глобального свойства `$primevue` в хост-приложении Vue;
- таблицы стилей темы PrimeVue, поэтому компоненты PrimeVue, которые расширение
  отображает внутри хост-приложения, отображаются без стилей; и
- всех глобальных CSS-переменных `--p-*`, таких как `--p-primary-color`,
  `--p-surface-*`, `--p-text-color`, `--p-content-background` и
  `--p-form-field-border-color`.

## Расширения, которые рендерят компоненты PrimeVue

Не полагайтесь на экземпляр PrimeVue хост-приложения. Замените компоненты PrimeVue собственной разметкой или создайте собственное приложение Vue для вашего интерфейса и установите PrimeVue и его тему в этом приложении.

## Расширения, которые читают переменные `--p-*`

Замените их переменными темы дизайн-системы: они следуют активной светлой или тёмной теме и активной цветовой палитре:

| Переменная PrimeVue                                       | Переменная темы     |
| --------------------------------------------------------- | ------------------- |
| `--p-primary-color`                                       | `--primary`         |
| `--p-text-color`                                          | `--foreground`      |
| `--p-text-muted-color`                                    | `--muted-foreground` |
| `--p-content-background`                                  | `--background`      |
| `--p-surface-*` (панели, приподнятые области)             | `--secondary`       |
| `--p-content-border-color`, `--p-form-field-border-color` | `--border`          |

## Подсказки

Глобальная директива `v-tooltip` удалена, и подсказки больше не рендерят DOM PrimeVue:

- `.p-tooltip` и `.p-tooltip-text`
- атрибут `data-pd-tooltip`
- свойства элемента `$_ptooltip*`

Открытая подсказка теперь рендерит один элемент с `data-slot="tooltip-content"`, который порталируется в конец `document.body`. Он существует только пока подсказка открыта. Расширения, скрывающие подсказки во время работы собственного интерфейса, должны нацеливаться на `[data-slot="tooltip-content"]` вместо `.p-tooltip`.

Переменные CSS `--node-component-tooltip*` также удалены из таблицы стилей дизайн-системы. Вместо них используйте переменные темы: `--background`, `--foreground` и `--border`. Старые имена `--base-background`, `--base-foreground` и `--border-default` устарели; см. [Устаревшие имена переменных](#устаревшие-имена-переменных).

## Устаревшие имена переменных

Ранее в этих заметках использовались старые имена дизайн-системы. Они всё ещё работают, но считаются устаревшими и будут удалены в одном из будущих выпусков. Переходите на переменные темы:

| Устаревшее имя                | Переменная темы |
| ----------------------------- | --------------- |
| `--base-background`           | `--background`  |
| `--base-foreground`           | `--foreground`  |
| `--border-default`            | `--border`      |
| `--primary-background`        | `--primary`     |
| `--secondary-background`      | `--secondary`   |
| `--component-node-background` | `--node`        |

PrimeIcons по-прежнему загружаются, поэтому существующие классы иконок `pi pi-*` продолжают работать, но постепенно выводятся из использования. Не используйте их в новом коде.
