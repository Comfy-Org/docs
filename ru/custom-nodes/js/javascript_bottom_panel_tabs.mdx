Bottom Panel Tabs API позволяет расширениям добавлять пользовательские вкладки в нижнюю панель интерфейса ComfyUI. Это полезно для добавления таких функций, как логи, инструменты отладки или пользовательские панели.
## Базовое использование

```javascript
app.registerExtension({
  name: "MyExtension",
  bottomPanelTabs: [
    {
      id: "customTab",
      title: "Custom Tab",
      type: "custom",
      render: (el) => {
        el.innerHTML = '<div>This is my custom tab content</div>';
      }
    }
  ]
});
```
## Настройка вкладок

Каждая вкладка требует `id`, `title` и `type`, а также функцию рендеринга:

```javascript
{
  id: string,              // Уникальный идентификатор вкладки
  title: string,           // Отображаемый заголовок на вкладке
  type: string,            // Тип вкладки (обычно "custom")
  icon?: string,           // Класс иконки (необязательно)
  render: (element) => void // Функция, заполняющая содержимое вкладки
}
```

Функция `render` получает DOM-элемент, в который нужно вставить содержимое вкладки.
## Интерактивные элементы

Вы можете добавлять интерактивные элементы, например кнопки:

```javascript
app.registerExtension({
  name: "InteractiveTabExample",
  bottomPanelTabs: [
    {
      id: "controlsTab",
      title: "Controls",
      type: "custom",
      render: (el) => {
        el.innerHTML = `
          <div style="padding: 10px;">
            <button id="runBtn">Run Workflow</button>
          </div>
        `;
        
        // Добавьте обработчики событий
        el.querySelector('#runBtn').addEventListener('click', () => {
          app.queuePrompt();
        });
      }
    }
  ]
});
```
## Использование React-компонентов

Вы можете монтировать React-компоненты во вкладках нижней панели:

```javascript
// Импортируйте зависимости React в вашем расширении
import React from "react";
import ReactDOM from "react-dom/client";

// Простой React-компонент
function TabContent() {
  const [count, setCount] = React.useState(0);
  
  return (
    <div style={{ padding: "10px" }}>
      <h3>React Component</h3>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
}

// Зарегистрируйте расширение с React-содержимым
app.registerExtension({
  name: "ReactTabExample",
  bottomPanelTabs: [
    {
      id: "reactTab",
      title: "React Tab",
      type: "custom",
      render: (el) => {
        const container = document.createElement("div");
        container.id = "react-tab-container";
        el.appendChild(container);
        
        // Смонтируйте React-компонент
        ReactDOM.createRoot(container).render(
          <React.StrictMode>
            <TabContent />
          </React.StrictMode>
        );
      }
    }
  ]
});
```
## Отдельная регистрация

Вы также можете регистрировать вкладки вне `registerExtension`:

```javascript
app.extensionManager.registerBottomPanelTab({
  id: "standAloneTab",
  title: "Stand-Alone Tab",
  type: "custom",
  render: (el) => {
    el.innerHTML = '<div>This tab was registered independently</div>';
  }
});
```
