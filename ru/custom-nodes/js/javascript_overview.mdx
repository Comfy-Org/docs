## Расширение клиента Comfy

Comfy можно модифицировать с помощью механизма расширений. Чтобы добавить расширение, необходимо:

- Экспортировать `WEB_DIRECTORY` из вашего Python-модуля,
- Поместить один или несколько файлов `.js` в этот каталог,
- Использовать `app.registerExtension` для регистрации расширения.

Эти три шага описаны ниже. Когда вы узнаете, как добавить расширение, просмотрите доступные [хуки](/custom-nodes/js/javascript_hooks), чтобы ваш код вызывался, описание различных [объектов Comfy](/custom-nodes/js/javascript_objects_and_hijacking), которые могут вам понадобиться, или сразу перейдите к [примерам фрагментов кода](/custom-nodes/js/javascript_examples).

### Экспорт `WEB_DIRECTORY`

Веб-клиент Comfy можно расширить, создав подкаталог в каталоге вашего пользовательского узла, обычно называемый `js`, и экспортировав `WEB_DIRECTORY`, поэтому ваш `__init_.py` будет содержать примерно следующее:
```python
WEB_DIRECTORY = "./js"
__all__ = ["NODE_CLASS_MAPPINGS", "NODE_DISPLAY_NAME_MAPPINGS", "WEB_DIRECTORY"]
```

### Включение файлов `.js`

<Tip>Все файлы JavaScript `.js` будут загружены браузером при загрузке веб-страницы Comfy. Вам не нужно указывать файл, в котором находится ваше расширение.</Tip>

_Только_ файлы `.js` будут добавлены на веб-страницу. К другим ресурсам (например, файлам `.css`) можно получить доступ по пути `extensions/custom_node_subfolder/the_file.css` и добавить их программно.

<Warning>Этот путь _не_ включает имя подпапки. Значение `WEB_DIRECTORY` вставляется сервером.</Warning>

### Регистрация расширения

Базовая структура расширения следующая: импортировать основной объект `app` Comfy и вызвать `app.registerExtension`, передав словарь, содержащий уникальное `name` и одну или несколько функций, которые будут вызываться хуками в коде Comfy.

Полное, тривиальное и раздражающее расширение может выглядеть так:
```Javascript
import { app } from "../../scripts/app.js";
app.registerExtension({ 
	name: "a.unique.name.for.a.useless.extension",
	async setup() { 
		alert("Setup complete!")
	},
})
```
