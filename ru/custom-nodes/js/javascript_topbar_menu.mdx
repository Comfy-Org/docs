API меню верхней панели позволяет расширениям добавлять пользовательские пункты меню в верхнюю панель меню ComfyUI. Это полезно для предоставления доступа к расширенным функциям или реже используемым командам.

## Базовое использование

```javascript
app.registerExtension({
  name: "MyExtension",
  // Определить команды
  commands: [
    { 
      id: "myCommand", 
      label: "My Command", 
      function: () => { alert("Command executed!"); } 
    }
  ],
  // Добавить команды в меню
  menuCommands: [
    { 
      path: ["Extensions", "My Extension"], 
      commands: ["myCommand"] 
    }
  ]
});
```

Определения команд следуют тому же шаблону, что и в [API команд и горячих клавиш](./javascript_commands_keybindings). Дополнительную информацию об определении команд см. на этой странице.

## Конфигурация команд

Для каждой команды требуются `id`, `label` и `function`:

```javascript
{
  id: string,              // Unique identifier for the command
  label: string,           // Display name for the command
  function: () => void     // Function to execute when command is triggered
}
```

## Настройка меню

Массив `menuCommands` определяет, где размещать команды в структуре меню:

```javascript
{
  path: string[],          // Массив, представляющий иерархию меню
  commands: string[]       // Массив идентификаторов команд для добавления в это место
}
```

Массив `path` задаёт иерархию меню. Например, `["File", "Export"]` добавит команды в подменю "Export" меню "File".

## Примеры меню

### Добавление в существующие меню

```javascript
app.registerExtension({
  name: "MenuExamples",
  commands: [
    { 
      id: "saveAsImage", 
      label: "Save as Image", 
      function: () => { 
        // Код для сохранения холста как изображения
      } 
    },
    { 
      id: "exportWorkflow", 
      label: "Export Workflow", 
      function: () => { 
        // Код для экспорта рабочего процесса
      } 
    }
  ],
  menuCommands: [
    // Добавить в меню File
    { 
      path: ["File"], 
      commands: ["saveAsImage", "exportWorkflow"] 
    }
  ]
});
```

### Создание структуры подменю

```javascript
app.registerExtension({
  name: "SubmenuExample",
  commands: [
    { 
      id: "option1", 
      label: "Option 1", 
      function: () => { console.log("Option 1"); } 
    },
    { 
      id: "option2", 
      label: "Option 2", 
      function: () => { console.log("Option 2"); } 
    },
    { 
      id: "suboption1", 
      label: "Sub-option 1", 
      function: () => { console.log("Sub-option 1"); } 
    }
  ],
  menuCommands: [
    // Создать вложенную структуру меню
    { 
      path: ["Extensions", "My Tools"], 
      commands: ["option1", "option2"] 
    },
    { 
      path: ["Extensions", "My Tools", "Advanced"], 
      commands: ["suboption1"] 
    }
  ]
});
```

### Добавление команды в несколько меню

Вы можете добавить одну и ту же команду в несколько меню:

```javascript
app.registerExtension({
  name: "MultiLocationExample",
  commands: [
    { 
      id: "helpCommand", 
      label: "Get Help", 
      function: () => { window.open("https://docs.example.com", "_blank"); } 
    }
  ],
  menuCommands: [
    // Добавить в меню Help
    { 
      path: ["Help"], 
      commands: ["helpCommand"] 
    },
    // Также добавить в меню Extensions
    { 
      path: ["Extensions"], 
      commands: ["helpCommand"] 
    }
  ]
});
```

Команды могут работать и с другими API ComfyUI, например с настройками. Подробнее об API настроек см. в документации [Settings API](./javascript_settings).
