API Selection Toolbox позволяет расширениям добавлять пользовательские кнопки действий, которые появляются при выборе узлов на холсте. Это обеспечивает быстрый доступ к контекстно-зависимым командам для выбранных элементов (узлов, групп и т. д.).

## Базовое использование

Чтобы добавить команды в панель инструментов выделения, вашему расширению необходимо:
1. Определить команды с помощью стандартного [интерфейса команд](https://docs.comfy.org/custom-nodes/js/javascript_commands_keybindings)
2. Реализовать метод `getSelectionToolboxCommands`, чтобы указать, какие команды отображаются на панели инструментов

Примечание: метод `getSelectionToolboxCommands` вызывается для каждого элемента в наборе выделения при каждом создании нового выделения.

```javascript
app.registerExtension({
  name: "MyExtension",
  commands: [
    {
      id: "my-extension.duplicate-special",
      label: "Duplicate Special",
      icon: "icon-[lucide--copy]",
      function: (selectedItem) => {
        // Your command logic here
        console.log("Duplicating selected nodes with special behavior");
      }
    }
  ],
  getSelectionToolboxCommands: (selectedItem) => {
    // Return array of command IDs to show in the toolbox
    return ["my-extension.duplicate-special"];
  }
});
```

## Определение команды

Команды для инструментов выделения используют стандартный интерфейс команд ComfyUI:

```javascript
{
  id: string,          // Уникальный идентификатор команды
  label: string,       // Текст для всплывающей подсказки кнопки
  icon?: string,       // Класс иконки для кнопки (необязательно)
  function: (selectedItem) => void  // Функция, выполняемая при нажатии
}
```

`function` получает выбранный элемент (или элементы) в качестве параметра, что позволяет выполнять действия с текущим выделением.

## Параметры иконок

Кнопки панели инструментов выделения используют классы иконок [Lucide](https://lucide.dev/icons/) в формате `icon-[lucide--<icon-name>]` (например, `icon-[lucide--star]`).

Фронтенд генерирует эти классы при сборке, поэтому доступны только те иконки Lucide, которые использует сам фронтенд. Если иконка не отображается, выберите другую иконку или определите собственный класс иконки в таблице стилей, которую загружает ваше расширение.

Классы PrimeIcons (`pi pi-*`) и Material Design Icons (`mdi mdi-*`) пока ещё отображаются, но постепенно выводятся из использования. Не используйте их в новом коде. См. [Миграция при удалении PrimeVue](/ru/custom-nodes/js/primevue-removal-migration).

## Динамическая видимость команд

Метод `getSelectionToolboxCommands` вызывается каждый раз при изменении выделения, что позволяет вам показывать разные команды в зависимости от того, что выбрано:

```javascript
app.registerExtension({
  name: "ContextualCommands",
  commands: [
    {
      id: "my-ext.align-nodes",
      label: "Align Nodes",
      icon: "icon-[lucide--align-start-vertical]",
      function: () => {
        // Align multiple nodes
      }
    },
    {
      id: "my-ext.configure-single",
      label: "Configure",
      icon: "icon-[lucide--settings]",
      function: () => {
        // Configure single node
      }
    }
  ],
  getSelectionToolboxCommands: (selectedItem) => {
    const selectedItems = app.canvas.selectedItems;
    const itemCount = selectedItems ? selectedItems.size : 0;
    
    if (itemCount > 1) {
      // Show alignment command for multiple items
      return ["my-ext.align-nodes"];
    } else if (itemCount === 1) {
      // Show configuration for single item
      return ["my-ext.configure-single"];
    }
    
    return [];
  }
});
```

## Работа с выбранными элементами

Получайте информацию о выбранных элементах через объект `canvas` приложения. Свойство `selectedItems` представляет собой Set, включающий узлы, группы и другие элементы холста:

```javascript
app.registerExtension({
  name: "SelectionInfo",
  commands: [
    {
      id: "my-ext.show-info",
      label: "Show Selection Info",
      icon: "icon-[lucide--info]",
      function: () => {
        const selectedItems = app.canvas.selectedItems;
        
        if (selectedItems && selectedItems.size > 0) {
          console.log(`Selected ${selectedItems.size} items`);
          
          // Iterate through selected items
          selectedItems.forEach(item => {
            if (item.type) {
              console.log(`Item: ${item.type} (ID: ${item.id})`);
            }
          });
        }
      }
    }
  ],
  getSelectionToolboxCommands: () => ["my-ext.show-info"]
});
```

## Полный пример

Вот простой пример, демонстрирующий различные функции панели инструментов выделения:

```javascript
app.registerExtension({
  name: "SelectionTools",
  commands: [
    {
      id: "selection-tools.count",
      label: "Count Selection",
      icon: "icon-[lucide--tag]",
      function: () => {
        const count = app.canvas.selectedItems?.size || 0;
        app.extensionManager.toast.add({
          severity: "info",
          summary: "Selection Count",
          detail: `You have ${count} item${count !== 1 ? 's' : ''} selected`,
          life: 3000
        });
      }
    },
    {
      id: "selection-tools.copy-ids",
      label: "Copy IDs",
      icon: "icon-[lucide--copy]",
      function: () => {
        const items = Array.from(app.canvas.selectedItems || []);
        const ids = items.map(item => item.id).filter(id => id !== undefined);
        
        if (ids.length > 0) {
          navigator.clipboard.writeText(ids.join(', '));
          app.extensionManager.toast.add({
            severity: "success",
            summary: "Copied",
            detail: `Copied ${ids.length} IDs to clipboard`,
            life: 2000
          });
        }
      }
    },
    {
      id: "selection-tools.log-types",
      label: "Log Types",
      icon: "icon-[lucide--info]",
      function: () => {
        const items = Array.from(app.canvas.selectedItems || []);
        const typeCount = {};
        
        items.forEach(item => {
          const type = item.type || 'unknown';
          typeCount[type] = (typeCount[type] || 0) + 1;
        });
        
        console.log("Selection types:", typeCount);
      }
    }
  ],
  
  getSelectionToolboxCommands: (selectedItem) => {
    const selectedItems = app.canvas.selectedItems;
    const itemCount = selectedItems ? selectedItems.size : 0;
    
    if (itemCount === 0) return [];
    
    const commands = ["selection-tools.count", "selection-tools.log-types"];
    
    // Only show copy command if items have IDs
    const hasIds = Array.from(selectedItems).some(item => item.id !== undefined);
    if (hasIds) {
      commands.push("selection-tools.copy-ids");
    }
    
    return commands;
  }
});
```

## Примечания

- Панель инструментов выделения должна быть включена в настройках: `Comfy.Canvas.SelectionToolbox`
- Команды должны быть определены в массиве `commands`, прежде чем на них ссылаться в `getSelectionToolboxCommands`
- Панель инструментов обновляется автоматически при изменении выделения
- Метод `getSelectionToolboxCommands` вызывается для каждого элемента набора выделения при каждом новом выделении
- Используйте `app.canvas.selectedItems` (Set), чтобы получить доступ ко всем выбранным элементам, включая узлы, группы и другие элементы холста
- Для обратной совместимости `app.canvas.selected_nodes` по-прежнему существует, но содержит только узлы
