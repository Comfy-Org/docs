API вкладок боковой панели позволяет расширениям добавлять пользовательские вкладки в боковую панель интерфейса ComfyUI. Это полезно для добавления функций, которым требуются постоянная видимость и быстрый доступ.

## Базовое использование

```javascript
app.extensionManager.registerSidebarTab({
  id: "customSidebar",
  icon: "icon-[lucide--compass]",
  title: "Custom Tab",
  tooltip: "My Custom Sidebar Tab",
  type: "custom",
  render: (el) => {
    el.innerHTML = '<div>This is my custom sidebar content</div>';
  }
});
```

## Настройка вкладки

Для каждой вкладки нужно указать несколько свойств:

```javascript
{
  id: string,              // Уникальный идентификатор вкладки
  icon: string,            // Класс иконки для кнопки вкладки
  title: string,           // Текст заголовка вкладки
  tooltip?: string,        // Текст подсказки при наведении (необязательно)
  type: string,            // Тип вкладки (обычно "custom")
  render: (element) => void // Функция, заполняющая содержимое вкладки
}
```

Функция `render` получает DOM-элемент, в который нужно вставить содержимое вкладки.

## Параметры иконок

Иконки вкладок боковой панели используют классы иконок [Lucide](https://lucide.dev/icons/) в формате
`icon-[lucide--<icon-name>]` (например, `icon-[lucide--compass]`).

Frontend генерирует эти классы при сборке, поэтому доступны только те иконки Lucide, которые
использует сам frontend. Если иконка не отображается, выберите другую
иконку или определите собственный класс иконки в таблице стилей, которую загружает ваше расширение.

Классы PrimeIcons (`pi pi-*`) и Material Design Icons (`mdi mdi-*`) пока
отображаются, но постепенно выводятся из использования. Не используйте их в новом коде. См.
[Миграция после удаления PrimeVue](/ru/custom-nodes/js/primevue-removal-migration).

## Пример вкладки с сохранением состояния

Вы можете создавать вкладки, которые сохраняют состояние:

```javascript
app.extensionManager.registerSidebarTab({
  id: "statefulTab",
  icon: "icon-[lucide--list]",
  title: "Notes",
  type: "custom",
  render: (el) => {
    // Create elements
    const container = document.createElement('div');
    container.style.padding = '10px';
    
    const notepad = document.createElement('textarea');
    notepad.style.width = '100%';
    notepad.style.height = '200px';
    notepad.style.marginBottom = '10px';
    
    // Load saved content if available
    const savedContent = localStorage.getItem('comfyui-notes');
    if (savedContent) {
      notepad.value = savedContent;
    }
    
    // Auto-save content
    notepad.addEventListener('input', () => {
      localStorage.setItem('comfyui-notes', notepad.value);
    });
    
    // Assemble the UI
    container.appendChild(notepad);
    el.appendChild(container);
  }
});
```

## Использование компонентов React

Вы можете монтировать компоненты React во вкладках боковой панели:

```javascript
// Импортируйте зависимости React в своём расширении
import React from "react";
import ReactDOM from "react-dom/client";

// Зарегистрируйте вкладку боковой панели с содержимым React
app.extensionManager.registerSidebarTab({
  id: "reactSidebar",
  icon: "icon-[lucide--blocks]",
  title: "React Tab",
  type: "custom",
  render: (el) => {
    const container = document.createElement("div");
    container.id = "react-sidebar-container";
    el.appendChild(container);
    
    // Определите простой компонент React
    function SidebarContent() {
      const [count, setCount] = React.useState(0);
      
      return (
        <div style={{ padding: "10px" }}>
          <h3>React Sidebar</h3>
          <p>Count: {count}</p>
          <button onClick={() => setCount(count + 1)}>
            Increment
          </button>
        </div>
      );
    }
    
    // Смонтируйте компонент React
    ReactDOM.createRoot(container).render(
      <React.StrictMode>
        <SidebarContent />
      </React.StrictMode>
    );
  }
});
```

Пример реального приложения React, интегрированного как вкладка боковой панели, вы найдёте в [проекте ComfyUI-Copilot на GitHub](https://github.com/AIDC-AI/ComfyUI-Copilot).

## Обновления динамического контента

Вы можете обновлять содержимое боковой панели в ответ на изменения графа:

```javascript
app.extensionManager.registerSidebarTab({
  id: "dynamicSidebar",
  icon: "icon-[lucide--activity]",
  title: "Stats",
  type: "custom",
  render: (el) => {
    const container = document.createElement('div');
    container.style.padding = '10px';
    el.appendChild(container);
    
    // Function to update stats
    function updateStats() {
      const stats = {
        nodes: app.graph._nodes.length,
        connections: Object.keys(app.graph.links).length
      };
      
      container.innerHTML = `
        <h3>Workflow Stats</h3>
        <ul>
          <li>Nodes: ${stats.nodes}</li>
          <li>Connections: ${stats.connections}</li>
        </ul>
      `;
    }
    
    // Initial update
    updateStats();
    
    // Listen for graph changes
    const api = app.api;
    api.addEventListener("graphChanged", updateStats);
    
    // Clean up listeners when tab is destroyed
    return () => {
      api.removeEventListener("graphChanged", updateStats);
    };
  }
});
```
