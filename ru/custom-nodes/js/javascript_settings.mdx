Вы можете передать ComfyUI объект настроек, который отобразится, когда пользователь откроет панель настроек ComfyUI.

## Основные операции

### Добавить настройку

```javascript
import { app } from "../../scripts/app.js";

app.registerExtension({
    name: "My Extension",
    settings: [
        {
            id: "example.boolean",
            name: "Example boolean setting",
            type: "boolean",
            defaultValue: false,
        },
    ],
});
```

Значение `id` должно быть уникальным среди всех расширений и будет использоваться для получения значений.

Если вы не [указываете категорию](#категории), то `id` будет разделён по символу `.`, чтобы определить, где он появится на панели настроек.

- Если ваш `id` не содержит ни одного `.`, он появится в категории «Other», а ваш `id` будет использоваться в качестве заголовка раздела.
- Если ваш `id` содержит хотя бы один `.`, то самая левая часть будет использоваться как категория настройки, а вторая часть будет использоваться как заголовок раздела. Остальные части игнорируются.


### Прочитать настройку

```javascript
import { app } from "../../scripts/app.js";

if (app.extensionManager.setting.get('example.boolean')) {
    console.log("Setting is enabled.");
} else {
    console.log("Setting is disabled.");
}
```

### Реагировать на изменения

Обработчик события `onChange()` будет вызван, как только пользователь изменит настройку на панели настроек.

Он также будет вызываться при регистрации расширения при каждой загрузке страницы.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Записать настройку

```javascript
import { app } from "../../scripts/app.js";

try {
    await app.extensionManager.setting.set("example.boolean", true);
} catch (error) {
    console.error(`Error changing setting: ${error}`);
}
```

### Дополнительная конфигурация

Каждый тип настройки отображает компонент формы фронтенда ComfyUI. Вы можете передать дополнительные пропсы этому компоненту в поле `attrs`. Пропсы, которые поддерживает каждый тип, перечислены в разделе [Типы](#типы).

Например, это ограничивает числовой ввод диапазоном и шагом:

```javascript
{
    id: "example.number",
    name: "Example number setting",
    type: "number",
    defaultValue: 0,
    attrs: {
        min: 0,
        max: 100,
        step: 5,
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```


Если ваше расширение передавало пропсы PrimeVue, такие как `showButtons`, `maxFractionDigits`, `editable` или `filter`, см. [Миграция после удаления PrimeVue](/ru/custom-nodes/js/primevue-removal-migration). Панель настроек больше не использует компоненты PrimeVue, поэтому эти пропсы ни на что не влияют.

## Типы

### Логический (Boolean)

Здесь показан переключатель вкл./выкл.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Text

Это свободный текст.

```javascript
{
    id: "example.text",
    name: "Example text setting",
    type: "text",
    defaultValue: "Foo",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Число

Это для ввода чисел.

Поле ввода всегда отображает кнопки увеличения и уменьшения. Поддерживаемые `attrs`:
`min`, `max`, `step` и `formatOptions`. `formatOptions` принимает
[`Intl.NumberFormatOptions`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat#options),
поэтому `maximumFractionDigits` управляет количеством отображаемых знаков после запятой.

```javascript
{
    id: "example.number",
    name: "Example number setting",
    type: "number",
    defaultValue: 42,
    attrs: {
        step: 0.1,
        formatOptions: { maximumFractionDigits: 1 },
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Слайдер

Это позволяет пользователю ввести число напрямую или с помощью ползунка.

Поддерживаемые `attrs`: `min`, `max` и `step`. Диапазоны не поддерживаются.

```javascript
{
    id: "example.slider",
    name: "Example slider setting",
    type: "slider",
    attrs: {
        min: -10,
        max: 10,
        step: 0.5,
    },
    defaultValue: 0,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Комбо

Это позволяет пользователю выбрать значение из раскрывающегося списка.

Вы можете передавать варианты либо как обычную строку, либо как объект с полями `text`
и `value`. Если вы передаёте только обычную строку, она будет использована
для обоих.

Вы можете разрешить пользователю искать по списку, указав атрибут `searchable: true`. Группы и свободный ввод текста не поддерживаются.

```javascript
{
    id: "example.combo",
    name: "Example combo setting",
    type: "combo",
    defaultValue: "first",
    options: [
        { text: "My first option", value: "first" },
        "My second option",
    ],
    attrs: {
        searchable: true,
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Цвет

Это позволяет пользователю выбрать цвет с помощью палитры цветов или ввести шестнадцатеричное значение.

Обратите внимание, что формат требует шесть полных шестнадцатеричных цифр (или восемь, с альфа-каналом). Сокращение
из трёх цифр не работает.

```javascript
{
    id: "example.color",
    name: "Example color setting",
    type: "color",
    defaultValue: "ff0000",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Изображение

Это позволяет пользователю загрузить изображение.

Настройка будет сохранена в виде [data URL](https://developer.mozilla.org/en-US/docs/Web/URI/Schemes/data).

```javascript
{
    id: "example.image",
    name: "Example image setting",
    type: "image",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Скрыто

Скрытые настройки не отображаются на панели настроек, но вы можете читать их и
записывать в них из своего кода.

```javascript
{
    id: "example.hidden",
    name: "Example hidden setting",
    type: "hidden",
}
```

## Прочее

### Категории

Вы можете указать категоризацию вашей настройки отдельно от `id`.
Это означает, что вы можете изменить категоризацию и название, не меняя
`id` и не теряя значения, которые уже были заданы пользователями.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    category: ["Category name", "Section heading", "Setting label"],
}
```

### Подсказки

Вы можете добавить дополнительную контекстную справку с помощью поля `tooltip`. Это добавляет маленький ℹ︎
значок после имени поля, который будет показывать текст справки, когда пользователь наводит
на него курсор.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    tooltip: "This is some helpful information",
}
```
