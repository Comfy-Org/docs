## Контекстные меню

### Меню фона

Основное фоновое меню (правый клик по холсту) генерируется вызовом
`LGraphCanvas.getCanvasMenuOptions`. Стандартный способ изменить это: реализовать метод `getCanvasMenuItems` в вашем расширении:

```javascript
app.registerExtension({
  name: "MyExtension",
  getCanvasMenuItems(canvas) {
    const items = []
    items.push(null) // вставляет разделитель
    items.push({
      content: "The text for the menu",
      callback: async () => {
        // выполните нужные действия
      }
    })
    return items
  }
});
```

### Меню узлов

При щелчке правой кнопкой мыши по узлу меню аналогичным образом формируется с помощью `node.getExtraMenuOptions`.
Стандартный способ: реализовать метод `getNodeMenuItems` в вашем расширении:

```javascript
app.registerExtension({
  name: "MyExtension",
  getNodeMenuItems(node) {
    const items = []

    // При необходимости можно фильтровать по типу узла
    if (node.comfyClass === "MyNodeClass") {
      items.push({
        content: "Do something fun",
        callback: async () => {
          // весёлая штука
        }
      })
    }

    return items
  }
});
```

### Подменю

Если вы хотите создать подменю, используйте свойство `submenu` с массивом `options`:

```javascript
app.registerExtension({
  name: "MyExtension",
  getCanvasMenuItems(canvas) {
    const items = []
    items.push({
      content: "Menu with options",
      submenu: {
        options: [
          {
            content: "option 1",
            callback: (v) => {
              // сделать что-то с v
            }
          },
          {
            content: "option 2",
            callback: (v) => {
              // сделать что-то с v
            }
          },
          {
            content: "option 3",
            callback: (v) => {
              // сделать что-то с v
            }
          }
        ]
      }
    })
    return items
  }
});
```

## Захват событий интерфейса

Это работает так, как вы и ожидаете: найдите элемент интерфейса в DOM и
добавьте eventListener. `setup()` хорошо подходит для этого, так как страница
уже полностью загружена. Например, чтобы отследить клик по кнопке «Queue»:

```Javascript
function queue_button_pressed() { console.log("Queue button was pressed!") }
document.getElementById("queue-button").addEventListener("click", queue_button_pressed);
```

## Обнаружение запуска рабочего процесса

Это одно из многих событий `api`:

```javascript
import { api } from "../../scripts/api.js";
/* in setup() */
    function on_execution_start() { 
        /* do whatever */
    }
    api.addEventListener("execution_start", on_execution_start);
```

## Обнаружение прерванного рабочего процесса

<Note>
**Устарело:** Показанный ниже шаблон перехвата API устарел и может быть изменён в любой момент в ближайшем будущем. Используйте официальные [хуки расширений](/ru/custom-nodes/js/javascript_hooks) и прослушиватели событий API, где они доступны.
</Note>

Простой пример перехвата api:

```Javascript
import { api } from "../../scripts/api.js";
/* in setup() */
    const original_api_interrupt = api.interrupt;
    api.interrupt = function () {
        /* Do something before the original method is called */
        original_api_interrupt.apply(this, arguments);
        /* Or after */
    }
```

## Перехват кликов по вашему узлу

<Note>
**Устарело:** Паттерн перехвата методов узла, показанный ниже, устарел и может быть изменён в любой момент в ближайшем будущем. Используйте официальные [хуки расширений](/ru/custom-nodes/js/javascript_hooks), где они доступны.
</Note>

У метода `node` есть mouseDown, который можно перехватить.
На этот раз мы аккуратно передаём возвращаемое значение дальше.

```javascript
async nodeCreated(node) {
    if (node?.comfyClass === "My Node Name") {
        const original_onMouseDown = node.onMouseDown;
        node.onMouseDown = function( e, pos, canvas ) {
            alert("ouch!");
            return original_onMouseDown?.apply(this, arguments);
        }        
    }
}
```
