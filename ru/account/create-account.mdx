Ваш аккаунт Comfy даёт доступ к [партнёрским узлам (Partner Node)](/ru/tutorials/partner-nodes/overview) и [облачным подпискам](https://www.comfy.org/cloud), позволяя использовать премиальные функции и сервисы платформы ComfyUI.

## Создать аккаунт Comfy в Comfy Cloud

Вы можете создать аккаунт Comfy для ComfyUI прямо в Comfy Cloud:

1. Перейдите на [Comfy Cloud](https://www.comfy.org)
2. Нажмите **Sign up** или **Create account**
3. Выберите один из следующих способов входа:
   - **Email**: введите адрес электронной почты и создайте пароль
   - **Google**: зарегистрируйтесь с помощью аккаунта Google
   - **GitHub**: зарегистрируйтесь с помощью аккаунта GitHub
4. Завершите регистрацию
5. Подтвердите электронную почту, если регистрировались через неё

## Создать аккаунт Comfy локально

Если ComfyUI установлен локально, вы можете создать аккаунт Comfy через приложение:

1. Откройте ComfyUI на своём компьютере
2. Перейдите в раздел **Settings** в интерфейсе
3. Откройте раздел **User** (подробнее см. [User settings](/ru/interface/user))
4. Нажмите **Create account** или **Sign up**
5. Выберите один из следующих способов входа:
   - **Email**: введите адрес электронной почты и создайте пароль
   - **Google**: зарегистрируйтесь с помощью аккаунта Google
   - **GitHub**: зарегистрируйтесь с помощью аккаунта GitHub
6. Завершите регистрацию

## Дальнейшие шаги

После создания и подтверждения аккаунта:
- [Войдите в свой аккаунт](/ru/account/login)
- Настройте параметры профиля
- Начните использовать функции ComfyUI
- Изучите учебники и документацию

## Устранение неполадок

Если у вас возникли проблемы при создании аккаунта:
- Убедитесь, что адрес электронной почты действителен и ещё не зарегистрирован
- Проверьте, что пароль соответствует минимальным требованиям
- Очистите кэш браузера и попробуйте снова
- Если проблемы сохраняются, обратитесь в [поддержку](/ru/support/contact-support)
