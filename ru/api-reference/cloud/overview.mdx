<Warning>
  **Экспериментальное API:** Это API является экспериментальным и может измениться. Конечные точки, форматы запросов и ответов, а также поведение могут быть изменены без предупреждения.
</Warning>

Cloud API предоставляет программный доступ к запуску рабочих процессов на инфраструктуре Comfy Cloud.

<Note>
  **Требуется подписка:** Доступ к API предоставляется на тарифах **Standard**, **Creator** и **Pro**. Бесплатный тариф не включает доступ к API. Подробности см. в разделе [тарифные планы](https://www.comfy.org/cloud/pricing?utm_source=docs).
</Note>

## Категории конечных точек

| Категория | Описание |
|----------|-------------|
| Workflow | Отправка рабочих процессов на выполнение |
| Job | Отслеживание статуса задач и управление очередью |
| Asset | Загрузка и скачивание файлов |
| Model | Просмотр доступных моделей |
| Node | Получение информации о доступных узлах |
| User | Информация об аккаунте и личные данные |
| System | Статус сервера и проверки работоспособности |
