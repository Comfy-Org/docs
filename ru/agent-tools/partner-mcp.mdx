Comfy Partner MCP: локальный сервер MCP, который даёт AI-агентам единые инструменты генерации у **более чем 30 партнёрских провайдеров**, включая BFL, Ideogram, Kling, Runway, Veo, Meshy, ElevenLabs и других. Для всех типов генерации используется единая каноническая форма запроса.

**Ключевые возможности:**
- 🎨 **6 модальностей генерации**: изображение, видео, 3D, SVG, аудио и музыка
- 🔌 **Более 30 провайдеров** в одном интерфейсе
- 💻 **Локальный сервер**: работает на вашей машине и подключается к API Comfy
- 🔍 **Встроенный поиск моделей** с текстовым поиском BM25
- 🧩 **Полная совместимость** с Claude Desktop, Claude Code и Amp

---

## Требования

- **Node.js 20+**
- **pnpm 10**
- **[Comfy API-ключ](/ru/development/api-development/getting-an-api-key)** (начинается с `comfyui-`). Получите его в панели управления партнёра Comfy.

---

## Установить

```bash
git clone <repo-url> partner-mcp
cd partner-mcp
pnpm install
pnpm build
```

После сборки лаунчер сервера MCP находится по пути `packages/mcp/dist/bin.js`.

---

## Настройка

Добавьте сервер в конфигурацию вашего MCP-клиента. Один и тот же формат JSON работает в Claude Desktop, Claude Code и Amp:

```json
{
  "mcpServers": {
    "comfy-partner": {
      "command": "node",
      "args": ["/ABSOLUTE/PATH/TO/partner-mcp/packages/mcp/dist/bin.js"],
      "env": {
        "COMFY_API_KEY": "comfyui-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX"
      }
    }
  }
}
```

**Расположение файлов конфигурации клиентов:**

| Клиент | Файл конфигурации |
|--------|-------------------|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) / `%APPDATA%/Claude/claude_desktop_config.json` (Windows) |
| Claude Code | `~/.claude/mcp.json` (или выполните `claude mcp add`) |
| Amp | Настройки → MCP Servers, или `~/.config/amp/settings.json` |

После добавления конфигурации перезапустите MCP-клиент. Вы должны увидеть **10 инструментов**, зарегистрированных на сервере `comfy-partner`.

Чтобы проверить, что сервер запускается корректно до подключения к клиенту, запустите его напрямую. Он должен вывести рукопожатие JSON-RPC, после чего перейдёт в режим ожидания:

```bash
COMFY_API_KEY=comfyui-... node /ABSOLUTE/PATH/TO/partner-mcp/packages/mcp/dist/bin.js
```

## Переменные среды

| Переменная | Обязательно | Назначение |
|----------|----------|---------|
| `COMFY_API_KEY` | да | API-ключ (`comfyui-…`). Передаётся в заголовке `X-API-Key`. |
| `COMFY_API_BASE_URL` | нет | Переопределяет хост прокси (по умолчанию используется production Comfy API). |
| `COMFY_INLINE_LIMIT_KB` | нет | Ограничение (КБ) на встраивание байтов изображения в результаты инструмента. По умолчанию `600`. |
| `COMFY_MCP_RESOURCE_LINKS` | нет | Принудительно включает или отключает блоки содержимого `resource_link`. По умолчанию используется список разрешённых (`claude-*`, `mcp-inspector`). |

## Доступные инструменты

MCP-сервер предоставляет **10 инструментов**. После успешной установки ваш MCP-клиент должен показать все 10, зарегистрированные на сервере `comfy-partner`.

| Инструмент | Описание |
|------|-------------|
| `generate_image` | Генерировать статичные изображения: текст в изображение, редактирование или upscale |
| `generate_video` | Генерировать видеоклипы: текст в видео, изображение в видео или lipsync |
| `generate_3d` | Генерировать 3D-сетки (GLB/FBX/OBJ) по тексту или референсному изображению |
| `generate_svg` | Генерировать векторные иллюстрации SVG по текстовому промпту |
| `generate_audio` | Генерировать речь, клоны голоса или звуковые эффекты по тексту |
| `generate_music` | Генерировать инструментальную или вокальную музыку по промпту |
| `media_upload` | Загрузить файл (изображение/видео/аудио) и получить ссылку `media:<id>` для использования в вызовах `generate_*` |
| `read_media` | Получить и отобразить медиафайл прямо в ответе: принимает HTTPS-URL или токен `media:…` |
| `models_explore` | Находить модели, выполнять поиск по возможностям и читать полную форму вызова модели |
| `balance` | Получить остаток баланса текущего аккаунта в USD |
