## Выберите вариант установки

Вам нужна учётная запись Comfy.

- **Comfy Cloud:** Comfy Agent общедоступен. [Войти в Cloud](https://cloud.comfy.org). Локальная установка и список ожидания не требуются.
- **Comfy Desktop:** Comfy Agent для локального ComfyUI скоро будет. [Присоединяйтесь к списку ожидания](https://links.comfy.org/agentalpha), чтобы получить уведомление.

## Создать первое изображение

### Открыть Agent

Откройте пустой рабочий процесс, затем выберите **Agent** в крайней правой части панели вкладок, рядом с вашим аватаром. Прочитайте уведомление о согласии и примите его, если появится запрос. В панели Agent используйте **Choose a workflow**, чтобы выбрать пустой рабочий процесс.

### Собрать рабочий процесс

Отправьте это сообщение:

> Создайте рабочий процесс «текст в изображение» для красного кроссовка на нейтральном сером фоне. Используйте доступную модель и включите узел Save Image. Проверьте рабочий процесс на ошибки, но пока не запускайте его.

Agent создаёт рабочий процесс на холсте, заполняет промпт и настройки модели, а также проверяет соединения узлов и обязательные входы. Вы должны увидеть рабочий процесс, в котором все узлы соединены и который заканчивается узлом **Save Image**.

Если Agent сообщает об отсутствующей модели или файле, предоставьте их или попросите альтернативу, доступную в вашей установке. Попросите его снова проверить рабочий процесс, прежде чем продолжить.

### Сгенерировать изображение

Откройте **Run permissions** рядом с полем сообщения, выберите **Ask** и нажмите **Save changes**, если вы изменили эту настройку.

Отправьте «Запустите этот рабочий процесс». Когда Agent запросит подтверждение, выберите **Run**. Если вы не хотите начинать этот запуск, вместо этого выберите **Cancel**.

Когда генерация завершится, Agent вернёт результат в диалоге. Изображение также появится в узле **Save Image**. Щёлкните по изображению там правой кнопкой мыши, чтобы сохранить его на компьютер.

### Внести изменение

Отправьте «Измените фон на белый и оставьте модель и другие настройки». Agent обновляет существующий рабочий процесс. Попросите Agent запустить рабочий процесс ещё раз, чтобы сравнить результат.

## Устранение неполадок

### Кнопка Агент отсутствует

Войдите в свою учётную запись Comfy. В Comfy Desktop [обновите приложение](/ru/installation/update_comfyui) и перезапустите его. Если кнопка по-прежнему отсутствует, проверьте доступ к Агенту для своей учётной записи через [поддержку](/support/contact-support).

### Агент не редактирует нужный рабочий процесс

Выберите нужный рабочий процесс на панели Агента, затем отправьте сообщение снова. См. [Выбор рабочего процесса для редактирования](/ru/agent-tools/in-app-agent#выбрать-рабочий-процесс-для-редактирования).

### Агент запрашивает вход

Выберите **Прикрепить файл** или перетащите запрошенный файл в поле сообщения, затем попросите Агента продолжить.

### Не удаётся найти локальный диалог в Cloud

Локальная история и история Cloud хранятся отдельно. См. [Данные и конфиденциальность](/ru/agent-tools/in-app-agent-data-privacy#история-чатов-и-синхронизация).
