[comfy-cli](https://github.com/Comfy-Org/comfy-cli) это инструмент командной строки Comfy. Наряду с [MCP-серверами](/ru/agent-tools) он даёт агентам и разработчикам ещё один способ управлять Comfy вне интерфейса.

Используйте его для **доступа из терминала или скриптов**: пакетные задания, CI-пайплайны, автоматизация рабочих процессов и работа вместе с агентами программирования через встроенные навыки CLI.

<Info>
  **Краткая справка для агентов.** Эта страница представляет собой сокращённый обзор: его достаточно, чтобы сориентироваться вместе с MCP и выполнить типичные вызовы `comfy generate`. Полную **документацию по CLI** (локальная установка, `comfy setup`, `comfy run`, шаблоны, редактирование рабочих процессов, поиск узлов и моделей и многое другое) см. в разделе [Начало работы с Comfy CLI](/ru/comfy-cli/getting-started).
</Info>

## Как это сочетается с MCP

| | Comfy MCP (cloud) | Comfy CLI |
|---|---|---|
| **Интерфейс** | Общение с MCP-клиентом (Claude Code, Claude Desktop, …) | Команды терминала и скрипты |
| **Лучше всего подходит для** | Интерактивные рабочие процессы агента в чате | Автоматизация, пакетные запуски, CI, конвейеры командной оболочки |
| **Аутентификация** | OAuth в MCP-клиентах или API-ключ (headless) | `comfy cloud login` (OAuth) или API-ключ (CI) |
| **Вывод** | Возвращается в сеансе чата | Сохраняется на диск (`--download`) или в JSON (`--json`) |

Настройка MCP, установка, списки инструментов и методы аутентификации описаны в разделе [Comfy MCP](/ru/agent-tools/mcp).

## Что делает CLI

1. **Локальный ComfyUI**: установка, запуск, обновление и управление пользовательскими узлами
2. **Генерация через партнёров**: `comfy generate` для одноразовых вызовов Партнёрского API генерации изображений, видео, аудио и 3D
3. **Облачные рабочие процессы**: `comfy run`, шаблоны, редактирование слотов и отслеживание задач в Comfy Cloud

## Доступные модели

`comfy generate` охватывает партнёрские модели для изображений и видео. Узнать, что доступно в вашей версии CLI:

```bash
comfy generate list                            # все модели
comfy generate list --category text-to-video   # фильтровать по категории
comfy generate list --partner kling            # фильтровать по партнёру
comfy generate schema flux-kontext             # параметры для одной модели
```

Распространённые псевдонимы:

| Категория | Примеры |
|---|---|
| **Изображения** | `flux-pro`, `flux-ultra`, `flux-kontext`, `nano-banana`, `grok`, `grok-edit`, `ideogram-edit`, `dalle`, `recraft`, `stability` |
| **Видео** | `seedance`, `kling`, `luma`, `runway`, `pika`, `vidu`, `hailuo`, `moonvalley`, `grok-video` |

Выполните `comfy generate list`, чтобы увидеть полный набор в вашем окружении.

## За пределами `comfy generate`

Всё, что описано выше, представляет собой краткую сводку для агентов. Полное руководство подробно разбирает каждую команду:

- `comfy run`, `comfy jobs` и `comfy validate` для полных рабочих процессов
- `comfy templates` и редактирование слотов в `comfy workflow`
- Обзор `comfy nodes` и `comfy models`
- Конверты `--json` и `comfy --json discover` для агентов

→ [Начало работы с Comfy CLI](/ru/comfy-cli/getting-started) (полная документация)
