## Что такое MCP?

**Model Context Protocol (MCP)** — это открытый стандарт, который позволяет ИИ-ассистентам взаимодействовать с внешними инструментами и сервисами через стандартизованный интерфейс. Вместо того чтобы ИИ-агент знал собственные форматы API для каждого сервиса, MCP даёт единый способ предоставления инструментов.

Когда вы подключаете MCP-сервер к Claude Desktop, Claude Code, Cursor или Amp, ИИ-ассистент может:

- **Генерировать изображения** по текстовым описаниям
- **Создавать видео** из текста или изображений
- **Генерировать 3D-модели** из текста или изображений
- **Генерировать аудио и музыку** с помощью ИИ-моделей
- **Искать модели и шаблоны**, чтобы найти подходящие инструменты для вашей задачи

...и всё это через обычный разговор на естественном языке, без ручного написания вызовов API.
