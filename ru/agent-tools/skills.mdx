[**Comfy Skills**](https://github.com/Comfy-Org/comfy-skills) объединяет навыки и плагины для агентов программирования. Навыки представляют собой упакованные знания, которые агент загружает по запросу: рекомендации по моделям, шаблоны рабочих процессов и готовые команды.

В репозитории представлены:

- **Плагины Claude Code**: например **comfy-cloud**, который добавляет подключение Comfy Cloud MCP и слэш-команды `/comfy-cloud:*` за одну установку.
- **Навыки агентов**: специализированные инструкции для конкретных задач, например актуальные рекомендации по моделям и практические приёмы построения рабочих процессов, которые поддерживаются в актуальном состоянии по мере изменения моделей.
- **Вклад сообщества**: навыки и плагины от сообщества Comfy.

Чтобы использовать репозиторий в Claude Code:

```
/plugin marketplace add Comfy-Org/comfy-skills
/plugin install comfy-cloud@comfy-skills
```

Слэш-команды плагина и подробности настройки см. в [Comfy MCP](/ru/agent-tools/mcp).
