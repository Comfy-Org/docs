## Пути конфигурации

Начиная с V3.38, Менеджер использует защищённый системный путь для повышения безопасности.

| Версия ComfyUI | Путь Менеджера |
|-----------------|--------------|
| v0.3.76+ (с System User API) | `<USER_DIRECTORY>/__manager/` |
| Более старые версии | `<USER_DIRECTORY>/default/ComfyUI-Manager/` |

<Note>
Если запустить без параметров, путь `<USER_DIRECTORY>` по умолчанию равен `ComfyUI/user`. Его можно задать с помощью `--user-directory <USER_DIRECTORY>`.
</Note>

### Файлы конфигурации

| Файл | Описание |
|------|-------------|
| `config.ini` | Базовая конфигурация |
| `channels.list` | Настраиваемые списки каналов |
| `pip_overrides.json` | Пользовательские сопоставления пакетов pip |
| `pip_blacklist.list` | Пакеты, установку которых нужно блокировать |
| `pip_auto_fix.list` | Пакеты для автоматического восстановления |
| `snapshots/` | Сохранённые файлы снимков |
| `startup-scripts/` | Файлы скриптов запуска |
| `components/` | Файлы компонентов |

## Параметры Config.ini

Измените файл `config.ini`, чтобы применить настройки. Путь отображается в сообщениях журнала при запуске.

```ini
[default]
git_exe = <path to git executable>
use_uv = <True/False - use uv instead of pip>
default_cache_as_channel_url = <True/False - retrieve DB designated as channel_url at startup>
bypass_ssl = <True/False - disable SSL if errors occur>
file_logging = <True/False - create log file>
windows_selector_event_loop_policy = <True/False - fix event loop errors on Windows>
model_download_by_agent = <True/False - use agent for model downloads>
downgrade_blacklist = <comma-separated list of packages to prevent downgrades>
security_level = <strong|normal|normal-|weak>
always_lazy_install = <True/False - perform dependency installation on restart>
network_mode = <public|private|offline>
```

### Режимы сети

| Режим | Описание |
|------|-------------|
| `public` | Стандартная публичная сетевая среда |
| `private` | Закрытая сеть с приватной базой данных узлов, настроенной через `channel_url` (используется кэш, если он доступен) |
| `offline` | Нет внешних подключений (используется кэш, если он доступен) |

### Уровни безопасности

| Уровень | Описание |
|-------|-------------|
| `strong` | Не допускает использования функций высокого и среднего уровня риска |
| `normal` | Не допускает функций высокого уровня риска; функции среднего уровня доступны |
| `normal-` | Не допускает функций высокого уровня риска, если указан `--listen` и он не начинается с `127.`; функции среднего уровня доступны |
| `weak` | Все функции доступны |

#### Уровни риска функций

| Уровень риска | Функции |
|------------|----------|
| **Высокий** | Установка по URL git, pip install, установка пользовательских узлов не из канала по умолчанию, исправление пользовательских узлов |
| **Средний** | Удаление/обновление, установка пользовательских узлов из канала по умолчанию, восстановление/удаление снимка, перезапуск |
| **Низкий** | Обновить ComfyUI |

## Переменные среды

| Переменная | Описание |
|----------|-------------|
| `COMFYUI_PATH` | Путь установки ComfyUI |
| `GITHUB_ENDPOINT` | Обратный прокси для доступа к GitHub |
| `HF_ENDPOINT` | Обратный прокси для доступа к Hugging Face |

### Примеры

Перенаправление запросов GitHub через прокси:
```bash
GITHUB_ENDPOINT=https://mirror.ghproxy.com/https://github.com
```

Изменение эндпоинта Hugging Face:
```bash
HF_ENDPOINT=https://some-hf-mirror.com
```

## Расширенная конфигурация

### Предотвратить понижение версии определённых пакетов

Перечислите названия пакетов в разделе `downgrade_blacklist` файла `config.ini`, разделяя их запятыми:

```ini
downgrade_blacklist = diffusers, kornia
```

### Пользовательское сопоставление pip

Создайте файл `pip_overrides.json`, чтобы заменить установку определённых pip-пакетов на пользовательские. Формат описан в `pip_overrides.json.template`.

### Предотвратить установку определённых pip-пакетов

Перечислите названия пакетов по одному в строке в файле `pip_blacklist.list`.

### Автоматически восстанавливать установку pip

Перечислите требования pip в `pip_auto_fix.list` (аналогично `requirements.txt`). Указанные версии будут автоматически восстанавливаться при запуске ComfyUI или при несоответствии версий во время установки пользовательских узлов. Можно использовать `--index-url`.

### Использовать aria2 в качестве загрузчика

Для более быстрой загрузки можно настроить ComfyUI-Manager на использование aria2. См. [руководство по настройке aria2](https://github.com/Comfy-Org/ComfyUI-Manager/blob/main/docs/en/use_aria2.md).

## Настройка extra_model_paths.yaml

Следующие настройки применяются на основе раздела, отмеченного как `is_default`:

- `custom_nodes`: путь для установки пользовательских узлов
- `download_model_base`: путь для загрузки моделей

## Инструменты CLI

ComfyUI-Manager предоставляет `cm-cli`: инструмент командной строки, который позволяет использовать возможности Менеджера без запуска ComfyUI. Это удобно для автоматизации установки пользовательских узлов и управления установками в средах без графического интерфейса.

Подробная документация по cm-cli приведена в [официальном руководстве по cm-cli](https://github.com/Comfy-Org/ComfyUI-Manager/blob/main/docs/en/cm-cli.md).

Для более широких возможностей работы с CLI можно использовать [comfy-cli](/comfy-cli/getting-started).
