## Распространённые проблемы

### Пользовательский путь к исполняемому файлу git

Если ваш `git.exe` установлен в определённом месте, отличном от системного по умолчанию:

1. Установите ComfyUI-Manager и запустите ComfyUI один раз
2. Откройте `<USER_DIRECTORY>/default/ComfyUI-Manager/config.ini`
3. Укажите полный путь, включая имя файла, в `git_exe =`

```ini
git_exe = C:\Program Files\Git\bin\git.exe
```

### Сбой обновления ComfyUI-Manager

Если обновление самого ComfyUI-Manager завершается ошибкой, перейдите в каталог ComfyUI-Manager и выполните:

Если обновление самого ComfyUI-Manager завершается ошибкой, перейдите в каталог ComfyUI-Manager и выполните:

```bash
git update-ref refs/remotes/origin/main a361cc1 && git fetch --all && git pull
```

### Windows: ошибка Overlapped Object

Если вы столкнулись с ошибкой `Overlapped Object has pending operation at deallocation on ComfyUI Manager load`:

Отредактируйте `config.ini` и добавьте:

```ini
windows_selector_event_loop_policy = True
```

### Не удалось проверить SSL-сертификат

Если вы столкнулись с ошибкой `SSL: CERTIFICATE_VERIFY_FAILED`:

Отредактируйте `config.ini` и добавьте:

```ini
bypass_ssl = True
```

## Проблемы установки

### Неверный путь установки

Файлы ComfyUI-Manager должны находиться в `ComfyUI/custom_nodes/comfyui-manager`.

**Частые ошибки, которых следует избегать:**

| Проблема | Описание |
|-------|---------|
| Файлы не в том месте | Файлы менеджера, такие как `__init__.py`, размещены прямо в каталоге `custom_nodes` |
| Двойная вложенность папок | Установлено как `custom_nodes/ComfyUI-Manager/ComfyUI-Manager` |
| Неверное имя папки | Установлено как `custom_nodes/ComfyUI-Manager-main` |
| Сжатый формат | Установка из сжатого файла без правильной распаковки |

<Warning>
При неверной установке ComfyUI-Manager может казаться рабочим, но не будет распознаваться для обновлений и может привести к дублированию установок. Удалите его и переустановите правильно через `git clone`.
</Warning>

## Проблемы с сетью

### Проблемы с доступом к GitHub

Если у вас ограниченный доступ к GitHub, задайте переменную окружения `GITHUB_ENDPOINT`:

```bash
GITHUB_ENDPOINT=https://mirror.ghproxy.com/https://github.com
```

### Проблемы с доступом к Hugging Face

Если у вас ограниченный доступ к Hugging Face, задайте переменную окружения `HF_ENDPOINT`:

```bash
HF_ENDPOINT=https://some-hf-mirror.com
```

## Устранение неполадок сканера

При запуске скрипта `scan.sh`:

- Он обновляет `extension-node-map.json`, загружая или клонируя пользовательские узлы, перечисленные в `custom-node-list.json`, в `~/.tmp/default`
- Он обновляет `github-stats.json` с помощью API GitHub

| Параметр | Описание |
|--------|-------------|
| `--skip-update` | Пропустить обновление extension-node-map.json |
| `--skip-stat-update` | Пропустить обновление github-stats.json |
| `--skip-all` | Пропустить оба шага обновления |

<Tip>
Чтобы избежать ограничений частоты запросов к API GitHub, задайте свой токен: `export GITHUB_TOKEN=your_token_here`
</Tip>

Если вы хотите указать другой путь вместо `~/.tmp/default`, запустите `python scanner.py [path]` напрямую вместо `scan.sh`.

## Политика безопасности

Если при установке пользовательских узлов по git URL или при использовании ночной версии вы получаете ошибку `This action is not allowed with this security level configuration`, необходимо изменить уровень безопасности в файле `config.ini`.

Файл `config.ini` расположен по пути:
- **ComfyUI v0.3.76+**: `<USER_DIRECTORY>/__manager/config.ini`
- **Более старые версии**: `<USER_DIRECTORY>/default/ComfyUI-Manager/config.ini`

По умолчанию `<USER_DIRECTORY>` указывает на `ComfyUI/user`. Подробнее см. в разделе [Конфигурация](/ru/manager/configuration).

Настройте уровни безопасности в `config.ini`:

```ini
security_level = normal
```

| Уровень | Описание |
|-------|-------------|
| `strong` | Не разрешает функции высокого и среднего уровня риска |
| `normal` | Не разрешает функции высокого уровня риска; функции среднего уровня доступны |
| `normal-` | Не разрешает функции высокого уровня риска, если указан `--listen` и адрес не начинается с `127.`; функции среднего уровня доступны |
| `weak` | Доступны все функции |

### Уровни риска функций

| Уровень риска | Функции |
|------------|----------|
| **Высокий** | Установка по git URL, pip install, установка пользовательских узлов не из канала по умолчанию, исправление пользовательских узлов |
| **Средний** | Удаление/обновление, установка пользовательских узлов из канала по умолчанию, восстановление/удаление snapshot, перезапуск |
| **Низкий** | Обновить ComfyUI |

<Tip>
Чтобы устанавливать пользовательские узлы по git URL или ночные версии, задайте `security_level = weak` в файле `config.ini`.
</Tip>
