## Частые проблемы

### Пользовательский путь к исполняемому файлу git

Если `git.exe` установлен не в стандартном месте, а в другом каталоге:

1. Установите ComfyUI-Manager и запустите ComfyUI один раз
2. Откройте `<USER_DIRECTORY>/default/ComfyUI-Manager/config.ini`
3. Укажите полный путь вместе с именем файла в `git_exe =`

```ini
git_exe = C:\Program Files\Git\bin\git.exe
```

### Не удаётся обновить ComfyUI-Manager

Если обновление самого ComfyUI-Manager завершается ошибкой, перейдите в каталог ComfyUI-Manager и выполните:

```bash
git update-ref refs/remotes/origin/main a361cc1 && git fetch --all && git pull
```

### Windows: ошибка Overlapped Object

Если появляется сообщение `Overlapped Object has pending operation at deallocation on ComfyUI Manager load`:

Отредактируйте `config.ini` и добавьте:

```ini
windows_selector_event_loop_policy = True
```

### Ошибка проверки SSL-сертификата

Если появляется ошибка `SSL: CERTIFICATE_VERIFY_FAILED`:

Отредактируйте `config.ini` и добавьте:

```ini
bypass_ssl = True
```

## Проблемы установки

### Неверный путь установки

Файлы ComfyUI-Manager должны находиться в `ComfyUI/custom_nodes/comfyui-manager`.

**Распространённые ошибки, которых следует избегать:**

| Ошибка | В чём проблема |
|-------|---------|
| Файлы в неправильном месте | Файлы менеджера, например `__init__.py`, размещены прямо в каталоге `custom_nodes` |
| Двойная вложенность папок | Установлено как `custom_nodes/ComfyUI-Manager/ComfyUI-Manager` |
| Неправильное имя папки | Установлено как `custom_nodes/ComfyUI-Manager-main` |
| Сжатый формат | Установка из архива без правильной распаковки |

<Warning>
При неправильной установке ComfyUI-Manager может выглядеть работающим, но не будет распознаваться для обновлений и может привести к дублирующим установкам. Удалите его и переустановите правильно через `git clone`.
</Warning>

## Проблемы с сетью

### Проблемы с доступом к GitHub

Если доступ к GitHub ограничен, задайте переменную среды `GITHUB_ENDPOINT`:

```bash
GITHUB_ENDPOINT=https://mirror.ghproxy.com/https://github.com
```

### Проблемы с доступом к Hugging Face

Если доступ к Hugging Face ограничен, задайте переменную среды `HF_ENDPOINT`:

```bash
HF_ENDPOINT=https://some-hf-mirror.com
```

## Устранение неполадок сканера

При запуске скрипта `scan.sh`:

- Он обновляет `extension-node-map.json`, загружая или клонируя пользовательские узлы, перечисленные в `custom-node-list.json`, в `~/.tmp/default`.
- Он обновляет `github-stats.json` с помощью GitHub API.

| Параметр | Описание |
|--------|-------------|
| `--skip-update` | Пропустить обновление extension-node-map.json |
| `--skip-stat-update` | Пропустить обновление github-stats.json |
| `--skip-all` | Пропустить оба шага обновления |

<Tip>
Чтобы избежать ограничений частоты запросов к GitHub API, задайте свой токен: `export GITHUB_TOKEN=your_token_here`
</Tip>

Если вы хотите указать другой путь вместо `~/.tmp/default`, запустите `python scanner.py [path]` напрямую вместо `scan.sh`.

## Политика безопасности

Если при установке пользовательских узлов по git URL или при использовании ночной версии вы получаете ошибку `This action is not allowed with this security level configuration`, необходимо изменить уровень безопасности в файле `config.ini`.

Файл `config.ini` находится по пути:
- **ComfyUI v0.3.76+**: `<USER_DIRECTORY>/__manager/config.ini`
- **Более ранние версии**: `<USER_DIRECTORY>/default/ComfyUI-Manager/config.ini`

По умолчанию `<USER_DIRECTORY>` равно `ComfyUI/user`. Подробнее см. в разделе [Конфигурация](/ru/manager/configuration).

Настройте уровни безопасности в `config.ini`:

```ini
security_level = normal
```

| Уровень | Описание |
|-------|-------------|
| `strong` | Не разрешает функции с высоким и средним уровнем риска |
| `normal` | Не разрешает функции с высоким уровнем риска; функции со средним уровнем доступны |
| `normal-` | Не разрешает функции с высоким уровнем риска, если указан параметр `--listen` и адрес не начинается с `127.`; функции со средним уровнем доступны |
| `weak` | Доступны все функции |

### Уровни риска функций

| Уровень риска | Функции |
|------------|----------|
| **Высокий** | Установка по git url, pip install, установка пользовательских узлов не из канала по умолчанию, исправление пользовательских узлов |
| **Средний** | Удаление/обновление, установка пользовательских узлов из канала по умолчанию, восстановление/удаление снимка, перезапуск |
| **Низкий** | Обновление ComfyUI |

<Tip>
Чтобы устанавливать пользовательские узлы по git URL или использовать ночные версии, задайте `security_level = weak` в файле `config.ini`.
</Tip>

Если проблемы всё ещё сохраняются:

1. Проверьте [issues ComfyUI-Manager на GitHub](https://github.com/Comfy-Org/ComfyUI-Manager/issues) на наличие похожих проблем
2. Просмотрите сообщения журнала запуска, чтобы найти детали ошибок
3. Присоединяйтесь к [ComfyUI Discord](https://discord.com/invite/comfyorg), чтобы получить поддержку сообщества
