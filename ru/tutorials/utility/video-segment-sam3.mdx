[SAM 3](https://ai.meta.com/sam3) (Segment Anything Model 3) — это унифицированная фундаментальная модель Meta для сегментации по промптам в изображениях и видео. Она умеет обнаруживать, сегментировать и отслеживать объекты с помощью текстовых или визуальных промптов, таких как точки, рамки и маски. По сравнению с предшественницей [SAM 2](https://github.com/facebookresearch/sam2) в SAM 3 появилась возможность исчерпывающе сегментировать все экземпляры концепции из открытого словаря, заданной короткой текстовой фразой.

[SAM 3.1 Multiplex](https://github.com/facebookresearch/sam3) — это последний релиз чекпойнта, в котором появился подход с общей памятью для совместного отслеживания нескольких объектов: значительно быстрее без потери точности.

SAM 3.1 нативно поддерживается в ComfyUI (PR [#13408](https://github.com/Comfy-Org/ComfyUI/pull/13408)), а веса модели доступны на условиях [лицензии SAM](https://github.com/facebookresearch/sam3/blob/main/LICENSE).

[SAM 3 GitHub](https://github.com/facebookresearch/sam3) | [Статья (arXiv)](https://arxiv.org/abs/2604.02296) | [🤗 Хаб моделей](https://huggingface.co/Comfy-Org/sam3.1)

SAM 3.1 сегментирует и отслеживает объекты по кадрам видео на основе текстовых промптов. В примере выше показан результат сегментации с масками, наложенными на целевые объекты на протяжении всего видео.

### Ключевые преимущества

- **Сегментация по тексту**: опишите, что нужно сегментировать, на естественном языке, без ручной разметки точками и рамками
- **Работа с изображениями и видео**: поддерживаются как отдельные изображения, так и видеопоследовательности с отслеживанием по кадрам
- **Несколько объектов**: сегментируйте и отслеживайте несколько объектов одновременно с помощью промптов, разделённых запятыми
- **Открытый словарь**: охватывает значительно более широкий набор концепций открытого словаря, чем предыдущие работы

> **Ограничения:** максимальный лимит токенов для текстовых промптов у модели составляет 32. Для лучших результатов делайте промпты короткими и конкретными относительно целевого объекта.

### 3. Использование рабочих процессов

**Сегментация изображений:**

- **Изображение**: загрузите изображение через узел `Load Image` (поместите его в папку `input/` ComfyUI)
- **Промпт объекта**: короткое текстовое описание объекта(ов) для сегментации, например `person`, `car`, `cat`
- На выходе получается маска, применённая к изображению, с предпросмотром в RGBA, показывающим результат сегментации

**Сегментация видео:**

- **Видео**: загрузите видео через узел `Load Video`
- **Промпт объекта**: то же, что и для изображения: короткий текстовый промпт с описанием того, что нужно отслеживать и сегментировать по кадрам
- На выходе получаются маски и ограничивающие рамки для каждого кадра

**Формат промпта:**

| Промпт | Роль |
|--------|------|
| Промпт объекта SAM3 | Короткое описание того, **что** сегментировать. Не более 32 токенов. |

Чтобы задать промпты для нескольких субъектов отдельно, разделите их запятыми и укажите `:N`, чтобы ограничить количество объектов, обнаруживаемых для каждого промпта:
`eye:2, window panels:4`

## Дополнительные примечания

- **Оставляйте промпты короткими и конкретными**: модель имеет ограничение в 32 токена на промпт
- **Детекция нескольких объектов**: разделяйте разные типы объектов запятыми, а `:N` ограничивает число детекций для каждого типа
- **Маски сегментации**: выходную маску можно использовать как вход для других рабочих процессов (например, инпейтинг, удаление фона)
- **Обязательно обновить**: убедитесь, что ComfyUI обновлён до последней версии, чтобы получить поддержку SAM 3.1
