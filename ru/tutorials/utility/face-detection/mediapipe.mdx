[MediaPipe](https://github.com/google-ai-edge/mediapipe) представляет собой открытое решение Google для машинного обучения в задачах восприятия в реальном времени. В ComfyUI MediaPipe Face Detection обеспечивает детекцию **BlazeFace**, оценку ключевых точек **FaceMesh v2** и blendshapes **ARKit-52** в едином рабочем процессе.

MediaPipe Face Detection поддерживается в ComfyUI нативно (PR [#14009](https://github.com/Comfy-Org/ComfyUI/pull/14009)), а веса модели доступны по [лицензии Apache 2.0](https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE).

[MediaPipe GitHub](https://github.com/google-ai-edge/mediapipe) | [Репозиторий моделей Comfy-Org](https://huggingface.co/Comfy-Org/mediapipe)

### Ключевые возможности

- **Быстрая детекция лиц**: детектор на основе BlazeFace с вариантами малого (~2 м) и полного (~5 м) диапазона
- **478 точек лица**: плотные ключевые точки FaceMesh v2 для каждого обнаруженного лица
- **Blendshapes ARKit-52**: коэффициенты мимики в реальном времени
- **Маски областей лица**: маски для овала лица, губ, глаз и радужки
- **Ограничивающие рамки лиц**: выходы совместимы с `DrawBBoxes` для визуализации рамок

> **Область применения:** только детекция лиц: BlazeFace + FaceMesh v2 + blendshapes ARKit. Здесь не рассматриваются детекция рук, позы и holistic-детекция.

### 1. Скачать рабочий процесс

Обновите ComfyUI до последней версии, затем перейдите в `Workflow` → `Browse Templates` и найдите «Mediapipe: Image Face Detection» в категории Utility.

### 2. Скачать модель

Модель MediaPipe Face Detection размещена в [репозитории моделей Comfy-Org MediaPipe](https://huggingface.co/Comfy-Org/mediapipe).

- [mediapipe_face_fp32.safetensors](https://huggingface.co/Comfy-Org/mediapipe/blob/main/detection/mediapipe_face_fp32.safetensors)

Поместите её в следующую структуру каталогов:

```
📂 ComfyUI/
└── 📂 models/
    └── 📂 detection/
        └── mediapipe_face_fp32.safetensors
```

### 3. Использовать рабочий процесс

Этот рабочий процесс использует узел **подграфа**, который управляет детекцией лиц, визуализацией и генерацией маски. Подграф предоставляет следующие элементы управления:

<Card title="Подробнее о подграфе" icon="book-open" href="/ru/interface/features/subgraph">
  В этом рабочем процессе узлы подграфа используются для модульной обработки. Ознакомьтесь с документацией по подграфам, чтобы узнать, как настроить и расширить рабочий процесс.
</Card>

**Входы подграфа:**

| Вход | Описание |
|-------|-------------|
| **image** | Пакет входных изображений для анализа |
| **face_landmarker** | Необязательно. Оставьте пусто, чтобы использовать встроенный загрузчик модели. Подключите внешний выход `FACE_DETECTION_MODEL`, чтобы переопределить его |

**Параметры подграфа:**

| Параметр | По умолчанию | Описание |
|-----------|:-------:|-------------|
| **model_name** | `mediapipe_face_fp32.safetensors` | Чекпойнт в `ComfyUI/models/detection/`. Если он отсутствует, скачайте модель выше |
| **detector_variant** | `short` | **short**: настроен на близкие/крупные лица (диапазон ~2 м). **full**: охватывает меньшие/более далёкие лица (~5 м), работает медленнее. **both**: запускает оба детектора и оставляет тот результат, где найдено больше лиц на кадр (затраты ~2×) |
| **num_faces** | `1` | Максимальное число лиц, возвращаемых на кадр. `0` = без ограничения (вернуть все обнаруженные). Диапазон: 0–16 |
| **custom_face_oval** | `false` | Включать область контура лица в выходную маску |
| **custom_lips** | `false` | Включать губы в маску (объединение с другими включёнными областями) |
| **custom_left_eye** | `false` | Включать область левого глаза в маску |
| **custom_right_eye** | `false` | Включать область правого глаза в маску |
| **custom_irises** | `false` | Включать области радужки в маску |

Переключатели маски внутренне используют пользовательский режим: заполняются только отмеченные области; если включено несколько областей, они **объединяются** в одну маску на кадр.

**Выходы подграфа:**

| Выход | Тип | Описание |
|--------|------|-------------|
| **face_landmarks** | `FACE_LANDMARKS` | Лица по кадрам с 478 2D/3D ориентирами, blendshapes ARKit-52 и данными топологии сетки. Передаётся в узлы визуализации и маски |
| **bboxes** | `BOUNDING_BOX` | Ограничивающие рамки лиц: совместимы с узлом `DrawBBoxes` |
| **mask** | `MASK` | Бинарная маска из включённых переключателей областей |

### 4. Запустить рабочий процесс

1. Убедитесь, что файл модели находится в `ComfyUI/models/detection/`
2. Загрузите изображение в узле `Load Image`
3. Настройте параметры детекции по необходимости
4. Нажмите `Queue` или используйте `Ctrl(Cmd) + Enter` для запуска
5. Рабочий процесс выводит перекрытие сетки, ограничивающие рамки и предпросмотр маски
