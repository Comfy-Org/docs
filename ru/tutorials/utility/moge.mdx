# Введение в ComfyUI MoGe

[MoGe](https://github.com/microsoft/MoGe) (CVPR 2025, Microsoft Research) представляет собой мощную модель для восстановления 3D-геометрии по монокулярным изображениям произвольных сцен. Она оценивает метрические карты точек, метрические карты глубины, карты нормалей и угол обзора камеры: всё за один прямой проход.

Ключевые возможности:

- **Точная оценка 3D-геометрии**: карты точек, карты глубины и карты нормалей из одного изображения: одна модель, один прямой проход
- **Метрический масштаб** (MoGe-2, MoGe-3): карты точек и карты глубины в реальном масштабе
- **Гибкая поддержка разрешения**: работает с различными разрешениями и соотношениями сторон (от 2:1 до 1:2)
- **Быстрый вывод**: ~60 мс на изображение на A100 / RTX 3090 (FP16, ViT-L)
- **Генерация сетки** как для перспективных, так и для панорамных изображений

ComfyUI поставляется с чекпойнтами для трёх версий MoGe:

| Файл | Версия | Метрический масштаб | Карты нормалей | Параметры |
|------|---------|:------------:|:-----------:|:-----:|
| `moge_1_vitl_fp16` | **MoGe-1** | - | - | 314M |
| `moge_2_vitl_normal_fp16` | **MoGe-2** | ✅ | ✅ | 331M |
| `moge_3_vitl_fp16` | **MoGe-3** | ✅ | ✅ | 370M |
| `moge_3_vitg_fp16` | **MoGe-3** | ✅ | ✅ | 1.25B |

> MoGe-2 добавляет метрический масштаб и высококачественную оценку карт нормалей с более резкими визуальными деталями и меньшей задержкой вывода. **MoGe-2 с нормалями (`moge_2_vitl_normal_fp16`) является рекомендуемым чекпойнтом.**
>
> MoGe-3 сохраняет архитектуру MoGe-2 и добавляет этап самоуправляемого разреженного объёмного уточнения (self-guided sparse volumetric refinement), что значительно улучшает мелкодетализированную геометрию карт точек. Он поставляется как чекпойнт ViT-L (`moge_3_vitl_fp16`) и более крупный чекпойнт ViT-g (`moge_3_vitg_fp16`).

<UpdateReminder/>

<Tip>
ComfyUI теперь нативно поддерживает узлы MoGe. Перед началом убедитесь, что вы обновили [ComfyUI](https://github.com/Comfy-Org/ComfyUI) до последней версии.

Сгенерированные модели в формате `.glb` будут сохранены в папку `ComfyUI/output/mesh`.
</Tip>

## Установить модель

Скачайте чекпойнт(ы) MoGe и сохраните их в соответствующую папку ComfyUI:

- **MoGe-2 (рекомендуется)**: [moge_2_vitl_normal_fp16.safetensors](https://huggingface.co/Comfy-Org/MoGe/blob/main/geometry_estimation/moge_2_vitl_normal_fp16.safetensors)
- **MoGe-1 (базовый)**: [moge_1_vitl_fp16.safetensors](https://huggingface.co/Comfy-Org/MoGe/blob/main/geometry_estimation/moge_1_vitl_fp16.safetensors)
- **MoGe-3 (максимальная детализация)**: [moge_3_vitg_fp16.safetensors](https://huggingface.co/Comfy-Org/MoGe/blob/main/geometry_estimation/moge_3_vitg_fp16.safetensors) (1.25B) или [moge_3_vitl_fp16.safetensors](https://huggingface.co/Comfy-Org/MoGe/blob/main/geometry_estimation/moge_3_vitl_fp16.safetensors) (370M)

```
ComfyUI/
├── models/
│   ├── geometry_estimation/
│   │   ├── moge_2_vitl_normal_fp16.safetensors
│   │   ├── moge_1_vitl_fp16.safetensors
│   │   ├── moge_3_vitg_fp16.safetensors
│   │   └── moge_3_vitl_fp16.safetensors
```

Только для чекпойнтов MoGe-3: узлы `Run MoGe Inference` и `Run MoGe Panorama Inference` предоставляют расширенный элемент управления `refine_steps` (от 0 до 8, по умолчанию 3), который выполняет разреженные объёмные проходы уточнения по предсказанной глубине. `0` отключает уточнение, а большее число проходов повышает резкость мелких деталей и рёбер при примерно линейных затратах. Чекпойнты MoGe-1 и MoGe-2 игнорируют этот параметр.

### 1.1 Шаги запуска

1. Убедитесь, что в узле `LoadMoGeModel` загружен чекпойнт MoGe.
2. Загрузите изображение в узле `Load Image`.
3. Нажмите `Queue` или используйте `Ctrl(cmd) + Enter`, чтобы запустить рабочий процесс.
4. Рабочий процесс выводит цветной предпросмотр глубины, исходный предпросмотр глубины и маску.

### MoGe 3: оценка геометрии {#utility_moge3_geometry_estimation}

Оценивайте мелкодетализированную геометрию по одному изображению с помощью MoGe 3. Чекпойнты MoGe-3 переносят грубую карту точек на разреженную воксельную оболочку и уточняют глубину с помощью лёгких разреженных 3D-свёрток, что сохраняет тонкие структуры и разрывы глубины, которые размывают декодеры в пространстве изображения.

### 4.1 Шаги запуска

1. Убедитесь, что в подграфе `Geometry Estimation (MoGe 3)` выбран чекпойнт MoGe 3: шаблон поставляется с `moge_3_vitg_fp16.safetensors`, а `moge_3_vitl_fp16.safetensors` доступен в том же раскрывающемся списке
2. Загрузите изображение в узле `Load Image`
3. (Необязательно) Измените `output` на узле подграфа, чтобы отобразить другую карту: `mask` используется по умолчанию, другие варианты: `depth`, `depth_colored`, `normal_opengl` и `normal_directx`
4. Нажмите `Queue` или используйте `Ctrl(cmd) + Enter`, чтобы запустить
