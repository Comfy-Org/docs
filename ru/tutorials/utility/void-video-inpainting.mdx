VOID (Video Object Inpainting and Deletion) представляет собой мощную модель инпейтинга видео с открытым исходным кодом от Netflix. Она использует двухпроходный diffusion-пайплайн на основе [CogVideoX](https://github.com/THUDM/CogVideo), чтобы удалять объекты из видео и заполнять образовавшиеся пустоты временно согласованным содержимым.

VOID удаляет объекты вместе со **всеми взаимодействиями, которые они вызывают в сцене**: не только вторичными эффектами вроде теней и отражений, но и физическими взаимодействиями, например падением предметов при удалении человека. Например, если удалить человека, держащего гитару, VOID также убирает влияние этого человека на гитару, и она падает естественно.

VOID нативно поддерживается в ComfyUI (PR [#13403](https://github.com/Comfy-Org/ComfyUI/pull/13403)), а полные веса модели доступны по [лицензии Apache 2.0](https://github.com/Netflix/void-model?tab=Apache-2.0-1-ov-file).

[VOID Model - GitHub](https://github.com/Netflix/void-model) | [Статья (arXiv)](https://arxiv.org/abs/2604.02296) | [🤗 Diffusers Pipeline](https://huggingface.co/netflix/void-model)

**ДО** (слева): оригинальные кадры со сноубордистом. **ПОСЛЕ** (справа): результат обработки после удаления сноубордиста из сцены. VOID удаляет нежелательные объекты, сохраняя естественное движение, освещение и целостность сцены от кадра к кадру.

### Ключевые преимущества

- **Удаление с учётом взаимодействий**: удаляет не только сам объект, но и все физические взаимодействия, которые он вызвал в сцене (тени, отражения, падающие предметы)
- **Удаление объекта**, а не заплатка на одном кадре: обеспечивает согласованное движение и освещение на всём клипе
- **Двухпроходное уточнение**: проход 2 обеспечивает лучшую временную стабильность (меньше дрожания и вспышек) по сравнению с одним только проходом 1, особенно на длинных фрагментах и текстурированных фонах

> **Ограничения:** нечёткие маски, хаотичное движение или объекты, занимающие почти весь кадр, всё ещё могут давать неоптимальный результат. Промпт не исправит принципиально неверную сегментацию.

### 3. Использование рабочего процесса

**Входы:**

- **Исходное видео**: загрузите видео через узел `Load Video` (поместите его в папку `input/` в ComfyUI)
- **Позитивный промпт (заполнение при инпейтинге)**: опишите сцену **после** удаления. Сосредоточьтесь на том, что осталось и как это выглядит, а не на том, что было удалено
  - Пример: `empty kitchen counter, daylight, tiles visible`
- **Негативный промпт**: необязательный список для борьбы с артефактами; можно оставить пустым
- **Промпт объекта для SAM3**: короткая метка того, **что** нужно замаскировать. SAM3 использует семантическое понимание, чтобы создать маску сегментации для целевого объекта.
  - Пример: `person in blue jacket`, `red cup on table`
  - Максимум токенов для промптов SAM3: **32**. Чтобы задать несколько объектов по отдельности, разделяйте их запятыми и используйте `:N`, чтобы указать максимальное число обнаруженных объектов на один промпт: `eye:2, window panels:4`

**Режимы:**

| Промпт | Роль |
|--------|------|
| Объект SAM3 | **Что** удаляется (SAM3 создаёт маску с помощью семантической сегментации) |
| Позитив (инпейтинг) | **Как** заполняется вырезанная область во времени |

Используйте **Pass 2** (проход уточнения) для длинных клипов или текстурных фонов, где важна временная стабильность. Один **Pass 1** быстрее, но может давать больше дрожания.

## Дополнительные примечания

- **Качество маски важно**: чистая и точная маска вокруг целевого объекта даёт наилучший результат
- **Совет по составлению промпта**: описывайте сцену так, как она должна выглядеть _естественно_ после удаления, а не само удаление
- **Используйте негативный промпт** только если видите повторяющиеся дефекты (водяные знаки, размытие, лишние конечности)
- **Рабочий процесс из двух проходов**: шаблон автоматически выполняет Pass 1, затем Pass 2; можно также запускать только Pass 1 для более быстрых итераций при тестировании
