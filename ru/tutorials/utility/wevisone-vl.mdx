WeVisOne-VL это компактная визуально-языковая модель, которая отвечает формами, а не текстом. Передайте ей изображение и короткий текстовый запрос, и она вернёт боксы, точки или альфа-матту для каждого экземпляра за один проход: без аннотаций и без промптинга для каждого объекта.

В ComfyUI модель работает как узел **WeVisOne-VL Detect**. Шаблон ниже оборачивает её в подграф и показывает превью матты, боксов, нарисованных поверх исходного изображения, а также вырезанных переднего и заднего планов, так что матту можно сразу использовать в цепочке удаления фона, маскирования или композиционирования.

Веса взяты из релизов Tencent под лицензией Apache-2.0 и перепакованы для ComfyUI в [Comfy-Org/WeVisOne-VL](https://huggingface.co/Comfy-Org/WeVisOne-VL). Поддержка появилась в [ComfyUI #17632](https://github.com/Comfy-Org/ComfyUI/pull/17632), а для шаблона требуется ComfyUI 0.45.0 или более поздняя версия.

## Сегментация изображений: WeVisOne-VL {#utility_image_segment_wevisone_vl}

## Задачи

Виджет `task` переписывает ваш запрос в инструкцию, на которой обучался чекпойнт. Каждая задача принимает запрос в немного разной форме:

| `task` | Форма запроса | Возвращает |
| :--- | :--- | :--- |
| `segmentation` | Одна короткая именная фраза, например `human` | Альфа-маска и коробки (одна общая маска, если `individual_masks` не включён) |
| `detection` | По одной метке на строку | Только коробки |
| `referring` | Описывающая фраза, например `the cup on the left` | Коробки |
| `point` | По одной метке на строку | Центральные точки в формате JSON |
| `count_box` | Объект для подсчёта | Количество, с коробкой на каждом экземпляре |
| `count_point` | Объект для подсчёта | Количество, с точкой на каждом экземпляре |
| `ocr` | Ничего | Коробка на каждом слове на изображении |
| `ocr_grounding` | Точная строка для поиска | Коробка вокруг этой строки |
| `visual_prompt` | Ничего, используется вход `bboxes` | Коробки для объектов, похожих на референсные коробки |
| `freeform` | Что угодно | Необработанный ответ, в котором запрос составляет весь промпт |

Оставляйте запрос коротким. Полное предложение заставляет `segmentation` выдавать лишнее, а фраза, называющая объект, работает лучше, чем его описание.

## Больше контроля над узлом

- **`individual_masks`**: включено, одна маска на каждую коробку; выключено, одна объединённая маска на кадр
- **`max_length`**: ограничение длины ответа, по умолчанию 4096 токенов и до 32768
- **Выходы**: `masks`, `bboxes`, `points` (JSON с полями x, y, label и frame) и `text` (необработанный ответ)
