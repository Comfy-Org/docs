Marigold V2 представляет собой семейство моделей монокулярной оценки от Huawei Bayer Lab. Эти модели адаптируют diffusion transformer (Qwen-Image Edit 2509) для оценки геометрии и intrinsic-свойств изображения. По одному RGB-изображению модели предсказывают карту глубины, нормали поверхности или альбедо, продолжая оригинальный Marigold (CVPR 2024), в котором для той же задачи была адаптирована Stable Diffusion. Модели V2 поставляются как LoRA поверх общей базовой diffusion-модели, поэтому каждая загрузка остаётся небольшой, а структура рабочего процесса одинаковой для всех трёх задач.

По сравнению с классическими сетями оценки глубины подход на основе diffusion даёт чёткие предсказания, учитывающие границы, и обобщается на изображения из произвольных предметных областей без дообучения. Типичные применения: управление по карте глубины для генерации изображений и видео, конвейеры реконструкции 3D-сцен, переосвещение и редактирование материалов на основе оценённого альбедо.

Marigold V2 поддерживается в ComfyUI нативно. Перед началом работы обновите [ComfyUI](https://github.com/comfyanonymous/ComfyUI) до последней версии.

## Узел постобработки Marigold V2

Каждый рабочий процесс завершается узлом **Marigold V2 Post-Process**, который превращает сырое декодированное предсказание в изображение для просмотра. Значение параметра **prediction** должно соответствовать задаче:

- **depth**: нормализует предсказание так, чтобы близкие поверхности были светлыми
- **normals**: преобразует сырые значения в единичные нормали поверхности
- **albedo**: преобразует предсказание в sRGB
