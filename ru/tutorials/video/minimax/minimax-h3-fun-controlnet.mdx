Управляйте движением видео MiniMax H3 с помощью контрольного видео, а не только текста. Патч Fun ControlNet Union ([alibaba-pai/MiniMax-H3-Fun-Controlnet-Union](https://huggingface.co/alibaba-pai/MiniMax-H3-Fun-Controlnet-Union), упакованный в [Comfy-Org/MiniMax-H3](https://huggingface.co/Comfy-Org/MiniMax-H3)) представляет собой единый чекпойнт, который задаёт условие для H3 на основе контрольных видео Canny, Depth, HED, MLSD или Pose, а также выполняет инпейтинг видео с маской. Он работает с обоими файлами трансформера `fl2va` и `ref2va`.

Для этого шаблона требуется ComfyUI 0.35.0 или более поздняя версия. В примере используется контрольное видео позы: встроенный подграф SDPose извлекает скелет позы из входного видео, поэтому результат воспроизводит движения танцора. Вы также можете подключить любое предварительно обработанное контрольное видео напрямую ко входу `control_video` узла `Apply MiniMax H3 Fun ControlNet`.

## Советы по составлению промптов

1. **Длина видео**: Целевое видео длится от 5 до 15 секунд на сетке кадров 17n+5 при 24 кадрах/с (124 кадра = 5 секунд). Управляющее видео длиннее целевого обрезается до первых кадров; более короткое удерживает последний кадр. Чтобы длина точно совпадала с длиной управляющего видео, подключите вычисленный в примере выход `batch_size` ко входу длины узла `MiniMax H3 Reference to Video`
2. **Направление и сила**: Оставляйте `guidance_scale` равным 1.0. Повышайте `strength` патча выше 1, только если результат отклоняется от управляющего сигнала
3. **Инпейтинг видео**: Подключите маску ко входу `mask`: области, отмеченные `1`, создаются заново под управлением необязательного входа `source_video`, а остальная часть кадра остаётся неизменной
4. **Режим Turbo (необязательно)**: Установите флажок **Lightning LoRA**, чтобы использовать 4-шаговую turbo LoRA для гораздо более быстрой генерации с немного более низким качеством аудио и движения
5. **Подготовка управляющих видео**: ComfyUI поставляется со встроенными узлами предварительной обработки для каждого типа управления. См. [узел Detect Edges (Canny)](https://docs.comfy.org/built-in-nodes/Canny) для рёбер и [учебник Depth Anything 3](https://docs.comfy.org/tutorials/utility/depth-anything-3) для карт глубины
