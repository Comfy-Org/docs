## Советы по промптам

1. **Ссылки по тегам**: `<Picture 1>` обозначает изображение, подключённое к первому слоту `ref_images`, `<Picture 2>` соответствует второму слоту и так далее. В этом рабочем процессе `<Picture 1>` одновременно фиксирует идентичность и служит первым кадром видео
2. **Привязки на таймлайне и ссылки**: изображения, подключённые только к узлам Add Guide, закрепляют композицию на определённых кадрах, но не видны текстовому энкодеру. Подключите их также к дополнительным слотам `ref_images`, если промпт должен видеть их как `<Picture N>`
3. **Индекс кадра**: каждый Add Guide принимает `frame_idx` в кадрах при 24fps; шаблон вычисляет его из секунд с помощью `round(seconds * 24)`. Отрицательные значения отсчитываются от конца видео. Индекс вместе с длиной направляющей должен оставаться в пределах сгенерированной длительности
4. **Добавьте больше ключевых кадров**: скопируйте один блок направляющей (Load Image + Frame Index + Math Expression + Add Guide for MiniMax H3) и оставьте выходы `positive` соединёнными последовательно в Basic Guider
5. **Режим Turbo (необязательно)**: включите флажок **Lightning LoRA**, чтобы использовать 4-шаговый turbo LoRA для значительно более быстрой генерации с немного более низким качеством аудио и движения

## Руководство по написанию промптов

Промпт из шаблона составлен по [руководству по промптам для режима full-reference](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md): в нём описан каждый субъект, каждый `<Picture N>` привязан к первому кадру или ключевому кадру определённого плана, а переходы между планами заданы явными метками времени. Используйте ту же структуру, когда пишете собственные промпты с несколькими планами. Руководство кратко изложено в разделе [руководство по промптам](/ru/tutorials/video/minimax/minimax-h3-prompt-guide).
