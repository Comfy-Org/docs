**SCAIL-2** представляет собой сквозную модель анимации персонажей, построенную на Wan2.1. Она управляет референсным изображением персонажа с помощью управляющего видео, что позволяет как анимировать персонажа (персонаж выполняет движение), так и заменять персонажа в видео (подменять отслеживаемого человека в видео референсным персонажем).

**Ключевые возможности**:
- **Сквозная анимация персонажа**: статичным изображением персонажа управляет движение из управляющего видео
- **Два режима**: режим анимации (персонаж выполняет движение) и режим замены (подмена отслеживаемого человека референсным персонажем)
- **Поддержка длинных видео**: расширенная генерация по чанкам с перекрытием кадров между сегментами
- **Встроенные узлы ComfyUI**: используются нативные `WanSCAILToVideo`, `SCAIL2ColoredMask` и трекинг `SAM3`. Пользовательские узлы не нужны, достаточно стандартной загрузки моделей.

## Как работает рабочий процесс

В этом рабочем процессе используются два узла подграфа: подграф **Base** (первый сегмент) и подграф **Extend** (последующие сегменты). Это обеспечивает анимацию персонажа как для коротких, так и для длинных видео.

1. **Загрузите** управляющее видео (`pose_video`) и референсное изображение персонажа
2. **Подграф Base** обрабатывает первый сегмент (по умолчанию 81 кадр)
3. **Подграф Extend** обрабатывает дополнительные сегменты со 2-го и далее, связывая `previous_frames` из предыдущего сегмента
4. Просмотрите результат и сохраните его

### Длинные видео

Для более длинных видео рассчитайте количество сегментов: `ceil(total_frames / 76)`. Каждый сегмент, кроме первого, использует подграф Extend. Дублируйте узел Extend для дополнительных сегментов, свяжите выход `previous_frames` и увеличьте значение `segment_index`.

> **Примечание:** `WanSCAILToVideo` не может автоматически поставить в очередь все сегменты. Запускайте каждый сегмент вручную.

## Два режима

| Режим | `replace_mode` | Фон маски драйвера | Краткое описание |
|------|:--------------:|:---------------:|---------|
| **Замена** | `true` (по умолчанию) | Белый | Заменить отслеживаемого человека в управляющем видео на референс-персонажа |
| **Анимация** | `false` | Черный | Референс-персонаж выполняет движение из управляющего видео |

Установите параметр `replace_mode` на обоих узлах подграфа.

## Входы и параметры

### Общие параметры (Base и Extend)

| Параметр | Описание |
|-----------|-------------|
| `pose_video` | Управляющее видео, содержащее движение для переноса |
| `reference_image` | Изображение персонажа для анимации или вставки |
| `prompt` | Описание выходного видео |
| `replace_mode` | `true` = замена, `false` = анимация |
| `segment_index` | `1` для первого фрагмента, `2+` для продолжения. Смещение позы = `76 × (index − 1)` |
| `width` / `height` | Разрешение на выходе, например `896×512`. Должно делиться на 16 |
| `frame_count` | Количество кадров на сегмент (по умолчанию: 81) |
| `previous_frame_count` | Кадры перекрытия между сегментами (по умолчанию: 5) |
| `pose_strength` / `pose_start` / `pose_end` | Сила условия позы и время его применения |

### Трекинг SAM3 (два входа)

Входы `sam3_video_object` и `sam3_image_object` управляют трекингом масок SAM3, **а не** промптом вывода SCAIL-2. Они определяют, какие объекты отслеживаются для цветных масок:

| Вход | Цель | Выход |
|-------|--------|--------|
| `sam3_video_object` | Управляющее видео | `pose_video_mask` |
| `sam3_image_object` | Опорное изображение | `reference_image_mask` |

- Используйте текст на основе открытого словаря (по умолчанию: `human`)
- Используйте один и тот же термин, если объект совпадает на видео и на опорном изображении
- Используйте разные термины, если на видео и на опорном изображении нужен разный акцент (например, в сценах с большим числом объектов)
