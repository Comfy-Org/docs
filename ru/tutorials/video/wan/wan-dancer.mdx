Wan Dancer: это модель генерации танцевального видео по аудио, построенная на архитектуре Wan 2.2. Она использует иерархическую структуру с глобальной и локальной экспертными моделями для создания согласованных и выразительных танцевальных видео, синхронизированных с входной музыкой.

По референсному изображению персонажа и аудиодорожке Wan Dancer создаёт танцевальное видео, в котором персонаж выполняет движения, соответствующие ритму и стилю музыки. Глобальная модель отвечает за общую структуру танца и координацию тела, а локальная модель уточняет мелкие детали движения для естественного результата высокого качества.

## Ключевые особенности модели

- **Генерация танца под аудио**: создаёт танцевальные движения прямо из музыки без ручного кейфрейминга и захвата движения
- **Иерархическая структура**: двухэтапная архитектура (глобальная и локальная) для согласованного движения тела и детальной доработки движений
- **Синхронизация с музыкой**: танцевальные движения естественно выровнены по ритму и темпу входного аудио
- **Управление стилем**: настраиваемые стиль танца и амплитуда движений для творческого направления
- **Генерация длительностью в минуты**: создаёт длинные связные танцевальные видео с временной согласованностью на всём протяжении

## Обзор рабочего процесса

Рабочий процесс Wan Dancer принимает два входных данных: референсное изображение персонажа и аудиофайл. Он создает два выходных видео: глобальный предпросмотр, показывающий общую структуру танца, и финальный улучшенный результат с более детальной проработкой движения.

### 4. Инструкции по рабочему процессу

<Tip>
  Wan Dancer обрабатывает 149 кадров за один раз и требует значительного объёма VRAM. Рабочий процесс по умолчанию выдаёт 5-секундное видео. Перед запуском этого рабочего процесса убедитесь, что у вас есть GPU с достаточным объёмом VRAM.
</Tip>

1. **Загрузите референсное изображение**: используйте узел `Load Image`, чтобы загрузить изображение персонажа. Во входе по умолчанию используется `blue_dancer.png`.

2. **Загрузите аудиофайл**: используйте узел `Load Audio`, чтобы загрузить музыку или аудиодорожку. Во входе по умолчанию используется `wan_dancer_reference_audio.mp3`.

3. **Настройте параметры танца**:
   - `dance_style`: выберите стиль танца для выходного видео
   - `motion_amplitude`: управляйте интенсивностью танцевальных движений
   - `audio_duration`: установите значение, соответствующее длительности входного аудио
   - `final_duration`: выберите итоговую длительность выходного видео

4. **Настройте размеры выходного видео**:
   - `width` и `height`: задайте разрешение выходного видео. Выбирайте значения, соответствующие доступному объёму VRAM вашей GPU.

5. **Проверьте пути к моделям**: убедитесь, что виджеты выбора моделей указывают на правильные файлы моделей:
   - `global_model`: должен загружать `wan2.2_dancer_14b_global_fp8_scaled.safetensors`
   - `local_model`: должен загружать `wan2.2_dancer_14b_local_fp8_scaled.safetensors`
   - `lightning_lora`: должен загружать `lightx2v_I2V_14B_480p_cfg_step_distill_rank64_bf16.safetensors`
   - `clip_vision`: должен загружать `clip_vision_h.safetensors`

6. **Запустите генерацию**: нажмите кнопку `Run` или используйте сочетание клавиш `Ctrl(Cmd) + Enter`, чтобы выполнить генерацию видео.

### 5. Выход

Рабочий процесс создаёт два выходных видео:
- **Предпросмотр глобального выхода**: показывает общую структуру танца, сгенерированную глобальной моделью
- **Итоговый выход**: улучшенное танцевальное видео после обработки локальной моделью

Оба выхода сохраняются автоматически с помощью узлов `SaveVideo`.
