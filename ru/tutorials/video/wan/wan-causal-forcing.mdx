**Causal Forcing** представляет собой технику генерации видео, в которой во время вывода применяется **рекуррентное условие**: каждый сгенерированный кадр подаётся обратно в модель для предсказания следующего кадра. Так из одного стартового изображения получаются плавные, темпорально согласованные видео всего за 1-4 шага вывода.

Этот рабочий процесс использует **Wan2.1** и поддерживает режимы **Causal Forcing** (стандартный) и **Causal Forcing++** (улучшенный).

## Как это работает

В отличие от стандартной генерации видео, которая обрабатывает все кадры параллельно, Causal Forcing рассматривает генерацию видео как **последовательный процесс**:

1. Модель принимает входное изображение как **первый кадр**
2. Она генерирует следующий кадр, используя предыдущий как условие
3. Каждый новый кадр становится входом для следующего предсказания
4. Это повторяется для нужного количества кадров

Такой рекуррентный подход обеспечивает **сильную временную согласованность**: каждый кадр естественно вытекает из предыдущего. Это позволяет получать высококачественные результаты при очень малом числе шагов вывода (от 1 до 4).

### Сравнение Causal Forcing и Causal Forcing++

| Режим | Описание |
|---|---|
| **Causal Forcing** | Стандартное рекуррентное условие. Хорошее качество при 2–4 шагах. |
| **Causal Forcing++** | Расширенный режим, который применяет дополнительное условие для лучшей временной согласованности. Хорошо работает даже при 1–2 шагах. |

## Использовать рабочий процесс

### Входы

Рабочий процесс принимает одно входное изображение (первый кадр) и текстовый промпт с описанием желаемого содержимого видео (необязательно).

| Параметр | Описание |
|---|---|
| **first_frame** (обязательно) | Начальное изображение для видео. Загрузите PNG/JPG через узел **LoadImage**. |
| **positive_prompt** (необязательно) | Текстовое описание желаемого содержимого видео. Оставьте пустым, чтобы не применять условие. |
| **duration** (необязательно) | Количество кадров для генерации. По умолчанию: количество кадров в ожидаемом выходе модели. |

### Параметры подграфа WAN I2V

Эти параметры отображаются как элементы управления на узле подграфа чертежа:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `unet_name` | - | Чекпойнт модели Wan2.1 I2V для использования |
| `clip_name` | - | Модель CLIP / текстового энкодера для промпта |
| `vae_name` | - | Модель VAE для кодирования/декодирования |
| `width` | - | Ширина выходного видео |
| `height` | - | Высота выходного видео |
| `noise_seed` | - | Сид для воспроизводимости |

## Шаги запуска

1. **Загрузите изображение**: используйте узел **LoadImage**, чтобы загрузить начальный кадр
2. **Напишите промпт** (необязательно): опишите желаемое содержимое видео
3. **Задайте длительность**: сколько кадров нужно сгенерировать
4. **Выберите модели**: выберите чекпойнт Wan2.1 I2V, CLIP и VAE
5. **Выберите режим**: Causal Forcing или Causal Forcing++ (задаётся во внутренней конфигурации подграфа или через вход, специфичный для Causal Forcing, если он доступен)
6. **Запустите**: кадры будут сгенерированы последовательно и сохранены в `ComfyUI/output/`
