# Знакомство с ComfyUI Bernini-R

[Bernini-R](https://github.com/bytedance/Bernini) это модель Wan 2.2 от ByteDance, которая работает **только как рендерер** и предназначена для передачи условий на основе изображений и видео в контексте. Она использует набор потоков условий (исходное видео, референсные изображения, референсное видео), чтобы направлять генерацию. Обучение LoRA или тонкая настройка не требуются.

Ключевые возможности:

- **Несколько типов задач в одной модели**: генерация изображений и видео, редактирование, изменение освещения, изменение стиля, вставка объектов
- **Условия в контексте**: референсные изображения и видео действуют как визуальные промпты и внедряются в виде токенов
- **Лёгкость**: модель работает только как рендерер, без диффузионной базовой модели для генерации видео по тексту.
- **Гибкая поддержка входов**: одно или несколько референсных изображений, видео в видео, редактирование по референсу

Bernini-R поддерживает следующие типы задач:

| Задача | Входы | Описание |
|------|--------|-------------|
| **t2v** | Текстовый промпт | Генерация видео по тексту |
| **v2v** | Исходное видео | Изменение стиля в режиме видео в видео |
| **rv2v** | Исходное видео + референсное изображение (изображения) | Редактирование видео по референсу (изменение освещения, вставка объектов) |
| **r2v** | Только референсное изображение (изображения) | Генерация видео по референсу |
| **img** | Исходное изображение + текстовый промпт | Редактирование изображения (изменение освещения, изменение стиля, вставка объектов) |
| **ads2v** | Исходное видео + референсное видео | Вставка изображения или видео в исходное видео |

<Tip>
ComfyUI теперь нативно поддерживает узлы Bernini-R. Перед началом убедитесь, что вы обновились до последней версии [ComfyUI](https://github.com/Comfy-Org/ComfyUI).
</Tip>

## Установка модели

Скачайте необходимые веса модели и сохраните их в соответствующие папки ComfyUI:

**text_encoders:**
- [umt5_xxl_fp8_e4m3fn_scaled.safetensors](https://huggingface.co/Comfy-Org/Wan_2.1_ComfyUI_repackaged/blob/main/split_files/text_encoders/umt5_xxl_fp8_e4m3fn_scaled.safetensors?download=true)

- [Wan2_1_VAE_bf16.safetensors](https://huggingface.co/Kijai/WanVideo_comfy/blob/main/Wan2_1_VAE_bf16.safetensors?download=true)

- [lightx2v_T2V_14B_cfg_step_distill_v2_lora_rank64_bf16.safetensors](https://huggingface.co/Kijai/WanVideo_comfy/blob/main/lightx2v_T2V_14B_cfg_step_distill_v2_lora_rank64_bf16.safetensors?download=true)

**diffusion_models:**
- [wan2.2_bernini_r_fp16.safetensors](https://huggingface.co/Comfy-Org/Bernini-R/blob/main/wan2.2_bernini_r_fp16.safetensors)

### Шаги запуска

1. **Выберите тип задачи**: укажите задачу (Image Editing, Subject to Image и т. д.).
2. **Подключите входы**: загрузите исходное изображение и при необходимости референсные изображения.
3. **Напишите промпт**: опишите желаемое изменение.
4. **Запустите**: нажмите «Очередь» или используйте `Cmd+Enter`.

**Вход референсного изображения:** используйте для **Subject to Image**, когда нужно одно или несколько референсных изображений (объект, одежда, сцена, реквизит). В промпте используйте `image0`, `image1`, …, чтобы ссылаться на каждое изображение. Не требуется для **Image Editing**: эта задача вместо этого использует `source_image`.

### Шаги запуска

1. **Загрузите исходное видео**: подключите входное видео
2. **(Необязательно) Загрузите референсы**: референсные изображения или референсное видео
3. **Выберите тип задачи**: v2v, rv2v, r2v или ads2v
4. **Напишите промпт**: опишите желаемое изменение
5. **Запустите**: нажмите Queue или используйте `Cmd+Enter`

**Вход Reference Image:** используется, когда задаче требуются одно или несколько референсных изображений (rv2v, r2v, комплекты одежды из нескольких предметов). Каждое изображение в пакете становится отдельным in-context токеном. Указывайте `image0`, `image1`, … в промпте, если референсы выполняют разные роли.
