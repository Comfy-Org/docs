**Mage-Flow** представляет собой компактный генеративный стек масштаба 4B от Microsoft Research для эффективной генерации изображений по тексту и редактирования изображений по инструкции. Стек построен из двух совместно спроектированных компонентов: [Mage-VAE](https://huggingface.co/microsoft/Mage-VAE), лёгкого высокоточного латентного токенизатора, и Native-Resolution Multimodal Diffusion Transformer (NR-MMDiT), обученного с помощью rectified flow matching. Вместе с упаковкой в нативном разрешении этот общий стек обеспечивает работу двух вариантов модели: Mage-Flow для генерации изображений по тексту и Mage-Flow-Edit для редактирования изображений по инструкции. Каждый поставляется в вариантах Base, RL-aligned и 4-step Turbo.

Mage-Flow поддерживает нативные разрешения от 512 до 2048 пикселей по каждой стороне при любом соотношении сторон, включая экстремальные значения, например 4:1.

### Генерация в один клик

В самом простом случае достаточно ввести текстовый промпт в подграфе, задать нужное разрешение и нажать **Queue Prompt**. Настройки по умолчанию позволяют получить качественное изображение при минимальной конфигурации.

### Как пользоваться рабочим процессом

1. **Введите промпт**: введите текстовое описание во вход промпта подграфа
2. **Задайте разрешение**: настройте ширину и высоту для нужного размера выходного изображения. Mage-Flow поддерживает нативные разрешения от 512 до 2048 пикселей по каждой стороне.
3. **Настройте параметры**: при необходимости задайте seed и негативный промпт
4. **Нажмите Queue**: нажмите `Ctrl+Enter`, чтобы запустить генерацию

Рабочий процесс редактирования изображений использует Mage-Flow-Edit, модель, управляемую инструкциями и редактирующую изображения с помощью описаний на естественном языке. Загрузите одно или несколько референсных изображений и опишите желаемое изменение.

Рабочий процесс состоит из нескольких частей:

1. **LoadImage**: загрузите референсные изображения (до 3)
2. **Подграф Image Edit (Mage-Flow-Edit)**: основной конвейер редактирования, включающий загрузку модели, conditioning референсных изображений, обработку промпта и выборку
3. **ImageCompare**: сравнение оригинала и отредактированного изображения бок о бок
4. **SaveImage**: сохраняет отредактированный результат

### Как отредактировать изображение

1. **Загрузите референсные изображения**: используйте узел **LoadImage**, чтобы загрузить изображение, которое хотите отредактировать (до 3 изображений)
2. **Введите инструкцию по редактированию**: введите текстовое описание изменения, которое хотите применить (например, «замените фон на пляжную сцену» или «превратите это в акварельный рисунок»)
3. **Настройте параметры**: задайте разрешение, seed и другие параметры
4. **Нажмите Queue**: нажмите `Ctrl+Enter`, чтобы сгенерировать результат
