**PiD (Pixel Diffusion Decoder)** превращает диффузионный **латент** в **изображение с 4-кратным увеличением разрешения** за 4 дистиллированных шага в пиксельном пространстве. Отдельное декодирование VAE не требуется. Этот рабочий процесс демонстрирует, как с помощью PiD увеличить латент Z-Image-Turbo с **1024px до 4096px**.

## Как работает PiD

PiD сопоставляет чекпойнты по **VAE / латентному пространству** исходной модели (сторона энкодера), а не только по имени модели диффузии. Нужно выбрать чекпойнт PiD, соответствующий латентному пространству модели, которая использовалась для первичной генерации.

В этом рабочем процессе используется **Z-Image-Turbo** (латент 1024px, выход 4096px), который использует тот же 16-канальный VAE, что и Flux.1.

### Настройки подграфа

Настройте эти параметры в подграфе **Latent Upscale Decode (PiD)**:

| Параметр | Значение | Описание |
|---|---|---|
| `latent_format` | `flux` | `flux` для Flux.1/Flux.2/Z-Image, `sd3` для SD3 (Flux.2 определяется автоматически по 128 каналам) |
| `degrade_sigma` | `0.0` | Насколько «завершён» входной латент. `0.0` для полностью выполненного denoise (по умолчанию), `0.1–0.8` для частичного denoise, `1.0` для чистого шума |

### Запустить рабочий процесс

1. **Сгенерируйте латент**. Используйте рабочий процесс T2I (например, Z-Image-Turbo), чтобы получить латентное изображение.
2. **Подключите к PiD**. Подайте латент на вход узла подграфа **Latent Upscale Decode (PiD)**.
3. **Выберите чекпойнт**. Выберите чекпойнт PiD, соответствующий латентному пространству VAE исходной модели.
4. **Задайте размер выхода**. Установите размер выхода PiD в **4x** от разрешения входного латента.
5. **Запустите**. Подграф выполняет декодирование и апскейл за один проход из 4 шагов.
