**Qwen-Image-2512** — это декабрьское обновление базовой модели Qwen-Image для генерации изображений по тексту. По сравнению с базовой моделью Qwen-Image, выпущенной в августе, Qwen-Image-2512 отличается значительными улучшениями качества и реалистичности изображений.

**Ключевые улучшения в Qwen-Image-2512**:
- **Повышенная реалистичность людей**: значительно снижает «сгенерированный ИИ» вид и существенно повышает общую реалистичность изображений, особенно для людей
- **Более тонкая детализация природы**: заметно более детальная прорисовка пейзажей, шерсти животных и других природных элементов
- **Улучшенный рендеринг текста**: повышает точность и качество текстовых элементов, обеспечивая лучшую компоновку и более точную мультимодальную (текст + изображение) композицию

### 1. Файл рабочего процесса

После обновления ComfyUI файл рабочего процесса можно найти в шаблонах или перетащить предпросмотр выше в ComfyUI, чтобы загрузить его.

Рабочий процесс включает два подграфа:
- **Text to Image (Qwen-Image 2512)**: стандартная генерация за 50 шагов
- **Text to Image (Qwen-Image 2512 4steps)**: ускоренная генерация за 4 шага с Lightning LoRA

### 2. Загрузка моделей

**Текстовые энкодеры**

- [qwen_2.5_vl_7b_fp8_scaled.safetensors](https://huggingface.co/Comfy-Org/Qwen-Image_ComfyUI/blob/main/split_files/text_encoders/qwen_2.5_vl_7b_fp8_scaled.safetensors)
