**Qwen-Image-Layered**: это модель, разработанная командой Qwen компании Alibaba, которая раскладывает изображение на несколько слоёв RGBA. Такое слоистое представление даёт естественную редактируемость: каждым слоем можно управлять независимо, не затрагивая остальное содержимое.

**Ключевые особенности**:
- **Естественная редактируемость**: каждый слой можно независимо изменять, не затрагивая остальное содержимое
- **Высокоточные элементарные операции**: поддерживаются изменение размера, перемещение и перекрашивание с физической изоляцией семантических компонентов
- **Декомпозиция с переменным числом слоёв**: число слоёв не фиксировано, можно разложить на 3, 4, 8 или больше слоёв по мере необходимости
- **Рекурсивная декомпозиция**: любой слой можно разложить дальше, что обеспечивает бесконечную глубину декомпозиции

## Слои и выходные данные

Количество слоёв задаётся виджетом `layers` на узле **Empty Qwen Image Layered Latent** внутри [подграфа](/ru/interface/features/subgraph).

Эта модель заново генерирует как полное изображение, так и слои, поэтому при генерации всегда декодируется `layers + 1` изображений:

| `layers` | Декодируется изображений | Содержимое |
| --- | --- | --- |
| `0` | 1 | Только полное изображение |
| `2` (по умолчанию в шаблоне) | 3 | Полное изображение, затем 2 слоя |
| `5` | 6 | Полное изображение, затем 5 слоёв |

**Первое изображение это полное изображение, а не слой.** Рабочий процесс image to layers отбрасывает его автоматически с помощью узла `LatentCut` (`dim` `t`, `index` `1`) перед разделением на пакет, поэтому шаблон выдаёт `layers` изображений. Если вы строите пользовательский граф без этого узла, отбрасывайте первое изображение, когда нужны только слои. `layers` принимает значение `0`, и в этом случае вы получаете только полное изображение.

**Композиционирование всех слоёв обратно воедино воссоздаёт полное изображение.** Используйте это как проверку: если при наложении слоёв первое изображение не воспроизводится, значит декомпозиция сделала не то, что вы хотели.

### Как слои становятся отдельными изображениями

Узел **Empty Qwen Image Layered Latent** выделяет 5D-латент формы `[batch_size, 16, layers + 1, height // 8, width // 8]`. Слои располагаются по третьей оси, той же временной оси, которую модели видео используют для кадров. Узел **LatentCutToBatch** с параметром `dim`, установленным в `t`, переносит эту ось в измерение пакета, поэтому после **VAE Decode** каждый слой становится отдельным изображением в пакете. Шаблон вставляет узел `LatentCut` (`dim` `t`, `index` `1`) перед `LatentCutToBatch`, чтобы отбросить запись полного изображения, поэтому декодированный пакет содержит только слои.

Положение слоя в стеке, таким образом, это его индекс в пакете, считая от полного изображения с индексом 0. Ни поля z-index, ни метаданных для каждого слоя, несущих этот порядок, нет, поэтому переупорядочивание или фильтрация пакета меняет порядок слоёв.

VAE модели Qwen-Image-Layered декодирует в 4 канала, поэтому декодированные слои несут альфа-канал.

## Настройки рабочего процесса

### Настройки сэмплера

Эта модель работает медленно. Оригинальные настройки выборки: steps: 50 и CFG: 4.0, что как минимум удвоит время генерации.

### Размер входа

Для размера входа рекомендуется 640px. Используйте 1024px для вывода в высоком разрешении.

### Промпт (необязательно)

Текстовый промпт предназначен для описания общего содержимого входного изображения, включая элементы, которые могут быть частично перекрыты (например, можно указать текст, скрытый за объектом переднего плана). Он не предназначен для явного управления смысловым содержимым отдельных слоёв.
