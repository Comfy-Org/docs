![Демонстрация HiDream-O1-Image](https://raw.githubusercontent.com/HiDream-ai/HiDream-O1-Image/main/assets/general.webp)

HiDream-O1-Image представляет собой унифицированную базовую модель генерации изображений, открытую HiDream-ai 8 мая 2026 года. Построенная на Pixel-level Unified Transformer (UiT), она работает без внешних VAE или отдельных текстовых энкодеров и поддерживает **текст в изображение**, **редактирование изображений по инструкции**, **персонализацию по субъекту** и **генерацию раскадровок** с разрешением до 2,048 × 2,048.

HiDream-O1-Image выпущена под [лицензией MIT](https://github.com/HiDream-ai/HiDream-O1-Image?tab=MIT-1-ov-file) и нативно поддерживается в ComfyUI (PR [#13817](https://github.com/Comfy-Org/ComfyUI/pull/13817)).

[HiDream-O1-Image на GitHub](https://github.com/HiDream-ai/HiDream-O1-Image)

### 2. Скачать модели

**Чекпойнт**: перепакован и квантован. Во всех вариантах для наихудших выбросов используется bf16, неиспользуемые слои deepstack удалены:

- [hidream_o1_image_fp8_scaled.safetensors](https://huggingface.co/Comfy-Org/HiDream-O1-Image/blob/main/checkpoints/hidream_o1_image_fp8_scaled.safetensors): FP8, использует fp8/mxfp8 matmul на безопасных слоях MLP для ускорения на поддерживаемом оборудовании
- [hidream_o1_image_mxfp8.safetensors](https://huggingface.co/Comfy-Org/HiDream-O1-Image/blob/main/checkpoints/hidream_o1_image_mxfp8.safetensors): квантованный вариант MXFP8
- [hidream_o1_image_bf16.safetensors](https://huggingface.co/Comfy-Org/HiDream-O1-Image/blob/main/checkpoints/hidream_o1_image_bf16.safetensors): полная точность bf16 (самый большой)

**Текстовый энкодер** (улучшение промпта): общий для всех версий:

- [gemma4_e4b_it_fp8_scaled.safetensors](https://huggingface.co/Comfy-Org/gemma-4/blob/main/text_encoders/gemma4_e4b_it_fp8_scaled.safetensors)

**LoRA (необязательно)**: дистилляцию Dev можно также применить к модели Full в виде LoRA, что позволяет регулировать силу дистилляции (от [Kijai](https://huggingface.co/Kijai/hidream-O1-image_comfy)):

- [hidream_o1_dev_lora_rank_64_bf16.safetensors](https://huggingface.co/Kijai/hidream-O1-image_comfy/blob/main/loras/hidream_o1_dev_lora_rank_64_bf16.safetensors): полный ранг
- [hidream_o1_dev_lora_rank_64_bf16_pruned_v1.safetensors](https://huggingface.co/Kijai/hidream-O1-image_comfy/blob/main/loras/hidream_o1_dev_lora_rank_64_bf16_pruned_v1.safetensors): прореженный вариант
- [hidream_o1_image_dev_2604_lora_avg_rankg_224_bf16.safetensors](https://huggingface.co/Kijai/hidream-O1-image_comfy/blob/main/loras/hidream_o1_image_dev_2604_lora_avg_rankg_224_bf16.safetensors): альтернативная дистилляция на основе чекпойнта

### 3. Использовать рабочий процесс

- Убедитесь, что `CheckpointLoaderSimple` загружает выбранный чекпойнт
- Введите промпт в узле `CLIPTextEncode`
- **Режим текст в изображение:** установите переключатель **«Switch to Image Edit»** в положение **off** (по умолчанию). Сэмплер будет использовать ваш текстовый промпт напрямую.
- **Режим редактирования изображения:** установите **«Switch to Image Edit»** в положение **on**, затем загрузите референсное изображение в узле `Load Image` и подключите его к `HiDreamO1ReferenceImages`.

> **Примечание:** сэмплер O1 выдаёт латентные сэмплы, которые нужно декодировать через узел `VAEDecode` с помощью VAE, загруженного через `CheckpointLoaderSimple`.

- **Режим текст в изображение:** установите переключатель **«Switch to Image Edit»** в положение **off** (по умолчанию)

## Дополнительные примечания

- **Рендеринг длинного текста:** HiDream-O1-Image отлично справляется с отрисовкой текста внутри изображений. Для лучшего результата укажите в промпте содержимое текста, стиль шрифта, цвет и расположение.

  ![Рендеринг длинного текста и управление компоновкой](https://raw.githubusercontent.com/HiDream-ai/HiDream-O1-Image/main/assets/text-layout.webp)

- **Масштабирование изображения:** Если входное референсное изображение слишком большое, включите узел `ImageScaleToTotalPixels` (Ctrl+B), чтобы масштабировать его до 4MP.

- **Сглаживание швов патча (экспериментальное):** Узел `HiDreamO1PatchSeamSmoothing` уменьшает заметные артефакты швов во время выборки. Включён по умолчанию в рабочем процессе Full.
