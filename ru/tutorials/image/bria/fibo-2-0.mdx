FIBO 2.0 это 8B-модель изображений от Bria, которая генерирует и редактирует с одним набором весов. Релиз с открытыми весами работает локально в ComfyUI без кредитов, использует латентное пространство FLUX.2 VAE и кодирует промпты с помощью Qwen3-VL-4B.

В комплекте идут два шаблона. Шаблон **Fibo 2.0 Turbo: Image Edit** представляет собой дистиллированную версию для быстрых проверок направления, а **Fibo 2.0 Dev: Image Edit** запускает недистиллированную базовую модель для наиболее чистого редактирования. Оба шаблона принимают референсное изображение и однострочную инструкцию.

## Загрузки моделей
