**NewBie-image-Exp0.1** представляет собой DiT-модель с 3.5B параметров, разработанную NewBieAI Lab для генерации аниме-изображений по текстовому описанию. Она построена на архитектуре Next-DiT и создаёт удивительно детализированные и визуально выразительные аниме-изображения.

**Ключевые особенности**:
- **Модель с 3.5B параметров**: эффективный, но мощный размер модели для генерации аниме высокого качества
- **Архитектура Next-DiT**: основана на исследованиях архитектуры Lumina с новой архитектурой NewBie
- **Два текстовых энкодера**: Gemma3-4B-it используется как основной энкодер, а Jina CLIP v2 улучшает понимание промптов
- **FLUX VAE**: используется 16-канальный VAE от FLUX.1-dev для более насыщенных цветов и тонких деталей текстуры
- **Промпты со структурой XML**: поддерживается формат XML для лучшей привязки внимания и разделения атрибутов

## Формат промпта

NewBie-image представляет собой модель генерации аниме-изображений, оптимизированную для создания персонажей. При обучении модель использует XML-структурированные промпты: каждый тег `<>` задаёт категорию (например, `<appearance>`, `<clothing>`), а `</>` закрывает её. Внутри используются стандартные теги Danbooru. Эта структура обеспечивает точный контроль над сценами с несколькими персонажами и более точную привязку атрибутов.

Полное руководство по написанию промптов см. в [официальной документации](https://ai.feishu.cn/wiki/NZl9wm7V1iuNzmkRKCUcb1USnsh).

NewBie-image-Exp0.1 поддерживает три формата промптов:
- **Естественный язык**: стандартные текстовые описания
- **Теги**: теги в стиле Danbooru
- **XML-структурированный формат**: рекомендуется для сцен с несколькими персонажами

### XML-структурированный промпт

Для сцен с несколькими персонажами использование XML-структурированных промптов обычно даёт более точные результаты генерации изображений за счёт лучшего связывания внимания и разделения атрибутов.

```xml
<character_1>
<n>$character_1$</n>
<gender>1girl</gender>
<appearance>chibi, red_eyes, blue_hair, long_hair, hair_between_eyes, head_tilt, tareme, closed_mouth</appearance>
<clothing>school_uniform, serafuku, white_sailor_collar, white_shirt, short_sleeves, red_neckerchief, bow, blue_skirt, miniskirt, pleated_skirt, blue_hat, mini_hat, thighhighs, grey_thighhighs, black_shoes, mary_janes</clothing>
<expression>happy, smile</expression>
<action>standing, holding, holding_briefcase</action>
<position>center_left</position>
</character_1>

<character_2>
<n>$character_2$</n>
<gender>1girl</gender>
<appearance>chibi, red_eyes, pink_hair, long_hair, very_long_hair, multi-tied_hair, open_mouth</appearance>
<clothing>school_uniform, serafuku, white_sailor_collar, white_shirt, short_sleeves, red_neckerchief, bow, red_skirt, miniskirt, pleated_skirt, hair_bow, multiple_hair_bows, white_bow, ribbon_trim, ribbon-trimmed_bow, white_thighhighs, black_shoes, mary_janes, bow_legwear, bare_arms</clothing>
<expression>happy, smile</expression>
<action>standing, holding, holding_briefcase, waving</action>
<position>center_right</position>
</character_2>

<general_tags>
<count>2girls, multiple_girls</count>
<style>anime_style, digital_art</style>
<background>white_background, simple_background</background>
<atmosphere>cheerful</atmosphere>
<quality>high_resolution, detailed</quality>
<objects>briefcase</objects>
<other>alternate_costume</other>
</general_tags>
```

### Справочник по XML-тегам

| Тег | Описание |
|-----|-------------|
| `<n>` | Имя/идентификатор персонажа |
| `<gender>` | Пол персонажа (1girl, 1boy и т. д.) |
| `<appearance>` | Внешний вид (волосы, глаза, телосложение) |
| `<clothing>` | Одежда и аксессуары |
| `<expression>` | Выражение лица |
| `<action>` | Поза и действия |
| `<position>` | Положение на изображении |
| `<count>` | Количество персонажей |
| `<style>` | Художественный стиль |
| `<background>` | Описание фона |
| `<atmosphere>` | Общее настроение |
| `<quality>` | Теги качества |
| `<objects>` | Объекты в сцене |
| `<other>` | Дополнительные теги |
