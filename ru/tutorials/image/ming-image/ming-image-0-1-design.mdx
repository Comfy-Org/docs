**Ming Image 0.1 Design**: это 6B-модель с открытыми весами для преобразования текста в изображение от inclusionAI (Ant Group), выпущенная под лицензией MIT. Она рассчитана на дизайнерские задачи, а не на фотографический реализм: экраны интерфейсов, инфографика, постеры и другие макеты с большим количеством текста. Выходы имеют формат RGBA с настоящим альфа-каналом, поэтому прозрачный результат можно сразу перенести в дизайн-файл.

В рабочем процессе перед сэмплером добавлен этап переписывания промпта. Qwen3.8-27B разворачивает короткую идею в структурированное описание макета до выборки, а enhancer можно отключить, если вы хотите, чтобы ваш текст отправлялся точно так, как набран.

## В чём сильные стороны Ming Image 0.1 Design

- **Длинные структурированные макеты**: страницы, постеры и инфографика с множеством разделов, собираемые раздел за разделом
- **Рендеринг текста**: строки, заключённые в кавычки в промпте, воспроизводятся точно, поэтому подписи, цены и заголовки остаются читаемыми
- **Прозрачный вывод**: RGBA-изображения с настоящим альфа-каналом для композиционирования изолированных элементов
- **Переписывание промпта**: визуально-языковая модель, следующая инструкциям, разворачивает короткое задание в подробное описание макета
- **Открытые веса**: лицензия MIT, поэтому чекпойнты можно свободно использовать и дообучать

## Рабочий процесс текст в изображение Ming Image 0.1 Design

### Шаги запуска рабочего процесса

1. Войдите в подграф **Text to Image (Ming Image 0.1 Design)** кнопкой **Войти в подграф** внизу этого узла
2. Напишите промпт в поле `prompt`, описывая макет секция за секцией, а любой текст, который нужно отрисовать, заключайте в кавычки
3. Выберите холст узлом `ResolutionSelector`: 2048 x 2048 даёт лучшее качество, 1024 x 1024 работает быстрее
4. Оставьте усилитель промпта включённым, чтобы Qwen3.8-27B расширил ваш промпт, или отключите `enable_PE`, чтобы отправить текст ровно в том виде, как он введён
5. Поставьте промпт в очередь. Декодированное изображение появится в узле `PreviewImage`
6. Для прозрачного фона добавьте в начало промпта RGBA-фразу, например `RGBA, 4-channel, transparent background`

## Руководство по промптам

- [Переписывание промптов для генерации текст в изображение](https://github.com/inclusionAI/Ming-Image#text-to-image-prompt-rewriting): официальная структура промпта и системный промпт рерайтера, который запускает энхансер этого рабочего процесса
- [Совет по генерации прозрачного фона](https://github.com/inclusionAI/Ming-Image#transparent-background-generation-tip): фиксированные RGBA-фразы, которые нужно добавить в начало промпта

## Начать

1. Обновите ComfyUI до последней версии. Поддержка Ming Image 0.1 присутствует в новейших сборках ComfyUI.
2. Перейдите в Template Library и найдите `Ming Image 0.1 Design`.

<Note>
Comfy Desktop и Comfy Cloud следуют стабильным выпускам, поэтому модель, поддерживаемая только в новейшей сборке ComfyUI, может быть там ещё недоступна.
</Note>
