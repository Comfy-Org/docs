**Krea 2** это модель генерации изображений от [Krea AI](https://www.krea.ai), обученная с нуля и ориентированная на творческое и стилистическое исследование.

Krea 2 выпускается в виде двух моделей, рассчитанных на совместную работу: **обучайте LoRA на RAW, а вывод выполняйте на Turbo**:
- **Krea 2 RAW**: базовая модель с полным числом шагов выборки (52 шага). Без дистилляции, разнообразная и очень гибкая, идеальна для дообучения и обучения LoRA.
- **Krea 2 Turbo**: 8-шаговый дистиллированный чекпойнт для быстрой генерации высокого качества. LoRA, обученные на RAW, без проблем применяются к Turbo.

Рабочий процесс состоит из нескольких частей:

1. **Подграф Text to Image (Krea-2 Turbo)**: основной конвейер генерации, включающий загрузку моделей, обработку промпта, сэмплирование и декодирование VAE
2. **ResolutionSelector**: выбор желаемого разрешения результата. Krea 2 поддерживает изображения от 1K до 2K. Установите значение мегапикселей 2.0, чтобы получить разрешение 2K.
3. **CustomCombo (выбор LoRA)**: готовый селектор триггерных слов для доступных LoRA стилей. Если вы скачаете дополнительные LoRA, селектор можно настроить и сопоставить с соответствующими файлами LoRA.
4. **SaveImage**: сохраняет сгенерированное изображение

### Генерация в один клик

В простейшем случае достаточно ввести текстовый промпт в подграфе, выбрать разрешение и нажать **Queue Prompt**. Значения по умолчанию (8 шагов, включённое улучшение промпта, без LoRA) дают качественное изображение при минимальной настройке.

### Параметры рабочего процесса

Подграф **Text to Image (Krea-2 Turbo)** предоставляет следующие параметры:

| Параметр | Описание |
|---------|-------------|
| **Text String (User Prompt)** | Текстовый промпт с описанием изображения, которое нужно получить |
| **prompt_enhance** | Включает и выключает расширение промпта с помощью LLM |
| **LLM_max_token** | Максимальная длина токенов для расширения промпта |
| **Width / Height** | Разрешение результата (управляется через ResolutionSelector) |
| **Seed** | Случайное зерно для воспроизводимости |
| **enable_lora?** | Включает или выключает LoRA стиля |
| **LoRA Strength** | Сила применённой LoRA стиля |
| **LoRA Trigger Word** | Триггерное слово выбранной LoRA, подставляется автоматически |

Рабочий процесс со стилевым референсом расширяет конвейер Krea-2 Turbo обусловливанием по референсным изображениям. Загрузите одно или несколько референсных изображений, чтобы повлиять на эстетику, настроение и визуальное направление результата.

Рабочий процесс состоит из нескольких частей:

1. **Подграф Image Style Reference (Krea-2 Turbo)**: основной конвейер генерации с поддержкой стилевого референса, включающий загрузку моделей, обусловливание по референсным изображениям, обработку промпта и сэмплирование
2. **LoadImage**: загрузка референсных изображений стиля
3. **ResolutionSelector**: выбор желаемого разрешения результата. Krea 2 поддерживает изображения от 1K до 2K.
4. **SaveImage**: сохраняет сгенерированное изображение

### Как пользоваться стилевым референсом

1. **Загрузите референсные изображения**: используйте узел **LoadImage**, чтобы загрузить одно или несколько изображений стиля
2. **Введите промпт**: опишите текстом, что нужно получить, в поле пользовательского промпта подграфа
3. **Выберите вариант модели**: укажите чекпойнт в селекторе моделей подграфа
4. **Настройте параметры**: задайте разрешение, seed и при желании включите расширение промпта
5. **Нажмите Queue**: нажмите `Ctrl+Enter`, чтобы запустить генерацию

Этот рабочий процесс использует отдельную модель диффузии и LoRA. Текстовый энкодер и VAE общие с рабочим процессом «текст в изображение».
