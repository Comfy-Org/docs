**PixelDiT** это пиксельный diffusion-трансформер от NVIDIA для генерации изображений 1024px по тексту (текст в изображение). В отличие от традиционных моделей diffusion, работающих в латентном пространстве, PixelDiT генерирует изображения напрямую в пиксельном пространстве, используя двухуровневую архитектуру DiT: DiT уровня патчей в сочетании с DiT пиксельного уровня, с объединением MM-DiT для совместного внимания между текстовыми и графическими токенами.

**Ключевые особенности модели**:
- **Без VAE**: генерация идёт напрямую в пиксельном пространстве, без традиционного кодирования и декодирования VAE
- **Двухуровневый DiT**: DiT уровня патчей + DiT пиксельного уровня для генерации высокого качества
- **Множество соотношений сторон**: базовое разрешение 1024px с поддержкой нескольких соотношений сторон
- **~1.3B параметров**: достаточно эффективно для потребительских GPU
- **Лицензия**: NSCLv1 (только для некоммерческих исследований и оценки)

Рабочий процесс состоит из трёх основных узлов:

1. **ResolutionSelector**: выберите желаемое разрешение выходного изображения
2. **Text to Image (PixelDiT) subgraph**: основной узел генерации с вынесенными элементами управления для промпта, seed, выбора модели и разрешения
3. **SaveImage**: сохраняет сгенерированное изображение

  В этом рабочем процессе используются узлы подграфа для модульной обработки. Ознакомьтесь с документацией по подграфам, чтобы узнать, как настраивать и расширять рабочий процесс.

### Элементы управления рабочего процесса

К вынесенным элементам управления на узле подграфа **Text to Image (PixelDiT)** относятся:

| Элемент управления | Описание |
|---------|-------------|
| **Positive Prompt** | Текстовый промпт, описывающий изображение, которое вы хотите сгенерировать |
| **Negative Prompt** | Текст, описывающий, чего следует избегать в сгенерированном изображении |
| **Seed** | Случайный seed для воспроизводимости |
| **UNet Model** | Выбор чекпойнта модели PixelDiT |
| **CLIP Model** | Выбор модели текстового энкодера |
