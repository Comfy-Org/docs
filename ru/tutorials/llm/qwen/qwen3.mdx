**Qwen 3.0** (также известна как Qwen3): это мощная открытая LLM от Alibaba Cloud, предназначенная для генерации текста, рассуждений и структурированного анализа. В ComfyUI она поддерживается нативно через встроенный узел `TextGenerate`.

**Ключевые особенности модели**:

- **Сильные рассуждения**: Qwen3-4B-Thinking поддерживает пошаговое рассуждение по принципу цепочки рассуждений
- **Фокус на генерации текста**: оптимизирована для структурированного текстового вывода, анализа и задач программирования
- **Нативная поддержка в ComfyUI**: работает со встроенным узлом `TextGenerate`, пользовательские узлы не требуются
- **Лёгкость**: использует тот же формат текстового энкодера, что и Qwen3.5, доступна в вариантах 2B, 4B и 9B, что позволяет подобрать вариант под разное оборудование

## Сценарии использования

Qwen 3.0 хорошо подходит для задач, требующих структурированной генерации текста и интеллектуального рассуждения в рамках рабочего процесса ComfyUI:

- **Оптимизация промптов**: передайте существующие промпты в Qwen 3.0 и попросите переписать, расширить или уточнить их для лучших результатов генерации изображений. Например, преобразуйте короткий промпт из ключевых слов в подробные структурированные описания со стилем, освещением и композицией.
- **Рассуждение о логике рабочего процесса**: используйте модель для анализа параметров рабочего процесса, предложения шагов обработки или генерации структурированных инструкций, которые передаются в другие узлы.
- **Анализ текста**: извлекайте информацию, классифицируйте содержимое или создавайте структурированные отчёты из текстовых входов.
- **Рассуждение по цепочке мыслей**: включите режим размышления для сложных многошаговых задач, которые выигрывают от промежуточных рассуждений перед получением итогового результата.

Этот рабочий процесс демонстрирует основные возможности **генерации текста** Qwen 3.0. Он принимает текстовый промпт и генерирует подробные структурированные ответы, используя встроенные возможности рассуждения модели.

**Входы**:
- **Текстовый промпт**: ваш вопрос, инструкция или описание задачи

**Ключевые параметры**:
- **Макс. длина**: максимальное количество токенов для генерации (по умолчанию 256)
- **Режим выборки**: включите или отключите выборку и настройте temperature, top-k, top-p, штраф за повторения и seed
- **Режим рассуждения**: включить пошаговое рассуждение перед финальным ответом
- **Использовать шаблон по умолчанию**: применить встроенный системный промпт модели

**Выход**:
- **Сгенерированный текст**: ответ модели в виде простой текстовой строки

## Загрузка модели

Модели Qwen 3.0 загружаются в ComfyUI как текстовые энкодеры. Файлы моделей общие с Qwen3.5. Скачайте вариант, который лучше всего подходит для вашего оборудования:

<CardGroup cols={2}>
<Card title="Qwen3.5 2B (bf16)" icon="download" href="https://huggingface.co/Comfy-Org/Qwen3.5/blob/main/text_encoders/qwen3.5_2b_bf16.safetensors">
    Лёгкий вариант, ~4.5 GB. Лучше всего подходит для систем с небольшим объёмом VRAM и быстрого скачивания.
  </Card>

<Card title="Qwen3.5 4B (bf16)" icon="download" href="https://huggingface.co/Comfy-Org/Qwen3.5/blob/main/text_encoders/qwen3.5_4b_bf16.safetensors">
    Сбалансированный размер и качество. Рекомендуется для большинства потребительских GPU.
  </Card>

<Card title="Qwen3.5 9B (bf16)" icon="download" href="https://huggingface.co/Comfy-Org/Qwen3.5/blob/main/text_encoders/qwen3.5_9b_bf16.safetensors">
    Самый крупный вариант, ~19 GB. Более высокое качество результата, требует больше VRAM.
  </Card>
</CardGroup>

Поместите скачанный файл `.safetensors` в:

```
📂 ComfyUI/
├── 📂 models/
│   └── 📂 text_encoders/
│       └── qwen3.5_4b_bf16.safetensors   # или вариант 2b / 9b
```
