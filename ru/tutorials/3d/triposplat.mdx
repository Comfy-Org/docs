**TripoSplat** — это модель с открытым исходным кодом, которая генерирует представления **3D Gaussian splat** напрямую из одного 2D-изображения. Она разработана VAST-AI и выпущена по лицензии с открытым исходным кодом.

В отличие от традиционных методов 3D-реконструкции, которым требуется несколько ракурсов или которые выдают меши в качестве основного результата, TripoSplat создаёт представления **Gaussian splat**: технику рендеринга, при которой тысячи цветных 3D-гауссиан размещаются в пространстве и представляют сцену. Такой подход обеспечивает быстрый рендеринг высокого качества с управляемой плотностью и бюджетом.

## Как это работает

TripoSplat использует **feed-forward архитектуру**, которая принимает одно RGB-изображение и напрямую предсказывает набор 3D-гауссовых примитивов. Pipeline включает следующие этапы:

1. **Кодирование изображения**: входное изображение обрабатывается визуальным энкодером (DINOv2)
2. **Генерация триплейна**: признаки декодируются в триплейн-представление
3. **Предсказание гауссианов**: из триплейна сэмплируются параметры гауссианов (положение, масштаб, поворот, непрозрачность, цвет)
4. **Рендеринг**: гауссианы рендерятся из произвольных ракурсов с помощью дифференцируемого сплаттинга

## Руководство по узлам рабочего процесса

### LoadImage
- Загружает входное изображение (PNG/JPG)
- Пример изображения: `white-hotel-on-rocky-island.png` (доступно в библиотеке шаблонов)

### TripoSplat (подграф)

Основной узел подграфа обрабатывает изображение и генерирует 3D Gaussian splat. Доступные параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `switch` | - | Включение/отключение подграфа |
| `num_gaussians` | - | Количество генерируемых гауссовых примитивов (влияет на качество/производительность) |
| `seed` | - | Случайное зерно для воспроизводимости |
| `unet_name` | - | Чекпойнт diffusion-модели TripoSplat |
| `clip_name` | - | Модель CLIP vision encoder |
| `vae_name` | - | VAE для кодирования/декодирования (2 записи: одна для основного VAE, одна для энкодера) |
| `bg_removal_name` | - | Модель удаления фона |

### CreateCameraInfo
- Определяет орбиту камеры для рендеринга результата
- Параметры: тип орбиты, угол, расстояние, поле зрения и т. д.
- По умолчанию: орбита с углом подъёма 35°, расстоянием 30 и масштабом 2.5

### RenderSplat
- Рендерит Gaussian splat в 2D-изображение с заданного угла камеры
- Параметры: разрешение выходного изображения (по умолчанию 1024×1024), настройки качества изображения

### SplatToMesh
- Преобразует Gaussian splat в сетку (необязательно)
- Параметры: плотность сетки, сглаживание, упрощение

### SaveGLB
- Сохраняет результат как 3D-файл GLB

### SaveVideo
- Сохраняет видео с отрендеренной 3D-сценой

### SplatToFile3D
- Экспортирует Gaussian splat в формате SPZ

### CreateVideo
- Создаёт видео из отрендеренных кадров

## Шаги запуска

1. **Загрузите изображение**: используйте узел **LoadImage**, чтобы загрузить одно 2D-изображение
2. **Запустите подграф TripoSplat**: модель сгенерирует представление в виде гауссовых сплатов
3. **Выберите формат вывода**: экспорт в GLB, SPZ, видео или рендеринг в сетку
4. **Просмотрите результаты**: используйте созданный 3D-файл или отрендеренный предпросмотр

## Параметры вывода

| Узел | Формат | Применение |
|---|---|---|
| **SaveGLB** | `.glb` | Стандартный формат 3D-файлов, импортируемый в 3D-программы |
| **SplatToFile3D** | `.spz` | Сжатый формат гауссовых сплатов для эффективного хранения |
| **RenderSplat** | 2D-изображение | Быстрый предпросмотр результата с любого угла |
| **SplatToMesh** | Сетка | Преобразование в традиционную сетку для дальнейшего редактирования |
