Ideogram 4.0 это модель «текст в изображение» от Ideogram, которая обеспечивает фотореалистичное качество, точный рендеринг текста и тонкий контроль стиля. Вы можете использовать как обычный естественный язык, так и **структурированные JSON-промпты** для детального управления компоновкой, цветами и текстом на изображении. Ideogram 4.5 это более новая модель семейства, у неё есть отдельная страница: [Ideogram 4.5 в ComfyUI](/ru/tutorials/partner-nodes/ideogram/ideogram-4-5).

## Что умеет Ideogram 4.0

- **Фотореалистичное качество**: превосходный фотореализм сгенерированных изображений
- **Точное воспроизведение текста**: отображает текст на изображении буквально, хорошо подходит для композиций в стиле постера
- **Точное управление стилем**: структурированные JSON-промпты управляют палитрой стиля, размещением элементов (`bbox`) и палитрами цветов для каждого элемента
- **Гибкие промпты**: принимает обычный текст на естественном языке для быстрых идей или структурированный JSON для точного контроля
- **Негативные промпты не нужны**: использует асимметричное направление без классификатора вместо отдельной строки негативного промпта

### Формат промпта

Узел Ideogram V4 поддерживает два формата промптов:

1. **Естественный язык**: простой и интуитивно понятный, лучше всего подходит для быстрых идей.
2. **Структурированный JSON**: даёт детальный контроль над стилем, цветовой палитрой, размещением элементов (`bbox`) и отрисовкой точного текста на изображении. Рекомендуется для композиций в стиле постера.

В примере рабочего процесса по умолчанию используется структурированный JSON-промпт, который содержит:
- `high_level_description`: общее описание сцены
- `style_description`: эстетика, освещение, материал, цветовая палитра
- `compositional_deconstruction`: ограничивающие рамки, описания и цветовые палитры для каждого элемента

### Шаги рабочего процесса

1. Скачайте файл рабочего процесса и перетащите его в ComfyUI
2. Узел `Ideogram V4` уже содержит структурированный JSON-промпт по умолчанию: вы можете изменить его или написать обычный текст на естественном языке
3. Нажмите `Run` или используйте сочетание клавиш `Ctrl(cmd) + Enter`, чтобы сгенерировать изображение
4. После того как API вернёт результат, просмотрите сгенерированное изображение в узле `Save Image`. Изображения сохраняются в каталог `ComfyUI/output/`

### Использование конструктора JSON-промптов (необязательно)

Рабочий процесс включает встроенный узел **Gemini** (Gemini 3.1 Pro), который помогает создавать структурированные JSON-промпты:

1. Опишите свою идею в поле пользовательского промпта узла Gemini
2. Модель сгенерирует JSON-промпт, соответствующий схеме
3. Подключите выход `STRING` к входу `prompt` узла `Ideogram V4`
4. Запустите рабочий процесс

## Дополнительные примечания

- **Негативные промпты не нужны**: модель Ideogram 4.0 использует асимметричное направление без классификатора, при котором безусловный проход отбрасывает текстовые токены, а не требует отдельной строки негативного промпта.
- **Построение промптов с помощью модели**: рассмотрите возможность использования **Ideogram 4 Prompt Builder** (KJNodes) для визуального контроля над построением промптов в ComfyUI.
