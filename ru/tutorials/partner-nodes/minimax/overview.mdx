MiniMax (Hailuo): ведущая платформа генерации видео с помощью ИИ, известная исключительным качеством движения и кинематографичным результатом, теперь доступна внутри ComfyUI. Она предлагает две линейки моделей: **MiniMax-01** (T2V-01 для генерации из текста и I2V-01 для генерации из изображения с режимами Director/Live) и **MiniMax S2V-01** (генерация по референсу персонажа). Вместе они покрывают всё: от кинематографичного повествования до контента с узнаваемым персонажем.

## Ключевые возможности

- **T2V-01 с режимом Director**: 15 типов кинематографичного движения камеры (панорама, наклон, наезд, кран, слежение, аэросъёмка, съёмка с рук, крен, приближение, отдаление, вдавливание, отъезд, облёт, вид от первого лица, статичная камера) для точного управления на уровне отдельного кадра
- **I2V-01-Director**: кинематографичное управление камерой для видео, инициированного изображением: визуальная основа стартового изображения сочетается с выразительными возможностями режима Director
- **I2V-01-Live**: естественное, живое движение из одного изображения с органичной динамикой: идеально подходит, чтобы оживить портреты, пейзажи и предметные съёмки
- **Референс персонажа в S2V-01**: сохранение внешности персонажа, лица или объекта во всём сгенерированном видео по одному референсному изображению; отлично подходит для серийного контента
- **Высокое качество движения**: реализм движений персонажей, физики и динамики жидкостей на уровне отраслевого лидера во всех вариантах моделей
