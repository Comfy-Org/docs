Создавайте диалог нескольких персонажей с разными голосами из одного текста. Задайте голоса персонажей и напишите сценарий разговора: ElevenLabs озвучит каждого персонажа его назначенным голосом за один проход.

## Ключевые возможности

- **Генерация с несколькими голосами**: несколько персонажей с разными голосами за один проход
- **На основе сценария**: ввод структурированного текста диалога с назначением персонажей
- **Единообразные голоса персонажей**: каждый персонаж сохраняет назначенную ему идентичность голоса
