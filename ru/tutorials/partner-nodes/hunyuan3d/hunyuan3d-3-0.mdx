Hunyuan 3D 3.0 — это передовая модель генерации 3D от Tencent, которая позволяет создавать 3D-контент за считанные минуты. Она генерирует готовые к использованию 3D-ассеты по текстовым промптам, изображениям или скетчам, причём порог входа здесь гораздо ниже, чем у традиционных пайплайнов 3D-моделирования.

ComfyUI теперь имеет нативную интеграцию с соответствующим API Hunyuan 3D, поэтому вы можете удобно использовать нужные узлы прямо в ComfyUI для генерации моделей.

Сейчас Партнёрские узлы ComfyUI поддерживают следующие возможности генерации моделей Hunyuan 3D:
- Генерация 3D по тексту
- Генерация 3D по изображению
- Генерация 3D по нескольким ракурсам

## Для чего подходит Hunyuan 3D 3.0

- **Идеи для игровой разработки**: быстрое создание персонажей, пропсов и окружения с оптимизированной топологией для риггинга и рендеринга в реальном времени
- **Товары и электронная коммерция**: превращайте фотографии товаров в интерактивные 3D-модели для онлайн-демонстрации
- **Промышленный дизайн**: прототипирование от эскиза к 3D-модели и разбиение деталей для 3D-печати
- **VFX и анимация**: ассеты высокого разрешения с профессиональными UV и PBR-материалами

## Начало работы

### 1. Открыть шаблоны рабочих процессов

1. Откройте библиотеку шаблонов на боковой панели
2. Перейдите в **3D** → **Hunyuan 3D**
3. Выберите шаблон рабочего процесса для Hunyuan 3D

### 2. Запустить рабочий процесс

1. Введите промпт, изображения или эскизы в зависимости от типа рабочего процесса
2. Нажмите кнопку `Run` или используйте сочетание клавиш `Ctrl(cmd) + Enter`, чтобы выполнить генерацию модели
3. После завершения рабочего процесса просмотрите и экспортируйте вашу 3D-модель
