**Meshy T2.5** создаёт 3D-сетку сразу с тем количеством треугольников, которое вы задаёте. Раньше сетку генерировали плотной, а затем выполняли ретопологию: это приводит к потере деталей и требует очистки перед отправкой ассета. T2.5 сразу ориентируется на заданный бюджет, поэтому проп на 15000 треугольников возвращается примерно с 15000 треугольниками и сразу отправляется в движок.

ComfyUI предоставляет к нему доступ через два партнёрских узла: **Meshy: Text to Model (Smart Topology)** и **Meshy: Image to Model (Smart Topology)**. Оба представляют собой облачные API-узлы: для них нужен аккаунт Comfy с кредитами, а файлы моделей локально не скачиваются. Каждый возвращает файл GLB и файл FBX, а шаблоны записывают GLB с помощью узла Save GLB.

T2.5 подходит для пропов, оформления окружения и низкополигональных игровых ассетов, где важно предсказуемое количество треугольников. Для риггинга, анимации и полного цикла работы с ассетами используйте [Meshy 7](/ru/tutorials/partner-nodes/meshy/meshy-7).

## Управление узлом

| Элемент управления | Значения | Применяется к | Действие |
| --- | --- | --- | --- |
| `model` | `meshy-t2.5` | оба узла | Выпуск модели Smart Topology |
| `prompt` | текст, до 800 символов | Text to Model | Описание объекта для построения |
| `image` | одно изображение | Image to Model | Исходное изображение, из которого строится сетка |
| `target_polycount` | от 100 до 30000, по умолчанию 15000 | оба узла | Приблизительное количество треугольников в результате |
| `pose_mode` | пусто, `A-pose`, `T-pose` | оба узла | Фиксирует позу персонажа. Для предметов оставьте пусто |
| `should_texture` | `true`, `false` | Image to Model | Выполнять ли текстурирование сетки после генерации |
| `enable_pbr` | по умолчанию выключено | Image to Model, текстурирование включено | Добавляет карты металличности, шероховатости и нормалей к базовому цвету |
| `texture_prompt` | текст, до 800 символов | Image to Model, текстурирование включено | Текстовое направление для текстуры. Нельзя комбинировать с `texture_image` |
| `texture_image` | одно изображение | Image to Model, текстурирование включено | Графическое направление для текстуры. Нельзя комбинировать с `texture_prompt` |
| `texture_resolution` | `2k`, `4k`, `8k` | Image to Model, текстурирование включено | Разрешение сгенерированных текстур |
| `seed` | целое число | оба узла | Определяет, будет ли узел запускаться повторно. Результат Meshy недетерминирован независимо от seed |

Узел выводит `meshy_task_id`, `GLB` и `FBX`. Save GLB записывает файл из выхода `GLB`, а не из идентификатора задачи или выхода FBX.

## Советы по составлению промптов

- **Называйте объект и силуэт.** `Standalone game prop, clean silhouette, no text` не даёт модели добавить сцену, подставку или надписи, которые потом придётся удалять.
- **Указывайте бюджет полигонов до генерации.** Изменение `target_polycount` после генерации означает новую генерацию, поэтому сначала решите, что это за ассет: главный объект или фоновый реквизит.
- **Описывайте материал, а не схемы освещения.** Такие слова о поверхности, как `weathered wood, iron banding, rusted lock plate`, сохраняются в сетке и текстуре. Слова про студийное освещение влияют только на то, как читается предпросмотр.
- **Используйте `pose_mode` только для персонажей.** A-pose или T-pose даёт удобную для риггинга позу. Для реквизита лучше оставить «пусто».
- **Текстурируйте, когда форма уже верна.** Запустите один раз без текстурирования, проверьте силуэт, затем включите `should_texture` для финального прохода.
- **Не рассчитывайте получить одну и ту же сетку дважды.** Seed решает только, перезапустится ли узел, поэтому повторный запуск даёт новый результат.
