Anthropic Claude представляет собой семейство мощных ИИ-моделей, известных способностью к рассуждениям, безопасностью и поддержкой длинного контекста. ComfyUI интегрировал API Anthropic Claude через Партнёрские узлы, что позволяет использовать Claude напрямую в ваших рабочих процессах для задач диалога и анализа изображений.

## Что Anthropic Claude умеет хорошо

- **Сильное рассуждение**: семейство моделей, известное способностью к рассуждениям, безопасностью и поддержкой длинного контекста
- **Диалоговые задачи и анализ изображений**: используйте Claude напрямую в рабочих процессах ComfyUI через партнёрские узлы
- **Мультимодальный вход**: каждая поддерживаемая модель принимает текстовые входы и входы «текст + изображение», до 20 изображений на запрос
- **Модель для любой нагрузки**: от флагманской линейки Opus до быстрой и экономичной Haiku для сценариев с высокой пропускной способностью

В соответствующем шаблоне мы подготовили промпт для анализа и генерации ролевых промптов: он интерпретирует ваши изображения в соответствующие промпты для рисования.
</Note>

Чтобы выполнить базовый рабочий процесс, следуйте пронумерованным шагам на изображении:
1. В узле `Load Image` загрузите изображение, которое ИИ должен интерпретировать (необязательно: пропустите этот шаг для текстовых запросов)
2. В узле `Anthropic Claude` измените `prompt`, чтобы задать промпт беседы, или измените `model`, чтобы выбрать другую модель Claude
3. (Необязательно) Задайте `system_prompt`, чтобы определить инструкции поведения модели
4. Нажмите `Run` или `Ctrl(cmd) + Enter`, чтобы выполнить беседу
5. После того как API вернёт результаты, просмотрите ответ ИИ в узле `Preview Any`

### Дополнительные примечания

- Настройте `max_tokens` (до 32768) и `temperature` (от 0.0 до 1.0) в расширенных параметрах узла. `temperature` недоступен при включённом thinking, а также на `Opus 4.7`
- Параметр `seed` определяет, будет ли узел запускаться повторно: результаты недетерминированы независимо от значения seed
