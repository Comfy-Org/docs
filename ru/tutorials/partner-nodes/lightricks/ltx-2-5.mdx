[LTX-2.5](https://ltx.io/model/ltx-2-5): это открытая видеомодель и модель мира от Lightricks, доступная в ComfyUI через API-узлы LTX-2.5. Рабочие процессы API выполняют генерацию на серверах Lightricks, поэтому не нужно скачивать модели или иметь локальный GPU, а каждая секунда сгенерированного видео тарифицируется на вашем аккаунте Comfy API.

API LTX-2.5 предлагает два уровня модели: **LTX-2.5 (Pro)** для максимального качества и **LTX-2.5 (Fast)** для более быстрой генерации с использованием дистиллированной модели. Оба уровня поддерживают синхронизированную генерацию видео и аудио с нативными мультишот-сценами, а на уровне Fast выходное разрешение достигает 4K.

## В чём сильные стороны LTX-2.5

- **Синхронизированные аудио и видео**: оба уровня генерируют аудио и видео вместе, с нативными многоплановыми сценами
- **Два уровня моделей**: LTX-2.5 (Pro) для максимального качества, LTX-2.5 (Fast) для более быстрой генерации на дистиллированной модели
- **Вывод до 4K**: уровень Fast выдаёт разрешение до 4K
- **Локальный GPU не требуется**: генерация выполняется на серверах Lightricks, модели не скачиваются
- **Несколько режимов генерации**: текст в видео, изображение в видео и видео из первого и последнего кадра (first-last-frame-to-video)

## Рабочие процессы API LTX-2.5

Библиотека шаблонов включает три примера рабочих процессов API:

- **Text to Video**: генерируйте видео по текстовым промптам
- **Image to Video**: генерируйте видео по одному начальному изображению
- **FLF2V**: генерируйте видео между первым и последним кадром

#### Советы по промптам

1. **Модель**: выберите `LTX-2.5 (Pro)` для максимального качества или `LTX-2.5 (Fast)` для более быстрой генерации
2. **Длительность**: Pro поддерживает 2-10 секунд; Fast поддерживает 2-20 секунд. Длительность свыше 10 секунд требует разрешения 720p или 1080p и 24/25 FPS
3. **Разрешение и соотношение**: выберите пресет разрешения, например `1280x720` (альбомный) или `720x1280` (портретный); Fast добавляет варианты `2560x1440` и `3840x2160`
4. **FPS**: на Fast доступны 24, 25, 48 или 50 FPS, на Pro: 24, 25 или 50 FPS
5. **Аудио**: генерация аудио включена по умолчанию; отключите её в расширенных настройках узла, если вам нужно только видео без звука
6. **Промпт**: опишите всю сцену одним плавным абзацем, включая план, действие, персонажей, движение камеры и желаемое аудио

#### Советы по промптам

1. **Модель**: в этом рабочем процессе выбрано `LTX-2.5 (Fast)` для более быстрых итераций; переключите на `LTX-2.5 (Pro)` для максимального качества
2. **Только одно изображение**: на вход изображения принимается ровно один начальный кадр
3. **Промпт**: опишите, что происходит дальше: движение, движение камеры и звуки, вытекающие из начального изображения. Формулировка вроде «Use the provided start image as the first frame» помогает задать генерацию
4. **Длительность и разрешение**: тариф Fast поддерживает до 20 секунд и разрешения до 4K; длительность свыше 10 секунд требует 720p/1080p при 24/25 FPS
