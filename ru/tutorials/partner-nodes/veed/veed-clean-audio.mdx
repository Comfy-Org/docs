**VEED Clean Audio** выделяет голос в записи. Он убирает фоновый шум, а поскольку узел создан для речи, музыка и звуковые эффекты уходят вместе с шумом: на выходе остаётся только диалог, очищенный и готовый к использованию.

В ComfyUI модель работает через два партнёрских узла. **VEED Clean Audio** принимает отдельную запись и возвращает очищенное аудио. **VEED Clean Audio (in Video)** принимает клип, очищает только его звуковую дорожку и возвращает видео с неизменной картинкой. Оба узла относятся к облачным API-узлам: им нужен аккаунт Comfy с кредитами, и они не скачивают файлы модели локально.

Узлы возвращают разные результаты. **Clean Audio** возвращает аудио 48 кГц в моно. **Clean Audio (in Video)** возвращает само видео: картинка остаётся нетронутой, а звуковая дорожка заменяется на ту же очищенную монофоническую речь 48 кГц. Оба узла принимают записи длительностью до 1799 секунд, то есть чуть меньше 30 минут. О синхронизации губ, говорящих портретах и удалении фона читайте в разделе [VEED Video Nodes](/ru/tutorials/partner-nodes/veed/veed-video).

Клип без звуковой дорожки останавливается с ошибкой вместо того, чтобы вернуть видео без звука. Сохраняется только первая звуковая дорожка: дополнительные звуковые дорожки и встроенные субтитры отбрасываются, поэтому экспортируйте их заранее, если в клипе их больше одной.

## Управление узлом

| Параметр | Значения | Применимо к | Эффект |
| --- | --- | --- | --- |
| `audio` | запись длительностью до 1799 секунд | Clean Audio | Речь для очистки |
| `video` | клип со звуком длительностью до 1799 секунд | Clean Audio (in Video) | Клип, звуковая дорожка которого очищается. Изображение не перекодируется на этапе очистки |
| `strength` | от 0.0 до 1.0, по умолчанию 0.874 | оба узла | Насколько сильно удаляется шум под речью. Меньшие значения сохраняют больше естественного фона за голосом |
| `loudness` | `normalize`, `keep input level` | оба узла | Нормализуется ли выходной сигнал до целевой громкости |
| `target_lufs` | от -40 до -8, по умолчанию -19 | оба узла, только при `normalize` | Интегрированная громкость выходного сигнала |

Паузы между словами всегда очищаются полностью, независимо от значения `strength`, а значения выше значения по умолчанию меняют результат незначительно. Пики ограничены на уровне -1.1 dBTP, поэтому при громкой целевой громкости обработка останавливается раньше: обычная речь стабилизируется около -15 LUFS.

## Советы

- **Сначала оставьте `strength` по умолчанию.** Значение настроено под речь. Снижайте его только тогда, когда комнатный фон за голосом является частью звука, который вы хотите сохранить.
- **Нормализуйте, когда очищенное аудио должно совпадать с другими клипами.** Именно общий `target_lufs` заставляет серию записей звучать на одном уровне.
- **Не ждите, что музыка вернётся.** Музыка и эффекты удаляются вместе с шумом, поэтому этот узел очищает диалог, а не полный микс. Запускайте его на отдельной дорожке вокала, если звуковая дорожка должна сохраниться.
- **Обрезайте длинные записи перед запуском.** Ограничение составляет 1799 секунд, а короткий файл дешевле при поминутной тарификации.
- **Включите его в цепочку с узлами для говорящих портретов.** Очищенная речь даёт лучший вход для lip sync и говорящих портретов, чем исходная запись.
