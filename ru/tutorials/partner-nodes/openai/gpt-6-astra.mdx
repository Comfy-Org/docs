**GPT-6 Astra** — самая мощная модель OpenAI, созданная для сложнейших задач от начала до конца: комплексные рассуждения, программирование, работа с компьютером, исследования и создание документов. Выпущенная 3 сентября 2026 года, она поддерживает контекстное окно на 1 050 000 токенов, ввод текста и изображений, а также уровни интенсивности рассуждений от `low` до `max`.

В ComfyUI GPT-6 Astra работает через узел `OpenAI Chat`: выберите `gpt-6-astra` в выпадающем списке `model` этого узла. Эта страница посвящена использованию модели в рабочих процессах ComfyUI. С основами работы с узлом, общими для всех моделей, можно ознакомиться в [учебнике по OpenAI Chat](/ru/tutorials/partner-nodes/openai/chat).

## Когда выбирать GPT-6 Astra

Узел `OpenAI Chat` предлагает множество моделей, от `gpt-5-nano` до `gpt-6-astra`. GPT-6 Astra, самая мощная, но и самая дорогая опция, подходит для задач, где более дешёвые модели не справляются:

- **Анализ изображений с длинным контекстом**: передача множества изображений (через `Batch Images`) или больших файлов с промптами и запрос структурированного анализа за один проход
- **Промпт-инжиниринг**: превращение референсного изображения или черновой идеи в подробный позитивный промпт через запятую для моделей изображений или видео
- **Агентные рабочие процессы**: многошаговые задачи, например сначала анализ описания набора данных, затем составление плана генерации, затем написание самих промптов
- **Следование сложным инструкциям**: точные форматы вывода (JSON, YAML, фиксированный порядок разделов), которые небольшие модели обычно нарушают

Для простых подписей к изображениям или коротких ответов `gpt-5` или `gpt-5-mini` дают хороший результат при гораздо меньшей стоимости. Тарифы для каждой модели смотрите в [таблице цен](/ru/tutorials/partner-nodes/pricing).

## Использование модели в узле OpenAI Chat

Узел `OpenAI Chat` принимает:

- `prompt`: инструкция. Для задач генерации промптов опишите, что именно нужно извлечь из изображения, и желаемый формат вывода
- `images`: необязательный контекст изображений. Подключите `LoadImage` или `Batch Images` для нескольких изображений; каждое прикреплённое изображение отправляется в модель
- `files`: необязательные документы из узла `OpenAI Chat Input Files`
- `advanced_options`: необязательная конфигурация из узла `OpenAI Chat Advanced Options`

На выходе получается `String`. Типичные способы использовать его далее:

- В узел `Preview Any`, чтобы прочитать ответ
- В `Save Text`, чтобы записать сгенерированный промпт в файл `.txt`
- Во вход положительного промпта узла `CLIP Text Encode`, что позволяет строить полностью автоматические конвейеры генерации изображений или видео, где LLM пишет промпт
- В текстовые входы партнёрских узлов, например чтобы подготовить описание сцены перед генерацией видео

## Усилия рассуждения

GPT-6 Astra — это модель рассуждения. Подключите узел `OpenAI Chat Advanced Options` и задайте `reasoning_effort`, чтобы управлять балансом между качеством ответа и стоимостью:

| Уровень | Поведение |
|-------|----------|
| `default` | Модель выбирает автоматически |
| `low` | Самый быстрый и дешёвый, подходит для простого анализа |
| `medium` | Сбалансированный вариант по умолчанию для генерации промптов |
| `high` | Тщательный анализ сложных изображений или инструкций |
| `xhigh` | Глубокое многошаговое рассуждение |
| `max` | Максимальное рассуждение для самых сложных задач |

Тот же узел также предоставляет `max_output_tokens` (от 16 до 16384, включая токены рассуждения) и поле `instructions`, которое работает как постоянный системный промпт. Это полезно для фиксации формата вывода при многих запусках.

Шаги:

1. Загрузите изображение в узле `LoadImage`
2. В узле `OpenAI Chat` при необходимости измените промпт для анализа или переключите `model`. Промпт шаблона просит модель извлечь объект, композицию, камеру, освещение, цветовую палитру, текстуру и стиль, а затем вывести только позитивный промпт, разделённый запятыми
3. Нажмите `Run`. Сгенерированный промпт появляется в предпросмотре и сохраняется в файл `.txt` узлом `Save Text`

Чтобы пойти дальше, скопируйте сохранённый промпт в узел `CLIP Text Encode` или в узел модели изображений / видео и генерируйте напрямую из вывода модели.

GPT-6 Astra оплачивается по использованию токенов API, по более высокой ставке, чем другие модели OpenAI Chat. Подробности в [таблице цен](/ru/tutorials/partner-nodes/pricing).
