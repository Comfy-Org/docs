OpenAI GPT-Image-2 (`gpt-image-2`) - новейшая модель генерации изображений от OpenAI, доступная в ComfyUI через партнёрские узлы. Это первая модель изображений OpenAI, которая *рассуждает* перед генерацией: вместо одношаговой выборки модель планирует композицию, проверяет свою работу и итеративно улучшает результат.

Этот узел поддерживает:
- Генерацию из текста в изображение с уверенной обработкой плотного текста, элементов интерфейса, иконографии, инфографики, карт, слайдов и панелей манги
- Редактирование изображений с высокой структурной точностью при разрешении до 2K
- До 8 согласованных изображений из одного промпта с сохранением непрерывности персонажей и объектов

GPT-Image-2 выбирается как опция `model` на узле **OpenAI GPT Image 2.5** в Библиотеке нод. Узел синхронно вызывает API генерации изображений OpenAI и возвращает изображения, соответствующие описанию.

## В чём GPT-Image-2 особенно хорош

### Генерация на основе рассуждений

GPT-Image-2 планирует композицию перед рендерингом. Благодаря этому он хорошо подходит для промптов, которые ранее ломали модели генерации изображений: например, постер с маркированным списком из семи пунктов шрифтом Helvetica 11pt по центру. Модель выдаёт чистый результат для плотного текста, мелких элементов интерфейса, иконок, инфографики, карт и слайдов.

### Редактирование изображений с сохранением важного

GPT-Image-2 выполняет точечные правки со структурной точностью: всё за пределами зоны редактирования остаётся пиксельно стабильным, а запрошенное изменение аккуратно применяется в разрешении до 2K. Используйте его для таких задач, как раскрашивание чёрно-белых фотографий или смена освещения сцены с полуденного на сумеречное без искажения лиц, геометрии или мелких деталей.

### До восьми согласованных изображений на один промпт

Модель может вернуть до **восьми различных изображений на один промпт**, сохраняя непрерывность персонажей и объектов во всей серии. Это удобно для раскадровки, референсных листов, оборотных листов персонажей и вариантов продукта без фиксации seed и сложных ухищрений с промптами. Передайте пакет напрямую в узел `Save Image` или подключите его далее к рабочему процессу для видео.

## Гибридные pipeline

GPT-Image-2 естественно вписывается в гибридные pipeline: используйте его для насыщенного текстом основного кадра, затем передайте локальным моделям для увеличения разрешения, стилизации или генерации видео: лучшая модель для каждого шага в одном графе.

## Начало работы

1. Обновите ComfyUI до последней версии (v0.21.1 или более поздней) или используйте [Comfy Cloud](https://links.comfy.org/4u4o7Pv).
2. В Библиотеке нод найдите **OpenAI GPT Image 2.5** и добавьте этот узел.
3. Укажите в поле `model` значение `gpt-image-2`.
