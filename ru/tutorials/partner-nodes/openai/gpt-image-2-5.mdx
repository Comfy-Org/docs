OpenAI GPT Image 2.5 (`gpt-image-2.5`) — это новейшее семейство моделей изображений от OpenAI, доступное в ComfyUI через Партнёрские узлы на узле **OpenAI GPT Image 2.5**. Оно представлено в двух вариантах, настроенных для разных этапов творческого процесса:

- **GPT Image 2.5 Flare** (`gpt-image-2.5-flare`): быстрое создание и редактирование изображений, оптимизированное для быстрого прототипирования и творческих итераций. Он выдаёт быстрые превью для поиска концепции, мудбордов, черновиков постеров, набросков персонажей и макетов сцен, сочетая достойное визуальное качество с низкой задержкой для рабочих процессов с большим объёмом проб и ошибок.
- **GPT Image 2.5 Sunburst** (`gpt-image-2.5-sunburst`): создание и редактирование изображений с высокой точностью для отполированных, насыщенных деталями визуалов. Он сохраняет идентичность субъекта, сложные материалы, целостность освещения и структуру сцены между итерациями, что делает его подходящим для доработки концепции, визуалов продуктов, сцен с персонажами, кинематографичных фонов и готовых работ.

Оба варианта поддерживают текст в изображение и редактирование изображений с референсными изображениями (до 16), необязательную маску для инпейтинга и пять уровней качества: `low`, `medium`, `high`, `xhigh` и `max`.

Библиотека шаблонов сейчас включает четыре примера рабочих процессов:

- **Flare: Text to Image**. Быстрая генерация постера по текстовому промпту
- **Flare: Image Edit**. Замена одежды и причёски при неизменной сцене
- **Sunburst: Text to Image**. Высокоточный редакционный fashion-постер с отрисованной типографикой
- **Sunburst: Image Edit**. Высокоточное редактирование причёски и макияжа с сохранением субъекта

## Начало работы

1. Обновите ComfyUI до последней версии. Для узла и шаблонов требуется ComfyUI 0.35.0 или более поздняя версия
2. В Библиотеке нод найдите **OpenAI GPT Image 2.5** и добавьте узел
3. Задайте в поле `model` значение `gpt-image-2.5-flare` или `gpt-image-2.5-sunburst`

## Настройки узла

Узел **OpenAI GPT Image 2.5** синхронно вызывает API изображений OpenAI и возвращает сгенерированное изображение. Параметры зависят от выбранной модели:

- **model**: `gpt-image-2.5-flare` (быстрая итерация) или `gpt-image-2.5-sunburst` (высокая точность)
- **prompt**: Текстовое описание изображения для генерации или инструкция по редактированию, когда прикреплены референсные изображения
- **size**: `auto`, предустановленный размер, например `1024x1024` или `3840x2160`, либо `Custom`
- **custom_width / custom_height**: Используются только когда `size` имеет значение `Custom`. От 480 до 3840 с шагом 16
- **background**: `auto`, `opaque` или `transparent` (оба варианта 2.5 поддерживают прозрачный фон)
- **quality**: `low`, `medium`, `high`, `xhigh` или `max`. Влияет на стоимость и время генерации
- **images**: Необязательные референсные изображения для редактирования, до 16
- **mask**: Необязательная маска для инпейтинга (белые области заменяются). Требует ровно одно референсное изображение
- **n**: Сколько изображений генерировать (от 1 до 8)
- **seed**: Сохранён для совместимости с API; бэкенд пока его не использует

3. **Исключайте нежелательные элементы**: Промпт шаблона заканчивается списком исключений («No sidebar, no extra UI panels...»), который помогает сохранять плакаты чистыми
4. **Используйте размеры Custom**: Выберите `Custom` в параметре `size`, чтобы задать точную ширину и высоту с шагом 16 px, до 3840

## GPT Image 2.5 Flare: редактирование изображения

Редактируйте входное изображение с помощью Flare. Шаблон демонстрирует замену одежды и причёски, но рабочий процесс представляет собой универсальное редактирование изображений: изменение внешнего вида персонажа (одежда, причёска, аксессуары, выражение лица), замена объектов, замена фона, корректировки цвета и любые локальные изменения, для которых нужен быстрый предпросмотр. Подходит для итераций над правками перед финальным запуском в высоком качестве.

Советы:

1. **Укажите, что нужно сохранить**: промпт шаблона начинается с фразы «Keep the background environment... completely unchanged» перед описанием правки. Именно эта привязка сохраняет остальную часть кадра стабильной, и она работает для любого типа правки: опишите сцену, позу и освещение, которые нужно сохранить, а затем изменение, которое нужно внести
2. **Меняйте любой атрибут внешнего вида**: та же структура промпта подходит для смены одежды, причёски, аксессуаров, цветовых схем или полного редизайна персонажа с сохранением позы и сцены
3. **Одно изменение за запуск**: описывайте одну правку (или тесно связанный набор), а не список несвязанных изменений. Лучше выполните несколько итераций
4. **Маска для локальных правок**: подключите маску, чтобы ограничить правку определёнными областями; белые области заменяются. Маска требует ровно одного референсного изображения
5. **Итерируйте в Flare, завершайте в Sunburst**: используйте Flare, чтобы недорого исследовать варианты правок, затем повторно запустите удачный промпт с `gpt-image-2.5-sunburst` для финального рендера

## GPT Image 2.5 Sunburst: текст в изображение

Сгенерируйте высокодетализированный редакционный постер с помощью Sunburst. Промпт шаблона представляет собой длинный структурированный редакционный промпт: сцена, субъект, крупная типографика, разбросанные графические элементы, блок подписи и полная спецификация палитры и рендеринга. Используйте его как каркас для собственных промптов постера.

1. **Структурируйте длинные промпты по слоям**: промпт шаблона описывает по одному слою за раз (фоновая сцена, субъект, типографика, мелкие графические элементы, подпись, затем общий стиль). Так каждый элемент остаётся там, где вы его указали
2. **Закрепите расположение текста**: укажите, что это за текст, его стиль шрифта, цвет и что он должен перекрывать («буквы, вплетающиеся в верхнюю половину кадра, некоторые позади байкера, некоторые спереди»)

4. **Повышайте качество для финальных вариантов**: преимущество Sunburst в точности проявляется при `high` и выше; для экспериментов оставляйте `low`

## GPT Image 2.5 Sunburst: редактирование изображений

Редактируйте исходное изображение с высокой точностью Sunburst. Шаблон демонстрирует смену причёски и макияжа, но рабочий процесс предназначен для универсального редактирования изображений: замена внешнего вида персонажа (одежда, причёска, аксессуары), добавление или удаление объектов, преобразование стиля и точные частичные изменения. Используйте его для любых правок, где важны сохранение идентичности и точность деталей.

Советы:

1. **Сначала список сохранения, потом список изменений**: в промпте шаблона сначала перечисляется всё, что нужно сохранить («Оставить голову, лицо, тело, цветы, свитер, фон и освещение без изменений»), а затем единственное изменение. Следуйте этому порядку при любых правках: смене внешнего вида, изменениях объектов, замене фона или преобразовании стиля
2. **Замена внешнего вида персонажа**: чтобы задать персонажу новый наряд или образ, перечислите якоря идентичности, которые нужно сохранить (лицо, пропорции тела, позу, освещение), а затем точно опишите новый внешний вид
3. **Устойчивая согласованность субъекта**: Sunburst сохраняет идентичность при последовательных правках, что делает его пригодным для многошаговых цепочек редактирования и генерации кадр за кадром с одним и тем же персонажем
4. **Прозрачный фон**: оба варианта могут возвращать `transparent` фон; это полезно для композиционирования результата в другую сцену далее по цепочке
