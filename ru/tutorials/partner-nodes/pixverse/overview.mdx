PixVerse — платформа генерации видео с помощью ИИ, которая создаёт кинематографичные видео из текста и изображений и теперь интегрирована в ComfyUI в виде партнёрских узлов. Поддерживаются модели **V5.6**, **V6**, **C1** и **R1**, а режимы **текст в видео**, **изображение в видео** и **изображение в видео по шаблону** позволяют быстро и повторяемо создавать видео без отдельных ключей API и внешней настройки.

## Ключевые возможности

- **Текст в видео**: генерация оригинальных видео по текстовым промптам; подходит для визуализации концепций, раскадровки и быстрого творческого поиска.
- **Изображение в видео**: анимация опорного изображения с сохранением внешнего вида объекта и композиции сцены; статичное изображение оживает с естественным движением.
- **Изображение в видео по шаблону**: применение заранее заданных шаблонов движения к входным изображениям для предсказуемых и повторяемых стилей анимации, подходящих для производственных пайплайнов.
