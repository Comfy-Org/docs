**Stable Audio 1.0** — первая модель генерации аудио с открытым исходным кодом от Stability AI. Она принимает текстовый промпт и генерирует аудиофрагмент. В ComfyUI она работает как стандартный pipeline «текст в аудио»: CLIP кодирует промпт, сэмплер KSampler удаляет шум из латента, а VAE декодирует его в аудио.

**Связанные ссылки**:
- [Hugging Face (stabilityai/stable-audio-open-1.0)](https://huggingface.co/stabilityai/stable-audio-open-1.0)

Рабочий процесс использует **стандартные узлы ComfyUI**: пользовательские узлы не требуются. Он загружает чекпойнт Stable Audio 1.0, кодирует ваш промпт через текстовый энкодер CLIP (t5-base), удаляет шум из латента аудио с помощью KSampler и декодирует его в аудио через VAE модели.

**Как использовать**:
1. **Загрузите чекпойнт**: узел `CheckpointLoaderSimple` использует `stable-audio-open-1.0.safetensors`
2. **Напишите промпт**: введите своё описание в узле `CLIPTextEncode` (например, «heaven church electronic dance music»)
3. **Задайте длительность**: настройте значение length у узла `EmptyLatentAudio` (по умолчанию 47.6 секунды)
4. Нажмите **Run** (`Ctrl/Cmd + Enter`), чтобы сгенерировать. Аудио будет сохранено в `ComfyUI/output/audio/`

## Загрузка модели

При загрузке рабочего процесса ComfyUI предложит вам ссылки для скачивания отсутствующих моделей. Чтобы настроить всё вручную, скачайте файлы ниже и поместите их в соответствующие папки.

### Чекпойнт

<Card title="stable-audio-open-1.0.safetensors" icon="download" href="https://huggingface.co/StabilityAI/stable-audio-open-1.0/blob/main/stable-audio-open-1.0.safetensors">
    2.3GB. Поместите в models/checkpoints/
  </Card>

Поместите чекпойнт в:

```
📂 ComfyUI/
├── 📂 models/
│   └── 📂 checkpoints/
│       └── stable-audio-open-1.0.safetensors
```

### Текстовый энкодер

<Card title="t5-base.safetensors" icon="download" href="https://huggingface.co/Comfy-Org/t5-base/blob/main/t5-base.safetensors">
    Текстовый энкодер для формирования условия по промпту. Поместите в models/text_encoders/
  </Card>

Поместите текстовый энкодер в:

```
📂 ComfyUI/
├── 📂 models/
│   └── 📂 text_encoders/
│       └── t5-base.safetensors
```

После размещения файлов нажмите **R** в ComfyUI, чтобы обновить узлы и загрузить последние модели.
