## Links connect nodes

In ComfyUI, the lines or curves drawn between nodes are called **_links_** (also referred to as **_connections_** or wires). They carry data from one node's output to another node's input, defining the flow of your workflow.

Every link operation below works on the same target: the small colored circle at the edge of a node port. Outputs sit on the right edge of a node, inputs on the left.

### Connect two nodes

Drag from an output port to the input port of the same color. Compatible ports highlight while you drag, and the link snaps to the input when you release.

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/connect-two-nodes.mp4"
></video>

Ports carry a color per data type, and only ports of the same color connect. See [Color-coding](#color-coding) for the full list.

### Drop a link on empty canvas

Release the link over empty canvas and ComfyUI opens the add-node search filtered to the data type you are carrying. Pick a node from the list and it is created already connected, which is the fastest way to extend a chain.

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/release-on-empty-search.mp4"
></video>

Hold `Shift` while releasing for the context menu instead. It offers **Add Node**, **Add Reroute**, **Add SetNode**, the compatible node types, and the same search box.

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/release-shift-context-menu.mp4"
></video>

Both behaviors are configurable in **Settings → Lite Graph → Link Release**. Set **Action on link release (No modifier)** and **Action on link release (Shift)** to search box, context menu, or no action.

### Hide or delete a link

Right-click a link to open its menu:

- **Hide Link** keeps the connection and hides only the wire, so the data still flows
- **Delete** removes the connection
- **Add Reroute** inserts a reroute point on the wire
- **Add Node** opens the compatible node list and splices the new node into the link
- **Convert to Set/Get** replaces the wire with a Set node and a Get node pair

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/delete-link.mp4"
></video>

### Hide every link

The link visibility toggle in the canvas toolbar hides all wires at once without changing the workflow. It is the same as setting **Link Render Mode** to **Hidden**, and turning it back on restores the previous style.

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/hide-links.mp4"
></video>

<Tip>
Showing links is especially useful when learning, sharing, or debugging a workflow. They make the data flow visible at a glance. For finished workflows that aren't meant to be edited, hiding links can reduce visual clutter.
</Tip>

### Reroute a link

When a workflow becomes complex, wires overlap or pass behind nodes. **Add Reroute** in the link menu drops a native reroute point on the wire; drag that point anywhere to route the wire around other nodes.

<video
  controls
  className="w-full aspect-video"
  src="/images/basic-concepts/links/link-menu-reroute.mp4"
></video>

ComfyUI also ships a **Reroute** node, which does the same job with an explicit node you can put in a group, bypass, or reuse. For new workflows, the native reroute point is enough.

## Link render modes

Links can be drawn as curves, right angles, straight lines, or hidden entirely.

![Link styles](/images/interface/link/link_styles.jpg)

Change the style in **Settings → Lite Graph → Graph → Link Render Mode**, or toggle link visibility from the canvas toolbar.

![Render mode setting](/images/interface/link/render_mode.jpg)

## Color-coding

Every data type in ComfyUI has a distinct color. Node input and output ports, as well as the link wires connecting them, all share this color scheme. **You can only connect ports of the same color**. This ensures type safety across your workflow.

![ComfyUI Node Data Types](/images/concepts/node/data_type.jpg)

| Data type                 | Color       |
|---------------------------|-------------|
| Diffusion model           | Lavender    |
| CLIP model                | Yellow      |
| VAE model                 | Rose        |
| Conditioning              | Orange      |
| Latent Image              | Pink        |
| Pixel image               | Blue        |
| Mask                      | Green       |
| Number (integer or float) | Gray        |
| Mesh                      | Bright green|
