<Warning>
  **Vista previa privada: aún no disponible al público.** El servidor MCP de Comfy Partner está actualmente en pruebas privadas. Las funciones y las API pueden cambiar. El acceso está limitado a los socios invitados.
</Warning>

Comfy Partner MCP es un servidor MCP local que proporciona a los agentes de IA herramientas de generación unificadas en **más de 30 proveedores socios**, entre ellos BFL, Ideogram, Kling, Runway, Veo, Meshy, ElevenLabs y más. Usa una única forma de solicitud canónica para todos los tipos de generación.

**Funciones principales:**
- 🎨 **6 modalidades de generación**: imagen, video, 3D, SVG, audio y música
- 🔌 **Más de 30 proveedores** en una sola interfaz
- 💻 **Servidor local**: se ejecuta en tu máquina y se conecta a la API de Comfy
- 🔍 **Buscar modelos integrado** con búsqueda de texto BM25
- 🧩 **Compatible de forma directa** con Claude Desktop, Claude Code y Amp

---

## Requisitos

- **Node.js 20+**
- **pnpm 10**
- **[Clave API de Comfy](/es/development/api-development/getting-an-api-key)** (empieza por `comfyui-`). Consíguela en el panel de socios de Comfy

---

## Instalación

```bash
git clone <repo-url> partner-mcp
cd partner-mcp
pnpm install
pnpm build
```

Después de compilar, el lanzador del servidor MCP está en `packages/mcp/dist/bin.js`.

---

## Configuración

Añade el servidor a la configuración de tu cliente MCP. El mismo formato JSON funciona en Claude Desktop, Claude Code y Amp:

```json
{
  "mcpServers": {
    "comfy-partner": {
      "command": "node",
      "args": ["/ABSOLUTE/PATH/TO/partner-mcp/packages/mcp/dist/bin.js"],
      "env": {
        "COMFY_API_KEY": "comfyui-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX"
      }
    }
  }
}
```

**Ubicaciones de la configuración del cliente:**

| Cliente | Archivo de configuración |
|--------|-------------|
| Claude Desktop | `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) / `%APPDATA%/Claude/claude_desktop_config.json` (Windows) |
| Claude Code | `~/.claude/mcp.json` (or run `claude mcp add`) |
| Amp | Settings → MCP Servers, o `~/.config/amp/settings.json` |

Después de añadir la configuración, reinicia tu cliente MCP. Deberías ver **10 herramientas** registradas en el servidor `comfy-partner`.

Para comprobar que el servidor arranca correctamente antes de conectarlo a un cliente, ejecútalo directamente: debería imprimir el handshake JSON-RPC y después quedarse inactivo:

```bash
COMFY_API_KEY=comfyui-... node /ABSOLUTE/PATH/TO/partner-mcp/packages/mcp/dist/bin.js
```

## Variables de entorno

| Variable | Requerido | Propósito |
|----------|----------|---------|
| `COMFY_API_KEY` | sí | Clave API (`comfyui-…`). Se envía como cabecera `X-API-Key`. |
| `COMFY_API_BASE_URL` | no | Sobrescribe el host del proxy (de forma predeterminada, la API de Comfy de producción). |
| `COMFY_INLINE_LIMIT_KB` | no | Límite (KB) para la inclusión en línea de los bytes de imagen en los resultados de la herramienta. Predeterminado: `600`. |
| `COMFY_MCP_RESOURCE_LINKS` | no | Fuerza la activación o desactivación de los bloques de contenido `resource_link`. De forma predeterminada, usa una lista de permitidos (`claude-*`, `mcp-inspector`). |

## Herramientas disponibles

El servidor MCP expone **10 herramientas**. Después de una instalación correcta, tu cliente MCP debería mostrar las 10 registradas en el servidor `comfy-partner`.

| Herramienta | Descripción |
|------|-------------|
| `generate_image` | Generar imágenes fijas: texto a imagen, edición o upscale |
| `generate_video` | Generar clips de video: texto a video, imagen a video o sincronización labial |
| `generate_3d` | Generar mallas 3D (GLB/FBX/OBJ) a partir de texto o una imagen de referencia |
| `generate_svg` | Generar ilustraciones vectoriales SVG a partir de un prompt de texto |
| `generate_audio` | Generar voz, clones de voz o efectos de sonido a partir de texto |
| `generate_music` | Generar música instrumental o vocal a partir de un prompt |
| `media_upload` | Subir un archivo (imagen/video/audio) y obtener una referencia `media:<id>` para usar en llamadas `generate_*` |
| `read_media` | Obtener y renderizar un artefacto multimedia insertado: acepta una URL HTTPS o un token `media:…` |
| `models_explore` | Descubrir modelos, buscar por capacidad y consultar la forma completa de llamada de un modelo |
| `balance` | Obtener el saldo restante de la cuenta actual en USD |
