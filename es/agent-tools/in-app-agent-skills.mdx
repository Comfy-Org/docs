## ¿Qué es una habilidad personal?

Una habilidad personal es un conjunto reutilizable de instrucciones para Comfy Agent. Incluye un nombre, una descripción de una línea sobre cuándo usarla y las instrucciones en sí.

Usa habilidades personales para repetir instrucciones como «haz imágenes cuadradas», «usa un fondo blanco» o «revisa las conexiones entre nodos antes de ejecutar».

Las habilidades personales se guardan en tu cuenta. El Agente carga una habilidad cuando su descripción coincide con tu solicitud o cuando la pides por su nombre.

## Crear una habilidad en el chat

Dile al Agente qué guardar, cómo llamarla y cuándo debe usarse:

> Guarda esto como una habilidad llamada product-shot: cuando pida una imagen de producto, usa un lienzo cuadrado de 1024 × 1024, un fondo gris neutro y un nodo Save Image. Valida el flujo de trabajo antes de ejecutarlo.

El Agente guarda la habilidad para mensajes futuros. Una habilidad nueva o actualizada surte efecto con tu siguiente mensaje.

## Gestionar habilidades desde el panel del Agente

El menú **+** del cuadro de mensaje tiene un submenú **Habilidades** con la lista de tus habilidades. Elige una para adjuntarla a tu mensaje, o selecciona **Administrar habilidades** para abrir la pantalla de habilidades, donde puedes añadir, editar y eliminar habilidades.

![Pantalla de habilidades en el panel del Agente](/images/agent_tools/agent_skills_panel.png)

El nombre de una habilidad no se puede cambiar después de guardarla. Para renombrarla, elimínala y vuelve a añadirla con el nuevo nombre. Si cierras el formulario de alta o edición sin guardar, lo que escribiste queda como borrador en este dispositivo y la lista lo marca hasta que lo guardes o lo descartes.

## Campos de una habilidad

| Campo | Para qué sirve | Reglas |
| --- | --- | --- |
| **Nombre** | El identificador con el que el Agente carga la habilidad. | Hasta 64 caracteres, con letras, dígitos, `.`, `_` y `-`. Debe ser único, y los nombres de las habilidades integradas que siempre se cargan están reservados. |
| **Cuándo usar** | Una línea que indica cuándo cargar la habilidad. Viaja con cada mensaje, se use la habilidad o no. | Una sola línea de hasta 1024 caracteres. Mantenla corta. |
| **Instrucciones** | Lo que el Agente sigue una vez cargada la habilidad. | Obligatorio. |

## Límites de tamaño

La lista muestra el tamaño de cada habilidad en bytes. Al añadir o editar una habilidad, el formulario muestra el tamaño de las instrucciones mientras escribes. Las habilidades comparten un límite de tamaño para tu cuenta. Si al guardar se supera el límite, el formulario no lo guarda y te pide eliminar antes una habilidad.

## Usar una habilidad

Pide una habilidad por su nombre:

> Usa mi habilidad product-shot para crear un flujo de trabajo de fotografía de estudio para una zapatilla roja.

El Agente también puede seleccionar una habilidad automáticamente cuando tu solicitud coincide con su descripción. Para elegir una de tu lista, escribe `/` en el cuadro de mensaje y selecciónala en la sección **Habilidades** del menú.

## Actualizar o eliminar una habilidad

Usa el mismo nombre de habilidad para reemplazar sus instrucciones:

> Actualiza mi habilidad product-shot para que use un fondo blanco y un lienzo de 1536 × 1536.

Elimina una habilidad por su nombre:

> Elimina mi habilidad product-shot.

## Guardar un archivo de habilidad existente

Pega el contenido de tu archivo `SKILL.md` en el chat y pide al Agente que lo guarde como una habilidad personal. El Agente lee su nombre y su descripción del encabezado al inicio del archivo. La habilidad guardada está disponible desde tu siguiente mensaje.

## Usar una habilidad pública

Las habilidades públicas son habilidades compartidas que cualquiera puede usar, no solo las que tú creaste. Pide una habilidad pública por su nombre o describe lo que quieres hacer, y el Agente la usa igual que una de las tuyas:

> Usa la habilidad pública product-shot para una zapatilla roja sobre un fondo gris neutro.

## Orientación integrada y habilidades para agentes de programación

Comfy Agent incluye orientación para crear flujos de trabajo y elegir modelos. Las habilidades personales y públicas añaden instrucciones para tareas repetitivas sobre esa orientación.

Las [habilidades para agentes de programación](/es/agent-tools/skills) se instalan por separado en herramientas como Claude Code. Instalar una allí no la agrega a Comfy Agent.

No incluyas claves de API, contraseñas ni tokens de acceso en las instrucciones de las habilidades. Para saber cómo se manejan los datos, consulta [Datos y privacidad](/es/agent-tools/in-app-agent-data-privacy#habilidades-y-orientación).
