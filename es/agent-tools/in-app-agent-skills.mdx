## ¿Qué es un paquete de habilidades?

Un paquete de habilidades es un conjunto reutilizable de instrucciones para Comfy Agent. Cada paquete incluye un nombre, una línea de activación que indica cuándo cargarlo y las instrucciones en sí.

Usa paquetes para preferencias que repites, como «haz imágenes cuadradas», «usa un fondo blanco» o «revisa las conexiones entre nodos antes de ejecutar».

Los paquetes que creas son privados de tu cuenta. El Agente carga un paquete cuando su línea de activación coincide con tu solicitud o cuando lo pides por su nombre.

## Crear una habilidad en el chat

Dile al Agente qué guardar, cómo llamarla y cuándo debe usarse:

> Guarda esto como una habilidad llamada product-shot: cuando pida una imagen de producto, usa un lienzo cuadrado de 1024 × 1024, un fondo gris neutro y un nodo Save Image. Valida el flujo de trabajo antes de ejecutarlo.

El Agente guarda la habilidad para mensajes futuros. Una habilidad nueva o actualizada surte efecto con tu siguiente mensaje.

## Usar una habilidad

Pide una habilidad por su nombre:

> Usa mi habilidad product-shot para crear un flujo de trabajo de fotografía de estudio para una zapatilla roja.

El Agente también puede seleccionar una habilidad automáticamente cuando tu solicitud coincide con su línea de activación. Para elegir una de tu lista, escribe `/` en el cuadro de mensaje y selecciónala en la sección **Skills** (Habilidades) del menú.

## Gestionar paquetes de habilidades en Ajustes

Abre **Ajustes** → **Paquetes de habilidades** para ver todos los paquetes de tu cuenta. Cada paquete aparece con su nombre y su tamaño.

- **Añadir paquete de habilidades** abre un formulario para crear uno nuevo.
- **Editar** cambia la línea de activación o las instrucciones de un paquete existente. El nombre no se puede cambiar después de crearlo.
- **Eliminar** quita un paquete. No se puede deshacer.

## Campos de un paquete de habilidades

| Campo | Para qué sirve | Reglas |
| --- | --- | --- |
| **Nombre** | El identificador con el que el Agente carga el paquete. | Hasta 64 caracteres, con letras, dígitos, `.`, `_` y `-`. Debe ser único, y los nombres de los paquetes integrados que siempre están activos están reservados. |
| **Línea de activación** | Una línea que indica cuándo cargar el paquete. Viaja con cada mensaje, se use el paquete o no. | Una sola línea de hasta 1024 caracteres. Mantenla corta. |
| **Instrucciones** | Lo que el Agente sigue una vez cargado el paquete. | Obligatorio. |

## Límites de tamaño

La lista muestra el tamaño total de cada paquete en bytes. Al crear o editar un paquete, el formulario muestra el tamaño de las instrucciones mientras escribes. Los paquetes comparten un límite de tamaño para tu cuenta. Si un paquete nuevo supera el límite, el formulario no lo guarda y te pide eliminar antes un paquete.

## Actualizar o eliminar una habilidad

Usa el mismo nombre de habilidad para reemplazar sus instrucciones:

> Actualiza mi habilidad product-shot para que use un fondo blanco y un lienzo de 1536 × 1536.

Elimina una habilidad por su nombre:

> Elimina mi habilidad product-shot.

## Guardar un archivo de habilidad existente

Pega el contenido de tu archivo `SKILL.md` en el chat y pide al Agente que lo guarde como un paquete de habilidades. El Agente lee su nombre y su descripción del encabezado al inicio del archivo. La habilidad guardada está disponible desde tu siguiente mensaje.

## Usar una habilidad pública

Las habilidades públicas son habilidades compartidas que cualquiera puede usar, no solo las que tú creaste. Pide una habilidad pública por su nombre o describe lo que quieres hacer, y el Agente la usa igual que una de las tuyas:

> Usa la habilidad pública product-shot para una zapatilla roja sobre un fondo gris neutro.

## Orientación integrada y habilidades para agentes de programación

Comfy Agent incluye orientación para crear flujos de trabajo y elegir modelos. Los paquetes de habilidades y las habilidades públicas añaden instrucciones para tareas repetitivas sobre esa orientación.

Las [habilidades para agentes de programación](/es/agent-tools/skills) se instalan por separado en herramientas como Claude Code. Instalar una allí no la agrega a Comfy Agent.

No incluyas claves de API, contraseñas ni tokens de acceso en las instrucciones de las habilidades. Para saber cómo se manejan los datos, consulta [Datos y privacidad](/es/agent-tools/in-app-agent-data-privacy#habilidades-y-orientación).
