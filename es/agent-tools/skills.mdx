[**Comfy Skills**](https://github.com/Comfy-Org/comfy-skills) es el hogar de las habilidades y los plugins para agentes de programación. Las habilidades son conocimiento empaquetado que un agente carga bajo demanda: orientación sobre modelos, patrones de flujo de trabajo y comandos listos para usar.

El repositorio aloja:

- **Plugins de Claude Code**: por ejemplo **comfy-cloud**, que añade la conexión MCP de Comfy Cloud y los comandos de barra `/comfy-cloud:*` en una sola instalación.
- **Habilidades de agente**: instrucciones enfocadas en tareas específicas, como las recomendaciones actuales de modelos y el conocimiento para crear flujos de trabajo, mantenidas al día a medida que cambian los modelos.
- **Contribuciones de la comunidad**: habilidades y plugins de la comunidad de Comfy.

Para usarlo en Claude Code:

```
/plugin marketplace add Comfy-Org/comfy-skills
/plugin install comfy-cloud@comfy-skills
```

Para ver los comandos de barra del plugin y los detalles de configuración, consulta [Comfy MCP](/es/agent-tools/mcp).
