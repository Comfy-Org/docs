[comfy-cli](https://github.com/Comfy-Org/comfy-cli) es la herramienta de línea de comandos de Comfy. Junto con los [servidores MCP](/es/agent-tools), ofrece a los agentes y a los desarrolladores otra forma de controlar Comfy desde fuera de la interfaz.

Úsala para el **acceso desde terminal o scripts**: tareas por lotes, pipelines de CI, automatización de flujos de trabajo y uso combinado con agentes de programación mediante las habilidades incluidas en la CLI.

<Info>
  **Referencia rápida para agentes.** Esta página es un resumen breve: lo suficiente para orientarte junto con MCP y ejecutar las llamadas habituales de `comfy generate`. Para la **documentación completa de la CLI** (instalación local, `comfy setup`, `comfy run`, plantillas, edición de flujos de trabajo, descubrimiento de nodos y modelos, y más), consulta [Primeros pasos con Comfy CLI](/es/comfy-cli/getting-started).
</Info>

## Cómo encaja con MCP

| | Comfy MCP (cloud) | Comfy CLI |
|---|---|---|
| **Interfaz** | Chat con un cliente MCP (Claude Code, Claude Desktop, …) | Comandos de terminal y scripts |
| **Ideal para** | Flujos de trabajo interactivos con agentes en el chat | Automatización, ejecuciones por lote, CI, canalizaciones de shell |
| **Autenticación** | OAuth en clientes MCP, o clave API (sin interfaz) | `comfy cloud login` (OAuth) o clave API (CI) |
| **Salida** | Devuelta en la sesión de chat | Guardada en disco (`--download`) o en JSON (`--json`) |

Para la configuración de MCP, la instalación, las listas de herramientas y los métodos de autenticación, consulta [Comfy MCP](/es/agent-tools/mcp).

## Qué hace el CLI

1. **ComfyUI local**: instala, inicia, actualiza y administra nodos personalizados
2. **Generación con socios**: `comfy generate` para llamadas puntuales a la API de socios de imagen, video, audio y 3D
3. **Flujos de trabajo en la nube**: `comfy run`, plantillas, edición de slots y seguimiento de tareas en Comfy Cloud

## Install and set up

<InstallCli/>

```bash
comfy setup
```

Pass `-y` for non-interactive installs in CI or scripts. See [Comfy CLI getting started](/es/comfy-cli/getting-started#configuración-rápida-recomendado) for the full `comfy setup` flag table.

Sign in to Comfy Cloud:

```bash
comfy cloud login
comfy cloud whoami
```

## Modelos disponibles

`comfy generate` abarca modelos de socios para imagen y video. Descubre qué hay disponible en tu versión de la CLI:

```bash
comfy generate list                            # todos los modelos
comfy generate list --category text-to-video   # filtrar por categoría
comfy generate list --partner kling            # filtrar por socio
comfy generate schema flux-kontext             # parámetros de un modelo
```

Los alias comunes incluyen:

| Categoría | Ejemplos |
|---|---|
| **Imagen** | `flux-pro`, `flux-ultra`, `flux-kontext`, `nano-banana`, `grok`, `grok-edit`, `ideogram-edit`, `dalle`, `recraft`, `stability` |
| **Video** | `seedance`, `kling`, `luma`, `runway`, `pika`, `vidu`, `hailuo`, `moonvalley`, `grok-video` |

Ejecuta `comfy generate list` para ver el conjunto completo en tu entorno.
