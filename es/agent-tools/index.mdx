| | Comfy MCP<br />Conexión con la nube | Comfy MCP<br />Conexión local | Comfy Agent |
|---|---|---|---|
| **Qué es** | Ejecuta flujos de trabajo de Comfy Cloud con tu propio agente. | Controla tu propio ComfyUI local con tu propio agente. | Chatea con un agente dentro de ComfyUI para entender, crear, editar y ejecutar un flujo de trabajo seleccionado. |

## ¿Qué es MCP?

El **Model Context Protocol (MCP)** es un estándar abierto que permite a los asistentes de IA interactuar con herramientas y servicios externos mediante una interfaz estandarizada. En lugar de que un agente de IA necesite conocer formatos de API personalizados para cada servicio, MCP ofrece una forma uniforme de exponer herramientas.

Cuando conectas un servidor MCP a Claude Desktop, Claude Code, Cursor o Amp, el asistente de IA puede:

- **Generar imágenes** a partir de descripciones de texto
- **Crear videos** a partir de texto o imágenes
- **Generar modelos 3D** a partir de texto o imágenes
- **Generar audio y música** con modelos de IA
- **Buscar modelos y plantillas** para encontrar las herramientas adecuadas para tu tarea

...todo mediante una conversación en lenguaje natural, sin escribir llamadas a la API manualmente.
