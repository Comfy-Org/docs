## Descripción general

Comfy Cloud te permite importar modelos directamente desde Civitai y Hugging Face. Esta función está disponible para usuarios con una suscripción **Creator** o superior.

## Requisitos

- **Suscripción**: plan Creador o superior
- **Fuentes compatibles**: Civitai y Hugging Face

## Cómo importar modelos

### 1. Accede a la función de importación
![Importar](/images/cloud/import_model/import_model.png)
1. Haz clic en el botón **Modelos** de la barra lateral izquierda para abrir la Biblioteca de modelos.
2. En la ventana de la Biblioteca de modelos, haz clic en el botón **Importar**.

### 2. Pega el enlace
1. Pega el enlace del modelo que obtuviste de Hugging Face o Civitai.
![Ventana de importación](/images/cloud/import_model/import_model_modal-1.png)

2. Si el enlace es válido, verás un indicador de confirmación y podrás hacer clic en el botón `Continue` para continuar.
![Ventana de importación](/images/cloud/import_model/import_model_modal-2.png)

3. Selecciona el tipo de modelo y la carpeta de destino.
![Ventana de importación](/images/cloud/import_model/import_model_modal-3.png)

4. Espera a que el modelo termine de descargarse.
![Ventana de importación](/images/cloud/import_model/import_model_modal-4.png)

5. Una vez descargado, puedes encontrar el modelo en tu Biblioteca de modelos.

## Cómo ver los modelos importados

En la Biblioteca de modelos, selecciona "Mis modelos" en el filtro desplegable para filtrar los modelos que importaste.

![Modelos importados](/images/cloud/import_model/imported_model.png)

## Cómo obtener enlaces de importación de modelos

### 1. Obtén el enlace desde Civitai

1. Ve a [Civitai](https://civitai.com/) y busca el modelo que quieres importar.
2. Haz clic derecho en el botón de descarga y selecciona "Copiar dirección del enlace" para obtener el enlace de descarga del modelo.

![Copiar enlace de Civitai](/images/cloud/import_model/copy_civitai_link.png)

### 2. Obtén el enlace desde Hugging Face

1. Ve a [Hugging Face](https://huggingface.co/) y busca el repositorio del modelo que quieres importar.
2. Navega a la página de archivos del modelo. Los formatos compatibles suelen ser archivos ".safetensor" o ".sft". Haz clic en el nombre del modelo específico para entrar a su página de detalles.

![Copiar enlace del modelo de Huggingface](/images/cloud/import_model/copy_huggingface_link-1.png)

3. En la página de detalles, haz clic en el botón `Copy Download Link` para obtener el enlace de descarga del modelo.

![Copiar enlace del modelo de Huggingface](/images/cloud/import_model/copy_huggingface_link-2.png)

## Importar modelos privados

Si quieres importar modelos privados desde Hugging Face o Civitai, primero debes configurar tus claves API.

### 1. Genera tus claves API

Primero, debes generar claves API desde las plataformas correspondientes:

<Tabs>
  <Tab title="Civitai">
    1. Inicia sesión en Civitai y visita [https://civitai.com/user/account](https://civitai.com/user/account).
    2. Genera tu clave API en la configuración de la cuenta.

    ![Clave API de Civitai](/images/cloud/import_model/civitai_key-1.png)
  </Tab>
  <Tab title="Hugging Face">
    1. Visita [https://huggingface.co/settings/tokens](https://huggingface.co/settings/tokens).
    2. Genera tu token de API.

    ![Clave API de Hugging Face](/images/cloud/import_model/huggingface_key-1.png)

    3. Asegúrate de que tu token tenga acceso de lectura a los repositorios que contienen los modelos privados que quieres importar.

    ![Permisos del token de Hugging Face](/images/cloud/import_model/huggingface_key-2.png)
  </Tab>
</Tabs>

### 2. Guarda tus claves API

1. Ve a [Configuraciones de Comfy Cloud](https://cloud.comfy.org) y navega hasta la sección **Credenciales**.

![Credenciales de configuración](/images/cloud/import_model/setting_secerts-1.png)

2. Haz clic para agregar tus claves API (puedes nombrar la clave como quieras):

![Agregar clave secreta](/images/cloud/import_model/setting_secerts-2.png)

3. Asegúrate de que tus claves API tengan permisos de acceso a los modelos privados que quieres importar.

### 3. Importa el modelo privado

Una vez que tus claves API estén configuradas, puedes importar modelos privados usando el mismo proceso que para los modelos públicos:

1. Obtén el enlace del modelo desde Hugging Face o Civitai.
2. Pega el enlace en la ventana de importación.
3. El sistema usará automáticamente tus claves API guardadas para acceder al modelo privado.

<Note>
Asegúrate de que tu clave API tenga los permisos necesarios para acceder al modelo privado específico que quieres importar.
</Note>

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Hay restricciones sobre los modelos que puedo subir?">
    Sí. Solo se admiten archivos de tipo **safetensor**. En la práctica, no hay límite de tamaño de archivo (hasta 100GB).
  </Accordion>

  <Accordion title="¿Los modelos que subo son privados o se comparten con todos?">
    Los modelos que importas son **privados para ti**. Solo tú puedes ver los modelos de tu biblioteca.
  </Accordion>

  <Accordion title="¿Puedo subir mis propios modelos personalizados desde mi disco duro local?">
    Por ahora, primero debes subir el modelo a un **repositorio público de Hugging Face o Civitai** y luego importarlo desde esas plataformas.
  </Accordion>

  <Accordion title="¿Puedo subir archivos de modelos divididos en partes?">
    No. Debes combinar los archivos de modelos divididos en partes en un solo archivo antes de importar.
  </Accordion>

  <Accordion title="¿Esta función está incluida en mi suscripción actual a la nube?">
    Esta función solo está disponible para los planes **Creator** y **Pro**.
  </Accordion>

  <Accordion title="¿Esta función está disponible en las versiones Desktop o portable de Comfy?">
    No. Es una función **exclusiva de la nube**.
  </Accordion>

  <Accordion title="¿Puedo eliminar un modelo que subí?">
    Sí. Puedes eliminar los modelos que importaste. Ten en cuenta que los modelos subidos por el equipo interno de Comfy no se pueden eliminar.
  </Accordion>

  <Accordion title="¿Qué tipos de modelos puedo importar (BYOM)?">
    No solo los ejemplos a continuación. BYOM admite cualquier carpeta de modelos que Comfy Cloud muestre en el **selector de tipo de importación** durante la importación. Esa lista proviene de las carpetas de modelos de ComfyUI compatibles con Comfy Cloud y es la fuente de referencia.

    En la práctica, si ComfyUI trata un archivo como un peso de modelo (checkpoint, LoRA, VAE, ControlNet, embedding, upscaler, IP-Adapter, SAM, codificador de audio y similares), puedes importarlo siempre que la carpeta aparezca en ese selector.

    Ejemplos comunes:

    - **Checkpoints y UNets**: `checkpoints`, `diffusion_models`
    - **LoRAs y adaptadores**: `loras`, `animatediff_motion_lora`, `cogvideox_loras` y carpetas de adaptadores similares
    - **VAE**: `vae`, `vae_approx`
    - **ControlNet**: `controlnet`
    - **CLIP y codificadores de texto**: `clip_vision`, `text_encoders`
    - **Embeddings / inversión textual**: `embeddings` (haz referencia en los prompts de `CLIPTextEncode` con `embedding:my-embedding-name`)
    - **Upscalers**: `upscale_models`, `latent_upscale_models`
    - **Visión / segmentación / eliminación**: `ipadapter`, `gligen`, `sams`, `sam3`, `rmbg`, `ultralytics_bbox`, `ultralytics_segm`
    - **Otras carpetas del selector**: `audio_encoders`, `model_patches`, `style_models`, `photomaker`, `LLM`, `CogVideo` y más

    Lo que realmente limita la importación no es la categoría del modelo, sino estas reglas:

    - **Formato de archivo**: solo `.safetensors` (incluso si ComfyUI de forma local admite `.ckpt`, `.pth` o `.onnx` para esa carpeta)
    - **Fuente**: solo enlaces de descarga de Civitai o Hugging Face (no se permite subir archivos locales directamente)
    - **Carpeta bloqueada**: los modelos `nlf` no se pueden importar
  </Accordion>
</AccordionGroup>
