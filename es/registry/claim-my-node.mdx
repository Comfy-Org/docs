## Descripción general

La función **Claim My Node** permite a los desarrolladores reclamar la propiedad de Nodos Personalizados en el ComfyUI Registry. Este sistema garantiza que solo los autores legítimos puedan Administrar y Actualizar sus nodos publicados, lo que aporta seguridad y responsabilidad dentro de la Comunidad.

## ¿Qué son los nodos no reclamados?

A medida que migramos del ComfyUI Manager al Comfy Registry con nuevos estándares, muchos Nodos Personalizados que antes figuraban en el sistema Clásico del ComfyUI Manager ahora aparecen como "no reclamados" en el registro. Estos son nodos que:

- Se publicaron originalmente en el sistema Clásico del ComfyUI Manager
- Se han migrado al Comfy Registry para cumplir con los últimos estándares
- Están esperando que sus autores originales reclamen la Propiedad

Ofrecemos una forma sencilla para que los desarrolladores reclamen estos nodos migrados, lo que garantiza una transición Suave del sistema Clásico al nuevo Estándar del registro mientras se mantiene la Propiedad y el control adecuados.

## Primeros pasos

Para reclamar tus nodos:

1. **Ve a la página de tu nodo sin reclamar**: visita la página de tu nodo sin reclamar y haz clic en el botón "Claim my node!".

2. **Crea un editor (si aún no tienes uno)**:
   - Si todavía no has creado un editor, se te pedirá que crees uno. Se requiere un editor para reclamar nodos y administrarlos de forma efectiva.

3. **Selecciona un editor**: elige el editor bajo el cual deseas reclamar el nodo. Este paso te redirigirá a la página de reclamación.

Para reclamar el nodo bajo el editor elegido, sigue estos pasos:

1. **Revisa la información del nodo:**
   - Comprueba los detalles del nodo, incluidos el nombre, el enlace del repositorio y el estado del editor tal como se muestran en pantalla.

2. **Autenticación con GitHub:**
   - Haz clic en el botón "Continue with GitHub" para iniciar el proceso de autenticación. Asegúrate de haber iniciado sesión con la cuenta de GitHub correcta que tenga derechos de administrador sobre el repositorio.

3. **Verifica el acceso de administrador:**
   - Una vez que hayas iniciado sesión, el sistema verificará si tienes privilegios de administrador para el repositorio de GitHub especificado. Este paso es fundamental para garantizar que cuentas con los permisos necesarios.

4. **Reclama el nodo:**
   - Si la verificación es exitosa, haz clic en "Claim" para reclamar el nodo. El estado del editor cambiará, lo que indicará la propiedad.

5. **¡Completado!**
   - Después de reclamar el nodo con éxito, puedes continuar con la [publicación](./publishing) y administrar tu nodo como el propietario legítimo.

## Preguntas frecuentes

<AccordionGroup>

  <Accordion title="¿Quién puede reclamar nodos?">
    Cualquier usuario de GitHub puede enviar una solicitud de reclamo, pero los reclamos se verifican con el repositorio original de nodos y la información del autor.
  </Accordion>

  <Accordion title="¿Cuánto tarda el proceso de reclamo?">
    Los reclamos se aprueban automáticamente una vez que se verifican los permisos de administrador de GitHub en el repositorio. Esto ocurre al instante cuando envías tu reclamo.
  </Accordion>

  <Accordion title="¿Qué pasa después de que se aprueba mi reclamo?">
    Una vez aprobado, tendrás control total sobre la gestión de tus nodos, incluyendo publicar versiones, actualizar metadatos, deprecación y configuraciones de políticas.
  </Accordion>

  <Accordion title="¿Puedo reclamar nodos que no creé?">
    No, los reclamos se validan automáticamente con los permisos de administrador del repositorio de GitHub. Solo los usuarios con acceso de administrador al repositorio original pueden reclamar nodos con éxito.
  </Accordion>

  <Accordion title="¿Qué pasa si rechazan mi reclamo?">
    Los reclamos se procesan automáticamente según los permisos de administrador de GitHub. Si no tienes acceso de administrador al repositorio, el reclamo se rechazará automáticamente. Contacta al propietario del repositorio para solicitar acceso de administrador si crees que deberías tener derechos de propiedad.
  </Accordion>
</AccordionGroup>
