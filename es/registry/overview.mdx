## Introducción

El Registry es una colección pública de nodos personalizados que impulsa [ComfyUI-Manager](https://github.com/Comfy-Org/ComfyUI-Manager). Los desarrolladores pueden publicar, versionar, marcar como obsoletos y hacer seguimiento de las métricas relacionadas con sus nodos personalizados. Los usuarios de ComfyUI pueden descubrir, instalar y calificar nodos personalizados del Registry a través de ComfyUI-Manager.

## ¿Por qué usar el Registry?

El Comfy Registry ayuda a la comunidad estandarizando el desarrollo de Nodos Personalizados:

<Icon icon="timeline" iconType="solid" size={20}/>&nbsp; **Versionado de nodos:** Los desarrolladores publican con frecuencia nuevas versiones de sus Nodos Personalizados que a menudo rompen los flujos de trabajo que dependen de ellos. Con los nodos del registry usando [versionado semántico](https://semver.org/), los usuarios ahora pueden elegir actualizar de forma segura, deprecar o fijar las versiones de sus nodos, sabiendo de antemano cómo sus acciones afectarán sus flujos de trabajo. El JSON del flujo de trabajo almacenará la versión del nodo utilizado, así que siempre podrás reproducir tus flujos de trabajo de forma confiable.

<Icon icon="shield" iconType="solid" size={20}/>&nbsp; **Seguridad de nodos:** El registry servirá como backend para el [ComfyUI-manager](https://github.com/Comfy-Org/ComfyUI-Manager). Todos los nodos serán escaneados en busca de comportamientos maliciosos, como paquetes pip personalizados, llamadas arbitrarias al sistema, etc. Los nodos que pasen estas verificaciones tendrán una marca de verificación (<Icon icon="check" iconType="solid" />) junto a su nombre en el administrador de la interfaz. Para ver una lista de los estándares de seguridad, consulta los [estándares](/es/registry/standards).

<Icon icon="magnifying-glass" iconType="solid" size={20}/>&nbsp; **Buscar:** Busca entre todos los nodos del Registry para encontrar nodos existentes para tu flujo de trabajo.

## Preguntas frecuentes

<AccordionGroup>
  <Accordion title="¿Los nodos del Registry tienen identificadores únicos?">
    Sí, un nodo personalizado en el Registry tiene un nombre único a nivel global, y esto permite que los archivos JSON de Comfy Workflow identifiquen de forma única cualquier nodo personalizado sin colisiones.
  </Accordion>
  <Accordion title="¿Existen restricciones sobre lo que puedo publicar?">
    Consulta los [estándares](/es/registry/standards) para obtener más información.
  </Accordion>

  <Accordion title="¿Cómo garantizan la estabilidad de los nodos?">
    Una vez que se publica una versión de un nodo personalizado, no se puede modificar. Esto garantiza que los usuarios puedan confiar en la estabilidad del nodo personalizado con el tiempo.
  </Accordion>

  <Accordion title="¿Cómo se versionan los nodos?">
    Los nodos personalizados se versionan usando [versionado semántico](https://semver.org/). Esto permite a los usuarios entender el impacto de actualizar a una nueva versión.
  </Accordion>

  <Accordion title="¿Cómo marco como obsoleta una versión de un nodo?">
    Puedes marcar una versión como obsoleta en el sitio web de Comfy Registry haciendo clic en **More Actions > Deprecate**. A los usuarios que instalaron esta versión se les mostrará el mensaje de obsolescencia y se les animará a actualizar a una versión más reciente.

    Marcar versiones como obsoletas es útil cuando se descubre un problema después de publicarlas.
  </Accordion>

</AccordionGroup>
