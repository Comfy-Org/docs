Puedes ejecutar un flujo de trabajo que creaste en el editor de Comfy Cloud desde tu propia aplicación, como un servicio de backend o un script por lotes, con los [Comfy SDKs](/es/development/api-development/sdks). Comfy Cloud ejecuta los flujos de trabajo en una compilación estándar con un conjunto predeterminado de Nodos Personalizados. Si un flujo de trabajo necesita Nodos Personalizados o modelos que la compilación estándar no tiene, creas una Build personalizada: un paquete con tus propios Nodos Personalizados y modelos que Comfy Cloud ejecuta por ti. Esta página muestra cómo ejecutar un flujo de trabajo mediante la API en la compilación estándar y, luego, cómo apuntar el mismo código a una Build personalizada.

## Antes de empezar

Para llamar a Comfy Cloud desde tu código, asegúrate de tener lo siguiente:

- **Una suscripción de pago a Comfy Cloud**
- **Un flujo de trabajo que se ejecute en el editor de Comfy Cloud**: pruébalo en el editor antes de ejecutarlo desde el código. Si necesita Nodos Personalizados o modelos que la compilación estándar no incluye, primero [crea una compilación personalizada](/es/development/deploy/cloud-custom-builds).
- **Python 3.10 o posterior, o Node 22 o posterior**: el SDK que instales necesita uno de ellos.

Si aún no has usado Comfy Cloud, empieza por [Comfy Cloud](/es/get_started/cloud).

## Ejecutar un flujo de trabajo en la compilación estándar

La compilación estándar ejecuta cualquier flujo de trabajo que use solo los Nodos Personalizados que admite Comfy Cloud. Para ejecutar uno desde tu código, creas una clave API, instalas el SDK y exportas el flujo de trabajo en formato API.

<Steps>
  <Step title="Crear una clave API">
    Tu aplicación envía la clave con cada solicitud, así que crea una clave para tu aplicación en la Developer Platform.

    1. Inicia sesión en [platform.comfy.org](https://platform.comfy.org) y luego haz clic en **API Keys**.
    2. Haz clic en **New API key**, escribe un nombre y luego haz clic en **Generate key**.
    3. Copia la clave y guárdala en un lugar seguro. La Developer Platform la muestra una sola vez.

    La clave empieza con `comfyui-`. Consulta [Getting an API Key](/es/development/api-development/getting-an-api-key) para saber cómo administrar las claves.
  </Step>
  <Step title="Instalar el SDK">
    <CodeGroup>
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    </CodeGroup>
  </Step>
  <Step title="Exportar el flujo de trabajo en formato API">
    El SDK envía el formato API de un flujo de trabajo, no el archivo que guarda el editor.

    - En el editor de Comfy Cloud, abre el flujo de trabajo, selecciona **File** > **Export (API)** y guarda el archivo como `workflow_api.json`.

    Consulta [Workflow API Format](/es/development/api-development/workflow-api-format) para saber qué contiene el archivo.
  </Step>
  <Step title="Ejecutar el flujo de trabajo">
    El SDK envía las solicitudes a Comfy Cloud a menos que establezcas otra URL base, así que pasa solo tu clave API:

    <CodeGroup>
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." });

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    </CodeGroup>

    - Reemplaza `"9"` por el ID del nodo de salida en tu `workflow_api.json`.
    - `run()` espera hasta que la tarea finalice y luego el código escribe las salidas en el disco.

    Para establecer las entradas, seguir el progreso y manejar los errores, consulta los [Comfy SDKs](/es/development/api-development/sdks).
  </Step>
</Steps>

## Ejecutar un flujo de trabajo en un Build personalizado

Desplegar un Build personalizado te da un despliegue con su propia URL. Tu código de la sección anterior se ejecuta en el despliegue en cuanto cambias la URL base.

<Warning>
  Un despliegue genera costos de tiempo de GPU mientras sus workers se ejecutan y de almacenamiento hasta que lo elimines. Cuando termines de probar, detenlo o elimínalo. Consulta [Limpieza](/es/development/serverless/overview#limpieza).
</Warning>

<Steps>
  <Step title="Crear y desplegar un Build">
    Sigue [Builds personalizados](/es/development/deploy/cloud-custom-builds) para crear un Build a partir de tu flujo de trabajo y desplegarlo.
  </Step>
  <Step title="Copiar la URL del despliegue">
    1. En la Developer Platform, abre la página del despliegue.
    2. Espera hasta que el estado del despliegue indique **Ready**.
    3. En **Run via API**, copia la **Deployment URL**.

    Una URL de despliegue tiene el formato `https://dep-<id>.run.comfy.app`.
  </Step>
  <Step title="Configurar la URL base">
    Configura `COMFY_BASE_URL` con la URL del despliegue:

    ```bash
    export COMFY_BASE_URL="https://dep-<id>.run.comfy.app"
    ```
  </Step>
  <Step title="Ejecutar el flujo de trabajo">
    Ejecuta el código de [Ejecutar un flujo de trabajo en el Build estándar](#ejecutar-un-flujo-de-trabajo-en-la-compilación-estándar) con tu clave API. Ahora el SDK envía la tarea a tu despliegue.
  </Step>
</Steps>

<Tip>
  Para probar primero el despliegue desde una terminal, ejecuta:

  ```bash
  comfy deploy run --deployment <deployment-id> --workflow workflow_api.json
  ```
</Tip>
