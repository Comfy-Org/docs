Ejecuta un flujo de trabajo completo desde código y guarda su salida como `first-result.png`. Este ejemplo crea una **imagen azul sólida de 512 × 512** usando dos nodos integrados. Verifica la autenticación, la ejecución del flujo de trabajo y la descarga de la salida sin necesitar un modelo, una imagen de entrada ni Nodos Personalizados.

Para generar una imagen llamando directamente a un modelo alojado, comienza con el [inicio rápido de Comfy Router](/es/development/comfy-router/quickstart).

Este ejemplo se ejecuta en Comfy Cloud. Para otras opciones de alojamiento, incluidas las implementaciones de Comfy API y el autoalojamiento, consulta [Desplegar ComfyUI](/es/development/deploy/overview).

## Antes de empezar

- Una [clave API de Comfy](/es/development/api-development/getting-an-api-key).
- Una [suscripción de pago a Comfy Cloud](/es/development/deploy/cloud). El acceso a la API de flujos de trabajo de Cloud no está incluido en el plan gratis.
- Python 3.10 o posterior, o Node.js 22.18 o posterior para el ejemplo de TypeScript.

Esta guía usa Comfy Cloud, el objetivo predeterminado de los SDK. Si configuraste `COMFY_BASE_URL` anteriormente, elimínala para usar Cloud. Para una implementación existente de la API de Comfy o una instancia autoalojada, consulta [Elegir una URL base](/es/development/api-development/sdks#elegir-una-url-base).

## 1. Descargar el ejemplo {#1-download-the-sample}

Crea una carpeta para el ejemplo. Descarga [workflow_api.json](/files/api-first-result/workflow_api.json) y el script para tu idioma dentro de esa carpeta:

- [Python: first_workflow.py](/files/api-first-result/first_workflow.py)
- [TypeScript: first_workflow.mts](/files/api-first-result/first_workflow.mts)

El flujo de trabajo ya está en formato API. El nodo `"1"` crea la imagen azul y el nodo `"2"` la guarda. Los scripts leen las salidas de ese nodo SaveImage exacto, así que no necesitas buscar ni editar un ID de nodo.

## 2. Instalar el SDK y configurar tu clave

Abre una terminal en la carpeta donde guardaste los archivos.

<CodeGroup>
```bash Python
python -m venv .venv
source .venv/bin/activate
python -m pip install comfy-sdk
```

```bash TypeScript
npm init -y
npm install @comfyorg/sdk
```
</CodeGroup>

En Windows, activa el entorno de Python con `.venv\Scripts\Activate.ps1` en PowerShell.

Configura tu clave en la misma terminal:

<CodeGroup>
```bash macOS / Linux
export COMFY_API_KEY="comfyui-your-key"
```

```powershell Windows PowerShell
$env:COMFY_API_KEY = "comfyui-your-key"
```
</CodeGroup>

Mantén tu Clave API en el entorno de tu servidor. No la incluyas en código de navegador ni la confirmes en el control de código fuente.

## 3. Ejecutar y ver el resultado

<CodeGroup>
```bash Python
python first_workflow.py
```

```bash TypeScript
node first_workflow.mts
```
</CodeGroup>

El script envía el flujo de trabajo, espera a que finalice y descarga la imagen. Cuando imprima `Saved` seguido de una ruta, abre `first-result.png` desde esa ubicación. Deberías ver un cuadrado azul sólido. Al ejecutar el ejemplo de nuevo, se reemplaza ese archivo local.

<Note>
  Esta es una comprobación de conexión del flujo de trabajo. No utiliza un modelo generativo. Los mismos pasos de envío, espera y descarga funcionan con tus propios flujos de trabajo de generación.
</Note>

### Si la solicitud falla

- **Clave faltante o no autorizado:** verifica que `COMFY_API_KEY` esté configurada en la terminal que ejecuta el script y que contenga una clave activa.
- **Error de acceso o de créditos:** revisa tu suscripción de Cloud y los créditos disponibles antes de volver a intentarlo.
- **Archivo de flujo de trabajo no encontrado:** mantén `workflow_api.json` junto al script descargado.
- **Endpoint inesperado:** revisa `COMFY_BASE_URL`. Déjala sin establecer para este ejemplo de Cloud.

Para obtener información sobre el manejo de errores y el progreso de las tareas, consulta la [guía del SDK](/es/development/api-development/sdks).

## 4. Ejecutar tu propio flujo de trabajo de generación

Crea o elige un flujo de trabajo en el editor de ComfyUI, ejecútalo correctamente allí y [expórtalo en formato API](/es/development/api-development/workflow-api-format). Reemplaza `workflow_api.json` con tu exportación y actualiza `get_outputs("2")` en Python o `getOutputs("2")` en TypeScript para usar el ID del nodo SaveImage de tu flujo de trabajo. Comprueba que el entorno objetivo tenga los modelos y los Nodos Personalizados que usa tu flujo de trabajo.

Para alojar flujos de trabajo con tus propios modelos y Nodos Personalizados, sigue la [Guía de inicio rápido de Comfy API](/es/development/serverless/quickstart). Para cambiar las entradas del flujo de trabajo, subir archivos o seguir el progreso, continúa con [Comfy SDKs](/es/development/api-development/sdks).
