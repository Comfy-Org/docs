ComfyUI se ejecuta de forma predeterminada como un servidor HTTP en tu máquina. Puedes llamarlo de forma programática para enviar flujos de trabajo, subir archivos, descargar salidas y monitorear el progreso, todo sin abrir el navegador.

## Iniciar el servidor

Cuando inicias ComfyUI, se inicia automáticamente un servidor HTTP en `http://127.0.0.1:8188`.

Para ejecutar ComfyUI como servidor sin interfaz gráfica (sin navegador):

<CodeGroup>
```bash
# Ejecutar sin abrir el navegador
python main.py --disable-auto-launch
```

```bash
# Especificar un puerto personalizado
python main.py --port 8288
```

```bash
# Escuchar en todas las interfaces de red (para acceso remoto)
python main.py --listen 0.0.0.0
```
</CodeGroup>

<Tip>
  Para ver una lista completa de las opciones de inicio, ejecuta `python main.py --help` o consulta la [Referencia de indicadores de inicio](/es/development/comfyui-server/startup-flags).
</Tip>

## Cómo funciona el servidor

El servidor de Comfy se ejecuta sobre el [framework aiohttp](https://docs.aiohttp.org/), que a su vez utiliza [asyncio](https://pypi.org/project/asyncio/).

Los mensajes del servidor al cliente se envían mediante mensajes de socket a través del método `send_sync` del servidor, que es una instancia de `PromptServer` (definida en `server.py`). Un escucha de eventos de socket registrado en `api.js` los procesa. Consulta [mensajes](/development/comfyui-server/comms_messages).

Los mensajes del cliente al servidor se envían mediante el método `api.fetchApi()` definido en `api.js`, y los manejan las rutas HTTP definidas por el servidor. Consulta [rutas](/development/comfyui-server/comms_routes).

<Tip>
  El cliente envía todo el flujo de trabajo (los valores de los widgets y todo lo demás) cuando pones una solicitud en cola.
  El servidor no recibe ningún cambio que hagas después de enviar una solicitud a la cola.
  Si quieres modificar el comportamiento del servidor durante la ejecución, necesitarás rutas.
</Tip>
