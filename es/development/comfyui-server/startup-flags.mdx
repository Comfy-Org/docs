ComfyUI accepts command-line arguments when started with `python main.py`. This page documents every flag defined in [`comfy/cli_args.py`](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy/cli_args.py).

<Note>
  **Windows Portable** users can add flags to the `.bat` launch files (for example, `run_nvidia_gpu.bat`). See the [Windows Portable guide](/installation/comfyui_portable_windows) for details.
</Note>

Run `python main.py --help` in your ComfyUI directory for the built-in help text. Combine multiple flags as needed:

```bash
python main.py --listen 0.0.0.0 --port 8288 --disable-auto-launch --lowvram
```

## Red y servidor

| Flag | Predeterminado | Descripción |
|------|---------|-------------|
| `--listen` `[IP]` | `127.0.0.1` | Dirección IP en la que escuchar. Se admite una lista separada por comas (por ejemplo, `127.2.2.2,127.3.3.3`). Si se indica sin valor, el predeterminado es `0.0.0.0,::` (todas las interfaces IPv4 e IPv6). |
| `--port` | `8188` | Puerto en el que escuchar. |
| `--tls-keyfile` `PATH` | — | Ruta al archivo de clave TLS (SSL). Habilita HTTPS. Requiere `--tls-certfile`. |
| `--tls-certfile` `PATH` | — | Ruta al archivo de certificado TLS (SSL). Habilita HTTPS. Requiere `--tls-keyfile`. |
| `--enable-cors-header` `[ORIGIN]` | disabled | Habilita CORS. Origen opcional, o `*` para todos los orígenes cuando no se indica ningún valor. |
| `--max-upload-size` | `100` | Tamaño máximo de subida en MB. |
| `--enable-compress-response-body` | disabled | Habilita la compresión del cuerpo de la respuesta HTTP. |

<CodeGroup>
```bash
# Escuchar en todas las interfaces (acceso a la LAN)
python main.py --listen

# Escuchar en una IP específica
python main.py --listen 0.0.0.0

# Puerto personalizado con HTTPS
python main.py --port 8443 --tls-keyfile key.pem --tls-certfile cert.pem
```
</CodeGroup>

## Directorios

| Flag | Predeterminado | Descripción |
|------|---------|-------------|
| `--base-directory` `PATH` | Raíz de ComfyUI | Directorio base para las carpetas models, custom_nodes, input, output, temp y user. |
| `--models-directory` `PATH` | ComfyUI root/models | Directorio de modelos. Reemplaza la carpeta models de `--base-directory`. |
| `--extra-model-paths-config` `PATH` | — | Carga uno o más archivos `extra_model_paths.yaml`. Se puede especificar varias veces. |
| `--output-directory` `PATH` | — | Directorio de salida. Reemplaza `--base-directory`. |
| `--temp-directory` `PATH` | — | Directorio temporal. Reemplaza `--base-directory`. |
| `--input-directory` `PATH` | — | Directorio de entrada. Reemplaza `--base-directory`. |
| `--user-directory` `PATH` | — | Directorio de usuario (ruta absoluta). Reemplaza `--base-directory`. La ruta debe existir y ser legible. |

## Launch & Browser

| Flag | Default | Description |
|------|---------|-------------|
| `--auto-launch` | disabled | Automatically open ComfyUI in the default browser on startup. |
| `--disable-auto-launch` | disabled | Disable auto-launching the browser. |
| `--windows-standalone-build` | disabled | Windows portable build convenience mode. Enables auto-launch on startup (equivalent to `--auto-launch`) and turns on the assets system. |

<Note>
  `--windows-standalone-build` sets `auto_launch` to `true` and enables the assets system. `--disable-auto-launch` overrides the browser launch and `--disable-assets` overrides the assets system. To run as a server without opening a browser, use `--disable-auto-launch`.
</Note>

```bash
# Run server without opening browser
python main.py --disable-auto-launch
```

## Dispositivos y CUDA

| Opción | Predeterminado | Descripción |
|------|---------|-------------|
| `--cuda-device` `DEVICE_ID` | — | IDs de dispositivos CUDA que se deben usar, separados por comas (p. ej. `0` o `0,1`), o `all` para mantener visibles todos los dispositivos visibles actualmente. Los demás dispositivos quedan ocultos. |
| `--default-device` `ID` | — | ID del dispositivo predeterminado. Todos los demás dispositivos permanecen visibles. |
| `--cuda-malloc` | Automático (torch 2.0+) | Activa cudaMallocAsync. Es mutuamente excluyente con `--disable-cuda-malloc`. |
| `--disable-cuda-malloc` | — | Desactiva cudaMallocAsync. Es mutuamente excluyente con `--cuda-malloc`. |
| `--directml` `[DEVICE]` | — | Usa torch-directml. Índice de dispositivo opcional; toma el valor `-1` cuando no se especifica ninguno. |
| `--oneapi-device-selector` `STRING` | — | Cadena selectora de dispositivo oneAPI para dispositivos Intel. |

<Note>
  En Windows, ComfyUI usa solo la GPU 0 de forma predeterminada. Para restaurar todas las GPU, pasa `--cuda-device all`.
</Note>

## Precisión e inferencia

<Note>
  Los flags de los grupos **Global**, **UNET**, **VAE** y **Text Encoder** que aparecen a continuación son mutuamente excluyentes dentro de cada grupo. Solo se puede usar un flag por grupo a la vez.
</Note>

### Punto flotante global

| Flag | Descripción |
|------|-------------|
| `--force-fp32` | Fuerza fp32 de forma global. Reporta si esto mejora el rendimiento de la GPU. |
| `--force-fp16` | Fuerza fp16 de forma global. También establece `--fp16-unet`. |

### Precisión de UNET

| Flag | Descripción |
|------|-------------|
| `--fp32-unet` | Ejecuta el modelo de diffusion en fp32. |
| `--fp64-unet` | Ejecuta el modelo de diffusion en fp64. |
| `--bf16-unet` | Ejecuta el modelo de diffusion en bf16. |
| `--fp16-unet` | Ejecuta el modelo de diffusion en fp16. |
| `--fp8_e4m3fn-unet` | Almacena los pesos de la UNet en fp8 (e4m3fn). |
| `--fp8_e5m2-unet` | Almacena los pesos de la UNet en fp8 (e5m2). |
| `--fp8_e8m0fnu-unet` | Almacena los pesos de la UNet en fp8 (e8m0fnu). |

Cada sufijo de flag FP8 nombra un formato de punto flotante de 8 bits de la especificación FP8 de la industria (ONNX / OCP):
- **e4m3fn**: 4 bits de exponente, 3 bits de mantisa. Buen equilibrio entre precisión y alcance para los pesos del modelo en GPU NVIDIA Ada Lovelace y posteriores.
- **e5m2**: 5 bits de exponente, 2 bits de mantisa. Mayor rango dinámico pero menor precisión que e4m3fn. Útil cuando las magnitudes de los pesos varían mucho.
- **e8m0fnu**: 8 bits de exponente, 0 bits de mantisa. Rango dinámico máximo sin precisión fraccionaria. Suele usarse como factor de escala de bloque (solo potencias de dos).

### Precisión de VAE

| Flag | Descripción |
|------|-------------|
| `--fp16-vae` | Ejecuta el VAE en fp16. Puede causar imágenes negras. |
| `--fp32-vae` | Ejecuta el VAE en precisión completa fp32. |
| `--bf16-vae` | Ejecuta el VAE en bf16. |
| `--cpu-vae` | Ejecuta el VAE en la CPU (no es mutuamente excluyente con los flags de precisión de VAE). |

### Precisión del codificador de texto

| Flag | Descripción |
|------|-------------|
| `--fp8_e4m3fn-text-enc` | Almacena los pesos del codificador de texto en fp8 (e4m3fn). |
| `--fp8_e5m2-text-enc` | Almacena los pesos del codificador de texto en fp8 (e5m2). |
| `--fp16-text-enc` | Almacena los pesos del codificador de texto en fp16. |
| `--fp32-text-enc` | Almacena los pesos del codificador de texto en fp32. |
| `--bf16-text-enc` | Almacena los pesos del codificador de texto en bf16. |

Consulta la sección [Precisión de UNET](#precisión-de-unet) para ver la explicación de cada sufijo de formato FP8.

### Otras opciones de inferencia

| Flag | Predeterminado | Descripción |
|------|---------|-------------|
| `--fp16-intermediates` | deshabilitado | Experimental: usa fp16 para los tensores intermedios entre nodos en lugar de fp32. |
| `--force-channels-last` | deshabilitado | Forzar el formato de memoria de los canales al final durante la inferencia. |
| `--supports-fp8-compute` | deshabilitado | Actúa como si el dispositivo admitiera cómputo fp8. |
| `--enable-triton-backend` | deshabilitado | Habilita el backend Triton en comfy-kitchen. Deshabilitado de forma predeterminada al iniciar. |
| `--disable-triton-backend` | deshabilitado | Fuerza la deshabilitación del backend Triton de comfy-kitchen, anulando `--enable-triton-backend`. |

## Vista previa

| Flag | Predeterminado | Descripción |
|------|---------|-------------|
| `--preview-method` | `none` | Método de vista previa para los nodos sampler. Opciones: `none`, `auto`, `latent2rgb`, `taesd`. |
| `--preview-size` | `512` | Tamaño máximo de la vista previa de imagen en píxeles. |

## Caché

<Note>
  Los flags de modo de caché son mutuamente excluyentes. Solo debes usar uno de `--cache-ram`, `--cache-classic`, `--high-ram`, `--cache-lru` o `--cache-none`.
</Note>

| Flag | Predeterminado | Descripción |
|------|---------|-------------|
| `--cache-ram` `[GB] [GB]` | habilitado (modo predeterminado) | Caché por presión de RAM. Primer valor: umbral de la caché activa en GB. Segundo valor opcional: umbral de la caché inactiva/anclaje en GB. Cuando no se indican valores: activa = 10 % de la RAM del sistema (mín. 2 GB, máx. 10 GB); inactiva = 100 % de la RAM del sistema (máx. 128 GB). Acepta como máximo dos valores. |
| `--cache-classic` | - | Usa el antiguo estilo de caché agresivo. |
| `--high-ram` | deshabilitado | Puede mejorar ligeramente el rendimiento en sistemas con abundante RAM o donde se prefiere usar el archivo de paginación antes que recargar modelos. También habilita la caché clásica. |
| `--cache-lru` `N` | `0` (deshabilitado) | Caché LRU con un máximo de N resultados de nodos en caché. Sin límite superior estricto; está limitada por la RAM/VRAM disponible. Puede usar más RAM/VRAM. |
| `--cache-none` | - | Menor uso de RAM/VRAM; vuelve a ejecutar cada nodo en cada ejecución. |

<Note>
  ComfyUI reutiliza los resultados de nodos en caché entre ejecuciones de la misma sesión, y eso es lo que hace más rápidas las ejecuciones repetidas. Usa `--cache-none` cuando prefieras que cada ejecución comience con una caché limpia, por ejemplo, mientras depuras un flujo de trabajo o descartas la reutilización de la caché entre ejecuciones. Cada nodo se vuelve a ejecutar, así que las generaciones tardan más. Es un flag de inicio, así que reinicia ComfyUI para que surta efecto.
</Note>

## Atención

<Note>
  Los flags de método de atención cruzada son mutuamente excluyentes. Las atenciones split y quad se ignoran cuando se usa xformers.
</Note>

| Flag | Descripción |
|------|-------------|
| `--use-split-cross-attention` | Usar la optimización de atención cruzada split. |
| `--use-quad-cross-attention` | Usar la optimización de atención cruzada subcuadrática. |
| `--use-pytorch-cross-attention` | Usar la atención cruzada de PyTorch 2.0. |
| `--use-sage-attention` | Usar Sage attention. |
| `--use-flash-attention` | Usar FlashAttention. |
| `--use-ck-attention` | Usar la atención de Comfy Kitchen. Requiere soporte de hardware para sus kernels INT8. |
| `--disable-xformers` | Deshabilitar xformers. |
| `--force-upcast-attention` | Forzar el upcasting de atención. Reportar si esto soluciona las imágenes negras. Mutuamente excluyente con `--dont-upcast-attention`. |
| `--dont-upcast-attention` | Deshabilitar todo el upcasting de atención. Solo para depuración. |

## VRAM y memoria

La descarga asíncrona de pesos está habilitada de forma predeterminada en GPUs Nvidia y AMD, y el VRAM dinámico se habilita automáticamente donde es compatible. Los flags siguientes anulan esos valores predeterminados.

<Note>
  Los flags de modo de VRAM (`--gpu-only`, `--highvram`, `--lowvram`, `--novram`, `--cpu`) son mutuamente excluyentes.
</Note>

| Flag | Predeterminado | Descripción |
|------|---------|-------------|
| `--gpu-only` | — | Almacena y ejecuta todo en la GPU (codificadores de texto, CLIP, etc.). |
| `--highvram` | — | Mantiene los modelos en la memoria de la GPU en lugar de descargarlos a la CPU después de usarlos. |
| `--lowvram` | — | No tiene efecto cuando el VRAM dinámico está habilitado. De lo contrario, ejecuta los codificadores de texto en la CPU. |
| `--novram` | — | Uso mínimo de VRAM cuando `--lowvram` no es suficiente. |
| `--cpu` | — | Usa la CPU para todo (lento). |
| `--reserve-vram` `GB` | Depende del SO | VRAM en GB que se reserva para el SO y otro software. |
| `--vram-headroom` `GB` | `0` | VRAM extra en GB que el VRAM dinámico mantiene libre por encima del margen predeterminado. ComfyUI intenta mantener esa cantidad de VRAM totalmente libre y sin usar, incluso contando la VRAM que usan otras aplicaciones. |
| `--disable-nvml-pressure` | deshabilitado | Usa CUDA en lugar de NVML para reportar la presión de memoria del VRAM dinámico. |
| `--async-offload` `[NUM_STREAMS]` | habilitado en Nvidia y AMD | Descarga asíncrona de pesos. Cantidad opcional de streams (predeterminado: 2). |
| `--disable-async-offload` | — | Deshabilita la descarga asíncrona de pesos. |
| `--disable-dynamic-vram` | — | Deshabilita el VRAM dinámico; usa carga de modelos basada en estimaciones. |
| `--enable-dynamic-vram` | automático en Nvidia, ROCm 7.14+ | Habilita el VRAM dinámico en sistemas donde no está habilitado de forma predeterminada. |
| `--fast-disk` | falso | Fuerza la carga dinámica y la descarga respaldadas por disco en lugar de usar RAM no fijada. Útil con NVMe rápido. Cuando no se define este flag ni `--disable-fast-disk`, la carga y la descarga respaldadas por disco se habilitan automáticamente si todos los archivos de modelo están en un almacenamiento detectado como rápido. |
| `--disable-fast-disk` | deshabilitado | Deshabilita la carga dinámica y la descarga respaldadas por disco, de modo que se usa RAM no fijada en su lugar. Anula `--fast-disk` y la detección automática. |
| `--disable-cuda-graphs` | deshabilitado | Deshabilita los CUDA graphs. |
| `--disable-comfy-compiler` | deshabilitado | Deshabilita el compilador de modelos de Comfy, incluida su subfunción de CUDA graphs. |
| `--assert-graph-breaks` | deshabilitado | Hace fallar la ejecución ante cortes de gráfico del compilador de modelos de Comfy. |
| `--force-non-blocking` | deshabilitado | Fuerza operaciones de tensor no bloqueantes. Puede ayudar en sistemas que no son Nvidia; puede romper algunos flujos de trabajo. |
| `--disable-smart-memory` | deshabilitado | Descarga de forma agresiva a la RAM en lugar de mantener los modelos en la VRAM. |
| `--disable-pinned-memory` | deshabilitado | Deshabilita el uso de memoria fijada. |
| `--mmap-torch-files` | deshabilitado | Usa mmap al cargar archivos ckpt/pt. |
| `--disable-mmap` | deshabilitado | No usa mmap al cargar safetensors. |

## Performance & Debugging

| Flag | Default | Description |
|------|---------|-------------|
| `--fast` `[OPT...]` | disabled | Enable experimental optimizations that may affect quality or stability. `--fast` alone enables all. Specific options: `fp16_accumulation`, `fp8_matrix_mult`, `cublas_ops`, `autotune`. |
| `--deterministic` | disabled | Use slower deterministic PyTorch algorithms where possible. Does not guarantee identical images in all cases. |
| `--default-hashing-function` | `sha256` | Hash function for duplicate filename/content comparison. Choices: `md5`, `sha1`, `sha256`, `sha512`. |
| `--debug-hang` | disabled | Enable stack trace dumps on Ctrl-C for debugging hangs. |

```bash
# Enable all fast optimizations (experimental)
python main.py --fast

# Enable specific optimizations only
python main.py --fast fp16_accumulation cublas_ops
```

## Custom Nodes & API Nodes

| Flag | Default | Description |
|------|---------|-------------|
| `--disable-all-custom-nodes` | disabled | Disable loading all custom nodes. |
| `--whitelist-custom-nodes` `FOLDER...` | — | Custom node folders to load even when `--disable-all-custom-nodes` is set. |
| `--disabled-nodes-config` `PATH` | — | Path to a YAML file that lists node IDs to disable. The file must contain a `disabled_nodes` list of node ID strings. |
| `--disable-partner-nodes` | disabled | Disable loading Partner Nodes (the paid API nodes). The frontend keeps its internet access. |
| `--offline` | disabled | Prevent the frontend from communicating with the internet by adding a restrictive Content-Security-Policy. Also disables Partner Nodes. |
| `--disable-api-nodes` | disabled | Deprecated alias for `--offline`. Use `--offline`, or `--disable-partner-nodes` to only disable Partner Nodes. |
| `--disable-metadata` | disabled | Disable saving prompt metadata in output files. |

<Note>
  `--offline` also changes what the browser is allowed to load. The flag adds a Content-Security-Policy that keeps the page on resources served by ComfyUI itself, so images, fonts, media, frames, and network requests from other origins are blocked, and Partner Nodes (API nodes) are not registered at all. If a preview or a thumbnail that normally loads goes missing after a restart, check the launch arguments for this flag before troubleshooting the node. `--disable-partner-nodes` only stops Partner Nodes from loading and leaves the rest of the frontend's internet access intact.
</Note>

```bash
# Troubleshoot custom node issues
python main.py --disable-all-custom-nodes

# Allow only specific custom nodes
python main.py --disable-all-custom-nodes --whitelist-custom-nodes ComfyUI-Manager
```

## Frontend & API

| Flag | Default | Description |
|------|---------|-------------|
| `--front-end-version` | `comfyanonymous/ComfyUI@latest` | Frontend version in `[owner]/[repo]@[version]` format. Requires internet to download from GitHub releases. Version can be `latest` or a semver (e.g. `1.0.0`). |
| `--front-end-root` `PATH` | — | Local filesystem path to the frontend directory. Overrides `--front-end-version`. |
| `--comfy-api-base` | `https://api.comfy.org` | Base URL for the ComfyUI API. |
| `--database-url` | `sqlite:///<ComfyUI>/user/comfyui.db` | Database URL. Use `sqlite:///:memory:` for in-memory. |
| `--enable-assets` | disabled | Enable the assets system (API routes, database sync, background scanning). |
| `--disable-assets` | disabled | Disable the assets system, even when `--enable-assets` or `--windows-standalone-build` is turned on. |
| `--enable-asset-hashing` | disabled | Compute blake3 content hashes when scanning assets. Enables future asset portability features such as deduplication and cross-machine model resolution, at the cost of startup time and per-output hashing on large model directories. Off by default; requires the assets system (`--enable-assets` or `--windows-standalone-build`). |
| `--feature-flag` `KEY[=VALUE]` | — | Set a server feature flag. Bare `KEY` sets true. Can be repeated. Booleans and numbers are auto-converted. |
| `--list-feature-flags` | — | Print known CLI-settable feature flags as JSON and exit. |

```bash
# List available feature flags
python main.py --list-feature-flags

# Set feature flags
python main.py --feature-flag show_signin_button=true
```
