El mismo cuerpo, enviado a `POST https://api.comfy.org/v2/models/ltx/ltx-video-to-video-hdr/requests`. El Router responde `201` con un `request_id` en cuanto se admite la ejecución, y puedes recoger el resultado cuando esté listo, desde este proceso u otro. [Entrega en cola](/es/development/comfy-router/queue) describe el estado, la cancelación y la recogida.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Lee COMFY_API_KEY desde el entorno.
# Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "ltx/ltx-video-to-video-hdr",
            {
                "output_colorspace": "acescg",
                "video_uri": "https://test-videos.co.uk/vids/sintel/mp4/h264/720/Sintel_720_10s_1MB.mp4",
            },
        )
        print("request_id:", handle.request_id)  # con el ID del modelo, todo lo que necesita otro proceso

        # Sondea hasta que se complete la solicitud, esperando el Retry-After que indique el servidor.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # La carga útil propia del proveedor, el mismo valor que devuelve models.run().
        # Una solicitud que falló o se canceló lanza aquí el error tipado de Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Lee COMFY_API_KEY desde el entorno.
// Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
const handle = await comfy.models.submit("ltx/ltx-video-to-video-hdr", {
  output_colorspace: "acescg",
  video_uri: "https://test-videos.co.uk/vids/sintel/mp4/h264/720/Sintel_720_10s_1MB.mp4",
});
console.log("requestId:", handle.requestId); // con el ID del modelo, todo lo que necesita otro proceso

// Sondea hasta que se complete la solicitud, esperando el Retry-After que indique el servidor.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// El mismo resultado que devuelve models.run(). Una solicitud que falló o se canceló provoca aquí un rechazo.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Envía. El Router responde 201 con request_id, status_url, response_url y cancel_url.

  -H "X-API-Key: $COMFY_API_KEY" \

  -H "X-API-Key: $COMFY_API_KEY"

# 3. Recoge. 200 con la salida nativa del modelo, 202 con el cuerpo del estado mientras sigue en ejecución.
```

## Esquema

### Entrada

<ParamField body="output_colorspace" type="string" default="&quot;acescg&quot;">
  Espacio de color de la secuencia de fotogramas OpenEXR en `result.exr_frames_url`. No afecta a `result.video_url`.

  Valores posibles: `acescg`, `acescct`, `srgb_linear`, `aces2065-1`
</ParamField>

<ParamField body="video_uri" type="string" required>
  Video de entrada como una URL HTTPS de acceso público o un URI de datos base64. H.264 o HEVC en MP4, MOV o MKV, de hasta 200 MB por URL. El ancho y el alto deben caber dentro de 3840x2160 en cualquiera de las dos orientaciones.
</ParamField>

Generado a partir del esquema que Router expone en `GET /v2/models/ltx/ltx-video-to-video-hdr/openapi.json`, el mismo documento con el que valida una llamada antes de que la solicitud llegue al proveedor.
