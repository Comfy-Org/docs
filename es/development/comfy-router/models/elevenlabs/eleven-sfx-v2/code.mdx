Router responde `201` con un `request_id` en cuanto se admite la ejecución, y el resultado se recoge cuando está listo, desde este proceso o desde otro. import asyncio
from comfy_sdk import AsyncComfy

# Lee COMFY_API_KEY del entorno.
# Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "elevenlabs/eleven_sfx_v2",
            {
                "duration_seconds": 5,
                "text": "A distant rumble of thunder rolling across a valley.",
            },
        )
        print("request_id:", handle.request_id)  # junto con el ID del modelo, es todo lo que necesita otro proceso

        # Sondea hasta que la solicitud se complete, esperando el Retry-After que indica el servidor.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # La carga propia del proveedor, el mismo valor que devuelve models.run().
        # Una solicitud que falló o se canceló lanza aquí el error tipado de Router.
        result = await handle.get()

    print(result)

asyncio.run(main())

import { comfy } from "@comfyorg/sdk";

// Lee COMFY_API_KEY del entorno.
// Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.

for await (const update of handle.events()) {

}

// El mismo resultado que devuelve models.run(). Una solicitud que falló o se canceló se rechaza aquí.
const result = await handle.get();

console.log(result.data);

## Esquema

### Entrada

<ParamField body="duration_seconds" type="number" required>
  La duración del sonido que se generará, en segundos.
Debe ser como mínimo 0.5 y como máximo 30.
REQUERIDO en esta ruta: a diferencia de la API de ElevenLabs upstream, que
adivina una duración óptima cuando el campo es null, esta ruta
rechaza con 400 "Duration is required" cualquier solicitud que lo omita.
El campo sigue siendo anulable solo para que un null explícito sea un
documento bien formado; aun así se rechaza.
Este valor es la cantidad sobre la que se mide la solicitud.

  Alcance: `0.5` a `30`

  Formato: `double`
</ParamField>

<ParamField body="loop" type="boolean" default="false">
  Indica si se debe crear un efecto de sonido que se repita en bucle de forma fluida.
ElevenLabs documenta esto como disponible únicamente para el modelo
'eleven_text_to_sound_v2', que es el modelo al que esta ruta reenvía
'eleven_sfx_v2' (consulta model_id), así que aplica aquí.
</ParamField>

<ParamField body="model_id" type="string">
  El ID del modelo que se usará para la generación de sonido. Esta ruta admite
'eleven_sfx_v2' y nada más; cualquier otro valor se rechaza con
400 antes de que la solicitud llegue a ElevenLabs. 'eleven_sfx_v2' es
el id de Comfy para el modelo que ElevenLabs llama 'eleven_text_to_sound_v2';
el proxy reescribe el cuerpo reenviado a esa denominación del proveedor, que el
enum propio de ElevenLabs exige (rechaza 'eleven_sfx_v2' con 422),
de modo que quien llama nunca envía el id del proveedor. NO está en la
lista `required` de este esquema porque Comfy Router lo rellena desde el
segmento de ruta `{model}` de /v2/models/elevenlabs/\{model}, así que quien llama
a través de Router lo omite.
</ParamField>

<ParamField body="prompt_influence" type="number">
  Una mayor influencia del prompt hace que tu generación siga el prompt
más de cerca y que las generaciones sean menos variables.
Debe ser un valor entre 0 y 1. El valor predeterminado es 0.3.

  Alcance: `0` a `1`

  Formato: `double`
</ParamField>

<ParamField body="text" type="string" required>
  El texto que se convertirá en un efecto de sonido.
</ParamField>
