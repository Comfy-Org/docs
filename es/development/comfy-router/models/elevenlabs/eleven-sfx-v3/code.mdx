El mismo cuerpo, enviado a `POST https://api.comfy.org/v2/models/elevenlabs/eleven_sfx_v3/requests`. Router responde `201` con un `request_id` en cuanto admite la ejecución, y recoges el resultado cuando está listo, desde este proceso o desde otro. [Entrega en cola](/es/development/comfy-router/queue) repasa el estado, la cancelación y la recogida.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Lee COMFY_API_KEY del entorno.
# Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "elevenlabs/eleven_sfx_v3",
            {
                "duration_seconds": 5,
                "text": "A distant rumble of thunder rolling across a valley.",
            },
        )
        print("request_id:", handle.request_id)  # junto con el ID del modelo, es todo lo que otro proceso necesita

        # Sondea hasta que la solicitud se complete, esperando el Retry-After que indique el servidor.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # La carga útil propia del proveedor, el mismo valor que devuelve models.run().
        # Una solicitud que falló o se canceló genera aquí el error tipado de Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Lee COMFY_API_KEY del entorno.
// Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
const handle = await comfy.models.submit("elevenlabs/eleven_sfx_v3", {
  duration_seconds: 5,
  text: "A distant rumble of thunder rolling across a valley.",
});
console.log("requestId:", handle.requestId); // junto con el ID del modelo, es todo lo que otro proceso necesita

// Sondea hasta que se complete la solicitud, esperando el Retry-After que indique el servidor.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// El mismo resultado que devuelve models.run(). Una solicitud que falló o se canceló se rechaza aquí.
const result = await handle.get();

console.log(result.data);
```

### Entrada

<ParamField body="duration_seconds" type="number" required>
  La duración del sonido que se generará, en segundos.
Debe ser como mínimo 0.5 y como máximo 30.
REQUERIDO en esta ruta: a diferencia de la API upstream de ElevenLabs, que
estima una duración óptima cuando el campo es null, esta ruta
rechaza con 400 "Duration is required" una solicitud que lo omita.
El campo sigue siendo anulable solo para que un null explícito sea un documento
bien formado; aun así se rechaza.
Este valor es la cantidad por la que se tarifica la solicitud.

  Rango: `0.5` a `30`

  Formato: `double`
</ParamField>

<ParamField body="loop" type="boolean" default="false">
  Si se debe crear un efecto de sonido que se repita sin cortes.
</ParamField>

<ParamField body="model_id" type="string">
  El ID de modelo que se usará para la generación de sonido. Esta ruta admite
solo los ids de Comfy del enum de la solicitud v1; cualquier otro valor se
rechaza con 400 antes de que la solicitud llegue a ElevenLabs. Cada uno es
el id de Comfy para un modelo de ElevenLabs ('eleven_sfx_v2' es el modelo
que ElevenLabs llama 'eleven_text_to_sound_v2'). El proxy reescribe el
cuerpo reenviado a la grafía del proveedor, que el propio enum de ElevenLabs
exige (rechaza 'eleven_sfx_v2' con 422), así que quien llama nunca
envía el id del proveedor. NO está en la
lista `required` de este esquema porque Comfy Router lo rellena a partir del
segmento de ruta `{model}` de /v2/models/elevenlabs/\{model}, por lo que quien llama desde Router
lo omite.
</ParamField>

<ParamField body="prompt_influence" type="number">
  Una mayor influencia del prompt hace que tu generación siga el prompt
más de cerca y, al mismo tiempo, que las generaciones sean menos variables.
Debe ser un valor entre 0 y 1. El valor predeterminado es 0.3.

  Rango: `0` a `1`

  Formato: `double`
</ParamField>

<ParamField body="text" type="string" required>
  El texto que se convertirá en un efecto de sonido.
