El mismo cuerpo, enviado a `POST https://api.comfy.org/v2/models/viggle/motion-capture/requests`. Router responde `201` con un `request_id` en cuanto se admite la ejecución, y el resultado se recoge cuando está listo, desde este proceso u otro. [Entrega en cola](/es/development/comfy-router/queue) explica el estado, la cancelación y la recogida.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Lee COMFY_API_KEY del entorno.
# Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "viggle/motion-capture",
            {
                "motion_video_url": "https://example.invalid/viggle/dance.mp4",
            },
        )
        print("request_id:", handle.request_id)  # junto con el ID del modelo, es todo lo que otro proceso necesita

        # Sondea hasta que la solicitud se complete, esperando el Retry-After que indica el servidor.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # La carga propia del proveedor, el mismo valor que devuelve models.run().
        # Una solicitud que falló o se canceló lanza aquí el error tipado de Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Lee COMFY_API_KEY del entorno.
// Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
const handle = await comfy.models.submit("viggle/motion-capture", {
  motion_video_url: "https://example.invalid/viggle/dance.mp4",
});
console.log("requestId:", handle.requestId); // junto con el ID del modelo, es todo lo que otro proceso necesita

// Sondea hasta que la solicitud se complete, esperando el Retry-After que indica el servidor.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// El mismo resultado que devuelve models.run(). Una solicitud que falló o se canceló se rechaza aquí.
const result = await handle.get();

console.log(result.data);
```

```bash cURL
# 1. Envía. Router responde 201 con request_id, status_url, response_url y cancel_url.
curl https://api.comfy.org/v2/models/viggle/motion-capture/requests \
  -H "X-API-Key: $COMFY_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d "{\"motion_video_url\": \"https://example.invalid/viggle/dance.mp4\"}"

# 2. Sondea hasta que el estado sea COMPLETED, esperando los segundos de Retry-After que indica cada respuesta.
REQUEST_ID="<request_id from the 201 body>"
curl -i https://api.comfy.org/v2/models/viggle/motion-capture/requests/$REQUEST_ID/status \
  -H "X-API-Key: $COMFY_API_KEY"

# 3. Recoge. 200 con la salida nativa del modelo, 202 con el cuerpo de estado mientras sigue en ejecución.
curl https://api.comfy.org/v2/models/viggle/motion-capture/requests/$REQUEST_ID \
  -H "X-API-Key: $COMFY_API_KEY"
```
