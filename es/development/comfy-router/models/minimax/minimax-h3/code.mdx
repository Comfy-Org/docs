Referencia de API para MiniMax H3. MiniMax H3 (Hailuo 03) es un modelo de video omnimodal. Genera la imagen y su pista de audio juntas en una sola pasada, así que un clip finalizado ya incluye diálogo, efectos de sonido y música.

**Entrada:** Texto, Imagen · **Salida:** Video + Audio

## Inicio rápido

El mismo cuerpo, enviado a `POST https://api.comfy.org/v2/models/minimax/minimax-h3/requests`. Router responde `201` con un `request_id` en cuanto se admite la ejecución, y el resultado se recoge cuando está listo, desde este proceso o desde otro. [Entrega en cola](/es/development/comfy-router/queue) explica el estado, la cancelación y la recogida del resultado.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Lee COMFY_API_KEY del entorno.
# Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "minimax/minimax-h3",
            {
                "content": [
                    {
                        "text": "A single red maple leaf resting on a plain white background.",
                        "type": "text",
                    },
                ],
                "duration": 5,
                "ratio": "16:9",
                "resolution": "768P",
            },
        )
        print("request_id:", handle.request_id)  # junto con el ID del modelo, es todo lo que otro proceso necesita

        # Consulta el estado hasta que la solicitud se completa, esperando el Retry-After que indica el servidor.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # La carga útil propia del proveedor, el mismo valor que devuelve models.run().
        # Una solicitud que falló o se canceló genera aquí el error tipado de Router.
        result = await handle.get()

    print("video:", result["task"]["content"]["url"])

asyncio.run(main())
```

for await (const update of handle.events()) {

### Salida

```json
{
  "task": {
    "content": {
      "url": "https://example.invalid/minimax/minimax-h3/generated.mp4"
    },
    "duration": 6,
    "id": "3f7a1b28-5c0d-4e91-8a6f-1b2c3d4e5f60",
    "model": "MiniMax-H3",
    "ratio": "16:9",
    "resolution": "768P",
    "status": "succeeded",
    "usage": {
      "output_seconds": 6,
      "total_seconds": 6
    }
  }
}
```

**El MP4 incluye una pista de audio generada.** H3 es omnicanal: la voz, los efectos de sonido y la música se sintetizan junto con la imagen en una sola pasada hacia adelante, no se añaden después, y el resultado es un único MP4 con audio estéreo nativo. Nada en el cuerpo de la solicitud anterior desactiva eso: los campos documentados son el contenido del prompt, `duration`, `ratio`, `resolution`, `seed`, `aigc_watermark` y `callback_url`, y ninguno de ellos selecciona una renderización silenciosa. Por eso, un pipeline que pretenda superponer su propia voz en off sobre el clip tiene que silenciar o quitar primero la pista devuelta, o hará el mux sobre un clip que ya está hablando. El prompt es lo que guía el audio: describe el diálogo, los efectos de sonido y la música en el mismo bloque de prompt que la toma. Consulta la [guía de prompts de MiniMax H3](/es/tutorials/video/minimax/minimax-h3-prompt-guide) para saber cómo estructurar uno, y la [descripción general de MiniMax H3](/es/tutorials/video/minimax/minimax-h3) para saber qué hace el modelo en ComfyUI.

La URL del video caduca. Router vuelve a alojar el MP4 y responde con una URL firmada por Comfy válida durante 12 horas, y recurre al enlace propio de MiniMax, de vida más corta, cuando el re-alojamiento falla. La descripción de `task.content.url` en el esquema de respuesta anterior te indica que consultes de nuevo para obtener una URL actualizada: esa es la redacción propia de MiniMax para su API, trasladada sin cambios, y Router no expone la ruta de consulta de tareas de MiniMax. Volver a leer la ruta de resultados de una solicitud en cola devuelve el documento de resultado almacenado mientras la solicitud se [conserva durante 24 horas después de completarse](/es/development/comfy-router/queue#idempotencia-y-facturación), pero nada documenta que esa lectura genere una URL recién firmada. Descarga el MP4 cuanto antes en lugar de guardar el enlace.
