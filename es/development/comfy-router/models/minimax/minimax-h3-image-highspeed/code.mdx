<ParamField body="area" type="string">
  Nivel de área de salida cuando se omite `size` o es `auto`. Uno de `1K`, `2K`, `4K` (predeterminado).
</ParamField>

<ParamField body="aspect_ratio" type="string">
  Relación de aspecto de salida cuando se omite `size` o es `auto`. `auto` (predeterminado) o `X:Y` entre 1:3 y 3:1, por ejemplo `16:9`.
</ParamField>

<ParamField body="disable_prompt_enhanced" type="boolean" default="false">
  Desactiva el mejoramiento de prompt de MiniMax. Requiere un `size` fijo o un `aspect_ratio` con formato `X:Y`.
</ParamField>

<ParamField body="images" type="object[]">
  Imágenes de referencia opcionales. Cuando están presentes, la solicitud se ejecuta como una edición de imagen, exactamente igual que en la ruta de ediciones.
</ParamField>

<ParamField body="images[].image_url" type="string" required>
  Una URL http(s) pública o un URI `data:image/<format>;base64,`. JPEG, PNG, WEBP, HEIC o HEIF, cada lado de 128 a 8192 px, con el lado largo como máximo 4 veces el lado corto.
</ParamField>

<ParamField body="model" type="string">
  Nombre del modelo. `MiniMax-H3-Image` o `MiniMax-H3-Image-Highspeed`. Quienes llaman al Router pueden omitir este campo o enviar null; el Router completa el modelo seleccionado por la ruta de la solicitud.
</ParamField>

<ParamField body="n" type="integer" default="1">
  Cantidad de imágenes. Los tokens de entrada se cobran una vez por imagen.

  Alcance: `1` a `10`
</ParamField>

<ParamField body="output_compression" type="integer">
  Calidad de compresión para `jpeg` y `webp`, predeterminado 95.

  Alcance: `0` a `100`
</ParamField>

<ParamField body="output_format" type="string">
  Formato de la imagen de salida. Uno de `png`, `jpeg`, `jpg` (predeterminado), `webp`.
</ParamField>

<ParamField body="prompt" type="string" required>
  Descripción de texto de la imagen. Junto con `images`, es la descripción de la edición; las imágenes de referencia son la imagen 1, la imagen 2 y así sucesivamente, en el orden del arreglo.
</ParamField>

<ParamField body="size" type="string">
  Tamaño de salida, `auto` (predeterminado) o `WIDTHxHEIGHT`, por ejemplo `2720x1536`. Un tamaño fijo debe tener un área de 655,360 a 20,000,000 píxeles y una relación de aspecto entre 1:3 y 3:1, y no se puede combinar con `aspect_ratio` ni con `area`.
</ParamField>
