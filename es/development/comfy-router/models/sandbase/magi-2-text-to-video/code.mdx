El mismo cuerpo, enviado a `POST https://api.comfy.org/v2/models/sandbase/magi-2-text-to-video/requests`. Router responde `201` con un `request_id` en cuanto se admite la ejecución, y el resultado se recoge cuando está listo, desde este proceso u otro. [Entrega en cola](/es/development/comfy-router/queue) explica el estado, la cancelación y la recogida.

```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Lee COMFY_API_KEY desde el entorno.
# Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza en los reintentos automáticos.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "sandbase/magi-2-text-to-video",
            {
                "aspect_ratio": "16:9",
                "duration": 5,
                "generate_audio": True,
                "prompt": "At dawn, waves break gently against the rocks as the camera slowly moves forward.",
                "resolution": "1080p",
            },
        )
        print("request_id:", handle.request_id)  # junto con el ID del modelo, es todo lo que otro proceso necesita

        # Consulta hasta que la solicitud se complete, esperando el Retry-After que indique el servidor.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # La carga útil propia del proveedor, el mismo valor que devuelve models.run().
        # Una solicitud fallida o cancelada lanza aquí el error tipado de Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

import { comfy } from "@comfyorg/sdk";

// Lee COMFY_API_KEY desde el entorno.
// Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza en los reintentos automáticos.

// Consulta hasta que la solicitud se complete, esperando el Retry-After que indique el servidor.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// El mismo resultado que devuelve models.run(). Una solicitud fallida o cancelada se rechaza aquí.
const result = await handle.get();

console.log(result.data);
