  La información del error. Si la tarea tiene éxito, se devuelve null. Si la tarea falla, se devuelve la información del error.
</ResponseField>

<ResponseField name="error.code" type="string">
  Código de error de ModelArk del proveedor. SensitiveContentDetected, InputTextSensitiveContentDetected, InputImageSensitiveContentDetected, InputVideoSensitiveContentDetected, InputAudioSensitiveContentDetected, OutputTextSensitiveContentDetected, OutputImageSensitiveContentDetected, OutputVideoSensitiveContentDetected y OutputAudioSensitiveContentDetected identifican rechazos por políticas de contenido. Una familia puede tener un motivo separado por puntos, como InputImageSensitiveContentDetected.PrivacyInformation, OutputVideoSensitiveContentDetected.PolicyViolation o OutputImageSensitiveContentDetected.DeepFake. Es una cadena abierta, no un enum: otros códigos describen fallos de validación y del proveedor. Router reconoce las familias de políticas en envolturas de error HTTP 400 y en respuestas HTTP 200 de tareas fallidas sin sobrescribir los fallos de transporte.
</ResponseField>

<ResponseField name="error.message" type="string">
  El mensaje de error
</ResponseField>

<ResponseField name="id" type="string">
  El ID de la tarea de generación de video
</ResponseField>

<ResponseField name="model" type="string">
  El nombre y la versión del modelo usado por la tarea
</ResponseField>

<ResponseField name="output_format" type="string">
  Formato de contenedor del video generado (mp4 o mov), devuelto en el NIVEL SUPERIOR como un campo hermano de `content`: ahí es donde la consulta de tareas de video de Seedance lo devuelve. Es un campo propio de BytePlus, reenviado sin cambios.
</ResponseField>

<ResponseField name="resolution" type="string">
  La resolución del video generado, por ejemplo `1080p`. Es un campo propio de BytePlus, devuelto en las tareas de video exitosas y reenviado sin cambios.
</ResponseField>

<ResponseField name="seed" type="integer">
  La semilla de generación que realmente se usó para la tarea. Es un campo propio de BytePlus, devuelto en las tareas de video exitosas y reenviado sin cambios.

  Formato: `int64`
</ResponseField>

<ResponseField name="status" type="string">
  El estado de la tarea

  Valores posibles: `queued`, `running`, `cancelled`, `succeeded`, `failed`, `expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  La hora en que la tarea se actualizó por última vez. El valor es una marca de tiempo UNIX en segundos.
</ResponseField>

<ResponseField name="usage" type="object">
  El uso de tokens de la solicitud
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  La cantidad de tokens generados por el modelo
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  Para el modelo de generación de video, la cantidad de tokens de entrada no se calcula y es 0 por defecto. Por lo tanto, total_tokens = completion_tokens.
</ResponseField>
