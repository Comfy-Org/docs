  Valores posibles: `queued`, `running`, `cancelled`, `succeeded`, `failed`, `expired`
</ResponseField>

<ResponseField name="updated_at" type="integer">
  La hora en que la tarea se actualizó por última vez. El valor es una marca de tiempo UNIX en segundos.
</ResponseField>

<ResponseField name="usage" type="object">
  El uso de tokens de la solicitud
</ResponseField>

<ResponseField name="usage.completion_tokens" type="integer">
  El número de tokens generados por el modelo
</ResponseField>

<ResponseField name="usage.total_tokens" type="integer">
  Para el modelo de generación de video, el número de tokens de entrada no se calcula y es 0 por defecto. Por lo tanto, total_tokens = completion_tokens.
</ResponseField>
