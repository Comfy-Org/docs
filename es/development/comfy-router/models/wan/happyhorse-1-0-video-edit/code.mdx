import { comfy } from "@comfyorg/sdk";

// Lee COMFY_API_KEY del entorno.
// Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza en los reintentos automáticos.
type Result = { output: { video_url: string } };
const handle = await comfy.models.submit<Result>("wan/happyhorse-1.0-video-edit", {
  input: {
    prompt: "restyle the clip as a hand-drawn ink sketch, keep the dancer's movement unchanged",
    media: [
      {
        type: "video",
        url: "https://raw.githubusercontent.com/Comfy-Org/workflow_templates/main/input/street_dancer.mp4",
      },
    ],
  },
  parameters: {
    resolution: "720P",
  },
});
console.log("requestId:", handle.requestId); // junto con el ID del modelo, es todo lo que necesita otro proceso

// Sondea hasta que la solicitud se complete, esperando el Retry-After que indique el servidor.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// El mismo resultado que devuelve models.run(). Una solicitud que falló o se canceló se rechaza aquí.
const result = await handle.get();
if (result.kind !== "json") throw new Error("expected a JSON result");

console.log("video:", result.data.output.video_url);

<ParamField body="input.media" type="object[]">

video) para la generación de video. Cada elemento contiene un campo type y un campo url.
Este campo es compartido por todos los modelos servidos desde este componente, y qué

  entre 1:8 y 8:1, como máximo 20MB, una URL pública o una URL
  data:\{MIME_type};base64,... reference_video: una URL HTTP/HTTPS pública; no se acepta
  una URL data: en línea.
- wan2.7-videoedit: video (exactamente 1, el clip que se edita: MP4/MOV, 2-10 segundos,

  variantes toman su primer fotograma AQUÍ y no en img_url. Al menos 300x300 píxeles,

  pública o una URL data:\{MIME_type};base64,...
- happyhorse-1.0-r2v, happyhorse-1.1-r2v: solo reference_image, de 1 a 9. Esta es la
  única entrada de referencia del modelo. El lado más corto debe medir al menos 400
  píxeles, JPEG/JPG/PNG/WEBP, como máximo 20MB, una URL pública o una URL
  data:\{MIME_type};base64,... reference_video no es un tipo de entrada para esta
  operación.
- happyhorse-1.0-video-edit: video (exactamente 1, el clip que se edita: MP4/MOV, 3-60
  segundos, lado más largo como máximo 4096 píxeles, lado más corto al menos 360 píxeles,
  relación de aspecto entre 1:2.5 y 2.5:1, como máximo 100MB, una URL HTTP/HTTPS pública;
  no se acepta una URL data: en línea) más un reference_image opcional de 0 a 5
  (JPEG/JPG/PNG/WEBP, al menos 300x300 píxeles, relación de aspecto entre 1:2.5 y 2.5:1,

- happyhorse-1.0-t2v, happyhorse-1.1-t2v, wan2.7-t2v, wan2.6-t2v, wan2.5-t2v-preview:

  media, así que deja este campo sin definir.
- wan2.5-i2v-preview, wan2.6-i2v, wan2.6-r2v: este componente no enumera ningún

esquema: no se declara minItems/maxItems en media, porque los tipos admisibles y sus
límites difieren según el modelo. Que el esquema lo acepte no implica que el proveedor lo
acepte; y, en la dirección contraria, las cifras de "como máximo 20MB" por recurso
anteriores, el techo de las entradas de imagen, las únicas entradas que pueden enviarse en
línea, son el techo del socio sobre el recurso con el que termina, y se aplican tal como
están escritas cuando el recurso es una URL pública, porque esos bytes nunca pasan por
Comfy. Una URL data:\{MIME_type};base64,... en línea sí pasa por Comfy y además encuentra
un techo de transporte: el cuerpo de una solicitud POST de Comfy Router está limitado a
100 MiB en total y se responde 413 por encima de eso, y base64 infla una carga útil en
alrededor de 4/3, así que un único recurso en línea de más de unos 75 MB se rechaza antes
de llegar a cualquiera de las reglas del socio indicadas aquí. Con ese tamaño, un único
recurso con el propioEl techo de 20 MB cabe en línea sin problemas, así que para un solo recurso lo que manda es la regla del socio;
el techo de transporte manda cuando hay varios recursos, ya que el tope de 100 MiB del Router acota la solicitud
COMPLETA y no cada elemento. Envía cualquier cosa cercana a estos techos como una
URL pública.

devuelve 400 en todos los modelos que la descripción de resolution indica como modelos sin 480P.
</ParamField>

<ParamField body="parameters.watermark" type="boolean" default="false">
  Si se debe agregar un logotipo de marca de agua; la marca de agua se ubica en la esquina inferior derecha
</ParamField>
