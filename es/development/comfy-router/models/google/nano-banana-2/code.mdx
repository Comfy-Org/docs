Referencia de API de Nano Banana 2. Nano Banana 2 (Gemini 3.1 Flash Image) genera imágenes a partir de texto y edita una imagen de entrada cuando se proporciona una.

**Entrada:** Texto, Imagen, Video · **Salida:** Imagen + Texto

## Inicio rápido

Crea una clave en [tu espacio de trabajo de Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) y expórtala como `COMFY_API_KEY`. Los fragmentos de Python y TypeScript usan los SDK de Comfy (`pip install comfy-sdk` y `npm install @comfyorg/sdk`); el fragmento de cURL es la misma llamada sobre HTTP sin procesar.

**ID del modelo:** `vertexai/gemini-3.1-flash-image`

**Endpoint:** `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image`

## Proveedores de servicio

Este modelo es servido por Comfy Router directamente a menos que la solicitud nombre otro proveedor. Los proveedores a continuación también lo sirven, en el mismo endpoint y con el mismo ID de modelo, seleccionados con el parámetro de consulta `model_provider`.

- **Comfy** (predeterminado): `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image`
- **fal**, como `fal/fal-nano-banana-2`: `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image?model_provider=fal`
- **Pika**, como `pika/pika-nano-banana-2`: `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image?model_provider=pika`
- **Runware**, como `runware/runware-nano-banana-2`: `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image?model_provider=runware`
- **WaveSpeed**, como `wavespeed/wavespeed-nano-banana-2`: `POST https://api.comfy.org/v2/models/vertexai/gemini-3.1-flash-image?model_provider=wavespeed`

`strict_mode` tiene como valor predeterminado false, por lo que Router traduce el cuerpo de la solicitud nativa documentado en esta página al esquema propio del proveedor y traduce la respuesta de vuelta. Consulta [`model_provider`, `strict_mode` y `fallback_provider`](/es/development/comfy-router/reference#post-v2modelsprovidermodel) en la Referencia de la API, y [Proveedores de servicio](/es/development/comfy-router/providers) para cada modelo enrutado de esta manera.

## Ejemplos

### Entrada

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {
          "text": "a single red maple leaf on a plain white background, studio lighting"
        }
      ]
    }
  ],
  "generationConfig": {
    "responseModalities": [
      "IMAGE"
    ],
    "imageConfig": {
      "aspectRatio": "1:1"
    }
  }
}
```

### Salida

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [
          {
            "inlineData": {
              "mimeType": "image/png",
              "data": "PGJhc2U2ND4="
            }
          }
        ]
      },
      "finishReason": "STOP"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 12,
    "candidatesTokenCount": 1290
  }
}
```

De forma predeterminada, las partes de imagen generadas contienen bytes en base64 en `inlineData.data` y un tipo de medio en `inlineData.mimeType`. Decodifica los bytes y guárdalos en un archivo. Con `uploadImagesToStorage: true`, las imágenes subidas usan en su lugar `fileData.fileUri` para una URL firmada y `fileData.mimeType` para el tipo de medio. Descarga estas imágenes antes de que las URL expiren, 24 horas después de su creación. Un fallo en la subida deja esa imagen en línea, así que revisa cada parte en busca de `inlineData` o `fileData`; también pueden aparecer partes de texto, y no se garantiza que la imagen sea la primera parte. La ruta `candidates[0].content.parts[0].inlineData.data` de los ejemplos de inicio rápido anteriores lee la única parte en línea de la respuesta de ejemplo de esta página; frente a una respuesta real, recorre `parts` en busca de la clave que quieras en lugar de indexar la posición 0.
