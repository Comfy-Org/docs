Referencia de la API de `stability/generate-ultra`, que Comfy Router sirve desde Stability.

**Entrada:** Texto, Imagen · **Salida:** Imagen

## Inicio rápido

Crea una clave en [tu espacio de trabajo de Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) y expórtala como `COMFY_API_KEY`. Los fragmentos de Python y TypeScript usan los SDK de Comfy (`pip install comfy-sdk` y `npm install @comfyorg/sdk`); el fragmento de cURL es la misma llamada por HTTP directo.

**ID del modelo:** `stability/generate-ultra`

**Endpoint:** `POST https://api.comfy.org/v2/models/stability/generate-ultra`

El mismo cuerpo, enviado a `POST https://api.comfy.org/v2/models/stability/generate-ultra/requests`. El Router responde `201` con un `request_id` en cuanto se admite la ejecución, y recoges el resultado cuando está listo, desde este proceso o desde otro. [Entrega en cola](/es/development/comfy-router/queue) recorre el estado, la cancelación y la recogida.

<CodeGroup>
```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Lee COMFY_API_KEY del entorno.
# Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza en los reintentos automáticos.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/generate-ultra",
            {
                "aspect_ratio": "16:9",
                "prompt": "a lighthouse on a cliff at sunset, oil painting",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # con el ID del modelo, todo lo que necesita otro proceso

        # Sondea hasta que la solicitud se complete, esperando el Retry-After que indique el servidor.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # El payload propio del proveedor, el mismo valor que devuelve models.run().
        # Una solicitud que falló o se canceló lanza aquí el error tipado del Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Lee COMFY_API_KEY del entorno.
// Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza en los reintentos automáticos.
const handle = await comfy.models.submit("stability/generate-ultra", {
  aspect_ratio: "16:9",
  prompt: "a lighthouse on a cliff at sunset, oil painting",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // con el ID del modelo, todo lo que necesita otro proceso

// Sondea hasta que la solicitud se complete, esperando el Retry-After que indique el servidor.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// El mismo resultado que devuelve models.run(). Una solicitud que falló o se canceló se rechaza aquí.
const result = await handle.get();

console.log(result.data);
```

# 1. Envía. El Router responde 201 con request_id, status_url, response_url y cancel_url.

  -H "X-API-Key: $COMFY_API_KEY"

# 3. Recoge. 200 con la salida nativa del modelo, 202 con el cuerpo de estado mientras sigue en ejecución.

## Esquema

### Entrada

<ParamField body="aspect_ratio" type="string">
  Solo texto a imagen. Relación de aspecto de salida. Predeterminado 1:1.

  Valores posibles: `1:1`, `16:9`, `9:16`, `21:9`, `9:21`, `3:2`, `2:3`, `5:4`, `4:5`
</ParamField>

<ParamField body="image" type="string (uri)">
  Solo `stability/generate-ultra`. Una URL de recurso firmada por Comfy de una imagen de origen; si la envías, cambia a imagen a imagen y requiere `strength`.

  Formato: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Lo que quieres mantener fuera de la imagen.
</ParamField>

<ParamField body="output_format" type="string">
  Solo se devuelve `png`.

  Valores posibles: `png`
</ParamField>

<ParamField body="prompt" type="string" required>
  Lo que quieres generar.
</ParamField>

<ParamField body="seed" type="integer">
  0 u omitido selecciona una semilla aleatoria.

  Alcance: `0` a `4294967294`
</ParamField>

<ParamField body="strength" type="number">
  Solo imagen a imagen de `stability/generate-ultra`. Cuánto desplazarse desde la imagen de origen; 1 la ignora.

  Alcance: `0` a `1`
</ParamField>

<ParamField body="style_preset" type="string">
  Preajuste de estilo de Stability, por ejemplo `photographic`.
</ParamField>

Se genera a partir del esquema que el Router sirve en `GET /v2/models/stability/generate-ultra/openapi.json`, el mismo documento con el que valida una llamada antes de que la solicitud llegue al proveedor.

### Salida

<ResponseField name="finish_reason" type="string" required>
  Siempre SUCCESS en un 200.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  URL firmada por Comfy de la (primera) imagen PNG, válida hasta 24 horas.

  Formato: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  Solo SDXL, cuando se devolvió más de una imagen. Cada URL de imagen firmada por Comfy, en el orden de salida, y cada una válida hasta 24 horas.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  La semilla con la que se generó la imagen.
</ResponseField>
