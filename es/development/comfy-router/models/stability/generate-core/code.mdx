## Esquema

### Entrada

<ParamField body="aspect_ratio" type="string">
  Solo texto a imagen. Relación de aspecto de salida. Por defecto 1:1.

  Valores posibles: `1:1`, `16:9`, `9:16`, `21:9`, `9:21`, `3:2`, `2:3`, `5:4`, `4:5`
</ParamField>

<ParamField body="image" type="string (uri)">
  Solo para `stability/generate-ultra`. Una URL de recurso firmada por Comfy de una imagen de origen; enviarla cambia a imagen a imagen y requiere `strength`.

  Formato: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Lo que quieres mantener fuera de la imagen.
</ParamField>

<ParamField body="output_format" type="string">
  Solo se devuelve `png`.

  Valores posibles: `png`
</ParamField>

<ParamField body="prompt" type="string" required>
  Lo que quieres generar.
</ParamField>

<ParamField body="seed" type="integer">
  0 u omitido elige una semilla aleatoria.

  Alcance: `0` a `4294967294`
</ParamField>

<ParamField body="strength" type="number">
  Solo para imagen a imagen de `stability/generate-ultra`. Cuánto mover desde la imagen de origen; 1 la ignora.

  Alcance: `0` a `1`
</ParamField>

<ParamField body="style_preset" type="string">
  Preajuste de estilo de Stability, por ejemplo `photographic`.
</ParamField>

Generado a partir del esquema que Router sirve en `GET /v2/models/stability/generate-core/openapi.json`, el mismo documento con el que valida una llamada antes de que la solicitud llegue al proveedor.

### Salida

<ResponseField name="finish_reason" type="string" required>
  Siempre SUCCESS en una respuesta 200.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  URL firmada por Comfy de la (primera) imagen PNG, válida hasta 24 horas.

  Formato: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  Solo SDXL, cuando se devolvió más de una imagen. Todas las URL de imagen firmadas por Comfy, en el orden de salida, cada una válida hasta 24 horas.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  La semilla con la que se generó la imagen.
</ResponseField>
