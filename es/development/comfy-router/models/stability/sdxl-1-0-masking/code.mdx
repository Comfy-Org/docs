  Una URL de asset firmada por Comfy de la máscara. Requerida con MASK_IMAGE_WHITE y MASK_IMAGE_BLACK, rechazada con INIT_IMAGE_ALPHA.

<ParamField body="mask_source" type="string" required>

  Valores posibles: `MASK_IMAGE_WHITE`, `MASK_IMAGE_BLACK`, `INIT_IMAGE_ALPHA`
</ParamField>

<ParamField body="sampler" type="string">
  El nombre del sampler de Stability, por ejemplo `K_DPMPP_2M`.
