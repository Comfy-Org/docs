Router responde `201` con un `request_id` en cuanto admite la ejecución, y puedes recoger el resultado cuando esté listo, desde este proceso o desde otro. [Entrega en cola](/es/development/comfy-router/queue) explica paso a paso el estado, la cancelación y la recogida.

import asyncio
from comfy_sdk import AsyncComfy

# Lee COMFY_API_KEY del entorno.
# Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/upscale-creative",
            {
                "creativity": 0.3,
                "image": "https://storage.googleapis.com/example-bucket/source.png",
                "prompt": "a detailed photo of a cat",
                "seed": 12345,
            },
        )
        print("request_id:", handle.request_id)  # junto con el ID del modelo, es todo lo que otro proceso necesita

        # Consulta periódicamente hasta que la solicitud se complete, esperando el Retry-After que indica el servidor.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # La carga útil propia del proveedor, el mismo valor que devuelve models.run().
        # Una solicitud que falló o se canceló lanza aquí el error tipado de Router.
        result = await handle.get()

    print(result)

asyncio.run(main())

import { comfy } from "@comfyorg/sdk";

// Lee COMFY_API_KEY del entorno.
// Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
const handle = await comfy.models.submit("stability/upscale-creative", {

// Consulta periódicamente hasta que la solicitud se complete, esperando el Retry-After que indica el servidor.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// El mismo resultado que devuelve models.run(). Una solicitud que falló o se canceló se rechaza aquí.
const result = await handle.get();

console.log(result.data);

## Esquema

### Entrada

<ParamField body="creativity" type="number">
  Cuánto detalle inventar. Predeterminado 0.3.

  Rango: `0.1` a `0.5`
</ParamField>

<ParamField body="image" type="string (uri)" required>
  Una URL de recurso firmada por Comfy de la imagen de origen.

  Formato: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Lo que hay que dejar fuera de la imagen con upscale.
</ParamField>

<ParamField body="output_format" type="string">
  Solo se devuelve `png`.

  Valores posibles: `png`
</ParamField>

<ParamField body="prompt" type="string" required>
  Lo que muestra la imagen con upscale.
</ParamField>

<ParamField body="seed" type="integer">
  Un valor de 0, o si se omite, elige una semilla aleatoria.

  Rango: `0` a `4294967294`
</ParamField>

<ParamField body="style_preset" type="string">
  Un estilo aplicado a `prompt` y `negative_prompt`.

  Valores posibles: `3d-model`, `analog-film`, `anime`, `cinematic`, `comic-book`, `digital-art`, `enhance`, `fantasy-art`, `isometric`, `line-art`, `low-poly`, `modeling-compound`, `neon-punk`, `origami`, `photographic`, `pixel-art`, `tile-texture`
</ParamField>

Generado a partir del esquema que Router sirve en `GET /v2/models/stability/upscale-creative/openapi.json`, el mismo documento con el que valida una llamada antes de que la solicitud llegue al proveedor.

### Salida

<ResponseField name="finish_reason" type="string" required>
  Siempre SUCCESS en una respuesta 200.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  URL firmada por Comfy de la imagen PNG (la primera), válida por hasta 24 horas.

  Formato: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  Solo SDXL, cuando se devolvió más de una imagen. Todas las URL de imágenes firmadas por Comfy, en el orden de salida, cada una válida por hasta 24 horas.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  La semilla con la que se generó la imagen.
</ResponseField>
