Router responde `201` con un `request_id` en cuanto acepta la ejecución, y puedes recoger el resultado cuando esté listo, desde este proceso o desde otro. import asyncio
```python Python
from comfy_sdk import AsyncComfy

# Lee COMFY_API_KEY del entorno.
# Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "stability/upscale-conservative",
            {
                "creativity": 0.35,
                "image": "https://storage.googleapis.com/example-bucket/source.png",
                "prompt": "a detailed photo of a cat",

            },
        )
        print("request_id:", handle.request_id)  # con el ID del modelo, es todo lo que otro proceso necesita

        # Consulta hasta que la solicitud se complete, esperando el Retry-After que indica el servidor.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # El payload propio del proveedor, el mismo valor que devuelve models.run().
        # Una solicitud que falló o se canceló genera aquí el error tipado de Router.
        result = await handle.get()

    print(result)

asyncio.run(main())
```

```typescript TypeScript
import { comfy } from "@comfyorg/sdk";

// Lee COMFY_API_KEY del entorno.
// Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
const handle = await comfy.models.submit("stability/upscale-conservative", {
  creativity: 0.35,
  image: "https://storage.googleapis.com/example-bucket/source.png",
  prompt: "a detailed photo of a cat",
  seed: 12345,
});
console.log("requestId:", handle.requestId); // con el ID del modelo, es todo lo que otro proceso necesita

// Consulta hasta que la solicitud se complete, esperando el Retry-After que indica el servidor.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// Devuelve el mismo resultado que models.run(). Una solicitud que falló o se canceló se rechaza aquí.
const result = await handle.get();

console.log(result.data);
```

## Esquema

### Entrada

<ParamField body="creativity" type="number">
  Cuánto detalle inventar. Valor predeterminado 0.35.

  Alcance: `0.2` a `0.5`
</ParamField>

<ParamField body="image" type="string (uri)" required>
  Una URL de recurso firmada por Comfy de la imagen de origen.

  Formato: `uri`
</ParamField>

<ParamField body="negative_prompt" type="string">
  Lo que se debe mantener fuera de la imagen con upscale.
</ParamField>

<ParamField body="output_format" type="string">
  Solo se devuelve `png`.

  Valores posibles: `png`
</ParamField>

<ParamField body="prompt" type="string" required>
  Lo que muestra la imagen con upscale.
</ParamField>

<ParamField body="seed" type="integer">
  0, u omitir el campo, elige una semilla aleatoria.

  Alcance: `0` a `4294967294`
</ParamField>

Se genera a partir del esquema que Router sirve en `GET /v2/models/stability/upscale-conservative/openapi.json`, el mismo documento con el que valida una llamada antes de que la solicitud llegue al proveedor.

### Salida

<ResponseField name="finish_reason" type="string" required>
  Siempre SUCCESS en una respuesta 200.
</ResponseField>

<ResponseField name="image" type="string (uri)" required>
  URL de la imagen PNG (la primera) firmada por Comfy, válida hasta 24 horas.

  Formato: `uri`
</ResponseField>

<ResponseField name="images" type="string (uri)[]">
  Solo SDXL, cuando se devolvió más de una imagen. Todas las URL de imagen firmadas por Comfy, en el orden de salida, y cada una válida hasta 24 horas.
</ResponseField>

<ResponseField name="seed" type="integer" required>
  La semilla con la que se generó la imagen.
</ResponseField>
