El mismo cuerpo, enviado a `POST https://api.comfy.org/v2/models/tencent/hunyuan-3d-smart-topology/requests`. Router responde `201` con un `request_id` en cuanto se admite la ejecución, y el resultado se recoge cuando está listo, desde este proceso o desde otro. [Entrega en cola](/es/development/comfy-router/queue) recorre el estado, la cancelación y la recogida.

import asyncio
from comfy_sdk import AsyncComfy

# Lee COMFY_API_KEY del entorno.
# Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "tencent/hunyuan-3d-smart-topology",
            {
                "File3D": {
                    "Type": "GLB",
                    "Url": "https://vcg-test-1258344699.cos.ap-guangzhou.myqcloud.com/test/3d/test.glb",
                },
            },
        )
        print("request_id:", handle.request_id)  # junto con el ID del modelo, es todo lo que necesita otro proceso

        # Sondea hasta que la solicitud se complete, esperando el Retry-After que indica el servidor.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # La carga propia del proveedor, el mismo valor que devuelve models.run().
        # Una solicitud que falló o se canceló genera aquí el error tipado de Router.
        result = await handle.get()

    print(result)

asyncio.run(main())

<ResponseField name="Response" type="object" required>

<ResponseField name="Response.ErrorCode" type="string">
  Código de error de Tencent, documentado como una cadena vacía cuando no hay error. Router no lo lee una vez que `Status` está presente.

<ResponseField name="Response.ErrorMessage" type="string">
  Mensaje de error de Tencent, documentado como una cadena vacía cuando no hay error. Router no lo lee una vez que `Status` está presente.

<ResponseField name="Response.RequestId" type="string">
  Identificador de solicitud propio de Tencent, para solucionar problemas con Tencent. No es el ID de trabajo ni un recurso.
</ResponseField>

<ResponseField name="Response.ResultFile3Ds" type="object[]" required>
  Los archivos 3D generados por la tarea finalizada. Está presente y no vacío en el documento que devuelve Router; al menos una entrada incluye una `Url` que se puede obtener. Los enlaces son de Tencent y están documentados como válidos durante 24 horas.
</ResponseField>

<ResponseField name="Response.ResultFile3Ds[].PreviewImageUrl" type="string (uri)">
  URL de la vista previa de imagen

  Formato: `uri`
</ResponseField>

<ResponseField name="Response.ResultFile3Ds[].Type" type="string">
  Formato de archivo. Una tarea finalizada puede devolver varias entradas sin un
orden fijo, y no todas las entradas son una malla: se ha observado que las
operaciones de UV y de topología inteligente devuelven mallas OBJ, GLB y FBX
junto a una IMAGE (una textura PNG). Selecciona una entrada por `Type` en lugar
de por posición. Deliberadamente no es un enum: los valores anteriores son solo
los observados, este componente se comparte con operaciones cuya salida nunca se
ha observado (part, texture-edit), y el esquema de salida es descriptivo, así que
un valor no listado que devuelva Tencent no debe convertir un resultado correcto
en una violación del esquema.
</ResponseField>

<ResponseField name="Response.ResultFile3Ds[].Url" type="string (uri)">
  URL del archivo (válida durante 24 horas)

  Formato: `uri`
</ResponseField>

<ResponseField name="Response.Status" type="string" required>
  Valores posibles: `DONE`
</ResponseField>
