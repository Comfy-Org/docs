Router responde `201` con un `request_id` en cuanto se admite la ejecución, y recoges el resultado cuando está listo, desde este proceso u otro. ```python Python
import asyncio
from comfy_sdk import AsyncComfy

# Lee COMFY_API_KEY del entorno.
# Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
async def main():
    async with AsyncComfy() as client:
        handle = await client.models.submit(
            "pika/pika-h3-flex-image-to-video",
            {
                "duration": 5,
                "image": "https://example.invalid/pika/first-frame.png",
                "prompt": "The camera slowly pushes in as the leaves begin to sway in the wind",
                "resolution": "480p",
            },
        )
        print("request_id:", handle.request_id)  # junto con el ID del modelo, es todo lo que necesita otro proceso

        # Sondea hasta que la solicitud se complete, esperando el Retry-After que indica el servidor.
        async for update in handle.iter_events():
            print(update.status, update.queue_position)

        # La carga útil propia del proveedor, el mismo valor que devuelve models.run().
        # Una solicitud que falló o se canceló lanza aquí el error tipado de Router.
        result = await handle.get()

    print(result)

asyncio.run(main())

import { comfy } from "@comfyorg/sdk";

// Lee COMFY_API_KEY del entorno.
// Cada llamada a submit() genera su propia Idempotency-Key y la reutiliza para los reintentos automáticos.
const handle = await comfy.models.submit("pika/pika-h3-flex-image-to-video", {

  image: "https://example.invalid/pika/first-frame.png",
  prompt: "The camera slowly pushes in as the leaves begin to sway in the wind",
  resolution: "480p",
});
console.log("requestId:", handle.requestId); // junto con el ID del modelo, es todo lo que necesita otro proceso

// Sondea hasta que la solicitud se complete, esperando el Retry-After que indica el servidor.
for await (const update of handle.events()) {
  console.log(update.status, update.queuePosition);
}

// El mismo resultado que devuelve models.run(). Una solicitud que falló o se canceló se rechaza aquí.
const result = await handle.get();

console.log(result.data);

## Esquema

### Entrada

<ParamField body="aspect_ratio" type="string">
  Relación de aspecto de salida. `auto` elige una a partir del prompt y de las entradas de medios. Omítela para que Pika elija: `auto` cuando `rewrite` está activado; si no, la relación del primer medio de entrada; si no, 16:9.

  Valores posibles: `auto`, `21:9`, `16:9`, `3:2`, `4:3`, `5:4`, `1:1`, `4:5`, `3:4`, `2:3`, `9:16`, `9:21`
</ParamField>

<ParamField body="channel_mode" type="string" default="&quot;mono&quot;">
  Solo para pistas de audio. `mono` mezcla a un solo canal antes de la separación; `stereo` conserva ambos canales. El audio del video no cambia.

  Valores posibles: `stereo`, `mono`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  Duración del video en segundos enteros, de 5 a 15.

  Alcance: `5` a `15`
</ParamField>

<ParamField body="image" type="string">
  URL de la imagen del primer fotograma, un JPEG, PNG o WebP estático de como máximo 24 MiB y 40 millones de píxeles.
</ParamField>

<ParamField body="last_frame_image" type="string">
  URL de la imagen del último fotograma, con el mismo formato y los mismos límites de tamaño que `image`.
</ParamField>

<ParamField body="output_mode" type="string" default="&quot;video&quot;">
  `video` devuelve solo el video. `audio-stems` también devuelve pistas WAV de diálogo, música y efectos en `output.stems`, y agrega el cargo de Pika por separación de pistas por segundo.

  Valores posibles: `video`, `audio-stems`
</ParamField>

<ParamField body="prompt" type="string" required>
  Prompt de texto que describe el video y su audio.
</ParamField>

<ParamField body="resolution" type="string" default="&quot;768p&quot;">
  Resolución de salida. 480p y 768p son nativas. 1080p, 2k y 4k se generan a 768p y después reciben upscale, y conservan el audio y la frecuencia de cuadros.

  Valores posibles: `480p`, `768p`, `1080p`, `2k`, `4k`
</ParamField>

<ParamField body="rewrite" type="boolean" default="true">
  Mejora el prompt antes de generar. Establécelo en false para usar el prompt tal como se escribió.
</ParamField>

<ParamField body="seed" type="integer" default="0">
  Semilla para el video, 0 o más.

  Alcance: `0` a `…`

  Formato: `int64`
</ParamField>
