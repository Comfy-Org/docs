Referencia de API para `openrouter/images`, servida por Comfy Router desde Openrouter.

**Entrada:** Texto, Imagen · **Salida:** Imagen

## Configurar la solicitud

Crea una clave en [tu espacio de trabajo de Comfy](https://platform.comfy.org/profile/api-keys?onboarding=router) y expórtala como `COMFY_API_KEY`. Para Python, ejecuta `pip install comfy-sdk`. Para TypeScript, ejecuta `npm install @comfyorg/sdk`. cURL usa HTTP sin procesar.

**ID del modelo:** `openrouter/images`

**Endpoint:** `POST https://api.comfy.org/v2/models/openrouter/images`

<Note>
Este modelo no tiene un ejemplo de solicitud ejecutable. Construye el cuerpo a partir de la documentación de entrada que aparece a continuación y luego úsalo con la [guía de inicio rápido de Router](/es/development/comfy-router/quickstart).
</Note>
