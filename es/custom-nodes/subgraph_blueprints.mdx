Si tienes componentes de subgráfico reutilizables asociados a tus nodos personalizados, ComfyUI puede ponerlos a disposición de los usuarios como planos de subgráficos globales. Los planos de subgráficos permiten a los usuarios añadir rápidamente grupos de nodos ya creados desde el menú de subgráficos.

Como desarrollador de nodos, todo lo que tienes que hacer es crear una carpeta `subgraphs` en el directorio de tu nodo personalizado y colocar allí los archivos `.json`.

Internamente, ComfyUI busca archivos de subgráficos en todos los directorios de nodos personalizados y los sirve a través del endpoint de API `/global_subgraphs`.

## Ejemplo

Dentro del directorio `ComfyUI-MyCustomNodeModule/subgraphs/`:
 - `My_upscale_subgraph.json`
 - `My_effects_subgraph.json`

En este ejemplo, el navegador de subgráficos de ComfyUI muestra los planos de `ComfyUI-MyCustomNodeModule` que los usuarios pueden añadir a sus flujos de trabajo.

## Crear un archivo JSON de subgráfico

Los archivos JSON de subgráficos usan el mismo formato que los archivos JSON de flujos de trabajo. La forma más sencilla de crear uno:

1. Crea tu subgráfico en ComfyUI
2. Selecciona los nodos que quieres incluir
3. Conviértelos en un subgráfico
4. Exporta el subgráfico como JSON
5. Coloca el archivo JSON en tu carpeta `subgraphs/`
