Puedes proporcionar a ComfyUI un objeto de configuraciones que aparecerá cuando el usuario abra el panel de configuraciones de ComfyUI.

## Funcionamiento básico

### Agregar una configuración

```javascript
import { app } from "../../scripts/app.js";

app.registerExtension({
    name: "My Extension",
    settings: [
        {
            id: "example.boolean",
            name: "Example boolean setting",
            type: "boolean",
            defaultValue: false,
        },
    ],
});
```

El `id` debe ser único en todas las extensiones y se usará para obtener los valores.

Si no [proporcionas una categoría](#categorías), el `id` se dividirá por `.` para
determinar dónde aparece en el panel de configuraciones.

- Si tu `id` no contiene ningún `.`, aparecerá en la categoría "Other" y tu `id`
  se usará como encabezado de sección.
- Si tu `id` contiene al menos un `.`, la parte más a la izquierda se usará como
  categoría de la configuración y la segunda parte se usará como encabezado de
  sección. Las demás partes se ignoran.


### Leer una configuración

```javascript
import { app } from "../../scripts/app.js";

if (app.extensionManager.setting.get('example.boolean')) {
    console.log("Setting is enabled.");
} else {
    console.log("Setting is disabled.");
}
```

### Reaccionar a los cambios

El controlador de eventos `onChange()` se llamará en cuanto el usuario cambie la
configuración en el panel de configuraciones.

También se llamará cuando se registre la extensión, en cada carga de página.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Escribir una configuración

```javascript
import { app } from "../../scripts/app.js";

try {
    await app.extensionManager.setting.set("example.boolean", true);
} catch (error) {
    console.error(`Error changing setting: ${error}`);
}
```

### Configuración adicional

Los tipos de configuración se basan en componentes de [PrimeVue](https://primevue.org/).
Puedes definir las props descritas en la documentación de PrimeVue para las
configuraciones de ComfyUI agregándolas en un campo `attrs`.

Por ejemplo, esto agrega botones de incremento y decremento a una entrada de número:

```javascript
{
    id: "example.number",
    name: "Example number setting",
    type: "number",
    defaultValue: 0,
    attrs: {
        showButtons: true,
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```
## Tipos

### Booleano

Muestra un interruptor de activado/desactivado.

Basado en el [componente ToggleSwitch de PrimeVue](https://primevue.org/toggleswitch/).

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Texto

Es texto de forma libre.

Basado en el [componente InputText de PrimeVue](https://primevue.org/inputtext/).

```javascript
{
    id: "example.text",
    name: "Example text setting",
    type: "text",
    defaultValue: "Foo",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Número

Sirve para introducir números.

Para permitir decimales, establece el atributo `maxFractionDigits` en un número mayor que cero.

Basado en el [componente InputNumber de PrimeVue](https://primevue.org/inputnumber/).

```javascript
{
    id: "example.number",
    name: "Example number setting",
    type: "number",
    defaultValue: 42,
    attrs: {
        showButtons: true,
        maxFractionDigits: 1,
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Control deslizante

Permite al usuario introducir un número directamente o mediante un control deslizante.

Basado en el [componente Slider de PrimeVue](https://primevue.org/slider/). No se admiten rangos.

```javascript
{
    id: "example.slider",
    name: "Example slider setting",
    type: "slider",
    attrs: {
        min: -10,
        max: 10,
        step: 0.5,
    },
    defaultValue: 0,
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Combo

Permite al usuario elegir de una lista desplegable de valores.

Puedes proporcionar las opciones como una cadena simple o como un objeto con los campos `text` y `value`. Si solo proporcionas una cadena simple, se usará tanto como texto como valor.

Puedes permitir que el usuario introduzca texto libre aportando el atributo `editable: true`, o que busque aportando el atributo `filter: true`.

Basado en el [componente Select de PrimeVue](https://primevue.org/select/). No se admiten grupos.

```javascript
{
    id: "example.combo",
    name: "Example combo setting",
    type: "combo",
    defaultValue: "first",
    options: [
        { text: "My first option", value: "first" },
        "My second option",
    ],
    attrs: {
        editable: true,
        filter: true,
    },
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Color

Permite al usuario seleccionar un color desde un selector de color o escribir una referencia hexadecimal.

Ten en cuenta que el formato requiere seis dígitos hexadecimales completos: la forma abreviada de tres dígitos no funciona.

Basado en el [componente ColorPicker de PrimeVue](https://primevue.org/colorpicker/).

```javascript
{
    id: "example.color",
    name: "Example color setting",
    type: "color",
    defaultValue: "ff0000",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Imagen

Permite al usuario subir una imagen.

La configuración se guarda como [data URL](https://developer.mozilla.org/en-US/docs/Web/URI/Schemes/data).

Basado en el [componente FileUpload de PrimeVue](https://primevue.org/fileupload/).

```javascript
{
    id: "example.image",
    name: "Example image setting",
    type: "image",
    onChange: (newVal, oldVal) => {
        console.log(`Setting was changed from ${oldVal} to ${newVal}`);
    },
}
```

### Oculto

Las configuraciones ocultas no se muestran en el panel de configuraciones, pero puedes leerlas y escribir en ellas desde tu código.

```javascript
{
    id: "example.hidden",
    name: "Example hidden setting",
    type: "hidden",
}
```
## Otros

### Categorías

Puedes especificar la categorización de tu ajuste de forma independiente al `id`.
Esto significa que puedes cambiar la categorización y el nombre sin cambiar el
`id` y perder los valores que los usuarios ya hayan establecido.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    category: ["Category name", "Section heading", "Setting label"],
}
```

### Tooltips

Puedes añadir ayuda contextual adicional con el campo `tooltip`. Esto añade un pequeño icono ℹ︎
después del nombre del campo que mostrará el texto de ayuda cuando el usuario pase el cursor
sobre él.

```javascript
{
    id: "example.boolean",
    name: "Example boolean setting",
    type: "boolean",
    defaultValue: false,
    tooltip: "This is some helpful information",
}
```
