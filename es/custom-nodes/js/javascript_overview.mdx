## Extender el cliente de Comfy

Comfy se puede modificar mediante un mecanismo de extensiones. Para añadir una extensión necesitas:

- Exportar `WEB_DIRECTORY` desde tu módulo de Python, 
- Colocar uno o más archivos `.js` en ese directorio,
- Usar `app.registerExtension` para registrar tu extensión.

Estos tres pasos se describen a continuación. Cuando ya sepas cómo añadir una extensión, consulta 
los [hooks](/custom-nodes/js/javascript_hooks) disponibles para que tu código se ejecute, 
la descripción de los distintos [objetos de Comfy](/custom-nodes/js/javascript_objects_and_hijacking) que puedas necesitar,
o pasa directamente a algunos [fragmentos de código de ejemplo](/custom-nodes/js/javascript_examples).

### Exportar `WEB_DIRECTORY`

El cliente web de Comfy se puede extender creando un subdirectorio en el directorio de tu nodo personalizado, al que por convención se llama `js`, y
exportando `WEB_DIRECTORY`, de modo que tu `__init_.py` incluirá algo como:
```python
WEB_DIRECTORY = "./js"
__all__ = ["NODE_CLASS_MAPPINGS", "NODE_DISPLAY_NAME_MAPPINGS", "WEB_DIRECTORY"]
```

### Incluir archivos `.js`

<Tip>Todos los archivos `.js` de JavaScript los cargará el navegador a medida que se carga la página web de Comfy. No necesitas especificar el archivo 
en el que está tu extensión.</Tip>

_Solo_ se añadirán a la página web los archivos `.js`. Otros recursos (como los archivos `.css`) se pueden consultar
en `extensions/custom_node_subfolder/the_file.css` y añadir mediante código.

<Warning>Esa ruta _no_ incluye el nombre del subdirectorio. El valor de `WEB_DIRECTORY` lo inserta el servidor.</Warning>

### Registrar una extensión

La estructura básica de una extensión consiste en importar el objeto principal `app` de Comfy y llamar a `app.registerExtension`, 
pasando un diccionario que contenga un `name` único, 
y una o más funciones que los hooks del código de Comfy llamarán.

Una extensión completa, trivial y molesta podría tener este aspecto:
```Javascript
import { app } from "../../scripts/app.js";
app.registerExtension({ 
	name: "a.unique.name.for.a.useless.extension",
	async setup() { 
		alert("Setup complete!")
	},
})
```
