El frontend de ComfyUI ahora normaliza los ID de nodo locales al tipo de cadena
con marca `NodeId` en los límites internos. Los flujos de trabajo serializados y
las cargas útiles de la API todavía pueden contener ID numéricos, pero los ID de
nodo en litegraph, como `node.id`, `LLink.origin_id` y `LLink.target_id`, deben
tratarse como cadenas después de entrar al frontend. Los ID de enlace
(`LLink.id`) y los ID de reenrutamiento siguen siendo números.

Quienes escriben extensiones deben evitar las comparaciones numéricas con los ID
de nodo. En particular, los centinelas de límite de subgrafo se exponen como ID
de cadena con marca:

- `SUBGRAPH_INPUT_ID` se serializa a partir de `-10`
- `SUBGRAPH_OUTPUT_ID` se serializa a partir de `-20`

Compara con las cadenas `'-10'` y `'-20'`, o normaliza ambos lados a cadenas
antes de comparar valores clásicos.
