Si tienes archivos de flujo de trabajo de ejemplo asociados con tus nodos personalizados,
ComfyUI puede mostrárselos al usuario en el explorador de plantillas (menú `Workflow`/`Browse Templates`).
Las plantillas de flujos de trabajo son una excelente manera de ayudar a quienes están empezando con tus nodos.

Todo lo que tienes que hacer como desarrollador de nodos es crear una carpeta `example_workflows` y colocar allí los archivos `json`.
De forma opcional, puedes colocar archivos `jpg` con el mismo nombre para que se muestren como miniatura de la plantilla.

Internamente, ComfyUI sirve estos archivos de forma estática junto con un endpoint (`/api/workflow_templates`)
que devuelve la colección de plantillas de flujos de trabajo.

<Note>

También se aceptan los siguientes nombres de carpeta, pero seguimos recomendando `example_workflows`:
- workflow
- workflows
- example
- examples
</Note>

## Ejemplo

En el directorio `ComfyUI-MyCustomNodeModule/example_workflows/`:
 - `My_example_workflow_1.json`
 - `My_example_workflow_1.jpg`
 - `My_example_workflow_2.json`

En este ejemplo, el explorador de plantillas de ComfyUI muestra una categoría llamada `ComfyUI-MyCustomNodeModule` con dos elementos, uno de los cuales tiene miniatura.

Para ver un ejemplo real, consulta la [carpeta example_workflows de ComfyUI-Impact-Pack](https://github.com/ltdrdata/ComfyUI-Impact-Pack/tree/Main/example_workflows).
