## Acerca de los nodos personalizados

Después de instalar ComfyUI, descubrirás que incluye muchos nodos integrados. Estos nodos nativos se denominan nodos **Comfy Core**, los cuales son mantenidos oficialmente por ComfyUI.

Además, existen numerosos [**nodos personalizados**](https://registry.comfy.org) creados por diversos autores de la comunidad de ComfyUI. Estos nodos personalizados aportan una amplia funcionalidad a ComfyUI, ampliando enormemente sus capacidades y los límites de sus funciones.

En esta guía, veremos diversas operaciones relacionadas con los nodos personalizados, incluyendo la instalación, las actualizaciones, la desactivación, la desinstalación y la instalación de dependencias.

Cualquier persona puede desarrollar sus propias extensiones personalizadas para ComfyUI y compartirlas con los demás. Puedes encontrar muchos nodos personalizados de la comunidad [aquí](https://registry.comfy.org). Si quieres desarrollar tus propios nodos personalizados, visita la siguiente sección para empezar:

### 1. Instalar nodos personalizados

Actualmente, ComfyUI admite instalar nodos personalizados mediante varios métodos, entre ellos:

- [Instalar mediante ComfyUI Manager (recomendado)](#install-via-comfyui-manager)
- Instalar mediante Git
- Instalación manual

Recomendamos instalar nodos personalizados mediante **ComfyUI Manager**, que es una herramienta sumamente importante en el ecosistema de nodos personalizados de ComfyUI. Hace que la gestión de nodos personalizados (como buscar, instalar, actualizar, deshabilitar y desinstalar) sea sencilla: solo necesitas buscar el nodo que quieres instalar en ComfyUI Manager y hacer clic en instalar.

Sin embargo, dado que actualmente todos los nodos personalizados se almacenan en GitHub, para las regiones que no pueden acceder a GitHub con normalidad, hemos escrito en esta guía instrucciones detalladas para los distintos métodos de instalación de nodos personalizados.

Además, como recomendamos usar **ComfyUI Manager** para la gestión de complementos, te recomendamos usar esta herramienta para la gestión de complementos. Puedes encontrar su código fuente [aquí](https://github.com/Comfy-Org/ComfyUI-Manager).
Por lo tanto, en esta documentación usaremos la instalación de ComfyUI Manager como ejemplo de instalación de un nodo personalizado, y complementaremos cómo usarlo para la gestión de nodos en las secciones de introducción correspondientes.

### 2. Instalando las Dependencias de los Nodos

Todos los nodos personalizados requieren la instalación de las dependencias relacionadas. Por ejemplo, para ComfyUI-Manager, puedes visitar el archivo [requirements.txt](https://github.com/Comfy-Org/ComfyUI-Manager/blob/main/requirements.txt) para ver los requisitos de los paquetes de dependencias.

En los pasos anteriores, solo clonamos el código del nodo personalizado de forma local y no instalamos las dependencias correspondientes, así que a continuación necesitamos instalar las dependencias correspondientes.

<Note>
En realidad, si usas ComfyUI-Manager para instalar plugins, ComfyUI Manager te ayudará automáticamente a completar la instalación de las dependencias. Solo necesitas reiniciar ComfyUI después de instalar el plugin. Esta es la razón por la que recomendamos encarecidamente usar ComfyUI Manager para instalar nodos personalizados.

Pero quizás en algunas situaciones no puedas usar ComfyUI Manager para instalar nodos personalizados sin problemas, por lo que proporcionamos esta guía más detallada de instalación de dependencias.
</Note>

En el capítulo de [Dependencias](/es/basic-concepts/dependencies), presentamos el contenido relacionado con las dependencias en ComfyUI. ComfyUI es un proyecto basado en **Python**, y creamos un entorno de ejecución de **Python** independiente para ejecutar ComfyUI. Todas las dependencias relacionadas deben instalarse en este entorno de ejecución de **Python** independiente.

Si ejecutas `pip install -r requirements.txt` directamente en la terminal a nivel del sistema, las dependencias correspondientes podrían instalarse en el entorno de **Python** a nivel del sistema, lo que hará que las dependencias sigan faltando en el entorno de ComfyUI e impedirá que los nodos personalizados correspondientes funcionen normalmente.

Así que a continuación necesitamos usar el entorno de ejecución de Python independiente de ComfyUI para completar la instalación de las dependencias.

Según las diferentes versiones de ComfyUI, usaremos diferentes métodos para instalar las dependencias correspondientes:

<Tabs>
<Tab title="ComfyUI Portable">
La versión ComfyUI Portable usa un Python Integrado ubicado en el directorio `\ComfyUI_windows_portable\python_embeded`. Necesitamos usar este Python para completar la instalación de las dependencias.

Primero, inicia la terminal en el directorio de la versión portable, o usa el comando `cd` para navegar al directorio `\ComfyUI_windows_portable\` después de iniciar la terminal.

![Iniciar Terminal](/images/concepts/custom_nodes/open_terminal.jpg)

Asegúrate de que el directorio de la terminal sea `\ComfyUI_windows_portable\`, como se muestra a continuación para `D:\ComfyUI_windows_portable\`

![Terminal](/images/concepts/custom_nodes/terminal.jpg)

Luego usa `python_embeded\python.exe` para completar la instalación de las dependencias:

```bash
python_embeded\python.exe -m pip install -r ComfyUI\custom_nodes\ComfyUI-Manager\requirements.txt
```
Por supuesto, puedes reemplazar ComfyUI-Manager con el nombre del nodo personalizado que realmente instalaste, pero asegúrate de que exista un archivo `requirements.txt` en el directorio del nodo correspondiente.
</Tab>

<Tab title="Comfy Desktop">

<Tip>
Dado que Comfy Desktop ya tiene ComfyUI-Manager y sus dependencias instalados durante el proceso de instalación, y esta guía usa ComfyUI Manager como ejemplo para la instalación de nodos personalizados, en realidad no necesitas realizar la instalación de las dependencias de ComfyUI Manager en la versión de escritorio.
Si no hay problemas inesperados, recomendamos usar ComfyUI Manager para instalar nodos personalizados, así no necesitas instalar las dependencias manualmente.
</Tip>

![Terminal de Comfy Desktop](/images/concepts/custom_nodes/desktop_terminal.png)
 
Luego usa el siguiente comando para instalar las dependencias del plugin correspondiente:

```bash
pip install -r .\custom_nodes\<corresponding_custom_node_name>\requirements.txt
```
Como se muestra a continuación, esta es la instalación de dependencias de ComfyUI-Hunyuan3Dwrapper:

![Instalación de Dependencias de Comfy Desktop](/images/concepts/custom_nodes/install_dependencies.png)

</Tab>

<Tab title="Usuarios con Entorno de Python Personalizado">
Para los usuarios con entornos de Python personalizados, recomendamos usar `pip install -r requirements.txt` para completar la instalación de las dependencias.

### Control de versiones de los nodos personalizados

El control de versiones de los nodos personalizados se basa en realidad en el control de versiones de Git. Puedes administrar las versiones de los nodos mediante Git, pero ComfyUI Manager ya ha integrado esta funcionalidad de administración de versiones muy bien. Muchas gracias a [@Dr.Lt.Data](https://github.com/ltdrdata) por brindarnos una herramienta tan conveniente.

En esta sección, seguiremos explicando estos dos métodos diferentes de administración de versiones de plugins, pero si usas paquetes ZIP para la instalación manual, se perderá la información correspondiente del historial de versiones de git, lo que hará imposible realizar la administración de versiones.

<Tabs>

<Tab title="Administración de versiones con ComfyUI Manager">

<Tip>Dado que estamos iterando en ComfyUI Manager, la interfaz y los pasos más recientes pueden cambiar significativamente</Tip>

<Steps>
<Step title="Entrar a la interfaz de administración de nodos">
Realiza las operaciones correspondientes como se muestra para entrar a la interfaz de ComfyUI Manager
</Step>
<Step title="Encontrar el paquete de nodos personalizados correspondiente">
Puedes usar los filtros correspondientes para filtrar los paquetes de nodos instalados y luego realizar la administración de nodos correspondiente
</Step>
<Step title="Realizar el cambio de versión">
Cambia a la versión correspondiente. El administrador te ayudará a completar las actualizaciones e instalación de las dependencias correspondientes. Por lo general, debes reiniciar ComfyUI después de cambiar de versión para que los cambios surtan efecto.
</Step>
</Steps>

</Tab>

<Tab title="Administración de versiones con Git">

<Steps>
<Step title="Navegar al directorio usando la línea de comandos">

Encuentra la carpeta del directorio donde se ubica tu nodo correspondiente, por ejemplo `ComfyUI/custom_nodes/ComfyUI-Manager`
Usa el comando `cd` para entrar a la carpeta correspondiente:
```bash
cd <your_installation_directory>/ComfyUI/custom_nodes/ComfyUI-Manager
```

</Step>
<Step title="Ver las versiones usando comandos de Git">

Puedes usar el siguiente comando para ver todas las etiquetas y versiones disponibles:
```bash
git tag
```
Esto listará todas las etiquetas de versión, y puedes elegir la versión a la que deseas cambiar.

</Step>
<Step title="Cambiar a una versión especificada">
Usa el siguiente comando para cambiar a una etiqueta o versión especificada:
```bash
git checkout <tag_name>
```
Reemplaza `<tag_name>` con la etiqueta de versión específica a la que deseas cambiar.

</Step>
<Step title="Cambiar a una versión de commit específica">
Si deseas cambiar a una versión de commit específica, puedes usar el siguiente comando:
```bash
git checkout <commit_hash>
```
Reemplaza `<commit_hash>` con el hash del commit específico al que deseas cambiar.

</Step>
<Step title="Instalar las dependencias">
Dado que las dependencias del paquete de nodos personalizados correspondiente pueden cambiar después del cambio de versión, debes reinstalar las dependencias del nodo correspondiente. Consulta las instrucciones de la sección [Instalando las dependencias del nodo](#2-installing-node-dependencies) para entrar al entorno correspondiente e instalarlas.
</Step>
</Steps>

</Tab>

### Instalando el Administrador

Si estás ejecutando la aplicación servidor de ComfyUI, necesitas instalar el administrador. Si ComfyUI se está ejecutando, ciérralo antes de continuar.

El primer paso es instalar Git, que es una aplicación de línea de comandos para el control de versiones de software. Git descargará el administrador de ComfyUI desde [github.com](https://github.com). Descarga e instala Git desde [git-scm.com](https://git-scm.com/).

Después de instalar Git, navega al directorio del programa servidor de ComfyUI y entra en la carpeta llamada **custom_nodes**. Abre una ventana de comandos o terminal. Asegúrate de que la línea de comandos muestre la ruta del directorio actual como **custom_nodes**. Ejecuta el siguiente comando para clonar el repositorio de ComfyUI-Manager:

```bash
git clone https://github.com/Comfy-Org/ComfyUI-Manager.git
```

Esto descargará el administrador. Técnicamente, esto se denomina _clonar un repositorio de Git_.
