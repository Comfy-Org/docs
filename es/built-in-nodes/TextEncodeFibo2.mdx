Codifica un prompt de Fibo 2.0 en condicionamiento y un latente vacío correspondiente. El prompt puede ser texto plano o una descripción JSON estructurada; con imágenes conectadas, se convierte en la instrucción de edición, o en una descripción JSON del resultado con una clave `edit_instruction`, y las imágenes actúan como latentes de referencia para ambas salidas cuando hay un VAE conectado. Realiza el muestreo de la salida `latent`, cuyo tamaño es el tamaño al que se recortan las imágenes.

## Entradas

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
| --- | --- | --- | --- | --- |
| `clip` | El codificador de texto Fibo 2.0 usado para tokenizar y codificar el prompt. | CLIP | Sí | - |
| `prompt` | La descripción a partir de la cual generar, o la instrucción de edición cuando hay imágenes conectadas. Haz referencia a las imágenes como `<image_1>`, `<image_2>` y así sucesivamente. También funciona una descripción JSON del resultado esperado, con el cambio descrito en su clave `edit_instruction`. | STRING | Sí | - |
| `negative_prompt` | Descripción de la que alejarse, codificada como el condicionamiento negativo. Un valor no vacío se envía tal cual dentro de la plantilla de chat de Fibo 2.0, sin limpiarse como una descripción. Vacío es la descripción nula con la que se entrenó Fibo 2.0 para guía sin clasificador en flujos de edición (predeterminado: vacío). | STRING | Sí | - |
| `vae` | VAE usado para codificar las imágenes en latentes de referencia. Sin él, las imágenes solo condicionan la codificación de texto. | VAE | No | - |
| `images` | Imágenes a editar, hasta 16. Una sola imagen se escala y se recorta desde el centro al tamaño del resultado, porque la edición se alinea con ella píxel a píxel; varias imágenes se escalan cada una a su propio tamaño de entrenamiento. | IMAGE | No | 0 a 16 imágenes |
| `width` | Ancho del resultado, redondeado hacia abajo a un múltiplo de 16. 0 usa el tamaño con el que se entrenó Fibo 2.0 para la relación de aspecto de la primera imagen, aproximadamente 1 megapíxel, o 1024 sin imágenes (predeterminado: 0). | INT | Sí | 0 a 16384 (paso 16) |
| `height` | Alto del resultado, redondeado hacia abajo a un múltiplo de 16. 0 usa el tamaño con el que se entrenó Fibo 2.0 para la relación de aspecto de la primera imagen, aproximadamente 1 megapíxel, o 1024 sin imágenes (predeterminado: 0). | INT | Sí | 0 a 16384 (paso 16) |
| `batch_size` | Número de latentes a crear en el lote (predeterminado: 1). | INT | Sí | 1 a 4096 |

Los latentes de referencia se adjuntan a ambas salidas, de modo que las imágenes viajan con el condicionamiento en lugar de solo con la rama positiva. Cuando el VAE no está conectado, las imágenes solo las ve el codificador de texto y no se añaden latentes de referencia.

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
| --- | --- | --- |
| `positive` | Condicionamiento del prompt, con los latentes de referencia cuando un VAE y las imágenes están conectados. | CONDITIONING |
| `negative` | Condicionamiento de `negative_prompt`, solo texto, con los mismos latentes de referencia. | CONDITIONING |
| `latent` | Latente vacío con el tamaño solicitado, listo para realizar el muestreo. | LATENT |
