El nodo ModelMergeSD2 fusiona dos modelos Stable Diffusion 2.x mezclando sus componentes correspondientes, con un peso independiente para el embedding de tiempo, el embedding de etiquetas y cada bloque de entrada, central y de salida. La disposición de los bloques es la misma que en ModelMergeSD1, por lo que ambos nodos exponen el mismo conjunto de proporciones.

## Entradas

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
| --- | --- | --- | --- | --- |
| `modelo1` | El primer modelo que se va a fusionar. Todo lo que no aporta el segundo modelo se conserva de este modelo | MODEL | Sí | - |
| `modelo2` | El segundo modelo que se va a fusionar. Sus pesos se mezclan según las proporciones indicadas a continuación | MODEL | Sí | - |
| `time_embed.` | Proporción de mezcla para la capa de embedding de tiempo (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |
| `label_emb.` | Proporción de mezcla para la capa de embedding de etiquetas (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |
| `input_blocks.0.` hasta `input_blocks.11.` | Proporción de mezcla para cada uno de los 12 bloques de entrada (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |
| `middle_block.0.` hasta `middle_block.2.` | Proporción de mezcla para cada uno de los 3 bloques centrales (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |
| `output_blocks.0.` hasta `output_blocks.11.` | Proporción de mezcla para cada uno de los 12 bloques de salida (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |
| `out.` | Proporción de mezcla para la capa de salida (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |

Una proporción de 0.0 mantiene ese componente tal como está en `model1`, una proporción de 1.0 lo toma por completo de `model2`, y los valores intermedios producen una mezcla ponderada. Ambas entradas deben ser modelos Stable Diffusion 2.x con la misma estructura de bloques.

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
| --- | --- | --- |
| `MODEL` | El modelo fusionado, que combina ambas entradas según las proporciones especificadas | MODEL |
