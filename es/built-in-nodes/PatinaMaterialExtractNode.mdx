Extrae un material PBR con mosaico continuo y sin costuras de una región de una imagen de entrada, guiado por un prompt que indica qué tomar: una pared, un suelo, una tela. Devuelve la textura base extraída más hasta cinco mapas de material, con un escalado opcional de los mapas mediante SeedVR. Úsalo para convertir la foto de una superficie real en un material reutilizable y repetible.

## Entradas

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `image` | La imagen de la que se extrae una textura. | IMAGE | Sí | - |
| `prompt` | Descripción de qué textura extraer de la imagen; por ejemplo, `"la pared"`. | STRING | Sí | Texto multilínea |
| `image_size` | Tamaño de la textura de salida. `"custom"` revela las entradas `width` y `height`. Predeterminado: `"1:1 (1024x1024)"`. | DYNAMIC_COMBO | Sí | `"1:1 (1024x1024)"`<br />`"1:1 (512x512)"`<br />`"4:3 (1024x768)"`<br />`"3:4 (768x1024)"`<br />`"16:9 (1024x576)"`<br />`"9:16 (576x1024)"`<br />`"custom"` |
| `basecolor` | Generar el mapa de color base (albedo). Predeterminado: True. | BOOLEAN | Sí | true<br />false |
| `normal` | Generar el mapa de normales. Predeterminado: True. | BOOLEAN | Sí | true<br />false |
| `roughness` | Generar el mapa de rugosidad. Predeterminado: False. | BOOLEAN | Sí | true<br />false |
| `metalness` | Generar el mapa de metalicidad. Predeterminado: False. | BOOLEAN | Sí | true<br />false |
| `height` | Generar el mapa de altura (desplazamiento). Predeterminado: False. | BOOLEAN | Sí | true<br />false |
| `upscale_factor` | Escalado SeedVR sin costuras de los mapas PBR. La textura base no se escala, y 4x convierte un mapa de 2048 píxeles en uno de 8K. Predeterminado: 0 (desactivado). | INT | Sí | 0 a 4 (paso 2) |
| `seed` | Semilla para una generación reproducible. Predeterminado: 42. | INT | Sí | 0 a 2147483646 |
| `strength` | Cuánto transformar la imagen de entrada. Ajuste avanzado. Predeterminado: 0.6. | FLOAT | Sí | 0.01 a 1.0 (paso 0.01) |
| `tiling_mode` | Dirección del mosaico: omnidireccional, horizontal o vertical. Ajuste avanzado. Predeterminado: `"both"`. | COMBO | Sí | `"both"`<br />`"horizontal"`<br />`"vertical"` |
| `num_inference_steps` | Pasos de eliminación de ruido para la generación de textura. Ajuste avanzado. Predeterminado: 8. | INT | Sí | 1 a 8 |
| `tile_size` | Tamaño de mosaico en el espacio latente, donde 64 significa 512 píxeles y 128 significa 1024 píxeles. Ajuste avanzado. Predeterminado: 128. | INT | Sí | 32 a 256 (paso 2) |
| `tile_stride` | Desplazamiento de mosaico en el espacio latente. Ajuste avanzado. Predeterminado: 64. | INT | Sí | 16 a 128 (paso 2) |

Desactivado de forma predeterminada, porque la expansión reformula el prompt como una fotografía y tiende a atenuar el mapa de metalicidad. Ajuste avanzado. | BOOLEAN | Sí | true<br />false |

### Entradas de tamaño de imagen personalizado

Estas entradas aparecen cuando `image_size` se establece en `"custom"`.

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `image_size.width` | Ancho de la textura en píxeles. Predeterminado: 1024. | INT | Sí | 512 a 2048 (paso 16) |
| `image_size.height` | Alto de la textura en píxeles. Predeterminado: 1024. | INT | Sí | 512 a 2048 (paso 16) |

**Restricciones y comportamiento:**

* Se debe habilitar al menos un mapa de material; de lo contrario, la ejecución falla.
* El prompt es obligatorio y no debe estar vacío; nombra la región que se va a extraer con la mayor precisión posible.
* Un resultado 8K proviene de escalar 4x los mapas de un render de 2048 píxeles, no de una única generación 8K.

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
|------------------|-------------|---------------|
| `texture` | La textura base extraída, sin ningún mapa aplicado. | IMAGE |
| `basecolor` | El mapa de color base (albedo), o un marcador de posición de 1x1 cuando ese mapa está deshabilitado. | IMAGE |
| `normal` | El mapa de normales, o un marcador de posición de 1x1 cuando ese mapa está deshabilitado. | IMAGE |
| `roughness` | El mapa de rugosidad, o un marcador de posición de 1x1 cuando ese mapa está deshabilitado. | IMAGE |
| `metalness` | El mapa de metalicidad, o un marcador de posición de 1x1 cuando ese mapa está deshabilitado. | IMAGE |
| `height` | El mapa de altura (desplazamiento), o un marcador de posición de 1x1 cuando ese mapa está deshabilitado. | IMAGE |
| `expanded_prompt` | El prompt que el proveedor utilizó realmente, que difiere de la entrada solo cuando `prompt_expansion` está habilitado. | STRING |
