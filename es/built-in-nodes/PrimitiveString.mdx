El nodo Text proporciona una forma sencilla de introducir y transmitir datos de texto en tu flujo de trabajo. Toma una cadena de texto como entrada y emite la misma cadena sin cambios, lo que resulta útil para proporcionar entradas de texto a otros nodos que requieren parámetros de tipo cadena.

## Entradas

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
| --- | --- | --- | --- | --- |
| `valor` | La cadena de texto que se transmitirá a través del nodo | STRING | Sí | Cualquier texto |

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
| --- | --- | --- |
| `output` | La misma cadena de texto que se proporcionó como entrada | STRING |
