Prepare el condicionamiento de SenseNova para la generación de imágenes o para la salida intercalada de texto e imagen. El selector `task` establece la plantilla del prompt y el comportamiento de parada, y el nodo informa si el modelo quiere una imagen, de modo que un bucle sepa cuándo ejecutar el sampler.

## Entradas

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `clip` | Modelo CLIP de SenseNova. Conecte el cargador CLIP que también alimenta a CLIP Text Encode; la salida del codificador va a `conditioning`. Obligatorio para todas las tareas excepto cuando el condicionamiento entrante ya está finalizado. | CLIP | No | - |
| `conditioning` | Condicionamiento de texto de SenseNova desde CLIP Text Encode. | CONDITIONING | Sí | - |
| `negative` | Condicionamiento negativo opcional. Se actualiza y se devuelve para las tareas `interleave` y `self-correction`. | CONDITIONING | No | - |
| `task` | Tarea que se va a ejecutar. `"image"` codifica el prompt para un sampler estándar, `"image thinking"` permite que el modelo piense antes de responder, `"interleave"` produce texto e imágenes en una sola pasada, y `"self-correction"` permite que el modelo corrija su propia salida anterior. | DYNAMIC_COMBO | Sí | `"image"`<br />`"image thinking"`<br />`"interleave"`<br />`"self-correction"` |
| `max_tokens` | Número máximo de tokens generados durante esta llamada. Predeterminado: 1024. | INT | Sí | 1 a 8192 |

### Entradas de `interleave`

Estas entradas aparecen cuando `task` se establece en `"interleave"`.

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `thinking` | Permite que el modelo piense antes de responder. Predeterminado: True. | BOOLEAN | Sí | True<br />False |
| `samples` | Salida anterior del sampler, que se conecta cuando se continúa después de una solicitud de imagen. | LATENT | No | - |

### Entradas de `self-correction`

Estas entradas aparecen cuando `task` se establece en `"self-correction"`.

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `samples` | Salida anterior del sampler, que se conecta cuando se continúa después de una solicitud de imagen. | LATENT | No | - |

**Restricciones y comportamiento:**

* La entrada `clip` recibe el modelo CLIP de SenseNova, no la salida de CLIP Text Encode (que es `CONDITIONING`). El nodo da error si `clip` falta (salvo que el condicionamiento entrante ya esté finalizado) o no es un CLIP de SenseNova.
* `"image thinking"` necesita exactamente una entrada de condicionamiento positiva; `"interleave"` y `"self-correction"` necesitan una entrada positiva y una negativa.
* Cuando el modelo esté esperando una imagen, conecte la salida LATENT del sampler anterior a `samples`. Pasar `samples` antes de que se solicite una imagen es un error.
* Cuando el condicionamiento entrante ya está finalizado, el nodo lo devuelve sin cambios con `generated_text` vacío y `image_requested` establecido en False.

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
|------------------|-------------|---------------|
| `conditioning` | Condicionamiento para el sampler, extendido con el texto generado por esta llamada. | CONDITIONING |
| `generated_text` | Texto generado por esta llamada. Use SenseNova Interleave Decode para obtener el resultado completo. | STRING |
| `negative` | Condicionamiento negativo actualizado para las tareas `interleave` y `self-correction`. | CONDITIONING |
| `image_requested` | True cuando el modelo solicitó una imagen: ejecute el sampler y luego realimente el bucle en este nodo. | BOOLEAN |
