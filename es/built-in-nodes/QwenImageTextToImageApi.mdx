Qwen Image 3 Text to Image genera una o más imágenes a partir de un prompt de texto utilizando los modelos Qwen-Image 3.0. Seleccionas un modelo y proporcionas un prompt, y el nodo devuelve las imágenes generadas como un lote.

## Entradas

### Entradas comunes

| Parámetro | Descripción | Tipo de datos | Requerido | Rango |
|-----------|-------------|---------------|-----------|-------|
| `model` | Modelo a utilizar (predeterminado: "qwen-image-3.0-pro"). Este selector compuesto también proporciona el prompt, el prompt negativo, el ancho y el alto de la imagen. | DYNAMIC_COMBO | Sí | "qwen-image-3.0-pro"<br />"qwen-image-3.0" |
| `n` | Número de imágenes a generar, devueltas como un lote (predeterminado: 1). | INT | No | 1 a 6 |
| `seed` | Semilla a utilizar para la generación (predeterminado: 42). Se puede configurar para que se actualice automáticamente después de cada generación. | INT | No | 0 a 2147483647 |
| `prompt_extend` | Si se debe mejorar el prompt con asistencia de IA (predeterminado: true). Opción avanzada. | BOOLEAN | No | true<br />false |
| `watermark` | Si se debe agregar una marca de agua generada por IA al resultado (predeterminado: false). Opción avanzada. | BOOLEAN | No | true<br />false |

### Entradas de qwen-image-3.0-pro and qwen-image-3.0

Compartidas por qwen-image-3.0-pro y qwen-image-3.0.

| Parámetro | Descripción | Tipo de datos | Requerido | Rango |
|-----------|-------------|---------------|-----------|-------|
| `prompt` | Prompt que describe la imagen. Admite inglés y chino. Debe contener al menos 1 carácter. | STRING | Sí | Texto libre |
| `negative_prompt` | Prompt negativo que describe lo que se debe evitar (predeterminado: ""). | STRING | No | Texto libre |
| `width` | El área total de píxeles debe estar entre 512x512 y 2560x2560; cualquier relación de aspecto dentro de esa área funciona. (predeterminado: 1024) | INT | No | 256 a 2560 (paso 16) |
| `height` | El área total de píxeles debe estar entre 512x512 y 2560x2560; cualquier relación de aspecto dentro de esa área funciona. (predeterminado: 1024) | INT | No | 256 a 2560 (paso 16) |

Nota: La entrada `model` es un selector compuesto con los subcampos `model` (ID del modelo), `prompt` (requerido, debe contener al menos 1 carácter), `negative_prompt` (opcional), `width` y `height`. El área combinada de píxeles de `width` y `height` debe estar entre 262,144 píxeles (512x512) y 6,553,600 píxeles (2560x2560), y la relación de aspecto debe mantenerse entre 1:8 y 8:1.

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
|------------------|-------------|---------------|
| `image` | La imagen o imágenes generadas, devueltas como un lote. | IMAGE |
