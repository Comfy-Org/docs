Convierte el historial de intercalado que deja SenseNova Conditioning en texto, imágenes y razonamiento utilizables. Ejecútalo al final del bucle, con la opción End Loop accumulate deshabilitada, para recopilar todo lo que el modelo produjo en una pasada.

## Entradas

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `clip` | Modelo CLIP de SenseNova utilizado para decodificar los tokens generados. | CLIP | Sí | - |
| `conditioning` | Acondicionamiento de intercalado de SenseNova Conditioning. | CONDITIONING | Sí | - |
| `samples` | Último latente de píxeles del KSampler, necesario cuando el bucle terminó en una solicitud de imagen. | LATENT | No | - |

**Restricciones y comportamiento:**

* El acondicionamiento debe provenir de SenseNova Conditioning en la tarea `interleave` o `self-correction`; cualquier otro valor genera un error.
* Cuando el modelo está esperando una imagen, conecta la salida LATENT del sampler a `samples`.
* Las imágenes de referencia conectadas al inicio de la ejecución se excluyen de la salida, y los consumidores de imágenes se omiten cuando no se generó ninguna imagen.

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
|------------------|-------------|---------------|
| `text` | Texto decodificado del historial de intercalado, con los marcadores de imagen reemplazados por líneas en blanco. | STRING |
| `images` | Las imágenes que el modelo generó durante la ejecución. | IMAGE |
| `thinking` | El texto de razonamiento del modelo, cuando lo produjo. | STRING |
