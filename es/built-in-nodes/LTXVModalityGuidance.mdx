Este nodo aplica guía transmodal (audio-video) a un modelo LTXV-AV. Durante el muestreo, ejecuta una pasada adicional por paso con las conexiones de atención cruzada de audio a video y de video a audio deshabilitadas, y luego empuja el resultado hacia la predicción acoplada para fortalecer la sincronización audiovisual, como la sincronización de labios. El valor predeterminado de referencia para `modality_scale` es 3.0; establecerlo en 1.0 deshabilita la pasada adicional, y se combina con la guía de CFG dual y el STG.

## Entradas

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|-----------|----------|-------|
| `modelo` | El modelo base al que se aplicará la guía de modalidad. Se clona internamente, dejando el modelo original sin cambios. | MODEL | Sí | - |
| `modality_scale` | Fuerza de la guía de acoplamiento audio-video. El valor predeterminado es 3.0. Establézcalo en 1.0 para deshabilitar la pasada adicional. | FLOAT | Sí | 1.0 a 100.0 (predeterminado: 3.0) |
| `porcentaje_inicio` | El punto del proceso de muestreo, como porcentaje de 0.0 a 1.0, en el que comienza la guía de modalidad. Este es un parámetro avanzado. El valor predeterminado es 0.0. | FLOAT | Sí | 0.0 a 1.0 (predeterminado: 0.0) |
| `porcentaje_fin` | El punto del proceso de muestreo, como porcentaje de 0.0 a 1.0, en el que termina la guía de modalidad. Este es un parámetro avanzado. El valor predeterminado es 1.0. | FLOAT | Sí | 0.0 a 1.0 (predeterminado: 1.0) |

La guía se aplica únicamente a los pasos de muestreo cuyos valores sigma se encuentren dentro del rango definido por `start_percent` y `end_percent`. Fuera de este rango, el nodo devuelve el resultado denoizado sin cambios. Un `modality_scale` de 1.0 también deshabilita por completo la pasada adicional.

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
|-------------|-------------|-----------|
| `model` | El modelo clonado con una función de guía posterior a CFG adjunta. Este modelo modificado aplica la guía de modalidad durante el muestreo. | MODEL |
