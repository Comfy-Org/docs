Este nodo genera música a partir de una descripción de texto y letras opcionales, o hace una versión de una canción que proporciones, con Pika. Elige `"text to music"` para escribir una canción nueva con la duración que establezcas, o `"cover"` para regrabar una canción y conservar su duración.

## Entradas

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `mode` | Qué hace el nodo: `"text to music"` escribe una canción nueva, `"cover"` regraba una canción proporcionada. Cada modo muestra sus propias entradas a continuación. Predeterminado: `"text to music"`. | DYNAMIC_COMBO | Sí | `"text to music"`<br />`"cover"` |

### Entradas de Text to Music

Estas entradas aparecen cuando `mode` se establece en `"text to music"`.

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `prompt` | Cómo debe sonar la música. No debe estar vacío. Predeterminado: "" (cadena vacía). | STRING | Sí | 1 a 4000 caracteres |
| `lyrics` | Letras opcionales. Se permiten etiquetas de sección como `[Verse]` y `[Chorus]`. Predeterminado: "" (cadena vacía). | STRING | Sí | 0 a 8000 caracteres |
| `duration` | Duración de la canción en segundos. Predeterminado: 30.0. | FLOAT | Sí | 10.0 a 360.0 (paso: 0.1) |
| `rewrite_prompt` | Expande un prompt breve o impreciso con un modelo antes de generar. Predeterminado: False. | BOOLEAN | Sí | true<br />false |
| `seed` | Semilla para el muestreo. Predeterminado: 42. | INT | Sí | 0 a 2147483647 |

### Entradas de Cover

Estas entradas aparecen cuando `mode` se establece en `"cover"`.

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `source_audio` | La canción que se va a versionar. El resultado tiene la misma duración, limitada al rango de 5 a 360 segundos. | AUDIO | Sí | - |
| `prompt` | Cómo debe sonar la versión. No debe estar vacío. Predeterminado: "" (cadena vacía). | STRING | Sí | 1 a 4000 caracteres |
| `lyrics` | Letras opcionales. Se permiten etiquetas de sección como `[Verse]` y `[Chorus]`. Predeterminado: "" (cadena vacía). | STRING | Sí | 0 a 8000 caracteres |
| `rewrite_prompt` | Expande un prompt breve o impreciso con un modelo antes de generar. Predeterminado: False. | BOOLEAN | Sí | true<br />false |
| `seed` | Semilla para el muestreo. Predeterminado: 42. | INT | Sí | 0 a 2147483647 |

**Restricciones:**

* El prompt debe tener entre 1 y 4000 caracteres, y las letras 8000 caracteres o menos.
* El modo cover ignora `duration`: la salida coincide con la duración de `source_audio`, limitada al rango de 5 a 360 segundos.

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
|------------------|-------------|---------------|
| `AUDIO` | La canción generada o la versión de la pista proporcionada. | AUDIO |
