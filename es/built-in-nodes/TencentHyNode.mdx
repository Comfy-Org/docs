Este nodo genera respuestas de texto con el modelo Hy4 de Tencent. Envía un mensaje de texto y, opcionalmente, una o más imágenes como contexto, y devuelve la respuesta del modelo como texto.

## Entradas

| Parámetro | Descripción | Tipo de dato | Obligatorio | Rango |
|-----------|-------------|--------------|-------------|-------|
| `model` | El modelo utilizado para generar la respuesta. Al seleccionarlo, se muestran sus entradas a continuación. Predeterminado: `"Hy4"`. | DYNAMIC_COMBO | Sí | `"Hy4"` |

### Entradas de Hy4

Estas entradas aparecen cuando `model` se establece en `"Hy4"`.

| Parámetro | Descripción | Tipo de dato | Obligatorio | Rango |
|-----------|-------------|--------------|-------------|-------|
| `prompt` | El mensaje que se enviará al modelo. No debe estar vacío. Predeterminado: "" (cadena vacía). | STRING | Sí | Al menos 1 carácter |
| `images` | Hasta 20 imágenes. Cada imagen de un lote cuenta. Predeterminado: sin imágenes. | AUTOGROW | No | 0 a 20 imágenes |
| `seed` | La semilla controla si el nodo debe volver a ejecutarse; los resultados no son deterministas independientemente de la semilla. Predeterminado: 42. | INT | Sí | 0 a 2147483647 |
| `system_prompt` | Instrucciones fundamentales que determinan el comportamiento del modelo. Predeterminado: "" (cadena vacía). | STRING | No | - |
| `reasoning` | El modelo razona antes de responder. Las respuestas tardan más y consumen más tokens, y las tareas muy difíciles pueden agotar el tiempo de espera. Predeterminado: False. | BOOLEAN | Sí | true<br />false |
| `temperature` | Controla la aleatoriedad. Los resultados siguen variando con 0. Predeterminado: 1.0. | FLOAT | Sí | 0.0 a 1.4 (paso: 0.01) |
| `max_tokens` | Número máximo de tokens a generar, incluidos los tokens de razonamiento cuando `reasoning` está activado. Las respuestas muy largas pueden agotar el tiempo de espera. Predeterminado: 32000. | INT | Sí | 1 a 64000 |

**Restricciones:**

* Se aceptan como máximo 20 imágenes por solicitud, contando cada imagen de un lote.
* El filtro de contenido de Tencent puede bloquear una solicitud, lo que provoca un error.
* Si `max_tokens` se agota antes de que termine la respuesta, el nodo genera un error: aumente `max_tokens` o desactive `reasoning`.

## Salidas

| Nombre de salida | Descripción | Tipo de dato |
|------------------|-------------|--------------|
| `STRING` | La respuesta de texto del modelo Hy4. | STRING |
