El nodo Generate Text utiliza un modelo CLIP para producir texto a partir de un prompt. A diferencia del nodo anterior de un solo adjunto, acepta pilas ampliables de imágenes, videos y archivos de audio como contexto adicional, de modo que se puede alimentar un conjunto completo de referencias en un solo nodo. Se controlan la longitud de salida, si se usa muestreo y si se aplican la plantilla de chat y el modo de pensamiento propios del modelo.

## Entradas

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
| --- | --- | --- | --- | --- |
| `clip` | El modelo CLIP usado para tokenizar el prompt y generar el texto. | CLIP | Sí | - |
| `prompt` | El prompt que guía la generación. Admite varias líneas y prompts dinámicos (predeterminado: cadena vacía). | STRING | Sí | - |
| `images` | Grupo ampliable de hasta 50 imágenes, `image1` a `image50`, usado como contexto visual para el modelo. | AUTOGROW | No | 0 a 50 imágenes |
| `videos` | Grupo ampliable de hasta 100 entradas de video, `video1` a `video100`. Cada video es un lote de fotogramas que se asume que están a 24 FPS y se submuestrean internamente a la velocidad de fotogramas del modelo. | AUTOGROW | No | 0 a 100 videos |
| `audios` | Grupo ampliable de hasta 100 entradas de audio, `audio1` a `audio100`, usado como contexto de audio para el modelo. | AUTOGROW | No | 0 a 100 archivos de audio |
| `max_length` | Número máximo de tokens a generar (predeterminado: 512). | INT | Sí | 1 a 32768 |
| `sampling_mode` | `on` muestrea la salida y muestra los parámetros de muestreo a continuación. `off` genera de forma codiciosa sin muestreo aleatorio. | DYNAMIC_COMBO | Sí | `"on"`<br />`"off"` |
| `thinking` | Operar en modo de pensamiento si el modelo lo admite (predeterminado: False). | BOOLEAN | No | True o False |
| `use_default_template` | Usar el mensaje de sistema o la plantilla de chat integrados si el modelo tiene uno (predeterminado: True). Parámetro avanzado. | BOOLEAN | No | True o False |
| `mtp` | Decodificación especulativa con la cabeza de predicción de múltiples tokens del checkpoint. No tiene efecto sin pesos MTP. `"auto"` adapta la profundidad y la amplitud del borrador a las coincidencias de tokens observadas y al costo de ejecución; `"2"` a `"5"` fijan una profundidad de borrador constante, y los modos `tree` fijan tanto la amplitud como la profundidad. La salida muestreada mantiene una distribución correcta, pero difiere de la salida sin MTP para la misma semilla (predeterminado: `"auto"`). | COMBO | No | `"auto"`<br />`"off"`<br />`"2"`<br />`"3"`<br />`"4"`<br />`"5"`<br />`"tree2s1"`<br />`"tree2s2"`<br />`"tree3s1"`<br />`"tree4s1m8"` |
| `system_prompt` | Reemplaza el mensaje de sistema en la plantilla de chat del modelo. Se ignora cuando no se usa la plantilla predeterminada. Conecte una entrada STRING en lugar de escribir en el nodo (predeterminado: vacío). | STRING | No | - |

### Parámetros de muestreo (cuando `sampling_mode` es `"on"`)

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
| --- | --- | --- | --- | --- |
| `temperature` | Controla la aleatoriedad de la salida. Los valores más bajos hacen que la salida sea más predecible; los valores más altos, más creativa (predeterminado: 0.7). | FLOAT | Sí | 0.01 a 2.0 |
| `top_k` | Limita el grupo de muestreo a los K tokens siguientes más probables. Un valor de 0 desactiva el filtro (predeterminado: 64). | INT | Sí | 0 a 1000 |
| `top_p` | Muestreo de núcleo: conserva el conjunto más pequeño de tokens más probables cuya probabilidad acumulada alcanza este valor (predeterminado: 0.95). | FLOAT | Sí | 0.0 a 1.0 |
| `min_p` | Probabilidad mínima que debe alcanzar un token para permanecer en el grupo (predeterminado: 0.05). | FLOAT | Sí | 0.0 a 1.0 |
| `repetition_penalty` | Penaliza los tokens que ya se han generado para reducir la repetición. Un valor de 1.0 no aplica penalización (predeterminado: 1.05). | FLOAT | Sí | 0.0 a 5.0 |
| `presence_penalty` | Penaliza los tokens nuevos según si han aparecido en el texto hasta el momento, lo que anima al modelo a pasar a temas nuevos (predeterminado: 0.0). | FLOAT | Sí | 0.0 a 5.0 |
| `seed` | Número usado para inicializar el generador de números aleatorios para obtener resultados reproducibles (predeterminado: 0). | INT | Sí | 0 a 18446744073709551615 |

**Nota:** Los parámetros de muestreo anteriores solo existen cuando `sampling_mode` es `"on"`. Con `"off"`, el nodo genera texto sin muestreo aleatorio y los parámetros se ocultan.

**Nota:** Cuando la salida del modelo abre un bloque de razonamiento con `<think>`, el nodo lo divide: `generated_text` contiene la respuesta y `thinking` contiene el razonamiento con la etiqueta de apertura eliminada. De lo contrario, `generated_text` contiene todo lo que produjo el modelo y `thinking` está vacío. El razonamiento que se truncó por `max_length` permanece en `generated_text`.

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
| --- | --- | --- |
| `generated_text` | El texto que generó el modelo, con cualquier bloque de razonamiento separado en la salida `thinking`. | STRING |
| `thinking` | El bloque de razonamiento que produjo el modelo, con la etiqueta de apertura `<think>` eliminada. Vacío cuando el modelo no produjo ningún bloque de razonamiento. | STRING |
