El nodo ModelMergeMOSSImage fusiona dos modelos de imagen MOSS mezclando sus pesos coincidentes bloque por bloque, de modo que una parte del resultado puede provenir de un modelo base y el resto de un ajuste fino o de un segundo modelo. Cada componente principal de la arquitectura tiene su propia proporción: el embedder de video, el embedder de texto, el embedding temporal, la modulación de bloque compartida, las 42 capas transformer y las cabeceras de salida.

## Entradas

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
| --- | --- | --- | --- | --- |
| `model1` | El primer modelo a fusionar. Todo lo que el segundo modelo no aporta se conserva de este modelo | MODEL | Sí | - |
| `model2` | El segundo modelo a fusionar. Sus pesos se mezclan de acuerdo con las proporciones siguientes | MODEL | Sí | - |
| `video_embedder.` | Proporción de mezcla para el bloque del embedder de video (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |
| `text_embedder.proj.` | Proporción de mezcla para la capa de proyección del embedder de texto (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |
| `text_embedder.blocks.0.` y `text_embedder.blocks.1.` | Proporción de mezcla para cada uno de los dos bloques del embedder de texto (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |
| `time_embedding.` | Proporción de mezcla para el bloque de embedding temporal (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |
| `shared_block_modulation.` | Proporción de mezcla para la capa de modulación compartida utilizada por los bloques transformer (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |
| `layers.0.` hasta `layers.41.` | Proporción de mezcla para cada una de las 42 capas transformer (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |
| `final_norm_video.` | Proporción de mezcla para la normalización final del flujo de video (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |
| `final_linear_video.` | Proporción de mezcla para la capa lineal final del flujo de video (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |
| `video_head_modulation.` | Proporción de mezcla para la capa de modulación de la cabecera de salida de video (predeterminado: 1.0) | FLOAT | Sí | 0.0 a 1.0 (paso: 0.01) |

Una proporción de 0.0 mantiene ese componente tal como está en `model1`, una proporción de 1.0 lo toma completamente de `model2`, y los valores intermedios producen una mezcla ponderada. Ambas entradas deben ser modelos de imagen MOSS con la misma arquitectura; los pesos que no coincidan con ninguno de los prefijos anteriores usan la proporción de `video_embedder.`.

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
| --- | --- | --- |
| `MODEL` | El modelo fusionado, que combina ambas entradas de acuerdo con las proporciones especificadas | MODEL |
