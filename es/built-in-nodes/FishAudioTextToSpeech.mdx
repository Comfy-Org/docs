Este nodo convierte texto escrito en audio hablado usando modelos de texto a voz de Fish Audio. Admite indicaciones integradas en el texto: [happy] y [whispering] en s2.1-pro, (happy) en s1, e indicaciones en lenguaje natural [directions] y etiquetas por palabra `<whisper>...</whisper>` en drama-3. El diálogo con múltiples hablantes usa etiquetas @Voice1/@Voice2 cuando hay varias voces conectadas. Hay tres modelos disponibles: drama-3 y s2.1-pro, que admiten hasta cinco voces y diálogo con múltiples hablantes, y s1, que usa una única voz opcional.

## Entradas

### Entradas comunes

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `texto` | El texto que se convertirá a voz. Con dos o más voces conectadas, marca los cambios de hablante con @Voice1, @Voice2, etc. (predeterminado: vacío) | STRING | Sí | Cualquier texto no vacío |
| `modelo` | Modelo que se usará para texto a voz. | DYNAMIC_COMBO | Sí | "drama-3"<br />"s2.1-pro"<br />"s1" |
| `semilla` | La semilla controla si el nodo debe volver a ejecutarse; los resultados no son deterministas independientemente de la semilla. (predeterminado: 42) | INT | Sí | 0 a 2147483647 |

### Entradas de drama-3 y s2.1-pro

Estas entradas aparecen cuando se selecciona el modelo `drama-3` o `s2.1-pro`. Los conjuntos de parámetros son idénticos.

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `voices` | Ranura ampliable: conecta de 0 a 5 elementos de voz (`voice_1`, `voice_2`, ...). Voces para la síntesis. Déjalo vacío para usar una voz aleatoria. Con dos o más voces, marca los cambios de hablante en el texto con @Voice1, @Voice2, etc. | FISHAUDIO_VOICE | No | 0 a 5 voces |
| `temperature` | Expresividad. Los valores más altos son más variados; los valores más bajos, más consistentes. (predeterminado: 0.7) | FLOAT | Sí | 0.0 a 1.0 |
| `top_p` | Diversidad mediante muestreo de núcleo. (predeterminado: 0.7) | FLOAT | Sí | 0.01 a 1.0 |
| `speed` | Velocidad del habla. 1.0 es normal, &lt;1.0 más lento, >1.0 más rápido. (predeterminado: 1.0) | FLOAT | Sí | 0.5 a 2.0 |
| `volume` | Ajuste de volumen en decibelios. 0 significa sin cambio. (predeterminado: 0.0) | FLOAT | Sí | -10.0 a 10.0 |
| `normalize` | Normaliza números y texto para inglés y chino, mejorando la estabilidad con números y fechas. (predeterminado: true) | BOOLEAN | Sí | true / false |

### Entradas de s1

Estas entradas aparecen cuando se selecciona el modelo s1.

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `voice` | Voz para la síntesis. Déjala sin conectar para usar una voz aleatoria. | FISHAUDIO_VOICE | No | Voz única opcional |
| `temperature` | Expresividad. Los valores más altos son más variados; los valores más bajos, más consistentes. (predeterminado: 0.7) | FLOAT | Sí | 0.0 a 1.0 |
| `top_p` | Diversidad mediante muestreo de núcleo. (predeterminado: 0.7) | FLOAT | Sí | 0.01 a 1.0 |
| `speed` | Velocidad del habla. 1.0 es normal, &lt;1.0 más lento, >1.0 más rápido. (predeterminado: 1.0) | FLOAT | Sí | 0.5 a 2.0 |
| `volume` | Ajuste de volumen en decibelios. 0 significa sin cambio. (predeterminado: 0.0) | FLOAT | Sí | -10.0 a 10.0 |
| `normalize` | Normaliza números y texto para inglés y chino, mejorando la estabilidad con números y fechas. (predeterminado: true) | BOOLEAN | Sí | true / false |

**Nota:** La entrada `text` no debe estar vacía. Las etiquetas de hablante (@Voice1, @Voice2, etc.) no distinguen entre mayúsculas y minúsculas y deben hacer referencia a una voz conectada; etiquetar una voz que no está conectada genera un error. Cuando hay dos o más voces conectadas, el texto debe hacer referencia a cada voz conectada al menos una vez, o el nodo informa las etiquetas faltantes. En drama-3 y s2.1-pro, conectar 0 voces usa una voz aleatoria, 1 voz usa esa voz sola, y 2 o más voces habilitan el diálogo con múltiples hablantes. En s1, se usa una única voz opcional y, si se deja sin conectar, se usa una voz aleatoria. Se pueden colocar indicaciones en el texto: [happy] y [whispering] en s2.1-pro, (happy) en s1, e indicaciones en lenguaje natural [directions] y etiquetas por palabra `<whisper>...</whisper>` en drama-3.
