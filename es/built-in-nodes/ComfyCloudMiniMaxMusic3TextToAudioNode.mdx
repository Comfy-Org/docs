Ejecuta el flujo de trabajo MiniMax Music 3 en una GPU de Comfy Cloud y devuelve una canción generada. El prompt contiene el estilo, la instrumentación y el estado de ánimo; la letra se canta en lugar de describirse, y una letra vacía deja la pista como instrumental. Este es un nodo beta y se factura por segundo de GPU.

## Entradas

| Parámetro | Descripción | Tipo de datos | Requerido | Rango |
|-----------|-------------|---------------|-----------|-------|
| `prompt` | Descripción de la canción: estilo, instrumentación y estado de ánimo. Se eliminan los espacios en blanco iniciales y finales antes del envío. | STRING | Sí | 1 a 4096 caracteres |
| `lyrics` | Palabras que se cantarán. Déjalo vacío para obtener una pista instrumental. | STRING | No | 0 a 4096 caracteres |
| `seed` | Semilla aleatoria que controla el resultado generado (predeterminado: 42). | INT | Sí | 0 a 9223372036854775807 |
| `max_duration` | Duración máxima que puede tener la pista, en segundos (predeterminado: 120.0). El modelo puede finalizar la canción antes. | FLOAT | Sí | 0.04 a 360.0 (paso 0.04) |
| `audio_quality` | Tasa de bits de salida. `"V0"` es variable y la de mayor calidad de las tres (predeterminado: `"V0"`). | COMBO | Sí | `"V0"`<br />`"128k"`<br />`"320k"` |

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
|------------------|-------------|---------------|
| `AUDIO` | La canción generada. | AUDIO |
