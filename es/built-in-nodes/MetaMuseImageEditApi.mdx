Edita o combina hasta 10 imágenes de referencia usando un prompt de texto y el modelo Muse Image de Meta. Describe la edición deseada en el prompt y, cuando sea necesario, haz referencia a las imágenes de referencia como `@Image1`, `@Image2`, etc. El nodo sube las imágenes de referencia, llama a la API de Meta Muse Image y devuelve el resultado editado como una imagen.

## Entradas

El nodo se controla mediante un selector `model`. Las entradas específicas del modelo descritas a continuación aparecen cuando se selecciona un modelo, y la cantidad de imágenes de referencia que conectes puede ampliarse o reducirse según sea necesario.

### Entradas comunes

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `model` | Modelo a usar. | DYNAMIC_COMBO | Sí | "muse-image-1.0" |

### Entradas de muse-image-1.0

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `prompt` | Instrucciones de edición. Admite referencias al estilo `@Image1` a las imágenes de entrada. Predeterminado: cadena vacía. El prompt debe contener al menos un carácter. | STRING | Sí | Cualquier texto con una longitud mínima de 1 carácter |
| `aspect_ratio` | Relación de aspecto de la salida. Las imágenes se renderizan a aproximadamente 2,5 megapíxeles (1:1 es 1600x1600, 16:9 es 2048x1152); "auto" mantiene la relación de aspecto de la entrada. | COMBO | Sí | "auto"<br />"1:1"<br />"3:2"<br />"2:3"<br />"4:3"<br />"3:4"<br />"5:4"<br />"4:5"<br />"16:9"<br />"9:16"<br />"21:9"<br />"9:21"<br />"2:1"<br />"1:2" |
| `reasoning_strength` | Grado en que el modelo piensa, planifica y se autorrefina antes de renderizar. | COMBO | Sí | "high"<br />"low" |
| `enable_web_search` | Permite que el modelo busque en la web datos e información en vivo mientras planifica la imagen. Predeterminado: true. | BOOLEAN | Sí | true o false (predeterminado: true) |
| `enable_image_search` | Permite que el modelo busque imágenes de referencia mientras planifica la imagen. Predeterminado: true. | BOOLEAN | Sí | true o false (predeterminado: true) |
| `enable_shell` | Permite que el modelo ejecute código mientras planifica, para diseños, gráficos y diagramas precisos; cuando está desactivado, las cantidades y la alineación se aproximan. Predeterminado: true. | BOOLEAN | Sí | true o false (predeterminado: true) |
| `seed` | Semilla para determinar si el nodo debe volver a ejecutarse; la API no tiene semilla, por lo que los resultados reales no son deterministas independientemente de este valor. Predeterminado: 42. | INT | Sí | 0 a 2147483647 (paso 1) |

### Entradas de referencia

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `images` | Ranura ampliable: conecta de 1 a 10 imágenes de referencia (`image_1` a `image_10`) para editarlas o combinarlas. Haz referencia a ellas en el prompt como `@Image1`, `@Image2`, ..., numeradas en el orden de entrada; una entrada en lote cuenta una vez por cada imagen. | IMAGE | Sí | 1 a 10 imágenes de referencia |

Nota: el prompt no puede estar vacío, y cada referencia `@ImageN` que contenga debe coincidir con una de las imágenes conectadas en el orden de entrada (por ejemplo, `@Image1` es la primera imagen de referencia conectada). Si el prompt hace referencia a un número de imagen que no está conectado, o si se conectan más de 10 imágenes de referencia, el nodo genera un error.

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
|------------------|-------------|---------------|
| `image` | La imagen editada o combinada devuelta por el modelo Muse Image. Si la API devuelve varias imágenes, se devuelven como un lote. | IMAGE |
