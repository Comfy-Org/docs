Genera o edita una imagen con Flux.1 Kontext [pro] a través de la API de BFL, basándose en un prompt y una relación de aspecto. Con `input_image` conectada, el prompt describe la edición; sin ella, el nodo genera una imagen nueva solo a partir del prompt.

## Entradas

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `prompt` | Prompt para la generación de la imagen. Con una imagen de entrada, especifica qué y cómo editar. | STRING | Sí | - |
| `relación_de_aspecto` | Relación de aspecto de la imagen; debe estar entre 1:4 y 4:1 (predeterminado: `"16:9"`). | STRING | Sí | - |
| `guía` | Intensidad de guía para el proceso de generación de la imagen (predeterminado: 3.0). | FLOAT | Sí | 0.1 a 99.0 (paso 0.1) |
| `pasos` | Número de pasos para el proceso de generación de la imagen (predeterminado: 50). | INT | Sí | 1 a 150 |
| `semilla` | La semilla aleatoria utilizada para crear el ruido (predeterminado: 1234). | INT | Sí | 0 a 18446744073709551615 |
| `mejora_de_prompt` | Indica si se debe realizar sobremuestreo en el prompt. Si está activo, el prompt se modifica automáticamente para una generación más creativa, pero los resultados no son deterministas, por lo que la misma semilla no producirá exactamente el mismo resultado (predeterminado: `False`). Esta es una configuración avanzada. | BOOLEAN | Sí | True / False |
| `imagen de entrada` | Imagen opcional para editar. Cuando se omite, se valida el prompt para asegurar que no esté vacío. | IMAGE | No | - |

**Nota:** El nodo envía la solicitud a BFL y consulta repetidamente hasta que la imagen esté lista. Las solicitudes rechazadas por la moderación de contenido de BFL fallan en lugar de devolver una imagen.

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
|------------------|-------------|---------------|
| `IMAGE` | La imagen generada o editada. | IMAGE |
