Este nodo genera un video a partir de una imagen del primer fotograma usando el modelo Wan 3.0. Opcionalmente, puedes proporcionar una imagen del último fotograma para controlar cómo termina el video; el modelo entonces crea un video que hace una transición desde el primer fotograma hasta el último.

## Entradas

### Entradas comunes

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `model` | Selecciona la variante del modelo Wan 3.0 que se usará y determina qué ajustes específicos del modelo se muestran a continuación. | DYNAMIC_COMBO | Sí | "wan3.0-video"<br />"wan3.0-video-prime" |
| `first_frame` | Imagen del primer fotograma. Se requiere exactamente una imagen. | IMAGE | Sí | Imagen única |
| `last_frame` | Imagen del último fotograma. El modelo genera un video con una transición desde el primer fotograma hasta el último. Opcional; si se proporciona, se requiere exactamente una imagen. | IMAGE | No | Imagen única |
| `seed` | Semilla que se usará para la generación (valor predeterminado: 42). | INT | Sí | 0 - 2147483647 |
| `watermark` | Indica si se debe agregar una marca de agua generada por IA al resultado (valor predeterminado: false). | BOOLEAN | Sí | true<br />false |

### Entradas de wan3.0-video y wan3.0-video-prime

Estos ajustes específicos del modelo son compartidos por ambas opciones de modelo y aparecen cuando se selecciona un modelo.

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `prompt` | Prompt que describe los elementos y las características visuales. Admite inglés y chino. Puede dejarse vacío (valor predeterminado: vacío). | STRING | Sí | Hasta 20000 caracteres |
| `resolution` | Resolución del video de salida. | COMBO | Sí | "1080P"<br />"720P"<br />"480P" |
| `ratio` | Relación de aspecto del video de salida. Con "adaptive", las dimensiones de salida se derivan del primer fotograma. | COMBO | Sí | "adaptive"<br />"16:9"<br />"9:16"<br />"1:1"<br />"4:3"<br />"3:4" |
| `duration` | Duración de salida en segundos. Con "auto", el modelo elige una duración que se ajuste al prompt. | COMBO | Sí | "auto"<br />"2" - "30" |
| `audio` | Indica si el video de salida contiene una pista de audio (valor predeterminado: true). | BOOLEAN | Sí | true<br />false |
| `prompt_extend` | Indica si se debe mejorar el prompt con asistencia de IA (valor predeterminado: true). | BOOLEAN | Sí | true<br />false |

Nota: El nodo acepta exactamente una imagen de `first_frame` y, opcionalmente, una imagen de `last_frame`. Si se conecta más de una imagen a cualquiera de las entradas, se genera un error. Cuando se proporciona `last_frame`, el video generado hace una transición desde el primer fotograma hasta el último. El `prompt` está limitado a 20.000 caracteres. El precio de una ejecución depende del `model`, la `resolution` y la `duration` seleccionados.

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
|------------------|-------------|---------------|
| `video` | El video generado. Contiene una pista de audio cuando la opción `audio` está habilitada. | VIDEO |
