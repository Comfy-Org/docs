Tripo: Smart UV vuelve a desenvolver las UV de un modelo y reasigna sus texturas, rig y animación a la nueva distribución. Úsalo cuando la distribución UV original de un modelo no sea utilizable, por ejemplo, después de una retopología o cuando sea necesario rehacer las costuras de textura. El modelo de entrada no debe superar los 80.000 triángulos (un quad cuenta como dos), así que reduce primero los modelos más grandes con Tripo: Retopology o un `face_limit`.

> **Nota:** Tripo conserva los registros de tareas en sus servidores durante 7 días (vigente a partir del 1 de diciembre de 2026). Un ID de tarea más antiguo que ese ya no se puede resolver, por lo que volver a ejecutar un flujo de trabajo guardado después de ese plazo falla en este nodo. Vuelve a ejecutar el nodo Tripo anterior para crear un ID de tarea nuevo, o vuelve a importar el modelo descargado con **Tripo: Import Model**.

## Entradas

| Parámetro | Descripción | Tipo de datos | Obligatorio | Rango |
|-----------|-------------|---------------|-------------|-------|
| `model_task_id` | ID de tarea del modelo que se va a volver a desenvolver. Acepta un ID de tarea de modelo de un nodo de generación de Tripo, o un ID de tarea de rig, retarget o segmentación. | MODEL_TASK_ID | Sí | ID de tarea de Tripo |
| `bake` | Aplica horneado a las texturas existentes sobre la nueva distribución UV. Desactivado omite el horneado y devuelve el modelo sin sus texturas de color (predeterminado: True). | BOOLEAN | Sí | `True`<br />`False` |

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
|------------------|-------------|---------------|
| `model task_id` | ID de tarea de la tarea UV finalizada. Se puede pasar a otros nodos de Tripo, por ejemplo, Tripo: Texture. | MODEL_TASK_ID |
| `GLB` | El modelo con las UV desenvueltas de nuevo en formato GLB. Vacío cuando el modelo de origen es FBX. | GLB FILE |
| `FBX` | El modelo con las UV desenvueltas de nuevo en formato FBX. Solo se completa cuando el modelo de origen es FBX, por ejemplo, una malla de cuadriláteros. | FBX FILE |
| `UV atlas` | La distribución UV renderizada del modelo como una imagen. | IMAGE |
