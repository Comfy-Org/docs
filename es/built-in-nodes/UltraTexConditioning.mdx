Condiciona FLUX.2 Klein 9B con el LoRA UltraTex para pintar el aspecto de una imagen de referencia sobre una malla, como una imagen por vista. Renderiza las vistas con Render Mesh en modo `world normal`, desde un Create Camera Orbit de 4 más las vistas superior e inferior, y hornea el resultado con Bake Texture From Views.

## Entradas

| Parámetro | Descripción | Tipo de datos | Requerido | Rango |
| --- | --- | --- | --- | --- |
| `conditioning` | Condicionamiento de texto. UltraTex se entrenó con un prompt vacío. | CONDITIONING | Sí | - |
| `vae` | VAE usado para codificar las normales, las vistas y la referencia. | VAE | Sí | - |
| `normals` | Imágenes `world normal` de Render Mesh: las 6 vistas canónicas o las 4 vistas laterales. | IMAGE | Sí | - |
| `masks` | Máscaras de Render Mesh de las mismas vistas, una por vista. | MASK | Sí | - |
| `reference` | El objeto tal como debería verse, visto desde el lado de la cámara frontal. | IMAGE | Sí | - |
| `reference_mask` | Máscara del objeto de la referencia; blanca para el objeto. Predeterminado: completamente blanca. | MASK | No | - |
| `extra_views` | Más referencias: el objeto visto desde las otras vistas, cada una vinculada a su vista como la referencia está vinculada al frente. Predeterminado: `"off"`. | DYNAMIC_COMBO | Sí | `"off"`<br />`"on"` |

### Entradas de vistas adicionales con "on"

| Parámetro | Descripción | Tipo de datos | Requerido | Rango |
| --- | --- | --- | --- | --- |
| `right` | El objeto visto desde la vista derecha. | IMAGE | No | - |
| `back` | El objeto visto desde la vista trasera. | IMAGE | No | - |
| `left` | El objeto visto desde la vista izquierda. | IMAGE | No | - |
| `top` | El objeto visto desde la vista superior. | IMAGE | No | - |
| `bottom` | El objeto visto desde la vista inferior. | IMAGE | No | - |

## Salidas

| Nombre de salida | Descripción | Tipo de datos |
| --- | --- | --- |
| `conditioning` | Condicionamiento que transporta la cuadrícula de vistas, los latentes de referencia y las máscaras de tokens que necesita UltraTex. | CONDITIONING |

Nota: `normals` debe contener las 6 vistas canónicas (Create Camera Orbit con `count` 4 y `poles` superior e inferior) o las 4 vistas laterales, y `masks` debe coincidir con su número de vistas.
