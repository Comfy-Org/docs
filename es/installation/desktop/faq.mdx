## Preguntas generales

<Accordion title="¿Cuál es la diferencia entre Comfy Desktop y Legacy Desktop?">
Comfy Desktop es una reescritura completa que funciona como un **administrador de múltiples instalaciones**. A diferencia de Legacy Desktop, que era una aplicación de instalación única, Comfy Desktop te permite instalar, administrar y ejecutar varias versiones de ComfyUI en paralelo. También agrega instantáneas y gestión de descargas de modelos.

Si usas Legacy Desktop, consulta la [Guía de migración](/es/installation/desktop/usage/migrate) para transferir tu configuración existente.
</Accordion>
<Accordion title="¿Comfy Desktop es de código abierto?">
Sí. El código fuente está en [GitHub](https://github.com/Comfy-Org/Comfy-Desktop). Comfy Desktop tiene doble licencia: [AGPL-3.0-or-later](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/LICENSE), o una licencia comercial de Comfy Org (`licensing@comfy.org`).
</Accordion>
<Accordion title="¿Comfy Desktop reemplaza la instalación Portable/Manual?">
Comfy Desktop es una de varias opciones de instalación. Aún puedes usar la instalación **Portable (Windows)**, la **Instalación manual** o **Comfy Cloud** según tus necesidades. Desktop es la opción RECOMENDADO para la mayoría de los usuarios por su facilidad de uso y funciones como las actualizaciones con un solo clic y la gestión de instantáneas.
</Accordion>
<Accordion title="¿Puedo desactivar las comprobaciones de actualizaciones?">
No. Comfy Desktop comprueba si hay una nueva versión poco después de iniciarse y luego cada 10 minutos, y esa comprobación no se puede desactivar. La única configuración de actualización es **Instalar automáticamente las actualizaciones de Desktop** en **Configuraciones de Escritorio → Actualizaciones**, y está activada de forma predeterminada.

- **Activada**: una nueva versión se descarga en segundo plano y se instala sin preguntar. La barra de título muestra **Descargando actualización…** mientras se descarga, y luego **Actualización de Desktop lista** cuando la actualización está lista para aplicarse.
- **Desactivada**: Comfy Desktop sigue comprobando y te avisa, pero deja de descargar por su cuenta. En su lugar, la barra de título muestra un indicador **Actualización de Desktop**, y al hacer clic en él se descarga la actualización y se ofrece reiniciar.

La versión de ComfyUI dentro de una instancia se actualiza por separado. Usa la pestaña **Actualizar** de la instancia y elige allí el canal **Estable** o **Última en GitHub**.

En Linux, el actualizador integrado no se aplica a las instalaciones con `.deb`. Descarga el nuevo paquete con el [enlace de descarga universal](https://dl.todesktop.com/241130tqe9q3y) e instálalo con `sudo apt install ./*.deb`.
</Accordion>

## Instalación y configuración

<Accordion title="¿Cuáles son los requisitos del sistema?">
Consulta los [requisitos del sistema](/es/installation/system_requirements) para ver todos los detalles.

- **Windows:** Windows 10+, x64 o ARM64. Se recomienda una GPU dedicada (NVIDIA / AMD), pero no es obligatoria.
- **macOS:** macOS 13+ (Ventura), Apple Silicon (M1+)
- **Linux:** Los paquetes oficiales `.deb` y AppImage se distribuyen a través del [repositorio de Comfy Desktop](https://github.com/Comfy-Org/Comfy-Desktop). Se recomienda una GPU dedicada.
- **Disco:** al menos 4.85 GB por instalación independiente
- **RAM:** 8 GB como mínimo, 16 GB recomendados
</Accordion>
<Accordion title="¿Puedo instalar Comfy Desktop sin permisos de administrador?">
En **Windows**, la instalación independiente no requiere permisos de administrador. En **macOS**, necesitarás permisos de administrador para la instalación inicial en todo el sistema. En **Linux**, instalar el paquete `.deb` requiere `sudo`; el AppImage se ejecuta en el espacio del usuario sin permisos de administrador.
</Accordion>
<Accordion title="¿Cómo descargo Comfy Desktop?">
Descarga la última versión para Windows o macOS desde la [página oficial de descarga de ComfyUI](https://comfy.org/download). En Linux, descarga el `.deb` o el AppImage con el [enlace de descarga universal](https://dl.todesktop.com/241130tqe9q3y) del [repositorio de Comfy Desktop](https://github.com/Comfy-Org/Comfy-Desktop). Si prefieres ejecutarlo desde la fuente, consulta la [guía de instalación en Linux](/es/installation/desktop/linux).
</Accordion>
<Accordion title="¿Puedo tener instalados tanto Legacy Desktop como Comfy Desktop?">
Sí, pueden coexistir. Sin embargo, recomendamos migrar tus instalaciones al nuevo Comfy Desktop y, con el tiempo, desinstalar Legacy Desktop. Consulta la [guía de migración](/es/installation/desktop/usage/migrate).
</Accordion>

## Uso

<Accordion title="¿Cómo agrego una nueva instalación de ComfyUI?">
En el Panel, haz clic en **Nueva Instancia** para crear una instancia independiente, o abre **Nueva Instancia** y elige **Agregar Instancia Existente** para rastrear un clon de git o una instalación portable de Windows. Usa la tarjeta **Comfy Cloud** para conectarte a Cloud.

- **Independiente**: instalación nueva con Python incluido
- **Agregar Instancia Existente**: rastrea un clon de git o una instalación portable
- **Cloud**: conéctate a Comfy Cloud
</Accordion>
<Accordion title="¿Puedo ejecutar varias versiones de ComfyUI al mismo tiempo?">
¡Sí! Comfy Desktop está diseñado para eso. Cada instalación se ejecuta en su propio entorno aislado con su propio Python y sus propias dependencias. Puedes iniciarlas simultáneamente en ventanas separadas.
</Accordion>
<Accordion title="¿Dónde se guardan mis modelos, nodos personalizados y configuraciones?">
Los modelos se comparten entre instancias de forma predeterminada. Configura las carpetas compartidas en [Configuraciones de Escritorio → Almacenamiento](/es/installation/desktop/usage/settings#almacenamiento).

- **Independiente:** la instalación en sí vive en su carpeta de instalación. Los nodos personalizados y el entorno de Python son por instalación. Los modelos normalmente provienen de los directorios de modelos compartidos.
- **Clon de git / portable (rastreado):** los datos permanecen en esa carpeta existente (`models/`, `custom_nodes/`, `user/`). Aún puedes optar por modelos, entradas y salidas compartidos.
</Accordion>
<Accordion title="¿Cómo funcionan las instantáneas?">
Comfy Desktop crea instantáneas automáticamente en eventos clave: en cada arranque y reinicio, antes y después de una actualización, y después de una restauración. Una instantánea registra la versión de ComfyUI de la instancia, los nodos personalizados con sus versiones y todos los paquetes pip del entorno. Los archivos de modelos, las entradas y las salidas no forman parte de una instantánea.

Puedes explorar, restaurar, exportar y compartir instantáneas desde la pestaña **Snapshots** de la instancia. Consulta [Instantáneas](/es/installation/desktop/usage/snapshots).
</Accordion>
### Cómo detener/salir de Comfy Desktop

Para detener una instancia de ComfyUI en ejecución (detener el backend de Python manteniendo la aplicación abierta):

1. Haz clic en el **menú ⋮ (kebab)** de la tarjeta de la instancia
2. Selecciona **Detener**
3. Confirma en el diálogo

Esto detiene el proceso de Python de ComfyUI pero deja abierta la ventana de la aplicación de escritorio para que puedas relanzarla en cualquier momento. Para salir completamente de la aplicación de escritorio, abre el **menú ☰** en la esquina superior izquierda y selecciona **Salir de Desktop** (o usa el comando de salida equivalente del sistema operativo). Al cerrar la última ventana vuelves al Panel, a menos que salgas de la aplicación.

## Solución de problemas

<Accordion title="La aplicación no inicia después de la instalación">
1. **Windows:** intenta ejecutarla como administrador una vez
2. **macOS:** si ves una advertencia de seguridad, ve a **Configuración del Sistema → Privacidad y seguridad** y haz clic en **Abrir de todos modos**
3. **Linux:** asegúrate de que FUSE 2 esté instalado (`sudo apt install libfuse2`)
4. Revisa la [página de Descargas](https://comfy.org/download) para obtener la última versión
</Accordion>
<Accordion title="Comfy Desktop se cierra solo después de una actualización (Windows)">
En Windows, Comfy Desktop 1.0.46 y versiones anteriores pueden quedarse bloqueados si una descarga de actualización no terminó. La aplicación muestra brevemente una pantalla de actualización y luego se cierra sin mostrar un error. Esto se repite en cada inicio, y la aplicación se cierra antes de poder descargar la corrección. La versión 1.0.47 y posteriores corrigen este problema.

Para recuperarte, instala la última versión manualmente:

1. Descarga el [último instalador para Windows](https://dl.todesktop.com/241130tqe9q3y/windows), o consíguelo desde la [página de Descargas](https://comfy.org/download).
2. Ejecuta el instalador. No necesitas desinstalar la versión anterior primero.
3. Inicia Comfy Desktop.

Tus instalaciones, modelos y configuraciones se conservan.
</Accordion>
<Accordion title="Mi GPU no se detecta">
- Asegúrate de que tus controladores NVIDIA estén actualizados
- En Linux, verifica que el kit de herramientas CUDA esté instalado
- Comprueba que el tipo de instalación admita GPU (Standalone y Git Clone sí lo hacen; las conexiones Cloud usan una GPU remota)
</Accordion>
<Accordion title="Una instalación no se actualiza">
- Revisa tu conexión a internet
- Crea una instantánea manual desde la pestaña **Snapshots** de la instancia antes de intentar de nuevo
- Si el problema persiste, restaura una instantánea anterior e intenta de nuevo
</Accordion>
<Accordion title="Veo Low Disk Space o Not Enough Space for Template Models">
Durante **New Instance**, Comfy Desktop verifica el espacio libre en la unidad de instalación. **Low Disk Space** es una advertencia: selecciona **Continue Anyway** para continuar, o elige otra ruta. **Not Enough Space for Template Models** bloquea esa plantilla; elige un flujo de trabajo más ligero o libera espacio. Los discos muy pequeños pueden omitir el paso de la plantilla. Consulta [Crear una nueva instancia](/es/installation/desktop/usage/instance-management#crear-una-nueva-instancia).
</Accordion>
<Accordion title="¿Cómo reviso los registros de inicio de Comfy Desktop?">
La aplicación de Escritorio escribe un archivo `app.log` rotativo. La forma más rápida de encontrarlo es **Configuraciones de Escritorio → Registros → Diagnóstico → Abrir carpeta de registros** (menú ☰ en la esquina superior izquierda).

Carpetas de registros predeterminadas:

- **Windows:** `%APPDATA%\Comfy Desktop\logs`
- **macOS:** `~/Library/Logs/Comfy Desktop`
- **Linux:** `~/.config/Comfy Desktop/logs`

Busca `app.log`. Las sesiones anteriores rotan a archivos `app.log_*.log` con marca de tiempo.

Para ver la salida del proceso de ComfyUI (no la de la aplicación de Escritorio en sí), abre el panel **Administrar** de la instancia y usa la pestaña **Terminal**. Consulta [Administrar](/es/installation/desktop/usage/manage).
</Accordion>
<Accordion title="¿Puedo usar Ollama con ComfyUI?">
ComfyUI no se integra de forma nativa con [Ollama](https://ollama.ai) para backends de modelos de difusión. Sin embargo, puedes usar LLMs servidos por Ollama para la generación de prompts y el procesamiento de texto mediante **nodos personalizados** disponibles en el registro de ComfyUI Manager.

Para conectar ComfyUI con servicios de LLM, consulta [Instalar nodos personalizados](/es/installation/install_custom_node).
</Accordion>
<Accordion title="¿Cómo desinstalo Comfy Desktop?">
Comfy Desktop y sus instalaciones están separados en el disco. Para desinstalar la aplicación y sus instalaciones:

1. **Elimina las instalaciones** desde dentro de la aplicación (clic derecho → Eliminar) o borra las carpetas de instalación manualmente
2. **Desinstala la aplicación** usando el método estándar de tu sistema (Agregar o quitar programas en Windows, arrastrar a la Papelera en macOS, el gestor de paquetes en Linux)

Eso no elimina las configuraciones de la aplicación, los registros, los modelos compartidos ni las salidas. Para las carpetas que quedan y una limpieza completa, consulta [Windows](/es/installation/desktop/windows#lo-que-la-desinstalación-de-la-aplicación-no-elimina), [macOS](/es/installation/desktop/macos#lo-que-la-desinstalación-de-la-app-no-elimina) o [Linux](/es/installation/desktop/linux#eliminar-datos-residuales).
</Accordion>
<Accordion title="¿Puedo ejecutar Comfy Desktop en modo headless o de servidor?">
No. Comfy Desktop está diseñado como una aplicación GUI local y no admite modos de operación headless, solo servidor ni remotos. Requiere un entorno de escritorio gráfico para iniciar y administrar instancias de ComfyUI.

Para despliegues headless o de servidor, usa una **instalación manual de ComfyUI** o la compilación **Windows Portable** en su lugar.
</Accordion>
