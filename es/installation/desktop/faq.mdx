## Preguntas generales

<Accordion title="¿Cuál es la diferencia entre Comfy Desktop y Legacy Desktop?">
Comfy Desktop es una reescritura completa que funciona como un **administrador de múltiples instalaciones**. A diferencia de Legacy Desktop, que era una aplicación de instalación única, Comfy Desktop te permite instalar, administrar y ejecutar varias versiones de ComfyUI en paralelo. También agrega instantáneas y gestión de descargas de modelos.

Si usas Legacy Desktop, consulta la [Guía de migración](/es/installation/desktop/usage/migrate) para transferir tu configuración existente.
</Accordion>
<Accordion title="¿Comfy Desktop es de código abierto?">
Sí. El código fuente está en [GitHub](https://github.com/Comfy-Org/Comfy-Desktop). Comfy Desktop tiene doble licencia: [AGPL-3.0-or-later](https://github.com/Comfy-Org/Comfy-Desktop/blob/main/LICENSE), o una licencia comercial de Comfy Org (`licensing@comfy.org`).
</Accordion>
<Accordion title="¿Comfy Desktop reemplaza la instalación Portable/Manual?">
Comfy Desktop es una de varias opciones de instalación. Aún puedes usar la instalación **Portable (Windows)**, la **Manual Install** o **Comfy Cloud** según tus necesidades. Desktop es la opción recomendada para la mayoría de los usuarios por su facilidad de uso y por funciones como las actualizaciones con un clic y la gestión de instantáneas.
</Accordion>
<Accordion title="¿Puedo desactivar las comprobaciones de actualizaciones?">
No. Comfy Desktop comprueba si hay una nueva versión poco después de iniciarse y luego cada 10 minutos, y esa comprobación no se puede desactivar. La única configuración de actualización es **Instalar automáticamente las actualizaciones de Desktop** en **Configuraciones de Escritorio → Actualizaciones**, y está activada de forma predeterminada.

- **Activada**: una nueva versión se descarga en segundo plano y se instala sin preguntar. La barra de título muestra **Downloading update…** mientras se descarga, y luego **Desktop Update Ready** cuando la actualización está lista para aplicarse.
- **Desactivada**: la barra de título muestra **Desktop Update** y la tarjeta Updates muestra **Update … available**. La actualización se sigue descargando en segundo plano, pero nada se instala por sí solo: no se aplica al salir ni en el siguiente inicio. Cuando esté lista, haz clic en la píldora **Desktop Update Ready** y elige **Restart & Update**.

La versión de ComfyUI dentro de una compilación se actualiza por separado. Usa la pestaña **Overview** de la compilación y elige allí el canal **Stable** o **Latest on GitHub**.

En Linux, el actualizador integrado no se aplica a las instalaciones con `.deb`. Descarga el nuevo paquete con el [enlace de descarga universal](https://dl.todesktop.com/241130tqe9q3y) e instálalo con `sudo apt install ./*.deb`.
</Accordion>

## Instalación y configuración

<Accordion title="¿Cuáles son los requisitos del sistema?">
Consulta los [requisitos del sistema](/es/installation/system_requirements) para ver todos los detalles.

- **Windows:** Windows 10+, x64 o ARM64. Se recomienda una GPU dedicada (NVIDIA / AMD), pero no es obligatoria.
- **macOS:** macOS 13+ (Ventura), Apple Silicon (M1+)
- **Linux:** Los paquetes oficiales `.deb` y AppImage se distribuyen a través del [repositorio de Comfy Desktop](https://github.com/Comfy-Org/Comfy-Desktop). Se recomienda una GPU dedicada.
- **Disco:** al menos 4.85 GB por instalación independiente
- **RAM:** 8 GB como mínimo, 16 GB recomendados
</Accordion>
<Accordion title="¿Puedo instalar Comfy Desktop sin permisos de administrador?">
En **Windows**, la instalación independiente no requiere permisos de administrador. En **macOS**, necesitarás permisos de administrador para la instalación inicial en todo el sistema. En **Linux**, instalar el paquete `.deb` requiere `sudo`; el AppImage se ejecuta en el espacio del usuario sin permisos de administrador.
</Accordion>
<Accordion title="¿Cómo descargo Comfy Desktop?">
Descarga la última versión para Windows o macOS desde la [página oficial de descarga de ComfyUI](https://comfy.org/download). En Linux, descarga el `.deb` o el AppImage con el [enlace de descarga universal](https://dl.todesktop.com/241130tqe9q3y) del [repositorio de Comfy Desktop](https://github.com/Comfy-Org/Comfy-Desktop). Si prefieres ejecutarlo desde la fuente, consulta la [guía de instalación en Linux](/es/installation/desktop/overview#instalar-comfy-desktop-para-tu-sistema-operativo).
</Accordion>
<Accordion title="¿Puedo tener instalados tanto Legacy Desktop como Comfy Desktop?">
Sí, pueden coexistir. Sin embargo, recomendamos migrar tus instalaciones al nuevo Comfy Desktop y, con el tiempo, desinstalar Legacy Desktop. Consulta la [guía de migración](/es/installation/desktop/usage/migrate).
</Accordion>

## Uso

<Accordion title="¿Cómo agrego una nueva instalación de ComfyUI?">
Abre la página **Builds** y haz clic en **New build** para instalar una versión nueva en esta computadora. Para agregar una que ya tienes, haz clic en la flecha junto a **New build** (**More build options**) y selecciona **Add existing build**. Para ejecutar ComfyUI en Comfy Cloud en su lugar, abre la instalación de **Comfy Cloud**.

- **New build**: una instalación nueva que Comfy Desktop configura por ti.
- **Add existing build**: rastrea un ComfyUI que ya instalaste, como un clon de git o una instalación portable.
- **Comfy Cloud**: ejecuta ComfyUI en GPUs en la nube, sin instalar nada en esta computadora.

Consulta [Builds](/es/installation/desktop/usage/instance-management) para ver todas las opciones.
</Accordion>
<Accordion title="¿Puedo ejecutar varias versiones de ComfyUI al mismo tiempo?">
¡Sí! Comfy Desktop está diseñado para eso. Cada instalación se ejecuta en su propio entorno aislado con su propio Python y sus propias dependencias. Puedes iniciarlas al mismo tiempo en ventanas separadas.
</Accordion>
<Accordion title="¿Dónde se guardan mis modelos, nodos personalizados y configuraciones?">
Los modelos se comparten entre instalaciones de forma predeterminada. Configura las carpetas compartidas en [Configuraciones de Escritorio → Carpetas](/es/installation/desktop/usage/settings#storage).

- **Standalone:** la instalación en sí vive en su carpeta de instalación. Los nodos personalizados y el entorno de Python son propios de cada instalación. Los modelos normalmente provienen de las carpetas de modelos compartidas.
- **Git clone / portable (tracked):** los datos permanecen en esa carpeta existente (`models/`, `custom_nodes/`, `user/`). Aún puedes optar por usar modelos, entradas y salidas compartidos.
</Accordion>
<Accordion title="¿Cómo funcionan las instantáneas?">
Comfy Desktop crea instantáneas automáticamente en eventos clave: en cada arranque y reinicio, antes y después de una actualización, y después de una restauración. Una instantánea registra la versión de ComfyUI de la instalación, los nodos personalizados con sus versiones y todos los paquetes pip del entorno. Los archivos de modelos, las entradas y las salidas no forman parte de una instantánea.

Puedes explorar, restaurar, exportar y compartir instantáneas desde la pestaña **Snapshots** de la instalación. Consulta [Guardar y restaurar instantáneas](/es/installation/desktop/usage/instance-management#guardar-y-restaurar-instantáneas).
</Accordion>

### Cómo detener y salir de Comfy Desktop

Para detener una instalación de ComfyUI en ejecución y mantener Comfy Desktop abierto:

1. Abre la página de la instalación desde la **barra lateral** o desde la página **Builds**.
2. Haz clic en **Stop**.
3. Confirma en el diálogo.

Para salir de Comfy Desktop, abre el **Menú** de la **barra de título** y selecciona **Quit Desktop**, o cierra la última ventana. Al cerrar la última ventana se cierra Comfy Desktop; no existe un modo de bandeja que lo mantenga en ejecución en segundo plano. Una ventana que ejecuta ComfyUI también tiene **Close window** en su **Menú**, que cierra esa ventana y detiene la instalación que se ejecuta en ella.

## Solución de problemas

<Accordion title="La aplicación no inicia después de la instalación">
1. **Windows:** intenta ejecutarla como administrador una vez
2. **macOS:** si ves una advertencia de seguridad, ve a **Configuración del Sistema → Privacidad y seguridad** y haz clic en **Abrir de todos modos**
3. **Linux:** instala FUSE 2: `libfuse2t64` en Ubuntu 24.04 y posteriores, `libfuse2` en 22.04
4. Revisa la [página de Descargas](https://comfy.org/download) para obtener la última versión
</Accordion>
<Accordion title="Comfy Desktop se cierra solo después de una actualización (Windows)">
En Windows, Comfy Desktop 1.0.46 y versiones anteriores pueden quedarse bloqueados si una descarga de actualización no terminó. La aplicación muestra brevemente una pantalla de actualización y luego se cierra sin mostrar un error. Esto se repite en cada inicio, y la aplicación se cierra antes de poder descargar la corrección. La versión 1.0.47 y posteriores corrigen este problema.

Para recuperarte, instala la última versión manualmente:

1. Descarga el [último instalador para Windows](https://dl.todesktop.com/241130tqe9q3y/windows), o consíguelo desde la [página de Descargas](https://comfy.org/download).
2. Ejecuta el instalador. No necesitas desinstalar la versión anterior primero.
3. Inicia Comfy Desktop.

Tus instalaciones, modelos y configuraciones se conservan.
</Accordion>
<Accordion title="Mi GPU no se detecta">
- Asegúrate de que tus controladores NVIDIA estén actualizados
- En Linux, verifica que el kit de herramientas CUDA esté instalado
- Comprueba que el tipo de instalación admita GPU (Standalone y Git Clone sí lo hacen; las conexiones Cloud usan una GPU remota)
</Accordion>
<Accordion title="Una instalación no se actualiza">
- Revisa tu conexión a internet
- Crea una instantánea manual desde la pestaña **Snapshots** de la compilación antes de intentar de nuevo
- Si el problema persiste, restaura una instantánea anterior e intenta de nuevo
</Accordion>

<Accordion title="La instalación o actualización muestra Operation failed">
La pantalla de progreso permanece abierta con **Operation failed**, el error y (cuando está disponible) el panel **View logs** abierto automáticamente.

- **Reboot** reintenta la misma operación (**Restart ComfyUI** si falló un inicio).
- **Back** vuelve a **Home** sin preguntar y deja la instalación fallida en el disco.
- Salir mientras los pasos siguen en ejecución cancela: **Back to Home** pregunta **Cancel current operation?**. Cancelar una instalación intenta eliminar la carpeta a medio crear (pueden quedar archivos si la eliminación falla).

Si sigue fallando, revisa la red y luego recoge `app.log` (y cualquier `app.log_*.log`) desde **Configuraciones de Escritorio → Registros → Abrir carpeta de registros**. En una primera instalación, abre el **Menú** de la **barra de título** y selecciona **Skip onboarding** para llegar primero a **Home**. Consulta también [¿Cómo reviso los registros de inicio de Comfy Desktop?](#cómo-reviso-los-registros-de-inicio-de-comfy-desktop).
</Accordion>
<Accordion title="Veo Low Disk Space o Not Enough Space for Template Models">
Durante **New build**, Comfy Desktop verifica el espacio libre en la unidad de instalación. **Low disk space** es una advertencia: selecciona **Continue anyway** para continuar, o elige otra carpeta. Consulta [Instalar una nueva compilación](/es/installation/desktop/usage/instance-management#crear-una-nueva-instancia).
</Accordion>
<Accordion title="¿Cómo reviso los registros de inicio de Comfy Desktop?">
La aplicación de Escritorio escribe un archivo `app.log` rotativo. La forma más rápida de encontrarlo es **Configuraciones de Escritorio → Registros → Abrir carpeta de registros**, en la parte inferior de la barra lateral.

Carpetas de registros predeterminadas:

- **Windows:** `%APPDATA%\Comfy Desktop\logs`
- **macOS:** `~/Library/Logs/Comfy Desktop`
- **Linux:** `~/.config/Comfy Desktop/logs`

Busca `app.log`. Las sesiones anteriores rotan a archivos `app.log_*.log` con marca de tiempo.

Para ver la salida del proceso de ComfyUI (no la de la aplicación de Escritorio en sí), abre la página de la compilación y usa la pestaña **Terminal**. Consulta [Administrar compilaciones](/es/installation/desktop/usage/instance-management#administrar-builds).
</Accordion>
<Accordion title="¿Puedo usar Ollama con ComfyUI?">
ComfyUI no se integra de forma nativa con [Ollama](https://ollama.ai) para backends de modelos de difusión. Sin embargo, puedes usar LLMs servidos por Ollama para la generación de prompts y el procesamiento de texto mediante **Nodos Personalizados** disponibles en el registro de ComfyUI Manager.

Para conectar ComfyUI con servicios de LLM, consulta [Instalar Nodos Personalizados](/es/installation/install_custom_node).
</Accordion>
<Accordion title="¿Cómo desinstalo Comfy Desktop?">
Comfy Desktop y sus instalaciones están separados en el disco. Para desinstalar la aplicación y sus instalaciones:

1. **Elimina las instalaciones** desde dentro de la aplicación (clic derecho → Eliminar) o borra las carpetas de instalación manualmente
2. **Desinstala la aplicación** usando el método estándar de tu sistema (Agregar o quitar programas en Windows, arrastrar a la Papelera en macOS, el gestor de paquetes en Linux)

Eso no elimina las configuraciones de la aplicación, los registros, los modelos compartidos ni las salidas. Para las carpetas que quedan y una limpieza completa, consulta [Windows](/es/installation/desktop/overview#desinstalar-comfy-desktop), [macOS](/es/installation/desktop/overview#desinstalar-comfy-desktop) o [Linux](/es/installation/desktop/overview#desinstalar-comfy-desktop).
</Accordion>
<Accordion title="¿Puedo ejecutar Comfy Desktop en modo headless o de servidor?">
No. Comfy Desktop está diseñado como una aplicación GUI local y no admite modos de operación headless, solo servidor ni remotos. Requiere un entorno de escritorio gráfico para iniciar y administrar instancias de ComfyUI.

Para despliegues headless o de servidor, usa una **instalación manual de ComfyUI** o la compilación **Windows Portable** en su lugar.
</Accordion>
