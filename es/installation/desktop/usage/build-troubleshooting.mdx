Esta página enumera los mensajes que Comfy Desktop muestra cuando un build falla, con la solución de cada uno. Para instalar, agregar o conectar el build, consulta [Builds](/es/installation/desktop/usage/instance-management).

## Corregir un build que falla

Cuando un build falla, Comfy Desktop lo indica en varios lugares:

- **barra lateral**: un punto rojo. Su tooltip muestra, por ejemplo, **Crashed (exit code 1)** o **Didn't start:** y el motivo.
- **página Builds**: un chip de estado en el mosaico, como **Didn't start**, **Crashed** o **Error**.
- **menú de acciones rápidas**: **View error**, que abre los detalles.
- **página del build**: un chip rojo junto al nombre. Haz clic en él para abrir los detalles.
- **Inicio**: la tarjeta del build muestra **Didn't start** o indica un problema con el build, como **Install failed** o **Folder not found**. Un cierre inesperado no aparece en la tarjeta.

Busca abajo el mensaje que veas.

<AccordionGroup>
  <Accordion title="ComfyUI didn't install">
    La instalación se detuvo antes de finalizar. El diálogo **Installing ComfyUI** muestra **ComfyUI didn't install** e indica el paso que falló. Haz clic en **View logs** en el diálogo para leer la salida.

    Después, el build muestra **Install failed**: **This build's installation did not finish. Uninstall it and reinstall.** Haz clic en [**Uninstall**](/es/installation/desktop/usage/build-duplicate-and-remove#eliminar-una-compilación) para desinstalar el build y luego [vuelve a instalarlo](/es/installation/desktop/usage/instance-management#instalar-una-compilación-nueva).
  </Accordion>
  <Accordion title="ComfyUI didn't start">
    El build no pudo iniciarse. La página del build muestra **ComfyUI didn't start** con el motivo.

    1. Haz clic en **View logs** en la página del build o selecciona **View error** en el menú de acciones rápidas para leer qué salió mal.
    2. Corrige la causa. En el diálogo que se abre, haz clic en **Try again**.
  </Accordion>
  <Accordion title="ComfyUI exited unexpectedly">
    ComfyUI se detuvo mientras se ejecutaba. El tooltip de la **barra lateral** muestra **Crashed** con el código de salida o la señal, y la página del build muestra **ComfyUI exited unexpectedly**.

    - Selecciona **View error** en el menú de acciones rápidas para leer el mensaje y las últimas líneas que imprimió ComfyUI.
    - En la ventana de ComfyUI, haz clic en **Restart ComfyUI** para volver a iniciarlo, o en **Back to Home**.

    En Windows, un cierre inesperado puede reportar una infracción de acceso a la memoria. Si el mensaje también indica que faltan algunos archivos de Microsoft Visual C++ Redistributable, repara o instala el redistributable más reciente y luego reinicia el build.
  </Accordion>
  <Accordion title="Folder not found or Folder access denied">
    Comfy Desktop no puede acceder a la carpeta del build.

    - **Folder not found**: **Build folder not found. Reconnect the drive or restore the folder, then try again.**
    - **Folder access denied**: **Can't access the build folder. Check that you have permission to read it (or that the drive is online), then try again.**

    Selecciona **View error** en el menú de acciones rápidas para leer el mensaje y la ruta de la carpeta.
  </Accordion>
  <Accordion title="Uninstall didn't finish">
    La página del build muestra **Uninstall didn't finish** con el motivo. Cuando un archivo está en uso, el motivo indica el programa que lo retiene o señala que Comfy Desktop no pudo identificarlo. Cierra ese programa y luego haz clic en **Try again**. Haz clic en **Dismiss** para cerrar el mensaje.

    Si una desinstalación anterior quedó interrumpida, el build muestra **Uninstall interrupted**: **A previous uninstall of this build was interrupted. Open it to resume or retry the uninstall.** Abre la página del build y luego [desinstálalo](/es/installation/desktop/usage/build-duplicate-and-remove#eliminar-una-compilación) de nuevo.
  </Accordion>
  <Accordion title="Port already in use">
    ComfyUI escucha en un puerto, `8188`, a menos que los argumentos de inicio del build definan `--port`. Cuando otro programa usa ese puerto, el ajuste **If port is busy** en [Configurar la ventana, la caché y el puerto](/es/installation/desktop/usage/build-startup-arguments#configurar-la-ventana-la-caché-y-el-puerto) decide qué ocurre:

    - **Use next available port (asks if --port is set)**: el valor predeterminado para los builds **Standalone** y **Portable**. Comfy Desktop inicia el build en el siguiente puerto libre, y el progreso de inicio indica el puerto ocupado y el puerto que usa en su lugar.
    - **Ask what to do**: el valor predeterminado para los demás tipos de build.

    Comfy Desktop abre **Port already in use** e indica el programa que ocupa el puerto cuando **If port is busy** está en **Ask what to do**, cuando los argumentos de inicio definen `--port` o cuando Comfy Desktop no encuentra ningún puerto libre.

    <Warning>
      **Stop process and retry** detiene el otro ComfyUI y pierde su trabajo sin guardar.
    </Warning>

    - **Use next available port**: inicia este build en el siguiente puerto libre.
    - **Stop process and retry**: detiene el programa que ocupa el puerto y luego inicia el build de nuevo. Solo aparece cuando ese programa parece ser un ComfyUI.

    Cierra el diálogo para cancelar el inicio.

    Cuando los argumentos de inicio del build incluyen `--enable-assets`, Comfy Desktop también comprueba si el puerto lo ocupa otro ComfyUI que ejecuta este mismo build. Si es así, Comfy Desktop no ofrece otro puerto, porque ambas copias de ComfyUI usarían la misma base de datos. Detén primero la otra copia o cierra la aplicación que la inició.
  </Accordion>
  <Accordion title="An earlier ComfyUI is still running">
    Una sesión anterior de Comfy Desktop dejó un ComfyUI en ejecución para este build. Ese ComfyUI retiene la base de datos del build, así que no puede iniciarse un nuevo ComfyUI para este build.

    <Warning>
      **Stop it and start this build** cancela los prompts que el ComfyUI anterior está procesando.
    </Warning>

    - **ComfyUI is still running a prompt**: haz clic en **Stop it and start this build** para detenerlo y cancelar sus prompts, o déjalo en ejecución y cancela este inicio.
    - **Processes from an earlier ComfyUI are still running**: el mensaje enumera sus identificadores de proceso. Haz clic en **Stop them and start this build**.
    - Si el ComfyUI anterior no se cierra, finaliza el proceso tú mismo y luego inicia el build de nuevo.
  </Accordion>
  <Accordion title="Another ComfyUI is using this build's database">
    Otro ComfyUI usa la base de datos de este build, así que ComfyUI no puede iniciarse para este build. Cierra el otro ComfyUI, o la aplicación que lo inició, y vuelve a iniciar el build. Para ejecutar ambos a la vez, dale a uno de ellos su propia ubicación de base de datos con el argumento de inicio `--database-url`.
  </Accordion>
</AccordionGroup>
