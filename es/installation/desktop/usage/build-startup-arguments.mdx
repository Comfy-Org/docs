Esta página cubre la pestaña **Argumentos de inicio** de la página de un build. Para instalar, agregar o conectar el build, consulta [Builds](/es/installation/desktop/usage/instance-management).

## Establecer los argumentos de inicio

La pestaña **Startup arguments** de la página de la compilación controla cómo inicia ComfyUI para esta compilación: sus flags de línea de comandos, la política de ComfyUI Manager, la ventana y el entorno.

![Pestaña Startup arguments de una compilación Standalone en Launch settings: el campo Startup arguments con --enable-manager, una insignia +1 beta y el engranaje; luego Manager security level, Manager network mode, Launch mode, Browser cache, If port is busy y Environment variables con Add variable](/images/desktop/usage/comfy-desktop-startup-arguments.png)

Todos los cambios se aplican la próxima vez que se inicie la compilación. Si la compilación está en ejecución cuando cambias un campo, el campo muestra **Restart to apply** y el botón del encabezado dice **Restart to apply changes**. Haz clic en él para reiniciar la compilación con las nuevas configuraciones.

### Elegir flags de la lista

El campo **Startup arguments** contiene los argumentos de línea de comandos que se pasan a ComfyUI, como `--listen`. Puedes escribirlos o elegirlos de una lista ordenada por categoría. Si las funciones beta agregan argumentos, una insignia **+N beta** junto al campo los enumera. Para ver todos los flags, consulta la [Referencia de argumentos de inicio](/es/development/comfyui-server/startup-flags).

1. Haz clic en el engranaje (**Configure arguments**) junto a **Startup arguments**.
2. Activa o desactiva flags en las categorías, o edita **Raw arguments**. Ambas acciones cambian los mismos argumentos para esta compilación.
3. Haz clic en **Back** para volver a la pestaña.

### Controlar lo que instala ComfyUI Manager

Dos configuraciones deciden qué Paquetes de Nodos puede instalar ComfyUI Manager para esta compilación. Configura primero **Manager security level**:

- **Strict**: bloquea todas las instalaciones, actualizaciones y desinstalaciones de Paquetes de Nodos. ComfyUI Manager es de solo lectura.
- **Standard (recommended)**: permite los Paquetes de Nodos registrados y bloquea las instalaciones desde fuentes no registradas, como URLs de git arbitrarias. Es la opción predeterminada.
- **Relaxed**: como Standard, pero además permite instalaciones desde fuentes no registradas mientras ComfyUI sea accesible solo desde esta computadora. `--listen` las bloquea de nuevo.
- **Permissive**: permite todos los niveles de riesgo.

Luego configura **Manager network mode**, que decide cómo ComfyUI Manager llega al registro de Nodos.

<Warning>
  **Personal cloud** elimina el bloqueo de instalaciones por `--listen`. Selecciónalo solo en una computadora que controles.
</Warning>

- **Public (default)**: usa el registro público. Con `--listen`, las instalaciones de Paquetes de Nodos se bloquean en todos los niveles de seguridad.
- **Private**: usa una base de datos de Nodos privada que configuras tú mismo.
- **Offline**: no realiza conexiones de red externas. Las instalaciones y actualizaciones que necesitan descargas no están disponibles.
- **Personal cloud**: trata esta computadora como tu propia máquina remota de confianza y elimina el bloqueo de instalaciones por `--listen`. El nivel de seguridad sigue aplicándose.

### Configurar la ventana, la caché y el puerto

Estas configuraciones deciden cómo se abre la compilación y qué hace cuando su puerto está ocupado:

- **Launch mode**: **App window** (la opción predeterminada) o **Console only**.
- **Browser cache**: **Unique to this build** o **Shared** con otras compilaciones. Una nueva compilación Standalone comienza con **Unique to this build**.
- **If port is busy**: **Ask what to do** o **Use next available port (asks if --port is set)**. Las compilaciones Standalone y Portable usan **Use next available port (asks if --port is set)** de forma predeterminada, y las compilaciones de git usan **Ask what to do**.

### Agregar variables de entorno

Las variables de entorno pasan configuraciones adicionales a ComfyUI cuando se inicia la compilación.

<Warning>
  Comfy Desktop almacena los valores de las variables de entorno sin cifrar en el disco. No agregues claves de API, tokens ni contraseñas.
</Warning>

- En **Environment variables**, haz clic en **Add variable** y luego ingresa el nombre y el valor.

Los valores de nombres que parecen credenciales, como `HF_TOKEN`, permanecen ocultos hasta que los reveles. Un nombre repetido muestra **Duplicate key**.
