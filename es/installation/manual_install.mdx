La instalación de ComfyUI se divide principalmente en varios pasos:
1. Crear un entorno virtual (para evitar contaminar el entorno de Python del sistema)
2. Clonar el repositorio de código de ComfyUI
3. Instalar las dependencias
4. Iniciar ComfyUI

También puedes consultar [ComfyUI CLI](/comfy-cli/getting-started) para instalar ComfyUI. Es una herramienta de línea de comandos que permite instalar ComfyUI y administrar sus dependencias fácilmente.

## Crear un entorno virtual

<Tip>
    Los entornos virtuales independientes son necesarios porque las dependencias de ComfyUI pueden entrar en conflicto con otras dependencias del sistema, y también permiten evitar contaminar el entorno de Python a nivel de sistema.
</Tip>

## Clone the ComfyUI code repository

You need to ensure that you have installed [Git](https://git-scm.com/downloads) on your system. First, you need to open the terminal (command line), then clone the code repository.
<Tabs>
<Tab title="Windows">
<Warning>If you have not installed Microsoft Visual C++ Redistributable, please install it [here.](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)</Warning>
</Tab>
<Tab title="Linux">
Open Terminal application.
</Tab>
<Tab title="MacOS">
Open [Terminal application](https://support.apple.com/guide/terminal/open-or-quit-terminal-apd5265185d-f365-44cb-8b09-71a064a42125/mac).
</Tab>
</Tabs>

```bash
git clone https://github.com/Comfy-Org/ComfyUI.git
```

## Cómo actualizar ComfyUI

<Steps>
    <Step title="Trae el código más reciente">
    Usa la línea de comandos para entrar en la ruta de instalación de ComfyUI y luego trae el código más reciente.
    ```bash
    cd <installation path>/ComfyUI
    git pull
    ```
    </Step>
    <Step title="Instala las dependencias">
    Usa la línea de comandos para entrar en la ruta de instalación de ComfyUI y luego instala las dependencias.
    <Warning>
    Debes asegurarte de que el entorno actual de Python sea el entorno virtual de ComfyUI; de lo contrario, las dependencias se instalarán en el entorno de Python del sistema, contaminándolo.
    </Warning>
    ```bash
        pip install -r requirements.txt
    ```
    </Step>
</Steps>

### Cómo detener/salir de ComfyUI

Presiona **Ctrl+C** en la ventana de terminal donde se está ejecutando ComfyUI, o simplemente cierra la ventana de terminal.
