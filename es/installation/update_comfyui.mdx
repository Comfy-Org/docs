Aunque las actualizaciones de ComfyUI ya aparecen en varias guías de instalación, aquí reunimos todos los procedimientos en un solo sitio para que quede claro cómo actualizar.

## ¿Cómo actualizar ComfyUI?

<Tabs>
<Tab title="Portátil">
 ComfyUI Portable incluye scripts `.bat` prácticos para actualizar con facilidad.

 ### Ubicación de los scripts de actualización
 En la carpeta `update` de tu instalación Portable encontrarás estos scripts:

 ```
 ComfyUI_windows_portable
 └─ 📂update
    ├── update.py
    ├── update_comfyui.bat                           // Actualizar a la última versión de desarrollo
    ├── update_comfyui_stable.bat                    // Actualizar a la última versión estable
    └── update_comfyui_and_python_dependencies.bat   // ⚠️ PELIGRO: Reinstala las dependencias - puede causar conflictos
```
<Warning>Asegúrate de tener una conexión a internet estable durante las actualizaciones.</Warning>

<Warning>
**⚠️ PELIGRO: ¡Usa `update_comfyui_and_python_dependencies.bat` con muchísima precaución!**

Este script es más exhaustivo que las actualizaciones normales y hará lo siguiente:
- ✅ Actualizar el propio código de ComfyUI
- ✅ Actualizar PyTorch (para NVIDIA GPU CUDA 12.9)
- ✅ Reinstalar TODAS las dependencias de Python

**Riesgos:**
- Puede causar conflictos de dependencias con tu configuración actual
- Puede romper nodos personalizados que dependen de versiones específicas de paquetes
- Puede sobrescribir paquetes configurados manualmente

**⚠️ Usa este script solo cuando:**
- Necesites solucionar problemas de dependencias
- Vayas a realizar actualizaciones de versión mayor
- Para actualizaciones diarias, usa `update_comfyui.bat` en su lugar

**Antes de ejecutar este script:**
1. **Haz una copia de seguridad de toda tu instalación de ComfyUI**
2. Documenta las versiones de paquetes personalizados que hayas instalado
3. Prepárate para reinstalar los nodos personalizados si es necesario
</Warning>
</Tab>
<Tab title="Escritorio">
Para actualizar ComfyUI, abre el [panel Administrar](/es/installation/desktop/usage/manage#pestaña-actualizar) y usa la pestaña Actualizar. Puedes elegir entre los canales de actualización **Stable** (predeterminado) y **Latest on GitHub**.

La aplicación de escritorio se actualiza automáticamente y es independiente de las actualizaciones de la instancia de ComfyUI.
</Tab>
<Tab title="Instalación manual">
ComfyUI instalado manualmente requiere comandos de Git para completar las actualizaciones.

### Requisitos previos a la actualización
Asegúrate de que tu sistema tenga [Git](https://git-scm.com/downloads) instalado y de que ComfyUI se haya instalado mediante Git clone.

### Pasos de actualización
<Steps>
<Step title="Activar el entorno virtual">
Primero, activa el entorno virtual de Python de ComfyUI (si estás usando uno):
```bash
# Para entorno conda
conda activate comfyui

# Para entorno venv
# Windows
venv\Scripts\activate
# macOS/Linux  
source venv/bin/activate
```
</Step>
<Step title="Obtener el código más reciente">
Navega a tu directorio de instalación de ComfyUI y obtén el código más reciente:
```bash
cd <ComfyUI-installation-path>
git pull
```
</Step>
<Step title="Actualizar las dependencias">
Instala o actualiza los paquetes de dependencias de ComfyUI:
```bash
pip install -r requirements.txt
```
<Warning>
Asegúrate de estar en el entorno virtual de ComfyUI para evitar contaminar el entorno de Python a nivel del sistema
</Warning>
</Step>
<Step title="Reiniciar ComfyUI">
Después de actualizar, reinicia ComfyUI:
```bash
python main.py
```
</Step>
</Steps>

### Cambiar de versión (opcional)
Para cambiar a una versión específica, usa estos comandos:
```bash
# Ver el historial de commits
git log --oneline

# Cambiar a un commit específico
git checkout <commit-hash>

# Volver a la última versión
git checkout master
```
<Tip>Se recomiendan las actualizaciones regulares para obtener las últimas funciones y correcciones de seguridad, mientras que las versiones estables se recomiendan para la estabilidad del sistema</Tip>
</Tab>
</Tabs>

## ¿Qué se debe actualizar al actualizar ComfyUI?

Las actualizaciones de ComfyUI consisten principalmente en dos componentes:
1. Actualizar el código principal de ComfyUI
2. Actualizar las dependencias principales de ComfyUI, incluidas las dependencias necesarias de Python y los paquetes de dependencias funcionales de ComfyUI

**Código principal**: Nuevos nodos, soporte para nuevos modelos, nuevas funciones, etc.
**Dependencias principales**: Incluye principalmente la funcionalidad del frontend de ComfyUI, las plantillas de flujo de trabajo, la documentación de ayuda de nodos, etc.

```
comfyui-frontend-package   # Funcionalidad del frontend de ComfyUI
comfyui-workflow-templates # Plantillas de flujo de trabajo de ComfyUI  
comfyui-embedded-docs      # Documentación de ayuda de nodos de ComfyUI
comfy-kitchen              # Utilidades principales de ComfyUI
comfy-aimdo                # Utilidades principales de ComfyUI
```

Estas dependencias principales se mantienen en repositorios separados:
- [ComfyUI_frontend](https://github.com/Comfy-Org/ComfyUI_frontend/) - Interfaz del frontend y funciones interactivas
- [workflow_templates](https://github.com/Comfy-Org/workflow_templates) - Plantillas de flujo de trabajo prediseñadas
- [comfyui-embedded-docs](https://github.com/Comfy-Org/embedded-docs) - Documentación de ayuda de nodos
- [comfy-kitchen](https://github.com/Comfy-Org/comfy-kitchen) - Biblioteca de kernels rápida para inferencia de Diffusion con múltiples backends de cómputo
- [comfy-aimdo](https://github.com/Comfy-Org/comfy-aimdo) - Asignador de descarga bajo demanda de modelos de IA

Es importante entender la diferencia entre las versiones de desarrollo (nocturnas) y las estables (release):
- **Versión de desarrollo (nocturna)**: Código del último commit, que te da acceso a las funciones más recientes, pero puede contener posibles problemas
- **Versión estable (release)**: Basada en lanzamientos estables, normalmente va por detrás de las versiones de desarrollo, pero ofrece mayor estabilidad. Damos soporte a las versiones estables después de que las funciones se prueban y estabilizan

Muchos usuarios suelen encontrarse en versiones estables (release) o en el canal **Stable** predeterminado de Desktop durante las actualizaciones, pero descubren que las funciones que necesitan solo están disponibles en las compilaciones de desarrollo o nocturnas. En **Desktop**, cambia a **Latest on GitHub** en [Administrar → Actualizar](/es/installation/desktop/usage/manage#pestaña-actualizar). Para instalaciones portables o manuales, verifica si tu archivo local `ComfyUI/requirements.txt` coincide con las [dependencias de la versión nocturna](https://github.com/Comfy-Org/ComfyUI/blob/master/requirements.txt) para determinar si todas las dependencias admiten las funciones más recientes.

## Problemas comunes al actualizar

### Interfaz, plantillas de flujos de trabajo y nodos faltantes o desactualizados después de actualizar


<Tabs><Tab title="Dependencias no actualizadas correctamente">
    Muchos usuarios solo usan el comando `git pull` para actualizar el código de ComfyUI, pero **descuidan la actualización de las dependencias principales**, lo que provoca los siguientes problemas:

  - Funcionalidad del frontend faltante o anómala
  - No se encuentran las plantillas de flujos de trabajo recién añadidas
  - Documentación de ayuda de nodos desactualizada o faltante
  - Las nuevas funciones carecen del soporte correspondiente en el frontend

  Después de usar el comando `git pull`, usa el entorno de ComfyUI correspondiente para ejecutar `pip install -r requirements.txt` y actualizar las dependencias.
  </Tab><Tab title="Fallos en la actualización de dependencias">
    Si las actualizaciones de dependencias fallan, normalmente se debe a problemas de red o de permisos del equipo. Cuando ocurren fallos en las dependencias principales durante las actualizaciones, el sistema recurre a versiones anteriores. Por lo general verás registros como este al iniciar:
    ```
    Falling back to the default frontend.
    ComfyUI frontend version: xxx
    ```

    Sigue estos pasos para solucionar problemas:
    1. Usa `pip list` en el entorno adecuado para ver los paquetes de dependencias instalados actualmente. Si encuentras inconsistencias de versión, usa `pip install -r requirements.txt` en el entorno de ComfyUI para intentar actualizar las dependencias de nuevo.
    2. Si los problemas persisten después de actualizar, revisa tu conexión de red. Los usuarios de China continental pueden necesitar configurar un proxy para acceder de forma confiable a los repositorios de GitHub.
    3. Si los problemas continúan, revisa los permisos del equipo. Si se requieren privilegios de administrador, ejecuta la línea de comandos con permisos de administrador.
  </Tab>
</Tabs>

### Solución de problemas de actualización de dependencias principales

Si las actualizaciones de las dependencias principales fallan, sigue estos pasos para solucionar problemas:

<Steps>
  <Step title="Revisa la conexión de red">
    Si te encuentras en China continental, asegúrate de poder acceder a PyPI o configura un espejo nacional:
    ```bash
    # Usando el espejo de la Universidad de Tsinghua
    pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
    ```
  </Step>
  <Step title="Instala los paquetes principales individualmente">
    Si la instalación por lotes falla, intenta instalar los paquetes individualmente. **Primero revisa los requisitos de versión en `ComfyUI/requirements.txt`**:
    
    **Luego instala según las versiones especificadas (usa los números de versión de tu requirements.txt):**
    ```bash
    pip install comfyui-frontend-package==<version> 
    pip install comfyui-workflow-templates==<version>
    pip install comfyui-embedded-docs==<version>
    pip install comfy-kitchen==<version>
    pip install comfy-aimdo==<version>
    ```
    <Warning>
    Se recomienda usar los números de versión exactos especificados en `ComfyUI/requirements.txt`. No actualices a las versiones más recientes por tu cuenta, ya que esto puede causar problemas de compatibilidad.
    </Warning>
  </Step>
</Steps>

### ¿Por qué no encuentro las funciones nuevas después de actualizar?

Este es uno de los problemas más comunes:
- Si usas **Desktop** en el canal de actualización **Stable**, las funciones pueden ir por detrás de los commits más recientes de GitHub. Cambia el canal a **Latest on GitHub** en la pestaña [Manage → Update](/es/installation/desktop/usage/manage#pestaña-actualizar) cuando necesites funciones más recientes (Latest puede ser menos estable).
- Para instalaciones Portable o manuales, asegúrate de estar en la **versión de desarrollo (nightly)** y no en la **versión estable (release)** cuando necesites los commits más recientes.

Además, asegúrate de que las dependencias correspondientes se hayan actualizado correctamente durante el proceso de actualización. Si los problemas persisten después de actualizar, consulta la sección [Solución de problemas de actualización de dependencias](#solución-de-problemas-de-actualización-de-dependencias-principales) para diagnosticar el problema.

### ¿Cómo cambiar entre las versiones de desarrollo (Nocturna) y estable (Release)?

Diferencias entre versiones:

<Tabs>
  <Tab title="Versión de desarrollo (Nocturna)">
    - **Características**: Contiene el código del commit más reciente
    - **Ventajas**: Prueba primero las funciones y mejoras más recientes
    - **Riesgos**: Puede contener errores no descubiertos o factores de inestabilidad
    - **Adecuada para**: Desarrolladores, testers y usuarios que quieren probar las funciones más recientes
  </Tab>
  <Tab title="Versión estable (Release)">
    - **Características**: Código estable probado y verificado
    - **Ventajas**: Alta estabilidad, adecuada para entornos de producción
    - **Desventajas**: Las actualizaciones de funciones tienen retrasos, pueden ir por detrás de las versiones de desarrollo por semanas o meses
    - **Adecuada para**: Usuarios que requieren estabilidad, usuarios de entornos de producción
  </Tab>
</Tabs>

<Tabs>
  <Tab title="Portable">
    Usa `update_comfyui.bat` en lugar de `update_comfyui_stable.bat`:
    ```
    # Versión de desarrollo (funciones más recientes)
    double-click: update_comfyui.bat
    
    # Versión estable
    double-click: update_comfyui_stable.bat
    ```
  </Tab>
  <Tab title="Instalación manual">
    ```bash
    # Cambiar a la versión de desarrollo
    git checkout master
    git pull
    
    # Cambiar a la última versión estable
    git fetch --tags
    git checkout $(git describe --tags `git rev-list --tags --max-count=1`)
    ```
  </Tab>
  <Tab title="Desktop">
    Abre el [panel Manage](/es/installation/desktop/usage/manage#pestaña-actualizar) y usa la pestaña Update para cambiar de canal:
    - **Stable** (predeterminado): versiones probadas, pueden ir por detrás de los commits más recientes de GitHub
    - **Latest on GitHub**: sigue los commits más recientes de GitHub; puede ser menos estable

    Usa **Switch Channel**, **Update Now** o **Copy & Update** según si el canal seleccionado tiene una compilación más reciente. Encontrarás los detalles en la página [Manage Update tab](/es/installation/desktop/usage/manage#pestaña-actualizar).
  </Tab>
</Tabs>

### ¿Qué hacer cuando aparecen errores después de actualizar?

1. **Revisa las dependencias**: Ejecuta `pip install -r requirements.txt` para asegurarte de que todas las dependencias estén actualizadas
2. **Revisa los nodos personalizados**: Algunos nodos personalizados pueden ser incompatibles con las versiones nuevas
3. **Revierte la versión**: Si los problemas son graves, puedes volver a una versión estable anterior

Si se presentan problemas, consulta nuestra página de solución de problemas para encontrar soluciones.
