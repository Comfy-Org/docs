## Descripción general de la nueva interfaz

![Nueva interfaz](/images/manager/new_ui_labeled.jpg)

1. **Barra lateral izquierda (Filtros)**: Filtra nodos instalados, nodos en el flujo de trabajo, nodos faltantes, nodos actualizables, etc.
2. **Barra de búsqueda superior**: Busca paquetes de nodos (Node Pack) o nodos individuales (Node); cambia el tipo de búsqueda con el menú desplegable Filtrar
3. **Panel de detalles derecho**: Haz clic en un nodo para mostrar información detallada, incluida la descripción, el estado de habilitación, la información de versión, etc. La pestaña Descripción contiene la información del repositorio y la pestaña Nodes muestra una vista previa de todos los nodos

## Gestión de nodos

Aprende a usar el nuevo ComfyUI Manager para administrar nodos personalizados

### Buscar nodos
![Filtrar](/images/manager/new_ui_filter.jpg)

El Administrador permite buscar paquetes de nodos y nodos individuales por separado. Como se muestra arriba, puedes cambiar el tipo de búsqueda alternando el filtro.
- Node Pack: Un paquete de nodos personalizados completo
- Individual Node: Busca nodos individuales dentro de los paquetes de nodos

### Instalar nodos

![Instalar nodos](/images/manager/new_ui_install_pack.jpg)
1. Selecciona la tarjeta del nodo correspondiente
2. Haz clic en **Install** en la información del nodo expandida
3. O selecciona una versión específica en **Version** para instalar

### Actualizar nodos
En el filtro **Update available**, puedes filtrar los nodos que tienen actualizaciones disponibles en la lista de nodos actual
![Actualizar nodos](/images/manager/new_ui_update_pack.jpg)
1. Los nodos actualizables mostrarán un indicador de flecha de actualización
2. Selecciona una versión específica en **Version**
3. Haz clic en el botón **Update** después de seleccionar una versión para actualizar

### Encontrar nodos faltantes

![Encontrar nodos faltantes](/images/manager/new_ui_missing_packs_prompt.jpg)
Si tu ComfyUI Manager está instalado correctamente, aparecerá un aviso al cargar un flujo de trabajo con nodos faltantes
1. Puedes elegir **Install All** para instalar todos los nodos a la vez
2. O elegir **Open Manager** para abrir el Manager y revisar los detalles antes de instalar

![Encontrar nodos faltantes](/images/manager/new_ui_missing_pack.jpg)
Para encontrar nodos faltantes en un flujo de trabajo, selecciona el nodo correspondiente y luego haz clic en el botón **Missing** en el panel de vista previa para encontrar los nodos faltantes

### Desinstalar nodos
![Desinstalar nodos](/images/manager/new_ui_uninstall_pack.jpg)
Para desinstalar un nodo instalado, selecciona el nodo correspondiente y luego haz clic en el botón **Uninstall** en el panel de vista previa para desinstalarlo

## Preguntas frecuentes
1. ¿Por qué no encuentro el nodo que necesito?
El nuevo Administrador solo permite instalar nodos desde el [registro](/es/registry/overview). Si tu nodo no está registrado en el registro, regístralo primero en el Administrador.

2. ¿Por qué no encuentro la opción de instalar mediante git?
Por seguridad y estabilidad del sistema de usuarios de ComfyUI, la nueva interfaz no permite instalar nodos mediante git. Consulta [Instalar nodos personalizados manualmente](/es/installation/install_custom_node) para aprender a instalar nodos personalizados manualmente.
