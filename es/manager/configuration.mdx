## Rutas de configuración

A partir de la V3.38, el Administrador usa una ruta de sistema protegida para mejorar la seguridad.

| Versión de ComfyUI | Ruta del Administrador |
|-----------------|--------------|
| v0.3.76+ (con API de usuario del sistema) | `<USER_DIRECTORY>/__manager/` |
| Versiones anteriores | `<USER_DIRECTORY>/default/ComfyUI-Manager/` |

<Note>
Si se ejecuta sin ninguna opción, la ruta `<USER_DIRECTORY>` toma por defecto el valor `ComfyUI/user`. Se puede definir con `--user-directory <USER_DIRECTORY>`.
</Note>

### Archivos de configuración

| Archivo | Descripción |
|------|-------------|
| `config.ini` | Configuración básica |
| `channels.list` | Listas de canales configurables |
| `pip_overrides.json` | Asignaciones personalizadas de paquetes pip |
| `pip_blacklist.list` | Paquetes cuya instalación se impide |
| `pip_auto_fix.list` | Paquetes que se restauran automáticamente |
| `snapshots/` | Archivos de instantáneas guardados |
| `startup-scripts/` | Archivos de scripts de inicio |
| `components/` | Archivos de componentes |

## Opciones de Config.ini

Modifica el archivo `config.ini` para aplicar configuraciones. La ruta se muestra en los mensajes del registro de inicio.

```ini
[default]
git_exe = <path to git executable>
use_uv = <True/False - use uv instead of pip>
default_cache_as_channel_url = <True/False - retrieve DB designated as channel_url at startup>
bypass_ssl = <True/False - disable SSL if errors occur>
file_logging = <True/False - create log file>
windows_selector_event_loop_policy = <True/False - fix event loop errors on Windows>
model_download_by_agent = <True/False - use agent for model downloads>
downgrade_blacklist = <comma-separated list of packages to prevent downgrades>
security_level = <strong|normal|normal-|weak>
always_lazy_install = <True/False - perform dependency installation on restart>
network_mode = <public|private|offline>
```

### Modos de red

| Modo | Descripción |
|------|-------------|
| `public` | Entorno de red pública estándar |
| `private` | Red cerrada con una base de datos de nodos privada configurada mediante `channel_url` (usa la caché si está disponible) |
| `offline` | Sin conexiones externas (usa la caché si está disponible) |

### Niveles de seguridad

| Nivel | Descripción |
|-------|-------------|
| `strong` | No permite funciones de riesgo alto ni medio |
| `normal` | No permite funciones de riesgo alto; las funciones de nivel medio están disponibles |
| `normal-` | No permite funciones de riesgo alto si se especifica `--listen` y este no comienza con `127.`; las funciones de nivel medio están disponibles |
| `weak` | Todas las funciones disponibles |

#### Niveles de riesgo de las funciones

| Nivel de riesgo | Funciones |
|------------|----------|
| **Alto** | Instalar mediante git url, pip install, instalación de nodos personalizados que no están en el canal predeterminado, corregir nodos personalizados |
| **Medio** | Desinstalar/Actualizar, instalación de nodos personalizados en el canal predeterminado, restaurar/eliminar instantánea, reiniciar |
| **Bajo** | Actualizar ComfyUI |

## Variables de entorno

| Variable | Descripción |
|----------|-------------|
| `COMFYUI_PATH` | Ruta de instalación de ComfyUI |
| `GITHUB_ENDPOINT` | Proxy inverso para el acceso a GitHub |
| `HF_ENDPOINT` | Proxy inverso para el acceso a Hugging Face |

### Ejemplos

Redirigir las solicitudes de GitHub a través de un proxy:
```bash
GITHUB_ENDPOINT=https://mirror.ghproxy.com/https://github.com
```

Cambiar el endpoint de Hugging Face:
```bash
HF_ENDPOINT=https://some-hf-mirror.com
```

## Configuración avanzada

### Evitar la degradación de paquetes específicos

Enumera los nombres de los paquetes en la sección `downgrade_blacklist` de `config.ini`, separados por comas:

```ini
downgrade_blacklist = diffusers, kornia
```

### Asignación personalizada de pip

Crea un archivo `pip_overrides.json` para cambiar la instalación de paquetes pip específicos por instalaciones definidas por el usuario. Consulta `pip_overrides.json.template` para ver el formato.

### Evitar la instalación de paquetes pip específicos

Enumera los nombres de los paquetes, uno por línea, en el archivo `pip_blacklist.list`.

### Restaurar automáticamente la instalación de pip

Enumera los requisitos de especificación de pip en `pip_auto_fix.list` (similar a `requirements.txt`). Restaurará automáticamente las versiones especificadas al iniciar ComfyUI o cuando las versiones no coincidan durante la instalación de nodos personalizados. Se puede usar `--index-url`.

### Usar aria2 como descargador

Para descargas más rápidas, puedes configurar ComfyUI-Manager para usar aria2. Consulta la [guía de configuración de aria2](https://github.com/Comfy-Org/ComfyUI-Manager/blob/main/docs/en/use_aria2.md).

## Configuración de extra_model_paths.yaml

Las siguientes configuraciones se aplican según la sección marcada como `is_default`:

- `custom_nodes`: Ruta para instalar nodos personalizados
- `download_model_base`: Ruta para descargar modelos

## Herramientas CLI

ComfyUI-Manager proporciona `cm-cli`, una herramienta de línea de comandos que te permite usar las funciones del Administrador sin ejecutar ComfyUI. Esto es útil para automatizar la instalación de nodos personalizados y gestionar instalaciones en entornos sin interfaz gráfica.

Para consultar la documentación detallada de cm-cli, revisa la [guía oficial de cm-cli](https://github.com/Comfy-Org/ComfyUI-Manager/blob/main/docs/en/cm-cli.md).

Si buscas una experiencia de CLI más completa, considera usar [comfy-cli](/es/comfy-cli/getting-started).
