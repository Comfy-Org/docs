## Problemas comunes

### Ruta personalizada del ejecutable de git

Si tu `git.exe` está instalado en una ubicación específica distinta de la predeterminada del sistema:

1. Instala ComfyUI-Manager y ejecuta ComfyUI una vez
2. Abre `<USER_DIRECTORY>/default/ComfyUI-Manager/config.ini`
3. Especifica la ruta completa, incluido el nombre del archivo, en `git_exe =`

```ini
git_exe = C:\Program Files\Git\bin\git.exe
```

### La actualización de ComfyUI-Manager falla

Si falla la actualización de ComfyUI-Manager, ve al directorio de ComfyUI-Manager y ejecuta:

```bash
git update-ref refs/remotes/origin/main a361cc1 && git fetch --all && git pull
```

### Windows: error Overlapped Object

Si encuentras `Overlapped Object has pending operation at deallocation on ComfyUI Manager load`:

Edita `config.ini` y agrega:

```ini
windows_selector_event_loop_policy = True
```

### Falló la verificación del certificado SSL

Si encuentras el error `SSL: CERTIFICATE_VERIFY_FAILED`:

Edita `config.ini` y agrega:

```ini
bypass_ssl = True
```

## Problemas de instalación

### Ruta de instalación incorrecta

Los archivos de ComfyUI-Manager deben estar ubicados en `ComfyUI/custom_nodes/comfyui-manager`.

**Errores comunes que debes evitar:**

| Problema | Descripción |
|-------|---------|
| Archivos en la ubicación incorrecta | Archivos del administrador como `__init__.py` colocados directamente en el directorio `custom_nodes` |
| Carpeta anidada dos veces | Instalado como `custom_nodes/ComfyUI-Manager/ComfyUI-Manager` |
| Nombre de carpeta incorrecto | Instalado como `custom_nodes/ComfyUI-Manager-main` |
| Formato comprimido | Instalar desde un archivo comprimido sin la extracción adecuada |

<Warning>
Si la instalación es incorrecta, ComfyUI-Manager puede parecer que funciona, pero no se reconocerá para las actualizaciones y puede provocar instalaciones duplicadas. Elimínalo y vuelve a instalarlo correctamente con `git clone`.
</Warning>

## Problemas de red

### Problemas de acceso a GitHub

Si tu acceso a GitHub es limitado, configura la variable de entorno `GITHUB_ENDPOINT`:

```bash
GITHUB_ENDPOINT=https://mirror.ghproxy.com/https://github.com
```

### Problemas de acceso a Hugging Face

Si tu acceso a Hugging Face es limitado, configura la variable de entorno `HF_ENDPOINT`:

```bash
HF_ENDPOINT=https://some-hf-mirror.com
```

## Solución de problemas del escáner

Al ejecutar el script `scan.sh`:

- Actualiza `extension-node-map.json` al extraer o clonar los nodos personalizados listados en `custom-node-list.json` en `~/.tmp/default`
- Actualiza `github-stats.json` usando la API de GitHub

| Opción | Descripción |
|--------|-------------|
| `--skip-update` | Salta la actualización de extension-node-map.json |
| `--skip-stat-update` | Salta la actualización de github-stats.json |
| `--skip-all` | Salta ambos pasos de actualización |

<Tip>
Para evitar los límites de tasa de la API de GitHub, configura tu token: `export GITHUB_TOKEN=your_token_here`
</Tip>

Si quieres especificar una ruta diferente en lugar de `~/.tmp/default`, ejecuta `python scanner.py [path]` directamente en lugar de `scan.sh`.

## Política de seguridad

Si encuentras el error `This action is not allowed with this security level configuration` al instalar nodos personalizados mediante una URL de git o al usar la versión nocturna, necesitas ajustar el nivel de seguridad en tu archivo `config.ini`.

El archivo `config.ini` se encuentra en:
- **ComfyUI v0.3.76+**: `<USER_DIRECTORY>/__manager/config.ini`
- **Versiones anteriores**: `<USER_DIRECTORY>/default/ComfyUI-Manager/config.ini`

Donde `<USER_DIRECTORY>` es `ComfyUI/user` de forma predeterminada. Consulta [Configuración](/es/manager/configuration) para más detalles.

Configura los niveles de seguridad en `config.ini`:

```ini
security_level = normal
```

| Nivel | Descripción |
|-------|-------------|
| `strong` | No permite funciones de riesgo alto ni medio |
| `normal` | No permite funciones de riesgo alto; las funciones de riesgo medio están disponibles |
| `normal-` | No permite funciones de riesgo alto si se especifica `--listen` y este no comienza con `127.`; las funciones de riesgo medio están disponibles |
| `weak` | Todas las funciones disponibles |

### Niveles de riesgo de las funciones

| Nivel de riesgo | Funciones |
|------------|----------|
| **Alto** | Instalar mediante URL de git, pip install, instalación de nodos personalizados que no están en el canal predeterminado, reparar nodos personalizados |
| **Medio** | Desinstalar/Actualizar, instalación de nodos personalizados en el canal predeterminado, restaurar/eliminar instantáneas, reiniciar |
| **Bajo** | Actualizar ComfyUI |

<Tip>
Para instalar nodos personalizados mediante URL de git o versiones nocturnas, establece `security_level = weak` en tu archivo `config.ini`.
</Tip>
