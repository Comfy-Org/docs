## Common issues

### Custom git executable path

If your `git.exe` is installed in a specific location other than the system default:

1. Install ComfyUI-Manager and run ComfyUI once
2. Open `<USER_DIRECTORY>/default/ComfyUI-Manager/config.ini`
3. Specify the full path including the file name in `git_exe =`

```ini
git_exe = C:\Program Files\Git\bin\git.exe
```

### ComfyUI-Manager update fails

If updating ComfyUI-Manager itself fails, go to the ComfyUI-Manager directory and run:

```bash
git update-ref refs/remotes/origin/main a361cc1 && git fetch --all && git pull
```

### Windows: Overlapped Object error

If you encounter `Overlapped Object has pending operation at deallocation on ComfyUI Manager load`:

Edit `config.ini` and add:

```ini
windows_selector_event_loop_policy = True
```

### SSL certificate verification failed

If you encounter `SSL: CERTIFICATE_VERIFY_FAILED` error:

Edit `config.ini` and add:

```ini
bypass_ssl = True
```

## Problemas de instalación

### Ruta de instalación incorrecta

Los archivos de ComfyUI-Manager deben estar ubicados en `ComfyUI/custom_nodes/comfyui-manager`.

**Errores comunes que debes evitar:**

| Problema | Descripción |
|-------|---------|
| Archivos en la ubicación incorrecta | Archivos del administrador como `__init__.py` colocados directamente en el directorio `custom_nodes` |
| Carpeta anidada doble | Instalado como `custom_nodes/ComfyUI-Manager/ComfyUI-Manager` |
| Nombre de carpeta incorrecto | Instalado como `custom_nodes/ComfyUI-Manager-main` |
| Formato comprimido | Instalar desde un archivo comprimido sin la extracción adecuada |

<Warning>
Si se instala de forma incorrecta, puede parecer que ComfyUI-Manager funciona, pero no será reconocido para las actualizaciones y puede provocar instalaciones duplicadas. Elimínalo y reinstálalo correctamente mediante `git clone`.
</Warning>

## Network issues

### GitHub access problems

If you have limited access to GitHub, set the `GITHUB_ENDPOINT` environment variable:

```bash
GITHUB_ENDPOINT=https://mirror.ghproxy.com/https://github.com
```

### Hugging Face access problems

If you have limited access to Hugging Face, set the `HF_ENDPOINT` environment variable:

```bash
HF_ENDPOINT=https://some-hf-mirror.com
```

## Solución de problemas del escáner

Al ejecutar el script `scan.sh`:

- Actualiza `extension-node-map.json` al traer o clonar los Nodos Personalizados listados en `custom-node-list.json` dentro de `~/.tmp/default`
- Actualiza `github-stats.json` usando la API de GitHub

| Opción | Descripción |
|--------|-------------|
| `--skip-update` | Saltar la actualización de extension-node-map.json |
| `--skip-stat-update` | Saltar la actualización de github-stats.json |
| `--skip-all` | Saltar ambos pasos de actualización |

<Tip>
Para evitar los límites de tasa de la API de GitHub, configura tu token: `export GITHUB_TOKEN=your_token_here`
</Tip>

Si quieres especificar una ruta diferente en lugar de `~/.tmp/default`, ejecuta `python scanner.py [path]` directamente en vez de `scan.sh`.

## Política de seguridad

Si encuentras el error `This action is not allowed with this security level configuration` al instalar nodos personalizados mediante git URL o al usar la versión nocturna, necesitas ajustar el nivel de seguridad en tu archivo `config.ini`.

El archivo `config.ini` se encuentra en:
- **ComfyUI v0.3.76+**: `<USER_DIRECTORY>/__manager/config.ini`
- **Versiones anteriores**: `<USER_DIRECTORY>/default/ComfyUI-Manager/config.ini`

Donde `<USER_DIRECTORY>` tiene como valor predeterminado `ComfyUI/user`. Consulta [Configuración](/es/manager/configuration) para más detalles.

Configura los niveles de seguridad en `config.ini`:

```ini
security_level = normal
```

| Nivel | Descripción |
|-------|-------------|
| `strong` | No permite funciones de riesgo alto ni medio |
| `normal` | No permite funciones de riesgo alto; las funciones de riesgo medio están disponibles |
| `normal-` | No permite funciones de riesgo alto si se especifica `--listen` y este no comienza con `127.`; las funciones de riesgo medio están disponibles |
| `weak` | Todas las funciones están disponibles |

### Niveles de riesgo de las funciones

| Nivel de riesgo | Funciones |
|------------|----------|
| **Alto** | Instalar mediante git url, pip install, instalación de nodos personalizados que no están en el canal predeterminado, reparar nodos personalizados |
| **Medio** | Desinstalar/Actualizar, instalación de nodos personalizados en el canal predeterminado, restaurar/eliminar snapshot, reiniciar |
| **Bajo** | Actualizar ComfyUI |

<Tip>
Para instalar nodos personalizados mediante git URL o versiones nocturnas, establece `security_level = weak` en tu `config.ini`.
</Tip>
