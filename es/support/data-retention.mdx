Esta página describe cómo Comfy conserva los datos de los clientes. Para consultar los términos legales completos que rigen tu uso de Comfy, consulta nuestros [Términos del servicio](https://www.comfy.org/terms-of-service?utm_source=docs) y nuestra [Política de privacidad](https://www.comfy.org/privacy-policy?utm_source=docs).

## Períodos de retención

| Tipo de datos | Descripción | Retención |
| --- | --- | --- |
| Datos de cuenta | Correo electrónico, perfil y detalles de la organización | Durante toda la vida de la cuenta |
| Contenido del cliente | Prompts, flujos de trabajo, salidas y otro contenido que crees o subas | Se conserva durante el tiempo necesario para operar, analizar y mejorar el servicio |
| Datos de analítica | Métricas agregadas y seudonimizadas sobre el uso y el rendimiento de la plataforma | Se conservan durante el tiempo necesario para operar, analizar y mejorar el servicio |
| Datos de eventos de comportamiento | Acciones dentro del producto, como clics, sesiones e interacciones con funciones | Se conservan durante el tiempo necesario para operar, analizar y mejorar el servicio |
| Datos de uso del producto | Ejecuciones de flujos de trabajo, metadatos de recursos y telemetría operativa | Se conservan durante el tiempo necesario para operar, analizar y mejorar el servicio |

## Solicitar la eliminación

<Note>
  Para solicitar la eliminación de tu cuenta o de los datos asociados, escribe a [support@comfy.org](mailto:support@comfy.org). Algunos registros pueden conservarse cuando sea necesario para cumplir obligaciones legales, de seguridad, de auditoría o de prevención de fraude.
</Note>

## Contenido multimedia de Partner Node

Las entradas y salidas de Partner Node se eliminan 24 horas después de almacenarse. Para más detalles, consulta [Retención de datos de Partner Node](/es/tutorials/partner-nodes/data-retention).
