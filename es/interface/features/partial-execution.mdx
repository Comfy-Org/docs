![Función de ejecución parcial](/images/interface/features/partial-execution/partial-execution-icon.jpg)

La función de ejecución parcial se encuentra en el cuadro de herramientas de selección de nodos de ComfyUI. Te permite ejecutar solo una parte de tu flujo de trabajo en lugar de ejecutar todos los nodos. Esta función solo está disponible cuando el nodo seleccionado es un nodo de salida y, cuando está disponible, aparece como un icono de triángulo azul.

## ¿Qué es la ejecución parcial?

La ejecución parcial, como su nombre indica, te permite ejecutar solo una parte de tu flujo de trabajo en lugar de ejecutar todos los nodos del flujo de trabajo.

![Ejecución parcial](/images/interface/features/partial-execution/partial-execution-vs-run-workflow.jpg)

El diagrama anterior compara la ejecución parcial con la ejecución de todo el flujo de trabajo:

1. Ejecución parcial (izquierda): solo ejecuta la rama del flujo de trabajo desde el nodo inicial hasta el nodo de salida.
2. Ejecutar flujo de trabajo (derecha): ejecuta todos los nodos del flujo de trabajo.

Esta función te permite ejecutar de forma flexible partes específicas de tu flujo de trabajo, en lugar de ejecutar todo el flujo de trabajo cada vez.

## ¿Cómo usar la función de ejecución parcial?

![Requisitos de la ejecución parcial](/images/interface/features/partial-execution/requirement.jpg)

Para usar la función de ejecución parcial, el nodo seleccionado actualmente debe ser un nodo de salida, como los nodos de vista previa o de guardado. Cuando el nodo correspondiente cumple con los criterios, después de seleccionarlo, el botón del cuadro de herramientas se mostrará como un icono de triángulo azul. Haz clic en este icono para ejecutar el flujo de trabajo parcial.

## Problemas comunes

Si la ejecución parcial parece ejecutar todo el gráfico, revisa primero la versión del frontend:
