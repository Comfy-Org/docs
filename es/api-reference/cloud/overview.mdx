<Warning>
  **API experimental:** Esta API es experimental y está sujeta a cambios. Los endpoints, los formatos de solicitud y respuesta, y el comportamiento pueden modificarse sin previo aviso.
</Warning>

La API de Comfy Cloud ofrece acceso programático para ejecutar flujos de trabajo en la infraestructura de Comfy Cloud.

<Note>
  **Suscripción requerida:** El acceso a la API está disponible en los planes **Standard**, **Creator** y **Pro**. El plan Free no incluye acceso a la API. Consulta los [planes de precios](https://www.comfy.org/cloud/pricing?utm_source=docs) para más detalles.
</Note>

## Primeros pasos

- [Referencia de la API](/es/development/cloud/api-reference): documentación completa de los endpoints con ejemplos de código

## Categorías de endpoints

| Categoría | Descripción |
|----------|-------------|
| Flujo de trabajo | Enviar flujos de trabajo para su ejecución |
| Tarea | Monitorear el estado de las tareas y administrar la cola |
| Recurso | Subir y descargar archivos |
| Modelo | Explorar los modelos de IA disponibles |
| Nodo | Obtener información sobre los nodos disponibles |
| Usuario | Información de la cuenta y datos personales |
| Sistema | Estado del servidor y comprobaciones de salud |
