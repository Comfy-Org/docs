**Stable Audio 1.0** es el primer modelo de generación de audio de código abierto de Stability AI. Recibe un prompt de texto y genera un clip de audio. En ComfyUI funciona como un pipeline estándar de texto a audio: CLIP codifica el prompt, un KSampler aplica denoise al latente y el VAE lo decodifica a audio.

**Enlaces relacionados**:
- [Hugging Face (stabilityai/stable-audio-open-1.0)](https://huggingface.co/stabilityai/stable-audio-open-1.0)

El flujo de trabajo usa **nodos estándar de ComfyUI**: no necesitas nodos personalizados. Carga el checkpoint de Stable Audio 1.0, codifica tu prompt mediante un codificador de texto CLIP (t5-base), aplica denoising al audio latente con un KSampler y lo decodifica a audio mediante el VAE del modelo.

**Cómo usarlo**:
1. **Carga el checkpoint**: el nodo `CheckpointLoaderSimple` usa `stable-audio-open-1.0.safetensors`
2. **Escribe un prompt**: introduce tu descripción en el nodo `CLIPTextEncode` (por ejemplo, "heaven church electronic dance music")
3. **Establece la duración**: ajusta el valor de longitud del nodo `EmptyLatentAudio` (47.6 segundos por defecto)
4. Haz clic en **Run** (`Ctrl/Cmd + Enter`) para generar. El audio se guardará en `ComfyUI/output/audio/`

## Descargar el modelo

Al cargar el flujo de trabajo, ComfyUI te mostrará enlaces de descarga para los modelos faltantes. Para configurarlo manualmente, descarga los archivos a continuación y colócalos en las carpetas correctas.

### Checkpoint

<Card title="stable-audio-open-1.0.safetensors" icon="download" href="https://huggingface.co/StabilityAI/stable-audio-open-1.0/blob/main/stable-audio-open-1.0.safetensors">
    2.3GB. Colócalo en models/checkpoints/
  </Card>

Coloca el checkpoint en:

```
📂 ComfyUI/
├── 📂 models/
│   └── 📂 checkpoints/
│       └── stable-audio-open-1.0.safetensors
```

### Codificador de texto

<Card title="t5-base.safetensors" icon="download" href="https://huggingface.co/Comfy-Org/t5-base/blob/main/t5-base.safetensors">
    Codificador de texto para el acondicionamiento del prompt. Colócalo en models/text_encoders/
  </Card>

Coloca el codificador de texto en:

```
📂 ComfyUI/
├── 📂 models/
│   └── 📂 text_encoders/
│       └── t5-base.safetensors
```

Después de colocar los archivos, presiona **R** en ComfyUI para actualizar los nodos y cargar los últimos modelos.
