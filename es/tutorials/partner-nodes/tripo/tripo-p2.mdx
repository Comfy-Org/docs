Tripo P2 es el modelo de generación 3D de la serie P de Tripo que produce mallas con topología de cuádruples nativa. Mientras que los modelos tradicionales de texto a 3D e imagen a 3D devuelven mallas de triángulos, Tripo P2 construye la geometría a partir de caras de cuatro lados, con bucles de aristas limpios alrededor de las articulaciones y una densidad uniforme en las superficies planas. Los cuádruples se deforman de forma predecible bajo un rig, se subdividen sin problemas y son la entrada estándar de los flujos de trabajo con mucha retopología en videojuegos, cine y visualización de productos.

Tripo P2 admite tres modos de entrada: texto a modelo, una sola imagen a modelo y multivista a modelo (referencias de frente, izquierda, atrás y derecha). El presupuesto de malla llega a 50,000 triángulos, o 25,000 cuádruples en modo cuádruple. La salida de texturas va por niveles: Estándar en 2K, Detallado en 4K, Extremo en 8K, con mapas PBR (metálico, rugosidad, normal) disponibles junto con el color base.

En ComfyUI, los nodos P2 funcionan como el resto de los Nodos asociados de Tripo: agrega el nodo, proporciona tu entrada y el flujo de trabajo se encarga del texturizado, el rigging, la conversión y la exportación de forma automática. No se requiere una GPU local ni descargar el modelo.

## En qué destaca Tripo P2

- **Topología de quads nativa**: mallas de quads con un flujo de aristas limpio, listas para rigging y animación sin retopología manual
- **Presupuestos de malla amplios**: de 48 a 50,000 triángulos, o de 48 a 25,000 quads en modo quad
- **Texturizado por niveles**: texturas de color base estándar (2K), detalladas (4K) o extremas (8K), con mapas PBR opcionales
- **Tres modos de entrada**: prompts de texto, una única imagen de referencia o hasta cuatro imágenes multivista (frente, izquierda, atrás, derecha)

El precio depende del nivel de texturizado seleccionado. Consulta [Precios](/es/tutorials/partner-nodes/pricing) para ver los detalles.

## Tripo P2: Texto a modelo

Genera un modelo 3D a partir de una descripción de texto. Tripo P2 primero dibuja una imagen conceptual a partir del prompt (controlada por `image_seed`) y luego modela la geometría a partir de ella.

### Pasos para ejecutar

1. **Ingresa tu prompt**: describe el modelo 3D en el nodo **Tripo P2: Text to Model** (hasta 1024 caracteres). Hay un prompt negativo disponible en las opciones avanzadas
2. **Elige el nivel de textura**: `standard` (2K), `detailed` (4K), `extreme` (8K) o `none` para una malla sin textura
3. **Activa la salida quad**: con `quad` habilitado, la malla se devuelve como FBX; deshabilitado, se devuelve como GLB
4. **Establece el límite de caras**: el recuento objetivo de caras entre 48 y 50,000 (48 a 25,000 con quad), o déjalo en -1 para que Tripo elija
5. **Haz clic en Queue**: presiona `Ctrl+Enter` para generar

Después de la generación, el nodo solicita el nivel de textura que seleccionaste, así que la malla se texturiza como parte de la generación, y el flujo de trabajo guarda ese resultado directamente (la salida GLB, o FBX cuando `quad` está activado). La plantilla también contiene los nodos **TripoTextureNodeV2**, **TripoRigNode**, **TripoRetargetNode** y **TripoConversionNode**, pero están omitidos y desconectados de forma predeterminada: conéctalos y habilítalos (`Ctrl+B` activa o desactiva Omitir) cuando quieras ese posprocesamiento adicional.

### Nota sobre la salida quad

Cuando `quad` está habilitado, conecta **Save 3D** a la ranura de salida FBX. Cuando `quad` está deshabilitado, usa la ranura de salida GLB.

### Pasos para ejecutar

1. **Sube una imagen de referencia**: carga una imagen de vista frontal de tu sujeto con el nodo **LoadImage**
2. **Elige el nivel de textura**: `standard`, `detailed`, `extreme` o `none`
3. **Alterna la salida quad**: FBX cuando está activada, GLB cuando está desactivada
4. **Configura la alineación de textura**: `original_image` coincide con los colores de la imagen de entrada, `geometry` ajusta las texturas a la forma generada (opciones avanzadas)
5. **Haz clic en Queue**: presiona `Ctrl+Enter` para generar

### Consejos de entrada

- Puedes mejorar las imágenes de baja resolución o baja calidad antes del modelado con la opción avanzada `enable_image_autofix`
- La orientación de `align_image` gira el modelo al punto de vista de la imagen de entrada (opciones avanzadas)

## Tripo P2: de multivista a modelo

Genera un modelo 3D a partir de vistas de referencia. El nodo multivista requiere una vista frontal y hasta tres de las vistas izquierda, trasera y derecha, y al menos una de esas vistas adicionales debe estar conectada: con solo la vista frontal, el nodo devuelve un error. Reconstruye la geometría con la misma topología nativa de quads que los demás nodos P2.

### Pasos para ejecutar

1. **Carga las vistas de referencia**: la plantilla incluye una vista frontal (nodo `LoadImage` 16) y una vista trasera (nodo `LoadImage` 19). El nodo también expone las entradas `image_left` e `image_right` para una reconstrucción de cuatro vistas
2. **Elige el nivel de textura**: `standard` (2K), `detailed` (4K), `extreme` (8K) o `none` para una malla sin textura
3. **Alterna la salida de quads**: con `quad` activado, el nodo devuelve la malla en FBX; desactivado, en GLB
4. **Define el límite de caras**: una cantidad objetivo de caras entre 48 y 50,000 (de 48 a 25,000 con quad), o déjalo en -1 para que Tripo elija
5. **Haz clic en Queue**: presiona `Ctrl+Enter` para generar

El flujo de trabajo guarda la malla generada directamente. Los nodos de textura, rig, retarget y conversión que la plantilla también contiene están omitidos y desconectados de forma predeterminada.

## Referencia de opciones de nodo

Opciones compartidas por los tres nodos P2:

| Opción | Valores | Predeterminado | Notas |
| ------ | ------ | ------- | ----- |
| `quad` | on / off | off | Malla quad como FBX cuando está activado, malla triangular como GLB cuando está desactivado |
| `face_limit` | 48 a 50,000 (25,000 con quad) | -1 | Recuento objetivo de caras; el resultado puede superarlo |
| `texture` | standard / detailed / extreme / none | standard | Color base 2K / 4K / 8K; none devuelve una malla sin textura |
| `pbr` | on / off | on | Mapas metálicos, de rugosidad y normales; se ignora cuando texture es none |
| `model_seed` | 0 a 2147483647 | 42 | Semilla para la geometría |

Las opciones avanzadas incluyen `texture_seed`, `auto_size` (escala del mundo real en metros), `export_uv` y `compress_geometry` (compresión Meshopt; las mallas comprimidas son mucho más pequeñas, pero no es posible previsualizarlas en el visor 3D de ComfyUI).
