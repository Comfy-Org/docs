GPT Image 2.6 es la familia de modelos de imagen de OpenAI, disponible en ComfyUI en el nodo socio **OpenAI GPT Image 2.6**. Viene en dos variantes:

- **Flare** (`gpt-image-2.6-flare`): devuelve un borrador en segundos y mantiene la composición sobre carteles densos y fotos de producto. Úsala para primeras pasadas de concepto, mood boards y borradores con mucha tipografía
- **Sunburst** (`gpt-image-2.6-sunburst`): invierte su presupuesto de render en textura fina, tipografía pequeña y materiales, y mantiene sujetos e iluminación consistentes entre pasadas. Úsala para visuales finalizados y composiciones densas donde el detalle tiene que resistir

Ambas variantes hacen texto a imagen y edición de imagen, con hasta 16 imágenes de referencia, una capa de anotación opcional para ediciones locales, niveles de calidad de `low` a `max` y un control de `complexity` que define cuánto planifica la imagen el modelo antes de renderizar. El nodo devuelve una imagen por ejecución. El nodo **OpenAI GPT Image** ofrece las mismas variantes 2.6 y 2.5 con `n` hasta 8 e inpainting con máscara, y es donde se seleccionan GPT Image 2 y GPT Image 1.5.

## Primeros pasos

1. Actualiza ComfyUI a una versión posterior a 0.44.2. Las versiones anteriores no incluyen la capa de anotación ni los nodos GIF y SVG
2. En la Biblioteca de nodos, busca **OpenAI GPT Image 2.6** y agrega el nodo
3. Establece `model` en `gpt-image-2.6-flare` o `gpt-image-2.6-sunburst`
4. Conecta la salida de imagen del nodo a un nodo Guardar Imagen, o abre una de las cuatro plantillas que aparecen a continuación

## Configuraciones del nodo

- **modelo**: `gpt-image-2.6-flare` para iterar rápido, `gpt-image-2.6-sunburst` para renders que priorizan el detalle
- **prompt**: qué generar, o la instrucción de edición cuando hay imágenes de referencia conectadas
- **tamaño**: `auto`, un preset como `1024x1024` o `3840x2160`, o `Custom`
- **custom_width / custom_height**: se usan solo cuando `size` es `Custom`, de 480 a 3840 en pasos de 16
- **fondo**: `auto`, `opaque` o `transparent`
- **calidad**: `low`, `medium`, `high`, `xhigh` o `max`. Afecta el costo y el tiempo de generación
- **complejidad**: `low`, `medium` o `high` (predeterminado). Cuánto planifica el modelo la imagen antes de renderizarla
- **imágenes**: imágenes de referencia opcionales para edición, hasta 16
- **markup / markup_alpha**: capa de anotación opcional para ediciones locales. Conecta a `markup` una imagen dibujada sobre la primera imagen de referencia y a `markup_alpha` una máscara donde el blanco marca las áreas que quieres cambiar. Conecta las dos o ninguna, y ambas deben tener el mismo tamaño que la imagen de referencia. La salida de máscara del nodo Painter sirve directamente en `markup_alpha`
- **semilla**: se conserva por compatibilidad con la API, el backend todavía no la usa

Flare es la forma más económica de encontrar un prompt que funcione. Ejecútalo con calidad `low` o `medium` hasta que la composición quede bien y, después, vuelve a ejecutar el prompt ganador en Sunburst para obtener la imagen final.

## GPT Image 2.6 GIF: salida animada

El nodo **OpenAI GPT Image 2.6 GIF** genera un GIF animado a partir de un prompt y devuelve sus fotogramas y la tasa de fotogramas. Conecta `frames` y `fps` a **Save Animated WEBP**, **Save Animated PNG** o **Save WEBM** para escribir el archivo.

- **model**: `gpt-image-2.6-flare` o `gpt-image-2.6-sunburst`
- **size**: 12 tamaños de fotograma desde `384x384` hasta `1280x720` o `720x1280`, `512x512` por defecto. Los tamaños mayores solo admiten menos fotogramas
- **frame_count**: de 2 a 16 fotogramas, 9 por defecto. La facturación va por tramos: 2-8, 9, 10-12, 13-16
- **frame_duration_ms**: cuánto permanece cada fotograma en pantalla, de 20 a 2000 ms, 200 por defecto. `fps` se calcula a partir de este valor: 200 ms son 5 fps
- **background**: `opaque` o `transparent`. La transparencia se conserva en Save Animated WEBP, Save Animated PNG y Save WEBM con vp9
- **quality** y **complexity**: calidad de cada fotograma y cuánto planifica el modelo la animación
- **seed**: controla si el nodo se vuelve a ejecutar; el resultado no es determinista independientemente del seed

## GPT Image 2.6 SVG: salida vectorial

El nodo **OpenAI GPT Image 2.6 SVG** genera un SVG editable a partir de un prompt. El resultado es marcado vectorial, así que las formas y el texto siguen siendo editables en un editor vectorial. Conecta su salida `svg` a **Save SVG** para escribir el archivo `.svg`.

- **model**: `gpt-image-2.6-flare` o `gpt-image-2.6-sunburst`
- **size**: `1024x1024`, `1024x1536` o `1536x1024`
- **background**: `auto`, `opaque` o `transparent`
- **quality** y **complexity**: calidad de la imagen de referencia a partir de la cual se dibuja el SVG y cuánto la planifica el modelo
- **seed**: controla si el nodo se vuelve a ejecutar; el resultado no es determinista independientemente del seed
