**Tencent HY4** es el modelo de lenguaje grande de Tencent, disponible en ComfyUI a través del nodo socio `Tencent HY`. El nodo recibe un prompt de texto y hasta 20 imágenes, y devuelve texto: un prompt artístico escrito a partir de una imagen de referencia, una descripción de imagen, un desglose de gráfico o cualquier otra respuesta que pidas.

Hy4 se lanzó el 4 de noviembre de 2026. Es la primera generación Hy con comprensión visual, y Tencent reporta mejoras sobre Hy4 preview en el seguimiento de instrucciones, la comprensión de contexto largo y las tareas agénticas de horizonte largo. El nodo llama al modelo a través de Comfy API, así que no se requieren descargas de modelos ni una GPU local.

La plantilla que se cubre aquí es el ejemplo image to prompt: lee una foto y escribe un prompt separado por comas que puedes pegar en un modelo de imagen.

## Para qué sirve el nodo Tencent HY

- **De imagen a prompt**: escribe un prompt estructurado que cubre sujeto, composición, cámara, iluminación, color, textura y estilo
- **Comprensión de imágenes**: descripciones, desglose de gráficos y diagramas, y revisión de detalles finos en fotos, capturas de pantalla y documentos
- **Varias imágenes por solicitud**: hasta 20 imágenes en una sola llamada, donde cada imagen de un lote cuenta una vez
- **Control por instrucciones**: `system_prompt` mantiene un rol permanente, mientras que `prompt` lleva la tarea de esta ejecución
- **Alternar el razonamiento**: `reasoning` hace que el modelo piense antes de responder, para las tareas que lo necesitan
- **Respuestas largas**: `max_tokens` acepta hasta 64000 tokens

### Pasos para ejecutar el flujo de trabajo

1. Carga tu imagen en el nodo `LoadImage`. El flujo de trabajo descargado hace referencia a `blue_poppies_field.png` por su nombre, así que el nodo queda vacío hasta que subas ese archivo
2. Edita el nodo `Text (User Prompt)`. Su texto se envía al modelo como `prompt`, y la plantilla ya pide un prompt positivo separado por comas y nada más. Reescríbelo para otras salidas, por ejemplo `Describe this chart and list the trends it shows`
3. (Opcional) Activa `reasoning` para tareas que requieren razonamiento paso a paso. Las respuestas tardan más y consumen más tokens
4. (Opcional) Aumenta `max_tokens` desde el valor predeterminado `32000` (hasta `64000`) para respuestas largas, o cambia `temperature` desde `1.0` (rango de 0 a 1.4) para obtener menos o más variedad
5. Haz clic en `Run` o presiona `Ctrl(cmd) + Enter`
6. Lee la respuesta en `Preview Any`. `Save Text` escribe el prompt y la respuesta en un archivo `.txt` dentro de `output/Hy4/`

### Consejos para los prompts

- Indica el formato de salida. La línea de la plantilla `Only output positive prompt, no extra explanations` es lo que mantiene la respuesta lista para pegar
- Cuando conectes varias imágenes, refiérete a ellas en orden (`the first image`, `the second image`) para que los detalles correspondan a la imagen correcta
- Coloca las instrucciones repetidas en `system_prompt` y deja `prompt` para la tarea, por ejemplo `You write photography prompts for a stock library`
- La `seed` solo decide si el nodo se vuelve a ejecutar. Las respuestas siguen variando entre ejecuciones

## Empezar

1. Actualiza ComfyUI a la última versión
2. Ve a la Biblioteca de plantillas y busca `Tencent: Hy4`
3. Abre el flujo de trabajo de imagen a prompt y ejecútalo

Tencent HY4 factura según el consumo de tokens de la API. Consulta la [tabla de precios](/es/tutorials/partner-nodes/pricing) para conocer las tarifas de Hy4.
