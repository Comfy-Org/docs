**TRELLIS.2** es un modelo de código abierto de imagen a 3D de Microsoft Research y el sucesor de TRELLIS. Es un modelo de 4B parámetros construido sobre VAE 3D nativos con compresión espacial de 16× y una representación de vóxeles dispersos llamada O-Voxel, que produce recursos 3D detallados con materiales PBR completos a partir de una sola imagen.

TRELLIS.2 comparte su arquitectura base con Pixal3D: ambos usan el mismo codificador de imágenes DINOv3, los mismos VAE de forma y textura, y las mismas etapas de generación de estructura, forma y textura. Solo difieren el modelo de difusión principal y el formato de acondicionamiento. Si ya has ejecutado el [flujo de trabajo de Pixal3D](/es/tutorials/3d/pixal3d), la configuración del modelo es casi idéntica.

### TRELLIS.2: modelo 3D a partir de una imagen {#trellis2}

Sube una sola imagen. Genera un modelo 3D de alta fidelidad con texturas PBR completas usando TRELLIS.2.

Este flujo de trabajo también incluye el pipeline de Pixal3D. Para ejecutar TRELLIS.2, establece el nodo `Boolean (Switch to Trellis2)` en `true`. El flujo de trabajo cambia automáticamente al modelo TRELLIS.2 y a su acondicionamiento.

## Cómo funciona

TRELLIS.2 genera un recurso 3D en tres etapas de difusión y después ejecuta un pipeline completo de posprocesamiento de la malla:

1. **Eliminación de fondo**: BiRefNet elimina el fondo de la imagen de entrada y el flujo de trabajo recorta el sujeto a un lienzo centrado. Un interruptor te permite saltar la eliminación de fondo
2. **Generación de estructura**: se muestrea un latente de estructura dispersa y se decodifica en vóxeles, que luego se convierten en una malla aproximada
3. **Refinamiento de forma**: la etapa de forma y la etapa de upsampling refinan la malla hasta la resolución objetivo (1536)
4. **Generación de textura**: una etapa de difusión de textura produce vóxeles de material PBR (color base, metalicidad, rugosidad)
5. **Posprocesamiento**: DC remesh, QEM decimation, UV unwrapping y baking de mapas de color base, normal y oclusión ambiental en la malla texturizada final

## Pasos para ejecutar

1. **Carga una imagen**: usa el nodo `LoadImage` para cargar una sola imagen del objeto
2. **Cambia al pipeline de TRELLIS.2**: establece `Boolean (Switch to Trellis2)` en `true`. El flujo de trabajo carga el checkpoint de TRELLIS.2 automáticamente
3. **Envía el flujo de trabajo a la cola**: presiona Ctrl (Cmd en macOS) + Enter
4. **Espera a que termine el pipeline**: las etapas de estructura, forma y textura se ejecutan en secuencia, seguidas del posprocesamiento
5. **Revisa el resultado**: inspecciona la malla en el nodo `Preview3DAdvanced`. El modelo 3D se guarda en `ComfyUI/output/3d/ComfyUI/`
