# Introducción a Hunyuan3D 2.0

![Hunyuan 3D 2](https://raw.githubusercontent.com/Tencent/Hunyuan3D-2/main/assets/images/e2e-1.gif)
![Hunyuan 3D 2](https://raw.githubusercontent.com/Tencent/Hunyuan3D-2/main/assets/images/e2e-2.gif)
[Hunyuan3D 2.0](https://github.com/Tencent/Hunyuan3D-2) es un modelo de generación de recursos 3D de código abierto publicado por Tencent, capaz de generar modelos 3D de alta fidelidad con mapas de textura de alta resolución a partir de texto o imágenes.

Hunyuan3D 2.0 adopta un enfoque de generación en dos etapas: primero genera un modelo de geometría sin texturas y después sintetiza mapas de textura de alta resolución. Así separa de forma efectiva la complejidad de la generación de forma y de textura. A continuación se presentan los dos componentes principales de Hunyuan3D 2.0:

1. **Modelo de generación de geometría (Hunyuan3D-DiT)**: basado en una arquitectura Transformer de difusión por flujo, genera modelos geométricos sin textura que coinciden con precisión con las condiciones de entrada.
2. **Modelo de generación de texturas (Hunyuan3D-Paint)**: combina condiciones geométricas y técnicas de difusión multivista para añadir texturas de alta resolución a los modelos, con soporte para materiales PBR.

**Ventajas principales**

- **Generación de alta precisión**: estructuras geométricas nítidas, colores de textura ricos, soporte para la generación de materiales PBR y efectos de iluminación casi realistas.
- **Diversas formas de uso**: ofrece llamadas desde código, plugins de Blender, aplicaciones Gradio y experiencia en línea a través del sitio web oficial, adecuado para distintas necesidades de los usuarios.
- **Ligero y compatible**: el modelo Hunyuan3D-2mini solo requiere 5GB de VRAM, la versión estándar necesita 6GB de VRAM para la generación de forma y el proceso completo (forma + textura) requiere solo 12GB de VRAM.

Recientemente (18 de marzo de 2025), Hunyuan3D 2.0 también presentó un modelo de generación de forma multivista (Hunyuan3D-2mv), que permite generar estructuras geométricas más detalladas a partir de entradas desde distintos ángulos.

Este ejemplo incluye cuatro flujos de trabajo:
- Usar Hunyuan3D-2mv con múltiples entradas de vista para generar modelos 3D
- Usar Hunyuan3D-2mv-turbo con múltiples entradas de vista para generar modelos 3D
- Usar Hunyuan3D-2 con una sola entrada de vista para generar modelos 3D
- Usar Hunyuan3D 2.1 con una sola entrada de vista para generar modelos 3D

<Tip>
ComfyUI ahora tiene soporte nativo para Hunyuan3D-2mv, pero todavía no soporta la generación de texturas ni de materiales. Asegúrate de haber actualizado a la última versión de [ComfyUI](https://github.com/Comfy-Org/ComfyUI) antes de comenzar.

Las imágenes PNG de ejemplo de los flujos de trabajo en este tutorial contienen el JSON del flujo de trabajo en sus metadatos:
- Puedes arrastrarlas directamente a ComfyUI
- O usar el menú `Workflows` -> `Open (ctrl+o)`

Esto cargará el flujo de trabajo correspondiente y te pedirá que descargues los modelos requeridos. Los modelos generados en formato `.glb` se guardarán en la carpeta `ComfyUI/output/mesh`.
</Tip>

### 3. Pasos para ejecutar el flujo de trabajo

![ComfyUI hunyuan3d_2mv](/images/tutorial/3d/hunyuan3d-2mv/hunyuan3d_2mv.jpg)

1. Asegúrate de que el Image Only Checkpoint Loader (modelo img2vid) haya cargado nuestro modelo `hunyuan3d-dit-v2-mv.safetensors` descargado y renombrado
2. Carga las imágenes de vista correspondientes en cada nodo `Load Image`
3. Haz clic en el botón `Queue` o usa el atajo `Ctrl(cmd) + Enter` para ejecutar el flujo de trabajo

Si necesitas añadir más vistas, asegúrate de cargar las otras imágenes de vista en el nodo `Hunyuan3Dv2ConditioningMultiView` y de cargar las imágenes de vista correspondientes en los nodos `Load Image`.

## Flujo de trabajo Hunyuan3D-2mv-turbo

En el flujo de trabajo Hunyuan3D-2mv-turbo, usaremos el modelo Hunyuan3D-2mv-turbo para generar modelos 3D. Este modelo es una versión con destilación por pasos de Hunyuan3D-2mv, lo que permite generar modelos 3D más rápido. En esta versión del flujo de trabajo, establecemos `cfg` en 1.0 y añadimos un nodo `flux guidance` para controlar la generación con `distilled cfg`.
