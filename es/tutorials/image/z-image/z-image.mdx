**Z-Image (造相)** es un modelo de generación de imágenes potente y altamente eficiente con **6B** parámetros, desarrollado por Tongyi Lab de Alibaba. Utiliza una arquitectura **Scalable Single-Stream DiT** (S3-DiT), en la que los tokens de texto, los tokens semánticos visuales y los tokens VAE de imagen se concatenan a nivel de secuencia para formar un flujo de entrada unificado, lo que maximiza la eficiencia de los parámetros.

Z-Image (Base) es el modelo base no destilado diseñado para el ajuste fino impulsado por la comunidad y el desarrollo personalizado.

**Puntos destacados del modelo**:
- **Calidad fotorrealista**: ofrece una potente generación de imágenes fotorrealistas y mantiene una excelente calidad estética.
- **Renderizado de texto bilingüe preciso**: destaca por renderizar con precisión texto complejo en chino e inglés.
- **Mejora de prompt y razonamiento**: Prompt Enhancer dota al modelo de capacidades de razonamiento.
- **Listo para ajuste fino**: modelo base ideal para entrenamiento personalizado y adaptación.
