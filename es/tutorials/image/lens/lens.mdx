**Lens** es un modelo de texto a imagen abierto de **Microsoft**, con licencia MIT. Con **3800 millones** de parámetros, usa una arquitectura **MMDiT de doble flujo** con características del codificador de texto **GPT-OSS-20B** y el **VAE semántico de FLUX.2** para ofrecer una calidad de imagen competitiva con mucho menos cómputo de entrenamiento que modelos T2I más grandes.

**Aspectos destacados del modelo**:
- **Arquitectura MMDiT de doble flujo**: procesamiento conjunto de imagen y texto para una generación coherente
- **Características de texto multicapa de GPT-OSS-20B**: comprensión avanzada del texto para seguir con precisión el prompt
- **VAE semántico de FLUX.2**: representación latente de alta fidelidad
- **Entrenamiento con resolución mixta**: admite varias relaciones de aspecto sin recortar
- **Tamaño compacto de 3.8B**: se ejecuta en GPU de consumo con 24 GB de VRAM

**Enlaces relacionados**:
- [Artículo (arXiv)](https://arxiv.org/abs/2605.21573)
- [GitHub](https://github.com/microsoft/Lens)
- [Hugging Face (Microsoft)](https://huggingface.co/microsoft/Lens)
- [Hugging Face (Comfy-Org)](https://huggingface.co/Comfy-Org/Lens)

## Flujo de trabajo de texto a imagen de Lens

Tanto la variante estándar como la Turbo usan un nodo **Subgraph** para gestionar el pipeline de generación de texto a imagen. Puedes abrir el subgrafo para inspeccionar o personalizar los nodos internos.
