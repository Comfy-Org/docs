**Anima** es un modelo abierto de texto a imagen de [CircleStone Labs](https://huggingface.co/circlestone-labs/Anima) en colaboración con Comfy Org. Con **2 mil millones** de parámetros, está diseñado para generar imágenes de **anime y no fotorrealistas** de alta calidad, ideales para personajes, escenas y arte conceptual.

**Aspectos destacados del modelo**:
- **Enfoque en anime e ilustración artística**: ajustado para estilos de arte no fotorrealistas
- **Compatibilidad nativa con ComfyUI**: se carga con los nodos estándar UNETLoader, CLIPLoader y VAELoader
- **Codificador de texto Qwen-3 0.6B**: ofrece una sólida comprensión del lenguaje y adherencia al prompt
- **No se necesita imagen de entrada**: generación pura de texto a imagen
- **Tamaño compacto**: modelo de diffusion de 2B, funciona sin problemas en GPUs de consumo

**Enlaces relacionados**:
- [Hugging Face (Anima)](https://huggingface.co/circlestone-labs/Anima)

## Flujos de trabajo disponibles

Anima ofrece dos flujos de trabajo: la versión base para uso estándar y una versión preliminar para acceso anticipado.

Ambos flujos de trabajo usan un nodo **Subgraph** para gestionar el pipeline de generación de texto a imagen. Puedes abrir el subgraph para inspeccionar o personalizar los nodos internos.

## Limitaciones

- **Sin realismo**: el modelo está diseñado intencionalmente para estilos de anime e ilustración; las representaciones realistas quedan fuera de su alcance
- **Renderizado de texto deficiente**: el texto en alta resolución y la tipografía compleja pueden no verse con claridad
- **Estilo sencillo**: el modelo base produce composiciones más simples; los estilos artísticos avanzados pueden requerir refinamiento o ajuste fino
