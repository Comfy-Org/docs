**Qwen-Image** es el primer modelo fundacional de generación de imágenes publicado por el equipo Qwen de Alibaba. Es un modelo MMDiT (Multimodal Diffusion Transformer) de 20B de parámetros, de código abierto bajo la licencia Apache 2.0. El modelo ha logrado avances significativos en el **renderizado de texto complejo** y la **edición precisa de imágenes**, alcanzando una salida de alta fidelidad en varios idiomas, incluidos el inglés y el chino.

**Aspectos destacados del modelo**:
- **Excelente renderizado de texto multilingüe**: admite la generación de texto de alta precisión en varios idiomas, incluidos inglés, chino, coreano y japonés, manteniendo los detalles tipográficos y la consistencia del diseño
- **Estilos artísticos diversos**: desde escenas fotorrealistas hasta pinturas impresionistas, desde la estética anime hasta el diseño minimalista, adaptándose con fluidez a distintos prompts creativos

**Enlaces relacionados**:
 - [GitHub](https://github.com/QwenLM/Qwen-Image)
 - [Hugging Face](https://huggingface.co/Qwen/Qwen-Image)
 - [ModelScope](https://modelscope.cn/models/qwen/Qwen-Image)

Actualmente, Qwen-Image tiene disponibles varias opciones de soporte para ControlNet:
- [Qwen-Image-DiffSynth-ControlNets/model_patches](https://huggingface.co/Comfy-Org/Qwen-Image-DiffSynth-ControlNets/tree/main/split_files/model_patches): incluye modelos canny, de profundidad e inpaint
- [qwen_image_union_diffsynth_lora.safetensors](https://huggingface.co/Comfy-Org/Qwen-Image-DiffSynth-ControlNets/blob/main/split_files/loras/qwen_image_union_diffsynth_lora.safetensors): LoRA de control de la estructura de la imagen compatible con canny, profundidad, pose, arte lineal, softedge, normal y openpose
- InstantX ControlNet: pendiente de actualización

### 3. Instrucciones del flujo de trabajo

![Guía paso a paso](/images/tutorial/image/qwen/image_qwen_image-guide.jpg)

1. Asegúrate de que el nodo `Load Diffusion Model` haya cargado `qwen_image_fp8_e4m3fn.safetensors`
2. Asegúrate de que el nodo `Load CLIP` haya cargado `qwen_2.5_vl_7b_fp8_scaled.safetensors`
3. Asegúrate de que el nodo `Load VAE` haya cargado `qwen_image_vae.safetensors`
4. Asegúrate de que el nodo `EmptySD3LatentImage` tenga configuradas las dimensiones de imagen correctas
5. Configura tu prompt en el nodo `CLIP Text Encoder`; actualmente admite al menos inglés, chino, coreano, japonés, italiano, etc.
6. Si quieres habilitar el LoRA de aceleración de 8 pasos de lightx2v, selecciona el nodo y usa `Ctrl + B` para habilitarlo, y modifica las configuraciones del KSampler como se describe en el paso 8
7. Haz clic en el botón `Queue`, o usa el atajo `Ctrl(cmd) + Enter` para ejecutar el flujo de trabajo
8. Para las diferentes versiones de modelos y flujos de trabajo, ajusta los parámetros del KSampler en consecuencia

<Note>
 El modelo destilado y el LoRA de aceleración de 8 pasos de lightx2v no parecen ser compatibles para usarlos de forma simultánea. Puedes probar distintas combinaciones para comprobar si funcionan juntos.
</Note>

### 3. Instrucciones de uso del flujo de trabajo

Actualmente, diffsynth tiene tres modelos de parche: Canny, Profundidad y Relleno inteligente.

Si es la primera vez que usas flujos de trabajo relacionados con ControlNet, debes saber que las imágenes de control deben preprocesarse a formatos de imagen compatibles antes de que el modelo pueda usarlas y reconocerlas.

![Diagrama de tipos de entrada](/images/tutorial/image/qwen/controlnet_input_types.jpg)

- Canny: borde Canny procesado, contornos de line art
- Profundidad: mapa de profundidad preprocesado que muestra las relaciones espaciales
- Relleno inteligente: requiere usar una máscara para marcar las áreas que se deben repintar

Como este modelo de parche se divide en tres modelos diferentes, debes seleccionar el tipo de preprocesamiento correcto al introducir la imagen para garantizar un preprocesamiento adecuado de la misma.

**Instrucciones de uso de ControlNet con el modelo Canny**

![Flujo de trabajo con Canny](/images/tutorial/image/qwen/image_qwen_image_controlnet_patch-canny.jpg)
1. Asegúrate de que `qwen_image_canny_diffsynth_controlnet.safetensors` esté cargado
2. Sube la imagen de entrada para el procesamiento posterior
3. El nodo Canny es un nodo de preprocesamiento nativo que preprocesa la imagen de entrada según los parámetros que definas para controlar la generación
4. Si lo necesitas, puedes modificar `strength` en el nodo `QwenImageDiffsynthControlnet` para controlar la intensidad del control de line art
5. Haz clic en el botón `Run` o usa el atajo `Ctrl(cmd) + Enter` para ejecutar el flujo de trabajo

> Para usar qwen_image_depth_diffsynth_controlnet.safetensors, debes preprocesar la imagen a un mapa de profundidad y reemplazar la parte de `image processing`. Para este uso, consulta el método de procesamiento de InstantX en este documento. Las demás partes son similares al uso del modelo Canny.

**Instrucciones de uso de ControlNet con el modelo de relleno inteligente**
![Flujo de trabajo de relleno inteligente](/images/tutorial/image/qwen/image_qwen_image_controlnet_patch-inpaint.jpg)

El modelo de relleno inteligente requiere usar el [Editor de máscara](/es/interface/maskeditor) para dibujar una máscara y usarla como condición de control de entrada.

1. Asegúrate de que `ModelPatchLoader` cargue el modelo `qwen_image_inpaint_diffsynth_controlnet.safetensors`
2. Sube la imagen y usa el [Editor de máscara](/es/interface/maskeditor) para dibujar una máscara. Debes conectar la salida `mask` del nodo `Load Image` correspondiente a la entrada `mask` de `QwenImageDiffsynthControlnet` para asegurar que se cargue la máscara correspondiente
3. Usa el atajo `Ctrl-B` para poner el Canny original del flujo de trabajo en modo Omitir, de modo que el procesamiento del nodo Canny correspondiente no tenga efecto
4. En `CLIP Text Encoder`, escribe aquello a lo que quieres cambiar el área enmascarada
5. Si lo necesitas, puedes modificar `strength` en el nodo `QwenImageDiffsynthControlnet` para controlar la intensidad de control correspondiente
6. Haz clic en el botón `Run` o usa el atajo `Ctrl(cmd) + Enter` para ejecutar el flujo de trabajo

Después de actualizar ComfyUI, puedes encontrar el archivo del flujo de trabajo en las plantillas, o arrastrar la vista previa del flujo de trabajo de arriba a ComfyUI para cargarlo.

### 2. Enlaces de modelos

Descarga el modelo que aparece a continuación. Como se trata de un modelo LoRA, debe guardarse en la carpeta `ComfyUI/models/loras/`
-  [qwen_image_union_diffsynth_lora.safetensors](https://huggingface.co/Comfy-Org/Qwen-Image-DiffSynth-ControlNets/blob/main/split_files/loras/qwen_image_union_diffsynth_lora.safetensors): LoRA de control de estructura de imagen compatible con canny, profundidad, pose, arte lineal, softedge, normal y openpose

### 3. Instrucciones del flujo de trabajo

Este modelo es un LoRA de control unificado compatible con los controles canny, profundidad, pose, arte lineal, softedge, normal y openpose. Como muchos de los nodos nativos de preprocesamiento de imágenes no son totalmente compatibles, conviene usar algo como [comfyui_controlnet_aux](https://github.com/Fannovel16/comfyui_controlnet_aux) para completar el resto del preprocesamiento de imágenes.

![Union Control LoRA](/images/tutorial/image/qwen/image_qwen_image_union_control_lora.jpg)

1. Asegúrate de que `LoraLoaderModelOnly` cargue correctamente el modelo `qwen_image_union_diffsynth_lora.safetensors`
2. Sube la imagen de entrada
3. Si es necesario, puedes ajustar los parámetros del nodo `Canny`. Como cada imagen de entrada requiere distintos valores de parámetros para obtener un mejor resultado de preprocesamiento, puedes probar a ajustar los valores correspondientes para obtener más o menos detalles
4. Haz clic en el botón `Run` o usa el atajo `Ctrl(cmd) + Enter` para ejecutar el flujo de trabajo

> Para otros tipos de control, también debes reemplazar la parte de procesamiento de imágenes.
