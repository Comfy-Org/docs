**Qwen-Image-Layered** es un modelo desarrollado por el equipo Qwen de Alibaba que puede descomponer una imagen en varias capas RGBA. Esta representación por capas habilita una capacidad de edición inherente: cada capa se puede manipular de forma independiente sin afectar el contenido de las demás.

**Características principales**:
- **Capacidad de edición inherente**: cada capa se puede manipular de forma independiente sin afectar el contenido de las demás
- **Operaciones elementales de alta fidelidad**: admite cambiar el tamaño, la posición y el color con aislamiento físico de los componentes semánticos
- **Descomposición en cantidad variable de capas**: no se limita a un número fijo de capas; descompón en 3, 4, 8 o más capas según lo necesites
- **Descomposición recursiva**: cualquier capa se puede descomponer aún más, lo que permite una profundidad de descomposición infinita

## Capas y salida

El número de capas se establece con el widget `layers` del nodo **Empty Qwen Image Layered Latent**, dentro del [Subgraph](/es/interface/features/subgraph).

Este modelo regenera la imagen completa además de las capas, así que cada generación siempre se decodifica en `layers + 1` imágenes:

| `layers` | Imágenes decodificadas | Contenido |
| --- | --- | --- |
| `0` | 1 | Solo la imagen completa |
| `2` (valor predeterminado de la plantilla) | 3 | La imagen completa y luego 2 capas |
| `5` | 6 | La imagen completa y luego 5 capas |

**La primera imagen es la imagen completa, no una capa.** El flujo de trabajo de imagen a capas la descarta automáticamente con un nodo `LatentCut` (`dim` `t`, `index` `1`) antes de dividir el lote, así que la plantilla genera `layers` imágenes. Si construyes un gráfico personalizado sin ese nodo, descarta la primera imagen cuando solo quieras las capas. `layers` acepta `0`, lo que te da esa imagen por sí sola.

**Recomponer todas las capas recrea la imagen completa.** Úsalo como comprobación: si al apilar las capas no se reproduce la primera imagen, la descomposición no hizo lo que querías.

### Cómo las capas se convierten en imágenes separadas

El nodo **Empty Qwen Image Layered Latent** asigna un latente 5D con forma `[batch_size, 16, layers + 1, height // 8, width // 8]`. Las capas ocupan el tercer eje, el mismo eje temporal que usan los modelos de video para los fotogramas. El nodo **LatentCutToBatch** con `dim` ajustado a `t` mueve ese eje a la dimensión del lote, de modo que después de **VAE Decode** cada capa es una imagen separada dentro del lote. La plantilla inserta un nodo `LatentCut` (`dim` `t`, `index` `1`) antes de `LatentCutToBatch` para descartar la entrada de la imagen completa, así que el lote decodificado contiene solo las capas.

La posición de una capa en la pila es, por lo tanto, su índice en el lote, contando desde la imagen completa en el índice 0. No existe ningún campo de z-index ni metadatos por capa que guarden ese orden, así que reordenar o filtrar el lote reordena las capas.

El VAE de Qwen-Image-Layered decodifica a 4 canales, por lo que las capas decodificadas llevan un canal alfa.

## Configuración del flujo de trabajo

### Configuración del sampler

Este modelo es lento. La configuración de muestreo original es steps: 50 y CFG: 4.0, lo que como mínimo duplica el tiempo de generación.

### Tamaño de entrada

Para el tamaño de entrada, el valor recomendado es 640px. Usa 1024px para obtener una salida de alta resolución.

### Prompt (opcional)

El prompt de texto sirve para describir el contenido general de la imagen de entrada, incluidos los elementos que pueden estar parcialmente ocluidos (por ejemplo, puedes especificar el texto oculto detrás de un objeto en primer plano). No está diseñado para controlar de forma explícita el contenido semántico de cada capa.
