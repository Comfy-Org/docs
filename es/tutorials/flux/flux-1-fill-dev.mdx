## Introducción al modelo Flux.1 fill dev

Flux.1 fill dev es una de las herramientas principales de la [suite FLUX.1 Tools](https://blackforestlabs.ai/flux-1-tools/) lanzada por [Black Forest Labs](https://blackforestlabs.ai/), diseñada específicamente para inpainting y outpainting de imágenes.

Características principales de Flux.1 fill dev:
- Potentes capacidades de inpainting y outpainting de imágenes, con resultados solo superados por la versión comercial FLUX.1 Fill [pro].
- Excelente capacidad para comprender y seguir el prompt, capturando con precisión la intención del usuario y manteniendo una alta consistencia con la imagen original.
- Tecnología avanzada de entrenamiento con destilación guiada, que hace el modelo más eficiente sin dejar de producir salidas de alta calidad.
- Términos de licencia flexibles: las salidas generadas se pueden usar para uso personal, científico y comercial. Consulta la [licencia no comercial de FLUX.1 [dev]](https://huggingface.co/black-forest-labs/FLUX.1-dev/blob/main/LICENSE.md) para más detalles.

Repositorio de código abierto: [FLUX.1 [dev]](https://huggingface.co/black-forest-labs/FLUX.1-dev)

Esta guía mostrará flujos de trabajo de inpainting y outpainting basados en el modelo Flux.1 fill dev.
Si no estás familiarizado con los flujos de trabajo de inpainting y outpainting, puedes consultar el [ejemplo de inpainting de ComfyUI Layout](/es/tutorials/basic/inpaint) y el [ejemplo de extensión de imagen de ComfyUI](/es/tutorials/basic/outpaint) para ver explicaciones relacionadas.

## Flux.1 Fill dev and related models installation

Before we begin, let's complete the installation of the Flux.1 Fill dev model files. The inpainting and outpainting workflows will use exactly the same model files.
If you've previously used the full version of the [Flux.1 Text-to-Image workflow](/es/tutorials/flux/flux-1-text-to-image),
then you only need to download the **flux1-fill-dev.safetensors** model file in this section.

However, since downloading the corresponding model requires agreeing to the corresponding usage agreement, please visit the [black-forest-labs/FLUX.1-Fill-dev](https://huggingface.co/black-forest-labs/FLUX.1-Fill-dev) page and make sure you have agreed to the corresponding agreement as shown in the image below.
![Flux Agreement](/images/tutorial/flux/flux1_fill_dev_agreement.jpg)

Complete model list:
|- [clip_l.safetensors](https://huggingface.co/comfyanonymous/flux_text_encoders/blob/main/clip_l.safetensors)
|- [t5xxl_fp16.safetensors](https://huggingface.co/comfyanonymous/flux_text_encoders/blob/main/t5xxl_fp16.safetensors)
|- [ae.safetensors](https://huggingface.co/black-forest-labs/FLUX.1-schnell/blob/main/ae.safetensors)
|- [flux1-fill-dev.safetensors](https://huggingface.co/black-forest-labs/FLUX.1-Fill-dev/blob/main/flux1-fill-dev.safetensors)

File storage location:
```
ComfyUI/
├── models/
│   ├── text_encoders/
│   │    ├── clip_l.safetensors
│   │    └── t5xxl_fp16.safetensors
│   ├── vae/
│   │    └── ae.safetensors
│   └── diffusion_models/
│        └── flux1-fill-dev.safetensors
```

### 1. Flujo de trabajo de relleno inteligente y recursos

<Note>
La imagen correspondiente ya contiene un canal alfa, así que no necesitas dibujar una máscara por separado.
Si quieres dibujar tu propia máscara, [haz clic aquí](https://raw.githubusercontent.com/Comfy-Org/example_workflows/main/flux/inpaint/flux_fill_inpaint_input_original.png) para obtener la imagen sin máscara y consulta la sección de uso de MaskEditor en el [Ejemplo de relleno inteligente de diseño de ComfyUI](/es/tutorials/basic/inpaint#usar-el-editor-de-máscara) para aprender a dibujar una máscara en el nodo `Load Image`.
</Note>

### 2. Pasos para ejecutar el flujo de trabajo

![Flujo de trabajo de relleno inteligente con Flux.1 Fill dev de ComfyUI](/images/tutorial/flux/flow_diagram_inpaint.jpg)

1. Asegúrate de que el nodo `Load Diffusion Model` tenga cargado `flux1-fill-dev.safetensors`.
2. Asegúrate de que el nodo `DualCLIPLoader` tenga cargados los siguientes modelos:
   - clip_name1: `t5xxl_fp16.safetensors`
   - clip_name2: `clip_l.safetensors`
3. Asegúrate de que el nodo `Load VAE` tenga cargado `ae.safetensors`.
4. Sube la imagen de entrada proporcionada en el documento al nodo `Load Image`; si usas la versión sin máscara, recuerda completar el dibujo de la máscara con el editor de máscara
5. Haz clic en el botón `Queue` o usa el atajo `Ctrl(cmd) + Enter` para ejecutar el flujo de trabajo
