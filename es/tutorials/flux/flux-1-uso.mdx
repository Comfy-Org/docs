**USO (Unified Style-Subject Optimized)** es un modelo desarrollado por el equipo UXO de ByteDance que unifica las tareas de generación guiadas por estilo y por sujeto.
Construido sobre la arquitectura FLUX.1-dev, el modelo logra tanto similitud de estilo como consistencia del sujeto mediante aprendizaje desacoplado y aprendizaje con recompensa de estilo (SRL).

USO admite tres enfoques principales:
- **Guiado por sujeto**: coloca al sujeto en escenas nuevas mientras mantienes la consistencia de su identidad
- **Guiado por estilo**: aplica estilos artísticos a contenido nuevo basándote en imágenes de referencia
- **Combinado**: usa referencias de sujeto y de estilo al mismo tiempo

### 3. Instrucciones del flujo de trabajo

![Instrucciones del flujo de trabajo](/images/tutorial/flux/flux1_uso_reference_image_gen.jpg)

1. Carga los modelos:
    - 1.1 Asegúrate de que el nodo `Load Checkpoint` tenga cargado `flux1-dev-fp8.safetensors`
    - 1.2 Asegúrate de que el nodo `LoraLoaderModelOnly` tenga cargado `dit_lora.safetensors`
    - 1.3 Asegúrate de que el nodo `ModelPatchLoader` tenga cargado `projector.safetensors`
    - 1.4 Asegúrate de que el nodo `Load CLIP Vision` tenga cargado `sigclip_vision_patch14_384.safetensors`
2. Referencia de contenido:
    - 2.1 Haz clic en `Upload` para subir la imagen de entrada que proporcionamos
    - 2.2 El nodo `ImageScaleToMaxDimension` escalará tu imagen de entrada para la referencia de contenido; 512px conservará más rasgos del personaje, pero si solo usas la cabeza del personaje como entrada, la imagen de salida final suele tener problemas, como que el personaje ocupe demasiado espacio. Ajustarlo a 1024px da resultados mucho mejores.
3. En el ejemplo, solo usamos la entrada de imagen `content reference`. Si quieres usar la entrada de imagen `style reference`, puedes usar `Ctrl-B` para omitir el grupo de nodos marcado.
4. Escribe tu prompt o mantén el valor predeterminado
5. Establece el tamaño de la imagen si lo necesitas
6. El nodo EasyCache sirve para acelerar la inferencia, pero también sacrificará algo de calidad y detalles. Puedes omitirlo (Ctrl+B) si no necesitas usarlo.
7. Haz clic en el botón `Run`, o usa el atajo `Ctrl(Cmd) + Enter` para ejecutar el flujo de trabajo

### 4. Notas adicionales

1. Solo referencia de estilo:

También incluimos una versión que solo usa la referencia de estilo dentro del mismo flujo de trabajo que proporcionamos.

![Flujo de trabajo](/images/tutorial/flux/flux1_uso_reference_image_gen_style_reference_only.jpg)
La única diferencia es que reemplazamos el nodo `content reference` y solo usamos un nodo `Empty Latent Image`.

2. También puedes omitir todo el grupo `Style Reference` y usar el flujo de trabajo como un flujo de trabajo de texto a imagen, lo que significa que este flujo de trabajo tiene 4 variantes
- Usar solo la referencia de contenido (sujeto)
- Usar solo la referencia de estilo
- Combinar referencias de contenido y estilo
- Usar como flujo de trabajo de texto a imagen
