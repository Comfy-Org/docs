Choose a starting point based on what you want to run. Comfy Router calls hosted models directly. The workflow API runs ComfyUI workflows from your application.

## Quick Start

<CardGroup cols={2}>
  <Card title="Call a model with Comfy Router" icon="rocket" href="/development/comfy-router/quickstart">
    Send a prompt to a hosted model and save the result. Requires a Comfy API key, Router access, and credits. No workflow or deployment is needed.
  </Card>
  <Card title="Run a ComfyUI workflow" icon="play" href="/development/api-development/quickstart">
    Download a sample workflow and run it with Python or TypeScript on Comfy Cloud. Requires a paid Comfy Cloud subscription and an API key.
  </Card>
</CardGroup>

Both quickstarts take you through getting a key, running an example, and saving the output. If you already have a workflow, see [Running Workflows](/development/run-workflows/overview).

When you need your own models and custom nodes behind an endpoint, create a [Comfy API deployment](/development/serverless/overview). You can also [self-host ComfyUI](/development/deploy/self-hosting).
