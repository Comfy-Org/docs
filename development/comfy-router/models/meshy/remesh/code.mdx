## Quick start

Create a key at [platform.comfy.org/profile/api-keys](https://platform.comfy.org/profile/api-keys) and export it as `COMFY_API_KEY`. The Python and TypeScript snippets use the Comfy SDKs (`pip install comfy-sdk`, `npm install @comfyorg/sdk`); the cURL snippet is the same call over raw HTTP.

**Model ID:** `meshy/remesh`

**Endpoint:** `POST https://api.comfy.org/v2/models/meshy/remesh`

```python Python
import uuid
from comfy_sdk import Comfy

# Reads COMFY_API_KEY from the environment. Store this UUID before starting a
# generation. Use the same value if you retry it.
idempotency_key = str(uuid.uuid4())
with Comfy() as client:
    result = client.models.run(
        "meshy/remesh",
        {
            "input_task_id": "0193abcd-0000-0000-0000-000000000000",
            "origin_at": "bottom",
            "resize_height": 1,
            "target_formats": ["glb", "fbx"],
            "target_polycount": 50000,
            "topology": "quad",
        },
        idempotency_key=idempotency_key,
        timeout=660.0,
    )

print(result)
```
