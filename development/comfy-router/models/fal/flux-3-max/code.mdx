### Input

<ParamField body="aspect_ratio" type="string" default="&quot;auto&quot;">
  Aspect ratio of the generated video. auto is 16:9 for a text prompt and follows the first image otherwise.

  Possible values: `auto`, `21:9`, `2:1`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  Duration of the generated video in seconds, 5 to 20. fal bills per second of this value.

  Range: `5` to `20`
</ParamField>

<ParamField body="generate_audio" type="boolean" default="true">
  Generate synchronized audio. The price is the same.
</ParamField>

<ParamField body="prompt" type="string" required>
  Text prompt that describes the video and its sound.
</ParamField>

<ParamField body="reasoning_level" type="string" default="&quot;high&quot;">
  How much the model reasons about and expands the prompt before generation. high is slower. The price is the same.

  Possible values: `low`, `high`
</ParamField>

<ParamField body="resolution" type="string" default="&quot;720p&quot;">
  Resolution of the generated video. 1080p costs more per second than 720p.

  Possible values: `720p`, `1080p`
</ParamField>

<ParamField body="seed" type="integer">
  Random seed. A random seed is selected when omitted.
</ParamField>
