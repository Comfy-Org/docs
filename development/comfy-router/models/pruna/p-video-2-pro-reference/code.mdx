## Schema

### Input

<ParamField body="input" type="object" required>
  P-Video-2-Pro Reference parameters. The job is billed per second of the returned video, measured from the returned file and rounded down to a whole second, at the rate for `resolution` and `mode`. Each reference is billed too: every image (`first_frame_image` and `last_frame_image` included) once, and every video and audio clip per second of its real length, at most `duration` + 0.5 seconds per clip. Video and audio references must be publicly readable http(s) URLs, because their lengths are read before the job is sent. The safety filter is always on; an `enable_safety_filter` value in the request is ignored.
</ParamField>

<ParamField body="input.aspect_ratio" type="string" default="&quot;16:9&quot;">
  adaptive, 16:9, 9:16, 4:3, 3:4, 3:2, 2:3 or 1:1.
</ParamField>

<ParamField body="input.audio" type="string[]">
  Reference audio URIs. At most 3, 15 seconds combined.
</ParamField>

<ParamField body="input.duration" type="integer" default="5">
  Output length in seconds.

  Range: `5` to `15`
</ParamField>

<ParamField body="input.first_frame_image" type="string">
  Opening frame image URI. Billed as a reference image.
</ParamField>

<ParamField body="input.image" type="string[]">

<ParamField body="input.resolution" type="string" default="&quot;768p&quot;">
