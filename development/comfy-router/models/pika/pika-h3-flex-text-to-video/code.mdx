### Input

<ParamField body="aspect_ratio" type="string">
  Output aspect ratio. `auto` picks one from the prompt and the media inputs. Omit it to let Pika choose: `auto` when `rewrite` is on, else the first media input's ratio, else 16:9.

  Possible values: `auto`, `21:9`, `16:9`, `3:2`, `4:3`, `5:4`, `1:1`, `4:5`, `3:4`, `2:3`, `9:16`, `9:21`
</ParamField>

<ParamField body="channel_mode" type="string" default="&quot;mono&quot;">
  Audio stems only. `mono` downmixes before separation; `stereo` keeps both channels. The video's audio does not change.

  Possible values: `stereo`, `mono`
</ParamField>

<ParamField body="duration" type="integer" default="5">
  Video length in whole seconds, 5 to 15.

  Range: `5` to `15`
</ParamField>

<ParamField body="output_mode" type="string" default="&quot;video&quot;">
  `video` returns the video only. `audio-stems` also returns Dialogue, Music and Effect WAV stems in `output.stems`, and adds Pika's per-second stem separation charge.

  Possible values: `video`, `audio-stems`
</ParamField>

<ParamField body="prompt" type="string" required>
  Text prompt describing the video and its audio.
</ParamField>

<ParamField body="resolution" type="string" default="&quot;768p&quot;">
  Output resolution. 480p and 768p are native. 1080p, 2k and 4k generate at 768p and then upscale, keeping the audio and frame rate.

  Possible values: `480p`, `768p`, `1080p`, `2k`, `4k`
</ParamField>

<ParamField body="rewrite" type="boolean" default="true">
  Improve the prompt before generation. Set it to false to use the prompt as written.
</ParamField>

<ParamField body="seed" type="integer" default="0">
  Seed for the video, 0 or more.

  Range: `0` to `…`

  Format: `int64`
