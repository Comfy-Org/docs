## Schema

### Input

<ParamField body="auto_trim" type="boolean">
  When true, videos longer than 5 seconds are trimmed to the first 5 seconds. When false (default), longer videos are rejected.
</ParamField>

<ParamField body="mask" type="string" required>
  Publicly accessible URL of a mask video that defines the area to erase. White pixels mark the region to remove, black pixels are preserved.
</ParamField>

<ParamField body="output_container_and_codec" type="string">
  Output container and codec preset.

  Possible values: `mp4_h264`, `mp4_h265`, `webm_vp9`, `mov_h265`, `mov_proresks`, `mkv_h264`, `mkv_h265`, `mkv_vp9`, `gif`
</ParamField>

<ParamField body="preserve_audio" type="boolean">
  Whether to preserve audio from the input video.
</ParamField>

<ParamField body="video" type="string" required>
  Publicly accessible URL of the input video. Maximum duration 5 seconds unless auto_trim is true. Input resolution supported up to 750p; larger inputs are downscaled.
</ParamField>
