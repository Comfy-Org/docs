You can run a Workflow you built in the Comfy Cloud editor from your own application, such as a backend service or a batch script, with the [Comfy SDKs](/development/api-development/sdks). Comfy Cloud runs Workflows on a standard build with a default set of Custom Nodes. If a Workflow needs Custom Nodes or models the standard build doesn't have, you create a custom Build: a package of your own Custom Nodes and models that Comfy Cloud runs for you. This page shows how to run a Workflow through the API on the standard build, and then how to point the same code at a custom Build.

## Before you begin

To call Comfy Cloud from your code, make sure you have these:

- **A paid Comfy Cloud subscription**
- **A Workflow that runs in the Comfy Cloud editor**: test it in the editor before you run it from code. If it needs Custom Nodes or models the standard build doesn't have, [create a custom Build](/development/deploy/cloud-custom-builds) first.
- **Python 3.10 or later, or Node 22 or later**: the SDK you install needs one of them.

If you haven't used Comfy Cloud yet, start with [Comfy Cloud](/get_started/cloud).

## Run a Workflow on the standard build

The standard build runs any Workflow that uses only the Custom Nodes Comfy Cloud supports. To run one from your code, you create an API key, install the SDK, and export the Workflow in API format.

<Steps>
  <Step title="Create an API key">
    Your application sends the key with each request, so create a key for your application on the Developer Platform.

    1. Sign in at [platform.comfy.org](https://platform.comfy.org), and then click **API Keys**.
    2. Click **New API key**, enter a name, and then click **Generate key**.
    3. Copy the key and store it somewhere safe. The Developer Platform shows it once.

    The key starts with `comfyui-`. See [Getting an API Key](/development/api-development/getting-an-api-key) for how to manage keys.
  </Step>
  <Step title="Install the SDK">
    <CodeGroup>
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    </CodeGroup>
  </Step>
  <Step title="Export the Workflow in API format">
    The SDK sends the API format of a Workflow, not the file the editor saves.

    - In the Comfy Cloud editor, open the Workflow, select **File** > **Export (API)**, and save the file as `workflow_api.json`.

    See [Workflow API Format](/development/api-development/workflow-api-format) for what the file contains.
  </Step>
  <Step title="Run the Workflow">
    The SDK sends requests to Comfy Cloud unless you set another base URL, so pass only your API key:

    <CodeGroup>
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." });

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    </CodeGroup>

    - Replace `"9"` with the ID of the output Node in your `workflow_api.json`.
    - `run()` waits until the job finishes, and then the code writes the outputs to disk.

    To set inputs, follow progress, and handle errors, see the [Comfy SDKs](/development/api-development/sdks).
  </Step>
</Steps>

## Run a Workflow on a custom Build

Deploying a custom Build gives you a deployment with its own URL. Your code from the previous section runs on the deployment once you change the base URL.

<Warning>
  A deployment costs GPU time while its workers run and storage until you delete it. When you finish testing, stop or delete it. See [Clean up](/development/serverless/overview#clean-up).
</Warning>

<Steps>
  <Step title="Create and deploy a Build">
    Follow [Custom Builds](/development/deploy/cloud-custom-builds) to create a Build from your Workflow and deploy it.
  </Step>
  <Step title="Copy the deployment URL">
    1. On the Developer Platform, open the deployment's page.
    2. Wait until the deployment's status reads **Ready**.
    3. In **Run via API**, copy the **Deployment URL**.

    A deployment URL has the form `https://dep-<id>.run.comfy.app`.
  </Step>
  <Step title="Set the base URL">
    Set `COMFY_BASE_URL` to the deployment URL:

    ```bash
    export COMFY_BASE_URL="https://dep-<id>.run.comfy.app"
    ```
  </Step>
  <Step title="Run the Workflow">
    Run the code from [Run a Workflow on the standard build](#run-a-workflow-on-the-standard-build) with your API key. The SDK now sends the job to your deployment.
  </Step>
</Steps>

<Tip>
  To test the deployment from a terminal first, run:

  ```bash
  comfy deploy run --deployment <deployment-id> --workflow workflow_api.json
  ```
</Tip>
