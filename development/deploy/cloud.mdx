Comfy Cloud is a fully managed, always-available ComfyUI environment. Build workflows in the browser or run them through the SDK. There is no Build or deployment to create.

<Note>
  New to Comfy Cloud? Start with the [Comfy Cloud introduction](/get_started/cloud). This quickstart shows how to run workflows from an app.
</Note>

## Quickstart

Requires a paid subscription, an [API key](/development/api-development/getting-an-api-key), and an API-format workflow. The [Comfy SDKs](/development/api-development/sdks) target Cloud by default.

<Steps>
  <Step title="Create an API key">
    Create an API key at [platform.comfy.org](https://platform.comfy.org). See [Getting an API Key](/development/api-development/getting-an-api-key) for details.
  </Step>
  <Step title="Install the SDK">
    <CodeGroup>
    ```bash Python
    pip install comfy-sdk
    ```

    ```bash TypeScript
    npm i @comfyorg/sdk
    ```
    </CodeGroup>
  </Step>
  <Step title="Export a workflow in API format">
    In the Cloud editor, save your tested workflow as `workflow_api.json` with `File → Export Workflow (API)`. See [Workflow API Format](/development/api-development/workflow-api-format).
  </Step>
  <Step title="Run it">
    <CodeGroup>
    ```python Python
    from comfy_sdk import Comfy

    client = Comfy(api_key="comfyui-...")  # Comfy Cloud is the default target

    wf = client.workflows.from_file("workflow_api.json")

    job = client.run(wf)
    for output in job.get_outputs("9"):
        output.to_file(output.name)
    ```

    ```typescript TypeScript
    import { Comfy } from "@comfyorg/sdk";

    const client = new Comfy({ apiKey: "comfyui-..." }); // Comfy Cloud is the default target

    const wf = await client.workflows.fromFile("workflow_api.json");

    const job = await client.run(wf);
    await job.getOutputs("9")[0].toFile("out.png");
    ```
    </CodeGroup>

    `"9"` is the output node ID. See the [SDK guide](/development/api-development/sdks) for inputs, progress, and error handling.
  </Step>
</Steps>

The same SDK code can target [Comfy API deployments](/development/serverless/quickstart) and [self-hosted ComfyUI](/development/deploy/self-hosting). See [Running Workflows](/development/run-workflows/overview).
