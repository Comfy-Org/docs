Use this tutorial when you have a local ComfyUI install. To start with an agent, a Desktop snapshot, the ComfyUI graph menu, or a workflow JSON, see the [Comfy API Quickstart](/development/serverless/quickstart).

<Steps>
  <Step title="Create a Build">
    From the directory containing your local ComfyUI install, scan its models and custom nodes:

    ```bash
    comfy build init --name "my-comfy-build" --models-dir ./models --custom-nodes-dir ./custom_nodes
    ```
  </Step>
  <Step title="Create a release">
    Create a Linux/NVIDIA release from the Build:

    ```bash
    comfy build push --release --target linux/nvidia
    ```
  </Step>
  <Step title="Choose compute and deploy">
    Find an available GPU and region, then set worker bounds that fit your latency and cost needs:

    ```bash
    comfy deploy refs compute
    comfy deploy up --gpu <gpu> --region <region> --min <min-workers> --max <max-workers> --watch
    ```

    `deploy up` prints the deployment ID for the next step.
  </Step>
  <Step title="Run an API-format workflow">
    Export a workflow in [API format](/development/api-development/workflow-api-format), then submit it to the deployment:

    ```bash
    comfy deploy run \
      --workflow workflow_api.json \
      --deployment <deployment-id> \
      --output-dir ./results
    ```
  </Step>
</Steps>
