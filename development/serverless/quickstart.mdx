<Warning>
  Comfy API deployments are in beta. Sign up for access at [platform.comfy.org](https://platform.comfy.org/?onboarding=comfyapi).
</Warning>

Before you start, install the [Comfy CLI](/comfy-cli/getting-started#install-cli), prepare a local ComfyUI install, and export an [API-format workflow](/development/api-development/workflow-api-format) as `workflow_api.json`.

<Steps>
  <Step title="Create a Build">
    ```bash
    comfy build init --name "my-comfy-build" --models-dir ./models --custom-nodes-dir ./custom_nodes
    ```
  </Step>
  <Step title="Create a release">
    ```bash
    comfy build push --release --target linux/nvidia
    ```
  </Step>
  <Step title="Choose compute and deploy">
    Find an available GPU and region, then create the deployment:

    ```bash
    comfy deploy refs compute
    comfy deploy up --gpu <gpu> --region <region> --min 1 --max 4 --watch
    ```

    Use a GPU and region returned by the compute catalog. `deploy up` prints the deployment ID for the next step.
  </Step>
</Steps>

## Run a workflow

Use the deployment ID printed by `deploy up`:

```bash
comfy deploy run \
  --workflow workflow_api.json \
  --deployment <deployment-id> \
  --output-dir ./results
```
