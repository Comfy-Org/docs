## Start with an agent (recommended)

Start your coding agent in the folder for the local ComfyUI install you want to deploy. Paste this prompt:

```text
Install or update comfy-cli, then read its Build and Deploy skills:

pip install -U comfy-cli
comfy skills show comfy-build
comfy skills show comfy-deploy

Use comfy-build to inspect this local ComfyUI install and package its models, custom nodes, and pinned dependencies into a Comfy API Build. Show me what will be included and create a Linux/NVIDIA release. Then use comfy-deploy to show the available GPU and region options, worker bounds, and current rates. Wait for my approval before creating a deployment. After approval, deploy it and explain how to run a workflow.
```

<AccordionGroup>
  <Accordion title="Run the command-line steps yourself">
    From the directory containing your local ComfyUI install, create a Build and release:

    ```bash
    comfy build init --name "my-comfy-build" --models-dir ./models --custom-nodes-dir ./custom_nodes
    comfy build push --release --target linux/nvidia
    ```

    Check available compute, then create a deployment. Replace the GPU and region with a pair from the catalog:

    ```bash
    comfy deploy refs compute
    comfy deploy up --gpu <gpu> --region <region> --min 1 --max 4 --watch
    ```

    `deploy up` prints the deployment ID. Submit an [API-format workflow](/development/api-development/workflow-api-format) to the deployment:

    ```bash
    comfy deploy run \
      --workflow workflow_api.json \
      --deployment <deployment-id> \
      --output-dir ./results
    ```
  </Accordion>
</AccordionGroup>

## Other ways to start

Use these paths if your environment or workflow already exists in Comfy Desktop, ComfyUI, or a workflow file.

<CardGroup cols={3}>
  <Card title="Comfy Desktop snapshot" icon="camera" href="/development/serverless/build-sources#comfy-desktop-snapshot">
    Export a snapshot from Desktop, then import it into the Build Wizard.
  </Card>
  <Card title="From ComfyUI" icon="diagram-project" href="/development/serverless/build-sources#comfyui-graph-menu">
    Send the open workflow from ComfyUI to the Build Wizard or to your agent.
  </Card>
  <Card title="Import workflow JSON" icon="file-import" href="/development/serverless/build-sources#workflow-json">
    Start a Build by importing a saved workflow into the Build Wizard.
  </Card>
</CardGroup>

<Note>
  The **Deploy to Comfy API** graph-menu action may not be available in every ComfyUI account yet. If you do not see it, open the [Comfy API Build Wizard](https://platform.comfy.org/?onboarding=comfyapi) directly.
</Note>
