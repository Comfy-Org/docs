The [Comfy API Quickstart](/development/serverless/quickstart) recommends starting with an agent and `comfy-cli`. Use one of these paths when your environment or workflow already exists in another form. Review the Build contents before creating a release.

## Comfy Desktop snapshot

Use a snapshot to carry a Desktop instance's ComfyUI version, custom nodes, and Python packages into a Build.

1. In Comfy Desktop, open the instance's **Snapshots** tab and export a snapshot file. See [Desktop snapshot steps](/installation/desktop/usage/snapshots#snapshots-tab-overview).
2. Open the [Comfy API Build Wizard](https://platform.comfy.org/?onboarding=comfyapi) and import the snapshot file.
3. Review the Build contents and add or correct any missing models or dependencies before creating a release.

## ComfyUI graph menu

When the **Deploy to Comfy API** action is available for your account, you can send the open workflow from ComfyUI to the Build Wizard:

1. Open the workflow you want to deploy.
2. Open the graph menu and choose **Deploy to Comfy API**.
3. Choose **Deploy on Platform** to continue in the Build Wizard with the workflow, or **Build with your agent** to copy an agent brief.
4. Review the Build contents and add or correct any missing models or dependencies.

If you do not see this menu action, open the Build Wizard directly at [platform.comfy.org](https://platform.comfy.org/?onboarding=comfyapi).

## Workflow JSON

Use a saved workflow file to configure a Build in the Build Wizard:

1. Open the [Comfy API Build Wizard](https://platform.comfy.org/?onboarding=comfyapi).
2. Drag the workflow JSON into the import step.
3. Review the Build contents and add or correct any missing models or dependencies before creating a release.

## Next steps

Use the [Comfy API Quickstart](/development/serverless/quickstart) to create a release, deploy it, and run a workflow. For Build details, scaling, billing, and troubleshooting, see the [Comfy API Deployment Guide](/development/serverless/overview).
