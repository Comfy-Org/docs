<Warning>
**This node is deprecated.** Do not add it to new workflows.

Use **[Apply ControlNet](/built-in-nodes/ControlNetApplyAdvanced)** (`ControlNetApplyAdvanced`) instead. That is the current node shown as **Apply ControlNet** in search and in the [ControlNet tutorial](/tutorials/controlnet/controlnet).

`Apply ControlNet (Old)` / `ControlNetApply` stays in ComfyUI so older graphs still load. It is **hidden from search by default**. To see it, open **Settings → Comfy → Node** and enable **Show deprecated nodes in search**. Prefer migrating the graph to **Apply ControlNet**.
</Warning>

## What to use instead

| Goal | Use this |
| --- | --- |
| Apply a ControlNet model to positive and negative conditioning | **[Apply ControlNet](/built-in-nodes/ControlNetApplyAdvanced)** |
| Load the ControlNet weights | **[Load ControlNet Model](/built-in-nodes/ControlNetLoader)** (or Diff ControlNet Loader when needed) |
| Step-by-step scribble / ControlNet workflow | **[ControlNet tutorial](/tutorials/controlnet/controlnet)** |

## Preprocessors (prefer core, then aux)

ControlNet expects a **condition image** (depth, pose, edges, scribble, and so on), not usually a raw photo alone.

1. **Prefer Comfy Core tools when they cover your case**, for example:
   - [Depth Anything 3](/tutorials/utility/depth-anything-3)
   - [SDPose](/tutorials/utility/pose-detection-sdpose)
   - [MediaPipe face detection](/tutorials/utility/face-detection/mediapipe)
   - [Marigold V2](/tutorials/utility/marigold-v2)
   - Other guides under [Utility tutorials](/tutorials/utility/preprocessors)
2. **Use a custom preprocessor pack only when core does not provide the map you need** (for example some scribble / lineart variants). Common options:
   - [ComfyUI ControlNet aux](https://github.com/Fannovel16/comfyui_controlnet_aux)
   - [ComfyUI-Advanced-ControlNet](https://github.com/Kosinkadink/ComfyUI-Advanced-ControlNet)

You still need the matching **ControlNet model files** under `ComfyUI/models/controlnet/` (or another folder ComfyUI reads).

## Why this page still exists

Older workflows and shared images may still contain **Apply ControlNet (Old)**. Opening those graphs can surface this node even when it is hidden from search. Replace it with **Apply ControlNet** when you edit the graph.

## Legacy node (reference only)

<Note>
The table below is for reading old graphs. For new work, use [Apply ControlNet](/built-in-nodes/ControlNetApplyAdvanced). Confirm field names against your ComfyUI build if a loaded graph disagrees.
</Note>

### Typical legacy inputs

| Parameter | Data Type | Function |
| --- | --- | --- |
| `conditioning` | `CONDITIONING` | Conditioning to adjust (legacy single conditioning path) |
| `control_net` | `CONTROL_NET` | ControlNet model from a ControlNet loader |
| `image` | `IMAGE` | Preprocessed condition image |
| `strength` | `FLOAT` | How strongly ControlNet steers generation |

### Typical legacy outputs

| Parameter | Data Type | Function |
| --- | --- | --- |
| `conditioning` | `CONDITIONING` | Conditioning after ControlNet is applied |

The current **Apply ControlNet** node uses separate `positive` / `negative` conditioning inputs (and timing widgets such as `start_percent` / `end_percent`). Do not copy those Advanced fields onto this deprecated node when editing docs or tutorials.
