This node replaces the part of a video between the start and resume times with a newly generated scene, guided by a prompt and optional reference images and videos. The source video is cut at `start_time` and resumes at `resume_time`; the removed span is regenerated and spliced back in. Use it to fix a shot, swap out an action, or bridge two parts of a clip.

| Parameter | Description | Data Type | Required | Range |

| `model` | Model to use for video generation. | DYNAMIC_COMBO | Yes | "MiniMax H3 Max" |

### MiniMax H3 Max Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `video` | Source video, up to 60 seconds long. The aspect ratio must be between 0.4 and 2.5. | VIDEO | Yes | 0 to 60 seconds |
| `reference_images` | Growable slot: connect up to 9 optional reference images (`image_1`...`image_9`) for the new scene, at least 256x256 pixels. They are referred to in the prompt as `@Image1`..`@Image9` in connection order. | IMAGE | No | 0 to 9 images |
| `reference_videos` | Growable slot: connect up to 3 optional reference videos (`video_1`...`video_3`) for the new scene, 2 to 15 seconds each and 15 seconds in total. They are referred to in the prompt as `@Video1`..`@Video3` in connection order. | VIDEO | No | 0 to 3 videos |
| `prompt` | The new scene. A prompt or at least one reference is required; references without a prompt are often ignored. | STRING | Yes | 0 to 50000 characters |
| `start_time` | Second where the source video stops and the new scene begins (default: 2.0). | FLOAT | Yes | 1.625 to 60.0 |
| `resume_time` | Second where the source video resumes after the new scene (default: 3.0). Must be after `start_time` and at least 1.375 seconds before the end of the video. The source between `start_time` and `resume_time` is removed. | FLOAT | Yes | 1.625 to 60.0 |
| `duration` | Length of the new scene in seconds (default: 5). | INT | Yes | 5 to 13 |
| `resolution` | Resolution of the output video (default: "768P"). | COMBO | Yes | "480P"<br />"768P" |
| `color_match` | Match the colors of the new scene to the source video (default: true). | BOOLEAN | No | true<br />false |
| `prompt_expansion` | Rewrite the prompt using the source video. Turn it off to get reproducible results for the same seed (default: true). | BOOLEAN | No | true<br />false |
| `seed` | Random seed. The same request with the same seed gives similar, but not guaranteed identical, results (default: 42). | INT | Yes | 0 to 2147483647 |

### Parameter Constraints

- `resume_time` must be greater than `start_time` and at least 1.375 seconds before the end of the video, otherwise the request is rejected.
- Each reference video must be between 2 and 15 seconds long, and all of them together cannot exceed 15 seconds.
