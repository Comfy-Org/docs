Tripo: Smart UV re-unwraps the UVs of a model and remaps its textures, rig and animation onto the new layout. Use it when a model's original UV layout is unusable, for example after retopology or when texture seams need to be redone. The input model must not exceed 80,000 triangles (a quad counts as two), so reduce larger models with Tripo: Retopology or a `face_limit` first.

> **Note:** Tripo keeps task records on its servers for 7 days (effective December 1, 2026). A task ID older than that can no longer be resolved, so rerunning a saved workflow after the window fails at this node. Run the earlier Tripo node again to create a fresh task ID, or re-import the downloaded model with **Tripo: Import Model**.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | Task ID of the model to re-unwrap. Accepts a model task ID from a Tripo generation node, or a rig, retarget or segment task ID. | MODEL_TASK_ID | Yes | Tripo task ID |
| `bake` | Bake the existing textures onto the new UV layout. Off skips the bake and returns the model without its colour textures (default: True). | BOOLEAN | Yes | `True`<br />`False` |

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `model task_id` | Task ID of the finished UV task. Can be passed to other Tripo nodes, for example Tripo: Texture. | MODEL_TASK_ID |
| `GLB` | The re-unwrapped model in GLB format. Empty when the source model is FBX. | GLB FILE |
| `FBX` | The re-unwrapped model in FBX format. Only populated when the source model is FBX, for example a quad mesh. | FBX FILE |
| `UV atlas` | The rendered UV layout of the model as an image. | IMAGE |
