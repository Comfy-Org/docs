Ask a yes/no question about the text, images, audio or video you connect and get a boolean to route on. Connect `result` to an If/Else Switch node to choose between two paths, and read `answer` and `probability` to see how clear the answer was.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | Model to use. `heygen-decision-1-turbo` is faster and costs less than `heygen-decision-1` (default: `"heygen-decision-1"`). | COMBO | Yes | `"heygen-decision-1"`<br />`"heygen-decision-1-turbo"` |
| `question` | The yes/no question about what is connected, up to 5000 characters. Ask it so that "yes" is the case you act on (default: "Is there a person in the image?"). | STRING | Yes | 1 to 5000 characters |
| `threshold` | Probability of "yes" at which `result` becomes true; clear answers are close to 0 or 1 (default: 0.5). | FLOAT | Yes | 0.01 to 0.99 (step 0.01) |
| `images` | Images to ask about, up to 4 in total, counting every frame of a batch. They are numbered `image_1` to `image_4` in order across the sockets. | IMAGE | No | Up to 4 images |
| `audio_1` | Audio to ask about, up to 30 minutes. | AUDIO | No | Up to 30 minutes |
| `video_1` | Video to ask about, up to 60 seconds. | VIDEO | No | Up to 60 seconds |
| `text` | Text the question is about, such as a prompt or an LLM response, up to 20000 characters. | STRING | No | Up to 20000 characters |

Connect at least one of `text`, `images`, `audio_1` or `video_1`, and refer to them by socket name inside the question, for example "Does image_2 show the same person as image_1?".

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `result` | True when the probability of "yes" reaches `threshold`, false otherwise. | BOOLEAN |
| `answer` | The verdict as the string `"yes"` or `"no"`, following the same `threshold` as `result`. | STRING |
| `probability` | Probability of "yes" between 0 and 1. | FLOAT |
