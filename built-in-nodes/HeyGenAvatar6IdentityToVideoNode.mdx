Generate a talking video of a HeyGen avatar with Avatar 6. Pick one of the built-in looks that support Avatar 6 or paste your own HeyGen avatar ID, then drive it with a text script or your own audio.

## Inputs

### Common Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | Model selector. `"heygen-avatar-6-turbo"` is the cheaper, faster tier; both models accept the same inputs and resolutions. | COMBO | Yes | `"heygen-avatar-6"`<br />`"heygen-avatar-6-turbo"` |
| `avatar` | Avatar look to present. The 19 built-in looks that support Avatar 6 are listed directly; `custom avatar` reveals `custom_avatar_id` for a look you made in HeyGen. | DYNAMIC_COMBO | Yes | 19 built-in looks<br />`custom avatar` |
| `speech` | Drive the avatar with a text script (HeyGen text-to-speech) or your own audio. Display name: speech source. | DYNAMIC_COMBO | Yes | `"script"`<br />`"audio"` |
| `resolution` | Resolution of the output video. Default: `"1080p"`. | COMBO | Yes | `"1080p"`<br />`"2k"` |
| `aspect_ratio` | Aspect ratio of the output video. `"auto"` follows the avatar look's own footage. Default: `"auto"`. | COMBO | Yes | `"auto"`<br />`"16:9"`<br />`"9:16"`<br />`"1:1"`<br />`"4:5"`<br />`"5:4"` |
| `motion_prompt` | Optional direction for gestures, expression, posture and camera movement. Default: empty string. | STRING | Yes | Multiline text |
| `motion_expressiveness` | `"less"` gives fewer, smaller gestures. The motion prompt takes precedence where the two overlap. Default: `"default"`. | COMBO | Yes | `"less"`<br />`"default"` |
| `seed` | Seed controls whether the node should re-run; results are non-deterministic regardless of seed. Default: 42. | INT | Yes | 0 to 2147483647 |

### `custom avatar` Inputs

These inputs appear when `avatar` is set to `custom avatar`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `custom_avatar_id` | HeyGen avatar look ID that supports Avatar 6, such as one made with HeyGen Create Avatar. Default: empty string. | STRING | Yes | - |

### `script` Speech Inputs

These inputs appear when `speech` is set to `"script"`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `text` | Text for the avatar to speak. Default: empty string. | STRING | Yes | Up to 5000 characters |
| `voice` | Voice for the script. The default option uses the voice HeyGen assigned to the avatar; avatars made with HeyGen Create Avatar have none, so pick a voice for them. | COMBO | Yes | `"(avatar's default voice)"` plus HeyGen's general voice list |
| `custom_voice_id` | Optional HeyGen voice ID. When set, it overrides the voice selected above. Default: empty string. | STRING | No | - |
| `voice_speed` | Speech speed multiplier. Default: 1.0. | FLOAT | No | 0.5 to 1.5 (step 0.05) |

### `audio` Speech Inputs

These inputs appear when `speech` is set to `"audio"`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `audio` | Speech for the avatar. The video length follows the audio. | AUDIO | Yes | 0.5 seconds to 10 minutes |

**Constraints and behavior:**

* `custom avatar` needs a non-empty avatar ID, otherwise the node raises an error.
* A script is limited to 5000 characters, and audio to 10 minutes.
* Pricing is per second of output video and depends on the model and the resolution.

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `video` | The generated talking video, downloaded from HeyGen once rendering finishes. | VIDEO |
