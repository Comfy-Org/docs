Runs the MiniMax H3 first-last frame workflow on a Comfy Cloud GPU and returns the motion between two keyframes with a matching soundtrack. Give it the opening and closing frames and the model fills in the shot between them. The last frame is optional: leave it out and the motion runs away from the first frame instead. This is a beta node and is billed by GPU second.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `first_frame` | The image the video starts from. It is uploaded at up to 2048x2048 pixels before the workflow runs. | IMAGE | Yes | - |
| `last_frame` | Optional closing frame. When connected, the generated motion ends on this image; without it the motion runs away from `first_frame`. | IMAGE | No | - |
| `prompt` | The text description of the motion and the sounds the shot should carry. Leading and trailing whitespace is removed before submission. | STRING | Yes | 1 to 4096 characters |
| `seed` | Random seed that controls the generated result (default: 42). | INT | Yes | 0 to 18446744073709551615 |
| `aspect_ratio` | Aspect ratio of the generated video (default: `"1:1"`). | COMBO | Yes | `"1:1"`<br />`"3:4"`<br />`"2:3"`<br />`"3:2"`<br />`"4:3"`<br />`"16:9"`<br />`"9:16"`<br />`"21:9"` |
| `resolution` | Frame size budget (default: `"480p"`). 720p costs roughly twice the GPU-seconds of 480p. | COMBO | Yes | `"480p"`<br />`"720p"` |
| `duration_seconds` | Length in seconds (default: 5). The pipeline quantises to 17-frame steps at 24 fps, so the clip lands within about two thirds of a second of this value. | INT | Yes | 5 to 15 |

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `VIDEO` | The generated video with its soundtrack. | VIDEO |
