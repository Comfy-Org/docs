## Overview

OpenAI GPT Image 2.6 generates images from a prompt, and edits them when you connect reference images, using OpenAI's GPT Image models. The node offers four models: `gpt-image-2.6-flare`, `gpt-image-2.6-sunburst`, `gpt-image-2.5-flare` and `gpt-image-2.5-sunburst`. Draw annotations on the first reference image and connect them as a markup pair to show the model exactly where to edit.

**Parameter Constraints and Limitations:**

- With `model.size` set to "Custom", `model.custom_width` and `model.custom_height` must both be multiples of 16, the longest edge must not exceed 3840, the aspect ratio must not exceed 3:1, and the total pixel count must be between 655,360 and 8,294,400.
- `model.markup` and `model.markup_alpha` must be connected together. Markup needs at least one reference image, and its width and height must match the first reference image.
- Without `model.images` the node generates images from the prompt alone; with reference images it edits and combines them.
- Reference images are downscaled before they are sent to the API.
- `model.complexity` exists only on `gpt-image-2.6-flare` and `gpt-image-2.6-sunburst`; the 2.5 models use a fixed planning depth.
