This node generates a sound effect from a text description with Pika. Describe the sound and how long it should last, and the node returns an audio clip.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | What the sound effect should be. Must not be empty. Default: "" (empty string). | STRING | Yes | 1 to 4000 characters |
| `duration` | Length of the sound effect in seconds. Default: 5.0. | FLOAT | Yes | 1.0 to 20.0 (step: 0.1) |
| `seed` | Seed for sampling. Default: 42. | INT | Yes | 0 to 2147483647 |

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `AUDIO` | The generated sound effect. | AUDIO |
