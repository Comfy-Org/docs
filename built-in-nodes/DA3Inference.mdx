This node runs the Depth Anything 3 model on an image to estimate depth and geometry information. In multi-view mode, multiple images are processed together as separate views of the same scene to produce geometrically consistent depth maps and camera poses.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `da3_model` | The Depth Anything 3 model to use for inference | DA3_MODEL | Yes | - |
| `image` | Input image or images to process. In multi-view mode, each image is treated as a separate view of the same scene | IMAGE | Yes | - |
| `resolution` | Resolution the model runs at (longest side, multiple of 14). Lower = faster / less VRAM. Higher = more detail. Output is upsampled back to the original size (default: 504) | INT | Yes | 140 to 2520 (step: 14) |
| `resize_method` | upper_bound_resize: scale so the longest side = resolution (caps memory, default).<br />lower_bound_resize: scale so the shortest side = resolution (preserves more detail on tall/wide images, uses more memory) | COMBO | Yes | `"upper_bound_resize"`<br />`"lower_bound_resize"` |
| `mode` | mono: single view image (works with any model variant).<br />multiview: all images processed together for geometric consistency + camera pose (for Small/Base models only) | COMBO | Yes | `"mono"`<br />`"multiview"` |
| `ref_view_strategy` | Which view acts as the geometric anchor (default: `"saddle_balanced"`).<br />saddle_balanced: the view most "average" across all others (best general choice).<br />saddle_sim_range: the view most visually distinct from the others.<br />first / middle: fixed positional picks | COMBO | No (conditional) | `"saddle_balanced"`<br />`"saddle_sim_range"`<br />`"first"`<br />`"middle"` |
| `pose_method` | How the camera field-of-view is estimated (default: `"cam_dec"`).<br />cam_dec: learned from image features.<br />ray_pose: derived geometrically from the model's 3D ray output.<br />Affects perspective correctness of the 3D output. Try both if results look distorted | COMBO | No (conditional) | `"cam_dec"`<br />`"ray_pose"` |

**Notes on parameter constraints:**
- The `ref_view_strategy` and `pose_method` parameters are only available when `mode` is set to `"multiview"`.
- Multi-view mode requires a Small or Base model variant. Models with other head types do not support cross-view attention or camera pose estimation.
- When `pose_method` is set to `"cam_dec"`, the loaded model must have a camera decoder. When set to `"ray_pose"`, the loaded model must have a DualDPT head.
- If the selected `pose_method` is not compatible with the loaded model, an error is raised.
- In multi-view mode, `image` must be a batch of images with shape (B, H, W, 3), where B is the number of views to process together.

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `da3_geometry` | Dictionary of non-normalized tensors. Always contains the keys: depth, image, mode. Optional keys include: sky (for Mono/Metric models), confidence (for Small/Base models), extrinsics and intrinsics (for multi-view mode) | DA3_GEOMETRY |
