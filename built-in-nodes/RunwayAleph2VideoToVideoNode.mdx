Edits a video using a text prompt with Runway's Aleph2 model. It can restyle, relight, add or remove elements, or change the viewpoint while keeping the original motion and timing, and the output resolution matches the input video. The input video must be 2-30 seconds long at 30 fps or lower, and you can optionally guide the edit with keyframes or prompt images, not both.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Describes what should appear in the output (1-1000 characters, default: empty). | STRING | Yes | 1-1000 characters |
| `video` | Input video to edit. Must be 2-30 seconds at 30 fps or lower. | VIDEO | Yes | 2-30 seconds, 30 fps max |
| `seed` | Random seed for generation (default: 0). | INT | Yes | 0 to 4294967295 |
| `public_figure_threshold` | Content moderation for recognizable public figures (default: "low"). | COMBO | Yes | `"auto"`<br />`"low"` |
| `keyframes` | Guidance images anchored to the input video, from Aleph2 Keyframe nodes (up to 5). Use keyframes or prompt images, not both. | KEYFRAME | No | Up to 5 items |
| `prompt_images` | Guidance images anchored to the output video, from Aleph2 Prompt Image nodes (up to 5). Use keyframes or prompt images, not both. | PROMPT_IMAGE | No | Up to 5 items |

**Important constraints:**
- The prompt must be between 1 and 1000 characters.
- The input video must be between 2 and 30 seconds long and run at 30 fps or lower.
- `keyframes` and `prompt_images` cannot be used together.
- Each guidance input is limited to 5 items.
- Keyframe timestamps and prompt image timestamps must not exceed the input video duration.

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `video` | The edited video generated by the Aleph2 model. The output resolution matches the input video. | VIDEO |
