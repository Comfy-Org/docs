Generates a complete, seamlessly tiling PBR material from a text description: a base texture plus up to five material maps, with optional SeedVR upscaling of the maps. An input image can drive the result as an image-to-image pass, and an input image with a mask turns it into an inpaint pass. Use it to produce game-ready or 3D-ready surfaces without scanning a real material.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Description of the material or texture to generate. | STRING | Yes | Multiline text |
| `image_size` | Output texture size. `"custom"` reveals `width` and `height` inputs. Default: `"1:1 (1024x1024)"`. | DYNAMIC_COMBO | Yes | `"1:1 (1024x1024)"`<br />`"1:1 (512x512)"`<br />`"4:3 (1024x768)"`<br />`"3:4 (768x1024)"`<br />`"16:9 (1024x576)"`<br />`"9:16 (576x1024)"`<br />`"custom"` |
| `basecolor` | Generate the basecolor (albedo) map. Default: True. | BOOLEAN | Yes | true<br />false |
| `normal` | Generate the normal map. Default: True. | BOOLEAN | Yes | true<br />false |
| `roughness` | Generate the roughness map. Default: False. | BOOLEAN | Yes | true<br />false |
| `metalness` | Generate the metalness map. Default: False. | BOOLEAN | Yes | true<br />false |
| `height` | Generate the height (displacement) map. Default: False. | BOOLEAN | Yes | true<br />false |
| `upscale_factor` | Seamless SeedVR upscaling of the PBR maps. The base texture is not upscaled, and 4x turns a 2048-pixel map into an 8K one. Default: 0 (off). | INT | Yes | 0 to 4 (step 2) |
| `seed` | Seed for reproducible generation. Default: 42. | INT | Yes | 0 to 2147483646 |
| `tiling_mode` | Tiling direction: omnidirectional, horizontal or vertical. Advanced setting. Default: `"both"`. | COMBO | Yes | `"both"`<br />`"horizontal"`<br />`"vertical"` |
| `num_inference_steps` | Denoising steps for texture generation. Advanced setting. Default: 8. | INT | Yes | 1 to 8 |
| `tile_size` | Tile size in latent space, where 64 means 512 pixels and 128 means 1024 pixels. Advanced setting. Default: 128. | INT | Yes | 32 to 256 (step 2) |
| `tile_stride` | Tile stride in latent space. Advanced setting. Default: 64. | INT | Yes | 16 to 128 (step 2) |
| `image` | Optional source image. On its own it runs image-to-image; together with a mask it runs an inpaint pass. | IMAGE | No | - |
| `mask` | Optional inpaint mask, requires an input image. White areas are regenerated and black areas are kept. | MASK | No | - |
| `strength` | How much to transform the input image. Only used when an image is connected. Advanced setting. Default: 0.6. | FLOAT | Yes | 0.01 to 1.0 (step 0.01) |
| `prompt_expansion` | Expand the prompt with a language model for richer texture detail. Off by default, because expansion reframes the prompt as a photograph and tends to wash out the metalness map. Advanced setting. | BOOLEAN | Yes | true<br />false |
| `safety_checker` | Run the provider's content safety check on the request. Advanced setting. Default: False. | BOOLEAN | Yes | true<br />false |

### custom Image Size Inputs

These inputs appear when `image_size` is set to `"custom"`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `image_size.width` | Texture width in pixels. Default: 1024. | INT | Yes | 512 to 2048 (step 16) |
| `image_size.height` | Texture height in pixels. Default: 1024. | INT | Yes | 512 to 2048 (step 16) |

**Constraints and behavior:**

* Enabling no material map is allowed: the node then returns only the base texture, and every map output stays a 1x1 placeholder.
* A mask requires an input image; a mask on its own raises an error.
* An 8K result comes from 4x upscaling the maps of a 2048-pixel render, not from a single 8K generation.
