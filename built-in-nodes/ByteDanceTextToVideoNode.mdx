# ByteDance Text to Video Node

The ByteDance Text to Video node generates videos using ByteDance models via an API based on text prompts. It takes a text description and various video settings as input, then creates a video that matches the provided specifications. The node handles the API communication and returns the generated video as output.

## Overview

The ByteDance Text to Video Node is designed to convert text prompts into videos using ByteDance's AI capabilities. Users can specify the model, resolution, aspect ratio, duration, and other parameters to control the video generation process.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | The ByteDance model to use for generation. | STRING | Yes | 
  - "seedance-1-5-pro-251215"
  - "seedance-1-0-pro-250528"
  - "seedance-1-0-pro-fast-251015" |
| `prompt` | The text prompt used to generate the video. | STRING | Yes | Multiline text input |
| `resolution` | The resolution of the output video. | STRING | Yes | 
  - "480p"
  - "720p"
  - "1080p" |
| `aspect_ratio` | The aspect ratio of the output video. | STRING | Yes | 
  - "16:9"
  - "4:3"
  - "1:1"
  - "3:4"
  - "9:16"
  - "21:9" |
| `duration` | The duration of the output video in seconds. | INT | Yes | 3 to 12 seconds |
| `seed` | Seed to use for generation. | INT | No | 0 to 2,147,483,647 |
| `camera_fixed` | Specifies whether to fix the camera. | BOOLEAN | No | - |
| `watermark` | Whether to add an "AI generated" watermark to the video. | BOOLEAN | No | - |
| `generate_audio` | This parameter is ignored for any model except `seedance-1-5-pro-251215`. | BOOLEAN | No | - |

**Parameter Constraints:**

- The `prompt` must contain at least 1 character after whitespace removal.
- The `prompt` cannot contain the following text parameters: "resolution", "ratio", "duration", "seed", "camerafixed", "watermark".
- The `duration` is limited to values between 3 and 12 seconds.
- For the `seedance-1-5-pro-251215` model, the minimum supported duration is 4 seconds.
- The `seed` accepts values from 0 to 2,147,483,647.
- The `generate_audio` parameter only has an effect when the `model` is set to `seedance-1-5-pro-251215`; it is ignored for all other models.

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `output` | The generated video file. | VIDEO |

**Note:** The ByteDance Text to Video Node is an API node and requires authentication tokens and API keys to function properly. These are provided through the `auth_token_comfy_org` and `api_key_comfy_org` hidden inputs.
