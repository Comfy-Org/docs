The Sonilo Music 1.5 node generates a complete song with sung vocals from a text prompt. Describe the genre, mood, instruments and vocals, and optionally supply your own lyrics; the node sends the request to the Sonilo service and returns the finished track as audio. Use it when you need a full song rather than an instrumental clip.

## Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `prompt` | Description of the song: genre, mood, instruments and vocals. To set the words yourself, add a `Lyrics:` block with `[Verse]` and `[Chorus]` tags; without one the model writes its own lyrics. Must be 1 to 2000 characters after trimming whitespace. | STRING | Yes | 1 to 2000 characters |
| `duration` | `auto` fits the song length to the lyrics. `custom` uses the `seconds` value, cutting lyrics that do not fit and repeating short ones. | DYNAMIC_COMBO | Yes | `"auto"`<br />`"custom"` |
| `seed` | Seed controls whether the node should re-run; results are non-deterministic regardless of seed (default: 42). | INT | Yes | 0 to 18446744073709551615 |

### Custom Duration Parameters (when `duration` is `"custom"`)

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `seconds` | Length of the generated song in seconds (default: 60). | INT | Yes | 10 to 360 |

**Note:** The `prompt` input is required and must not be empty. The node validates that it contains at least 1 character after trimming whitespace and no more than 2000.

**Note:** Usage is billed at $0.0032175 per second of the requested duration, and the price badge follows `duration.seconds` when `custom` is selected.

## Outputs

| Output Name | Description | Data Type |
| --- | --- | --- |
| `audio` | The generated song, including vocals, as an audio file. | AUDIO |
