## Overview

The ImageColorSpace node converts images between different color spaces, including sRGB, HDR (Rec.2020 HLG), and HDR PQ (Rec.2020 PQ). It supports narrowing tone-maps excess luminance across the batch and compressing out-of-gamut colors, and operates on RGB channels only, with alpha channels passed through unchanged.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `image` | The input image to be converted. | IMAGE | Yes | Any valid image format. |
| `source` | The color space of the input pixels. | COMBO | Yes | <br /> "sRGB" <br /> "HDR" <br /> "HDR PQ" |
| `destination` | The color space of the output pixels. | COMBO | Yes | <br /> "sRGB" <br /> "HDR" <br /> "HDR PQ" |

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `image` | The converted image in the specified output color space. | IMAGE |

## Notes

- The node uses 203-nit SDR white and a 1000-nit HLG reference display for conversions.
- The conversions are computed in float32 and return the intermediate device and dtype.
- Straight alpha is not color-transformed.
- The node supports conversions between sRGB, HDR (Rec.2020 HLG), and HDR PQ (Rec.2020 PQ) color spaces.
- The node performs narrowing tone-mapping and compresses out-of-gamut colors to ensure accurate conversions.
- The RGB channels are used for conversions, and the alpha channel (if present) is passed through unchanged.
