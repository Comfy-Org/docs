The Not node performs a logical NOT operation on any input value. It returns True when the input value is considered falsy (such as 0, an empty string, None, or False) and returns False when the input value is truthy, following Python's standard rules for truthiness.

## Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `value` | The input value to be inverted. Any data type is accepted and evaluated using Python's truthiness rules. | ANY | Yes | Any value |

## Outputs

| Output Name | Description | Data Type |
| --- | --- | --- |
| `output` | The logical inverse of the input value. Returns True if the input is falsy, False if the input is truthy. | BOOLEAN |
