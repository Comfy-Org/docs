Edit an image guided by a text prompt with Ideogram 4.6 or 4.5 precise editing: only what the prompt asks for changes, untouched pixels stay identical, and the output keeps the size of image 1. A whole-image edit on 4.6 returns a smaller image when the source is above 16.7 MP or 8192 pixels per side, because it is scaled down before upload. Image 1 is the image to edit and up to 4 further images can be connected as references. A single region of image 1 can also be edited on its own, selected by a mask or by bounding boxes, which returns the image at full size.

## Inputs

Selecting a `model` determines which inputs appear. Both models edit a region through `context_window`, but 4.6 takes its mask on `mask` while 4.5 takes it on `context_window_mask`, and 4.6 defaults to `"auto"` instead of `"none"`.

### Parameter Constraints

- **Image count:** at least 1 and at most 5 images; a batched input counts once per image. Whenever a mask is connected, at most 4 images are accepted, that is image 1 and 3 references.
- **Output size:** the node has no size, width or height inputs. A region edit returns the full image at the size of image 1. A whole-image edit returns the size of image 1 as uploaded: on 4.6 an image above 16.7 MP or 8192 pixels per side is scaled down first, and on 4.5 the same happens above about 4 MP or 4608 pixels per side.
- **Region source size:** with a context window in use, image 1 may be up to 8192x8192 pixels (about 67 MP); larger sources raise an error.
- **Region limits:** a region from `context_window_bboxes` can be up to 8192 pixels per side and about 16.7 MP on 4.6, and up to 4608 pixels per side and about 4 MP on 4.5. Boxes that lie entirely outside image 1 raise an error.
- **Prompt tags:** `@ImageN` is matched case-insensitively and must not exceed the number of connected images; the prompt must be non-whitespace and at most 10000 characters.
- **Upload limit:** image 1, the mask and the references together must fit in Ideogram's 50 MB upload; image 1 is re-encoded as JPEG when needed and the node raises an error if it still does not fit.
- **Content safety:** if Ideogram's content safety filter blocks the result, the node raises an error instead of returning an image.
