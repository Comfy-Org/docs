MiniMax Music3 Text Encode 使用 MiniMax Music3 CLIP 模型，将文字描述和歌词转换成用于生成音乐的声学条件序列。该节点会返回转换后的 CONDITIONING 数据，以及根据输入时长计算出的实际音频秒数。

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `clip` | MiniMax Music3 CLIP 模型，用于文本编码和条件序列生成。 | CLIP | Yes | - |
| `caption` | 描述要生成音乐的文字内容。支持多行文本和动态提示。 | STRING | Yes | - |
| `lyrics` | 要用于生成音乐的歌词文本。支持多行文本和动态提示。 | STRING | Yes | - |
| `seed` | 用于生成过程的可复现随机种子。默认值：0。 | INT | Yes | 0 到 18446744073709551615（0xffffffffffffffff） |
| `max_duration` | 生成音乐的最大时长（秒），模型可能提前结束歌曲。默认值：120.0。 | FLOAT | Yes | 0.04 到模型最大音频时长（MAX_AUDIO_FRAMES / AUDIO_FRAMES_PER_SECOND），步长 0.04 |
| `cfg_scale` | 分类器自由引导缩放系数。默认值：模型常量 CFG_SCALE。高级参数。 | FLOAT | Yes | 0.0 到 100.0，步长 0.1（保留 2 位小数） |
| `top_k` | 用于声学 token 选择的 top-k 采样值。默认值：模型常量 CFG_TOP_K。高级参数。 | INT | Yes | 1 到模型词汇表大小（C0_VOCAB_SIZE） |

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `conditioning` | 生成的声学条件序列，用于指导后续音乐生成。 | CONDITIONING |
| `seconds` | 条件序列对应的实际时长，以秒为单位。 | FLOAT |
