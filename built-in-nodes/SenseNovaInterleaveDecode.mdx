Turn the interleave history left by SenseNova Conditioning into usable text, images and thinking. Run it at the end of the loop, with End Loop accumulate disabled, to collect everything the model produced in one pass.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `clip` | SenseNova CLIP model used to decode the generated tokens. | CLIP | Yes | - |
| `conditioning` | Interleave conditioning from SenseNova Conditioning. | CONDITIONING | Yes | - |
| `samples` | Last KSampler pixel latent, needed when the loop ended on an image request. | LATENT | No | - |

**Constraints and behavior:**

* The conditioning must come from SenseNova Conditioning in the `interleave` or `self-correction` task; anything else raises an error.
* When the model is waiting for an image, connect the sampler's LATENT output to `samples`.
* Reference images connected at the start of the run are excluded from the output, and image consumers are skipped when no image was generated.

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `text` | Text decoded from the interleave history, with image markers replaced by blank lines. | STRING |
| `images` | The images the model generated during the run. | IMAGE |
| `thinking` | The model's reasoning text, when it produced one. | STRING |
