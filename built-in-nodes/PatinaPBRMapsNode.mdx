Derives a set of PBR material maps from an existing texture image: basecolor, normal, roughness, metalness and height. Enable only the maps you need, since each enabled map adds to the cost. Use it to complete a texture that has no material maps yet, or to rebuild a single broken map.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `image` | The photograph or render to derive the PBR maps from. | IMAGE | Yes | - |
| `basecolor` | Generate the basecolor (albedo) map. Default: True. | BOOLEAN | Yes | true<br />false |
| `normal` | Generate the normal map. Default: True. | BOOLEAN | Yes | true<br />false |
| `roughness` | Generate the roughness map. Default: False. | BOOLEAN | Yes | true<br />false |
| `metalness` | Generate the metalness map. Default: False. | BOOLEAN | Yes | true<br />false |
| `height` | Generate the height (displacement) map. Default: False. | BOOLEAN | Yes | true<br />false |
| `seed` | Seed for reproducible denoising. Default: 42. | INT | Yes | 0 to 2147483646 |
| `safety_checker` | Run the provider's content safety check on the request. Advanced setting. Default: False. | BOOLEAN | Yes | true<br />false |
| `auto_downscale` | Automatically downscale an input image whose longest side exceeds 2048 pixels, the model's input limit, preserving the aspect ratio; smaller images are left as they are. Disable it to raise an error on oversized images instead. Advanced setting. Default: True. | BOOLEAN | No | true<br />false |

**Constraints and behavior:**

* At least one map must be enabled, otherwise the run fails.
* The input image is limited to 2048 pixels on its longest side; either let `auto_downscale` shrink it or the run fails on an oversized image.
* Each map that is disabled still returns an output, but as a 1x1 placeholder image, so only connect the outputs you actually generated.

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `basecolor` | The generated basecolor (albedo) map, or a 1x1 placeholder when that map is disabled. | IMAGE |
| `normal` | The generated normal map, or a 1x1 placeholder when that map is disabled. | IMAGE |
| `roughness` | The generated roughness map, or a 1x1 placeholder when that map is disabled. | IMAGE |
| `metalness` | The generated metalness map, or a 1x1 placeholder when that map is disabled. | IMAGE |
| `height` | The generated height (displacement) map, or a 1x1 placeholder when that map is disabled. | IMAGE |
