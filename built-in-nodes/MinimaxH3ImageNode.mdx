Generates images from text with MiniMax H3 Image, or edits and combines up to 16 reference images. The prompt refers to the references by connection order: `@Image1`, `@Image2`, and so on.

## Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `model` | `MiniMax-H3-Image`, or `MiniMax-H3-Image-Highspeed` for faster runs. Default: `"MiniMax-H3-Image"`. | COMBO | Yes | `"MiniMax-H3-Image"`<br />`"MiniMax-H3-Image-Highspeed"` |
| `prompt` | What to generate, or how to edit the references. With reference images connected it can be at most 8,000 characters. Default: empty. | STRING | Yes | 1 to 8000 characters |
| `size` | `2K` and `4K` derive the size from an aspect ratio; `custom` sets an exact width and height. Default: `"2K"`. | DYNAMIC_COMBO | Yes | `"2K"`<br />`"4K"`<br />`"custom"` |
| `enhance_prompt` | MiniMax rewrites the prompt into a detailed scene description before generating. Image edits are always enhanced. When off, pick a fixed aspect ratio or a custom size. Default: true. | BOOLEAN | No | true<br />false |
| `seed` | Controls whether the node re-runs; results are non-deterministic regardless of the seed. Default: 42. | INT | No | 0 to 2147483647 |
| `images` | Reference images to edit or combine, addressed in the prompt as `@Image1` to `@Image16` in connection order. | AUTOGROW | No | Up to 16 images |

### Size "2K" and "4K" Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | With `auto`, MiniMax picks the ratio from the prompt, or follows the reference image when one is connected. Text to image with `enhance_prompt` off needs a fixed ratio. Default: `"auto"`. | COMBO | Yes | Multiple options available |

### Size "custom" Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `width` | Output width in pixels. Default: 2048. | INT | Yes | 512 to 7680 (step 16) |
| `height` | Output height in pixels. Default: 2048. | INT | Yes | 512 to 7680 (step 16) |

Note: For a custom size, width times height must be between 655,360 and 20,000,000 pixels with an aspect ratio of at most 3:1.

## Outputs

| Output Name | Description | Data Type |
| --- | --- | --- |
| `image` | The generated or edited image, as PNG. | IMAGE |
| `revised_prompt` | The rewritten prompt MiniMax used, when prompt enhancement was on. | STRING |
