Pick the best image from a batch. Connect `index` to Get Image from Batch to keep the chosen image, so the rest of the workflow only runs on the pick.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | Model to use (default: `"gemini-decision-1"`). | COMBO | Yes | `"gemini-decision-1"` |
| `question` | Which image to pick (default: "Which image best matches the prompt in text? If there is no text, which image has the best quality?"). | STRING | Yes | 1 to 5000 characters |
| `images` | The images to choose from, as a batch or a single batch of frames. | IMAGE | Yes | 2 to 64 images |
| `text` | Text the question is about, such as the prompt the images were made from, up to 20000 characters. | STRING | No | Up to 20000 characters |

The node needs 2 to 64 images and raises an error on a single image. Connect `text` when the choice should follow a prompt rather than image quality alone.

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `index` | Position of the picked image in the batch, starting at 0. | INT |
| `confidence` | Confidence in the pick, between 0 and 1. | FLOAT |
