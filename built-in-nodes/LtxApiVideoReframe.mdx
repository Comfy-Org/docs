Reframes a video to a new resolution and aspect ratio. The area outside the original video is generated to match its content, so a portrait clip can become a landscape one or the reverse.

## Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `video` | Video to reframe, up to 60 seconds and 1800 frames, with each side between 64 and 4096 pixels. | VIDEO | Yes | - |
| `resolution` | Output size and aspect ratio, at 720p or 1080p. Default: `"(1080p) 1080x1920 (9:16)"`. | COMBO | Yes | `"(720p) 720x720 (1:1)"`<br />`"(720p) 720x900 (4:5)"`<br />`"(720p) 900x720 (5:4)"`<br />`"(720p) 720x1280 (9:16)"`<br />`"(720p) 1280x720 (16:9)"`<br />`"(1080p) 1080x1080 (1:1)"`<br />`"(1080p) 1080x1350 (4:5)"`<br />`"(1080p) 1350x1080 (5:4)"`<br />`"(1080p) 1080x1920 (9:16)"`<br />`"(1080p) 1920x1080 (16:9)"` |
| `placement` | Where the original video sits in the new frame. The video always fills one side of the frame, so an anchor moves it along the other side only. Default: `"center"`. | DYNAMIC_COMBO | Yes | `"center"`<br />`"top"`<br />`"bottom"`<br />`"left"`<br />`"right"`<br />`"custom"` |
| `seed` | Controls whether the node re-runs; results are non-deterministic regardless of the seed. Default: 42. | INT | No | 0 to 4294967295 |

### Placement "custom" Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `x` | Left edge of the video as a fraction of the output width. Default: 0.25. | FLOAT | No | 0.0 to 0.99 (step 0.01) |
| `y` | Top edge of the video as a fraction of the output height. Default: 0.25. | FLOAT | No | 0.0 to 0.99 (step 0.01) |
| `width` | Width of the video as a fraction of the output width; the height follows the video's aspect ratio. The video must stay inside the frame and can be enlarged at most 2x. Default: 0.5. | FLOAT | No | 0.01 to 1.0 (step 0.01) |

## Outputs

| Output Name | Description | Data Type |
| --- | --- | --- |
| `video` | The reframed video. | VIDEO |
