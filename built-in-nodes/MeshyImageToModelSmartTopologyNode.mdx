This node generates a game-ready triangle mesh from a reference image at a target face count with Meshy T2.5. The topology is built at the requested polycount instead of being decimated afterwards, so the result is ready for a game engine without a separate retopology pass.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | The Meshy model version to use for generation. | COMBO | Yes | `"meshy-t2.5"` |
| `image` | The reference image the model is generated from. | IMAGE | Yes | - |
| `target_polycount` | Approximate number of triangles in the generated mesh. Default: 15000. | INT | Yes | 100 to 30000 |
| `should_texture` | Determines whether textures are generated. `"false"` skips the texture phase and returns an untextured mesh. | DYNAMIC_COMBO | Yes | `"true"`<br />`"false"` |
| `enable_pbr` | Generate PBR Maps (metallic, roughness, normal) in addition to the base color. This input is only available when `should_texture` is set to `"true"`. Default: `False`. | BOOLEAN | No | - |
| `texture_prompt` | Text prompt to guide the texturing process. Maximum 800 characters. Cannot be used at the same time as `texture_image`. This input is only available when `should_texture` is set to `"true"`. Default: `""` (empty string). | STRING | No | 1 to 800 characters |
| `texture_image` | Reference image for the texturing process. Only one of `texture_image` or `texture_prompt` may be used at the same time. This input is only available when `should_texture` is set to `"true"`. | IMAGE | No | - |
| `texture_resolution` | Texture resolution. Higher resolutions capture more surface detail. This input is only available when `should_texture` is set to `"true"`. | COMBO | No | `"2k"`<br />`"4k"`<br />`"8k"` |
| `pose_mode` | The pose of the generated character. An empty string requests no specific pose. This is an advanced setting. Default: `""` (empty string). | COMBO | Yes | `""`<br />`"A-pose"`<br />`"T-pose"` |
| `seed` | Seed controls whether the node should re-run; results are non-deterministic regardless of seed. Default: 42. | INT | Yes | 0 to 2147483647 |

**Note:** The `enable_pbr`, `texture_prompt`, `texture_image` and `texture_resolution` inputs are only available when `should_texture` is set to `"true"`.

**Constraints:**

* `target_polycount` is the number of triangles the mesh is built from, not a limit applied after generation.
* When `should_texture` is set to `"true"`, `texture_prompt` and `texture_image` cannot be used at the same time. If both are provided, the node raises an error.
* `texture_prompt` has a maximum length of 800 characters.

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `meshy_task_id` | The unique identifier of the Meshy API task. | MESHY_TASK_ID |
| `GLB` | The generated 3D model in GLB format. | FILE3DGLB |
| `FBX` | The generated 3D model in FBX format. | FILE3DFBX |
