Pad an image with a solid color or a mirrored copy of its edges. The padding can be set as exact pixels on each side, as a size multiplier, or as the smallest amount that makes the width and height divisible by a number, which is handy before saving or tiling. The original image keeps its place: `left` and `top` padding is added before it, `right` and `bottom` after it.

## Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `image` | The image to pad. | IMAGE | Yes | - |
| `padding_type` | How much padding to add: `"pad dimensions"` for exact amounts per side, `"pad by multiplier"` for an output size relative to the input, or `"pad to multiple"` to reach the next multiple. Selecting an option reveals its parameters. | DYNAMIC_COMBO | Yes | `"pad dimensions"`<br />`"pad by multiplier"`<br />`"pad to multiple"` |
| `left` | Pixels to add on the left. Available when `padding_type` is `"pad dimensions"` (default: 0). | INT | Yes | 0 to 16384 |
| `top` | Pixels to add on the top. Available when `padding_type` is `"pad dimensions"` (default: 0). | INT | Yes | 0 to 16384 |
| `right` | Pixels to add on the right. Available when `padding_type` is `"pad dimensions"` (default: 0). | INT | Yes | 0 to 16384 |
| `bottom` | Pixels to add on the bottom. Available when `padding_type` is `"pad dimensions"` (default: 0). | INT | Yes | 0 to 16384 |
| `multiplier` | Output size relative to the input, for example 1.5 adds 25% on each side. The padding is split evenly between opposite sides. Available when `padding_type` is `"pad by multiplier"` (default: 1.0). | FLOAT | Yes | 1.0 to 8.0 (step 0.01) |
| `multiple` | Pad so that the width and height are divisible by this number. The padding is split evenly between opposite sides, with the extra pixel going to the right and the bottom. Available when `padding_type` is `"pad to multiple"` (default: 32). | INT | Yes | 1 to 16384 |
| `padding_style` | What to fill the padded area with: `"color"` or `"mirror image"`. Selecting an option reveals its parameters. | DYNAMIC_COMBO | Yes | `"color"`<br />`"mirror image"` |
| `color` | Fill color for the padded area; alpha is ignored. Available when `padding_style` is `"color"` (default: `"#000000"`). | COLOR | Yes | - |
| `feathering` | Blend this many pixels of the image edge into the fill color on the padded sides. 0 leaves a hard edge. Available when `padding_style` is `"color"` (default: 0). | INT | Yes | 0 to 16384 |

`"mirror image"` reflects the image edges rather than filling them with a color. The edge pixel is not repeated, and when the padding is wider or taller than the image itself the mirrored image repeats to cover the rest. When every padding amount works out to 0, the input image is returned unchanged.

## Outputs

| Output Name | Description | Data Type |
| --- | --- | --- |
| `image` | The padded image, with the batch dimension and channel count of the input. | IMAGE |
