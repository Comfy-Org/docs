Runs the MiniMax H3 text-to-video workflow on a Comfy Cloud GPU and returns a video with a matching soundtrack. Picture and audio come out of the same pass instead of being dubbed on afterwards. This is a beta node and is billed by GPU second.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | The text description of the video, including the sounds the shot should carry. Leading and trailing whitespace is removed before submission. | STRING | Yes | 1 to 4096 characters |
| `seed` | Random seed that controls the generated result (default: 42). | INT | Yes | 0 to 18446744073709551615 |
| `aspect_ratio` | Aspect ratio of the generated video (default: `"16:9"`). | COMBO | Yes | `"1:1"`<br />`"3:4"`<br />`"2:3"`<br />`"3:2"`<br />`"4:3"`<br />`"16:9"`<br />`"9:16"`<br />`"21:9"` |
| `resolution` | Frame size budget (default: `"480p"`). 720p costs roughly twice the GPU-seconds of 480p. | COMBO | Yes | `"480p"`<br />`"720p"` |
| `duration_seconds` | Length in seconds (default: 5). The pipeline quantises to 17-frame steps at 24 fps, so the clip lands within about two thirds of a second of this value. | INT | Yes | 5 to 15 |

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `VIDEO` | The generated video with its soundtrack. | VIDEO |
