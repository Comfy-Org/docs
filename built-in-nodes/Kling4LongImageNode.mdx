Generate one tall image with Kling 4.0: a full webpage design, or an e-commerce product detail page. Pick the `skill` that matches the layout you want and the node reveals that layout's inputs.

## Inputs

### Common Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `skill` | Layout to generate. `"webpage"` designs a full page around an optional style image and subject; `"ecommerce"` builds a product detail page from product photos. | DYNAMIC_COMBO | Yes | `"webpage"`<br />`"ecommerce"` |

### `webpage` Inputs

These inputs appear when `skill` is set to `"webpage"`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `style_image` | Optional reference for the visual style and layout. Refer to it as `@Image1`. | IMAGE | No | Single image |
| `subject_image` | Optional subject to keep and design the page around. Refer to it as `@Image2`. | IMAGE | No | Single image |
| `prompt` | Optional description of the page. Refer to the style image as `@Image1` and the subject image as `@Image2`, and name the language for the page text, for example "All visible text must be in English only." Default: empty string. | STRING | Yes | Multiline text |
| `resolution` | Resolution of the output image. Default: `"1K"`. | COMBO | Yes | `"1K"`<br />`"2K"` |
| `seed` | Seed controls whether the node should re-run; results are non-deterministic regardless of seed. Default: 42. | INT | Yes | 0 to 2147483647 |

### `ecommerce` Inputs

These inputs appear when `skill` is set to `"ecommerce"`.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `product_images` | Growable slots for the product photos (`image_1` ... `image_3`). Refer to them in the prompt as `@Image1`, `@Image2`, `@Image3`. | AUTOGROW | Yes | 1 to 3 images |
| `prompt` | Optional description of the page. Refer to the product images as `@Image1`, `@Image2`, `@Image3`. Default: empty string. | STRING | Yes | Multiline text |
| `length` | Length of the generated page. Default: `"medium"`. | COMBO | Yes | `"short"`<br />`"medium"`<br />`"long"` |
| `resolution` | Resolution of the output image. Default: `"1K"`. | COMBO | Yes | `"1K"`<br />`"2K"` |
| `seed` | Seed controls whether the node should re-run; results are non-deterministic regardless of seed. Default: 42. | INT | Yes | 0 to 2147483647 |

**Constraints and behavior:**

* At most 3 product images can be connected in `ecommerce`.
* Every image must be at least 300x300 pixels with an aspect ratio between 2:5 and 5:2.
* With `webpage`, a prompt that mentions `@Image1` or `@Image2` raises an error when that image is not connected.
* The price of a call depends on the skill, the resolution and, for `ecommerce`, the page length.

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `image` | The generated long image, downloaded from Kling once the task completes. | IMAGE |
