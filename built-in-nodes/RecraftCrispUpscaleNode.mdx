Upscales an input image synchronously using the 'crisp upscale' tool, increasing its resolution and making it sharper and cleaner. Each image in the input batch is processed independently, and the upscaled results are returned as a batch.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `image` | The input image to be upscaled. Accepts a batch of images. | IMAGE | Yes | — |

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `image` | The upscaled image with enhanced resolution and clarity. Returns a batch of images if a batch was provided as input. | IMAGE |
