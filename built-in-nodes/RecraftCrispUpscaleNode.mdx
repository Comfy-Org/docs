This node upscales an image synchronously using the "crisp upscale" tool. It enhances a given raster image by increasing its resolution, making the image sharper and cleaner. When a batch of images is provided, each image is processed independently and the upscaled results are returned as a batch.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `image` | The input image to be upscaled. Accepts a batch of images; each image is processed independently. | IMAGE | Yes | — |

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `image` | The upscaled image with enhanced resolution and clarity. Returns a batch of images if a batch was provided as input. | IMAGE |
