## Overview

OpenAI GPT Image 2.6 GIF generates an animated GIF from a prompt with OpenAI's GPT Image models and returns it as a frame batch plus the frame rate, so it can go straight into a video or animated-image save node. Two models are available: `gpt-image-2.6-flare` and `gpt-image-2.6-sunburst`.

## Inputs

### Common Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `model` | The GPT Image model to use for the animation. | DYNAMIC_COMBO | Yes | `"gpt-image-2.6-flare"`<br />`"gpt-image-2.6-sunburst"` |

### gpt-image-2.6-flare and gpt-image-2.6-sunburst Inputs

Both models share the same parameters.

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `model.prompt` | What to animate. (default: `""`) | STRING | Yes | N/A |
| `model.size` | Size of each frame. Larger sizes only fit lower frame counts. (default: `"512x512"`) | COMBO | Yes | `"384x384"`<br />`"512x512"`<br />`"640x640"`<br />`"720x720"`<br />`"768x768"`<br />`"960x960"`<br />`"512x288"`<br />`"288x512"`<br />`"1024x576"`<br />`"576x1024"`<br />`"1280x720"`<br />`"720x1280"` |
| `model.frame_count` | Number of frames. Frames are billed in steps: 2 to 8, 9, 10 to 12, 13 to 16. (default: `9`) | INT | Yes | 2 to 16 |
| `model.frame_duration_ms` | How long each frame is shown, in milliseconds. (default: `200`) | INT | Yes | 20 to 2000 (step 10) |
| `model.background` | Frame background. Transparency is kept by Save WEBM with vp9, Save Animated WEBP and Save Animated PNG. (default: `"opaque"`) | COMBO | Yes | `"opaque"`<br />`"transparent"` |
| `model.quality` | Image quality. Higher levels cost more and take longer. (default: `"low"`) | COMBO | Yes | `"low"`<br />`"medium"`<br />`"high"`<br />`"xhigh"`<br />`"max"` |
| `model.complexity` | How much the model plans the animation before rendering. (default: `"high"`) | COMBO | Yes | `"low"`<br />`"medium"`<br />`"high"` |
| `model.seed` | Controls whether the node re-runs; results are non-deterministic regardless of seed. (default: `42`) | INT | Yes | 0 to 2147483647 |

**Parameter Constraints and Limitations:**

- The frame rate is calculated from `model.frame_duration_ms`: 200 ms gives 5 fps.
- A large `model.size` combined with a high `model.frame_count` is not available and shows "Size too large for this frame count" on the price badge.

## Outputs

| Output Name | Description | Data Type |
| --- | --- | --- |
| `frames` | The animation as a batch of frames, ready for a video or animated-image save node. | IMAGE |
| `fps` | Frames per second, read from the returned GIF's frame duration. | FLOAT |
