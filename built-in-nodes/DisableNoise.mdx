This node provides an empty noise configuration that disables noise generation during sampling. It outputs a special noise object containing no noise data, so any node connected to it skips noise-related operations. It is also searchable under the alias "zero noise".

| `NOISE` | Returns an empty noise configuration that can be used to disable noise generation in sampling processes. | NOISE |
