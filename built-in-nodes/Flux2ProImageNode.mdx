Generates an image with Flux.2 [pro] through the BFL API from a prompt and explicit output dimensions, optionally guided by reference images.

**Note:** This node is marked as deprecated in the source code.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Prompt for the image generation or edit. | STRING | Yes | - |
| `width` | Width of the generated image in pixels (default: 1024). | INT | Yes | 256 to 2048 (step 32) |
| `height` | Height of the generated image in pixels (default: 768). | INT | Yes | 256 to 2048 (step 32) |
| `seed` | The random seed used for creating the noise (default: 0). | INT | Yes | 0 to 18446744073709551615 |
| `prompt_upsampling` | Whether to perform upsampling on the prompt. If active, the prompt is modified automatically for more creative generation (default: `True`). This is an advanced setting. | BOOLEAN | Yes | True / False |
| `images` | Optional reference images for image-to-image generation. Each image is downscaled to at most 2048x2048 pixels before upload. | IMAGE | No | 0 to 9 images |

**Constraints:**

* Connecting more than 9 reference images raises an error.
* Output size is charged per megapixel, so larger `width` and `height` values cost more.

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `IMAGE` | The generated image. | IMAGE |
