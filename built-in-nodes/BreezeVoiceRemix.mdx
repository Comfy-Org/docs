Creates a changed copy of a voice in the same language, either from a written description of the change or from a named preset. The copy is saved to your account and returned with an audio preview.

## Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `voice` | Breeze voice to change. | BREEZE_VOICE | Yes | - |
| `change` | `custom` describes the change in text, `preset` picks a named change. Default: `"custom"`. | DYNAMIC_COMBO | Yes | `"custom"`<br />`"preset"` |
| `strength` | Higher values change the voice more. Default: 4.0. | FLOAT | No | 1.0 to 10.0 (step 0.1) |
| `seed` | Controls whether the node re-runs; results are non-deterministic regardless of the seed. Default: 42. | INT | No | 0 to 2147483647 |

### Change "custom" Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `prompt` | How the voice should change, for example older and husky. Default: empty. | STRING | Yes | Multiline text |

### Change "preset" Inputs

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `preset` | Named change, grouped by age, gender, pitch, pace, energy and emotion. | COMBO | Yes | Multiple options available |

## Outputs

| Output Name | Description | Data Type |
| --- | --- | --- |
| `voice` | The changed copy of the voice. | BREEZE_VOICE |
| `preview` | Audio preview of the remixed voice. | AUDIO |
