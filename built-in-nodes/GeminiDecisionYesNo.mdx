Ask a yes/no question about the text, images, audio or video you connect and get a boolean to route on. Connect `result` to an If/Else Switch node to send the run down one of two paths, and read `answer` and `probability` when you want to see why the model answered that way.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | Model to use (default: `"gemini-decision-1"`). | COMBO | Yes | `"gemini-decision-1"` |
| `question` | The yes/no question about what is connected, up to 5000 characters. Ask it so that "yes" is the case you act on (default: "Is there a person in the image?"). | STRING | Yes | 1 to 5000 characters |
| `threshold` | Probability of "yes" at which `result` becomes true. Clear yes answers score about 0.85 to 0.92, so 0.9 or more rejects many of them (default: 0.5). | FLOAT | Yes | 0.01 to 0.99 (step 0.01) |
| `images` | Images to ask about, up to 16 across the growable slots (`image_1` ... `image_16`). A batched image counts once per image. | IMAGE | No | Up to 16 images |
| `audio` | Audio clip to ask about. | AUDIO | No | - |
| `video` | Video clip to ask about. | VIDEO | No | - |
| `text` | Text the question is about, such as a prompt or an LLM response, up to 20000 characters. | STRING | No | Up to 20000 characters |

Connect at least one of `text`, `images`, `audio` or `video`; the node raises an error when there is nothing to look at. With several images, name them `image_1`, `image_2` and so on inside the question: a batch is expanded frame by frame, so the numbers count individual frames across the slots in connection order.

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `result` | True when the probability of "yes" reaches `threshold`, false otherwise. | BOOLEAN |
| `answer` | The verdict as the string `"yes"` or `"no"`, following the same `threshold` as `result`. | STRING |
| `probability` | Probability of "yes" between 0 and 1. | FLOAT |
