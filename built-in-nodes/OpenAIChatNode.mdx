This node generates text responses from an OpenAI model. It takes a text prompt and optionally images or files as context, and then sends this information to an OpenAI model to generate a text response.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Text inputs to the model, used to generate a response. This is the text that you want the model to respond to. | STRING | Yes | - |
| `persist_context` | This parameter is deprecated and has no effect. It is included for backward compatibility but does not influence the node's behavior. | BOOLEAN | No | - |
| `model` | The model used to generate the response. Select from the available OpenAI models. | COMBO | Yes | gpt-6-astra<br />gpt-5.6-sol<br />gpt-5.6-terra<br />gpt-5.6-luna<br />gpt-5.5-pro<br />gpt-5.5<br />gpt-5<br />gpt-5-mini<br />gpt-5-nano<br />gpt-4.1<br />gpt-4.1-mini<br />gpt-4.1-nano<br />o4-mini<br />o3<br />o1-pro<br />o1 |
| `images` | Optional image(s) to use as context for the model. To include multiple images, you can use the Batch Images node. | IMAGE | No | - |
| `files` | Optional file(s) to use as context for the model. Accepts inputs from the OpenAI Chat Input Files node. | OPENAI_INPUT_FILES | No | - |
| `advanced_options` | Optional configuration for the model. Accepts inputs from the OpenAI Chat Advanced Options node. | OPENAI_CHAT_CONFIG | No | - |

## Outputs

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `output_text` | The text response generated by the OpenAI model. This is the generated text based on the input prompt and context. | STRING |

## Notes

- The `persist_context` parameter is deprecated and has no effect. It is included for backward compatibility but should not be used.
- The `images` input can be used to provide additional context to the model. If multiple images are provided, they should be connected using the Batch Images node.
- The `files` input allows you to provide additional context in the form of files. These files should be connected from the OpenAI Chat Input Files node.
- The `advanced_options` input allows for more detailed configuration of the model's behavior. This should be connected from the OpenAI Chat Advanced Options node.
- The pricing for using this node depends on the model selected. The cost is calculated based on the number of tokens used by the model. The exact cost will be displayed in the node's UI.
