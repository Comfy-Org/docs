FLUX 3 Max Image to Video animates 1 to 10 images with FLUX 3 Max. Each image becomes a frame of the clip: one image opens it, two become its first and last frame, and more are spread across the clip or pinned to times you choose.

## Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | How the scene should move and sound (default: empty). | STRING | Yes | Multiline text |
| `keyframes` | Growable slot: connect 1 to 10 keyframe images in playback order, e.g. `image_1`, `image_2`, and so on. Each image becomes a frame of the clip. | IMAGE | Yes | 1 to 10 images |
| `placement` | `"spread across the clip"` puts the first image at the start, the last at the end and the rest evenly between; `"at times"` pins every image to a second you choose (default: `"spread across the clip"`). | DYNAMIC_COMBO | Yes | `"spread across the clip"`<br />`"at times"` |
| `aspect_ratio` | Output aspect ratio. `"auto"` follows the first keyframe image (default: `"auto"`). | COMBO | Yes | `"auto"`<br />`"21:9"`<br />`"2:1"`<br />`"16:9"`<br />`"4:3"`<br />`"1:1"`<br />`"3:4"`<br />`"9:16"` |
| `duration` | Clip length in seconds (default: `"5"`). | COMBO | Yes | `"5"`<br />`"6"`<br />`"7"`<br />`"8"`<br />`"9"`<br />`"10"`<br />`"11"`<br />`"12"`<br />`"13"`<br />`"14"`<br />`"15"`<br />`"16"`<br />`"17"`<br />`"18"`<br />`"19"`<br />`"20"` |
| `resolution` | Output resolution (default: `"720p"`). | COMBO | Yes | `"720p"`<br />`"1080p"` |
| `reasoning_level` | How much the model reasons about and expands the prompt before generating. `"high"` takes longer; the price is the same (default: `"high"`). | COMBO | Yes | `"low"`<br />`"high"` |
| `generate_audio` | Generate synchronized audio. Off produces a video with no audio track (default: true). | BOOLEAN | Yes | `true`<br />`false` |
| `seed` | Seed controlling whether the node re-runs. Results are non-deterministic regardless of this value (default: 42). | INT | Yes | 0 to 2147483646 |

### at times Inputs

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `times` | One time in seconds per image, comma-separated and increasing, e.g. "0, 2.5, 5". Only appears when `placement` is `"at times"`. | STRING | No | Comma-separated seconds |

Note: `prompt` must contain at least one character. `keyframes` must hold at least one image and cannot hold more than 10; a batched input counts once per image.

With `placement` set to `"spread across the clip"`, one or two images are sent as the start image and an optional end image, while three or more are placed on keyframes spread evenly across the clip at 24 fps.

With `placement` set to `"at times"`, `times` must give one value per image and those values must increase, cannot be negative, and the last time cannot be past the end of the clip.

The displayed price is based on `resolution` and `duration`: 720p is charged at $0.060775 per second and 1080p at $0.103675 per second until November 7, 2026, and at $0.2431 and $0.4147 per second after that date. The total estimated cost for the clip is shown in the UI.

|-------------|-------------|-----------|
| `video` | The generated video clip built from the keyframe images at the chosen aspect ratio, duration, resolution, and audio setting. | VIDEO |
