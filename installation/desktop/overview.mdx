**Comfy Desktop** is a desktop application that lets you install, manage, and launch multiple ComfyUI instances from a single launcher.

To put it simply: **Comfy Desktop** is the app that manages and launches **ComfyUI**, the node-based engine for generative AI. You don't install ComfyUI separately — Comfy Desktop handles the installation, Python environment, and dependencies for you. Each ComfyUI instance runs independently with its own version, custom nodes, and settings.

![Comfy Desktop screenshot](/images/desktop/usage/01-homepage.png)

Comfy Desktop runs on **Windows 10+**, **macOS 13+ (Apple Silicon)**, and **Linux** (official `.deb` and AppImage packages). Each standalone installation requires at least **4.85 GB** of disk space and **8 GB RAM (16 GB recommended)**. Check the platform-specific pages for full details.

## First Launch

The first time you open Comfy Desktop, a full-screen setup asks **How do you want to run Comfy?** and collects the choices it needs before anything is installed. The window stays in this setup until you finish it: if you close the app partway through, the same screen comes back on the next launch.

### Cloud or Local

Two cards cover the two ways to run ComfyUI:

- **Cloud** runs ComfyUI on Comfy Cloud GPUs. Nothing is installed on your machine and there is nothing to download. The card carries a **TRY FREE** pill while free Cloud runs are available.
- **Local** installs ComfyUI on this machine. You control the ComfyUI version, custom nodes, and startup arguments, and it runs offline.

If Comfy Desktop detects that this machine's GPU is not powerful enough for most workflows, the Cloud card carries a **Recommended for your hardware** badge and neither card is preselected, so the choice is deliberate rather than a default. **Continue** stays disabled until a card is selected.

### Terms and data sharing

Three checkboxes sit below the cards:

- **I agree to the EULA and Terms of Service**: required. The links open the EULA, the Terms of Service, and the Privacy Policy. **Continue** does not proceed until this box is ticked, every time the setup runs.
- **Help improve Comfy by sharing anonymous usage data**: optional and ticked by default. Comfy Desktop sends anonymous usage data and never collects workflow contents, prompts, generated media, or personal information. You can change this later in [Desktop Settings](/installation/desktop/usage/settings).
- **Opt in to beta features and help test what ships next**: optional and ticked by default, and available only while data sharing is on. Clearing data sharing also clears this box.

### Express Install

When **Local** is selected, an **Express Install with recommended settings** checkbox appears. It is cleared by default, so the install wizard shows the ComfyUI version, install location, and startup options before anything is written to disk. Tick it to skip that step and install a Standalone instance with the recommended settings. Comfy Desktop then names the hardware it detected under the checkbox, so you can clear it if the detected GPU is not the one you want to use.

### Migrating an existing install

If Comfy Desktop finds a Legacy Desktop installation on the machine, a **Migrate existing instance** checkbox appears next to Express Install, ticked by default. Leave it ticked to bring your workflows, models, and settings over when you continue, see [Migrate from Legacy Desktop](/installation/desktop/usage/migrate) for what moves. Clear it to install a fresh instance instead. With both checkboxes cleared, Comfy Desktop asks once more before the install starts: select **Migrate** to bring the Legacy Desktop install over, or **Start Fresh** to install a clean instance and leave the existing projects in place.

### Chinese mirrors

When the app runs in Chinese, the setup adds one question after **Continue**: **Enable Chinese Mirrors?** Select **Enable Mirrors** to clone Git repositories from `gitcode.com` and fetch PyPI packages from Aliyun and Tencent mirrors instead of `github.com` and `pypi.org`, which is faster in mainland China. Select **Not now** to keep the defaults. Either answer is stored as the **Use Chinese Mirrors (Git & PyPI)** setting, so you can change it later.

### After setup

**Continue** saves your choices and shows a short **Preparing your install…** step.

- **Cloud**: Comfy Desktop closes the setup and launches Comfy Cloud.
- **Local**: the install wizard runs unless Express Install is on, the install shows its progress, and the finished instance appears on the dashboard.

If Comfy Desktop already has a standalone, tracked, or remote installation, it skips the Cloud or Local choice and takes you straight to the dashboard once the terms are accepted. Consenting is required every time the setup runs.

The setup is a full-screen takeover: the title bar is locked while it is open, and once you leave the consent step the app menu (☰) is reduced to a single **Skip Onboarding** item, which closes the setup and drops you on the dashboard without installing anything.
