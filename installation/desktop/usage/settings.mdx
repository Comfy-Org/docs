Comfy Desktop runs your ComfyUI builds, and **Desktop settings** holds the options that apply to all of them at once, such as the folders every build shares for models or the mirror that package downloads use. Settings for a single build, such as its own folders or startup arguments, live on that build's page instead. Use **Desktop settings** to update Comfy Desktop, choose shared folders and the default install location, set mirrors and the download cache, turn on beta features, and find the app log.

## Open Desktop settings

- At the bottom of the **sidebar**, click **Desktop settings**. In a window that runs ComfyUI, you can also open the **title bar** **Menu** and select **Desktop settings**. See [Get around Comfy Desktop](/installation/desktop/usage/overview#find-your-way-around-the-sidebar) for the **sidebar** and **title bar**.

![The Builds page with the Desktop settings row outlined at the bottom of the sidebar](/images/desktop/usage/comfy_desktop_settings_00_menu.png)

The **Desktop settings** window has five tabs on its left: **Preferences**, **Updates**, **Folders**, **Advanced**, and **Logs**. Click a tab to switch to it.

## Set your preferences {#preferences}

The **Preferences** tab sets the app language and how Comfy Desktop behaves when you close windows or start builds.

![Preferences tab: Language set to English, the App behavior switches, Share anonymous usage telemetry and Opt in to beta features under Privacy, and the Comfy Desktop card under Community](/images/desktop/usage/comfy_desktop_settings_01_preferences.png)

- **Language**: the language of Comfy Desktop. Select **English** or **简体中文**.

Under **App behavior**:

| Setting | Default | What it does |
| --- | --- | --- |
| **Confirm before closing a window** | Off | Asks before closing a window when that stops ComfyUI or quits Comfy Desktop. |
| **Warn before running multiple builds** | On | Shows a warning before you start another local ComfyUI build while one is running or starting. |
| **Hide Cloud from the build picker** | Off | Hides the Comfy Cloud row from **Home**. Comfy Cloud keeps working, and you can turn the switch off again any time. |

Under **Privacy**:

- **Share anonymous usage telemetry**: sends anonymous usage data. The switch shows on until you turn it off.
- **Opt in to beta features**: lets Comfy Desktop turn on early ComfyUI features in your builds. See [Turn on beta features](#turn-on-beta-features).

Under **Community**, the **Comfy Desktop** card opens the [Comfy Desktop GitHub repository](https://github.com/Comfy-Org/Comfy-Desktop).

### Turn on beta features

With **Opt in to beta features** on, you help test ComfyUI features before they ship. When the switch is on, Comfy Desktop can add one of these startup arguments when it starts a build on this computer: `--enable-asset-hashing`, `--disable-assets`, or `--enable-agent`. It adds an argument only when the build's ComfyUI version supports it. If you already set that argument or its opposite in the build's startup arguments, Comfy Desktop leaves yours as it is.

If you never changed the switch, it follows your answer to **Help improve Comfy by sharing anonymous usage data.** in setup. To turn it on:

1. On the **Preferences** tab, turn on **Opt in to beta features**.
2. If the switch doesn't turn on, confirm data sharing first: turn **Share anonymous usage telemetry** off, then on again. Then turn on **Opt in to beta features**.

When a build starts with a beta feature, a notice in its **title bar** reads **A beta feature is on** or **The {feature} beta is on**. Click **Got it** to close it, or **Settings** to open this tab at the beta switch. When a beta feature is turned off for a build, the notice reads **A beta feature is off** or **The {feature} beta is off**.

To see which arguments a beta feature added, open the build's [**Startup arguments** tab](/installation/desktop/usage/build-startup-arguments#set-startup-arguments) and click the **+N beta** pill. It lists the arguments under **Added for this session** or **Eligible for next launch**, and **Manage beta features** opens this tab at the beta switch.

## Update Comfy Desktop {#updates}

Comfy Desktop checks for updates to itself 2 seconds after it starts and then every 10 minutes. Comfy Desktop has no update channel to choose. The update channel on a build's page is for ComfyUI in that build: see [Update ComfyUI](/installation/desktop/usage/build-management#update-comfyui).

<Note>
  On Linux, how Comfy Desktop updates depends on whether you installed the `.deb` package, the AppImage, or a source checkout. See [Updating on Linux](/installation/desktop/overview#install-comfy-desktop-for-your-os).
</Note>

### Let updates install on their own

**Automatically install Desktop updates** on the **Updates** tab is on by default. When a check finds an update, Comfy Desktop downloads it and installs it:

- On macOS and Linux, when you quit Comfy Desktop.
- On Windows, the next time you start Comfy Desktop.

When the switch is off, an update installs only when you click **Restart & update**.

### Update from the sidebar

When an update is available, an entry at the bottom of the **sidebar** shows its state:

| Entry reads | Click it to |
| --- | --- |
| **Desktop update** | Open the **Desktop update available** dialog. Click **Download**. |
| **Downloading update…** | Open **Desktop settings** at the **Updates** tab, where the download progress shows. |
| **Desktop update ready** | Open the **Desktop update ready** dialog. Click **Restart & update** to restart into the update. |

### Check for updates yourself

1. Open **Desktop settings** and click the **Updates** tab.
2. Click **Check for updates**.
3. If the tab reads **Update {version} available**, click **Download**.
4. When the tab reads **Update {version} ready to install**, click **Restart & update**.

Comfy Desktop restarts into the update. The update worked when the **Updates** tab reads **Comfy Desktop is up to date** and **Installed** shows the version you downloaded.

![Updates tab reading Comfy Desktop is up to date, with the installed version, the Check for updates button, and the Automatically install Desktop updates switch](/images/desktop/usage/comfy_desktop_settings_02_updates.png)

## Choose shared folders and the install location {#storage}

Shared folders let every build use the same models, inputs, and outputs, so you download a model once instead of once per build. The **Folders** tab sets these folders and the folder where Comfy Desktop suggests putting the builds you create.

![Folders tab: Default install location with its path, the Shared folders list with Models, Input, and Output rows, the Downloads tag, Use for downloads, and Add models folder, then Remove Comfy Desktop data](/images/desktop/usage/comfy_desktop_settings_03_storage.png)

On each folder row, click the path to open the folder, or click the folder icon to pick another folder.

- **Default install location**: the parent folder Comfy Desktop suggests when you create a build. Changing it doesn't move existing builds.
- **Shared folders**: one list of **Models**, **Input**, and **Output** folders. Every build uses them by default. To change that for one build, see [Choose which folders the build uses](/installation/desktop/usage/build-folders#choose-which-folders-the-build-uses).

To manage the shared model folders:

- **Add a models folder**: click **Add models folder** and pick the folder.
- **Choose where models download**: on a **Models** row, click **Use for downloads**. That row then carries the **Downloads** tag. A build can pick its own download folder instead. See [Where downloads are saved](/installation/desktop/usage/downloads#where-downloads-are-saved).
- **Remove a models folder**: click the **⋯** menu on the row, select **Remove**, and confirm. The files stay on disk. The folder tagged **Downloads** has no **⋯** menu, so pick another download folder first. The **Input** and **Output** rows can't be removed.

By default, the folders are:

| Folder | macOS and Linux | Windows |
| --- | --- | --- |
| **Default install location** | `~/ComfyUI-Installs` | `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Installs` |
| Shared **Models**, **Input**, **Output** | `~/ComfyUI-Shared/models`, `input`, `output` | `%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared\models`, `input`, `output` |

<Note>
  On Windows, if your user folder already had `ComfyUI-Installs` or `ComfyUI-Shared`, Comfy Desktop keeps using those. If you installed Comfy Desktop on a drive other than the system drive, the folders are under `<drive>:\Comfy-Desktop` instead.
</Note>

On macOS and Linux, the **Folders** tab also has **Remove Comfy Desktop data**, which removes the app's logs, caches, and temporary files before you uninstall it. See [uninstall Comfy Desktop on macOS](/installation/desktop/overview#uninstall-comfy-desktop) or [remove leftover data on Linux](/installation/desktop/overview#uninstall-comfy-desktop).

## Set mirrors and hardware acceleration {#advanced}

If downloads from pypi.org or github.com are slow where you are, point Comfy Desktop at a mirror on the **Advanced** tab.

![Advanced tab: PyPI mirror URL, Use Chinese mirrors (Git & PyPI), Use hardware acceleration, and the Cache section with the cache directory](/images/desktop/usage/comfy_desktop_settings_04_advanced.png)

- **PyPI mirror URL**: a Python package index, such as `https://mirrors.aliyun.com/pypi/simple/`. Comfy Desktop installs Python packages from this index and uses pypi.org as an extra index. Empty by default.
- **Use Chinese mirrors (Git & PyPI)**: off by default. When it's on, Git repositories clone from gitcode.com instead of github.com, and Python packages come from mirrors.aliyun.com and mirrors.cloud.tencent.com instead of pypi.org. When the app language is Chinese, this switch is on the **Preferences** tab under **App behavior** instead. When your system language is Chinese, setup also asks **Enable Chinese mirrors?**.
- **Use hardware acceleration**: on by default. Uses the GPU to render Comfy Desktop. Restart Comfy Desktop for a change to take effect.

### Keep the download cache

When you install a Standalone build, Comfy Desktop downloads a ComfyUI bundle into the cache folder shown under **Cache** on the **Advanced** tab. By default, the folder is named `download-cache`. If you install the same bundle again, the install shows **Using cached download** and skips the download.

Comfy Desktop keeps only the most recent bundle in this folder. When a download finishes, it deletes the other subfolders inside the cache folder, so don't store anything else there. Click the folder icon to pick another folder.

## Find the app log {#logs}

The app log records what Comfy Desktop does, including the output when a build installs or starts. Attach it when you report a problem on the [Comfy Desktop issue tracker](https://github.com/Comfy-Org/Comfy-Desktop/issues).

![Logs tab with the Diagnostics section and the Open logs folder button](/images/desktop/usage/comfy_desktop_settings_05_logs.png)

- On the **Logs** tab, under **Diagnostics**, click **Open logs folder**.

The folder holds `app.log` for the current session. At each start, and when `app.log` passes 5 MB, Comfy Desktop renames the old file to `app.log_<timestamp>.log` and keeps up to 50 of them. Pick the file from the session where the problem happened.
