Click **Desktop settings** at the bottom of the sidebar to open the global settings panel. In a build window, the ☰ menu lists it too.

![Comfy Desktop sidebar with the Desktop settings row at the bottom outlined](/images/desktop/usage/comfy_desktop_settings_00_menu.png)

The panel has five tabs: **Preferences**, **Updates**, **Folders**, **Advanced**, and **Logs**. Click a tab in the left column to switch.

## Preferences

![Preferences: language, app behavior, telemetry, and the Comfy Desktop card](/images/desktop/usage/comfy_desktop_settings_01_preferences.png)

The Preferences tab opens with a **Language** picker, then groups the rest of its controls into three sections.

- **Language**: Choose the display language. **English** and **简体中文** are available.

### App behavior

- **Confirm before closing a window**: Ask before closing a window when that stops ComfyUI or quits Comfy Desktop.
- **Warn before running multiple builds**: Show a warning before launching another local ComfyUI build while one is already running or starting.
- **Hide Cloud from the build picker**: Hide the Cloud row from Home. Cloud still works if you turn this back off.

### Privacy

- **Share anonymous usage telemetry**: Send anonymous usage data to help improve Comfy Desktop.
- **Opt in to beta features**: Let Comfy Desktop turn on early Core features for your builds. The switch stays disabled until you confirm data sharing with **Share anonymous usage telemetry**, even when telemetry is already on.

Beta features arrive as extra startup arguments, added in front of the ones you set yourself. Your own arguments keep their order and are never rewritten, and Desktop drops only a `--` flag the installed ComfyUI does not list. When it cannot read that list, it launches with your arguments exactly as they are and adds no beta arguments. When a beta feature turns on for a build, a card headed **A beta feature is on** appears in the title bar. **Got it** dismisses it, and **Settings** opens this panel on the opt-in switch. You can see which arguments a beta feature added in the build's Startup Args tab, behind the **+N beta** pill next to **Startup arguments**.

### Community

- **Comfy Desktop**: A card linking to the [Comfy Desktop GitHub repository](https://github.com/Comfy-Org/Comfy-Desktop).

## Updates

![Updates tab: up to date, installed version, Check for updates, and Automatically install Desktop updates](/images/desktop/usage/comfy_desktop_settings_02_updates.png)

- **Status line**: The first line of the tab says whether Comfy Desktop is up to date, or that an update is available, ready to install, or downloading. The installed version sits below it, with the time of the last check once a check has run.
- **Check for updates**: Manually check for a new version. When an update is available the button changes to **Download**, then to **Restart & update** once the download finishes.
- **Automatically install Desktop updates**: Auto-download and install updates in the background.

## Folders {#storage}

![Folders tab: default install location, shared folders with a Downloads tag, and Remove Comfy Desktop data](/images/desktop/usage/comfy_desktop_settings_03_storage.png)

- **Default install location**: The parent folder suggested when you create a build. Existing builds stay where they are. Click the folder icon to change it.
- **Shared folders**: Folders every build can use, so a model is downloaded once instead of once per build. Each row shows its path and its kind: **Models**, **Input**, or **Output**.
  - The models folder marked **Downloads** receives new models. On another models folder, select **Use for downloads** to give it that role.
  - Click a path to open that folder, or the folder icon to pick another location. On a model folder that is not the downloads target, the **⋯** menu removes it from the list without deleting its files.
  - **+ Add models folder** adds another models folder to the list.
- **Remove Comfy Desktop data** (macOS and Linux): Before you delete the app, remove the logs, caches, and temporary files it keeps on this computer. The confirm dialog holds three checkboxes, **Delete all ComfyUI builds**, **Delete all model files**, and **Delete shared input and output files**, all off by default. Comfy Desktop quits and cleans up, then you delete the app yourself.

Each build decides in its own **Folders** tab whether it uses the shared input and output folders, and can add model folders only that build sees. See [Managing a build](/installation/desktop/usage/manage).

## Advanced

![Advanced tab: PyPI mirror, Chinese mirrors, hardware acceleration, and the cache directory](/images/desktop/usage/comfy_desktop_settings_04_advanced.png)

- **PyPI mirror URL**: Custom pip mirror (e.g. `https://mirrors.aliyun.com/pypi/simple/`).
- **Use Chinese mirrors (Git & PyPI)**: Use Chinese mirror servers for Git and PyPI. Helpful in mainland China. When the app language is Chinese, this switch sits under **App behavior** on the Preferences tab instead.
- **Use hardware acceleration**: Use the GPU to render Comfy Desktop. Restart Comfy Desktop for changes to take effect.
- **Cache directory**: Where Comfy Desktop stores temporary and cached data. Click the folder icon to change it.

### Download Cache

Standalone builds download a ComfyUI bundle into the **Cache directory** (defaults end in `download-cache`). A later install of the same bundle skips the download and shows **Using cached download**, so it finishes much faster.

Keep **Cache directory** dedicated to this cache: when a download finishes, older subfolders inside it are pruned, so anything else you store there can be deleted. Deleting a dedicated cache folder only forces a re-download on the next install; models, inputs, outputs, and builds live elsewhere.

## Logs

![Logs tab with Diagnostics and Open logs folder](/images/desktop/usage/comfy_desktop_settings_05_logs.png)

- **Diagnostics**: **Open logs folder** reveals the Desktop app log directory (`app.log`). See [How do I check Comfy Desktop startup logs?](/installation/desktop/faq#how-do-i-check-comfy-desktop-startup-logs).

## Data Locations

Comfy Desktop stores data in platform-specific directories.

<Tabs>
  <Tab title="Windows">
```
App data:     %APPDATA%\Comfy Desktop
Logs:         %APPDATA%\Comfy Desktop\logs
Installs:     %LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Installs
Shared data:  %LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Shared
```

New installs put large data (installs, shared models, cache) under `%LOCALAPPDATA%\Comfy-Desktop`. If you already had `ComfyUI-Installs` or `ComfyUI-Shared` in your user profile before upgrading, those home-root folders are kept. If you installed the app to another drive, large data lives in `<drive>\Comfy-Desktop\` instead.
  </Tab>
  <Tab title="macOS">
```
App data:     ~/Library/Application Support/Comfy Desktop
Logs:         ~/Library/Logs/Comfy Desktop
Installs:     ~/ComfyUI-Installs
Shared data:  ~/ComfyUI-Shared
```
  </Tab>
  <Tab title="Linux">
```
Config:       ~/.config/comfyui-desktop-2
Data:         ~/.local/share/comfyui-desktop-2
Cache:        ~/.cache/comfyui-desktop-2
State:        ~/.local/state/comfyui-desktop-2
Logs:         ~/.config/Comfy Desktop/logs
Installs:     ~/ComfyUI-Installs
Shared data:  ~/ComfyUI-Shared
```

On Linux, Comfy Desktop keeps its settings, cache, data and state under `comfyui-desktop-2`, while Electron keeps the app profile and its logs under the display name `Comfy Desktop`. A source checkout uses `comfyui-desktop-2` for both. These are the default locations: `XDG_CONFIG_HOME`, `XDG_CACHE_HOME`, `XDG_DATA_HOME` and `XDG_STATE_HOME` move them, and the logs follow `XDG_CONFIG_HOME`.
  </Tab>
</Tabs>

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+R` / `Cmd+R` | Reload the current ComfyUI view |
| `Ctrl`/`Cmd` + `+` / `-` / `0` | Zoom the ComfyUI view in, out, or back to 100% |
| `Escape` | Close a dialog or popup |

Comfy Desktop does not bind `Ctrl+W` / `Cmd+W`, so a stray keystroke cannot close a window with a running build. Close a window from the ☰ menu's **Close window** instead.
