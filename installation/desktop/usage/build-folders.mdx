This page covers the **Folders** tab of a build's page. To install, add, or connect the build, see [Builds](/installation/desktop/usage/instance-management).

## Choose which folders the build uses

The **Folders** tab on the build page sets where a build finds its models and where it reads inputs and saves outputs. It has three sections: **Models**, **Input**, and **Output**. By default, all three use the shared folders from **Desktop settings**.

![Folders tab of a Standalone build: Models with Include shared directories on, a shared models folder tagged Downloads and Shared, the build's own models folder tagged Build, and Add models folder, then Input and Output with Use shared input and Use shared output on and their shared folders](/images/desktop/usage/comfy-desktop-folders.png)

- **Models**: **Include shared directories** turns the shared model folders on or off for this build. The list shows:
  - Shared folders, tagged **Shared**.
  - The build's own models folder, tagged **Build**. The build always uses it.
  - Folders you add for this build only, with **Add models folder**.
  - A row tagged **YAML** when the build has an `extra_model_paths.yaml` file.
- **Input**: with **Use shared input** on, the build reads inputs from the shared input folder. Turn it off to use the build's own input folder.
- **Output**: with **Use shared output** on, the build saves outputs to the shared output folder. Turn it off to use the build's own output folder.

In the **Models** list:

- The folder tagged **Downloads** receives new model downloads.
- A folder's menu holds the actions it allows, such as **Use for model downloads**, **Change folder**, or **Remove**.
- On a shared folder, select **Manage shared directories in Desktop settings** to change the shared folders.

Clicking the **YAML** row opens **Custom model paths**, a read-only list of the folders that `extra_model_paths.yaml` adds. To change those folders:

1. In **Custom model paths**, click **Show extra_model_paths.yaml** to find the file.
2. Edit and save the file.
3. Click **Refresh status**.

After a change, the tab shows **Restart the application (or close and reopen) for these changes to take effect.**

### Set output options for remote and Comfy Cloud builds

A remote build's **Startup arguments** tab and a Comfy Cloud build's **Storage** tab hold these settings:

![Folders tab of the Comfy Cloud build: Browser cache set to Shared, Auto-download outputs on, and Use shared output directory on, with Open Cloud at the top right](/images/desktop/usage/comfy-desktop-cloud-storage.png)

- **Browser cache**: **Shared** by default, or **Unique to this build**.
- **Auto-download outputs**: on by default. It downloads each run's outputs to this computer.
- **Use shared output directory**: appears while **Auto-download outputs** is on, and saves the outputs to the shared output folder. To pick a folder for this build, turn it off.
