This page covers the **Terminal** tab of a build's page. To install, add, or connect the build, see [Builds](/installation/desktop/usage/instance-management).

## Run commands in the terminal

The **Terminal** tab on the build page opens a shell in the `ComfyUI` folder inside the build's folder. The build's Python environment is active, so commands such as `pip` act on this build.

![Terminal tab of a Standalone build with a shell prompt that shows the active .venv environment in the ComfyUI folder](/images/desktop/usage/comfy-desktop-terminal.png)

- The terminal works whether ComfyUI is running or stopped.
- Right-click the terminal to **Copy**, **Paste**, or **Select all**.
