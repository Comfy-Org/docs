The **Assets** page in Comfy Desktop shows the files your builds and Comfy Cloud generated: images, video, audio, and 3D models. It shows one place at a time, such as Comfy Cloud or one build's output folder. To open it, click **Assets** in the **sidebar**.

<Note>
  This is Comfy Desktop's own page. Inside a running ComfyUI, the **Assets** panel is a separate gallery for that build. See [Assets in ComfyUI](/interface/assets).
</Note>

## Choose where to look

The menu at the top left of the page picks the place whose files you see. It has two groups:

- **Comfy Cloud**: your outputs from Comfy Cloud. You need to be logged in. The menu shows your workspace name under it.
- **This computer**: **Shared folder**, the shared output folder that your local builds use by default, and each local build that saves to its own output folder. The menu shows each folder's path. Click the folder button next to a place to open it in Finder or Explorer.

Assets lists the places in the workspace selected in the **sidebar**. Remote builds aren't listed. When **Auto-download outputs** is on for a remote build, its outputs appear under the folder they download to. See [Set output options for remote and Comfy Cloud builds](/installation/desktop/usage/instance-management#set-output-options-for-remote-and-comfy-cloud-builds).

## Find a file

- **Type**: **All**, **Images**, **Videos**, **3D**, or **Audio**.
- **Search by name…**: finds files whose name contains what you type.
- **Refresh assets**: loads the list again. Click it after a build saves new files.

On Comfy Cloud, a type filter checks your newest 50,000 outputs in the current sort order, and the page notes this under the list.

## Change the view

Click **View options** to set:

- **Layout**: **Masonry** or **Grid**.
- **Sort by**: **Newest first** or **Oldest first**.
- **Show**: **File name** and **File details** under each file.

Comfy Desktop remembers these options. At the bottom of the page, move between pages and choose how many files a page shows: 50, 100, or 200.

## Preview a file

Click a file to open it in the viewer. The viewer shows the file large, with its type, **Created** date, size, and dimensions. For a file on this computer, it also shows **Saved in** with the folder.

- Press the left and right arrow keys to move to the previous or next file.
- For an image, choose **Fit** or a zoom level.
- A 3D model up to 100 MB opens in a 3D view. For a larger model, the viewer reads **Can't show this 3D model. Download it to open it in a 3D app.**
- **Tags** show the file's tags. You edit tags in ComfyUI.

## Act on a file

Hold the pointer over a file for its main action, or click **More actions** (**⋯**) or right-click it for the rest:

| Action | Where | What it does |
| --- | --- | --- |
| **Open** | Images, video, and audio on this computer | Opens the file in its default app. |
| **Show in Finder**, **Show in Explorer**, or **Show in folder** | Files on this computer | Opens the file's folder. The name follows your operating system. |
| **Download** | Comfy Cloud | Saves a copy to this computer. See [Download from Comfy Cloud](#download-from-comfy-cloud). |
| **Copy** | Images | Copies the image to the clipboard. |
| **Delete** | Files on this computer | Asks **Delete {name}?**, then moves the file to the Trash, or the Recycle Bin on Windows. |

You act on one file at a time. You can't delete Comfy Cloud files from Comfy Desktop.

## Open the Workflow that made a file

When an image, video, or audio file holds the Workflow that made it, the viewer shows **Open workflow**.

- For a Comfy Cloud file, the Workflow opens in Comfy Cloud.
- For a file on this computer, the Workflow opens in the build whose folder holds the file. When several builds share the folder, choose the build under **Open in**.

Comfy Desktop starts the build if it isn't running. If the Workflow doesn't open, the page reads **Couldn't open workflow**.

## Download from Comfy Cloud

1. Select **Comfy Cloud** in the menu at the top left.
2. Hold the pointer over a file, and then click **Download**.
3. Choose a folder. The save dialog opens in the folder you saved to last, or in your Downloads folder.

The download appears in the [Downloads](/installation/desktop/usage/downloads) tray.

## Where files are saved

- **This computer**: outputs go to the shared output folder, or to a build's own output folder. Set the shared folder in [Desktop settings](/installation/desktop/usage/settings), and a build's folder on its [Folders tab](/installation/desktop/usage/instance-management#choose-which-folders-the-build-uses).
- **Comfy Cloud**: outputs stay in Comfy Cloud until you download them.

## Troubleshoot

<AccordionGroup>
  <Accordion title="No assets yet">
    The selected place has no files yet. Run a Workflow in a build, or an [app](/installation/desktop/usage/apps), and then click **Refresh assets**.
  </Accordion>
  <Accordion title="No matching assets">
    The type or search hides every file. Choose **All**, or clear **Search by name…**.
  </Accordion>
  <Accordion title="Log in to see your assets">
    **Comfy Cloud** is selected and you aren't logged in. Click **Log in to Comfy Cloud**.
  </Accordion>
  <Accordion title="This workspace has no Comfy Cloud build">
    The workspace selected in the **sidebar** has no Comfy Cloud build. Restart Comfy Desktop to add Comfy Cloud back.
  </Accordion>
  <Accordion title="Couldn't load assets">
    Comfy Desktop couldn't read the list. For Comfy Cloud, check your internet connection. Then click **Refresh assets**.
  </Accordion>
</AccordionGroup>
