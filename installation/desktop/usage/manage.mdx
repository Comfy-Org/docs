## The Manage Panel

The Manage panel content varies by instance type. The screenshots on this page show a **local standalone installation**. Cloud and remote instances have fewer tabs and settings.

To open it, go to the **Chooser** view (the home screen that lists your instances), click the ⋮ icon on an instance card, then select **Manage**.

![Manage panel for a local instance: Update, Startup Args, Snapshots, Storage, Terminal, About](/images/desktop/usage/instance_settings_00.png)

The panel has six tabs: **Update**, **Startup Args**, **Snapshots**, **Storage**, **Terminal**, and **About**.

### Update Tab

![Manage Update tab: the ComfyUI update card with installed and latest versions, above the PyTorch package card](/images/desktop/usage/instance_settings_01_update.png)

The tab holds one card for ComfyUI and one for PyTorch. Both work the same way: a headline shows what you are on, the dropdowns pick the channel or the torch stack, and the buttons under the card act on that choice.

#### ComfyUI

The headline is the ComfyUI version, with an **Up to date** badge while the selected channel has nothing newer. Once a newer release exists, the headline shows that release with an **Update available** badge, and the card adds an **Installed Version** row and a **Latest Version** row. **Last checked** shows how long ago Comfy Desktop looked; hover it for the exact time.

- **Update Channel**: **Stable** (tested releases, the default) or **Latest on GitHub** (newest commits from the master branch). The dropdown marks the channel the instance is on with **Current**.
- **Check for updates**: appears while the selected channel has nothing newer, and re-checks immediately. Comfy Desktop also runs this check on its own, see [the FAQ](/installation/desktop/faq#general-questions).
- **Update Now**: appears while the selected channel has something newer. The confirmation shows the versions it moves between, or the channel it switches to, includes any release notes the channel publishes, and points at the Snapshots tab, because Comfy Desktop saves a snapshot before it updates. If the new version breaks a custom node, restore the previous state from there.
- **Copy & Update**: copies the instance, updates the copy, and leaves the original untouched. Use it to try a new version against the node set you already have.
- **Switch Channel**: appears when you select a channel that has nothing newer to install, and moves the instance to that channel without updating it.

Selecting **Stable** on an instance that runs ahead of the stable release is a rollback: the confirmation says so, and the newer commits are removed.

#### PyTorch

The card shows the installed torch build and lists the official stacks Comfy Desktop can install for this instance. When the catalog spans several backends, a second dropdown picks the backend first (**CUDA 13.0**, **CUDA 12.8**, and so on, plus **ROCm**, **Intel XPU**, and **CPU**). Each option lists its torchvision and torchaudio versions and, when the stack ships as a bundle, its download size. It also warns when the stack lacks torchaudio, because switching removes it and custom nodes that need it stop working.

- **Change PyTorch** switches this instance to the selected stack. The confirmation shows the download, and Comfy Desktop backs up the current environment during the change and restores it if anything fails.
- **Copy & Change PyTorch** makes the same switch on a new copy of the instance and leaves the original alone.

Nightly builds are marked unstable. The picker offers them for about 45 days after their wheel date, short of the roughly 60 days after which PyTorch removes a dated nightly from its index.

### Startup Args Tab

![Manage Startup Args tab for instance launch arguments and beta args](/images/desktop/usage/instance_settings_02_startup_args.png)

Configure startup CLI arguments, Manager policy, launch mode, browser cache sharing, port conflict behavior, and environment variables.

- **Startup Arguments**: Custom CLI arguments for ComfyUI (e.g. `--listen`). Click the gear icon for categorized flags. When beta features are enabled, a **+N beta** pill next to the field lists the beta arguments Comfy Desktop added for the running session, or the ones the next launch is eligible for.
- **Manager Security Level**: Controls which node packs ComfyUI-Manager can install for this instance. Applies the next time you launch.
  - **Strict**: Blocks all node pack installs, updates, and uninstalls. Manager is read-only.
  - **Standard (recommended)**: Allows registered node packs. Blocks installs from unregistered sources (for example arbitrary git URLs).
  - **Relaxed**: Like Standard, but also allows unregistered-source installs while ComfyUI is only reachable from this machine. `--listen` blocks them again.
  - **Permissive**: Allows every risk tier. If ComfyUI is exposed with `--listen`, installs still require **Personal cloud** network mode.
- **Manager Network Mode**: How Manager talks to the node registry.
  - **Public (default)**: Uses the public registry. `--listen` blocks node pack installs at every security level.
  - **Private**: Uses a private node database you configure yourself.
  - **Offline**: No external network. Downloads are unavailable.
  - **Personal cloud**: Treats this machine as a trusted remote box and lifts the `--listen` install block. The chosen security level still applies. Only use this on a machine you control.
- **Launch Mode**: **App window** (embedded) or **Console only** (no app window; ComfyUI runs as a console process).
- **Browser Cache**: **Unique to this instance** or **Shared**.
- **If Port is Busy**: **Ask what to do**, or **Use next available port (asks if --port is set)**.
- **Environment Variables**: Add custom environment variables with the **+ Add Variable** button. Values whose key looks like a credential (for example `HF_TOKEN` or `AWS_SECRET_ACCESS_KEY`) are masked until you reveal them, and a duplicated key is flagged under the field. Comfy Desktop stores these values unencrypted on disk, so keep real secrets out of this list.

#### Build Startup Arguments with the Picker

Click the gear icon next to **Startup Arguments** to open the argument editor. It reads the flag list from the ComfyUI version installed in this instance, so it only offers arguments that version accepts.

![Startup Arguments editor: raw arguments field, search box, Active section, and the Network category](/images/desktop/usage/instance_settings_02-2_startup_args_builder.png)

- **Raw arguments** holds the argument string Comfy Desktop passes to ComfyUI. You can edit it directly, and every switch on the page follows the text. The field also checks the flags as you type: an unknown flag is marked **Unsupported**, a flag that needs a value and has none yet is marked **Missing value for**, and a flag that takes a value says it expects one until you type it. Autocomplete suggests flag names while you type.
- **Search arguments** filters the list by flag name and by the help text under each flag, and sorts the matches within each category by relevance. Clear the box to see every flag and the Active section again.
- **Active** collects the flags this instance already sets, so you can change them without hunting through every category.
- The rest of the page groups the flags by topic: Network, Launch, GPU & VRAM, Precision, Performance, Cache, Preview, Manager, Frontend, Features, Paths, Logging, Advanced, and Other. Switch a flag on to add it; flags that take a value then show an input under the help text.
- Flags that cannot be used together collapse into a single **Choose one** row. Pick one in the dropdown, or pick **None (default)** to clear the group. Turning on one member clears the others.

Flags the editor does not recognize stay in the field and survive a pass through the switches, but Comfy Desktop does not pass them to ComfyUI when it launches the instance.

Changes apply the next time the instance starts. Editing an argument while the instance is running marks the editor **Restart to apply**. If Comfy Desktop cannot read the flag list from the installed ComfyUI, the page shows that error instead of the categories, and the raw field still works.

### Snapshots Tab

![Manage Snapshots tab listing restore points for the instance](/images/desktop/usage/instance_settings_03_snapshots.png)

View, import, export, and create snapshots. Each entry shows version changes and package statistics.

- **Timeline**: Lists all snapshots chronologically with version changes and stats.
- **Latest**: Shows when the most recent snapshot was taken.
- **Import**: Import a snapshot from a file.
- **Export All**: Export all snapshots as a backup.
- **Create Snapshot**: Manually create a new snapshot at any time.
- Each snapshot entry shows:
  - Version change (e.g. `v0.20.1 → v0.24.1`)
  - Package changes
  - Node and package counts
  - **Export** and **Delete** buttons

### Storage Tab

![Manage Storage tab for per-instance model and I/O paths](/images/desktop/usage/instance_settings_04_storage.png)

Configure whether this instance uses the global shared folders, and add extra model directories that apply only to this instance.

- **Include Shared Directories**: Toggle whether this instance scans the global shared model directories from [Desktop Settings → Storage](/installation/desktop/usage/settings#storage).
- **Use Shared Input Folder**: When enabled, this instance reads input files from the global shared input folder. Disable to use this instance's own input folder.
- **Use Shared Output Folder**: When enabled, this instance writes generated outputs to the global shared output folder. Disable to use this instance's own output folder.
- **Model Directories**: Extra model directories for this instance only, searched in addition to the shared model directories.
- **Input Directory** / **Output Directory**: This instance's own folders when the shared toggles above are off.

### Terminal Tab

![Manage Terminal tab showing the instance console](/images/desktop/usage/instance_settings_05_console.png)

An interactive shell in this instance's folder. It works whether ComfyUI is running or stopped.

- Use it to inspect startup logs, errors, and Python output.
- Copy, paste, and select-all follow OS shortcuts. Right-click the terminal for the same actions.

### About Tab

![Manage About tab: the editable instance name, the instance facts, and the installation path](/images/desktop/usage/instance_settings_05_about.png)

The About tab collects what Comfy Desktop knows about the instance. A path opens in your file manager when you click it, and the copy button beside it copies the path.

The facts are grouped, and a group only appears when it has something to show:

- **Instance details**: ComfyUI version, hardware, and the Python and PyTorch versions. For a Remote Connection this group holds the connection URL and the date the connection was added.
- **Running details**: the port ComfyUI is listening on. It appears while the instance is running.
- **Location & storage**: the full installation path on disk and how much space the installation uses. Only a local installation keeps files on this machine, so Cloud and Remote Connections have no such group.
- **Lineage**: the instance this one was copied from, and when. It appears on an instance that came from **Duplicate Instance**, from a copy that changed its version or PyTorch, from a Legacy Desktop migration, or from an in-place adoption.

#### Rename an Instance

![About tab with the instance name and the pencil it reveals on hover outlined](/images/desktop/usage/instance_settings_06_rename.png)

Click the instance name at the top of the About tab, type the new name, then press Enter or click anywhere else. Hovering the name reveals a pencil that puts the cursor in the same field. Esc cancels the edit and keeps the old name, and an empty name, or the name the instance already has, changes nothing.

The Manage panel's **More** menu carries the same action as **Rename**, which opens a **Rename Instance** dialog with a **Name** field.

Comfy Desktop rejects a name that another instance already uses, and the message asks you to pick a different one. A Comfy Cloud entry keeps its name and has no pencil; local, remote, and tracked instances can be renamed.

#### Change a Remote Connection's URL

![About tab of a Remote Connection with the connection URL and its pencil outlined](/images/desktop/usage/instance_settings_07_remote_url.png)

A Remote Connection's address is the **URL** row in the About tab. Click the URL, or the pencil beside it, type the new address, and press Enter or click anywhere else. An address without a scheme is read as `http://`, and a trailing slash is dropped when the address is saved.

While the instance is connected, an edited URL takes effect on the next launch: the row shows **Restart to apply** until you restart the instance, and the running session keeps the old address. An address Comfy Desktop cannot read is not saved, and the row returns to the previous value.
