**Comfy Desktop** is a multi-installation manager that lets you run multiple ComfyUI instances from a single launcher. Linux builds are distributed as a `.deb` (Debian/Ubuntu) and an AppImage.

## System Requirements

- **OS:** Debian-based Linux (Ubuntu 22.04 or later recommended)
- **Architecture:** x64
- **GPU:** A dedicated GPU (NVIDIA / AMD) is recommended, but not required
- **Disk Space:** At least 4.85 GB recommended per installation

## Installation

### Debian / Ubuntu (`.deb`)

From the directory you downloaded the package to:

```bash
sudo apt install ./*.deb
```

Then launch **Comfy Desktop** from your application menu.

### AppImage

```bash
chmod +x ./*.AppImage
./*.AppImage
```

If Chromium cannot create a sandbox and the AppImage fails to start, retry with `--no-sandbox`:

```bash
./*.AppImage --no-sandbox
```

<Warning>`--no-sandbox` disables Electron sandboxing for every process. Use it only when the AppImage cannot start without it. This is a common AppImage packaging limitation, not the preferred launch mode.</Warning>

If the AppImage fails to start, install FUSE 2:

```bash
sudo apt install libfuse2
```

You can also build from source. See the [Comfy Desktop repository](https://github.com/Comfy-Org/Comfy-Desktop).

## Uninstalling

### Remove Comfy Desktop

- **`.deb`:** remove the package with your system package manager (`apt`, `dpkg`, or your desktop's software center).
- **AppImage:** delete the `.AppImage` file

### What Uninstalling the App Does NOT Remove

Uninstalling Comfy Desktop only removes the launcher app itself. The following data is **not** removed and must be deleted manually if you want a complete cleanup:

| Data | Default Location | Description |
|------|-----------------|-------------|
| Installations | `~/ComfyUI-Installs` | Each ComfyUI installation you created (can also be deleted from within the app). Custom install paths are also not removed. |
| Shared models & outputs | `~/ComfyUI-Shared` | Shared model library, input/output directories |
| App config | `~/.config/comfyui-desktop-2` | Settings and installation records |
| App data | `~/.local/share/comfyui-desktop-2` | Persistent app data |
| Cache | `~/.cache/comfyui-desktop-2` | Download cache and other non-essential files |
| State | `~/.local/state/comfyui-desktop-2` | Runtime state such as port locks |
| Logs | `~/.config/comfyui-desktop-2/logs` | Desktop app logs (`app.log`) |

To fully remove everything:

1. **Delete the config folder**: `~/.config/comfyui-desktop-2`
2. **Delete the data, cache, and state folders**: `~/.local/share/comfyui-desktop-2`, `~/.cache/comfyui-desktop-2`, and `~/.local/state/comfyui-desktop-2`
3. **Delete individual installations** from within the app, or manually delete `~/ComfyUI-Installs` plus any custom installation directories you configured
4. **Delete the shared model library** at `~/ComfyUI-Shared` (only if you no longer need these files)
