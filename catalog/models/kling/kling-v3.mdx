Model ID: kling/kling-v3
Provider: kling
Product: router, workflows, nodes
Input: image, text
Output: video
License: closed

Kling V3 is Kling's video model. It runs on Kling's servers, so you can use it through Comfy Router or through Partner Nodes in ComfyUI. It has no open weights, so you can't run it locally.

## Where you can run it

| Surface | Page | Use it when |
| --- | --- | --- |
| Comfy Router (API) | [Use Kling V3 with Comfy Router](/development/comfy-router/models/kling/kling-v3/code) | You're calling the model from your own code with `COMFY_API_KEY` |
| Partner Nodes (ComfyUI and Comfy Cloud) | [Kling 3.0 in ComfyUI](/tutorials/partner-nodes/kling/kling-3-0) | You're building a workflow in ComfyUI |
| Built-in node | [Kling 3.0 Video node](/built-in-nodes/KlingVideoNode) | You need the node's inputs and outputs |

Router endpoint: `POST https://api.comfy.org/v2/models/kling/kling-v3`. The live request schema is at `GET /v2/models/kling/kling-v3/openapi.json` on the Router host.

Workflow templates: `api_kling_v3_video`, `api_kling_v3_flf2v`, `api_kling_motion_control3`.
